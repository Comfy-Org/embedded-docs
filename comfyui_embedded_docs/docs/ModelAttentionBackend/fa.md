# ModelAttentionBackend

این گره به شما امکان می‌دهد انتخاب کنید که یک مدل برای محاسبات توجه خود از کدام پشتیبان توجه استفاده کند. یک کپی از مدل ایجاد کرده و تابع توجه انتخابی شما را جایگزین می‌کند که می‌تواند بر عملکرد یا رفتار تأثیر بگذارد. اگر پشتیبان انتخابی در دسترس نباشد، به‌طور خودکار به «pytorch attention» بازگشت کرده و یک هشدار ثبت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که پشتیبان توجه انتخاب‌شده روی آن اعمال می‌شود. | MODEL | بله |  |
| `attention` | پشتیبان توجه مورد استفاده (پیش‌فرض: «pytorch attention»). اگر پشتیبان انتخاب‌شده در دسترس نباشد، از «pytorch attention» به‌عنوان جایگزین استفاده می‌شود. | STRING | بله | "pytorch attention"<br>"comfy kitchen attention" |

نکته: گزینه «comfy kitchen attention» تنها زمانی فهرست می‌شود که ماژول «comfy kitchen int8 attention» در محیط فعلی موجود باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | یک کپی از مدل ورودی با اعمال پشتیبان توجه انتخاب‌شده. | MODEL |
