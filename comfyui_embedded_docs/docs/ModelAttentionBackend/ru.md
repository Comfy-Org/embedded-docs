# ModelAttentionBackend

Этот узел позволяет выбрать, какой бэкенд внимания модель использует для своих вычислений внимания. Он создает копию модели и подменяет функцию внимания на выбранную, что может повлиять на производительность или поведение. Если выбранный бэкенд недоступен, он автоматически переключается на PyTorch attention и регистрирует предупреждение.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, к которой будет применен выбранный бэкенд внимания. | MODEL | Да |  |
| `attention` | Бэкенд внимания для использования (по умолчанию: "pytorch attention"). Если выбранный бэкенд недоступен, используется PyTorch attention в качестве запасного варианта. | STRING | Да | "pytorch attention"<br>"comfy kitchen attention" |

Примечание: опция "comfy kitchen attention" отображается только тогда, когда в текущем окружении доступен модуль comfy kitchen int8 attention.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Клон входной модели с примененным выбранным бэкендом внимания. | MODEL |
