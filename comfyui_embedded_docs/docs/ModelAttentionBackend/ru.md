# Бэкенд внимания модели

Этот узел выбирает реализацию dense attention для модели, клонирует модель, применяет выбранный бэкенд и возвращает пропатченную копию. При использовании с Block Sparse Attention этот бэкенд применяется всякий раз, когда sparse attention неактивно или не поддерживается. Если выбранный бэкенд недоступен, узел автоматически переключается на PyTorch attention.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, которую нужно пропатчить. | MODEL | Да |  |
| `attention` | Применяемый бэкенд dense attention. Comfy Kitchen attention использует квантованное INT8 attention и доступен только на GPU Nvidia и AMD. По умолчанию: "pytorch attention". Если выбранный бэкенд недоступен, в качестве запасного используется PyTorch attention. | COMBO | Да | "pytorch attention"<br>"comfy kitchen attention" |

Примечание. Опция "comfy kitchen attention" отображается только в том случае, если модуль Comfy Kitchen INT8 attention доступен в текущей среде.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Клон входной модели с применённым выбранным бэкендом attention. | MODEL |
