# پیش‌پردازش تصویر TripoSplat

```markdown
این گره هر تصویر ورودی را به یک مربع مرکزی روی پس‌زمینه سیاه برش می‌زند و سپس برای رسیدن به اندازه خروجی مشخص‌شده، حاشیه‌گذاری اضافه می‌کند. هدف آن آماده‌سازی تصاویر برای مدل سه‌بعدی TripoSplat با تضمین قاب‌بندی مربعی یکنواخت و فرسایش اختیاری مات آلفا برای جلوگیری از مصنوعات لبه است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر(های) ورودی برای پیش‌پردازش | IMAGE | بله | - |
| `mask` | ماسک آلفا برای تصویر که برای تعیین ناحیه برش استفاده می‌شود | MASK | بله | - |
| `erode_radius` | فرسایش مات آلفا به اندازه این شعاع پیکسلی قبل از برش (جلوگیری از نشت لبه). پیش‌فرض: ۱ | INT | بله | 0 تا 16 |
| `size` | اندازه تصویر مربع. مدل با ۱۰۲۴ آموزش دیده است؛ اندازه‌های دیگر اجرا می‌شوند اما خارج از توزیع هستند. پیش‌فرض: ۱۰۲۴ | INT | بله | 256 تا 4096 (گام ۱۶) |

**نکته:** ورودی `mask` الزامی است و باید ارائه شود. اگر ماسک اندازه دسته (batch size) متفاوتی نسبت به تصویر داشته باشد، به‌طور خودکار تکرار می‌شود تا مطابقت یابد. اگر ابعاد ماسک با ابعاد تصویر متفاوت باشد، ماسک با استفاده از درون‌یابی دوخطی (bilinear interpolation) به‌اندازه تصویر تغییر اندازه می‌یابد. اندازه خروجی به‌صورت خودکار به نزدیک‌ترین مضرب ۱۶ گرد می‌شود تا سازگاری با الزامات پچ DINOv3 و گام VAE فلکس۲ تضمین شود. اگر ماسک هیچ پیکسل پیش‌زمینه‌ای نداشته باشد، خطا رخ می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) پیش‌پردازش‌شده که به مربع مرکزی با پس‌زمینه سیاه و حاشیه برش خورده‌اند | IMAGE |
```
