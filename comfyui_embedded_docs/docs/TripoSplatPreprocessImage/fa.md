# پیش‌پردازش تصویر TripoSplat

این گره هر تصویر ورودی را به یک مربع مرکزی روی پس‌زمینه سیاه برش می‌زند و برای رسیدن به اندازه خروجی مشخص‌شده، حاشیه (padding) اضافه می‌کند. هدف آن آماده‌سازی تصاویر برای مدل سه‌بعدی TripoSplat با اطمینان از قاب‌بندی مربعی یکنواخت و فرسایش اختیاری ماسک آلفا برای جلوگیری از مصنوعات حاشیه است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `تصویر` | تصویر(های) ورودی برای پیش‌پردازش. | IMAGE | بله | - |
| `ماسک` | ماسک آلفا برای تصویر، که برای تعیین ناحیه برش استفاده می‌شود. | MASK | بله | - |
| `شعاع فرسایش` | ماسک آلفا را با این شعاع پیکسل قبل از برش فرسایش می‌دهد (از نشت حاشیه جلوگیری می‌کند). پیش‌فرض: 1. برای غیرفعال‌کردن فرسایش، مقدار 0 را تنظیم کنید. | INT | بله | 0 تا 16 |
| `اندازه` | اندازه مربع تصویر. مدل با 1024 آموزش دیده است؛ سایر اندازه‌ها اجرا می‌شوند اما خارج از توزیع هستند. پیش‌فرض: 1024. | INT | بله | 256 تا 4096 (مرحله 16) |

**نکته:** ورودی `mask` الزامی است و باید ارائه شود. اگر اندازه دسته (batch size) ماسک با تصویر متفاوت باشد، به‌طور خودکار برای مطابقت تکرار می‌شود. اگر ابعاد ماسک با ابعاد تصویر متفاوت باشد، ماسک با استفاده از درون‌یابی دوخطی به اندازه تصویر تغییر اندازه می‌دهد. اندازه خروجی به‌طور خودکار به نزدیک‌ترین مضرب 16 (حداقل 16) به پایین گرد می‌شود تا با الزامات پچ DINOv3 و گام VAE فلکس2 سازگار باشد. اگر ماسک هیچ پیکسل پیش‌زمینه‌ای نداشته باشد (ماسک خالی)، گره خطا می‌دهد. وقتی `erode_radius` صفر است، هیچ فرسایشی اعمال نمی‌شود. برش مربعی روی جعبه محدود آلفای ماسک متمرکز است و اندازه آن 1.2 برابر بعد بزرگ‌تر جعبه محدود است؛ هر ناحیه خارج از مرزهای تصویر با رنگ سیاه پر می‌شود.

| نام خروجی | توضیحات | نوع داده |
