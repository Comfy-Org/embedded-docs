# TripoSplat Предобработка Изображения

Этот узел обрезает каждое входное изображение до центрированного квадрата на черном фоне и добавляет отступы для достижения указанного выходного размера. Он предназначен для подготовки изображений для 3D-модели TripoSplat, обеспечивая согласованное квадратное кадрирование и опциональное эрозирование альфа-маски для предотвращения артефактов на границах.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение (изображения) для предварительной обработки. | IMAGE | Да | - |
| `mask` | Альфа-маска для изображения, используемая для определения области кадрирования. | MASK | Да | - |
| `erode_radius` | Эродировать альфа-маску на этот радиус в пикселях перед кадрированием (позволяет избежать растекания по краям). По умолчанию: 1. Установите 0 для отключения эрозии. | INT | Да | от 0 до 16 |
| `size` | Размер квадратного изображения. Модель обучена на 1024; другие размеры работают, но находятся вне распределения. По умолчанию: 1024. | INT | Да | от 256 до 4096 (шаг 16) |

**Примечание:** Входной параметр `mask` обязателен и должен быть предоставлен. Если маска имеет другой размер пакета, чем изображение, она автоматически повторяется для соответствия. Если размеры маски отличаются от размеров изображения, маска изменяется до размеров изображения с помощью билинейной интерполяции. Выходной размер автоматически округляется вниз до ближайшего кратного 16 (минимум 16) для обеспечения совместимости с требованиями к патчам DINOv3 и шагам VAE Flux2. Узел вызывает ошибку, если маска не содержит пикселей переднего плана (пустая маска). Когда `erode_radius` равен 0, эрозия не применяется. Квадратное кадрирование центрируется по ограничивающей рамке альфы маски и имеет размер 1.2 от большей стороны ограничивающей рамки; любая область за пределами изображения заполняется черным.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Предварительно обработанное изображение (изображения), обрезанное до центрированного квадрата на черном фоне с отступами, в запрошенном разрешении `size`. | IMAGE |
