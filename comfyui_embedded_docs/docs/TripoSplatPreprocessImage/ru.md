# TripoSplat Предобработка Изображения

Этот узел обрезает каждое входное изображение до центрированного квадрата на черном фоне, затем добавляет заполнение (padding) для достижения указанного выходного размера. Он предназначен для подготовки изображений для 3D-модели TripoSplat, обеспечивая согласованное квадратное кадрирование и опциональную эрозию альфа-маски для предотвращения краевых артефактов.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение (изображения) для предварительной обработки | IMAGE | Да | - |
| `mask` | Альфа-маска изображения, используемая для определения области кадрирования | MASK | Да | - |
| `erode_radius` | Эрозия альфа-маски на указанный радиус в пикселях перед кадрированием (предотвращает растекание по краям). По умолчанию: 1 | INT | Да | 0 to 16 |
| `size` | Размер квадратного изображения. Модель обучена на 1024; другие размеры работают, но выходят за пределы распределения. По умолчанию: 1024 | INT | Да | 256 to 4096 (step of 16) |

**Примечание:** Входной параметр `mask` обязателен и должен быть предоставлен. Если размер пакета маски отличается от размера пакета изображения, маска автоматически повторяется для соответствия. Если размеры маски отличаются от размеров изображения, маска масштабируется до размеров изображения с помощью билинейной интерполяции. Выходной размер автоматически округляется вниз до ближайшего числа, кратного 16, для обеспечения совместимости с требованиями к шагу (stride) патчей DINOv3 и VAE Flux2. Если маска не содержит пикселей переднего плана, возникает ошибка.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Предварительно обработанное изображение (изображения), обрезанное до центрированного квадрата на черном фоне с заполнением | IMAGE |
