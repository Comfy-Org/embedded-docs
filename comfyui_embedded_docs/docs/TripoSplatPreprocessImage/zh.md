# TripoSplat 预处理图像

此节点将每个输入图像裁剪为黑色背景上的居中正方形，然后添加填充以达到指定的输出尺寸。它旨在通过确保一致的方形构图和可选的 Alpha 遮罩腐蚀来防止边缘伪影，从而为 TripoSplat 3D 模型准备图像。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要预处理的输入图像 | IMAGE | 是 | - |
| `mask` | 图像的 Alpha 遮罩，用于确定裁剪区域 | MASK | 是 | - |
| `erode_radius` | 在裁剪前按此像素半径腐蚀 Alpha 遮罩（避免边缘渗色）。默认值：1 | INT | 是 | 0 to 16 |
| `size` | 正方形图像尺寸。模型在 1024 下训练；其他尺寸可以运行但偏离分布。默认值：1024 | INT | 是 | 256 to 4096 (step of 16) |

**注意：** `mask` 输入为必填项，必须提供。如果遮罩的批次大小与图像不同，则会自动重复以匹配。如果遮罩尺寸与图像尺寸不同，则使用双线性插值将遮罩调整为匹配图像。输出尺寸会自动向下取整到最接近的 16 的倍数，以确保与 DINOv3 patch 和 Flux2 VAE stride 要求兼容。如果遮罩不包含任何前景像素，则会引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 预处理后的图像，裁剪为黑色背景上的居中正方形并添加填充 | IMAGE |
