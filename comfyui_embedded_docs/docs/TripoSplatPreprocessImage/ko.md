# TripoSplat 전처리 이미지

이 노드는 각 입력 이미지를 검은색 배경의 중앙 정사각형으로 크롭한 후, 지정된 출력 크기에 도달하도록 패딩을 추가합니다. 일관된 정사각형 프레임을 보장하고 선택적 알파 매트 침식을 통해 테두리 아티팩트를 방지하여 TripoSplat 3D 모델용 이미지를 준비하도록 설계되었습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 전처리할 입력 이미지 | IMAGE | 예 | - |
| `mask` | 크롭 영역을 결정하는 데 사용되는 이미지의 알파 마스크 | MASK | 예 | - |
| `erode_radius` | 크롭 전에 알파 매트를 이 픽셀 반경만큼 침식합니다(테두리 번짐 방지). 기본값: 1 | INT | 예 | 0 to 16 |
| `size` | 정사각형 이미지 크기. 모델은 1024에서 학습되었으며, 다른 크기로도 실행되지만 분포를 벗어납니다. 기본값: 1024 | INT | 예 | 256 to 4096 (step of 16) |

**참고:** `mask` 입력은 필수이며 반드시 제공해야 합니다. 마스크의 배치 크기가 이미지와 다른 경우, 자동으로 반복되어 일치시킵니다. 마스크의 크기가 이미지와 다른 경우, 쌍선형 보간법을 사용하여 이미지 크기에 맞게 조정합니다. 출력 크기는 DINOv3 패치 및 Flux2 VAE 스트라이드 요구 사항과의 호환성을 위해 자동으로 가장 가까운 16의 배수로 내림됩니다. 마스크에 전경 픽셀이 없으면 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 검은색 배경의 중앙 정사각형으로 크롭되고 패딩이 추가된 전처리된 이미지 | IMAGE |
