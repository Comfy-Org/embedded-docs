# TripoSplat 前処理画像

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 前処理する入力画像です。 | IMAGE | Yes | - |
| `mask` | 画像のアルファマスクで、クロップ領域を決定するために使用されます。 | MASK | Yes | - |
| `erode_radius` | クロップ前にアルファマットをこのピクセル半径だけ収縮させます（境界ブリードを防ぎます）。デフォルト: 1 | INT | Yes | 0 to 16 |
| `size` | 正方形画像のサイズ。モデルは1024でトレーニングされており、他のサイズでも実行できますが、分布外となります。デフォルト: 1024 | INT | Yes | 256 to 4096 (step of 16) |

**注記:** `mask` 入力は必須であり、必ず指定する必要があります。マスクのバッチサイズが画像と異なる場合、自動的に繰り返して一致させます。マスクの寸法が画像の寸法と異なる場合、バイリニア補間を使用して画像に合わせてマスクのサイズを変更します。出力サイズは、DINOv3パッチおよびFlux2 VAEストライド要件との互換性を確保するために、自動的に16の倍数に切り捨てられます。マスクに前景ピクセルが含まれていない場合は、エラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 黒背景の中央正方形にクロップされ、パディングが追加された前処理済みの画像です。 | IMAGE |
