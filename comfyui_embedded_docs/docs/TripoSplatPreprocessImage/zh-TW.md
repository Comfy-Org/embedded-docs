# TripoSplat 預處理圖像

此節點將每個輸入影像裁切為黑底中央正方形，然後加入邊距以達到指定的輸出尺寸。其設計目的是為 TripoSplat 3D 模型準備影像，確保一致的正方形取景，並可選擇進行 Alpha 遮罩侵蝕，以防止邊緣偽影。

## 輸入

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要預處理的輸入影像 | IMAGE | 是 | - |
| `mask` | 影像的 Alpha 遮罩，用於決定裁切區域 | MASK | 是 | - |
| `erode_radius` | 在裁切前以此像素半徑侵蝕 Alpha 遮罩（避免邊緣滲色）。預設值：1 | INT | 是 | 0 到 16 |
| `size` | 正方形影像尺寸。模型以 1024 訓練；其他尺寸可執行但會偏離分佈。預設值：1024 | INT | 是 | 256 到 4096（步進 16） |

**注意：** `mask` 輸入為必要項目，必須提供。如果遮罩的批次大小與影像不同，系統會自動重複遮罩以匹配。如果遮罩的尺寸與影像尺寸不同，則會使用雙線性插值將遮罩調整為與影像相符。輸出尺寸會自動無條件捨去至最接近的 16 倍數，以確保符合 DINOv3 patch 與 Flux2 VAE stride 的需求。若遮罩不包含任何前景像素，則會引發錯誤。

## 輸出

| 輸出名稱 | 描述 | 資料型別 |
|-------------|-------------|-----------|
| `image` | 經過預處理的影像，裁切為黑底中央正方形並加入邊距 | IMAGE |
