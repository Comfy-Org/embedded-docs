# TripoSplat 預處理圖像

此節點將每個輸入圖片裁切為黑色背景上的居中正方形，並添加邊距以達到指定的輸出尺寸。它旨在透過確保一致的正方形取景以及可選的 Alpha 遮罩侵蝕來防止邊緣偽影，從而為 TripoSplat 3D 模型準備圖片。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `圖像` | 要預處理的輸入圖片。 | IMAGE | 是 | - |
| `遮罩` | 圖片的 Alpha 遮罩，用於決定裁切區域。 | MASK | 是 | - |
| `腐蝕半徑` | 在裁切前以這個像素半徑侵蝕 Alpha 遮罩（避免邊緣滲色）。預設：1。設定為 0 以停用侵蝕。 | INT | 是 | 0 至 16 |
| `尺寸` | 正方形圖片尺寸。模型以 1024 訓練；其他尺寸可以運行，但會偏離分佈。預設：1024。 | INT | 是 | 256 至 4096 (step of 16) |

**注意：** 必須提供 `mask` 輸入。如果遮罩的批次大小與圖片不同，則會自動重複以匹配。如果遮罩尺寸與圖片尺寸不同，則使用雙線性插值將遮罩調整為與圖片相同。輸出尺寸會自動向下取整到最接近的 16 的倍數（最小為 16），以確保與 DINOv3 patch 和 Flux2 VAE stride 需求相容。如果遮罩中沒有前景像素（空遮罩），節點會引發錯誤。當 `erode_radius` 為 0 時，不套用侵蝕。正方形裁切以遮罩的 Alpha 邊界框為中心，尺寸設定為較大邊界框尺寸的 1.2 倍；超出圖片邊界的任何區域將以黑色填充。
