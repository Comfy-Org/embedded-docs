# FluxDisableGuidance

این گره عملکرد جاسازی راهنما (guidance embed) را برای مدل‌های Flux و مدل‌های مشابه Flux به‌طور کامل غیرفعال می‌کند. داده‌های شرطی‌سازی (conditioning) را به‌عنوان ورودی دریافت می‌کند، مؤلفه راهنما را با تنظیم آن بر روی None حذف می‌کند و داده‌های شرطی‌سازی اصلاح‌شده را بازمی‌گرداند و عملاً شرطی‌سازی مبتنی بر راهنما را برای فرایند تولید غیرفعال می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |

| `conditioning` | داده‌های شرطی‌سازی که باید پردازش شده و راهنما از آن حذف شود | CONDITIONING | بله | - |
