# FluxDisableGuidance

Этот узел полностью отключает guidance-эмбеддинг в моделях Flux и Flux-подобных. Он принимает данные кондиционирования на вход и устанавливает значение guidance в None, тем самым отключая кондиционирование на основе guidance для процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные кондиционирования для обработки и удаления из них guidance | CONDITIONING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Изменённые данные кондиционирования с отключённым guidance | CONDITIONING |
