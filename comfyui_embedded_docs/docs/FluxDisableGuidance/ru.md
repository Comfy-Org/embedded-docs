# FluxDisableGuidance

Этот узел полностью отключает эмбеддинг guidance на моделях Flux и подобных. Он принимает данные кондиционирования на вход и удаляет компонент guidance, устанавливая его в None, фактически отключая кондиционирование, основанное на guidance, для процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные кондиционирования для обработки и удаления guidance | CONDITIONING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Измененные данные кондиционирования с отключенным guidance | CONDITIONING |
