# FluxDisableGuidance

Этот узел полностью отключает функциональность встраивания guidance для моделей Flux и подобных им. Он принимает данные кондиционирования на вход, удаляет компонент guidance, устанавливая его в None, и возвращает модифицированные данные кондиционирования, фактически отключая кондиционирование на основе guidance для процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные кондиционирования для обработки и удаления guidance | CONDITIONING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Модифицированные данные кондиционирования с отключенным guidance | CONDITIONING |
