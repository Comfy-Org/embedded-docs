# Ideogram 4 스케줄러

Ideogram 4 Scheduler 노드는 Ideogram 4 참조 스케줄을 기반으로 확산 샘플링 과정을 위한 시그마 값(노이즈 수준)의 시퀀스를 생성합니다. 이 노드는 이미지 크기에 적응하는 사용자 지정 노이즈 스케줄을 생성하며, 통계적 매개변수를 통한 미세 조정을 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `steps` | 스케줄을 생성할 샘플링 단계 수입니다 (기본값: 20) | INT | 예 | 1 to 200 |
| `width` | 이미지의 너비(픽셀 단위)입니다 (기본값: 1024) | INT | 예 | 256 to 8192 (step: 16) |
| `height` | 이미지의 높이(픽셀 단위)입니다 (기본값: 1024) | INT | 예 | 256 to 8192 (step: 16) |
| `mu` | 로짓-정규 분포의 평균 매개변수로, 중심 노이즈 수준을 제어합니다 (기본값: 0.0) | FLOAT | 예 | -10.0 to 10.0 (step: 0.05) |
| `std` | 로짓-정규 분포의 표준 편차 매개변수로, 노이즈 수준의 분포를 제어합니다 (기본값: 1.75) | FLOAT | 예 | 0.1 to 5.0 (step: 0.05) |

참고: 스케줄의 실질적인 중심 이동은 `mu`와 512×512 기준에 대한 이미지 면적에 기반한 해상도 항이 결합되어 결정됩니다. 따라서 이미지 면적이 클수록 작은 면적에 비해 노이즈 스케줄이 이동합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SIGMAS` | 노이즈 스케줄을 나타내는 시그마 값 텐서로, 길이는 `steps + 1`과 같습니다. 값은 높은 노이즈에서 낮은 노이즈 순으로 감소하며, 완전한 노이즈 제거를 위해 마지막 값은 0.0으로 설정됩니다. | SIGMAS |
