# Ideogram 4 Scheduler

צומת Ideogram 4 Scheduler יוצר רצף של ערכי סיגמא (רמות רעש) עבור תהליך דגימת הדיפוזיה, בהתאם ללוח הזמנים הייחוסי של Ideogram 4. הוא יוצר לוח זמני רעש מותאם אישית שמסתגל לממדי התמונה ומאפשר כוונון עדין באמצעות פרמטרים סטטיסטיים.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `steps` | מספר צעדי הדגימה שעבורם יש ליצור את לוח הזמנים (ברירת מחדל: 20). הפלט מכיל `steps + 1` ערכי סיגמא. | INT | כן | 1 עד 200 |
| `width` | רוחב התמונה בפיקסלים (ברירת מחדל: 1024). הרזולוציה ביחס לייחוס של 512×512 מסיטה את לוח זמני הרעש. | INT | כן | 256 עד 8192 (צעד: 16) |
| `height` | גובה התמונה בפיקסלים (ברירת מחדל: 1024). הרזולוציה ביחס לייחוס של 512×512 מסיטה את לוח זמני הרעש. | INT | כן | 256 עד 8192 (צעד: 16) |
| `mu` | פרמטר התוחלת של ההתפלגות הלוגיט-נורמלית, השולט ברמת הרעש המרכזית. משולב עם איבר הרזולוציה כדי ליצור את היסט ה-logSNR (ברירת מחדל: 0.0). | FLOAT | כן | -10.0 עד 10.0 (צעד: 0.05) |
| `std` | פרמטר סטיית התקן של ההתפלגות הלוגיט-נורמלית, השולט בפיזור רמות הרעש (ברירת מחדל: 1.75). | FLOAT | כן | 0.1 עד 5.0 (צעד: 0.05) |

הערה: לוח הזמנים נגזר מהתפלגות לוגיט-נורמלית על פני זמן ייחוס. איבר רזולוציה השווה ל-`0.5 * log((width × height) / (512 × 512))` מתווסף ל-`mu`, כך שתמונות גדולות או קטנות יותר מסיטות את לוח הזמנים ביחס לייחוס של 512×512 באותו ערך `mu`.

## פלטים

| שם פלט | תיאור | סוג נתון |
|-------------|-----------|-----------|
| `SIGMAS` | טנזור של ערכי סיגמא המייצג את לוח זמני הרעש, שאורכו שווה ל-`steps + 1`. הערכים יורדים מרעש גבוה לרעש נמוך, כאשר הערך האחרון מוגדר ל-0.0 לצורך הסרת רעש מלאה. | SIGMAS |
