# Ideogram 4 スケジューラー

Ideogram 4 Scheduler ノードは、Ideogram 4 リファレンススケジュールに基づいて、拡散サンプリングプロセス用のシグマ値（ノイズレベル）のシーケンスを生成します。画像サイズに適応するカスタムノイズスケジュールを作成し、統計パラメータによる微調整を可能にします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `steps` | スケジュールを生成するためのサンプリングステップ数（デフォルト：20） | INT | はい | 1 to 200 |
| `width` | 画像の幅（ピクセル単位）（デフォルト：1024） | INT | はい | 256 to 8192 (step: 16) |
| `height` | 画像の高さ（ピクセル単位）（デフォルト：1024） | INT | はい | 256 to 8192 (step: 16) |
| `mu` | ロジット正規分布の平均パラメータ。中心ノイズレベルを制御します（デフォルト：0.0） | FLOAT | はい | -10.0 to 10.0 (step: 0.05) |
| `std` | ロジット正規分布の標準偏差パラメータ。ノイズレベルの広がりを制御します（デフォルト：1.75） | FLOAT | はい | 0.1 to 5.0 (step: 0.05) |

注：スケジュールの実効的な中心シフトは、`mu` と、512×512のリファレンスに対する画像面積に基づく解像度項を組み合わせて決定されます。したがって、画像面積が大きいほど、小さい場合と比較してノイズスケジュールがシフトします。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SIGMAS` | ノイズスケジュールを表すシグマ値のテンソルで、長さは `steps + 1` です。値は高ノイズから低ノイズへ降順に並び、完全なデノイズのために最終値は 0.0 に設定されます。 | SIGMAS |
