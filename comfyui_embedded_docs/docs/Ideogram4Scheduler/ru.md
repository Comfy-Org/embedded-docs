# Планировщик Ideogram 4

The Ideogram 4 Scheduler node generates a sequence of sigma values (noise levels) for the diffusion sampling process, based on the Ideogram 4 reference schedule. It creates a custom noise schedule that adapts to the image dimensions and allows fine-tuning through statistical parameters.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `steps` | Количество шагов сэмплирования, для которых создается расписание (по умолчанию: 20) | INT | Да | 1 to 200 |
| `width` | Ширина изображения в пикселях (по умолчанию: 1024) | INT | Да | 256 to 8192 (step: 16) |
| `height` | Высота изображения в пикселях (по умолчанию: 1024) | INT | Да | 256 to 8192 (step: 16) |
| `mu` | Параметр среднего для логит-нормального распределения, управляющий центральным уровнем шума (по умолчанию: 0.0) | FLOAT | Да | -10.0 to 10.0 (step: 0.05) |
| `std` | Параметр стандартного отклонения для логит-нормального распределения, управляющий разбросом уровней шума (по умолчанию: 1.75) | FLOAT | Да | 0.1 to 5.0 (step: 0.05) |

Примечание: Эффективный центральный сдвиг расписания определяется `mu` в сочетании с членом разрешения, основанным на площади изображения относительно эталонных 512×512. Поэтому большие площади изображения сдвигают расписание шума по сравнению с меньшими.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SIGMAS` | Тензор значений сигма, представляющий расписание шума, длиной равной `steps + 1`. Значения убывают от высокого шума к низкому, при этом последнее значение установлено в 0.0 для полного удаления шума. | SIGMAS |
