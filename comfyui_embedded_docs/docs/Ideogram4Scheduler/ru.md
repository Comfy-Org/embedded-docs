# Планировщик Ideogram 4

Узел Ideogram 4 Scheduler генерирует последовательность значений сигмы (уровней шума) для процесса диффузионной выборки на основе эталонного расписания Ideogram 4. Он создает пользовательское расписание шума, которое адаптируется к размерам изображения и позволяет выполнять точную настройку с помощью статистических параметров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `шаги` | Количество шагов сэмплирования для генерации расписания (по умолчанию: 20). Выходные данные содержат значения сигмы в количестве `steps + 1`. | INT | Да | 1 до 200 |
| `ширина` | Ширина изображения в пикселях (по умолчанию: 1024). Разрешение относительно эталонного значения 512×512 смещает расписание шума. | INT | Да | 256 до 8192 (step: 16) |
| `высота` | Высота изображения в пикселях (по умолчанию: 1024). Разрешение относительно эталонного значения 512×512 смещает расписание шума. | INT | Да | 256 до 8192 (step: 16) |
| `mu` | Параметр среднего для логит-нормального распределения, управляющий центральным уровнем шума. В сочетании с членом разрешения образует сдвиг logSNR (по умолчанию: 0.0). | FLOAT | Да | -10.0 до 10.0 (step: 0.05) |
| `std` | Параметр стандартного отклонения для логит-нормального распределения, управляющий разбросом уровней шума (по умолчанию: 1.75). | FLOAT | Да | 0.1 до 5.0 (step: 0.05) |

Примечание: расписание выводится из логит-нормального распределения по эталонному времени. Член разрешения, равный `0.5 * log((width × height) / (512 × 512))`, добавляется к `mu`, поэтому изображения большего или меньшего размера смещают расписание относительно эталона 512×512 при том же значении `mu`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SIGMAS` | Тензор значений сигмы, представляющий расписание шума, длиной равной `steps + 1`. Значения убывают от высокого шума к низкому, при этом конечное значение устанавливается в 0.0 для полного удаления шума. | SIGMAS |
