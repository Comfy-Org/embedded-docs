# Ideogram 4 调度器

Ideogram 4 Scheduler 节点基于 Ideogram 4 参考调度生成扩散采样过程中的一组 sigma 值（噪声水平）。它会创建适应图像尺寸的自定义噪声调度，并允许通过统计参数进行微调。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `steps` | 用于生成调度的采样步数（默认值：20） | INT | 是 | 1 至 200 |
| `width` | 图像宽度（以像素为单位）（默认值：1024） | INT | 是 | 256 至 8192（步长：16） |
| `height` | 图像高度（以像素为单位）（默认值：1024） | INT | 是 | 256 至 8192（步长：16） |
| `mu` | logit-normal 分布的均值参数，控制中心噪声水平（默认值：0.0） | FLOAT | 是 | -10.0 至 10.0（步长：0.05） |
| `std` | logit-normal 分布的标准差参数，控制噪声水平的分布范围（默认值：1.75） | FLOAT | 是 | 0.1 至 5.0（步长：0.05） |

注意：调度的有效中心偏移由 `mu` 与基于图像面积相对 512×512 参考的分辨率项共同决定。因此，较大的图像面积会使噪声调度相对较小面积产生偏移。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `SIGMAS` | 表示噪声调度的 sigma 值张量，长度等于 `steps + 1`。数值从高噪声降至低噪声，最终值设为 0.0 以实现完全去噪。 | SIGMAS |
