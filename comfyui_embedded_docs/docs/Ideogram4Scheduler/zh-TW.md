# Ideogram 4 排程器

Ideogram 4 Scheduler 節點會根據 Ideogram 4 參考排程，為擴散取樣過程產生一系列 sigma 值（雜訊級別）。它會建立自訂雜訊排程，以適應影像尺寸，並可透過統計參數進行微調。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `steps` | 要為其產生排程的取樣步數（預設值：20） | INT | 是 | 1 到 200 |
| `width` | 影像的寬度（以像素為單位）（預設值：1024） | INT | 是 | 256 到 8192（間距：16） |
| `height` | 影像的高度（以像素為單位）（預設值：1024） | INT | 是 | 256 到 8192（間距：16） |
| `mu` | logit-常態分佈的平均數參數，控制中央雜訊級別（預設值：0.0） | FLOAT | 是 | -10.0 到 10.0（間距：0.05） |
| `std` | logit-常態分佈的標準差參數，控制雜訊級別的分佈範圍（預設值：1.75） | FLOAT | 是 | 0.1 到 5.0（間距：0.05） |

注意：排程的有效中心偏移由 `mu` 與解析度項共同決定，其中解析度項是根據影像面積相對於 512×512 參考面積計算。因此，與較小影像面積相比，較大的影像面積會使雜訊排程產生偏移。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `SIGMAS` | 代表雜訊排程的 sigma 值張量，長度等於 `steps + 1`。數值從高雜訊遞減到低雜訊，最終值設為 0.0 以完成完整去雜訊。 | SIGMAS |
