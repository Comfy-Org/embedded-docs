# Ideogram 4 排程器

Ideogram 4 Scheduler 節點會根據 Ideogram 4 參考排程，為擴散取樣過程生成一系列 sigma 值（雜訊水平）。它建立自訂的雜訊排程，可適應影像尺寸，並允許透過統計參數進行微調。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `步驟數` | 要產生排程的取樣步數（預設值：20）。輸出包含 `steps + 1` 個 sigma 值。 | INT | 是 | 1 至 200 |
| `寬度` | 影像寬度（像素）（預設值：1024）。相對於 512×512 參考的解析度會偏移雜訊排程。 | INT | 是 | 256 至 8192 (step: 16) |
| `高度` | 影像高度（像素）（預設值：1024）。相對於 512×512 參考的解析度會偏移雜訊排程。 | INT | 是 | 256 至 8192 (step: 16) |
| `μ` | logit-normal 分布的均值參數，控制中心雜訊水平。與解析度項結合形成 logSNR 偏移（預設值：0.0）。 | FLOAT | 是 | -10.0 至 10.0 (step: 0.05) |
| `標準差` | logit-normal 分布的標準差參數，控制雜訊水平的分布範圍（預設值：1.75）。 | FLOAT | 是 | 0.1 至 5.0 (step: 0.05) |

注意：此排程是根據參考時間上的 logit-normal 分布推導而來。解析度項等於 `0.5 * log((width × height) / (512 × 512))`，會加到 `mu` 上，因此較大或較小的影像在相同的 `mu` 值下，會相對於 512×512 參考偏移排程。

## 輸出

| 輸出名 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `SIGMAS` | 一個 sigma 值張量，代表雜訊排程，長度等於 `steps + 1`。這些值從高雜訊下降到低雜訊，最終值設為 0.0 以完成完全去噪。 | SIGMAS |
