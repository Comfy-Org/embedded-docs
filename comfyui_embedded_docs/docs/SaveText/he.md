# SaveText

צומת Save Text כותב תוכן טקסט לקובץ בתיקיית הפלט. הוא תומך בשמירה בפורמט .txt, .csv, .md או .json, ומבצע אוטומטית עיצוב קריא של JSON כאשר מסופק JSON תקין.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `text` | תוכן הטקסט לשמירה לקובץ. קלט זה חייב להיות מחובר מצומת אחר. | STRING | כן | - |
| `filename_prefix` | קידומת לשם קובץ הפלט. מונה בן 5 ספרות מתווסף כדי למנוע דריסה של קבצים קיימים (ברירת מחדל: "ComfyUI"). | STRING | לא | - |
| `format` | פורמט הקובץ שבו לשמור את הטקסט (ברירת מחדל: "txt"). כאשר נבחר "json", טקסט JSON תקין מעוצב עם הזחה של 2 רווחים; אחרת, הטקסט נשמר כפי שהוא. | COMBO | לא | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

### הערות

- `text` הוא קלט מאולץ וחייב להיות מחובר לצומת אחר; לא ניתן להקליד אותו ישירות.
- הקובץ הנשמר נקרא `<filename_prefix>_<5-digit counter>.<extension>` ונכתב לתוך תיקיית הפלט של ComfyUI (בתת-תיקייה הנגזרת מהקידומת).
- בחירה בפורמט `"json"` מנסה לנתח את הטקסט כ-JSON. אם הניתוח מצליח, התוכן נכתב כשהוא מעוצב עם הזחה של 2 רווחים; אם הניתוח נכשל, הטקסט הגולמי נכתב ללא שינוי.
- הצומת מדווח על הקובץ הנשמר בחזרה לממשק כך שהוא מופיע יחד עם שאר קובצי הפלט שנוצרו.
