# ذخیره متن

گره ذخیره متن (Save Text) محتوای متنی را در یک فایل در دایرکتوری خروجی ذخیره می‌کند. این گره از ذخیره‌سازی در قالب‌های `.txt`، `.md` یا `.json` پشتیبانی کرده و در صورت ارائه JSON معتبر، به‌طور خودکار قالب‌بندی زیبا (pretty-printing) آن را انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|---------|---------|----------|-------|--------|
| `text` | محتوای متنی برای ذخیره در یک فایل. این ورودی باید از گره دیگری متصل شود. | STRING | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی. برای جلوگیری از بازنویسی فایل‌های موجود، یک شمارنده ۵ رقمی اضافه می‌شود (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `format` | فرمت فایل برای ذخیره متن (پیش‌فرض: "txt"). وقتی "json" انتخاب شود، متن JSON معتبر با تورفتگی ۲ فاصله به‌صورت خوانا چاپ می‌شود؛ در غیر این صورت متن همان‌طور که هست ذخیره می‌شود. | COMBO | خیر | `"txt"`<br>`"md"`<br>`"json"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `text` | محتوای متنی اصلی که در فایل ذخیره شد | STRING |
