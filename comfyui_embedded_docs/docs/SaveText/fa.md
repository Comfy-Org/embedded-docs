# ذخیره متن

گره Save Text محتوای متنی را در فایلی در پوشه خروجی می‌نویسد. از ذخیره‌سازی در قالب‌های .txt، .csv، .md یا .json پشتیبانی می‌کند و وقتی JSON معتبر ارائه شود، به‌طور خودکار قالب‌بندی خوانا JSON را انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | محتوای متنی که باید در فایل ذخیره شود. این ورودی باید از یک گره دیگر متصل شود. | STRING | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی. یک شمارنده ۵ رقمی برای جلوگیری از بازنویسی فایل‌های موجود به آن افزوده می‌شود (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `format` | قالب فایلی که متن باید با آن ذخیره شود (پیش‌فرض: "txt"). وقتی "json" انتخاب شود، متن JSON معتبر با تورفتگی ۲ فاصله‌ای به‌صورت خوانا قالب‌بندی می‌شود؛ در غیر این صورت، متن همان‌گونه که هست ذخیره می‌شود. | COMBO | خیر | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

### نکات

- `text` یک ورودی اجباری است و باید به یک گره دیگر متصل شود؛ نمی‌توان آن را مستقیماً تایپ کرد.
- فایل ذخیره‌شده به شکل `<filename_prefix>_<5-digit counter>.<extension>` نام‌گذاری می‌شود و در پوشه خروجی ComfyUI (در زیرپوشه‌ای برگرفته از پیشوند) نوشته می‌شود.
- انتخاب قالب `"json"` تلاش می‌کند متن را به‌عنوان JSON تجزیه کند. اگر تجزیه موفق شود، محتوا با تورفتگی ۲ فاصله‌ای به‌صورت خوانا نوشته می‌شود؛ اگر تجزیه ناموفق باشد، متن خام بدون تغییر نوشته می‌شود.
- گره فایل ذخیره‌شده را به رابط گزارش می‌دهد تا همراه سایر فایل‌های خروجی تولیدشده نمایش داده شود.
