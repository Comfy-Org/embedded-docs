# ذخیره متن

گره Save Text محتوای متنی را در یک فایل در دایرکتوری خروجی می‌نویسد. این گره از ذخیره‌سازی در قالب‌های `.txt`، `.csv`، `.md` یا `.json` پشتیبانی می‌کند و در صورت ارائه JSON معتبر، به‌طور خودکار قالب‌بندی زیبای JSON (pretty-printing) را انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | محتوای متنی که باید در فایل ذخیره شود. این ورودی باید از گره دیگری متصل شود. | STRING | بله | - |
| `filename_prefix` | پیشوندی برای نام فایل خروجی. یک شمارنده ۵ رقمی به انتهای نام اضافه می‌شود تا از بازنویسی فایل‌های موجود جلوگیری کند (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `format` | قالبی که متن باید به‌عنوان آن ذخیره شود (پیش‌فرض: "txt"). وقتی «json» انتخاب شود، متن JSON معتبر با تورفتگی ۲ فضایی به‌صورت زیبا قالب‌بندی می‌شود؛ در غیر این صورت، متن همان‌طور که هست ذخیره می‌شود. | COMBO | خیر | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `text` | محتوای متنی اصلی که در فایل ذخیره شده است | STRING |
