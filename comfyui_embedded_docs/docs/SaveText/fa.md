# ذخیره متن

گره Save Text محتوای متنی را در یک فایل در دایرکتوری خروجی ذخیره می‌کند. این گره از ذخیره‌سازی در قالب‌های txt.، csv.، md. یا json. پشتیبانی می‌کند و هنگام دریافت JSON معتبر، به‌صورت خودکار قالب‌بندی زیبای JSON را انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | محتوای متنی که باید در یک فایل ذخیره شود. این ورودی باید از یک گره دیگر متصل شود. | STRING | بله | - |
| `filename_prefix` | پیشوند برای نام فایل خروجی. برای جلوگیری از بازنویسی فایل‌های موجود، یک شمارنده ۵ رقمی به انتهای نام اضافه می‌شود (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `format` | قالبی که متن با آن ذخیره می‌شود (پیش‌فرض: "txt"). هنگام انتخاب "json"، متن JSON معتبر با تورفتگی ۲ فاصله‌ای به‌صورت خوانا قالب‌بندی می‌شود؛ در غیر این صورت، متن همان‌طور که هست ذخیره می‌شود. | COMBO | خیر | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `text` | محتوای متنی اصلی که در فایل ذخیره شده است | STRING |
