# حفظ نص

تكتب عقدة Save Text محتوى نصيًا إلى ملف في دليل المخرجات. وهي تدعم الحفظ بصيغ .txt أو .csv أو .md أو .json، وتتعامل تلقائيًا مع التنسيق الجميل لـ JSON عند تمرير JSON صالح.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | المحتوى النصي المراد حفظه في ملف. يجب توصيل هذا المدخل من عقدة أخرى. | STRING | نعم | - |
| `filename_prefix` | بادئة اسم ملف المخرجات. تُضاف إليها عدّاد من 5 أرقام لمنع الكتابة فوق الملفات الموجودة (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `format` | صيغة الملف المراد حفظ النص بها (الافتراضي: "txt"). عند اختيار "json"، يُنسّق نص JSON الصالح بشكل جميل مع إزاحة مسافتين؛ بخلاف ذلك، يُحفظ النص كما هو. | COMBO | لا | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

### ملاحظات

- `text` مدخل إجباري ويجب توصيله بعقدة أخرى؛ لا يمكن كتابته مباشرة.
- يُسمّى الملف المحفوظ `<filename_prefix>_<5-digit counter>.<extension>` ويُكتب في دليل مخرجات ComfyUI (داخل مجلد فرعي مشتق من البادئة).
- اختيار صيغة `"json"` يحاول تحليل النص بصيغة JSON. إذا نجح التحليل، يُكتب المحتوى منسّقًا بشكل جميل مع إزاحة مسافتين؛ وإذا فشل التحليل، يُكتب النص الخام دون تغيير.
- تُبلّغ العقدة عن الملف المحفوظ إلى الواجهة بحيث يظهر مع ملفات المخرجات المُنشأة الأخرى.
