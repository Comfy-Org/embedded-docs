# حفظ نص

عقدة Save Text تكتُب محتوى نصيًا إلى ملف في دليل الإخراج. وهي تدعم الحفظ بصيغ .txt أو .csv أو .md أو .json، وتتعامل تلقائيًا مع تنسيق JSON الجميل (pretty-printing) عندما يتم توفير نص JSON صالح.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | النص المراد حفظه في ملف. يجب أن يكون هذا المدخل متصلاً من عقدة أخرى. | STRING | نعم | - |
| `filename_prefix` | بادئة لاسم ملف الإخراج. يتم إلحاق عداد من 5 أرقام لمنع استبدال الملفات الموجودة (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `format` | صيغة الملف لحفظ النص به (الافتراضي: "txt"). عند اختيار "json"، يتم تنسيق نص JSON الصالح بمسافة بادئة من مسافتين؛ وإلا، يُحفظ النص كما هو. | COMBO | لا | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `text` | المحتوى النصي الأصلي الذي تم حفظه في الملف | STRING |
