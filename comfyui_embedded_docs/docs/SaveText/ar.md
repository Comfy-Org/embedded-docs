# حفظ نص

عقدة حفظ النص (Save Text) تكتب المحتوى النصي إلى ملف في دليل الإخراج. وهي تدعم الحفظ بصيغ .txt أو .csv أو .md أو .json، وتتعامل تلقائيًا مع تنسيق JSON الجميل (pretty-printing) عند توفير JSON صالح.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | المحتوى النصي المطلوب حفظه في ملف. يجب أن يكون هذا الإدخال متصلاً من عقدة أخرى. | STRING | نعم | - |
| `filename_prefix` | بادئة لاسم ملف الإخراج. يُلحق عداد من خمس خانات لمنع الكتابة فوق الملفات الموجودة (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `format` | صيغة الملف التي سيُحفظ بها النص (الافتراضي: "txt"). عند اختيار "json"، تتم طباعة نص JSON الصالح بتنسيق جميل مع مسافة بادئة بمقدار مسافتين؛ وإلا، يُحفظ النص كما هو. | COMBO | لا | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `text` | المحتوى النصي الأصلي الذي تم حفظه في الملف | STRING |
