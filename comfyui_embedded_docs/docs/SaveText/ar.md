# حفظ نص

تقوم عقدة حفظ النص بكتابة المحتوى النصي إلى ملف في مجلد الإخراج. وهي تدعم الحفظ بصيغة `.txt` أو `.md` أو `.json`، وتتعامل تلقائيًا مع تنسيق JSON بشكل منسق عند توفير JSON صالح.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | المحتوى النصي الذي سيتم حفظه في ملف. يجب أن يكون هذا الإدخال متصلًا من عقدة أخرى. | STRING | نعم | - |
| `filename_prefix` | بادئة لاسم ملف الإخراج. يُضاف عداد من 5 أرقام لمنع استبدال الملفات الموجودة (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `format` | صيغة الملف الذي سيتم حفظ النص به (الافتراضي: "txt"). عند تحديد "json"، تتم طباعة نص JSON الصالح بشكل منسق بمسافة بادئة من مسافتين؛ وإلا، يُحفظ النص كما هو. | COMBO | لا | `"txt"`<br>`"md"`<br>`"json"` |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `text` | المحتوى النصي الأصلي الذي تم حفظه في الملف | STRING |
