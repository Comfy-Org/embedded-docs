# テキストを保存

Save Text ノードは、テキストコンテンツを出力ディレクトリ内のファイルに保存します。`.txt`、`.csv`、`.md`、`.json` の各形式での保存に対応しており、有効な JSON が指定された場合は、JSON の整形出力（pretty-printing）を自動的に処理します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | ファイルに保存するテキストコンテンツです。この入力は別のノードから接続する必要があります。 | STRING | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックスです。既存ファイルの上書きを防ぐため、5桁のカウンターが末尾に追加されます（デフォルト: "ComfyUI"）。 | STRING | いいえ | - |
| `format` | テキストを保存するファイル形式です（デフォルト: "txt"）。"json" を選択した場合、有効な JSON テキストは2スペースインデントで整形されます。それ以外の場合は、テキストがそのまま保存されます。 | COMBO | いいえ | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | ファイルに保存された元のテキストコンテンツ | STRING |
