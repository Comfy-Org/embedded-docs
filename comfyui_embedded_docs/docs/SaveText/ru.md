# Сохранить текст

Узел Save Text записывает текстовое содержимое в файл в выходном каталоге. Он поддерживает сохранение в форматах .txt, .csv, .md или .json и автоматически выполняет форматирование JSON с отступами, когда передан корректный JSON.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текстовое содержимое для сохранения в файл. Этот вход должен быть подключён к выходу другого узла. | STRING | Да | - |
| `filename_prefix` | Префикс для имени выходного файла. К нему добавляется 5-значный счётчик, чтобы предотвратить перезапись существующих файлов (по умолчанию: "ComfyUI"). | STRING | Нет | - |
| `format` | Формат файла, в котором сохраняется текст (по умолчанию: "txt"). Если выбран "json", корректный JSON-текст форматируется с отступом в 2 пробела; в противном случае текст сохраняется как есть. | COMBO | Нет | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

### Примечания

- `text` — принудительный вход, и он должен быть подключён к другому узлу; его нельзя ввести напрямую.
- Сохранённый файл называется `<filename_prefix>_<5-digit counter>.<extension>` и записывается в выходной каталог ComfyUI (в подпапку, производную от префикса).
- Выбор формата `"json"` пытается разобрать текст как JSON. Если разбор успешен, содержимое записывается с форматированием и отступом в 2 пробела; если разбор не удался, необработанный текст записывается без изменений.
- Узел сообщает интерфейсу о сохранённом файле, чтобы он отображался вместе с другими сгенерированными выходными файлами.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `text` | Исходное текстовое содержимое, которое было сохранено в файл | STRING |
