# Сохранить текст

Узел Save Text записывает текстовое содержимое в файл в выходной директории. Он поддерживает сохранение в форматах .txt, .csv, .md или .json и автоматически выполняет форматирование JSON с отступами, если предоставлен корректный JSON.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `text` | Текстовое содержимое для сохранения в файл. Этот вход должен быть подключён от другого узла. | STRING | Да | - |
| `filename_prefix` | Префикс для имени выходного файла. Для предотвращения перезаписи существующих файлов добавляется 5-значный счётчик (по умолчанию: "ComfyUI"). | STRING | Нет | - |
| `format` | Формат файла для сохранения текста (по умолчанию: "txt"). При выборе "json" корректный JSON-текст форматируется с отступом в 2 пробела; в противном случае текст сохраняется как есть. | COMBO | Нет | `"txt"`<br>`"csv"`<br>`"md"`<br>`"json"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `text` | Исходное текстовое содержимое, которое было сохранено в файл | STRING |
