# モデルデバイス選択

### ノード概要

SelectModelDevice ノードを使用すると、ディフュージョンモデルを実行するデバイス（CPU または特定の GPU）を選択できます。選択したオプションに応じて、ローダーの元のデバイスに復元したり、モデルを CPU に固定したり、特定の GPU に移動したりします。また、他のマルチ GPU ノードとの競合も自動的に処理します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 特定のデバイスに配置するディフュージョンモデル。 | MODEL | はい |  |
| `device` | モデルのターゲットデバイス。利用可能な GPU に基づいてオプションが動的に生成されます。（既定値: "default"） | COMBO | はい | `"default"`<br>`"cpu"`<br>`"gpu:N"` （利用可能な各 GPU に対応。例: `"gpu:0"`、`"gpu:1"`、...） |

**パラメータの詳細：**
- `"default"`: 以前の SelectModelDevice ノードが変更した場合でも、モデルローダーによって割り当てられたデバイスに復元します。
- `"cpu"`: ロードデバイスとオフロードデバイスの両方を CPU に固定します。
- `"gpu:N"`: ロードデバイスを N 番目の利用可能な GPU に固定します（例: 最初の GPU は `"gpu:0"`）。オフロードデバイスはローダーの元の設定に復元されます。

**重要な注意事項：**
- 不明な `"gpu:N"` 値は検証時には受け入れられるため、GPU が少ないマシンでもポータブルなワークフローが失敗しません。実行時にデバイスが利用できない場合、ログメッセージとともにモデルは変更されずにそのまま渡されます。
- 要求されたデバイスが現在のマシンに存在しない場合（例: 2 GPU マシンで作成されたワークフローを 1 GPU マシンで開いた場合）、ノードは失敗せず、モデルを変更せずに通過させ、ログメッセージを記録します。
- モデルがすでに要求されたデバイス上にある場合、ノードは高速パスを採用し、モデルを再読み込みしません。
- 要求されたデバイスが現在のデバイスと異なる場合、ローダーのリロードファクトリを使用して新しいモデルが作成されるため、返されるモデルは新しいデバイス上で独立した重みを持ちます。これをサポートしないローダーの場合、ノードは警告とともにモデルを変更せずに通過させます。
- ワークフローに MultiGPU CFG Split がすでに適用されており、選択した GPU が既存のマルチ GPU クローンのいずれかと一致する場合、そのクローンは削除され、2 つのパッチャーが同じデバイスにバインドされないようにします。
- モデルをすでに消費したノード（例: KSampler）の*後に*このノードを配置することは推奨されません。デバイスが元のデバイスと一致する場合、前のノードによって変更された状態が参照されるためです。
