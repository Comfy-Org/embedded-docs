# Выбор устройства для модели

## Обзор

Узел SelectModelDevice позволяет вручную выбрать устройство (CPU или конкретный GPU), на котором будет работать диффузионная модель. Он может переместить модель на другое устройство и автоматически обрабатывает конфликты с другими multi-GPU узлами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, которую нужно разместить на конкретном устройстве. | MODEL | Да |  |
| `device` | Целевое устройство для модели. Варианты формируются динамически на основе доступных GPU. (по умолчанию: `"default"`) | COMBO | Да | `"default"`<br>`"cpu"`<br>`"gpu:0"`<br>`"gpu:1"`<br>... (по одной записи `"gpu:N"` для каждого обнаруженного GPU) |

**Описания параметров:**
- `"default"`: Восстанавливает устройство, назначенное загрузчиком модели, даже если предыдущий узел SelectModelDevice изменил его.
- `"cpu"`: Закрепляет и устройство загрузки, и устройство выгрузки за CPU.
- `"gpu:N"`: Закрепляет устройство загрузки за N-м доступным GPU (например, `"gpu:0"` для первого GPU). Устройство выгрузки возвращается к исходному выбору загрузчика.

**Важные примечания:**
- Если запрошенное устройство отсутствует на текущей машине (например, рабочий процесс, созданный на машине с 2 GPU, открыт на машине с 1 GPU), узел передаёт модель без изменений и записывает сообщение в журнал, а не завершается ошибкой.
- Если модель уже находится на запрошенном устройстве, узел использует быстрый путь и не перезагружает модель.
- Если загрузчик модели не поддерживает multi-GPU (нет фабрики перезагрузки), узел передаёт модель без изменений и записывает предупреждение в журнал.
- Если клон MultiGPU CFG Split уже занимает выбранное устройство, этот клон удаляется, чтобы две модели не были привязаны к одному устройству.
- При выборе конкретного устройства узел также изменяет вычислительный dtype модели на поддерживаемый этим устройством.
- Не рекомендуется размещать этот узел *после* узла, который уже потребил модель (например, KSampler), поскольку если устройство совпадает с исходным, будут видны изменения состояния, внесённые предыдущим узлом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Диффузионная модель, теперь размещённая на выбранном устройстве. Если устройство было недопустимым или недоступным, модель передаётся без изменений. | MODEL |
