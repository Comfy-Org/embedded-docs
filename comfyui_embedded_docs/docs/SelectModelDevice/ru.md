# Выбор устройства для модели

Узел SelectModelDevice позволяет выбрать устройство (CPU или конкретный GPU), на котором будет работать диффузионная модель. В зависимости от выбранного варианта он восстанавливает исходное устройство загрузчика, закрепляет модель на CPU или перемещает её на конкретный GPU, а также автоматически обрабатывает конфликты с другими узлами multi-GPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, которую нужно разместить на конкретном устройстве. | MODEL | Да |  |
| `device` | Целевое устройство для модели. Варианты динамически генерируются на основе доступных GPU. (по умолчанию: "default") | COMBO | Да | `"default"`<br>`"cpu"`<br>`"gpu:N"` для каждого доступного GPU (например, `"gpu:0"`, `"gpu:1"`, ...) |

**Подробнее о параметрах:**
- `"default"`: восстанавливает устройство, назначенное загрузчиком модели, даже если предыдущий узел SelectModelDevice изменил его.
- `"cpu"`: закрепляет и устройство загрузки, и устройство выгрузки за CPU.
- `"gpu:N"`: закрепляет устройство загрузки за N-м доступным GPU (например, `"gpu:0"` для первого GPU). Устройство выгрузки возвращается к исходному выбору загрузчика.

**Важные замечания:**
- Неизвестные значения `"gpu:N"` принимаются при проверке, чтобы переносимые рабочие процессы не завершались сбоем на машинах с меньшим количеством GPU. Во время выполнения, если устройство недоступно, модель передается без изменений с записью в журнал.
- Если запрошенное устройство не существует на текущей машине (например, рабочий процесс, созданный на машине с 2 GPU, открыт на машине с 1 GPU), узел передает модель без изменений и записывает сообщение в журнал, а не завершается с ошибкой.
- Если модель уже находится на запрошенном устройстве, узел использует быстрый путь и не перезагружает модель.
- Когда запрошенное устройство отличается от текущего, создается новая модель с использованием фабрики перезагрузки загрузчика, поэтому возвращаемая модель имеет независимые веса на новом устройстве. Если загрузчик не поддерживает это, узел передает модель без изменений с предупреждением.
- Если в рабочем процессе уже применен MultiGPU CFG Split и выбранный GPU совпадает с одним из существующих мультиграфических клонов, этот клон удаляется, чтобы два патчера не оказались привязанными к одному и тому же устройству.
- Размещение этого узла *после* узла, который уже потребил модель (например, KSampler), не рекомендуется, так как любые изменения состояния, внесенные предыдущим узлом, будут наблюдаться, если устройство совпадает с исходным.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Диффузионная модель, теперь размещенная на выбранном устройстве. Если устройство было недопустимым или недоступным, модель передается без изменений. | MODEL |
