# Выбор устройства для модели

Узел Select Model Device позволяет вручную выбрать устройство (CPU или конкретный GPU), на котором выполняется диффузионная модель. Он может перемещать модель на другое устройство и автоматически разрешает конфликты с другими multi-GPU узлами. Выбор `"default"` восстанавливает исходное устройство, выбранное загрузчиком модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, которую нужно разместить на определённом устройстве. | MODEL | Да |  |
| `device` | Целевое устройство для модели. Опции динамически создаются на основе доступных устройств на текущей машине. (по умолчанию: `"default"`) | COMBO | Да | `"default"`<br>`"cpu"`<br>`"gpu:0"`<br>`"gpu:1"`<br>... (по одной записи `"gpu:N"` на каждый обнаруженный GPU) |

**Сведения о параметрах:**
- `"default"`: Восстанавливает устройства загрузки и выгрузки, назначенные загрузчиком модели, даже после предыдущего вызова Select Model Device.
- `"cpu"`: Привязывает и устройство загрузки, и устройство выгрузки к CPU.
- `"gpu:N"`: Привязывает устройство загрузки к N-му доступному GPU (например, `"gpu:0"` для первого GPU). Устройство выгрузки восстанавливается до исходного выбора загрузчика.

**Важные примечания:**
- Если запрошенное устройство не существует на текущей машине (например, workflow, созданный на машине с 2 GPU, открывается на машине с 1 GPU), узел передаёт модель без изменений и записывает сообщение в журнал вместо ошибки. Неизвестные значения `gpu:N` допускаются во время проверки входных данных, чтобы переносимые workflow не завершались ошибкой раньше времени.
- Если модель уже находится на запрошенном устройстве, узел использует быстрый путь и не перезагружает модель.
- Когда запрошенное устройство отличается от устройства, на котором уже находится входная модель, создаётся новая модель с использованием фабрики перезагрузки загрузчика, чтобы новый патчер владел независимыми весами на новом устройстве.
- Если загрузчик модели не поддерживает multi-GPU (нет фабрики перезагрузки), узел передаёт модель без изменений и записывает предупреждение в журнал.
- Если клон MultiGPU CFG Split уже занимает выбранное устройство, этот клон удаляется, чтобы две модели не были привязаны к одному устройству.
- Когда выбрано устройство не по умолчанию (CPU или GPU), узел также изменяет compute dtype модели на тип, поддерживаемый этим устройством.
- Не рекомендуется размещать этот узел после узла, который уже использовал модель (например, KSampler), поскольку любое состояние, изменённое предыдущим узлом, будет учтено, если устройство совпадает с исходным.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Диффузионная модель, теперь размещённая на выбранном устройстве. Если устройство было недопустимым или недоступным, модель передаётся без изменений. | MODEL |
