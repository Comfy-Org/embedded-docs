# 選擇模型裝置

## 概述

SelectModelDevice 節點可讓您手動選擇擴散模型執行時所使用的裝置（CPU 或特定的 GPU）。它可以將模型移動到不同的裝置，並自動處理與其他多 GPU 節點的衝突。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要放置在特定裝置上的擴散模型。 | MODEL | 是 |  |
| `device` | 模型的目標裝置。選項會根據可用的 GPU 動態產生。（預設值：`"default"`） | COMBO | 是 | `"default"`<br>`"cpu"`<br>`"gpu:0"`<br>`"gpu:1"`<br>……（每個偵測到的 GPU 對應一個 `"gpu:N"` 項目） |

**參數詳細說明：**
- `"default"`：恢復模型載入器所指定的裝置，即使先前的 SelectModelDevice 節點已變更過它。
- `"cpu"`：將載入（load）與卸載（offload）裝置都固定為 CPU。
- `"gpu:N"`：將載入裝置固定到第 N 個可用的 GPU（例如第一個 GPU 為 `"gpu:0"`）。卸載裝置則恢復為載入器原本的選擇。

**重要注意事項：**
- 如果目前機器上不存在所要求的裝置（例如，在配備 2 個 GPU 的機器上建立的工作流程，卻在只有 1 個 GPU 的機器上開啟），此節點會直接傳遞模型而不做任何變更，並記錄一則訊息，而不會失敗。
- 如果模型已在所要求的裝置上，此節點會採用快速路徑，不會重新載入模型。
- 如果模型載入器不支援多 GPU（沒有重新載入工廠），此節點會直接傳遞模型而不做任何變更，並記錄一則警告。
- 當 MultiGPU CFG Split 的複製體已佔用所選的裝置時，該複製體會被移除，以避免兩個模型綁定到同一個裝置。
- 當選定特定裝置時，此節點也會將模型的計算 dtype 調整為該裝置所支援的類型。
- 不建議將此節點放置在已消耗模型的節點（例如 KSampler）*之後*，因為如果裝置與原始裝置相符，先前節點所變更的任何狀態都會生效。
