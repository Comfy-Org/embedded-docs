# 選擇模型裝置

Select Model Device 節點可讓您手動選擇擴散模型執行所在的裝置（CPU 或特定 GPU）。它可以將模型移動到其他裝置，並自動處理與其他多 GPU 節點的衝突。選擇 `"default"` 會還原模型載入器所選的原始裝置。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要放置到特定裝置上的擴散模型。 | MODEL | 是 |  |
| `device` | 模型的目標裝置。選項會根據目前機器上可用的裝置動態產生。（預設：`"default"`） | COMBO | 是 | `"default"`<br>`"cpu"`<br>`"gpu:0"`<br>`"gpu:1"`<br>...（每個偵測到的 GPU 一個 `"gpu:N"` 項目） |

**參數詳情：**
- `"default"`：還原模型載入器所指派的載入與卸載裝置，即使先前曾呼叫過 Select Model Device 也一樣。
- `"cpu"`：將載入與卸載裝置都固定到 CPU。
- `"gpu:N"`：將載入裝置固定到第 N 個可用 GPU（例如 `"gpu:0"` 代表第一個 GPU）。卸載裝置會還原為載入器原本的選擇。

**重要注意事項：**
- 如果目前機器上不存在要求的裝置（例如在 2-GPU 機器上建立的工作流程被拿到 1-GPU 機器上開啟），節點會將模型原樣傳遞並記錄訊息，而不是失敗。在輸入驗證期間允許未知的 `gpu:N` 值，讓可攜式工作流程不會提早報錯。
- 如果模型已在要求的裝置上，節點會使用快速路徑，不會重新載入模型。
- 當要求的裝置與輸入模型目前所在的裝置不同時，會使用載入器的 reload factory 產生全新的模型，讓新的 patcher 在新裝置上擁有獨立的權重。
- 如果模型載入器不支援多 GPU（沒有 reload factory），節點會將模型原樣傳遞並記錄警告。
- 當 MultiGPU CFG Split 複本已佔用所選裝置時，會剪除該複本，以免兩個模型綁定到同一裝置。
- 當選擇非預設裝置（CPU 或 GPU）時，節點也會將模型的計算 dtype 調整為該裝置支援的 dtype。
- 不建議將此節點放在已取用該模型的節點（例如 KSampler）之後，因為若裝置與原始裝置相符，前一個節點所變更的任何狀態都會被觀察到。
