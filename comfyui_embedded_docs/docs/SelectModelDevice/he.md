# בחר התקן מודל

צומת Select Model Device מאפשר לך לבחור ידנית על איזה התקן (CPU או GPU מסוים) פועל מודל דיפוזיה. הוא יכול להעביר מודל להתקן אחר, והוא מטפל אוטומטית בקונפליקטים עם צמתים אחרים מרובי GPU. בחירה ב-`"default"` משחזרת את ההתקן המקורי שנבחר על ידי טוען המודל.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה שיש למקם על התקן מסוים. | MODEL | כן |  |
| `device` | התקן היעד עבור המודל. האפשרויות נוצרות באופן דינמי בהתאם להתקנים הזמינים במחשב הנוכחי. (ברירת מחדל: `"default"`) | COMBO | כן | `"default"`<br>`"cpu"`<br>`"gpu:0"`<br>`"gpu:1"`<br>... (רשומת `"gpu:N"` אחת לכל GPU שזוהה) |

**פרטי פרמטרים:**
- `"default"`: משחזר את התקני הטעינה והפריקה שהוקצו על ידי טוען המודל, גם לאחר קריאה קודמת ל-Select Model Device.
- `"cpu"`: מצמיד גם את התקן הטעינה וגם את התקן הפריקה ל-CPU.
- `"gpu:N"`: מצמיד את התקן הטעינה ל-GPU הזמין ה-N (לדוגמה, `"gpu:0"` עבור ה-GPU הראשון). התקן הפריקה משוחזר לבחירה המקורית של הטוען.

**הערות חשובות:**
- אם ההתקן המבוקש אינו קיים במחשב הנוכחי (לדוגמה, זרימת עבודה שנוצרה במחשב עם 2 GPUs נפתחת במחשב עם GPU אחד), הצומת מעביר את המודל ללא שינוי ורושם הודעה ביומן במקום להיכשל. ערכי `gpu:N` לא מזוהים מותרים במהלך אימות הקלט כדי שזרימות עבודה ניידות לא יגרמו לשגיאה מוקדמת.
- אם המודל כבר נמצא בהתקן המבוקש, הצומת משתמש במסלול מהיר ואינו טוען מחדש את המודל.
- כאשר ההתקן המבוקש שונה מההתקן שעליו נמצא מודל הקלט, נוצר מודל חדש באמצעות מנגנון הטעינה מחדש (reload factory) של הטוען, כך שה-patcher החדש מחזיק במשקולות עצמאיות בהתקן החדש.
- אם טוען המודל אינו תומך בריבוי GPU (אין reload factory), הצומת מעביר את המודל ללא שינוי ורושם אזהרה ביומן.
- כאשר שיבוט של MultiGPU CFG Split כבר תופס את ההתקן הנבחר, השיבוט מוסר כך ששני מודלים לא יהיו מקושרים לאותו התקן.
- כאשר נבחר התקן שאינו ברירת מחדל (CPU או GPU), הצומת גם מתאים את ה-compute dtype של המודל לאחד הנתמכים על ידי אותו התקן.
- לא מומלץ למקם צומת זה לאחר צומת שכבר צרך את המודל (לדוגמה, KSampler), מכיוון שכל מצב ששונה על ידי הצומת הקודם יילקח בחשבון אם ההתקן תואם למקורי.
