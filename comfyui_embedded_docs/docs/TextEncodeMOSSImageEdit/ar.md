# Text Encode MOSS-Image Edit

يقوم بتشفير تعليمة تعديل إلى جانب الصور المرجعية إلى تهيئة شرطية من أجل LoRA لتعديل MOSS-Image. وصّل المخرج كتهيئة شرطية موجبة، وشغّل نسخة ثانية مع المراجع نفسها من أجل التهيئة السلبية. تُستخدم المراجع بالحجم الذي تصل به، لذا قم بتحجيمها قبل التوصيل. هذه العقدة مُعلّمة كتجريبية في ComfyUI.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP الذي يُجزّئ التعليمة إلى رموز ويشفّرها. | CLIP | نعم | - |
| `prompt` | التعليمة التي تصف التعديل. تدعم النص متعدد الأسطر والتوجيهات الديناميكية. | STRING | نعم | أي نص |
| `vae` | VAE المستخدم لتشفير الصور المرجعية إلى تمثيلات كامنة مرجعية. | VAE | نعم | - |
| `edit_format` | التخطيط الذي دُرّب عليه LoRA التعديل. يحدد طريقة التمثيلات الكامنة المرجعية وما إذا كان مشفّر النص يرى المراجع أيضًا. | COMBO | نعم | `"ai-toolkit"`<br>`"ai-toolkit (kv_cache off)"`<br>`"Moss-Image-Edit"` |
| `images` | فتحة قابلة للتوسع: وصّل صورة مرجعية واحدة أو أكثر (`image_1`, `image_2`, ...). تُستخدم كل صورة بالحجم الذي تصل به، وتُسقَط قناة ألفا الخاصة بها، وتُشفَّر عبر VAE إلى تمثيل كامن مرجعي. | IMAGE | نعم | صورة واحدة أو أكثر |

**ملاحظة:** مع `"ai-toolkit"` و`"ai-toolkit (kv_cache off)"`، يرى مشفّر النص أيضًا كل مرجع، بعد تصغيره إلى 384x384 بكسل كحد أقصى وتسبقه علامة `Picture N:` في التوجيه، بحيث يمكن للتعليمة الإشارة إليها برقمها. مع `"Moss-Image-Edit"`، تصل المراجع إلى النموذج فقط كتمثيلات كامنة مرجعية، ويرى مشفّر النص التعليمة وحدها. بالإضافة إلى ذلك، يحافظ `"ai-toolkit (kv_cache off)"` على انتباه المراجع إلى الصورة الجاري توليدها، لذا يُعاد حسابها في كل خطوة أخذ عينات.
