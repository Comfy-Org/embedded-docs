# Text Encode MOSS-Image Edit

קידוד הוראת עריכה יחד עם תמונות עזר ל-conditioning עבור LoRA לעריכת MOSS-Image. חברו את הפלט כ-conditioning חיובי, והריצו מופע שני עם אותן תמונות עזר עבור ה-conditioning השלילי. תמונות העזר משמשות בגודל שבו הן מגיעות, לכן יש לשנות את קנה המידה שלהן לפני החיבור. צומת זה מסומן כניסיוני ב-ComfyUI.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP שמבצע טוקניזציה של ההוראה ומקודד אותה. | CLIP | כן | - |
| `prompt` | ההוראה המתארת את העריכה. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | כל טקסט |
| `vae` | ה-VAE המשמש לקידוד תמונות העזר ל-latent-ים של עזר. | VAE | כן | - |
| `edit_format` | הפריסה שבה אומן ה-LoRA לעריכה. היא בוחרת את שיטת ה-latent-ים של העזר ואת השאלה אם מקודד הטקסט רואה גם את תמונות העזר. | COMBO | כן | `"ai-toolkit"`<br>`"ai-toolkit (kv_cache off)"`<br>`"Moss-Image-Edit"` |
| `images` | חריץ מתרחב: חברו תמונת עזר אחת או יותר (`image_1`, `image_2`, ...). כל תמונה משמשת בגודל שבו היא מגיעה, ערוץ האלפא שלה מושמט, והיא מקודדת ב-VAE ל-latent של עזר. | IMAGE | כן | תמונה אחת או יותר |

**הערה:** עם `"ai-toolkit"` ו-`"ai-toolkit (kv_cache off)"` מקודד הטקסט רואה גם כל תמונת עזר, מוקטנת ל-384x384 פיקסלים לכל היותר, ולפניה סימון `Picture N:` בפרומפט, כך שההוראה יכולה להתייחס אליהן לפי מספר. עם `"Moss-Image-Edit"` תמונות העזר מגיעות למודל רק כ-latent-ים של עזר, ומקודד הטקסט רואה את ההוראה בלבד. `"ai-toolkit (kv_cache off)"` בנוסף שומר על כך שתמונות העזר מתייחסות לתמונה שנוצרת, ולכן הן מחושבות מחדש בכל צעד דגימה.
