# モデルマージLTXV

ModelMergeLTXV は、2つのLTXVモデルの内部コンポーネントをブレンドして1つのモデルに結合します。各ウェイトパラメータは、`model2` の特定の部分が `model1` にどの程度の強さで混合されるかを制御します。値が低いほど `model1` が優先され、値が高いほど `model2` が優先されます。
