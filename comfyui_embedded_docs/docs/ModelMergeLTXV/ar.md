# ModelMergeLTXV

عقدة ModelMergeLTXV تدمج نموذجي LTXV عبر مزج مكوّناتهما المتطابقة. يمكن مزج كل جزء من أجزاء النموذج — مثل كتل المحوّل، وطبقات الإسقاط، وجدول المقياس والإزاحة — بشكل منفصل بوزنه الخاص، مما يمنح تحكمًا دقيقًا في كيفية دمج النموذجين.
