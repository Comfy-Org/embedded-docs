# ModelMergeLTXV

يدمج `ModelMergeLTXV` نموذجَي LTXV في نموذج واحد عبر مزج مكوناتهما الداخلية. يتحكم كل معامل وزن في مدى قوة مزج جزء معين من `model2` في `model1`، حيث تُفضّل القيم المنخفضة `model1` بينما تُفضّل القيم المرتفعة `model2`.
