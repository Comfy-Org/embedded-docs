# Слияние моделей LTXV

ModelMergeLTXV объединяет две модели LTXV в одну, смешивая их внутренние компоненты. Каждый весовой параметр управляет тем, насколько сильно конкретная часть `model2` смешивается в `model1`, где меньшие значения отдают предпочтение `model1`, а большие — `model2`.
