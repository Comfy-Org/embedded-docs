# ModelMergeLTXV

הצומת ModelMergeLTXV ממזגת שני מודלים של LTXV על ידי ערבוב הרכיבים התואמים שלהם. כל חלק במודל — כגון בלוקי טרנספורמר, שכבות הקרנה וטבלת scale shift — ניתן לערבב בנפרד עם משקל משלו, מה שמאפשר שליטה מדויקת באופן שבו שני המודלים משולבים.
