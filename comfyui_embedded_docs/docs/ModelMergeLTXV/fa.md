# ModelMergeLTXV

گره ModelMergeLTXV عملیات پیشرفته ادغام مدل را انجام می‌دهد که به‌طور خاص برای معماری‌های مدل LTXV طراحی شده است. این گره به شما امکان می‌دهد دو مدل مختلف را با تنظیم وزن‌های درون‌یابی برای اجزای مختلف مدل، از جمله بلوک‌های ترنسفورمر، لایه‌های پروجکشن و سایر ماژول‌های تخصصی، ترکیب کنید.
