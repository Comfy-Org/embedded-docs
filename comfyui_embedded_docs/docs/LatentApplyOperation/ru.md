# Применить операцию к латенту

Узел LatentApplyOperation применяет заданную операцию к латентным сэмплам. Он принимает латентные данные и операцию в качестве входных данных, обрабатывает латентные сэмплы с помощью указанной операции и возвращает измененные латентные данные. Этот узел позволяет преобразовывать или манипулировать латентными представлениями в вашем рабочем процессе. В настоящее время этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Латентные сэмплы для обработки операцией | LATENT | Да | - |
| `операция` | Операция, применяемая к латентным сэмплам | LATENT_OPERATION | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Измененные латентные сэмплы после применения операции | LATENT |
