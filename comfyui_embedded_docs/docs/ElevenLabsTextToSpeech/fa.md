# تبدیل متن به گفتار ElevenLabs

گره ElevenLabs Text to Speech متن نوشته‌شده را با استفاده از API مربوط به ElevenLabs به صدای گفتاری تبدیل می‌کند. این گره به شما امکان می‌دهد صدای مشخصی را انتخاب کنید و ویژگی‌های مختلف گفتار مانند پایداری، سرعت و سبک را برای تولید خروجی صوتی سفارشی دقیق‌تر تنظیم کنید. متن باید حداقل شامل یک کاراکتر باشد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیح | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تبدیل متن به گفتار. با انتخاب یک مدل، پارامترهای مخصوص آن نمایان می‌شود. | DYNAMIC_COMBO | خیر | `"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `voice` | صدای مورد استفاده برای سنتز گفتار. از Voice Selector یا Instant Voice Clone متصل کنید. | CUSTOM | بله | N/A |
| `text` | متنی که باید به گفتار تبدیل شود. باید حداقل شامل یک کاراکتر باشد. | STRING | بله | N/A |
| `stability` | پایداری صدا. مقادیر کمتر گسترهٔ احساسی وسیع‌تری می‌دهند، مقادیر بالاتر گفتار یکنواخت‌تر اما بالقوه تکراری‌تری تولید می‌کنند (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `apply_text_normalization` | حالت نرمال‌سازی متن. «auto» تصمیم را به سیستم واگذار می‌کند، «on» همیشه نرمال‌سازی را اعمال می‌کند، «off» آن را نادیده می‌گیرد. | COMBO | خیر | `"auto"`<br>`"on"`<br>`"off"` |
| `language_code` | کد زبان ISO-639-1 یا ISO-639-3 (مثلاً 'en'، 'es'، 'fra'). برای تشخیص خودکار خالی بگذارید (پیش‌فرض: ""). | STRING | خیر | N/A |
| `seed` | دانه برای تکرارپذیری (قطعیت تضمین نمی‌شود) (پیش‌فرض: 1). | INT | خیر | 0 - 2147483647 |
| `output_format` | قالب خروجی صوتی. | COMBO | خیر | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### ورودی‌های eleven_multilingual_v2

این پارامترها زمانی در دسترس قرار می‌گیرند که `model` روی `"eleven_multilingual_v2"` تنظیم شده باشد.

| پارامتر | توضیح | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعت گفتار. 1.0 نرمال است، <1.0 کندتر، >1.0 سریع‌تر (پیش‌فرض: 1.0). | FLOAT | خیر | 0.7 - 1.3 |
| `similarity_boost` | تقویت شباهت. مقادیر بالاتر باعث می‌شود صدا شبیه‌تر به صدای اصلی شود (پیش‌فرض: 0.75). | FLOAT | خیر | 0.0 - 1.0 |
| `use_speaker_boost` | تقویت شباهت به صدای گوینده اصلی (پیش‌فرض: False). | BOOLEAN | خیر | True / False |
| `style` | اغراق سبک. مقادیر بالاتر بیان سبکی را افزایش می‌دهد اما ممکن است پایداری را کاهش دهد (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 - 0.2 |

### ورودی‌های eleven_v3

این پارامترها زمانی در دسترس قرار می‌گیرند که `model` روی `"eleven_v3"` تنظیم شده باشد.

| پارامتر | توضیح | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعت گفتار. 1.0 نرمال است، <1.0 کندتر، >1.0 سریع‌تر (پیش‌فرض: 1.0). | FLOAT | خیر | 0.7 - 1.3 |
| `similarity_boost` | تقویت شباهت. مقادیر بالاتر باعث می‌شود صدا شبیه‌تر به صدای اصلی شود (پیش‌فرض: 0.75). | FLOAT | خیر | 0.0 - 1.0 |
