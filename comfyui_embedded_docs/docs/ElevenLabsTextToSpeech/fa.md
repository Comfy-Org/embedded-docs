# تبدیل متن به گفتار ElevenLabs

گره تبدیل متن به گفتار ElevenLabs، متن نوشته‌شده را با استفاده از API ایلون لبز به گفتار صوتی تبدیل می‌کند. این گره به شما امکان می‌دهد صدای مشخصی را انتخاب کنید و ویژگی‌های مختلف گفتار مانند ثبات، سرعت و سبک را تنظیم کنید تا خروجی صوتی سفارشی تولید کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تبدیل متن به گفتار. انتخاب یک مدل، پارامترهای مخصوص آن را نمایش می‌دهد. | DYNAMIC_COMBO | خیر | `"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `voice` | صدای مورد استفاده برای سنتز گفتار. از Voice Selector یا Instant Voice Clone متصل کنید. | CUSTOM | بله | N/A |
| `text` | متنی که به گفتار تبدیل می‌شود. باید حداقل یک کاراکتر داشته باشد. | STRING | بله | N/A |
| `stability` | ثبات صدا. مقادیر پایین‌تر دامنه احساسی گسترده‌تری می‌دهند، مقادیر بالاتر گفتار یکنواخت‌تر اما احتمالاً خسته‌کننده تولید می‌کنند (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `apply_text_normalization` | حالت نرمال‌سازی متن. 'auto' به سیستم اجازه تصمیم‌گیری می‌دهد، 'on' همیشه نرمال‌سازی را اعمال می‌کند، 'off' آن را رد می‌کند. | COMBO | خیر | `"auto"`<br>`"on"`<br>`"off"` |
| `language_code` | کد زبان ISO-639-1 یا ISO-639-3 (مثلاً 'en', 'es', 'fra'). برای تشخیص خودکار خالی بگذارید (پیش‌فرض: ""). | STRING | خیر | N/A |
| `seed` | Seed برای تکرارپذیری (قطعیت تضمین نشده است) (پیش‌فرض: 1). | INT | خیر | 0 - 2147483647 |
| `output_format` | قالب خروجی صوتی. | COMBO | خیر | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### ورودی‌های eleven_multilingual_v2

این پارامترها زمانی در دسترس می‌شوند که `model` روی `"eleven_multilingual_v2"` تنظیم شود.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعت گفتار. 1.0 نرمال است، <1.0 کندتر، >1.0 سریع‌تر (پیش‌فرض: 1.0). | FLOAT | خیر | 0.7 - 1.3 |
| `similarity_boost` | تقویت شباهت. مقادیر بالاتر صدا را به صدای اصلی شبیه‌تر می‌کند (پیش‌فرض: 0.75). | FLOAT | خیر | 0.0 - 1.0 |
| `use_speaker_boost` | تقویت شباهت به صدای گوینده اصلی (پیش‌فرض: False). | BOOLEAN | خیر | True / False |
| `style` | اغراق در سبک. مقادیر بالاتر بیان سبکی را افزایش می‌دهند اما ممکن است ثبات را کاهش دهند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 - 0.2 |

### ورودی‌های eleven_v3

این پارامترها زمانی در دسترس می‌شوند که `model` روی `"eleven_v3"` تنظیم شود.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعت گفتار. 1.0 نرمال است، <1.0 کندتر، >1.0 سریع‌تر (پیش‌فرض: 1.0). | FLOAT | خیر | 0.7 - 1.3 |
| `similarity_boost` | تقویت شباهت. مقادیر بالاتر صدا را به صدای اصلی شبیه‌تر می‌کند (پیش‌فرض: 0.75). | FLOAT | خیر | 0.0 - 1.0 |
