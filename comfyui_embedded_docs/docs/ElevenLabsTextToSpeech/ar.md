# ElevenLabs تحويل النص إلى كلام

تقوم عقدة تحويل النص إلى كلام من ElevenLabs بتحويل النص المكتوب إلى صوت منطوق باستخدام واجهة برمجة تطبيقات ElevenLabs. تتيح لك اختيار صوت محدد وضبط خصائص الكلام المختلفة بدقة مثل الاستقرار والسرعة والأسلوب لتوليد مخرج صوتي مخصص.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `النموذج` | النموذج المستخدم لتحويل النص إلى كلام. يؤدي اختيار نموذج إلى إظهار معاملاته الخاصة. | DYNAMIC_COMBO | لا | `"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `الصوت` | الصوت المستخدم في تركيب الكلام. يمكن توصيله من أداة اختيار الصوت أو استنساخ الصوت الفوري. | CUSTOM | نعم | N/A |
| `النص` | النص المراد تحويله إلى كلام. يجب أن يحتوي على حرف واحد على الأقل. | STRING | نعم | N/A |
| `الثبات` | استقرار الصوت. القيم الأقل تمنح نطاقًا عاطفيًا أوسع، بينما تنتج القيم الأعلى كلامًا أكثر اتساقًا لكنه قد يكون رتيبًا (الافتراضي: 0.5). | FLOAT | لا | 0.0 - 1.0 |
| `تطبيق تنسيق النص` | وضع تطبيع النص. يترك الخيار `'auto'` القرار للنظام، بينما يطبق `'on'` التطبيع دائمًا، ويتجاوزه `'off'`. | COMBO | لا | `"auto"`<br>`"on"`<br>`"off"` |
| `رمز اللغة` | رمز اللغة وفق معيار ISO-639-1 أو ISO-639-3 (مثل `'en'` أو `'es'` أو `'fra'`). اتركه فارغًا للكشف التلقائي (الافتراضي: `""`). | STRING | لا | N/A |
| `البذرة` | بذرة (Seed) لإمكانية إعادة الإنتاج (الانتظام غير مضمون) (الافتراضي: 1). | INT | لا | 0 - 2147483647 |
| `صيغة الإخراج` | تنسيق إخراج الصوت. | COMBO | لا | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### مدخلات eleven_multilingual_v2

تصبح هذه المعاملات متاحة عندما يتم تعيين `model` إلى `"eleven_multilingual_v2"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `speed` | سرعة الكلام. القيمة 1.0 طبيعية، <1.0 أبطأ، >1.0 أسرع (الافتراضي: 1.0). | FLOAT | لا | 0.7 - 1.3 |
| `similarity_boost` | تعزيز التشابه. القيم الأعلى تجعل الصوت أكثر تشابهًا مع الصوت الأصلي (الافتراضي: 0.75). | FLOAT | لا | 0.0 - 1.0 |
| `use_speaker_boost` | تعزيز التشابه مع صوت المتحدث الأصلي (الافتراضي: False). | BOOLEAN | لا | True / False |
| `style` | مبالغة الأسلوب. القيم الأعلى تزيد التعبير الأسلوبي لكنها قد تقلل الاستقرار (الافتراضي: 0.0). | FLOAT | لا | 0.0 - 0.2 |

### مدخلات eleven_v3

تصبح هذه المعاملات متاحة عندما يتم تعيين `model` إلى `"eleven_v3"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `speed` | سرعة الكلام. القيمة 1.0 طبيعية، <1.0 أبطأ، >1.0 أسرع (الافتراضي: 1.0). | FLOAT | لا | 0.7 - 1.3 |
| `similarity_boost` | تعزيز التشابه. القيم الأعلى تجعل الصوت أكثر تشابهًا مع الصوت الأصلي (الافتراضي: 0.75). | FLOAT | لا | 0.0 - 1.0 |
