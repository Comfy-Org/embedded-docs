# ElevenLabs تحويل النص إلى كلام

تقوم عقدة ElevenLabs Text to Speech بتحويل النص المكتوب إلى صوت منطوق باستخدام واجهة برمجة تطبيقات ElevenLabs. تتيح لك اختيار صوت محدد وضبط خصائص متعددة للكلام مثل الاستقرار والسرعة والأسلوب لإنشاء مخرج صوتي مخصص. يجب أن يحتوي النص على حرف واحد على الأقل.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم لتحويل النص إلى كلام. يؤدي تحديد نموذج إلى إظهار معاملاته الخاصة. | DYNAMIC_COMBO | لا | `"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `voice` | الصوت المستخدم لتركيب الكلام. يتم التوصيل من Voice Selector أو Instant Voice Clone. | CUSTOM | نعم | N/A |
| `text` | النص المراد تحويله إلى كلام. يجب أن يحتوي على حرف واحد على الأقل. | STRING | نعم | N/A |
| `stability` | استقرار الصوت. القيم الأقل تمنح نطاقًا عاطفيًا أوسع، بينما تنتج القيم الأعلى كلامًا أكثر ثباتًا ولكن قد يكون رتيبًا (الافتراضي: 0.5). | FLOAT | لا | 0.0 - 1.0 |
| `apply_text_normalization` | وضع تسوية النص. 'auto' يدع النظام يقرر، و'on' يطبق التسوية دائمًا، و'off' يتخطاها. | COMBO | لا | `"auto"`<br>`"on"`<br>`"off"` |
| `language_code` | رمز اللغة وفق ISO-639-1 أو ISO-639-3 (مثل 'en'، 'es'، 'fra'). اتركه فارغًا للكشف التلقائي (الافتراضي: ""). | STRING | لا | N/A |
| `seed` | بذرة عشوائية لإمكانية إعادة الإنتاج (لا يتم ضمان الحتمية) (الافتراضي: 1). | INT | لا | 0 - 2147483647 |
| `output_format` | تنسيق إخراج الصوت. | COMBO | لا | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### مدخلات eleven_multilingual_v2

تصبح هذه المعاملات متاحة عندما يتم تعيين `model` إلى `"eleven_multilingual_v2"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعة الكلام. 1.0 هي السرعة العادية، <1.0 أبطأ، >1.0 أسرع (الافتراضي: 1.0). | FLOAT | لا | 0.7 - 1.3 |
| `similarity_boost` | تعزيز التشابه. القيم الأعلى تجعل الصوت أكثر تشابهًا مع الأصل (الافتراضي: 0.75). | FLOAT | لا | 0.0 - 1.0 |
| `use_speaker_boost` | تعزيز التشابه مع صوت المتحدث الأصلي (الافتراضي: False). | BOOLEAN | لا | True / False |
| `style` | مبالغة الأسلوب. تزيد القيم الأعلى التعبير الأسلوبي ولكنها قد تقلل الاستقرار (الافتراضي: 0.0). | FLOAT | لا | 0.0 - 0.2 |

### مدخلات eleven_v3

تصبح هذه المعاملات متاحة عندما يتم تعيين `model` إلى `"eleven_v3"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعة الكلام. 1.0 هي السرعة العادية، <1.0 أبطأ، >1.0 أسرع (الافتراضي: 1.0). | FLOAT | لا | 0.7 - 1.3 |
| `similarity_boost` | تعزيز التشابه. القيم الأعلى تجعل الصوت أكثر تشابهًا مع الأصل (الافتراضي: 0.75). | FLOAT | لا | 0.0 - 1.0 |
