# ElevenLabs טקסט לדיבור

צומת ElevenLabs Text to Speech ממיר טקסט כתוב לאודיו מדובר באמצעות ElevenLabs API. הוא מאפשר לבחור קול ספציפי ולכוונן מאפיינים שונים של דיבור כמו יציבות, מהירות וסגנון כדי ליצור פלט אודיו מותאם אישית. הטקסט חייב להכיל לפחות תו אחד.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש עבור טקסט לדיבור. בחירת מודל חושפת את הפרמטרים הייחודיים שלו. | DYNAMIC_COMBO | לא | `"eleven_v4"`<br>`"eleven_v4_turbo"`<br>`"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `voice` | קול לשימוש בסינתזת דיבור. יש לחבר מ-Voice Selector או Instant Voice Clone. | CUSTOM | כן | N/A |
| `text` | הטקסט להמרה לדיבור. חייב להכיל לפחות תו אחד. | STRING | כן | N/A |
| `stability` | יציבות הקול. ערכים נמוכים יותר מעניקים טווח רגשי רחב יותר, ערכים גבוהים יותר מפיקים דיבור עקבי יותר אך עלולים להיות מונוטוניים (ברירת מחדל: 0.5). | FLOAT | לא | 0.0 - 1.0 |
| `apply_text_normalization` | מצב נרמול טקסט. 'auto' נותן למערכת להחליט, 'on' תמיד מיישם נרמול, 'off' מדלג עליו. | COMBO | לא | `"auto"`<br>`"on"`<br>`"off"` |
| `language_code` | קוד שפה ISO 639-1 (למשל 'en', 'es', 'ja'). יש להשאיר ריק לזיהוי אוטומטי (ברירת מחדל: ""). | STRING | לא | N/A |
| `seed` | Seed לשחזוריות (דטרמיניזם אינו מובטח) (ברירת מחדל: 1). | INT | לא | 0 - 2147483647 |
| `output_format` | פורמט פלט האודיו. | COMBO | לא | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### קלטים של eleven_multilingual_v2

פרמטרים אלה הופכים לזמינים כאשר `model` מוגדר ל-`"eleven_multilingual_v2"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `speed` | מהירות דיבור. 1.0 הוא רגיל, פחות מ-1.0 איטי יותר, יותר מ-1.0 מהיר יותר (ברירת מחדל: 1.0). | FLOAT | לא | 0.7 - 1.2 |
| `similarity_boost` | הגברת דמיון. ערכים גבוהים יותר הופכים את הקול לדומה יותר למקור (ברירת מחדל: 0.75). | FLOAT | לא | 0.0 - 1.0 |
| `use_speaker_boost` | הגברת הדמיון לקול הדובר המקורי (ברירת מחדל: False). | BOOLEAN | לא | True / False |
| `style` | הגזמה סגנונית. ערכים גבוהים יותר מגבירים ביטוי סגנוני אך עלולים להפחית יציבות (ברירת מחדל: 0.0). | FLOAT | לא | 0.0 - 0.2 |
