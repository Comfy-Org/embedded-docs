# ElevenLabs 語音合成

ElevenLabs 文字轉語音節點會使用 ElevenLabs API 將書面文字轉換為語音音訊。您可以選取特定語音，並微調穩定性、速度和風格等各種語音特性，以產生自訂的音訊輸出。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於文字轉語音的模型。選取模型後會顯示其特定參數。 | DYNAMIC_COMBO | 否 | `"eleven_multilingual_v2"`<br>`"eleven_v3"` |
| `語音` | 用於語音合成的語音。從 Voice Selector 或 Instant Voice Clone 連接。 | CUSTOM | 是 | N/A |
| `文字` | 要轉換為語音的文字。必須至少包含一個字元。 | STRING | 是 | N/A |
| `穩定性` | 語音穩定性。數值越低，情感範圍越廣；數值越高，語音更一致但可能較為單調（預設值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `套用文字正規化` | 文字正規化模式。'auto' 由系統決定，'on' 一律套用正規化，'off' 則略過。 | COMBO | 否 | `"auto"`<br>`"on"`<br>`"off"` |
| `語言代碼` | ISO-639-1 或 ISO-639-3 語言代碼（例如：'en'、'es'、'fra'）。留空以自動偵測（預設值：""）。 | STRING | 否 | N/A |
| `種子值` | 用於可重現性的種子（不保證確定性）（預設值：1）。 | INT | 否 | 0 - 2147483647 |
| `輸出格式` | 音訊輸出格式。 | COMBO | 否 | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### eleven_multilingual_v2 輸入

當 `model` 設定為 `"eleven_multilingual_v2"` 時，可使用以下參數。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 語音速度。1.0 為正常速度，<1.0 較慢，>1.0 較快（預設值：1.0）。 | FLOAT | 否 | 0.7 - 1.3 |
| `similarity_boost` | 相似度增強。數值越高，語音越接近原始語音（預設值：0.75）。 | FLOAT | 否 | 0.0 - 1.0 |
| `use_speaker_boost` | 增強與原始說話者語音的相似度（預設值：False）。 | BOOLEAN | 否 | True / False |
| `style` | 風格誇張程度。數值越高，風格表現越強，但可能降低穩定性（預設值：0.0）。 | FLOAT | 否 | 0.0 - 0.2 |

| `similarity_boost` | 相似度增強。數值越高，語音越接近原始語音（預設值：0.75）。 | FLOAT | 否 | 0.0 - 1.0 |
