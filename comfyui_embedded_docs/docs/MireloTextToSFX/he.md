# Mirelo Text to SFX

צור אפקט קול מתיאור טקסטואלי עם Mirelo SFX. תָאֵר את הצליל עצמו, לא את התמונה שאליה הוא שייך, והצומת מחזיר רצועת אודיו אחת באורך המבוקש. השתמש בו לפיילי, אווירה, השפעות וטקסטורות מוזיקליות קצרות ללא צילום או העלאת וידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל לשימוש. בחירת מודל חושפת את הפרמטרים הייחודיים לו: `prompt`, `negative_prompt`, `duration` ו-`seed`. | DYNAMIC_COMBO | כן | `"sfx-2.0"` |
| `prompt` | תאר את הצליל, לא את התמונה. 1 עד 2000 תווים. | STRING | כן | 1 עד 2000 תווים |
| `negative_prompt` | צלילים שיש להימנע מהם, כרשימה קצרה מופרדת בפסיקים. ניתן להשאיר ריק (ברירת מחדל: ריק). מקסימום 1000 תווים. | STRING | כן | עד 1000 תווים |
| `duration` | אורך הצליל בשניות. (ברירת מחדל: 5.0) | FLOAT | כן | 0.1 עד 600.0 (צעד 0.1) |
| `seed` | הזרע לבקשה. התוצאות אינן דטרמיניסטיות, ולכן אותו זרע אינו חוזר על צליל זהה. (ברירת מחדל: 42) | INT | כן | 0 עד 4294967295 |

הצומת נעצר עם שגיאה כאשר `prompt` ריק או ארוך מ-2000 תווים, וכאשר `negative_prompt` ארוך מ-1000 תווים.
