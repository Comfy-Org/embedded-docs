# Mirelo Text to SFX

Создавайте звуковой эффект по текстовому описанию с помощью Mirelo SFX. Описывайте сам звук, а не изображение, к которому он относится; узел возвращает одну аудиодорожку запрошенной длины. Используйте его для фоли, атмосферных звуков, ударов и коротких музыкальных текстур без съёмки или загрузки видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель. При выборе модели отображаются специфичные для неё параметры: `prompt`, `negative_prompt`, `duration` и `seed`. | DYNAMIC_COMBO | Да | `"sfx-2.0"` |
| `prompt` | Опишите звук, а не изображение. От 1 до 2000 символов. | STRING | Да | 1–2000 символов |
| `negative_prompt` | Звуки, которых следует избегать, в виде короткого списка через запятую. Может быть оставлен пустым (по умолчанию: пусто). Максимум 1000 символов. | STRING | Да | До 1000 символов |
| `duration` | Длительность звука в секундах. (по умолчанию: 5.0) | FLOAT | Да | 0.1–600.0 (шаг 0.1) |
| `seed` | Сид для запроса. Результаты недетерминированы, поэтому одно и то же значение seed не гарантирует повторение звука. (по умолчанию: 42) | INT | Да | 0–4294967295 |

Узел завершается с ошибкой, если `prompt` пуст или длиннее 2000 символов, а также если `negative_prompt` длиннее 1000 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `AUDIO` | Сгенерированный звуковой эффект длительностью, равной `duration`. | AUDIO |
