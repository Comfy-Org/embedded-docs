# مقیاس‌بندی ROPE

گره ScaleROPE، جاسازی موقعیت چرخشی (ROPE) یک مدل را با اعمال عوامل مقیاس‌گذاری و جابجایی جداگانه به مؤلفه‌های X، Y و T (زمان) آن اصلاح می‌کند. این یک گره پیشرفته و آزمایشی است که برای تنظیم رفتار رمزگذاری موقعیتی مدل استفاده می‌شود.

| `model` | مدلی که پارامترهای ROPE آن اصلاح خواهد شد. | MODEL | بله | - |
| `scale_x` | ضریب مقیاس‌گذاری که برای مؤلفه X از ROPE اعمال می‌شود (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 100.0 (step 0.1) |

| `scale_y` | ضریب مقیاس‌گذاری که برای مؤلفه Y از ROPE اعمال می‌شود (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 100.0 (step 0.1) |
