# مقیاس‌بندی ROPE

گره ScaleROPE به شما امکان می‌دهد تا جاسازی موقعیت چرخشی (ROPE) یک مدل را با اعمال عوامل مقیاس‌گذاری و جابه‌جایی جداگانه بر مؤلفه‌های X، Y و T (زمان) آن تغییر دهید. این یک گره پیشرفته و آزمایشی است که برای تنظیم رفتار کدگذاری موقعیتی مدل استفاده می‌شود.

| `مدل` | مدلی که پارامترهای ROPE آن تغییر خواهد کرد. | MODEL | بله | - |
| `مقیاس X` | ضریب مقیاس‌گذاری برای اعمال بر مؤلفه X از ROPE (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 100.0 (step 0.1) |

| `مقیاس Y` | ضریب مقیاس‌گذاری برای اعمال بر مؤلفه Y از ROPE (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 100.0 (step 0.1) |
| `جابجایی Y` | مقدار جابه‌جایی برای اعمال بر مؤلفه Y از ROPE (پیش‌فرض: 0.0). | FLOAT | بله | -256.0 - 256.0 (step 0.1) |

| `جابجایی T` | مقدار جابه‌جایی برای اعمال بر مؤلفه T (زمان) از ROPE (پیش‌فرض: 0.0). | FLOAT | بله | -256.0 - 256.0 (step 0.1) |
