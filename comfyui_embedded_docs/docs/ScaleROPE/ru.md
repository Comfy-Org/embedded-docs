# ScaleROPE

Узел ScaleROPE позволяет изменять вращательное позиционное кодирование (ROPE) модели, применяя отдельные коэффициенты масштабирования и сдвига к её компонентам X, Y и T (время). Это продвинутый экспериментальный узел, используемый для настройки поведения позиционного кодирования модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, параметры ROPE которой будут изменены. | MODEL | Да | - |
| `масштаб_x` | Коэффициент масштабирования, применяемый к компоненту X кодирования ROPE (по умолчанию: 1.0). | FLOAT | Да | 0.0 - 100.0 (step 0.1) |
| `сдвиг_x` | Величина сдвига, применяемая к компоненту X кодирования ROPE (по умолчанию: 0.0). | FLOAT | Да | -256.0 - 256.0 (step 0.1) |
| `масштаб_y` | Коэффициент масштабирования, применяемый к компоненту Y кодирования ROPE (по умолчанию: 1.0). | FLOAT | Да | 0.0 - 100.0 (step 0.1) |
| `сдвиг_y` | Величина сдвига, применяемая к компоненту Y кодирования ROPE (по умолчанию: 0.0). | FLOAT | Да | -256.0 - 256.0 (step 0.1) |
| `масштаб_t` | Коэффициент масштабирования, применяемый к компоненту T (время) кодирования ROPE (по умолчанию: 1.0). | FLOAT | Да | 0.0 - 100.0 (step 0.1) |
| `сдвиг_t` | Величина сдвига, применяемая к компоненту T (время) кодирования ROPE (по умолчанию: 0.0). | FLOAT | Да | -256.0 - 256.0 (step 0.1) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с применёнными новыми параметрами масштабирования и сдвига ROPE. | MODEL |
