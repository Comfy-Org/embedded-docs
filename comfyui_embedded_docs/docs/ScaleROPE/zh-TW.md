# 縮放ROPE

ScaleROPE 節點允許您透過對模型的 X、Y、T（時間）分量分別套用縮放與平移因子，來修改模型的旋轉位置編碼（ROPE）。這是一個進階的實驗性節點，用於調整模型的位置編碼行為。

| 參數 | 描述 | 資料類型 | 是否必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `模型` | 要修改其 ROPE 參數的模型。 | MODEL | 是 | - |
| `x軸縮放` | 套用至 ROPE X 分量的縮放因子（預設值：1.0）。 | FLOAT | 是 | 0.0 - 100.0（步長 0.1） |
| `x軸平移` | 套用至 ROPE X 分量的平移值（預設值：0.0）。 | FLOAT | 是 | -256.0 - 256.0（步長 0.1） |
| `y軸縮放` | 套用至 ROPE Y 分量的縮放因子（預設值：1.0）。 | FLOAT | 是 | 0.0 - 100.0（步長 0.1） |
| `y軸平移` | 套用至 ROPE Y 分量的平移值（預設值：0.0）。 | FLOAT | 是 | -256.0 - 256.0（步長 0.1） |
