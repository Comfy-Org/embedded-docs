# ROPE 스케일

ScaleROPE 노드는 모델의 X, Y, T(시간) 성분에 별도의 스케일링 계수와 시프트 값을 적용하여 회전 위치 임베딩(ROPE)을 수정합니다. 이는 모델의 위치 인코딩 동작을 조정하는 데 사용되는 고급 실험용 노드입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | ROPE 매개변수가 수정될 모델입니다. | MODEL | 예 | - |
| `scale_x` | ROPE의 X 성분에 적용할 스케일링 계수입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 - 100.0 (단계 0.1) |
| `shift_x` | ROPE의 X 성분에 적용할 시프트 값입니다 (기본값: 0.0). | FLOAT | 예 | -256.0 - 256.0 (단계 0.1) |
| `scale_y` | ROPE의 Y 성분에 적용할 스케일링 계수입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 - 100.0 (단계 0.1) |
| `shift_y` | ROPE의 Y 성분에 적용할 시프트 값입니다 (기본값: 0.0). | FLOAT | 예 | -256.0 - 256.0 (단계 0.1) |
| `scale_t` | ROPE의 T(시간) 성분에 적용할 스케일링 계수입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 - 100.0 (단계 0.1) |
| `shift_t` | ROPE의 T(시간) 성분에 적용할 시프트 값입니다 (기본값: 0.0). | FLOAT | 예 | -256.0 - 256.0 (단계 0.1) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 새로운 ROPE 스케일링 및 시프트 매개변수가 적용된 모델입니다. | MODEL |
