# Comfy Cloud Flux 2 متن به تصویر [بتا]

مدل متن‌به‌تصویر Flux 2 dev را روی GPU ابری Comfy اجرا می‌کند و تصویر تولیدشده را برمی‌گرداند. گزینهٔ `turbo` یک LoRA Turbo را با زمان‌بندی کوتاه اعمال می‌کند تا اجرا بسیار سریع‌تر شود، به قیمت از دست رفتن اندکی وفاداری؛ خاموش کردن آن، اجرای کامل dev را بدون LoRA انجام می‌دهد. این یک مجموعهٔ گره بتا است و هزینهٔ آن بر اساس مدت‌زمان اجرا با اعتبار (credits) محاسبه می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن پرامپتی که تصویر مورد نظر برای تولید را توصیف می‌کند. فاصله‌های خالی ابتدا و انتها پیش از ارسال حذف می‌شود. | STRING | بله | 1 تا 4096 کاراکتر |
| `seed` | دانهٔ تصادفی که نتیجهٔ تولیدشده را برای بازتولیدپذیری کنترل می‌کند (پیش‌فرض: 42). | INT | بله | 0 تا 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد تصویر خروجی (پیش‌فرض: "1:1"). | COMBO | بله | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | بودجهٔ کل پیکسل‌ها. مقدار 1.0 در نسبت مربعی حدوداً معادل 1024x1024 است (پیش‌فرض: 1.0). | FLOAT | بله | 0.1 تا 16.0 (گام 0.1) |
| `turbo` | اجرای LoRA Turbo با زمان‌بندی کوتاه؛ این کار کمی از وفاداری را فدای اجرای بسیار سریع‌تر می‌کند. خاموش بودن آن، اجرای کامل dev را بدون LoRA انجام می‌دهد (پیش‌فرض: True). | BOOLEAN | بله | True / False |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر تولیدشده از متن پرامپت که به‌صورت تنسور تصویر ComfyUI برگردانده می‌شود و می‌توان آن را به گره‌های دیگر داد. | IMAGE |
