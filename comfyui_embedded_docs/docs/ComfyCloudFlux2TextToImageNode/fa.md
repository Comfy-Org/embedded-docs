# ComfyCloudFlux2TextToImageNode

مدل متن‌به‌تصویر Flux 2 dev را روی GPU ابری Comfy اجرا می‌کند و تصویر تولیدشده را برمی‌گرداند. گزینه‌ی `turbo` با یک برنامه‌ی زمانی کوتاه، Turbo LoRA را اعمال می‌کند تا اجرا بسیار سریع‌تر انجام شود، در ازای افت کمی در وفاداری. در حالت خاموش، پاس کامل dev بدون LoRA اجرا می‌شود. این مجموعه‌ی گره‌ها در مرحله‌ی بتا است و هزینه‌ی آن بر اساس مدت زمان اجرا بر حسب اعتبار محاسبه می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن prompt که تصویر مورد نظر برای تولید را توصیف می‌کند. فاصله‌های ابتدایی و انتهایی قبل از ارسال حذف می‌شوند. | STRING | بله | 1 تا 4096 کاراکتر |
| `seed` | Seed تصادفی که برای تکرارپذیری، نتیجه‌ی تولیدشده را کنترل می‌کند (پیش‌فرض: 42). | INT | بله | 0 تا 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد تصویر خروجی (پیش‌فرض: "1:1"). | COMBO | بله | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | کل بودجه‌ی پیکسل. مقدار 1.0 تقریباً معادل 1024×1024 در نسبت مربع است (پیش‌فرض: 1.0). | FLOAT | بله | 0.1 تا 16.0 (گام 0.1) |
| `turbo` | اجرای Turbo LoRA با یک برنامه‌ی زمانی کوتاه، که کمی وفاداری را با سرعت بسیار بیشتر معاوضه می‌کند. در حالت غیرفعال، پاس کامل dev بدون LoRA اجرا می‌شود (پیش‌فرض: True). | BOOLEAN | بله | True / False |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر تولیدشده از روی متن prompt، به‌صورت یک تنسور تصویر ComfyUI بازگردانده می‌شود که می‌توان آن را به گره‌های دیگر ارسال کرد. | IMAGE |
