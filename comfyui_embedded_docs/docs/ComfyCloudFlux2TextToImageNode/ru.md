# Comfy Cloud Flux 2 Текст в изображение [БЕТА]

Запускает модель Flux 2 dev для преобразования текста в изображение на GPU Comfy Cloud и возвращает сгенерированное изображение. Опция `turbo` применяет Turbo LoRA с коротким расписанием для значительно более быстрого запуска ценой небольшой потери точности; при её отключении выполняется полный dev-проход без LoRA. Это бета-набор узлов, тарифицируемый по времени работы в кредитах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации. Начальные и конечные пробелы удаляются перед отправкой. | STRING | Да | от 1 до 4096 символов |
| `seed` | Случайное зерно, управляющее сгенерированным результатом для воспроизводимости (по умолчанию: 42). | INT | Да | от 0 до 18446744073709551615 |
| `aspect_ratio` | Соотношение сторон выходного изображения (по умолчанию: "1:1"). | COMBO | Да | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | Общий бюджет пикселей. 1.0 — это примерно 1024x1024 при квадратном соотношении (по умолчанию: 1.0). | FLOAT | Да | от 0.1 до 16.0 (шаг 0.1) |
| `turbo` | Запускает Turbo LoRA по короткому расписанию, жертвуя небольшой точностью ради значительно более быстрого запуска. Отключено — запускает полный dev-проход без LoRA (по умолчанию: True). | BOOLEAN | Да | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, сгенерированное из текстового запроса, возвращается как тензор изображения ComfyUI, который можно передать другим узлам. | IMAGE |
