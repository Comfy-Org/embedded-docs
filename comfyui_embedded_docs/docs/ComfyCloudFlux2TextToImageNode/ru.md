# ComfyCloudFlux2TextToImageNode

Запускает модель Flux 2 dev для преобразования текста в изображение на GPU Comfy Cloud и возвращает сгенерированное изображение. Опция `turbo` применяет Turbo LoRA с коротким расписанием для гораздо более быстрого выполнения ценой небольшой точности; её отключение выполняет полный проход dev без LoRA. Это бета-набор узлов, тарифицируемый в кредитах в зависимости от времени выполнения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации. Пробельные символы в начале и конце удаляются перед отправкой. | STRING | Да | от 1 до 4096 символов |
| `seed` | Случайное зерно (seed), управляющее результатом генерации для воспроизводимости (по умолчанию: 42). | INT | Да | от 0 до 18446744073709551615 |
| `aspect_ratio` | Соотношение сторон выходного изображения (по умолчанию: "1:1"). | COMBO | Да | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | Общий пиксельный бюджет. 1.0 примерно соответствует 1024x1024 при квадратном соотношении сторон (по умолчанию: 1.0). | FLOAT | Да | от 0.1 до 16.0 (шаг 0.1) |
| `turbo` | Запуск Turbo LoRA по короткому расписанию: небольшая потеря точности ради гораздо более быстрого выполнения. При выключении выполняется полный проход dev без LoRA (по умолчанию: True). | BOOLEAN | Да | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, сгенерированное из текстового запроса, возвращаемое как тензор изображения ComfyUI, который может быть передан другим узлам. | IMAGE |
