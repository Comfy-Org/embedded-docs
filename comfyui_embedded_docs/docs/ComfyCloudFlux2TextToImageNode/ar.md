# Comfy Cloud Flux 2 تحويل النص إلى صورة [تجريبي]

يشغّل نموذج Flux 2 dev للنص إلى صورة على وحدة معالجة رسومات Comfy Cloud ويعيد الصورة المُنشأة. خيار `turbo` يطبّق Turbo LoRA بجدول قصير لتشغيل أسرع بكثير مقابل فقدان القليل من الدقة؛ إيقاف تشغيله ينفذ تمريرة dev كاملة بدون LoRA. هذه مجموعة عُقد تجريبية، يتم احتساب التكلفة حسب مدة التشغيل بالرصيد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | النص التوجيهي الذي يصف الصورة المراد إنشاؤها. تتم إزالة المسافات البيضاء البادئة واللاحقة قبل الإرسال. | STRING | نعم | 1 إلى 4096 characters |
| `seed` | بذرة عشوائية تتحكم في النتيجة المُنشأة لأغراض إعادة الإنتاج (الافتراضي: 42). | INT | نعم | 0 إلى 18446744073709551615 |
| `aspect_ratio` | نسبة أبعاد الصورة الناتجة (الافتراضي: "1:1"). | COMBO | نعم | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | إجمالي ميزانية البكسل. 1.0 تعادل تقريبًا 1024x1024 عند نسبة مربعة (الافتراضي: 1.0). | FLOAT | نعم | 0.1 إلى 16.0 (خطوة: 0.1) |
| `turbo` | تشغيل Turbo LoRA وفق جدول قصير، مما يقايض القليل من الدقة مقابل تشغيل أسرع بكثير. إيقاف التشغيل ينفذ تمريرة dev كاملة بدون LoRA (الافتراضي: True). | BOOLEAN | نعم | True / False |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `IMAGE` | الصورة المُنشأة من النص التوجيهي، تُعاد كموتر صورة ComfyUI يمكن تمريره إلى عُقد أخرى. | IMAGE |
