# Comfy Cloud Flux 2 טקסט לתמונה [BETA]

מפעיל את מודל Flux 2 dev לטקסט-לתמונה על GPU של Comfy Cloud ומחזיר את התמונה שנוצרה. האפשרות `turbo` מחילה את ה-Turbo LoRA עם לוח זמנים קצר להרצה מהירה בהרבה, במחיר של מעט פחות נאמנות; כיבויה מבצע מעבר dev באורך מלא ללא ה-LoRA. זוהי ערכת צמתים בגרסת בטא, שהחיוב עבורה נעשה לפי משך ההרצה בקרדיטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית הטקסט המתארת את התמונה ליצירה. רווחים בתחילת ובסוף המחרוזת מוסרים לפני השליחה. | STRING | כן | 1 to 4096 characters |
| `seed` | זרע אקראי השולט בתוצאה הנוצרת לצורך שחזוריות (ברירת מחדל: 42). | INT | כן | 0 to 18446744073709551615 |
| `aspect_ratio` | יחס רוחב-גובה של תמונת הפלט (ברירת מחדל: "1:1"). | COMBO | כן | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | תקציב הפיקסלים הכולל. 1.0 הוא בערך 1024x1024 ביחס ריבועי (ברירת מחדל: 1.0). | FLOAT | כן | 0.1 to 16.0 (step 0.1) |
| `turbo` | מפעיל את ה-Turbo LoRA בלוח זמנים קצר, תוך החלפת מעט נאמנות בהרצה מהירה בהרבה. כבוי מריץ את מעבר ה-dev באורך מלא ללא LoRA (ברירת מחדל: True). | BOOLEAN | כן | True / False |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `IMAGE` | התמונה שנוצרה מהנחיית הטקסט, מוחזרת כטנסור תמונה של ComfyUI שניתן להעביר לצמתים אחרים. | IMAGE |
