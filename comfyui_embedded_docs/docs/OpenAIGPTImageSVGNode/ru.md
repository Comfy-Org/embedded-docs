# OpenAI GPT Image 2.6 SVG

## Обзор

OpenAI GPT Image 2.6 SVG создаёт редактируемый SVG по запросу с помощью моделей OpenAI GPT Image. Результат представляет собой векторную разметку, поэтому фигуры и текст остаются редактируемыми в векторном редакторе. Доступны две модели: `gpt-image-2.6-flare` и `gpt-image-2.6-sunburst`.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель GPT Image, используемая для SVG. | DYNAMIC_COMBO | Да | `"gpt-image-2.6-flare"`<br>`"gpt-image-2.6-sunburst"` |

### Входы gpt-image-2.6-flare и gpt-image-2.6-sunburst

Обе модели используют одинаковые параметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Описание SVG для отрисовки. (по умолчанию: `""`) | STRING | Да | Н/Д |
| `model.size` | Размер референсного изображения, на основе которого создаётся SVG. (по умолчанию: `"1024x1024"`) | COMBO | Да | `"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `model.background` | Фон референсного изображения. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | Качество референсного изображения, на основе которого создаётся SVG. (по умолчанию: `"low"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.complexity` | Насколько детально модель планирует референсное изображение перед рендерингом. (по умолчанию: `"high"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `model.seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от seed. (по умолчанию: `42`) | INT | Да | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `svg` | Сгенерированное векторное изображение в виде SVG-разметки. | SVG |
