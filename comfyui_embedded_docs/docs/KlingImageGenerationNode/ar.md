# توليد صورة كليغ

عقدة توليد الصور Kling تنشئ الصور من الموجّهات النصية مع خيار استخدام صورة مرجعية للتوجيه. تنشئ صورة واحدة أو أكثر بناءً على وصفك النصي وإعدادات المرجع، ثم تُرجع الصور المولّدة كمخرجات.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجّه نصي إيجابي. مطلوب، ويجب أن يتراوح طوله بين 1 و500 حرف. | STRING | نعم | الحد الأقصى 500 حرف |
| `negative_prompt` | موجّه نصي سلبي. | STRING | نعم | الحد الأقصى 500 حرف |
| `image_type` | اختيار نوع مرجع الصورة (متقدم). مطلوب عند توفير صورة مرجعية. | COMBO | نعم | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | شدة المرجعية للصور التي يرفعها المستخدم (الافتراضي: 0.5، متقدم) | FLOAT | نعم | 0.0 - 1.0 |
| `human_fidelity` | تشابه مرجع الموضوع (الافتراضي: 0.45، متقدم) | FLOAT | نعم | 0.0 - 1.0 |
| `model_name` | اختيار النموذج لتوليد الصور (الافتراضي: "kling-v3") | COMBO | نعم | `"kling-v3"` |
| `aspect_ratio` | نسبة العرض إلى الارتفاع للصور المولّدة (الافتراضي: "16:9") | COMBO | نعم | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | عدد الصور المولّدة (الافتراضي: 1) | INT | نعم | 1 - 9 |
| `image` | صورة مرجعية اختيارية | IMAGE | لا | - |
| `seed` | تتحكم البذرة في ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | لا | 0 - 2147483647 |

**قيود المعاملات:**

- المعامل `image` اختياري. عند توفير صورة مرجعية، يحدد المعامل `image_type` ما إذا كان المرجع سيُستخدم كمرجع موضوع أو مرجع نمط.
- عند عدم توفير صورة مرجعية، لا يكون لإعدادات المرجع (`image_type`، `image_fidelity`، `human_fidelity`) أي تأثير على النتيجة.
- يبلغ الحد الأقصى لطول `prompt` و`negative_prompt` 500 حرف.
- المعامل `seed` اختياري ولا يضمن نتائج حتمية.
- يتحكم المعامل `n` في عدد الصور المنتجة، كما يحدد سعر الطلب.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `output` | صورة/صور مولّدة بناءً على معاملات الإدخال. عندما تكون قيمة `n` أكبر من 1، تُعاد صور متعددة دفعةً واحدة. | IMAGE |
