# Kling画像生成

Kling Image Generation Node は、テキストプロンプトから画像を生成し、必要に応じて参照画像をガイドとして使用できます。テキストによる説明と参照設定に基づいて1枚以上の画像を作成し、生成された画像を出力として返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ポジティブテキストプロンプト | STRING | はい | 最大500文字 |
| `negative_prompt` | ネガティブテキストプロンプト | STRING | はい | 最大500文字 |
| `image_type` | 画像参照タイプの選択（上級者向け）。参照画像が提供された場合に使用されます。 | COMBO | はい | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | ユーザーがアップロードした画像の参照強度（デフォルト: 0.5、上級者向け） | FLOAT | はい | 0.0 - 1.0 |
| `human_fidelity` | 被写体参照の類似度（デフォルト: 0.45、上級者向け） | FLOAT | はい | 0.0 - 1.0 |
| `model_name` | 画像生成用モデルの選択（デフォルト: "kling-v3"） | COMBO | はい | `"kling-v3"`<br>`"kling-v2"` |
| `aspect_ratio` | 生成画像のアスペクト比（デフォルト: "16:9"） | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | 生成する画像の枚数（デフォルト: 1） | INT | はい | 1 - 9 |
| `image` | 任意の参照画像 | IMAGE | いいえ | - |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 0） | INT | いいえ | 0 - 2147483647 |

**パラメータ制約:**

- `image` パラメータは任意です。参照画像が提供された場合、`image_type` によって被写体参照かスタイル参照かが決まります。参照画像が提供されない場合、`image_type` は適用されません。
- `prompt` は少なくとも1文字、最大500文字である必要があります。`negative_prompt` は空でも構いませんが、500文字に制限されます。
- `seed` パラメータは任意であり、決定的な結果を保証するものではありません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 入力パラメータに基づいて生成された画像。複数の画像が要求された場合は、すべての画像が1つのバッチにスタックされて返されます。 | IMAGE |
