# Kling 3.0 תמונה

צומת Kling Image Generation יוצר תמונות מפרומפטים טקסטואליים עם אפשרות להשתמש בתמונת ייחוס להכוונה. הוא יוצר תמונה אחת או יותר בהתבסס על תיאור הטקסט והגדרות הייחוס שלך, ואז מחזיר את התמונות שנוצרו כפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסט חיובי. חובה, חייב להיות בין 1 ל-500 תווים. | STRING | כן | מקסימום 500 תווים |
| `negative_prompt` | פרומפט טקסט שלילי. | STRING | כן | מקסימום 500 תווים |
| `image_type` | בחירת סוג ייחוס תמונה (מתקדם). חובה כאשר מסופקת תמונת ייחוס. | COMBO | כן | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | עוצמת ייחוס לתמונות שהעלה המשתמש (ברירת מחדל: 0.5, מתקדם) | FLOAT | כן | 0.0 - 1.0 |
| `human_fidelity` | דמיון לייחוס נושא (ברירת מחדל: 0.45, מתקדם) | FLOAT | כן | 0.0 - 1.0 |
| `model_name` | בחירת מודל ליצירת תמונות (ברירת מחדל: "kling-v3") | COMBO | כן | `"kling-v3"` |
| `aspect_ratio` | יחס גובה-רוחב לתמונות שנוצרות (ברירת מחדל: "16:9") | COMBO | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | מספר התמונות שנוצרות (ברירת מחדל: 1) | INT | כן | 1 - 9 |
| `image` | תמונת ייחוס אופציונלית | IMAGE | לא | - |
| `seed` | `seed` קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed` (ברירת מחדל: 0) | INT | לא | 0 - 2147483647 |

**אילוצי פרמטרים:**

- הפרמטר `image` הוא אופציונלי. כאשר מסופקת תמונת ייחוס, הפרמטר `image_type` קובע אם הייחוס משמש כייחוס נושא או כייחוס סגנון.
- כאשר לא מסופקת תמונת ייחוס, להגדרות הקשורות לייחוס (`image_type`, `image_fidelity`, `human_fidelity`) אין השפעה על התוצאה.
- האורך המקסימלי של `prompt` ו-`negative_prompt` הוא 500 תווים.
- הפרמטר `seed` הוא אופציונלי ואינו מבטיח תוצאות דטרמיניסטיות.
- הפרמטר `n` קובע כמה תמונות מיוצרות וגם קובע את מחיר הבקשה.
