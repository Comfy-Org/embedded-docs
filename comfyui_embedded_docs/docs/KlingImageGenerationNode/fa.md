# تولید تصویر Kling

گره تولید تصویر Kling تصاویر را از پرامپت‌های متنی تولید می‌کند و گزینه استفاده از تصویر مرجع را برای راهنمایی فراهم می‌آورد. این گره بر اساس توضیحات متنی و تنظیمات مرجع، یک یا چند تصویر ایجاد می‌کند و سپس تصاویر تولیدشده را به‌عنوان خروجی برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی مثبت. الزامی است و باید بین 1 و 500 کاراکتر باشد. | STRING | بله | حداکثر 500 کاراکتر |
| `negative_prompt` | پرامپت متنی منفی. | STRING | بله | حداکثر 500 کاراکتر |
| `image_type` | انتخاب نوع مرجع تصویر (پیشرفته). هنگام ارائه تصویر مرجع الزامی است. | COMBO | بله | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | شدت مرجع برای تصاویر بارگذاری‌شده توسط کاربر (پیش‌فرض: 0.5، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `human_fidelity` | میزان شباهت مرجع سوژه (پیش‌فرض: 0.45، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `model_name` | انتخاب مدل برای تولید تصویر (پیش‌فرض: "kling-v3") | COMBO | بله | `"kling-v3"` |
| `aspect_ratio` | نسبت ابعاد تصاویر تولیدشده (پیش‌فرض: "16:9") | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | تعداد تصاویر تولیدشده (پیش‌فرض: 1) | INT | بله | 1 - 9 |
| `image` | تصویر مرجع اختیاری | IMAGE | خیر | - |
| `seed` | `seed` کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به `seed` قطعی نیستند (پیش‌فرض: 0) | INT | خیر | 0 - 2147483647 |

**محدودیت‌های پارامترها:**

- پارامتر `image` اختیاری است. هنگامی که تصویر مرجع ارائه می‌شود، پارامتر `image_type` تعیین می‌کند که مرجع به‌عنوان مرجع سوژه یا مرجع سبک استفاده شود.
- وقتی هیچ تصویر مرجعی ارائه نشود، تنظیمات مرتبط با مرجع (`image_type`، `image_fidelity`، `human_fidelity`) هیچ تأثیری بر نتیجه ندارند.
- `prompt` و `negative_prompt` حداکثر طول 500 کاراکتر دارند.
- پارامتر `seed` اختیاری است و نتایج قطعی را تضمین نمی‌کند.
- پارامتر `n` کنترل می‌کند که چند تصویر تولید شود و همچنین هزینه درخواست را تعیین می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) تولیدشده بر اساس پارامترهای ورودی. وقتی `n` بزرگ‌تر از 1 باشد، چند تصویر به‌صورت یک دسته برگردانده می‌شوند. | IMAGE |
