# تولید تصویر Kling

گره تولید تصویر Kling، تصاویری را از پرامپت‌های متنی تولید می‌کند و امکان استفاده از یک تصویر مرجع برای راهنمایی را نیز فراهم می‌کند. این گره بر اساس توضیحات متنی و تنظیمات مرجع شما، یک یا چند تصویر ایجاد کرده و سپس تصاویر تولیدشده را به عنوان خروجی بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی مثبت | STRING | بله | حداکثر ۵۰۰ کاراکتر |
| `negative_prompt` | پرامپت متنی منفی | STRING | بله | حداکثر ۵۰۰ کاراکتر |
| `image_type` | انتخاب نوع مرجع تصویر (پیشرفته). زمانی استفاده می‌شود که یک تصویر مرجع ارائه شده باشد. | COMBO | بله | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | شدت مرجع برای تصاویر بارگذاری‌شده توسط کاربر (پیش‌فرض: 0.5، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `human_fidelity` | میزان شباهت مرجع سوژه (پیش‌فرض: 0.45، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `model_name` | انتخاب مدل برای تولید تصویر (پیش‌فرض: "kling-v3") | COMBO | بله | `"kling-v3"`<br>`"kling-v2"` |
| `aspect_ratio` | نسبت ابعاد تصاویر تولیدشده (پیش‌فرض: "16:9") | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | تعداد تصاویر تولیدشده (پیش‌فرض: 1) | INT | بله | 1 - 9 |
| `image` | تصویر مرجع اختیاری | IMAGE | خیر | - |
| `seed` | سید تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید قطعی نیستند (پیش‌فرض: 0) | INT | خیر | 0 - 2147483647 |

**محدودیت‌های پارامتر:**

- پارامتر `image` اختیاری است. هنگامی که یک تصویر مرجع ارائه شود، `image_type` تعیین می‌کند که آیا به عنوان مرجع سوژه استفاده شود یا مرجع سبک. اگر هیچ تصویر مرجعی ارائه نشود، `image_type` اعمال نمی‌شود.
- `prompt` باید حداقل ۱ کاراکتر و حداکثر ۵۰۰ کاراکتر داشته باشد. `negative_prompt` می‌تواند خالی باشد، اما حداکثر ۵۰۰ کاراکتر است.
- پارامتر `seed` اختیاری است و نتایج قطعی را تضمین نمی‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) تولیدشده بر اساس پارامترهای ورودی. زمانی که بیش از یک تصویر درخواست شود، همه تصاویر به صورت انباشته در یک دسته واحد بازگردانده می‌شوند. | IMAGE |
