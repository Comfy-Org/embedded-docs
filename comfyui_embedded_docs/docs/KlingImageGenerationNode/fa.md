# تولید تصویر Kling

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی مثبت | STRING | بله | حداکثر ۵۰۰ کاراکتر |
| `negative_prompt` | پرامپت متنی منفی | STRING | بله | حداکثر ۵۰۰ کاراکتر |
| `image_type` | انتخاب نوع مرجع تصویر (پیشرفته). زمانی که تصویر مرجع ارائه شده باشد، الزامی است. | COMBO | بله | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | شدت مرجع برای تصاویر بارگذاری‌شده توسط کاربر (پیش‌فرض: 0.5، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `human_fidelity` | شباهت مرجع سوژه (پیش‌فرض: 0.45، پیشرفته) | FLOAT | بله | 0.0 - 1.0 |
| `model_name` | انتخاب مدل برای تولید تصویر (پیش‌فرض: "kling-v3") | COMBO | بله | `"kling-v3"` |
| `aspect_ratio` | نسبت تصویر برای تصاویر تولیدشده (پیش‌فرض: "16:9") | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | تعداد تصاویر تولیدشده (پیش‌فرض: 1) | INT | بله | 1 - 9 |
| `image` | تصویر مرجع اختیاری | IMAGE | خیر | - |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed قطعی نیستند (پیش‌فرض: 0) | INT | خیر | 0 - 2147483647 |

**محدودیت‌های پارامتر:**

- پارامتر `image` اختیاری است. هنگامی که یک تصویر مرجع ارائه می‌شود، پارامتر `image_type` تعیین می‌کند که آیا مرجع به‌عنوان مرجع سوژه استفاده شود یا مرجع سبک.
- هنگامی که هیچ تصویر مرجعی ارائه نشود، تنظیمات مرتبط با مرجع (`image_type`، `image_fidelity`، `human_fidelity`) تأثیری بر نتیجه ندارند.
- `prompt` و `negative_prompt` حداکثر طول ۵۰۰ کاراکتر دارند.
- پارامتر `seed` اختیاری است و نتایج قطعی را تضمین نمی‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) تولیدشده بر اساس پارامترهای ورودی. وقتی `n` بزرگ‌تر از ۱ باشد، چندین تصویر به‌صورت یک دسته (batch) بازگردانده می‌شوند. | IMAGE |
