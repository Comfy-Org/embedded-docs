# Генерация изображений Kling

Узел Kling Image Generation генерирует изображения из текстовых промптов с возможностью использовать эталонное изображение для управления. Он создаёт одно или несколько изображений на основе вашего текстового описания и настроек эталона, а затем возвращает сгенерированные изображения в качестве выходных данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Положительный текстовый промпт. Обязателен, должен содержать от 1 до 500 символов. | STRING | Да | Максимум 500 символов |
| `negative_prompt` | Негативный текстовый промпт. | STRING | Да | Максимум 500 символов |
| `image_type` | Выбор типа эталонного изображения (расширенный). Обязателен, если предоставлено эталонное изображение. | COMBO | Да | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | Интенсивность использования эталонного изображения для загруженных пользователем изображений (по умолчанию: 0.5, расширенный) | FLOAT | Да | 0.0 - 1.0 |
| `human_fidelity` | Сходство с эталонным субъектом (по умолчанию: 0.45, расширенный) | FLOAT | Да | 0.0 - 1.0 |
| `model_name` | Выбор модели для генерации изображений (по умолчанию: "kling-v3") | COMBO | Да | `"kling-v3"` |
| `aspect_ratio` | Соотношение сторон для сгенерированных изображений (по умолчанию: "16:9") | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | Количество сгенерированных изображений (по умолчанию: 1) | INT | Да | 1 - 9 |
| `image` | Необязательное эталонное изображение | IMAGE | Нет | - |
| `seed` | `seed` управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от `seed` (по умолчанию: 0) | INT | Нет | 0 - 2147483647 |

**Ограничения параметров:**

- Параметр `image` является необязательным. Когда предоставлено эталонное изображение, параметр `image_type` определяет, используется ли эталон как эталон субъекта или как эталон стиля.
- Если эталонное изображение не предоставлено, настройки, связанные с эталоном (`image_type`, `image_fidelity`, `human_fidelity`), не влияют на результат.
- `prompt` и `negative_prompt` имеют максимальную длину 500 символов.
- Параметр `seed` является необязательным и не гарантирует детерминированные результаты.
- Параметр `n` управляет количеством создаваемых изображений, а также определяет стоимость запроса.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение (или изображения) на основе входных параметров. Когда `n` больше 1, возвращается несколько изображений пакетом. | IMAGE |
