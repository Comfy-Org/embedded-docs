# Генерация изображений Kling

Узел Kling Image Generation создает изображения на основе текстовых подсказок с возможностью использования эталонного изображения для управления. Он создает одно или несколько изображений на основе вашего текстового описания и настроек эталона, затем возвращает сгенерированные изображения в качестве вывода.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Положительный текстовый промпт | STRING | Да | Максимум 500 символов |
| `negative_prompt` | Отрицательный текстовый промпт | STRING | Да | Максимум 500 символов |
| `image_type` | Выбор типа эталонного изображения (расширенная настройка). Обязательно при предоставлении эталонного изображения. | COMBO | Да | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | Интенсивность эталона для загруженных пользователем изображений (по умолчанию: 0.5, расширенная настройка) | FLOAT | Да | 0.0 - 1.0 |
| `human_fidelity` | Сходство с эталоном субъекта (по умолчанию: 0.45, расширенная настройка) | FLOAT | Да | 0.0 - 1.0 |
| `model_name` | Выбор модели для генерации изображений (по умолчанию: "kling-v3") | COMBO | Да | `"kling-v3"` |
| `aspect_ratio` | Соотношение сторон для сгенерированных изображений (по умолчанию: "16:9") | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | Количество генерируемых изображений (по умолчанию: 1) | INT | Да | 1 - 9 |
| `image` | Необязательное эталонное изображение | IMAGE | Нет | - |
| `seed` | Сид управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Нет | 0 - 2147483647 |

**Ограничения параметров:**

- Параметр `image` необязателен. Если эталонное изображение предоставлено, параметр `image_type` определяет, используется ли эталон в качестве эталона субъекта или эталона стиля.
- Если эталонное изображение не предоставлено, настройки, связанные с эталоном (`image_type`, `image_fidelity`, `human_fidelity`), не влияют на результат.
- `prompt` и `negative_prompt` имеют максимальную длину 500 символов.
- Параметр `seed` необязателен и не гарантирует детерминированных результатов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение (изображения) на основе входных параметров. Когда `n` больше 1, несколько изображений возвращаются пакетом. | IMAGE |
