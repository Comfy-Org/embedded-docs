# Генерация изображений Kling

Узел Kling Image Generation генерирует изображения на основе текстовых запросов, с возможностью использования референсного изображения для управления. Он создает одно или несколько изображений на основе вашего текстового описания и настроек референса, затем возвращает сгенерированные изображения в качестве выходных данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Положительный текстовый запрос | STRING | Да | Максимум 500 символов |
| `negative_prompt` | Отрицательный текстовый запрос | STRING | Да | Максимум 500 символов |
| `image_type` | Выбор типа референсного изображения (расширенное). Используется, когда предоставлено референсное изображение. | COMBO | Да | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | Интенсивность референса для изображений, загруженных пользователем (по умолчанию: 0.5, расширенное) | FLOAT | Да | 0.0 - 1.0 |
| `human_fidelity` | Сходство с объектом референса (по умолчанию: 0.45, расширенное) | FLOAT | Да | 0.0 - 1.0 |
| `model_name` | Выбор модели для генерации изображений (по умолчанию: "kling-v3") | COMBO | Да | `"kling-v3"`<br>`"kling-v2"` |
| `aspect_ratio` | Соотношение сторон генерируемых изображений (по умолчанию: "16:9") | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | Количество генерируемых изображений (по умолчанию: 1) | INT | Да | 1 - 9 |
| `image` | Необязательное референсное изображение | IMAGE | Нет | - |
| `seed` | Сид управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Нет | 0 - 2147483647 |

**Ограничения параметров:**

- Параметр `image` является необязательным. Если предоставлено референсное изображение, `image_type` определяет, используется ли оно как референс объекта или референс стиля. Если референсное изображение не предоставлено, `image_type` не применяется.
- `prompt` должен содержать не менее 1 и не более 500 символов. `negative_prompt` может быть пустым, но ограничен 500 символами.
- Параметр `seed` является необязательным и не гарантирует детерминированных результатов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение(я) на основе входных параметров. Если запрошено более одного изображения, все изображения возвращаются объединенными в один пакет (batch). | IMAGE |
