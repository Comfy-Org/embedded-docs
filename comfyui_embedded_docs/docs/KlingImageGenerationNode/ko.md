# Kling 이미지 생성 (텍스트 → 이미지)

Kling 이미지 생성 노드는 텍스트 프롬프트에서 이미지를 생성하며, 참조 이미지를 사용하여 생성 방향을 안내할 수 있는 옵션을 제공합니다. 텍스트 설명과 참조 설정에 따라 하나 이상의 이미지를 생성한 다음, 생성된 이미지를 출력으로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 긍정 텍스트 프롬프트 | STRING | 예 | 최대 500자 |
| `negative_prompt` | 부정 텍스트 프롬프트 | STRING | 예 | 최대 500자 |
| `image_type` | 이미지 참조 유형 선택(고급). 참조 이미지가 제공된 경우 사용됩니다. | COMBO | 예 | `"subject_reference"`<br>`"style_reference"` |
| `image_fidelity` | 사용자 업로드 이미지에 대한 참조 강도(기본값: 0.5, 고급) | FLOAT | 예 | 0.0 - 1.0 |
| `human_fidelity` | 피사체 참조 유사도(기본값: 0.45, 고급) | FLOAT | 예 | 0.0 - 1.0 |
| `model_name` | 이미지 생성 모델 선택(기본값: "kling-v3") | COMBO | 예 | `"kling-v3"`<br>`"kling-v2"` |
| `aspect_ratio` | 생성된 이미지의 종횡비(기본값: "16:9") | COMBO | 예 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `n` | 생성할 이미지 수(기본값: 1) | INT | 예 | 1 - 9 |
| `image` | 선택적 참조 이미지 | IMAGE | 아니오 | - |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니오 | 0 - 2147483647 |

**매개변수 제약 조건:**

- `image` 매개변수는 선택 사항입니다. 참조 이미지가 제공되면 `image_type`은 해당 이미지를 피사체 참조로 사용할지 스타일 참조로 사용할지 결정합니다. 참조 이미지가 제공되지 않으면 `image_type`은 적용되지 않습니다.
- `prompt`는 최소 1자 이상, 최대 500자 이하여야 합니다. `negative_prompt`는 비어 있을 수 있지만 500자로 제한됩니다.
- `seed` 매개변수는 선택 사항이며 결정적 결과를 보장하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `output` | 입력 매개변수를 기반으로 생성된 이미지입니다. 둘 이상의 이미지를 요청한 경우, 모든 이미지가 단일 배치로 쌓여 반환됩니다. | IMAGE |
