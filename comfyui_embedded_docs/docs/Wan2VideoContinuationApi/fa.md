# وان ۲.۷ ادامه ویدیو

گره «ادامه ویدیو Wan 2.7» یک بخش ویدیویی جدید تولید می‌کند که از انتهای کلیپ ویدیویی ورودی ادامه می‌یابد. این گره از مدل Wan 2.7 برای تولید ادامه بر اساس یک متن راهنما استفاده می‌کند و به صورت اختیاری می‌تواند پایان را به سمت یک فریم هدف خاص هدایت کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل تولید ویدیو که باید استفاده شود. | COMBO | بله | `"wan2.7-i2v"` |
| `first_clip` | ویدیوی ورودی که ادامه از آن ساخته می‌شود. مدت‌زمان: ۲ تا ۱۰ ثانیه. نسبت ابعاد خروجی از این ویدیو گرفته می‌شود. | VIDEO | بله | 2 تا 10 ثانیه |
| `last_frame` | تصویر آخرین فریم. ادامه به سمت این فریم انتقال می‌یابد. | IMAGE | خیر | - |
| `seed` | مقدار seed برای تولید. (پیش‌فرض: ۰) | INT | بله | 0 تا 2147483647 |
| `prompt_extend` | آیا متن راهنما با کمک هوش مصنوعی تقویت شود یا خیر. (پیش‌فرض: True) | BOOLEAN | بله | - |
| `watermark` | آیا به نتیجه، واترمارک تولیدشده توسط هوش مصنوعی اضافه شود یا خیر. (پیش‌فرض: False) | BOOLEAN | بله | - |

### ورودی‌های wan2.7-i2v

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.prompt` | متنی که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. (پیش‌فرض: رشته خالی) | STRING | بله | - |
| `model.negative_prompt` | متن منفی (negative prompt) که مواردی را که باید اجتناب شود توصیف می‌کند. (پیش‌فرض: رشته خالی) | STRING | بله | - |
| `model.resolution` | وضوح تصویر برای ویدیوی خروجی. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `model.duration` | مدت‌زمان کل خروجی بر حسب ثانیه. مدل برای پر کردن زمان باقی‌مانده پس از کلیپ ورودی، ادامه تولید می‌کند. (پیش‌فرض: ۵) | INT | بله | 2 تا 15 |

**توجه:** ویدیوی ورودی `first_clip` باید بین ۲ تا ۱۰ ثانیه مدت‌زمان داشته باشد.
