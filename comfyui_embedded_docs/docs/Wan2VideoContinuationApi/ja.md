# Wan 2.7 ビデオ継続生成

Wan 2.7 Video Continuation ノードは、入力ビデオクリップの終端から続く新しいビデオセグメントを生成します。Wan 2.7 モデルを使用してテキストプロンプトに基づく継続部分を合成し、オプションで特定のターゲットフレームに向けて終端を誘導できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するビデオ生成モデル。 | COMBO | はい | `"wan2.7-i2v"` |
| `最初のクリップ` | 継続生成の元となる入力ビデオ。長さ: 2秒～10秒。出力のアスペクト比はこのビデオから取得されます。 | VIDEO | はい | 2〜10 秒 |
| `ラストフレーム` | 最終フレーム画像。継続部分はこのフレームに向かって遷移します。 | IMAGE | いいえ | - |
| `シード値` | 生成に使用するシード値。(デフォルト: 0) | INT | はい | 0〜2147483647 |
| `プロンプト拡張` | AI支援によるプロンプト拡張を行うかどうか。(デフォルト: True) | BOOLEAN | はい | - |
| `ウォーターマーク` | 結果にAI生成ウォーターマークを追加するかどうか。(デフォルト: False) | BOOLEAN | はい | - |

### wan2.7-i2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応。(デフォルト: 空文字列) | STRING | はい | - |
| `ネガティブプロンプト` | 回避すべき内容を説明するネガティブプロンプト。(デフォルト: 空文字列) | STRING | はい | - |
| `解像度` | 出力ビデオの解像度。 | COMBO | はい | `"720P"`<br>`"1080P"` |
| `長さ` | 出力全体の長さ（秒）。モデルは入力クリップの後の残り時間を埋める継続部分を生成します。(デフォルト: 5) | INT | はい | 2〜15 |

**注:** `first_clip` 入力ビデオの長さは2秒以上10秒以下である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成されたビデオ継続部分。 | VIDEO |
