# Wan2VideoContinuationApi

צומת המשך וידאו Wan 2.7 יוצר קטע וידאו חדש שממשיך מסוף קטע וידאו קלט. הוא משתמש במודל Wan 2.7 כדי לסנתז את ההמשך על בסיס פרומפט טקסט, ויכול באופן אופציונלי לכוון את הסיום לעבר פריים יעד מסוים.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל יצירת הווידאו שיש להשתמש בו. האפשרות הנבחרת קובעת אילו הגדרות נוספות יופיעו למטה. | DYNAMIC_COMBO | כן | `"wan2.7-i2v"` |
| `first_clip` | וידאו קלט שממנו ממשיכים. משך: 2s-10s. יחס הגובה-רוחב של הפלט נגזר מהווידאו הזה. | VIDEO | כן | 2s to 10s |
| `last_frame` | תמונת הפריים האחרון. ההמשך יעבור בהדרגה לעבר הפריים הזה. | IMAGE | לא | - |
| `seed` | Seed שיש להשתמש בו ליצירה. (ברירת מחדל: 0) | INT | כן | 0 to 2147483647 |
| `prompt_extend` | האם לשפר את הפרומפט בעזרת בינה מלאכותית. (ברירת מחדל: True) | BOOLEAN | כן | - |
| `watermark` | האם להוסיף סימן מים שנוצר על ידי בינה מלאכותית לתוצאה. (ברירת מחדל: False) | BOOLEAN | כן | - |

### קלטים של wan2.7-i2v

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט המתאר את המרכיבים והמאפיינים החזותיים. תומך באנגלית ובסינית. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `negative_prompt` | פרומפט שלילי המתאר ממה להימנע. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `resolution` | רזולוציית הפלט עבור הווידאו שנוצר. | COMBO | כן | `"720P"`<br>`"1080P"` |
| `duration` | משך הפלט הכולל בשניות. המודל יוצר המשך כדי למלא את הזמן שנותר לאחר קטע הווידאו בקלט. (ברירת מחדל: 5) | INT | כן | 2 to 15 |

**הערה:** וידאו הקלט `first_clip` חייב להיות באורך שבין 2 ל-10 שניות.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | המשך הווידאו שנוצר. | VIDEO |
