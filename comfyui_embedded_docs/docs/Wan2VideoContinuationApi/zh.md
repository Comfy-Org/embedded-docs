# Wan 2.7 视频续写

Wan 2.7 视频续写节点用于从输入视频片段的结尾处生成新的视频片段。它使用 Wan 2.7 模型，根据文本提示词合成后续内容，并可选地将结尾引导至特定的目标帧。

## 输入

### 通用输入

| 参数 | 说明 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的视频生成模型。 | COMBO | 是 | `"wan2.7-i2v"` |
| `first_clip` | 要从中继续生成的输入视频。时长：2 秒至 10 秒。输出视频的长宽比由此视频决定。 | VIDEO | 是 | 2 到 10 秒 |
| `last_frame` | 最后一帧图像。后续内容将向此帧过渡。 | IMAGE | 否 | - |
| `seed` | 用于生成的种子。（默认值：0） | INT | 是 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词。（默认值：True） | BOOLEAN | 是 | - |
| `watermark` | 是否在结果中添加 AI 生成的水印。（默认值：False） | BOOLEAN | 是 | - |

### wan2.7-i2v 输入

| 参数 | 说明 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英文和中文。（默认值：空字符串） | STRING | 是 | - |
| `negative_prompt` | 负面提示词，描述需要避免的内容。（默认值：空字符串） | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br>`"1080P"` |
| `duration` | 总输出时长（秒）。模型生成后续内容以填补输入片段之后的剩余时间。（默认值：5） | INT | 是 | 2 到 15 |
