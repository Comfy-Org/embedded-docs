# Wan 2.7 Продолжение видео

Узел Wan 2.7 Video Continuation генерирует новый видеофрагмент, который продолжает конец входного видеоклипа. Он использует модель Wan 2.7 для синтеза продолжения на основе текстового промпта и при необходимости может направлять завершение к заданному целевому кадру.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель генерации видео для использования. | COMBO | Да | `"wan2.7-i2v"` |
| `first_clip` | Входное видео для продолжения. Длительность: 2–10 секунд. Соотношение сторон выходного видео определяется этим видео. | VIDEO | Да | от 2 до 10 секунд |
| `last_frame` | Изображение последнего кадра. Продолжение будет плавно переходить к этому кадру. | IMAGE | Нет | - |
| `seed` | Сид для генерации. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `prompt_extend` | Нужно ли улучшать промпт с помощью ИИ. (по умолчанию: True) | BOOLEAN | Да | - |
| `watermark` | Нужно ли добавлять водяной знак, созданный ИИ, к результату. (по умолчанию: False) | BOOLEAN | Да | - |

### Входы wan2.7-i2v

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model.prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. (по умолчанию: пустая строка) | STRING | Да | - |
| `model.negative_prompt` | Негативный промпт, описывающий, чего следует избегать. (по умолчанию: пустая строка) | STRING | Да | - |
| `model.resolution` | Разрешение выходного видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `model.duration` | Общая длительность выходного видео в секундах. Модель генерирует продолжение для заполнения оставшегося времени после входного клипа. (по умолчанию: 5) | INT | Да | от 2 до 15 |

**Примечание:** Входное видео `first_clip` должно иметь длительность от 2 до 10 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное продолжение видео. | VIDEO |
