# 삼중 CLIP 로드

TripleCLIPLoader 노드는 세 개의 텍스트 인코더 모델을 동시에 로드하여 단일 CLIP 모델로 결합합니다. 이는 여러 텍스트 인코더가 필요한 고급 텍스트 인코딩 시나리오에서 유용하며, clip-l, clip-g 및 t5 모델이 함께 작동해야 하는 SD3 워크플로우와 같은 경우에 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip_name1` | 사용 가능한 텍스트 인코더 중에서 로드할 첫 번째 텍스트 인코더 모델 | COMBO | 예 | text_encoders 폴더의 모든 텍스트 인코더 파일 |
| `clip_name2` | 사용 가능한 텍스트 인코더 중에서 로드할 두 번째 텍스트 인코더 모델 | COMBO | 예 | text_encoders 폴더의 모든 텍스트 인코더 파일 |
| `clip_name3` | 사용 가능한 텍스트 인코더 중에서 로드할 세 번째 텍스트 인코더 모델 | COMBO | 예 | text_encoders 폴더의 모든 텍스트 인코더 파일 |

**참고:** 세 개의 텍스트 인코더 매개변수는 시스템에서 사용 가능한 텍스트 인코더 모델 중에서 선택해야 합니다. 이 노드는 지정된 순서대로 세 개의 모델을 로드하고 이를 단일 CLIP 모델로 결합하여 처리합니다. SD3 워크플로우의 경우 clip-l, clip-g 및 t5를 세 개의 인코더로 사용하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-----------|-------------|-----------|
| `CLIP` | 로드된 세 개의 텍스트 인코더를 모두 포함하는 결합된 CLIP 모델 | CLIP |
