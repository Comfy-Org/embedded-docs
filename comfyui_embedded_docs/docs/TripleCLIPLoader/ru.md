# Тройной загрузчик CLIP

TripleCLIPLoader загружает три модели текстовых энкодеров одновременно и объединяет их в единую модель CLIP. Он используется для рабочих процессов, в которых требуется несколько текстовых энкодеров, работающих вместе, например SD3, где используются модели clip-l, clip-g и t5.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_name1` | Первая модель текстового энкодера, загружаемая из доступных текстовых энкодеров | COMBO | Да | Доступно несколько вариантов (все файлы в папке text_encoders) |
| `clip_name2` | Вторая модель текстового энкодера, загружаемая из доступных текстовых энкодеров | COMBO | Да | Доступно несколько вариантов (все файлы в папке text_encoders) |
| `clip_name3` | Третья модель текстового энкодера, загружаемая из доступных текстовых энкодеров | COMBO | Да | Доступно несколько вариантов (все файлы в папке text_encoders) |

**Примечание:** Все три параметра обязательны. Доступные варианты — это файлы текстовых энкодеров в вашей папке text_encoders. Если выбранный файл не найден, узел выдаёт ошибку. Узел загружает все три выбранные модели и объединяет их в единую модель CLIP.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CLIP` | Объединённая модель CLIP, содержащая все три загруженных текстовых энкодера | CLIP |
