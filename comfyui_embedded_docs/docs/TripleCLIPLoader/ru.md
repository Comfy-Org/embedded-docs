# Тройной загрузчик CLIP

Узел TripleCLIPLoader загружает три модели текстовых кодировщиков одновременно и объединяет их в одну модель CLIP. Это полезно для расширенных сценариев кодирования текста, где требуется несколько текстовых кодировщиков, например, в рабочих процессах SD3, где модели clip-l, clip-g и t5 должны работать вместе.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_name1` | Первая модель текстового кодировщика для загрузки из доступных текстовых кодировщиков | COMBO | Да | Все файлы текстовых кодировщиков в папке text_encoders |
| `clip_name2` | Вторая модель текстового кодировщика для загрузки из доступных текстовых кодировщиков | COMBO | Да | Все файлы текстовых кодировщиков в папке text_encoders |
| `clip_name3` | Третья модель текстового кодировщика для загрузки из доступных текстовых кодировщиков | COMBO | Да | Все файлы текстовых кодировщиков в папке text_encoders |

**Примечание:** Все три параметра текстовых кодировщиков должны быть выбраны из доступных моделей текстовых кодировщиков в вашей системе. Узел загружает все три модели в заданном порядке и объединяет их в одну модель CLIP для обработки. Для рабочих процессов SD3 используйте clip-l, clip-g и t5 в качестве трех кодировщиков.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-----------|-------------|-----------|
| `CLIP` | Объединенная модель CLIP, содержащая все три загруженных текстовых кодировщика | CLIP |
