# RemoveBackground

## סקירה כללית

הצומת Remove Background יוצר מסכת חזית שמפרידה בין הנושא הראשי לרקע של תמונת קלט. הוא משתמש במודל להסרת רקע כדי לנתח את התמונה ולהפיק מסכה שמדגישה את מרכיבי החזית.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `bg_removal_model` | מודל להסרת רקע המשמש ליצירת המסכה | BACKGROUND_REMOVAL_MODEL | כן | N/A |
| `image` | תמונת קלט שממנה יש להסיר את הרקע | IMAGE | כן | N/A |

## פלטים

| שם פלט | תיאור | סוג נתונים |
