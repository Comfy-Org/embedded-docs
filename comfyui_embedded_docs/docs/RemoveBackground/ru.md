# Удалить фон

## Обзор

Узел Remove Background создает маску переднего плана, которая отделяет основной объект от фона входного изображения. Он использует модель удаления фона для анализа изображения и создания маски, выделяющей элементы переднего плана.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `bg_removal_model` | Модель удаления фона, используемая для создания маски | BACKGROUND_REMOVAL_MODEL | Да | N/A |
| `изображение` | Входное изображение, из которого нужно удалить фон | IMAGE | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mask` | Созданная маска переднего плана | MASK |
