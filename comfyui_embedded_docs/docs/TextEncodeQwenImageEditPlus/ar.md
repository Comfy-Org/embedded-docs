# TextEncodeQwenImageEditPlus

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم في تقطيع النص وتشفيره | CLIP | نعم | - |
| `prompt` | تعليمة نصية تصف التعديل المطلوب على الصورة (تدعم الإدخال متعدد الأسطر والمطالبات الديناميكية) | STRING | نعم | - |
| `vae` | نموذج VAE اختياري لتوليد الكمونات المرجعية من الصور المدخلة | VAE | لا | - |
| `image1` | الصورة الاختيارية الأولى للتحليل والتعديل | IMAGE | لا | - |
| `image2` | الصورة الاختيارية الثانية للتحليل والتعديل | IMAGE | لا | - |
| `image3` | الصورة الاختيارية الثالثة للتحليل والتعديل | IMAGE | لا | - |

**ملاحظة:** عند توفير VAE، تقوم العقدة بتوليد الكمونات المرجعية من جميع الصور المدخلة. يمكن للعقدة معالجة ما يصل إلى ثلاث صور في وقت واحد. يتم تحجيم الصور تلقائيًا إلى مساحة مستهدفة تبلغ حوالي 384×384 بكسل (مع الحفاظ على نسبة الأبعاد) لمعالجة الرؤية واللغة، وإلى أبعاد قابلة للقسمة على 8 بمساحة مستهدفة تبلغ حوالي 1024×1024 بكسل لتشفير VAE.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
