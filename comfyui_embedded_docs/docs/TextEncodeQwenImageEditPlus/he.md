# קידוד טקסט Qwen Image Edit Plus

צומת TextEncodeQwenImageEditPlus מעבד `prompt` טקסטואלי ועד שלוש תמונות אופציונליות כדי להפיק נתוני conditioning למשימות יצירת תמונה או עריכה. הוא משתמש בתבנית ייעודית שמבקשת תחילה מהמודל לתאר את המאפיינים העיקריים של תמונות הקלט, ולאחר מכן להסביר כיצד הוראת הטקסט של המשתמש אמורה לשנות אותן, כך שהתוצאה המקודדת מבינה גם את התמונות וגם את השינוי המבוקש. כאשר מסופק VAE, הצומת יוצר גם latent-ים של ייחוס מתמונות הקלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל CLIP המשמש לטוקניזציה ולקידוד | CLIP | כן | - |
| `prompt` | הוראת טקסט המתארת את שינוי התמונה הרצוי (תומך בקלט מרובה שורות ובפרומפטים דינמיים) | STRING | כן | - |
| `vae` | מודל VAE אופציונלי ליצירת latent-ים של ייחוס מתמונות הקלט | VAE | לא | - |
| `image1` | תמונת הקלט האופציונלית הראשונה לניתוח ולשינוי | IMAGE | לא | - |
| `image2` | תמונת הקלט האופציונלית השנייה לניתוח ולשינוי | IMAGE | לא | - |
| `image3` | תמונת הקלט האופציונלית השלישית לניתוח ולשינוי | IMAGE | לא | - |

**הערה:** כאשר מסופק VAE, הצומת יוצר latent-ים של ייחוס מכל תמונות הקלט שסופקו. ניתן לעבד עד שלוש תמונות בבת אחת. התמונות מותאמות לגודל אזור יעד של 384x384 פיקסלים (יחס גובה-רוחב נשמר) לעיבוד חזותי-לשוני, ולממדים המתחלקים ב-8 (עם אזור יעד של 1024x1024 פיקסלים) לקידוד VAE.
