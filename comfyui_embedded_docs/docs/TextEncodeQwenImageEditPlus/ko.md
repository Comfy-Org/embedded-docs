# TextEncodeQwenImageEditPlus

TextEncodeQwenImageEditPlus 노드는 텍스트 프롬프트와 선택적 이미지를 처리하여 이미지 생성 또는 편집 작업을 위한 컨디셔닝 데이터를 생성합니다. 이 노드는 특수 템플릿을 사용하여 입력 이미지를 분석하고 텍스트 지침에 따라 이미지를 어떻게 수정해야 하는지 이해한 다음, 이 정보를 인코딩하여 후속 생성 단계에서 사용할 수 있도록 합니다. 이 노드는 최대 3개의 입력 이미지를 처리할 수 있으며, VAE가 제공되면 선택적으로 참조 잠상을 생성할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 토큰화 및 인코딩에 사용되는 CLIP 모델 | CLIP | 예 | - |
| `prompt` | 원하는 이미지 수정을 설명하는 텍스트 지침(여러 줄 입력 및 동적 프롬프트 지원) | STRING | 예 | - |
| `vae` | 입력 이미지에서 참조 잠상을 생성하기 위한 선택적 VAE 모델 | VAE | 아니요 | - |
| `image1` | 분석 및 수정을 위한 첫 번째 선택적 입력 이미지 | IMAGE | 아니요 | - |
| `image2` | 분석 및 수정을 위한 두 번째 선택적 입력 이미지 | IMAGE | 아니요 | - |
| `image3` | 분석 및 수정을 위한 세 번째 선택적 입력 이미지 | IMAGE | 아니요 | - |

**참고:** VAE가 제공되면 노드는 모든 입력 이미지에서 참조 잠상을 생성합니다. 노드는 최대 3개의 이미지를 동시에 처리할 수 있습니다. 이미지는 비전-언어 처리를 위해 약 384×384픽셀의 대상 면적(종횡비 유지)으로 자동 크기가 조정되며, VAE 인코딩을 위해 약 1024×1024픽셀의 대상 면적으로 8의 배수 크기에 맞춰 자동 조정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CONDITIONING` | 이미지 생성을 위한 텍스트 토큰과 선택적 참조 잠상을 포함하는 인코딩된 컨디셔닝 데이터 | CONDITIONING |
