# TextEncodeQwenImageEditPlus

TextEncodeQwenImageEditPlus ノードは、テキストプロンプトとオプションの画像を処理して、画像生成または編集タスク用のコンディショニングデータを生成します。専用のテンプレートを使用して入力画像を分析し、テキスト指示が画像をどのように変更すべきかを理解した上で、この情報を後続の生成ステップで使用できるようエンコードします。このノードは最大3つの入力画像を処理でき、VAEが提供された場合はオプションで参照用ラテントを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | トークン化とエンコードに使用されるCLIPモデル | CLIP | 必須 | - |
| `prompt` | 望ましい画像変更を説明するテキスト指示（複数行入力と動的プロンプトに対応） | STRING | 必須 | - |
| `vae` | 入力画像から参照ラテントを生成するためのオプションのVAEモデル | VAE | 任意 | - |
| `image1` | 分析と変更のための1つ目のオプション入力画像 | IMAGE | 任意 | - |
| `image2` | 分析と変更のための2つ目のオプション入力画像 | IMAGE | 任意 | - |
| `image3` | 分析と変更のための3つ目のオプション入力画像 | IMAGE | 任意 | - |

**注記:** VAEが指定された場合、ノードはすべての入力画像から参照ラテントを生成します。ノードは最大3つの画像を同時に処理できます。画像は、視覚言語処理のためにターゲット面積約384×384ピクセル（アスペクト比は維持）に自動スケーリングされ、VAEエンコードのためにはターゲット面積約1024×1024ピクセルで8で割り切れる寸法にスケーリングされます。

## 出力
