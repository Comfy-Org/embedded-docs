# TextEncodeQwenImageEditPlus

گره TextEncodeQwenImageEditPlus متن‌های ورودی و تصاویر اختیاری را پردازش می‌کند تا داده‌های شرط‌سازی برای کارهای تولید یا ویرایش تصویر تولید کند. این گره از یک الگوی تخصصی برای تحلیل تصاویر ورودی و درک نحوه اعمال دستورات متنی بر آن‌ها استفاده می‌کند، سپس این اطلاعات را برای استفاده در مراحل بعدی تولید رمزگذاری می‌کند. این گره می‌تواند تا سه تصویر ورودی را مدیریت کند و در صورت ارائه VAE، به‌صورت اختیاری لاتنت‌های مرجع تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |
| `پرامپت` | دستورالعمل متنی توصیف‌کننده تغییر تصویر مورد نظر (پشتیبانی از ورودی چندخطی و پرامپت‌های پویا) | STRING | بله | - |
| `vae` | مدل VAE اختیاری برای تولید لاتنت‌های مرجع از تصاویر ورودی | VAE | خیر | - |
| `تصویر ۱` | اولین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |
| `تصویر ۲` | دومین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |
| `تصویر ۳` | سومین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |

**نکته:** وقتی VAE ارائه شود، گره از تمام تصاویر ورودی ارائه‌شده، لاتنت‌های مرجع تولید می‌کند. حداکثر سه تصویر می‌توانند همزمان پردازش شوند. تصاویر برای پردازش زبان-تصویر به مساحت هدف ۳۸۴×۳۸۴ پیکسل (با حفظ نسبت ابعاد) و برای رمزگذاری VAE به ابعادی که بر ۸ بخش‌پذیرند (با مساحت هدف ۱۰۲۴×۱۰۲۴ پیکسل) مقیاس‌دهی می‌شوند.
