# TextEncodeQwenImageEditPlus

گره TextEncodeQwenImageEditPlus یک پرامپت متنی و حداکثر سه تصویر اختیاری را پردازش می‌کند تا داده‌های شرطی‌سازی برای وظایف تولید یا ویرایش تصویر تولید کند. این گره از یک قالب تخصصی استفاده می‌کند که ابتدا از مدل می‌خواهد ویژگی‌های کلیدی تصاویر ورودی را توصیف کند و سپس توضیح دهد که دستور متنی کاربر باید چگونه آن‌ها را تغییر دهد؛ به این ترتیب نتیجه رمزگذاری‌شده هم تصاویر و هم تغییر درخواستی را درک می‌کند. هنگامی که یک VAE ارائه شود، گره همچنین latentهای مرجع را از تصاویر ورودی ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |
| `prompt` | دستور متنی که تغییر دلخواه تصویر را توصیف می‌کند (از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند) | STRING | بله | - |
| `vae` | مدل VAE اختیاری برای تولید latentهای مرجع از تصاویر ورودی | VAE | خیر | - |
| `image1` | اولین تصویر ورودی اختیاری برای تحلیل و تغییر | IMAGE | خیر | - |
| `image2` | دومین تصویر ورودی اختیاری برای تحلیل و تغییر | IMAGE | خیر | - |
| `image3` | سومین تصویر ورودی اختیاری برای تحلیل و تغییر | IMAGE | خیر | - |

**توجه:** هنگامی که یک VAE ارائه شود، گره از همه تصاویر ورودی ارائه‌شده latentهای مرجع تولید می‌کند. حداکثر سه تصویر را می‌توان همزمان پردازش کرد. تصاویر برای پردازش بینایی-زبانی به مساحت هدف 384x384 پیکسل (با حفظ نسبت ابعاد) و برای رمزگذاری VAE به ابعاد بخش‌پذیر بر 8 (با مساحت هدف 1024x1024 پیکسل) مقیاس می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی‌سازی رمزگذاری‌شده شامل توکن‌های متنی و latentهای مرجع اختیاری برای تولید تصویر | CONDITIONING |
