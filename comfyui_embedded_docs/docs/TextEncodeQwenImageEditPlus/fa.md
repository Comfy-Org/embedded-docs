# TextEncodeQwenImageEditPlus

گره `TextEncodeQwenImageEditPlus` متن راهنما و تصاویر اختیاری را پردازش می‌کند تا داده‌های شرطی (conditioning) برای کارهای تولید یا ویرایش تصویر ایجاد کند. این گره از یک الگوی تخصصی برای تحلیل تصاویر ورودی و درک نحوهٔ اصلاح آن‌ها توسط دستورات متنی استفاده می‌کند و سپس این اطلاعات را برای مراحل بعدی تولید، رمزگذاری می‌کند. این گره می‌تواند حداکثر سه تصویر ورودی را مدیریت کند و در صورت ارائهٔ VAE، به‌صورت اختیاری لاتنت‌های مرجع (reference latents) تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |
| `prompt` | دستور متنی که تغییر موردنظر در تصویر را توصیف می‌کند (پشتیبانی از ورودی چندخطی و پرامپت پویا) | STRING | بله | - |
| `vae` | مدل VAE اختیاری برای تولید لاتنت‌های مرجع از تصاویر ورودی | VAE | خیر | - |
| `image1` | اولین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |
| `image2` | دومین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |
| `image3` | سومین تصویر ورودی اختیاری برای تحلیل و اصلاح | IMAGE | خیر | - |

**نکته:** وقتی VAE ارائه می‌شود، گره از تمام تصاویر ورودی لاتنت‌های مرجع تولید می‌کند. این گره می‌تواند همزمان تا سه تصویر را پردازش کند. تصاویر به‌صورت خودکار برای پردازش بینایی-زبانی به مساحتی تقریباً ۳۸۴×۳۸۴ پیکسل (با حفظ نسبت ابعاد) و برای رمزگذاری VAE به ابعادی که بر ۸ بخش‌پذیر است و مساحتی تقریباً ۱۰۲۴×۱۰۲۴ پیکسل دارد، مقیاس‌دهی می‌شوند.
