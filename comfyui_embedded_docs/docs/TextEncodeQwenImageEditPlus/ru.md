# TextEncodeQwenImageEditPlus

Узел `TextEncodeQwenImageEditPlus` обрабатывает текстовые промпты и дополнительные изображения для создания данных кондиционирования для задач генерации или редактирования изображений. Он использует специализированный шаблон для анализа входных изображений и понимания того, как текстовые инструкции должны их изменить, а затем кодирует эту информацию для использования на последующих этапах генерации. Узел может обрабатывать до трех входных изображений и при необходимости создавать референсные латентные представления при наличии VAE.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Да | - |
| `prompt` | Текстовая инструкция, описывающая желаемое изменение изображения (поддерживает многострочный ввод и динамические промпты) | STRING | Да | - |
| `vae` | Необязательная модель VAE для генерации референсных латентных представлений из входных изображений | VAE | Нет | - |
| `image1` | Первое необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |
| `image2` | Второе необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |
| `image3` | Третье необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |

**Примечание:** Если указан VAE, узел генерирует референсные латентные представления из всех входных изображений. Узел может обрабатывать до трех изображений одновременно. Изображения автоматически масштабируются до целевой области примерно 384×384 пикселя (с сохранением соотношения сторон) для визуально-языковой обработки, а для кодирования VAE — до размеров, кратных 8, с целевой областью примерно 1024×1024 пикселя.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированные данные кондиционирования, содержащие текстовые токены и необязательные референсные латентные представления для генерации изображений | CONDITIONING |
