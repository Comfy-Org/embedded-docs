# TextEncodeQwenImageEditPlus

Узел TextEncodeQwenImageEditPlus обрабатывает текстовые подсказки и необязательные изображения для создания данных conditioning для задач генерации или редактирования изображений. Он использует специализированный шаблон для анализа входных изображений и понимания того, как текстовые инструкции должны их изменять, а затем кодирует эту информацию для использования в последующих шагах генерации. Узел может обрабатывать до трех входных изображений и при необходимости генерировать эталонные скрытые представления, если предоставлена VAE.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Да | - |
| `промпт` | Текстовая инструкция, описывающая желаемое изменение изображения (поддерживает многострочный ввод и динамические подсказки) | STRING | Да | - |
| `vae` | Необязательная модель VAE для генерации эталонных скрытых представлений из входных изображений | VAE | Нет | - |
| `изображение1` | Первое необязательное входное изображение для анализа и модификации | IMAGE | Нет | - |
| `изображение2` | Второе необязательное входное изображение для анализа и модификации | IMAGE | Нет | - |
| `изображение3` | Третье необязательное входное изображение для анализа и модификации | IMAGE | Нет | - |

**Примечание:** При наличии VAE узел генерирует эталонные скрытые представления из всех предоставленных входных изображений. Одновременно можно обработать до трех изображений. Изображения масштабируются до целевой области 384×384 пикселя (с сохранением соотношения сторон) для визуально-языковой обработки, и до размеров, кратных 8 (с целевой областью 1024×1024 пикселя) для кодирования VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированные данные conditioning, содержащие текстовые токены и необязательные эталонные скрытые представления для генерации изображений | CONDITIONING |
