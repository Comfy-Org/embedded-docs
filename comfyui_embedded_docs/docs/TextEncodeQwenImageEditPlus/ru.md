# TextEncodeQwenImageEditPlus

Узел TextEncodeQwenImageEditPlus обрабатывает текстовый промпт и до трёх необязательных изображений, чтобы создать данные кондиционирования для задач генерации или редактирования изображений. Он использует специализированный шаблон, который сначала просит модель описать ключевые особенности входных изображений, а затем объяснить, как текстовая инструкция пользователя должна их изменить, чтобы закодированный результат учитывал как изображения, так и запрошенное изменение. Если предоставлен VAE, узел также создаёт эталонные латенты из входных изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Да | - |
| `промпт` | Текстовая инструкция, описывающая желаемое изменение изображения (поддерживает многострочный ввод и динамические промпты) | STRING | Да | - |
| `vae` | Необязательная модель VAE для генерации эталонных латентов из входных изображений | VAE | Нет | - |
| `изображение1` | Первое необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |
| `изображение2` | Второе необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |
| `изображение3` | Третье необязательное входное изображение для анализа и изменения | IMAGE | Нет | - |

**Примечание:** Когда предоставлен VAE, узел генерирует эталонные латенты из всех предоставленных входных изображений. Одновременно можно обработать до трёх изображений. Изображения масштабируются до целевой области 384x384 пикселей (с сохранением пропорций) для визуально-языковой обработки и до размеров, кратных 8 (с целевой областью 1024x1024 пикселей), для кодирования VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированные данные кондиционирования, содержащие текстовые токены и необязательные эталонные латенты для генерации изображений | CONDITIONING |
