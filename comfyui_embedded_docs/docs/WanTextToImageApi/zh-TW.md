# 萬文字轉圖像

Wan Text to Image 節點會根據文字描述生成圖像。它使用 AI 模型從文字提示建立視覺內容，支援英文與中文文字輸入。此節點提供多種控制項，可調整輸出圖像的尺寸、品質與風格偏好。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的模型（預設："wan2.5-t2i-preview"） | STRING | 是 | "wan2.5-t2i-preview" |
| `提示詞` | 描述元素與視覺特徵的提示詞。支援英文與中文（預設：空） | STRING | 是 | - |
| `負面提示詞` | 描述要避免內容的負向提示詞（預設：空） | STRING | 否 | - |
| `寬度` | 圖像寬度（像素）（預設：1024，步長：32） | INT | 否 | 768-1440 |
| `高度` | 圖像高度（像素）（預設：1024，步長：32） | INT | 否 | 768-1440 |
| `種子值` | 用於生成的種子（預設：0） | INT | 否 | 0-2147483647 |
| `提示詞擴展` | 是否使用 AI 輔助增強提示詞（預設：True） | BOOLEAN | 否 | - |
| `浮水印` | 是否在結果中加入 AI 生成浮水印（預設：False） | BOOLEAN | 否 | - |

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 根據文字提示生成的圖像 | IMAGE |
