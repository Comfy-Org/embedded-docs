# Wan Текст в изображение

Узел Wan Text to Image генерирует изображения на основе текстовых описаний. Он использует модели ИИ для создания визуального контента по текстовым промптам, поддерживая ввод текста как на английском, так и на китайском языке. Узел предоставляет различные элементы управления для настройки размера выходного изображения, качества и предпочтений по стилю.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель (по умолчанию: "wan2.5-t2i-preview") | STRING | Да | "wan2.5-t2i-preview" |
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки (по умолчанию: пусто) | STRING | Да | - |
| `negative_prompt` | Негативный промпт, описывающий, чего следует избегать (по умолчанию: пусто) | STRING | Нет | - |
| `width` | Ширина изображения в пикселях (по умолчанию: 1024, шаг: 32) | INT | Нет | 768-1440 |
| `height` | Высота изображения в пикселях (по умолчанию: 1024, шаг: 32) | INT | Нет | 768-1440 |
| `seed` | Сид, используемый для генерации (по умолчанию: 0) | INT | Нет | 0-2147483647 |
| `prompt_extend` | Улучшать ли промпт с помощью ИИ (по умолчанию: True) | BOOLEAN | Нет | - |
| `watermark` | Добавлять ли сгенерированный ИИ водяной знак к результату (по умолчанию: False) | BOOLEAN | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение на основе текстового промпта | IMAGE |
