# وان تبدیل متن به تصویر

گره Wan Text to Image تصاویر را بر اساس توصیف‌های متنی تولید می‌کند. این گره از مدل‌های هوش مصنوعی برای ساخت محتوای بصری از پرامپت‌های نوشته‌شده استفاده می‌کند و از ورودی متن انگلیسی و چینی پشتیبانی می‌کند. این گره کنترل‌های متنوعی برای تنظیم اندازه، کیفیت و ترجیحات سبک تصویر خروجی فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده (پیش‌فرض: "wan2.5-t2i-preview") | STRING | بله | "wan2.5-t2i-preview" |
| `پرامپت` | پرامپت توصیف‌کننده عناصر و ویژگی‌های بصری. از انگلیسی و چینی پشتیبانی می‌کند (پیش‌فرض: خالی) | STRING | بله | - |
| `پرامپت منفی` | پرامپت منفی که مواردی را که باید از آن‌ها پرهیز شود توصیف می‌کند (پیش‌فرض: خالی) | STRING | خیر | - |
| `عرض` | عرض تصویر بر حسب پیکسل (پیش‌فرض: 1024، گام: 32) | INT | خیر | 768-1440 |
| `ارتفاع` | ارتفاع تصویر بر حسب پیکسل (پیش‌فرض: 1024، گام: 32) | INT | خیر | 768-1440 |
| `بذر` | مقدار seed مورد استفاده برای تولید (پیش‌فرض: 0) | INT | خیر | 0-2147483647 |
| `افزایش پرامپت` | اینکه آیا پرامپت با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `واترمارک` | اینکه آیا یک واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: False) | BOOLEAN | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر تولیدشده بر اساس پرامپت متنی | IMAGE |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/WanTextToImageApi/fa.md)
