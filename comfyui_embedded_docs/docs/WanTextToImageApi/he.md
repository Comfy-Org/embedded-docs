# WanTextToImageApi

הצומת Wan Text to Image יוצר תמונות על בסיס תיאורי טקסט. הוא משתמש במודלי בינה מלאכותית כדי ליצור תוכן חזותי מהנחיות כתובות, ותומך בקלט טקסט באנגלית ובסינית. הצומת מספק פקדים שונים להתאמת גודל תמונת הפלט, האיכות והעדפות הסגנון.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש (ברירת מחדל: "wan2.5-t2i-preview") | STRING | כן | "wan2.5-t2i-preview" |
| `prompt` | הנחיה המתארת את האלמנטים והמאפיינים החזותיים. תומכת באנגלית ובסינית (ברירת מחדל: ריק) | STRING | כן | - |
| `negative_prompt` | הנחיה שלילית המתארת ממה להימנע (ברירת מחדל: ריק) | STRING | לא | - |
| `width` | רוחב התמונה בפיקסלים (ברירת מחדל: 1024, צעד: 32) | INT | לא | 768-1440 |
| `height` | גובה התמונה בפיקסלים (ברירת מחדל: 1024, צעד: 32) | INT | לא | 768-1440 |
| `seed` | Seed לשימוש ביצירה (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `prompt_extend` | האם לשפר את ההנחיה בעזרת בינה מלאכותית (ברירת מחדל: True) | BOOLEAN | לא | - |
| `watermark` | האם להוסיף סימן מים שנוצר בבינה מלאכותית לתוצאה (ברירת מחדל: False) | BOOLEAN | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | התמונה שנוצרה על בסיס הנחיית הטקסט | IMAGE |
