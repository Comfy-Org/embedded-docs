# وان من النص إلى الصورة

تُنشئ عقدة Wan Text to Image الصور بناءً على الأوصاف النصية. تستخدم نماذج الذكاء الاصطناعي لإنشاء محتوى مرئي من المطالبات المكتوبة، وتدعم إدخال النصوص باللغتين الإنجليزية والصينية. توفر العقدة عناصر تحكم متنوعة لضبط حجم الصورة الناتجة وجودتها وتفضيلات النمط.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `نموذج` | النموذج المراد استخدامه (الافتراضي: "wan2.5-t2i-preview") | STRING | نعم | "wan2.5-t2i-preview" |
| `نص موجه` | المطالبة التي تصف العناصر والسمات المرئية. تدعم الإنجليزية والصينية (الافتراضي: فارغ) | STRING | نعم | - |
| `نص موجه سلبي` | مطالبة سلبية تصف ما يجب تجنبه (الافتراضي: فارغ) | STRING | لا | - |
| `العرض` | عرض الصورة بالبكسل (الافتراضي: 1024، الخطوة: 32) | INT | لا | 768-1440 |
| `الارتفاع` | ارتفاع الصورة بالبكسل (الافتراضي: 1024، الخطوة: 32) | INT | لا | 768-1440 |
| `بذرة` | البذرة المراد استخدامها للتوليد (الافتراضي: 0) | INT | لا | 0-2147483647 |
| `توسيع النص الموجه` | ما إذا كان سيتم تحسين المطالبة بمساعدة الذكاء الاصطناعي (الافتراضي: True) | BOOLEAN | لا | - |
| `علامة مائية` | ما إذا كانت إضافة علامة مائية مولّدة بالذكاء الاصطناعي إلى النتيجة (الافتراضي: False) | BOOLEAN | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الصورة المولّدة بناءً على المطالبة النصية | IMAGE |
