# Google Gemini Decision (Choice)

בחרו אחת מהאפשרויות שלכם עבור הטקסט, התמונות, השמע או הווידאו שאתם מחברים, וקבלו בחזרה את האפשרות שנבחרה, את מיקומה ואת רמת הביטחון. חברו את `choice` לצומת Branch שכניסותיה נושאות את אותם שמות אפשרויות, או נתבו לפי `option_index`. צומת Branch מקבל לכל היותר 32 קלטים, לכן נתבו קבוצות אפשרויות גדולות יותר באמצעות `option_index`.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש (ברירת מחדל: `"gemini-decision-1"`). | COMBO | כן | `"gemini-decision-1"` |
| `question` | השאלה שהאפשרויות עונות עליה, עד 5000 תווים (ברירת מחדל: "What style is the image?"). | STRING | כן | 1 עד 5000 תווים |
| `options` | אפשרות אחת בכל שורה, בשימוש בדיוק כפי שהוקלדה, עד 128 תווים לכל אחת. הוסיפו אפשרות כגון `other` לקלטים שאינם מתאימים לאף אחת מהן (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | כן | 2 עד 255 אפשרויות |
| `images` | תמונות לסיווג, עד 16 בסך הכול לאורך החריצים הניתנים להרחבה (`image_1` ... `image_16`). תמונה שנשלחת באצווה נספרת פעם אחת לכל תמונה. | IMAGE | לא | עד 16 תמונות |
| `audio` | קטע שמע לסיווג. | AUDIO | לא | - |
| `video` | קטע וידאו לסיווג. | VIDEO | לא | - |
| `text` | טקסט שהשאלה עוסקת בו, כגון פרומפט או תגובה של LLM, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

ספקו לפחות 2 ולכל היותר 255 אפשרויות, ואל תפרטו אף אחת מהן פעמיים; אחרת הצומת יזרוק שגיאה. חברו לפחות אחד מהקלטים `text`, `images`, `audio` או `video`, ותנו שמות למספר תמונות `image_1`, `image_2` וכן הלאה בתוך השאלה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `choice` | האפשרות שנבחרה, בדיוק כפי שנכתבה ב-`options`. | STRING |
| `option_index` | מיקום האפשרות שנבחרה ב-`options`, החל מ-0. | INT |
| `confidence` | רמת הביטחון בבחירה, בין 0 ל-1. | FLOAT |
