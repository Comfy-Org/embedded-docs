# Google Gemini Decision (Choice)

בחר אחת מהאפשרויות שלך עבור הטקסט, התמונות, השמע או הווידאו שאתה מחבר, וקבל בחזרה את האפשרות שנבחרה, את מיקומה ורמת ביטחון. חבר את `choice` לצומת Branch שכניסותיו משתמשות באותם שמות אפשרויות, או נתב לפי `option_index` כאשר צומת Branch אינו זמין.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל שבו יש להשתמש (ברירת מחדל: `"gemini-decision-1"`). | COMBO | כן | `"gemini-decision-1"` |
| `question` | השאלה שהאפשרויות עונות עליה, עד 5000 תווים (ברירת מחדל: "What style is the image?"). | STRING | כן | 1 עד 5000 תווים |
| `options` | אפשרות אחת בכל שורה, בשימוש בדיוק כפי שהוקלדה, עד 128 תווים לכל אחת. הוסף אפשרות כגון `other` עבור קלטים שאינם מתאימים לאף אחת מהן (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | כן | 2 עד 255 אפשרויות |
| `images` | תמונות לסיווג, עד 16 לאורך החריצים הניתנים להרחבה (`image_1` ... `image_16`). תמונה באצווה נספרת פעם אחת עבור כל תמונה. | IMAGE | לא | עד 16 תמונות |
| `audio` | קטע שמע לסיווג. | AUDIO | לא | - |
| `video` | קטע וידאו לסיווג. | VIDEO | לא | - |
| `text` | טקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

ספק לפחות 2 אפשרויות ולכל היותר 255 אפשרויות, ואל תציין אף אחת מהן פעמיים; אחרת הצומת תעלה שגיאה. חבר לפחות אחד מ-`text`, `images`, `audio` או `video`, ותן שמות למספר תמונות כ-`image_1`, `image_2` וכן הלאה בתוך השאלה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `choice` | האפשרות שנבחרה, בדיוק כפי שנכתבה ב-`options`. | STRING |
| `option_index` | מיקום האפשרות שנבחרה ב-`options`, החל מ-0. | INT |
| `confidence` | רמת הביטחון בבחירה, בין 0 ל-1. | FLOAT |
