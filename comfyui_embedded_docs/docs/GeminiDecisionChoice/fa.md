# Google Gemini Decision (Choice)

یکی از گزینه‌های خودتان را برای متن، تصاویر، صدا یا ویدیویی که متصل می‌کنید انتخاب کنید و گزینه انتخاب‌شده، موقعیت آن و یک میزان اطمینان دریافت کنید. `choice` را به یک گره Branch متصل کنید که ورودی‌هایش همان نام گزینه‌ها را دارند، یا وقتی گره Branch در دسترس نیست، بر اساس `option_index` مسیریابی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که باید استفاده شود (پیش‌فرض: `"gemini-decision-1"`). | COMBO | بله | `"gemini-decision-1"` |
| `question` | پرسشی که گزینه‌ها به آن پاسخ می‌دهند، تا 5000 نویسه (پیش‌فرض: "What style is the image?"). | STRING | بله | 1 تا 5000 نویسه |
| `options` | هر گزینه در یک خط، دقیقاً همان‌طور که تایپ شده استفاده می‌شود، هرکدام تا 128 نویسه. گزینه‌ای مانند `other` برای ورودی‌هایی که با هیچ‌کدام از آن‌ها سازگار نیستند اضافه کنید (پیش‌فرض: `photo`، `illustration`، `3d render`، `anime`، `sketch`، `other`). | STRING | بله | 2 تا 255 گزینه |
| `images` | تصاویری که باید طبقه‌بندی شوند، تا 16 تصویر در جایگاه‌های قابل‌افزایش (`image_1` ... `image_16`). یک تصویر دسته‌ای به ازای هر تصویر یک‌بار شمرده می‌شود. | IMAGE | خیر | تا 16 تصویر |
| `audio` | قطعه صوتی برای طبقه‌بندی. | AUDIO | خیر | - |
| `video` | قطعه ویدیویی برای طبقه‌بندی. | VIDEO | خیر | - |
| `text` | متنی که پرسش درباره آن است، مانند یک پرامپت یا پاسخ LLM، تا 20000 نویسه. | STRING | خیر | تا 20000 نویسه |

حداقل 2 و حداکثر 255 گزینه بدهید و هیچ‌کدام را دو بار فهرست نکنید؛ در غیر این صورت گره خطا می‌دهد. حداقل یکی از `text`، `images`، `audio` یا `video` را متصل کنید و اگر چند تصویر دارید، آن‌ها را درون پرسش با نام‌های `image_1`، `image_2` و به همین ترتیب نام‌گذاری کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `choice` | گزینه انتخاب‌شده، دقیقاً همان‌طور که در `options` نوشته شده است. | STRING |
| `option_index` | موقعیت گزینه انتخاب‌شده در `options`، با شروع از 0. | INT |
| `confidence` | میزان اطمینان به انتخاب، بین 0 و 1. | FLOAT |
