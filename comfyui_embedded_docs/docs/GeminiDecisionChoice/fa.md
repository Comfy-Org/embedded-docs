# Google Gemini Decision (Choice)

یکی از گزینه‌های خودتان را برای متن، تصویر، صدا یا ویدیویی که متصل می‌کنید انتخاب کنید و گزینه انتخاب‌شده، موقعیت آن و میزان اطمینان را دریافت کنید. `choice` را به یک گره Branch متصل کنید که ورودی‌هایش همان نام‌های گزینه را دارند، یا بر اساس `option_index` مسیریابی کنید. یک گره Branch حداکثر 32 ورودی می‌پذیرد، بنابراین مجموعه‌های گزینه بزرگ‌تر را با `option_index` مسیریابی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده (پیش‌فرض: `"gemini-decision-1"`). | COMBO | بله | `"gemini-decision-1"` |
| `question` | سؤالی که گزینه‌ها به آن پاسخ می‌دهند، حداکثر 5000 کاراکتر (پیش‌فرض: "What style is the image?"). | STRING | بله | 1 تا 5000 کاراکتر |
| `options` | در هر خط یک گزینه، دقیقاً همان‌طور که تایپ شده استفاده می‌شود، هر کدام حداکثر 128 کاراکتر. گزینه‌ای مانند `other` را برای ورودی‌هایی که با هیچ‌کدام از آن‌ها مطابقت ندارند اضافه کنید (پیش‌فرض: `photo`، `illustration`، `3d render`، `anime`، `sketch`، `other`). | STRING | بله | 2 تا 255 گزینه |
| `images` | تصاویری برای طبقه‌بندی، حداکثر 16 تصویر در اسلات‌های قابل‌افزایش (`image_1` ... `image_16`). یک تصویر دسته‌ای به‌ازای هر تصویر یک‌بار شمرده می‌شود. | IMAGE | خیر | حداکثر 16 تصویر |
| `audio` | کلیپ صوتی برای طبقه‌بندی. | AUDIO | خیر | - |
| `video` | کلیپ ویدیویی برای طبقه‌بندی. | VIDEO | خیر | - |
| `text` | متنی که سؤال درباره آن است، مانند یک پرامپت یا پاسخ یک LLM، حداکثر 20000 کاراکتر. | STRING | خیر | حداکثر 20000 کاراکتر |

حداقل 2 و حداکثر 255 گزینه بدهید و هیچ‌کدام را دو بار فهرست نکنید؛ در غیر این صورت گره خطا می‌دهد. حداقل یکی از `text`، `images`، `audio` یا `video` را متصل کنید و چند تصویر را داخل سؤال با نام‌های `image_1`، `image_2` و به همین ترتیب نام‌گذاری کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `choice` | گزینه انتخاب‌شده، دقیقاً همان‌طور که در `options` نوشته شده است. | STRING |
| `option_index` | موقعیت گزینه انتخاب‌شده در `options`، با شروع از 0. | INT |
| `confidence` | میزان اطمینان به انتخاب، بین 0 و 1. | FLOAT |
