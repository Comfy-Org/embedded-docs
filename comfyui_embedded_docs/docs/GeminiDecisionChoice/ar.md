# Google Gemini Decision (Choice)

اختر أحد خياراتك الخاصة للنص أو الصور أو الصوت أو الفيديو الذي توصله، واحصل على الخيار المختار وموضعه ودرجة ثقة. وصّل `choice` بعقدة Branch تكون مدخلاتها تحمل أسماء الخيارات نفسها، أو وجّه المسار بناءً على `option_index` عند عدم توفر عقدة Branch.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المراد استخدامه (الافتراضي: `"gemini-decision-1"`). | COMBO | نعم | `"gemini-decision-1"` |
| `question` | السؤال الذي تجيب عنه الخيارات، بحد أقصى 5000 حرف (الافتراضي: "What style is the image?"). | STRING | نعم | من 1 إلى 5000 حرف |
| `options` | خيار واحد في كل سطر، يُستخدم كما هو مكتوب تمامًا، بحد أقصى 128 حرفًا لكل خيار. أضف خيارًا مثل `other` للمدخلات التي لا تناسب أيًا منها (الافتراضي: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | نعم | من 2 إلى 255 خيارًا |
| `images` | الصور المراد تصنيفها، بحد أقصى 16 عبر الخانات القابلة للتوسعة (`image_1` ... `image_16`). تُحتسب الصورة المُجمّعة مرة واحدة لكل صورة. | IMAGE | لا | حتى 16 صورة |
| `audio` | مقطع صوتي المراد تصنيفه. | AUDIO | لا | - |
| `video` | مقطع فيديو المراد تصنيفه. | VIDEO | لا | - |
| `text` | النص الذي يدور حوله السؤال، مثل موجه أو استجابة LLM، بحد أقصى 20000 حرف. | STRING | لا | حتى 20000 حرف |

قدّم خيارين على الأقل و255 خيارًا كحد أقصى، ولا تكرر أيًا منها؛ وإلا فإن العقدة ستُطلق خطأً. وصّل واحدًا على الأقل من `text` أو `images` أو `audio` أو `video`، وسمِّ عدة صور باسم `image_1` و`image_2` وهكذا داخل السؤال.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `choice` | الخيار المختار، تمامًا كما كُتب في `options`. | STRING |
| `option_index` | موضع الخيار المختار في `options`، بدءًا من 0. | INT |
| `confidence` | درجة الثقة في الاختيار، بين 0 و1. | FLOAT |
