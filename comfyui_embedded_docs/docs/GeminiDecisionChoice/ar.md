# Google Gemini Decision (Choice)

اختر أحد خياراتك الخاصة للنص أو الصور أو الصوت أو الفيديو الذي توصله، ثم استرجع الخيار المختار وموضعه ودرجة الثقة. صِل `choice` بعقدة Branch تكون مدخلاتها تحمل أسماء الخيارات نفسها، أو وجّه المسار عبر `option_index`. تقبل عقدة Branch 32 مدخلًا كحد أقصى، لذلك وجّه مجموعات الخيارات الأكبر باستخدام `option_index`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المراد استخدامه (الافتراضي: `"gemini-decision-1"`). | COMBO | نعم | `"gemini-decision-1"` |
| `question` | السؤال الذي تجيب عنه الخيارات، حتى 5000 حرف (الافتراضي: "What style is the image?"). | STRING | نعم | 1 إلى 5000 حرف |
| `options` | خيار واحد في كل سطر، يُستخدم تمامًا كما هو مكتوب، حتى 128 حرفًا لكل خيار. أضف خيارًا مثل `other` للمدخلات التي لا تناسب أيًا منها (الافتراضي: `photo`، `illustration`، `3d render`، `anime`، `sketch`، `other`). | STRING | نعم | 2 إلى 255 خيارًا |
| `images` | الصور المراد تصنيفها، حتى 16 صورة عبر الخانات القابلة للزيادة (`image_1` ... `image_16`). تُحسب الصورة المضمّنة في دفعة مرة واحدة لكل صورة. | IMAGE | لا | حتى 16 صورة |
| `audio` | مقطع صوتي المراد تصنيفه. | AUDIO | لا | - |
| `video` | مقطع فيديو المراد تصنيفه. | VIDEO | لا | - |
| `text` | النص الذي يدور حوله السؤال، مثل مُوجّه (prompt) أو استجابة LLM، حتى 20000 حرف. | STRING | لا | حتى 20000 حرف |

قدّم خيارين على الأقل و255 خيارًا كحد أقصى، ولا تكرر أيًا منها؛ وإلا فسترفع العقدة خطأً. صِل واحدًا على الأقل من `text` أو `images` أو `audio` أو `video`، وسمِّ عدة صور باسم `image_1` و`image_2` وهكذا داخل السؤال.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `choice` | الخيار المختار، تمامًا كما كُتب في `options`. | STRING |
| `option_index` | موضع الخيار المختار في `options`، بدءًا من 0. | INT |
| `confidence` | درجة الثقة في الاختيار، بين 0 و1. | FLOAT |
