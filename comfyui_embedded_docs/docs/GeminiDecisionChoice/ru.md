# Google Gemini Decision (Choice)

Выберите один из собственных вариантов для текста, изображений, аудио или видео, которые вы подключаете, и получите выбранный вариант, его позицию и оценку уверенности. Подключите `choice` к узлу Branch, входы которого имеют те же имена вариантов, или маршрутизируйте по `option_index`. Узел Branch принимает не более 32 входов, поэтому для больших наборов вариантов используйте маршрутизацию по `option_index`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Используемая модель (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `вопрос` | Вопрос, на который отвечают варианты, до 5000 символов (по умолчанию: "What style is the image?"). | STRING | Да | от 1 до 5000 символов |
| `варианты` | Один вариант на строку, используется точно в том виде, как введён, до 128 символов каждый. Добавьте вариант, например `other`, для входов, которые не подходят ни под один из них (по умолчанию: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | Да | от 2 до 255 опций |
| `изображения` | Изображения для классификации, до 16 в расширяемых слотах (`image_1` ... `image_16`). Изображения в пакете учитываются по отдельности. | IMAGE | Нет | До 16 изображений |
| `аудио` | Аудиоклип для классификации. | AUDIO | Нет | - |
| `видео` | Видеоклип для классификации. | VIDEO | Нет | - |
| `текст` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Укажите не менее 2 и не более 255 вариантов и не перечисляйте ни один из них дважды; иначе узел выдаст ошибку. Подключите хотя бы один из `text`, `images`, `audio` или `video` и назовите несколько изображений `image_1`, `image_2` и так далее в тексте вопроса.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `choice` | Выбранный вариант, ровно в том виде, как он был записан в `options`. | STRING |
| `option_index` | Позиция выбранного варианта в `options`, начиная с 0. | INT |
| `confidence` | Уверенность в выборе, от 0 до 1. | FLOAT |
