# RenormCFG

RenormCFGノードは、条件付きスケーリングと正規化を適用することで、拡散モデルにおけるClassifier-Free Guidance（CFG）プロセスを変更します。指定されたタイムステップしきい値と再正規化係数に基づいてノイズ除去プロセスを調整し、画像生成中の条件付き予測と非条件付き予測の影響度を制御します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 再正規化CFGを適用する拡散モデル | MODEL | はい | - |
| `cfg_trunc` | CFGスケーリングを適用するタイムステップのしきい値。現在のタイムステップがこの値未満の場合、CFGスケーリングが適用されます。それ以外の場合、条件付き予測のみが使用されます（デフォルト: 100.0） | FLOAT | いいえ | 0.0 - 100.0 |
| `renorm_cfg` | 元の条件付き予測に対するCFGスケーリング済み予測の最大ノルムを制限する再正規化係数。0.0を指定すると再正規化が無効になります（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 100.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | 再正規化CFG機能が適用された変更済みモデル | MODEL |
