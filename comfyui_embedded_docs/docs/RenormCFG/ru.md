# RenormCFG

Узел RenormCFG модифицирует процесс наведения без классификатора (CFG) в диффузионных моделях, применяя условное масштабирование и нормализацию. Он регулирует процесс шумоподавления на основе заданных пороговых значений шага по времени и коэффициентов перенормировки, чтобы контролировать влияние условных и безусловных предсказаний во время генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется перенормированный CFG | MODEL | Да | - |
| `cfg_trunc` | Пороговое значение шага по времени для применения масштабирования CFG. Когда текущий шаг по времени ниже этого значения, применяется масштабирование CFG; в противном случае используется только условное предсказание (по умолчанию: 100.0) | FLOAT | Нет | 0.0 - 100.0 |
| `renorm_cfg` | Коэффициент перенормировки, ограничивающий максимальную норму предсказания, масштабированного с помощью CFG, относительно исходного условного предсказания. Значение 0.0 отключает перенормировку (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённой функцией перенормированного CFG | MODEL |
