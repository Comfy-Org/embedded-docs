# RenormCFG

Узел RenormCFG изменяет процесс classifier-free guidance (CFG) в диффузионных моделях, применяя условное масштабирование и нормализацию. Он настраивает процесс удаления шума на основе заданного порога временного шага и коэффициента перенормировки, управляя влиянием условных и безусловных предсказаний во время генерации изображения. Возвращается результирующая модель с таким изменённым поведением CFG.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется перенормированный CFG | MODEL | Да | - |
| `cfg_trunc` | Порог временного шага для применения масштабирования CFG. Когда текущий временной шаг ниже этого значения, применяются масштабирование CFG и перенормировка; в противном случае используется только условное предсказание (по умолчанию: 100.0) | FLOAT | Нет | 0.0 - 100.0 (шаг: 0.01) |
| `renorm_cfg` | Коэффициент перенормировки, ограничивающий максимальную норму предсказания, масштабированного CFG, относительно исходного условного предсказания. Значение 0.0 отключает перенормировку (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 100.0 (шаг: 0.01) |

Примечание: `cfg_trunc` и `renorm_cfg` — это расширенные параметры. Перенормировка вступает в силу только когда `renorm_cfg` больше 0.0, а текущий временной шаг ниже `cfg_trunc`; если норма нового предсказания уже ниже вычисленного максимума, повторное масштабирование не выполняется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённой функцией перенормированного CFG | MODEL |
