# Pika H3 Flex Video

Этот узел генерирует видео с синхронизированным звуком по текстовому промпту, при необходимости с привязкой к первому кадру, последнему кадру или обоим. Pika H3 Flex — это модель MiniMax H3, дообученная Pika: она рендерит изображение и звук к нему за один проход, а вы задаёте разрешение, соотношение сторон и длительность. Если ни один кадр не подключён, узел работает в режиме текст-в-видео; подключение кадра переключает его в режим изображение-в-видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Что происходит в видео, включая желаемый звук. Не должен быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | от 1 до 8000 символов |
| `first_frame` | Необязательное изображение, используемое в качестве начального кадра. При его подключении узел работает в режиме изображение-в-видео вместо режима текст-в-видео. | IMAGE | Нет | - |
| `last_frame` | Необязательное изображение, используемое в качестве конечного кадра. Может использоваться вместе с `first_frame` или отдельно. | IMAGE | Нет | - |
| `resolution` | Разрешение выходного видео. `"1080p"` и выше рендерятся в 768p и однократно масштабируются вверх. Тот же seed при 480p даёт другое видео. По умолчанию: `"768p"`. | COMBO | Да | `"480p"`<br>`"768p"`<br>`"1080p"`<br>`"2k"`<br>`"4k"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` ориентируется на первый подключённый кадр, иначе — на промпт. По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"21:9"`<br>`"16:9"`<br>`"3:2"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"2:3"`<br>`"9:16"`<br>`"9:21"` |
| `duration` | Длительность клипа в секундах. Длина выходного видео соответствует сетке кадров: 5 секунд дают 124 кадра, примерно 5,17 секунды. По умолчанию: 5. | INT | Да | от 5 до 15 секунд |
| `rewrite_prompt` | Разрешить Pika сначала расширить промпт. Тогда один и тот же seed при каждом запуске даёт другое видео. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `seed` | Seed для сэмплирования. Если `rewrite_prompt` выключен, тот же seed в точности повторяет видео, хотя локальный запуск с тем же seed даёт другой результат. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения:**

* Промпт должен содержать от 1 до 8000 символов.
* Оплата зависит от выбранного разрешения и длительности клипа и рассчитывается за каждую секунду выходного видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный клип с синхронизированным звуком. | VIDEO |
