# Pika H3 Flex Video

צומת זה יוצר סרטון עם אודיו מסונכרן מתוך פרומפט טקסטואלי, כאשר באפשרותך לעגן אותו בפריים ראשון, בפריים אחרון, או בשניהם. Pika H3 Flex הוא המודל MiniMax H3 שעבר אימון-המשך של Pika: הוא מרנדר את התמונה ואת הפסקול שלה במעבר אחד, ואתה קובע את הרזולוציה, יחס הגובה-רוחב והמשך. כאשר לא מחובר אף פריים, הצומת פועל במצב טקסט לסרטון; חיבור פריים מעביר אותו למצב תמונה לסרטון.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה קורה בסרטון, כולל הצליל הרצוי. אין להשאיר ריק. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 1 עד 8000 תווים |
| `first_frame` | תמונה אופציונלית המשמשת כפריים הפותח. חיבורה מפעיל מצב תמונה לסרטון במקום טקסט לסרטון. | IMAGE | לא | - |
| `last_frame` | תמונה אופציונלית המשמשת כפריים הסוגר. ניתן להשתמש בה יחד עם `first_frame` או בנפרד. | IMAGE | לא | - |
| `resolution` | רזולוציית הפלט. `"1080p"` ומעלה מרונדרות ב-768p ומוגדלות פעם אחת. אותו seed ב-480p מניב סרטון שונה. ברירת מחדל: `"768p"`. | COMBO | כן | `"480p"`<br>`"768p"`<br>`"1080p"`<br>`"2k"`<br>`"4k"` |
| `aspect_ratio` | יחס גובה-רוחב של הפלט. `"auto"` עוקב אחר הפריים המחובר הראשון, ואם אין כזה — אחר הפרומפט. ברירת מחדל: `"auto"`. | COMBO | כן | `"auto"`<br>`"21:9"`<br>`"16:9"`<br>`"3:2"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"2:3"`<br>`"9:16"`<br>`"9:21"` |
| `duration` | אורך הקליפ בשניות. אורך הפלט עוקב אחר רשת פריימים: 5 שניות נותנות 124 פריימים, כ-5.17 שניות. ברירת מחדל: 5. | INT | כן | 5 עד 15 שניות |
| `rewrite_prompt` | לאפשר ל-Pika להרחיב תחילה את הפרומפט. אותו seed יניב אז סרטון שונה בכל הרצה. ברירת מחדל: False. | BOOLEAN | כן | true<br>false |
| `seed` | seed לדגימה. כאשר `rewrite_prompt` כבוי, אותו seed חוזר על אותו סרטון בדיוק, אך הרצה מקומית עם אותו seed תניב תוצאה שונה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים:**

* אורך הפרומפט חייב להיות בין 1 ל-8000 תווים.
* החיוב נקבע לפי הרזולוציה שנבחרה ואורך הקליפ, ומחושב לפי שנייה של פלט.
