# Pika H3 Flex Video

此節點可依據文字提示詞產生帶有同步音訊的影片，並可選擇性地以第一幀、最後一幀或同時以兩者作為錨定。Pika H3 Flex 是 Pika 基於 MiniMax H3 進行後訓練的模型：它能在一次生成中同時渲染畫面與聲音，並由您設定解析度、長寬比與時長。未連接任何幀時，此節點執行文字轉影片；連接幀後則切換為圖片轉影片。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 影片中發生的事情，包括您想要的聲音。不得為空。預設：""（空字串）。 | STRING | 是 | 1 至 8000 個字元 |
| `first_frame` | 可選的圖片，用作開場幀。連接後會改以圖片轉影片執行，而非文字轉影片。 | IMAGE | 否 | - |
| `last_frame` | 可選的圖片，用作結尾幀。可與 `first_frame` 一起使用，也可單獨使用。 | IMAGE | 否 | - |
| `resolution` | 輸出解析度。`"1080p"` 及以上會以 768p 渲染後再放大一次。相同的 `seed` 在 480p 下會產生不同的影片。預設：`"768p"`。 | COMBO | 是 | `"480p"`<br>`"768p"`<br>`"1080p"`<br>`"2k"`<br>`"4k"` |
| `aspect_ratio` | 輸出長寬比。`"auto"` 會依首個連接的幀決定，否則依提示詞決定。預設：`"auto"`。 | COMBO | 是 | `"auto"`<br>`"21:9"`<br>`"16:9"`<br>`"3:2"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"2:3"`<br>`"9:16"`<br>`"9:21"` |
| `duration` | 片段長度（秒）。輸出長度依幀格計算：5 秒會產生 124 幀，約 5.17 秒。預設：5。 | INT | 是 | 5 至 15 秒 |
| `rewrite_prompt` | 讓 Pika 先擴寫提示詞。如此一來，相同的 `seed` 在每次執行時都會產生不同的影片。預設：False。 | BOOLEAN | 是 | True<br>False |
| `seed` | 取樣用的種子。關閉 `rewrite_prompt` 時，相同的 `seed` 會完全重現同一段影片，不過在本機執行時使用相同的 `seed` 會得到不同的結果。預設：42。 | INT | 是 | 0 至 2147483647 |

**限制條件：**

* 提示詞長度必須介於 1 至 8000 個字元之間。
* 計費依所選解析度與片段長度計算，並以每秒輸出計價。
