# חיתוך תמונה (אקראי)

הצומת Random Crop Images בוחר באופן אקראי אזור מלבני מכל תמונת קלט ומחתך אותו לרוחב ולגובה שצוינו. הדבר משמש בדרך כלל להרחבת נתונים (data augmentation) כדי ליצור וריאציות של תמונות אימון. המיקום האקראי של החיתוך נקבע לפי ערך seed, כך שניתן לשחזר את אותו חיתוך.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | התמונה שיש לחתוך. | IMAGE | כן | - |
| `width` | הרוחב של אזור החיתוך (ברירת מחדל: 512). | INT | לא | 1 - 8192 |
| `height` | הגובה של אזור החיתוך (ברירת מחדל: 512). | INT | לא | 1 - 8192 |
| `seed` | מספר המשמש לשליטה במיקום האקראי של החיתוך (ברירת מחדל: 0). | INT | לא | 0 - 18446744073709551615 |

**הערה:** הפרמטרים `width` ו-`height` חייבים להיות קטנים או שווים לממדי תמונת הקלט. אם ממד שצוין גדול מהתמונה, החיתוך יוגבל לגבול התמונה.
