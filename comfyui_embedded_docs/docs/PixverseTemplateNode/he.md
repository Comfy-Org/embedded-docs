# PixVerse Template

צומת PixVerse Template מאפשר לך לבחור מבין התבניות הזמינות ליצירת וידאו של PixVerse. הוא ממיר את שם התבנית שנבחרה למזהה התבנית המתאים שנדרש על ידי PixVerse API ליצירת וידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `template` | התבנית לשימוש ביצירת וידאו של PixVerse. האפשרויות הזמינות תואמות לתבניות מוגדרות מראש במערכת PixVerse. | STRING | כן | אפשרויות מרובות זמינות |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `pixverse_template` | מזהה התבנית המתאים לשם התבנית שנבחרה, אשר יכול לשמש צמתי PixVerse אחרים ליצירת וידאו. | STRING |
