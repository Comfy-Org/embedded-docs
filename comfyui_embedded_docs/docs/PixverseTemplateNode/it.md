# PixverseTemplateNode

Il nodo PixVerse Template consente di selezionare tra i template disponibili per la generazione video PixVerse. Converte il nome del template selezionato nell'ID template corrispondente richiesto dall'API PixVerse per la creazione del video.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
|-----------|-------------|--------------|--------------|------------|
| `template` | Il template da usare per la generazione video PixVerse. Le opzioni disponibili corrispondono ai template predefiniti nel sistema PixVerse. | STRING | Sì | Più opzioni disponibili |

## Output

| Nome output | Descrizione | Tipo di dati |
|-------------|-------------|--------------|
| `pixverse_template` | L'ID del template corrispondente al nome del template selezionato, che può essere usato da altri nodi PixVerse per la generazione video. | STRING |
