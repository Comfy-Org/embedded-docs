# TSR - Временное перемасштабирование оценки

Этот узел применяет Temporal Score Rescaling (TSR) к диффузионной модели. Он изменяет поведение модели при сэмплировании, масштабируя предсказанный шум или оценку (score) в процессе удаления шума (денойзинга), что позволяет управлять разнообразием генерируемого результата. Это реализовано как функция после CFG (Classifier-Free Guidance).

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будет применена функция TSR. | MODEL | Да | - |
| `tsr_k` | Управляет силой масштабирования. Более низкие значения k дают более детализированные результаты; более высокие значения k дают более гладкие результаты при генерации изображений. Установка k = 1 отключает масштабирование. (по умолчанию: 0.95) | FLOAT | Нет | 0.01 - 100.0 |
| `tsr_sigma` | Управляет тем, насколько рано начинает действовать масштабирование. Большие значения действуют раньше. (по умолчанию: 1.0) | FLOAT | Нет | 0.01 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `patched_model` | Входная модель, теперь модифицированная функцией Temporal Score Rescaling, примененной к ее процессу сэмплирования. | MODEL |
