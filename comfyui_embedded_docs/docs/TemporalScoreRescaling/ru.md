# TSR - Временное перемасштабирование оценки

Этот узел применяет временное масштабирование оценки (Temporal Score Rescaling, TSR) к модели диффузии. Он изменяет поведение сэмплирования модели, перемасштабируя предсказанный шум или оценку в процессе денойзинга, что позволяет управлять разнообразием генерируемого результата. Это реализовано как функция, применяемая после CFG (Classifier-Free Guidance).

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель диффузии, к которой будет применена функция TSR. | MODEL | Да | - |
| `tsr_k` | Управляет силой масштабирования. Меньшие значения k дают более детализированные результаты, большие значения k — более гладкие результаты при генерации изображений. Установка k = 1 отключает масштабирование. (по умолчанию: 0.95) | FLOAT | Да | 0.01 - 100.0 |
| `tsr_sigma` | Управляет тем, насколько рано начинает действовать масштабирование. Большие значения действуют раньше. (по умолчанию: 1.0) | FLOAT | Да | 0.01 - 100.0 |

## Выходы

| Выход | Описание | Тип данных |
| --- | --- | --- |
| `исправленная_модель` | Входная модель, теперь модифицированная функцией TSR, применённой к её процессу сэмплирования. | MODEL |
