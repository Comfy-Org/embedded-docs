# TSR - Временное перемасштабирование оценки

Этот узел применяет Temporal Score Rescaling (TSR) к диффузионной модели. Он модифицирует модель таким образом, что во время сэмплирования предсказанная оценка или шум масштабируются для управления разнообразием генерируемых результатов. Это реализовано как функция пост-CFG (Classifier-Free Guidance).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется функция TSR. | MODEL | Да | - |
| `tsr_k` | Управляет силой масштабирования. Меньшее значение k дает более детализированные результаты; большее значение k дает более гладкие результаты при генерации изображений. Установка k = 1 отключает масштабирование. (по умолчанию: 0.95) | FLOAT | Да | 0.01 - 100.0 |
| `tsr_sigma` | Управляет тем, как рано начинает действовать масштабирование. Большие значения начинают действовать раньше. (по умолчанию: 1.0) | FLOAT | Да | 0.01 - 100.0 |

Примечание: Масштабирование пропускается, когда `tsr_k` установлен в 1, когда значение sigma равно 0 или когда отношение сигнал/шум равно 0.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `patched_model` | Входная модель, теперь модифицированная с применением функции Temporal Score Rescaling к ее процессу сэмплирования. | MODEL |
