# StableCascade_Этап B_Кондиционирование

Узел StableCascade_StageB_Conditioning подготавливает данные кондиционирования для генерации Stable Cascade Stage B, объединяя существующую информацию кондиционирования с априорным латентным представлением, созданным Stage C. Он копирует каждую запись кондиционирования и сохраняет в неё латентные образцы Stage C, чтобы последующие шаги генерации могли использовать эту априорную информацию для более согласованных результатов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые нужно изменить с помощью априорной информации Stage C. Каждая запись в списке копируется и получает образцы Stage C. | CONDITIONING | Да | - |
| `стадия_c` | Латентное представление из Stage C. Его значение `samples` используется как априорная информация, добавляемая к кондиционированию. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Изменённые данные кондиционирования со встроенной априорной информацией Stage C. | CONDITIONING |
