# StableCascade_Этап B_Кондиционирование

Узел StableCascade_StageB_Conditioning подготавливает данные кондиционирования для генерации Stage B в Stable Cascade, объединяя существующую информацию кондиционирования с предварительными латентными представлениями из Stage C. Он копирует каждый элемент кондиционирования и добавляет в него латентные сэмплы Stage C, что позволяет процессу генерации использовать предварительную информацию для получения более связных результатов.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые будут изменены с использованием предварительной информации из Stage C | CONDITIONING | Да | - |
| `стадия_c` | Латентное представление из Stage C, содержащее предварительные сэмплы для кондиционирования | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Измененные данные кондиционирования с интегрированной предварительной информацией из Stage C | CONDITIONING |
