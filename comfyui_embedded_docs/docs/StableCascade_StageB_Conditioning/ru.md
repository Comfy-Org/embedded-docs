# StableCascade_Этап B_Кондиционирование

Узел StableCascade_StageB_Conditioning подготавливает данные кондиционирования для генерации Stable Cascade Stage B, объединяя существующую информацию кондиционирования с предварительными скрытыми представлениями из Stage C. Он изменяет каждый элемент кондиционирования, чтобы включить скрытые образцы из Stage C, что позволяет процессу генерации использовать предварительную информацию для более согласованных результатов.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные кондиционирования для изменения с предварительной информацией Stage C | CONDITIONING | Да | - |
| `stage_c` | Скрытое представление из Stage C, содержащее предварительные образцы для кондиционирования | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Измененные данные кондиционирования с интегрированной предварительной информацией Stage C | CONDITIONING |
