# StableCascade_StageB_Conditioning

گره `StableCascade_StageB_Conditioning` داده‌های شرطی‌سازی را برای تولید مرحله B در Stable Cascade آماده می‌کند؛ به این صورت که اطلاعات شرطی موجود را با بازنمایی‌های نهفته (latent) قبلی از مرحله C ترکیب می‌کند. این گره هر ورودی شرطی را تغییر می‌دهد تا نمونه‌های نهفته مرحله C را در بر بگیرد و بدین ترتیب فرایند تولید می‌تواند از اطلاعات قبلی برای خروجی‌های منسجم‌تر بهره ببرد.

| `stage_c` | بازنمایی نهفته از مرحله C شامل نمونه‌های قبلی برای شرطی‌سازی | LATENT | بله | - |
