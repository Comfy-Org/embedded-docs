# CropByBBoxes

הצומת CropByBBoxes מחלץ ומשנה את הגודל של אזורים מלבניים מסוימים מתוך אצווה של תמונות קלט. הוא משתמש בקואורדינטות של תיבות תוחמות שסופקו כדי להגדיר את האזור לחיתוך מכל תמונה. לאחר מכן האזורים החתוכים משונים בגודלם לממד פלט שצוין, עם אפשרויות למתוח את החיתוך או לרפד אותו כדי לשמור על יחס הגובה-רוחב המקורי שלו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | אצוות תמונות הקלט לחיתוך. | IMAGE | כן | - |
| `bboxes` | רשימת התיבות התוחמות המגדירות את האזורים לחיתוך. קלט זה כפוי, כלומר חייב להיות מחובר. | BOUNDINGBOX | כן | - |
| `output_width` | הרוחב שאליו משונה הגודל של כל חיתוך (ברירת מחדל: 512). | INT | לא | 64 - 4096 |
| `output_height` | הגובה שאליו משונה הגודל של כל חיתוך (ברירת מחדל: 512). | INT | לא | 64 - 4096 |
| `padding` | ריפוד נוסף בפיקסלים שמתווסף בכל צד של התיבה התוחמת לפני החיתוך (ברירת מחדל: 0). | INT | לא | 0 - 1024 |
| `keep_aspect` | האם למתוח את החיתוך כך שיתאים לגודל הפלט, או לרפד בפיקסלים שחורים כדי לשמור על יחס הגובה-רוחב שלו (ברירת מחדל: "stretch"). | COMBO | לא | `"stretch"`<br>`"pad"` |

**הערה:** הצומת מעבד פריים תמונה אחד בכל פעם. אם מסופקות מספר תיבות תוחמות עבור פריים בודד, הוא מחשב אזור חיתוך יחיד שהוא האיחוד (המלבן הקטן ביותר המכיל את כל התיבות) של כל התיבות המסופקות. אם אזור חיתוך מחושב אינו תקין (למשל, רוחב או גובה אפס), הצומת ייצור חיתוך חלופי מהמרכז העליון של התמונה.
