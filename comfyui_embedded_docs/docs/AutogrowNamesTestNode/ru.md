# AutogrowNamesTestNode

Этот узел является тестом для функции Autogrow для входных данных. Он принимает динамическое количество входов типа float, каждый с определённым именем, и объединяет их значения в одну строку, разделённую запятыми.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `autogrow` | Динамическая группа входов. Вы можете добавить несколько входов типа float, каждый с предопределённым именем из списка: "a", "b" или "c". Узел будет принимать любую комбинацию этих именованных входов. | FLOAT | Да | N/A |

**Примечание:** Вход `autogrow` является динамическим. Вы можете добавлять или удалять отдельные входы типа float (названные "a", "b" или "c") по мере необходимости для вашего рабочего процесса. Узел обрабатывает все предоставленные значения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Строка, содержащая значения всех предоставленных входов типа float, объединённые запятыми. | STRING |
