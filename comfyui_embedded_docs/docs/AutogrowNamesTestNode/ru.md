# AutogrowNamesTestNode

Этот узел является тестом функции входов Autogrow. Он принимает динамическую группу входов типа FLOAT, каждый с предопределённым именем, и объединяет их значения в одну строку, разделённую запятыми.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `autogrow` | Динамическая группа входов. Вы можете добавить несколько входов типа FLOAT, каждый с предопределённым именем из списка: "a", "b" или "c". Узел принимает любую комбинацию этих именованных входов. | FLOAT | Да | Именованные слоты: `a`, `b`, `c` |

**Примечание:** Вход `autogrow` является динамическим. Отдельные входы типа FLOAT с именами "a", "b" и "c" можно добавлять или удалять по мере необходимости. Все предоставленные значения обрабатываются узлом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Одна строка, содержащая значения из всех предоставленных входов типа FLOAT, объединённые запятыми. | STRING |
