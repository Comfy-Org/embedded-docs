# AutogrowNamesTestNode

Этот узел является тестом для функции автоматически расширяемых входов (Autogrow). Он принимает динамическое количество входов типа float, каждый из которых помечен конкретным именем, и объединяет их значения в единую строку, разделённую запятыми.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `autogrow` | Динамическая группа входов. Можно добавить несколько входов типа float, каждый с предопределённым именем из списка: «a», «b» или «c». Узел принимает любую комбинацию этих именованных входов. | FLOAT | Да | N/A |

**Примечание:** Вход `autogrow` является динамическим. Вы можете добавлять или удалять отдельные входы типа float (с именами «a», «b» или «c») по мере необходимости для вашего рабочего процесса. Узел обрабатывает все предоставленные значения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Единая строка, содержащая значения из всех предоставленных входов типа float, объединённые через запятую. | STRING |
