# Vidu マルチフレーム動画生成

このノードは、複数のキーフレーム間のトランジションを生成することでビデオを作成します。初期画像から開始し、ユーザーが定義した一連の終了画像とプロンプトを経由してアニメーション化し、単一のビデオファイルを出力として生成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ビデオ生成に使用するViduモデルです。 | COMBO | 必須 | "viduq2-pro"<br>"viduq2-turbo" |
| `start_image` | 開始フレームの画像です。アスペクト比は1:4から4:1の間である必要があります。 | IMAGE | 必須 | アスペクト比 1:4 から 4:1 |
| `seed` | 再現性のある結果を保証するための乱数生成のシード値です（デフォルト: 1）。 | INT | 必須 | 0 から 2147483647 |
| `resolution` | 出力ビデオの解像度です。 | COMBO | 必須 | "720p"<br>"1080p" |
| `frames` | キーフレームトランジションの数（2〜9）です。値を選択すると、各フレームに必要な入力が動的に表示されます。 | DYNAMIC_COMBO | 必須 | "2"<br>"3"<br>"4"<br>"5"<br>"6"<br>"7"<br>"8"<br>"9" |

### フレーム入力（すべてのフレーム数オプションで共通）

`frames` が数値に設定されると、1 からその数までの各フレーム `i` に対して、次の 3 つの入力が表示されます。たとえば、"3" を選択すると、`prompt1` / `end_image1` / `duration1`、`prompt2` / `end_image2` / `duration2`、`prompt3` / `end_image3` / `duration3` が追加されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | フレーム {i} のトランジションのためのテキストプロンプトです。複数行テキストフィールドです。最大2000文字です。 | STRING | 必須 | 最大2000文字 |
| `end_image{i}` | セグメント {i} の終了フレーム画像です。アスペクト比は1:4から4:1の間である必要があります。 | IMAGE | 必須 | アスペクト比 1:4 から 4:1 |
| `duration{i}` | セグメント {i} の長さ（秒単位）です。 | INT | 必須 | 2 から 7（デフォルト: 4） |

**注記：**

- すべての入力は必須です。`seed` にはデフォルト値がありますが、それでも必須の入力です。
- `start_image` とすべての `end_image{i}` は、アスペクト比が 1:4 から 4:1 の間である必要があります。
- すべての `prompt{i}` は最大 2000 文字です。
- すべての `duration{i}` は 2 秒から 7 秒の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | アニメーション化されたすべてのトランジションを含む、生成されたビデオファイルです。 | VIDEO |
