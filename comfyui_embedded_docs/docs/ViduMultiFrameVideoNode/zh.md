# Vidu 多帧视频生成

此节点通过在多个关键帧之间创建过渡来生成视频。它从初始图像开始，通过一系列用户定义的结束图像和提示词进行动画处理，最终输出一个视频文件。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的 Vidu 模型。 | COMBO | 是 | "viduq2-pro"<br>"viduq2-turbo" |
| `start_image` | 起始帧图像。宽高比必须在 1:4 到 4:1 之间。 | IMAGE | 是 | 宽高比 1:4 到 4:1 |
| `seed` | 用于随机数生成的种子值，以确保结果可重现（默认：1）。 | INT | 是 | 0 到 2147483647 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "720p"<br>"1080p" |
| `frames` | 关键帧过渡的数量（2-9）。选择一个值会动态显示每个帧所需的输入。 | DYNAMIC_COMBO | 是 | "2"<br>"3"<br>"4"<br>"5"<br>"6"<br>"7"<br>"8"<br>"9" |

### 帧输入（所有帧计数选项共用）

当 `frames` 设置为某个数字时，对于从 1 到该数字的每个帧 `i`，会显示以下三个输入。例如，选择“3”会添加 `prompt1` / `end_image1` / `duration1`、`prompt2` / `end_image2` / `duration2` 和 `prompt3` / `end_image3` / `duration3`。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | 帧 {i} 过渡的文本提示。多行文本字段。最多 2000 个字符。 | STRING | 是 | 最多 2000 个字符 |
| `end_image{i}` | 分段 {i} 的结束帧图像。宽高比必须在 1:4 到 4:1 之间。 | IMAGE | 是 | 宽高比 1:4 到 4:1 |
| `duration{i}` | 分段 {i} 的持续时间（秒）。 | INT | 是 | 2 到 7（默认：4） |

**注意：**

- 所有输入均为必填项。`seed` 有默认值，但仍是必填输入。
- `start_image` 和每个 `end_image{i}` 的宽高比必须在 1:4 到 4:1 之间。
- 每个 `prompt{i}` 的最大长度为 2000 个字符。
- 每个 `duration{i}` 必须在 2 到 7 秒之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件，包含所有动画过渡。 | VIDEO |
