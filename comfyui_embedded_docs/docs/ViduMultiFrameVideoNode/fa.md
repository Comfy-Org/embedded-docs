# تولید ویدیو چندفریمی Vidu

این گره با ایجاد گذار بین چند فریم کلیدی، ویدیو تولید می‌کند. از یک تصویر اولیه شروع کرده و با انیمیشن‌سازی بین دنباله‌ای از تصاویر پایانی و پرامپت‌های تعریف‌شده توسط کاربر، یک فایل ویدیویی واحد به عنوان خروجی تولید می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل Vidu مورد استفاده برای تولید ویدیو. | COMBO | بله | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `تصویر شروع` | تصویر فریم آغازین. نسبت تصویر باید بین 1:4 و 4:1 باشد. | IMAGE | بله | نسبت تصویر 1:4 تا 4:1 |
| `seed` | مقدار seed برای تولید اعداد تصادفی جهت اطمینان از نتایج قابل تکرار (پیش‌فرض: 1). | INT | بله | 0 تا 2147483647 |
| `رزولوشن` | وضوح ویدیوی خروجی. | COMBO | بله | `"720p"`<br>`"1080p"` |
| `فریم‌ها` | تعداد گذارهای فریم کلیدی (2-9). انتخاب یک مقدار، ورودی‌های موردنیاز برای هر فریم را به‌صورت پویا نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"` |

### ورودی‌های فریم (مشترک بین همه گزینه‌های تعداد فریم)

وقتی `frames` روی یک عدد تنظیم شود، سه ورودی زیر برای هر فریم `i` از 1 تا آن عدد نمایش داده می‌شود. برای مثال، انتخاب `"3"` باعث افزوده شدن `prompt1` / `end_image1` / `duration1`، `prompt2` / `end_image2` / `duration2` و `prompt3` / `end_image3` / `duration3` می‌شود.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | پرامپت متنی برای گذار فریم {i}. فیلد متنی چندخطی. حداکثر 2000 کاراکتر. | STRING | بله | حداکثر 2000 کاراکتر |
| `end_image{i}` | تصویر فریم پایانی برای بخش {i}. نسبت تصویر باید بین 1:4 و 4:1 باشد. | IMAGE | بله | نسبت تصویر 1:4 تا 4:1 |
| `duration{i}` | مدت‌زمان بخش {i} بر حسب ثانیه. | INT | بله | 2 تا 7 (پیش‌فرض: 4) |

**نکته‌ها:**

- همه ورودی‌ها الزامی هستند. `seed` مقدار پیش‌فرض دارد اما همچنان یک ورودی الزامی است.
- `start_image` و همه `end_image{i}` باید نسبت تصویری بین 1:4 و 4:1 داشته باشند.
- هر `prompt{i}` حداکثر 2000 کاراکتر طول دارد.
- هر `duration{i}` باید بین 2 تا 7 ثانیه باشد.

## خروجی‌ها
