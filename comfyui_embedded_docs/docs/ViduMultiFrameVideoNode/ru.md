# Vidu: генерация видео с несколькими ключевыми кадрами

Этот узел создает видео, формируя переходы между несколькими ключевыми кадрами. Он начинается с начального изображения и анимирует последовательность заданных пользователем конечных изображений и подсказок, создавая на выходе один видеофайл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Vidu, используемая для генерации видео. | COMBO | Да | "viduq2-pro"<br>"viduq2-turbo" |
| `start_image` | Начальный кадр изображения. Соотношение сторон должно быть от 1:4 до 4:1. | IMAGE | Да | Соотношение сторон от 1:4 до 4:1 |
| `seed` | Значение зерна для генерации случайных чисел, обеспечивающее воспроизводимые результаты (по умолчанию: 1). | INT | Да | от 0 до 2147483647 |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "720p"<br>"1080p" |
| `frames` | Количество переходов между ключевыми кадрами (от 2 до 9). Выбор значения динамически отображает необходимые входы для каждого кадра. | DYNAMIC_COMBO | Да | "2"<br>"3"<br>"4"<br>"5"<br>"6"<br>"7"<br>"8"<br>"9" |

### Входы кадров (общие для всех значений количества кадров)

Когда параметр `frames` задан числом, для каждого кадра `i` от 1 до этого числа отображаются следующие три входа. Например, выбор значения «3» добавляет `prompt1` / `end_image1` / `duration1`, `prompt2` / `end_image2` / `duration2`, и `prompt3` / `end_image3` / `duration3`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | Текстовая подсказка для перехода кадра {i}. Многострочное текстовое поле. Максимум 2000 символов. | STRING | Да | До 2000 символов |
| `end_image{i}` | Конечное изображение кадра для сегмента {i}. Соотношение сторон должно быть от 1:4 до 4:1. | IMAGE | Да | Соотношение сторон от 1:4 до 4:1 |
| `duration{i}` | Длительность сегмента {i} в секундах (по умолчанию: 4). | INT | Да | от 2 до 7 |

**Примечания:**

- Все входы обязательны. `seed` имеет значение по умолчанию, но все равно является обязательным входом.
- `start_image` и каждое `end_image{i}` должны иметь соотношение сторон от 1:4 до 4:1.
- Максимальная длина каждого `prompt{i}` — 2000 символов.
- Каждый `duration{i}` должен быть от 2 до 7 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл, содержащий все анимированные переходы. | VIDEO |
