# Vidu 多畫格影片生成

此節點透過在多个關鍵幀之間建立轉場效果來產生影片。它從起始幀影像開始，依序透過一系列使用者定義的結束幀影像和提示進行動畫處理，最終產生單一影片檔案作為輸出。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要用於影片生成的 Vidu 模型。 | COMBO | 是 | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `start_image` | 起始幀影像。長寬比必須介於 1:4 和 4:1 之間。 | IMAGE | 是 | 長寬比 1:4 至 4:1 |
| `seed` | 用於隨機數生成的種子值，以確保結果可重現（預設值：1）。 | INT | 是 | 0 至 2147483647 |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `frames` | 關鍵幀轉場的數量（2-9）。選擇一個值會動態顯示每個幀所需的輸入。 | DYNAMIC_COMBO | 是 | `"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"` |

### 幀輸入（所有幀數選項共用）

當 `frames` 設定為某個數字時，下列三個輸入會針對從 1 到該數字的每個幀 `i` 顯示。例如，選擇 `"3"` 會新增 `prompt1` / `end_image1` / `duration1`、`prompt2` / `end_image2` / `duration2` 以及 `prompt3` / `end_image3` / `duration3`。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | 幀 {i} 轉場的文字提示。多行文字欄位。最多 2000 個字元。 | STRING | 是 | 最多 2000 個字元 |
| `end_image{i}` | 區段 {i} 的結束幀影像。長寬比必須介於 1:4 和 4:1 之間。 | IMAGE | 是 | 長寬比 1:4 至 4:1 |
| `duration{i}` | 區段 {i} 的持續時間（秒）。 | INT | 是 | 2 至 7（預設值：4） |

**注意事項：**

- 所有輸入皆為必填。`seed` 有預設值，但仍為必填輸入。
- `start_image` 和每個 `end_image{i}` 的長寬比必須介於 1:4 和 4:1 之間。
- 每個 `prompt{i}` 的最大長度為 2000 個字元。
- 每個 `duration{i}` 必須介於 2 到 7 秒之間。
