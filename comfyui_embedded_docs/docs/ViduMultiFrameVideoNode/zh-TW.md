# Vidu 多畫格影片生成

此節點會透過在多個關鍵影格之間建立轉場來生成影片。它會從初始影像開始，並依照使用者定義的一連串結束影像與提示詞進行動畫生成，最後輸出單一影片檔案。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成影片的 Vidu 模型。 | COMBO | 是 | "viduq2-pro"<br>"viduq2-turbo" |
| `start_image` | 起始影格影像。長寬比必須介於 1:4 與 4:1 之間。 | IMAGE | 是 | 長寬比 1:4 至 4:1 |
| `seed` | 用於隨機數生成的種子值，以確保結果可重現（預設：1）。 | INT | 是 | 0 至 2147483647 |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "720p"<br>"1080p" |
| `frames` | 關鍵影格轉場的數量（2-9）。選擇某個值會動態顯示每個影格所需的輸入。 | DYNAMIC_COMBO | 是 | "2"<br>"3"<br>"4"<br>"5"<br>"6"<br>"7"<br>"8"<br>"9" |

### 影格輸入（所有影格數量選項共用）

當 `frames` 設為某個數字時，系統會為從 1 到該數字的每個影格 `i` 顯示以下三個輸入。例如，選擇 "3" 會新增 `prompt1` / `end_image1` / `duration1`、`prompt2` / `end_image2` / `duration2`，以及 `prompt3` / `end_image3` / `duration3`。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | 用於影格 {i} 轉場的文字提示詞。多行文字欄位。最多 2000 個字元。 | STRING | 是 | 最多 2000 個字元 |
| `end_image{i}` | 片段 {i} 的結束影格影像。長寬比必須介於 1:4 與 4:1 之間。 | IMAGE | 是 | 長寬比 1:4 至 4:1 |
| `duration{i}` | 片段 {i} 的持續時間，以秒為單位（預設：4）。 | INT | 是 | 2 至 7 |

**備註：**

- 所有輸入皆為必填。`seed` 雖有預設值，但仍屬於必填輸入。
- `start_image` 與每個 `end_image{i}` 的長寬比都必須介於 1:4 與 4:1 之間。
- 每個 `prompt{i}` 的長度上限為 2000 個字元。
- 每個 `duration{i}` 都必須介於 2 到 7 秒之間。
- 影格數量可以介於 2 到 9 之間，因此可能的影格索引會從 1 到 9。

|-------------|-------------|-----------|
| `output` | 生成的影片檔案，包含所有動畫轉場。 | VIDEO |
