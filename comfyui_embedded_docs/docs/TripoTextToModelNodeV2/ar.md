# TripoTextToModelNodeV2

ينشئ نموذجًا ثلاثي الأبعاد من وصف نصي باستخدام خدمة Tripo. ترسل العقدة المطالبة والإعدادات إلى Tripo، وتنتظر اكتمال مهمة التوليد، ثم تعيد ملف النموذج ثلاثي الأبعاد المكتمل مع معرّف المهمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | الوصف النصي للنموذج المراد توليده. يجب ألا يكون فارغًا. | STRING | نعم | نص متعدد الأسطر |
| `negative_prompt` | نص يوضح ما يجب ألا يظهر في النموذج المولّد. حتى 255 حرفًا. | STRING | لا | نص متعدد الأسطر، بحد أقصى 255 حرفًا |
| `model_version` | إصدار نموذج Tripo المستخدم في التوليد (الافتراضي: `v3.1_20260211`). | COMBO | لا | قائمة إصدارات نماذج Tripo المدعومة |
| `texture` | توليد خرائط النسيج. عند الإيقاف، يُعاد الشكل الهندسي المجرّد ويُتجاهل `pbr` (الافتراضي: True). | BOOLEAN | لا | True<br>False |
| `pbr` | خرائط مواد PBR (اللون الأساسي، معدني، خشونة، normal). يتطلب `texture` (الافتراضي: True). | BOOLEAN | لا | True<br>False |
| `image_seed` | قيمة البذرة لتوليد الصورة (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `model_seed` | قيمة البذرة لتوليد النموذج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `texture_seed` | قيمة البذرة لتوليد النسيج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `texture_quality` | مستوى تفاصيل النسيج (الافتراضي: "standard"). "detailed" = أنسجة HD، و"extreme" = أنسجة 8K فائقة. | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `face_limit` | الحد الأقصى لعدد الأوجه. القيمة -1 تدع Tripo يختار تكيفيًا (حوالي 1.4 مليون وجه في v3.x standard، و2 مليون في detailed). يقوم Tripo بالقص بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000 (الافتراضي: -1). | INT | لا | -1 إلى 2000000 |
| `quad` | إخراج شبكة رباعية. يسلّم Tripo الشبكات الرباعية بصيغة FBX، لذلك تصل النتيجة عبر مخرج FBX ويبقى مخرج GLB فارغًا (الافتراضي: False). | BOOLEAN | لا | True<br>False |
| `geometry_quality` | مستوى تفاصيل الشكل الهندسي (الافتراضي: "standard"). | COMBO | لا | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | شبكة منخفضة المضلعات ذات طوبولوجيا نظيفة بأسلوب مصمم يدويًا (500-20,000 وجه، وللرباعية 500-10,000). الأفضل للمواضيع البسيطة؛ قد تفشل الموضوعات المعقدة (الافتراضي: False). | BOOLEAN | لا | True<br>False |
| `auto_size` | تحجيم النماذج المزوّدة بنسيج إلى حجمها الواقعي بالمتر. يخزّن Tripo الحجم كتحويل مشهد النموذج ويدمجه عند تحويل النموذج أو تجهيزه بهيكل عظمي أو إعادة استهدافه؛ يُتجاهل عند عدم وجود نسيج (الافتراضي: True). | BOOLEAN | لا | True<br>False |

### ملاحظات

- `prompt` مطلوب ولا يمكن أن يكون فارغًا أو يحتوي على مسافات فقط.
- عندما تكون `texture` مضبوطة على False، يتم إيقاف `pbr` قسريًا، ولا يكون لـ `auto_size` أي تأثير.
- عند تمكين `smart_low_poly` وكان `face_limit` ليس -1، يجب أن يكون `face_limit` بين 500 و20,000 للشبكات المثلثية، أو بين 500 و10,000 عند تمكين `quad`.
- عند تمكين `quad`، يعيد Tripo ملف FBX، لذا يبقى مخرج `GLB` فارغًا ويتم تعبئة مخرج `FBX`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model task_id` | معرّف مهمة توليد Tripo التي أنتجت النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج المولّد بصيغة GLB. فارغ عند تمكين `quad`. | FILE3D_GLB |
| `FBX` | النموذج المولّد بصيغة FBX. يتم تعبئته فقط عند تمكين `quad`. | FILE3D_FBX |
