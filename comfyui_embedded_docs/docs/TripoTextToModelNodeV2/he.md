# TripoTextToModelNodeV2

יוצר מודל תלת-ממדי מתיאור טקסטואלי באמצעות שירות Tripo. הצומת שולח את ההנחיה וההגדרות אל Tripo, ממתין להשלמת משימת היצירה, ומחזיר את קובץ התלת-ממד המוגמר יחד עם מזהה המשימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור הטקסט של המודל שיש ליצור. אינו יכול להיות ריק. | STRING | כן | טקסט מרובה שורות |
| `negative_prompt` | טקסט המתאר מה לא אמור להופיע במודל שנוצר. עד 255 תווים. | STRING | לא | טקסט מרובה שורות, עד 255 תווים |
| `model_version` | גרסת המודל של Tripo המשמשת ליצירה (ברירת מחדל: `v3.1_20260211`). | COMBO | לא | רשימת גרסאות המודל הנתמכות של Tripo |
| `texture` | צור מפות טקסטורה. כיבוי מחזיר גאומטריה בלבד ומתעלם מ-`pbr` (ברירת מחדל: True). | BOOLEAN | לא | True<br>False |
| `pbr` | מפות חומר PBR (צבע בסיס, מטאליות, חספוס, נורמל). דורש `texture` (ברירת מחדל: True). | BOOLEAN | לא | True<br>False |
| `image_seed` | ערך seed ליצירת תמונה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `model_seed` | ערך seed ליצירת המודל (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `texture_seed` | ערך seed ליצירת טקסטורה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `texture_quality` | רמת פירוט הטקסטורה (ברירת מחדל: "standard"). "detailed" = טקסטורות HD, "extreme" = טקסטורות 8K Ultra. | COMBO | לא | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `face_limit` | מספר הפאות המקסימלי. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי (כ-1.4M פאות ב-v3.x standard, 2M ב-detailed). Tripo מגביל בשקט: v2.5 ב-500,000, רשתות quad ב-150,000 (ברירת מחדל: -1). | INT | לא | -1 עד 2000000 |
| `quad` | פלט רשת quad. Tripo מספק רשתות quad כקובצי FBX, כך שהתוצאה מגיעה בפלט FBX ופלט ה-GLB נשאר ריק (ברירת מחדל: False). | BOOLEAN | לא | True<br>False |
| `geometry_quality` | רמת פירוט הגאומטריה (ברירת מחדל: "standard"). | COMBO | לא | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | רשת low-poly עם טופולוגיה נקייה בסגנון עבודת יד (500-20,000 פאות, quad 500-10,000). מתאים ביותר לנושאים פשוטים; נושאים מורכבים עלולים להיכשל (ברירת מחדל: False). | BOOLEAN | לא | True<br>False |
| `auto_size` | מתאים את קנה המידה של מודלים עם טקסטורה לגודלם במציאות במטרים. Tripo שומר את הגודל כטרנספורמציית הסצנה של המודל ומטמיע אותו כאשר המודל מומר, עובר ריגינג או רטרגוט; מתעלמים ממנו כשאין טקסטורה (ברירת מחדל: True). | BOOLEAN | לא | True<br>False |

### הערות

- `prompt` הוא חובה ואינו יכול להיות ריק או להכיל רווחים בלבד.
- כאשר `texture` מוגדר ל-False, `pbr` נכפה לכבות, ול-`auto_size` אין השפעה.
- כאשר `smart_low_poly` מופעל ו-`face_limit` אינו -1, `face_limit` חייב להיות בין 500 ל-20,000 עבור רשתות משולשים, או בין 500 ל-10,000 כאשר `quad` מופעל.
- כאשר `quad` מופעל, Tripo מחזיר קובץ FBX, כך שפלט ה-`GLB` נשאר ריק ופלט ה-`FBX` מתמלא.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model task_id` | מזהה של משימת היצירה של Tripo שהפיקה את המודל. | MODEL_TASK_ID |
| `GLB` | המודל שנוצר בפורמט GLB. ריק כאשר `quad` מופעל. | FILE3D_GLB |
| `FBX` | המודל שנוצר בפורמט FBX. מתמלא רק כאשר `quad` מופעל. | FILE3D_FBX |
