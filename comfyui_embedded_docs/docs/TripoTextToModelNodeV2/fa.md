# TripoTextToModelNodeV2

با استفاده از سرویس Tripo یک مدل سه‌بعدی از روی توضیح متنی تولید می‌کند. این گره `prompt` و تنظیمات را به Tripo می‌فرستد، منتظر می‌ماند تا وظیفه تولید کامل شود، و فایل سه‌بعدی نهایی را همراه با شناسه وظیفه برمی‌گرداند.

## ورودی‌ها

|-----------|-------------|-----------|----------|-------|
| `پرامپت` | توضیح متنی مدلی که باید تولید شود. نباید خالی باشد. | STRING | بله | متن چندخطی |
| `پرامپت منفی` | متنی که توصیف می‌کند چه چیزی نباید در مدل تولیدشده ظاهر شود. حداکثر 255 کاراکتر. | STRING | خیر | متن چندخطی، حداکثر 255 کاراکتر |
| `نسخهٔ مدل` | نسخه مدل Tripo که برای تولید استفاده می‌شود (پیش‌فرض: `v3.1_20260211`). | COMBO | خیر | فهرست نسخه‌های مدل Tripo پشتیبانی‌شده |
| `بافت` | نقشه‌های بافت را تولید می‌کند. خاموش بودن آن هندسه بدون بافت برمی‌گرداند و `pbr` را نادیده می‌گیرد (پیش‌فرض: True). | BOOLEAN | خیر | True<br>False |

| `کیفیت هندسه` | سطح جزئیات هندسه (پیش‌فرض: "standard"). | COMBO | خیر | `"standard"`<br>`"detailed"` |

| `اندازه‌گذاری خودکار` | مدل‌های دارای بافت را به اندازه واقعی‌شان بر حسب متر مقیاس‌دهی می‌کند. Tripo اندازه را به‌عنوان ترنسفورم صحنه مدل ذخیره می‌کند و هنگام تبدیل، ریگ‌بندی یا ری‌تارگت مدل آن را bake می‌کند؛ بدون بافت نادیده گرفته می‌شود (پیش‌فرض: True). | BOOLEAN | خیر | True<br>False |

### یادداشت‌ها

- `prompt` الزامی است و نمی‌تواند خالی یا فقط شامل فاصله باشد.
- وقتی `texture` روی False تنظیم شود، `pbr` به‌اجبار خاموش می‌شود و `auto_size` اثری ندارد.
- وقتی `smart_low_poly` فعال است و `face_limit` برابر -1 نیست، `face_limit` باید برای مش‌های مثلثی بین 500 و 20,000 باشد، یا وقتی `quad` فعال است بین 500 و 10,000 باشد.
- با فعال بودن `quad`، Tripo یک فایل FBX برمی‌گرداند؛ بنابراین خروجی `GLB` خالی می‌ماند و خروجی `FBX` پر می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model task_id` | شناسه وظیفه تولید Tripo که مدل را تولید کرده است. | MODEL_TASK_ID |
| `GLB` | مدل تولیدشده در قالب GLB. وقتی `quad` فعال باشد خالی است. | FILE3D_GLB |
| `FBX` | مدل تولیدشده در قالب FBX. فقط وقتی `quad` فعال باشد پر می‌شود. | FILE3D_FBX |
