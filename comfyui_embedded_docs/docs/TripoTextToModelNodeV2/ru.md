# TripoTextToModelNodeV2

Создаёт 3D-модель по текстовому описанию с использованием сервиса Tripo. Узел отправляет промпт и настройки в Tripo, ожидает завершения задачи генерации и возвращает готовый 3D-файл вместе с идентификатором задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание модели для генерации. Не должно быть пустым. | STRING | Да | Многострочный текст |
| `negative_prompt` | Текст, описывающий, чего не должно быть в сгенерированной модели. До 255 символов. | STRING | Нет | Многострочный текст, максимум 255 символов |
| `model_version` | Версия модели Tripo, используемая для генерации (по умолчанию: `v3.1_20260211`). | COMBO | Нет | Список поддерживаемых версий модели Tripo |
| `texture` | Создавать карты текстуры. При отключении возвращает только геометрию и игнорирует `pbr` (по умолчанию: True). | BOOLEAN | Нет | True<br>False |
| `pbr` | Карты PBR-материала (основной цвет, металличность, шероховатость, нормали). Требует `texture` (по умолчанию: True). | BOOLEAN | Нет | True<br>False |
| `image_seed` | Значение seed для генерации изображения (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `model_seed` | Значение seed для генерации модели (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `texture_seed` | Значение seed для генерации текстуры (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `texture_quality` | Уровень детализации текстуры (по умолчанию: `"standard"`). `"detailed"` = HD-текстуры, `"extreme"` = 8K Ultra-текстуры. | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `face_limit` | Максимальное количество граней. -1 позволяет Tripo выбрать адаптивно (около 1,4 млн граней в v3.x standard, 2 млн в detailed). Tripo без предупреждения ограничивает: v2.5 — 500 000, quad-сетки — 150 000 (по умолчанию: -1). | INT | Нет | от -1 до 2000000 |
| `quad` | Вывод quad-сетки. Tripo выдаёт quad-сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым (по умолчанию: False). | BOOLEAN | Нет | True<br>False |
| `geometry_quality` | Уровень детализации геометрии (по умолчанию: `"standard"`). | COMBO | Нет | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | Низкополигональная сетка с чистой топологией в ручном стиле (500–20 000 граней, quad 500–10 000). Лучше всего подходит для простых объектов; для сложных генерация может не удаться (по умолчанию: False). | BOOLEAN | Нет | True<br>False |
| `auto_size` | Масштабировать модели с текстурами до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и запекает его при конвертации, риггинге или ретаргетинге модели; игнорируется без текстуры (по умолчанию: True). | BOOLEAN | Нет | True<br>False |

### Примечания

- `prompt` обязателен и не может быть пустым или состоять только из пробельных символов.
- Когда для `texture` установлено значение False, `pbr` принудительно отключается, а `auto_size` не действует.
- Когда `smart_low_poly` включён, а `face_limit` не равен -1, `face_limit` должен быть в диапазоне от 500 до 20 000 для треугольных сеток или от 500 до 10 000, когда `quad` включён.
- При включённом `quad` Tripo возвращает файл FBX, поэтому выход `GLB` остаётся пустым, а выход `FBX` заполняется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | Идентификатор задачи генерации Tripo, создавшей модель. | MODEL_TASK_ID |
| `GLB` | Сгенерированная модель в формате GLB. Пусто, когда `quad` включён. | FILE3D_GLB |
| `FBX` | Сгенерированная модель в формате FBX. Заполняется только когда `quad` включён. | FILE3D_FBX |
