# ImageCropToMask

חותך תמונה לתיבה התוחמת של המסכה שלה, ומייצר נושא ממורכז מעל צבע רקע אחיד. הצומת מרכיב את התמונה הממוסכת מעל הרקע הנבחר ומשנה את גודל התוצאה לממדי הפלט שצוינו, מה שהופך אותה למתאימה לצינורות עיבוד תלת-ממדיים שמצפים לנושא ממורכז ונקי מרקע ברזולוציה קבועה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | תמונת הקלט או אצוות תמונות לחיתוך. | IMAGE | כן | — |
| `masks` | המסכה או אצוות המסכות שמגדירות את אזור הנושא. מסכה בודדת מוחלת על כל התמונות; אחרת, גודל אצוות המסכות חייב להתאים לגודל אצוות התמונות. אם רזולוציית המסכה שונה מרזולוציית התמונה, המסכה תשתנה אוטומטית לגודל המתאים. | MASK | כן | — |
| `width` | רוחב הפלט בפיקסלים. (ברירת מחדל: 1024) | INT | כן | 64 עד 4096 (צעד 8) |
| `height` | גובה הפלט בפיקסלים. (ברירת מחדל: 1024) | INT | כן | 64 עד 4096 (צעד 8) |
| `pad_factor` | שוליים נוספים סביב התיבה התוחמת של המסכה כמכפיל. (ברירת מחדל: 1.0) | FLOAT | כן | 1.0 עד 2.0 (צעד 0.01) |
| `grow_mask` | מגדיל או מקטין את המסכה במספר הפיקסלים הזה לפני החיתוך. ערכים חיוביים מרחיבים את המסכה, ערכים שליליים מקטינים אותה. (ברירת מחדל: 0) | INT | כן | -32 עד 32 (צעד 1) |
| `background` | צבע הרקע מאחורי הנושא הממוסך. (ברירת מחדל: #000000) | COLOR | כן | — |

הערה: אזור החיתוך ממורכז סביב התיבה התוחמת של המסכה, ויחס הגובה-רוחב שלו תואם את `width` / `height`. הצומת מזהה ומתקן אוטומטית מסכה הפוכה (פיקסלי חזית לאורך השוליים, רקע במרכז). אם המסכה אינה מכילה פיקסלי חזית, הצומת מנסה את המסכה ההפוכה; אם גם זו ריקה, הוא רושם אזהרה וחוצה את התמונה כולה. שגיאה מועלית כאשר גודל אצוות המסכות אינו תואם לגודל אצוות התמונות והוא אינו מייצג מסכה בודדת.
