# ImageCropToMask

將圖片裁剪到其遮罩的邊界框，產生在純色背景上的置中主體。此節點將帶遮罩的圖片合成到所選背景上，並將結果調整為指定的輸出尺寸，使其適合需要固定解析度下置中且無背景主體的 3D 流程。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `images` | 要裁剪的輸入圖片或圖片批次。 | IMAGE | 是 | — |
| `masks` | 定義主體區域的遮罩或遮罩批次。單一遮罩會套用至所有圖片；否則遮罩批次大小必須與圖片批次大小相符。如果遮罩解析度與圖片解析度不同，遮罩會自動調整大小以相符。 | MASK | 是 | — |
| `width` | 輸出寬度（像素）。（預設：1024） | INT | 是 | 64 至 4096（步長 8） |
| `height` | 輸出高度（像素）。（預設：1024） | INT | 是 | 64 至 4096（步長 8） |
| `pad_factor` | 遮罩邊界框周圍的額外邊距倍率。（預設：1.0） | FLOAT | 是 | 1.0 至 2.0（步長 0.01） |
| `grow_mask` | 裁剪前將遮罩擴張或收縮此像素數。正值會擴大遮罩，負值會縮小遮罩。（預設：0） | INT | 是 | -32 至 32（步長 1） |
| `background` | 帶遮罩主體後方的背景顏色。（預設：#000000） | COLOR | 是 | — |

注意：裁剪區域以遮罩的邊界框為中心，其長寬比與 `width` / `height` 相符。此節點會自動偵測並修正反相的遮罩（前景像素位於邊緣，背景位於中心）。如果遮罩中沒有前景像素，節點會嘗試反相的遮罩；若仍為空，則會記錄警告並裁剪整張圖片。當遮罩批次大小與圖片批次大小不符，且不是單一遮罩時，會引發錯誤。

## 輸出

| 輸出名 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `images` | 裁剪後的合成圖片（帶遮罩主體置於所選背景顏色上），已調整為 `width` x `height`。批次大小與輸入圖片批次相符。 | IMAGE |
