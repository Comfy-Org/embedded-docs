# 依遮罩裁切影像

此節點會將影像裁剪至其遮罩的邊界框，產生位於純色背景上且置中的主體。此節點會將套用遮罩的影像合成到所選背景上，並將結果調整為指定的輸出尺寸，使其適合需要固定解析度、置中且無背景主體的 3D 管線。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `images` | 要裁剪的輸入影像或影像批次。 | IMAGE | 是 | — |
| `masks` | 定義主體區域的遮罩或遮罩批次。單一遮罩會套用至所有影像；否則遮罩批次大小必須符合影像批次大小。若遮罩解析度與影像解析度不同，遮罩會自動調整大小以相符。 | MASK | 是 | — |
| `width` | 輸出寬度，單位為像素。（預設：1024） | INT | 是 | 64 到 4096（步長 8） |
| `height` | 輸出高度，單位為像素。（預設：1024） | INT | 是 | 64 到 4096（步長 8） |
| `pad_factor` | 在遮罩邊界框周圍增加的額外邊距，以乘數表示。（預設：1.0） | FLOAT | 是 | 1.0 到 2.0（步長 0.01） |
| `grow_mask` | 裁剪前將遮罩擴張或縮小此像素數。正值會擴張遮罩，負值會縮小遮罩。（預設：0） | INT | 是 | -32 到 32（步長 1） |
| `background` | 套用遮罩之主體後方的背景顏色。（預設：#000000） | COLOR | 是 | — |

注意：裁剪區域會以遮罩的邊界框為中心，且其長寬比會符合 `width` / `height`。此節點會自動偵測並修正反轉的遮罩（邊界處為前景像素、中心為背景）。若遮罩不包含任何前景像素，節點會嘗試反轉後的遮罩；若該遮罩也是空的，則記錄警告並裁剪整張影像。當遮罩批次大小與影像批次大小不符，且不是單一遮罩時，會拋出錯誤。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `images` | 裁剪後的合成影像（套用遮罩的主體位於所選背景顏色上），已調整為 `width` x `height`。批次大小會符合輸入影像批次。 | IMAGE |
