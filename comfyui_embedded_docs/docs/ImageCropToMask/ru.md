# ImageCropToMask

Обрезает изображение по ограничивающей рамке его маски, создавая центрированный объект на сплошном фоновом цвете. Узел компонует изображение с маской поверх выбранного фона и изменяет размер результата до указанных выходных размеров, что делает его подходящим для 3D-конвейеров, которые ожидают центрированный объект без фона с фиксированным разрешением.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Входное изображение или пакет изображений для обрезки. | IMAGE | Да | — |
| `маски` | Маска или пакет масок, определяющих область объекта. Одна маска применяется ко всем изображениям; в противном случае размер пакета масок должен соответствовать размеру пакета изображений. Если разрешение маски отличается от разрешения изображения, маска автоматически масштабируется до соответствующего размера. | MASK | Да | — |
| `ширина` | Ширина выходного изображения в пикселях. (по умолчанию: 1024) | INT | Да | 64 до 4096 (step 8) |
| `высота` | Высота выходного изображения в пикселях. (по умолчанию: 1024) | INT | Да | 64 до 4096 (step 8) |
| `pad_factor` | Дополнительный отступ вокруг ограничивающей рамки маски в виде множителя. (по умолчанию: 1.0) | FLOAT | Да | 1.0 до 2.0 (step 0.01) |
| `grow_mask` | Увеличить или уменьшить маску на указанное количество пикселей перед обрезкой. Положительные значения расширяют маску, отрицательные — сжимают её. (по умолчанию: 0) | INT | Да | -32 до 32 (step 1) |
| `фон` | Цвет фона позади объекта, заданного маской. (по умолчанию: #000000) | COLOR | Да | — |

Примечание: Область обрезки центрируется по ограничивающей рамке маски, и её соотношение сторон соответствует `width` / `height`. Узел автоматически обнаруживает и исправляет инвертированную маску (пиксели переднего плана по краям, фон в центре). Если маска не содержит пикселей переднего плана, узел пробует инвертированную маску; если она также пуста, выводится предупреждение и обрезается всё изображение. Ошибка возникает, когда размер пакета масок не совпадает с размером пакета изображений и при этом не является одной единственной маской.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `изображения` | Обрезанные составные изображения (объект с маской поверх выбранного фонового цвета), изменённые до размера `width` x `height`. Размер пакета соответствует входному пакету изображений. | IMAGE |
