# Обрезать изображение по маске

Обрезает изображение по ограничивающей рамке его маски, создавая центрированный объект на сплошном фоновом цвете. Узел накладывает изображение с применённой маской на выбранный фон и изменяет размер результата до указанных выходных размеров, что делает его пригодным для 3D-конвейеров, которые ожидают центрированный объект без фона при фиксированном разрешении.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Входное изображение или пакет изображений для обрезки. | IMAGE | Да | — |
| `маски` | Маска или пакет масок, определяющих область объекта. Одна маска применяется ко всем изображениям; в противном случае размер пакета масок должен совпадать с размером пакета изображений. Если разрешение маски отличается от разрешения изображения, маска автоматически масштабируется до соответствия. | MASK | Да | — |
| `ширина` | Ширина вывода в пикселях. (по умолчанию: 1024) | INT | Да | от 64 до 4096 (шаг 8) |
| `высота` | Высота вывода в пикселях. (по умолчанию: 1024) | INT | Да | от 64 до 4096 (шаг 8) |
| `pad_factor` | Дополнительный отступ вокруг ограничивающей рамки маски в виде множителя. (по умолчанию: 1.0) | FLOAT | Да | от 1.0 до 2.0 (шаг 0.01) |
| `grow_mask` | Расширить или сузить маску на указанное число пикселей перед обрезкой. Положительные значения расширяют маску, отрицательные — сужают её. (по умолчанию: 0) | INT | Да | от -32 до 32 (шаг 1) |
| `фон` | Цвет фона позади объекта, выделенного маской. (по умолчанию: #000000) | COLOR | Да | — |

Примечание: Область обрезки центрируется по ограничивающей рамке маски, а её соотношение сторон соответствует `width` / `height`. Узел автоматически обнаруживает и исправляет инвертированную маску (пиксели переднего плана по краям, фон в центре). Если маска не содержит пикселей переднего плана, узел пробует инвертированную маску; если и она пуста, он записывает предупреждение в журнал и обрезает изображение целиком. Ошибка возникает, когда размер пакета масок не совпадает с размером пакета изображений и маска не является единственной.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Обрезанные композитные изображения (объект, выделенный маской, поверх выбранного цвета фона), изменённые до `width` x `height`. Размер пакета совпадает с размером пакета входных изображений. | IMAGE |
