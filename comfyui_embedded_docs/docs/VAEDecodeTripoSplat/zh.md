# TripoSplat 解码

将 TripoSplat 的潜在表示解码为 3D 高斯溅射。此节点获取来自 TripoSplat 模型的采样潜在变量，并将其重建为一组 3D 高斯体，可通过修改生成的高斯体数量来调整密度。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 要解码的潜在样本 | LATENT | 是 | - |
| `vae` | TripoSplat VAE 解码器 | VAE | 是 | - |
| `num_gaussians` | 要生成的高斯体数量（向上取整为 32 的倍数）。262144 与八叉树的点密度匹配；值越高，同一批点的过采样越密集（更密，但没有新细节），并且按比例消耗更多的显存/时间。默认值：262144 | INT | 是 | 32 to 1048576 (step: 32) |
| `seed` | 为八叉树点采样器（全局随机数生成器）设定种子，以实现确定性解码。默认值：0 | INT | 是 | 0 to 18446744073709551615 |

**注意：** `num_gaussians` 的值会自动取整为 VAE 解码器每个点高斯体设置的倍数。实际使用的高斯体数量可能与输入值略有不同。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `splat` | 解码后的 3D 高斯溅射，包含位置、缩放、旋转、不透明度和球谐系数 | SPLAT |
