# رمزگشایی TripoSplat

یک نمایش نهفته (latent) از TripoSplat را به یک اسپلات گاوسی سه‌بعدی رمزگشایی کنید. این گره، نمونهٔ نهفتهٔ گرفته‌شده از مدل TripoSplat را می‌گیرد و آن را به مجموعه‌ای از گاوسی‌های سه‌بعدی بازسازی می‌کند که می‌توان تراکم آن را با تغییر تعداد گاوسی‌های تولیدشده تنظیم کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `samples` | نمونه‌های نهفته برای رمزگشایی | LATENT | بله | - |
| `vae` | رمزگشای VAE مدل TripoSplat | VAE | بله | - |
| `num_gaussians` | تعداد گاوسی‌هایی که تولید می‌شود (به مضربی از 32 گرد می‌شود). 262144 با تراکم نقطه‌ای اکت‌ری مطابقت دارد؛ مقادیر بالاتر همان نقاط را بیش‌نمونه‌برداری می‌کنند (تراکم بیشتر، اما جزئیات جدیدی اضافه نمی‌شود) و هزینهٔ VRAM/زمان را به‌طور متناسب افزایش می‌دهند. پیش‌فرض: 262144 | INT | بله | 32 to 1048576 (step: 32) |
| `seed` | نمونه‌بردار نقطهٔ اکت‌ری (RNG سراسری) را برای رمزگشایی‌های قطعی مقداردهی می‌کند. پیش‌فرض: 0 | INT | بله | 0 to 18446744073709551615 |

**نکته:** مقدار `num_gaussians` به‌طور خودکار به مضربی از تنظیم تعداد گاوسی‌ها در هر نقطهٔ رمزگشای VAE گرد می‌شود. تعداد واقعی ممکن است اندکی با مقدار ورودی متفاوت باشد.

## خروجی‌ها
