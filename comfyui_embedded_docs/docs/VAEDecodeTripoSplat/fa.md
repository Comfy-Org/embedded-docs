# رمزگشایی TripoSplat

یک نمایش نهفتهٔ TripoSplat را به یک اسپلات گاوسی سه‌بعدی رمزگشایی می‌کند. این گره نمونهٔ نهفتهٔ گرفته‌شده از مدل TripoSplat را بازسازی کرده و آن را به مجموعه‌ای از گاوسی‌های سه‌بعدی تبدیل می‌کند؛ تراکم این مجموعه با تغییر تعداد گاوسی‌های تولیدشده قابل تنظیم است.

## ورودی‌ها

| پارامتر | شرح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `نمونه‌ها` | نمونه‌های نهفته برای رمزگشایی. اگر نمونه‌ها حاوی جریان دوربین تو در تو در کنار نهفته باشند، فقط جریان نهفته رمزگشایی می‌شود. | LATENT | بله | - |
| `vae` | رمزگشای VAE مدل TripoSplat | VAE | بله | - |
| `تعداد گوسین‌ها` | تعداد گاوسی‌های تولیدشده (به مضربی از ۳۲ گرد می‌شود). مقدار 262144 با چگالی نقاط هشت‌درختی (octree) مطابقت دارد؛ مقادیر بالاتر همان نقاط را بیش‌نمونه‌برداری می‌کنند (تراکم بیشتر، اما بدون جزئیات جدید) و به همان نسبت VRAM و زمان بیشتری مصرف می‌کنند. پیش‌فرض: 262144 | INT | بله | 32 تا 1048576 (گام: 32) |
| `بذر` | نمونه‌بردار نقطهٔ هشت‌درختی (RNG سراسری) را برای رمزگشایی قطعی مقداردهی می‌کند. پیش‌فرض: 0 | INT | بله | 0 تا 18446744073709551615 |

**نکته:** مقدار `num_gaussians` به‌طور خودکار در محدودهٔ مجاز محدود شده و به مضربی از تنظیم گاوسی-بر-نقطهٔ رمزگشای VAE گرد می‌شود. تعداد واقعی استفاده‌شده ممکن است اندکی با مقدار ورودی متفاوت باشد.
