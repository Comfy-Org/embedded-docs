# TripoSplat 디코드

TripoSplat 잠재 표현을 3D 가우시안 스플랫으로 디코딩합니다. 이 노드는 TripoSplat 모델에서 샘플링된 잠재 표현을 가져와 3D 가우시안 집합으로 재구성하며, 생성되는 가우시안 수를 조정하여 밀도를 변경할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 디코딩할 잠재 샘플 | LATENT | 예 | - |
| `vae` | TripoSplat VAE 디코더 | VAE | 예 | - |
| `num_gaussians` | 생성할 가우시안 수(32의 배수로 반올림됨). 262144는 옥트리의 포인트 밀도와 일치합니다. 더 높은 값은 동일한 포인트를 과표본화하여(더 조밀하지만 새로운 디테일은 없음) VRAM/시간이 비례적으로 더 소모됩니다. 기본값: 262144 | INT | 예 | 32 to 1048576 (step: 32) |
| `seed` | 옥트리 포인트 샘플러(전역 RNG)를 시드하여 결정적 디코딩을 가능하게 합니다. 기본값: 0 | INT | 예 | 0 to 18446744073709551615 |

**참고:** `num_gaussians` 값은 VAE 디코더의 가우시안-포인트당 설정의 배수로 자동 반올림됩니다. 실제 사용되는 수는 입력 값과 약간 다를 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `splat` | 위치, 스케일, 회전, 불투명도 및 구면 조화 계수를 포함하는 디코딩된 3D 가우시안 스플랫 | SPLAT |
