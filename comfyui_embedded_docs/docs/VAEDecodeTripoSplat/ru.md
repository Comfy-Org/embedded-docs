# TripoSplat Декодирование

Декодирование скрытого представления TripoSplat в 3D-гауссов сплэт. Этот узел принимает сэмплированное скрытое представление из модели TripoSplat и восстанавливает его в виде набора 3D-гауссианов, плотность которых можно регулировать, изменяя количество создаваемых гауссианов.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Скрытые сэмплы для декодирования. Если сэмплы содержат вложенный поток камеры наряду со скрытым представлением, декодируется только поток скрытого представления. | LATENT | Да | - |
| `vae` | Декодер VAE TripoSplat | VAE | Да | - |
| `num_gaussians` | Количество генерируемых гауссианов (округляется до числа, кратного 32). Значение 262144 соответствует плотности точек октодерева; большее значение приводит к избыточной выборке тех же точек (плотнее, но без новых деталей) и требует пропорционально больше видеопамяти/времени. По умолчанию: 262144 | INT | Да | 32 до 1048576 (step: 32) |
| `seed` | Задает зерно для сэмплера точек октодерева (глобальный ГПСЧ) для детерминированного декодирования. По умолчанию: 0 | INT | Да | 0 до 18446744073709551615 |

**Примечание:** Значение `num_gaussians` автоматически ограничивается допустимым диапазоном и округляется до числа, кратного настройке декодера VAE (количество гауссианов на точку). Фактическое используемое число может незначительно отличаться от введённого значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `splat` | Декодированный 3D-гауссов сплэт, содержащий положения, масштабы, вращения, непрозрачности и коэффициенты сферических гармоник. | SPLAT |
