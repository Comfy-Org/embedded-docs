# TripoSplat Декодирование

Decode a TripoSplat latent representation into a 3D gaussian splat.

Этот узел принимает сэмплированный латент из модели TripoSplat и восстанавливает его как набор 3D-гауссов. Их плотность можно регулировать, изменяя количество генерируемых гауссов.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Латентные сэмплы для декодирования | LATENT | Да | - |
| `vae` | VAE-декодер TripoSplat | VAE | Да | - |
| `num_gaussians` | Количество генерируемых гауссов (округляется до кратного 32). 262144 соответствует плотности точек октодерева; большие значения избыточно дискретизируют те же точки (плотнее, но без новых деталей) и требуют пропорционально больше памяти/времени. По умолчанию: 262144 | INT | Да | 32 to 1048576 (step: 32) |
| `seed` | Задаёт начальное значение глобального ГПСЧ для сэмплирования точек октодерева, обеспечивая детерминированное декодирование. По умолчанию: 0 | INT | Да | 0 to 18446744073709551615 |

**Примечание:** Значение `num_gaussians` автоматически округляется до кратного настройке «гауссианов на точку» декодера VAE. Фактически используемое число может незначительно отличаться от указанного.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `splat` | Декодированный 3D-гауссов сплат, содержащий позиции, масштабы, повороты, непрозрачности и коэффициенты сферических гармоник | SPLAT |
