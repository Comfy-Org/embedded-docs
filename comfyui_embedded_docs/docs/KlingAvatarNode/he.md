# KlingAvatarNode

צומת Kling Avatar 2.0 מייצר סרטוני אדם דיגיטלי בסגנון שידור מתמונת ייחוס בודדת ומקובץ אודיו. הוא יוצר סרטון אווטאר מדבר, עם הנחיית טקסט אופציונלית להגדרת הפעולות, הרגשות ותנועות המצלמה של האווטאר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת ייחוס של האווטאר. הרוחב והגובה חייבים להיות לפחות 300px. יחס הגובה-רוחב חייב להיות בין 1:2.5 ל-2.5:1. | IMAGE | כן | - |
| `sound_file` | קלט אודיו. חייב להיות באורך של בין 2 ל-300 שניות. | AUDIO | כן | - |
| `mode` | מצב היצירה שבו יש להשתמש. | COMBO | כן | `"std"`<br>`"pro"` |
| `prompt` | הנחיה אופציונלית להגדרת הפעולות, הרגשות ותנועות המצלמה של האווטאר. (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `seed` | ה-Seed קובע אם הצומת תרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |

**הערה:** לקלטים `image` ו-`sound_file` יש דרישות ולידציה ספציפיות. התמונה חייבת להיות בגודל של לפחות 300x300 פיקסלים, עם יחס גובה-רוחב בין 1:2.5 ל-2.5:1. קובץ האודיו חייב להיות באורך של בין 2 ל-300 שניות.
