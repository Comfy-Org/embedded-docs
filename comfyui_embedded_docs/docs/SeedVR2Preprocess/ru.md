# Предобработка входных данных SeedVR2

Этот узел дополняет масштабированное изображение для подготовки к работе модели SeedVR2. В процессе обработки он удаляет альфа-канал, который позже восстанавливается сопутствующим узлом Post-Process SeedVR2 Output с использованием исходного масштабированного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | Масштабированное изображение для обработки. | IMAGE | Да | - |

Примечание: На вход может подаваться одно изображение или последовательность кадров (например, кадры видео). Его меньшая сторона должна быть не менее 2 пикселей. Во время обработки альфа-канал (если он присутствует) удаляется, значения пикселей ограничиваются диапазоном [0, 1], а ширина и высота дополняются до значений, кратных 16. Последовательности кадров дополняются так, чтобы их длина соответствовала ряду 1, 5, 9, 13, ... кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Дополненное изображение для кодирования VAE. | IMAGE |
