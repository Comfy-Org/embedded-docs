# Предобработка входных данных SeedVR2

Этот узел подготавливает изображение или видео с изменённым размером для модели SeedVR2, дополняя его до формы, которую ожидает модель. Значения пикселей ограничиваются диапазоном 0–1, высота и ширина дополняются до кратных 16, а количество кадров дополняется повторением последнего кадра, пока не будет соответствовать шаблону 4n+1 (1, 5, 9, 13, ...). Альфа-канал отбрасывается во время обработки; сопутствующий узел Post-Process SeedVR2 Output позже восстанавливает его из исходного изображения с изменённым размером.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | Изображение с изменённым размером для обработки. | IMAGE | Да | - |

Примечание: Входные данные могут быть одним кадром, последовательностью кадров или пакетом видео (4-D или 5-D тензоры IMAGE). Если у них больше 3 каналов, альфа-канал отбрасывается и сохраняется только RGB. Меньшая сторона входных данных должна быть не менее 2 пикселей. Пространственное дополнение заполняется чёрным (значение 0), а допустимое количество кадров соответствует шаблону 4n+1 (1, 5, 9, 13, ...).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Дополненное изображение для кодирования VAE. | IMAGE |
