# Предобработка входных данных SeedVR2

Этот узел подготавливает масштабированное изображение или видео для модели SeedVR2, дополняя его до формы, ожидаемой моделью. Во время обработки альфа-канал отбрасывается; вспомогательный узел Post-Process SeedVR2 Output восстанавливает его позже из исходного масштабированного изображения. Значения пикселей ограничиваются диапазоном 0–1, высота и ширина дополняются до значений, кратных 16, а количество кадров при необходимости дополняется повторением последнего кадра.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | Масштабированное изображение для обработки. | IMAGE | Да | - |

Примечание: входные данные могут быть одним кадром, последовательностью кадров или пакетом видео. Если каналов больше трёх, альфа-канал отбрасывается и сохраняется только RGB. Меньшая сторона входных данных должна быть не менее 2 пикселей. Пространственное заполнение выполняется чёрным цветом (значение 0), а допустимое количество кадров соответствует шаблону 4n+1 (1, 5, 9, 13, ...).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Дополненное изображение для кодирования VAE. | IMAGE |
