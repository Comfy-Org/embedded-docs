# 預處理 SeedVR2 輸入

此節點透過將調整大小後的影像或影片填充至模型預期的形狀，為 SeedVR2 模型做好準備。處理過程中會捨棄 Alpha 通道；搭配的「Post-Process SeedVR2 Output」節點會稍後從原始調整大小後的影像中還原該通道。像素值會被限制在 0 到 1 的範圍內，高度與寬度會填充至 16 的倍數，且在需要時透過重複最後一個影格來填充影格數量。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | 要處理的調整大小後影像。 | IMAGE | 是 | - |

注意：輸入可以是單一影格、一系列影格或一批影片。如果通道數超過 3，則會捨棄 Alpha 通道，僅保留 RGB。輸入的較短邊至少必須為 2 像素。空間填充以黑色（值 0）填入，有效的影格數量遵循 4n+1 模式（1、5、9、13、...）。
