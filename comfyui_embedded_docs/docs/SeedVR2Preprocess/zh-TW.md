此節點會為 SeedVR2 模型準備調整大小後的影像或影片，透過填充將其調整為模型預期的形狀。像素值會被限制在 0-1 範圍內，高度與寬度會填充至 16 的倍數，而影格數量則會透過重複最後一個影格來填充，直到符合 4n+1 模式（1、5、9、13、...）。處理過程中會捨棄 alpha 通道；搭配使用的 Post-Process SeedVR2 Output 節點會在後續從原始已調整大小的影像中將其還原。
