# SeedVR2 입력 전처리

이 노드는 크기가 조정된 이미지를 패딩하여 SeedVR2 모델에 맞게 준비합니다. 처리 과정에서 알파 채널이 제거되며, 이 채널은 나중에 함께 제공되는 Post-Process SeedVR2 Output 노드가 원본 크기 조정 이미지를 사용하여 복원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | 처리할 크기 조정된 이미지입니다. | IMAGE | 예 | - |

참고: 입력은 단일 이미지 또는 프레임 시퀀스(예: 비디오의 프레임)일 수 있습니다. 입력의 짧은 변은 최소 2픽셀 이상이어야 합니다. 처리 중에 알파 채널(있는 경우)이 제거되고, 픽셀 값은 [0, 1] 범위로 제한되며, 너비와 높이는 16의 배수로 패딩됩니다. 프레임 시퀀스는 길이가 1, 5, 9, 13, ... 프레임 패턴을 따르도록 패딩됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | VAE 인코딩을 위한 패딩된 이미지입니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SeedVR2Preprocess/ko.md)
