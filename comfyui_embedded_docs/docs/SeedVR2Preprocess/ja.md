# SeedVR2入力の前処理

このノードは、リサイズされた画像をパディングして SeedVR2 モデル用に準備します。処理中にアルファチャンネルを除去し、その後、対となる Post-Process SeedVR2 Output ノードが元のリサイズ画像を使用してアルファチャンネルを復元します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `resized_images` | 処理するリサイズ済み画像。 | IMAGE | はい | - |

注意: 入力は単一の画像または一連のフレーム（例: 動画のフレーム）です。その短辺は少なくとも2ピクセルである必要があります。処理中に、アルファチャンネル（存在する場合）は除去され、ピクセル値は [0, 1] にクランプされ、幅と高さは16の倍数にパディングされます。フレームシーケンスは、その長さが 1, 5, 9, 13, ... フレームのパターンに従うようにパディングされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | VAEエンコーディング用のパディング済み画像。 | IMAGE |
