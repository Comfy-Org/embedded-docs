# フォルダから画像とテキストデータセットを読み込む

このノードは、指定されたフォルダから画像とテキストキャプションのペアのデータセットを読み込み、リストとして返します。対応形式: PNG、JPG、JPEG、WEBP。各画像ファイルについて、ノードは自動的に同じベース名を持つ一致する `.txt` ファイルをキャプションとして探します。また、サブフォルダ名が数字プレフィックス（例: `10_folder_name`）で始まるフォルダ構造にも対応しており、そのサブフォルダ内の画像は、指定された回数だけ出力に繰り返し含まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `folder` | 画像とテキストキャプションを読み込むフォルダ。利用可能なオプションは、ComfyUIの入力ディレクトリ内のサブディレクトリです。 | COMBO | はい | *`folder_paths.get_input_subfolders()` から動的に読み込まれます* |

**注記:** ノードは特定のファイル構造を想定しています。各画像ファイル（`.png`、`.jpg`、`.jpeg`、`.webp`）について、同じ名前の `.txt` ファイルをキャプションとして探します。キャプションファイルが見つからない場合は、空の文字列が使用されます。また、サブフォルダ名が数字とアンダースコアで始まる特殊な構造（例: `5_cats`）にも対応しており、そのサブフォルダ内のすべての画像は、最終的な出力リストにその回数だけ繰り返し含まれます。選択されたフォルダはComfyUIの入力ディレクトリ内にある必要があります。ディレクトリ外に解決されるフォルダ名は拒否されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `images` | 読み込まれた画像テンソルのリスト。 | IMAGE |
| `texts` | 各読み込み画像に対応するテキストキャプションのリスト。 | STRING |
