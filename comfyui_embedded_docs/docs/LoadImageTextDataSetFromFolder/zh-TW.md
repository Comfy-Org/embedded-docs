# 從資料夾載入圖片與文字資料集

此節點會從選取的資料夾載入一組影像與文字標題配對，並將其作為列表傳回。它支援 PNG、JPG、JPEG 與 WEBP 影像，且會為每個影像尋找同一個基本名稱的 `.txt` 檔案作為標題。此節點也支援 kohya-ss/sd-scripts 資料夾結構，其中以數字開頭的子資料夾名稱（例如 `10_cats`）會讓該子資料夾內的影像在輸出中重複該次數。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `資料夾` | 要從中載入影像與文字標題的資料夾。 | COMBO | 是 | ComfyUI 輸入目錄內的子資料夾（動態載入） |

**注意：** 選取的資料夾必須是 ComfyUI 輸入目錄的子資料夾。此節點預期每個影像對應一個 `.txt` 標題檔案：對於每個影像檔案（`.png`、`.jpg`、`.jpeg`、`.webp`），它會在同一個位置尋找具有相同基本名稱的 `.txt` 檔案，並將其去除前後空白後的內容作為標題。若找不到標題檔案，則使用空字串。此節點也支援 kohya-ss/sd-scripts 資料夾結構：名稱以數字和底線開頭的子資料夾（例如 `5_cats`）會讓其中的影像在最終輸出列表中重複該數字次數。如果選取的資料夾沒有包含任何有效影像，節點會拋出錯誤。
