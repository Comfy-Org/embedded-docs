# 폴더에서 이미지 및 텍스트 데이터셋 불러오기

이 노드는 지정된 폴더에서 이미지와 텍스트 캡션 쌍으로 구성된 데이터셋을 로드하여 목록으로 반환합니다. 지원 형식: PNG, JPG, JPEG, WEBP. 각 이미지 파일에 대해 노드는 동일한 기본 이름을 가진 일치하는 `.txt` 파일을 자동으로 찾아 캡션으로 사용합니다. 또한 하위 폴더 이름이 숫자 접두사(예: `10_folder_name`)로 시작하는 폴더 구조를 지원하며, 해당 하위 폴더 안의 이미지는 출력에서 그 횟수만큼 반복됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `folder` | 이미지와 텍스트 캡션을 로드할 폴더입니다. 사용 가능한 옵션은 ComfyUI 입력 디렉터리 내의 하위 폴더입니다. | COMBO | 예 | *`folder_paths.get_input_subfolders()`에서 동적으로 로드됨* |

**참고:** 이 노드는 특정 파일 구조를 요구합니다. 각 이미지 파일(`.png`, `.jpg`, `.jpeg`, `.webp`)에 대해 동일한 이름의 `.txt` 파일을 찾아 캡션으로 사용합니다. 캡션 파일이 없으면 빈 문자열이 사용됩니다. 또한 하위 폴더 이름이 숫자와 밑줄로 시작하는 특별한 구조(예: `5_cats`)를 지원하며, 해당 하위 폴더의 모든 이미지는 최종 출력 목록에서 그 횟수만큼 반복됩니다. 선택한 폴더는 ComfyUI 입력 디렉터리 내에 있어야 하며, 이 디렉터리 밖으로 확인되는 폴더 이름은 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 로드된 이미지 텐서의 목록입니다. | IMAGE |
| `texts` | 로드된 각 이미지에 해당하는 텍스트 캡션 목록입니다. | STRING |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/LoadImageTextDataSetFromFolder/ko.md)
