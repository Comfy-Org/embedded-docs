# Загрузить набор изображений и текстов из папки

Этот узел загружает набор пар «изображение-текст» (изображения и текстовые подписи) из выбранной папки и возвращает их в виде списка. Он поддерживает изображения PNG, JPG, JPEG и WEBP; для каждого изображения ищется подпись в файле `.txt` с тем же базовым именем. Узел также поддерживает структуру папок kohya-ss/sd-scripts, где имя подпапки, начинающееся с числа (например, `10_cats`), повторяет изображения внутри этой подпапки в выводе соответствующее количество раз.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `folder` | Папка, из которой загружаются изображения и текстовые подписи. | COMBO | Да | Подпапки внутри входного каталога ComfyUI (загружаются динамически) |

**Примечание:** Выбранная папка должна быть подпапкой входного каталога ComfyUI. Узел ожидает один файл подписи `.txt` на каждое изображение: для каждого файла изображения (`.png`, `.jpg`, `.jpeg`, `.webp`) он ищет файл `.txt` с тем же базовым именем в том же месте и использует его содержимое без ведущих и завершающих пробелов в качестве подписи. Если файл подписи не найден, используется пустая строка. Узел также поддерживает структуру папок kohya-ss/sd-scripts: подпапки, имя которых начинается с числа и символа подчёркивания (например, `5_cats`), повторяют изображения внутри них соответствующее количество раз в итоговом выходном списке. Если выбранная папка не содержит допустимых изображений, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Список загруженных изображений. Изображения преобразуются в RGB и нормализуются к диапазону float 0–1. | IMAGE |
| `texts` | Список текстовых подписей, по одной для каждого загруженного изображения. Подписи представляют собой содержимое соответствующего файла `.txt` без ведущих и завершающих пробелов; если файл подписи отсутствует, используется пустая строка. | STRING |
