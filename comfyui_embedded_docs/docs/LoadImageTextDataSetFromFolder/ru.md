# Загрузить набор изображений и текстов из папки

Этот узел загружает набор данных, состоящий из пар изображений и текстовых подписей, из указанной папки и возвращает их в виде списка. Поддерживаемые форматы: PNG, JPG, JPEG, WEBP. Для каждого файла изображения узел автоматически ищет соответствующий `.txt`-файл с тем же базовым именем, который используется в качестве подписи. Узел также поддерживает структуру папок, в которой имена вложенных папок начинаются с числового префикса (например, `10_folder_name`), что приводит к повторению изображений внутри этой вложенной папки соответствующее количество раз в выходных данных.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `folder` | Папка, из которой загружаются изображения и текстовые подписи. Доступные варианты — это вложенные папки внутри входной директории ComfyUI. | COMBO | Да | *Загружается динамически через `folder_paths.get_input_subfolders()`* |

**Примечание:** Узел ожидает определённую структуру файлов. Для каждого файла изображения (`.png`, `.jpg`, `.jpeg`, `.webp`) он ищет `.txt`-файл с тем же именем, который используется в качестве подписи. Если файл с подписью не найден, используется пустая строка. Узел также поддерживает специальную структуру, когда имя вложенной папки начинается с числа и подчёркивания (например, `5_cats`), что приводит к повторению всех изображений внутри этой вложенной папки указанное количество раз в итоговом выходном списке. Выбранная папка должна находиться внутри входной директории ComfyUI; имена папок, которые разрешаются в путь за её пределами, отклоняются.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Список загруженных тензоров изображений. | IMAGE |
| `texts` | Список текстовых подписей, соответствующих каждому загруженному изображению. | STRING |
