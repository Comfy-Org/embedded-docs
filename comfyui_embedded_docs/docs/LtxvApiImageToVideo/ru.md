# LTXV Изображение в Видео

Узел LTXV Image To Video создает профессиональное видео из одного стартового изображения. Он использует внешний API для создания видеопоследовательности на основе вашего текстового запроса, позволяя настроить длительность, разрешение и частоту кадров.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Первый кадр, который будет использоваться для видео. | IMAGE | Да | - |
| `model` | Модель ИИ для генерации видео. Модель «Pro» оптимизирована для качества, а модель «Fast» — для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | Текстовое описание, которое определяет содержимое и движение создаваемого видео. | STRING | Да | - |
| `duration` | Длительность видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | Выходное разрешение создаваемого видео. | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | Частота кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `generate_audio` | Если значение true, созданное видео будет включать сгенерированный ИИ звук, соответствующий сцене (по умолчанию: False). | BOOLEAN | Нет | - |

**Важные ограничения:**

* Вход `image` должен содержать ровно одно изображение.
* `prompt` должен содержать от 1 до 10 000 символов.
* Если вы выберете `duration` больше 10 секунд, необходимо использовать модель **"LTX-2 (Fast)"**, разрешение **"1920x1080"** и **25** FPS. Эта комбинация обязательна для более длинных видео.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Созданный видеофайл. | VIDEO |
