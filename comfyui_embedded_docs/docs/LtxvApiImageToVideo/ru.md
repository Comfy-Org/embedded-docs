# LTXV Изображение в Видео

Узел LTXV Image To Video создаёт видеоролик профессионального качества на основе одного исходного изображения. Он использует внешний API для создания видеопоследовательности по вашему текстовому запросу, позволяя настраивать длительность, разрешение и частоту кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Первый кадр, используемый для видео. | IMAGE | Да | - |
| `модель` | Модель ИИ для генерации видео. Модель "Pro" оптимизирована для качества, а модель "Fast" — для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `промпт` | Текстовое описание, которое определяет содержимое и движение генерируемого видео (по умолчанию: пусто). | STRING | Да | - |
| `длительность` | Длительность видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `разрешение` | Разрешение выходного видео. | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `кадров_в_секунду` | Частота кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `генерировать_аудио` | Если задано значение true, генерируемое видео будет включать аудио, созданное ИИ и соответствующее сцене (по умолчанию: False). | BOOLEAN | Нет | - |

**Важные ограничения:**

* Вход `image` должен содержать ровно одно изображение.
* Значение `prompt` должно содержать от 1 до 10 000 символов.
* Если вы выберете `duration` больше 10 секунд, необходимо использовать модель **"LTX-2 (Fast)"**, разрешение **"1920x1080"** и **25** кадров в секунду. Эта комбинация обязательна для более длинных видео.

**Примечание:** этот узел отмечен как устаревший.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сгенерированный видеофайл. | VIDEO |
