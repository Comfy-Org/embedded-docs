# LtxvApiImageToVideo

Узел LTXV Image To Video создаёт видео профессионального качества из одного начального изображения. Он использует внешний API для создания видеопоследовательности на основе вашего текстового запроса, позволяя настраивать длительность, разрешение и частоту кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Первый кадр, используемый для видео. | IMAGE | Да | - |
| `model` | ИИ-модель, используемая для генерации видео. Модель "Pro" оптимизирована для качества, а модель "Fast" — для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | Текстовое описание, которое направляет содержание и движение генерируемого видео (по умолчанию: пусто). | STRING | Да | - |
| `duration` | Длительность видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | Выходное разрешение генерируемого видео. | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | Кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `generate_audio` | Если true, генерируемое видео будет включать аудио, созданное ИИ и соответствующее сцене (по умолчанию: False). | BOOLEAN | Нет | - |

**Важные ограничения:**

* Вход `image` должен содержать ровно одно изображение.
* `prompt` должен быть длиной от 1 до 10 000 символов.
* Если вы выбираете `duration` длиннее 10 секунд, необходимо использовать модель **"LTX-2 (Fast)"**, разрешение **"1920x1080"** и **25** FPS. Эта комбинация требуется для более длинных видео.

**Примечание:** Этот узел помечен как устаревший. Оценочная стоимость, отображаемая на узле, зависит от выбранных `model`, `duration` и `resolution`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сгенерированный видеофайл. | VIDEO |
