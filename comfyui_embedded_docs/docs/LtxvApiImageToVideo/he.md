# LtxvApiImageToVideo

הצומת LTXV Image To Video יוצר סרטון באיכות מקצועית מתמונת התחלה בודדת. הוא משתמש ב-API חיצוני כדי ליצור רצף סרטון בהתבסס על פרומפט הטקסט שלך, ומאפשר לך להתאים את משך הזמן, הרזולוציה וקצב הפריימים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | הפריים הראשון שישמש לסרטון. | IMAGE | כן | - |
| `model` | מודל ה-AI שישמש ליצירת הסרטון. מודל "Pro" מותאם לאיכות, בעוד שמודל "Fast" מותאם למהירות. | COMBO | כן | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | תיאור טקסטואלי שמנחה את התוכן והתנועה של הסרטון שנוצר (ברירת מחדל: ריק). | STRING | כן | - |
| `duration` | אורך הסרטון בשניות (ברירת מחדל: 8). | COMBO | כן | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | רזולוציית הפלט של הסרטון שנוצר. | COMBO | כן | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | מספר הפריימים לשנייה בסרטון (ברירת מחדל: 25). | COMBO | כן | `25`<br>`50` |
| `generate_audio` | כאשר true, הסרטון שנוצר יכלול אודיו שנוצר ב-AI המתאים לסצנה (ברירת מחדל: False). | BOOLEAN | לא | - |

**אילוצים חשובים:**

* הקלט `image` חייב להכיל תמונה אחת בדיוק.
* הקלט `prompt` חייב להיות באורך שבין 1 ל-10,000 תווים.
* אם תבחר `duration` ארוך מ-10 שניות, עליך להשתמש במודל **"LTX-2 (Fast)"**, ברזולוציה **"1920x1080"** ובקצב **25** FPS. שילוב זה נדרש עבור סרטונים ארוכים יותר.

**הערה:** צומת זה מסומן כמיושן. העלות המשוערת המוצגת על הצומת תלויה ב-`model`, `duration` ו-`resolution` שנבחרו.
