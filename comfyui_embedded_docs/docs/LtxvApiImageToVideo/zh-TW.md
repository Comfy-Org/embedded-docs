# LTXV 圖片轉影片

LTXV Image To Video 節點會從單一起始圖片生成專業品質的影片。它使用外部 API，根據您的文字提示建立影片序列，讓您自訂長度、解析度和影格速率。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `圖片` | 作為影片第一幀的圖片。 | IMAGE | 是 | - |
| `模型` | 用於影片生成的 AI 模型。「Pro」模型針對品質最佳化，而「Fast」模型針對速度最佳化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `提示詞` | 引導生成影片內容與動作的文字描述（預設：空）。 | STRING | 是 | - |
| `持續時間` | 影片長度（秒）（預設：8）。 | COMBO | 是 | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `解析度` | 生成影片的輸出解析度。 | COMBO | 是 | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `幀率` | 影片的每秒影格數（預設：25）。 | COMBO | 是 | `25`<br>`50` |
| `生成音訊` | 當設為 true 時，生成的影片將包含與場景相符的 AI 生成音訊（預設：False）。 | BOOLEAN | 否 | - |

**重要限制：**

* `image` 輸入必須只包含一張圖片。
* `prompt` 的長度必須介於 1 到 10,000 個字元之間。
* 如果您選擇的 `duration` 超過 10 秒，則必須使用 **"LTX-2 (Fast)"** 模型、**"1920x1080"** 解析度以及 **25** FPS。較長的影片需要此組合。

**注意：** 此節點已標記為已棄用。
