# LtxvApiImageToVideo

گره LTXV Image To Video یک ویدئو با کیفیت حرفه‌ای را از یک تصویر آغازین تولید می‌کند. این گره از یک API خارجی برای ساخت دنباله ویدئو بر اساس متن راهنمای شما استفاده می‌کند و به شما امکان می‌دهد مدت، رزولوشن و نرخ فریم را سفارشی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | اولین فریم برای استفاده در ویدئو. | IMAGE | بله | - |
| `model` | مدل هوش مصنوعی برای تولید ویدئو. مدل "Pro" برای کیفیت بهینه شده است، در حالی که مدل "Fast" برای سرعت بهینه شده است. | COMBO | بله | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | توضیح متنی که محتوا و حرکت ویدئوی تولیدشده را هدایت می‌کند (پیش‌فرض: خالی). | STRING | بله | - |
| `duration` | طول ویدئو بر حسب ثانیه (پیش‌فرض: 8). | COMBO | بله | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | رزولوشن خروجی ویدئوی تولیدشده. | COMBO | بله | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | تعداد فریم در ثانیه برای ویدئو (پیش‌فرض: 25). | COMBO | بله | `25`<br>`50` |
| `generate_audio` | وقتی مقدار آن true باشد، ویدئوی تولیدشده شامل صدای تولیدشده توسط هوش مصنوعی متناسب با صحنه خواهد بود (پیش‌فرض: False). | BOOLEAN | خیر | - |

**محدودیت‌های مهم:**

* ورودی `image` باید دقیقاً شامل یک تصویر باشد.
* `prompt` باید بین 1 و 10,000 کاراکتر طول داشته باشد.
* اگر `duration` بیشتر از 10 ثانیه انتخاب کنید، باید از مدل **"LTX-2 (Fast)"**، رزولوشن **"1920x1080"** و **25** FPS استفاده کنید. این ترکیب برای ویدئوهای طولانی‌تر الزامی است.

**توجه:** این گره به‌عنوان منسوخ‌شده علامت‌گذاری شده است. هزینه تخمینی نمایش‌داده‌شده روی گره به `model`، `duration` و `resolution` انتخاب‌شده بستگی دارد.
