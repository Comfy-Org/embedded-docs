# تبدیل تصویر به ویدیو LTXV

گره LTXV Image To Video یک ویدیوی با کیفیت حرفه‌ای از یک تصویر شروع واحد تولید می‌کند. این گره از یک API خارجی برای ساخت سکانس ویدیویی بر اساس متن پرامپت شما استفاده می‌کند و به شما امکان می‌دهد مدت‌زمان، وضوح و نرخ فریم را سفارشی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | اولین فریمی که برای ویدیو استفاده می‌شود. | IMAGE | بله | - |
| `model` | مدل هوش مصنوعی مورد استفاده برای تولید ویدیو. مدل «Pro» برای کیفیت بهینه شده است، در حالی که مدل «Fast» برای سرعت بهینه شده است. | COMBO | بله | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | توصیف متنی که محتوا و حرکت ویدیوی تولیدشده را هدایت می‌کند. | STRING | بله | - |
| `duration` | طول ویدیو بر حسب ثانیه (پیش‌فرض: ۸). | COMBO | بله | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | وضوح خروجی ویدیوی تولیدشده. | COMBO | بله | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | نرخ فریم بر ثانیه برای ویدیو (پیش‌فرض: ۲۵). | COMBO | بله | `25`<br>`50` |
| `generate_audio` | هنگامی که مقدار آن `true` باشد، ویدیوی تولیدشده شامل صدای تولیدشده توسط هوش مصنوعی مطابق با صحنه خواهد بود (پیش‌فرض: `False`). | BOOLEAN | خیر | - |

**محدودیت‌های مهم:**

* ورودی `image` باید دقیقاً شامل یک تصویر باشد.
* طول `prompt` باید بین ۱ تا ۱۰,۰۰۰ کاراکتر باشد.
* اگر `duration` طولانی‌تر از ۱۰ ثانیه انتخاب کنید، باید از مدل **"LTX-2 (Fast)"**، وضوح **"1920x1080"** و نرخ فریم **۲۵** استفاده کنید. این ترکیب برای ویدیوهای طولانی‌تر الزامی است.
