# Kling 3.0 Omni תמונה

צומת Kling Omni Image (Pro) יוצר או עורך תמונות באמצעות מודל Kling AI העדכני ביותר. הוא מייצר תמונות על בסיס תיאור טקסטואלי ויכול להשתמש באופן אופציונלי בתמונות עזר כדי להנחות את הסגנון או התוכן. הצומת שולח בקשה ל-API חיצוני, שמעבד את המשימה ומחזיר את התמונה/התמונות הסופיות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_name` | מודל Kling AI הספציפי שבו יש להשתמש ליצירת התמונה. | COMBO | כן | `"kling-v3-omni"`<br>`"kling-image-o1"` |
| `prompt` | הנחיית טקסט המתארת את תוכן התמונה. זה יכול לכלול גם תיאורים חיוביים וגם תיאורים שליליים. הטקסט חייב להיות באורך שבין 1 ל-2500 תווים. ניתן להשתמש ב-`@image`, `@image1`, `@image2` וכו' או ב-`@video`, `@video1`, `@video2` וכו' כדי להפנות לתמונות או סרטונים שהועלו בהנחיה. | STRING | כן | - |
| `resolution` | רזולוציית היעד עבור התמונה שתיווצר. הערה: רזולוציית 4K אינה נתמכת עבור המודל `kling-image-o1`. | COMBO | כן | `"1K"`<br>`"2K"`<br>`"4K"` |
| `aspect_ratio` | יחס הרוחב-גובה הרצוי (רוחב לגובה) עבור התמונה שתיווצר. | COMBO | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"3:2"`<br>`"2:3"`<br>`"21:9"` |
| `series_amount` | יצירת סדרת תמונות. תכונה זו אינה נתמכת עבור המודל `kling-image-o1`. (ברירת מחדל: `"disabled"`) | COMBO | כן | `"disabled"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"` |
| `reference_images` | עד 10 תמונות עזר נוספות. כל תמונה חייבת להיות בגודל של לפחות 300 פיקסלים ברוחב ובגובה, ויחס הרוחב-גובה שלה חייב להיות בין 1:2.5 ל-2.5:1. | IMAGE | לא | - |
| `seed` | הפרמטר `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. (ברירת מחדל: 0) | INT | לא | 0 to 2147483647 |
