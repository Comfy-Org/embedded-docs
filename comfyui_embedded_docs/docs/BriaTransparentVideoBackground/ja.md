# Bria 動画背景除去（透明）

このノードは、Bria の AI サービスを使用して動画から背景を削除し、切り出したフレームとアルファマスクを返します。両方の出力をコンポジットノードに接続するか、Save WEBM ノードに渡して透明な動画を書き出します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `video` | 処理する入力動画。最大長は60秒です。 | VIDEO | はい | - |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 0） | INT | はい | 0 から 2147483647 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | 背景が削除された動画フレーム | IMAGE |
| `mask` | 動画フレームのアルファマスク。1は透明を意味します。 | MASK |
