# حذف پس‌زمینه ویدیو با Bria (شفاف)

این گره با استفاده از سرویس هوش مصنوعی Bria پس‌زمینه را از ویدیو حذف می‌کند و فریم‌های جدا شده را به همراه یک ماسک آلفا خروجی می‌دهد. هر دو خروجی را به یک گره ترکیب‌کننده متصل کنید، یا آن‌ها را به گره Save WEBM بدهید تا یک ویدیوی شفاف ذخیره شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | ویدیوی ورودی برای پردازش. ویدیو باید ۶۰ ثانیه یا کوتاه‌تر باشد. | VIDEO | بله | - |
| `seed` | سید کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید غیرقطعی هستند (پیش‌فرض: ۰) | INT | بله | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصاویر` | فریم‌های ویدیو با حذف پس‌زمینه، به‌صورت تصاویر RGB در محدوده ۰.۰ تا ۱.۰ | IMAGE |
| `ماسک` | ماسک آلفا برای فریم‌های ویدیو، مطابق با قرارداد Load Image که در آن ۱ به معنای شفاف است | MASK |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/BriaTransparentVideoBackground/fa.md)
