# BriaTransparentVideoBackground

צומת זה מסיר את הרקע מווידאו באמצעות שירות ה-AI של Bria ומפיק את הפריימים החתוכים יחד עם מסכת אלפא. חבר את שני הפלטים לצומת קומפוזיציה, או הזן אותם לצומת Save WEBM כדי לכתוב וידאו שקוף.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | הווידאו הקלטי לעיבוד. הווידאו חייב להיות באורך 60 שניות או פחות. | VIDEO | כן | - |
| `seed` | ערך ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `images` | פריימי הווידאו עם הרקע שהוסר, כתמונות RGB בטווח 0.0 עד 1.0 | IMAGE |
| `mask` | מסכת האלפא עבור פריימי הווידאו, לפי המוסכמה של Load Image שבה 1 פירושו שקוף | MASK |
