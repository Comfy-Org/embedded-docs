# Bria Удаление фона видео (прозрачный)

Этот узел удаляет фон из видео с помощью ИИ-сервиса Bria и выводит кадры с вырезанным фоном вместе с альфа-маской. Подключите оба выхода к узлу композитинга или подайте их на узел Save WEBM, чтобы записать видео с прозрачностью.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Входное видео для обработки. Длительность видео не должна превышать 60 секунд. | VIDEO | Да | - |
| `seed` | Seed управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от seed (по умолчанию: 0) | INT | Да | 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `изображения` | Кадры видео с удалённым фоном в виде RGB-изображений в диапазоне от 0.0 до 1.0 | IMAGE |
| `маска` | Альфа-маска для кадров видео, согласно соглашению Load Image, где 1 означает прозрачность | MASK |
