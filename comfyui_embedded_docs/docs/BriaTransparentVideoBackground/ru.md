# Bria Удаление фона видео (прозрачный)

Этот узел удаляет фон из видео с помощью ИИ-сервиса Bria и возвращает вырезанные кадры вместе с альфа-маской. Подключите оба выхода к узлу композиции или передайте их в узел Save WEBM для записи прозрачного видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Входное видео для обработки. Максимальная длительность — 60 секунд. | VIDEO | Да | - |
| `seed` | Сид управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | 0 to 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Кадры видео с удалённым фоном | IMAGE |
| `mask` | Альфа-маска для кадров видео, где 1 означает прозрачность | MASK |
