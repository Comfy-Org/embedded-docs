# Flux 影片編輯

根據書面指令編輯現有影片片段。您可以移除、新增或替換物件、變更場景設定、重新調整影片風格、變更畫面文字，或替換口說對話。長度、取景、攝影機運動與音訊皆來自來源片段，因此任何您在 `prompt` 中未提及的內容都會維持原樣。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 來源片段長度為 0.7 到 15 秒，且至少為 160x160 像素。輸出會以 24 fps 渲染，且每幀上限約為 0.9 百萬像素，因此較大的來源會以較小尺寸返回。 | VIDEO | 是 | 0.7 到 15 秒；最小 160x160 像素 |
| `提示詞` | 要以淺白語言說明要變更的內容，最多 4096 個字元。任何未提及的內容都會維持原樣。替換的對話必須符合原始語音所佔的時間，而無聲片段會保持無聲。預設：空字串。 | STRING | 是 | 1 到 4096 個字元 |
| `自動縮小` | 在上傳前自動縮小面積大於 1280x704 像素的來源。會保留長寬比；較小的影片不會受到影響。預設：true。 | BOOLEAN | 否 | true<br>false |
| `安全容忍度` | 審核容忍度，0 為最嚴格。預設：4。 | INT | 否 | 0 到 4 |
| `種子` | 用於決定節點是否應重新執行的種子；FLUX 會自行選擇種子，因此無論此值為何，實際結果都是非確定性的。預設：42。 | INT | 否 | 0 到 4294967295 |

**注意：** `prompt` 必須至少包含 1 個字元，且不得超過 4096 個字元。來源 `video` 長度必須介於 0.7 到 15 秒之間，且至少為 160x160 像素；超出這些限制的上傳會在傳送請求前被拒絕。
