# RandomNoise

הצומת RandomNoise יוצר מחולל רעש המבוסס על ערך seed לשימוש במהלך תהליך הדגימה. אותו seed תמיד מפיק אותו דפוס רעש, מה שמאפשר תוצאות עקביות וניתנות לשחזור בין הרצות מרובות. דוגמים משתמשים ברעש שנוצר בעת עיבוד תמונות latent.
