# ランダムノイズ

RandomNoise ノードは、シード値に基づいてランダムなノイズパターンを生成します。さまざまな画像処理や生成タスクに使用できる再現可能なノイズを作成します。同じシードは常に同じノイズパターンを生成するため、複数回の実行で一貫した結果が得られます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `noise_seed` | ランダムノイズパターンの生成に使用するシード値です（デフォルト: 0）。同じシードは常に同じノイズ出力を生成します。生成後のコントロールが有効になっており、生成のたびにシード値をランダム化、固定、増分、または減分することができます。 | INT | はい | 0 から 18446744073709551615 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `noise` | 指定されたシード値に基づいて生成されたランダムノイズパターンです。 | NOISE |
