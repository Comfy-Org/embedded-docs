# Случайный шум

Узел RandomNoise создает генератор шума на основе значения seed для использования в процессе сэмплирования. Одно и то же seed всегда создает один и тот же паттерн шума, что обеспечивает стабильные и воспроизводимые результаты при многократных запусках. Сэмплеры используют сгенерированный шум при обработке латентных изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `сид_шума` | Значение seed, используемое для генерации случайного паттерна шума (по умолчанию: 0). Одно и то же seed всегда дает одинаковый шум на выходе. Этот вход включает опцию control-after-generate для автоматического обновления seed после каждой генерации. | INT | Да | 0 до 18446744073709551615 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `noise` | Объект шума, который генерирует случайный шум для латентных образцов на основе заданного значения seed. Используется сэмплерами в процессе сэмплирования. | NOISE |
