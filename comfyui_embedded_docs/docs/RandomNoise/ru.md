# Случайный шум

Узел RandomNoise генерирует случайные шумовые паттерны на основе значения seed. Он создает воспроизводимый шум, который можно использовать для различных задач обработки и генерации изображений. Одно и то же значение seed всегда дает одинаковый шумовой паттерн, что обеспечивает согласованные результаты при нескольких запусках.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `noise_seed` | Значение seed, используемое для генерации случайного шумового паттерна (по умолчанию: 0). Одно и то же значение seed всегда дает одинаковый шум на выходе. Включено управление после генерации, позволяющее рандомизировать, фиксировать, увеличивать или уменьшать значение seed после каждой генерации. | INT | Да | от 0 до 18446744073709551615 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `noise` | Сгенерированный случайный шумовой паттерн на основе предоставленного значения seed. | NOISE |
