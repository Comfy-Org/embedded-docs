# بارگذاری چک‌پوینت با تنظیمات (منسوخ‌شده)

گره CheckpointLoader یک checkpoint مدل از‌پیش آموزش‌دیده را همراه با فایل پیکربندی آن بارگذاری می‌کند. این گره یک فایل پیکربندی و یک فایل checkpoint را به عنوان ورودی می‌گیرد و اجزای مدل بارگذاری‌شده شامل مدل اصلی، مدل CLIP و مدل VAE را برای استفاده در گردش کار بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `config_name` | فایل پیکربندی که معماری و تنظیمات مدل را تعریف می‌کند | STRING | بله | فایل‌های پیکربندی موجود |
| `ckpt_name` | فایل checkpoint حاوی وزن‌ها و پارامترهای آموزش‌دیده مدل | STRING | بله | فایل‌های checkpoint موجود |

**توجه:** این گره نیازمند انتخاب هر دو فایل پیکربندی و فایل checkpoint است. فایل پیکربندی باید با معماری فایل checkpoint بارگذاری‌شده مطابقت داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مؤلفه مدل اصلی بارگذاری‌شده آماده برای استنتاج | MODEL |
| `CLIP` | مؤلفه مدل CLIP بارگذاری‌شده برای کدگذاری متن | CLIP |
| `VAE` | مؤلفه مدل VAE بارگذاری‌شده برای کدگذاری و کدگشایی تصویر | VAE |

**نکته مهم:** این گره به‌عنوان منسوخ (deprecated) علامت‌گذاری شده است و ممکن است در نسخه‌های آینده حذف شود. برای گردش کارهای جدید، استفاده از گره‌های جایگزین بارگذاری را در نظر بگیرید.
