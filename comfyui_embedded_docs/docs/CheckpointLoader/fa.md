# بارگذاری چک‌پوینت با تنظیمات (منسوخ‌شده)

گره CheckpointLoader یک checkpoint مدل از پیش‌آموزش‌دیده را به همراه فایل پیکربندی آن بارگذاری می‌کند. این گره یک فایل پیکربندی و یک فایل checkpoint را به عنوان ورودی دریافت می‌کند و اجزای مدل بارگذاری‌شده — مدل اصلی، مدل CLIP و مدل VAE — را برای استفاده در گردش کار بازمی‌گرداند. این گره منسوخ شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نام تنظیمات` | فایل پیکربندی که معماری و تنظیمات مدل را تعریف می‌کند | COMBO | بله | فایل‌های پیکربندی موجود |
| `نام چک‌پوینت` | فایل checkpoint شامل وزن‌ها و پارامترهای آموزش‌دیده مدل | COMBO | بله | فایل‌های checkpoint موجود |

**نکته:** این گره نیاز دارد که هم فایل پیکربندی و هم فایل checkpoint انتخاب شوند. فایل پیکربندی باید با معماری فایل checkpoint در حال بارگذاری مطابقت داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | کامپوننت مدل اصلی بارگذاری‌شده، آماده برای استنتاج | MODEL |
| `CLIP` | کامپوننت مدل CLIP بارگذاری‌شده برای رمزگذاری متن | CLIP |
| `VAE` | کامپوننت مدل VAE بارگذاری‌شده برای رمزگذاری و رمزگشایی تصویر | VAE |

**نکته مهم:** این گره به عنوان منسوخ‌شده علامت‌گذاری شده است و ممکن است در نسخه‌های آینده حذف شود. برای گردش کارهای جدید، استفاده از گره‌های بارگذاری جایگزین را در نظر بگیرید.
