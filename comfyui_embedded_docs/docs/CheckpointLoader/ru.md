# Загрузить сheckpoint с конфигурацией (УСТАРЕЛО)

Узел CheckpointLoader загружает контрольную точку предварительно обученной модели вместе с её конфигурационным файлом. Он принимает конфигурационный файл и файл контрольной точки в качестве входных данных и возвращает загруженные компоненты модели, включая основную модель, модель CLIP и модель VAE для использования в рабочем процессе.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `config_name` | Конфигурационный файл, определяющий архитектуру и настройки модели | STRING | Да | Доступные конфигурационные файлы |
| `ckpt_name` | Файл контрольной точки, содержащий веса и параметры обученной модели | STRING | Да | Доступные файлы контрольных точек |

**Примечание:** Для работы этого узла необходимо выбрать и конфигурационный файл, и файл контрольной точки. Конфигурационный файл должен соответствовать архитектуре загружаемой контрольной точки.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Загруженная основная модель, готовая к выполнению вывода | MODEL |
| `CLIP` | Загруженный компонент модели CLIP для кодирования текста | CLIP |
| `VAE` | Загруженный компонент модели VAE для кодирования и декодирования изображений | VAE |

**Важное примечание:** Этот узел помечен как устаревший и может быть удалён в будущих версиях. Для новых рабочих процессов рассмотрите возможность использования альтернативных узлов загрузки.
