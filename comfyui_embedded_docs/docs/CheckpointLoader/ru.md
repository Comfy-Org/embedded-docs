# Загрузить сheckpoint с конфигурацией (УСТАРЕЛО)

Узел CheckpointLoader загружает предварительно обученную модель (чекпоинт) вместе с её конфигурационным файлом. На вход подаются конфигурационный файл и файл чекпоинта, а на выходе возвращаются загруженные компоненты модели — основная модель, модель CLIP и модель VAE — для использования в рабочем процессе. Этот узел является устаревшим.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `название_конфигурации` | Конфигурационный файл, определяющий архитектуру и настройки модели | COMBO | Да | Доступные конфигурационные файлы |
| `название_точки_проверки` | Файл чекпоинта, содержащий веса и параметры обученной модели | COMBO | Да | Доступные файлы чекпоинтов |

**Примечание:** Этот узел требует выбора как конфигурационного файла, так и файла чекпоинта. Конфигурационный файл должен соответствовать архитектуре загружаемого файла чекпоинта.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Загруженный основной компонент модели, готовый к инференсу | MODEL |
| `CLIP` | Загруженный компонент модели CLIP для кодирования текста | CLIP |
| `VAE` | Загруженный компонент модели VAE для кодирования и декодирования изображений | VAE |

**Важное примечание:** Этот узел помечен как устаревший и может быть удалён в будущих версиях. Для новых рабочих процессов рассмотрите использование альтернативных узлов загрузки.
