# Breeze Text to Speech

Преобразует текст в речь с помощью Breeze TTS 2. Выберите голос Breeze, укажите язык текста и при необходимости задайте, как должна исполняться реплика. Для английского и китайского можно использовать любую из моделей Breeze TTS 2; для всех остальных языков используется Breeze TTS 2 Multilingual.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voice` | Голос Breeze для озвучивания, выбранный в Breeze Voice Selector или в одном из узлов создания голоса Breeze. | BREEZE_VOICE | Да | - |
| `text` | Текст для озвучивания, от 1 до 1000 символов. Аудиотеги, такие как `(laughs)` или `(sighs)`, воспроизводятся, а не читаются вслух. По умолчанию: пусто. | STRING | Да | от 1 до 1000 символов |
| `language` | Язык текста. Для английского и китайского можно использовать любую из моделей; для других языков используется Breeze TTS 2 Multilingual. Голос лучше всего звучит на своём языке, поэтому для другого языка используйте копию, созданную с помощью Breeze Voice Localize. | DYNAMIC_COMBO | Да | Доступно несколько вариантов |
| `delivery` | Как исполняется реплика: `neutral` сохраняет голос как есть, `directed` следует письменным инструкциям. По умолчанию: `"neutral"`. | DYNAMIC_COMBO | Да | `"neutral"`<br>`"directed"` |
| `speed` | Множитель темпа, не изменяющий высоту тона. По умолчанию: 1.0. | FLOAT | Нет | от 0.5 до 2.0 (шаг: 0.05) |
| `seed` | Управляет повторным запуском узла; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |

### Входы для языка "English" и "Chinese"

Появляются только когда `language` имеет значение English или Chinese.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | `Breeze TTS 2` или `Breeze TTS 2 Multilingual`. По умолчанию: `"Breeze TTS 2"`. | COMBO | Да | `"Breeze TTS 2"`<br>`"Breeze TTS 2 Multilingual"` |

### Входы для режима delivery "neutral"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `speaker_boost` | Сохраняет голос ближе к его исходному звучанию. По умолчанию: false. | BOOLEAN | Нет | true<br>false |

### Входы для режима delivery "directed"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `instructions` | Как исполнять текст; записывается на том же языке, что и текст. По умолчанию: пусто. | STRING | Нет | Многострочный текст |
| `strength` | Насколько строго голос следует инструкциям. По умолчанию: 4.0. | FLOAT | Нет | от 1.0 до 10.0 (шаг: 0.1) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Сгенерированная речь в виде WAV-аудио. | AUDIO |
