# MiniMax H3 Latent Upscale With Model

MiniMax H3 Latent Upscale With Model изменяет размер видеочасти латента MiniMax H3 до целевой ширины и высоты с помощью модели латентного апскейла. Аудиолатент передаётся без изменений, поэтому клип сохраняет звук и повторная дискретизация не требуется. Используйте его после сэмплирования MiniMax H3 и перед декодированием H3 VAE, когда клип должен получиться больше.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель латентного апскейла, обычно загружаемая с помощью Load Latent Upscale Model. Должна быть 3D-свёрточной моделью латентного апскейла MiniMax H3. | LATENT_UPSCALE_MODEL | Да | - |
| `samples` | Латент MiniMax H3 для изменения размера. Вложенный латент сохраняет свою аудиочасть как есть. | LATENT | Да | - |
| `width` | Целевая ширина видео в пикселях. Латент изменяется до `width / 16` столбцов, поэтому значение округляется вниз до кратного 16. (по умолчанию: 2560) | INT | Да | 32–16384 (шаг 32) |
| `height` | Целевая высота видео в пикселях, также округляется вниз до кратного 16. (по умолчанию: 1440) | INT | Да | 32–16384 (шаг 32) |

Если запрошенный размер уже совпадает с латентом, входной латент возвращается без изменений. У масштабированного латента нет `noise_mask`, поэтому частично маскированный латент теряет свою маску. Сеть выполняет 3D-свёртки временными блоками, благодаря чему использование памяти на длинных клипах остаётся близким к использованию для одного блока.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Латент с изменённым размером, готовый для декодирования H3 VAE. | LATENT |
