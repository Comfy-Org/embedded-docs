# MiniMax H3 Latent Upscale With Model

MiniMax H3 Latent Upscale With Model משנה את גודלו של חלק הווידאו ב-latent של MiniMax H3 לרוחב ולגובה יעד באמצעות מודל להגדלת latent. ה-latent של האודיו נשאר ללא שינוי, כך שהקליפ שומר על הצליל שלו ואין צורך בדגימה מחדש. יש להשתמש בו לאחר דגימת MiniMax H3 ולפני פענוח H3 VAE כאשר רוצים שהקליפ ייצא גדול יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל להגדלת latent, בדרך כלל נטען עם Load Latent Upscale Model. עליו להיות מגדיל latent תלת-ממדי (3D-conv) של MiniMax H3. | LATENT_UPSCALE_MODEL | כן | - |
| `samples` | latent של MiniMax H3 לשינוי גודל. latent מקונן שומר על חלק האודיו שלו כפי שהוא. | LATENT | כן | - |
| `width` | רוחב הווידאו ביעד בפיקסלים. ה-latent משתנה לגודל של `width / 16` עמודות, ולכן הערך מעוגל למטה לכפולה של 16. (ברירת מחדל: 2560) | INT | כן | 32 עד 16384 (צעד 32) |
| `height` | גובה הווידאו ביעד בפיקסלים, גם הוא מעוגל למטה לכפולה של 16. (ברירת מחדל: 1440) | INT | כן | 32 עד 16384 (צעד 32) |

כאשר הגודל המבוקש כבר תואם ל-latent, ה-latent שמתקבל בקלט מוחזר ללא שינוי. latent ששונה גודלו אינו נושא `noise_mask`, ולכן latent עם מסכה חלקית מאבד את המסכה שלו. הרשת מריצה את הקונבולוציות התלת-ממדיות שלה בפרוסות זמניות, מה שמשאיר את השימוש בזיכרון בקליפים ארוכים קרוב לזה של פרוסה בודדת.
