# Регулировка контрастности

Узел Adjust Contrast изменяет уровень контрастности входного изображения. Он работает путем регулировки разницы между светлыми и темными областями изображения. Коэффициент 1.0 оставляет изображение без изменений, значения ниже 1.0 уменьшают контраст, а значения выше 1.0 увеличивают его.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение, контраст которого необходимо отрегулировать. | IMAGE | Да | - |
| `factor` | Коэффициент контрастности. 1.0 = без изменений, <1.0 = меньше контраста, >1.0 = больше контраста. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 2.0 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Результирующее изображение с отрегулированным контрастом. | IMAGE |
