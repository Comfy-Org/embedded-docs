# GligenTextBoxApply

צומת `GLIGENTextBoxApply` מיועד לשילוב התניה מבוססת טקסט בקלט של מודל גנרטיבי, במיוחד על ידי החלת פרמטרים של תיבת טקסט וקידודם באמצעות מודל CLIP. תהליך זה מעשיר את ההתניה במידע מרחבי וטקסטואלי, ומאפשר יצירה מדויקת יותר ומודעת להקשר.

## קלטים

| פרמטר | תיאור | סוג נתונים ב-Comfy |
| --- | --- | --- |
| `conditioning_to` | מציין את קלט ההתניה הראשוני שאליו יצורפו פרמטרים של תיבת טקסט ומידע טקסט מקודד. יש לו תפקיד מכריע בקביעת הפלט הסופי על ידי שילוב נתוני התניה חדשים. | `CONDITIONING` |
| `clip` | מודל ה-CLIP המשמש לקידוד הטקסט שסופק לפורמט שניתן להשתמש בו במודל הגנרטיבי. הכרחי להמרת מידע טקסטואלי לפורמט התניה תואם. | `CLIP` |
| `gligen_textbox_model` | מייצג את תצורת מודל ה-GLIGEN הספציפית שתשמש ליצירת תיבת הטקסט. חיוני להבטחה שתיבת הטקסט תיווצר בהתאם למפרט הרצוי. | `GLIGEN` |
| `text` | תוכן הטקסט לקידוד ולשילוב בהתניה. מספק את המידע הסמנטי שמנחה את המודל הגנרטיבי. | `STRING` |
| `width` | רוחב תיבת הטקסט בפיקסלים. מגדיר את הממד המרחבי של תיבת הטקסט בתוך התמונה הנוצרת. | `INT` |
| `height` | גובה תיבת הטקסט בפיקסלים. בדומה לרוחב, מגדיר את הממד המרחבי של תיבת הטקסט בתוך התמונה הנוצרת. | `INT` |
| `x` | קואורדינטת ה-x של הפינה השמאלית העליונה של תיבת הטקסט בתוך התמונה הנוצרת. מציין את מיקום תיבת הטקסט אופקית. | `INT` |
| `y` | קואורדינטת ה-y של הפינה השמאלית העליונה של תיבת הטקסט בתוך התמונה הנוצרת. מציין את מיקום תיבת הטקסט אנכית. | `INT` |

## פלטים

| פרמטר | תיאור | סוג נתונים ב-Comfy |
| --- | --- | --- |
| `conditioning` | פלט ההתניה המועשר, הכולל את נתוני ההתניה המקוריים יחד עם פרמטרי תיבת הטקסט שנוספו ומידע הטקסט המקודד. משמש להנחות את המודל הגנרטיבי ליצירת פלטים מודעי הקשר. | `CONDITIONING` |
