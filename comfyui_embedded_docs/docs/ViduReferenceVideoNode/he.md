# הפקת וידאו מהפניות ב-Vidu

צומת Vidu Reference Video יוצר וידאו ממספר תמונות עזר והנחיית טקסט. הוא משתמש במודלים של בינה מלאכותית כדי ליצור תוכן וידאו עקבי המבוסס על התמונות והתיאור שסופקו. הצומת תומך בהגדרות וידאו שונות, כולל משך, יחס גובה-רוחב, רזולוציה ושליטה בתנועה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | שם המודל ליצירת וידאו (ברירת מחדל: "viduq1") | COMBO | כן | `"viduq1"` |
| `images` | תמונות לשימוש כתמונות עזר ליצירת וידאו עם סובייקטים עקביים (מקסימום 7 תמונות) | IMAGE | כן | - |
| `prompt` | תיאור טקסטואלי ליצירת וידאו | STRING | כן | - |
| `duration` | משך הווידאו בפלט בשניות (ברירת מחדל: 5) | INT | לא | 5-5 |
| `seed` | Seed ליצירת וידאו (0 עבור אקראי) (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `aspect_ratio` | יחס הגובה-רוחב של הווידאו בפלט | COMBO | לא | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `resolution` | הערכים הנתמכים עשויים להשתנות בהתאם למודל ולמשך (ברירת מחדל: "1080p") | COMBO | לא | `"1080p"` |
| `movement_amplitude` | משרעת התנועה של אובייקטים בפריים (ברירת מחדל: "auto") | COMBO | לא | `"auto"`<br>`"small"`<br>`"medium"`<br>`"large"` |

**אילוצים ומגבלות:**

- שדה `prompt` הוא חובה ואינו יכול להיות ריק
- מותר להשתמש במקסימום 7 תמונות כעזר
- לכל תמונה חייב להיות יחס גובה-רוחב בין 1:4 ל-4:1
- לכל תמונה חייבים להיות ממדים מינימליים של 128x128 פיקסלים
- משך הווידאו קבוע ל-5 שניות
