# MiniMaxH3FunControlNetApply

צומת זה מחיל MiniMax H3 Fun ControlNet על מודל טקסט-לווידאו בתור תיקון למודל. הוא יכול להשתמש בסרטון בקרה אופציונלי ובמסכה אופציונלית כדי לכוון את היצירה, ומחזיר עותק מתוקן של המודל להמשך דגימה. כאשר העוצמה מוגדרת ל-0, או כאשר לא מסופקים סרטון בקרה ולא מסכה, מוחזר מודל הקלט ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל הדיפוזיה שעליו מוחל תיקון ה-MiniMax H3 Fun ControlNet. | MODEL | כן | N/A |
| `model_patch` | תיקון ה-MiniMax H3 Fun ControlNet שאותות הבקרה שלו מוזרקים למודל; עליו להיות תואם ל-`model` הנתון. | MODEL_PATCH | כן | N/A |
| `vae` | VAE המשמש לקידוד פריימים של סרטון הבקרה וסרטון המקור למרחב הלטנטי שהמודל מצפה לו. | VAE | כן | N/A |
| `strength` | עוצמה כוללת של אפקט ה-ControlNet. כאשר מוגדר ל-0, הצומת לא עושה דבר ומחזיר את מודל הקלט ללא שינוי. (ברירת מחדל: 1.0) | FLOAT | כן | מינימום 0.0, מקסימום 10.0, צעד 0.01 |
| `start_percent` | תחילת טווח הדגימה, מבוטאת כאחוז מלוח הזמנים של הדגימה, שבו ה-ControlNet פעיל. הערך מומר פנימית לערך הסיגמה המתאים. זוהי הגדרה מתקדמת. (ברירת מחדל: 0.0) | FLOAT | כן | מינימום 0.0, מקסימום 1.0, צעד 0.001 |
| `end_percent` | סוף טווח הדגימה, מבוטא כאחוז מלוח הזמנים של הדגימה, שבו ה-ControlNet פעיל. הערך מומר פנימית לערך הסיגמה המתאים. זוהי הגדרה מתקדמת. (ברירת מחדל: 1.0) | FLOAT | כן | מינימום 0.0, מקסימום 1.0, צעד 0.001 |
| `control_video` | פריימי וידאו אופציונליים המשמשים כרמז חזותי ל-ControlNet. הפריימים משתנים בגודלם כדי להתאים לווידאו המיוצר ומקודדים עם ה-`vae`. | IMAGE | לא | N/A |
| `mask` | 1 מסמן את האזורים שיש ליצור מחדש. ערכי מסכה מעל 0.5 נחשבים לאזורים מסומנים. | MASK | לא | N/A |
| `source_video` | וידאו מאחורי המסכה; נקרא רק כאשר ניתנת מסכה. | IMAGE | לא | N/A |

הערה: כדי שלתיקון תהיה השפעה, `strength` חייב להיות גדול מ-0 ולפחות אחד מבין `control_video` או `mask` חייב להיות מסופק. מתעלמים מ-`source_video` אלא אם כן מסופקת `mask`; אם ניתנת `mask` ללא `source_video`, התוכן שמאחורי האזורים הממוסכים מטופל כשחור. כאשר מסופקים גם `control_video` וגם `mask`, רמז הבקרה משלב את תכונות סרטון הבקרה עם תוכן המקור הממוסך.
