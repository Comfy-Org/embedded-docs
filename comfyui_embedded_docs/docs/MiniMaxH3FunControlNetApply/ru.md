# Применить MiniMax H3 Fun ControlNet

Этот узел применяет MiniMax H3 Fun ControlNet к модели text-to-video как патч модели. Он может использовать необязательное контрольное видео и необязательную маску для управления генерацией и возвращает пропатченную копию модели для дальнейшего сэмплирования. Когда `strength` установлен в 0 или когда не предоставлены ни контрольное видео, ни маска, входная модель возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Диффузионная модель, к которой применяется патч MiniMax H3 Fun ControlNet. | MODEL | Да | N/A |
| `model_patch` | Патч MiniMax H3 Fun ControlNet, управляющие сигналы которого внедряются в модель; он должен быть совместим с указанной `model`. | MODEL_PATCH | Да | N/A |
| `vae` | VAE, используемый для кодирования кадров контрольного и исходного видео в латентное пространство, ожидаемое моделью. | VAE | Да | N/A |
| `strength` | Общая сила эффекта ControlNet. При значении 0 узел ничего не делает и возвращает входную модель без изменений. (по умолчанию: 1.0) | FLOAT | Да | мин 0.0, макс 10.0, шаг 0.01 |
| `start_percent` | Начало диапазона сэмплирования, выраженное в процентах от расписания сэмплирования, в течение которого ControlNet активен. Внутри преобразуется в эквивалентное значение sigma. Это расширенная настройка. (по умолчанию: 0.0) | FLOAT | Да | мин 0.0, макс 1.0, шаг 0.001 |
| `end_percent` | Конец диапазона сэмплирования, выраженный в процентах от расписания сэмплирования, в течение которого ControlNet активен. Внутри преобразуется в эквивалентное значение sigma. Это расширенная настройка. (по умолчанию: 1.0) | FLOAT | Да | мин 0.0, макс 1.0, шаг 0.001 |
| `control_video` | Необязательные кадры видео, используемые как визуальная подсказка для ControlNet. Кадры изменяются в размере, чтобы соответствовать генерируемому видео, и кодируются с помощью `vae`. | IMAGE | Нет | N/A |
| `mask` | 1 обозначает области для повторной генерации. Значения маски выше 0.5 считаются отмеченными областями. | MASK | Нет | N/A |
| `source_video` | Видео под маской; читается только при наличии маски. | IMAGE | Нет | N/A |

Примечание: Чтобы патч оказал эффект, `strength` должен быть больше 0, и должен быть передан хотя бы один из параметров `control_video` или `mask`. `source_video` игнорируется, если не предоставлена `mask`; если `mask` задана без `source_video`, содержимое за маскированными областями считается чёрным. Когда предоставлены и `control_video`, и `mask`, контрольная подсказка объединяет признаки контрольного видео с содержимым исходного видео под маской.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Пропатченная копия входной модели с применённым MiniMax H3 Fun ControlNet. Если `strength` равен 0 или не предоставлены контрольное видео или маска, возвращается исходная модель без изменений. | MODEL |
