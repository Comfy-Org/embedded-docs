# MiniMaxH3FunControlNetApply

Этот узел применяет MiniMax H3 Fun ControlNet к модели генерации видео из текста в качестве патча модели. Он может использовать необязательное управляющее видео и необязательную маску для направления генерации и возвращает пропатченную копию модели для дальнейшего сэмплирования. Когда сила (`strength`) установлена в 0 или не предоставлено ни управляющее видео, ни маска, входная модель возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Диффузионная модель, к которой применяется патч MiniMax H3 Fun ControlNet. | MODEL | Да | N/A |
| `model_patch` | Патч MiniMax H3 Fun ControlNet, чьи управляющие сигналы внедряются в модель; он должен быть совместим с заданной моделью `model`. | MODEL_PATCH | Да | N/A |
| `vae` | VAE, используемый для кодирования кадров управляющего и исходного видео в латентное пространство, ожидаемое моделью. | VAE | Да | N/A |
| `strength` | Общая сила эффекта ControlNet. Если установлено значение 0, узел ничего не делает и возвращает входную модель без изменений. (по умолчанию: 1.0) | FLOAT | Да | min 0.0, max 10.0, step 0.01 |
| `start_percent` | Начало диапазона сэмплирования, выраженное в процентах от графика сэмплирования, в течение которого ControlNet активен. Внутренне преобразуется в эквивалентное значение сигма. (по умолчанию: 0.0) | FLOAT | Да | min 0.0, max 1.0, step 0.001 |
| `end_percent` | Конец диапазона сэмплирования, выраженный в процентах от графика сэмплирования, в течение которого ControlNet активен. Внутренне преобразуется в эквивалентное значение сигма. (по умолчанию: 1.0) | FLOAT | Да | min 0.0, max 1.0, step 0.001 |
| `control_video` | Необязательные видеокадры, используемые в качестве визуальной подсказки для ControlNet. Кадры масштабируются в соответствии с генерируемым видео и кодируются с помощью `vae`. | IMAGE | Нет | N/A |
| `mask` | Значение 1 отмечает области для повторной генерации. Значения маски выше 0.5 считаются отмеченными областями. | MASK | Нет | N/A |
| `source_video` | Видео за маской; считывается только при наличии маски. | IMAGE | Нет | N/A |

Примечание: Чтобы патч действовал, значение `strength` должно быть больше 0, и необходимо указать хотя бы один из параметров `control_video` или `mask`. Параметр `source_video` игнорируется, если не задан `mask`; если `mask` задан без `source_video`, содержимое за маскированными областями считается чёрным.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Копия входной модели с патчем, к которой применён MiniMax H3 Fun ControlNet. Если `strength` равна 0 или не указано ни управляющее видео, ни маска, исходная модель возвращается без изменений. | MODEL |
