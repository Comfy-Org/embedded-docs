# اعمال MiniMax H3 Fun ControlNet

این گره یک MiniMax H3 Fun ControlNet را به‌عنوان یک پچ مدل روی یک مدل متن‌به‌ویدئو اعمال می‌کند. می‌تواند از یک ویدئوی کنترل اختیاری و یک ماسک اختیاری برای هدایت تولید استفاده کند و یک نسخه پچ‌شده از مدل را برای نمونه‌گیری بعدی برمی‌گرداند. زمانی که `strength` روی 0 تنظیم شود، یا وقتی نه ویدئوی کنترل و نه ماسک ارائه نشده باشد، مدل ورودی بدون تغییر برگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل دیفیوژنی که پچ MiniMax H3 Fun ControlNet روی آن اعمال می‌شود. | MODEL | بله | N/A |
| `model_patch` | پچ MiniMax H3 Fun ControlNet که سیگنال‌های کنترلی آن به مدل تزریق می‌شود؛ باید با `model` داده‌شده سازگار باشد. | MODEL_PATCH | بله | N/A |
| `vae` | VAE مورد استفاده برای رمزگذاری فریم‌های ویدئوی کنترل و منبع به فضای نهفته (latent) مورد انتظار مدل. | VAE | بله | N/A |
| `strength` | قدرت کلی اثر ControlNet. وقتی روی 0 تنظیم شود، گره کاری انجام نمی‌دهد و مدل ورودی را بدون تغییر برمی‌گرداند. (پیش‌فرض: 1.0) | FLOAT | بله | min 0.0, max 10.0, step 0.01 |
| `start_percent` | شروع بازه نمونه‌گیری، به‌صورت درصدی از زمان‌بندی نمونه‌گیری، که در آن ControlNet فعال است. این مقدار در داخل به مقدار سیگمای معادل تبدیل می‌شود. این یک تنظیم پیشرفته است. (پیش‌فرض: 0.0) | FLOAT | بله | min 0.0, max 1.0, step 0.001 |
| `end_percent` | پایان بازه نمونه‌گیری، به‌صورت درصدی از زمان‌بندی نمونه‌گیری، که در آن ControlNet فعال است. این مقدار در داخل به مقدار سیگمای معادل تبدیل می‌شود. این یک تنظیم پیشرفته است. (پیش‌فرض: 1.0) | FLOAT | بله | min 0.0, max 1.0, step 0.001 |
| `control_video` | فریم‌های ویدئویی اختیاری که به‌عنوان راهنمای بصری ControlNet استفاده می‌شوند. فریم‌ها برای تطبیق با ویدئوی تولیدشده تغییر اندازه داده می‌شوند و با `vae` رمزگذاری می‌شوند. | IMAGE | خیر | N/A |
| `mask` | مقدار 1 نواحی‌ای را علامت می‌زند که باید بازتولید شوند. مقادیر ماسک بالای 0.5 به‌عنوان نواحی علامت‌خورده در نظر گرفته می‌شوند. | MASK | خیر | N/A |
| `source_video` | ویدئوی پشت ماسک؛ فقط زمانی خوانده می‌شود که ماسکی داده شده باشد. | IMAGE | خیر | N/A |

نکته: برای اینکه پچ اثری داشته باشد، `strength` باید بزرگ‌تر از 0 باشد و حداقل یکی از `control_video` یا `mask` باید ارائه شود. `source_video` نادیده گرفته می‌شود مگر اینکه `mask` ارائه شده باشد؛ اگر `mask` بدون `source_video` داده شود، محتوای پشت نواحی ماسک‌شده سیاه در نظر گرفته می‌شود. وقتی هم `control_video` و هم `mask` ارائه شوند، راهنمای کنترل ویژگی‌های ویدئوی کنترل را با محتوای منبع ماسک‌شده ترکیب می‌کند.
