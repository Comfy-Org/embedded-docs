# MiniMaxH3FunControlNetApply

این گره یک MiniMax H3 Fun ControlNet را به‌صورت یک وصله‌ی مدل (model patch) بر روی یک مدل متن‌به‌ویدیو اعمال می‌کند. این گره می‌تواند از یک ویدیوی کنترلی اختیاری و یک ماسک اختیاری برای هدایت تولید استفاده کند و یک کپی وصله‌شده از مدل را برای نمونه‌برداری بیشتر بازمی‌گرداند. وقتی `strength` روی 0 تنظیم شود یا هیچ‌یک از ویدیوی کنترلی و ماسک ارائه نشود، مدل ورودی بدون تغییر بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل انتشار (diffusion model) که وصله‌ی MiniMax H3 Fun ControlNet روی آن اعمال می‌شود. | MODEL | بله | N/A |
| `model_patch` | وصله‌ی MiniMax H3 Fun ControlNet که سیگنال‌های کنترلی آن به مدل تزریق می‌شود؛ باید با `model` داده‌شده سازگار باشد. | MODEL_PATCH | بله | N/A |
| `vae` | VAE مورد استفاده برای کدگذاری فریم‌های ویدیوی کنترلی و منبع در فضای نهان (latent space) مورد انتظار مدل. | VAE | بله | N/A |
| `strength` | شدت کلی اثر ControlNet. وقتی روی 0 باشد، گره هیچ کاری انجام نمی‌دهد و مدل ورودی را بدون تغییر بازمی‌گرداند. (پیش‌فرض: 1.0) | FLOAT | بله | حداقل 0.0، حداکثر 10.0، گام 0.01 |
| `start_percent` | شروع محدوده‌ی نمونه‌برداری، به‌صورت درصدی از زمان‌بندی نمونه‌برداری، که در آن ControlNet فعال است. این مقدار به‌صورت داخلی به مقدار سیگمای معادل تبدیل می‌شود. (پیش‌فرض: 0.0) | FLOAT | بله | حداقل 0.0، حداکثر 1.0، گام 0.001 |
| `end_percent` | پایان محدوده‌ی نمونه‌برداری، به‌صورت درصدی از زمان‌بندی نمونه‌برداری، که در آن ControlNet فعال است. این مقدار به‌صورت داخلی به مقدار سیگمای معادل تبدیل می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | حداقل 0.0، حداکثر 1.0، گام 0.001 |
| `control_video` | فریم‌های ویدیویی اختیاری که به‌عنوان راهنمای بصری ControlNet استفاده می‌شوند. فریم‌ها برای تطبیق با ویدیوی تولیدشده تغییر اندازه داده شده و با `vae` کدگذاری می‌شوند. | IMAGE | خیر | N/A |
| `mask` | مقدار 1 نواحی را برای بازتولید مشخص می‌کند. مقادیر ماسک بالای 0.5 به‌عنوان نواحی علامت‌گذاری‌شده در نظر گرفته می‌شوند. | MASK | خیر | N/A |
| `source_video` | ویدیوی پشت ماسک؛ فقط زمانی خوانده می‌شود که ماسک داده شده باشد. | IMAGE | خیر | N/A |

نکته: برای اینکه وصله اثربخش باشد، `strength` باید بزرگ‌تر از 0 باشد و حداقل یکی از `control_video` یا `mask` ارائه شود. `source_video` نادیده گرفته می‌شود مگر اینکه `mask` ارائه شده باشد؛ اگر `mask` بدون `source_video` داده شود، محتوای پشت نواحی ماسک‌شده سیاه در نظر گرفته می‌شود.
