# ByteDanceImageReferenceNode

צומת ByteDance Image Reference יוצר סרטונים באמצעות הנחיית טקסט ואחת עד ארבע תמונות עזר. הוא שולח את התמונות ואת ההנחיה לשירות API חיצוני שיוצר סרטון התואם את התיאור שלך תוך שילוב הסגנון החזותי והתוכן מהתמונות שלך. הצומת מספק פקדים שונים עבור רזולוציית הסרטון, יחס הגובה-רוחב, משך ופרמטרים אחרים ליצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI לשימוש ליצירת סרטון (ברירת מחדל: `"seedance-1-0-lite-i2v-250428"`). | STRING | כן | `"seedance-1-0-pro-250528"`<br>`"seedance-1-0-lite-i2v-250428"` |
| `prompt` | הנחיית הטקסט המשמשת ליצירת הסרטון. | STRING | כן | - |
| `images` | תמונה אחת עד ארבע תמונות. כל תמונה חייבת להיות בין 300x300 ל-6000x6000 פיקסלים, עם יחס גובה-רוחב בין 0.4 ל-2.5. | IMAGE | כן | - |
| `resolution` | הרזולוציה של סרטון הפלט. | STRING | כן | `"480p"`<br>`"720p"` |
| `aspect_ratio` | יחס הגובה-רוחב של סרטון הפלט (ברירת מחדל: `"adaptive"`). | STRING | כן | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | משך סרטון הפלט בשניות (ברירת מחדל: 5). | INT | כן | 3 - 12 |
| `seed` | Seed לשימוש ליצירה (ברירת מחדל: 0). | INT | לא | 0 - 2147483647 |
| `watermark` | האם להוסיף סימן מים "AI generated" לסרטון (ברירת מחדל: False). | BOOLEAN | לא | - |

**הערה:** אסור שטקסט ההנחיה יכיל את מחרוזות הפרמטרים הבאות: `--resolution`, `--ratio`, `--duration`, `--seed`, או `--watermark`. ערכים אלה נשלטים אך ורק באמצעות ווידג'טי הקלט הייעודיים שלהם.
