# FLUX 3 Max Image to Video

FLUX 3 Max Image to Video анимирует от 1 до 10 изображений с помощью FLUX 3 Max. Каждое изображение становится кадром клипа: одно изображение открывает его, два становятся его первым и последним кадром, а большее количество распределяется по клипу или привязывается к выбранным вами моментам времени.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Как должна двигаться сцена и каким должен быть звук (по умолчанию: пусто). | STRING | Да | Многострочный текст |
| `keyframes` | Расширяемый слот: подключите от 1 до 10 изображений ключевых кадров в порядке воспроизведения, например `image_1`, `image_2` и т. д. Каждое изображение становится кадром клипа. | IMAGE | Да | от 1 до 10 изображений |
| `placement` | `"spread across the clip"` помещает первое изображение в начало, последнее — в конец, а остальные равномерно между ними; `"at times"` привязывает каждое изображение к выбранной вами секунде (по умолчанию: `"spread across the clip"`). | DYNAMIC_COMBO | Да | `"spread across the clip"`<br>`"at times"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` соответствует первому изображению ключевого кадра (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"21:9"`<br>`"2:1"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Длительность клипа в секундах (по умолчанию: `"5"`). | COMBO | Да | `"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"`<br>`"11"`<br>`"12"`<br>`"13"`<br>`"14"`<br>`"15"`<br>`"16"`<br>`"17"`<br>`"18"`<br>`"19"`<br>`"20"` |
| `resolution` | Разрешение выходного видео (по умолчанию: `"720p"`). | COMBO | Да | `"720p"`<br>`"1080p"` |
| `reasoning_level` | Насколько подробно модель анализирует и расширяет промпт перед генерацией. `"high"` занимает больше времени; цена та же (по умолчанию: `"high"`). | COMBO | Да | `"low"`<br>`"high"` |
| `generate_audio` | Генерировать синхронизированный звук. При выключении создаётся видео без звуковой дорожки (по умолчанию: true). | BOOLEAN | Да | `true`<br>`false` |
| `seed` | Сид, определяющий, будет ли узел запускаться повторно. Результаты недетерминированы независимо от этого значения (по умолчанию: 42). | INT | Да | от 0 до 2147483646 |

### Входы at times

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `times` | Одно время в секундах на изображение, через запятую и по возрастанию, например "0, 2.5, 5". Появляется только когда `placement` имеет значение `"at times"`. | STRING | Нет | Секунды через запятую |

Примечание: `prompt` должен содержать хотя бы один символ. `keyframes` должен содержать хотя бы одно изображение и не может содержать больше 10; пакетный ввод учитывается один раз для каждого изображения.

Если для `placement` задано `"spread across the clip"`, одно или два изображения передаются как начальное изображение и необязательное конечное изображение, а три или более размещаются на ключевых кадрах, равномерно распределённых по клипу с частотой 24 кадра в секунду.

Если для `placement` задано `"at times"`, `times` должен содержать одно значение для каждого изображения; эти значения должны возрастать, не могут быть отрицательными, а последнее время не может выходить за конец клипа.

Отображаемая стоимость рассчитывается на основе `resolution` и `duration`: для 720p тариф составляет $0.060775 за секунду, для 1080p — $0.103675 за секунду до 7 ноября 2026 года; после этой даты — $0.2431 и $0.4147 за секунду соответственно. Общая оценочная стоимость клипа отображается в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип, созданный из изображений ключевых кадров с выбранными соотношением сторон, длительностью, разрешением и настройкой звука. | VIDEO |
