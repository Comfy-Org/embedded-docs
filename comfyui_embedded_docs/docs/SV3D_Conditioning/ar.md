# تهيئة SV3D

تُهيّئ العقدة SV3D_Conditioning بيانات التكييف لتوليد فيديو ثلاثي الأبعاد باستخدام نموذج SV3D. تأخذ صورة أولية وتعالجها عبر مشفرات CLIP vision وVAE لإنشاء تكييف إيجابي وسلبي، إلى جانب تمثيل كامن. تُنشئ العقدة تسلسلات زوايا ارتفاع وسمت الكاميرا لتوليد فيديو متعدد الإطارات استنادًا إلى عدد إطارات الفيديو المحدد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip_vision` | نموذج CLIP vision المستخدم لترميز الصورة المدخلة | CLIP_VISION | نعم | - |
| `init_image` | الصورة الأولية التي تُستخدم كنقطة بداية لتوليد الفيديو ثلاثي الأبعاد | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصورة إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض الإخراج لإطارات الفيديو المُولَّدة (الافتراضي: 576، بخطوة 8) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع الإخراج لإطارات الفيديو المُولَّدة (الافتراضي: 576، بخطوة 8) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `video_frames` | عدد الإطارات المطلوب توليدها لتسلسل الفيديو (الافتراضي: 21) | INT | نعم | 1 إلى 4096 |
| `elevation` | زاوية ارتفاع الكاميرا بالدرجات للعرض ثلاثي الأبعاد (الافتراضي: 0.0، بخطوة 0.1) | FLOAT | نعم | -90.0 إلى 90.0 |

ملاحظة: يبدأ سمت الكاميرا عند 0 درجة ويزداد بمقدار ثابت في كل إطار بحيث تُكمل الكاميرا دورة كاملة بمقدار 360 درجة حول الجسم عبر الإطارات المُولَّدة. ويُحسب مقدار الزيادة لكل إطار على أنه 360 مقسومًا على (`video_frames` - 1)، مع استخدام حد أدنى للمقسوم عليه قدره 2 عند طلب إطار واحد فقط. تبقى قيمة `elevation` ثابتة لكل إطار.

يتم تغيير مقياس `init_image` إلى `width` و`height` المحددين قبل ترميز VAE، ويستخدم الكامن المُعاد أبعادًا مقدارها `video_frames` × 4 × (`height` // 8) × (`width` // 8).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | بيانات التكييف الإيجابي التي تحتوي على تضمينات الصورة ومعاملات الكاميرا للتوليد | CONDITIONING |
| `negative` | بيانات التكييف السلبي ذات التضمينات والكامنات المُصفَّرة للتوليد التبايني | CONDITIONING |
| `latent` | موتر كامن فارغ بأبعاد تطابق إطارات الفيديو والدقة المحددة | LATENT |
