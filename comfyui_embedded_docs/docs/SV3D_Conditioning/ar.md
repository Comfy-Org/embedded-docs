# تهيئة SV3D

تُحضّر عقدة SV3D_Conditioning بيانات التوجيه (Conditioning) لتوليد فيديو ثلاثي الأبعاد باستخدام نموذج SV3D. تأخذ العقدة صورة أولية وتعالجها عبر مُرمِّزات CLIP vision وVAE لإنشاء توجيه إيجابي وسلبي، بالإضافة إلى تمثيل كامن. وتُنشئ العقدة تسلسلات زاوية الارتفاع والسمت للكاميرا لتوليد فيديو متعدد الإطارات استنادًا إلى عدد إطارات الفيديو المحدد.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | نموذج رؤية CLIP المستخدم لترميز الصورة المدخلة | CLIP_VISION | نعم | - |
| `init_image` | الصورة الأولية التي تعمل كنقطة بداية لتوليد الفيديو ثلاثي الأبعاد | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصورة في الفضاء الكامن | VAE | نعم | - |
| `width` | العرض الناتج لإطارات الفيديو المُولّدة (الافتراضي: 576، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION (step of 8) |
| `height` | الارتفاع الناتج لإطارات الفيديو المُولّدة (الافتراضي: 576، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION (step of 8) |
| `video_frames` | عدد الإطارات المراد توليدها لتسلسل الفيديو (الافتراضي: 21) | INT | نعم | 1 to 4096 |
| `elevation` | زاوية ارتفاع الكاميرا بالدرجات للعرض ثلاثي الأبعاد، وتُطبَّق على كل إطار (الافتراضي: 0.0) | FLOAT | نعم | -90.0 to 90.0 (step of 0.1) |

ملاحظة: تبدأ زاوية سمت الكاميرا من 0 درجة وتزداد بمقدار 360 / (video_frames - 1) درجة لكل إطار، وبذلك تُكمل الكاميرا مدارًا كاملاً حول الكائن عبر التسلسل. وتُطبَّق قيمة `elevation` نفسها على جميع الإطارات.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | بيانات التوجيه الإيجابية التي تحتوي على تضمينات الصورة ومعاملات الكاميرا للتوليد | CONDITIONING |
| `negative` | بيانات التوجيه السلبية ذات التضمينات المُصفّرة للتوليد التبايني | CONDITIONING |
| `latent` | موتر كامن فارغ أبعاده تطابق عدد إطارات الفيديو والدقة المحددين | LATENT |
