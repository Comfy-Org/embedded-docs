# تهيئة SV3D

تقوم عقدة `SV3D_Conditioning` بتجهيز بيانات التكييف لتوليد فيديو ثلاثي الأبعاد باستخدام نموذج SV3D. تأخذ صورة أولية وتعالجها عبر ترميزات CLIP vision وVAE لإنشاء تكييف إيجابي وسلبي، بالإضافة إلى تمثيل كامن. تولّد العقدة تسلسلات زاوية الارتفاع وسمت الكاميرا لتوليد فيديو متعدد الإطارات بناءً على عدد إطارات الفيديو المحدد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `رؤية المقطع` | نموذج CLIP vision المستخدم لترميز صورة الإدخال | CLIP_VISION | نعم | - |
| `الصورة الأصلية` | الصورة الأولية التي تمثل نقطة البداية لتوليد الفيديو ثلاثي الأبعاد | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصورة إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الإخراج لإطارات الفيديو المولدة (الافتراضي: 576، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الإخراج لإطارات الفيديو المولدة (الافتراضي: 576، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `إطارات الفيديو` | عدد الإطارات المراد توليدها لتسلسل الفيديو (الافتراضي: 21) | INT | نعم | 1 إلى 4096 |
| `الارتفاع الزاوي` | زاوية ارتفاع الكاميرا بالدرجات للعرض ثلاثي الأبعاد (الافتراضي: 0.0) | FLOAT | نعم | -90.0 إلى 90.0 |

ملاحظة: تبدأ زاوية سمت الكاميرا من 0 درجة وتزداد بمقدار ثابت في كل إطار بحيث تكمل الكاميرا دورانًا كاملاً بزاوية 360 درجة حول الكائن عبر الإطارات المولدة. تظل قيمة `elevation` ثابتة لكل إطار.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | بيانات التكييف الإيجابي التي تحتوي على تضمينات الصورة ومعاملات الكاميرا للتوليد | CONDITIONING |
| `سلبي` | بيانات التكييف السلبي مع تضمينات وتمثيلات كامنة مصفّرة للتوليد التبايني | CONDITIONING |
| `كامِن` | موتر كامن فارغ بأبعاد تطابق إطارات الفيديو والدقة المحددين | LATENT |
