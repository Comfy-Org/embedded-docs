# SV3D条件付け

SV3D_Conditioning ノードは、SV3Dモデルを使用して3Dビデオ生成用の条件付けデータを準備します。初期画像を受け取り、CLIPビジョンとVAEエンコーダーを介して処理し、ポジティブ条件付けとネガティブ条件付け、および潜在表現を生成します。このノードは、指定されたビデオフレーム数に基づいて、マルチフレームビデオ生成用のカメラ仰角と方位角のシーケンスを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | 入力画像のエンコードに使用するCLIPビジョンモデル | CLIP_VISION | はい | - |
| `init_image` | 3Dビデオ生成の開始点となる初期画像 | IMAGE | はい | - |
| `vae` | 画像を潜在空間にエンコードするために使用するVAEモデル | VAE | はい | - |
| `width` | 生成するビデオフレームの出力幅（デフォルト: 576、8で割り切れる必要があります） | INT | はい | 16 から MAX_RESOLUTION（ステップ 8） |
| `height` | 生成するビデオフレームの出力高さ（デフォルト: 576、8で割り切れる必要があります） | INT | はい | 16 から MAX_RESOLUTION（ステップ 8） |
| `video_frames` | ビデオシーケンスとして生成するフレーム数（デフォルト: 21） | INT | はい | 1 から 4096 |
| `elevation` | 3Dビューにおけるカメラの仰角（度）。すべてのフレームに適用されます（デフォルト: 0.0） | FLOAT | はい | -90.0 から 90.0（ステップ 0.1） |

注記：カメラの方位角は0度から始まり、フレームごとに360 / (video_frames - 1)度ずつ増加するため、カメラはシーケンス全体でオブジェクトの周りを一周します。同じ`elevation`値がすべてのフレームに適用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | 生成用の画像埋め込みとカメラパラメータを含むポジティブ条件付けデータ | CONDITIONING |
| `negative` | 対照的な生成のためのゼロ化された埋め込みを含むネガティブ条件付けデータ | CONDITIONING |
| `latent` | 指定されたビデオフレーム数と解像度に一致する次元を持つ空の潜在テンソル | LATENT |
