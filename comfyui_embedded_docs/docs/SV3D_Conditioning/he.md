# SV3D_Conditioning

SV3D_Conditioning מכין נתוני התניה ליצירת וידאו תלת-ממדי באמצעות מודל SV3D. הוא מקבל תמונה ראשונית ומעבד אותה דרך מקודדי CLIP vision ו-VAE כדי ליצור התניה חיובית ושלילית, יחד עם ייצוג latent. הצומת מייצר רצפי elevation ו-azimuth של המצלמה ליצירת וידאו מרובה-פריימים בהתאם למספר פריימי הווידאו שצוין.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip_vision` | מודל CLIP vision המשמש לקידוד תמונת הקלט | CLIP_VISION | כן | - |
| `init_image` | התמונה הראשונית המשמשת כנקודת התחלה ליצירת וידאו תלת-ממדי | IMAGE | כן | - |
| `vae` | מודל VAE המשמש לקידוד התמונה למרחב latent | VAE | כן | - |
| `width` | רוחב הפלט עבור פריימי הווידאו שנוצרים (ברירת מחדל: 576, צעד של 8) | INT | כן | 16 to MAX_RESOLUTION |
| `height` | גובה הפלט עבור פריימי הווידאו שנוצרים (ברירת מחדל: 576, צעד של 8) | INT | כן | 16 to MAX_RESOLUTION |
| `video_frames` | מספר הפריימים ליצירה עבור רצף הווידאו (ברירת מחדל: 21) | INT | כן | 1 to 4096 |
| `elevation` | זווית ה-elevation של המצלמה במעלות עבור תצוגת התלת-ממד (ברירת מחדל: 0.0, צעד של 0.1) | FLOAT | כן | -90.0 to 90.0 |

הערה: ה-azimuth של המצלמה מתחיל ב-0 מעלות וגדל בכמות קבועה בכל פריים, כך שהמצלמה משלימה מסלול הקפה מלא של 360 מעלות סביב האובייקט לאורך הפריימים שנוצרים. התוספת בכל פריים מחושבת כ-360 חלקי (`video_frames` - 1), תוך שימוש במחלק מינימלי של 2 כאשר מתבקש פריים אחד בלבד. הערך `elevation` נשאר קבוע בכל פריים.

ה-`init_image` מותאמת ל-`width` ול-`height` שצוינו לפני קידוד VAE, וה-latent המוחזר משתמש בממדים של `video_frames` x 4 x (`height` // 8) x (`width` // 8).

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | נתוני ההתניה החיובית המכילים הטמעות תמונה ופרמטרי מצלמה ליצירה | CONDITIONING |
| `negative` | נתוני ההתניה השלילית עם הטמעות ו-latents מאופסים ליצירה קונטרסטיבית | CONDITIONING |
| `latent` | טנסור latent ריק עם ממדים התואמים למספר פריימי הווידאו והרזולוציה שצוינו | LATENT |
