# شرط‌گذاری SV3D

SV3D_Conditioning داده‌های شرطی‌سازی را برای تولید ویدئوی سه‌بعدی با مدل SV3D آماده می‌کند. یک تصویر اولیه می‌گیرد و آن را از طریق رمزگذارهای CLIP vision و VAE پردازش می‌کند تا شرطی‌سازی مثبت و منفی، همراه با یک نمایش latent، ایجاد کند. این گره دنباله‌های ارتفاع و آزیموت دوربین را برای تولید ویدئوی چندفریمی بر اساس تعداد مشخص‌شده فریم‌های ویدئو تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip vision` | مدل CLIP vision استفاده‌شده برای رمزگذاری تصویر ورودی | CLIP_VISION | بله | - |
| `تصویر اولیه` | تصویر اولیه‌ای که به‌عنوان نقطه شروع تولید ویدئوی سه‌بعدی عمل می‌کند | IMAGE | بله | - |
| `vae` | مدل VAE استفاده‌شده برای رمزگذاری تصویر در فضای latent | VAE | بله | - |
| `عرض` | عرض خروجی برای فریم‌های ویدئوی تولیدشده (پیش‌فرض: 576، گام: 8) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی برای فریم‌های ویدئوی تولیدشده (پیش‌فرض: 576، گام: 8) | INT | بله | 16 تا MAX_RESOLUTION |
| `فریم‌های ویدیو` | تعداد فریم‌هایی که برای دنباله ویدئو تولید می‌شود (پیش‌فرض: 21) | INT | بله | 1 تا 4096 |
| `ارتفاع زاویه` | زاویه ارتفاع دوربین بر حسب درجه برای نمای سه‌بعدی (پیش‌فرض: 0.0، گام: 0.1) | FLOAT | بله | -90.0 تا 90.0 |

نکته: زاویه آزیموت دوربین از 0 درجه شروع می‌شود و در هر فریم به مقدار ثابتی افزایش می‌یابد، به‌طوری‌که دوربین در طول فریم‌های تولیدشده یک مدار کامل 360 درجه دور شیء را کامل می‌کند. افزایش هر فریم به‌صورت 360 تقسیم بر (`video_frames` - 1) محاسبه می‌شود و زمانی که فقط یک فریم درخواست شود، حداقل مقسوم‌علیه 2 در نظر گرفته می‌شود. مقدار `elevation` برای همه فریم‌ها ثابت می‌ماند.

`init_image` پیش از رمزگذاری VAE به `width` و `height` مشخص‌شده مقیاس‌بندی می‌شود، و latent بازگردانده‌شده از ابعاد `video_frames` x 4 x (`height` // 8) x (`width` // 8) استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | داده‌های شرطی‌سازی مثبت شامل embeddingهای تصویر و پارامترهای دوربین برای تولید | CONDITIONING |
| `negative` | داده‌های شرطی‌سازی منفی با embeddingها و latentهای صفرشده برای تولید تقابلی | CONDITIONING |
| `latent` | یک تنسور latent خالی با ابعادی مطابق فریم‌های ویدئو و وضوح مشخص‌شده | LATENT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SV3D_Conditioning/fa.md)
