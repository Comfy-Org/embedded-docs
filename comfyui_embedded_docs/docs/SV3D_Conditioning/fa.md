# شرط‌گذاری SV3D

گره SV3D_Conditioning داده‌های شرطی‌سازی را برای تولید ویدیوی سه‌بعدی با استفاده از مدل SV3D آماده می‌کند. این گره یک تصویر اولیه دریافت می‌کند و آن را از طریق رمزگذارهای CLIP vision و VAE پردازش می‌کند تا شرطی‌سازی مثبت و منفی به همراه یک نمایش نهفته ایجاد کند. این گره توالی‌های ارتفاع و آزیموت دوربین را برای تولید ویدیوی چندفریمی بر اساس تعداد فریم‌های ویدیویی مشخص‌شده تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip vision` | مدل CLIP vision مورد استفاده برای رمزگذاری تصویر ورودی | CLIP_VISION | بله | - |
| `تصویر اولیه` | تصویر اولیه‌ای که به عنوان نقطه شروع برای تولید ویدیوی سه‌بعدی عمل می‌کند | IMAGE | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر به فضای نهفته | VAE | بله | - |
| `عرض` | عرض خروجی برای فریم‌های ویدیوی تولیدشده (پیش‌فرض: 576، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی برای فریم‌های ویدیوی تولیدشده (پیش‌فرض: 576، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `فریم‌های ویدیو` | تعداد فریم‌هایی که برای توالی ویدیو تولید می‌شود (پیش‌فرض: 21) | INT | بله | 1 تا 4096 |
| `ارتفاع زاویه` | زاویه ارتفاع دوربین بر حسب درجه برای نمای سه‌بعدی (پیش‌فرض: 0.0) | FLOAT | بله | 90.0- تا 90.0 |

نکته: آزیموت دوربین از 0 درجه شروع می‌شود و هر فریم به میزان ثابتی افزایش می‌یابد تا دوربین در طول فریم‌های تولیدشده یک مدار کامل 360 درجه به دور جسم بزند. مقدار `elevation` برای هر فریم ثابت می‌ماند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | داده‌های شرطی‌سازی مثبت شامل بردارهای نهفته تصویر و پارامترهای دوربین برای تولید | CONDITIONING |
| `منفی` | داده‌های شرطی‌سازی منفی با بردارهای نهفته و نمایش‌های نهفته صفرشده برای تولید تقابلی | CONDITIONING |
| `latent` | یک تنسور نهفته خالی با ابعادی مطابق با فریم‌های ویدیویی و وضوح مشخص‌شده | LATENT |
