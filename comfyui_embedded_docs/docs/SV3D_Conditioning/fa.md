# شرط‌گذاری SV3D

گره SV3D_Conditioning داده‌های شرطی‌سازی را برای تولید ویدیوی سه‌بعدی با استفاده از مدل SV3D آماده می‌کند. این گره یک تصویر اولیه می‌گیرد و آن را از طریق رمزگذارهای CLIP vision و VAE پردازش می‌کند تا شرطی‌سازی مثبت و منفی به همراه یک بازنمایی نهان ایجاد کند. این گره توالی‌های زاویه ارتفاع و آزیموت دوربین را برای تولید ویدیوی چندفریمی بر اساس تعداد فریم‌های ویدیویی مشخص‌شده تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | مدل CLIP vision که برای رمزگذاری تصویر ورودی استفاده می‌شود | CLIP_VISION | بله | - |
| `init_image` | تصویر اولیه‌ای که به‌عنوان نقطه شروع تولید ویدیوی سه‌بعدی عمل می‌کند | IMAGE | بله | - |
| `vae` | مدل VAE که برای رمزگذاری تصویر به فضای نهان استفاده می‌شود | VAE | بله | - |
| `width` | عرض خروجی برای فریم‌های ویدیویی تولیدشده (پیش‌فرض: 576، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `height` | ارتفاع خروجی برای فریم‌های ویدیویی تولیدشده (پیش‌فرض: 576، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `video_frames` | تعداد فریم‌هایی که باید برای توالی ویدیو تولید شوند (پیش‌فرض: 21) | INT | بله | 1 تا 4096 |
| `elevation` | زاویه ارتفاع دوربین بر حسب درجه برای نمای سه‌بعدی، که به هر فریم اعمال می‌شود (پیش‌فرض: 0.0) | FLOAT | بله | 90.0- تا 90.0 (گام 0.1) |

نکته: آزیموت دوربین از ۰ درجه شروع می‌شود و در هر فریم به میزان 360 / (video_frames - 1) درجه افزایش می‌یابد؛ بنابراین دوربین در طول توالی، یک چرخش کامل به دور جسم انجام می‌دهد. همان مقدار `elevation` به همه فریم‌ها اعمال می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | داده شرطی‌سازی مثبت شامل جاسازی‌های تصویر و پارامترهای دوربین برای تولید | CONDITIONING |
| `negative` | داده شرطی‌سازی منفی با جاسازی‌های صفرشده برای تولید تقابلی | CONDITIONING |
| `latent` | تانسور نهان خالی با ابعادی مطابق با فریم‌های ویدیویی و وضوح مشخص‌شده | LATENT |
