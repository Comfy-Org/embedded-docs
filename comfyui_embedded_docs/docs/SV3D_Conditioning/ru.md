# SV3D_Кондиционирование

Узел `SV3D_Conditioning` подготавливает данные кондиционирования для генерации 3D-видео с использованием модели SV3D. Он принимает исходное изображение и обрабатывает его через энкодеры CLIP vision и VAE для создания положительного и отрицательного кондиционирования, а также латентного представления. Узел генерирует последовательности углов возвышения и азимута камеры для генерации многокадрового видео на основе заданного количества видеокадров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|-------------|-----------|----------|-------|
| `clip_vision` | Модель CLIP vision, используемая для кодирования входного изображения | CLIP_VISION | Да | - |
| `init_image` | Исходное изображение, которое служит отправной точкой для генерации 3D-видео | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображения в латентное пространство | VAE | Да | - |
| `width` | Ширина выходных видеокадров (по умолчанию: 576, должна делиться на 8) | INT | Да | 16 до MAX_RESOLUTION (шаг 8) |
| `height` | Высота выходных видеокадров (по умолчанию: 576, должна делиться на 8) | INT | Да | 16 до MAX_RESOLUTION (шаг 8) |
| `video_frames` | Количество кадров для генерации видеопоследовательности (по умолчанию: 21) | INT | Да | 1 до 4096 |
| `elevation` | Угол возвышения камеры в градусах для 3D-вида, применяется к каждому кадру (по умолчанию: 0.0) | FLOAT | Да | -90.0 до 90.0 (шаг 0.1) |

Примечание: Азимут камеры начинается с 0 градусов и увеличивается на 360 / (`video_frames` - 1) градусов на кадр, поэтому камера совершает полный оборот вокруг объекта за последовательность. Одно и то же значение `elevation` применяется ко всем кадрам.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительные данные кондиционирования, содержащие эмбеддинги изображения и параметры камеры для генерации | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования с обнулёнными эмбеддингами для контрастивной генерации | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, соответствующими заданным видеокадрам и разрешению | LATENT |
