# SV3D_Кондиционирование

SV3D_Conditioning подготавливает данные conditioning для генерации 3D-видео с использованием модели SV3D. Он принимает исходное изображение и обрабатывает его через энкодеры CLIP vision и VAE, создавая положительный и отрицательный conditioning, а также латентное представление. Узел генерирует последовательности углов возвышения и азимута камеры для многокадровой генерации видео на основе указанного количества кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования входного изображения | CLIP_VISION | Да | - |
| `начальное_изображение` | Исходное изображение, которое служит отправной точкой для генерации 3D-видео | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображения в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходных кадров видео (по умолчанию: 576, должна делиться на 8) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходных кадров видео (по умолчанию: 576, должна делиться на 8) | INT | Да | 16 to MAX_RESOLUTION |
| `кадры_видео` | Количество кадров для генерации видеопоследовательности (по умолчанию: 21) | INT | Да | 1 до 4096 |
| `высота` | Угол возвышения камеры в градусах для 3D-обзора (по умолчанию: 0.0) | FLOAT | Да | -90.0 до 90.0 |

Примечание: азимут камеры начинается с 0 градусов и увеличивается на постоянную величину для каждого кадра, так что камера совершает полный оборот на 360 градусов вокруг объекта за все сгенерированные кадры. Значение `elevation` остается постоянным для каждого кадра.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Положительные данные conditioning, содержащие эмбеддинги изображения и параметры камеры для генерации | CONDITIONING |
| `отрицательный` | Отрицательные данные conditioning с обнуленными эмбеддингами и латентными представлениями для контрастной генерации | CONDITIONING |
| `латентный` | Пустой латентный тензор с размерностями, соответствующими указанному количеству кадров и разрешению | LATENT |
