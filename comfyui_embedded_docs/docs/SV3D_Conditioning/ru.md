# SV3D_Кондиционирование

SV3D_Conditioning подготавливает данные кондиционирования для генерации 3D-видео с использованием модели SV3D. Он принимает исходное изображение и обрабатывает его через CLIP vision и VAE-энкодеры для создания позитивного и негативного кондиционирования, а также латентного представления. Узел генерирует последовательности углов возвышения и азимута камеры для многокадровой генерации видео на основе указанного количества кадров видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования входного изображения | CLIP_VISION | Да | - |
| `начальное_изображение` | Исходное изображение, служащее начальной точкой для генерации 3D-видео | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображения в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходных кадров генерируемого видео (по умолчанию: 576, шаг 8) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходных кадров генерируемого видео (по умолчанию: 576, шаг 8) | INT | Да | 16 to MAX_RESOLUTION |
| `кадры_видео` | Количество кадров для генерации видеопоследовательности (по умолчанию: 21) | INT | Да | 1 до 4096 |
| `высота` | Угол возвышения камеры в градусах для 3D-вида (по умолчанию: 0.0, шаг 0.1) | FLOAT | Да | -90.0 до 90.0 |

Примечание. Азимут камеры начинается с 0 градусов и увеличивается на постоянную величину с каждым кадром, так что камера совершает полный оборот на 360 градусов вокруг объекта на протяжении всех сгенерированных кадров. Приращение на кадр рассчитывается как 360, делённое на (`video_frames` - 1), с использованием минимального делителя 2, когда запрашивается только один кадр. Значение `elevation` остаётся постоянным для каждого кадра.

`init_image` масштабируется до указанных `width` и `height` перед кодированием VAE, а возвращаемый латент имеет размеры `video_frames` x 4 x (`height` // 8) x (`width` // 8).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивные данные кондиционирования, содержащие эмбеддинги изображения и параметры камеры для генерации | CONDITIONING |
| `negative` | Негативные данные кондиционирования с обнулёнными эмбеддингами и латентами для контрастивной генерации | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, соответствующими указанному количеству кадров видео и разрешению | LATENT |
