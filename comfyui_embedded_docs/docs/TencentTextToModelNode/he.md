# Hunyuan3D: טקסט למודל

צומת זה משתמש ב-API של Tencent's Hunyuan3D Pro כדי ליצור מודל תלת-ממד מתיאור טקסטואלי. הוא שולח בקשה ליצירת משימת יצירה, מבצע polling לתוצאה, ומוריד את קבצי המודל הסופיים בפורמטים GLB ו-OBJ.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת מודל Hunyuan3D לשימוש. אפשרות LowPoly אינה זמינה עבור מודל `3.1`. | COMBO | כן | `"3.0"`<br>`"3.1"` |
| `prompt` | התיאור הטקסטואלי של מודל התלת-ממד ליצירה. תומך עד 1024 תווים. | STRING | כן | - |
| `face_count` | מספר הפאות הרצוי עבור מודל התלת-ממד המיוצר. ברירת מחדל: 500000. | INT | כן | 3000 - 1500000 |
| `generate_type` | סוג מודל התלת-ממד ליצירה. האפשרויות הזמינות והפרמטרים המשויכים להן הם:<br>- **Normal**: יוצר מודל סטנדרטי. כולל פרמטר `pbr` (ברירת מחדל: `False`).<br>- **LowPoly**: יוצר מודל בעל מספר פאות נמוך. כולל פרמטרים `polygon_type` (`"triangle"` או `"quadrilateral"`) ו-`pbr` (ברירת מחדל: `False`).<br>- **Geometry**: יוצר מודל גאומטריה בלבד. | DYNAMICCOMBO | כן | `"Normal"`<br>`"LowPoly"`<br>`"Geometry"` |
| `seed` | ערך seed ליצירה. התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. הגדרת seed חדש קובעת אם הצומת אמור לרוץ מחדש. ברירת מחדל: 0. | INT | לא | 0 - 2147483647 |

**הערה:** הפרמטר `generate_type` הוא דינמי. בחירה ב-`"LowPoly"` תחשוף קלטים נוספים עבור `polygon_type` ו-`pbr`. בחירה ב-`"Normal"` תחשוף קלט עבור `pbr`. בחירה ב-`"Geometry"` לא תחשוף קלטים נוספים.

**אילוץ:** אין להשתמש בסוג היצירה `"LowPoly"` עם המודל `"3.1"`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | פלט מיושן לתאימות לאחור. | STRING |
| `GLB` | מודל התלת-ממד שנוצר בפורמט קובץ GLB. | FILE3DGLB |
| `OBJ` | מודל התלת-ממד שנוצר בפורמט קובץ OBJ. | FILE3DOBJ |
| `texture_image` | תמונת הטקסטורה שחולצה מקובץ ה-OBJ שנוצר, אם קיימת. | IMAGE |
