# WanPhantomSubjectToVideo

گره WanPhantomSubjectToVideo با پردازش ورودی‌های conditioning و تصاویر مرجع اختیاری، محتوای ویدیویی تولید می‌کند. این گره نمایش‌های نهفته (latent) برای تولید ویدیو ایجاد می‌کند و در صورت ارائه تصاویر ورودی، می‌تواند از راهنمای تصویری آن‌ها استفاده کند. گره داده‌های conditioning را با الحاق در بُعد زمانی برای مدل‌های ویدیویی Wan آماده می‌کند و conditioning اصلاح‌شده را به همراه داده‌های ویدیویی نهفته تولیدشده خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرط‌گذاری مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `negative` | ورودی شرط‌گذاری منفی برای اجتناب از ویژگی‌های خاص | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر در صورت ارائه | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی تولیدشده (پیش‌فرض: 81، باید بر 4 بخش‌پذیر باشد) | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `images` | تصاویر مرجع اختیاری برای شرط‌گذاری در بُعد زمان | IMAGE | خیر | - |

**نکته:** وقتی `images` ارائه می‌شوند، به‌طور خودکار به `width` و `height` مشخص‌شده بزرگ‌نمایی می‌شوند و فقط اولین `length` فریم برای پردازش استفاده می‌شود. هر تصویر قبل از رمزگذاری توسط VAE به ۳ کانال رنگی اول کاهش می‌یابد. وقتی `images` ارائه نمی‌شوند، ورودی‌های conditioning بدون تغییر عبور می‌کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرط‌گذاری مثبت اصلاح‌شده با الحاق در بُعد زمان هنگام ارائه تصاویر | CONDITIONING |
| `negative_text` | شرط‌گذاری منفی اصلاح‌شده با الحاق در بُعد زمان هنگام ارائه تصاویر | CONDITIONING |
| `negative_img_text` | شرط‌گذاری منفی با الحاق صفرشده در بُعد زمان هنگام ارائه تصاویر | CONDITIONING |
| `latent` | نمایش ویدیویی نهفته پر از صفر با ۱۶ کانال، بُعد زمانی ((length - 1) // 4) + 1 و ابعاد فضایی height // 8 و width // 8 | LATENT |
