# WanPhantomSubjectToVideo

گره WanPhantomSubjectToVideo داده‌های شرطی‌سازی و یک latent را برای تولید ویدئوی Wan آماده می‌کند. یک ویدئوی latent خالی از عرض، ارتفاع، طول و اندازه دسته درخواستی می‌سازد و هنگامی که تصاویر مرجع ارائه شوند، آن‌ها را با VAE کدگذاری می‌کند و به‌عنوان راهنمای بصری در بُعد زمان به شرطی‌سازی‌ها می‌افزاید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | ورودی شرطی‌سازی مثبت برای هدایت تولید ویدئو | CONDITIONING | بله | - |
| `منفی` | ورودی شرطی‌سازی منفی برای پرهیز از ویژگی‌های خاص | CONDITIONING | بله | - |
| `vae` | مدل VAE که هنگام ارائه تصاویر مرجع برای کدگذاری آن‌ها استفاده می‌شود | VAE | بله | - |
| `عرض` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 832) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `ارتفاع` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `طول` | تعداد فریم‌های ویدئوی تولیدشده (پیش‌فرض: 81) | INT | بله | 1 تا MAX_RESOLUTION (گام 4) |
| `اندازه بچ` | تعداد ویدئوهایی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `تصاویر` | تصاویر مرجع اختیاری که به‌عنوان راهنمای بصری در بُعد زمان استفاده می‌شوند | IMAGE | خیر | - |

**نکته:** هنگامی که `images` ارائه می‌شوند، به‌طور خودکار برای تطبیق با `width` و `height` مشخص‌شده بزرگ‌نمایی می‌شوند و فقط اولین `length` تصویر برای پردازش استفاده می‌شود. هر تصویر با `vae` کدگذاری و در امتداد بُعد زمان الحاق می‌شود و تنها کانال‌های RGB هر تصویر استفاده می‌شوند. هنگامی که `images` ارائه نمی‌شوند، هر سه خروجی شرطی‌سازی بدون تغییر از شرطی‌سازی‌های ورودی بازگردانده می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت همراه با الحاق در بُعد زمان از تصاویر مرجع کدگذاری‌شده هنگام ارائه تصاویر؛ در غیر این صورت، `positive` ورودی بدون تغییر بازگردانده می‌شود | CONDITIONING |
| `negative_text` | شرطی‌سازی منفی همراه با الحاق در بُعد زمان از تصاویر مرجع کدگذاری‌شده هنگام ارائه تصاویر؛ در غیر این صورت، `negative` ورودی بدون تغییر بازگردانده می‌شود | CONDITIONING |
| `negative_img_text` | شرطی‌سازی منفی همراه با الحاق صفرشده در بُعد زمان هنگام ارائه تصاویر؛ در غیر این صورت، `negative` ورودی بدون تغییر بازگردانده می‌شود | CONDITIONING |
| `latent` | تنسور ویدئوی latent پر از صفر با 16 کانال؛ تعداد فریم‌های آن از `length` و ابعاد مکانی آن از `height` و `width` مشتق می‌شود | LATENT |
