# وان فانتوم موضوع إلى فيديو

تقوم عقدة WanPhantomSubjectToVideo بتحضير بيانات التكييف وتمثيل كامن لتوليد فيديو Wan. وهي تنشئ فيديو كامنًا فارغًا وفق العرض والارتفاع والطول وحجم الدفعة المطلوبة، وعند توفير صور مرجعية، ترمّزها باستخدام VAE وتضيفها إلى بيانات التكييف كتوجيه بصري في البُعد الزمني.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل التكييف الإيجابي لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السلبي لتجنب خصائص معينة | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور المرجعية عند توفيرها | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832) | INT | نعم | 16 إلى MAX_RESOLUTION (خطوة 16) |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480) | INT | نعم | 16 إلى MAX_RESOLUTION (خطوة 16) |
| `الطول` | عدد الإطارات في الفيديو المولّد (الافتراضي: 81) | INT | نعم | 1 إلى MAX_RESOLUTION (خطوة 4) |
| `حجم الدُفعة` | عدد الفيديوهات التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `الصور` | صور مرجعية اختيارية تُستخدم كتوجيه بصري في البُعد الزمني | IMAGE | لا | - |

**ملاحظة:** عند توفير `images`، يتم تكبيرها تلقائيًا لتطابق `width` و`height` المحددين، وتُستخدم أول `length` صورة فقط للمعالجة. تُرمّز كل صورة باستخدام `vae` وتُدمج على طول البُعد الزمني، وتُستخدم قنوات RGB فقط من كل صورة. عند عدم توفير `images`، تُعاد مخرجات التكييف الثلاثة جميعها دون تغيير من بيانات التكييف المدخلة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي مع دمج في البُعد الزمني للصور المرجعية المرمزة عند توفير الصور؛ وإلا يُعاد `positive` المدخل دون تغيير | CONDITIONING |
| `negative_text` | تكييف سلبي مع دمج في البُعد الزمني للصور المرجعية المرمزة عند توفير الصور؛ وإلا يُعاد `negative` المدخل دون تغيير | CONDITIONING |
| `negative_img_text` | تكييف سلبي مع دمج صفري في البُعد الزمني عند توفير الصور؛ وإلا يُعاد `negative` المدخل دون تغيير | CONDITIONING |
| `latent` | موتر فيديو كامن مملوء بالأصفار بـ16 قناة؛ يُشتق عدد إطاراته من `length` وأبعاده المكانية من `height` و`width` | LATENT |
