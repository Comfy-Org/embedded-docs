# وان فانتوم موضوع إلى فيديو

تقوم عقدة WanPhantomSubjectToVideo بتجهيز بيانات التوجيه (conditioning) وكامن (latent) لتوليد فيديو Wan. تنشئ فيديو كامنًا فارغًا بناءً على العرض والارتفاع والطول وحجم الدفعة المطلوبة، وعند توفير صور مرجعية، تقوم بترميزها باستخدام VAE وتضيفها إلى التوجيهات كإرشاد بصري عبر بُعد الزمن.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل توجيه إيجابي لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | مدخل توجيه سلبي لتجنب خصائص معينة | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور المرجعية عند توفيرها | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، يجب أن يكون مضاعفًا للعدد 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، يجب أن يكون مضاعفًا للعدد 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الطول` | عدد الإطارات في الفيديو المُولَّد (الافتراضي: 81، يجب أن يكون مضاعفًا للعدد 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `حجم الدُفعة` | عدد الفيديوهات التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `الصور` | صور مرجعية اختيارية تُستخدم كإرشاد بصري عبر بُعد الزمن | IMAGE | لا | - |

**ملاحظة:** عند توفير `images`، يتم رفع دقتها تلقائيًا لتطابق `width` و`height` المحددين، ويُستخدم فقط أول `length` صورة للمعالجة. يتم ترميز كل صورة باستخدام `vae` وتُدمج على طول بُعد الزمن، وتُستخدم قنوات RGB فقط من كل صورة.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
| `النص الإيجابي` | توجيه إيجابي مع دمج زمني للصور المرجعية المرمزة عند توفير الصور؛ وإلا فسيتم إرجاع المدخل `positive` دون تغيير | CONDITIONING |
| `النص السلبي` | توجيه سلبي مع دمج زمني للصور المرجعية المرمزة عند توفير الصور؛ وإلا فسيتم إرجاع المدخل `negative` دون تغيير | CONDITIONING |
| `نص الصورة السلبية` | توجيه سلبي مع دمج زمني مُصفَّر (صفر) عند توفير الصور؛ وإلا فسيتم إرجاع المدخل `negative` دون تغيير | CONDITIONING |
| `الكامن` | موتر فيديو كامن مملوء بالأصفار بعدد 16 قناة؛ يُشتق عدد إطاره من `length` وأبعاده المكانية من `height` و`width` | LATENT |
