# وان فانتوم موضوع إلى فيديو

تنشئ عقدة WanPhantomSubjectToVideo محتوى فيديو من خلال معالجة مدخلات التكييف والصور المرجعية الاختيارية. تُنشئ تمثيلات كامنة لتوليد الفيديو، ويمكنها دمج توجيه بصري من الصور المدخلة عند توفيرها. تُحضّر العقدة بيانات التكييف مع دمج عبر البعد الزمني لنماذج Wan للفيديو، وتُخرج تكييفًا معدلًا إلى جانب بيانات الفيديو الكامنة المولدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مدخل التكييف الإيجابي لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي لتجنب خصائص معينة | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لتشفير الصور عند توفيرها | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، يجب أن يكون قابلاً للقسمة على 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، يجب أن يكون قابلاً للقسمة على 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو المولّد (الافتراضي: 81، يجب أن يكون قابلاً للقسمة على 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `images` | صور مرجعية اختيارية لتكييف البعد الزمني | IMAGE | لا | - |

**ملاحظة:** عند توفير `images`، يتم رفع دقتها تلقائيًا لمطابقة `width` و `height` المحددة، ويتم استخدام أول `length` إطارًا فقط للمعالجة. يتم تقليل كل صورة إلى قنوات الألوان الثلاثة الأولى قبل تشفيرها بواسطة VAE. عندما لا يتم توفير `images`، تمر مدخلات التكييف دون تغيير.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدل مع دمج عبر البعد الزمني عند توفير الصور | CONDITIONING |
| `negative_text` | تكييف سلبي معدل مع دمج عبر البعد الزمني عند توفير الصور | CONDITIONING |
| `negative_img_text` | تكييف سلبي مع دمج عبر البعد الزمني مُصفَّر عند توفير الصور | CONDITIONING |
| `latent` | تمثيل فيديو كامن مملوء بالأصفار بـ 16 قناة، وبُعد زمني مقداره ((length - 1) // 4) + 1، وأبعاد مكانية height // 8 و width // 8 | LATENT |
