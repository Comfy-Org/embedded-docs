# WanPhantomSubjectToVideo

Узел WanPhantomSubjectToVideo генерирует видеоконтент, обрабатывая входные данные кондиционирования и дополнительные референсные изображения. Он создаёт скрытые представления для генерации видео и может включать визуальное руководство из входных изображений при их наличии. Узел подготавливает данные кондиционирования с временной конкатенацией для видеомоделей Wan и выводит модифицированное кондиционирование вместе со сгенерированными скрытыми видеоданными.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование для избегания определённых характеристик | CONDITIONING | Да | - |
| `vae` | Модель VAE для кодирования изображений при их наличии | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в генерируемом видео (по умолчанию: 81, должно делиться на 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `images` | Дополнительные референсные изображения для временного кондиционирования | IMAGE | Нет | - |

**Примечание:** Когда предоставлены `images`, они автоматически масштабируются до указанных `width` и `height`, и для обработки используются только первые `length` кадров. Каждое изображение сокращается до первых 3 цветовых каналов перед кодированием VAE. Если `images` не предоставлены, входные кондиционирования передаются без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование с временной конкатенацией при наличии изображений | CONDITIONING |
| `negative_text` | Модифицированное отрицательное кондиционирование с временной конкатенацией при наличии изображений | CONDITIONING |
| `negative_img_text` | Отрицательное кондиционирование с обнулённой временной конкатенацией при наличии изображений | CONDITIONING |
| `latent` | Заполненное нулями скрытое представление видео с 16 каналами, временным измерением ((length - 1) // 4) + 1 и пространственными измерениями height // 8 и width // 8 | LATENT |
