# WanPhantomSubjectToVideo

Узел WanPhantomSubjectToVideo подготавливает данные кондиционирования и латентное представление для генерации видео Wan. Он создает пустое латентное видео с запрошенными шириной, высотой, длиной и размером пакета, а при наличии эталонных изображений кодирует их с помощью VAE и добавляет их в кондиционирования в качестве временной визуальной информации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Вход положительного кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `негативный` | Вход отрицательного кондиционирования для предотвращения нежелательных характеристик | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования эталонных изображений, если они предоставлены | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в генерируемом видео (по умолчанию: 81, должно быть кратно 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество одновременно генерируемых видео (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `изображения` | Необязательные эталонные изображения, используемые в качестве временной визуальной информации | IMAGE | Нет | - |

**Примечание:** Когда `images` предоставлены, они автоматически увеличиваются до указанных `width` и `height`, и для обработки используются только первые `length` изображений. Каждое изображение кодируется с помощью `vae` и конкатенируется вдоль временного измерения, при этом используются только RGB-каналы каждого изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Положительное кондиционирование с конкатенацией закодированных эталонных изображений по временному измерению, если изображения предоставлены; в противном случае возвращается входное `positive` без изменений | CONDITIONING |
| `негативный_текст` | Отрицательное кондиционирование с конкатенацией закодированных эталонных изображений по временному измерению, если изображения предоставлены; в противном случае возвращается входное `negative` без изменений | CONDITIONING |
| `негативный_изображение_текст` | Отрицательное кондиционирование с обнуленной конкатенацией по временному измерению, если изображения предоставлены; в противном случае возвращается входное `negative` без изменений | CONDITIONING |
| `латентный` | Латентный видео-тензор, заполненный нулями, с 16 каналами; количество кадров определяется из `length`, а пространственные размеры — из `height` и `width` | LATENT |
