# WanPhantomSubjectToVideo

Узел WanPhantomSubjectToVideo подготавливает conditioning-данные и latent для генерации видео Wan. Он создаёт пустое latent-видео на основе заданных width, height, length и batch size, а при наличии эталонных изображений кодирует их с помощью VAE и добавляет в conditioning как визуальное управление по временному измерению.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительный conditioning-вход для управления генерацией видео | CONDITIONING | Да | - |
| `негативный` | Отрицательный conditioning-вход, чтобы избежать определённых характеристик | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования эталонных изображений, когда они предоставлены | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832) | INT | Да | 16 до MAX_RESOLUTION (шаг 16) |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480) | INT | Да | 16 до MAX_RESOLUTION (шаг 16) |
| `длина` | Количество кадров в генерируемом видео (по умолчанию: 81) | INT | Да | 1 до MAX_RESOLUTION (шаг 4) |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `изображения` | Необязательные эталонные изображения, используемые как визуальное управление по временному измерению | IMAGE | Нет | - |

**Примечание:** Когда `images` предоставлены, они автоматически масштабируются до указанных `width` и `height`, и для обработки используются только первые `length` изображений. Каждое изображение кодируется с помощью `vae` и объединяется по временному измерению, при этом используются только RGB-каналы каждого изображения. Когда `images` не предоставлены, все три выхода conditioning возвращаются без изменений из входных conditioning.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный conditioning с конкатенацией закодированных эталонных изображений по временному измерению, когда изображения предоставлены; иначе входной `positive` возвращается без изменений | CONDITIONING |
| `negative_text` | Отрицательный conditioning с конкатенацией закодированных эталонных изображений по временному измерению, когда изображения предоставлены; иначе входной `negative` возвращается без изменений | CONDITIONING |
| `negative_img_text` | Отрицательный conditioning с обнулённой конкатенацией по временному измерению, когда изображения предоставлены; иначе входной `negative` возвращается без изменений | CONDITIONING |
| `latent` | Латентный тензор видео, заполненный нулями, с 16 каналами; количество кадров определяется по `length`, а пространственные размеры — по `height` и `width` | LATENT |
