# TextEncodeAceStepAudio1.5

Узел TextEncodeAceStepAudio1.5 подготавливает текст и связанные с аудио метаданные для использования с моделью AceStepAudio 1.5. Он принимает описательные теги, текст песни и музыкальные параметры, а затем с помощью модели CLIP преобразует их в формат кондиционирования, подходящий для генерации аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования входного текста. | CLIP | Да | N/A |
| `tags` | Описательные теги для аудио, например жанр, настроение или инструменты. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | N/A |
| `lyrics` | Текст песни для аудиодорожки. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | N/A |
| `seed` | Случайное значение seed для воспроизводимой генерации. Имеет виджет `control_after_generate`. По умолчанию: 0. | INT | Нет | 0 to 18446744073709551615 |
| `bpm` | Количество ударов в минуту (BPM) для генерируемого аудио. По умолчанию: 120. | INT | Нет | 10 to 300 |
| `duration` | Желаемая длительность аудио в секундах. По умолчанию: 120.0. | FLOAT | Нет | 0.0 to 2000.0 |
| `timesignature` | Музыкальный размер. | COMBO | Нет | `"2"`<br>`"3"`<br>`"4"`<br>`"6"` |
