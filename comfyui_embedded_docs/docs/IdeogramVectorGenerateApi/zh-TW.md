# Ideogram Vector Generate SVG

此節點使用 Ideogram Vector，從文字提示生成可編輯的 SVG，並可選擇性地以最多 5 張參考圖像作為引導。結果是向量標記而非點陣圖像，因此圖形在向量編輯器中仍可保持可編輯狀態。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。預設值：`"ideogram-vector-1"`。 | DYNAMIC_COMBO | 是 | `"ideogram-vector-1"` |
| `images` | 選用的參考圖像。圖像 1 是主要來源，圖像 2 至 5 是額外參考；請在提示中以 `@Image1`、`@Image2` 等方式引用它們。批次輸入時，每張圖像各計一次。 | AUTOGROW | 否 | 0 到 5 張圖像 |
| `prompt` | SVG 的描述。支援以 `@Image1` 形式引用輸入圖像。 | STRING | 是 | 1 到 9500 個字元 |
| `aspect_ratio` | `"auto"` 會跟隨圖像 1，若未連接任何圖像則跟隨提示。預設值：`"auto"`。 | COMBO | 是 | `"auto"`<br>`"1:3"`<br>`"1:2"`<br>`"9:16"`<br>`"10:16"`<br>`"2:3"`<br>`"3:4"`<br>`"4:5"`<br>`"1:1"`<br>`"5:4"`<br>`"4:3"`<br>`"3:2"`<br>`"16:10"`<br>`"16:9"`<br>`"2:1"`<br>`"3:1"` |
| `quality` | 品質等級。等級越高，費用越高且耗時越長。預設值：`"medium"`。 | COMBO | 是 | `"low"`<br>`"medium"`<br>`"high"` |
| `seed` | 生成用的種子。相同的提示、圖像、設定與種子會產生相同的 SVG。預設值：42。 | INT | 是 | 0 到 2147483647 |

**限制條件：**

* 提示長度必須介於 1 到 9500 個字元之間。
* `images` 最多接受 5 張圖像，當輸入為批次時按每張圖像計算，且每張圖像的長寬比必須介於 1:6 與 6:1 之間。
* 最長邊超過 2048 像素的圖像會在上傳前被縮小。
* 引用未連接的圖像（例如只提供兩張圖像卻使用 `@Image4`）會引發錯誤。
