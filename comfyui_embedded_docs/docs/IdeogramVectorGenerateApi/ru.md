# Ideogram Vector Generate SVG

Этот узел генерирует редактируемый SVG по текстовому промпту с помощью Ideogram Vector, при необходимости используя до 5 референсных изображений. Результат представляет собой векторную разметку, а не растровое изображение, поэтому фигуры остаются редактируемыми в векторном редакторе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель для использования. По умолчанию: `"ideogram-vector-1"`. | DYNAMIC_COMBO | Да | `"ideogram-vector-1"` |
| `images` | Необязательные референсные изображения. Изображение 1 — основной источник, изображения со 2 по 5 — дополнительные референсы; упоминайте их в промпте как `@Image1`, `@Image2` и т. д. При пакетном вводе каждое изображение учитывается отдельно. | AUTOGROW | Нет | от 0 до 5 изображений |
| `prompt` | Описание SVG. Поддерживает ссылки на входные изображения в стиле `@Image1`. | STRING | Да | от 1 до 9500 символов |
| `aspect_ratio` | `"auto"` определяется по изображению 1 или по промпту, если изображение не подключено. По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"1:3"`<br>`"1:2"`<br>`"9:16"`<br>`"10:16"`<br>`"2:3"`<br>`"3:4"`<br>`"4:5"`<br>`"1:1"`<br>`"5:4"`<br>`"4:3"`<br>`"3:2"`<br>`"16:10"`<br>`"16:9"`<br>`"2:1"`<br>`"3:1"` |
| `quality` | Уровень качества. Более высокие уровни стоят дороже и занимают больше времени. По умолчанию: `"medium"`. | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `seed` | Сид для генерации. Одинаковые промпт, изображения, настройки и сид дают одинаковый SVG. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения:**

* Промпт должен содержать от 1 до 9500 символов.
* `images` принимает не более 5 изображений; при пакетном вводе изображения считаются отдельно, и каждое изображение должно иметь соотношение сторон от 1:6 до 6:1.
* Изображения, у которых наибольшая сторона превышает 2048 пикселей, уменьшаются перед загрузкой.
* Ссылка на неподключённое изображение, например `@Image4` при наличии только двух изображений, вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `SVG` | Сгенерированный SVG в виде редактируемой векторной разметки. | SVG |
