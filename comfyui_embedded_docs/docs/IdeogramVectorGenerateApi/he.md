# Ideogram Vector Generate SVG

צומת זה יוצר SVG ניתן לעריכה מתוך פרומפט טקסט באמצעות Ideogram Vector, כאשר ניתן להנחותו באמצעות עד 5 תמונות עזר. התוצאה היא סימון וקטורי ולא תמונת רסטר, ולכן הצורות נשארות ניתנות לעריכה בעורך וקטורי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש. ברירת מחדל: `"ideogram-vector-1"`. | DYNAMIC_COMBO | כן | `"ideogram-vector-1"` |
| `images` | תמונות עזר אופציונליות. תמונה 1 היא המקור הראשי ותמונות 2 עד 5 הן תמונות עזר נוספות; יש להזכיר אותן בפרומפט כ-`@Image1`, `@Image2` וכן הלאה. קלט באצווה נספר לפי כל תמונה בנפרד. | AUTOGROW | לא | 0 עד 5 תמונות |
| `prompt` | תיאור ה-SVG. תומך באזכורים בסגנון `@Image1` לתמונות הקלט. | STRING | כן | 1 עד 9500 תווים |
| `aspect_ratio` | `"auto"` עוקב אחרי תמונה 1, או אחרי הפרומפט כאשר לא מחוברת תמונה. ברירת מחדל: `"auto"`. | COMBO | כן | `"auto"`<br>`"1:3"`<br>`"1:2"`<br>`"9:16"`<br>`"10:16"`<br>`"2:3"`<br>`"3:4"`<br>`"4:5"`<br>`"1:1"`<br>`"5:4"`<br>`"4:3"`<br>`"3:2"`<br>`"16:10"`<br>`"16:9"`<br>`"2:1"`<br>`"3:1"` |
| `quality` | רמת איכות. רמות גבוהות יותר עולות יותר ואורכות זמן רב יותר. ברירת מחדל: `"medium"`. | COMBO | כן | `"low"`<br>`"medium"`<br>`"high"` |
| `seed` | Seed ליצירה. אותו פרומפט, אותן תמונות, אותן הגדרות ואותו `seed` מפיקים את אותו SVG. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים:**

* הפרומפט חייב להכיל בין 1 ל-9500 תווים.
* `images` מקבל לכל היותר 5 תמונות, כאשר קלט באצווה נספר לפי כל תמונה בנפרד, וכל תמונה חייבת להיות ביחס רוחב-גובה בין 1:6 ל-6:1.
* תמונות שהצד הארוך שלהן גדול מ-2048 פיקסלים מוקטנות לפני ההעלאה.
* אזכור תמונה שאינה מחוברת, כגון `@Image4` כאשר סופקו רק שתי תמונות, יגרום לשגיאה.
