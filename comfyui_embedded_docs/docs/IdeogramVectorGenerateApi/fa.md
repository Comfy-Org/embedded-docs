# Ideogram Vector Generate SVG

این گره با Ideogram Vector از یک پرامپت متنی، یک SVG قابل ویرایش تولید می‌کند و به‌صورت اختیاری می‌تواند با حداکثر 5 تصویر مرجع هدایت شود. نتیجه نشانه‌گذاری برداری است نه تصویر رستری، بنابراین شکل‌ها در ویرایشگر برداری قابل ویرایش می‌مانند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. پیش‌فرض: `"ideogram-vector-1"`. | DYNAMIC_COMBO | بله | `"ideogram-vector-1"` |
| `images` | تصاویر مرجع اختیاری. تصویر 1 منبع اصلی است و تصاویر 2 تا 5 مراجع اضافی هستند؛ آن‌ها را در پرامپت به‌صورت `@Image1`، `@Image2` و به همین ترتیب ذکر کنید. یک ورودی دسته‌ای به‌ازای هر تصویر یک‌بار شمرده می‌شود. | AUTOGROW | خیر | 0 تا 5 تصویر |
| `prompt` | توضیح SVG. از ارجاع‌هایی به سبک `@Image1` به تصاویر ورودی پشتیبانی می‌کند. | STRING | بله | 1 تا 9500 کاراکتر |
| `aspect_ratio` | `"auto"` از تصویر 1 پیروی می‌کند، یا وقتی هیچ تصویری متصل نیست از پرامپت. پیش‌فرض: `"auto"`. | COMBO | بله | `"auto"`<br>`"1:3"`<br>`"1:2"`<br>`"9:16"`<br>`"10:16"`<br>`"2:3"`<br>`"3:4"`<br>`"4:5"`<br>`"1:1"`<br>`"5:4"`<br>`"4:3"`<br>`"3:2"`<br>`"16:10"`<br>`"16:9"`<br>`"2:1"`<br>`"3:1"` |
| `quality` | سطح کیفیت. سطوح بالاتر هزینه بیشتری دارند و زمان بیشتری می‌برند. پیش‌فرض: `"medium"`. | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |
| `seed` | مقدار seed برای تولید. پرامپت، تصاویر، تنظیمات و seed یکسان، SVG یکسانی تولید می‌کنند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

**محدودیت‌ها:**

* پرامپت باید بین 1 تا 9500 کاراکتر باشد.
* `images` حداکثر 5 تصویر می‌پذیرد؛ در ورودی دسته‌ای، شمارش به‌ازای هر تصویر انجام می‌شود و نسبت ابعاد هر تصویر باید بین 1:6 و 6:1 باشد.
* تصاویری که ضلع بلندشان بیشتر از 2048 پیکسل باشد، پیش از بارگذاری کوچک‌تر می‌شوند.
* ارجاع به تصویری که متصل نیست، مانند `@Image4` وقتی فقط دو تصویر ارائه شده است، خطا ایجاد می‌کند.
