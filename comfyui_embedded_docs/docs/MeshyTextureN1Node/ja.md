# Meshy: Texture Model (N1)

このノードは、以前に作成した 3D モデルに対して、同じオブジェクトの 1～4 枚の参照ビューを用いて Meshy N1 テクスチャモデルでテクスチャを適用します。元のモデルのタスク ID とビューを接続すると、ノードはそれらを Meshy に送信し、ジョブの完了を待って、テクスチャ適用済みのモデルを GLB ファイルと FBX ファイルとして、新しいタスク ID とともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | テクスチャリングジョブに使用する AI モデルです。現在は `"meshy-n1"` のみが利用可能です。 | COMBO | はい | `"meshy-n1"` |
| `meshyタスクID` | テクスチャを適用する対象となる、以前に作成された 3D モデルのタスク ID です。 | MESHY_TASK_ID, STRING | はい | N/A |
| `正面ビュー` | Meshy が正面として扱うビューです。画像 1 枚では正面にのみテクスチャが適用され、背面は無地のままになります。背面を忠実に再現するには、`追加ビュー` に背面ビューと側面ビューを追加してください。 | IMAGE | はい | 単一画像 |
| `追加ビュー` | 同じオブジェクトの追加ビューです。順序は任意です。拡張可能なスロット：0～3 枚の画像（`view_1` ... `view_3`）を接続できます。`正面ビュー` と合わせて最大 4 枚の画像となります。 | IMAGE | いいえ | 0～3 枚の画像 |
| `元のUVを有効化` | 新しい UV を生成する代わりに、モデルの元の UV を使用します。有効にすると、Meshy はアップロードされたモデルの既存のテクスチャを保持します。モデルに元の UV がない場合、出力の品質が十分でない可能性があります。（デフォルト：True、詳細オプション） | BOOLEAN | いいえ | True または False |

**注意：** `正面ビュー` と `追加ビュー` は合わせて最大 4 枚の画像を保持できます。それ以上接続すると、ノードはエラーを発生させます。接続された画像がバッチを含む場合、バッチ内の各画像がこの上限にカウントされます。テクスチャ解像度は 2K に固定されており、PBR マップは生成されません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `meshy_task_id` | テクスチャリングジョブのタスク ID です。後続の Meshy ノードで使用できます。 | MESHY_TASK_ID, STRING |
| `GLB` | GLB 形式でダウンロードされた、テクスチャ適用済みの 3D モデルです。 | FILE3DGLB |
| `FBX` | FBX 形式でダウンロードされた、テクスチャ適用済みの 3D モデルです。 | FILE3DFBX |
