# Meshy: Texture Model (N1)

צומת זה מטקסטר מודל תלת-ממדי שנוצר קודם לכן באמצעות מודל הטקסטורה Meshy N1, תוך שימוש ב-1 עד 4 תצוגות עזר של אותו אובייקט. חברו את מזהה המשימה של המודל המקורי יחד עם התצוגות; הצומת שולח אותן ל-Meshy, ממתין לסיום המשימה ומחזיר את המודל המטוקסטר כקבצי GLB ו-FBX יחד עם מזהה המשימה החדש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI המשמש למשימת הטקסטור. נכון לעכשיו זמין רק `"meshy-n1"`. | COMBO | כן | `"meshy-n1"` |
| `meshy_task_id` | מזהה המשימה של מודל התלת-ממד שנוצר קודם לכן ואמור להיות מטוקסטר. | MESHY_TASK_ID, STRING | כן | N/A |
| `front_view` | התצוגה ש-Meshy מתייחס אליה כחזית. תמונה אחת מטקסטרת את החזית ומשאירה את הגב חלק; הוסיפו תצוגות גב וצד ב-`extra_views` לגב נאמן למקור. | IMAGE | כן | תמונה בודדת |
| `extra_views` | תצוגות נוספות של אותו אובייקט, בכל סדר. משבצת ניתנת להרחבה: חברו 0 עד 3 תמונות (`view_1` ... `view_3`). יחד עם `front_view` לכל היותר 4 תמונות. | IMAGE | לא | 0 עד 3 תמונות |
| `enable_original_uv` | השתמשו ב-UV המקורי של המודל במקום ליצור UV חדש. כאשר מופעל, Meshy שומר על הטקסטורות הקיימות מהמודל שהועלה. אם למודל אין UV מקורי, איכות הפלט עשויה שלא להיות טובה באותה מידה. (ברירת מחדל: True; אפשרות מתקדמת) | BOOLEAN | לא | True / False |

**הערה:** `front_view` ו-`extra_views` יכולים להחזיק יחד לכל היותר 4 תמונות; הצומת מציג שגיאה כאשר מחוברות יותר. אם תמונה מחוברת מכילה אצווה, כל תמונה באצווה נספרת במסגרת המגבלה. רזולוציית הטקסטורה קבועה על 2K ולא נוצרים מפות PBR.

## פלטים

| שם פלט | תיאור | סוג נתונים |
