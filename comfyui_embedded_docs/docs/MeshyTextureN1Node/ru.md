# Meshy: Texture Model (N1)

Этот узел текстурирует ранее созданную 3D-модель с помощью модели текстурирования Meshy N1, используя от 1 до 4 эталонных видов одного и того же объекта. Подключите ID задачи исходной модели вместе с видами; узел отправляет их в Meshy, ждёт завершения задания и возвращает текстурированную модель в виде файлов GLB и FBX вместе с новым ID задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | AI-модель, используемая для задачи текстурирования. В настоящее время доступна только `"meshy-n1"`. | COMBO | Да | `"meshy-n1"` |
| `id_задачи_meshy` | ID задачи ранее созданной 3D-модели, которую нужно текстурировать. | MESHY_TASK_ID, STRING | Да | Н/Д |
| `вид_спереди` | Вид, который Meshy считает передним. Одно изображение текстурирует переднюю часть, а задняя остаётся незаполненной; добавьте виды сзади и сбоку в `extra_views` для точной передачи задней части. | IMAGE | Да | Одно изображение |
| `дополнительные ракурсы` | Дополнительные виды того же объекта в любом порядке. Расширяемый слот: подключите от 0 до 3 изображений (`view_1` ... `view_3`). Вместе с `front_view` — не более 4 изображений. | IMAGE | Нет | от 0 до 3 изображений |
| `использовать_исходную_uv` | Использовать исходные UV модели вместо генерации новых UV. Если включено, Meshy сохраняет существующие текстуры из загруженной модели. Если у модели нет исходных UV, качество результата может быть ниже. (по умолчанию: True; дополнительная опция) | BOOLEAN | Нет | True / False |

**Примечание:** `front_view` и `extra_views` вместе могут содержать не более 4 изображений; если подключено больше, узел выдаёт ошибку. Если подключённое изображение передаётся пакетом, каждое изображение в пакете учитывается в этом ограничении. Разрешение текстуры фиксировано на 2K, а PBR-карты не генерируются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `meshy_task_id` | ID задачи текстурирования, который можно использовать в последующих узлах Meshy. | MESHY_TASK_ID, STRING |
| `GLB` | Текстурированная 3D-модель, загруженная в формате GLB. | FILE3DGLB |
| `FBX` | Текстурированная 3D-модель, загруженная в формате FBX. | FILE3DFBX |
