# Meshy: Texture Model (N1)

این گره یک مدل سه‌بعدی از پیش ساخته‌شده را با مدل بافت Meshy N1 بافت‌دهی می‌کند و از ۱ تا ۴ نمای مرجع از همان شیء استفاده می‌کند. شناسه وظیفه (Task ID) مدل اصلی را به‌همراه نماها متصل کنید؛ گره آن‌ها را به Meshy می‌فرستد، منتظر پایان کار می‌ماند و مدل بافت‌دار را به‌صورت فایل‌های GLB و FBX همراه با شناسه وظیفه جدید برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای کار بافت‌دهی. در حال حاضر فقط `"meshy-n1"` در دسترس است. | COMBO | بله | `"meshy-n1"` |
| `meshy_task_id` | شناسه وظیفه مدل سه‌بعدی از پیش ساخته‌شده‌ای که باید بافت‌دهی شود. | MESHY_TASK_ID, STRING | بله | N/A |
| `front_view` | نمایی که Meshy آن را به‌عنوان نمای جلو در نظر می‌گیرد. یک تصویر بخش جلو را بافت‌دار می‌کند و پشت را بدون بافت می‌گذارد؛ برای داشتن پشت دقیق، نماهای پشت و کناره را در `extra_views` اضافه کنید. | IMAGE | بله | تک تصویر |
| `extra_views` | نماهای بیشتر از همان شیء، به هر ترتیبی. جایگاه قابل‌افزایش: 0 تا 3 تصویر را متصل کنید (`view_1` ... `view_3`). همراه با `front_view` حداکثر ۴ تصویر. | IMAGE | خیر | 0 تا 3 تصویر |
| `enable_original_uv` | از UV اصلی مدل به‌جای تولید UVهای جدید استفاده کنید. وقتی فعال باشد، Meshy بافت‌های موجود از مدل بارگذاری‌شده را حفظ می‌کند. اگر مدل UV اصلی نداشته باشد، ممکن است کیفیت خروجی به همان خوبی نباشد. (پیش‌فرض: True؛ گزینه پیشرفته) | BOOLEAN | خیر | True یا False |

**توجه:** `front_view` و `extra_views` می‌توانند در مجموع حداکثر ۴ تصویر داشته باشند؛ اگر بیشتر متصل شود، گره خطا می‌دهد. اگر تصویر متصل‌شده شامل یک batch باشد، هر تصویر در batch به سقف مذکور حساب می‌شود. وضوح بافت ثابت 2K است و هیچ نقشه PBR تولید نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `meshy_task_id` | شناسه وظیفه کار بافت‌دهی، قابل استفاده توسط گره‌های بعدی Meshy. | MESHY_TASK_ID, STRING |
| `GLB` | مدل سه‌بعدی بافت‌دار دانلودشده در قالب GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی بافت‌دار دانلودشده در قالب FBX. | FILE3DFBX |
