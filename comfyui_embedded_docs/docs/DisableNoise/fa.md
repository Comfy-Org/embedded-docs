# غیرفعال‌سازی نویز

گره DisableNoise یک پیکربندی خالی نویز فراهم می‌کند که می‌توان از آن برای غیرفعال کردن تولید نویز در فرآیندهای نمونه‌برداری استفاده کرد. این گره یک شیء نویز ویژه برمی‌گرداند که حاوی هیچ داده نویزی نیست و به سایر گره‌ها اجازه می‌دهد هنگام اتصال به این خروجی، عملیات مرتبط با نویز را رد کنند.
