# غیرفعال‌سازی نویز

گره `DisableNoise` یک پیکربندی خالی نویز ارائه می‌دهد که می‌تواند برای غیرفعال‌سازی تولید نویز در فرآیندهای نمونه‌برداری استفاده شود. این گره یک شیء نویز ویژه بازمی‌گرداند که حاوی داده‌های نویز نیست و به سایر گره‌ها اجازه می‌دهد هنگام اتصال به این خروجی، عملیات مرتبط با نویز را نادیده بگیرند. همچنین این گره با نام مستعار «zero noise» قابل جستجو است.
