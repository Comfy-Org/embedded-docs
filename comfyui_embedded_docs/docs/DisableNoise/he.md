# השבת רעש

צומת זה מספק תצורת רעש ריקה שמשביתה יצירת רעש במהלך הדגימה. הוא מפיק אובייקט רעש מיוחד שאינו מכיל נתוני רעש, כך שכל צומת המחובר אליו מדלג על פעולות הקשורות לרעש. ניתן לאתר אותו גם תחת הכינוי "zero noise".
