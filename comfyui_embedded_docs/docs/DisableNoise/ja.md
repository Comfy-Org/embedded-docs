# ノイズを無効にする

DisableNoise ノードは、サンプリングプロセスにおけるノイズ生成を無効化するために使用できる空のノイズ設定を提供します。ノイズデータを含まない特別なノイズオブジェクトを返すため、この出力に接続された他のノードはノイズ関連の操作をスキップできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| *入力パラメータなし* | このノードは入力パラメータを必要としません。 | - | - | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `NOISE` | サンプリングプロセスにおけるノイズ生成を無効化するために使用できる空のノイズ設定を返します。 | NOISE |
