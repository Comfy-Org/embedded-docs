# Отключить шум

Узел DisableNoise предоставляет пустую конфигурацию шума, которую можно использовать для отключения генерации шума в процессах сэмплирования. Он возвращает специальный объект шума, не содержащий данных шума, что позволяет другим узлам пропускать операции, связанные с шумом, при подключении к этому выходу. Узел также доступен для поиска по псевдониму «zero noise».

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| *Нет входных параметров* | Этот узел не требует входных параметров. | - | - | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `NOISE` | Возвращает пустую конфигурацию шума, которую можно использовать для отключения генерации шума в процессах сэмплирования. | NOISE |
