# Отключить шум

Этот узел предоставляет пустую конфигурацию шума, которая отключает генерацию шума во время сэмплирования. Он выводит специальный объект шума, не содержащий данных шума, поэтому любой подключенный к нему узел пропускает операции, связанные с шумом. Его также можно найти по псевдониму «zero noise».

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| *Нет входных параметров* | Этот узел не требует входных параметров. | - | - | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `NOISE` | Возвращает пустую конфигурацию шума, которую можно использовать для отключения генерации шума в процессах сэмплирования. | NOISE |
