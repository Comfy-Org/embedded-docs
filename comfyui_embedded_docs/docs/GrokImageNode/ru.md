# Grok Image

Узел Grok Image генерирует одно или несколько изображений на основе текстового описания с использованием модели искусственного интеллекта Grok. Он отправляет ваш запрос во внешний сервис и возвращает сгенерированные изображения в виде тензоров, которые можно использовать в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель Grok для генерации изображений. Разные модели могут предлагать разное качество, скорость или функциональность. | COMBO | Да | `"grok-imagine-image-2.0"`<br>`"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `prompt` | Текстовый запрос, используемый для генерации изображения. Это описание помогает ИИ понять, что нужно создать. Длина должна быть не менее 1 символа. | STRING | Да | N/A |
| `aspect_ratio` | Желаемое соотношение ширины и высоты генерируемого изображения. | COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |
| `number_of_images` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 10 |
| `seed` | Зерно (seed) для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от значения зерна (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `разрешение` | Желаемое разрешение выходных изображений (по умолчанию: "1K"). | COMBO | Нет | `"1K"`<br>`"2K"` |
| `качество` | Уровень качества, поддерживается только моделью `grok-imagine-image-2.0` (по умолчанию: "medium"; "low" — один из доступных вариантов). Для всех остальных моделей этот параметр игнорируется. | COMBO | Нет | Доступно несколько вариантов |

**Примечание:** Параметр `seed` в основном используется для управления моментом повторного выполнения узла в рабочем процессе. Из-за особенностей внешнего ИИ-сервиса сгенерированные изображения не могут быть воспроизведены или идентичны при разных запусках, даже при одинаковом значении зерна.

**Примечание о ценообразовании:** Стоимость генерации изображений зависит от выбранных `model`, `resolution`, `quality` и `number_of_images`. Для модели `grok-imagine-image-2.0` качество "low" стоит $0.04 за изображение при разрешении 1K и $0.06 за изображение при разрешении 2K; другие уровни качества стоят $0.06 за изображение при 1K и $0.08 при 2K. Модель `grok-imagine-image-quality` стоит $0.05 за изображение при разрешении 1K и $0.07 за изображение при разрешении 2K. Модель `grok-imagine-image-pro` стоит $0.07 за изображение. Модель `grok-imagine-image` стоит $0.02 за изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. Если `number_of_images` равно 1, возвращается один тензор изображения. Если больше 1, возвращается пакет тензоров изображений. | IMAGE |
