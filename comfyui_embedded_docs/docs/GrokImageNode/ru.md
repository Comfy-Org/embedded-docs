# Grok Image

Узел Grok Image генерирует одно или несколько изображений на основе текстового запроса с использованием моделей генерации изображений Grok AI. Он отправляет запрос и настройки во внешний сервис и возвращает сгенерированные изображения в виде тензоров, которые можно использовать в других местах рабочего процесса.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель Grok для генерации изображений. Разные модели могут предлагать различное качество, скорость или функциональность. | COMBO | Да | `"grok-imagine-image-2.0"`<br>`"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `prompt` | Текстовый запрос (промпт), используемый для генерации изображения. Это описание указывает ИИ, что создавать. Должен содержать как минимум 1 непробельный символ. | STRING | Да | N/A |
| `aspect_ratio` | Желаемое соотношение ширины и высоты генерируемого изображения. | COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |
| `number_of_images` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 10 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `resolution` | Желаемое разрешение вывода для генерируемых изображений (по умолчанию: "1K"). | COMBO | Нет | `"1K"`<br>`"2K"` |
| `quality` | Уровень качества, поддерживается только моделью grok-imagine-image-2.0 (по умолчанию: "medium"). | COMBO | Нет | Доступно несколько вариантов |

**Примечание:** параметр `quality` применяется только когда `model` установлена в "grok-imagine-image-2.0". Для всех остальных моделей этот параметр игнорируется.

**Примечание:** параметр `seed` в основном используется для управления моментом повторного выполнения узла в рамках рабочего процесса. Из-за особенностей внешнего ИИ-сервиса сгенерированные изображения не воспроизводимы между запусками, даже при одинаковом сиде.

**Примечание о ценообразовании:** стоимость генерации изображений зависит от выбранных `model`, `resolution`, `quality` и `number_of_images`; общая цена равна стоимости за одно изображение, умноженной на `number_of_images`. Для модели "grok-imagine-image-2.0" стоимость за изображение составляет $0.04 при разрешении "1K" и $0.06 при "2K" с качеством "low", или $0.06 при "1K" и $0.08 при "2K" с другими уровнями качества. Модель "grok-imagine-image-quality" стоит $0.05 за изображение при "1K" и $0.07 за изображение при "2K". Модель "grok-imagine-image-pro" стоит $0.07 за изображение. Другие модели стоят $0.02 за изображение.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. Если `number_of_images` равен 1, возвращается один тензор изображения. Если больше 1, возвращается пакет тензоров изображений. | IMAGE |
