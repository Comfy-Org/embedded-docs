# Grok Image

Узел Grok Image генерирует одно или несколько изображений из текстового описания с помощью модели Grok AI. Он отправляет ваш промпт во внешний сервис и возвращает сгенерированные изображения в виде тензоров, которые можно использовать в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель Grok для генерации изображений. Разные модели могут обеспечивать разное качество, скорость или функциональность. | COMBO | Да | `"grok-imagine-image-2.0"`<br>`"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `prompt` | Текстовый промпт, используемый для генерации изображения. Это описание направляет ИИ в том, что создавать. Длина должна быть не менее 1 символа (текст, состоящий только из пробельных символов, не принимается). | STRING | Да | N/A |
| `aspect_ratio` | Желаемое соотношение ширины к высоте для сгенерированного изображения. | COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |
| `number_of_images` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 10 |
| `seed` | Seed для определения, должен ли узел выполняться повторно; фактические результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `разрешение` | Желаемое выходное разрешение для сгенерированных изображений (по умолчанию: "1K"). | COMBO | Нет | `"1K"`<br>`"2K"` |
| `качество` | Уровень качества, поддерживается только моделью `grok-imagine-image-2.0` (по умолчанию: "medium"; "low" — один из доступных вариантов). Для всех остальных моделей этот параметр игнорируется. | COMBO | Нет | Доступно несколько вариантов |

**Примечание:** Параметр `seed` в первую очередь используется для управления тем, когда узел повторно выполняется в рабочем процессе. Из-за особенностей внешнего ИИ-сервиса сгенерированные изображения не будут воспроизводимыми или идентичными между запусками, даже при одинаковом seed.

**Примечание о стоимости:** Стоимость генерации изображений зависит от выбранных `model`, `resolution`, `quality` и `number_of_images`. Для модели `grok-imagine-image-2.0` качество "low" стоит $0.04 за изображение при разрешении 1K и $0.06 за изображение при разрешении 2K; другие уровни качества стоят $0.06 за изображение при 1K и $0.08 за изображение при 2K. `grok-imagine-image-quality` и `grok-imagine-image-pro` больше не поддерживаются xAI и теперь работают как `grok-imagine-image-2.0` с низким качеством, поэтому стоят $0.04 за изображение при 1K и $0.06 при 2K. Модель `grok-imagine-image` стоит $0.02 за изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. Если `number_of_images` равен 1, возвращается один тензор изображения. Если больше 1, возвращается пакет тензоров изображений. | IMAGE |
