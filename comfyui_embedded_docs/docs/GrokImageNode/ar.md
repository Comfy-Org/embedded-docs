# صورة Grok

تُنشئ عقدة Grok Image صورة واحدة أو أكثر من وصف نصي باستخدام نموذج Grok AI. وترسل المطالبة النصية الخاصة بك إلى خدمة خارجية، ثم تعيد الصور المولّدة كموترات (tensors) يمكن استخدامها في سير العمل الخاص بك.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | نموذج Grok المحدد المراد استخدامه لتوليد الصور. قد توفر النماذج المختلفة جودة أو سرعة أو ميزات متفاوتة. | COMBO | نعم | `"grok-imagine-image-2.0"`<br>`"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `المطالبة` | المطالبة النصية المستخدمة لتوليد الصورة. يوجّه هذا الوصف الذكاء الاصطناعي بشأن ما يجب إنشاؤه. يجب أن يكون طوله حرفًا واحدًا على الأقل (لا يُقبل النص الذي يتكون من مسافات بيضاء فقط). | STRING | نعم | غير متاح |
| `نسبة العرض إلى الارتفاع` | نسبة العرض إلى الارتفاع المطلوبة للصورة المولّدة. | COMBO | نعم | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |
| `عدد الصور` | عدد الصور المراد توليدها (الافتراضي: 1). | INT | نعم | 1 إلى 10 |
| `البذرة` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0). | INT | نعم | 0 إلى 2147483647 |
| `الدقة` | دقة الإخراج المطلوبة للصور المولّدة (الافتراضي: "1K"). | COMBO | لا | `"1K"`<br>`"2K"` |
| `الجودة` | مستوى الجودة، مدعوم فقط بواسطة نموذج `grok-imagine-image-2.0` (الافتراضي: "medium"؛ "low" أحد الخيارات المتاحة). بالنسبة لجميع النماذج الأخرى، يتم تجاهل هذا الإعداد. | COMBO | لا | خيارات متعددة متاحة |

**ملاحظة:** تُستخدم معلمة `seed` أساسًا للتحكم في وقت إعادة تنفيذ العقدة داخل سير العمل. نظرًا لطبيعة خدمة الذكاء الاصطناعي الخارجية، لن تكون الصور المولّدة قابلة لإعادة الإنتاج أو متطابقة عبر عمليات التشغيل، حتى مع بذرة مطابقة.

**ملاحظة حول التسعير:** تعتمد تكلفة توليد الصور على `model` و`resolution` و`quality` و`number_of_images` المحددة. بالنسبة لنموذج `grok-imagine-image-2.0`، تبلغ تكلفة جودة "low" 0.04 دولار لكل صورة عند دقة 1K و0.06 دولار لكل صورة عند دقة 2K؛ بينما تبلغ تكلفة مستويات الجودة الأخرى 0.06 دولار لكل صورة عند 1K و0.08 دولار لكل صورة عند 2K. تبلغ تكلفة نموذج `grok-imagine-image-quality` 0.05 دولار لكل صورة عند دقة 1K و0.07 دولار لكل صورة عند دقة 2K. تبلغ تكلفة نموذج `grok-imagine-image-pro` 0.07 دولار لكل صورة. تبلغ تكلفة نموذج `grok-imagine-image` 0.02 دولار لكل صورة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
