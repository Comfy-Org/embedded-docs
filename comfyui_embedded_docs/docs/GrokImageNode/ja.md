# Grok画像生成

Grok Image ノードは、Grok AI 画像モデルを使用して、テキストプロンプトに基づいて1つ以上の画像を生成します。プロンプトと設定を外部サービスに送信し、生成された画像をテンソルとして返します。これにより、生成された画像をワークフローの他の場所で使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像生成に使用する特定のGrokモデル。モデルによって、品質、速度、機能が異なる場合があります。 | COMBO | はい | `"grok-imagine-image-2.0"`<br>`"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `prompt` | 画像を生成するために使用されるテキストプロンプト。この説明が、何を作成するかについてAIをガイドします。空白以外の文字が少なくとも1文字含まれている必要があります。 | STRING | はい | N/A |
| `aspect_ratio` | 生成される画像の希望する幅と高さの比率。 | COMBO | はい | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |
| `number_of_images` | 生成する画像の数（デフォルト: 1）。 | INT | はい | 1 ～ 10 |
| `seed` | ノードを再実行するかどうかを決定するためのシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0 ～ 2147483647 |
| `resolution` | 生成される画像に希望する出力解像度（デフォルト: "1K"）。 | COMBO | いいえ | `"1K"`<br>`"2K"` |
| `quality` | 品質レベル。grok-imagine-image-2.0 モデルでのみサポートされます（デフォルト: "medium"）。 | COMBO | いいえ | 複数のオプションが利用可能 |

**注記：** `quality` パラメータは、`model` が "grok-imagine-image-2.0" に設定されている場合にのみ適用されます。他のすべてのモデルでは、この設定は無視されます。

**注記：** `seed` パラメータは、主にワークフロー内でノードが再実行されるタイミングを制御するために使用されます。外部AIサービスの性質上、同じシードを使用しても、生成された画像は実行間で再現できません。

**料金に関する注記：** 画像生成のコストは、選択した `model`、`resolution`、`quality`、`number_of_images` によって異なります。合計料金は、画像1枚あたりの料金に `number_of_images` を掛けた金額です。「grok-imagine-image-2.0」モデルの場合、画像1枚あたりの料金は、"low" 品質では "1K" 解像度で $0.04、"2K" 解像度で $0.06 です。その他の品質レベルでは "1K" で $0.06、"2K" で $0.08 です。「grok-imagine-image-quality」モデルは、"1K" で1枚あたり $0.05、"2K" で1枚あたり $0.07 です。「grok-imagine-image-pro」モデルは1枚あたり $0.07 です。他のモデルは1枚あたり $0.02 です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された画像、または画像のバッチ。`number_of_images` が 1 の場合は単一の画像テンソルが返され、1 より大きい場合は画像テンソルのバッチが返されます。 | IMAGE |
