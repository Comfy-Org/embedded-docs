# המרת צבע תמונה למסכה

הצומת `ImageColorToMask` נועד להמיר צבע מוגדר בתמונה למסכה. הוא מעבד תמונה וצבע יעד, ומייצר מסכה שבה הצבע המוגדר מודגש, ובכך מאפשר פעולות כמו סגמנטציה מבוססת צבע או בידוד אובייקטים.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | הפרמטר `image` מייצג את תמונת הקלט שיש לעבד. הוא חיוני לקביעת האזורים בתמונה שתואמים לצבע המוגדר ואשר יומרו למסכה. | `IMAGE` |
| `color` | הפרמטר `color` מגדיר את צבע היעד בתמונה שאותו יש להמיר למסכה. הוא ממלא תפקיד מרכזי בזיהוי אזורי הצבע הספציפיים שיודגשו במסכה המתקבלת. | `INT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `mask` | הפלט הוא מסכה שמדגישה את האזורים בתמונת הקלט שתואמים לצבע המוגדר. ניתן להשתמש במסכה זו במשימות עיבוד תמונה נוספות, כגון סגמנטציה או בידוד אובייקטים. | `MASK` |
