# Запечь текстуру из вокселей

Этот узел запекает PBR-текстуры на 3D-меш, используя существующую UV-развёртку меша. Он растеризует меш в UV-пространстве и сэмплирует цветовые и материальные атрибуты из разрежённого воксельного объёма для каждого текселя, выводя изображение базового цвета, а также карты металличности и шероховатости. Он не выполняет развёртку меша, поэтому узел UV-развёртки должен быть подключён выше по графу; полученные изображения предназначены для использования в паре с тем же мешем в ApplyTextureToMesh для сохранения в формате GLB.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-меш, на который нужно запечь текстуры. Должен уже иметь UV-развёртку; узел UV-развёртки должен быть подключён выше по графу. | MESH | Да | |
| `voxel_colors` | Разрежённый воксельный объём, содержащий цвета каждого вокселя и необязательные PBR-атрибуты (каналы металличности и шероховатости). | VOXEL | Да | |
| `texture_size` | Разрешение квадратного UV-атласа (отображаемое имя: "resolution", по умолчанию: 2048). | INT | Да | 64 до 8192 |
| `reference_mesh` | Необязательный плотный меш до прореживания; выполняет обратное проецирование каждого текселя на его истинную поверхность перед сэмплированием, устраняя фасеточное запекание на грубых мешах. | MESH | Нет | |

Примечания:

- Входной меш должен иметь UV. Если UV отсутствуют, узел выдаёт ошибку. UV-координаты должны быть 1:1 с вершинами (одна UV-координата на вершину).
- Когда координаты меша и вокселей содержат измерение батча, каждый элемент батча запекается отдельно. Если у элемента батча нет вокселей или нет граней, он пропускается, и для него выводится чёрная текстура.
- Когда для батча предоставлен `reference_mesh`, он сопоставляется по индексу батча, если только не содержит единственный меш; в этом случае этот меш используется для всех элементов.
- Тексели, не покрытые ни одним UV-треугольником, заполняются из ближайшего покрытого текселя, чтобы швы текстуры не втягивали чёрный цвет.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_color` | RGB-карта базового цвета. Значения — float в диапазоне 0–1. | IMAGE |
| `metallic` | Карта металличности в градациях серого (float, 0–1). Чёрная, если цвета вокселей не содержат канала металличности. | IMAGE |
| `roughness` | Карта шероховатости в градациях серого (float, 0–1). Чёрная, если цвета вокселей не содержат канала шероховатости. | IMAGE |
