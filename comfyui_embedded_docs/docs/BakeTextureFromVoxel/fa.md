# BakeTextureFromVoxel

این گره با استفاده از چیدمان UV موجودِ مش، بافت‌های PBR را روی یک مش سه‌بعدی می‌پزد. در هر تکسِل، رنگ و ویژگی‌های مادی را از حجم وکسلِ پراکنده نمونه‌برداری می‌کند و یک تصویر رنگ پایه به همراه نقشه‌های فلزی و زبری خروجی می‌دهد. این گره مش را آنراپ (بازکردن UV) نمی‌کند؛ بنابراین باید یک گره آنراپ UV در بالادست متصل شده باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی که بافت‌ها روی آن پخت می‌شود. باید از قبل دارای چیدمان UV باشد؛ یک گره آنراپ UV باید در بالادست متصل شده باشد. | MESH | بله | |
| `voxel_colors` | حجم وکسل پراکنده شامل رنگ‌های هر وکسل و ویژگی‌های اختیاری PBR (کانال‌های فلزی و زبری). | VOXEL | بله | |
| `texture_size` | وضوح اطلس UV مربعی (نام نمایشی: «resolution»، پیش‌فرض: 2048). | INT | بله | 64 تا 8192 |
| `reference_mesh` | مش متراکم اختیاری پیش از ساده‌سازی؛ قبل از نمونه‌برداری، هر تکسِل را بر روی سطح واقعی خود بازتابش می‌کند و پخت وجهی را روی مش‌های درشت حذف می‌نماید. | MESH | خیر | |

یادداشت‌ها:

- مش ورودی باید UV داشته باشد. اگر UV وجود نداشته باشد، گره خطا صادر می‌کند. UVها باید با رئوس به نسبت ۱:۱ باشند (به ازای هر رأس یک UV).
- وقتی مش و مختصات وکسل دارای بُعد دسته‌ای باشند، هر آیتم دسته به‌طور جداگانه پخت می‌شود. اگر یک آیتم دسته هیچ وکسل یا وجهی نداشته باشد، رد شده و یک بافت سیاه برای آن تولید می‌شود.
- وقتی برای یک دسته، `reference_mesh` ارائه می‌شود، با شاخص دسته مطابقت داده می‌شود؛ مگر اینکه فقط یک مش داشته باشد، که در این صورت آن مش برای همه آیتم‌ها استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `base_color` | نقشه بافت رنگ پایه RGB. مقادیر به صورت شناور در بازه ۰ تا ۱ هستند. | IMAGE |
| `metallic` | نقشه فلزی خاکستری (شناور، ۰ تا ۱). زمانی که وکسل‌ها دارای کانال فلزی نباشند، سیاه است. | IMAGE |
| `roughness` | نقشه زبری خاکستری (شناور، ۰ تا ۱). زمانی که وکسل‌ها دارای کانال زبری نباشند، سیاه است. | IMAGE |
