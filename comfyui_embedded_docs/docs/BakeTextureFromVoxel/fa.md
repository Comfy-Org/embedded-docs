# بیک‌کردن بافت از وکسل

این گره بافت‌های PBR را با استفاده از چیدمان UV موجود مش روی یک مش سه‌بعدی بیک می‌کند. این گره مش را در فضای UV رستر می‌کند و در هر تکسِل، رنگ و ویژگی‌های جنس را از یک حجم ووکسل تُنُک نمونه‌برداری می‌کند و در خروجی یک تصویر رنگ پایه به‌همراه نقشه‌های فلزی و زبری تولید می‌کند. این گره مش را باز نمی‌کند (unwrap نمی‌کند)، بنابراین باید یک گره UV unwrap در بالادست متصل شود؛ تصاویر حاصل باید همراه با همان مش در ApplyTextureToMesh جفت شوند تا به‌صورت GLB ذخیره شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی برای بیک کردن بافت‌ها روی آن. باید از قبل چیدمان UV داشته باشد؛ یک گره UV unwrap باید در بالادست متصل شود. | MESH | بله | |
| `voxel_colors` | حجم ووکسل تُنُک شامل رنگ‌های هر ووکسل و ویژگی‌های اختیاری PBR (کانال‌های فلزی و زبری). | VOXEL | بله | |
| `texture_size` | وضوح اطلس UV مربعی (نام نمایشی: "resolution"، پیش‌فرض: 2048). | INT | بله | 64 تا 8192 |
| `reference_mesh` | مش متراکم اختیاری پیش از کاهش‌دهی؛ هر تکسِل را پیش از نمونه‌برداری روی سطح واقعی خودش بازتصویر می‌کند و بیک‌کردن وجه‌دار روی مش‌های درشت را حذف می‌کند. | MESH | خیر | |

یادداشت‌ها:

- مش ورودی باید UV داشته باشد. اگر UV وجود نداشته باشد، گره خطا می‌دهد. UVها باید ۱:۱ با رأس‌ها باشند (یک UV برای هر رأس).
- وقتی مختصات مش و ووکسل شامل بُعد دسته‌ای باشند، هر آیتم دسته جداگانه بیک می‌شود. اگر یک آیتم دسته هیچ ووکسلی یا هیچ وجهی نداشته باشد، نادیده گرفته می‌شود و یک بافت سیاه برای آن تولید می‌شود.
- وقتی `reference_mesh` برای یک دسته فراهم شود، بر اساس اندیس دسته تطبیق داده می‌شود، مگر اینکه فقط شامل یک مش باشد؛ در آن صورت آن مش برای همه آیتم‌ها استفاده می‌شود.
- تکسِل‌هایی که توسط هیچ مثلث UV پوشش داده نشده‌اند، از نزدیک‌ترین تکسِل پوشش‌داده‌شده پر می‌شوند تا درزهای بافت سیاهی را جذب نکنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `base_color` | نقشه بافت رنگ پایه RGB. مقادیر از نوع float در بازه ۰–۱ هستند. | IMAGE |
| `metallic` | نقشه فلزی خاکستری (float، ۰–۱). وقتی رنگ‌های ووکسل هیچ کانال فلزی نداشته باشند، سیاه است. | IMAGE |
| `roughness` | نقشه زبری خاکستری (float، ۰–۱). وقتی رنگ‌های ووکسل هیچ کانال زبری نداشته باشند، سیاه است. | IMAGE |
