# אפיית מרקם מווקסל

צומת זה מבצע אפייה של טקסטורות PBR על גבי מש תלת-ממדית באמצעות פריסת ה-UV הקיימת של המש. הוא מבצע רסטריזציה של המש במרחב UV ודוגם צבע ומאפייני חומר מנפח ווקסלים דליל בכל טקסל, ופולט תמונת צבע בסיס בתוספת מפות metallic ו-roughness. הוא אינו מבצע unwrap למש, לכן יש לחבר צומת UV unwrap במעלה הזרימה; התמונות המתקבלות מיועדות להיות משויכות לאותה מש ב-ApplyTextureToMesh לצורך שמירה כ-GLB.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | המש התלת-ממדית שעליה יש לאפות טקסטורות. חייבת כבר להכיל פריסת UV; יש לחבר צומת UV unwrap במעלה הזרימה. | MESH | כן | |
| `voxel_colors` | נפח ווקסלים דליל המכיל צבעים לכל ווקסל ומאפייני PBR אופציונליים (ערוצי metallic ו-roughness). | VOXEL | כן | |
| `texture_size` | רזולוציית אטלס UV מרובעת (שם תצוגה: "resolution", ברירת מחדל: 2048). | INT | כן | 64 עד 8192 |
| `reference_mesh` | מש צפופה אופציונלית לפני דה-צמצום; מבצעת הקרנה אחורה של כל טקסל על פני השטח האמיתיים שלו לפני הדגימה, ובכך מסירה אפייה פאסתית במשות גסות. | MESH | לא | |

הערות:

- למש הקלט חייבת להיות פריסת UV. אם אין UV, הצומת מעלה שגיאה. UV חייב להיות 1:1 עם הקודקודים (UV אחד לכל קודקוד).
- כאשר קואורדינטות המש והווקסלים מכילות ממד אצווה, כל פריט אצווה נאפה בנפרד. אם לפריט אצווה אין ווקסלים או אין פאות, הוא מדולג ומופקת עבורו טקסטורה שחורה.
- כאשר `reference_mesh` מסופק עבור אצווה, הוא מותאם לפי אינדקס האצווה, אלא אם הוא מכיל מש בודדת בלבד; במקרה כזה אותה מש משמשת עבור כל הפריטים.
- טקסלים שאינם מכוסים על ידי אף משולש UV ממולאים מהטקסל המכוסה הקרוב ביותר, כך שתפרי טקסטורה לא ימשכו שחור.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `base_color` | מפת טקסטורת צבע בסיס RGB. הערכים הם float בטווח 0–1. | IMAGE |
| `metallic` | מפת מתכתיות בגווני אפור (float, 0–1). שחורה כאשר צבעי הווקסלים אינם מכילים ערוץ metallic. | IMAGE |
| `roughness` | מפת חספוס בגווני אפור (float, 0–1). שחורה כאשר צבעי הווקסלים אינם מכילים ערוץ roughness. | IMAGE |
