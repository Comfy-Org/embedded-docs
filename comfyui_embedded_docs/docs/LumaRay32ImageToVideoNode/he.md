# LumaRay32ImageToVideoNode

יצירת וידאו מפריים התחלה ו/או סיום באמצעות המודל Ray 3.2 של Luma. יצירות מעוגנות בתמונה הן תמיד באורך 5 שניות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית טקסט ליצירת הווידאו. | STRING | כן | 1 עד 6000 תווים |
| `resolution` | רזולוציית הפלט של הווידאו שנוצר (ברירת מחדל: "720p"). | COMBO | כן | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `loop` | גרום לווידאו לחזור על עצמו בצורה חלקה. לא זמין כאשר מוגדר end_frame. | BOOLEAN | כן | True<br>False |
| `seed` | ערך Seed ליצירה ניתנת לשחזור. | INT | כן | 0 עד 2147483647 |
| `start_frame` | הפריים הראשון של הווידאו שנוצר. | IMAGE | לא | - |
| `end_frame` | הפריים האחרון של הווידאו שנוצר. | IMAGE | לא | - |

**הערה:** יש לספק לפחות אחד מהפרמטרים `start_frame` או `end_frame`. אם שניהם מסופקים, הווידאו שנוצר יעבור מפריים ההתחלה לפריים הסיום. לא ניתן להפעיל את האפשרות `loop` כאשר מוגדר `end_frame`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `video` | פלט הווידאו שנוצר. | VIDEO |
| `generation_id` | המזהה הייחודי של בקשת היצירה. | STRING |
