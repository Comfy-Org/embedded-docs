# WanAnimate2Cache

Кэширует поблочные активации pose-видео один раз, чтобы их не приходилось пересчитывать на каждом шаге сэмплирования, что примерно вдвое сокращает время генерации. Обратная сторона — дополнительное потребление памяти: около 12,5 ГБ оперативной памяти при разрешении 480x832 и 81 кадре в bf16, с ростом при увеличении разрешения и длины видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Wan Animate2, к которой нужно прикрепить кэш. | MODEL | Да | |
| `device` | Где хранить кэш. cpu (RAM) — безопасный выбор: при типичных размерах кэш не поместится в VRAM вместе с моделью. gpu (VRAM) может быть быстрее, если кэш помещается. (по умолчанию: "cpu") | STRING | Да | "cpu"<br>"gpu" |
| `dtype` | Точность хранения. default хранит активации в вычислительном dtype модели. int8 уменьшает кэш вдвое, int4 — вчетверо, convrot используется для сохранения точности. (по умолчанию: "default") | STRING | Да | "default"<br>"int8"<br>"int4" |

Примечание: при использовании контекстных окон каждое окно кэшируется отдельно, поэтому потребление памяти масштабируется с количеством окон. Следует использовать расписание static_standard, поскольку uniform-расписания сдвигают окна на каждом шаге, и кэш не переиспользуется.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Клонированная модель с прикреплённым кэшем активаций для pose-видео. Кэш автоматически освобождается по завершении генерации. | MODEL |
