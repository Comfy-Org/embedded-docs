# WanAnimate2Cache

فعال‌سازی‌های هر بلوک ویدیوی حالت (pose-video) را یک‌بار کش می‌کند تا در هر مرحله نمونه‌برداری مجدداً محاسبه نشوند، که زمان تولید را تقریباً نصف می‌کند. در مقابل، حافظه بیشتری مصرف می‌شود: حدود ۱۲.۵ گیگابایت RAM سیستم در وضوح 480x832 با ۸۱ فریم در bf16، که با وضوح و طول ویدیو مقیاس می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل Wan Animate2 که کش به آن متصل می‌شود. | MODEL | بله | |
| `دستگاه` | محل نگهداری کش. گزینه cpu (RAM) انتخاب امنی است؛ کش در اندازه‌های معمول همراه با مدل در VRAM جا نمی‌شود. gpu (VRAM) در صورت جا شدن می‌تواند سریع‌تر باشد. (پیش‌فرض: "cpu") | STRING | بله | "cpu"<br>"gpu" |
| `دقت ذخیره‌سازی` | دقت ذخیره‌سازی. گزینه default فعال‌سازی‌ها را با dtype محاسباتی مدل ذخیره می‌کند. int8 کش را نصف می‌کند، int4 آن را یک‌چهارم می‌کند، و convrot برای حفظ دقت استفاده می‌شود. (پیش‌فرض: "default") | STRING | بله | "default"<br>"int8"<br>"int4" |

توجه: وقتی از پنجره‌های زمینه (context windows) استفاده می‌شود، هر پنجره به‌طور جداگانه کش می‌شود، بنابراین مصرف حافظه با تعداد پنجره‌ها مقیاس می‌شود. باید از برنامه زمانی static_standard استفاده شود، زیرا برنامه‌های زمانی یکنواخت (uniform) پنجره‌ها را در هر مرحله جابه‌جا می‌کنند و کش هرگز استفاده مجدد نمی‌شود.
