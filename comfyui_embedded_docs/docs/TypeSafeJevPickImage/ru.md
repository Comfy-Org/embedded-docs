# TypeSafe Jev (Pick Image)

Узел TypeSafe Jev (Pick Image) выбирает одно изображение из пакета. Подключите `index` к Get Image from Batch, чтобы сохранить выбранное изображение, или прочитайте `confidence`, чтобы решить, достаточно ли хорош выбор. Это API-узел, для работы с ним требуются аккаунт Comfy.org и API-ключ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель Jev. В настоящее время доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Какое изображение выбрать. Подключите промпт к `text`, чтобы выбрать изображение, которое лучше всего ему соответствует (по умолчанию: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | Да | от 1 до 1000 символов |
| `images` | Изображения для выбора. Пакетный вход учитывается по одному разу на каждое изображение, поэтому каждое изображение в пакете является кандидатом. | IMAGE | Да | от 2 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт, по которому были созданы изображения. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Узел выдаёт ошибку, если подключено меньше 2 или больше 32 изображений.
- `index` считается с 0 — это позиция, которую ожидает Get Image from Batch.
- Оплата основана на токенах; значок цены на узле показывает приблизительную стоимость за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `index` | Позиция выбранного изображения в пакете, начиная с 0. | INT |
| `confidence` | Насколько Jev уверен — от 0 (нет явного победителя) до 1 (полная уверенность). | FLOAT |
