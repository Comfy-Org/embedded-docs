# TypeSafe Jev (Pick Image)

Узел TypeSafe Jev (Pick Image) выбирает одно изображение из пакета. Подключите тот же пакет изображений к Get Image from Batch вместе с `index`, чтобы сохранить выбранное изображение, или прочитайте `confidence`, чтобы решить, достаточно ли хорош выбор. Это API-узел: он выполняется на серверах Comfy и требует учетной записи Comfy.org с кредитами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель Jev. Сейчас доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Какое изображение выбрать. Подключите промпт к `text`, чтобы выбрать изображение, которое лучше всего ему соответствует (по умолчанию: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | Да | от 1 до 1000 символов |
| `images` | Изображения для выбора. Пакетный вход учитывается по одному разу на изображение, поэтому каждое изображение в пакете является кандидатом. Длинная сторона каждого изображения ограничивается размером пакета перед загрузкой: 1568 px при до 4 изображений, 1024 px при до 8, 768 px при до 16 и 512 px при до 32, поэтому больший пакет может снизить детализацию каждого изображения. | IMAGE | Да | от 2 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт, по которому были созданы изображения. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Узел выдает ошибку, если подключено менее 2 или более 32 изображений.
- `index` отсчитывается от 0; именно эту позицию ожидает Get Image from Batch.
- Оплата основана на токенах; значок цены на узле показывает приблизительный тариф за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `index` | Позиция выбранного изображения в пакете, начиная с 0. | INT |
| `confidence` | Насколько Jev уверен: от 0 (нет явного победителя) до 1 (полная уверенность). | FLOAT |
