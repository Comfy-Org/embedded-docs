# TypeSafe Jev (Pick Image)

צומת TypeSafe Jev (Pick Image) בוחר תמונה אחת מתוך אצווה. חבר את אותה אצוות תמונות אל Get Image from Batch יחד עם `index` כדי לשמור את התמונה שנבחרה, או קרא את `confidence` כדי להחליט אם הבחירה טובה מספיק. זהו צומת API: הוא פועל על שרתי Comfy ודורש חשבון Comfy.org עם קרדיטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. נכון לעכשיו זמין רק מודל אחד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | איזו תמונה לבחור. חבר את הפרומפט אל `text` כדי לבחור את התמונה שמתאימה לו ביותר (ברירת מחדל: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | כן | 1 עד 1000 תווים |
| `images` | התמונות שמהן לבחור. קלט באצווה נספר פעם אחת לכל תמונה, כך שכל תמונה באצווה היא מועמדת. הצלע הארוכה של כל תמונה מוגבלת לפי גודל האצווה לפני ההעלאה: 1568 פיקסלים עבור עד 4 תמונות, 1024 פיקסלים עבור עד 8, 768 פיקסלים עבור עד 16 ו-512 פיקסלים עבור עד 32, כך שאצווה גדולה יותר משמעה פחות פירוט בכל תמונה. | IMAGE | כן | 2 עד 32 תמונות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון הפרומפט שממנו נוצרו התמונות. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- הצומת מציג שגיאה כאשר מחוברות פחות מ-2 או יותר מ-32 תמונות.
- `index` מתחיל מ-0, וזהו המיקום שאליו Get Image from Batch מצפה.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל מיליון טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `index` | המיקום של התמונה שנבחרה באצווה, החל מ-0. | INT |
| `confidence` | מידת הביטחון של Jev, מ-0 (אין מנצח ברור) עד 1 (ודאי). | FLOAT |
