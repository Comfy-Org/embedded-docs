# TypeSafe Jev (Pick Image)

عقدة TypeSafe Jev (Pick Image) تختار صورة واحدة من بين دفعة صور. صِل `index` بعقدة Get Image from Batch للاحتفاظ بالصورة المختارة، أو اقرأ `confidence` لتقرر ما إذا كان الاختيار جيدًا بما يكفي. هذه عقدة API وتتطلب حساب Comfy.org ومفتاح API.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج Jev المراد استخدامه. يتوفر حاليًا نموذج واحد فقط: `jev-1.14.0`. | COMBO | نعم | `"jev-1.14.0"` |
| `question` | الصورة التي يجب اختيارها. صِل الأمر النصي (prompt) بـ `text` لاختيار الصورة التي تطابقه على أفضل وجه (الافتراضي: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | نعم | 1 إلى 1000 حرف |
| `images` | الصور المراد الاختيار منها. يُحتسب الإدخال المجمّع مرة واحدة لكل صورة، لذا فإن كل صورة في الدفعة تُعدّ مرشحة. | IMAGE | نعم | 2 إلى 32 صورة |
| `text` | النص الذي يدور حوله السؤال، مثل الأمر النصي الذي أُنشئت منه الصور. | STRING | لا | 0 إلى 3000 حرف |

**ملاحظات:**

- تُطلق العقدة خطأً عندما يكون عدد الصور المتصلة أقل من 2 أو أكثر من 32.
- يبدأ عدّ `index` من 0، وهو الموضع الذي تتوقعه عقدة Get Image from Batch.
- تعتمد الفوترة على الرموز (tokens)؛ وتُظهر شارة السعر على العقدة المعدل التقريبي لكل مليون رمز.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `index` | موضع الصورة المختارة داخل الدفعة، بدءًا من 0. | INT |
| `confidence` | مدى تأكد Jev، من 0 (لا فائز واضح) إلى 1 (مؤكد). | FLOAT |
