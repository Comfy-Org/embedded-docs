# TypeSafe Jev (Pick Image)

گره TypeSafe Jev (Pick Image) یک تصویر را از یک دسته انتخاب می‌کند. همان دسته تصویر را همراه با `index` به Get Image from Batch وصل کنید تا تصویر انتخاب‌شده را نگه دارید، یا `confidence` را بخوانید تا تصمیم بگیرید که آیا انتخاب به‌اندازه کافی خوب است. این یک گره API است: روی سرورهای Comfy اجرا می‌شود و به یک حساب Comfy.org با اعتبار نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | تصویری که باید انتخاب شود. برای انتخاب تصویری که بیشترین تطابق را با آن دارد، پرامپت را به `text` وصل کنید (پیش‌فرض: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `images` | تصاویری که از میان آن‌ها انتخاب می‌شود. یک ورودی دسته‌ای به ازای هر تصویر یک بار شمرده می‌شود، بنابراین هر تصویر در دسته یک کاندید است. ضلع بلند هر تصویر پیش از بارگذاری بر اساس اندازه دسته محدود می‌شود: 1568 پیکسل برای حداکثر 4 تصویر، 1024 پیکسل برای حداکثر 8 تصویر، 768 پیکسل برای حداکثر 16 تصویر و 512 پیکسل برای حداکثر 32 تصویر؛ بنابراین دسته بزرگ‌تر یعنی جزئیات کمتر در هر تصویر. | IMAGE | بله | 2 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند پرامپتی که تصاویر از روی آن ساخته شده‌اند. | STRING | خیر | 0 تا 3000 کاراکتر |

**نکته‌ها:**

- گره زمانی خطا می‌دهد که کمتر از 2 یا بیشتر از 32 تصویر وصل شده باشد.
- `index` از 0 شروع می‌شود، که همان موقعیتی است که Get Image from Batch انتظار دارد.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره نرخ تقریبی به ازای هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `index` | موقعیت تصویر انتخاب‌شده در دسته، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (برنده واضحی وجود ندارد) تا 1 (مطمئن). | FLOAT |
