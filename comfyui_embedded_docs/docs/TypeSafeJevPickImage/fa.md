# TypeSafe Jev (Pick Image)

گره TypeSafe Jev (Pick Image) یک تصویر را از میان یک دسته انتخاب می‌کند. همان دسته تصویر را همراه با `index` به Get Image from Batch متصل کنید تا تصویر انتخاب‌شده را نگه دارید، یا `confidence` را بخوانید تا تصمیم بگیرید آیا انتخاب به‌اندازه کافی خوب است. این یک گره API است: روی سرورهای Comfy اجرا می‌شود و به حساب Comfy.org با اعتبار نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | کدام تصویر انتخاب شود. اعلان (prompt) را به `text` متصل کنید تا تصویری انتخاب شود که بیشترین تطابق را دارد (پیش‌فرض: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `images` | تصاویری که باید از میان آن‌ها انتخاب شود. ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود، بنابراین هر تصویر در دسته یک گزینه است. ضلع بلند هر تصویر پیش از بارگذاری بر اساس اندازه دسته محدود می‌شود: 1568 پیکسل تا 4 تصویر، 1024 پیکسل تا 8 تصویر، 768 پیکسل تا 16 تصویر و 512 پیکسل تا 32 تصویر؛ از این رو دسته بزرگ‌تر می‌تواند جزئیات هر تصویر را کاهش دهد. | IMAGE | بله | 2 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند اعلانی که تصاویر از آن ساخته شده‌اند. | STRING | خیر | 0 تا 3000 کاراکتر |

**یادداشت‌ها:**

- گره زمانی خطا می‌دهد که کمتر از 2 یا بیشتر از 32 تصویر متصل باشد.
- `index` از 0 شروع می‌شود، که همان موقعیتی است که Get Image from Batch انتظار دارد.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره نرخ تقریبی به ازای هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `index` | موقعیت تصویر انتخاب‌شده در دسته، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (بدون برنده مشخص) تا 1 (قطعی). | FLOAT |
