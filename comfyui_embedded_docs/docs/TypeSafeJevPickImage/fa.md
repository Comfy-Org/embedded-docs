# TypeSafe Jev (Pick Image)

گره TypeSafe Jev (Pick Image) یک تصویر را از میان یک دسته انتخاب می‌کند. برای نگه‌داشتن تصویر انتخاب‌شده، `index` را به Get Image from Batch وصل کنید، یا `confidence` را بخوانید تا تصمیم بگیرید که انتخاب به‌اندازه کافی خوب است یا نه. این یک گره API است و به حساب Comfy.org و کلید API نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | کدام تصویر انتخاب شود. برای انتخاب تصویری که بهترین تطابق را دارد، پرامپت را به `text` وصل کنید (پیش‌فرض: `Which image best matches the prompt in text? If there is no text, which image has the best quality?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `images` | تصاویری که باید از میان آن‌ها انتخاب شود. ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود، بنابراین هر تصویر در دسته یک گزینه است. | IMAGE | بله | 2 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند پرامپتی که تصاویر از آن ساخته شده‌اند. | STRING | خیر | 0 تا 3000 کاراکتر |

**نکته‌ها:**

- اگر کمتر از 2 یا بیشتر از 32 تصویر متصل شود، گره خطا می‌دهد.
- `index` از 0 شروع می‌شود، که همان موقعیتی است که Get Image from Batch انتظار دارد.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره نرخ تقریبی را به‌ازای هر 1 میلیون توکن نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `index` | موقعیت تصویر انتخاب‌شده در دسته، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (بدون برنده مشخص) تا 1 (قطعی). | FLOAT |
