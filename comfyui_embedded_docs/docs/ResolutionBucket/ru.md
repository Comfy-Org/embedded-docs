# Группировка по разрешению

Этот узел упорядочивает список латентных изображений и соответствующие им данные кондиционирования по их разрешению. Он группирует элементы с одинаковой высотой и шириной, создавая отдельные пакеты для каждого уникального разрешения. Этот процесс полезен для подготовки данных к эффективному обучению, поскольку позволяет моделям обрабатывать несколько элементов одного размера вместе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей латентных представлений для группировки по разрешению. | LATENT | Да | N/A |
| `conditioning` | Список списков кондиционирования (длина должна совпадать с `latents`). | CONDITIONING | Да | N/A |

**Примечание:** Оба входа являются входами типа список, то есть узел получает список элементов для каждого из них. Количество элементов в списке `latents` должно точно совпадать с количеством элементов в списке `conditioning`; если количество не совпадает, узел выдаёт ошибку. Каждый словарь латентных представлений может содержать пакет образцов, а соответствующий список кондиционирования должен содержать совпадающее количество элементов кондиционирования для этого пакета, поскольку каждый образец в пакете сопоставлен со своей собственной записью кондиционирования. Латентные образцы могут иметь форму (B, C, H, W) для изображений или (B, T, C, H, W) для видео; узел группирует их только по высоте и ширине.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список пакетированных словарей латентных представлений, по одному на каждую группу разрешений. | LATENT |
| `conditioning` | Список списков кондиционирования, по одному на каждую группу разрешений. | CONDITIONING |

**Примечание:** Оба выхода являются выходами типа список. Каждый выходной список содержит одну запись для каждого уникального разрешения (высоты и ширины), найденного во входных данных, в порядке первого появления разрешений. Латентные представления внутри каждой группы объединяются в стек вдоль новой размерности пакета.
