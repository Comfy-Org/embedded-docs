# Группировка по разрешению

Этот узел группирует список латентных представлений (latents) и соответствующих данных conditioning по их разрешению. Он объединяет элементы с одинаковыми высотой и шириной, создавая отдельные батчи для каждого уникального разрешения. Этот процесс полезен для подготовки данных к эффективному обучению, поскольку позволяет моделям обрабатывать несколько элементов одного размера вместе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей латентных представлений для группировки по разрешению. | LATENT | Да | N/A |
| `conditioning` | Список списков conditioning (должен соответствовать длине списка `latents`). | CONDITIONING | Да | N/A |

**Примечание:** Количество элементов в списке `latents` должно точно совпадать с количеством элементов в списке `conditioning`. Каждый словарь латентного представления может содержать батч образцов, и соответствующий список conditioning должен содержать согласованное количество элементов conditioning для этого батча.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список батчевых словарей латентных представлений, по одному на каждую группу разрешения. | LATENT |
| `conditioning` | Список списков conditioning, по одному на каждую группу разрешения. | CONDITIONING |
