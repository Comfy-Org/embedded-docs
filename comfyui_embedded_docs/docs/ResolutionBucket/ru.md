# Группировка по разрешению

Этот узел группирует список латентных изображений и соответствующих им данных conditioning по разрешению. Он объединяет элементы с одинаковыми высотой и шириной, создавая отдельные пакеты для каждого уникального разрешения. Данный процесс полезен для подготовки данных к эффективному обучению, поскольку позволяет моделям обрабатывать несколько элементов одного размера вместе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей latent для группировки по разрешению. | LATENT | Да | Н/Д |
| `conditioning` | Список списков conditioning (должен соответствовать длине списка `latents`). | CONDITIONING | Да | Н/Д |

**Примечание:** Количество элементов в списке `latents` должно точно совпадать с количеством элементов в списке `conditioning`. Если количество не совпадает, узел вызывает ошибку. Каждый словарь latent может содержать пакет образцов, а соответствующий список conditioning должен содержать такое же количество элементов conditioning для этого пакета. Образцы latent могут иметь форму (B, C, H, W) для изображений или (B, T, C, H, W) для видео; узел группирует их только по высоте и ширине.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список пакетных словарей latent, по одному для каждой группы разрешений. | LATENT |
| `conditioning` | Список списков conditioning, по одному для каждой группы разрешений. | CONDITIONING |
