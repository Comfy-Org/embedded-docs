# 해상도 버킷

이 노드는 잠재 변수 목록과 해당 컨디셔닝 데이터를 해상도별로 구성합니다. 동일한 높이와 너비를 공유하는 항목들을 그룹화하여 각 고유 해상도에 대해 별도의 배치를 생성합니다. 이 과정은 모델이 동일한 크기의 여러 항목을 함께 처리할 수 있게 하므로 효율적인 학습을 위한 데이터 준비에 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `latents` | 해상도별로 그룹화할 잠재 변수 사전 목록입니다. | LATENT | 예 | N/A |
| `conditioning` | 컨디셔닝 목록의 목록입니다(`latents` 길이와 일치해야 함). | CONDITIONING | 예 | N/A |

**참고:** `latents` 목록의 항목 수는 `conditioning` 목록의 항목 수와 정확히 일치해야 합니다. 각 잠재 변수 사전에는 샘플 배치가 포함될 수 있으며, 해당 컨디셔닝 목록에는 해당 배치에 대한 일치하는 수의 컨디셔닝 항목이 포함되어야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latents` | 해상도 버킷당 하나씩, 배치된 잠재 변수 사전 목록입니다. | LATENT |
| `conditioning` | 해상도 버킷당 하나씩, 컨디셔닝 목록의 목록입니다. | CONDITIONING |
