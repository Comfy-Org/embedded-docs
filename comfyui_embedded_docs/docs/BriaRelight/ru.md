# BriaRelight

Этот узел изменяет атмосферу и направление освещения изображения с помощью Bria. Изображение повторно рендерится Bria, поэтому результат не выравнивается попиксельно с входным; весь кадр заново генерируется с разрешением около 1 мегапикселя.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Изображение, освещение которого изменяется. Любой альфа-канал отбрасывается перед загрузкой изображения. | IMAGE | Да | - |
| `light_type` | Атмосфера освещения, которую нужно применить. | COMBO | Да | `"midday"`<br>`"blue hour light"`<br>`"low-angle sunlight"`<br>`"sunrise light"`<br>`"spotlight on subject"`<br>`"overcast light"`<br>`"soft overcast daylight lighting"`<br>`"cloud-filtered lighting"`<br>`"fog-diffused lighting"`<br>`"moonlight lighting"`<br>`"starlight nighttime"`<br>`"soft bokeh lighting"`<br>`"harsh studio lighting"` |
| `light_direction` | Откуда исходит свет. Атмосферы с жёстким светом, такие как «midday», «spotlight on subject» и «harsh studio lighting», реагируют на это сильнее всего. | COMBO | Да | `"front"`<br>`"side"`<br>`"bottom"`<br>`"top-down"` |
| `модерация` | Настройки модерации. Выберите `"true"`, чтобы показать параметры модерации, или `"false"`, чтобы запустить без них. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы модерации

Эти параметры появляются, когда `moderation` имеет значение `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию содержимого для входного изображения. По умолчанию: false. | BOOLEAN | Нет | `true`<br>`false` |
| `visual_output_moderation` | Включает модерацию содержимого для сгенерированного выходного изображения. По умолчанию: false. | BOOLEAN | Нет | `true`<br>`false` |

Примечание: Bria повторно рендерит весь кадр с разрешением около 1 мегапикселя, поэтому результат не выравнивается попиксельно с входным изображением.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение с изменённым освещением, возвращённое Bria. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
