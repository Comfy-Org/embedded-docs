# Reroute

Node-Name: Reroute Node
Node-Zweck: Wird hauptsächlich verwendet, um die Logik übermäßig langer Verbindungslinien im ComfyUI-Workflow zu organisieren.

## Verwendung von Reroute-Nodes

| Menüoptionen | Beschreibung |
| --- | --- |
| Typ anzeigen | Zeigt die Typ-Eigenschaft des Nodes an |
| Typ standardmäßig ausblenden | Blendet die Typ-Eigenschaft des Nodes standardmäßig aus |
| Vertikal einstellen | Legt die Verbindungsrichtung des Nodes auf vertikal fest |
| Horizontal einstellen | Legt die Verbindungsrichtung des Nodes auf horizontal fest |

Wenn Ihre Verbindungslogik zu lang und komplex ist und Sie die Oberfläche aufräumen möchten, können Sie einen ```Reroute```-Node zwischen zwei Verbindungspunkten einfügen. Der Eingang und der Ausgang dieses Nodes sind nicht auf einen bestimmten Typ beschränkt, und der Standardstil ist horizontal. Sie können die Verbindungsrichtung über das Rechtsklick-Menü auf vertikal ändern.
