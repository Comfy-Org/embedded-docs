# Reroute

שם הצומת: Reroute Node
מטרת הצומת: משמשת בעיקר לארגון הלוגיקה של קווי חיבור ארוכים מדי בתהליך העבודה של ComfyUI.

## כיצד להשתמש בצומתי Reroute

| אפשרויות תפריט | תיאור |
| --- | --- |
| הצג סוג | הצג את מאפיין הסוג של הצומת |
| הסתר סוג כברירת מחדל | הסתר את מאפיין הסוג של הצומת כברירת מחדל |
| הגדר אנכי | הגדר את כיוון החיווט של הצומת לאנכי |
| הגדר אופקי | הגדר את כיוון החיווט של הצומת לאופקי |

כאשר לוגיקת החיווט שלך ארוכה ומסובכת מדי, ואתה רוצה לסדר את הממשק, ניתן להוסיף צומת ```Reroute``` בין שתי נקודות חיבור. הקלט והפלט של צומת זה אינם מוגבלים לפי סוג, וסגנון ברירת המחדל הוא אופקי. ניתן לשנות את כיוון החיווט לאנכי דרך תפריט הלחיצה הימנית.
