# PixVerse V6 圖像轉影片

此節點使用 PixVerse V6 模型為輸入圖像製作動畫，並回傳影片，可選擇包含原生音訊軌道。輸出影片保持輸入圖像的長寬比。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型與生成設定。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |
| `圖像` | 要製作動畫的輸入圖像。 | IMAGE | 是 | 單張圖像 |

### PixVerse V6 輸入

這些設定會在選取「PixVerse V6」模型時顯示。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 影片生成的提示詞（預設：空白）。 | STRING | 是 | 1 至 5000 個字元 |
| `quality` | 輸出解析度。設定長邊：360p 為 640px、540p 為 1024px、720p 為 1280px、1080p 為 1920px（預設："720p"）。 | COMBO | 是 | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | 生成影片的長度（秒）（預設：5）。 | INT | 是 | 1 至 15 |
| `generate_audio` | 與影片一同生成原生音訊軌道（預設：true）。 | BOOLEAN | 是 | true 或 false |
| `multi_clip` | 讓模型將影片分割成多個鏡頭，而非單一連續拍攝（預設：false）。 | BOOLEAN | 是 | true 或 false |
| `seed` | 影片生成的種子。PixVerse 會記錄它，但不會從中重現某次生成（預設：42，生成後控制已啟用）。 | INT | 是 | 0 至 2147483647 |
| `negative_prompt` | 影片中不需要元素的可選文字描述（預設：空白）。 | STRING | 否 | 最多 2048 個字元 |
| `style` | 套用至整個影片的可選視覺風格（預設：none）。 | COMBO | 否 | 多個可用選項（PixVerse V6 風格預設集） |

注意：提示詞必須包含至少一個非空白字元，且最多 5000 個字元；負面提示詞若提供，則必須最多 2048 個字元。輸出影片的長寬比一律與輸入圖像相符，因此無需設定長寬比。僅接受單一輸入圖像。當內容審核失敗、供應商帳戶額度不足，或同時進行的生成已達上限時，PixVerse 可能會拒絕請求。
