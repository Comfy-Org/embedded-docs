# PixVerse V6 تصویر به ویدئو

این گره یک تصویر ورودی را با مدل PixVerse V6 به انیمیشن تبدیل می‌کند و یک ویدیو بازمی‌گرداند، به‌صورت اختیاری همراه با یک قطعه صوتی بومی. ویدیوی خروجی نسبت ابعاد تصویر ورودی را حفظ می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی برای انیمیشن‌سازی. | IMAGE | بله | یک تصویر |
| `مدل` | تنظیمات مدل و تولید. | DYNAMIC_COMBO | بله | "PixVerse V6" |

### ورودی‌های PixVerse V6

این تنظیمات زمانی نمایش داده می‌شوند که مدل "PixVerse V6" انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت برای تولید ویدیو (پیش‌فرض: خالی). | STRING | بله | 1 تا 5000 کاراکتر |
| `quality` | وضوح خروجی. ضلع بلند را تعیین می‌کند: 360p برابر 640px، 540p برابر 1024px، 720p برابر 1280px، 1080p برابر 1920px (پیش‌فرض: "720p"). | COMBO | بله | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | طول ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 1 تا 15 |
| `generate_audio` | تولید یک قطعه صوتی بومی همراه با ویدیو (پیش‌فرض: true). | BOOLEAN | بله | true یا false |
| `multi_clip` | اجازه دادن به مدل برای تقسیم ویدیو به چند نما به‌جای یک برداشت پیوسته (پیش‌فرض: false). | BOOLEAN | بله | true یا false |
| `seed` | بذر تولید ویدیو. PixVerse آن را ثبت می‌کند اما اجرا را از روی آن بازتولید نمی‌کند (پیش‌فرض: 42، کنترل پس از تولید فعال است). | INT | بله | 0 تا 2147483647 |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در ویدیو (پیش‌فرض: خالی). | STRING | خیر | حداکثر 2048 کاراکتر |
| `style` | سبک بصری اختیاری که روی کل ویدیو اعمال می‌شود (پیش‌فرض: هیچ‌کدام). | COMBO | خیر | گزینه‌های متعدد موجود است (پیش‌تنظیم‌های سبک PixVerse V6) |

توجه: پرامپت باید حداقل یک کاراکتر غیرفاصله و حداکثر 5000 کاراکتر داشته باشد؛ پرامپت منفی، در صورت ارائه، باید حداکثر 2048 کاراکتر باشد. ویدیوی خروجی همیشه با نسبت ابعاد تصویر ورودی مطابقت دارد، بنابراین نیازی به تنظیم نسبت ابعاد نیست. فقط یک تصویر ورودی پذیرفته می‌شود. PixVerse ممکن است یک درخواست را رد کند زمانی که بازبینی محتوا شکست بخورد، موجودی حساب ارائه‌دهنده تمام شود، یا حداکثر تعداد تولیدهای هم‌زمان در حال اجرا باشد.
