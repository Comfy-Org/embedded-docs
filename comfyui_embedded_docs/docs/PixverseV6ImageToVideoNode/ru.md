# PixVerse V6: из изображения в видео

Этот узел анимирует входное изображение с помощью модели PixVerse V6 и возвращает видео, опционально со встроенной аудиодорожкой. Выходное видео сохраняет соотношение сторон входного изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель и настройки генерации. | DYNAMIC_COMBO | Да | "PixVerse V6" |
| `изображение` | Входное изображение для анимации. | IMAGE | Да | Одно изображение |

### Входы PixVerse V6

Эти настройки появляются при выборе модели "PixVerse V6".

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт для генерации видео (по умолчанию: пусто). | STRING | Да | от 1 до 5000 символов |
| `quality` | Разрешение выходного видео. Определяет длинную сторону: 360p — 640px, 540p — 1024px, 720p — 1280px, 1080p — 1920px (по умолчанию: "720p"). | COMBO | Да | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | Длительность генерируемого видео в секундах (по умолчанию: 5). | INT | Да | от 1 до 15 |
| `generate_audio` | Создавать встроенную аудиодорожку вместе с видео (по умолчанию: true). | BOOLEAN | Да | true or false |
| `multi_clip` | Позволяет модели разделить видео на несколько планов вместо одного непрерывного дубля (по умолчанию: false). | BOOLEAN | Да | true or false |
| `seed` | Сид для генерации видео. PixVerse записывает его, но не воспроизводит генерацию по нему (по умолчанию: 42, управление после генерации включено). | INT | Да | от 0 до 2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов в видео (по умолчанию: пусто). | STRING | Нет | До 2048 символов |
| `style` | Необязательный визуальный стиль, применяемый ко всему видео (по умолчанию: none). | COMBO | Нет | Доступно несколько вариантов (пресеты стилей PixVerse V6) |

Примечание. Промпт должен содержать хотя бы один непробельный символ и не более 5000 символов; негативный промпт, если он указан, должен содержать не более 2048 символов. Выходное видео всегда соответствует соотношению сторон входного изображения, поэтому настройка соотношения сторон не требуется. Принимается только одно входное изображение. PixVerse может отклонить запрос, если не пройдена модерация контента, если на аккаунте провайдера закончились кредиты или если уже запущено максимальное количество одновременных генераций.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, включая встроенную аудиодорожку, если `generate_audio` включён. Соотношение сторон соответствует входному изображению. | VIDEO |
