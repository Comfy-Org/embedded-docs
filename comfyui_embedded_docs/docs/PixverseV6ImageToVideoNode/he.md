# PixverseV6ImageToVideoNode

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט להנפשה. | IMAGE | כן | תמונה בודדת |
| `model` | הגדרות מודל ויצירה. | DYNAMIC_COMBO | כן | "PixVerse V6" |

### קלטים של PixVerse V6

הגדרות אלו מופיעות כאשר המודל "PixVerse V6" נבחר.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת הסרטון (ברירת מחדל: ריק). | STRING | כן | 1 עד 5000 תווים |
| `quality` | רזולוציית הפלט. קובע את הצד הארוך: 360p הוא 640px, 540p 1024px, 720p 1280px, 1080p 1920px (ברירת מחדל: "720p"). | COMBO | כן | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | אורך הסרטון הנוצר בשניות (ברירת מחדל: 5). | INT | כן | 1 עד 15 |
| `generate_audio` | יצירת רצועת אודיו מקורית יחד עם הסרטון (ברירת מחדל: true). | BOOLEAN | כן | true or false |
| `multi_clip` | לאפשר למודל לחתוך את הסרטון למספר שוטים במקום צילום רציף אחד (ברירת מחדל: false). | BOOLEAN | כן | true or false |
| `seed` | Seed ליצירת הסרטון. PixVerse רושם אותו אך אינו משחזר ריצה ממנו (ברירת מחדל: 42, השליטה לאחר יצירה מופעלת). | INT | כן | 0 עד 2147483647 |
| `negative_prompt` | תיאור טקסטואלי אופציונלי של אלמנטים לא רצויים בסרטון (ברירת מחדל: ריק). | STRING | לא | עד 2048 תווים |
| `style` | סגנון חזותי אופציונלי שמוחל על כל הסרטון (ברירת מחדל: ללא). | COMBO | לא | אפשרויות מרובות זמינות (פריסטים של סגנון PixVerse V6) |

הערה: הפרומפט חייב להכיל לפחות תו אחד שאינו רווח ולכל היותר 5000 תווים; הפרומפט השלילי, אם סופק, חייב להיות באורך של לכל היותר 2048 תווים. סרטון הפלט תמיד תואם את יחס הגובה-רוחב של תמונת הקלט, ולכן אין צורך בהגדרת יחס גובה-רוחב. מתקבלת רק תמונת קלט אחת. PixVerse עשוי לדחות בקשה כאשר סינון התוכן נכשל, כאשר לחשבון הספק נגמרו הקרדיטים, או כאשר מספר היצירות בו-זמניות המקסימלי כבר פועל.
