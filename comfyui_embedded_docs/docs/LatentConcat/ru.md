# Объединение латентов

Узел LatentConcat объединяет два латентных сэмпла, соединяя их вдоль выбранного измерения. Он принимает два латентных входных сэмпла и конкатенирует их по оси x, y или t, с возможностью управления тем, какой сэмпл будет первым. Перед выполнением конкатенации узел автоматически приводит размер пакета второго входного сэмпла к размеру пакета первого.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples1` | Первый латентный сэмпл для конкатенации | LATENT | Да | - |
| `samples2` | Второй латентный сэмпл для конкатенации | LATENT | Да | - |
| `dim` | Измерение, вдоль которого выполняется конкатенация латентных сэмплов. Положительные значения (x, y, t) размещают `samples1` перед `samples2` в результате. Отрицательные значения (-x, -y, -t) размещают `samples2` перед `samples1`. Соответствие измерений: x = ширина, y = высота, t = время/кадры | COMBO | Да | `"x"`<br>`"-x"`<br>`"y"`<br>`"-y"`<br>`"t"`<br>`"-t"` |

**Примечание:** Второй латентный сэмпл (`samples2`) автоматически приводится к размеру пакета первого латентного сэмпла (`samples1`) перед конкатенацией.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Результирующие латентные сэмплы, полученные путём объединения двух входных сэмплов вдоль указанного измерения | LATENT |
