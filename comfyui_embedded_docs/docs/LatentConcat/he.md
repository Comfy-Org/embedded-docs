# LatentConcat

צומת LatentConcat משלבת שתי דגימות לטנט על ידי חיבורן יחד לאורך ממד נבחר. היא מקבלת שני קלטי לטנט ומשרשרת אותם לאורך ציר x, y או t, עם אפשרות לשלוט איזו דגימה תופיע ראשונה. הצומת מתאים אוטומטית את גודל האצווה של הקלט השני כך שיתאים לראשון לפני ביצוע השרשור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `samples1` | דגימת הלטנט הראשונה לשרשור | LATENT | כן | - |
| `samples2` | דגימת הלטנט השנייה לשרשור | LATENT | כן | - |
| `dim` | הממד שלאורכו יש לשרשר את דגימות הלטנט. ערכים חיוביים (x, y, t) מציבים את samples1 לפני samples2 בתוצאה. ערכים שליליים (-x, -y, -t) מציבים את samples2 לפני samples1. מיפוי הממדים הוא: x = רוחב, y = גובה, t = זמן/פריימים | COMBO | כן | `"x"`<br>`"-x"`<br>`"y"`<br>`"-y"`<br>`"t"`<br>`"-t"` |

**הערה:** דגימת הלטנט השנייה (`samples2`) משוכפלת אוטומטית לפי הצורך כדי להתאים לגודל האצווה של דגימת הלטנט הראשונה (`samples1`) לפני השרשור.
