# کاهش مش

یک مش سه‌بعدی را با استفاده از ساده‌سازی QEM (معیار خطای کوآدریک) به تعداد وجه هدف کاهش می‌دهد و محاسبات را روی دستگاه محاسبه فعال اجرا می‌کند. حالت قرارگیری `"midpoint"` همان پیش‌تنظیم cumesh-faithful است که بهترین کیفیت را ارائه می‌دهد و در عین حال ویژگی‌های نازک مانند مو را حفظ می‌کند، در حالی که `"qem"` رأس‌ها را در موقعیت بهینه QEM قرار می‌دهد و کنترل‌های اختیاری خط و یال ویژگی را فراهم می‌کند. مش خروجی جوش‌خورده باقی می‌ماند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی برای ساده‌سازی. | MESH | بله | - |
| `target_face_count` | حداکثر تعداد وجه هدف. مقدار 0 آن را غیرفعال می‌کند. (پیش‌فرض: 200000) | INT | بله | 0 تا 50000000 |
| `placement_mode` | midpoint: cumesh-faithful (توصیه‌شده). qem: قرارگیری بهینه QEM. (پیش‌فرض: `"midpoint"`) | DYNAMIC_COMBO | بله | `"midpoint"`<br>`"qem"` |

### ورودی‌های Midpoint

حالت قرارگیری `"midpoint"` هیچ زیرپارامتر اضافه‌ای را در معرض نمایش قرار نمی‌دهد؛ از پیش‌تنظیم پیش‌فرض قرارگیری midpoint استفاده می‌کند.

### ورودی‌های QEM

زیرپارامترهای زیر فقط زمانی در رابط کاربری ظاهر می‌شوند که `placement_mode` روی `"qem"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | وزن کوآدریک خط برای هر یال؛ برجستگی‌ها/فرورفتگی‌های تیز را حفظ می‌کند. 0 = خاموش. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 تا 100.0 |
| `feature_edge_quadric_weight` | وزن کوآدریک اضافی روی یال‌های ویژگی دووجهی (چین‌ها). 0 = خاموش. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 تا 1000.0 |
| `feature_edge_min_dihedral_deg` | حداقل زاویه دووجهی (درجه) برای اینکه یک یال به‌عنوان یال ویژگی در نظر گرفته شود. (پیش‌فرض: 30.0) | FLOAT | خیر | 0.0 تا 180.0 |
| `clamp_v_to_edge` | موقعیت بهینه QEM را روی پاره‌خط یال فروپاشیده تصویر می‌کند. (پیش‌فرض: true) | BOOLEAN | خیر | `true`<br>`false` |

توجه: کاهش تعداد وجه زمانی انجام نمی‌شود که `target_face_count` برابر 0 باشد یا مش از قبل تعداد وجهی بیش از هدف نداشته باشد. گره یک خلاصه کاهش وجه را روی خودش نمایش می‌دهد، برای مثال `faces: 1.23M → 200K (-84%)`.
