# DecimateMesh

DecimateMesh упрощает 3D-сетку до заданного количества граней с помощью упрощения на основе метрики квадратичной ошибки (QEM), выполняя вычисления на активном вычислительном устройстве. Режим размещения `"midpoint"` — это предустановка, соответствующая cumesh, обеспечивающая наилучшее качество и сохраняющая тонкие элементы, такие как волосы, тогда как `"qem"` размещает вершины в позиции, оптимальной по QEM, с дополнительными опциями управления рёбрами и линиями. Выходная сетка остаётся сварной.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-сетка для упрощения. | MESH | Да | - |
| `target_face_count` | Целевое максимальное количество граней. 0 отключает. (по умолчанию: 200000) | INT | Да | 0 до 50000000 |
| `placement_mode` | midpoint: соответствует cumesh (рекомендуется). qem: размещение, оптимальное по QEM. (по умолчанию: `"midpoint"`) | DYNAMIC_COMBO | Да | `"midpoint"`<br>`"qem"` |

### Входы Midpoint

Режим размещения `"midpoint"` не требует дополнительных подпараметров; он использует предустановку размещения по умолчанию для midpoint.

### Входы QEM

Следующие подпараметры появляются в интерфейсе только когда для `placement_mode` задано значение `"qem"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | Вес линейной квадратичной метрики на ребро; сохраняет острые гребни/впадины. 0 = выкл. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 до 100.0 |
| `feature_edge_quadric_weight` | Дополнительный вес квадратичной метрики на двугранных характерных рёбрах (сгибах). 0 = выкл. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 до 1000.0 |
| `feature_edge_min_dihedral_deg` | Минимальный двугранный угол (в градусах), при котором ребро считается характерным. (по умолчанию: 30.0) | FLOAT | Нет | 0.0 до 180.0 |
| `clamp_v_to_edge` | Проецировать позицию, оптимальную по QEM, на сегмент схлопнутого ребра. (по умолчанию: true) | BOOLEAN | Нет | `true`<br>`false` |

Примечание: упрощение пропускается, когда `target_face_count` равен 0 или когда сетка уже содержит меньше граней, чем целевое значение. Узел отображает сводку сокращения граней, например `faces: 1.23M → 200K (-84%)`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Упрощённая сетка с уменьшенным количеством граней; связность остаётся сварной. | MESH |
