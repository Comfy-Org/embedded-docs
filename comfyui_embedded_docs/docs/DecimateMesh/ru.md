# Упростить сетку

Упрощает 3D-сетку до целевого количества граней с помощью упрощения QEM (quadric error metric), выполняя вычисления на активном вычислительном устройстве. Режим размещения `"midpoint"` — это пресет, точно соответствующий cumesh, который обеспечивает наилучшее качество при сохранении тонких элементов, таких как волосы, тогда как `"qem"` размещает вершины в QEM-оптимальной позиции с дополнительными элементами управления линиями и рёберными особенностями. Выходная сетка остаётся сшитой.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-сетка для упрощения. | MESH | Да | - |
| `target_face_count` | Целевое максимальное количество граней. 0 отключает. (по умолчанию: 200000) | INT | Да | 0–50000000 |
| `placement_mode` | midpoint: точно как cumesh (рекомендуется). qem: QEM-оптимальное размещение. (по умолчанию: `"midpoint"`) | DYNAMIC_COMBO | Да | `"midpoint"`<br>`"qem"` |

### Входы Midpoint

Режим размещения `"midpoint"` не предоставляет дополнительных подпараметров; он использует стандартный пресет размещения midpoint.

### Входы QEM

Следующие подпараметры появляются в интерфейсе только когда `placement_mode` имеет значение `"qem"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | Вес линейной квадратичной метрики на ребро; сохраняет резкие гребни/впадины. 0 = выключено. (по умолчанию: 0.0) | FLOAT | Нет | 0.0–100.0 |
| `feature_edge_quadric_weight` | Дополнительный вес квадратичной метрики на двугранных рёбрах особенностей (сгибах). 0 = выключено. (по умолчанию: 0.0) | FLOAT | Нет | 0.0–1000.0 |
| `feature_edge_min_dihedral_deg` | Минимальный двугранный угол (в градусах), при котором ребро считается рёберной особенностью. (по умолчанию: 30.0) | FLOAT | Нет | 0.0–180.0 |
| `clamp_v_to_edge` | Проецировать QEM-оптимальную позицию на сегмент схлопываемого ребра. (по умолчанию: true) | BOOLEAN | Нет | `true`<br>`false` |

Примечание: Децимация пропускается, когда `target_face_count` равен 0 или когда в сетке уже не больше граней, чем целевое значение. Узел отображает на себе сводку по сокращению числа граней, например `faces: 1.23M → 200K (-84%)`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `mesh` | Упрощённая сетка с уменьшенным количеством граней; связность остаётся сшитой. | MESH |
