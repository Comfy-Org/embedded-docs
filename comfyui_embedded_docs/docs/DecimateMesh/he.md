# DecimateMesh

מפשט מש תלת-ממדי למספר פאות יעד באמצעות QEM (מדד שגיאת קוודריקה), תוך ביצוע החישוב בהתקן החישוב הפעיל. מצב המיקום `"midpoint"` הוא הפריסט הנאמן ל-cumesh, המספק את האיכות הטובה ביותר תוך שימור תכונות דקות כגון שיער, ואילו `"qem"` מציב קודקודים במיקום האופטימלי לפי QEM עם בקרות אופציונליות של קו וקשתות תכונה. המש בפלט נשאר מרותך.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | המש התלת-ממדי שיש לפשט. | MESH | כן | - |
| `target_face_count` | מספר פאות מרבי ליעד. 0 מנטרל. (ברירת מחדל: 200000) | INT | כן | 0 עד 50000000 |
| `placement_mode` | midpoint: נאמן ל-cumesh (מומלץ). qem: מיקום אופטימלי לפי QEM. (ברירת מחדל: `"midpoint"`) | DYNAMIC_COMBO | כן | `"midpoint"`<br>`"qem"` |

### קלטים של Midpoint

מצב המיקום `"midpoint"` אינו חושף תת-פרמטרים נוספים; הוא משתמש בפריסט מיקום ה-midpoint המוגדר כברירת מחדל.

### קלטים של QEM

תת-הפרמטרים הבאים מופיעים בממשק רק כאשר `placement_mode` מוגדר ל-`"qem"`.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | משקל קוודריקה של קו לכל קשת; משמר רכסים/עמקים חדים. 0 = כבוי. (ברירת מחדל: 0.0) | FLOAT | לא | 0.0 עד 100.0 |
| `feature_edge_quadric_weight` | משקל קוודריקה נוסף על קשתות תכונה דיהדרליות (קמטים). 0 = כבוי. (ברירת מחדל: 0.0) | FLOAT | לא | 0.0 עד 1000.0 |
| `feature_edge_min_dihedral_deg` | זווית דיהדרלית מינימלית (במעלות) כדי להחשיב קשת כקשת תכונה. (ברירת מחדל: 30.0) | FLOAT | לא | 0.0 עד 180.0 |
| `clamp_v_to_edge` | הקרן את המיקום האופטימלי לפי QEM על מקטע הקשת המכווץ. (ברירת מחדל: true) | BOOLEAN | לא | `true`<br>`false` |

הערה: דצימציה מדולגת כאשר `target_face_count` הוא 0 או כאשר למש כבר אין יותר פאות מהיעד. הצומת מציג סיכום הפחתת פאות על עצמו, לדוגמה `faces: 1.23M → 200K (-84%)`.
