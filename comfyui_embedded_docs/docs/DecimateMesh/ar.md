# تبسيط الشبكة

يبسّط شبكة ثلاثية الأبعاد إلى عدد أوجه مستهدف باستخدام تبسيط QEM (مقياس الخطأ التربيعي)، مع تنفيذ الحساب على جهاز الحوسبة النشط. وضع الإسناد `"midpoint"` هو الإعداد المسبق cumesh-faithful الذي يوفر أفضل جودة مع الحفاظ على الميزات الرقيقة مثل الشعر، بينما يضع `"qem"` الرؤوس عند الموضع الأمثل وفق QEM مع عناصر تحكم اختيارية للخطوط وحواف الميزات. تبقى الشبكة الناتجة ملحومة.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة ثلاثية الأبعاد المراد تبسيطها. | MESH | نعم | - |
| `target_face_count` | الحد الأقصى المستهدف للأوجه. القيمة 0 تعطّل. (الافتراضي: 200000) | INT | نعم | 0 إلى 50000000 |
| `placement_mode` | midpoint: cumesh-faithful (موصى به). qem: إسناد أمثل وفق QEM. (الافتراضي: `"midpoint"`) | DYNAMIC_COMBO | نعم | `"midpoint"`<br>`"qem"` |

### مدخلات Midpoint

لا يعرض وضع الإسناد `"midpoint"` أي معاملات فرعية إضافية؛ بل يستخدم الإعداد المسبق الافتراضي لإسناد midpoint.

### مدخلات QEM

تظهر المعاملات الفرعية التالية في الواجهة فقط عندما يكون `placement_mode` مضبوطًا على `"qem"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | وزن الخط التربيعي لكل حافة؛ يحافظ على النتوءات/المنخفضات الحادة. 0 = معطّل. (الافتراضي: 0.0) | FLOAT | لا | 0.0 إلى 100.0 |
| `feature_edge_quadric_weight` | وزن تربيعي إضافي على حواف الميزات ثنائية السطوح (الطيات). 0 = معطّل. (الافتراضي: 0.0) | FLOAT | لا | 0.0 إلى 1000.0 |
| `feature_edge_min_dihedral_deg` | الحد الأدنى للزاوية ثنائية السطوح (بالدرجات) لاعتبار الحافة حافة ميزة. (الافتراضي: 30.0) | FLOAT | لا | 0.0 إلى 180.0 |
| `clamp_v_to_edge` | إسقاط الموضع الأمثل وفق QEM على قطعة الحافة المنهارة. (الافتراضي: true) | BOOLEAN | لا | `true`<br>`false` |

ملاحظة: يتم تخطي التقليص عندما يكون `target_face_count` مساويًا 0 أو عندما لا تحتوي الشبكة بالفعل على أوجه أكثر من العدد المستهدف. تعرض العقدة ملخصًا لتقليل الأوجه على نفسها، على سبيل المثال `faces: 1.23M → 200K (-84%)`.
