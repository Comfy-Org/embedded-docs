# IdeogramV2

צומת Ideogram V2 יוצר תמונות באמצעות מודל הבינה המלאכותית Ideogram V2. הוא מקבל הנחיות טקסט והגדרות יצירה שונות כדי ליצור תמונות דרך שירות API. הצומת תומך ביחסי רוחב-גובה, רזולוציות ואפשרויות סגנון שונים כדי להתאים אישית את תמונות הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `turbo` | האם להשתמש במצב טורבו (יצירה מהירה יותר, ייתכן שאיכות נמוכה יותר) (ברירת מחדל: False) | BOOLEAN | לא | - |
| `aspect_ratio` | יחס הרוחב-גובה ליצירת התמונה. מתעלמים ממנו אם resolution אינו מוגדר ל-AUTO. (ברירת מחדל: "1:1") | COMBO | לא | "1:1"<br>"4:3"<br>"3:4"<br>"16:9"<br>"9:16"<br>"2:1"<br>"1:2"<br>"3:2"<br>"2:3"<br>"4:5"<br>"5:4" |
| `resolution` | הרזולוציה ליצירת התמונה. אם אינה מוגדרת ל-AUTO, היא דורסת את ההגדרה aspect_ratio. (ברירת מחדל: "Auto") | COMBO | לא | "Auto"<br>"512 x 1536"<br>"576 x 1408"<br>"576 x 1472"<br>"576 x 1536"<br>"640 x 1024"<br>"640 x 1344"<br>"640 x 1408"<br>"640 x 1472"<br>"640 x 1536"<br>"704 x 1152"<br>"704 x 1216"<br>"704 x 1280"<br>"704 x 1344"<br>"704 x 1408"<br>"704 x 1472"<br>"720 x 1280"<br>"736 x 1312"<br>"768 x 1024"<br>"768 x 1088"<br>"768 x 1152"<br>"768 x 1216"<br>"768 x 1232"<br>"768 x 1280"<br>"768 x 1344"<br>"832 x 960"<br>"832 x 1024"<br>"832 x 1088"<br>"832 x 1152"<br>"832 x 1216"<br>"832 x 1248"<br>"864 x 1152"<br>"896 x 960"<br>"896 x 1024"<br>"896 x 1088"<br>"896 x 1120"<br>"896 x 1152"<br>"960 x 832"<br>"960 x 896"<br>"960 x 1024"<br>"960 x 1088"<br>"1024 x 640"<br>"1024 x 768"<br>"1024 x 832"<br>"1024 x 896"<br>"1024 x 960"<br>"1024 x 1024"<br>"1088 x 768"<br>"1088 x 832"<br>"1088 x 896"<br>"1088 x 960"<br>"1120 x 896"<br>"1152 x 704"<br>"1152 x 768"<br>"1152 x 832"<br>"1152 x 864"<br>"1152 x 896"<br>"1216 x 704"<br>"1216 x 768"<br>"1216 x 832"<br>"1232 x 768"<br>"1248 x 832"<br>"1280 x 704"<br>"1280 x 720"<br>"1280 x 768"<br>"1280 x 800"<br>"1312 x 736"<br>"1344 x 640"<br>"1344 x 704"<br>"1344 x 768"<br>"1408 x 576"<br>"1408 x 640"<br>"1408 x 704"<br>"1472 x 576"<br>"1472 x 640"<br>"1472 x 704"<br>"1536 x 512"<br>"1536 x 576"<br>"1536 x 640" |
| `magic_prompt_option` | קובע אם יש להשתמש ב-MagicPrompt ביצירה (ברירת מחדל: "AUTO") | COMBO | לא | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | זרע אקראי ליצירה (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `style_type` | סוג הסגנון ליצירה (V2 בלבד) (ברירת מחדל: "NONE") | COMBO | לא | "AUTO"<br>"GENERAL"<br>"REALISTIC"<br>"DESIGN"<br>"RENDER_3D"<br>"ANIME" |
| `negative_prompt` | תיאור של מה שיש להוציא מהתמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `num_images` | מספר התמונות ליצירה (ברירת מחדל: 1) | INT | לא | 1-8 |

**הערה:** כאשר `resolution` אינו מוגדר ל-"Auto", הוא דורס את ההגדרה `aspect_ratio`. בפרמטר `num_images` יש מגבלה מקסימלית של 8 תמונות לכל יצירה.
