# OpenAI ChatGPT

تولّد هذه العقدة استجابات نصية باستخدام نماذج GPT من OpenAI. ترسل موجّهًا نصيًا، واختياريًا صورًا أو ملفات كسياق، وتعيد الإجابة على هيئة سلسلة نصية. توجد كل الإعدادات داخل محدد `model`: يؤدي اختيار نموذج إلى عرض مستويات `reasoning_effort` الخاصة به، وحد الرموز، والبذرة وموجّه النظام، لذا لا حاجة إلى عقدة إعداد منفصلة. تستبدل هذه العقدة عقدة OpenAI ChatGPT السابقة، التي باتت شيفرة المصدر تصنّفها على أنها مهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم لتوليد الاستجابة. يعرض كل نموذج مستويات `reasoning_effort` التي يدعمها (افتراضي: `"gpt-6.2-sol"`). | DYNAMIC_COMBO | نعم | `"gpt-6.2-sol"`<br>`"gpt-6.2-astra"`<br>`"gpt-6-astra"`<br>`"gpt-6.1-sol"`<br>`"gpt-6.1-terra"`<br>`"gpt-6-sol"`<br>`"gpt-6-luna"`<br>`"gpt-5.6-sol"`<br>`"gpt-5.6-terra"`<br>`"gpt-5.6-luna"`<br>`"gpt-5.5-pro"`<br>`"gpt-5.5"` |
| `prompt` | إدخال نصي إلى النموذج (افتراضي: سلسلة فارغة). | STRING | نعم | - |
| `images` | حقل قابل للتوسيع: وصّل من 1..16 عنصرًا (`image_1`، `image_2`، ...). صورة/صور اختيارية تُستخدم كسياق للنموذج. | IMAGE | لا | 0 إلى 16 صورة |
| `files` | ملف/ملفات اختيارية تُستخدم كسياق للنموذج. تقبل مدخلات من عقدة OpenAI ChatGPT Input Files. | OPENAI_INPUT_FILES | لا | - |
| `reasoning_effort` | مقدار استدلال النموذج قبل الإجابة. تستهلك المستويات الأعلى عددًا أكبر من الرموز وتستغرق وقتًا أطول. تعتمد المستويات المتاحة على النموذج المحدد (افتراضي: `"medium"`، و`"high"` من أجل `gpt-5.5-pro`). | COMBO | نعم | انظر قائمة كل نموذج أدناه |
| `max_output_tokens` | الحد الأقصى لعدد الرموز المراد توليدها، بما في ذلك رموز الاستدلال. قد تؤدي قيمة منخفضة مع `reasoning_effort` مرتفع إلى عدم ترك مساحة للإجابة (افتراضي: 32768). | INT | نعم | 16 إلى 128000 |
| `seed` | يتحكم `seed` في ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن `seed` (افتراضي: 42). | INT | نعم | 0 إلى 2147483647 |
| `system_prompt` | تعليمات أساسية تحدد سلوك النموذج (افتراضي: سلسلة فارغة). | STRING | لا | - |

### مستويات جهد الاستدلال لكل نموذج

- `gpt-6.2-sol`، `gpt-6.2-astra`، `gpt-6-astra`، `gpt-6.1-sol`: `"low"`، `"medium"`، `"high"`، `"xhigh"`، `"max"`، الافتراضي `"medium"`.
- `gpt-6.1-terra`، `gpt-6-sol`، `gpt-6-luna`، `gpt-5.6-sol`، `gpt-5.6-terra`، `gpt-5.6-luna`: `"none"`، `"low"`، `"medium"`، `"high"`، `"xhigh"`، `"max"`، الافتراضي `"medium"`.
- `gpt-5.5-pro`: `"medium"`، `"high"`، `"xhigh"`، الافتراضي `"high"`.
- `gpt-5.5`: `"none"`، `"low"`، `"medium"`، `"high"`، `"xhigh"`، الافتراضي `"medium"`.

### ملاحظات حول السلوك

- لا يُعاد إلا نص الإجابة. تُتجاهل الرسائل التي يصدرها النموذج في مرحلة التعليق أثناء التفكير.
- إذا نفدت ميزانية الرموز قبل كتابة الإجابة، فتُطلق العقدة خطأً يطلب منك زيادة `max_output_tokens`.
- تُرسل الصور بدقتها الخاصة مع مستوى التفاصيل التلقائي الخاص بـ API، لذا تستهلك الصور الكبيرة عددًا أكبر من الرموز.
- يُخزَّن كل طلب لدى OpenAI، ويجمع النص المُعاد أجزاء الإجابة بأسطر جديدة.
