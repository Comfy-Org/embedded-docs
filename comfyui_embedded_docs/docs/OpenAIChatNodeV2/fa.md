# OpenAI ChatGPT

این گره با مدل‌های GPT شرکت OpenAI پاسخ‌های متنی تولید می‌کند. یک پرامپت متنی و به‌صورت اختیاری تصاویر یا فایل‌ها را به‌عنوان زمینه ارسال می‌کند و پاسخ را به‌صورت رشته برمی‌گرداند. همه تنظیمات داخل انتخاب‌گر `model` قرار دارند: انتخاب یک مدل، سطوح `reasoning_effort`، محدودیت توکن، seed و پرامپت سیستمی مخصوص همان مدل را نمایش می‌دهد؛ بنابراین نیازی به گره پیکربندی جداگانه نیست. این گره جایگزین گره پیشین OpenAI ChatGPT می‌شود که کد منبع اکنون آن را منسوخ علامت‌گذاری کرده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید پاسخ استفاده می‌شود. هر مدل سطوح `reasoning_effort` را که پشتیبانی می‌کند نمایش می‌دهد (پیش‌فرض: `"gpt-6.2-sol"`). | DYNAMIC_COMBO | بله | `"gpt-6.2-sol"`<br>`"gpt-6.2-astra"`<br>`"gpt-6-astra"`<br>`"gpt-6.1-sol"`<br>`"gpt-6.1-terra"`<br>`"gpt-6-sol"`<br>`"gpt-6-luna"`<br>`"gpt-5.6-sol"`<br>`"gpt-5.6-terra"`<br>`"gpt-5.6-luna"`<br>`"gpt-5.5-pro"`<br>`"gpt-5.5"` |
| `prompt` | ورودی متنی به مدل (پیش‌فرض: رشته خالی). | STRING | بله | - |
| `images` | جایگاه قابل‌افزایش: 1..16 مورد را متصل کنید (`image_1`، `image_2`، ...). تصویر(های) اختیاری که به‌عنوان زمینه برای مدل استفاده می‌شود. | IMAGE | خیر | 0 تا 16 تصویر |
| `files` | فایل(های) اختیاری که به‌عنوان زمینه برای مدل استفاده می‌شود. ورودی‌هایی را از گره OpenAI ChatGPT Input Files می‌پذیرد. | OPENAI_INPUT_FILES | خیر | - |
| `reasoning_effort` | میزان استدلال مدل پیش از پاسخ دادن. سطوح بالاتر توکن بیشتری مصرف می‌کنند و زمان بیشتری می‌برند. سطوح ارائه‌شده به مدل انتخاب‌شده بستگی دارد (پیش‌فرض: `"medium"`، برای `gpt-5.5-pro`: `"high"`). | COMBO | بله | فهرست هر مدل در ادامه را ببینید |
| `max_output_tokens` | حداکثر توکن‌ها برای تولید، شامل توکن‌های استدلال. مقدار کم همراه با `reasoning_effort` بالا می‌تواند فضایی برای پاسخ باقی نگذارد (پیش‌فرض: 32768). | INT | بله | 16 تا 128000 |
| `seed` | `seed` کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |
| `system_prompt` | دستورالعمل‌های پایه‌ای که رفتار مدل را تعیین می‌کنند (پیش‌فرض: رشته خالی). | STRING | خیر | - |

### سطوح تلاش استدلال برای هر مدل

- `gpt-6.2-sol`، `gpt-6.2-astra`، `gpt-6-astra`، `gpt-6.1-sol`: `"low"`، `"medium"`، `"high"`، `"xhigh"`، `"max"`، پیش‌فرض `"medium"`.
- `gpt-6.1-terra`، `gpt-6-sol`، `gpt-6-luna`، `gpt-5.6-sol`، `gpt-5.6-terra`، `gpt-5.6-luna`: `"none"`، `"low"`، `"medium"`، `"high"`، `"xhigh"`، `"max"`، پیش‌فرض `"medium"`.
- `gpt-5.5-pro`: `"medium"`، `"high"`، `"xhigh"`، پیش‌فرض `"high"`.
- `gpt-5.5`: `"none"`، `"low"`، `"medium"`، `"high"`، `"xhigh"`، پیش‌فرض `"medium"`.

### نکاتی درباره رفتار

- فقط متن پاسخ برگردانده می‌شود. پیام‌هایی که مدل در مرحلهٔ اظهارنظر خود هنگام اندیشیدن منتشر می‌کند نادیده گرفته می‌شوند.
- اگر بودجه توکن پیش از نوشته‌شدن پاسخ تمام شود، گره خطایی ایجاد می‌کند که به شما می‌گوید `max_output_tokens` را افزایش دهید.
- تصاویر با وضوح خودشان و سطح جزئیات خودکار API فرستاده می‌شوند، بنابراین تصاویر بزرگ‌تر توکن بیشتری مصرف می‌کنند.
- هر درخواست در سمت OpenAI ذخیره می‌شود، و متن برگردانده‌شده بخش‌های پاسخ را با خطوط جدید به هم می‌پیوندد.
