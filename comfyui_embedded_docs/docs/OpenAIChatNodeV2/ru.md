# OpenAI ChatGPT

Этот узел генерирует текстовые ответы с помощью моделей GPT от OpenAI. Он отправляет текстовый промпт и, необязательно, изображения или файлы в качестве контекста, а затем возвращает ответ в виде строки. Все настройки находятся внутри селектора `model`: при выборе модели отображаются её собственные уровни `reasoning_effort`, лимит токенов, seed и системный промпт, поэтому отдельный узел конфигурации не нужен. Этот узел заменяет более ранний узел OpenAI ChatGPT, который в исходном коде теперь помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации ответа. Каждая модель предоставляет поддерживаемые ею уровни `reasoning_effort` (по умолчанию: `"gpt-6.2-sol"`). | DYNAMIC_COMBO | Да | `"gpt-6.2-sol"`<br>`"gpt-6.2-astra"`<br>`"gpt-6-astra"`<br>`"gpt-6.1-sol"`<br>`"gpt-6.1-terra"`<br>`"gpt-6-sol"`<br>`"gpt-6-luna"`<br>`"gpt-5.6-sol"`<br>`"gpt-5.6-terra"`<br>`"gpt-5.6-luna"`<br>`"gpt-5.5-pro"`<br>`"gpt-5.5"` |
| `prompt` | Текстовый ввод для модели (по умолчанию: пустая строка). | STRING | Да | - |
| `images` | Расширяемый слот: подключите от 1 до 16 элементов (`image_1`, `image_2`, ...). Необязательные изображения, используемые как контекст для модели. | IMAGE | Нет | от 0 до 16 изображений |
| `files` | Необязательные файлы, используемые как контекст для модели. Принимает входы от узла OpenAI ChatGPT Input Files. | OPENAI_INPUT_FILES | Нет | - |
| `reasoning_effort` | Насколько глубоко модель рассуждает перед ответом. Более высокие уровни используют больше токенов и занимают больше времени. Доступные уровни зависят от выбранной модели (по умолчанию: `"medium"`, `"high"` для `gpt-5.5-pro`). | COMBO | Да | См. список по моделям ниже |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая токены рассуждения. Низкое значение вместе с высоким `reasoning_effort` может не оставить места для ответа (по умолчанию: 32768). | INT | Да | от 16 до 128000 |
| `seed` | Seed управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели (по умолчанию: пустая строка). | STRING | Нет | - |

### Уровни reasoning effort для каждой модели

- `gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6-astra`, `gpt-6.1-sol`: `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, по умолчанию `"medium"`.
- `gpt-6.1-terra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, по умолчанию `"medium"`.
- `gpt-5.5-pro`: `"medium"`, `"high"`, `"xhigh"`, по умолчанию `"high"`.
- `gpt-5.5`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, по умолчанию `"medium"`.

### Примечания по поведению

- Возвращается только текст ответа. Сообщения, которые модель выдаёт в фазе комментариев во время размышления, пропускаются.
- Если бюджет токенов заканчивается до того, как ответ будет сформирован, узел вызывает ошибку с рекомендацией увеличить `max_output_tokens`.
- Изображения отправляются в собственном разрешении с автоматическим уровнем детализации API, поэтому большие изображения используют больше токенов.
- Каждый запрос сохраняется на стороне OpenAI, а возвращаемый текст объединяет части ответа с помощью переводов строк.
