# OpenAI ChatGPT

This node generates text responses with OpenAI's GPT models. It sends a text prompt, and optionally images or files as context, and returns the answer as a string. Every setting lives inside the `model` selector: picking a model shows that model's own `reasoning_effort` levels, token limit, seed and system prompt, so no separate configuration node is needed. This node replaces the earlier OpenAI ChatGPT node, which the source code now marks as deprecated.

### Reasoning effort levels per model

- `gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6-astra`, `gpt-6.1-sol`: `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, default `"medium"`.
- `gpt-6.1-terra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, default `"medium"`.
- `gpt-5.5-pro`: `"medium"`, `"high"`, `"xhigh"`, default `"high"`.
- `gpt-5.5`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, default `"medium"`.

### Notes on behavior

- Only the answer text is returned. Messages the model emits in its commentary phase while thinking are skipped.
- If the token budget runs out before the answer is written, the node raises an error telling you to increase `max_output_tokens`.
- Images are sent at their own resolution with the API's automatic detail level, so large images use more tokens.
- Every request is stored on OpenAI's side, and the returned text joins the answer parts with newlines.
