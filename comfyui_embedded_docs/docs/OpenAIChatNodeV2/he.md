# OpenAI ChatGPT

צומת זה מייצר תגובות טקסט עם מודלי GPT של OpenAI. הוא שולח הנחיית טקסט, ובאופן אופציונלי תמונות או קבצים כהקשר, ומחזיר את התשובה כמחרוזת. כל הגדרה נמצאת בתוך בורר ה-`model`: בחירת מודל מציגה את רמות ה-`reasoning_effort` של אותו מודל, מגבלת טוקנים, seed והנחיית מערכת, כך שאין צורך בצומת תצורה נפרד. צומת זה מחליף את הצומת הקודם OpenAI ChatGPT, שקוד המקור מסמן כעת כמיושן.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל המשמש ליצירת התגובה. כל מודל חושף את רמות ה-`reasoning_effort` שהוא תומך בהן (ברירת מחדל: `"gpt-6.2-sol"`). | DYNAMIC_COMBO | כן | `"gpt-6.2-sol"`<br>`"gpt-6.2-astra"`<br>`"gpt-6-astra"`<br>`"gpt-6.1-sol"`<br>`"gpt-6.1-terra"`<br>`"gpt-6-sol"`<br>`"gpt-6-luna"`<br>`"gpt-5.6-sol"`<br>`"gpt-5.6-terra"`<br>`"gpt-5.6-luna"`<br>`"gpt-5.5-pro"`<br>`"gpt-5.5"` |
| `prompt` | קלט טקסט למודל (ברירת מחדל: מחרוזת ריקה). | STRING | כן | - |
| `images` | משבצת ניתנת להרחבה: חברו 1..16 פריטים (`image_1`, `image_2`, ...). תמונה/תמונות אופציונליות המשמשות כהקשר למודל. | IMAGE | לא | 0 עד 16 תמונות |
| `files` | קובץ/קבצים אופציונליים המשמשים כהקשר למודל. מקבל קלטים מהצומת OpenAI ChatGPT Input Files. | OPENAI_INPUT_FILES | לא | - |
| `reasoning_effort` | כמה המודל מהרהר לפני שהוא עונה. רמות גבוהות יותר צורכות יותר טוקנים ולוקחות יותר זמן. הרמות המוצעות תלויות במודל הנבחר (ברירת מחדל: `"medium"`, `"high"` עבור `gpt-5.5-pro`). | COMBO | כן | ראו את הרשימה לפי מודל למטה |
| `max_output_tokens` | מספר הטוקנים המקסימלי ליצירה, כולל טוקני חשיבה. ערך נמוך יחד עם `reasoning_effort` גבוה עלול לא להשאיר מקום לתשובה (ברירת מחדל: 32768). | INT | כן | 16 עד 128000 |
| `seed` | ה-seed קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |
| `system_prompt` | הנחיות יסוד שקובעות את התנהגות המודל (ברירת מחדל: מחרוזת ריקה). | STRING | לא | - |

### רמות מאמץ חשיבה לפי מודל

- `gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6-astra`, `gpt-6.1-sol`: `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, ברירת מחדל `"medium"`.
- `gpt-6.1-terra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, `"max"`, ברירת מחדל `"medium"`.
- `gpt-5.5-pro`: `"medium"`, `"high"`, `"xhigh"`, ברירת מחדל `"high"`.
- `gpt-5.5`: `"none"`, `"low"`, `"medium"`, `"high"`, `"xhigh"`, ברירת מחדל `"medium"`.

### הערות לגבי התנהגות

- רק טקסט התשובה מוחזר. הודעות שהמודל פולט בשלב הפרשנות בזמן החשיבה מדולגות.
- אם תקציב הטוקנים נגמר לפני שהתשובה נכתבת, הצומת מעלה שגיאה שמבקשת להגדיל את `max_output_tokens`.
- תמונות נשלחות ברזולוציה שלהן עם רמת הפירוט האוטומטית של ה-API, ולכן תמונות גדולות צורכות יותר טוקנים.
- כל בקשה נשמרת בצד של OpenAI, והטקסט המוחזר מחבר את חלקי התשובה עם שורות חדשות.
