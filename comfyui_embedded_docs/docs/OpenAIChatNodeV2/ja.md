# OpenAI ChatGPT

このノードは、OpenAI の GPT モデルでテキスト応答を生成します。テキストプロンプトを送信し、必要に応じて画像やファイルをコンテキストとして渡し、回答を文字列として返します。すべての設定は `model` セレクター内にあります。モデルを選択すると、そのモデル固有の `reasoning_effort` レベル、トークン上限、シード、システムプロンプトが表示されるため、別個の設定ノードは不要です。このノードは以前の OpenAI ChatGPT ノードを置き換えるもので、ソースコードでは現在非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用するモデルです。各モデルは、サポートする `reasoning_effort` レベルを公開します（デフォルト: `"gpt-6.2-sol"`）。 | DYNAMIC_COMBO | はい | `"gpt-6.2-sol"`<br>`"gpt-6.2-astra"`<br>`"gpt-6-astra"`<br>`"gpt-6.1-sol"`<br>`"gpt-6.1-terra"`<br>`"gpt-6-sol"`<br>`"gpt-6-luna"`<br>`"gpt-5.6-sol"`<br>`"gpt-5.6-terra"`<br>`"gpt-5.6-luna"`<br>`"gpt-5.5-pro"`<br>`"gpt-5.5"` |
| `prompt` | モデルへのテキスト入力です（デフォルト: 空文字列）。 | STRING | はい | - |
| `images` | 拡張可能スロット: 1～16 個の項目（`image_1`、`image_2`、...）を接続します。モデルのコンテキストとして使用する任意の画像です。 | IMAGE | いいえ | 0～16 枚の画像 |
| `files` | モデルのコンテキストとして使用する任意のファイルです。OpenAI ChatGPT Input Files ノードからの入力を受け付けます。 | OPENAI_INPUT_FILES | いいえ | - |
| `reasoning_effort` | モデルが回答前にどれだけ推論するかです。レベルが高いほど、より多くのトークンを使用し、時間がかかります。提供されるレベルは選択したモデルによって異なります（デフォルト: `"medium"`、`gpt-5.5-pro` の場合は `"high"`）。 | COMBO | はい | 以下のモデル別リストを参照してください |
| `max_output_tokens` | 生成する最大トークン数です。推論トークンも含みます。低い値と高い `reasoning_effort` を組み合わせると、回答用の余裕がなくなる可能性があります（デフォルト: 32768）。 | INT | はい | 16～128000 |
| `seed` | シードは、ノードを再実行すべきかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 42）。 | INT | はい | 0～2147483647 |
| `system_prompt` | モデルの動作を規定する基本的な指示です（デフォルト: 空文字列）。 | STRING | いいえ | - |

### モデルごとの推論エフォートレベル

- `gpt-6.2-sol`、`gpt-6.2-astra`、`gpt-6-astra`、`gpt-6.1-sol`: `"low"`、`"medium"`、`"high"`、`"xhigh"`、`"max"`、デフォルトは `"medium"`。
- `gpt-6.1-terra`、`gpt-6-sol`、`gpt-6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`: `"none"`、`"low"`、`"medium"`、`"high"`、`"xhigh"`、`"max"`、デフォルトは `"medium"`。
- `gpt-5.5-pro`: `"medium"`、`"high"`、`"xhigh"`、デフォルトは `"high"`。
- `gpt-5.5`: `"none"`、`"low"`、`"medium"`、`"high"`、`"xhigh"`、デフォルトは `"medium"`。

### 動作に関する注意

- 返されるのは回答テキストのみです。モデルが思考中にコメンタリーフェーズで出力するメッセージはスキップされます。
- 回答が書き込まれる前にトークン予算を使い果たすと、ノードは `max_output_tokens` を増やすよう求めるエラーを発生させます。
- 画像は API の自動詳細レベルで元の解像度のまま送信されるため、大きな画像はより多くのトークンを使用します。
- すべてのリクエストは OpenAI 側に保存され、返されるテキストは回答パートを改行で結合します。
