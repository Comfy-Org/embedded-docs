# Переключатель

Узел Switch выбирает между двумя возможными входами на основе логического условия. Он выводит вход `on_true`, когда `switch` включён, и вход `on_false`, когда `switch` выключен, что позволяет создавать условную логику и выбирать различные пути данных в вашем рабочем процессе. В настоящее время этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `switch` | Логическое условие, определяющее, какой вход передать на выход. Когда условие включено (true), выбирается вход `on_true`. Когда условие выключено (false), выбирается вход `on_false`. | BOOLEAN | Да |  |
| `on_false` | Данные, которые передаются на выход, когда `switch` выключен (false). Этот вход требуется только тогда, когда `switch` равен false. | MATCH_TYPE | Нет |  |
| `on_true` | Данные, которые передаются на выход, когда `switch` включён (true). Этот вход требуется только тогда, когда `switch` равен true. | MATCH_TYPE | Нет |  |

**Примечание о требованиях к входам:** Входы `on_false` и `on_true` являются условно обязательными. Узел запрашивает вход `on_true` только тогда, когда `switch` равен true, и вход `on_false` только тогда, когда `switch` равен false. Оба входа должны иметь один и тот же тип данных.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Выбранные данные. Это будет значение из входа `on_true`, если `switch` равен true, или значение из входа `on_false`, если `switch` равен false. | MATCH_TYPE |
