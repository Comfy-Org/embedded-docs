# Переключатель

Узел If/Else Switch выбирает между двумя возможными входами на основе логического условия. Когда `switch` включён (true), он передаёт вход `on_true` на выход; когда отключён (false), он передаёт `on_false`. Входы являются ленивыми, поэтому вычисляется только выбранная ветвь, а другой вход не обязательно должен быть подключён.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `переключатель` | Логическое условие, определяющее, какой вход передаётся на выход. Когда включено (true), выбирается вход `on_true`. Когда отключено (false), выбирается вход `on_false`. | BOOLEAN | Да |  |
| `если_ложь` | Данные, передаваемые на выход, когда `switch` отключён (false). Этот вход запрашивается только когда `switch` имеет значение false. | MATCH_TYPE | Нет |  |
| `если_истина` | Данные, передаваемые на выход, когда `switch` включён (true). Этот вход запрашивается только когда `switch` имеет значение true. | MATCH_TYPE | Нет |  |

**Примечание о требованиях к входам:** Входы `on_false` и `on_true` запрашиваются условно. Узел запрашивает `on_true` только когда `switch` имеет значение true, и запрашивает `on_false` только когда `switch` имеет значение false. Оба входа должны иметь один и тот же тип данных, и этот тип должен совпадать с типом данных выхода. Если выбранный вход не подключён, узел не выводит значение.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Выбранные данные: значение из `on_true`, когда `switch` имеет значение true, или значение из `on_false`, когда `switch` имеет значение false. | MATCH_TYPE |
