# Переключатель

Узел Switch выбирает между двумя возможными входами на основе логического условия. Он передаёт на выход вход `on_true`, когда `switch` включён, и вход `on_false`, когда `switch` выключен. Вычисляется только выбранная ветвь, поэтому другой вход не требуется. Это позволяет создавать условную логику и выбирать различные пути данных в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `переключатель` | Логическое условие, определяющее, какой вход пропустить. Когда включено (true), выбирается вход `on_true`. Когда выключено (false), выбирается вход `on_false`. | BOOLEAN | Да |  |
| `если_ложь` | Данные, передаваемые на выход, когда `switch` выключен (false). Этот вход требуется только тогда, когда `switch` равен false. | MATCH_TYPE | Нет |  |
| `если_истина` | Данные, передаваемые на выход, когда `switch` включен (true). Этот вход требуется только тогда, когда `switch` равен true. | MATCH_TYPE | Нет |  |

**Примечание о требованиях к входам:** Входы `on_false` и `on_true` требуются условно. Узел запрашивает вход `on_true` только когда `switch` равен true, а вход `on_false` — только когда `switch` равен false. Оба входа должны иметь одинаковый тип данных и соответствовать типу данных выхода.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `выход` | Выбранные данные. Это будет значение из входа `on_true`, если `switch` равен true, или значение из входа `on_false`, если `switch` равен false. | MATCH_TYPE |
