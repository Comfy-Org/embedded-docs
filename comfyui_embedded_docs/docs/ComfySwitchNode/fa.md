# سوئیچ

گره Switch بر اساس یک شرط بولی، بین دو ورودی ممکن انتخاب می‌کند. وقتی `switch` فعال باشد، ورودی `on_true` و وقتی `switch` غیرفعال باشد، ورودی `on_false` را به خروجی می‌دهد و به شما امکان می‌دهد منطق شرطی ایجاد کرده و مسیرهای داده‌ای متفاوتی را در گردش کار خود انتخاب کنید. این گره در حال حاضر به‌عنوان آزمایشی (experimental) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `switch` | یک شرط بولی که تعیین می‌کند کدام ورودی عبور داده شود. وقتی فعال باشد (true)، ورودی `on_true` انتخاب می‌شود. وقتی غیرفعال باشد (false)، ورودی `on_false` انتخاب می‌شود. | BOOLEAN | بله |  |
| `on_false` | داده‌هایی که هنگام غیرفعال بودن (false) بودن `switch` به خروجی منتقل می‌شود. این ورودی فقط زمانی ضروری است که `switch` برابر false باشد. | MATCH_TYPE | خیر |  |
| `on_true` | داده‌هایی که هنگام فعال بودن (true) بودن `switch` به خروجی منتقل می‌شود. این ورودی فقط زمانی ضروری است که `switch` برابر true باشد. | MATCH_TYPE | خیر |  |

**نکته درباره الزامات ورودی:** ورودی‌های `on_false` و `on_true` به‌صورت شرطی ضروری هستند. گره فقط زمانی درخواست ورودی `on_true` را می‌کند که `switch` برابر true باشد، و تنها زمانی درخواست ورودی `on_false` را می‌کند که `switch` برابر false باشد. هر دو ورودی باید از نوع داده یکسانی باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | داده انتخابی. اگر `switch` برابر true باشد، مقدار ورودی `on_true` خواهد بود، و اگر `switch` برابر false باشد، مقدار ورودی `on_false` خواهد بود. | MATCH_TYPE |
