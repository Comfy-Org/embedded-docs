# سوئیچ

گره Switch بین دو ورودی ممکن را بر اساس یک شرط بولی انتخاب می‌کند. زمانی که `switch` فعال باشد، ورودی `on_true` را خروجی می‌دهد و زمانی که `switch` غیرفعال باشد، ورودی `on_false` را خروجی می‌دهد. فقط شاخهٔ انتخاب‌شده ارزیابی می‌شود، بنابراین ورودی دیگر الزامی نیست. این امکان را به شما می‌دهد تا منطق شرطی ایجاد کرده و مسیرهای دادهٔ متفاوتی را در گردش کار خود انتخاب کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `سوئیچ` | یک شرط بولی که تعیین می‌کند کدام ورودی عبور داده شود. وقتی فعال باشد (true)، ورودی `on_true` انتخاب می‌شود. وقتی غیرفعال باشد (false)، ورودی `on_false` انتخاب می‌شود. | BOOLEAN | بله |  |
| `در حالت نادرست` | داده‌ای که وقتی `switch` غیرفعال است (false) به خروجی منتقل می‌شود. این ورودی فقط زمانی الزامی است که `switch` برابر false باشد. | MATCH_TYPE | خیر |  |
| `در حالت درست` | داده‌ای که وقتی `switch` فعال است (true) به خروجی منتقل می‌شود. این ورودی فقط زمانی الزامی است که `switch` برابر true باشد. | MATCH_TYPE | خیر |  |

**نکته درباره الزامات ورودی:** ورودی‌های `on_false` و `on_true` به‌صورت شرطی الزامی هستند. گره فقط زمانی ورودی `on_true` را درخواست می‌کند که `switch` برابر true باشد و فقط زمانی ورودی `on_false` را درخواست می‌کند که `switch` برابر false باشد. هر دو ورودی باید از یک نوع داده باشند و با نوع داده خروجی مطابقت داشته باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `خروجی` | دادهٔ انتخاب‌شده. اگر `switch` برابر true باشد، این مقدار از ورودی `on_true` خواهد بود و اگر `switch` برابر false باشد، مقدار از ورودی `on_false` خواهد بود. | MATCH_TYPE |
