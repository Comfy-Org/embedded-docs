# تحويل هندسة DA3 إلى شبكة

تقوم هذه العقدة بتحويل حزمة DA3_GEOMETRY إلى شبكة ثلاثية الأبعاد عبر إلغاء إسقاط خريطة العمق وتثليث سحابة النقاط الناتجة. تعالج صورة واحدة من دفعة وتنتج شبكة مزودة بنسيج أو غير مزودة به، مناسبة للتصيير ثلاثي الأبعاد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | حزمة DA3_GEOMETRY التي تحتوي على خريطة عمق، وخريطة ثقة اختيارية، وخريطة سماء اختيارية، والصورة المصدر | DA3_GEOMETRY | نعم | - |
| `batch_index` | أي صورة من دفعة سيتم تحويلها. تختلف أعداد الرؤوس لكل صورة، لذا لا يمكن تكديس الدفعات (الافتراضي: 0). يجب أن يكون أقل من حجم دفعة هندسة الإدخال، وإلا يُرفع خطأ | INT | نعم | 0 إلى 4096 |
| `decimation` | خطوة الرؤوس. 1 = الدقة الكاملة، 2 = النصف، إلخ. (الافتراضي: 1) | INT | نعم | 1 إلى 8 |
| `discontinuity_threshold` | استبعاد المثلثات التي يتجاوز فيها امتداد العمق 3×3 هذا الكسر. 0 = إيقاف (الافتراضي: 0.04) | FLOAT | نعم | 0.0 إلى 1.0 |
| `confidence_threshold` | استبعاد البكسلات التي تكون فيها الثقة المطبّعة لكل صورة أقل من هذه القيمة. 0 = الاحتفاظ بالكل، 1 = الاحتفاظ بالبكسل الأكثر ثقة فقط. يُستخدم عندما تحتوي الهندسة على خريطة ثقة (نماذج Small/Base) (الافتراضي: 0.1) | FLOAT | نعم | 0.0 إلى 1.0 |
| `use_sky_mask` | استبعاد البكسلات ذات احتمال السماء (سماء >= 0.5) من الشبكة. يُستخدم عندما تحتوي الهندسة على خريطة سماء (نماذج Mono/Metric) (الافتراضي: True) | BOOLEAN | نعم | True or False |
| `texture` | استخدام الصورة المصدر كنسيج لون أساسي (الافتراضي: True) | BOOLEAN | نعم | True or False |

تُستبعد دائمًا البكسلات ذات قيم العمق غير المنتهية أو الصفرية أو السالبة من الشبكة. يتم رفع خطأ إذا كانت الشبكة الناتجة فارغة؛ وتقترح رسالة الخطأ رفع `discontinuity_threshold`، أو خفض `confidence_threshold`، أو تعطيل `use_sky_mask`.

## المخرجات
