# המרת DA3 Geometry לרשת תלת-ממדית

צומת זה ממיר חבילת DA3_GEOMETRY למש תלת-ממדי על ידי הקרנה הפוכה של מפת העומק ויצירת משולשים מענן הנקודות המתקבל. הוא מעבד תמונה בודדת ממקבץ ומפיק מש עם טקסטורה או ללא טקסטורה המתאים לרינדור תלת-ממדי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | חבילת DA3_GEOMETRY המכילה מפת עומק, מפת ביטחון אופציונלית, מפת שמיים אופציונלית ותמונת מקור | DA3_GEOMETRY | כן | - |
| `batch_index` | איזו תמונה במקבץ להמיר. מספרי הקודקודים לכל תמונה שונים, ולכן לא ניתן לערום מקבצים (ברירת מחדל: 0). חייב להיות קטן מגודל המקבץ של גאומטריית הקלט, אחרת תיזרק שגיאה | INT | כן | 0 to 4096 |
| `decimation` | צעד קודקודים. 1 = רזולוציה מלאה, 2 = חצי, וכו' (ברירת מחדל: 1) | INT | כן | 1 to 8 |
| `discontinuity_threshold` | השלך משולשים שטווח העומק 3x3 שלהם עולה על שבר זה. 0 = כבוי (ברירת מחדל: 0.04) | FLOAT | כן | 0.0 to 1.0 |
| `confidence_threshold` | החרג פיקסלים שרמת הביטחון המנורמלת לכל תמונה שלהם נמוכה מערך זה. 0 = שמור הכל, 1 = שמור רק את הפיקסל בעל הביטחון הגבוה ביותר. משמש כאשר לגאומטריה יש מפת ביטחון (מודלים Small/Base) (ברירת מחדל: 0.1) | FLOAT | כן | 0.0 to 1.0 |
| `use_sky_mask` | החרג פיקסלים בעלי הסתברות שמיים (sky >= 0.5) מהמש. משמש כאשר לגאומטריה יש מפת שמיים (מודלים Mono/Metric) (ברירת מחדל: True) | BOOLEAN | כן | True or False |
| `texture` | השתמש בתמונת המקור כטקסטורת צבע בסיס (ברירת מחדל: True) | BOOLEAN | כן | True or False |

פיקסלים עם ערכי עומק לא סופיים, אפס או שליליים תמיד מוחרגים מהמש. תיזרק שגיאה אם המש המתקבל ריק; הודעת השגיאה מציעה להעלות את `discontinuity_threshold`, להנמיך את `confidence_threshold`, או להשבית את `use_sky_mask`.
