# Преобразовать DA3 Geometry в Mesh

Этот узел преобразует пакет DA3_GEOMETRY в 3D-сетку путём обратного проецирования карты глубины и триангуляции полученного облака точек. Он обрабатывает одно изображение из пакета и создаёт текстурированную или не текстурированную сетку, подходящую для 3D-рендеринга.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | Пакет DA3_GEOMETRY, содержащий карту глубины, необязательную карту уверенности, необязательную карту неба и исходное изображение | DA3_GEOMETRY | Да | - |
| `batch_index` | Какое изображение из пакета преобразовывать. Количество вершин для каждого изображения различается, поэтому пакеты нельзя объединять в стопку (по умолчанию: 0). Должно быть меньше размера пакета входной геометрии, иначе возникает ошибка | INT | Да | 0 до 4096 |
| `decimation` | Шаг вершин. 1 = полное разрешение, 2 = половина и т. д. (по умолчанию: 1) | INT | Да | 1 до 8 |
| `discontinuity_threshold` | Отбрасывать треугольники, у которых разброс глубины в окне 3x3 превышает эту долю. 0 = отключено (по умолчанию: 0.04) | FLOAT | Да | 0.0 до 1.0 |
| `confidence_threshold` | Исключать пиксели, у которых нормализованная уверенность для изображения ниже этого значения. 0 = оставить все, 1 = оставить только один самый уверенный пиксель. Используется, когда геометрия имеет карту уверенности (модели Small/Base) (по умолчанию: 0.1) | FLOAT | Да | 0.0 до 1.0 |
| `use_sky_mask` | Исключать пиксели с вероятностью неба (небо >= 0.5) из сетки. Используется, когда геометрия имеет карту неба (модели Mono/Metric) (по умолчанию: True) | BOOLEAN | Да | True или False |
| `texture` | Использовать исходное изображение в качестве текстуры базового цвета (по умолчанию: True) | BOOLEAN | Да | True или False |

Пиксели с неконечными, нулевыми или отрицательными значениями глубины всегда исключаются из сетки. Если полученная сетка пуста, возникает ошибка; сообщение об ошибке предлагает увеличить `discontinuity_threshold`, уменьшить `confidence_threshold` или отключить `use_sky_mask`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MESH` | Триангулированная 3D-сетка с вершинами, гранями, UV-координатами и необязательной текстурой | MESH |
