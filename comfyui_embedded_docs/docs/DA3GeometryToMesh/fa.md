# تبدیل هندسه DA3 به Mesh

این گره یک بسته DA3_GEOMETRY را با بازتصویرسازی نقشه عمق و مثلث‌بندی ابر نقاط حاصل، به یک مش سه‌بعدی تبدیل می‌کند. یک تصویر از یک دسته را پردازش می‌کند و یک مش بافت‌دار یا بدون بافت مناسب برای رندر سه‌بعدی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | بسته DA3_GEOMETRY حاوی نقشه عمق، نقشه اطمینان اختیاری، نقشه آسمان اختیاری و تصویر منبع | DA3_GEOMETRY | بله | - |
| `batch_index` | مشخص می‌کند کدام تصویر از یک دسته تبدیل شود. تعداد رأس‌ها برای هر تصویر متفاوت است، بنابراین دسته‌ها را نمی‌توان روی هم انباشت کرد (پیش‌فرض: 0). باید کمتر از اندازه دسته هندسه ورودی باشد، در غیر این صورت خطا داده می‌شود | INT | بله | 0 تا 4096 |
| `decimation` | گام رأس. 1 = وضوح کامل، 2 = نصف، و غیره (پیش‌فرض: 1) | INT | بله | 1 تا 8 |
| `discontinuity_threshold` | مثلث‌هایی را حذف می‌کند که گستره عمق 3x3 آن‌ها از این کسر فراتر می‌رود. 0 = خاموش (پیش‌فرض: 0.04) | FLOAT | بله | 0.0 تا 1.0 |
| `confidence_threshold` | پیکسل‌هایی را حذف می‌کند که اطمینان نرمال‌شده به‌ازای هر تصویر آن‌ها کمتر از این مقدار باشد. 0 = نگه‌داشتن همه، 1 = نگه‌داشتن تنها مطمئن‌ترین پیکسل. زمانی استفاده می‌شود که هندسه نقشه اطمینان داشته باشد (مدل‌های Small/Base) (پیش‌فرض: 0.1) | FLOAT | بله | 0.0 تا 1.0 |
| `use_sky_mask` | پیکسل‌های دارای احتمال آسمان (sky >= 0.5) را از مش حذف می‌کند. زمانی استفاده می‌شود که هندسه نقشه آسمان داشته باشد (مدل‌های Mono/Metric) (پیش‌فرض: True) | BOOLEAN | بله | True یا False |
| `texture` | از تصویر منبع به‌عنوان بافت رنگ پایه استفاده می‌کند (پیش‌فرض: True) | BOOLEAN | بله | True یا False |

پیکسل‌هایی با مقادیر عمق غیرمتناهی، صفر یا منفی همیشه از مش حذف می‌شوند. اگر مش حاصل خالی باشد، خطا داده می‌شود؛ پیام خطا پیشنهاد می‌کند `discontinuity_threshold` را افزایش دهید، `confidence_threshold` را کاهش دهید یا `use_sky_mask` را غیرفعال کنید.
