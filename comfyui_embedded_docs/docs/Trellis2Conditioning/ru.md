# Trellis2Conditioning

Trellis2Conditioning преобразует входное изображение в данные кондиционирования для модели TRELLIS.2. Он использует модель CLIP vision для кодирования изображения в два набора признаков (в масштабах 512 и 1024) и упаковывает их в положительную пару кондиционирования, а также создаёт соответствующую отрицательную пару кондиционирования, заполненную нулями, которая служит пустым эталоном.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | Модель CLIP vision, используемая для кодирования изображения в признаки кондиционирования. | CLIP_VISION | Да | Любая доступная модель CLIP vision |
| `изображение` | Предварительно обработанное изображение из ImageCropToMask (pad_factor=1.0 для TRELLIS.2). | IMAGE | Да | Любое изображение |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `позитивное` | Кондиционирование, содержащее закодированные признаки изображения в масштабах 512 и 1024, используемое в качестве положительного кондиционирования для модели TRELLIS.2. | CONDITIONING |
| `негативное` | Кондиционирование, заполненное нулями, имеющее ту же форму, что и положительное кондиционирование, и используемое в качестве пустого отрицательного эталона. | CONDITIONING |
