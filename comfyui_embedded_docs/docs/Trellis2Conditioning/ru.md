# Trellis2Conditioning

Trellis2Conditioning преобразует входное изображение в данные conditioning для модели TRELLIS.2. Он использует модель CLIP vision для кодирования изображения в два набора признаков (в масштабах 512 и 1024) и упаковывает их как положительную пару conditioning, а также создает соответствующую отрицательную пару conditioning, заполненную нулями, которая служит пустой ссылкой.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | Модель CLIP vision, используемая для кодирования изображения в признаки conditioning. | CLIP_VISION | Да | Любая доступная модель CLIP vision |
| `image` | Предварительно обработанное изображение из ImageCropToMask (pad_factor=1.0 для TRELLIS.2). | IMAGE | Да | Любое изображение |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Conditioning, содержащий закодированные признаки изображения в масштабах 512 и 1024, используемый в качестве положительного conditioning для модели TRELLIS.2. | CONDITIONING |
| `negative` | Conditioning, заполненный нулями, с той же формой, что и положительный conditioning, используемый в качестве пустой отрицательной ссылки. | CONDITIONING |
