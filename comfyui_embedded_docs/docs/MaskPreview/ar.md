# معاينة القناع

نقدم عقدة MaskPreview معاينة مرئية لبيانات القناع مباشرةً في واجهة ComfyUI، دون حفظها في مجلد المخرجات. يتيح لك ذلك فحص قيم القناع الدقيقة في أي نقطة من سير عملك.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `قناع` | بيانات القناع المراد معاينتها | MASK | نعم | - |
| `filename_prefix` | بادئة لاسم ملف المعاينة (الافتراضي: "ComfyUI") | STRING | لا | - |
| `prompt` | معلومات الموجّه (prompt) للبيانات الوصفية (تُوفَّر تلقائيًا) | PROMPT | لا | - |
| `extra_pnginfo` | معلومات PNG إضافية للبيانات الوصفية (تُوفَّر تلقائيًا) | EXTRA_PNGINFO | لا | - |

إن مدخلي `prompt` و`extra_pnginfo` مخفيان ويتم توفيرهما تلقائيًا بواسطة نظام ComfyUI؛ فلا حاجة لتوصيلهما يدويًا.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `mask` | بيانات القناع التي تمت معاينتها، وتُعاد دون تغيير لاستخدامها لاحقًا في سير العمل | MASK |
