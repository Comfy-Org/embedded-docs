# معاينة القناع

تُظهر عقدة MaskPreview معاينة مرئية لبيانات القناع مباشرةً في واجهة ComfyUI، بحيث يمكنك فحص الأقنعة أثناء سير العمل. تعرض المعاينة دون حفظها في دليل إخراج ComfyUI، وتمرر القناع كما هو كإخراج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mask` | بيانات القناع المطلوب معاينته | MASK | نعم | - |
| `filename_prefix` | بادئة اسم ملف الإخراج (الافتراضي: "ComfyUI") | STRING | لا | - |
| `prompt` | معلومات البرومبت للبيانات الوصفية (تُقدم تلقائيًا) | PROMPT | لا | - |
| `extra_pnginfo` | معلومات PNG إضافية للبيانات الوصفية (تُقدم تلقائيًا) | EXTRA_PNGINFO | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `mask` | بيانات القناع التي تمت معاينتها، مرّرة دون تغيير | MASK |
