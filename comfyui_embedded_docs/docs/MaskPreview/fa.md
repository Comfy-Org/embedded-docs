# پیش‌نمایش ماسک

گره MaskPreview پیش‌نمایش بصری داده‌های ماسک را مستقیماً در رابط ComfyUI نشان می‌دهد، بنابراین می‌توانید ماسک‌ها را در طول گردش کار خود بررسی کنید. این پیش‌نمایش را بدون ذخیره‌سازی در دایرکتوری خروجی ComfyUI نمایش می‌دهد و ماسک را به‌عنوان خروجی عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mask` | داده‌های ماسک که باید پیش‌نمایش شوند | MASK | بله | - |
| `filename_prefix` | پیشوند برای نام فایل خروجی (پیش‌فرض: "ComfyUI") | STRING | خیر | - |
| `prompt` | اطلاعات پرامپت برای فراداده (به‌طور خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG برای فراداده (به‌طور خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `mask` | داده‌های ماسک که پیش‌نمایش شدند، بدون تغییر عبور داده‌شده‌اند | MASK |
