# پیش‌نمایش ماسک

گره MaskPreview یک پیش‌نمایش بصری از داده ماسک را مستقیماً در رابط کاربری ComfyUI نمایش می‌دهد، بدون اینکه آن را در پوشه خروجی ذخیره کند. این امکان را می‌دهد که ماسک را در هر نقطه‌ای از گردش‌کار خود بررسی کنید، در حالی که ماسک نیز بدون تغییر از این گره عبور می‌کند تا بتوان از آن در مراحل بعدی استفاده کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ماسک` | داده ماسکی که باید پیش‌نمایش داده شود | MASK | بله | - |
| `filename_prefix` | پیشوند نام فایل که برای پیش‌نمایش استفاده می‌شود (پیش‌فرض: "ComfyUI") | STRING | خیر | - |
| `prompt` | اطلاعات پرامپت برای فراداده (به‌صورت خودکار فراهم می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG برای فراداده (به‌صورت خودکار فراهم می‌شود) | EXTRA_PNGINFO | خیر | - |

تنها `mask` یک ورودی قابل مشاهده است که باید متصل شود. پارامترهای `filename_prefix`، `prompt` و `extra_pnginfo` توسط سیستم تأمین می‌شوند: `filename_prefix` به مقدار پیش‌فرض خود برمی‌گردد، در حالی که `prompt` و `extra_pnginfo` پنهان هستند و به‌صورت خودکار توسط محیط اجرایی ComfyUI فراهم می‌شوند.
