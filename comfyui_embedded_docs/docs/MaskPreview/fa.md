# پیش‌نمایش ماسک

گره MaskPreview پیش‌نمایشی بصری از داده ماسک را مستقیماً در رابط ComfyUI نمایش می‌دهد، بدون اینکه آن را در دایرکتوری خروجی ذخیره کند. این کار به شما امکان می‌دهد مقادیر دقیق ماسک را در هر نقطه از گردش کار خود بررسی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ماسک` | داده ماسک برای پیش‌نمایش | MASK | بله | - |
| `filename_prefix` | پیشوند برای نام فایل پیش‌نمایش (پیش‌فرض: "ComfyUI") | STRING | خیر | - |
| `prompt` | اطلاعات prompt برای فراداده (به‌صورت خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات تکمیلی PNG برای فراداده (به‌صورت خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

ورودی‌های `prompt` و `extra_pnginfo` پنهان هستند و به‌صورت خودکار توسط سیستم ComfyUI تأمین می‌شوند؛ نیازی به اتصال دستی آن‌ها نیست.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `mask` | داده ماسکی که پیش‌نمایش شد، بدون تغییر برای استفاده بیشتر در گردش کار بازگردانده می‌شود | MASK |
