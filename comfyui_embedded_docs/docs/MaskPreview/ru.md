# MaskPreview

Узел MaskPreview отображает визуальный предпросмотр данных маски прямо в интерфейсе ComfyUI, не сохраняя его в выходной каталог. Это позволяет проверить маску на любом этапе рабочего процесса, при этом маска также проходит через узел без изменений, поэтому может использоваться дальше.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mask` | Данные маски для предпросмотра | MASK | Да | - |
| `filename_prefix` | Префикс имени файла, используемый для предпросмотра (по умолчанию: "ComfyUI") | STRING | Нет | - |
| `prompt` | Информация запроса для метаданных (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная информация PNG для метаданных (предоставляется автоматически) | EXTRA_PNGINFO | Нет | - |

Только `mask` является видимым входом, который нужно подключить. Параметры `filename_prefix`, `prompt` и `extra_pnginfo` предоставляются системой: `filename_prefix` принимает значение по умолчанию, тогда как `prompt` и `extra_pnginfo` скрыты и автоматически передаются средой выполнения ComfyUI.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mask` | Те же данные маски, которые были показаны в предпросмотре, возвращаются без изменений, чтобы их можно было использовать в другом месте рабочего процесса | MASK |
