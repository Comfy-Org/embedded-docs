# MaskPreview

Узел MaskPreview отображает визуальное предварительное просмотр данных маски непосредственно в интерфейсе ComfyUI, без сохранения в выходную директорию. Это позволяет вам проверять точные значения маски в любой точке вашего рабочего процесса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mask` | Данные маски для предварительного просмотра | MASK | Да | - |
| `filename_prefix` | Префикс для имени файла предварительного просмотра (по умолчанию: "ComfyUI") | STRING | Нет | - |
| `prompt` | Информация о промпте для метаданных (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная PNG-информация для метаданных (предоставляется автоматически) | EXTRA_PNGINFO | Нет | - |

Входы `prompt` и `extra_pnginfo` скрыты и автоматически предоставляются системой ComfyUI; вам не нужно подключать их вручную.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mask` | Данные маски, которые были предварительно просмотрены, возвращаются без изменений для дальнейшего использования в рабочем процессе | MASK |
