# MaskPreview

Узел MaskPreview отображает визуальное предварительное просмотр данных маски непосредственно в интерфейсе ComfyUI, что позволяет проверять маски во время рабочего процесса. Он показывает предварительный просмотр без сохранения в выходную директорию ComfyUI и передаёт маску на выход без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mask` | Данные маски для предварительного просмотра | MASK | Да | - |
| `filename_prefix` | Префикс для имени выходного файла (по умолчанию: "ComfyUI") | STRING | Нет | - |
| `prompt` | Информация для метаданных (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная PNG-информация для метаданных (предоставляется автоматически) | EXTRA_PNGINFO | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mask` | Данные маски, которые были предварительно просмотрены, передаются без изменений | MASK |
