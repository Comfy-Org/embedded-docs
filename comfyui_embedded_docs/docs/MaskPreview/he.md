# MaskPreview

צומת MaskPreview מציג תצוגה חזותית של נתוני המסכה ישירות בממשק ComfyUI, מבלי לשמור אותם בתיקיית הפלט. הדבר מאפשר לך לבדוק את המסכה בכל נקודה בתהליך העבודה, בעוד המסכה גם עוברת דרך הצומת ללא שינוי כך שניתן להמשיך להשתמש בה בהמשך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mask` | נתוני המסכה לתצוגה מקדימה | MASK | כן | - |
| `filename_prefix` | קידומת שם קובץ המשמשת לתצוגה המקדימה (ברירת מחדל: "ComfyUI") | STRING | לא | - |
| `prompt` | מידע פרומפט עבור מטא-נתונים (מסופק אוטומטית) | PROMPT | לא | - |
| `extra_pnginfo` | מידע PNG נוסף עבור מטא-נתונים (מסופק אוטומטית) | EXTRA_PNGINFO | לא | - |

רק `mask` הוא קלט גלוי שיש לחבר. הפרמטרים `filename_prefix`, `prompt` ו-`extra_pnginfo` מסופקים על ידי המערכת: `filename_prefix` משתמש בערך ברירת המחדל שלו, בעוד `prompt` ו-`extra_pnginfo` מוסתרים ומסופקים אוטומטית על ידי סביבת ההרצה של ComfyUI.
