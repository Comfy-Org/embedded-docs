# Vidu Q3: генерация видео из изображения

Узел Vidu Q3 Image-to-Video Generation создает видеопоследовательность на основе входного изображения. Для анимации изображения используется модель Vidu Q3, при необходимости с текстовой подсказкой, и на выходе получается видеофайл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации видео. | DYNAMIC_COMBO | Да | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `image` | Изображение, используемое в качестве начального кадра генерируемого видео. | IMAGE | Да | - |
| `prompt` | Необязательная текстовая подсказка для генерации видео (максимум 2000 символов) (по умолчанию: пусто). | STRING | Да | - |
| `seed` | Значение seed для управления случайностью генерации (по умолчанию: 1). | INT | Да | 0 до 2147483647 |

### Входы viduq3-pro

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"`<br>`"1080p"`<br>`"2K"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 5). | INT | Да | 1 до 16 |
| `audio` | Если включено, выводит видео со звуком (включая диалоги и звуковые эффекты) (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |

### Входы viduq3-turbo

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 5). | INT | Да | 1 до 16 |
| `audio` | Если включено, выводит видео со звуком (включая диалоги и звуковые эффекты) (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |

**Примечание:** изображение `image` должно иметь соотношение сторон от 1:4 до 4:1 (от портретного до ландшафтного). Параметр `prompt` необязателен, но не может превышать 2000 символов. Варианты разрешения зависят от выбранной модели: `"viduq3-pro"` поддерживает `"720p"`, `"1080p"` и `"2K"`; `"viduq3-turbo"` поддерживает `"720p"` и `"1080p"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
