# Vidu Q3 圖像轉影片生成

Vidu Q3 影像轉影片生成節點會從輸入的影像開始建立影片序列。它使用 Vidu Q3 模型來為影像製作動畫，可選擇性地由文字提示詞引導，並輸出影片檔案。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片生成的模型。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `image` | 作為生成影片起始幀的影像。 | IMAGE | 是 | - |
| `prompt` | 影片生成的可選文字提示詞（最多 2000 個字元）（預設值：空）。 | STRING | 否 | - |
| `seed` | 用於控制生成隨機性的種子值（預設值：1）。支援生成後控制。 | INT | 否 | 0 至 2147483647 |

### viduq3-pro 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model.resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720p"`<br>`"1080p"`<br>`"2K"` |
| `model.duration` | 輸出影片的持續時間（秒）（預設值：5）。 | INT | 是 | 1 至 16 |
| `model.audio` | 啟用時，輸出帶有聲音（包括對話和音效）的影片（預設值：False）。 | BOOLEAN | 是 | `True`<br>`False` |

### viduq3-turbo 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model.resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `model.duration` | 輸出影片的持續時間（秒）（預設值：5）。 | INT | 是 | 1 至 16 |

**注意：** `image` 的長寬比必須介於 1:4 和 4:1 之間（直式到橫式）。`prompt` 為選填，但不能超過 2000 個字元。解析度選項取決於所選的模型：`"viduq3-pro"` 支援 `"720p"`、`"1080p"` 和 `"2K"`；`"viduq3-turbo"` 支援 `"720p"` 和 `"1080p"`。
