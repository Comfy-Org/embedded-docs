# Vidu Q3 圖像轉影片生成

Vidu Q3 影像轉影片生成節點會從輸入影像建立影片序列。它使用 Vidu Q3 模型來為影像製作出動畫效果，並可選擇性地以文字提示詞引導，最後輸出影片檔案。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片生成的模型。 | COMBO | 是 | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `image` | 作為生成影片起始幀的影像。 | IMAGE | 是 | - |
| `prompt` | 用於影片生成的選用文字提示詞（最多 2000 個字元）（預設值：空白）。 | STRING | 否 | - |
