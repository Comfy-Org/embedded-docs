# Vidu Q3 圖像轉影片生成

Vidu Q3 圖像轉影片生成節點會從輸入影像開始建立一段影片序列。它使用 Vidu Q3 模型來為影像製作動畫，並可選擇性地以文字提示引導，最後輸出影片檔案。

| `model` | 用於影片生成的模型。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br>`"viduq3-turbo"` |
