# نمایش نمودار Loss

LossGraphNode یک نمودار خطی از مقادیر loss آموزش در طول گام‌های آموزش ایجاد می‌کند و آن را به‌صورت تصویر پیش‌نمایش نشان می‌دهد. این گره مقادیر loss را از یک گره آموزش می‌خواند، آن‌ها را روی نموداری با محورهای برچسب‌دار و مقادیر کمینه/بیشینه loss رسم می‌کند و نمودار را به‌عنوان پیش‌نمایش تصویر در رابط کاربری برمی‌گرداند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است و یک گره خروجی محسوب می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `loss` | نقشه loss از گره آموزش. باید شامل کلید `loss` با فهرستی از مقادیر عددی loss باشد. | LOSS_MAP | بله | - |
| `filename_prefix` | پیشوند برای تصویر نمودار loss ذخیره‌شده. (پیش‌فرض: "loss_graph") | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `ui.images` | تصویر نمودار loss تولیدشده که به‌عنوان پیش‌نمایش نمایش داده می‌شود. | IMAGE |
