# نمایش نمودار Loss

گره LossGraphNode یک نمودار تصویری از مقادیر loss آموزش در طول زمان ایجاد می‌کند و آن را به‌صورت تصویر پیش‌نمایش نمایش می‌دهد. این گره داده‌های loss را از فرآیندهای آموزش دریافت کرده و نمودار خطی تولید می‌کند که تغییرات loss را در مراحل آموزش نشان می‌دهد. نمودار حاصل شامل برچسب‌های محور و مقادیر حداقل/حداکثر loss است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `loss` | نقشه loss از گره آموزش. باید شامل کلید `loss` با فهرستی از مقادیر loss باشد که برای رسم نمودار استفاده می‌شود. | LOSS_MAP | بله | - |
| `filename_prefix` | پیشوندی برای تصویر نمودار loss ذخیره‌شده. (پیش‌فرض: "loss_graph") | STRING | بله | - |
