# نمایش نمودار Loss

گره LossGraphNode نمودار خطی مقادیر خطای آموزش (loss) را در طول مراحل آموزش ترسیم کرده و آن را به‌صورت تصویر پیش‌نمایش نمایش می‌دهد. این گره مقادیر loss را از یک گره آموزشی می‌خواند، آن‌ها را روی نموداری با محورهای برچسب‌دار و مقادیر حداقل/حداکثر loss رسم می‌کند و نمودار را به‌عنوان پیش‌نمایش تصویر در رابط کاربری بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مقدار loss` | نقشه loss از گره آموزشی. باید شامل یک کلید `loss` با فهرستی از مقادیر عددی loss باشد. | LOSS_MAP | بله | - |
| `پیشوند نام فایل` | پیشوندی برای تصویر نمودار loss ذخیره‌شده. (پیش‌فرض: "loss_graph") | STRING | بله | - |
