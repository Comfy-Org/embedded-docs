# LossGraphNode

הצומת LossGraphNode יוצר תרשים קווים של ערכי loss באימון לאורך צעדי האימון ומציג אותו כתמונת תצוגה מקדימה. הוא קורא ערכי loss מצומת אימון, משרטט אותם בגרף עם צירים מתויגים וערכי loss מינימליים/מקסימליים, ומחזיר את הגרף כתצוגה מקדימה של תמונה בממשק המשתמש. צומת זה מסומן כניסיוני והוא צומת פלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `loss` | מפת loss מצומת אימון. עליה להכיל מפתח `loss` עם רשימה של ערכי loss מספריים. | LOSS_MAP | כן | - |
| `filename_prefix` | קידומת לשם הקובץ של תמונת גרף ה-loss הנשמרת. (ברירת מחדל: "loss_graph") | STRING | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `ui.images` | תמונת גרף ה-loss שנוצרה, המוצגת כתצוגה מקדימה. | IMAGE |
