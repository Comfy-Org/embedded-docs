# 損失グラフをプロット

The LossGraphNode は、トレーニング損失値の経時変化を視覚的なグラフとして作成し、プレビュー画像として表示します。トレーニングプロセスから損失データを受け取り、トレーニングステップ全体での損失の変化を示す折れ線グラフを生成します。生成されたグラフには、軸ラベルと損失の最小値/最大値が含まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `loss` | トレーニングノードからの損失マップ。グラフを描画するために使用する損失値のリストを含む `loss` キーが必須です。 | LOSS_MAP | はい | - |
| `filename_prefix` | 保存される損失グラフ画像のプレフィックス。(デフォルト: "loss_graph") | STRING | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ui.images` | 生成された損失グラフ画像。プレビューとして表示されます。 | IMAGE |
