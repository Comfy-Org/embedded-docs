# Построить график потерь

Узел LossGraphNode создает визуальный график значений потерь (loss) в процессе обучения и отображает его в виде превью-изображения. Он принимает данные о потерях из процессов обучения и генерирует линейный график, показывающий, как изменяются потери по шагам обучения. Результирующий график включает подписи осей и минимальные/максимальные значения потерь.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `loss` | Карта потерь из обучающего узла. Должна содержать ключ `loss` со списком значений потерь, используемых для построения графика. | LOSS_MAP | Да | - |
| `filename_prefix` | Префикс для сохраняемого изображения графика потерь. (по умолчанию: "loss_graph") | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `ui.images` | Сгенерированное изображение графика потерь, отображаемое как превью. | IMAGE |
