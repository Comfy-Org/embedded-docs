# Построить график потерь

Узел LossGraphNode создаёт линейный график значений потерь (loss) в процессе обучения и показывает его как изображение предпросмотра. Он считывает значения потерь из узла обучения, строит график с подписанными осями и минимальными/максимальными значениями потерь, после чего возвращает график в виде изображения-предпросмотра в интерфейсе.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `потери` | Карта потерь из узла обучения. Она должна содержать ключ `loss` со списком числовых значений потерь. | LOSS_MAP | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого изображения графика потерь. (по умолчанию: "loss_graph") | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `ui.images` | Сгенерированное изображение графика потерь, отображаемое в качестве предпросмотра. | IMAGE |
