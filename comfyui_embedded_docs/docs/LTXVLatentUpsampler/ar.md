# LTXVLatentUpsampler

عقدة `LTXVLatentUpsampler` تزيد من الدقة المكانية للتمثيل الكامن للفيديو بمعامل اثنين. تستخدم نموذج تكبير متخصصًا لمعالجة البيانات الكامنة، حيث يتم إلغاء تطبيعها أولًا ثم إعادة تطبيعها باستخدام إحصاءات القنوات الخاصة بـ VAE المُقدَّم. صُمِّمت هذه العقدة لسير عمل الفيديو ضمن الفضاء الكامن.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `samples` | التمثيل الكامن للفيديو الذي سيتم تكبيره. | LATENT | نعم |  |
| `upscale_model` | النموذج المُحمَّل المستخدم لتنفيذ التكبير بمقدار 2× على البيانات الكامنة. | LATENT_UPSCALE_MODEL | نعم |  |
| `vae` | نموذج VAE المستخدم لإلغاء تطبيع المدخلات الكامنة قبل التكبير ولإعادة تطبيع المخرجات الكامنة بعده. | VAE | نعم |  |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `LATENT` | التمثيل الكامن المكبَّر، بأبعاد مكانية مضاعفة مقارنةً بالمدخل. يحافظ المخرج الكامن على نفس حجم الدفعة وعدد القنوات والطول الزمني للمدخل، ويُحوَّل مرة أخرى إلى نفس نوع بيانات المدخلات الكامنة. تتم إزالة `noise_mask` من المدخل، إذا كانت موجودة، من المخرج. | LATENT |
