# LTXVLatentUpsampler

عقدة LTXVLatentUpsampler تزيد الدقة المكانية لتمثيل كامن (latent) لفيديو بمقدار الضعف. تستخدم نموذج رفع دقة مخصص لمعالجة البيانات الكامنة، والتي يتم أولاً إلغاء تطبيعها ثم إعادة تطبيعها باستخدام إحصاءات قنوات VAE المقدَّمة. صُممت هذه العقدة لسير عمل الفيديو ضمن الفضاء الكامن.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `عينات` | تمثيل كامن (latent) للمدخلات الخاص بالفيديو المراد رفع دقته. | LATENT | نعم |  |
| `نموذج التكبير` | النموذج المحمَّل المستخدم لإجراء رفع الدقة بمقدار 2x على البيانات الكامنة. | LATENT_UPSCALE_MODEL | نعم |  |
| `vae` | نموذج VAE المستخدم لإلغاء تطبيع المدخلات الكامنة قبل رفع الدقة، ولتطبيع المخرجات الكامنة بعد ذلك. | VAE | نعم |  |

ملاحظة: هذه العقدة مصنَّفة كتجريبية في ComfyUI.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `LATENT` | تمثيل كامن (latent) مرفوع الدقة، مع مضاعفة الأبعاد المكانية مقارنةً بالمدخل. يمتلك المخرج الكامن نفس حجم الدفعة وعدد القنوات والطول الزمني كالمدخل. تتم إزالة `noise_mask` من المدخل، إن وُجد، من المخرج. | LATENT |
