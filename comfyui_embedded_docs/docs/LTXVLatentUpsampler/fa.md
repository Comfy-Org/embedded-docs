# LTXVLatentUpsampler

گره LTXVLatentUpsampler تفکیک‌پذیری مکانی نمایش نهفته ویدیو را با ضریب دو افزایش می‌دهد. این گره از یک مدل بزرگ‌نمایی تخصصی برای پردازش داده‌های نهفته استفاده می‌کند که ابتدا با استفاده از آمار کانال‌های VAE ارائه‌شده غیرنرمال‌سازی شده و سپس مجدداً نرمال‌سازی می‌شود. این گره برای گردش‌های کاری ویدیویی در فضای نهفته طراحی شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | نمایش نهفته ورودی ویدیویی که قرار است بزرگ‌نمایی شود. | LATENT | بله |  |
| `upscale_model` | مدل بارگذاری‌شده‌ای که برای انجام بزرگ‌نمایی ۲ برابری روی داده‌های نهفته استفاده می‌شود. | LATENT_UPSCALE_MODEL | بله |  |
| `vae` | مدل VAE که برای غیرنرمال‌سازی ورودی‌های نهفته پیش از بزرگ‌نمایی و نرمال‌سازی خروجی‌های نهفته پس از آن استفاده می‌شود. | VAE | بله |  |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `LATENT` | نمایش نهفته بزرگ‌نمایی‌شده، با ابعاد مکانی دو برابر نسبت به ورودی. خروجی نهفته دارای همان اندازه دسته، تعداد کانال‌ها و طول زمانی ورودی است و به همان نوع داده ورودی‌های نهفته تبدیل می‌شود. `noise_mask` از ورودی، در صورت وجود، از خروجی حذف می‌شود. | LATENT |
