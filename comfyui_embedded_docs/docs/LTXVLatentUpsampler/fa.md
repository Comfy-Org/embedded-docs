# LTXVLatentUpsampler

گره LTXVLatentUpsampler وضوح فضایی بازنمایی نهان ویدیو را به ضریب دو افزایش می‌دهد. این گره از یک مدل بزرگ‌نمایی تخصصی برای پردازش داده‌های نهان استفاده می‌کند که ابتدا نرمال‌زدایی شده و سپس با استفاده از آمار کانال‌های VAE ارائه‌شده، مجدداً نرمال‌سازی می‌شود. این گره برای گردش‌های کاری ویدیویی در فضای نهان طراحی شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | بازنمایی نهان ورودی ویدیو که قرار است بزرگ‌نمایی شود. | LATENT | بله |  |
| `upscale_model` | مدل بارگذاری‌شده‌ای که برای انجام بزرگ‌نمایی ۲ برابری روی داده‌های نهان استفاده می‌شود. | LATENT_UPSCALE_MODEL | بله |  |
| `vae` | مدل VAE که برای نرمال‌زدایی بازنمایی‌های نهان ورودی پیش از بزرگ‌نمایی و نرمال‌سازی بازنمایی‌های نهان خروجی پس از آن به کار می‌رود. | VAE | بله |  |

توجه: این گره در ComfyUI به عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `LATENT` | بازنمایی نهان بزرگ‌شده، با ابعاد فضایی دو برابر نسبت به ورودی. خروجیِ نهان دارای همان اندازه دسته، تعداد کانال‌ها و طول زمانی ورودی است. `noise_mask` ورودی، در صورت وجود، از خروجی حذف می‌شود. | LATENT |
