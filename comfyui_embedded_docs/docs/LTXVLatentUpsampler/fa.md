# LTXVLatentUpsampler

گره LTXVLatentUpsampler وضوح مکانی یک بازنمایی لاتنت ویدیو را با ضریب دو افزایش می‌دهد. این گره از یک مدل افزایش‌وضوح اختصاصی برای پردازش داده‌های لاتنت استفاده می‌کند؛ این داده‌ها ابتدا از حالت نرمال خارج و سپس با استفاده از آماره‌های کانال VAE ارائه‌شده دوباره نرمال‌سازی می‌شوند. این گره برای جریان‌های کاری ویدیویی در فضای لاتنت طراحی شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | بازنمایی لاتنت ورودی ویدیویی که قرار است افزایش‌وضوح یابد. | LATENT | بله |  |
| `upscale_model` | مدل بارگذاری‌شده‌ای که برای انجام افزایش‌وضوح ۲ برابری روی داده‌های لاتنت استفاده می‌شود. | LATENT_UPSCALE_MODEL | بله |  |
| `vae` | مدل VAE که برای خارج کردن لاتنت‌های ورودی از حالت نرمال پیش از افزایش‌وضوح و نرمال‌سازی لاتنت‌های خروجی پس از آن استفاده می‌شود. | VAE | بله |  |

توجه: این گره در ComfyUI به‌عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `LATENT` | بازنمایی لاتنت افزایش‌وضوح‌یافته، با ابعاد مکانی دو برابر نسبت به ورودی. لاتنت خروجی همان اندازهٔ دسته، تعداد کانال‌ها و طول زمانی ورودی را دارد. اگر `noise_mask` در ورودی موجود باشد، از خروجی حذف می‌شود. | LATENT |
