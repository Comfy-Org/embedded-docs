# LTXVLatentUpsampler

Узел `LTXVLatentUpsampler` увеличивает пространственное разрешение латентного представления видео в два раза. Для обработки латентных данных используется специализированная модель апскейлинга: входные данные сначала денормализуются, а затем повторно нормализуются с использованием статистики каналов предоставленной VAE. Этот узел предназначен для видеопроцессов, работающих в латентном пространстве.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Входное латентное представление видео, которое необходимо увеличить. | LATENT | Да |  |
| `upscale_model` | Загруженная модель, используемая для двукратного увеличения разрешения латентных данных. | LATENT_UPSCALE_MODEL | Да |  |
| `vae` | Модель VAE, используемая для денормализации входных латентных данных перед увеличением и нормализации выходных латентных данных после него. | VAE | Да |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Увеличенное латентное представление, пространственные размеры которого вдвое превышают входные. Выходной латент имеет тот же размер пакета, число каналов и временную длину, что и входной, и преобразуется обратно в тот же тип данных, что и входные латенты. `noise_mask` из входа, если он присутствует, удаляется из выхода. | LATENT |

Примечание: Этот узел помечен как экспериментальный.
