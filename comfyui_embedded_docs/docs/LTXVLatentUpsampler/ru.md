# LTXVLatentUpsampler

Узел `LTXVLatentUpsampler` увеличивает пространственное разрешение скрытого представления видео в два раза. Он использует специализированную модель апскейла для обработки скрытых данных, которые сначала денормализуются, а затем повторно нормализуются с использованием статистики каналов предоставленного VAE. Этот узел предназначен для видеопроцессов в скрытом пространстве.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Входное скрытое представление видео, которое необходимо увеличить. | LATENT | Да |  |
| `модель увеличения` | Загруженная модель, используемая для выполнения 2x увеличения скрытых данных. | LATENT_UPSCALE_MODEL | Да |  |
| `vae` | Модель VAE, используемая для денормализации входных скрытых представлений перед увеличением и для нормализации выходных скрытых представлений после. | VAE | Да |  |

Примечание: Этот узел помечен как экспериментальный в ComfyUI.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Увеличенное скрытое представление, пространственные размеры которого удвоены по сравнению с входными данными. Выходное скрытое представление имеет тот же размер пакета, количество каналов и временную длину, что и входные данные. `noise_mask` из входных данных, если присутствует, удаляется из выходных данных. | LATENT |
