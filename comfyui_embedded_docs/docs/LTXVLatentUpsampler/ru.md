# LTXVLatentUpsampler

Узел LTXVLatentUpsampler увеличивает пространственное разрешение латентного представления видео в два раза. Он использует специализированную модель увеличения для обработки латентных данных, которые сначала денормализуются, а затем повторно нормализуются с использованием статистики каналов предоставленного VAE. Этот узел предназначен для рабочих процессов с видео в латентном пространстве.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Входное латентное представление видео, которое нужно увеличить. | LATENT | Да |  |
| `модель увеличения` | Загруженная модель, используемая для двукратного увеличения латентных данных. | LATENT_UPSCALE_MODEL | Да |  |
| `vae` | Модель VAE, используемая для денормализации входных латентов перед увеличением и для нормализации выходных латентов после него. | VAE | Да |  |

Примечание: В ComfyUI этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Увеличенное латентное представление, пространственные размеры которого вдвое больше, чем у входных данных. Выходной латент имеет тот же размер пакета, число каналов и временную длину, что и входной. `noise_mask` из входных данных, если он присутствует, удаляется из выходных. | LATENT |
