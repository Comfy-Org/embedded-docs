# Постобработка Marigold V2

Этот узел преобразует декодированное предсказание Marigold V2 в изображение для просмотра. Он принимает необработанный тензор предсказания и форматирует его в зависимости от типа предсказания: нормализованная глубина (близкие объекты выглядят яркими), поверхностные нормали единичной длины или альбедо sRGB.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Декодированное предсказание Marigold V2, которое нужно преобразовать в отображаемое изображение. | IMAGE | Да | - |
| `prediction` | Тип предсказания, содержащегося во входных данных, который определяет способ преобразования данных. `"depth"` нормализует значения глубины так, что близкие поверхности становятся яркими, а далёкие — тёмными, после чего результат копируется во все три цветовых канала. `"normals"` перемасштабирует значения в диапазон -1..1, нормализует их до поверхностных нормалей единичной длины и отображает обратно в 0..1. `"albedo"` применяет линейное преобразование в sRGB к значениям. | COMBO | Да | `"depth"`<br>`"normals"`<br>`"albedo"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Обработанное изображение в выбранном представлении: нормализованная глубина (оттенки серого, повторённые по трём каналам), поверхностные нормали единичной длины или альбедо sRGB. | IMAGE |
