# المعالجة اللاحقة لـ Marigold V2

تقوم هذه العقدة بتحويل تنبؤ Marigold V2 بعد فك ترميزه إلى صورة قابلة للعرض. تأخذ موتر التنبؤ الخام وتنسّقه وفقًا لنوع التنبؤ: عمق مُطبَّع (تظهر الأجسام القريبة ساطعة)، أو متجهات عمودية للسطح بطول وحدة، أو ألبيدو sRGB.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | تنبؤ Marigold V2 بعد فك ترميزه المراد تحويله إلى صورة قابلة للعرض. | IMAGE | نعم | - |
| `prediction` | نوع التنبؤ الموجود في المدخل، وهو الذي يحدد كيفية تحويل البيانات. `"depth"` يطبّع قيم العمق بحيث تكون الأسطح القريبة ساطعة والأسطح البعيدة داكنة، ثم ينسخ النتيجة إلى قنوات الألوان الثلاث جميعها. `"normals"` يعيد قياس القيم إلى النطاق -1..1، ويطبعها إلى متجهات عمودية للسطح بطول وحدة، ثم يعيد ربطها إلى 0..1. `"albedo"` يطبّق تحويلًا خطيًا إلى sRGB على القيم. | COMBO | نعم | `"depth"`<br>`"normals"`<br>`"albedo"` |
