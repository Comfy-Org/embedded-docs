# Convert SDR to HDR

تعمل عقدة **Convert SDR to HDR** على توسيع الصور sRGB ذات النطاق الديناميكي القياسي إلى Rec.2020 HLG HDR. وهي تحافظ على المظهر الحالي للصورة وتُعيّن سطوعها ضمن نطاق أوسع، لذا يجب حفظ النتيجة مع تحديد فضاء لوني HDR. تُحفظ قناة ألفا دون تغيير.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة/صور SDR بتنسيق sRGB المراد توسيعها إلى HDR. | IMAGE | نعم | - |
| `algorithm` | خوارزمية توسيع HDR. يؤدي اختيار خوارزمية إلى إظهار معاملاتها (`target_luminance`). | DYNAMIC_COMBO | نعم | `"lottes"` |

### مدخلات lottes

تظهر هذه المعاملات عندما تكون قيمة `algorithm` مضبوطة على `"lottes"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `target_luminance` | هدف أبيض الذروة بوحدة النيت (nits). القيمة 0 تحافظ على العرض المعاير. لا تُطبَّع الصور الداكنة على هذه الذروة. (الافتراضي: 650.0) | FLOAT | نعم | 0.0 إلى 10000.0 (خطوة 1.0) |

تُحوَّل كل صورة في الدفعة على حدة: يُعكَس ترميز sRGB إلى ضوء خطي، ويُوسَّع السطوع باستخدام منحنى عقلاني بنمط Lottes ممزوج بمنحنى كسب لوغاريتمي رتيب معاير، ثم يُعاد ترميز النتيجة بوصفها Rec.2020 HLG. ولأن الخرج بتقنية HDR، يجب أن تستخدم عقدة الحفظ الفضاء اللوني `HDR`؛ فحفظها كـ sRGB يعرض السطوع بشكل غير صحيح.

يفترض HLG شاشة مرجعية بشدة سطوع 1000 nits، لذا تحافظ قيم `target_luminance` الأقل من 1000 على هذا المرجع، بينما تترك القيمة `0` العرض المعاير دون تغيير. تُوسَّع الصور أحادية القناة إلى ثلاث قنوات قبل التحويل، وتُنسخ قناة ألفا كما هي دون تغيير.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `IMAGE` | صورة/صور Rec.2020 HLG HDR. | IMAGE |
