# Convert SDR to HDR

Узел **Convert SDR to HDR** расширяет изображения sRGB со стандартным динамическим диапазоном до Rec.2020 HLG HDR. Он сохраняет существующий вид изображения и отображает его яркость в более широкий диапазон, поэтому результат необходимо сохранять с выбранным цветовым пространством HDR. Альфа-канал сохраняется без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение(я) SDR в sRGB для расширения до HDR. | IMAGE | Да | - |
| `algorithm` | Алгоритм расширения HDR. При выборе алгоритма отображаются его параметры (`target_luminance`). | DYNAMIC_COMBO | Да | `"lottes"` |

### Входы lottes

Эти параметры появляются, когда для `algorithm` выбрано значение `"lottes"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `target_luminance` | Целевая пиковая яркость белого в нитах. Значение 0 сохраняет калиброванный рендеринг. Тёмные изображения не нормализуются к этой пиковой яркости. (по умолчанию: 650.0) | FLOAT | Да | от 0.0 до 10000.0 (шаг 1.0) |

Каждое изображение в пакете преобразуется отдельно: кодировка sRGB инвертируется в линейный свет, яркость расширяется с помощью рациональной кривой в стиле Lottes, смешанной с калиброванной монотонной кривой логарифмического усиления, а результат повторно кодируется как Rec.2020 HLG. Поскольку выходные данные относятся к HDR, узел сохранения должен использовать цветовое пространство `HDR`; при сохранении как sRGB яркость отображается некорректно.

HLG предполагает эталонный дисплей с яркостью 1000 нит, поэтому значения `target_luminance` ниже 1000 сохраняют этот эталон, а значение `0` оставляет калиброванный рендеринг без изменений. Одноканальные изображения перед преобразованием расширяются до трёх каналов, а альфа-канал копируется без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение(я) Rec.2020 HLG HDR. | IMAGE |
