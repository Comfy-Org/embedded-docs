# Tencent3DTextureEditNode

צומת זה משתמש ב-API של Tencent Hunyuan3D כדי לערוך את הטקסטורות של מודל תלת-ממדי. אתם מספקים מודל תלת-ממדי ותיאור טקסטואלי של השינויים הרצויים, והצומת מחזיר גרסה חדשה של המודל שטקסטורותיו מצוירות מחדש בהתאם להנחיה שלכם.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | מודל תלת-ממדי בפורמט FBX. המודל צריך להכיל פחות מ-100000 פאות. | FILE3D | כן | FBX, Any |
| `prompt` | מתאר עריכת טקסטורות. תומך בעד 1024 תווים ב-UTF-8. | STRING | כן |  |
| `seed` | הפרמטר `seed` קובע האם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 0) | INT | לא | 0 to 2147483647 |

**הערה:** הקלט `model_3d` חייב להיות קובץ בפורמט FBX. פורמטים אחרים של קבצים תלת-ממדיים אינם נתמכים על ידי צומת זה. הפרמטר `prompt` הוא חובה וחייב להיות באורך שבין 1 ל-1024 תווים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `GLB` | המודל התלת-ממדי המעובד בפורמט GLB. | FILE3D |
| `OBJ` | המודל התלת-ממדי המעובד בפורמט OBJ. | FILE3D |
| `texture_image` | תמונת הטקסטורה החדשה שנוצרה עבור המודל התלת-ממדי. | IMAGE |
