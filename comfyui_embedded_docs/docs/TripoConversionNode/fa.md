# Tripo: تبدیل مدل

این گره یک مدل سه‌بعدی Tripo موجود را به قالب فایل سه‌بعدی دیگری تبدیل می‌کند. شناسه وظیفه (task ID) مدلی را می‌گیرد که پیش‌تر توسط یک عملیات Tripo (مانند تولید مدل، ریگ‌بندی، ری‌تارگتینگ یا قطعه‌بندی) ایجاد یا پردازش شده است، یک وظیفه تبدیل به Tripo API ارسال می‌کند، منتظر پایان آن وظیفه می‌ماند و سپس فایل مدل تبدیل‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | شناسه وظیفه مدل Tripo برای تبدیل. باید از یک وظیفه قبلی تولید مدل، ریگ‌بندی، ری‌تارگتینگ یا قطعه‌بندی Tripo آمده باشد. اگر شناسه موجود نباشد یا خالی باشد، گره خطا ایجاد می‌کند. | STRING | بله | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `format` | قالب فایل هدف برای مدل سه‌بعدی تبدیل‌شده. | COMBO | بله | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | وقتی فعال باشد، مثلث‌ها را به چهارضلعی تبدیل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `face_limit` | حداکثر تعداد وجوه در مدل تبدیل‌شده. برای بدون محدودیت مقدار -1 را تنظیم کنید (پیش‌فرض: -1). | INT | خیر | -1 تا 2000000 |
| `texture_size` | رزولوشن بافت‌های خروجی بر حسب پیکسل (پیش‌فرض: 4096). | INT | خیر | 128 تا 8192 |
| `texture_format` | قالب فایل مورد استفاده برای بافت‌های صادرشده (پیش‌فرض: JPEG). | COMBO | خیر | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `force_symmetry` | وقتی فعال باشد، مدل را مجبور به متقارن‌بودن می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `flatten_bottom` | وقتی فعال باشد، پایین مدل را تخت می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `flatten_bottom_threshold` | عمق تخت‌سازی که همراه با `flatten_bottom` استفاده می‌شود (پیش‌فرض: 0.01). این مقدار فقط زمانی اعمال می‌شود که `flatten_bottom` فعال باشد. | FLOAT | خیر | 0.01 تا 1.0 |
| `pivot_to_center_bottom` | وقتی فعال باشد، نقطه محور (pivot) را به مرکز پایین مدل منتقل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `scale_factor` | ضریب مقیاسی که به مدل تبدیل‌شده اعمال می‌شود (پیش‌فرض: 1.0). | FLOAT | خیر | 0.01 و بالاتر |
| `with_animation` | اسکلت و انیمیشن مدل‌های ریگ‌شده یا ری‌تارگت‌شده را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `pack_uv` | وقتی فعال باشد، مختصات UV را دوباره بسته‌بندی می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `bake` | متریال‌های پیشرفته را برای سازگاری بیشتر در بافت‌های پایه پخت می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `part_names` | فهرست جدا‌شده با ویرگول از نام قطعات مدل که به تبدیل فرستاده می‌شوند. ورودی‌های خالی نادیده گرفته می‌شوند و نام‌های تکراری حذف می‌شوند. برای حذف این گزینه، آن را خالی بگذارید (پیش‌فرض: خالی). | STRING | خیر | فهرست جدا‌شده با ویرگول از نام قطعات |
| `fbx_preset` | پیش‌تنظیم سازگاری FBX. مقدار bake_scale تبدیل مقیاس را در هندسه پخت می‌کند (پیش‌فرض: blender). | COMBO | خیر | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `export_vertex_colors` | وقتی فعال باشد، رنگ‌های رأس را صادر می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `export_orientation` | محور جلویی مدل صادرشده. مقدار default محور +x مربوط به Tripo را حفظ می‌کند (پیش‌فرض: default). | COMBO | خیر | default<br>+x<br>-x<br>+y<br>-y |
| `animate_in_place` | وقتی فعال باشد، مدل را در جای خود انیمیت می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |

**توجه:** به‌جز `original_model_task_id` و `format`، همه ورودی‌ها تنظیمات پیشرفته اختیاری هستند. بیشتر تنظیماتی که در مقادیر پیش‌فرض خود رها شوند از درخواست تبدیل حذف می‌شوند تا Tripo API بتواند رفتار استاندارد خود را اعمال کند. گزینه‌های `with_animation` و `bake` همیشه ارسال می‌شوند. `flatten_bottom_threshold` فقط زمانی اعمال می‌شود که `flatten_bottom` فعال باشد.
