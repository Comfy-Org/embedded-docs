# Tripo: تحويل النموذج

تحوّل هذه العقدة نموذج Tripo ثلاثي الأبعاد موجود إلى صيغة ملف ثلاثية الأبعاد أخرى. تأخذ معرّف المهمة (task ID) لنموذج أُنشئ أو عُولج سابقًا بواسطة عملية Tripo (مثل توليد النموذج، أو التجهيز الهيكلي، أو إعادة الاستهداف، أو التقسيم)، ثم ترسل مهمة تحويل إلى Tripo API، وتنتظر انتهاء تلك المهمة، ثم تُعيد ملف النموذج المحوَّل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | معرّف المهمة لنموذج Tripo المراد تحويله. يجب أن يأتي من مهمة سابقة لتوليد نموذج Tripo أو تجهيز هيكلي أو إعادة استهداف أو تقسيم. إذا كان المعرّف مفقودًا أو فارغًا، تُطلق العقدة خطأً. | STRING | نعم | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `format` | صيغة الملف الهدف للنموذج ثلاثي الأبعاد المحوَّل. | COMBO | نعم | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | تحويل المثلثات إلى رباعيات عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `face_limit` | الحد الأقصى لعدد الأوجه في النموذج المحوَّل. اضبطه على -1 لعدم وجود حد (الافتراضي: -1). | INT | لا | -1 إلى 2000000 |
| `texture_size` | دقة الأنسجة في المخرجات بالبكسل (الافتراضي: 4096). | INT | لا | 128 إلى 8192 |
| `texture_format` | صيغة الملف المستخدمة للأنسجة المُصدَّرة (الافتراضي: JPEG). | COMBO | لا | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `force_symmetry` | فرض تناظر النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `flatten_bottom` | تسوية الجزء السفلي من النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `flatten_bottom_threshold` | عمق التسوية المستخدم مع `flatten_bottom` (الافتراضي: 0.01). تُطبَّق هذه القيمة فقط عند تمكين `flatten_bottom`. | FLOAT | لا | 0.01 إلى 1.0 |
| `pivot_to_center_bottom` | نقل نقطة الارتكاز إلى مركز الجزء السفلي من النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `scale_factor` | عامل القياس المطبَّق على النموذج المحوَّل (الافتراضي: 1.0). | FLOAT | لا | 0.01 وما فوق |
| `with_animation` | الاحتفاظ بالهيكل العظمي والحركة للنماذج المجهزة هيكليًا أو المعاد استهدافها (الافتراضي: True). | BOOLEAN | لا | True or False |
| `pack_uv` | إعادة تجميع إحداثيات UV عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `bake` | دمج المواد المتقدمة في الأنسجة الأساسية لتوافق أوسع (الافتراضي: True). | BOOLEAN | لا | True or False |
| `part_names` | قائمة أسماء أجزاء النموذج مفصولة بفواصل لإرسالها إلى التحويل. تُتجاهل الإدخالات الفارغة وتُزال الأسماء المكررة. اتركها فارغة لتجاهل هذا الخيار (الافتراضي: فارغ). | STRING | لا | قائمة أسماء الأجزاء مفصولة بفواصل |
| `fbx_preset` | إعداد مسبق لتوافق FBX. يقوم bake_scale بدمج تحويل القياس في الهندسة (الافتراضي: blender). | COMBO | لا | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `export_vertex_colors` | تصدير ألوان الرؤوس عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `export_orientation` | المحور الأمامي للنموذج المُصدَّر. يحافظ default على +x الخاص بـ Tripo (الافتراضي: default). | COMBO | لا | default<br>+x<br>-x<br>+y<br>-y |
| `animate_in_place` | تحريك النموذج في مكانه عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |

**ملاحظة:** باستثناء `original_model_task_id` و`format`، فإن جميع المدخلات إعدادات متقدمة اختيارية. تُحذف معظم الإعدادات التي تُترك على قيمها الافتراضية من طلب التحويل حتى يتمكن Tripo API من استخدام سلوكه القياسي. يُرسَل الخياران `with_animation` و`bake` دائمًا. لا يُطبَّق `flatten_bottom_threshold` إلا عندما يكون `flatten_bottom` ممكّنًا.
