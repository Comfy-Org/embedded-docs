# Tripo: Конвертировать модель

Этот узел преобразует существующую 3D-модель Tripo в другой формат 3D-файла. Он принимает ID задачи модели, ранее созданной или обработанной операцией Tripo (например, генерацией модели, риггингом, ретаргетингом или сегментацией), отправляет задачу преобразования в Tripo API, ожидает завершения этой задачи, а затем возвращает преобразованный файл модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | ID задачи модели Tripo для преобразования. Он должен происходить из более ранней задачи Tripo по генерации модели, риггингу, ретаргетингу или сегментации. Если ID отсутствует или пуст, узел вызывает ошибку. | STRING | Да | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `format` | Целевой формат файла для преобразованной 3D-модели. | COMBO | Да | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | Преобразовывать треугольники в четырёхугольники, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `face_limit` | Максимальное количество граней в преобразованной модели. Установите -1, чтобы не ограничивать (по умолчанию: -1). | INT | Нет | -1 до 2000000 |
| `texture_size` | Разрешение выходных текстур в пикселях (по умолчанию: 4096). | INT | Нет | 128 до 8192 |
| `texture_format` | Формат файла, используемый для экспортируемых текстур (по умолчанию: JPEG). | COMBO | Нет | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `принудительная симметрия` | Принудительно сделать модель симметричной, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `выравнивание низа` | Сделать нижнюю часть модели плоской, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `порог выравнивания низа` | Глубина выравнивания, используемая с `flatten_bottom` (по умолчанию: 0.01). Это значение применяется только когда `flatten_bottom` включён. | FLOAT | Нет | 0.01 до 1.0 |
| `центрировать нижнюю точку` | Переместить точку привязки (pivot) в центр нижней части модели, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `коэффициент масштабирования` | Коэффициент масштабирования, применяемый к преобразованной модели (по умолчанию: 1.0). | FLOAT | Нет | 0.01 и выше |
| `с анимацией` | Сохранять скелет и анимацию моделей с риггингом или ретаргетингом (по умолчанию: True). | BOOLEAN | Нет | True or False |
| `упаковать UV` | Перепаковать UV-координаты, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `запечь` | Запекать продвинутые материалы в базовые текстуры для более широкой совместимости (по умолчанию: True). | BOOLEAN | Нет | True or False |
| `имена частей` | Список имён частей модели, разделённых запятыми, для отправки в преобразование. Пустые элементы игнорируются, а дубликаты имён удаляются. Оставьте пустым, чтобы пропустить эту опцию (по умолчанию: пусто). | STRING | Нет | Список имён частей, разделённых запятыми |
| `FBX-пресет` | Пресет совместимости FBX. bake_scale запекает преобразование масштаба в геометрию (по умолчанию: blender). | COMBO | Нет | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `экспортировать цвета вершин` | Экспортировать цвета вершин, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `экспортировать ориентацию` | Ось направления вперёд экспортируемой модели. default сохраняет +x Tripo (по умолчанию: default). | COMBO | Нет | default<br>+x<br>-x<br>+y<br>-y |
| `анимировать на месте` | Анимировать модель на месте, когда включено (по умолчанию: False). | BOOLEAN | Нет | True or False |

**Примечание:** За исключением `original_model_task_id` и `format`, все входы являются необязательными расширенными настройками. Большинство настроек, оставленных со значениями по умолчанию, не включаются в запрос на преобразование, чтобы Tripo API мог использовать стандартное поведение. Опции `with_animation` и `bake` отправляются всегда. `flatten_bottom_threshold` применяется только когда `flatten_bottom` включён.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Преобразованная модель в запрошенном формате. Tripo поставляет OBJ в виде ZIP-архива (сетка, материал и текстуры). | FILE_3D |
