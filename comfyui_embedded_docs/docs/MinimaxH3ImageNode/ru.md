# MiniMax H3 Image

Создаёт изображения из текста с помощью MiniMax H3 Image или редактирует и объединяет до 16 референсных изображений. В промпте на референсы ссылаются по порядку подключения: `@Image1`, `@Image2` и так далее.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | `MiniMax-H3-Image` или `MiniMax-H3-Image-Highspeed` для более быстрого выполнения. По умолчанию: `"MiniMax-H3-Image"`. | COMBO | Да | `"MiniMax-H3-Image"`<br>`"MiniMax-H3-Image-Highspeed"` |
| `prompt` | Что сгенерировать или как отредактировать референсы. Если подключены референсные изображения, он может содержать не более 8,000 символов. По умолчанию: пусто. | STRING | Да | от 1 до 8000 символов |
| `size` | `2K` и `4K` вычисляют размер из соотношения сторон; `custom` задаёт точную ширину и высоту. По умолчанию: `"2K"`. | DYNAMIC_COMBO | Да | `"2K"`<br>`"4K"`<br>`"custom"` |
| `enhance_prompt` | MiniMax переписывает промпт в подробное описание сцены перед генерацией. Редактирование изображений всегда проходит с улучшением. Если выключено, выберите фиксированное соотношение сторон или пользовательский размер. По умолчанию: true. | BOOLEAN | Нет | true<br>false |
| `seed` | Управляет тем, перезапускается ли узел; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |
| `images` | Референсные изображения для редактирования или объединения; в промпте на них ссылаются как `@Image1`–`@Image16` в порядке подключения. | AUTOGROW | Нет | До 16 изображений |

### Входы размера "2K" и "4K"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | При `auto` MiniMax выбирает соотношение по промпту или следует за референсным изображением, если оно подключено. Для генерации изображения по тексту при выключенном `enhance_prompt` требуется фиксированное соотношение. По умолчанию: `"auto"`. | COMBO | Да | Доступно несколько вариантов |

### Входы размера "custom"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина выхода в пикселях. По умолчанию: 2048. | INT | Да | от 512 до 7680 (шаг 16) |
| `height` | Высота выхода в пикселях. По умолчанию: 2048. | INT | Да | от 512 до 7680 (шаг 16) |

Примечание: для пользовательского размера произведение ширины на высоту должно быть между 655,360 и 20,000,000 пикселей при соотношении сторон не более 3:1.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Сгенерированное или отредактированное изображение в формате PNG. | IMAGE |
| `revised_prompt` | Переписанный промпт, который использовал MiniMax, когда улучшение промпта было включено. | STRING |
