# Wan Image to Image

הצומת Wan Image to Image יוצר תמונה מתמונת קלט אחת או שתיים ומפרומפט טקסטואלי. הוא משנה את תמונות הקלט שלך בהתבסס על התיאור שתספק, ויוצר תמונה חדשה ששומרת על יחס הגובה-רוחב של הקלט המקורי שלך. תמונת הפלט קבועה ב-1.6 מגה-פיקסל ללא תלות בגודל הקלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש (ברירת מחדל: "wan2.5-i2i-preview"). | COMBO | כן | "wan2.5-i2i-preview" |
| `image` | עריכה של תמונה בודדת או מיזוג תמונות מרובות. מקסימום 2 תמונות. | IMAGE | כן | - |
| `prompt` | פרומפט המתאר את המרכיבים והמאפיינים החזותיים. תומך באנגלית ובסינית (ברירת מחדל: ריק). | STRING | כן | - |
| `negative_prompt` | פרומפט שלילי המתאר ממה יש להימנע (ברירת מחדל: ריק). | STRING | לא | - |
| `seed` | Seed לשימוש ביצירה (ברירת מחדל: 0). | INT | לא | 0 to 2147483647 |
| `watermark` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה (ברירת מחדל: false). | BOOLEAN | לא | - |

**הערה:** הצומת מקבל בדיוק תמונה אחת או 2 תמונות קלט. אם תספק יותר מ-2 תמונות או לא תספק תמונות כלל, הצומת יחזיר שגיאה.
