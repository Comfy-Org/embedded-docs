# تهيئة Lotus

عقدة LotusConditioning توفر تضمينات تكييف ثابتة ومحسوبة مسبقًا لنموذج Lotus. نظرًا لأن Lotus يستخدم مشفّرًا مجمّدًا مع تكييف فارغ، فإن العقدة تضمّن تضمينات المطالبة الناتجة مباشرة بدلًا من تشغيل الاستدلال أو تحميل ملفات موترات كبيرة، لذا لا يتغير مخرجها أبدًا. يمكن توصيل التكييف المُعاد مباشرةً بخط أنابيب توليد يتوقع تكييفًا متوافقًا مع Lotus.
