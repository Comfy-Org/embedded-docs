# تهيئة Lotus

عقدة LotusConditioning توفر تضمينات تكييف محسوبة مسبقًا لنموذج Lotus. تستخدم مشفِّرًا مجمَّدًا مع تكييف فارغ، وتُعيد تضمينات مطالبة ثابتة (hardcoded) لتحقيق التكافؤ مع التنفيذ المرجعي دون الحاجة إلى استدلال أو تحميل ملفات موتر كبيرة. تُخرج هذه العقدة موتر تكييف ثابتًا يمكن استخدامه مباشرةً في خط أنابيب التوليد.
