# تهيئة Lotus

توفر عقدة `LotusConditioning` ترميزات شرطية محسوبة مسبقًا لطراز Lotus. تستخدم العقدة مشفّرًا مجمّدًا مع تكييف فارغ (null conditioning) وتُعيد ترميزات مطالبة (prompt embeddings) مكتوبة بشكل ثابت (hardcoded) لتحقيق التطابق مع التنفيذ المرجعي، دون الحاجة إلى الاستدلال أو تحميل ملفات موترات كبيرة. تُخرج هذه العقدة موترًا شرطيًا ثابتًا يمكن استخدامه مباشرةً في خط أنابيب التوليد.
