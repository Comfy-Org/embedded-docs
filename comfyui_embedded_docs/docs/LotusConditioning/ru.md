# LotusConditioning

Узел LotusConditioning предоставляет фиксированные предварительно вычисленные эмбеддинги кондиционирования для модели Lotus. Поскольку Lotus использует замороженный энкодер с пустым кондиционированием, узел встраивает полученные эмбеддинги промпта напрямую вместо выполнения инференса или загрузки больших файлов тензоров, поэтому его выход никогда не меняется. Возвращаемое кондиционирование можно напрямую подключить к пайплайну генерации, который ожидает кондиционирование, совместимое с Lotus.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| *Нет входов* | Этот узел не принимает входные параметры. | - | - | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Предварительно вычисленные эмбеддинги кондиционирования для модели Lotus. Возвращается в виде списка кондиционирования, содержащего фиксированные эмбеддинги промпта вместе с пустым словарём. | CONDITIONING |
