# LotusConditioning

### Описание

Узел `LotusConditioning` предоставляет предварительно вычисленные кондиционирующие эмбеддинги для модели Lotus. Он использует замороженный энкодер с нулевым кондиционированием и возвращает жестко заданные эмбеддинги промпта для достижения паритета с эталонной реализацией без необходимости выполнения инференса или загрузки больших тензорных файлов. Этот узел выводит фиксированный тензор кондиционирования, который можно использовать непосредственно в конвейере генерации.
