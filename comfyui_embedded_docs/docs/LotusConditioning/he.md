# LotusConditioning

צומת LotusConditioning מספק הטמעות קונדישנינג קבועות ומחושבות מראש עבור מודל Lotus. מכיוון ש-Lotus משתמש במקודד קפוא עם קונדישנינג null, הצומת משבץ ישירות את הטמעות הפרומפט המתקבלות במקום להריץ אינפרנס או לטעון קבצי טנזור גדולים, ולכן הפלט שלו לעולם אינו משתנה. ניתן לחבר את הקונדישנינג המוחזר ישירות לצינור יצירה שמצפה לקונדישנינג תואם Lotus.
