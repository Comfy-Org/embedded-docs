# LotusConditioning

گره LotusConditioning تعبیه‌های conditioning ثابت و پیش‌محاسبه‌شده را برای مدل Lotus فراهم می‌کند. از آنجا که Lotus از یک رمزگذار فریزشده با conditioning تهی استفاده می‌کند، گره به‌جای اجرای استنتاج یا بارگذاری فایل‌های تنسور بزرگ، تعبیه‌های پرامپت حاصل را مستقیماً درون‌خطی می‌کند؛ بنابراین خروجی آن هرگز تغییر نمی‌کند. conditioning بازگردانده‌شده را می‌توان مستقیماً به یک پایپ‌لاین تولید متصل کرد که conditioning سازگار با Lotus را انتظار دارد.
