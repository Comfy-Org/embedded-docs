# LotusConditioning

گره LotusConditioning، جاسازی‌های conditioning از پیش محاسبه‌شده را برای مدل Lotus فراهم می‌کند. این گره از یک رمزگذار منجمد با conditioning تهی استفاده می‌کند و جاسازی‌های prompt از پیش تعیین‌شده را برمی‌گرداند تا با پیاده‌سازی مرجع هماهنگی داشته باشد، بدون نیاز به استنتاج یا بارگذاری فایل‌های تنسور بزرگ. این گره یک تنسور conditioning ثابت خروجی می‌دهد که می‌تواند مستقیماً در خط لوله تولید به کار رود.
