# LotusConditioning

گره `LotusConditioning` جاسازی‌های شرطی‌سازی از پیش محاسبه‌شده را برای مدل Lotus فراهم می‌کند. این گره از یک رمزگذار ثابت (frozen encoder) با شرطی‌سازی تهی استفاده می‌کند و جاسازی‌های پرامپت از پیش تعیین‌شده را برمی‌گرداند تا با پیاده‌سازی مرجع هماهنگ باشد، بدون نیاز به استنتاج یا بارگذاری فایل‌های تانسور بزرگ. این گره یک تانسور شرطی‌سازی ثابت خروجی می‌دهد که می‌توان مستقیماً در خط لوله تولید استفاده کرد.
