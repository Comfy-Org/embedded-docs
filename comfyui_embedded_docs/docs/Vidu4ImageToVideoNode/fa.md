# Vidu Q4 Image-to-Video Generation

با مدل Vidu Q4، یک ویدیو از یک فریم شروع و یک پرامپت اختیاری تولید کنید. خروجی نسبت تصویر تصویر ورودی را حفظ می‌کند.

با انتخاب `model`، پارامترهای مخصوص آن مدل نمایش داده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | فریم شروع ویدیوی تولیدشده. نسبت تصویر باید بین 1:5 و 5:1 باشد. | IMAGE | بله | N/A |
| `model` | مدل مورد استفاده برای تولید ویدیو. با انتخاب یک مدل، پارامترهای مخصوص آن نمایش داده می‌شوند: `prompt`، `resolution`، `duration`، `audio` و `seed`. | DYNAMIC_COMBO | بله | `"Vidu Q4 Preview"` |
| `prompt` | یک پرامپت متنی اختیاری برای تولید ویدیو، حداکثر 5000 کاراکتر (پیش‌فرض: خالی). | STRING | بله | هر متنی |
| `resolution` | رزولوشن ویدیوی خروجی (پیش‌فرض: `"720p"`). | COMBO | بله | `"540p"`<br>`"720p"`<br>`"1080p"`<br>`"2K"`<br>`"4K"` |
| `duration` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 16 |
| `audio` | در صورت فعال بودن، ویدیو را همراه با صدا، شامل گفت‌وگو و جلوه‌های صوتی، خروجی می‌دهد (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |
| `seed` | `seed` کنترل می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج صرف‌نظر از seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 1 تا 2147483647 |

**توجه:** نسبت تصویر `image` باید بین 1:5 و 5:1 باقی بماند و `prompt` نمی‌تواند از 5000 کاراکتر فراتر رود. نتیجه نسبت تصویر تصویر ورودی را حفظ می‌کند؛ بنابراین اندازه خروجی فقط در همان نسبت از تنظیم `resolution` پیروی می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `VIDEO` | فایل ویدیوی تولیدشده. | VIDEO |
