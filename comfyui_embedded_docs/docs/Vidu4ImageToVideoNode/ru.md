# Vidu Q4 Image-to-Video Generation

Создаёт видео из начального кадра и необязательного промпта с помощью модели Vidu Q4. Выходное видео сохраняет соотношение сторон входного изображения.

Выбор `model` открывает параметры, специфичные для этой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Начальный кадр генерируемого видео. Соотношение сторон должно быть в диапазоне от 1:5 до 5:1. | IMAGE | Да | N/A |
| `model` | Модель, используемая для генерации видео. При выборе модели отображаются специфичные для неё параметры: `prompt`, `resolution`, `duration`, `audio` и `seed`. | DYNAMIC_COMBO | Да | `"Vidu Q4 Preview"` |
| `prompt` | Необязательный текстовый промпт для генерации видео длиной до 5000 символов (по умолчанию: пусто). | STRING | Да | Любой текст |
| `resolution` | Разрешение выходного видео (по умолчанию: `"720p"`). | COMBO | Да | `"540p"`<br>`"720p"`<br>`"1080p"`<br>`"2K"`<br>`"4K"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | от 3 до 16 |
| `audio` | Если включено, выводит видео со звуком, включая диалоги и звуковые эффекты (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. Этот параметр имеет функциональность «control after generate» (по умолчанию: 42). | INT | Да | от 1 до 2147483647 |

**Примечание:** Соотношение сторон `image` должно оставаться в диапазоне от 1:5 до 5:1, а `prompt` не может превышать 5000 символов. Результат сохраняет соотношение сторон входного изображения, поэтому выходной размер соответствует настройке `resolution` только в пределах этого соотношения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный видеофайл. | VIDEO |
