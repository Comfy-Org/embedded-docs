# Kling 4.0 Reference to Video

使用 Kling 4.0 模型，從參考圖片和參考影片生成包含音訊的影片。這些參考素材驅動主體、風格與動作，而可選的第一幀與最後一幀則固定影片的開頭與結尾。適合在單一鏡頭中保持角色或場景的一致性，同時在提示詞中描述動作。

**限制與行為：**

* 圖片總數上限為 10 張，計算範圍包含參考圖片、第一幀與最後幀。
* 每張圖片必須至少為 300x300 像素，長寬比介於 2:5 與 5:2 之間。
* 每段參考影片必須為 3 至 30 秒長、至少 700x700 且最多 4553x4553 像素、總像素不超過 8,294,400，長寬比介於 2:5 與 5:2 之間，且影格率至少為 24 fps。所有參考影片的總長度不得超過 30 秒。
* 若提示詞提到 `@ImageN` 或 `@VideoN`，但實際連接的該類輸入少於 N 個，就會引發錯誤。
* 當連接了第一幀或最後幀時，節點會加入一項指示，要求影片必須正好從該幀開始或結束。
