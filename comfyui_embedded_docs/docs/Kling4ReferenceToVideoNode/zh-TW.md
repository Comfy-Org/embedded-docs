# Kling 4.0 參考轉影片

使用 Kling 4.0 模型，從參考影像和參考影片生成帶有音訊的影片。參考素材可驅動主體、風格和動態，而選用的首幀與末幀則可固定影片的開頭與結尾。當您需要在鏡頭中保持角色或場景的一致性，同時在提示詞中描述動作時，可使用此節點。

**限制與行為：**

* 影像總數上限為 10 張，計入參考影像、首幀與末幀。
* 每張影像必須至少為 300x300 像素，畫面比例介於 2:5 與 5:2 之間。
* 每支參考影片長度必須為 3 至 30 秒（使用 `kling-4.0-flash` 時為 3 至 20 秒），解析度至少 700x700 且最多 4553x4553 像素，總像素不得超過 8,294,400，畫面比例介於 2:5 與 5:2 之間，且影格率至少為 24 fps。所有參考影片合計亦不得超過相同的限制。
* 若提示詞提及 `@ImageN` 或 `@VideoN`，但實際連接的該類輸入少於 N 個，則會引發錯誤。
* 當連接首幀或末幀時，節點會加入指示，要求影片必須恰好從該幀開始或結束。
