# Kling 4.0 參考轉影片

使用 Kling 4.0 模型從參考影像與參考影片產生影片，並包含音訊。參考內容會驅動主體、風格與動作，而選用的第一影格與最後影格可固定片段的開頭與結尾。可用於在單一鏡頭中保持角色或場景一致，同時在提示詞中描述動作。

**限制與行為：**

* 影像總數上限為 10 張，計算包含參考影像、第一影格與最後影格。
* 每張影像必須至少為 300x300 像素，且長寬比介於 2:5 與 5:2 之間。
* 每段參考影片長度必須為 3 至 30 秒（使用 `kling-4.0-flash` 時為 3 至 20 秒），至少 700x700 且最多 4553x4553 像素，總像素不得超過 8,294,400，長寬比介於 2:5 與 5:2 之間，且影格率至少 24 fps。所有參考影片合計不得超過相同限制。
* 若提示詞提及 `@ImageN` 或 `@VideoN`，但該類輸入連接的數量少於 N，則會引發錯誤。
* 當連接第一影格或最後影格時，節點會加入指示，讓影片正好從該影格開始或正好在該影格結束。
