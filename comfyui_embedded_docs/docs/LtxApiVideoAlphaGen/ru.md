# LTX Video AlphaGen

Извлекает полутоновую альфа-матту, в которой передний план белый, покадрово соответствующую входному видео. Передайте матту в Get Video Components и Image To Mask, чтобы преобразовать её в маску. Аудио не сохраняется.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Видео для создания матты, длительностью до 10 секунд и разрешением 3840x2160 в любой ориентации. | VIDEO | Да | - |
| `seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Нет | от 0 до 4294967295 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `matte` | Альфа-матта в виде видео: один кадр на каждый входной кадр, без аудио. | VIDEO |
