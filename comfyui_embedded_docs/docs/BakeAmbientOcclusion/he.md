# BakeAmbientOcclusion

מבצע אפייה של מפת ambient-occlusion מרשת high-poly אל פריסת ה-UV של רשת low-poly. הפלט הוא תמונה בגווני אפור שבה טקסלים לבנים הם פתוחים וטקסלים כהים נמצאים בשקעים; היא מיועדת לקלט ה-occlusion של הצומת Apply Texture To Mesh. חברו את רשת ה-low-poly עם פריסת ה-UV ואת רשת ה-high-poly שממנה בוצע הפישוט (decimation).

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | רשת ה-low-poly עם פריסת UV שאליה מבצעים את האפייה. חייבת להיות בעלת UV; הצומת מעלה שגיאה אם הם חסרים. | MESH | כן | - |
| `high_poly` | רשת ה-high-poly שממנה בוצע הפישוט של ה-low-poly, ומשמשת כגיאומטריית המקור עבור ה-occlusion. | MESH | כן | - |
| `resolution` | רזולוציית הטקסטורה בפיקסלים; כל טקסל מקבל ערך occlusion. ברירת מחדל: 1024. | INT | כן | 64 עד 8192 (צעד 64) |
| `samples` | קרניים לכל טקסל. יותר = חלק יותר, איטי יותר. יש להעלות אם התוצאה מגורענת. ברירת מחדל: 64. | INT | כן | 4 עד 1024 (צעד 4) |
| `max_distance` | אורך הקרן, כשבר מהאלכסון של תיבת התחום (bounding box). קטן יותר = הדוק יותר, occlusion מקומי יותר. ברירת מחדל: 0.5. | FLOAT | כן | 0.01 עד 2.0 (צעד 0.01) |
| `strength` | מכוונן את עוצמת ה-occlusion. >1 מכהה, <1 מבהיר. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 2.0 (צעד 0.05) |
| `bias` | הרמת מקור הקרן מעל פני השטח, כשבר מהאלכסון של תיבת התחום. יש להעלות אם גם משטחים חלקים מציגים כתמים כהים/חורים. ברירת מחדל: 0.01. | FLOAT | כן | 0.0001 עד 0.2 (צעד 0.0005) |

הערה: ל-`low_poly` חייבות להיות קואורדינטות UV — צומת זה לעולם אינו פורש את הרשת מחדש (unwraps). אם `high_poly` מכיל רק פריט אצווה אחד, הוא נעשה בו שימוש חוזר עבור כל פריט אצווה של `low_poly`; פריטי אצווה של `low_poly` ללא פאות מדולגים ומוחלפים בתמונה לבנה לחלוטין, עם אזהרה שנרשמת ביומן. אם קואורדינטות ה-UV של `low_poly` חורגות מחוץ לטווח 0-1, הן מותאמות באופן אחיד בחזרה לתוכו, ואזהרה נרשמת ביומן כאשר מזוהה פריסה בסגנון tiled/UDIM.

## פלטים

| שם פלט | תיאור | סוג נתונים |

| `occlusion` | תמונת ambient-occlusion בגווני אפור עם ערכים בטווח [0,1] (לבן = פתוח, כהה = שקעים), תמונה אחת לכל פריט אצווה של `low_poly`. מיועדת לקלט ה-occlusion של הצומת Apply Texture To Mesh (נארזת אל מפת ORM / occlusionTexture). | IMAGE |
