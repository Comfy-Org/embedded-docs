# Запечь ambient occlusion

Запекает карту ambient occlusion с высокополигонального меша в UV-развёртку низкополигонального меша. Результат — изображение в оттенках серого, в котором белые тексели соответствуют открытым участкам, а тёмные — углублениям; оно предназначено для входа `occlusion` узла Apply Texture To Mesh. Подключите низкополигональный меш с UV-развёрткой и высокополигональный меш, из которого он был получен путём децимации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | Низкополигональный меш с UV-развёрткой, в который выполняется запекание. Должен иметь UV; узел выдаёт ошибку, если они отсутствуют. | MESH | Да | - |
| `high_poly` | Высокополигональный меш, из которого низкополигональный был получен путём децимации; используется как исходная геометрия для окклюзии. | MESH | Да | - |
| `resolution` | Разрешение текстуры в пикселях; каждый тексель получает значение окклюзии. По умолчанию: 1024. | INT | Да | 64–8192 (шаг 64) |
| `samples` | Количество лучей на тексель. Больше = глаже, медленнее. Увеличьте, если результат зернистый. По умолчанию: 64. | INT | Да | 4–1024 (шаг 4) |
| `max_distance` | Длина луча как доля диагонали ограничивающего бокса. Меньше = более плотная, более локальная окклюзия. По умолчанию: 0.5. | FLOAT | Да | 0.01–2.0 (шаг 0.01) |
| `strength` | Масштабирует окклюзию. >1 затемняет, <1 осветляет. По умолчанию: 1.0. | FLOAT | Да | 0.0–2.0 (шаг 0.05) |
| `bias` | Смещение начала луча от поверхности как доля диагонали ограничивающего бокса. Увеличьте, если даже на ровных поверхностях появляются тёмные пятна/дыры. По умолчанию: 0.01. | FLOAT | Да | 0.0001–0.2 (шаг 0.0005) |

Примечание: `low_poly` должен иметь UV-координаты — этот узел никогда не создаёт UV-развёртку меша. Если `high_poly` содержит только один элемент батча, он повторно используется для каждого элемента батча `low_poly`; элементы батча `low_poly` без граней пропускаются и заменяются полностью белым изображением, при этом регистрируется предупреждение. Если UV-координаты `low_poly` выходят за диапазон 0–1, они равномерно вписываются обратно в него; предупреждение регистрируется, когда обнаруживается тайловая раскладка / раскладка в стиле UDIM.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `occlusion` | Изображение ambient occlusion в оттенках серого со значениями в диапазоне [0,1] (белый = открытые участки, тёмный = углубления), по одному изображению на каждый элемент батча `low_poly`. Предназначено для входа `occlusion` узла Apply Texture To Mesh (упаковывается в ORM-карту / occlusionTexture). | IMAGE |
