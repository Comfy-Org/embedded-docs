# BakeAmbientOcclusion

Запекает карту амбиентного затенения из высокополигонального меша в UV-развёртку низкополигонального меша. На выходе получается изображение в градациях серого: белые тексели соответствуют открытым участкам, а тёмные — углублениям. Результат предназначен для входа `occlusion` узла Apply Texture To Mesh. Подключите низкополигональный меш с UV-развёрткой и высокополигональный меш, из которого он был получен децимацией.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | Низкополигональный меш с UV-развёрткой, в который выполняется запекание. Должен иметь UV-координаты; при их отсутствии узел выдаёт ошибку. | MESH | Да | - |
| `high_poly` | Высокополигональный меш, из которого был получен низкополигональный; используется как исходная геометрия для затенения. | MESH | Да | - |
| `resolution` | Разрешение текстуры в пикселях; каждый тексель получает значение затенения. По умолчанию: 1024. | INT | Да | от 64 до 8192 (шаг 64) |
| `samples` | Количество лучей на тексель. Больше — более гладкий результат, но медленнее. Увеличивайте при зернистости. По умолчанию: 64. | INT | Да | от 4 до 1024 (шаг 4) |
| `max_distance` | Длина луча как доля диагонали ограничивающей рамки. Меньше — более компактное, более локальное затенение. По умолчанию: 0.5. | FLOAT | Да | от 0.01 до 2.0 (шаг 0.01) |
| `strength` | Масштабирует затенение. При >1 затемняет, при <1 осветляет. По умолчанию: 1.0. | FLOAT | Да | от 0.0 до 2.0 (шаг 0.05) |
| `bias` | Отступ начала луча от поверхности, выраженный как доля диагонали ограничивающей рамки. Увеличьте, если даже на ровных поверхностях появляются тёмные пятна/дыры. По умолчанию: 0.01. | FLOAT | Да | от 0.0001 до 0.2 (шаг 0.0005) |

Примечание: `low_poly` должен иметь UV-координаты — этот узел никогда не выполняет UV-развёртку меша. Если `high_poly` содержит только один элемент батча, он повторно используется для каждого элемента батча `low_poly`; элементы батча `low_poly` без граней пропускаются и заменяются полностью белым изображением, при этом в журнал выводится предупреждение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `occlusion` | Изображение амбиентного затенения в градациях серого со значениями в [0,1] (белый — открытые участки, тёмный — углубления), по одному изображению на каждый элемент батча `low_poly`. Предназначено для входа `occlusion` узла Apply Texture To Mesh (упаковано в ORM-карту / occlusionTexture). | IMAGE |
