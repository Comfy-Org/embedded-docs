# 烘焙環境遮蔽

將高多邊形網格的環境光遮蔽貼圖烘焙到低多邊形網格的 UV 佈局中。輸出是一張灰階影像，其中白色紋素代表開放區域，深色紋素代表位於縫隙中的區域；此輸出供 Apply Texture To Mesh 節點的 `occlusion` 輸入使用。請連接已展開 UV 的低多邊形網格，以及其減面來源的高多邊形網格。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 要烘焙至其中的已展開 UV 低多邊形網格。必須具有 UV；若缺少 UV，節點會引發錯誤。 | MESH | 是 | - |
| `high_poly` | 低多邊形網格所源自的高多邊形網格（低多邊形網格由其減面而來），用作遮蔽的來源幾何。 | MESH | 是 | - |
| `resolution` | 以像素為單位的貼圖解析度；每個紋素會接收一個遮蔽值。預設值：1024。 | INT | 是 | 64 至 8192 （步進值：64） |
| `samples` | 每個紋素的射線數量。數值越高越平滑，但速度越慢。若出現顆粒感，請提高此值。預設值：64。 | INT | 是 | 4 至 1024 （步進值：4） |
| `max_distance` | 射線長度，以邊界框對角線的比例表示。數值越小，遮蔽越緊密、越局部。預設值：0.5。 | FLOAT | 是 | 0.01 至 2.0 （步進值：0.01） |
| `strength` | 縮放遮蔽效果。大於 1 會變暗，小於 1 會變亮。預設值：1.0。 | FLOAT | 是 | 0.0 至 2.0 （步進值：0.05） |
| `bias` | 射線原點抬離表面的距離，以邊界框對角線的比例表示。若平坦表面出現深色斑塊/孔洞，請提高此值。預設值：0.01。 | FLOAT | 是 | 0.0001 至 0.2 （步進值：0.0005） |

注意：`low_poly` 必須具有 UV 座標——此節點永遠不會展開網格。若 `high_poly` 只包含一個批次項目，則會重複用於 `low_poly` 的每個批次項目；`low_poly` 中沒有面的批次項目會被跳過，並替換為全白影像，同時記錄一則警告。若 `low_poly` 的 UV 超出 0-1 範圍，會將其均勻縮放回該範圍；當偵測到平鋪/UDIM 風格佈局時，會記錄一則警告。

## 輸出
