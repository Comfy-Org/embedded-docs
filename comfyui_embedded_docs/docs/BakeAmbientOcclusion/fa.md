# بیک‌کردن انسداد محیطی

یک نقشه انسداد محیطی را از یک مش پرپالیگان به درون چیدمان UV یک مش کم‌پالیگان بیک می‌کند. خروجی یک تصویر خاکستری است که در آن تکسِل‌های سفید باز و تکسِل‌های تیره درون شکاف‌ها قرار دارند؛ این تصویر برای ورودی occlusion گره Apply Texture To Mesh در نظر گرفته شده است. مش کم‌پالیگان دارای UV آنرپ‌شده و مش پرپالیگانی که از آن کاهش یافته است را متصل کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | مش کم‌پالیگان دارای UV آنرپ‌شده که باید درون آن بیک شود. باید UV داشته باشد؛ اگر UVها وجود نداشته باشند، گره خطا می‌دهد. | MESH | بله | - |
| `high_poly` | مش پرپالیگانی که مش کم‌پالیگان از آن کاهش یافته است و به‌عنوان هندسه مبدأ برای انسداد استفاده می‌شود. | MESH | بله | - |
| `resolution` | رزولوشن بافت بر حسب پیکسل؛ هر تکسِل یک مقدار انسداد دریافت می‌کند. پیش‌فرض: 1024. | INT | بله | 64 تا 8192 (گام 64) |
| `samples` | تعداد پرتوها به ازای هر تکسِل. بیشتر = هموارتر، کندتر. اگر دانه‌دانه است افزایش دهید. پیش‌فرض: 64. | INT | بله | 4 تا 1024 (گام 4) |
| `max_distance` | طول پرتو، به‌صورت کسری از قطر جعبه مرزی. کوچک‌تر = محدودتر، انسداد محلی‌تر. پیش‌فرض: 0.5. | FLOAT | بله | 0.01 تا 2.0 (گام 0.01) |
| `strength` | انسداد را مقیاس‌دهی می‌کند. بزرگ‌تر از 1 تیره‌تر می‌کند، کوچک‌تر از 1 روشن‌تر. پیش‌فرض: 1.0. | FLOAT | بله | 0.0 تا 2.0 (گام 0.05) |
| `bias` | بالا بردن مبدأ پرتو از سطح، به‌صورت کسری از قطر جعبه مرزی. اگر حتی سطوح صاف لکه‌ها/حفره‌های تیره نشان می‌دهند، افزایش دهید. پیش‌فرض: 0.01. | FLOAT | بله | 0.0001 تا 0.2 (گام 0.0005) |

نکته: `low_poly` باید مختصات UV داشته باشد — این گره هرگز مش را آنرپ نمی‌کند. اگر `high_poly` فقط شامل یک آیتم دسته باشد، برای هر آیتم دسته از `low_poly` دوباره استفاده می‌شود؛ آیتم‌های دسته‌ای `low_poly` که وجه ندارند نادیده گرفته شده و با یک تصویر تمام‌سفید جایگزین می‌شوند و هشداری ثبت می‌شود. اگر UVهای `low_poly` خارج از بازه 0-1 قرار بگیرند، به‌صورت یکنواخت دوباره درون آن برازش داده می‌شوند و زمانی که یک چیدمان کاشی‌کاری‌شده/به سبک UDIM تشخیص داده شود، هشداری ثبت می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `occlusion` | تصویر انسداد محیطی خاکستری با مقادیر در [0,1] (سفید = باز، تیره = شکاف‌ها)، یک تصویر به ازای هر آیتم دسته از `low_poly`. برای ورودی occlusion گره Apply Texture To Mesh در نظر گرفته شده است (بسته‌بندی‌شده در نقشه ORM / occlusionTexture). | IMAGE |
