# BakeAmbientOcclusion

یک نقشه انسداد محیطی (ambient occlusion) را از مش high-poly به چیدمان UV مش low-poly می‌پزد. خروجی یک تصویر خاکستری است که در آن تکسل‌های سفید باز و تکسل‌های تیره در شکاف‌ها هستند؛ این تصویر برای ورودی occlusion گره Apply Texture To Mesh در نظر گرفته شده است. مش low-poly با UV باز شده و مش high-poly که از آن کاهش یافته است را متصل کنید.

## ورودی‌ها

| Parameter | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | مش low-poly با UV باز شده که نقشه روی آن پخته می‌شود. باید دارای UV باشد؛ در صورت نبودن UV، گره خطا صادر می‌کند. | MESH | بله | - |
| `high_poly` | مش high-poly که low-poly از آن کاهش یافته است و به‌عنوان هندسه منبع برای انسداد استفاده می‌شود. | MESH | بله | - |
| `resolution` | وضوح بافت بر حسب پیکسل؛ هر تکسل یک مقدار انسداد دریافت می‌کند. پیش‌فرض: 1024. | INT | بله | 64 تا 8192 (step 64) |
| `samples` | تعداد پرتوها به ازای هر تکسل. بیشتر = صاف‌تر، کندتر. در صورت دانه‌دانه بودن، افزایش دهید. پیش‌فرض: 64. | INT | بله | 4 تا 1024 (step 4) |
| `max_distance` | طول پرتو، به‌صورت کسری از قطر جعبه محاط (bounding box). کوچک‌تر = جمع‌وجورتر، انسداد موضعی‌تر. پیش‌فرض: 0.5. | FLOAT | بله | 0.01 تا 2.0 (step 0.01) |
| `strength` | مقیاس انسداد را تنظیم می‌کند. بزرگ‌تر از 1 تیره‌تر، کوچک‌تر از 1 روشن‌تر. پیش‌فرض: 1.0. | FLOAT | بله | 0.0 تا 2.0 (step 0.05) |
| `bias` | فاصله نقطه شروع پرتو از سطح، به‌صورت کسری از قطر جعبه محاط. اگر سطوح صاف نیز لکه‌ها/حفره‌های تیره نشان دادند، آن را افزایش دهید. پیش‌فرض: 0.01. | FLOAT | بله | 0.0001 تا 0.2 (step 0.0005) |

توجه: `low_poly` باید مختصات UV داشته باشد — این گره هرگز مش را باز نمی‌کند (unwrap نمی‌کند). اگر `high_poly` فقط یک آیتم دسته‌ای داشته باشد، برای هر آیتم دسته‌ای از `low_poly` استفاده مجدد می‌شود؛ آیتم‌های دسته‌ای `low_poly` که هیچ وجهی ندارند نادیده گرفته شده و با یک تصویر تمام‌سفید جایگزین می‌شوند و یک هشدار ثبت می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `occlusion` | تصویر خاکستری انسداد محیطی با مقادیر در بازه [0,1] (سفید = باز، تیره = شکاف‌ها)، یک تصویر به ازای هر آیتم دسته‌ای از `low_poly`. برای ورودی occlusion گره Apply Texture To Mesh (که در نقشه ORM / occlusionTexture بسته‌بندی می‌شود) در نظر گرفته شده است. | IMAGE |
