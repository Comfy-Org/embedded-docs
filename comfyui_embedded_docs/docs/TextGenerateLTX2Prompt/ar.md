# TextGenerateLTX2Prompt

توسّع عقدة TextGenerateLTX2Prompt مطالبة مستخدم قصيرة إلى وصف مفصّل سمعي-بصري مناسب لتوليد فيديو باستخدام سلسلة نماذج الفيديو LTX-2. تضيف تلقائيًا تعليمات نظام خاصة بالمهمة، وترسل المطالبة المنسّقة إلى نموذج لغوي، وتعيد النص المُحسَّن. عند توفير صورة مرجعية اختيارية، تنتقل العقدة إلى وضع الصورة إلى الفيديو وتوسّع المطالبة انطلاقًا من محتوى تلك الصورة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لترميز النص. تتحقق العقدة من اسم المُرمِّز (tokenizer) الخاص بالنموذج لتحديد التعليمات المطابقة: النماذج المبنية على Gemma 4 تستخدم تنسيق LTX-2.4، بينما تستخدم النماذج الأخرى تنسيق LTX-2 (Gemma 3). | CLIP | نعم |  |
| `prompt` | إدخال النص الخام الذي يصف المشهد أو المفهوم المراد توسيعه إلى مطالبة مفصلة لتوليد الفيديو. | STRING | نعم |  |
| `max_length` | الحد الأقصى لعدد الرموز (tokens) المسموح للنموذج اللغوي بتوليدها. | INT | نعم |  |
| `sampling_mode` | استراتيجية أخذ العينات المستخدمة لاختيار الرمز التالي أثناء توليد النص. | COMBO | نعم | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | صورة إدخال اختيارية تُستخدم كالإطار الأول للفيديو. عند توفيرها، تنتقل العقدة إلى وضع الصورة إلى الفيديو وتستخدم مطالبة نظام توسّع مطالبة المستخدم بناءً على محتوى الصورة. | IMAGE | لا |  |
| `thinking` | عند التفعيل، يُوجَّه النموذج إلى التفكير قبل الإجابة. تُزال أي كتلة تفكير من المخرجات المُعادة (الافتراضي: False). | BOOLEAN | لا |  |
| `use_default_template` | عند التفعيل، تستخدم العقدة قالب المحادثة الافتراضي للتنسيق (الافتراضي: True). | BOOLEAN | لا |  |
| `video` | إدخال فيديو اختياري يمكن استخدامه كسياق إضافي للتوليد. | VIDEO | لا |  |
| `audio` | إدخال صوتي اختياري يمكن استخدامه كسياق إضافي للتوليد. | AUDIO | لا |  |

**ملاحظة:** يتغير سلوك العقدة بناءً على مدخلاتها:

- إذا تم توفير `image`، تُنسَّق المطالبة المولَّدة لمهمة الصورة إلى الفيديو باستخدام مطالبة نظام تصف كيفية توسيع المطالبة بناءً على محتوى الصورة. وإذا لم تُوفَّر صورة، يكون التنسيق لمهمة النص إلى الفيديو باستخدام مطالبة نظام توسّع المطالبة إلى وصف مفصّل لتوليد الفيديو.
- إذا كان اسم مُرمِّز CLIP يحتوي على "gemma4"، تستخدم العقدة مطالبات نظام LTX-2.4 وتنسيق محادثة Gemma 4. وإلا، فإنها تستخدم مطالبات نظام LTX-2 (Gemma 3) وتنسيق المحادثة.
- عند تفعيل `thinking` مع نموذج Gemma 4، يُفتح النموذج على قناة التفكير الخاصة به؛ وعند تعطيله، يُفتح النموذج مباشرة على قناة الإجابة النهائية. بالنسبة للنماذج غير Gemma 4، تُمرَّر `thinking` إلى خطوة التوليد الأساسية.
- إذا لم ينتج النموذج اللغوي أي نص قابل للاستخدام بعد إزالة كتل التفكير، تعيد العقدة `prompt` الأصلي بدلاً من ذلك.
