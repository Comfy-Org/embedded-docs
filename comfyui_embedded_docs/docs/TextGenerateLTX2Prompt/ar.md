# TextGenerateLTX2Prompt

تقوم عقدة `TextGenerateLTX2Prompt` بتوسيع موجه مستخدم قصير إلى وصف صوتي-بصري مفصل مناسب لتوليد الفيديو باستخدام سلسلة نماذج الفيديو LTX-2. تضيف تلقائيًا تعليمات نظام خاصة بالمهمة، وترسل الموجه المنسق إلى نموذج لغة، وتعيد النص المحسّن. عند توفير صورة مرجعية اختيارية، تتحول العقدة إلى وضع الصورة إلى فيديو وتوسع الموجه بدءًا من محتوى تلك الصورة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لترميز النص. تتحقق العقدة من اسم مُرمِّز النموذج لتحديد التعليمات المطابقة: النماذج المبنية على Gemma 4 تستخدم تنسيق LTX-2.4، بينما تستخدم النماذج الأخرى تنسيق LTX-2 (Gemma 3). | CLIP | نعم |  |
| `المطالبة` | النص الخام المُدخل الذي يصف المشهد أو المفهوم المطلوب توسيعه إلى موجه توليد فيديو مفصّل. | STRING | نعم |  |
| `الحد الأقصى للطول` | الحد الأقصى لعدد الرموز الممكِنة (tokens) التي يُسمح لنموذج اللغة بتوليدها. | INT | نعم |  |
| `وضع العينة` | استراتيجية أخذ العينات المستخدمة لاختيار الرمز المميز التالي أثناء توليد النص. | COMBO | نعم | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `الصورة` | صورة إدخال اختيارية تُستخدم كإطار أول للفيديو. عند توفيرها، تتحول العقدة إلى وضع الصورة إلى فيديو وتستخدم موجه نظام يعمل على توسيع موجه المستخدم بناءً على محتوى الصورة. | IMAGE | لا |  |
| `التفكير` | عند التفعيل، يُطلب من النموذج التفكير قبل الإجابة. تتم إزالة أي كتلة استدلال من المخرجات المعادة (الافتراضي: False). | BOOLEAN | لا |  |
| `استخدام القالب الافتراضي` | عند التفعيل، تستخدم العقدة قالب الدردشة الافتراضي للتنسيق (الافتراضي: True). | BOOLEAN | لا |  |
| `فيديو` | إدخال فيديو اختياري يمكن استخدامه كسياق إضافي للتوليد. | VIDEO | لا |  |
| `صوت` | إدخال صوتي اختياري يمكن استخدامه كسياق إضافي للتوليد. | AUDIO | لا |  |

**ملاحظة:** يعتمد سلوك العقدة على مدخلاتها:

- إذا تم توفير `image`، يتم تنسيق الموجه المُولَّد لمهمة صورة إلى فيديو باستخدام موجه نظام يصف كيفية توسيع الموجه بناءً على محتوى الصورة. إذا لم يتم توفير صورة، يكون التنسيق لمهمة نص إلى فيديو باستخدام موجه نظام يقوم بتوسيع الموجه إلى وصف مفصّل لتوليد الفيديو.
- إذا كان اسم مُرمِّز CLIP يحتوي على "gemma4"، تستخدم العقدة موجهات نظام LTX-2.4 وتنسيق دردشة Gemma 4. بخلاف ذلك، تستخدم موجهات نظام LTX-2 (Gemma 3) وتنسيق الدردشة.
- إذا لم يُنتج نموذج اللغة أي نص قابل للاستخدام بعد إزالة كتل الاستدلال، تعيد العقدة الموجه الأصلي `prompt` بدلاً من ذلك.
