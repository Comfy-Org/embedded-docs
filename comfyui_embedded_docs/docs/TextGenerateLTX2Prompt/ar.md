# TextGenerateLTX2Prompt

عقدة `TextGenerateLTX2Prompt` هي نسخة متخصصة من عقدة توليد النصوص. تأخذ نصًا من المستخدم وتقوم تلقائيًا بتنسيقه مع تعليمات نظام خاصة بـ LTX2 قبل إرساله إلى نموذج اللغة لتحسينه أو إكماله. يمكن أن تعمل العقدة في وضع النص فقط أو في وضع مرجع الصورة، وتقوم تلقائيًا بتكييف تنسيقها مع نموذج CLIP المتصل، باستخدام تنسيق LTX 2.4 لنماذج Gemma 4 وتنسيق LTX 2.0 لنماذج Gemma 3.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتشفير النص. يحدد النموذج تنسيق المطالبة: نماذج Gemma 4 تستخدم تنسيق LTX 2.4 ونماذج Gemma 3 تستخدم تنسيق LTX 2.0. | CLIP | نعم |  |
| `prompt` | نص الإدخال الخام من المستخدم الذي سيتم تحسينه أو إكماله. | STRING | نعم |  |
| `max_length` | الحد الأقصى لعدد الرموز (tokens) المسموح لنموذج اللغة بإنشائه. | INT | نعم |  |
| `sampling_mode` | استراتيجية أخذ العينات المستخدمة لاختيار الرمز التالي أثناء توليد النص. | COMBO | نعم | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | صورة إدخال اختيارية. عند توفيرها، تستخدم العقدة موجه نظام مختلف يتضمن سياق الصورة لتوليد فيديو من صورة. | IMAGE | لا |  |
| `thinking` | عند التمكين، سيخرج النموذج عملية تفكيره قبل الإجابة النهائية. تتم إزالة كتلة التفكير من النتيجة النهائية. | BOOLEAN | لا |  |
| `use_default_template` | عند التمكين، ستستخدم العقدة قالب المحادثة الافتراضي للتنسيق. | BOOLEAN | لا |  |
| `video` | إدخال فيديو اختياري يمكن استخدامه كسياق إضافي للتوليد. | VIDEO | لا |  |
| `audio` | إدخال صوتي اختياري يمكن استخدامه كسياق إضافي للتوليد. | AUDIO | لا |  |

**ملاحظات:** يختلف سلوك العقدة بناءً على وجود مدخل `image`. إذا تم توفير صورة، يتم تنسيق المطالبة لمهمة تحويل صورة إلى فيديو باستخدام موجه نظام يوسع المطالبة بناءً على محتوى الصورة. إذا لم يتم توفير صورة، يكون التنسيق لمهمة تحويل نص إلى فيديو باستخدام موجه نظام يوسع المطالبة إلى وصف تفصيلي لتوليد الفيديو.

يؤثر نموذج `clip` المتصل أيضًا على التنسيق: عندما يكون رمز CLIP نموذج Gemma 4، تستخدم العقدة تنسيق دردشة LTX 2.4 وموجهات النظام؛ وإلا فإنها تستخدم تنسيق دردشة Gemma 3 / LTX 2.0. بعد التوليد، تتم إزالة أي كتلة تفكير (مثل `<think>...</think>`) من المخرجات، وإذا كان النص الناتج فارغًا، يتم إرجاع `prompt` الأصلي.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |

| `output` | السلسلة النصية المحسّنة أو المكتملة التي يولدها نموذج اللغة، مع إزالة أي محتوى تفكير. إذا لم ينتج النموذج أي نص، يتم إرجاع المطالبة الأصلية. | STRING |
