# TextGenerateLTX2Prompt

הצומת TextGenerateLTX2Prompt מרחיב פרומפט משתמש קצר לתיאור מפורט ואורקולי, המתאים ליצירת וידאו עם סדרת מודלי הווידאו LTX-2. הוא מוסיף באופן אוטומטי הוראות מערכת ייעודיות למשימה, שולח את הפרומפט המעוצב למודל שפה, ומחזיר את הטקסט המשופר. כאשר מסופקת תמונת עזר אופציונלית, הצומת עובר למצב תמונה-לווידאו ומרחיב את הפרומפט החל מתוכן התמונה.

### פרמטרי דגימה (כאשר `sampling_mode` הוא `"on"`)

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `temperature` | קובע את מידת האקראיות של הפלט. ערכים נמוכים יותר הופכים את הפלט ליותר צפוי, וערכים גבוהים יותר הופכים אותו ליותר יצירתי (ברירת מחדל: 0.7). | FLOAT | כן | 0.01 עד 2.0 |
| `top_k` | מגביל את מאגר הדגימה ל-K הטוקנים הבאים הסבירים ביותר. ערך 0 מבטל את המסנן הזה (ברירת מחדל: 64). | INT | כן | 0 עד 1000 |
| `top_p` | משתמש בדגימת גרעין (nucleus sampling): שומר על הקבוצה הקטנה ביותר של טוקנים סבירים שההסתברות המצטברת שלהם מגיעה לערך הזה. (ברירת מחדל: 0.95) | FLOAT | כן | 0.0 עד 1.0 |
| `min_p` | מגדיר סף הסתברות מינימלי לטוקנים שיישקלו (ברירת מחדל: 0.05). | FLOAT | כן | 0.0 עד 1.0 |
| `repetition_penalty` | מטיל ענישה על טוקנים שכבר נוצרו כדי להפחית חזרות. ערך 1.0 אינו מטיל ענישה (ברירת מחדל: 1.05). | FLOAT | כן | 0.0 עד 5.0 |
| `seed` | מספר המשמש לאתחול מחולל המספרים האקראיים לקבלת תוצאות ניתנות לשחזור (ברירת מחדל: 0). | INT | כן | 0 עד 18446744073709551615 |
| `presence_penalty` | מטיל ענישה על טוקנים חדשים בהתאם לשאלה אם הם הופיעו בטקסט עד כה, ומעודד את המודל לדבר על נושאים חדשים (ברירת מחדל: 0.0). | FLOAT | לא | 0.0 עד 5.0 |

**הערה:** פרמטרי הדגימה שלעיל פעילים וגלויים בממשק הצומת רק כאשר `sampling_mode` מוגדר ל-`"on"`. כאשר הוא מוגדר ל-`"off"`, לא זמינים פרמטרי דגימה והצומת מייצר טקסט ללא דגימה אקראית.

**הערה:** התנהגות הצומת משתנה בהתאם לקלטים שלו:

- אם מסופק `image`, הפרומפט הנוצר מעוצב למשימת תמונה-ללווידאו תוך שימוש בפרומפט מערכת המתאר כיצד להרחיב את הפרומפט בהתאם לתוכן התמונה. אם לא מסופקת תמונה, העיצוב מיועד למשימת טקסט-ללווידאו תוך שימוש בפרומפט מערכת שמרחיב את הפרומפט לתיאור מפורט ליצירת וידאו.
- אם שם הטוקנייזר של CLIP מכיל "gemma4", הצומת משתמש בפרומפטי המערכת של LTX-2.4 ובפורמט הצ'אט של Gemma 4. אחרת, הוא משתמש בפרומפטי המערכת של LTX-2 (Gemma 3) ובפורמט הצ'אט שלהם.
- כאשר `thinking` מופעל עם מודל Gemma 4, המודל נפתח בערוץ החשיבה שלו; כאשר הוא מושבת, המודל נפתח ישירות בערוץ התשובה הסופית. עבור מודלים שאינם Gemma 4, `thinking` מועבר לשלב היצירה הבסיסי.
- `system_prompt` מחליף את ההוראות המובנות עבור המצב הנבחר (תמונה-ללווידאו או טקסט-ללווידאו); כאשר הוא ריק, נעשה שימוש בפרומפט המובנה.
- כל בלוק חשיבה מוחזר בפלט `thinking` במקום ב-`generated_text`.
- אם מודל השפה לא מייצר טקסט שמיש, הצומת מחזיר את `prompt` המקורי במקום.
