# TextGenerateLTX2Prompt

TextGenerateLTX2Prompt 節點會將簡短的使用者提示詞擴展為詳細的視聽描述，適用於搭配 LTX-2 系列影片模型生成影片。它會自動加入特定任務的系統指示，將格式化後的提示詞傳送給語言模型，並傳回增強後的文字。當提供選填的參考影像時，此節點會切換至圖像轉影片模式，並從該影像的內容開始擴展提示詞。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `clip` | 用於文字編碼的 CLIP 模型。此節點會檢查模型的 tokenizer 名稱以選擇相符的指示：基於 Gemma 4 的模型使用 LTX-2.4 格式，其他模型則使用 LTX-2 (Gemma 3) 格式。 | CLIP | 是 |  |
| `提示詞` | 原始文字輸入，描述要擴展為詳細影片生成提示詞的場景或概念。 | STRING | 是 |  |

**注意：** 此節點的行為會依其輸入而改變：

- 若提供 `image`，生成的提示詞會格式化為圖像轉影片任務，並使用系統提示詞來說明如何根據影像內容擴展提示詞。若未提供影像，則格式化為文字轉影片任務，並使用系統提示詞將提示詞擴展為詳細的影片生成描述。
- 若 CLIP tokenizer 的名稱包含 "gemma4"，此節點會使用 LTX-2.4 系統提示詞與 Gemma 4 聊天格式。否則，會使用 LTX-2 (Gemma 3) 系統提示詞與聊天格式。
- 當在 Gemma 4 模型上啟用 `thinking` 時，模型會以推理通道開啟；停用時，模型會直接以最終答案通道開啟。對於非 Gemma 4 模型，`thinking` 會傳遞至底層生成步驟。
- 若語言模型在移除推理區塊後未產生可用文字，此節點會改為傳回原始 `prompt`。
