# TextGenerateLTX2Prompt

TextGenerateLTX2Prompt 節點將使用者的簡短提示詞擴展為詳細的影音描述，適用於搭配 LTX-2 系列影片模型生成影片。它會自動加入任務特定的系統指示，將格式化後的提示詞傳送至語言模型，並回傳增強後的文字。當提供可選的參考影像時，節點會切換至「影像轉影片」模式，並從該影像的內容開始擴展提示詞。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |

| `提示詞` | 描述場景或概念的原始文字輸入，將被擴展為詳細的影片生成提示詞。 | STRING | 是 |  |
| `最大長度` | 語言模型允許生成的最大 token 數量。 | INT | 是 |  |

| `圖像` | 可選的輸入影像，用作影片的第一幀。提供此參數時，節點會切換至影像轉影片模式，並使用系統提示詞根據影像內容擴展使用者提示詞。 | IMAGE | 否 |  |

**注意：** 節點的行為會根據其輸入而改變：

- 若提供了 `image`，生成的提示詞會使用系統提示詞格式化為影像轉影片任務，該系統提示詞描述如何根據影像內容擴展提示詞。若未提供影像，則格式化為文字轉影片任務，使用系統提示詞將提示詞擴展為詳細的影片生成描述。
- 若 CLIP tokenizer 的名稱包含 "gemma4"，節點會使用 LTX-2.4 系統提示詞和 Gemma 4 對話格式。否則，使用 LTX-2 (Gemma 3) 系統提示詞和對話格式。
- 若語言模型在移除推理區塊後未產生可用文字，節點會改為回傳原始 `prompt`。
