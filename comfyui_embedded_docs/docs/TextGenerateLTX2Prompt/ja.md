# TextGenerateLTX2Prompt

TextGenerateLTX2Prompt ノードは、テキスト生成ノードの特殊版です。ユーザーのテキストプロンプトを受け取り、LTX2 専用のシステム指示で自動的にフォーマットしてから、言語モデルに送信して拡張または補完を行います。このノードは、テキストのみモードと画像参照モードの両方で動作し、接続された CLIP モデルに応じてフォーマットを自動的に適応させます。Gemma 4 モデルでは LTX 2.4 プロンプト形式を使用し、Gemma 3 モデルでは LTX 2.0 形式を使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | テキストエンコーディングに使用される CLIP モデル。このモデルがプロンプト形式を決定します。Gemma 4 モデルは LTX 2.4 形式を使用し、Gemma 3 モデルは LTX 2.0 形式を使用します。 | CLIP | はい |  |
| `prompt` | 拡張または補完されるユーザーからの生のテキスト入力。 | STRING | はい |  |
| `max_length` | 言語モデルが生成できる最大トークン数。 | INT | はい |  |
| `sampling_mode` | テキスト生成中に次のトークンを選択するために使用されるサンプリング戦略。 | COMBO | はい | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | オプションの入力画像。指定すると、ノードは画像コンテキストを含む別のシステムプロンプトを使用して、画像から動画への生成を行います。 | IMAGE | いいえ |  |
| `thinking` | 有効にすると、モデルは最終回答の前に推論プロセスを出力します。推論ブロックは最終結果から除去されます。 | BOOLEAN | いいえ |  |
| `use_default_template` | 有効にすると、ノードはフォーマットにデフォルトのチャットテンプレートを使用します。 | BOOLEAN | いいえ |  |
| `video` | 生成の追加コンテキストとして使用できるオプションのビデオ入力。 | VIDEO | いいえ |  |
| `audio` | 生成の追加コンテキストとして使用できるオプションのオーディオ入力。 | AUDIO | いいえ |  |

**注記：** ノードの動作は `image` 入力の有無によって変化します。画像が指定された場合、プロンプトは画像の内容に基づいてプロンプトを拡張するシステムプロンプトを使用して、画像から動画へのタスク用にフォーマットされます。画像が指定されない場合、フォーマットはテキストから動画へのタスク用であり、プロンプトを詳細な動画生成の説明に拡張するシステムプロンプトを使用します。

接続されている `clip` モデルもフォーマットに影響します。CLIP トークナイザーが Gemma 4 モデルの場合、ノードは LTX 2.4 チャット形式とシステムプロンプトを使用します。それ以外の場合は、Gemma 3 / LTX 2.0 チャット形式を使用します。生成後、推論ブロック（例：`<think>...</think>`）は出力から除去され、結果のテキストが空の場合は元の `prompt` が返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 言語モデルによって生成された拡張または補完済みのテキスト文字列。推論コンテンツは除去されています。モデルがテキストを生成しなかった場合は、元のプロンプトが返されます。 | STRING |
