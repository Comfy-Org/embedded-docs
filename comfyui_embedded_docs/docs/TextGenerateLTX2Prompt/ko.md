# TextGenerateLTX2Prompt

TextGenerateLTX2Prompt 노드는 텍스트 생성 노드의 특수 버전입니다. 사용자의 텍스트 프롬프트를 받아 LTX2 관련 시스템 지침으로 자동 형식화한 후, 언어 모델에 보내 향상 또는 완성을 수행합니다. 이 노드는 텍스트 전용 또는 이미지 참조 모드로 작동할 수 있으며, 연결된 CLIP 모델에 맞게 형식을 자동으로 조정합니다. Gemma 4 모델의 경우 LTX 2.4 프롬프트 형식을 사용하고, Gemma 3 모델의 경우 LTX 2.0 형식을 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 텍스트 인코딩에 사용되는 CLIP 모델입니다. 이 모델은 프롬프트 형식을 결정합니다. Gemma 4 모델은 LTX 2.4 형식을 사용하고, Gemma 3 모델은 LTX 2.0 형식을 사용합니다. | CLIP | 예 |  |
| `prompt` | 향상 또는 완성을 위해 사용자가 입력한 원시 텍스트입니다. | STRING | 예 |  |
| `max_length` | 언어 모델이 생성할 수 있는 최대 토큰 수입니다. | INT | 예 |  |
| `sampling_mode` | 텍스트 생성 중 다음 토큰을 선택하는 데 사용되는 샘플링 전략입니다. | COMBO | 예 | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | 선택적 입력 이미지입니다. 제공되면 노드는 이미지-투-비디오 생성을 위한 이미지 컨텍스트를 포함하는 다른 시스템 프롬프트를 사용합니다. | IMAGE | 아니요 |  |
| `thinking` | 활성화하면 모델이 최종 답변 전에 추론 과정을 출력합니다. 추론 블록은 최종 결과에서 제거됩니다. | BOOLEAN | 아니요 |  |
| `use_default_template` | 활성화하면 노드는 형식 지정에 기본 채팅 템플릿을 사용합니다. | BOOLEAN | 아니요 |  |
| `video` | 생성에 추가 컨텍스트로 사용할 수 있는 선택적 비디오 입력입니다. | VIDEO | 아니요 |  |
| `audio` | 생성에 추가 컨텍스트로 사용할 수 있는 선택적 오디오 입력입니다. | AUDIO | 아니요 |  |

**참고:** 노드의 동작은 `image` 입력 제공 여부에 따라 달라집니다. 이미지가 제공되면 프롬프트는 이미지 내용을 기반으로 프롬프트를 확장하는 시스템 프롬프트를 사용하여 이미지-투-비디오 작업용으로 형식화됩니다. 이미지가 제공되지 않으면 프롬프트를 상세한 비디오 생성 설명으로 확장하는 시스템 프롬프트를 사용하여 텍스트-투-비디오 작업용으로 형식화됩니다.

연결된 `clip` 모델도 형식에 영향을 줍니다. CLIP 토크나이저가 Gemma 4 모델인 경우 노드는 LTX 2.4 채팅 형식과 시스템 프롬프트를 사용하며, 그 외의 경우 Gemma 3 / LTX 2.0 채팅 형식을 사용합니다. 생성 후 `<think>...</think>`와 같은 추론 블록은 출력에서 제거되며, 결과 텍스트가 비어 있으면 원래 `prompt`가 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `output` | 언어 모델이 생성한 향상 또는 완성된 텍스트 문자열로, 추론 내용은 제거됩니다. 모델이 텍스트를 생성하지 않으면 원래 프롬프트가 반환됩니다. | STRING |
