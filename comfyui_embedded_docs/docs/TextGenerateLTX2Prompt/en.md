# Generate LTX2 Prompt

The TextGenerateLTX2Prompt node is a specialized version of a text generation node. It takes a user's text prompt and automatically formats it with LTX2-specific system instructions before sending it to a language model for enhancement or completion. The node can work in a text-only or an image-reference mode, and it automatically adapts its formatting to the connected CLIP model, using the LTX 2.4 prompt format for Gemma 4 models and the LTX 2.0 format for Gemma 3 models.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `clip` | The CLIP model used for text encoding. The model determines the prompt format: Gemma 4 models use the LTX 2.4 format and Gemma 3 models use the LTX 2.0 format. | CLIP | Yes |  |
| `prompt` | The raw text input from the user that will be enhanced or completed. | STRING | Yes |  |
| `max_length` | The maximum number of tokens the language model is allowed to generate. | INT | Yes |  |
| `sampling_mode` | The sampling strategy used to select the next token during text generation. | COMBO | Yes | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | An optional input image. When provided, the node uses a different system prompt that includes image context for image-to-video generation. | IMAGE | No |  |
| `thinking` | When enabled, the model will output its reasoning process before the final answer. The reasoning block is removed from the final result. | BOOLEAN | No |  |
| `use_default_template` | When enabled, the node will use the default chat template for formatting. | BOOLEAN | No |  |
| `video` | An optional video input that can be used as additional context for generation. | VIDEO | No |  |
| `audio` | An optional audio input that can be used as additional context for generation. | AUDIO | No |  |

**Notes:** The behavior of the node changes based on the presence of the `image` input. If an image is provided, the prompt is formatted for an image-to-video task using a system prompt that expands the prompt based on the image's content. If no image is provided, the formatting is for a text-to-video task using a system prompt that expands the prompt into a detailed video generation description.

The connected `clip` model also affects formatting: when the CLIP tokenizer is a Gemma 4 model, the node uses the LTX 2.4 chat format and system prompts; otherwise it uses the Gemma 3 / LTX 2.0 chat format. After generation, any reasoning block (for example `<think>...</think>`) is removed from the output, and if the resulting text is empty, the original `prompt` is returned.

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `output` | The enhanced or completed text string generated by the language model, with any reasoning content removed. If the model produces no text, the original prompt is returned. | STRING |
