# TextGenerateLTX2Prompt

Узел TextGenerateLTX2Prompt расширяет короткий пользовательский промпт до подробного аудиовизуального описания, подходящего для генерации видео с помощью серии видеомоделей LTX-2. Он автоматически добавляет системные инструкции, зависящие от задачи, отправляет отформатированный промпт языковой модели и возвращает улучшенный текст. Если подано необязательное эталонное изображение, узел переключается в режим «изображение-в-видео» и расширяет промпт, отталкиваясь от содержимого этого изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для текстового кодирования. Узел проверяет имя токенизатора модели, чтобы выбрать соответствующие инструкции: модели на основе Gemma 4 используют формат LTX-2.4, а другие модели — формат LTX-2 (Gemma 3). | CLIP | Да | - |
| `подсказка` | Исходный текстовый ввод, описывающий сцену или концепцию, которую нужно расширить до подробного промпта для генерации видео. | STRING | Да | - |
| `изображение` | Необязательное входное изображение, используемое в качестве первого кадра видео. Если оно предоставлено, узел переключается в режим «изображение-в-видео» и использует системный промпт, который расширяет пользовательский промпт на основе содержимого изображения. | IMAGE | Нет | - |
| `видео` | Необязательный входной видеофайл, используемый как дополнительный контекст. Передаётся языковой модели как пакет изображений; предполагается, что он имеет 24 FPS, и внутри субдискретизируется до 1 FPS. | IMAGE | Нет | - |
| `аудио` | Необязательный входной аудиофайл, который можно использовать как дополнительный контекст для генерации. | AUDIO | Нет | - |
| `максимальная длина` | Максимальное количество токенов, которое языковой модели разрешено сгенерировать (по умолчанию: 512). | INT | Да | от 1 до 32768 |
| `режим выборки` | Определяет, используется ли случайное сэмплирование во время генерации текста. При значении `"on"` становятся доступны параметры сэмплирования ниже; при `"off"` узел генерирует текст без случайного сэмплирования. | DYNAMIC_COMBO | Да | `"on"`<br>`"off"` |
| `мышление` | Если включено, модели даётся инструкция рассуждать перед ответом. Любой блок рассуждений удаляется из возвращаемого вывода (по умолчанию: False). | BOOLEAN | Нет | True/False |
| `use_default_template` | Если включено, узел использует шаблон чата по умолчанию для форматирования (по умолчанию: True). Дополнительная настройка. | BOOLEAN | Нет | True/False |
| `mtp` | Спекулятивное декодирование с использованием головки многотокенного предсказания чекпоинта. Не даёт эффекта без весов MTP. `"auto"` адаптирует глубину черновика, `"2"`–`"5"` фиксируют её. Выборка на выходе сохраняет корректное распределение, но отличается от выхода без MTP при том же seed (по умолчанию: `"auto"`). | COMBO | Нет | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"` |

### Параметры сэмплирования (когда `sampling_mode` имеет значение "on")

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `temperature` | Управляет случайностью вывода. Меньшие значения делают вывод более предсказуемым, большие — более творческим (по умолчанию: 0.7). | FLOAT | Да | от 0.01 до 2.0 |
| `top_k` | Ограничивает пул сэмплирования K наиболее вероятными следующими токенами. Значение 0 отключает этот фильтр (по умолчанию: 64). | INT | Да | от 0 до 1000 |
| `top_p` | Использует ядерное сэмплирование, ограничивая выбор токенами, совокупная вероятность которых меньше этого значения (по умолчанию: 0.95). | FLOAT | Да | от 0.0 до 1.0 |
| `min_p` | Задаёт минимальный порог вероятности, при котором токены учитываются (по умолчанию: 0.05). | FLOAT | Да | от 0.0 до 1.0 |
| `repetition_penalty` | Штрафует токены, которые уже были сгенерированы, чтобы уменьшить повторения. Значение 1.0 не применяет штраф (по умолчанию: 1.05). | FLOAT | Да | от 0.0 до 5.0 |
| `seed` | Число, используемое для инициализации генератора случайных чисел для воспроизводимых результатов (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `presence_penalty` | Штрафует новые токены в зависимости от того, появлялись ли они в тексте ранее, побуждая модель говорить о новых темах (по умолчанию: 0.0). | FLOAT | Нет | от 0.0 до 5.0 |

**Примечание:** Приведённые выше параметры сэмплирования активны и видимы в интерфейсе узла только тогда, когда `sampling_mode` установлен в `"on"`. Когда он установлен в `"off"`, параметры сэмплирования недоступны, и узел генерирует текст без случайного сэмплирования.

**Примечание:** Поведение узла зависит от его входов:

- Если предоставлено `image`, сгенерированный промпт форматируется для задачи «изображение-в-видео» с использованием системного промпта, который описывает, как расширить промпт на основе содержимого изображения. Если изображение не предоставлено, форматирование выполняется для задачи «текст-в-видео» с использованием системного промпта, который расширяет промпт до подробного описания для генерации видео.
- Если имя токенизатора CLIP содержит "gemma4", узел использует системные промпты LTX-2.4 и формат чата Gemma 4. В противном случае он использует системные промпты LTX-2 (Gemma 3) и формат чата.
- Когда `thinking` включён для модели Gemma 4, модель открывается на своём канале рассуждений; когда отключён — непосредственно на канале финального ответа. Для моделей, не относящихся к Gemma 4, `thinking` передаётся в базовый этап генерации.
- Если языковая модель не выдаёт пригодный текст после удаления блоков рассуждений, узел возвращает исходный `prompt`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `generated_text` | Улучшенный промпт для генерации видео, созданный языковой моделью, с удалёнными блоками рассуждений. Если результат пуст, возвращается исходный пользовательский промпт. | STRING |
