# TextGenerateLTX2Prompt

Узел **TextGenerateLTX2Prompt** — это специализированная версия узла генерации текста. Он принимает текстовый запрос пользователя и автоматически форматирует его с помощью системных инструкций, специфичных для LTX2, перед отправкой в языковую модель для улучшения или завершения. Узел может работать в режиме только текста или в режиме с референсным изображением; он автоматически адаптирует форматирование под подключённую модель CLIP, используя формат подсказок LTX 2.4 для моделей Gemma 4 и формат LTX 2.0 для моделей Gemma 3.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для кодирования текста. Модель определяет формат подсказки: модели Gemma 4 используют формат LTX 2.4, а модели Gemma 3 — формат LTX 2.0. | CLIP | Да |  |
| `prompt` | Исходный текстовый ввод пользователя, который будет улучшен или дополнен. | STRING | Да |  |
| `max_length` | Максимальное количество токенов, которое языковой модели разрешено сгенерировать. | INT | Да |  |
| `sampling_mode` | Стратегия выборки, используемая для выбора следующего токена во время генерации текста. | COMBO | Да | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | Необязательное входное изображение. Если оно задано, узел использует другой системный промпт, включающий контекст изображения для генерации видео из изображения. | IMAGE | Нет |  |
| `thinking` | Если включено, модель выводит свой процесс рассуждения перед окончательным ответом. Блок рассуждения удаляется из конечного результата. | BOOLEAN | Нет |  |
| `use_default_template` | Если включено, узел использует стандартный шаблон чата для форматирования. | BOOLEAN | Нет |  |
| `video` | Необязательное входное видео, которое может использоваться как дополнительный контекст для генерации. | VIDEO | Нет |  |
| `audio` | Необязательное входное аудио, которое может использоваться как дополнительный контекст для генерации. | AUDIO | Нет |  |

**Примечания:** Поведение узла изменяется в зависимости от наличия входного параметра `image`. Если изображение предоставлено, подсказка форматируется для задачи преобразования изображения в видео с использованием системного промпта, который расширяет подсказку на основе содержимого изображения. Если изображение не предоставлено, форматирование выполняется для задачи преобразования текста в видео с использованием системного промпта, который расширяет подсказку в подробное описание для генерации видео.

Подключённая модель `clip` также влияет на форматирование: если токенизатор CLIP относится к модели Gemma 4, узел использует чат-формат и системные промпты LTX 2.4; в противном случае используется чат-формат Gemma 3 / LTX 2.0. После генерации любые блоки рассуждений (например, `<think>...</think>`) удаляются из выходных данных, и если результирующий текст пуст, возвращается исходный `prompt`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Улучшенная или завершённая текстовая строка, сгенерированная языковой моделью, с удалённым содержимым рассуждений. Если модель не создала текст, возвращается исходный промпт. | STRING |
