# TextGenerateLTX2Prompt

Узел TextGenerateLTX2Prompt расширяет короткий пользовательский запрос в подробное аудиовизуальное описание, подходящее для генерации видео с помощью серии видеомоделей LTX-2. Он автоматически добавляет специфичные для задачи системные инструкции, отправляет отформатированный запрос языковой модели и возвращает расширенный текст. Если указано необязательное эталонное изображение, узел переключается в режим «изображение в видео» и расширяет запрос, начиная с содержимого этого изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для кодирования текста. Узел проверяет имя токенизатора модели, чтобы выбрать соответствующие инструкции: модели на основе Gemma 4 используют формат LTX-2.4, а другие модели используют формат LTX-2 (Gemma 3). | CLIP | Да |  |
| `подсказка` | Исходный текст, описывающий сцену или концепцию, которую необходимо расширить в подробный запрос для генерации видео. | STRING | Да |  |
| `максимальная длина` | Максимальное количество токенов, которое может сгенерировать языковая модель. | INT | Да |  |
| `режим выборки` | Стратегия сэмплирования, используемая для выбора следующего токена во время генерации текста. | COMBO | Да | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `изображение` | Необязательное входное изображение, используемое в качестве первого кадра видео. Если оно задано, узел переключается в режим «изображение в видео» и использует системный запрос, который расширяет пользовательский запрос на основе содержимого изображения. | IMAGE | Нет |  |
| `мышление` | Если включено, модели предписывается рассуждать перед ответом. Любой блок рассуждений удаляется из возвращаемого результата (по умолчанию: False). | BOOLEAN | Нет |  |
| `use_default_template` | Если включено, узел использует шаблон чата по умолчанию для форматирования (по умолчанию: True). | BOOLEAN | Нет |  |
| `видео` | Необязательное входное видео, которое может использоваться в качестве дополнительного контекста для генерации. | VIDEO | Нет |  |
| `аудио` | Необязательный входной аудиопоток, который может использоваться в качестве дополнительного контекста для генерации. | AUDIO | Нет |  |

**Примечание:** Поведение узла изменяется в зависимости от его входов:

- Если указано `image`, сгенерированный запрос форматируется для задачи «изображение в видео» с использованием системного запроса, который описывает, как расширить пользовательский запрос на основе содержимого изображения. Если изображение не указано, форматирование выполняется для задачи «текст в видео» с использованием системного запроса, который расширяет пользовательский запрос в подробное описание для генерации видео.
- Если имя токенизатора CLIP содержит «gemma4», узел использует системные запросы LTX-2.4 и чат-формат Gemma 4. В противном случае используются системные запросы LTX-2 (Gemma 3) и соответствующий чат-формат.
- Если языковая модель не создает пригодного для использования текста после удаления блоков рассуждений, узел вместо этого возвращает исходный `prompt`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `сгенерированный текст` | Расширенный запрос для генерации видео, созданный языковой моделью, с удалённым блоком рассуждений. Если результат пуст, возвращается исходный пользовательский запрос. | STRING |
