# تولید متن LTX2Prompt

گره TextGenerateLTX2Prompt یک درخواست کوتاه کاربر را به توصیفی دقیق و سمعی-بصری گسترش می‌دهد که برای تولید ویدیو با سری مدل‌های ویدیویی LTX-2 مناسب است. این گره به‌طور خودکار دستورالعمل‌های سیستمی مخصوص وظیفه را اضافه می‌کند، درخواست فرمت‌شده را به یک مدل زبانی ارسال می‌کند و متن ارتقایافته را برمی‌گرداند. هنگامی که یک تصویر مرجع اختیاری ارائه شود، گره به حالت تصویر-به-ویدیو تغییر می‌کند و درخواست را از محتوای آن تصویر گسترش می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. گره نام توکنایزر مدل را بررسی می‌کند تا دستورالعمل‌های مطابق را انتخاب کند: مدل‌های مبتنی بر Gemma 4 از قالب LTX-2.4 استفاده می‌کنند، در حالی که سایر مدل‌ها از قالب LTX-2 (Gemma 3) استفاده می‌کنند. | CLIP | بله |  |
| `پرامپت` | ورودی متن خام که صحنه یا مفهوم را توصیف می‌کند تا به یک درخواست تولید ویدیوی دقیق گسترش یابد. | STRING | بله |  |
| `حداکثر طول` | حداکثر تعداد توکن‌هایی که مدل زبانی مجاز به تولید آن‌ها است. | INT | بله |  |
| `حالت نمونه‌گیری` | راهبرد نمونه‌برداری مورد استفاده برای انتخاب توکن بعدی در حین تولید متن. | COMBO | بله | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `تصویر` | یک تصویر ورودی اختیاری که به عنوان فریم اول ویدیو استفاده می‌شود. در صورت ارائه، گره به حالت تصویر-به-ویدیو تغییر می‌کند و از یک درخواست سیستمی استفاده می‌کند که درخواست کاربر را بر اساس محتوای تصویر گسترش می‌دهد. | IMAGE | خیر |  |
| `تفکر` | هنگامی که فعال باشد، به مدل دستور داده می‌شود که قبل از پاسخ‌گویی استدلال کند. هر بلوک استدلالی از خروجی برگشتی حذف می‌شود (پیش‌فرض: False). | BOOLEAN | خیر |  |
| `use_default_template` | هنگامی که فعال باشد، گره از قالب چت پیش‌فرض برای قالب‌بندی استفاده می‌کند (پیش‌فرض: True). | BOOLEAN | خیر |  |
| `ویدیو` | یک ورودی ویدیویی اختیاری که می‌تواند به عنوان زمینه اضافی برای تولید استفاده شود. | VIDEO | خیر |  |
| `صدا` | یک ورودی صوتی اختیاری که می‌تواند به عنوان زمینه اضافی برای تولید استفاده شود. | AUDIO | خیر |  |

**نکته:** رفتار گره بر اساس ورودی‌های آن تغییر می‌کند:

- اگر یک `image` ارائه شود، درخواست تولیدشده برای وظیفه تصویر-به-ویدیو با استفاده از یک درخواست سیستمی فرمت می‌شود که نحوه گسترش درخواست را بر اساس محتوای تصویر توصیف می‌کند. اگر تصویری ارائه نشود، قالب‌بندی برای وظیفه متن-به-ویدیو با استفاده از یک درخواست سیستمی انجام می‌شود که درخواست را به توصیفی دقیق از تولید ویدیو گسترش می‌دهد.
- اگر نام توکنایزر CLIP شامل "gemma4" باشد، گره از درخواست‌های سیستمی LTX-2.4 و قالب چت Gemma 4 استفاده می‌کند. در غیر این صورت، از درخواست‌های سیستمی و قالب چت LTX-2 (Gemma 3) استفاده می‌کند.
- اگر مدل زبانی پس از حذف بلوک‌های استدلالی متنی قابل استفاده تولید نکند، گره در عوض `prompt` اصلی را برمی‌گرداند.
