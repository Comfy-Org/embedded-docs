# تولید متن LTX2Prompt

گره TextGenerateLTX2Prompt نسخه‌ای تخصصی از یک گره تولید متن است. پرامت متنی کاربر را دریافت کرده و به‌صورت خودکار با دستورالعمل‌های سیستمی مخصوص LTX2 قالب‌بندی می‌کند و سپس آن را برای بهبود یا تکمیل به یک مدل زبانی می‌فرستد. این گره می‌تواند در حالت متن‌محور یا حالت مرجع تصویر کار کند و به‌طور خودکار قالب‌بندی خود را با مدل CLIP متصل تطبیق می‌دهد؛ به‌طوری که برای مدل‌های Gemma 4 از قالب پرامت LTX 2.4 و برای مدل‌های Gemma 3 از قالب LTX 2.0 استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. مدل تعیین‌کننده قالب پرامت است: مدل‌های Gemma 4 از قالب LTX 2.4 و مدل‌های Gemma 3 از قالب LTX 2.0 استفاده می‌کنند. | CLIP | بله |  |
| `prompt` | متن خام ورودی از کاربر که قرار است بهبود یابد یا تکمیل شود. | STRING | بله |  |
| `max_length` | حداکثر تعداد توکن‌هایی که مدل زبانی مجاز به تولید آن است. | INT | بله |  |
| `sampling_mode` | راهبرد نمونه‌برداری مورد استفاده برای انتخاب توکن بعدی در طول تولید متن. | COMBO | بله | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | یک تصویر ورودی اختیاری. وقتی ارائه شود، گره از یک پرامت سیستمی متفاوت استفاده می‌کند که زمینه تصویر را برای تولید ویدیو از تصویر شامل می‌شود. | IMAGE | خیر |  |
| `thinking` | در صورت فعال بودن، مدل فرایند استدلال خود را قبل از پاسخ نهایی خروجی می‌دهد. بلوک استدلال از نتیجه نهایی حذف می‌شود. | BOOLEAN | خیر |  |
| `use_default_template` | در صورت فعال بودن، گره از قالب چت پیش‌فرض برای قالب‌بندی استفاده می‌کند. | BOOLEAN | خیر |  |
| `video` | یک ورودی ویدیویی اختیاری که می‌تواند به عنوان زمینه اضافی برای تولید استفاده شود. | VIDEO | خیر |  |
| `audio` | یک ورودی صوتی اختیاری که می‌تواند به عنوان زمینه اضافی برای تولید استفاده شود. | AUDIO | خیر |  |

**نکات:** رفتار گره بر اساس وجود ورودی `image` تغییر می‌کند. اگر تصویری ارائه شود، پرامت برای یک وظیفه تبدیل تصویر به ویدیو با استفاده از یک پرامت سیستمی قالب‌بندی می‌شود که پرامت را بر اساس محتوای تصویر گسترش می‌دهد. اگر تصویری ارائه نشود، قالب‌بندی برای یک وظیفه تبدیل متن به ویدیو با استفاده از یک پرامت سیستمی است که پرامت را به یک توصیف دقیق تولید ویدیو گسترش می‌دهد.

مدل `clip` متصل نیز بر قالب‌بندی تأثیر می‌گذارد: وقتی توکنایزر CLIP یک مدل Gemma 4 باشد، گره از قالب چت و پرامت‌های سیستمی LTX 2.4 استفاده می‌کند؛ در غیر این صورت از قالب چت Gemma 3 / LTX 2.0 استفاده می‌کند. پس از تولید، هر بلوک استدلال (مثلاً `<think>...</think>`) از خروجی حذف می‌شود و اگر متن حاصل خالی باشد، `prompt` اصلی بازگردانده می‌شود.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
| --- | --- | --- |
| `output` | رشته متنی بهبودیافته یا تکمیل‌شده تولیدشده توسط مدل زبانی، با حذف هرگونه محتوای استدلالی. اگر مدل متنی تولید نکند، پرامت اصلی بازگردانده می‌شود. | STRING |
