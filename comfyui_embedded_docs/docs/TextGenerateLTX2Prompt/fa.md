# تولید متن LTX2Prompt

### TextGenerateLTX2Prompt

گره TextGenerateLTX2Prompt یک پرامپت کوتاه کاربر را به توصیفی دقیق و صوتی‑تصویری گسترش می‌دهد که برای تولید ویدیو با مجموعه مدل‌های ویدیویی LTX-2 مناسب است. این گره به‌طور خودکار دستورالعمل‌های سیستمی مخصوص هر وظیفه را اضافه می‌کند، پرامپت قالب‌بندی‌شده را به یک مدل زبانی می‌فرستد و متن بهبودیافته را برمی‌گرداند. هنگامی که یک تصویر مرجع اختیاری ارائه شود، گره به حالت تصویر به ویدیو تغییر می‌کند و پرامپت را با شروع از محتوای آن تصویر گسترش می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. گره نام توکن‌ساز مدل را بررسی می‌کند تا دستورالعمل‌های متناظر را انتخاب کند: مدل‌های مبتنی بر Gemma 4 از قالب LTX-2.4 استفاده می‌کنند، در حالی که سایر مدل‌ها از قالب LTX-2 (Gemma 3) استفاده می‌کنند. | CLIP | بله |  |
| `prompt` | ورودی متنی خام که صحنه یا مفهوم مورد نظر برای گسترش به یک پرامپت دقیق تولید ویدیو را توصیف می‌کند. | STRING | بله |  |
| `max_length` | حداکثر تعداد توکن‌هایی که مدل زبانی مجاز است تولید کند. | INT | بله |  |
| `sampling_mode` | راهبرد نمونه‌گیری مورد استفاده برای انتخاب توکن بعدی در طول تولید متن. | COMBO | بله | `"greedy"`<br>`"top_k"`<br>`"top_p"`<br>`"temperature"` |
| `image` | یک تصویر ورودی اختیاری که به‌عنوان فریم اول ویدیو استفاده می‌شود. هنگامی که ارائه شود، گره به حالت تصویر به ویدیو تغییر می‌کند و از یک پرامپت سیستمی استفاده می‌کند که پرامپت کاربر را بر اساس محتوای تصویر گسترش می‌دهد. | IMAGE | خیر |  |
| `thinking` | وقتی فعال باشد، به مدل دستور داده می‌شود پیش از پاسخ‌دادن استدلال کند. هر بلوک استدلال از خروجی برگشتی حذف می‌شود (پیش‌فرض: False). | BOOLEAN | خیر |  |
| `use_default_template` | وقتی فعال باشد، گره از قالب گفتگوی پیش‌فرض برای قالب‌بندی استفاده می‌کند (پیش‌فرض: True). | BOOLEAN | خیر |  |
| `video` | یک ورودی ویدیوی اختیاری که می‌تواند به‌عنوان زمینه اضافی برای تولید استفاده شود. | VIDEO | خیر |  |
| `audio` | یک ورودی صوتی اختیاری که می‌تواند به‌عنوان زمینه اضافی برای تولید استفاده شود. | AUDIO | خیر |  |

**توجه:** رفتار گره بر اساس ورودی‌هایش تغییر می‌کند:

- اگر `image` ارائه شود، پرامپت تولیدشده برای یک وظیفه تصویر به ویدیو قالب‌بندی می‌شود، با استفاده از یک پرامپت سیستمی که نحوه گسترش پرامپت بر اساس محتوای تصویر را توصیف می‌کند. اگر تصویری ارائه نشود، قالب‌بندی برای یک وظیفه متن به ویدیو است، با استفاده از یک پرامپت سیستمی که پرامپت را به یک توصیف دقیق تولید ویدیو گسترش می‌دهد.
- اگر نام توکن‌ساز CLIP شامل `"gemma4"` باشد، گره از پرامپت‌های سیستمی LTX-2.4 و قالب گفتگوی Gemma 4 استفاده می‌کند. در غیر این صورت، از پرامپت‌های سیستمی LTX-2 (Gemma 3) و قالب گفتگو استفاده می‌کند.
- وقتی `thinking` با یک مدل Gemma 4 فعال باشد، مدل روی کانال استدلال خود باز می‌شود؛ وقتی غیرفعال باشد، مدل مستقیماً روی کانال پاسخ نهایی باز می‌شود. برای مدل‌های غیر Gemma 4، `thinking` به مرحله تولید زیرین منتقل می‌شود.
- اگر مدل زبانی پس از حذف بلوک‌های استدلال هیچ متن قابل استفاده‌ای تولید نکند، گره `prompt` اصلی را برمی‌گرداند.
