# تولید متن LTX2Prompt

گره TextGenerateLTX2Prompt یک پرامپت کوتاه کاربر را به یک توصیف مفصل و صوتی‑تصویری گسترش می‌دهد که برای تولید ویدئو با مجموعه مدل‌های ویدئویی LTX-2 مناسب است. این گره به‌طور خودکار دستورالعمل‌های سیستمی مخصوص وظیفه را اضافه می‌کند، پرامپت قالب‌بندی‌شده را به یک مدل زبانی می‌فرستد و متن بهبودیافته را برمی‌گرداند. هنگامی که یک تصویر مرجع اختیاری ارائه شود، گره به حالت تصویر‑به‑ویدئو تغییر می‌کند و پرامپت را با شروع از محتوای آن تصویر گسترش می‌دهد.

## ورودی‌ها

### ورودی‌های مشترک

| `پرامپت` | ورودی متنی خام که صحنه یا مفهوم موردنظر برای گسترش به یک پرامپت مفصل تولید ویدئو را توصیف می‌کند. | STRING | بله | - |
| `تصویر` | تصویر ورودی اختیاری که به‌عنوان فریم اول ویدئو استفاده می‌شود. در صورت ارائه، گره به حالت تصویر‑به‑ویدئو تغییر می‌کند و از یک پرامپت سیستمی استفاده می‌کند که پرامپت کاربر را بر اساس محتوای تصویر گسترش می‌دهد. | IMAGE | خیر | - |
| `ویدیو` | ورودی ویدئویی اختیاری که به‌عنوان زمینه اضافی استفاده می‌شود. به‌صورت دسته‌ای تصویر به مدل زبانی داده می‌شود؛ فرض می‌شود 24 FPS است و به‌صورت داخلی به 1 FPS نمونه‌برداری کاهشی می‌شود. | IMAGE | خیر | - |
| `صدا` | ورودی صوتی اختیاری که می‌تواند به‌عنوان زمینه اضافی برای تولید استفاده شود. | AUDIO | خیر | - |
| `حداکثر طول` | حداکثر تعداد توکن‌هایی که مدل زبانی مجاز به تولید آن است (پیش‌فرض: 512). | INT | بله | 1 تا 32768 |
| `حالت نمونه‌گیری` | کنترل می‌کند که آیا در طول تولید متن از نمونه‌گیری تصادفی استفاده شود یا نه. وقتی روی `"on"` تنظیم شود، پارامترهای نمونه‌گیری زیر در دسترس قرار می‌گیرند؛ با `"off"` گره متن را بدون نمونه‌گیری تصادفی تولید می‌کند. | DYNAMIC_COMBO | بله | `"on"`<br>`"off"` |
| `تفکر` | وقتی فعال باشد، به مدل دستور داده می‌شود پیش از پاسخ‌دادن استدلال کند. هر بلوک استدلال از خروجی برگشتی حذف می‌شود (پیش‌فرض: False). | BOOLEAN | خیر | True/False |
| `use_default_template` | وقتی فعال باشد، گره از قالب چت پیش‌فرض برای قالب‌بندی استفاده می‌کند (پیش‌فرض: True). تنظیم پیشرفته. | BOOLEAN | خیر | True/False |
| `mtp` | رمزگشایی گمانه‌زنانه (speculative decoding) با سر پیش‌بینی چندتوکنی چک‌پوینت. بدون وزن‌های MTP بی‌اثر است. `"auto"` عمق پیش‌نویس را تطبیق می‌دهد، `"2"` تا `"5"` آن را تثبیت می‌کند. خروجی نمونه‌گیری‌شده توزیع درست خود را حفظ می‌کند اما برای همان seed با خروجی غیر‑MTP متفاوت است (پیش‌فرض: `"auto"`). | COMBO | خیر | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"` |

### پارامترهای نمونه‌گیری (وقتی `sampling_mode` روی "on" است)

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `temperature` | میزان تصادفی‌بودن خروجی را کنترل می‌کند. مقادیر پایین‌تر خروجی را قابل‌پیش‌بینی‌تر و مقادیر بالاتر آن را خلاقانه‌تر می‌کنند (پیش‌فرض: 0.7). | FLOAT | بله | 0.01 تا 2.0 |
| `top_k` | استخر نمونه‌گیری را به K توکن بعدی محتمل‌تر محدود می‌کند. مقدار 0 این فیلتر را غیرفعال می‌کند (پیش‌فرض: 64). | INT | بله | 0 تا 1000 |
| `top_p` | از نمونه‌گیری هسته‌ای (nucleus sampling) استفاده می‌کند و انتخاب‌ها را به توکن‌هایی محدود می‌کند که احتمال تجمعی آن‌ها کمتر از این مقدار است (پیش‌فرض: 0.95). | FLOAT | بله | 0.0 تا 1.0 |
| `min_p` | حداقل آستانه احتمال را برای در نظر گرفتن توکن‌ها تعیین می‌کند (پیش‌فرض: 0.05). | FLOAT | بله | 0.0 تا 1.0 |
| `repetition_penalty` | به توکن‌هایی که قبلاً تولید شده‌اند جریمه اعمال می‌کند تا تکرار کاهش یابد. مقدار 1.0 هیچ جریمه‌ای اعمال نمی‌کند (پیش‌فرض: 1.05). | FLOAT | بله | 0.0 تا 5.0 |
| `seed` | عددی که برای مقداردهی اولیه مولد اعداد تصادفی جهت نتایج قابل‌تکرار استفاده می‌شود (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `presence_penalty` | توکن‌های جدید را بر اساس اینکه تاکنون در متن ظاهر شده‌اند یا نه جریمه می‌کند و مدل را به صحبت درباره موضوعات جدید تشویق می‌کند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 تا 5.0 |

**توجه:** پارامترهای نمونه‌گیری بالا فقط زمانی در رابط گره فعال و قابل مشاهده هستند که `sampling_mode` روی "on" تنظیم شده باشد. وقتی روی "off" تنظیم شود، هیچ پارامتر نمونه‌گیری در دسترس نیست و گره متن را بدون نمونه‌گیری تصادفی تولید می‌کند.

**توجه:** رفتار گره بر اساس ورودی‌هایش تغییر می‌کند:

- اگر یک `image` ارائه شود، پرامپت تولیدشده برای وظیفه تصویر‑به‑ویدئو قالب‌بندی می‌شود و از یک پرامپت سیستمی استفاده می‌کند که نحوه گسترش پرامپت بر اساس محتوای تصویر را توصیف می‌کند. اگر تصویری ارائه نشود، قالب‌بندی برای وظیفه متن‑به‑ویدئو است و از یک پرامپت سیستمی استفاده می‌کند که پرامپت را به یک توصیف مفصل تولید ویدئو گسترش می‌دهد.
- اگر نام توکن‌ساز CLIP شامل "gemma4" باشد، گره از پرامپت‌های سیستمی LTX-2.4 و قالب چت Gemma 4 استفاده می‌کند. در غیر این صورت، از پرامپت‌های سیستمی LTX-2 (Gemma 3) و قالب چت آن استفاده می‌کند.
- وقتی `thinking` با یک مدل Gemma 4 فعال باشد، مدل روی کانال استدلال خود باز می‌شود؛ وقتی غیرفعال باشد، مدل مستقیماً روی کانال پاسخ نهایی باز می‌شود. برای مدل‌های غیر‑Gemma 4، `thinking` به مرحله تولید زیرین منتقل می‌شود.
- اگر مدل زبانی پس از حذف بلوک‌های استدلال هیچ متن قابل‌استفاده‌ای تولید نکند، گره به‌جای آن `prompt` اصلی را برمی‌گرداند.
