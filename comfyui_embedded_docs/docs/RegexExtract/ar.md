# استخراج التعبير النمطي

تقوم عقدة RegexExtract بالبحث عن أنماط في النص باستخدام التعبيرات النمطية. يمكنها العثور على أول تطابق، أو جميع التطابقات، أو مجموعات محددة من التطابقات، أو جميع المجموعات عبر تطابقات متعددة. تدعم العقدة عدة علامات تعبير نمطي للتحكم في حساسية حالة الأحرف، والمطابقة متعددة الأسطر، وسلوك النقطة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `السلسلة النصية` | النص المدخل للبحث عن الأنماط | STRING | نعم | - |
| `نمط التعبير النمطي` | نمط التعبير النمطي للبحث عنه | STRING | نعم | - |
| `الوضع` | يحدد وضع الاستخراج أجزاء التطابقات التي سيتم إرجاعها (الافتراضي: "أول تطابق") | COMBO | نعم | "أول تطابق"<br>"جميع التطابقات"<br>"المجموعة الأولى"<br>"جميع المجموعات" |
| `غير حساس لحالة الأحرف` | تجاهل حالة الأحرف عند المطابقة (الافتراضي: صحيح) | BOOLEAN | لا | - |
| `متعدد الأسطر` | معالجة النص كأسطر متعددة (الافتراضي: خطأ) | BOOLEAN | لا | - |
| `dotall` | مطابقة النقطة (.) لأسطر جديدة (الافتراضي: خطأ) | BOOLEAN | لا | - |
| `مؤشر المجموعة` | فهرس مجموعة الالتقاط لاستخراجها عند استخدام أوضاع المجموعة (الافتراضي: 1) | INT | لا | 0-100 |

**ملاحظة:** عند استخدام وضعي "المجموعة الأولى" أو "جميع المجموعات"، يحدد معامل `group_index` مجموعة الالتقاط المراد استخراجها. تمثل المجموعة 0 التطابق بأكمله، بينما تمثل المجموعات 1+ مجموعات الالتقاط المرقمة في نمط التعبير النمطي الخاص بك.

| --- | --- | --- |
