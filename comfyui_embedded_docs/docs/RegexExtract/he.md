# חילוץ טקסט

צומת RegexExtract מחפש תבניות בטקסט באמצעות ביטויים רגולריים. הוא יכול למצוא את ההתאמה הראשונה, את כל ההתאמות, קבוצות ספציפיות מתוך התאמות, או את כל הקבוצות על פני התאמות מרובות. הצומת תומך בדגלי regex שונים עבור רגישות לאותיות רישיות, התאמה מרובת שורות, והתנהגות dotall.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | טקסט הקלט לחיפוש תבניות | STRING | כן | - |
| `regex_pattern` | תבנית הביטוי הרגולרי לחיפוש | STRING | כן | - |
| `mode` | מצב החילוץ קובע איזה חלקים מההתאמות מוחזרים (ברירת מחדל: "First Match") | COMBO | כן | "First Match"<br>"All Matches"<br>"First Group"<br>"All Groups" |
| `case_insensitive` | האם להתעלם מאותיות רישיות בעת ההתאמה (ברירת מחדל: True) | BOOLEAN | לא | - |
| `multiline` | האם להתייחס למחרוזת כמרובת שורות (ברירת מחדל: False) | BOOLEAN | לא | - |
| `dotall` | האם הנקודה (.) מתאימה לשורות חדשות (ברירת מחדל: False) | BOOLEAN | לא | - |
| `group_index` | אינדקס קבוצת הלכידה לחילוץ בעת שימוש במצבי קבוצה (ברירת מחדל: 1) | INT | לא | 0-100 |

**הערה:** כאשר משתמשים במצבים "First Group" או "All Groups", הפרמטר `group_index` מגדיר איזו קבוצת לכידה לחלץ. קבוצה 0 מייצגת את ההתאמה כולה, בעוד שקבוצות 1+ מייצגות את קבוצות הלכידה הממוספרות בתבנית הרגולרית שלך.
