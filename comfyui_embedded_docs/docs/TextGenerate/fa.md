# تولید متن

گره TextGenerate از یک مدل CLIP برای تولید متن بر اساس پرامپت کاربر استفاده می‌کند. می‌تواند به‌صورت اختیاری از تصویر، ویدئو یا صدا به‌عنوان زمینهٔ اضافی برای هدایت تولید متن استفاده کند. می‌توانید طول خروجی را کنترل کنید، برای مدل‌های پشتیبانی‌شده حالت تفکر را فعال کنید، و انتخاب کنید که از نمونه‌گیری تصادفی با تنظیمات مختلف استفاده شود یا متن بدون نمونه‌گیری تولید شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `حالت نمونه‌گیری` | کنترل می‌کند که آیا در طول تولید متن از نمونه‌گیری تصادفی استفاده شود یا نه. وقتی روی "on" تنظیم شود، پارامترهای نمونه‌گیری بیشتری در دسترس قرار می‌گیرند. وقتی روی "off" تنظیم شود، گره متن را بدون نمونه‌گیری تصادفی تولید می‌کند. | DYNAMIC_COMBO | بله | `"on"`<br>`"off"` |
| `clip` | مدل CLIP که برای توکن‌سازی پرامپت و تولید متن استفاده می‌شود. | CLIP | بله | N/A |
| `پرامپت` | پرامپت متنی که تولید را هدایت می‌کند. این فیلد از چند خط و پرامپت‌های پویا پشتیبانی می‌کند. مقدار پیش‌فرض یک رشتهٔ خالی است. | STRING | بله | N/A |
| `تصویر` | تصویر اختیاری که می‌تواند همراه با پرامپت متنی برای تأثیر بر متن تولیدشده استفاده شود. | IMAGE | خیر | N/A |
| `ویدیو` | فریم‌های ویدئو به‌صورت یک دسته تصویر. فرض می‌شود 24 FPS است؛ در داخل به 1 FPS کاهش‌نمونه‌برداری می‌شود. | IMAGE | خیر | N/A |
| `صدا` | ورودی صوتی اختیاری که می‌تواند همراه با پرامپت متنی برای تأثیر بر متن تولیدشده استفاده شود. | AUDIO | خیر | N/A |
| `حداکثر طول` | حداکثر تعداد توکن‌هایی که مدل تولید می‌کند. مقدار پیش‌فرض 512 است. | INT | بله | 1 تا 32768 |
| `تفکر` | اگر مدل پشتیبانی کند، در حالت تفکر کار می‌کند. مقدار پیش‌فرض False است. | BOOLEAN | خیر | True یا False |
| `use_default_template` | اگر مدل قالب/پرامپت سیستمی داخلی دارد، از آن استفاده می‌کند. مقدار پیش‌فرض True است. این یک پارامتر پیشرفته است. | BOOLEAN | خیر | True یا False |
| `mtp` | رمزگشایی گمانه‌زنانه با سر پیش‌بینی چندتوکنی چک‌پوینت. بدون وزن‌های MTP هیچ اثری ندارد. `"auto"` عمق پیش‌نویس را تطبیق می‌دهد، `"2"` تا `"5"` آن را ثابت می‌کنند. خروجی نمونه‌گیری‌شده به‌درستی توزیع می‌ماند اما برای همان seed با خروجی غیر-MTP متفاوت است (پیش‌فرض: `"auto"`). | COMBO | خیر | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"` |

### پارامترهای نمونه‌گیری (وقتی `sampling_mode` روی "on" است)

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `temperature` | میزان تصادفی‌بودن خروجی را کنترل می‌کند. مقادیر پایین‌تر خروجی را قابل‌پیش‌بینی‌تر و مقادیر بالاتر آن را خلاقانه‌تر می‌کنند. مقدار پیش‌فرض 0.7 است. | FLOAT | بله | 0.01 تا 2.0 |
| `top_k` | استخر نمونه‌گیری را به K توکن بعدی محتمل‌تر محدود می‌کند. مقدار 0 این فیلتر را غیرفعال می‌کند. مقدار پیش‌فرض 64 است. | INT | بله | 0 تا 1000 |
| `top_p` | از نمونه‌گیری هسته‌ای استفاده می‌کند و انتخاب‌ها را به توکن‌هایی محدود می‌کند که احتمال تجمعی آن‌ها کمتر از این مقدار باشد. مقدار پیش‌فرض 0.95 است. | FLOAT | بله | 0.0 تا 1.0 |
| `min_p` | آستانهٔ حداقل احتمال را برای در نظر گرفته شدن توکن‌ها تعیین می‌کند. مقدار پیش‌فرض 0.05 است. | FLOAT | بله | 0.0 تا 1.0 |
| `repetition_penalty` | به توکن‌هایی که قبلاً تولید شده‌اند جریمه اعمال می‌کند تا تکرار کاهش یابد. مقدار 1.0 هیچ جریمه‌ای اعمال نمی‌کند. مقدار پیش‌فرض 1.05 است. | FLOAT | بله | 0.0 تا 5.0 |
| `seed` | عددی که برای مقداردهی اولیه به مولد اعداد تصادفی جهت نتایج قابل‌بازتولید استفاده می‌شود. مقدار پیش‌فرض 0 است. | INT | بله | 0 تا 18446744073709551615 |
| `presence_penalty` | بر اساس اینکه توکن‌های جدید تا این لحظه در متن ظاهر شده‌اند یا نه به آن‌ها جریمه اعمال می‌کند و مدل را به صحبت دربارهٔ موضوعات جدید تشویق می‌کند. مقدار پیش‌فرض 0.0 است. | FLOAT | خیر | 0.0 تا 5.0 |

**توجه:** پارامترهای نمونه‌گیری بالا فقط زمانی فعال و در رابط گره قابل مشاهده هستند که `sampling_mode` روی "on" تنظیم شده باشد. وقتی `sampling_mode` روی "off" تنظیم شود، هیچ پارامتر نمونه‌گیری در دسترس نیست و گره متن را بدون نمونه‌گیری تصادفی تولید می‌کند.
