# تولید متن

گره TextGenerate از یک مدل CLIP برای ایجاد متن بر اساس درخواست کاربر استفاده می‌کند. این گره می‌تواند به‌صورت اختیاری از تصویر، ویدیو یا صدا به‌عنوان زمینه‌ای اضافی برای هدایت تولید متن استفاده کند. می‌توانید طول خروجی را کنترل کنید، حالت تفکر را برای مدل‌های پشتیبانی‌شده فعال کنید و تعیین کنید که آیا از نمونه‌برداری تصادفی با تنظیمات مختلف استفاده شود یا متن بدون نمونه‌برداری تولید گردد.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکن‌سازی درخواست و تولید متن استفاده می‌شود. | CLIP | بله | N/A |
| `prompt` | درخواست متنی که تولید را هدایت می‌کند. این فیلد از چند خط و درخواست‌های پویا پشتیبانی می‌کند. مقدار پیش‌فرض یک رشته خالی است. | STRING | بله | N/A |
| `image` | یک تصویر اختیاری که می‌تواند همراه با درخواست متنی برای تأثیرگذاری بر متن تولیدشده استفاده شود. | IMAGE | خیر | N/A |
| `video` | فریم‌های ویدیو به‌صورت یک دسته تصویری. فرض بر این است که ۲۴ فریم بر ثانیه است؛ به‌صورت داخلی به ۱ فریم بر ثانیه کاهش می‌یابد. | IMAGE | خیر | N/A |
| `audio` | یک ورودی صوتی اختیاری که می‌تواند همراه با درخواست متنی برای تأثیرگذاری بر متن تولیدشده استفاده شود. | AUDIO | خیر | N/A |
| `max_length` | حداکثر تعداد توکن‌هایی که مدل تولید خواهد کرد. مقدار پیش‌فرض ۵۱۲ است. | INT | بله | 1 to 32768 |
| `sampling_mode` | کنترل می‌کند که آیا نمونه‌برداری تصادفی در طول تولید متن استفاده شود یا خیر. وقتی روی «on» تنظیم شود، پارامترهای اضافی برای کنترل نمونه‌برداری در دسترس قرار می‌گیرند. پیش‌فرض «on» است. | DYNAMIC_COMBO | بله | "on"<br>"off" |
| `thinking` | در صورت پشتیبانی مدل، در حالت تفکر عمل می‌کند. مقدار پیش‌فرض False است. | BOOLEAN | خیر | True or False |
| `use_default_template` | اگر مدل دارای پرامپت/قالب سیستمی داخلی باشد، از آن استفاده کنید. مقدار پیش‌فرض True است. این یک پارامتر پیشرفته است. | BOOLEAN | خیر | True or False |

### ورودی‌های «on»

پارامترهای نمونه‌برداری زیر زمانی در دسترس هستند که `sampling_mode` روی «on» تنظیم شده باشد:

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `temperature` | تصادفی‌بودن خروجی را کنترل می‌کند. مقادیر پایین‌تر خروجی را قابل‌پیش‌بینی‌تر می‌کند و مقادیر بالاتر آن را خلاقانه‌تر می‌سازد. مقدار پیش‌فرض ۰.۷ است. | FLOAT | خیر | 0.01 to 2.0 |
| `top_k` | مخزن نمونه‌برداری را به K توکن بعدی با بیشترین احتمال محدود می‌کند. مقدار ۰ این فیلتر را غیرفعال می‌کند. مقدار پیش‌فرض ۶۴ است. | INT | خیر | 0 to 1000 |
| `top_p` | از نمونه‌برداری هسته‌ای استفاده می‌کند و انتخاب‌ها را به توکن‌هایی محدود می‌سازد که احتمال تجمعی آن‌ها کمتر از این مقدار باشد. مقدار پیش‌فرض ۰.۹۵ است. | FLOAT | خیر | 0.0 to 1.0 |
| `min_p` | آستانه حداقل احتمال را برای در نظر گرفتن توکن‌ها تعیین می‌کند. مقدار پیش‌فرض ۰.۰۵ است. | FLOAT | خیر | 0.0 to 1.0 |
| `repetition_penalty` | توکن‌هایی که قبلاً تولید شده‌اند را جریمه می‌کند تا تکرار کاهش یابد. مقدار ۱.۰ هیچ جریمه‌ای اعمال نمی‌کند. مقدار پیش‌فرض ۱.۰۵ است. | FLOAT | خیر | 0.0 to 5.0 |
| `presence_penalty` | توکن‌های جدید را بر اساس ظاهر شدنشان در متن تاکنون جریمه می‌کند و مدل را تشویق می‌کند درباره موضوعات جدید صحبت کند. مقدار پیش‌فرض ۰.۰ است. | FLOAT | خیر | 0.0 to 5.0 |
| `seed` | عددی که برای مقداردهی اولیه مولد اعداد تصادفی به‌منظور نتایج قابل‌تکرار زمانی که نمونه‌برداری «on» است استفاده می‌شود. مقدار پیش‌فرض ۰ است. | INT | خیر | 0 to 18446744073709551615 |

### ورودی‌های «off»

وقتی `sampling_mode` روی «off» تنظیم شود، هیچ پارامتر نمونه‌برداری اضافی در دسترس نیست و گره متن را بدون نمونه‌برداری تصادفی تولید می‌کند.

**توجه:** پارامترهای `temperature`، `top_k`، `top_p`، `min_p`، `repetition_penalty`، `presence_penalty` و `seed` تنها زمانی فعال و در رابط گره قابل مشاهده هستند که `sampling_mode` روی «on» تنظیم شده باشد.
