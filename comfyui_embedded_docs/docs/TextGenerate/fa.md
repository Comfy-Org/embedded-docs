# تولید متن

گره TextGenerate از یک مدل CLIP برای ایجاد متن بر اساس پرامپت کاربر استفاده می‌کند. این گره به‌طور اختیاری می‌تواند از تصاویر، ویدیو یا صدا به‌عنوان زمینه‌های اضافی برای هدایت تولید متن بهره ببرد. شما می‌توانید طول خروجی را کنترل کنید، حالت تفکر را برای مدل‌های پشتیبانی‌شده فعال کنید، و انتخاب کنید که آیا از نمونه‌برداری تصادفی با تنظیمات مختلف استفاده شود یا متن بدون نمونه‌برداری تولید گردد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `حالت نمونه‌گیری` | کنترل می‌کند که آیا نمونه‌برداری تصادفی در طول تولید متن استفاده شود. وقتی روی «on» تنظیم شود، پارامترهای نمونه‌برداری اضافی در دسترس قرار می‌گیرند. وقتی روی «off» تنظیم شود، گره متن را بدون نمونه‌برداری تصادفی تولید می‌کند. | DYNAMIC_COMBO | بله | `"on"`<br>`"off"` |
| `clip` | مدل CLIP که برای توکن‌سازی پرامپت و تولید متن استفاده می‌شود. | CLIP | بله | N/A |
| `پرامپت` | پرامپت متنی که تولید را هدایت می‌کند. این فیلد از چند خط و پرامپت‌های پویا پشتیبانی می‌کند. مقدار پیش‌فرض رشته خالی است. | STRING | بله | N/A |
| `تصویر` | یک تصویر اختیاری که می‌تواند در کنار پرامپت متنی برای تأثیرگذاری بر متن تولیدشده استفاده شود. | IMAGE | خیر | N/A |
| `ویدیو` | فریم‌های ویدیو به‌صورت یک دسته تصویر. فرض بر ۲۴ فریم بر ثانیه است؛ به‌صورت داخلی به ۱ فریم بر ثانیه کاهش نمونه‌برداری می‌شود. | IMAGE | خیر | N/A |
| `صدا` | یک ورودی صوتی اختیاری که می‌تواند در کنار پرامپت متنی برای تأثیرگذاری بر متن تولیدشده استفاده شود. | AUDIO | خیر | N/A |
| `حداکثر طول` | حداکثر تعداد توکن‌هایی که مدل تولید خواهد کرد. مقدار پیش‌فرض ۵۱۲ است. | INT | بله | 1 تا 32768 |
| `تفکر` | در حالت تفکر عمل کن اگر مدل از آن پشتیبانی می‌کند. مقدار پیش‌فرض False است. | BOOLEAN | خیر | True or False |
| `use_default_template` | از پرامپت/قالب سیستمی داخلی استفاده کن اگر مدل یکی دارد. مقدار پیش‌فرض True است. این یک پارامتر پیشرفته است. | BOOLEAN | خیر | True or False |

### پارامترهای نمونه‌برداری (وقتی `sampling_mode` روی «on» است)

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `temperature` | تصادفی بودن خروجی را کنترل می‌کند. مقادیر پایین‌تر خروجی را قابل‌پیش‌بینی‌تر می‌کنند، مقادیر بالاتر آن را خلاقانه‌تر می‌کنند. مقدار پیش‌فرض 0.7 است. | FLOAT | بله | 0.01 تا 2.0 |
| `top_k` | استخر نمونه‌برداری را به K توکن بعدی با بیشترین احتمال محدود می‌کند. مقدار 0 این فیلتر را غیرفعال می‌کند. مقدار پیش‌فرض ۶۴ است. | INT | بله | 0 تا 1000 |
| `top_p` | از نمونه‌برداری هسته‌ای استفاده می‌کند و انتخاب‌ها را به توکن‌هایی محدود می‌کند که احتمال تجمعی آن‌ها کمتر از این مقدار است. مقدار پیش‌فرض 0.95 است. | FLOAT | بله | 0.0 تا 1.0 |
| `min_p` | آستانه حداقل احتمال برای توکن‌هایی که در نظر گرفته شوند تنظیم می‌کند. مقدار پیش‌فرض 0.05 است. | FLOAT | بله | 0.0 تا 1.0 |
| `repetition_penalty` | توکن‌هایی که قبلاً تولید شده‌اند را جریمه می‌کند تا تکرار کاهش یابد. مقدار 1.0 جریمه‌ای اعمال نمی‌کند. مقدار پیش‌فرض 1.05 است. | FLOAT | بله | 0.0 تا 5.0 |
| `seed` | عددی که برای مقداردهی اولیه مولد اعداد تصادفی جهت نتایج قابل‌تکرار استفاده می‌شود. مقدار پیش‌فرض 0 است. | INT | بله | 0 تا 18446744073709551615 |
| `presence_penalty` | توکن‌های جدید را بر اساس اینکه آیا تاکنون در متن ظاهر شده‌اند جریمه می‌کند و مدل را به صحبت درباره موضوعات جدید ترغیب می‌کند. مقدار پیش‌فرض 0.0 است. | FLOAT | خیر | 0.0 تا 5.0 |

**توجه:** پارامترهای نمونه‌برداری فوق فقط زمانی در رابط گره فعال و قابل مشاهده هستند که `sampling_mode` روی «on» تنظیم شده باشد. وقتی `sampling_mode` روی «off» تنظیم شود، هیچ پارامتر نمونه‌برداری در دسترس نیست و گره متن را بدون نمونه‌برداری تصادفی تولید می‌کند.
