# TextGenerate

TextGenerate 節點使用 CLIP 模型，根據使用者的提示詞建立文字。它可選擇性地使用影像、影片或音訊作為額外上下文，以引導文字生成。您可以控制輸出的長度、為支援的模型啟用思考模式，以及選擇是否使用具有各種設定的隨機取樣，或在不進行取樣的情況下生成文字。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |

| `clip` | 用於對提示詞進行分詞並生成文字的 CLIP 模型。 | CLIP | 是 | N/A |
| `提示詞` | 引導文字生成過程的文字提示。此欄位支援多行和動態提示。預設值為空字串。 | STRING | 是 | N/A |
| `圖像` | 可選的影像，可與文字提示一起使用，以影響生成的文字。 | IMAGE | 否 | N/A |

### 取樣參數（當 `sampling_mode` 為「on」時）

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `temperature` | 控制輸出的隨機性。數值越低，輸出越可預測；數值越高，輸出越具創造力。預設值為 0.7。 | FLOAT | 是 | 0.01 至 2.0 |
| `top_k` | 將取樣池限制為最有可能的下一個 token 的前 K 個。值為 0 時停用此濾波器。預設值為 64。 | INT | 是 | 0 至 1000 |
| `top_p` | 使用核取樣（nucleus sampling），將選擇限制為累積機率低於此值的 token。預設值為 0.95。 | FLOAT | 是 | 0.0 至 1.0 |
| `min_p` | 設定 token 被納入考量時所需的最低機率門檻。預設值為 0.05。 | FLOAT | 是 | 0.0 至 1.0 |
| `repetition_penalty` | 對已生成的 token 施加懲罰，以減少重複。值為 1.0 時不施加任何懲罰。預設值為 1.05。 | FLOAT | 是 | 0.0 至 5.0 |
| `seed` | 用於初始化隨機數生成器的數字，以獲得可重現的結果。預設值為 0。 | INT | 是 | 0 至 18446744073709551615 |
| `presence_penalty` | 根據新 token 是否已出現在目前的文字中來施加懲罰，鼓勵模型討論新主題。預設值為 0.0。 | FLOAT | 否 | 0.0 至 5.0 |

**注意：** 當 `sampling_mode` 設為「on」時，上述取樣參數才在節點介面中啟用並可見。當 `sampling_mode` 設為「off」時，不會提供任何取樣參數，節點會在不進行隨機取樣的情況下生成文字。
