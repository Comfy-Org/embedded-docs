# TextGenerate

TextGenerate 節點使用 CLIP 模型根據使用者的提示詞產生文字。它可選擇性地使用圖像、影片或音訊作為額外上下文來引導文字產生。你可以控制輸出長度、為支援的模型啟用思考模式，並選擇要使用隨機取樣與各種設定，或是在不進行取樣的情況下產生文字。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `取樣模式` | 控制文字產生期間是否使用隨機取樣。設為 "on" 時，會提供額外的取樣參數。設為 "off" 時，節點會在不進行隨機取樣的情況下產生文字。 | DYNAMIC_COMBO | 是 | `"on"`<br>`"off"` |
| `clip` | 用於對提示詞進行 token 化並產生文字的 CLIP 模型。 | CLIP | 是 | N/A |
| `提示詞` | 引導產生的文字提示詞。此欄位支援多行與動態提示詞。預設值為空字串。 | STRING | 是 | N/A |
| `圖像` | 可選圖像，可與文字提示詞一起使用以影響產生的文字。 | IMAGE | 否 | N/A |
| `影片` | 作為圖像批次的影片影格。假設為 24 FPS；內部會降採樣至 1 FPS。 | IMAGE | 否 | N/A |
| `音訊` | 可選音訊輸入，可與文字提示詞一起使用以影響產生的文字。 | AUDIO | 否 | N/A |
| `最大長度` | 模型將產生的最大 token 數量。預設值為 512。 | INT | 是 | 1 至 32768 |
| `思考模式` | 若模型支援，則以思考模式運作。預設值為 False。 | BOOLEAN | 否 | True or False |

### 取樣參數（當 `sampling_mode` 為 "on" 時）

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `temperature` | 控制輸出的隨機性。較低數值使輸出更可預測，較高數值使輸出更具創意。預設值為 0.7。 | FLOAT | 是 | 0.01 至 2.0 |
| `top_k` | 將取樣池限制在接下來最有可能的前 K 個 token。數值 0 會停用此篩選。預設值為 64。 | INT | 是 | 0 至 1000 |
| `top_p` | 使用核心取樣（nucleus sampling），將選擇限制在累積機率小於此數值的 token。預設值為 0.95。 | FLOAT | 是 | 0.0 至 1.0 |
| `min_p` | 設定 token 被納入考量的最小機率閾值。預設值為 0.05。 | FLOAT | 是 | 0.0 至 1.0 |
| `repetition_penalty` | 對已產生的 token 進行懲罰以減少重複。數值 1.0 表示不施加懲罰。預設值為 1.05。 | FLOAT | 是 | 0.0 至 5.0 |
| `seed` | 用於初始化隨機數生成器以獲得可重現結果的數字。預設值為 0。 | INT | 是 | 0 至 18446744073709551615 |
| `presence_penalty` | 根據新 token 是否已在目前文字中出現來對其進行懲罰，藉此鼓勵模型談論新主題。預設值為 0.0。 | FLOAT | 否 | 0.0 至 5.0 |

**注意：** 只有在 `sampling_mode` 設為 "on" 時，上述取樣參數才會在節點介面中生效並顯示。當 `sampling_mode` 設為 "off" 時，沒有可用的取樣參數，節點會在不進行隨機取樣的情況下產生文字。
