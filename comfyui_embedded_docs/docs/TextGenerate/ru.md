# TextGenerate

Узел TextGenerate использует модель CLIP для создания текста на основе промпта пользователя. Он может дополнительно использовать изображения, видео или аудио в качестве дополнительного контекста, чтобы направлять генерацию текста. Вы можете управлять длиной вывода, включать режим размышления для поддерживаемых моделей и выбирать, использовать ли случайное сэмплирование с различными настройками или генерировать текст без сэмплирования.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `режим выборки` | Управляет тем, используется ли случайное сэмплирование во время генерации текста. При значении "on" становятся доступны дополнительные параметры сэмплирования. При значении "off" узел генерирует текст без случайного сэмплирования. | DYNAMIC_COMBO | Да | `"on"`<br>`"off"` |
| `clip` | Модель CLIP, используемая для токенизации промпта и генерации текста. | CLIP | Да | N/A |
| `запрос` | Текстовый промпт, направляющий генерацию. Это поле поддерживает несколько строк и динамические промпты. Значение по умолчанию — пустая строка. | STRING | Да | N/A |
| `изображение` | Необязательное изображение, которое можно использовать вместе с текстовым промптом, чтобы влиять на генерируемый текст. | IMAGE | Нет | N/A |
| `видео` | Кадры видео в виде пакета изображений. Предполагается 24 FPS; внутри выполняется субдискретизация до 1 FPS. | IMAGE | Нет | N/A |
| `аудио` | Необязательный аудиовход, который можно использовать вместе с текстовым промптом, чтобы влиять на генерируемый текст. | AUDIO | Нет | N/A |
| `максимальная длина` | Максимальное количество токенов, которое сгенерирует модель. Значение по умолчанию — 512. | INT | Да | 1–32768 |
| `мышление` | Работать в режиме размышления, если модель его поддерживает. Значение по умолчанию — False. | BOOLEAN | Нет | True или False |
| `use_default_template` | Использовать встроенный системный промпт/шаблон, если он есть у модели. Значение по умолчанию — True. Это расширенный параметр. | BOOLEAN | Нет | True или False |
| `mtp` | Спекулятивное декодирование с головой multi-token-prediction чекпоинта. Не даёт эффекта без весов MTP. `"auto"` адаптирует глубину драфта, `"2"`–`"5"` фиксируют её. Сэмплированный вывод остаётся корректно распределённым, но отличается от вывода без MTP для того же seed (по умолчанию: `"auto"`). | COMBO | Нет | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"` |

### Параметры сэмплирования (когда `sampling_mode` имеет значение "on")

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `temperature` | Управляет случайностью вывода. Меньшие значения делают вывод более предсказуемым, большие — более творческим. Значение по умолчанию — 0.7. | FLOAT | Да | 0.01–2.0 |
| `top_k` | Ограничивает пул сэмплирования K наиболее вероятными следующими токенами. Значение 0 отключает этот фильтр. Значение по умолчанию — 64. | INT | Да | 0–1000 |
| `top_p` | Использует нуклеарное сэмплирование, ограничивая выбор токенами, чья совокупная вероятность меньше этого значения. Значение по умолчанию — 0.95. | FLOAT | Да | 0.0–1.0 |
| `min_p` | Устанавливает минимальный порог вероятности для рассматриваемых токенов. Значение по умолчанию — 0.05. | FLOAT | Да | 0.0–1.0 |
| `repetition_penalty` | Штрафует токены, которые уже были сгенерированы, чтобы уменьшить повторы. Значение 1.0 не применяет штраф. Значение по умолчанию — 1.05. | FLOAT | Да | 0.0–5.0 |
| `seed` | Число, используемое для инициализации генератора случайных чисел для воспроизводимых результатов. Значение по умолчанию — 0. | INT | Да | 0–18446744073709551615 |
| `presence_penalty` | Штрафует новые токены в зависимости от того, появлялись ли они в тексте до этого момента, побуждая модель говорить на новые темы. Значение по умолчанию — 0.0. | FLOAT | Нет | 0.0–5.0 |

**Примечание:** Приведённые выше параметры сэмплирования активны и видимы в интерфейсе узла только когда `sampling_mode` имеет значение "on". Когда `sampling_mode` имеет значение "off", параметры сэмплирования недоступны, и узел генерирует текст без случайного сэмплирования.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `generated_text` | Текст, сгенерированный моделью на основе входного промпта и необязательного изображения, видео или аудио. | STRING |
