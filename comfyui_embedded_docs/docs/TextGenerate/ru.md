# TextGenerate

Узел TextGenerate использует модель CLIP для создания текста на основе пользовательского запроса. При необходимости он может использовать изображения, видео или аудио в качестве дополнительного контекста для управления генерацией текста. Вы можете контролировать длину выходного текста, включать режим мышления для поддерживаемых моделей, а также выбирать, использовать ли случайную выборку с различными настройками или генерировать текст без выборки.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации запроса и генерации текста. | CLIP | Да | Н/Д |
| `prompt` | Текстовый запрос, который управляет генерацией. Это поле поддерживает многострочный текст и динамические запросы. Значение по умолчанию — пустая строка. | STRING | Да | Н/Д |
| `image` | Необязательное изображение, которое можно использовать вместе с текстовым запросом для влияния на генерируемый текст. | IMAGE | Нет | Н/Д |
| `video` | Кадры видео в виде пакета изображений. Предполагается частота 24 кадра/с; внутренне прореживается до 1 кадра/с. | IMAGE | Нет | Н/Д |
| `audio` | Необязательный аудиовход, который можно использовать вместе с текстовым запросом для влияния на генерируемый текст. | AUDIO | Нет | Н/Д |
| `max_length` | Максимальное количество токенов, которое сгенерирует модель. Значение по умолчанию — 512. | INT | Да | 1 to 32768 |
| `sampling_mode` | Управляет тем, используется ли случайная выборка при генерации текста. Если задано значение "on", становятся доступны дополнительные параметры управления выборкой. По умолчанию — "on". | DYNAMIC_COMBO | Да | "on"<br>"off" |
| `thinking` | Работа в режиме мышления, если модель его поддерживает. Значение по умолчанию — False. | BOOLEAN | Нет | True or False |
| `use_default_template` | Использовать встроенный системный запрос/шаблон, если он есть у модели. Значение по умолчанию — True. Это расширенный параметр. | BOOLEAN | Нет | True or False |

### Входы для режима "on"

Следующие параметры выборки доступны, когда для `sampling_mode` задано значение "on":

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `temperature` | Управляет случайностью выходного текста. Более низкие значения делают результат более предсказуемым, более высокие — более креативным. Значение по умолчанию — 0.7. | FLOAT | Нет | 0.01 to 2.0 |
| `top_k` | Ограничивает пул выборки K наиболее вероятными следующими токенами. Значение 0 отключает этот фильтр. Значение по умолчанию — 64. | INT | Нет | 0 to 1000 |
| `top_p` | Использует ядерную выборку, ограничивая выбор токенами, чья совокупная вероятность меньше этого значения. Значение по умолчанию — 0.95. | FLOAT | Нет | 0.0 to 1.0 |
| `min_p` | Задает минимальный порог вероятности для токенов, которые следует рассматривать. Значение по умолчанию — 0.05. | FLOAT | Нет | 0.0 to 1.0 |
| `repetition_penalty` | Штрафует уже сгенерированные токены для уменьшения повторений. Значение 1.0 не применяет штраф. Значение по умолчанию — 1.05. | FLOAT | Нет | 0.0 to 5.0 |
| `presence_penalty` | Штрафует новые токены в зависимости от того, появлялись ли они в тексте ранее, побуждая модель обсуждать новые темы. Значение по умолчанию — 0.0. | FLOAT | Нет | 0.0 to 5.0 |
| `seed` | Число, используемое для инициализации генератора случайных чисел для воспроизводимых результатов, когда выборка включена ("on"). Значение по умолчанию — 0. | INT | Нет | 0 to 18446744073709551615 |

### Входы для режима "off"

Когда для `sampling_mode` задано значение "off", дополнительные параметры выборки недоступны, и узел генерирует текст без случайной выборки.

**Примечание:** Параметры `temperature`, `top_k`, `top_p`, `min_p`, `repetition_penalty`, `presence_penalty` и `seed` активны и видны в интерфейсе узла только тогда, когда для `sampling_mode` задано значение "on".

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `generated_text` | Текст, сгенерированный моделью на основе входного запроса и необязательных изображения, видео или аудио. | STRING |
