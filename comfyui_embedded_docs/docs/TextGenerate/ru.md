# TextGenerate

Узел TextGenerate использует модель CLIP для создания текста на основе промпта пользователя. Он может дополнительно использовать изображения, видео или аудио в качестве контекста для управления генерацией текста. Вы можете контролировать длину выходных данных, включать режим рассуждений для поддерживаемых моделей и выбирать, использовать ли случайную выборку с различными настройками или генерировать текст без выборки.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `режим выборки` | Управляет использованием случайной выборки при генерации текста. Если задано значение "on", становятся доступны дополнительные параметры выборки. Если задано значение "off", узел генерирует текст без случайной выборки. | DYNAMIC_COMBO | Да | `"on"`<br>`"off"` |
| `clip` | Модель CLIP, используемая для токенизации промпта и генерации текста. | CLIP | Да | N/A |
| `запрос` | Текстовый промпт, направляющий генерацию. Это поле поддерживает многострочный ввод и динамические промпты. Значение по умолчанию — пустая строка. | STRING | Да | N/A |
| `изображение` | Необязательное изображение, которое можно использовать вместе с текстовым промптом для влияния на генерируемый текст. | IMAGE | Нет | N/A |
| `видео` | Видеокадры в виде пакета изображений. Предполагается частота 24 FPS; внутренне прореживается до 1 FPS. | IMAGE | Нет | N/A |
| `аудио` | Необязательный аудиовход, который можно использовать вместе с текстовым промптом для влияния на генерируемый текст. | AUDIO | Нет | N/A |
| `максимальная длина` | Максимальное количество токенов, которое сгенерирует модель. Значение по умолчанию: 512. | INT | Да | 1 до 32768 |
| `мышление` | Работа в режиме рассуждений, если модель это поддерживает. Значение по умолчанию: False. | BOOLEAN | Нет | True or False |
| `use_default_template` | Использовать встроенный системный промпт/шаблон, если он есть у модели. Значение по умолчанию: True. Это расширенный параметр. | BOOLEAN | Нет | True or False |

### Параметры выборки (когда `sampling_mode` имеет значение "on")

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `temperature` | Управляет случайностью выходных данных. Меньшие значения делают вывод более предсказуемым, большие — более креативным. Значение по умолчанию: 0.7. | FLOAT | Да | 0.01 до 2.0 |
| `top_k` | Ограничивает пул выборки K наиболее вероятными следующими токенами. Значение 0 отключает этот фильтр. Значение по умолчанию: 64. | INT | Да | 0 до 1000 |
| `top_p` | Использует nucleus-выборку, ограничивая выбор токенами, чья совокупная вероятность меньше этого значения. Значение по умолчанию: 0.95. | FLOAT | Да | 0.0 до 1.0 |
| `min_p` | Задает минимальный порог вероятности для рассматриваемых токенов. Значение по умолчанию: 0.05. | FLOAT | Да | 0.0 до 1.0 |
| `repetition_penalty` | Штрафует уже сгенерированные токены для уменьшения повторений. Значение 1.0 не применяет штраф. Значение по умолчанию: 1.05. | FLOAT | Да | 0.0 до 5.0 |
| `seed` | Число, используемое для инициализации генератора случайных чисел для воспроизводимых результатов. Значение по умолчанию: 0. | INT | Да | 0 до 18446744073709551615 |
| `presence_penalty` | Штрафует новые токены в зависимости от того, появлялись ли они в тексте ранее, побуждая модель говорить на новые темы. Значение по умолчанию: 0.0. | FLOAT | Нет | 0.0 до 5.0 |

**Примечание:** Указанные выше параметры выборки активны и видны в интерфейсе узла только тогда, когда `sampling_mode` имеет значение "on". Когда `sampling_mode` имеет значение "off", параметры выборки недоступны, и узел генерирует текст без случайной выборки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `сгенерированный текст` | Текст, сгенерированный моделью на основе входного промпта и необязательных изображения, видео или аудио. | STRING |
