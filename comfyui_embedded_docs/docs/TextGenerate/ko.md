# 텍스트 생성

TextGenerate 노드는 CLIP 모델을 사용하여 사용자의 프롬프트를 기반으로 텍스트를 생성합니다. 선택적으로 이미지, 비디오 또는 오디오를 추가 컨텍스트로 사용하여 텍스트 생성을 안내할 수 있습니다. 출력 길이를 제어하고, 지원되는 모델에 대해 추론 모드를 활성화하며, 다양한 설정으로 무작위 샘플링을 사용할지 또는 샘플링 없이 텍스트를 생성할지 선택할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 프롬프트를 토큰화하고 텍스트를 생성하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | N/A |
| `prompt` | 생성을 안내하는 텍스트 프롬프트입니다. 이 필드는 여러 줄과 동적 프롬프트를 지원합니다. 기본값은 빈 문자열입니다. | STRING | 예 | N/A |
| `image` | 텍스트 프롬프트와 함께 사용하여 생성된 텍스트에 영향을 줄 수 있는 선택적 이미지입니다. | IMAGE | 아니요 | N/A |
| `video` | 이미지 배치 형태의 비디오 프레임입니다. 24FPS로 가정되며 내부적으로 1FPS로 서브샘플링됩니다. | IMAGE | 아니요 | N/A |
| `audio` | 텍스트 프롬프트와 함께 사용하여 생성된 텍스트에 영향을 줄 수 있는 선택적 오디오 입력입니다. | AUDIO | 아니요 | N/A |
| `max_length` | 모델이 생성할 최대 토큰 수입니다. 기본값은 512입니다. | INT | 예 | 1 to 32768 |
| `sampling_mode` | 텍스트 생성 중 무작위 샘플링 사용 여부를 제어합니다. "on"으로 설정하면 샘플링을 제어하는 추가 매개변수를 사용할 수 있습니다. 기본값은 "on"입니다. | DYNAMIC_COMBO | 예 | "on"<br>"off" |
| `thinking` | 모델이 지원하는 경우 추론 모드로 작동합니다. 기본값은 False입니다. | BOOLEAN | 아니요 | True or False |
| `use_default_template` | 모델에 내장 시스템 프롬프트/템플릿이 있는 경우 이를 사용합니다. 기본값은 True입니다. 고급 매개변수입니다. | BOOLEAN | 아니요 | True or False |

### "on" 입력

`sampling_mode`가 "on"으로 설정된 경우 다음 샘플링 매개변수를 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `temperature` | 출력의 무작위성을 제어합니다. 값이 낮을수록 출력이 더 예측 가능해지고, 값이 높을수록 더 창의적입니다. 기본값은 0.7입니다. | FLOAT | 아니요 | 0.01 to 2.0 |
| `top_k` | 샘플링 풀을 가장 가능성이 높은 상위 K개의 다음 토큰으로 제한합니다. 0 값은 이 필터를 비활성화합니다. 기본값은 64입니다. | INT | 아니요 | 0 to 1000 |
| `top_p` | 누적 확률이 이 값보다 낮은 토큰으로 선택을 제한하는 핵 샘플링(nucleus sampling)을 사용합니다. 기본값은 0.95입니다. | FLOAT | 아니요 | 0.0 to 1.0 |
| `min_p` | 토큰이 고려되기 위한 최소 확률 임계값을 설정합니다. 기본값은 0.05입니다. | FLOAT | 아니요 | 0.0 to 1.0 |
| `repetition_penalty` | 반복을 줄이기 위해 이미 생성된 토큰에 패널티를 적용합니다. 1.0 값은 패널티를 적용하지 않습니다. 기본값은 1.05입니다. | FLOAT | 아니요 | 0.0 to 5.0 |
| `presence_penalty` | 지금까지 텍스트에 나타났는지 여부에 따라 새 토큰에 패널티를 적용하여 모델이 새로운 주제에 대해 이야기하도록 유도합니다. 기본값은 0.0입니다. | FLOAT | 아니요 | 0.0 to 5.0 |
| `seed` | 샘플링이 "on"일 때 재현 가능한 결과를 위해 난수 생성기를 초기화하는 데 사용되는 숫자입니다. 기본값은 0입니다. | INT | 아니요 | 0 to 18446744073709551615 |

### "off" 입력

`sampling_mode`가 "off"로 설정된 경우 추가 샘플링 매개변수를 사용할 수 없으며 노드는 무작위 샘플링 없이 텍스트를 생성합니다.

**참고:** `temperature`, `top_k`, `top_p`, `min_p`, `repetition_penalty`, `presence_penalty` 및 `seed` 매개변수는 `sampling_mode`가 "on"으로 설정된 경우에만 노드 인터페이스에서 활성화되고 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `generated_text` | 모델이 입력 프롬프트와 선택적 이미지, 비디오 또는 오디오를 기반으로 생성한 텍스트입니다. | STRING |
