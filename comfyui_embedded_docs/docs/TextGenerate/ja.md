# TextGenerate

TextGenerate ノードは、CLIP モデルを使用してユーザーのプロンプトに基づいてテキストを生成します。オプションで画像、ビデオ、またはオーディオを追加のコンテキストとして使用し、テキスト生成を導くことができます。出力の長さを制御したり、対応するモデルで思考モードを有効にしたり、さまざまな設定でランダムサンプリングを使用するか、サンプリングなしでテキストを生成するかを選択できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | プロンプトのトークン化とテキスト生成に使用されるCLIPモデル。 | CLIP | はい | N/A |
| `prompt` | 生成を導くテキストプロンプト。このフィールドは複数行と動的プロンプトをサポートしています。デフォルト値は空文字列です。 | STRING | はい | N/A |
| `image` | テキストプロンプトと併用して生成テキストに影響を与えるために使用できるオプションの画像。 | IMAGE | いいえ | N/A |
| `video` | 画像バッチとしてのビデオフレーム。24 FPS と想定され、内部で 1 FPS にサブサンプリングされます。 | IMAGE | いいえ | N/A |
| `audio` | テキストプロンプトと併用して生成テキストに影響を与えるために使用できるオプションのオーディオ入力。 | AUDIO | いいえ | N/A |
| `max_length` | モデルが生成する最大トークン数。デフォルト値は512です。 | INT | はい | 1 to 32768 |
| `sampling_mode` | テキスト生成中にランダムサンプリングを使用するかどうかを制御します。"on" に設定すると、サンプリングを制御する追加パラメータが使用可能になります。デフォルトは "on" です。 | DYNAMIC_COMBO | はい | "on"<br>"off" |
| `thinking` | モデルがサポートしている場合、思考モードで動作します。デフォルト値は False です。 | BOOLEAN | いいえ | True or False |
| `use_default_template` | モデルに組み込みのシステムプロンプト/テンプレートがある場合はそれを使用します。デフォルト値は True です。これは高度なパラメータです。 | BOOLEAN | いいえ | True or False |

### "on" 入力

`sampling_mode` が "on" に設定されている場合、以下のサンプリングパラメータが使用可能です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `temperature` | 出力のランダム性を制御します。値が低いほど出力は予測しやすくなり、値が高いほど創造的になります。デフォルト値は 0.7 です。 | FLOAT | いいえ | 0.01 to 2.0 |
| `top_k` | サンプリングプールを、次に来る可能性が最も高い上位 K 個のトークンに制限します。0 に設定するとこのフィルターは無効になります。デフォルト値は 64 です。 | INT | いいえ | 0 to 1000 |
| `top_p` | 核サンプリング（nucleus sampling）を使用し、累積確率がこの値未満のトークンに選択肢を制限します。デフォルト値は 0.95 です。 | FLOAT | いいえ | 0.0 to 1.0 |
| `min_p` | 考慮するトークンの最小確率しきい値を設定します。デフォルト値は 0.05 です。 | FLOAT | いいえ | 0.0 to 1.0 |
| `repetition_penalty` | 既に生成されたトークンにペナルティを課し、繰り返しを減らします。1.0 の場合はペナルティが適用されません。デフォルト値は 1.05 です。 | FLOAT | いいえ | 0.0 to 5.0 |
| `presence_penalty` | これまでのテキストに出現したかどうかに基づいて新しいトークンにペナルティを課し、モデルが新しいトピックについて生成することを促します。デフォルト値は 0.0 です。 | FLOAT | いいえ | 0.0 to 5.0 |
| `seed` | サンプリングが "on" の場合に再現可能な結果を得るために、乱数生成器を初期化する数値。デフォルト値は 0 です。 | INT | いいえ | 0 to 18446744073709551615 |

### "off" 入力

`sampling_mode` が "off" に設定されている場合、追加のサンプリングパラメータは使用できず、ノードはランダムサンプリングなしでテキストを生成します。

**注：** `temperature`、`top_k`、`top_p`、`min_p`、`repetition_penalty`、`presence_penalty`、`seed` の各パラメータは、`sampling_mode` が "on" に設定されている場合にのみノードインターフェースで有効になり、表示されます。

| --- | --- | --- |
| `generated_text` | 入力されたプロンプトと、オプションの画像、ビデオ、またはオーディオに基づいてモデルが生成したテキスト。 | STRING |
