# Bria Guided Remove Background

Этот узел удаляет фон с изображения с помощью Bria, сохраняя то, что описано в промпте. Исходные пиксели возвращаются в полном разрешении с новым альфа-каналом вместо повторного рендеринга, поэтому мелкие детали и края сохраняются. Промпт, который ничему не соответствует, возвращает полностью прозрачное изображение. Для простого вырезания без указаний Bria Remove Image Background обходится дешевле.

## Входы

Селектор `moderation` открывает дополнительные параметры модерации, если установлен в `"true"`.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для вырезания. | IMAGE | Да | - |
| `prompt` | Что сохранить и, при необходимости, что удалить или ограничить, например 'человек с ковриком и растением', 'женщина за столом без лампы' или 'только стул'. Не должен быть пустым. Если ничего не соответствует промпту, результат будет полностью прозрачным. По умолчанию: `""` (пустая строка). | STRING | Да | 1 символ или больше |
| `moderation` | Настройки модерации. Если установлено в `"true"`, становятся доступны флаги визуальной модерации, приведённые ниже. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы при `moderation` = `"true"`

Эти параметры появляются только когда `moderation` установлен в `"true"`. Опция `"false"` не добавляет дополнительных входов.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию содержимого входного изображения. По умолчанию: `False`. | BOOLEAN | Нет | True / False |
| `visual_output_moderation` | Включает модерацию содержимого сгенерированного изображения. По умолчанию: `False`. | BOOLEAN | Нет | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Вырезанное изображение: исходные пиксели с новым альфа-каналом. | IMAGE |
