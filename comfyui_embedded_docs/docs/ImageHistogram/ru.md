# Гистограмма изображения

Узел ImageHistogram анализирует цветовое распределение входного изображения. Он вычисляет и выводит несколько гистограмм — графиков, показывающих, сколько пикселей изображения имеют каждое возможное значение интенсивности. Он создает отдельные гистограммы для красного, зеленого и синего цветовых каналов, объединенную RGB-гистограмму и гистограмму яркости на основе стандартной формулы яркости. Каждая гистограмма содержит 256 бинов, охватывающих уровни интенсивности от 0 до 255.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Входное изображение для анализа. Узел обрабатывает первое изображение в пакете. | IMAGE | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `rgb` | Составная гистограмма, представляющая среднюю интенсивность пикселей по красному, зеленому и синему каналам. | HISTOGRAM |
| `яркость` | Гистограмма воспринимаемой яркости изображения, рассчитанная по стандартной формуле яркости ITU-R BT.709. | HISTOGRAM |
| `красный` | Гистограмма, показывающая распределение интенсивностей пикселей в красном цветовом канале. | HISTOGRAM |
| `зелёный` | Гистограмма, показывающая распределение интенсивностей пикселей в зеленом цветовом канале. | HISTOGRAM |
| `синий` | Гистограмма, показывающая распределение интенсивностей пикселей в синем цветовом канале. | HISTOGRAM |
