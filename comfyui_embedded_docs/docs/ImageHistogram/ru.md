# Гистограмма изображения

Узел ImageHistogram анализирует цветовое распределение входного изображения. Он вычисляет и выводит несколько гистограмм — графиков, показывающих, сколько пикселей изображения имеют каждое возможное значение интенсивности. Он создает отдельные гистограммы для красного, зеленого и синего цветовых каналов, составную RGB-гистограмму и гистограмму яркости на основе стандартной формулы яркости.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение для анализа. Узел обрабатывает первое изображение в пакете. | IMAGE | Да | N/A |

## Выходные параметры

Все выходные гистограммы содержат 256 значений, по одному для каждого уровня интенсивности от 0 до 255.

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `rgb` | Составная гистограмма, представляющая среднюю интенсивность пикселей по красному, зеленому и синему каналам. | HISTOGRAM |
| `luminance` | Гистограмма воспринимаемой яркости изображения, рассчитанная по стандартной формуле яркости ITU-R BT.709. | HISTOGRAM |
| `red` | Гистограмма, показывающая распределение интенсивностей пикселей в красном цветовом канале. | HISTOGRAM |
| `green` | Гистограмма, показывающая распределение интенсивностей пикселей в зеленом цветовом канале. | HISTOGRAM |
| `blue` | Гистограмма, показывающая распределение интенсивностей пикселей в синем цветовом канале. | HISTOGRAM |
