# 影像直方圖

ImageHistogram 節點會分析輸入影像的色彩分佈。它計算並輸出數個直方圖，這些圖表顯示影像中每個可能強度值的像素數量。它會為紅色、綠色和藍色色彩通道分別產生直方圖，以及一個複合 RGB 直方圖和一個根據標準亮度公式計算的亮度直方圖。每個直方圖包含 256 個區間，涵蓋 0 到 255 的強度等級。

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
