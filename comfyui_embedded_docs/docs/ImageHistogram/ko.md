# 이미지 히스토그램

ImageHistogram 노드는 입력 이미지의 색상 분포를 분석합니다. 이 노드는 이미지의 각 가능한 강도 값에 해당하는 픽셀 수를 보여주는 그래프인 여러 히스토그램을 계산하고 출력합니다. 빨간색, 녹색, 파란색 색상 채널에 대한 개별 히스토그램, 복합 RGB 히스토그램, 그리고 표준 밝기 공식에 기반한 휘도 히스토그램을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 분석할 입력 이미지입니다. 이 노드는 배치에서 첫 번째 이미지를 처리합니다. | IMAGE | 예 | N/A |

## 출력

모든 출력 히스토그램은 0부터 255까지의 각 강도 수준에 대해 하나씩, 총 256개의 값을 포함합니다.

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `rgb` | 빨간색, 녹색, 파란색 채널에 걸친 평균 픽셀 강도를 나타내는 복합 히스토그램입니다. | HISTOGRAM |
| `luminance` | ITU-R BT.709 표준 휘도 공식을 사용하여 계산된 이미지의 인지 밝기에 대한 히스토그램입니다. | HISTOGRAM |
| `red` | 빨간색 색상 채널의 픽셀 강도 분포를 보여주는 히스토그램입니다. | HISTOGRAM |
| `green` | 녹색 색상 채널의 픽셀 강도 분포를 보여주는 히스토그램입니다. | HISTOGRAM |
| `blue` | 파란색 색상 채널의 픽셀 강도 분포를 보여주는 히스토그램입니다. | HISTOGRAM |
