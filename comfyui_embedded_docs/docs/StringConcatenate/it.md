# Concatena Testo

Il nodo StringConcatenate combina due stringhe di testo in una sola unendole con un delimitatore specificato. Riceve in input due stringhe e un carattere o una stringa delimitatore, quindi restituisce in output un'unica stringa in cui i due input sono collegati con il delimitatore posto tra essi.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `string_a` | La prima stringa di testo da concatenare | STRING | Sì | - |
| `string_b` | La seconda stringa di testo da concatenare | STRING | Sì | - |
| `delimiter` | Il carattere o la stringa da inserire tra le due stringhe di input (predefinito: stringa vuota) | STRING | No | - |

## Output

| Nome output | Descrizione | Tipo di dato |
| --- | --- | --- |
| `output` | La stringa combinata con il delimitatore inserito tra string_a e string_b | STRING |
