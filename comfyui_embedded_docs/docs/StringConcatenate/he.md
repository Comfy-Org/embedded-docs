# StringConcatenate

צומת StringConcatenate משלבת שתי מחרוזות טקסט לאחת על ידי חיבורן עם מפריד מוגדר. היא מקבלת שתי מחרוזות קלט ותו או מחרוזת מפריד, ולאחר מכן מפיקה מחרוזת אחת שבה שני הקלטים מחוברים כשהמפריד מוצב ביניהם.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string_a` | מחרוזת הטקסט הראשונה לשרשור | STRING | כן | - |
| `string_b` | מחרוזת הטקסט השנייה לשרשור | STRING | כן | - |
| `delimiter` | התו או המחרוזת שיש להכניס בין שתי מחרוזות הקלט (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | המחרוזת המשולבת עם המפריד המוכנס בין string_a ל-string_b | STRING |
