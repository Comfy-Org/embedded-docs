# Create Camera Orbit

تُنشئ منظومة كاميرات حول هدف الكاميرا الأولى: طاولة دوارة افتراضيًا، ومسحًا مائلًا عند ضبط `pitch`، مع مناظر اختيارية مباشرة إلى الأسفل وإلى الأعلى. تُصيّر عقدة Render Mesh صورة واحدة لكل كاميرا، وتقوم عقدة Bake Texture From Views بإسقاطها مجددًا على الشبكة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `camera_info` | الكاميرا الأولى للمدار. عند تمرير قائمة كاميرات، يتم إنشاء مدار حول كل كاميرا فيها. | LOAD3D_CAMERA | نعم | - |
| `count` | عدد الكاميرات الموزعة بالتساوي على طول المسار الدوراني. الافتراضي: 4. | INT | نعم | 1 إلى 64 |
| `yaw` | إجمالي الدوران حول الهدف، وفق اتجاه yaw الخاص بعقدة Create Camera Info. تتوقف الدورات الكاملة قبل خطوة واحدة من الكاميرا الأولى؛ أما المسارات الأخرى فتنتهي عند الكاميرا الأخيرة. الافتراضي: 360.0. | FLOAT | نعم | -720.0 إلى 720.0 (خطوة: 1.0) |
| `pitch` | إجمالي الميل فوق الهدف، ويكون موجبًا صاعدًا مثل pitch في Create Camera Info؛ وعند تجاوز 90 تمر الكاميرات فوق القمة. تتكرر الدورات الكاملة مثل `yaw`. الافتراضي: 0.0. | FLOAT | نعم | -720.0 إلى 720.0 (خطوة: 1.0) |
| `poles` | مناظر مباشرة إلى الأسفل و/أو الأعلى باتجاه الهدف، تُضاف بعد المدار. يشير أعلى صورتها بعيدًا عن الكاميرا الأولى. الافتراضي: `"none"`. | COMBO | نعم | `"none"`<br>`"top"`<br>`"bottom"`<br>`"top and bottom"` |
