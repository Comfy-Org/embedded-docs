# Create Camera Orbit

Создаёт риг камер вокруг цели первой камеры: по умолчанию — круговой облёт (turntable), наклонный облёт, если задан `pitch`, и, опционально, виды строго вниз и вверх. Render Mesh рендерит одно изображение на камеру, а Bake Texture From Views проецирует их обратно на меш.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `camera_info` | Первая камера орбиты. Если задан список камер, орбита создаётся вокруг каждой камеры из списка. | LOAD3D_CAMERA | Да | - |
| `count` | Количество камер, равномерно распределённых вдоль облёта. По умолчанию: 4. | INT | Да | от 1 до 64 |
| `yaw` | Общий поворот вокруг цели в направлении yaw узла Create Camera Info. Полные обороты останавливаются за один шаг до первой камеры; остальные облёты заканчиваются на последней камере. По умолчанию: 360.0. | FLOAT | Да | от -720.0 до 720.0 (шаг 1.0) |
| `pitch` | Общий наклон над целью; положительное значение поднимается, как pitch в Create Camera Info; после 90 градусов камеры проходят через верхнюю точку. Полные обороты зацикливаются так же, как `yaw`. По умолчанию: 0.0. | FLOAT | Да | от -720.0 до 720.0 (шаг 1.0) |
| `poles` | Виды строго вниз и/или вверх на цель, добавляемые после орбиты. Верх их изображения направлен в сторону от первой камеры. По умолчанию: `"none"`. | COMBO | Да | `"none"`<br>`"top"`<br>`"bottom"`<br>`"top and bottom"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `camera_info` | Список камер рига: сначала в порядке орбиты, затем виды с полюсов. | LOAD3D_CAMERA |
