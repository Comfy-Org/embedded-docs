# Reve Создание изображения

Узел Reve Image Create генерирует изображения по текстовым описаниям с помощью модели Reve AI. Он отправляет текстовый запрос в API Reve и возвращает сгенерированное изображение. Вы можете управлять соотношением сторон изображения и применять дополнительные эффекты постобработки, такие как масштабирование и удаление фона. Этот узел устарел.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели для генерации. Выбор этой модели открывает настройки `aspect_ratio` и `test_time_scaling`. | DYNAMIC_COMBO | Да | `"reve-create@20250915"` |
| `prompt` | Текстовое описание желаемого изображения. Максимум 2560 символов. По умолчанию: пусто. | STRING | Да | N/A |
| `seed` | Управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Нет | 0–2147483647 |
| `upscale` | Масштабировать сгенерированное изображение. Может привести к дополнительным затратам. Если задано значение `enabled`, появляется параметр `upscale_factor`. По умолчанию: `disabled`. | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удалить фон из сгенерированного изображения. Может привести к дополнительным затратам. По умолчанию: false. | BOOLEAN | Нет | true<br>false |

### Входы reve-create@20250915

Эти параметры появляются, когда для `model` задано значение `"reve-create@20250915"`.

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон выходного изображения. | COMBO | Да | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Более высокие значения дают лучшие изображения, но стоят больше кредитов. По умолчанию: 1. | INT | Нет | 1–5 |

### Входы Upscale

Эти параметры появляются, когда для `upscale` задано значение `"enabled"`.

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | Коэффициент масштабирования (2x, 3x или 4x). По умолчанию: 2. | INT | Нет | 2–4 (шаг 1) |

**Примечание:** Параметр `seed` не гарантирует детерминированных результатов. Параметр `upscale` управляет тем, применяется ли масштабирование как этап постобработки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение, сгенерированное моделью Reve на основе входного запроса. | IMAGE |
