# Reve Создание изображения

Узел Reve Image Create генерирует изображения по текстовым описаниям с использованием модели Reve AI. Он отправляет текстовый запрос в API Reve и возвращает сгенерированное изображение, с контролем соотношения сторон и дополнительной пост-обработкой, такой как масштабирование и удаление фона. Этот узел устарел.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Версия модели, используемая для генерации. | DYNAMIC_COMBO | Да | `"reve-create@20250915"` |
| `prompt` | Текстовое описание желаемого изображения. Максимум 2560 символов. | STRING | Да | 1 до 2560 символов |
| `upscale` | Увеличить масштаб сгенерированного изображения. Может добавить дополнительную стоимость. По умолчанию: "disabled". | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удалить фон сгенерированного изображения. Может добавить дополнительную стоимость. По умолчанию: False. | BOOLEAN | Нет | N/A |
| `seed` | Seed управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Нет | 0 до 2147483647 |

### Входы reve-create@20250915

Опции, доступные, когда `model` установлено в `"reve-create@20250915"`:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | Соотношение сторон выходного изображения. | COMBO | Да | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Более высокие значения дают лучшие изображения, но стоят больше кредитов. По умолчанию: 1. Расширенная опция. | INT | Нет | 1 до 5 |

### Входы масштабирования

Опции, доступные, когда `upscale` установлено в `"enabled"`:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `upscale_factor` | Коэффициент масштабирования (2x, 3x или 4x). По умолчанию: 2. | INT | Нет | 2 до 4 |

**Примечание:** Параметр `seed` не гарантирует детерминированных результатов. Параметр `upscale` управляет тем, применяется ли масштабирование как этап пост-обработки, и может добавлять дополнительную стоимость. Параметр `prompt` должен содержать от 1 до 2560 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Изображение, сгенерированное моделью Reve на основе входного запроса. | IMAGE |
