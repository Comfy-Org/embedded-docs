# Reve Создание изображения

Узел Reve Image Create создаёт изображения из текстового описания с помощью модели Reve AI. Он отправляет промпт в API Reve и возвращает полученное изображение с необязательной постобработкой для масштабирования и удаления фона. Этот узел устарел.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Версия модели, используемая для генерации. | DYNAMIC_COMBO | Да | `"reve-create@20250915"` |
| `prompt` | Текстовое описание желаемого изображения. Максимум 2560 символов. По умолчанию: "" (пусто). | STRING | Да | от 1 до 2560 символов |
| `upscale` | Увеличивает масштаб сгенерированного изображения. Может увеличить стоимость. По умолчанию: "disabled". | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удаляет фон со сгенерированного изображения. Может увеличить стоимость. По умолчанию: False. | BOOLEAN | Нет | Н/Д |
| `seed` | `seed` управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от значения seed. По умолчанию: 0. | INT | Нет | от 0 до 2147483647 |

### Входы reve-create@20250915

Параметры, доступные, когда `model` установлен в `"reve-create@20250915"`:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | Соотношение сторон выходного изображения. | COMBO | Да | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Более высокие значения дают лучшее качество изображений, но требуют больше кредитов. По умолчанию: 1. Расширенный параметр. | INT | Нет | от 1 до 5 |

### Входы масштабирования

Параметры, доступные, когда `upscale` установлен в `"enabled"`:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `upscale_factor` | Коэффициент масштабирования (2x, 3x или 4x). По умолчанию: 2. | INT | Нет | от 2 до 4 |

**Примечание:** `prompt` должен содержать от 1 до 2560 символов. Вход `upscale_factor` появляется только тогда, когда `upscale` установлен в `"enabled"`. Параметр `seed` не гарантирует детерминированные выходные данные — результаты недетерминированы независимо от значения seed. Оба параметра `upscale` и `remove_background` могут увеличить стоимость.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Изображение, сгенерированное моделью Reve на основе входного промпта. | IMAGE |
