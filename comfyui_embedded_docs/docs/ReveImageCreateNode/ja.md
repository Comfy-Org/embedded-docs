# Reve画像生成

Reve Image Create ノードは、Reve AI モデルを使用してテキスト記述から画像を生成します。テキストプロンプトを Reve API に送信し、生成された画像を返します。画像のアスペクト比を制御したり、アップスケーリングや背景除去などのオプションの後処理効果を適用したりできます。このノードは非推奨です。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルバージョン。このモデルを選択すると、`aspect_ratio` と `test_time_scaling` の設定が表示されます。 | DYNAMIC_COMBO | はい | `"reve-create@20250915"` |
| `prompt` | 希望する画像のテキスト記述。最大2560文字。デフォルト: 空。 | STRING | はい | N/A |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルト: 0。 | INT | いいえ | 0 から 2147483647 |
| `upscale` | 生成された画像をアップスケールします。追加コストがかかる場合があります。`enabled` に設定すると、`upscale_factor` 設定が表示されます。デフォルト: `disabled`。 | DYNAMIC_COMBO | いいえ | `"disabled"`<br>`"enabled"` |
| `remove_background` | 生成された画像から背景を除去します。追加コストがかかる場合があります。デフォルト: false。 | BOOLEAN | いいえ | true<br>false |

### reve-create@20250915 入力

これらの設定は、`model` が `"reve-create@20250915"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 出力画像のアスペクト比。 | COMBO | はい | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 値が大きいほど高品質な画像が生成されますが、より多くのクレジットを消費します。デフォルト: 1。 | INT | いいえ | 1 から 5 |

### アップスケール入力

これらの設定は、`upscale` が `"enabled"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | アップスケール係数（2倍、3倍、または4倍）。デフォルト: 2。 | INT | いいえ | 2 から 4 (ステップ 1) |

**注:** `seed` パラメータは決定的な出力を保証しません。`upscale` パラメータは、後処理ステップとしてアップスケーリングを適用するかどうかを制御します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | Reve モデルが入力プロンプトに基づいて生成した画像。 | IMAGE |
