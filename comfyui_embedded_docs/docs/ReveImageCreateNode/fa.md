# ایجاد تصویر با Reve

گره Reve Image Create تصاویری را از توصیف‌های متنی با استفاده از مدل Reve AI تولید می‌کند. یک متن (prompt) به API سرویس Reve ارسال کرده و تصویر تولیدشده را بازمی‌گرداند، همراه با کنترل نسبت ابعاد و پس‌پردازش اختیاری مانند بزرگ‌نمایی و حذف پس‌زمینه. این گره منسوخ شده است.

## ورودی‌ها

### ورودی‌های مشترک

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `مدل` | نسخه مدل مورد استفاده برای تولید. | DYNAMIC_COMBO | بله | `"reve-create@20250915"` |
| `پرامپت` | توضیح متنی تصویر موردنظر. حداکثر ۲۵۶۰ کاراکتر. | STRING | بله | 1 تا 2560 characters |
| `افزایش وضوح` | بزرگ‌نمایی تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. پیش‌فرض: `"disabled"`. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `حذف پس‌زمینه` | حذف پس‌زمینه از تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. پیش‌فرض: False. | BOOLEAN | خیر | N/A |
| `seed` | پارامتر `seed` کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. پیش‌فرض: ۰. | INT | خیر | 0 تا 2147483647 |

### ورودی‌های reve-create@20250915

گزینه‌های موجود زمانی که `model` روی `"reve-create@20250915"` تنظیم شده است:

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | نسبت ابعاد تصویر خروجی. | COMBO | بله | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما اعتبار بیشتری مصرف می‌کنند. پیش‌فرض: ۱. گزینه پیشرفته. | INT | خیر | 1 تا 5 |

### ورودی‌های بزرگ‌نمایی

گزینه‌های موجود زمانی که `upscale` روی `"enabled"` تنظیم شده است:

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `upscale_factor` | ضریب بزرگ‌نمایی (۲ برابر، ۳ برابر، یا ۴ برابر). پیش‌فرض: ۲. | INT | خیر | 2 تا 4 |

**نکته:** پارامتر `seed` خروجی‌های قطعی را تضمین نمی‌کند. پارامتر `upscale` کنترل می‌کند که آیا بزرگ‌نمایی به عنوان مرحله پس‌پردازش اعمال شود و ممکن است هزینه اضافی داشته باشد. `prompt` باید بین 1 تا 2560 کاراکتر باشد.
