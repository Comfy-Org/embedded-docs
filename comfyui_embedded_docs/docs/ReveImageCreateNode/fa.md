# ایجاد تصویر با Reve

گره Reve Image Create با استفاده از مدل Reve AI از یک توصیف متنی تصویر تولید می‌کند. این گره پرامپت را به Reve API ارسال می‌کند و تصویر حاصل را بازمی‌گرداند، همراه با پس‌پردازش اختیاری برای بزرگ‌نمایی و حذف پس‌زمینه. این گره منسوخ شده است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `مدل` | نسخه مدل مورد استفاده برای تولید. | DYNAMIC_COMBO | بله | `"reve-create@20250915"` |
| `پرامپت` | توصیف متنی تصویر مورد نظر. حداکثر 2560 کاراکتر. پیش‌فرض: `""` (خالی). | STRING | بله | 1 تا 2560 کاراکتر |
| `افزایش وضوح` | تصویر تولیدشده را بزرگ‌نمایی می‌کند. ممکن است هزینه اضافی ایجاد کند. پیش‌فرض: `"disabled"`. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `حذف پس‌زمینه` | پس‌زمینه را از تصویر تولیدشده حذف می‌کند. ممکن است هزینه اضافی ایجاد کند. پیش‌فرض: False. | BOOLEAN | خیر | N/A |
| `seed` | پارامتر `seed` کنترل می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به مقدار `seed` غیرقطعی هستند. پیش‌فرض: 0. | INT | خیر | 0 تا 2147483647 |

### ورودی‌های reve-create@20250915

گزینه‌های موجود وقتی `model` روی `"reve-create@20250915"` تنظیم شده است:

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | نسبت ابعاد تصویر خروجی. | COMBO | بله | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما اعتبار بیشتری مصرف می‌کنند. پیش‌فرض: 1. گزینه پیشرفته. | INT | خیر | 1 تا 5 |

### ورودی‌های بزرگ‌نمایی

گزینه‌های موجود وقتی `upscale` روی `"enabled"` تنظیم شده است:

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `upscale_factor` | ضریب بزرگ‌نمایی (2x، 3x یا 4x). پیش‌فرض: 2. | INT | خیر | 2 تا 4 |

**توجه:** `prompt` باید بین 1 تا 2560 کاراکتر باشد. ورودی `upscale_factor` تنها زمانی نمایش داده می‌شود که `upscale` روی `"enabled"` تنظیم شده باشد. پارامتر `seed` خروجی‌های قطعی را تضمین نمی‌کند — نتایج بدون توجه به مقدار `seed` غیرقطعی هستند. هر دو `upscale` و `remove_background` ممکن است هزینه اضافی ایجاد کنند.
