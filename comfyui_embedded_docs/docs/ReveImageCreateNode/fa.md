# ایجاد تصویر با Reve

گره Reve Image Create با استفاده از مدل هوش مصنوعی Reve تصاویری را از توضیحات متنی تولید می‌کند. این گره یک متن prompt را به Reve API ارسال کرده و تصویر تولیدشده را بازمی‌گرداند. می‌توانید نسبت ابعاد تصویر را کنترل کرده و افکت‌های پس‌پردازش اختیاری مانند افزایش مقیاس و حذف پس‌زمینه را اعمال کنید. این گره منسوخ شده است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدلی که برای تولید استفاده می‌شود. انتخاب این مدل، تنظیمات `aspect_ratio` و `test_time_scaling` را نمایان می‌کند. | DYNAMIC_COMBO | بله | `"reve-create@20250915"` |
| `prompt` | توضیح متنی تصویر موردنظر. حداکثر ۲۵۶۰ کاراکتر. پیش‌فرض: خالی. | STRING | بله | N/A |
| `seed` | seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از seed قطعی نیستند. پیش‌فرض: ۰. | INT | خیر | 0 تا 2147483647 |
| `upscale` | افزایش مقیاس تصویر تولیدشده. ممکن است هزینه‌ی اضافی به همراه داشته باشد. وقتی روی `enabled` تنظیم شود، تنظیم `upscale_factor` ظاهر می‌شود. پیش‌فرض: `disabled`. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `remove_background` | پس‌زمینه را از تصویر تولیدشده حذف می‌کند. ممکن است هزینه‌ی اضافی به همراه داشته باشد. پیش‌فرض: false. | BOOLEAN | خیر | true<br>false |

### ورودی‌های reve-create@20250915

این تنظیمات زمانی ظاهر می‌شوند که `model` روی `"reve-create@20250915"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | نسبت ابعاد تصویر خروجی. | COMBO | بله | `"3:2"`<br>`"16:9"`<br>`"9:16"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما اعتبار بیشتری هزینه دارند. پیش‌فرض: ۱. | INT | خیر | 1 تا 5 |

### ورودی‌های افزایش مقیاس

این تنظیمات زمانی ظاهر می‌شوند که `upscale` روی `"enabled"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | ضریب افزایش مقیاس (۲ برابر، ۳ برابر یا ۴ برابر). پیش‌فرض: ۲. | INT | خیر | 2 تا 4 (گام 1) |

**توجه:** پارامتر `seed` خروجی‌های قطعی را تضمین نمی‌کند. پارامتر `upscale` کنترل می‌کند که آیا افزایش مقیاس به‌عنوان یک مرحله پس‌پردازش اعمال شود یا خیر.
