# WanTrackToVideo

הצומת WanTrackToVideo ממיר נתוני מעקב תנועה לרצפי וידאו על ידי עיבוד נקודות מעקב ויצירת פריימי וידאו מתאימים. הוא מקבל קואורדינטות מעקב כקלט ומפיק התניית וידאו וייצוגי latent שניתן להשתמש בהם ליצירת וידאו. כאשר לא מסופקים נתוני מעקב, הוא עובר למצב המרת תמונה לווידאו רגילה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | התניה חיובית ליצירת וידאו | CONDITIONING | כן | - |
| `negative` | התניה שלילית ליצירת וידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE לקידוד ופענוח | VAE | כן | - |
| `tracks` | נתוני מעקב בפורמט JSON כמחרוזת מרובת שורות (ברירת מחדל: "[]"). כל מסלול ממולא או מקוצר לאורך קבוע של 121 נקודות. | STRING | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו הפלט (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הסרטונים ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `temperature` | פרמטר טמפרטורה עבור הטלאת תנועה (ברירת מחדל: 220.0, צעד: 0.1). הגדרה מתקדמת. | FLOAT | כן | 1.0 עד 1000.0 |
| `topk` | ערך Top-k עבור הטלאת תנועה (ברירת מחדל: 2). הגדרה מתקדמת. | INT | כן | 1 עד 10 |
| `start_image` | תמונת התחלה ליצירת וידאו | IMAGE | לא | - |
| `clip_vision_output` | פלט CLIP vision להתניה נוספת | CLIP_VISION_OUTPUT | לא | - |

**הערה:** כאשר `tracks` מכיל נתוני מעקב תקינים, הצומת מעבד מסלולי תנועה כדי ליצור וידאו. כאשר `tracks` ריק, הוא עובר למצב תמונה לווידאו רגיל. אם מסופק `start_image`, הוא מאתחל את הפריים הראשון של רצף הווידאו, ותוצאת הטלאת התנועה מתווספת גם להתניה החיובית וגם להתניה השלילית. אם מסופק `clip_vision_output`, הוא מתווסף גם להתניה החיובית וגם להתניה השלילית.
