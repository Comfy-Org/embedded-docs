# WanTrackToVideo

Узел WanTrackToVideo использует данные отслеживания движения (траектории точек) для управления генерацией видео. Он обрабатывает треки, при необходимости объединяет их со стартовым изображением и формирует положительное и отрицательное кондиционирование, а также латентный тензор для видеомодели Wan. Если допустимые треки не предоставлены, узел выполняет стандартное преобразование изображения в видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование для генерации видео | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование для генерации видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования видеокадров | VAE | Да | - |
| `tracks` | Данные отслеживания в формате JSON в виде многострочной строки (по умолчанию: "[]") | STRING | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в выходном видео (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `temperature` | Расширенный температурный параметр для подбора движения (по умолчанию: 220.0, шаг: 0.1) | FLOAT | Да | 1.0 to 1000.0 |
| `topk` | Расширенное значение top-k для подбора движения (по умолчанию: 2) | INT | Да | 1 to 10 |
| `start_image` | Стартовое изображение, используемое для первого кадра генерации видео | IMAGE | Да | - |
| `clip_vision_output` | Выход CLIP vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |

**Примечания:**
- Вход `tracks` ожидает JSON-строку или список JSON-строк, содержащих данные отслеживания точек. Если `tracks` пуст или не может быть разобран, узел использует поведение WanImageToVideo.
- Когда указано `start_image`, оно масштабируется до значений `width` и `height` и используется как первый кадр видеопоследовательности.
- Когда указано `clip_vision_output`, оно добавляется и к положительному, и к отрицательному кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование с применёнными данными отслеживания движения и, при необходимости, информацией об изображении | CONDITIONING |
| `negative` | Отрицательное кондиционирование с применёнными данными отслеживания движения и, при необходимости, информацией об изображении | CONDITIONING |
| `latent` | Заполненный нулями латентный тензор, размерность которого соответствует запрошенным размерам видео, длине и размеру пакета | LATENT |
