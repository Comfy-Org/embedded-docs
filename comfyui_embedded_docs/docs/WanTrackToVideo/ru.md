# WanTrackToVideo

Узел WanTrackToVideo преобразует данные отслеживания движения в видеопоследовательности, обрабатывая точки траекторий и генерируя соответствующие видеокадры. На вход он принимает координаты отслеживания и создаёт кондиционирование видео и латентные представления, которые можно использовать для генерации видео. Если треки не заданы, узел возвращается к стандартному преобразованию изображения в видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование для генерации видео | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование для генерации видео | CONDITIONING | Да | - |
| `vae` | VAE-модель для кодирования и декодирования | VAE | Да | - |
| `tracks` | Данные отслеживания в формате JSON в виде многострочной строки (по умолчанию: "[]"). Каждый трек дополняется или обрезается до фиксированной длины в 121 точку. | STRING | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в выходном видео (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `temperature` | Температурный параметр для подбора движения (по умолчанию: 220.0, шаг: 0.1) | FLOAT | Да | 1.0 до 1000.0 |
| `topk` | Значение top-k для подбора движения (по умолчанию: 2) | INT | Да | 1 до 10 |
| `start_image` | Начальное изображение для генерации видео | IMAGE | Нет | - |
| `clip_vision_output` | Выход CLIP Vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Когда `tracks` содержит допустимые данные отслеживания, узел обрабатывает траектории движения для генерации видео. Когда `tracks` пуст, узел переключается в стандартный режим преобразования изображения в видео. Если задано `start_image`, оно инициализирует первый кадр видеопоследовательности, а результат подбора движения добавляется и к положительному, и к отрицательному кондиционированию. Если задан `clip_vision_output`, он также добавляется к положительному и отрицательному кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Положительное кондиционирование с применённой информацией о траекториях движения | CONDITIONING |
| `негативный` | Отрицательное кондиционирование с применённой информацией о траекториях движения | CONDITIONING |
| `латентный` | Сгенерированное латентное представление видео | LATENT |
