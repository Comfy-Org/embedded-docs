# Wan 追蹤轉影片

WanTrackToVideo 節點透過處理追蹤點並產生對應的影片幀，將動作追蹤資料轉換為影片序列。它將追蹤座標作為輸入，並產生可用於影片生成的影片條件與潛在表示。當未提供追蹤資料時，它會改為標準的圖像轉影片轉換。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `正向` | 用於影片生成的正向條件 | CONDITIONING | 是 | - |
| `負向` | 用於影片生成的負向條件 | CONDITIONING | 是 | - |
| `VAE` | 用於編碼和解碼的 VAE 模型 | VAE | 是 | - |
| `追蹤` | 以多行字串表示的 JSON 格式追蹤資料（預設值："[]"）。每條軌道會填充或截斷至固定長度 121 點。 | STRING | 是 | - |
| `寬度` | 輸出影片寬度（像素）（預設值：832，步長：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 輸出影片高度（像素）（預設值：480，步長：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `長度` | 輸出影片的幀數（預設值：81，步長：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 同時生成的影片數量（預設值：1） | INT | 是 | 1 至 4096 |
| `溫度` | 動作修補的溫度參數（預設值：220.0，步長：0.1） | FLOAT | 是 | 1.0 至 1000.0 |
| `TopK` | 動作修補的 Top-k 值（預設值：2） | INT | 是 | 1 至 10 |
| `起始影像` | 用於影片生成的起始圖像 | IMAGE | 否 | - |
| `CLIP 視覺輸出` | 用於提供額外條件的 CLIP 視覺輸出 | CLIP_VISION_OUTPUT | 否 | - |

**注意：** 當 `tracks` 包含有效的追蹤資料時，此節點會處理動作軌道以生成影片。當 `tracks` 為空時，它會切換為標準的圖像轉影片模式。如果提供了 `start_image`，它會初始化影片序列的第一幀，並將動作修補結果添加到正向和負向條件中。如果提供了 `clip_vision_output`，它也會被添加到正向和負向條件中。
