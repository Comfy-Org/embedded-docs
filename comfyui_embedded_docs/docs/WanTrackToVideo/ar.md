# تتبع_الفيديو

تقوم عقدة WanTrackToVideo بتحويل بيانات تتبع الحركة إلى تسلسلات فيديو من خلال معالجة نقاط التتبع وتوليد إطارات الفيديو المقابلة. تأخذ إحداثيات التتبع كمدخل وتنتج تمثيلات تهيئة وكامنة للفيديو يمكن استخدامها لتوليد الفيديو. عندما لا يتم توفير أي مسارات، تعود إلى تحويل الصورة-إلى-فيديو القياسي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التهيئة الموجبة لتوليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | التهيئة السالبة لتوليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE للتشفير وفك التشفير | VAE | نعم | - |
| `مسارات` | بيانات التتبع بتنسيق JSON كسلسلة متعددة الأسطر (الافتراضي: "[]"). يتم حشو كل مسار أو قصّه إلى طول ثابت يبلغ 121 نقطة. | STRING | نعم | - |
| `عرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `ارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `طول` | عدد الإطارات في الفيديو الناتج (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم_الدفعة` | عدد الفيديوهات المولّدة في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `درجة_الحرارة` | معامل درجة الحرارة لترقيع الحركة (الافتراضي: 220.0، الخطوة: 0.1) | FLOAT | نعم | 1.0 إلى 1000.0 |
| `أعلى_ك` | قيمة Top-k لترقيع الحركة (الافتراضي: 2) | INT | نعم | 1 إلى 10 |
| `صورة_البداية` | الصورة البادئة لتوليد الفيديو | IMAGE | لا | - |
| `مخرج_رؤية_المقطع` | مخرج رؤية CLIP لتهيئة إضافية | CLIP_VISION_OUTPUT | لا | - |

**ملاحظة:** عندما تحتوي `tracks` على بيانات تتبع صالحة، تقوم العقدة بمعالجة مسارات الحركة لتوليد الفيديو. عندما تكون `tracks` فارغة، تتحول إلى وضع الصورة-إلى-فيديو القياسي. إذا تم توفير `start_image`، فإنه يهيئ الإطار الأول من تسلسل الفيديو، وتُضاف نتيجة ترقيع الحركة إلى كل من التهيئة الموجبة والسالبة. إذا تم توفير `clip_vision_output`، فإنه يُضاف أيضًا إلى كل من التهيئة الموجبة والسالبة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | تهيئة موجبة مع تطبيق معلومات مسار الحركة | CONDITIONING |
| `سلبي` | تهيئة سالبة مع تطبيق معلومات مسار الحركة | CONDITIONING |
| `كامن` | تمثيل كامن للفيديو المولّد | LATENT |
