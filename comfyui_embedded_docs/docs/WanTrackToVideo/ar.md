# تتبع_الفيديو

تستخدم عقدة WanTrackToVideo بيانات تتبع الحركة (مسارات النقاط) لتوجيه توليد الفيديو. تقوم بمعالجة المسارات، وتدمجها اختياريًا مع صورة البداية، وتنتج مخرجات تكييف إيجابية وسلبية بالإضافة إلى موتر كامن لنموذج Wan للفيديو. عندما لا يتم توفير مسارات صالحة، تعود إلى التحويل القياسي من صورة إلى فيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التكييف الإيجابي لتوليد الفيديو | CONDITIONING | نعم | - |
| `negative` | التكييف السلبي لتوليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير إطارات الفيديو | VAE | نعم | - |
| `tracks` | بيانات تتبع بتنسيق JSON كسلسلة نصية متعددة الأسطر (الافتراضي: "[]") | STRING | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو الناتج (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات المولدة في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `temperature` | معامل درجة الحرارة المتقدم لترقيع الحركة (الافتراضي: 220.0، الخطوة: 0.1) | FLOAT | نعم | 1.0 إلى 1000.0 |
| `topk` | قيمة top-k المتقدمة لترقيع الحركة (الافتراضي: 2) | INT | نعم | 1 إلى 10 |
| `start_image` | صورة البداية المستخدمة للإطار الأول من توليد الفيديو | IMAGE | نعم | - |
| `clip_vision_output` | مخرجات رؤية CLIP لتكييف إضافي | CLIP_VISION_OUTPUT | لا | - |

**ملاحظات:**

- تتوقع مدخلات `tracks` سلسلة JSON أو قائمة من سلاسل JSON تحتوي على بيانات تتبع النقاط. إذا كانت `tracks` فارغة أو تعذر تحليلها، تعود العقدة إلى سلوك WanImageToVideo.
- عند وجود `start_image`، يتم تغيير حجمه ليطابق `width` و `height` ويُستخدم كإطار أول من تسلسل الفيديو.
- عند توفير `clip_vision_output`، يُضاف إلى كل من التكييف الإيجابي والسلبي.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي مع تطبيق مسار الحركة ومعلومات الصورة الاختيارية | CONDITIONING |
| `negative` | التكييف السلبي مع تطبيق مسار الحركة ومعلومات الصورة الاختيارية | CONDITIONING |
| `latent` | موتر كامن معبأ بالأصفار بحجم يتوافق مع أبعاد الفيديو وطوله وحجم الدفعة المطلوبة | LATENT |
