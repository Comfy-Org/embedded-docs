# WanTrackToVideo

گره WanTrackToVideo داده‌های ردیابی حرکت را با پردازش نقاط ردیابی و تولید فریم‌های ویدیویی متناظر به دنباله‌های ویدیویی تبدیل می‌کند. این گره مختصات ردیابی را به عنوان ورودی دریافت کرده و بازنمایی‌های شرطی‌سازی ویدیو (conditioning) و نهفته (latent) تولید می‌کند که می‌توانند برای تولید ویدیو استفاده شوند. وقتی هیچ ردیابی‌ای ارائه نشود، به تبدیل استاندارد تصویر به ویدیو بازمی‌گردد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | شرط مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `منفی` | شرط منفی برای تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری و رمزگشایی | VAE | بله | - |
| `ترک‌ها` | داده‌های ردیابی با قالب JSON به صورت رشته چندخطی (پیش‌فرض: "[]"). هر مسیر ردیابی تا طول ثابت ۱۲۱ نقطه تکمیل یا برش می‌خورد. | STRING | بله | - |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیوی خروجی (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه بچ` | تعداد ویدیوهایی که به طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `دمای تصادفی‌سازی` | پارامتر دما برای وصله‌کردن حرکت (پیش‌فرض: 220.0، گام: 0.1) | FLOAT | بله | 1.0 تا 1000.0 |
| `topk` | مقدار Top-k برای وصله‌کردن حرکت (پیش‌فرض: 2) | INT | بله | 1 تا 10 |
| `تصویر شروع` | تصویر شروع برای تولید ویدیو | IMAGE | خیر | - |
| `خروجی clip vision` | خروجی vision مدل CLIP برای شرطی‌سازی اضافی | CLIP_VISION_OUTPUT | خیر | - |

**نکته:** وقتی `tracks` حاوی داده‌های ردیابی معتبر باشد، گره مسیرهای حرکت را پردازش کرده و ویدیو تولید می‌کند. وقتی `tracks` خالی باشد، به حالت استاندارد تصویر به ویدیو تغییر می‌کند. اگر `start_image` ارائه شود، فریم اول دنباله ویدیو مقداردهی می‌شود و نتیجه وصله‌کردن حرکت به هر دو شرط مثبت و منفی اضافه می‌شود. اگر `clip_vision_output` ارائه شود، آن نیز به هر دو شرط مثبت و منفی اضافه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرط مثبت با اطلاعات مسیر حرکت اعمال‌شده | CONDITIONING |
| `منفی` | شرط منفی با اطلاعات مسیر حرکت اعمال‌شده | CONDITIONING |
| `latent` | بازنمایی نهفته ویدیوی تولیدشده | LATENT |
