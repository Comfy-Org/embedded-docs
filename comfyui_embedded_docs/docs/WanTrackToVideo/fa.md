# WanTrackToVideo

گره WanTrackToVideo از داده‌های ردیابی حرکت (مسیرهای نقطه‌ای) برای هدایت تولید ویدیو استفاده می‌کند. این گره مسیرها را پردازش می‌کند، در صورت وجود آن‌ها را با یک تصویر شروع ترکیب می‌کند و خروجی‌های مثبت و منفی شرطی‌شده به همراه یک تنسور نهان برای مدل ویدیویی Wan تولید می‌کند. وقتی هیچ مسیر معتبری ارائه نشود، به تبدیل استاندارد تصویر به ویدیو بازمی‌گردد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی برای تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری فریم‌های ویدیو | VAE | بله | - |
| `tracks` | داده‌های ردیابی با فرمت JSON به صورت رشته چندخطی (پیش‌فرض: "[]") | STRING | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی خروجی (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `temperature` | پارامتر پیشرفته دما برای وصله‌کردن حرکت (پیش‌فرض: 220.0، گام: 0.1) | FLOAT | بله | 1.0 تا 1000.0 |
| `topk` | مقدار پیشرفته top-k برای وصله‌کردن حرکت (پیش‌فرض: 2) | INT | بله | 1 تا 10 |
| `start_image` | تصویر شروع که برای اولین فریم تولید ویدیو استفاده می‌شود | IMAGE | بله | - |
| `clip_vision_output` | خروجی CLIP vision برای شرطی‌سازی اضافی | CLIP_VISION_OUTPUT | خیر | - |

**نکات:**
- ورودی `tracks` یک رشته JSON یا فهرستی از رشته‌های JSON حاوی داده‌های ردیابی نقطه‌ای را می‌پذیرد. اگر `tracks` خالی باشد یا قابل تجزیه نباشد، گره به رفتار WanImageToVideo بازمی‌گردد.
- وقتی `start_image` وجود داشته باشد، برای مطابقت با `width` و `height` تغییر اندازه می‌دهد و به عنوان اولین فریم دنباله ویدیو استفاده می‌شود.
- وقتی `clip_vision_output` ارائه شود، به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت با اعمال مسیر حرکت و اطلاعات تصویر اختیاری | CONDITIONING |
| `negative` | شرطی‌سازی منفی با اعمال مسیر حرکت و اطلاعات تصویر اختیاری | CONDITIONING |
| `latent` | تنسور نهان صفرپرشده با اندازه متناسب با ابعاد، طول و اندازه دسته درخواستی ویدیو | LATENT |
