# PiD Conditioning

Прикрепляет скрытое изображение и значение сигмы ухудшения к данным CONDITIONING. Это используется для декодирования PiD (Pixel-in-Detail) или увеличения масштаба, позволяя контролировать степень ухудшения скрытого изображения перед обработкой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Данные кондиционирования, к которым прикрепляются скрытое изображение и сигма ухудшения. | CONDITIONING | Да | - |
| `latent` | Скрытое изображение (из VAEEncode или KSampler), которое нужно прикрепить к кондиционированию. | LATENT | Да | - |
| `latent_format` | Формат скрытого изображения. Скрытые изображения Flux1 (16-канальные) и Flux2 (128-канальные) автоматически определяются по размерности каналов при значении "flux". Для SD3 (16-канальные), SDXL (4-канальные) или QwenImage (16-канальные) выберите вручную (по умолчанию: "flux"). | COMBO | Да | `"flux"`<br>`"sd3"`<br>`"sdxl"`<br>`"qwenimage"` |
| `degrade_sigma` | 0 = чистое скрытое изображение. Увеличьте, чтобы уменьшить шум поврежденных выходных скрытых изображений (по умолчанию: 0.0). | FLOAT | Да | 0.0 to 1.0 (step: 0.01) |

Примечание: Когда `latent_format` равен "flux", узел автоматически определяет, является ли скрытое изображение Flux1 (16 каналов) или Flux2 (128 каналов) по его размерности каналов. Если обработанное скрытое изображение имеет 5 измерений, используется только первый срез по последнему измерению.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Исходные данные кондиционирования с прикрепленными скрытым изображением и значениями сигмы ухудшения. | CONDITIONING |
