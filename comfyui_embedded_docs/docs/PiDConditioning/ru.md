# PiD Conditioning

Прикрепляет латентное представление и значение сигмы деградации к данным CONDITIONING. Это используется для декодирования PiD (Pixel-in-Detail) или увеличения разрешения, позволяя управлять степенью деградации латентного представления перед обработкой.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Данные CONDITIONING, к которым необходимо прикрепить латентное представление и сигму деградации. | CONDITIONING | Да | - |
| `latent` | Латентное представление (из VAEEncode или KSampler), прикрепляемое к данным CONDITIONING. | LATENT | Да | - |
| `latent_format` | Формат латентного представления. Латентные представления Flux1 (16-канальные) и Flux2 (128-канальные) автоматически определяются по размерности каналов при значении `"flux"`. Для SD3 (16-канальных), SDXL (4-канальных) или QwenImage (16-канальных) выберите вручную (по умолчанию: `"flux"`). | COMBO | Да | `"flux"`<br>`"sd3"`<br>`"sdxl"`<br>`"qwenimage"` |
| `degrade_sigma` | Степень применяемой деградации. Значение 0 означает чистое латентное представление. Увеличьте это значение, чтобы убрать шум из повреждённых выходных латентных представлений (по умолчанию: 0.0). | FLOAT | Да | 0.0–1.0 (шаг: 0.01) |

Примечание: когда для `latent_format` задано значение `"flux"`, узел автоматически определяет тип латентного представления по размерности каналов: 128 каналов рассматриваются как латентные представления Flux2, а 16 каналов — как латентные представления Flux1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Исходные данные CONDITIONING с прикреплёнными латентным представлением и значением сигмы деградации. | CONDITIONING |
