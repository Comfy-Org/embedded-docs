# PiD Conditioning

Прикрепляет латент и значение `degrade_sigma` к CONDITIONING, чтобы их можно было использовать для декодирования PiD или апскейлинга. Это позволяет управлять степенью деградации латента перед его обработкой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Данные CONDITIONING, к которым нужно прикрепить латент и sigma деградации. | CONDITIONING | Да | - |
| `latent` | Латент (из VAEEncode или KSampler), который нужно прикрепить к CONDITIONING. | LATENT | Да | - |
| `latent_format` | Формат латента. Латенты Flux1 (16 каналов) и Flux2 (128 каналов) автоматически определяются по размерности каналов при значении "flux". Для SD3 (16 каналов), SDXL (4 канала) или QwenImage (16 каналов) выберите вручную (по умолчанию: "flux"). | COMBO | Да | `"flux"`<br>`"sd3"`<br>`"sdxl"`<br>`"qwenimage"` |
| `degrade_sigma` | Величина применяемой деградации. 0 означает чистый латент. Увеличьте это значение, чтобы очистить от шума повреждённые выходные латенты (по умолчанию: 0.0). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |

Примечание. Когда для `latent_format` задано значение `"flux"`, узел автоматически определяет тип латента по размерности каналов: 128 каналов рассматриваются как латенты Flux2, а 16 каналов — как латенты Flux1.

Примечание. Неподдерживаемое значение `latent_format` вызывает ошибку, но все доступные варианты обрабатываются узлом.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Исходные данные CONDITIONING с прикреплённым латентом и значением sigma деградации. | CONDITIONING |
