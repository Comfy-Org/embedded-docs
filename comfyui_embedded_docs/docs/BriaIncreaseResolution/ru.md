# Bria: увеличение разрешения

Bria Increase Resolution масштабирует входное изображение с коэффициентом 2x или 4x, используя сервис увеличения изображений Bria, сохраняя исходное содержимое. Узел загружает изображение, отправляет его на обработку в сервис Bria, ожидает результата и возвращает изображение с увеличенным разрешением.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для увеличения разрешения. | IMAGE | Да | Одно изображение |
| `desired_increase` | Множитель разрешения. Выходное изображение должно укладываться в 8192 пикселя по каждой стороне. | COMBO | Да | "2"<br>"4" |
| `auto_downscale` | Автоматически снижает множитель и уменьшает входное изображение, если этого всё ещё недостаточно, когда выходное изображение превысило бы ограничение. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `модерация` | Настройки модерации. При значении "true" включаются подпараметры `visual_input_moderation` и `visual_output_moderation`, оба по умолчанию имеют значение False. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Примечания:
- Когда для `moderation` установлено значение "true", становятся доступны подпараметры `visual_input_moderation` и `visual_output_moderation`, оба по умолчанию имеют значение False. Они управляют модерацией входного изображения и содержимого выходного изображения.
- Узел ограничивает максимальную сторону выходного изображения значением 8192 пикселя. Если выбранный множитель превышает это ограничение, а `auto_downscale` отключён, возникает ошибка. Включение `auto_downscale` позволяет узлу автоматически использовать меньший множитель или вместо этого уменьшить входное изображение.
- Перед увеличением разрешения Bria сначала увеличивает короткую сторону входного изображения как минимум до 224 пикселей. Слишком вытянутые изображения могут вызвать ошибку с предложением обрезать их до более квадратной формы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение с увеличенным разрешением, возвращённое сервисом Bria. | IMAGE |
