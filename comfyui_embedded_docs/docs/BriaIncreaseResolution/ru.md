# BriaIncreaseResolution

Bria Increase Resolution увеличивает входное изображение в 2 или 4 раза с помощью сервиса увеличения разрешения Bria, сохраняя исходное содержимое. Узел загружает изображение, обрабатывает его в сервисе Bria и возвращает увеличенное изображение в качестве результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для увеличения разрешения. | IMAGE | Да | Одиночное изображение |
| `desired_increase` | Множитель разрешения. Результат должен умещаться в пределах 8192 пикселей по каждой стороне. | COMBO | Да | "2"<br>"4" |
| `auto_downscale` | Автоматически снижать множитель, а если этого всё ещё недостаточно, уменьшать входное изображение, когда результат превышает ограничение. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `модерация` | Настройки модерации. Если задано значение «true», становятся доступны под-опции `visual_input_moderation` и `visual_output_moderation`, обе по умолчанию False. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Примечания:
- Если для параметра `moderation` задано значение «true», становятся доступны под-опции `visual_input_moderation` и `visual_output_moderation`, обе по умолчанию False. Они управляют модерацией содержимого входного и выходного изображения.
- Узел обеспечивает максимальный размер выходной стороны 8192 пикселей. Если выбранный множитель превышает это ограничение, а `auto_downscale` отключён, возникает ошибка. Включение `auto_downscale` позволяет узлу автоматически использовать меньший множитель или уменьшить входное изображение.
- Bria сначала увеличивает короткую сторону входного изображения минимум до 224 пикселей перед увеличением разрешения. Слишком вытянутые изображения могут вызвать ошибку с требованием обрезать их до более квадратной формы.
