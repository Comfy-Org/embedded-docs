# BriaIncreaseResolution

Bria Increase Resolution увеличивает входное изображение в 2 или 4 раза с помощью API масштабирования Bria, сохраняя исходное содержимое. Нод загружает изображение, обрабатывает его в сервисе Bria и возвращает увеличенное изображение.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для масштабирования. | IMAGE | Да | Single image |
| `desired_increase` | Множитель разрешения. Выходное изображение должно помещаться в пределах 8192 пикселей по каждой стороне. | COMBO | Да | "2"<br>"4" |
| `auto_downscale` | Автоматически снижать множитель и уменьшать входное изображение, если этого все еще недостаточно, когда выходной размер превышает лимит. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `moderation` | Настройки модерации. Если установлено значение "true", включает подопции `visual_input_moderation` и `visual_output_moderation`, обе по умолчанию False. | COMBO | Да | "false"<br>"true" |

Примечания:
- Нод обеспечивает максимальный размер стороны выходного изображения 8192 пикселя. Если выбранный множитель превысит этот предел, а `auto_downscale` отключен, будет вызвана ошибка. Включение `auto_downscale` позволяет ноду автоматически использовать меньший множитель или вместо этого уменьшить входное изображение.
- Bria сначала увеличивает короткую сторону входного изображения как минимум до 224 пикселей перед масштабированием. Слишком вытянутые изображения могут вызвать ошибку с запросом обрезать их до более квадратной формы.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Увеличенное изображение, возвращенное API Bria. | IMAGE |
