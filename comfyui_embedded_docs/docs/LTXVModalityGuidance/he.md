# LTXVModalityGuidance

צומת זה מחיל הנחיה חוצת-מודאליות (אודיו-וידאו) על מודל LTXV-AV. במהלך הדגימה, הוא מריץ מעבר קדימה נוסף אחד בכל צעד כאשר חיבורי הקשב הצולב אודיו-לווידאו ווידאו-לאודיו מושבתים, ואז דוחף את התוצאה לעבר החיזוי המצומד כדי לחזק סנכרון אודיו-חזותי, כגון סנכרון שפתיים. ברירת המחדל הייחוסית עבור `modality_scale` היא 3.0; הגדרה שלה ל-1.0 משביתה את המעבר הנוסף, והיא מצטברת עם dual-CFG guider ועם STG.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל הבסיסי שעליו תיושם הנחיית המודאליות. הוא משוכפל פנימית, כך שהמודל המקורי נשאר ללא שינוי. | MODEL | כן | - |
| `modality_scale` | עוצמת הנחיית הצימוד אודיו-וידאו. ברירת המחדל היא 3.0. יש להגדיר 1.0 כדי להשבית את מעבר הקדימה הנוסף. | FLOAT | כן | 1.0 עד 100.0 (ברירת מחדל: 3.0) |
| `start_percent` | הנקודה בתהליך הדגימה, כאחוז מ-0.0 עד 1.0, שבה מתחילה הנחיית המודאליות. זהו פרמטר מתקדם. ברירת המחדל היא 0.0. | FLOAT | כן | 0.0 עד 1.0 (ברירת מחדל: 0.0) |
| `end_percent` | הנקודה בתהליך הדגימה, כאחוז מ-0.0 עד 1.0, שבה מסתיימת הנחיית המודאליות. זהו פרמטר מתקדם. ברירת המחדל היא 1.0. | FLOAT | כן | 0.0 עד 1.0 (ברירת מחדל: 1.0) |

ההנחיה מיושמת רק עבור צעדי דגימה שערכי ה-sigma שלהם נמצאים בטווח המוגדר על ידי `start_percent` ו-`end_percent`. מחוץ לטווח זה, הצומת מחזיר את התוצאה המנוקה מרעש ללא שינוי. בנוסף, `modality_scale` בערך 1.0 משבית לחלוטין את מעבר הקדימה הנוסף.
