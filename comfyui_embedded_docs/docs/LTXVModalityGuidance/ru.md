# LTXVModalityGuidance

Этот узел применяет кросс-модальное (аудио-видео) управление к модели LTXV-AV. Во время сэмплирования он выполняет один дополнительный прямой проход на каждом шаге с отключенными перекрёстными связями внимания «аудио-видео» и «видео-аудио», а затем направляет результат к связанному предсказанию. Это усиливает аудиовизуальную синхронизацию, например синхронизацию губ. Базовое значение по умолчанию для `modality_scale` — 3.0; установка его в 1.0 отключает дополнительный проход.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Базовая модель, к которой будет применено модальное управление. Внутренне клонируется, оставляя исходную модель без изменений. | MODEL | Да | - |
| `modality_scale` | Сила управления аудио-видео связью. По умолчанию: 3.0. Установите 1.0, чтобы отключить дополнительный прямой проход. | FLOAT | Да | 1.0 до 100.0 (default: 3.0) |
| `start_percent` | Точка в процессе сэмплирования, выраженная долей от 0.0 до 1.0, в которой начинается модальное управление. По умолчанию: 0.0. | FLOAT | Да | 0.0 до 1.0 (default: 0.0) |
| `end_percent` | Точка в процессе сэмплирования, выраженная долей от 0.0 до 1.0, в которой заканчивается модальное управление. По умолчанию: 1.0. | FLOAT | Да | 0.0 до 1.0 (default: 1.0) |

Управление применяется только для тех шагов сэмплирования, значения сигмы которых попадают в диапазон, определяемый параметрами `start_percent` и `end_percent`. Вне этого диапазона узел возвращает результат шумоподавления без изменений. Значение `modality_scale`, равное 1.0, также полностью отключает дополнительный прямой проход.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Клонированная модель с прикреплённой функцией управления после CFG. Эта модифицированная модель применяет модальное управление во время сэмплирования. | MODEL |
