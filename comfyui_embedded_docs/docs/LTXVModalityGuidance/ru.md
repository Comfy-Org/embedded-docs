# LTXV Modality Guidance (A/V coupling)

Этот узел применяет кросс-модальное (аудио-видео) управление к модели LTXV-AV. Во время семплирования он выполняет один дополнительный прямой проход на каждом шаге с отключенными перекрестными связями аудио-в-видео и видео-в-аудио, затем подталкивает результат к связанному предсказанию для усиления аудиовизуальной синхронизации, например, синхронизации губ. Эталонное значение по умолчанию для `modality_scale` — 3.0; установка его в 1.0 отключает дополнительный проход, и оно сочетается с направляющим устройством dual-CFG и STG.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Базовая модель, к которой будет применено модальное управление. Она клонируется внутренне, исходная модель остается неизменной. | MODEL | Да | - |
| `modality_scale` | Сила кросс-модального управления аудио-видео связью. По умолчанию 3.0. Установите 1.0, чтобы отключить дополнительный прямой проход. | FLOAT | Да | 1.0 до 100.0 (default: 3.0) |
| `start_percent` | Точка в процессе семплирования, в процентах от 0.0 до 1.0, в которой начинается модальное управление. Это дополнительный параметр. По умолчанию 0.0. | FLOAT | Да | 0.0 до 1.0 (default: 0.0) |
| `end_percent` | Точка в процессе семплирования, в процентах от 0.0 до 1.0, в которой заканчивается модальное управление. Это дополнительный параметр. По умолчанию 1.0. | FLOAT | Да | 0.0 до 1.0 (default: 1.0) |

Управление применяется только к шагам семплирования, значения сигмы которых попадают в диапазон, определяемый `start_percent` и `end_percent`. Вне этого диапазона узел возвращает результат денойзинга без изменений. Значение `modality_scale` равное 1.0 также полностью отключает дополнительный прямой проход.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `model` | Клонированная модель с прикрепленной функцией управления после CFG. Эта модифицированная модель применяет модальное управление во время семплирования. | MODEL |
