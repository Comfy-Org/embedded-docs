# Создать многослойное изображение

Этот узел объединяет несколько слоёв изображения в одно скомпонованное изображение. Он принимает стек слоёв, созданный с помощью узла Add Layer, и при необходимости применяет сохранённые настройки композиции из редактора композитинга, смешивая слои в соответствии с их размещением, размером, поворотом, непрозрачностью и режимом смешивания. Сохранённая композиция, совпадающая с текущими входами, имеет приоритет; в противном случае узел выполняет композитинг на основе свойств слоёв и помечает сохранённое состояние как устаревшее.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `слои` | Стек слоёв для композитинга; создайте его с помощью узла Add Layer. Элементы упорядочиваются по z_index, кадры пакета внутри одного элемента разворачиваются в последовательные слои, а размещение элемента, непрозрачность и режим смешивания определяют начальную композицию. Без явного холста документа размер определяется как максимально возможная протяжённость размещённых слоёв. Сохранённая композиция, совпадающая с текущими входами, имеет приоритет. | LAYERS | Да | Максимум 50 слоёв |
| `композитор` | Слоистая композиция, сохранённая редактором композитинга. | COMPOSITOR | Нет | Нет |

**Примечания по ограничениям:**

- Стек слоёв поддерживает максимум 50 развёрнутых слоёв; при передаче большего числа возникает ошибка.
- В настоящее время поддерживаются только растровые элементы слоёв; другие типы элементов вызывают ошибку.
- Версия документа `layers` должна быть 1; другие версии вызывают ошибку.
- Сохранённое состояние `compositor` воспроизводится только тогда, когда записанные отпечатки входов совпадают с текущим стеком слоёв. Если они не совпадают, узел возвращается к композитингу на основе свойств слоёв и помечает сохранённое состояние как устаревшее.
- Непрозрачность слоя ограничивается диапазоном от 0.0 до 1.0.
- Горизонтальное и вертикальное размещение слоя (`x`, `y`) ограничивается максимальным пределом разрешения.
- Ширина и высота слоя при значении ноль или меньше заменяются на естественный размер изображения и ограничиваются максимальным пределом разрешения.
- Размер холста композитинга не должен превышать максимальный предел разрешения.
- Если слои не переданы, возвращается изображение-заполнитель 64x64.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Скомпонованное изображение. Содержит альфа-канал, если в композите есть прозрачные области (например, скрытый фон), иначе обычный RGB. | IMAGE |
| `MASK` | Прозрачность композита (1 = полностью прозрачный). Все нули, когда композит непрозрачен. | MASK |
