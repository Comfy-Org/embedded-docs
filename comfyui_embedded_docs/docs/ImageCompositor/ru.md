# ImageCompositor

Этот узел объединяет несколько слоев изображения в одно композитное изображение. Он принимает стек слоев, созданный с помощью узла Add Layer, и, опционально, сохраненную композицию из редактора композитора, затем смешивает слои вместе, используя их положение, размер, поворот, непрозрачность и режим наложения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `layers` | Стек слоев для композитинга; создается с помощью Add Layer. Элементы располагаются по z_index, кадры внутри элемента расширяются в последовательные слои, а положение элемента, непрозрачность и режим наложения определяют исходную композицию. При отсутствии явного холста документа размер вычисляется как наилучшая оценка максимальной протяженности размещенных слоев. Сохраненная композиция, соответствующая текущим входным данным, имеет приоритет. | LAYERS | Да | Maximum 50 layers |
| `compositor` | Многослойная композиция, сохраненная редактором композитора. | COMPOSITOR | Нет | None |

**Примечания по ограничениям:**

- Стек слоев поддерживает максимум 50 слоев (развернутые кадры); при передаче большего количества возникает ошибка.
- В настоящее время поддерживаются только растровые слои; другие типы элементов слоя вызывают ошибку.
- Версия документа `layers` должна быть 1; другие версии вызывают ошибку.
- Сохраненное состояние `compositor` воспроизводится только тогда, когда записанные отпечатки входных данных соответствуют текущему стеку слоев. Если они не совпадают, узел возвращается к компоновке из свойств слоев и помечает сохраненное состояние как устаревшее.
- Непрозрачность слоя ограничивается диапазоном от 0.0 до 1.0.
- Горизонтальное/вертикальное размещение слоя (`x`, `y`) ограничивается максимальным разрешением.
- Ширина и высота слоя возвращаются к естественному размеру изображения, если установлены в ноль или меньше, и ограничиваются максимальным разрешением.
- Размер композитного холста не должен превышать максимальное разрешение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Композитное изображение. Содержит альфа-канал, если композиция имеет прозрачные области (например, скрытый фон), в противном случае — обычное RGB. | IMAGE |
| `MASK` | Прозрачность композиции (1 = полностью прозрачно). Все нули, когда композиция непрозрачна. | MASK |
