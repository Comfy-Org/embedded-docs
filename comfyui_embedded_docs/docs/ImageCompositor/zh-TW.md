# 建立分層影像

此節點會將多個影像圖層合併成單一合成影像。它接收使用 Add Layer 節點建立的圖層堆疊，並可選擇性地套用來自 compositor 編輯器的已儲存合成設定，依據圖層的位置、大小、旋轉、不透明度和混合模式來混合圖層。若已儲存的合成與目前的輸入相符，則會優先採用；否則節點會根據圖層屬性進行合成，並將已儲存狀態標記為過期。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 要合成的圖層堆疊；使用 Add Layer 建立。項目會依 z_index 堆疊，項目內的批次影格會展開為連續圖層，而項目的位置、不透明度和混合模式會定義初始合成。若沒有明確的文件畫布，尺寸會以已放置圖層的最大範圍做最佳推估。符合目前輸入的已儲存合成會優先採用。 | LAYERS | 是 | 最多 50 層 |
| `compositor` | 由 compositor 編輯器儲存的圖層合成。 | COMPOSITOR | 否 | None |

**限制注意事項：**

- 圖層堆疊最多支援 50 個展開圖層；提供更多圖層會引發錯誤。
- 目前僅支援點陣圖層項目；其他項目類型會引發錯誤。
- `layers` 文件版本必須為 1；其他版本會引發錯誤。
- 只有在已記錄的輸入指紋與目前圖層堆疊相符時，才會重播已儲存的 `compositor` 狀態。若不相符，節點會退回根據圖層屬性進行合成，並將已儲存狀態標記為過期。
- 圖層不透明度會限制在 0.0 到 1.0 的範圍內。
- 圖層水平與垂直位置（`x`、`y`）會限制在最大解析度限制內。
- 當圖層寬度與高度設為零或更小值時，會退回使用自然影像尺寸，並以最大解析度限制為上限。
- 合成畫布尺寸不得超過最大解析度限制。
- 未提供任何圖層時，會傳回 64x64 的佔位影像。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `IMAGE` | 合成影像。當合成結果有透明區域（例如隱藏的背景）時會帶有 alpha 通道，否則為一般 RGB。 | IMAGE |
| `MASK` | 合成結果的透明度（1 = 完全透明）。當合成結果為不透明時，全部為零。 | MASK |
