# ImageCompositor

此節點將多個影像圖層合成為單一合成影像。它接收使用「Add Layer」節點建立的圖層堆疊，以及可選的、由合成器編輯器儲存的合成狀態，然後根據圖層的位置、大小、旋轉、不透明度和混合模式設定，將圖層混合在一起。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 要合成的圖層堆疊；使用 Add Layer 建立。項目依 z_index 堆疊，項目內部的批次幀會展開為連續圖層，而項目的位置、不透明度和混合模式則定義初始合成。若未指定明確的文件畫布，則尺寸為所放置圖層的最大範圍（盡力而為）。與目前輸入相符的已儲存合成會優先採用。 | LAYERS | 是 | Maximum 50 layers |
| `compositor` | 由合成器編輯器儲存的分層合成。 | COMPOSITOR | 否 | None |

**限制說明：**

- 圖層堆疊最多支援 50 個圖層（展開後的幀）；超過會產生錯誤。
- 目前僅支援點陣圖層；其他圖層項目類型會產生錯誤。
- `layers` 文件版本必須為 1；其他版本會產生錯誤。
- 已儲存的 `compositor` 狀態只有在錄製的輸入指紋與目前圖層堆疊相符時才會重放。若不相符，節點會退回根據圖層屬性合成，並將已儲存狀態標記為過期。
- 圖層不透明度會被限制在 0.0 到 1.0 的範圍內。
- 圖層的水平/垂直位置（`x`、`y`）會被限制在最大解析度限制內。
- 當圖層寬高設定為零或以下時，會回退為自然影像尺寸，並限制在最大解析度限制內。
- 合成畫布尺寸不得超過最大解析度限制。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| IMAGE | 合成後的影像。當合成結果含有透明區域（例如隱藏背景）時會帶有 Alpha 色版，否則為純 RGB。 | IMAGE |
| MASK | 合成結果的透明度（1 = 完全透明）。當合成結果不透明時全為零。 | MASK |
