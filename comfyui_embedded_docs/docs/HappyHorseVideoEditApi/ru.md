# HappyHorse: редактирование видео

Редактируйте видео с помощью текстовых инструкций или эталонных изображений с использованием модели HappyHorse. Продолжительность вывода составляет 3–15 секунд и соответствует входному видео; входные видео длиннее 15 секунд обрезаются.

## Входы

### Общие входы

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель редактирования видео HappyHorse. Этот выбор определяет, какие варианты подсказки, разрешения, соотношения сторон и эталонных изображений доступны. | DYNAMIC_COMBO | Да | "happyhorse-1.0-video-edit" |
| `video` | Видео для редактирования. | VIDEO | Да | 3 до 60 seconds |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | 0 до 2147483647 |
| `watermark` | Определяет, добавлять ли водяной знак, созданный ИИ, к результату (по умолчанию: False). Дополнительный параметр. | BOOLEAN | Да | True<br>False |

### Входы happyhorse-1.0-video-edit

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию или требования к переносу стиля. Должно быть не менее 1 символа. | STRING | Да | - |
| `resolution` | Выходное разрешение. | COMBO | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон. Если не изменено, аппроксимирует соотношение сторон входного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### Эталонные входы

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 0 до 5 эталонных изображений (`image1`...`image5`) для управления редактированием. | IMAGE | Нет | от 0 до 5 изображений |

**Примечание:** Входное видео должно быть длиной от 3 до 60 секунд. Продолжительность вывода составляет 3–15 секунд и соответствует входному видео; входные видео длиннее 15 секунд обрезаются. Поле `prompt` должно содержать не менее 1 символа.

## Выходы

|-------------|-------------|-----------|
