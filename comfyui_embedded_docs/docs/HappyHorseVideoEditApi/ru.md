# HappyHorse: редактирование видео

Редактируйте видео с помощью текстовых инструкций или референсных изображений, используя модель HappyHorse. Длительность выходного видео составляет 3–15 секунд и соответствует длительности входного видео; входные видео длиннее 15 секунд обрезаются.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель HappyHorse для редактирования видео. Этот выбор определяет, какие параметры промпта, разрешения, соотношения сторон и референсных изображений доступны. | DICT | Да | "happyhorse-1.0-video-edit" |
| `video` | Видео для редактирования. | VIDEO | Да | от 3 до 60 секунд |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `watermark` | Нужно ли добавлять водяной знак, сгенерированный ИИ, к результату (по умолчанию: False). | BOOLEAN | Нет | True<br>False |

### Входы happyhorse-1.0-video-edit

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию или требования к переносу стиля. Должен содержать не менее 1 символа. | STRING | Да | - |
| `resolution` | Выходное разрешение. | STRING | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон. Если не изменено, приближается к соотношению сторон входного видео. | STRING | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### Референсные входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 0 до 5 референсных изображений (`image1`...`image5`), чтобы управлять редактированием. | IMAGE | Нет | от 0 до 5 изображений |

**Примечание:** Входное видео должно быть длиной от 3 до 60 секунд. Длительность выходного видео составляет 3–15 секунд и соответствует длительности входного видео; входные видео длиннее 15 секунд обрезаются. Параметр `prompt` должен содержать не менее 1 символа.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Выходное отредактированное видео. | VIDEO |
