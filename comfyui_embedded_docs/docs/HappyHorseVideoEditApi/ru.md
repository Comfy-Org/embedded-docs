# HappyHorse: редактирование видео

Редактируйте видео с помощью текстовых инструкций или референсных изображений, используя модель HappyHorse. Длительность выходного видео составляет 3–15 секунд и соответствует длительности входного видео; входные видео длиннее 15 секунд обрезаются.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель HappyHorse для редактирования видео. Этот выбор определяет, какие параметры промпта, разрешения, соотношения сторон и референсных изображений доступны. | DYNAMIC_COMBO | Да | "happyhorse-1.0-video-edit" |
| `video` | Видео для редактирования. | VIDEO | Да | 3 to 60 seconds |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | 0 to 2147483647 |
| `watermark` | Нужно ли добавлять водяной знак, сгенерированный ИИ, к результату (по умолчанию: False). | BOOLEAN | Да | True<br>False |

### Входы happyhorse-1.0-video-edit

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Инструкции по редактированию или требования к переносу стиля. Должен содержать не менее 1 символа. | STRING | Да | - |
| `resolution` | Выходное разрешение. | COMBO | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон. Если не изменено, приближается к соотношению сторон входного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `reference_images` | Расширяемый слот: подключите от 0 до 5 референсных изображений (`image1`...`image5`), чтобы управлять редактированием. | IMAGE | Нет | 0 to 5 images |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `video` | The edited video output. | VIDEO |
