# HappyHorse 视频编辑

使用 HappyHorse 模型，通过文本指令或参考图像编辑视频。输出时长为 3-15 秒，与输入视频的时长一致；长于 15 秒的输入视频将被截断。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的 HappyHorse 视频编辑模型。此选择决定了可用的提示词、分辨率、宽高比和参考图像选项。 | DICT | 是 | "happyhorse-1.0-video-edit" |
| `video` | 要编辑的视频。 | VIDEO | 是 | 3 到 60 秒 |
| `seed` | 用于生成的种子（默认值：0）。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：False）。 | BOOLEAN | 否 | True<br>False |

### happyhorse-1.0-video-edit 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 编辑指令或风格迁移要求。长度必须至少为 1 个字符。 | STRING | 是 | - |
| `resolution` | 输出分辨率。 | STRING | 是 | "720P"<br>"1080P" |
| `ratio` | 宽高比。如果未更改，则近似于输入视频的宽高比。 | STRING | 是 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|

**注意：** 输入视频的长度必须为 3 到 60 秒。输出时长为 3-15 秒，与输入视频的时长一致；长于 15 秒的输入视频将被截断。`prompt` 的长度必须至少为 1 个字符。
