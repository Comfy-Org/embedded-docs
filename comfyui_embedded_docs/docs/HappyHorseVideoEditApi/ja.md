# HappyHorse 動画編集

以下に、提供された英語ドキュメントを日本語に翻訳しました。出力名・パラメータ名・データ型・Range列の値は原文のまま保持し、説明文は丁寧語（です・ます体）で統一しています。

HappyHorse モデルを使用して、テキスト指示または参照画像によって動画を編集します。出力の長さは 3〜15 秒で、入力動画に一致します。15 秒を超える入力は切り捨てられます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用する HappyHorse 動画編集モデルです。この選択により、利用可能なプロンプト、解像度、アスペクト比、参照画像オプションが決まります。 | DYNAMIC_COMBO | 必須 | "happyhorse-1.0-video-edit" |
| `動画` | 編集する動画です。 | VIDEO | 必須 | 3 〜 60 seconds |
| `シード` | 生成に使用するシードです（デフォルト: 0）。 | INT | 必須 | 0 〜 2147483647 |
| `ウォーターマーク` | 結果に AI 生成の透かしを追加するかどうかを指定します（デフォルト: False）。 | BOOLEAN | 必須 | True<br>False |

### happyhorse-1.0-video-edit 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編集指示またはスタイル変換の要件です。1 文字以上である必要があります。 | STRING | 必須 | - |
| `resolution` | 出力解像度です。 | COMBO | 必須 | "720P"<br>"1080P" |
| `ratio` | アスペクト比です。変更しない場合、入力動画の比率に近似します。 | COMBO | 必須 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能なスロットです。0〜5 枚の参照画像（`image1`...`image5`）を接続して、編集をガイドします。 | IMAGE | 任意 | 0 〜 5 images |

**注:** 入力動画は 3〜60 秒である必要があります。出力の長さは 3〜15 秒で、入力動画に一致します。15 秒を超える入力動画は切り捨てられます。`prompt` は 1 文字以上である必要があります。
