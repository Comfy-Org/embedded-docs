# HappyHorse 動画編集

HappyHorse モデルを使用して、テキスト指示または参照画像でビデオを編集します。出力時間は3〜15秒で、入力ビデオに一致します。15秒を超える入力は切り捨てられます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用するHappyHorseビデオ編集モデル。この選択により、利用可能なプロンプト、解像度、アスペクト比、参照画像のオプションが決まります。 | DICT | はい | "happyhorse-1.0-video-edit" |
| `動画` | 編集するビデオ。 | VIDEO | はい | 3〜60秒 |
| `シード` | 生成に使用するシード値（デフォルト: 0）。 | INT | はい | 0〜2147483647 |
| `ウォーターマーク` | 結果にAI生成の透かしを追加するかどうか（デフォルト: False）。 | BOOLEAN | いいえ | True<br>False |

### happyhorse-1.0-video-edit 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編集指示またはスタイル変換の要件。1文字以上である必要があります。 | STRING | はい | - |
| `resolution` | 出力解像度。 | STRING | はい | "720P"<br>"1080P" |
| `ratio` | アスペクト比。変更しない場合、入力ビデオのアスペクト比に近似します。 | STRING | はい | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | グローバブルスロット: 編集をガイドするために0〜5枚の参照画像（`image1`...`image5`）を接続します。 | IMAGE | いいえ | 0〜5枚 |

**注:** 入力ビデオは3〜60秒の長さである必要があります。出力時間は3〜15秒で、入力ビデオに一致します。15秒を超える入力ビデオは切り捨てられます。`prompt` は1文字以上である必要があります。

## 出力

|-------------|-------------|-----------|
| `video` | 編集されたビデオ出力。 | VIDEO |
