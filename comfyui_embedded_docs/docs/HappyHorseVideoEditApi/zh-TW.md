# HappyHorse 影片編輯

此節點使用 HappyHorse 模型，透過文字指令或參考圖片來編輯影片。輸出長度為 3-15 秒，且與輸入影片相符；超過 15 秒的輸入影片會被截斷。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的 HappyHorse 影片編輯模型。此選擇決定可用的提示詞、解析度、比例和參考圖片選項。 | DICT | 是 | "happyhorse-1.0-video-edit" |
| `video` | 要編輯的影片。 | VIDEO | 是 | 3 至 60 秒 |
| `seed` | 用於生成的種子（預設值：0）。 | INT | 是 | 0 至 2147483647 |
| `watermark` | 是否在結果中加入 AI 生成的水印（預設值：False）。 | BOOLEAN | 否 | True<br>False |

### happyhorse-1.0-video-edit 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編輯指示或風格轉換需求。長度必須至少為 1 個字元。 | STRING | 是 | - |
| `resolution` | 輸出解析度。 | STRING | 是 | "720P"<br>"1080P" |
| `ratio` | 長寬比。若未更改，則會近似輸入影片的比例。 | STRING | 是 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |

### 參考輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可擴充插槽：連接 0 到 5 張參考圖片（`image1`...`image5`）以引導編輯。 | IMAGE | 否 | 0 至 5 張圖片 |

**注意：** 輸入影片長度必須為 3 到 60 秒。輸出長度為 3-15 秒且與輸入影片相符；超過 15 秒的輸入影片會被截斷。`prompt` 長度必須至少為 1 個字元。
