# FillHoles

此節點透過偵測開放邊界邊緣並建立新面來封閉它們，從而填補 3D 網格中的孔洞。它在 GPU 上執行，保留現有的幾何形狀和 UV，並可處理單一網格、網格列表或批次網格。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要處理的 3D 網格。接受單一網格、網格列表或批次網格。 | MESH | 是 | - |
| `max_perimeter` | 要填補的最大孔洞周長。0 表示停用。（預設值：0.03） | FLOAT | 是 | 0.0 to no upper limit |
| `weld_epsilon_rel` | 預焊接容差（邊界框對角線的比例）；邊界偵測需要焊接後的頂點。0 表示跳過。（預設值：1e-5） | FLOAT | 是 | 0.0 to no upper limit |
| `max_vertices` | 每個循環的邊界頂點上限；centroid-fan 僅適用於小型近似平面的孔洞。建議 ≤16。（預設值：16） | INT | 是 | 3 至 1024 |
| `fill_chains` | 同時填補開放鏈（而不僅是循環）。容易產生雜訊；關閉時與 cumesh 行為一致。（預設值：False） | BOOLEAN | 是 | True or False |

注意：當 `weld_epsilon_rel` 大於 0 時，節點會在偵測孔洞前預先焊接重複的頂點。焊接容差從指定的邊界框對角線比例開始，並自動加倍增加，直到網格被視為已焊接或容差達到 1e-2 的上限。邊界頂點數多於 8 個的孔洞使用質心扇形填充（插入新的質心頂點），而較小的孔洞則使用頂點扇形填充，重用現有的邊界頂點。
