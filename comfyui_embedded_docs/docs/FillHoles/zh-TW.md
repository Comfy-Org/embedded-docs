# 填補孔洞

此節點透過偵測開放的邊界邊，並建立新面將它們封閉，以填補 3D 網格中的孔洞。它在 GPU 上執行，保留現有幾何與 UV，並且可以處理單一網格、網格清單或網格批次。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要處理的 3D 網格。接受單一網格、網格清單或批次網格。 | MESH | 是 | - |
| `max_perimeter` | 要填補的最大孔洞周長。0 會停用。（預設值：0.03） | FLOAT | 是 | 0.0 to no upper limit （步進值：0.0001） |
| `weld_epsilon_rel` | 預先焊接容差（邊界框對角線的比例）；邊界偵測需要已焊接的頂點。0 會略過。（預設值：1e-5） | FLOAT | 是 | 0.0 to no upper limit (step 1e-6) |
| `max_vertices` | 限制每個週期的邊界頂點數量；質心扇形填補僅適用於小型且接近平面的孔洞。保持 ≤16。（預設值：16） | INT | 是 | 3 至 1024 |
| `fill_chains` | 同時填補開放鏈（不僅是封閉環）。可能產生雜訊；關閉時與 cumesh 相符。（預設值：False） | BOOLEAN | 是 | True or False |

注意：當 `max_perimeter` 大於 0 時，節點會填補孔洞；當其為 0 時，會完全略過孔洞填補。當 `weld_epsilon_rel` 大於 0 時，節點會在偵測孔洞前預先焊接重複頂點。焊接容差會從指定的邊界框對角線比例開始，並自動以加倍方式遞增，直到網格被視為已焊接，或容差達到 1e-2 的上限。具有超過 8 個邊界頂點的孔洞會使用質心扇形填補（插入新的質心頂點），而較小的孔洞則使用頂點扇形填補，重用既有的邊界頂點。預設情況下只會填補封閉的邊界環；將 `fill_chains` 設為 True 也會封閉開放鏈。

|-------------|-------------|-----------|
