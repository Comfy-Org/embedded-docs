# FillHoles

این گره سوراخ‌های موجود در مش سه‌بعدی را با تشخیص لبه‌های مرزی باز و ایجاد وجه‌های جدید برای بستن آن‌ها پر می‌کند. روی GPU اجرا می‌شود، هندسه و UVهای موجود را حفظ می‌کند و می‌تواند مش‌های تکی، فهرستی از مش‌ها یا دسته‌هایی از مش‌ها را پردازش کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی برای پردازش. یک مش واحد، فهرستی از مش‌ها یا یک مش دسته‌ای را می‌پذیرد. | MESH | بله | - |
| `max_perimeter` | بیشینه محیط سوراخ برای پر کردن. 0 غیرفعال می‌کند. (پیش‌فرض: 0.03) | FLOAT | بله | 0.0 تا بدون حد بالا |
| `weld_epsilon_rel` | تلورانس جوش پیشین (کسری از قطر جعبه محدود)؛ تشخیص مرز به رئوس جوش‌خورده نیاز دارد. 0 رد می‌کند. (پیش‌فرض: 1e-5) | FLOAT | بله | 0.0 تا بدون حد بالا |
| `max_vertices` | سقف رئوس مرزی در هر چرخه؛ بادبزنی مرکزی فقط برای سوراخ‌های کوچک تقریباً تخت کار می‌کند. ≤16 نگه دارید. (پیش‌فرض: 16) | INT | بله | 3 تا 1024 |
| `fill_chains` | همچنین زنجیره‌های باز (نه فقط چرخه‌ها) را پر می‌کند. نویزدار؛ خاموش مطابق با cumesh است. (پیش‌فرض: False) | BOOLEAN | بله | True یا False |

نکته: وقتی `weld_epsilon_rel` بزرگ‌تر از 0 است، گره قبل از تشخیص سوراخ‌ها، رئوس تکراری را از قبل جوش می‌دهد. تلورانس جوش از کسر داده‌شده از قطر جعبه محدود شروع شده و به‌طور خودکار با دو برابر شدن افزایش می‌یابد تا زمانی که مش جوش‌خورده در نظر گرفته شود یا تلورانس به سقف 1e-2 برسد. سوراخ‌هایی با بیش از 8 رأس مرزی از روش بادبزنی مرکز (درج یک رأس مرکز جدید) استفاده می‌کنند، در حالی که سوراخ‌های کوچک‌تر از روش بادبزنی رأس استفاده می‌کنند که یک رأس مرزی موجود را دوباره به کار می‌گیرد.
