# پر کردن حفره‌ها

این گره حفره‌های یک مش سه‌بعدی را با شناسایی لبه‌های مرزی باز و ساخت وجه‌های جدید برای بستن آن‌ها پر می‌کند. روی GPU اجرا می‌شود، هندسه و UVهای موجود را حفظ می‌کند و می‌تواند مش‌های تکی، فهرست‌هایی از مش‌ها یا دسته‌هایی از مش‌ها را پردازش کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی برای پردازش. یک مش، فهرستی از مش‌ها یا یک مش دسته‌بندی‌شده را می‌پذیرد. | MESH | بله | - |
| `max_perimeter` | حداکثر محیط حفره برای پر کردن. مقدار 0 آن را غیرفعال می‌کند. (پیش‌فرض: 0.03) | FLOAT | بله | 0.0 تا بدون حد بالا (گام 0.0001) |
| `weld_epsilon_rel` | تلورانس پیش‌جوش‌دهی (کسری از قطر جعبه مرزی)؛ تشخیص مرز به رأس‌های جوش‌خورده نیاز دارد. مقدار 0 آن را رد می‌کند. (پیش‌فرض: 1e-5) | FLOAT | بله | 0.0 تا بدون حد بالا (گام 1e-6) |
| `max_vertices` | تعداد رأس‌های مرزی در هر چرخه را محدود می‌کند؛ پرکننده بادبزنی مرکزی فقط برای حفره‌های کوچک و تقریباً مسطح کار می‌کند. آن را ≤16 نگه دارید. (پیش‌فرض: 16) | INT | بله | 3 تا 1024 |
| `fill_chains` | زنجیره‌های باز را نیز پر می‌کند (نه فقط چرخه‌ها). نویزی است؛ حالت OFF با cumesh مطابقت دارد. (پیش‌فرض: False) | BOOLEAN | بله | True یا False |

توجه: وقتی `max_perimeter` بزرگ‌تر از 0 باشد، گره حفره‌ها را پر می‌کند؛ وقتی 0 باشد، پر کردن حفره کاملاً نادیده گرفته می‌شود. وقتی `weld_epsilon_rel` بزرگ‌تر از 0 باشد، گره قبل از تشخیص حفره‌ها رأس‌های تکراری را پیش‌جوش می‌دهد. تلورانس جوش‌دهی از کسر داده‌شده از قطر جعبه مرزی شروع می‌شود و به‌طور خودکار با دو برابر کردن افزایش می‌یابد تا زمانی که مش جوش‌خورده در نظر گرفته شود یا تلورانس به سقف 1e-2 برسد. حفره‌هایی با بیش از 8 رأس مرزی از پرکننده بادبزنی مرکزی (با درج یک رأس مرکزی جدید) استفاده می‌کنند، در حالی که حفره‌های کوچک‌تر از پرکننده بادبزنی رأسی استفاده می‌کنند که یک رأس مرزی موجود را دوباره به کار می‌گیرد. به‌طور پیش‌فرض فقط چرخه‌های مرزی بسته پر می‌شوند؛ `fill_chains` را روی True تنظیم کنید تا زنجیره‌های باز نیز بسته شوند.
