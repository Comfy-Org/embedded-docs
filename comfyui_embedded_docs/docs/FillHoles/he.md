# FillHoles

צומת זה ממלא חורים ברשת תלת-ממדית על ידי זיהוי קצוות גבול פתוחים ויצירת פאות חדשות לסגירתם. הוא פועל על ה-GPU, משמר גאומטריה ו-UVs קיימים, ויכול לעבד רשת בודדת, רשימות של רשתות או אצוות של רשתות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | הרשת התלת-ממדית לעיבוד. מקבל רשת בודדת, רשימה של רשתות או רשת באצווה. | MESH | כן | - |
| `max_perimeter` | היקף החור המרבי למילוי. 0 משבית. (ברירת מחדל: 0.03) | FLOAT | כן | 0.0 עד ללא הגבלה עליונה (צעד 0.0001) |
| `weld_epsilon_rel` | סבילות ריתוך מקדימה (חלק מאלכסון תיבת התיחום); זיהוי גבולות מצריך קודקודים מרותכים. 0 מדלג. (ברירת מחדל: 1e-5) | FLOAT | כן | 0.0 עד ללא הגבלה עליונה (צעד 1e-6) |
| `max_vertices` | הגבלת קודקודי הגבול בכל מחזור; מניפת מרכז (centroid-fan) פועלת רק עבור חורים קטנים וקרובים למישור. יש להשאיר ≤16. (ברירת מחדל: 16) | INT | כן | 3 עד 1024 |
| `fill_chains` | ממלא גם שרשראות פתוחות (לא רק מחזורים). מייצר רעש; OFF תואם ל-cumesh. (ברירת מחדל: False) | BOOLEAN | כן | True או False |

הערה: כאשר `max_perimeter` גדול מ-0, הצומת ממלא חורים; כאשר הוא 0, מילוי החורים מדולג לחלוטין. כאשר `weld_epsilon_rel` גדול מ-0, הצומת מרתך מראש קודקודים כפולים לפני זיהוי החורים. סבילות הריתוך מתחילה בשבר הנתון מאלכסון תיבת התיחום וגדלה אוטומטית באמצעות הכפלה עד שהרשת נחשבת מרותכת או עד שסבילות הריתוך מגיעה לתקרה של 1e-2. חורים עם יותר מ-8 קודקודי גבול משתמשים במילוי מניפת מרכז (centroid-fan) (הכנסת קודקוד מרכז חדש), בעוד חורים קטנים יותר משתמשים במילוי מניפת קודקודים (vertex-fan) שעושה שימוש חוזר בקודקוד גבול קיים. כברירת מחדל ממולאים רק מחזורי גבול סגורים; יש להגדיר את `fill_chains` ל-True כדי לסגור גם שרשראות פתוחות.
