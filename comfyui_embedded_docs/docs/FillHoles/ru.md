# FillHoles

Этот узел заполняет отверстия в 3D-сетке, обнаруживая открытые граничные рёбра и создавая новые грани для их закрытия. Он работает на GPU, сохраняет существующую геометрию и UV-развёртку и может обрабатывать одиночные сетки, списки сеток или пакеты сеток.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-сетка для обработки. Принимает одиночную сетку, список сеток или пакет сеток. | MESH | Да | - |
| `max_perimeter` | Максимальный периметр отверстия для заполнения. 0 отключает. (по умолчанию: 0.03) | FLOAT | Да | 0.0 to no upper limit |
| `weld_epsilon_rel` | Допуск предварительной сварки (доля диагонали ограничивающего бокса); для обнаружения границ требуются сваренные вершины. 0 пропускает. (по умолчанию: 1e-5) | FLOAT | Да | 0.0 to no upper limit |
| `max_vertices` | Предел количества граничных вершин на цикл; веерная заливка от центроида работает только для небольших почти плоских отверстий. Держите ≤16. (по умолчанию: 16) | INT | Да | 3 до 1024 |
| `fill_chains` | Также заполнять открытые цепочки (не только циклы). Шумно; OFF соответствует cumesh. (по умолчанию: False) | BOOLEAN | Да | True or False |

Примечание: Когда `weld_epsilon_rel` больше 0, узел предварительно сваривает дублирующиеся вершины перед обнаружением отверстий. Допуск сварки начинается с заданной доли диагонали ограничивающего бокса и автоматически увеличивается удвоением, пока сетка не будет считаться сваренной или допуск не достигнет предельного значения 1e-2. Отверстия с более чем 8 граничными вершинами заполняются веером от центроида (вставляется новая вершина центроида), а меньшие отверстия заполняются веером от вершины, повторно использующим существующую граничную вершину.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Сетка с заполненными отверстиями, соответствующая формату входного пакета. | MESH |
