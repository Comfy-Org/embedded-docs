# Заполнить отверстия

Этот узел заполняет отверстия в 3D-меше, обнаруживая открытые граничные рёбра и создавая новые грани для их закрытия. Он выполняется на GPU, сохраняет существующую геометрию и UV-координаты и может обрабатывать отдельные меши, списки мешей или пакеты мешей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-меш для обработки. Принимает один меш, список мешей или пакетный меш. | MESH | Да | - |
| `max_perimeter` | Максимальный периметр отверстия для заполнения. 0 отключает. (по умолчанию: 0.03) | FLOAT | Да | 0.0 без верхнего предела (шаг 0.0001) |
| `weld_epsilon_rel` | Допуск предварительной сварки (доля диагонали ограничивающего параллелепипеда); для обнаружения границ нужны сваренные вершины. 0 пропускает. (по умолчанию: 1e-5) | FLOAT | Да | 0.0 без верхнего предела (шаг 1e-6) |
| `max_vertices` | Максимальное число граничных вершин на цикл; центроидный веер работает только для небольших почти плоских отверстий. Оставляйте ≤16. (по умолчанию: 16) | INT | Да | от 3 до 1024 |
| `fill_chains` | Также заполнять открытые цепочки (не только циклы). Может давать шум; OFF соответствует cumesh. (по умолчанию: False) | BOOLEAN | Да | True или False |

Примечание: Когда `max_perimeter` больше 0, узел заполняет отверстия; когда он равен 0, заполнение отверстий полностью пропускается. Когда `weld_epsilon_rel` больше 0, узел предварительно сваривает дублирующиеся вершины перед обнаружением отверстий. Допуск сварки начинается с заданной доли диагонали ограничивающего параллелепипеда и автоматически увеличивается удвоением, пока меш не будет считаться сваренным или пока допуск не достигнет верхнего предела 1e-2. Отверстия с более чем 8 граничными вершинами заполняются центроидным веером (вставляется новая вершина-центроид), тогда как меньшие отверстия заполняются веером от вершины, который повторно использует существующую граничную вершину. По умолчанию заполняются только замкнутые граничные циклы; установите `fill_chains` в True, чтобы также закрывать открытые цепочки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Меш с заполненными отверстиями, соответствующий формату входного пакета. | MESH |
