# FillHoles

هذه العقدة تملأ الثقوب في شبكة ثلاثية الأبعاد عبر اكتشاف الحواف الحدودية المفتوحة وإنشاء أوجه جديدة لإغلاقها. تعمل على وحدة معالجة الرسومات (GPU)، وتحافظ على الهندسة الحالية وإحداثيات UV، ويمكنها معالجة شبكة واحدة أو قائمة شبكات أو دفعات من الشبكات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `mesh` | الشبكة ثلاثية الأبعاد المراد معالجتها. تقبل شبكة واحدة أو قائمة شبكات أو شبكة مجمّعة دفعة واحدة. | MESH | نعم | - |
| `max_perimeter` | أقصى محيط للثقب يتم تعبئته. القيمة 0 تعطيل. (الافتراضي: 0.03) | FLOAT | نعم | 0.0 إلى ما لا نهاية |
| `weld_epsilon_rel` | تفاوت اللحام المسبق (جزء من قطر الصندوق المحيط)؛ اكتشاف الحدود requires رؤوسًا ملحومة. القيمة 0 تتخطى. (الافتراضي: 1e-5) | FLOAT | نعم | 0.0 إلى ما لا نهاية |
| `max_vertices` | حد أقصى لعدد رؤوس الحدود لكل دورة؛ تعبئة المروحة المركزية تعمل فقط مع الثقوب الصغيرة شبه المسطحة. اجعل القيمة ≤16. (الافتراضي: 16) | INT | نعم | 3 إلى 1024 |
| `fill_chains` | قم أيضًا بتعبئة السلاسل المفتوحة (وليس فقط الحلقات المغلقة). تُحدث ضوضاء؛ الإيقاف يطابق سلوك cumesh. (الافتراضي: False) | BOOLEAN | نعم | True أو False |

ملاحظة: عندما تكون قيمة `weld_epsilon_rel` أكبر من 0، تقوم العقدة بلحام الرؤوس المكررة مسبقًا قبل اكتشاف الثقوب. يبدأ تفاوت اللحام بالجزء المحدد من قطر الصندوق المحيط، ثم يزداد تلقائيًا بالمضاعفة حتى تُعتبر الشبكة ملحومة أو يصل التفاوت إلى حد أقصى قدره 1e-2. الثقوب التي تحتوي على أكثر من 8 رؤوس حدودية تستخدم تعبئة بالمروحة المركزية (إدراج رأس مركزي جديد)، بينما تستخدم الثقوب الأصغر تعبئة بمروحة الرؤوس التي تعيد استخدام رأس حدودي موجود.
