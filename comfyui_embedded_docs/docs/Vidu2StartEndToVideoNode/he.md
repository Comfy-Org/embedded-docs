# Vidu2 יצירת וידאו מפריים התחלה/סיום

צומת זה יוצר וידאו על ידי אינטרפולציה בין פריים התחלה ופריים סיום שסופקו, בהנחיית פרומפט טקסטואלי. הוא משתמש במודל Vidu שצוין כדי ליצור מעבר חלק בין שתי התמונות לאורך משך מוגדר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-Vidu שישמש ליצירת וידאו. | COMBO | כן | `"viduq2-pro-fast"`<br>`"viduq2-pro"`<br>`"viduq2-turbo"` |
| `first_frame` | תמונת הפתיחה עבור רצף הווידאו. מותרת תמונה בודדת בלבד. | IMAGE | כן | - |
| `end_frame` | תמונת הסיום עבור רצף הווידאו. מותרת תמונה בודדת בלבד. | IMAGE | כן | - |
| `prompt` | תיאור פרומפט (עד 2000 תווים). | STRING | כן | - |
| `duration` | אורך הווידאו הנוצר בשניות (ברירת מחדל: 5). | INT | לא | 2 to 8 |
| `seed` | מספר המשמש לאתחול היצירה האקראית לשם תוצאות ניתנות לשחזור (ברירת מחדל: 1). | INT | לא | 0 to 2147483647 |
| `resolution` | רזולוציית הפלט של הווידאו הנוצר. | COMBO | לא | `"720p"`<br>`"1080p"` |
| `movement_amplitude` | משרעת התנועה של עצמים בפריים. | COMBO | לא | `"auto"`<br>`"small"`<br>`"medium"`<br>`"large"` |

**הערה:** התמונות `first_frame` ו-`end_frame` חייבות להיות בעלות יחסי גובה-רוחב דומים. הצומת מאמת שיחסי הגובה-רוחב שלהן נמצאים בטווח יחסי של 0.8 עד 1.25. מותרת תמונה אחת בלבד עבור כל קלט.

## פלטים

|-------------|-------------|-----------|
| `output` | קובץ הווידאו שנוצר. | VIDEO |
