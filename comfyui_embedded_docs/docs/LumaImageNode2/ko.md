# Luma UNI-1 이미지

## 개요

이 노드는 Luma UNI-1 모델을 사용하여 텍스트 설명으로부터 이미지를 생성합니다. 텍스트 프롬프트와 가로세로 비율, 스타일 같은 선택적 설정을 받아 Luma API에 요청을 보내 이미지를 만듭니다. `uni-1` 및 `uni-1-max` 두 가지 모델 변형을 사용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `prompt` | 원하는 이미지에 대한 텍스트 설명입니다. 1~6000자입니다. | STRING | 예 | 1~6000자 |
| `model` | 생성에 사용할 모델입니다. 모델을 선택하면 해당 모델에 대한 추가 설정이 표시됩니다. | COMBO | 예 | `"uni-1"`<br>`"uni-1-max"` |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 결과는 시드와 무관하게 비결정적입니다. (기본값: 0) | INT | 예 | 0~2147483647 |

### uni-1 및 uni-1-max 입력

`uni-1` 및 `uni-1-max` 모델 옵션에서 공유됩니다. 이 설정은 두 모델 중 하나를 선택하면 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 출력 이미지의 가로세로 비율입니다. `"auto"`는 프롬프트를 기반으로 모델이 선택하게 합니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | 스타일 프리셋입니다. `"auto"`는 프롬프트를 기반으로 선택하며, `"manga"`는 만화/애니메이션 미학을 적용하고 세로형 가로세로 비율(2:3, 9:16, 1:2, 1:3)이 필요합니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br>`"manga"` |
| `web_search` | 생성 전에 웹에서 시각적 참조를 검색합니다. (기본값: False) | BOOLEAN | 예 | True / False |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `image_ref` | 확장 가능한 슬롯: 1~9개 항목(예: `image_1`부터 `image_9`까지)을 연결할 수 있습니다. 스타일/콘텐츠 안내를 위한 최대 9개의 참조 이미지를 제공합니다. | IMAGE | 아니요 | 최대 9개 이미지 |

**참고:** `style`을 `"manga"`로 설정한 경우 `aspect_ratio`는 `"auto"` 또는 세로형 비율인 `"2:3"`, `"9:16"`, `"1:2"`, `"1:3"` 중 하나여야 합니다. `"manga"` 스타일과 함께 다른 비율을 사용하면 오류가 발생합니다. 참조 이미지의 최대 개수는 `uni-1` 및 `uni-1-max` 모두 9개입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 생성된 이미지를 텐서로 나타낸 것입니다. | IMAGE |
