# Luma UNI-1 圖像

### 概述

此節點使用 Luma UNI-1 模型，根據文字描述生成圖像。它接受文字提示及長寬比、樣式等選用設定，然後將請求傳送至 Luma API 以建立圖像。提供兩種模型變體：`uni-1` 與 `uni-1-max`。

### 輸入

#### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 用於生成的模型。選擇模型會顯示該模型的額外設定。 | DYNAMIC_COMBO | 是 | `"uni-1"`<br>`"uni-1-max"` |
| `prompt` | 所需圖像的文字描述。1–6000 個字元。 | STRING | 是 | 1 至 6000 個字元 |
| `seed` | 種子控制節點是否應重新執行；無論種子為何，結果都是非確定性的。（預設值：0） | INT | 是 | 0 至 2147483647 |

#### uni-1 與 uni-1-max 輸入

由 `uni-1` 與 `uni-1-max` 模型選項共用。選擇任一模型時，即會顯示這些設定。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 輸出圖像的長寬比。`"auto"` 讓模型根據提示自行選擇。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | 樣式預設集。`"auto"` 根據提示選擇；`"manga"` 套用漫畫／動畫美學，且需要直向長寬比（2:3、9:16、1:2、1:3）。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"manga"` |
| `web_search` | 在生成前搜尋網路上的視覺參考。（預設值：False） | BOOLEAN | 是 | True / False |

#### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image_ref` | 可增長插槽：連接 1 至 9 個項目（例如 `image_1` 到 `image_9`）。最多 9 張參考圖像，用於風格／內容導引。 | IMAGE | 否 | 最多 9 張圖像 |
