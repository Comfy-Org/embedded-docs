# Luma UNI-1 圖像

此節點使用 Luma UNI-1 模型，根據文字描述生成圖像。它接收文字提示，以及例如長寬比和風格等選用設定，然後將請求傳送至 Luma API 來產生圖像。有兩種模型變體可用：`uni-1` 和 `uni-1-max`。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `提示` | 所需圖像的文字描述。1–6000 個字元。（預設值：""） | STRING | 是 | 1 到 6000 個字元 |
| `模型` | 用於生成的模型。選取模型後會顯示該模型的其他設定。（預設值：第一個選項，`"uni-1"`） | DYNAMIC_COMBO | 是 | `"uni-1"`<br>`"uni-1-max"` |
| `種子` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果皆非確定性。（預設值：0） | INT | 是 | 0 到 2147483647 |

### uni-1 和 uni-1-max 輸入

由 `uni-1` 和 `uni-1-max` 模型選項共用。選取任一模型時都會顯示這些設定。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 輸出圖像的長寬比。`"auto"` 讓模型根據提示選擇。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | 風格預設。`"auto"` 會根據提示選擇；`"manga"` 會套用漫畫/動畫美學，並要求直向長寬比（2:3、9:16、1:2、1:3）。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"manga"` |
| `web_search` | 在產生前搜尋網路以取得視覺參考。（預設值：False） | BOOLEAN | 是 | True / False |

### 參考輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image_ref` | 可擴充插槽：連接 1 到 9 個項目（例如 `image_1` 到 `image_9`）。最多 9 張參考圖片，用於風格/內容引導。 | IMAGE | 否 | 最多 9 張圖片 |
