# Luma UNI-1 圖像

## 概述

此節點使用 Luma UNI-1 模型根據文字描述產生影像。它接收文字提示以及可選的設定（如長寬比和風格），然後將請求傳送至 Luma API 以建立影像。提供兩種模型變體：`uni-1` 和 `uni-1-max`。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `提示` | 所需影像的文字描述。1–6000 個字元。 | STRING | 是 | 1 到 6000 個字元 |
| `模型` | 用於產生的模型。選擇模型會顯示該模型的額外設定。 | DYNAMIC_COMBO | 是 | `"uni-1"`<br>`"uni-1-max"` |
| `種子` | 種子控制節點是否應重新執行；無論種子為何，結果皆為非確定性。（預設值：0） | INT | 是 | 0 到 2147483647 |

### uni-1 和 uni-1-max 輸入

由 `uni-1` 和 `uni-1-max` 模型選項共用。當選取任一模型時，這些設定便會出現。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 輸出影像的長寬比。`"auto"` 會讓模型根據提示自行選擇。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | 風格預設。`"auto"` 會根據提示選擇；`"manga"` 會套用漫畫／動畫美學，且需要人像長寬比（2:3、9:16、1:2、1:3）。（預設值：`"auto"`） | COMBO | 是 | `"auto"`<br>`"manga"` |
| `web_search` | 在產生前搜尋網路以取得視覺參考。（預設值：False） | BOOLEAN | 是 | True / False |

### 參考輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `image_ref` | 可擴充插槽：連接 1 至 9 個項目（例如 `image_1` 至 `image_9`）。最多 9 張參考影像，用於風格／內容引導。 | IMAGE | 否 | 最多 9 張影像 |
