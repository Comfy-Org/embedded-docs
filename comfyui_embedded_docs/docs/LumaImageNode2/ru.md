# Luma UNI-1 Image

Этот узел генерирует изображения по текстовым описаниям с использованием модели Luma UNI-1. Он принимает текстовый промпт и необязательные настройки, такие как соотношение сторон и стиль, затем отправляет запрос в Luma API для создания изображения. Доступны два варианта модели: `uni-1` и `uni-1-max`.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовое описание желаемого изображения. 1–6000 символов. (по умолчанию: "") | STRING | Да | От 1 до 6000 символов |
| `model` | Модель для использования при генерации. Выбор модели открывает дополнительные настройки для этой модели. (по умолчанию: первый вариант, `"uni-1"`) | DYNAMIC_COMBO | Да | `"uni-1"`<br>`"uni-1-max"` |
| `seed` | Seed управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | От 0 до 2147483647 |

### Входы uni-1 и uni-1-max

Общие для вариантов модели `uni-1` и `uni-1-max`. Эти настройки отображаются при выборе любой из этих моделей.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | Соотношение сторон выходного изображения. `"auto"` позволяет модели выбрать его на основе промпта. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | Предустановленный стиль. `"auto"` выбирает на основе промпта; `"manga"` применяет эстетику манги/аниме и требует портретное соотношение сторон (2:3, 9:16, 1:2, 1:3). (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"manga"` |
| `web_search` | Искать в интернете визуальные референсы перед генерацией. (по умолчанию: False) | BOOLEAN | Да | True / False |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `image_ref` | Расширяемый слот: подключите от 1 до 9 элементов (например, `image_1`–`image_9`). До 9 эталонных изображений для управления стилем/содержанием. | IMAGE | Нет | До 9 изображений |

**Примечание:** Если `style` установлен в `"manga"`, `aspect_ratio` должен быть либо `"auto"`, либо одним из портретных соотношений `"2:3"`, `"9:16"`, `"1:2"`, `"1:3"`. Использование любого другого соотношения со стилем `"manga"` вызовет ошибку. Максимальное количество эталонных изображений — 9 как для `uni-1`, так и для `uni-1-max`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Сгенерированное изображение. | IMAGE |
