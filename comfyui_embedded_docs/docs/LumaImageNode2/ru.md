# Luma UNI-1 Image

## Обзор

Этот узел генерирует изображения по текстовым описаниям с использованием модели Luma UNI-1. Он принимает текстовый запрос и необязательные настройки, такие как соотношение сторон и стиль, затем отправляет запрос к Luma API для создания изображения. Доступны два варианта модели: `uni-1` и `uni-1-max`.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовое описание желаемого изображения. От 1 до 6000 символов. | STRING | Да | от 1 до 6000 символов |
| `model` | Модель для генерации. Выбор модели открывает дополнительные настройки для этой модели. | COMBO | Да | `"uni-1"`<br>`"uni-1-max"` |
| `seed` | Сид (seed) управляет тем, следует ли узлу выполнить повторный запуск; результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

### Входы uni-1 и uni-1-max

Общие для опций модели `uni-1` и `uni-1-max`. Эти настройки отображаются при выборе любой из этих моделей.

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | Соотношение сторон выходного изображения. Значение `"auto"` позволяет модели выбрать его на основе запроса. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"3:1"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"1:3"` |
| `style` | Пресет стиля. `"auto"` выбирает стиль на основе запроса; `"manga"` применяет эстетику манги/аниме и требует портретное соотношение сторон (2:3, 9:16, 1:2, 1:3). (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"manga"` |
| `web_search` | Искать в интернете визуальные референсы перед генерацией. (по умолчанию: False) | BOOLEAN | Да | True / False |

### Референсные входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `image_ref` | Расширяемый слот: подключите от 1 до 9 элементов (например, `image_1`–`image_9`). До 9 референсных изображений для управления стилем/содержанием. | IMAGE | Нет | до 9 изображений |

**Примечание:** Если для `style` задано значение `"manga"`, параметр `aspect_ratio` должен быть либо `"auto"`, либо одним из портретных соотношений: `"2:3"`, `"9:16"`, `"1:2"`, `"1:3"`. Использование любого другого соотношения со стилем `"manga"` вызовет ошибку. Максимальное количество референсных изображений — 9 как для `uni-1`, так и для `uni-1-max`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Сгенерированное изображение в виде тензора. | IMAGE |
