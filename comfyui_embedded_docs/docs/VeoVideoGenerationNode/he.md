# VeoVideoGenerationNode

יוצר סרטונים מהנחיות טקסט באמצעות Google Veo API. צומת זה יכול ליצור סרטונים מתיאורי טקסט וקלטי תמונה אופציונליים, עם שליטה בפרמטרים כגון יחס גובה-רוחב, משך ועוד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור טקסטואלי של הסרטון (ברירת מחדל: ריק) | STRING | כן | - |
| `aspect_ratio` | יחס גובה-רוחב של סרטון הפלט (ברירת מחדל: "16:9") | COMBO | כן | "16:9"<br>"9:16" |
| `negative_prompt` | הנחיית טקסט שלילית שמגדירה ממה להימנע בסרטון (ברירת מחדל: ריק) | STRING | לא | - |
| `duration_seconds` | משך סרטון הפלט בשניות (ברירת מחדל: 5) | INT | לא | 5-8 |
| `enhance_prompt` | האם לשפר את ההנחיה בסיוע בינה מלאכותית (ברירת מחדל: True). זהו פרמטר מתקדם. | BOOLEAN | לא | - |
| `person_generation` | האם לאפשר יצירת אנשים בסרטון (ברירת מחדל: "ALLOW"). זהו פרמטר מתקדם. | COMBO | לא | "ALLOW"<br>"BLOCK" |
| `seed` | Seed ליצירת הסרטון (0 עבור אקראי) (ברירת מחדל: 0). זהו פרמטר מתקדם. | INT | לא | 0-4294967295 |
| `image` | תמונת עזר אופציונלית להנחות יצירת הסרטון | IMAGE | לא | - |
| `model` | מודל Veo שבו יש להשתמש ליצירת הסרטון (ברירת מחדל: "veo-2.0-generate-001") | COMBO | לא | "veo-2.0-generate-001"<br>"veo-3.1-generate"<br>"veo-3.1-fast-generate"<br>"veo-3.1-lite"<br>"veo-3.0-generate-001"<br>"veo-3.0-fast-generate-001" |

**הערה:** הפרמטר `generate_audio` זמין רק עבור מודלים Veo 3.0 ו-Veo 3.1 ומטופל באופן אוטומטי על ידי הצומת בהתאם למודל שנבחר. בעת שימוש במודלים Veo 3.0 או Veo 3.1, הפרמטר `enhance_prompt` נכפה ל-True.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | קובץ הסרטון שנוצר | VIDEO |
