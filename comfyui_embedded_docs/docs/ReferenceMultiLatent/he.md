# Set Reference Multi Latent

צומת זה מקודד תמונת עזר אחת או יותר ומצרף את הלטנטים שלהן להתנייה שמודל עריכה צורך. זהו המקבילה המרובת-תמונות של Set Reference Latent: מחברים VAE יחד עם קבוצה של תמונות עזר, והצומת מצרף כל לטנט מקודד להתנייה החיובית, וכאשר אחד מחובר, גם להתנייה השלילית. השתמשו בו כאשר מודל מצפה למספר תמונות עזר בבת אחת במקום ללטנט בודד.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | ההתנייה החיובית שעליה יש להחיל את לטנטי העזר. | CONDITIONING | כן | - |
| `negative` | התנייה שלילית אופציונלית שמקבלת את אותם לטנטי עזר. השאירו אותה לא מחוברת כדי לעשות שימוש חוזר בהתנייה החיובית שהשתנתה בפלט `negative`. | CONDITIONING | לא | - |
| `vae` | ה-VAE המשמש לקידוד תמונות העזר המחוברות. כאשר אין VAE מחובר, מתעלמים מתמונות העזר. | VAE | לא | - |
| `resolution` | כיצד כל תמונת עזר מוכנה לפני הקידוד. `"keep resolution"` מקודד אותה בגודל הנכנס שלה; `"resize"` משנה את גודלה ליעד של מספר מגה-פיקסלים תוך שמירה על יחס הגובה-רוחב, מה שמציג את `megapixels`. (ברירת מחדל: "keep resolution") | DYNAMIC_COMBO | כן | `"keep resolution"`<br>`"resize"` |
| `images` | חריץ שניתן להרחבה: חברו תמונת עזר אחת או יותר (`image_1`, `image_2`, ...) לשימוש כתמונות עזר. התמונות מקודדות לפי סדר החריצים ומצורפות להתנייה באותו סדר. | IMAGE | לא | 1 עד 100 |

### קלטי שינוי גודל

אפשרויות אלו מופיעות כאשר `resolution` מוגדר ל-`"resize"`.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `megapixels` | גודל היעד של כל תמונת עזר, תוך שמירה על יחס הגובה-רוחב. 1.0 הוא בערך 1024 x 1024 פיקסלים. (ברירת מחדל: 1.0) | FLOAT | כן | 0.01 עד 16.0 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | ההתנייה החיובית עם לטנטי העזר המקודדים מצורפים. | CONDITIONING |
| `negative` | ההתנייה השלילית עם אותם לטנטי עזר מצורפים. מחזיר את הפלט `positive` כאשר לא מחוברת התנייה שלילית. | CONDITIONING |
| `empty_latent` | לטנט העזר הראשון כפול 0.0, מוכן לאתחול סמפלר. כאשר לא נוצר לטנט עזר כלשהו, מוחזר במקומו לטנט ריק מרובע ברזולוציה שנבחרה. | LATENT |

## הערות

- הלטנטים מצורפים ולא מוחלפים, כך ששרשור של כמה צמתי Set Reference Multi Latent צובר תמונות עזר.
- כל תמונה מחוברת מקודדת בנפרד, ולכן תמונות העזר אינן חייבות להיות באותו גודל.
- ללא VAE מחובר או ללא תמונה מחוברת, `positive` ו-`negative` מוחזרים ללא שינוי ו-`empty_latent` הוא לטנט ריק מרובע: 1024 x 1024, או בגודל הנגזר מ-`megapixels` כאשר `resolution` הוא `"resize"`.
