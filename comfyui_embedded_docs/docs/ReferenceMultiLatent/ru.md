# Set Reference Multi Latent

Этот узел кодирует одно или несколько эталонных изображений и добавляет их латенты к conditioning, который использует модель редактирования. Это многоизображенческий аналог Set Reference Latent: вы подключаете VAE и набор эталонных изображений, и узел присоединяет каждый закодированный латент к положительному conditioning, а если он подключён, то и к отрицательному conditioning. Используйте его, когда модель ожидает несколько эталонных изображений одновременно вместо одного латента.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный conditioning для модификации эталонными латентами. | CONDITIONING | Да | - |
| `negative` | Необязательный отрицательный conditioning, который получает те же эталонные латенты. Оставьте его неподключённым, чтобы повторно использовать модифицированный положительный conditioning на выходе `negative`. | CONDITIONING | Нет | - |
| `vae` | VAE, используемый для кодирования подключённых эталонных изображений. Обязателен, когда подключено хотя бы одно изображение, иначе узел выдаёт ошибку. | VAE | Нет | - |
| `resolution` | Как каждое эталонное изображение подготавливается перед кодированием. `"keep resolution"` кодирует его в исходном размере; `"resize"` масштабирует его до целевого количества мегапикселей, сохраняя соотношение сторон, что открывает `megapixels`. (по умолчанию: "keep resolution") | DYNAMIC_COMBO | Да | `"keep resolution"`<br>`"resize"` |
| `images` | Расширяемый слот: подключите одно или несколько эталонных изображений (`image_1`, `image_2`, ...), чтобы использовать их как эталоны. Изображения кодируются в порядке слотов и добавляются к conditioning в том же порядке. | IMAGE | Нет | 1 до 100 |

### Входы изменения размера

Эти параметры появляются, когда `resolution` установлен в `"resize"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `megapixels` | Целевой размер каждого эталонного изображения с сохранением соотношения сторон. 1.0 — это примерно 1024 x 1024 пикселя. (по умолчанию: 1.0) | FLOAT | Да | 0.01 до 16.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный conditioning с добавленными закодированными эталонными латентами. | CONDITIONING |
| `negative` | Отрицательный conditioning с теми же добавленными эталонными латентами. Возвращает выход `positive`, когда отрицательный conditioning не подключён. | CONDITIONING |
| `empty_latent` | Первый эталонный латент, умноженный на 0.0, готов для инициализации сэмплера. Пустой, когда ни одно эталонное изображение не подключено. | LATENT |

## Примечания

- Латенты добавляются, а не заменяются, поэтому последовательное соединение нескольких узлов Set Reference Multi Latent накапливает эталоны.
- Каждое подключённое изображение кодируется отдельно, поэтому эталонные изображения не обязаны иметь одинаковый размер.
- Без подключённых изображений `positive` и `negative` возвращаются без изменений, а `empty_latent` пуст.
