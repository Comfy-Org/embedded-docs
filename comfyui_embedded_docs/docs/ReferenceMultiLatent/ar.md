# Set Reference Multi Latent

تُرمِّز هذه العقدة صورة مرجعية واحدة أو أكثر وتُلحق كوامنها بالتكييف الذي يستهلكه نموذج التحرير. وهي النظير متعدد الصور لعقدة Set Reference Latent: حيث توصل VAE مع مجموعة من الصور المرجعية، فتُرفق العقدة كل كامن مُرمَّز بالتكييف الإيجابي، وكذلك بالتكييف السلبي عند توصيله. استخدمها عندما يتوقع النموذج عدة صور مرجعية دفعة واحدة بدلًا من كامن واحد.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التكييف الإيجابي المراد تعديله بالكوامن المرجعية. | CONDITIONING | نعم | - |
| `negative` | تكييف سلبي اختياري يتلقى الكوامن المرجعية نفسها. اتركه غير موصول لإعادة استخدام التكييف الإيجابي المعدَّل في مخرج `negative`. | CONDITIONING | لا | - |
| `vae` | الـ VAE المستخدم لترميز الصور المرجعية الموصولة. إذا لم يتم توصيل VAE، يتم تجاهل الصور المرجعية. | VAE | لا | - |
| `resolution` | كيفية تجهيز كل صورة مرجعية قبل الترميز. `"keep resolution"` تُرمِّزها بالحجم الوارد؛ `"resize"` تغيّر حجمها إلى عدد ميغابكسل مستهدف مع الحفاظ على نسبة الأبعاد، مما يُظهر `megapixels`. (الافتراضي: "keep resolution") | DYNAMIC_COMBO | نعم | `"keep resolution"`<br>`"resize"` |
| `images` | خانة قابلة للتوسيع: صِل صورة مرجعية واحدة أو أكثر (`image_1`, `image_2`, ...) لاستخدامها كمراجع. تُرمَّز الصور حسب ترتيب الخانات وتُلحق بالتكييف بهذا الترتيب. | IMAGE | لا | 1 إلى 100 |

### مدخلات تغيير الحجم

تظهر هذه الخيارات عندما يتم ضبط `resolution` على `"resize"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `megapixels` | الحجم المستهدف لكل صورة مرجعية مع الحفاظ على نسبة الأبعاد. 1.0 يعادل تقريبًا 1024 x 1024 بكسل. (الافتراضي: 1.0) | FLOAT | نعم | 0.01 إلى 16.0 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي مع إلحاق الكوامن المرجعية المُرمَّزة. | CONDITIONING |
| `negative` | التكييف السلبي مع إلحاق الكوامن المرجعية نفسها. يُعيد المخرج `positive` عندما لا يكون هناك تكييف سلبي موصول. | CONDITIONING |
| `empty_latent` | الكامن المرجعي الأول مضروبًا في 0.0، وجاهز لتهيئة أداة أخذ العينات. فارغ عندما لا تكون هناك صورة مرجعية موصولة. | LATENT |

## ملاحظات

- تُلحق الكوامن بدلًا من استبدالها، لذا فإن تسلسل عدة عُقد Set Reference Multi Latent يراكم المراجع.
- تُرمَّز كل صورة موصولة على حدة، لذا لا يلزم أن تكون الصور المرجعية بالحجم نفسه.
- عند عدم توصيل أي صورة، يُعاد `positive` و`negative` دون تغيير، ويكون `empty_latent` فارغًا.
