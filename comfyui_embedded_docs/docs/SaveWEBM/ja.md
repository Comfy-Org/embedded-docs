# SaveWEBM

以下に日本語訳を提供します。

---

SaveWEBM ノードは、一連の画像を WEBM ビデオファイルとして保存します。入力画像を VP9 または AV1 コーデックを使用してビデオにエンコードし、フレームレートと品質設定を構成できます。ファイルは出力ディレクトリに保存されます。プロンプトとワークフローのメタデータは、利用可能な場合にビデオファイルに埋め込まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | ビデオにエンコードする画像のシーケンスです。RGBA 画像は、そのアルファチャンネルを透明度として保存します（vp9 コーデックのみ）。 | IMAGE | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックスです。カウンターと .webm 拡張子が自動的に付加されます（デフォルト: "ComfyUI"）。 | STRING | いいえ | - |
| `codec` | エンコードに使用するビデオコーデックです。 | COMBO | はい | "vp9"<br>"av1" |
| `fps` | 出力ビデオのフレームレートです（デフォルト: 24.0）。 | FLOAT | いいえ | 0.01-1000.0 |
| `crf` | crf が高いほど品質が低くなりファイルサイズが小さくなります。crf が低いほど品質が高くなりファイルサイズが大きくなります（デフォルト: 32.0）。 | FLOAT | いいえ | 0-63.0 |

**アルファチャンネルの注意点：** RGBA 画像のアルファチャンネルは、vp9 コーデックを使用した場合にのみ保持されます。av1 コーデックを使用する場合、アルファチャンネルは無視され、RGB データのみがエンコードされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | 入力画像のシーケンスをそのまま渡します。 | IMAGE |
| `ui` | 保存された WEBM ファイルを表示するビデオプレビューです。 | PREVIEW |
