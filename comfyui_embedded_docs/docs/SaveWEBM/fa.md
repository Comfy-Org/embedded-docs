# ذخیره WEBM

گره SaveWEBM یک دنباله از تصاویر را به‌عنوان یک فایل ویدیویی WEBM ذخیره می‌کند. این گره چند تصویر ورودی دریافت کرده و آن‌ها را با استفاده از کدک VP9 یا AV1 با تنظیمات کیفیت و نرخ فریم قابل‌تنظیم، به ویدیو رمزگذاری می‌کند. فایل ویدیویی حاصل در دایرکتوری خروجی همراه با فراداده‌ای شامل اطلاعات prompt ذخیره می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | تصاویر RGBA با کانال آلفای خود به‌عنوان شفافیت ذخیره می‌شوند (فقط در کدک vp9). | IMAGE | بله | - |
| `پیشوند نام فایل` | پیشوندی برای نام فایل خروجی (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `کدک` | کدک ویدیویی که برای رمزگذاری استفاده می‌شود. | COMBO | بله | "vp9"<br>"av1" |
| `فریم بر ثانیه` | نرخ فریم برای ویدیوی خروجی (پیش‌فرض: 24.0). | FLOAT | خیر | 0.01-1000.0 |
| `CRF` | crf بالاتر به معنای کیفیت پایین‌تر با حجم فایل کمتر است؛ crf پایین‌تر به معنای کیفیت بالاتر و حجم فایل بیشتر است (پیش‌فرض: 32.0). | FLOAT | خیر | 0-63.0 |

**نکته‌ای درباره کانال آلفا:** کانال آلفای تصاویر RGBA تنها هنگام استفاده از کدک VP9 حفظ می‌شود. هنگام استفاده از کدک AV1، کانال آلفا نادیده گرفته می‌شود و تنها داده‌های RGB رمزگذاری می‌شوند.

**نکته‌ای درباره نام‌گذاری فایل:** ویدیوها در دایرکتوری خروجی به صورت `{filename_prefix}_{counter:05}_.webm` ذخیره می‌شوند، که در آن شمارنده به‌طور خودکار افزایش می‌یابد تا از بازنویسی فایل‌های موجود جلوگیری شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصاویر` | تصاویر ورودی که پس از ذخیره‌شدن ویدیو بدون تغییر عبور داده می‌شوند. | IMAGE |
| UI preview | پیش‌نمایش ویدیو که فایل WEBM ذخیره‌شده را نشان می‌دهد. | PREVIEW |
