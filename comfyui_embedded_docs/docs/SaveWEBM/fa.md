# ذخیره WEBM

گره SaveWEBM یک توالی از تصاویر را به‌صورت یک فایل ویدئویی WEBM ذخیره می‌کند. این گره چندین تصویر ورودی می‌گیرد و آن‌ها را با استفاده از کدک VP9 یا AV1 و تنظیمات کیفیت و نرخ فریم قابل‌پیکربندی به ویدئو کدگذاری می‌کند. فایل ویدئویی حاصل همراه با فراداده‌ای شامل اطلاعات پرامپت در پوشه خروجی ذخیره می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | تصاویر RGBA با کانال آلفای خود به‌عنوان شفافیت ذخیره می‌شوند (فقط کدک vp9). | IMAGE | بله | - |
| `پیشوند نام فایل` | پیشوند برای نام فایل خروجی (پیش‌فرض: "ComfyUI"). | STRING | خیر | - |
| `کدک` | کدک ویدئویی مورد استفاده برای کدگذاری. | COMBO | بله | "vp9"<br>"av1" |
| `فریم بر ثانیه` | نرخ فریم برای ویدئوی خروجی (پیش‌فرض: 24.0). | FLOAT | خیر | 0.01-1000.0 |
| `CRF` | crf بالاتر به‌معنای کیفیت پایین‌تر با حجم فایل کوچک‌تر است؛ crf پایین‌تر به‌معنای کیفیت بالاتر با حجم فایل بزرگ‌تر است (پیش‌فرض: 32.0). | FLOAT | خیر | 0-63.0 |

**نکته درباره کانال آلفا:** کانال آلفا از تصاویر RGBA فقط هنگام استفاده از کدک VP9 حفظ می‌شود. هنگام استفاده از کدک AV1، کانال آلفا نادیده گرفته می‌شود و تنها داده‌های RGB کدگذاری می‌شوند.

**نکته درباره نام‌گذاری فایل:** ویدئوها در پوشه خروجی با نام `{filename_prefix}_{counter:05}_.webm` ذخیره می‌شوند، که در آن شمارنده به‌صورت خودکار افزایش می‌یابد تا از بازنویسی فایل‌های موجود جلوگیری شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `images` | تصاویر ورودی، پس از ذخیره ویدئو بدون تغییر عبور داده می‌شوند. | IMAGE |
| UI preview | پیش‌نمایش ویدئو که فایل WEBM ذخیره‌شده را نشان می‌دهد. | PREVIEW |
