# ذخیره WEBM

گره SaveWEBM توالی تصاویر را به‌عنوان یک فایل ویدیویی WEBM ذخیره می‌کند. این گره تصاویر ورودی را با استفاده از کدک VP9 یا AV1 و با نرخ فریم و تنظیمات کیفیت قابل‌تنظیم به ویدیو کدگذاری می‌کند و فایل را در فهرست خروجی ذخیره می‌کند. ابرداده‌های پرامپت و گردش‌کار در صورت وجود در فایل ویدیویی تعبیه می‌شوند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | توالی تصاویری که باید در ویدیو کدگذاری شوند. تصاویر RGBA با کانال آلفای خود به‌صورت شفافیت ذخیره می‌شوند (فقط کدک vp9). | IMAGE | بله | - |
| `filename_prefix` | پیشوند برای نام فایل خروجی؛ یک شمارنده و پسوند .webm به‌صورت خودکار اضافه می‌شوند (پیش‌فرض: "ComfyUI") | STRING | خیر | - |
| `codec` | کدک ویدیویی مورد استفاده برای کدگذاری | COMBO | بله | "vp9"<br>"av1" |
| `fps` | نرخ فریم برای ویدیوی خروجی (پیش‌فرض: 24.0) | FLOAT | خیر | 0.01-1000.0 |
| `crf` | crf بالاتر به معنای کیفیت پایین‌تر با حجم فایل کوچک‌تر است؛ crf پایین‌تر به معنای کیفیت بالاتر با حجم فایل بیشتر است (پیش‌فرض: 32.0) | FLOAT | خیر | 0-63.0 |

**نکته کانال آلفا:** کانال آلفای تصاویر RGBA تنها هنگام استفاده از کدک vp9 حفظ می‌شود. هنگام استفاده از کدک av1، کانال آلفا نادیده گرفته شده و تنها داده‌های RGB کدگذاری می‌شوند.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `images` | توالی تصاویر ورودی که بدون تغییر عبور داده شده است | IMAGE |
| `ui` | پیش‌نمایش ویدیو که فایل WEBM ذخیره‌شده را نشان می‌دهد | PREVIEW |
