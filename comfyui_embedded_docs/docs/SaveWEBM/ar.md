# حفظ WEBM

تقوم عقدة SaveWEBM بحفظ تسلسل من الصور كملف فيديو بصيغة WEBM. تأخذ صور إدخال متعددة وتقوم بترميزها إلى فيديو باستخدام إما برنامج الترميز VP9 أو AV1 مع إعدادات جودة قابلة للضبط ومعدل إطارات. يُحفظ ملف الفيديو الناتج في دليل الإخراج مع بيانات وصفية تتضمن معلومات الموجّه (prompt).

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصور` | تُحفظ صور RGBA مع قناة الشفافية (alpha) الخاصة بها كشفافية (باستخدام برنامج الترميز vp9 فقط). | IMAGE | نعم | - |
| `بادئة اسم الملف` | بادئة لاسم ملف الإخراج (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `الترميز` | برنامج الترميز المستخدم للتشفير. | COMBO | نعم | "vp9"<br>"av1" |
| `معدل الإطارات في الثانية` | معدل الإطارات لفيديو الإخراج (الافتراضي: 24.0). | FLOAT | لا | 0.01-1000.0 |
| `crf` | قيمة crf الأعلى تعني جودة أقل مع حجم ملف أصغر، بينما قيمة crf الأقل تعني جودة أعلى مع حجم ملف أكبر (الافتراضي: 32.0). | FLOAT | لا | 0-63.0 |

**ملاحظة حول قناة الشفافية (alpha):** يتم الحفاظ على قناة الشفافية (alpha) من صور RGBA فقط عند استخدام برنامج الترميز VP9. عند استخدام برنامج الترميز AV1، يتم تجاهل قناة الشفافية (alpha) ويتم ترميز بيانات RGB فقط.

**ملاحظة حول تسمية الملفات:** تُحفظ الفيديوهات في دليل الإخراج بالشكل `{filename_prefix}_{counter:05}_.webm`، حيث يزداد العداد تلقائيًا لتجنب الكتابة فوق الملفات الموجودة.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `الصور` | صور الإدخال، التي تُمرر كما هي دون تغيير بعد حفظ الفيديو. | IMAGE |
| UI preview | معاينة الفيديو التي تعرض ملف WEBM المحفوظ. | PREVIEW |
