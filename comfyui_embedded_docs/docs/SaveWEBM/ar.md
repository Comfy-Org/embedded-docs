# حفظ WEBM

تحفظ عقدة SaveWEBM سلسلة من الصور في ملف فيديو WEBM. تأخذ عدة صور مُدخلة وترمّزها إلى فيديو باستخدام برنامج الترميز VP9 أو AV1 مع إعدادات جودة ومعدل إطارات قابلين للضبط. يُحفظ ملف الفيديو الناتج في دليل الإخراج مع بيانات وصفية تتضمن معلومات المُوجّه.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | تُحفظ صور RGBA مع قناة ألفا الخاصة بها كشفافية (برنامج الترميز vp9 فقط). | IMAGE | نعم | - |
| `filename_prefix` | بادئة اسم ملف الإخراج (الافتراضي: "ComfyUI"). | STRING | لا | - |
| `codec` | برنامج ترميز الفيديو المستخدم للترميز. | COMBO | نعم | "vp9"<br>"av1" |
| `fps` | معدل الإطارات لفيديو الإخراج (الافتراضي: 24.0). | FLOAT | لا | 0.01-1000.0 |
| `crf` | تعني قيمة crf الأعلى جودة أقل مع حجم ملف أصغر، وتعني قيمة crf الأقل جودة أعلى وحجم ملف أكبر (الافتراضي: 32.0). | FLOAT | لا | 0-63.0 |

**ملاحظة حول قناة ألفا:** لا يتم الحفاظ على قناة ألفا من صور RGBA إلا عند استخدام برنامج الترميز VP9. عند استخدام برنامج الترميز AV1، يتم تجاهل قناة ألفا ويُرمّز فقط بيانات RGB.

**ملاحظة حول تسمية الملفات:** تُحفظ مقاطع الفيديو في دليل الإخراج بالاسم `{filename_prefix}_{counter:05}_.webm`، حيث يزداد العداد تلقائيًا لتجنب الكتابة فوق الملفات الموجودة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `images` | الصور المدخلة، تُمَرَّر دون تغيير بعد حفظ الفيديو. | IMAGE |
| UI preview | معاينة فيديو تُظهر ملف WEBM المحفوظ. | PREVIEW |
