# حفظ WEBM

تقوم عقدة SaveWEBM بحفظ سلسلة من الصور كملف فيديو بصيغة WEBM. تقوم بترميز الصور المدخلة إلى فيديو باستخدام أحد برنامجَي الترميز VP9 أو AV1 مع إعدادات قابلة للضبط لمعدل الإطارات والجودة، وتحفظ الملف في دليل الإخراج. تُضمَّن بيانات وصفية للموجّه وسير العمل في ملف الفيديو عند توفّرها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | تسلسل الصور المراد ترميزه إلى الفيديو. تُحفظ صور RGBA مع قناة ألفا الخاصة بها كشفافية (باستخدام برنامج الترميز vp9 فقط). | IMAGE | نعم | - |
| `filename_prefix` | بادئة لاسم ملف الإخراج؛ يُلحق عدّاد وامتداد .webm تلقائيًا (الافتراضي: "ComfyUI") | STRING | لا | - |
| `codec` | برنامج الترميز المستخدم في التشفير | COMBO | نعم | "vp9"<br>"av1" |
| `fps` | معدل الإطارات للفيديو الناتج (الافتراضي: 24.0) | FLOAT | لا | 0.01-1000.0 |
| `crf` | ارتفاع قيمة crf يعني جودة أقل مع حجم ملف أصغر، وانخفاضها يعني جودة أعلى وحجم ملف أكبر (الافتراضي: 32.0) | FLOAT | لا | 0-63.0 |

**ملاحظة حول قناة ألفا:** يُحافظ على قناة ألفا لصور RGBA فقط عند استخدام برنامج الترميز vp9. أما عند استخدام برنامج الترميز av1، يتم تجاهل قناة ألفا وترميز بيانات RGB فقط.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `images` | تسلسل الصور المُدخل، ويُمرَّر دون تغيير | IMAGE |
| `ui` | معاينة فيديو تعرض ملف WEBM المحفوظ | PREVIEW |
