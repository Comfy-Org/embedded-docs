# SaveWEBM

Узел SaveWEBM сохраняет последовательность изображений в видеофайл WEBM. Он принимает несколько входных изображений и кодирует их в видео с использованием кодека VP9 или AV1 с настраиваемыми параметрами качества и частоты кадров. Результирующий видеофайл сохраняется в выходной каталог с метаданными, включающими информацию о промпте.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Изображения RGBA сохраняются с альфа-каналом в качестве прозрачности (только для кодека vp9). | IMAGE | Да | - |
| `префикс_имени_файла` | Префикс для имени выходного файла (по умолчанию: "ComfyUI"). | STRING | Нет | - |
| `кодек` | Видеокодек для кодирования. | COMBO | Да | "vp9"<br>"av1" |
| `fps` | Частота кадров для выходного видео (по умолчанию: 24.0). | FLOAT | Нет | 0.01-1000.0 |
| `crf` | Более высокий crf означает более низкое качество при меньшем размере файла, более низкий crf — более высокое качество при большем размере файла (по умолчанию: 32.0). | FLOAT | Нет | 0-63.0 |

**Примечание об альфа-канале:** Альфа-канал изображений RGBA сохраняется только при использовании кодека VP9. При использовании кодека AV1 альфа-канал игнорируется, и кодируются только данные RGB.

**Примечание об именовании файлов:** Видео сохраняются в выходной каталог как `{filename_prefix}_{counter:05}_.webm`, где счетчик автоматически увеличивается, чтобы избежать перезаписи существующих файлов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `изображения` | Входные изображения, передаваемые без изменений после сохранения видео. | IMAGE |
| UI preview | Предварительный просмотр видео, показывающий сохраненный WEBM-файл. | PREVIEW |
