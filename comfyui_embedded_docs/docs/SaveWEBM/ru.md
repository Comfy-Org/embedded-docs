# SaveWEBM

Узел SaveWEBM сохраняет последовательность изображений в видеофайл WEBM. Он кодирует входные изображения в видео с использованием кодеков VP9 или AV1 с настраиваемой частотой кадров и параметрами качества, а затем сохраняет файл в выходную директорию. Метаданные запроса (prompt) и рабочего процесса (workflow) встраиваются в видеофайл при их наличии.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Последовательность изображений для кодирования в видео. RGBA-изображения сохраняются с альфа-каналом как прозрачность (только для кодека vp9). | IMAGE | Да | - |
| `filename_prefix` | Префикс для имени выходного файла; счётчик и расширение .webm добавляются автоматически (по умолчанию: "ComfyUI") | STRING | Нет | - |
| `codec` | Видеокодек, используемый для кодирования | COMBO | Да | "vp9"<br>"av1" |
| `fps` | Частота кадров для выходного видео (по умолчанию: 24.0) | FLOAT | Нет | 0.01-1000.0 |
| `crf` | Более высокий CRF означает более низкое качество при меньшем размере файла, более низкий CRF — более высокое качество и больший размер файла (по умолчанию: 32.0) | FLOAT | Нет | 0-63.0 |

**Примечание об альфа-канале:** Альфа-канал RGBA-изображений сохраняется только при использовании кодека vp9. При использовании кодека av1 альфа-канал игнорируется, и кодируются только данные RGB.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Входная последовательность изображений, передаваемая без изменений | IMAGE |
| `ui` | Предварительный просмотр видео, показывающий сохранённый WEBM-файл | PREVIEW |
