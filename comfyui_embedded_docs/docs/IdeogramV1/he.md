# IdeogramV1

צומת IdeogramV1 יוצר תמונות באמצעות מודל Ideogram V1 דרך API. הוא מקבל הנחיות טקסט והגדרות יצירה שונות כדי ליצור תמונה אחת או יותר בהתבסס על הקלט שלך. הצומת תומך ביחסי רוחב-גובה שונים ובמצבי יצירה שונים כדי להתאים את הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: ריק) | STRING | כן | - |
| `turbo` | האם להשתמש במצב טורבו (יצירה מהירה יותר, איכות שעשויה להיות נמוכה יותר) (ברירת מחדל: False) | BOOLEAN | כן | - |
| `aspect_ratio` | יחס רוחב-גובה ליצירת התמונה (ברירת מחדל: "1:1") | COMBO | לא | "1:1"<br>"4:3"<br>"3:4"<br>"16:9"<br>"9:16"<br>"2:1"<br>"1:2"<br>"3:2"<br>"2:3"<br>"4:5"<br>"5:4" |
| `magic_prompt_option` | קבע אם להשתמש ב-MagicPrompt ביצירה (ברירת מחדל: "AUTO") | COMBO | לא | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | ערך seed אקראי ליצירה (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `negative_prompt` | תיאור של מה להחריג מהתמונה (ברירת מחדל: ריק) | STRING | לא | - |
| `num_images` | מספר התמונות ליצירה (ברירת מחדל: 1) | INT | לא | 1-8 |

**הערה:** לפרמטר `num_images` יש מגבלה מקסימלית של 8 תמונות לכל בקשת יצירה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | התמונה/התמונות שנוצרו ממודל Ideogram V1 | IMAGE |
