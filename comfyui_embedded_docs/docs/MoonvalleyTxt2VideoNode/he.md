# MoonvalleyTxt2VideoNode

הצומת Moonvalley Marey Text to Video יוצר תוכן וידאו מתיאורי טקסט באמצעות Moonvalley API. הוא מקבל הנחיית טקסט וממיר אותה לווידאו עם הגדרות הניתנות להתאמה לרזולוציה, איכות וסגנון. הצומת מטפל בכל התהליך, משליחת בקשת היצירה ועד הורדת פלט הווידאו הסופי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `prompt` | תיאור טקסטואלי של תוכן הווידאו ליצירה | STRING | כן | - |
| `negative_prompt` | טקסט הנחיה שלילית (ברירת מחדל: רשימה נרחבת של אלמנטים מוחרגים כמו synthetic, scene cut, artifacts, noise וכו') | STRING | לא | - |
| `resolution` | רזולוציית סרטון הפלט (ברירת מחדל: "16:9 (1920 x 1080)") | STRING | לא | "16:9 (1920 x 1080)"<br>"9:16 (1080 x 1920)"<br>"1:1 (1152 x 1152)"<br>"4:3 (1536 x 1152)"<br>"3:4 (1152 x 1536)"<br>"21:9 (2560 x 1080)" |
| `prompt_adherence` | סולם הנחיה לשליטה ביצירה (ברירת מחדל: 4.0) | FLOAT | לא | 1.0-20.0 |
| `seed` | ערך seed אקראי (ברירת מחדל: 9) | INT | לא | 0-4294967295 |
| `steps` | שלבי הסקה (ברירת מחדל: 33) | INT | לא | 1-100 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `video` | פלט הווידאו שנוצר בהתבסס על הנחיית הטקסט | VIDEO |
