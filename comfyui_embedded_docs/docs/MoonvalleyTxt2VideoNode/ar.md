# MoonvalleyTxt2VideoNode

تقوم عقدة Moonvalley Marey لتحويل النص إلى فيديو بإنشاء محتوى فيديو من الأوصاف النصية باستخدام واجهة برمجة تطبيقات Moonvalley. تأخذ هذه العقدة مطالبة نصية وتحولها إلى فيديو بإعدادات قابلة للتخصيص للدقة والجودة والأسلوب. تتعامل العقدة مع العملية بأكملها بدءًا من إرسال طلب التوليد وحتى تنزيل مخرجات الفيديو النهائية.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `prompt` | وصف نصي لمحتوى الفيديو المراد إنشاؤه | STRING | نعم | - |
| `negative_prompt` | نص المطالبة السلبية (الافتراضي: قائمة واسعة من العناصر المستبعدة مثل الاصطناعي، قطع المشهد، القطع الأثرية، الضوضاء، إلخ.) | STRING | لا | - |
| `resolution` | دقة الفيديو الناتج (الافتراضي: "16:9 (1920 × 1080)") | STRING | لا | "16:9 (1920 × 1080)"<br>"9:16 (1080 × 1920)"<br>"1:1 (1152 × 1152)"<br>"4:3 (1536 × 1152)"<br>"3:4 (1152 × 1536)"<br>"21:9 (2560 × 1080)" |
| `prompt_adherence` | مقياس التوجيه للتحكم في التوليد (الافتراضي: 4.0) | FLOAT | لا | 1.0-20.0 |
| `seed` | قيمة البذرة العشوائية (الافتراضي: 9) | INT | لا | 0-4294967295 |
| `steps` | خطوات الاستدلال (الافتراضي: 33) | INT | لا | 1-100 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `video` | مخرجات الفيديو المُنشأة بناءً على المطالبة النصية | VIDEO |
