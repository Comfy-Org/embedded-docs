# Пустой SD3LatentImage

Узел EmptySD3LatentImage создаёт пустой тензор латентного изображения, специально отформатированный для моделей Stable Diffusion 3. Он создаёт заполненный нулями тензор с правильными размерами и структурой, ожидаемыми конвейерами SD3. Обычно используется как отправная точка для рабочих процессов генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина выходного латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `height` | Высота выходного латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `batch_size` | Количество латентных изображений, генерируемых в одном пакете (по умолчанию: 1) | INT | Да | 1 to 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Тензор латентного представления, содержащий пустые образцы с размерами, совместимыми с SD3. Тензор имеет 16 каналов и пространственно уменьшен в 8 раз относительно входных ширины и высоты. | LATENT |
