# Пустой SD3LatentImage

EmptySD3LatentImage создаёт пустое (состоящее из нулей) латентное изображение в формате, который ожидают модели Stable Diffusion 3. Поскольку латент пуст, обычно он используется как отправная точка, которую рабочий процесс генерации заполняет изображением. Выбранные ширина и высота определяют размер итогового изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного изображения в пикселях (по умолчанию: 1024). Значения изменяются с шагом 16. | INT | Да | от 16 до MAX_RESOLUTION (шаг: 16) |
| `высота` | Высота латентного изображения в пикселях (по умолчанию: 1024). Значения изменяются с шагом 16. | INT | Да | от 16 до MAX_RESOLUTION (шаг: 16) |
| `размер_пакета` | Количество латентных изображений для генерации в пакете (по умолчанию: 1). | INT | Да | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Латентный тензор, содержащий пустые (состоящие из нулей) сэмплы в формате, совместимом с SD3. Тензор имеет 16 каналов, уменьшен в 8 раз относительно `width` и `height` и имеет коэффициент пространственного уменьшения, равный 8. | LATENT |
