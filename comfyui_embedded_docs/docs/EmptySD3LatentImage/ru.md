# Пустой SD3LatentImage

EmptySD3LatentImage создает пустой латентный тензор изображения, специально отформатированный для моделей Stable Diffusion 3. Он генерирует тензор, заполненный нулями, с правильными размерами и структурой, ожидаемыми конвейерами SD3. Это часто используется как отправная точка для рабочих процессов генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина выходного латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `высота` | Высота выходного латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `размер_пакета` | Количество латентных изображений для генерации за один пакет (по умолчанию: 1) | INT | Да | 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Латентный тензор, содержащий пустые образцы с совместимыми с SD3 размерами. Тензор имеет 16 каналов и пространственно уменьшен в 8 раз по сравнению с входной шириной и высотой. | LATENT |
