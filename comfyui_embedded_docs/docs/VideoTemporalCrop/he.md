# VideoTemporalCrop

צומת זה חותך טווח רציף של פריימים מסרטון. הוא פועל באופן עצל לחלוטין, כלומר הוא מעבד רק את החלק הנבחר מהסרטון לפי הצורך בהמשך זרימת העבודה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | סרטון קלט. | VIDEO | כן | – |
| `start_frame` | אינדקס פריים התחלה (ברירת מחדל: 0). | INT | כן | 0 עד 99999 |
| `length` | מספר הפריימים לשמירה (ברירת מחדל: 16). | INT | כן | 1 עד 99999 |

הערה: `start_frame` מוגבל כך שלא יעבור את הפריים האחרון של הסרטון, ו-`length` מצטמצם אם הוא יחרג מהפריימים הזמינים.
