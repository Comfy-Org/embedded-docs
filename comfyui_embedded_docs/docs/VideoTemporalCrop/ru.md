# Обрезка видео (по времени)

Этот узел обрезает непрерывный диапазон кадров из видео. Он работает полностью «ленивым» образом, то есть обрабатывает только выбранную часть видео по мере необходимости на последующих этапах рабочего процесса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Входное видео. | VIDEO | Да | – |
| `начальный_кадр` | Индекс начального кадра (по умолчанию: 0). | INT | Да | 0 to 99999 |
| `длина` | Количество сохраняемых кадров (по умолчанию: 16). | INT | Да | 1 to 99999 |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Обрезанное видео (ленивое). | VIDEO |
