# تصویر نهفته Hunyuan خالی

گره EmptyHunyuanImageLatent یک فضای نهفته خالی و تماماً صفر برای مدل‌های تولید تصویر Hunyuan می‌سازد. با استفاده از عرض، ارتفاع و اندازه دسته داده‌شده، یک لاتنت شروع خالی تولید می‌کند که سپس می‌توان آن را به گره‌های پایین‌دستی در گردش‌کار پاس داد. تنسور نهفته شامل ۶۴ کانال است و هر بُعد فضایی برابر با بُعد پیکسلی متناظر تقسیم بر ۳۲ است.
