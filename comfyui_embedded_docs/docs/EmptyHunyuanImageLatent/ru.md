# EmptyHunyuanImageLatent

Узел EmptyHunyuanImageLatent создает пустое (заполненное нулями) латентное пространство для моделей генерации изображений Hunyuan. Он генерирует пустой начальный латент с указанными шириной, высотой и размером пакета, который можно передать последующим узлам в рабочем процессе. Латентный тензор имеет 64 канала, а его пространственные размеры равны ширине и высоте, каждая из которых делится на 32.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `ширина` | Ширина сгенерированного латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | 64 to MAX_RESOLUTION |
| `высота` | Высота сгенерированного латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | 64 to MAX_RESOLUTION |
| `размер_пакета` | Количество латентных сэмплов для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `LATENT` | Пустой латентный тензор с 64 каналами и размерами высота ÷ 32 на ширина ÷ 32, готовый к обработке изображений Hunyuan | LATENT |
