# EmptyHunyuanImageLatent

Узел EmptyHunyuanImageLatent создает пустой латентный тензор с определенными размерами для использования с моделями генерации изображений Hunyuan. Он генерирует пустую начальную точку, которая может быть обработана последующими узлами в рабочем процессе. Узел позволяет указать ширину, высоту и размер пакета латентного пространства.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина генерируемого латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `height` | Высота генерируемого латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `batch_size` | Количество латентных образцов для генерации в одном пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Пустой латентный тензор с указанными размерами для обработки изображений Hunyuan. Тензор имеет 64 канала, а его пространственные размеры составляют одну тридцать вторую (1/32) запрошенной ширины и высоты. | LATENT |
