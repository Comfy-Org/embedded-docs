# EmptyHunyuanImageLatent

Узел EmptyHunyuanImageLatent создаёт пустое латентное пространство, заполненное нулями, для моделей генерации изображений Hunyuan. Он формирует пустой начальный латент с заданными шириной, высотой и размером пакета, который затем можно передавать в последующие узлы рабочего процесса. Латентный тензор содержит 64 канала, а каждый пространственный размер равен соответствующему размеру в пикселях, делённому на 32.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ширина` | Ширина генерируемого латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `высота` | Высота генерируемого латентного изображения в пикселях (по умолчанию: 2048, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `размер_пакета` | Количество латентных образцов для генерации в пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Пустой латентный тензор с 64 каналами и размерами высота ÷ 32 на ширина ÷ 32, готовый для обработки изображений Hunyuan | LATENT |
