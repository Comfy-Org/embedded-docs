# Patina Material Extract

Извлекает бесшовно тайлящийся PBR-материал из области входного изображения, используя промпт, который указывает, что именно нужно взять: стену, пол, ткань. Возвращает извлечённую базовую текстуру плюс до пяти карт материала, с дополнительным апскейлингом карт через SeedVR. Используйте этот узел, чтобы превратить фотографию реальной поверхности в переиспользуемый тайлируемый материал.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, из которого нужно извлечь текстуру. | IMAGE | Да | - |
| `prompt` | Описание того, какую текстуру извлечь из изображения, например `"the wall"`. | STRING | Да | Многострочный текст |
| `image_size` | Размер выходной текстуры. `"custom"` открывает входы `width` и `height`. По умолчанию: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Да | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | Сгенерировать карту базового цвета (albedo). По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `normal` | Сгенерировать карту нормалей. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `roughness` | Сгенерировать карту шероховатости. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `metalness` | Сгенерировать карту металличности. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `height` | Сгенерировать карту высоты (смещения). По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `upscale_factor` | Бесшовный апскейлинг PBR-карт с помощью SeedVR. Базовая текстура не апскейлится; 4x превращает карту 2048 пикселей в 8K. По умолчанию: 0 (выключено). | INT | Да | 0 до 4 (шаг: 2) |
| `seed` | Сид для воспроизводимой генерации. По умолчанию: 42. | INT | Да | 0 до 2147483646 |
| `strength` | Насколько сильно преобразовывать входное изображение. Расширенная настройка. По умолчанию: 0.6. | FLOAT | Да | 0.01 до 1.0 (шаг: 0.01) |
| `tiling_mode` | Направление тайлинга: всенаправленное, горизонтальное или вертикальное. Расширенная настройка. По умолчанию: `"both"`. | COMBO | Да | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | Шаги денойзинга для генерации текстуры. Расширенная настройка. По умолчанию: 8. | INT | Да | 1 до 8 |
| `tile_size` | Размер тайла в латентном пространстве, где 64 означает 512 пикселей, а 128 — 1024 пикселя. Расширенная настройка. По умолчанию: 128. | INT | Да | 32 до 256 (шаг: 2) |
| `tile_stride` | Шаг тайла в латентном пространстве. Расширенная настройка. По умолчанию: 64. | INT | Да | 16 до 128 (шаг: 2) |
| `prompt_expansion` | Расширять промпт с помощью языковой модели для более детализированной текстуры. По умолчанию выключено, поскольку расширение переформулирует промпт как фотографию и обычно размывает карту металличности. Расширенная настройка. | BOOLEAN | Да | true<br>false |
| `safety_checker` | Выполнять проверку безопасности содержимого запроса у провайдера. Расширенная настройка. По умолчанию: False. | BOOLEAN | Да | true<br>false |

### Входы пользовательского размера изображения

Эти входы появляются, когда `image_size` имеет значение `"custom"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | Ширина текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |
| `image_size.height` | Высота текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |

**Ограничения и поведение:**

* Разрешается не включать ни одной карты материала: в этом случае узел возвращает только базовую текстуру, а все выходы карт остаются заглушками 1x1.
* Промпт обязателен и не должен быть пустым; указывайте извлекаемую область как можно точнее.
* Результат 8K получается за счёт 4x-апскейлинга карт из рендера 2048 пикселей, а не из одной генерации 8K.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `texture` | Извлечённая базовая текстура без применения каких-либо карт. | IMAGE |
| `basecolor` | Карта базового цвета (albedo) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `normal` | Карта нормалей или заглушка 1x1, если эта карта отключена. | IMAGE |
| `roughness` | Карта шероховатости или заглушка 1x1, если эта карта отключена. | IMAGE |
| `metalness` | Карта металличности или заглушка 1x1, если эта карта отключена. | IMAGE |
| `height` | Карта высоты (смещения) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `expanded_prompt` | Промпт, который фактически использовал провайдер; отличается от входного только при включённом `prompt_expansion`. | STRING |
