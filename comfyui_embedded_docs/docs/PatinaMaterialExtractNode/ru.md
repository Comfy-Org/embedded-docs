# Patina Material Extract

Извлекает бесшовно тайлящийся PBR-материал из области входного изображения, руководствуясь промптом, который указывает, что именно взять: стену, пол, ткань. Возвращает извлечённую базовую текстуру плюс до пяти карт материала с опциональным апскейлингом карт через SeedVR. Используйте этот узел, чтобы превратить фотографию реальной поверхности в переиспользуемый материал с тайлингом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, из которого нужно извлечь текстуру. | IMAGE | Да | - |
| `prompt` | Описание того, какую текстуру извлечь из изображения, например `"the wall"`. | STRING | Да | Multiline text |
| `image_size` | Размер выходной текстуры. Значение `"custom"` открывает входы `width` и `height`. По умолчанию: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Да | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | Генерировать карту базового цвета (albedo). По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `normal` | Генерировать карту нормалей. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `roughness` | Генерировать карту шероховатости. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `metalness` | Генерировать карту металличности. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `height` | Генерировать карту высот (displacement). По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `upscale_factor` | Бесшовный апскейлинг PBR-карт через SeedVR. Базовая текстура не увеличивается; коэффициент 4x превращает карту размером 2048 пикселей в 8K. По умолчанию: 0 (выкл.). | INT | Да | 0 до 4 (шаг: 2) |
| `seed` | Сид для воспроизводимой генерации. По умолчанию: 42. | INT | Да | 0 до 2147483646 |
| `strength` | Насколько сильно преобразовывать входное изображение. Расширенная настройка. По умолчанию: 0.6. | FLOAT | Да | 0.01 до 1.0 (шаг: 0.01) |
| `tiling_mode` | Направление тайлинга: всенаправленный, горизонтальный или вертикальный. Расширенная настройка. По умолчанию: `"both"`. | COMBO | Да | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | Шаги денойзинга для генерации текстуры. Расширенная настройка. По умолчанию: 8. | INT | Да | 1 до 8 |
| `tile_size` | Размер тайла в латентном пространстве, где 64 означает 512 пикселей, а 128 — 1024 пикселя. Расширенная настройка. По умолчанию: 128. | INT | Да | 32 до 256 (шаг: 2) |
| `tile_stride` | Шаг тайла в латентном пространстве. Расширенная настройка. По умолчанию: 64. | INT | Да | 16 до 128 (шаг: 2) |
| `prompt_expansion` | Расширять промпт с помощью языковой модели для более богатой детализации текстуры. По умолчанию выключено, поскольку расширение переформулирует промпт как фотографию и обычно размывает карту металличности. Расширенная настройка. | BOOLEAN | Да | true<br>false |
| `safety_checker` | Запускать проверку безопасности содержимого запроса у провайдера. Расширенная настройка. По умолчанию: False. | BOOLEAN | Да | true<br>false |

### Входы пользовательского размера изображения

Эти входы появляются, когда для `image_size` задано значение `"custom"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | Ширина текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |
| `image_size.height` | Высота текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |

**Ограничения и поведение:**

* Должна быть включена хотя бы одна карта материала, иначе запуск завершится ошибкой.
* Промпт обязателен и не должен быть пустым; указывайте область для извлечения как можно точнее.
* Результат 8K получается в результате 4x-апскейлинга карт рендера размером 2048 пикселей, а не за счёт одной генерации 8K.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `texture` | Извлечённая базовая текстура без наложения каких-либо карт. | IMAGE |
| `basecolor` | Карта базового цвета (albedo) или заглушка 1x1, когда эта карта отключена. | IMAGE |
| `normal` | Карта нормалей или заглушка 1x1, когда эта карта отключена. | IMAGE |
| `roughness` | Карта шероховатости или заглушка 1x1, когда эта карта отключена. | IMAGE |
| `metalness` | Карта металличности или заглушка 1x1, когда эта карта отключена. | IMAGE |
| `height` | Карта высот (displacement) или заглушка 1x1, когда эта карта отключена. | IMAGE |
| `expanded_prompt` | Промпт, который фактически использовал провайдер; отличается от входного только если включён `prompt_expansion`. | STRING |
