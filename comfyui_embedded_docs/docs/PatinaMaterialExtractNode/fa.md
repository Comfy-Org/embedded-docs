# Patina Material Extract

یک متریال PBR با کاشی‌کاری بدون درز را از ناحیه‌ای از تصویر ورودی استخراج می‌کند، با هدایت پرامپتی که مشخص می‌کند چه چیزی برداشته شود: یک دیوار، یک کف، یک پارچه. بافت پایه استخراج‌شده به‌همراه حداکثر پنج نقشه متریال برمی‌گرداند، با امکان بزرگ‌نمایی اختیاری SeedVR برای نقشه‌ها. از آن برای تبدیل عکس یک سطح واقعی به متریالی قابل استفاده مجدد و قابل کاشی‌کاری استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که بافت از آن استخراج می‌شود. | IMAGE | بله | - |
| `prompt` | توضیح اینکه کدام بافت از تصویر استخراج شود، برای مثال `"the wall"`. | STRING | بله | متن چندخطی |
| `image_size` | اندازه بافت خروجی. `"custom"` ورودی‌های `width` و `height` را نمایش می‌دهد. پیش‌فرض: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | بله | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | نقشه basecolor (albedo) را تولید می‌کند. پیش‌فرض: True. | BOOLEAN | بله | true<br>false |
| `normal` | نقشه normal را تولید می‌کند. پیش‌فرض: True. | BOOLEAN | بله | true<br>false |
| `roughness` | نقشه roughness را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `metalness` | نقشه metalness را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `height` | نقشه height (displacement) را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `upscale_factor` | بزرگ‌نمایی بدون درز SeedVR برای نقشه‌های PBR. بافت پایه بزرگ‌نمایی نمی‌شود، و 4x یک نقشه 2048 پیکسلی را به یک نقشه 8K تبدیل می‌کند. پیش‌فرض: 0 (خاموش). | INT | بله | 0 تا 4 (گام: 2) |
| `seed` | seed برای تولید قابل بازتولید. پیش‌فرض: 42. | INT | بله | 0 تا 2147483646 |
| `strength` | میزان تغییر تصویر ورودی. تنظیم پیشرفته. پیش‌فرض: 0.6. | FLOAT | بله | 0.01 تا 1.0 (گام: 0.01) |
| `tiling_mode` | جهت کاشی‌کاری: همه‌جهته، افقی یا عمودی. تنظیم پیشرفته. پیش‌فرض: `"both"`. | COMBO | بله | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | مراحل نویززدایی برای تولید بافت. تنظیم پیشرفته. پیش‌فرض: 8. | INT | بله | 1 تا 8 |
| `tile_size` | اندازه کاشی در فضای latent، که در آن 64 یعنی 512 پیکسل و 128 یعنی 1024 پیکسل. تنظیم پیشرفته. پیش‌فرض: 128. | INT | بله | 32 تا 256 (گام: 2) |
| `tile_stride` | گام کاشی در فضای latent. تنظیم پیشرفته. پیش‌فرض: 64. | INT | بله | 16 تا 128 (گام: 2) |
| `prompt_expansion` | گسترش پرامپت با یک مدل زبانی برای جزئیات غنی‌تر بافت. به‌طور پیش‌فرض خاموش است، زیرا گسترش پرامپت را به‌صورت یک عکس بازقالب‌بندی می‌کند و معمولاً نقشه metalness را کمرنگ می‌کند. تنظیم پیشرفته. | BOOLEAN | بله | true<br>false |
| `safety_checker` | اجرای بررسی ایمنی محتوای ارائه‌دهنده روی درخواست. تنظیم پیشرفته. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |

### ورودی‌های اندازه تصویر سفارشی

این ورودی‌ها زمانی ظاهر می‌شوند که `image_size` روی `"custom"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | عرض بافت بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 512 تا 2048 (گام: 16) |
| `image_size.height` | ارتفاع بافت بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 512 تا 2048 (گام: 16) |

**محدودیت‌ها و رفتار:**

* حداقل یک نقشه متریال باید فعال باشد، در غیر این صورت اجرا شکست می‌خورد.
* پرامپت الزامی است و نباید خالی باشد؛ ناحیه‌ای که باید استخراج شود را تا حد امکان دقیق نام‌گذاری کنید.
* نتیجه 8K از بزرگ‌نمایی 4x نقشه‌های یک رندر 2048 پیکسلی به دست می‌آید، نه از یک تولید واحد 8K.
