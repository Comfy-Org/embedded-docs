# Patina Material Extract

یک متریال PBR با کاشی‌بندی بدون درز را از ناحیه‌ای از تصویر ورودی استخراج می‌کند، با هدایت یک پرامپت که مشخص می‌کند چه چیزی برداشته شود: یک دیوار، یک کف، یک پارچه. بافت پایه استخراج‌شده به‌همراه حداکثر پنج نقشه متریال را برمی‌گرداند، با بزرگ‌نمایی اختیاری SeedVR برای نقشه‌ها. از آن برای تبدیل عکس یک سطح واقعی به یک متریال قابل استفاده مجدد و کاشی‌پذیر استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که بافت از آن استخراج می‌شود. | IMAGE | بله | - |
| `prompt` | توضیح اینکه کدام بافت از تصویر استخراج شود، برای مثال `"the wall"`. | STRING | بله | متن چندخطی |
| `image_size` | اندازه بافت خروجی. `"custom"` ورودی‌های `width` و `height` را نمایش می‌دهد. پیش‌فرض: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | بله | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | نقشه basecolor (albedo) را تولید می‌کند. پیش‌فرض: True. | BOOLEAN | بله | true<br>false |
| `normal` | نقشه normal را تولید می‌کند. پیش‌فرض: True. | BOOLEAN | بله | true<br>false |
| `roughness` | نقشه roughness را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `metalness` | نقشه metalness را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `height` | نقشه height (displacement) را تولید می‌کند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `upscale_factor` | بزرگ‌نمایی بدون درز SeedVR برای نقشه‌های PBR. بافت پایه بزرگ‌نمایی نمی‌شود، و 4x یک نقشه 2048 پیکسلی را به یک نقشه 8K تبدیل می‌کند. پیش‌فرض: 0 (خاموش). | INT | بله | 0 تا 4 (گام 2) |
| `seed` | مقدار `seed` برای تولید قابل بازتولید. پیش‌فرض: 42. | INT | بله | 0 تا 2147483646 |
| `strength` | میزان تغییر تصویر ورودی. تنظیم پیشرفته. پیش‌فرض: 0.6. | FLOAT | بله | 0.01 تا 1.0 (گام 0.01) |
| `tiling_mode` | جهت کاشی‌بندی: همه‌جهته، افقی یا عمودی. تنظیم پیشرفته. پیش‌فرض: `"both"`. | COMBO | بله | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | مراحل رفع نویز (denoising) برای تولید بافت. تنظیم پیشرفته. پیش‌فرض: 8. | INT | بله | 1 تا 8 |
| `tile_size` | اندازه کاشی در فضای latent، که در آن 64 یعنی 512 پیکسل و 128 یعنی 1024 پیکسل. تنظیم پیشرفته. پیش‌فرض: 128. | INT | بله | 32 تا 256 (گام 2) |
| `tile_stride` | گام کاشی در فضای latent. تنظیم پیشرفته. پیش‌فرض: 64. | INT | بله | 16 تا 128 (گام 2) |
| `prompt_expansion` | پرامپت را با یک مدل زبانی برای جزئیات بافت غنی‌تر گسترش می‌دهد. به‌طور پیش‌فرض خاموش است، زیرا گسترش، پرامپت را به‌صورت یک عکس بازقالب‌بندی می‌کند و معمولاً باعث کم‌رنگ شدن نقشه metalness می‌شود. تنظیم پیشرفته. | BOOLEAN | بله | true<br>false |
| `safety_checker` | بررسی ایمنی محتوای ارائه‌دهنده را روی درخواست اجرا می‌کند. تنظیم پیشرفته. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |

### ورودی‌های اندازه تصویر سفارشی

این ورودی‌ها زمانی نمایش داده می‌شوند که `image_size` روی `"custom"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | عرض بافت بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 512 تا 2048 (گام 16) |
| `image_size.height` | ارتفاع بافت بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 512 تا 2048 (گام 16) |

**محدودیت‌ها و رفتار:**

* فعال نکردن هیچ نقشه متریالی مجاز است: در این صورت گره فقط بافت پایه را برمی‌گرداند و هر خروجی نقشه به‌صورت یک جای‌نگهدار 1x1 باقی می‌ماند.
* پرامپت الزامی است و نباید خالی باشد؛ ناحیه‌ای را که باید استخراج شود تا حد امکان دقیق نام‌گذاری کنید.
* نتیجه 8K از بزرگ‌نمایی 4x نقشه‌های یک رندر 2048 پیکسلی به دست می‌آید، نه از یک تولید تک‌مرحله‌ای 8K.
