# Patina Material Extract

يستخرج مادة PBR قابلة للتبليط بسلاسة من منطقة في صورة إدخال، موجّهًا بموجّه نصي يحدد ما يجب أخذه: جدار، أو أرضية، أو قماش. يعيد الخامة الأساسية المستخرجة بالإضافة إلى ما يصل إلى خمس خرائط مواد، مع إمكانية رفع دقة الخرائط اختياريًا باستخدام SeedVR. استخدمه لتحويل صورة لسطح حقيقي إلى مادة قابلة لإعادة الاستخدام وقابلة للتبليط.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المراد استخراج خامة منها. | IMAGE | نعم | - |
| `prompt` | وصف الخامة أو النسيج المراد استخراجه من الصورة، على سبيل المثال `"the wall"`. | STRING | نعم | نص متعدد الأسطر |
| `image_size` | حجم الخامة الناتجة. عند اختيار `"custom"` تظهر مدخلات `width` و`height`. الافتراضي: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | نعم | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | توليد خريطة basecolor (albedo). الافتراضي: True. | BOOLEAN | نعم | true<br>false |
| `normal` | توليد خريطة normal. الافتراضي: True. | BOOLEAN | نعم | true<br>false |
| `roughness` | توليد خريطة الخشونة. الافتراضي: False. | BOOLEAN | نعم | true<br>false |
| `metalness` | توليد خريطة metalness. الافتراضي: False. | BOOLEAN | نعم | true<br>false |
| `height` | توليد خريطة الارتفاع (الإزاحة). الافتراضي: False. | BOOLEAN | نعم | true<br>false |
| `upscale_factor` | رفع دقة خرائط PBR باستخدام SeedVR مع الحفاظ على التبليط السلس. لا يتم رفع دقة الخامة الأساسية، ويحوّل المعامل 4x خريطة بحجم 2048 بكسل إلى خريطة 8K. الافتراضي: 0 (إيقاف). | INT | نعم | 0 إلى 4 (خطوة 2) |

| `tiling_mode` | اتجاه التبليط: متعدد الاتجاهات، أو أفقي، أو رأسي. إعداد متقدم. الافتراضي: `"both"`. | COMBO | نعم | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | خطوات إزالة الضوضاء لتوليد الخامة. إعداد متقدم. الافتراضي: 8. | INT | نعم | 1 إلى 8 |
| `tile_size` | حجم البلاطة في الفضاء الكامن، حيث يعني 64 حجم 512 بكسل و128 يعني 1024 بكسل. إعداد متقدم. الافتراضي: 128. | INT | نعم | 32 إلى 256 (خطوة 2) |
| `tile_stride` | خطوة البلاطة في الفضاء الكامن. إعداد متقدم. الافتراضي: 64. | INT | نعم | 16 إلى 128 (خطوة 2) |
| `prompt_expansion` | توسيع الموجّه النصي باستخدام نموذج لغوي للحصول على تفاصيل نسيج أغنى. معطّل افتراضيًا، لأن التوسيع يعيد تأطير الموجّه النصي كصورة فوتوغرافية ويميل إلى إضعاف خريطة metalness. إعداد متقدم. | BOOLEAN | نعم | true<br>false |
| `safety_checker` | تشغيل فحص سلامة المحتوى الخاص بالمزوّد على الطلب. إعداد متقدم. الافتراضي: False. | BOOLEAN | نعم | true<br>false |

### مدخلات custom Image Size

تظهر هذه المدخلات عندما يتم ضبط `image_size` على `"custom"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | عرض الخامة بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة 16) |
| `image_size.height` | ارتفاع الخامة بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة 16) |

**القيود والسلوك:**

* يجب تمكين خريطة مواد واحدة على الأقل، وإلا ستفشل عملية التشغيل.
* الموجّه النصي مطلوب ويجب ألا يكون فارغًا؛ حدّد المنطقة المراد استخراجها بأكبر قدر ممكن من الدقة.
* تنتج نتيجة 8K عن رفع دقة الخرائط بمقدار 4x لعملية تصيير بحجم 2048 بكسل، وليس عن توليد واحد بدقة 8K.
