# MoonvalleyImg2VideoNode

הצומת Moonvalley Marey Image to Video ממיר תמונת ייחוס לווידאו באמצעות Moonvalley API. הוא מקבל תמונת קלט ופרומפט טקסטואלי כדי ליצור וידאו עם רזולוציה מוגדרת, הגדרות איכות ובקרות יצירתיות. הצומת מטפל בכל התהליך מהעלאת התמונה ועד יצירת הווידאו והורדתו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הייחוס המשמשת ליצירת הווידאו | IMAGE | כן | - |
| `prompt` | תיאור טקסטואלי ליצירת וידאו (קלט רב-שורתי) | STRING | כן | - |
| `negative_prompt` | טקסט פרומפט שלילי להחרגת אלמנטים לא רצויים (ברירת מחדל: רשימה מפורטת של פרומפטים שליליים) | STRING | לא | - |
| `resolution` | רזולוציית הווידאו של הפלט (ברירת מחדל: "16:9 (1920 x 1080)") | COMBO | לא | "16:9 (1920 x 1080)"<br>"9:16 (1080 x 1920)"<br>"1:1 (1152 x 1152)"<br>"4:3 (1536 x 1152)"<br>"3:4 (1152 x 1536)" |
| `prompt_adherence` | סקאלת הנחיה לשליטה ביצירה (ברירת מחדל: 4.5, צעד: 1.0) | FLOAT | לא | 1.0 - 20.0 |
| `seed` | ערך seed אקראי (ברירת מחדל: 9, שליטה לאחר יצירה מופעלת) | INT | לא | 0 - 4294967295 |
| `steps` | מספר צעדי הסרת רעש (ברירת מחדל: 33, צעד: 1) | INT | לא | 1 - 100 |

**אילוצים:**

- לתמונת הקלט חייבים להיות ממדים בין 300x300 פיקסלים לבין הגובה/רוחב המרבי המותר
- אורך הטקסט של פרומפט ופרומפט שלילי מוגבל לאורך הפרומפט המרבי של Moonvalley Marey
