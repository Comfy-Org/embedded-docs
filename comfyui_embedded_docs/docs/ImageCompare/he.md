# השוואת תמונות

## סקירה כללית

הצומת Image Compare מספק ממשק חזותי להשוואה בין שתי תמונות זו לצד זו באמצעות סליידר הניתן לגרירה. הוא מתוכנן כצומת פלט, כלומר הוא אינו מעביר נתונים לצמתים אחרים, אלא מציג את התמונות ישירות בממשק המשתמש לצורך בדיקה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image_a` | התמונה הראשונה להשוואה. | IMAGE | לא | - |
| `image_b` | התמונה השנייה להשוואה. | IMAGE | לא | - |
| `compare_view` | הבקרה שמאפשרת את תצוגת השוואת הסליידר בממשק המשתמש. | IMAGECOMPARE | כן | - |

**הערה:** צומת זה הוא צומת פלט. למרות ש-`image_a` ו-`image_b` הם אופציונליים, יש לספק לפחות תמונה אחת כדי שלצומת תהיה השפעה נראית לעין. הצומת יציג אזור ריק עבור כל קלט תמונה שאינו מחובר. כל מקבץ תמונות שסופק נשמר באחסון זמני תחת הקידומות `comfy.compare.a` ו-`comfy.compare.b` בהתאמה, ולאחר מכן מוצג בתצוגת הסליידר.
