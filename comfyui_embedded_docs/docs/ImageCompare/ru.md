# Сравнение изображений

Узел **Image Compare** предоставляет визуальный интерфейс для сравнения двух изображений бок о бок с помощью перетаскиваемого ползунка. Он предназначен как выходной узел: он не передаёт данные другим узлам, а отображает изображения непосредственно в пользовательском интерфейсе для просмотра.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image_a` | Первое изображение для сравнения. | IMAGE | Нет | - |
| `image_b` | Второе изображение для сравнения. | IMAGE | Нет | - |
| `compare_view` | Элемент управления, включающий режим сравнения с помощью ползунка в интерфейсе. | IMAGECOMPARE | Да | - |

**Примечание:** Этот узел является выходным. Хотя `image_a` и `image_b` необязательны, для видимого результата необходимо подать хотя бы одно изображение. Узел будет отображать пустую область для любого неподключенного входа изображения.

## Выходы

Этот узел является выходным и не создаёт выходных данных для использования в других узлах. Его функция — отображать переданные изображения в интерфейсе ComfyUI.
