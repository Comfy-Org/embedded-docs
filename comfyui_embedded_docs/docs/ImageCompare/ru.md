# Сравнение изображений

## Обзор

Узел Image Compare предоставляет визуальный интерфейс для сравнения двух изображений рядом друг с другом с помощью перетаскиваемого ползунка. Он спроектирован как выходной узел, то есть не передаёт данные другим узлам, а вместо этого отображает изображения непосредственно в пользовательском интерфейсе для просмотра.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image_a` | Первое изображение для сравнения. | IMAGE | Нет | - |
| `image_b` | Второе изображение для сравнения. | IMAGE | Нет | - |
| `compare_view` | Элемент управления, включающий режим сравнения с ползунком в интерфейсе. | IMAGECOMPARE | Да | - |

**Примечание:** Этот узел является выходным. Хотя `image_a` и `image_b` необязательны, необходимо предоставить хотя бы одно изображение, чтобы узел оказал видимый эффект. Для любого неподключённого входа изображения узел отобразит пустую область. Каждый предоставленный пакет изображений сохраняется во временное хранилище с префиксами `comfy.compare.a` и `comfy.compare.b` соответственно, после чего отображается в режиме сравнения с ползунком.

## Выходы

Этот узел является выходным и не создаёт выходных данных для использования другими узлами. Его функция — отображать предоставленные изображения в интерфейсе ComfyUI.
