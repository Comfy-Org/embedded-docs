# مقایسه تصویر

## مرور کلی

گره Image Compare یک رابط بصری برای مقایسه دو تصویر به‌صورت کنار‌به‌کنار با استفاده از یک اسلایدر قابل‌کشیدن فراهم می‌کند. این گره به‌عنوان یک گره خروجی طراحی شده است؛ یعنی داده‌ای را به گره‌های دیگر منتقل نمی‌کند و در عوض تصاویر را مستقیماً در رابط کاربری برای بررسی نمایش می‌دهد.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image_a` | اولین تصویر برای مقایسه. | IMAGE | خیر | - |
| `image_b` | دومین تصویر برای مقایسه. | IMAGE | خیر | - |
| `compare_view` | کنترلی که نمای مقایسه‌ای اسلایدری را در رابط کاربری فعال می‌کند. | IMAGECOMPARE | بله | - |

**توجه:** این گره یک گره خروجی است. هرچند `image_a` و `image_b` اختیاری هستند، برای اینکه گره اثر قابل‌مشاهده داشته باشد باید حداقل یک تصویر ارائه شود. گره برای هر ورودی تصویری که متصل نباشد، یک ناحیه خالی نمایش می‌دهد. هر دسته تصویر ارائه‌شده به‌ترتیب در فضای ذخیره‌سازی موقت با پیشوندهای `comfy.compare.a` و `comfy.compare.b` ذخیره می‌شود و سپس در نمای اسلایدر نمایش داده می‌شود.

## خروجی‌ها

این گره یک گره خروجی است و هیچ خروجی داده‌ای برای استفاده در گره‌های دیگر تولید نمی‌کند. کارکرد آن نمایش تصاویر ارائه‌شده در رابط کاربری ComfyUI است.
