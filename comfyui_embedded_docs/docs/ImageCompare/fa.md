# مقایسه تصویر

گره Image Compare یک رابط بصری برای مقایسه دو تصویر در کنار یکدیگر با استفاده از یک لغزنده قابل‌کشیدن فراهم می‌کند. این گره به‌عنوان یک گره خروجی طراحی شده است؛ به این معنی که داده‌ای به گره‌های دیگر منتقل نمی‌کند، بلکه تصاویر را مستقیماً در رابط کاربری برای بازرسی نمایش می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `تصویر A` | اولین تصویر برای مقایسه. | IMAGE | خیر | - |
| `تصویر B` | دومین تصویر برای مقایسه. | IMAGE | خیر | - |
| `نمای مقایسه` | کنترلی که نمای مقایسه کشویی را در رابط کاربری فعال می‌کند. | IMAGECOMPARE | بله | - |

**توجه:** این گره یک گره خروجی است. اگرچه `image_a` و `image_b` اختیاری هستند، برای اینکه گره اثر قابل‌مشاهده‌ای داشته باشد، حداقل یک تصویر باید ارائه شود. گره برای هر ورودی تصویری که متصل نشده باشد، یک ناحیه خالی نمایش می‌دهد.

## خروجی‌ها

این گره یک گره خروجی است و هیچ خروجی داده‌ای برای استفاده در گره‌های دیگر تولید نمی‌کند. عملکرد آن نمایش تصاویر ارائه‌شده در رابط کاربری ComfyUI است.
