# رمزگشایی VAE (کاشی‌بندی‌شده)

گرهای `VAEDecodeTiled` بازنمایی‌های نهفته (latent) را با استفاده از رویکرد تایل‌شده به تصاویر تبدیل می‌کند تا تصاویر بزرگ را به‌طور کارآمد مدیریت کند. این گره ورودی را در تایل‌های کوچک‌تری پردازش می‌کند تا مصرف حافظه را کنترل کرده و کیفیت تصویر را حفظ کند. همچنین این گره از VAEهای ویدیویی با پردازش فریم‌های زمانی به‌صورت تکه‌هایی با همپوشانی برای انتقال نرم پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نمونه‌ها` | بازنمایی نهفته که باید به تصویر رمزگشایی شود | LATENT | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگشایی نمونه‌های نهفته | VAE | بله | - |
| `اندازه کاشی` | اندازه هر تایل برای پردازش (پیش‌فرض: 512) | INT | بله | 64-4096 (گام: 32) |
| `همپوشانی` | میزان همپوشانی بین تایل‌های مجاور (پیش‌فرض: 64) | INT | بله | 0-4096 (گام: 32) |
| `اندازه زمانی` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌هایی که در هر بار رمزگشایی می‌شوند (پیش‌فرض: 64) | INT | بله | 8-4096 (گام: 4) |
| `همپوشانی زمانی` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌های همپوشانی (پیش‌فرض: 8) | INT | بله | 4-4096 (گام: 4) |

**نکته:** گره به‌طور خودکار مقادیر همپوشانی را در صورت فراتر رفتن از محدودیت‌های عملی تنظیم می‌کند. اگر `tile_size` کمتر از ۴ برابر `overlap` باشد، همپوشانی به یک‌چهارم اندازه تایل کاهش می‌یابد. به‌طور مشابه، اگر `temporal_size` کمتر از دو برابر `temporal_overlap` باشد، همپوشانی زمانی نصف می‌شود. گره همچنین نسبت‌های فشرده‌سازی داخلی VAE را هنگام محاسبه اندازه‌های تایل و همپوشانی برای هر دو بعد مکانی و زمانی در نظر می‌گیرد. اگر ورودی نهفته یک دسته تودرتو از latentها باشد، فقط اولین آیتم در دسته رمزگشایی می‌شود.
