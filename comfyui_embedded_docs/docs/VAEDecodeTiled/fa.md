# رمزگشایی VAE (کاشی‌بندی‌شده)

گره VAEDecodeTiled با استفاده از رویکرد تایل‌بندی، بازنمایی‌های لاتنت را به تصاویر تبدیل می‌کند تا تصاویر بزرگ را به‌طور کارآمد پردازش کند. این گره ورودی را به تایل‌های کوچک‌تر تقسیم می‌کند تا مصرف حافظه مدیریت شود و کیفیت تصویر حفظ گردد. همچنین با پردازش فریم‌های زمانی به‌صورت تکه‌تکه و با هم‌پوشانی برای انتقال نرم، از VAEهای ویدیویی پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | بازنمایی لاتنتی که باید به تصویر تبدیل شود | LATENT | بله | - |
| `vae` | مدل VAE که برای رمزگشایی نمونه‌های لاتنت استفاده می‌شود | VAE | بله | - |
| `tile_size` | اندازه هر تایل برای پردازش (پیش‌فرض: 512) | INT | بله | 64-4096 (step: 32) |
| `overlap` | میزان هم‌پوشانی بین تایل‌های مجاور (پیش‌فرض: 64) | INT | بله | 0-4096 (step: 32) |
| `temporal_size` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌هایی که در هر بار رمزگشایی می‌شوند (پیش‌فرض: 64) | INT | بله | 8-4096 (step: 4) |
| `temporal_overlap` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌های هم‌پوشانی (پیش‌فرض: 8) | INT | بله | 4-4096 (step: 4) |

**نکته:** این گره به‌طور خودکار مقادیر هم‌پوشانی را در صورت تجاوز از محدوده‌های عملی تنظیم می‌کند. اگر `tile_size` کمتر از 4 برابر `overlap` باشد، هم‌پوشانی به یک‌چهارم اندازه تایل کاهش می‌یابد. به همین ترتیب، اگر `temporal_size` کمتر از دو برابر `temporal_overlap` باشد، هم‌پوشانی زمانی نصف می‌شود. گره همچنین نسبت‌های فشرده‌سازی داخلی VAE را هنگام محاسبه اندازه تایل و هم‌پوشانی برای هر دو بعد مکانی و زمانی در نظر می‌گیرد. برای VAEهای بدون فشرده‌سازی زمانی (VAEهای غیرویدیویی)، پارامترهای `temporal_size` و `temporal_overlap` نادیده گرفته می‌شوند.
