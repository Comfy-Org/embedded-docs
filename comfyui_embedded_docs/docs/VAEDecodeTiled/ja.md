# VAEデコード（タイル）

VAEDecodeTiled ノードは、タイル方式を用いて潜在表現を画像にデコードし、大きな画像を効率的に処理します。メモリ使用量を管理しながら画像品質を維持するために、入力を小さなタイルに分割して処理します。また、このノードはビデオVAEにも対応しており、時間的なフレームをチャンク単位で重複させながら処理することで、滑らかな遷移を実現します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `samples` | デコードして画像に変換する潜在表現です。 | LATENT | はい | - |
| `vae` | 潜在サンプルのデコードに使用するVAEモデルです。 | VAE | はい | - |
| `tile_size` | 処理時の各タイルのサイズです（デフォルト: 512）。 | INT | はい | 64-4096 (step: 32) |
| `overlap` | 隣接するタイル間の重なり量です（デフォルト: 64）。 | INT | はい | 0-4096 (step: 32) |
| `temporal_size` | ビデオVAEでのみ使用されます。一度にデコードするフレーム数です（デフォルト: 64）。 | INT | はい | 8-4096 (step: 4) |
| `temporal_overlap` | ビデオVAEでのみ使用されます。重複させるフレーム数です（デフォルト: 8）。 | INT | はい | 4-4096 (step: 4) |

**注記:** ノードは、オーバーラップ値が実用的な制限を超えている場合、自動的に調整します。`tile_size` が `overlap` の4倍未満の場合、オーバーラップはタイルサイズの4分の1に縮小されます。同様に、`temporal_size` が `temporal_overlap` の2倍未満の場合、時間的オーバーラップは半分にされます。また、ノードは空間的および時間的次元の両方について、タイルサイズとオーバーラップサイズを計算する際に、VAEの内部圧縮率も考慮します。時間的圧縮のないVAE（非ビデオVAE）の場合、`temporal_size` と `temporal_overlap` のパラメータは無視されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | 潜在表現から生成されたデコード済みの画像、または画像群です。ビデオの潜在表現をデコードする場合、すべてのデコード済みフレームが1つの画像リストに結合されます。 | IMAGE |
