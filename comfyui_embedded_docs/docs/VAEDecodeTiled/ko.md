# VAE 디코드 (타일)

VAEDecodeTiled 노드는 타일링 방식을 사용하여 잠재 표현을 이미지로 디코딩하며, 대형 이미지를 효율적으로 처리합니다. 입력을 더 작은 타일로 나누어 처리함으로써 메모리 사용량을 관리하면서도 이미지 품질을 유지합니다. 또한 이 노드는 시간적 프레임을 겹침과 함께 청크 단위로 처리하여 매끄러운 전환을 제공함으로써 비디오 VAE도 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `samples` | 이미지로 디코딩할 잠재 표현입니다 | LATENT | 예 | - |
| `vae` | 잠재 샘플을 디코딩하는 데 사용되는 VAE 모델입니다 | VAE | 예 | - |
| `tile_size` | 처리할 각 타일의 크기입니다 (기본값: 512) | INT | 예 | 64-4096 (step: 32) |
| `overlap` | 인접한 타일 간의 겹침 정도입니다 (기본값: 64) | INT | 예 | 0-4096 (step: 32) |
| `temporal_size` | 비디오 VAE에서만 사용됩니다: 한 번에 디코딩할 프레임 수입니다 (기본값: 64) | INT | 예 | 8-4096 (step: 4) |
| `temporal_overlap` | 비디오 VAE에서만 사용됩니다: 겹칠 프레임 수입니다 (기본값: 8) | INT | 예 | 4-4096 (step: 4) |

**참고:** 노드는 겹침 값이 실질적인 한계를 초과하는 경우 이를 자동으로 조정합니다. `tile_size`가 `overlap`의 4배보다 작으면 겹침은 타일 크기의 4분의 1로 줄어듭니다. 마찬가지로 `temporal_size`가 `temporal_overlap`의 2배보다 작으면 시간적 겹침은 절반으로 줄어듭니다. 또한 노드는 공간 및 시간 차원 모두에서 타일과 겹침 크기를 계산할 때 VAE의 내부 압축 비율을 고려합니다. 시간적 압축이 없는 VAE(비디오가 아닌 VAE)의 경우 `temporal_size` 및 `temporal_overlap` 매개변수는 무시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `IMAGE` | 잠재 표현에서 생성된 디코딩된 이미지 또는 이미지들입니다. 비디오 잠재를 디코딩할 때 모든 디코딩된 프레임이 단일 이미지 목록으로 결합됩니다. | IMAGE |
