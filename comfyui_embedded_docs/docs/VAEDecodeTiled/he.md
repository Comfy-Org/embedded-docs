# VAEDecodeTiled

הצומת VAEDecodeTiled מפענח ייצוגים לטנטיים לתמונות באמצעות גישה מבוססת אריחים כדי להתמודד ביעילות עם תמונות גדולות. הוא מעבד את הקלט באריחים קטנים יותר כדי לנהל את השימוש בזיכרון תוך שמירה על איכות התמונה. הצומת תומך גם ב-VAE לווידאו על ידי עיבוד פריימים לאורך הציר הזמני במקטעים עם חפיפה כדי להבטיח מעברים חלקים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `samples` | הייצוג הלטנטי שיש לפענח לתמונות | LATENT | כן | - |
| `vae` | מודל ה-VAE המשמש לפענוח דגימות לטנטיות | VAE | כן | - |
| `tile_size` | גודל כל אריח לעיבוד (ברירת מחדל: 512) | INT | כן | 64-4096 (step: 32) |
| `overlap` | כמות החפיפה בין אריחים סמוכים (ברירת מחדל: 64) | INT | כן | 0-4096 (step: 32) |
| `temporal_size` | משמש רק ל-VAE לווידאו: מספר הפריימים לפענוח בכל פעם (ברירת מחדל: 64) | INT | כן | 8-4096 (step: 4) |
| `temporal_overlap` | משמש רק ל-VAE לווידאו: מספר הפריימים לחפיפה (ברירת מחדל: 8) | INT | כן | 4-4096 (step: 4) |

**הערה:** הקלטים `tile_size`, `overlap`, `temporal_size` ו-`temporal_overlap` מסומנים כהגדרות מתקדמות.

**הערה:** הצומת מתאים אוטומטית את ערכי החפיפה אם הם חורגים מגבולות מעשיים. אם `tile_size` קטן מ-4 כפול `overlap`, החפיפה מצטמצמת לרבע מגודל האריח. באופן דומה, אם `temporal_size` קטן מ-2 כפול `temporal_overlap`, החפיפה הזמנית מצטמצמת בחצי. הצומת גם מתחשב ביחסי הדחיסה הפנימיים של ה-VAE בעת חישוב גדלי האריחים והחפיפה הן בממדים המרחביים והן בממדים הזמניים. אם הייצוג הלטנטי בקלט הוא אצווה מקוננת של ייצוגים לטנטיים, רק הפריט הראשון באצווה מפוענח.
