# VAE 解碼（分割區塊）

VAEDecodeTiled 節點使用分塊方法將潛在表示解碼為影像，以有效率地處理大型影像。它會將輸入分成較小的區塊進行處理，以管理記憶體使用量，同時維持影像品質。此節點也支援影片 VAE，透過以具有重疊的區塊處理時間影格，以實現平順的轉場。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `樣本` | 要解碼為影像的潛在表示 | LATENT | 是 | - |
| `vae` | 用於解碼潛在樣本的 VAE 模型 | VAE | 是 | - |
| `區塊大小` | 每個區塊的處理大小（預設值：512） | INT | 是 | 64-4096 （步進值：32） |
| `重疊` | 相鄰區塊之間的重疊量（預設值：64） | INT | 是 | 0-4096 （步進值：32） |
| `時間區塊大小` | 僅用於影片 VAE：一次解碼的影格數量（預設值：64） | INT | 是 | 8-4096 （步進值：4） |
| `時間重疊` | 僅用於影片 VAE：重疊的影格數量（預設值：8） | INT | 是 | 4-4096 （步進值：4） |

**注意：** `tile_size`、`overlap`、`temporal_size` 和 `temporal_overlap` 輸入標記為進階設定。

**注意：** 如果重疊值超出實際限制，此節點會自動調整它們。如果 `tile_size` 小於 `overlap` 的 4 倍，則會將重疊縮減為區塊大小的四分之一。類似地，如果 `temporal_size` 小於 `temporal_overlap` 的兩倍，則會將時間重疊減半。在計算空間與時間維度的區塊與重疊大小時，此節點也會考量 VAE 的內部壓縮比例。如果輸入的潛在表示是巢狀的潛在批次，則只會解碼批次中的第一個項目。
