# VAE 解碼（分割區塊）

VAEDecodeTiled 節點使用平鋪（tiled）方法將潛在表示解碼為影像，以有效處理大型影像。它將輸入拆分為較小的區塊進行處理，以管理記憶體使用量，同時保持影像品質。此節點還透過以重疊方式分批處理時間幀來支援影片 VAE，以實現平滑轉換。

## 輸入
| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `樣本` | 要解碼為影像的潛在表示 | LATENT | 是 | - |
| `vae` | 用於解碼潛在樣本的 VAE 模型 | VAE | 是 | - |
| `區塊大小` | 每個平鋪區塊的處理大小（預設：512） | INT | 是 | 64-4096 (step: 32) |
| `重疊` | 相鄰平鋪區塊之間的重疊量（預設：64） | INT | 是 | 0-4096 (step: 32) |
| `時間區塊大小` | 僅用於影片 VAE：每次解碼的幀數（預設：64） | INT | 是 | 8-4096 (step: 4) |
| `時間重疊` | 僅用於影片 VAE：要重疊的幀數（預設：8） | INT | 是 | 4-4096 (step: 4) |

**注意：** 此節點會自動調整重疊值，若超過實際限制。如果 `tile_size` 小於 `overlap` 的 4 倍，則重疊會減少為平鋪大小的四分之一。同樣地，如果 `temporal_size` 小於 `temporal_overlap` 的 2 倍，則時間重疊會減半。此節點在計算空間和時間維度的平鋪與重疊大小時，也會考量 VAE 的內部壓縮比率。如果輸入的潛在樣本是巢狀批次的潛在值，則僅解碼批次中的第一個項目。
