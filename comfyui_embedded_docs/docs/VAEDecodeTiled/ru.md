# Декодировать VAE (плитками)

Узел VAEDecodeTiled декодирует латентные представления в изображения, используя тайловый подход для эффективной обработки больших изображений. Он обрабатывает входные данные меньшими тайлами, чтобы контролировать использование памяти, сохраняя качество изображения. Узел также поддерживает видео-VAE, обрабатывая временные кадры порциями с перекрытием для плавных переходов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Латентное представление, которое нужно декодировать в изображения | LATENT | Да | - |
| `vae` | Модель VAE, используемая для декодирования латентных представлений | VAE | Да | - |
| `размер_плитки` | Размер каждого тайла для обработки (по умолчанию: 512) | INT | Да | 64-4096 (шаг: 32) |
| `перекрытие` | Величина перекрытия между соседними тайлами (по умолчанию: 64) | INT | Да | 0-4096 (шаг: 32) |
| `temporal_size` | Используется только для видео-VAE: количество кадров, декодируемых за один раз (по умолчанию: 64) | INT | Да | 8-4096 (шаг: 4) |
| `temporal_overlap` | Используется только для видео-VAE: количество перекрывающихся кадров (по умолчанию: 8) | INT | Да | 4-4096 (шаг: 4) |

**Примечание:** Входы `tile_size`, `overlap`, `temporal_size` и `temporal_overlap` помечены как расширенные настройки.

**Примечание:** Узел автоматически корректирует значения перекрытия, если они превышают практические ограничения. Если `tile_size` меньше 4-кратного значения `overlap`, перекрытие уменьшается до одной четверти размера тайла. Аналогично, если `temporal_size` меньше удвоенного значения `temporal_overlap`, временное перекрытие уменьшается вдвое. Узел также учитывает внутренние коэффициенты сжатия VAE при расчёте размеров тайлов и перекрытий как для пространственных, так и для временных измерений. Если входной латент представляет собой вложенный батч латентов, декодируется только первый элемент в батче.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Декодированное изображение или изображения, сгенерированные из латентного представления. При декодировании видео-латентов выход представляет собой последовательность кадров изображений. | IMAGE |
