# Декодировать VAE (плитками)

Узел VAEDecodeTiled декодирует латентные представления в изображения, используя мозаичный подход для эффективной обработки больших изображений. Он обрабатывает входные данные небольшими фрагментами, чтобы управлять использованием памяти, сохраняя при этом качество изображения. Узел также поддерживает видео VAE, обрабатывая временные кадры частями с перекрытием для плавных переходов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Латентное представление, которое нужно декодировать в изображения | LATENT | Да | - |
| `vae` | Модель VAE, используемая для декодирования латентных представлений | VAE | Да | - |
| `размер_плитки` | Размер каждого фрагмента для обработки (по умолчанию: 512) | INT | Да | 64-4096 (step: 32) |
| `перекрытие` | Величина перекрытия между соседними фрагментами (по умолчанию: 64) | INT | Да | 0-4096 (step: 32) |
| `temporal_size` | Используется только для видео VAE: количество кадров для декодирования за раз (по умолчанию: 64) | INT | Да | 8-4096 (step: 4) |
| `temporal_overlap` | Используется только для видео VAE: количество перекрывающихся кадров (по умолчанию: 8) | INT | Да | 4-4096 (step: 4) |

**Примечание:** Узел автоматически корректирует значения перекрытия, если они выходят за практические пределы. Если `tile_size` меньше, чем 4-кратный `overlap`, перекрытие уменьшается до четверти размера фрагмента. Аналогично, если `temporal_size` меньше, чем двукратный `temporal_overlap`, временное перекрытие уменьшается вдвое. Узел также учитывает внутренние коэффициенты сжатия VAE при расчёте размеров фрагментов и перекрытий как для пространственных, так и для временных измерений. Если входное латентное представление является вложенным пакетом латентных представлений, декодируется только первый элемент пакета.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Декодированное изображение или изображения, созданные из латентного представления. При декодировании видео латентных представлений выходные данные представляют собой последовательность кадров. | IMAGE |
