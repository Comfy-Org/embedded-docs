# Декодировать VAE (плитками)

Узел VAEDecodeTiled декодирует латентные представления в изображения, используя мозаичный подход для эффективной обработки больших изображений. Он обрабатывает входные данные меньшими тайлами, чтобы управлять использованием памяти, сохраняя при этом качество изображения. Узел также поддерживает видео VAE, обрабатывая временные кадры блоками с перекрытием для плавных переходов.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Латентное представление, которое необходимо декодировать в изображения | LATENT | Да | - |
| `vae` | Модель VAE, используемая для декодирования латентных представлений | VAE | Да | - |
| `tile_size` | Размер каждого тайла для обработки (по умолчанию: 512) | INT | Да | 64-4096 (шаг: 32) |
| `overlap` | Величина перекрытия между соседними тайлами (по умолчанию: 64) | INT | Да | 0-4096 (шаг: 32) |
| `temporal_size` | Используется только для видео VAE: количество кадров для декодирования за раз (по умолчанию: 64) | INT | Да | 8-4096 (шаг: 4) |
| `temporal_overlap` | Используется только для видео VAE: количество перекрывающихся кадров (по умолчанию: 8) | INT | Да | 4-4096 (шаг: 4) |

**Примечание:** Узел автоматически корректирует значения перекрытия, если они превышают практически допустимые пределы. Если `tile_size` меньше 4-кратного значения `overlap`, перекрытие уменьшается до одной четверти размера тайла. Аналогично, если `temporal_size` меньше удвоенного `temporal_overlap`, временное перекрытие уменьшается вдвое. Узел также учитывает внутренние коэффициенты сжатия VAE при расчёте размеров тайлов и перекрытий как для пространственных, так и для временных измерений. Для VAE без временного сжатия (не видео VAE) параметры `temporal_size` и `temporal_overlap` игнорируются.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Декодированное изображение или изображения, сгенерированные из латентного представления. При декодировании видео-латентных представлений все декодированные кадры объединяются в единый список изображений. | IMAGE |
