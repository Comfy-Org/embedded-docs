# كليغ صورة إلى فيديو

تم إنشاء عقدة Kling Image to Video لإنشاء فيديو قصير باستخدام صورة البداية كإطار أول. تجمع العقدة بين الصورة والنصوص الوصفية وإعدادات التوليد، ثم تُرجع الفيديو الناتج مع معرّفه ومدته.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|---------|-------|---------------|--------|--------|
| `الإطار الابتدائي` | الصورة المرجعية المستخدمة لتوليد الفيديو. يجب أن تكون الصورة بدقة لا تقل عن 300×300 بكسل وأن تكون نسبة الأبعاد بين 1:2.5 و2.5:1. | IMAGE | نعم | - |
| `نص التوجيه الإيجابي` | النص الوصفي الإيجابي. يجب ألا يكون فارغًا. الحد الأقصى 500 حرف. | STRING | نعم | - |
| `نص التوجيه السلبي` | النص الوصفي السلبي. الحد الأقصى 500 حرف. اتركه فارغًا إذا لم يُستخدم. | STRING | نعم | - |
| `اسم النموذج` | النموذج المستخدم لتوليد الفيديو (الافتراضي: `"kling-v2-5-turbo"`). | COMBO | نعم | `"kling-v2-5-turbo"` |
| `مقياس CFG` | يتحكم في مدى قرب الفيديو من النص الوصفي. القيم الأعلى تعني التزامًا أقوى (الافتراضي: 0.8). | FLOAT | نعم | 0.0 إلى 1.0 |
| `الوضع` | وضع التوليد (الافتراضي: `"pro"`). | COMBO | نعم | `"pro"` |
| `نسبة العرض إلى الارتفاع` | نسبة الأبعاد للفيديو المُولَّد (الافتراضي: `"16:9"`). | COMBO | نعم | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `المدة` | مدة الفيديو المُولَّد بالثواني (الافتراضي: `"5"`). | COMBO | نعم | `"5"`<br>`"10"` |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------|--------------|
| `output` | مخرَج الفيديو المُولَّد. | VIDEO |
| `معرّف الفيديو` | معرّف فريد للفيديو المُولَّد. | STRING |
| `المدة` | معلومات المدة للفيديو المُولَّد. | STRING |
