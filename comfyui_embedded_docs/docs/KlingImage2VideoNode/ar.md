# كليغ صورة إلى فيديو

تقوم عقدة Kling Image to Video بإنشاء فيديو من صورة مرجعية أولية باستخدام مطالبات نصية. تستخدم الصورة كإطار أول وتُنشئ تسلسل فيديو استنادًا إلى الأوصاف النصية الإيجابية والسلبية، مع خيارات قابلة للتكوين للنموذج والمدة ووضع التوليد ونسبة الأبعاد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | الصورة المرجعية المستخدمة لتوليد الفيديو. يجب أن تكون بدقة لا تقل عن 300×300 بكسل وبنسية أبعاد بين 1:2.5 و 2.5:1. | IMAGE | نعم | - |
| `prompt` | المطالبة النصية الإيجابية. الحد الأقصى 500 حرف. | STRING | نعم | - |
| `negative_prompt` | المطالبة النصية السلبية. الحد الأقصى 500 حرف. يمكن تركها فارغة. | STRING | نعم | - |
| `model_name` | النموذج المستخدم لتوليد الفيديو (الافتراضي: `"kling-v2-5-turbo"`). | COMBO | نعم | `"kling-v2-5-turbo"` |
| `cfg_scale` | يتحكم في مدى التزام الفيديو بالمطالبة. القيم الأعلى تعني التزامًا أقوى (الافتراضي: 0.8). | FLOAT | نعم | 0.0 إلى 1.0 |
| `mode` | وضع التوليد (الافتراضي: `"pro"`). | COMBO | نعم | `"pro"` |
| `aspect_ratio` | نسبة أبعاد الفيديو المولّد (الافتراضي: `"16:9"`). | COMBO | نعم | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدة الفيديو المولّد بالثواني (الافتراضي: `"5"`). | COMBO | نعم | `"5"`<br>`"10"` |

ملاحظة: يجب ألا تكون المطالبة الإيجابية فارغة. كلا المطالبتين الإيجابية والسلبية محدودتان بـ 500 حرف. يجب أن تكون صورة الإدخال بدقة لا تقل عن 300×300 بكسل وبنسية أبعاد بين 1:2.5 و 2.5:1.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الفيديو المولّد. | VIDEO |
| `video_id` | معرّف فريد للفيديو المولّد. | STRING |
| `duration` | مدة الفيديو المولّد. | STRING |
