# تبدیل تصویر Kling (فریم اول) به ویدیو

گره «Kling Image to Video» ویدیویی را از یک تصویر مرجع آغازین با استفاده از فرمان‌های متنی تولید می‌کند. این گره از تصویر به‌عنوان فریم اول استفاده می‌کند و دنباله‌ای ویدیویی را بر اساس توصیف‌های متنی مثبت و منفی، با گزینه‌های قابل تنظیم برای مدل، مدت‌زمان، حالت تولید و نسبت ابعاد می‌سازد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | تصویر مرجع مورد استفاده برای تولید ویدیو. باید حداقل 300×300 پیکسل و نسبت ابعاد بین 1:2.5 و 2.5:1 باشد. | IMAGE | بله | - |
| `prompt` | فرمان متنی مثبت. حداکثر 500 کاراکتر. | STRING | بله | - |
| `negative_prompt` | فرمان متنی منفی. حداکثر 500 کاراکتر. می‌تواند خالی بماند. | STRING | بله | - |
| `model_name` | مدل مورد استفاده برای تولید ویدیو (پیش‌فرض: `"kling-v2-5-turbo"`). | COMBO | بله | `"kling-v2-5-turbo"` |
| `cfg_scale` | کنترل می‌کند که ویدیو چقدر از فرمان پیروی کند. مقادیر بالاتر به معنای پایبندی قوی‌تر است (پیش‌فرض: 0.8). | FLOAT | بله | 0.0 to 1.0 |
| `mode` | حالت تولید (پیش‌فرض: `"pro"`). | COMBO | بله | `"pro"` |
| `aspect_ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: `"16:9"`). | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: `"5"`). | COMBO | بله | `"5"`<br>`"10"` |

توجه: فرمان متنی مثبت نباید خالی باشد. هر دو فرمان مثبت و منفی به 500 کاراکتر محدود هستند. تصویر ورودی باید حداقل 300×300 پیکسل و نسبت ابعاد بین 1:2.5 و 2.5:1 داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | ویدیوی تولیدشده. | VIDEO |
| `video_id` | شناسه یکتای ویدیوی تولیدشده. | STRING |
| `duration` | مدت‌زمان ویدیوی تولیدشده. | STRING |
