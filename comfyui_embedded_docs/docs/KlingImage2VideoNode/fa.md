# تبدیل تصویر Kling (فریم اول) به ویدیو

گره Kling Image to Video با استفاده از یک تصویر شروع‌کننده به‌عنوان فریم اول، یک ویدیوی کوتاه تولید می‌کند. این گره تصویر را با راهنمای متنی و تنظیمات تولید ترکیب کرده و سپس ویدیوی حاصل را به‌همراه شناسه و مدت‌زمان آن بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | تصویر مرجعی که برای تولید ویدیو استفاده می‌شود. تصویر باید حداقل 300×300 پیکسل باشد و نسبت ابعاد آن بین 1:2.5 و 2.5:1 باشد. | IMAGE | بله | - |
| `prompt` | راهنمای متنی مثبت. نباید خالی باشد. حداکثر 500 کاراکتر. | STRING | بله | - |
| `negative_prompt` | راهنمای متنی منفی. حداکثر 500 کاراکتر. در صورت عدم استفاده، خالی بگذارید. | STRING | بله | - |
| `model_name` | مدل مورد استفاده برای تولید ویدیو (پیش‌فرض: `"kling-v2-5-turbo"`). | COMBO | بله | `"kling-v2-5-turbo"` |
| `cfg_scale` | کنترل می‌کند که ویدیو چقدر دقیق از راهنما پیروی کند. مقادیر بالاتر به معنای پایبندی قوی‌تر است (پیش‌فرض: 0.8). | FLOAT | بله | 0.0 تا 1.0 |
| `mode` | حالت تولید (پیش‌فرض: `"pro"`). | COMBO | بله | `"pro"` |
| `aspect_ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: `"16:9"`). | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: `"5"`). | COMBO | بله | `"5"`<br>`"10"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | خروجی ویدیوی تولیدشده. | VIDEO |
| `video_id` | شناسه یکتای ویدیوی تولیدشده. | STRING |
| `duration` | اطلاعات مدت‌زمان ویدیوی تولیدشده. | STRING |
