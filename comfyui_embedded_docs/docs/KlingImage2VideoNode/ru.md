# Kling Image to Video

Узел Kling Image to Video создает короткое видео, используя начальное изображение в качестве первого кадра. Он объединяет изображение с текстовыми запросами и настройками генерации, а затем возвращает полученное видео вместе с его идентификатором и длительностью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | Эталонное изображение, используемое для генерации видео. Изображение должно быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. | IMAGE | Да | - |
| `prompt` | Положительный текстовый запрос. Не должен быть пустым. Максимум 500 символов. | STRING | Да | - |
| `negative_prompt` | Отрицательный текстовый запрос. Максимум 500 символов. Оставьте пустым, если не используется. | STRING | Да | - |
| `model_name` | Модель, используемая для генерации видео (по умолчанию: `"kling-v2-5-turbo"`). | COMBO | Да | `"kling-v2-5-turbo"` |
| `cfg_scale` | Управляет тем, насколько точно видео следует запросу. Более высокие значения означают более сильное соответствие (по умолчанию: 0.8). | FLOAT | Да | 0.0 до 1.0 |
| `mode` | Режим генерации (по умолчанию: `"pro"`). | COMBO | Да | `"pro"` |
| `aspect_ratio` | Соотношение сторон генерируемого видео (по умолчанию: `"16:9"`). | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность генерируемого видео в секундах (по умолчанию: `"5"`). | COMBO | Да | `"5"`<br>`"10"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеовыход. | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео. | STRING |
| `duration` | Информация о длительности сгенерированного видео. | STRING |
