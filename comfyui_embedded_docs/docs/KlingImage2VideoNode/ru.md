# Kling Image to Video

Узел Kling Image to Video генерирует видео из исходного изображения с помощью текстовых промптов. Он использует изображение как первый кадр и создает видеопоследовательность на основе положительного и отрицательного текстовых описаний, с настраиваемыми параметрами для модели, длительности, режима генерации и соотношения сторон.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | Исходное изображение, используемое для генерации видео. Должно быть не менее 300x300 пикселей с соотношением сторон от 1:2.5 до 2.5:1. | IMAGE | Да | - |
| `prompt` | Положительный текстовый промпт. Максимум 500 символов. | STRING | Да | - |
| `negative_prompt` | Отрицательный текстовый промпт. Максимум 500 символов. Может быть оставлен пустым. | STRING | Да | - |
| `model_name` | Модель, используемая для генерации видео (по умолчанию: `"kling-v2-5-turbo"`). | COMBO | Да | `"kling-v2-5-turbo"` |
| `cfg_scale` | Управляет тем, насколько точно видео соответствует промпту. Более высокие значения означают более строгое следование (по умолчанию: 0.8). | FLOAT | Да | 0.0 to 1.0 |
| `mode` | Режим генерации (по умолчанию: `"pro"`). | COMBO | Да | `"pro"` |
| `aspect_ratio` | Соотношение сторон генерируемого видео (по умолчанию: `"16:9"`). | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Продолжительность генерируемого видео в секундах (по умолчанию: `"5"`). | COMBO | Да | `"5"`<br>`"10"` |

Примечание: положительный промпт не должен быть пустым. И положительный, и отрицательный промпты ограничены 500 символами. Входное изображение должно быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео. | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео. | STRING |
| `duration` | Продолжительность сгенерированного видео. | STRING |
