# Kling תמונה (פריים ראשון) לוידאו

צומת Kling Image to Video יוצר סרטון קצר תוך שימוש בתמונת התחלה כפריים הראשון. הוא משלב את התמונה עם הנחיות טקסט והגדרות יצירה, ולאחר מכן מחזיר את הסרטון שנוצר יחד עם המזהה ומשך הזמן שלו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | תמונת העזר המשמשת ליצירת הסרטון. התמונה חייבת להיות בגודל של לפחות 300x300 פיקסלים וביחס רוחב-גובה שבין 1:2.5 ל-2.5:1. | IMAGE | כן | - |
| `prompt` | הנחיית טקסט חיובית. לא יכולה להיות ריקה. עד 500 תווים. | STRING | כן | - |
| `negative_prompt` | הנחיית טקסט שלילית. עד 500 תווים. יש להשאיר ריק אם אינה בשימוש. | STRING | כן | - |
| `model_name` | המודל המשמש ליצירת הסרטון. | COMBO | כן | `"kling-v2-5-turbo"` |
| `cfg_scale` | שולט במידת ההיצמדות של הסרטון להנחיה. ערכים גבוהים יותר משמעם היצמדות חזקה יותר (ברירת מחדל: 0.8). | FLOAT | כן | 0.0 עד 1.0 |
| `mode` | מצב היצירה. | COMBO | כן | `"pro"` |
| `aspect_ratio` | יחס הרוחב-גובה של הסרטון שנוצר (ברירת מחדל: `"16:9"`). | COMBO | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | משך הסרטון שנוצר בשניות (ברירת מחדל: `"5"`). | COMBO | כן | `"5"`<br>`"10"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | פלט הסרטון שנוצר. | VIDEO |
| `video_id` | מזהה ייחודי לסרטון שנוצר. | STRING |
| `duration` | מידע על משך הזמן של הסרטון שנוצר. | STRING |
