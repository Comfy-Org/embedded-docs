# Kling 画像から動画へ

The Kling Image to Video ノードは、テキストプロンプトを使用して開始参照画像からビデオを生成します。このノードは、画像を最初のフレームとして使用し、ポジティブおよびネガティブなテキスト記述に基づいてビデオシーケンスを作成します。モデル、長さ、生成モード、アスペクト比を設定できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | ビデオ生成に使用される参照画像。300x300 ピクセル以上で、アスペクト比が 1:2.5 から 2.5:1 の間である必要があります。 | IMAGE | はい | - |
| `prompt` | ポジティブなテキストプロンプト。最大 500 文字です。 | STRING | はい | - |
| `negative_prompt` | ネガティブなテキストプロンプト。最大 500 文字です。空のままでも構いません。 | STRING | はい | - |
| `model_name` | ビデオ生成に使用するモデル（デフォルト: `"kling-v2-5-turbo"`）。 | COMBO | はい | `"kling-v2-5-turbo"` |
| `cfg_scale` | ビデオがプロンプトにどの程度忠実に従うかを制御します。値が大きいほど、より強くプロンプトに従います（デフォルト: 0.8）。 | FLOAT | はい | 0.0 から 1.0 |
| `mode` | 生成モード（デフォルト: `"pro"`）。 | COMBO | はい | `"pro"` |
| `aspect_ratio` | 生成されるビデオのアスペクト比（デフォルト: `"16:9"`）。 | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | 生成されるビデオの長さ（秒）（デフォルト: `"5"`）。 | COMBO | はい | `"5"`<br>`"10"` |

注：ポジティブなプロンプトは空にしないでください。ポジティブおよびネガティブの両方のプロンプトは 500 文字に制限されています。入力画像は 300x300 ピクセル以上で、アスペクト比が 1:2.5 から 2.5:1 の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成されたビデオ。 | VIDEO |
| `video_id` | 生成されたビデオの一意の識別子。 | STRING |
| `duration` | 生成されたビデオの長さ。 | STRING |
