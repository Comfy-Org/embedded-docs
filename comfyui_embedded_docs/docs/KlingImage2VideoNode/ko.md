# Kling 비디오 생성 (이미지 → 비디오)

Kling Image to Video 노드는 텍스트 프롬프트를 사용하여 시작 참조 이미지에서 비디오를 생성합니다. 이미지를 첫 번째 프레임으로 사용하고 긍정 및 부정 텍스트 설명을 기반으로 비디오 시퀀스를 생성하며, 모델, 지속 시간, 생성 모드 및 화면 비율에 대한 구성 가능한 옵션을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | 비디오 생성에 사용되는 참조 이미지입니다. 최소 300x300 픽셀이어야 하며 화면 비율이 1:2.5에서 2.5:1 사이여야 합니다. | IMAGE | 예 | - |
| `prompt` | 긍정 텍스트 프롬프트입니다. 최대 500자입니다. | STRING | 예 | - |
| `negative_prompt` | 부정 텍스트 프롬프트입니다. 최대 500자입니다. 비워 둘 수 있습니다. | STRING | 예 | - |
| `model_name` | 비디오 생성에 사용되는 모델입니다 (기본값: `"kling-v2-5-turbo"`). | COMBO | 예 | `"kling-v2-5-turbo"` |
| `cfg_scale` | 비디오가 프롬프트를 얼마나 밀접하게 따르는지 제어합니다. 값이 높을수록 프롬프트에 더 강하게 부합합니다 (기본값: 0.8). | FLOAT | 예 | 0.0 to 1.0 |
| `mode` | 생성 모드입니다 (기본값: `"pro"`). | COMBO | 예 | `"pro"` |
| `aspect_ratio` | 생성된 비디오의 화면 비율입니다 (기본값: `"16:9"`). | COMBO | 예 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | 생성된 비디오의 지속 시간(초)입니다 (기본값: `"5"`). | COMBO | 예 | `"5"`<br>`"10"` |

참고: 긍정 프롬프트는 비어 있으면 안 됩니다. 긍정 및 부정 프롬프트 모두 500자로 제한됩니다. 입력 이미지는 최소 300x300 픽셀이어야 하며 화면 비율이 1:2.5에서 2.5:1 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오입니다. | VIDEO |
| `video_id` | 생성된 비디오의 고유 식별자입니다. | STRING |
| `duration` | 생성된 비디오의 지속 시간입니다. | STRING |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/KlingImage2VideoNode/ko.md)
