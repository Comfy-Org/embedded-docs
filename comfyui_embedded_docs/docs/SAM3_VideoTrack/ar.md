# تتبع فيديو SAM3

تتبع الكائنات عبر إطارات الفيديو باستخدام متتبع SAM3 القائم على الذاكرة. تعالج هذه العقدة سلسلة من إطارات الفيديو وتحافظ على هويات الكائنات عبر الإطارات، باستخدام إما أقنعة أولية أو مطالبات نصية لتحديد ما يجب تتبعه.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `الصور` | إطارات الفيديو كصور مجمعة | IMAGE | نعم | إطارات الفيديو المجمعة |
| `النموذج` | نموذج SAM3 المستخدم للتتبع | MODEL | نعم | نموذج SAM3 |
| `القناع الأولي` | قناع (أقنعة) للإطار الأول للتتبع (قناع واحد لكل كائن) | MASK | لا | قناع واحد لكل كائن |
| `التهيئة` | تهيئة نصية لاكتشاف كائنات جديدة أثناء التتبع | CONDITIONING | لا | تهيئة نصية |
| `عَتَبة الكشف` | عتبة الدرجة للاكتشاف الموجّه بنص (الافتراضي: 0.5) | FLOAT | لا | من 0.0 إلى 1.0 |
| `أقصى عدد للكائنات` | الحد الأقصى للكائنات المتتبعة. تُحتسب الأقنعة الأولية ضمن هذا الحد. القيمة 0 تستخدم الحد الداخلي البالغ 64. (الافتراضي: 4) | INT | لا | من 0 إلى 64 |
| `فاصل الكشف` | تشغيل الاكتشاف كل N إطارًا (1 = كل إطار). القيم الأعلى توفر موارد الحوسبة. (الافتراضي: 1) | INT | لا | 1 أو أعلى |

**ملاحظة:** يجب توفير إما `initial_mask` أو `conditioning`. إذا تم حذف كلاهما، تقوم العقدة بإصدار خطأ.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
| `بيانات التتبع` | بيانات التتبع التي تحتوي على أقنعة الكائنات والبيانات الوصفية عبر جميع إطارات الفيديو | SAM3TrackData |
