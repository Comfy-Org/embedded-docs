# تتبع فيديو SAM3

تتبّع الكائنات عبر إطارات الفيديو باستخدام متعقّب SAM3 المعتمد على الذاكرة. تعالج العقدة سلسلة من إطارات الفيديو وتحافظ على هويات الكائنات عبر الإطارات، باستخدام أقنعة أولية أو أوامر نصية لتحديد ما يجب تتبعه، ويمكنها اكتشاف كائنات جديدة أثناء ذلك باستخدام التكييف النصي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `images` | إطارات الفيديو كصور مُجمّعة في دفعات | IMAGE | نعم | إطارات فيديو مُجمّعة في دفعات |
| `model` | نموذج SAM3 المستخدم للتتبع | MODEL | نعم | نموذج SAM3 |
| `initial_mask` | قناع (أقنعة) للإطار الأول المراد تتبعه (واحد لكل كائن) | MASK | لا | قناع واحد لكل كائن |
| `conditioning` | تكييف نصي لاكتشاف كائنات جديدة أثناء التتبع | CONDITIONING | لا | تكييف نصي |
| `detection_threshold` | عتبة الدرجة للكشف المُوجَّه بالنص (الافتراضي: 0.5) | FLOAT | لا | 0.0 إلى 1.0 (خطوة 0.01) |
| `max_objects` | الحد الأقصى للكائنات المتتبعة. تُحتسب الأقنعة الأولية ضمن هذا الحد. القيمة 0 تستخدم الحد الداخلي 64. (الافتراضي: 4) | INT | لا | 0 إلى 64 |
| `detect_interval` | تشغيل الكشف كل N إطارًا (1=كل إطار). القيم الأعلى توفر في الحوسبة. (الافتراضي: 1) | INT | لا | 1 أو أعلى |

**ملاحظة:** يجب توفير إما `initial_mask` أو `conditioning`. إذا حُذف كلاهما، تُطلق العقدة خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `track_data` | بيانات التتبع التي تحتوي على أقنعة الكائنات وبياناتها الوصفية عبر جميع إطارات الفيديو | SAM3_TRACK_DATA |
