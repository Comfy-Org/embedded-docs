# تتبع فيديو SAM3

تتبّع الأجسام عبر إطارات الفيديو باستخدام متتبّع SAM3 القائم على الذاكرة. تعالج هذه العقدة تسلسل إطارات الفيديو وتحافظ على هوية الأجسام عبر الإطارات، باستخدام إمّا أقنعة أولية أو مطالبات نصية لتحديد ما يجب تتبّعه.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `images` | إطارات الفيديو كصور مجمّعة | IMAGE | نعم | إطارات فيديو مجمّعة |
| `model` | نموذج SAM3 المستخدم للتتبّع | MODEL | نعم | نموذج SAM3 |
| `initial_mask` | قناع (أقنعة) للإطار الأول المراد تتبّعه (واحد لكل جسم). مطلوب إذا لم يتم توفير `conditioning`. | MASK | لا | قناع واحد لكل جسم |
| `conditioning` | التكييف النصي لاكتشاف أجسام جديدة أثناء التتبّع. مطلوب إذا لم يتم توفير `initial_mask`. | CONDITIONING | لا | تكييف نصي |
| `detection_threshold` | حدّ الدرجة للكشف عبر المطالبة النصية (الافتراضي: 0.5). | FLOAT | نعم | من 0.0 إلى 1.0 |
| `max_objects` | الحد الأقصى للأجسام المتتبَّعة. تُحتسب الأقنعة الأولية ضمن هذا الحد. القيمة 0 تستخدم الحد الداخلي البالغ 64 (الافتراضي: 4). | INT | نعم | من 0 إلى 64 |
| `detect_interval` | تشغيل الكشف كل N إطارًا (1=كل إطار). القيم الأعلى توفر استهلاك الحوسبة (الافتراضي: 1). | INT | نعم | 1 أو أعلى |

**ملاحظة:** يجب توفير إمّا `initial_mask` أو `conditioning`. إذا تم حذف كلاهما، ستُصدر العقدة خطأً. عند توفير كلاهما، تحدد الأقنعة الأولية الأجسام التي سيتم تتبّعها من الإطار الأول، بينما تكتشف المطالبات النصية أجسامًا إضافية أثناء التتبّع.
