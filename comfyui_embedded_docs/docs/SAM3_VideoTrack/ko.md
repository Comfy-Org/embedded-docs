# SAM3 비디오 트랙

비디오 프레임에서 SAM3의 메모리 기반 트래커를 사용하여 객체를 추적합니다. 이 노드는 비디오 프레임 시퀀스를 처리하고 프레임 간 객체 ID를 유지하며, 초기 마스크 또는 텍스트 프롬프트를 사용하여 추적할 대상을 정의합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `images` | 비디오 프레임을 배치된 이미지로 제공합니다 | IMAGE | 예 | 배치된 비디오 프레임 |
| `model` | 추적에 사용할 SAM3 모델 | MODEL | 예 | SAM3 모델 |
| `initial_mask` | 추적할 첫 번째 프레임의 마스크(객체당 하나). `conditioning`이 제공되지 않은 경우 필요합니다. | MASK | 아니요 | 객체당 하나의 마스크 |
| `conditioning` | 추적 중 새 객체를 감지하기 위한 텍스트 컨디셔닝. `initial_mask`가 제공되지 않은 경우 필요합니다. | CONDITIONING | 아니요 | 텍스트 컨디셔닝 |
| `detection_threshold` | 텍스트 프롬프트 기반 탐지를 위한 점수 임계값(기본값: 0.5) | FLOAT | 예 | 0.0 ~ 1.0 |
| `max_objects` | 최대 추적 객체 수. 초기 마스크도 이 한도에 포함됩니다. 0은 내부 상한인 64를 사용합니다(기본값: 4). | INT | 예 | 0 ~ 64 |
| `detect_interval` | N프레임마다 탐지를 실행합니다(1=모든 프레임). 값이 클수록 계산량이 줄어듭니다(기본값: 1). | INT | 예 | 1 이상 |

**참고:** `initial_mask` 또는 `conditioning` 중 하나는 반드시 제공해야 합니다. 둘 다 생략하면 노드에서 오류가 발생합니다. 둘 다 제공하는 경우, 초기 마스크는 첫 번째 프레임에서 추적할 객체를 정의하고 텍스트 프롬프트는 추적 중 추가 객체를 감지합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `track_data` | 원본 프레임 크기를 포함하여 모든 비디오 프레임에 걸친 객체 마스크와 메타데이터를 포함하는 추적 데이터입니다. | SAM3_TRACK_DATA |
