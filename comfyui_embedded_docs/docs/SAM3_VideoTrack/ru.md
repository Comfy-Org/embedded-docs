# SAM3 Видеотрек

Отслеживайте объекты между видеокадрами с помощью трекера SAM3 на основе памяти. Узел обрабатывает последовательность видеокадров и сохраняет идентификацию объектов между кадрами, используя либо начальные маски, либо текстовые подсказки, чтобы определить, что отслеживать, и может обнаруживать новые объекты по ходу с помощью текстового кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Видеокадры в виде пакета изображений | IMAGE | Да | Пакет видеокадров |
| `model` | Модель SAM3, используемая для отслеживания | MODEL | Да | Модель SAM3 |
| `начальная_маска` | Маска(и) для первого кадра, который нужно отслеживать (по одной на объект) | MASK | Нет | Одна маска на объект |
| `condition` | Текстовое кондиционирование для обнаружения новых объектов во время отслеживания | CONDITIONING | Нет | Текстовое кондиционирование |
| `порог_обнаружения` | Порог оценки для обнаружения по текстовой подсказке (по умолчанию: 0.5) | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.01) |
| `макс_объектов` | Максимальное количество отслеживаемых объектов. Начальные маски учитываются в этом лимите. 0 использует внутренний предел 64. (по умолчанию: 4) | INT | Нет | от 0 до 64 |
| `интервал_обнаружения` | Запускать обнаружение каждые N кадров (1=каждый кадр). Более высокие значения экономят вычислительные ресурсы. (по умолчанию: 1) | INT | Нет | 1 или выше |

**Примечание:** Необходимо указать либо `initial_mask`, либо `conditioning`. Если оба параметра опущены, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `track_data` | Данные отслеживания, содержащие маски объектов и метаданные по всем видеокадрам | SAM3_TRACK_DATA |
