# SAM3 Видеотрек

Отслеживайте объекты на видеокадрах с помощью трекера на основе памяти SAM3. Этот узел обрабатывает последовательность видеокадров и сохраняет идентичность объектов между кадрами, используя либо начальные маски, либо текстовые подсказки для определения того, что отслеживать.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Видеокадры в виде пакета изображений | IMAGE | Да | Пакетные видеокадры |
| `model` | Модель SAM3 для отслеживания | MODEL | Да | модель SAM3 |
| `начальная_маска` | Маска(и) для первого кадра отслеживания (по одной на объект) | MASK | Нет | Одна маска на объект |
| `condition` | Текстовое кондиционирование для обнаружения новых объектов во время отслеживания | CONDITIONING | Нет | Текстовое кондиционирование |
| `порог_обнаружения` | Порог оценки для обнаружения по текстовому запросу (по умолчанию: 0.5) | FLOAT | Нет | 0.0 до 1.0 |
| `макс_объектов` | Максимальное количество отслеживаемых объектов. Начальные маски учитываются в этом лимите. 0 использует внутренний предел 64. (по умолчанию: 4) | INT | Нет | 0 до 64 |
| `интервал_обнаружения` | Запускать обнаружение каждые N кадров (1=каждый кадр). Более высокие значения экономят вычисления. (по умолчанию: 1) | INT | Нет | 1 или больше |

**Примечание:** Необходимо указать либо `initial_mask`, либо `conditioning`. Если оба параметра опущены, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `данные_трека` | Данные отслеживания, содержащие маски объектов и метаданные по всем видеокадрам | SAM3TrackData |
