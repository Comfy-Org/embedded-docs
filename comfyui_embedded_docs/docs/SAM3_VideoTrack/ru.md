# SAM3 Видеотрек

Отслеживание объектов на видеокадрах с помощью трекера на основе памяти SAM3. Этот узел обрабатывает последовательность видеокадров и поддерживает идентичность объектов между кадрами, используя либо начальные маски, либо текстовые подсказки для определения того, что отслеживать.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Видеокадры в виде пакета изображений | IMAGE | Да | Пакетные видеокадры |
| `model` | Модель SAM3, используемая для отслеживания | MODEL | Да | Модель SAM3 |
| `initial_mask` | Маска(и) для первого отслеживаемого кадра (по одной на объект). Требуется, если `conditioning` не указано. | MASK | Нет | Одна маска на объект |
| `conditioning` | Текстовое кондиционирование для обнаружения новых объектов во время отслеживания. Требуется, если `initial_mask` не указано. | CONDITIONING | Нет | Текстовое кондиционирование |
| `detection_threshold` | Порог оценки для обнаружения по текстовому запросу (по умолчанию: 0,5). | FLOAT | Да | 0.0 to 1.0 |
| `max_objects` | Максимальное количество отслеживаемых объектов. Начальные маски учитываются в этом пределе. 0 использует внутренний предел 64 (по умолчанию: 4). | INT | Да | 0 to 64 |
| `detect_interval` | Запускать обнаружение каждые N кадров (1 = каждый кадр). Более высокие значения экономят вычисления (по умолчанию: 1). | INT | Да | 1 или выше |

**Примечание:** Должно быть указано либо `initial_mask`, либо `conditioning`. Если оба опущены, узел вызовет ошибку. Если указаны оба, начальные маски определяют объекты для отслеживания с первого кадра, а текстовые подсказки обнаруживают дополнительные объекты во время отслеживания.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `track_data` | Данные отслеживания, содержащие маски объектов и метаданные по всем видеокадрам, включая исходные размеры кадра. | SAM3_TRACK_DATA |
