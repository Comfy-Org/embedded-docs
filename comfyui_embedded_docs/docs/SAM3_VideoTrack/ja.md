# SAM3ビデオトラック

SAM3のメモリベーストラッカーを使用して、ビデオフレーム全体でオブジェクトを追跡します。このノードは、ビデオフレームのシーケンスを処理し、初期マスクまたはテキストプロンプトを使用して追跡対象を定義し、フレーム間でオブジェクトの識別情報を維持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | バッチ化された画像としてのビデオフレーム | IMAGE | はい | バッチ化されたビデオフレーム |
| `model` | 追跡に使用するSAM3モデル | MODEL | はい | SAM3モデル |
| `initial_mask` | 最初のフレームで追跡するマスク（オブジェクトごとに1つ）。`conditioning`が提供されていない場合に必要です。 | MASK | いいえ | オブジェクトごとに1つのマスク |
| `conditioning` | 追跡中に新しいオブジェクトを検出するためのテキストコンディショニング。`initial_mask`が提供されていない場合に必要です。 | CONDITIONING | いいえ | テキストコンディショニング |
| `detection_threshold` | テキストプロンプトによる検出のスコアしきい値（デフォルト: 0.5）。 | FLOAT | はい | 0.0 to 1.0 |
| `max_objects` | 追跡するオブジェクトの最大数。初期マスクはこの制限にカウントされます。0は内部上限の64を使用します（デフォルト: 4）。 | INT | はい | 0 to 64 |
| `detect_interval` | Nフレームごとに検出を実行します（1=毎フレーム）。値が大きいほど計算リソースを節約します（デフォルト: 1）。 | INT | はい | 1以上 |

**注:** `initial_mask` または `conditioning` のいずれかを指定する必要があります。両方とも省略すると、ノードはエラーを発生させます。両方指定した場合、初期マスクは最初のフレームから追跡するオブジェクトを定義し、テキストプロンプトは追跡中に追加のオブジェクトを検出します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `track_data` | すべてのビデオフレームにわたるオブジェクトマスクとメタデータを含む追跡データ。元のフレーム寸法も含まれます。 | SAM3_TRACK_DATA |
