# הרצת מסלול וידאו SAM3

עקוב אחר אובייקטים לאורך פריימי וידאו באמצעות העוקב מבוסס הזיכרון של SAM3. הצומת מעבד רצף של פריימי וידאו ומשמר את זהויות האובייקטים בין פריימים, תוך שימוש במסכות ראשוניות או בהנחיות טקסט כדי להגדיר מה לעקוב אחריו, ויכול לזהות אובייקטים חדשים תוך כדי באמצעות התניה טקסטואלית.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `images` | פריימי וידאו כתמונות באצווה | IMAGE | כן | פריימי וידאו באצווה |
| `model` | מודל SAM3 לשימוש למעקב | MODEL | כן | מודל SAM3 |
| `initial_mask` | מסכה/מסכות עבור הפריים הראשון למעקב (אחת לכל אובייקט) | MASK | לא | מסכה אחת לכל אובייקט |
| `conditioning` | התניה טקסטואלית לזיהוי אובייקטים חדשים במהלך המעקב | CONDITIONING | לא | התניה טקסטואלית |
| `detection_threshold` | סף ניקוד לזיהוי מבוסס הנחיית טקסט (ברירת מחדל: 0.5) | FLOAT | לא | 0.0 עד 1.0 (צעד 0.01) |
| `max_objects` | מספר מרבי של אובייקטים במעקב. מסכות ראשוניות נספרות במסגרת המגבלה הזו. 0 משתמש בתקרה הפנימית של 64. (ברירת מחדל: 4) | INT | לא | 0 עד 64 |
| `detect_interval` | הפעל זיהוי כל N פריימים (1=כל פריים). ערכים גבוהים יותר חוסכים חישוב. (ברירת מחדל: 1) | INT | לא | 1 ומעלה |

**הערה:** יש לספק את `initial_mask` או את `conditioning`. אם שניהם מושמטים, הצומת תזרוק שגיאה.
