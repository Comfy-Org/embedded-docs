# ردیابی ویدئویی SAM3

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | فریم‌های ویدیو به‌صورت تصاویر دسته‌ای | IMAGE | بله | فریم‌های ویدیوی دسته‌ای |
| `model` | مدل SAM3 مورد استفاده برای ردیابی | MODEL | بله | مدل SAM3 |
| `initial_mask` | ماسک(ها) برای فریم اول جهت دنبال‌کردن (یک ماسک برای هر شیء). اگر `conditioning` ارائه نشده باشد، الزامی است. | MASK | خیر | یک ماسک برای هر شیء |
| `conditioning` | شرطی‌سازی متنی برای تشخیص اشیاء جدید در طول ردیابی. اگر `initial_mask` ارائه نشده باشد، الزامی است. | CONDITIONING | خیر | شرطی‌سازی متنی |
| `detection_threshold` | آستانه امتیاز برای تشخیص مبتنی بر پرامپت متنی (پیش‌فرض: 0.5). | FLOAT | بله | 0.0 تا 1.0 |
| `max_objects` | حداکثر اشیاء ردیابی‌شده. ماسک‌های اولیه در این محدودیت محاسبه می‌شوند. مقدار 0 از سقف داخلی 64 استفاده می‌کند (پیش‌فرض: 4). | INT | بله | 0 تا 64 |
| `detect_interval` | تشخیص را هر N فریم اجرا کنید (1=هر فریم). مقادیر بیشتر در مصرف محاسبات صرفه‌جویی می‌کنند (پیش‌فرض: 1). | INT | بله | 1 یا بالاتر |

**توجه:** یا `initial_mask` یا `conditioning` باید ارائه شود. اگر هر دو حذف شوند، گره یک خطا ایجاد می‌کند. وقتی هر دو ارائه شوند، ماسک‌های اولیه اشیاء را برای ردیابی از فریم اول تعیین می‌کنند و پرامپت‌های متنی اشیاء اضافی را در طول ردیابی تشخیص می‌دهند.
