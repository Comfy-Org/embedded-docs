# ردیابی ویدئویی SAM3

ردیابی اشیاء در بین فریم‌های ویدیو با استفاده از ردیاب مبتنی بر حافظه SAM3. این گره یک دنباله از فریم‌های ویدیو را پردازش می‌کند و هویت اشیاء را در بین فریم‌ها حفظ می‌کند؛ با استفاده از ماسک‌های اولیه یا پرامپت‌های متنی برای تعیین اینکه چه چیزی ردیابی شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `تصاویر` | فریم‌های ویدیو به‌صورت تصاویر دسته‌ای | IMAGE | بله | فریم‌های ویدیویی دسته‌ای |
| `مدل` | مدل SAM3 مورد استفاده برای ردیابی | MODEL | بله | مدل SAM3 |
| `ماسک اولیه` | ماسک(های) فریم اول برای ردیابی (یکی برای هر شیء) | MASK | خیر | یک ماسک برای هر شیء |
| `شرط‌گذاری` | شرطی‌سازی متنی برای شناسایی اشیاء جدید در طول ردیابی | CONDITIONING | خیر | شرطی‌سازی متنی |
| `آستانه تشخیص` | آستانه امتیاز برای شناسایی مبتنی بر پرامپت متنی (پیش‌فرض: 0.5) | FLOAT | خیر | 0.0 تا 1.0 |
| `حداکثر اشیاء` | حداکثر اشیاء ردیابی‌شده. ماسک‌های اولیه در این محدوده محاسبه می‌شوند. مقدار 0 از سقف داخلی 64 استفاده می‌کند. (پیش‌فرض: 4) | INT | خیر | 0 تا 64 |
| `فاصله تشخیص` | اجرای شناسایی هر N فریم (1=هر فریم). مقادیر بالاتر محاسبات را کاهش می‌دهد. (پیش‌فرض: 1) | INT | خیر | 1 یا بیشتر |

**نکته:** یا `initial_mask` یا `conditioning` باید ارائه شود. اگر هر دو حذف شوند، گره یک خطا صادر می‌کند.
