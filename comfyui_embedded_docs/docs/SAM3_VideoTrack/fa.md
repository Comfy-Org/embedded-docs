# ردیابی ویدئویی SAM3

با استفاده از ردیاب مبتنی بر حافظه SAM3، اشیاء را در فریم‌های ویدیو ردیابی کنید. این گره یک توالی از فریم‌های ویدیو را پردازش می‌کند و هویت اشیاء را در طول فریم‌ها حفظ می‌کند، یا با استفاده از ماسک‌های اولیه یا پرامپت‌های متنی تعیین می‌کند چه چیزی ردیابی شود، و می‌تواند در طول مسیر با استفاده از شرط‌گذاری متنی اشیاء جدید را تشخیص دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | فریم‌های ویدیو به‌صورت تصاویر دسته‌ای | IMAGE | بله | فریم‌های ویدیویی دسته‌ای |
| `model` | مدل SAM3 برای استفاده در ردیابی | MODEL | بله | مدل SAM3 |
| `initial_mask` | ماسک(ها) برای اولین فریم جهت ردیابی (یکی برای هر شیء) | MASK | خیر | یک ماسک برای هر شیء |
| `conditioning` | شرط‌گذاری متنی برای تشخیص اشیاء جدید در حین ردیابی | CONDITIONING | خیر | شرط‌گذاری متنی |
| `detection_threshold` | آستانه امتیاز برای تشخیص مبتنی بر پرامپت متنی (پیش‌فرض: 0.5) | FLOAT | خیر | 0.0 تا 1.0 (گام 0.01) |
| `max_objects` | حداکثر اشیاء ردیابی‌شده. ماسک‌های اولیه در این محدودیت لحاظ می‌شوند. مقدار 0 از سقف داخلی 64 استفاده می‌کند. (پیش‌فرض: 4) | INT | خیر | 0 تا 64 |
| `detect_interval` | اجرای تشخیص در هر N فریم (1=هر فریم). مقادیر بالاتر محاسبات را کاهش می‌دهند. (پیش‌فرض: 1) | INT | خیر | 1 یا بیشتر |

**توجه:** باید یا `initial_mask` یا `conditioning` ارائه شود. اگر هر دو حذف شوند، گره خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `track_data` | داده‌های ردیابی شامل ماسک‌های اشیاء و فراداده‌ها در تمام فریم‌های ویدیو | SAM3_TRACK_DATA |
