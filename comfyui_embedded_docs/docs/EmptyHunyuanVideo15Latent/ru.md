# Пустой HunyuanVideo 1.5 latent

Этот узел создаёт пустой латентный тензор, специально отформатированный для использования с моделью HunyuanVideo 1.5. Он генерирует пустую отправную точку для генерации видео, выделяя тензор нулей с правильным количеством каналов и пространственными размерами для латентного пространства модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина кадра видео в пикселях. | INT | Да | - |
| `height` | Высота кадра видео в пикселях. | INT | Да | - |
| `length` | Количество кадров в видеопоследовательности. | INT | Да | - |
| `batch_size` | Количество видеообразцов для генерации в одном пакете (по умолчанию: 1). | INT | Нет | - |

**Примечание:** Пространственные размеры сгенерированного латентного тензора вычисляются путём деления входных `width` и `height` на 16. Временное измерение (кадры) вычисляется как `((length - 1) // 4) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой латентный тензор с размерами, подходящими для модели HunyuanVideo 1.5. Тензор имеет форму `[batch_size, 32, frames, height//16, width//16]`. Выходные данные также включают значение `downscale_ratio_spacial`, равное 16. | LATENT |
