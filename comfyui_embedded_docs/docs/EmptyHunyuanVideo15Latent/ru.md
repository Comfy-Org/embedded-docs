# Пустой HunyuanVideo 1.5 latent

Этот узел создаёт пустой латентный тензор, специально отформатированный для использования с моделью HunyuanVideo 1.5. Он формирует пустую отправную точку для генерации видео, выделяя тензор из нулей с правильным количеством каналов и пространственными размерами для латентного пространства модели.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина видеокадра в пикселях. | INT | Да | - |
| `высота` | Высота видеокадра в пикселях. | INT | Да | - |
| `длина` | Количество кадров в видеопоследовательности. | INT | Да | - |
| `размер_пакета` | Количество видеообразцов для генерации в одном пакете (по умолчанию: 1). | INT | Нет | - |

**Примечание:** Пространственные размеры генерируемого латентного тензора вычисляются делением входных значений `width` и `height` на 16. Временное измерение (кадры) вычисляется как `((length - 1) // 4) + 1`. В этих вычислениях используется целочисленное деление, поэтому `width` и `height` должны быть кратны 16, чтобы избежать усечения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой латентный тензор с размерами, подходящими для модели HunyuanVideo 1.5. Тензор имеет форму `[batch_size, 32, frames, height//16, width//16]`. Выходные данные также содержат значение `downscale_ratio_spacial` равное 16. | LATENT |
