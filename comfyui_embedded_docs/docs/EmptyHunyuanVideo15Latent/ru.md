# Пустой HunyuanVideo 1.5 latent

Этот узел создаёт пустой латентный тензор, специально отформатированный для использования с моделью HunyuanVideo 1.5. Он создаёт пустую начальную точку для генерации видео, выделяя тензор нулей с правильным количеством каналов и пространственными размерами для латентного пространства модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина видеокадра в пикселях. | INT | Да | - |
| `высота` | Высота видеокадра в пикселях. | INT | Да | - |
| `длина` | Количество кадров в видеопоследовательности. | INT | Да | - |
| `размер_пакета` | Количество видеообразцов для генерации в пакете (по умолчанию: 1). | INT | Нет | - |

**Примечание:** Пространственные размеры создаваемого латентного тензора вычисляются делением входных `width` и `height` на 16 (этот узел использует коэффициент пространственного масштабирования 16, а не 8). Временная размерность (кадры) вычисляется как `((length - 1) // 4) + 1`. Эти вычисления используют целочисленное деление, поэтому `width` и `height` должны быть кратны 16, чтобы избежать усечения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой латентный тензор с размерами, подходящими для модели HunyuanVideo 1.5. Тензор имеет форму `[batch_size, 32, ((length - 1) // 4) + 1, height // 16, width // 16]`. Выход также включает значение `downscale_ratio_spacial`, равное 16. | LATENT |
