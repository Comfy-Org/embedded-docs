# EmptyHunyuanVideo15Latent

צומת זה יוצר טנזור לטנטי ריק המעוצב במיוחד לשימוש עם המודל HunyuanVideo 1.5. הוא מייצר נקודת התחלה ריקה ליצירת וידאו על ידי הקצאת טנזור של אפסים עם מספר הערוצים והממדים המרחביים הנכונים עבור מרחב לטנטי של המודל.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `width` | הרוחב של פריים הווידאו בפיקסלים. | INT | כן | - |
| `height` | הגובה של פריים הווידאו בפיקסלים. | INT | כן | - |
| `length` | מספר הפריימים ברצף הווידאו. | INT | כן | - |
| `batch_size` | מספר דגימות הווידאו ליצירה באצווה (ברירת מחדל: 1). | INT | לא | - |

**הערה:** הממדים המרחביים של הטנזור הלטנטי שנוצר מחושבים על ידי חלוקת `width` ו-`height` של הקלט ב-16 (צומת זה משתמש במקדם קנה מידה מרחבי של 16 ולא 8). הממד הזמני (פריימים) מחושב כ-`((length - 1) // 4) + 1`. חישובים אלו משתמשים בחילוק שלמים, ולכן `width` ו-`height` צריכים להיות כפולות של 16 כדי למנוע קיטוע.
