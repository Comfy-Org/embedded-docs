# ویدیوی نهفته Hunyuan ۱.۵ خالی

این گره یک تنسور نهفته (latent) خالی ایجاد می‌کند که به‌طور خاص برای استفاده با مدل HunyuanVideo 1.5 قالب‌بندی شده است. با تخصیص یک تنسور صفر با تعداد کانال‌ها و ابعاد فضایی صحیح برای فضای نهفته مدل، نقطه‌ی شروع خالی برای تولید ویدیو فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | عرض فریم ویدیو بر حسب پیکسل. | INT | بله | - |
| `height` | ارتفاع فریم ویدیو بر حسب پیکسل. | INT | بله | - |
| `length` | تعداد فریم‌ها در دنباله ویدیو. | INT | بله | - |
| `batch_size` | تعداد نمونه‌های ویدیو برای تولید در یک دسته (پیش‌فرض: ۱). | INT | خیر | - |

**توجه:** ابعاد فضایی تنسور نهفته تولیدشده با تقسیم `width` و `height` ورودی بر ۱۶ محاسبه می‌شود. بُعد زمانی (فریم‌ها) به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | یک تنسور نهفته خالی با ابعادی مناسب برای مدل HunyuanVideo 1.5. این تنسور دارای شکلی به‌صورت `[batch_size, 32, frames, height//16, width//16]` است. خروجی همچنین شامل مقدار `downscale_ratio_spacial` برابر با ۱۶ است. | LATENT |
