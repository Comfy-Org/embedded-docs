# ویدیوی نهفته Hunyuan ۱.۵ خالی

این گره یک تنسور نهفته خالی ایجاد می‌کند که به‌طور خاص برای استفاده با مدل HunyuanVideo 1.5 قالب‌بندی شده است. با تخصیص یک تنسور از صفرها با تعداد کانال‌ها و ابعاد فضایی صحیح برای فضای نهفته مدل، یک نقطه شروع خالی برای تولید ویدیو ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `عرض` | عرض قاب ویدیو به پیکسل. | INT | بله | - |
| `ارتفاع` | ارتفاع قاب ویدیو به پیکسل. | INT | بله | - |
| `طول` | تعداد فریم‌ها در توالی ویدیو. | INT | بله | - |
| `اندازه دسته` | تعداد نمونه‌های ویدیویی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | خیر | - |

**نکته:** ابعاد فضایی تنسور نهفته تولیدشده با تقسیم `width` و `height` ورودی بر ۱۶ محاسبه می‌شود. بُعد زمانی (فریم‌ها) به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود. این محاسبات از تقسیم صحیح استفاده می‌کنند، بنابراین `width` و `height` باید مضربی از ۱۶ باشند تا از برش (truncation) جلوگیری شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | یک تنسور نهفته خالی با ابعاد مناسب برای مدل HunyuanVideo 1.5. تنسور شکلی به‌صورت `[batch_size, 32, frames, height//16, width//16]` دارد. خروجی همچنین شامل مقدار `downscale_ratio_spacial` برابر با ۱۶ است. | LATENT |
