# ویدیوی نهفته Hunyuan ۱.۵ خالی

این گره یک تنسور نهفته خالی می‌سازد که به‌طور ویژه برای استفاده با مدل HunyuanVideo 1.5 قالب‌بندی شده است. این گره با تخصیص تنسوری از صفرها با تعداد کانال و ابعاد فضایی صحیح برای فضای نهفته مدل، یک نقطه شروع خالی برای تولید ویدئو ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | عرض فریم ویدئو برحسب پیکسل. | INT | بله | - |
| `height` | ارتفاع فریم ویدئو برحسب پیکسل. | INT | بله | - |
| `length` | تعداد فریم‌ها در دنباله ویدئو. | INT | بله | - |
| `batch_size` | تعداد نمونه‌های ویدئویی برای تولید در یک دسته (پیش‌فرض: 1). | INT | خیر | - |

**توجه:** ابعاد فضایی تنسور نهفته تولیدشده با تقسیم `width` و `height` ورودی بر 16 محاسبه می‌شوند (این گره از ضریب مقیاس فضایی 16 به‌جای 8 استفاده می‌کند). بعد زمانی (فریم‌ها) به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود. این محاسبات از تقسیم صحیح استفاده می‌کنند، بنابراین `width` و `height` باید مضرب 16 باشند تا از بریده‌شدن مقادیر جلوگیری شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | یک تنسور نهفته خالی با ابعادی مناسب مدل HunyuanVideo 1.5. تنسور شکلی به‌صورت `[batch_size, 32, ((length - 1) // 4) + 1, height // 16, width // 16]` دارد. خروجی همچنین شامل مقدار `downscale_ratio_spacial` برابر با 16 است. | LATENT |
