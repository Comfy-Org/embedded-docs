# فيديو Hunyuan 1.5 كامن فارغ

تقوم هذه العقدة بإنشاء موتر كامن فارغ مُنسّق خصيصًا للاستخدام مع نموذج HunyuanVideo 1.5. وهي تولّد نقطة بداية فارغة لتوليد الفيديو عبر تخصيص موتر من الأصفار بعدد القنوات والأبعاد المكانية الصحيحين للفضاء الكامن الخاص بالنموذج.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `العرض` | عرض إطار الفيديو بالبكسل. | INT | نعم | - |
| `الارتفاع` | ارتفاع إطار الفيديو بالبكسل. | INT | نعم | - |
| `الطول` | عدد الإطارات في تسلسل الفيديو. | INT | نعم | - |
| `حجم الدفعة` | عدد عينات الفيديو التي سيتم توليدها في دفعة واحدة (الافتراضي: 1). | INT | لا | - |

**ملاحظة:** تُحسب الأبعاد المكانية للموتر الكامن الناتج عبر قسمة `width` و `height` المُدخلين على 16 (تستخدم هذه العقدة معامل مقياس مكاني مقداره 16 بدلًا من 8). ويُحسب البعد الزمني (الإطارات) كـ `((length - 1) // 4) + 1`. تستخدم هذه الحسابات القسمة الصحيحة، لذا ينبغي أن تكون قيمتا `width` و `height` من مضاعفات 16 لتجنب الاقتطاع.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `samples` | موتر كامن فارغ بأبعاد مناسبة لنموذج HunyuanVideo 1.5. يكون شكل الموتر `[batch_size, 32, ((length - 1) // 4) + 1, height // 16, width // 16]`. يتضمن المخرج أيضًا قيمة `downscale_ratio_spacial` مقدارها 16. | LATENT |
