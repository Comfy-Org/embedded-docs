# فيديو Hunyuan 1.5 كامن فارغ

تنشئ هذه العقدة موترًا كامنًا (latent tensor) فارغًا مصممًا خصيصًا للاستخدام مع نموذج HunyuanVideo 1.5. وهي تولّد نقطة بداية فارغة لتوليد الفيديو عن طريق تخصيص موتر من الأصفار بعدد القنوات الصحيح والأبعاد المكانية المناسبة للفضاء الكامن للنموذج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `width` | عرض إطار الفيديو بالبكسل. | INT | نعم | - |
| `height` | ارتفاع إطار الفيديو بالبكسل. | INT | نعم | - |
| `length` | عدد الإطارات في تسلسل الفيديو. | INT | نعم | - |
| `batch_size` | عدد عينات الفيديو التي سيتم توليدها في دفعة واحدة (الافتراضي: 1). | INT | لا | - |

**ملاحظة:** تُحسب الأبعاد المكانية للموتر الكامن المُولَّد بقسمة قيمتي `width` و `height` على 16. أما البعد الزمني (الإطارات) فيُحسب بالمعادلة `((length - 1) // 4) + 1`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `samples` | موتر كامن فارغ بأبعاد مناسبة لنموذج HunyuanVideo 1.5. ويكون شكل الموتر `[batch_size, 32, frames, height//16, width//16]`. يتضمن المخرج أيضًا قيمة `downscale_ratio_spacial` تساوي 16. | LATENT |
