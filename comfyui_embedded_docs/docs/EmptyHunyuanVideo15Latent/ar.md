# فيديو Hunyuan 1.5 كامن فارغ

تنشئ هذه العقدة موترًا كامنًا فارغًا مصممًا خصيصًا للاستخدام مع نموذج HunyuanVideo 1.5. وهي تولّد نقطة بداية فارغة لتوليد الفيديو عبر تخصيص موتر من الأصفار بعدد القنوات الصحيح والأبعاد المكانية المناسبة لفضاء النموذج الكامن.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `العرض` | عرض إطار الفيديو بالبكسل. | INT | نعم | - |
| `الارتفاع` | ارتفاع إطار الفيديو بالبكسل. | INT | نعم | - |
| `الطول` | عدد الإطارات في تسلسل الفيديو. | INT | نعم | - |
| `حجم الدفعة` | عدد عينات الفيديو المراد توليدها في الدفعة الواحدة (الافتراضي: 1). | INT | لا | - |

**ملاحظة:** تُحسب الأبعاد المكانية للموتر الكامن الناتج بقسمة `width` و`height` المُدخلين على 16. أما البعد الزمني (الإطارات) فيُحسب على النحو التالي: `((length - 1) // 4) + 1`. تستخدم هذه الحسابات القسمة الصحيحة، لذا ينبغي أن تكون قيم `width` و`height` من مضاعفات الرقم 16 لتجنب اقتطاع القيم.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `samples` | موتر كامن فارغ بأبعاد مناسبة لنموذج HunyuanVideo 1.5. يكون شكل الموتر `[batch_size, 32, frames, height//16, width//16]`. يتضمن المخرج أيضًا قيمة `downscale_ratio_spacial` تساوي 16. | LATENT |
