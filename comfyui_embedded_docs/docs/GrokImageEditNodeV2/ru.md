# Grok Image Edit

Изменяет одно или несколько существующих изображений на основе текстового запроса. Узел отправляет подключённые эталонные изображения и запрос в API редактирования изображений Grok, используя выбранную модель, после чего возвращает отредактированные изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель изображений Grok. Показанные ниже подпараметры меняются в зависимости от выбранной модели. | DYNAMIC_COMBO | Да | "grok-imagine-image-2.0"<br>"grok-imagine-image-quality"<br>"grok-imagine-image-pro"<br>"grok-imagine-image" |
| `prompt` | Текстовый запрос, используемый для генерации изображения. (по умолчанию: "") | STRING | Да | N/A |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | 0 до 2147483647 |

### Входы grok-imagine-image-2.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 до 10 |
| `quality` | Уровень качества генерируемых изображений. | COMBO | Да | "medium"<br>"low" |
| `aspect_ratio` | Соотношение сторон отредактированного изображения. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"9:16"<br>"16:9"<br>"9:19.5"<br>"19.5:9"<br>"9:20"<br>"20:9"<br>"1:2"<br>"2:1" |

### Входы grok-imagine-image-quality и grok-imagine-image

Общие для grok-imagine-image-quality и grok-imagine-image.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 до 10 |
| `aspect_ratio` | Разрешено только при подключении нескольких изображений. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"9:16"<br>"16:9"<br>"9:19.5"<br>"19.5:9"<br>"9:20"<br>"20:9"<br>"1:2"<br>"2:1" |

### Входы grok-imagine-image-pro

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 до 10 |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до N эталонных изображений для редактирования. Слоты используют шаблонные имена `image_1`, `image_2`, `image_3`; максимальное количество слотов зависит от выбранной модели. | IMAGE | Да | 1 изображение для `grok-imagine-image-pro`<br>от 1 до 3 изображений для `grok-imagine-image-2.0`, `grok-imagine-image-quality` и `grok-imagine-image` |

**Примечание об ограничениях:**
- `prompt` должен содержать как минимум 1 непробельный символ.
- Для редактирования требуется как минимум одно эталонное изображение; если ни одно изображение не подключено, узел выдаёт ошибку.
- Максимальное количество входных изображений — 1 для `grok-imagine-image-pro` и 3 для `grok-imagine-image-2.0`, `grok-imagine-image-quality` и `grok-imagine-image`. Подключение большего количества изображений, чем поддерживает модель, вызывает ошибку.
- Ограничение на изображения учитывает каждое изображение в подключённых входах, поэтому пакет, содержащий несколько изображений, считается как несколько изображений в пределах лимита.
- Для `grok-imagine-image-quality` и `grok-imagine-image` пользовательское значение `aspect_ratio` (любое, кроме "auto") разрешено только при подключении нескольких изображений. При одном изображении `aspect_ratio` должен быть "auto".
- Для `grok-imagine-image-2.0` `aspect_ratio` можно задавать свободно даже при одном изображении.
- Подпараметр `quality` доступен только для `grok-imagine-image-2.0`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Отредактированные изображения, возвращаемые API Grok. Если сгенерировано одно изображение, оно возвращается напрямую. Если сгенерировано несколько изображений, они объединяются в единый батч-тензор. | IMAGE |
