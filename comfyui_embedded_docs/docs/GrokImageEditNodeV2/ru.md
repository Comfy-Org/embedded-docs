# Grok Image Edit

Измените существующее изображение на основе текстового запроса. Этот узел отправляет ваши изображения и текстовое описание в API Grok, который редактирует изображения в соответствии с вашими инструкциями и возвращает результат.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель изображений Grok для использования. Отображаемые ниже подпараметры изменяются в зависимости от выбранной модели. | DYNAMIC_COMBO | Да | "grok-imagine-image-2.0"<br>"grok-imagine-image-quality"<br>"grok-imagine-image-pro"<br>"grok-imagine-image" |
| `prompt` | Текстовый запрос, используемый для генерации изображения. (по умолчанию: "") | STRING | Да | N/A |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | 0 to 2147483647 |

### Входы grok-imagine-image-2.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 to 10 |
| `quality` | Уровень качества генерируемых изображений. | COMBO | Да | "medium"<br>"low" |
| `aspect_ratio` | Соотношение сторон отредактированного изображения. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"9:16"<br>"16:9"<br>"9:19.5"<br>"19.5:9"<br>"9:20"<br>"20:9"<br>"1:2"<br>"2:1" |

### Входы grok-imagine-image-quality и grok-imagine-image

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 to 10 |
| `aspect_ratio` | Допускается только при подключении нескольких изображений. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"9:16"<br>"16:9"<br>"9:19.5"<br>"19.5:9"<br>"9:20"<br>"20:9"<br>"1:2"<br>"2:1" |

### Входы grok-imagine-image-pro

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `resolution` | Выходное разрешение отредактированных изображений. | COMBO | Да | "1K"<br>"2K" |
| `number_of_images` | Количество отредактированных изображений для генерации. (по умолчанию: 1) | INT | Да | 1 to 10 |

### Ссылочные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `images` | Расширяемый слот: подключите одно или несколько ссылочных изображений для редактирования. Можно добавлять нумерованные слоты, такие как `image_1`, `image_2`, `image_3`. Максимальное количество изображений зависит от выбранной модели (см. разделы моделей выше). | IMAGE | Да | 1 image for `grok-imagine-image-pro`<br>1 to 3 images for `grok-imagine-image-2.0`, `grok-imagine-image-quality`, and `grok-imagine-image` |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `IMAGE` | The edited image(s) returned by the Grok API. If a single image is generated, it is returned directly. If multiple images are generated, they are concatenated into a single batch tensor. | IMAGE |
