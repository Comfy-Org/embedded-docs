# Grok Image Edit

یک یا چند تصویر موجود را بر اساس یک متن دستور (prompt) تغییر دهید. این گره تصویر(های) مرجع متصل و متن دستور را با استفاده از مدل انتخاب‌شده به API ویرایش تصویر Grok می‌فرستد، سپس تصویر(های) ویرایش‌شده را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل تصویر Grok برای استفاده. زیرپارامترهای نمایش‌داده‌شده در ادامه بسته به مدل انتخاب‌شده تغییر می‌کنند. | DYNAMIC_COMBO | بله | "grok-imagine-image-2.0"<br>"grok-imagine-image-quality"<br>"grok-imagine-image-pro"<br>"grok-imagine-image" |
| `prompt` | متن دستور برای تولید تصویر. (پیش‌فرض: "") | STRING | بله | N/A |
| `seed` | مقدار بذر برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی فارغ از مقدار seed غیرقطعی هستند. (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `resolution` | رزولوشن خروجی تصاویر ویرایش‌شده. | COMBO | بله | "1K"<br>"2K" |
| `number_of_images` | تعداد تصاویر ویرایش‌شده برای تولید. (پیش‌فرض: 1) | INT | بله | 1 تا 10 |
| `quality` | سطح کیفیت تصاویر تولیدشده. | COMBO | بله | "medium"<br>"low" |
| `aspect_ratio` | نسبت ابعاد تصویر ویرایش‌شده. (پیش‌فرض: "auto") | COMBO | بله | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"9:16"<br>"16:9"<br>"9:19.5"<br>"19.5:9"<br>"9:20"<br>"20:9"<br>"1:2"<br>"2:1" |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | جایگاه قابل‌افزایش: 1 تا N تصویر مرجع را برای ویرایش متصل کنید. این جایگاه‌ها از نام‌های قالبی `image_1`، `image_2`، `image_3` استفاده می‌کنند؛ حداکثر تعداد جایگاه‌ها به مدل انتخاب‌شده بستگی دارد. | IMAGE | بله | 1 تصویر برای `grok-imagine-image-pro`<br>1 تا 3 تصویر برای `grok-imagine-image-2.0`، `grok-imagine-image-quality` و `grok-imagine-image` |

**نکته درباره محدودیت‌ها:**
- `prompt` باید حداقل 1 نویسه غیرفاصله داشته باشد.
- حداقل یک تصویر مرجع برای ویرایش لازم است؛ اگر هیچ تصویری متصل نباشد، گره خطا می‌دهد.
- حداکثر تعداد تصاویر ورودی برای `grok-imagine-image-pro` برابر 1 و برای `grok-imagine-image-2.0`، `grok-imagine-image-quality` و `grok-imagine-image` برابر 3 است. اتصال تصاویر بیشتر از آنچه مدل پشتیبانی می‌کند، خطا ایجاد می‌کند.
- محدودیت تصاویر، هر تصویر را در ورودی‌های متصل می‌شمارد؛ بنابراین یک دسته شامل چند تصویر به‌اندازه چند تصویر در محدودیت لحاظ می‌شود.
- برای `grok-imagine-image-quality` و `grok-imagine-image`، یک `aspect_ratio` سفارشی (هر چیزی غیر از "auto") فقط زمانی مجاز است که چند تصویر متصل باشند. با یک تصویر واحد، `aspect_ratio` باید "auto" باشد.
- برای `grok-imagine-image-2.0`، `aspect_ratio` حتی با یک تصویر نیز می‌تواند آزادانه تنظیم شود.
- زیرپارامتر `quality` فقط با `grok-imagine-image-2.0` در دسترس است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) ویرایش‌شده بازگردانده‌شده توسط API Grok. اگر یک تصویر تولید شود، مستقیماً بازگردانده می‌شود. اگر چند تصویر تولید شود، در یک تنسور دسته‌ای واحد به‌هم متصل می‌شوند. | IMAGE |
