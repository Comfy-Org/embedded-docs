# קבלת פריט מרשימה

צומת זה מחזיר פריט בודד מרשימה, שנבחר לפי מיקומו. אתם מספקים את הרשימה ואת מספר האינדקס של הפריט הרצוי, והצומת מוציא את הפריט הזה. הדבר שימושי לבחירת רכיב ספציפי אחד מתוך קבוצת ערכים, כגון תמונה מסוימת מתוך אצווה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `list` | רשימת הערכים שמתוכם לבחור. מכיוון שצומת זה מסומן ככזה שמקבל קלט רשימה, הערך המחובר מטופל כקבוצת פריטים. | Any Type | כן | כל רשימה של ערכים |
| `index` | המיקום של הפריט להחזרה. הערך מתחיל ב-0, כך ש-`0` מחזיר את הפריט הראשון, `1` מחזיר את הפריט השני, וכן הלאה (ברירת מחדל: 0). | INT | כן | כל אינדקס שלם |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `OUTPUT` | הפריט הבודד שנמצא באינדקס `index` שצוין בתוך `list` שסופקה. | Any Type |
