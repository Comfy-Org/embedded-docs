# GetItemFromList

این گره یک آیتم واحد را از یک فهرست بازمی‌گرداند که بر اساس موقعیت آن انتخاب می‌شود. شما فهرست و شماره اندیس آیتم موردنظر را ارائه می‌دهید و گره آن آیتم را خروجی می‌دهد. این ویژگی آن را برای انتخاب یک عنصر مشخص از میان مجموعه‌ای از مقادیر، مانند یک تصویر خاص از یک دسته، مفید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `list` | فهرست مقادیری که باید از میان آن‌ها انتخاب شود. چون این گره به‌عنوان گره‌ای با ورودی فهرست علامت‌گذاری شده است، مقدار متصل‌شده به‌صورت گروهی از آیتم‌ها در نظر گرفته می‌شود. | Any Type | بله | هر فهرستی از مقادیر |
| `index` | موقعیت آیتمی که باید بازگردانده شود. مقدار از ۰ شروع می‌شود، بنابراین `0` اولین آیتم را برمی‌گرداند، `1` دومین آیتم را برمی‌گرداند و به همین ترتیب (پیش‌فرض: 0). | INT | بله | هر اندیس عددی |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `OUTPUT` | آیتم واحدی که در `index` داده‌شده درون `list` ارائه‌شده قرار دارد. | Any Type |
