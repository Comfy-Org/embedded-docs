# GetItemFromList

Этот узел возвращает один элемент из списка, выбранный по его позиции. Вы предоставляете список и номер индекса нужного элемента, и узел выводит этот элемент. Это полезно для выбора одного конкретного элемента из группы значений, например определённого изображения из пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `list` | Список значений, из которого нужно выбрать. Поскольку этот узел отмечен как принимающий список на вход, подключённое значение обрабатывается как группа элементов. | Любой тип | Да | Любой список значений |
| `index` | Позиция возвращаемого элемента. Значение начинается с 0, поэтому `0` возвращает первый элемент, `1` — второй и так далее (по умолчанию: 0). | INT | Да | Любой целочисленный индекс |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `OUTPUT` | Единственный элемент, расположенный по заданному `index` в предоставленном `list`. | Любой тип |
