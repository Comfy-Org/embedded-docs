# StabilityStableImageSD_3_5Node

צומת זה יוצר תמונות באופן סינכרוני באמצעות המודל Stable Diffusion 3.5 של Stability AI. הוא יוצר תמונות על בסיס הנחיות טקסט ויכול גם לשנות תמונות קיימות כאשר הן מסופקות כקלט. הצומת תומך במגוון יחסי גובה-רוחב ובפריסטים של סגנון כדי להתאים אישית את הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה תרצו לראות בתמונת הפלט. הנחיה חזקה ותיאורית שמגדירה בבירור אלמנטים, צבעים ונושאים תוביל לתוצאות טובות יותר. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `model` | מודל Stable Diffusion 3.5 שבו להשתמש ליצירה. | COMBO | כן | `sd3.5-large`<br>`sd3.5-large-turbo`<br>`sd3.5-medium` |
| `aspect_ratio` | יחס גובה-רוחב של התמונה הנוצרת. (ברירת מחדל: 1:1) | COMBO | כן | `16:9`<br>`1:1`<br>`21:9`<br>`2:3`<br>`3:2`<br>`4:5`<br>`5:4`<br>`9:16`<br>`9:21` |
| `style_preset` | סגנון רצוי אופציונלי לתמונה הנוצרת. בחרו "None" כדי לא להשתמש בפריסט סגנון. | COMBO | לא | `3d-model`<br>`analog-film`<br>`anime`<br>`cinematic`<br>`comic-book`<br>`digital-art`<br>`enhance`<br>`fantasy-art`<br>`isometric`<br>`line-art`<br>`low-poly`<br>`modeling-compound`<br>`neon-punk`<br>`origami`<br>`photographic`<br>`pixel-art`<br>`tile-texture`<br>`None` |
| `cfg_scale` | עד כמה תהליך הדיפוזיה מקפיד להיצמד לטקסט ההנחיה (ערכים גבוהים יותר מקרבים את התמונה להנחיה שלכם). (ברירת מחדל: 4.0) | FLOAT | כן | 1.0 עד 10.0 |
| `seed` | הזרע האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | כן | 0 עד 4294967294 |
| `image` | תמונת קלט אופציונלית ליצירה מתמונה לתמונה. כאשר מסופקת, הצומת עובר למצב תמונה-לתמונה והפרמטר `aspect_ratio` לא בשימוש. | IMAGE | לא | - |
| `negative_prompt` | מילות מפתח של מה שאינכם רוצים לראות בתמונת הפלט. זוהי תכונה מתקדמת. (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `image_denoise` | הסרת רעש מתמונת הקלט; 0.0 מניב תמונה זהה לקלט, 1.0 הוא כאילו לא סופקה תמונה כלל. (ברירת מחדל: 0.5) פרמטר זה משמש רק כאשר מסופקת `image`. | FLOAT | לא | 0.0 עד 1.0 |

**הערה:** כאשר מסופקת `image`, הצומת עובר למצב יצירה מתמונה לתמונה והפרמטר `aspect_ratio` נקבע אוטומטית מתמונת הקלט. כאשר לא מסופקת `image`, הפרמטר `image_denoise` אינו בשימוש.
