# MiniMaxMusic3TextEncode

MiniMax Music3 Text Encode משתמש במודל MiniMax Music3 CLIP כדי להמיר כיתובי טקסט ומילות שיר לרצף התניה אקוסטי ליצירת מוזיקה. הצומת מחזיר את נתוני ה-CONDITIONING המתקבלים, יחד עם משך האודיו בפועל בשניות, המחושב מתוך משך הזמן המקסימלי שהוזן.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל MiniMax Music3 CLIP, המשמש לקידוד טקסט ויצירת רצף התניה. | CLIP | כן | - |
| `caption` | טקסט המתאר את המוזיקה ליצירה. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `lyrics` | טקסט מילות השיר שישמש ליצירת המוזיקה. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `seed` | זרע אקראי לשחזור עבור תהליך היצירה. ברירת מחדל: 0. מסופק ווידג'ט control-after-generate. | INT | כן | 0 עד 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | משך זמן מקסימלי בשניות; המודל יכול לסיים את השיר מוקדם יותר. ברירת מחדל: 120.0. | FLOAT | כן | 0.04 עד משך האודיו המקסימלי של המודל (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), צעד 0.04 |
| `cfg_scale` | סולם הנחיה ללא מסווג (classifier-free guidance). ברירת מחדל: קבוע המודל CFG_SCALE. פרמטר מתקדם. | FLOAT | כן | 0.0 עד 100.0, צעד 0.1 (שומר 2 ספרות עשרוניות) |
| `top_k` | ערך דגימת Top-k המשמש לבחירת טוקנים אקוסטיים. ברירת מחדל: קבוע המודל CFG_TOP_K. פרמטר מתקדם. | INT | כן | 1 עד גודל אוצר המילים של המודל (C0_VOCAB_SIZE) |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `conditioning` | רצף ההתניה האקוסטי שנוצר, המשמש להנחות יצירת מוזיקה עוקבת. | CONDITIONING |
| `seconds` | משך הזמן בפועל של רצף ההתניה, בשניות. | FLOAT |
