# MiniMax Music3 Кодирование текста

Узел MiniMax Music3 Text Encode использует модель CLIP MiniMax Music3 для преобразования текстовых подписей и текста песни в последовательность акустического кондиционирования для генерации музыки. Узел возвращает полученные данные CONDITIONING, а также фактическую длительность аудио в секундах, рассчитанную на основе входного параметра максимальной длительности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `clip` | Модель CLIP MiniMax Music3, используемая для текстового кодирования и генерации последовательности кондиционирования. | CLIP | Да | - |
| `caption` | Текст, описывающий музыку для генерации. Поддерживает многострочный текст и динамические промпты. | STRING | Да | - |
| `текст песни` | Текст песни, используемый для генерации музыки. Поддерживает многострочный текст и динамические промпты. | STRING | Да | - |
| `seed` | Воспроизводимое случайное зерно для процесса генерации. По умолчанию: 0. Предусмотрен виджет управления после генерации. | INT | Да | 0 до 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | Максимальная длительность в секундах; модель может завершить песню раньше. По умолчанию: 120.0. | FLOAT | Да | 0.04 до максимальной длительности аудио модели (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), шаг 0.04 |
| `cfg_scale` | Масштаб управления без классификатора (classifier-free guidance). По умолчанию: константа модели CFG_SCALE. Расширенный параметр. | FLOAT | Да | 0.0 до 100.0, шаг 0.1 (сохраняет 2 знака после запятой) |
| `top_k` | Значение top-k сэмплирования, используемое для выбора акустических токенов. По умолчанию: константа модели CFG_TOP_K. Расширенный параметр. | INT | Да | 1 до размера словаря модели (C0_VOCAB_SIZE) |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `conditioning` | Сгенерированная последовательность акустического кондиционирования, используемая для управления последующей генерацией музыки. | CONDITIONING |
| `seconds` | Фактическая длительность последовательности кондиционирования в секундах. | FLOAT |
