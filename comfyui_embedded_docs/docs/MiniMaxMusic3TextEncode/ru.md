# MiniMaxMusic3TextEncode

MiniMax Music3 Text Encode использует модель MiniMax Music3 CLIP для преобразования текстовых описаний и текста песни в акустическую последовательность кондиционирования для генерации музыки. Узел возвращает результирующие данные CONDITIONING, а также фактическую длительность аудио в секундах, рассчитанную на основе введенной максимальной длительности.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель MiniMax Music3 CLIP, используемая для кодирования текста и генерации последовательности кондиционирования. | CLIP | Да | - |
| `caption` | Текст, описывающий музыку для генерации. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `текст песни` | Текст песни, который будет использоваться для генерации музыки. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `seed` | Воспроизводимое случайное зерно для процесса генерации. По умолчанию: 0. | INT | Да | 0 до 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | Максимальная длительность в секундах; модель может завершить песню раньше. По умолчанию: 120.0. | FLOAT | Да | 0.04 to the model's maximum audio duration (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), step 0.04 |
| `cfg_scale` | Масштаб классификатор-свободного руководства. По умолчанию: константа модели CFG_SCALE. Дополнительный параметр. | FLOAT | Да | 0.0 до 100.0, step 0.1 (keeps 2 decimal places) |
| `top_k` | Значение top-k сэмплирования, используемое для выбора акустических токенов. По умолчанию: константа модели CFG_TOP_K. Дополнительный параметр. | INT | Да | 1 to the model's vocabulary size (C0_VOCAB_SIZE) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `conditioning` | Сгенерированная акустическая последовательность кондиционирования, используемая для управления последующей генерацией музыки. | CONDITIONING |
| `секунды` | Фактическая длительность последовательности кондиционирования, в секундах. | FLOAT |
