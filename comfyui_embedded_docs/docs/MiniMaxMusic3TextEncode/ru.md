# MiniMaxMusic3TextEncode

MiniMax Music3 Text Encode использует модель MiniMax Music3 CLIP для преобразования текстовых описаний и текста песни в акустическую условную последовательность для генерации музыки. Этот узел возвращает преобразованные данные CONDITIONING, а также фактическую длительность аудио в секундах, вычисленную на основе введённой длительности.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель MiniMax Music3 CLIP, используемая для кодирования текста и генерации условной последовательности. | CLIP | Да | - |
| `caption` | Текстовое содержимое, описывающее музыку для генерации. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `lyrics` | Текст песни для использования при генерации музыки. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `seed` | Воспроизводимое случайное начальное значение для процесса генерации. Значение по умолчанию: 0. | INT | Да | 0 до 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | Максимальная длительность (в секундах) генерируемой музыки; модель может завершить песню раньше. Значение по умолчанию: 120.0. | FLOAT | Да | 0.04 до максимальной длительности аудио модели (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), шаг 0.04 |
| `cfg_scale` | Коэффициент масштабирования для classifier-free guidance (управление без классификатора). Значение по умолчанию: константа модели CFG_SCALE. Расширенный параметр. | FLOAT | Да | 0.0 до 100.0, шаг 0.1 (с сохранением 2 знаков после запятой) |
| `top_k` | Значение top-k для выбора акустических токенов. Значение по умолчанию: константа модели CFG_TOP_K. Расширенный параметр. | INT | Да | 1 до размера словаря модели (C0_VOCAB_SIZE) |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `conditioning` | Сгенерированная акустическая условная последовательность, используемая для управления последующей генерацией музыки. | CONDITIONING |
| `seconds` | Фактическая длительность, соответствующая условной последовательности, в секундах. | FLOAT |
