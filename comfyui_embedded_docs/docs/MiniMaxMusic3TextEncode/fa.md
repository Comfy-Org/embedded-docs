# MiniMaxMusic3TextEncode

MiniMax Music3 Text Encode از یک مدل MiniMax Music3 CLIP برای تبدیل زیرنویس‌های متنی و متن آهنگ (lyrics) به یک توالی شرطی‌سازی صوتی برای تولید موسیقی استفاده می‌کند. این گره داده‌های CONDITIONING حاصل را همراه با مدت‌زمان واقعی صدا بر حسب ثانیه که از حداکثر مدت‌زمان ورودی محاسبه می‌شود، بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `clip` | مدل MiniMax Music3 CLIP که برای رمزگذاری متن و تولید توالی شرطی‌سازی استفاده می‌شود. | CLIP | بله | - |
| `شرح` | متنی که موسیقی مورد نظر برای تولید را توصیف می‌کند. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `متن ترانه` | متن آهنگ (lyrics) که برای تولید موسیقی استفاده می‌شود. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `سید` | مقدار seed تصادفی قابل تکرار برای فرآیند تولید. پیش‌فرض: 0. | INT | بله | 0 تا 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | حداکثر مدت‌زمان بر حسب ثانیه؛ مدل می‌تواند آهنگ را زودتر تمام کند. پیش‌فرض: 120.0. | FLOAT | بله | 0.04 تا حداکثر مدت‌زمان صوتی مدل (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، گام 0.04 |
| `cfg_scale` | مقیاس راهنمایی بدون طبقه‌بند (Classifier-free guidance scale). پیش‌فرض: ثابت مدل CFG_SCALE. پارامتر پیشرفته. | FLOAT | بله | 0.0 تا 100.0، گام 0.1 (حفظ ۲ رقم اعشار) |
| `top_k` | مقدار نمونه‌برداری Top-k که برای انتخاب توکن صوتی استفاده می‌شود. پیش‌فرض: ثابت مدل CFG_TOP_K. پارامتر پیشرفته. | INT | بله | 1 تا اندازه واژگان مدل (C0_VOCAB_SIZE) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|----------|----------|
| `conditioning` | توالی شرطی‌سازی صوتی تولیدشده که برای هدایت تولید موسیقی بعدی استفاده می‌شود. | CONDITIONING |
| `ثانیه` | مدت‌زمان واقعی توالی شرطی‌سازی، بر حسب ثانیه. | FLOAT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MiniMaxMusic3TextEncode/fa.md)
