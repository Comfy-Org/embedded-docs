# کدگذاری متن MiniMax Music3

MiniMax Music3 Text Encode از یک مدل MiniMax Music3 CLIP برای تبدیل کپشن‌های متنی و متن ترانه به یک توالی شرطی‌سازی آکوستیک جهت تولید موسیقی استفاده می‌کند. این گره داده‌های CONDITIONING به‌دست‌آمده را همراه با مدت‌زمان واقعی صوت بر حسب ثانیه که از حداکثر مدت ورودی محاسبه می‌شود، برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل MiniMax Music3 CLIP که برای رمزگذاری متن و تولید توالی شرطی‌سازی استفاده می‌شود. | CLIP | بله | - |
| `شرح` | متن توصیف‌کننده موسیقی برای تولید. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `متن ترانه` | متن ترانه‌ای که برای تولید موسیقی استفاده می‌شود. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `سید` | بذر تصادفی تکرارپذیر برای فرایند تولید. پیش‌فرض: 0. یک ویجت کنترل پس از تولید ارائه شده است. | INT | بله | 0 تا 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | حداکثر مدت بر حسب ثانیه؛ مدل می‌تواند آهنگ را زودتر پایان دهد. پیش‌فرض: 120.0. | FLOAT | بله | 0.04 تا حداکثر مدت صوت مدل (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، گام 0.04 |
| `cfg_scale` | مقیاس هدایت بدون طبقه‌بند. پیش‌فرض: مقدار ثابت مدل CFG_SCALE. پارامتر پیشرفته. | FLOAT | بله | 0.0 تا 100.0، گام 0.1 (با حفظ ۲ رقم اعشار) |
| `top_k` | مقدار نمونه‌گیری top-k که برای انتخاب توکن آکوستیک استفاده می‌شود. پیش‌فرض: مقدار ثابت مدل CFG_TOP_K. پارامتر پیشرفته. | INT | بله | 1 تا اندازه واژگان مدل (C0_VOCAB_SIZE) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `conditioning` | توالی شرطی‌سازی آکوستیک تولیدشده که برای هدایت تولید موسیقی بعدی استفاده می‌شود. | CONDITIONING |
| `seconds` | مدت‌زمان واقعی توالی شرطی‌سازی، بر حسب ثانیه. | FLOAT |
