# MiniMaxMusic3TextEncode

MiniMax Music3 Text Encode با استفاده از مدل MiniMax Music3 CLIP، توصیف متنی و متن ترانه را به توالی شرایط صوتی برای تولید موسیقی تبدیل می‌کند. این گره داده‌ی CONDITIONING تبدیل‌شده و همچنین تعداد ثانیه‌های واقعی صدا را که بر اساس مدت‌زمان ورودی محاسبه می‌شود، برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل MiniMax Music3 CLIP، برای رمزگذاری متن و تولید توالی شرایط. | CLIP | بله | - |
| `caption` | محتوای متنی توصیف‌کننده موسیقی موردنظر برای تولید. پشتیبانی از متن چندخطی و پرامپت‌های پویا. | STRING | بله | - |
| `lyrics` | متن ترانه‌ای که برای تولید موسیقی استفاده می‌شود. پشتیبانی از متن چندخطی و پرامپت‌های پویا. | STRING | بله | - |
| `seed` | عدد تصادفی قابل تکرار برای فرایند تولید. مقدار پیش‌فرض: 0. | INT | بله | 0 تا 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | حداکثر مدت‌زمان تولید موسیقی (بر حسب ثانیه)؛ مدل ممکن است آهنگ را زودتر به پایان برساند. مقدار پیش‌فرض: 120.0. | FLOAT | بله | 0.04 تا حداکثر مدت‌زمان صوتی مدل (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، گام 0.04 |
| `cfg_scale` | ضریب مقیاس راهنمایی آزاد طبقه‌بند. مقدار پیش‌فرض: ثابت مدل CFG_SCALE. پارامتر پیشرفته. | FLOAT | بله | 0.0 تا 100.0، گام 0.1 (با 2 رقم اعشار) |
| `top_k` | مقدار نمونه‌برداری top-k برای انتخاب توکن صوتی. مقدار پیش‌فرض: ثابت مدل CFG_TOP_K. پارامتر پیشرفته. | INT | بله | 1 تا اندازه واژگان مدل (C0_VOCAB_SIZE) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `conditioning` | توالی شرایط صوتی تولیدشده، برای هدایت تولید موسیقی بعدی. | CONDITIONING |
| `seconds` | مدت‌زمان واقعی متناظر با توالی شرایط، بر حسب ثانیه. | FLOAT |
