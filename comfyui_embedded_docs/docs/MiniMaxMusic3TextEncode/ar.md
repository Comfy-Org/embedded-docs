# MiniMaxMusic3TextEncode

يقوم **MiniMax Music3 Text Encode** باستخدام نموذج **MiniMax Music3 CLIP** لتحويل التسميات التوضيحية النصية وكلمات الأغاني إلى تسلسل تهيئة صوتية (acoustic conditioning sequence) لتوليد الموسيقى. تُرجع العقدة بيانات `CONDITIONING` الناتجة، بالإضافة إلى المدة الفعلية للصوت بالثواني المحسوبة من المدة القصوى المُدخلة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج MiniMax Music3 CLIP، المستخدم لتشفير النصوص وتوليد تسلسل التهيئة. | CLIP | نعم | - |
| `التسمية التوضيحية` | نص يصف الموسيقى المطلوب توليدها. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `كلمات الأغنية` | نص كلمات الأغاني المستخدم لتوليد الموسيقى. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `البذرة` | بذرة عشوائية قابلة لإعادة الإنتاج لعملية التوليد. الافتراضي: 0. | INT | نعم | 0 إلى 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | المدة القصوى بالثواني؛ يمكن للنموذج إنهاء الأغنية مبكرًا. الافتراضي: 120.0. | FLOAT | نعم | 0.04 إلى أقصى مدة صوتية للنموذج (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، بخطوة 0.04 |
| `cfg_scale` | مقياس التوجيه الخالي من المصنف. الافتراضي: ثابت النموذج CFG_SCALE. معلمة متقدمة. | FLOAT | نعم | 0.0 إلى 100.0، بخطوة 0.1 (يحتفظ بمنزلتين عشريتين) |
| `top_k` | قيمة أخذ العينات top-k المستخدمة لاختيار الرموز الصوتية. الافتراضي: ثابت النموذج CFG_TOP_K. معلمة متقدمة. | INT | نعم | 1 إلى حجم مفردات النموذج (C0_VOCAB_SIZE) |

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `conditioning` | تسلسل التهيئة الصوتية المُولّد، يُستخدم لتوجيه توليد الموسيقى اللاحق. | CONDITIONING |
| `ثوانٍ` | المدة الفعلية لتسلسل التهيئة، بالثواني. | FLOAT |
