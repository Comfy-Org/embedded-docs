# ترميز نص MiniMax Music3

MiniMax Music3 Text Encode uses a MiniMax Music3 CLIP model to convert text captions and lyrics into an acoustic conditioning sequence for music generation. تُرجع العقدة بيانات CONDITIONING الناتجة، إلى جانب المدة الفعلية للصوت بالثواني المحسوبة من مدة الإدخال القصوى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج MiniMax Music3 CLIP، ويُستخدم لترميز النص وتوليد تسلسل التهيئة. | CLIP | نعم | - |
| `caption` | نص يصف الموسيقى المراد توليدها. يدعم النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `lyrics` | نص كلمات الأغاني المستخدم لتوليد الموسيقى. يدعم النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `seed` | بذرة عشوائية قابلة للتكرار لعملية التوليد. الافتراضي: 0. يتم توفير أداة تحكم بعد التوليد. | INT | نعم | 0 إلى 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | الحد الأقصى للمدة بالثواني؛ يمكن للنموذج إنهاء الأغنية مبكرًا. الافتراضي: 120.0. | FLOAT | نعم | 0.04 إلى الحد الأقصى لمدة الصوت لدى النموذج (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، الخطوة 0.04 |
| `cfg_scale` | مقياس التوجيه الخالي من المصنّف. الافتراضي: ثابت النموذج CFG_SCALE. معامل متقدم. | FLOAT | نعم | 0.0 إلى 100.0، الخطوة 0.1 (يحتفظ بمنزلتين عشريتين) |
| `top_k` | قيمة أخذ العينات Top-k المستخدمة لاختيار الرموز الصوتية. الافتراضي: ثابت النموذج CFG_TOP_K. معامل متقدم. | INT | نعم | 1 إلى حجم مفردات النموذج (C0_VOCAB_SIZE) |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `conditioning` | تسلسل التهيئة الصوتي المُولَّد، ويُستخدم لتوجيه توليد الموسيقى اللاحق. | CONDITIONING |
| `seconds` | المدة الفعلية لتسلسل التهيئة، بالثواني. | FLOAT |
