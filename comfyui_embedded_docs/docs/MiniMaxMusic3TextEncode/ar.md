# MiniMaxMusic3TextEncode

```markdown
يقوم `MiniMax Music3 Text Encode` باستخدام نموذج MiniMax Music3 CLIP لتحويل الوصف النصي وكلمات الأغاني إلى تسلسل شرطي صوتي يستخدم لتوليد الموسيقى. يُرجع هذا العقد بيانات `CONDITIONING` المحوّلة، بالإضافة إلى عدد الثواني الصوتية الفعلية المحسوبة بناءً على المدة المُدخلة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج MiniMax Music3 CLIP، يُستخدم لتشفير النصوص وتوليد التسلسلات الشرطية. | CLIP | نعم | - |
| `caption` | النص الذي يصف الموسيقى المطلوب توليدها. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `lyrics` | نص كلمات الأغاني المستخدم لتوليد الموسيقى. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `seed` | بذرة عشوائية قابلة لإعادة الإنتاج لعملية التوليد. القيمة الافتراضية: 0. | INT | نعم | 0 إلى 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | الحد الأقصى لمدة الموسيقى المُولَّدة (بالثواني)، قد ينهي النموذج الأغنية مبكرًا. القيمة الافتراضية: 120.0. | FLOAT | نعم | 0.04 إلى أقصى مدة صوتية للنموذج (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، الخطوة 0.04 |
| `cfg_scale` | معامل قياس التوجيه الحر للمصنف. القيمة الافتراضية: ثابت النموذج CFG_SCALE. معلمة متقدمة. | FLOAT | نعم | 0.0 إلى 100.0، الخطوة 0.1 (مع الاحتفاظ بمنزلتين عشريتين) |
| `top_k` | قيمة أخذ العينات top-k لاختيار الرموز الصوتية (tokens). القيمة الافتراضية: ثابت النموذج CFG_TOP_K. معلمة متقدمة. | INT | نعم | 1 إلى حجم مفردات النموذج (C0_VOCAB_SIZE) |

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `conditioning` | التسلسل الشرطي الصوتي المُولَّد، يُستخدم لتوجيه توليد الموسيقى اللاحق. | CONDITIONING |
| `seconds` | المدة الفعلية المقابلة للتسلسل الشرطي، بالثواني. | FLOAT |
```
