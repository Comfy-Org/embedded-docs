# EmptyImage

## תיאור הפונקציה

צומת EmptyImage משמשת ליצירת תמונות ריקות במידות ובצבעים מוגדרים. היא יכולה ליצור תמונות רקע בצבע אחיד, המשמשות לרוב כנקודות התחלה או תמונות רקע בתהליכי עיבוד תמונה.

## עקרון הפעולה

ממש כמו צייר שמכין קנבס ריק לפני שמתחיל ליצור, צומת EmptyImage מספקת לך "קנבס דיגיטלי". ניתן לציין את גודל הקנבס (רוחב וגובה), לבחור את צבע הבסיס של הקנבס, ואף להכין כמה קנבסים באותם מפרטים בבת אחת. צומת זו דומה לחנות ציוד אמנות חכמה שיכולה ליצור קנבסים סטנדרטיים העונים בדיוק על דרישות הגודל והצבע שלך.

## קלטים

| שם הפרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `width` | קובע את רוחב התמונה שנוצרת (בפיקסלים), וכך את הממד האופקי של הקנבס | INT |
| `height` | קובע את גובה התמונה שנוצרת (בפיקסלים), וכך את הממד האנכי של הקנבס | INT |
| `batch_size` | מספר התמונות ליצירה בבת אחת, המשמש ליצירה קבוצתית של תמונות באותם מפרטים | INT |
| `color` | צבע הרקע של התמונה. ניתן להזין הגדרת צבע הקסדצימלית, שתומר אוטומטית לעשרוני | INT |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | טנזור התמונה הריקה שנוצרה, בפורמט [batch_size, height, width, 3], המכיל שלושה ערוצי צבע RGB | IMAGE |
