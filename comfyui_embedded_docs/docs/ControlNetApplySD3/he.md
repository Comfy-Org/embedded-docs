# הפעלת ControlNet עם VAE

צומת זה מחיל הנחיית ControlNet על קונדישנינג של Stable Diffusion 3. הוא מקבל קלטי קונדישנינג חיוביים ושליליים יחד עם מודל ControlNet ותמונה, ולאחר מכן מחיל את הנחיית הבקרה עם פרמטרים הניתנים להתאמה של חוזק ותזמון כדי להשפיע על תהליך היצירה.

**הערה:** צומת זה סומן כמיושן ועשוי להיות מוסר בגרסאות עתידיות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | הקונדישנינג החיובי שעליו להחיל הנחיית ControlNet | CONDITIONING | כן | - |
| `negative` | הקונדישנינג השלילי שעליו להחיל הנחיית ControlNet | CONDITIONING | כן | - |
| `control_net` | מודל ה-ControlNet שישמש להנחיה | CONTROL_NET | כן | - |
| `vae` | מודל ה-VAE המשמש בתהליך | VAE | כן | - |
| `image` | תמונת הקלט שמודל ControlNet ישתמש בה כהנחיה | IMAGE | כן | - |
| `strength` | עוצמת אפקט ה-ControlNet (ברירת מחדל: 1.0). כאשר מוגדר ל-0.0, הצומת מדלג על הפעלת ControlNet ומחזיר את הקונדישנינג ללא שינוי. | FLOAT | כן | 0.0 - 10.0 |
| `start_percent` | נקודת ההתחלה בתהליך היצירה שבה ControlNet מתחיל לפעול (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 - 1.0 |
| `end_percent` | נקודת הסיום בתהליך היצירה שבה ControlNet מפסיק לפעול (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 1.0 |

**הערה:** כאשר `strength` מוגדר ל-0.0, לא מוחלת הנחיית ControlNet וקונדישנינג הקלט מועבר ללא שינוי לשני הפלטים.

**הערה:** אם אותו קונדישנינג נמצא בשימוש חוזר במקום אחר וכבר מכיל מידע בקרה, ה-ControlNet החדש מקושר אחרי הקודם, כך שניתן להחיל מספר ControlNets ברצף.
