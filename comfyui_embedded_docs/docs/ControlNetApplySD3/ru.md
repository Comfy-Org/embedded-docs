# Применить ControlNet с VAE

Этот узел применяет управление ControlNet к кондиционированию Stable Diffusion 3. Он принимает положительное и отрицательное кондиционирование, а также модель ControlNet и изображение, затем применяет управление с настраиваемыми параметрами силы и времени для влияния на процесс генерации.

**Примечание:** Этот узел помечен как устаревший и может быть удалён в будущих версиях.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительное кондиционирование, к которому применяется управление ControlNet | CONDITIONING | Да | - |
| `отрицательный` | Отрицательное кондиционирование, к которому применяется управление ControlNet | CONDITIONING | Да | - |
| `control_net` | Модель ControlNet, используемая для управления | CONTROL_NET | Да | - |
| `vae` | Модель VAE, используемая в процессе | VAE | Да | - |
| `изображение` | Входное изображение, которое ControlNet будет использовать в качестве управления | IMAGE | Да | - |
| `сила` | Сила эффекта ControlNet (по умолчанию: 1.0). При значении 0.0 узел пропускает применение ControlNet и возвращает кондиционирование без изменений. | FLOAT | Да | 0.0 - 10.0 |
| `процент_начала` | Начальная точка в процессе генерации, с которой ControlNet начинает применяться (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `процент_конца` | Конечная точка в процессе генерации, в которой ControlNet прекращает применяться (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

**Примечание:** Когда `strength` установлено в 0.0, управление ControlNet не применяется, и входное кондиционирование передаётся без изменений в оба выхода.

**Примечание:** Если то же самое кондиционирование используется повторно в другом месте и уже содержит управляющую информацию, новый ControlNet связывается после предыдущего, поэтому несколько ControlNet могут применяться последовательно.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированное положительное кондиционирование с применённым управлением ControlNet | CONDITIONING |
| `отрицательный` | Модифицированное отрицательное кондиционирование с применённым управлением ControlNet | CONDITIONING |
