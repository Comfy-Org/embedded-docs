# Применить ControlNet с VAE

Этот узел применяет управление ControlNet к conditioning модели Stable Diffusion 3. Он принимает положительное и отрицательное conditioning, а также модель ControlNet и изображение, после чего применяет управляющее воздействие с настраиваемой силой и параметрами тайминга, влияющими на процесс генерации.

**Примечание:** Этот узел помечен как устаревший и может быть удалён в будущих версиях.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное conditioning, к которому применяется управление ControlNet | CONDITIONING | Да | - |
| `negative` | Отрицательное conditioning, к которому применяется управление ControlNet | CONDITIONING | Да | - |
| `control_net` | Модель ControlNet, используемая для управления | CONTROL_NET | Да | - |
| `vae` | Модель VAE, используемая в процессе | VAE | Да | - |
| `image` | Входное изображение, которое ControlNet использует в качестве ориентира | IMAGE | Да | - |
| `strength` | Сила эффекта ControlNet (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |
| `start_percent` | Начальная точка процесса генерации, с которой ControlNet начинает применяться (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `end_percent` | Конечная точка процесса генерации, где ControlNet прекращает применяться (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

**Примечание:** Если `strength` установлено в 0, узел возвращает положительное и отрицательное conditioning без изменений, не применяя ControlNet.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное conditioning с применённым управлением ControlNet | CONDITIONING |
| `negative` | Модифицированное отрицательное conditioning с применённым управлением ControlNet | CONDITIONING |
