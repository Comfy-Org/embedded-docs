# اعمال ControlNet با VAE

این گره راهنمایی ControlNet را بر روی شرطی‌سازی Stable Diffusion 3 اعمال می‌کند. این گره ورودی‌های شرطی‌سازی مثبت و منفی را به همراه مدل ControlNet و تصویر دریافت می‌کند، سپس راهنمایی کنترل را با قدرت و زمان‌بندی قابل تنظیم اعمال می‌کند تا فرآیند تولید را تحت تأثیر قرار دهد.

**توجه:** این گره به‌عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است و ممکن است در نسخه‌های آینده حذف شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبتی که راهنمایی ControlNet روی آن اعمال می‌شود | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی که راهنمایی ControlNet روی آن اعمال می‌شود | CONDITIONING | بله | - |
| `control_net` | مدل ControlNet مورد استفاده برای راهنمایی | CONTROL_NET | بله | - |
| `vae` | مدل VAE استفاده‌شده در فرآیند | VAE | بله | - |
| `image` | تصویر ورودی که ControlNet به‌عنوان راهنما از آن استفاده خواهد کرد | IMAGE | بله | - |
| `strength` | قدرت اثر ControlNet (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |
| `start_percent` | نقطه شروع در فرآیند تولید که ControlNet در آن اعمال می‌شود (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `end_percent` | نقطه پایان در فرآیند تولید که ControlNet در آن دیگر اعمال نمی‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |

**توجه:** وقتی `strength` برابر 0 باشد، گره شرطی‌سازی مثبت و منفی را بدون تغییر و بدون اعمال ControlNet برمی‌گرداند.
