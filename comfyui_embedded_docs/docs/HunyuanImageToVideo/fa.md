# HunyuanImageToVideo

گره HunyuanImageToVideo با استفاده از مدل ویدیویی Hunyuan، تصاویر را به نمایش‌های نهفته ویدیویی تبدیل می‌کند. این گره ورودی‌های شرطی و تصاویر شروع اختیاری را دریافت کرده و نمایش‌های نهفته ویدیویی تولید می‌کند که می‌توانند توسط مدل‌های تولید ویدیو پردازش بیشتری شوند. این گره از انواع مختلف راهنمایی برای کنترل نحوه تأثیرگذاری تصویر شروع بر فرآیند تولید ویدیو پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | ورودی شرطی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر به فضای نهفته | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 848، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیوی خروجی (پیش‌فرض: 53، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدیوهایی که به صورت هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `نوع راهنما` | روش ادغام تصویر شروع در تولید ویدیو (پیش‌فرض: "v1 (concat)"). گزینه پیشرفته | COMBO | بله | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `تصویر شروع` | تصویر شروع اختیاری (یا دنباله تصویر) برای مقداردهی اولیه تولید ویدیو. تنها `length` فریم اول و 3 کانال رنگی اول استفاده می‌شود | IMAGE | خیر | - |

**توجه:** وقتی `start_image` ارائه می‌شود، این گره از روش‌های راهنمایی متفاوتی بر اساس `guidance_type` انتخاب‌شده استفاده می‌کند:

- "v1 (concat)": نمایش نهفته تصویر را با نمایش نهفته ویدیو الحاق (concat) کرده و یک ماسک برای ترکیب تصویر در ویدیو اعمال می‌کند
- "v2 (replace)": فریم‌های اولیه ویدیو را با نمایش نهفته تصویر جایگزین کرده و یک ماسک نویز اعمال می‌کند
- "custom": از تصویر به عنوان نمایش نهفته مرجع برای راهنمایی استفاده می‌کند

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی مثبت اصلاح‌شده با راهنمایی تصویر که هنگام ارائه `start_image` اعمال می‌شود | CONDITIONING |
| `latent` | نمایش نهفته ویدیویی آماده برای پردازش بیشتر توسط مدل‌های تولید ویدیو | LATENT |
