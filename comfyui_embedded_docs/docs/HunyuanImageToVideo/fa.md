# HunyuanImageToVideo

گره HunyuanImageToVideo تصاویر را با استفاده از مدل ویدئوی Hunyuan به بازنمایی‌های latent ویدئو تبدیل می‌کند. این گره ورودی‌های conditioning و تصاویر شروع اختیاری را دریافت می‌کند تا latentهای ویدئویی تولید کند که می‌توانند توسط مدل‌های تولید ویدئو بیشتر پردازش شوند. این گره از انواع مختلف راهنمایی پشتیبانی می‌کند تا کنترل شود تصویر شروع چگونه بر فرایند تولید ویدئو تأثیر می‌گذارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی conditioning مثبت برای راهنمایی تولید ویدئو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر در فضای latent | VAE | بله | - |
| `width` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 848، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدئوی خروجی (پیش‌فرض: 53، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدئوهایی که هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `guidance_type` | روش واردکردن تصویر شروع در تولید ویدئو (پیش‌فرض: "v1 (concat)"). گزینه پیشرفته | COMBO | بله | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `start_image` | تصویر شروع اختیاری (یا دنباله تصویر) برای مقداردهی اولیه تولید ویدئو. فقط اولین `length` فریم و اولین ۳ کانال رنگی استفاده می‌شوند | IMAGE | خیر | - |

**توجه:** هنگامی که `start_image` ارائه می‌شود، گره بر اساس `guidance_type` انتخاب‌شده از روش‌های راهنمایی مختلفی استفاده می‌کند:

- "v1 (concat)": latent تصویر را با latent ویدئو الحاق می‌کند و ماسکی اعمال می‌کند تا تصویر را در ویدئو ترکیب کند
- "v2 (replace)": فریم‌های اولیه ویدئو را با latent تصویر جایگزین می‌کند و یک ماسک نویز اعمال می‌کند
- "custom": از تصویر به‌عنوان latent مرجع برای راهنمایی استفاده می‌کند

اگر `start_image` ارائه نشود، هیچ conditioning راهنمایی اضافه نمی‌شود و latent به‌صورت یک بلوک ساده از صفرها بازگردانده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | conditioning مثبت اصلاح‌شده با راهنمایی تصویر که هنگام ارائه `start_image` اعمال می‌شود | CONDITIONING |
| `latent` | بازنمایی latent ویدئو آماده برای پردازش بیشتر توسط مدل‌های تولید ویدئو | LATENT |
