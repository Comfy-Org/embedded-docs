# HunyuanImageToVideo

گره HunyuanImageToVideo با استفاده از مدل ویدیویی Hunyuan، تصاویر را به نمایش‌های نهفته ویدیویی تبدیل می‌کند. این گره ورودی‌های شرطی‌سازی و تصویر شروع اختیاری را دریافت می‌کند تا latentهای ویدیویی تولید کند که می‌توانند توسط مدل‌های تولید ویدیو پردازش شوند. گره از انواع راهنمایی (guidance) مختلف برای کنترل نحوه تأثیر تصویر شروع بر فرایند تولید ویدیو پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر به فضای نهفته | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 848، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی خروجی (پیش‌فرض: 53، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `guidance_type` | روش ترکیب تصویر شروع در تولید ویدیو (پیش‌فرض: "v1 (concat)") | COMBO | بله | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `start_image` | تصویر شروع اختیاری برای مقداردهی اولیه تولید ویدیو | IMAGE | خیر | - |

**توجه:** وقتی `start_image` ارائه می‌شود، گره بسته به `guidance_type` انتخاب‌شده از روش‌های راهنمایی متفاوتی استفاده می‌کند:

- "v1 (concat)": latent تصویر را با latent ویدیویی ادغام می‌کند و یک ماسک برای ترکیب تصویر در ویدیو اعمال می‌کند
- "v2 (replace)": فریم‌های اولیه ویدیو را با latent تصویر جایگزین می‌کند و یک ماسک نویز اعمال می‌کند
- "custom": از تصویر به‌عنوان latent مرجع برای راهنمایی استفاده می‌کند

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده با اعمال راهنمایی تصویر هنگام ارائه `start_image` | CONDITIONING |
| `latent` | نمایش نهفته ویدیو آماده برای پردازش بیشتر توسط مدل‌های تولید ویدیو | LATENT |
