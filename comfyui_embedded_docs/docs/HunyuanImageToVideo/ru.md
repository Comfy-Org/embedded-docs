# HunyuanImageToVideo

Узел HunyuanImageToVideo преобразует изображения в латентные представления видео с помощью видеомодели Hunyuan. Он принимает входы кондиционирования и необязательные начальные изображения для генерации видеолатентов, которые могут быть далее обработаны моделями генерации видео. Узел поддерживает различные типы управления, определяющие, как начальное изображение влияет на процесс генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Вход положительного кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 848, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в выходном видео (по умолчанию: 53, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `тип руководства` | Метод включения начального изображения в генерацию видео (по умолчанию: "v1 (concat)"). Расширенная опция | COMBO | Да | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `начальное изображение` | Необязательное начальное изображение (или последовательность изображений) для инициализации генерации видео. Используются только первые `length` кадров и первые 3 цветовых канала | IMAGE | Нет | - |

**Примечание:** Когда указан `start_image`, узел использует разные методы управления в зависимости от выбранного `guidance_type`:

- "v1 (concat)": Конкатенирует латент изображения с латентом видео и применяет маску для смешивания изображения с видео
- "v2 (replace)": Заменяет начальные кадры видео латентом изображения и применяет маску шума
- "custom": Использует изображение как эталонный латент для управления

Если `start_image` не указан, управляющее кондиционирование не добавляется, и латент возвращается как обычный блок нулей.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование с управлением по изображению, применяемым при наличии `start_image` | CONDITIONING |
| `latent` | Латентное представление видео, готовое для дальнейшей обработки моделями генерации видео | LATENT |
