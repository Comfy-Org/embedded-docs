# HunyuanImageToVideo

Узел HunyuanImageToVideo преобразует изображения в латентные представления видео с помощью видеомодели Hunyuan. Он принимает входные данные кондиционирования и необязательные начальные изображения для генерации видеолатентов, которые могут быть дополнительно обработаны моделями генерации видео. Узел поддерживает различные типы управления для контроля того, как начальное изображение влияет на процесс генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 848, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в выходном видео (по умолчанию: 53, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `guidance_type` | Метод включения начального изображения в генерацию видео (по умолчанию: "v1 (concat)") | COMBO | Да | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `start_image` | Необязательное начальное изображение для инициализации генерации видео | IMAGE | Нет | - |

**Примечание:** Когда предоставлено `start_image`, узел использует различные методы управления в зависимости от выбранного `guidance_type`:

- "v1 (concat)": объединяет латентное представление изображения с латентным представлением видео и применяет маску для смешивания изображения с видео.
- "v2 (replace)": заменяет начальные кадры видео латентным представлением изображения и применяет маску шума.
- "custom": использует изображение в качестве эталонного латентного представления для управления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное позитивное кондиционирование с применением управления изображением, если предоставлено `start_image` | CONDITIONING |
| `latent` | Латентное представление видео, готовое к дальнейшей обработке моделями генерации видео | LATENT |
