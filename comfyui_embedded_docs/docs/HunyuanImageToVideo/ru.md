# HunyuanImageToVideo

Узел HunyuanImageToVideo преобразует изображения в латентные представления видео с помощью модели Hunyuan video. Он принимает входы кондиционирования и необязательные начальные изображения для генерации видео-латентов, которые могут быть дополнительно обработаны моделями генерации видео. Узел поддерживает различные типы управления (guidance) для контроля того, как начальное изображение влияет на процесс генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 848, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в выходном видео (по умолчанию: 53, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `тип руководства` | Метод включения начального изображения в генерацию видео (по умолчанию: "v1 (concat)"). Расширенный параметр | COMBO | Да | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `начальное изображение` | Необязательное начальное изображение (или последовательность изображений) для инициализации генерации видео. Используются только первые `length` кадров и первые 3 цветовых канала | IMAGE | Нет | - |

**Примечание:** Если `start_image` предоставлен, узел использует различные методы управления в зависимости от выбранного `guidance_type`:

- "v1 (concat)": Конкатенирует латентное представление изображения с латентным представлением видео и применяет маску для смешивания изображения с видео
- "v2 (replace)": Заменяет начальные кадры видео латентным представлением изображения и применяет шумовую маску
- "custom": Использует изображение в качестве эталонного латентного представления для управления

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированное положительное кондиционирование с применением управления изображением, когда задан `start_image` | CONDITIONING |
| `скрытое пространство` | Латентное представление видео, готовое к дальнейшей обработке моделями генерации видео | LATENT |
