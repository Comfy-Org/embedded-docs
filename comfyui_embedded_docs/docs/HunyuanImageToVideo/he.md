# HunyuanImageToVideo

הצומת HunyuanImageToVideo ממיר תמונות לייצוגי לטנט של וידאו באמצעות מודל הווידאו Hunyuan. הוא מקבל קלטי התניה ותמונות התחלה אופציונליות כדי ליצור לטנטים של וידאו שיכולים לעבור עיבוד נוסף על ידי מודלים ליצירת וידאו. הצומת תומך בסוגי הנחיה שונים לשליטה באופן שבו תמונת ההתחלה משפיעה על תהליך יצירת הווידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט התניה חיובי להנחיית יצירת הווידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות למרחב לטנטי | VAE | כן | - |
| `width` | רוחב הווידאו בפלט בפיקסלים (ברירת מחדל: 848, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה הווידאו בפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו בפלט (ברירת מחדל: 53, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הסרטונים ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `guidance_type` | שיטה לשילוב תמונת ההתחלה ביצירת הווידאו (ברירת מחדל: "v1 (concat)"). אפשרות מתקדמת | COMBO | כן | "v1 (concat)"<br>"v2 (replace)"<br>"custom" |
| `start_image` | תמונת התחלה אופציונלית (או רצף תמונות) לאתחול יצירת הווידאו. נעשה שימוש רק בפריימים הראשונים במספר `length` ובשלושת ערוצי הצבע הראשונים | IMAGE | לא | - |

**הערה:** כאשר מסופק `start_image`, הצומת משתמש בשיטות הנחיה שונות בהתאם ל-`guidance_type` שנבחר:

- "v1 (concat)": משרשר את לטנט התמונה עם לטנט הווידאו ומחיל מסכה כדי למזג את התמונה לתוך הווידאו
- "v2 (replace)": מחליף פריימים ראשוניים בווידאו בלטנט התמונה ומחיל מסכת רעש
- "custom": משתמש בתמונה כלטנט ייחוס להנחיה

אם `start_image` לא מסופק, לא מתווספת התניית הנחיה והלטנט מוחזר כבלוק אפסים פשוט.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | התניה חיובית ששונתה, עם הנחיית תמונה מיושמת כאשר `start_image` מסופק | CONDITIONING |
| `latent` | ייצוג לטנט של וידאו המוכן לעיבוד נוסף על ידי מודלים ליצירת וידאו | LATENT |
