# OptimalStepsScheduler

گره OptimalStepsScheduler یک زمان‌بندی نویز (دنباله‌ای از مقادیر سیگما) برای استفاده در نمونه‌برداری انتشار ایجاد می‌کند. این گره سطوح نویز پایه را از نوع مدل انتخاب‌شده برمی‌گزیند، زمان‌بندی را هنگام اعمال جزئی نویززدایی تنظیم می‌کند، و سطوح را درون‌یابی می‌کند تا سیگماهای بازگردانده‌شده با تعداد گام درخواستی مطابقت داشته باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model_type` | نوع مدل انتشار برای محاسبه سطح نویز. هر گزینه از جدول از پیش تعریف‌شده سطوح نویز خود استفاده می‌کند. | COMBO | بله | "FLUX"<br>"Wan"<br>"Chroma" |
| `گام‌ها` | تعداد کل گام‌های نمونه‌برداری برای محاسبه (پیش‌فرض: 20). | INT | بله | 3 تا 1000 |
| `کاهش نویز` | شدت نویززدایی را کنترل می‌کند، که تعداد مؤثر گام‌ها را تنظیم می‌کند (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (step: 0.01) |

**توجه:** جدول سطح نویز پایه برای `model_type` انتخاب‌شده هر زمان که طول آن با `steps + 1` برابر نباشد، با درون‌یابی لگاریتمی-خطی بازنمونه‌برداری می‌شود؛ بنابراین خروجی همیشه با تعداد گام درخواستی مطابقت دارد.

**توجه:** وقتی `denoise` کمتر از 1.0 باشد، گره از `round(steps * denoise)` به عنوان تعداد کل گام‌های مؤثر استفاده می‌کند و فقط دنبالهٔ متناظر انتهای زمان‌بندی را نگه می‌دارد. اگر `denoise` برابر 0.0 یا کمتر باشد، گره یک تنسور خالی برمی‌گرداند.
