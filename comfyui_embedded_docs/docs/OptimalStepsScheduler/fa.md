# OptimalStepsScheduler

گره OptimalStepsScheduler یک زمان‌بندی نویز (دنباله‌ای از مقادیر سیگما) برای استفاده در نمونه‌برداری دیفیوژن ایجاد می‌کند. این گره سطوح نویز پایه را از نوع مدل انتخاب‌شده برمی‌گزیند، زمان‌بندی را هنگام اعمال جزئی نویززدایی تنظیم می‌کند، و سطوح را درونیابی می‌کند تا سیگماهای بازگشتی با تعداد گام درخواستی مطابقت داشته باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model_type` | نوع مدل دیفیوژن مورد استفاده برای محاسبه سطح نویز. | COMBO | بله | "FLUX"<br>"Wan"<br>"Chroma" |
| `گام‌ها` | تعداد کل گام‌های نمونه‌برداری برای محاسبه (پیش‌فرض: ۲۰). | INT | بله | ۳ تا ۱۰۰۰ |
| `کاهش نویز` | قدرت نویززدایی را کنترل می‌کند، که تعداد مؤثر گام‌ها را تنظیم می‌کند (پیش‌فرض: ۱.۰). | FLOAT | بله | ۰.۰ تا ۱.۰ (گام: ۰.۰۱) |

**نکته:** وقتی `denoise` کمتر از ۱.۰ باشد، گره از `round(steps * denoise)` به عنوان تعداد کل گام‌های مؤثر استفاده می‌کند. اگر `denoise` برابر ۰.۰ باشد، گره یک تنسور خالی برمی‌گرداند.
