# OptimalStepsScheduler

Узел OptimalStepsScheduler создаёт расписание шума (последовательность значений sigma) для использования во время диффузионного сэмплирования. Он выбирает базовые уровни шума из выбранного типа модели, корректирует расписание, когда шумоподавление применяется лишь частично, и интерполирует уровни так, чтобы возвращаемые `sigmas` соответствовали запрошенному количеству шагов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model_type` | Тип диффузионной модели, используемой для расчёта уровней шума. Каждый вариант использует собственную предопределённую таблицу уровней шума. | COMBO | Да | "FLUX"<br>"Wan"<br>"Chroma" |
| `шаги` | Общее количество шагов сэмплирования для расчёта (по умолчанию: 20). | INT | Да | от 3 до 1000 |
| `шумоподавление` | Управляет силой шумоподавления, которая корректирует эффективное количество шагов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

**Примечание:** Таблица базовых уровней шума для выбранного `model_type` пересэмплируется с помощью логарифмически-линейной интерполяции всякий раз, когда её длина не равна `steps + 1`, поэтому выходные данные всегда соответствуют запрошенному количеству шагов.

**Примечание:** Когда `denoise` меньше 1.0, узел использует `round(steps * denoise)` в качестве общего количества эффективных шагов и сохраняет только соответствующую хвостовую часть расписания. Если `denoise` равен 0.0 или меньше, узел возвращает пустой тензор.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Последовательность значений sigma, представляющая расписание шума для диффузионного сэмплирования. Последнее значение в последовательности всегда устанавливается в 0. | SIGMAS |
