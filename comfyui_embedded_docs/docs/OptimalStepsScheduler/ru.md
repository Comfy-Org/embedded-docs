# OptimalStepsScheduler

Узел OptimalStepsScheduler создаёт расписание шума (последовательность значений сигмы) для использования во время диффузионного сэмплирования. Он выбирает базовые уровни шума в соответствии с выбранным типом модели, корректирует расписание при частичном применении денойзинга и интерполирует уровни так, чтобы возвращаемые сигмы соответствовали запрошенному количеству шагов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model_type` | Тип диффузионной модели, используемый для расчёта уровня шума. | COMBO | Да | "FLUX"<br>"Wan"<br>"Chroma" |
| `шаги` | Общее количество шагов сэмплирования для расчёта (по умолчанию: 20). | INT | Да | от 3 до 1000 |
| `шумоподавление` | Управляет степенью денойзинга, которая корректирует эффективное количество шагов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

**Примечание:** Когда `denoise` меньше 1.0, узел использует `round(steps * denoise)` в качестве общего количества эффективных шагов. Если `denoise` равно 0.0, узел возвращает пустой тензор.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Последовательность значений сигмы, представляющая расписание шума для диффузионного сэмплирования. | SIGMAS |
