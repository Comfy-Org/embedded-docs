# OptimalStepsScheduler

Узел `OptimalStepsScheduler` вычисляет сигмы графика шума для диффузионных моделей на основе выбранного типа модели и конфигурации шагов. Он корректирует общее количество шагов в соответствии с параметром `denoise` и интерполирует уровни шума для соответствия запрошенному количеству шагов. Узел возвращает последовательность значений сигмы, которые определяют уровни шума, используемые в процессе диффузионной выборки.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `model_type` | Тип диффузионной модели, используемой для расчета уровня шума | COMBO | Да | "FLUX"<br>"Wan"<br>"Chroma" |
| `steps` | Общее количество шагов выборки для расчета (по умолчанию: 20) | INT | Да | 3-1000 |
| `denoise` | Управляет силой шумоподавления, которая корректирует эффективное количество шагов (по умолчанию: 1.0) | FLOAT | Да | 0.0-1.0 |

**Примечание:** Когда `denoise` установлен менее 1.0, узел вычисляет эффективное количество шагов как `steps * denoise`. Если `denoise` установлен на 0.0, узел возвращает пустой тензор.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Последовательность значений сигмы, представляющая график шума для диффузионной выборки | SIGMAS |
