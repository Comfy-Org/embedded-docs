# Wan Reference to Video

הצומת Wan Reference to Video משתמש במראה החזותי ובקול מסרטון ייחוס אחד או יותר, יחד עם פרומפט טקסטואלי, כדי ליצור וידאו חדש. הוא שומר על עקביות עם הדמויות מחומר הייחוס תוך יצירת תוכן חדש בהתאם לתיאור שלך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל הספציפי של ה-AI שיש להשתמש בו ליצירת הווידאו. | COMBO | כן | `"wan2.6-r2v"` |
| `prompt` | תיאור של האלמנטים והמאפיינים החזותיים עבור הווידאו החדש. תומך באנגלית ובסינית. השתמש במזהים כגון `character1` ו-`character2` כדי להתייחס לדמויות מסרטוני הייחוס. | STRING | כן | - |
| `negative_prompt` | תיאור של אלמנטים או מאפיינים שיש להימנע מהם בווידאו שנוצר. | STRING | לא | - |
| `reference_videos` | רשימה של קלטי וידאו המשמשים כייחוס למראה הדמויות ולקול. עליך לספק לפחות סרטון אחד. ניתן להקצות לכל סרטון שם כגון `character1`, `character2` או `character3`. | AUTOGROW | כן | - |
| `size` | הרזולוציה ויחס הממדים של וידאו הפלט. | COMBO | כן | `"720p: 1:1 (960x960)"`<br>`"720p: 16:9 (1280x720)"`<br>`"720p: 9:16 (720x1280)"`<br>`"720p: 4:3 (1088x832)"`<br>`"720p: 3:4 (832x1088)"`<br>`"1080p: 1:1 (1440x1440)"`<br>`"1080p: 16:9 (1920x1080)"`<br>`"1080p: 9:16 (1080x1920)"`<br>`"1080p: 4:3 (1632x1248)"`<br>`"1080p: 3:4 (1248x1632)"` |
| `duration` | אורך הווידאו שנוצר בשניות (ברירת מחדל: 5). | INT | כן | 5 to 10 |
| `seed` | ערך seed אקראי לתוצאות ניתנות לשחזור. ערך 0 ייצור seed אקראי. | INT | לא | 0 to 2147483647 |
| `shot_type` | מציין אם הווידאו שנוצר הוא צילום רציף יחיד או מכיל מספר צילומים עם חיתוכים. | COMBO | כן | `"single"`<br>`"multi"` |
| `watermark` | כאשר מופעל, מתווסף סימן מים שנוצר על ידי AI לוידאו הסופי (ברירת מחדל: False). | BOOLEAN | לא | - |

**אילוצים:**

* כל סרטון המסופק ב-`reference_videos` חייב להיות באורך שבין 2 ל-30 שניות.
* הפרמטר `duration` מוגבל לערכים של 5 או 10 שניות.
