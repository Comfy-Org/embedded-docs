# عزل الصوت من ElevenLabs

تقوم عقدة عزل الصوت من ElevenLabs بإزالة الضوضاء الخلفية من ملف صوتي، وعزل الأصوات أو الكلام. ترسل العقدة الصوت إلى واجهة برمجة تطبيقات ElevenLabs للمعالجة وتعيد الصوت المنقّى.
