# گسترش سیگماهای میانی

گره ExtendIntermediateSigmas یک دنباله موجود از مقادیر سیگما را می‌گیرد و مقادیر سیگمای میانی بیشتری را بین آن‌ها درج می‌کند. این گره به شما امکان می‌دهد مشخص کنید چند گام اضافی افزوده شود، روش فاصله‌گذاری برای درون‌یابی، و مرزهای اختیاری سیگمای شروع و پایان برای کنترل محل انجام این گسترش در دنباله سیگما.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | اجباری | بازه |
| --- | --- | --- | --- | --- |
| `sigmas` | دنباله سیگمای ورودی برای گسترش با مقادیر میانی | SIGMAS | بله | - |
| `steps` | تعداد مقادیر سیگمای میانی درج‌شده بین هر جفت سیگمای موجود را کنترل می‌کند. بازه بین دو سیگما به `steps` بخش تقسیم می‌شود و برای هر جفت `steps - 1` مقدار جدید تولید می‌کند (پیش‌فرض: 2، که برای هر جفت یک مقدار درج می‌کند) | INT | بله | 1 تا 100 |
| `start_at_sigma` | مرز بالایی سیگما برای گسترش. فقط بازه‌های سیگمایی که سیگمای شروع آن‌ها کوچک‌تر یا مساوی این مقدار است گسترش می‌یابند. وقتی روی -1.0 تنظیم شود، به‌عنوان بی‌نهایت در نظر گرفته می‌شود، یعنی هیچ حد بالایی اعمال نمی‌شود. پیش‌فرض: -1.0 | FLOAT | بله | -1.0 تا 20000.0 |
| `end_at_sigma` | مرز پایینی سیگما برای گسترش. فقط بازه‌های سیگمایی که سیگمای شروع آن‌ها بزرگ‌تر یا مساوی این مقدار است گسترش می‌یابند. پیش‌فرض: 12.0 | FLOAT | بله | 0.0 تا 20000.0 |
| `spacing` | روش درون‌یابی برای فاصله‌گذاری مقادیر سیگمای میانی (پیش‌فرض: "linear") | COMBO | بله | `"linear"`<br>`"cosine"`<br>`"sine"` |

**توجه:** گره فقط برای بازه‌های سیگمایی مقادیر میانی درج می‌کند که سیگمای شروع آن‌ها کوچک‌تر یا مساوی `start_at_sigma` و بزرگ‌تر یا مساوی `end_at_sigma` باشد. وقتی `start_at_sigma` روی -1.0 تنظیم شود، به‌عنوان بی‌نهایت در نظر گرفته می‌شود، بنابراین فقط مرز پایینی `end_at_sigma` اعمال می‌شود.
