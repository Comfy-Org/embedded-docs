# ExtendIntermediateSigmas

Узел ExtendIntermediateSigmas принимает существующую последовательность значений сигмы и вставляет между ними дополнительные промежуточные значения сигмы. Он позволяет указать, сколько дополнительных шагов добавить, метод интерполяции для распределения значений, а также необязательные границы начальной и конечной сигмы, чтобы контролировать, где происходит расширение в последовательности сигмы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Входная последовательность сигмы, которую необходимо расширить промежуточными значениями | SIGMAS | Да | - |
| `шаги` | Управляет количеством промежуточных значений сигмы, вставляемых между каждой парой существующих сигм. Интервал между двумя сигмами делится на `steps` частей, что даёт `steps - 1` новых значений для каждой пары (по умолчанию: 2, что вставляет одно значение на пару) | INT | Да | от 1 до 100 |
| `начать_с_sigma` | Верхняя граница сигмы для расширения — расширять только сигмы, меньшие этого значения (по умолчанию: -1.0, что означает бесконечность) | FLOAT | Да | от -1.0 до 20000.0 |
| `закончить_на_sigma` | Нижняя граница сигмы для расширения — расширять только сигмы, большие этого значения (по умолчанию: 12.0) | FLOAT | Да | от 0.0 до 20000.0 |
| `интервал` | Метод интерполяции для распределения промежуточных значений сигмы (по умолчанию: "linear") | COMBO | Да | `"linear"`<br>`"cosine"`<br>`"sine"` |

**Примечание:** Узел вставляет промежуточные сигмы только между существующими парами сигм, где текущая сигма меньше или равна `start_at_sigma` и больше или равна `end_at_sigma`. Если `start_at_sigma` установлено в -1.0, это значение рассматривается как бесконечность, то есть применяется только нижняя граница `end_at_sigma`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Расширенная последовательность сигмы с вставленными дополнительными промежуточными значениями | SIGMAS |
