# ExtendIntermediateSigmas

Узел ExtendIntermediateSigmas принимает существующую последовательность значений sigma и вставляет дополнительные промежуточные значения sigma между ними. Он позволяет указать, сколько дополнительных шагов добавить, метод интерполяции для распределения и необязательные начальную и конечную границы sigma, чтобы контролировать, где происходит расширение внутри последовательности sigma.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Входная последовательность sigma, которую нужно расширить промежуточными значениями | SIGMAS | Да | - |
| `шаги` | Управляет количеством промежуточных значений sigma, вставляемых между каждой парой существующих sigma. Интервал между двумя sigma делится на `steps` частей, создавая `steps - 1` новых значений на пару (по умолчанию: 2, что вставляет одно значение на пару) | INT | Да | 1–100 |
| `начать_с_sigma` | Верхняя граница sigma для расширения. Расширяются только интервалы sigma, начальное значение sigma которых меньше или равно этому значению. Если установлено -1.0, оно рассматривается как бесконечность, то есть верхний предел не применяется. По умолчанию: -1.0 | FLOAT | Да | -1.0–20000.0 |
| `закончить_на_sigma` | Нижняя граница sigma для расширения. Расширяются только интервалы sigma, начальное значение sigma которых больше или равно этому значению. По умолчанию: 12.0 | FLOAT | Да | 0.0–20000.0 |
| `интервал` | Метод интерполяции для распределения промежуточных значений sigma (по умолчанию: "linear") | COMBO | Да | `"linear"`<br>`"cosine"`<br>`"sine"` |

**Примечание:** Узел вставляет промежуточные sigma только для интервалов sigma, где начальное значение sigma меньше или равно `start_at_sigma` и больше или равно `end_at_sigma`. Когда `start_at_sigma` установлено в -1.0, оно рассматривается как бесконечность, поэтому применяется только нижняя граница `end_at_sigma`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Расширенная последовательность sigma с добавленными промежуточными значениями | SIGMAS |
