# ExtendIntermediateSigmas

Узел ExtendIntermediateSigmas принимает существующую последовательность значений сигмы и вставляет между ними дополнительные промежуточные значения сигмы. Он позволяет указать, сколько дополнительных шагов добавить, метод интерполяции для распределения, а также необязательные границы начальной и конечной сигмы для управления тем, где в последовательности сигмы происходит расширение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Входная последовательность сигм для расширения промежуточными значениями | SIGMAS | Да | - |
| `steps` | Количество промежуточных шагов для вставки между существующими сигмами; при N шагах между каждой подходящей парой вставляется N-1 промежуточных значений сигмы (по умолчанию: 2) | INT | Да | 1 to 100 |
| `start_at_sigma` | Верхняя граница сигмы для расширения — расширять только сигмы ниже этого значения (по умолчанию: -1.0, что означает бесконечность) | FLOAT | Да | -1.0 to 20000.0 |
| `end_at_sigma` | Нижняя граница сигмы для расширения — расширять только сигмы выше этого значения (по умолчанию: 12.0) | FLOAT | Да | 0.0 to 20000.0 |
| `spacing` | Метод интерполяции для распределения промежуточных значений сигмы: `"linear"` распределяет их равномерно, `"cosine"` и `"sine"` применяют криволинейное распределение (по умолчанию: `"linear"`) | COMBO | Да | `"linear"`<br>`"cosine"`<br>`"sine"` |

**Примечание:** Узел вставляет промежуточные сигмы только между существующими парами сигм, где текущая сигма меньше или равна `start_at_sigma` и больше или равна `end_at_sigma`. Когда `start_at_sigma` установлено в -1.0, оно рассматривается как бесконечность, то есть применяется только нижняя граница `end_at_sigma`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Расширенная последовательность сигм с добавленными дополнительными промежуточными значениями | SIGMAS |
