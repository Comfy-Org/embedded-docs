# ComfyCloudMageFlowTextToImageNode

این گره با ارسال درخواست به گردش‌کار متن‌به‌تصویر Mage-Flow در Comfy Cloud، تصویری از یک متن ورودی تولید می‌کند. این گره به‌جای عبور سریع‌تر نسخهٔ turbo تقطیرشده، کل فرایند تولید ۳۰ مرحله‌ای را اجرا می‌کند و یک prompt منفی نیز می‌پذیرد تا بتوانید محتوایی را که در تصویر نهایی نمی‌خواهید توصیف کنید. prompt منفی در این حالت ۳۰ مرحله‌ای پشتیبانی می‌شود؛ طبق خلاصهٔ گره، نسخهٔ turbo تقطیرشده نمی‌تواند به خوبی از آن استفاده کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی تصویری که باید تولید شود. | STRING | بله | متن آزاد |
| `negative_prompt` | متن توصیف‌کنندهٔ محتوایی که نباید در تصویر تولیدشده ظاهر شود. این ورودی در فرایند استاندارد ۳۰ مرحله‌ای استفاده می‌شود، اما نسخهٔ turbo تقطیرشده از prompt منفی به خوبی استفاده نمی‌کند. | STRING | خیر | متن آزاد |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویری که از متن ورودی و prompt منفی ارائه‌شده تولید شده است. | IMAGE |
