# Comfy Cloud Mage Flow Текст в изображение [БЕТА]

Этот узел генерирует изображение по текстовому промпту, отправляя запрос в рабочий процесс Mage-Flow для преобразования текста в изображение в Comfy Cloud. Он выполняет полный 30-шаговый проход генерации, а не более быстрый дистиллированный turbo-проход, и принимает негативный промпт, чтобы можно было описать содержимое, которое вы не хотите видеть в итоговом изображении. Негативный промпт поддерживается в этом 30-шаговом режиме; согласно описанию узла, дистиллированный turbo-вариант не может эффективно его использовать.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание изображения для генерации. | STRING | Да | Произвольный текст |
| `negative_prompt` | Текст, описывающий содержимое, которое не должно появляться в сгенерированном изображении. Этот вход используется во время стандартного 30-шагового прохода генерации, но дистиллированный turbo-вариант плохо использует негативные промпты. | STRING | Нет | Произвольный текст |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение, сгенерированное на основе предоставленного текстового промпта и негативного промпта. | IMAGE |
