# ComfyCloudMageFlowTextToImageNode

Этот узел генерирует изображение по текстовому запросу, отправляя запрос в рабочий процесс Mage-Flow для генерации изображений из текста (text-to-image) в Comfy Cloud. Он выполняет полный 30-шаговый цикл генерации, а не более быстрый дистиллированный турбо-проход, и поддерживает негативный промпт, чтобы вы могли описать содержимое, которого не должно быть в итоговом изображении. Негативный промпт используется в этом режиме с 30 шагами; согласно описанию узла, дистиллированный турбо-вариант не может эффективно его использовать.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание изображения, которое нужно сгенерировать. | STRING | Да | Произвольный текст |
| `negative_prompt` | Текст, описывающий содержимое, которого не должно быть в сгенерированном изображении. Этот вход используется во время стандартного 30-шагового цикла генерации, но дистиллированный турбо-вариант неэффективно использует негативные промпты. | STRING | Нет | Произвольный текст |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение, сгенерированное на основе предоставленного текстового запроса и негативного промпта. | IMAGE |
