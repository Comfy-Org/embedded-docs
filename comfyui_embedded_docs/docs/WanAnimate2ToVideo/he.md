# WanAnimate2ToVideo

WanAnimate2ToVideo מניע דמות מתוך תמונת עזר על ידי העברת הבעות פנים, תנועת גוף ומחוות ידיים מסרטון תנוחה נפרד. הוא בונה את נתוני ההתניה ואת ה-latent ההתחלתי שדוגם ליצירת וידאו משתמש בהם כדי ליצור את האנימציה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | ההתניה החיובית ליצירת הווידאו. | CONDITIONING | כן | N/A |
| `negative` | ההתניה השלילית ליצירת הווידאו. | CONDITIONING | כן | N/A |
| `vae` | ה-VAE המשמש לקידוד תמונת העזר ופריימים של הווידאו למרחב ה-latent. | VAE | כן | N/A |
| `width` | רוחב וידאו הפלט בפיקסלים. (ברירת מחדל: 832) | INT | כן | 16 to MAX_RESOLUTION (step 16) |
| `height` | גובה וידאו הפלט בפיקסלים. (ברירת מחדל: 480) | INT | כן | 16 to MAX_RESOLUTION (step 16) |
| `length` | מספר הפריימים ליצירה. (ברירת מחדל: 81) | INT | כן | 1 to MAX_RESOLUTION (step 4) |
| `batch_size` | מספר הווידאו ליצירה בו-זמנית. (ברירת מחדל: 1) | INT | כן | 1 to 4096 |
| `reference_image` | הדמות להנפשה. אם מושמט, נעשה שימוש בתמונה שחורה. | IMAGE | לא | N/A |
| `pose_video` | הווידאו שתנועתו מועברת לדמות העזר. אם יש בו פחות פריימים מ-`length`, הפריים האחרון חוזר על עצמו כדי להשלים את הפריימים החסרים. | IMAGE | לא | N/A |
| `clip_vision_output` | פלט CLIP vision של תמונת העזר. | CLIP_VISION_OUTPUT | לא | N/A |
| `positive_pose` | פרומפט לענף סרטון התנוחה, המתאר את התנועה ולא את הדמות. ברירת המחדל היא `positive`. משמש גם למעברי cond וגם למעברי uncond. | CONDITIONING | לא | N/A |
| `clip_vision_output_pose` | פלט CLIP vision של הפריים הראשון של סרטון התנוחה. ברירת המחדל היא `clip_vision_output`. | CLIP_VISION_OUTPUT | לא | N/A |
| `continue_motion` | רצף תנועה קודם שממשיכים ממנו לצורך עקביות זמנית. רק הפריים האחרון ברצף זה משמש כפריים תנועה ההתחלתי. | IMAGE | לא | N/A |
| `video_frame_offset` | פריימים לדילוג בסרטון התנוחה. יש לחבר לפלט `video_frame_offset` של הצומת הקודם בעת הרחבה. (ברירת מחדל: 0) | INT | כן | 0 to MAX_RESOLUTION |
| `pose_strength` | מכפיל את השפעת סרטון התנוחה על התנועה. 1.0 הוא ההתנהגות שאומנה; מתחת מחליש את ההיצמדות, מעל מגביר. 0.0 משתיק אותה אך לא מסיר אותה לחלוטין. (ברירת מחדל: 1.0) | FLOAT | כן | 0.00 to 10.00 (step 0.01) |
| `pose_start_percent` | אחוז הדגימה שבו השפעת התנוחה מתחילה. מחוץ לחלון ענף התנוחה מדולג לחלוטין, מה גם שמאיץ את השלבים האלה. (ברירת מחדל: 0.0) | FLOAT | כן | 0.00 to 1.00 (step 0.01) |
| `pose_end_percent` | אחוז הדגימה שבו השפעת התנוחה מסתיימת. התנועה נוצרת בעיקר בשלב מוקדם, כך שלמשל 0.7 יכול להרפות פרטים עדינים תוך שמירה על הכוריאוגרפיה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.00 to 1.00 (step 0.01) |
| `reference_image_strength` | מכפיל באיזו עוצמה פריימים שנוצרו מתייחסים לפריים ה-latent של תמונת העזר. מתחת ל-1.0 מרפה את ההיצמדות לזהות/מראה (למשל כדי לאפשר לפרומפט לעצב מחדש), מעל מהדק אותה כנגד סחיפה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.00 to 10.00 (step 0.01) |

**הערות אימות:**

- `pose_start_percent` לא צריך להיות גדול מ-`pose_end_percent`; אחרת הצומת מעלה ValueError.
- אם `pose_video` מסופק, מספר הפריימים שלו צריך להיות גדול מ-`video_frame_offset`; אחרת הצומת מעלה ValueError.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | התניה חיובית לדגימה, עם תמונת העזר, המסכה ונתוני התנוחה האופציונליים מצורפים. | CONDITIONING |
| `negative` | התניה שלילית לדגימה, עם אותה תמונת עזר, מסכה ונתוני תנוחה אופציונליים מצורפים. | CONDITIONING |
| `latent` | latent התחלתי מלא באפסים עבור דוגם הווידאו; יש להסיר את `trim_latent` הפריימים הראשונים לפני הפענוח. | LATENT |
| `trim_latent` | מספר פריימי ה-latent שיש לחתוך לפני הפענוח. | INT |
| `trim_image` | מספר פריימי התמונה החופפים בעת הרחבת וידאו. | INT |
| `video_frame_offset` | פריימים לדילוג בסרטון התנוחה; שווה להזזת הקלט המותאמת בתוספת מספר הפריימים שנוצרו. | INT |
