# WanAnimate2ToVideo

Ниже приведён перевод документации узла WanAnimate2ToVideo на русский язык в соответствии с правилами.

---

WanAnimate2ToVideo анимирует персонажа из референсного изображения, перенося мимику, движения тела и жесты рук из отдельного видео с позой. Узел формирует данные кондиционирования и начальный латент, которые сэмплер генерации видео использует для создания анимации.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Позитивное кондиционирование для генерации видео. | CONDITIONING | Да | N/A |
| `negative` | Негативное кондиционирование для генерации видео. | CONDITIONING | Да | N/A |
| `vae` | VAE, используемый для кодирования референсного изображения и кадров видео в латентное пространство. | VAE | Да | N/A |
| `width` | Ширина выходного видео в пикселях. (по умолчанию: 832) | INT | Да | 16 до MAX_RESOLUTION (шаг 16) |
| `height` | Высота выходного видео в пикселях. (по умолчанию: 480) | INT | Да | 16 до MAX_RESOLUTION (шаг 16) |
| `length` | Количество кадров для генерации. (по умолчанию: 81) | INT | Да | 1 до MAX_RESOLUTION (шаг 4) |
| `batch_size` | Количество видео, генерируемых одновременно. (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `reference_image` | Персонаж для анимации. Если не указано, используется чёрное изображение. | IMAGE | Нет | N/A |
| `pose_video` | Видео, движение из которого переносится на референсного персонажа. Если в нём меньше кадров, чем `length`, последний кадр повторяется для заполнения недостающих кадров. | IMAGE | Нет | N/A |
| `clip_vision_output` | CLIP-видение референсного изображения. | CLIP_VISION_OUTPUT | Нет | N/A |
| `positive_pose` | Промпт для ветви pose-video, описывающий движение, а не персонажа. По умолчанию используется `positive`. Применяется как для условного (cond), так и для безусловного (uncond) проходов. | CONDITIONING | Нет | N/A |
| `clip_vision_output_pose` | CLIP-видение первого кадра видео с позой. По умолчанию используется `clip_vision_output`. | CLIP_VISION_OUTPUT | Нет | N/A |
| `continue_motion` | Предыдущая последовательность движения, которую нужно продолжить для временной согласованности. Используется только последний кадр этой последовательности в качестве начального кадра движения. | IMAGE | Нет | N/A |
| `video_frame_offset` | Смещение по кадрам в видео с позой. При расширении подключите к выходу `video_frame_offset` предыдущего узла. (по умолчанию: 0) | INT | Да | 0 до MAX_RESOLUTION |
| `pose_strength` | Масштабирует влияние видео с позой на движение. 1.0 — поведение, полученное при обучении; ниже — ослабляет следование, выше — усиливает. 0.0 отключает его, но не убирает полностью. (по умолчанию: 1.0) | FLOAT | Да | 0.00 до 10.00 (шаг 0.01) |
| `pose_start_percent` | Процент сэмплирования, начиная с которого начинает действовать влияние позы. За пределами окна ветвь позы полностью пропускается, что также ускоряет эти шаги. (по умолчанию: 0.0) | FLOAT | Да | 0.00 до 1.00 (шаг 0.01) |
| `pose_end_percent` | Процент сэмплирования, на котором заканчивается влияние позы. Движение в основном формируется в начале, поэтому, например, 0.7 может ослабить мелкие детали, сохраняя хореографию. (по умолчанию: 1.0) | FLOAT | Да | 0.00 до 1.00 (шаг 0.01) |
| `reference_image_strength` | Масштабирует силу внимания генерируемых кадров к латентному кадру референсного изображения. Ниже 1.0 ослабляет следование идентичности/внешности (например, чтобы позволить промпту изменить стиль), выше — ужесточает его против дрейфа. (по умолчанию: 1.0) | FLOAT | Да | 0.00 до 10.00 (шаг 0.01) |

**Примечания по валидации:**

- `pose_start_percent` не должен быть больше `pose_end_percent`; в противном случае узел вызывает ValueError.
- Если указан `pose_video`, количество его кадров должно быть больше `video_frame_offset`; в противном случае узел вызывает ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование для сэмплирования с прикреплёнными референсным изображением, маской и опциональными данными позы. | CONDITIONING |
| `negative` | Негативное кондиционирование для сэмплирования с теми же референсным изображением, маской и опциональными данными позы. | CONDITIONING |
| `latent` | Стартовый латент, заполненный нулями, для сэмплера видео; перед декодированием следует удалить первые `trim_latent` кадров. | LATENT |
| `trim_latent` | Количество латентных кадров, которые следует обрезать перед декодированием. | INT |
| `trim_image` | Количество перекрывающихся кадров изображения при расширении видео. | INT |
| `video_frame_offset` | Смещение по кадрам в видео с позой; равно скорректированному входному смещению плюс количество сгенерированных кадров. | INT |
