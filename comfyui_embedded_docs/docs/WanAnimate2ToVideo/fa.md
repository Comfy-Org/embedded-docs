# WanAnimate2ToVideo

```markdown
WanAnimate2ToVideo شخصیت را از یک تصویر مرجع با انتقال حالات چهره، حرکت بدن و اشارات دست از یک ویدئوی ژست جداگانه پویانمایی می‌کند. این گره داده‌های شرطی‌سازی و یک لاتنت آغازین می‌سازد که یک نمونه‌بردار تولید ویدئو برای ایجاد انیمیشن از آن استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `positive` | شرطی‌سازی مثبت برای تولید ویدئو. | CONDITIONING | بله | N/A |
| `negative` | شرطی‌سازی منفی برای تولید ویدئو. | CONDITIONING | بله | N/A |
| `vae` | VAE مورد استفاده برای رمزگذاری تصویر مرجع و فریم‌های ویدئو در فضای لاتنت. | VAE | بله | N/A |
| `width` | عرض ویدئوی خروجی بر حسب پیکسل. (پیش‌فرض: 832) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `height` | ارتفاع ویدئوی خروجی بر حسب پیکسل. (پیش‌فرض: 480) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `length` | تعداد فریم‌هایی که تولید می‌شوند. (پیش‌فرض: 81) | INT | بله | 1 تا MAX_RESOLUTION (گام 4) |
| `batch_size` | تعداد ویدئوهایی که به‌طور همزمان تولید می‌شوند. (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `reference_image` | شخصیتی که قرار است پویانمایی شود. اگر حذف شود، یک تصویر سیاه استفاده می‌شود. | IMAGE | خیر | N/A |
| `pose_video` | ویدئویی که حرکت آن به شخصیت مرجع منتقل می‌شود. اگر تعداد فریم‌های آن کمتر از `length` باشد، آخرین فریم برای پر کردن فریم‌های باقی‌مانده تکرار می‌شود. | IMAGE | خیر | N/A |
| `clip_vision_output` | خروجی بینایی CLIP از تصویر مرجع. | CLIP_VISION_OUTPUT | خیر | N/A |
| `positive_pose` | پرامپت برای شاخه ویدئوی ژست، که حرکت را توصیف می‌کند نه شخصیت را. به‌طور پیش‌فرض برابر با `positive` است. برای هر دو گذر cond و uncond استفاده می‌شود. | CONDITIONING | خیر | N/A |
| `clip_vision_output_pose` | خروجی بینایی CLIP از فریم اول ویدئوی ژست. به‌طور پیش‌فرض برابر با `clip_vision_output` است. | CLIP_VISION_OUTPUT | خیر | N/A |
| `continue_motion` | دنباله حرکت قبلی برای ادامه دادن از آن به‌منظور سازگاری زمانی. فقط آخرین فریم این دنباله به‌عنوان فریم شروع حرکت استفاده می‌شود. | IMAGE | خیر | N/A |
| `video_frame_offset` | فریم‌هایی که باید در ویدئوی ژست به جلو پرش کرد. هنگام گسترش، به خروجی `video_frame_offset` گره قبلی متصل کنید. (پیش‌فرض: 0) | INT | بله | 0 تا MAX_RESOLUTION |
| `pose_strength` | میزان تأثیر ویدئوی ژست بر حرکت را مقیاس می‌کند. 1.0 رفتار آموزش‌دیده است؛ کمتر از آن پایبندی را ضعیف می‌کند و بیشتر از آن آن را تقویت می‌کند. 0.0 آن را بی‌صدا می‌کند اما کاملاً حذف نمی‌کند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.00 تا 10.00 (گام 0.01) |
| `pose_start_percent` | درصد نمونه‌برداری که تأثیر ژست از آن شروع می‌شود. خارج از این بازه، شاخه ژست کاملاً رد می‌شود که آن مراحل را نیز سریع‌تر می‌کند. (پیش‌فرض: 0.0) | FLOAT | بله | 0.00 تا 1.00 (گام 0.01) |
| `pose_end_percent` | درصد نمونه‌برداری که تأثیر ژست در آن پایان می‌یابد. حرکت عمدتاً در اوایل شکل می‌گیرد، بنابراین مثلاً 0.7 می‌تواند جزئیات دقیق را شل کند و در عین حال طراحی حرکات را حفظ کند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.00 تا 1.00 (گام 0.01) |
| `reference_image_strength` | میزان توجه فریم‌های تولیدشده به فریم لاتنت تصویر مرجع را مقیاس می‌کند. کمتر از 1.0 پایبندی به هویت/ظاهر را شل می‌کند (مثلاً برای اینکه پرامپت بتواند سبک را تغییر دهد)، و بیشتر از آن در برابر انحراف آن را سفت می‌کند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.00 تا 10.00 (گام 0.01) |

**یادداشت‌های اعتبارسنجی:**

- `pose_start_percent` نباید بزرگ‌تر از `pose_end_percent` باشد؛ در غیر این صورت گره یک ValueError برمی‌انگیزد.
- اگر `pose_video` ارائه شود، تعداد فریم‌های آن باید بزرگ‌تر از `video_frame_offset` باشد؛ در غیر این صورت گره یک ValueError برمی‌انگیزد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت برای نمونه‌برداری، با تصویر مرجع، ماسک و داده‌های اختیاری ژست پیوست‌شده. | CONDITIONING |
| `negative` | شرطی‌سازی منفی برای نمونه‌برداری، با همان تصویر مرجع، ماسک و داده‌های اختیاری ژست پیوست‌شده. | CONDITIONING |
| `latent` | لاتنت شروع پر از صفر برای نمونه‌بردار ویدئو؛ اولین `trim_latent` فریم باید قبل از رمزگشایی حذف شوند. | LATENT |
| `trim_latent` | تعداد فریم‌های لاتنت که باید قبل از رمزگشایی بریده شوند. | INT |
| `trim_image` | تعداد فریم‌های تصویری همپوشان هنگام گسترش یک ویدئو. | INT |
| `video_frame_offset` | فریم‌هایی که باید در ویدئوی ژست به جلو پرش کرد؛ برابر است با آفست ورودی تنظیم‌شده به‌علاوه تعداد فریم‌های تولیدشده. | INT |
```
