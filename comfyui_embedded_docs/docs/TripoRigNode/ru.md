# Tripo: Риггинг модели

Этот узел берёт существующую 3D-модель Tripo и создаёт её риггированную версию, то есть модель получает скелет, чтобы её можно было анимировать. Вы указываете ID задачи модели для риггинга, выбираете версию рига, тип скелета, стиль именования костей и формат выходного файла, после чего узел отправляет задание в Tripo, ждёт его завершения и возвращает загруженный результат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `идентификатор_задачи_исходной_модели` | ID задачи исходной 3D-модели, которую нужно риггировать. Обычно это ID, созданный предыдущим узлом генерации модели Tripo. | MODEL_TASK_ID | Да | - |
| `model_version` | Версия модели для риггинга. v1.0: только гуманоидные (двухногие) персонажи, 90+ анимационных пресетов. v2.5: негуманоидные существа (четвероногие, шестиногие, восьминогие, птицы, змееподобные, водные). По умолчанию: `v1.0-20240301`. | COMBO | Нет | "v1.0-20240301"<br>"v2.5-20260210" |
| `rig_type` | Тип скелета. При значении "auto" сначала выполняется бесплатная проверка возможности риггинга Tripo и используется рекомендованный тип. По умолчанию: "auto". | COMBO | Нет | "auto"<br>"biped"<br>"quadruped"<br>"hexapod"<br>"octopod"<br>"avian"<br>"serpentine"<br>"aquatic" |
| `spec` | Именование костей: нативное Tripo или совместимое с Mixamo. Tripo не может перенацелить свои анимационные пресеты на риг v1.0, созданный со спецификацией mixamo; для узла Tripo: Retarget rigged model используйте tripo. По умолчанию: "tripo". | COMBO | Нет | "tripo"<br>"mixamo" |
| `out_format` | Формат выходного файла; результат приходит на соответствующий выход. По умолчанию: "glb". | COMBO | Нет | "glb"<br>"fbx" |

**Примечание:** Версия модели v1.0 (`v1.0-20240301`) поддерживает только скелеты biped. Если с этой версией используется `rig_type`, отличный от biped, узел выдаёт ошибку и предлагает вместо этого использовать `v2.5-20260210`.

**Примечание:** Когда `rig_type` имеет значение "auto", Tripo сначала проверяет, можно ли риггировать модель, и выбирает рекомендованный тип скелета. Если Tripo сообщает, что модель нельзя риггировать, узел завершается с ошибкой.

**Примечание:** Узел ожидает, что Tripo вернёт файл GLB или FBX. Если Tripo вернёт файл любого другого типа, узел выдаёт ошибку.

**Примечание:** Заполняется только выход, соответствующий `out_format`: `GLB`, когда `out_format` имеет значение "glb", и `FBX`, когда `out_format` имеет значение "fbx". Другой 3D-выход остаётся пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя сгенерированного файла модели с ригом (ID задачи плюс расширение формата). Оставлено только для обратной совместимости. | STRING |
| `rig task_id` | ID задачи для отслеживания процесса генерации рига. | RIG_TASK_ID |
| `GLB` | Модель с ригом в виде 3D-файла GLB. Заполняется, когда `out_format` имеет значение "glb". | FILE3DGLB |
| `FBX` | Модель с ригом в виде 3D-файла FBX. Заполняется, когда `out_format` имеет значение "fbx". | FILE3DFBX |
