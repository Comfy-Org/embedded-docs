# Tripo: ریگ مدل

این گره یک مدل سه‌بعدی Tripo موجود را می‌گیرد و نسخه‌ای ریگ‌شده از آن می‌سازد؛ یعنی مدل یک اسکلت دریافت می‌کند تا بتوان آن را انیمیت کرد. شما شناسه وظیفه (task ID) مدل موردنظر برای ریگ‌کردن را ارائه می‌دهید، نسخه ریگ، نوع اسکلت، سبک نام‌گذاری استخوان‌ها و قالب فایل خروجی را انتخاب می‌کنید، و گره کار را به Tripo می‌فرستد، تا پایان آن صبر می‌کند و سپس نتیجه دانلودشده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | شناسه وظیفه مدل سه‌بعدی اصلی که باید ریگ شود. این معمولاً شناسه‌ای است که یک گره تولید مدل Tripo پیشین تولید کرده است. | MODEL_TASK_ID | بله | - |
| `model_version` | نسخه مدل ریگ برای استفاده. v1.0: فقط کاراکترهای انسان‌نما (دوپا)، بیش از ۹۰ پیش‌تنظیم انیمیشن. v2.5: موجودات غیرانسان‌نما (چهارپا، شش‌پا، هشت‌پا، پرنده، مارگونه، آبزی). پیش‌فرض: `v1.0-20240301`. | COMBO | خیر | "v1.0-20240301"<br>"v2.5-20260210" |
| `rig_type` | نوع اسکلت. "auto" ابتدا بررسی رایگان ریگ Tripo را اجرا می‌کند و از نوع توصیه‌شده استفاده می‌کند. پیش‌فرض: "auto". | COMBO | خیر | "auto"<br>"biped"<br>"quadruped"<br>"hexapod"<br>"octopod"<br>"avian"<br>"serpentine"<br>"aquatic" |
| `spec` | نام‌گذاری استخوان‌ها: بومی Tripo یا سازگار با Mixamo. Tripo نمی‌تواند پیش‌تنظیم‌های انیمیشن خود را روی یک ریگ v1.0 ساخته‌شده با spec مربوط به mixamo بازهدف‌گیری کند؛ برای Tripo: Retarget rigged model از tripo استفاده کنید. پیش‌فرض: "tripo". | COMBO | خیر | "tripo"<br>"mixamo" |
| `out_format` | قالب فایل خروجی؛ نتیجه روی خروجی متناظر می‌آید. پیش‌فرض: "glb". | COMBO | خیر | "glb"<br>"fbx" |

**توجه:** نسخه مدل v1.0 (`v1.0-20240301`) فقط از اسکلت‌های دوپا پشتیبانی می‌کند. اگر `rig_type` غیر دوپا با این نسخه استفاده شود، گره خطا می‌دهد و به شما می‌گوید که به‌جای آن از `v2.5-20260210` استفاده کنید.

**توجه:** وقتی `rig_type` برابر "auto" است، Tripo ابتدا بررسی می‌کند که آیا مدل قابل ریگ‌کردن است و نوع اسکلت توصیه‌شده را انتخاب می‌کند. اگر Tripo گزارش دهد که مدل قابل ریگ‌کردن نیست، گره با خطا شکست می‌خورد.

**توجه:** گره انتظار دارد Tripo یک فایل GLB یا FBX برگرداند. اگر Tripo هر نوع فایل دیگری برگرداند، گره خطا می‌دهد.

**توجه:** فقط خروجی متناظر با `out_format` پر می‌شود: `GLB` وقتی `out_format` برابر "glb" است، و `FBX` وقتی `out_format` برابر "fbx" است. خروجی سه‌بعدی دیگر خالی است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل ریگ‌شده تولیدشده (شناسه وظیفه به‌همراه پسوند قالب). فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `rig task_id` | شناسه وظیفه برای پیگیری فرایند تولید ریگ. | RIG_TASK_ID |
| `GLB` | مدل ریگ‌شده به‌صورت فایل سه‌بعدی GLB. وقتی `out_format` برابر "glb" است پر می‌شود. | FILE3DGLB |
| `FBX` | مدل ریگ‌شده به‌صورت فایل سه‌بعدی FBX. وقتی `out_format` برابر "fbx" است پر می‌شود. | FILE3DFBX |
