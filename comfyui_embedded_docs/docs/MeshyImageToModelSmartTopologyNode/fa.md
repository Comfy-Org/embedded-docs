# Meshy: Image to Model (Smart Topology)

این گره با Meshy T2.5 یک مش مثلثی آمادهٔ بازی را از یک تصویر مرجع و با تعداد وجه هدف تولید می‌کند. توپولوژی در همان تعداد چندضلعی درخواستی ساخته می‌شود، نه اینکه بعداً کاهش تعداد وجه انجام شود؛ بنابراین نتیجه بدون نیاز به مرحلهٔ جدای بازتوپولوژی برای موتور بازی آماده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخهٔ مدل Meshy که برای تولید استفاده می‌شود. | COMBO | بله | `"meshy-t2.5"` |
| `image` | تصویر مرجعی که مدل از روی آن تولید می‌شود. | IMAGE | بله | - |
| `target_polycount` | تعداد تقریبی مثلث‌ها در مش تولیدشده. پیش‌فرض: 15000. | INT | بله | 100 تا 30000 |
| `should_texture` | تعیین می‌کند که آیا بافت‌ها تولید شوند یا نه. `"false"` مرحلهٔ بافت را رد می‌کند و یک مش بدون بافت برمی‌گرداند. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `enable_pbr` | نقشه‌های PBR (فلزی، زبری، نرمال) را علاوه بر رنگ پایه تولید می‌کند. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: `False`. | BOOLEAN | خیر | - |
| `texture_prompt` | پرامپت متنی برای هدایت فرایند بافت‌دهی. حداکثر ۸۰۰ کاراکتر. نمی‌تواند هم‌زمان با `texture_image` استفاده شود. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: `""` (رشتهٔ خالی). | STRING | خیر | 1 تا 800 کاراکتر |
| `texture_image` | تصویر مرجع برای فرایند بافت‌دهی. فقط یکی از `texture_image` یا `texture_prompt` می‌تواند هم‌زمان استفاده شود. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. | IMAGE | خیر | - |
| `texture_resolution` | رزولوشن بافت. رزولوشن‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. | COMBO | خیر | `"2k"`<br>`"4k"`<br>`"8k"` |
| `pose_mode` | ژست کاراکتر تولیدشده. رشتهٔ خالی به‌معنای درخواست نکردن ژست مشخص است. این یک تنظیم پیشرفته است. پیش‌فرض: `""` (رشتهٔ خالی). | COMBO | بله | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | `seed` تعیین می‌کند که گره دوباره اجرا شود یا نه؛ نتایج فارغ از مقدار seed قطعی نیستند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

**توجه:** ورودی‌های `enable_pbr`، `texture_prompt`، `texture_image` و `texture_resolution` فقط زمانی در دسترس هستند که `should_texture` روی `"true"` تنظیم شده باشد.

**محدودیت‌ها:**

* `target_polycount` تعداد مثلث‌هایی است که مش بر اساس آن ساخته می‌شود، نه محدودیتی که پس از تولید اعمال شود.
* وقتی `should_texture` روی `"true"` تنظیم شده باشد، `texture_prompt` و `texture_image` نمی‌توانند هم‌زمان استفاده شوند. اگر هر دو ارائه شوند، گره خطا می‌دهد.
* `texture_prompt` حداکثر طولی برابر با ۸۰۰ کاراکتر دارد.
