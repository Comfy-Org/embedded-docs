# Meshy: Image to Model (Smart Topology)

צומת זה יוצר רשת משולשים מוכנה למשחק מתמונת ייחוס במספר פאות יעד עם Meshy T2.5. הטופולוגיה נבנית לפי מספר הפוליגונים המבוקש ולא עוברת דקימציה בדיעבד, כך שהתוצאה מוכנה למנוע משחק ללא שלב ריטופולוגיה נפרד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת המודל של Meshy לשימוש ביצירה. | COMBO | כן | `"meshy-t2.5"` |
| `image` | תמונת הייחוס שממנה נוצר המודל. | IMAGE | כן | - |
| `target_polycount` | מספר משולשים משוער ברשת הנוצרת. ברירת מחדל: 15000. | INT | כן | 100 עד 30000 |
| `should_texture` | קובע אם נוצרות טקסטורות. `"false"` מדלג על שלב הטקסטור ומחזיר רשת ללא טקסטורות. | DYNAMIC_COMBO | כן | `"true"`<br>`"false"` |
| `enable_pbr` | יוצר מפות PBR (מטאלי, חספוס, נורמל) בנוסף לצבע הבסיס. קלט זה זמין רק כאשר `should_texture` מוגדר ל-`"true"`. ברירת מחדל: `False`. | BOOLEAN | לא | - |
| `texture_prompt` | הנחיית טקסט לכוונון תהליך הטקסטור. מקסימום 800 תווים. לא ניתן להשתמש בו בו-זמנית עם `texture_image`. קלט זה זמין רק כאשר `should_texture` מוגדר ל-`"true"`. ברירת מחדל: `""` (מחרוזת ריקה). | STRING | לא | 1 עד 800 תווים |
| `texture_image` | תמונת ייחוס לתהליך הטקסטור. ניתן להשתמש רק באחד מבין `texture_image` או `texture_prompt` בו-זמנית. קלט זה זמין רק כאשר `should_texture` מוגדר ל-`"true"`. | IMAGE | לא | - |
| `texture_resolution` | רזולוציית טקסטורה. רזולוציות גבוהות יותר לוכדות יותר פרטי פני שטח. קלט זה זמין רק כאשר `should_texture` מוגדר ל-`"true"`. | COMBO | לא | `"2k"`<br>`"4k"`<br>`"8k"` |
| `pose_mode` | התנוחה של הדמות הנוצרת. מחרוזת ריקה מבקשת שלא תוגדר תנוחה ספציפית. זו הגדרה מתקדמת. ברירת מחדל: `""` (מחרוזת ריקה). | COMBO | כן | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | `seed` קובע האם הצומת תרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**הערה:** הקלטים `enable_pbr`, `texture_prompt`, `texture_image` ו-`texture_resolution` זמינים רק כאשר `should_texture` מוגדר ל-`"true"`.

**אילוצים:**

* `target_polycount` הוא מספר המשולשים שמהם נבנית הרשת, ולא מגבלה שמוחלת לאחר היצירה.
* כאשר `should_texture` מוגדר ל-`"true"`, לא ניתן להשתמש ב-`texture_prompt` וב-`texture_image` בו-זמנית. אם מסופקים שניהם, הצומת תחזיר שגיאה.
* ל-`texture_prompt` אורך מרבי של 800 תווים.
