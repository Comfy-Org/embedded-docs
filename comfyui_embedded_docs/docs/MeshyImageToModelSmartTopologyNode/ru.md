# Meshy: Image to Model (Smart Topology)

Этот узел генерирует треугольный меш, готовый для использования в игре, из референсного изображения с целевым количеством граней с помощью Meshy T2.5. Топология строится сразу под заданное количество полигонов, а не получается последующим упрощением, поэтому результат готов для игрового движка без отдельного прохода ретопологии.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Meshy, используемая для генерации. | COMBO | Да | `"meshy-t2.5"` |
| `image` | Референсное изображение, по которому генерируется модель. | IMAGE | Да | - |
| `target_polycount` | Приблизительное количество треугольников в сгенерированном меше. По умолчанию: 15000. | INT | Да | 100–30000 |
| `should_texture` | Определяет, будут ли сгенерированы текстуры. `"false"` пропускает этап текстурирования и возвращает меш без текстуры. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `enable_pbr` | Генерировать PBR-карты (металличности, шероховатости и нормалей) в дополнение к базовому цвету. Этот вход доступен только когда `should_texture` имеет значение `"true"`. По умолчанию: `False`. | BOOLEAN | Нет | - |
| `texture_prompt` | Текстовый промпт для управления процессом текстурирования. Максимум 800 символов. Нельзя использовать одновременно с `texture_image`. Этот вход доступен только когда `should_texture` имеет значение `"true"`. По умолчанию: `""` (пустая строка). | STRING | Нет | 1–800 символов |
| `texture_image` | Референсное изображение для процесса текстурирования. Одновременно можно использовать только один из параметров `texture_image` или `texture_prompt`. Этот вход доступен только когда `should_texture` имеет значение `"true"`. | IMAGE | Нет | - |
| `texture_resolution` | Разрешение текстуры. Более высокие разрешения передают больше деталей поверхности. Этот вход доступен только когда `should_texture` имеет значение `"true"`. | COMBO | Нет | `"2k"`<br>`"4k"`<br>`"8k"` |
| `pose_mode` | Поза сгенерированного персонажа. Пустая строка означает отсутствие конкретной позы. Это расширенная настройка. По умолчанию: `""` (пустая строка). | COMBO | Да | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Сид управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от сида. По умолчанию: 42. | INT | Да | 0–2147483647 |

**Примечание:** Входы `enable_pbr`, `texture_prompt`, `texture_image` и `texture_resolution` доступны только когда `should_texture` имеет значение `"true"`.

**Ограничения:**

* `target_polycount` — это количество треугольников, из которых строится меш, а не ограничение, применяемое после генерации.
* Когда `should_texture` имеет значение `"true"`, `texture_prompt` и `texture_image` нельзя использовать одновременно. Если указаны оба, узел выдаёт ошибку.
* `texture_prompt` имеет максимальную длину 800 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. | FILE3DFBX |
