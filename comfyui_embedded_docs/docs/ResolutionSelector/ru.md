# Выбор разрешения

Узел Resolution Selector вычисляет ширину и высоту в пикселях на основе выбранного соотношения сторон и целевого общего разрешения в мегапикселях. Он полезен для создания согласованных размеров для других узлов, таких как узел Empty Latent Image.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон для выходных размеров (по умолчанию: `"1:1 (Square)"`). | COMBO | Да | `"1:1 (Square)"`<br>`"2:3 (Portrait Photo)"`<br>`"3:2 (Photo)"`<br>`"3:4 (Portrait Standard)"`<br>`"4:3 (Standard)"`<br>`"9:16 (Portrait Widescreen)"`<br>`"16:9 (Widescreen)"`<br>`"21:9 (Ultrawide)"` |
| `megapixels` | Целевое общее количество мегапикселей. 1.0 MP ≈ 1024x1024 для квадратного формата (по умолчанию: 1.0). | FLOAT | Да | 0.1 - 16.0 (шаг: 0.1) |
| `preview` | Живой предпросмотр рассчитанного выходного разрешения. Этот виджет только для чтения обновляется автоматически и не принимает пользовательский ввод. | RESOLUTION_PREVIEW | Нет | Н/Д |
| `кратность` | Ближайшее кратное результата, к которому нужно привести выбранное разрешение (по умолчанию: 8). | INT | Нет | 8 - 128 (шаг: 4) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `width` | Рассчитанная ширина в пикселях с учётом выбранного кратного. | INT |
| `height` | Рассчитанная высота в пикселях с учётом выбранного кратного. | INT |
