# انتخابگر وضوح

گره Resolution Selector عرض و ارتفاع پیکسلی را بر اساس نسبت تصویر انتخاب‌شده و یک رزولوشن کل هدف بر حسب مگاپیکسل محاسبه می‌کند. این گره برای تولید ابعاد سازگار برای دیگر گره‌ها، مانند گره Empty Latent Image، مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `نسبت تصویر` | نسبت تصویر برای ابعاد خروجی (پیش‌فرض: `"1:1 (Square)"`). | COMBO | بله | `"1:1 (Square)"`<br>`"2:3 (Portrait Photo)"`<br>`"3:2 (Photo)"`<br>`"3:4 (Portrait Standard)"`<br>`"4:3 (Standard)"`<br>`"9:16 (Portrait Widescreen)"`<br>`"16:9 (Widescreen)"`<br>`"21:9 (Ultrawide)"` |
| `مگاپیکسل` | مجموع مگاپیکسل هدف. 1.0 MP ≈ 1024x1024 برای مربع (پیش‌فرض: 1.0). | FLOAT | بله | 0.1 - 16.0 (گام: 0.1) |
| `preview` | پیش‌نمایش زندهٔ رزولوشن خروجی محاسبه‌شده. این ویجت فقط‌خواندنی به‌صورت خودکار به‌روزرسانی می‌شود و ورودی کاربر را نمی‌پذیرد. | RESOLUTION_PREVIEW | خیر | N/A |
| `ضرب‌کننده` | نزدیک‌ترین مضرب از نتیجه که رزولوشن انتخاب‌شده به آن تنظیم می‌شود (پیش‌فرض: 8). | INT | خیر | 8 - 128 (گام: 4) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `width` | عرض محاسبه‌شده بر حسب پیکسل، ضرب‌شده در مضرب انتخاب‌شده. | INT |
| `height` | ارتفاع محاسبه‌شده بر حسب پیکسل، ضرب‌شده در مضرب انتخاب‌شده. | INT |
