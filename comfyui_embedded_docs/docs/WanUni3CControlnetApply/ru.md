# Применить Wan Uni3C ControlNet

## Обзор

Этот узел применяет управляющую сеть Uni3C ControlNet к модели диффузии видео Wan, используя подготовленное направляющее видео (например, искажённые рендеры облака точек) для влияния на выход модели. Он внедряет управляющие сигналы на определённых уровнях блоков, обеспечивая управление на основе траектории камеры в процессе генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|----------|----------|------------|-------------|----------|
| `модель` | Модель диффузии Wan, к которой применяется патч. | MODEL | Да | – |
| `model_patch` | Патч управляющей сети Uni3C ControlNet (должен быть экземпляром `comfy.ldm.wan.uni3c.WanUni3CControlnet`). | MODEL_PATCH | Да | – |
| `vae` | VAE, используемый для кодирования направляющего видео в латентное представление. | VAE | Да | – |
| `рендер-видео` | Направляющее видео, полученное рендерингом траектории камеры; чаще всего это искажённые рендеры облака точек исходного изображения. | IMAGE | Да | – |
| `интенсивность` | Сила применяемого управляющего сигнала. | FLOAT | Да | -10.0 до 10.0 (по умолчанию: 1.0) |
| `начальный_процент` | Процент процесса шумоподавления, начиная с которого применяется управление. | FLOAT | Да | 0.0 до 1.0 (по умолчанию: 0.0) |
| `конечный_процент` | Процент процесса шумоподавления, на котором завершается управление. | FLOAT | Да | 0.0 до 1.0 (по умолчанию: 1.0) |

**Примечания:**
- `model_patch` должен быть экземпляром Uni3C ControlNet; в противном случае узел выдаёт ошибку.
- Внутренняя размерность управляющей сети должна совпадать с размерностью модели Wan – в случае несоответствия возникает ошибка.
- Входное изображение `render_video` должно быть в формате RGB (используются только первые 3 канала).

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `MODEL` | Модель Wan с применённым патчем Uni3C ControlNet. | MODEL |
