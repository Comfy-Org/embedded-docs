# StabilityStableImageUltraNode

יוצר תמונות באופן סינכרוני בהתבסס על פרומפט ורזולוציה. צומת זה יוצר תמונות באמצעות המודל Stable Image Ultra של Stability AI, מעבד את פרומפט הטקסט שלך ומייצר תמונה מתאימה עם יחס רוחב-גובה והסגנון שצוינו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה שאתה רוצה לראות בתמונת הפלט. פרומפט חזק ותיאורי שמגדיר בבירור אלמנטים, צבעים ונושאים יוביל לתוצאות טובות יותר. כדי לשלוט במשקל של מילה נתונה השתמש בפורמט `(word:weight)`, כאשר `word` היא המילה שברצונך לשלוט במשקלה ו-`weight` הוא ערך בין 0 ל-1. לדוגמה: `The sky was a crisp (blue:0.3) and (green:0.8)` יעביר שמיים שהיו כחולים וירוקים, אך יותר ירוקים מאשר כחולים. | STRING | כן | - |
| `aspect_ratio` | יחס רוחב-גובה של התמונה שנוצרה (ברירת מחדל: "1:1"). | COMBO | כן | `"1:1"`<br>`"16:9"`<br>`"21:9"`<br>`"2:3"`<br>`"3:2"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"9:21"` |
| `style_preset` | סגנון רצוי אופציונלי של התמונה שנוצרה. בחר "None" כדי לא להחיל פריסט סגנון. | COMBO | לא | `"3d-model"`<br>`"analog-film"`<br>`"anime"`<br>`"cinematic"`<br>`"comic-book"`<br>`"digital-art"`<br>`"enhance"`<br>`"fantasy-art"`<br>`"isometric"`<br>`"line-art"`<br>`"low-poly"`<br>`"modeling-compound"`<br>`"neon-punk"`<br>`"origami"`<br>`"photographic"`<br>`"pixel-art"`<br>`"tile-texture"` |
| `seed` | הזרע האקראי המשמש ליצירת הרעש. | INT | כן | 0 - 4294967294 |
| `image` | תמונת קלט אופציונלית ליצירה מתמונה לתמונה. | IMAGE | לא | - |
| `negative_prompt` | טקסט קצר המתאר מה אינך רוצה לראות בתמונת הפלט. זהו מאפיין מתקדם. | STRING | לא | - |
| `image_denoise` | הפחתת רעש של תמונת הקלט; 0.0 מניב תמונה זהה לקלט, 1.0 הוא כאילו לא סופקה תמונה כלל (ברירת מחדל: 0.5). | FLOAT | לא | 0.0 - 1.0 |

**הערה:** כאשר לא מסופקת תמונת קלט, הפרמטר `image_denoise` מושבת ומתעלם ממנו באופן אוטומטי.
