# Bria Virtual Try-On

צומת זה מלביש אדם בפריטי לבוש או באביזרים באמצעות Bria. זהות האדם, התנוחה והרקע נשמרים, והסצנה מעובדת מחדש ברזולוציה של כ־1 מגה־פיקסל, ולכן התוצאה אינה מיושרת ברמת הפיקסל לתמונת הקלט. כל תמונת לבוש מחליפה את הפריט המתאים שהאדם כבר לובש.

## קלטים

הבורר `moderation` חושף אפשרות מודרציה נוספת כאשר הוא מוגדר ל־`"true"`.

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `person_image` | התמונה של האדם שמנסה את פריטי הלבוש. ערוץ האלפא מוסר לפני העלאת התמונה. | IMAGE | כן | - |
| `garment_images` | 1 עד 3 פריטי לבוש או אביזרים הנלבשים יחד, שכל אחד מהם מחליף את הפריט המתאים שהאדם לובש. קלט באצווה נספר פעם אחת לכל תמונה, ואזורים שקופים מטופלים כלבן. | AUTOGROW | כן | 1 עד 3 תמונות |
| `instruction` | הנחיה נוספת אופציונלית שמתווספת להנחיה המובנית של Bria, כגון איזה פריט לבוש להלביש מעל. ברירת מחדל: `""` (מחרוזת ריקה). | STRING | כן | - |
| `aspect_ratio` | `"auto"` שומר על המסגור של תמונת האדם בכ־1 מגה־פיקסל. יחס קבוע מחזיר בין 0.6 ל־1 מגה־פיקסל, לדוגמה 768x1024 עבור `"3:4"`. ברירת מחדל: `"auto"`. | COMBO | כן | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"` |
| `seed` | ה־seed שנשלח ל־Bria עם הבקשה. ברירת מחדל: 42. | INT | כן | 1 עד 2147483647 |
| `moderation` | הגדרות מודרציה. כאשר מוגדר ל־`"true"`, דגל המודרציה שלהלן הופך לזמין. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |

### קלטים של Moderation "true"

פרמטר זה מופיע רק כאשר `moderation` מוגדר ל־`"true"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | מפעיל מודרציית תוכן על התמונה שנוצרה. ברירת מחדל: `False`. | BOOLEAN | לא | True / False |

**אילוצים:**

* `garment_images` מקבל מקסימום 3 תמונות, בספירה לכל תמונה כאשר הקלט באצווה.
* פיקסלים שקופים בתמונות הלבוש ממוזגים על רקע לבן לפני ההעלאה.
* ערוץ האלפא של `person_image` מוסר לפני ההעלאה.
