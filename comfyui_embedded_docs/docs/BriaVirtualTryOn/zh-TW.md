# Bria Virtual Try-On

此節點會使用 Bria 為人物換上服裝或配件。會保留人物的身份、姿勢與背景，同時以約 1 百萬像素重新渲染場景，因此結果不會與輸入照片像素對齊。每張服裝影像會替換人物原本穿著的對應單品。

## 輸入

當 `moderation` 選擇器設為 `"true"` 時，會顯示額外的內容審核選項。

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 人物試穿服裝的照片。影像上傳前會移除 alpha 通道。 | IMAGE | 是 | - |
| `garment_images` | 1 到 3 件一起穿著的服裝或配件，每件會替換人物原本穿著的對應單品。批次輸入會依每張影像計數一次，透明區域會視為白色。 | AUTOGROW | 是 | 1 至 3 張圖像 |
| `instruction` | 添加到 Bria 內建指令的選用額外指示，例如要將哪件服裝疊在上層。預設值：`""`（空字串）。 | STRING | 是 | - |
| `aspect_ratio` | `"auto"` 會保留人物照片的構圖，約 1 百萬像素。固定比例會回傳 0.6 到 1 百萬像素，例如 `"3:4"` 為 768x1024。預設值：`"auto"`。 | COMBO | 是 | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"` |
| `seed` | 隨請求傳送給 Bria 的種子。預設值：42。 | INT | 是 | 1 至 2147483647 |
| `moderation` | 內容審核設定。設為 `"true"` 時，下方的內容審核旗標會變為可用。 | DYNAMIC_COMBO | 是 | `"false"`<br>`"true"` |

### 內容審核 `"true"` 輸入

此參數僅在 `moderation` 設為 `"true"` 時出現。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 啟用生成影像的內容審核。預設值：`False`。 | BOOLEAN | 否 | True / False |

**限制條件：**

* `garment_images` 最多接受 3 張影像；當輸入為批次時，會依每張影像計數。
* 服裝影像中的透明像素會在上傳前合成到白色背景上。
* `person_image` 的 alpha 通道會在上傳前移除。
