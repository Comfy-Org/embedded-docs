# Bria Virtual Try-On

Этот узел с помощью Bria одевает человека в предметы одежды или аксессуары. Идентичность человека, поза и фон сохраняются, при этом сцена перерисовывается с разрешением около 1 мегапикселя, поэтому результат не совпадает попиксельно с входной фотографией. Каждое изображение одежды заменяет соответствующий предмет, который уже надет на человеке.

## Входы

Селектор `moderation` открывает дополнительную опцию модерации, если для него установлено значение `"true"`.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `person_image` | Фотография человека, который примеряет одежду. Альфа-канал удаляется перед загрузкой изображения. | IMAGE | Да | - |
| `garment_images` | От 1 до 3 предметов одежды или аксессуаров, надеваемых вместе; каждый заменяет соответствующий предмет, который надет на человеке. При пакетном вводе каждое изображение учитывается отдельно, а прозрачные области обрабатываются как белые. | AUTOGROW | Да | от 1 до 3 изображений |
| `instruction` | Необязательное дополнительное указание, добавляемое к встроенной инструкции Bria, например, какой предмет одежды надеть сверху. По умолчанию: `""` (пустая строка). | STRING | Да | - |
| `aspect_ratio` | `"auto"` сохраняет кадрирование фотографии человека на уровне около 1 мегапикселя. Фиксированное соотношение возвращает от 0,6 до 1 мегапикселя, например 768x1024 для `"3:4"`. По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"` |
| `seed` | Seed, отправляемый в Bria вместе с запросом. По умолчанию: 42. | INT | Да | от 1 до 2147483647 |
| `moderation` | Настройки модерации. Если установлено значение `"true"`, становится доступен флаг модерации, приведённый ниже. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы при `moderation` = `"true"`

Этот параметр отображается только когда для `moderation` установлено значение `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | Включает модерацию содержимого для сгенерированного изображения. По умолчанию: `False`. | BOOLEAN | Нет | True / False |

**Ограничения:**

* `garment_images` принимает не более 3 изображений; при пакетном вводе подсчёт ведётся по каждому изображению отдельно.
* Прозрачные пиксели в изображениях одежды накладываются на белый фон перед загрузкой.
* Альфа-канал `person_image` удаляется перед загрузкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированная фотография, на которой человек одет в предоставленные предметы одежды. | IMAGE |
