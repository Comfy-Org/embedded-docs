# CombineHooksEight

צומת Combine Hooks [8] ממזג עד שמונה קבוצות Hook שונות לקבוצת Hook משולבת אחת. הוא מקבל מספר קלטי Hook ומשלב אותם באמצעות יכולת שילוב ה-Hook של ComfyUI. הדבר מאפשר לך לאחד תצורות Hook מרובות לצורך עיבוד יעיל בזרימות עבודה מתקדמות.

## קלטים

| פרמטר | תיאור | סוג נתונים | סוג קלט | ברירת מחדל | טווח |
| --- | --- | --- | --- | --- | --- |
| `hooks_A` | קבוצת ה-Hook הראשונה לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_B` | קבוצת ה-Hook השנייה לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_C` | קבוצת ה-Hook השלישית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_D` | קבוצת ה-Hook הרביעית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_E` | קבוצת ה-Hook החמישית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_F` | קבוצת ה-Hook השישית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_G` | קבוצת ה-Hook השביעית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_H` | קבוצת ה-Hook השמינית לשילוב | HOOKS | אופציונלי | None | - |

**הערה:** כל פרמטרי הקלט אופציונליים. הצומת ישלב רק את קבוצות ה-Hook שסופקו, תוך התעלמות מכל קבוצה שהושארה ריקה. ניתן לספק בין קבוצת Hook אחת לשמונה קבוצות Hook לשילוב.
