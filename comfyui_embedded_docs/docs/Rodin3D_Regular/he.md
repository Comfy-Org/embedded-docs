# Rodin 3D Generate - יצירה רגילה

צומת Rodin 3D Regular יוצר נכסי תלת-ממד באמצעות API של Rodin. הוא מקבל תמונות קלט ומעבד אותן דרך שירות Rodin כדי ליצור מודלים תלת-ממדיים. הצומת מטפל בכל זרימת העבודה מיצירת משימה ועד הורדת קבצי מודל התלת-ממד הסופיים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `Images` | תמונות קלט המשמשות ליצירת מודל תלת-ממד. ניתן לספק עד 5 תמונות. נדרשת לפחות תמונה אחת. | IMAGE | כן | - |
| `Seed` | ערך זרע אקראי לקבלת תוצאות ניתנות לשחזור (ברירת מחדל: 0). | INT | לא | 0 עד 65535 |
| `Material_Type` | סוג החומר להחלה על מודל התלת-ממד (ברירת מחדל: `"PBR"`). | STRING | לא | `"PBR"`<br>`"Shaded"` |
| `Polygon_count` | יעד מספר המצולעים וסוג המש עבור מודל התלת-ממד שנוצר (ברירת מחדל: `"18K-Quad"`). | STRING | לא | `"4K-Quad"`<br>`"8K-Quad"`<br>`"18K-Quad"`<br>`"50K-Quad"`<br>`"200K-Triangle"` |

**הערה:** נדרשת לפחות תמונה אחת ליצירת מודל תלת-ממד. ניתן לספק לכל היותר 5 תמונות.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `3D Model Path` | נתיב קובץ למודל התלת-ממד שנוצר (נשמר לתאימות לאחור). | STRING |
| `GLB` | מודל התלת-ממד שנוצר בפורמט GLB. | FILE3DGLB |
