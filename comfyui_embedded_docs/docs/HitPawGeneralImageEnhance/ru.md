# HitPaw General Image Enhance

Этот узел улучшает изображения низкого разрешения, увеличивая их до сверхвысокого разрешения, одновременно удаляя артефакты и шум. Он отправляет изображение во внешний API для обработки и может автоматически корректировать размер входных данных, чтобы оставаться в пределах допустимого лимита выходных данных. Максимально допустимый размер выходных данных — 32 мегапикселя.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель улучшения, которую нужно использовать. Модель `generative_portrait` оптимизирована для портретов, а `generative` — универсальная модель. | COMBO | Да | `"generative_portrait"`<br>`"generative"` |
| `изображение` | Входное изображение для улучшения. | IMAGE | Да | - |
| `коэффициент_масштабирования` | Коэффициент, во сколько раз нужно увеличить размеры изображения. Коэффициент 1 означает отсутствие увеличения, 2 удваивает размеры, а 4 увеличивает их в четыре раза. | COMBO | Да | `1`<br>`2`<br>`4` |
| `авто_понижение_разрешения` | Автоматически уменьшать входное изображение, если выходные данные превысят лимит. (по умолчанию: `False`) | BOOLEAN | Нет | - |

**Примечание:** Узел выдаёт ошибку, если рассчитанный размер выходных данных (ширина входного изображения × upscale_factor × высота входного изображения × upscale_factor) превышает 32 000 000 пикселей (32MP) и `auto_downscale` отключён. Когда `auto_downscale` включён, узел автоматически уменьшает размер входного изображения или коэффициент увеличения (или и то, и другое), чтобы выходные данные укладывались в лимит 32MP. Выбранные `model` и `upscale_factor` объединяются в имя модели, отправляемое в сервис.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Улучшенное и увеличенное выходное изображение. | IMAGE |
