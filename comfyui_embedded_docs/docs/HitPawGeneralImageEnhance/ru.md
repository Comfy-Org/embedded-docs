# HitPaw General Image Enhance

Этот узел улучшает изображения с низким разрешением, увеличивая их до сверхвысокого разрешения, удаляя артефакты и шум. Он использует внешний API для обработки изображения и может автоматически регулировать размер входного изображения, чтобы оставаться в пределах ограничений обработки. Максимально допустимый размер выходного изображения — 32 мегапикселя.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `модель` | Модель улучшения. Модель `generative_portrait` оптимизирована для портретов, а `generative` — модель общего назначения. | COMBO | Да | `"generative_portrait"`<br>`"generative"` |
| `изображение` | Входное изображение для улучшения. | IMAGE | Да | - |
| `коэффициент_масштабирования` | Коэффициент увеличения размеров изображения. Коэффициент 1 означает отсутствие увеличения, 2 удваивает размеры, а 4 учетверяет их. | COMBO | Да | `1`<br>`2`<br>`4` |
| `авто_понижение_разрешения` | Автоматически уменьшать входное изображение, если выходное превысит лимит. (по умолчанию: `False`) | BOOLEAN | Нет | - |

**Примечание:** Узел вызывает ошибку, если расчетный размер выходного изображения (ширина входа × upscale_factor × высота входа × upscale_factor) превышает 32 000 000 пикселей (32 МП), а `auto_downscale` отключен. Когда `auto_downscale` включен, узел автоматически уменьшает размер входного изображения или коэффициент увеличения (или оба), чтобы выходное изображение соответствовало лимиту 32 МП.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Улучшенное и увеличенное выходное изображение. | IMAGE |
