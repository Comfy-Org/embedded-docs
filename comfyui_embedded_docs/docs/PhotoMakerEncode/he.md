# PhotoMakerEncode

צומת PhotoMakerEncode משלב תמונת עזר עם פרומפט טקסט כדי ליצור נתוני התניה ליצירת תמונות. כאשר הטקסט מכיל את המילה "photomaker", הצומת משתמש במודל PhotoMaker כדי להכניס את הזהות החזותית של תמונת העזר אל תוך נתוני ההתניה במיקום הזה בפרומפט.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `photomaker` | מודל PhotoMaker המשמש לעיבוד תמונת העזר וליצירת הטמעות מבוססות תמונה | PHOTOMAKER | כן | - |
| `image` | תמונת העזר המספקת את המאפיינים החזותיים עבור נתוני ההתניה | IMAGE | כן | - |
| `clip` | מודל CLIP המשמש לטוקניזציה של טקסט ולקידוד טקסט | CLIP | כן | - |
| `text` | פרומפט הטקסט ליצירת נתוני התניה. תומך בטקסט רב-שורתי ובפרומפטים דינמיים (ברירת מחדל: "photograph of photomaker") | STRING | כן | כל מחרוזת |

**הערה:** כאשר הטקסט מכיל את "photomaker" כמילה בפני עצמה, הצומת מסיר מילה זו מהפרומפט המקודד ומחיל את הזהות של תמונת העזר במיקום הזה באמצעות מודל PhotoMaker. אם "photomaker" אינו נמצא בטקסט, הצומת מחזיר נתוני התניה סטנדרטיים של טקסט ללא השפעת תמונה.

## פלטים

| שם פלט | תיאור | סוג נתון |
| --- | --- | --- |
| `CONDITIONING` | נתוני התניה המכילים את הטקסט ואת הטמעות התמונה שמנחות את יצירת התמונה, יחד עם פלט ה-pooled של מקודד הטקסט CLIP | CONDITIONING |
