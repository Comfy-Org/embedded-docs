# Кодирование PhotoMaker

PhotoMakerEncode создает данные conditioning для генерации изображений с помощью ИИ, объединяя референсное изображение с текстовым запросом. Он ищет в текстовом запросе слово «photomaker» и, когда оно найдено, использует модель PhotoMaker для применения визуальных характеристик референсного изображения в этой позиции запроса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `photomaker` | Модель PhotoMaker, используемая для обработки референсного изображения и создания эмбеддингов на основе изображения | PHOTOMAKER | Да | - |
| `image` | Референсное изображение, которое предоставляет визуальные характеристики для conditioning | IMAGE | Да | - |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текста | CLIP | Да | - |
| `text` | Текстовый запрос для генерации conditioning. Поддерживает несколько строк и динамические промпты (по умолчанию: "photograph of photomaker") | STRING | Да | - |

**Примечание:** Слово «photomaker» должно присутствовать в текстовом запросе как отдельное слово (совпадение учитывает регистр), чтобы было применено conditioning на основе изображения. Когда оно присутствует, характеристики изображения внедряются в эту позицию запроса. Если «photomaker» не найдено, узел возвращает стандартное текстовое conditioning без влияния изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные conditioning, содержащие эмбеддинги изображения и текста для управления генерацией изображения, а также объединенный выход текстового энкодера CLIP | CONDITIONING |
