# Кодирование PhotoMaker

Узел PhotoMakerEncode объединяет эталонное изображение с текстовым запросом для создания данных кондиционирования для генерации изображений. Когда текст содержит слово «photomaker», узел использует модель PhotoMaker для вставки визуальной идентичности эталонного изображения в кондиционирование в этой позиции запроса.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `photomaker` | Модель PhotoMaker, используемая для обработки эталонного изображения и создания эмбеддингов на основе изображения | PHOTOMAKER | Да | - |
| `изображение` | Эталонное изображение, которое обеспечивает визуальные характеристики для кондиционирования | IMAGE | Да | - |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текста | CLIP | Да | - |
| `текст` | Текстовый запрос для генерации кондиционирования. Поддерживает многострочный текст и динамические запросы (по умолчанию: "photograph of photomaker") | STRING | Да | Любая строка |

**Примечание:** Когда текст содержит «photomaker» как отдельное слово, узел удаляет это слово из закодированного запроса и применяет идентичность эталонного изображения в этой позиции с помощью модели PhotoMaker. Если «photomaker» не найдено в тексте, узел возвращает стандартное текстовое кондиционирование без влияния изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные кондиционирования, содержащие эмбеддинги текста и изображения, которые направляют генерацию изображения, а также объединённый вывод текстового кодировщика CLIP | CONDITIONING |
