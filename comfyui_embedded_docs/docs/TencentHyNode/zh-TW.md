# Tencent HY

此節點使用騰訊的 Hy4 模型產生文字回應。它會送出一個文字提示，並可選擇性地附上一張或多張影像作為上下文，然後以文字形式回傳模型的回答。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於產生回答的模型。選取後會在其下方顯示對應的輸入項。預設：`"Hy4"`。 | DYNAMIC_COMBO | 是 | `"Hy4"` |

### Hy4 輸入

當 `model` 設為 `"Hy4"` 時，會顯示這些輸入項。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要傳送給模型的訊息。不可為空。預設：""（空字串）。 | STRING | 是 | 至少 1 個字元 |
| `images` | 最多 20 張影像。批次中的每張影像都計為一張。預設：無影像。 | AUTOGROW | 否 | 0 至 20 張影像 |
| `seed` | `seed` 控制節點是否應重新執行；無論種子值為何，結果皆不具確定性。預設：42。 | INT | 是 | 0 至 2147483647 |
| `system_prompt` | 用於規範模型行為的基礎指示。預設：""（空字串）。 | STRING | 否 | - |
| `reasoning` | 模型會先思考再回答。回答耗時較長且使用更多 token，極困難的任務可能會逾時。預設：False。 | BOOLEAN | 是 | true<br>false |
| `temperature` | 控制隨機性。即使設為 0，結果仍會有所變動。預設：1.0。 | FLOAT | 是 | 0.0 至 1.4（步進值：0.01） |
| `max_tokens` | 可產生的最大 token 數，當 `reasoning` 開啟時包含推理 token。極長的回答可能會逾時。預設：32000。 | INT | 是 | 1 至 64000 |

**限制條件：**

* 每次請求最多接受 20 張影像，批次中的每張影像都會計入。
* 騰訊的內容過濾機制可能會封鎖請求，並引發錯誤。
* 若在回答完成前 `max_tokens` 就已用盡，節點會引發錯誤：請提高 `max_tokens` 或關閉 `reasoning`。
