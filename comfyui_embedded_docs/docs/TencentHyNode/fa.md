# Tencent HY

این گره با مدل Hy4 شرکت Tencent پاسخ‌های متنی تولید می‌کند. یک پرامپت متنی، به‌همراه اختیاری یک یا چند تصویر به‌عنوان زمینه ارسال می‌کند و پاسخ مدل را به‌صورت متن برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید پاسخ استفاده می‌شود. با انتخاب آن، ورودی‌هایش در ادامه نمایش داده می‌شوند. پیش‌فرض: `"Hy4"`. | DYNAMIC_COMBO | بله | `"Hy4"` |

### ورودی‌های Hy4

این ورودی‌ها زمانی نمایش داده می‌شوند که `model` روی `"Hy4"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پیامی که به مدل ارسال می‌شود. نباید خالی باشد. پیش‌فرض: "" (رشته خالی). | STRING | بله | حداقل 1 نویسه |
| `images` | حداکثر 20 تصویر. هر تصویر در یک دسته نیز شمرده می‌شود. پیش‌فرض: بدون تصویر. | AUTOGROW | خیر | 0 تا 20 تصویر |
| `seed` | `seed` کنترل می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج صرف‌نظر از `seed` غیرقطعی هستند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |
| `system_prompt` | دستورالعمل‌های پایه‌ای که رفتار مدل را تعیین می‌کنند. پیش‌فرض: "" (رشته خالی). | STRING | خیر | - |
| `reasoning` | مدل پیش از پاسخ دادن فکر می‌کند. پاسخ‌ها زمان بیشتری می‌برند و توکن‌های بیشتری مصرف می‌کنند، و وظایف بسیار دشوار ممکن است به پایان مهلت برسند. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `temperature` | تصادفی‌بودن را کنترل می‌کند. نتایج حتی در 0 نیز متغیر هستند. پیش‌فرض: 1.0. | FLOAT | بله | 0.0 تا 1.4 (گام: 0.01) |
| `max_tokens` | حداکثر تعداد توکن‌هایی که تولید می‌شود، شامل توکن‌های استدلال زمانی که `reasoning` روشن است. پاسخ‌های بسیار طولانی ممکن است به پایان مهلت برسند. پیش‌فرض: 32000. | INT | بله | 1 تا 64000 |

**محدودیت‌ها:**

* حداکثر 20 تصویر در هر درخواست پذیرفته می‌شود، و هر تصویر از یک دسته نیز شمرده می‌شود.
* فیلتر محتوای Tencent می‌تواند یک درخواست را مسدود کند، که منجر به بروز خطا می‌شود.
* اگر `max_tokens` پیش از پایان پاسخ تمام شود، گره خطا ایجاد می‌کند: `max_tokens` را افزایش دهید یا `reasoning` را خاموش کنید.
