# Tencent HY

Этот узел генерирует текстовые ответы с помощью модели Hy4 от Tencent. Он отправляет текстовый запрос и, при необходимости, одно или несколько изображений в качестве контекста, а затем возвращает ответ модели в виде текста.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации ответа. При её выборе ниже отображаются соответствующие входы. По умолчанию: `"Hy4"`. | DYNAMIC_COMBO | Да | `"Hy4"` |

### Входы Hy4

Эти входы отображаются, когда `model` имеет значение `"Hy4"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Сообщение для отправки модели. Не должно быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | Не менее 1 символа |
| `images` | До 20 изображений. Каждое изображение в пакете считается отдельно. По умолчанию: без изображений. | AUTOGROW | Нет | от 0 до 20 изображений |
| `seed` | Seed управляет тем, следует ли повторно запускать узел; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. По умолчанию: "" (пустая строка). | STRING | Нет | - |
| `reasoning` | Модель размышляет перед ответом. Ответы занимают больше времени и используют больше токенов, а очень сложные задачи могут завершиться по тайм-ауту. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `temperature` | Управляет степенью случайности. При значении 0 результаты всё равно могут различаться. По умолчанию: 1.0. | FLOAT | Да | от 0.0 до 1.4 (шаг: 0.01) |
| `max_tokens` | Максимальное количество токенов для генерации, включая токены рассуждения, когда `reasoning` включен. Очень длинные ответы могут завершиться по тайм-ауту. По умолчанию: 32000. | INT | Да | от 1 до 64000 |

**Ограничения:**

* За один запрос принимается не более 20 изображений, при этом каждое изображение в пакете считается отдельно.
* Контент-фильтр Tencent может заблокировать запрос, что приведет к ошибке.
* Если `max_tokens` закончится до завершения ответа, узел выдаст ошибку: увеличьте `max_tokens` или отключите `reasoning`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовый ответ модели Hy4. | STRING |
