# Tencent HY

צומת זה מייצר תגובות טקסט עם מודל Hy4 של Tencent. הוא שולח הנחיית טקסט, ובאופן אופציונלי תמונה אחת או יותר כהקשר, ומחזיר את תשובת המודל כטקסט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל המשמש ליצירת התשובה. בחירתו חושפת את הקלטים שלו בהמשך. ברירת מחדל: `"Hy4"`. | DYNAMIC_COMBO | כן | `"Hy4"` |

### קלטים של Hy4

קלטים אלה מופיעים כאשר `model` מוגדר ל-`"Hy4"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ההודעה לשליחה למודל. אסור שתהיה ריקה. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | לפחות תו 1 |
| `images` | עד 20 תמונות. כל תמונה באצווה נחשבת. ברירת מחדל: ללא תמונות. | AUTOGROW | לא | 0 עד 20 תמונות |
| `seed` | ה-seed קובע האם הצומת ירוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |
| `system_prompt` | הוראות בסיס הקובעות את התנהגות המודל. ברירת מחדל: "" (מחרוזת ריקה). | STRING | לא | - |
| `reasoning` | המודל חושב לפני שהוא עונה. התשובות אורכות יותר זמן ומשתמשות ביותר טוקנים, ומשימות קשות במיוחד עלולות לפגות בזמן. ברירת מחדל: False. | BOOLEAN | כן | true<br>false |
| `temperature` | שולט באקראיות. התוצאות עדיין משתנות גם ב-0. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 1.4 (צעד: 0.01) |
| `max_tokens` | מספר הטוקנים המרבי ליצירה, כולל טוקני חשיבה כאשר `reasoning` פעיל. תשובות ארוכות מאוד עלולות לפגות בזמן. ברירת מחדל: 32000. | INT | כן | 1 עד 64000 |

**אילוצים:**

* מתקבלות לכל היותר 20 תמונות לבקשה, כאשר כל תמונה באצווה נספרת.
* מסנן התוכן של Tencent יכול לחסום בקשה, מה שמעלה שגיאה.
* אם `max_tokens` נגמר לפני שהתשובה מסתיימת, הצומת מעלה שגיאה: העלה את `max_tokens` או כבה את `reasoning`.
