# Tripo: Из изображения в мультиракурс

Создаёт фронтальный, левый, задний и правый виды объекта из одного входного изображения с помощью Tripo API. Изображение загружается, запускается задача многовидовой генерации, состояние которой периодически проверяется до завершения, после чего четыре полученных вида возвращаются вместе с ID задачи. Это платная задача, стоимость которой составляет примерно 0,10 доллара США.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Исходное изображение объекта, из которого Tripo генерирует фронтальный, левый, задний и правый виды. Для запроса используется только одно изображение, даже если передан батч. | IMAGE | Да | Одно изображение |

Примечание: Узел вызывает облачный API Tripo и ждёт завершения задачи генерации. Обычно задача занимает около 25 секунд. Аутентификация выполняется автоматически через скрытые входы узла, поэтому в рабочем процессе не нужно указывать API-ключ Tripo. Узел требует наличия всех четырёх URL-адресов видов в ответе Tripo (`front_view_url`, `left_view_url`, `back_view_url`, `right_view_url`); если какой-либо вид отсутствует, выполнение завершается с ошибкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `multiview task_id` | Идентификатор задачи, возвращаемый Tripo для запроса на генерацию многовидового изображения. Его можно использовать для ссылки на завершённую задачу, например при уточнении видов с помощью Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `front` | Сгенерированный фронтальный вид объекта. | IMAGE |
| `left` | Сгенерированный левый вид объекта. | IMAGE |
| `back` | Сгенерированный задний вид объекта. | IMAGE |
| `right` | Сгенерированный правый вид объекта. | IMAGE |
