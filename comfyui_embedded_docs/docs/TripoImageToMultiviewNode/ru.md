# TripoImageToMultiviewNode

Генерирует виды объекта спереди, слева, сзади и справа из одного входного изображения с помощью Tripo API. Это платная операция стоимостью примерно 0,10 доллара США. Узел загружает изображение, ожидает завершения задачи генерации Tripo, а затем возвращает четыре вида вместе с идентификатором мультивидовой задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Исходное изображение объекта, по которому Tripo генерирует виды спереди, слева, сзади и справа. Для запроса используется ровно одно изображение. | IMAGE | Да | Single image |

Примечание: узел вызывает облачный API Tripo и ожидает завершения задачи генерации. Обычно задача занимает около 25 секунд. Аутентификация выполняется автоматически через скрытые входы узла, поэтому в рабочем процессе не нужно указывать API-ключ Tripo.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `task_id мультиракурса` | Идентификатор задачи, возвращаемый Tripo для запроса мультивидовой генерации изображений. Это строковый идентификатор, который можно использовать для ссылки на выполненную задачу. | MULTIVIEW_TASK_ID |
| `спереди` | Сгенерированный вид объекта спереди. | IMAGE |
| `слева` | Сгенерированный вид объекта слева. | IMAGE |
| `сзади` | Сгенерированный вид объекта сзади. | IMAGE |
| `справа` | Сгенерированный вид объекта справа. | IMAGE |
