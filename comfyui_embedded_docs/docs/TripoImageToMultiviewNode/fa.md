# Tripo: تصویر به چندنما

نمای جلو، چپ، پشت و راست سوژه را از یک تصویر ورودی واحد با استفاده از Tripo API تولید می‌کند. تصویر بارگذاری می‌شود، یک وظیفه تولید چندنما آغاز و تا تکمیل شدن بررسی می‌شود، و چهار نمای حاصل همراه با شناسه وظیفه بازگردانده می‌شوند. این یک وظیفه پرداختی است و تقریباً ۰٫۱۰ دلار آمریکا هزینه دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر مبدأ سوژه که Tripo از آن نمای جلو، چپ، پشت و راست را تولید می‌کند. برای درخواست فقط یک تصویر استفاده می‌شود، حتی اگر یک دسته تصویر ارائه شود. | IMAGE | بله | یک تصویر |

توجه: این گره API ابری Tripo را فراخوانی می‌کند و منتظر می‌ماند تا وظیفه تولید به پایان برسد. یک وظیفه معمول حدود ۲۵ ثانیه طول می‌کشد. احراز هویت به‌طور خودکار از طریق ورودی‌های پنهان گره انجام می‌شود، بنابراین نیازی به ارائه کلید API Tripo در گردش‌کار نیست. گره به هر چهار URL نما در پاسخ Tripo نیاز دارد (`front_view_url`، `left_view_url`، `back_view_url`، `right_view_url`)؛ اگر هر نما موجود نباشد، اجرا با خطا شکست می‌خورد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `multiview task_id` | شناسه وظیفه‌ای که Tripo برای درخواست تولید تصویر چندنما بازمی‌گرداند. می‌توان از آن برای ارجاع به وظیفه تکمیل‌شده استفاده کرد، برای مثال هنگام اصلاح نماها با Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `front` | نمای جلوی تولیدشدهٔ سوژه. | IMAGE |
| `left` | نمای چپ تولیدشدهٔ سوژه. | IMAGE |
| `back` | نمای پشت تولیدشدهٔ سوژه. | IMAGE |
| `right` | نمای راست تولیدشدهٔ سوژه. | IMAGE |
