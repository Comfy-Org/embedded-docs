# TripoImageToMultiviewNode

نمای جلو، چپ، عقب و راست سوژه را از یک تصویر ورودی واحد، با استفاده از Tripo API تولید می‌کند. این یک وظیفه پولی است که تقریباً ۰.۱۰ دلار آمریکا هزینه دارد. این گره تصویر را بارگذاری می‌کند، منتظر پایان یافتن وظیفه تولید Tripo می‌ماند و سپس چهار نمای به‌همراه شناسه وظیفه چندنمایی را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر منبع سوژه که Tripo نمای جلو، چپ، عقب و راست را از روی آن تولید می‌کند. برای درخواست دقیقاً یک تصویر استفاده می‌شود. | IMAGE | بله | تک‌تصویر |

توجه: این گره با API ابری Tripo تماس می‌گیرد و منتظر پایان یافتن وظیفه تولید می‌ماند. یک وظیفه معمولی حدود ۲۵ ثانیه زمان می‌برد. احراز هویت به‌طور خودکار از طریق ورودی‌های پنهان گره انجام می‌شود، بنابراین نیازی به ارائه کلید API ترایپو در گردش کار نیست.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `task_id چندنما` | شناسه وظیفه‌ای که توسط Tripo برای درخواست تولید تصویر چندنمایی بازگردانده می‌شود. این یک شناسه رشته‌ای است که می‌توان از آن برای ارجاع به وظیفه تکمیل‌شده استفاده کرد. | MULTIVIEW_TASK_ID |
| `جلو` | نمای جلوی تولیدشدهٔ سوژه. | IMAGE |
| `چپ` | نمای سمت چپ تولیدشدهٔ سوژه. | IMAGE |
| `پشت` | نمای عقب تولیدشدهٔ سوژه. | IMAGE |
| `راست` | نمای سمت راست تولیدشدهٔ سوژه. | IMAGE |
