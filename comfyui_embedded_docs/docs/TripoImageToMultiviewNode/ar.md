# TripoImageToMultiviewNode

يُولّد المناظر الأربعة للموضوع (الأمامي، والجانبي الأيسر، والخلفي، والجانبي الأيمن) من صورة إدخال واحدة، باستخدام واجهة برمجة تطبيقات Tripo. هذه مهمة مدفوعة تُحاسَب بتكلفة تقريبية تبلغ 0.10 دولار أمريكي. ترفع العقدةُ الصورةَ، وتنتظر اكتمال مهمة التوليد لدى Tripo، ثم تُرجع المناظر الأربعة إلى جانب معرّف مهمة العرض المتعدد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | صورة المصدر للموضوع التي يستخدمها Tripo لتوليد المنظر الأمامي، والجانبي الأيسر، والخلفي، والجانبي الأيمن. تُستخدم صورة واحدة بالضبط في الطلب. | IMAGE | نعم | صورة واحدة |

ملاحظة: تستدعي العقدةُ الواجهةَ البرمجيةَ السحابيةَ لـ Tripo وتنتظر اكتمال مهمة التوليد. تستغرق المهمة النموذجية حوالي 25 ثانية. تتم المصادقة تلقائيًا عبر المدخلات المخفية للعقدة، لذا لا يلزم توفير مفتاح واجهة Tripo البرمجية في سير العمل.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `معرّف مهمة المناظر المتعددة task_id` | معرّف المهمة الذي يعيده Tripo لطلب توليد الصور متعددة المناظر. وهو معرّف نصي يمكن استخدامه للإشارة إلى المهمة المكتملة. | MULTIVIEW_TASK_ID |
| `أمام` | المنظر الأمامي المُولَّد للموضوع. | IMAGE |
| `يسار` | المنظر الجانبي الأيسر المُولَّد للموضوع. | IMAGE |
| `خلف` | المنظر الخلفي المُولَّد للموضوع. | IMAGE |
| `يمين` | المنظر الجانبي الأيمن المُولَّد للموضوع. | IMAGE |
