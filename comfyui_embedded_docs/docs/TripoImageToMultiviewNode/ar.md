# Tripo: من صورة إلى مناظر متعددة

يولّد المناظر الأمامية واليسرى والخلفية واليمنى للعنصر من صورة إدخال واحدة باستخدام Tripo API. تُرفع الصورة، وتبدأ مهمة توليد متعددة المناظر ويُستعلم عنها دوريًا حتى تكتمل، ثم تُعاد المناظر الأربعة الناتجة مع معرّف المهمة. هذه مهمة مدفوعة تُحتسب بتكلفة تقارب 0.10 دولار أمريكي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة المصدر للعنصر التي يولّد منها Tripo المناظر الأمامية واليسرى والخلفية واليمنى. تُستخدم صورة واحدة فقط للطلب، حتى إذا تم تمرير دفعة. | IMAGE | نعم | صورة واحدة |

ملاحظة: تستدعي العقدة واجهة API السحابية الخاصة بـ Tripo وتنتظر انتهاء مهمة التوليد. تستغرق المهمة النموذجية حوالي 25 ثانية. تتم المصادقة تلقائيًا عبر مدخلات العقدة المخفية، لذا لا حاجة لتقديم مفتاح Tripo API في سير العمل. تتطلب العقدة جميع روابط URL للمناظر الأربعة في استجابة Tripo (`front_view_url`, `left_view_url`, `back_view_url`, `right_view_url`)؛ وإذا كان أي منظر مفقودًا، يفشل التنفيذ مع خطأ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `multiview task_id` | معرّف المهمة الذي يعيده Tripo لطلب توليد الصورة متعددة المناظر. يمكن استخدامه للإشارة إلى المهمة المكتملة، على سبيل المثال عند تحسين المناظر باستخدام Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `front` | المنظر الأمامي المولّد للعنصر. | IMAGE |
| `left` | المنظر الجانبي الأيسر المولّد للعنصر. | IMAGE |
| `back` | المنظر الخلفي المولّد للعنصر. | IMAGE |
| `right` | المنظر الجانبي الأيمن المولّد للعنصر. | IMAGE |
