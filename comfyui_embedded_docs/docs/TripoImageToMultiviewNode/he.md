# TripoImageToMultiviewNode

יוצר תצוגות חזית, שמאל, אחור וימין של הנושא מתמונת קלט אחת באמצעות Tripo API. התמונה מועלית, משימת יצירת ריבוי תצוגות מתחילה ונבדקת עד להשלמתה, וארבע התצוגות המתקבלות מוחזרות יחד עם מזהה המשימה. זוהי משימה בתשלום בחיוב של כ-0.10 USD.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת המקור של הנושא שממנה Tripo יוצר את תצוגות החזית, שמאל, אחור וימין. רק תמונה אחת משמשת לבקשה, גם אם מסופקת קבוצה. | IMAGE | כן | Single image |

הערה: הצומת קורא ל-API של Tripo בענן וממתין להשלמת משימת היצירה. משימה טיפוסית נמשכת כ-25 שניות. האימות מטופל אוטומטית דרך קלטים מוסתרים של הצומת, כך שאין צורך לספק מפתח API של Tripo בתהליך העבודה. הצומת דורש את כל ארבעת כתובות ה-URL של התצוגות בתגובת Tripo (`front_view_url`, `left_view_url`, `back_view_url`, `right_view_url`); אם תצוגה כלשהי חסרה, הביצוע נכשל עם שגיאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `multiview task_id` | מזהה המשימה שהוחזר על ידי Tripo עבור בקשת יצירת תמונת ריבוי התצוגות. ניתן להשתמש בו כדי להפנות למשימה שהושלמה, למשל בעת עידון התצוגות עם Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `front` | תצוגת החזית שנוצרה של הנושא. | IMAGE |
| `left` | תצוגת הצד השמאלי שנוצרה של הנושא. | IMAGE |
| `back` | תצוגת הגב שנוצרה של הנושא. | IMAGE |
| `right` | תצוגת הצד הימני שנוצרה של הנושא. | IMAGE |
