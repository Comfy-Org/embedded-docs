# Сэмплер Эйлера (Анастр.) CFG++

Узел SamplerEulerAncestralCFGPP создает сэмплер, использующий метод Euler Ancestral с управлением без классификатора (CFG++) для генерации изображений. Этот сэмплер сочетает предковое сэмплирование с управляющим кондиционированием, чтобы создавать разнообразные вариации изображений, сохраняя согласованность, и позволяет выполнять тонкую настройку за счет параметров, контролирующих шум и размер шага.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет размером шага во время сэмплирования, при этом более высокие значения приводят к более агрессивным обновлениям (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |
| `s_noise` | Регулирует количество шума, добавляемого в процессе сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера, который можно использовать в конвейере генерации изображений | SAMPLER |
