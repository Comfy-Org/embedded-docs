# RecraftStyleV3LogoRaster

צומת זה בוחר את סגנון הראסטר של הלוגו ואת תת-הסגנון הספציפי ליצירת תמונות לוגו. הוא מתמחה ביצירת עיצובי לוגו עם טיפולים חזותיים מבוססי ראסטר. הסגנון הנבחר מוחזר כהגדרת סגנון Recraft שניתן להעביר לצמתי Recraft אחרים.
