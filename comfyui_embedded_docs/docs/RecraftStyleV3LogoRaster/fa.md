# سبک Recraft - رستر لوگو

این گره سبک رستری لوگو و یک زیرسبک مشخص را برای تولید تصاویر لوگو انتخاب می‌کند. این گره در ساخت طرح‌های لوگو با پرداخت‌های بصری مبتنی بر رستر تخصص دارد. سبک انتخاب‌شده به‌صورت تنظیم سبک Recraft بازگردانده می‌شود که می‌توان آن را به سایر گره‌های Recraft ارسال کرد.
