# WanFunControlToVideo

צומת זה נוסף כדי לתמוך במודל Alibaba Wan Fun Control ליצירת וידאו, והוא נוסף לאחר [הקומיט הזה](https://github.com/comfyanonymous/ComfyUI/commit/3661c833bcc41b788a7c9f0e7bc48524f8ee5f82).

- **מטרה:** הכנת מידע ההתניה הנדרש ליצירת וידאו, תוך שימוש במודל Wan 2.1 Fun Control.

הצומת WanFunControlToVideo הוא תוספת ל-ComfyUI שנועדה לתמוך במודלי Wan Fun Control ליצירת וידאו, במטרה להשתמש ב-WanFun control ליצירת וידאו.

צומת זה משמש כנקודת הכנה למידע התניה חיוני ומאתחל את נקודת המרכז של המרחב הלטנטי, ומנחה את תהליך יצירת הווידאו הבא באמצעות מודל Wan 2.1 Fun. שם הצומת מציין בבירור את תפקידו: הוא מקבל קלטים שונים וממיר אותם לפורמט המתאים לשליטה ביצירת וידאו במסגרת WanFun.

מיקומו של הצומת בהיררכיית הצמתים של ComfyUI מצביע על כך שהוא פועל בשלבים המוקדמים של צינור יצירת הווידאו, תוך התמקדות בטיפול באותות התניה לפני הדגימה או הפענוח בפועל של פריימי וידאו.

## קלטים

| שם פרמטר | תיאור | חובה | סוג נתונים | ערך ברירת מחדל |
| --- | --- | --- | --- | --- |
| positive | נתוני התניה חיוביים סטנדרטיים של ComfyUI, בדרך כלל מצומת "CLIP Text Encode". הפרומפט החיובי מתאר את התוכן, הנושא והסגנון האמנותי שהמשתמש רוצה בסרטון שנוצר. | כן | CONDITIONING | N/A |
| negative | נתוני התניה שליליים סטנדרטיים של ComfyUI, בדרך כלל נוצרים על ידי צומת "CLIP Text Encode". הפרומפט השלילי מציין אלמנטים, סגנונות או ארטיפקטים שהמשתמש רוצה להימנע מהם בסרטון שנוצר. | כן | CONDITIONING | N/A |
| vae | דורש מודל VAE (Variational Autoencoder) התואם למשפחת המודלים Wan 2.1 Fun, המשמש לקידוד ולפענוח של נתוני תמונה/וידאו. | כן | VAE | N/A |
| width | הרוחב הרצוי של פריימי וידאו בפלט בפיקסלים, עם ערך ברירת מחדל 832, ערך מינימלי 16, ערך מקסימלי שנקבע על ידי nodes.MAX_RESOLUTION, וגודל צעד 16. | כן | INT | 832 |
| height | הגובה הרצוי של פריימי וידאו בפלט בפיקסלים, עם ערך ברירת מחדל 480, ערך מינימלי 16, ערך מקסימלי שנקבע על ידי nodes.MAX_RESOLUTION, וגודל צעד 16. | כן | INT | 480 |
| length | המספר הכולל של פריימים בסרטון שנוצר, עם ערך ברירת מחדל 81, ערך מינימלי 1, ערך מקסימלי שנקבע על ידי nodes.MAX_RESOLUTION, וגודל צעד 4. | כן | INT | 81 |
| batch_size | מספר הסרטונים שנוצרים באצווה אחת, עם ערך ברירת מחדל 1, ערך מינימלי 1, וערך מקסימלי 4096. | כן | INT | 1 |
| clip_vision_output | (אופציונלי) תכונות חזותיות שחולצו על ידי מודל ראייה CLIP, המאפשרות הנחיה של סגנון ותוכן חזותיים. | לא | CLIP_VISION_OUTPUT | None |
| start_image | (אופציונלי) תמונה התחלתית שמשפיעה על תחילת הסרטון שנוצר. | לא | IMAGE | None |
| control_video | (אופציונלי) מאפשר למשתמשים לספק וידאו ייחוס ControlNet מעובד מראש שינחה את התנועה והמבנה האפשרי של הסרטון שנוצר. | לא | IMAGE | None |

## פלטים

| שם פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
