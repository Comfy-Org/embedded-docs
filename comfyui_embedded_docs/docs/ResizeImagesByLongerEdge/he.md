# ResizeImagesByLongerEdge

צומת Resize Images by Longer Edge משנה גודל של תמונה אחת או יותר כך שהצד הארוך ביותר שלהן יתאים לאורך יעד שצוין. הוא קובע אוטומטית אם הרוחב או הגובה ארוך יותר, ומשנה את הממד האחר באופן פרופורציונלי כדי לשמור על יחס הגובה-רוחב המקורי. צומת זה מיושן (deprecated) והוחלף על ידי הצומת Resize Image/Mask עם סוג שינוי הגודל המוגדר ל-"scale longer dimension".

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט או קבוצת תמונות שיש לשנות את גודלן. | IMAGE | כן | - |
| `longer_edge` | ממד היעד עבור הצד הארוך. הצד הקצר ישתנה באופן פרופורציונלי. (ברירת מחדל: 1024) | INT | כן | 1 - 8192 |
