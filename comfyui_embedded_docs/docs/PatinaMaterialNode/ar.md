# Patina Material

يُنشئ مادة PBR كاملة وقابلة للتبليط بسلاسة انطلاقًا من وصف نصي: نسيجًا أساسيًا إضافةً إلى ما يصل إلى خمس خرائط للمادة، مع إمكانية اختيارية لتكبير الخرائط باستخدام SeedVR. يمكن لصورة إدخال أن توجّه النتيجة عبر تمريرة صورة-إلى-صورة، كما أن إرفاق قناع مع صورة إدخال يحوّلها إلى تمريرة إعادة رسم داخلي (inpaint). استخدمه لإنتاج أسطح جاهزة للألعاب أو الرسوم ثلاثية الأبعاد دون مسح مادة حقيقية ضوئيًا.

### مدخلات custom Image Size

تظهر هذه المدخلات عندما تكون `image_size` مضبوطة على `"custom"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | عرض النسيج بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة: 16) |
| `image_size.height` | ارتفاع النسيج بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة: 16) |

**القيود والسلوك:**

* يُسمح بعدم تفعيل أي خريطة مادة: عندئذٍ تُرجع العقدة النسيج الأساسي فقط، ويبقى كل مخرج خاص بالخرائط عنصرًا نائبًا بحجم 1x1.
* يتطلب القناع صورة إدخال؛ واستخدام قناع بمفرده يؤدي إلى رفع خطأ.
* تنتج نتيجة بدقة 8K عن تكبير الخرائط بمعامل 4x لتصيير بدقة 2048 بكسل، وليس عن توليد واحد بدقة 8K.
