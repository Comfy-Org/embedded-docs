# Patina Material

يولّد مادة PBR كاملة وقابلة للتبليط بسلاسة من وصف نصي: نسيج أساسي بالإضافة إلى ما يصل إلى خمس خرائط مواد، مع إمكانية تكبير خرائط المواد اختياريًا باستخدام SeedVR. يمكن لصورة إدخال أن تقود النتيجة كتمريرة صورة إلى صورة، كما تحوّل صورة إدخال مع قناع الأمر إلى تمريرة Inpaint. استخدمه لإنتاج أسطح جاهزة للألعاب أو الرسومات ثلاثية الأبعاد دون مسح مادة حقيقية ضوئيًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|

| `image_size` | حجم النسيج الناتج. يؤدي اختيار `"custom"` إلى إظهار مدخلات `width` و`height`. الافتراضي: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | نعم | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | توليد خريطة اللون الأساسي (albedo). الافتراضي: True. | BOOLEAN | نعم | true<br>false |
| `normal` | توليد خريطة Normal. الافتراضي: True. | BOOLEAN | نعم | true<br>false |

| `safety_checker` | تشغيل فحص أمان المحتوى الخاص بمزوّد الخدمة على الطلب. إعداد متقدم. الافتراضي: False. | BOOLEAN | نعم | true<br>false |

### مدخلات حجم الصورة المخصص

تظهر هذه المدخلات عندما يتم تعيين `image_size` إلى `"custom"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | عرض النسيج بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة 16) |
| `image_size.height` | ارتفاع النسيج بالبكسل. الافتراضي: 1024. | INT | نعم | 512 إلى 2048 (خطوة 16) |

**القيود والسلوك:**

* يجب تمكين خريطة مواد واحدة على الأقل، وإلا سيفشل التشغيل.
* يتطلب القناع صورة إدخال؛ ويؤدي تمرير قناع بمفرده إلى رفع خطأ.
* تنتج نتيجة 8K من تكبير الخرائط بمعامل 4x لتصيير بدقة 2048 بكسل، وليس من توليد واحد بدقة 8K.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `texture` | النسيج الأساسي للمادة، دون تطبيق أي خريطة. | IMAGE |
| `basecolor` | خريطة اللون الأساسي (albedo)، أو عنصر نائب بحجم 1x1 عندما تكون هذه الخريطة معطّلة. | IMAGE |
| `normal` | خريطة Normal، أو عنصر نائب بحجم 1x1 عندما تكون هذه الخريطة معطّلة. | IMAGE |
| `roughness` | خريطة الخشونة، أو عنصر نائب بحجم 1x1 عندما تكون هذه الخريطة معطّلة. | IMAGE |
| `metalness` | خريطة المعدنية، أو عنصر نائب بحجم 1x1 عندما تكون هذه الخريطة معطّلة. | IMAGE |
| `height` | خريطة الارتفاع (الإزاحة)، أو عنصر نائب بحجم 1x1 عندما تكون هذه الخريطة معطّلة. | IMAGE |
| `expanded_prompt` | الأمر النصي الذي استخدمه مزوّد الخدمة فعليًا، ويختلف عن الإدخال فقط عند تمكين `prompt_expansion`. | STRING |
