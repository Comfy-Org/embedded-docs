# Patina Material

Создаёт полноценный бесшовно тайлируемый PBR-материал по текстовому описанию: базовую текстуру плюс до пяти карт материала, с необязательным апскейлингом карт через SeedVR. Входное изображение может управлять результатом как проход image-to-image, а входное изображение с маской превращает его в inpaint-проход. Используйте это для создания поверхностей, готовых для игр или 3D, без сканирования реального материала.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание материала или текстуры для генерации. | STRING | Да | Многострочный текст |
| `image_size` | Размер выходной текстуры. `"custom"` открывает входы `width` и `height`. По умолчанию: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Да | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | Создавать карту basecolor (albedo). По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `normal` | Создавать карту нормалей. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `roughness` | Создавать карту шероховатости. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `metalness` | Создавать карту металличности. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `height` | Создавать карту высоты (смещения). По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `upscale_factor` | Бесшовный апскейлинг PBR-карт с помощью SeedVR. Базовая текстура не апскейлится, а коэффициент 4x превращает карту 2048 пикселей в 8K. По умолчанию: 0 (выкл.). | INT | Да | 0 до 4 (шаг: 2) |
| `seed` | Сид для воспроизводимой генерации. По умолчанию: 42. | INT | Да | 0 до 2147483646 |
| `tiling_mode` | Направление тайлинга: всенаправленный, горизонтальный или вертикальный. Расширенная настройка. По умолчанию: `"both"`. | COMBO | Да | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | Шаги денойзинга для генерации текстуры. Расширенная настройка. По умолчанию: 8. | INT | Да | 1 до 8 |
| `tile_size` | Размер тайла в латентном пространстве, где 64 означает 512 пикселей, а 128 — 1024 пикселя. Расширенная настройка. По умолчанию: 128. | INT | Да | 32 до 256 (шаг: 2) |
| `tile_stride` | Шаг тайла в латентном пространстве. Расширенная настройка. По умолчанию: 64. | INT | Да | 16 до 128 (шаг: 2) |
| `image` | Необязательное исходное изображение. Само по себе запускает image-to-image; вместе с маской запускает inpaint-проход. | IMAGE | Нет | - |
| `mask` | Необязательная маска для inpaint; требуется входное изображение. Белые области регенерируются, чёрные сохраняются. | MASK | Нет | - |
| `strength` | Насколько сильно преобразовывать входное изображение. Используется только при подключённом изображении. Расширенная настройка. По умолчанию: 0.6. | FLOAT | Да | 0.01 до 1.0 (шаг: 0.01) |
| `prompt_expansion` | Расширять промпт с помощью языковой модели для более насыщенных деталей текстуры. По умолчанию выключено, поскольку расширение переформулирует промпт как фотографию и обычно размывает карту металличности. Расширенная настройка. | BOOLEAN | Да | true<br>false |
| `safety_checker` | Выполнять проверку безопасности контента провайдера для запроса. Расширенная настройка. По умолчанию: False. | BOOLEAN | Да | true<br>false |

### Входы пользовательского размера изображения (custom)

Эти входы появляются, когда `image_size` установлен в `"custom"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | Ширина текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |
| `image_size.height` | Высота текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512 до 2048 (шаг: 16) |

**Ограничения и поведение:**

* Должна быть включена как минимум одна карта материала, иначе запуск завершится ошибкой.
* Маска требует входного изображения; маска сама по себе вызывает ошибку.
* Результат 8K получается путём 4x-апскейлинга карт рендера 2048 пикселей, а не одной генерацией 8K.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `texture` | Базовая текстура материала без применения каких-либо карт. | IMAGE |
| `basecolor` | Карта basecolor (albedo) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `normal` | Карта нормалей или заглушка 1x1, если эта карта отключена. | IMAGE |
| `roughness` | Карта шероховатости или заглушка 1x1, если эта карта отключена. | IMAGE |
| `metalness` | Карта металличности или заглушка 1x1, если эта карта отключена. | IMAGE |
| `height` | Карта высоты (смещения) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `expanded_prompt` | Промпт, который фактически использовал провайдер; отличается от входного только когда `prompt_expansion` включён. | STRING |
