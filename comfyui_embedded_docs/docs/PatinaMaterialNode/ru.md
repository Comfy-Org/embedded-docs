# Patina Material

Создаёт полноценный бесшовно тайлящийся PBR-материал по текстовому описанию: базовую текстуру плюс до пяти карт материала с необязательным апскейлингом карт через SeedVR. Входное изображение может управлять результатом как проход image-to-image, а входное изображение с маской превращает его в проход inpaint. Используйте узел для создания поверхностей, готовых для игр или 3D, без сканирования реального материала.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание материала или текстуры для генерации. | STRING | Да | Многострочный текст |
| `image_size` | Размер выходной текстуры. `"custom"` открывает входы `width` и `height`. По умолчанию: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Да | `"1:1 (1024x1024)"`<br>`"1:1 (512x512)"`<br>`"4:3 (1024x768)"`<br>`"3:4 (768x1024)"`<br>`"16:9 (1024x576)"`<br>`"9:16 (576x1024)"`<br>`"custom"` |
| `basecolor` | Сгенерировать карту basecolor (albedo). По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `normal` | Сгенерировать карту нормалей. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `roughness` | Сгенерировать карту шероховатости. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `metalness` | Сгенерировать карту металличности. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `height` | Сгенерировать карту высоты (смещения). По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `upscale_factor` | Бесшовный апскейлинг PBR-карт через SeedVR. Базовая текстура не увеличивается; при 4x карта размером 2048 пикселей становится 8K. По умолчанию: 0 (выключено). | INT | Да | 0–4 (шаг 2) |
| `seed` | Сид для воспроизводимой генерации. По умолчанию: 42. | INT | Да | 0–2147483646 |
| `tiling_mode` | Направление тайлинга: всенаправленное, горизонтальное или вертикальное. Расширенная настройка. По умолчанию: `"both"`. | COMBO | Да | `"both"`<br>`"horizontal"`<br>`"vertical"` |
| `num_inference_steps` | Шаги денойзинга для генерации текстуры. Расширенная настройка. По умолчанию: 8. | INT | Да | 1–8 |
| `tile_size` | Размер тайла в латентном пространстве, где 64 означает 512 пикселей, а 128 — 1024 пикселя. Расширенная настройка. По умолчанию: 128. | INT | Да | 32–256 (шаг 2) |
| `tile_stride` | Шаг тайла в латентном пространстве. Расширенная настройка. По умолчанию: 64. | INT | Да | 16–128 (шаг 2) |
| `image` | Необязательное исходное изображение. Само по себе запускает image-to-image; вместе с маской запускает проход inpaint. | IMAGE | Нет | - |
| `mask` | Необязательная маска inpaint, требует входное изображение. Белые области регенерируются, чёрные области сохраняются. | MASK | Нет | - |
| `strength` | Насколько сильно преобразовывать входное изображение. Используется только при подключённом изображении. Расширенная настройка. По умолчанию: 0.6. | FLOAT | Да | 0.01–1.0 (шаг 0.01) |
| `prompt_expansion` | Расширять промпт с помощью языковой модели для более детальной текстуры. По умолчанию выключено, поскольку расширение переформулирует промпт как фотографию и обычно размывает карту металличности. Расширенная настройка. | BOOLEAN | Да | true<br>false |
| `safety_checker` | Запускать проверку безопасности контента провайдера для запроса. Расширенная настройка. По умолчанию: False. | BOOLEAN | Да | true<br>false |

### Входы пользовательского размера изображения

Эти входы появляются, когда для `image_size` задано значение `"custom"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | Ширина текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512–2048 (шаг 16) |
| `image_size.height` | Высота текстуры в пикселях. По умолчанию: 1024. | INT | Да | 512–2048 (шаг 16) |

**Ограничения и поведение:**

* Разрешается не включать ни одной карты материала: в этом случае узел возвращает только базовую текстуру, а каждый выход карты остаётся заглушкой 1x1.
* Маска требует входного изображения; маска сама по себе вызывает ошибку.
* Результат 8K получается четырёхкратным апскейлом карт рендера размером 2048 пикселей, а не одной генерацией 8K.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `texture` | Базовая текстура материала без наложенных карт. | IMAGE |
| `basecolor` | Карта basecolor (albedo) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `normal` | Карта нормалей или заглушка 1x1, если эта карта отключена. | IMAGE |
| `roughness` | Карта шероховатости или заглушка 1x1, если эта карта отключена. | IMAGE |
| `metalness` | Карта металличности или заглушка 1x1, если эта карта отключена. | IMAGE |
| `height` | Карта высоты (смещения) или заглушка 1x1, если эта карта отключена. | IMAGE |
| `expanded_prompt` | Промпт, который фактически использовал провайдер; отличается от входного только при включённом `prompt_expansion`. | STRING |
