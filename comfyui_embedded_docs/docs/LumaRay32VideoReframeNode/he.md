# LumaRay32VideoReframeNode

צומת זה משנה את יחס הגובה-רוחב של סרטון קיים באמצעות Luma Ray 3.2, אשר ממלא את אזורי הקנבס החדשים שנחשפו בתוכן מיוצר. הסרטון המקור יכול להיות באורך של עד 30 שניות, והחיוב הוא לפי שנייה של פלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | סרטון מקור לשינוי מסגור. עד 30 שניות. | VIDEO | כן | - |
| `prompt` | מתאר כיצד יש למלא את אזורי הקנבס החדשים שנחשפו. | STRING | כן | אורך מינימלי: 1 תו<br>אורך מקסימלי: 6000 תווים |
| `aspect_ratio` | יחס הגובה-רוחב הרצוי עבור הסרטון לאחר שינוי המסגור (ברירת מחדל: "16:9"). | STRING | כן | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9" |
| `resolution` | רזולוציית הפלט של הסרטון לאחר שינוי המסגור (ברירת מחדל: "720p"). | STRING | כן | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `seed` | ערך Seed ליצירה הניתנת לשחזור. | INT | כן | - |

**הערה:** רזולוציית `1080p` אינה זמינה עבור יחסי גובה-רוחב אנכיים (`9:16` ו-`3:4`) בעת שינוי מסגור.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `video` | הסרטון לאחר שינוי המסגור עם יחס הגובה-רוחב החדש ואזורי הקנבס שמולאו. | VIDEO |
| `generation_id` | המזהה הייחודי של בקשת היצירה. | STRING |
