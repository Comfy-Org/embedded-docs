# VSR Decode

VSR Decode превращает латентные представления ключевых кадров из RelayVSR Conditioning обратно в полноценное видео с помощью декодера RelayVSR Flash. Декодер добавляет свою детализацию поверх бикубического увеличения кадров низкого качества, которые вы передаёте, с коэффициентом x2 или x4, заданным декодером. Количество кадров остаётся неизменным.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Декодер RelayVSR Flash, загруженный через Load VAE: `relayvsr_flash_vae_x2_fp32.safetensors` или `relayvsr_flash_vae_x4_fp32.safetensors`. Метаданные файла задают коэффициент увеличения, поэтому файл должен соответствовать модели. | VAE | Да | Н/Д |
| `samples` | Латент, возвращённый сэмплером, содержащий по одному кадру на каждый ключевой кадр. | LATENT | Да | Н/Д |
| `images` | То же видео низкого качества, которое передаётся в RelayVSR Conditioning. | IMAGE | Да | Н/Д |
| `detail` | Насколько детализация декодера сохраняется поверх бикубического увеличения: 1 — полный вывод модели, 0 — только бикубическое увеличение. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Увеличенное видео с восстановленными кадрами. | IMAGE |

## Примечания

- Передавайте одно и то же видео низкого качества в оба узла. Декодер читает его покадрово, поэтому несовпадение длины или разрешения приведёт к неверному или нарушенному результату.
- Уменьшение `detail` смягчает восстановленную детализацию и приближает выход к обычному бикубическому увеличению, что может помочь при очень зашумлённых источниках.
