# AlignYourStepsScheduler

گره AlignYourStepsScheduler مقادیر سیگما را برای فرآیند نویززدایی بر اساس انواع مختلف مدل تولید می‌کند. این گره سطوح نویز مناسب را برای هر گام از فرآیند نمونه‌برداری محاسبه کرده و تعداد کل گام‌ها را مطابق با پارامتر `denoise` تنظیم می‌کند. این کار به هم‌ترازی گام‌های نمونه‌برداری با الزامات خاص مدل‌های انتشار مختلف کمک می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نوع مدل` | نوع مدل مورد استفاده برای محاسبه سیگما را مشخص می‌کند (پیش‌فرض: "SD1") | COMBO | بله | `"SD1"`<br>`"SDXL"`<br>`"SVD"` |
| `گام‌ها` | تعداد کل گام‌های نمونه‌برداری برای تولید (پیش‌فرض: 10) | INT | بله | 1 تا 10000 |
| `کاهش نویز` | میزان نویززدایی تصویر را کنترل می‌کند؛ به طوری که مقدار 1.0 از همه گام‌ها استفاده می‌کند و مقادیر کمتر از گام‌های کمتری استفاده می‌کنند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |

نکته: هر نوع مدل دارای یک برنامه سطح نویز داخلی شامل ۱۱ مقدار سیگما (برای ۱۰ گام) است. وقتی `denoise` برابر 0.0 باشد، گره یک تانسور سیگما خالی بازمی‌گرداند. وقتی `denoise` بین 0.0 و 1.0 باشد، تعداد گام‌های مؤثر به صورت `round(steps × denoise)` محاسبه می‌شود و تنها بخش انتهایی متناظر از برنامه سیگما استفاده می‌شود. اگر مقدار درخواستی `steps` با طول برنامه داخلی مطابقت نداشته باشد، سطوح نویز به صورت لگاریتمی-خطی درونیابی می‌شوند تا با تعداد گام‌های درخواستی همخوانی شوند. مقدار نهایی سیگما همیشه 0 تنظیم می‌شود.
