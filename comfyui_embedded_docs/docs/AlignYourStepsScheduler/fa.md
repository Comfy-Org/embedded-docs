# AlignYourStepsScheduler

گره AlignYourStepsScheduler مقادیر سیگما را که در فرآیند نویززدایی برای انواع مختلف مدل‌های انتشار استفاده می‌شود، ایجاد می‌کند. این گره سطوح نویز پایه را برای مدل انتخابی برمی‌گزیند، تعداد مراحل را بر اساس تنظیم `denoise` تنظیم می‌کند و یک تانسور از مقادیر سیگما بازمی‌گرداند که به ۰ ختم می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model_type` | نوع مدلی که برای انتخاب سطوح نویز پایه استفاده می‌شود (پیش‌فرض: "SD1") | COMBO | بله | `"SD1"`<br>`"SDXL"`<br>`"SVD"` |
| `steps` | تعداد کل مراحل نمونه‌برداری برای تولید (پیش‌فرض: ۱۰) | INT | بله | ۱ تا ۱۰۰۰۰ |
| `denoise` | میزان استفاده از فرآیند نمونه‌برداری را کنترل می‌کند: مقدار ۱.۰ از همه مراحل استفاده می‌کند، مقادیر کمتر از تعداد مراحل کمتری استفاده می‌کنند، و مقدار ۰.۰ یک تانسور سیگمای خالی بازمی‌گرداند (پیش‌فرض: ۱.۰) | FLOAT | بله | ۰.۰ تا ۱.۰ |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `sigmas` | مقادیر سیگمای محاسبه‌شده برای فرآیند نویززدایی. اگر `denoise` برابر ۰.۰ باشد، یک تانسور خالی بازگردانده می‌شود. | SIGMAS |
