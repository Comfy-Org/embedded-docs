# Scheduler выравнивания шагов

Узел AlignYourStepsScheduler генерирует значения sigma (уровни шума) для процесса удаления шума на основе различных типов моделей. Он рассчитывает подходящие уровни шума для каждого шага процесса сэмплирования и корректирует общее количество шагов в соответствии с параметром `denoise`, помогая согласовать шаги сэмплирования с конкретными требованиями различных диффузионных моделей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `тип_модели` | Указывает тип модели, используемой для расчёта sigma (по умолчанию: "SD1") | COMBO | Да | `"SD1"`<br>`"SDXL"`<br>`"SVD"` |
| `шаги` | Общее количество шагов сэмплирования для генерации (по умолчанию: 10) | INT | Да | от 1 до 10000 |
| `шумоподавление` | Управляет степенью удаления шума из изображения, где 1.0 использует все шаги, а меньшие значения используют меньше шагов (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

Примечание: Каждый тип модели имеет встроенное расписание уровней шума, содержащее 11 значений sigma (для 10 шагов). Когда `denoise` равен 0.0, узел возвращает пустой тензор sigma. Когда `denoise` находится в диапазоне от 0.0 до 1.0, эффективное количество шагов рассчитывается как `round(steps × denoise)`, и используется только соответствующая последняя часть расписания sigma. Если запрошенное значение `steps` не совпадает с длиной встроенного расписания, уровни шума логлинейно интерполируются для соответствия запрошенному количеству шагов. Итоговое значение sigma всегда устанавливается равным 0.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Возвращает рассчитанные значения sigma для процесса удаления шума | SIGMAS |
