# Scheduler выравнивания шагов

Узел AlignYourStepsScheduler создаёт значения сигма, используемые в процессе шумоподавления для различных типов диффузионных моделей. Он выбирает базовые уровни шума для выбранной модели, корректирует количество шагов в зависимости от значения `denoise` и возвращает тензор значений сигма, который заканчивается на 0.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `model_type` | Тип модели, используемый для выбора базовых уровней шума (по умолчанию: "SD1") | COMBO | Да | `"SD1"`<br>`"SDXL"`<br>`"SVD"` |
| `steps` | Общее количество шагов сэмплирования для генерации (по умолчанию: 10) | INT | Да | 1 to 10000 |
| `denoise` | Управляет тем, какая часть процесса сэмплирования используется: 1.0 использует все шаги, меньшие значения используют меньше шагов, а 0.0 возвращает пустой тензор сигма (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Рассчитанные значения сигма для процесса шумоподавления. Если `denoise` равен 0.0, возвращается пустой тензор. | SIGMAS |
