# Scheduler выравнивания шагов

Узел AlignYourStepsScheduler генерирует значения сигмы для процесса шумоподавления на основе различных типов моделей. Он вычисляет подходящие уровни шума для каждого шага процесса сэмплирования и корректирует общее количество шагов в соответствии с параметром `denoise`. Это помогает согласовать шаги сэмплирования с конкретными требованиями различных диффузионных моделей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `тип_модели` | Указывает тип модели для расчета сигмы (по умолчанию: "SD1") | COMBO | Да | `"SD1"`<br>`"SDXL"`<br>`"SVD"` |
| `шаги` | Общее количество шагов сэмплирования для генерации (по умолчанию: 10) | INT | Да | от 1 до 10000 |
| `шумоподавление` | Управляет степенью шумоподавления изображения, где 1.0 использует все шаги, а меньшие значения используют меньше шагов (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 |

Примечание: Каждый тип модели имеет встроенный график уровней шума, содержащий 11 значений сигмы (для 10 шагов). Когда `denoise` равен 0.0, узел возвращает пустой тензор сигмы. Когда `denoise` находится между 0.0 и 1.0, эффективное количество шагов вычисляется как `round(steps × denoise)`, и используется только соответствующая последняя часть графика сигмы. Если запрошенное значение `steps` не совпадает с длиной встроенного графика, уровни шума интерполируются лог-линейно для соответствия запрошенному количеству шагов. Финальное значение сигмы всегда устанавливается равным 0.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Возвращает вычисленные значения сигмы для процесса шумоподавления | SIGMAS |
