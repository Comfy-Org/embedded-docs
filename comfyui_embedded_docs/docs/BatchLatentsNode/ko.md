# latent 배치

Batch Latents 노드는 여러 잠재 입력을 단일 배치로 결합합니다. 가변 개수의 잠재 샘플을 받아 배치 차원을 따라 병합하므로, 이후 노드에서 함께 처리할 수 있습니다. 이는 단일 작업으로 여러 이미지를 생성하거나 처리할 때 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `latents` | 단일 배치로 결합할 잠재 샘플 집합입니다. 최소 하나의 잠재 입력을 제공해야 하며, 최대 50개까지 추가할 수 있습니다. 노드는 더 많은 잠재 입력을 연결하면 입력 슬롯을 자동으로 생성합니다. | LATENT | 예 | 1~50개 입력 |

**참고:** 노드가 작동하려면 최소 하나의 잠재 입력을 제공해야 합니다. 노드는 더 많은 잠재 입력을 연결하면 최대 50개까지 입력 슬롯을 자동으로 생성합니다.

모든 입력 잠재는 결합되기 전에 첫 번째 잠재의 공간 차원에 맞게 형태가 조정됩니다. 각 잠재의 `batch_index` 메타데이터는 출력으로 전달되며, `batch_index`가 없는 입력에는 0부터 시작하는 기본 시퀀스가 할당됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 모든 입력 잠재를 하나의 배치로 결합한 단일 잠재 출력입니다. | LATENT |
