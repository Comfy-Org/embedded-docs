# Пакет латентных

Узел **Batch Latents** объединяет несколько входных латентных представлений в один пакет. Он принимает переменное количество латентных сэмплов и объединяет их по измерению пакета, позволяя обрабатывать их вместе в последующих узлах. Это полезно для генерации или обработки нескольких изображений за одну операцию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Набор латентных сэмплов для объединения в один пакет. Необходимо предоставить хотя бы одно латентное представление; можно добавить до 50. Узел автоматически создаёт входные слоты по мере подключения дополнительных латентных представлений. | LATENT | Да | от 1 до 50 входов |

**Примечание:** Для работы узла необходимо подать хотя бы одно латентное представление на вход. Узел автоматически создаёт входные слоты по мере подключения дополнительных латентных представлений, вплоть до максимума в 50.

Все входные латентные представления перед объединением изменяются так, чтобы соответствовать пространственным размерам первого латентного представления. Метаданные `batch_index` каждого латентного представления переносятся в выходные данные; вход без `batch_index` получает последовательность по умолчанию, начинающуюся с 0.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Единый латентный выход, содержащий все входные латентные представления, объединённые в один пакет. | LATENT |
