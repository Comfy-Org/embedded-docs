# Пакет латентных

Узел Batch Latents объединяет несколько латентных входов в один батч. Он принимает переменное число латентных образцов и объединяет их по размерности батча, чтобы последующие узлы могли обрабатывать их вместе. Узел также объединяет метаданные индексов батча всех входов в комбинированный выход.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `латентные` | Набор латентных образцов, которые нужно объединить в один батч. Необходимо указать хотя бы один латент, можно добавить до 50. Узел автоматически создаёт входные слоты (`latent_1`, `latent_2` и так далее) по мере подключения дополнительных латентов. | LATENT | Да | от 1 до 50 входов |

**Примечание:** Для работы узла необходимо подать хотя бы один латентный вход. Узел автоматически создаёт входные слоты по мере подключения дополнительных латентов, максимум до 50. Каждый входной латент перед объединением изменяет форму, чтобы соответствовать форме образца первого латента, а любому латенту без метаданных индекса батча назначается последовательный индекс батча. Входные латенты соединяются по размерности батча, образуя объединённый результат.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Единый латентный выход, содержащий все входные латенты, объединённые в один батч, вместе с их объединёнными метаданными индексов батча. | LATENT |
