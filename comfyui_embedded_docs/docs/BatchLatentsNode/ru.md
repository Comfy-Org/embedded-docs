# Пакет латентных

Узел Batch Latents объединяет несколько латентных входов в один батч. Он принимает переменное количество латентных сэмплов и объединяет их по размерности батча, чтобы последующие узлы могли обрабатывать их совместно. Узел также объединяет метаданные индекса батча всех входов в единый выходной тензор.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `латентные` | Набор латентных сэмплов для объединения в один батч. Необходимо указать как минимум один латентный тензор; можно добавить до 50. Узел автоматически создаёт входные слоты по мере подключения новых латентов. | LATENT | Да | 1 до 50 inputs |

**Примечание:** Для работы узла необходимо указать как минимум один латентный вход. Узел автоматически создаёт входные слоты по мере подключения дополнительных латентов, вплоть до максимума в 50. Каждый входной латент изменяет свою форму, чтобы соответствовать форме сэмпла первого латента перед объединением, а любой латент, не имеющий метаданных индекса батча, получает последовательный индекс батча.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Единый латентный выход, содержащий все входные латенты, объединённые в один батч, вместе с их объединёнными метаданными индекса батча. | LATENT |
