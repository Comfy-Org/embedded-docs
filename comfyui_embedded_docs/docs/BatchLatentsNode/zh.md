# 批量latent

Batch Latents 节点将多个潜空间输入合并为单个批次。它接受可变数量的潜空间样本，并沿批次维度合并它们，使它们可以在后续节点中一起处理。这对于在单次操作中生成或处理多张图像非常有用。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `latents` | 一组要合并为单个批次的潜空间样本。您必须至少提供一个潜空间，最多可以添加 50 个。当您连接更多潜空间时，节点会自动创建输入插槽。 | LATENT | 是 | 1 to 50 inputs |

**注意：** 节点必须至少有一个潜空间输入才能运行。当您连接更多潜空间时，节点会自动创建输入插槽，最多可达 50 个。

所有输入潜空间在合并前都会重塑为与第一个潜空间相同的空间维度。每个潜空间的 `batch_index` 元数据会传递到输出；没有 `batch_index` 的输入会获得从 0 开始的默认序列。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 包含合并为一个批次的所有输入潜空间的单个潜空间输出。 | LATENT |
