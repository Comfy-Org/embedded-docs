# 批次 latent

「Batch Latents」節點將多個潛在（latent）輸入合併為單一批次。它接受可變數量的潛在樣本，並沿著批次維度將其合併，以便後續節點可以一起處理。該節點也會將所有輸入的批次索引中繼資料合併到組合輸出中。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `latent` | 一組要合併為單一批次的潛在樣本。您必須至少提供一個潛在樣本，最多可以新增 50 個。當您連接更多潛在樣本時，節點會自動建立輸入插槽。 | LATENT | 是 | 1 至 50 inputs |

**注意：** 您必須至少提供一個潛在輸入，節點才能運作。當您連接更多潛在樣本時，節點會自動建立輸入插槽，最多可達 50 個。每個輸入潛在樣本在合併前都會被重塑，以符合第一個潛在樣本的樣本形狀；任何沒有批次索引中繼資料的潛在樣本都會被指派一個連續的批次索引。
