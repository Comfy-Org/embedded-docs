# SaveSVGNode

Сохраняет SVG-файлы на диск. Этот узел принимает SVG-данные на вход и сохраняет их в выходную директорию с возможностью встраивания метаданных. Узел автоматически обрабатывает имена файлов с суффиксами-счётчиками и может встраивать информацию о промпте рабочего процесса непосредственно в SVG-файл.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `svg` | SVG-данные, которые будут сохранены на диск. | SVG | Да | - |
| `filename_prefix` | Префикс для сохраняемого файла. Может включать форматирующую информацию, такую как %date:yyyy-MM-dd% или %Empty Latent Image.width%, для подстановки значений из узлов. (по умолчанию: "svg/ComfyUI") | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `svg` | SVG-данные, которые были сохранены на диск. | SVG |
| `ui` | Возвращает информацию о файле, включая имя файла, подпапку и тип, для отображения в интерфейсе ComfyUI. | DICT |

**Примечание.** Этот узел автоматически встраивает метаданные рабочего процесса (информацию о промпте и дополнительную PNG-информацию) в SVG-файл, когда они доступны. Метаданные вставляются как раздел CDATA внутри элемента metadata в SVG.
