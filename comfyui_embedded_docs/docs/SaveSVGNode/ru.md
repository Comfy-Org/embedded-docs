# SaveSVGNode

Сохранить SVG-файлы на диск. Этот узел принимает SVG-данные на вход и сохраняет их в ваш выходной каталог с возможностью встраивания метаданных. Узел автоматически обрабатывает имена файлов, добавляя счетчики-суффиксы, и может встраивать информацию о workflow (программе) непосредственно в SVG-файл.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `svg` | SVG-данные для сохранения на диск | SVG | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может содержать форматирующую информацию, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для включения значений из узлов. (по умолчанию: "svg/ComfyUI") | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `svg` | Исходные SVG-данные, передаваемые после сохранения | SVG |
| `ui` | Информация о сохраненном файле, включая имя файла, подпапку и тип, для отображения в интерфейсе ComfyUI | DICT |

**Примечание:** Этот узел автоматически встраивает метаданные workflow (prompt и дополнительную PNG-информацию) в SVG-файл, когда они доступны. Метаданные вставляются как раздел CDATA внутри элемента metadata SVG-файла. Файлы сохраняются по шаблону `filename_prefix_00001_.svg`; при пакетной обработке `%batch_num%` в префиксе заменяется на индекс текущего элемента пакета.
