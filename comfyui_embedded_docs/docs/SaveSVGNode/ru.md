# SaveSVGNode

Сохраняет SVG-файлы на диск. Этот узел принимает данные SVG на вход и записывает их в выходной каталог ComfyUI, автоматически обрабатывая именование файлов с суффиксами-счётчиками. Когда доступна информация о запросе (prompt) workflow, она встраивается непосредственно в SVG-файл как элемент метаданных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `svg` | Данные SVG для сохранения на диск | SVG | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может включать информацию о форматировании, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, чтобы включать значения из узлов. (по умолчанию: "svg/ComfyUI") | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `svg` | Исходные данные SVG, передаваемые дальше после сохранения | SVG |
| `ui` | Информация о сохранённом файле, включая имя файла, подпапку и тип, для отображения в интерфейсе ComfyUI | DICT |

**Примечание:** Этот узел автоматически встраивает метаданные workflow (prompt и дополнительную информацию PNG) в SVG-файл, когда они доступны. Метаданные вставляются как секция CDATA внутри элемента metadata SVG. Файлы сохраняются по шаблону `filename_prefix_00001_.svg`; при обработке пакета `%batch_num%` в префиксе заменяется на индекс текущего элемента пакета. Этот узел является выходным, поэтому он создаёт сохранённый результат в выходной папке, даже если сам файл не отображается как предпросмотр изображения.
