# SVG保存ノード

SVGファイルをディスクに保存します。このノードは、SVGデータを入力として受け取り、オプションのメタデータ埋め込みとともに出力ディレクトリに保存します。ノードは、カウンターサフィックスを使用したファイル名を自動的に処理し、ワークフローのプロンプト情報をSVGファイルに直接埋め込むことができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `svg` | ディスクに保存するSVGデータ | SVG | Yes | - |
| `filename_prefix` | 保存するファイルのプレフィックスです。ノードの値を含めるための、%date:yyyy-MM-dd% や %Empty Latent Image.width% などのフォーマット情報を含めることができます。（デフォルト: "svg/ComfyUI"） | STRING | Yes | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `svg` | ディスクに保存されたSVGデータ | SVG |
| `ui` | ComfyUIインターフェースで表示するための、ファイル名、サブフォルダ、タイプを含むファイル情報を返します | DICT |

**注意:** このノードは、利用可能な場合、ワークフローのメタデータ（プロンプトと追加のPNG情報）をSVGファイルに自動的に埋め込みます。メタデータはSVGのmetadata要素内のCDATAセクションとして挿入されます。
