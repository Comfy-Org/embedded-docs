# ذخیره SVG Node

فایل‌های SVG را روی دیسک ذخیره می‌کند. این گره داده SVG را به عنوان ورودی دریافت کرده و آن را با جاسازی فراداده اختیاری در پوشه خروجی شما ذخیره می‌کند. این گره به‌طور خودکار نام‌گذاری فایل را با پسوندهای شمارنده مدیریت می‌کند و می‌تواند اطلاعات پرامپت گردش کار را مستقیماً در فایل SVG جاسازی کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `svg` | داده SVG که باید روی دیسک ذخیره شود | SVG | بله | - |
| `filename_prefix` | پیشوند فایل برای ذخیره. این می‌تواند شامل اطلاعات قالب‌بندی مانند %date:yyyy-MM-dd% یا %Empty Latent Image.width% برای درج مقادیر از گره‌ها باشد. (پیش‌فرض: "svg/ComfyUI") | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `svg` | داده SVG که روی دیسک ذخیره شد | SVG |
| `ui` | اطلاعات فایل شامل نام فایل، زیرپوشه و نوع را برای نمایش در رابط ComfyUI برمی‌گرداند | DICT |

**نکته:** این گره به‌طور خودکار فراداده گردش کار (اطلاعات پرامپت و PNG اضافی) را در صورت وجود در فایل SVG جاسازی می‌کند. این فراداده به‌صورت یک بخش CDATA در عنصر metadata فایل SVG درج می‌شود.

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SaveSVGNode/fa.md)
