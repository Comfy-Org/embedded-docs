# ذخیره SVG Node

فایل‌های SVG را روی دیسک ذخیره می‌کند. این گره داده SVG را به‌عنوان ورودی می‌گیرد و آن را در پوشه خروجی ComfyUI می‌نویسد و نام‌گذاری فایل را به‌طور خودکار با پسوندهای شمارنده مدیریت می‌کند. هنگامی که اطلاعات پرامپت گردش‌کار در دسترس باشد، مستقیماً به‌عنوان یک عنصر فراداده در فایل SVG جاسازی می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `svg` | داده SVG که باید روی دیسک ذخیره شود | SVG | بله | - |
| `filename_prefix` | پیشوند فایل برای ذخیره. ممکن است شامل اطلاعات قالب‌بندی مانند %date:yyyy-MM-dd% یا %Empty Latent Image.width% باشد تا مقادیر گره‌ها را شامل شود. (پیش‌فرض: "svg/ComfyUI") | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `svg` | داده SVG اصلی، که پس از ذخیره عبور داده می‌شود | SVG |
| `ui` | اطلاعات فایل ذخیره‌شده شامل نام فایل، زیرپوشه و نوع برای نمایش در رابط ComfyUI | DICT |

**توجه:** این گره به‌طور خودکار فراداده گردش‌کار (پرامپت و اطلاعات PNG اضافی) را در صورت وجود در فایل SVG جاسازی می‌کند. فراداده به‌صورت یک بخش CDATA درون عنصر metadata فایل SVG درج می‌شود. فایل‌ها با الگوی `filename_prefix_00001_.svg` ذخیره می‌شوند؛ هنگام پردازش یک دسته، `%batch_num%` در پیشوند با اندیس آیتم دسته جاری جایگزین می‌شود. این گره یک گره خروجی است، بنابراین نتیجه‌ای ذخیره‌شده در پوشه خروجی تولید می‌کند، حتی اگر خود فایل به‌عنوان پیش‌نمایش تصویر نمایش داده نشود.
