# ذخیره SVG Node

ذخیرهٔ فایل‌های SVG روی دیسک. این گره دادهٔ SVG را به‌عنوان ورودی دریافت کرده و آن را با جاسازی فرادادهٔ اختیاری در فهرست خروجی شما ذخیره می‌کند. گره به‌صورت خودکار نام‌گذاری فایل را با پسوندهای شمارنده مدیریت می‌کند و می‌تواند اطلاعات پرامپت گردش کار را مستقیماً در فایل SVG جاسازی کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `SVG` | دادهٔ SVG که باید روی دیسک ذخیره شود | SVG | بله | - |
| `پیشوند نام فایل` | پیشوند فایل برای ذخیره‌سازی. این می‌تواند شامل اطلاعات قالب‌بندی مانند `%date:yyyy-MM-dd%` یا `%Empty Latent Image.width%` برای درج مقادیر گره‌های دیگر باشد. (پیش‌فرض: "svg/ComfyUI") | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `SVG` | دادهٔ SVG اصلی که پس از ذخیره‌سازی بازگردانده می‌شود | SVG |
| `ui` | اطلاعات فایل ذخیره‌شده شامل نام فایل، زیرپوشه و نوع برای نمایش در رابط ComfyUI | DICT |

**نکته:** این گره به‌صورت خودکار فرادادهٔ گردش کار (اطلاعات پرامپت و اطلاعات اضافی PNG) را در صورت وجود در فایل SVG جاسازی می‌کند. فراداده به‌صورت یک بخش CDATA در عنصر metadata داخل SVG درج می‌شود. فایل‌ها با الگوی `filename_prefix_00001_.svg` ذخیره می‌شوند؛ هنگام پردازش دسته‌ای، `%batch_num%` در پیشوند با شمارهٔ آیتم فعلی دسته جایگزین می‌شود.
