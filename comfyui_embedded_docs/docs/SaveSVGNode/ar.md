# عقدة حفظ SVG

حفظ ملفات SVG على القرص. تستقبل هذه العقدة بيانات SVG كمدخل وتحفظها في مجلد الإخراج مع إمكانية تضمين بيانات وصفية اختيارية. تتعامل العقدة تلقائيًا مع تسمية الملفات باستخدام لاحقات عدّاد، ويمكنها تضمين معلومات سير العمل مباشرة داخل ملف SVG.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `svg` | بيانات SVG التي سيتم حفظها على القرص | SVG | نعم | - |
| `filename_prefix` | البادئة لاسم الملف المراد حفظه. يمكن أن تتضمن معلومات تنسيق مثل %date:yyyy-MM-dd% أو %Empty Latent Image.width% لتضمين قيم من العقد. (الافتراضي: "svg/ComfyUI") | STRING | نعم | - |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `svg` | بيانات SVG التي تم حفظها على القرص | SVG |
| `ui` | يعيد معلومات الملف بما في ذلك اسم الملف والمجلد الفرعي والنوع لعرضها في واجهة ComfyUI | DICT |

**ملاحظة:** تقوم هذه العقدة تلقائيًا بتضمين بيانات وصفية لسير العمل (معلومات prompt وبيانات PNG الإضافية) داخل ملف SVG عندما تكون متاحة. تُدرج البيانات الوصفية كقسم CDATA داخل عنصر البيانات الوصفية في SVG.
