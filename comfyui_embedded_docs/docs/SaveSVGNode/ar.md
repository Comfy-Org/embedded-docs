# عقدة حفظ SVG

احفظ ملفات SVG على القرص. تأخذ هذه العقدة بيانات SVG كمدخل وتحفظها في مجلد الإخراج لديك مع إمكانية تضمين بيانات وصفية اختيارية. تتعامل العقدة تلقائيًا مع تسمية الملفات باستخدام لاحقات عدّادية، ويمكنها تضمين معلومات تلقين سير العمل مباشرة داخل ملف SVG.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `svg` | بيانات SVG المراد حفظها على القرص | SVG | نعم | - |
| `بادئة اسم الملف` | بادئة اسم الملف للحفظ. قد تتضمن معلومات تنسيق مثل `%date:yyyy-MM-dd%` أو `%Empty Latent Image.width%` لتضمين قيم من العقد. (الافتراضي: `"svg/ComfyUI"`) | STRING | نعم | - |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `svg` | بيانات SVG الأصلية، تم تمريرها بعد الحفظ | SVG |
| `ui` | معلومات الملف المحفوظ بما في ذلك اسم الملف والمجلد الفرعي والنوع لعرضها في واجهة ComfyUI | DICT |

**ملاحظة:** تقوم هذه العقدة تلقائيًا بتضمين بيانات وصفية لسير العمل (التلقين ومعلومات PNG الإضافية) في ملف SVG عند توفّرها. تُدرج البيانات الوصفية كقسم CDATA داخل عنصر البيانات الوصفية في SVG. تُحفظ الملفات باستخدام النمط `filename_prefix_00001_.svg`؛ وعند معالجة دفعة، يُستبدل `%batch_num%` في البادئة بمؤشر عنصر الدفعة الحالي.
