# Luma Ray 3.2 تحرير الفيديو

## نظرة عامة

تعيد هذه العقدة تصيير فيديو موجود باستخدام Luma Ray 3.2 وفق موجّه جديد، مما يتيح لك إعادة تصميم النمط أو الإضاءة، أو إضافة عناصر أو إزالتها مع الحفاظ على الحركة الأصلية. يمكن أن تصل مدة الفيديو المصدر إلى 18 ثانية، ويحتفظ الفيديو المعدّل بالطول الأصلي للمصدر.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `video` | الفيديو المصدر المراد تعديله. حتى 18 ثانية. | VIDEO | نعم | - |
| `prompt` | يصف التعديل المطلوب. | STRING | نعم | - |
| `resolution` | دقة الإخراج للفيديو المعدّل. (الافتراضي: "720p") | COMBO | نعم | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `strength` | مدى قوة الحفاظ على المصدر مقابل إعادة تخيله. يترك "auto" لـ Ray 3.2 الاختيار؛ تمثل adhere_* أعلى درجة حفاظ، وflex_* خيارًا متوازنًا، وreimagine_* أعلى درجة تغيير. (الافتراضي: "auto") | COMBO | نعم | `"auto"`<br>`"adhere_1"`<br>`"adhere_2"`<br>`"adhere_3"`<br>`"flex_1"`<br>`"flex_2"`<br>`"flex_3"`<br>`"reimagine_1"`<br>`"reimagine_2"`<br>`"reimagine_3"` |
| `seed` | البذرة لضمان قابلية إعادة الإنتاج. | INT | نعم | - |

**ملاحظة:** يجب أن يتراوح طول `prompt` بين 1 و6000 حرف. ويجب ألا تتجاوز مدة الفيديو المصدر 18 ثانية.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `VIDEO` | مخرَج الفيديو المعدّل. | VIDEO |
| `generation_id` | المعرّف الفريد لطلب التوليد. | STRING |
