# Luma Ray 3.2 ویرایش ویدیو

## نمای کلی

این گره یک ویدیوی موجود را با استفاده از Luma Ray 3.2 زیر یک پرامپت جدید بازرندر می‌کند و به شما امکان می‌دهد سبک یا نورپردازی را تغییر دهید و عناصر را اضافه یا حذف کنید، در حالی که حرکت اصلی حفظ می‌شود. ویدیوی منبع می‌تواند تا ۱۸ ثانیه باشد و ویدیوی ویرایش‌شده طول اصلی منبع را حفظ می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | ویدیوی منبع برای ویرایش. حداکثر ۱۸ ثانیه. | VIDEO | بله | - |
| `prompt` | ویرایش موردنظر را توصیف می‌کند. | STRING | بله | - |
| `resolution` | وضوح خروجی برای ویدیوی ویرایش‌شده. (پیش‌فرض: "720p") | COMBO | بله | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `strength` | میزان قوی بودن حفظ در برابر بازتصور منبع. "auto" باعث می‌شود Ray 3.2 انتخاب کند؛ adhere_* بیشترین حفظ را دارد، flex_* متعادل است، reimagine_* بیشترین تغییر را ایجاد می‌کند. (پیش‌فرض: "auto") | COMBO | بله | `"auto"`<br>`"adhere_1"`<br>`"adhere_2"`<br>`"adhere_3"`<br>`"flex_1"`<br>`"flex_2"`<br>`"flex_3"`<br>`"reimagine_1"`<br>`"reimagine_2"`<br>`"reimagine_3"` |
| `seed` | دانه برای تکرارپذیری. | INT | بله | - |

**توجه:** طول `prompt` باید بین ۱ و ۶۰۰۰ کاراکتر باشد. مدت‌زمان ویدیوی منبع نباید از ۱۸ ثانیه بیشتر شود.

## خروجی‌ها

|-------------|-------------|-----------|
| `VIDEO` | خروجی ویدیوی ویرایش‌شده. | VIDEO |
| `generation_id` | شناسه یکتای درخواست تولید. | STRING |
