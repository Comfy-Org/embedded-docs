# Luma Ray 3.2: Редактирование видео

## Обзор

Этот узел повторно рендерит существующее видео с новым промптом с помощью Luma Ray 3.2, позволяя изменять стиль, освещение, добавлять или удалять элементы, сохраняя исходное движение. Исходное видео может быть длительностью до 18 секунд, а отредактированное видео сохраняет исходную длительность.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Исходное видео для редактирования. До 18 секунд. | VIDEO | Да | - |
| `prompt` | Описывает желаемое редактирование. | STRING | Да | - |
| `resolution` | Выходное разрешение для отредактированного видео. (по умолчанию: "720p") | COMBO | Да | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `strength` | Насколько сильно сохранять или переосмысливать исходное видео. `"auto"` позволяет Ray 3.2 выбрать; `adhere_*` сохраняет в наибольшей степени, `flex_*` — сбалансированный вариант, `reimagine_*` изменяет в наибольшей степени. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"adhere_1"`<br>`"adhere_2"`<br>`"adhere_3"`<br>`"flex_1"`<br>`"flex_2"`<br>`"flex_3"`<br>`"reimagine_1"`<br>`"reimagine_2"`<br>`"reimagine_3"` |
| `seed` | Сид для воспроизводимости. | INT | Да | - |

**Примечание:** `prompt` должен содержать от 1 до 6000 символов. Исходное видео не должно превышать 18 секунд по длительности.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Отредактированное видео на выходе. | VIDEO |
| `generation_id` | Уникальный идентификатор запроса генерации. | STRING |
