# Luma Ray 3.2: Редактирование видео

## Обзор

Этот узел повторно рендерит существующее видео на основе нового запроса с помощью Luma Ray 3.2, позволяя изменять стиль, переосвещать, добавлять или удалять элементы, сохраняя исходное движение. Исходное видео может быть длиной до 18 секунд, а отредактированное видео сохраняет исходную длину.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Исходное видео для редактирования. Длительностью до 18 секунд. | VIDEO | Да | - |
| `prompt` | Описание желаемого изменения. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. (по умолчанию: "720p") | COMBO | Да | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `strength` | Насколько сильно сохранять источник по сравнению с его переосмыслением. «auto» позволяет Ray 3.2 выбрать автоматически; adhere_* сохраняет максимально, flex_* — сбалансированно, reimagine_* — изменяет сильнее всего. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"adhere_1"`<br>`"adhere_2"`<br>`"adhere_3"`<br>`"flex_1"`<br>`"flex_2"`<br>`"flex_3"`<br>`"reimagine_1"`<br>`"reimagine_2"`<br>`"reimagine_3"` |
| `seed` | Сид для воспроизводимости результатов. | INT | Да | - |

**Примечание:** `prompt` должен содержать от 1 до 6000 символов. Исходное видео не должно превышать 18 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Выходное отредактированное видео. | VIDEO |
| `generation_id` | Уникальный идентификатор запроса на генерацию. | STRING |
