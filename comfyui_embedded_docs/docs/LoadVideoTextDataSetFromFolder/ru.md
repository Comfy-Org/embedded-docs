# Загрузить Видео-Текст (из папки)

Этот узел загружает набор данных из видео-текстовых пар из выбранной подпапки во входном каталоге ComfyUI и возвращает их в виде двух списков: видео и текстовых подписей. Видеозаписи представляют собой ленивые ссылки, поэтому кадры декодируются только тогда, когда они требуются последующему узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV. Подписи считываются из файлов `.txt`, которые имеют то же имя, что и каждый видеофайл.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `folder` | Папка, содержащая видеофайлы и .txt подписи. | COMBO | Да | Все подпапки внутри входного каталога ComfyUI (динамический список) |

Примечания:
- Выбранная папка должна быть подпапкой входного каталога ComfyUI; пути, ведущие за её пределы, отклоняются.
- Если папка не содержит файлов с поддерживаемым видео-расширением, узел выдаёт ошибку.
- Вложенные папки, имя которых начинается с числа, за которым следует подчёркивание (например, `5_classname/`, как используется в инструментах вроде kohya-ss/sd-scripts), также поддерживаются: каждый видеофайл внутри такой папки включается в набор данных столько раз, сколько указано в этом префиксе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `videos` | Ленивые ссылки на видео; кадры декодируются только при необходимости последующими узлами. По одной записи на каждый видеофайл, найденный в папке. | VIDEO (list) |
| `texts` | Список текстовых подписей. По одной подписи на видео; если для видео нет соответствующего файла `.txt`, его подпись — пустая строка. | STRING (list) |
