# Загрузить Видео-Текст (из папки)

Этот узел загружает набор данных из видеофайлов и соответствующих им текстовых подписей из указанной вложенной папки внутри директории ввода ComfyUI. Он возвращает два списка: отложенные ссылки на видео (кадры декодируются только при необходимости в последующих узлах) и связанные с ними подписи. Узел поддерживает распространённые видеоформаты, такие как MP4, AVI, MOV, WEBM, MKV и FLV, а также может обрабатывать вложенные структуры папок с префиксами повторения (например, `5_classname/`), используемыми в таких инструментах, как kohya‑ss/sd‑scripts.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `папка` | Вложенная папка, содержащая видеофайлы и файлы подписей `.txt`. Выберите из доступных вложенных папок в директории ввода ComfyUI. | STRING | Да | Combo: динамический список всех поддиректорий внутри папки ввода ComfyUI |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `videos` | Отложенные ссылки на загруженные видеофайлы. Кадры декодируются только при подключении к последующему узлу, который их обрабатывает. Каждый элемент соответствует видео из входной папки. | VIDEO (list) |
| `texts` | Список текстовых подписей, по одной на каждое видео. Если для видео нет соответствующего файла `.txt`, его подпись — пустая строка. | STRING (list) |
