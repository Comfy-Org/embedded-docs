# Загрузить Видео-Текст (из папки)

Этот узел загружает видеофайлы и соответствующие им текстовые подписи из папки внутри каталога input ComfyUI и возвращает их в виде двух списков: видео и подписей. Видеозаписи являются ленивыми ссылками, поэтому кадры декодируются только тогда, когда они понадобятся нижестоящему узлу. Поддерживаются форматы MP4, AVI, MOV, WEBM, MKV и FLV, а также вложенные папки с префиксом количества повторов (например, `5_classname/`, как используется в таких инструментах, как kohya-ss/sd-scripts).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `папка` | Папка, содержащая видеофайлы и `.txt`-подписи. | COMBO | Да | Динамически перечисляет все подпапки внутри каталога input ComfyUI |

Выбранная папка должна быть подпапкой каталога input ComfyUI; имя папки, ведущее за пределы этого каталога, вызывает ошибку. Если выбранная папка не содержит файлов с поддерживаемым расширением видео (MP4, AVI, MOV, WEBM, MKV, FLV), узел вызывает ошибку. Для вложенных папок, имя которых начинается с числа, за которым следует подчёркивание (например, `5_classname`), каждое видео внутри такой папки включается в набор данных столько раз, сколько указано в этом префиксе. Подпись каждого видео считывается из файла `.txt` с тем же базовым именем; если соответствующего файла `.txt` не существует, подпись представляет собой пустую строку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `videos` | Ленивые ссылки на видео; кадры декодируются только тогда, когда они понадобятся нижестоящим узлам. По одной записи на каждый найденный в папке видеофайл. | VIDEO (list) |
| `texts` | Список текстовых подписей. По одной подписи на видео; если для видео нет соответствующего файла `.txt`, его подпись — пустая строка. | STRING (list) |
