# Загрузить Видео-Текст (из папки)

Этот узел загружает видеофайлы и связанные с ними текстовые подписи из выбранной вложенной папки во входной директории ComfyUI и возвращает их в виде двух списков: видеозаписей и подписей. Видеозаписи передаются как ленивые ссылки, поэтому кадры декодируются только тогда, когда они нужны нижестоящему узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV. Также поддерживаются вложенные папки с префиксом количества повторов (например, `5_classname/`, как в инструментах типа kohya-ss/sd-scripts).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `папка` | Папка, содержащая видеофайлы и текстовые подписи `.txt`. | COMBO | Да | Доступно несколько вариантов: динамически перечисляются все вложенные папки во входной директории ComfyUI |

Выбранная папка должна быть вложенной папкой входной директории ComfyUI; если указанное имя папки приводит к пути за пределами этой директории, узел выдаёт ошибку. Если в выбранной папке нет файлов с поддерживаемым видео-расширением (MP4, AVI, MOV, WEBM, MKV, FLV), узел выдаёт ошибку. Для вложенных папок, имя которых начинается с числа, за которым следует знак подчёркивания (например, `5_classname`), каждое видео внутри такой папки включается в набор данных указанное число раз. Подпись для каждого видео считывается из файла `.txt` с тем же базовым именем; если соответствующего файла `.txt` нет, подпись представляет собой пустую строку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `видео` | Ленивые ссылки на видео; кадры декодируются только при необходимости в нижестоящих узлах. По одной записи на каждый видеофайл, найденный в папке. | VIDEO (list) |
| `тексты` | Список текстовых подписей. По одной подписи на видео; если для видео нет соответствующего файла `.txt`, его подпись — пустая строка. | STRING (list) |
