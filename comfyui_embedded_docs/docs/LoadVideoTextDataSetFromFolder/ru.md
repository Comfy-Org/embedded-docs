# Загрузить Видео-Текст (из папки)

Этот узел загружает видеофайлы и связанные с ними текстовые подписи из выбранной вложенной папки внутри директории ввода ComfyUI и возвращает их в виде двух списков: видео и подписи. Видеоэлементы — это ленивые ссылки, поэтому кадры декодируются только тогда, когда они нужны нижестоящему узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV. Также поддерживаются вложенные папки с префиксом количества повторов (например, `5_classname/`, как используется в таких инструментах, как kohya-ss/sd-scripts).

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `папка` | Папка, содержащая видеофайлы и подписи .txt. | STRING | Да | Combo: динамический список всех вложенных папок внутри директории ввода ComfyUI |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
Если в выбранной папке нет файлов с поддерживаемым видео-расширением, узел вызывает ошибку. Для вложенных папок, имя которых начинается с числа, за которым следует подчеркивание (например, `5_classname`), каждое видео внутри такой папки включается в набор данных столько раз, сколько указано этим префиксом.
|------------|----------|------------|
| `videos` | Ленивые ссылки на видео; кадры декодируются только при необходимости ниже по потоку. По одной записи на каждый видеофайл, найденный в папке. | VIDEO (list) |
| `texts` | Список текстовых подписей. По одной подписи на видео; если для видео нет соответствующего файла `.txt`, его подпись — пустая строка. | STRING (list) |
