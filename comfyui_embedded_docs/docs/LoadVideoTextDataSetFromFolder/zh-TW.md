# 載入影片-文字（資料夾）

此節點會從 ComfyUI 輸入目錄中選定的子資料夾載入影片檔案及其相關的文字說明，並以兩個清單回傳：`videos` 和 `texts`。影片條目屬於惰性參考，只有在下游節點需要時才會解碼影格。支援的格式為 MP4、AVI、MOV、WEBM、MKV 和 FLV。也支援帶有重複次數前綴的巢狀資料夾（例如 `5_classname/`，如 kohya-ss/sd-scripts 等工具所用）。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `資料夾` | 包含影片檔案和 .txt 文字說明的資料夾。 | COMBO | 是 | 多個選項可用：動態列出 ComfyUI 輸入目錄中的所有子資料夾 |

所選資料夾必須是 ComfyUI 輸入目錄的子資料夾；若資料夾名稱解析到該目錄之外，則會引發錯誤。如果所選資料夾中沒有任何支援的影片副檔名（MP4、AVI、MOV、WEBM、MKV、FLV）檔案，節點會引發錯誤。對於名稱以數字加底線開頭的巢狀資料夾（例如 `5_classname`），該資料夾中的每個影片都會依照前綴指定的次數包含在資料集中。每個影片的文字說明會從同一個主檔名的 `.txt` 檔案讀取；如果沒有相符的 `.txt` 檔案，則文字說明為空字串。
