# 載入影片-文字（資料夾）

此節點從 ComfyUI 輸入目錄中所選的子資料夾載入視頻-文本對資料集，並將其作為兩個列表返回：視頻與文字說明。視頻條目為惰性參考，因此僅在下游節點需要時才解碼幀。支援的格式包括 MP4、AVI、MOV、WEBM、MKV 與 FLV。文字說明會從與每個視頻檔案同名的 `.txt` 檔案中讀取。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `folder` | 包含視頻檔案與 .txt 文字說明的資料夾。 | COMBO | 是 | ComfyUI 輸入目錄內的所有子資料夾（動態列表） |

備註：
- 選取的資料夾必須是 ComfyUI 輸入目錄的子資料夾；解析到該目錄之外的路徑將被拒絕。
- 如果資料夾中沒有包含受支援副檔名的視頻檔案，節點會引發錯誤。
- 也支援名稱以數字後接底線開頭的巢狀資料夾（例如 `5_classname/`，如 kohya-ss/sd-scripts 等工具所用）：該資料夾內的每個視頻會依前綴指定的次數納入資料集。

## 輸出

| 輸出名 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `videos` | 惰性視頻參考；僅在下游需要時才解碼幀。資料夾中找到的每個視頻檔案對應一個條目。 | VIDEO (list) |
| `texts` | 文字說明列表。每個視頻對應一個說明；若視頻沒有相符的 `.txt` 檔案，其說明為空字串。 | STRING (list) |
