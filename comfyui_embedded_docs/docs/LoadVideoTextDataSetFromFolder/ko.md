# 비디오-텍스트 불러오기 (폴더에서)

이 노드는 ComfyUI 입력 디렉토리에서 선택한 하위 폴더에 있는 비디오-텍스트 쌍 데이터셋을 불러와서 두 개의 목록(비디오 목록과 텍스트 캡션 목록)으로 반환합니다. 비디오 항목은 지연 참조 방식이므로 프레임은 다운스트림 노드가 필요로 할 때만 디코딩됩니다. 지원 형식은 MP4, AVI, MOV, WEBM, MKV, FLV입니다. 캡션은 각 비디오 파일과 같은 이름을 가진 `.txt` 파일에서 읽어옵니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `folder` | 비디오 파일과 `.txt` 캡션이 포함된 폴더입니다. | COMBO | 예 | ComfyUI 입력 디렉토리 안의 모든 하위 폴더 (동적 목록) |

참고:
- 선택한 폴더는 ComfyUI 입력 디렉토리의 하위 폴더여야 합니다. 해당 디렉토리 밖으로 확인되는 경로는 거부됩니다.
- 폴더에 지원되는 비디오 확장자를 가진 파일이 없으면 노드는 오류를 발생시킵니다.
- 이름이 숫자 뒤에 밑줄로 시작하는 중첩 폴더(예: `5_classname/`, kohya-ss/sd-scripts와 같은 도구에서 사용됨)도 지원됩니다. 해당 폴더 안의 각 비디오는 접두사가 나타내는 횟수만큼 데이터셋에 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `videos` | 지연 비디오 참조입니다. 프레임은 다운스트림에서 필요할 때만 디코딩됩니다. 폴더에서 발견된 각 비디오 파일마다 하나의 항목이 있습니다. | VIDEO (목록) |
| `texts` | 텍스트 캡션 목록입니다. 비디오마다 캡션 하나씩 있습니다. 비디오에 해당하는 `.txt` 파일이 없으면 캡션은 빈 문자열입니다. | STRING (목록) |
