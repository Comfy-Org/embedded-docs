# 加载视频-文本（来自文件夹）

此节点从 ComfyUI 输入目录中的选定子文件夹加载视频-文本对数据集，并将其作为两个列表返回：视频列表和文本字幕列表。视频条目是惰性引用，因此只有在下游节点需要时才会解码帧。支持的格式为 MP4、AVI、MOV、WEBM、MKV 和 FLV。字幕从与每个视频文件同名的 `.txt` 文件中读取。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `folder` | 包含视频文件和 .txt 字幕的文件夹。 | COMBO | 是 | ComfyUI 输入目录内的所有子文件夹（动态列表） |

备注：
- 所选文件夹必须是 ComfyUI 输入目录的子文件夹；解析到该目录之外的路径将被拒绝。
- 如果文件夹中没有包含受支持视频扩展名的文件，节点将引发错误。
- 名称以数字加下划线开头的嵌套文件夹（例如 `5_classname/`，如 kohya-ss/sd-scripts 等工具使用）也受支持：该文件夹中的每个视频都会根据该前缀给定的次数被包含在数据集中。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `videos` | 惰性视频引用；帧仅在需要时于下游解码。文件夹中找到的每个视频文件对应一个条目。 | VIDEO（列表） |
| `texts` | 文本字幕列表。每个视频对应一条字幕；如果某个视频没有匹配的 `.txt` 文件，则其字幕为空字符串。 | STRING（列表） |
