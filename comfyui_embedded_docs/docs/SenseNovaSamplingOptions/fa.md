# SenseNovaSamplingOptions

گزینه‌های نمونه‌برداری SenseNova، فلو شیفت SenseNova را روی یک مدل تنظیم می‌کند. این گره مدل ورودی را شبیه‌سازی می‌کند، با استفاده از مقدار فلو شیفت انتخاب‌شده یک پیکربندی نمونه‌برداری مدل SenseNova را به آن متصل می‌کند و مدل وصله‌شده را برای استفاده در هنگام نمونه‌برداری بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که پیکربندی نمونه‌برداری فلو شیفت SenseNova روی آن اعمال می‌شود. | MODEL | بله | - |
| `shift` | مقدار فلو شیفتی که روی نمونه‌برداری مدل SenseNova تنظیم می‌شود (پیش‌فرض: 3.0؛ گام رابط کاربری: 0.01). | FLOAT | بله | بدون حداقل یا حداکثر تعریف‌شده |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | شبیه‌سازی از مدل ورودی که فلو شیفت SenseNova روی پیکربندی نمونه‌برداری آن اعمال شده است. | MODEL |
