# گزینه‌های نمونه‌گیری SenseNova

گزینه‌های نمونه‌گیری SenseNova، شیفت جریان SenseNova را روی یک مدل تنظیم می‌کند. این گره مدل ورودی را کلون می‌کند، پیکربندی نمونه‌گیری مدل SenseNova را با استفاده از مقدار شیفت جریان انتخاب‌شده به آن ضمیمه می‌کند و مدل وصله‌شده را برای استفاده در زمان نمونه‌گیری بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که پیکربندی نمونه‌گیری شیفت جریان SenseNova روی آن اعمال می‌شود. | MODEL | بله | - |
| `shift` | مقدار شیفت جریان برای تنظیم روی نمونه‌گیری مدل SenseNova (پیش‌فرض: 3.0؛ گام رابط کاربری: 0.01). | FLOAT | بله | حداقل یا حداکثر تعریف نشده است |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `MODEL` | یک کلون از مدل ورودی که شیفت جریان SenseNova روی پیکربندی نمونه‌گیری آن اعمال شده است. | MODEL |
