# Параметры сэмплирования SenseNova

SenseNova Sampling Options задаёт flow shift SenseNova для модели. Он клонирует входную модель, прикрепляет конфигурацию сэмплирования модели SenseNova с выбранным значением flow shift и возвращает пропатченную модель для использования при сэмплировании.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, к которой применяется конфигурация сэмплирования с flow shift SenseNova. | MODEL | Да | - |
| `shift` | Значение flow shift, устанавливаемое для сэмплирования модели SenseNova (по умолчанию: 3.0; шаг в UI: 0.01). | FLOAT | Да | Минимум и максимум не определены |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Клон входной модели с применённым flow shift SenseNova к её конфигурации сэмплирования. | MODEL |
