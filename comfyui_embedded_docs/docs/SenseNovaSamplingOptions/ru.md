# SenseNovaSamplingOptions

SenseNova Sampling Options задаёт сдвиг потока SenseNova для модели. Он клонирует входную модель, добавляет конфигурацию сэмплирования модели SenseNova с использованием выбранного значения сдвига потока и возвращает модифицированную модель для использования во время сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|----------|----------|------------|-------------|----------|
| `model` | Модель, к которой применяется конфигурация сэмплирования SenseNova со сдвигом потока. | MODEL | Да | - |
| `shift` | Значение сдвига потока для конфигурации сэмплирования модели SenseNova (по умолчанию: 3.0; шаг в интерфейсе: 0.01). | FLOAT | Да | Минимум и максимум не заданы |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| MODEL | Клон входной модели, к конфигурации сэмплирования которой применён сдвиг потока SenseNova. | MODEL |
