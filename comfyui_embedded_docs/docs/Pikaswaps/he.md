# Pikaswaps

הצומת Pika Swaps מחליף אובייקטים או אזורים בווידאו שלך בתמונה חדשה. אתה מגדיר את האזורים להחלפה באמצעות מסכה, והצומת מחליף באופן חלק את התוכן שצוין לאורך רצף הווידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `video` | הווידאו שבו יש להחליף אובייקט. | VIDEO | כן | - |
| `image` | התמונה המשמשת להחלפת האובייקט הממוסך בווידאו. | IMAGE | כן | - |
| `mask` | השתמש במסכה כדי להגדיר אזורים בווידאו להחלפה. | MASK | כן | - |
| `prompt_text` | הנחיית טקסט המתארת את ההחלפה הרצויה. | STRING | כן | - |
| `negative_prompt` | הנחיית טקסט המתארת ממה להימנע בהחלפה. | STRING | כן | - |
| `seed` | ערך זרע אקראי לקבלת תוצאות עקביות. | INT | כן | 0 עד 4294967295 |

**הערה:** צומת זה דורש שכל פרמטרי הקלט יסופקו. `video`, `image` ו-`mask` פועלים יחד כדי להגדיר את פעולת ההחלפה, כאשר המסכה מציינת אילו אזורים בווידאו יוחלפו בתמונה שסופקה.
