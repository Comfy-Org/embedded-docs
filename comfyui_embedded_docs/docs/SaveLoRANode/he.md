# SaveLoRANode

צומת SaveLoRA שומר מודלים מסוג LoRA (התאמת דירוג נמוך) בתיקיית הפלט. הוא מקבל מודל LoRA כקלט ויוצר קובץ safetensors עם שם קובץ שנוצר אוטומטית. ניתן להתאים את קידומת שם הקובץ, ובאופן אופציונלי לכלול את מספר שלבי האימון בשם הקובץ לארגון טוב יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `lora` | מודל ה-LoRA לשמירה. אין להשתמש במודל עם שכבות LoRA. | LORA_MODEL | כן | - |
| `prefix` | הקידומת לשימוש עבור קובץ ה-LoRA הנשמר (ברירת מחדל: "loras/ComfyUI_trained_lora"). | STRING | כן | - |
| `steps` | אופציונלי: מספר שלבי האימון של ה-LoRA, המשמש לשם הקובץ הנשמר. | INT | לא | - |
