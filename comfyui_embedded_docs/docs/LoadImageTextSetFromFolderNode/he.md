# LoadImageTextSetFromFolderNode

טוען אצוות תמונות ואת כיתובי הטקסט המתאימים להן מתיקייה שצוינה למטרות אימון. הצומת מחפש אוטומטית קבצי תמונה וקבצי טקסט של כיתובים המשויכים אליהם, מעבד את התמונות בהתאם להגדרות שינוי הגודל שצוינו, ומקודד את הכיתובים באמצעות מודל ה-CLIP שסופק.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `folder` | התיקייה שממנה לטעון תמונות. | STRING | כן | - |
| `clip` | מודל ה-CLIP המשמש לקידוד הטקסט. | CLIP | כן | - |
| `resize_method` | השיטה המשמשת לשינוי גודל התמונות (ברירת מחדל: "None"). | COMBO | לא | "None"<br>"Stretch"<br>"Crop"<br>"Pad" |
| `width` | הרוחב שאליו לשנות את גודל התמונות. -1 משמעו להשתמש ברוחב המקורי (ברירת מחדל: -1). | INT | לא | -1 עד 10000 |
| `height` | הגובה שאליו לשנות את גודל התמונות. -1 משמעו להשתמש בגובה המקורי (ברירת מחדל: -1). | INT | לא | -1 עד 10000 |

**הערה:** קלט ה-CLIP חייב להיות תקין ואינו יכול להיות None. אם מודל ה-CLIP מגיע מצומת טעינת checkpoint, ודא שה-checkpoint מכיל מודל CLIP או מקודד טקסט תקין.

**הערה לגבי מבנה התיקיות:** הצומת תומך במבנה התיקיות של kohya-ss/sd-scripts. אם שם תת-תיקייה מתחיל במספר ואחריו קו תחתון (למשל, `5_myclass`), המספר הזה משמש כמספר חזרות, והתמונות שבתוך תת-התיקייה ייטענו כמספר החזרות הזה.
