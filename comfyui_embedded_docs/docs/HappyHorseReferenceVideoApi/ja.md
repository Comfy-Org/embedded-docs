# HappyHorse 参照から動画へ

このノードは、HappyHorse モデルを使用して参照画像から人物や物体を特徴とする動画を生成します。単一キャラクターの演技や複数キャラクターのインタラクションに対応しています。参照画像はアップロードされ、生成された動画内のキャラクターを表現するために使用されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 生成に使用する HappyHorse 参照画像から動画へのモデルです。 | DYNAMIC_COMBO | はい | `"happyhorse-1.1-r2v"`<br>`"happyhorse-1.0-r2v"` |
| `シード` | 生成に使用するシード値です（デフォルト: 0）。生成のたびに自動的に変更するように設定できます。 | INT | いいえ | 0 ～ 2147483647 |
| `ウォーターマーク` | 結果に AI 生成の透かしを追加するかどうか（デフォルト: False）。 | BOOLEAN | いいえ | True または False |

### HappyHorse 1.1 入力 (happyhorse-1.1-r2v)

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画を説明するプロンプトです。参照キャラクターを参照するには、「character1」や「character2」などの識別子を使用します。 | STRING | はい | N/A |
| `resolution` | 生成される動画の解像度です。 | COMBO | はい | `"720P"`<br>`"1080P"` |
| `ratio` | 生成される動画のアスペクト比です。 | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"`<br>`"5:4"`<br>`"4:5"` |
| `duration` | 生成される動画の長さ（秒）です（デフォルト: 5）。 | INT | はい | 3 ～ 15 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能なスロット: 動画に登場させる人物または物体の参照画像を 1 ～ 9 枚接続します。少なくとも 1 枚の参照画像を指定する必要があります。 | IMAGE | はい | 1 ～ 9（モデルごと） |

注: 少なくとも 1 枚の参照画像を指定する必要があります。指定しない場合、ノードはエラーを発生します。各参照画像は 400 x 400 ピクセル以上で、アスペクト比が 1:2.5 ～ 2.5:1 の範囲内である必要があります。プロンプトは空にできません。
