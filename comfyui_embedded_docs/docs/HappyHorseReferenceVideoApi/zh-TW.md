# HappyHorse 參考素材轉影片

此節點使用 HappyHorse 模型，從參考影像生成以人物或物體為特色的影片。它支援單一角色表演與多角色互動。參考影像會被上傳並用於代表生成影片中的角色。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成的 HappyHorse 參考轉影片模型。 | DYNAMIC_COMBO | 是 | `"happyhorse-1.1-r2v"`<br>`"happyhorse-1.0-r2v"` |
| `seed` | 用於生成的隨機種子（預設：0）。可設定為在每次生成後自動變更。 | INT | 否 | 0 to 2147483647 |
| `watermark` | 是否在結果中加入 AI 生成的浮水印（預設：False）。 | BOOLEAN | 否 | True or False |
