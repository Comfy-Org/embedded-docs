# HappyHorse تبدیل مرجع به ویدیو

این گره با استفاده از مدل HappyHorse، ویدیویی از یک شخص یا شیء بر اساس تصاویر مرجع تولید می‌کند. از اجرای تک‌شخصیتی و تعاملات چندشخصیتی پشتیبانی می‌کند. تصاویر مرجع بارگذاری شده و برای نمایش شخصیت‌ها در ویدیوی تولیدشده استفاده می‌شوند.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مرجع-به-ویدیوی HappyHorse که برای تولید استفاده می‌شود. | DYNAMIC_COMBO | بله | `"happyhorse-1.1-r2v"`<br>`"happyhorse-1.0-r2v"` |
| `seed` | Seed مورد استفاده برای تولید (پیش‌فرض: 0). می‌توان آن را به‌گونه‌ای تنظیم کرد که پس از هر تولید به‌طور خودکار تغییر کند. | INT | خیر | 0 تا 2147483647 |
| `واترمارک` | آیا یک واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: False). | BOOLEAN | خیر | True یا False |

### ورودی‌های HappyHorse 1.1 (happyhorse-1.1-r2v)

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که ویدیو را توصیف می‌کند. برای اشاره به شخصیت‌های مرجع از شناسه‌هایی مانند 'character1' و 'character2' استفاده کنید. | STRING | بله | N/A |
| `resolution` | رزولوشن ویدیوی تولیدشده. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `ratio` | نسبت تصویر ویدیوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"`<br>`"5:4"`<br>`"4:5"` |
| `duration` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | اسلات قابل گسترش: ۱ تا ۹ تصویر مرجع از شخص یا شیء موردنظر برای نمایش در ویدیو را متصل کنید. حداقل یک تصویر مرجع باید ارائه شود. | IMAGE | بله | 1 تا 9 (به‌ازای هر مدل) |

توجه: حداقل یک تصویر مرجع باید ارائه شود، در غیر این صورت گره خطا ایجاد می‌کند. هر تصویر مرجع باید حداقل 400×400 پیکسل باشد و نسبت تصویری بین 1:2.5 و 2.5:1 داشته باشد. پرامپت نباید خالی باشد.
