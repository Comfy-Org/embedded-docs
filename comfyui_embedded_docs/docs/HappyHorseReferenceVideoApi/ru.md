# HappyHorse: референс в видео

Этот узел генерирует видео с человеком или объектом по референсным изображениям с использованием модели HappyHorse. Поддерживаются выступления одного персонажа и взаимодействие нескольких персонажей. Референсные изображения загружаются и используются для представления персонажей в сгенерированном видео.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель HappyHorse reference-to-video для генерации. | COMBO | Да | `"happyhorse-1.1-r2v"`<br>`"happyhorse-1.0-r2v"` |
| `seed` | Сид для генерации (по умолчанию: 0). Можно задать автоматическое изменение после каждой генерации. | INT | Нет | 0 to 2147483647 |
| `watermark` | Добавлять ли AI-водяной знак к результату (по умолчанию: False). | BOOLEAN | Нет | True или False |

### Входные параметры HappyHorse 1.1 (happyhorse-1.1-r2v)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий видео. Используйте идентификаторы, такие как 'character1' и 'character2', для обращения к референсным персонажам. | STRING | Да | N/A |
| `resolution` | Разрешение генерируемого видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `ratio` | Соотношение сторон генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"`<br>`"5:4"`<br>`"4:5"` |
| `duration` | Продолжительность видео в секундах (по умолчанию: 5). | INT | Да | 3 to 15 |

### Входные параметры HappyHorse 1.0 (happyhorse-1.0-r2v)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий видео. Используйте идентификаторы, такие как 'character1' и 'character2', для обращения к референсным персонажам. | STRING | Да | N/A |
| `resolution` | Разрешение генерируемого видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `ratio` | Соотношение сторон генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Продолжительность видео в секундах (по умолчанию: 5). | INT | Да | 3 to 15 |

### Входные параметры референсов

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до 9 референсных изображений человека или объекта для отображения в видео. Необходимо указать хотя бы одно референсное изображение. | IMAGE | Да | от 1 до 9 (на модель) |

Примечание: необходимо указать хотя бы одно референсное изображение, иначе узел выдаст ошибку. Каждое референсное изображение должно быть не менее 400 x 400 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. Промпт не должен быть пустым.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный видеофайл. | VIDEO |
