# TextEncodeZImageOmni

گره «TextEncodeZImageOmni» یک گره پیشرفته‌ی کاندیشنینگ است که یک متن پرامپت را همراه با تصاویر مرجع اختیاری به فرمت کاندیشنینگ مناسب برای مدل‌های تولید تصویر کدگذاری می‌کند. این گره می‌تواند تا سه تصویر را پردازش کند، در صورت نیاز آن‌ها را با انکودر بینایی و/یا VAE کدگذاری کرده و لاتنت‌های مرجع تولید کند، و این ارجاعات بصری را با استفاده از یک ساختار قالبی مشخص با پرامپت متنی ترکیب می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و کدگذاری پرامپت متنی. | CLIP | بله |  |
| `image_encoder` | یک مدل انکودر بینایی اختیاری. در صورت ارائه، برای کدگذاری تصاویر ورودی استفاده می‌شود و بردارهای حاصل به کاندیشنینگ اضافه می‌شوند. | CLIPVision | خیر |  |
| `prompt` | پرامپت متنی که باید کدگذاری شود. این فیلد از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `auto_resize_images` | وقتی فعال باشد (پیش‌فرض: True)، تصاویر ورودی بر اساس مساحت پیکسلی آن‌ها قبل از ارسال به VAE برای کدگذاری، به‌طور خودکار تغییر اندازه می‌دهند. این یک تنظیم پیشرفته است. | BOOLEAN | خیر |  |
| `vae` | یک مدل VAE اختیاری. در صورت ارائه، برای کدگذاری تصاویر ورودی به بازنمایی‌های لاتنت استفاده می‌شود که به عنوان لاتنت‌های مرجع به کاندیشنینگ اضافه می‌گردند. | VAE | خیر |  |
| `image1` | اولین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `image2` | دومین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `image3` | سومین تصویر مرجع اختیاری. | IMAGE | خیر |  |

**توجه:** این گره حداکثر می‌تواند سه تصویر (`image1`، `image2`، `image3`) را بپذیرد. ورودی‌های `image_encoder` و `vae` تنها در صورتی استفاده می‌شوند که حداقل یک تصویر ارائه شده باشد. وقتی `auto_resize_images` برابر True باشد و یک `vae` متصل باشد، تصاویر قبل از کدگذاری به‌گونه‌ای تغییر اندازه می‌دهند که مساحت کل پیکسل‌ها نزدیک به ۱۰۲۴×۱۰۲۴ پیکسل باشد و ابعاد به مضربی از ۸ گرد شوند. اگر هیچ تصویری ارائه نشود، گره پرامپت متنی را بدون هیچ ارجاع بصری کدگذاری می‌کند.
