# TextEncodeZImageOmni

TextEncodeZImageOmni یک پرامپت متنی را همراه با حداکثر سه تصویر مرجع اختیاری به قالب conditioning برای مدل‌های تولید تصویر رمزگذاری می‌کند. پرامپت با مدل CLIP توکن‌بندی و رمزگذاری می‌شود، و هر تصویر متصل‌شده می‌تواند به‌صورت اختیاری توسط یک رمزگذار بینایی و/یا یک VAE پردازش شود تا ارجاعات بصری در کنار متن تعبیه شوند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکن‌بندی و رمزگذاری پرامپت متنی استفاده می‌شود. | CLIP | بله |  |
| `image_encoder` | یک مدل رمزگذار بینایی اختیاری. در صورت ارائه، برای رمزگذاری تصاویر ورودی استفاده می‌شود و امبدینگ‌های حاصل به conditioning اضافه می‌شوند. | CLIP_VISION | خیر |  |
| `prompt` | پرامپت متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `auto_resize_images` | وقتی فعال باشد (پیش‌فرض: True)، تصاویر ورودی قبل از رمزگذاری VAE به‌صورت خودکار تغییر اندازه داده می‌شوند تا مساحت کل پیکسل‌های آن‌ها نزدیک به 1024x1024 باشد، و ابعاد به مضرب‌های 8 گرد می‌شوند. | BOOLEAN | بله | True<br>False |
| `vae` | یک مدل VAE اختیاری. در صورت ارائه، برای رمزگذاری تصاویر ورودی به نمایش‌های نهفته (latent) استفاده می‌شود که به‌عنوان latentهای مرجع به conditioning اضافه می‌شوند. | VAE | خیر |  |
| `image1` | اولین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `image2` | دومین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `image3` | سومین تصویر مرجع اختیاری. | IMAGE | خیر |  |

**توجه:** گره حداکثر سه تصویر (`image1`، `image2`، `image3`) را می‌پذیرد. ورودی‌های `image_encoder` و `vae` فقط زمانی استفاده می‌شوند که حداقل یک تصویر ارائه شده باشد؛ وقتی هر دو متصل باشند، هر تصویر توسط هر دو پردازش می‌شود. وقتی `auto_resize_images` برابر True باشد و یک `vae` متصل باشد، تصاویر قبل از رمزگذاری طوری تغییر اندازه داده می‌شوند که مساحت کل پیکسل‌هایشان نزدیک به 1024x1024 باشد. اگر هیچ تصویری ارائه نشود، فقط پرامپت متنی رمزگذاری می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |

| `CONDITIONING` | خروجی conditioning نهایی. شامل پرامپت متنی رمزگذاری‌شده است و زمانی که تصاویر ارائه شوند، ممکن است شامل امبدینگ‌های تصویر رمزگذاری‌شده، latentهای مرجع، و امبدینگ‌های متنی اضافی مشتق‌شده از قالب جانگهدار تصویر باشد. | CONDITIONING |
