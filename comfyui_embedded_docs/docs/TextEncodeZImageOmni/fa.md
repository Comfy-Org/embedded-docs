# TextEncodeZImageOmni

TextEncodeZImageOmni یک پرامپت متنی را همراه با حداکثر سه تصویر مرجع اختیاری به قالبی برای شرطی‌سازی مدل‌های تولید تصویر رمزگذاری می‌کند. پرامپت با مدل CLIP توکنیزه و رمزگذاری می‌شود و هر تصویر متصل می‌تواند به‌صورت اختیاری توسط یک رمزگذار بینایی و/یا یک VAE پردازش شود تا ارجاع‌های تصویری در کنار متن جاسازی شوند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنیزه کردن و رمزگذاری پرامپت متنی. | CLIP | بله |  |
| `رمزگذار تصویر` | یک مدل رمزگذار بینایی اختیاری. در صورت ارائه، برای رمزگذاری تصاویر ورودی استفاده می‌شود و جاسازی‌های حاصل به شرطی‌سازی اضافه می‌شوند. | CLIP_VISION | خیر |  |
| `پرامپت` | پرامپت متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `تغییر اندازه خودکار تصاویر` | وقتی فعال باشد (پیش‌فرض: True)، تصاویر ورودی قبل از رمزگذاری VAE به‌طور خودکار تغییر اندازه می‌دهند تا مساحت کل پیکسل آن‌ها نزدیک به 1024x1024 باشد و ابعاد به مضربی از 8 گرد شوند. | BOOLEAN | خیر | True<br>False |
| `vae` | یک مدل VAE اختیاری. در صورت ارائه، برای رمزگذاری تصاویر ورودی به نمایش‌های نهفته (latent) استفاده می‌شود که به‌عنوان لاتنت‌های مرجع به شرطی‌سازی اضافه می‌شوند. | VAE | خیر |  |
| `تصویر ۱` | اولین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `تصویر ۲` | دومین تصویر مرجع اختیاری. | IMAGE | خیر |  |
| `تصویر ۳` | سومین تصویر مرجع اختیاری. | IMAGE | خیر |  |

**نکته:** این گره حداکثر سه تصویر (`image1`، `image2`، `image3`) را می‌پذیرد. ورودی‌های `image_encoder` و `vae` فقط زمانی استفاده می‌شوند که حداقل یک تصویر ارائه شده باشد؛ وقتی هر دو متصل باشند، هر تصویر توسط هر دو پردازش می‌شود. وقتی `auto_resize_images` برابر True باشد و یک `vae` متصل باشد، تصاویر قبل از رمزگذاری به‌گونه‌ای تغییر اندازه می‌یابند که مساحت کل پیکسل آن‌ها نزدیک به 1024x1024 باشد.
