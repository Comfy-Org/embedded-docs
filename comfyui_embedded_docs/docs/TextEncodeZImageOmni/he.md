# TextEncodeZImageOmni

TextEncodeZImageOmni מקודד הנחיית טקסט יחד עם עד שלוש תמונות עזר אופציונליות לפורמט התניה עבור מודלים ליצירת תמונות. ההנחיה עוברת טוקניזציה וקידוד באמצעות מודל CLIP, וכל תמונה שמחוברת יכולה לעבור באופן אופציונלי עיבוד על ידי מקודד ראייה ו/או VAE, כך שהפניות חזותיות מוטמעות לצד הטקסט. צומת זה מסומן כניסיוני.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה ולקידוד הנחיית הטקסט. | CLIP | כן |  |
| `image_encoder` | מודל מקודד ראייה אופציונלי. אם הוא מסופק, הוא משמש לקידוד תמונות הקלט, וההטמעות המתקבלות מתווספות להתניה. | CLIP_VISION | לא |  |
| `prompt` | הנחיית הטקסט לקידוד. תומך בקלט רב-שורתי ובהנחיות דינמיות. | STRING | כן |  |
| `auto_resize_images` | כאשר מופעל (ברירת מחדל: True), תמונות הקלט ממותאמות אוטומטית לפני קידוד VAE כך שסך שטח הפיקסלים שלהן יהיה קרוב ל-1024x1024, כאשר הממדים מעוגלים לכפולות של 8. | BOOLEAN | כן | True<br>False |
| `vae` | מודל VAE אופציונלי. אם הוא מסופק, הוא משמש לקידוד תמונות הקלט לייצוגים חבויים (latents), שמתווספים להתניה כ-latents עזר. | VAE | לא |  |
| `image1` | תמונת העזר האופציונלית הראשונה. | IMAGE | לא |  |
| `image2` | תמונת העזר האופציונלית השנייה. | IMAGE | לא |  |
| `image3` | תמונת העזר האופציונלית השלישית. | IMAGE | לא |  |

**הערה:** מספר התמונות המקסימלי שהצומת מקבל הוא שלוש (`image1`, `image2`, `image3`). קלטי `image_encoder` ו-`vae` משמשים רק כאשר מסופקת לפחות תמונה אחת; כאשר שניהם מחוברים, כל תמונה מעובדת על ידי שניהם. כאשר `auto_resize_images` הוא True ו-`vae` מחובר, התמונות ממותאמות כך שסך שטח הפיקסלים שלהן קרוב ל-1024x1024 לפני הקידוד. אם לא מסופקות תמונות, רק הנחיית הטקסט מקודדת.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | פלט ההתניה הסופי. הוא מכיל את הנחיית הטקסט המקודדת, וכאשר מסופקות תמונות, עשוי לכלול הטמעות תמונה מקודדות, latents עזר, והטמעות טקסט נוספות הנגזרות מתבנית מציין המיקום של התמונה. | CONDITIONING |
