# TextEncodeZImageOmni

TextEncodeZImageOmni يقوم بترميز موجه نصي مع ما يصل إلى ثلاث صور مرجعية اختيارية إلى تنسيق تكييف لنماذج توليد الصور. يتم تقسيم الموجه إلى رموز وترميزه باستخدام نموذج CLIP، ويمكن اختياريًا معالجة كل صورة متصلة عبر مُرمِّز رؤية و/أو VAE بحيث تُدمج المراجع البصرية إلى جانب النص. هذه العقدة مُعلَّمة على أنها تجريبية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتقسيم الموجه النصي وترميزه. | CLIP | نعم |  |
| `مُرمّز الصورة` | نموذج مُرمِّز رؤية اختياري. إذا تم توفيره، فسيتم استخدامه لترميز الصور المدخلة، وتُضاف التضمينات الناتجة إلى التكييف. | CLIP_VISION | لا |  |
| `التوجيه` | الموجه النصي المراد ترميزه. يدعم الإدخال متعدد الأسطر والموجهات الديناميكية. | STRING | نعم |  |
| `تغيير حجم الصور تلقائياً` | عند التفعيل (الافتراضي: True)، يُعاد تحجيم الصور المدخلة تلقائيًا قبل ترميز VAE بحيث تكون مساحة البكسل الإجمالية قريبة من 1024×1024، مع تقريب الأبعاد إلى مضاعفات الرقم 8. | BOOLEAN | لا | True<br>False |
| `vae` | نموذج VAE اختياري. إذا تم توفيره، يُستخدم لترميز الصور المدخلة إلى تمثيلات كامنة (latent)، وتُضاف إلى التكييف كمراجع كامنة. | VAE | لا |  |
| `الصورة ١` | الصورة المرجعية الاختيارية الأولى. | IMAGE | لا |  |
| `الصورة ٢` | الصورة المرجعية الاختيارية الثانية. | IMAGE | لا |  |
| `الصورة ٣` | الصورة المرجعية الاختيارية الثالثة. | IMAGE | لا |  |

**ملاحظة:** تقبل العقدة ثلاث صور كحد أقصى (`image1`، `image2`, `image3`). لا تُستخدم مدخلات `image_encoder` و `vae` إلا عند توفير صورة واحدة على الأقل؛ وعند اتصال كلاهما، تتم معالجة كل صورة بواسطة كليهما. عندما يكون `auto_resize_images` على True ويكون `vae` متصلاً، يتم تحجيم الصور بحيث تكون مساحة البكسل الإجمالية قريبة من 1024×1024 قبل الترميز.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | مخرج التكييف النهائي. يحتوي على الموجه النصي المشفر، وعند توفير الصور، قد يشمل تضمينات الصور المشفرة، والمراجع الكامنة، وتضمينات نصية إضافية مستمدة من قالب نائب الصورة. | CONDITIONING |
