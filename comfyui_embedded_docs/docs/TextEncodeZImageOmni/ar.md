# TextEncodeZImageOmni

تقوم عقدة TextEncodeZImageOmni بترميز موجّه نصي مع ما يصل إلى ثلاث صور مرجعية اختيارية إلى تنسيق تكييف لنماذج توليد الصور. يُقسَّم الموجّه النصي إلى رموز (tokens) ويُرمَّز باستخدام نموذج CLIP، ويمكن اختياريًا معالجة كل صورة موصولة بواسطة مُرمِّز رؤية و/أو VAE بحيث تُدمج المراجع البصرية إلى جانب النص. هذه العقدة مصنّفة كتجريبية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتقسيم موجّه النص إلى رموز وترميزه. | CLIP | نعم |  |
| `image_encoder` | نموذج مُرمِّز رؤية اختياري. إذا تم توفيره، يُستخدم لترميز الصور المُدخلة، وتُضاف التضمينات الناتجة إلى التكييف. | CLIP_VISION | لا |  |
| `prompt` | موجّه النص المراد ترميزه. يدعم الإدخال متعدد الأسطر والموجّهات الديناميكية. | STRING | نعم |  |
| `auto_resize_images` | عند تمكينه (الافتراضي: True)، يتم تغيير حجم الصور المُدخلة تلقائيًا قبل ترميز VAE بحيث تقترب مساحة البكسل الإجمالية لها من 1024x1024، مع تقريب الأبعاد إلى مضاعفات 8. | BOOLEAN | نعم | True<br>False |
| `vae` | نموذج VAE اختياري. إذا تم توفيره، يُستخدم لترميز الصور المُدخلة إلى تمثيلات كامنة، تُضاف إلى التكييف كعناصر كامنة مرجعية. | VAE | لا |  |
| `image1` | الصورة المرجعية الاختيارية الأولى. | IMAGE | لا |  |
| `image2` | الصورة المرجعية الاختيارية الثانية. | IMAGE | لا |  |
| `image3` | الصورة المرجعية الاختيارية الثالثة. | IMAGE | لا |  |

**ملاحظة:** تقبل العقدة ثلاث صور كحد أقصى (`image1`، `image2`، `image3`). يتم استخدام مدخلي `image_encoder` و`vae` فقط عند توفير صورة واحدة على الأقل؛ وعند توصيلهما معًا، تتم معالجة كل صورة بواسطة كليهما. عندما تكون `auto_resize_images` بقيمة True ويكون `vae` موصولًا، يتم تغيير حجم الصور لتقترب مساحة البكسل الإجمالية لها من 1024x1024 قبل الترميز. إذا لم يتم توفير أي صور، فلا يُرمَّز سوى موجّه النص.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | مخرجات التكييف النهائية. تحتوي على موجّه النص المُرمَّز، وعند توفير الصور، قد تتضمن تضمينات صور مُرمَّزة، وعناصر كامنة مرجعية، وتضمينات نصية إضافية مشتقة من قالب العنصر النائب للصورة. | CONDITIONING |
