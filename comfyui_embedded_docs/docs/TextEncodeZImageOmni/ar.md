# TextEncodeZImageOmni

تُعد عقدة `TextEncodeZImageOmni` عقدة تكييف متقدمة تقوم بترميز نص التوجيه مع صور مرجعية اختيارية إلى تنسيق تكييف مناسب لنماذج توليد الصور. يمكنها معالجة ما يصل إلى ثلاث صور، مع ترميزها اختياريًا باستخدام مشفر رؤية و/أو VAE لإنتاج كمونات مرجعية، وتدمج هذه المراجع البصرية مع نص التوجيه باستخدام بنية قالب محددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتحويل نص التوجيه إلى رموز وترميزه. | CLIP | نعم |  |
| `image_encoder` | نموذج مشفر رؤية اختياري. إذا تم توفيره، سيُستخدم لترميز الصور المدخلة، وستُضاف التضمينات الناتجة إلى التكييف. | CLIPVision | لا |  |
| `prompt` | نص التوجيه المراد ترميزه. يدعم هذا الحقل الإدخال متعدد الأسطر والتوجيهات الديناميكية. | STRING | نعم |  |
| `auto_resize_images` | عند التفعيل (الافتراضي: True)، يتم إعادة تحجيم الصور المدخلة تلقائيًا بناءً على مساحتها البكسلية قبل تمريرها إلى VAE للترميز. هذا إعداد متقدم. | BOOLEAN | لا |  |
| `vae` | نموذج VAE اختياري. إذا تم توفيره، سيُستخدم لترميز الصور المدخلة إلى تمثيلات كامنة، وتُضاف إلى التكييف ككمونات مرجعية. | VAE | لا |  |
| `image1` | الصورة المرجعية الاختيارية الأولى. | IMAGE | لا |  |
| `image2` | الصورة المرجعية الاختيارية الثانية. | IMAGE | لا |  |
| `image3` | الصورة المرجعية الاختيارية الثالثة. | IMAGE | لا |  |

**ملاحظة:** يمكن للعقدة استقبال ما يصل إلى ثلاث صور (`image1`، `image2`, `image3`). يتم استخدام مدخلي `image_encoder` و`vae` فقط إذا تم توفير صورة واحدة على الأقل. عندما تكون قيمة `auto_resize_images` صحيحة (True) ويكون `vae` متصلًا، تتم إعادة تحجيم الصور بحيث تكون المساحة البكسلية الإجمالية قريبة من 1024×1024 بكسل، مع تقريب الأبعاد إلى مضاعفات الرقم 8، قبل الترميز. إذا لم يتم توفير أي صور، تقوم العقدة بترميز نص التوجيه دون أي مراجع بصرية.
