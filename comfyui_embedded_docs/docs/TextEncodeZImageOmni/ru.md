# TextEncodeZImageOmni

TextEncodeZImageOmni кодирует текстовый промпт вместе с не более чем тремя необязательными эталонными изображениями в формат кондиционирования для моделей генерации изображений. Промпт токенизируется и кодируется с помощью модели CLIP, а каждое подключенное изображение может быть дополнительно обработано визуальным энкодером и/или VAE, чтобы визуальные референсы встраивались вместе с текстом. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстового промпта. | CLIP | Да |  |
| `кодировщик_изображения` | Необязательная модель визуального энкодера. Если указана, она используется для кодирования входных изображений, и полученные эмбеддинги добавляются к кондиционированию. | CLIP_VISION | Нет |  |
| `промпт` | Текстовый промпт для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да |  |
| `автоматическое_изменение_размера_изображений` | Когда включено (по умолчанию: True), входные изображения автоматически изменяются перед кодированием VAE, чтобы их общая площадь в пикселях была близка к 1024x1024, а размеры округлялись до значений, кратных 8. | BOOLEAN | Нет | True<br>False |
| `vae` | Необязательная модель VAE. Если указана, она используется для кодирования входных изображений в латентные представления, которые добавляются к кондиционированию в качестве эталонных латентных представлений. | VAE | Нет |  |
| `изображение1` | Первое необязательное эталонное изображение. | IMAGE | Нет |  |
| `изображение2` | Второе необязательное эталонное изображение. | IMAGE | Нет |  |
| `изображение3` | Третье необязательное эталонное изображение. | IMAGE | Нет |  |

**Примечание:** Узел принимает максимум три изображения (`image1`, `image2`, `image3`). Входы `image_encoder` и `vae` используются только тогда, когда предоставлено хотя бы одно изображение; когда подключены оба, каждое изображение обрабатывается обоими. Когда `auto_resize_images` имеет значение True и подключен `vae`, изображения изменяются так, чтобы их общая площадь в пикселях была близка к 1024x1024 перед кодированием.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Итоговый выход кондиционирования. Он содержит закодированный текстовый промпт и, при наличии изображений, может включать закодированные эмбеддинги изображений, эталонные латентные представления и дополнительные текстовые эмбеддинги, полученные из шаблона-заполнителя изображения. | CONDITIONING |
