# TextEncodeZImageOmni

The TextEncodeZImageOmni — это продвинутый узел кондиционирования, который кодирует текстовый промпт вместе с дополнительными референсными изображениями в формат кондиционирования, подходящий для моделей генерации изображений. Он может обрабатывать до трёх изображений, опционально кодируя их с помощью энкодера изображений и/или VAE для получения референсных латентных представлений, и объединяет эти визуальные ссылки с текстовым промптом, используя специальную шаблонную структуру.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстового промпта. | CLIP | Да |  |
| `image_encoder` | Необязательная модель энкодера изображений. Если она задана, она будет использоваться для кодирования входных изображений, а полученные эмбеддинги будут добавлены в кондиционирование. | CLIPVision | Нет |  |
| `prompt` | Текстовый промпт для кодирования. Это поле поддерживает многострочный ввод и динамические промпты. | STRING | Да |  |
| `auto_resize_images` | Когда включено (по умолчанию: True), входные изображения автоматически изменяют размер на основе их площади в пикселях перед передачей в VAE для кодирования. Это расширенная настройка. | BOOLEAN | Нет |  |
| `vae` | Необязательная модель VAE. Если она задана, она будет использоваться для кодирования входных изображений в латентные представления, которые добавляются в кондиционирование как референсные латенты. | VAE | Нет |  |
| `image1` | Первое дополнительное референсное изображение. | IMAGE | Нет |  |
| `image2` | Второе дополнительное референсное изображение. | IMAGE | Нет |  |
| `image3` | Третье дополнительное референсное изображение. | IMAGE | Нет |  |

**Примечание:** Узел может принимать максимум три изображения (`image1`, `image2`, `image3`). Входы `image_encoder` и `vae` используются только в том случае, если задано хотя бы одно изображение. Когда `auto_resize_images` имеет значение True и подключён `vae`, изображения изменяются так, чтобы их общая площадь в пикселях была близка к 1024×1024 пикселя, а размеры округляются до кратных 8 перед кодированием. Если изображения не заданы, узел кодирует текстовый промпт без визуальных ссылок.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Итоговый результат кондиционирования, который содержит закодированный текстовый промпт и может включать закодированные эмбеддинги изображений и/или референсные латенты, если были предоставлены изображения. | CONDITIONING |
