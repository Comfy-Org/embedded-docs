# TextEncodeZImageOmni

TextEncodeZImageOmni кодирует текстовый промпт вместе с до трёх необязательными эталонными изображениями в формат conditioning для моделей генерации изображений. Промпт токенизируется и кодируется с помощью модели CLIP, а каждое подключённое изображение может дополнительно обрабатываться визуальным энкодером и/или VAE, чтобы визуальные эталоны были встроены вместе с текстом. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстового промпта. | CLIP | Да |  |
| `кодировщик_изображения` | Необязательная модель визуального энкодера. Если указана, используется для кодирования входных изображений, а полученные эмбеддинги добавляются к conditioning. | CLIP_VISION | Нет |  |
| `промпт` | Текстовый промпт для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да |  |
| `автоматическое_изменение_размера_изображений` | Если включено (по умолчанию: True), входные изображения автоматически изменяются в размере перед кодированием VAE, чтобы их общая площадь пикселей была близка к 1024x1024, а размеры округлялись до кратных 8. | BOOLEAN | Да | True<br>False |
| `vae` | Необязательная модель VAE. Если указана, используется для кодирования входных изображений в латентные представления, которые добавляются к conditioning в качестве эталонных латентов. | VAE | Нет |  |
| `изображение1` | Первое необязательное эталонное изображение. | IMAGE | Нет |  |
| `изображение2` | Второе необязательное эталонное изображение. | IMAGE | Нет |  |
| `изображение3` | Третье необязательное эталонное изображение. | IMAGE | Нет |  |

**Примечание:** Узел принимает максимум три изображения (`image1`, `image2`, `image3`). Входы `image_encoder` и `vae` используются только когда предоставлено хотя бы одно изображение; когда подключены оба, каждое изображение обрабатывается обоими. Когда `auto_resize_images` имеет значение True и подключён `vae`, изображения изменяются в размере так, чтобы их общая площадь пикселей была близка к 1024x1024, перед кодированием. Если изображения не предоставлены, кодируется только текстовый промпт.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Итоговый выход conditioning. Содержит закодированный текстовый промпт и, когда изображения предоставлены, может включать закодированные эмбеддинги изображений, эталонные латенты и дополнительные текстовые эмбеддинги, полученные из шаблона-заполнителя изображения. | CONDITIONING |
