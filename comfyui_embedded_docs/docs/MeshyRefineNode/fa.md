# Meshy: بهبود مدل پیش‌نویس

گره «Meshy: Refine Draft Model» یک مدل سه‌بعدی پیش‌نویس را از یک وظیفهٔ قبلی Meshy دریافت کرده و آن را بهبود می‌بخشد و به‌صورت اختیاری با استفاده از یک متن prompt یا تصویر مرجع، بافت‌دهی می‌کند. این گره کار بهبود را به API Meshy ارسال می‌کند و پس از تکمیل وظیفه، مدل نهایی را بهصورت فایل‌های GLB و FBX برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای بهبود مدل پیش‌نویس. | COMBO | بله | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | شناسه یکتای وظیفهٔ مدل پیش‌نویسی که می‌خواهید بهبود دهید. | MESHY_TASK_ID | بله | - |
| `enable_pbr` | تولید نقشه‌های PBR (فلزینگی، زبری، نرمال) علاوه بر رنگ پایه. توجه: هنگام استفاده از سبک Sculpture این مقدار باید `false` تنظیم شود، زیرا سبک Sculpture مجموعه نقشه‌های PBR خودش را تولید می‌کند. (پیش‌فرض: False) | BOOLEAN | بله | - |
| `texture_prompt` | یک پرامپت متنی برای هدایت فرآیند بافت‌دهی ارائه دهید. حداکثر ۶۰۰ کاراکتر. نمی‌توان همزمان با `texture_image` استفاده شود. (پیش‌فرض: رشتهٔ خالی) | STRING | بله | - |
| `texture_image` | فقط یکی از `texture_image` یا `texture_prompt` می‌تواند همزمان استفاده شود. | IMAGE | خیر | - |
| `texture_resolution` | رزولوشن بافت رنگ پایه. رزولوشن‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. | COMBO | بله | `"2k"`<br>`"4k"`<br>`"8k"` |

**توجه:** ورودی‌های `texture_prompt` و `texture_image` متقابلاً انحصاری هستند. نمی‌توانید هم متن prompt و هم تصویر را برای بافت‌دهی در یک عملیات ارائه دهید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | نام فایل مدل GLB تولیدشده. (فقط برای سازگاری با نسخه‌های قبلی) | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای وظیفه برای کار بهبود ارسال‌شده. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی نهایی بهبودیافته در قالب GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی نهایی بهبودیافته در قالب FBX. | FILE3DFBX |
