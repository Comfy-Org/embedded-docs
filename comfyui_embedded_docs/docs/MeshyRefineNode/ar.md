# Meshy: تحسين النموذج الأولي

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المستخدم لتحسين النموذج الأولي. | COMBO | نعم | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | المعرّف الفريد للمهمة الخاصة بالنموذج الأولي الذي تريد تحسينه. | MESHY_TASK_ID | نعم | - |
| `enable_pbr` | توليد خرائط PBR (اللمعان المعدني، الخشونة، الطبيعي) بالإضافة إلى اللون الأساسي. ملاحظة: يجب ضبط هذا الخيار على False عند استخدام نمط النحت (Sculpture)، حيث يولّد نمط النحت مجموعة خاصة به من خرائط PBR. (الافتراضي: False) | BOOLEAN | نعم | - |
| `texture_prompt` | قدّم موجهًا نصيًا لتوجيه عملية إضافة المواد. الحد الأقصى 600 حرفًا. لا يمكن استخدامه في نفس الوقت مع `texture_image`. (الافتراضي: سلسلة فارغة) | STRING | نعم | - |
| `texture_image` | يمكن استخدام واحد فقط من `texture_image` أو `texture_prompt` في نفس الوقت. | IMAGE | لا | - |
| `texture_resolution` | دقة مادة اللون الأساسي. الدقة الأعلى تلتقط تفاصيل سطح أكثر. | COMBO | نعم | `"2k"`<br>`"4k"`<br>`"8k"` |

**ملاحظة:** إن المدخلين `texture_prompt` و`texture_image` متنافيان. لا يمكنك تقديم موجه نصي وصورة معًا لعمليات إضافة المواد في نفس العملية.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-----------|-------------|
| `model_file` | اسم ملف نموذج GLB المُنشأ. (لأغراض التوافق مع الإصدارات السابقة فقط) | STRING |
| `meshy_task_id` | المعرّف الفريد للمهمة الخاصة بعملية التحسين المُرسلة. | MESHY_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُحسَّن النهائي بصيغة GLB. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المُحسَّن النهائي بصيغة FBX. | FILE3DFBX |

> تم إنشاء هذه الوثيقة بواسطة الذكاء الاصطناعي. إذا وجدت أي أخطاء أو لديك اقتراحات للتحسين، فلا تتردد في المساهمة! [تحرير على GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyRefineNode/ar.md)
