# Meshy: Улучшить Черновую Модель

Узел Meshy: Refine Draft Model принимает 3D-черновую модель из предыдущей задачи Meshy и улучшает её, при необходимости добавляя текстуры с помощью текстового запроса или эталонного изображения. Он отправляет задачу уточнения в API Meshy и возвращает готовую модель в виде файлов GLB и FBX после завершения задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель ИИ, используемая для уточнения черновой модели. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | Уникальный идентификатор задачи черновой модели, которую вы хотите уточнить. | MESHY_TASK_ID | Да | - |
| `enable_pbr` | Генерировать PBR-карты (metallic, roughness, normal) в дополнение к базовому цвету. Примечание: должно быть false при использовании стиля Sculpture, так как стиль Sculpture генерирует собственный набор PBR-карт. (по умолчанию: False) | BOOLEAN | Да | - |
| `texture_prompt` | Предоставьте текстовый запрос для управления процессом текстурирования. Максимум 600 символов. Нельзя использовать одновременно с `texture_image`. (по умолчанию: пустая строка) | STRING | Да | - |
| `texture_image` | Одновременно можно использовать только один из параметров `texture_image` или `texture_prompt`. | IMAGE | Нет | - |
| `разрешение текстуры` | Разрешение текстуры базового цвета. Более высокое разрешение позволяет захватить больше деталей поверхности. | COMBO | Да | `"2k"`<br>`"4k"`<br>`"8k"` |

**Примечание:** входы `texture_prompt` и `texture_image` являются взаимоисключающими. Нельзя одновременно указать текстовый запрос и изображение для текстурирования в одной операции.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла сгенерированной модели GLB. (Только для обратной совместимости) | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи для отправленного задания на уточнение. | MESHY_TASK_ID |
| `GLB` | Финальная уточненная 3D-модель в формате GLB. | FILE3DGLB |
| `FBX` | Финальная уточненная 3D-модель в формате FBX. | FILE3DFBX |
