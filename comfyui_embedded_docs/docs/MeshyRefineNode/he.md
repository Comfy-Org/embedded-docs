# MeshyRefineNode

הצומת Meshy: Refine Draft Model מקבל מודל תלת-ממדי טיוטתי ממשימת Meshy קודמת ומשפר אותו, ובאופן אופציונלי מוסיף טקסטורות באמצעות הנחיית טקסט או תמונת עזר. הוא שולח את משימת העידון אל ה-API של Meshy ומחזיר את המודל המוגמר כקבצי GLB ו-FBX לאחר השלמת המשימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI המשמש לעידון מודל הטיוטה. | COMBO | כן | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | מזהה המשימה הייחודי של מודל הטיוטה שברצונך לעדן. | MESHY_TASK_ID | כן | - |
| `enable_pbr` | יצירת מפות PBR (מטאלי, חספוס, נורמל) בנוסף לצבע הבסיס. הערה: יש להגדיר זאת כ-false בעת שימוש בסגנון Sculpture, מכיוון שסגנון Sculpture מייצר סט מפות PBR משלו. (ברירת מחדל: False) | BOOLEAN | כן | - |
| `texture_prompt` | ספק הנחיית טקסט כדי להנחות את תהליך יצירת הטקסטורה. מקסימום 600 תווים. לא ניתן להשתמש בו בו-זמנית עם `texture_image`. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | מקסימום 600 תווים |
| `texture_image` | ניתן להשתמש רק באחד מהקלטים `texture_image` או `texture_prompt` בו-זמנית. | IMAGE | לא | - |
| `texture_resolution` | רזולוציית טקסטורת צבע הבסיס. רזולוציות גבוהות יותר לוכדות יותר פרטים של פני השטח. | COMBO | כן | `"2k"`<br>`"4k"`<br>`"8k"` |

**הערה:** הקלטים `texture_prompt` ו-`texture_image` סותרים זה את זה. לא ניתן לספק גם הנחיית טקסט וגם תמונה ליצירת טקסטורה באותה פעולה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | שם הקובץ של מודל ה-GLB שנוצר. (לצורכי תאימות לאחור בלבד) | STRING |
| `meshy_task_id` | מזהה המשימה הייחודי של משימת העידון שנשלחה. | MESHY_TASK_ID |
| `GLB` | המודל התלת-ממדי המעודן הסופי בפורמט GLB. | FILE3DGLB |
| `FBX` | המודל התלת-ממדי המעודן הסופי בפורמט FBX. | FILE3DFBX |
