# Контекстные окна (Ручная настройка)

Узел **Context Windows (Manual)** позволяет вручную настраивать контекстные окна для моделей во время сэмплирования. Он создает перекрывающиеся контекстные сегменты с заданной длиной, перекрытием и паттернами планирования, чтобы обрабатывать данные управляемыми частями, сохраняя непрерывность между сегментами. Этот узел предоставляет расширенные возможности для управления применением контекстных окон, включая перемешивание шума, сохранение кондиционирования, сохранение шумового латентного представления и исправление каузальных окон.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяются контекстные окна во время сэмплирования. | MODEL | Да | - |
| `context_length` | Длина контекстного окна (по умолчанию: 16). | INT | Нет | 1+ |
| `context_overlap` | Перекрытие контекстного окна (по умолчанию: 4). | INT | Нет | 0+ |
| `context_schedule` | Алгоритм планирования контекстных окон, зависящий от шага (по умолчанию: STATIC_STANDARD). | COMBO | Нет | `"STATIC_STANDARD"`<br>`"UNIFORM_STANDARD"`<br>`"UNIFORM_LOOPED"`<br>`"BATCHED"` |
| `context_stride` | Шаг контекстного окна; применимо только к равномерным расписаниям (по умолчанию: 1). | INT | Нет | 1+ |
| `closed_loop` | Замыкать ли цикл контекстного окна; применимо только к зацикленным расписаниям (по умолчанию: False). | BOOLEAN | Нет | - |
| `fuse_method` | Метод слияния контекстных окон (по умолчанию: PYRAMID). | COMBO | Нет | `"PYRAMID"`<br>`"LIST_STATIC"` |
| `dim` | Измерение, к которому применяются контекстные окна (по умолчанию: 0). | INT | Нет | 0-5 |
| `freenoise` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон (по умолчанию: False). | BOOLEAN | Нет | - |
| `cond_retain_index_list` | Список индексов латентного представления, которые следует сохранить в тензорах кондиционирования для каждого окна. Для моделей I2V конкатенационного типа (например, Wan I2V, HunyuanVideo I2V, Cosmos I2V, SVD) закодированное начальное изображение находится в каналах кондиционирования c_concat; установка значения '0' сохранит содержимое начального изображения на подпозиции 0 каждого окна (по умолчанию: ""). | STRING | Нет | - |
| `split_conds_to_windows` | Разделять ли несколько кондиционирований (созданных узлом ConditionCombine) по окнам на основе индекса региона (по умолчанию: False). | BOOLEAN | Нет | - |
| `latent_retain_index_list` | Список индексов латентного представления, которые следует сохранить в самом шумовом латентном представлении для каждого окна. Используется для рабочих процессов, где эталонное содержимое (например, начальное изображение) находится непосредственно в шумовом латентном представлении, а не в отдельных каналах кондиционирования (например, I2V в стиле inplace, как LTXV, AnimateDiff). Не зависит от `cond_retain_index_list` (по умолчанию: ""). | STRING | Нет | - |
| `causal_window_fix` | Добавлять ли кадр каузальной коррекции к контекстным окнам с ненулевым индексом (по умолчанию: True). | BOOLEAN | Нет | - |

**Ограничения параметров:**

- `context_stride` используется только при выборе равномерных расписаний
- `closed_loop` применимо только к зацикленным расписаниям
- `dim` должно быть в диапазоне от 0 до 5 включительно
- `cond_retain_index_list` ожидает строку, содержащую список целочисленных индексов через запятую (например, "0,1,2")
- `latent_retain_index_list` ожидает строку, содержащую список целочисленных индексов через запятую (например, "0,1,2") и не зависит от `cond_retain_index_list`
