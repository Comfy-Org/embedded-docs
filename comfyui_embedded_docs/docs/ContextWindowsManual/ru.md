# Контекстные окна (Ручная настройка)

Узел Context Windows (Manual) позволяет вручную настраивать контекстные окна для модели во время сэмплирования, создавая перекрывающиеся контекстные сегменты с заданной длиной, перекрытием и схемой планирования, чтобы данные обрабатывались небольшими порциями с сохранением непрерывности между сегментами. Он предоставляет расширенные опции для управления применением контекстных окон, включая перемешивание шума, сохранение conditioning и исправление каузальных окон. Этот узел является экспериментальным.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяются контекстные окна во время сэмплирования. | MODEL | Да | - |
| `длина_контекста` | Длина контекстного окна (по умолчанию: 16). | INT | Да | 1+ |
| `перекрытие_контекста` | Перекрытие контекстного окна (по умолчанию: 4). | INT | Да | 0+ |
| `расписание_контекста` | Зависящий от шага алгоритм планирования для контекстных окон (по умолчанию: STATIC_STANDARD). | COMBO | Да | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `шаг_контекста` | Шаг контекстного окна; применимо только к равномерным расписаниям (по умолчанию: 1). | INT | Да | 1+ |
| `замкнутый_цикл` | Замыкать ли цикл контекстного окна; применимо только к зацикленным расписаниям (по умолчанию: False). | BOOLEAN | Да | - |
| `метод_объединения` | Метод, используемый для слияния контекстных окон (по умолчанию: PYRAMID). | COMBO | Да | Статические методы слияния (см. `ContextFuseMethods.LIST_STATIC`) |
| `измерение` | Размерность, к которой применяются контекстные окна (по умолчанию: 0). | INT | Да | 0-5 |
| `свободный_шум` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон (по умолчанию: False). | BOOLEAN | Да | - |
| `cond_retain_index_list` | Список индексов латента, которые нужно сохранить в тензорах conditioning для каждого окна. Для I2V-моделей concat-типа (например, Wan I2V, HunyuanVideo I2V, Cosmos I2V, SVD) закодированное стартовое изображение содержится в каналах conditioning c_concat; установка значения '0' сохранит содержимое стартового изображения на суб-позиции 0 каждого окна (по умолчанию: ""). | STRING | Нет | - |
| `split_conds_to_windows` | Следует ли разделять несколько conditioning (созданных узлом ConditionCombine) по каждому окну на основе индекса региона (по умолчанию: False). | BOOLEAN | Нет | - |
| `latent_retain_index_list` | Список индексов латента, которые нужно сохранить в самом шумовом латенте для каждого окна. Используйте для рабочих процессов, где эталонное содержимое (например, стартовое изображение) находится непосредственно в шумовом латенте, а не в отдельных каналах conditioning (например, для I2V в стиле inplace, таких как LTXV, AnimateDiff). Не зависит от cond_retain_index_list (по умолчанию: ""). | STRING | Нет | - |
| `causal_window_fix` | Добавлять ли кадр каузальной коррекции к контекстным окнам с ненулевым индексом (по умолчанию: True). | BOOLEAN | Нет | - |

**Ограничения параметров:**

- `context_stride` используется только при выборе равномерного расписания (`UNIFORM_STANDARD` или `UNIFORM_LOOPED`).
- `closed_loop` применимо только к зацикленным расписаниям (`UNIFORM_LOOPED`).
- Значение `dim` должно быть в диапазоне от 0 до 5 включительно.
- `cond_retain_index_list` и `latent_retain_index_list` ожидают строку со списком целочисленных индексов, разделённых запятыми (например, "0,1,2").
- `latent_retain_index_list` не зависит от `cond_retain_index_list`.
