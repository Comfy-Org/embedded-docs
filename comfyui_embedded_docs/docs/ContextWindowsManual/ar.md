# Context Windows (Manual)

تتيح لك عقدة Context Windows (Manual) ضبط نوافذ السياق يدويًا للنماذج أثناء أخذ العينات. فهي تنشئ مقاطع سياق متداخلة بطول وتداخل وأنماط جدولة محددة لمعالجة البيانات في أجزاء يمكن إدارتها مع الحفاظ على الاستمرارية بين المقاطع. توفر هذه العقدة خيارات متقدمة للتحكم في كيفية تطبيق نوافذ السياق، بما في ذلك خلط الضوضاء، والاحتفاظ بالتكييف، والاحتفاظ بالضوضاء الكامنة، وإصلاح النوافذ السببية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج الذي سيتم تطبيق نوافذ السياق عليه أثناء أخذ العينات. | MODEL | نعم | - |
| `context_length` | طول نافذة السياق (الافتراضي: 16). | INT | لا | 1+ |
| `context_overlap` | تداخل نافذة السياق (الافتراضي: 4). | INT | لا | 0+ |
| `context_schedule` | خوارزمية الجدولة المعتمدة على الخطوة لنوافذ السياق (الافتراضي: STATIC_STANDARD). | COMBO | لا | `"STATIC_STANDARD"`<br>`"UNIFORM_STANDARD"`<br>`"UNIFORM_LOOPED"`<br>`"BATCHED"` |
| `context_stride` | خطوة نافذة السياق؛ تنطبق فقط على الجداول الموحدة (الافتراضي: 1). | INT | لا | 1+ |
| `closed_loop` | ما إذا كان سيتم إغلاق حلقة نافذة السياق؛ ينطبق فقط على الجداول الحلقية (الافتراضي: False). | BOOLEAN | لا | - |
| `fuse_method` | الطريقة المستخدمة لدمج نوافذ السياق (الافتراضي: PYRAMID). | COMBO | لا | `"PYRAMID"`<br>`"LIST_STATIC"` |
| `dim` | البُعد الذي سيتم تطبيق نوافذ السياق عليه (الافتراضي: 0). | INT | لا | 0-5 |
| `freenoise` | ما إذا كان سيتم تطبيق خلط الضوضاء FreeNoise، يحسّن مزج النوافذ (الافتراضي: False). | BOOLEAN | لا | - |
| `cond_retain_index_list` | قائمة مؤشرات الكامن للاحتفاظ بها في موترات التكييف لكل نافذة. بالنسبة لنماذج I2V من نمط التوصيل (مثل Wan I2V وHunyuanVideo I2V وCosmos I2V وSVD)، تعيش صورة البداية المشفّرة في قنوات التكييف c_concat؛ تعيين هذا على '0' سيحتفظ بمحتوى صورة البداية عند الموضع الفرعي 0 لكل نافذة (الافتراضي: ""). | STRING | لا | - |
| `split_conds_to_windows` | ما إذا كان سيتم تقسيم التكييفات المتعددة (التي تم إنشاؤها بواسطة ConditionCombine) إلى كل نافذة بناءً على مؤشر المنطقة (الافتراضي: False). | BOOLEAN | لا | - |
| `latent_retain_index_list` | قائمة مؤشرات الكامن للاحتفاظ بها في الضوضاء الكامنة نفسها لكل نافذة. تُستخدم لسير العمل حيث يكون المحتوى المرجعي (مثل صورة البداية) موجودًا مباشرة في الضوضاء الكامنة بدلاً من قنوات التكييف المنفصلة (مثل نمط inplace I2V مثل LTXV وAnimateDiff). مستقل عن cond_retain_index_list (الافتراضي: ""). | STRING | لا | - |
| `causal_window_fix` | ما إذا كان سيتم إضافة إطار إصلاح سببي إلى نوافذ السياق غير المفهرسة بـ 0 (الافتراضي: True). | BOOLEAN | لا | - |

**قيود المعاملات:**

- `context_stride` يُستخدم فقط عند تحديد الجداول الموحدة
- `closed_loop` ينطبق فقط على الجداول الحلقية
- يجب أن يكون `dim` بين 0 و5 شاملًا
- تتوقع `cond_retain_index_list` قائمة مفصولة بفواصل من المؤشرات الصحيحة كسلسلة نصية (مثل "0,1,2")
- تتوقع `latent_retain_index_list` قائمة مفصولة بفواصل من المؤشرات الصحيحة كسلسلة نصية (مثل "0,1,2") وهي مستقلة عن `cond_retain_index_list`
