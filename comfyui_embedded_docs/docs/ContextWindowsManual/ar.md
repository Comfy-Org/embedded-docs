# Context Windows (Manual)

تتيح لك عقدة "Context Windows (Manual)" ضبط نوافذ السياق يدويًا لنموذج أثناء أخذ العينات، وإنشاء مقاطع سياق متداخلة بطول وتداخل ونمط جدولة محدد، بحيث تتم معالجة البيانات في أجزاء يمكن إدارتها مع الحفاظ على الاستمرارية بين المقاطع. توفر العقدة خيارات متقدمة للتحكم في كيفية تطبيق نوافذ السياق، بما في ذلك خلط الضوضاء، والاحتفاظ بالتكييف، وإصلاح النوافذ السببية. هذه العقدة تجريبية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج الذي سيتم تطبيق نوافذ السياق عليه أثناء أخذ العينات. | MODEL | نعم | - |
| `context_length` | طول نافذة السياق (الافتراضي: 16). | INT | نعم | 1+ |
| `context_overlap` | تداخل نافذة السياق (الافتراضي: 4). | INT | نعم | 0+ |
| `context_schedule` | خوارزمية جدولة تعتمد على الخطوة لنوافذ السياق (الافتراضي: STATIC_STANDARD). | COMBO | نعم | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `context_stride` | خطوة نافذة السياق؛ تنطبق فقط على الجداول الموحدة (الافتراضي: 1). | INT | نعم | 1+ |
| `closed_loop` | ما إذا كان سيتم إغلاق حلقة نافذة السياق؛ ينطبق فقط على الجداول الحلقية (الافتراضي: False). | BOOLEAN | نعم | - |
| `fuse_method` | الطريقة المستخدمة لدمج نوافذ السياق (الافتراضي: PYRAMID). | COMBO | نعم | طرق الدمج الثابتة (انظر `ContextFuseMethods.LIST_STATIC`) |
| `dim` | البُعد الذي سيتم تطبيق نوافذ السياق عليه (الافتراضي: 0). | INT | نعم | 0-5 |
| `ضجيج حر` | ما إذا كان سيتم تطبيق خلط الضوضاء FreeNoise، مما يحسّن مزج النوافذ (الافتراضي: False). | BOOLEAN | نعم | - |
| `cond_retain_index_list` | قائمة بمؤشرات المساحة الكامنة (latent) للاحتفاظ بها في موترات التكييف لكل نافذة. بالنسبة لنماذج I2V من نمط concat-style (مثل Wan I2V وHunyuanVideo I2V وCosmos I2V وSVD)، تعيش صورة البداية المشفرة في قنوات التكييف c_concat؛ تعيين هذا إلى '0' سيحتفظ بمحتوى صورة البداية في الموضع الفرعي 0 لكل نافذة (الافتراضي: ""). | STRING | لا | - |
| `split_conds_to_windows` | ما إذا كان سيتم تقسيم التكييفات المتعددة (التي تم إنشاؤها بواسطة ConditionCombine) إلى كل نافذة بناءً على مؤشر المنطقة (الافتراضي: False). | BOOLEAN | لا | - |
| `latent_retain_index_list` | قائمة بمؤشرات المساحة الكامنة للاحتفاظ بها في الضوضاء الكامنة نفسها لكل نافذة. استخدمها لسير العمل حيث يكون المحتوى المرجعي (مثل صورة بداية) موجودًا مباشرة في الضوضاء الكامنة بدلاً من قنوات التكييف المنفصلة (مثل نماذج I2V من نمط inplace-style مثل LTXV وAnimateDiff). مستقلة عن `cond_retain_index_list` (الافتراضي: ""). | STRING | لا | - |
| `causal_window_fix` | ما إذا كان سيتم إضافة إطار إصلاح سببي إلى نوافذ السياق غير المفهرسة بـ 0 (الافتراضي: True). | BOOLEAN | لا | - |

**قيود المعاملات:**

- `context_stride` يُستخدم فقط عند تحديد جدول موحد (`UNIFORM_STANDARD` أو `UNIFORM_LOOPED`).
- `closed_loop` ينطبق فقط على الجداول الحلقية (`UNIFORM_LOOPED`).
- يجب أن يكون `dim` بين 0 و5 ضمناً.
- يتوقع كل من `cond_retain_index_list` و`latent_retain_index_list` قائمة مفصولة بفواصل من المؤشرات الصحيحة كسلسلة نصية (مثل: "0,1,2").
- `latent_retain_index_list` مستقل عن `cond_retain_index_list`.
