# ContextWindowsManual

הצומת Context Windows (Manual) מאפשר לך להגדיר ידנית חלונות הקשר עבור מודל במהלך הדגימה, ליצור מקטעי הקשר חופפים עם אורך, חפיפה ותבנית תזמון מוגדרים, כך שהנתונים מעובדים במנות ניתנות לניהול תוך שמירה על רציפות בין המקטעים. הוא מספק אפשרויות מתקדמות לשליטה באופן שבו חלונות הקשר מיושמים, כולל ערבול רעש, שימור קונדישנינג ותיקוני חלון סיבתיים. צומת זה ניסיוני.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו יחולו חלונות ההקשר במהלך הדגימה. | MODEL | כן | - |
| `context_length` | אורך חלון ההקשר (ברירת מחדל: 16). | INT | כן | 1+ |
| `context_overlap` | החפיפה של חלון ההקשר (ברירת מחדל: 4). | INT | כן | 0+ |
| `context_schedule` | אלגוריתם תזמון תלוי-צעד עבור חלונות הקשר (ברירת מחדל: STATIC_STANDARD). | COMBO | כן | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `context_stride` | הצעד (stride) של חלון ההקשר; רלוונטי רק ללוחות זמנים אחידים (ברירת מחדל: 1). | INT | כן | 1+ |
| `closed_loop` | האם לסגור את לולאת חלון ההקשר; רלוונטי רק ללוחות זמנים עם לולאה (ברירת מחדל: False). | BOOLEAN | כן | - |
| `fuse_method` | השיטה שבה יש למזג את חלונות ההקשר (ברירת מחדל: PYRAMID). | COMBO | כן | שיטות מיזוג סטטיות (ראו `ContextFuseMethods.LIST_STATIC`) |
| `dim` | הממד שעליו יחולו חלונות ההקשר (ברירת מחדל: 0). | INT | כן | 0-5 |
| `freenoise` | האם להחיל ערבול רעש FreeNoise, משפר את מיזוג החלונות (ברירת מחדל: False). | BOOLEAN | כן | - |
| `cond_retain_index_list` | רשימת אינדקסים של לטנטים שיש לשמר בטנסורי הקונדישנינג עבור כל חלון. עבור מודלים בסגנון concat של I2V (למשל Wan I2V, HunyuanVideo I2V, Cosmos I2V, SVD), תמונת ההתחלה המקודדת נמצאת בערוצי הקונדישנינג של `c_concat`; הגדרת ערך זה ל-'0' תשמור את תוכן תמונת ההתחלה בתת-מיקום 0 של כל חלון (ברירת מחדל: ""). | STRING | לא | - |
| `split_conds_to_windows` | האם לפצל מספר קונדישנינגים (שנוצרו על ידי ConditionCombine) לכל חלון בהתאם לאינדקס האזור (ברירת מחדל: False). | BOOLEAN | לא | - |
| `latent_retain_index_list` | רשימת אינדקסים של לטנטים שיש לשמר בתוך לטנט הרעש עצמו עבור כל חלון. יש להשתמש בכך בתהליכי עבודה שבהם תוכן עזר (למשל תמונת התחלה) נמצא ישירות בלטנט הרעש ולא בערוצי קונדישנינג נפרדים (למשל I2V בסגנון inplace כמו LTXV, AnimateDiff). בלתי תלוי ב-`cond_retain_index_list` (ברירת מחדל: ""). | STRING | לא | - |
| `causal_window_fix` | האם להוסיף פריים תיקון סיבתי לחלונות הקשר שאינם באינדקס 0 (ברירת מחדל: True). | BOOLEAN | לא | - |

**אילוצי פרמטרים:**

- `context_stride` משמש רק כאשר נבחר לוח זמנים אחיד (`UNIFORM_STANDARD` או `UNIFORM_LOOPED`).
- `closed_loop` רלוונטי רק ללוחות זמנים עם לולאה (`UNIFORM_LOOPED`).
- `dim` חייב להיות בין 0 ל-5 כולל.
- `cond_retain_index_list` ו-`latent_retain_index_list` מצפים לרשימת אינדקסים שלמים מופרדים בפסיקים כמחרוזת (למשל, "0,1,2").
- `latent_retain_index_list` בלתי תלוי ב-`cond_retain_index_list`.
