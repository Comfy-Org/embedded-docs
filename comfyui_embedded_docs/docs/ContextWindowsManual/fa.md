# پنجره‌های زمینه (دستی)

گره Context Windows (Manual) به شما امکان می‌دهد تا پنجره‌های زمینه را برای یک مدل در طول نمونه‌برداری به‌صورت دستی پیکربندی کنید و بخش‌های هم‌پوشان زمینه را با طول، هم‌پوشانی و الگوی زمان‌بندی مشخص بسازید؛ به این ترتیب داده‌ها در تکه‌های قابل‌مدیریت پردازش می‌شوند و پیوستگی بین بخش‌ها حفظ می‌گردد. این گره گزینه‌های پیشرفته‌ای برای کنترل نحوه اعمال پنجره‌های زمینه فراهم می‌کند، از جمله درهم‌ریزی نویز، حفظ شرطی‌سازی و اصلاح پنجره علّی. این گره آزمایشی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که برای اعمال پنجره‌های زمینه در طول نمونه‌برداری استفاده می‌شود. | MODEL | بله | - |
| `طول پنجره زمینه` | طول پنجره زمینه (پیش‌فرض: 16). | INT | بله | 1+ |
| `همپوشانی پنجره زمینه` | میزان هم‌پوشانی پنجره زمینه (پیش‌فرض: 4). | INT | بله | 0+ |
| `برنامه‌ریزی پنجره زمینه` | الگوریتم زمان‌بندی وابسته به گام برای پنجره‌های زمینه (پیش‌فرض: STATIC_STANDARD). | COMBO | بله | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `گام پنجره زمینه` | گام پنجره زمینه؛ فقط برای زمان‌بندی‌های یکنواخت قابل اعمال است (پیش‌فرض: 1). | INT | بله | 1+ |
| `حلقه بسته` | آیا حلقه پنجره زمینه بسته شود؛ فقط برای زمان‌بندی‌های حلقه‌ای قابل اعمال است (پیش‌فرض: False). | BOOLEAN | بله | - |
| `روش ادغام` | روشی که برای ادغام پنجره‌های زمینه استفاده می‌شود (پیش‌فرض: PYRAMID). | COMBO | بله | روش‌های ادغام ایستا (به `ContextFuseMethods.LIST_STATIC` مراجعه کنید) |
| `بُعد` | بعدی که پنجره‌های زمینه به آن اعمال می‌شوند (پیش‌فرض: 0). | INT | بله | 0-5 |
| `FreeNoise` | آیا FreeNoise درهم‌ریزی نویز اعمال شود؛ ترکیب پنجره‌ها را بهبود می‌بخشد (پیش‌فرض: False). | BOOLEAN | بله | - |
| `cond_retain_index_list` | فهرست ایندکس‌های نهفته (latent) که باید در تنسورهای شرطی‌سازی (conditioning) برای هر پنجره حفظ شوند. برای مدل‌های I2V سبک الحاقی (مثلاً Wan I2V، HunyuanVideo I2V، Cosmos I2V، SVD) تصویر شروع کدگذاری‌شده در کانال‌های شرطی‌سازی c_concat قرار دارد؛ تنظیم این گزینه بر روی '0' محتوای آن تصویر شروع را در زیرموقعیت 0 هر پنجره حفظ می‌کند (پیش‌فرض: ""). | STRING | خیر | - |
| `split_conds_to_windows` | آیا چند شرطی‌سازی (ایجادشده توسط ConditionCombine) بر اساس ایندکس ناحیه به هر پنجره تقسیم شوند (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `latent_retain_index_list` | فهرست ایندکس‌های نهفته که باید در خود نویز نهفته (latent) برای هر پنجره حفظ شوند. برای گردش‌کارهایی استفاده می‌شود که محتوای مرجع (مثلاً تصویر شروع) مستقیماً در نویز نهفته قرار دارد، نه در کانال‌های شرطی‌سازی جداگانه (مثلاً I2V سبک درجا مانند LTXV، AnimateDiff). مستقل از cond_retain_index_list است (پیش‌فرض: ""). | STRING | خیر | - |
| `causal_window_fix` | آیا یک فریم اصلاح علّی (causal fix) به پنجره‌های زمینه غیر نمایه‌صفر اضافه شود (پیش‌فرض: True). | BOOLEAN | خیر | - |

**محدودیت‌های پارامتر:**

- `context_stride` فقط زمانی استفاده می‌شود که یک زمان‌بندی یکنواخت انتخاب شده باشد (`UNIFORM_STANDARD` یا `UNIFORM_LOOPED`).
- `closed_loop` فقط برای زمان‌بندی‌های حلقه‌ای (`UNIFORM_LOOPED`) قابل اعمال است.
- `dim` باید بین 0 و 5 شامل 0 و 5 باشد.
- `cond_retain_index_list` و `latent_retain_index_list` انتظار یک فهرست جداشده با کاما از ایندکس‌های صحیح را به‌صورت رشته دارند (مثلاً "0,1,2").
- `latent_retain_index_list` مستقل از `cond_retain_index_list` است.
