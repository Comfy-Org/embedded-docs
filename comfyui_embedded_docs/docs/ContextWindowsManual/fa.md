# پنجره‌های زمینه (دستی)

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل موردنظر برای اعمال پنجره‌های زمینه در طول نمونه‌برداری. | MODEL | بله | - |
| `context_length` | طول پنجره زمینه (پیش‌فرض: ۱۶). | INT | خیر | 1+ |
| `context_overlap` | میزان هم‌پوشانی پنجره زمینه (پیش‌فرض: ۴). | INT | خیر | 0+ |
| `context_schedule` | الگوریتم زمان‌بندی وابسته به مرحله برای پنجره‌های زمینه (پیش‌فرض: STATIC_STANDARD). | COMBO | خیر | `"STATIC_STANDARD"`<br>`"UNIFORM_STANDARD"`<br>`"UNIFORM_LOOPED"`<br>`"BATCHED"` |
| `context_stride` | گام پنجره زمینه؛ فقط برای زمان‌بندی‌های یکنواخت قابل استفاده است (پیش‌فرض: ۱). | INT | خیر | 1+ |
| `closed_loop` | آیا حلقه پنجره زمینه بسته شود؛ فقط برای زمان‌بندی‌های حلقه‌ای قابل استفاده است (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `fuse_method` | روشی که برای ادغام پنجره‌های زمینه استفاده می‌شود (پیش‌فرض: PYRAMID). | COMBO | خیر | `"PYRAMID"`<br>`"LIST_STATIC"` |
| `dim` | بعدی که پنجره‌های زمینه روی آن اعمال می‌شوند (پیش‌فرض: ۰). | INT | خیر | 0-5 |
| `freenoise` | آیا به‌هم‌ریختگی نویز FreeNoise اعمال شود، ترکیب پنجره را بهبود می‌بخشد (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `cond_retain_index_list` | فهرست اندیس‌های نهان که باید در تانسورهای شرطی‌سازی برای هر پنجره حفظ شوند. برای مدل‌های I2V به سبک concat (مانند Wan I2V، HunyuanVideo I2V، Cosmos I2V، SVD) تصویر شروع کدگذاری‌شده در کانال‌های شرطی‌سازی c_concat قرار دارد؛ تنظیم این مقدار روی '0' محتوای تصویر شروع را در زیرموقعیت 0 هر پنجره حفظ می‌کند (پیش‌فرض: ""). | STRING | خیر | - |
| `split_conds_to_windows` | آیا چند شرطی‌سازی (ایجاد شده توسط ConditionCombine) بر اساس اندیس منطقه به هر پنجره تقسیم شود (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `latent_retain_index_list` | فهرست اندیس‌های نهان که باید در خود نویز نهان برای هر پنجره حفظ شوند. برای گردش کارهایی استفاده کنید که محتوای مرجع (مانند تصویر شروع) مستقیماً در نویز نهان قرار دارد نه در کانال‌های شرطی‌سازی جداگانه (مانند I2V به سبک inplace مانند LTXV، AnimateDiff). مستقل از `cond_retain_index_list` است (پیش‌فرض: ""). | STRING | خیر | - |
| `causal_window_fix` | آیا یک فریم اصلاح علّی به پنجره‌های زمینه با اندیس غیرصفر اضافه شود (پیش‌فرض: True). | BOOLEAN | خیر | - |

**محدودیت‌های پارامتر:**

- `context_stride` فقط زمانی استفاده می‌شود که زمان‌بندی‌های یکنواخت انتخاب شده باشند.
- `closed_loop` فقط برای زمان‌بندی‌های حلقه‌ای قابل استفاده است.
- `dim` باید بین ۰ و ۵ به‌صورت شامل باشد.
- `cond_retain_index_list` انتظار یک رشته از فهرست اندیس‌های صحیح جداشده با کاما را دارد (مثلاً "0,1,2").
- `latent_retain_index_list` انتظار یک رشته از فهرست اندیس‌های صحیح جداشده با کاما را دارد (مثلاً "0,1,2") و مستقل از `cond_retain_index_list` است.
