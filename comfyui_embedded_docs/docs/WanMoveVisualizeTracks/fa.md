# WanMoveVisualizeTracks

گره WanMoveVisualizeTracks داده‌های ردیابی حرکت را بر روی دنباله‌ای از تصاویر یا فریم‌های ویدیویی ترسیم می‌کند. برای هر نقطه ردیابی‌شده، یک دایره در موقعیت فعلی آن قرار می‌دهد و یک خط مسیر محوکننده رسم می‌کند که مکان حرکت نقطه را در فریم‌های اخیر نشان می‌دهد. اگر داده‌ای برای ردیابی ارائه نشود، تصاویر ورودی بدون تغییر بازگردانده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | دنباله‌ای از تصاویر ورودی یا فریم‌های ویدیویی که مسیرها روی آن‌ها ترسیم می‌شوند. | IMAGE | بله | - |
| `tracks` | داده‌های ردیابی حرکت شامل موقعیت نقاط و اطلاعات دیداری. اگر ارائه نشود، تصاویر ورودی بدون تغییر عبور می‌کنند. | TRACKS | خیر | - |
| `line_resolution` | تعداد فریم‌های قبلی که برای ترسیم خط مسیر دنباله‌رو برای هر مسیر استفاده می‌شود (پیش‌فرض: 24). | INT | بله | 1 - 1024 |
| `circle_size` | اندازه دایره‌ای که در موقعیت فعلی هر نقطه ردیابی‌شده ترسیم می‌شود (پیش‌فرض: 12). | INT | بله | 1 - 128 |
| `opacity` | شفافیت لایه‌های رویی مسیر ترسیم‌شده (پیش‌فرض: 0.75). | FLOAT | بله | 0.0 - 1.0 |
| `line_width` | عرض خطوطی که برای ترسیم مسیرها استفاده می‌شود (پیش‌فرض: 16). | INT | بله | 1 - 128 |

**نکته:** اگر تعداد تصاویر ورودی با تعداد فریم‌های داده `tracks` مطابقت نداشته باشد، دنباله تصاویر ورودی برای هم‌ترازی با داده مسیر تکرار می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
