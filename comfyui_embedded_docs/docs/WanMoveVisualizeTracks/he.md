# WanMoveVisualizeTracks

צומת WanMoveVisualizeTracks מציג נתוני מעקב תנועה כשכבת-על על רצף תמונות או פריימים של וידאו. הוא מצייר ייצוגים חזותיים של נקודות במעקב, כולל נתיבי התנועה ומיקומן הנוכחי, מה שהופך את נתוני התנועה לגלויים וקלים יותר לניתוח.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | רצף תמונות הקלט או פריימים של וידאו שעליהם יש להציג את המסלולים. | IMAGE | כן | - |
| `tracks` | נתוני מעקב תנועה המכילים נתיבי נקודות ומידע על נראות. אם לא מסופק, תמונות הקלט מועברות ללא שינוי. | TRACKS | לא | - |
| `line_resolution` | מספר הפריימים הקודמים לשימוש בעת ציור קו הנתיב הנגרר עבור כל מסלול (ברירת מחדל: 24). | INT | כן | 1 - 1024 |
| `circle_size` | גודל העיגול המצויר במיקום הנוכחי של כל מסלול (ברירת מחדל: 12). מסומן כפרמטר מתקדם. | INT | כן | 1 - 128 |
| `opacity` | אטימות שכבות-העל של המסלולים המצוירים (ברירת מחדל: 0.75). | FLOAT | כן | 0.0 - 1.0 |
| `line_width` | רוחב הקווים המשמשים לציור נתיבי המסלולים (ברירת מחדל: 16). מסומן כפרמטר מתקדם. | INT | כן | 1 - 128 |

**הערה:** אם מספר תמונות הקלט אינו תואם למספר הפריימים בנתוני `tracks` המסופקים, רצף התמונות יחזר על עצמו כדי להתאים לאורך המסלול.

**הערה:** נקודות מעקב מצוירות עם סט מוגבל של צבעים חוזרים, ונקודה מדולגת בפריים כאשר דגל הנראות שלה הוא אפס עבור אותו פריים.
