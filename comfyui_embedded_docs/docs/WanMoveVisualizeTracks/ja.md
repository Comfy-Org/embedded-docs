# WanMoveVisualizeTracks

WanMoveVisualizeTracksノードは、一連の画像またはビデオフレームにモーショントラッキングデータを描画します。各追跡ポイントの現在位置に円を配置し、最近のフレームでポイントが移動した経路を示すフェードする軌跡ラインを描画します。トラックデータが提供されない場合、入力画像は変更されずに返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | トラックが可視化される入力画像またはビデオフレームのシーケンスです。 | IMAGE | はい | - |
| `tracks` | ポイント位置と可視性情報を含むモーショントラッキングデータです。提供されない場合、入力画像は変更されずに通過します。 | TRACKS | いいえ | - |
| `line_resolution` | 各トラックの軌跡ラインを描画する際に使用する過去のフレーム数です（デフォルト：24）。 | INT | はい | 1 - 1024 |
| `circle_size` | 各追跡ポイントの現在位置に描画される円のサイズです（デフォルト：12）。 | INT | はい | 1 - 128 |
| `opacity` | 描画されるトラックオーバーレイの不透明度です（デフォルト：0.75）。 | FLOAT | はい | 0.0 - 1.0 |
| `line_width` | トラックパスの描画に使用されるラインの幅です（デフォルト：16）。 | INT | はい | 1 - 128 |

**注記：** 入力画像の数が提供された`tracks`データのフレーム数と一致しない場合、入力画像シーケンスはトラックデータに合わせて繰り返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | モーショントラッキングデータがオーバーレイとして描画された画像シーケンスです。`tracks`が提供されなかった場合、元の入力画像が変更されずに返されます。 | IMAGE |
