# WanMoveVisualizeTracks

WanMoveVisualizeTracks 節點會將動態追蹤資料疊加到位於影像或視訊幀序列上。它會繪製追蹤點的視覺化表示，包含其移動路徑與當前位置，讓動態資料更易於觀察與分析。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要在其上視覺化軌跡的輸入影像或視訊幀序列。 | IMAGE | 是 | - |
| `軌跡` | 包含點路徑與可見性資訊的動態追蹤資料。若未提供，輸入影像將原封不動地傳遞。 | TRACKS | 否 | - |
| `線條解析度` | 用於繪製每個軌跡尾端路徑線的先前幀數（預設值：24）。 | INT | 是 | 1 - 1024 |
| `圓圈大小` | 在每個軌跡當前位置所繪製圓形的大小（預設值：12）。 | INT | 是 | 1 - 128 |
| `不透明度` | 所繪製軌跡疊加圖層的不透明度（預設值：0.75）。 | FLOAT | 是 | 0.0 - 1.0 |
| `線寬` | 用於繪製軌跡路徑的線條寬度（預設值：16）。 | INT | 是 | 1 - 128 |

**注意：** 如果輸入影像的數量與所提供 `tracks` 資料中的幀數不符，影像序列將重複以符合軌跡長度。
