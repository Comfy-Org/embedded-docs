# WanMoveVisualizeTracks

WanMoveVisualizeTracks 節點會將動作追蹤資料疊加到一系列影像或視訊影格上。它會繪製被追蹤點的視覺化表示，包括其移動路徑與目前位置，使動作資料可視化並更容易分析。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要在其上視覺化追蹤結果的輸入影像或視訊影格序列。 | IMAGE | 是 | - |
| `軌跡` | 包含點路徑與可見性資訊的動作追蹤資料。若未提供，輸入影像會原樣傳遞。 | TRACKS | 否 | - |
| `線條解析度` | 為每個追蹤繪製尾跡線時要使用的先前影格數量（預設：24）。 | INT | 是 | 1 - 1024 |
| `圓圈大小` | 在每個追蹤目前位置繪製的圓形大小（預設：12）。標記為進階參數。 | INT | 是 | 1 - 128 |
| `不透明度` | 所繪製追蹤疊加層的不透明度（預設：0.75）。 | FLOAT | 是 | 0.0 - 1.0 |
| `線寬` | 用於繪製追蹤路徑的線條寬度（預設：16）。標記為進階參數。 | INT | 是 | 1 - 128 |

**注意：** 若輸入影像的數量與所提供的 `tracks` 資料中的影格數不符，影像序列將會重複以符合追蹤長度。

**注意：** 追蹤點會以一組有限的重複顏色繪製，而當某個點在該影格的可見性旗標為零時，該點會在該影格中被略過。
