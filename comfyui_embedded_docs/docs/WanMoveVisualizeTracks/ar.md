# WanMoveVisualizeTracks

تضع عُقدة WanMoveVisualizeTracks بيانات تتبّع الحركة كتراكب فوق سلسلة من الصور أو إطارات الفيديو. وهي ترسم تمثيلات بصرية للنقاط المتتبعة، بما في ذلك مسارات حركتها ومواضعها الحالية، مما يجعل بيانات الحركة مرئية وأسهل في التحليل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | سلسلة الصور المدخلة أو إطارات الفيديو المراد إظهار المسارات فوقها. | IMAGE | نعم | - |
| `tracks` | بيانات تتبّع الحركة التي تحتوي على مسارات النقاط ومعلومات الظهور. إذا لم يتم توفيرها، تمرّر الصور المدخلة كما هي دون تغيير. | TRACKS | لا | - |
| `line_resolution` | عدد الإطارات السابقة المستخدمة عند رسم خط المسار اللاحق لكل تتبّع (القيمة الافتراضية: 24). | INT | نعم | 1 - 1024 |
| `circle_size` | حجم الدائرة المرسومة عند الموضع الحالي لكل تتبّع (القيمة الافتراضية: 12). موسوم كمعامل متقدم. | INT | نعم | 1 - 128 |
| `opacity` | مقدار العتامة لتراكبات التتبّع المرسومة (القيمة الافتراضية: 0.75). | FLOAT | نعم | 0.0 - 1.0 |
| `line_width` | عرض الخطوط المستخدمة لرسم مسارات التتبّع (القيمة الافتراضية: 16). موسوم كمعامل متقدم. | INT | نعم | 1 - 128 |

**ملاحظة:** إذا لم يتطابق عدد الصور المدخلة مع عدد الإطارات في بيانات `tracks` الموفّرة، فستُكرّر سلسلة الصور لتطابق طول التتبّع.

**ملاحظة:** تُرسم نقاط التتبّع باستخدام مجموعة محدودة من الألوان المتكررة، ويُتخطّى رسم النقطة في أحد الإطارات عندما تكون إشارة ظهورها صفرًا في ذلك الإطار.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
