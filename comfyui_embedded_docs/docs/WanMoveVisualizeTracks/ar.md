# WanMoveVisualizeTracks

تستمد العقدة `WanMoveVisualizeTracks` بيانات تتبع الحركة على سلسلة من الصور أو إطارات الفيديو. ترسم دائرة عند الموضع الحالي لكل نقطة متتبَّعة، وترسم خط مسار متلاشي يوضح المكان الذي تحركت إليه النقطة عبر الإطارات السابقة. إذا لم يتم توفير بيانات تتبع، فتُعاد الصور المدخلة كما هي دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `images` | سلسلة الصور المدخلة أو إطارات الفيديو التي سيتم عرض بيانات التتبع عليها. | IMAGE | نعم | - |
| `tracks` | بيانات تتبع الحركة التي تحتوي على مواضع النقاط ومعلومات الرؤية. إذا لم يتم توفيرها، تَمُر الصور المدخلة دون تغيير. | TRACKS | لا | - |
| `line_resolution` | عدد الإطارات السابقة المستخدمة عند رسم خط المسار المتلاشي لكل مسار (الافتراضي: 24). | INT | نعم | 1 - 1024 |
| `circle_size` | حجم الدائرة المرسومة عند الموضع الحالي لكل نقطة متتبَّعة (الافتراضي: 12). | INT | نعم | 1 - 128 |
| `opacity` | شفافية تراكبات التتبع المرسومة (الافتراضي: 0.75). | FLOAT | نعم | 0.0 - 1.0 |
| `line_width` | عرض الخطوط المستخدمة لرسم مسارات التتبع (الافتراضي: 16). | INT | نعم | 1 - 128 |

**ملاحظة:** إذا كان عدد الصور المدخلة لا يطابق عدد الإطارات في بيانات `tracks` المقدَّمة، تُكرَّر سلسلة الصور المدخلة لمحاذاة بيانات التتبع.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
