# WanMoveVisualizeTracks

The WanMoveVisualizeTracks node overlays motion tracking data onto a sequence of images or video frames. It draws visual representations of tracked points, including their movement paths and current positions, making the motion data visible and easier to analyze.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصور` | تسلسل الصور المدخلة أو إطارات الفيديو لعرض المسارات عليها. | IMAGE | نعم | - |
| `المسارات` | بيانات تتبع الحركة التي تحتوي على مسارات النقاط ومعلومات الرؤية. إذا لم يتم توفيرها، تمرر الصور المدخلة دون تغيير. | TRACKS | لا | - |
| `دقة الخط` | عدد الإطارات السابقة المستخدمة عند رسم خط المسار اللاحق لكل مسار (الافتراضي: 24). | INT | نعم | 1 - 1024 |
| `حجم الدائرة` | حجم الدائرة المرسومة عند الموضع الحالي لكل مسار (الافتراضي: 12). | INT | نعم | 1 - 128 |
| `الشفافية` | شفافية التراكبات المرسومة للمسارات (الافتراضي: 0.75). | FLOAT | نعم | 0.0 - 1.0 |
| `عرض الخط` | عرض الخطوط المستخدمة لرسم مسارات التتبع (الافتراضي: 16). | INT | نعم | 1 - 128 |

**ملاحظة:** إذا كان عدد الصور المدخلة لا يطابق عدد الإطارات في بيانات `tracks` المقدمة، فسيتم تكرار تسلسل الصور ليطابق طول المسارات.
