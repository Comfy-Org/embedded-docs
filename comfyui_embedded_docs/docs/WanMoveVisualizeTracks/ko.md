# WanMoveVisualizeTracks

WanMoveVisualizeTracks 노드는 이미지 또는 비디오 프레임 시퀀스에 모션 추적 데이터를 그립니다. 각 추적 지점의 현재 위치에 원을 표시하고, 해당 지점이 최근 프레임에서 이동한 경로를 보여주는 페이딩 경로 선을 그립니다. 추적 데이터가 제공되지 않으면 입력 이미지가 변경되지 않은 채 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `images` | 추적이 시각화될 입력 이미지 또는 비디오 프레임의 시퀀스입니다. | IMAGE | 예 | - |
| `tracks` | 점 위치 및 가시성 정보를 포함하는 모션 추적 데이터입니다. 제공되지 않으면 입력 이미지가 변경되지 않은 채 통과됩니다. | TRACKS | 아니요 | - |
| `line_resolution` | 각 추적의 경로 선을 그릴 때 사용할 이전 프레임 수입니다 (기본값: 24). | INT | 예 | 1 - 1024 |
| `circle_size` | 각 추적 지점의 현재 위치에 그려지는 원의 크기입니다 (기본값: 12). | INT | 예 | 1 - 128 |
| `opacity` | 그려진 추적 오버레이의 불투명도입니다 (기본값: 0.75). | FLOAT | 예 | 0.0 - 1.0 |
| `line_width` | 추적 경로를 그리는 데 사용되는 선의 굵기입니다 (기본값: 16). | INT | 예 | 1 - 128 |

**참고:** 입력 이미지 수가 제공된 `tracks` 데이터의 프레임 수와 일치하지 않으면, 입력 이미지 시퀀스가 추적 데이터에 맞춰 반복됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `IMAGE` | 모션 추적 데이터가 오버레이로 그려진 이미지 시퀀스입니다. `tracks`가 제공되지 않은 경우 원본 입력 이미지가 변경되지 않은 채 반환됩니다. | IMAGE |
