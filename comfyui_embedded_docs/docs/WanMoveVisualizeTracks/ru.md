# WanMoveVisualizeTracks

**Узел WanMoveVisualizeTracks** накладывает данные отслеживания движения на последовательность изображений или видеокадров. Он отображает визуальные представления отслеживаемых точек, включая их пути движения и текущие позиции, что делает данные о движении наглядными и упрощает их анализ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Последовательность входных изображений или видеокадров, на которых визуализируются треки. | IMAGE | Да | - |
| `треки` | Данные отслеживания движения, содержащие пути точек и информацию о видимости. Если не указаны, входные изображения передаются без изменений. | TRACKS | Нет | - |
| `разрешение_линии` | Количество предыдущих кадров, используемых для отрисовки линии пройденного пути каждого трека (по умолчанию: 24). | INT | Да | 1 - 1024 |
| `размер_круга` | Размер круга, отображаемого в текущей позиции каждого трека (по умолчанию: 12). | INT | Да | 1 - 128 |
| `непрозрачность` | Непрозрачность наложений, отображающих треки (по умолчанию: 0.75). | FLOAT | Да | 0.0 - 1.0 |
| `толщина_линии` | Ширина линий, используемых для отрисовки путей треков (по умолчанию: 16). | INT | Да | 1 - 128 |

**Примечание:** Если количество входных изображений не совпадает с количеством кадров в предоставленных данных `tracks`, последовательность изображений будет повторена для соответствия длине треков.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Последовательность изображений с визуализированными данными отслеживания движения в виде наложений. Если `tracks` не были предоставлены, возвращаются исходные входные изображения. | IMAGE |
