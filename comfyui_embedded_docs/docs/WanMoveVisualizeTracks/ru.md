# WanMoveVisualizeTracks

Узел WanMoveVisualizeTracks накладывает данные отслеживания движения на последовательность изображений или видеокадров. Он рисует визуальные представления отслеживаемых точек, включая траектории их движения и текущие позиции, делая данные о движении видимыми и более удобными для анализа.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Последовательность входных изображений или видеокадров, на которые нужно визуализировать треки. | IMAGE | Да | - |
| `треки` | Данные отслеживания движения, содержащие траектории точек и информацию о видимости. Если не предоставлены, входные изображения передаются без изменений. | TRACKS | Нет | - |
| `разрешение_линии` | Количество предыдущих кадров, используемых при отрисовке линии следа для каждого трека (по умолчанию: 24). | INT | Да | 1 - 1024 |
| `размер_круга` | Размер круга, рисуемого в текущей позиции каждого трека (по умолчанию: 12). Отмечен как расширенный параметр. | INT | Да | 1 - 128 |
| `непрозрачность` | Непрозрачность накладываемых визуализаций треков (по умолчанию: 0.75). | FLOAT | Да | 0.0 - 1.0 |
| `толщина_линии` | Ширина линий, используемых для отрисовки траекторий треков (по умолчанию: 16). Отмечен как расширенный параметр. | INT | Да | 1 - 128 |

**Примечание:** Если количество входных изображений не совпадает с количеством кадров в предоставленных данных `tracks`, последовательность изображений будет повторена, чтобы соответствовать длине треков.

**Примечание:** Точки треков рисуются с ограниченным набором повторяющихся цветов, и точка пропускается в кадре, когда её флаг видимости равен нулю для этого кадра.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Последовательность изображений с визуализированными данными отслеживания движения в виде наложений. Если `tracks` не были предоставлены, возвращаются исходные входные изображения. | IMAGE |
