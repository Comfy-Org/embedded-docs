# WanMoveVisualizeTracks

Узел `WanMoveVisualizeTracks` отображает данные отслеживания движения на последовательности изображений или видеокадров. Он помещает круг в текущую позицию каждой отслеживаемой точки и рисует затухающую линию пути, показывающую, куда перемещалась точка за последние кадры. Если данные отслеживания не предоставлены, входные изображения возвращаются без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Последовательность входных изображений или видеокадров, на которых будут визуализироваться треки. | IMAGE | Да | - |
| `tracks` | Данные отслеживания движения, содержащие позиции точек и информацию о видимости. Если не предоставлены, входные изображения передаются без изменений. | TRACKS | Нет | - |
| `line_resolution` | Количество предыдущих кадров, используемых при рисовании линии траектории для каждого трека (по умолчанию: 24). | INT | Да | 1 - 1024 |
| `circle_size` | Размер круга, рисуемого в текущей позиции каждой отслеживаемой точки (по умолчанию: 12). | INT | Да | 1 - 128 |
| `opacity` | Непрозрачность наложенных элементов отображения треков (по умолчанию: 0.75). | FLOAT | Да | 0.0 - 1.0 |
| `line_width` | Ширина линий, используемых для рисования путей треков (по умолчанию: 16). | INT | Да | 1 - 128 |

**Примечание:** Если количество входных изображений не совпадает с количеством кадров в предоставленных данных `tracks`, последовательность входных изображений повторяется для согласования с данными треков.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Последовательность изображений с наложенными данными отслеживания движения. Если `tracks` не были предоставлены, возвращаются исходные входные изображения без изменений. | IMAGE |
