# Breeze Voice Selector

Выбирает представленный голос Breeze или любой идентификатор голоса Breeze и передаёт его в Breeze Text to Speech. Узел только разрешает идентификатор и не выполняет вызов API.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `language` | Языковая группа представленных голосов или `custom` для ввода идентификатора. По умолчанию: `"English"`. | DYNAMIC_COMBO | Да | `"English"`<br>`"Chinese"`<br>`"Japanese"`<br>`"custom"` |

### Входы для языков "English", "Chinese" и "Japanese"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voice` | Представленный голос на этом языке. | COMBO | Да | Доступно несколько вариантов |

### Входы для языка "custom"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voice_id` | Любой идентификатор голоса Breeze, например голос, созданный другими узлами Breeze. Только буквы, цифры, `_` и `-`. По умолчанию: пусто. | STRING | Да | Идентификатор голоса Breeze |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voice` | Выбранный голос Breeze. | BREEZE_VOICE |
