# LayersFromBoundingBoxes

Этот узел преобразует пакет изображений и его ограничивающие рамки в стек слоев, создавая один слой на кадр и размещая каждый слой в соответствии с его рамкой. Используйте его, когда узел выводит слои в виде пакета, поскольку пакет содержит только одно размещение для каждого кадра, и в противном случае индивидуальные позиции были бы потеряны.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Пакет изображений; каждый кадр становится одним слоем. | IMAGE | Да | — |
| `ограничивающие_рамки` | Рамки размещения, выровненные по индексу с пакетом изображений. Принимает ограничивающие рамки (x, y, width, height), нормализованные элементы (с "bbox" — для них требуются canvas_width/canvas_height для преобразования в пиксели) или JSON-строку любого из этих вариантов. Кадры без соответствующей рамки размещаются в начале координат. Ширина/высота рамки масштабирует слой, чтобы он соответствовал ей. metadata.name (или desc) и metadata.z_index используются при их наличии, а metadata.content_rect (относительно кадра) обрезает кадр до его реального содержимого. | BOUNDING_BOX, ARRAY или STRING | Да | — |
| `маска` | Прозрачность для каждого кадра, выровненная по индексу с пакетом изображений (1 = прозрачный, согласно соглашению LoadImage). | MASK | Нет | — |
| `слои` | Стек слоев, к которому нужно добавить. Оставьте неподключенным, чтобы начать новый стек. | LAYERS | Нет | — |
| `обрезать_по_контенту` | Обрезать каждый кадр до metadata.content_rect, если он присутствует, и размещать содержимое в позиции рамки плюс смещение прямоугольника. Оставьте включенным для пакетов, кадры которых имеют поля — это сохраняет только реальное содержимое в его истинном месте. (по умолчанию: true) | BOOLEAN | Нет | true<br>false |
| `ширина_холста` | Ширина документа. 0 означает автоматическое определение по размещенным слоям. (по умолчанию: 0) | INT | Нет | 0 до MAX_RESOLUTION |
| `высота_холста` | Высота документа. 0 означает автоматическое определение по размещенным слоям. (по умолчанию: 0) | INT | Нет | 0 до MAX_RESOLUTION |

Примечания:

- `bboxes` и `mask` должны быть выровнены по индексу с `image`: n-я рамка и n-й кадр маски соответствуют n-му кадру изображения. Кадры без соответствующей рамки размещаются в начале координат.
- Когда `bboxes` содержит нормализованные элементы (с "bbox"), необходимо указать `canvas_width` и `canvas_height`, чтобы эти нормализованные позиции можно было преобразовать в пиксели.
- `canvas_width` и `canvas_height` должны быть больше 0, чтобы явно задать холст документа. Если любое из них равно 0, холст определяется по размещенным слоям или наследуется из подключенного стека `layers`.
- Когда `layers` подключен, новые слои добавляются к нему и получают значения z-index выше самого высокого z-index, уже присутствующего в стеке.
- Когда `crop_to_content` включен и кадр имеет metadata.content_rect, кадр обрезается до этого прямоугольника, и масштабирование ширины/высоты рамки не применяется; вместо этого смещение прямоугольника добавляется к позиции рамки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LAYERS` | Стек слоев, готовый для Create Layered Image. | LAYERS |
