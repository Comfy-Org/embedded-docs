# LayersFromBoundingBoxes

این گره یک دسته تصویر و جعبه‌های محدودکننده‌ی آن را به یک پشته لایه تبدیل می‌کند؛ به‌طوری که برای هر فریم یک لایه ساخته و هر لایه را مطابق جعبه‌ی متناظرش قرار می‌دهد. زمانی از آن استفاده کنید که یک گره، لایه‌ها را به‌صورت دسته‌ای خروجی می‌دهد، زیرا یک دسته فقط یک مکان‌دهی واحد برای همه فریم‌ها حمل می‌کند و در غیر این صورت موقعیت‌های جداگانه از بین می‌روند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | دسته تصویر؛ هر فریم به یک لایه تبدیل می‌شود. | IMAGE | بله | — |
| `bboxes` | جعبه‌های مکان‌دهی، هم‌اندیس با دسته تصویر. جعبه‌های محدودکننده (x, y, width, height)، عناصر نرمال‌شده (دارای «bbox» — این‌ها برای تبدیل شدن به پیکسل به canvas_width/canvas_height نیاز دارند)، یا یک رشته JSON از هر کدام را می‌پذیرد. فریم‌هایی که جعبه‌ی متناظر ندارند در مبدأ قرار می‌گیرند. عرض/ارتفاع یک جعبه، لایه را برای تناسب با آن مقیاس‌بندی می‌کند. در صورت وجود، metadata.name (یا desc) و metadata.z_index استفاده می‌شوند و metadata.content_rect (نسبت به فریم) فریم را تا محتوای واقعی آن برش می‌دهد. | BOUNDING_BOX, ARRAY, یا STRING | بله | — |
| `mask` | شفافیت به‌ازای هر فریم، هم‌اندیس با دسته تصویر (1 = شفاف، مطابق قرارداد LoadImage). | MASK | خیر | — |
| `layers` | پشته لایه‌ای که لایه‌ها به آن اضافه می‌شوند. برای شروع یک پشته جدید، آن را متصل نکنید. | LAYERS | خیر | — |
| `crop_to_content` | هر فریم را در صورت وجود به metadata.content_rect برش می‌دهد و محتوا را در موقعیت جعبه به‌علاوه‌ی آفست مستطیل قرار می‌دهد. برای دسته‌هایی که فریم‌هایشان padding دارند، آن را روشن بگذارید — این کار فقط محتوای واقعی را در مکان درست نگه می‌دارد. (پیش‌فرض: true) | BOOLEAN | خیر | true<br>false |
| `canvas_width` | عرض بوم سند. 0 آن را از لایه‌های قرارگرفته استخراج می‌کند. (پیش‌فرض: 0) | INT | خیر | 0 تا MAX_RESOLUTION |
| `canvas_height` | ارتفاع بوم سند. 0 آن را از لایه‌های قرارگرفته استخراج می‌کند. (پیش‌فرض: 0) | INT | خیر | 0 تا MAX_RESOLUTION |

نکات:

- `bboxes` و `mask` باید هم‌اندیس با `image` باشند: جعبه‌ی nام و فریم nام ماسک با فریم nام تصویر متناظرند. فریم‌هایی که جعبه‌ی متناظر ندارند در مبدأ قرار می‌گیرند.
- وقتی `bboxes` شامل عناصر نرمال‌شده (دارای «bbox») است، باید `canvas_width` و `canvas_height` ارائه شوند تا آن موقعیت‌های نرمال‌شده به پیکسل تبدیل شوند.
- برای تنظیم صریح بوم سند، `canvas_width` و `canvas_height` هر دو باید بزرگ‌تر از 0 باشند. اگر هر یک 0 باشد، بوم از لایه‌های قرارگرفته استخراج می‌شود یا از پشته `layers` متصل به ارث برده می‌شود.
- وقتی `layers` متصل باشد، لایه‌های جدید به آن اضافه می‌شوند و مقادیر z-index بالاتر از بالاترین z-index موجود در پشته دریافت می‌کنند.
- وقتی `crop_to_content` فعال باشد و فریمی دارای metadata.content_rect باشد، فریم به آن مستطیل برش می‌خورد و مقیاس‌بندی عرض/ارتفاع جعبه اعمال نمی‌شود؛ در عوض، آفست مستطیل به موقعیت جعبه اضافه می‌شود.
