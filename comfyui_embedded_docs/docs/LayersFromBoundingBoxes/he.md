# LayersFromBoundingBoxes

צומת זה ממיר אצוות תמונות ותיבות תוחמות שלה לערימת שכבות, ויוצר שכבה אחת לכל פריים וממקם כל שכבה בהתאם לתיבה המתאימה לה. השתמש בו כאשר צומת מוציא שכבות כאצווה, מכיוון שאצווה נושאת מיקום יחיד בלבד לכל פריים והמיקומים הנפרדים היו הולכים לאיבוד אחרת.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | אצוות תמונות; כל פריים הופך לשכבה אחת. | IMAGE | כן | — |
| `bboxes` | תיבות מיקום, מיושרות לפי אינדקס עם אצוות התמונות. מקבל תיבות תוחמות (x, y, width, height), רכיבים מנורמלים (עם "bbox" — אלה דורשים canvas_width/canvas_height כדי להמיר לפיקסלים), או מחרוזת JSON של כל אחד מאלה. פריימים ללא תיבה תואמת ממוקמים בנקודת הראשית. רוחב/גובה של תיבה משנה את קנה המידה של השכבה כדי להתאים לה. metadata.name (או desc) ו-metadata.z_index משמשים כאשר קיימים, ו-metadata.content_rect (יחסי לפריים) חותך את הפריים לתוכן האמיתי שלו. | BOUNDING_BOX, ARRAY, or STRING | כן | — |
| `mask` | שקיפות לכל פריים, מיושרת לפי אינדקס עם אצוות התמונות (1 = שקוף, לפי המוסכמה של LoadImage). | MASK | לא | — |
| `layers` | ערימת שכבות להוספה אליה. השאר ללא חיבור כדי להתחיל ערימה חדשה. | LAYERS | לא | — |
| `crop_to_content` | חתוך כל פריים ל-metadata.content_rect היכן שקיים, ומקם את התוכן במיקום התיבה בתוספת היסט המלבן. השאר מופעל עבור אצוות שהפריימים שלהן מרופדים — הוא שומר רק את התוכן האמיתי במקומו הנכון. (ברירת מחדל: true) | BOOLEAN | לא | true<br>false |
| `canvas_width` | רוחב קנבס המסמך. 0 גוזר אותו מהשכבות הממוקמות. (ברירת מחדל: 0) | INT | לא | 0 to MAX_RESOLUTION |
| `canvas_height` | גובה קנבס המסמך. 0 גוזר אותו מהשכבות הממוקמות. (ברירת מחדל: 0) | INT | לא | 0 to MAX_RESOLUTION |

הערות:

- `bboxes` ו-`mask` חייבים להיות מיושרים לפי אינדקס עם `image`: התיבה ה-n ופריים המסכה ה-n תואמים לפריים התמונה ה-n. פריימים ללא תיבה תואמת ממוקמים בנקודת הראשית.
- כאשר `bboxes` מכיל רכיבים מנורמלים (עם "bbox"), יש לספק `canvas_width` ו-`canvas_height` כדי שניתן יהיה להמיר את המיקומים המנורמלים האלה לפיקסלים.
- `canvas_width` ו-`canvas_height` חייבים שניהם להיות גדולים מ-0 כדי להגדיר את קנבס המסמך במפורש. אם אחד מהם הוא 0, הקנבס נגזר מהשכבות הממוקמות או עובר בירושה מערימת `layers` המחוברת.
- כאשר `layers` מחובר, שכבות חדשות מתווספות אליו ומקבלות ערכי z-index גבוהים מה-z-index הגבוה ביותר שכבר קיים בערימה.
- כאשר `crop_to_content` מופעל ולפריים יש metadata.content_rect, הפריים נחתך לאותו מלבן ולא מיושם שינוי קנה המידה של רוחב/גובה התיבה; במקום זאת, ההיסט של המלבן מתווסף למיקום התיבה.
