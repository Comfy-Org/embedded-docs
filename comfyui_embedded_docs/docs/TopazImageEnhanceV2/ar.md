# تحسين الصورة Topaz

تطبق Topaz Image Enhance التحسين القياسي الصناعي للصور ورفع دقتها على صورة إدخال واحدة باستخدام نماذج Topaz. ترسل الصورة إلى واجهة برمجة تطبيقات Topaz، وتعالجها باستخدام النموذج المحدد، وتعيد النتيجة المحسّنة. يمكنك الاختيار من بين ثلاثة نماذج: Reimagine وBloom 2 وWonder 3.5.

## المدخلات

### المدخلات العامة

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `الصورة` | صورة الإدخال المراد تحسينها. يتم دعم صورة إدخال واحدة فقط. | IMAGE | نعم | صورة واحدة |
| `النموذج` | نموذج التحسين من Topaz الذي سيتم استخدامه. يحدد النموذج المحدد الإعدادات الخاصة بالنموذج التي تظهر. | DYNAMIC_COMBO | نعم | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `عرض الإخراج` | القيمة صفر تعني الحساب تلقائيًا (عادةً سيكون الحجم الأصلي أو مقياسًا نسبيًا إلى `output_height` إذا تم تحديده). يدعم Wonder 3.5 عوامل رفع دقة من 1x إلى 6x فقط. تحافظ Bloom 2 وWonder 3.5 على نسبة الأبعاد الأصلية وتتعاملان مع الحجم المطلوب كهدف. (الافتراضي: 0) | INT | لا | 0 إلى 32000 |
| `ارتفاع الإخراج` | القيمة صفر تعني إخراج بنفس الارتفاع الأصلي أو مقياسًا نسبيًا إلى `output_width` إذا تم تحديده. يدعم Wonder 3.5 عوامل رفع دقة من 1x إلى 6x فقط. تحافظ Bloom 2 وWonder 3.5 على نسبة الأبعاد الأصلية وتتعاملان مع الحجم المطلوب كهدف. (الافتراضي: 0) | INT | لا | 0 إلى 32000 |

### مدخلات Reimagine

تنطبق هذه الإعدادات عندما يتم تعيين `model` على `"Reimagine"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجه نصي اختياري لتوجيه رفع الدقة الإبداعي. (الافتراضي: "") | STRING | نعم | أي نص |
| `creativity` | مستوى الإبداع للتحسين. (الافتراضي: 3) | INT | نعم | 1 إلى 9 |
| `subject_detection` | وضع اكتشاف الموضوع. | COMBO | نعم | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | تحسين الوجوه (إن وجدت) أثناء المعالجة. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `face_enhancement_creativity` | تعيين مستوى الإبداع لتحسين الوجه. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `face_enhancement_strength` | التحكم في مدى حدة الوجوه المحسّنة مقارنة بالخلفية. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `face_preservation` | الحفاظ على الهوية الوجهية للمواضيع. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `color_preservation` | الحفاظ على الألوان الأصلية. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `crop_to_fill` | افتراضيًا، تُضاف أشرطة سوداء (Letterbox) إلى الصورة عندما تختلف نسبة الأبعاد الناتجة. قم بالتمكين لقص الصورة لملء أبعاد الإخراج. (الافتراضي: False) | BOOLEAN | نعم | true<br>false |

### مدخلات Bloom 2

تنطبق هذه الإعدادات عندما يتم تعيين `model` على `"Bloom 2"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجه نصي اختياري للتوليد. اتركه فارغًا لتوليد موجه تلقائيًا من صورة الإدخال. (الافتراضي: "") | STRING | نعم | أي نص |
| `creativity` | 1 تعني تحسينًا مقيدًا، و9 تعني إعادة تفسير واضحة مع تفاصيل مولّدة حديثًا. (الافتراضي: 3) | INT | نعم | 1 إلى 9 |
| `seed` | البذرة (Seed) لتوليد قابل للتكرار. (الافتراضي: 2) | INT | نعم | 1 إلى 2000 |
| `color_preservation` | الحفاظ على الألوان الأصلية. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `grain` | إضافة حبيبات (Grain) إلى صورة الإخراج. (الافتراضي: False) | BOOLEAN | نعم | true<br>false |
| `grain_model` | نموذج الحبيبات المراد استخدامه. يتم تجاهله إذا كان grain معطلاً. | COMBO | نعم | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | قوة تأثير الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 إلى 1.0 |
| `grain_size` | حجم جزيئات الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 1.0) | FLOAT | نعم | 1.0 إلى 5.0 |
| `grain_density` | كثافة تأثير الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 إلى 1.0 |

### مدخلات Wonder 3.5

تنطبق هذه الإعدادات عندما يتم تعيين `model` على `"Wonder 3.5"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | مستوى التحسين لظروف الإدخال المختلفة. (الافتراضي: "high") | COMBO | نعم | `"low"`<br>`"medium"`<br>`"high"` |
| `grain` | إضافة حبيبات (Grain) إلى صورة الإخراج. (الافتراضي: False) | BOOLEAN | نعم | true<br>false |
| `grain_model` | نموذج الحبيبات المراد استخدامه. يتم تجاهله إذا كان grain معطلاً. | COMBO | نعم | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | قوة تأثير الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 إلى 1.0 |
| `grain_size` | حجم جزيئات الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 1.0) | FLOAT | نعم | 1.0 إلى 5.0 |
| `grain_density` | كثافة تأثير الحبيبات. يتم تجاهله إذا كان grain معطلاً. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 إلى 1.0 |

**ملاحظة:** يتم دعم صورة إدخال واحدة فقط. يتم تجاهل إعدادات الحبيبات (`grain_model` و`grain_strength` و`grain_size` و`grain_density`) ما لم يتم تمكين `grain`. بالنسبة إلى Bloom 2، يؤدي ترك `prompt` فارغًا إلى توليد موجه تلقائيًا من صورة الإدخال. يدعم Wonder 3.5 عوامل رفع دقة من 1x إلى 6x فقط؛ وتحافظ Bloom 2 وWonder 3.5 على نسبة الأبعاد الأصلية وتتعاملان مع الحجم المطلوب كهدف.
