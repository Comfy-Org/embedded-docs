# TopazImageEnhanceV2

Topaz Image Enhance يطبّق الترقية (Upscaling) وتحسين الصور وفق المعايير الصناعية على صورة إدخال واحدة باستخدام نماذج Topaz. يرسل الصورة إلى واجهة برمجة تطبيقات Topaz، ويعالجها باستخدام النموذج المحدد، ثم يعيد النتيجة المحسّنة. يمكنك الاختيار من بين ثلاثة نماذج: Reimagine وBloom 2 وWonder 3.5.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة الإدخال المراد تحسينها. يتم دعم صورة إدخال واحدة فقط. | IMAGE | نعم | صورة واحدة |
| `model` | نموذج التحسين من Topaz الذي سيتم استخدامه. يحدد النموذج المحدد الإعدادات الخاصة بالنموذج التي ستظهر. | STRING | نعم | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `output_width` | القيمة صفر تعني الحساب تلقائيًا (عادةً سيكون الحجم الأصلي أو مقياسًا نسبيًا إلى `output_height` إذا تم تحديده). يدعم Wonder 3.5 عوامل تكبير من 1x إلى 6x فقط. يحافظ كل من Bloom 2 وWonder 3.5 على نسبة العرض إلى الارتفاع للصورة المدخلة ويعاملان الحجم المطلوب كهدف. (الافتراضي: 0) | INT | لا | 0 to 32000 |
| `output_height` | القيمة صفر تعني الإخراج بنفس ارتفاع الصورة الأصلية أو بمقياس نسبي إلى `output_width` إذا تم تحديده. يدعم Wonder 3.5 عوامل تكبير من 1x إلى 6x فقط. يحافظ كل من Bloom 2 وWonder 3.5 على نسبة العرض إلى الارتفاع للصورة المدخلة ويعاملان الحجم المطلوب كهدف. (الافتراضي: 0) | INT | لا | 0 to 32000 |

### إعدادات Reimagine

تُطبق هذه الإعدادات عندما يتم تعيين `model` إلى `"Reimagine"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | مطالبة نصية اختيارية لتوجيه الترقية الإبداعية. (الافتراضي: "") | STRING | نعم | أي نص |
| `creativity` | مستوى الإبداع للتحسين. (الافتراضي: 3) | INT | نعم | 1 to 9 |
| `subject_detection` | وضع اكتشاف الموضوع. | STRING | نعم | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | تحسين الوجوه (إذا كانت موجودة) أثناء المعالجة. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `face_enhancement_creativity` | ضبط مستوى الإبداع لتحسين الوجه. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 to 1.0 |
| `face_enhancement_strength` | يتحكم في مدى حدة الوجوه المحسّنة مقارنة بالخلفية. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 to 1.0 |
| `face_preservation` | الحفاظ على الهوية الوجهية للأشخاص. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `color_preservation` | الحفاظ على الألوان الأصلية. (الافتراضي: True) | BOOLEAN | نعم | true<br>false |
| `crop_to_fill` | افتراضيًا، يتم عرض الصورة بأشرطة سوداء عندما يختلف نسبة أبعاد الإخراج. قم بالتمكين لقص الصورة لملء أبعاد الإخراج. (الافتراضي: False) | BOOLEAN | نعم | true<br>false |

| `grain_density` | كثافة تأثير الحبيبات. يتم تجاهله إذا كانت الحبيبات معطلة. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 to 1.0 |
