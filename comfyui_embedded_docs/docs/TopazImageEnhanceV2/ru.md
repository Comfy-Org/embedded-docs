# Topaz Улучшение Изображения

Topaz Image Enhance применяет стандартное для отрасли увеличение и улучшение изображения к одному входному изображению с помощью моделей Topaz. Он отправляет изображение в Topaz API, обрабатывает его выбранной моделью и возвращает улучшенный результат. Можно выбрать одну из трёх моделей: Reimagine, Bloom 2 и Wonder 3.5.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для улучшения. Поддерживается только одно входное изображение. | IMAGE | Да | Одно изображение |
| `model` | Используемая модель улучшения Topaz. Выбранная модель определяет, какие настройки, специфичные для модели, отображаются. | DYNAMIC_COMBO | Да | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `output_width` | Нулевое значение означает автоматический расчёт (обычно это будет исходный размер или размер, пропорционально масштабированный относительно `output_height`, если он указан). Wonder 3.5 поддерживает только коэффициенты увеличения от 1x до 6x. Bloom 2 и Wonder 3.5 сохраняют соотношение сторон входного изображения и рассматривают запрошенный размер как целевой. (по умолчанию: 0) | INT | Нет | 0 до 32000 |
| `output_height` | Нулевое значение означает вывод с исходной высотой или масштабирование пропорционально `output_width`, если он указан. Wonder 3.5 поддерживает только коэффициенты увеличения от 1x до 6x. Bloom 2 и Wonder 3.5 сохраняют соотношение сторон входного изображения и рассматривают запрошенный размер как целевой. (по умолчанию: 0) | INT | Нет | 0 до 32000 |

### Входы Reimagine

Эти настройки применяются, когда для `model` выбрано `"Reimagine"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Необязательный текстовый промпт для указания направления творческого увеличения. (по умолчанию: "") | STRING | Да | Любой текст |
| `creativity` | Уровень творческой свободы при улучшении. (по умолчанию: 3) | INT | Да | 1 до 9 |
| `subject_detection` | Режим определения субъекта (расширенный). | COMBO | Да | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | Улучшать лица (если они есть) во время обработки. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `face_enhancement_creativity` | Задаёт уровень творческой свободы для улучшения лиц. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 |
| `face_enhancement_strength` | Управляет тем, насколько резкими будут улучшенные лица по сравнению с фоном. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 |
| `face_preservation` | Сохранять лицевую идентичность субъектов. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `color_preservation` | Сохранять исходные цвета. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `crop_to_fill` | По умолчанию изображение вписывается с чёрными полосами, когда соотношение сторон вывода отличается. Включите, чтобы обрезать изображение для заполнения размеров вывода. (по умолчанию: False) | BOOLEAN | Да | true<br>false |

### Входы Bloom 2

Эти настройки применяются, когда для `model` выбрано `"Bloom 2"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Необязательный текстовый промпт для генерации. Оставьте пустым, чтобы автоматически сгенерировать промпт из входного изображения. (по умолчанию: "") | STRING | Да | Любой текст |
| `creativity` | 1 — сдержанное улучшение, 9 — выраженная переинтерпретация с заново сгенерированными деталями. (по умолчанию: 3) | INT | Да | 1 до 9 |
| `seed` | Seed для воспроизводимой генерации. (по умолчанию: 2) | INT | Да | 1 до 2000 |
| `color_preservation` | Сохранять исходные цвета. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `grain` | Добавлять зерно на выходное изображение. (по умолчанию: False) | BOOLEAN | Да | true<br>false |
| `grain_model` | Модель зерна. Игнорируется, если зерно отключено. | COMBO | Да | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | Сила эффекта зерна. Игнорируется, если зерно отключено. (по умолчанию: 0.5) | FLOAT | Да | 0.0 до 1.0 |
| `grain_size` | Размер частиц зерна. Игнорируется, если зерно отключено. (по умолчанию: 1.0) | FLOAT | Да | 1.0 до 5.0 |
| `grain_density` | Интенсивность эффекта зерна. Игнорируется, если зерно отключено. (по умолчанию: 0.5) | FLOAT | Да | 0.0 до 1.0 |

### Входы Wonder 3.5

Эти настройки применяются, когда для `model` выбрано `"Wonder 3.5"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | Уровень улучшения для различных входных условий. (по умолчанию: "high") | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `grain` | Добавлять зерно на выходное изображение. (по умолчанию: False) | BOOLEAN | Да | true<br>false |
| `grain_model` | Модель зерна. Игнорируется, если зерно отключено. | COMBO | Да | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | Сила эффекта зерна. Игнорируется, если зерно отключено. (по умолчанию: 0.5) | FLOAT | Да | 0.0 до 1.0 |
| `grain_size` | Размер частиц зерна. Игнорируется, если зерно отключено. (по умолчанию: 1.0) | FLOAT | Да | 1.0 до 5.0 |
| `grain_density` | Интенсивность эффекта зерна. Игнорируется, если зерно отключено. (по умолчанию: 0.5) | FLOAT | Да | 0.0 до 1.0 |

**Примечание:** Поддерживается только одно входное изображение; узел выдаёт ошибку, если входной пакет содержит более одного изображения. Настройки зерна (`grain_model`, `grain_strength`, `grain_size`, `grain_density`) игнорируются, если не включено `grain`. Для Bloom 2, если оставить `prompt` пустым, промпт автоматически генерируется из входного изображения. Wonder 3.5 поддерживает только коэффициенты увеличения от 1x до 6x; Bloom 2 и Wonder 3.5 сохраняют соотношение сторон входного изображения и рассматривают запрошенный размер как целевой.
