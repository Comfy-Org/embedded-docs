# TopazImageEnhanceV2

Topaz Image Enhance применяет отраслевые стандарты масштабирования и улучшения изображения к одному входному изображению с использованием моделей Topaz. Он отправляет изображение в Topaz API, обрабатывает его выбранной моделью и возвращает улучшенный результат. Вы можете выбрать одну из трех моделей: Reimagine, Bloom 2 и Wonder 3.5.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для улучшения. Поддерживается только одно входное изображение. | IMAGE | Да | Одно изображение |
| `model` | Модель улучшения Topaz для использования. Выбранная модель определяет, какие настройки, специфичные для модели, отображаются. | STRING | Да | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `output_width` | Нулевое значение означает автоматический расчет (обычно это исходный размер или масштабирование пропорционально `output_height`, если оно задано). Wonder 3.5 поддерживает только коэффициенты увеличения от 1x до 6x. Bloom 2 и Wonder 3.5 сохраняют соотношение сторон входного изображения и рассматривают запрошенный размер как целевой. (по умолчанию: 0) | INT | Нет | 0 to 32000 |
| `output_height` | Нулевое значение означает вывод с той же высотой, что и оригинал, или масштабирование пропорционально `output_width`, если оно задано. Wonder 3.5 поддерживает только коэффициенты увеличения от 1x до 6x. Bloom 2 и Wonder 3.5 сохраняют соотношение сторон входного изображения и рассматривают запрошенный размер как целевой. (по умолчанию: 0) | INT | Нет | 0 to 32000 |

### Настройки Reimagine

Эти настройки применяются, когда `model` установлен в `"Reimagine"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Необязательный текстовый промпт для управления творческим масштабированием. (по умолчанию: "") | STRING | Да | Любой текст |
| `creativity` | Уровень креативности для улучшения. (по умолчанию: 3) | INT | Да | 1 to 9 |
| `subject_detection` | Режим обнаружения объекта. | STRING | Да | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | Улучшать лица (если присутствуют) во время обработки. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `face_enhancement_creativity` | Задайте уровень креативности для улучшения лиц. (по умолчанию: 0.0) | FLOAT | Да | 0.0 to 1.0 |
| `face_enhancement_strength` | Управляет резкостью улучшенных лиц относительно фона. (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 1.0 |
| `face_preservation` | Сохранять идентичность лиц объектов. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `color_preservation` | Сохранять исходные цвета. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `crop_to_fill` | По умолчанию изображение получает черные полосы, когда выходное соотношение сторон отличается. Включите, чтобы обрезать изображение для заполнения выходных размеров. (по умолчанию: False) | BOOLEAN | Да | true<br>false |

### Настройки Bloom 2

Эти настройки применяются, когда `model` установлен в `"Bloom 2"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Необязательный текстовый промпт для генерации. Оставьте пустым, чтобы автоматически сгенерировать промпт из входного изображения. (по умолчанию: "") | STRING | Да | Любой текст |
| `creativity` | 1 — сдержанное улучшение, 9 — выраженная реинтерпретация с новыми деталями. (по умолчанию: 3) | INT | Да | 1 to 9 |
| `seed` | Сид (зерно) для воспроизводимой генерации. (по умолчанию: 2) | INT | Да | 1 to 2000 |
| `color_preservation` | Сохранять исходные цвета. (по умолчанию: True) | BOOLEAN | Да | true<br>false |
| `grain` | Добавить зернистость к выходному изображению. (по умолчанию: False) | BOOLEAN | Да | true<br>false |
| `grain_model` | Используемая модель зернистости. Игнорируется, если зернистость отключена. | STRING | Да | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | Сила эффекта зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 0.5) | FLOAT | Да | 0.0 to 1.0 |
| `grain_size` | Размер частиц зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 1.0) | FLOAT | Да | 1.0 to 5.0 |
| `grain_density` | Интенсивность эффекта зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 0.5) | FLOAT | Да | 0.0 to 1.0 |

### Настройки Wonder 3.5

Эти настройки применяются, когда `model` установлен в `"Wonder 3.5"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | Уровень улучшения для разных входных условий. (по умолчанию: "high") | STRING | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `grain` | Добавить зернистость к выходному изображению. (по умолчанию: False) | BOOLEAN | Да | true<br>false |
| `grain_model` | Используемая модель зернистости. Игнорируется, если зернистость отключена. | STRING | Да | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | Сила эффекта зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 0.5) | FLOAT | Да | 0.0 to 1.0 |
| `grain_size` | Размер частиц зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 1.0) | FLOAT | Да | 1.0 to 5.0 |
| `grain_density` | Интенсивность эффекта зернистости. Игнорируется, если зернистость отключена. (по умолчанию: 0.5) | FLOAT | Да | 0.0 to 1.0 |

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Улучшенное и масштабированное изображение, возвращаемое Topaz API. | IMAGE |
