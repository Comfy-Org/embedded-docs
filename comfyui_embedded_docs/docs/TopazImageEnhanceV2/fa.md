# TopazImageEnhanceV2

### Topaz Image Enhance

گره Topaz Image Enhance با استفاده از مدل‌های Topaz، بزرگ‌نمایی و بهبود تصویر را در سطح استاندارد صنعت بر روی یک تصویر ورودی اعمال می‌کند. تصویر را به API توپاز ارسال می‌کند، آن را با مدل انتخاب‌شده پردازش کرده و نتیجه بهبودیافته را بازمی‌گرداند. می‌توانید از سه مدل انتخاب کنید: Reimagine، Bloom 2 و Wonder 3.5.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی برای بهبود. تنها یک تصویر ورودی پشتیبانی می‌شود. | IMAGE | بله | تک‌تصویر |
| `مدل` | مدل بهبود Topaz که استفاده می‌شود. مدل انتخاب‌شده تعیین می‌کند کدام تنظیمات مخصوص مدل نمایش داده شوند. | STRING | بله | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `عرض خروجی` | مقدار صفر به معنای محاسبه خودکار است (معمولاً اندازه اصلی یا مقیاس‌شده متناسب با `output_height` در صورت مشخص بودن). Wonder 3.5 فقط از ضریب بزرگ‌نمایی 1x تا 6x پشتیبانی می‌کند. Bloom 2 و Wonder 3.5 نسبت ابعاد ورودی را حفظ کرده و اندازه درخواستی را به‌عنوان هدف در نظر می‌گیرند. (پیش‌فرض: 0) | INT | خیر | 0 تا 32000 |
| `ارتفاع خروجی` | مقدار صفر به معنای خروجی با همان ارتفاع اصلی یا مقیاس‌شده متناسب با `output_width` در صورت مشخص بودن است. Wonder 3.5 فقط از ضریب بزرگ‌نمایی 1x تا 6x پشتیبانی می‌کند. Bloom 2 و Wonder 3.5 نسبت ابعاد ورودی را حفظ کرده و اندازه درخواستی را به‌عنوان هدف در نظر می‌گیرند. (پیش‌فرض: 0) | INT | خیر | 0 تا 32000 |

### تنظیمات Reimagine

این تنظیمات زمانی اعمال می‌شوند که `model` روی `"Reimagine"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنمای اختیاری برای بزرگ‌نمایی خلاقانه. (پیش‌فرض: "") | STRING | بله | هر متنی |
| `creativity` | سطح خلاقیت برای بهبود. (پیش‌فرض: 3) | INT | بله | 1 تا 9 |
| `subject_detection` | حالت تشخیص سوژه. | STRING | بله | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | بهبود چهره‌ها (در صورت وجود) در طول پردازش. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `face_enhancement_creativity` | سطح خلاقیت را برای بهبود چهره تنظیم کنید. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 |
| `face_enhancement_strength` | کنترل می‌کند که چهره‌های بهبودیافته نسبت به پس‌زمینه چقدر شارپ باشند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |
| `face_preservation` | حفظ هویت چهره سوژه‌ها. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `color_preservation` | حفظ رنگ‌های اصلی. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `crop_to_fill` | به‌طور پیش‌فرض، وقتی نسبت ابعاد خروجی متفاوت باشد، تصویر به‌صورت letterbox نمایش داده می‌شود. برای برش تصویر و پر کردن ابعاد خروجی، این گزینه را فعال کنید. (پیش‌فرض: False) | BOOLEAN | بله | true<br>false |

| `grain_size` | اندازه ذرات گرین. اگر گرین غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 1.0 تا 5.0 |
| `grain_density` | تراکم افکت گرین. اگر گرین غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 تا 1.0 |
