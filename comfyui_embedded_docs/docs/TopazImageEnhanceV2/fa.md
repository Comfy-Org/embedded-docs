# افزایش کیفیت تصویر Topaz

Topaz Image Enhance با استفاده از مدل‌های Topaz، بزرگ‌نمایی و بهبود تصویر در سطح استانداردهای صنعتی را روی یک تصویر ورودی اعمال می‌کند. تصویر را به Topaz API می‌فرستد، آن را با مدل انتخاب‌شده پردازش می‌کند و نتیجه بهبودیافته را بازمی‌گرداند. می‌توانید از میان سه مدل انتخاب کنید: Reimagine، Bloom 2 و Wonder 3.5.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای بهبود. فقط یک تصویر ورودی پشتیبانی می‌شود. | IMAGE | بله | تک تصویر |
| `model` | مدل بهبود Topaz برای استفاده. مدل انتخاب‌شده تعیین می‌کند کدام تنظیمات مخصوص مدل نمایش داده شوند. | DYNAMIC_COMBO | بله | `"Reimagine"`<br>`"Bloom 2"`<br>`"Wonder 3.5"` |
| `output_width` | مقدار صفر یعنی محاسبه خودکار (معمولاً اندازه اصلی خواهد بود یا در صورت مشخص بودن `output_height`، به‌صورت متناسب با آن مقیاس می‌شود). Wonder 3.5 فقط از فاکتورهای بزرگ‌نمایی 1x تا 6x پشتیبانی می‌کند. Bloom 2 و Wonder 3.5 نسبت ابعاد ورودی را حفظ می‌کنند و اندازه درخواستی را به‌عنوان هدف در نظر می‌گیرند. (پیش‌فرض: 0) | INT | خیر | 0 تا 32000 |
| `output_height` | مقدار صفر یعنی خروجی با همان ارتفاع اصلی یا در صورت مشخص بودن `output_width`، به‌صورت متناسب با آن مقیاس می‌شود. Wonder 3.5 فقط از فاکتورهای بزرگ‌نمایی 1x تا 6x پشتیبانی می‌کند. Bloom 2 و Wonder 3.5 نسبت ابعاد ورودی را حفظ می‌کنند و اندازه درخواستی را به‌عنوان هدف در نظر می‌گیرند. (پیش‌فرض: 0) | INT | خیر | 0 تا 32000 |

### ورودی‌های Reimagine

این تنظیمات زمانی اعمال می‌شوند که `model` روی `"Reimagine"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | اعلان متنی اختیاری برای راهنمایی بزرگ‌نمایی خلاقانه. (پیش‌فرض: "") | STRING | بله | هر متنی |
| `creativity` | سطح خلاقیت برای بهبود. (پیش‌فرض: 3) | INT | بله | 1 تا 9 |
| `subject_detection` | حالت تشخیص سوژه (پیشرفته). | COMBO | بله | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | بهبود چهره‌ها (در صورت وجود) در طول پردازش. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `face_enhancement_creativity` | سطح خلاقیت را برای بهبود چهره تنظیم می‌کند. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 |
| `face_enhancement_strength` | کنترل می‌کند که چهره‌های بهبودیافته نسبت به پس‌زمینه چقدر واضح باشند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |
| `face_preservation` | حفظ هویت چهره سوژه‌ها. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `color_preservation` | حفظ رنگ‌های اصلی. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `crop_to_fill` | به‌طور پیش‌فرض، هنگامی که نسبت ابعاد خروجی متفاوت است، تصویر با حاشیه (letterbox) نمایش داده می‌شود. برای برش تصویر جهت پر کردن ابعاد خروجی، فعال کنید. (پیش‌فرض: False) | BOOLEAN | بله | true<br>false |

### ورودی‌های Bloom 2

این تنظیمات زمانی اعمال می‌شوند که `model` روی `"Bloom 2"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | اعلان متنی اختیاری برای تولید. برای تولید خودکار اعلان از تصویر ورودی، خالی بگذارید. (پیش‌فرض: "") | STRING | بله | هر متنی |
| `creativity` | 1 بهبود محدود، 9 بازتفسیر آشکار با جزئیات تازه‌تولیدشده است. (پیش‌فرض: 3) | INT | بله | 1 تا 9 |
| `seed` | دانه برای تولید قابل بازتولید. (پیش‌فرض: 2) | INT | بله | 1 تا 2000 |
| `color_preservation` | حفظ رنگ‌های اصلی. (پیش‌فرض: True) | BOOLEAN | بله | true<br>false |
| `grain` | افزودن دانه به تصویر خروجی. (پیش‌فرض: False) | BOOLEAN | بله | true<br>false |
| `grain_model` | مدل دانه برای استفاده. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. | COMBO | بله | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | شدت اثر دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 تا 1.0 |
| `grain_size` | اندازه ذرات دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 1.0 تا 5.0 |
| `grain_density` | میزان شدت اثر دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 تا 1.0 |

### ورودی‌های Wonder 3.5

این تنظیمات زمانی اعمال می‌شوند که `model` روی `"Wonder 3.5"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | سطح بهبود برای شرایط مختلف ورودی. (پیش‌فرض: "high") | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |
| `grain` | افزودن دانه به تصویر خروجی. (پیش‌فرض: False) | BOOLEAN | بله | true<br>false |
| `grain_model` | مدل دانه برای استفاده. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. | COMBO | بله | `"silver"`<br>`"gaussian"`<br>`"grey"` |
| `grain_strength` | شدت اثر دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 تا 1.0 |
| `grain_size` | اندازه ذرات دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 1.0 تا 5.0 |
| `grain_density` | میزان شدت اثر دانه. اگر دانه غیرفعال باشد نادیده گرفته می‌شود. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 تا 1.0 |

**توجه:** فقط یک تصویر ورودی پشتیبانی می‌شود؛ اگر دسته ورودی بیش از یک تصویر داشته باشد، گره خطا می‌دهد. تنظیمات دانه (`grain_model`، `grain_strength`، `grain_size`، `grain_density`) نادیده گرفته می‌شوند مگر اینکه `grain` فعال باشد. برای Bloom 2، خالی گذاشتن `prompt` به‌طور خودکار اعلانی از تصویر ورودی تولید می‌کند. Wonder 3.5 فقط از فاکتورهای بزرگ‌نمایی 1x تا 6x پشتیبانی می‌کند؛ Bloom 2 و Wonder 3.5 نسبت ابعاد ورودی را حفظ می‌کنند و اندازه درخواستی را به‌عنوان هدف در نظر می‌گیرند.
