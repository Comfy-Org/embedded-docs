# Flux2Scheduler

Flux2Scheduler ノードは、Flux2 モデル専用に調整された、デノイジング処理用のノイズレベル（シグマ）のシーケンスを生成します。このノードは、デノイジングステップ数と生成する画像の寸法に基づいてスケジュールを計算し、画像生成中におけるノイズ除去の進行に影響を与えます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `steps` | 実行するデノイジングステップ数。値が大きいほど通常はより詳細な結果が得られますが、処理に時間がかかります（デフォルト: 20）。 | INT | はい | 1 to 4096 |
| `width` | 生成する画像の幅（ピクセル単位）。この値はノイズスケジュールの計算に影響します（デフォルト: 1024）。 | INT | はい | 16 to 16384 (MAX_RESOLUTION) |
| `height` | 生成する画像の高さ（ピクセル単位）。この値はノイズスケジュールの計算に影響します（デフォルト: 1024）。 | INT | はい | 16 to 16384 (MAX_RESOLUTION) |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `sigmas` | サンプラー用のデノイジングスケジュールを定義するノイズレベル値（シグマ）のシーケンス。出力には、ステップ数よりも1つ多い値（`steps + 1`）が含まれます。 | SIGMAS |
