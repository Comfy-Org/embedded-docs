# Flux2Scheduler

Flux2Scheduler генерирует последовательность уровней шума (сигм) для процесса удаления шума, специально адаптированную для модели Flux. Он вычисляет расписание на основе количества шагов удаления шума и размеров целевого изображения, что влияет на последовательность удаления шума во время генерации изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `steps` | Количество шагов удаления шума. Более высокое значение обычно приводит к более детализированным результатам, но требует больше времени на обработку (по умолчанию: 20). | INT | Да | 1 до 4096 |
| `width` | Ширина генерируемого изображения в пикселях. Это значение влияет на расчет расписания шума (по умолчанию: 1024). | INT | Да | 16 до 16384 |
| `height` | Высота генерируемого изображения в пикселях. Это значение влияет на расчет расписания шума (по умолчанию: 1024). | INT | Да | 16 до 16384 |

Примечание: расписание вычисляется на основе длины последовательности изображения, которая определяется из `width` и `height` как `(width * height) / 256`, что отражает 16-кратное уменьшение скрытого пространства модели. Более крупные изображения создают более длинные последовательности, что соответствующим образом сдвигает расписание шума.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Последовательность значений уровня шума (сигм), определяющая расписание удаления шума для сэмплера. | SIGMAS |
