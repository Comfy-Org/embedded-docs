# Flux2Scheduler

Узел Flux2Scheduler генерирует последовательность уровней шума (сигм) для процесса денойзинга, специально адаптированную для модели Flux2. Он вычисляет расписание на основе количества шагов денойзинга и размеров целевого изображения, что влияет на прогрессию удаления шума во время генерации изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `steps` | Количество выполняемых шагов денойзинга. Более высокое значение обычно приводит к более детальным результатам, но требует больше времени на обработку (по умолчанию: 20). | INT | Да | 1 to 4096 |
| `width` | Ширина генерируемого изображения в пикселях. Это значение влияет на расчет расписания шума (по умолчанию: 1024). | INT | Да | 16 to 16384 (MAX_RESOLUTION) |
| `height` | Высота генерируемого изображения в пикселях. Это значение влияет на расчет расписания шума (по умолчанию: 1024). | INT | Да | 16 to 16384 (MAX_RESOLUTION) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Последовательность значений уровня шума (сигм), определяющая расписание денойзинга для сэмплера. Выход содержит на одно значение больше, чем количество шагов (`steps + 1`). | SIGMAS |
