# Flux2Scheduler

Flux2Scheduler 會為去噪過程生成一系列雜訊等級（sigma），專為 Flux 模型量身定制。它會根據去噪步數與目標影像的尺寸計算排程，進而影響影像生成期間雜訊移除的進程。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `步數` | 要執行的去噪步數。數值越高通常會產生更詳細的結果，但處理時間也會更長（預設值：20）。 | INT | 是 | 1 至 4096 |
| `寬度` | 要生成影像的寬度（像素）。此值會影響雜訊排程的計算（預設值：1024）。 | INT | 是 | 16 至 16384 |
| `高度` | 要生成影像的高度（像素）。此值會影響雜訊排程的計算（預設值：1024）。 | INT | 是 | 16 至 16384 |

注意：排程是根據影像序列長度計算的，而影像序列長度是由 `width` 和 `height` 以 `(width * height) / 256` 推導而來，反映了模型的 16 倍潛在空間降採樣。較大的影像會產生較長的序列，這會相應地改變雜訊排程。

## 輸出

| 輸出名 | 說明 | 資料型別 |
| --- | --- | --- |
| `sigmas` | 定義取樣器去噪排程的一系列雜訊等級值（sigma）。 | SIGMAS |
