# sync.so Lip Sync

צומת זה מסנכרן מחדש את תנועת הפה בסרטון עם אודיו דיבור חדש באמצעות API של sync.so. הוא מטפל אוטומטית בתקריבים, בפרופילים ובחסימות תוך שמירה על הבעת הדובר. העלות משתנה בהתאם למשך הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | קטע וידאו של הדובר לסנכרון מחדש. עד 4K (4096x2160); קצב פריימים קבוע של 24/25/30 fps מתאים ביותר. | VIDEO | כן | - |
| `audio` | אודיו דיבור שאליו לסנכרן את תנועת הפה. | AUDIO | כן | - |
| `seed` | Seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 42). | INT | כן | 0 to 2147483647 |
| `model` | מודל יצירה של sync.so. | COMBO | כן | "sync-3" |

הפרמטר `model` הוא קומבו דינמי הכולל את תת-הפרמטרים הבאים:

| תת-פרמטר | תיאור | סוג נתונים | חובה | טווח |
|---------------|-------------|-----------|----------|-------|
| `sync_mode` | כיצד לטפל באי-התאמה במשך בין הווידאו לאודיו; זה גם קובע את אורך הפלט. bounce: הווידאו מופעל קדימה ואז אחורה עד שהאודיו מסתיים (פלט = אורך האודיו). loop: הווידאו מתחיל מחדש עד שהאודיו מסתיים (פלט = אורך האודיו). remap: הווידאו נמתח בזמן כדי להתאים לאודיו (פלט = אורך האודיו). cut_off: הרצועה הארוכה נחתכת (פלט = האורך הקצר). silence: שום דבר לא נחתך; הרצועה הקצרה מרופדת (פלט = האורך הארוך). (ברירת מחדל: "bounce") | COMBO | כן | "bounce"<br>"cut_off"<br>"loop"<br>"silence"<br>"remap" |
| `speaker_selection` | איזה פנים לבצע סנכרון שפתיים כאשר כמה אנשים גלויים. default: תן למודל להחליט. auto-detect: זהה ועקוב אחר הדובר הפעיל. coordinates: כוון לפנים במיקום הפיקסל (speaker_x, speaker_y) בפריים שנבחר על ידי speaker_frame. (ברירת מחדל: "default") | COMBO | כן | "default"<br>"auto-detect"<br>"coordinates" |
| `speaker_frame` | פריים וידאו המשמש לאיתור הדובר. משמש רק כאשר `speaker_selection` מוגדר ל-'coordinates'. (ברירת מחדל: 0) | INT | לא | 0 to 1,000,000 |
| `speaker_x` | קואורדינטת X בפיקסלים של פני הדובר. משמש רק כאשר `speaker_selection` מוגדר ל-'coordinates'. (ברירת מחדל: 0) | INT | לא | 0 to 4096 |
| `speaker_y` | קואורדינטת Y בפיקסלים של פני הדובר. משמש רק כאשר `speaker_selection` מוגדר ל-'coordinates'. (ברירת מחדל: 0) | INT | לא | 0 to 4096 |

**אילוצים:**
- רזולוציית הווידאו לא תעלה על 4K (4096x2160). סרטונים מעל מגבלה זו יגרמו לשגיאה.
- משכי הווידאו והאודיו לא יעלו על 600 שניות (10 דקות).
- הפרמטרים `speaker_frame`, `speaker_x` ו-`speaker_y` משמשים רק כאשר `speaker_selection` מוגדר ל-"coordinates".
