# LumaRay32TextToVideoNode

צומת זה יוצר סרטון מפרומפט טקסטואלי באמצעות מודל Ray 3.2 של Luma. הוא שולח את הפרומפט והגדרות הסרטון שלך אל ה-API של Luma ומחזיר את הסרטון שנוצר יחד עם מזהה יצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי ליצירת הסרטון. | STRING | כן | 1 עד 6000 תווים |
| `aspect_ratio` | יחס הרוחב-גובה של הסרטון שנוצר. | STRING | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"` |
| `resolution` | רזולוציית הפלט של הסרטון (ברירת מחדל: "720p"). | STRING | כן | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration` | משך הסרטון שנוצר. | STRING | כן | `"5s"`<br>`"10s"` |
| `loop` | הפיכת הסרטון ללופ חלק. זמין רק עם משך של 5s. | BOOLEAN | לא | True/False (ברירת מחדל: False) |
| `seed` | Seed ליצירה ניתנת לשחזור. | INT | לא | 0 עד 2147483647 |

**הערה:** ניתן להפעיל את הפרמטר `loop` רק כאשר `duration` מוגדר ל-"5s". אם תגדיר את `duration` ל-"10s" ותפעיל את `loop`, הצומת יחזיר שגיאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `VIDEO` | קובץ הסרטון שנוצר. | VIDEO |
| `generation_id` | המזהה הייחודי של בקשת יצירת הסרטון. | STRING |
