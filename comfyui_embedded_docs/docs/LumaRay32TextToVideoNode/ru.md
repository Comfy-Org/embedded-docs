# Luma Ray 3.2: Текст в видео

Этот узел генерирует видео по текстовому запросу с помощью модели Luma Ray 3.2. Он отправляет ваш запрос и настройки видео в Luma API и возвращает сгенерированный видеофайл вместе с идентификатором генерации.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. | STRING | Да | от 1 до 6000 символов |
| `aspect_ratio` | Соотношение сторон генерируемого видео. | STRING | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"` |
| `resolution` | Выходное разрешение видео (по умолчанию: "720p"). | STRING | Да | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration` | Продолжительность генерируемого видео. | STRING | Да | `"5s"`<br>`"10s"` |
| `loop` | Создавать бесшовный цикл видео. Доступно только при длительности 5s. | BOOLEAN | Нет | True/False (по умолчанию: False) |
| `seed` | Сид для воспроизводимой генерации. | INT | Нет | от 0 до 2147483647 |

**Примечание:** Параметр `loop` можно включить только когда `duration` установлено в "5s". Если вы установите `duration` в "10s" и включите `loop`, узел вернёт ошибку.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный видеофайл. | VIDEO |
| `generation_id` | Уникальный идентификатор запроса на генерацию видео. | STRING |
