# Hunyuan3Dv2التكييف متعدد الرؤى

تجمع عقدة Hunyuan3Dv2ConditioningMultiView مخرجات رؤية CLIP من حتى أربع زوايا (أمامية، يسارية، خلفية، ويمينية) في تكييف واحد متعدد الزوايا. تُضاف ترميزات موضعية إلى تضمين رؤية CLIP لكل زاوية مقدَّمة، ثم تُدمج التضمينات الناتجة. تُخرج العقدة تكييفًا موجبًا بناءً على التضمينات المجمعة، وتكييفًا سالبًا مملوءًا بأصفار بنفس الشكل.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `الأمامي` | مخرجات رؤية CLIP للزاوية الأمامية. مدخل زاوية اختياري. | CLIP_VISION_OUTPUT | لا | - |
| `الأيسر` | مخرجات رؤية CLIP للزاوية اليسارية. مدخل زاوية اختياري. | CLIP_VISION_OUTPUT | لا | - |
| `الخلفي` | مخرجات رؤية CLIP للزاوية الخلفية. مدخل زاوية اختياري. | CLIP_VISION_OUTPUT | لا | - |
| `الأيمن` | مخرجات رؤية CLIP للزاوية اليمينية. مدخل زاوية اختياري. | CLIP_VISION_OUTPUT | لا | - |

**ملاحظة:** يجب توفير مدخل زاوية واحد على الأقل لكي تعمل العقدة. تعالج العقدة فقط الزوايا التي تحتوي على بيانات صالحة لمخرجات رؤية CLIP، وتتخطى الزوايا غير المتصلة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف موجب يحتوي على التضمينات متعددة الزوايا المجمعة مع الترميز الموضعي. | CONDITIONING |
| `negative` | تكييف سالب بقيم صفرية تطابق شكل التكييف الموجب. | CONDITIONING |
