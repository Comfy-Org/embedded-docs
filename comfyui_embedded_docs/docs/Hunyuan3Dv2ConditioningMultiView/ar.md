# Hunyuan3Dv2التكييف متعدد الرؤى

العقدة `Hunyuan3Dv2ConditioningMultiView` تعالج تضمينات رؤية CLIP متعددة العروض لتوليد فيديو ثلاثي الأبعاد. تستقبل تضمينات اختيارية للعروض الأمامية واليسرى والخلفية واليمنى، وتضيف ترميزًا موضعيًا إلى كل عرض مُقدَّم قبل دمجها في تسلسل تهيئة واحد. تُخرج العقدة كلاً من التهيئة الموجبة المستخلصة من التضمينات المجمعة والتهيئة السالبة بقيم صفرية.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `front` | مخرج رؤية CLIP للعرض الأمامي | CLIP_VISION_OUTPUT | لا | - |
| `left` | مخرج رؤية CLIP للعرض الأيسر | CLIP_VISION_OUTPUT | لا | - |
| `back` | مخرج رؤية CLIP للعرض الخلفي | CLIP_VISION_OUTPUT | لا | - |
| `right` | مخرج رؤية CLIP للعرض الأيمن | CLIP_VISION_OUTPUT | لا | - |

**ملاحظة:** يجب توفير مدخل عرض واحد على الأقل لكي تعمل العقدة. تقوم العقدة بمعالجة العروض التي تحتوي على بيانات صالحة لمخرج رؤية CLIP فقط. يحصل كل عرض مُقدَّم على ترميز موضعي استنادًا إلى موقعه (أمامي، يسار، خلفي، يمين)، ثم تُدمج العروض المشفَّرة بنفس هذا الترتيب.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تهيئة موجبة تحتوي على التضمينات متعددة العروض المجمعة مع الترميز الموضعي | CONDITIONING |
| `negative` | تهيئة سالبة تحتوي على قيم صفرية بنفس شكل التهيئة الموجبة | CONDITIONING |
