# Hunyuan3Dv2ConditioningMultiView

Узел Hunyuan3Dv2ConditioningMultiView обрабатывает мультивидовые CLIP vision эмбеддинги для генерации 3D-видео. Он принимает опциональные эмбеддинги видов спереди, слева, сзади и справа и добавляет позиционное кодирование к каждому предоставленному виду перед объединением их в единую последовательность conditioning. Узел выводит как позитивный conditioning из объединённых эмбеддингов, так и негативный conditioning с нулевыми значениями.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `front` | Выход CLIP vision для переднего вида | CLIP_VISION_OUTPUT | Нет | - |
| `left` | Выход CLIP vision для вида слева | CLIP_VISION_OUTPUT | Нет | - |
| `back` | Выход CLIP vision для заднего вида | CLIP_VISION_OUTPUT | Нет | - |
| `right` | Выход CLIP vision для вида справа | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Для работы узла необходимо передать хотя бы один вход вида. Узел обрабатывает только те виды, которые содержат корректные данные выхода CLIP vision. Каждый предоставленный вид получает позиционное кодирование в зависимости от его положения (спереди, слева, сзади, справа), после чего закодированные виды объединяются в том же порядке.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивный conditioning, содержащий объединённые мультивидовые эмбеддинги с позиционным кодированием | CONDITIONING |
| `negative` | Негативный conditioning, содержащий нулевые значения с той же формой, что и позитивный conditioning | CONDITIONING |
