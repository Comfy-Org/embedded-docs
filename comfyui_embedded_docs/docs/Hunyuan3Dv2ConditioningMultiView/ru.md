# Hunyuan3Dv2ConditioningMultiView

Узел Hunyuan3Dv2ConditioningMultiView объединяет выходы CLIP vision до четырех ракурсов (спереди, слева, сзади и справа) в единое многоракурсное кондиционирование. Для каждого переданного ракурса к его эмбеддингу CLIP vision добавляется позиционное кодирование, после чего полученные эмбеддинги конкатенируются. Узел выводит позитивное кондиционирование, основанное на объединённых эмбеддингах, и негативное кондиционирование, заполненное нулями той же формы.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `фронт` | Выход CLIP vision для вида спереди. Необязательный вход. | CLIP_VISION_OUTPUT | Нет | - |
| `слева` | Выход CLIP vision для вида слева. Необязательный вход. | CLIP_VISION_OUTPUT | Нет | - |
| `сзади` | Выход CLIP vision для вида сзади. Необязательный вход. | CLIP_VISION_OUTPUT | Нет | - |
| `справа` | Выход CLIP vision для вида справа. Необязательный вход. | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Для работы узла необходимо подать хотя бы один вход вида. Узел обрабатывает только те виды, которые содержат корректные выходные данные CLIP vision, и пропускает неподключённые виды.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование, содержащее объединённые многоракурсные эмбеддинги с позиционным кодированием. | CONDITIONING |
| `negative` | Негативное кондиционирование с нулевыми значениями, по форме совпадающее с позитивным кондиционированием. | CONDITIONING |
