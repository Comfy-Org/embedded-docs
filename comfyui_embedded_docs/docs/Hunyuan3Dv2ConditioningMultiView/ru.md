# Hunyuan3Dv2ConditioningMultiView

Узел Hunyuan3Dv2ConditioningMultiView объединяет выходы CLIP vision с максимум четырёх видов (спереди, слева, сзади и справа) в единый многовидовой conditioning. Для каждого предоставленного вида к его эмбеддингу CLIP vision добавляется позиционное кодирование, а полученные эмбеддинги конкатенируются. Узел выводит положительный conditioning на основе объединённых эмбеддингов и отрицательный conditioning, заполненный нулями той же формы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `фронт` | Выход CLIP vision для вида спереди. Необязательный вход вида. | CLIP_VISION_OUTPUT | Нет | - |
| `слева` | Выход CLIP vision для вида слева. Необязательный вход вида. | CLIP_VISION_OUTPUT | Нет | - |
| `сзади` | Выход CLIP vision для вида сзади. Необязательный вход вида. | CLIP_VISION_OUTPUT | Нет | - |
| `справа` | Выход CLIP vision для вида справа. Необязательный вход вида. | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Для работы узла должен быть предоставлен хотя бы один вход вида. Узел обрабатывает только виды, содержащие допустимые данные выхода CLIP vision, и пропускает неподключённые виды. Каждый вид получает фиксированное позиционное кодирование в зависимости от своего слота (`front`, `left`, `back`, `right`), а обработанные эмбеддинги из всех предоставленных видов объединяются по измерению последовательности.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный conditioning, содержащий объединённые многовидовые эмбеддинги с позиционным кодированием. | CONDITIONING |
| `negative` | Отрицательный conditioning с нулевыми значениями, совпадающий по форме с положительным conditioning. | CONDITIONING |
