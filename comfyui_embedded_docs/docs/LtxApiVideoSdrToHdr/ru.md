# LTX Video SDR to HDR

Преобразует SDR-видео в 10-битное HDR-видео в BT.2020 с передаточной функцией HLG при том же разрешении. Аудио не сохраняется.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | SDR-видео для преобразования, не более 3840x2160 в любой ориентации. До 273 кадров при 1080p, 193 кадров при 1440p и 65 кадров при 4K. | VIDEO | Да | - |
| `seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Нет | от 0 до 4294967295 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Преобразованное 10-битное HDR-видео без аудио. | VIDEO |
