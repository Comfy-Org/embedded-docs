# VideoTrim

Этот узел обрезает видео до выбранного временного окна, устанавливая время начала и продолжительность. Он также предлагает строгий режим, который вызывает ошибку, если запрошенная продолжительность не может быть достигнута.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Видео для обрезки. | VIDEO | Да | — |
| `trim` | Окно обрезки, определяемое начальным/конечным кадрами. Окно преобразуется во время начала (в секундах от начала видео) и продолжительность (в секундах). Когда и время начала, и продолжительность равны 0, видео возвращается без обрезки. | VIDEO_EDIT | Да | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `strict_duration` | Если True, то, когда указанная продолжительность невозможна, будет вызвана ошибка. (по умолчанию: False) | BOOLEAN | Нет | true<br>false |

Примечание: продолжительность обрезки должна быть >= 0; отрицательные значения вызывают ошибку. Запрошенное окно обрезки должно помещаться внутри исходного видео. Если обрезка не может быть применена, возникает ошибка, в которой сообщается исходная продолжительность, время начала и целевая продолжительность.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Обрезанное видео. Если окно обрезки пустое (время начала и продолжительность оба равны 0), исходное видео возвращается без изменений. | VIDEO |
