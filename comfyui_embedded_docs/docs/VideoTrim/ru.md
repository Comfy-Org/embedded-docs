# Обрезка видео (расширенная)

Этот узел обрезает видео до выбранного временного окна, задавая время начала и длительность. Он также предлагает строгий режим, который вызывает ошибку, если запрошенная длительность не может быть достигнута.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Видео для обрезки. | VIDEO | Да | — |
| `trim` | Окно обрезки, задаваемое начальным/конечным кадрами. Окно преобразуется во время начала (в секундах от начала видео) и длительность (в секундах). Когда и время начала, и длительность равны 0, видео возвращается без какой-либо обрезки. | VIDEO_EDIT | Да | start_time: >= 0, по умолчанию 0<br>duration: >= 0, по умолчанию 0 |
| `strict_duration` | Если True, то при невозможности указанной длительности будет вызвана ошибка. (по умолчанию: False) | BOOLEAN | Нет | true<br>false |

Примечание: Длительность обрезки должна быть >= 0; отрицательные значения вызывают ошибку. Запрошенное окно обрезки должно полностью помещаться в исходном видео. Если обрезку невозможно применить, вызывается ошибка, в которой сообщаются длительность исходного видео, время начала и целевая длительность.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Обрезанное видео. Когда окно обрезки пустое (время начала и длительность оба равны 0), исходное видео возвращается без изменений. | VIDEO |
