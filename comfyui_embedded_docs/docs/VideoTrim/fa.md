# VideoTrim

این گره با تنظیم زمان شروع و مدت‌زمان، ویدیو را به یک بازه زمانی انتخابی برش می‌دهد. همچنین حالت سخت‌گیرانه‌ای ارائه می‌دهد که در صورت عدم امکان دستیابی به مدت‌زمان درخواستی، خطا ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | ویدیویی که باید برش داده شود. | VIDEO | بله | — |
| `trim` | بازه برش با استفاده از فریم‌های شروع/پایان. این بازه به یک زمان شروع (به ثانیه از ابتدای ویدیو) و یک مدت‌زمان (به ثانیه) تبدیل می‌شود. وقتی هر دو زمان شروع و مدت‌زمان صفر باشند، ویدیو بدون هیچ برشی بازگردانده می‌شود. | VIDEO_EDIT | بله | start_time: >= 0، پیش‌فرض 0<br>duration: >= 0، پیش‌فرض 0 |
| `strict_duration` | اگر True باشد، وقتی مدت‌زمان مشخص‌شده امکان‌پذیر نباشد، خطا ایجاد می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | true<br>false |

نکته: مدت‌زمان برش باید >= 0 باشد؛ مقادیر منفی خطا ایجاد می‌کنند. بازه برش درخواستی باید درون ویدیوی منبع جای بگیرد. اگر برش قابل اعمال نباشد، خطایی ایجاد می‌شود که مدت‌زمان منبع، زمان شروع و مدت‌زمان هدف را گزارش می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی برش‌خورده. وقتی بازه برش خالی است (زمان شروع و مدت‌زمان هر دو 0)، ویدیوی اصلی بدون تغییر بازگردانده می‌شود. | VIDEO |
