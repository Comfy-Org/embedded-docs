# کوتاه‌سازی ویدیو (پیشرفته)

این گره یک ویدئو را با تعیین زمان شروع و مدت، به بازه زمانی انتخاب‌شده برش می‌دهد. همچنین حالت سخت‌گیرانه‌ای ارائه می‌کند که وقتی مدت درخواستی قابل تحقق نباشد، خطا ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | ویدئویی که باید برش داده شود. | VIDEO | بله | — |
| `trim` | بازه برش را با فریم‌های شروع/پایان تعیین کنید. این بازه به یک زمان شروع (بر حسب ثانیه از ابتدای ویدئو) و یک مدت (بر حسب ثانیه) تبدیل می‌شود. وقتی هم زمان شروع و هم مدت 0 باشند، ویدئو بدون هیچ برشی بازگردانده می‌شود. | VIDEO_EDIT | بله | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `strict_duration` | اگر True باشد، وقتی مدت مشخص‌شده امکان‌پذیر نباشد، خطا ایجاد می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | true<br>false |

نکته: مدت برش باید >= 0 باشد؛ مقادیر منفی خطا ایجاد می‌کنند. بازه برش درخواستی باید داخل ویدئوی منبع جای بگیرد. اگر برش قابل اعمال نباشد، خطایی ایجاد می‌شود که مدت منبع، زمان شروع و مدت هدف را گزارش می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدئوی برش‌خورده. وقتی بازه برش خالی باشد (زمان شروع و مدت هر دو 0)، ویدئوی اصلی بدون تغییر بازگردانده می‌شود. | VIDEO |
