# קיצוץ וידאו (מתקדם)

הצומת הזה חותך וידאו לחלון זמן נבחר על ידי הגדרת זמן התחלה ומשך. הוא גם מציע מצב קפדני שמעלה שגיאה כאשר לא ניתן להשיג את משך הזמן המבוקש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | הווידאו לחיתוך. | VIDEO | כן | — |
| `trim` | חלון חיתוך באמצעות פריימים של התחלה/סיום. החלון מומר לזמן התחלה (בשניות מתחילת הווידאו) ולמשך (בשניות). כאשר גם זמן ההתחלה וגם משך הזמן הם 0, הווידאו מוחזר ללא כל חיתוך. | VIDEO_EDIT | כן | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `strict_duration` | אם True, כאשר משך הזמן שצוין אינו אפשרי, תועלה שגיאה. (ברירת מחדל: False) | BOOLEAN | לא | true<br>false |

הערה: משך החיתוך חייב להיות >= 0; ערכים שליליים מעלים שגיאה. חלון החיתוך המבוקש חייב להתאים בתוך וידאו המקור. אם לא ניתן להחיל את החיתוך, תועלה שגיאה שמדווחת את משך המקור, זמן ההתחלה ומשך היעד.
