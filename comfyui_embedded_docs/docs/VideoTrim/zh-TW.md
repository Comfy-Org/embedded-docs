# 修剪影片（進階）

此節點透過設定開始時間與持續時間，將影片剪裁至選定的時間範圍。它亦提供嚴格模式，當無法達成要求的持續時間時會引發錯誤。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 要修剪的影片。 | VIDEO | 是 | — |
| `修剪` | 使用開始/結束影格來指定修剪視窗。此視窗會轉換為開始時間（從影片開頭起算的秒數）與持續時間（以秒為單位）。當開始時間與持續時間皆為 0 時，會回傳未經任何修剪的影片。 | VIDEO_EDIT | 是 | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `嚴格持續時間` | 若為 True，當指定的持續時間無法達成時，將引發錯誤。（預設：False） | BOOLEAN | 否 | true<br>false |

注意：修剪持續時間必須 >= 0；負值會引發錯誤。要求的修剪視窗必須位於來源影片範圍內。若無法套用修剪，會引發錯誤，並回報來源持續時間、開始時間與目標持續時間。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `video` | 修剪後的影片。當修剪視窗為空（開始時間與持續時間皆為 0）時，會回傳未變更的原始影片。 | VIDEO |
