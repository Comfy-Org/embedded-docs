# VideoTrim

此節點透過設定開始時間與持續時間，將影片裁剪至指定的時間範圍。它也提供嚴格模式，在無法達成所要求的持續時間時會觸發錯誤。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 要裁剪的影片。 | VIDEO | 是 | — |
| `修剪` | 使用開始/結束影格定義裁剪範圍。此範圍會被轉換為開始時間（從影片開頭起算的秒數）與持續時間（秒數）。當開始時間與持續時間皆為 0 時，影片原樣回傳而不做任何裁剪。 | VIDEO_EDIT | 是 | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `嚴格持續時間` | 若為 True，當指定的持續時間無法達成時將觸發錯誤。（預設值：False） | BOOLEAN | 否 | true<br>false |

注意：裁剪持續時間必須 >= 0；負數會觸發錯誤。要求的裁剪範圍必須完全落在來源影片內。若無法套用裁剪，則會觸發錯誤，並回報來源持續時間、開始時間與目標持續時間。

## 輸出

| 輸出名 | 說明 | 資料型別 |
|-------------|-------------|-----------|
| `video` | 裁剪後的影片。當裁剪範圍為空（開始時間與持續時間皆為 0）時，原始影片會原樣回傳且不做任何變更。 | VIDEO |
