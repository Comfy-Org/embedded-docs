# اقتطاع الفيديو (متقدم)

تقوم هذه العقدة بقص الفيديو إلى نافذة زمنية مختارة عبر تعيين وقت بدء ومدة. كما توفر وضعًا صارمًا يرفع خطأً عندما يتعذر تحقيق المدة المطلوبة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `video` | الفيديو المراد قصه. | VIDEO | نعم | — |
| `trim` | نافذة القص باستخدام إطارات البداية/النهاية. تُحوَّل النافذة إلى وقت بدء (بالثواني من بداية الفيديو) ومدة (بالثواني). عندما يكون وقت البدء والمدة كلاهما 0، يُعاد الفيديو دون أي قص. | VIDEO_EDIT | نعم | start_time: >= 0, default 0<br>duration: >= 0, default 0 |
| `strict_duration` | إذا كانت True، فعندما لا تكون المدة المحددة ممكنة، سيتم رفع خطأ. (الافتراضي: False) | BOOLEAN | لا | true<br>false |

ملاحظة: يجب أن تكون مدة القص >= 0؛ القيم السالبة تؤدي إلى رفع خطأ. يجب أن تقع نافذة القص المطلوبة ضمن الفيديو المصدر. إذا تعذّر تطبيق القص، يُرفع خطأ يوضح مدة المصدر، ووقت البدء، والمدة المستهدفة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `video` | الفيديو المقصوص. عندما تكون نافذة القص فارغة (وقت البدء والمدة كلاهما 0)، يُعاد الفيديو الأصلي دون تغيير. | VIDEO |
