# TextEncodeMageFlowEdit

---

## Обзор

Этот узел кодирует инструкцию по редактированию (промпт) вместе с одним или несколькими эталонными изображениями для модели Mage-Flow-Edit. Он изменяет размер всех эталонных изображений до целевого разрешения на выходе, кодирует их в скрытое пространство (латентное пространство), если предоставлен VAE, и присоединяет эталонные латентные представления к выходу conditioning. Также генерируется пустой латентный тензор с правильными размерами для сэмплирования, гарантируя, что его размер всегда соответствует выходной ширине и высоте.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстовых промптов. | CLIP | Да | |
| `prompt` | Инструкция по редактированию (позитивный промпт), которую нужно применить. | STRING | Да | многострочный, динамические промпты включены |
| `negative_prompt` | Негативный промпт, от которого следует отталкиваться. По умолчанию: пустая строка (при пустом значении внутри используется пробел). | STRING | Нет | многострочный, динамические промпты включены |
| `vae` | Модель VAE для кодирования эталонных изображений в скрытое пространство. Если не указана, эталонные латентные представления не добавляются к conditioning. | VAE | Нет | |
| `images` | Одно или несколько эталонных изображений для редактирования. Все изображения изменяются до выходного разрешения перед кодированием. | IMAGE (autogrow) | Нет | До 16 изображений (с именами `image_1`…`image_16`), минимум 0 |
| `width` | Выходная ширина в пикселях. Если установлено 0, используется ширина первого эталонного изображения. Всегда округляется вниз до ближайшего числа, кратного 16. По умолчанию: 0. | INT | Да | 0–8192 (шаг 16) |
| `height` | Выходная высота в пикселях. Поведение резервного значения такое же, как для ширины. По умолчанию: 0. | INT | Да | 0–8192 (шаг 16) |
| `batch_size` | Количество генерируемых латентных сэмплов. По умолчанию: 1. | INT | Да | 1–4096 |

**Примечания о зависимостях параметров:**
- Если `width` и/или `height` равны 0 и не предоставлено эталонных изображений, они принимают значение 1024 каждое.
- Параметр `vae` необязателен; эталонные латентные представления создаются и присоединяются к conditioning только при подключении VAE.
- Поле `negative_prompt` необязательно – если оставить его пустым, внутри в качестве негативного текста используется одиночный пробел.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `positive` | Выход conditioning, содержащий токены позитивного промпта и (если был предоставлен VAE) закодированные эталонные латентные представления. | CONDITIONING |
| `negative` | Выход conditioning, содержащий токены негативного промпта и те же эталонные латентные представления (если VAE предоставлен). | CONDITIONING |
| `latent` | Пустой латентный тензор формы `[batch_size, 128, height÷16, width÷16]` для использования в качестве начального шума во время сэмплирования. | LATENT |
