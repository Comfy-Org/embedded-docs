# TextEncodeMageFlowEdit

## סקירה כללית

צומת זה מקודד הוראת עריכה (פרומפט) יחד עם תמונת עזר אחת או יותר עבור מודל Mage-Flow-Edit. הוא משנה את גודלן של כל תמונות העזר לרזולוציית הפלט היעד, מקודד אותן למרחב לטנטי אם מסופק VAE, ומצרף את לטנטי העזר לפלט ההתניה. כמו כן נוצר טנזור לטנטי ריק עם הממדים הנכונים לדגימה, מה שמבטיח שהגודל תמיד תואם לרוחב ולגובה הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל CLIP המשמש לטוקניזציה ולקידוד של פרומפטי הטקסט. | CLIP | כן | |
| `prompt` | הוראת העריכה (פרומפט חיובי) שיש להחיל. | STRING | כן | multiline, dynamic prompts enabled |
| `negative_prompt` | הפרומפט השלילי שממנו יש להתרחק. ברירת מחדל: מחרוזת ריקה (כאשר השדה ריק, נעשה שימוש פנימי ברווח יחיד). מוצג בחלק המתקדם של ממשק המשתמש. | STRING | לא | multiline, dynamic prompts enabled |
| `vae` | מודל VAE לקידוד תמונות עזר למרחב לטנטי. אם לא מסופק, לא מתווספים לטנטי עזר להתניה. | VAE | לא | |
| `images` | תמונת עזר אחת או יותר לעריכה. כל תמונות העזר משנות את גודלן לרזולוציית הפלט לפני הקידוד. | IMAGE (autogrow) | לא | עד 16 תמונות (בשמות `image_1`…`image_16`), לפחות 0 |
| `width` | רוחב הפלט בפיקסלים. אם מוגדר ל-0, נעשה שימוש ברוחב של תמונת העזר הראשונה. תמיד מעוגל כלפי מטה לכפולה של 16. ברירת מחדל: 0. | INT | כן | 0 עד 8192 (צעד 16) |
| `height` | גובה הפלט בפיקסלים. התנהגות הגיבוי זהה לזו של הרוחב. ברירת מחדל: 0. | INT | כן | 0 עד 8192 (צעד 16) |
| `batch_size` | מספר דגימות לטנט ליצירה. ברירת מחדל: 1. | INT | כן | 1 עד 4096 |

**הערות על תלויות פרמטרים:**
- אם `width` ו/או `height` הם 0 ולא מסופקות תמונות עזר, הם משתמשים בברירת מחדל של 1024 כל אחד.
- אם רק אחד מבין `width` או `height` הוא 0, הממד החסר נלקח מתמונת העזר הראשונה בעוד שהממד שהוגדר במפורש נשמר.
- הפרמטר `vae` הוא אופציונלי; לטנטי עזר נוצרים ומצורפים להתניה רק כאשר VAE מחובר.
- השדה `negative_prompt` הוא אופציונלי – אם נותר ריק, נעשה שימוש פנימי ברווח יחיד כטקסט השלילי.
- עבור התניית הטקסט, כל תמונת עזר משנה את גודלה כך שהקצה הארוך שלה הוא לכל היותר 384 פיקסלים, בהתאמה לעיבוד המקדים של האימון. לעומת זאת, ענף קידוד ה-VAE משנה את גודלן של כל תמונות העזר לרזולוציית הפלט המלאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | פלט התניה המכיל את טוקני הפרומפט החיובי, ובנוסף (אם סופק VAE) את לטנטי העזר המקודדים. | CONDITIONING |
| `negative` | פלט התניה המכיל את טוקני הפרומפט השלילי, ובנוסף את אותם לטנטי עזר (אם סופק VAE). | CONDITIONING |
| `latent` | טנזור לטנטי ריק עם צורה `[batch_size, 128, height÷16, width÷16]` לשימוש כרעש ההתחלתי בזמן הדגימה. | LATENT |
