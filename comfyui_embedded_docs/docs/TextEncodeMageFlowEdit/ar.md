# TextEncodeMageFlowEdit

تقوم هذه العقدة بترميز تعليمات تحرير (موجه) مع صورة مرجعية واحدة أو أكثر لنموذج Mage-Flow-Edit. تقوم بتغيير حجم جميع الصور المرجعية إلى دقة الإخراج المستهدفة، وترميزها في الفضاء الكامن إذا تم توفير VAE، ثم تُرفق البيانات الكامنة المرجعية بمخرجات التكييف. كما يتم إنشاء موتر كامن فارغ بالأبعاد الصحيحة لأخذ العينات، مما يضمن مطابقة الحجم دائمًا لعرض الإخراج وارتفاعه.

# المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|---------|-------|---------------|--------|--------|
| `clip` | نموذج CLIP المستخدم لتحليل النصوص الموجهة وترميزها | CLIP | نعم | |
| `prompt` | تعليمات التحرير (الموجب) المراد تطبيقها | STRING | نعم | متعدد الأسطر، موجهات ديناميكية مفعلة |
| `negative_prompt` | الموجه السلبي لتفادي الابتعاد عنه. الافتراضي: سلسلة فارغة (تُستخدم مسافة داخليًا عند تركها فارغة) | STRING | لا | متعدد الأسطر، موجهات ديناميكية مفعلة |
| `vae` | نموذج VAE لترميز الصور المرجعية في الفضاء الكامن. إذا لم يتم توفيره، لا تُضاف أي بيانات كامنة مرجعية إلى التكييف | VAE | لا | |
| `images` | صورة مرجعية واحدة أو أكثر لتحريرها. تُغيَّر جميع الصور حجمها إلى دقة الإخراج قبل الترميز | IMAGE (نمو تلقائي) | لا | حتى 16 صورة (تُسمى `image_1`…`image_16`)، على الأقل 0 |
| `width` | عرض الإخراج بالبكسل. إذا ضُبط على 0، يُستخدم عرض أول صورة مرجعية. يُقرَّب دائمًا إلى أسفل إلى مضاعف 16. الافتراضي: 0 | INT | نعم | 0 إلى 8192 (خطوة 16) |
| `height` | ارتفاع الإخراج بالبكسل. نفس سلوك الاحتياطي للعرض. الافتراضي: 0 | INT | نعم | 0 إلى 8192 (خطوة 16) |
| `batch_size` | عدد العينات الكامنة المراد توليدها. الافتراضي: 1 | INT | نعم | 1 إلى 4096 |

**ملاحظات حول تبعيات المعاملات:**
- إذا كان `width` و/أو `height` بقيمة 0 ولم يتم توفير صور مرجعية، فإنهما يتراجعان إلى 1024 لكل منهما.
- معامل `vae` اختياري؛ تُنشأ البيانات الكامنة المرجعية وتُرفق بالتكييف فقط عند توصيل VAE.
- حقل `negative_prompt` اختياري – إذا تُرك فارغًا، تُستخدم مسافة واحدة داخليًا كنص سلبي.

# المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|------------|-------|---------------|
| `positive` | مخرج التكييف الذي يحتوي على رموز الموجه الموجب، بالإضافة إلى (إذا تم توفير VAE) البيانات الكامنة المرجعية المرمزة | CONDITIONING |
| `negative` | مخرج التكييف الذي يحتوي على رموز الموجه السلبي، بالإضافة إلى نفس البيانات الكامنة المرجعية (إذا تم توفير VAE) | CONDITIONING |
| `latent` | موتر كامن فارغ بالشكل `[batch_size, 128, height÷16, width÷16]` لاستخدامه كضوضاء أولية أثناء أخذ العينات | LATENT |
