# TextEncodeMageFlowEdit

## نمای کلی

این گره یک دستور ویرایش (پرامپت) را به همراه یک یا چند تصویر مرجع برای مدل Mage-Flow-Edit کدگذاری می‌کند. تمام تصاویر مرجع را به وضوح خروجی هدف تغییر اندازه می‌دهد، در صورت وجود VAE آن‌ها را به فضای نهفته کدگذاری می‌کند و نهفته‌های مرجع را به خروجی conditioning متصل می‌کند. یک تنسور نهفته خالی با ابعاد صحیح برای نمونه‌برداری نیز تولید می‌شود که اندازه آن همواره با عرض و ارتفاع خروجی مطابقت دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و کدگذاری پرامپت‌های متنی. | CLIP | بله | |
| `پرامپت` | دستور ویرایش (پرامپت مثبت) که اعمال می‌شود. | STRING | بله | چندخطی، پرامپت‌های پویا فعال است |
| `پرامپت منفی` | پرامپت منفی برای دوری از آن. پیش‌فرض: رشته خالی (در صورت خالی بودن، درون‌سیستمی از یک فاصله استفاده می‌کند). در بخش پیشرفته رابط کاربری نمایش داده می‌شود. | STRING | خیر | چندخطی، پرامپت‌های پویا فعال |
| `vae` | مدل VAE برای کدگذاری تصاویر مرجع به فضای نهفته. در صورت عدم ارائه، هیچ نهفته‌ای به conditioning اضافه نمی‌شود. | VAE | خیر | |
| `تصاویر` | تصویر(های) مرجع برای ویرایش. همه مراجع قبل از کدگذاری به وضوح خروجی تغییر اندازه می‌شوند. | IMAGE (خود-افزاینده) | خیر | حداکثر ۱۶ تصویر (نام‌گذاری‌شده به‌صورت `image_1`…`image_16`)، حداقل ۰ |
| `عرض` | عرض خروجی بر حسب پیکسل. اگر روی ۰ تنظیم شود، عرض اولین تصویر مرجع استفاده می‌شود. همواره به مضرب ۱۶ گرد می‌شود. پیش‌فرض: ۰. | INT | بله | ۰ تا ۸۱۹۲ (گام ۱۶) |
| `ارتفاع` | ارتفاع خروجی بر حسب پیکسل. رفتار بازگشتی مشابه عرض. پیش‌فرض: ۰. | INT | بله | ۰ تا ۸۱۹۲ (گام ۱۶) |
| `اندازه بچ` | تعداد نمونه‌های نهفته برای تولید. پیش‌فرض: ۱. | INT | بله | ۱ تا ۴۰۹۶ |

**نکاتی درباره وابستگی پارامترها:**
- اگر `width` و/یا `height` برابر ۰ باشند و هیچ تصویر مرجعی ارائه نشود، هر یک به طور پیش‌فرض به ۱۰۲۴ برمی‌گردند.
- اگر فقط یکی از `width` یا `height` برابر ۰ باشد، بُعد گم‌شده از اولین تصویر مرجع گرفته می‌شود و بُعدی که صریحاً تنظیم شده حفظ می‌شود.
- پارامتر `vae` اختیاری است؛ نهفته‌های مرجع تنها زمانی تولید و به conditioning متصل می‌شوند که یک VAE متصل شده باشد.
- فیلد `negative_prompt` اختیاری است – در صورت خالی ماندن، یک فاصله به‌عنوان متن منفی به صورت داخلی استفاده می‌شود.
- برای شرطی‌سازی متنی، هر تصویر مرجع طوری تغییر اندازه می‌یابد که طولانی‌ترین لبه آن حداکثر ۳۸۴ پیکسل باشد، مطابق با پیش‌پردازش آموزش. شاخه رمزگذاری VAE در عوض همه مراجع را به وضوح خروجی کامل تغییر اندازه می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `positive` | خروجی conditioning حاوی توکن‌های پرامپت مثبت، به همراه (در صورت ارائه VAE) نهفته‌های مرجع کدگذاری‌شده. | CONDITIONING |
| `negative` | خروجی conditioning حاوی توکن‌های پرامپت منفی، به همراه همان نهفته‌های مرجع (در صورت ارائه VAE). | CONDITIONING |
| `latent` | یک تنسور نهفته خالی با شکل `[batch_size, 128, height÷16, width÷16]` برای استفاده به‌عنوان نویز اولیه در هنگام نمونه‌برداری. | LATENT |
