# WeldVertices

3D 메시에서 일치하는 정점을 병합하므로, 이전에 별도의 코너 점을 가지고 있던 면들이 결국 동일한 정점을 공유하게 됩니다. 메시 경계 상자를 기준으로 한 허용 오차를 사용하는 그리드 양자화를 통해 가까운 정점들을 그룹화하고, 병합된 각 그룹의 정점 색상을 평균화합니다. 이는 메시가 용접되지 않은 상태, 즉 각 면이 고유한 정점을 가지고 있고 공유 가장자리가 없는 상태로 도착했을 때 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 병합될 일치하는 정점을 포함하는 입력 3D 메시입니다. | MESH | 예 | - |
| `epsilon_rel` | 용접 허용 오차(경계 상자 대각선의 비율)입니다. 부동소수점 중복 제거에는 1e-5, 육안으로는 가깝지만 구별되는 정점에는 1e-3을 사용합니다. 기본값: 1e-5. | FLOAT | 예 | 0.0 to unlimited |
| `epsilon_abs` | 절대 용접 허용 오차입니다(0보다 크면 `epsilon_rel`을 재정의합니다). 기본값: 0.0. | FLOAT | 예 | 0.0 to unlimited |

참고: `epsilon_abs`가 0보다 크면 `epsilon_rel`보다 우선하며 상대 허용 오차는 무시됩니다. `epsilon_abs`가 0이면 상대 허용 오차 `epsilon_rel`이 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `mesh` | 병합된 정점, 업데이트된 면 인덱스, 평균화된 정점 색상(입력 메시에 색상이 있는 경우)을 가진 용접된 메시입니다. | MESH |
