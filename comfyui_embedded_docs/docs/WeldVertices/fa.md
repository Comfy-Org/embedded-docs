# جوش‌دادن رأس‌ها

Weld Vertices رأس‌های منطبق در یک مش سه‌بعدی را ادغام می‌کند تا وجه‌هایی که قبلاً نقاط گوشه‌ای جداگانه داشتند، اکنون همان رأس‌ها را به اشتراک بگذارند. این گره رأس‌های نزدیک را با کوانتیزه‌سازی شبکه‌ای و با تلورانسی مبتنی بر جعبه محدودکننده مش گروه‌بندی می‌کند و رنگ رأس‌ها را برای هر گروه ادغام‌شده میانگین می‌گیرد. این کار زمانی مفید است که یک مش به‌صورت جوش‌نخورده وارد شود؛ یعنی هر وجه رأس‌های خودش را داشته باشد و هیچ یال مشترکی وجود نداشته باشد، و می‌تواند به‌عنوان مرحله پیش‌پردازش پیش از عملیات‌های آگاه از توپولوژی مانند FillHoles یا DecimateMesh استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی ورودی که رأس‌های منطبق آن ادغام خواهند شد. | MESH | بله | - |
| `epsilon_rel` | تلورانس جوش (کسری از قطر جعبه محدودکننده). 1e-5 برای حذف تکراری‌های float؛ 1e-3 برای رأس‌های به‌ظاهر نزدیک ولی متمایز. پیش‌فرض: 1e-5. | FLOAT | بله | 0.0 تا نامحدود (گام 1e-6) |
| `epsilon_abs` | تلورانس جوش مطلق (در صورت > 0 بودن، `epsilon_rel` را نادیده می‌گیرد). پیش‌فرض: 0.0. | FLOAT | بله | 0.0 تا نامحدود (گام 1e-6) |

توجه: هنگامی که `epsilon_abs` بزرگ‌تر از 0 باشد، بر `epsilon_rel` اولویت دارد و تلورانس نسبی نادیده گرفته می‌شود. وقتی `epsilon_abs` برابر 0 باشد، تلورانس نسبی `epsilon_rel` استفاده می‌شود و با ضرب آن در قطر جعبه محدودکننده مش به فاصله مطلق تبدیل می‌گردد.

## خروجی‌ها

|-------------|-------------|-----------|
