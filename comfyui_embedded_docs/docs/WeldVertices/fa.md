# WeldVertices

Weld Vertices رئوس هم‌مکان را در یک مش سه‌بعدی ادغام می‌کند، به‌طوری‌که وجه‌هایی که قبلاً نقاط گوشه‌ای جداگانه داشتند، در نهایت رئوس مشترکی را به اشتراک می‌گذارند. این کار با استفاده از کمی‌سازی شبکه‌ای با تلورانس مبتنی بر کادر محدود مش، رئوس نزدیک به هم را گروه‌بندی کرده و برای هر گروه ادغام‌شده رنگ رئوس را میانگین می‌گیرد. این زمانی مفید است که مش به‌صورت جوش‌نخورده وارد می‌شود؛ یعنی هر وجه رئوس مخصوص به خود را دارد و هیچ لبه مشترکی وجود ندارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی ورودی که رئوس هم‌مکان آن ادغام خواهند شد. | MESH | بله | - |
| `epsilon_rel` | تلورانس جوش‌کاری (کسری از قطر کادر محدود). 1e-5 برای حذف تکرار با دقت ممیز شناور؛ 1e-3 برای رئوسِ به‌وضوح نزدیک ولی متمایز. پیش‌فرض: 1e-5. | FLOAT | بله | 0.0 to unlimited |
| `epsilon_abs` | تلورانس مطلق جوش‌کاری (در صورت بزرگ‌تر بودن از 0 بر epsilon_rel مقدم است). پیش‌فرض: 0.0. | FLOAT | بله | 0.0 to unlimited |

توجه: وقتی `epsilon_abs` بزرگ‌تر از 0 است، بر `epsilon_rel` مقدم بوده و تلورانس نسبی نادیده گرفته می‌شود. وقتی `epsilon_abs` برابر 0 باشد، تلورانس نسبی `epsilon_rel` استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
