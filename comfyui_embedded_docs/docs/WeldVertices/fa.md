# WeldVertices

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `mesh` | مش سه‌بعدی ورودی که رئوس منطبق آن ادغام خواهند شد. | MESH | بله | - |
| `epsilon_rel` | تلورانس جوش (کسری از قطر جعبه‌ی محدوده). `1e-5` برای حذف تکرار ممیز شناور؛ `1e-3` برای رئوس نزدیک‌قابل‌مشاهده اما متمایز. پیش‌فرض: `1e-5`. | FLOAT | بله | 0.0 تا نامحدود |
| `epsilon_abs` | تلورانس جوش مطلق (زمانی که بزرگ‌تر از 0 باشد، `epsilon_rel` را لغو می‌کند). پیش‌فرض: 0.0. | FLOAT | بله | 0.0 تا نامحدود |

توجه: وقتی `epsilon_abs` بزرگ‌تر از 0 باشد، بر `epsilon_rel` اولویت دارد و تلورانس نسبی نادیده گرفته می‌شود. وقتی `epsilon_abs` برابر 0 باشد، تلورانس نسبی `epsilon_rel` استفاده می‌شود.
