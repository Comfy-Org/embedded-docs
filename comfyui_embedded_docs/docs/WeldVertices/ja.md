# WeldVertices

Weld Vertices は、3D メッシュ内の一致する頂点を結合するノードです。これにより、以前は別々のコーナーポイントを持っていた面が、同じ頂点を共有するようになります。メッシュのバウンディングボックスに基づく許容差を用いたグリッド量子化によって近傍の頂点をグループ化し、結合された各グループの頂点カラーを平均化します。これは、メッシュが未溶着の状態（つまり、各面が独自の頂点を持ち、共有エッジがない状態）で読み込まれた場合に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 一致する頂点が結合される入力 3D メッシュ。 | MESH | Yes | - |
| `epsilon_rel` | ウェルド許容差（バウンディングボックスの対角線に対する割合）。float の重複除去には 1e-5、目視で近いが異なる頂点には 1e-3。デフォルト: 1e-5。 | FLOAT | Yes | 0.0 to unlimited |
| `epsilon_abs` | 絶対ウェルド許容差（0 より大きい場合、`epsilon_rel` を上書きします）。デフォルト: 0.0。 | FLOAT | Yes | 0.0 to unlimited |

注: `epsilon_abs` が 0 より大きい場合は、これが `epsilon_rel` より優先され、相対許容差は無視されます。`epsilon_abs` が 0 の場合は、相対許容差 `epsilon_rel` が使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 頂点が結合され、面インデックスが更新され、頂点カラーが平均化された（入力メッシュにカラーがある場合）ウェルド済みメッシュ。 | MESH |
