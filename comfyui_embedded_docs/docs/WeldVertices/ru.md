# Объединить вершины

Weld Vertices объединяет совпадающие вершины в 3D-меше, так что грани, которые ранее имели отдельные угловые точки, начинают использовать общие вершины. Он группирует близкие вершины с помощью квантования по сетке с допуском, основанным на ограничивающем боксе меша, и усредняет цвета вершин для каждой объединённой группы. Это полезно, когда меш приходит несваренным, то есть каждая грань имеет собственные вершины и нет общих рёбер, и может служить предварительным проходом перед операциями, учитывающими топологию, такими как FillHoles или DecimateMesh.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Входной 3D-меш, совпадающие вершины которого будут объединены. | MESH | Да | - |
| `epsilon_rel` | Допуск сварки (доля диагонали ограничивающего бокса). 1e-5 для дедупликации чисел с плавающей запятой; 1e-3 для визуально близких, но различных вершин. По умолчанию: 1e-5. | FLOAT | Да | 0.0 до unlimited (шаг 1e-6) |
| `epsilon_abs` | Абсолютный допуск сварки (переопределяет `epsilon_rel`, когда > 0). По умолчанию: 0.0. | FLOAT | Да | 0.0 до unlimited (шаг 1e-6) |

Примечание: Когда `epsilon_abs` больше 0, он имеет приоритет над `epsilon_rel`, и относительный допуск игнорируется. Когда `epsilon_abs` равен 0, используется относительный допуск `epsilon_rel`, преобразуемый в абсолютное расстояние умножением на диагональ ограничивающего бокса меша.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Меш после сварки с объединёнными вершинами, обновлёнными индексами граней и усреднёнными цветами вершин (если у входного меша были цвета). | MESH |
