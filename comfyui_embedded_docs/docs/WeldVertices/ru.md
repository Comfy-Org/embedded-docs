# WeldVertices

Weld Vertices объединяет совпадающие вершины в 3D-сетке, поэтому грани, которые ранее имели отдельные угловые точки, в итоге используют одни и те же вершины. Он группирует близко расположенные вершины с помощью квантования по сетке с допуском, основанным на ограничивающей рамке сетки, и усредняет цвета вершин для каждой объединенной группы. Это полезно, когда сетка поступает несваренной, то есть каждая грань имеет свои собственные вершины и не имеет общих ребер.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная 3D-сетка, чьи совпадающие вершины будут объединены. | MESH | Да | - |
| `epsilon_rel` | Допуск сварки (доля диагонали ограничивающей рамки). 1e-5 для дедупликации float; 1e-3 для визуально близких, но различных вершин. По умолчанию: 1e-5. | FLOAT | Да | 0.0 to unlimited |
| `epsilon_abs` | Абсолютный допуск сварки (переопределяет epsilon_rel, если > 0). По умолчанию: 0.0. | FLOAT | Да | 0.0 to unlimited |

Примечание: когда `epsilon_abs` больше 0, он имеет приоритет над `epsilon_rel`, и относительный допуск игнорируется. Когда `epsilon_abs` равен 0, используется относительный допуск `epsilon_rel`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Сваренная сетка с объединенными вершинами, обновленными индексами граней и усредненными цветами вершин (если входная сетка имела цвета). | MESH |
