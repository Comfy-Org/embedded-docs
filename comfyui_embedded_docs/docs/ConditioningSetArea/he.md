# התניה (הגדרת אזור)

צומת זה נועד לשנות את מידע הקונדישנינג על ידי הגדרת אזורים מסוימים בתוך הקשר הקונדישנינג. הוא מאפשר מניפולציה מרחבית מדויקת של רכיבי קונדישנינג, ומאפשר התאמות ושיפורים ממוקדים בהתבסס על מידות ועוצמה שצוינו.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | נתוני הקונדישנינג שיש לשנות. משמש כבסיס להחלת התאמות מרחביות. | CONDITIONING |
| `width` | מגדיר את הרוחב של האזור שיש להגדיר בתוך הקשר הקונדישנינג, ומשפיע על ההיקף האופקי של ההתאמה. | `INT` |
| `height` | קובע את הגובה של האזור שיש להגדיר, ומשפיע על הטווח האנכי של שינוי הקונדישנינג. | `INT` |
| `x` | נקודת ההתחלה האופקית של האזור שיש להגדיר, וממקמת את ההתאמה בתוך הקשר הקונדישנינג. | `INT` |
| `y` | נקודת ההתחלה האנכית של התאמת האזור, וקובעת את מיקומה בתוך הקשר הקונדישנינג. | `INT` |
| `strength` | מגדיר את עוצמת שינוי הקונדישנינג באזור שצוין, ומאפשר שליטה מדויקת יותר בהשפעת ההתאמה. | `FLOAT` |
