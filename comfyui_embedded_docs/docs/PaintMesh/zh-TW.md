# PaintMesh

PaintMesh 會佔用一個 3D 網格與一個體素顏色欄位。它將每個頂點指派為欄位中最近體素的顏色，並將結果以頂點顏色的形式寫入輸出網格。若體素欄位為空，則網格會以預設的零（黑色）頂點顏色進行繪製。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要進行繪製的網格。 | MESH | 是 | N/A |
| `voxel_colors` | 包含用於繪製之顏色資料的體素欄位。僅使用欄位中的基底顏色 RGB 通道。 | VOXEL | 是 | N/A |

注意：當體素欄位座標包含批次索引通道，且輸入網格包含多個網格項目時，節點會分別將顏色套用至批次中的每個網格項目。取樣顏色會從 sRGB 轉換為線性 RGB，以供輸出網格使用。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 已套用頂點顏色的繪製網格。 | MESH |
