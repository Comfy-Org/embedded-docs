# 繪製網格

PaintMesh 接收一個 3D 網格與一個體素色彩場。它會為每個頂點指派該場中最近體素的顏色，並回傳套用了這些頂點顏色的網格。若體素場為空，則以預設的零值（黑色）頂點顏色為網格上色。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要上色的網格。 | MESH | 是 | N/A |
| `voxel_colors` | 包含用於上色之色彩資料的體素場。此場僅會使用基礎顏色（base color）的 RGB 通道。 | VOXEL | 是 | N/A |

注意：當體素場的座標包含批次索引（batch index）通道，且輸入網格包含多個網格項目時，此節點會分別為批次中的每個網格項目套用顏色。若某個網格項目沒有對應的體素，則會套用預設的零值（黑色）頂點顏色。取樣得到的顏色會從 sRGB 轉換為線性 RGB 後輸出至網格，因為體素場可能帶有完整的 PBR 資料，但頂點顏色只會使用基礎顏色（base color）的 RGB。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 已套用頂點顏色的上色網格。 | MESH |
