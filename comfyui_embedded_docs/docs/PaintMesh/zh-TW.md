# PaintMesh

PaintMesh 作用於一個 3D 網格和一個體素顏色場。它將網格中的每個頂點指派為顏色場中最近體素的顏色，並將結果以頂點顏色的形式寫入輸出網格。如果體素場為空，則網格會以預設的零值（黑色）頂點顏色進行繪製。

## 輸入

| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要繪製的網格。 | MESH | 是 | N/A |
| `voxel_colors` | 包含用於繪製的色彩資料的體素場。僅使用體素場中的基礎顏色 RGB 通道。 | VOXEL | 是 | N/A |

注意：當體素場座標包含批次索引通道，且輸入網格包含多個網格項目時，節點會將顏色分別套用至批次中的每個網格項目。取樣的顏色會從 sRGB 轉換為線性 RGB，以用於輸出網格。

## 輸出

| 輸出名 | 說明 | 資料型別 |
|-------------|-------------|-----------|
| `網格` | 已套用頂點顏色的繪製網格。 | MESH |
