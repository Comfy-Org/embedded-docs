# PaintMesh

PaintMesh использует 3D-сетку и воксельное цветовое поле. Он присваивает каждой вершине цвет ближайшего вокселя в поле, записывая результат как цвета вершин на выходной сетке. Если воксельное поле пусто, сетка окрашивается в нулевые (чёрные) цвета вершин по умолчанию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Сетка для окрашивания. | MESH | Да | N/A |
| `voxel_colors` | Воксельное поле, содержащее данные о цвете для окрашивания. Из поля используются только каналы RGB базового цвета. | VOXEL | Да | N/A |

Примечание: Когда координаты воксельного поля включают канал индекса пакета и входная сетка содержит несколько элементов сетки, узел применяет цвета отдельно к каждому элементу сетки в пакете. Выбранные цвета преобразуются из sRGB в линейный RGB для выходной сетки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `сетка` | Окрашенная сетка с применёнными цветами вершин. | MESH |
