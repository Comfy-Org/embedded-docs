# Раскрасить сетку

PaintMesh принимает 3D-меш и воксельное цветовое поле. Он назначает каждой вершине цвет ближайшего вокселя в поле и возвращает меш с применёнными цветами вершин. Если воксельное поле пусто, меш окрашивается цветами вершин по умолчанию — нулевыми (чёрными).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Меш, который нужно окрасить. | MESH | Да | N/A |
| `voxel_colors` | Воксельное поле, содержащее цветовые данные, используемые для окрашивания. Из поля используются только RGB-каналы базового цвета. | VOXEL | Да | N/A |

Примечание: Если координаты воксельного поля включают канал индекса пакета, а входной меш содержит несколько элементов меша, узел применяет цвета отдельно к каждому элементу меша в пакете. Если для данного элемента меша нет совпадающих вокселей, он получает цвета вершин по умолчанию — нулевые (чёрные). Сэмплированные цвета преобразуются из sRGB в линейное RGB для выходного меша, поскольку воксельное поле может содержать полные PBR-данные, но для цветов вершин используется только RGB базового цвета.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Окрашенный меш с применёнными цветами вершин. | MESH |
