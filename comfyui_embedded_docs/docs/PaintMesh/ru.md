# PaintMesh

PaintMesh принимает 3D-сетку и воксельное цветовое поле. Он назначает каждой вершине цвет ближайшего вокселя в поле, записывая результат в виде цветов вершин на выходной сетке. Если воксельное поле пустое, сетка окрашивается с использованием нулевых (чёрных) цветов вершин по умолчанию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Сетка для окрашивания. | MESH | Да | N/A |
| `voxel_colors` | Воксельное поле, содержащее цветовые данные, используемые для окрашивания. Из поля используются только каналы основного цвета RGB. | VOXEL | Да | N/A |

Примечание: если координаты воксельного поля включают канал индекса пакета, а входная сетка содержит несколько элементов сетки, узел применяет цвета отдельно к каждому элементу сетки в пакете. Сэмплированные цвета преобразуются из sRGB в линейный RGB для выходной сетки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Окрашенная сетка с применёнными цветами вершин. | MESH |
