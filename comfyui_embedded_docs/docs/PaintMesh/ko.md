# PaintMesh

PaintMesh는 3D 메시와 복셀 색상 필드를 입력으로 받습니다. 필드에서 가장 가까운 복셀의 색상을 각 정점에 할당하고, 그 결과를 출력 메시의 정점 색상으로 기록합니다. 복셀 필드가 비어 있는 경우, 메시는 기본값인 0(검은색) 정점 색상으로 칠해집니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 페인팅할 메시입니다. | MESH | 예 | 해당 없음 |
| `voxel_colors` | 페인팅에 사용되는 색상 데이터가 포함된 복셀 필드입니다. 필드에서 기본 색상 RGB 채널만 사용됩니다. | VOXEL | 예 | 해당 없음 |

참고: 복셀 필드 좌표에 배치 인덱스 채널이 포함되어 있고 입력 메시에 여러 메시 항목이 포함된 경우, 노드는 배치 내 각 메시 항목에 색상을 개별적으로 적용합니다. 샘플링된 색상은 출력 메시를 위해 sRGB에서 선형 RGB로 변환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | 정점 색상이 적용된 페인팅된 메시입니다. | MESH |
