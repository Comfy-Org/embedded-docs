# PaintMesh

PaintMesh 接收一个 3D 网格和一个体素颜色场。它将场中最近体素的颜色分配给每个顶点，并将结果作为顶点颜色写入输出网格。如果体素场为空，则使用默认的零（黑色）顶点颜色对网格进行着色。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要着色的网格。 | MESH | Yes | N/A |
| `voxel_colors` | 包含用于着色的颜色数据的体素场。仅使用该场中的基础颜色 RGB 通道。 | VOXEL | Yes | N/A |

注意：当体素场坐标包含批次索引通道且输入网格包含多个网格项时，节点会将颜色分别应用于批次中的每个网格项。采样颜色会从 sRGB 转换为线性 RGB，以供输出网格使用。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 已应用顶点颜色的着色网格。 | MESH |
