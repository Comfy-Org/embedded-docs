# PaintMesh

يقوم PaintMesh بتلوين شبكة ثلاثية الأبعاد وحقل ألوان فوكسل. يعيّن لكل رأس لون أقرب فوكسل في الحقل، ويكتب النتيجة كألوان رؤوس على الشبكة الناتجة. إذا كان حقل الفوكسل فارغًا، تُلون الشبكة بألوان رؤوس افتراضية صفرية (سوداء).

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `الشبكة` | الشبكة التي سيتم تلوينها. | MESH | نعم | N/A |
| `voxel_colors` | حقل فوكسل يحتوي على بيانات الألوان المستخدمة للتلوين. يتم استخدام قنوات RGB للون الأساسي فقط من الحقل. | VOXEL | نعم | N/A |

ملاحظة: عندما تتضمن إحداثيات حقل الفوكسل قناة فهرس دفعة وتحتوي الشبكة المدخلة على عدة عناصر شبكة، يطبق العقد الألوان بشكل منفصل على كل عنصر شبكة في الدفعة. يتم تحويل الألوان المأخوذة من sRGB إلى RGB الخطي للشبكة الناتجة.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `الشبكة` | الشبكة الملوّنة مع تطبيق ألوان الرؤوس. | MESH |
