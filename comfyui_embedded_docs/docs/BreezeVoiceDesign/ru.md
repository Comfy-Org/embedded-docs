# Breeze Voice Design

Создает новый голос Breeze по письменному описанию. Укажите описание голоса и фразу, которую он должен произнести; голос создается на основе этого превью и сохраняется в вашей учетной записи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `description` | Описание голоса от 3 до 500 символов: возраст, пол, акцент, тон, темп. По умолчанию: пусто. | STRING | Да | от 3 до 500 символов |
| `preview_text` | Фраза, которую новый голос произносит в превью, до 500 символов. Напишите её на выбранном языке, поскольку голос создается на основе этого превью. По умолчанию: пусто. | STRING | Да | от 1 до 500 символов |
| `language` | Язык текста превью. Английский и китайский могут использовать любую модель; другие языки используют Breeze TTS 2 Multilingual. | DYNAMIC_COMBO | Да | Доступно несколько вариантов |
| `strength` | Насколько точно голос следует описанию. По умолчанию: 4.0. | FLOAT | Нет | от 1.0 до 10.0 (шаг 0.1) |
| `seed` | Управляет повторным выполнением узла; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |

### Входы для языка "English" и "Chinese"

Эти параметры появляются только когда `language` имеет значение English или Chinese.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | `Breeze TTS 2` или `Breeze TTS 2 Multilingual`. По умолчанию: `"Breeze TTS 2"`. | COMBO | Да | `"Breeze TTS 2"`<br>`"Breeze TTS 2 Multilingual"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voice` | Новый голос Breeze, названный по описанию. | BREEZE_VOICE |
| `preview` | Аудиопревью созданного голоса. | AUDIO |
