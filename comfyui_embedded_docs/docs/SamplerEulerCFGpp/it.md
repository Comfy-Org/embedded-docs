# SamplerEulerCFGpp

Il nodo SamplerEulerCFGpp fornisce un metodo di campionamento Euler CFG++ per generare output. Questo nodo offre due diverse versioni di implementazione del campionatore Euler CFG++ selezionabili in base alle preferenze dell'utente.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `version` | La versione di implementazione del campionatore Euler CFG++ da utilizzare (predefinito: "regular") | STRING | Sì | `"regular"`<br>`"alternative"` |

## Output

| Nome output | Descrizione | Tipo di dati |
| --- | --- | --- |
| `sampler` | Restituisce un'istanza configurata del campionatore Euler CFG++ | SAMPLER |
