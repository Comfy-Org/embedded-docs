# Meshy：為模型貼圖（多視角）

此節點使用同一物件的 1 到 4 個參考視圖，為先前建立的 3D 模型加入紋理。您提供原始模型的任務 ID 與參考圖片；節點會將這些資料傳送至 Meshy 服務，等待工作完成，並以 GLB 與 FBX 檔案格式回傳貼上紋理的模型。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於紋理生成工作的 AI 模型。目前僅提供 "meshy-7"。 | COMBO | 是 | `"meshy-7"` |
| `Meshy 工作 ID` | 要加入紋理之先前建立 3D 模型的任務 ID。 | MESHY_TASK_ID | 是 | — |
| `多視角影像` | 同一物件的參考視圖。第一張圖片是主要（正面）視圖；其餘視圖的順序並不重要。可擴充插槽：連接 1 到 4 張圖片（`image_1` 至 `image_4`）。 | IMAGE | 是 | 1 到 4 張圖片 |
| `啟用原始 UV` | 使用模型的原始 UV，而非生成新的 UV。啟用時，Meshy 會保留上傳模型中的現有紋理。如果模型沒有原始 UV，輸出品質可能不會那麼好。（預設值：True） | BOOLEAN | 否 | True / False |
| `PBR` | 啟用 PBR（基於物理的渲染）紋理生成。（預設值：False） | BOOLEAN | 否 | True / False |
| `紋理解析度` | 基礎顏色紋理解析度。更高的解析度能捕捉更多表面細節。 | COMBO | 是 | `"2k"`<br>`"4k"`<br>`"8k"` |

**注意：** `multiview_images` 必須包含 1 到 4 張圖片。節點會在執行時驗證此條件，若數量超出此範圍則會引發錯誤。如果連接的圖片包含多張圖片的批次，則批次中的每張圖片都計入此限制。第一張圖片用作主要（正面）視圖；其餘圖片的順序不重要。
