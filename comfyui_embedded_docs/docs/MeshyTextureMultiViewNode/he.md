# Meshy: מרקם למודל (ריבוי תצוגות)

צומת זה מייצר טקסטורה למודל תלת-ממדי שנוצר קודם לכן באמצעות 1 עד 4 תצוגות עזר של אותו אובייקט. עליך לספק את מזהה המשימה של המודל המקורי ואת תמונות העזר; הצומת שולח אותן לשירות Meshy, ממתין לסיום המשימה, ומחזיר את המודל עם הטקסטורה כקבצי GLB ו-FBX.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI המשמש למשימת יצירת הטקסטורה. רק `"meshy-7"` זמין כעת. | COMBO | כן | `"meshy-7"` |
| `meshy_task_id` | מזהה המשימה של המודל התלת-ממדי שנוצר קודם לכן, שעבורו יש ליצור טקסטורה. | MESHY_TASK_ID | כן | — |
| `multiview_images` | תצוגות עזר של אותו אובייקט. התמונה הראשונה היא התצוגה הראשית (קדמית); סדר שאר התצוגות אינו משנה. משבצת ניתנת להרחבה: חבר 1 עד 4 תמונות (`image_1` עד `image_4`). | IMAGE | כן | 1 עד 4 תמונות |
| `enable_original_uv` | השתמש ב-UV המקורי של המודל במקום ליצור UV חדשים. כאשר האפשרות מופעלת, Meshy משמר טקסטורות קיימות מהמודל שהועלה. אם למודל אין UV מקורי, איכות הפלט עשויה להיות נמוכה יותר. (ברירת מחדל: True; אפשרות מתקדמת) | BOOLEAN | לא | True / False |
| `pbr` | מפעיל יצירת טקסטורה PBR (רינדור מבוסס פיזיקה). (ברירת מחדל: False; אפשרות מתקדמת) | BOOLEAN | לא | True / False |
| `texture_resolution` | רזולוציית טקסטורת צבע בסיס. רזולוציות גבוהות יותר לוכדות יותר פרטי משטח. | COMBO | כן | `"2k"`<br>`"4k"`<br>`"8k"` |

**הערה:** `multiview_images` חייב להכיל בין 1 ל-4 תמונות. הצומת מאמת זאת בזמן ריצה ומעלה שגיאה אם מספר התמונות מחוץ לטווח זה. אם תמונה מחוברת מכילה אצווה של מספר תמונות, כל תמונה באצווה נספרת לצורך המגבלה. התמונה הראשונה משמשת כתצוגה הראשית (קדמית); סדר שאר התמונות אינו משנה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | שם קובץ המודל. פלט זה נשמר לצורך תאימות לאחור בלבד. | STRING |
| `meshy_task_id` | מזהה המשימה של עבודת יצירת הטקסטורה. | MESHY_TASK_ID |
| `GLB` | המודל התלת-ממדי עם הטקסטורה שהורד בפורמט GLB. | FILE3DGLB |
| `FBX` | המודל התלת-ממדי עם הטקסטורה שהורד בפורמט FBX. | FILE3DFBX |
