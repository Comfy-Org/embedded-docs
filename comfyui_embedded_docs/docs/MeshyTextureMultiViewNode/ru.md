# Meshy: Текстурировать модель (мультиракурс)

Этот узел текстурирует ранее созданную 3D-модель, используя от 1 до 4 эталонных видов одного и того же объекта. Вы указываете ID задачи исходной модели и эталонные изображения; узел отправляет их в сервис Meshy, ожидает завершения задания и возвращает текстурированную модель в виде файлов GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | AI-модель, используемая для задания текстурирования. В настоящее время доступна только `"meshy-7"`. | COMBO | Да | `"meshy-7"` |
| `ID задачи Meshy` | ID задачи ранее созданной 3D-модели, которую нужно текстурировать. | MESHY_TASK_ID | Да | — |
| `многовидовые изображения` | Эталонные виды одного и того же объекта. Первое изображение — основной (передний) вид; порядок остальных изображений не имеет значения. Расширяемый слот: подключите от 1 до 4 изображений (`image_1`–`image_4`). | IMAGE | Да | от 1 до 4 изображений |
| `использовать исходные UV` | Использовать исходные UV-координаты модели вместо создания новых. Если включено, Meshy сохраняет существующие текстуры из загруженной модели. Если у модели нет исходных UV, качество результата может быть хуже. (по умолчанию: True; дополнительная опция) | BOOLEAN | Нет | True / False |
| `PBR` | Включает генерацию PBR-текстур (physically based rendering). (по умолчанию: False; дополнительная опция) | BOOLEAN | Нет | True / False |
| `разрешение текстуры` | Разрешение текстуры базового цвета. Более высокие разрешения передают больше деталей поверхности. | COMBO | Да | `"2k"`<br>`"4k"`<br>`"8k"` |

**Примечание:** `multiview_images` должен содержать от 1 до 4 изображений. Узел проверяет это во время выполнения и выдаёт ошибку, если количество выходит за пределы этого диапазона. Если подключённое изображение содержит пакет из нескольких изображений, каждое изображение в пакете учитывается в лимите. Первое изображение используется как основной (передний) вид; порядок остальных изображений не имеет значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла модели. Этот выход сохранён только для обратной совместимости. | STRING |
| `meshy_task_id` | ID задачи задания текстурирования. | MESHY_TASK_ID |
| `GLB` | Текстурированная 3D-модель, скачанная в формате GLB. | FILE3DGLB |
| `FBX` | Текстурированная 3D-модель, скачанная в формате FBX. | FILE3DFBX |
