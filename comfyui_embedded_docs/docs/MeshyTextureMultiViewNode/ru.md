# Meshy: Текстурировать модель (мультиракурс)

Этот узел накладывает текстуры на ранее созданную 3D-модель, используя от 1 до 4 эталонных изображений одного и того же объекта. Вы предоставляете идентификатор задачи исходной модели и эталонные изображения; узел отправляет их в сервис Meshy, ожидает завершения задания и возвращает модель с текстурами в файлах GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель ИИ, используемая для задания наложения текстуры. Сейчас доступна только "meshy-7". | COMBO | Да | `"meshy-7"` |
| `ID задачи Meshy` | Идентификатор задачи ранее созданной 3D-модели, на которую нужно наложить текстуру. | MESHY_TASK_ID | Да | — |
| `многовидовые изображения` | Эталонные изображения одного и того же объекта. Первое изображение является основным (вид спереди); порядок остальных изображений не имеет значения. Расширяемый слот: подключите от 1 до 4 изображений (`image_1` — `image_4`). | IMAGE | Да | от 1 до 4 изображений |
| `использовать исходные UV` | Использовать исходную UV-развертку модели вместо создания новой. При включении Meshy сохраняет существующие текстуры загруженной модели. Если у модели нет исходной UV-развертки, качество результата может быть ниже. (по умолчанию: True) | BOOLEAN | Нет | True / False |
| `PBR` | Включает генерацию PBR-текстур (физически корректный рендеринг). (по умолчанию: False) | BOOLEAN | Нет | True / False |
| `разрешение текстуры` | Разрешение базовой цветовой текстуры. Более высокое разрешение позволяет передать больше деталей поверхности. | COMBO | Да | `"2k"`<br>`"4k"`<br>`"8k"` |

**Примечание:** `multiview_images` должен содержать от 1 до 4 изображений. Узел проверяет это во время выполнения и вызывает ошибку, если количество выходит за пределы диапазона. Если подключенное изображение содержит пакет из нескольких изображений, каждое изображение в пакете учитывается в лимите. Первое изображение используется как основное (вид спереди); порядок остальных изображений не имеет значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Имя файла модели. Этот выход сохранен только для обратной совместимости. | STRING |
| `ID задачи Meshy` | Идентификатор задания наложения текстуры. | MESHY_TASK_ID |
| `GLB` | 3D-модель с текстурами, загруженная в формате GLB. | GLB |
| `FBX` | 3D-модель с текстурами, загруженная в формате FBX. | FBX |
