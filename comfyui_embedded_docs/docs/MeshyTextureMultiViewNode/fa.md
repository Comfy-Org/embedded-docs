# Meshy: بافت‌دهی مدل (چندنما)

این گره به یک مدل سه‌بعدی که قبلاً ساخته شده است، با استفاده از ۱ تا ۴ نمای مرجع از همان شیء بافت می‌دهد. شما شناسه وظیفه مدل اصلی و تصاویر مرجع را ارائه می‌دهید؛ گره آن‌ها را به سرویس Meshy می‌فرستد، منتظر می‌ماند تا کار تمام شود و مدل بافت‌دهی‌شده را به‌صورت فایل‌های GLB و FBX برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای کار بافت‌دهی. در حال حاضر فقط «meshy-7» در دسترس است. | COMBO | بله | `"meshy-7"` |
| `meshy_task_id` | شناسه وظیفه مدل سه‌بعدی که قبلاً ساخته شده و باید بافت‌دهی شود. | MESHY_TASK_ID | بله | — |
| `multiview_images` | نماهای مرجع همان شیء. تصویر اول نمای اصلی (جلو) است؛ ترتیب نماهای باقی‌مانده اهمیتی ندارد. جایگاه قابل گسترش: ۱ تا ۴ تصویر را متصل کنید (`image_1` تا `image_4`). | IMAGE | بله | 1 تا 4 تصویر |
| `enable_original_uv` | از UV اصلی مدل به‌جای تولید UVهای جدید استفاده کنید. وقتی فعال باشد، Meshy بافت‌های موجود از مدل بارگذاری‌شده را حفظ می‌کند. اگر مدل UV اصلی نداشته باشد، کیفیت خروجی ممکن است به‌خوبی نباشد. (پیش‌فرض: True؛ گزینه پیشرفته) | BOOLEAN | خیر | True / False |
| `pbr` | تولید بافت PBR (رندر مبتنی بر فیزیک) را فعال می‌کند. (پیش‌فرض: False؛ گزینه پیشرفته) | BOOLEAN | خیر | True / False |
| `texture_resolution` | رزولوشن بافت رنگ پایه. رزولوشن‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. | COMBO | بله | `"2k"`<br>`"4k"`<br>`"8k"` |

**توجه:** `multiview_images` باید بین ۱ تا ۴ تصویر داشته باشد. گره این مورد را در زمان اجرا بررسی می‌کند و اگر تعداد خارج از این محدوده باشد، خطا ایجاد می‌کند. اگر تصویر متصل‌شده شامل یک دسته از چند تصویر باشد، هر تصویر در آن دسته در سقف مجاز شمرده می‌شود. تصویر اول به‌عنوان نمای اصلی (جلو) استفاده می‌شود؛ ترتیب تصاویر باقی‌مانده اهمیتی ندارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل. این خروجی فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `meshy_task_id` | شناسه وظیفه کار بافت‌دهی. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی بافت‌دهی‌شده که در قالب GLB دانلود شده است. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی بافت‌دهی‌شده که در قالب FBX دانلود شده است. | FILE3DFBX |
