# Meshy: بافت‌دهی مدل (چندنما)

این گره یک مدل سه‌بعدی که قبلاً ساخته شده را با استفاده از ۱ تا ۴ نمای مرجع از همان شیء بافت‌دار می‌کند. شما شناسه وظیفه مدل اصلی و تصاویر مرجع را ارائه می‌دهید؛ گره آن‌ها را به سرویس Meshy ارسال می‌کند، منتظر اتمام کار می‌ماند و مدل بافت‌خورده را به‌صورت فایل‌های GLB و FBX بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای کار بافت‌دهی. در حال حاضر فقط «meshy-7» در دسترس است. | COMBO | بله | `"meshy-7"` |
| `meshy_task_id` | شناسه وظیفه مدل سه‌بعدی که قبلاً ساخته شده و قرار است بافت‌دهی شود. | MESHY_TASK_ID | بله | — |
| `multiview_images` | نمای‌های مرجع از همان شیء. تصویر اول نمای اصلی (جلو) است؛ ترتیب بقیه تصاویر مهم نیست. اسلات قابل افزایش: ۱ تا ۴ تصویر را متصل کنید (`image_1` تا `image_4`). | IMAGE | بله | ۱ تا ۴ تصویر |
| `enable_original_uv` | از UV اصلی مدل استفاده کنید به جای تولید UV جدید. وقتی فعال باشد، Meshy بافت‌های موجود از مدل بارگذاری‌شده را حفظ می‌کند. اگر مدل UV اصلی نداشته باشد، کیفیت خروجی ممکن است چندان خوب نباشد. (پیش‌فرض: True) | BOOLEAN | خیر | True / False |
| `pbr` | تولید بافت PBR (رندر مبتنی بر فیزیک) را فعال می‌کند. (پیش‌فرض: False) | BOOLEAN | خیر | True / False |
| `texture_resolution` | رزولوشن بافت رنگ پایه. رزولوشن‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. | COMBO | بله | `"2k"`<br>`"4k"`<br>`"8k"` |

**نکته:** `multiview_images` باید بین ۱ تا ۴ تصویر داشته باشد. گره این موضوع را در زمان اجرا اعتبارسنجی می‌کند و در صورت خارج بودن تعداد از این محدوده، خطایی صادر می‌کند. اگر یک تصویر متصل شامل دسته‌ای از چند تصویر باشد، هر تصویر در آن دسته در سقف تعداد لحاظ می‌شود. تصویر اول به‌عنوان نمای اصلی (جلو) استفاده می‌شود؛ ترتیب بقیه تصاویر مهم نیست.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل. این خروجی فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `meshy_task_id` | شناسه وظیفه کار بافت‌دهی. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی بافت‌خورده دانلود شده در قالب GLB. | GLB |
| `FBX` | مدل سه‌بعدی بافت‌خورده دانلود شده در قالب FBX. | FBX |
