# ClipTextEncode

`CLIP Text Encode (CLIPTextEncode)` выступает в роли переводчика, преобразуя ваши текстовые описания в формат, понятный ИИ. Это помогает ИИ интерпретировать ваш ввод и генерировать желаемое изображение.

Представьте, что вы общаетесь с художником, который говорит на другом языке. Модель CLIP, обученная на огромном количестве пар «изображение-текст», устраняет этот разрыв, преобразуя ваши описания в «инструкции», которым может следовать модель ИИ.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `текст` | Текст для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Любой текст |
| `clip` | Модель CLIP, используемая для кодирования текста. | CLIP | Да | Загруженные CLIP-модели |

Примечание: если вход `clip` равен None (например, когда он получен из загрузчика чекпоинтов, а сам чекпоинт не содержит корректной модели CLIP или текстового энкодера), узел выдаст ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Кондиционирующий вектор, содержащий встроенный текст и используемый для управления диффузионной моделью. | CONDITIONING |

## Возможности промпта

### Эмбеддинг-модели

Эмбеддинг-модели позволяют применять определённые художественные эффекты или стили. Поддерживаемые форматы: `.safetensors`, `.pt`, `.bin`. Чтобы использовать эмбеддинг-модель:

1. Поместите файл в папку `ComfyUI/models/embeddings`.
2. Укажите его в тексте с помощью `embedding:model_name`.

Пример: если у вас есть модель `EasyNegative.pt` в папке `ComfyUI/models/embeddings`, вы можете использовать её так:

```
worst quality, embedding:EasyNegative, bad quality
```

**ВАЖНО**: при использовании эмбеддинг-моделей проверьте, что имя файла точно совпадает и что эмбеддинг совместим с архитектурой вашей модели. Например, эмбеддинг, созданный для SD1.5, не будет корректно работать с моделью SDXL.

### Регулировка веса промпта

Вы можете регулировать важность отдельных частей описания с помощью круглых скобок. Например:

- `(beautiful:1.2)` увеличивает вес слова «beautiful».
- `(beautiful:0.8)` уменьшает вес слова «beautiful».
- Обычные круглые скобки `(beautiful)` применяют вес по умолчанию 1.1.

Для быстрой регулировки весов можно использовать сочетания клавиш `ctrl + стрелка вверх/вниз`. Величину шага изменения веса можно изменить в настройках.

Если нужно включить в промпт сами круглые скобки без изменения веса, экранируйте их обратной косой чертой, например `\(word\)`.

### Wildcard/динамические промпты

Используйте `{}` для создания динамических промптов. Например, `{day|night|morning}` будет случайным образом выбирать один из вариантов при каждой обработке промпта.

Если нужно включить в промпт сами фигурные скобки, не вызывая динамического поведения, экранируйте их обратной косой чертой, например `\{word\}`.
