# Кодирование текста CLIP (Запрос)

`CLIP Text Encode (CLIPTextEncode)` действует как переводчик, преобразуя ваши текстовые описания в формат, понятный ИИ. Это помогает ИИ интерпретировать ваш ввод и создавать желаемое изображение.

Представьте, что вы общаетесь с художником, который говорит на другом языке. Модель CLIP, обученная на огромном количестве пар «изображение—текст», устраняет этот разрыв, преобразуя ваши описания в «инструкции», которым может следовать модель ИИ.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `text` | Текст для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Любой текст |
| `clip` | Модель CLIP, используемая для кодирования текста. | CLIP | Да | Загруженные модели CLIP |

**Примечание**: Входной параметр `clip` должен быть допустимой моделью CLIP. Если он равен `None`, узел вызывает ошибку. Обычно это происходит, когда чекпойнт, загруженный узлом загрузки чекпойнтов, не содержит допустимой модели CLIP или текстового энкодера.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Кондиционирование, содержащее встроенный текст и используемое для управления диффузионной моделью. | CONDITIONING |

## Возможности промптов

### Модели эмбеддингов

Модели эмбеддингов позволяют применять определённые художественные эффекты или стили. Поддерживаемые форматы: `.safetensors`, `.pt`, `.bin`. Чтобы использовать модель эмбеддинга:

1. Поместите файл в папку `ComfyUI/models/embeddings`.
2. Укажите её в тексте с помощью `embedding:model_name`.

Пример: если у вас есть модель `EasyNegative.pt` в папке `ComfyUI/models/embeddings`, вы можете использовать её следующим образом:

```
worst quality, embedding:EasyNegative, bad quality
```

**ВАЖНО**: При использовании моделей эмбеддингов убедитесь, что имя файла точно совпадает и что эмбеддинг совместим с архитектурой вашей модели. Например, эмбеддинг, разработанный для SD1.5, не будет корректно работать с моделью SDXL.

### Регулировка веса промпта

Вы можете регулировать важность отдельных частей вашего описания с помощью круглых скобок. Например:

- `(beautiful:1.2)` увеличивает вес слова "beautiful".
- `(beautiful:0.8)` уменьшает вес слова "beautiful".
- Обычные круглые скобки `(beautiful)` применяют вес по умолчанию 1.1.

Вы можете использовать сочетания клавиш `ctrl + стрелка вверх/вниз` для быстрой регулировки весов. Шаг изменения веса можно изменить в настройках.

Если вы хотите включить в промпт буквальные круглые скобки без изменения веса, экранируйте их обратной косой чертой, например `\(word\)`.

### Подстановочные/динамические промпты

Используйте `{}` для создания динамических промптов. Например, `{day|night|morning}` будет случайным образом выбирать один из вариантов при каждой обработке промпта.

Если вы хотите включить в промпт буквальные фигурные скобки, не активируя динамическое поведение, экранируйте их обратной косой чертой, например `\{word\}`.
