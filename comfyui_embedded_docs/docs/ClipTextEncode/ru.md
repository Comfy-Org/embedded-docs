# ClipTextEncode

Кодирует текстовый промпт с помощью модели CLIP в эмбеддинг, который можно использовать для управления диффузионной моделью при генерации конкретных изображений.

`CLIP Text Encode (CLIPTextEncode)` действует как переводчик, преобразуя ваши текстовые описания в формат, понятный ИИ. Это помогает ИИ интерпретировать ваш ввод и генерировать нужное изображение.

Представьте, что вы общаетесь с художником, говорящим на другом языке. Модель CLIP, обученная на огромных наборах пар изображение-текст, преодолевает этот разрыв, преобразуя ваши описания в «инструкции», которым может следовать модель ИИ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `текст` | Текст для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Любой текст |
| `clip` | Модель CLIP, используемая для кодирования текста. | CLIP | Да | Загруженные модели CLIP |

Примечание. Если вход `clip` имеет значение None (например, когда он поступает от загрузчика чекпоинтов, в чекпоинте которого нет допустимой модели CLIP или текстового энкодера), узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Кондиционирование, содержащее эмбеддинг текста, который используется для управления диффузионной моделью. | CONDITIONING |

## Возможности промпта

### Модели эмбеддингов

Модели эмбеддингов позволяют применять определённые художественные эффекты или стили. Поддерживаемые форматы включают `.safetensors`, `.pt` и `.bin`. Чтобы использовать модель эмбеддингов:

1. Поместите файл в папку `ComfyUI/models/embeddings`.
2. Ссылайтесь на неё в тексте с помощью `embedding:model_name`.

Пример: если у вас есть модель с именем `EasyNegative.pt` в папке `ComfyUI/models/embeddings`, её можно использовать так:

```
worst quality, embedding:EasyNegative, bad quality
```

**ВАЖНО**: При использовании моделей эмбеддингов убедитесь, что имя файла совпадает и совместимо с архитектурой вашей модели. Например, эмбеддинг, предназначенный для SD1.5, не будет корректно работать с моделью SDXL.

### Настройка веса промпта

Вы можете регулировать важность определённых частей описания с помощью круглых скобок. Например:

- `(beautiful:1.2)` увеличивает вес "beautiful".
- `(beautiful:0.8)` уменьшает вес "beautiful".
- Обычные круглые скобки `(beautiful)` применяют вес по умолчанию 1.1.

Вы можете использовать сочетания клавиш `ctrl + up/down arrow` для быстрой настройки весов. Шаг изменения веса можно изменить в настройках.

Если вы хотите включить в промпт буквальные круглые скобки, не изменяя вес, их можно экранировать с помощью обратной косой черты, например `\(word\)`.

### Подстановочные/динамические промпты

Используйте `{}` для создания динамических промптов. Например, `{day|night|morning}` будет случайным образом выбирать один вариант при каждой обработке промпта.

Если вы хотите включить в промпт буквальные фигурные скобки, не вызывая динамическое поведение, их можно экранировать с помощью обратной косой черты, например `\{word\}`.
