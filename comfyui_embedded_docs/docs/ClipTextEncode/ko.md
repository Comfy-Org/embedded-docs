# CLIP 텍스트 인코딩 (프롬프트)

`CLIP Text Encode (CLIPTextEncode)`는 텍스트 설명을 AI가 이해할 수 있는 형식으로 변환하는 번역기 역할을 합니다. 이는 AI가 입력을 해석하고 원하는 이미지를 생성하도록 도와줍니다.

다른 언어를 사용하는 아티스트와 대화한다고 생각해 보세요. 방대한 이미지-텍스트 쌍으로 학습된 CLIP 모델은 텍스트 설명을 AI 모델이 따를 수 있는 "지침"으로 변환하여 이 간극을 메웁니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `text` | 인코딩할 텍스트입니다. 여러 줄 입력과 동적 프롬프트를 지원합니다. | STRING | 예 | 모든 텍스트 |
| `clip` | 텍스트 인코딩에 사용되는 CLIP 모델입니다. | CLIP | 예 | 로드된 CLIP 모델 |

**참고**: `clip` 입력은 유효한 CLIP 모델이어야 합니다. `None`이면 노드가 오류를 발생시킵니다. 이는 일반적으로 체크포인트 로더 노드가 로드한 체크포인트에 유효한 CLIP 또는 텍스트 인코더 모델이 포함되지 않은 경우 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `CONDITIONING` | 확산 모델을 안내하는 데 사용되는 임베딩된 텍스트가 포함된 컨디셔닝입니다. | CONDITIONING |

## 프롬프트 기능

### 임베딩 모델

임베딩 모델을 사용하면 특정 예술적 효과나 스타일을 적용할 수 있습니다. 지원되는 형식은 `.safetensors`, `.pt`, `.bin`입니다. 임베딩 모델을 사용하려면:

1. 파일을 `ComfyUI/models/embeddings` 폴더에 넣습니다.
2. 텍스트에서 `embedding:model_name` 형식으로 참조합니다.

예: `ComfyUI/models/embeddings` 폴더에 `EasyNegative.pt` 모델이 있으면 다음과 같이 사용할 수 있습니다.

```
worst quality, embedding:EasyNegative, bad quality
```

**중요**: 임베딩 모델을 사용할 때 파일 이름이 일치하는지, 모델 아키텍처와 호환되는지 확인하세요. 예를 들어 SD1.5용으로 설계된 임베딩은 SDXL 모델에서 올바르게 작동하지 않습니다.

### 프롬프트 가중치 조정

괄호를 사용하여 설명의 특정 부분 중요도를 조정할 수 있습니다. 예를 들어:

- `(beautiful:1.2)` "beautiful"의 가중치를 증가시킵니다.
- `(beautiful:0.8)` "beautiful"의 가중치를 감소시킵니다.
- 일반 괄호 `(beautiful)`는 기본 가중치 1.1을 적용합니다.

키보드 단축키 `Ctrl + 위/아래 화살표`를 사용하여 가중치를 빠르게 조정할 수 있습니다. 가중치 조정 단계 크기는 설정에서 변경할 수 있습니다.

가중치 변경 없이 리터럴 괄호를 프롬프트에 포함하려면 백슬래시로 이스케이프할 수 있습니다. 예: `\(word\)`.

### 와일드카드/동적 프롬프트

`{}`를 사용하여 동적 프롬프트를 만들 수 있습니다. 예를 들어 `{day|night|morning}`은 프롬프트가 처리될 때마다 옵션 중 하나를 무작위로 선택합니다.

동적 동작을 유발하지 않고 리터럴 중괄호를 프롬프트에 포함하려면 백슬래시로 이스케이프할 수 있습니다. 예: `\{word\}`.
