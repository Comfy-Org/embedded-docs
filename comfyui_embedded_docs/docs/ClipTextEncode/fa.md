# ClipTextEncode

یک پرامپت متنی را با استفاده از یک مدل CLIP به یک امبدینگ رمزگذاری می‌کند که می‌توان از آن برای هدایت مدل انتشار (diffusion model) به سمت تولید تصاویر مشخص استفاده کرد.

`CLIP Text Encode (CLIPTextEncode)` مانند یک مترجم عمل می‌کند و توضیحات متنی شما را به قالبی تبدیل می‌کند که هوش مصنوعی می‌تواند آن را بفهمد. این کار به هوش مصنوعی کمک می‌کند ورودی شما را تفسیر کند و تصویر مورد نظر را تولید کند.

آن را مانند ارتباط با هنرمندی در نظر بگیرید که به زبان دیگری صحبت می‌کند. مدل CLIP که بر روی جفت‌های عظیم تصویر-متن آموزش دیده است، این شکاف را با تبدیل توضیحات شما به «دستورالعمل‌هایی» که مدل هوش مصنوعی می‌تواند دنبال کند، پر می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `text` | متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | هر متنی |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. | CLIP | بله | مدل‌های CLIP بارگذاری‌شده |

نکته: اگر ورودی `clip` برابر None باشد (برای مثال، زمانی که از یک بارگذارنده checkpoint می‌آید که checkpoint آن شامل یک مدل CLIP یا رمزگذار متن معتبر نیست)، گره خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | یک conditioning شامل متن امبدشده که برای هدایت مدل انتشار استفاده می‌شود. | CONDITIONING |

## ویژگی‌های پرامپت

### مدل‌های امبدینگ

مدل‌های امبدینگ به شما امکان می‌دهند جلوه‌ها یا سبک‌های هنری مشخصی را اعمال کنید. قالب‌های پشتیبانی‌شده شامل `.safetensors`، `.pt` و `.bin` هستند. برای استفاده از یک مدل امبدینگ:

1. فایل را در پوشه `ComfyUI/models/embeddings` قرار دهید.
2. آن را در متن خود با استفاده از `embedding:model_name` ارجاع دهید.

مثال: اگر مدلی با نام `EasyNegative.pt` در پوشه `ComfyUI/models/embeddings` خود دارید، می‌توانید از آن به این صورت استفاده کنید:

```
worst quality, embedding:EasyNegative, bad quality
```

**مهم**: هنگام استفاده از مدل‌های امبدینگ، بررسی کنید که نام فایل مطابقت داشته باشد و با معماری مدل شما سازگار باشد. برای مثال، یک امبدینگ طراحی‌شده برای SD1.5 برای مدل SDXL به‌درستی کار نخواهد کرد.

### تنظیم وزن پرامپت

می‌توانید اهمیت بخش‌های خاصی از توضیح خود را با استفاده از پرانتز تنظیم کنید. برای مثال:

- `(beautiful:1.2)` وزن «beautiful» را افزایش می‌دهد.
- `(beautiful:0.8)` وزن «beautiful» را کاهش می‌دهد.
- پرانتزهای ساده `(beautiful)` وزن پیش‌فرض 1.1 را اعمال می‌کنند.

می‌توانید از میانبرهای صفحه‌کلید `ctrl + up/down arrow` برای تنظیم سریع وزن‌ها استفاده کنید. اندازه گام تنظیم وزن را می‌توان در تنظیمات تغییر داد.

اگر می‌خواهید پرانتزهای عینی را بدون تغییر وزن در پرامپت خود بگنجانید، می‌توانید با استفاده از بک‌اسلش آن‌ها را escape کنید؛ برای مثال `\(word\)`.

### پرامپت‌های Wildcard/پویا

از `{}` برای ایجاد پرامپت‌های پویا استفاده کنید. برای مثال، `{day|night|morning}` هر بار که پرامپت پردازش می‌شود، به‌صورت تصادفی یکی از گزینه‌ها را انتخاب می‌کند.

اگر می‌خواهید آکولادهای عینی را بدون فعال‌کردن رفتار پویا در پرامپت خود بگنجانید، می‌توانید با استفاده از بک‌اسلش آن‌ها را escape کنید؛ برای مثال `\{word\}`.
