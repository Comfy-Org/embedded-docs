# ClipTextEncode

`CLIP Text Encode (CLIPTextEncode)` مانند یک مترجم عمل می‌کند و توضیحات متنی شما را به قالبی تبدیل می‌کند که هوش مصنوعی بتواند آن را درک کند. این کار به هوش مصنوعی کمک می‌کند ورودی شما را تفسیر کرده و تصویر موردنظر را تولید کند.

آن را مانند ارتباط با هنرمندی در نظر بگیرید که به زبانی دیگر صحبت می‌کند. مدل CLIP که بر روی مجموعه‌های عظیمی از جفت‌های تصویر-متن آموزش دیده است، با تبدیل توضیحات شما به «دستورالعمل‌هایی» که مدل هوش مصنوعی می‌تواند دنبال کند، این شکاف را پر می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `متن` | متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | هر متنی |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. | CLIP | بله | مدل‌های CLIP بارگذاری‌شده |

نکته: اگر ورودی `clip` تهی (None) باشد (مثلاً وقتی از یک بارگذار checkpoint می‌آید که checkpoint آن حاوی مدل CLIP یا رمزگذار متن معتبر نیست)، گره خطا صادر می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | یک کاندیشنینگ شامل متن رمزگذاری‌شده که برای هدایت مدل دیفیوژن استفاده می‌شود. | CONDITIONING |

## ویژگی‌های پرامپت

### مدل‌های Embedding

مدل‌های Embedding به شما امکان می‌دهند جلوه‌ها یا سبک‌های هنری خاصی اعمال کنید. فرمت‌های پشتیبانی‌شده شامل `.safetensors`، `.pt` و `.bin` هستند. برای استفاده از یک مدل Embedding:

1. فایل را در پوشه `ComfyUI/models/embeddings` قرار دهید.
2. در متن خود با استفاده از `embedding:model_name` به آن ارجاع دهید.

مثال: اگر مدلی به نام `EasyNegative.pt` در پوشه `ComfyUI/models/embeddings` خود داشته باشید، می‌توانید به این صورت از آن استفاده کنید:

```
worst quality, embedding:EasyNegative, bad quality
```

**مهم**: هنگام استفاده از مدل‌های Embedding، مطمئن شوید که نام فایل با معماری مدل شما مطابقت و سازگاری دارد. برای مثال، یک Embedding طراحی‌شده برای SD1.5 با مدل SDXL به‌درستی کار نخواهد کرد.

### تنظیم وزن پرامپت

می‌توانید اهمیت بخش‌های خاصی از توضیحات خود را با استفاده از پرانتز تنظیم کنید. برای مثال:

- `(beautiful:1.2)` وزن «beautiful» را افزایش می‌دهد.
- `(beautiful:0.8)` وزن «beautiful» را کاهش می‌دهد.
- پرانتزهای ساده `(beautiful)` وزن پیش‌فرض 1.1 را اعمال می‌کنند.

می‌توانید از میانبرهای صفحه‌کلید `ctrl + up/down arrow` برای تنظیم سریع وزن‌ها استفاده کنید. اندازه گام تنظیم وزن را می‌توان در تنظیمات تغییر داد.

اگر می‌خواهید پرانتزهای واقعی را بدون تغییر وزن در پرامپت خود قرار دهید، می‌توانید با استفاده از بک‌اسلش آن‌ها را escape کنید، مثلاً `\(word\)`.

### پرامپت‌های Wildcard/پویا

از `{}` برای ایجاد پرامپت‌های پویا استفاده کنید. برای مثال، `{day|night|morning}` هر بار که پرامپت پردازش می‌شود، به‌طور تصادفی یک گزینه را انتخاب می‌کند.

اگر می‌خواهید آکولادهای واقعی را بدون فعال‌کردن رفتار پویا در پرامپت خود قرار دهید، می‌توانید آن‌ها را با بک‌اسلش escape کنید، مثلاً `\{word\}`.
