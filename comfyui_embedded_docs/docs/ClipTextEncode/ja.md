# CLIPテキストエンコード（プロンプト）

`CLIP Text Encode (CLIPTextEncode)` は、テキストによる説明をAIが理解できる形式に変換する、翻訳者のような役割を果たします。これにより、AIは入力内容を解釈し、目的の画像を生成できます。

これを、異なる言語を話すアーティストとのコミュニケーションと考えてみてください。CLIPモデルは、膨大な画像とテキストのペアでトレーニングされており、あなたの説明をAIモデルが従える「指示」に変換することで、このギャップを埋めます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `text` | エンコードするテキストです。複数行の入力と動的プロンプトに対応しています。 | STRING | はい | 任意のテキスト |
| `clip` | テキストのエンコードに使用するCLIPモデルです。 | CLIP | はい | 読み込み済みのCLIPモデル |

**注意**: `clip` 入力は有効なCLIPモデルである必要があります。`None` の場合、ノードはエラーを発生させます。これは通常、チェックポイントローダーノードによって読み込まれたチェックポイントに、有効なCLIPまたはテキストエンコーダーモデルが含まれていない場合に発生します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `CONDITIONING` | 拡散モデルを導くために使用される埋め込みテキストを含むコンディショニングです。 | CONDITIONING |

## プロンプト機能

### 埋め込みモデル

埋め込みモデルを使用すると、特定のアーティスティックな効果やスタイルを適用できます。対応形式は `.safetensors`、`.pt`、`.bin` です。埋め込みモデルを使用するには:

1. ファイルを `ComfyUI/models/embeddings` フォルダに配置します。
2. テキスト内で `embedding:model_name` を使用して参照します。

例: `ComfyUI/models/embeddings` フォルダに `EasyNegative.pt` というモデルがある場合、次のように使用できます:

```
worst quality, embedding:EasyNegative, bad quality
```

**重要**: 埋め込みモデルを使用する際は、ファイル名が一致し、モデルのアーキテクチャと互換性があることを確認してください。例えば、SD1.5向けに設計された埋め込みモデルは、SDXLモデルでは正しく機能しません。

### プロンプトの重み調整

括弧を使用して、説明の特定部分の重要度を調整できます。例:

- `(beautiful:1.2)` は「beautiful」の重みを増加させます。
- `(beautiful:0.8)` は「beautiful」の重みを減少させます。
- 通常の括弧 `(beautiful)` はデフォルトの重み1.1を適用します。

キーボードショートカット `ctrl + 上/下矢印` を使用して、重みをすばやく調整できます。重み調整のステップサイズは設定で変更できます。

重みを変更せずにプロンプトにリテラルの括弧を含めたい場合は、バックスラッシュでエスケープできます。例: `\(word\)`。

### ワイルドカード／動的プロンプト

`{}` を使用して動的プロンプトを作成できます。例えば、`{day|night|morning}` はプロンプトが処理されるたびにいずれかのオプションをランダムに選択します。

動的な動作を発生させずにプロンプトにリテラルの波括弧を含めたい場合は、バックスラッシュでエスケープできます。例: `\{word\}`。
