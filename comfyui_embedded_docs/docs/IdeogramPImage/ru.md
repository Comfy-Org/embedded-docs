# Ideogram & Pruna P-Image

Ideogram & Pruna P-Image генерирует изображения из текстового промпта с помощью быстрой модели Ideogram для преобразования текста в изображение, которая известна сильной типографикой и фотореализмом. Он также поддерживает структурированные JSON-описания Ideogram 4.0 для точного контроля над текстовыми строками, цветами и компоновкой. Узел возвращает сгенерированное изображение (изображения) вместе с итоговым промптом, на основе которого изображение фактически было сгенерировано.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт. Также принимает структурированное JSON-описание Ideogram 4.0 (точные цвета в виде шестнадцатеричных кодов #RRGGBB, точные текстовые строки, компоновка с ограничивающими рамками) — установите `prompt_upsampling` в OFF, чтобы использовать его дословно. Не должен быть пустым. (по умолчанию: "") | STRING | Да | Любой непустой текст |
| `quality` | Уровень скорости/цены/качества. MEDIUM — повседневный вариант по умолчанию; HIGH — для сложных промптов, мелких деталей и сложного текста; VERY_LOW/LOW — для черновиков в больших объёмах. Сложный текст плохо рендерится ниже MEDIUM. (по умолчанию: "MEDIUM") | COMBO | Да | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | Класс размера выходного изображения (точные пиксели зависят от соотношения сторон, например 16:9 даёт 1280x720 при 1K и 2560x1440 при 2K). Для чёткой типографики предпочитайте HIGH + 2K. (по умолчанию: "1K") | COMBO | Да | "1K"<br>"2K" |
| `aspect_ratio` | Соотношение сторон для генерации изображения. (по умолчанию: "1:1") | COMBO | Да | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | Разворачивает короткие промпты в подробное структурированное описание перед генерацией (переписанный промпт возвращается как `final_prompt`). Установите OFF, если вы подаёте собственное JSON-описание или точную формулировку. (по умолчанию: "AUTO") | COMBO | Да | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Сид для воспроизводимой генерации. При `prompt_upsampling` OFF одинаковые сид и настройки возвращают одно и то же изображение; при ON/AUTO переписывание промпта варьируется от запуска к запуску — чтобы воспроизвести результат, повторно используйте его выход `final_prompt` с `prompt_upsampling` OFF и тем же сидом. (по умолчанию: 42) | INT | Нет | от 0 до 2147483647 |

**Примечание по ограничениям:** Промпт должен содержать хотя бы один непробельный символ, иначе узел завершается с ошибкой. Установите `prompt_upsampling` в OFF, если подаёте собственное структурированное JSON-описание или точную формулировку. Когда `prompt_upsampling` имеет значение ON или AUTO, промпт переписывается перед генерацией, поэтому один и тот же сид может не воспроизвести одно и то же изображение; чтобы воспроизвести изображение, повторно используйте его выход `final_prompt` с `prompt_upsampling` OFF и тем же сидом.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (изображения), возвращаемое в виде пакета изображений. Если фильтр безопасности контента Ideogram блокирует генерацию, вместо этого возникает ошибка. | IMAGE |
| `final_prompt` | Промпт, на основе которого изображение фактически было сгенерировано (переписанное структурированное описание, если запускался `prompt_upsampling`, иначе ваш промпт). Подайте его обратно с `prompt_upsampling` OFF и тем же сидом, чтобы воспроизвести это изображение. | STRING |
