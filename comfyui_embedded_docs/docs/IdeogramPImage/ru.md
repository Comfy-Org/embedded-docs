# IdeogramPImage

Ideogram P-Image генерирует изображения по текстовому запросу, используя быструю модель преобразования текста в изображение Ideogram, известную своей качественной типографикой и фотореализмом. Она также поддерживает структурированные JSON-описания Ideogram 4.0 для точного контроля над текстовыми строками, цветами и макетом. Узел возвращает сгенерированные изображения вместе с финальным запросом, по которому изображение было фактически создано.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос. Также принимает структурированное JSON-описание Ideogram 4.0 (точные цвета в виде шестнадцатеричных кодов #RRGGBB, точные текстовые строки, макет с ограничивающими рамками) — установите prompt_upsampling в OFF, чтобы использовать его без изменений. Не должен быть пустым. (по умолчанию: "") | STRING | Да | Любой текст |
| `quality` | Уровень скорости/цены/качества. MEDIUM — повседневный выбор по умолчанию; HIGH — для сложных запросов, мелких деталей и сложного текста; VERY_LOW/LOW — для черновиков в больших объёмах. Сложный текст отображается плохо ниже MEDIUM. (по умолчанию: "MEDIUM") | STRING | Да | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | Класс размера выходного изображения (точные пиксели зависят от соотношения сторон, например, 16:9 даёт 1280x720 при 1K и 2560x1440 при 2K). Для чёткой типографики предпочтителен HIGH + 2K. (по умолчанию: "1K") | STRING | Да | "1K"<br>"2K" |
| `aspect_ratio` | Соотношение сторон для генерации изображения. (по умолчанию: "1:1") | STRING | Да | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | Расширяет короткие запросы в подробное структурированное описание перед генерацией (переписанный запрос возвращается как final_prompt). Установите OFF при использовании собственного JSON-описания или точной формулировки. (по умолчанию: "AUTO") | STRING | Да | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Сид для воспроизводимой генерации. При prompt_upsampling OFF один и тот же сид и настройки возвращают одно и то же изображение; при ON/AUTO переписывание запроса меняется от запуска к запуску — воспроизведите результат, повторно используя его выходной final_prompt с prompt_upsampling OFF и тем же сидом. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |

**Примечание об ограничениях:** Запрос должен содержать хотя бы один непробельный символ, иначе узел завершится с ошибкой. Установите `prompt_upsampling` в OFF при использовании собственного структурированного JSON-описания или точной формулировки. Когда `prompt_upsampling` установлен в ON или AUTO, запрос переписывается перед генерацией, поэтому один и тот же сид может не воспроизвести то же изображение; чтобы воспроизвести изображение, повторно используйте его выходной `final_prompt` с `prompt_upsampling` OFF и тем же сидом.

## Выходы

| Выходное имя | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (изображения), возвращаемое как пакет изображений. Если фильтр безопасности контента Ideogram блокирует генерацию, вместо этого возникает ошибка. | IMAGE |
| `final_prompt` | Запрос, по которому изображение было фактически сгенерировано (переписанное структурированное описание, если выполнялся prompt_upsampling, иначе ваш запрос). Подайте его обратно с prompt_upsampling OFF и тем же сидом, чтобы воспроизвести это изображение. | STRING |
