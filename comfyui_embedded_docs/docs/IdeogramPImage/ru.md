# Ideogram P-Image

Ideogram и Pruna P-Image генерируют изображения по текстовому запросу с помощью быстрой модели преобразования текста в изображение Ideogram, известной своей качественной типографикой и фотореализмом. Узел также поддерживает структурированные JSON-описания Ideogram 4.0 для точного управления текстовыми строками, цветами и компоновкой. Узел возвращает сгенерированные изображения вместе с итоговым запросом, из которого они фактически были созданы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос. Также принимает структурированное JSON-описание Ideogram 4.0 (точные цвета в виде #RRGGBB, точные текстовые строки, компоновка по ограничивающим рамкам) — установите `prompt_upsampling` в OFF, чтобы использовать его дословно. Не должно быть пустым. (по умолчанию: "") | STRING | Да | Любой непустой текст |
| `quality` | Уровень скорости/цены/качества. MEDIUM — стандартный вариант для повседневных задач; HIGH — для сложных запросов, мелких деталей и сложного текста; VERY_LOW/LOW — для черновиков в больших количествах. Сложный текст отображается плохо при качестве ниже MEDIUM. (по умолчанию: "MEDIUM") | COMBO | Да | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | Класс размера выходного изображения (точные значения пикселей зависят от соотношения сторон, например, 16:9 даёт 1280x720 при 1K и 2560x1440 при 2K). Для чёткой типографики выбирайте HIGH + 2K. (по умолчанию: "1K") | COMBO | Да | "1K"<br>"2K" |
| `aspect_ratio` | Соотношение сторон для генерации изображения. (по умолчанию: "1:1") | COMBO | Да | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | Расширяет короткие запросы в подробное структурированное описание перед генерацией (переписанный запрос возвращается в качестве `final_prompt`). Установите OFF, если вы предоставляете собственное JSON-описание или точную формулировку. (по умолчанию: "AUTO") | COMBO | Да | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Сид для воспроизводимой генерации. При `prompt_upsampling` OFF одинаковый сид и настройки возвращают одно и то же изображение; при ON/AUTO переписывание запроса меняется от запуска к запуску — чтобы воспроизвести результат, повторно используйте его выход `final_prompt` с `prompt_upsampling` OFF и тем же сидом. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |

**Примечание об ограничениях:** Запрос должен содержать хотя бы один непробельный символ, иначе узел завершится с ошибкой. Установите `prompt_upsampling` в OFF, если вы предоставляете собственное структурированное JSON-описание или точную формулировку. Когда `prompt_upsampling` имеет значение ON или AUTO, запрос переписывается перед генерацией, поэтому один и тот же сид может не воспроизвести одно и то же изображение; чтобы воспроизвести изображение, повторно используйте его выход `final_prompt` с `prompt_upsampling` OFF и тем же сидом.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (изображения), возвращаемое в виде пакета изображений. Если фильтр безопасности контента Ideogram блокирует генерацию, вместо этого возникает ошибка. | IMAGE |
| `final_prompt` | Запрос, из которого фактически было сгенерировано изображение (переписанное структурированное описание, если выполнялся `prompt_upsampling`, в противном случае — ваш запрос). Подайте его обратно с `prompt_upsampling` OFF и тем же сидом, чтобы воспроизвести это изображение. | STRING |
