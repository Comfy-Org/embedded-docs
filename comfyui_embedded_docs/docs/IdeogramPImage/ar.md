# IdeogramPImage

يقوم Ideogram P-Image بتوليد الصور من موجه نصي باستخدام نموذج Ideogram السريع للتحويل من نص إلى صورة، والذي يُعرف بقوته في الطباعة والواقعية. كما يدعم التسميات التوضيحية المنظمة بصيغة JSON من Ideogram 4.0 للتحكم الدقيق في السلاسل النصية والألوان والتخطيط. تُرجع العقدة الصور المولّدة بالإضافة إلى الموجه النهائي الذي تم توليد الصورة منه فعليًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجه نصي. يقبل أيضًا تسمية توضيحية منظمة بصيغة JSON من Ideogram 4.0 (ألوان دقيقة بصيغة #RRGGBB، سلاسل نصية دقيقة، تخطيط مربع الإحاطة) — اضبط prompt_upsampling على OFF لاستخدامها كما هي. يجب ألا يكون فارغًا. (الافتراضي: "") | STRING | نعم | أي نص |
| `quality` | مستوى السرعة/السعر/الجودة. MEDIUM هو الافتراضي اليومي؛ HIGH للموجهات المعقدة، والتفاصيل الدقيقة، والنصوص الصعبة؛ VERY_LOW/LOW للمسودات على نطاق واسع. النصوص الصعبة تظهر بشكل سيء دون مستوى MEDIUM. (الافتراضي: "MEDIUM") | STRING | نعم | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | فئة حجم المخرجات (البكسلات الدقيقة تتبع نسبة الأبعاد، على سبيل المثال 16:9 يعطي 1280x720 عند 1K و2560x1440 عند 2K). يُفضَّل HIGH مع 2K للحصول على طباعة واضحة. (الافتراضي: "1K") | STRING | نعم | "1K"<br>"2K" |
| `aspect_ratio` | نسبة الأبعاد لتوليد الصورة. (الافتراضي: "1:1") | STRING | نعم | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | يوسّع الموجهات القصيرة إلى تسمية توضيحية منظمة مفصلة قبل التوليد (يُعاد الموجه المعاد كتابته كـ final_prompt). اضبطه على OFF عند تقديم تسمية JSON التوضيحية الخاصة بك أو صياغة دقيقة. (الافتراضي: "AUTO") | STRING | نعم | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | القيمة المبدئية (البذرة) لتوليد قابل للتكرار. مع تعطيل prompt_upsampling (OFF)، تعيد نفس البذرة والإعدادات نفس الصورة؛ مع ON/AUTO يتغير الموجه المعاد كتابته في كل تشغيل — لإعادة إنتاج نتيجة، أعد استخدام مخرجه final_prompt مع تعطيل prompt_upsampling ونفس البذرة. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |

**ملاحظة حول القيود:** يجب أن يحتوي الموجه على حرف واحد غير مسافة بيضاء على الأقل، وإلا تفشل العقدة. اضبط `prompt_upsampling` على OFF عند تقديم تسمية JSON التوضيحية المنظمة الخاصة بك أو الصياغة الدقيقة. عندما يكون `prompt_upsampling` على ON أو AUTO، يُعاد كتابة الموجه قبل التوليد، لذلك قد لا تعيد نفس البذرة إنتاج نفس الصورة؛ لإعادة إنتاج صورة، أعد استخدام مخرج `final_prompt` مع `prompt_upsampling` على OFF ونفس البذرة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة (الصور) المولّدة كمُخرَج على شكل دفعة من الصور. إذا حظر مرشح أمان المحتوى في Ideogram التوليد، يتم إطلاق خطأ بدلاً من ذلك. | IMAGE |
| `final_prompt` | الموجه الذي تم توليد الصورة منه فعليًا (التسمية التوضيحية المنظمة المعاد كتابتها عند تشغيل prompt_upsampling، أو موجهك بخلاف ذلك). أعد إدخاله مع تعطيل prompt_upsampling (OFF) ونفس البذرة لإعادة إنتاج هذه الصورة. | STRING |
