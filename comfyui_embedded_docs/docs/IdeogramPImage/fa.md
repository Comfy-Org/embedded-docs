# IdeogramPImage

```markdown
Ideogram P-Image با استفاده از مدل سریع متن‌به‌تصویر Ideogram، تصاویری را از یک متن راهنما (prompt) تولید می‌کند که به تایپوگرافی قوی و واقع‌گرایی عکاسی معروف است. این گره همچنین از زیرنویس‌های ساختاریافته JSON نسخه 4.0 Ideogram برای کنترل دقیق رشته‌های متنی، رنگ‌ها و چیدمان پشتیبانی می‌کند. گره تصویر(های) تولیدشده را به همراه متن راهنمای نهایی که تصویر واقعاً از روی آن تولید شده است، بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنما. همچنین یک زیرنویس ساختاریافته JSON نسخه 4.0 Ideogram را می‌پذیرد (رنگ‌های دقیق به صورت هگز #RRGGBB، رشته‌های متنی دقیق، چیدمان جعبه‌محصور) — برای استفاده عیناً از آن، `prompt_upsampling` را روی OFF قرار دهید. نباید خالی باشد. (پیش‌فرض: "") | STRING | بله | هر متنی |
| `quality` | سطح سرعت/قیمت/کیفیت. MEDIUM پیش‌فرض روزمره است؛ HIGH برای متن‌های راهنمای پیچیده، جزئیات دقیق و متن دشوار؛ VERY_LOW/LOW برای پیش‌نویس‌ها در مقیاس بزرگ. متن دشوار در سطوح پایین‌تر از MEDIUM کیفیت ضعیفی دارد. (پیش‌فرض: "MEDIUM") | STRING | بله | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | کلاس اندازه خروجی (پیکسل‌های دقیق تابع نسبت ابعاد هستند، مثلاً 16:9 در 1K تصویر 1280x720 و در 2K تصویر 2560x1440 می‌دهد). برای تایپوگرافی واضح، HIGH + 2K را ترجیح دهید. (پیش‌فرض: "1K") | STRING | بله | "1K"<br>"2K" |
| `aspect_ratio` | نسبت ابعاد برای تولید تصویر. (پیش‌فرض: "1:1") | STRING | بله | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | متن‌های راهنمای کوتاه را قبل از تولید به یک زیرنویس ساختاریافته دقیق گسترش می‌دهد (متن راهنمای بازنویسی‌شده به عنوان `final_prompt` بازگردانده می‌شود). هنگامی که زیرنویس JSON یا عبارت دقیق خود را ارائه می‌دهید، آن را روی OFF قرار دهید. (پیش‌فرض: "AUTO") | STRING | بله | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | دانه (Seed) برای تولید قابل تکرار. با خاموش بودن `prompt_upsampling`، همان seed و تنظیمات، همان تصویر را بازمی‌گردانند؛ با ON/AUTO بازنویسی متن راهنما در هر اجرا متفاوت است — برای تکرار یک نتیجه، خروجی `final_prompt` آن را با خاموش بودن `prompt_upsampling` و همان seed دوباره استفاده کنید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

**نکته درباره محدودیت‌ها:** متن راهنما باید حداقل یک نویسه غیرفضایی داشته باشد، در غیر این صورت گره با خطا مواجه می‌شود. هنگام ارائه زیرنویس ساختاریافته JSON یا عبارت دقیق خود، `prompt_upsampling` را روی OFF قرار دهید. وقتی `prompt_upsampling` روی ON یا AUTO باشد، متن راهنما قبل از تولید بازنویسی می‌شود، بنابراین ممکن است همان seed تصویر مشابهی را تولید نکند؛ برای تکرار یک تصویر، خروجی `final_prompt` آن را با `prompt_upsampling` خاموش و همان seed دوباره استفاده کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) تولیدشده به صورت یک دسته از تصاویر بازگردانده می‌شود. اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، در عوض یک خطا صادر می‌شود. | IMAGE |
| `final_prompt` | متن راهنمایی که تصویر واقعاً از روی آن تولید شده است (زیرنویس ساختاریافته بازنویسی‌شده وقتی `prompt_upsampling` اجرا شده، در غیر این صورت متن راهنمای شما). برای تکرار این تصویر، آن را با خاموش بودن `prompt_upsampling` و همان seed دوباره وارد کنید. | STRING |
```
