# ایدوگرام P-Image

Ideogram و Pruna P-Image تصاویری را از یک پرامپت متنی با استفاده از مدل سریع متن‌به‌تصویر Ideogram تولید می‌کند که به خاطر تایپوگرافی قوی و فتورئالیسم شناخته می‌شود. همچنین از کپشن‌های JSON ساختاریافته Ideogram 4.0 برای کنترل دقیق رشته‌های متنی، رنگ‌ها و چیدمان پشتیبانی می‌کند. گره تصویر(های) تولیدشده را همراه با پرامپت نهایی که تصویر در واقع بر اساس آن تولید شده است، برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|----------|-----------|--------|-------|
| `prompt` | پرامپت متنی. همچنین یک کپشن JSON ساختاریافته Ideogram 4.0 را می‌پذیرد (رنگ‌های دقیق به صورت هگز #RRGGBB، رشته‌های متنی دقیق، چیدمان جعبه محدودکننده) — برای استفاده از آن به صورت دقیق (بدون تغییر)، `prompt_upsampling` را روی OFF تنظیم کنید. نباید خالی باشد. (پیش‌فرض: "") | STRING | بله | هر متن غیرخالی |
| `quality` | سطح سرعت/هزینه/کیفیت. MEDIUM پیش‌فرض معمول روزانه است؛ HIGH برای پرامپت‌های پیچیده، جزئیات ریز و متن دشوار؛ VERY_LOW/LOW برای پیش‌نویس‌ها در مقیاس بزرگ. متن دشوار در کیفیت پایین‌تر از MEDIUM ضعیف رندر می‌شود. (پیش‌فرض: "MEDIUM") | COMBO | بله | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | کلاس اندازه خروجی (پیکسل‌های دقیق با نسبت تصویر هماهنگ است، به عنوان مثال 16:9 در 1K تصویر 1280x720 و در 2K تصویر 2560x1440 می‌دهد). برای تایپوگرافی واضح، HIGH + 2K را ترجیح دهید. (پیش‌فرض: "1K") | COMBO | بله | "1K"<br>"2K" |
| `aspect_ratio` | نسبت تصویر برای تولید تصویر. (پیش‌فرض: "1:1") | COMBO | بله | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | پرامپت‌های کوتاه را قبل از تولید به یک کپشن ساختاریافته و دقیق گسترش می‌دهد (پرامپت بازنویسی‌شده به عنوان final_prompt بازگردانده می‌شود). زمانی که کپشن JSON یا متن دقیق خودتان را ارائه می‌دهید، آن را روی OFF تنظیم کنید. (پیش‌فرض: "AUTO") | COMBO | بله | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Seed برای تولید قابل تکرار. با `prompt_upsampling` روی OFF، همان seed و تنظیمات، همان تصویر را برمی‌گردانند؛ با ON/AUTO بازنویسی پرامپت در هر اجرا متفاوت است — برای تکرار یک نتیجه، خروجی final_prompt آن را با `prompt_upsampling` روی OFF و همان seed دوباره استفاده کنید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

**نکته درباره محدودیت‌ها:** پرامپت باید حداقل یک کاراکتر غیرفضایی داشته باشد، در غیر این صورت گره با خطا مواجه می‌شود. هنگام ارائه کپشن JSON ساختاریافته یا متن دقیق خودتان، `prompt_upsampling` را روی OFF تنظیم کنید. وقتی `prompt_upsampling` روی ON یا AUTO باشد، پرامپت قبل از تولید بازنویسی می‌شود، بنابراین ممکن است همان seed تصویر یکسانی را بازتولید نکند؛ برای بازتولید یک تصویر، خروجی `final_prompt` آن را با `prompt_upsampling` روی OFF و همان seed دوباره استفاده کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|----------|-----------|
| `image` | تصویر(های) تولیدشده به صورت یک دسته از تصاویر بازگردانده می‌شود. اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، به جای آن یک خطا برمی‌خیزد. | IMAGE |
| `final_prompt` | پرامپتی که تصویر در واقع از روی آن تولید شده است (کپشن ساختاریافته بازنویسی‌شده وقتی prompt_upsampling اجرا شده، وگرنه پرامپت شما). آن را با `prompt_upsampling` روی OFF و همان seed بازخورد دهید تا این تصویر را بازتولید کنید. | STRING |
