# Ideogram & Pruna P-Image

Ideogram & Pruna P-Image با استفاده از مدل سریع متن‌به‌تصویر Ideogram تصاویری را از یک درخواست متنی تولید می‌کند، که به تایپوگرافی قوی و واقع‌گرایی عکاسی شهرت دارد. همچنین از زیرنویس‌های JSON ساختاریافته Ideogram 4.0 برای کنترل دقیق رشته‌های متنی، رنگ‌ها و چیدمان پشتیبانی می‌کند. این گره تصویر(های) تولیدشده را همراه با درخواست نهایی که تصویر واقعاً از آن تولید شده است برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | درخواست متنی. همچنین یک زیرنویس JSON ساختاریافته Ideogram 4.0 را می‌پذیرد (رنگ‌های دقیق به‌صورت هگز #RRGGBB، رشته‌های متنی دقیق، چیدمان جعبه محدودکننده) — برای استفاده عین‌به‌عین از آن، `prompt_upsampling` را روی OFF قرار دهید. نباید خالی باشد. (پیش‌فرض: "") | STRING | بله | هر متن غیرخالی |
| `quality` | رده سرعت/قیمت/کیفیت. MEDIUM پیش‌فرض روزمره است؛ HIGH برای درخواست‌های پیچیده، جزئیات ظریف و متن دشوار؛ VERY_LOW/LOW برای پیش‌نویس‌های انبوه. متن دشوار پایین‌تر از MEDIUM ضعیف رندر می‌شود. (پیش‌فرض: "MEDIUM") | COMBO | بله | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | رده اندازه خروجی (پیکسل‌های دقیق از نسبت تصویر پیروی می‌کنند، مثلاً 16:9 در 1K برابر 1280x720 و در 2K برابر 2560x1440 می‌دهد). برای تایپوگرافی واضح HIGH + 2K را ترجیح دهید. (پیش‌فرض: "1K") | COMBO | بله | "1K"<br>"2K" |
| `aspect_ratio` | نسبت تصویر برای تولید تصویر. (پیش‌فرض: "1:1") | COMBO | بله | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | درخواست‌های کوتاه را پیش از تولید به یک زیرنویس ساختاریافته مفصل گسترش می‌دهد (درخواست بازنویسی‌شده به‌عنوان `final_prompt` برگردانده می‌شود). زمانی که زیرنویس JSON خودتان یا جمله‌بندی دقیق را ارائه می‌دهید، آن را روی OFF قرار دهید. (پیش‌فرض: "AUTO") | COMBO | بله | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | بذر برای تولید قابل‌تکرار. وقتی `prompt_upsampling` روی OFF باشد، همان بذر و تنظیمات همان تصویر را برمی‌گردانند؛ وقتی ON/AUTO باشد، بازنویسی درخواست در هر اجرا متفاوت است — برای بازتولید یک نتیجه، خروجی `final_prompt` آن را با `prompt_upsampling` روی OFF و همان بذر دوباره استفاده کنید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

**نکته درباره محدودیت‌ها:** درخواست باید حداقل شامل یک کاراکتر غیرفاصله باشد، در غیر این صورت گره شکست می‌خورد. وقتی زیرنویس JSON ساختاریافته خودتان یا جمله‌بندی دقیق را ارائه می‌دهید، `prompt_upsampling` را روی OFF قرار دهید. وقتی `prompt_upsampling` روی ON یا AUTO باشد، درخواست پیش از تولید بازنویسی می‌شود، بنابراین ممکن است همان بذر همان تصویر را بازتولید نکند؛ برای بازتولید یک تصویر، خروجی `final_prompt` آن را با `prompt_upsampling` روی OFF و همان بذر دوباره استفاده کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) تولیدشده که به‌صورت یک دسته از تصاویر برگردانده می‌شوند. اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، به‌جای آن خطا ایجاد می‌شود. | IMAGE |
| `final_prompt` | درخواستی که تصویر واقعاً از آن تولید شده است (زیرنویس ساختاریافته بازنویسی‌شده وقتی `prompt_upsampling` اجرا شده باشد، در غیر این صورت درخواست شما). آن را با `prompt_upsampling` روی OFF و همان بذر دوباره بدهید تا این تصویر بازتولید شود. | STRING |
