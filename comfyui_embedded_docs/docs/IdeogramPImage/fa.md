# IdeogramPImage

Ideogram P-Image تصاویری را از یک متن ورودی (prompt) با استفاده از مدل سریع متن‌به‌تصویر Ideogram تولید می‌کند که به حروف‌نگاری قوی و فتورئالیسم معروف است. همچنین از زیرنویس‌های ساختاریافته JSON نسخه 4.0 Ideogram برای کنترل دقیق رشته‌های متنی، رنگ‌ها و چیدمان پشتیبانی می‌کند. این گره تصویر(های) تولیدشده را به همراه prompt نهایی که تصویر در واقع بر اساس آن تولید شده است بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|----------|-----------|---------|--------|
| `prompt` | متن ورودی (prompt). همچنین یک زیرنویس ساختاریافته JSON نسخه 4.0 Ideogram را می‌پذیرد (رنگ‌های دقیق به‌صورت هگز #RRGGBB، رشته‌های متنی دقیق، چیدمان جعبه مرزبندی) — برای استفاده دقیقاً به همین شکل، prompt_upsampling را روی OFF قرار دهید. نباید خالی باشد. (پیش‌فرض: "") | STRING | بله | هر متنی |
| `quality` | سطح سرعت/قیمت/کیفیت. MEDIUM پیش‌فرض روزمره است؛ HIGH برای promptهای پیچیده، جزئیات دقیق و متن دشوار؛ VERY_LOW/LOW برای پیش‌نویس‌ها در مقیاس بزرگ. متن دشوار در سطح پایین‌تر از MEDIUM کیفیت ضعیفی تولید می‌کند. (پیش‌فرض: "MEDIUM") | STRING | بله | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | کلاس اندازه خروجی (پیکسل‌های دقیق تابع نسبت ابعاد هستند، به‌عنوان مثال 16:9 در 1K تصویر 1280x720 و در 2K تصویر 2560x1440 تولید می‌کند). برای حروف‌نگاری واضح، HIGH + 2K را ترجیح دهید. (پیش‌فرض: "1K") | STRING | بله | "1K"<br>"2K" |
| `aspect_ratio` | نسبت ابعاد برای تولید تصویر. (پیش‌فرض: "1:1") | STRING | بله | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | promptهای کوتاه را قبل از تولید به یک زیرنویس ساختاریافته دقیق بسط می‌دهد (prompt بازنویسی‌شده به‌عنوان final_prompt بازگردانده می‌شود). هنگام ارائه زیرنویس JSON یا عبارت دقیق خودتان، آن را روی OFF قرار دهید. (پیش‌فرض: "AUTO") | STRING | بله | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Seed برای تولید قابل تکرار. با OFF بودن prompt_upsampling، همان seed و تنظیمات، همان تصویر را بازمی‌گردانند؛ با ON/AUTO بازنویسی prompt در هر اجرا تغییر می‌کند — برای تکرار یک نتیجه، خروجی final_prompt آن را با OFF بودن prompt_upsampling و همان seed دوباره استفاده کنید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

**نکته درباره محدودیت‌ها:** prompt باید حداقل یک نویسه غیر فضایی داشته باشد، در غیر این صورت گره با خطا مواجه می‌شود. هنگام ارائه زیرنویس ساختاریافته JSON یا عبارت دقیق خودتان، `prompt_upsampling` را روی OFF قرار دهید. وقتی `prompt_upsampling` روی ON یا AUTO باشد، prompt قبل از تولید بازنویسی می‌شود، بنابراین همان seed ممکن است تصویر یکسانی را بازتولید نکند؛ برای تکرار یک تصویر، خروجی `final_prompt` آن را با `prompt_upsampling` روی OFF و همان seed دوباره استفاده کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|------------|----------|-----------|
| `image` | تصویر(های) تولیدشده به‌صورت یک دسته از تصاویر بازگردانده می‌شود. اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، در عوض یک خطا صادر می‌شود. | IMAGE |
| `final_prompt` | prompt که تصویر در واقع بر اساس آن تولید شده است (زیرنویس ساختاریافته بازنویسی‌شده زمانی که prompt_upsampling اجرا شده، وگرنه prompt خود شما). برای تکرار این تصویر، آن را با OFF بودن prompt_upsampling و همان seed دوباره وارد کنید. | STRING |
