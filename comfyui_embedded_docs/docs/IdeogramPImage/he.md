# IdeogramPImage

Ideogram & Pruna P-Image יוצר תמונות מפרומפט טקסטואלי באמצעות מודל טקסט-לתמונה המהיר של Ideogram, הידוע בטיפוגרפיה חזקה ובריאליזם פוטוגרפי. הוא תומך גם בכיתובי JSON מובנים של Ideogram 4.0 לשליטה מדויקת במחרוזות טקסט, צבעים ופריסה. הצומת מחזיר את התמונה/התמונות שנוצרו יחד עם הפרומפט הסופי שממנו התמונה למעשה נוצרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי. מקבל גם כיתוב JSON מובנה של Ideogram 4.0 (צבעים מדויקים כערכי hex מסוג #RRGGBB, מחרוזות טקסט מדויקות, פריסת תיבות תוחמות) — יש להגדיר את prompt_upsampling ל-OFF כדי להשתמש בו כפי שהוא. אסור שיהיה ריק. (ברירת מחדל: "") | STRING | כן | כל טקסט לא ריק |
| `quality` | דרגת מהירות/מחיר/איכות. MEDIUM היא ברירת המחדל היומיומית; HIGH עבור פרומפטים מורכבים, פרטים עדינים וטקסט קשה; VERY_LOW/LOW עבור טיוטות בקנה מידה. טקסט קשה נוצר באיכות ירודה מתחת ל-MEDIUM. (ברירת מחדל: "MEDIUM") | COMBO | כן | "VERY_LOW"<br>"LOW"<br>"MEDIUM"<br>"HIGH" |
| `resolution` | מחלקת גודל פלט (הפיקסלים המדויקים נגזרים מיחס הגובה-רוחב, למשל 16:9 מפיק 1280x720 ב-1K ו-2560x1440 ב-2K). מומלץ HIGH + 2K עבור טיפוגרפיה חדה. (ברירת מחדל: "1K") | COMBO | כן | "1K"<br>"2K" |
| `aspect_ratio` | יחס הגובה-רוחב ליצירת התמונה. (ברירת מחדל: "1:1") | COMBO | כן | "1:3"<br>"3:1"<br>"1:2"<br>"2:1"<br>"9:16"<br>"16:9"<br>"10:16"<br>"16:10"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"1:1" |
| `prompt_upsampling` | מרחיב פרומפטים קצרים לכיתוב מובנה מפורט לפני היצירה (הפרומפט שנוסח מחדש מוחזר בתור final_prompt). יש להגדיר OFF כאשר מספקים כיתוב JSON משלכם או ניסוח מדויק. (ברירת מחדל: "AUTO") | COMBO | כן | "AUTO"<br>"ON"<br>"OFF" |
| `seed` | Seed ליצירה ניתנת לשחזור. כאשר prompt_upsampling מוגדר ל-OFF, אותו seed ואותן הגדרות מחזירים את אותה תמונה; כאשר ON/AUTO, שכתוב הפרומפט משתנה בכל ריצה — ניתן לשחזר תוצאה על ידי שימוש חוזר בפלט final_prompt שלה עם prompt_upsampling OFF ואותו seed. (ברירת מחדל: 42) | INT | לא | 0 to 2147483647 |

**הערה על אילוצים:** הפרומפט חייב להכיל לפחות תו אחד שאינו רווח, אחרת הצומת נכשל. יש להגדיר את `prompt_upsampling` ל-OFF כאשר מספקים כיתוב JSON מובנה משלכם או ניסוח מדויק. כאשר `prompt_upsampling` מוגדר ל-ON או AUTO, הפרומפט נכתב מחדש לפני היצירה, כך שאותו seed עשוי שלא לשחזר את אותה תמונה; כדי לשחזר תמונה, השתמשו שוב בפלט `final_prompt` שלה עם `prompt_upsampling` OFF ואותו seed.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `image` | התמונה/תמונות שנוצרו מוחזרות כאצווה של תמונות. אם מסנן בטיחות התוכן של Ideogram חוסם את היצירה, תופעל שגיאה במקום. | IMAGE |
| `final_prompt` | הפרומפט שממנו התמונה למעשה נוצרה (הכיתוב המובנה שנוסח מחדש כאשר prompt_upsampling פעל, אחרת הפרומפט שלכם). הזינו אותו בחזרה עם prompt_upsampling OFF ואותו seed כדי לשחזר את התמונה הזו. | STRING |
