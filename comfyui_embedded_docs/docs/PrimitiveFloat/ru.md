# Число с плавающей запятой

Узел PrimitiveFloat создает значение числа с плавающей запятой, которое можно использовать в вашем рабочем процессе. Он принимает одно числовое значение и выводит то же самое значение, позволяя вам задавать и передавать значения с плавающей запятой между различными узлами в конвейере ComfyUI.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Значение числа с плавающей запятой для вывода (по умолчанию: 0.0) | FLOAT | Да | -sys.maxsize to sys.maxsize (step: 0.1) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Входное значение числа с плавающей запятой | FLOAT |
