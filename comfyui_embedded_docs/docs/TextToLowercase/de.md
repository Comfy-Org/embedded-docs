# TextToLowercase

Der Node „Text to Lowercase“ nimmt eine Textzeichenfolge als Eingabe entgegen und wandelt alle Zeichen in Kleinbuchstaben um. Es ist ein einfaches Hilfsmittel zur Vereinheitlichung der Groß-/Kleinschreibung von Text.

> **Hinweis:** Dieser Node ist veraltet und wurde durch den Node „Convert Text Case“ ersetzt.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
| --- | --- | --- | --- | --- |
| `text` | Die Textzeichenfolge, die in Kleinbuchstaben umgewandelt werden soll. | STRING | Ja | Beliebige Textzeichenfolge |

## Ausgaben

| Ausgabename | Beschreibung | Datentyp |
| --- | --- | --- |
| `text` | Der Eingabetext, bei dem alle Zeichen in Kleinbuchstaben umgewandelt wurden. | STRING |
