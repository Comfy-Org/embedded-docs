# TextToLowercase

Il nodo Text to Lowercase accetta in input una stringa di testo e converte tutti i suoi caratteri in minuscolo. È un semplice strumento di utilità per standardizzare l'uso di maiuscole e minuscole nel testo.

> **Nota:** questo nodo è deprecato ed è stato sostituito dal nodo Convert Text Case.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `text` | La stringa di testo da convertire in minuscolo. | STRING | Sì | Qualsiasi stringa di testo |

## Output

| Nome output | Descrizione | Tipo di dati |
| --- | --- | --- |
| `text` | Il testo di input con tutti i caratteri convertiti in minuscolo. | STRING |
