# p-h3-image Conditioning

Этот узел преобразует промпт в кондиционирование и пустой латент для одного неподвижного изображения с помощью p-h3-image. Без изображений это режим текст-в-изображение; при подключённых изображениях `image_1` — редактируемое изображение, а остальные слоты служат эталонами, к которым промпт обращается как `<Picture 1>`, `<Picture 2>` и т. д. Сэмплеру нужна модель, пропатченная узлом сдвига сигмы MiniMax H3, при этом оба значения сдвига должны быть равны 1.0.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | CLIP-модель p-h3-image, используемая для токенизации промпта, включая любые эталонные изображения, и для кодирования кондиционирования. | CLIP | Да | - |
| `prompt` | Что сгенерировать или как отредактировать `image_1`. При подключённых изображениях к короткой инструкции добавляется префикс `Edit <Picture 1>. `. Инструкция, которая уже начинается с `Edit <Picture`, или краткое описание редактирования, созданное апсемплером промпта, используется ровно в том виде, в каком оно записано. | STRING | Да | - |
| `width` | Ширина выходного изображения в пикселях. 0 использует ширину `image_1` после масштабирования или 2912, если изображение не подключено (по умолчанию: 0). | INT | Да | от 0 до MAX_RESOLUTION |
| `height` | Высота выходного изображения в пикселях. 0 использует высоту `image_1` после масштабирования или 2912, если изображение не подключено (по умолчанию: 0). | INT | Да | от 0 до MAX_RESOLUTION |
| `vae` | VAE p-h3-image. Требуется, как только подключён слот изображения, поскольку с его помощью кодируются эталонные латенты. | VAE | Нет | - |
| `images` | Расширяемая группа до 9 изображений, от `image_1` до `image_9`. `image_1` — редактируемое изображение, остальные слоты — эталоны. | AUTOGROW | Нет | от 0 до 9 изображений |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Кондиционирование для сэмплера p-h3-image. При подключённых изображениях также содержит упакованные эталонные латенты. | CONDITIONING |
| `latent` | Пустой латент для одного неподвижного кадра, включая два аудиолатента, которые ожидает модель. | LATENT |

**Примечание.** Для изображений требуется вход `vae`. Запуск узла с подключённым изображением и без VAE вызывает ошибку.

**Примечание.** Кондиционирование охватывает один кадр. Для видео или аудио используйте вместо этого видеоузлы MiniMax H3.
