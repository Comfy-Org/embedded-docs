# p-h3-image Conditioning

このノードは、p-h3-image を使用して、プロンプトをコンディショニングと 1 枚の静止画像用の空の latent に変換します。画像がない場合はテキストから画像への生成となり、画像が接続されている場合、`image_1` は編集対象の画像で、他のスロットは参照として機能します。プロンプトではこれらを `<Picture 1>`、`<Picture 2>` などで指定します。サンプラーには、MiniMax H3 sigma shift ノードでパッチを適用し、両方の shift 値を 1.0 に設定したモデルが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | プロンプト（参照画像を含む）をトークン化し、コンディショニングをエンコードするために使用される p-h3-image CLIP モデルです。 | CLIP | はい | - |
| `prompt` | 生成する内容、または `image_1` を編集する方法です。画像が接続されている場合、短い指示の先頭に `Edit <Picture 1>. ` が付加されます。`Edit <Picture` で始まる指示、またはプロンプトアップサンプラーによって生成された編集用ブリーフは、書かれているとおりにそのまま使用されます。 | STRING | はい | - |
| `width` | 出力幅（ピクセル単位）です。0 の場合、`image_1` のスケーリング後の幅を使用します。画像が接続されていない場合は 2912 を使用します（デフォルト: 0）。 | INT | はい | 0～MAX_RESOLUTION |
| `height` | 出力高さ（ピクセル単位）です。0 の場合、`image_1` のスケーリング後の高さを使用します。画像が接続されていない場合は 2912 を使用します（デフォルト: 0）。 | INT | はい | 0～MAX_RESOLUTION |
| `vae` | p-h3-image の VAE です。接続すると画像が参照 latent としても固定され、接続しない場合はテキストエンコーダーの条件付けにのみ使われます。 | VAE | いいえ | - |
| `images` | 最大 9 枚の画像（`image_1` から `image_9`）を追加できるグループです。`image_1` は編集対象の画像で、残りのスロットは参照です。 | AUTOGROW | いいえ | 0～9 枚の画像 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | p-h3-image サンプラー用のコンディショニングです。画像が接続されている場合は、パックされた参照 latent も保持します。 | CONDITIONING |
| `latent` | 1 フレームの静止画像用の空の latent です。モデルが想定する 2 つのオーディオ latent を含みます。 | LATENT |

**注:** 画像を接続して `vae` を指定しない場合も、画像はテキストエンコーダー経由でプロンプトに反映されますが、参照 latent としては固定されません。

**注:** コンディショニングは 1 フレームのみを対象とします。動画または音声については、代わりに MiniMax H3 ビデオノードを使用してください。
