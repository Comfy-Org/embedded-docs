# p-h3-image Conditioning

این گره یک پرامپت را به شرطی‌سازی و یک latent خالی برای تولید یک تصویر ثابت با p-h3-image تبدیل می‌کند. بدون تصاویر، حالت متن‌به‌تصویر است؛ وقتی تصاویر متصل باشند، `image_1` تصویری است که ویرایش می‌شود و اسلات‌های دیگر به‌عنوان مرجع عمل می‌کنند، که پرامپت با `<Picture 1>`، `<Picture 2>` و غیره به آن‌ها اشاره می‌کند. نمونه‌بردار به مدلی نیاز دارد که توسط گره MiniMax H3 sigma shift پچ شده باشد و هر دو مقدار shift آن روی 1.0 باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مربوط به p-h3-image که برای توکن‌بندی پرامپت، شامل هر تصویر مرجع، و برای کدگذاری شرطی‌سازی استفاده می‌شود. | CLIP | بله | - |
| `prompt` | اینکه چه چیزی تولید شود، یا `image_1` چگونه ویرایش شود. وقتی تصاویر متصل باشند، یک دستور کوتاه با `Edit <Picture 1>. ` در ابتدای آن قرار می‌گیرد. دستوری که از قبل با `Edit <Picture` شروع می‌شود یا دستورالعمل مختصر ویرایشی که توسط بالابرنده پرامپت تولید شده باشد، دقیقاً همان‌طور که نوشته شده استفاده می‌شود. | STRING | بله | - |
| `width` | عرض خروجی به پیکسل، گرد شده به مضربی از 32. مقدار 0 از عرض `image_1` پس از مقیاس‌بندی استفاده می‌کند، یا وقتی هیچ تصویری متصل نیست 2912 استفاده می‌شود (پیش‌فرض: 0). | INT | بله | 0 تا MAX_RESOLUTION |
| `height` | ارتفاع خروجی به پیکسل، گرد شده به مضربی از 32. مقدار 0 از ارتفاع `image_1` پس از مقیاس‌بندی استفاده می‌کند، یا وقتی هیچ تصویری متصل نیست 2912 استفاده می‌شود (پیش‌فرض: 0). | INT | بله | 0 تا MAX_RESOLUTION |
| `vae` | VAE مربوط به p-h3-image. به‌محض اتصال یک اسلات تصویر الزامی است، زیرا latentهای مرجع با آن کدگذاری می‌شوند. | VAE | خیر | - |
| `images` | گروه قابل‌گسترش تا 9 تصویر، از `image_1` تا `image_9`. `image_1` تصویری است که ویرایش می‌شود و اسلات‌های باقی‌مانده مرجع هستند. | AUTOGROW | خیر | 0 تا 9 تصویر |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی برای نمونه‌بردار p-h3-image. وقتی تصاویر متصل باشند، latentهای مرجع بسته‌بندی‌شده را نیز حمل می‌کند. | CONDITIONING |
| `latent` | latent خالی برای یک فریم ثابت، شامل دو latent صوتی که مدل انتظار دارد. | LATENT |

**توجه:** تصاویر به ورودی `vae` نیاز دارند. اجرای گره در حالی که تصویر متصل است و VAE وجود ندارد، خطا ایجاد می‌کند.

**توجه:** شرطی‌سازی تنها یک فریم را پوشش می‌دهد. برای ویدئو یا صدا، به‌جای آن از گره‌های ویدئوی MiniMax H3 استفاده کنید.
