# Выборка модели AuraFlow

Узел ModelSamplingAuraFlow применяет специализированную конфигурацию сэмплирования к диффузионным моделям, специально разработанную для архитектур моделей AuraFlow. Он изменяет поведение сэмплирования модели, применяя параметр `shift`, который регулирует распределение сэмплирования. Этот узел наследует фреймворк сэмплирования моделей SD3 и обеспечивает точный контроль над процессом сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Диффузионная модель, к которой применяется конфигурация сэмплирования AuraFlow. | MODEL | Да | - |
| `shift` | Значение сдвига для применения к распределению сэмплирования. По умолчанию: 1.73. Шаг: 0.01. | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Модифицированная модель с примененной конфигурацией сэмплирования AuraFlow. | MODEL |
