# Выборка модели AuraFlow

Узел ModelSamplingAuraFlow применяет специализированную конфигурацию сэмплирования к диффузионным моделям, специально разработанную для архитектур моделей AuraFlow. Он изменяет поведение сэмплирования модели, применяя значение сдвига, которое корректирует распределение сэмплирования. Этот узел наследуется от фреймворка сэмплирования модели SD3 и обеспечивает тонкий контроль над процессом сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется конфигурация сэмплирования AuraFlow | MODEL | Да | - |
| `сдвиг` | Значение сдвига, применяемое к распределению сэмплирования (по умолчанию: 1.73, шаг: 0.01) | FLOAT | Да | 0.0 - 100.0 |
| `sampling` | Режим сэмплирования, используемый при патчинге модели (по умолчанию: "flow"). Отмечен как расширенная опция. | COMBO | Нет | "flow"<br>"img_to_img_velocity" |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённой конфигурацией сэмплирования AuraFlow | MODEL |
