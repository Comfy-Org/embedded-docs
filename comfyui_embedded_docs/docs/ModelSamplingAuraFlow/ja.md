# モデルサンプリングオーラフロー

The ModelSamplingAuraFlow ノードは、拡散モデルに特殊なサンプリング設定を適用します。これは特に AuraFlow モデルアーキテクチャ向けに設計されています。`shift` パラメータを適用してサンプリング分布を調整し、モデルのサンプリング動作を変更します。このノードは SD3 モデルサンプリングフレームワークを継承し、サンプリングプロセスを細かく制御します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | AuraFlow サンプリング設定を適用する拡散モデル。 | MODEL | はい | - |
| `shift` | サンプリング分布に適用するシフト値。デフォルト: 1.73。ステップ: 0.01。 | FLOAT | はい | 0.0 - 100.0 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model` | AuraFlow サンプリング設定が適用された変更済みモデル。 | MODEL |
