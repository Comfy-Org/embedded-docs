# ModelSamplingAuraFlow

گره ModelSamplingAuraFlow یک پیکربندی نمونه‌برداری تخصصی را برای مدل‌های انتشار (دیفیوژن) اعمال می‌کند که به‌طور خاص برای معماری مدل AuraFlow طراحی شده است. این گره رفتار نمونه‌برداری مدل را با اعمال پارامتر `shift` که توزیع نمونه‌برداری را تنظیم می‌کند، تغییر می‌دهد. این گره از چارچوب نمونه‌برداری مدل SD3 به ارث می‌برد و کنترل دقیقی بر فرآیند نمونه‌برداری فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل دیفیوژنی که پیکربندی نمونه‌برداری AuraFlow روی آن اعمال می‌شود. | MODEL | بله | - |
| `shift` | مقدار shift برای اعمال روی توزیع نمونه‌برداری. پیش‌فرض: 1.73. گام: 0.01. | FLOAT | بله | 0.0 - 100.0 |
