# ModelSamplingAuraFlow

این گره ModelSamplingAuraFlow یک پیکربندی نمونه‌گیری تخصصی را به مدل‌های دیفیوژن اعمال می‌کند و به‌طور خاص برای معماری‌های مدل AuraFlow طراحی شده است. این گره با اعمال یک مقدار شیفت که توزیع نمونه‌گیری را تنظیم می‌کند، رفتار نمونه‌گیری مدل را تغییر می‌دهد. این گره از چارچوب نمونه‌گیری مدل SD3 ارث‌بری می‌کند و کنترل دقیقی بر فرایند نمونه‌گیری فراهم می‌آورد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل دیفیوژنی که پیکربندی نمونه‌گیری AuraFlow به آن اعمال می‌شود | MODEL | بله | - |
| `شیفت` | مقدار شیفتی که به توزیع نمونه‌گیری اعمال می‌شود (پیش‌فرض: 1.73، گام: 0.01) | FLOAT | بله | 0.0 - 100.0 |
| `sampling` | حالت نمونه‌گیری مورد استفاده هنگام وصله‌کردن مدل (پیش‌فرض: "flow"). به‌عنوان گزینه پیشرفته علامت‌گذاری شده است. | COMBO | خیر | "flow"<br>"img_to_img_velocity" |
