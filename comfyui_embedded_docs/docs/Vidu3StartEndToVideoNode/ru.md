# Vidu Q3 Генерация видео по начальному и конечному кадрам

Этот узел генерирует видео путём интерполяции между заданным начальным кадром и конечным кадром, руководствуясь текстовым запросом. Он использует модель Vidu Q3 для создания плавного перехода между двумя изображениями, создавая видео указанной длительности и разрешения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для генерации видео. Выбор опции открывает дополнительные параметры конфигурации: `resolution`, `duration` и `audio`. | DYNAMIC_COMBO | Да | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `начальный кадр` | Начальное изображение для видеопоследовательности. | IMAGE | Да | - |
| `конечный кадр` | Конечное изображение для видеопоследовательности. | IMAGE | Да | - |
| `промпт` | Описание запроса (максимум 2000 символов). | STRING | Да | - |
| `seed` | Значение seed для управления случайностью генерации (по умолчанию: 1). | INT | Да | от 0 до 2147483647 |

### Входы viduq3-pro и viduq3-turbo

Следующие параметры являются общими для обоих вариантов модели (`viduq3-pro` и `viduq3-turbo`). Они становятся доступны после выбора модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `разрешение` | Разрешение выходного видео. Этот параметр становится доступен после выбора `model`. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `длительность` | Длительность выходного видео в секундах (по умолчанию: 5). Этот параметр становится доступен после выбора `model`. | INT | Да | от 1 до 16 |
| `аудио` | Если включено, выводит видео со звуком (включая диалоги и звуковые эффекты) (по умолчанию: False). Этот параметр становится доступен после выбора `model`. | BOOLEAN | Да | `True`<br>`False` |

**Примечание:** Изображения `first_frame` и `end_frame` должны иметь схожее соотношение сторон для достижения наилучших результатов. Соотношение сторон двух изображений должно находиться в пределах от 80% до 125% друг от друга (относительная близость от 0.8 до 1.25).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
