# Vidu Q3 Генерация видео по начальному и конечному кадрам

Этот узел создаёт видео, формируя переход между начальным и конечным кадром под управлением текстового запроса. Он использует модель Vidu Q3 для интерполяции между двумя изображениями и создаёт видео с выбранной длительностью и разрешением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для генерации видео. При выборе опции отображаются дополнительные параметры конфигурации для `resolution`, `duration` и `audio`. | DYNAMIC_COMBO | Да | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `начальный кадр` | Начальное изображение видеопоследовательности. | IMAGE | Да | - |
| `конечный кадр` | Конечное изображение видеопоследовательности. | IMAGE | Да | - |
| `промпт` | Описание запроса (максимум 2000 символов). | STRING | Да | До 2000 символов |
| `seed` | Значение seed, используемое для управления случайностью генерации. Имеет опцию control-after-generate (по умолчанию: 1). | INT | Да | от 0 до 2147483647 |

### Входы viduq3-pro и viduq3-turbo

Следующие параметры являются общими для обеих опций модели (`viduq3-pro` и `viduq3-turbo`). Они появляются после выбора модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | от 1 до 16 |
| `audio` | Если включено, выводит видео со звуком (включая диалоги и звуковые эффекты) (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |

**Примечание:** Изображения `first_frame` и `end_frame` должны иметь схожие соотношения сторон. Соотношение сторон двух изображений должно оставаться в пределах от 80% до 125% друг от друга (относительная близость между 0.8 и 1.25).

**Примечание:** Для `viduq3-turbo` цена составляет 0.06 USD за секунду при 720p и 0.08 USD за секунду при 1080p. Для `viduq3-pro` цена составляет 0.15 USD за секунду при 720p и 0.16 USD за секунду при 1080p.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
