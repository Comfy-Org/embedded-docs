# Vidu Q3 起始/結束影格轉影片生成

此節點透過在提供的起始影格與結束影格之間進行插值，並以文字提示引導，來產生影片。它使用 Vidu Q3 模型在兩張影像之間建立無縫轉場，產生指定長度與解析度的影片。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片生成的模型。選取選項會顯示 `resolution`、`duration` 與 `audio` 的額外設定參數。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `起始影格` | 影片序列的起始影像。 | IMAGE | 是 | - |
| `結束影格` | 影片序列的結束影像。 | IMAGE | 是 | - |
| `提示詞` | 提示描述（最多 2000 個字元）。 | STRING | 是 | - |
| `隨機種子` | 用於控制生成隨機性的種子值（預設值：1）。 | INT | 是 | 0 至 2147483647 |

### viduq3-pro 與 viduq3-turbo 輸入

以下參數由兩個模型選項（`viduq3-pro` 與 `viduq3-turbo`）共用。選取模型後會顯示這些參數。

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 輸出影片的解析度。選取 `model` 後會顯示此參數。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `duration` | 輸出影片的持續時間（秒）（預設值：5）。選取 `model` 後會顯示此參數。 | INT | 是 | 1 至 16 |
| `audio` | 啟用時，輸出含有聲音的影片（包括對話與音效）（預設值：False）。選取 `model` 後會顯示此參數。 | BOOLEAN | 是 | `True`<br>`False` |

**注意：** `first_frame` 和 `end_frame` 影像必須具有相似的長寬比。兩張影像的長寬比必須在彼此的 80% 至 125% 之間（相對接近度介於 0.8 與 1.25）。
