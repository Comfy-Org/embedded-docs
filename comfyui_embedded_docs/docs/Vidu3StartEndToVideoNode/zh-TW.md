# Vidu Q3 起始/結束影格轉影片生成

此節點會建立起始影格與結束影格之間的轉場，並由文字提示詞引導，藉此生成影片。它使用 Vidu Q3 模型在兩張影像之間進行插值，並以選定的時長與解析度生成影片。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片生成的模型。選擇某個選項後，會顯示 `resolution`、`duration` 和 `audio` 的額外設定參數。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `起始影格` | 影片序列的起始影像。 | IMAGE | 是 | - |
| `結束影格` | 影片序列的結束影像。 | IMAGE | 是 | - |
| `提示詞` | 提示詞描述（最多 2000 個字元）。 | STRING | 是 | 最多 2000 個字元 |
| `隨機種子` | 用於控制生成隨機性的種子值。具有生成後控制選項（預設：1）。 | INT | 是 | 0 到 2147483647 |

### viduq3-pro 與 viduq3-turbo 輸入

以下參數由兩個模型選項（`viduq3-pro` 和 `viduq3-turbo`）共用。它們會在選取模型後顯示。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `duration` | 輸出影片的時長，以秒為單位（預設：5）。 | INT | 是 | 1 到 16 |
| `audio` | 啟用時，輸出包含聲音的影片（包括對話與音效）（預設：False）。 | BOOLEAN | 是 | `True`<br>`False` |

**注意：** `first_frame` 與 `end_frame` 影像必須具有相似的長寬比。兩張影像的長寬比必須保持在彼此的 80% 至 125% 之間（相對接近程度介於 0.8 與 1.25 之間）。

**注意：** 對於 `viduq3-turbo`，720p 的價格為每秒 0.06 USD，1080p 的價格為每秒 0.08 USD。對於 `viduq3-pro`，720p 的價格為每秒 0.15 USD，1080p 的價格為每秒 0.16 USD。
