# تولید ویدیو از فریم آغازین/پایانی Vidu Q3

این گره با درونیابی بین یک فریم شروع و یک فریم پایان و با هدایت یک توصیف متنی، ویدیو تولید می‌کند. از مدل Vidu Q3 برای ایجاد انتقالی روان بین دو تصویر استفاده کرده و ویدیویی با مدت‌زمان و وضوح مشخص می‌سازد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید ویدیو استفاده می‌شود. انتخاب یک گزینه، پارامترهای پیکربندی اضافی برای `resolution`، `duration` و `audio` را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `فریم آغازین` | تصویر شروع برای دنباله ویدیو. | IMAGE | بله | - |
| `فریم پایانی` | تصویر پایان برای دنباله ویدیو. | IMAGE | بله | - |
| `پرامپت` | توضیح متن (حداکثر ۲۰۰۰ کاراکتر). | STRING | بله | - |
| `بذر` | مقدار seed برای کنترل تصادفی بودن تولید (پیش‌فرض: 1). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های viduq3-pro و viduq3-turbo

پارامترهای زیر بین هر دو گزینه مدل (`viduq3-pro` و `viduq3-turbo`) مشترک هستند. این پارامترها پس از انتخاب مدل نمایش داده می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `وضوح` | وضوح ویدیوی خروجی. این پارامتر پس از انتخاب یک `model` نمایش داده می‌شود. | COMBO | بله | `"720p"`<br>`"1080p"` |
| `مدت زمان` | مدت‌زمان ویدیوی خروجی به ثانیه (پیش‌فرض: 5). این پارامتر پس از انتخاب یک `model` نمایش داده می‌شود. | INT | بله | 1 تا 16 |
| `صدا` | در صورت فعال بودن، ویدیو را همراه با صدا (شامل دیالوگ و افکت‌های صوتی) خروجی می‌دهد (پیش‌فرض: False). این پارامتر پس از انتخاب یک `model` نمایش داده می‌شود. | BOOLEAN | بله | `True`<br>`False` |

**نکته:** تصاویر `first_frame` و `end_frame` برای بهترین نتیجه باید نسبت ابعاد مشابهی داشته باشند. نسبت ابعاد دو تصویر باید بین ۸۰٪ تا ۱۲۵٪ از یکدیگر باشد (نزدیکی نسبی بین ۰٫۸ و ۱٫۲۵).
