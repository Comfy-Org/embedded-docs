# Vidu Q3 開始/終了フレームからの動画生成

このノードは、テキストプロンプトに基づいて、指定された開始フレームと終了フレームの間を補間するビデオを生成します。Vidu Q3 モデルを使用して、2つの画像間のシームレスな遷移を作成し、指定された長さと解像度のビデオを生成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ビデオ生成に使用するモデル。オプションを選択すると、`resolution`、`duration`、`audio` の追加設定パラメータが表示されます。 | COMBO | はい | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `first_frame` | ビデオシーケンスの開始画像。 | IMAGE | はい | - |
| `end_frame` | ビデオシーケンスの終了画像。 | IMAGE | はい | - |
| `prompt` | プロンプトの説明（最大2000文字）。 | STRING | はい | - |
| `seed` | 生成のランダム性を制御するシード値（デフォルト: 1）。 | INT | いいえ | 0 から 2147483647 |

### viduq3-pro と viduq3-turbo の入力

以下のパラメータは、両方のモデルオプション（`viduq3-pro` と `viduq3-turbo`）で共通です。これらは、モデルを選択した後に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model.resolution` | 出力ビデオの解像度。このパラメータは、`model` を選択した後に表示されます。 | COMBO | はい | `"720p"`<br>`"1080p"` |
| `model.duration` | 出力ビデオの長さ（秒）（デフォルト: 5）。このパラメータは、`model` を選択した後に表示されます。 | INT | はい | 1 から 16 |
| `model.audio` | 有効にすると、音声（ダイアログと効果音を含む）付きのビデオを出力します（デフォルト: False）。このパラメータは、`model` を選択した後に表示されます。 | BOOLEAN | はい | `True`<br>`False` |

**注:** 最適な結果を得るには、`first_frame` と `end_frame` の画像は類似したアスペクト比を持つ必要があります。2つの画像のアスペクト比は、互いの80%～125%以内（相対的な近さが0.8～1.25）である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成されたビデオファイル。 | VIDEO |
