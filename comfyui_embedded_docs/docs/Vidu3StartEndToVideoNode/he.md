# Vidu3StartEndToVideoNode

צומת זה יוצר סרטון על ידי יצירת מעבר בין פריים התחלה לפריים סיום, בהנחיית פרומפט טקסטואלי. הוא משתמש במודל Vidu Q3 כדי לבצע אינטרפולציה בין שתי התמונות ומפיק סרטון במשך וברזולוציה שנבחרו.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש ליצירת וידאו. בחירת אפשרות חושפת פרמטרי תצורה נוספים עבור `resolution`, `duration` ו-`audio`. | DYNAMIC_COMBO | כן | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `first_frame` | תמונת הפתיחה של רצף הווידאו. | IMAGE | כן | - |
| `end_frame` | תמונת הסיום של רצף הווידאו. | IMAGE | כן | - |
| `prompt` | תיאור הפרומפט (עד 2000 תווים). | STRING | כן | עד 2000 תווים |
| `seed` | ערך seed המשמש לשליטה באקראיות של היצירה. כולל אפשרות שליטה לאחר יצירה (ברירת מחדל: 1). | INT | כן | 0 עד 2147483647 |

### קלטים של viduq3-pro ו-viduq3-turbo

הפרמטרים הבאים משותפים לשתי אפשרויות המודל (`viduq3-pro` ו-`viduq3-turbo`). הם מופיעים לאחר בחירת מודל.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `resolution` | רזולוציה של סרטון הפלט. | COMBO | כן | `"720p"`<br>`"1080p"` |
| `duration` | משך סרטון הפלט בשניות (ברירת מחדל: 5). | INT | כן | 1 עד 16 |
| `audio` | כאשר מופעל, מפיק סרטון עם צליל (כולל דיאלוג ואפקטי קול) (ברירת מחדל: False). | BOOLEAN | כן | `True`<br>`False` |

**הערה:** לתמונות `first_frame` ו-`end_frame` חייבים להיות יחסי רוחב-גובה דומים. יחס הרוחב-גובה של שתי התמונות חייב להישאר בטווח של 80% עד 125% זו מזו (קרבה יחסית בין 0.8 ל-1.25).

**הערה:** עבור `viduq3-turbo`, המחיר הוא 0.06 USD לשנייה ב-720p ו-0.08 USD לשנייה ב-1080p. עבור `viduq3-pro`, המחיר הוא 0.15 USD לשנייה ב-720p ו-0.16 USD לשנייה ב-1080p.
