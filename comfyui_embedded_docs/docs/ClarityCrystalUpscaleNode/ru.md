# Clarity AI Crystal Upscale

Увеличьте изображение с помощью Crystal Upscaler от Clarity AI — высокоточного апскейлера, который сохраняет верность оригиналу, восстанавливая при этом лица, кожу и мелкие текстуры. Изображение отправляется в API Clarity AI, а увеличенный результат возвращается в виде изображения.

Выбор `model` открывает параметры, специфичные для этой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования. Выбор модели открывает специфичные для неё параметры: `image`, `scale_factor` и `creativity`. | DYNAMIC_COMBO | Да | `"crystal-upscaler"` |
| `image` | Изображение для увеличения. Должно содержать ровно одно изображение; пакеты изображений не поддерживаются. | IMAGE | Да | N/A |
| `scale_factor` | Коэффициент, на который умножаются ширина и высота изображения. Выход ограничен 100 мегапикселями (по умолчанию: 2.0). | FLOAT | Да | от 1.0 до 200.0 (шаг 0.1) |
| `creativity` | Более высокие значения позволяют модели восстанавливать больше деталей вместо строгого сохранения оригинала. Не влияет на изображения, у которых меньшая сторона равна 256 пикселям или меньше (по умолчанию: 0). | INT | Да | от 0 до 10 |

**Примечание:** Входное изображение должно быть не меньше 2x2 пикселей. Выход ограничен 100 мегапикселями и 65535 пикселями на сторону; при большем результате возникает ошибка, поэтому используйте изображение меньшего размера или меньшее значение `scale_factor`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Увеличенное изображение. | IMAGE |
