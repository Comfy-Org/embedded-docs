# Pixal3DConditioning

Узел Pixal3DConditioning подготавливает кондиционирование изображения для конвейера генерации 3D Trellis2. Он использует vision-модель DINOv3 для извлечения визуальных признаков из входного изображения в двух разрешениях (512 и 1024), а затем организует их в карты признаков для каждого этапа, которые могут быть опционально улучшены моделью NAF. Информация о камере выводится из горизонтального угла обзора для построения матрицы проекционного преобразования, и узел выводит пару положительного кондиционирования (признаки, полученные из изображения, плюс данные проекции) и пару отрицательного кондиционирования (обнулённые тензоры признаков) для classifier-free guidance (управления без классификатора).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision. | CLIP_VISION | Да | — |
| `изображение` | Предварительно обработанное изображение из ImageCropToMask (pad_factor=1.1 для Pixal3D). | IMAGE | Да | — |
| `camera_angle_x` | Горизонтальный FOV в градусах (отображается как `fov`). Подключите MoGeGeometryToFOV (axis='horizontal', unit='degrees') для FoV на каждое изображение (совпадает со значением по умолчанию в upstream). По умолчанию: 49.13. | FLOAT | Да | 1.0 – 170.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Выход положительного кондиционирования, содержащий карты признаков, полученные из изображения, и данные проекции для генерации Trellis2. | CONDITIONING |
| `negative` | Выход отрицательного кондиционирования с обнулёнными тензорами признаков, используемый для classifier-free guidance. | CONDITIONING |

Примечание: Значение `camera_angle_x` внутри преобразуется из градусов в радианы, и на его основе вычисляется расстояние до камеры для построения матрицы проекционного преобразования. Если предоставленная vision-модель включает компонент NAF, узел также создаёт карты признаков высокого разрешения для этапов формы и текстуры.
