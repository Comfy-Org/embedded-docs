# Pixal3DConditioning

Этот узел подготавливает кондиционирование изображения для конвейера 3D-генерации Trellis2. Он извлекает визуальные признаки из входного изображения с помощью модели компьютерного зрения DINOv3 в двух разрешениях, организует их в карты признаков для каждого этапа (при необходимости улучшенные моделью NAF) и объединяет их с данными камеры, полученными из горизонтального поля зрения. На выходе формируется пара из позитивного и негативного кондиционирования, где в негативном используются нулевые признаки для направляющего воздействия без классификатора.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision. | CLIP_VISION | Да | — |
| `image` | Предварительно обработанное изображение из ImageCropToMask (pad_factor=1.1 для Pixal3D). | IMAGE | Да | — |
| `camera_angle_x` | Горизонтальное поле зрения (FOV) в градусах (отображаемое имя: fov). Подключите MoGeGeometryToFOV (axis='horizontal', unit='degrees') для получения FOV для каждого изображения (соответствует исходному значению по умолчанию). По умолчанию: 49.13. | FLOAT | Да | 1.0 – 170.0 |

Примечание: Значение `camera_angle_x` внутренне преобразуется в радианы и используется для вычисления расстояния до камеры для матрицы проекционного преобразования. Если переданная модель компьютерного зрения содержит компонент NAF, узел дополнительно создает карты признаков высокого разрешения для этапов формирования формы и текстуры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование, содержащее карты признаков, полученные из изображения, и данные проекции для генерации Trellis2. | CONDITIONING |
| `negative` | Негативное кондиционирование с обнулёнными тензорами признаков, используемое для направляющего воздействия без классификатора. | CONDITIONING |
