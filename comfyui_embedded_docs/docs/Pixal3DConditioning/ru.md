# Pixal3DConditioning

Этот узел подготавливает кондиционирование изображения для конвейера 3D-генерации Trellis2. Он извлекает визуальные признаки из входного изображения с помощью модели зрения DINOv3 в двух разрешениях, организует их в поэтапные карты признаков (при необходимости дополненные моделью NAF) и объединяет их с данными камеры, полученными из горизонтального поля зрения. На выходе он формирует пару положительного и отрицательного кондиционирования, где отрицательное использует обнуленные признаки для управления без классификатора.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision. | CLIP_VISION | Да | — |
| `изображение` | Предобработанное изображение из ImageCropToMask (pad_factor=1.1 для Pixal3D). | IMAGE | Да | — |
| `camera_angle_x` | Горизонтальное поле зрения в градусах (отображаемое имя: fov). Подключите MoGeGeometryToFOV (axis='horizontal', unit='degrees') для получения поля зрения для каждого изображения (соответствует значению по умолчанию вышестоящего узла). По умолчанию: 49.13. | FLOAT | Да | 1.0 – 170.0 |

Примечание: значение `camera_angle_x` преобразуется в радианы внутри узла и используется для вычисления расстояния до камеры для матрицы проекционного преобразования. Если используемая модель зрения включает компонент NAF, узел дополнительно создает карты признаков высокого разрешения для этапов формы и текстуры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `положительное` | Положительное кондиционирование, содержащее карты признаков, полученные из изображения, и данные проекции для генерации Trellis2. | CONDITIONING |
| `отрицательное` | Отрицательное кондиционирование с обнуленными тензорами признаков, используемое для управления без классификатора. | CONDITIONING |
