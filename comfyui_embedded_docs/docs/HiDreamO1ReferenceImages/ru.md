# Референсные изображения HiDream-O1

## Обзор

Прикрепите референсные изображения и к положительному, и к отрицательному кондишинингу. Этот узел позволяет предоставить одно или несколько референсных изображений, которые будут использоваться для управления процессом генерации изображений — либо для редактирования на основе инструкции, либо для персонализации на основе объекта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный кондишининг, к которому прикрепляются референсные изображения. | CONDITIONING | Да | - |
| `negative` | Отрицательный кондишининг, к которому прикрепляются референсные изображения. | CONDITIONING | Да | - |
| `images` | Референсные изображения. 1 изображение = редактирование по инструкции; 2–10 изображений = мульти-референс. | IMAGE | Да | от 1 до 10 изображений |

**Примечание о параметре `images`:** Это автоматически расширяемый вход, принимающий от 1 до 10 изображений. Изображения помечаются от `image_1` до `image_10`. Необходимо предоставить как минимум 1 изображение. Количество изображений определяет режим работы: одно изображение используется для редактирования по инструкциям, а несколько изображений (2–10) — для персонализации на основе объекта.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный кондишининг с прикрепленными референсными изображениями. | CONDITIONING |
| `negative` | Отрицательный кондишининг с прикрепленными референсными изображениями. | CONDITIONING |
