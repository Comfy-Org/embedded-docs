# تصاویر مرجع HiDream-O1

## نمای کلی

تصاویر مرجع را به هر دو شرطی‌سازی مثبت و منفی متصل کنید. این گره به شما امکان می‌دهد یک یا چند تصویر مرجع ارائه دهید که برای هدایت فرآیند تولید تصویر استفاده می‌شوند، خواه برای ویرایش بر اساس یک دستورالعمل یا برای شخصی‌سازی مبتنی بر سوژه.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبتی که تصاویر مرجع به آن متصل می‌شوند. | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی که تصاویر مرجع به آن متصل می‌شوند. | CONDITIONING | بله | - |
| `images` | تصاویر مرجع. ۱ تصویر = ویرایش مبتنی بر دستورالعمل؛ ۲-۱۰ تصویر = مرجع چندگانه. | IMAGE | بله | ۱ تا ۱۰ تصویر |

**نکته درباره پارامتر `images`:** این یک ورودی خودگسترش‌شونده است که بین ۱ تا ۱۰ تصویر را می‌پذیرد. تصاویر با نام‌های `image_1` تا `image_10` برچسب‌گذاری می‌شوند. شما باید حداقل ۱ تصویر ارائه دهید. تعداد تصاویر حالت عملیات را تعیین می‌کند: یک تصویر واحد برای دستورالعمل‌های ویرایش استفاده می‌شود، در حالی که چندین تصویر (۲-۱۰) برای شخصی‌سازی مبتنی بر سوژه استفاده می‌شوند.

## خروجی‌ها
