# שנה גודל תמונה לממד מקסימלי

צומת ImageScaleToMaxDimension משנה את גודל התמונות כך שיתאימו לממד מקסימלי שצוין תוך שמירה על יחס הגובה-רוחב המקורי. הוא מחשב אם התמונה היא לאורך (פורטרט) או לרוחב (לנדסקייפ), ולאחר מכן מגדיל את הממד הגדול יותר כך שיתאים לגודל היעד תוך התאמה פרופורציונלית של הממד הקטן יותר. הצומת תומך במספר שיטות הגדלה לדרישות איכות וביצועים שונות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט שיש לשנות את גודלה | IMAGE | כן | - |
| `upscale_method` | שיטת האינטרפולציה המשמשת לשינוי גודל התמונה (ברירת מחדל: "area") | STRING | כן | "area"<br>"lanczos"<br>"bilinear"<br>"nearest-exact"<br>"bilinear"<br>"bicubic" |
| `largest_size` | הממד המקסימלי עבור התמונה לאחר שינוי הגודל (ברירת מחדל: 512) | INT | כן | 0 to 16384 |
