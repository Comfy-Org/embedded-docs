# EmptyTrellis2LatentStructure

Этот узел создает пустую латентную структуру для модели Trellis2, в которой все значения установлены в ноль. Он создает пустой 3D-тензор латентного пространства с 32 каналами и разрешением 16×16×16, размер которого соответствует указанному количеству элементов в пакете.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|------------|--------------|-------------|
| `batch_size` | Количество латентных изображений в пакете (по умолчанию: 1). | INT | Да | 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-------------|
| `LATENT` | Пустая латентная структура Trellis2. Образцы представляют собой тензор, заполненный нулями, с формой (batch_size, 32, 16, 16, 16), а тип латентного пространства установлен как «trellis2». | LATENT |
