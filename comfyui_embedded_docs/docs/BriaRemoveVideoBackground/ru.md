# Bria Удалить фон видео

Этот узел удаляет фон из видео с помощью сервиса Bria AI. Он обрабатывает входное видео и заменяет исходный фон сплошным цветом на ваш выбор. Операция выполняется через внешний API, а результат возвращается в виде нового видеофайла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Входной видеофайл, из которого будет удалён фон. | VIDEO | Да | N/A |
| `цвет фона` | Цвет фона для выходного видео. | COMBO | Да | `"Black"`<br>`"White"`<br>`"Gray"`<br>`"Red"`<br>`"Green"`<br>`"Blue"`<br>`"Yellow"`<br>`"Cyan"`<br>`"Magenta"`<br>`"Orange"` |
| `seed` | Seed управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | 0 до 2147483647 |

**Примечание:** Входное видео должно иметь длительность не более 60 секунд. Результаты недетерминированы, даже если значение seed не изменяется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Обработанный видеофайл, в котором фон удалён и заменён выбранным цветом, закодированный как MP4 с кодеком H.264. | VIDEO |
