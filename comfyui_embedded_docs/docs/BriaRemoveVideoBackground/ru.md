# Bria Удалить фон видео

Этот узел удаляет фон из видео с помощью сервиса Bria AI. Он обрабатывает входное видео и заменяет исходный фон на сплошной цвет по вашему выбору. Операция выполняется через внешний API, а результат возвращается в виде нового видеофайла.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Входной видеофайл, из которого будет удалён фон. | VIDEO | Да | Н/Д |
| `цвет фона` | Цвет фона для выходного видео. | COMBO | Да | `"Black"`<br>`"White"`<br>`"Gray"`<br>`"Red"`<br>`"Green"`<br>`"Blue"`<br>`"Yellow"`<br>`"Cyan"`<br>`"Magenta"`<br>`"Orange"` |
| `seed` | Семя управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от семени. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

**Примечание:** Длительность входного видео не должна превышать 60 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Обработанный видеофайл с удалённым фоном, заменённым выбранным цветом, закодированный в MP4 с кодеком H.264. | VIDEO |
