# Bria Удалить фон видео

Данный узел удаляет фон из видео с помощью сервиса Bria AI. Он обрабатывает входное видео и заменяет исходный фон на сплошной цвет по вашему выбору. Операция выполняется через внешний API, а результат возвращается в виде нового видеофайла.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Входной видеофайл, из которого будет удалён фон. | VIDEO | Да | Н/Д |
| `background_color` | Цвет фона для выходного видео. | COMBO | Да | `"Black"`<br>`"White"`<br>`"Gray"`<br>`"Red"`<br>`"Green"`<br>`"Blue"`<br>`"Yellow"`<br>`"Cyan"`<br>`"Magenta"`<br>`"Orange"` |
| `seed` | Управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от значения seed. (по умолчанию: 0) | INT | Да | 0 to 2147483647 |

**Примечание:** Входное видео должно иметь продолжительность не более 60 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Обработанный видеофайл с удалённым фоном, заменённым на выбранный цвет. Выходное видео кодируется в MP4 с кодеком H.264. | VIDEO |
