# حذف پس‌زمینه ویدیو Bria

این گره پس‌زمینه را از ویدیو با استفاده از سرویس Bria AI حذف می‌کند. ویدیوی ورودی را پردازش کرده و پس‌زمینه اصلی را با یک رنگ ثابت به انتخاب شما جایگزین می‌کند. این عملیات از طریق یک API خارجی انجام می‌شود و نتیجه به‌صورت یک فایل ویدیویی جدید بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | فایل ویدیوی ورودی که پس‌زمینه از آن حذف خواهد شد. | VIDEO | بله | N/A |
| `رنگ پس‌زمینه` | رنگ پس‌زمینه برای ویدیوی خروجی. | COMBO | بله | `"Black"`<br>`"White"`<br>`"Gray"`<br>`"Red"`<br>`"Green"`<br>`"Blue"`<br>`"Yellow"`<br>`"Cyan"`<br>`"Magenta"`<br>`"Orange"` |
| `seed` | seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed قطعی نیستند. (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |

**نکته:** ویدیوی ورودی باید مدت‌زمان ۶۰ ثانیه یا کمتر داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | فایل ویدیوی پردازش‌شده با پس‌زمینه حذف‌شده و جایگزین‌شده با رنگ انتخابی، کدگذاری‌شده به‌صورت MP4 با کدک H.264. | VIDEO |
