# BriaRemoveVideoBackground

צומת זה מסיר את הרקע מווידאו באמצעות שירות Bria AI. הוא מעבד את קלט הווידאו ומחליף את הרקע המקורי בצבע אחיד לבחירתך. הפעולה מתבצעת דרך API חיצוני, והתוצאה מוחזרת כקובץ וידאו חדש.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | קובץ הווידאו שממנו יוסר הרקע. | VIDEO | כן | N/A |
| `background_color` | צבע רקע לוידאו הפלט. | COMBO | כן | `"Black"`<br>`"White"`<br>`"Gray"`<br>`"Red"`<br>`"Green"`<br>`"Blue"`<br>`"Yellow"`<br>`"Cyan"`<br>`"Magenta"`<br>`"Orange"` |
| `seed` | הפרמטר `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות בערך ה-seed. (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |

**הערה:** קלט הווידאו חייב להיות באורך של 60 שניות או פחות. התוצאות אינן דטרמיניסטיות גם אם ערך ה-seed לא משתנה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | קובץ הווידאו המעובד, עם הרקע שהוסר והוחלף בצבע שנבחר, מקודד כ-MP4 עם קודק H.264. | VIDEO |
