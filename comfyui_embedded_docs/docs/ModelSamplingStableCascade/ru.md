# Выборка модели Stable Cascade

Узел ModelSamplingStableCascade применяет к модели стабильное каскадное сэмплирование, регулируя параметры сэмплирования с помощью значения сдвига. Он создает модифицированную копию входной модели с пользовательской конфигурацией стабильного каскадного сэмплирования, оставляя исходную модель без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Входная модель, к которой применяется стабильное каскадное сэмплирование | MODEL | Да | - |
| `сдвиг` | Значение сдвига, применяемое к параметрам сэмплирования (по умолчанию: 2.0) | FLOAT | Да | 0.0 - 100.0 (шаг 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным стабильным каскадным сэмплированием | MODEL |
