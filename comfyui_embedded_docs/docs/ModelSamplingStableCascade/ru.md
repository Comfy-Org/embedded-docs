# Выборка модели Stable Cascade

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Входная модель, к которой применяется сэмплирование стабильного каскада | MODEL | Да | - |
| `shift` | Значение сдвига, применяемое к параметрам сэмплирования (по умолчанию: 2.0) | FLOAT | Да | 0.0 - 100.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным сэмплированием стабильного каскада | MODEL |
