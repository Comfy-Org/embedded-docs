# モデルサンプリング安定カスケード

ModelSamplingStableCascade ノードは、シフト値を使用してサンプリングパラメータを調整することにより、モデルにステーブルカスケードサンプリングを適用します。安定したカスケード生成用のカスタムサンプリング設定を備えた、入力モデルの変更されたクローンを作成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | ステーブルカスケードサンプリングを適用する入力モデル | MODEL | はい | - |
| `shift` | サンプリングパラメータに適用するシフト値（デフォルト：2.0） | FLOAT | はい | 0.0 - 100.0 (step: 0.01) |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | ステーブルカスケードサンプリングが適用された変更済みモデル | MODEL |
