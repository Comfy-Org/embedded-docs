# CLIPAdd

הצומת CLIPAdd משלב שני מודלי CLIP על ידי מיזוג טלאי המפתח (key patches) שלהם. הוא יוצר עותק של מודל ה-CLIP הראשון ולאחר מכן מוסיף את מרבית טלאי המפתח מהמודל השני, למעט מזהי מיקום (position IDs) ופרמטרי logit scale. הדבר מאפשר לך למזג תכונות ממודלי CLIP שונים תוך שמירה על המבנה של המודל הראשון.
