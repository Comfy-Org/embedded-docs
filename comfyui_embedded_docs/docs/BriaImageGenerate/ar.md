# Bria FIBO 2.0 Image Generate

تُنشئ صورة جديدة من موجّه نصي، أو موجّه منظم بصيغة JSON، أو صورة مرجعية واحدة باستخدام Bria FIBO 2.0. ترسل العقدة الطلب إلى Bria API، وتنتظر اكتمال الإنشاء، وتعيد الصورة مع موجّه منظم يمكنه إعادة إنشاء الصورة أو تحسينها في تشغيل لاحق.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | وصف بلغة طبيعية للصورة المطلوب إنشاؤها (الافتراضي: فارغ). | STRING | نعم | نص متعدد الأسطر |
| `structured_prompt` | موجّه منظم بصيغة JSON من نتيجة Bria FIBO سابقة. مع نفس قيمة seed يعيد إنشاء تلك الصورة؛ غيّر JSON أو أضف موجّهًا لتحسينه (الافتراضي: فارغ). | STRING | نعم | نص متعدد الأسطر |
| `aspect_ratio` | نسبة أبعاد المخرجات (الافتراضي: `"1:1"`). النسب من `"16:10"` فما بعدها هي أحجام FIBO 2.0 ذات متطلبات إضافية، المذكورة أدناه. | COMBO | نعم | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"16:10"`<br>`"10:16"`<br>`"2:1"`<br>`"1:2"`<br>`"21:9"`<br>`"9:21"`<br>`"3:1"`<br>`"1:3"`<br>`"4:1"`<br>`"1:4"`<br>`"5:1"`<br>`"1:5"` |
| `resolution` | دقة المخرجات بالميغابكسل (الافتراضي: `"1MP"`). | COMBO | نعم | `"1MP"`<br>`"4MP"` |
| `seed` | قيمة seed التي تهيّئ الإنشاء (الافتراضي: 42). | INT | نعم | 1 إلى 2147483647 |
| `moderation` | إعدادات مراقبة المحتوى. يؤدي اختيار `"true"` إلى إظهار مدخلات مراقبة المحتوى المدرجة أدناه. | DYNAMIC_COMBO | نعم | `"false"`<br>`"true"` |
| `image` | صورة مرجعية اختيارية يُستند إليها في الإنشاء. النتيجة صورة جديدة بنسبة الأبعاد المحددة، وليست تعديلًا لهذه الصورة. | IMAGE | لا | - |

### مدخلات مراقبة المحتوى

عند ضبط `moderation` على `"true"`، تصبح هذه المدخلات الإضافية متاحة:

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | هل يتم تطبيق مراقبة المحتوى على النص الموجّه؛ يفشل الطلب عندما ترفضه مراقبة المحتوى (الافتراضي: false). | BOOLEAN | لا | `true`<br>`false` |
| `visual_input_moderation` | هل يتم تطبيق مراقبة المحتوى على الصورة المرجعية؛ يفشل الطلب عندما ترفضه مراقبة المحتوى (الافتراضي: false). | BOOLEAN | لا | `true`<br>`false` |
| `visual_output_moderation` | هل يتم تطبيق مراقبة المحتوى على الصورة المُنشأة؛ يفشل الطلب عندما ترفضه مراقبة المحتوى (الافتراضي: false). | BOOLEAN | لا | `true`<br>`false` |

**قيود مهمة:**

- قدّم واحدًا على الأقل من `prompt` أو `structured_prompt` أو صورة `image` مرجعية. إذا كانت الثلاثة فارغة، فسترفع العقدة خطأً.
- لا يمكن الجمع بين صورة مرجعية و`structured_prompt`: استخدم أحدهما فقط.
- تتطلب نسب FIBO 2.0 (`"16:10"`، `"10:16"`، `"2:1"`، `"1:2"`، `"21:9"`، `"9:21"`، `"3:1"`، `"1:3"`، `"4:1"`، `"1:4"`، `"5:1"`، `"1:5"`) ضبط `resolution` على `"1MP"` وواحدًا فقط من `prompt` أو `structured_prompt`.
- هذه العقدة عقدة API مدفوعة؛ تفرض ComfyUI رسومًا تقارب 0.0572 دولار أمريكي لكل عملية تشغيل.
