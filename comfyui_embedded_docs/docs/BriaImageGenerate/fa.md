# Bria FIBO 2.0 Image Generate

با استفاده از Bria FIBO 2.0، تصویری جدید از یک پرامپت متنی، یک پرامپت JSON ساختاریافته یا یک تصویر مرجع واحد تولید می‌کند. گره درخواست را به Bria API می‌فرستد، منتظر پایان تولید می‌ماند و تصویر را همراه با یک پرامپت ساختاریافته برمی‌گرداند که می‌تواند در اجرای بعدی آن را بازسازی یا اصلاح کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توصیف به زبان ساده از تصویری که باید تولید شود (پیش‌فرض: خالی). | STRING | بله | متن چندخطی |
| `structured_prompt` | پرامپت ساختاریافته JSON از یک نتیجه قبلی Bria FIBO. با همان seed، آن تصویر را بازسازی می‌کند؛ JSON را تغییر دهید یا برای اصلاح آن یک پرامپت اضافه کنید (پیش‌فرض: خالی). | STRING | بله | متن چندخطی |
| `aspect_ratio` | نسبت ابعاد خروجی (پیش‌فرض: `"1:1"`). نسبت‌های از `"16:10"` به بعد، اندازه‌های FIBO 2.0 با الزامات اضافی هستند که در ادامه فهرست شده‌اند. | COMBO | بله | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"16:10"`<br>`"10:16"`<br>`"2:1"`<br>`"1:2"`<br>`"21:9"`<br>`"9:21"`<br>`"3:1"`<br>`"1:3"`<br>`"4:1"`<br>`"1:4"`<br>`"5:1"`<br>`"1:5"` |
| `resolution` | رزولوشن خروجی بر حسب مگاپیکسل (پیش‌فرض: `"1MP"`). | COMBO | بله | `"1MP"`<br>`"4MP"` |
| `seed` | seedی که تولید را مقداردهی اولیه می‌کند (پیش‌فرض: 42). | INT | بله | 1 تا 2147483647 |
| `moderation` | تنظیمات نظارت. انتخاب `"true"` ورودی‌های نظارت فهرست‌شده در ادامه را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"false"`<br>`"true"` |
| `image` | تصویر مرجع اختیاری برای استفاده به‌عنوان مبنا. نتیجه یک تصویر جدید با نسبت ابعاد انتخاب‌شده است، نه ویرایش این تصویر. | IMAGE | خیر | - |

### ورودی‌های نظارت

وقتی `moderation` روی `"true"` تنظیم شود، این ورودی‌های اضافی در دسترس قرار می‌گیرند:

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | اینکه آیا متن پرامپت نظارت شود؛ اگر نظارت آن را رد کند، درخواست شکست می‌خورد (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `visual_input_moderation` | اینکه آیا تصویر مرجع نظارت شود؛ اگر نظارت آن را رد کند، درخواست شکست می‌خورد (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `visual_output_moderation` | اینکه آیا تصویر تولیدشده نظارت شود؛ اگر نظارت آن را رد کند، درخواست شکست می‌خورد (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |

**محدودیت‌های مهم:**

- حداقل یکی از `prompt`، `structured_prompt` یا یک `image` مرجع را ارائه دهید. اگر هر سه خالی باشند، گره خطا می‌دهد.
- یک تصویر مرجع را نمی‌توان با `structured_prompt` ترکیب کرد: از یکی یا دیگری استفاده کنید.
- نسبت‌های FIBO 2.0 (`"16:10"`، `"10:16"`، `"2:1"`، `"1:2"`، `"21:9"`، `"9:21"`، `"3:1"`، `"1:3"`، `"4:1"`، `"1:4"`، `"5:1"`، `"1:5"`) به `resolution` برابر `"1MP"` و دقیقاً یکی از `prompt` یا `structured_prompt` نیاز دارند.
- این گره یک گره API پولی است؛ هر اجرا تقریباً 0.0572 دلار آمریکا هزینه دارد.
