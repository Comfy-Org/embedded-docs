# Bria FIBO 2.0 Image Generate

Создает новое изображение из текстового промпта, структурированного JSON-промпта или одного эталонного изображения с помощью Bria FIBO 2.0. Узел отправляет запрос в API Bria, ожидает завершения генерации и возвращает изображение вместе со структурированным промптом, который позволяет воссоздать или уточнить его при последующем запуске.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание изображения для генерации на простом языке (по умолчанию: пусто). | STRING | Да | Многострочный текст |
| `structured_prompt` | Структурированный JSON-промпт из предыдущего результата Bria FIBO. С тем же seed он воссоздает это изображение; измените JSON или добавьте промпт, чтобы уточнить его (по умолчанию: пусто). | STRING | Да | Многострочный текст |
| `aspect_ratio` | Соотношение сторон выходного изображения (по умолчанию: `"1:1"`). Соотношения начиная с `"16:10"` и далее — это размеры FIBO 2.0 с дополнительными требованиями, перечисленными ниже. | COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"16:10"`<br>`"10:16"`<br>`"2:1"`<br>`"1:2"`<br>`"21:9"`<br>`"9:21"`<br>`"3:1"`<br>`"1:3"`<br>`"4:1"`<br>`"1:4"`<br>`"5:1"`<br>`"1:5"` |
| `resolution` | Разрешение выходного изображения в мегапикселях (по умолчанию: `"1MP"`). | COMBO | Да | `"1MP"`<br>`"4MP"` |
| `seed` | Seed, инициализирующий генерацию (по умолчанию: 42). | INT | Да | от 1 до 2147483647 |
| `moderation` | Настройки модерации. При выборе `"true"` отображаются входы модерации, перечисленные ниже. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |
| `image` | Необязательное эталонное изображение для опоры. Результат — новое изображение с выбранным соотношением сторон, а не редактирование этого изображения. | IMAGE | Нет | - |

### Входы модерации

Когда для `moderation` установлено значение `"true"`, становятся доступны следующие дополнительные входы:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | Следует ли модерировать текст промпта; запрос завершается ошибкой, если модерация отклоняет его (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `visual_input_moderation` | Следует ли модерировать эталонное изображение; запрос завершается ошибкой, если модерация отклоняет его (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `visual_output_moderation` | Следует ли модерировать сгенерированное изображение; запрос завершается ошибкой, если модерация отклоняет его (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |

**Важные ограничения:**

- Укажите хотя бы один из параметров: `prompt`, `structured_prompt` или эталонное `image`. Если все три пусты, узел выдает ошибку.
- Эталонное изображение нельзя комбинировать с `structured_prompt`: используйте одно или другое.
- Соотношения FIBO 2.0 (`"16:10"`, `"10:16"`, `"2:1"`, `"1:2"`, `"21:9"`, `"9:21"`, `"3:1"`, `"1:3"`, `"4:1"`, `"1:4"`, `"5:1"`, `"1:5"`) требуют `resolution` `"1MP"` и ровно одного из параметров: `prompt` или `structured_prompt`.
- Этот узел является платным API-узлом; каждый запуск стоит примерно 0,0572 USD.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, сгенерированное и возвращенное API Bria. | IMAGE |
| `structured_prompt` | Структурированное описание сгенерированного изображения для воссоздания или уточнения его с помощью этого узла. | STRING |
