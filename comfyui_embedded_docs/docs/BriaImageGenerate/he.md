# Bria FIBO 2.0 Image Generate

יוצר תמונה חדשה מתוך פרומפט טקסטואלי, פרומפט JSON מובנה או תמונת עזר בודדת באמצעות Bria FIBO 2.0. הצומת שולח את הבקשה ל-API של Bria, ממתין לסיום היצירה ומחזיר את התמונה יחד עם פרומפט מובנה שמאפשר לשחזר או לחדד אותה בהרצה מאוחרת יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור בשפה חופשית של התמונה ליצירה (ברירת מחדל: ריק). | STRING | כן | טקסט רב-שורתי |
| `structured_prompt` | פרומפט JSON מובנה מתוצאת Bria FIBO קודמת. עם אותו `seed` הוא משחזר את התמונה הזו; שינוי ה-JSON או הוספת פרומפט מחדדים אותה (ברירת מחדל: ריק). | STRING | כן | טקסט רב-שורתי |
| `aspect_ratio` | יחס הממדים של הפלט (ברירת מחדל: `"1:1"`). היחסים מ-`"16:10"` ואילך הם גדלים של FIBO 2.0 עם דרישות נוספות, המפורטות בהמשך. | COMBO | כן | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"16:10"`<br>`"10:16"`<br>`"2:1"`<br>`"1:2"`<br>`"21:9"`<br>`"9:21"`<br>`"3:1"`<br>`"1:3"`<br>`"4:1"`<br>`"1:4"`<br>`"5:1"`<br>`"1:5"` |
| `resolution` | רזולוציית הפלט במגה-פיקסלים (ברירת מחדל: `"1MP"`). | COMBO | כן | `"1MP"`<br>`"4MP"` |
| `seed` | ערך seed שמאתחל את היצירה (ברירת מחדל: 42). | INT | כן | 1 עד 2147483647 |
| `moderation` | הגדרות מודרציה. בחירת `"true"` חושפת את קלטי המודרציה המפורטים בהמשך. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |
| `image` | תמונת עזר אופציונלית שעליה להתבסס. התוצאה היא תמונה חדשה ביחס הממדים שנבחר, ולא עריכה של תמונה זו. | IMAGE | לא | - |

### קלטי מודרציה

כאשר `moderation` מוגדר ל-`"true"`, קלטים נוספים אלה הופכים לזמינים:

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | האם לבצע מודרציה על טקסט הפרומפט; הבקשה נכשלת כאשר המודרציה דוחה אותו (ברירת מחדל: false). | BOOLEAN | לא | `true`<br>`false` |
| `visual_input_moderation` | האם לבצע מודרציה על תמונת העזר; הבקשה נכשלת כאשר המודרציה דוחה אותה (ברירת מחדל: false). | BOOLEAN | לא | `true`<br>`false` |
| `visual_output_moderation` | האם לבצע מודרציה על התמונה שנוצרה; הבקשה נכשלת כאשר המודרציה דוחה אותה (ברירת מחדל: false). | BOOLEAN | לא | `true`<br>`false` |

**אילוצים חשובים:**

- יש לספק לפחות אחד מ-`prompt`, `structured_prompt` או תמונת עזר `image`. אם כל השלושה ריקים, הצומת מעלה שגיאה.
- לא ניתן לשלב תמונת עזר עם `structured_prompt`: יש להשתמש באחד מהם בלבד.
- יחסי FIBO 2.0 (`"16:10"`, `"10:16"`, `"2:1"`, `"1:2"`, `"21:9"`, `"9:21"`, `"3:1"`, `"1:3"`, `"4:1"`, `"1:4"`, `"5:1"`, `"1:5"`) דורשים `resolution` `"1MP"` ובדיוק אחד מבין `prompt` או `structured_prompt`.
- צומת זה הוא צומת API בתשלום; ComfyUI גובה כ-0.0572 USD עבור כל הרצה.
