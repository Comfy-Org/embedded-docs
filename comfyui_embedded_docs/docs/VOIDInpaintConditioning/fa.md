# VOIDInpaintConditioning

گره VOIDInpaintConditioning داده‌های شرطی‌سازی لازم برای درون‌پردازی با مدل‌های CogVideoX را آماده می‌کند. این گره یک ویدیوی منبع و یک چهارماسک از‌پیش‌پردازش‌شده را دریافت کرده، آن‌ها را از طریق VAE رمزگذاری می‌کند و در یک سیگنال شرطی‌سازی ۳۲ کاناله (۱۶ کانال ماسک + ۱۶ کانال ویدیوی ماسک‌شده) ترکیب می‌کند که مدل از آن برای پر کردن نواحی ماسک‌شده استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبت که باید با اطلاعات نهانِ درون‌پردازی تقویت شود | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی که باید با اطلاعات نهانِ درون‌پردازی تقویت شود | CONDITIONING | بله | - |
| `vae` | مدل VAE که برای رمزگذاری ماسک و ویدیوی ماسک‌شده به فضای نهان استفاده می‌شود | VAE | بله | - |
| `video` | فریم‌های ویدیوی منبع [T, H, W, 3] | IMAGE | بله | - |
| `quadmask` | چهارماسک پیش‌پردازش‌شده از گره VOIDQuadmaskPreprocess [T, H, W] | MASK | بله | - |
| `width` | عرضی که ویدیو و ماسک به آن تغییر اندازه می‌دهند (پیش‌فرض: 672) | INT | بله | 16 تا MAX_RESOLUTION (گام: 8) |
| `height` | ارتفاعی که ویدیو و ماسک به آن تغییر اندازه می‌دهند (پیش‌فرض: 384) | INT | بله | 16 تا MAX_RESOLUTION (گام: 8) |
| `length` | تعداد فریم‌های پیکسلی برای پردازش. برای CogVideoX-Fun-V1.5 (patch_size_t=2)، latent_t باید زوج باشد — طول‌هایی که latent_t فرد تولید می‌کنند به پایین گرد می‌شوند (مثلاً 49 → 45) (پیش‌فرض: 45) | INT | بله | 1 تا MAX_RESOLUTION (گام: 1) |
| `batch_size` | اندازه دسته برای نویز نهان خروجی (پیش‌فرض: 1) | INT | بله | 1 تا 64 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت با اطلاعات نهان درون‌پردازی افزوده‌شده | CONDITIONING |
| `negative` | شرطی‌سازی منفی با اطلاعات نهان درون‌پردازی افزوده‌شده | CONDITIONING |
| `latent` | تانسور نویز نهان پر از صفر با شکل [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
