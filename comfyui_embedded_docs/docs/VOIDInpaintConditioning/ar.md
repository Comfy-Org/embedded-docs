# VOIDInpaintConditioning

تُجهّز عقدة VOIDInpaintConditioning بيانات التكييف اللازمة لإجراء الترميم الداخلي (inpainting) باستخدام نماذج CogVideoX. تأخذ فيديو مصدرًا وقناعًا رباعيًا (quadmask) مُعالجًا مسبقًا، وتُرمّزهما عبر VAE، ثم تدمجهما في إشارة تكييف من 32 قناة (16 قناة من القناع + 16 قناة من الفيديو المقنّع) يستخدمها النموذج لملء المناطق المقنّعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التكييف الإيجابي الذي سيُعزَّز بمعلومات الكامن الخاصة بالترميم الداخلي | CONDITIONING | نعم | - |
| `negative` | التكييف السلبي الذي سيُعزَّز بمعلومات الكامن الخاصة بالترميم الداخلي | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير القناع والفيديو المقنّع إلى الفضاء الكامن | VAE | نعم | - |
| `video` | إطارات فيديو المصدر [T, H, W, 3] | IMAGE | نعم | - |
| `quadmask` | قناع رباعي مُعالج مسبقًا من VOIDQuadmaskPreprocess [T, H, W] | MASK | نعم | - |
| `width` | العرض المطلوب تغيير حجم الفيديو والقناع إليه (الافتراضي: 672) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `height` | الارتفاع المطلوب تغيير حجم الفيديو والقناع إليه (الافتراضي: 384) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `length` | عدد إطارات البكسل المطلوب معالجتها. بالنسبة إلى CogVideoX-Fun-V1.5 (patch_size_t=2)، يجب أن يكون latent_t زوجيًا — الأطوال التي تنتج latent_t فرديًا تُقرَّب لأسفل (مثال: 49 → 45) (الافتراضي: 45) | INT | نعم | 1 إلى MAX_RESOLUTION (الخطوة: 1) |
| `batch_size` | حجم الدفعة للمتجه الكامن للضجيج الناتج (الافتراضي: 1) | INT | نعم | 1 إلى 64 |

**ملاحظة:** لأن CogVideoX-Fun-V1.5 يستخدم `patch_size_t=2`، يجب أن يكون للكامن المُرمَّز بُعد زمني زوجي. إذا كان `length` سينتج `latent_t` فرديًا، فستقوم العقدة تلقائيًا بتقريبه لأسفل إلى أقرب قيمة صالحة وتسجّل تحذيرًا. يؤدي استخدام `latent_t` فردي إلى إفساد الإطار الأخير عبر الحشو الدائري، مما قد يسبب اهتزازًا مرئيًا أو اختفاءً للكائنات قرب نهاية الفيديو المفكوك.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي مع إضافة المعلومات الكامنة الخاصة بالترميم الداخلي | CONDITIONING |
| `negative` | التكييف السلبي مع إضافة المعلومات الكامنة الخاصة بالترميم الداخلي | CONDITIONING |
| `latent` | موتر كامن للضجيج مملوء بالأصفار بالشكل [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
