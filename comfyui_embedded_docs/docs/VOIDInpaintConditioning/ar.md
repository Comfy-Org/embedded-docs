# VOIDInpaintConditioning

عقدة VOIDInpaintConditioning تُحضّر بيانات التكييف اللازمة لملء المناطق المحذوفة (inpainting) في نماذج CogVideoX. تأخذ هذه العقدة فيديو مصدرًا وقناعًا رباعيًا معالجًا مسبقًا، وتشفّرهما عبر VAE، ثم تدمجهما في إشارة تكييف من 32 قناة (16 قناة من القناع + 16 قناة من الفيديو المُقنّع) يستخدمها النموذج لملء المناطق المقنّعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التكييف الإيجابي الذي سيتم تعزيزه بمعلومات الكامن الخاصة بالملء | CONDITIONING | نعم | - |
| `negative` | التكييف السلبي الذي سيتم تعزيزه بمعلومات الكامن الخاصة بالملء | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير القناع والفيديو المُقنّع إلى الفضاء الكامن | VAE | نعم | - |
| `video` | إطارات الفيديو المصدرية [T, H, W, 3] | IMAGE | نعم | - |
| `quadmask` | القناع الرباعي المعالج مسبقًا من عقدة VOIDQuadmaskPreprocess [T, H, W] | MASK | نعم | - |
| `width` | العرض الذي سيتم تغيير حجم الفيديو والقناع إليه (الافتراضي: 672) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `height` | الارتفاع الذي سيتم تغيير حجم الفيديو والقناع إليه (الافتراضي: 384) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `length` | عدد إطارات البكسل المطلوب معالجتها. بالنسبة لـ CogVideoX-Fun-V1.5 (patch_size_t=2)، يجب أن يكون latent_t زوجيًا — ويتم تقريب الأطوال التي تُنتج latent_t فرديًا إلى الأسفل (مثل 49 ← 45) (الافتراضي: 45) | INT | نعم | 1 إلى MAX_RESOLUTION (الخطوة: 1) |
| `batch_size` | حجم الدفعة لموتر الضوضاء الكامن الناتج (الافتراضي: 1) | INT | نعم | 1 إلى 64 |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي مع إضافة معلومات الكامن الخاصة بالملء | CONDITIONING |
| `negative` | التكييف السلبي مع إضافة معلومات الكامن الخاصة بالملء | CONDITIONING |
| `latent` | موتر كامن ضوضائي مملوء بالأصفار بشكل [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
