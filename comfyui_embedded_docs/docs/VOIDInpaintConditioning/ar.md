# VOIDInpaintConditioning

عقدة VOIDInpaintConditioning تُعدّ بيانات التوجيه اللازمة للاستكمال (inpainting) باستخدام نماذج CogVideoX. فهي تأخذ فيديو مصدرًا وقناعًا رباعيًا مُعالَجًا مسبقًا، وتشفّرهما عبر VAE، ثم تجمعهما في إشارة توجيه من 32 قناة (16 قناة للقناع + 16 قناة للفيديو المقنّع) يستخدمها النموذج لملء المناطق المقنّعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التوجيه الإيجابي الذي سيتم تعزيزه بمعلومات الكمون الخاصة بالاستكمال | CONDITIONING | نعم | - |
| `negative` | التوجيه السلبي الذي سيتم تعزيزه بمعلومات الكمون الخاصة بالاستكمال | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير القناع والفيديو المقنّع إلى الفضاء الكامن | VAE | نعم | - |
| `video` | إطارات الفيديو المصدر [T, H, W, 3] | IMAGE | نعم | - |
| `quadmask` | قناع رباعي مُعالَج مسبقًا من VOIDQuadmaskPreprocess [T, H, W] | MASK | نعم | - |
| `width` | العرض الذي سيتم تغيير حجم الفيديو والقناع إليه (الافتراضي: 672) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `height` | الارتفاع الذي سيتم تغيير حجم الفيديو والقناع إليه (الافتراضي: 384) | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 8) |
| `length` | عدد إطارات البكسل المطلوب معالجتها. بالنسبة إلى CogVideoX-Fun-V1.5 (patch_size_t=2)، يجب أن يكون latent_t زوجيًا — الأطوال التي ينتج عنها latent_t فردي يتم تقريبها للأسفل (مثال: 49 ← 45) (الافتراضي: 45) | INT | نعم | 1 إلى MAX_RESOLUTION (الخطوة: 1) |
| `batch_size` | حجم الدفعة للكمون الضوضائي الناتج (الافتراضي: 1) | INT | نعم | 1 إلى 64 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التوجيه الإيجابي مع إضافة معلومات الكمون الخاصة بالاستكمال | CONDITIONING |
| `negative` | التوجيه السلبي مع إضافة معلومات الكمون الخاصة بالاستكمال | CONDITIONING |
| `latent` | موتر كمون ضوضائي معبأ بالأصفار بالشكل [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
