# VOIDInpaintConditioning

Узел VOIDInpaintConditioning подготавливает данные conditioning, необходимые для инпейнтинга с моделями CogVideoX. Он принимает исходное видео и предобработанную quadmask, кодирует их через VAE и объединяет в 32-канальный conditioning-сигнал (16 каналов от маски + 16 каналов от маскированного видео), который модель использует для заполнения областей, закрытых маской.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный conditioning, который будет дополнен информацией о латентном представлении инпейнтинга | CONDITIONING | Да | - |
| `negative` | Отрицательный conditioning, который будет дополнен информацией о латентном представлении инпейнтинга | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования маски и маскированного видео в латентное пространство | VAE | Да | - |
| `video` | Кадры исходного видео [T, H, W, 3] | IMAGE | Да | - |
| `quadmask` | Предобработанная quadmask из VOIDQuadmaskPreprocess [T, H, W] | MASK | Да | - |
| `width` | Ширина, до которой изменяются размеры видео и маски (по умолчанию: 672) | INT | Да | 16 to MAX_RESOLUTION (step: 8) |
| `height` | Высота, до которой изменяются размеры видео и маски (по умолчанию: 384) | INT | Да | 16 to MAX_RESOLUTION (step: 8) |
| `length` | Количество пиксельных кадров для обработки. Для CogVideoX-Fun-V1.5 (patch_size_t=2) latent_t должен быть четным — значения длины, дающие нечетное latent_t, округляются вниз (например, 49 → 45) (по умолчанию: 45) | INT | Да | 1 to MAX_RESOLUTION (step: 1) |
| `batch_size` | Размер пакета для выходного шумового латентного представления (по умолчанию: 1) | INT | Да | 1 до 64 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный conditioning с добавленной информацией о латентном представлении инпейнтинга | CONDITIONING |
| `negative` | Отрицательный conditioning с добавленной информацией о латентном представлении инпейнтинга | CONDITIONING |
| `latent` | Тензор шумового латентного представления, заполненный нулями, с формой [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
