# VOIDInpaintConditioning

Узел VOIDInpaintConditioning подготавливает данные кондиционирования, необходимые для inpainting с моделями CogVideoX. Он принимает исходное видео и предварительно обработанную quadmask, кодирует их через VAE и объединяет в 32-канальный сигнал кондиционирования (16 каналов из маски + 16 каналов из маскированного видео), который модель использует для заполнения замаскированных областей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование, которое нужно дополнить латентной информацией inpainting | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование, которое нужно дополнить латентной информацией inpainting | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования маски и маскированного видео в латентное пространство | VAE | Да | - |
| `video` | Кадры исходного видео [T, H, W, 3] | IMAGE | Да | - |
| `quadmask` | Предварительно обработанная quadmask из VOIDQuadmaskPreprocess [T, H, W] | MASK | Да | - |
| `width` | Ширина, до которой нужно изменить размер видео и маски (по умолчанию: 672) | INT | Да | 16 to MAX_RESOLUTION (шаг: 8) |
| `height` | Высота, до которой нужно изменить размер видео и маски (по умолчанию: 384) | INT | Да | 16 to MAX_RESOLUTION (шаг: 8) |
| `length` | Количество пиксельных кадров для обработки. Для CogVideoX-Fun-V1.5 (patch_size_t=2) `latent_t` должен быть чётным — значения длины, дающие нечётный `latent_t`, округляются вниз (например, 49 → 45) (по умолчанию: 45) | INT | Да | 1 to MAX_RESOLUTION (шаг: 1) |
| `batch_size` | Размер батча для выходного латента шума (по умолчанию: 1) | INT | Да | 1 до 64 |

**Примечание:** Поскольку CogVideoX-Fun-V1.5 использует `patch_size_t=2`, закодированный латент должен иметь чётную временную размерность. Если `length` даёт нечётный `latent_t`, узел автоматически округляет его вниз до ближайшего допустимого значения и записывает предупреждение в лог. Использование нечётного `latent_t` повреждает последний кадр из-за циклического паддинга, что может вызвать видимое дрожание или исчезновение объектов ближе к концу декодированного видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование с добавленной латентной информацией inpainting | CONDITIONING |
| `negative` | Негативное кондиционирование с добавленной латентной информацией inpainting | CONDITIONING |
| `latent` | Латентный тензор шума, заполненный нулями, формы [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
