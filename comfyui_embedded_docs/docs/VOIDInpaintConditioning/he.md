# VOIDInpaintConditioning

צומת VOIDInpaintConditioning מכין את נתוני ההתניה הדרושים לאינפיינטינג עם מודלי CogVideoX. הוא מקבל וידאו מקור ו-quadmask שעברה עיבוד מקדים, מקודד אותם דרך ה-VAE ומשלב אותם לאות התניה בן 32 ערוצים (16 ערוצים מהמסכה + 16 ערוצים מהווידאו הממוסך) שבו המודל משתמש כדי למלא את האזורים הממוסכים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | ההתניה החיובית שאליה יתווסף מידע לטנטי של אינפיינטינג | CONDITIONING | כן | - |
| `negative` | ההתניה השלילית שאליה יתווסף מידע לטנטי של אינפיינטינג | CONDITIONING | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד המסכה והווידאו הממוסך למרחב הלטנטי | VAE | כן | - |
| `video` | פריימים של וידאו מקור [T, H, W, 3] | IMAGE | כן | - |
| `quadmask` | quadmask שעברה עיבוד מקדים מ-VOIDQuadmaskPreprocess [T, H, W] | MASK | כן | - |
| `width` | הרוחב שאליו יש לשנות את גודל הווידאו והמסכה (ברירת מחדל: 672) | INT | כן | 16 עד MAX_RESOLUTION (צעד: 8) |
| `height` | הגובה שאליו יש לשנות את גודל הווידאו והמסכה (ברירת מחדל: 384) | INT | כן | 16 עד MAX_RESOLUTION (צעד: 8) |
| `length` | מספר פריימי פיקסל לעיבוד. עבור CogVideoX-Fun-V1.5 (patch_size_t=2), latent_t חייב להיות זוגי — אורכים שמפיקים latent_t אי-זוגי מעוגלים כלפי מטה (למשל 49 → 45) (ברירת מחדל: 45) | INT | כן | 1 עד MAX_RESOLUTION (צעד: 1) |
| `batch_size` | גודל האצווה עבור latent הרעש בפלט (ברירת מחדל: 1) | INT | כן | 1 עד 64 |

**הערה:** מכיוון ש-CogVideoX-Fun-V1.5 משתמש ב-`patch_size_t=2`, ל-latent המקודד חייב להיות ממד זמני זוגי. אם `length` יפיק `latent_t` אי-זוגי, הצומת מעגל אותו אוטומטית כלפי מטה לערך החוקי הקרוב ורושם אזהרה. שימוש ב-`latent_t` אי-זוגי מקלקל את הפריים האחרון באמצעות ריפוד מעגלי, מה שעלול לגרום לריצוד נראה לעין או להיעלמות של סובייקטים בסמוך לסוף הווידאו המפוענח.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | ההתניה החיובית עם מידע לטנטי של אינפיינטינג שהוסף | CONDITIONING |
| `negative` | ההתניה השלילית עם מידע לטנטי של אינפיינטינג שהוסף | CONDITIONING |
| `latent` | טנזור latent של רעש מלא באפסים עם צורה [batch_size, 16, latent_t, latent_h, latent_w] | LATENT |
