# Topaz Video Enhance

**Узел Topaz Video Enhance V2** вдохнул новую жизнь в видео благодаря мощной технологии масштабирования и восстановления. Он позволяет увеличивать разрешение видео с помощью различных моделей увеличения Topaz, изменять частоту кадров за счет интерполяции кадров, а также применять творческие или реалистичные настройки улучшения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `видео` | Входное видео для обработки. Должно быть в формате контейнера MP4. | VIDEO | Да | - |
| `upscaler_model` | Модель ИИ, используемая для увеличения разрешения видео. Доступные подпараметры зависят от выбранной модели. Выбор `"Disabled"` отключает масштабирование. | DYNAMIC_COMBO | Да | `"Astra 2"`<br>`"Starlight (Astra) Fast"`<br>`"Starlight (Astra) Creative"`<br>`"Starlight Precise 2.5"`<br>`"Disabled"` |
| `interpolation_model` | Модель ИИ, используемая для интерполяции кадров. Доступные подпараметры зависят от выбранной модели. Выбор `"Disabled"` отключает интерполяцию. | DYNAMIC_COMBO | Да | `"Disabled"`<br>`"apo-8"` |
| `уровень динамического сжатия` | Уровень CQP, используемый для сжатия видео (по умолчанию: `"Low"`). | COMBO | Нет | `"Low"`<br>`"Mid"`<br>`"High"` |

В следующих разделах описаны подпараметры, которые появляются для каждой опции селекторов `upscaler_model` и `interpolation_model`. Опции `"Disabled"` не показывают дополнительных параметров.

### Входы Astra 2

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `upscaler_model.upscaler_resolution` | Целевое выходное разрешение увеличения. | COMBO | Да (при выборе "Astra 2") | `"FullHD (1080p)"`<br>`"4K (2160p)"` |
| `upscaler_model.creativity` | Творческая сила увеличения (по умолчанию: 0.5). | FLOAT | Нет | 0.0 до 1.0 (step 0.1) |
| `upscaler_model.prompt` | Необязательный описательный (не инструктивный) промпт сцены. При задании промпта вход ограничивается 450 кадрами (~15 секунд при 30 кадрах/с) (по умолчанию: пусто). | STRING | Нет | - |
| `upscaler_model.sharp` | Предварительная резкость: 0.0=размытие по Гауссу, 0.5=без изменений (по умолчанию), 1.0=резкость USM. | FLOAT | Нет | 0.0 до 1.0 (step 0.01) |
| `upscaler_model.realism` | Приближает выходной результат к фотографическому реализму. Оставьте 0, чтобы использовать значение модели по умолчанию (по умолчанию: 0.0). | FLOAT | Нет | 0.0 до 1.0 (step 0.01) |

**Важные ограничения:**

- По крайней мере один из параметров `upscaler_model` или `interpolation_model` должен быть включен. Если оба установлены в `"Disabled"`, узел выдает ошибку, поскольку обрабатывать нечего.
- Входное видео `video` должно быть в формате контейнера MP4.
- Модель `"Astra 2"` ограничена 9000 входных кадров. Когда задан `prompt`, лимит составляет 450 входных кадров (~15 секунд при 30 кадрах/с). Узел выдает ошибку, если видео превышает действующий лимит.
- Параметр `upscaler_model.upscaler_resolution` обязателен при выборе любой модели масштабирования, кроме `"Disabled"`. Значение `"FullHD (1080p)"` нацелено на результат 1080p, а `"4K (2160p)"` — на результат 2160p; точная ширина и высота вычисляются из соотношения сторон входного видео, ограничиваются максимальной длинной стороной 1920 или 3840 пикселей соответственно и округляются до четного числа.
- Параметр `interpolation_model.interpolation_frame_rate` обязателен при выборе `interpolation_model` = `"apo-8"`.
- Очень большие файлы в настоящее время не поддерживаются; загрузка ограничена одним файлом, в противном случае узел выдает ошибку.
- Некоторые параметры (`sharp`, `realism`, `interpolation_slowmo`, `interpolation_duplicate`, `interpolation_duplicate_threshold`) помечены в интерфейсе как расширенные и по умолчанию могут быть скрыты.
