# InvertBooleanNode

Этот узел принимает одно булево значение (true/false) на входе и выводит противоположное значение. Он выполняет логическую операцию NOT, превращая `true` в `false` и `false` в `true`.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `boolean` | Входное булево значение для инвертирования. | BOOLEAN | Да | `true`<br>`false` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Инвертированное булево значение. | BOOLEAN |
