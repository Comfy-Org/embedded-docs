# InvertBooleanNode

Ce nœud prend une seule entrée booléenne (`true`/`false`) et renvoie la valeur opposée. Il effectue une opération NON logique, transformant `true` en `false` et `false` en `true`.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
|-----------|-------------|-----------------|--------|-------|
| `boolean` | La valeur booléenne d’entrée à inverser. | BOOLEAN | Oui | `true`<br>`false` |

## Sorties

| Nom de sortie | Description | Type de données |
|---------------|-------------|-----------------|
| `output` | La valeur booléenne inversée. | BOOLEAN |
