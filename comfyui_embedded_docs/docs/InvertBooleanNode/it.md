# InvertBooleanNode

Questo nodo accetta un singolo input booleano (true/false) e restituisce il valore opposto. Esegue un'operazione logica NOT, trasformando `true` in `false` e `false` in `true`.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
|-----------|-------------|--------------|--------------|------------|
| `boolean` | Il valore booleano di input da invertire. | BOOLEAN | Sì | `true`<br>`false` |

## Output

| Nome output | Descrizione | Tipo di dati |
|-------------|-------------|--------------|
| `output` | Il valore booleano invertito. | BOOLEAN |
