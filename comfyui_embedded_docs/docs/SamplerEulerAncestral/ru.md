# Сэмплер Эйлера (Анастр.)

Узел `SamplerEulerAncestral` создаёт семплер Euler Ancestral для генерации изображений. Этот семплер использует особый математический подход, сочетающий интегрирование по Эйлеру с методами предкового сэмплирования для создания вариаций изображений. Узел позволяет настраивать поведение сэмплирования, регулируя параметры, которые управляют случайностью и размером шага в процессе генерации.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет размером шага и стохастичностью процесса сэмплирования (по умолчанию: 1.0). Это расширенный параметр. | FLOAT | Нет | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0). Это расширенный параметр. | FLOAT | Нет | 0.0 - 100.0 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный семплер Euler Ancestral, который можно использовать в конвейере сэмплирования. | SAMPLER |
