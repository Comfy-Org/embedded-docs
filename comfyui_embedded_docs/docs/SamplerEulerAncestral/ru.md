# Сэмплер Эйлера (Анастр.)

Узел SamplerEulerAncestral создаёт сэмплер Euler Ancestral, который можно использовать во время генерации изображения. Этот сэмплер сочетает интегрирование Эйлера с ancestral-сэмплированием, что добавляет определённую степень случайности на каждом шаге для получения разнообразных результатов. Узел позволяет регулировать величину применяемой случайности с помощью своих настроек.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет размером шага и стохастичностью процесса сэмплирования (по умолчанию: 1.0). Это расширенный параметр. | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0). Это расширенный параметр. | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный сэмплер Euler Ancestral, который можно использовать в конвейере сэмплирования. | SAMPLER |
