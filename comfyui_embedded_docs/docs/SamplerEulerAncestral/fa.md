# SamplerEulerAncestral

گره SamplerEulerAncestral یک نمونه‌بردار (سمپلر) ایولر اجدادی برای تولید تصاویر ایجاد می‌کند. این نمونه‌بردار از یک رویکرد ریاضی خاص استفاده می‌کند که انتگرال‌گیری ایولر را با تکنیک‌های نمونه‌برداری اجدادی برای تولید تغییرات تصویری ترکیب می‌کند. این گره به شما امکان می‌دهد رفتار نمونه‌برداری را با تنظیم پارامترهایی که تصادفی بودن و اندازه گام را در طول فرآیند تولید کنترل می‌کنند، پیکربندی کنید.

## ورودی‌ها
