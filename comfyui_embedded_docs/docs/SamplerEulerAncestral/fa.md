# SamplerEulerAncestral

گره SamplerEulerAncestral یک نمونه‌بردار Euler Ancestral ایجاد می‌کند که می‌تواند در طول تولید تصویر استفاده شود. این نمونه‌بردار انتگرال‌گیری اویلر را با نمونه‌گیری Ancestral ترکیب می‌کند، که در هر گام درجه‌ای از تصادفی‌بودن اضافه می‌کند تا نتایج متنوعی تولید شود. این گره به شما امکان می‌دهد میزان تصادفی‌بودن اعمال‌شده را از طریق تنظیمات آن تغییر دهید.
