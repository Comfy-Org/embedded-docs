# VEED Remove Video Background

Вырежьте объект из видео с помощью VEED и получите кадры вместе с альфа-маской. Используйте два выхода для композитинга или передайте их через Join Image with Alpha и Save WEBM, чтобы записать видео с прозрачностью. Выберите `"standard"` для лучших краёв на любом фоне, `"fast"`, когда важна скорость, или `"green screen"` для материала, снятого на зелёном фоне.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель сегментации: `"standard"` — для любого фона с наилучшими краями и выводом до 3840x2160, `"fast"` — для более быстрого результата до 1920x1080, или `"green screen"` — для удаления зелёного фона до 3840x2160. Видео большего размера уменьшаются. При выборе варианта отображаются его параметры. | DYNAMIC_COMBO | Да | `"standard"`<br>`"fast"`<br>`"green screen"` |
| `video` | Видео, из которого нужно вырезать объект. До 60 секунд. | VIDEO | Да | До 60 секунд |
| `refine_foreground_edges` | Более чистые края на волосах, шерсти и мелких деталях. При отключении снижается стоимость. Доступно для `"standard"` и `"fast"` (по умолчанию: True). | BOOLEAN | Да | false<br>true |
| `subject_is_person` | Отключите, если объект съёмки — предмет или животное. Доступно для `"standard"` и `"fast"` (по умолчанию: True). | BOOLEAN | Да | false<br>true |
| `spill_suppression_strength` | Насколько сильно удаляется зелёный оттенок с объекта. Увеличьте, если остаются зелёные пятна; уменьшите, если цвета объекта смещаются. Доступно для `"green screen"` (по умолчанию: 0.8). | FLOAT | Да | от 0.0 до 1.0 (шаг 0.01) |

Клип ограничен 60 секундами; более длинные видео отклоняются с ошибкой. Маска равна 1 там, где фон был удалён, поэтому используйте Invert Mask перед Image Composite Masked, если хотите вместо этого сохранить объект.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Кадры видео с удалённым фоном. | IMAGE |
| `mask` | 1 там, где фон был удалён, для каждого кадра. | MASK |
