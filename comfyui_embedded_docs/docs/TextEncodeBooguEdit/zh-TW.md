# TextEncodeBooguEdit

此節點為使用 Boogu 進行影像編輯準備條件化輸入。它處理參考影像以產生正向和負向條件化輸出。參考影像被使用兩次：來自影像的視覺標記僅添加到正向條件化中以增強編輯指令，而 VAE 參考潛在空間則同時添加到正向和負向條件化中，使其在 CFG 下相互抵消，從而保留原始影像的識別特徵；分詞器會根據是否存在影像和空負向提示詞自動選擇合適的系統提示詞。

## ## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用於文字編碼的 CLIP 模型 | CLIP | 是 | |
| `prompt` | 描述所需編輯的文字提示。支援多行文字和動態提示詞。 | STRING | 是 | |
| `negative_prompt` | 描述編輯中應避免內容的文字提示。可留空以放棄負向條件化。進階參數。 | STRING | 是 | |
| `vae` | 用於將參考影像編碼為潛在空間的 VAE 模型。需要用於向條件化輸出添加參考潛在空間。 | VAE | 否 | |
| `images` | 要編輯的參考影像。Boogu 專注於每個樣本一個參考；允許更多。 | IMAGE | 否 | 最多 16 張影像 |
僅當 `vae` 與至少一張參考 `image` 一起提供時，參考潛在空間才會添加到兩個條件化輸出中。如果省略 `vae`，正向輸出仍會收到參考影像的視覺標記，但兩個輸出都不包含參考潛在空間。

## ## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `positive` | 包含文字提示（含視覺標記）和參考潛在空間的條件化 | CONDITIONING |
| `negative` | 包含負向文字提示和參考潛在空間的條件化 | CONDITIONING |
