# TextEncodeBooguEdit

Этот узел подготавливает conditioning для редактирования изображений с помощью Boogu. Он обрабатывает референсные изображения для создания как положительного, так и отрицательного conditioning на выходе. Референсное изображение используется дважды: визуальные токены из изображения добавляются только в положительный conditioning для усиления инструкции редактирования, в то время как VAE-референсный латент добавляется и в положительный, и в отрицательный conditioning, чтобы он взаимно сокращался при CFG, сохраняя идентичность исходного изображения; токенизатор автоматически выбирает подходящий системный промпт на основе наличия изображений и пустых отрицательных промптов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для кодирования текста | CLIP | Да | |
| `prompt` | Текстовый промпт, описывающий желаемое редактирование. Поддерживает многострочный текст и динамические промпты. | STRING | Да | |
| `negative_prompt` | Текстовый промпт, описывающий то, чего следует избегать при редактировании. Можно оставить пустым, чтобы отбросить негативный conditioning. Расширенный параметр. | STRING | Да | |
| `vae` | Модель VAE, используемая для кодирования референсных изображений в латентное пространство. Необходима для добавления референсных латентов в выходные conditioning. | VAE | Нет | |
| `images` | Референсное изображение(я) для редактирования. Boogu фокусируется на одном референсе на семпл; больше — допустимо. | IMAGE | Нет | До 16 изображений |

Референсные латенты добавляются к обоим выходным conditioning только тогда, когда `vae` предоставлен вместе с хотя бы одним референсным `image`. Если `vae` опущен, положительный выход всё равно получает визуальные токены из референсных изображений, но ни один из выходов не содержит референсных латентов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Conditioning, содержащее как текстовый промпт с визуальными токенами, так и референсные латенты | CONDITIONING |
| `negative` | Conditioning, содержащее отрицательный текстовый промпт и референсные латенты | CONDITIONING |
