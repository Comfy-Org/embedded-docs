# TextEncodeBooguEdit

این گره، شرطی‌سازی (conditioning) را برای ویرایش تصویر با Boogu آماده می‌کند. این گره تصاویر مرجع را پردازش کرده و خروجی‌های شرطی‌سازی مثبت و منفی ایجاد می‌کند. تصویر مرجع دو بار استفاده می‌شود: توکن‌های بینایی (vision tokens) از تصویر فقط به شرطی‌سازی مثبت اضافه می‌شوند تا دستور ویرایش تقویت شود؛ در حالی که یک latent مرجع VAE به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود تا تحت CFG خنثی گردد و هویت تصویر اصلی حفظ شود. توکنایزر به‌طور خودکار پرامپت سیستم مناسب را بر اساس وجود تصاویر و پرامپت‌های منفی خالی انتخاب می‌کند.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای کدگذاری متن استفاده می‌شود | CLIP | بله | |
| `prompt` | متن پرامپت که ویرایش موردنظر را توصیف می‌کند. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | |
| `negative_prompt` | متن پرامپت که مشخص می‌کند در ویرایش از چه چیزی اجتناب شود. برای حذف شرطی‌سازی منفی می‌توان آن را خالی گذاشت. پارامتر پیشرفته. | STRING | بله | |
| `vae` | مدل VAE که برای کدگذاری تصاویر مرجع به فضای latent استفاده می‌شود. برای افزودن latentهای مرجع به خروجی‌های شرطی‌سازی لازم است. | VAE | خیر | |
| `images` | تصویر(های) مرجع برای ویرایش. Boogu روی یک مرجع در هر نمونه تمرکز دارد؛ تعداد بیشتر مجاز است. | IMAGE | خیر | حداکثر 16 تصویر |

latentهای مرجع تنها زمانی به هر دو خروجی شرطی‌سازی اضافه می‌شوند که `vae` به همراه حداقل یک `image` مرجع ارائه شده باشد. اگر `vae` حذف شود، خروجی مثبت همچنان توکن‌های بینایی را از تصاویر مرجع دریافت می‌کند، اما هیچ‌کدام از خروجی‌ها شامل latentهای مرجع نمی‌شوند.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی شامل پرامپت متنی با توکن‌های بینایی و همچنین latentهای مرجع | CONDITIONING |
| `negative` | شرطی‌سازی شامل پرامپت متن منفی و latentهای مرجع | CONDITIONING |
