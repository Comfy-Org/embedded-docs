# TextEncodeBooguEdit

צומת זה מכין קונדישנינג (conditioning) לעריכת תמונות עם Boogu. הוא מעבד תמונות ייחוס כדי ליצור פלטי קונדישנינג חיוביים ושליליים. תמונת הייחוס משמשת פעמיים: טוקנים חזותיים (vision tokens) מהתמונה מתווספים רק לקונדישנינג החיובי כדי להגביר את הוראת העריכה, בעוד שלטנט ייחוס של VAE מתווסף גם לקונדישנינג החיובי וגם לשלילי כך שהוא מתבטל תחת CFG, ומשמר את זהות התמונה המקורית; הטוקנייזר בוחר אוטומטית את פרומפט המערכת המתאים בהתאם לנוכחות תמונות ולפרומפטים שליליים ריקים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל CLIP המשמש לקידוד טקסט | CLIP | כן | |
| `prompt` | פרומפט הטקסט המתאר את העריכה הרצויה. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | |
| `negative_prompt` | פרומפט הטקסט המתאר ממה להימנע בעריכה. ניתן להשאיר ריק כדי להשמיט קונדישנינג שלילי. פרמטר מתקדם. | STRING | כן | |
| `vae` | מודל ה-VAE המשמש לקידוד תמונות ייחוס למרחב הלטנטי. נחוץ כדי להוסיף לטנטי ייחוס לפלטי הקונדישנינג. | VAE | לא | |
| `images` | תמונת/ות ייחוס לעריכה. Boogu מתמקד בתמונת ייחוס אחת לדגימה; ניתן להשתמש ביותר. | IMAGE | לא | עד 16 תמונות |

לטנטי ייחוס מתווספים לשני פלטי הקונדישנינג רק כאשר `vae` מסופק יחד עם לפחות תמונת ייחוס אחת (`image`). אם `vae` מושמט, פלט ה-`positive` עדיין מקבל טוקנים חזותיים מתמונות הייחוס, אך אף אחד מהפלטים אינו כולל לטנטי ייחוס.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | קונדישנינג המכיל גם את פרומפט הטקסט עם טוקנים חזותיים וגם את לטנטי הייחוס | CONDITIONING |
| `negative` | קונדישנינג המכיל את פרומפט הטקסט השלילי ואת לטנטי הייחוס | CONDITIONING |
