# הנחיית קשב מנורמלת

צומת NAGuidance מיישם Normalized Attention Guidance על מודל. טכניקה זו מאפשרת שימוש בפרומפטים שליליים עם מודלים מזוקקים או schnell על ידי שינוי מנגנון הקשב של המודל במהלך תהליך הדגימה כדי להסיט את היצירה הרחק מרעיונות לא רצויים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו יש ליישם Normalized Attention Guidance. | MODEL | כן | - |
| `nag_scale` | מקדם קנה המידה של ההנחיה. ערכים גבוהים יותר דוחפים את היצירה הרחק מהפרומפט השלילי. (ברירת מחדל: 5.0) | FLOAT | כן | 0.0 - 50.0 |
| `nag_alpha` | מקדם המיזוג עבור הקשב המנורמל. ערך 1.0 מחליף לחלוטין את הקשב המקורי, בעוד של-0.0 אין השפעה. (ברירת מחדל: 0.5) | FLOAT | כן | 0.0 - 1.0 |
| `nag_tau` | מקדם קנה מידה המשמש להגבלת יחס הנרמול. (ברירת מחדל: 1.5) | FLOAT | כן | 1.0 - 10.0 |
