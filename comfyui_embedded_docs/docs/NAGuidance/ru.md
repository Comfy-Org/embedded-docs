# Нормализованное управление вниманием

Узел NAGuidance применяет нормализованное управление вниманием (Normalized Attention Guidance) к модели. Эта техника позволяет использовать негативные промпты с дистиллированными или schnell-моделями, модифицируя механизм внимания модели во время процесса сэмплирования, чтобы направлять генерацию в сторону от нежелательных концепций.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяется нормализованное управление вниманием. | MODEL | Да | - |
| `nag_scale` | Коэффициент масштаба управления. Более высокие значения сильнее отталкивают генерацию от негативного промпта. (по умолчанию: 5.0) | FLOAT | Да | 0.0 - 50.0 |
| `nag_alpha` | Коэффициент смешивания для нормализованного внимания. Значение 1.0 полностью заменяет исходное внимание, а 0.0 не оказывает эффекта. (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 1.0 |
| `nag_tau` | Масштабный коэффициент, используемый для ограничения отношения нормализации. (по умолчанию: 1.5) | FLOAT | Да | 1.0 - 10.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Пропатченная модель с включенным нормализованным управлением вниманием. | MODEL |
