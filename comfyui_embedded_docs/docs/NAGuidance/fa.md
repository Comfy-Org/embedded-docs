# راهنمای توجه نرمال‌سازی‌شده

گره NAGuidance راهنمایی توجه نرمال‌شده (Normalized Attention Guidance) را روی یک مدل اعمال می‌کند. این تکنیک امکان استفاده از پرامپت‌های منفی را با مدل‌های distilled یا schnell فراهم می‌کند؛ به این صورت که در طول فرآیند نمونه‌گیری، مکانیزم توجه مدل را تغییر می‌دهد تا تولید از مفاهیم ناخواسته دور شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدلی که باید Normalized Attention Guidance روی آن اعمال شود. | MODEL | بله | - |
| `nag_scale` | ضریب مقیاس راهنمایی. مقادیر بالاتر تولید را بیشتر از پرامپت منفی دور می‌کنند. (پیش‌فرض: 5.0) | FLOAT | بله | 0.0 - 50.0 |
| `nag_alpha` | ضریب ترکیب برای توجه نرمال‌شده. مقدار 1.0 توجه اصلی را کاملاً جایگزین می‌کند، در حالی که 0.0 هیچ تأثیری ندارد. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 - 1.0 |
| `nag_tau` | ضریب مقیاسی که برای محدود کردن نسبت نرمال‌سازی استفاده می‌شود. (پیش‌فرض: 1.5) | FLOAT | بله | 1.0 - 10.0 |
