# Слияние моделей Auraflow

Узел ModelMergeAuraflow позволяет смешивать две разные модели, регулируя определённые веса смешивания для различных компонентов модели. Он обеспечивает точный контроль над тем, как разные части моделей объединяются — от начальных слоёв до конечных выходов. Этот узел особенно полезен для создания пользовательских комбинаций моделей с точным контролем над процессом слияния.
