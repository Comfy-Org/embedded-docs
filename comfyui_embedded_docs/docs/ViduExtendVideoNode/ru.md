# Vidu: расширение видео

Узел ViduExtendVideoNode генерирует дополнительные кадры для продления длины существующего видео. Он использует указанную AI-модель для создания плавного продолжения на основе исходного видео и необязательного текстового запроса.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для продления видео. Выбор модели отображает её конкретные настройки длительности и разрешения. | COMBO | Да | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `video` | Исходное видео для продления. | VIDEO | Да | - |
| `prompt` | Необязательный текстовый запрос для продлённого видео (максимум 2000 символов, по умолчанию: пусто). | STRING | Нет | - |
| `seed` | Значение seed для управления случайностью генерации (по умолчанию: 1). | INT | Нет | от 0 до 2147483647 |
| `end_frame` | Необязательное изображение, используемое в качестве целевого конечного кадра для продления. | IMAGE | Нет | - |

### Входы viduq2-pro и viduq2-turbo

Эти настройки являются общими для обеих моделей.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model.duration` | Длительность продлённого видео в секундах (по умолчанию: 4). Этот параметр появляется после выбора модели. | INT | Да | от 1 до 7 |
| `model.resolution` | Разрешение выходного видео. Этот параметр появляется после выбора модели. | COMBO | Да | `"720p"`<br>`"1080p"` |

**Примечание:** Исходное `video` должно иметь длительность от 4 до 55 секунд. Если указан `end_frame`, его соотношение сторон должно быть от 1:4 до 4:1, а ширина и высота должны быть не менее 128 пикселей.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Недавно созданный видеофайл, содержащий продлённый видеоматериал. | VIDEO |
