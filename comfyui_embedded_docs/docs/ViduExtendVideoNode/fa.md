# افزایش طول ویدیو Vidu

گره ViduExtendVideoNode فریم‌های اضافی تولید می‌کند تا طول یک ویدیوی موجود را افزایش دهد. این گره از یک مدل هوش مصنوعی مشخص برای ایجاد ادامه‌ای یکپارچه بر اساس ویدیوی منبع و یک متن راهنمای اختیاری استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای افزایش ویدیو استفاده می‌شود. انتخاب یک مدل، تنظیمات مدت‌زمان و وضوح مخصوص آن را نمایش می‌دهد. | COMBO | بله | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `video` | ویدیوی منبع که قرار است افزایش یابد. | VIDEO | بله | - |
| `prompt` | یک متن راهنمای اختیاری برای ویدیوی افزایش‌یافته (حداکثر ۲۰۰۰ کاراکتر، پیش‌فرض: خالی). | STRING | خیر | - |
| `seed` | یک مقدار seed برای کنترل تصادفی بودن تولید (پیش‌فرض: ۱). | INT | خیر | 0 تا 2147483647 |
| `end_frame` | یک تصویر اختیاری که به‌عنوان فریم پایانی هدف برای افزایش استفاده می‌شود. | IMAGE | خیر | - |

### ورودی‌های viduq2-pro و viduq2-turbo

این تنظیمات توسط هر دو مدل به اشتراک گذاشته می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.duration` | مدت‌زمان ویدیوی افزایش‌یافته بر حسب ثانیه (پیش‌فرض: ۴). این تنظیم پس از انتخاب مدل ظاهر می‌شود. | INT | بله | 1 تا 7 |
| `model.resolution` | وضوح ویدیوی خروجی. این تنظیم پس از انتخاب مدل ظاهر می‌شود. | COMBO | بله | `"720p"`<br>`"1080p"` |

**نکته:** ویدیوی منبع `video` باید مدت‌زمانی بین ۴ تا ۵۵ ثانیه داشته باشد. اگر `end_frame` ارائه شود، نسبت ابعاد آن باید بین ۱:۴ و ۴:۱ باشد و عرض و ارتفاع هر یک حداقل ۱۲۸ پیکسل باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | فایل ویدیویی تازه‌تولیدشده شامل تصاویر افزایش‌یافته. | VIDEO |
