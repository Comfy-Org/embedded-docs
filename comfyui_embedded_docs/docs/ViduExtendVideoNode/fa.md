# افزایش طول ویدیو Vidu

گره Vidu Video Extension فریم‌های بیشتری برای افزایش طول یک ویدیوی موجود تولید می‌کند. این گره از یک مدل هوش مصنوعی مشخص برای ایجاد ادامه بر پایه ویدیوی منبع و یک پرامپت متنی اختیاری استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تمدید ویدیو استفاده می‌شود. با انتخاب یک مدل، تنظیمات مدت‌زمان و وضوح مخصوص آن نمایش داده می‌شود. | DYNAMIC_COMBO | بله | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `ویدیو` | ویدیوی منبع برای تمدید. | VIDEO | بله | - |
| `پرامپت` | یک پرامپت متنی اختیاری برای ویدیوی تمدیدشده (حداکثر 2000 کاراکتر؛ پیش‌فرض: خالی). | STRING | بله | - |
| `seed` | یک مقدار seed برای کنترل تصادفی‌بودن تولید (پیش‌فرض: 1). | INT | بله | 0 تا 2147483647 |
| `فریم پایانی` | یک تصویر اختیاری برای استفاده به‌عنوان فریم پایانی هدف برای تمدید. | IMAGE | خیر | - |

### ورودی‌های viduq2-pro و viduq2-turbo

این تنظیمات میان هر دو مدل مشترک است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `duration` | مدت‌زمان ویدیوی تمدیدشده بر حسب ثانیه (پیش‌فرض: 4). این تنظیم پس از انتخاب یک مدل نمایش داده می‌شود. | INT | بله | 1 تا 7 |
| `resolution` | وضوح ویدیوی خروجی. این تنظیم پس از انتخاب یک مدل نمایش داده می‌شود. | COMBO | بله | `"720p"`<br>`"1080p"` |

**توجه:** مدت‌زمان `video` منبع باید بین 4 و 55 ثانیه باشد. اگر `end_frame` ارائه شود، نسبت ابعاد آن باید بین 1:4 و 4:1 باشد و عرض و ارتفاع آن هر کدام باید حداقل 128 پیکسل باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | فایل ویدیوی تازه‌تولیدشده که شامل محتوای ویدیویی تمدیدشده است. | VIDEO |
