# ViduExtendVideoNode

צומת Vidu Video Extension יוצר פריימים נוספים כדי להאריך סרטון קיים. הוא משתמש במודל AI מוגדר כדי ליצור המשך המבוסס על סרטון המקור ופרומפט טקסטואלי אופציונלי.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש להארכת סרטון. בחירת מודל חושפת את הגדרות משך ורזולוציה הספציפיות שלו. | DYNAMIC_COMBO | כן | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `video` | סרטון המקור להארכה. | VIDEO | כן | - |
| `prompt` | פרומפט טקסטואלי אופציונלי עבור הסרטון המורחב (עד 2000 תווים; ברירת מחדל: ריק). | STRING | כן | - |
| `seed` | ערך seed לשליטה באקראיות של היצירה (ברירת מחדל: 1). | INT | כן | 0 to 2147483647 |
| `end_frame` | תמונה אופציונלית שתשמש כפריים סיום יעד להארכה. | IMAGE | לא | - |

### קלטים של viduq2-pro ו-viduq2-turbo

הגדרות אלו משותפות לשני המודלים.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `duration` | משך הסרטון המורחב בשניות (ברירת מחדל: 4). הגדרה זו מופיעה לאחר בחירת מודל. | INT | כן | 1 to 7 |
| `resolution` | רזולוציה של סרטון הפלט. הגדרה זו מופיעה לאחר בחירת מודל. | COMBO | כן | `"720p"`<br>`"1080p"` |

**הערה:** ל-`video` המקור חייב להיות משך בין 4 ל-55 שניות. אם `end_frame` מסופק, יחס הרוחב-גובה שלו חייב להיות בין 1:4 ל-4:1, והרוחב והגובה שלו חייבים להיות לפחות 128 פיקסלים כל אחד.
