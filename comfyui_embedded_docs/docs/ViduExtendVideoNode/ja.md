# Vidu 動画拡張

以下に日本語翻訳をご提示します。

---

ViduExtendVideoNode は、既存のビデオの長さを延長するために追加フレームを生成します。指定された AI モデルを使用して、ソースビデオとオプションのテキストプロンプトに基づき、シームレスな続きを作成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ延長に使用するモデル。モデルを選択すると、そのモデル固有の長さと解像度の設定が表示されます。 | DYNAMIC_COMBO | はい | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `動画` | 延長するソースビデオ。 | VIDEO | はい | - |
| `プロンプト` | 延長されたビデオに対するオプションのテキストプロンプト（最大2000文字、デフォルト: 空）。 | STRING | いいえ | - |
| `シード` | 生成のランダム性を制御するためのシード値（デフォルト: 1）。 | INT | いいえ | 0 〜 2147483647 |
| `終了フレーム` | 延長のターゲット終了フレームとして使用するオプションの画像。 | IMAGE | いいえ | - |

### viduq2-pro および viduq2-turbo 入力

これらの設定は両モデルで共通です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `長さ` | 拡張されたビデオの長さ（秒単位、デフォルト: 4）。この設定はモデル選択後に表示されます。 | INT | はい | 1 〜 7 |
| `解像度` | 出力ビデオの解像度。この設定はモデル選択後に表示されます。 | COMBO | はい | `"720p"`<br>`"1080p"` |

**注:** ソース `video` の長さは4秒から55秒の間でなければなりません。`end_frame` を指定する場合、そのアスペクト比は1:4から4:1の間で、幅と高さはそれぞれ128ピクセル以上である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 延長された映像を含む、新しく生成されたビデオファイル。 | VIDEO |
