# Vidu 影片延伸

ViduExtendVideoNode 會產生額外幀來延長現有影片的長度。它使用指定的 AI 模型，根據來源影片和選用的文字提示建立無縫銜接的延續內容。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片延長的模型。選取模型後會顯示其特定的持續時間與解析度設定。 | COMBO | 是 | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `video` | 要延長的來源影片。 | VIDEO | 是 | - |
| `prompt` | 延伸影片的選用文字提示（最多 2000 個字元，預設為空白）。 | STRING | 否 | - |
| `seed` | 用於控制生成隨機性的種子值（預設：1）。 | INT | 否 | 0 至 2147483647 |
| `end_frame` | 選用的影像，用於作為延長部分的目標結束幀。 | IMAGE | 否 | - |

### viduq2-pro 和 viduq2-turbo 輸入

這兩個模型共用這些設定。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 延長影片的持續時間（秒）（預設：4）。此設定會在選取模型後出現。 | INT | 是 | 1 至 7 |
| `resolution` | 輸出影片的解析度。此設定會在選取模型後出現。 | COMBO | 是 | `"720p"`<br>`"1080p"` |

**注意：** 來源 `video` 的長度必須介於 4 到 55 秒之間。如果提供了 `end_frame`，其長寬比必須介於 1:4 和 4:1 之間，且寬度和高度各至少為 128 像素。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 包含延長片段的新生成的影片檔案。 | VIDEO |
