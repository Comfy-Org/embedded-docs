# Vidu 影片延伸

ViduExtendVideoNode 節點會生成額外影格，以延長現有影片的長度。它使用指定的 AI 模型，根據來源影片與可選的文字提示，建立無縫銜接的後續內容。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片延伸的模型。選擇模型後，會顯示其特定的時長與解析度設定。 | DYNAMIC_COMBO | 是 | `"viduq2-pro"`<br>`"viduq2-turbo"` |
| `video` | 要延伸的來源影片。 | VIDEO | 是 | - |
| `prompt` | 用於延伸影片的可選文字提示（最多 2000 個字元；預設為空）。 | STRING | 是 | - |
| `seed` | 用於控制生成隨機性的種子值（預設：1）。 | INT | 是 | 0 to 2147483647 |
| `end_frame` | 可選的影像，作為延伸內容的目標結束影格。 | IMAGE | 否 | - |

### viduq2-pro 與 viduq2-turbo 輸入

以下設定由兩個模型共用。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model.duration` | 延伸影片的時長（秒）（預設：4）。此設定會在選擇模型後顯示。 | INT | 是 | 1 to 7 |
| `model.resolution` | 輸出影片的解析度。此設定會在選擇模型後顯示。 | COMBO | 是 | `"720p"`<br>`"1080p"` |

**注意：** 來源 `video` 的時長必須介於 4 至 55 秒之間。如果提供了 `end_frame`，其長寬比必須介於 1:4 至 4:1 之間，且寬度與高度皆須至少為 128 像素。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 包含延伸片段的新生成影片檔案。 | VIDEO |
