# LTXV Reference Audio (ID-LoRA)

LTXV Reference Audio переносит голосовую идентичность диктора из эталонного аудиофрагмента в генерируемое аудио. Он кодирует эталонное аудио в кондиционирование и опционально модифицирует модель с помощью направляющей идентичности, которая выполняет дополнительный прямой проход без эталона на каждом шаге для усиления эффекта идентичности диктора.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель для модификации с помощью направляющей идентичности. | MODEL | Да | - |
| `positive` | Входное положительное кондиционирование. | CONDITIONING | Да | - |
| `negative` | Входное отрицательное кондиционирование. | CONDITIONING | Да | - |
| `reference_audio` | Эталонный аудиофрагмент, чью идентичность диктора необходимо перенести. Рекомендуется ~5 секунд (длительность обучения). Более короткие или длинные фрагменты могут ухудшить перенос голосовой идентичности. | AUDIO | Да | - |
| `audio_vae` | LTXV Audio VAE для кодирования. | VAE | Да | - |
| `identity_guidance_scale` | Сила направляющей идентичности. Выполняет дополнительный прямой проход без эталона на каждом шаге для усиления идентичности диктора. Установите 0 для отключения (без дополнительного прохода). (по умолчанию: 3.0) | FLOAT | Да | 0.0 - 100.0 |
| `start_percent` | Начало диапазона сигмы, в котором активна направляющая идентичности. (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `end_percent` | Конец диапазона сигмы, в котором активна направляющая идентичности. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

Примечание: направляющая идентичности применяется только когда `identity_guidance_scale` больше 0 и текущий шаг сэмплирования находится в диапазоне, заданном `start_percent` и `end_percent`. Эталонное аудио передискретизируется в соответствии с частотой дискретизации аудио VAE, если они различаются.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель, модифицированная функцией направляющей идентичности. | MODEL |
| `positive` | Положительное кондиционирование, теперь содержащее данные закодированного эталонного аудио. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, теперь содержащее данные закодированного эталонного аудио. | CONDITIONING |
