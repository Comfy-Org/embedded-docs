# LTXV Reference Audio (ID-LoRA)

Узел LTXV Reference Audio задает эталонный аудиофрагмент для переноса идентичности говорящего через ID-LoRA при генерации аудио. Он кодирует фрагмент в кондиционирование, чтобы сгенерированное аудио перенимало голосовые характеристики говорящего, и при необходимости дополняет модель направляющей идентичности, которая выполняет дополнительный прямой проход без эталона для усиления эффекта идентичности говорящего.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяется направляющая идентичности. | MODEL | Да | - |
| `positive` | Положительное входное кондиционирование. | CONDITIONING | Да | - |
| `negative` | Отрицательное входное кондиционирование. | CONDITIONING | Да | - |
| `reference_audio` | Эталонный аудиофрагмент, идентичность говорящего которого требуется передать. Рекомендуется длительность около 5 секунд (как при обучении). Более короткие или длинные фрагменты могут ухудшить перенос идентичности голоса. | AUDIO | Да | - |
| `audio_vae` | Аудио VAE LTXV для кодирования. | VAE | Да | - |
| `identity_guidance_scale` | Сила направляющей идентичности. Выполняет дополнительный прямой проход без эталона на каждом шаге для усиления идентичности говорящего. Установите 0 для отключения (без дополнительного прохода). (по умолчанию: 3.0) | FLOAT | Нет | 0.0 - 100.0 |
| `start_percent` | Начало диапазона сигма, в котором активна направляющая идентичности. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 - 1.0 |
| `end_percent` | Конец диапазона сигма, в котором активна направляющая идентичности. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 1.0 |

Примечание: направляющая идентичности активна только для значений сигма в диапазоне, заданном параметрами `start_percent` и `end_percent`; вне этого диапазона результат денойзинга остается неизменным. Эталонное аудио добавляется и в положительное, и в отрицательное кондиционирование. Если частота дискретизации эталонного аудио отличается от частоты дискретизации аудио VAE, аудио автоматически передискретизируется для соответствия VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с примененной функцией направляющей идентичности. | MODEL |
| `positive` | Положительное кондиционирование, теперь содержащее закодированные данные эталонного аудио. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, теперь содержащее закодированные данные эталонного аудио. | CONDITIONING |
