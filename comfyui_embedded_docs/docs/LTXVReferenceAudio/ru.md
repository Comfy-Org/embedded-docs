# LTXV Reference Audio (ID-LoRA)

LTXV Reference Audio переносит голосовую идентичность говорящего из эталонного аудиоклипа в сгенерированное аудио. Он кодирует эталонное аудио в кондиционирование и, опционально, патчит модель с помощью управления идентичностью (identity guidance), которое выполняет дополнительный прямой проход без эталона на каждом шаге, чтобы усилить эффект голосовой идентичности говорящего.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, которую нужно пропатчить функцией управления идентичностью. | MODEL | Да | - |
| `positive` | Вход положительного кондиционирования. | CONDITIONING | Да | - |
| `negative` | Вход отрицательного кондиционирования. | CONDITIONING | Да | - |
| `reference_audio` | Эталонный аудиоклип, голосовую идентичность говорящего из которого нужно перенести. Рекомендуется ~5 секунд (длительность обучения). Более короткие или более длинные клипы могут ухудшить перенос голосовой идентичности. | AUDIO | Да | - |
| `audio_vae` | LTXV Audio VAE для кодирования. | VAE | Да | - |
| `identity_guidance_scale` | Сила управления идентичностью. Выполняет дополнительный прямой проход без эталона на каждом шаге, чтобы усилить идентичность говорящего. Установите 0, чтобы отключить (без дополнительного прохода). (по умолчанию: 3.0) | FLOAT | Да | 0.0 - 100.0 |
| `start_percent` | Начало диапазона sigma, в котором активно управление идентичностью. (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `end_percent` | Конец диапазона sigma, в котором активно управление идентичностью. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

Примечание: управление идентичностью применяется только когда `identity_guidance_scale` больше 0 и текущий шаг сэмплирования находится в диапазоне, заданном `start_percent` и `end_percent`. Эталонное аудио передискретизируется до частоты дискретизации аудио VAE, если они различаются.

Примечание: `start_percent` и `end_percent` — это расширенные параметры, отображаемые только когда в интерфейсе включены расширенные опции.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель, пропатченная функцией управления идентичностью. | MODEL |
| `positive` | Положительное кондиционирование, теперь содержащее закодированные данные эталонного аудио. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, теперь содержащее закодированные данные эталонного аудио. | CONDITIONING |
