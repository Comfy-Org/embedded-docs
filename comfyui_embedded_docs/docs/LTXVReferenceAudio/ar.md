# LTXV مرجع الصوت (ID-LoRA)

عقدة `LTXV Reference Audio` تُحدد مقطعًا صوتيًا مرجعيًا لنقل هوية المتحدث عبر تقنية ID-LoRA في توليد الصوت. تقوم بتشفير المقطع داخل بيانات التوجيه (conditioning) بحيث يتبنى الصوت المُولَّد الخصائص الصوتية للمتحدث، كما تقوم اختياريًا بتعديل النموذج باستخدام توجيه الهوية (identity guidance)، الذي ينفذ تمريرًا أماميًا إضافيًا دون المرجع في كل خطوة لتضخيم تأثير هوية المتحدث.

## المدخلات

| المعلمة | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج الذي سيتم تعديله باستخدام توجيه الهوية. | MODEL | نعم | - |
| `positive` | مدخل التوجيه الإيجابي. | CONDITIONING | نعم | - |
| `negative` | مدخل التوجيه السلبي. | CONDITIONING | نعم | - |
| `reference_audio` | مقطع صوتي مرجعي يتم نقل هوية المتحدث منه. يُنصح بمدة 5 ثوانٍ تقريبًا (مدة التدريب). قد تؤدي المقاطع الأقصر أو الأطول إلى تدهور نقل هوية الصوت. | AUDIO | نعم | - |
| `audio_vae` | VAE الصوتي من LTXV للتشفير. | VAE | نعم | - |
| `identity_guidance_scale` | قوة توجيه الهوية. ينفذ تمريرًا أماميًا إضافيًا بدون المرجع في كل خطوة لتضخيم هوية المتحدث. اضبطه على 0 لتعطيله (بدون تمرير إضافي). (الافتراضي: 3.0) | FLOAT | لا | 0.0 - 100.0 |
| `start_percent` | بداية نطاق sigma حيث يكون توجيه الهوية نشطًا. (الافتراضي: 0.0) | FLOAT | لا | 0.0 - 1.0 |
| `end_percent` | نهاية نطاق sigma حيث يكون توجيه الهوية نشطًا. (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 1.0 |

ملاحظة: يكون توجيه الهوية نشطًا فقط لقيم sigma ضمن النطاق المحدد بواسطة `start_percent` و `end_percent`؛ وخارج هذا النطاق، يُترك ناتج إزالة الضوضاء دون تغيير. تتم إضافة الصوت المرجعي إلى كل من التوجيه الإيجابي والسلبي. إذا اختلف معدل عينات الصوت المرجعي عن معدل عينات VAE الصوتي، يُعاد أخذ عينات الصوت تلقائيًا ليتطابق مع VAE.
