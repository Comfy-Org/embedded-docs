# LTXV مرجع الصوت (ID-LoRA)

يقوم LTXV Reference Audio بنقل هوية صوت المتحدث من مقطع صوتي مرجعي إلى الصوت المُولَّد. ويقوم بترميز الصوت المرجعي إلى التكييف، واختياريًا يعدّل النموذج بإرشاد الهوية، والذي يقوم بتشغيل تمريرة أمامية إضافية بدون المرجع في كل خطوة لتضخيم تأثير هوية المتحدث.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المراد تعديله بإرشاد الهوية. | MODEL | نعم | - |
| `إيجابي` | مدخل التكييف الإيجابي. | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السلبي. | CONDITIONING | نعم | - |
| `الصوت_المرجعي` | مقطع صوتي مرجعي تُنقل هوية المتحدث منه. يُوصى بحوالي 5 ثوانٍ (مدة التدريب). قد تؤدي المقاطع الأقصر أو الأطول إلى تدهور نقل هوية الصوت. | AUDIO | نعم | - |
| `audio_vae` | VAE الصوتي LTXV للترميز. | VAE | نعم | - |
| `مقياس توجيه الهوية` | قوة إرشاد الهوية. يقوم بتشغيل تمريرة أمامية إضافية بدون المرجع في كل خطوة لتضخيم هوية المتحدث. اضبطه على 0 لتعطيله (بدون تمريرة إضافية). (الافتراضي: 3.0) | FLOAT | نعم | 0.0 - 100.0 |
| `نسبة البداية` | بداية نطاق سيجما حيث يكون إرشاد الهوية نشطاً. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `نسبة النهاية` | نهاية نطاق سيجما حيث يكون إرشاد الهوية نشطاً. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 - 1.0 |

ملاحظة: لا يتم تطبيق إرشاد الهوية إلا عندما تكون قيمة `identity_guidance_scale` أكبر من 0 وتكون خطوة أخذ العينات الحالية ضمن النطاق المحدد بواسطة `start_percent` و`end_percent`. تتم إعادة أخذ عينات الصوت المرجعي إلى معدل أخذ العينات الخاص بـ VAE الصوتي إذا اختلف الاثنان.

ملاحظة: `start_percent` و`end_percent` هما معاملان متقدمان، ويظهران فقط عند تمكين الخيارات المتقدمة في الواجهة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج المعدّل بدالة إرشاد الهوية. | MODEL |
| `positive` | التكييف الإيجابي، الذي يحتوي الآن على بيانات الصوت المرجعي المُرمَّزة. | CONDITIONING |
| `negative` | التكييف السلبي، الذي يحتوي الآن على بيانات الصوت المرجعي المُرمَّزة. | CONDITIONING |
