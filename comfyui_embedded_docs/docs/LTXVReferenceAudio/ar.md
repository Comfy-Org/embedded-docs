# LTXV مرجع الصوت (ID-LoRA)

ينقل LTXV Reference Audio الهوية الصوتية لمتحدث من مقطع صوتي مرجعي إلى الصوت المُولَّد. وهو يرمّز الصوت المرجعي في التكييف (conditioning)، ويقوم اختياريًا بتزويد النموذج بتوجيه الهوية (identity guidance)، والذي يُجري تمريرًا أماميًا إضافيًا بدون المرجع في كل خطوة لتضخيم تأثير هوية المتحدث.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | المدى |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج الذي سيتم تزويده بتوجيه الهوية. | MODEL | نعم | - |
| `إيجابي` | مدخل التكييف الموجب. | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السالب. | CONDITIONING | نعم | - |
| `الصوت_المرجعي` | مقطع صوتي مرجعي يُنقل منه هوية المتحدث. يُنصح بمدة ~5 ثوانٍ (مدة التدريب). قد تؤدي المقاطع الأقصر أو الأطول إلى تدهور نقل هوية الصوت. | AUDIO | نعم | - |
| `audio_vae` | LTXV Audio VAE للتشفير. | VAE | نعم | - |
| `مقياس توجيه الهوية` | قوة توجيه الهوية. يُجري تمريرًا أماميًا إضافيًا بدون المرجع في كل خطوة لتضخيم هوية المتحدث. اضبطه على 0 لتعطيله (بدون تمرير إضافي). (الافتراضي: 3.0) | FLOAT | نعم | 0.0 - 100.0 |
| `نسبة البداية` | بداية نطاق sigma حيث يكون توجيه الهوية نشطًا. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `نسبة النهاية` | نهاية نطاق sigma حيث يكون توجيه الهوية نشطًا. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 - 1.0 |

ملاحظة: يتم تطبيق توجيه الهوية فقط عندما تكون قيمة `identity_guidance_scale` أكبر من 0 وتكون خطوة أخذ العينات الحالية ضمن النطاق المحدد بواسطة `start_percent` و `end_percent`. يُعاد أخذ عينات الصوت المرجعي إلى معدل أخذ العينات الخاص بـ VAE الصوتي إذا اختلف الاثنان.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| model | النموذج المُعدَّل بوظيفة توجيه الهوية. | MODEL |
| positive | التكييف الموجب، والذي يحتوي الآن على بيانات الصوت المرجعي المشفّرة. | CONDITIONING |
| negative | التكييف السالب، والذي يحتوي الآن على بيانات الصوت المرجعي المشفّرة. | CONDITIONING |
