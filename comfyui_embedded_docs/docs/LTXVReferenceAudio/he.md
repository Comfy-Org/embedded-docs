# LTXV Reference Audio (ID-LoRA)

LTXV Reference Audio מעביר את זהות הקול של דובר מקטע אודיו ייחוס לאודיו שנוצר. הוא מקודד את אודיו הייחוס לתוך ההתניה, ובאופן אופציונלי מטליא את המודל עם הנחיית זהות, שמריצה מעבר קדימה נוסף ללא הייחוס בכל שלב כדי להגביר את אפקט זהות הדובר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו להחיל patch עם הנחיית זהות. | MODEL | כן | - |
| `positive` | קלט ההתניה החיובי. | CONDITIONING | כן | - |
| `negative` | קלט ההתניה השלילי. | CONDITIONING | כן | - |
| `reference_audio` | קטע אודיו ייחוס שזהות הדובר שלו תועבר. מומלץ באורך של כ-5 שניות (משך האימון). קטעים קצרים או ארוכים יותר עלולים לפגוע בהעברת זהות הקול. | AUDIO | כן | - |
| `audio_vae` | LTXV Audio VAE לקידוד. | VAE | כן | - |
| `identity_guidance_scale` | עוצמת הנחיית הזהות. מפעיל מעבר קדימה נוסף ללא הייחוס בכל שלב כדי להגביר את זהות הדובר. יש להגדיר ל-0 כדי להשבית (ללא מעבר נוסף). (ברירת מחדל: 3.0) | FLOAT | כן | 0.0 - 100.0 |
| `start_percent` | תחילת טווח הסיגמה שבו הנחיית הזהות פעילה. (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 - 1.0 |
| `end_percent` | סוף טווח הסיגמה שבו הנחיית הזהות פעילה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 1.0 |

הערה: הנחיית זהות מוחלת רק כאשר `identity_guidance_scale` גדול מ-0 ושלב הדגימה הנוכחי נמצא בטווח המוגדר על ידי `start_percent` ו-`end_percent`. אודיו הייחוס נדגם מחדש לקצב הדגימה של ה-VAE של האודיו אם השניים שונים.

הערה: `start_percent` ו-`end_percent` הם פרמטרים מתקדמים, המוצגים רק כאשר אפשרויות מתקדמות מופעלות בממשק.
