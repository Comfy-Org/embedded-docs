# PixVerse V6: из первого и последнего кадра в видео

PixVerse V6 First-Last-Frame to Video генерирует видео, которое переходит от первого кадра к последнему с помощью PixVerse, опционально с нативным аудио. Два предоставленных изображения отправляются в PixVerse API, который создаёт переходное видео и возвращает его в виде видеофайла. На выходе сохраняется соотношение сторон первого кадра.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `first_frame` | Начальное изображение видео. | IMAGE | Да | — |
| `last_frame` | Конечное изображение видео. | IMAGE | Да | — |
| `model` | Модель и настройки генерации. Выбирает модель PixVerse и отображает её параметры генерации. | DYNAMIC_COMBO | Да | "PixVerse V6" |

### Входы PixVerse V6

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `prompt` | Запрос, описывающий переход. | STRING | Да | До 5000 символов |
| `quality` | Выходное разрешение. Задаёт длинную сторону: 360p соответствует 640px, 540p — 1024px, 720p — 1280px, 1080p — 1920px. (по умолчанию: 720p) | COMBO | Да | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | Длительность создаваемого видео в секундах. (по умолчанию: 5) | INT | Да | от 1 до 15 |
| `generate_audio` | Создавать нативную аудиодорожку вместе с видео. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `seed` | Зерно (seed) для генерации видео. PixVerse записывает его, но не воспроизводит генерацию на его основе. (по умолчанию: 42) | INT | Да | от 0 до 2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов в видео. | STRING | Нет | До 2048 символов |
| `style` | Необязательный визуальный стиль, применяемый ко всему видео. (по умолчанию: none) | COMBO | Нет | Доступно несколько вариантов (по умолчанию: "none") |

Примечание: Промпт не должен быть пустым после удаления пробелов и ограничен 5000 символами. Негативный промпт, если он указан, ограничен 2048 символами. Длительность должна быть от 1 до 15 секунд. На выходе видео сохраняет соотношение сторон первого кадра.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `output` | Сгенерированное видео, которое переходит от первого кадра к последнему, включая аудиодорожку, если `generate_audio` включён. | VIDEO |
