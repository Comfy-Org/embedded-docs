# PixVerse V6 فریم اول-آخر به ویدیو

PixVerse V6 First-Last-Frame to Video با استفاده از PixVerse ویدئویی تولید می‌کند که از یک فریم اول به فریم آخر انتقال می‌یابد و به‌صورت اختیاری صدای بومی دارد. دو تصویر ارائه‌شده به API PixVerse فرستاده می‌شوند؛ این API ویدئوی انتقال را تولید و آن را به‌صورت یک فایل ویدئویی بازمی‌گرداند. خروجی نسبت تصویر فریم اول را حفظ می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | تصویر شروع ویدئو. | IMAGE | بله | — |
| `last_frame` | تصویر پایان ویدئو. | IMAGE | بله | — |
| `model` | تنظیمات مدل و تولید. مدل PixVerse را انتخاب می‌کند و پارامترهای تولید آن را نمایش می‌دهد. | DYNAMIC_COMBO | بله | "PixVerse V6" |

### ورودی‌های PixVerse V6

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که انتقال را توصیف می‌کند. | STRING | بله | حداکثر 5000 کاراکتر |
| `quality` | رزولوشن خروجی. لبه بلند را تنظیم می‌کند: 360p برابر 640px، 540p برابر 1024px، 720p برابر 1280px، و 1080p برابر 1920px. (پیش‌فرض: 720p) | COMBO | بله | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | طول ویدئوی تولیدشده بر حسب ثانیه. (پیش‌فرض: 5) | INT | بله | 1 تا 15 |
| `generate_audio` | یک قطعه صوتی بومی همراه با ویدئو تولید می‌کند. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `seed` | مقدار اولیه (Seed) برای تولید ویدئو. PixVerse آن را ثبت می‌کند اما اجرای مجدد را از روی آن بازتولید نمی‌کند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در ویدئو. | STRING | خیر | حداکثر 2048 کاراکتر |
| `style` | سبک بصری اختیاری که روی کل ویدئو اعمال می‌شود. (پیش‌فرض: none) | COMBO | خیر | گزینه‌های متعدد موجود است (پیش‌فرض: "none") |

توجه: پس از حذف فاصله‌های خالی، `prompt` نباید خالی باشد و حداکثر 5000 کاراکتر است. `negative_prompt` در صورت ارائه، حداکثر 2048 کاراکتر است. مدت زمان باید بین 1 تا 15 ثانیه باشد. ویدئوی خروجی نسبت تصویر فریم اول را حفظ می‌کند.
