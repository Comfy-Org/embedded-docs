# PixVerse V6 فریم اول-آخر به ویدیو

PixVerse V6 First-Last-Frame to Video ویدیویی تولید می‌کند که با استفاده از PixVerse از یک فریم اول به یک فریم آخر گذار می‌کند و به‌صورت اختیاری دارای صدای بومی است. دو تصویر ارائه‌شده به PixVerse API ارسال می‌شوند؛ این API ویدیوی گذار را تولید کرده و آن را به‌عنوان یک فایل ویدیویی برمی‌گرداند. خروجی نسبت ابعاد فریم اول را حفظ می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | تصویر شروع ویدیو. | IMAGE | بله | — |
| `last_frame` | تصویر پایان ویدیو. | IMAGE | بله | — |
| `model` | مدل و تنظیمات تولید. مدل PixVerse را انتخاب می‌کند و پارامترهای تولید آن را نمایش می‌دهد. | DYNAMIC_COMBO | بله | "PixVerse V6" |

### ورودی‌های PixVerse V6

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت توصیف‌کننده گذار. | STRING | بله | حداکثر ۵۰۰۰ کاراکتر |
| `quality` | رزولوشن خروجی. لبه بلند را تنظیم می‌کند: 360p معادل 640 پیکسل، 540p معادل 1024 پیکسل، 720p معادل 1280 پیکسل، 1080p معادل 1920 پیکسل. (پیش‌فرض: 720p) | COMBO | بله | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | طول ویدیوی تولیدشده بر حسب ثانیه. (پیش‌فرض: 5) | INT | بله | 1 تا 15 |
| `generate_audio` | تولید یک تراک صوتی بومی به همراه ویدیو. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `seed` | Seed برای تولید ویدیو. PixVerse آن را ثبت می‌کند اما اجرایی را از روی آن بازتولید نمی‌کند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |
| `negative_prompt` | توضیح متنی اختیاری درباره عناصر نامطلوب در ویدیو. | STRING | خیر | حداکثر ۲۰۴۸ کاراکتر |
| `style` | یک سبک بصری اختیاری که روی کل ویدیو اعمال می‌شود. (پیش‌فرض: none) | COMBO | خیر | چندین گزینه موجود است (پیش‌فرض: "none") |

توجه: پرامپت پس از حذف فاصله‌های خالی نباید خالی باشد و به ۵۰۰۰ کاراکتر محدود است. پرامپت منفی، در صورت ارائه، به ۲۰۴۸ کاراکتر محدود است. مدت‌زمان باید بین ۱ تا ۱۵ ثانیه باشد. ویدیوی خروجی نسبت ابعاد فریم اول را حفظ می‌کند.
