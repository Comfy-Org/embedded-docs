# FluxProImageNode

يُنشئ الصور بشكل متزامن استنادًا إلى الموجّه والدقة. تُنشئ هذه العقدة الصور باستخدام نموذج Flux 1.1 Pro عبر إرسال طلبات إلى نقطة نهاية API والانتظار حتى تكتمل الاستجابة قبل إرجاع الصورة المُنشأة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `prompt` | الموجّه الخاص بتوليد الصورة (القيمة الافتراضية: سلسلة فارغة) | STRING | نعم | - |
| `prompt_upsampling` | ما إذا كان ينبغي إجراء رفع العينات على الموجّه. عند تفعيله، يُعدّل الموجّه تلقائيًا لتوليد أكثر إبداعًا، لكن النتائج غير حتمية (لن تُنتج البذرة نفسها النتيجة نفسها تمامًا). (القيمة الافتراضية: False) | BOOLEAN | نعم | - |
| `width` | عرض الصورة بالبكسل (القيمة الافتراضية: 1024، الخطوة: 32) | INT | نعم | 256-1440 |
| `height` | ارتفاع الصورة بالبكسل (القيمة الافتراضية: 768، الخطوة: 32) | INT | نعم | 256-1440 |
| `seed` | البذرة العشوائية المستخدمة في إنشاء التشويش. (القيمة الافتراضية: 0) | INT | نعم | 0-18446744073709551615 |
| `image_prompt` | صورة مرجعية اختيارية لتوجيه عملية التوليد | IMAGE | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | الصورة المُنشأة التي يعيدها API | IMAGE |
