# FluxProImageNode

Генерирует изображения синхронно на основе промпта и разрешения. Этот узел создаёт изображения с использованием модели Flux 1.1 Pro, отправляя запросы к эндпоинту API и дожидаясь полного ответа, прежде чем вернуть сгенерированное изображение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Промпт для генерации изображения (по умолчанию: пустая строка) | STRING | Да | - |
| `prompt_upsampling` | Выполнять ли апсемплинг промпта. Если включено, автоматически изменяет промпт для более креативной генерации, но результаты недетерминированы (одинаковый seed не даст точно такого же результата). (по умолчанию: False) | BOOLEAN | Да | - |
| `width` | Ширина изображения в пикселях (по умолчанию: 1024, шаг: 32) | INT | Да | 256-1440 |
| `height` | Высота изображения в пикселях (по умолчанию: 768, шаг: 32) | INT | Да | 256-1440 |
| `seed` | Случайное значение seed, используемое для создания шума. (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `image_prompt` | Необязательное референсное изображение для управления генерацией | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированное изображение, возвращённое API | IMAGE |
