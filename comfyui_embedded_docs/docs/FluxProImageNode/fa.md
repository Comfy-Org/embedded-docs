# FluxProImageNode

تصاویر را به‌صورت همگام بر اساس پرامپت و رزولوشن تولید می‌کند. این گره با استفاده از مدل Flux 1.1 Pro و با ارسال درخواست‌ها به یک نقطه پایانی API و انتظار برای دریافت پاسخ کامل، پیش از بازگرداندن تصویر تولیدشده، تصاویر را ایجاد می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `prompt` | پرامپت برای تولید تصویر (پیش‌فرض: رشته خالی) | STRING | بله | - |
| `prompt_upsampling` | آیا روی پرامپت نمونه‌برداری افزایشی انجام شود. در صورت فعال بودن، پرامپت را به‌طور خودکار برای تولید خلاقانه‌تر تغییر می‌دهد، اما نتایج غیرقطعی هستند (همان seed دقیقاً همان نتیجه را تولید نمی‌کند). (پیش‌فرض: False) | BOOLEAN | بله | - |
| `width` | عرض تصویر بر حسب پیکسل (پیش‌فرض: 1024، گام: 32) | INT | بله | 256-1440 |
| `height` | ارتفاع تصویر بر حسب پیکسل (پیش‌فرض: 768، گام: 32) | INT | بله | 256-1440 |
| `seed` | seed تصادفی مورد استفاده برای ایجاد نویز. (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `image_prompt` | تصویر مرجع اختیاری برای هدایت تولید | IMAGE | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | تصویر تولیدشده که از API بازگردانده می‌شود | IMAGE |
