# FluxProImageNode

יוצר תמונות באופן סינכרוני על בסיס פרומפט ורזולוציה. צומת זה יוצר תמונות באמצעות מודל Flux 1.1 Pro על ידי שליחת בקשות לנקודת קצה של API והמתנה לתגובה מלאה לפני החזרת התמונה שנוצרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `prompt_upsampling` | האם לבצע upsampling על הפרומפט. אם פעיל, משנה אוטומטית את הפרומפט ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה תוצאה). (ברירת מחדל: False) | BOOLEAN | כן | - |
| `width` | רוחב התמונה בפיקסלים (ברירת מחדל: 1024, צעד: 32) | INT | כן | 256-1440 |
| `height` | גובה התמונה בפיקסלים (ברירת מחדל: 768, צעד: 32) | INT | כן | 256-1440 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | כן | 0-18446744073709551615 |
| `image_prompt` | תמונת עזר אופציונלית להנחות את היצירה | IMAGE | לא | - |
