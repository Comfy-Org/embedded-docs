# Flux Video Upscale

Flux Video Upscale 使用 FLUX 超解析度來放大影片，可放大至固定的 1080p、2K 或 4K 畫面尺寸，或放大 1.5 至 3 倍。創意模式會修復並生成細部細節，適合生成素材；精確模式會銳化來源而不改變內容，適合臉部、產品與實拍素材。影片會上傳、輪詢 BFL 任務，完成的影片以 24 fps 回傳。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `video` | 長度 1 至 20 秒、至少 64x64 像素、長寬比介於 1:4 與 4:1 之間的來源影片。輸出以 24 fps 渲染，每幀上限約 14.4 百萬像素。 | VIDEO | 是 | 1 至 20 秒長度；長寬比介於 1:4 與 4:1 之間；最少 64x64 像素 |
| `target_resolution` | 輸出尺寸。`"1080p"`、`"2K"` 與 `"4K"` 會將結果置入 1920x1080、2560x1440 或 3840x2160 像素範圍內，直式影片則旋轉處理；`"by factor"` 則改用 `upscale_factor`。 | DYNAMIC_COMBO | 是 | `"2K"`<br>`"4K"`<br>`"1080p"`<br>`"by factor"` |
| `mode` | `"creative"` 會修復並生成細部細節，最適合生成素材、紋理與風景。`"precise"` 會銳化來源而不改變內容，適合臉部、產品與實拍素材。（預設值：`"creative"`） | COMBO | 是 | `"creative"`<br>`"precise"` |
| `prompt` | 選填的影片描述，用於引導強化的細節。留空則進行中性的放大。（預設值：空） | STRING | 是 | 多行文字 |
| `auto_downscale` | 對過大的來源進行縮小，而不是拒絕處理：面積超過 2560x1440 像素，或超過目標解析度的三分之二。長寬比會保持不變。（預設值：true） | BOOLEAN | 是 | true<br>false |
| `safety_tolerance` | 審核容忍度，0 為最嚴格。（預設值：2，進階參數） | INT | 是 | 0 至 4 |
| `seed` | 種子控制節點是否需重新執行；FLUX 會自行選擇種子，因此無論此值為何，實際結果都是不確定的。（預設值：42） | INT | 是 | 0 至 4294967295 |

### by factor 輸入

當 `target_resolution` 設為 `"by factor"` 時，會顯示這些輸入。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | 相對於來源的輸出尺寸。由於每幀上限，過大的來源實際放大倍率會低於請求的倍數。（預設值：2.0） | FLOAT | 是 | 1.5 至 3.0（步長 0.1） |

目標尺寸會以限制在 1.5-3.0 之間的放大倍率套用，因此若來源太小，即使放大 3 倍也無法填滿該框，輸出會小於請求的解析度；而若來源只需不到 1.5 倍就能填滿該框，則會先被縮小。關閉 `auto_downscale` 時，節點會停止並回報錯誤，而不是進行縮小。輸出為 24 fps，每幀上限約 14.4 百萬像素，因此過大的來源實際放大倍率可能低於請求的倍數。
