# Bria מחיקה לפי טקסט

צומת זה מסיר אובייקט המתואר בטקסט חופשי מתמונה באמצעות Bria. Bria מרנדרת מחדש את כל הפריים ברזולוציה של כ־1 מגה־פיקסל, ולכן התוצאה אינה מיושרת ברמת הפיקסל לקלט.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שממנה יש להסיר את האובייקט הנקוב. | IMAGE | כן | - |
| `object_name` | שם האובייקט להסרה, כגון 'המנורה'. ניתן לציין כמה אובייקטים בבת אחת, כגון 'הטלפון והעפרונות'. ציון משהו שאינו בתמונה עדיין מחזיר תמונה שעברה רינדור מחדש, והבקשה עדיין תחויב בתשלום. חייב להכיל לפחות תו אחד (ברירת מחדל: ריק). | STRING | כן | - |
| `moderation` | הגדרות מודרציה. קובע אם בקרות המודרציה האופציונליות מוצגות. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |

### קלטי מודרציה

פרמטרים אלו מופיעים כאשר `moderation` מוגדר ל-`"true"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | מפעיל מודרציה של תוכן על תמונת הקלט (ברירת מחדל: false). | BOOLEAN | לא | true<br>false |
| `visual_output_moderation` | מפעיל מודרציה של תוכן על תמונת הפלט שנוצרה (ברירת מחדל: false). | BOOLEAN | לא | true<br>false |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-----------|-----------|
| `IMAGE` | התמונה שעברה רינדור מחדש, כאשר האובייקט הנקוב הוסר ממנה. | IMAGE |
| `structured_prompt` | תיאור מובנה של התמונה הערוכה, עבור עריכה משלימה עם Bria FIBO Image Edit. | STRING |
