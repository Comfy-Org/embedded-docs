# BriaEraseByText

Этот узел удаляет объект, описанный обычным текстом, с изображения с помощью Bria. Bria полностью перерисовывает кадр с разрешением около 1 мегапикселя, поэтому результат не выровнен попиксельно с входным изображением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, с которого следует удалить указанный объект. | IMAGE | Да | - |
| `object_name` | Имя объекта для удаления, например 'the lamp'. Можно указать сразу несколько объектов, например 'the phone and the pencils'. Если указать объект, которого нет на изображении, всё равно будет возвращено перерисованное изображение и списана плата за него. Длина должна быть не менее 1 символа (по умолчанию: пусто). | STRING | Да | - |
| `moderation` | Настройки модерации. Определяют, показывать ли дополнительные элементы управления модерацией. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы модерации

Эти параметры отображаются, когда `moderation` имеет значение `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию содержимого входного изображения (по умолчанию: false). | BOOLEAN | Нет | true<br>false |
| `visual_output_moderation` | Включает модерацию содержимого сгенерированного выходного изображения (по умолчанию: false). | BOOLEAN | Нет | true<br>false |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Перерисованное изображение с удалённым указанным объектом. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
