# VAE 解碼音訊

此節點使用變分自編碼器（VAE）將音訊的潛在表示轉換回可播放的音訊波形。它會接收編碼後的樣本，透過所選的 VAE 進行解碼，然後將產生的波形正規化，使整體音量保持 Consistent。輸出音訊會採用 VAE 的音訊取樣率（預設為 44100 Hz），或者當輸入樣本本身帶有取樣率時，改用該樣本所儲存的取樣率。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 潛在空間中已編碼的音訊樣本，將被解碼回音訊波形。若這些樣本本身帶有取樣率，輸出便會採用該值。 | LATENT | 是 | - |
| `vae` | 用於將潛在樣本解碼為音訊的變分自編碼器模型。當輸入樣本未指定取樣率時，其音訊輸出取樣率（預設 44100 Hz）會決定所產生波形的取樣率。 | VAE | 是 | - |

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `AUDIO` | 已解碼且音量正規化的音訊波形，會連同其取樣率一併回傳（若輸入 `samples` 帶有取樣率則採用該取樣率，否則使用 VAE 的音訊取樣率，預設 44100 Hz）。 | AUDIO |
