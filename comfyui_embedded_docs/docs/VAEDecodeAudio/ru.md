# Декодировать аудио VAE

Узел VAEDecodeAudio преобразует скрытые представления обратно в аудиосигналы с помощью вариационного автокодировщика. Он принимает закодированные аудиосэмплы и обрабатывает их через VAE для восстановления исходного аудио, применяя нормализацию для обеспечения стабильных уровней выходного сигнала. Результирующее аудио возвращается с частотой дискретизации 44100 Гц по умолчанию, или с частотой дискретизации из входных сэмплов, если она указана.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `образцы` | Закодированные аудиосэмплы в скрытом пространстве, которые будут декодированы обратно в аудиосигнал | LATENT | Да | - |
| `vae` | Модель вариационного автокодировщика, используемая для декодирования скрытых сэмплов в аудио | VAE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Декодированный аудиосигнал с нормализованной громкостью и частотой дискретизации (по умолчанию: 44100 Гц, или частота дискретизации из входных `samples`, если она присутствует) | AUDIO |
