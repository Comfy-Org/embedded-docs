# Декодировать аудио VAE

Узел VAEDecodeAudio преобразует скрытые представления обратно в аудиосигналы с помощью вариационного автокодировщика. Он принимает закодированные аудиосэмплы и обрабатывает их через VAE для восстановления исходного аудио, применяя нормализацию для обеспечения стабильных уровней выходного сигнала. Полученное аудио возвращается со стандартной частотой дискретизации 44100 Гц или с частотой дискретизации из входных сэмплов, если она указана.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Закодированные аудиосэмплы в скрытом пространстве, которые будут декодированы обратно в аудиосигнал | LATENT | Да | - |
| `vae` | Модель вариационного автокодировщика, используемая для декодирования скрытых сэмплов в аудио | VAE | Да | - |

Примечание: если `samples` содержит вложенные скрытые данные, для декодирования используется только последний элемент.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `AUDIO` | Декодированный аудиосигнал с нормализованным уровнем громкости и частотой дискретизации (по умолчанию: 44100 Гц или частота дискретизации из входных `samples`, если она присутствует) | AUDIO |
