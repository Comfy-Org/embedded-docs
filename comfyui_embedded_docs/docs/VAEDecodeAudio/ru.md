# Декодировать аудио VAE

Этот узел преобразует латентное представление аудио обратно в воспроизводимую звуковую волновую форму с помощью вариационного автоэнкодера (VAE). Он принимает закодированные сэмплы, декодирует их через выбранный VAE, а затем нормализует полученную волновую форму, чтобы общий уровень громкости оставался постоянным. Выходное аудио использует частоту дискретизации аудио VAE (по умолчанию 44100 Гц) или частоту дискретизации, сохранённую во входных сэмплах, если она присутствует.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `образцы` | Закодированные аудиосэмплы в латентном пространстве, которые будут декодированы обратно в звуковую волновую форму. Если сэмплы содержат собственную частоту дискретизации, это значение используется для выхода. | LATENT | Да | - |
| `vae` | Модель вариационного автоэнкодера, используемая для декодирования латентных сэмплов в аудио. Частота дискретизации её аудиовыхода (по умолчанию 44100 Гц) определяет частоту дискретизации результирующей волновой формы, когда входные `samples` не задают её. | VAE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Декодированная звуковая волновая форма с нормализованной громкостью, возвращаемая вместе с её частотой дискретизации (частота дискретизации из входных `samples`, если она присутствует, иначе частота дискретизации аудио VAE, по умолчанию 44100 Гц). | AUDIO |
