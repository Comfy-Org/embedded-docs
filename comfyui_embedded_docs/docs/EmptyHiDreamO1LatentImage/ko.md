# Empty HiDream-O1 Latent Image

## 개요

이 노드는 픽셀 공간에서 빈 잠재 이미지를 생성하며, HiDream-O1-Image 모델을 위해 특별히 설계되었습니다. 너비, 높이 및 배치 크기 입력에 따라 차원이 결정되는, 0으로 채워진 빈 텐서를 생성하여 이미지 생성의 시작점 역할을 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `width` | 잠재 이미지의 너비(픽셀 단위, 기본값: 2048). 모델은 약 4메가픽셀 해상도로 학습되었습니다. 더 낮은 해상도를 사용하면 분포를 벗어나 품질이 눈에 띄게 저하됩니다. | INT | 예 | 64 ~ 4096 (간격: 32) |
| `height` | 잠재 이미지의 높이(픽셀 단위, 기본값: 2048). 모델은 약 4메가픽셀 해상도로 학습되었습니다. 더 낮은 해상도를 사용하면 분포를 벗어나 품질이 눈에 띄게 저하됩니다. | INT | 예 | 64 ~ 4096 (간격: 32) |
| `batch_size` | 단일 배치에서 생성할 잠재 이미지의 수(기본값: 1). | INT | 아니오 | 1 ~ 64 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 0으로 채워진 텐서로, 형태가 (batch_size, 3, height, width)인 빈 잠재 이미지를 나타냅니다. | LATENT |

## 참고 사항

- HiDream-O1-Image 모델은 약 4메가픽셀 해상도로 학습되었습니다. 현저히 낮은 해상도를 사용하면 이미지 품질이 저하될 수 있습니다.
- 학습된 해상도는 다음과 같습니다: 2048x2048, 2304x1728, 1728x2304, 2560x1440, 1440x2560, 2496x1664, 1664x2496, 3104x1312, 1312x3104, 2304x1792, 1792x2304.
