# Пустое HiDream-O1 латентное изображение

Этот узел создаёт пустое латентное изображение в пространстве пикселей для модели HiDream-O1-Image. Он генерирует пустой тензор, заполненный нулями, который служит начальной точкой для генерации изображения; его размеры определяются входными параметрами `width`, `height` и `batch_size`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного изображения в пикселях. По умолчанию: 2048. Значение должно быть кратно 32. Модель обучалась примерно на 4 мегапикселях; более низкие разрешения могут заметно снизить качество. | INT | Да | от 64 до 4096 (шаг: 32) |
| `высота` | Высота латентного изображения в пикселях. По умолчанию: 2048. Значение должно быть кратно 32. Модель обучалась примерно на 4 мегапикселях; более низкие разрешения могут заметно снизить качество. | INT | Да | от 64 до 4096 (шаг: 32) |
| `размер_пакета` | Количество латентных изображений для генерации в одном пакете. По умолчанию: 1. | INT | Да | от 1 до 64 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Тензор, заполненный нулями, представляющий пустое латентное изображение, с формой (batch_size, 3, height, width). | LATENT |

## Примечания

- Модель HiDream-O1-Image обучалась примерно на 4 мегапикселях. Использование значительно более низких разрешений может привести к заметному снижению качества изображения.
- Обучение выполнялось на следующих разрешениях: 2048x2048, 2304x1728, 1728x2304, 2560x1440, 1440x2560, 2496x1664, 1664x2496, 3104x1312, 1312x3104, 2304x1792, 1792x2304.
