# Пустое HiDream-O1 латентное изображение

Этот узел создаёт пустое латентное изображение в пиксельном пространстве, специально предназначенное для модели HiDream-O1-Image. Он генерирует пустой тензор, заполненный нулями, который служит отправной точкой для генерации изображения. Размеры тензора определяются входными параметрами `width`, `height` и `batch_size`.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного изображения в пикселях (по умолчанию: 2048). Модель обучалась на изображениях с разрешением около 4 мегапикселей; при более низких разрешениях значения выходят за пределы обучающего распределения, и качество заметно ухудшается. | INT | Да | 64 до 4096 (шаг: 32) |
| `высота` | Высота латентного изображения в пикселях (по умолчанию: 2048). Модель обучалась на изображениях с разрешением около 4 мегапикселей; при более низких разрешениях значения выходят за пределы обучающего распределения, и качество заметно ухудшается. | INT | Да | 64 до 4096 (шаг: 32) |
| `размер_пакета` | Количество латентных изображений для генерации в одном пакете (по умолчанию: 1). | INT | Нет | 1 до 64 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Тензор, заполненный нулями и представляющий пустое латентное изображение, с формой (batch_size, 3, height, width). | LATENT |

## Примечания

- Модель HiDream-O1-Image обучалась на изображениях с разрешением около 4 мегапикселей. Использование значительно более низких разрешений может привести к снижению качества изображения.
- Обучающие разрешения включают: 2048x2048, 2304x1728, 1728x2304, 2560x1440, 1440x2560, 2496x1664, 1664x2496, 3104x1312, 1312x3104, 2304x1792, 1792x2304.
