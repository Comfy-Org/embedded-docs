# Empty HiDream-O1 潜在画像

## 概要

このノードは、HiDream-O1-Imageモデル専用に設計された、ピクセル空間における空の潜在画像を作成します。画像生成の開始点となるゼロで埋められたテンソルを生成し、その次元は幅（width）、高さ（height）、バッチサイズ（batch_size）の入力によって定義されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `width` | 潜在画像の幅（ピクセル単位、デフォルト: 2048）。モデルは約4メガピクセルでトレーニングされています。これより低い解像度では分布から外れ、画質が著しく低下します。 | INT | はい | 64 to 4096 (step: 32) |
| `height` | 潜在画像の高さ（ピクセル単位、デフォルト: 2048）。モデルは約4メガピクセルでトレーニングされています。これより低い解像度では分布から外れ、画質が著しく低下します。 | INT | はい | 64 to 4096 (step: 32) |
| `batch_size` | 1回のバッチで生成する潜在画像の数（デフォルト: 1）。 | INT | いいえ | 1 to 64 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `samples` | 空の潜在画像を表すゼロで埋められたテンソル。形状は (batch_size, 3, height, width) です。 | LATENT |

## 注記

- HiDream-O1-Imageモデルは約4メガピクセルでトレーニングされています。大幅に低い解像度を使用すると、画質が低下する可能性があります。
- トレーニング済みの解像度: 2048x2048、2304x1728、1728x2304、2560x1440、1440x2560、2496x1664、1664x2496、3104x1312、1312x3104、2304x1792、1792x2304。
