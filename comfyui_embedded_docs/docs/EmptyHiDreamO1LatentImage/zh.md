# 空 HiDream-O1 潜空间图像

## 概述

此节点在像素空间中创建一个空的潜在图像，专为 HiDream-O1-Image 模型设计。它生成一个填充零的空白张量，作为图像生成的起点，其维度由宽度、高度和批次大小输入定义。

## 备注
