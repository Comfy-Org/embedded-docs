# Cond Pair Set Props

הצומת **PairConditioningSetProperties** מאפשר לך לשנות מאפיינים של זוגות קונדישנינג חיוביים ושליליים בו-זמנית. הוא מחיל התאמות עוצמה, הגדרות אזור קונדישנינג, ומסכות או בקרות תזמון אופציונליות על שני קלטי הקונדישנינג, ומחזיר את נתוני הקונדישנינג החיוביים והשליליים שהשתנו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive_NEW` | קלט הקונדישנינג החיובי שיש לשנות | CONDITIONING | כן | - |
| `negative_NEW` | קלט הקונדישנינג השלילי שיש לשנות | CONDITIONING | כן | - |
| `strength` | מכפיל העוצמה שמוחל על הקונדישנינג (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 10.0 |
| `set_cond_area` | קובע כיצד מחושב אזור הקונדישנינג (ברירת מחדל: "default") | STRING | כן | "default"<br>"mask bounds" |
| `mask` | מסכה אופציונלית להגבלת אזור הקונדישנינג | MASK | לא | - |
| `hooks` | קבוצת hooks אופציונלית לשינויים מתקדמים בקונדישנינג | HOOKS | לא | - |
| `timesteps` | טווח צעדי זמן אופציונלי להגבלת מתי מיושם הקונדישנינג | TIMESTEPS_RANGE | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | הקונדישנינג החיובי שהשתנה עם המאפיינים שהוחלו | CONDITIONING |
| `negative` | הקונדישנינג השלילי שהשתנה עם המאפיינים שהוחלו | CONDITIONING |
