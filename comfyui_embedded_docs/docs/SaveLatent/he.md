# SaveLatent

SaveLatent שומר טנזורי latent לדיסק כקבצי `.latent` כדי שניתן יהיה לעשות בהם שימוש חוזר או לשתף אותם מאוחר יותר. הוא מקבל דגימות latent, כותב אותן לתיקיית הפלט עם שם שנוצר אוטומטית, ויכול להטמיע מטא-נתוני workflow כגון ה-prompt בתוך הקובץ השמור. אותן דגימות latent מועברות גם כן ללא שינוי להמשך עיבוד.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `samples` | דגימות ה-latent שיש לשמור לדיסק. | LATENT | כן | - |
| `filename_prefix` | הקידומת המשמשת לבניית שם קובץ הפלט. היא יכולה לכלול תיקיות משנה, למשל "latents/ComfyUI" (ברירת מחדל: "latents/ComfyUI"). | STRING | כן | - |
| `prompt` | ה-prompt של ה-workflow, מומר ל-JSON ומאוחסן במטא-נתוני הקובץ השמור (פרמטר מוסתר, מסופק אוטומטית). | PROMPT | לא | - |
| `extra_pnginfo` | מידע נוסף של ה-workflow, מומר ל-JSON ומאוחסן במטא-נתוני הקובץ השמור (פרמטר מוסתר, מסופק אוטומטית). | EXTRA_PNGINFO | לא | - |

הערה: כל קובץ שמור מקבל שם לפי הקידומת ומונה בן 5 ספרות, לדוגמה `ComfyUI_00001_.latent`, והוא מוצב בתיקיית הפלט. הקובץ מכיל את טנזור ה-latent וסמן גרסה של פורמט latent. מטא-נתונים מוטמעים בקובץ השמור רק כאשר תמיכת המטא-נתונים מופעלת, כלומר כאשר ComfyUI לא הופעל עם האפשרות `--disable-metadata`.

## פלטים

| שם פלט | תיאור | סוג נתון |
| --- | --- | --- |
