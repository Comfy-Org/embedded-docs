# Сохранить латент

SaveLatent сохраняет латентные тензоры на диск в виде файлов `.latent`, чтобы их можно было повторно использовать или передавать другим. Он принимает латентные сэмплы, записывает их в выходную папку с автоматически сгенерированным именем и может встраивать метаданные рабочего процесса, такие как промпт, в сохраняемый файл. Те же самые латентные сэмплы также передаются без изменений для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Латентные сэмплы для сохранения на диск. | LATENT | Да | - |
| `префикс_названия_файла` | Префикс, используемый для формирования имени выходного файла. Может включать вложенные папки, например "latents/ComfyUI" (по умолчанию: "latents/ComfyUI"). | STRING | Да | - |
| `prompt` | Промпт рабочего процесса, сериализованный в JSON и сохранённый в метаданных файла (скрытый параметр, передаётся автоматически). | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная информация о рабочем процессе, сериализованная в JSON и сохранённая в метаданных файла (скрытый параметр, передаётся автоматически). | EXTRA_PNGINFO | Нет | - |

Примечание: каждый сохраняемый файл получает имя на основе префикса и 5-значного счётчика, например `ComfyUI_00001_.latent`, и помещается в выходной каталог. Файл содержит латентный тензор и маркер версии формата латентного представления. Метаданные встраиваются в сохраняемый файл только при включённой поддержке метаданных, то есть когда ComfyUI запущен без опции `--disable-metadata`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Те же латентные сэмплы, которые были поданы на вход, передаются без изменений. | LATENT |
| `ui` | Данные интерфейса для отображения, описывающие сохранённый файл: его имя, вложенная папка и тип выходных данных ("output"). | UI |
