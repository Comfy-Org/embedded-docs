# Сохранить латент

Узел SaveLatent сохраняет латентные сэмплы на диск в виде файлов `.latent` для последующего использования или обмена. Он записывает данные латентного тензора в выходную папку, используя указанный префикс имени файла, и встраивает необязательные метаданные, такие как информация о промпте. Узел также возвращает исходные латентные сэмплы без изменений, чтобы рабочий процесс мог продолжать их использовать.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Латентные сэмплы для сохранения на диск | LATENT | Да | - |
| `filename_prefix` | Префикс, используемый для генерации имени выходного файла и пути к подпапке (по умолчанию: "latents/ComfyUI") | STRING | Да | - |
| `prompt` | Данные промпта рабочего процесса, сохраняемые как JSON-метаданные в файле (скрытый вход, передается автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные рабочего процесса, сохраняемые как JSON в файле (скрытый вход, передается автоматически) | EXTRA_PNGINFO | Нет | - |

Примечание: Метаданные записываются в сохраняемый файл `.latent`, если только ComfyUI не запущен с аргументом `--disable-metadata`. Сохраненный файл именуется по шаблону `{filename}_{5-значный счетчик}_.latent`, например `ComfyUI_00001_.latent`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Исходные латентные сэмплы, возвращаемые без изменений | LATENT |
| `ui` | Сведения о местоположении файла (имя файла, подпапка и тип вывода) для сохраненного латентного файла | UI |
