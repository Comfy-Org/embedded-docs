# ذخیره Latent

گره SaveLatent نمونه‌های نهفته (latent) را به‌صورت فایل‌های `.latent` روی دیسک ذخیره می‌کند تا بعداً استفاده یا به اشتراک گذاشته شوند. این گره داده تنسور نهفته را با استفاده از پیشوند نام فایل مشخص‌شده در پوشه خروجی می‌نویسد و فراداده اختیاری مانند اطلاعات prompt را جاسازی می‌کند. همچنین گره، نمونه‌های نهفته اصلی را بدون تغییر بازمی‌گرداند تا گردش کار بتواند به استفاده از آن‌ها ادامه دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | نمونه‌های نهفته‌ای که باید روی دیسک ذخیره شوند | LATENT | بله | - |
| `filename_prefix` | پیشوندی که برای تولید نام فایل خروجی و مسیر زیرپوشه استفاده می‌شود (پیش‌فرض: "latents/ComfyUI") | STRING | بله | - |
| `prompt` | داده‌های prompt گردش کار، که به‌صورت فراداده JSON در فایل ذخیره‌شده ذخیره می‌شود (ورودی پنهان، به‌طور خودکار تأمین می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده اضافی گردش کار، که به‌صورت JSON در فایل ذخیره‌شده ذخیره می‌شود (ورودی پنهان، به‌طور خودکار تأمین می‌شود) | EXTRA_PNGINFO | خیر | - |

توجه: فراداده در فایل `.latent` ذخیره‌شده نوشته می‌شود، مگر اینکه ComfyUI با آرگومان `--disable-metadata` راه‌اندازی شده باشد. فایل ذخیره‌شده با الگوی `{filename}_{5-digit counter}_.latent` نام‌گذاری می‌شود، به عنوان مثال `ComfyUI_00001_.latent`.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | نمونه‌های نهفته اصلی، بدون تغییر بازگردانده‌شده | LATENT |
| `ui` | جزئیات مکان فایل (نام فایل، زیرپوشه و نوع خروجی) برای فایل نهفته ذخیره‌شده | UI |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SaveLatent/fa.md)
