# ذخیره Latent

SaveLatent تنسورهای نهان (latent) را به‌صورت فایل‌های `.latent` روی دیسک ذخیره می‌کند تا بعداً بتوان از آن‌ها مجدداً استفاده کرد یا به اشتراک گذاشت. این گره نمونه‌های نهان را دریافت می‌کند، آن‌ها را با نامی خودکار در پوشه خروجی می‌نویسد و می‌تواند فراداده‌هایی مانند پرامپت گردش کار را در فایل ذخیره‌شده جاسازی کند. همان نمونه‌های نهان بدون تغییر برای پردازش‌های بیشتر نیز عبور داده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نمونه‌ها` | نمونه‌های نهانی که باید روی دیسک ذخیره شوند. | LATENT | بله | - |
| `پیشوند نام فایل` | پیشوندی که برای ساخت نام فایل خروجی استفاده می‌شود. می‌تواند شامل زیرپوشه‌ها باشد، برای مثال «latents/ComfyUI» (پیش‌فرض: «latents/ComfyUI»). | STRING | بله | - |
| `prompt` | پرامپت گردش کار که به‌صورت JSON سریال‌سازی شده و در فراداده فایل ذخیره‌شده نگهداری می‌شود (پارامتر پنهان که به‌صورت خودکار ارائه می‌شود). | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات تکمیلی گردش کار که به‌صورت JSON سریال‌سازی شده و در فراداده فایل ذخیره‌شده نگهداری می‌شود (پارامتر پنهان که به‌صورت خودکار ارائه می‌شود). | EXTRA_PNGINFO | خیر | - |

توجه: هر فایل ذخیره‌شده با استفاده از پیشوند و یک شمارنده ۵ رقمی نام‌گذاری می‌شود، برای مثال `ComfyUI_00001_.latent`، و در پوشه خروجی قرار می‌گیرد. فایل شامل تنسور نهان و یک نشانگر نسخه قالب نهان است. فراداده تنها زمانی در فایل ذخیره‌شده جاسازی می‌شود که پشتیبانی فراداده فعال باشد، یعنی زمانی که ComfyUI با گزینه `--disable-metadata` راه‌اندازی نشده باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `نمونه‌ها` | همان نمونه‌های نهانی که به‌عنوان ورودی ارائه شده‌اند، بدون تغییر عبور داده می‌شوند. | LATENT |
