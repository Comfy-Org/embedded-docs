# حفظ الكامن

يقوم SaveLatent بحفظ التنسورات الكامنة (latent tensors) على القرص كملفات `.latent` بحيث يمكن إعادة استخدامها أو مشاركتها لاحقًا. يأخذ عينات كامنة (latent samples)، ويكتبها إلى مجلد الإخراج باسم يُنشأ تلقائيًا، ويمكنه تضمين بيانات وصفية لسير العمل مثل البرنامج النصي (prompt) داخل الملف المحفوظ. كما يتم تمرير نفس العينات الكامنة دون تغيير لمزيد من المعالجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `عينات` | العينات الكامنة التي سيتم حفظها على القرص. | LATENT | نعم | - |
| `بادئة اسم الملف` | البادئة المستخدمة لبناء اسم ملف الإخراج. يمكن أن تتضمن مجلدات فرعية، على سبيل المثال "latents/ComfyUI" (الافتراضي: "latents/ComfyUI"). | STRING | نعم | - |
| `prompt` | برنامج سير العمل النصي، مُسلسل بصيغة JSON ومُخزَّن في البيانات الوصفية للملف المحفوظ (معامل مخفي، يُوفَّر تلقائيًا). | PROMPT | لا | - |
| `extra_pnginfo` | معلومات إضافية عن سير العمل، مُسلسلة بصيغة JSON ومُخزَّنة في البيانات الوصفية للملف المحفوظ (معامل مخفي، يُوفَّر تلقائيًا). | EXTRA_PNGINFO | لا | - |

ملاحظة: يُسمى كل ملف محفوظ باستخدام البادئة وعداد من خمس خانات، على سبيل المثال `ComfyUI_00001_.latent`، ويُوضع في مجلد الإخراج. يحتوي الملف على التنسور الكامن وعلامة إصدار صيغة الكامن (latent format version marker). تُضمَّن البيانات الوصفية في الملف المحفوظ فقط عندما يكون دعم البيانات الوصفية مفعَّلاً، أي عندما لا يتم تشغيل ComfyUI مع الخيار `--disable-metadata`.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `عينات` | نفس العينات الكامنة التي تم توفيرها كمدخلات، ويتم تمريرها دون تغيير. | LATENT |
| `ui` | بيانات عرض الواجهة التي تصف الملف المحفوظ: اسم الملف، والمجلد الفرعي، ونوع الإخراج ("output"). | UI |
