# حفظ الكامن

العقدة `SaveLatent` تحفظ العينات الكامنة على القرص كملفات `.latent` لاستخدامها لاحقًا أو مشاركتها. وهي تكتب بيانات الموتر الكامن إلى مجلد الإخراج باستخدام بادئة اسم الملف المحددة، وتضمّن بيانات وصفية اختيارية مثل معلومات البرومبت. كما تعيد العقدة العينات الكامنة الأصلية دون تغيير، بحيث يمكن لسير العمل مواصلة استخدامها.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `samples` | العينات الكامنة التي سيتم حفظها على القرص | LATENT | نعم | - |
| `filename_prefix` | البادئة المستخدمة لتوليد اسم ملف الإخراج ومسار المجلد الفرعي (الافتراضي: "latents/ComfyUI") | STRING | نعم | - |
| `prompt` | بيانات برومبت سير العمل، تُخزَّن كبيانات وصفية JSON في الملف المحفوظ (إدخال مخفي، يُوفَّر تلقائيًا) | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية لسير العمل، تُخزَّن كـ JSON في الملف المحفوظ (إدخال مخفي، يُوفَّر تلقائيًا) | EXTRA_PNGINFO | لا | - |

ملاحظة: تُكتب البيانات الوصفية إلى ملف `.latent` المحفوظ ما لم يتم تشغيل ComfyUI مع الوسيط `--disable-metadata`. يُسمّى الملف المحفوظ وفق النمط `{filename}_{5-digit counter}_.latent`، على سبيل المثال `ComfyUI_00001_.latent`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `samples` | العينات الكامنة الأصلية، تُرجع كما هي دون تغيير | LATENT |
| `ui` | تفاصيل موقع الملف (اسم الملف، المجلد الفرعي، ونوع الإخراج) لملف `.latent` المحفوظ | UI |
