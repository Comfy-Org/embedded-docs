# ModelMergeQwenImage

צומת זה ממזג שני מודלי תמונה של Qwen על ידי ערבוב הרכיבים הנפרדים שלהם עם משקלים ניתנים להתאמה. כל משקל קובע עד כמה החלק המתאים במודל השני תורם לתוצאה הממוזגת, ומאפשר לך לערבב בנפרד הטמעות מיקום, שכבות עיבוד טקסט, שכבות קלט תמונה, את כל 60 בלוקי הטרנספורמר ואת הקרנת הפלט. התוצאה הסופית היא MODEL יחיד שבו ניתן להשתמש בכל מקום שבו מצפים למודל רגיל.
