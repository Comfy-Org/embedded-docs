# دمج_النموذج_QwenImage

تقوم عقدة ModelMergeQwenImage بدمج نموذجي ذكاء اصطناعي عبر تجميع مكوناتهما بأوزان قابلة للضبط. تتيح لك مزج أجزاء محددة من نماذج Qwen للصور، بما في ذلك كتل المحولات، والتضمينات الموضعية، ومكونات معالجة النص. يمكنك التحكم في مقدار التأثير الذي يتمتع به كل نموذج على أقسام مختلفة من النتيجة المدمجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model1` | النموذج الأول للدمج (الافتراضي: لا يوجد) | MODEL | نعم | - |
| `model2` | النموذج الثاني للدمج (الافتراضي: لا يوجد) | MODEL | نعم | - |
| `pos_embeds.` | وزن مزج التضمينات الموضعية (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `img_in.` | وزن مزج معالجة إدخال الصورة (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `txt_norm.` | وزن مزج تطبيع النص (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `txt_in.` | وزن مزج معالجة إدخال النص (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `time_text_embed.` | وزن مزج تضمين الوقت والنص (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `transformer_blocks.0.` إلى `transformer_blocks.59.` | وزن مزج كل كتلة محولات (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `proj_out.` | وزن مزج إسقاط المخرجات (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |

ملاحظة: يوجد 60 مدخلًا فرديًا لوزن كتل المحولات (من `transformer_blocks.0.` إلى `transformer_blocks.59.`)، واحد لكل كتلة محولات في النموذج.
