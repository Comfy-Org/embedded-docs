# СлияниеМоделейQwenImage

Этот узел объединяет две модели изображений Qwen, смешивая их отдельные компоненты с настраиваемыми весами. Каждый вес управляет тем, какую долю соответствующая часть второй модели вносит в объединённый результат, что позволяет отдельно смешивать позиционные эмбеддинги, слои обработки текста, слои ввода изображения, все 60 блоков трансформера и выходную проекцию. Итоговый результат — один MODEL, который можно использовать везде, где ожидается обычная модель.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель1` | Первая модель для объединения | MODEL | Да | - |
| `модель2` | Вторая модель для объединения | MODEL | Да | - |
| `pos_embeds.` | Вес для смешивания позиционных эмбеддингов (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `img_in.` | Вес для смешивания обработки входного изображения (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `txt_norm.` | Вес для смешивания нормализации текста (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `txt_in.` | Вес для смешивания обработки текстового входа (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `time_text_embed.` | Вес для смешивания эмбеддингов времени и текста (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `transformer_blocks.0.`–`transformer_blocks.59.` | Вес для смешивания каждого блока трансформера (по умолчанию: 1.0). Узел предоставляет один вес для каждого из 60 блоков трансформера. | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `proj_out.` | Вес для смешивания выходной проекции (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

Примечание: Все входы весов обязательны и имеют одинаковые ограничения — значение по умолчанию 1.0, допустимый диапазон от 0.0 до 1.0 с шагом 0.01.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Объединённая модель, сочетающая компоненты обеих входных моделей с указанными весами | MODEL |
