# СлияниеМоделейQwenImage

ModelMergeQwenImage объединяет две модели ИИ, комбинируя их компоненты с регулируемыми весами. Это позволяет смешивать отдельные части моделей изображений Qwen, включая блоки трансформера, позиционные эмбеддинги и компоненты обработки текста. Вы можете управлять степенью влияния каждой модели на различные разделы объединённого результата.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `модель1` | Первая модель для объединения | MODEL | Да | - |
| `модель2` | Вторая модель для объединения | MODEL | Да | - |
| `pos_embeds.` | Вес смешивания позиционных эмбеддингов (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `img_in.` | Вес смешивания обработки входных изображений (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `txt_norm.` | Вес смешивания нормализации текста (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `txt_in.` | Вес смешивания обработки входного текста (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `time_text_embed.` | Вес смешивания эмбеддингов времени и текста (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `transformer_blocks.0.` to `transformer_blocks.59.` | Вес смешивания для каждого блока трансформера (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |
| `proj_out.` | Вес смешивания выходной проекции (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Объединённая модель, сочетающая компоненты обеих входных моделей с заданными весами | MODEL |
