# СлияниеМоделейQwenImage

Узел ModelMergeQwenImage объединяет две модели ИИ путем смешивания их компонентов с настраиваемыми весами. Он позволяет смешивать отдельные части моделей изображений Qwen, включая блоки трансформера, позиционные встраивания и компоненты обработки текста. Вы можете контролировать степень влияния каждой модели на различные части объединенного результата.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model1` | Первая модель для объединения (по умолчанию: нет) | MODEL | Yes | - |
| `model2` | Вторая модель для объединения (по умолчанию: нет) | MODEL | Yes | - |
| `pos_embeds.` | Вес смешивания позиционных встраиваний (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `img_in.` | Вес смешивания обработки входного изображения (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `txt_norm.` | Вес смешивания нормализации текста (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `txt_in.` | Вес смешивания обработки текстового входа (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `time_text_embed.` | Вес смешивания встраивания времени и текста (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `transformer_blocks.0.` – `transformer_blocks.59.` | Вес смешивания каждого блока трансформера (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |
| `proj_out.` | Вес смешивания выходного проекционного слоя (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |

Примечание: имеется 60 отдельных входов весов для блоков трансформера (от `transformer_blocks.0.` до `transformer_blocks.59.`), по одному для каждого блока трансформера в модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Объединенная модель, сочетающая компоненты обеих входных моделей с указанными весами | MODEL |
