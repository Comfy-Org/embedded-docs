# 模型合併Qwen圖像

此節點透過以可調整的權重混合兩個 Qwen 影像模型的個別元件來合併它們。每個權重控制第二個模型中對應部分對合併結果的貢獻程度，讓您可以分別混合位置嵌入、文字處理層、影像輸入層、全部 60 個 Transformer 區塊，以及輸出投影。最終結果是單一 MODEL，您可以在任何預期使用一般模型的地方使用它。
