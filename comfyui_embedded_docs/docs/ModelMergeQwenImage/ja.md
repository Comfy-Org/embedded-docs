# ModelMergeQwenImage

ModelMergeQwenImage ノードは、2つのAIモデルの構成要素を調整可能な重みで結合してマージします。Qwen 画像モデルの特定部分（トランスフォーマーブロック、位置埋め込み、テキスト処理コンポーネントなど）をブレンドできます。マージ結果のさまざまなセクションに対して、各モデルの影響度を制御できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model1` | マージする最初のモデル（デフォルト: なし） | MODEL | はい | - |
| `model2` | マージする2番目のモデル（デフォルト: なし） | MODEL | はい | - |
| `pos_embeds.` | 位置埋め込みブレンドの重み（デフォルト: 1.0） | FLOAT | はい | 0.0 ～ 1.0 |
| `img_in.` | 画像入力処理ブレンドの重み（デフォルト: 1.0） | FLOAT | はい | 0.0 ～ 1.0 |
| `txt_norm.` | テキスト正規化ブレンドの重み（デフォルト: 1.0） | FLOAT | はい | 0.0 ～ 1.0 |
