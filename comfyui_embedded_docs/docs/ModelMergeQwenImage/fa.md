# ModelMergeQwenImage

ModelMergeQwenImage دو مدل هوش مصنوعی را با ترکیب مؤلفه‌های آن‌ها با وزن‌های قابل تنظیم ادغام می‌کند. این گره به شما امکان می‌دهد بخش‌های خاصی از مدل‌های تصویری Qwen، از جمله بلوک‌های ترنسفورمر، جاسازی‌های موقعیتی و مؤلفه‌های پردازش متن را ترکیب کنید. می‌توانید میزان تأثیر هر مدل بر بخش‌های مختلف نتیجهٔ ادغام‌شده را کنترل کنید.
