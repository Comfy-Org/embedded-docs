# ModelMergeQwenImage

این گره دو مدل تصویری Qwen را با ترکیب اجزای جداگانه‌شان و وزن‌های قابل تنظیم با هم ادغام می‌کند. هر وزن کنترل می‌کند که بخش متناظر مدل دوم چه مقدار در نتیجه ادغام‌شده سهیم باشد؛ این امکان را می‌دهد که تعبیه‌های موقعیتی، لایه‌های پردازش متن، لایه‌های ورودی تصویر، تمام ۶۰ بلوک ترانسفورمر و پروجکشن خروجی را به‌صورت جداگانه ترکیب کنید. نتیجه نهایی یک MODEL واحد است که می‌توانید هر جایی که یک مدل معمولی انتظار می‌رود از آن استفاده کنید.
