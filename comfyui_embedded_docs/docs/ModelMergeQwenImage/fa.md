# ModelMergeQwenImage

گره `ModelMergeQwenImage` دو مدل هوش مصنوعی را با ترکیب اجزای آن‌ها و استفاده از وزن‌های قابل تنظیم، در یک مدل واحد ادغام می‌کند. این گره به شما امکان می‌دهد بخش‌های خاصی از مدل‌های تصویری Qwen، از جمله بلوک‌های ترانسفورمر، تعبیه‌های موقعیتی و اجزای پردازش متن را با هم ترکیب کنید. می‌توانید تعیین کنید که هر مدل چه میزان تأثیری بر بخش‌های مختلف نتیجهٔ ادغام‌شده داشته باشد.
