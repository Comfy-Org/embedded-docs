# WanTextToVideoApi

הצומת Wan Text to Video מייצר תוכן וידאו על בסיס תיאורים טקסטואליים. הוא משתמש במודלים של בינה מלאכותית כדי ליצור וידאו מפרומפטים, ותומך בגדלים שונים של וידאו, במשכים שונים ובקלטי אודיו אופציונליים. הצומת יכול ליצור אודיו אוטומטית בעת הצורך, ומספק אפשרויות לשיפור הפרומפט ולהוספת סימן מים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש (ברירת מחדל: "wan2.6-t2v") | COMBO | כן | "wan2.5-t2v-preview"<br>"wan2.6-t2v" |
| `prompt` | פרומפט המתאר את האלמנטים והמאפיינים החזותיים. תומך באנגלית ובסינית (ברירת מחדל: "") | STRING | כן | - |
| `negative_prompt` | פרומפט שלילי המתאר ממה להימנע (ברירת מחדל: "") | STRING | לא | - |
| `size` | רזולוציית וידאו ויחס גובה-רוחב (ברירת מחדל: "720p: 1:1 (960x960)") | COMBO | לא | "480p: 1:1 (624x624)"<br>"480p: 16:9 (832x480)"<br>"480p: 9:16 (480x832)"<br>"720p: 1:1 (960x960)"<br>"720p: 16:9 (1280x720)"<br>"720p: 9:16 (720x1280)"<br>"720p: 4:3 (1088x832)"<br>"720p: 3:4 (832x1088)"<br>"1080p: 1:1 (1440x1440)"<br>"1080p: 16:9 (1920x1080)"<br>"1080p: 9:16 (1080x1920)"<br>"1080p: 4:3 (1632x1248)"<br>"1080p: 3:4 (1248x1632)" |
| `duration` | משך הווידאו בשניות. משך של 15 שניות זמין רק עבור מודל Wan 2.6 (ברירת מחדל: 5) | INT | לא | 5-15 (בצעדים של 5) |
| `audio` | האודיו חייב להכיל קול ברור וחזק, ללא רעש זר או מוזיקת רקע | AUDIO | לא | - |
| `seed` | ערך Seed לשימוש ביצירה (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `generate_audio` | אם לא סופק קלט אודיו, צור אודיו אוטומטית (ברירת מחדל: False) | BOOLEAN | לא | - |
| `prompt_extend` | האם לשפר את הפרומפט בעזרת בינה מלאכותית (ברירת מחדל: True) | BOOLEAN | לא | - |
| `watermark` | האם להוסיף סימן מים שנוצר בבינה מלאכותית לתוצאה (ברירת מחדל: False) | BOOLEAN | לא | - |
| `shot_type` | מציין את סוג הצילום עבור הווידאו הנוצר, כלומר האם הווידאו הוא צילום רציף יחיד או מספר צילומים עם חיתוכים. פרמטר זה נכנס לתוקף רק כאשר `prompt_extend` הוא True (ברירת מחדל: "single") | COMBO | לא | "single"<br>"multi" |

**הערה:** מודל Wan 2.6 אינו תומך ברזולוציות 480p. משך של 15 שניות נתמך רק במודל Wan 2.6. בעת אספקת קלט אודיו, משכו חייב להיות בין 3.0 ל-29.0 שניות, והוא חייב להכיל קול ברור ללא רעשי רקע או מוזיקה.
