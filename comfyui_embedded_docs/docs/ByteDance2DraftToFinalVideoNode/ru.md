# ByteDance Seedance 2.5 Draft to Final Video

Этот узел рендерит финальное видео 1080p для черновика Seedance 2.5. Черновик — это быстрое превью 480p: в узле видео Seedance 2.5 (текст-в-видео, первый-последний кадр-в-видео или референс-в-видео) установите `model` в `Seedance 2.5 Draft`, запустите его и подключите его выход `draft_task_id` сюда. Финальное видео сохраняет сцену и движение черновика и повторно использует промпт, референсы, длительность, соотношение сторон и настройку аудио, с которыми был создан черновик.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `draft_task_id` | Выход `draft_task_id` узла Seedance 2.5, запущенного с моделью Seedance 2.5 Draft, или вставленный ID задачи черновика. Когда вы повторно запускаете узел-производитель, установите его параметр seed в fixed, иначе следующий запуск сгенерирует новый черновик вместо повторного использования того, который вы просмотрели. | STRING | Да | - |
| `watermark` | Добавлять ли водяной знак на видео. По умолчанию False. Это расширенная настройка. | BOOLEAN | Нет | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Отрендеренное финальное видео 1080p, загруженное от провайдера после завершения задачи рендеринга. | VIDEO |

**Примечание:** Черновик можно отрендерить в течение 7 дней после его создания. ID задачи черновика идентифицирует черновик сам по себе, поэтому промпт, референсы, длительность, соотношение сторон и настройку аудио не нужно передавать повторно.
