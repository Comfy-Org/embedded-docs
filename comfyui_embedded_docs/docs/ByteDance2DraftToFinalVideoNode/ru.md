# ByteDance Seedance 2.5: из черновика в финальное видео

Этот узел рендерит финальное видео черновика Seedance 2.5 в разрешении 1080p или 4k. Разрешение 4k доступно для всех аккаунтов. Черновик — это быстрое превью в 480p: в узле видео Seedance 2.5 (текст в видео, первый и последний кадр в видео или референс в видео) установите `model` в `Seedance 2.5 Draft`, запустите его и подключите его выход `draft_task_id` сюда. Финальное видео сохраняет сцену и движение черновика и повторно использует промпт, референсы, длительность, соотношение сторон и настройку аудио, которые создали черновик.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `draft_task_id` | Выход `draft_task_id` узла Seedance 2.5, запущенного с моделью Seedance 2.5 Draft, или вставленный ID задачи черновика. При повторном запуске узла-производителя установите его управление seed в fixed, иначе следующий запуск создаст новый черновик вместо повторного использования того, который вы просмотрели. | STRING | Да | - |
| `водяной знак` | Добавлять ли водяной знак на видео. По умолчанию False. Это расширенная настройка. | BOOLEAN | Нет | True / False |
| `resolution` | Разрешение финального видео. `"4k"` доступно для всех аккаунтов; используйте точное значение в нижнем регистре `"4k"`. По умолчанию: `"1080p"`. | COMBO | Нет | `"1080p"`<br>`"4k"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Отрендеренное финальное видео, скачанное от провайдера после завершения задачи рендеринга. | VIDEO |

**Примечание:** Черновик можно отрендерить в течение 7 дней после его создания. ID задачи черновика сам по себе идентифицирует черновик, поэтому промпт, референсы, длительность, соотношение сторон и настройку аудио не нужно передавать повторно.
