# Pad Image

Добавьте к изображению отступы сплошным цветом или зеркальной копией его краёв. Отступы можно задать как точное количество пикселей с каждой стороны, как множитель размера или как минимальное количество, при котором ширина и высота становятся кратными числу, что удобно перед сохранением или тайлингом. Исходное изображение сохраняет своё положение: отступы `left` и `top` добавляются перед ним, `right` и `bottom` — после него.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Изображение, к которому добавляются отступы. | IMAGE | Да | - |
| `padding_type` | Сколько отступов добавить: `"pad dimensions"` — точное количество с каждой стороны, `"pad by multiplier"` — размер вывода относительно ввода, или `"pad to multiple"` — до ближайшего кратного. При выборе опции отображаются её параметры. | DYNAMIC_COMBO | Да | `"pad dimensions"`<br>`"pad by multiplier"`<br>`"pad to multiple"` |
| `left` | Пиксели, добавляемые слева. Доступно, когда `padding_type` имеет значение `"pad dimensions"` (по умолчанию: 0). | INT | Да | 0–16384 |
| `top` | Пиксели, добавляемые сверху. Доступно, когда `padding_type` имеет значение `"pad dimensions"` (по умолчанию: 0). | INT | Да | 0–16384 |
| `right` | Пиксели, добавляемые справа. Доступно, когда `padding_type` имеет значение `"pad dimensions"` (по умолчанию: 0). | INT | Да | 0–16384 |
| `bottom` | Пиксели, добавляемые снизу. Доступно, когда `padding_type` имеет значение `"pad dimensions"` (по умолчанию: 0). | INT | Да | 0–16384 |
| `multiplier` | Размер вывода относительно ввода; например, 1.5 добавляет по 25% с каждой стороны. Отступы распределяются равномерно между противоположными сторонами. Доступно, когда `padding_type` имеет значение `"pad by multiplier"` (по умолчанию: 1.0). | FLOAT | Да | 1.0–8.0 (шаг 0.01) |
| `multiple` | Добавить отступы так, чтобы ширина и высота делились на это число. Отступы распределяются равномерно между противоположными сторонами, а лишний пиксель добавляется справа и снизу. Доступно, когда `padding_type` имеет значение `"pad to multiple"` (по умолчанию: 32). | INT | Да | 1–16384 |
| `padding_style` | Чем заполнить область отступов: `"color"` или `"mirror image"`. При выборе опции отображаются её параметры. | DYNAMIC_COMBO | Да | `"color"`<br>`"mirror image"` |
| `color` | Цвет заливки для области отступов; альфа-канал игнорируется. Доступно, когда `padding_style` имеет значение `"color"` (по умолчанию: `"#000000"`). | COLOR | Да | - |
| `feathering` | Смешать указанное количество пикселей края изображения с цветом заливки на сторонах с отступами. 0 оставляет резкий край. Доступно, когда `padding_style` имеет значение `"color"` (по умолчанию: 0). | INT | Да | 0–16384 |

`"mirror image"` отражает края изображения вместо заливки цветом. Краевой пиксель не повторяется, и если отступ шире или выше самого изображения, зеркальное изображение повторяется, чтобы заполнить остаток. Если все значения отступов равны 0, входное изображение возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Изображение с отступами, с размером батча и количеством каналов входного изображения. | IMAGE |
