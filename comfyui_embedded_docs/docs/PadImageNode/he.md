# Pad Image

מוסיף ריפוד לתמונה באמצעות צבע אחיד או עותק משוקף של שוליה. ניתן להגדיר את הריפוד כפיקסלים מדויקים בכל צד, כמכפיל גודל, או ככמות הקטנה ביותר שמביאה לכך שהרוחב והגובה יתחלקו במספר, מה ששימושי לפני שמירה או יצירת ריצוף. התמונה המקורית נשארת במקומה: ריפוד `left` ו-`top` מתווסף לפניה, וריפוד `right` ו-`bottom` אחריה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | התמונה שעבורה יש להוסיף ריפוד. | IMAGE | כן | - |
| `padding_type` | כמות הריפוד להוספה: `"pad dimensions"` עבור כמויות מדויקות לכל צד, `"pad by multiplier"` עבור גודל פלט יחסי לקלט, או `"pad to multiple"` כדי להגיע לכפולה הבאה. בחירת אפשרות חושפת את הפרמטרים שלה. | DYNAMIC_COMBO | כן | `"pad dimensions"`<br>`"pad by multiplier"`<br>`"pad to multiple"` |
| `left` | פיקסלים להוספה בצד שמאל. זמין כאשר `padding_type` הוא `"pad dimensions"` (ברירת מחדל: 0). | INT | כן | 0 עד 16384 |
| `top` | פיקסלים להוספה בצד למעלה. זמין כאשר `padding_type` הוא `"pad dimensions"` (ברירת מחדל: 0). | INT | כן | 0 עד 16384 |
| `right` | פיקסלים להוספה בצד ימין. זמין כאשר `padding_type` הוא `"pad dimensions"` (ברירת מחדל: 0). | INT | כן | 0 עד 16384 |
| `bottom` | פיקסלים להוספה בצד למטה. זמין כאשר `padding_type` הוא `"pad dimensions"` (ברירת מחדל: 0). | INT | כן | 0 עד 16384 |
| `multiplier` | גודל הפלט ביחס לקלט, לדוגמה 1.5 מוסיף 25% בכל צד. הריפוד מתחלק באופן שווה בין צדדים מנוגדים. זמין כאשר `padding_type` הוא `"pad by multiplier"` (ברירת מחדל: 1.0). | FLOAT | כן | 1.0 עד 8.0 (צעד: 0.01) |
| `multiple` | מרפד כך שהרוחב והגובה יתחלקו במספר זה. הריפוד מתחלק באופן שווה בין צדדים מנוגדים, כאשר הפיקסל הנוסף הולך לימין ולמטה. זמין כאשר `padding_type` הוא `"pad to multiple"` (ברירת מחדל: 32). | INT | כן | 1 עד 16384 |
| `padding_style` | במה למלא את אזור הריפוד: `"color"` או `"mirror image"`. בחירת אפשרות חושפת את הפרמטרים שלה. | DYNAMIC_COMBO | כן | `"color"`<br>`"mirror image"` |
| `color` | צבע המילוי עבור אזור הריפוד; אלפא אינה נלקחת בחשבון. זמין כאשר `padding_style` הוא `"color"` (ברירת מחדל: `"#000000"`). | COLOR | כן | - |
| `feathering` | מערבב מספר זה של פיקסלים משולי התמונה אל צבע המילוי בצדדים המרופדים. 0 משאיר קצה חד. זמין כאשר `padding_style` הוא `"color"` (ברירת מחדל: 0). | INT | כן | 0 עד 16384 |

`"mirror image"` משקף את שולי התמונה במקום למלא אותם בצבע. פיקסל השוליים אינו משוכפל, וכאשר הריפוד רחב או גבוה מהתמונה עצמה, התמונה המשוקפת חוזרת על עצמה כדי לכסות את היתר. כאשר כל כמויות הריפוד יוצאות 0, תמונת הקלט מוחזרת ללא שינוי.
