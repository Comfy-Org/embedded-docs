# Breeze Voice Clone

Создаёт голос Breeze из записи одного диктора. Голос сохраняется в вашей учётной записи и возвращается в виде идентификатора голоса вместе с аудиопредпросмотром того, как он звучит.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Запись одного диктора длительностью не менее 3 секунд. Используются только первые 60 секунд. | AUDIO | Да | - |
| `remove_background_noise` | Очищает запись перед клонированием. По умолчанию: false. | BOOLEAN | Нет | true<br>false |
| `seed` | Управляет тем, будет ли узел выполняться повторно; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voice` | Новый голос Breeze для Breeze Text to Speech. | BREEZE_VOICE |
| `preview` | Аудиопредпросмотр клонированного голоса. | AUDIO |
