# Breeze Voice Clone

یک صدای Breeze از ضبط یک گوینده ایجاد می‌کند. صدا در حساب شما ذخیره می‌شود و به‌صورت یک شناسه صدا، همراه با پیش‌نمایش صوتی نحوهٔ شنیده‌شدن آن، بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `audio` | ضبط یک گوینده، با حداقل ۳ ثانیه طول. فقط ۶۰ ثانیه اول استفاده می‌شود. | AUDIO | بله | - |
| `remove_background_noise` | ضبط را پیش از کلون‌سازی تمیز می‌کند. پیش‌فرض: false. | BOOLEAN | خیر | true<br>false |
| `seed` | کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج صرف‌نظر از seed غیرقطعی هستند. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `voice` | صدای جدید Breeze، برای Breeze Text to Speech. | BREEZE_VOICE |
| `preview` | پیش‌نمایش صوتی صدای کلون‌شده. | AUDIO |
