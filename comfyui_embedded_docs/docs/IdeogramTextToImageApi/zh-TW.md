# Ideogram 4.5 Text to Image

使用 Ideogram 4.5 從文字提示生成影像。提示也接受 Ideogram 結構化 JSON 標題，例如先前執行回傳的 `final_prompt`，可精確控制文字字串、顏色與版面配置。此節點會回傳生成的影像，以及實際用於生成該影像的標題。

### 參數限制

- **必須提供提示：** 提示必須至少包含一個非空白字元，且最多 10000 個字元。當你提供自己的 JSON 標題或精確措辭時，請將 `magic_prompt` 設為 `"off"`。
- **尺寸：** `"auto"` 讓模型自行選擇。`(2K)` 預設集的長邊約為 2048 px，`(1K)` 預設集約為 1024 px；預設集的長寬比會受到遵循。僅預設集的像素尺寸部分會傳送至 API。
- **可重現性：** 當 `magic_prompt` 設為 `"auto"` 或 `"on"` 時，提示會在每次執行時被改寫，因此相同種子仍可能產生不同影像。若要重現影像，請將其 `final_prompt` 回饋輸入，並將 `magic_prompt` 設為 `"off"` 且使用相同種子。
- **內容安全：** 如果 Ideogram 的內容安全篩選器封鎖生成，節點會引發錯誤，而不是回傳影像。
