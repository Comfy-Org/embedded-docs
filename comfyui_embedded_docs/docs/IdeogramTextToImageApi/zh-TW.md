# Ideogram 4.5 文字轉圖像

### 參數限制

- **提示：** 至少需有一個非空白字元，最多 10000 個字元。提供自訂 JSON 說明文字時，請將 `magic_prompt` 設為 `"off"`。
- **自訂尺寸（4.6）：** 寬度乘以高度不得超過 16,777,216 像素（4096x4096），每一邊必須介於 256 至 8192 之間並對齊為 32 的倍數，且長邊不得超過短邊的 6 倍。
- **`very_low` 品質（4.6）：** 上限為 4,194,304 像素（2048x2048）；更大的尺寸會引發錯誤。
- **可重現性：** 當 `magic_prompt` 設為 `"auto"` 或 `"on"` 時，提示會在每次執行時改寫，因此相同的種子值可能產生不同的影像。
- **內容安全：** 若 Ideogram 的內容安全篩選器阻擋生成，此節點會引發錯誤，而非回傳影像。
