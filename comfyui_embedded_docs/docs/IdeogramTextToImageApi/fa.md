# Ideogram 4.5 Text to Image

تصاویر را از یک پرامپت متنی با Ideogram 4.5 تولید کنید. این پرامپت همچنین می‌تواند یک کپشن JSON ساختاریافته Ideogram را بپذیرد، برای مثال `final_prompt` بازگشتی از یک اجرای قبلی، که کنترل دقیق روی رشته‌های متنی، رنگ‌ها و چیدمان می‌دهد. این گره تصویر(های) تولیدشده را همراه با کپشنی که تصویر واقعاً از آن تولید شده است بازمی‌گرداند.

### محدودیت‌های پارامترها

- **پرامپت الزامی:** پرامپت باید حداقل یک کاراکتر غیرفاصله و حداکثر 10000 کاراکتر داشته باشد. زمانی که کپشن JSON خودتان یا جمله‌بندی دقیق را ارائه می‌دهید، `magic_prompt` را روی `"off"` تنظیم کنید.
- **اندازه:** `"auto"` اجازه می‌دهد مدل انتخاب کند. پیش‌تنظیم‌های `(2K)` حدود 3 تا 4 مگاپیکسل و پیش‌تنظیم‌های `(1K)` حدود 1 مگاپیکسل هستند؛ برچسب سطح بودجهٔ پیکسل را توصیف می‌کند نه یک ضلع بلند ثابت، و نسبت تصویر پیش‌تنظیم رعایت می‌شود. فقط بخش اندازه پیکسلی پیش‌تنظیم به API فرستاده می‌شود.
- **قابلیت بازتولید:** با `magic_prompt` روی `"auto"` یا `"on"`، پرامپت در هر اجرا بازنویسی می‌شود، بنابراین همان Seed ممکن است همچنان تصویر متفاوتی تولید کند. برای بازتولید یک تصویر، `final_prompt` آن را با `magic_prompt` روی `"off"` و همان Seed دوباره وارد کنید.
- **ایمنی محتوا:** اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، گره به‌جای بازگرداندن تصویر خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) تولیدشده به‌صورت یک دسته. | IMAGE |
