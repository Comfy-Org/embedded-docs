# تبدیل متن به تصویر با Ideogram 4.5

تولید تصویر از یک prompt متنی با Ideogram 4.6 یا 4.5. این prompt همچنین یک کپشن JSON ساختاریافتهٔ Ideogram را می‌پذیرد؛ مثلاً `final_prompt` بازگردانده‌شده از یک اجرای قبلی، که کنترل دقیق روی رشته‌های متنی، رنگ‌ها و چیدمان می‌دهد. این گره تصویر را همراه با کپشنی که تصویر در واقع از آن تولید شده است برمی‌گرداند.

## ورودی‌ها

انتخاب `model` تعیین می‌کند کدام ورودی‌ها نمایش داده شوند. Ideogram 4.6 گزینه‌های `background`، سطح کیفیت `very_low`، اندازه‌های `(4K)` و عرض و ارتفاع سفارشی را اضافه می‌کند؛ 4.5 پیش‌تنظیم‌های `(1K)` و `(2K)` را نگه می‌دارد.

### محدودیت‌های پارامترها

- **prompt:** حداقل یک نویسهٔ غیرفاصله و حداکثر 10000 نویسه. وقتی کپشن JSON خودتان را ارائه می‌دهید، `magic_prompt` را روی `"off"` قرار دهید.
- **اندازهٔ سفارشی (4.6):** عرض ضربدر ارتفاع نباید از 16.7 مگاپیکسل (4096x4096) بیشتر شود؛ هر ضلع باید بین 256 و 8192 باشد و به مضربی از 32 گرد شود؛ و ضلع بلندتر نباید از 6 برابر ضلع کوتاه‌تر بیشتر شود.
- **کیفیت `very_low` (4.6):** محدود به 4 مگاپیکسل (2048x2048)؛ اندازه‌های بزرگ‌تر خطا ایجاد می‌کنند.
- **بازتولیدپذیری:** وقتی `magic_prompt` روی `"auto"` یا `"on"` باشد، prompt در هر اجرا بازنویسی می‌شود، بنابراین همان بذر می‌تواند تصویر متفاوتی تولید کند.
- **ایمنی محتوا:** اگر فیلتر ایمنی محتوای Ideogram تولید را مسدود کند، گره به‌جای برگرداندن تصویر خطا ایجاد می‌کند.
