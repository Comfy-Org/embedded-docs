# Ideogram 4.5 Text to Image

Генерируйте изображения по текстовому промпту с помощью Ideogram 4.5. Промпт также принимает структурированную JSON-подпись Ideogram, например `final_prompt`, возвращённый предыдущим запуском, что даёт точный контроль над текстовыми строками, цветами и компоновкой. Узел возвращает сгенерированное изображение(я) вместе с подписью, на основе которой изображение фактически было сгенерировано.

### Ограничения параметров

- **Промпт обязателен:** промпт должен содержать хотя бы один непробельный символ и не более 10000 символов. Установите `magic_prompt` в `"off"`, если передаёте собственную JSON-подпись или точную формулировку.
- **Размер:** `"auto"` позволяет модели выбрать. Пресеты `(2K)` — около 2048 px по длинной стороне, а `(1K)` — около 1024 px; соотношение сторон пресета соблюдается. В API передаётся только часть пресета, отвечающая за размер в пикселях.
- **Воспроизводимость:** при `magic_prompt` в `"auto"` или `"on"` промпт переписывается при каждом запуске, поэтому один и тот же сид всё равно может дать другое изображение. Чтобы воспроизвести изображение, подайте его `final_prompt` обратно с `magic_prompt` в `"off"` и тем же сидом.
- **Безопасность контента:** если фильтр безопасности контента Ideogram блокирует генерацию, узел вызывает ошибку вместо возврата изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение(я) в виде батча. | IMAGE |
| `final_prompt` | Структурированная подпись, на основе которой было сгенерировано изображение. Подайте её обратно с `magic_prompt` в `"off"` и тем же сидом, чтобы воспроизвести изображение. | STRING |
