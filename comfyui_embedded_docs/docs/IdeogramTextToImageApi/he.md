# IdeogramTextToImageApi

צור תמונות מהנחיית טקסט עם Ideogram 4.5. ההנחיה מקבלת גם כיתוב JSON מובנה של Ideogram, לדוגמה `final_prompt` שהוחזר בהרצה קודמת, מה שמאפשר שליטה מדויקת במחרוזות טקסט, צבעים ופריסה. הצומת מחזיר את התמונה/התמונות שנוצרו יחד עם הכיתוב שממנו התמונה נוצרה בפועל.

### אילוצי פרמטרים

- **הנחיה נדרשת:** ההנחיה חייבת להכיל לפחות תו אחד שאינו רווח ולכל היותר 10000 תווים. הגדר `magic_prompt` ל-`"off"` כאשר אתה מספק כיתוב JSON משלך או ניסוח מדויק.
- **גודל:** `"auto"` נותן למודל לבחור. פריסטים `(2K)` הם בערך 3 עד 4 מגה-פיקסלים ופריסטים `(1K)` בערך 1 מגה-פיקסל, לכן תווית הדירוג מתארת את תקציב הפיקסלים ולא צלע ארוכה קבועה; יחס הגובה-רוחב של הפריסט נשמר. רק חלק גודל הפיקסלים של הפריסט נשלח ל-API.
- **יכולת שחזור:** כאשר `magic_prompt` מוגדר ל-`"auto"` או `"on"`, ההנחיה נכתבת מחדש בכל הרצה, כך שאותו זרע עדיין יכול להפיק תמונה שונה. כדי לשחזר תמונה, הזן בחזרה את `final_prompt` שלה כאשר `magic_prompt` מוגדר ל-`"off"` ואותו זרע.
- **בטיחות תוכן:** אם מסנן בטיחות התוכן של Ideogram חוסם את היצירה, הצומת מעלה שגיאה במקום להחזיר תמונה.
