# ByteDance תמונה לוידאו

הצומת ByteDance Image to Video יוצר סרטונים באמצעות מודלים של ByteDance דרך API, בהתבסס על תמונת קלט ופרומפט טקסטואלי. הוא מקבל פריים תמונה התחלתי ויוצר רצף וידאו שעוקב אחר התיאור שסופק. הצומת מציע אפשרויות התאמה אישית שונות לרזולוציית הווידאו, יחס הממדים, משך הזמן ופרמטרי יצירה אחרים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ByteDance לשימוש ביצירת וידאו (ברירת מחדל: `"seedance-1-0-pro-fast-251015"`). | COMBO | כן | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `prompt` | הפרומפט הטקסטואלי המשמש ליצירת הווידאו. חייב להכיל לפחות תו אחד לאחר הסרת רווחים בהתחלה ובסוף. | STRING | כן | - |
| `image` | הפריים הראשון שישמש עבור הווידאו. חייב להיות בין 300x300 ל-6000x6000 פיקסלים, עם יחס ממדים בין 0.4 ל-2.5. | IMAGE | כן | - |
| `resolution` | הרזולוציה של סרטון הפלט. | COMBO | כן | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | יחס הממדים של סרטון הפלט. | COMBO | כן | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | משך סרטון הפלט בשניות (ברירת מחדל: 5). עבור המודל `seedance-1-5-pro-251215`, משך הזמן המינימלי הנתמך הוא 4 שניות. | INT | כן | 3 - 12 |
| `seed` | ערך ה-seed שישמש ליצירה (ברירת מחדל: 0). | INT | לא | 0 - 2147483647 |
| `camera_fixed` | מציין האם לקבע את המצלמה. הפלטפורמה מוסיפה הוראה לקבע את המצלמה לפרומפט שלך, אך אינה מבטיחה את האפקט בפועל (ברירת מחדל: False). | BOOLEAN | לא | `False`<br>`True` |
| `watermark` | האם להוסיף סימן מים "AI generated" לסרטון (ברירת מחדל: False). | BOOLEAN | לא | `False`<br>`True` |
| `generate_audio` | פרמטר זה מתעלמים ממנו עבור כל מודל מלבד `seedance-1-5-pro-251215` (ברירת מחדל: False). | BOOLEAN | לא | `False`<br>`True` |

**הערה:** הפרומפט לא יכול להכיל את המילים הבאות (ללא תלות ברישיות): `resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`. פרמטרים אלה מוגדרים דרך הקלטים הייעודיים שלהם.
