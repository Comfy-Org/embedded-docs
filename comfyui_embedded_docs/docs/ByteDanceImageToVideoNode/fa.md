# تبدیل تصویر به ویدیو ByteDance

گره ByteDance Image to Video ویدئوهایی را با استفاده از مدل‌های ByteDance از طریق یک API و بر اساس تصویر ورودی و پرامپت متنی تولید می‌کند. این گره یک فریم تصویر آغازین را می‌گیرد و یک دنباله ویدئویی مطابق با توضیحات ارائه‌شده ایجاد می‌کند. این گره گزینه‌های سفارشی‌سازی متنوعی برای رزولوشن ویدئو، نسبت ابعاد، مدت‌زمان و سایر پارامترهای تولید ارائه می‌دهد.

**توجه:** BytePlus مدل Seedance 1.5 Pro را در ۱۱ نوامبر ۲۰۲۶ متوقف می‌کند، بنابراین این گره دیگر آن را ارائه نمی‌دهد و ورک‌فلوهای ذخیره‌شده با آن از کار می‌افتند. به‌جای آن از `seedance-1-0-pro-250528`، `seedance-1-0-pro-fast-251015` یا [گره شریک Seedance 2.5](https://docs.comfy.org/fa/tutorials/partner-nodes/bytedance/seedance-2-5) استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل ByteDance برای تولید ویدئو (پیش‌فرض: `"seedance-1-0-pro-fast-251015"`). | COMBO | بله | `"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `پرامپت` | پرامپت متنی برای تولید ویدئو. باید پس از حذف فاصله‌های اضافی حداقل 1 کاراکتر باشد. | STRING | بله | - |
| `تصویر` | فریم اول مورد استفاده برای ویدئو. باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت ابعاد آن بین 0.4 و 2.5 قرار گیرد. | IMAGE | بله | - |
| `رزولوشن` | رزولوشن ویدئوی خروجی. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبت تصویر` | نسبت ابعاد ویدئوی خروجی. | COMBO | بله | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `مدت زمان` | مدت‌زمان ویدئوی خروجی بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 - 12 |
| `seed` | مقدار seed برای تولید (پیش‌فرض: 0). | INT | خیر | 0 - 2147483647 |
| `ثابت بودن دوربین` | مشخص می‌کند آیا دوربین ثابت بماند یا نه. پلتفرم یک دستور برای ثابت کردن دوربین به پرامپت شما اضافه می‌کند، اما اثر واقعی را تضمین نمی‌کند (پیش‌فرض: False). | BOOLEAN | خیر | `False`<br>`True` |
| `واترمارک` | آیا واترمارک «AI generated» به ویدئو اضافه شود (پیش‌فرض: False). | BOOLEAN | خیر | `False`<br>`True` |
| BOOLEAN | خیر | `False`<br>`True` |

**توجه:** پرامپت نباید شامل واژه‌های زیر باشد (بدون حساسیت به بزرگی و کوچکی حروف): `resolution`، `ratio`، `duration`، `seed`، `camerafixed`، `watermark`. این پارامترها از طریق ورودی‌های اختصاصی خود تنظیم می‌شوند.
