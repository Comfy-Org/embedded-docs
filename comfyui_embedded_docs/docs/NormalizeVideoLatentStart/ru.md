# NormalizeVideoLatentStart

Этот узел корректирует первые несколько кадров латентного представления видео, чтобы они больше походили на последующие кадры. Он вычисляет среднее значение и вариацию на основе набора опорных кадров, расположенных дальше в видео, и применяет те же характеристики к начальным кадрам. Это помогает создать более плавный и согласованный визуальный переход в начале видео.

## Входные параметры

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Латентное представление видео для обработки. | LATENT | Да | - |
| `start_frame_count` | Количество латентных кадров для нормализации, начиная с начала (по умолчанию: 4). | INT | Да | от 1 до 16384 (максимальное разрешение) |
| `reference_frame_count` | Количество латентных кадров после начальных кадров, используемых в качестве опорных (по умолчанию: 5). | INT | Да | от 1 до 16384 (максимальное разрешение) |

**Примечание:** `reference_frame_count` автоматически ограничивается количеством кадров, доступных после начальных кадров. Если латентное представление видео содержит только один кадр, нормализация не выполняется, и исходное латентное представление возвращается без изменений.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Обработанное латентное представление видео с нормализованными начальными кадрами. | LATENT |
