# NormalizeVideoLatentStart

Этот узел корректирует первые несколько кадров латентного представления видео, чтобы они выглядели более похожими на последующие кадры. Он вычисляет среднее значение и вариацию на основе набора эталонных кадров, расположенных далее в видео, и применяет эти же характеристики к начальным кадрам. Это помогает создать более плавный и согласованный визуальный переход в начале видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Латентное представление видео для обработки. | LATENT | Да | - |
| `start_frame_count` | Количество латентных кадров для нормализации, считая с начала (по умолчанию: 4). | INT | Да | 1 до 16384 (max resolution) |
| `reference_frame_count` | Количество латентных кадров после начальных кадров, используемых в качестве эталона (по умолчанию: 5). | INT | Да | 1 до 16384 (max resolution) |

**Примечание:** Значение `reference_frame_count` автоматически ограничивается количеством кадров, доступных после начальных кадров. Если латентное представление видео состоит всего из 1 кадра, нормализация не выполняется, и исходное латентное представление возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Обработанное латентное представление видео с нормализованными начальными кадрами. | LATENT |
