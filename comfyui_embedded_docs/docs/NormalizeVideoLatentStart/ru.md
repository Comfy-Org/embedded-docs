# NormalizeVideoLatentStart

Этот узел корректирует первые несколько кадров латентного представления видео, чтобы они больше походили на кадры, идущие после них. Он вычисляет среднее и вариацию по набору эталонных кадров, расположенных позже в видео, и применяет те же характеристики к начальным кадрам. Это помогает уменьшить различия между начальными кадрами и остальной частью видео, создавая более плавный и согласованный переход.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Латентное представление видео для обработки. | LATENT | Да | - |
| `start_frame_count` | Количество латентных кадров для нормализации, отсчитываемое от начала (по умолчанию: 4). | INT | Да | от 1 до 16384 (макс. разрешение) |
| `reference_frame_count` | Количество латентных кадров после начальных, используемых в качестве эталонных (по умолчанию: 5). | INT | Да | от 1 до 16384 (макс. разрешение) |

**Примечание:** Эталонные кадры берутся сразу после кадров `start_frame_count`. Если доступно меньше кадров, чем запрашивает `reference_frame_count`, узел использует столько, сколько доступно (не более чем на один меньше общего числа кадров латента). Если латент видео содержит только 1 кадр, нормализация не выполняется, и исходный латент возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Обработанное латентное представление видео с нормализованными начальными кадрами. | LATENT |
