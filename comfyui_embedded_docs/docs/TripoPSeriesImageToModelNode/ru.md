# Tripo P2: Из изображения в модель

Создаёт низкополигональную 3D-модель с чистой топологией из одного изображения с помощью модели P2 от Tripo. Результат возвращается в виде треугольной сетки (GLB) или, когда включён `model.quad`, в виде преимущественно четырёхугольной сетки (FBX).

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель серии P от Tripo для использования. При выборе модели ниже отображаются её собственные входы. | DYNAMIC_COMBO | Да | `"P2"` |

### Входы P2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.image` | Изображение, из которого генерируется модель. | IMAGE | Да | - |
| `quad` | Возвращать преимущественно четырёхугольную сетку на выходе FBX вместо треугольной сетки на выходе GLB (по умолчанию: False). | BOOLEAN | Да | True/False |
| `face_limit` | Целевое количество полигонов. `-1` позволяет Tripo выбрать самостоятельно. При включённом `model.quad` ограничение составляет от 48 до 25 000, иначе от 48 до 50 000 (по умолчанию: -1). | INT | Да | -1, или от 48 до 50 000 |
| `texture` | Разрешение текстуры базового цвета: standard — 2K, detailed — 4K, extreme — 8K. `"none"` возвращает сетку без текстуры (по умолчанию: `"standard"`). | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"`<br>`"none"` |
| `pbr` | Добавлять карты металличности, шероховатости и нормалей к базовому цвету. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: True). | BOOLEAN | Да | True/False |
| `model_seed` | Сид для геометрии (по умолчанию: 42). | INT | Да | 0 до 2147483647 |
| `texture_alignment` | Сопоставлять цвета входного изображения или подгонять текстуры под сгенерированную геометрию. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: `"original_image"`). Дополнительная настройка. | COMBO | Да | `"original_image"`<br>`"geometry"` |
| `orientation` | `"align_image"` поворачивает модель к точке обзора входного изображения. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: `"default"`). Дополнительная настройка. | COMBO | Да | `"default"`<br>`"align_image"` |
| `enable_image_autofix` | Позволить Tripo улучшить изображение низкого разрешения или низкого качества перед моделированием (по умолчанию: False). Дополнительная настройка. | BOOLEAN | Да | True/False |
| `texture_seed` | Сид для текстур (по умолчанию: 42). Дополнительная настройка. | INT | Да | 0 до 2147483647 |
| `auto_size` | Масштабировать модель до её реального размера в метрах через преобразование сцены. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: False). Дополнительная настройка. | BOOLEAN | Да | True/False |
| `export_uv` | Создавать UV-развёртку сетки, когда она без текстуры. Сетки с текстурами всегда разворачиваются (по умолчанию: True). Дополнительная настройка. | BOOLEAN | Да | True/False |
| `compress_geometry` | Применять сжатие геометрии meshopt: файлы становятся намного меньше, но 3D-предпросмотр ComfyUI не может их отображать. Игнорируется для четырёхугольных сеток (по умолчанию: False). Дополнительная настройка. | BOOLEAN | Да | True/False |

**Примечания:**

- `model.image` обязателен, и используется только первое изображение из пакета.
- `model.face_limit` — это целевое значение, а не жёсткое ограничение, поэтому результат может содержать больше полигонов, чем запрошено. `-1` оставляет выбор Tripo.
- `model.quad` определяет, на каком выходе будет сетка. Если он включён, модель поступает на выход FBX, а выход GLB остаётся пустым; если отключён, модель поступает на GLB, а FBX остаётся пустым. Узел выдаёт ошибку, если пустым оказывается тот выход, к которому вы подключились.
- `model.texture`, `model.pbr`, `model.texture_seed`, `model.auto_size`, `model.texture_alignment` и `model.orientation` применяются только к моделям с текстурами: при `"none"` узел не отправляет настройки текстуры и возвращает геометрию без текстуры.
- `model.compress_geometry` не влияет на четырёхугольные сетки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model task_id` | Уникальный ID задачи для запроса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пустой, когда включён `model.quad`. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только тогда, когда включён `model.quad`. | FILE3DFBX |
