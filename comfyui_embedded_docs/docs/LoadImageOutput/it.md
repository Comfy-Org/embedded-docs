# LoadImageOutput

Il nodo LoadImageOutput carica le immagini dalla cartella di output. Quando fai clic sul pulsante di aggiornamento, aggiorna l'elenco delle immagini disponibili e seleziona automaticamente la prima, rendendo facile scorrere le immagini generate.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `image` | Carica un'immagine dalla cartella di output. Include un'opzione di caricamento e un pulsante di aggiornamento per aggiornare l'elenco delle immagini. Quando si fa clic sul pulsante di aggiornamento, il nodo aggiorna l'elenco delle immagini e seleziona automaticamente la prima immagine, consentendo di scorrere facilmente. | COMBO | Sì | Opzioni multiple disponibili |

## Output

| Nome output | Descrizione | Tipo di dato |
| --- | --- | --- |
| `image` | L'immagine caricata dalla cartella di output | IMAGE |
| `mask` | La maschera associata all'immagine caricata | MASK |
