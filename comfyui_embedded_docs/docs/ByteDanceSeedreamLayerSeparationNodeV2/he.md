# ByteDance Seedream 5.0 הפרדת שכבות

ByteDance Seedream 5.0 Layer Separation מפרק תמונה לרקע בסיסי בתוספת עד 16 שכבות שקופות הניתנות למיקום מחדש, שלכל אחת מהן סדר שכבות, תיבת תיחום, שם ותיאור. הוא מחזיר את הרקע, תמונות לפי שכבות עם מסכות, תיבות מיקום וערימת שכבות מוכנה לעריכה. הבורר `model` בוחר בין Seedream 5.0 Pro ל- Seedream 5.0 Flash המהיר יותר.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-Seedream המשמש להפרדה. "seedream 5.0 pro" (ברירת מחדל) מספק את איכות ההפרדה הגבוהה ביותר וגם חושף בקרת `prompt_optimization`; "seedream 5.0 flash" מהיר וזול יותר ואין לו בקרת אופטימיזציית פרומפט. | DYNAMIC_COMBO | כן | "seedream 5.0 pro"<br>"seedream 5.0 flash" |

### קלטים של Seedream 5.0 Pro ו-5.0 Flash

קלטים אלה זמינים עם שני המודלים.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שיש להפריד. תמונה אחת בדיוק, לפחות 512x512 פיקסלים, יחס רוחב-גובה בין 1:16 ל-16:1. קלטים גדולים מכ-4MP מוקטנים לפני העלאה. | IMAGE | כן | תמונה בודדת |
| `prompt` | כיצד להפריד את התמונה. השאר ריק כדי לזהות אוטומטית ולהפריד את כל האלמנטים העיקריים. תאר אלמנטים בשפה טבעית כדי לשלוט בהפרדה, או כוון לאזורים מדויקים באמצעות תגי `<bbox>left top right bottom</bbox>` (קואורדינטות ביחידות פרומיל 0-1000). ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `size` | רמת רזולוציית הפלט. "auto" עוקב אחר גודל תמונת הקלט (מוגבל לטווח 1K-2K). ברירת מחדל: "auto". | COMBO | כן | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | ערך Seed לשימוש ביצירה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |
| `watermark` | האם להוסיף סימן מים "AI generated" לתמונות. ברירת מחדל: false. | BOOLEAN | כן | false<br>true |
| `crop_layers` | גאומטריה של פלטי אצוות השכבות/מסכות (`layer_stack` אינו מושפע ותמיד חתוך באופן צמוד). קנבס מלא: כל שכבה על קנבס בגודל הבסיס במיקום תיבת התיחום שלה - הרכב מחדש ישירות עם ImageCompositeMasked. גודל מזערי: כל שכבה נחתכת לתיבת התיחום שלה (מרופדת לשכבה הגדולה ביותר לצורך אצווה) - טנסורים קטנים בהרבה; בנה מחדש את המיקום עם Layers From Bounding Boxes באמצעות פלט `bboxes`. ברירת מחדל: false (קנבס מלא). | BOOLEAN | כן | false (קנבס מלא)<br>true (גודל מזערי) |

### קלטים של Seedream 5.0 Pro בלבד

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt_optimization` | מצב אופטימיזציית פרומפט: "standard" נותן איכות גבוהה יותר, "fast" זמן יצירה קצר יותר. זמין רק עם Seedream 5.0 Pro. ברירת מחדל: "standard". | COMBO | כן | "standard"<br>"fast" |

**הערה:** הקלט `image` חייב להיות תמונה בודדת; אצוות אינן נתמכות. התמונה חייבת להיות לפחות 512x512 פיקסלים עם יחס רוחב-גובה בין 1:16 ל-16:1. ל-Seedream 5.0 Flash אין קלט `prompt_optimization`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `base_image` | תמונת הבסיס (לוח הרקע) שעליה נערמות השכבות. | IMAGE |
| `base_mask` | שקיפות תמונת הבסיס (1 = שקוף, לפי מוסכמת LoadImage); נכון לעכשיו תמיד אטום לחלוטין. | MASK |
| `layers` | שכבות שקופות מסודרות מלמטה למעלה. מצב קנבס מלא: ממוקמות על קנבס שחור בגודל הבסיס במיקום תיבת התיחום שלהן. מצב גודל מזערי: נחתכות לתיבת התיחום שלהן, מעוגנות בפינה השמאלית העליונה, ומרופדות לשכבה הגדולה ביותר. | IMAGE |
| `masks` | שקיפות לפי שכבה, מיושרת לפי אינדקס עם אצוות `layers` (1 = שקוף, לפי מוסכמת LoadImage). להרכבה בסגנון ImageCompositeMasked, הוסף InvertMask תחילה. | MASK |
| `bboxes` | תיבת מיקום אחת לכל שכבה, מיושרת לפי אינדקס עם אצוות `layers` (הזן את שתיהן, יחד עם `masks`, אל Layers From Bounding Boxes כדי לבנות מחדש מיקום לפי שכבה): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` הוא אזור התוכן של השכבה בתוך המסגרת שלה; הוא נוחת על הקנבס במיקום התיבה בתוספת ההיסט הזה. | BOUNDING_BOX |
| `layer_stack` | מסמך שכבות מוכן לעריכה עבור Create Layered Image: לוח הבסיס בתוספת כל אלמנט כשכבה נפרדת בעלת שם, חתוכה באופן צמוד, במיקומה האמיתי ובסדר השכבות שלה. חבר ישירות, או הרחב עם Add Layer. | LAYERS |
