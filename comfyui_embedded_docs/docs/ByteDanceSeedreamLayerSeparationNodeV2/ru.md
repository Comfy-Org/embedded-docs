# ByteDance Seedream 5.0 Layer Separation

ByteDance Seedream 5.0 Layer Separation разлагает изображение на фоновую подложку и до 16 перемещаемых прозрачных слоёв, каждый с порядком наложения, ограничивающей рамкой, именем и описанием. Возвращает фон, изображения каждого слоя с масками, рамки размещения и готовый к редактированию стек слоёв. Селектор `model` позволяет выбрать между Seedream 5.0 Pro и более быстрой Seedream 5.0 Flash.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Seedream, используемая для разделения. "seedream 5.0 pro" (по умолчанию) обеспечивает наивысшее качество разделения, а также предоставляет управление `prompt_optimization`; "seedream 5.0 flash" работает быстрее и дешевле, но не имеет управления оптимизацией промпта. | DYNAMIC_COMBO | Да | "seedream 5.0 pro"<br>"seedream 5.0 flash" |

### Входы Seedream 5.0 Pro и 5.0 Flash

Эти входы доступны для обеих моделей.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, которое нужно разделить. Ровно одно изображение, не менее 512x512 пикселей, соотношение сторон от 1:16 до 16:1. Входные изображения размером больше примерно 4 МП масштабируются вниз перед загрузкой. | IMAGE | Да | Одно изображение |
| `prompt` | Как разделять изображение. Оставьте пустым, чтобы автоматически определить и разделить все основные элементы. Описывайте элементы естественным языком, чтобы управлять разделением, или нацельтесь на точные области с помощью тегов `<bbox>left top right bottom</bbox>` (координаты в промилле от 0 до 1000). По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `size` | Уровень разрешения выходного изображения. "auto" следует размеру входного изображения (ограничивается диапазоном 1K–2K). По умолчанию: "auto". | COMBO | Да | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | Сид для генерации. По умолчанию: 42. | INT | Да | 0 до 2147483647 |
| `watermark` | Добавлять ли к изображениям водяной знак "AI generated". По умолчанию: false. | BOOLEAN | Да | false<br>true |
| `crop_layers` | Геометрия пакетных выходов слоёв/масок (`layer_stack` не затрагивается и всегда плотно обрезан). Полное полотно: каждый слой на холсте размером с основу в позиции своей ограничивающей рамки — можно напрямую собрать с помощью ImageCompositeMasked. Минимальный размер: каждый слой обрезается по своей ограничивающей рамке (дополняется до самого большого слоя для пакетной обработки) — тензоры значительно меньше; восстановите размещение с помощью Layers From Bounding Boxes, используя выход `bboxes`. По умолчанию: false (полное полотно). | BOOLEAN | Да | false (полное полотно)<br>true (минимальный размер) |

### Входы только для Seedream 5.0 Pro

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_optimization` | Режим оптимизации промпта: "standard" даёт более высокое качество, "fast" — меньшее время генерации. Доступно только в Seedream 5.0 Pro. По умолчанию: "standard". | COMBO | Да | "standard"<br>"fast" |

**Примечание:** Вход `image` должен быть одним изображением; пакеты не поддерживаются. Изображение должно быть не меньше 512x512 пикселей с соотношением сторон от 1:16 до 16:1. У Seedream 5.0 Flash нет входа `prompt_optimization`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_image` | Базовое изображение (фоновая подложка), на которое накладываются слои. | IMAGE |
| `base_mask` | Прозрачность базового изображения (1 = прозрачный, соглашение LoadImage); в настоящее время всегда полностью непрозрачно. | MASK |
| `layers` | Прозрачные слои, упорядоченные снизу вверх. Режим полного полотна: размещаются на чёрном холсте размером с основу в позиции своей ограничивающей рамки. Режим минимального размера: обрезаются по своей ограничивающей рамке, привязываются к верхнему левому углу, дополняются до самого большого слоя. | IMAGE |
| `masks` | Прозрачность для каждого слоя, выровненная по индексу с пакетом `layers` (1 = прозрачный, соглашение LoadImage). Для композитинга в стиле ImageCompositeMasked сначала добавьте InvertMask. | MASK |
| `bboxes` | Одна рамка размещения на слой, выровненная по индексу с пакетом `layers` (подайте обе эти выходные данные вместе с `masks` в Layers From Bounding Boxes, чтобы восстановить размещение каждого слоя): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` — это область содержимого слоя внутри его собственного кадра; она попадает на холст в позицию рамки плюс это смещение. | BOUNDING_BOX |
| `layer_stack` | Готовый к редактированию документ слоёв для Create Layered Image: базовая подложка плюс каждый элемент как отдельный именованный плотно обрезанный слой в его истинной позиции и порядке наложения. Подключите напрямую или расширьте с помощью Add Layer. | LAYERS |
