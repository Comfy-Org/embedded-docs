# Пустое латентное аудио YuE2

Этот узел создаёт пустой аудиолатент для YuE2 с размером, соответствующим выбранной длительности и размеру пакета. Он создаёт беззвучные данные-заполнители для аудио, которые последующие узлы могут заполнить во время генерации аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seconds` | Длина создаваемого аудиолатента в секундах (по умолчанию: 120.0). Количество латентных кадров вычисляется из этого значения, минимум — 1 кадр. | FLOAT | Да | от 0.04 до 1000.0 (шаг 0.04) |
| `batch_size` | Количество аудиолатентов, создаваемых в одном пакете (по умолчанию: 1). | INT | Да | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Пустой аудиолатент, содержащий тензор нулей, размер которого задаётся `batch_size` и количеством кадров, вычисленным из `seconds`. Помечен как аудиотип с коэффициентом временного уменьшения масштаба 1920. | LATENT |
