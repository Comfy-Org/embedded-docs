# QuiverImageToSVGNode

צומת זה ממיר תמונת רסטר לגרפיקה וקטורית ניתנת להרחבה (SVG) תוך שימוש במודלי הווקטוריזציה של Quiver AI. הוא שולח את התמונה ל-API חיצוני שמעבד אותה ומחזיר את התוצאה הווקטורית.

**הערה:** צומת זה מסומן כמיושן (deprecated) בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת קלט לווקטוריזציה. | IMAGE | כן | N/A |
| `auto_crop` | חיתוך אוטומטי לנושא הדומיננטי (ברירת מחדל: False). | BOOLEAN | כן | True<br>False |
| `model` | מודל לשימוש בווקטוריזציה של SVG. בחירת מודל חושפת פרמטרים נוספים ייחודיים לאותו מודל: `target_size` (יעד שינוי גודל מרובע בפיקסלים; 0 שומר על גודל תמונת המקור, אחרת 128 עד 4096), `temperature`, `top_p`, ו-`presence_penalty`. | DYNAMIC_COMBO | כן | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `seed` | זרע (Seed) לקביעה אם הצומת אמור לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות בערך הזרע. לפרמטר זה יש פונקציונליות "שליטה לאחר יצירה" (ברירת מחדל: 0). | INT | כן | 0 עד 2147483647 |
| `reasoning_effort` | כמה מאמץ חשיבה המודל משקיע לפני הציור. רמות גבוהות יותר משפרות את הפרטים ועולות יותר טוקנים. בשימוש רק במודלי Arrow 2 (ברירת מחדל: "high"). | COMBO | לא | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
