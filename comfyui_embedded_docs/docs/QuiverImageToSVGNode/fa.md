# تبدیل تصویر Quiver به SVG

این گره یک تصویر رستری را با استفاده از مدل‌های برداری‌سازی Quiver AI به یک گرافیک برداری مقیاس‌پذیر (SVG) تبدیل می‌کند. تصویر را به یک API خارجی می‌فرستد که آن را پردازش کرده و نتیجه برداری‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای برداری‌سازی. | IMAGE | بله | N/A |
| `auto_crop` | به‌صورت خودکار به سوژه غالب برش می‌دهد (پیش‌فرض: False). | BOOLEAN | بله | True<br>False |
| `model` | مدل مورد استفاده برای برداری‌سازی SVG. با انتخاب یک مدل، پارامترهای اضافی مخصوص آن مدل نمایش داده می‌شوند: `target_size` (هدف تغییر اندازه مربعی بر حسب پیکسل؛ مقدار 0 اندازه تصویر منبع را حفظ می‌کند، در غیر این صورت 128 تا 4096)، `temperature`، `top_p` و `presence_penalty`. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `seed` | بذر برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به مقدار بذر غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌بخشند و توکن‌های بیشتری مصرف می‌کنند. فقط توسط مدل‌های Arrow 2 استفاده می‌شود (پیش‌فرض: "high"). | COMBO | خیر | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `SVG` | خروجی SVG برداری‌شده. | SVG |
