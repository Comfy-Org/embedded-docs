# تولید ویدیو Google Veo 3

ویدیوهایی از توضیحات متنی با استفاده از API گوگل Veo 3 تولید می‌کند. این گره از چندین مدل Veo 3 از جمله انواع fast و lite پشتیبانی می‌کند و به شما امکان می‌دهد رزولوشن ویدیو، مدت زمان و تولید صدا را مشخص کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | توضیح متنی ویدیو (پیش‌فرض: "") | STRING | بله | - |
| `نسبت تصویر` | نسبت ابعاد ویدیوی خروجی (پیش‌فرض: "16:9") | COMBO | بله | "16:9"<br>"9:16" |
| `وضوح تصویر` | رزولوشن ویدیوی خروجی. رزولوشن 4K برای مدل veo-3.1-lite در دسترس نیست. (پیش‌فرض: "720p") | COMBO | خیر | "720p"<br>"1080p"<br>"4k" |
| `پرامپت منفی` | پیش‌فرمان متنی منفی برای راهنمایی درباره اجتناب از چه چیزهایی در ویدیو (پیش‌فرض: "") | STRING | خیر | - |
| `مدت زمان (ثانیه)` | مدت زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 8) | INT | خیر | 4 - 8 (گام 2) |
| `enhance_prompt` | این پارامتر منسوخ شده و نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `تولید افراد` | آیا اجازه تولید افراد در ویدیو داده شود یا نه (پیش‌فرض: "ALLOW") | COMBO | خیر | "ALLOW"<br>"BLOCK" |
| `seed` | مقدار seed برای تولید ویدیو (0 برای تصادفی) (پیش‌فرض: 0) | INT | خیر | 0 - 4294967295 |
| `تصویر` | تصویر مرجع اختیاری برای هدایت تولید ویدیو | IMAGE | خیر | - |
| `مدل` | مدل Veo 3 برای تولید ویدیو (پیش‌فرض: "veo-3.1-generate") | COMBO | خیر | "veo-3.1-generate"<br>"veo-3.1-fast-generate"<br>"veo-3.1-lite" |
| `تولید صدا` | تولید صدا برای ویدیو. توسط تمام مدل‌های Veo 3 پشتیبانی می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** پارامتر `enhance_prompt` منسوخ شده است و مقدار آن نادیده گرفته می‌شود. این گره همیشه پیش‌فرمان را به‌صورت داخلی بهبود می‌بخشد. اگر با مدل veo-3.1-lite رزولوشن "4k" را انتخاب کنید، گره خطا ایجاد می‌کند.

|-------------|-------------|-----------|
| `output` | فایل ویدیوی تولیدشده | VIDEO |
