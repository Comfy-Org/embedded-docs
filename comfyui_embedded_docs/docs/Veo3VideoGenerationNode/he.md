# Google Veo 3 יצירת וידאו

יוצר סרטונים מפרומפטים טקסטואליים באמצעות ה-API של Veo 3 מבית Google. צומת זה תומך במספר מודלים של Veo 3, כולל גרסאות fast ו-lite, ומאפשר לציין רזולוציית וידאו, משך ויצירת אודיו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור טקסטואלי של הווידאו (ברירת מחדל: "") | STRING | כן | - |
| `aspect_ratio` | יחס גובה-רוחב של וידאו הפלט (ברירת מחדל: "16:9") | COMBO | כן | "16:9"<br>"9:16" |
| `resolution` | רזולוציית וידאו הפלט. 4K אינו זמין עבור המודל veo-3.1-lite. (ברירת מחדל: "720p") | COMBO | לא | "720p"<br>"1080p"<br>"4k" |
| `negative_prompt` | פרומפט טקסט שלילי שמנחה מה להימנע ממנו בווידאו (ברירת מחדל: "") | STRING | לא | - |
| `duration_seconds` | משך וידאו הפלט בשניות (ברירת מחדל: 8) | INT | לא | 4 - 8 (step 2) |
| `enhance_prompt` | פרמטר זה הוצא משימוש ומתעלמים ממנו. (ברירת מחדל: True) | BOOLEAN | לא | - |
| `person_generation` | האם לאפשר יצירת אנשים בווידאו (ברירת מחדל: "ALLOW") | COMBO | לא | "ALLOW"<br>"BLOCK" |
| `seed` | Seed ליצירת וידאו (0 עבור אקראי) (ברירת מחדל: 0) | INT | לא | 0 - 4294967295 |
| `image` | תמונת עזר אופציונלית להנחיית יצירת הווידאו | IMAGE | לא | - |
| `model` | מודל Veo 3 לשימוש ליצירת וידאו (ברירת מחדל: "veo-3.1-generate") | COMBO | לא | "veo-3.1-generate"<br>"veo-3.1-fast-generate"<br>"veo-3.1-lite" |
| `generate_audio` | יצירת אודיו עבור הווידאו. נתמך בכל מודלי Veo 3. (ברירת מחדל: False) | BOOLEAN | לא | - |

**הערה:** הפרמטר `enhance_prompt` הוצא משימוש והערך שלו מתעלמים. הצומת תמיד משפר את הפרומפט באופן פנימי. אם תבחרו ברזולוציה "4k" עם המודל veo-3.1-lite, הצומת תעלה שגיאה.
