# إنشاء فيديو Google Veo 3

يولّد فيديوهات من النصوص الوصفية باستخدام واجهة برمجة تطبيقات Google Veo 3. تدعم هذه العقدة نماذج Veo 3 متعددة، بما في ذلك النسخ السريعة والخفيفة، وتتيح لك تحديد دقة الفيديو ومدته وتوليد الصوت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص_الوصفي` | وصف نصي للفيديو (الافتراضي: "") | STRING | نعم | - |
| `نسبة الأبعاد` | نسبة العرض إلى الارتفاع للفيديو الناتج (الافتراضي: "16:9") | COMBO | نعم | "16:9"<br>"9:16" |
| `الدقة` | دقة الفيديو الناتج. دقة 4K غير متاحة لنموذج veo-3.1-lite. (الافتراضي: "720p") | COMBO | لا | "720p"<br>"1080p"<br>"4k" |
| `النص السلبي` | وصف نصي سلبي لتوجيه ما يجب تجنبه في الفيديو (الافتراضي: "") | STRING | لا | - |
| `المدة بالثواني` | مدة الفيديو الناتج بالثواني (الافتراضي: 8) | INT | لا | 4 - 8 (step 2) |
| `تحسين النص` | هذا المعامل مهمل ويتم تجاهله. (الافتراضي: True) | BOOLEAN | لا | - |
| `إنشاء الأشخاص` | ما إذا كان يُسمح بتوليد أشخاص في الفيديو (الافتراضي: "ALLOW") | COMBO | لا | "ALLOW"<br>"BLOCK" |
| `البذرة` | بذرة لتوليد الفيديو (0 لعشوائي) (الافتراضي: 0) | INT | لا | 0 - 4294967295 |
| `الصورة` | صورة مرجعية اختيارية لتوجيه توليد الفيديو | IMAGE | لا | - |
| `النموذج` | نموذج Veo 3 المستخدم لتوليد الفيديو (الافتراضي: "veo-3.1-generate") | COMBO | لا | "veo-3.1-generate"<br>"veo-3.1-fast-generate"<br>"veo-3.1-lite" |
| `إنشاء الصوت` | توليد صوت للفيديو. مدعوم من جميع نماذج Veo 3. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** معامل `enhance_prompt` مهمل ويتم تجاهل قيمته. تقوم العقدة دائمًا بتحسين الوصف النصي داخليًا. إذا قمت بتحديد دقة "4k" مع نموذج veo-3.1-lite، فستقوم العقدة بإصدار خطأ.
