# Генерация видео Google Veo 3

Generates videos from text prompts using Google's Veo 3 API. This node supports multiple Veo 3 models, including fast and lite variants, and allows you to specify video resolution, duration, and audio generation.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео (по умолчанию: "") | STRING | Да | - |
| `aspect_ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9") | COMBO | Да | "16:9"<br>"9:16" |
| `разрешение` | Разрешение выходного видео. Разрешение 4K недоступно для модели veo-3.1-lite. (по умолчанию: "720p") | COMBO | Нет | "720p"<br>"1080p"<br>"4k" |
| `negative_prompt` | Негативный текстовый запрос, указывающий, чего следует избегать в видео (по умолчанию: "") | STRING | Нет | - |
| `duration_seconds` | Длительность выходного видео в секундах (по умолчанию: 8) | INT | Нет | 4 - 8 (step 2) |
| `enhance_prompt` | Этот параметр устарел и игнорируется. (по умолчанию: True) | BOOLEAN | Нет | - |
| `person_generation` | Следует ли разрешить генерацию людей в видео (по умолчанию: "ALLOW") | COMBO | Нет | "ALLOW"<br>"BLOCK" |
| `seed` | Сид для генерации видео (0 для случайного значения) (по умолчанию: 0) | INT | Нет | 0 - 4294967295 |
| `image` | Необязательное эталонное изображение для управления генерацией видео | IMAGE | Нет | - |
| `model` | Модель Veo 3 для генерации видео (по умолчанию: "veo-3.1-generate") | COMBO | Нет | "veo-3.1-generate"<br>"veo-3.1-fast-generate"<br>"veo-3.1-lite" |
| `generate_audio` | Генерировать аудио для видео. Поддерживается всеми моделями Veo 3. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Параметр `enhance_prompt` устарел, и его значение игнорируется. Узел всегда улучшает запрос внутренне. Если выбрать разрешение "4k" с моделью veo-3.1-lite, узел выдаст ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл | VIDEO |
