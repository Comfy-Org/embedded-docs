# Загрузить модель удаления фона

Загружает модель удаления фона из файла. Этот узел подготавливает модель для использования при удалении фона из изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bg_removal_name` | Модель, используемая для удаления фона из изображений. Выберите из списка доступных файлов моделей удаления фона. | COMBO | Да | Список доступных файлов моделей (отсортированный по алфавиту) |

Примечание: если выбранный файл не содержит допустимой модели удаления фона, узел вызывает ошибку RuntimeError.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `bg_model` | Загруженная модель удаления фона, готовая к использованию другими узлами для обработки изображений. | BACKGROUND_REMOVAL |
