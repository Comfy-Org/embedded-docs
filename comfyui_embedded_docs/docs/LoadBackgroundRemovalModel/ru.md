# Загрузить модель удаления фона

Загружает модель удаления фона из файла и подготавливает её к использованию другими узлами при удалении фона с изображений. Файл модели выбирается из доступных файлов в папке удаления фона.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bg_removal_name` | Модель, используемая для удаления фона с изображений. | COMBO | Да | Список доступных файлов моделей (отсортированный список файлов в папке background_removal) |

**Примечание:** Узел вызывает ошибку, если выбранный файл не содержит корректную модель удаления фона.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `bg_model` | Загруженная модель удаления фона, готовая к использованию другими узлами для обработки изображений. | BACKGROUND_REMOVAL |
