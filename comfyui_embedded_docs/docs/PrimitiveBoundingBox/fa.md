# جعبه مرزی

گره PrimitiveBoundingBox یک ناحیه مستطیلی ساده ایجاد می‌کند که توسط موقعیت و اندازه آن تعریف می‌شود. این گره مختصات X و Y را برای گوشه بالا-چپ، همراه با مقادیر عرض و ارتفاع دریافت می‌کند و یک ساختار داده جعبه محدودکننده (bounding box) خروجی می‌دهد که می‌تواند توسط سایر گره‌ها در یک گردش کار استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `x` | مختصات X برای گوشه بالا-چپ جعبه محدودکننده (پیش‌فرض: 0). | INT | بله | 0 to 8192 |
| `y` | مختصات Y برای گوشه بالا-چپ جعبه محدودکننده (پیش‌فرض: 0). | INT | بله | 0 to 8192 |
| `width` | عرض جعبه محدودکننده (پیش‌فرض: 512). | INT | بله | 1 to 8192 |
| `height` | ارتفاع جعبه محدودکننده (پیش‌فرض: 512). | INT | بله | 1 to 8192 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `bounding_box` | ساختار داده‌ای شامل ویژگی‌های `x`، `y`، `width` و `height` مستطیل تعریف‌شده. | BOUNDING_BOX |
