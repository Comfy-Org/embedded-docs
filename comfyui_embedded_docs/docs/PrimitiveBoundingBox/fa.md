# جعبه مرزی

گره PrimitiveBoundingBox یک ناحیه مستطیلی ساده که با موقعیت و اندازه آن تعریف می‌شود ایجاد می‌کند. این گره مختصات X و Y را برای گوشهٔ بالا-چپ، همراه با مقادیر عرض و ارتفاع دریافت می‌کند و یک ساختار دادهٔ جعبه محدود را خروجی می‌دهد که می‌تواند توسط سایر گره‌ها در یک گردش کار استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `x` | مختصات X برای گوشهٔ بالا-چپ جعبه محدود (پیش‌فرض: 0). | INT | بله | 0 تا 16384 |
| `y` | مختصات Y برای گوشهٔ بالا-چپ جعبه محدود (پیش‌فرض: 0). | INT | بله | 0 تا 16384 |
| `width` | عرض جعبه محدود (پیش‌فرض: 512). | INT | بله | 1 تا 16384 |
| `height` | ارتفاع جعبه محدود (پیش‌فرض: 512). | INT | بله | 1 تا 16384 |

نکته: همه مقادیر حداکثر از ثابت MAX_RESOLUTION در ComfyUI پیروی می‌کنند که بزرگ‌ترین بُعد تصویری پذیرفته‌شده توسط گره را تعریف می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `bounding_box` | یک ساختار داده شامل ویژگی‌های `x`، `y`، `width` و `height` از مستطیل تعریف‌شده. | BOUNDING_BOX |
