# Границы (Bounding Box)

Узел PrimitiveBoundingBox создает простую прямоугольную область, определяемую ее положением и размером. Он принимает координаты X и Y для верхнего левого угла, а также значения ширины и высоты, и выводит структуру данных ограничивающей рамки, которая может использоваться другими узлами в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `x` | X-координата верхнего левого угла ограничивающей рамки (по умолчанию: 0). | INT | Да | от 0 до 16384 |
| `y` | Y-координата верхнего левого угла ограничивающей рамки (по умолчанию: 0). | INT | Да | от 0 до 16384 |
| `ширина` | Ширина ограничивающей рамки (по умолчанию: 512). | INT | Да | от 1 до 16384 |
| `высота` | Высота ограничивающей рамки (по умолчанию: 512). | INT | Да | от 1 до 16384 |

Примечание: все максимальные значения соответствуют константе MAX_RESOLUTION в ComfyUI, которая определяет наибольшее измерение изображения, принимаемое узлом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `bounding_box` | Структура данных, содержащая свойства `x`, `y`, `width` и `height` заданного прямоугольника. | BOUNDING_BOX |
