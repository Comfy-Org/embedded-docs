# Границы (Bounding Box)

Узел PrimitiveBoundingBox создает простую прямоугольную область, определяемую ее положением и размером. Он принимает координаты X и Y верхнего левого угла, а также значения ширины и высоты и выводит структуру данных ограничивающей рамки, которая может использоваться другими узлами в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `x` | Координата X верхнего левого угла ограничивающей рамки (по умолчанию: 0). | INT | Да | 0 to 8192 |
| `y` | Координата Y верхнего левого угла ограничивающей рамки (по умолчанию: 0). | INT | Да | 0 to 8192 |
| `width` | Ширина ограничивающей рамки (по умолчанию: 512). | INT | Да | 1 to 8192 |
| `height` | Высота ограничивающей рамки (по умолчанию: 512). | INT | Да | 1 to 8192 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `bounding_box` | Структура данных, содержащая свойства `x`, `y`, `width` и `height` заданного прямоугольника. | BOUNDING_BOX |
