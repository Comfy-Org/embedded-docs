# مربع التحديد

تُنشئ عقدة PrimitiveBoundingBox منطقة مستطيلة بسيطة تُحدد من خلال موضعها وحجمها. تأخذ إحداثيات X و Y للزاوية العلوية اليسرى، بالإضافة إلى قيمتي العرض والارتفاع، وتُخرج بنية بيانات صندوق محيط يمكن استخدامها بواسطة عقد أخرى في سير العمل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `x` | إحداثي X للزاوية العلوية اليسرى للصندوق المحيط (القيمة الافتراضية: 0). | INT | نعم | 0 إلى 8192 |
| `y` | إحداثي Y للزاوية العلوية اليسرى للصندوق المحيط (القيمة الافتراضية: 0). | INT | نعم | 0 إلى 8192 |
| `width` | عرض الصندوق المحيط (القيمة الافتراضية: 512). | INT | نعم | 1 إلى 8192 |
| `height` | ارتفاع الصندوق المحيط (القيمة الافتراضية: 512). | INT | نعم | 1 إلى 8192 |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `bounding_box` | بنية بيانات تحتوي على خصائص `x` و `y` و `width` و `height` للمستطيل المحدد. | BOUNDING_BOX |
