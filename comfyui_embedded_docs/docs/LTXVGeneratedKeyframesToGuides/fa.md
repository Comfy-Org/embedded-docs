# تبدیل فریم‌های کلیدی تولیدشدهٔ LTXV به راهنما

گره LTXV Generated Keyframes to Guides، کی‌فریم‌های تولیدشده از مرحله‌ای پیشین را به‌عنوان راهنماهای تصویری ثابت‌شده روی یک بوم بعدی پین می‌کند. آن‌ها را به‌عنوان فریم‌های مستقل رمزگشایی می‌کند، در صورت نیاز اندازه‌شان را تغییر می‌دهد و آن‌ها را با ماسک نویز 0 می‌نویسد تا دوباره نویززدایی نشوند. پس از افزایش مقیاس زمانی (temporal upscale)، اندیس‌های ثبت‌شده از بومی که روی آن تولید شده‌اند به این بوم مقیاس‌بندی می‌شوند؛ برای تنظیم صریح موقعیت‌ها از `override_frame_indices` استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `positive` | کاندیشنینگ مثبت برای افزودن راهنماهای کی‌فریم به آن. | CONDITIONING | بله | |
| `negative` | کاندیشنینگ منفی برای افزودن راهنماهای کی‌فریم به آن. | CONDITIONING | بله | |
| `vae` | VAE مورد استفاده برای رمزگشایی کی‌فریم‌ها در صورت نیاز به تغییر اندازه. | VAE | بله | |
| `latent` | لاتنت ویدئوی هدف برای افزودن راهنماها به آن، مثلاً نسخه‌ای که به‌صورت زمانی افزایش مقیاس یافته است. | LATENT | بله | |
| `keyframes` | خروجی keyframes از LTXV Separate Generated Keyframes، که اندیس فریم پیکسلی‌ای را که هر کی‌فریم در آن تولید شده است حمل می‌کند. | LATENT | بله | |
| `strength` | قدرت راهنما. مقدار 1.0 یک پین سخت است؛ مقادیر کمتر آن را شل می‌کنند. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 (گام: 0.01) |
| `override_frame_indices` | اختیاری — به‌جای موقعیت‌های ثبت‌شده (یا مقیاس‌بندی‌شده خودکار) در این فریم‌های پیکسلی پین کنید. برای هر کی‌فریم یک اندیس ارائه دهید. خالی بگذارید تا از موقعیت‌های ثبت‌شده استفاده مجدد شود، یا زمانی که بوم هدف طول متفاوتی دارد (مثلاً پس از temporal x2) آن‌ها مقیاس‌بندی شوند. (پیش‌فرض: "") | STRING | خیر | |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | کاندیشنینگ مثبت همراه با کی‌فریم‌های پین‌شده به‌عنوان راهنماهای تصویری. | CONDITIONING |
| `negative` | کاندیشنینگ منفی همراه با کی‌فریم‌های پین‌شده به‌عنوان راهنماهای تصویری. | CONDITIONING |
| `latent` | لاتنت ویدئوی هدف با کی‌فریم‌های افزوده‌شده به‌عنوان راهنماهای ثابت‌شده. | LATENT |

## نکات

- ورودی `keyframes` باید به خروجی keyframes مربوط به LTXV Separate Generated Keyframes متصل شود. اگر لاتنت موقعیت‌های کی‌فریم تولیدشده را حمل نکند، گره خطا می‌دهد.
- ورودی‌های کاندیشنینگ `positive` و `negative` باید از خروجی‌های `positive` و `negative` مربوط به LTXV Separate Generated Keyframes بیایند. اگر کاندیشنینگ مثبت هنوز کی‌فریم‌های تولیدشده را حمل کند، گره خطا می‌دهد.
- ورودی `latent` باید یک لاتنت ویدئوی ساده (تانسور 5D) باشد. راهنماها باید پیش از ادغام لاتنت‌های ویدئو و صدا با Concat AV Latent افزوده شوند.
- فقط اندازه دسته 1 پشتیبانی می‌شود. هر راهنما از یک تصویر رمزگذاری می‌شود، بنابراین نمی‌تواند بین عناصر دسته متفاوت باشد.
- تعداد کی‌فریم‌ها در لاتنت `keyframes` باید با تعداد موقعیت‌های ثبت‌شده مطابقت داشته باشد؛ در غیر این صورت خطا ایجاد می‌شود.
- اگر `override_frame_indices` خالی بماند، از موقعیت‌های ثبت‌شده استفاده می‌شود. اگر بوم هدف تعداد فریم متفاوتی نسبت به بومی که کی‌فریم‌ها روی آن تولید شده‌اند داشته باشد، اندیس‌های ثبت‌شده به‌طور خودکار مقیاس‌بندی می‌شوند.
- اگر `override_frame_indices` ارائه شود، باید برای هر کی‌فریم یک اندیس صحیح داشته باشد که با کاما یا فاصله جدا شده‌اند. اندیس‌ها باید یکتا باشند و بین 1 و (تعداد فریم‌های پیکسلی در لاتنت هدف منهای 1) قرار گیرند. در غیر این صورت خطا ایجاد می‌شود.
- اگر هر اندیس نهایی کی‌فریم بزرگ‌تر یا مساوی تعداد فریم‌های پیکسلی در لاتنت هدف باشد، گره خطا می‌دهد. این وضعیت می‌تواند زمانی رخ دهد که هدف پس از تولید کی‌فریم‌ها به‌صورت زمانی تغییر اندازه داده شده باشد.
- پارامتر `strength` حداقل 0.0 و حداکثر 10.0 دارد.
