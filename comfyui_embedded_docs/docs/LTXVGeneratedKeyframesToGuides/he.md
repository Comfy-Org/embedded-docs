# LTXV המרת פריימים מרכזיים שנוצרו להנחיות

הצומת LTXV Generated Keyframes to Guides מצמיד פריימי מפתח שנוצרו משלב קודם כמדריכי תמונה קפואים על קנבס מאוחר יותר. הוא מפענח את פריימי המפתח כפריימים עצמאיים, משנה את גודלם במידת הצורך, וכותב אותם עם מסכת רעש של 0 כך שלא יבוצע בהם תהליך הסרת רעש שוב. לאחר הגדלה זמנית (temporal upscale), האינדקסים שנרשמו מותאמים בקנה מידה מהקנבס שבו נוצרו לקנבס הזה; השתמש ב-`override_frame_indices` כדי להגדיר מיקומים באופן מפורש.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | קונדישנינג חיובי שאליו יוספו מדריכי פריימי המפתח. | CONDITIONING | כן | |
| `negative` | קונדישנינג שלילי שאליו יוספו מדריכי פריימי המפתח. | CONDITIONING | כן | |
| `vae` | ה-VAE המשמש לפענוח פריימי המפתח אם יש צורך בשינוי גודל. | VAE | כן | |
| `latent` | ה-latent של הווידאו ביעד שאליו יש להוסיף את המדריכים, למשל זה שהוגדל זמנית. | LATENT | כן | |
| `keyframes` | הפלט `keyframes` של LTXV Separate Generated Keyframes, הנושא את אינדקס פריים הפיקסלים שבו נוצר כל פריים מפתח. | LATENT | כן | |
| `strength` | חוזק המדריך. 1.0 הוא הצמדה קשיחה; ערכים נמוכים יותר מרפים אותה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 10.0 (step 0.01) |
| `override_frame_indices` | אופציונלי — הצמד בפריימי פיקסלים אלה במקום במיקומים שנרשמו (או שהותאמו אוטומטית). ספק אינדקס אחד לכל פריים מפתח. השאר ריק כדי לעשות שימוש חוזר במיקומים שנרשמו, או כדי להתאים אותם בקנה מידה כאשר אורך הקנבס ביעד שונה (למשל לאחר temporal x2). (ברירת מחדל: "") | STRING | לא | |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | קונדישנינג חיובי עם פריימי המפתח מוצמדים כמדריכי תמונה. | CONDITIONING |
| `negative` | קונדישנינג שלילי עם פריימי המפתח מוצמדים כמדריכי תמונה. | CONDITIONING |
| `latent` | ה-latent של הווידאו ביעד עם פריימי המפתח שנוספו כמדריכים קפואים. | LATENT |

## הערות

- הקלט `keyframes` חייב להיות מחובר לפלט keyframes של LTXV Separate Generated Keyframes. הצומת מחזיר שגיאה אם ה-latent אינו נושא מיקומי פריימי מפתח שנוצרו.
- קלטי הקונדישנינג `positive` ו-`negative` חייבים להגיע מהפלטים `positive` ו-`negative` של LTXV Separate Generated Keyframes. הצומת מחזיר שגיאה אם הקונדישנינג החיובי עדיין נושא פריימי מפתח שנוצרו.
- הקלט `latent` חייב להיות latent וידאו פשוט (טנזור 5D). יש להוסיף מדריכים לפני מיזוג ה-latents של הווידאו והאודיו עם Concat AV Latent.
- נתמך רק גודל באטץ' של 1. כל מדריך מקודד מתמונה אחת, ולכן אינו יכול להשתנות בין רכיבי הבאטץ'.
- מספר פריימי המפתח ב-latent `keyframes` חייב להתאים למספר המיקומים שנרשמו; אחרת תוחזר שגיאה.
- אם `override_frame_indices` נשאר ריק, נעשה שימוש במיקומים שנרשמו. אם בקנבס היעד יש מספר פריימים שונה מאשר בקנבס שבו נוצרו פריימי המפתח, האינדקסים שנרשמו מותאמים אוטומטית בקנה מידה.
- אם `override_frame_indices` מסופק, עליו להכיל אינדקס שלם אחד לכל פריים מפתח, מופרד בפסיקים או ברווחים. האינדקסים חייבים להיות ייחודיים ולנוע בין 1 ל-(מספר פריימי הפיקסלים ב-latent היעד - 1). אחרת תוחזר שגיאה.
- אם אינדקס פריים המפתח הסופי גדול או שווה למספר פריימי הפיקסלים ב-latent היעד, הצומת מחזיר שגיאה. זה יכול לקרות כאשר היעד שונה בגודלו באופן זמני לאחר יצירת פריימי המפתח.
- לפרמטר `strength` יש מינימום של 0.0 ומקסימום של 10.0.
