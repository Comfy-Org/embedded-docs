# LTXV Преобразовать сгенерированные ключевые кадры в направляющие

Узел LTXV Generated Keyframes to Guides закрепляет сгенерированные ключевые кадры с более раннего этапа как замороженные направляющие-изображения на более позднем холсте. Он декодирует ключевые кадры как отдельные кадры, изменяет их размер при необходимости и записывает их с маской шума 0, чтобы они не подвергались повторному удалению шума. После временного апскейла записанные индексы масштабируются с холста, на котором они были сгенерированы, на текущий; используйте `override_frame_indices`, чтобы задать позиции явно.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Позитивное кондиционирование, к которому нужно добавить направляющие ключевых кадров. | CONDITIONING | Да | |
| `negative` | Негативное кондиционирование, к которому нужно добавить направляющие ключевых кадров. | CONDITIONING | Да | |
| `vae` | VAE, используемый для декодирования ключевых кадров, если требуется изменение размера. | VAE | Да | |
| `latent` | Целевой латент видео, к которому нужно добавить направляющие, например прошедший временной апскейл. | LATENT | Да | |
| `keyframes` | Выход keyframes узла LTXV Separate Generated Keyframes, который содержит индекс пиксельного кадра, на котором был сгенерирован каждый ключевой кадр. | LATENT | Да | |
| `strength` | Сила направляющих. 1.0 — жёсткое закрепление; меньшие значения ослабляют его. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 (шаг 0.01) |
| `override_frame_indices` | Необязательно — закрепить на этих пиксельных кадрах вместо записанных (или автоматически масштабированных) позиций. Укажите один индекс на каждый ключевой кадр. Оставьте пустым, чтобы повторно использовать записанные позиции или масштабировать их, когда целевой холст имеет другую длину (например, после временного апскейла x2). (по умолчанию: "") | STRING | Нет | |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование с ключевыми кадрами, закреплёнными как направляющие-изображения. | CONDITIONING |
| `negative` | Негативное кондиционирование с ключевыми кадрами, закреплёнными как направляющие-изображения. | CONDITIONING |
| `latent` | Целевой латент видео с ключевыми кадрами, добавленными как замороженные направляющие. | LATENT |

## Примечания

- Вход `keyframes` должен быть подключён к выходу keyframes узла LTXV Separate Generated Keyframes. Узел выдаёт ошибку, если латент не содержит позиции сгенерированных ключевых кадров.
- Входы кондиционирования `positive` и `negative` должны поступать с выходов positive и negative узла LTXV Separate Generated Keyframes. Узел выдаёт ошибку, если позитивное кондиционирование всё ещё содержит сгенерированные ключевые кадры.
- Вход `latent` должен быть обычным латентом видео (5D-тензор). Направляющие нужно добавить до объединения латентов видео и аудио с помощью Concat AV Latent.
- Поддерживается только размер батча, равный 1. Каждая направляющая кодируется из одного изображения, поэтому она не может различаться по элементам батча.
- Количество ключевых кадров в латенте `keyframes` должно совпадать с количеством записанных позиций; в противном случае выдаётся ошибка.
- Если `override_frame_indices` оставлен пустым, используются записанные позиции. Если целевой холст имеет другое количество кадров, чем холст, на котором были сгенерированы ключевые кадры, записанные индексы масштабируются автоматически.
- Если указан `override_frame_indices`, он должен содержать один целочисленный индекс на каждый ключевой кадр, разделённых запятыми или пробелами. Индексы должны быть уникальными и находиться в диапазоне от 1 до (количество пиксельных кадров в целевом латенте - 1). В противном случае выдаётся ошибка.
- Если любой итоговый индекс ключевого кадра больше или равен количеству пиксельных кадров в целевом латенте, узел выдаёт ошибку. Это может произойти, если целевой объект был изменён по времени после генерации ключевых кадров.
- Параметр `strength` имеет минимум 0.0 и максимум 10.0.
