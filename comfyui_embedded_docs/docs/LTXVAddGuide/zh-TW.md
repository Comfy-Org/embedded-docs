# LTXV 添加引導

LTXVAddGuide 節點透過編碼輸入的影像或影片，並將其作為關鍵幀納入條件資料中，為潛在序列加入影片條件引導。它會透過 VAE 編碼器處理輸入，並將產生的潛在向量策略性地放置在指定的幀位置，同時以關鍵幀資訊更新正向與負向條件。此節點負責處理幀對齊約束，並可控制條件影響的強度。

| `負向` | 要透過關鍵幀引導修改的負向條件輸入 | CONDITIONING | 是 | - |
| `vae` | 用於編碼輸入影像/影片幀的 VAE 模型 | VAE | 是 | - |

| `影像` | 用於對潛在影片進行條件的影像或影片。必須是 8*n + 1 幀。如果影片不是 8*n + 1 幀，則會裁剪至最近的 8*n + 1 幀。 | IMAGE | 是 | - |
| `起始幀索引` | 開始條件化的幀索引。對於單幀影像或具有 1-8 幀的影片，任何 `frame_idx` 值都可以接受。對於具有 9 幀以上的影片，`frame_idx` 必須能被 8 整除，否則將向下取整至最接近的 8 的倍數。負值從影片結尾開始計算。（預設值：0） | INT | 是 | -9999 至 9999 |

**關於 `iclora_parameters` 的注意事項：** 當使用 `reference_downscale_factor` 大於 1 的 IC-LoRA 參數時，潛在空間的尺寸（寬度和高度）必須能被該因子整除。如果未滿足此條件，節點將引發錯誤。
