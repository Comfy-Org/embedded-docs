# LTXV 添加引導

LTXVAddGuide 節點會透過 VAE 編碼器將輸入影像或影片編碼，並將其作為引導關鍵影格加入潛在影片序列。它會更新正向與負向條件，並傳回修改後的潛在表示，同時提供設定起始影格、條件強度、選用注意力遮罩，以及選用 IC-LoRA 參數等選項。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 要透過關鍵影格引導修改的正向條件輸入。 | CONDITIONING | 是 | - |
| `負向` | 要透過關鍵影格引導修改的負向條件輸入。 | CONDITIONING | 是 | - |
| `vae` | 用於編碼輸入影像/影片影格的 VAE 模型。 | VAE | 是 | - |
| `潛在空間` | 將接收條件影格的輸入潛在序列。 | LATENT | 是 | - |
| `影像` | 用於對潛在影片進行條件化的影像或影片。影格數必須為 8*n + 1。如果影片的影格數不是 8*n + 1，將會裁切至最接近的 8*n + 1 影格數。 | IMAGE | 是 | - |
| `起始幀索引` | 開始進行條件化的影格索引。對於單一影格影像或具有 1 至 8 個影格的影片，任何 `frame_idx` 值皆可接受。對於具有 9 個以上影格的影片，`frame_idx` 必須可被 8 整除，否則會向下取整至最接近的 8 的倍數。負值會從影片結尾開始計算。預設：0。 | INT | 是 | -9999 至 9999 |
| `強度` | 條件影響的強度，其中 1.0 會套用完整條件，0.0 則不套用任何條件。預設：1.0。 | FLOAT | 是 | 0.0 至 10.0 |
| `注意力遮罩` | 選用的像素空間空間遮罩。透過自注意力控制各區域的條件影響，並會乘以 `strength`。 | MASK | 否 | - |
| `iclora_parameters` | 來自 Get IC-LoRA Parameters 節點的選用 IC-LoRA 參數。用於依特定 IC-LoRA 的要求調整引導處理（例如 `reference_downscale_factor > 1` 的 IC-LoRA）。串接時，每個 LTXVAddGuide 只會使用連接到它的參數。 | IC_LORA_PARAMETERS | 否 | - |

**注意：** 輸入影像/影片的影格數必須遵循 8*n + 1 模式（例如 1、9、17、25 個影格）。如果輸入超過此模式，系統會自動將其裁切至最接近的有效影格數。

**關於 `iclora_parameters` 的注意事項：** 當使用 `reference_downscale_factor` 大於 1 的 IC-LoRA 參數時，潛在空間維度（寬度與高度）必須可被該因數整除。若不符合此條件，節點會引發錯誤。

**注意：** 編碼後的引導影格必須能在所選影格位置容納於潛在序列中。如果條件影格超過潛在序列的長度，節點會引發錯誤。

**注意：** 不支援將引導加入同時包含音訊與視訊通道的潛在表示，這麼做會引發錯誤。
