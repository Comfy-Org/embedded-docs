# LTXVAddGuide

Узел LTXVAddGuide добавляет к латентным последовательностям направляющее кондиционирование видео: он кодирует входные изображения или видео через VAE-энкодер и встраивает полученные латентные представления в данные кондиционирования в качестве ключевых кадров. При этом положительное и отрицательное кондиционирование обновляются информацией о ключевых кадрах. Узел учитывает ограничения выравнивания кадров и позволяет управлять силой влияния кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Входное положительное кондиционирование, которое будет изменено с использованием направляющей информации о ключевых кадрах | CONDITIONING | Да | - |
| `отрицательный` | Входное отрицательное кондиционирование, которое будет изменено с использованием направляющей информации о ключевых кадрах | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входных кадров изображения/видео | VAE | Да | - |
| `скрытое пространство` | Входная латентная последовательность, в которую будут добавлены кадры кондиционирования | LATENT | Да | - |
| `изображение` | Изображение или видео для кондиционирования латентного видео. Количество кадров должно быть вида 8*n + 1. Если количество кадров видео не равно 8*n + 1, оно будет обрезано до ближайшего количества кадров вида 8*n + 1. | IMAGE | Да | - |
| `индекс кадра` | Индекс кадра, с которого начинается кондиционирование. Для однокадровых изображений или видео с 1–8 кадрами допустимо любое значение frame_idx. Для видео с 9 и более кадрами frame_idx должен делиться на 8; в противном случае он будет округлен вниз до ближайшего числа, кратного 8. Отрицательные значения отсчитываются от конца видео. (по умолчанию: 0) | INT | Да | -9999 до 9999 |
| `сила` | Сила влияния кондиционирования, где 1.0 применяет полное кондиционирование, а 0.0 — не применяет кондиционирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 10.0 |
| `attention_mask` | Необязательная пространственная маска в пиксельном пространстве. Управляет влиянием кондиционирования на отдельные области через механизм самовнимания; значение умножается на strength. | MASK | Нет | - |
| `iclora_parameters` | Необязательные параметры IC-LoRA из узла Get IC-LoRA Parameters. Используются для настройки обработки направляющего кондиционирования в соответствии с требованиями некоторых IC-LoRA (например, тех, у которых `reference_downscale_factor` больше 1). При последовательном подключении каждый узел LTXVAddGuide использует только параметры, подключенные к нему. | IC_LORA_PARAMETERS | Нет | - |

**Примечание:** Входное изображение/видео должно иметь количество кадров, соответствующее шаблону 8*n + 1 (например, 1, 9, 17, 25 кадров). Если входные данные не соответствуют этому шаблону, они будут автоматически обрезаны до ближайшего допустимого количества кадров.

**Примечание о `iclora_parameters`:** При использовании параметров IC-LoRA с `reference_downscale_factor` больше 1 пространственные размеры латентного представления (ширина и высота) должны делиться на этот коэффициент. Если это условие не выполняется, узел выдаст ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Положительное кондиционирование, обновленное с учетом направляющей информации о ключевых кадрах | CONDITIONING |
| `отрицательный` | Отрицательное кондиционирование, обновленное с учетом направляющей информации о ключевых кадрах | CONDITIONING |
| `скрытое пространство` | Латентная последовательность со встроенными кадрами кондиционирования и обновленной маской шума | LATENT |
