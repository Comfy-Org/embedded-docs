# LTXVAddGuide

LTXVAddGuide добавляет направляющие данные видеокондиционирования к последовательностям латентных представлений, кодируя входные изображения или видео и включая их в качестве ключевых кадров в данные кондиционирования. Узел обрабатывает входные данные через VAE-энкодер и размещает полученные латентные представления на указанных позициях кадров, обновляя при этом и положительное, и отрицательное кондиционирование информацией о ключевых кадрах. Узел учитывает ограничения выравнивания кадров и позволяет управлять силой влияния кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Входное положительное кондиционирование, которое будет изменено с помощью направляющей информации о ключевых кадрах | CONDITIONING | Да | - |
| `negative` | Входное отрицательное кондиционирование, которое будет изменено с помощью направляющей информации о ключевых кадрах | CONDITIONING | Да | - |
| `vae` | VAE-модель, используемая для кодирования входных кадров изображения или видео | VAE | Да | - |
| `latent` | Входная последовательность латентных представлений, в которую будут добавлены кондиционирующие кадры | LATENT | Да | - |
| `image` | Изображение или видео для кондиционирования латентного видео. Должно содержать 8*n + 1 кадров. Если видео не соответствует формату 8*n + 1 кадров, оно будет обрезано до ближайшего количества кадров вида 8*n + 1. | IMAGE | Да | - |
| `frame_idx` | Индекс кадра, с которого начинается кондиционирование. Для однокадровых изображений или видео с 1–8 кадрами допустимо любое значение `frame_idx`. Для видео с 9+ кадрами `frame_idx` должен быть кратен 8, в противном случае он будет округлён вниз до ближайшего числа, кратного 8. Отрицательные значения отсчитываются от конца видео. (по умолчанию: 0) | INT | Нет | -9999 to 9999 |
| `strength` | Сила влияния кондиционирования, где 1.0 применяет полное кондиционирование, а 0.0 — отсутствие кондиционирования (по умолчанию: 1.0) | FLOAT | Нет | 0.0 to 10.0 |
| `attention_mask` | Необязательная пространственная маска в пиксельном пространстве. Управляет влиянием кондиционирования на отдельные области через самовнимание, умножается на `strength`. | MASK | Нет | - |
| `iclora_parameters` | Необязательные параметры IC-LoRA из узла Get IC-LoRA Parameters. Используются для настройки обработки направляющих в соответствии с требованиями некоторых IC-LoRA (например, тех, у которых `reference_downscale_factor` > 1). При объединении в цепочку каждый LTXVAddGuide использует только подключённые к нему параметры. | IC_LORA_PARAMETERS | Нет | - |

**Примечания:**

- Входное изображение или видео должно содержать количество кадров, соответствующее шаблону 8*n + 1 (например, 1, 9, 17, 25 кадров). Если входные данные превышают этот шаблон, они будут автоматически обрезаны до ближайшего допустимого количества кадров.
- При использовании параметров IC-LoRA с `reference_downscale_factor` больше 1 пространственные размеры латентного представления (ширина и высота) должны быть кратны этому коэффициенту. Узел вызывает ошибку, если это условие не выполнено.
- Направляющая должна помещаться в последовательность латентных представлений: начальный индекс кадра плюс количество кадров направляющей не могут превышать длину латентной последовательности, иначе узел вызывает ошибку.
- Узел не поддерживает комбинированные аудио-видео латентные представления. И входное `latent`, и закодированная направляющая должны использовать стандартный 128-канальный видео-латентный формат, в противном случае узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование, обновлённое информацией о направляющих ключевых кадров | CONDITIONING |
| `negative` | Отрицательное кондиционирование, обновлённое информацией о направляющих ключевых кадров | CONDITIONING |
| `latent` | Последовательность латентных представлений со включёнными кондиционирующими кадрами и обновлённой маской шума | LATENT |
