# LTXVAddGuide

Узел LTXVAddGuide кодирует входные изображения или видео с помощью VAE-энкодера и добавляет их как управляющие ключевые кадры в латентную видеопоследовательность. Он обновляет как положительное, так и отрицательное кондиционирование и возвращает изменённый латент, с возможностью задать начальный кадр, силу кондиционирования, необязательную маску внимания и необязательные параметры IC-LoRA.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `положительный` | Вход положительного кондиционирования, который будет изменён с помощью управления по ключевым кадрам. | CONDITIONING | Да | - |
| `отрицательный` | Вход отрицательного кондиционирования, который будет изменён с помощью управления по ключевым кадрам. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования кадров входного изображения/видео. | VAE | Да | - |
| `скрытое пространство` | Входная латентная последовательность, в которую будут добавлены кадры кондиционирования. | LATENT | Да | - |
| `изображение` | Изображение или видео, на основе которого выполняется кондиционирование латентного видео. Число кадров должно соответствовать формуле 8*n + 1. Если видео не содержит 8*n + 1 кадров, оно будет обрезано до ближайшего количества кадров, соответствующего формуле 8*n + 1. | IMAGE | Да | - |
| `индекс кадра` | Индекс кадра, с которого начинается кондиционирование. Для однокадровых изображений или видео с 1–8 кадрами любое значение `frame_idx` допустимо. Для видео с 9+ кадрами `frame_idx` должен делиться на 8, иначе он будет округлён вниз до ближайшего кратного 8. Отрицательные значения отсчитываются от конца видео. По умолчанию: 0. | INT | Да | -9999 – 9999 |
| `сила` | Сила влияния кондиционирования: 1.0 применяет полное кондиционирование, а 0.0 — никакого. По умолчанию: 1.0. | FLOAT | Да | 0.0 – 10.0 |
| `attention_mask` | Необязательная пространственная маска в пиксельном пространстве. Управляет влиянием кондиционирования для каждой области через self-attention, умножается на `strength`. | MASK | Нет | - |
| `iclora_parameters` | Необязательные параметры IC-LoRA из узла Get IC-LoRA Parameters. Используются для настройки обработки управляющих кадров по требованию некоторых IC-LoRA (например, с `reference_downscale_factor` > 1). При объединении в цепочку каждый LTXVAddGuide использует только подключённые к нему параметры. | IC_LORA_PARAMETERS | Нет | - |

**Примечание:** Число кадров входного изображения/видео должно соответствовать шаблону 8*n + 1 (например, 1, 9, 17, 25 кадров). Если входные данные превышают этот шаблон, они будут автоматически обрезаны до ближайшего допустимого количества кадров.

**Примечание о `iclora_parameters`:** При использовании параметров IC-LoRA с `reference_downscale_factor` больше 1 пространственные размеры латента (ширина и высота) должны делиться на этот коэффициент. Если это условие не выполнено, узел выдаст ошибку.

**Примечание:** Закодированные управляющие кадры должны помещаться в латентную последовательность в выбранной позиции кадра. Если кадры кондиционирования превышают длину латентной последовательности, узел выдаёт ошибку.

**Примечание:** Добавление управляющего материала к латенту, объединяющему аудио- и видеоканалы, не поддерживается и приведёт к ошибке.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование, обновлённое информацией управления по ключевым кадрам. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, обновлённое информацией управления по ключевым кадрам. | CONDITIONING |
| `latent` | Латентная последовательность со встроенными кадрами кондиционирования и обновлённой маской шума. | LATENT |
