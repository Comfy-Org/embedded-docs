# LTXVAddGuide

LTXVAddGuide は、入力画像または動画を VAE エンコーダーで処理し、その結果得られる潜在変数をキーフレームとして指定のフレーム位置に組み込むことで、潜在シーケンスにビデオ条件付けガイダンスを追加します。このノードは、フレーム位置の整合性に関する制約を処理し、条件付けの影響の強さを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | キーフレームガイダンスで変更されるポジティブ条件付け入力 | CONDITIONING | はい | - |
| `negative` | キーフレームガイダンスで変更されるネガティブ条件付け入力 | CONDITIONING | はい | - |
| `vae` | 入力画像/動画フレームのエンコードに使用される VAE モデル | VAE | はい | - |
| `latent` | 条件付けフレームを受け取る入力潜在シーケンス | LATENT | はい | - |
| `image` | 潜在ビデオを条件付けるための画像または動画。フレーム数は 8*n + 1 である必要があります。動画のフレーム数が 8*n + 1 でない場合、最も近い 8*n + 1 フレームにクロップされます。 | IMAGE | はい | - |
| `frame_idx` | 条件付けを開始するフレームインデックス。単一フレーム画像または 1〜8 フレームの動画の場合、任意の frame_idx 値を使用できます。9 フレーム以上の動画の場合、frame_idx は 8 で割り切れる必要があります。それ以外の場合は、最も近い 8 の倍数に切り捨てられます。負の値は動画の末尾から数えます（デフォルト: 0） | INT | いいえ | -9999 から 9999 |
| `strength` | 条件付けの影響の強さ。1.0 で完全な条件付け、0.0 で条件付けなしを適用します（デフォルト: 1.0） | FLOAT | いいえ | 0.0 から 10.0 |
| `attention_mask` | オプションのピクセル空間空間マスク。自己注意メカニズムを介して領域ごとの条件付けの影響を制御し、strength と乗算されます。 | MASK | いいえ | - |
| `iclora_parameters` | Get IC-LoRA Parameters ノードから取得するオプションの IC-LoRA パラメータ。特定の IC-LoRA（例: reference_downscale_factor > 1 のもの）で必要とされるガイド処理の調整に使用します。チェーン接続時、各 LTXVAddGuide は自分に接続されたパラメータのみを使用します。 | IC_LORA_PARAMETERS | いいえ | - |

**注意:**

- 入力画像/動画のフレーム数は 8*n + 1 のパターン（例: 1、9、17、25 フレーム）に従う必要があります。このパターンを超える場合、最も近い有効なフレーム数に自動的にクロップされます。
- reference_downscale_factor が 1 より大きい IC-LoRA パラメータを使用する場合、潜在変数の空間次元（幅と高さ）はその係数で割り切れる必要があります。この条件を満たさない場合、ノードはエラーを発生させます。
- ガイドは潜在シーケンス内に収まる必要があります。開始フレームインデックスとガイドフレーム数の合計が潜在長を超える場合、ノードはエラーを発生させます。
- このノードは、音声と動画を組み合わせた潜在変数には対応していません。入力 `latent` とエンコードされたガイドの両方が標準の 128 チャンネル動画潜在形式を使用する必要があります。それ以外の場合、ノードはエラーを発生させます。
