# LTXVAddGuide

צומת LTXVAddGuide מקודד תמונות או וידאו קלט באמצעות מקודד VAE ומוסיף אותם כפריימי מפתח מנחים לרצף וידאו לטנטי. הוא מעדכן גם את ההתניה החיובית וגם את ההתניה השלילית ומחזיר את הלטנט שהשתנה, עם אפשרויות לקביעת פריים ההתחלה, עוצמת ההתניה, מסכת קשב אופציונלית ופרמטרי IC-LoRA אופציונליים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | קלט התניה חיובית שיש לשנות באמצעות הנחיית פריימי מפתח. | CONDITIONING | כן | - |
| `negative` | קלט התניה שלילית שיש לשנות באמצעות הנחיית פריימי מפתח. | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד פריימי התמונה/הווידאו של הקלט. | VAE | כן | - |
| `latent` | רצף לטנטי קלט שיקבל את פריימי ההתניה. | LATENT | כן | - |
| `image` | תמונה או וידאו שעל פיהם תותנה הווידאו הלטנטי. חייבים להיות 8*n + 1 פריימים. אם הווידאו אינו 8*n + 1 פריימים, הוא ייחתך למספר הפריימים הקרוב ביותר שהוא 8*n + 1. | IMAGE | כן | - |
| `frame_idx` | אינדקס הפריים שממנו מתחילה ההתניה. עבור תמונות בנות פריים בודד או סרטונים עם 1-8 פריימים, כל ערך של `frame_idx` מתקבל. עבור סרטונים עם 9+ פריימים, `frame_idx` חייב להיות מתחלק ב-8, אחרת הוא יעוגל כלפי מטה לכפולה הקרובה ביותר של 8. ערכים שליליים נספרים מסוף הסרטון. ברירת מחדל: 0. | INT | כן | -9999 עד 9999 |
| `strength` | עוצמת השפעת ההתניה, כאשר 1.0 מחיל התניה מלאה ו-0.0 לא מחיל התניה כלל. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 10.0 |
| `attention_mask` | מסכה מרחבית אופציונלית במישור הפיקסלים. שולטת בהשפעת ההתניה לפי אזור באמצעות קשב עצמי, ומוכפלת ב-`strength`. | MASK | לא | - |
| `iclora_parameters` | פרמטרי IC-LoRA אופציונליים מצומת Get IC-LoRA Parameters. משמשים להתאמת עיבוד ההנחיה כנדרש על ידי IC-LoRA מסוימים (למשל, כאלה עם `reference_downscale_factor` > 1). כאשר הם משורשרים, כל LTXVAddGuide משתמש רק בפרמטרים המחוברים אליו. | IC_LORA_PARAMETERS | לא | - |

**הערה:** לקלט מסוג תמונה/וידאו חייב להיות מספר פריימים לפי התבנית 8*n + 1 (למשל, 1, 9, 17, 25 פריימים). אם הקלט חורג מהתבנית הזו, הוא ייחתך אוטומטית למספר הפריימים התקף הקרוב ביותר.

**הערה לגבי `iclora_parameters`:** כאשר משתמשים בפרמטרי IC-LoRA עם `reference_downscale_factor` גדול מ-1, הממדים המרחביים של הלטנט (רוחב וגובה) חייבים להיות מתחלקים בגורם הזה. הצומת יעלה שגיאה אם תנאי זה אינו מתקיים.

**הערה:** פריימי ההנחיה המקודדים חייבים להיכנס לרצף הלטנטי במיקום הפריים הנבחר. אם פריימי ההתניה חורגים מאורך הרצף הלטנטי, הצומת יעלה שגיאה.

**הערה:** הוספת הנחיה ללטנט שמשלב ערוצי אודיו ווידאו אינה נתמכת ותעלה שגיאה.
