# LTXV 가이드 추가

LTXVAddGuide는 입력 이미지나 비디오를 인코딩하고 이를 키프레임으로 컨디셔닝 데이터에 통합하여 잠재 시퀀스에 비디오 컨디셔닝 가이드를 추가합니다. 이 노드는 입력을 VAE 인코더로 처리하고, 결과로 생성된 잠재를 지정된 프레임 위치에 전략적으로 배치하며, 포지티브 및 네거티브 컨디셔닝을 키프레임 정보로 업데이트합니다. 또한 프레임 정렬 제약 조건을 처리하고 컨디셔닝 영향의 강도를 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 키프레임 가이드로 수정할 포지티브 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `negative` | 키프레임 가이드로 수정할 네거티브 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `vae` | 입력 이미지/비디오 프레임을 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `latent` | 컨디셔닝 프레임을 수신할 입력 잠재 시퀀스 | LATENT | 예 | - |
| `image` | 잠재 비디오를 컨디셔닝할 이미지 또는 비디오. 프레임 수가 8*n + 1이어야 합니다. 비디오가 8*n + 1 프레임이 아닌 경우 가장 가까운 8*n + 1 프레임으로 잘립니다. | IMAGE | 예 | - |
| `frame_idx` | 컨디셔닝을 시작할 프레임 인덱스. 단일 프레임 이미지 또는 1~8프레임 비디오의 경우 `frame_idx` 값은 무엇이든 허용됩니다. 9프레임 이상의 비디오에서는 `frame_idx`가 8로 나누어 떨어져야 하며, 그렇지 않으면 가장 가까운 8의 배수로 내림됩니다. 음수 값은 비디오의 끝에서부터 계산됩니다. (기본값: 0) | INT | 아니요 | -9999 ~ 9999 |
| `strength` | 컨디셔닝 영향의 강도로, 1.0은 전체 컨디셔닝을 적용하고 0.0은 컨디셔닝을 적용하지 않습니다. (기본값: 1.0) | FLOAT | 아니요 | 0.0 ~ 10.0 |
| `attention_mask` | 선택적 픽셀 공간 마스크. self-attention을 통해 영역별 컨디셔닝 영향을 제어하며 `strength`에 곱해집니다. | MASK | 아니요 | - |
| `iclora_parameters` | Get IC-LoRA Parameters 노드에서 가져온 선택적 IC-LoRA 매개변수. 특정 IC-LoRA(예: `reference_downscale_factor` > 1인 경우)에서 요구하는 대로 가이드 처리를 조정하는 데 사용됩니다. 연결(체이닝)된 경우 각 LTXVAddGuide는 연결된 매개변수만 사용합니다. | IC_LORA_PARAMETERS | 아니요 | - |

**참고 사항:**

- 입력 이미지/비디오는 8*n + 1 패턴(예: 1, 9, 17, 25프레임)에 해당하는 프레임 수를 가져야 합니다. 입력이 이 패턴에 맞지 않으면 자동으로 가장 가까운 유효 프레임 수로 잘립니다.
- `reference_downscale_factor`가 1보다 큰 IC-LoRA 매개변수를 사용하는 경우, 잠재 공간 차원(너비 및 높이)이 해당 값으로 나누어 떨어져야 합니다. 이 조건이 충족되지 않으면 노드에서 오류를 발생시킵니다.
- 가이드는 잠재 시퀀스 내에 맞아야 합니다. 시작 프레임 인덱스에 가이드 프레임 수를 더한 값이 잠재 길이를 초과할 수 없으며, 그렇지 않으면 노드에서 오류를 발생시킵니다.
- 이 노드는 오디오-비디오 결합 잠재를 지원하지 않습니다. 입력 `latent`와 인코딩된 가이드 모두 표준 128채널 비디오 잠재 형식을 사용해야 하며, 그렇지 않으면 노드에서 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `positive` | 키프레임 가이드 정보로 업데이트된 포지티브 컨디셔닝 | CONDITIONING |
| `negative` | 키프레임 가이드 정보로 업데이트된 네거티브 컨디셔닝 | CONDITIONING |
| `latent` | 컨디셔닝 프레임이 통합되고 노이즈 마스크가 업데이트된 잠재 시퀀스 | LATENT |
