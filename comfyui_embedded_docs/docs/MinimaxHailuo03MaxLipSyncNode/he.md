# MiniMax H3 Max Lip Sync

צומת זה מניע תמונה סטטית כך שתנועות הפה עוקבות אחר מסלול שמע שסופק. התמונה והשמע מועלים, משימת סינכרון השפתיים של Hailuo 03 Max נבדקת, והסרטון המדבר חוזר ברזולוציה שתבחרו. אורך סרטון הפלט כאורך השמע.
