# Comfy Cloud MiniMax Music 3: текст в аудио [БЕТА]

Запускает рабочий процесс MiniMax Music 3 на GPU Comfy Cloud и возвращает сгенерированную песню. Промпт задаёт стиль, инструментальную аранжировку и настроение; текст исполняется вокально, а не описывается, а пустой текст оставляет трек инструментальным. Это бета-узел, оплата производится по секундам работы GPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Описание песни: стиль, инструментальная аранжировка и настроение. Начальные и конечные пробелы удаляются перед отправкой. | STRING | Да | от 1 до 4096 символов |
| `текст песни` | Слова для исполнения. Оставьте пустым для инструментальной композиции. | STRING | Нет | от 0 до 4096 символов |
| `сид` | Случайное зерно (seed), которое управляет сгенерированным результатом (по умолчанию: 42). | INT | Да | от 0 до 9223372036854775807 |
| `максимальная длительность` | Максимальная длительность трека в секундах (по умолчанию: 120.0). Модель может завершить песню раньше. | FLOAT | Да | от 0.04 до 360.0 (шаг 0.04) |
| `качество аудио` | Битрейт выходного аудио. `"V0"` — переменный битрейт и наивысшее качество из трёх (по умолчанию: `"V0"`). | COMBO | Да | `"V0"`<br>`"128k"`<br>`"320k"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Сгенерированная песня. | AUDIO |
