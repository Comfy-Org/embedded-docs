# Comfy Cloud MiniMax Music 3 متن به صدا [BETA]

گردش‌کار MiniMax Music 3 را روی GPU ابری Comfy اجرا می‌کند و یک آهنگ تولیدشده برمی‌گرداند. پرامپت بیانگر سبک، سازبندی و حال‌وهوا است؛ متن ترانه خوانده می‌شود نه اینکه توصیف شود، و خالی گذاشتن متن ترانه باعث می‌شود قطعه بی‌کلام باشد. این یک گره بتا است و صورت‌حساب آن بر اساس هر ثانیه GPU انجام می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | توضیح آهنگ: سبک، سازبندی و حال‌وهوا. فضای خالی ابتدا و انتهای آن پیش از ارسال حذف می‌شود. | STRING | بله | 1 تا 4096 کاراکتر |
| `متن ترانه` | کلماتی که خوانده می‌شوند. برای قطعه بی‌کلام خالی بگذارید. | STRING | خیر | 0 تا 4096 کاراکتر |
| `بذر` | بذر تصادفی که نتیجه تولیدشده را کنترل می‌کند (پیش‌فرض: 42). | INT | بله | 0 تا 9223372036854775807 |
| `حداکثر مدت` | حداکثر مدت اجرای قطعه، بر حسب ثانیه (پیش‌فرض: 120.0). مدل می‌تواند آهنگ را زودتر به پایان برساند. | FLOAT | بله | 0.04 تا 360.0 (گام 0.04) |
| `کیفیت صدا` | نرخ بیت خروجی. `"V0"` متغیر است و بالاترین کیفیت میان این سه است (پیش‌فرض: `"V0"`). | COMBO | بله | `"V0"`<br>`"128k"`<br>`"320k"` |
