# Comfy Cloud MiniMax Music 3 טקסט לשמע [BETA]

מריץ את זרימת העבודה MiniMax Music 3 על GPU של Comfy Cloud ומחזיר שיר שנוצר. הפרומפט נושא את הסגנון, האינסטרומנטציה ומצב הרוח; המילים מושרות ולא מתוארות, ושדה מילים ריק יוצר רצועה אינסטרומנטלית. זהו צומת בטא והחיוב מתבצע לפי שניות GPU.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `פרומפט` | תיאור השיר: סגנון, אינסטרומנטציה ומצב רוח. רווחים בתחילה ובסוף מוסרים לפני השליחה. | STRING | כן | 1 עד 4096 תווים |
| `מילים` | מילים לשירה. השאר ריק לקבלת קטע אינסטרומנטלי. | STRING | לא | 0 עד 4096 תווים |
| `seed` | זרע אקראי שקובע את התוצאה שנוצרת (ברירת מחדל: 42). | INT | כן | 0 עד 9223372036854775807 |
| `max_duration` | המשך הארוך ביותר האפשרי של הרצועה, בשניות (ברירת מחדל: 120.0). המודל יכול לסיים את השיר מוקדם יותר. | FLOAT | כן | 0.04 עד 360.0 (צעד: 0.04) |
| `audio_quality` | קצב סיביות של הפלט. `"V0"` הוא קצב סיביות משתנה והאיכות הגבוהה מבין השלושה (ברירת מחדל: `"V0"`). | COMBO | כן | `"V0"`<br>`"128k"`<br>`"320k"` |
