# ذخیره سه‌بعدی (پیشرفته)

یک مدل سه‌بعدی را در فایلی در پوشه خروجی ComfyUI ذخیره می‌کند و پیش‌نمایشی از صحنه ذخیره‌شده تولید می‌کند. همچنین مدل سه‌بعدی، جای‌گذاری آن در صحنه، اطلاعات دوربین و ابعاد ویوپورت را به گره‌های پایین‌دستی منتقل می‌کند. زمانی که جای‌گذاری مدل یا اطلاعات دوربین متصل نباشد، گره از مقادیر ذخیره‌شده در وضعیت ویوپورت استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | فایل مدل سه‌بعدی از یک گره سه‌بعدی بالادستی. | FILE3D | بله | GLB<br>GLTF<br>FBX<br>OBJ<br>STL<br>USDZ<br>Any |
| `filename_prefix` | پیشوندی که برای نام فایل ذخیره‌شده استفاده می‌شود (پیش‌فرض: "3d/ComfyUI"). | STRING | بله | متن آزاد |
| `viewport_state` | وضعیت ویوپورت شامل اطلاعات دوربین و جای‌گذاری مدل، که معمولاً از یک گره Load 3D می‌آید. | LOAD3D | بله | - |
| `model_3d_info` | جای‌گذاری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی Y-up). در صورت اتصال، جای‌گذاری مدل ذخیره‌شده در `viewport_state` را بازنویسی می‌کند. | LOAD3DMODELINFO | خیر | - |
| `camera_info` | اطلاعات دوربین ویوپورت: موقعیت، هدف نگاه (look-at)، زوم و نوع. در صورت اتصال، اطلاعات دوربین ذخیره‌شده در `viewport_state` را بازنویسی می‌کند. | LOAD3DCAMERA | خیر | - |
| `width` | عرض رندر ویوپورت بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع رندر ویوپورت بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

توجه: `model_3d_info` و `camera_info` اختیاری هستند. زمانی که هر یک از این ورودی‌ها متصل نباشد، گره به مقادیر متناظر ذخیره‌شده در `viewport_state` بازمی‌گردد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل مدل سه‌بعدی که از ورودی عبور داده شده است. | FILE3D |
| `model_3d_info` | جای‌گذاری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی Y-up). | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین ویوپورت: موقعیت، هدف نگاه (look-at)، زوم و نوع. | LOAD3DCAMERA |
| `width` | مقدار عرض رندر که از ورودی عبور داده شده است. | INT |
| `height` | مقدار ارتفاع رندر که از ورودی عبور داده شده است. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Save3DAdvanced/fa.md)
