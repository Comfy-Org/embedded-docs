# Сохранить 3D (расширенно)

Сохраняет 3D-модель в файл в выходном каталоге ComfyUI и создаёт предпросмотр сохранённой сцены. Также передаёт 3D-модель, её размещение в сцене, информацию о камере и размеры вьюпорта дальше в нижестоящие узлы. Если размещение модели или информация о камере не подключены, узел использует значения, сохранённые в состоянии вьюпорта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл 3D-модели из вышестоящего 3D-узла. | FILE3D | Да | GLB<br>GLTF<br>FBX<br>OBJ<br>STL<br>USDZ<br>Any |
| `filename_prefix` | Префикс, используемый для имени сохраняемого файла (по умолчанию: "3d/ComfyUI"). | STRING | Да | Free text |
| `viewport_state` | Состояние вьюпорта, содержащее информацию о камере и размещении модели, обычно из узла Load 3D. | LOAD3D | Да | - |
| `model_3d_info` | Размещение каждой модели в сцене: позиция, поворот и масштаб (мировое пространство Y-up). Переопределяет размещение модели, сохранённое в `viewport_state`, при подключении. | LOAD3DMODELINFO | Нет | - |
| `camera_info` | Информация о камере вьюпорта: позиция, цель взгляда, зум и тип. Переопределяет информацию о камере, сохранённую в `viewport_state`, при подключении. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендеринга вьюпорта в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |
| `height` | Высота рендеринга вьюпорта в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |

Примечание: `model_3d_info` и `camera_info` необязательны. Если какой-либо из этих входов не подключён, узел использует соответствующие значения, сохранённые в `viewport_state`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Файл 3D-модели, переданный со входа. | FILE3D |
| `model_3d_info` | Размещение каждой модели в сцене: позиция, поворот и масштаб (мировое пространство Y-up). | LOAD3DMODELINFO |
| `camera_info` | Информация о камере вьюпорта: позиция, цель взгляда, зум и тип. | LOAD3DCAMERA |
| `width` | Значение ширины рендеринга, переданное со входа. | INT |
| `height` | Значение высоты рендеринга, переданное со входа. | INT |
