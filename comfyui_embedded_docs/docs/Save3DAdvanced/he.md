# שמירת תלת-ממד (מתקדם)

שומר מודל תלת-ממדי לקובץ בתיקיית הפלט של ComfyUI ומייצר תצוגה מקדימה של הסצנה שנשמרה. הוא גם מעביר הלאה לצמתים במורד הזרימה את המודל התלת-ממדי, את הצבתו בסצנה, מידע על המצלמה וממדי אזור התצוגה. כאשר הצבת המודל או מידע המצלמה אינם מחוברים, הצומת משתמש בערכים המאוחסנים במצב אזור התצוגה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | קובץ מודל תלת-ממדי מצומת 3D במעלה הזרימה. | FILE3D | כן | GLB<br>GLTF<br>FBX<br>OBJ<br>STL<br>USDZ<br>Any |
| `filename_prefix` | קידומת המשמשת לשם הקובץ הנשמר (ברירת מחדל: "3d/ComfyUI"). | STRING | כן | Free text |
| `viewport_state` | מצב אזור התצוגה המכיל מידע על מצלמה והצבת מודל, בדרך כלל מצומת Load 3D. | LOAD3D | כן | - |
| `model_3d_info` | הצבה של כל מודל בסצנה: מיקום, סיבוב וקנה מידה (מרחב עולמי עם Y למעלה). עוקף את הצבת המודל המאוחסנת ב-`viewport_state` כאשר הוא מחובר. | LOAD3DMODELINFO | לא | - |
| `camera_info` | מידע על מצלמת אזור התצוגה: מיקום, מטרת look-at, זום וסוג. עוקף את מידע המצלמה המאוחסן ב-`viewport_state` כאשר הוא מחובר. | LOAD3DCAMERA | לא | - |
| `width` | רוחב הרינדור של אזור התצוגה בפיקסלים (ברירת מחדל: 1024). | INT | כן | 1 to 4096 |
| `height` | גובה הרינדור של אזור התצוגה בפיקסלים (ברירת מחדל: 1024). | INT | כן | 1 to 4096 |

הערה: `model_3d_info` ו-`camera_info` הם אופציונליים. כאשר אחד מהקלטים אינו מחובר, הצומת חוזר לערכים המתאימים המאוחסנים ב-`viewport_state`.
