# ویدیو Grok

گره Grok Video یک ویدیوی کوتاه از یک توصیف متنی تولید می‌کند. می‌تواند با استفاده از یک prompt ویدیویی را از صفر بسازد، یا از یک تصویر ورودی واحد ویدیو تولید کند. این گره درخواست را به یک API خارجی می‌فرستد و ویدیوی تولیدشده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده برای تولید ویدیو (پیش‌فرض: `"grok-imagine-video-1.5-lite"`). | COMBO | بله | `"grok-imagine-video"`<br>`"grok-imagine-video-1.5"`<br>`"grok-imagine-video-1.5-lite"` |
| `راهنما` | توصیف متنی ویدیوی موردنظر. برای مدل‌های `grok-imagine-video-1.5` زمانی که تصویر ورودی ارائه شود، اختیاری است. | STRING | بله | - |
| `وضوح` | رزولوشن ویدیوی خروجی. `1080p` برای `grok-imagine-video` در دسترس نیست. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبت ابعاد` | نسبت ابعاد ویدیوی خروجی. زمانی که تصویر ورودی ارائه شود نادیده گرفته می‌شود؛ ویدیو از نسبت ابعاد تصویر تبعیت می‌کند. | COMBO | بله | `"auto"`<br>`"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `مدت زمان` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 6). | INT | بله | 1 تا 15 |
| `بذر` | دانه (Seed) برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `تصویر` | تصویر شروع اختیاری. اگر حذف شود، ویدیو فقط از روی توصیف متنی تولید می‌شود. | IMAGE | خیر | - |

**توجه:** زمانی که یک `image` ارائه می‌شود، فقط یک تصویر ورودی پشتیبانی می‌شود؛ ارائه چند تصویر باعث خطا می‌شود. زمانی که هیچ تصویری ارائه نشده باشد، یا هنگام استفاده از `grok-imagine-video` حتی با وجود تصویر، `prompt` پس از حذف فاصله‌های خالی باید غیرخالی باشد. برای مدل‌های `grok-imagine-video-1.5`، `prompt` تنها زمانی اختیاری است که تصویر ورودی ارائه شده باشد. رزولوشن `1080p` برای `grok-imagine-video` در دسترس نیست. وقتی `aspect_ratio` روی `"auto"` تنظیم شده باشد، نسبت ابعاد به‌طور خودکار توسط سرویس انتخاب می‌شود؛ وقتی تصویر ورودی ارائه شود، `aspect_ratio` نادیده گرفته می‌شود و ویدیو از نسبت ابعاد تصویر تبعیت می‌کند.
