# ویدیو Grok

گره Grok Video ویدیوی کوتاهی را از روی توضیح متنی تولید می‌کند. این گره می‌تواند با استفاده از یک prompt ویدیو را از ابتدا بسازد یا از یک تصویر ورودی، ویدیو تولید کند. گره درخواست را به یک API خارجی ارسال کرده و ویدیوی تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید ویدیو استفاده می‌شود. | COMBO | بله | `"grok-imagine-video"`<br>`"grok-imagine-video-1.5"` |
| `راهنما` | توضیح متنی ویدیوی موردنظر. برای `grok-imagine-video-1.5` زمانی که تصویر ورودی ارائه شود اختیاری است. | STRING | بله | - |
| `وضوح` | رزولوشن ویدیوی خروجی. 1080p فقط برای `grok-imagine-video-1.5` در دسترس است. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبت ابعاد` | نسبت ابعاد ویدیوی خروجی. | COMBO | بله | `"auto"`<br>`"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `مدت زمان` | مدت‌زمان ویدیوی خروجی به ثانیه (پیش‌فرض: 6). | INT | بله | 1 تا 15 |
| `بذر` | Seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `تصویر` | تصویر شروع اختیاری. اگر حذف شود، ویدیو تنها از روی متن prompt تولید می‌شود. | IMAGE | خیر | - |

**نکته:** وقتی `image` ارائه می‌شود، فقط یک تصویر ورودی پشتیبانی می‌شود؛ ارائه چند تصویر باعث خطا می‌شود. `prompt` باید پس از حذف فاصله‌های ابتدا و انتها غیرخالی باشد، چه زمانی که هیچ تصویری ارائه نمی‌شود، چه هنگام استفاده از `grok-imagine-video` حتی با وجود تصویر. برای `grok-imagine-video-1.5`، `prompt` فقط زمانی که تصویر ورودی ارائه شود اختیاری است. رزولوشن `1080p` فقط برای `grok-imagine-video-1.5` در دسترس است. وقتی `aspect_ratio` روی `"auto"` تنظیم شود، نسبت ابعاد به‌طور خودکار توسط سرویس انتخاب می‌شود.
