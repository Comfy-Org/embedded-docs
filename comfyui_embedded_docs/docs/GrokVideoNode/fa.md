# ویدیو Grok

گره Grok Video یک ویدیوی کوتاه از روی توضیحات متنی تولید می‌کند. این گره می‌تواند ویدیویی را از ابتدا با استفاده از یک پرامپت بسازد، یا یک تصویر ورودی واحد را متحرک کند و به‌صورت اختیاری توسط پرامپت هدایت شود. گره درخواستی به یک API خارجی ارسال می‌کند و ویدیوی تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید ویدیو استفاده می‌شود. | COMBO | بله | "grok-imagine-video"<br>"grok-imagine-video-1.5" |
| `prompt` | توضیح متنی ویدیوی موردنظر. برای grok-imagine-video-1.5 زمانی که تصویر ورودی ارائه شده باشد، اختیاری است. | STRING | بله | - |
| `resolution` | رزولوشن ویدیوی خروجی. 1080p فقط برای grok-imagine-video-1.5 در دسترس است. | COMBO | بله | "480p"<br>"720p"<br>"1080p" |
| `aspect_ratio` | نسبت ابعاد ویدیوی خروجی (پیش‌فرض: "auto"). | COMBO | بله | "auto"<br>"16:9"<br>"4:3"<br>"3:2"<br>"1:1"<br>"2:3"<br>"3:4"<br>"9:16" |
| `duration` | مدت زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 6). | INT | بله | 1 تا 15 |
| `seed` | seed برای تعیین اینکه آیا گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `image` | تصویر شروع اختیاری. اگر حذف شود، ویدیو فقط از روی پرامپت متنی تولید می‌شود. | IMAGE | خیر | - |

**نکته:**
- رزولوشن «1080p» فقط با مدل `grok-imagine-video-1.5` در دسترس است. انتخاب آن با `grok-imagine-video` باعث بروز خطا می‌شود.
- فقط یک تصویر ورودی پشتیبانی می‌شود. ارائه چند تصویر باعث بروز خطا می‌شود.
- `prompt` الزامی است مگر اینکه مدل روی `grok-imagine-video-1.5` تنظیم شده باشد و تصویر ورودی ارائه شود. وقتی الزامی است، پرامپت باید پس از حذف فاصله‌ها حداقل ۱ کاراکتر باشد.
- `seed` فقط تعیین می‌کند که آیا گره دوباره اجرا شود؛ نتایج تولیدشده بدون توجه به مقدار seed قطعی نیستند.
