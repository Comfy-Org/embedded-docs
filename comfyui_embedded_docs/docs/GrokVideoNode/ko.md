# Grok 비디오

Grok Video 노드는 텍스트 설명에서 짧은 비디오를 생성합니다. 프롬프트를 사용하여 처음부터 비디오를 만들거나, 선택적으로 프롬프트의 안내에 따라 단일 입력 이미지를 애니메이션화할 수 있습니다. 이 노드는 외부 API에 요청을 보내고 생성된 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다. | COMBO | 예 | "grok-imagine-video"<br>"grok-imagine-video-1.5" |
| `prompt` | 원하는 비디오에 대한 텍스트 설명입니다. 입력 이미지가 제공된 경우 `grok-imagine-video-1.5`에서는 선택 사항입니다. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. 1080p는 `grok-imagine-video-1.5`에서만 사용할 수 있습니다. | COMBO | 예 | "480p"<br>"720p"<br>"1080p" |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다(기본값: "auto"). | COMBO | 예 | "auto"<br>"16:9"<br>"4:3"<br>"3:2"<br>"1:1"<br>"2:3"<br>"3:4"<br>"9:16" |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 6). | INT | 예 | 1 to 15 |
| `seed` | 노드가 다시 실행되어야 하는지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0 to 2147483647 |
| `image` | 선택적 시작 이미지입니다. 생략하면 텍스트 프롬프트만으로 비디오가 생성됩니다. | IMAGE | 아니요 | - |

**참고:**

- "1080p" 해상도는 `grok-imagine-video-1.5` 모델에서만 사용할 수 있습니다. `grok-imagine-video`에서 선택하면 오류가 발생합니다.
- 입력 이미지는 하나만 지원됩니다. 여러 개의 이미지를 제공하면 오류가 발생합니다.
- `prompt`는 모델이 `grok-imagine-video-1.5`로 설정되고 입력 이미지가 제공되는 경우가 아니면 필수입니다. 필수인 경우 프롬프트는 공백을 제거한 후 최소 1자 이상이어야 합니다.
- `seed`는 노드가 다시 실행되는지 여부만 결정합니다. 생성된 결과는 시드 값과 관계없이 비결정적입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오입니다. | VIDEO |
