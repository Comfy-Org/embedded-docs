# Grok Video

Узел Grok Video генерирует короткое видео из текстового описания. Он может создать видео с нуля с помощью промпта или сгенерировать видео из одного входного изображения. Узел отправляет запрос во внешний API и возвращает сгенерированное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации видео (по умолчанию: `"grok-imagine-video-1.5-lite"`). | COMBO | Да | `"grok-imagine-video"`<br>`"grok-imagine-video-1.5"`<br>`"grok-imagine-video-1.5-lite"` |
| `prompt` | Текстовое описание желаемого видео. Необязателен для моделей `grok-imagine-video-1.5`, когда предоставлено входное изображение. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. `1080p` недоступно для `grok-imagine-video`. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. Игнорируется, если предоставлено входное изображение; видео следует соотношению сторон изображения. | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 6). | INT | Да | от 1 до 15 |
| `seed` | Сид для определения, должен ли узел перезапуститься; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `image` | Необязательное начальное изображение. Если не указано, видео генерируется только по текстовому промпту. | IMAGE | Нет | - |

**Примечание:** Если предоставлено `image`, поддерживается только одно входное изображение; передача нескольких изображений вызовет ошибку. `prompt` должен быть непустым после удаления пробелов, если изображение не предоставлено, или при использовании `grok-imagine-video` даже с изображением. Для моделей `grok-imagine-video-1.5` параметр `prompt` необязателен только при наличии входного изображения. Разрешение `1080p` недоступно для `grok-imagine-video`. Когда для `aspect_ratio` установлено значение `"auto"`, соотношение сторон выбирается сервисом автоматически; если предоставлено входное изображение, `aspect_ratio` игнорируется, и видео следует соотношению сторон изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео. | VIDEO |
