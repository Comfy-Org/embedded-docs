# Grok Video

Узел Grok Video генерирует короткое видео по текстовому описанию. Он может создать видео с нуля на основе промпта или анимировать одно входное изображение, при необходимости следуя промпту. Узел отправляет запрос к внешнему API и возвращает сгенерированное видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации видео. | COMBO | Да | "grok-imagine-video"<br>"grok-imagine-video-1.5" |
| `prompt` | Текстовое описание желаемого видео. Необязательно для grok-imagine-video-1.5, если предоставлено входное изображение. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. 1080p доступно только для grok-imagine-video-1.5. | COMBO | Да | "480p"<br>"720p"<br>"1080p" |
| `aspect_ratio` | Соотношение сторон выходного видео (по умолчанию: "auto"). | COMBO | Да | "auto"<br>"16:9"<br>"4:3"<br>"3:2"<br>"1:1"<br>"2:3"<br>"3:4"<br>"9:16" |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 6). | INT | Да | от 1 до 15 |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `image` | Необязательное начальное изображение. Если не указано, видео генерируется только на основе текстового промпта. | IMAGE | Нет | - |

**Примечание:**
- Разрешение «1080p» доступно только с моделью `grok-imagine-video-1.5`. Выбор его с `grok-imagine-video` вызывает ошибку.
- Поддерживается только одно входное изображение. Передача нескольких изображений вызывает ошибку.
- `prompt` обязателен, если только модель не установлена на `grok-imagine-video-1.5` и не предоставлено входное изображение. Если он обязателен, промпт должен содержать не менее 1 символа после удаления пробелов по краям.
- `seed` определяет только, должен ли узел перезапускаться; сгенерированные результаты недетерминированы независимо от значения сида.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео. | VIDEO |
