# Grok Video

Узел Grok Video генерирует короткое видео по текстовому описанию. Он может создать видео с нуля по запросу (prompt) или сгенерировать видео из одного входного изображения. Узел отправляет запрос во внешний API и возвращает сгенерированное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации видео. | COMBO | Да | `"grok-imagine-video"`<br>`"grok-imagine-video-1.5"` |
| `prompt` | Текстовое описание желаемого видео. Необязательно для grok-imagine-video-1.5, если предоставлено входное изображение. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. 1080p доступно только для grok-imagine-video-1.5. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 6). | INT | Да | от 1 до 15 |
| `seed` | Seed для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `image` | Необязательное начальное изображение. Если не указано, видео генерируется только из текстового запроса. | IMAGE | Нет | - |

**Примечание:** При предоставлении `image` поддерживается только одно входное изображение; передача нескольких изображений приведет к ошибке. Значение `prompt` должно быть непустым после удаления пробелов, если изображение не предоставлено, или при использовании `grok-imagine-video` даже с изображением. Для `grok-imagine-video-1.5` параметр `prompt` является необязательным только при предоставлении входного изображения. Разрешение `1080p` доступно только для `grok-imagine-video-1.5`. Когда для `aspect_ratio` установлено значение `"auto"`, соотношение сторон выбирается сервисом автоматически.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео. | VIDEO |
