# Grok動画生成

### Grok Video ノード

Grok Video ノードは、テキスト記述から短いビデオを生成します。プロンプトを使ってゼロからビデオを作成することも、単一の入力画像をアニメーション化することもできます。その際、必要に応じてプロンプトでガイドできます。このノードは外部APIにリクエストを送信し、生成されたビデオを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ビデオ生成に使用するモデル。 | COMBO | はい | "grok-imagine-video"<br>"grok-imagine-video-1.5" |
| `prompt` | 希望するビデオのテキスト説明。入力画像が提供されている場合、grok-imagine-video-1.5ではオプションです。 | STRING | はい | - |
| `resolution` | 出力ビデオの解像度。1080pはgrok-imagine-video-1.5でのみ利用できます。 | COMBO | はい | "480p"<br>"720p"<br>"1080p" |
| `aspect_ratio` | 出力ビデオのアスペクト比（デフォルト: "auto"）。 | COMBO | はい | "auto"<br>"16:9"<br>"4:3"<br>"3:2"<br>"1:1"<br>"2:3"<br>"3:4"<br>"9:16" |
| `duration` | 出力ビデオの長さ（秒）（デフォルト: 6）。 | INT | はい | 1 to 15 |
| `seed` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0 to 2147483647 |
| `image` | オプションの開始画像。省略した場合、ビデオはテキストプロンプトのみから生成されます。 | IMAGE | いいえ | - |

**注記：**
- 「1080p」解像度は、`grok-imagine-video-1.5` モデルでのみ利用できます。`grok-imagine-video` で選択するとエラーが発生します。
- 入力画像は1枚のみサポートされています。複数の画像を指定するとエラーが発生します。
- `prompt` は、モデルが `grok-imagine-video-1.5` に設定され、入力画像が提供されている場合を除き、必須です。必須の場合、プロンプトは空白を除去した後に少なくとも1文字以上である必要があります。
- `seed` はノードが再実行されるかどうかのみを決定します。生成結果はシード値に関係なく非決定的です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成されたビデオ。 | VIDEO |
