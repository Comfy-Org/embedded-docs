# VoxelToMesh

Узел VoxelToMesh преобразует 3D воксельные данные в геометрию меша, извлекая поверхность при заданном пороговом значении. Он предлагает два алгоритма извлечения поверхности: базовый метод, создающий простые грани в форме блоков, и метод surface net, который создаёт более гладкие и детализированные меши. Узел обрабатывает каждую воксельную сетку во входных данных и генерирует вершины и грани, образующие 3D-представление меша.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voxel` | Входные воксельные данные для преобразования в геометрию меша | VOXEL | Да | - |
| `алгоритм` | Алгоритм, используемый для извлечения поверхности. `"surface net"` создаёт более гладкие меши, а `"basic"` — простые грани в форме блоков (по умолчанию: `"surface net"`) | COMBO | Да | `"surface net"`<br>`"basic"` |
| `порог` | Пороговое значение для извлечения поверхности. Воксели со значениями выше этого порога считаются твёрдыми (по умолчанию: 0.6) | FLOAT | Да | -1.0 до 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MESH` | Сгенерированный 3D-меш, содержащий вершины и грани из всех входных воксельных сеток. Если все воксельные сетки создают меши с идентичной формой, выходные данные представляют собой тензор, собранный в стек; в противном случае возвращается пакет переменной длины | MESH |
