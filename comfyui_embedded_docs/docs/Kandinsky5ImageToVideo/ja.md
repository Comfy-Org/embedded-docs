# Kandinsky5ImageToVideo

Kandinsky5ImageToVideo ノードは、Kandinsky モデルを使用した動画生成のために、条件付けデータと潜在空間データを準備します。このノードは、空の動画用潜在テンソルを作成し、オプションで開始画像をエンコードして生成動画の最初のフレームをガイドし、それに応じてポジティブ条件付けとネガティブ条件付けを変更します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 動画生成をガイドするポジティブ条件付けプロンプト。 | CONDITIONING | はい | N/A |
| `negative` | 特定の概念から動画生成を遠ざけるためのネガティブ条件付けプロンプト。 | CONDITIONING | はい | N/A |
| `vae` | オプションの開始画像を潜在空間にエンコードするために使用される VAE モデル。 | VAE | はい | N/A |
| `width` | 出力動画の幅（ピクセル単位）（デフォルト: 768）。 | INT | はい | 16 to 8192 (step 16) |
| `height` | 出力動画の高さ（ピクセル単位）（デフォルト: 512）。 | INT | はい | 16 to 8192 (step 16) |
| `length` | 動画のフレーム数（デフォルト: 121）。 | INT | はい | 1 to 8192 (step 4) |
| `batch_size` | 同時に生成する動画シーケンスの数（デフォルト: 1）。 | INT | はい | 1 to 4096 |
| `start_image` | オプションの開始画像。指定すると、エンコードされてモデルの出力潜在表現のノイズを含む開始部分を置き換えるために使用されます。 | IMAGE | いいえ | N/A |

**注記:** `start_image` が指定された場合、バイリニア補間を使用して指定された `width` と `height` に合わせてリサイズされます。画像の最初の `length` フレームのみがエンコードに使用されます。その後、エンコードされた潜在表現は、開始フレームをマークするマスクとともに `positive` 条件付けと `negative` 条件付けの両方に注入され、クリーンなエンコード画像が生成動画のノイズを含む開始部分を置き換えます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | エンコードされた開始画像データで更新される可能性のある、変更後のポジティブ条件付け。 | CONDITIONING |
| `negative` | エンコードされた開始画像データで更新される可能性のある、変更後のネガティブ条件付け。 | CONDITIONING |
| `latent` | 指定された `batch_size`、`length`、`height`、`width` に基づく形状で、ゼロで埋められた空の動画用潜在テンソル。 | LATENT |
| `cond_latent` | 提供された開始画像のクリーンなエンコード済み潜在表現。モデルの出力潜在表現のノイズを含む開始部分を置き換えるために使用されます。`start_image` が指定されていない場合は空になります。 | LATENT |
