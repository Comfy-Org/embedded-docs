# Kandinsky5ImageToVideo

צומת Kandinsky5ImageToVideo מכין נתוני קונדישנינג ולטנט ליצירת וידאו באמצעות מודל Kandinsky. הוא יוצר לטנט וידאו ריק בגודל המתאים ל-`width`, `height`, `length` ו-`batch_size` המבוקשים, ויכול באופן אופציונלי לקודד תמונת התחלה כדי להנחות את הפריימים הראשוניים של הווידאו הנוצר על ידי עדכון הקונדישנינג החיובי והשלילי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | פרומפטים של קונדישנינג חיובי שמנחים את יצירת הווידאו. | CONDITIONING | כן | N/A |
| `negative` | פרומפטים של קונדישנינג שלילי שמרחיקים את יצירת הווידאו ממושגים מסוימים. | CONDITIONING | כן | N/A |
| `vae` | מודל ה-VAE המשמש לקידוד תמונת ההתחלה האופציונלית אל מרחב הלטנט. | VAE | כן | N/A |
| `width` | רוחב הווידאו בפלט בפיקסלים (ברירת מחדל: 768). | INT | כן | 16 עד 16384 (צעד 16) |
| `height` | גובה הווידאו בפלט בפיקסלים (ברירת מחדל: 512). | INT | כן | 16 עד 16384 (צעד 16) |
| `length` | מספר הפריימים בווידאו (ברירת מחדל: 121). | INT | כן | 1 עד 16384 (צעד 4) |
| `batch_size` | מספר רצפי הווידאו ליצירה בו-זמנית (ברירת מחדל: 1). | INT | כן | 1 עד 4096 |
| `start_image` | תמונת התחלה אופציונלית או אצוות פריימים. אם מסופקת, היא מקודדת ומשמשת להחלפת ההתחלה הרועשת של לטנטים בפלט המודל. | IMAGE | לא | N/A |

**הערה:** כאשר מסופק `start_image`, גודלו מותאם אוטומטית כך שיתאים ל-`width` ול-`height` שצוינו, באמצעות אינטרפולציה בילינארית. רק `length` הפריימים הראשונים מאצוות התמונות משמשים לקידוד; פריימים נוספים מתעלמים. אם באצוות התמונות יש פחות מ-`length` פריימים, משתמשים רק בפריימיםเหล่านั้น. רק ערוצי ה-RGB של התמונה מקודדים. הלטנט המקודד מוזרק לאחר מכן גם לקונדישנינג `positive` וגם לקונדישנינג `negative` כדי להנחות את המראה ההתחלתי של הווידאו, והפריימים המקודדים הנקיים מחליפים את ההתחלה הרועשת של לטנטים בפלט המודל.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | הקונדישנינג החיובי שהשתנה ועודכן בנתוני תמונת התחלה מקודדים כאשר מסופק `start_image`. | CONDITIONING |
| `negative` | הקונדישנינג השלילי שהשתנה ועודכן בנתוני תמונת התחלה מקודדים כאשר מסופק `start_image`. | CONDITIONING |
| `latent` | לטנט וידאו ריק. טנסור לטנט מלא באפסים, בצורה המתאימה לממדים שצוינו. | LATENT |
| `cond_latent` | תמונות התחלה מקודדות נקיות, המשמשות להחלפת ההתחלה הרועשת של לטנטים בפלט המודל. ריק כאשר לא מסופק `start_image`. | LATENT |
