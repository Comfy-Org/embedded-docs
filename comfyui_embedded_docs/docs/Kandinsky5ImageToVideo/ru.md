# Kandinsky5ImageToVideo

Узел Kandinsky5ImageToVideo подготавливает данные кондиционирования и латентного пространства для генерации видео с использованием модели Kandinsky. Он создает пустой латентный тензор видео и может опционально кодировать начальное изображение для управления начальными кадрами генерируемого видео, соответствующим образом изменяя положительное и отрицательное кондиционирование.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование (промпты) для управления генерацией видео. | CONDITIONING | Да | N/A |
| `negative` | Отрицательное кондиционирование (промпты), чтобы увести генерацию видео от нежелательных концепций. | CONDITIONING | Да | N/A |
| `vae` | Модель VAE, используемая для кодирования опционального начального изображения в латентное пространство. | VAE | Да | N/A |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 768). | INT | Да | 16 to 8192 (step 16) |
| `height` | Высота выходного видео в пикселях (по умолчанию: 512). | INT | Да | 16 to 8192 (step 16) |
| `length` | Количество кадров в видео (по умолчанию: 121). | INT | Да | 1 to 8192 (step 4) |
| `batch_size` | Количество видеопоследовательностей, генерируемых одновременно (по умолчанию: 1). | INT | Да | 1 to 4096 |
| `start_image` | Опциональное начальное изображение. Если указано, оно кодируется и используется для замены шумного начала латентных тензоров, выводимых моделью. | IMAGE | Нет | N/A |

**Примечание:** Если указано `start_image`, оно масштабируется до заданных `width` и `height` с помощью билинейной интерполяции. Для кодирования используются только первые `length` кадров изображения. Закодированный латентный тензор затем внедряется как в положительное, так и в отрицательное кондиционирование, вместе с маской, отмечающей начальные кадры, чтобы чистое закодированное изображение заменяло шумное начало генерируемого видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование, возможно обновленное данными закодированного начального изображения. | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование, возможно обновленное данными закодированного начального изображения. | CONDITIONING |
| `latent` | Пустой латентный тензор видео, заполненный нулями и имеющий форму, соответствующую указанным `batch_size`, `length`, `height` и `width`. | LATENT |
| `cond_latent` | Чистое закодированное латентное представление предоставленных начальных изображений. Используется для замены шумного начала латентных тензоров, выводимых моделью. Пусто, если `start_image` не указано. | LATENT |
