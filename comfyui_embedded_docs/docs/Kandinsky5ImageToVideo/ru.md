# Kandinsky5ImageToVideo

Узел Kandinsky5ImageToVideo подготавливает данные кондиционирования и латентные данные для генерации видео с использованием модели Kandinsky. Он создаёт пустой видеолатент с размерами, соответствующими указанным ширине, высоте, длине и размеру пакета, и может дополнительно закодировать начальное изображение, чтобы направлять начальные кадры генерируемого видео путём обновления положительного и отрицательного кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительные промпты кондиционирования, направляющие генерацию видео. | CONDITIONING | Да | N/A |
| `негативный` | Негативные промпты кондиционирования, уводящие генерацию видео от определённых концепций. | CONDITIONING | Да | N/A |
| `vae` | Модель VAE, используемая для кодирования необязательного начального изображения в латентное пространство. | VAE | Да | N/A |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 768). | INT | Да | от 16 до 16384 (шаг 16) |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 512). | INT | Да | от 16 до 16384 (шаг 16) |
| `длина` | Количество кадров в видео (по умолчанию: 121). | INT | Да | от 1 до 16384 (шаг 4) |
| `размер_пакета` | Количество видеопоследовательностей, генерируемых одновременно (по умолчанию: 1). | INT | Да | от 1 до 4096 |
| `стартовое_изображение` | Необязательное начальное изображение или пакет кадров. Если указано, оно кодируется и используется для замены зашумлённого начала выходных латентов модели. | IMAGE | Нет | N/A |

**Примечание:** Когда указан `start_image`, он автоматически масштабируется до указанных `width` и `height` с использованием билинейной интерполяции. Для кодирования используются только первые `length` кадров пакета изображений; любые дополнительные кадры игнорируются. Если пакет изображений содержит меньше `length` кадров, используются только эти кадры. Кодируются только RGB-каналы изображения. Затем закодированный латент внедряется в кондиционирование `positive` и `negative`, чтобы направлять начальный вид видео, а чистые закодированные кадры заменяют зашумлённое начало выходных латентов модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённое положительное кондиционирование, обновлённое закодированными данными начального изображения, когда указан `start_image`. | CONDITIONING |
| `negative` | Изменённое отрицательное кондиционирование, обновлённое закодированными данными начального изображения, когда указан `start_image`. | CONDITIONING |
| `latent` | Пустой видеолатент. Латентный тензор, заполненный нулями, с формой, соответствующей указанным размерам. | LATENT |
| `cond_latent` | Чистые закодированные начальные изображения, используемые для замены зашумлённого начала выходных латентов модели. Пусто, если `start_image` не указан. | LATENT |
