# Kandinsky5ImageToVideo

Узел Kandinsky5ImageToVideo подготавливает данные кондиционирования и латентного пространства для генерации видео с помощью модели Kandinsky. Он создаёт пустой латентный тензор видео и может дополнительно кодировать стартовое изображение для управления начальными кадрами генерируемого видео, соответствующим образом изменяя положительное и отрицательное кондиционирование.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительные промпты кондиционирования, направляющие генерацию видео. | CONDITIONING | Да | N/A |
| `негативный` | Отрицательные промпты кондиционирования, которые уводят генерацию видео от нежелательных концепций. | CONDITIONING | Да | N/A |
| `vae` | Модель VAE, используемая для кодирования необязательного стартового изображения в латентное пространство. | VAE | Да | N/A |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 768). | INT | Да | от 16 до 16384 (шаг 16) |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 512). | INT | Да | от 16 до 16384 (шаг 16) |
| `длина` | Количество кадров в видео (по умолчанию: 121). | INT | Да | от 1 до 16384 (шаг 4) |
| `размер_пакета` | Количество видеопоследовательностей для одновременной генерации (по умолчанию: 1). | INT | Да | от 1 до 4096 |
| `стартовое_изображение` | Необязательное стартовое изображение или пакет кадров. Если указано, оно кодируется и используется для замены шумного начального состояния латентных данных модели. | IMAGE | Нет | N/A |

**Примечание:** если указано `start_image`, оно автоматически масштабируется до заданных значений `width` и `height` с помощью билинейной интерполяции. Для кодирования используются только первые `length` кадров из пакета изображений; все дополнительные кадры игнорируются. Если в пакете изображений меньше `length` кадров, используются только эти кадры. Кодируются только RGB-каналы изображения. Затем закодированный латентный тензор внедряется и в положительное, и в отрицательное кондиционирование для управления начальным видом видео, а чистые закодированные кадры заменяют шумное начало латентных данных на выходе модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Изменённое положительное кондиционирование, возможно обновлённое данными закодированного стартового изображения. | CONDITIONING |
| `негативный` | Изменённое отрицательное кондиционирование, возможно обновлённое данными закодированного стартового изображения. | CONDITIONING |
| `latent` | Пустой латентный тензор видео, заполненный нулями и имеющий форму, соответствующую заданным размерам. | LATENT |
| `cond_latent` | Чистые закодированные стартовые изображения, используемые для замены шумного начала латентных данных на выходе модели. Пуст, если `start_image` не указано. | LATENT |
