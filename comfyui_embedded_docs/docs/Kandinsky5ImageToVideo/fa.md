# Kandinsky5ImageToVideo

گره Kandinsky5ImageToVideo داده‌های شرطی‌سازی و فضای نهان را برای تولید ویدیو با استفاده از مدل Kandinsky آماده می‌کند. این گره یک تنسور نهان ویدیوی خالی ایجاد می‌کند و به‌صورت اختیاری می‌تواند یک تصویر شروع را کدگذاری کند تا فریم‌های ابتدایی ویدیوی تولیدشده را هدایت کرده و شرطی‌سازی مثبت و منفی را متناسب با آن اصلاح کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت برای هدایت تولید ویدیو. | CONDITIONING | بله | N/A |
| `منفی` | پرامپت‌های شرطی‌سازی منفی برای دور نگه داشتن تولید ویدیو از مفاهیم خاص. | CONDITIONING | بله | N/A |
| `vae` | مدل VAE مورد استفاده برای کدگذاری تصویر شروع اختیاری در فضای نهان. | VAE | بله | N/A |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 16 تا 16384 (step 16) |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 512). | INT | بله | 16 تا 16384 (step 16) |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 121). | INT | بله | 1 تا 16384 (step 4) |
| `batch_size` | تعداد توالی‌های ویدیویی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `تصویر شروع` | یک تصویر شروع یا دسته‌ای از فریم‌ها به‌صورت اختیاری. در صورت ارائه، کدگذاری شده و برای جایگزینی شروع نویزی خروجی‌های نهان مدل استفاده می‌شود. | IMAGE | خیر | N/A |

**توجه:** وقتی `start_image` ارائه می‌شود، به‌طور خودکار با استفاده از درون‌یابی دوخطی به ابعاد مشخص‌شده `width` و `height` تغییر اندازه می‌یابد. تنها `length` فریم اول از دسته تصویر برای کدگذاری استفاده می‌شود؛ هر فریم اضافی نادیده گرفته می‌شود. اگر دسته تصویر کمتر از `length` فریم داشته باشد، فقط همان تعداد فریم استفاده می‌شود. تنها کانال‌های RGB تصویر کدگذاری می‌شوند. سپس فضای نهان کدگذاری‌شده به هر دو شرطی‌سازی `positive` و `negative` تزریق می‌شود تا ظاهر ابتدایی ویدیو هدایت شود و فریم‌های کدگذاری‌شده تمیز، شروع نویزی خروجی‌های نهان مدل را جایگزین کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده که احتمالاً با داده‌های تصویر شروع کدگذاری‌شده به‌روزرسانی شده است. | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده که احتمالاً با داده‌های تصویر شروع کدگذاری‌شده به‌روزرسانی شده است. | CONDITIONING |
| `latent` | فضای نهان ویدیوی خالی. یک تنسور نهان پر از صفر، با شکل متناسب با ابعاد مشخص‌شده. | LATENT |
| `cond_latent` | تصاویر شروع کدگذاری‌شده تمیز که برای جایگزینی شروع نویزی خروجی‌های نهان مدل استفاده می‌شوند. زمانی که `start_image` ارائه نشود، خالی است. | LATENT |
