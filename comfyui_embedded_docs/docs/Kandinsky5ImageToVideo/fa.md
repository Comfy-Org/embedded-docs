# Kandinsky5ImageToVideo

گره Kandinsky5ImageToVideo داده‌های شرطی‌سازی و لاتنت را برای تولید ویدیو با مدل Kandinsky آماده می‌کند. این گره یک لاتنت ویدیویی خالی هم‌اندازه با عرض، ارتفاع، طول و اندازه دسته درخواستی می‌سازد و می‌تواند به‌صورت اختیاری یک تصویر شروع را رمزگذاری کند تا فریم‌های ابتدایی ویدیوی تولیدشده را با به‌روزرسانی شرطی‌سازی مثبت و منفی هدایت کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت برای هدایت تولید ویدیو. | CONDITIONING | بله | N/A |
| `منفی` | پرامپت‌های شرطی‌سازی منفی برای دور کردن تولید ویدیو از مفاهیم خاص. | CONDITIONING | بله | N/A |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر شروع اختیاری در فضای لاتنت. | VAE | بله | N/A |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 16 تا 16384 (گام 16) |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 512). | INT | بله | 16 تا 16384 (گام 16) |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 121). | INT | بله | 1 تا 16384 (گام 4) |
| `batch_size` | تعداد دنباله‌های ویدیویی که به‌صورت هم‌زمان تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `تصویر شروع` | تصویر شروع اختیاری یا دسته‌ای از فریم‌ها. در صورت ارائه، رمزگذاری می‌شود و برای جایگزینی شروع نویزی لاتنت‌های خروجی مدل استفاده می‌شود. | IMAGE | خیر | N/A |

**توجه:** وقتی `start_image` ارائه شود، به‌طور خودکار با استفاده از درون‌یابی دوخطی تغییر اندازه می‌یابد تا با `width` و `height` مشخص‌شده مطابقت کند. فقط اولین `length` فریم از دسته تصویر برای رمزگذاری استفاده می‌شود؛ هر فریم اضافی نادیده گرفته می‌شود. اگر دسته تصویر کمتر از `length` فریم داشته باشد، فقط همان فریم‌ها استفاده می‌شوند. فقط کانال‌های RGB تصویر رمزگذاری می‌شوند. سپس لاتنت رمزگذاری‌شده به هر دو شرطی‌سازی `positive` و `negative` تزریق می‌شود تا ظاهر اولیه ویدیو را هدایت کند، و فریم‌های رمزگذاری‌شدهٔ تمیز جایگزین شروع نویزی لاتنت‌های خروجی مدل می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده که در صورت ارائه `start_image` با داده‌های تصویر شروع رمزگذاری‌شده به‌روزرسانی می‌شود. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده که در صورت ارائه `start_image` با داده‌های تصویر شروع رمزگذاری‌شده به‌روزرسانی می‌شود. | CONDITIONING |
| `latent` | لاتنت ویدیویی خالی. یک تنسور لاتنت پر از صفر که برای ابعاد مشخص‌شده شکل گرفته است. | LATENT |
| `cond_latent` | تصاویر شروع رمزگذاری‌شدهٔ تمیز، که برای جایگزینی شروع نویزی لاتنت‌های خروجی مدل استفاده می‌شوند. در صورت عدم ارائه `start_image` خالی است. | LATENT |
