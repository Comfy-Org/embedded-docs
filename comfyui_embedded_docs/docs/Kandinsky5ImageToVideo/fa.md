# Kandinsky5ImageToVideo

```markdown
گره Kandinsky5ImageToVideo داده‌های شرطی‌سازی (conditioning) و فضای نهان را برای تولید ویدیو با استفاده از مدل Kandinsky آماده می‌کند. این گره یک تنسور ویدیویی نهان خالی ایجاد می‌کند و به‌صورت اختیاری می‌تواند یک تصویر شروع را برای هدایت فریم‌های اولیه ویدیوی تولیدشده رمزگذاری کند و متناسب با آن، شرطی‌سازی مثبت و منفی را اصلاح نماید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت برای هدایت تولید ویدیو. | CONDITIONING | بله | N/A |
| `negative` | پرامپت‌های شرطی‌سازی منفی برای دور نگه داشتن تولید ویدیو از مفاهیم خاص. | CONDITIONING | بله | N/A |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر شروع اختیاری به فضای نهان. | VAE | بله | N/A |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 16 تا 8192 (گام 16) |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 512). | INT | بله | 16 تا 8192 (گام 16) |
| `length` | تعداد فریم‌های ویدیو (پیش‌فرض: 121). | INT | بله | 1 تا 8192 (گام 4) |
| `batch_size` | تعداد دنباله‌های ویدیویی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `start_image` | یک تصویر شروع اختیاری. در صورت ارائه، رمزگذاری شده و برای جایگزینی شروع نویزی لاتنت‌های خروجی مدل استفاده می‌شود. | IMAGE | خیر | N/A |

**توجه:** وقتی `start_image` ارائه می‌شود، با استفاده از درون‌یابی دوخطی (bilinear interpolation) به اندازه `width` و `height` مشخص‌شده تغییر اندازه می‌دهد. تنها `length` فریم اول تصویر برای رمزگذاری استفاده می‌شود. سپس لاتنت رمزگذاری‌شده به همراه یک ماسک که فریم‌های شروع را مشخص می‌کند، به هر دو شرطی‌سازی `positive` و `negative` تزریق می‌شود؛ بنابراین تصویر رمزگذاری‌شده تمیز، شروع نویزی ویدیوی تولیدشده را جایگزین می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده، که احتمالاً با داده‌های تصویر شروع رمزگذاری‌شده به‌روزرسانی شده است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده، که احتمالاً با داده‌های تصویر شروع رمزگذاری‌شده به‌روزرسانی شده است. | CONDITIONING |
| `latent` | یک تنسور ویدیویی نهان خالی که با صفرها پر شده و بر اساس `batch_size`، `length`، `height` و `width` مشخص‌شده شکل می‌گیرد. | LATENT |
| `cond_latent` | نمایش نهان تمیز و رمزگذاری‌شده از تصاویر شروع ارائه‌شده. برای جایگزینی شروع نویزی لاتنت‌های خروجی مدل استفاده می‌شود. وقتی هیچ `start_image` ارائه نشود، خالی است. | LATENT |
```
