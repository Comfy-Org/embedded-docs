# Tripo P1: من صورة إلى نموذج

Tripo P1: Image to Model يحوّل صورة ثنائية الأبعاد واحدة إلى نموذج ثلاثي الأبعاد باستخدام Tripo P1 API. وهو مُحسَّن لإنشاء شبكات منخفضة المضلعات وجاهزة للألعاب، ويتيح لك الاختيار بين شبكة هندسية فقط أو نموذج مُنسّج بخرائط PBR. يُعاد النموذج النهائي كملف GLB.

## المدخلات

### المدخلات العامة

هذه المعاملات متاحة دائمًا.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | يختار نوع النتيجة. يعيد "Geometry only" شبكة بدون تنسيج؛ بينما يضيف "Textured" خرائط الألوان/PBR ويكشف إعدادات تنسيج إضافية. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `image` | الصورة المصدرية ثنائية الأبعاد المستخدمة لإنشاء النموذج ثلاثي الأبعاد. يلزم توفير صورة واحدة؛ وتُرجع العقدة خطأً إذا لم يتم توفير أي صورة. | IMAGE | نعم | - |
| `enable_image_autofix` | إجراء معالجة مسبقة لصورة الإدخال للحصول على جودة إنشاء أفضل. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `face_limit` | عدد الأوجه المستهدف، 48-20000. القيمة -1 تتيح لـ Tripo الاختيار تكيفيًا. (الافتراضي: -1) | INT | لا | -1 إلى 20000 |
| `model_seed` | البذرة المستخدمة لإنشاء الهندسة بحيث يمكن إعادة إنتاج النتائج. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `auto_size` | تحجيم المخرجات لتقريب الأمتار الواقعية. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `export_uv` | إجراء فك UV أثناء الإنشاء. أوقفه للحصول على تشغيلات أسرع للهندسة فقط. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `compress_geometry` | تطبيق ضغط الهندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن معاينة 3D في ComfyUI لا يمكنها عرضها؛ فك الضغط قبل التحرير. (الافتراضي: False) | BOOLEAN | لا | True<br>False |

### مدخلات Geometry only

لا توجد معاملات إضافية. المخرجات شبكة بدون تنسيج.

### مدخلات Textured

تظهر هذه المعاملات عندما يتم ضبط `output_mode` على "Textured".

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند التفعيل، يتم تفعيل التنسيج الأساسي قسرًا أيضًا. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `texture_quality` | detailed = تنسيجات HD، extreme = تنسيجات 8K فائقة. (الافتراضي: "standard") | COMBO | نعم | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | إعطاء الأولوية للأمانة البصرية للصورة المصدرية، أو المحاذاة لهندسة الشبكة. (الافتراضي: "original_image") | COMBO | نعم | `"original_image"`<br>`"geometry"` |
| `orientation` | تدوير المخرجات لتطابق الصورة المصدرية. ينطبق فقط عند التنسيج. (الافتراضي: "default") | COMBO | نعم | `"default"`<br>`"align_image"` |
| `texture_seed` | البذرة المستخدمة لإنشاء التنسيج بحيث يمكن إعادة إنتاج النتائج المُنسّجة. (الافتراضي: 42) | INT | نعم | 0 إلى 2147483647 |

ملاحظة: عندما يكون `output_mode` هو "Geometry only"، يتم تعطيل التنسيج في الطلب. في وضع "Textured"، يُطلب دائمًا تنسيج لوني؛ يؤدي تعطيل `pbr` إلى إزالة خرائط PBR مع الإبقاء على تنسيج اللون الأساسي، بينما يؤدي تفعيل `pbr` إلى تفعيل التنسيج الأساسي قسرًا أيضًا. يتوفر `texture_alignment` و`orientation` فقط في وضع "Textured".

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | سلسلة نصية تحتوي على اسم ملف النموذج المُنشأ (`<task_id>.glb`). يُحتفظ به للتوافق مع الإصدارات السابقة فقط. | STRING |
| `model task_id` | معرّف المهمة الفريد الذي يعيده Tripo API لمهمة الإنشاء المكتملة. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُنشأ بصيغة GLB. | FILE3DGLB |
