# Tripo P1: Изображение в Модель

Tripo P1: Image to Model преобразует одно 2D-изображение в 3D-модель с помощью Tripo P1 API. Узел оптимизирован для создания низкополигональных мешей, готовых для игр, и позволяет выбрать либо меш только с геометрией, либо текстурированную модель с PBR-картами. Готовая модель возвращается в виде файла GLB.

## Входы

### Общие входы

Эти параметры доступны всегда.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `режим_вывода` | Выбирает тип результата. "Geometry only" возвращает меш без текстуры; "Textured" добавляет цветовые/PBR-карты и открывает дополнительные настройки текстуры. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `изображение` | Исходное 2D-изображение, используемое для генерации 3D-модели. Требуется одно изображение; если оно не предоставлено, узел выдаёт ошибку. | IMAGE | Да | - |
| `включить_автоисправление_изображения` | Предварительно обрабатывает входное изображение для лучшего качества генерации. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `ограничение_граней` | Целевое количество граней, 48–20000. -1 позволяет Tripo выбрать адаптивно. (по умолчанию: -1) | INT | Нет | от -1 до 20000 |
| `seed_модели` | Сид, используемый для генерации геометрии, чтобы результаты можно было воспроизвести. (по умолчанию: 42) | INT | Нет | от 0 до 2147483647 |
| `авторазмер` | Масштабирует выходные данные под примерные реальные метры. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `экспорт_uv` | Выполняет UV-развёртку во время генерации. Отключите для более быстрых запусков только с геометрией. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `сжать_геометрию` | Применяет сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-предпросмотр ComfyUI не может их отображать; распакуйте перед редактированием. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы для режима Geometry only

Дополнительных параметров нет. Выходные данные — меш без текстуры.

### Входы для режима Textured

Эти параметры появляются, когда `output_mode` установлен в "Textured".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включает PBR-карты. Если включено, базовая текстура также принудительно включается. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `texture_quality` | detailed = HD-текстуры, extreme = 8K Ultra текстуры. (по умолчанию: "standard") | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | Приоритет визуальной точности относительно исходного изображения или выравнивание по геометрии меша. (по умолчанию: "original_image") | COMBO | Да | `"original_image"`<br>`"geometry"` |
| `orientation` | Поворачивает выходные данные в соответствии с исходным изображением. Применяется только при текстурировании. (по умолчанию: "default") | COMBO | Да | `"default"`<br>`"align_image"` |
| `texture_seed` | Сид, используемый для генерации текстуры, чтобы текстурированные результаты можно было воспроизвести. (по умолчанию: 42) | INT | Да | от 0 до 2147483647 |

Примечание: Когда `output_mode` имеет значение "Geometry only", текстурирование для запроса отключено. В режиме "Textured" всегда запрашивается цветовая текстура; отключение `pbr` удаляет PBR-карты, но сохраняет базовую цветовую текстуру, а включение `pbr` также принудительно включает базовую текстуру. `texture_alignment` и `orientation` доступны только в режиме "Textured".

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Строка, содержащая имя сгенерированного файла модели (`<task_id>.glb`). Оставлено только для обратной совместимости. | STRING |
| `model task_id` | Уникальный ID задачи, возвращённый Tripo API для завершённой задачи генерации. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
