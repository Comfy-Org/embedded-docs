# TripoP1ImageToModelNode

Tripo P1: Image to Model ממיר תמונה דו-ממדית בודדת למודל תלת-ממדי באמצעות Tripo P1 API. הוא מותאם ליצירת meshes עם מספר פוליגונים נמוך, המתאימים למשחקים, ומאפשר לבחור בין mesh גאומטריה בלבד לבין מודל עם טקסטורה ומפות PBR. המודל המוגמר מוחזר כקובץ GLB.

## קלטים

### קלטים משותפים

פרמטרים אלה זמינים תמיד.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | בוחר את סוג התוצאה. "Geometry only" מחזיר mesh ללא טקסטורה; "Textured" מוסיף צבע/מפות PBR וחושף הגדרות טקסטורה נוספות. | DYNAMIC_COMBO | כן | `"Geometry only"`<br>`"Textured"` |
| `image` | תמונת המקור הדו-ממדית שמשמשת ליצירת המודל התלת-ממדי. נדרשת תמונה בודדת; הצומת תעלה שגיאה אם לא סופקה תמונה. | IMAGE | כן | - |
| `enable_image_autofix` | עיבוד מקדים של תמונת הקלט לקבלת איכות יצירה טובה יותר. (ברירת מחדל: False) | BOOLEAN | לא | True<br>False |
| `face_limit` | מספר הפאות המטרה, 48-20000. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי. (ברירת מחדל: -1) | INT | לא | -1 to 20000 |
| `model_seed` | Seed המשמש ליצירת הגאומטריה כדי שאפשר יהיה לשחזר תוצאות. (ברירת מחדל: 42) | INT | לא | 0 to 2147483647 |
| `auto_size` | שינוי קנה המידה של הפלט כך שיתקרב למטרים בעולם האמיתי. (ברירת מחדל: False) | BOOLEAN | לא | True<br>False |
| `export_uv` | ביצוע UV unwrap במהלך היצירה. כבה זאת להרצות מהירות יותר של גאומטריה בלבד. (ברירת מחדל: True) | BOOLEAN | לא | True<br>False |
| `compress_geometry` | הפעלת דחיסת גאומטריה meshopt (EXT_meshopt_compression). קבצים קטנים יותר, אך תצוגת התלת-ממד של ComfyUI אינה יכולה להציג אותם; יש לבצע דקומפרסיה לפני עריכה. (ברירת מחדל: False) | BOOLEAN | לא | True<br>False |

### קלטים של Geometry only

אין פרמטרים נוספים. הפלט הוא mesh ללא טקסטורה.

### קלטים של Textured

פרמטרים אלה מופיעים כאשר `output_mode` מוגדר ל-"Textured".

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `pbr` | כלול מפות PBR. כאשר מופעל, גם טקסטורת הבסיס נכפית לפעול. (ברירת מחדל: True) | BOOLEAN | כן | True<br>False |
| `texture_quality` | detailed = טקסטורות HD, extreme = טקסטורות 8K Ultra. (ברירת מחדל: "standard") | COMBO | כן | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | תעדוף נאמנות חזותית לתמונת המקור, או התאמה לגאומטריית ה-mesh. (ברירת מחדל: "original_image") | COMBO | כן | `"original_image"`<br>`"geometry"` |
| `orientation` | סיבוב הפלט כך שיתאים לתמונת המקור. חל רק כאשר קיימת טקסטורה. (ברירת מחדל: "default") | COMBO | כן | `"default"`<br>`"align_image"` |
| `texture_seed` | Seed המשמש ליצירת הטקסטורה כדי שאפשר יהיה לשחזר תוצאות עם טקסטורה. (ברירת מחדל: 42) | INT | כן | 0 to 2147483647 |

הערה: כאשר `output_mode` הוא "Geometry only", טקסטורה מושבתת עבור הבקשה. במצב "Textured", תמיד מתבקשת טקסטורת צבע; השבתת `pbr` מסירה את מפות ה-PBR אך משאירה את טקסטורת צבע הבסיס, בעוד שהפעלת `pbr` מפעילה בכוח גם את טקסטורת הבסיס. `texture_alignment` ו-`orientation` זמינים רק במצב "Textured".
