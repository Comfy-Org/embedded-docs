# BriaAddObject

تٌدرج هذه العقدة كائنًا موصوفًا بنص عادي في صورة باستخدام Bria. تعيد Bria عرض الإطار بالكامل بدقة تبلغ حوالي 1 ميجابكسل، لذا لا تكون النتيجة محاذية للإدخال على مستوى البكسل.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة التي يُضاف إليها الكائن الموصوف. يتم حذف قناة ألفا قبل رفع الصورة. | IMAGE | نعم | - |
| `instruction` | ما يجب إضافته وأين، مثل 'ضع مزهرية حمراء مع زهور على الطاولة'. يجب ألا يكون فارغًا. القيمة الافتراضية: "" (سلسلة فارغة). | STRING | نعم | - |
| `seed` | لا تستخدم Bria قيمة بذرة هنا، وتعيد تخيّل التعديل في كل استدعاء، لذا قد تختلف عمليات التشغيل المتكررة. لا يتم إرسال القيمة أبدًا: فهي تغيّر فقط مفتاح التخزين المؤقت لهذه العقدة، بحيث يعيد رسم بياني متطابق في ما عدا ذلك تشغيل التعديل بدلًا من إرجاع النتيجة المخزنة مؤقتًا. القيمة الافتراضية: 42. | INT | نعم | 0 إلى 2147483647 |
| `moderation` | إعدادات الإشراف. اختر "true" لإظهار خيارات الإشراف أدناه. | DYNAMIC_COMBO | نعم | "false"<br>"true" |

### المدخلات عند تفعيل الإشراف

متاحة عندما يتم ضبط `moderation` على "true".

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | يمكّن الإشراف على المحتوى في صورة الإدخال. القيمة الافتراضية: False. | BOOLEAN | لا | True / False |
| `visual_output_moderation` | يمكّن الإشراف على المحتوى في صورة المخرجات المُنشأة. القيمة الافتراضية: False. | BOOLEAN | لا | True / False |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة المعدّلة بعد إضافة الكائن الموصوف. | IMAGE |
| `structured_prompt` | وصف منظم للصورة المعدّلة، لاستخدامه في تعديل لاحق بواسطة Bria FIBO Image Edit. | STRING |
