# BriaAddObject

این گره با استفاده از Bria شیئی را که با متن ساده توصیف شده است در یک تصویر درج می‌کند. Bria کل قاب را در حدود ۱ مگاپیکسل دوباره رندر می‌کند، بنابراین نتیجه از نظر پیکسلی با ورودی هم‌تراز نیست.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویری که شیء توصیف‌شده به آن اضافه می‌شود. کانال آلفا پیش از بارگذاری تصویر حذف می‌شود. | IMAGE | بله | - |
| `دستور` | این‌که چه چیزی و کجا اضافه شود، مانند «یک گلدان قرمز با گل روی میز بگذارید». نباید خالی باشد. پیش‌فرض: "" (رشته خالی). | STRING | بله | - |
| `بذر` | Bria در اینجا هیچ seed نمی‌گیرد و در هر فراخوانی ویرایش را دوباره تصور می‌کند، بنابراین اجراهای تکراری می‌توانند متفاوت باشند. مقدار هرگز ارسال نمی‌شود: فقط کلید کش این گره را تغییر می‌دهد، تا گرافی که در غیر این صورت یکسان است، به‌جای بازگرداندن نتیجه کش‌شده، ویرایش را دوباره اجرا کند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |
| `تعدیل محتوا` | تنظیمات نظارت. برای نمایش پرچم‌های نظارت در زیر، "true" را انتخاب کنید. | DYNAMIC_COMBO | بله | "false"<br>"true" |

### ورودی‌های فعال در حالت نظارت

زمانی در دسترس هستند که `moderation` روی "true" تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | نظارت بر محتوا را روی تصویر ورودی فعال می‌کند. پیش‌فرض: False. | BOOLEAN | خیر | True / False |
| `visual_output_moderation` | نظارت بر محتوا را روی تصویر خروجی تولیدشده فعال می‌کند. پیش‌فرض: False. | BOOLEAN | خیر | True / False |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر ویرایش‌شده‌ای که شیء توصیف‌شده به آن اضافه شده است. | IMAGE |
| `structured_prompt` | توصیف ساختاریافته‌ی تصویر ویرایش‌شده، برای ویرایش بعدی با Bria FIBO Image Edit. | STRING |
