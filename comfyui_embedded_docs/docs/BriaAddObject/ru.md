# BriaAddObject

Этот узел вставляет объект, описанный обычным текстом, в изображение с помощью Bria. Bria полностью перерисовывает кадр с разрешением около 1 мегапикселя, поэтому результат не совпадает попиксельно с входным изображением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, в которое добавляется описанный объект. Альфа-канал отбрасывается перед загрузкой изображения. | IMAGE | Да | - |
| `instruction` | Что добавить и куда, например: «Поместите красную вазу с цветами на стол». Не должно быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | - |
| `seed` | Bria здесь не принимает seed и заново создаёт вариант правки при каждом вызове, поэтому повторные запуски могут отличаться. Значение никогда не отправляется: оно лишь меняет ключ кэша этого узла, чтобы в остальном идентичный граф снова выполнил правку вместо возврата кэшированного результата. По умолчанию: 42. | INT | Да | 0 до 2147483647 |
| `moderation` | Настройки модерации. Выберите "true", чтобы показать флаги модерации ниже. | DYNAMIC_COMBO | Да | "false"<br>"true" |

### Входы при включённой модерации

Доступны, когда для `moderation` установлено значение "true".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию контента для входного изображения. По умолчанию: False. | BOOLEAN | Нет | True / False |
| `visual_output_moderation` | Включает модерацию контента для сгенерированного выходного изображения. По умолчанию: False. | BOOLEAN | Нет | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение с добавленным описанным объектом. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
