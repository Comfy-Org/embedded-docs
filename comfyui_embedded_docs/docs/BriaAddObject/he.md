# BriaAddObject

צומת זה מכניס אובייקט המתואר בטקסט חופשי לתוך תמונה באמצעות Bria. Bria מרנדרת מחדש את כל הפריים ברזולוציה של כ-1 מגה-פיקסל, ולכן התוצאה אינה מיושרת ברמת הפיקסלים עם הקלט.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שאליה מתווסף האובייקט המתואר. ערוץ האלפא מוסר לפני העלאת התמונה. | IMAGE | כן | - |
| `instruction` | מה להוסיף והיכן, כגון 'הנח אגרטל אדום עם פרחים על השולחן'. אסור שיהיה ריק. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | - |
| `seed` | Bria אינה מקבלת seed כאן ומדמיינת מחדש את העריכה בכל קריאה, ולכן הרצות חוזרות עשויות להיות שונות. הערך לעולם אינו נשלח: הוא רק משנה את מפתח המטמון של הצומת, כך שגרף שאחרת היה זהה יריץ את העריכה שוב במקום להחזיר את התוצאה השמורה במטמון. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |
| `moderation` | הגדרות סינון תוכן. בחרו "true" כדי לחשוף את דגלי סינון התוכן שלמטה. | DYNAMIC_COMBO | כן | "false"<br>"true" |

### קלטים כאשר סינון תוכן מופעל

זמינים כאשר `moderation` מוגדר ל־"true".

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | מפעיל סינון תוכן על תמונת הקלט. ברירת מחדל: False. | BOOLEAN | לא | True / False |
| `visual_output_moderation` | מפעיל סינון תוכן על תמונת הפלט שנוצרה. ברירת מחדל: False. | BOOLEAN | לא | True / False |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `image` | התמונה הערוכה עם האובייקט המתואר שהוסף. | IMAGE |
| `structured_prompt` | תיאור מובנה של התמונה הערוכה, עבור עריכת המשך עם Bria FIBO Image Edit. | STRING |
