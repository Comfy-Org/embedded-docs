# Tripo: בדיקת rig

צומת זה שולח את המזהה של משימת מודל Tripo 3D שהושלמה אל Tripo API ובודק אם ניתן להרכיב שלד עבור אותו מודל. הוא ממתין לסיום הבדיקה ולאחר מכן מחזיר תוצאת כן/לא וכן את סוג השלד ש-Tripo ממליצה עליו עבור המודל.

<Note>
Tripo שומר רשומות משימה בשרתים שלו במשך 7 ימים (בתוקף מ-1 בדצמבר 2026). לא ניתן יותר לפענח מזהה משימה ישן מזה, ולכן הרצה חוזרת של תהליך עבודה שמור לאחר תקופה זו נכשלת בצומת הזה. כדי להמשיך, הריצו שוב את צומת Tripo הקודם כדי ליצור מזהה משימה חדש, או ייבאו מחדש את המודל שכבר הורדתם באמצעות **Tripo: ייבוא מודל**.
</Note>

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | מזהה משימת Tripo של המודל לניתוח. הוא מזהה מודל שנוצר קודם לכן, יובא, או נוצר בדרך אחרת באמצעות משימת Tripo. | MODEL_TASK_ID | כן | N/A |

## פלטים

| שם פלט | תיאור | סוג נתון |
|-------------|-------------|-----------|
| `riggable` | האם ניתן להרכיב שלד עבור המודל. | BOOLEAN |
| `rig_type` | שלד מומלץ: biped, quadruped, hexapod, octopod, avian, serpentine או aquatic; 'others' כאשר לא ניתן להרכיב שלד עבור המודל. | STRING |
