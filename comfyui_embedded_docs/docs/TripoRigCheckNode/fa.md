# Tripo: بررسی ریگ

این گره شناسهٔ یک وظیفهٔ تکمیل‌شدهٔ مدل سه‌بعدی Tripo را به API Tripo ارسال می‌کند و بررسی می‌کند که آیا آن مدل قابل ریگ‌بندی است یا نه. این گره تا پایان بررسی منتظر می‌ماند و سپس یک نتیجهٔ بله/خیر به‌همراه نوع اسکلتی که Tripo برای مدل پیشنهاد می‌کند بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسهٔ وظیفهٔ Tripo برای مدلی که باید تحلیل شود. این شناسه مدلی را مشخص می‌کند که قبلاً از طریق یک وظیفهٔ Tripo تولید، وارد یا به شکل دیگری ایجاد شده است. | MODEL_TASK_ID | بله | N/A |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `riggable` | این‌که مدل قابل ریگ‌بندی است یا نه. | BOOLEAN |
| `rig_type` | اسکلت پیشنهادی: biped، quadruped، hexapod، octopod، avian، serpentine یا aquatic؛ و 'others' زمانی که مدل قابل ریگ‌بندی نیست. | STRING |
