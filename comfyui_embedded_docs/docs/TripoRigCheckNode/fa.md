# TripoRigCheckNode

این گره شناسهٔ وظیفهٔ تکمیل‌شدهٔ مدل سه‌بعدی Tripo را به Tripo API ارسال می‌کند و بررسی می‌کند که آیا آن مدل قابل ریگ‌گذاری است. سپس منتظر می‌ماند تا بررسی به پایان برسد و نتیجهٔ بله/خیر را به همراه نوع اسکلتی که Tripo برای مدل پیشنهاد می‌کند برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسهٔ وظیفه (تسک) Tripo مدلی که باید تحلیل شود. این شناسه، مدلی را مشخص می‌کند که قبلاً از طریق یک وظیفهٔ Tripo تولید، وارد یا به شکل دیگری ایجاد شده است. | STRING | بله | N/A |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `riggable` | قابل ریگ‌گذاری بودن مدل. | BOOLEAN |
| `rig_type` | اسکلت پیشنهادی: biped، quadruped، hexapod، octopod، avian، serpentine یا aquatic؛ در صورت عدم قابلیت ریگ‌گذاری مدل، مقدار 'others'. | STRING |
