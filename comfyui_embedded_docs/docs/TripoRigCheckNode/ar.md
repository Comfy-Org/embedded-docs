# TripoRigCheckNode

ترسل هذه العقدة معرّف مهمة Tripo ثلاثية الأبعاد المكتملة إلى واجهة برمجة تطبيقات Tripo، وتتحقق مما إذا كان يمكن تجهيز هذا النموذج بالهيكل العظمي. تنتظر اكتمال الفحص ثم تُرجع نتيجة (نعم/لا) بالإضافة إلى نوع الهيكل العظمي الذي توصي به Tripo للنموذج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|---------|
| `model_task_id` | معرّف مهمة Tripo للنموذج المراد تحليله. وهو يحدد نموذجًا تم توليده سابقًا أو استيراده أو إنشاؤه عبر مهمة Tripo. | STRING | نعم | N/A |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-------------|
| `قابل للتجهيز بهيكل عظمي` | يشير إلى ما إذا كان يمكن تجهيز النموذج بالهيكل العظمي. | BOOLEAN |
| `rig_type` | الهيكل العظمي الموصى به: biped، quadruped، hexapod، octopod، avian، serpentine، aquatic؛ و'others' عندما لا يمكن تجهيز النموذج. | STRING |
