# TripoRigCheckNode

Данный узел отправляет идентификатор завершённой задачи Tripo 3D для модели в API Tripo и проверяет, можно ли выполнить для этой модели риггинг. Он ожидает завершения проверки и возвращает результат «да/нет», а также тип скелета, который Tripo рекомендует для данной модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Идентификатор задачи Tripo для анализируемой модели. Он определяет модель, которая была ранее сгенерирована, импортирована или иным образом создана с помощью задачи Tripo. | STRING | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `riggable` | Указывает, можно ли выполнить риггинг модели. | BOOLEAN |
| `rig_type` | Рекомендуемый тип скелета: biped, quadruped, hexapod, octopod, avian, serpentine или aquatic; 'others' — если модель не может быть риггирована. | STRING |
