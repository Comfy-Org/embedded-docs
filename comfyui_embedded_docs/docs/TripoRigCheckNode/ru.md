# Tripo: Проверка рига

Этот узел отправляет ID завершённой задачи Tripo 3D-модели в Tripo API и проверяет, можно ли для этой модели выполнить риггинг. Он ожидает завершения проверки, а затем возвращает результат «да/нет» и тип скелета, который Tripo рекомендует для модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи Tripo для модели, которую нужно проанализировать. Он идентифицирует модель, ранее сгенерированную, импортированную или иным способом созданную через задачу Tripo. | MODEL_TASK_ID | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `riggable` | Можно ли выполнить риггинг модели. | BOOLEAN |
| `rig_type` | Рекомендуемый скелет: biped, quadruped, hexapod, octopod, avian, serpentine или aquatic; 'others', если модель не поддаётся риггингу. | STRING |
