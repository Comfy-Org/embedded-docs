# Nano Banana 2

Этот узел генерирует или редактирует изображения синхронно с использованием модели Gemini от Google Vertex AI (Nano Banana 2 / Gemini 3.1 Flash Image). Он отправляет текстовый запрос, а также дополнительные справочные изображения или файлы в API и возвращает сгенерированное изображение, сопутствующий текст и, при необходимости, изображение из процесса размышлений модели.

## Входные параметры

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации или изменения, которые необходимо применить. Включите любые ограничения, стили или детали, которым должна следовать модель. Должен содержать по крайней мере один непробельный символ. | STRING | Да | N/A |
| `model` | Конкретная модель Gemini для генерации изображений. Единственный доступный вариант соответствует модели `gemini-3.1-flash-image-preview`. | COMBO | Да | `"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `seed` | Когда seed зафиксирован на определенном значении, модель прилагает все усилия, чтобы обеспечить одинаковый ответ для повторяющихся запросов. Детерминированный вывод не гарантируется. Кроме того, изменение модели или параметров настроек, таких как температура, может вызвать изменения в ответе, даже если используется то же значение seed. По умолчанию используется случайное значение seed. (по умолчанию: 42) | INT | Да | от 0 до 18446744073709551615 |
| `aspect_ratio` | Если установлено значение 'auto', соответствует соотношению сторон вашего входного изображения; если изображение не предоставлено, обычно генерируется изображение с соотношением сторон 16:9. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"` |
| `resolution` | Целевое разрешение выходного изображения. Для 2K/4K используется собственный апскейлер Gemini. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"` |
| `response_modalities` | Определяет тип контента, возвращаемого моделью: `IMAGE` возвращает только изображение, `IMAGE+TEXT` также возвращает текст рассуждений модели. (продвинутый) | COMBO | Да | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `thinking_level` | Управляет глубиной процесса рассуждений модели. | COMBO | Да | `"MINIMAL"`<br>`"HIGH"` |
| `images` | Необязательные справочные изображения. Чтобы включить несколько изображений, используйте узел Batch Images (до 14). | IMAGE | Нет | До 14 изображений |
| `files` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | Нет | N/A |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. (по умолчанию: встроенные инструкции, требующие от модели всегда создавать изображение) (продвинутый) | STRING | Нет | N/A |

**Примечание:** Вход `images` принимает максимум 14 изображений; передача большего количества вызывает ошибку. Если передано более 10 справочных изображений, первые 10 отправляются как URL-адреса файлов, а остальные изображения отправляются как встроенные данные. Параметр `prompt` не должен быть пустым после удаления пробелов. Этот узел помечен как устаревший.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Основное изображение, сгенерированное или отредактированное моделью. | IMAGE |
| `string` | Любой текстовый контент, возвращенный моделью. | STRING |
| `thought_image` | Первое изображение из процесса размышлений модели. Доступно только при уровне `thinking_level` HIGH и модальности IMAGE+TEXT. | IMAGE |
