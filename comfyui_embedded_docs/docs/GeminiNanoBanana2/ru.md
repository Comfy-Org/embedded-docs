# Nano Banana 2

Узел GeminiNanoBanana2 генерирует или редактирует изображения с помощью модели Gemini от Google Vertex AI. Он отправляет текстовый запрос вместе с дополнительными эталонными изображениями или файлами в API и возвращает сгенерированное изображение и сопутствующий текст. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос с описанием изображения, которое нужно сгенерировать, или изменений, которые нужно применить. Включите любые ограничения, стили или детали, которым должна следовать модель. Не может быть пустым. (по умолчанию: пусто) | STRING | Да | N/A |
| `model` | Конкретная модель Gemini для генерации изображений. | COMBO | Да | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | Когда seed фиксирован на определённом значении, модель прикладывает все усилия, чтобы при повторных запросах дать тот же ответ. Детерминированный вывод не гарантируется. Кроме того, изменение модели или параметров, таких как температура, может вызвать различия в ответе, даже если используется то же значение seed. По умолчанию используется случайное значение seed. (по умолчанию: 42) | INT | Да | 0 до 18446744073709551615 |
| `aspect_ratio` | Если задано значение 'auto', соотношение сторон соответствует вашему входному изображению; если изображение не предоставлено, обычно генерируется изображение с соотношением 16:9. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | Целевое разрешение выходного изображения. Для 2K/4K используется нативный апскейлер Gemini. | COMBO | Да | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | Определяет тип содержимого, возвращаемого моделью: "IMAGE" возвращает только изображение, "IMAGE+TEXT" также возвращает текст. (дополнительно) | COMBO | Да | "IMAGE"<br>"IMAGE+TEXT" |
| `thinking_level` | Управляет глубиной процесса рассуждения модели. | COMBO | Да | "MINIMAL"<br>"HIGH" |
| `images` | Необязательные эталонные изображения. Чтобы включить несколько изображений, используйте узел Batch Images (до 14). | IMAGE | Нет | от 1 до 14 изображений |
| `files` | Необязательные файлы для использования в качестве контекста для модели. Принимает входы от узла Gemini Generate Content Input Files. | CUSTOM | Нет | N/A |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. (по умолчанию: предустановленный промпт, который указывает модели всегда создавать изображение) (дополнительно) | STRING | Нет | N/A |

**Примечание:** Вход `images` поддерживает максимум 14 изображений. Если передано больше, узел выдаст ошибку. Вход `prompt` не должен быть пустым или содержать только пробелы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Основное изображение, сгенерированное или отредактированное моделью. | IMAGE |
| `string` | Текстовое содержимое, возвращаемое моделью. | STRING |
| `thought_image` | Первое изображение из процесса рассуждения модели. Доступно только при thinking_level HIGH и модальности IMAGE+TEXT. | IMAGE |
