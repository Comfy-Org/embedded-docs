# Nano Banana 2

Узел Nano Banana 2 синхронно генерирует или редактирует изображения через Google Vertex API с использованием модели Gemini 3.1 Flash Image. Он отправляет текстовую подсказку вместе с необязательными эталонными изображениями или файлами и возвращает сгенерированное изображение, сопроводительный текст и, при необходимости, изображение из процесса размышления модели. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовая подсказка, описывающая изображение для генерации или правки, которые нужно применить. Включите любые ограничения, стили или детали, которым должна следовать модель. Не может быть пустым или содержать только пробельные символы. (по умолчанию: пусто) | STRING | Да | N/A |
| `model` | Модель Gemini, используемая для генерации изображений. | COMBO | Да | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | Когда `seed` зафиксирован на определённом значении, модель по возможности старается выдавать одинаковый ответ на повторные запросы. Детерминированный вывод не гарантируется. Кроме того, изменение модели или настроек параметров, например `temperature`, может вызывать различия в ответе даже при использовании одного и того же значения `seed`. По умолчанию используется случайное значение seed. (по умолчанию: 42) | INT | Да | 0 до 18446744073709551615 |
| `aspect_ratio` | Если установлено значение 'auto', соответствует соотношению сторон входного изображения; если изображение не предоставлено, обычно генерируется квадрат 16:9. (по умолчанию: "auto") | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | Целевое разрешение выходного изображения. Для 2K/4K используется встроенный апскейлер Gemini. | COMBO | Да | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | Определяет тип содержимого, возвращаемого моделью: "IMAGE" возвращает только изображение, "IMAGE+TEXT" также возвращает текст. (расширенный) | COMBO | Да | "IMAGE"<br>"IMAGE+TEXT" |
| `thinking_level` | Управляет глубиной процесса рассуждения модели. | COMBO | Да | "MINIMAL"<br>"HIGH" |
| `images` | Необязательные эталонные изображения. Чтобы добавить несколько изображений, используйте узел Batch Images (до 14). | IMAGE | Нет | 1 до 14 images |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входные данные от узла Gemini Generate Content Input Files. | CUSTOM | Нет | N/A |
| `system_prompt` | Основополагающие инструкции, определяющие поведение ИИ. (по умолчанию: предустановленная подсказка, которая указывает модели всегда создавать изображение) (расширенный) | STRING | Нет | N/A |

**Примечание:** Вход `images` поддерживает максимум 14 изображений. Если передано больше, узел вызывает ошибку. Вход `prompt` не должен быть пустым или содержать только пробельные символы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Основное изображение, сгенерированное или отредактированное моделью. | IMAGE |
| `string` | Любой текстовый контент, возвращённый моделью. | STRING |
| `thought_image` | Первое изображение из процесса размышления модели. Доступно только при `thinking_level`, установленном в HIGH, и модальности IMAGE+TEXT. | IMAGE |
