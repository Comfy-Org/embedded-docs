# Nano Banana ۲

این گره به‌صورت همگام (synchronous) با استفاده از مدل Gemini گوگل در Vertex AI (Nano Banana 2 / Gemini 3.1 Flash Image) تصاویر را تولید یا ویرایش می‌کند. این گره یک متن prompt را به همراه تصاویر مرجع یا فایل‌های اختیاری به API می‌فرستد و تصویر تولیدشده، هر متن همراه، و در صورت درخواست، تصویری از فرایند تفکر مدل را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن prompt توصیف‌کننده تصویری که باید تولید شود یا ویرایش‌هایی که باید اعمال شوند. هرگونه محدودیت، سبک یا جزئیاتی که مدل باید دنبال کند را شامل شود. باید حداقل یک نویسه غیرفضایی (non-whitespace) داشته باشد. | STRING | بله | N/A |
| `model` | مدل Gemini خاص مورد استفاده برای تولید تصویر. تنها گزینه موجود به مدل `gemini-3.1-flash-image-preview` نگاشت می‌شود. | COMBO | بله | `"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `seed` | وقتی `seed` روی یک مقدار ثابت تنظیم شود، مدل برای ارائه پاسخ یکسان در درخواست‌های تکراری نهایت تلاش خود را می‌کند. با این حال، خروجی قطعی تضمین نمی‌شود. همچنین تغییر مدل یا تنظیمات پارامترهایی مانند دما می‌تواند حتی با استفاده از همان مقدار seed باعث تغییراتی در پاسخ شود. به‌طور پیش‌فرض، از یک مقدار seed تصادفی استفاده می‌شود. (پیش‌فرض: 42) | INT | بله | 0 to 18446744073709551615 |
| `aspect_ratio` | اگر روی `'auto'` تنظیم شود، با نسبت ابعاد تصویر ورودی شما مطابقت می‌کند؛ اگر تصویری ارائه نشود، معمولاً یک کادر 16:9 تولید می‌شود. (پیش‌فرض: "auto") | COMBO | بله | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"` |
| `resolution` | رزولوشن هدف خروجی. برای 2K/4K از ارتقاءدهنده وضوح (upscaler) بومی Gemini استفاده می‌شود. | COMBO | بله | `"1K"`<br>`"2K"`<br>`"4K"` |
| `response_modalities` | نوع محتوایی را که مدل برمی‌گرداند تعیین می‌کند: `IMAGE` فقط تصویر را برمی‌گرداند، `IMAGE+TEXT` متن استدلال مدل را نیز برمی‌گرداند. (پیشرفته) | COMBO | بله | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `thinking_level` | عمق فرایند استدلال مدل را کنترل می‌کند. | COMBO | بله | `"MINIMAL"`<br>`"HIGH"` |
| `images` | تصویر(های) مرجع اختیاری. برای گنجاندن چند تصویر، از گره «Batch Images» استفاده کنید (حداکثر 14 تصویر). | IMAGE | خیر | حداکثر 14 تصویر |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه (context) مدل. ورودی‌ها را از گره «Gemini Generate Content Input Files» می‌پذیرد. | GEMINI_INPUT_FILES | خیر | N/A |
| `system_prompt` | دستورالعمل‌های بنیادینی که رفتار هوش مصنوعی را تعیین می‌کنند. (پیش‌فرض: دستورالعمل‌های داخلی که مدل را ملزم می‌کنند همیشه تصویر تولید کند) (پیشرفته) | STRING | خیر | N/A |

**توجه:** ورودی `images` حداکثر 14 تصویر را می‌پذیرد؛ ارائه تعداد بیشتر باعث بروز خطا می‌شود. وقتی بیش از 10 تصویر مرجع ارائه شود، 10 تصویر اول به‌صورت URL فایل و مابقی به‌صورت داده‌های درون‌خطی (inline data) ارسال می‌شوند. `prompt` نباید پس از حذف کاراکترهای خالی، خالی باشد. این گره به‌عنوان منسوخ (deprecated) علامت‌گذاری شده است.
