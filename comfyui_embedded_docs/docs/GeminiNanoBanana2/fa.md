# Nano Banana ۲

گره GeminiNanoBanana2 با استفاده از مدل Gemini در سرویس Vertex AI گوگل، تصاویر را تولید یا ویرایش می‌کند. این گره یک پرامپت متنی را به همراه تصاویر یا فایل‌های مرجع اختیاری به API ارسال می‌کند و تصویر تولیدشده و هرگونه متن همراه را بازمی‌گرداند. این گره به‌عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | متن راهنمای (پرامپت) توصیف‌کننده تصویری که باید تولید یا ویرایش شود. هرگونه محدودیت، سبک یا جزئیاتی که مدل باید دنبال کند را شامل شود. نمی‌تواند خالی باشد. (پیش‌فرض: خالی) | STRING | بله | N/A |
| `مدل` | مدل خاص Gemini که برای تولید تصویر استفاده می‌شود. | COMBO | بله | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | هنگامی که seed روی مقدار خاصی ثابت شود، مدل بهترین تلاش خود را برای ارائه پاسخ یکسان به درخواست‌های تکراری به کار می‌گیرد. خروجی قطعی تضمین نمی‌شود. همچنین، تغییر مدل یا تنظیمات پارامترها، مانند دما (temperature)، می‌تواند حتی با استفاده از همان مقدار seed باعث تغییر در پاسخ شود. به‌طور پیش‌فرض، از یک مقدار seed تصادفی استفاده می‌شود. **توجه:** ورودی `images` حداکثر از ۱۴ تصویر پشتیبانی می‌کند. اگر تعداد بیشتری ارائه شود، گره خطا ایجاد می‌کند. ورودی `prompt` نباید خالی یا فقط شامل فاصله باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر اصلی که توسط مدل تولید یا ویرایش شده است. | IMAGE |
| `string` | هر محتوای متنی که توسط مدل بازگردانده شده است. | STRING |
| `thought_image` | اولین تصویر از فرآیند تفکر مدل. فقط با thinking_level برابر HIGH و حالت IMAGE+TEXT در دسترس است. | IMAGE |
