# Nano Banana ۲

گره Nano Banana 2 تصاویر را به‌صورت هم‌زمان از طریق Google Vertex API و با استفاده از مدل Gemini 3.1 Flash Image تولید یا ویرایش می‌کند. این گره یک پرامپت متنی، همراه با تصاویر یا فایل‌های مرجع اختیاری، ارسال می‌کند و تصویر تولیدشده، هر متن همراه، و به‌صورت اختیاری تصویری از فرایند تفکر مدل را بازمی‌گرداند. این گره به‌عنوان منسوخ علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی که تصویر مورد نظر برای تولید یا ویرایش‌هایی که باید اعمال شوند را توصیف می‌کند. هرگونه محدودیت، سبک یا جزئیاتی که مدل باید دنبال کند را شامل شود. نمی‌تواند خالی یا فقط شامل فاصله سفید باشد. (پیش‌فرض: خالی) | STRING | بله | ناموجود |
| `model` | مدل Gemini برای استفاده در تولید تصویر. | COMBO | بله | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | وقتی seed روی مقدار مشخصی ثابت شود، مدل نهایت تلاش خود را می‌کند تا برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. همچنین، تغییر مدل یا تنظیمات پارامترها، مانند temperature، می‌تواند حتی با استفاده از مقدار seed یکسان باعث تغییرات در پاسخ شود. به‌طور پیش‌فرض، یک مقدار seed تصادفی استفاده می‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 18446744073709551615 |
| `aspect_ratio` | اگر روی 'auto' تنظیم شود، با نسبت ابعاد تصویر ورودی شما مطابقت می‌کند؛ اگر تصویری ارائه نشود، معمولاً یک مربع 16:9 تولید می‌شود. (پیش‌فرض: "auto") | COMBO | بله | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | رزولوشن خروجی هدف. برای 2K/4K از مقیاس‌افزای بومی Gemini استفاده می‌شود. | COMBO | بله | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | نوع محتوایی را که مدل بازمی‌گرداند تعیین می‌کند: "IMAGE" فقط یک تصویر بازمی‌گرداند، "IMAGE+TEXT" متن را نیز بازمی‌گرداند. (پیشرفته) | COMBO | بله | "IMAGE"<br>"IMAGE+TEXT" |
| `thinking_level` | عمق فرایند استدلال مدل را کنترل می‌کند. | COMBO | بله | "MINIMAL"<br>"HIGH" |
| `images` | تصویر(های) مرجع اختیاری. برای گنجاندن چند تصویر، از گره Batch Images استفاده کنید (حداکثر 14). | IMAGE | خیر | 1 تا 14 تصویر |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌هایی را از گره Gemini Generate Content Input Files می‌پذیرد. | CUSTOM | خیر | ناموجود |
| `system_prompt` | دستورالعمل‌های بنیادین که رفتار هوش مصنوعی را تعیین می‌کنند. (پیش‌فرض: یک پرامپت از پیش تنظیم‌شده که به مدل دستور می‌دهد همیشه یک تصویر تولید کند) (پیشرفته) | STRING | خیر | ناموجود |

**توجه:** ورودی `images` حداکثر از 14 تصویر پشتیبانی می‌کند. اگر تعداد بیشتری ارائه شود، گره خطا می‌دهد. ورودی `prompt` نباید خالی یا فقط شامل فاصله سفید باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر اصلی تولیدشده یا ویرایش‌شده توسط مدل. | IMAGE |
| `string` | هر محتوای متنی که مدل بازمی‌گرداند. | STRING |
| `thought_image` | اولین تصویر از فرایند تفکر مدل. تنها زمانی در دسترس است که `thinking_level` روی HIGH تنظیم شده باشد و حالت IMAGE+TEXT فعال باشد. | IMAGE |
