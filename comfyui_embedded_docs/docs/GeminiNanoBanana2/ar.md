# Nano Banana 2

تُنشئ عقدة Nano Banana 2 الصور أو تعدّلها بشكل متزامن عبر Google Vertex API باستخدام نموذج Gemini 3.1 Flash Image. وهي ترسل مطالبة نصية، إلى جانب صور أو ملفات مرجعية اختيارية، وتُعيد الصورة المُنشأة، وأي نص مصاحب، واختياريًا صورة من عملية تفكير النموذج. هذه العقدة موسومة بأنها مهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | مطالبة نصية تصف الصورة المطلوب إنشاؤها أو التعديلات المطلوب تطبيقها. ضمّن أي قيود أو أنماط أو تفاصيل يجب أن يتبعها النموذج. لا يمكن أن تكون فارغة أو مكوّنة من مسافات بيضاء فقط. (الافتراضي: فارغ) | STRING | نعم | N/A |
| `model` | نموذج Gemini المستخدم لإنشاء الصور. | COMBO | نعم | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | عند تثبيت البذرة على قيمة محددة، يبذل النموذج قصارى جهده لتقديم الاستجابة نفسها للطلبات المتكررة. لا يكون الإخراج الحتمي مضمونًا. كذلك، قد يؤدي تغيير النموذج أو إعدادات المعاملات، مثل درجة الحرارة، إلى تباينات في الاستجابة حتى عند استخدام قيمة البذرة نفسها. افتراضيًا، تُستخدم قيمة بذرة عشوائية. (الافتراضي: 42) | INT | نعم | 0 إلى 18446744073709551615 |
| `aspect_ratio` | إذا تم ضبطه على 'auto'، فسيطابق نسبة أبعاد صورة الإدخال؛ وإذا لم يتم توفير صورة، فعادةً ما يتم إنشاء صورة بنسبة 16:9. (الافتراضي: "auto") | COMBO | نعم | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | دقة الإخراج المستهدفة. بالنسبة إلى 2K/4K، تُستخدم أداة التحجيم الأصلية من Gemini. | COMBO | نعم | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | يحدد نوع المحتوى الذي يعيده النموذج: "IMAGE" يعيد صورة فقط، و"IMAGE+TEXT" يعيد نصًا أيضًا. (متقدم) | COMBO | نعم | "IMAGE"<br>"IMAGE+TEXT" |
| `thinking_level` | يتحكم في عمق عملية استدلال النموذج. | COMBO | نعم | "MINIMAL"<br>"HIGH" |
| `images` | صورة/صور مرجعية اختيارية. لتضمين صور متعددة، استخدم عقدة Batch Images (بحد أقصى 14). | IMAGE | لا | 1 إلى 14 images |
| `files` | ملف/ملفات اختيارية لاستخدامها كسياق للنموذج. يقبل مدخلات من عقدة Gemini Generate Content Input Files. | CUSTOM | لا | N/A |
| `system_prompt` | تعليمات أساسية تحدّد سلوك الذكاء الاصطناعي. (الافتراضي: مطالبة معدّة مسبقًا توجّه النموذج لإنتاج صورة دائمًا) (متقدم) | STRING | لا | N/A |

**ملاحظة:** يدعم مدخل `images` حدًا أقصى قدره 14 صورة. إذا تم توفير أكثر من ذلك، تُطلق العقدة خطأً. يجب ألا يكون مدخل `prompt` فارغًا أو مكوّنًا من مسافات بيضاء فقط.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة الأساسية التي أنشأها النموذج أو عدّلها. | IMAGE |
| `string` | أي محتوى نصي يعيده النموذج. | STRING |
| `thought_image` | أول صورة من عملية تفكير النموذج. تتوفر فقط عندما تكون قيمة `thinking_level` مضبوطة على HIGH ووضعية IMAGE+TEXT. | IMAGE |
