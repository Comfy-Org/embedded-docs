# Nano Banana 2

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する画像や適用する編集内容を説明するテキストプロンプトです。モデルが従うべき制約、スタイル、詳細を含めてください。空白以外の文字を少なくとも1文字含む必要があります。 | STRING | はい | N/A |
| `model` | 画像生成に使用する Gemini モデルを指定します。利用可能な唯一のオプションは、`gemini-3.1-flash-image-preview` モデルに対応します。 | COMBO | はい | `"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `seed` | シードを特定の値に固定すると、モデルは繰り返しのリクエストに対して同じ応答を返すよう最善を尽くします。ただし、決定論的な出力は保証されません。また、モデルや温度などのパラメータ設定を変更すると、同じシード値を使用しても応答が変わることがあります。デフォルトでは、ランダムなシード値が使用されます。（デフォルト: 42） | INT | はい | 0 ～ 18446744073709551615 |
| `aspect_ratio` | 「auto」に設定すると、入力画像のアスペクト比に一致します。画像が提供されない場合は、通常 16:9 の画像が生成されます。（デフォルト: "auto"） | COMBO | はい | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"` |
| `resolution` | 目標の出力解像度です。2K/4K では、Gemini のネイティブアップスケーラーが使用されます。 | COMBO | はい | `"1K"`<br>`"2K"`<br>`"4K"` |
| `response_modalities` | モデルが返すコンテンツの種類を決定します。`IMAGE` は画像のみを返し、`IMAGE+TEXT` はモデルの推論テキストも返します。（上級者向け） | COMBO | はい | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `thinking_level` | モデルの推論プロセスの深さを制御します。 | COMBO | はい | `"MINIMAL"`<br>`"HIGH"` |
| `images` | オプションの参照画像です。複数の画像を含めるには、Batch Images ノードを使用してください（最大14枚）。 | IMAGE | いいえ | 最大14枚 |
| `files` | モデルのコンテキストとして使用するオプションのファイルです。Gemini Generate Content Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ | N/A |
| `system_prompt` | AI の動作を決定づける基盤となる指示です。（デフォルト: モデルに常に画像を生成させる組み込みの指示）（上級者向け） | STRING | いいえ | N/A |

**注：** `images` 入力は最大14枚の画像を受け付けます。それ以上指定するとエラーが発生します。参照画像が10枚を超える場合は、最初の10枚がファイル URL として送信され、残りの画像はインラインデータとして送信されます。`prompt` は、空白を除去した後も空であってはなりません。このノードは非推奨としてマークされています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | モデルによって生成または編集された主要な画像です。 | IMAGE |
| `string` | モデルが返したテキストコンテンツです。 | STRING |
| `thought_image` | モデルの思考プロセスから得られた最初の画像です。`thinking_level` が HIGH で、かつ `IMAGE+TEXT` モダリティの場合にのみ利用できます。 | IMAGE |
