# وان 2.7 تحويل النص إلى فيديو

هذه العقدة تولّد فيديو من وصف نصي باستخدام نموذج Wan 2.7. وهي ترسل طلبك إلى واجهة برمجة تطبيقات خارجية، تعالج الموجه ثم تعيد ملف فيديو. يمكنك اختياريًا توفير مقطع صوتي للتأثير على حركة الفيديو وتوقيته.

## المدخلات

تشمل المدخلات الإعدادات العامة وإعدادات خاصة بالنموذج تظهر عند تحديد نموذج `wan2.7-t2v`.

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المحدد لاستخدامه في توليد الفيديو. | COMBO | نعم | `"wan2.7-t2v"` |
| `audio` | صوت لقيادة توليد الفيديو (مثل مزامنة الشفاه، حركة متوافقة مع الإيقاع). المدة: 3 ثوانٍ إلى 30 ثانية. إذا لم يتم توفيره، يولد النموذج تلقائيًا موسيقى خلفية أو مؤثرات صوتية مطابقة. | AUDIO | لا | - |
| `seed` | البذرة (Seed) المستخدمة للتوليد (الافتراضي: 0). | INT | لا | 0 إلى 2147483647 |
| `prompt_extend` | ما إذا كان سيتم تحسين الموجه بمساعدة الذكاء الاصطناعي (الافتراضي: True). | BOOLEAN | لا | - |
| `watermark` | ما إذا كان سيتم إضافة علامة مائية مولّدة بالذكاء الاصطناعي إلى النتيجة (الافتراضي: False). | BOOLEAN | لا | - |

### مدخلات wan2.7-t2v

تظهر هذه الإعدادات عند تحديد نموذج `wan2.7-t2v`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجه يصف العناصر والخصائص البصرية. يدعم اللغتين الإنجليزية والصينية. | STRING | نعم | - |
| `negative_prompt` | موجه سلبي يصف ما يجب تجنبه. | STRING | لا | - |
| `resolution` | دقة الفيديو الناتج. | COMBO | نعم | `"720P"`<br>`"1080P"` |
| `ratio` | نسبة الأبعاد للفيديو الناتج. | COMBO | نعم | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | طول الفيديو بالثواني (الافتراضي: 5). | INT | نعم | 2 إلى 15 |

**ملاحظة:** يجب ألا يكون إدخال `prompt` فارغًا. إدخال `audio` اختياري؛ إذا تم توفيره، يجب أن تكون مدته بين 1.5 و60 ثانية. إذا تم حذفه، يولد النموذج تلقائيًا صوتًا مطابقًا. عند ترك `negative_prompt` فارغًا، لا يتم إرساله إلى واجهة API. يعد `prompt_extend` و`watermark` خيارين متقدمين.
