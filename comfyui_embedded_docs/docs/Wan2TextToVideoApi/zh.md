# Wan 2.7 文本转视频

此节点使用 Wan 2.7 模型根据文本描述生成视频。它将您的请求发送到外部 API，该 API 会处理提示词并返回视频文件。您可以选择提供音频片段来影响视频的运动和时序。

## 输入

输入包括通用设置和选择 `wan2.7-t2v` 模型时出现的模型特定设置。

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的特定模型。 | COMBO | 是 | `"wan2.7-t2v"` |
| `audio` | 用于驱动视频生成的音频（例如，唇形同步、节拍匹配动作）。时长：1.5秒-60秒。如果未提供，模型会自动生成匹配的背景音乐或音效。 | AUDIO | 否 | - |
| `seed` | 用于生成的种子（默认值：0）。 | INT | 否 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词（默认值：True）。 | BOOLEAN | 否 True / False |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：False）。 | BOOLEAN | 否 True / False |

### wan2.7-t2v 输入

选择 `wan2.7-t2v` 模型时，将显示以下设置。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英文和中文。 | STRING | 是 | - |
| `negative_prompt` | 描述需要避免的内容的负面提示词。 | STRING | 否 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br>`"1080P"` |
| `ratio` | 输出视频的宽高比。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 视频长度（以秒为单位，默认值：5）。 | INT | 是 | 2 到 15 |

**注意：** `prompt` 输入不能为空。`audio` 输入为可选；如果提供，其时长必须在 1.5 到 60 秒之间。如果省略，模型会自动生成匹配的音频。当 `negative_prompt` 留空时，它不会被发送到 API。`prompt_extend` 和 `watermark` 为高级选项。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件。 | VIDEO |
