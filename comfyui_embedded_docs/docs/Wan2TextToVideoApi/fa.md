# وان ۲.۷ تبدیل متن به ویدیو

این گره با استفاده از مدل Wan 2.7 ویدیویی از توضیحات متنی تولید می‌کند. پرامپت شما را به API تولید ویدیوی Wan ارسال می‌کند، منتظر اتمام وظیفه می‌ماند و ویدیوی حاصل را بازمی‌گرداند. می‌توانید به‌صورت اختیاری یک کلیپ صوتی متصل کنید تا بر حرکت و زمان‌بندی ویدیو تأثیر بگذارد؛ اگر صوتی ارائه نشود، مدل به‌طور خودکار صدای منطبق تولید می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

این ورودی‌ها همیشه در سطح بالای گره در دسترس هستند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل خاص مورد استفاده برای تولید ویدیو. | DYNAMIC_COMBO | بله | `"wan2.7-t2v"` |
| `صدا` | صدا برای هدایت تولید ویدیو (مثلاً همگام‌سازی لب، حرکت هماهنگ با ضرب). مدت‌زمان: ۳ تا ۳۰ ثانیه. اگر ارائه نشود، مدل به‌طور خودکار موسیقی پس‌زمینه یا جلوه‌های صوتی منطبق تولید می‌کند. | AUDIO | خیر | - |
| `بذر` | دانه (Seed) مورد استفاده برای تولید (پیش‌فرض: ۰). | INT | بله | 0 تا 2147483647 |
| `گسترش پرامپت` | تعیین می‌کند که آیا پرامپت با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: True). | BOOLEAN | بله | True<br>False |
| `واترمارک` | تعیین می‌کند که آیا واترمارک تولیدشده با هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: False). | BOOLEAN | بله | True<br>False |

### ورودی‌های wan2.7-t2v

این تنظیمات زمانی ظاهر می‌شوند که مدل `wan2.7-t2v` انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. | STRING | بله | - |
| `negative_prompt` | پرامپت منفی که مواردی را که باید اجتناب شود توصیف می‌کند. پیش‌فرض یک رشته خالی است. | STRING | خیر | - |
| `resolution` | وضوح ویدیوی خروجی. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `ratio` | نسبت ابعاد ویدیوی خروجی. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | طول ویدیو بر حسب ثانیه (پیش‌فرض: ۵). | INT | بله | 2 تا 15 |

**نکته:** ورودی `prompt` نباید خالی باشد. ورودی `audio` اختیاری است؛ در صورت ارائه، گره صدایی بین ۱.۵ تا ۶۰ ثانیه را می‌پذیرد، اگرچه راهنمای ابزار ۳ تا ۳۰ ثانیه را توصیه می‌کند. اگر صوتی ارائه نشود، مدل به‌طور خودکار صدای منطبق تولید می‌کند. وقتی `negative_prompt` خالی رها شود، به API ارسال نمی‌شود. `prompt_extend` و `watermark` گزینه‌های پیشرفته هستند.
