# وان ۲.۷ تبدیل متن به ویدیو

این گره با استفاده از مدل Wan 2.7، ویدیویی از توضیحات متنی تولید می‌کند. درخواست شما را به یک API خارجی ارسال می‌کند که پرامپت را پردازش کرده و یک فایل ویدیویی برمی‌گرداند. می‌توانید به‌صورت اختیاری یک کلیپ صوتی ارائه دهید تا بر حرکت و زمان‌بندی ویدیو تأثیر بگذارد.

## ورودی‌ها

ورودی‌ها شامل تنظیمات مشترک و تنظیمات مخصوص مدل هستند که هنگام انتخاب مدل `wan2.7-t2v` ظاهر می‌شوند.

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید ویدیو. | COMBO | بله | `"wan2.7-t2v"` |
| `audio` | صوت برای هدایت تولید ویدیو (مثلاً هم‌زمانی لب، حرکت هماهنگ با ضرب). مدت‌زمان: ۱.۵ تا ۶۰ ثانیه. اگر ارائه نشود، مدل به‌طور خودکار موسیقی پس‌زمینه یا افکت‌های صوتی متناسب تولید می‌کند. | AUDIO | خیر | - |
| `seed` | مقدار seed برای تولید (پیش‌فرض: ۰). | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | آیا پرامپت با کمک هوش مصنوعی بهبود یابد یا خیر (پیش‌فرض: True). | BOOLEAN | خیر True / False |
| `watermark` | آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: False). | BOOLEAN | خیر True / False |

### ورودی‌های wan2.7-t2v

این تنظیمات هنگام انتخاب مدل `wan2.7-t2v` ظاهر می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. | STRING | بله | - |
| `negative_prompt` | پرامپت منفی که مواردی که باید از آنها اجتناب شود را توصیف می‌کند. | STRING | خیر | - |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `ratio` | نسبت ابعاد ویدیوی خروجی. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | طول ویدیو بر حسب ثانیه (پیش‌فرض: ۵). | INT | بله | 2 تا 15 |

**توجه:** ورودی `prompt` نباید خالی باشد. ورودی `audio` اختیاری است؛ اگر ارائه شود، مدت‌زمان آن باید بین ۱٫۵ تا ۶۰ ثانیه باشد. اگر حذف شود، مدل به‌طور خودکار صوت متناسب تولید می‌کند. وقتی `negative_prompt` خالی گذاشته شود، به API ارسال نمی‌شود. `prompt_extend` و `watermark` گزینه‌های پیشرفته هستند.
