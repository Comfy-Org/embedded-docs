# Wan 2.7 Текст в видео

Этот узел генерирует видео по текстовому описанию с использованием модели Wan 2.7. Он отправляет ваш промпт в API генерации видео Wan, ожидает завершения задачи и возвращает итоговое видео. Вы можете дополнительно подключить аудиоклип, чтобы влиять на движение и тайминг видео; если аудио не предоставлено, модель автоматически генерирует соответствующее аудио.

## Входы

### Общие входы

Эти входы всегда доступны на верхнем уровне узла.

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель для генерации видео. | DYNAMIC_COMBO | Да | `"wan2.7-t2v"` |
| `audio` | Аудио для управления генерацией видео (например, синхронизация губ, движение в такт музыке). Длительность: 3–30 секунд. Если не указано, модель автоматически генерирует подходящую фоновую музыку или звуковые эффекты. | AUDIO | Нет | - |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | 0 до 2147483647 |
| `prompt_extend` | Следует ли улучшать промпт с помощью ИИ (по умолчанию: True). | BOOLEAN | Да | True<br>False |
| `watermark` | Добавлять ли к результату водяной знак, сгенерированный ИИ (по умолчанию: False). | BOOLEAN | Да | True<br>False |

### Входы wan2.7-t2v

Эти настройки появляются при выборе модели `wan2.7-t2v`.

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. | STRING | Да | - |
| `negative_prompt` | Негативный промпт, описывающий, чего следует избегать. По умолчанию — пустая строка. | STRING | Нет | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Длительность видео в секундах (по умолчанию: 5). | INT | Да | 2 до 15 |

**Примечание:** Вход `prompt` не может быть пустым. Вход `audio` является необязательным; при его наличии узел принимает аудио длительностью от 1,5 до 60 секунд, хотя во всплывающей подсказке рекомендуется 3–30 секунд. Если аудио не указано, модель автоматически генерирует соответствующее аудио. Если `negative_prompt` оставить пустым, он не отправляется в API. `prompt_extend` и `watermark` являются расширенными параметрами.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
