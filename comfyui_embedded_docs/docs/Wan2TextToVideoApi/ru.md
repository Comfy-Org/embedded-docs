# Wan 2.7 Текст в видео

Этот узел генерирует видео по текстовому описанию с помощью модели Wan 2.7. Он отправляет ваш запрос на внешний API, который обрабатывает промпт и возвращает видеофайл. Вы также можете указать аудиофрагмент, чтобы повлиять на движение и тайминг видео.

## Входы

Входные параметры включают общие настройки и параметры, специфичные для модели, которые появляются при выборе модели `wan2.7-t2v`.

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель для генерации видео. | DYNAMIC_COMBO | Да | `"wan2.7-t2v"` |
| `audio` | Аудио для управления генерацией видео (например, синхронизация губ, движение в такт музыке). Длительность: 1.5–60 секунд. Если не указано, модель автоматически генерирует подходящую фоновую музыку или звуковые эффекты. | AUDIO | Нет | - |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `prompt_extend` | Нужно ли улучшать промпт с помощью ИИ (по умолчанию: True). | BOOLEAN | Да | True / False |
| `watermark` | Нужно ли добавлять водяной знак, созданный ИИ, в результат (по умолчанию: False). | BOOLEAN | Да | True / False |

### Входы wan2.7-t2v

Эти параметры появляются, когда выбрана модель `wan2.7-t2v`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. | STRING | Да | - |
| `negative_prompt` | Негативный промпт, описывающий, чего следует избегать. | STRING | Нет | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Длительность видео в секундах (по умолчанию: 5). | INT | Да | от 2 до 15 |

**Примечание:** Параметр `prompt` не должен быть пустым. Параметр `audio` необязателен; если он задан, его длительность должна составлять от 1,5 до 60 секунд. Если параметр опущен, модель автоматически генерирует подходящее аудио. Если `negative_prompt` оставить пустым, он не будет отправлен в API. `prompt_extend` и `watermark` — расширенные параметры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
