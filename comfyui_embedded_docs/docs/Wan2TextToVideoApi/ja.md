# Wan 2.7 テキストからビデオへ

このノードは、Wan 2.7モデルを使用してテキスト記述から動画を生成します。リクエストを外部APIに送信し、そのAPIがプロンプトを処理して動画ファイルを返します。オプションでオーディオクリップを指定すると、動画の動きとタイミングに影響を与えることができます。

## 入力

入力には、`wan2.7-t2v` モデルが選択されたときに表示される共通設定とモデル固有の設定が含まれます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画生成に使用する特定のモデルです。 | COMBO | はい | `"wan2.7-t2v"` |
| `audio` | 動画生成を駆動するためのオーディオです（例：リップシンク、ビートに合わせた動き）。長さ：1.5秒〜60秒。指定しない場合、モデルは自動的に対応するBGMや効果音を生成します。 | AUDIO | いいえ | - |
| `seed` | 生成に使用するシードです（デフォルト: 0）。 | INT | いいえ | 0〜2147483647 |
| `prompt_extend` | AI支援によってプロンプトを拡張するかどうかです（デフォルト: True）。 | BOOLEAN | いいえ True / False |
| `watermark` | AI生成された透かしを結果に追加するかどうかです（デフォルト: False）。 | BOOLEAN | いいえ True / False |

### wan2.7-t2v 入力

これらの設定は、`wan2.7-t2v` モデルが選択されたときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を記述するプロンプトです。英語と中国語に対応しています。 | STRING | はい | - |
| `negative_prompt` | 回避すべき内容を記述するネガティブプロンプトです。 | STRING | いいえ | - |
| `resolution` | 出力動画の解像度です。 | COMBO | はい | `"720P"`<br>`"1080P"` |
| `ratio` | 出力動画のアスペクト比です。 | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 動画の長さ（秒）です（デフォルト: 5）。 | INT | はい | 2〜15 |

**注:** `prompt` 入力は空にすることはできません。`audio` 入力はオプションであり、指定する場合、その長さは1.5秒から60秒の間である必要があります。省略した場合、モデルは自動的に対応するオーディオを生成します。`negative_prompt` が空のままの場合、APIには送信されません。`prompt_extend` と `watermark` は高度なオプションです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイルです。 | VIDEO |
