# Wan 2.7 テキストからビデオへ

このノードは、Wan 2.7 モデルを使用して、テキスト記述から動画を生成します。リクエストを外部APIに送信し、プロンプトを処理して動画ファイルを返します。必要に応じて、動画の動きやタイミングに影響を与えるオーディオクリップを提供できます。

## 入力

入力には、共通設定と、`wan2.7-t2v` モデルが選択されたときに表示されるモデル固有の設定が含まれます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画生成に使用する特定のモデル。 | DYNAMIC_COMBO | 必須 | `"wan2.7-t2v"` |
| `オーディオ` | 動画生成を駆動するためのオーディオ（例：リップシンク、ビートに合わせた動き）。長さ：1.5秒〜60秒。指定しない場合、モデルは自動的に対応する背景音楽や効果音を生成します。 | AUDIO | 任意 | - |
| `シード値` | 生成に使用するシード（デフォルト：0）。 | INT | 必須 | 0 〜 2147483647 |
| `プロンプト拡張` | AI支援でプロンプトを拡張するかどうか（デフォルト：True）。 | BOOLEAN | 必須 | True<br>False |
| `ウォーターマーク` | 結果にAI生成の透かしを追加するかどうか（デフォルト：False）。 | BOOLEAN | 必須 | True<br>False |

### wan2.7-t2v 入力

これらの設定は、`wan2.7-t2v` モデルが選択されたときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。 | STRING | 必須 | - |
| `negative_prompt` | 避けるべき内容を説明するネガティブプロンプト。 | STRING | 任意 | - |
| `resolution` | 出力動画の解像度。 | COMBO | 必須 | `"720P"`<br>`"1080P"` |
| `ratio` | 出力動画のアスペクト比。 | COMBO | 必須 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 動画の長さ（秒単位）（デフォルト：5）。 | INT | 必須 | 2 〜 15 |

**注記：** `prompt` 入力は空にしないでください。`audio` 入力はオプションです。指定する場合、その長さは1.5秒から60秒の間である必要があります。省略した場合、モデルは自動的に対応するオーディオを生成します。`negative_prompt` を空にすると、APIに送信されません。`prompt_extend` と `watermark` は高度なオプションです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイル。 | VIDEO |
