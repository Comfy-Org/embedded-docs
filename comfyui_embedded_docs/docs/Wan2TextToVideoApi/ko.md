# Wan 2.7 텍스트 투 비디오

이 노드는 Wan 2.7 모델을 사용하여 텍스트 설명에서 비디오를 생성합니다. 요청을 외부 API로 전송하며, API가 프롬프트를 처리한 후 비디오 파일을 반환합니다. 선택적으로 오디오 클립을 제공하여 비디오의 움직임과 타이밍에 영향을 줄 수 있습니다.

## 입력

입력에는 공통 설정과 `wan2.7-t2v` 모델을 선택했을 때 나타나는 모델별 설정이 포함됩니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 특정 모델입니다. | COMBO | 예 | `"wan2.7-t2v"` |
| `audio` | 비디오 생성을 유도하는 오디오입니다(예: 립싱크, 비트 맞춤 동작). 지속 시간: 1.5초~60초. 제공하지 않으면 모델이 자동으로 어울리는 배경 음악이나 효과음을 생성합니다. | AUDIO | 아니요 | - |
| `seed` | 생성에 사용할 시드입니다(기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 강화할지 여부입니다(기본값: True). | BOOLEAN | 아니요 True / False |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다(기본값: False). | BOOLEAN | 아니요 True / False |

### wan2.7-t2v 입력

이 설정은 `wan2.7-t2v` 모델을 선택했을 때 나타납니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. | STRING | 예 | - |
| `negative_prompt` | 피해야 할 사항을 설명하는 네거티브 프롬프트입니다. | STRING | 아니요 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br>`"1080P"` |
| `ratio` | 출력 비디오의 화면 비율입니다. | COMBO | 예 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 2 ~ 15 |

**참고:** `prompt` 입력은 비어 있으면 안 됩니다. `audio` 입력은 선택 사항이며, 제공할 경우 지속 시간이 1.5초에서 60초 사이여야 합니다. 생략하면 모델이 자동으로 어울리는 오디오를 생성합니다. `negative_prompt`를 비워 두면 API로 전송되지 않습니다. `prompt_extend`와 `watermark`는 고급 옵션입니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일입니다. | VIDEO |
