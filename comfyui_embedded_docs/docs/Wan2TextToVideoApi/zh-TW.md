# Wan 2.7 文字轉影片

此節點使用 Wan 2.7 模型從文字描述生成影片。它會將您的請求傳送至外部 API，該 API 會處理提示詞並回傳影片檔案。您可以選擇提供音訊片段來影響影片的動作與節奏。

## 輸入

輸入包含通用設定，以及當選取 `wan2.7-t2v` 模型時顯示的模型特定設定。

### 通用輸入

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片生成的特定模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-t2v"` |
| `audio` | 用於驅動影片生成的音訊（例如：唇形同步、節拍匹配動作）。長度：1.5 秒至 60 秒。若未提供，模型會自動生成相符的背景音樂或音效。 | AUDIO | 否 | - |
| `seed` | 用於生成的種子（預設：0）。 | INT | 否 | 0 至 2147483647 |
| `prompt_extend` | 是否使用 AI 輔助來增強提示詞（預設：True）。 | BOOLEAN | 否 | True<br>False |
| `watermark` | 是否在結果中加入 AI 生成的浮水印（預設：False）。 | BOOLEAN | 否 | True<br>False |

### wan2.7-t2v 輸入

這些設定會在選取 `wan2.7-t2v` 模型時顯示。

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素與視覺特徵的提示詞。支援英文與中文。 | STRING | 是 | - |
| `negative_prompt` | 描述應避免內容的負面提示詞。 | STRING | 否 | - |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720P"`<br>`"1080P"` |
| `ratio` | 輸出影片的長寬比。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 影片長度（秒）（預設：5）。 | INT | 是 | 2 至 15 |

**注意：** `prompt` 輸入不可為空。`audio` 輸入為選用；若提供，其長度必須介於 1.5 至 60 秒之間。若省略，模型會自動生成相符的音訊。當 `negative_prompt` 留空時，不會傳送至 API。`prompt_extend` 與 `watermark` 為進階選項。
