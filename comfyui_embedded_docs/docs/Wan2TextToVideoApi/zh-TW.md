# Wan 2.7 文字轉影片

此節點使用 Wan 2.7 模型根據文字描述生成影片。它會將您的提示詞傳送至 Wan 影片生成 API，等待任務完成，然後返回生成的影片。您可以選擇連接音訊片段來影響影片的動作與節奏；如果未提供音訊，模型會自動生成匹配的音訊。

## 輸入

### 通用輸入

這些輸入始終可在節點的頂層使用。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要用於影片生成的特定模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-t2v"` |
| `audio` | 用於驅動影片生成的音訊（例如：唇形同步、節拍匹配動作）。時長：3秒-30秒。如果未提供，模型會自動生成匹配的背景音樂或音效。 | AUDIO | 否 | - |
| `seed` | 用於生成的種子（預設：0）。 | INT | 是 | 0 至 2147483647 |
| `prompt_extend` | 是否使用 AI 輔助增強提示詞（預設：True）。 | BOOLEAN | 是 | True<br>False |
| `watermark` | 是否在結果中添加 AI 生成的水印（預設：False）。 | BOOLEAN | 是 | True<br>False |

### wan2.7-t2v 輸入

當選取 `wan2.7-t2v` 模型時，會顯示這些設定。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和視覺特徵的提示詞。支援英文和中文。 | STRING | 是 | - |
| `negative_prompt` | 描述應避免內容的負面提示詞。預設為空字串。 | STRING | 否 | - |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | `"720P"`<br>`"1080P"` |
| `ratio` | 輸出影片的寬高比。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 影片的長度（秒）（預設：5）。 | INT | 是 | 2 至 15 |

**注意：** `prompt` 輸入不可為空。`audio` 輸入為選用；如果提供，節點接受介於 1.5 到 60 秒之間的音訊，即使工具提示建議 3 秒至 30 秒。若未提供音訊，模型會自動生成匹配的音訊。當 `negative_prompt` 留空時，不會發送至 API。`prompt_extend` 和 `watermark` 為進階選項。
