# Model Merge MiniMax H3

دو مدل سازگار MiniMax H3 را به‌صورت مؤلفه‌ای ادغام می‌کند، با نسبت جداگانه برای هر بخش از معماری. افزایش نسبت باعث می‌شود سهم بیشتری از آن مؤلفه از `model2` گرفته شود؛ بنابراین می‌توانید پروجکشن‌های patch و بلوک‌های پالایش یک مدل را نگه دارید و در همان حال بلوک‌های transformer را با مدل دیگری جایگزین کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model1` | نخستین مدل MiniMax H3؛ پایه‌ای که هر مؤلفه از آن گرفته می‌شود (وزن پیش‌فرض در جاهایی که از `model2` استفاده نمی‌شود اعمال می‌شود). | MODEL | بله | - |
| `model2` | دومین مدل MiniMax H3 که مؤلفه‌هایی را که در ترکیب وارد می‌کنید فراهم می‌کند. | MODEL | بله | - |
| `video_patch_proj.` | سهم `model2` برای پروجکشن patch ویدیو (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `audio_patch_proj.` | سهم `model2` برای پروجکشن patch صدا (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `condition_proj.` | سهم `model2` برای پروجکشن شرطی‌سازی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `time_embedder.` | سهم `model2` برای جاسازی‌گر زمان (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.blocks.0.` | سهم `model2` برای نخستین بلوک پالایش توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.blocks.1.` | سهم `model2` برای دومین بلوک پالایش توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.final_norm.` | سهم `model2` برای نرمال‌سازی نهایی پالایش توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `blocks.0.` تا `blocks.49.` | سهم `model2` برای هر یک از ۵۰ بلوک transformer، یک ویجت برای هر بلوک (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.norm.` | سهم `model2` برای نرمال‌سازی لایه نهایی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.adaln_proj.` | سهم `model2` برای پروجکشن نرمال‌سازی تطبیقی نهایی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.video_out.` | سهم `model2` برای لایه خروجی ویدیو (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.audio_out.` | سهم `model2` برای لایه خروجی صدا (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |

نسبت 0.0 آن مؤلفه را کاملاً از `model1` نگه می‌دارد و 1.0 آن را کاملاً از `model2` می‌گیرد؛ مقادیر میان این دو، آن دو را با هم ترکیب می‌کنند. تنسورهایی که نسبت ندارند، مانند آماره‌های نرمال‌سازی، همیشه از `model1` می‌آیند. هر دو ورودی باید مدل‌های MiniMax H3 با معماری یکسان باشند؛ در غیر این صورت، ادغام مدلی تولید می‌کند که اجرا نمی‌شود.
