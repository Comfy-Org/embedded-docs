# Model Merge MiniMax H3

دو مدل سازگار MiniMax H3 را برحسب مؤلفه ادغام کنید، با نسبتی جداگانه برای هر بخش از معماری. هر نسبت، سهم `model1` است؛ بنابراین می‌توانید پروجکشن‌های وصله و بلوک‌های پالایش یک مدل را نگه دارید و در همان حال بلوک‌های ترنسفورمر را با مدل دیگری جایگزین کنید.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model1` | نخستین مدل MiniMax H3. هر مؤلفه از آن آغاز می‌شود و هر نسبت تعیین می‌کند چه مقدار از آن مؤلفه به‌جای آن از `model2` گرفته شود. | MODEL | بله | - |
| `model2` | دومین مدل MiniMax H3 که مؤلفه‌هایی را برای ترکیب فراهم می‌کند. | MODEL | بله | - |
| `video_patch_proj.` | سهم `model1` برای پروجکشن وصله ویدئو (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `audio_patch_proj.` | سهم `model1` برای پروجکشن وصله صدا (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `condition_proj.` | سهم `model1` برای پروجکشن شرطی‌سازی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `time_embedder.` | سهم `model1` برای جاسازی‌گر زمان (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.blocks.0.` | سهم `model1` برای نخستین بلوک پالایش‌گر توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.blocks.1.` | سهم `model1` برای دومین بلوک پالایش‌گر توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `token_refiner.final_norm.` | سهم `model1` برای نرمال‌سازی نهایی پالایش‌گر توکن (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `blocks.0.` تا `blocks.49.` | سهم `model1` برای هر یک از 50 بلوک ترنسفورمر، یک ویجت برای هر بلوک (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.norm.` | سهم `model1` برای نرمال‌سازی لایه نهایی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.adaln_proj.` | سهم `model1` برای پروجکشن نرمال‌سازی تطبیقی نهایی (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.video_out.` | سهم `model1` برای لایه خروجی ویدئو (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_layer.audio_out.` | سهم `model1` برای لایه خروجی صدا (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |

نسبت 1.0 (مقدار پیش‌فرض) آن مؤلفه را به‌طور کامل از `model1` نگه می‌دارد و 0.0 آن را به‌طور کامل از `model2` می‌گیرد؛ مقادیر میان این دو، آن دو را ترکیب می‌کنند. تنسورهایی که نسبت ندارند، مانند آماره‌های نرمال‌سازی، همیشه از `model1` می‌آیند. هر دو ورودی باید مدل‌های MiniMax H3 با معماری یکسان باشند؛ در غیر این صورت، ادغام مدلی تولید می‌کند که اجرا نمی‌شود.
