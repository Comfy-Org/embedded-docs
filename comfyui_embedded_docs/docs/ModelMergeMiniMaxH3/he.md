# Model Merge MiniMax H3

מיזוג שני מודלי MiniMax H3 תואמים לפי רכיב, עם יחס נפרד לכל חלק בארכיטקטורה. העלאת יחס לוקחת יותר מאותו רכיב מ-`model2`, כך שניתן לשמור על היטלי הטלאים ובלוקי הזיכוך של מודל אחד ועם זאת להחליף את בלוקי הטרנספורמר במודל אחר.
