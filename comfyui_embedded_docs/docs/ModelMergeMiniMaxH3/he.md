# Model Merge MiniMax H3

מיזוג שני מודלים תואמים מסוג MiniMax H3 לפי רכיב, עם יחס נפרד לכל חלק בארכיטקטורה. כל יחס הוא החלק של `model1`, כך שניתן לשמור על היטלי ה-patch (patch projections) ועל בלוקי העידון (refinement blocks) של מודל אחד, ולהחליף את בלוקי ה-transformer במודל אחר.
