# Model Merge MiniMax H3

互換性のある 2 つの MiniMax H3 モデルをコンポーネント単位でマージします。アーキテクチャの各部分ごとに個別の割合を指定できます。割合を上げると、そのコンポーネントを `model2` からより多く取得します。これにより、一方のモデルのパッチ投影とリファインメントブロックを維持しながら、Transformer ブロックを別のモデルで置き換えられます。

| `model2` | ブレンドするコンポーネントを供給する 2 番目の MiniMax H3 モデルです。 | MODEL | はい | - |
| `video_patch_proj.` | 映像パッチ投影に対する `model2` の割合（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `audio_patch_proj.` | 音声パッチ投影に対する `model2` の割合（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |

| `final_layer.video_out.` | 映像出力層に対する `model2` の割合（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |

割合 0.0 はそのコンポーネントを完全に `model1` から保持し、1.0 は完全に `model2` から取得します。中間の値は 2 つをブレンドします。正規化統計量など、割合を持たないテンソルは常に `model1` から取得されます。両方の入力は同じアーキテクチャの MiniMax H3 モデルである必要があります。そうでない場合、マージによって実行できないモデルが生成されます。
