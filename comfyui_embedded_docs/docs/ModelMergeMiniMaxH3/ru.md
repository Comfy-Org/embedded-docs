# Model Merge MiniMax H3

Объединение двух совместимых моделей MiniMax H3 по компонентам, с отдельной долей для каждой части архитектуры. Каждая доля — это доля `model1`, поэтому можно сохранить проекции патчей и блоки уточнения одной модели, заменив блоки трансформера другой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model1` | Первая модель MiniMax H3. Каждый компонент берётся из неё, а каждая доля определяет, какая часть этого компонента вместо неё поступает из `model2`. | MODEL | Да | - |
| `model2` | Вторая модель MiniMax H3, из которой берутся смешиваемые компоненты. | MODEL | Да | - |
| `video_patch_proj.` | Доля `model1` для проекции патчей видео (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `audio_patch_proj.` | Доля `model1` для проекции патчей аудио (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `condition_proj.` | Доля `model1` для проекции кондиционирования (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `time_embedder.` | Доля `model1` для эмбеддера времени (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.blocks.0.` | Доля `model1` для первого блока уточнения токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.blocks.1.` | Доля `model1` для второго блока уточнения токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.final_norm.` | Доля `model1` для финальной нормализации уточнителя токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `blocks.0.`–`blocks.49.` | Доля `model1` для каждого из 50 блоков трансформера, по одному виджету на блок (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.norm.` | Доля `model1` для нормализации финального слоя (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.adaln_proj.` | Доля `model1` для проекции финальной адаптивной нормализации (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.video_out.` | Доля `model1` для выходного слоя видео (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.audio_out.` | Доля `model1` для выходного слоя аудио (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

Доля 1.0 (значение по умолчанию) полностью сохраняет этот компонент из `model1`, а 0.0 полностью берёт его из `model2`; промежуточные значения смешивают оба варианта. Тензоры, для которых доля не задана, например статистики нормализации, всегда берутся из `model1`. Оба входа должны быть моделями MiniMax H3 с одинаковой архитектурой, иначе в результате объединения получится модель, которая не запускается.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Объединённая модель MiniMax H3. | MODEL |
