# Model Merge MiniMax H3

Объедините две совместимые модели MiniMax H3 по компонентам, с отдельным коэффициентом для каждой части архитектуры. Увеличение коэффициента означает, что берётся больше этого компонента из `model2`, так что можно сохранить patch-проекции и блоки уточнения одной модели, заменив блоки трансформера другой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model1` | Первая модель MiniMax H3, база, из которой берётся каждый компонент (вес по умолчанию применяется там, где `model2` не используется). | MODEL | Да | - |
| `model2` | Вторая модель MiniMax H3, которая предоставляет компоненты для смешивания. | MODEL | Да | - |
| `video_patch_proj.` | Доля `model2` для проекции патчей видео (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `audio_patch_proj.` | Доля `model2` для проекции патчей аудио (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `condition_proj.` | Доля `model2` для проекции обусловливания (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `time_embedder.` | Доля `model2` для эмбеддера времени (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.blocks.0.` | Доля `model2` для первого блока уточнения токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.blocks.1.` | Доля `model2` для второго блока уточнения токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `token_refiner.final_norm.` | Доля `model2` для финальной нормализации уточнения токенов (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `blocks.0.` through `blocks.49.` | Доля `model2` для каждого из 50 блоков трансформера, по одному виджету на блок (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.norm.` | Доля `model2` для нормализации финального слоя (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.adaln_proj.` | Доля `model2` для проекции адаптивной нормализации финального слоя (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.video_out.` | Доля `model2` для выходного слоя видео (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `final_layer.audio_out.` | Доля `model2` для выходного слоя аудио (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

Коэффициент 0.0 означает, что компонент полностью берётся из `model1`, а 1.0 — полностью из `model2`; промежуточные значения смешивают оба варианта. Тензоры, для которых коэффициент не задан, например статистики нормализации, всегда берутся из `model1`. Оба входа должны быть моделями MiniMax H3 с одинаковой архитектурой, иначе при объединении получится модель, которая не запускается.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Объединённая модель MiniMax H3. | MODEL |
