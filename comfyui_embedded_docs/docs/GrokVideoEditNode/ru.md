# Grok Video Edit

Этот узел использует Grok API для редактирования существующего видео на основе текстового запроса. Он загружает ваше видео, отправляет запрос модели ИИ для изменения в соответствии с вашим описанием и возвращает вновь сгенерированное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель ИИ, используемая для редактирования видео (по умолчанию: "grok-imagine-video"). | COMBO | Да | "grok-imagine-video" |
| `prompt` | Текстовое описание желаемого видео. | STRING | Да | N/A |
| `video` | Входное видео для редактирования. Максимальная поддерживаемая длительность — 8,7 секунды и размер файла 50 МБ. | VIDEO | Да | N/A |
| `seed` | Сид, определяющий, должен ли узел перезапуститься; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Нет | 0 до 2147483647 |

**Ограничения:**

* Значение `prompt` не должно быть пустым.
* Длительность входного видео `video` должна быть от 1 до 8,7 секунды.
* Размер файла входного видео `video` не должен превышать 50 МБ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Отредактированное видео, сгенерированное моделью ИИ. | VIDEO |
