# Grok Video Edit

Этот узел использует Grok API для редактирования существующего видео на основе текстового промпта. Он загружает ваше видео, отправляет запрос ИИ-модели на изменение согласно вашему описанию и возвращает новое сгенерированное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель ИИ для редактирования видео (по умолчанию: "grok-imagine-video"). | COMBO | Да | "grok-imagine-video" |
| `prompt` | Текстовое описание желаемого видео. | STRING | Да | N/A |
| `video` | Входное видео для редактирования. Максимальная поддерживаемая длительность — 8,7 секунды, размер файла — 50 МБ. | VIDEO | Да | N/A |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |

**Ограничения:**

* `prompt` не должен быть пустым.
* Длительность входного `video` должна составлять от 1 до 8,7 секунды.
* Размер файла входного `video` не должен превышать 50 МБ.

**Примечание:** Этот узел является API-узлом; для его запуска требуются аккаунт Comfy.org и ключ API. Использование тарифицируется приблизительно по $0.06 за секунду видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Отредактированное видео, сгенерированное моделью ИИ. | VIDEO |
