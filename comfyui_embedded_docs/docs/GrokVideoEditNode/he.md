# Grok עריכת וידאו

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI שיש להשתמש בו לעריכת וידאו (ברירת מחדל: "grok-imagine-video"). | COMBO | כן | "grok-imagine-video" |
| `prompt` | תיאור טקסטואלי של הווידאו הרצוי. | STRING | כן | N/A |
| `video` | וידאו הקלט שיש לערוך. משך מקסימלי נתמך הוא 8.7 שניות וגודל קובץ של 50MB. | VIDEO | כן | N/A |
| `seed` | ערך seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות בערך ה-seed (ברירת מחדל: 0). | INT | לא | 0 to 2147483647 |

**אילוצים:**

* ה-`prompt` לא יכול להיות ריק.
* קלט ה-`video` חייב להיות באורך שבין 1 ל-8.7 שניות.
* גודל קובץ ה-`video` בקלט לא יעלה על 50MB.

**הערה:** צומת זה הוא צומת API ודורש חשבון Comfy.org ומפתח API כדי לפעול. השימוש מחויב בתעריף של כ-0.06$ לשנייה של וידאו.
