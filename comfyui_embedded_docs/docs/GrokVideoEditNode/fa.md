# ویرایش ویدیو Grok

این گره از Grok API برای ویرایش یک ویدیوی موجود بر اساس متن توصیفی استفاده می‌کند. ویدیوی شما را بارگذاری می‌کند، درخواستی برای اصلاح آن بر اساس توصیف شما به مدل هوش مصنوعی ارسال می‌کند و ویدیوی تازه تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | Range |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل هوش مصنوعی مورد استفاده برای ویرایش ویدیو (پیش‌فرض: "grok-imagine-video"). | COMBO | بله | "grok-imagine-video" |
| `راهنما` | توصیف متنی ویدیوی موردنظر. | STRING | بله | N/A |
| `ویدیو` | ویدیوی ورودی که باید ویرایش شود. حداکثر مدت زمان پشتیبانی‌شده ۸٫۷ ثانیه و حداکثر حجم فایل ۵۰ مگابایت است. | VIDEO | بله | N/A |
| `بذر` | Seed برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

**محدودیت‌ها:**

* مقدار `prompt` نباید خالی باشد.
* مدت زمان ویدیوی ورودی `video` باید بین ۱ تا ۸٫۷ ثانیه باشد.
* حجم فایل ویدیوی ورودی `video` نباید از ۵۰ مگابایت بیشتر باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی ویرایش‌شده تولیدشده توسط مدل هوش مصنوعی. | VIDEO |
