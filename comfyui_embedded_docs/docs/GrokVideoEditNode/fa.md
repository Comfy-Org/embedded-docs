# ویرایش ویدیو Grok

این گره از API Grok برای ویرایش یک ویدئوی موجود بر اساس یک پرامپت متنی استفاده می‌کند. ویدئوی شما را بارگذاری می‌کند، درخواستی به مدل هوش مصنوعی می‌فرستد تا آن را مطابق توضیحات شما تغییر دهد، و ویدئوی تازه‌تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای ویرایش ویدئو (پیش‌فرض: "grok-imagine-video"). | COMBO | بله | "grok-imagine-video" |
| `prompt` | توضیح متنی ویدئوی موردنظر. | STRING | بله | N/A |
| `video` | ویدئوی ورودی که باید ویرایش شود. حداکثر مدت پشتیبانی‌شده 8.7 ثانیه و حداکثر حجم فایل 50 مگابایت است. | VIDEO | بله | N/A |
| `seed` | مقدار `seed` برای تعیین اینکه گره باید دوباره اجرا شود یا نه؛ نتایج واقعی بدون توجه به `seed` غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

**محدودیت‌ها:**

* `prompt` نباید خالی باشد.
* مدت‌زمان `video` ورودی باید بین 1 و 8.7 ثانیه باشد.
* حجم فایل `video` ورودی نباید از 50 مگابایت بیشتر باشد.

**توجه:** این گره یک گره API است و برای اجرا به حساب Comfy.org و کلید API نیاز دارد. هزینه استفاده حدوداً 0.06 دلار برای هر ثانیه ویدئو محاسبه می‌شود.

|-------------|-------------|-----------|
| `video` | ویدئوی ویرایش‌شده‌ای که توسط مدل هوش مصنوعی تولید شده است. | VIDEO |
