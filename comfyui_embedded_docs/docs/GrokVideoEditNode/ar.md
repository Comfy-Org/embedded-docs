# تعديل فيديو Grok

تستخدم هذه العقدة واجهة Grok API لتحرير فيديو موجود بناءً على مطالبة نصية. تقوم برفع الفيديو الخاص بك، وإرسال طلب إلى نموذج الذكاء الاصطناعي لتعديله وفقًا لوصفك، ثم تُعيد الفيديو المُنشأ حديثًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المستخدم لتحرير الفيديو (الافتراضي: "grok-imagine-video"). | COMBO | نعم | "grok-imagine-video" |
| `prompt` | وصف نصي للفيديو المطلوب. | STRING | نعم | N/A |
| `video` | الفيديو المُدخل المراد تحريره. الحد الأقصى للمدة المدعومة هو 8.7 ثانية وحجم الملف 50 ميغابايت. | VIDEO | نعم | N/A |
| `seed` | بذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0). | INT | لا | 0 إلى 2147483647 |

**القيود:**

* يجب ألا تكون `prompt` فارغة.
* يجب أن تكون مدة `video` المُدخل بين 1 و8.7 ثانية.
* يجب ألا يتجاوز حجم ملف `video` المُدخل 50 ميغابايت.

**ملاحظة:** هذه العقدة عقدة API وتتطلب حساب Comfy.org ومفتاح API للتشغيل. تُحتسب الاستخدام بنحو 0.06 دولار لكل ثانية من الفيديو.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `video` | الفيديو المحرر الذي أنشأه نموذج الذكاء الاصطناعي. | VIDEO |
