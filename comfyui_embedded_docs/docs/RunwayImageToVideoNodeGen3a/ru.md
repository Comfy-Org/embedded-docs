# Runway: Изображение в видео (Gen3a Turbo)

Узел Runway Image to Video (Gen3a Turbo) генерирует видео из одного начального кадра с использованием модели Runway Gen3a Turbo. Он принимает текстовый запрос и начальный кадр изображения, затем создаёт видеопоследовательность на основе указанной длительности и соотношения сторон. Этот узел подключается к API Runway для удалённого выполнения генерации.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации (по умолчанию: "") | STRING | Да | N/A |
| `start_frame` | Начальный кадр для видео | IMAGE | Да | N/A |
| `duration` | Длительность видео в секундах (по умолчанию: "5") | COMBO | Да | `"5"`<br>`"10"` |
| `ratio` | Соотношение сторон генерируемого видео (по умолчанию: "768:1280") | COMBO | Да | `"768:1280"`<br>`"1280:768"` |
| `seed` | Случайное зерно (seed) для генерации (по умолчанию: 0) | INT | Нет | 0 to 4294967295 |

**Ограничения параметров:**

- `start_frame` должен иметь размеры, не превышающие 7999x7999 пикселей.
- `start_frame` должен иметь соотношение сторон от 0.5 до 2.0.
- `prompt` должен содержать хотя бы один символ (не может быть пустым).

**Примечания:**

- Этот узел устарел.
- Перед генерацией Runway рекомендует ознакомиться с руководством по лучшим практикам: https://help.runwayml.com/hc/en-us/articles/33927968552339-Creating-with-Act-One-on-Gen-3-Alpha-and-Turbo

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность | VIDEO |
