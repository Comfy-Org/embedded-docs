# Runway: Изображение в видео (Gen3a Turbo)

Узел Runway Image to Video (Gen3a Turbo) генерирует видео из одного начального кадра с помощью модели Gen3a Turbo от Runway. Он принимает текстовый запрос и начальный кадр изображения, затем создаёт видеопоследовательность на основе указанной длительности и соотношения сторон. Этот узел подключается к API Runway для удалённой обработки генерации. Runway рекомендует ознакомиться с руководством по лучшим практикам перед генерацией: https://help.runwayml.com/hc/en-us/articles/33927968552339-Creating-with-Act-One-on-Gen-3-Alpha-and-Turbo. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Текстовый запрос для генерации (по умолчанию: "") | STRING | Да | N/A |
| `начальный_кадр` | Начальный кадр для видео | IMAGE | Да | N/A |
| `продолжительность` | Длительность видео в секундах (по умолчанию: "5") | COMBO | Да | `"5"`<br>`"10"` |
| `соотношение` | Соотношение сторон генерируемого видео (по умолчанию: "768:1280") | COMBO | Да | `"768:1280"`<br>`"1280:768"` |
| `сид` | Случайное зерно для генерации (по умолчанию: 0) | INT | Да | 0 до 4294967295 |

**Ограничения параметров:**

- Размеры `start_frame` не должны превышать 7999x7999 пикселей.
- Соотношение сторон `start_frame` должно быть от 0.5 до 2.0.
- `start_frame` принимает одно изображение (максимум 1).
- `prompt` должен содержать хотя бы один символ (не может быть пустым).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность | VIDEO |
