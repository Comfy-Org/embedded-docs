# Runway: Изображение в видео (Gen3a Turbo)

Узел Runway Image to Video (Gen3a Turbo) генерирует видео из одного начального кадра с использованием модели Runway Gen3a Turbo. Он принимает текстовый запрос и начальный кадр изображения, а затем создаёт видеопоследовательность на основе указанной длительности и соотношения сторон. Генерация обрабатывается удалённо через API Runway. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Текстовый запрос для генерации (по умолчанию: "") | STRING | Да | N/A |
| `начальный_кадр` | Начальный кадр, используемый для видео | IMAGE | Да | N/A |
| `продолжительность` | Длительность сгенерированного видео в секундах (по умолчанию: "5") | COMBO | Да | `"5"`<br>`"10"` |
| `соотношение` | Соотношение сторон сгенерированного видео (по умолчанию: "768:1280") | COMBO | Да | `"768:1280"`<br>`"1280:768"` |
| `сид` | Случайное зерно для генерации (по умолчанию: 0) | INT | Да | 0 до 4294967295 |

**Ограничения параметров:**

- Значение `prompt` должно содержать как минимум один символ (не может быть пустым).
- `start_frame` принимает одно изображение (максимум 1).
- `start_frame` не должен превышать 7999 x 7999 пикселей по размерам.
- `start_frame` должен иметь соотношение сторон от 1:2 до 2:1 (от 0.5 до 2.0).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность | VIDEO |
