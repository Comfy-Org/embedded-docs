# Runway تبدیل تصویر به ویدیو (Gen3a Turbo)

گره Runway Image to Video (Gen3a Turbo) با استفاده از مدل Gen3a Turbo شرکت Runway، از یک فریم شروع واحد، ویدیو تولید می‌کند. این گره یک متن راهنما (prompt) و یک فریم تصویر اولیه می‌گیرد و سپس بر اساس مدت‌زمان و نسبت ابعاد مشخص‌شده، یک توالی ویدیویی ایجاد می‌کند. این گره برای پردازش از راه دور به API شرکت Runway متصل می‌شود. Runway توصیه می‌کند پیش از تولید، راهنمای بهترین روش‌های خود را مطالعه کنید: https://help.runwayml.com/hc/en-us/articles/33927968552339-Creating-with-Act-One-on-Gen-3-Alpha-and-Turbo. این گره به‌عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `پرامپت` | متن راهنما (prompt) برای تولید (پیش‌فرض: `""`) | STRING | بله | N/A |
| `فریم شروع` | فریم شروع برای استفاده در ویدیو | IMAGE | بله | N/A |
| `مدت زمان` | مدت‌زمان ویدیو بر حسب ثانیه (پیش‌فرض: `"5"`) | COMBO | بله | `"5"`<br>`"10"` |
| `نسبت تصویر` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: `"768:1280"`) | COMBO | بله | `"768:1280"`<br>`"1280:768"` |
| `seed` | seed تصادفی برای تولید (پیش‌فرض: 0) | INT | بله | 0 تا 4294967295 |

**محدودیت‌های پارامتر:**

- ابعاد `start_frame` نباید از 7999×7999 پیکسل بیشتر شود.
- نسبت ابعاد `start_frame` باید بین 0.5 و 2.0 باشد.
- `start_frame` فقط یک تصویر را می‌پذیرد (حداکثر ۱).
- `prompt` باید حداقل شامل یک نویسه (کاراکتر) باشد (نمی‌تواند خالی باشد).
