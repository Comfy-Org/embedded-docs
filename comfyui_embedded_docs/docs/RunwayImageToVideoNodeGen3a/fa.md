# Runway تبدیل تصویر به ویدیو (Gen3a Turbo)

گره Runway Image to Video (Gen3a Turbo) با استفاده از مدل Gen3a Turbo شرکت Runway، از یک فریم شروعِ تک، ویدیو تولید می‌کند. این گره یک متن راهنما (prompt) و یک فریم تصویر اولیه دریافت کرده و بر اساس مدت‌زمان و نسبت ابعاد مشخص‌شده، دنباله‌ای ویدیویی می‌سازد. برای پردازش تولید از راه دور، این گره به API رانوی متصل می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنما برای تولید (پیش‌فرض: "") | STRING | بله | N/A |
| `start_frame` | فریم شروعی که برای ویدیو استفاده می‌شود | IMAGE | بله | N/A |
| `duration` | مدت‌زمان ویدیو بر حسب ثانیه (پیش‌فرض: "5") | COMBO | بله | `"5"`<br>`"10"` |
| `ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: "768:1280") | COMBO | بله | `"768:1280"`<br>`"1280:768"` |
| `seed` | دانه تصادفی برای تولید (پیش‌فرض: 0) | INT | خیر | 0 تا 4294967295 |

**محدودیت‌های پارامتر:**

- ابعاد `start_frame` نباید از 7999×7999 پیکسل بیشتر باشد.
- نسبت ابعاد `start_frame` باید بین 0.5 و 2.0 باشد.
- `prompt` باید حداقل شامل یک نویسه باشد (نمی‌تواند خالی باشد).

**نکات:**

- این گره منسوخ شده است.
- پیش از تولید، Runway توصیه می‌کند راهنمای بهترین روش‌های خود را مرور کنید: https://help.runwayml.com/hc/en-us/articles/33927968552339-Creating-with-Act-One-on-Gen-3-Alpha-and-Turbo

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | دنباله ویدیویی تولیدشده | VIDEO |
