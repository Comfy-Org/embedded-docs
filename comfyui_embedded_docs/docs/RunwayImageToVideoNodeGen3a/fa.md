# Runway تبدیل تصویر به ویدیو (Gen3a Turbo)

Runway Image to Video (Gen3a Turbo) node با استفاده از مدل Gen3a Turbo شرکت Runway، یک ویدئو از یک فریم آغازین تولید می‌کند. این گره یک پرامپت متنی و یک تصویر فریم اولیه دریافت می‌کند و سپس بر اساس مدت‌زمان و نسبت تصویر مشخص‌شده، یک دنباله ویدئویی ایجاد می‌کند. فرایند تولید به‌صورت از راه دور از طریق API شرکت Runway پردازش می‌شود. این گره به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی برای تولید (پیش‌فرض: "") | STRING | بله | N/A |
| `start_frame` | فریم آغازین برای استفاده در ویدئو | IMAGE | بله | N/A |
| `duration` | مدت‌زمان ویدئوی تولیدشده، بر حسب ثانیه (پیش‌فرض: "5") | COMBO | بله | `"5"`<br>`"10"` |
| `ratio` | نسبت تصویر ویدئوی تولیدشده (پیش‌فرض: "768:1280") | COMBO | بله | `"768:1280"`<br>`"1280:768"` |
| `seed` | بذر تصادفی برای تولید (پیش‌فرض: 0) | INT | بله | 0 تا 4294967295 |

**محدودیت‌های پارامتر:**

- `prompt` باید حداقل یک نویسه داشته باشد (نمی‌تواند خالی باشد).
- `start_frame` تنها یک تصویر می‌پذیرد (حداکثر ۱).
- `start_frame` نباید از نظر ابعاد از 7999 × 7999 پیکسل فراتر رود.
- `start_frame` باید نسبت تصویری بین 1:2 و 2:1 داشته باشد (0.5 تا 2.0).

| `output` | دنباله ویدئویی تولیدشده | VIDEO |
