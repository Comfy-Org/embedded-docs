# Ideogram 4.5 Edit

ویرایش یا ترکیب حداکثر ۵ تصویر با راهنمایی یک پرامپت متنی با Ideogram 4.5. تصویر ۱ تصویری است که ویرایش می‌شود و تصاویر بعدی ارجاع‌های اختیاری هستند. کل تصویر دوباره رندر می‌شود، بنابراین اندازه یا نسبت ابعاد نتیجه می‌تواند تغییر کند؛ برای حفظ پیکسل‌های دست‌نخورده، در عوض از Ideogram 4.5 Precise Edit استفاده کنید.

### محدودیت‌های پارامترها

- **تعداد تصاویر:** حداقل ۱ و حداکثر ۵ تصویر؛ یک ورودی دسته‌ای برای هر تصویر یک‌بار شمرده می‌شود. تصویر ۱ تصویری است که ویرایش می‌شود و بقیه ارجاع هستند.
- **نسبت ابعاد تصویر:** هر تصویر باید عرضی حداکثر ۶ برابر ارتفاع و ارتفاعی حداکثر ۶ برابر عرض داشته باشد (بین 1:6 و 6:1).
- **برچسب‌های پرامپت:** `@ImageN` بدون حساسیت به بزرگی و کوچکی حروف تطبیق داده می‌شود و نباید از تعداد تصاویر متصل بیشتر باشد؛ پرامپت نباید فقط فاصله باشد و حداکثر ۱۰۰۰۰ کاراکتر داشته باشد.
- **اندازه سفارشی:** فقط زمانی استفاده می‌شود که `size` برابر `"custom"` باشد. حاصل‌ضرب عرض در ارتفاع نباید از 4194304 پیکسل (2048x2048) بیشتر شود، و ضلع بلندتر نباید بیش از ۶ برابر ضلع کوتاه‌تر باشد. عرض و ارتفاع باید بین 256 و 4608 باشند و به مضرب‌های 32 گرد می‌شوند.
- **مقیاس‌بندی هنگام بارگذاری:** تصاویر بزرگ‌تر از حدود 4 MP، یا بزرگ‌تر از 4608 پیکسل در ضلع بلند، پیش از ارسال کوچک می‌شوند.
- **ایمنی محتوا:** اگر فیلتر ایمنی محتوای Ideogram نتیجه را مسدود کند، گره به‌جای بازگرداندن تصویر، خطا ایجاد می‌کند.
