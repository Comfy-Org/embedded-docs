# Вычитание CLIP

Узел CLIPMergeSubtract выполняет объединение моделей, вычитая веса одной модели CLIP из другой. Он создаёт новую модель CLIP, клонируя первую модель и вычитая ключевые патчи из второй модели, с регулируемым множителем для контроля силы вычитания. Это позволяет точно настраивать смешивание моделей, удаляя определённые характеристики из базовой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip1` | Базовая модель CLIP, которая будет клонирована и модифицирована | CLIP | Да | - |
| `clip2` | Модель CLIP, чьи ключевые патчи будут вычтены из базовой модели | CLIP | Да | - |
| `множитель` | Управляет силой операции вычитания (по умолчанию: 1.0) | FLOAT | Да | -10.0 до 10.0 (step: 0.01) |

**Примечание:** Узел исключает параметры `.position_ids` и `.logit_scale` из операции вычитания независимо от значения множителя.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `clip` | Результирующая модель CLIP после вычитания весов второй модели из первой | CLIP |
