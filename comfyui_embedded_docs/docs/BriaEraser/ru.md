# BriaEraser

Bria Eraser удаляет объекты или области из изображения с помощью API Bria. Вы предоставляете изображение и маску, которая очерчивает области для удаления; узел загружает оба файла в Bria, запускает задачу удаления, ожидает её завершения и возвращает отредактированное изображение с удалёнными областями, закрытыми маской.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение, содержащее объекты или области для удаления. | IMAGE | Да | - |
| `mask` | Белые области удаляются, чёрные области сохраняются. Перед отправкой маска бинаризуется, поэтому частично закрашенные области считаются белыми. Соотношение сторон маски должно совпадать с соотношением сторон изображения. | MASK | Да | - |
| `mask_type` | Выбор способа создания маски. «manual» — для масок, созданных вручную или кистью; «automatic» — для масок, полученных с помощью моделей сегментации, таких как SAM. | COMBO | Да | "manual"<br>"automatic" |
| `moderation` | Настройки модерации. Установите значение «true», чтобы включить модерацию содержимого для входных и/или выходных изображений. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Примечание: если для параметра `moderation` установлено значение «true», становятся доступны два дополнительных логических параметра:

- `visual_input_moderation` — применяет визуальную модерацию содержимого к входному изображению (по умолчанию: false)
- `visual_output_moderation` — применяет визуальную модерацию содержимого к выходному изображению (по умолчанию: false)

Маска должна соответствовать соотношению сторон изображения, иначе запрос завершится ошибкой. Маска преобразуется в бинарную (чёрно-белую) маску перед отправкой в API, поэтому частично закрашенные области считаются белыми и будут удалены.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение с удалёнными объектами или областями, закрытыми маской. | IMAGE |
