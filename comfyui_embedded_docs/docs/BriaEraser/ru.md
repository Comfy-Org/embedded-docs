# Bria Eraser

Bria Eraser удаляет объекты или области с изображения с помощью Bria API. Вы предоставляете изображение и маску, которая обозначает области для удаления; узел загружает и то и другое в Bria, запускает задачу стирания, ожидает её завершения и возвращает отредактированное изображение с удалёнными замаскированными областями.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, содержащее объекты или области для удаления. | IMAGE | Да | - |
| `маска` | Белые области стираются, чёрные сохраняются. Перед отправкой маска бинаризуется, поэтому частично закрашенные области считаются белыми. Должна иметь то же соотношение сторон, что и изображение. | MASK | Да | - |
| `mask_type` | Тип источника маски. "manual" — для масок, нарисованных вручную или кистью; "automatic" — для масок, созданных моделями сегментации, такими как SAM. | COMBO | Да | "manual"<br>"automatic" |
| `модерация` | Настройки модерации. Установите "true", чтобы включить визуальную модерацию контента для входных и/или выходных изображений. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Когда для `moderation` установлено значение "true", становятся доступны две дополнительные логические настройки:

- `visual_input_moderation` — применяет визуальную модерацию контента к входному изображению (по умолчанию: false)
- `visual_output_moderation` — применяет визуальную модерацию контента к выходному изображению (по умолчанию: false)

Примечание: Маска должна соответствовать соотношению сторон изображения, иначе запрос завершится неудачно. Перед отправкой в API маска преобразуется в бинарную (чёрно-белую) маску: области, закрашенные менее чем с половиной непрозрачности, игнорируются, а частично закрашенные области считаются белыми и будут стёрты. Маска должна содержать хотя бы некоторую белую область; пустая маска приводит к сбою запроса, поскольку стирать нечего.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение с удалёнными замаскированными объектами или областями. | IMAGE |
