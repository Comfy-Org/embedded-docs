# BriaEraser

Bria Eraser удаляет объекты или области из изображения с помощью API Bria. Вы предоставляете изображение и маску, которая обозначает области для удаления; узел загружает оба файла в Bria, запускает задачу удаления, ожидает ее завершения и возвращает отредактированное изображение с удаленными областями, отмеченными маской.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `изображение` | Входное изображение, содержащее объекты или области для удаления. | IMAGE | Да | - |
| `маска` | Белые области удаляются, черные области сохраняются. Перед отправкой маска преобразуется в бинарную, поэтому частично закрашенные области считаются белыми. Соотношение сторон маски должно совпадать с соотношением сторон изображения. | MASK | Да | - |
| `mask_type` | Определяет, как была создана маска. «manual» — для масок, нарисованных вручную или кистью; «automatic» — для масок, созданных моделями сегментации, такими как SAM. | COMBO | Да | "manual"<br>"automatic" |
| `модерация` | Настройки модерации. Установите значение "true", чтобы включить визуальную модерацию содержимого входных и/или выходных изображений. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Примечание: когда для `moderation` установлено значение "true", становятся доступны два дополнительных логических параметра:

- `visual_input_moderation` — применяет визуальную модерацию содержимого к входному изображению (по умолчанию: false)
- `visual_output_moderation` — применяет визуальную модерацию содержимого к выходному изображению (по умолчанию: false)

Маска должна соответствовать соотношению сторон изображения, в противном случае запрос завершится ошибкой. Перед отправкой в API маска преобразуется в бинарную (черно-белую): области, закрашенные менее чем на половину непрозрачности, игнорируются, а частично закрашенные области считаются белыми и будут удалены. Маска должна содержать хотя бы некоторую белую область; пустая маска приводит к ошибке запроса, так как удалять нечего.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Отредактированное изображение с удаленными объектами или областями, отмеченными маской. | IMAGE |
