# Bria Eraser

Bria Eraser удаляет объекты или области с изображения с помощью API Bria. Вы предоставляете изображение и маску, которая очерчивает области для удаления; узел загружает и то и другое в Bria, запускает задание удаления, ожидает его завершения и возвращает отредактированное изображение с удалёнными областями, закрытыми маской.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, содержащее объекты или области для удаления. | IMAGE | Да | - |
| `маска` | Белые области удаляются, чёрные сохраняются. Перед отправкой маска бинаризуется, поэтому частично закрашенные области считаются белыми. Должна иметь то же соотношение сторон, что и изображение. | MASK | Да | - |
| `mask_type` | Тип источника маски. "manual" — для масок, нарисованных вручную или кистью; "automatic" — для масок, созданных моделями сегментации, такими как SAM. | COMBO | Да | "manual"<br>"automatic" |
| `модерация` | Настройки модерации. Установите "true", чтобы включить модерацию визуального контента для входных и/или выходных изображений. | DYNAMIC_COMBO | Да | "false"<br>"true" |

Когда `moderation` установлен в "true", становятся доступны две дополнительные булевы настройки:

- `visual_input_moderation` — применяет модерацию визуального контента к входному изображению (по умолчанию: false)
- `visual_output_moderation` — применяет модерацию визуального контента к выходному изображению (по умолчанию: false)

Примечание: Маска должна соответствовать соотношению сторон изображения, иначе запрос завершится ошибкой. Перед отправкой в API маска преобразуется в бинарную (чёрно-белую) маску: области, закрашенные с непрозрачностью менее половины, игнорируются, а частично закрашенные области считаются белыми и будут удалены. Маска должна содержать хотя бы некоторую белую область; пустая маска приводит к сбою запроса, поскольку удалять нечего.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение с удалёнными объектами или областями, закрытыми маской. | IMAGE |
