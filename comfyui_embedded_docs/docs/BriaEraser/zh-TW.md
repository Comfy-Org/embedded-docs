# Bria 擦除

Bria Eraser 會使用 Bria API 從影像中移除物件或區域。您提供一張影像，以及一個勾勒出要移除區域的遮罩；此節點會將兩者上傳至 Bria，執行清除作業，等待作業完成，並傳回已編輯的影像，其中被遮罩的區域已被清除。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 包含要移除之物件或區域的輸入影像。 | IMAGE | 是 | - |
| `遮罩` | 白色區域會被清除，黑色區域會被保留。遮罩在傳送前會先二值化，因此部分塗繪的區域會計為白色。必須與影像具有相同的長寬比。 | MASK | 是 | - |
| `遮罩類型` | 遮罩來源類型。"manual" 用於手繪或筆刷遮罩；"automatic" 用於由分割模型（例如 SAM）產生的遮罩。 | COMBO | 是 | "manual"<br>"automatic" |
| `內容審核` | 內容審核設定。設為 "true" 可對輸入及/或輸出影像啟用視覺內容審核。 | DYNAMIC_COMBO | 是 | "false"<br>"true" |

當 `moderation` 設為 "true" 時，會提供兩個額外的布林設定：

- `visual_input_moderation` — 對輸入影像套用視覺內容審核（預設：false）
- `visual_output_moderation` — 對輸出影像套用視覺內容審核（預設：false）

注意：遮罩必須與影像的長寬比相符，否則請求會失敗。遮罩在傳送至 API 前會轉換為二值（黑白）遮罩：以低於一半不透明度塗繪的區域會被忽略，而部分塗繪的區域會被視為白色並將被清除。遮罩必須至少包含一些白色區域；空遮罩會導致請求失敗，因為沒有可清除的內容。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `image` | 已編輯的影像，其中被遮罩的物件或區域已被移除。 | IMAGE |
