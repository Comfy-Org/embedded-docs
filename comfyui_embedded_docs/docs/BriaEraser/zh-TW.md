# BriaEraser

Bria Eraser 使用 Bria API 從圖像中移除物體或區域。您提供一張圖像和一個標示要移除區域的遮罩；節點會將兩者上傳至 Bria，執行清除作業，等待作業完成，然後傳回已將遮罩區域抹除的編輯後圖像。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 包含要移除之物體或區域的輸入圖像。 | IMAGE | 是 | - |
| `遮罩` | 白色區域會被抹除，黑色區域會被保留。遮罩在傳送前會先二值化，因此部分繪製的區域會被視為白色。必須與圖像具有相同的長寬比。 | MASK | 是 | - |
| `遮罩類型` | 選擇遮罩的建立方式。「manual」用於手繪或筆刷遮罩；「automatic」用於由分割模型（如 SAM）產生的遮罩。 | COMBO | 是 | "manual"<br>"automatic" |
| `內容審核` | 內容審核設定。設為「true」可對輸入和/或輸出圖像啟用視覺內容審核。 | DYNAMIC_COMBO | 是 | "false"<br>"true" |

注意：當 `moderation` 設為「true」時，會出現兩個額外的布林設定：

- `visual_input_moderation` — 對輸入圖像套用視覺內容審核（預設值：false）
- `visual_output_moderation` — 對輸出圖像套用視覺內容審核（預設值：false）

遮罩必須與圖像的長寬比相符，否則請求會失敗。遮罩在傳送至 API 前會轉換為二值（黑白）遮罩：不透明度低於一半的繪製區域會被忽略，而部分繪製的區域會被視為白色並遭到抹除。遮罩必須至少包含一些白色區域；空的遮罩會導致請求失敗，因為沒有可抹除的內容。
