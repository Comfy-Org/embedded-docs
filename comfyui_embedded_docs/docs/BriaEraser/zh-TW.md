# Bria 擦除

Bria Eraser 使用 Bria API 從影像中移除物件或區域。您需提供一張影像，以及一個標示要移除區域的遮罩；此節點會將兩者上傳至 Bria，執行擦除作業，等待其完成，並傳回已擦除遮罩區域的編輯後影像。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 包含要移除之物件或區域的輸入影像。 | IMAGE | 是 | - |
| `遮罩` | 白色區域會被擦除，黑色區域則會保留。遮罩在傳送前會進行二值化，因此部分塗繪的區域會被視為白色。必須與影像具有相同的長寬比。 | MASK | 是 | - |
| `遮罩類型` | 遮罩來源類型。"manual" 適用於手繪或筆刷遮罩；"automatic" 適用於由分割模型（例如 SAM）產生的遮罩。 | COMBO | 是 | "manual"<br>"automatic" |
| `內容審核` | 審核設定。設為 "true" 可對輸入及／或輸出影像啟用視覺內容審核。 | DYNAMIC_COMBO | 是 | "false"<br>"true" |

當 `moderation` 設為 "true" 時，會提供兩個額外的布林設定：

- `visual_input_moderation` — 對輸入影像套用視覺內容審核（預設值：false）
- `visual_output_moderation` — 對輸出影像套用視覺內容審核（預設值：false）

注意：遮罩必須與影像的長寬比相符，否則請求會失敗。遮罩在傳送至 API 前會轉換為二值（黑白）遮罩：不透明度低於一半的塗繪區域會被忽略，而部分塗繪的區域會被視為白色並遭到擦除。遮罩必須至少包含一些白色區域；空遮罩會導致請求失敗，因為沒有可擦除的內容。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `image` | 已移除遮罩物件或區域的編輯後影像。 | IMAGE |
