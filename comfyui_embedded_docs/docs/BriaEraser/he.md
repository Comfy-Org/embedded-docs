# מחק Bria

Bria Eraser מסיר אובייקטים או אזורים מתמונה באמצעות Bria API. אתה מספק תמונה ומסכה שמסמנת את האזורים להסרה; הצומת מעלה את שניהם ל-Bria, מריץ את משימת המחיקה, ממתין להשלמתה ומחזיר את התמונה הערוכה כאשר האזורים שסומנו במסכה נמחקו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט המכילה את האובייקטים או האזורים להסרה. | IMAGE | כן | - |
| `mask` | אזורים לבנים נמחקים, אזורים שחורים נשמרים. המסכה עוברת בינאריזציה לפני השליחה עם סף של 50%: רק אזורים שצבועים באטימות מעל 50% נחשבים ללבנים. חייבת להיות באותו יחס רוחב-גובה כמו התמונה. | MASK | כן | - |
| `mask_type` | סוג מקור המסכה. "manual" מיועד למסכות מצוירות ביד או במברשת; "automatic" מיועד למסכות שנוצרות על ידי מודלי סגמנטציה כגון SAM. | COMBO | כן | "manual"<br>"automatic" |
| `moderation` | הגדרות מודרציה. יש להגדיר ל-"true" כדי להפעיל מודרציה לתוכן חזותי על תמונות הקלט ו/או הפלט. | DYNAMIC_COMBO | כן | "false"<br>"true" |

כאשר `moderation` מוגדר ל-"true", שתי הגדרות בוליאניות נוספות הופכות לזמינות:

- `visual_input_moderation` — מפעיל מודרציה לתוכן חזותי על תמונת הקלט (ברירת מחדל: false)
- `visual_output_moderation` — מפעיל מודרציה לתוכן חזותי על תמונת הפלט (ברירת מחדל: false)

הערה: המסכה חייבת להתאים ליחס רוחב-גובה של התמונה, אחרת הבקשה תיכשל. המסכה מומרת למסכה בינארית (שחור-לבן) לפני שליחתה ל-API: אזורים שצבועים באטימות של פחות ממחצית מתעלמים מהם, ואזורים שצבועים חלקית מטופלים כלבנים ויימחקו. המסכה חייבת להכיל לפחות אזור לבן כלשהו; מסכה ריקה גורמת לבקשה להיכשל משום שאין מה למחוק.
