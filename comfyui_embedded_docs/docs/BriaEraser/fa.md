# پاک‌کن Bria

Bria Eraser اشیاء یا نواحی را با استفاده از API بریا از تصویر حذف می‌کند. شما یک تصویر و یک ماسک ارائه می‌دهید که نواحی مورد حذف را مشخص می‌کند؛ گره هر دو را به Bria بارگذاری می‌کند، کار حذف را اجرا می‌کند، منتظر تکمیل آن می‌ماند و تصویر ویرایش‌شده‌ای را برمی‌گرداند که نواحی ماسک‌شده در آن پاک شده‌اند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی حاوی اشیاء یا نواحی مورد حذف. | IMAGE | بله | - |
| `mask` | نواحی سفید حذف می‌شوند، نواحی سیاه حفظ می‌شوند. ماسک پیش از ارسال دودویی می‌شود، بنابراین نواحی نیمه‌رنگ به‌عنوان سفید در نظر گرفته می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `mask_type` | نوع منبع ماسک. "manual" برای ماسک‌های دستی یا قلم‌مویی است؛ "automatic" برای ماسک‌های تولیدشده توسط مدل‌های بخش‌بندی مانند SAM. | COMBO | بله | "manual"<br>"automatic" |
| `moderation` | تنظیمات بازبینی محتوا. برای فعال‌سازی بازبینی محتوای بصری روی تصویر ورودی و/یا خروجی، روی "true" تنظیم کنید. | DYNAMIC_COMBO | بله | "false"<br>"true" |

وقتی `moderation` روی "true" تنظیم شود، دو تنظیم بولی اضافی در دسترس قرار می‌گیرند:

- `visual_input_moderation` — بازبینی محتوای بصری را روی تصویر ورودی اعمال می‌کند (پیش‌فرض: false)
- `visual_output_moderation` — بازبینی محتوای بصری را روی تصویر خروجی اعمال می‌کند (پیش‌فرض: false)

توجه: ماسک باید با نسبت ابعاد تصویر مطابقت داشته باشد، در غیر این صورت درخواست شکست می‌خورد. ماسک پیش از ارسال به API به یک ماسک دودویی (سیاه و سفید) تبدیل می‌شود: نواحی با شفافیت کمتر از نیمه نادیده گرفته می‌شوند، و نواحی تا حدی رنگ‌شده سفید در نظر گرفته می‌شوند و حذف خواهند شد. ماسک باید حداقل مقداری ناحیه سفید داشته باشد؛ ماسک خالی باعث شکست درخواست می‌شود زیرا چیزی برای حذف وجود ندارد.
