# BriaEraser

Bria Eraser اشیاء یا نواحی را با استفاده از API بریا از تصویر حذف می‌کند. شما یک تصویر و یک ماسک که نواحی موردنظر برای حذف را مشخص می‌کند ارائه می‌دهید؛ گره هر دو را به بریا آپلود می‌کند، عملیات پاک‌سازی را اجرا می‌کند، منتظر تکمیل آن می‌ماند و تصویر ویرایش‌شده را با نواحی ماسک‌شده پاک‌شده بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی شامل اشیاء یا نواحی که باید حذف شوند. | IMAGE | بله | - |
| `mask` | نواحی سفید پاک می‌شوند، نواحی سیاه حفظ می‌شوند. ماسک قبل از ارسال باینری می‌شود، بنابراین نواحی نیمه‌رنگ‌شده سفید محسوب می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `mask_type` | نحوه ایجاد ماسک را انتخاب می‌کند. «manual» برای ماسک‌های دست‌کشیده یا قلم‌مویی است؛ «automatic» برای ماسک‌های تولیدشده توسط مدل‌های تقسیم‌بندی مانند SAM است. | COMBO | بله | "manual"<br>"automatic" |
| `moderation` | تنظیمات نظارت محتوا. روی «true» تنظیم کنید تا نظارت محتوای بصری روی تصویر ورودی و/یا خروجی فعال شود. | DYNAMIC_COMBO | بله | "false"<br>"true" |

توجه: وقتی `moderation` روی «true» تنظیم شود، دو تنظیم بولی اضافی در دسترس قرار می‌گیرند:

- `visual_input_moderation` — نظارت محتوای بصری را روی تصویر ورودی اعمال می‌کند (پیش‌فرض: false)
- `visual_output_moderation` — نظارت محتوای بصری را روی تصویر خروجی اعمال می‌کند (پیش‌فرض: false)

ماسک باید با نسبت ابعاد تصویر مطابقت داشته باشد، در غیر این صورت درخواست ناموفق می‌شود. ماسک قبل از ارسال به API به یک ماسک باینری (سیاه و سفید) تبدیل می‌شود: نواحی نقاشی‌شده با کمتر از نصف کدورت نادیده گرفته می‌شوند و نواحی نیمه‌رنگ‌شده سفید در نظر گرفته شده و پاک خواهند شد. ماسک باید حداقل دارای مقداری ناحیه سفید باشد؛ ماسک خالی باعث شکست درخواست می‌شود زیرا چیزی برای پاک‌کردن وجود ندارد.
