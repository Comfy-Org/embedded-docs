# پاک‌کن Bria

Bria Eraser با استفاده از Bria API اشیا یا نواحی را از یک تصویر حذف می‌کند. شما یک تصویر و یک ماسک ارائه می‌دهید که نواحی موردنظر برای حذف را مشخص می‌کند؛ گره هر دو را به Bria بارگذاری می‌کند، کار پاک‌سازی را اجرا می‌کند، منتظر تکمیل آن می‌ماند و تصویر ویرایش‌شده را با نواحی ماسک‌شده پاک‌شده برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی حاوی اشیا یا نواحی موردنظر برای حذف. | IMAGE | بله | - |
| `mask` | نواحی سفید پاک می‌شوند و نواحی سیاه حفظ می‌شوند. ماسک پیش از ارسال با آستانه ۵۰٪ دودویی می‌شود: فقط نواحی‌ای که با شفافیت بیش از ۵۰٪ رنگ‌آمیزی شده‌اند سفید در نظر گرفته می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `mask_type` | نوع منبع ماسک. "manual" برای ماسک‌های دست‌کشیده یا قلم‌مویی است؛ "automatic" برای ماسک‌های تولیدشده توسط مدل‌های بخش‌بندی مانند SAM است. | COMBO | بله | "manual"<br>"automatic" |
| `moderation` | تنظیمات بازبینی. برای فعال‌سازی بازبینی محتوای بصری روی تصویر ورودی و/یا خروجی، روی "true" تنظیم کنید. | DYNAMIC_COMBO | بله | "false"<br>"true" |

وقتی `moderation` روی "true" تنظیم شود، دو تنظیم بولی اضافی در دسترس قرار می‌گیرند:

- `visual_input_moderation` — بازبینی محتوای بصری را روی تصویر ورودی اعمال می‌کند (پیش‌فرض: false)
- `visual_output_moderation` — بازبینی محتوای بصری را روی تصویر خروجی اعمال می‌کند (پیش‌فرض: false)

توجه: ماسک باید با نسبت ابعاد تصویر مطابقت داشته باشد، در غیر این صورت درخواست شکست می‌خورد. ماسک پیش از ارسال به API به یک ماسک دودویی (سیاه و سفید) تبدیل می‌شود: نواحی‌ای که با شفافیت کمتر از نصف رنگ‌آمیزی شده‌اند نادیده گرفته می‌شوند و نواحی نیمه‌رنگ‌شده سفید در نظر گرفته می‌شوند و پاک خواهند شد. ماسک باید حداقل مقداری ناحیه سفید داشته باشد؛ ماسک خالی باعث شکست درخواست می‌شود، زیرا چیزی برای پاک کردن وجود ندارد.
