# BriaEraser

Bria Eraser با استفاده از API بریا، اشیاء یا نواحی را از یک تصویر حذف می‌کند. شما یک تصویر و یک ماسک که نواحی موردنظر برای حذف را مشخص می‌کند ارائه می‌دهید؛ گره هر دو را به بریا آپلود می‌کند، عملیات پاک‌سازی را اجرا می‌کند، منتظر تکمیل آن می‌ماند و تصویر ویرایش‌شده را با نواحی ماسک‌شده پاک‌شده برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی شامل اشیاء یا نواحی که باید حذف شوند. | IMAGE | بله | - |
| `mask` | نواحی سفید پاک می‌شوند و نواحی سیاه حفظ می‌شوند. ماسک قبل از ارسال دودویی (باینری) می‌شود، بنابراین نواحی که به‌طور جزئی رنگ‌آمیزی شده‌اند سفید محسوب می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `mask_type` | انتخاب می‌کند که ماسک چگونه ایجاد شده است. «manual» برای ماسک‌های دست‌کشیده یا قلم‌مویی است؛ «automatic» برای ماسک‌های تولیدشده توسط مدل‌های تقسیم‌بندی مانند SAM است. | COMBO | بله | "manual"<br>"automatic" |
| `moderation` | تنظیمات پالایش محتوا. مقدار «true» را برای فعال‌سازی پالایش محتوا روی تصاویر ورودی و/یا خروجی تنظیم کنید. | DYNAMIC_COMBO | بله | "false"<br>"true" |

توجه: وقتی `moderation` روی «true» تنظیم شود، دو تنظیم بولی اضافی در دسترس قرار می‌گیرند:

- `visual_input_moderation` — پالایش محتوای بصری را روی تصویر ورودی اعمال می‌کند (پیش‌فرض: false)
- `visual_output_moderation` — پالایش محتوای بصری را روی تصویر خروجی اعمال می‌کند (پیش‌فرض: false)

ماسک باید با نسبت ابعاد تصویر مطابقت داشته باشد، در غیر این صورت درخواست ناموفق خواهد بود. ماسک قبل از ارسال به API به یک ماسک دودویی (سیاه و سفید) تبدیل می‌شود، بنابراین نواحی که به‌طور جزئی رنگ‌آمیزی شده‌اند سفید در نظر گرفته شده و پاک می‌شوند.
