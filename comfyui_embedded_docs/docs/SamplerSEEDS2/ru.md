# SamplerSEEDS2

Этот узел предоставляет настраиваемый сэмплер для генерации изображений. Он основан на решателе стохастического дифференциального уравнения (SDE) и может работать как несколько конкретных сэмплеров в зависимости от настроек, включая `seeds_2`, `exp_heun_2_x0` и `exp_heun_2_x0_sde`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `solver_type` | Выбирает базовый алгоритм решателя для сэмплера. | COMBO | Да | "phi_1"<br>"phi_2" |
| `eta` | Сила стохастичности (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 100.0 |
| `s_noise` | Множитель шума SDE (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 100.0 |
| `r` | Относительный размер шага для промежуточного этапа (узел c2) (по умолчанию: 0.5). | FLOAT | Нет | 0.01 - 1.0 |

**Примечание:** В описании узла определены следующие пресеты сэмплера:
- `seeds_2`: настройки по умолчанию
- `exp_heun_2_x0`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 0.0
- `exp_heun_2_x0_sde`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 1.0, `s_noise` = 1.0

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, который можно передать другим узлам сэмплирования. | SAMPLER |
