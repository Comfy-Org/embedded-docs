# SamplerSEEDS2

Этот узел предоставляет настраиваемый сэмплер для генерации изображений. Он реализует алгоритм SEEDS-2, который является решателем стохастических дифференциальных уравнений (SDE). Регулируя параметры, вы можете настроить его для работы в качестве нескольких конкретных сэмплеров, включая `seeds_2`, `exp_heun_2_x0` и `exp_heun_2_x0_sde`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `solver_type` | Выбирает базовый алгоритм решателя для сэмплера. | COMBO | Да | `"phi_1"`<br>`"phi_2"` |
| `eta` | Стохастическая сила (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 100.0 |
| `s_noise` | Множитель шума SDE (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 100.0 |
| `r` | Относительный размер шага для промежуточной стадии (узел c2) (по умолчанию: 0.5). | FLOAT | Нет | 0.01 - 1.0 |

В зависимости от настроек параметров этот сэмплер может соответствовать:

- `seeds_2` — настройки по умолчанию
- `exp_heun_2_x0` — `solver_type`=`phi_2`, `r`=1.0, `eta`=0.0
- `exp_heun_2_x0_sde` — `solver_type`=`phi_2`, `r`=1.0, `eta`=1.0, `s_noise`=1.0

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, который можно передавать в другие узлы сэмплирования. | SAMPLER |
