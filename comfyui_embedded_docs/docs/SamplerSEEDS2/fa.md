# SamplerSEEDS2

این گره یک سمپلر قابل تنظیم برای تولید تصویر فراهم می‌کند. این گره الگوریتم SEEDS-2 را پیاده‌سازی می‌کند که یک حل‌کننده معادله دیفرانسیل تصادفی (SDE) است. با تنظیم پارامترهای آن، می‌توانید آن را طوری پیکربندی کنید که مانند چندین سمپلر خاص رفتار کند، از جمله `seeds_2`، `exp_heun_2_x0` و `exp_heun_2_x0_sde`.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `solver_type` | الگوریتم حل‌کننده اصلی سمپلر را انتخاب می‌کند. | COMBO | بله | "phi_1"<br>"phi_2" |
| `eta` | قدرت تصادفی (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 - 100.0 |
| `s_noise` | ضریب نویز SDE (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 - 100.0 |
| `r` | اندازه گام نسبی برای مرحله میانی (گره c2) (پیش‌فرض: 0.5). | FLOAT | خیر | 0.01 - 1.0 |

**توجه:** توضیحات گره، پیش‌تنظیم‌های زیر را برای سمپلر تعریف می‌کند:
- `seeds_2`: تنظیمات پیش‌فرض
- `exp_heun_2_x0`: `solver_type` = "phi_2"، `r` = 1.0، `eta` = 0.0
- `exp_heun_2_x0_sde`: `solver_type` = "phi_2"، `r` = 1.0، `eta` = 1.0، `s_noise` = 1.0
