# SamplerSEEDS2

توفّر هذه العقدة أداة أخذ عينات قابلة للتهيئة لتوليد الصور. وهي تستند إلى حلّال معادلة تفاضلية عشوائية (SDE) ويمكنها أن تعمل مثل عدة أدوات محددة لأخذ العينات حسب إعداداتها، بما في ذلك `seeds_2` و`exp_heun_2_x0` و`exp_heun_2_x0_sde`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `solver_type` | يحدد خوارزمية الحلّ الأساسية لأداة أخذ العينات. | COMBO | نعم | "phi_1"<br>"phi_2" |
| `eta` | شدة العشوائية (القيمة الافتراضية: 1.0). | FLOAT | لا | 0.0 - 100.0 |
| `s_noise` | مضاعف ضوضاء SDE (القيمة الافتراضية: 1.0). | FLOAT | لا | 0.0 - 100.0 |
| `r` | حجم الخطوة النسبي للمرحلة الوسيطة (عقدة c2) (القيمة الافتراضية: 0.5). | FLOAT | لا | 0.01 - 1.0 |

**ملاحظة:** يحدد وصف العقدة الإعدادات المسبقة التالية لأداة أخذ العينات:
- `seeds_2`: الإعدادات الافتراضية
- `exp_heun_2_x0`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 0.0
- `exp_heun_2_x0_sde`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 1.0, `s_noise` = 1.0
