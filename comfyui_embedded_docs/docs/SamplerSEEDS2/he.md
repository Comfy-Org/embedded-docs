# SamplerSEEDS2

צומת זה מספק דוגם (sampler) הניתן להגדרה ליצירת תמונות. הוא מבוסס על פותר משוואה דיפרנציאלית סטוכסטית (SDE) ויכול להתנהג כמו מספר דוגמים ספציפיים בהתאם להגדרותיו, כולל `seeds_2`, `exp_heun_2_x0`, ו-`exp_heun_2_x0_sde`.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `solver_type` | בוחר את אלגוריתם הפותר הבסיסי עבור הדוגם. | COMBO | כן | "phi_1"<br>"phi_2" |
| `eta` | עוצמה סטוכסטית (ברירת מחדל: 1.0). | FLOAT | לא | 0.0 - 100.0 |
| `s_noise` | מכפיל רעש SDE (ברירת מחדל: 1.0). | FLOAT | לא | 0.0 - 100.0 |
| `r` | גודל צעד יחסי עבור השלב הביניים (צומת c2) (ברירת מחדל: 0.5). | FLOAT | לא | 0.01 - 1.0 |

**הערה:** תיאור הצומת מגדיר את הפריסטים הבאים של הדוגם:
- `seeds_2`: הגדרות ברירת מחדל
- `exp_heun_2_x0`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 0.0
- `exp_heun_2_x0_sde`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 1.0, `s_noise` = 1.0
