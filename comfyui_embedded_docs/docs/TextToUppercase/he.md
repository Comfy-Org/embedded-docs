# המר טקסט לאותיות גדולות (לא בשימוש)

צומת Text to Uppercase מקבל קלט טקסט וממיר את כל התווים בו לאותיות רישיות. זהו כלי עיבוד טקסט פשוט המשנה את רישיות המחרוזת המסופקת.

**הערה:** צומת זה הוצא משימוש ומוחלף על ידי הצומת Convert Text Case.
