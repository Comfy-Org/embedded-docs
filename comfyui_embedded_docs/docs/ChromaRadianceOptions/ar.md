# خيارات ChromaRadiance

تتيح عقدة ChromaRadianceOptions تكوين إعدادات متقدمة لنموذج Chroma Radiance. وهي تُرفِق wrapper بنموذج موجود وتطبّق الخيارات المحددة أثناء عملية إزالة الضوضاء فقط عندما تقع قيمة sigma الحالية ضمن النطاق المضبوط، مما يتيح التحكم في حجم tile الخاص بـ NeRF ومعالجة معرّفات رموز النص.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج الذي ستُطبَّق عليه خيارات Chroma Radiance | MODEL | نعم | - |
| `preserve_wrapper` | عند التمكين، سيُفوَّض الأمر إلى wrapper دالة نموذج موجود إن وُجد. عمومًا ينبغي تركه مُمكَّنًا. (الافتراضي: True) | BOOLEAN | لا | - |
| `start_sigma` | أول قيمة sigma تكون عندها هذه الخيارات سارية المفعول. (الافتراضي: 1.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `end_sigma` | آخر قيمة sigma تكون عندها هذه الخيارات سارية المفعول. (الافتراضي: 0.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `nerf_tile_size` | يسمح بتجاوز حجم tile الافتراضي لـ NeRF. القيمة -1 تعني استخدام الافتراضي (32). القيمة 0 تعني استخدام وضع non-tiling (قد يتطلب قدرًا كبيرًا من VRAM). (الافتراضي: -1) | INT | لا | -1 وما فوق |
| `فرض استخدام معرفات نصية متسلسلة` | يفرض استخدام معرّفات رموز نصية تسلسلية بدلًا من الأصفار. ينبغي استخدامه مع نقاط التحقق (checkpoints) من 2026-05-22 إلى 2026-06-01 التي دُرّبت بهذه الطريقة لكنها لا تحتوي على المفتاح __sequential__ في state dict. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** لا تكون خيارات Chroma Radiance سارية المفعول إلا عندما تقع قيمة sigma الحالية بين `end_sigma` و`start_sigma` (شاملًا الطرفين). لا يُطبَّق خيار `nerf_tile_size` إلا عند ضبطه على 0 أو قيمة أعلى (القيمة -1 تستخدم حجم tile الافتراضي 32 ولا تخزّن أي تجاوز). لا يُطبَّق خيار `force_sequential_txt_ids` إلا عند ضبطه على True. عندما تكون `nerf_tile_size` مساوية لـ -1 و`force_sequential_txt_ids` مساوية لـ False، لا يتم تكوين أي خيارات ويُعاد النموذج دون تغيير دون تطبيق أي wrapper.

**ملاحظة:** جميع المدخلات بخلاف `model` هي خيارات متقدمة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model` | النموذج الذي طُبّقت عليه خيارات Chroma Radiance، أو النموذج دون تغيير إذا لم تكن أي خيارات نشطة | MODEL |
