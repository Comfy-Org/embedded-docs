# خيارات ChromaRadiance

عقدة **ChromaRadianceOptions** تسمح لك بإعداد خيارات متقدمة لنموذج Chroma Radiance. إنها تغلّف نموذجًا موجودًا وتطبّق خيارات محددة أثناء عملية إزالة الضوضاء بناءً على قيم سيغما، مما يتيح تحكمًا دقيقًا في حجم مربع NeRF والمعاملات الأخرى المتعلقة بالتوهج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج الذي سيتم تطبيق خيارات Chroma Radiance عليه | MODEL | نعم | - |
| `preserve_wrapper` | عند التمكين، سيتم التفويض إلى مغلّف دالة النموذج الموجود إذا كان موجودًا. يُنصح عمومًا بتركه ممكّنًا. (الافتراضي: True) | BOOLEAN | لا | - |
| `start_sigma` | أول قيمة سيغما التي ستكون فيها هذه الخيارات سارية المفعول. (الافتراضي: 1.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `end_sigma` | آخر قيمة سيغما التي ستكون فيها هذه الخيارات سارية المفعول. (الافتراضي: 0.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `nerf_tile_size` | يسمح بتجاوز حجم مربع NeRF الافتراضي. القيمة -1 تعني استخدام الافتراضي (32). القيمة 0 تعني استخدام الوضع غير المعبّأ (قد يتطلب الكثير من ذاكرة الفيديو VRAM). (الافتراضي: -1) | INT | لا | -1 فما فوق |
| `فرض استخدام معرفات نصية متسلسلة` | إجبار استخدام معرّفات النصوص التسلسلية بدلاً من الأصفار. يجب استخدامه لنقاط التحقق من الفترة 2026-05-22 إلى 2026-06-01 المدربة بهذه الطريقة ولكنها لا تحتوي على المفتاح `__sequential__` في قاموس الحالة. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** لا تصبح خيارات Chroma Radiance سارية المفعول إلا عندما تقع قيمة سيغما الحالية بين `end_sigma` و`start_sigma` (شاملًا). يتم تطبيق معامل `nerf_tile_size` فقط عند ضبطه على 0 أو قيمًا أعلى. يتم تطبيق معامل `force_sequential_txt_ids` فقط عند ضبطه على True. عندما يكون `nerf_tile_size` مساويًا لـ -1 و`force_sequential_txt_ids` مساويًا لـ False، لا يتم تكوين أي خيارات ويُعاد النموذج دون تغيير دون تطبيق أي مغلّف.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model` | النموذج مع تطبيق خيارات Chroma Radiance، أو النموذج دون تغيير إذا لم تكن هناك خيارات نشطة | MODEL |
