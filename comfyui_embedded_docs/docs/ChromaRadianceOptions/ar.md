# خيارات ChromaRadiance

```markdown
تتيح لك عقدة `ChromaRadianceOptions` ضبط الإعدادات المتقدمة لنموذج Chroma Radiance. وهي تغلّف نموذجًا موجودًا وتطبّق خيارات محددة أثناء عملية إزالة التشويش (denoising) استنادًا إلى قيم سيجما، مما يتيح تحكمًا دقيقًا في حجم بلاطات NeRF والمعلمات الأخرى المتعلقة بالإشعاعية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج الذي سيتم تطبيق خيارات Chroma Radiance عليه | MODEL | نعم | - |
| `preserve_wrapper` | عند التمكين، سيتم التفويض إلى غلاف دالة النموذج الموجود إذا كان موجودًا. يُنصح عمومًا بإبقائه مفعّلًا. (الافتراضي: True) | BOOLEAN | لا | - |
| `start_sigma` | أول قيمة سيجما تكون فيها هذه الخيارات سارية المفعول. (الافتراضي: 1.0) | FLOAT | لا | 0.0 to 1.0 |
| `end_sigma` | آخر قيمة سيجما تكون فيها هذه الخيارات سارية المفعول. (الافتراضي: 0.0) | FLOAT | لا | 0.0 to 1.0 |
| `nerf_tile_size` | يتيح تجاوز حجم بلاطة NeRF الافتراضي. القيمة -1 تعني استخدام الافتراضي (32)، والقيمة 0 تعني استخدام وضع عدم التقطيع (قد يتطلب الكثير من VRAM). (الافتراضي: -1) | INT | لا | -1 and above |
| `force_sequential_txt_ids` | فرض استخدام معرّفات نصية تسلسلية بدلاً من الأصفار. يجب استخدامه لنقاط التفتيش من 2026-05-22 إلى 2026-06-01 التي تم تدريبها بهذه الطريقة ولكنها لا تحتوي على مفتاح `__sequential__` في قاموس الحالة. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** تكون خيارات Chroma Radiance سارية المفعول فقط عندما تقع قيمة سيجما الحالية بين `end_sigma` و `start_sigma` (شاملًا الطرفين). يتم تطبيق معامل `nerf_tile_size` فقط عند تعيينه على 0 أو قيم أعلى. يتم تطبيق معامل `force_sequential_txt_ids` فقط عند تعيينه على True.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model` | النموذج المعدل مع تطبيق خيارات Chroma Radiance | MODEL |
```
