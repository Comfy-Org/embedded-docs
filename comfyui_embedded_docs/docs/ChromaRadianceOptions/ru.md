# ChromaRadianceOptions

Узел ChromaRadianceOptions позволяет настроить расширенные параметры для модели Chroma Radiance. Он присоединяет обёртку к существующей модели и применяет выбранные параметры во время процесса денойзинга только тогда, когда текущее значение sigma попадает в настроенный диапазон, что даёт контроль над размером тайла NeRF и обработкой ID текстовых токенов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, к которой нужно применить параметры Chroma Radiance | MODEL | Да | - |
| `сохранить_обёртку` | Если включено, будет делегировать существующей обёртке функции модели, если она существует. Обычно следует оставлять включённым. (по умолчанию: True) | BOOLEAN | Нет | - |
| `начальная_сигма` | Первое значение sigma, при котором эти параметры будут действовать. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 |
| `конечная_сигма` | Последнее значение sigma, при котором эти параметры будут действовать. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 до 1.0 |
| `размер_плитки_nerf` | Позволяет переопределить размер тайла NeRF по умолчанию. -1 означает использование значения по умолчанию (32). 0 означает использование режима без тайлинга (может потребовать много VRAM). (по умолчанию: -1) | INT | Нет | -1 и выше |
| `force_sequential_txt_ids` | Принудительно использовать последовательные ID текстовых токенов вместо нулей. Следует использовать для чекпоинтов с 2026-05-22 по 2026-06-01, которые обучены таким образом, но не содержат ключ __sequential__ в state dict. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Параметры Chroma Radiance вступают в силу только тогда, когда текущее значение sigma находится между `end_sigma` и `start_sigma` (включительно). Параметр `nerf_tile_size` применяется только при значении 0 или выше (значение -1 использует размер тайла по умолчанию 32 и не сохраняет переопределение). Параметр `force_sequential_txt_ids` применяется только при значении True. Когда `nerf_tile_size` равен -1, а `force_sequential_txt_ids` равен False, никакие параметры не настраиваются, и модель возвращается без изменений, без применения обёртки.

**Примечание:** Все входы, кроме `model`, являются расширенными параметрами.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Модель с применёнными параметрами Chroma Radiance или неизменённая модель, если ни один параметр не активен | MODEL |
