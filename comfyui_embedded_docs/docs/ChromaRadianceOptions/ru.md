# ChromaRadianceOptions

Узел **ChromaRadianceOptions** позволяет настраивать расширенные параметры для модели Chroma Radiance. Он оборачивает существующую модель и применяет определённые опции в процессе денойзинга на основе значений сигмы, обеспечивая точный контроль над размером тайла NeRF и другими параметрами, связанными с радианс-освещением.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|----------|----------|------------|-------------|----------|
| `model` | Модель, к которой применяются параметры Chroma Radiance | MODEL | Да | - |
| `preserve_wrapper` | Если включено, будет делегировать существующей обёртке функции модели, если она существует. Обычно должно оставаться включенным. (по умолчанию: True) | BOOLEAN | Нет | - |
| `start_sigma` | Первая сигма, при которой эти параметры будут действовать. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 to 1.0 |
| `end_sigma` | Последняя сигма, при которой эти параметры будут действовать. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 to 1.0 |
| `nerf_tile_size` | Позволяет переопределить стандартный размер тайла NeRF. -1 означает использование значения по умолчанию (32). 0 означает использование режима без тайлов (может потребовать много VRAM). (по умолчанию: -1) | INT | Нет | -1 and above |
| `force_sequential_txt_ids` | Принудительно использовать последовательные текстовые ID токенов вместо нулей. Следует использовать для чекпоинтов с 2026-05-22 по 2026-06-01, которые обучены таким образом, но не содержат ключ `__sequential__` в state dict. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Параметры Chroma Radiance действуют только когда текущее значение сигмы находится между `end_sigma` и `start_sigma` (включительно). Параметр `nerf_tile_size` применяется только если установлен в 0 или большее значение. Параметр `force_sequential_txt_ids` применяется только если установлен в True.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
