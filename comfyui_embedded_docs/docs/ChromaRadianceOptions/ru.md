# ChromaRadianceOptions

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, к которой применяются параметры Chroma Radiance | MODEL | Да | - |
| `сохранить_обёртку` | Если включено, будет передавать управление существующей обёртке функции модели, если она существует. Обычно должно оставаться включённым. (по умолчанию: True) | BOOLEAN | Нет | - |
| `начальная_сигма` | Первое значение сигмы, при котором эти параметры будут действовать. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 |
| `конечная_сигма` | Последнее значение сигмы, при котором эти параметры будут действовать. (по умолчанию: 0.0) | FLOAT | Нет | 0.0 до 1.0 |
| `размер_плитки_nerf` | Позволяет переопределить стандартный размер тайла NeRF. -1 означает использование значения по умолчанию (32). 0 означает режим без тайлов (может потребовать много видеопамяти). (по умолчанию: -1) | INT | Нет | -1 and above |
| `force_sequential_txt_ids` | Принудительно использовать последовательные ID текстовых токенов вместо нулей. Следует использовать для контрольных точек с 2026-05-22 по 2026-06-01, которые обучены таким образом, но не содержат ключа `__sequential__` в state dict. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Параметры Chroma Radiance действуют только когда текущее значение сигмы находится между `end_sigma` и `start_sigma` (включительно). Параметр `nerf_tile_size` применяется только при установке значения 0 или выше. Параметр `force_sequential_txt_ids` применяется только при установке значения True. Если `nerf_tile_size` равен -1 и `force_sequential_txt_ids` равен False, параметры не настраиваются, и модель возвращается без изменений без применения какой-либо обёртки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Модель с применёнными параметрами Chroma Radiance или неизменённая модель, если активные параметры отсутствуют | MODEL |
