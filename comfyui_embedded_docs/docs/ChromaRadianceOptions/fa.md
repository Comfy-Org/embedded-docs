# ChromaRadianceOptions

گره ChromaRadianceOptions به شما امکان می‌دهد تنظیمات پیشرفته را برای مدل Chroma Radiance پیکربندی کنید. این گره یک پوشاننده (wrapper) به مدل موجود متصل می‌کند و گزینه‌های انتخاب‌شده را در فرایند حذف نویز فقط زمانی اعمال می‌کند که مقدار sigma جاری در بازه پیکربندی‌شده قرار داشته باشد، و کنترل اندازه کاشی NeRF و مدیریت شناسه توکن متن را فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که گزینه‌های Chroma Radiance باید به آن اعمال شوند | MODEL | بله | - |
| `preserve_wrapper` | وقتی فعال باشد، در صورت وجود، به پوشاننده تابع مدل موجود واگذار می‌کند. عموماً باید فعال بماند. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `start_sigma` | نخستین sigma که این گزینه‌ها در آن اعمال می‌شوند. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 تا 1.0 |
| `end_sigma` | آخرین sigma که این گزینه‌ها در آن اعمال می‌شوند. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 تا 1.0 |
| `nerf_tile_size` | امکان بازنویسی اندازه کاشی پیش‌فرض NeRF را فراهم می‌کند. مقدار -1 یعنی استفاده از مقدار پیش‌فرض (32). مقدار 0 یعنی استفاده از حالت بدون کاشی‌بندی (ممکن است به VRAM زیادی نیاز داشته باشد). (پیش‌فرض: -1) | INT | خیر | -1 و بالاتر |
| `استفاده اجباری از شناسه‌های متنی ترتیبی` | استفاده از شناسه‌های توکن متن ترتیبی را به‌جای صفرها اجباری می‌کند. باید برای checkpoint‌های بازه 2026-05-22 تا 2026-06-01 استفاده شود که به این روش آموزش دیده‌اند اما کلید `__sequential__` را در state dict ندارند. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** گزینه‌های Chroma Radiance تنها زمانی اعمال می‌شوند که مقدار sigma جاری بین `end_sigma` و `start_sigma` (شامل هر دو) قرار گیرد. گزینه `nerf_tile_size` تنها زمانی اعمال می‌شود که روی 0 یا مقداری بالاتر تنظیم شده باشد (مقدار -1 از اندازه کاشی پیش‌فرض 32 استفاده می‌کند و هیچ بازنویسی‌ای ذخیره نمی‌کند). گزینه `force_sequential_txt_ids` تنها زمانی اعمال می‌شود که روی True تنظیم شده باشد. وقتی `nerf_tile_size` برابر -1 و `force_sequential_txt_ids` برابر False باشد، هیچ گزینه‌ای پیکربندی نمی‌شود و مدل بدون اعمال هیچ پوشاننده‌ای بدون تغییر بازگردانده می‌شود.

**توجه:** همه ورودی‌ها به‌جز `model` گزینه‌های پیشرفته هستند.
