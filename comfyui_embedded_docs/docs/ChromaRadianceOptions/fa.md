# ChromaRadianceOptions

نود ChromaRadianceOptions به شما امکان می‌دهد تنظیمات پیشرفته مدل Chroma Radiance را پیکربندی کنید. این نود یک مدل موجود را می‌پوشاند و گزینه‌های خاصی را در طول فرایند نویززدایی بر اساس مقادیر سیگما اعمال می‌کند و کنترل دقیقی بر اندازه تایل NeRF و سایر پارامترهای مرتبط با تابش فراهم می‌آورد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که گزینه‌های Chroma Radiance روی آن اعمال می‌شود | MODEL | بله | - |
| `preserve_wrapper` | هنگامی که فعال باشد، در صورت وجود wrapper تابع مدل، به آن واگذار می‌شود. به طور کلی بهتر است فعال باقی بماند. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `start_sigma` | اولین سیگمایی که این گزینه‌ها در آن فعال می‌شوند. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 to 1.0 |
| `end_sigma` | آخرین سیگمایی که این گزینه‌ها در آن فعال می‌شوند. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 to 1.0 |
| `nerf_tile_size` | اجازه می‌دهد اندازه تایل پیش‌فرض NeRF را بازنویسی کنید. مقدار 1- به معنای استفاده از مقدار پیش‌فرض (32) است. مقدار 0 به معنای استفاده از حالت غیرتایل‌بندی است (ممکن است به مقدار زیادی VRAM نیاز داشته باشد). (پیش‌فرض: 1-) | INT | خیر | -1 and above |
| `force_sequential_txt_ids` | استفاده از شناسه‌های توکن متنی ترتیبی را به جای صفرها اجباری می‌کند. باید برای checkpointهای بازه 2026-05-22 تا 2026-06-01 استفاده شود که به این روش آموزش دیده‌اند اما کلید __sequential__ را در state dict ندارند. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** گزینه‌های Chroma Radiance تنها زمانی اعمال می‌شوند که مقدار سیگمای فعلی بین `end_sigma` و `start_sigma` (شامل هر دو) باشد. پارامتر `nerf_tile_size` تنها زمانی اعمال می‌شود که روی 0 یا مقادیر بالاتر تنظیم شده باشد. پارامتر `force_sequential_txt_ids` تنها زمانی اعمال می‌شود که روی True تنظیم شده باشد.
