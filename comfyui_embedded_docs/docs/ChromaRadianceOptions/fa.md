# ChromaRadianceOptions

### معرفی

گره ChromaRadianceOptions به شما امکان می‌دهد تنظیمات پیشرفته‌ای را برای مدل Chroma Radiance پیکربندی کنید. این گره یک مدل موجود را می‌پوشاند و گزینه‌های خاصی را در طول فرآیند نویززدایی بر اساس مقادیر سیگما اعمال می‌کند و کنترل دقیقی بر اندازه tile در NeRF و سایر پارامترهای مرتبط با تابش فراهم می‌آورد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که گزینه‌های Chroma Radiance بر روی آن اعمال می‌شوند | MODEL | بله | - |
| `preserve_wrapper` | هنگامی که فعال باشد، در صورت وجود wrapper تابع مدل، به آن واگذار می‌کند. به طور کلی باید فعال بماند. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `start_sigma` | اولین سیگمایی که این گزینه‌ها در آن اثر دارند. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 تا 1.0 |
| `end_sigma` | آخرین سیگمایی که این گزینه‌ها در آن اثر دارند. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 تا 1.0 |
| `nerf_tile_size` | امکان بازنویسی اندازه پیش‌فرض tile در NeRF را فراهم می‌کند. مقدار -1 به معنای استفاده از پیش‌فرض (32) است. مقدار 0 به معنای استفاده از حالت غیر-tiling است (ممکن است به VRAM زیادی نیاز داشته باشد). (پیش‌فرض: -1) | INT | خیر | -1 and above |
| `استفاده اجباری از شناسه‌های متنی ترتیبی` | استفاده از شناسه‌های توکن متنی ترتیبی را به جای صفرها اجباری می‌کند. باید برای checkpointهای بازه 2026-05-22 تا 2026-06-01 که به این روش آموزش دیده‌اند اما کلید __sequential__ را در state dict ندارند، استفاده شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**نکته:** گزینه‌های Chroma Radiance تنها زمانی اثر می‌کنند که مقدار سیگمای فعلی بین `end_sigma` و `start_sigma` (شامل خود این مقادیر) قرار داشته باشد. پارامتر `nerf_tile_size` فقط زمانی اعمال می‌شود که روی 0 یا مقادیر بالاتر تنظیم شده باشد. پارامتر `force_sequential_txt_ids` فقط زمانی اعمال می‌شود که روی True تنظیم شده باشد. زمانی که `nerf_tile_size` برابر -1 و `force_sequential_txt_ids` برابر False باشد، هیچ گزینه‌ای پیکربندی نمی‌شود و مدل بدون هیچ wrapper ای بدون تغییر بازگردانده می‌شود.
