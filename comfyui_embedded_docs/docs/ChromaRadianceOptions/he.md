# ChromaRadianceOptions

הצומת ChromaRadianceOptions מאפשר לך להגדיר אפשרויות מתקדמות עבור מודל Chroma Radiance. הוא מצרף עטיפה למודל קיים ומחיל את האפשרויות שנבחרו במהלך תהליך הפחתת הרעש רק כאשר ערך הסיגמה הנוכחי נמצא בטווח המוגדר, ובכך מספק שליטה על גודל אריח NeRF ועל הטיפול במזהי אסימוני טקסט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל שעליו להחיל את אפשרויות Chroma Radiance | MODEL | כן | - |
| `preserve_wrapper` | כשמופעל, יאציל למעטפת פונקציית מודל קיימת אם היא קיימת. בדרך כלל יש להשאיר מופעל. (ברירת מחדל: True) | BOOLEAN | לא | - |
| `start_sigma` | הסיגמה הראשונה שבה אפשרויות אלו יהיו בתוקף. (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 to 1.0 |
| `end_sigma` | הסיגמה האחרונה שבה אפשרויות אלו יהיו בתוקף. (ברירת מחדל: 0.0) | FLOAT | לא | 0.0 to 1.0 |
| `nerf_tile_size` | מאפשר לדרוס את גודל אריח ה-NeRF המוגדר כברירת מחדל. -1 פירושו להשתמש בברירת המחדל (32). 0 פירושו להשתמש במצב ללא אריחים (עשוי לדרוש הרבה VRAM). (ברירת מחדל: -1) | INT | לא | -1 and above |
| `force_sequential_txt_ids` | אילוץ שימוש במזהי אסימוני טקסט עוקבים במקום אפסים. יש להשתמש בכך עבור צ'קפוינטים מתאריך 2026-05-22 עד 2026-06-01 שאומנו בדרך זו אך אינם מכילים את המפתח `__sequential__` ב-state dict. (ברירת מחדל: False) | BOOLEAN | לא | - |

**הערה:** אפשרויות Chroma Radiance נכנסות לתוקף רק כאשר ערך הסיגמה הנוכחי נמצא בין `end_sigma` ל-`start_sigma` (כולל). אפשרות `nerf_tile_size` מוחלת רק כאשר היא מוגדרת ל-0 או לערך גבוה יותר (ערך -1 משתמש בגודל האריח המוגדר כברירת מחדל של 32 ואינו שומר דריסה). אפשרות `force_sequential_txt_ids` מוחלת רק כאשר היא מוגדרת ל-True. כאשר `nerf_tile_size` הוא -1 ו-`force_sequential_txt_ids` הוא False, לא מוגדרות אפשרויות והמודל מוחזר ללא שינוי וללא החלת עטיפה.

**הערה:** כל הקלטים מלבד `model` הם אפשרויות מתקדמות.
