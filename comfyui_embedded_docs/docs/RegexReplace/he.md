# החלפת טקסט (Regex)

צומת RegexReplace מאתר ומחליף טקסט במחרוזות באמצעות תבניות של ביטויים רגולריים. הוא מאפשר לחפש תבניות טקסט ולהחליף אותן בטקסט חדש, עם אפשרויות לשלוט באופן התאמת התבנית, כולל רגישות לאותיות רישיות/קטנות, התאמה מרובת שורות והגבלת מספר ההחלפות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת הטקסט המקורית שבתוכה יש לחפש ולהחליף | STRING | כן | - |
| `regex_pattern` | תבנית הביטוי הרגולרי לחיפוש במחרוזת הקלט | STRING | כן | - |
| `replace` | טקסט ההחלפה שישמש במקום התבניות המתאימות | STRING | כן | - |
| `case_insensitive` | כאשר מופעל, גורם להתאמת התבנית להתעלם מהבדלים בין אותיות רישיות לקטנות (ברירת מחדל: True) | BOOLEAN | לא | - |
| `multiline` | כאשר מופעל, משנה את ההתנהגות של `^` ו-`$` כך שיתאימו לתחילת/סוף כל שורה, ולא רק לתחילת/סוף המחרוזת כולה (ברירת מחדל: False) | BOOLEAN | לא | - |
| `dotall` | כאשר מופעל, התו נקודה (.) יתאים לכל תו, כולל תווי שורה חדשה. כאשר מושבת, נקודות לא יתאימו לתווי שורה חדשה (ברירת מחדל: False) | BOOLEAN | לא | - |
| `count` | מספר ההחלפות המקסימלי לביצוע. יש להגדיר ל-0 כדי להחליף את כל המופעים (ברירת מחדל). יש להגדיר ל-1 כדי להחליף רק את ההתאמה הראשונה, 2 לשנייה הראשונות, וכן הלאה. (ברירת מחדל: 0) | INT | לא | 0-100 |
