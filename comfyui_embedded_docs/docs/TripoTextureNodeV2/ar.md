# TripoTextureNodeV2

تضيف هذه العقدة خامات إلى نموذج ثلاثي الأبعاد موجود من سير عمل Tripo، يُحدد بواسطة معرّف مهمة من خطوة توليد سابقة. يمكنها إنتاج خرائط مواد PBR أو خامة بلون بسيط، ويمكن توجيه النتيجة بواسطة موجه نصي، أو صورة نمط، أو صور مرجعية.

<Note>
يحتفظ Tripo بسجلات المهام على خوادمه لمدة 7 أيام (اعتبارًا من 1 ديسمبر 2026). لم يعد بالإمكان حل معرّف مهمة أقدم من ذلك، لذا تفشل إعادة تشغيل سير عمل محفوظ بعد هذه المدة عند هذه العقدة. للمتابعة، شغّل عقدة Tripo السابقة مرة أخرى لإنشاء معرّف مهمة جديد، أو أعد استيراد النموذج الذي نزّلته بالفعل باستخدام **Tripo: استيراد نموذج**.
</Note>

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف المهمة للنموذج المصدر الناتج عن عقدة Tripo سابقة (توليد النموذج أو تجزئة النموذج). | MODEL_TASK_ID / SEGMENT_TASK_ID | نعم | - |
| `pbr` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، normal)؛ عند إيقافه يعطي خامة بلون بسيط. (الافتراضي: true) | BOOLEAN | لا | true<br>false |
| `texture_seed` | البذرة المستخدمة لتوليد الخامات. (الافتراضي: 42) إدخال متقدم. | INT | لا | 0 إلى 2147483647 |
| `texture_quality` | جودة الخامات المولّدة. `detailed` = خامات HD، `extreme` = خامات 8K فائقة. (الافتراضي: "standard") إدخال متقدم. | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | كيفية محاذاة الخامات مع النموذج. (الافتراضي: "original_image") إدخال متقدم. | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري لتطبيق الخامات. مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model)، التي لا تحمل صورة مصدر لاستنتاج الألوان منها. لا يمكن دمجه مع الصور المرجعية. (الافتراضي: فارغ) | STRING | لا | - |
| `model_version` | نموذج الخامات: v3.0 للشبكات المولّدة باستخدام v3.x، وv2.5 للشبكات المولّدة باستخدام v2.5. (الافتراضي: v3_0_20250812) | COMBO | لا | إصدارات نموذج الخامات Tripo، الافتراضي "v3_0_20250812" |
| `style_image` | صورة مرجعية للنمط الفني للخامات. تُستخدم فقط مع `texture_prompt`. | IMAGE | لا | - |
| `reference` | صور مرجعية توجّه الخامات. لا يمكن دمجها مع `texture_prompt` أو `style_image`. (الافتراضي: "none") | DYNAMIC_COMBO | لا | "none"<br>"image"<br>"multiview" |
| `part_names` | أسماء الأجزاء مفصولة بفواصل من Tripo: Segment Model لتطبيق الخامات عليها. القيمة الفارغة تطبق الخامات على كل جزء. (الافتراضي: فارغ) إدخال متقدم. | STRING | لا | - |

### المدخلات المرجعية للصورة

تظهر عندما يتم تعيين `reference` إلى "image".

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | صورة مرجعية واحدة ينبغي أن تتبعها الخامات. | IMAGE | نعم | - |

### المدخلات المرجعية متعددة الزوايا

تظهر عندما يتم تعيين `reference` إلى "multiview".

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_front` | المنظر الأمامي (0°). | IMAGE | نعم | - |
| `image_left` | المنظر الأيسر (90°). | IMAGE | نعم | - |
| `image_back` | المنظر الخلفي (180°). | IMAGE | نعم | - |
| `image_right` | المنظر الأيمن (270°). | IMAGE | نعم | - |

**ملاحظات حول قيود المعاملات:**

- لا يمكن دمج الصور المرجعية (أوضاع المرجع "image" أو "multiview") مع `texture_prompt` أو `style_image`.
- يتطلب `style_image` توفير `texture_prompt`.
- عندما لا يتم تقديم `texture_prompt`، يجب أن يأتي النموذج المصدر من مهمة نص إلى نموذج، أو صورة إلى نموذج، أو متعدد الزوايا إلى نموذج، أو نموذج خامات. النماذج التي لا تحتوي على صورة مصدر (النماذج المستوردة، أو المجزأة، أو المكتملة، أو المعاد بناؤها طوبولوجيًا) تتطلب `texture_prompt`، لأن Tripo لا يقبل الصور المرجعية إلا للنماذج التي ولّدها بنفسه.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model task_id` | معرّف المهمة لعملية الخامات، والذي يمكن تمريره إلى عُقد Tripo أخرى. | MODEL_TASK_ID |
| `GLB` | نموذج مكسو بالخامات بصيغة GLB. يكون فارغًا عندما يكون المصدر شبكة رباعية أو استيراد FBX. | FILE_3D_GLB |
| `FBX` | نموذج مكسو بالخامات بصيغة FBX. يُرجع Tripo صيغة FBX للشبكات الرباعية واستيرادات FBX؛ ويكون فارغًا خلاف ذلك. | FILE_3D_FBX |
