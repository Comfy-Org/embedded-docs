# TripoTextureNodeV2

Этот узел добавляет текстуры к существующей 3D-модели из рабочего процесса Tripo, идентифицируемой по ID задачи из предыдущего шага генерации. Он может создавать PBR-карты материалов или простую цветную текстуру, а результат можно направлять с помощью текстовой подсказки, изображения стиля или эталонных изображений.

<Note>
Tripo хранит записи о задачах на своих серверах 7 дней (с 1 декабря 2026 г.). ID задачи, созданный раньше этого срока, больше не разрешается, поэтому повторный запуск сохранённого рабочего процесса после этого срока завершается ошибкой на этом узле. Чтобы продолжить, запустите предыдущий узел Tripo ещё раз, чтобы создать новый ID задачи, или повторно импортируйте уже загруженную модель с помощью **Tripo: Импорт модели**.
</Note>

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи исходной модели, созданной более ранним узлом Tripo (генерация модели или сегментация модели). | MODEL_TASK_ID / SEGMENT_TASK_ID | Да | - |
| `pbr` | PBR-карты материалов (основной цвет, металличность, шероховатость, нормали); при выключении создаётся простая цветная текстура. (по умолчанию: true) | BOOLEAN | Нет | true<br>false |
| `texture_seed` | Сид, используемый для генерации текстуры. (по умолчанию: 42) Дополнительный вход. | INT | Нет | 0–2147483647 |
| `texture_quality` | Качество генерируемых текстур. `detailed` = HD-текстуры, `extreme` = 8K Ultra-текстуры. (по умолчанию: "standard") Дополнительный вход. | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Как текстуры выравниваются относительно модели. (по умолчанию: "original_image") Дополнительный вход. | COMBO | Нет | "original_image"<br>"geometry" |
| `texture_prompt` | Необязательная текстовая подсказка для текстурирования. На практике обязательна для импортированных моделей (Tripo: Import Model), в которых нет исходного изображения, по которому можно определить цвета. Нельзя комбинировать с эталонными изображениями. (по умолчанию: пусто) | STRING | Нет | - |
| `model_version` | Модель текстурирования: v3.0 для сеток, созданных с помощью v3.x; v2.5 для сеток, созданных с помощью v2.5. (по умолчанию: v3_0_20250812) | COMBO | Нет | Версии модели текстурирования Tripo, по умолчанию "v3_0_20250812" |
| `style_image` | Эталонное изображение для художественного стиля текстур. Используется только вместе с `texture_prompt`. | IMAGE | Нет | - |
| `reference` | Эталонные изображения, направляющие текстурирование. Нельзя комбинировать с `texture_prompt` или `style_image`. (по умолчанию: "none") | DYNAMIC_COMBO | Нет | "none"<br>"image"<br>"multiview" |
| `part_names` | Разделённые запятыми имена частей из Tripo: Segment Model, которые нужно текстурировать. Пустое значение — текстурировать каждую часть. (по умолчанию: пусто) Дополнительный вход. | STRING | Нет | - |

### Эталонные входы изображения

Отображается, когда `reference` имеет значение "image".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | Одно эталонное изображение, которому должны соответствовать текстуры. | IMAGE | Да | - |

### Эталонные входы многовидовых изображений

Отображается, когда `reference` имеет значение "multiview".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_front` | Вид спереди (0°). | IMAGE | Да | - |
| `image_left` | Вид слева (90°). | IMAGE | Да | - |
| `image_back` | Вид сзади (180°). | IMAGE | Да | - |
| `image_right` | Вид справа (270°). | IMAGE | Да | - |

**Примечания по ограничениям параметров:**

- Эталонные изображения (режимы `reference` "image" или "multiview") нельзя комбинировать с `texture_prompt` или `style_image`.
- Для `style_image` требуется указать `texture_prompt`.
- Если `texture_prompt` не указан, исходная модель должна быть получена в результате задачи text-to-model, image-to-model, multiview-to-model или texture-model. Модели без исходного изображения (импортированные, сегментированные, завершённые или ретопологизированные модели) требуют `texture_prompt`, поскольку Tripo принимает эталонные изображения только для моделей, которые он сгенерировал сам.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи операции текстурирования, который можно передать другим узлам Tripo. | MODEL_TASK_ID |
| `GLB` | Текстурированная модель в формате GLB. Пусто, если источник — quad-сетка или импорт FBX. | FILE_3D_GLB |
| `FBX` | Текстурированная модель в формате FBX. Tripo возвращает FBX для quad-сеток и импортов FBX; в остальных случаях пусто. | FILE_3D_FBX |
