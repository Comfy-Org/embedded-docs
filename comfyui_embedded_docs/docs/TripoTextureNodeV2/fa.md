# TripoTextureNodeV2

این گره به یک مدل سه‌بعدی موجود از یک گردش‌کار Tripo، که با شناسه وظیفه (task ID) از مرحله تولید قبلی مشخص می‌شود، بافت اضافه می‌کند. می‌تواند نقشه‌های متریال PBR یا یک بافت رنگی ساده تولید کند، و نتیجه می‌تواند با یک راهنمای متنی، یک تصویر سبک، یا تصاویر مرجع هدایت شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | اجباری | بازه |
|-----------|-------------|-----------|----------|-------|
| `شناسهٔ وظیفهٔ مدل` | شناسه وظیفه مدل مبدأ که توسط یک گره Tripo قبلی (تولید مدل یا بخش‌بندی مدل) تولید شده است. | MODEL_TASK_ID / SEGMENT_TASK_ID | بله | - |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، فلزی، زبری، نرمال)؛ خاموش بودن آن یک بافت رنگی ساده می‌دهد. (پیش‌فرض: true) | BOOLEAN | خیر | true<br>false |
| `بذر بافت` | بذر مورد استفاده برای تولید بافت. (پیش‌فرض: 42) ورودی پیشرفته. | INT | خیر | 0 تا 2147483647 |
| `texture_quality` | کیفیت بافت‌های تولیدشده. `detailed` = بافت‌های HD، `extreme` = بافت‌های 8K Ultra. (پیش‌فرض: "standard") ورودی پیشرفته. | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | نحوه تراز شدن بافت‌ها با مدل. (پیش‌فرض: "original_image") ورودی پیشرفته. | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های واردشده (Tripo: Import Model) الزامی است، زیرا تصویر مبدأیی برای استنتاج رنگ‌ها ندارند. نمی‌توان آن را با تصاویر مرجع ترکیب کرد. (پیش‌فرض: خالی) | STRING | خیر | - |
| `model_version` | مدل بافت‌دهی: v3.0 برای مش‌های تولیدشده با v3.x، v2.5 برای مش‌های تولیدشده با v2.5. (پیش‌فرض: v3_0_20250812) | COMBO | خیر | نسخه‌های مدل بافت‌دهی Tripo، پیش‌فرض "v3_0_20250812" |
| `style_image` | تصویر مرجع برای سبک هنری بافت‌ها. فقط همراه با `texture_prompt` استفاده می‌شود. | IMAGE | خیر | - |
| `reference` | تصاویر مرجعی که بافت‌ها را هدایت می‌کنند. نمی‌توان آن را با `texture_prompt` یا `style_image` ترکیب کرد. (پیش‌فرض: "none") | DYNAMIC_COMBO | خیر | "none"<br>"image"<br>"multiview" |
| `part_names` | نام بخش‌های جداشده با کاما از Tripo: Segment Model برای بافت‌دهی. خالی بودن آن همه بخش‌ها را بافت‌دهی می‌کند. (پیش‌فرض: خالی) ورودی پیشرفته. | STRING | خیر | - |

### ورودی‌های مرجع تصویر

نمایش داده می‌شود وقتی `reference` روی "image" تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | اجباری | بازه |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | تصویر مرجع تکی که بافت‌ها باید از آن پیروی کنند. | IMAGE | بله | - |

### ورودی‌های مرجع چندنمایی

نمایش داده می‌شود وقتی `reference` روی "multiview" تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | اجباری | بازه |
|-----------|-------------|-----------|----------|-------|
| `image_front` | نمای جلو (0°). | IMAGE | بله | - |
| `image_left` | نمای چپ (90°). | IMAGE | بله | - |
| `image_back` | نمای پشت (180°). | IMAGE | بله | - |
| `image_right` | نمای راست (270°). | IMAGE | بله | - |

**نکاتی درباره محدودیت‌های پارامترها:**

- تصاویر مرجع (حالت‌های مرجع "image" یا "multiview") را نمی‌توان با `texture_prompt` یا `style_image` ترکیب کرد.
- `style_image` نیازمند ارائه یک `texture_prompt` است.
- وقتی هیچ `texture_prompt` داده نشود، مدل مبدأ باید از یک وظیفه متن‌به‌مدل، تصویر‌به‌مدل، چندنمایی‌به‌مدل، یا بافت‌دهی مدل آمده باشد. مدل‌های بدون تصویر مبدأ (واردشده، بخش‌بندی‌شده، تکمیل‌شده، یا ریتوپولوژی‌شده) به یک `texture_prompt` نیاز دارند، چون Tripo تصاویر مرجع را فقط برای مدل‌هایی می‌پذیرد که خودش تولید کرده است.
