# モデルサンプリングSD3

このノードは、Stable Diffusion 3 スタイルのサンプリング設定をモデルに適用します。モデルのコピーを作成し、そのサンプリング方式をフローベースのサンプリング構成に置き換えます。この構成では、指定された `shift` 値が使用され、サンプリング分布の形状を制御します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | SD3 サンプリングパラメータを適用する入力モデル | MODEL | はい | - |
| `シフト` | サンプリングのシフトパラメータを制御します（デフォルト: 3.0） | FLOAT | はい | 0.0 - 100.0（ステップ: 0.01） |

注: `shift` 値は、固定の内部乗数 1000 とともに適用されます。元のモデルにノイズスケール設定がある場合、その値は変更後のモデルに引き継がれます。元のモデルは変更されず、複製およびパッチ適用されたコピーが返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | SD3 サンプリングパラメータが適用された変更後のモデル | MODEL |
