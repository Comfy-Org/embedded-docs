# Выборка модели SD3

Узел ModelSamplingSD3 применяет параметры сэмплирования Stable Diffusion 3 к модели. Он изменяет поведение сэмплирования модели, регулируя параметр shift, который управляет характеристиками распределения сэмплирования. Узел создает модифицированную копию входной модели с примененной указанной конфигурацией сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Входная модель, к которой применяются параметры сэмплирования SD3 | MODEL | Да | - |
| `сдвиг` | Управляет параметром сдвига (shift) сэмплирования (по умолчанию: 3.0) | FLOAT | Да | 0.0 - 100.0 (шаг: 0.01) |

Примечание: Узел применяет значение `shift` с фиксированным внутренним множителем 1000. Если исходная модель имеет настройку масштаба шума, она сохраняется в модифицированной модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененными параметрами сэмплирования SD3 | MODEL |
