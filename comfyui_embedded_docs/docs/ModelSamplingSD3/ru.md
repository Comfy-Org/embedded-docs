# Выборка модели SD3

Узел ModelSamplingSD3 применяет параметры семплирования Stable Diffusion 3 к модели. Он изменяет поведение семплирования модели, регулируя параметр `shift`, который управляет характеристиками распределения при семплировании. Узел создает модифицированную копию входной модели с применённой указанной конфигурацией семплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Входная модель, к которой применяются параметры семплирования SD3 | MODEL | Да | - |
| `shift` | Управляет параметром сдвига семплирования (по умолчанию: 3.0) | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применёнными параметрами семплирования SD3 | MODEL |
