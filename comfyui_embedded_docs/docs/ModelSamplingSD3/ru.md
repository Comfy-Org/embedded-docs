# Выборка модели SD3

Этот узел применяет к модели настройки сэмплирования в стиле Stable Diffusion 3. Он создаёт копию модели и заменяет её метод сэмплирования на конфигурацию сэмплирования на основе потоков, использующую заданное значение `shift`, которое управляет формой распределения сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Входная модель, к которой применяются параметры сэмплирования SD3 | MODEL | Да | - |
| `сдвиг` | Управляет параметром сдвига сэмплирования (по умолчанию: 3.0) | FLOAT | Да | 0.0 - 100.0 (шаг: 0.01) |

Примечание: Значение `shift` применяется вместе с фиксированным внутренним множителем 1000. Если исходная модель имеет настройку масштаба шума, это значение переносится в изменённую модель. Исходная модель не изменяется; возвращается клонированная и пропатченная копия.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Изменённая модель с применёнными параметрами сэмплирования SD3 | MODEL |
