# VEED Clean Audio (in Video)

Удалите фоновый шум из речи в видео с помощью VEED. Меняется только звуковая дорожка: она заменяется очищенной монофонической речью с частотой дискретизации 48 кГц, тогда как изображение, разрешение и частота кадров остаются прежними. Инструмент предназначен для речи на любом языке; музыка и звуковые эффекты удаляются, а не сохраняются.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Видео со звуковой дорожкой речи длительностью менее 30 минут. Видео должно иметь аудиодорожку. | VIDEO | Да | До 1799 секунд |
| `strength` | Степень удаления шума в речевом сигнале. Меньшие значения сохраняют больше естественного фона помещения за голосом; паузы между словами всегда очищаются полностью, а значения выше значения по умолчанию мало что меняют. (по умолчанию: 0.874) | FLOAT | Да | от 0.0 до 1.0 (шаг 0.001) |
| `loudness` | Нормализовать ли громкость речи. `"normalize"` устанавливает её равной `target_lufs`; `"keep input level"` оставляет уровень без изменений. При выборе опции отображаются её параметры. (по умолчанию: `"normalize"`) | DYNAMIC_COMBO | Да | `"normalize"`<br>`"keep input level"` |
| `target_lufs` | Интегральная громкость очищенной речи в LUFS. Пиковые значения ограничиваются на уровне -1.1 dBTP, поэтому при высоких целевых значениях громкости нормализация останавливается раньше (около -15 LUFS для типичной речи). Доступно, когда `loudness` имеет значение `"normalize"` (по умолчанию: -19.0). | FLOAT | Да | от -40.0 до -8.0 (шаг 0.1) |

Узел завершает работу с ошибкой, если клип длиннее 1799 секунд или если в видео отсутствует аудиодорожка.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `VIDEO` | Входное видео, звуковая дорожка которого заменена очищенной речью. | VIDEO |
