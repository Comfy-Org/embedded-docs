# ByteDance Seedance 2.0: референс в видео

Этот узел генерирует, редактирует или расширяет видео с помощью ИИ-моделей Seedance 2.5 или 2.0 от ByteDance. Вы описываете видео в текстовом запросе и можете добавлять референсные изображения, видео и аудио для управления результатом. Он поддерживает мультимодальные референсные входы, редактирование видео и расширение видео.

## Входные параметры

Выбор `model` определяет, какие из параметров ниже доступны. `video_editing` и `output_format` появляются только при выборе Seedance 2.5.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | ИИ-модель, используемая для генерации видео. Seedance 2.5 — самая новая модель с видео до 30 секунд и выводом в mp4/mov; Seedance 2.0 — для максимального качества и разрешений 1080p/4k; Fast — для оптимизации скорости; Mini — для самой быстрой и недорогой генерации. Выбор модели отображает указанные ниже параметры, специфичные для модели. | COMBO | Да | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | Сид управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | 0–2147483647 |
| `watermark` | Добавлять ли водяной знак к видео (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |
| `prompt` | Текстовый запрос для генерации видео. Для Seedance 2.5 заключайте реплики в двойные кавычки, чтобы управлять генерируемым диалогом. Должен содержать хотя бы один непробельный символ. | STRING | Да | Любой текст |
| `resolution` | Разрешение выходного видео. Seedance 2.5, 2.0 Fast и 2.0 Mini предлагают 480p и 720p; Seedance 2.0 также предлагает 1080p и 4k (для Seedance 2.5 по умолчанию: 720p). | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"4k"` |
| `ratio` | Соотношение сторон выходного видео (для Seedance 2.5 по умолчанию: `"16:9"`; для моделей Seedance 2.0 по умолчанию: `"adaptive"`). | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах (Seedance 2.5: 4–30, по умолчанию 5; модели Seedance 2.0: 4–15, по умолчанию 7). | INT | Да | 4–30 (Seedance 2.5)<br>4–15 (Seedance 2.0)<br>Шаг: 1 |
| `generate_audio` | Включить генерацию аудио для выходного видео (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `video_editing` | Только для Seedance 2.5. Включайте, когда запрос редактирует подключенное референсное видео, например заменяет в нем объект. В этом случае выходные данные сохраняют собственную длину и соотношение сторон исходного клипа, а виджеты длительности и соотношения сторон игнорируются. Оставьте выключенным, чтобы сгенерировать новое видео или расширить существующее до заданной длительности (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |
| `output_format` | Только для Seedance 2.5. Контейнерный формат выходного видео (по умолчанию: `"mp4"`). | COMBO | Да | `"mp4"` |
| `reference_images` | Референсные изображения, которые направляют генерацию видео. Изображения автоматически уменьшаются до максимальной стороны 6000 пикселей и должны быть не менее 300x300 пикселей с соотношением сторон от 0,4 до 2,5. | IMAGE | Нет | до 30 (Seedance 2.5)<br>до 9 (Seedance 2.0) |
| `reference_videos` | Референсные видео, которые направляют генерацию видео; используются для редактирования и расширения видео. | VIDEO | Нет | до 10 (Seedance 2.5)<br>до 3 (Seedance 2.0) |
| `reference_audios` | Референсные аудиоклипы, которые направляют генерацию видео. | AUDIO | Нет | до 10 (Seedance 2.5)<br>до 3 (Seedance 2.0) |
| `auto_downscale` | Автоматически уменьшать референсные видео, которые превышают бюджет пикселей модели для выбранного разрешения. Соотношение сторон сохраняется; видео, уже находящиеся в пределах лимитов, не изменяются (по умолчанию: True). | BOOLEAN | Нет | `True`<br>`False` |
| `auto_upscale` | Автоматически увеличивать референсные видео, которые ниже минимального количества пикселей модели для выбранного разрешения. Соотношение сторон сохраняется; видео, уже соответствующие минимуму, не изменяются. Примечание: увеличение низкоразрешенного источника не добавляет реальных деталей и может привести к генерациям более низкого качества (по умолчанию: False). | BOOLEAN | Нет | `True`<br>`False` |
| `reference_assets` | Идентификаторы ранее созданных ресурсов виртуальной библиотеки Seedance (Image, Video или Audio) для использования в качестве референсов. Каждый ресурс должен существовать и иметь статус Active. В запросе на ресурсы можно ссылаться как asset1, asset 2 и т. д.; узел заменяет эти токены на метки, такие как Image 2. | STRING | Нет | до 30 (Seedance 2.5)<br>до 9 (Seedance 2.0) |

**Важные ограничения:**

* Требуется как минимум один референс. Для Seedance 2.0, 2.0 Fast и 2.0 Mini необходимо указать хотя бы одно изображение или видео в качестве референса (через `reference_images`, `reference_videos` или запись изображения/видео в `reference_assets`). Seedance 2.5 дополнительно принимает аудио-референсы.
* Максимальное количество референсов зависит от модели: Seedance 2.5 допускает до 30 `reference_images`, 10 `reference_videos`, 10 `reference_audios` и 30 `reference_assets`; модели Seedance 2.0 допускают до 9 изображений, 3 видео, 3 аудиоклипов и 9 ресурсов. Общее количество подсчитывается по сумме прямых входов и референсов из ресурсов и проверяется перед генерацией.
* Каждое референсное видео должно быть не короче 1,8 секунды, и каждый референсный аудиоклип также должен быть не короче 1,8 секунды. Суммарная длительность всех референсных видео и всех референсных аудио должна оставаться в пределах лимита выбранной модели (15,1 секунды для моделей Seedance 2.0).
* Референсные видео также должны соответствовать лимитам по количеству пикселей модели для выбранного разрешения. При включенном `auto_downscale` (по умолчанию) видео, превышающие лимит, автоматически изменяют размер; при включенном `auto_upscale` видео, не достигающие лимита, увеличиваются. Если любая из автоматических настроек отключена, видео, выходящие за соответствующий лимит, вызывают ошибку.
* Когда `video_editing` включен на Seedance 2.5, входы `duration` и `ratio` игнорируются; выходные данные соответствуют собственной длине и соотношению сторон референсного видео.
