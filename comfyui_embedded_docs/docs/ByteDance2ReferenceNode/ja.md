# ByteDance Seedance 2.0 リファレンスから動画生成

このノードは、ByteDance の Seedance 2.5 または 2.0 AI モデルを使用して、動画の生成、編集、または延長を行います。テキストプロンプトで動画を記述し、参照画像、動画、音声を追加して結果を導くことができます。マルチモーダルな参照入力、動画編集、動画延長をサポートしています。

## 入力

`model` を選択すると、以下のパラメータのうちどれが使用可能になるかが決まります。`video_editing` と `output_format` は、Seedance 2.5 が選択された場合にのみ表示されます。

**重要な制約事項:**

* 少なくとも1つの参照が必要です。Seedance 2.0、2.0 Fast、2.0 Mini では、画像または動画の参照を少なくとも1つ提供する必要があります（`reference_images`、`reference_videos`、または画像/動画の `reference_assets` エントリを介して）。Seedance 2.5 では、音声のみの参照も追加で受け付けます。
* 参照数はモデルによって異なります。Seedance 2.5 では、`reference_images` は最大30、`reference_videos` は最大10、`reference_audios` は最大10、`reference_assets` は最大30まで許可されます。Seedance 2.0 モデルでは、画像9、動画3、音声クリップ3、アセット9まで許可されます。合計は直接入力とアセット参照を合わせてカウントされ、生成前に検証されます。
* 各参照動画は少なくとも1.8秒の長さが必要で、各参照音声クリップも少なくとも1.8秒の長さが必要です。すべての参照動画とすべての参照音声の合計時間は、選択したモデルの制限内に収まる必要があります（Seedance 2.0 モデルでは15.1秒）。
* 参照動画は、選択した解像度のモデルのピクセル数制限も満たす必要があります。`auto_downscale` が有効（デフォルト）の場合、大きすぎる動画は自動的にサイズ変更されます。`auto_upscale` が有効な場合、小さすぎる動画は拡大されます。いずれかの自動調整が無効な場合、対応する制限を超えた動画はエラーを発生させます。
* Seedance 2.5 で `video_editing` が有効な場合、`duration` と `ratio` の入力は無視され、出力は参照動画自体の長さとアスペクト比に一致します。
