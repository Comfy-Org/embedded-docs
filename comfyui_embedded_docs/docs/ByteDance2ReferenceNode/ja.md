# ByteDance Seedance 2.0 リファレンスから動画生成

このノードは、ByteDance の Seedance 2.5 または 2.0 AI モデルを使用して、動画の生成、編集、拡張を行います。テキストプロンプトで動画を説明し、参照画像、動画、音声を追加して結果を導くことができます。マルチモーダル参照入力、動画編集、動画拡張に対応しています。

## 入力

`model` を選択すると、以下のパラメータのうちどれが使用可能になるかが決まります。`video_editing` と `output_format` は、Seedance 2.5 が選択された場合にのみ表示されます。拡張可能な参照スロットと参照動画の自動リサイズオプションは、すべてのモデルで共通であり、「参照入力」のセクションで説明します。

### 参照入力

すべてのモデルで使用できます。スロットの最大数は選択したモデルによって異なります。Seedance 2.5 は Seedance 2.0 モデルよりも多くの参照をサポートします。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能なスロット: 動画生成をガイドする1つ以上の参照画像（`image_1`、`image_2`、...）を接続します。画像は最大辺6000ピクセルに自動ダウンスケールされ、300x300 ピクセル以上、アスペクト比 0.4〜2.5 の間である必要があります。 | IMAGE | いいえ | 最大 30（Seedance 2.5）<br>最大 9（Seedance 2.0 モデル） |
| `reference_videos` | 拡張可能なスロット: 動画生成をガイドする1つ以上の参照動画（`video_1`、`video_2`、...）を接続します。動画の編集と拡張に使用されます。 | VIDEO | いいえ | 最大 10（Seedance 2.5）<br>最大 3（Seedance 2.0 モデル） |
| `reference_audios` | 拡張可能なスロット: 動画生成をガイドする1つ以上の参照音声クリップ（`audio_1`、`audio_2`、...）を接続します。 | AUDIO | いいえ | 最大 10（Seedance 2.5）<br>最大 3（Seedance 2.0 モデル） |
| `auto_downscale` | 選択した解像度におけるモデルのピクセル数の上限を超える参照動画を自動的にダウンスケールします。アスペクト比は維持されます。制限内の動画は変更されません（デフォルト: True）。 | BOOLEAN | いいえ | `True`<br>`False` |
| `auto_upscale` | 選択した解像度におけるモデルの最小ピクセル数を下回る参照動画を自動的にアップスケールします。アスペクト比は維持されます。最小値を満たす動画は変更されません。注: 低解像度のソースをアップスケールしても実際のディテールは追加されず、生成品質が低下する可能性があります（デフォルト: False）。 | BOOLEAN | いいえ | `True`<br>`False` |
| `reference_assets` | 拡張可能なスロット: 参照として使用する、以前作成した Seedance 仮想ライブラリのアセット（Image、Video、または Audio）の ID（`asset_1`、`asset_2`、...）を接続します。各アセットは存在し、Active ステータスである必要があります。プロンプト内では、アセットを `asset1`、`asset 1` などとして参照できます。ノードはこれらのトークンを「Image 2」のようなラベルに置き換えます。 | STRING | いいえ | 最大 30（Seedance 2.5）<br>最大 9（Seedance 2.0 モデル） |

**重要な制約事項：**

* 参照は少なくとも1つ必要です。Seedance 2.0、2.0 Fast、2.0 Mini では、`reference_images`、`reference_videos`、または `reference_assets` 内の画像または動画エントリを介して、少なくとも1つの画像または動画の参照を提供する必要があります。Seedance 2.5 では、さらに音声のみの参照（`reference_audios` または `reference_assets` の音声エントリを介して）も受け付けます。
* 参照数はモデルに依存し、直接入力とアセット参照を合わせて検証されます：Seedance 2.5 では、`reference_images` は最大30、`reference_videos` は最大10、`reference_audios` は最大10、`reference_assets` は最大30まで許可されます。Seedance 2.0 モデルでは、画像最大9、動画最大3、音声クリップ最大3、アセット最大9まで許可されます。
* 各参照動画は少なくとも1.8秒、各参照音声クリップは少なくとも1.8秒の長さが必要です。すべての参照動画の合計時間とすべての参照音声の合計時間は、選択したモデルの制限内に収まる必要があります（Seedance 2.0 モデルの場合は15.1秒）。
* 参照動画は、選択した解像度に対するモデルのピクセル数制限も満たす必要があります。`auto_downscale` が有効（デフォルト）の場合、過大な動画は自動的にリサイズされます。`auto_upscale` が有効な場合、過小な動画は拡大されます。いずれかの自動調整が無効な場合、対応する制限を超える動画はエラーになります。
* Seedance 2.5 で `video_editing` が有効な場合、`duration` と `ratio` の入力は無視されます。出力は参照動画自体の長さとアスペクト比に一致します。プロバイダーがプロンプトを参照動画の編集として解釈した場合、`video_editing` を有効にするか、新しい動画を説明するようにプロンプトを言い換えない限り、生成は失敗します。
* プロバイダーが動画用に生成された音声トラックを拒否した場合（例えば、著作権侵害の可能性がある場合）、タスクは失敗します。`generate_audio` を無効にすると、音声なしの動画が生成されます。
