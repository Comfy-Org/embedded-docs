# ByteDance Seedance 2.0 레퍼런스에서 비디오 생성

이 노드는 ByteDance의 Seedance 2.5 또는 2.0 AI 모델을 사용하여 비디오를 생성, 편집 또는 확장합니다. 텍스트 프롬프트로 비디오를 설명하고 결과를 안내하기 위해 참조 이미지, 비디오 및 오디오를 추가할 수 있습니다. 멀티모달 참조 입력, 비디오 편집 및 비디오 확장을 지원합니다.

## 입력

`model`을 선택하면 아래 매개변수 중 사용 가능한 항목이 결정됩니다. `video_editing` 및 `output_format`은 Seedance 2.5를 선택한 경우에만 나타납니다. 확장 가능한 참조 슬롯과 참조 비디오 자동 크기 조정 옵션은 모든 모델에서 공유되며 참조 입력 섹션에서 설명합니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용되는 AI 모델입니다. 최신 모델인 Seedance 2.5는 최대 30초 비디오와 mp4 출력을 지원하며, Seedance 2.0은 최고 품질과 1080p/4k를 지원합니다. Fast는 속도 최적화용, Mini는 가장 빠르고 저렴한 생성용입니다. 모델을 선택하면 아래에 나열된 모델별 입력이 표시됩니다. | COMBO | 예 | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다(기본값: False). | BOOLEAN | 예 | `True`<br>`False` |

### Seedance 2.5 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 생성된 대화를 유도하려면 말하는 대사를 큰따옴표로 묶으십시오. 공백이 아닌 문자가 하나 이상 있어야 합니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: `"720p"`). | COMBO | 예 | `"480p"`<br>`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: `"16:9"`). | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 4 ~ 30<br>간격: 1 |
| `generate_audio` | 출력 비디오에 대한 오디오 생성을 활성화합니다(기본값: True). | BOOLEAN | 예 | `True`<br>`False` |
| `video_editing` | 연결된 참조 비디오를 프롬프트가 편집하는 경우(예: 비디오 속 객체를 교체) 활성화합니다. 출력은 소스 클립의 자체 길이와 화면 비율을 유지하며, `duration` 및 `ratio` 위젯은 무시됩니다. 새 비디오를 생성하거나 설정한 `duration`으로 비디오를 확장하려면 비활성화된 상태로 두십시오(기본값: False). | BOOLEAN | 예 | `True`<br>`False` |
| `output_format` | 출력 비디오의 컨테이너 형식입니다(기본값: `"mp4"`). | COMBO | 예 | `"mp4"` |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

Seedance 2.0 Fast와 Seedance 2.0 Mini가 공유합니다. 이 두 모델은 `resolution`이 480p와 720p로 제한된다는 점을 제외하고 Seedance 2.0과 동일한 입력 세트를 제공합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 공백이 아닌 문자가 하나 이상 있어야 합니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br>`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: `"adaptive"`). | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 7). | INT | 예 | 4 ~ 15<br>간격: 1 |
| `generate_audio` | 출력 비디오에 대한 오디오 생성을 활성화합니다(기본값: True). | BOOLEAN | 예 | `True`<br>`False` |

### 참조 입력

모든 모델에서 사용할 수 있습니다. 최대 슬롯 수는 선택한 모델에 따라 다릅니다. Seedance 2.5는 Seedance 2.0 모델보다 더 많은 참조를 지원합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 비디오 생성을 안내하는 하나 이상의 참조 이미지(`image_1`, `image_2`, ...)를 연결합니다. 이미지는 최대 6000픽셀의 긴 변으로 자동 축소되며, 최소 300x300픽셀이어야 하고 화면 비율은 0.4에서 2.5 사이여야 합니다. | IMAGE | 아니오 | 최대 30개 (Seedance 2.5)<br>최대 9개 (Seedance 2.0 모델) |
| `reference_videos` | 확장 가능한 슬롯: 비디오 생성을 안내하는 하나 이상의 참조 비디오(`video_1`, `video_2`, ...)를 연결합니다. 비디오 편집 및 확장에 사용됩니다. | VIDEO | 아니오 | 최대 10개 (Seedance 2.5)<br>최대 3개 (Seedance 2.0 모델) |
| `reference_audios` | 확장 가능한 슬롯: 비디오 생성을 안내하는 하나 이상의 참조 오디오 클립(`audio_1`, `audio_2`, ...)을 연결합니다. | AUDIO | 아니오 | 최대 10개 (Seedance 2.5)<br>최대 3개 (Seedance 2.0 모델) |
| `auto_downscale` | 선택한 해상도에 대해 모델의 픽셀 예산을 초과하는 참조 비디오를 자동으로 축소합니다. 화면 비율은 유지되며 이미 한도 내에 있는 비디오는 변경되지 않습니다(기본값: True). | BOOLEAN | 아니오 | `True`<br>`False` |
| `auto_upscale` | 선택한 해상도에 대해 모델의 최소 픽셀 수보다 낮은 참조 비디오를 자동으로 확대합니다. 화면 비율은 유지되며 최소 기준을 이미 충족하는 비디오는 변경되지 않습니다. 참고: 저해상도 소스를 확대해도 실제 디테일이 추가되지 않으며 품질이 낮은 생성 결과가 나올 수 있습니다(기본값: False). | BOOLEAN | 아니오 | `True`<br>`False` |
| `reference_assets` | 확장 가능한 슬롯: 참조로 사용할 이전에 생성된 Seedance 가상 라이브러리 자산(Image, Video 또는 Audio)의 ID입니다(`asset_1`, `asset_2`, ...). 각 자산은 존재해야 하며 Active 상태여야 합니다. 프롬프트에서 자산은 `asset1`, `asset 1` 등으로 참조할 수 있으며, 노드는 이러한 토큰을 "Image 2"와 같은 라벨로 대체합니다. | STRING | 아니오 | 최대 30개 (Seedance 2.5)<br>최대 9개 (Seedance 2.0 모델) |

**중요한 제약 사항:**

* 최소 하나의 참조가 필요합니다. Seedance 2.0, 2.0 Fast 및 2.0 Mini의 경우 이미지 또는 비디오 참조를 하나 이상 제공해야 합니다(`reference_images`, `reference_videos` 또는 `reference_assets`의 이미지/비디오 항목을 통해). Seedance 2.5는 오디오 전용 참조(`reference_audios` 또는 `reference_assets`의 오디오 항목을 통해)도 추가로 허용합니다.
* 참조 수는 모델에 따라 다르며 직접 입력과 자산 참조를 합쳐 검증됩니다. Seedance 2.5는 최대 30개의 `reference_images`, 10개의 `reference_videos`, 10개의 `reference_audios`, 30개의 `reference_assets`를 허용하며, Seedance 2.0 모델은 최대 9개의 이미지, 3개의 비디오, 3개의 오디오 클립, 9개의 자산을 허용합니다.
* 각 참조 비디오의 길이는 최소 1.8초 이상이어야 하며, 각 참조 오디오 클립도 최소 1.8초 이상이어야 합니다. 모든 참조 비디오와 모든 참조 오디오의 총 길이는 선택한 모델의 한도(Seedance 2.0 모델의 경우 15.1초)를 초과할 수 없습니다.
* 참조 비디오는 선택한 해상도에 대한 모델의 픽셀 수 한도도 충족해야 합니다. `auto_downscale`이 활성화되어 있으면(기본값) 초과 크기 비디오가 자동으로 크기 조정되고, `auto_upscale`이 활성화되어 있으면 미달 크기 비디오가 확대됩니다. 자동 조정 중 하나라도 비활성화되면 해당 한도를 벗어난 비디오는 오류를 발생시킵니다.
* Seedance 2.5에서 `video_editing`이 활성화되면 `duration` 및 `ratio` 입력은 무시되며 출력은 참조 비디오의 자체 길이와 화면 비율을 따릅니다. 제공자가 프롬프트를 참조 비디오를 편집하는 것으로 해석하는 경우 `video_editing`을 활성화하거나 새 비디오를 설명하도록 프롬프트를 바꾸지 않으면 생성이 실패합니다.
* 제공자가 비디오용으로 생성된 오디오 트랙을 거부하면(예: 저작권 일치 가능성) 작업이 실패합니다. `generate_audio`를 비활성화하면 무성 비디오가 생성됩니다.
