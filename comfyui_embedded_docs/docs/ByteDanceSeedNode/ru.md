# ByteDance Seed

Генерируйте текстовые ответы с помощью моделей Seed 2.0 от ByteDance. Укажите текстовый запрос и при необходимости подключите изображения или видео, чтобы дать модели дополнительный контекст. Модель выбирается из доступных вариантов Seed 2.0, а узел возвращает текстовый ответ модели.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый ввод для модели. (по умолчанию: "") | STRING | Да | N/A |
| `model` | Модель Seed, используемая для генерации ответа. Этот селектор также отображает подпараметры модели. | DYNAMIC_COMBO | Да | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `seed` | Параметр `seed` управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от значения `seed`. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет | N/A |

### Входы модели (общие для Seed 2.0 Pro, Seed 2.0 Lite и Seed 2.0 Mini)

Все три модели Seed предоставляют одни и те же подпараметры при выборе.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `temperature` | Управляет степенью случайности. 0.0 — детерминированный результат, более высокие значения — более случайные. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 2.0 (шаг: 0.01) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательное изображение(я) для использования в качестве контекста модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов, например `image_1` … `image_20`. | IMAGE | Нет | от 0 до 20 изображений |
| `videos` | Необязательное видео(а) для использования в качестве контекста модели. До 4 видео. Расширяемый слот: подключите от 1 до 4 элементов, например `video_1` … `video_4`. | VIDEO | Нет | от 0 до 4 видео |

**Примечание.** Параметр `model` — это динамический комбинированный список, который показывает подпараметры эталонных входов и температуры после выбора модели. Слоты `images` и `videos` являются расширяемыми, поэтому можно подключить несколько входов для мультимодального контекста.

- `prompt` обязателен и должен содержать хотя бы один непробельный символ; иначе возникает ошибка.
- На один запрос поддерживается не более 20 изображений. Этот лимит учитывает все изображения во всех подключённых пакетах.
- На один запрос поддерживается не более 4 видео.
- Ошибка возникает, если модель возвращает пустой ответ или отказывается отвечать (текст отказа сообщается).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ модели Seed. | STRING |
