# ByteDance Seed

```markdown
ByteDance Seed генерирует текстовые ответы с использованием моделей Seed 2.0 от ByteDance. Укажите текстовый запрос и при необходимости добавьте одно или несколько изображений или видео для мультимодального контекста.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Seed, используемая для генерации ответа. | DYNAMIC_COMBO | Да | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `prompt` | Текстовый запрос к модели. (по умолчанию: "") | STRING | Да | N/A |
| `seed` | Seed управляет тем, должен ли узел выполниться повторно; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | 0 to 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет | N/A |

### Входные параметры Seed 2.0 Pro, Seed 2.0 Lite и Seed 2.0 Mini

Этот параметр является общим для всех трёх вариантов моделей.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `temperature` | Управляет степенью случайности. 0.0 — детерминированный результат, более высокие значения увеличивают случайность. (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 2.0 |

### Референсные входные параметры

Селектор `model` предоставляет эти расширяемые слоты, которые подключают изображения и видео, чтобы дать модели мультимодальный контекст.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные изображения для использования в качестве контекста для модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов (например, `image_1`...`image_20`). | IMAGE | Нет | `image_1` to `image_20` |
| `videos` | Необязательные видео для использования в качестве контекста для модели. До 4 видео. Расширяемый слот: подключите от 1 до 4 элементов (например, `video_1`...`video_4`). | VIDEO | Нет | `video_1` to `video_4` |

**Примечание:** Селектор `model` определяет, какая модель Seed используется для генерации ответа. Каждый вариант соответствует конкретному идентификатору модели: `"Seed 2.0 Pro"` → `seed-2-0-pro-260328`, `"Seed 2.0 Lite"` → `seed-2-0-lite-260228`, а `"Seed 2.0 Mini"` → `seed-2-0-mini-260215`.

**Примечание об ограничениях:** Запрос поддерживает максимум 20 изображений и 4 видео. Поле `prompt` должно быть непустой строкой.

**Примечание о ценообразовании:** Ценообразование основано на токенах и отображается в интерфейсе узла как приблизительный диапазон за 1 тыс. токенов: Seed 2.0 Mini: $0.00025-$0.0009; Seed 2.0 Lite: $0.0003-$0.002; Seed 2.0 Pro: $0.0005-$0.003.

## Выходные параметры

| Имя выходного параметра | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Seed. | STRING |
```
