# ByteDance Seed

Generate текстовые ответы с помощью моделей Seed 2.0 от ByteDance. Укажите текстовый запрос и при необходимости добавьте изображения или видео для мультимодального контекста.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Seed, используемая для генерации ответа. | DYNAMIC_COMBO | Да | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `prompt` | Текстовый ввод в модель. (по умолчанию: "") | STRING | Да | N/A |
| `seed` | `seed` управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет | N/A |

### Входы модели (общие для Seed 2.0 Pro, Seed 2.0 Lite и Seed 2.0 Mini)

Все три модели Seed предоставляют одинаковые вложенные параметры при выборе.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `temperature` | Управляет случайностью. 0.0 — детерминированное значение, более высокие значения увеличивают случайность. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 2.0 (step: 0.01) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательное изображение(я) для использования в качестве контекста модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов, например, с `image_1` по `image_20`. | IMAGE | Нет | от 0 до 20 изображений |
| `videos` | Необязательное видео для использования в качестве контекста модели. До 4 видео. Расширяемый слот: подключите от 1 до 4 элементов, например, с `video_1` по `video_4`. | VIDEO | Нет | от 0 до 4 видео |

**Примечание:** Параметр `model` является динамическим комбинированным параметром, который при выборе модели открывает вложенные параметры reference и temperature. Вы можете подключить входы изображений и видео к этому параметру, чтобы обеспечить мультимодальный контекст. Максимально поддерживается 20 изображений и 4 видео на один запрос, а параметр `prompt` обязателен и должен содержать хотя бы один непробельный символ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ модели Seed. | STRING |
