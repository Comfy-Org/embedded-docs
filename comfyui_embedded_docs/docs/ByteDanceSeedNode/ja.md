# ByteDance Seed

ByteDance Seed は、ByteDance の Seed 2.0 モデルを使用してテキスト応答を生成します。テキストプロンプトを指定し、オプションでマルチモーダルコンテキストとして1つ以上の画像または動画を含めることができます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用される Seed モデル。 | DYNAMIC_COMBO | はい | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `prompt` | モデルへのテキスト入力。（デフォルト: ""） | STRING | はい | N/A |
| `seed` | シードは、ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。（デフォルト: 0） | INT | はい | 0 to 2147483647 |
| `system_prompt` | モデルの動作を決定する基本指示。（デフォルト: ""） | STRING | いいえ | N/A |

### Seed 2.0 Pro、Seed 2.0 Lite、Seed 2.0 Mini の入力

この設定は、3つのモデルオプションすべてで共通です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | ランダム性を制御します。0.0 は決定的で、値が大きいほどランダム性が高くなります。（デフォルト: 1.0） | FLOAT | はい | 0.0 to 2.0 |

### 参照入力

`model` セレクターは、画像と動画を接続してモデルにマルチモーダルコンテキストを提供する、これらの拡張可能スロットを提供します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | モデルのコンテキストとして使用するオプションの画像。最大20枚。拡張可能スロット: 1〜20個の項目を接続します（例: `image_1`...`image_20`）。 | IMAGE | いいえ | `image_1` to `image_20` |
| `videos` | モデルのコンテキストとして使用するオプションの動画。最大4本。拡張可能スロット: 1〜4個の項目を接続します（例: `video_1`...`video_4`）。 | VIDEO | いいえ | `video_1` to `video_4` |

**注記:** `model` セレクターは、応答の生成に使用する Seed モデルを決定します。各オプションは特定のモデル ID に対応します: `"Seed 2.0 Pro"` → `seed-2-0-pro-260328`、`"Seed 2.0 Lite"` → `seed-2-0-lite-260228`、`"Seed 2.0 Mini"` → `seed-2-0-mini-260215`。

**制約に関する注記:** リクエストごとに最大20枚の画像と4本の動画がサポートされます。`prompt` は空でない文字列である必要があります。

**料金に関する注記:** 料金はトークン単位で計算され、ノード UI に1Kトークンあたりの概算範囲として表示されます: Seed 2.0 Mini: $0.00025-$0.0009; Seed 2.0 Lite: $0.0003-$0.002; Seed 2.0 Pro: $0.0005-$0.003。
