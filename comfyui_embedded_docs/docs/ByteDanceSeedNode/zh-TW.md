# ByteDance Seed

使用 ByteDance 的 Seed 2.0 模型產生文字回應。提供文字提示，並可選擇連接圖片或影片，為模型提供額外上下文。模型會從可用的 Seed 2.0 變體中選擇，節點會傳回模型的文字回答。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 輸入至模型的文字。（預設值：""） | STRING | 是 | N/A |
| `模型` | 用於產生回應的 Seed 模型。此選擇器也會顯示該模型的子參數。 | DYNAMIC_COMBO | 是 | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `隨機種子` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果都是非確定性的。（預設值：0） | INT | 是 | 0 至 2147483647 |
| `系統提示` | 決定模型行為的基礎指示。（預設值：""） | STRING | 否 | N/A |

### 模型輸入（Seed 2.0 Pro、Seed 2.0 Lite 與 Seed 2.0 Mini 共用）

三個 Seed 模型在選取後都會顯示相同的子參數。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 控制隨機性。0.0 為確定性，數值越高越隨機。（預設值：1.0） | FLOAT | 是 | 0.0 至 2.0 （步進值：0.01） |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可選的圖片，用作模型的上下文。最多 20 張圖片。可擴充槽位：連接 1..20 個項目，例如 `image_1` 到 `image_20`。 | IMAGE | 否 | 0 至 20 images |
| `videos` | 可選的影片，用作模型的上下文。最多 4 段影片。可擴充槽位：連接 1..4 個項目，例如 `video_1` 到 `video_4`。 | VIDEO | 否 | 0 至 4 videos |

**注意：** `model` 參數是動態組合，選取模型後會顯示參考與 `temperature` 子參數。`images` 與 `videos` 槽位可擴充，因此你可以連接多個輸入以提供多模態上下文。

- `prompt` 為必填，且必須包含至少一個非空白字元；否則會引發錯誤。
- 每次請求最多支援 20 張圖片。此限制會計入所有已連接批次中的圖片。
- 每次請求最多支援 4 段影片。
- 若模型傳回空回應，或模型拒絕回應（會回報拒絕文字），則會引發錯誤。
