# ByteDance Seed

使用 ByteDance 的 Seed 2.0 模型生成文字回應。提供文字提示，並可選擇性地包含圖片或影片以提供多模態上下文。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於生成回應的 Seed 模型。 | DYNAMIC_COMBO | 是 | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `提示詞` | 提供給模型的文字輸入。（預設值：""） | STRING | 是 | N/A |
| `隨機種子` | Seed 控制節點是否應重新執行；無論 seed 為何，結果都是非確定性的。（預設值：0） | INT | 是 | 0 至 2147483647 |
| `系統提示` | 規範模型行為的基礎指令。（預設值：""） | STRING | 否 | N/A |

### 模型輸入（由 Seed 2.0 Pro、Seed 2.0 Lite 和 Seed 2.0 Mini 共享）

選取時，所有三個 Seed 模型都會顯示相同的子參數。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 控制隨機性。0.0 為確定性，數值越高越隨機。（預設值：1.0） | FLOAT | 是 | 0.0 至 2.0 (step: 0.01) |

### 參考輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可選的圖片，作為模型的上下文。最多 20 張圖片。可擴充插槽：可連接 1 到 20 個項目，例如 `image_1` 到 `image_20`。 | IMAGE | 否 | 0 至 20 images |
| `videos` | 可選的影片，作為模型的上下文。最多 4 個影片。可擴充插槽：可連接 1 到 4 個項目，例如 `video_1` 到 `video_4`。 | VIDEO | 否 | 0 至 4 videos |

**注意：** `model` 參數是動態組合，當選取模型時會顯示 reference 和 temperature 子參數。您可以將圖片和影片輸入連接到此參數以提供多模態上下文。每個請求最多支援 20 張圖片和 4 個影片，且 `prompt` 為必填，必須包含至少一個非空白字元。
