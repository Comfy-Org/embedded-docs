# 字节跳动 Seed

ByteDance Seed 使用 ByteDance 的 Seed 2.0 模型生成文本响应。提供文本提示，并可选择包含一个或多个图像或视频作为多模态上下文。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成响应的 Seed 模型。 | DYNAMIC_COMBO | 是 | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `prompt` | 输入给模型的文本。(默认: "") | STRING | 是 | 不适用 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。(默认: 0) | INT | 是 | 0 到 2147483647 |
| `system_prompt` | 决定模型行为的基础指令。(默认: "") | STRING | 否 | 不适用 |

### Seed 2.0 Pro、Seed 2.0 Lite 和 Seed 2.0 Mini 输入

所有三个模型选项共享此设置。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 控制随机性。0.0 为确定性，值越大越随机。(默认: 1.0) | FLOAT | 是 | 0.0 到 2.0 |

### 参考输入

`model` 选择器提供这些可增长槽位，用于连接图像和视频，为模型提供多模态上下文。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可选的图像，用作模型的上下文。最多 20 张图像。可增长槽位：连接 1..20 个项目（例如 `image_1`...`image_20`）。 | IMAGE | 否 | `image_1` 到 `image_20` |
| `videos` | 可选的视频，用作模型的上下文。最多 4 个视频。可增长槽位：连接 1..4 个项目（例如 `video_1`...`video_4`）。 | VIDEO | 否 | `video_1` 到 `video_4` |

**注意：** `model` 选择器决定用于生成响应的 Seed 模型。每个选项对应一个特定的模型 ID：`"Seed 2.0 Pro"` → `seed-2-0-pro-260328`、`"Seed 2.0 Lite"` → `seed-2-0-lite-260228` 以及 `"Seed 2.0 Mini"` → `seed-2-0-mini-260215`。

**关于限制的说明：** 每个请求最多支持 20 张图像和 4 个视频。`prompt` 必须是非空字符串。

**关于定价的说明：** 定价基于 token，并在节点 UI 中显示为每 1K token 的近似范围：Seed 2.0 Mini：$0.00025-$0.0009；Seed 2.0 Lite：$0.0003-$0.002；Seed 2.0 Pro：$0.0005-$0.003。

|-------------|-------------|-----------|
