# ByteDance Seed

ByteDance Seed는 ByteDance의 Seed 2.0 모델을 사용하여 텍스트 응답을 생성합니다. 텍스트 프롬프트를 제공하고, 멀티모달 컨텍스트를 위해 하나 이상의 이미지 또는 비디오를 선택적으로 포함할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 응답을 생성하는 데 사용되는 Seed 모델입니다. | DYNAMIC_COMBO | 예 | `"Seed 2.0 Pro"`<br>`"Seed 2.0 Lite"`<br>`"Seed 2.0 Mini"` |
| `prompt` | 모델에 입력할 텍스트입니다. (기본값: "") | STRING | 예 | N/A |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 예 | 0 to 2147483647 |
| `system_prompt` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 | N/A |

### Seed 2.0 Pro, Seed 2.0 Lite 및 Seed 2.0 Mini 입력

이 설정은 세 가지 모델 옵션 모두에 공통으로 적용됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 값이 높을수록 더 무작위적입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 2.0 |

### 참조 입력

`model` 선택기에서 제공하는 확장 가능한 슬롯으로, 이미지와 비디오를 연결하여 모델에 멀티모달 컨텍스트를 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 모델의 컨텍스트로 사용할 선택적 이미지입니다. 최대 20개의 이미지를 사용할 수 있습니다. 확장 가능한 슬롯: 1~20개 항목을 연결합니다(예: `image_1`...`image_20`). | IMAGE | 아니요 | `image_1` to `image_20` |
| `videos` | 모델의 컨텍스트로 사용할 선택적 비디오입니다. 최대 4개의 비디오를 사용할 수 있습니다. 확장 가능한 슬롯: 1~4개 항목을 연결합니다(예: `video_1`...`video_4`). | VIDEO | 아니요 | `video_1` to `video_4` |

**참고:** `model` 선택기는 응답을 생성하는 데 사용할 Seed 모델을 결정합니다. 각 옵션은 특정 모델 ID에 매핑됩니다: `"Seed 2.0 Pro"` → `seed-2-0-pro-260328`, `"Seed 2.0 Lite"` → `seed-2-0-lite-260228`, `"Seed 2.0 Mini"` → `seed-2-0-mini-260215`.

**제약 조건 참고:** 요청당 최대 20개의 이미지와 4개의 비디오를 지원합니다. `prompt`는 비어 있지 않은 문자열이어야 합니다.

**가격 책정 참고:** 가격은 토큰 기준이며 노드 UI에 1K 토큰당 대략적인 범위로 표시됩니다: Seed 2.0 Mini: $0.00025-$0.0009; Seed 2.0 Lite: $0.0003-$0.002; Seed 2.0 Pro: $0.0005-$0.003.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Seed 모델에서 생성된 텍스트 응답입니다. | STRING |
