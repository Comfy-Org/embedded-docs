# ビデオコンポーネントの取得

Get Video Components ノードは、動画ファイルから主要な要素をすべて抽出します。動画を個々のフレームに分離し、オーディオトラックを抽出して、動画のフレームレート、ビット深度、および色空間情報を提供します。これにより、各コンポーネントを個別に使用して、さらなる処理や分析を行うことができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ビデオ` | コンポーネントを抽出する元の動画です。 | VIDEO | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `画像` | 動画から個別の画像として抽出された個々のフレームです。 | IMAGE |
| `オーディオ` | 動画から抽出されたオーディオトラックです。 | AUDIO |
| `fps` | 1秒あたりのフレーム数で表した動画のフレームレートです。 | FLOAT |
| `bit_depth` | 動画のビット深度です。 | INT |
| `color_space` | 動画の色空間です。 | COMBO |
