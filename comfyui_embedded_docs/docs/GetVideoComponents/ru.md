# Извлечь компоненты видео

Узел Get Video Components извлекает все основные элементы из видеофайла. Он разделяет видео на отдельные кадры, извлекает аудиодорожку и предоставляет частоту кадров, битовую глубину и цветовое пространство видео. Это позволяет работать с каждым компонентом независимо для дальнейшей обработки или анализа.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Видео, из которого нужно извлечь компоненты. | VIDEO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Отдельные кадры, извлечённые из видео, в виде отдельных изображений. | IMAGE |
| `audio` | Аудиодорожка, извлечённая из видео. | AUDIO |
| `fps` | Частота кадров видео в кадрах в секунду. | FLOAT |
| `bit_depth` | Битовая глубина видео. | COMBO |
| `color_space` | Цветовое пространство видео. | COMBO |
