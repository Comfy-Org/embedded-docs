# Извлечь компоненты видео

Узел Get Video Components извлекает все основные элементы из видеофайла. Он разделяет видео на отдельные кадры, извлекает аудиодорожку и предоставляет информацию о частоте кадров, битовой глубине и цветовом пространстве видео. Это позволяет работать с каждым компонентом независимо для дальнейшей обработки или анализа.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Видео, из которого извлекаются компоненты. | VIDEO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `изображения` | Отдельные кадры, извлеченные из видео в виде отдельных изображений. | IMAGE |
| `аудио` | Аудиодорожка, извлеченная из видео. | AUDIO |
| `fps` | Частота кадров видео в кадрах в секунду. | FLOAT |
| `bit_depth` | Битовая глубина видео. | INT |
| `color_space` | Цветовое пространство видео. | COMBO |
