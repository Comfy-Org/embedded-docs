# GetVideoComponents

הצומת Get Video Components מחלץ את כל הרכיבים העיקריים מקובץ וידאו. הוא מפריד את הווידאו לפריימים בודדים, מחלץ את רצועת השמע, ומספק את קצב הפריימים, עומק הסיביות ומרחב הצבע של הווידאו. הדבר מאפשר לך לעבוד עם כל רכיב בנפרד לצורך עיבוד או ניתוח נוספים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | הווידאו שממנו יש לחלץ רכיבים. | VIDEO | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `images` | הפריימים הבודדים שחולצו מהווידאו כתמונות נפרדות. | IMAGE |
| `audio` | רצועת השמע שחולצה מהווידאו. | AUDIO |
| `fps` | קצב הפריימים של הווידאו בפריימים לשנייה. | FLOAT |
| `bit_depth` | עומק הסיביות של הווידאו. | COMBO |
| `color_space` | מרחב הצבע של הווידאו. | COMBO |
