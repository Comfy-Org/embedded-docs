# استخراج اجزای ویدیو

گره «Get Video Components» تمام اجزای اصلی یک فایل ویدئویی را استخراج می‌کند. این گره ویدئو را به فریم‌های جداگانه تفکیک می‌کند، صدای آن را استخراج می‌نماید و اطلاعات نرخ فریم، عمق بیت و فضای رنگی ویدئو را ارائه می‌دهد. این امکان به شما اجازه می‌دهد تا با هر جزء به‌طور مستقل برای پردازش یا تحلیل بیشتر کار کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | ویدئویی که اجزاء از آن استخراج می‌شوند. | VIDEO | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصاویر` | فریم‌های جداگانه استخراج‌شده از ویدئو به‌صورت تصاویر مستقل. | IMAGE |
| `صدا` | صدای استخراج‌شده از ویدئو. | AUDIO |
| `نرخ فریم` | نرخ فریم ویدئو بر حسب فریم در ثانیه. | FLOAT |
| `bit_depth` | عمق بیت ویدئو. | INT |
| `color_space` | فضای رنگی ویدئو. | COMBO |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetVideoComponents/fa.md)
