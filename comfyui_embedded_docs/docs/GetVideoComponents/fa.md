# استخراج اجزای ویدیو

گره Get Video Components همه اجزای اصلی را از یک فایل ویدیویی استخراج می‌کند. این گره ویدیو را به فریم‌های جداگانه تفکیک می‌کند، تراک صوتی را استخراج می‌کند و نرخ فریم، عمق بیت و فضای رنگ ویدیو را ارائه می‌دهد. این امکان را فراهم می‌کند که با هر مؤلفه به‌صورت مستقل برای پردازش یا تحلیل بیشتر کار کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | ویدیویی که باید اجزای آن از آن استخراج شوند. | VIDEO | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `images` | فریم‌های جداگانه استخراج‌شده از ویدیو به‌صورت تصاویر مستقل. | IMAGE |
| `audio` | تراک صوتی استخراج‌شده از ویدیو. | AUDIO |
| `fps` | نرخ فریم ویدیو بر حسب فریم بر ثانیه. | FLOAT |
| `bit_depth` | عمق بیت ویدیو. | COMBO |
| `color_space` | فضای رنگ ویدیو. | COMBO |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetVideoComponents/fa.md)
