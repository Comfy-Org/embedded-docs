# Выбор кадра из видео

Узел `VideoFrameSample` извлекает фиксированное количество кадров из видео, используя одну из четырёх стратегий. Для смежных стратегий «head» и «tail» выходом является ленивая ссылка на видео (кадры не декодируются); для несмежных стратегий «uniform» и «random» декодируются только выбранные кадры.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|----------|------------|--------------|----------|
| `видео` | Входное видео. | VIDEO | Да | – |
| `количество_кадров` | Количество кадров для выборки (по умолчанию: 16). | INT | Да | 1 – 9999 |
| `стратегия` | Стратегия выборки (по умолчанию: "uniform"). | COMBO | Да | `"uniform"`<br>`"head"`<br>`"tail"`<br>`"random"` |
| `seed` | Случайное зерно, используется только со стратегией "random" (по умолчанию: 0). | INT | Да | 0 – 18446744073709551615 |

- Значение `num_frames` автоматически ограничивается общим количеством кадров входного видео.
- Параметр `seed` не действует, если `strategy` не установлена в `"random"`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Выбранное видео. | VIDEO |
