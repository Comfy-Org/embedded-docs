# نمونه‌گیری فریم ویدیو

گره `VideoFrameSample` تعداد ثابتی فریم از یک ویدیو با استفاده از یکی از چهار راهبرد استخراج می‌کند. برای راهبردهای متوالی "head" و "tail"، خروجی یک مرجع ویدیوی تنبل است (فریم‌ها رمزگشایی نمی‌شوند)؛ برای راهبردهای غیرمتوالی "uniform" و "random"، فقط فریم‌های انتخاب‌شده رمزگشایی می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|---------|---------|----------|-------|--------|
| `ویدیو` | ویدیوی ورودی. | VIDEO | بله | – |
| `تعداد فریم‌ها` | تعداد فریم‌های نمونه‌برداری (پیش‌فرض: ۱۶). | INT | بله | ۱ – ۹۹۹۹ |
| `استراتژی` | uniform: با فاصله یکنواخت، head: N فریم اول، tail: N فریم آخر، random: مرتب‌سازی تصادفی (پیش‌فرض: "uniform"). | COMBO | بله | "uniform"<br>"head"<br>"tail"<br>"random" |
| `seed` | دانه تصادفی، فقط با راهبرد "random" استفاده می‌شود (پیش‌فرض: ۰). | INT | بله | ۰ – ۱۸۴۴۶۷۴۴۰۷۳۷۰۹۵۵۱۶۱۵ |

- `num_frames` به‌طور خودکار به تعداد کل فریم‌های ویدیوی ورودی محدود می‌شود.
- پارامتر `seed` تأثیری ندارد مگر اینکه `strategy` روی `"random"` تنظیم شده باشد.
- وقتی `strategy` برابر `"uniform"` و `num_frames` برابر 1 باشد، فریم میانی ویدیو انتخاب می‌شود.
- مقدار ناشناخته `strategy` خطا ایجاد می‌کند.
