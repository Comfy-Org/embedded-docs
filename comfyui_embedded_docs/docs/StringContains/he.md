# StringContains

הצומת StringContains בודק אם מחרוזת נתונה מכילה תת-מחרוזת מוגדרת. הוא יכול לבצע בדיקה זו עם התאמה תלוית רישיות או ללא תלות ברישיות, ולהחזיר תוצאה בוליאנית המציינת אם תת-המחרוזת נמצאה בתוך המחרוזת הראשית.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת הטקסט הראשית שבתוכה יש לחפש | STRING | כן | - |
| `substring` | הטקסט שיש לחפש בתוך המחרוזת הראשית | STRING | כן | - |
| `case_sensitive` | קובע אם החיפוש צריך להיות תלוי רישיות (ברירת מחדל: true) | BOOLEAN | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `contains` | מחזיר true אם תת-המחרוזת נמצאת במחרוזת, אחרת false | BOOLEAN |
