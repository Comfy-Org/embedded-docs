# 空Latent图像（QwenImageLayerd）

`Empty Qwen Image Layered Latent` 节点用于准备 Qwen-Image-Layered 模型绘制所需的空白画布。可以把它想象成一叠按顺序夹在一起的干净描图纸：模型在第一张纸上绘制完整图像，并在之后的每张纸上绘制该图像的一部分。此节点决定纸张的大小和数量，但其本身并不绘制任何内容。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `width` | 要创建的潜空间图像的宽度。该值必须能被 16 整除。（默认值：640） | INT | 是 | 16 至 MAX_RESOLUTION（步长 16） |
| `height` | 要创建的潜空间图像的高度。该值必须能被 16 整除。（默认值：640） | INT | 是 | 16 至 MAX_RESOLUTION（步长 16） |
| `layers` | 要将图像分成多少层。始终会额外保留一张纸用于完整图像，因此你得到的是 `layers + 1` 张图像，而不是 `layers` 张。设为 2，你会得到完整图像外加 2 个层。设为 0，你只会得到完整图像本身。（默认值：3） | INT | 是 | 0 至 MAX_RESOLUTION（步长 1） |
| `batch_size` | 一批中生成的潜空间样本数量。（默认值：1） | INT | 是 | 1 至 4096 |

**注意：** `width` 和 `height` 参数会在内部除以 8，以确定输出潜空间张量的空间维度。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个用零填充的潜空间张量，其形状为 `[batch_size, 16, layers + 1, height // 8, width // 8]`。 | LATENT |

## 为什么你会多得到一张图像

Qwen-Image-Layered 不只是把图像拆开。它还会在独立的一张纸上，与各层一起重新绘制完整图像。因此，整叠纸总是比你要求的层数多一张。

- **第一张图像是完整图像，而不是某一层。** 它与你已有的图像完全相同；如果只需要各层，可以把它丢弃。
- **把各层重新叠放在一起，就能再次得到完整图像。** 如果它们叠加后不能还原成第一张图像，说明分离效果不符合你的预期，因此这也是快速检查结果的方法。
- **保持纸张顺序。** 整叠纸是唯一记录哪个层位于哪个层之上的凭据。纸张本身没有标注归属位置，因此重新排序或丢弃图像，等同于重新排序或丢失层。
- **各层带有透明通道**，因此可以相互叠放，而不会让下层被不透明背景遮住。

## 使用建议

像使用普通空潜空间一样，将输出发送给采样器，然后在 VAE Decode 之前接入一个 LatentCutToBatch，并将其 `dim` 设置为 `t`。这一步会按顺序将整叠纸拆分成单独的图像，从完整图像开始。

从默认的 3 层开始。要求更多层意味着生成时间更长、分离更精细；在看过该模型在较少层数下的效果之前，不值得调高。
