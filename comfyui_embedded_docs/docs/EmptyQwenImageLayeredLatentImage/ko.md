# Empty Qwen Image Layered Latent

Empty Qwen Image Layered Latent 노드는 Qwen-Image-Layered 모델이 그림을 그릴 빈 캔버스를 준비합니다. 마치 순서대로 묶인 깨끗한 트레이싱 시트 더미와 같다고 생각하면 됩니다. 모델은 첫 번째 시트에 전체 그림을 채우고, 그다음 시트에는 각각 그림의 일부를 채웁니다. 이 노드는 시트의 크기와 개수를 결정하지만, 자체적으로 아무것도 그리지는 않습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `width` | 생성할 latent 이미지의 너비입니다. 값은 16으로 나누어 떨어져야 합니다. (기본값: 640) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `height` | 생성할 latent 이미지의 높이입니다. 값은 16으로 나누어 떨어져야 합니다. (기본값: 640) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `layers` | 그림을 분리할 레이어 수입니다. 전체 그림용 시트 한 장이 항상 추가로 예약되므로, 실제로는 `layers`개가 아닌 `layers + 1`개의 이미지가 반환됩니다. 2로 설정하면 전체 그림과 레이어 2개를 얻습니다. 0으로 설정하면 전체 그림만 얻습니다. (기본값: 3) | INT | 예 | 0 ~ MAX_RESOLUTION (단계 1) |
| `batch_size` | 배치로 생성할 latent 샘플의 수입니다. (기본값: 1) | INT | 예 | 1 ~ 4096 |

**참고:** `width` 및 `height` 매개변수는 내부적으로 8로 나누어져 출력 latent 텐서의 공간 차원을 결정합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 0으로 채워진 latent 텐서입니다. 형태는 `[batch_size, 16, layers + 1, height // 8, width // 8]`입니다. | LATENT |

## 요청한 것보다 이미지가 하나 더 생기는 이유

Qwen-Image-Layered는 그림을 분리하기만 하지 않습니다. 레이어와 함께 완전한 그림 자체도 별도의 시트에 다시 그립니다. 그래서 시트 더미는 항상 요청한 레이어 수보다 한 장 더 높습니다.

- **첫 번째 이미지는 레이어가 아니라 전체 그림입니다.** 이미 가지고 있는 그림과 동일하므로 레이어만 필요한 경우에는 이 이미지를 버리면 됩니다.
- **모든 레이어를 다시 겹치면 전체 그림을 다시 얻을 수 있습니다.** 레이어를 합쳐도 첫 번째 이미지와 같아지지 않는다면 분리가 원하는 대로 이루어지지 않은 것이므로, 이는 결과를 빠르게 확인하는 방법입니다.
- **시트의 순서를 유지하세요.** 시트 더미는 어떤 레이어가 어떤 위에 놓여 있는지에 대한 유일한 기록입니다. 시트 자체에는 위치에 대한 정보가 적혀 있지 않으므로, 순서를 바꾸거나 이미지를 버리면 레이어가 다시 정렬되거나 손실됩니다.
- **레이어는 투명도를 가지고 반환됩니다.** 따라서 아래쪽 레이어가 불투명한 배경 뒤에 가려지지 않고 겹쳐질 수 있습니다.

## 사용 제안

일반적인 빈 latent를 샘플러에 보내는 것처럼 출력을 샘플러에 보낸 다음, VAE Decode 앞에 `dim`을 `t`로 설정한 LatentCutToBatch를 배치하세요. 이 단계에서 시트 더미가 전체 그림부터 시작하여 순서대로 개별 이미지로 분리됩니다.

기본값인 레이어 3개로 시작하세요. 더 많은 레이어를 요청하면 생성 시간이 길어지고 분리가 더 세밀해지지만, 모델이 적은 수의 레이어로 어떤 결과를 내는지 확인하기 전에는 레이어 수를 늘리지 않는 것이 좋습니다.
