# 空白 Qwen 圖像分層 Latent

Empty Qwen Image Layered Latent 節點準備 Qwen-Image-Layered 模型繪製所需的空白畫布。可以把它想像成一疊按順序夾在一起的乾淨描圖紙：模型會在第一張紙上畫出完整圖像，並在之後的每一張紙上畫出該圖像的其中一部分。此節點決定紙張的大小和數量。它本身不會繪製任何內容。

| `高度` | 要建立的潛在圖像高度。該值必須能被 16 整除。（預設值：640） | INT | 是 | 16 to MAX_RESOLUTION (step 16) |

## 為什麼你獲得的圖像會比要求的數量多一張

Qwen-Image-Layered 不只是將圖片拆解開來。它還會在完整圖層之外，額外在獨立的一張紙上重新繪製完整的圖片。這就是為什麼紙疊的高度永遠比你所要求的圖層數量多一張。

- **第一張圖像是完整圖片，而不是圖層。** 它就是你原本就有的那張圖片，所以當你只需要圖層時，可以將它丟棄。
- **將所有圖層重新依序疊在一起，你就會再次得到完整圖片。** 如果它們疊加起來並不等於第一張圖像，代表分離結果不如你預期，因此這是一個快速檢查結果的方法。
- **請保持紙張順序。** 這疊紙是唯一記錄各圖層上下順序的地方。紙張本身沒有標示它們應屬的位置，因此重新排序或刪除圖像，就等於重新排序或刪除圖層。
- **圖層會以透明方式輸出**，因此可以堆疊起來，而不會讓下方圖層被不透明的背景遮住。

## 使用建議

將輸出像平常的空潛在張量一樣送給取樣器，然後在 VAE Decode 之前放入 LatentCutToBatch，並將 `dim` 設為 `t`。這個步驟會依序將紙疊拆解成獨立的圖像，從完整圖片開始。

先從預設的 3 個圖層開始。要求更多圖層表示生成時間更長、分離更精細，在你看過模型處理少量圖層的效果之前，不值得增加圖層數量。
