# 空白 Qwen 圖像分層 Latent

## 概述

Empty Qwen Image Layered Latent 節點會準備好 Qwen-Image-Layered 模型在其上作畫的空白畫布。可以把它想像成一疊按順序夾在一起的乾淨描圖紙：模型在第一張紙上畫出完整畫面，之後的每張紙畫出畫面的一部分。此節點決定紙張的大小和數量，它本身不會繪製任何內容。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `寬度` | 要建立的潛在影像寬度。此值必須能被 16 整除。（預設值：640） | INT | 是 | 16 至 MAX_RESOLUTION |
| `高度` | 要建立的潛在影像高度。此值必須能被 16 整除。（預設值：640） | INT | 是 | 16 至 MAX_RESOLUTION |
| `圖層數` | 要將畫面分成多少層。永遠會為完整畫面預留一張額外的紙，因此你得到的是 `layers + 1` 張影像，而不是 `layers` 張。設為 2，你會得到完整畫面加上 2 個圖層。設為 0，你只會得到完整畫面。（預設值：3） | INT | 是 | 0 至 MAX_RESOLUTION |
| `批次大小` | 批次中要生成的潛在樣本數量。（預設值：1） | INT | 否 | 1 至 4096 |

**注意：** `width` 和 `height` 參數在內部會除以 8，以決定輸出潛在張量的空間維度。

## 為什麼你得到的影像比你要求的多了 1 張

Qwen-Image-Layered 不只是把畫面拆開，它還會在單獨的紙上與各圖層一起重新繪製完整畫面。這就是為什麼這疊紙永遠比你要求的圖層數多一張。

- **第一張影像是完整畫面，而不是圖層。** 它就是你已有的那張畫面，所以當你只需要圖層時，把它丟棄即可。
- **把所有圖層重新疊在一起，你就會再次得到完整畫面。** 如果它們疊加起來對不上第一張影像，表示分離沒有達到你想要的效果，因此這也是快速檢查結果的方法。
- **保持紙張順序。** 這疊紙是記錄哪一層在哪個之上唯一的依據。紙張本身沒有標註它們的位置，因此重新排序或丟棄影像就意味著重新排序或丟失圖層。
- **圖層帶有透明度**，因此可以疊放，而不會讓下方的圖層被不透明的背景遮擋。

## 使用建議

像使用普通空潛在值一樣把輸出傳送給取樣器，然後在 VAE 解碼之前接入 `dim` 設定為 `t` 的 LatentCutToBatch。這一步會把紙疊拆成獨立的影像，按順序排列，從完整畫面開始。

從預設的 3 層開始。要求更多層意味著更長的產生時間和更精細的分離，在你看過模型用少量圖層產生的效果之前，不值得增加。
