# 空白 Qwen 圖像分層 Latent

Empty Qwen Image Layered Latent 節點會準備 Qwen-Image-Layered 模型作畫的空白畫布。可以把它想成一疊按順序夾在一起的乾淨描圖紙：模型會在第一張紙上畫出完整影像，並在之後的每張紙上畫出該影像的一部分。此節點會決定紙張的大小與張數，但它本身不會繪製任何內容。

| --- | --- | --- | --- | --- |
| `width` | 要建立的潛在影像寬度。此值必須能被 16 整除。（預設值：640） | INT | 是 | 16 to MAX_RESOLUTION (step 16) |
| `height` | 要建立的潛在影像高度。此值必須能被 16 整除。（預設值：640） | INT | 是 | 16 to MAX_RESOLUTION (step 16) |

## 為什麼你會多得到一張影像

Qwen-Image-Layered 不只是把影像拆解開來；它也會在獨立的一張紙上重新畫出完整影像，與各圖層一起輸出。這就是為什麼這疊紙的張數永遠會比要求的圖層數多一張。

- **第一張影像是完整影像，而不是圖層。** 它就是原本那張完整影像；如果你只想要圖層，將它捨棄即可。
- **把所有圖層重新疊在一起，你就會再次得到完整影像。** 如果它們疊加後無法還原成第一張影像，表示分離效果不如預期，因此這也是一個快速檢查結果的方法。
- **請保持這些紙張的順序。** 這疊紙是唯一能記錄哪個圖層在上、哪個圖層在下的地方；紙張本身沒有標示它們應屬的位置，所以重新排序或丟棄影像，就等於重新排序或遺失圖層。
- **圖層輸出時會帶有透明度，** 因此可以直接堆疊，下方的圖層不會被不透明背景遮住。

## 使用建議

請像對待一般空白潛在張量一樣，將輸出送入採樣器，然後在 VAE Decode 之前放置 LatentCutToBatch，並將 `dim` 設為 `t`。這個步驟會依序將整疊紙拆成單獨的影像，並從完整影像開始。

先從預設的 3 個圖層開始。要求更多圖層表示生成時間更長、分離也更精細；在你還沒看過模型以少量圖層能做到什麼之前，不值得調高這個數值。
