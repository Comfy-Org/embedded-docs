# Пустой Qwen Image Layered latent

Empty Qwen Image Layered Latent подготавливает пустой холст, на который модель Qwen-Image-Layered наносит изображение. Представьте это как стопку чистых листов кальки, скреплённых вместе в порядке: модель заполняет первый лист полным изображением, а каждый следующий лист — одной частью этого изображения. Этот узел определяет, насколько большими будут листы и сколько их будет. Сам он ничего не рисует.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `высота` | Высота создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `слои` | На сколько слоёв разделить изображение. Один дополнительный лист всегда зарезервирован для полного изображения, поэтому на выходе вы получаете `layers + 1` изображений, а не `layers`. Установите значение 2 — и вы получите полное изображение плюс 2 слоя. Установите 0 — и вы получите только полное изображение. (по умолчанию: 3) | INT | Да | 0 to MAX_RESOLUTION (step 1) |
| `размер_пакета` | Количество латентных сэмплов для генерации в одном пакете. (по умолчанию: 1) | INT | Да | 1 до 4096 |

**Примечание:** Параметры `width` и `height` внутренне делятся на 8 для определения пространственных размеров выходного латентного тензора.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Его форма: `[batch_size, 16, layers + 1, height // 8, width // 8]`. | LATENT |

## Почему вы получаете на одно изображение больше, чем запросили

Qwen-Image-Layered не только разбирает изображение на части. Он также заново рисует полное изображение на отдельном листе, рядом со слоями. Поэтому стопка всегда на один лист выше, чем количество запрошенных вами слоёв.

- **Первое изображение — это полное изображение, а не слой.** Это то же самое изображение, которое у вас уже есть, поэтому выбросьте его, если вам нужны только слои.
- **Сложите все слои обратно друг на друга — и вы снова получите полное изображение.** Если они не совпадают с первым изображением, разделение не сработало так, как вы хотели, так что это быстрый способ проверить результат.
- **Сохраняйте порядок листов.** Стопка — единственная запись о том, какой слой находится поверх какого. На самих листах ничего не написано о том, куда они относятся, поэтому перестановка или удаление изображений означает перестановку или потерю слоёв.
- **Слои получаются с прозрачностью**, поэтому их можно накладывать друг на друга, не скрывая нижние за непрозрачным фоном.

## Рекомендации по использованию

Отправьте выходные данные в семплер так же, как обычный пустой латентный тензор, затем поместите LatentCutToBatch со значением `dim`, установленным в `t`, перед VAE Decode. Это шаг, который разбирает стопку на отдельные изображения по порядку, начиная с полного изображения.

Начните со значения по умолчанию — 3 слоя. Запрос большего количества означает более длительную генерацию и более тонкое разделение, и не стоит увеличивать количество, пока вы не увидите, что модель делает с малым числом слоёв.
