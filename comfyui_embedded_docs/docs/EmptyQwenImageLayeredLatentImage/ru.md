# Пустой Qwen Image Layered latent

Узел Empty Qwen Image Layered Latent подготавливает чистый холст, на котором модель Qwen-Image-Layered рисует изображение. Представьте стопку чистых листов кальки, скрепленных по порядку: модель заполняет первый лист полным изображением, а каждый следующий лист — частью этого изображения. Этот узел определяет размер и количество листов. Сам он ничего не рисует.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 до MAX_RESOLUTION |
| `высота` | Высота создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 до MAX_RESOLUTION |
| `слои` | На сколько слоев разделить изображение. Для полного изображения всегда резервируется один дополнительный лист, поэтому на выходе получается `layers + 1` изображений, а не `слои`. Установите значение 2 — получите полное изображение плюс 2 слоя. Установите значение 0 — получите только полное изображение. (по умолчанию: 3) | INT | Да | 0 до MAX_RESOLUTION |
| `размер_пакета` | Количество латентных образцов, генерируемых в одном пакете. (по умолчанию: 1) | INT | Нет | 1 до 4096 |

**Примечание:** Параметры `width` и `height` внутренне делятся на 8 для определения пространственных размеров выходного латентного тензора.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Его форма: `[batch_size, 16, layers + 1, height // 8, width // 8]`. | LATENT |

## Почему вы получаете на одно изображение больше, чем запросили

Qwen-Image-Layered не только разбирает изображение на части. Он также заново рисует полное изображение на отдельном листе, рядом со слоями. Поэтому стопка всегда на один лист выше, чем запрошенное количество слоев.

- **Первое изображение — это полное изображение, а не слой.** Это то же изображение, которое у вас уже есть, поэтому выбрасывайте его, когда нужны только слои.
- **Если сложить все слои вместе, снова получится полное изображение.** Если они не складываются в это первое изображение, разделение сработало не так, как вы хотели, поэтому это быстрый способ проверить результат.
- **Сохраняйте порядок листов.** Стопка — единственная запись о том, какой слой находится поверх какого. На самих листах не указано, где они должны находиться, поэтому перестановка или удаление изображений означает перестановку или потерю слоев.
- **Слои выводятся с прозрачностью**, поэтому их можно складывать, не скрывая нижние слои за непрозрачным фоном.

## Рекомендации по использованию

Отправьте выходные данные в сэмплер так же, как обычный пустой латент, затем поместите LatentCutToBatch с `dim`, установленным в `t`, перед декодированием VAE. Именно этот шаг разбирает стопку на отдельные изображения по порядку, начиная с полного изображения.

Начните со значения по умолчанию — 3 слоя. Запрос большего количества означает более долгую генерацию и более тонкое разделение, и увеличивать его не стоит, пока вы не увидите, что модель делает с малым количеством.
