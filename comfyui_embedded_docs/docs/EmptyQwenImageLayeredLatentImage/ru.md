# Пустой Qwen Image Layered latent

Узел Empty Qwen Image Layered Latent подготавливает чистый холст, на котором модель Qwen-Image-Layered рисует. Представьте его как стопку чистых листов кальки, скреплённых вместе по порядку: модель заполняет первый лист полным изображением, а каждый следующий лист — одной частью этого изображения. Этот узел определяет размер листов и их количество, но сам ничего не рисует.

## Входные данные

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `height` | Высота создаваемого латентного изображения. Значение должно делиться на 16. (по умолчанию: 640) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `layers` | На сколько слоёв разделять изображение. Один дополнительный лист всегда зарезервирован для полного изображения, поэтому на выходе вы получаете `layers + 1` изображений, а не `layers`. Установите значение 2 — получите полное изображение плюс 2 слоя. Установите значение 0 — получите только полное изображение. (по умолчанию: 3) | INT | Да | 0 to MAX_RESOLUTION (step 1) |
| `batch_size` | Количество латентных сэмплов для генерации в одном батче. (по умолчанию: 1) | INT | Да | 1 to 4096 |

**Примечание:** Параметры `width` и `height` внутри узла делятся на 8 для определения пространственных размеров выходного латентного тензора.

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Его форма: `[batch_size, 16, layers + 1, height // 8, width // 8]`. | LATENT |

## Почему вы получаете на одно изображение больше, чем запросили

Qwen-Image-Layered не только разбирает изображение на части. Он также заново рисует полное изображение на отдельном листе, рядом со слоями. Поэтому в стеке всегда на один лист больше, чем количество запрошенных слоёв.

- **Первое изображение — это полное изображение, а не слой.** Это то же изображение, которое у вас уже есть, поэтому выбрасывайте его, если вам нужны только слои.
- **Сложите все слои обратно друг на друга — и вы снова получите полное изображение.** Если в сумме они не дают то первое изображение, значит, разделение сработало не так, как вы хотели; это быстрый способ проверить результат.
- **Сохраняйте порядок листов.** Стек — единственная запись о том, какой слой находится поверх какого. На самих листах ничего не написано о том, где их место, поэтому перестановка или удаление изображений означает перестановку или потерю слоёв.
- **Слои получаются с прозрачностью**, поэтому их можно складывать, не скрывая нижние за непрозрачным фоном.

## Рекомендации по использованию

Передайте выходной результат в семплер так же, как обычный пустой латент, затем поместите LatentCutToBatch с параметром `dim`, установленным в `t`, перед VAE Decode. Этот шаг разбирает стек на отдельные изображения по порядку, начиная с полного изображения.

Начните со значения по умолчанию — 3 слоя. Запрос большего количества означает более долгую генерацию и более тонкое разделение, и повышать его не стоит, пока вы не увидите, что модель делает с небольшим числом.
