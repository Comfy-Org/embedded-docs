# Empty Qwen Image Layered Latent

「Empty Qwen Image Layered Latent ノードは、Qwen-Image-Layered モデルが描画するための空白のキャンバスを準備します。これは、順番にまとめられたきれいなトレーシングシートの束と考えてください。モデルは最初のシートに全体画像を描き、以降の各シートにはその画像の一部分を描きます。このノードはシートのサイズと枚数を決定しますが、それ自体は何も描画しません。」

## 要求した枚数より1枚多く画像が得られる理由

Qwen-Image-Layered は画像を分解するだけでなく、レイヤーと並べて、専用のシートに全体画像も再描画します。そのため、シート束は常に、要求したレイヤー数より1枚多い枚数になります。

- **最初の画像はレイヤーではなく全体画像です。** それはすでに持っている画像と同じものなので、レイヤーだけが必要な場合は破棄してください。
- **すべてのレイヤーを重ね合わせると、再び全体画像が得られます。** それらを重ねても最初の画像にならない場合、分離が意図したとおりに機能していないことになるため、結果を確認する簡単な方法です。
- **シートの順序を維持してください。** どのレイヤーがどの上に位置するかは、シート束が唯一の記録です。シート自体にはその所在を示す情報は何も書かれていないため、画像の順序を並べ替えたり破棄したりすると、レイヤーの順序を変更したり失ったりすることになります。
- **レイヤーは透明付きで出力されます**。そのため、下のレイヤーが不透明な背景に隠れることなく重ね合わせることができます。

## 使用上の提案

通常の空の潜在変数と同じように出力をサンプラーに送り、その後に VAE Decode の前に `dim` を `t` に設定した LatentCutToBatch を配置します。このステップが、シート束を全体画像から始まる順序で個別の画像に分解します。

まずはデフォルトの3レイヤーから始めてください。それ以上を要求すると生成時間が長くなり、より細かい分離になります。モデルが少ないレイヤーで何を行うかを確認するまでは、増やす価値はありません。
