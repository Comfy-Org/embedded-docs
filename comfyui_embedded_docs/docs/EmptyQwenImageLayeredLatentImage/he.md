# Empty Qwen Image Layered Latent

הצומת Empty Qwen Image Layered Latent מכין את הבד הריק שעליו מצייר המודל Qwen-Image-Layered. אפשר לחשוב עליו כעל ערימה של דפי שרטוט נקיים מהודקים יחד לפי סדר: המודל ממלא את הדף הראשון בתמונה השלמה, וכל דף אחריו בחלק אחד מאותה תמונה. הצומת הזה קובע כמה גדולים הדפים וכמה מהם יש. הוא עצמו אינו מצייר דבר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `width` | רוחב התמונה הלטנטית ליצירה. הערך חייב להיות מתחלק ב-16. (ברירת מחדל: 640) | INT | כן | 16 עד MAX_RESOLUTION (צעד 16) |
| `height` | גובה התמונה הלטנטית ליצירה. הערך חייב להיות מתחלק ב-16. (ברירת מחדל: 640) | INT | כן | 16 עד MAX_RESOLUTION (צעד 16) |
| `layers` | כמה שכבות לפצל את התמונה. תמיד נשמר דף נוסף אחד עבור התמונה השלמה, כך שמתקבלות `layers + 1` תמונות, ולא `layers`. אם תגדירו 2 תקבלו את התמונה השלמה ועוד 2 שכבות. אם תגדירו 0 תקבלו את התמונה השלמה לבדה. (ברירת מחדל: 3) | INT | כן | 0 עד MAX_RESOLUTION (צעד 1) |
| `batch_size` | מספר דגימות הלטנט ליצירה באצווה. (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |

**הערה:** הפרמטרים `width` ו-`height` מחולקים פנימית ב-8 כדי לקבוע את הממדים המרחביים של טנסור הלטנט בפלט.

| `samples` | טנסור לטנטי מלא באפסים. הצורה שלו היא `[batch_size, 16, layers + 1, height // 8, width // 8]`. | LATENT |

## מדוע מתקבלת תמונה אחת יותר משביקשתם

Qwen-Image-Layered לא רק מפרק תמונה. הוא גם מצייר מחדש את התמונה השלמה, על דף נפרד משלה, לצד השכבות. לכן הערימה תמיד גבוהה בדף אחד ממספר השכבות שביקשתם.

- **התמונה הראשונה היא התמונה השלמה, לא שכבה.** היא אותה תמונה שכבר יש לכם, אז השליכו אותה כאשר אתם רוצים רק את השכבות.
- **הניחו את כל השכבות זו על זו בחזרה ותקבלו שוב את התמונה השלמה.** אם הן לא מתחברות בחזרה לאותה תמונה ראשונה, ההפרדה לא עבדה כפי שרציתם, אז זו דרך מהירה לבדוק את התוצאה.
- **שמרו על סדר הדפים.** הערימה היא התיעוד היחיד של איזו שכבה יושבת מעל איזו. דבר לא כתוב על הדפים עצמם כדי לומר היכן הם שייכים, כך ששינוי סדר או השמטת תמונות פירושו שינוי סדר או אובדן שכבות.
- **השכבות יוצאות עם שקיפות**, כך שניתן לערום אותן בלי שהשכבות התחתונות יוסתרו מאחורי רקע אטום.

## הצעות שימוש

שלחו את הפלט לדוגם כפי שהייתם שולחים לטנט ריק רגיל, ואז הציבו את LatentCutToBatch עם `dim` מוגדר ל-`t` לפני VAE Decode. זה השלב שמפרק את הערימה לתמונות נפרדות, לפי הסדר, החל מהתמונה השלמה.

התחילו מברירת המחדל של 3 שכבות. בקשה ליותר שכבות משמעה יצירה ארוכה יותר והפרדה עדינה יותר, ולא כדאי להעלות את המספר עד שתראו מה המודל עושה עם מספר קטן.
