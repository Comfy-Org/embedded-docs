# Создать цветную маску SCAIL-2

Этот узел рендерит данные отслеживания SAM3 в цветные маски, которые используются узлом WanSCAILToVideo. Он обрабатывает данные отслеживания из видео с управляющей позой и, опционально, эталонного изображения, назначая согласованные цвета каждому отслеживаемому человеку в обоих выходах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `driving_track_data` | SAM3-трек видео с управляющей позой. Будет отрендерен в выход `pose_video_mask`. | SAM3_TRACK_DATA | Да | - |
| `ref_track_data` | SAM3-трек эталонного изображения(ий) (одна идентичность на объект, цвет назначается в порядке пакета) или обычная MASK эталонного субъекта (отображается как одна идентичность). | SAM3_TRACK_DATA или MASK | Нет | - |
| `object_indices` | Список индексов людей через запятую для включения (например, '0,2,3'). Применяется как к эталонной маске, так и к маске видео с позой. Пусто = все. (по умолчанию: "") | STRING | Да | - |
| `sort_by` | Порядок, в котором цвета палитры назначаются отслеживаемым объектам (применяется и к эталону, и к видео с позой, чтобы каждая идентичность сохраняла одинаковый цвет). Объекты, появляющиеся в более ранних кадрах, всегда идут первыми; внутри кадра left_to_right = самый левый объект (по центроиду при первом появлении) получает первый цвет, area = самый большой объект (по площади маски при первом появлении) получает первый цвет; none = сохранить порядок SAM3. (по умолчанию: "left_to_right") | COMBO | Да | `"none"`<br>`"left_to_right"`<br>`"area"` |
| `replacement_mode` | False = режим анимации (pose_video_mask имеет чёрный фон, reference_image_mask имеет белый фон). True = режим замены (pose_video_mask имеет белый фон, reference_image_mask имеет чёрный фон). (по умолчанию: False) | BOOLEAN | Да | False<br>True |

Примечание: `object_indices` принимает только цифры, разделённые запятыми; нечисловые записи и индексы вне диапазона игнорируются. Если `ref_track_data` не указан, выход `reference_image_mask` представляет собой сплошную заливку цветом фона эталона (белый в режиме анимации, чёрный в режиме замены).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `pose_video_mask` | Цветная маска, отрендеренная из данных отслеживания видео с управляющей позой. Цвет фона зависит от настройки `replacement_mode`. | IMAGE |
| `reference_image_mask` | Цветная маска, отрендеренная из данных отслеживания эталонного изображения. Фон чёрный в режиме замены, белый в режиме анимации. Если эталонные данные не предоставлены, возвращает сплошную заливку, совпадающую с цветом фона эталона. | IMAGE |
