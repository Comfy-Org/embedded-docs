# SDPoseKeypointExtractor

הצומת SDPoseKeypointExtractor מזהה נקודות מפתח של תנוחת אדם מתמונות קלט באמצעות מודל SDPose. הוא יכול לעבד תמונות מלאות או אזורים ספציפיים המוגדרים על ידי תיבות תוחמות, ומוציא את נקודות המפתח שזוהו בפורמט OpenPose, הכולל את הקואורדינטות עבור כל אדם וציון ביטחון עבור כל נקודת מפתח.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל SDPose המשמש לזיהוי נקודות מפתח. חייב להיות מודל עם מאפיין `heatmap_head`, במיוחד ממאגר SDPose. | MODEL | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד תמונות הקלט אל המרחב הלטנטי לצורך עיבוד. | VAE | כן | - |
| `image` | תמונת הקלט או אצוות תמונות שמהן יש לחלץ נקודות מפתח של תנוחה. | IMAGE | כן | - |
| `batch_size` | מספר התמונות לעיבוד בבת אחת כאשר פועלים במצב תמונה מלאה (כלומר, כאשר `bboxes` לא מסופק). זה יכול להאיץ את העיבוד. (ברירת מחדל: 16) | INT | לא | 1 to 10000 |
| `bboxes` | תיבות תוחמות אופציונליות לזיהויים מדויקים יותר. נדרש לזיהוי של מספר אנשים. אם מסופק, הצומת יחלץ נקודות מפתח מכל אזור שצוין. | BOUNDINGBOX | לא | - |

**אילוצי פרמטרים:**
*   קלט `model` חייב להיות מודל SDPose ספציפי. אם למודל שסופק אין מאפיין `heatmap_head`, הצומת תעלה שגיאה.
*   הצומת פועל בשני מצבים נפרדים בהתאם לקלט `bboxes`:
    1.  **מצב תיבות תוחמות:** כאשר `bboxes` מסופק, הוא מעבד כל אזור שצוין בנפרד. זה נדרש לזיהוי מספר אנשים בתמונה בודדת.
    2.  **מצב תמונה מלאה:** כאשר `bboxes` אינו מסופק, הוא מעבד את התמונה כולה כאצווה. הפרמטר `batch_size` חל רק במצב זה.
*   כאשר `bboxes` מסופק, עליו להיות רשימה של תיבות תוחמות. אם יש פחות רשימות תיבות תוחמות מאשר תמונות, הרשימה האחרונה משמשת מחדש עבור התמונות הנותרות.
*   תיבות תוחמות עם רוחב או גובה אפס (למשל, `x2 <= x1` או `y2 <= y1`) מדולגות.
