# إنشاء أصل صورة ByteDance

تنشئ هذه العقدة أصل صورة شخصي لخدمة Seedance 2.0 من ByteDance. تقوم برفع صورة إدخال وتسجيلها ضمن مجموعة أصول محددة. إذا لم يتم توفير معرف مجموعة، فستبدأ عملية التحقق من هوية الشخص الحقيقي في متصفحك لإنشاء مجموعة جديدة قبل إضافة الأصل.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `image` | الصورة المراد تسجيلها كأصل شخصي. | IMAGE | نعم |  |
| `group_id` | إعادة استخدام معرف مجموعة أصول Seedance موجود لتجنب التحقق البشري المتكرر لنفس الشخص. اتركه فارغًا لتشغيل التحقق من هوية الشخص الحقيقي في المتصفح وإنشاء مجموعة جديدة (الافتراضي: فارغ). | STRING | لا |  |

**قيود الصورة:**
*   يجب أن يتراوح عرض الصورة بين 300 و 6000 بكسل.
*   يجب أن يتراوح ارتفاع الصورة بين 300 و 6000 بكسل.
*   يجب أن تتراوح نسبة العرض إلى الارتفاع للصورة بين 0.4:1 و 2.5:1.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `asset_id` | المعرف الفريد لأصل الصورة المنشأ حديثًا. | STRING |
| `group_id` | معرف مجموعة الأصول. سيكون هذا هو `group_id` المقدم أو معرفًا تم إنشاؤه حديثًا. | STRING |
