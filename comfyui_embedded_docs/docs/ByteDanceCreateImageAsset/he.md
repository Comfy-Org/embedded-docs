# ByteDance יצירת נכס תמונה

צומת זה יוצר נכס תמונה אישי עבור שירות Seedance 2.0 של ByteDance. הוא מעלה תמונת קלט ורושם אותה בקבוצת נכסים שצוינה. אם לא מסופק מזהה קבוצה, הוא יתחיל תהליך אימות אדם אמיתי בדפדפן שלך כדי ליצור קבוצה חדשה לפני הוספת הנכס.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שתירשם כנכס אישי. | IMAGE | כן |  |
| `group_id` | השתמש מחדש במזהה קבוצת נכסים קיים של Seedance כדי לדלג על אימות אדם חוזר עבור אותו אדם. השאר ריק כדי להפעיל אימות אדם אמיתי בדפדפן וליצור קבוצה חדשה (ברירת מחדל: ריק). | STRING | לא |  |

**אילוצי תמונה:**
- רוחב התמונה חייב להיות בין 300 ל-6000 פיקסלים.
- גובה התמונה חייב להיות בין 300 ל-6000 פיקסלים.
- יחס הרוחב-לגובה של התמונה חייב להיות בין 0.4:1 ל-2.5:1.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `asset_id` | המזהה הייחודי לנכס התמונה החדש שנוצר. | STRING |
| `group_id` | המזהה של קבוצת הנכסים. זה יהיה ה-`group_id` שסופק או מזהה חדש שנוצר. | STRING |
