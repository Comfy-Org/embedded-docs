# Grok 비디오 확장

The Grok Video Extend 노드는 AI 모델을 사용하여 기존 비디오의 자연스러운 연속 영상을 생성합니다. 짧은 비디오와 다음에 어떤 내용이 이어져야 하는지를 설명하는 텍스트 프롬프트를 제공하면, 노드가 원본 비디오의 뒤를 잇는 새로운 비디오 클립을 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 확장에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"grok-imagine-video"` |
| `프롬프트` | 비디오에서 다음에 어떤 일이 일어나야 하는지에 대한 텍스트 설명입니다. | STRING | 예 | 해당 없음 |
| `비디오` | 확장할 원본 비디오입니다. MP4 형식, 2~15초 길이. | VIDEO | 예 | 해당 없음 |
| `시드` | 노드가 다시 실행되어야 하는지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0 ~ 2147483647 |

### grok-imagine-video 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 확장할 길이(초)입니다(기본값: 8). | INT | 예 | 2 ~ 10 |

**매개변수 제약 조건:**
*   `video` 입력은 길이가 2초에서 15초 사이인 MP4 파일이어야 하며 파일 크기가 50MB를 초과할 수 없습니다.
*   `prompt`에는 최소 한 자 이상의 문자가 포함되어야 합니다(공백은 제거됨).
*   `model` 매개변수는 동적 콤보입니다. "grok-imagine-video" 옵션을 선택하면 중첩된 `duration` 매개변수가 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 새로 생성된 비디오 확장 영상입니다. | VIDEO |
