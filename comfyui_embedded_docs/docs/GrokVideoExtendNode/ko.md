# Grok 비디오 확장

Grok Video Extend 노드는 AI 모델을 사용하여 기존 비디오를 자연스럽게 이어주는 연장 영상을 생성합니다. 짧은 비디오와 다음에 일어나야 할 내용을 설명하는 텍스트 프롬프트를 제공하면, 노드는 원본 비디오에 이어지는 새로운 비디오 클립을 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 연장에 사용할 모델입니다. | COMBO | 예 | `"grok-imagine-video"` |
| `프롬프트` | 비디오에서 다음에 일어나야 할 내용을 설명하는 텍스트입니다. | STRING | 예 | N/A |
| `비디오` | 연장할 원본 비디오입니다. MP4 형식, 2~15초 길이입니다. | VIDEO | 예 | N/A |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 시드와 관계없이 실제 결과는 비결정적입니다 (기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |

### grok-imagine-video 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 연장할 길이(초)입니다 (기본값: 8). | INT | 예 | 2 ~ 10 |

**매개변수 제약 조건:**
*   `video` 입력은 길이가 2~15초이고 파일 크기가 50MB를 초과할 수 없는 MP4 파일이어야 합니다.
*   `prompt`는 최소 한 글자 이상이어야 합니다 (공백은 제거됩니다).
*   `model` 매개변수는 동적 콤보입니다. "grok-imagine-video" 옵션을 선택하면 중첩된 `duration` 매개변수가 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 새로 생성된 비디오 연장 영상입니다. | VIDEO |
