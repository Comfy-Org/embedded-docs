# Grok 影片延伸

Grok Video Extend 節點會根據文字提示，以無縫接續的方式延伸現有影片。提供一段簡短的來源影片，並描述接下來應該發生什麼；此節點會傳回一段從原始影片繼續的新影片片段。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片延伸的模型。選擇 `"grok-imagine-video"` 選項會顯示其模型專屬設定。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video"` |
| `提示詞` | 描述影片中接下來應該發生什麼的文字。 | STRING | 是 | N/A |
| `影片` | 要延伸的來源影片。MP4 格式，2-15 秒。 | VIDEO | 是 | MP4, 2-15 seconds, maximum 50MB |
| `種子` | 用於決定節點是否應重新執行的種子；無論種子為何，實際結果都是不確定的（預設值：0）。 | INT | 是 | 0 至 2147483647 |

### grok-imagine-video 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 延伸長度，以秒為單位（預設值：8）。 | INT | 是 | 2 至 10 |

**參數限制：**
*   `video` 輸入必須是長度介於 2 到 15 秒之間的 MP4 檔案，且檔案大小不得超過 50MB。
*   `prompt` 在去除空白後必須至少包含一個字元。
*   `model` 參數是動態組合。選擇 `"grok-imagine-video"` 選項會顯示巢狀的 `duration` 參數。

## 輸出
