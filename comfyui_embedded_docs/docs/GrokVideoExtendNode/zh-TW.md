# Grok 影片延伸

Grok Video Extend 節點使用 AI 模型為現有影片建立無縫接續。您提供一段短片和一段文字提示，描述接下來應該發生什麼事，該節點便會生成接續原始影片的新影片片段。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片延伸的模型。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video"` |
| `提示詞` | 說明影片接下來應發生什麼事的文字描述。 | STRING | 是 | N/A |
| `影片` | 要延伸的來源影片。MP4 格式，2-15 秒。 | VIDEO | 是 | N/A |
| `種子` | 用於決定節點是否應重新執行的種子；實際結果與種子無關，皆為非確定性（預設：0）。 | INT | 是 | 0 至 2147483647 |

### grok-imagine-video 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 延伸長度（以秒為單位，預設：8）。 | INT | 是 | 2 至 10 |

**參數限制：**
*   `video` 輸入必須是長度介於 2 至 15 秒的 MP4 檔案，且檔案大小不得超過 50MB。
*   `prompt` 在去除空白字元後，必須至少包含一個字元。
*   `model` 參數是動態組合。選取「grok-imagine-video」選項會顯示巢狀的 `duration` 參數。

## 輸出
