# Grok 影片延伸

Grok Video Extend 節點使用 AI 模型來建立現有影片的無縫延續。您提供一段短影片和一段描述接下來應發生內容的文字提示，該節點就會產生接續原始影片的新影片剪輯。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片延續的模型。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video"` |
| `提示詞` | 描述影片接下來應發生內容的文字。 | STRING | 是 | N/A |
| `影片` | 要延伸的來源影片。MP4 格式，長度 2 至 15 秒。 | VIDEO | 是 | N/A |
| `種子` | 用於決定節點是否應重新執行的種子；無論種子為何，實際結果都是非確定性的（預設值：0）。 | INT | 是 | 0 至 2147483647 |

### grok-imagine-video 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 延伸的長度（以秒為單位）（預設值：8）。 | INT | 是 | 2 至 10 |

**參數限制：**
*   `video` 輸入必須是長度介於 2 至 15 秒之間的 MP4 檔案，且檔案大小不得超過 50MB。
*   `prompt` 必須包含至少一個字元（會移除空白字元）。
*   `model` 參數是動態組合。選取 "grok-imagine-video" 選項會顯示巢狀的 `duration` 參數。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 新產生的影片延伸片段。 | VIDEO |
