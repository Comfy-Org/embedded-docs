# Grok Video Extend

Узел Grok Video Extend использует модель ИИ для создания бесшовного продолжения существующего видео. Вы предоставляете короткое видео и текстовый запрос, описывающий, что должно произойти дальше, а узел генерирует новый видеоклип, который следует за исходным.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для продолжения видео. | DYNAMIC_COMBO | Да | `"grok-imagine-video"` |
| `запрос` | Текстовое описание того, что должно произойти дальше в видео. | STRING | Да | N/A |
| `видео` | Исходное видео для продолжения. Формат MP4, 2-15 секунд. | VIDEO | Да | N/A |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |

### Входы grok-imagine-video

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `duration` | Продолжительность продолжения в секундах (по умолчанию: 8). | INT | Да | от 2 до 10 |

**Ограничения параметров:**
*   Входной параметр `video` должен быть файлом MP4 длительностью от 2 до 15 секунд и размером не более 50 МБ.
*   Параметр `prompt` должен содержать хотя бы один символ (пробелы обрезаются).
*   Параметр `model` является динамическим комбинированным списком. Выбор опции "grok-imagine-video" открывает вложенный параметр `duration`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Новое сгенерированное продолжение видео. | VIDEO |
