# Grok Video Extend

Узел Grok Video Extend расширяет существующее видео бесшовным продолжением на основе текстового промпта. Укажите короткое исходное видео и опишите, что должно произойти далее; узел возвращает новый видеоклип, который продолжает исходный.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для расширения видео. Выбор опции `"grok-imagine-video"` открывает её настройки, специфичные для модели. | DYNAMIC_COMBO | Да | `"grok-imagine-video"` |
| `запрос` | Текстовое описание того, что должно произойти далее в видео. | STRING | Да | N/A |
| `видео` | Исходное видео для расширения. Формат MP4, 2–15 секунд. | VIDEO | Да | MP4, 2-15 seconds, maximum 50MB |
| `seed` | Начальное число (seed), определяющее, следует ли повторно запускать узел; фактические результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Да | 0 до 2147483647 |

### Входы grok-imagine-video

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `duration` | Длительность расширения в секундах (по умолчанию: 8). | INT | Да | 2 до 10 |

**Ограничения параметров:**
*   Вход `video` должен быть MP4-файлом длительностью от 2 до 15 секунд и размером не более 50 МБ.
*   Параметр `prompt` должен содержать хотя бы один символ после удаления пробельных символов.
*   Параметр `model` — это динамический комбинированный список. Выбор опции `"grok-imagine-video"` открывает вложенный параметр `duration`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Новое сгенерированное расширение видео. | VIDEO |
