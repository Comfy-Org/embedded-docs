# Grok Video Extend

Узел Grok Video Extend использует модель искусственного интеллекта для создания бесшовного продолжения существующего видео. Вы предоставляете короткое видео и текстовый запрос с описанием того, что должно произойти дальше, а узел генерирует новый видеоклип, который продолжает исходное видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для продолжения видео. | DYNAMIC_COMBO | Да | `"grok-imagine-video"` |
| `запрос` | Текстовое описание того, что должно произойти дальше в видео. | STRING | Да | N/A |
| `видео` | Исходное видео для продолжения. Формат MP4, длительностью 2–15 секунд. | VIDEO | Да | N/A |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | 0 до 2147483647 |

### Входы grok-imagine-video

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `duration` | Длительность продолжения в секундах (по умолчанию: 8). | INT | Да | 2 до 10 |

**Ограничения параметров:**
*   Входной параметр `video` должен быть MP4-файлом длительностью от 2 до 15 секунд и размером не более 50 МБ.
*   После удаления пробелов параметр `prompt` должен содержать хотя бы один символ.
*   Параметр `model` является динамическим комбинированным списком. Выбор опции "grok-imagine-video" открывает вложенный параметр `duration`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Новое сгенерированное продолжение видео. | VIDEO |
