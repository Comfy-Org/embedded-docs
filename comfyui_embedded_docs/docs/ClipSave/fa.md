# ذخیره CLIP

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که باید ذخیره شود. | CLIP | بله | - |
| `filename_prefix` | مسیر پیشوند و نام فایل(ها) برای ذخیره. گره یک پسوند جزء (مثلاً `_clip_l`، `_clip_g`) و یک شمارنده برای ایجاد نام‌های یکتا اضافه می‌کند (پیش‌فرض: `clip/ComfyUI`). | STRING | بله | - |
| `prompt` | اطلاعات پرامپت گردش کار که به‌عنوان فراداده در فایل خروجی ذخیره می‌شود. این پارامتر در رابط کاربری پنهان است. | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده اضافی که به‌صورت جفت‌های کلید-مقدار در فایل خروجی ذخیره می‌شود. این پارامتر در رابط کاربری پنهان است. | EXTRA_PNGINFO | خیر | - |

## خروجی‌ها

این گره هیچ اتصال خروجی ندارد. فایل‌های پردازش‌شده را مستقیماً در پوشه `ComfyUI/output/` ذخیره می‌کند.

### جزئیات فایل ذخیره‌شده

گره state dictionary مدل CLIP را تحلیل می‌کند و برای هر جزء شناسایی‌شده، فایل SafeTensors جداگانه‌ای ذخیره می‌کند. جزء مورد نظر از روی پیشوند کلیدهای پارامترهایش شناسایی می‌شود. گره پیشوندهای زیر را به ترتیب بررسی می‌کند:

- `clip_l.` (رمزگذار متن CLIP-L)
- `clip_g.` (رمزگذار متن CLIP-G)
- `clip_h.` (رمزگذار متن CLIP-H)
- `t5xxl.` (رمزگذار متن T5-XXL)
- `pile_t5xl.` (رمزگذار متن Pile-T5-XL)
- `mt5xl.` (رمزگذار متن mT5-XL)
- `umt5xxl.` (رمزگذار متن UMT5-XXL)
- `t5base.` (رمزگذار متن T5-Base)
- `gemma2_2b.` (رمزگذار متن Gemma 2 2B)
- `llama.` (رمزگذار متن LLaMA)
- `hydit_clip.` (رمزگذار متن Hydit CLIP)
- پیشوند خالی (سایر اجزای CLIP)

برای هر جزء شناسایی‌شده، گره فایلی با نام `{filename}_{counter:05}_.safetensors` ایجاد می‌کند (مثلاً `ComfyUI_clip_l_00001_.safetensors`)؛ در این نام، نام جزء به پیشوند نام فایل اضافه می‌شود و شمارنده یکتایی نام فایل‌ها را تضمین می‌کند. هنگام ذخیره یک جزء، پیشوند `transformer.` از کلیدهای پارامترهای آن حذف می‌شود.

فراداده نوشته‌شده در هر فایل شامل پرامپت گردش کار و هرگونه اطلاعات اضافی PNG است، مگر اینکه ذخیره فراداده با آرگومان خط فرمان `--disable-metadata` غیرفعال شده باشد.
