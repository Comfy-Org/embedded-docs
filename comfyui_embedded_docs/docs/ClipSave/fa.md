# ClipSave

گره `CLIPSave` یک مدل رمزگذار متنی CLIP را با فرمت SafeTensors روی دیسک ذخیره می‌کند. این گره برای گردشکارهای پیشرفته ادغام مدل طراحی شده است و به‌طور خودکار مدل CLIP را بر اساس ساختار داخلی مدل به بخش‌های تشکیل‌دهنده آن (مانند CLIP-L، CLIP-G یا T5XXL) جدا می‌کند و هر بخش را به‌صورت یک فایل جداگانه ذخیره می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که قرار است ذخیره شود. | CLIP | بله | - |
| `filename_prefix` | پیشوند مسیر و نام فایل برای فایل(های) ذخیره‌شده. گره یک پسوند مؤلفه (مثلاً `_clip_l`، `_clip_g`) و یک شمارنده به نام فایل اضافه می‌کند تا نام‌های یکتا ایجاد کند (پیش‌فرض: `clip/ComfyUI`). | STRING | بله | - |
| `prompt` | اطلاعات پرامپت گردشکار، که به‌صورت فراداده در فایل خروجی ذخیره می‌شود. این پارامتر در رابط کاربری پنهان است. | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده‌های اضافی، که به‌صورت جفت‌های کلید-مقدار در فایل خروجی ذخیره می‌شود. این پارامتر در رابط کاربری پنهان است. | EXTRA_PNGINFO | خیر | - |

## خروجی‌ها

این گره هیچ اتصال خروجی ندارد. فایل‌های پردازش‌شده را مستقیماً در پوشه `ComfyUI/output/` ذخیره می‌کند. فایل‌های ذخیره‌شده شامل فراداده هستند (فرمت روی «pt» تنظیم شده است، به‌همراه پرامپت گردشکار و هرگونه اطلاعات اضافی PNG) مگر اینکه ComfyUI با آرگومان `--disable-metadata` اجرا شود.

### جزئیات فایل ذخیره‌شده

گره دیکشنری وضعیت مدل CLIP را تجزیه‌وتحلیل می‌کند و برای هر مؤلفه شناسایی‌شده، فایل‌های SafeTensors جداگانه‌ای ذخیره می‌کند. مؤلفه از روی پیشوند کلیدهای پارامتر آن شناسایی می‌شود. پیشوندهای زیر بررسی می‌شوند:

- `clip_l.` (رمزگذار متنی CLIP-L)
- `clip_g.` (رمزگذار متنی CLIP-G)
- `clip_h.` (رمزگذار متنی CLIP-H)
- `t5xxl.` (رمزگذار متنی T5-XXL)
- `pile_t5xl.` (رمزگذار متنی Pile-T5-XL)
- `mt5xl.` (رمزگذار متنی mT5-XL)
- `umt5xxl.` (رمزگذار متنی UMT5-XXL)
- `t5base.` (رمزگذار متنی T5-Base)
- `gemma2_2b.` (رمزگذار متنی Gemma 2 2B)
- `llama.` (رمزگذار متنی LLaMA)
- `hydit_clip.` (رمزگذار متنی Hydit CLIP)
- پیشوند خالی (سایر مؤلفه‌های CLIP)

برای هر مؤلفه شناسایی‌شده، گره فایلی با نام `{filename_prefix}_{counter:05}_.safetensors` ایجاد می‌کند که در آن پیشوند مؤلفه به پیشوند نام فایل اضافه می‌شود (مثلاً `clip/ComfyUI_clip_l_00001_.safetensors`). پیشوند `transformer.` هنگام ذخیره‌سازی از کلیدهای پارامتر حذف می‌شود.
