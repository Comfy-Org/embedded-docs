# حفظ CLIP

تقوم عقدة `CLIPSave` بحفظ نموذج مشفّر النصوص CLIP على القرص بصيغة SafeTensors. صُمّمت لسير عمل دمج النماذج المتقدمة، وتفصل تلقائيًا نموذج CLIP إلى مكوناته الأساسية (مثل CLIP-L أو CLIP-G أو T5XXL) استنادًا إلى البنية الداخلية للنموذج، مع حفظ كل مكوّن في ملف منفصل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المطلوب حفظه. | CLIP | نعم | - |
| `filename_prefix` | المسار البادئ واسم الملف للملفات المحفوظة. تضيف العقدة لاحقة المكوّن (مثل `_clip_l`، `_clip_g`) وعدادًا لإنشاء أسماء ملفات فريدة (الافتراضي: `clip/ComfyUI`). | STRING | نعم | - |
| `prompt` | معلومات سير عمل العقدة، تُحفظ كبيانات وصفية في ملف الإخراج. هذه المعلمة مخفية في الواجهة. | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية، تُحفظ كأزواج مفتاح-قيمة في ملف الإخراج. هذه المعلمة مخفية في الواجهة. | EXTRA_PNGINFO | لا | - |

## المخرجات

لا تمتلك هذه العقدة أي وصلات إخراج. إنها تحفظ الملفات المعالجة مباشرةً في دليل `ComfyUI/output/`.

### تفاصيل الملفات المحفوظة

تقوم العقدة بتحليل قاموس الحالة لنموذج CLIP وحفظ ملفات SafeTensors منفصلة لكل مكوّن يتم اكتشافه. يُعرَّف المكوّن من خلال بادئة مفاتيح معاملاته. وتتحقق العقدة من البادئات التالية، بالترتيب:

- `clip_l.` (مشفّر نصوص CLIP-L)
- `clip_g.` (مشفّر نصوص CLIP-G)
- `clip_h.` (مشفّر نصوص CLIP-H)
- `t5xxl.` (مشفّر نصوص T5-XXL)
- `pile_t5xl.` (مشفّر نصوص Pile-T5-XL)
- `mt5xl.` (مشفّر نصوص mT5-XL)
- `umt5xxl.` (مشفّر نصوص UMT5-XXL)
- `t5base.` (مشفّر نصوص T5-Base)
- `gemma2_2b.` (مشفّر نصوص Gemma 2 2B)
- `llama.` (مشفّر نصوص LLaMA)
- `hydit_clip.` (مشفّر نصوص Hydit CLIP)
- البادئة الفارغة (مكونات CLIP الأخرى)

لكل مكوّن يتم اكتشافه، تنشئ العقدة ملفًا بالاسم `{filename}_{counter:05}_.safetensors` (على سبيل المثال، `ComfyUI_clip_l_00001_.safetensors`)، حيث يتم إلحاق اسم المكوّن ببادئة اسم الملف ويضمن العداد تفرد أسماء الملفات. عند حفظ مكوّن، تتم إزالة البادئة `transformer.` من مفاتيح معاملاته.

تتضمن البيانات الوصفية المكتوبة في كل ملف معلومات سير العمل وأي معلومات PNG إضافية، ما لم يتم تعطيل حفظ البيانات الوصفية باستخدام وسيط سطر الأوامر `--disable-metadata`.
