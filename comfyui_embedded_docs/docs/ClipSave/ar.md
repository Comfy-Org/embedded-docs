# ClipSave

تحفظ عقدة `CLIPSave` نموذج مشفّر النص CLIP على القرص بتنسيق SafeTensors. وهي مصممة لسير عمل دمج النماذج المتقدم، وتفصل تلقائيًا نموذج CLIP إلى مكوناته (مثل CLIP-L أو CLIP-G أو T5XXL) بناءً على البنية الداخلية للنموذج، وتحفظ كل مكوّن في ملف منفصل.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `CLIP` | نموذج CLIP المراد حفظه. | CLIP | نعم | - |
| `بادئة اسم الملف` | مسار البادئة واسم الملف للملفات المحفوظة. تضيف العقدة لاحقة مكوّن (مثل `_clip_l` أو `_clip_g`) وعدادًا لإنشاء أسماء ملفات فريدة (الافتراضي: `clip/ComfyUI`). | STRING | نعم | - |
| `prompt` | معلومات موجه سير العمل، تُحفظ كبيانات وصفية في ملف الإخراج. هذا المعامل مخفي في واجهة المستخدم. | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية، تُحفظ كأزواج مفتاح-قيمة في ملف الإخراج. هذا المعامل مخفي في واجهة المستخدم. | EXTRA_PNGINFO | لا | - |

## المخرجات

لا تحتوي هذه العقدة على وصلات إخراج. تحفظ الملفات المعالجة مباشرة في دليل `ComfyUI/output/`. تتضمن الملفات المحفوظة بيانات وصفية (التنسيق مضبوط على "pt"، بالإضافة إلى موجه سير العمل وأي معلومات PNG إضافية) ما لم يتم تشغيل ComfyUI مع الوسيط `--disable-metadata`.

### تفاصيل الملفات المحفوظة

تحلل العقدة قاموس الحالة لنموذج CLIP وتحفظ ملفات SafeTensors منفصلة لكل مكوّن يتم اكتشافه. يتم تحديد المكوّن من خلال بادئة مفاتيح معاملاته. يتم فحص البادئات التالية:

- `clip_l.` (مشفر النص CLIP-L)
- `clip_g.` (مشفر النص CLIP-G)
- `clip_h.` (مشفر النص CLIP-H)
- `t5xxl.` (مشفر النص T5-XXL)
- `pile_t5xl.` (مشفر النص Pile-T5-XL)
- `mt5xl.` (مشفر النص mT5-XL)
- `umt5xxl.` (مشفر النص UMT5-XXL)
- `t5base.` (مشفر النص T5-Base)
- `gemma2_2b.` (مشفر النص Gemma 2 2B)
- `llama.` (مشفر النص LLaMA)
- `hydit_clip.` (مشفر النص Hydit CLIP)
- بادئة فارغة (مكونات CLIP أخرى)

لكل مكوّن يتم اكتشافه، تنشئ العقدة ملفًا باسم `{filename_prefix}_{counter:05}_.safetensors`، حيث تُلحق بادئة المكوّن ببادئة اسم الملف (مثل `clip/ComfyUI_clip_l_00001_.safetensors`). تتم إزالة البادئة `transformer.` من مفاتيح المعاملات أثناء الحفظ.
