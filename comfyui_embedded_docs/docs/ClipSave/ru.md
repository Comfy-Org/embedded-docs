# Сохранить CLIP

Узел `CLIPSave` сохраняет модель текстового энкодера CLIP на диск в формате SafeTensors. Он предназначен для продвинутых рабочих процессов объединения моделей и автоматически разделяет модель CLIP на её составные части (такие как CLIP-L, CLIP-G или T5XXL) на основе внутренней структуры модели, сохраняя каждый компонент в отдельный файл.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP для сохранения. | CLIP | Да | - |
| `filename_prefix` | Префикс пути и имя файла для сохраняемых файлов. Узел добавляет суффикс компонента (например, `_clip_l`, `_clip_g`) и счётчик для создания уникальных имён файлов (по умолчанию: `clip/ComfyUI`). | STRING | Да | - |
| `prompt` | Информация о промпте рабочего процесса, сохраняемая как метаданные в выходном файле. Этот параметр скрыт в интерфейсе. | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные, сохраняемые в виде пар ключ-значение в выходном файле. Этот параметр скрыт в интерфейсе. | EXTRA_PNGINFO | Нет | - |

## Выходы

Этот узел не имеет выходных соединений. Он сохраняет обработанные файлы непосредственно в каталог `ComfyUI/output/`.

### Подробности о сохраняемых файлах

Узел анализирует словарь состояний модели CLIP и сохраняет отдельные файлы SafeTensors для каждого обнаруженного компонента. Компонент определяется по префиксу его ключей параметров. Узел проверяет следующие префиксы по порядку:

- `clip_l.` (текстовый энкодер CLIP-L)
- `clip_g.` (текстовый энкодер CLIP-G)
- `clip_h.` (текстовый энкодер CLIP-H)
- `t5xxl.` (текстовый энкодер T5-XXL)
- `pile_t5xl.` (текстовый энкодер Pile-T5-XL)
- `mt5xl.` (текстовый энкодер mT5-XL)
- `umt5xxl.` (текстовый энкодер UMT5-XXL)
- `t5base.` (текстовый энкодер T5-Base)
- `gemma2_2b.` (текстовый энкодер Gemma 2 2B)
- `llama.` (текстовый энкодер LLaMA)
- `hydit_clip.` (текстовый энкодер Hydit CLIP)
- Пустой префикс (другие компоненты CLIP)

Для каждого обнаруженного компонента узел создаёт файл с именем `{filename}_{counter:05}_.safetensors` (например, `ComfyUI_clip_l_00001_.safetensors`), где имя компонента добавляется к префиксу имени файла, а счётчик обеспечивает уникальность имён файлов. При сохранении компонента префикс `transformer.` удаляется из его ключей параметров.

Метаданные, записываемые в каждый файл, включают промпт рабочего процесса и любую дополнительную PNG-информацию, если только сохранение метаданных не отключено аргументом командной строки `--disable-metadata`.
