# ClipSave

Узел `CLIPSave` сохраняет модель текстового энкодера CLIP на диск в формате SafeTensors. Он предназначен для продвинутых рабочих процессов слияния моделей и автоматически разделяет модель CLIP на составные части (например, CLIP-L, CLIP-G или T5XXL) в зависимости от внутренней структуры модели, сохраняя каждый компонент в отдельный файл.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP для сохранения. | CLIP | Да | - |
| `префикс_названия_файла` | Префикс пути и имени файла для сохраняемого(-ых) файла(-ов). Узел добавляет суффикс компонента (например, `_clip_l`, `_clip_g`) и счётчик для создания уникальных имён файлов (по умолчанию: `clip/ComfyUI`). | STRING | Да | - |
| `prompt` | Информация о промпте рабочего процесса, сохраняемая в качестве метаданных в выходном файле. Этот параметр скрыт в интерфейсе. | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные, сохраняемые в виде пар «ключ—значение» в выходном файле. Этот параметр скрыт в интерфейсе. | EXTRA_PNGINFO | Нет | - |

## Выходы

Этот узел не имеет выходных соединений. Он сохраняет обработанные файлы непосредственно в каталог `ComfyUI/output/`. Сохранённые файлы включают метаданные (формат задан как «pt», а также промпт рабочего процесса и любые дополнительные PNG-данные), если только ComfyUI не запущен с аргументом `--disable-metadata`.

### Сведения о сохраняемых файлах

Узел анализирует словарь состояний (state dictionary) модели CLIP и сохраняет отдельные файлы SafeTensors для каждого обнаруженного компонента. Компонент определяется по префиксу его ключей параметров. Проверяются следующие префиксы:

- `clip_l.` (текстовый энкодер CLIP-L)
- `clip_g.` (текстовый энкодер CLIP-G)
- `clip_h.` (текстовый энкодер CLIP-H)
- `t5xxl.` (текстовый энкодер T5-XXL)
- `pile_t5xl.` (текстовый энкодер Pile-T5-XL)
- `mt5xl.` (текстовый энкодер mT5-XL)
- `umt5xxl.` (текстовый энкодер UMT5-XXL)
- `t5base.` (текстовый энкодер T5-Base)
- `gemma2_2b.` (текстовый энкодер Gemma 2 2B)
- `llama.` (текстовый энкодер LLaMA)
- `hydit_clip.` (текстовый энкодер Hydit CLIP)
- Пустой префикс (прочие компоненты CLIP)

Для каждого обнаруженного компонента узел создаёт файл с именем `{filename_prefix}_{counter:05}_.safetensors`, где к префиксу имени файла добавляется префикс компонента (например, `clip/ComfyUI_clip_l_00001_.safetensors`). Префикс `transformer.` удаляется из ключей параметров при сохранении.
