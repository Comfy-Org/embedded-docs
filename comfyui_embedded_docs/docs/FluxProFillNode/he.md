# Flux.1 מילוי תמונה

מבצע השלמה (inpainting) לתמונה בהתבסס על מסכה ופרומפט. צומת זה משתמש במודל Flux.1 כדי למלא אזורים בתמונה המכוסים במסכה בהתאם לתיאור הטקסט שסופק, וליצור תוכן חדש התואם לתמונה הסובבת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שעליה יש לבצע השלמה (inpainting) | IMAGE | כן | - |
| `mask` | המסכה שמגדירה אילו אזורים בתמונה יש למלא | MASK | כן | - |
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `prompt_upsampling` | האם לבצע upsampling לפרומפט. אם פעיל, משנה אוטומטית את הפרומפט ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה תוצאה). (ברירת מחדל: false) | BOOLEAN | לא | - |
| `guidance` | עוצמת ההנחיה עבור תהליך יצירת התמונה (ברירת מחדל: 60) | FLOAT | לא | 1.5-100 |
| `steps` | מספר הצעדים עבור תהליך יצירת התמונה (ברירת מחדל: 50) | INT | לא | 15-50 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | לא | 0-18446744073709551615 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output_image` | התמונה שנוצרה, כאשר האזורים המכוסים במסכה מולאו בהתאם לפרומפט | IMAGE |
