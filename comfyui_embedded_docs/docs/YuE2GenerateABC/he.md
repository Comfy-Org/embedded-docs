# YuE2GenerateABC

צומת זה יוצר סימון ABC לשיר בהתבסס על תיאור סגנון ומילים, תוך שימוש במודל טקסט ומילים של YuE2. ניתן לחבר את הפלט `abc` שנוצר לצומת YuE2 Generate Music כדי להפיק אודיו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל ה-YuE2 המשמש להמרת הסגנון והמילים לאסימונים וליצירת סימון ה-ABC. | CLIP | כן | - |
| `style` | טקסט המתאר את הסגנון המוזיקלי של השיר. תומך בקלט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `lyrics` | טקסט המכיל את מילות השיר. תומך בקלט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `seed` | זרע אקראי המשמש ליצירה. שינוי שלו מפיק תוצאות שונות. ברירת מחדל: 0. | INT | כן | 0 עד 18446744073709551615 |
| `mode` | full: יוצר מנגינה ואקורדים; melody: יוצר מנגינה בלבד, מומלץ לגרסאות כיסוי. | COMBO | כן | "full"<br>"melody" |
| `max_abc_tokens` | המספר המרבי של אסימונים שנוצרים עבור סימון ה-ABC. ברירת מחדל: 8192. הגדרה מתקדמת. | INT | כן | 1 עד 20000 |
| `temperature` | שולט באקראיות של האסימונים הנוצרים. ערכים גבוהים יותר מפיקים פלט מגוון יותר. ברירת מחדל: 0.7. הגדרה מתקדמת. | FLOAT | כן | 0.0 עד 5.0 |
| `top_p` | סף דגימת גרעין; רק אסימונים בתוך ההסתברות המצטברת הזו נלקחים בחשבון. ברירת מחדל: 0.9. הגדרה מתקדמת. | FLOAT | כן | 0.01 עד 1.0 |
| `top_k` | מגביל את בחירת האסימונים ל-K האסימונים הסבירים ביותר. ברירת מחדל: 30. הגדרה מתקדמת. | INT | כן | 1 עד 32768 |
| `repetition_penalty` | קנס המוחל על אסימונים חוזרים במהלך היצירה. ברירת מחדל: 1.005. הגדרה מתקדמת. | FLOAT | כן | 0.01 עד 10.0 |
| `penalty_window` | מספר אסימוני ה-ABC האחרונים המשמשים להענשת חזרות. ברירת מחדל: 100. הגדרה מתקדמת. | INT | כן | 1 עד 20000 |
