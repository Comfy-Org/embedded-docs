# إنشاء ABC باستخدام YuE2

هذه العقدة تولّد تدوين ABC لأغنية استنادًا إلى وصف النمط وكلمات الأغاني، باستخدام نموذج YuE2 للنص وكلمات الأغاني. يمكن توصيل المخرج `abc` الناتج بعقدة YuE2 Generate Music لإنتاج الصوت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج YuE2 المستخدم لترميز النمط وكلمات الأغاني وتوليد تدوين ABC. | CLIP | نعم | - |
| `style` | نص يصف النمط الموسيقي للأغنية. | STRING | نعم | - |
| `lyrics` | نص يحتوي على كلمات الأغنية. | STRING | نعم | - |
| `seed` | بذرة عشوائية تُستخدم للتوليد. تغييرها ينتج نتائج مختلفة. الافتراضي: 0. | INT | نعم | 0 to 18446744073709551615 |
| `mode` | full: يولّد اللحن والكوردات؛ melody: يولّد اللحن فقط، ويُوصى به لأغاني الكوفر. | COMBO | نعم | "full"<br>"melody" |
| `max_abc_tokens` | الحد الأقصى لعدد الرموز المولّدة لتدوين ABC. الافتراضي: 8192. | INT | نعم | 1 to 20000 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `abc` | تدوين ABC المولّد للأغنية، ويمكن توصيله بعقدة YuE2 Generate Music. | STRING |
