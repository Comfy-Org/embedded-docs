# إنشاء ABC باستخدام YuE2

هذه العقدة تولّد تدوين ABC لأغنية استنادًا إلى وصف النمط وكلمات الأغاني، باستخدام نموذج YuE2 للنص وكلمات الأغاني. يمكن توصيل المخرج `abc` الناتج بعقدة YuE2 Generate Music لإنتاج الصوت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج YuE2 المستخدم لترميز النمط وكلمات الأغاني وتوليد تدوين ABC. | CLIP | نعم | - |
| `style` | نص يصف النمط الموسيقي للأغنية. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `lyrics` | نص يحتوي على كلمات الأغنية. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `البذرة` | بذرة عشوائية تُستخدم للتوليد. تغييرها ينتج نتائج مختلفة. الافتراضي: 0. | INT | نعم | 0 إلى 18446744073709551615 |
| `الوضع` | full: يولّد اللحن والكوردات؛ melody: يولّد اللحن فقط، ويُوصى به لأغاني الكوفر. | COMBO | نعم | "full"<br>"melody" |
| `max_abc_tokens` | الحد الأقصى لعدد الرموز المولّدة لتدوين ABC. الافتراضي: 8192. إعداد متقدم. | INT | نعم | 1 إلى 20000 |
| `temperature` | يتحكم في عشوائية الرموز المولّدة. القيم الأعلى تنتج مخرجات أكثر تنوعًا. الافتراضي: 0.7. إعداد متقدم. | FLOAT | نعم | 0.0 إلى 5.0 |
| `top_p` | حد أخذ العينات النووي؛ لا تُعتبر إلا الرموز التي تقع احتمالاتها التراكمية ضمن هذا الحد. الافتراضي: 0.9. إعداد متقدم. | FLOAT | نعم | 0.01 إلى 1.0 |
| `top_k` | يقصر اختيار الرموز على أكثر K رموز احتمالًا. الافتراضي: 30. إعداد متقدم. | INT | نعم | 1 إلى 32768 |
| `repetition_penalty` | عقوبة تُطبق على الرموز المتكررة أثناء التوليد. الافتراضي: 1.005. إعداد متقدم. | FLOAT | نعم | 0.01 إلى 10.0 |
| `penalty_window` | عدد رموز ABC الأخيرة المستخدمة لعقاب التكرار. الافتراضي: 100. إعداد متقدم. | INT | نعم | 1 إلى 20000 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `abc` | تدوين ABC المولّد للأغنية، ويمكن توصيله بعقدة YuE2 Generate Music. | STRING |
