# تولید ABC YuE2

این گره برای یک آهنگ بر پایه توضیح سبک و متن ترانه، با استفاده از یک مدل متن‌و‌ترانه YuE2، نشانه‌گذاری ABC تولید می‌کند. خروجی `abc` حاصل را می‌توان به گره YuE2 Generate Music متصل کرد تا صدا تولید شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل YuE2 که برای توکن‌سازی سبک و متن ترانه و تولید نشانه‌گذاری ABC استفاده می‌شود. | CLIP | بله | - |
| `style` | متن توصیف‌کننده سبک موسیقی آهنگ. | STRING | بله | - |
| `lyrics` | متن حاوی ترانهٔ آهنگ. | STRING | بله | - |
| `seed` | بذر تصادفی مورد استفاده برای تولید. تغییر آن نتایج متفاوتی ایجاد می‌کند. پیش‌فرض: 0. | INT | بله | 0 تا 18446744073709551615 |
| `mode` | full: ملودی و آکوردها را تولید می‌کند؛ melody: فقط ملودی را تولید می‌کند و برای کاورها توصیه می‌شود. | COMBO | بله | "full"<br>"melody" |
| `max_abc_tokens` | حداکثر تعداد توکن‌های تولیدشده برای نشانه‌گذاری ABC. پیش‌فرض: 8192. | INT | بله | 1 تا 20000 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `abc` | نشانه‌گذاری ABC تولیدشده برای آهنگ، که می‌توان آن را به گره YuE2 Generate Music متصل کرد. | STRING |
