# تولید ABC YuE2

این گره برای یک آهنگ بر پایه توضیح سبک و متن ترانه، با استفاده از یک مدل متن‌و‌ترانه YuE2، نشانه‌گذاری ABC تولید می‌کند. خروجی `abc` حاصل را می‌توان به گره YuE2 Generate Music متصل کرد تا صدا تولید شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل YuE2 که برای توکن‌سازی سبک و متن ترانه و تولید نشانه‌گذاری ABC استفاده می‌شود. | CLIP | بله | - |
| `style` | متن توصیف‌کننده سبک موسیقی آهنگ. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `lyrics` | متن حاوی ترانهٔ آهنگ. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `بذر` | بذر تصادفی مورد استفاده برای تولید. تغییر آن نتایج متفاوتی ایجاد می‌کند. پیش‌فرض: 0. | INT | بله | 0 تا 18446744073709551615 |
| `حالت` | full: ملودی و آکوردها را تولید می‌کند؛ melody: فقط ملودی را تولید می‌کند و برای کاورها توصیه می‌شود. | COMBO | بله | "full"<br>"melody" |
| `max_abc_tokens` | حداکثر تعداد توکن‌های تولیدشده برای نشانه‌گذاری ABC. پیش‌فرض: 8192. تنظیم پیشرفته. | INT | بله | 1 تا 20000 |
| `temperature` | تصادفی بودن توکن‌های تولیدشده را کنترل می‌کند. مقادیر بالاتر خروجی متنوع‌تری تولید می‌کنند. پیش‌فرض: 0.7. تنظیم پیشرفته. | FLOAT | بله | 0.0 تا 5.0 |
| `top_p` | آستانه نمونه‌گیری nucleus؛ فقط توکن‌هایی که احتمال تجمعی‌شان در این آستانه است در نظر گرفته می‌شوند. پیش‌فرض: 0.9. تنظیم پیشرفته. | FLOAT | بله | 0.01 تا 1.0 |
| `top_k` | انتخاب توکن‌ها را به K توکن محتمل‌تر محدود می‌کند. پیش‌فرض: 30. تنظیم پیشرفته. | INT | بله | 1 تا 32768 |
| `repetition_penalty` | جریمه‌ای که در طول تولید به توکن‌های تکراری اعمال می‌شود. پیش‌فرض: 1.005. تنظیم پیشرفته. | FLOAT | بله | 0.01 تا 10.0 |
| `penalty_window` | تعداد توکن‌های ABC اخیر استفاده‌شده برای جریمه تکرار. پیش‌فرض: 100. تنظیم پیشرفته. | INT | بله | 1 تا 20000 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `abc` | نشانه‌گذاری ABC تولیدشده برای آهنگ، که می‌توان آن را به گره YuE2 Generate Music متصل کرد. | STRING |
