# YuE2: создать ABC

Этот узел генерирует ABC-нотацию для песни на основе описания стиля и слов песни, используя модель YuE2 text-and-lyrics. Полученный выход `abc` можно подключить к узлу YuE2 Generate Music для создания аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель YuE2, используемая для токенизации стиля и слов песни и генерации ABC-нотации. | CLIP | Да | - |
| `style` | Текст, описывающий музыкальный стиль песни. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `lyrics` | Текст, содержащий слова песни. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `seed` | Случайное зерно, используемое для генерации. Его изменение приводит к другим результатам. По умолчанию: 0. | INT | Да | 0 до 18446744073709551615 |
| `режим` | full: генерирует мелодию и аккорды; melody: генерирует только мелодию, рекомендуется для каверов. | COMBO | Да | "full"<br>"melody" |
| `max_abc_tokens` | Максимальное количество токенов, генерируемых для ABC-нотации. По умолчанию: 8192. Дополнительная настройка. | INT | Да | 1 до 20000 |
| `temperature` | Управляет степенью случайности генерируемых токенов. Более высокие значения дают более разнообразный результат. По умолчанию: 0.7. Дополнительная настройка. | FLOAT | Да | от 0.0 до 5.0 |
| `top_p` | Порог nucleus-сэмплирования; учитываются только токены с накопленной вероятностью в пределах этого порога. По умолчанию: 0.9. Дополнительная настройка. | FLOAT | Да | от 0.01 до 1.0 |
| `top_k` | Ограничивает выбор токенов K наиболее вероятными. По умолчанию: 30. Дополнительная настройка. | INT | Да | от 1 до 32768 |
| `repetition_penalty` | Штраф, применяемый к повторяющимся токенам во время генерации. По умолчанию: 1.005. Дополнительная настройка. | FLOAT | Да | от 0.01 до 10.0 |
| `penalty_window` | Количество последних ABC-токенов, используемых для штрафования повторов. По умолчанию: 100. Дополнительная настройка. | INT | Да | от 1 до 20000 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `abc` | Сгенерированная ABC-нотация песни, которую можно подключить к узлу YuE2 Generate Music. | STRING |
