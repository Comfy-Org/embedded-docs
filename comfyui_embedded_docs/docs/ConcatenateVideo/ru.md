# ConcatenateVideo

Объединяет несколько видеосегментов в одно видео, сохраняя порядок их подключения. Совместимые кодированные входы объединяются без декодирования, а также можно подать отдельную необязательную аудиодорожку для замены исходного звука.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `videos` | Видеосегменты для объединения в порядке подключения на входе. Подключите от 1 до 100 видео; каждое видео отображается как отдельный входной слот с именем `video_1`, `video_2` и т. д. | VIDEO | Да | от 1 до 100 сегментов |
| `codec` | Кодек, используемый для кодирования видеотензоров. При значении `"auto"` используется H.264; совместимые уже закодированные входные данные остаются без изменений. По умолчанию: `"auto"` | COMBO | Да | `"auto"`<br>Другие варианты определяются доступными типами видеокодеков. |
| `complete_audio` | Необязательная полная аудиодорожка для объединённого видео. Переопределяет аудио, содержащееся во входных видео. | AUDIO | Нет | Н/Д |

**Примечание:** Вход `videos` принимает от 1 до 100 видеосегментов. Если указан `complete_audio`, он заменяет аудио всех входных видео. Когда для `codec` задано значение `"auto"`, совместимые кодированные входы объединяются без декодирования.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Объединённое видео. | VIDEO |
