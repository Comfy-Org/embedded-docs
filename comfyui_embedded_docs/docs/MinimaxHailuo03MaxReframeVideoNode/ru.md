# MiniMax H3 Max Reframe Video

Этот узел адаптирует видео к новому соотношению сторон, размещая его на новом холсте и генерируя окружающие области. Тайминг и звук исходного видео сохраняются. Используйте его, чтобы превратить горизонтальный клип в вертикальный или наоборот без обрезки объекта за пределами кадра.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель для генерации видео. | DYNAMIC_COMBO | Да | "MiniMax H3 Max" |

### Входы MiniMax H3 Max

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Исходное видео для перекадрирования длительностью от 0,5 до 300 секунд. | VIDEO | Да | 0.5 до 300 секунд |
| `aspect_ratio` | Соотношение сторон выходного холста (по умолчанию: "9:16"). | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9"<br>"9:21" |
| `resolution` | Разрешение выходного видео (по умолчанию: "768P"). | COMBO | Да | "480P"<br>"768P"<br>"1080P" |
| `prompt` | Необязательное указание для генерируемых окружающих областей. | STRING | Да | 0 до 50000 символов |
| `seed` | Случайное зерно. Одинаковый запрос с одинаковым seed даёт похожие, но не гарантированно идентичные результаты (по умолчанию: 42). | INT | Да | 0 до 4294967295 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Видео после перекадрирования с выбранным соотношением сторон. | VIDEO |
