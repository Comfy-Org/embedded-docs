# EmptyCosmosLatentVideo

Узел EmptyCosmosLatentVideo создает пустой тензор латентного видео с заданными размерами. Он генерирует заполненное нулями латентное представление, которое можно использовать в качестве отправной точки для рабочих процессов генерации видео, с настраиваемыми параметрами ширины, высоты, длины и размера пакета. Пространственные размеры латентного тензора уменьшаются в 8 раз.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина латентного видео в пикселях (по умолчанию: 1280, должно быть кратно 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота латентного видео в пикселях (по умолчанию: 704, должно быть кратно 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в латентном видео (по умолчанию: 121, должно быть кратно 8) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество латентных видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 to 4096 |

Латентный тензор использует 16 каналов. Пространственные размеры делятся на 8 по сравнению с размерами в пикселях (height // 8, width // 8), а количество кадров сжимается до ((length - 1) // 8) + 1 латентных кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный пустой тензор латентного видео с нулевыми значениями. Форма: (batch_size, 16, ((length - 1) // 8) + 1, height // 8, width // 8) | LATENT |
