# EmptyCosmosLatentVideo

EmptyCosmosLatentVideo создает пустой латентный видеотензор с заданными размерами. Он генерирует заполненное нулями латентное представление, которое может использоваться в качестве отправной точки для рабочих процессов генерации видео, с настраиваемыми параметрами ширины, высоты, длины и размера пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ширина` | Ширина латентного видео в пикселях (по умолчанию: 1280, шаг 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота латентного видео в пикселях (по умолчанию: 704, шаг 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в латентном видео (по умолчанию: 121, шаг 8) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество латентных видео для генерации в одном пакете (по умолчанию: 1) | INT | Нет | 1 до 4096 |

Примечание: Латентный тензор пространственно уменьшен в 8 раз по высоте и ширине и содержит 16 каналов. Количество временных кадров латентного представления вычисляется по формуле `((length - 1) // 8) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `samples` | Сгенерированный пустой латентный видеотензор с нулевыми значениями | LATENT |
