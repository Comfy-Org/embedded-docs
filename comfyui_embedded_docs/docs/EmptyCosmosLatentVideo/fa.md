# ویدیوی نهفته Cosmos خالی

گره EmptyCosmosLatentVideo یک تانسور ویدیوی نهفته خالی با ابعاد مشخص ایجاد می‌کند. این گره یک نمایش نهفته پر از صفر تولید می‌کند که می‌تواند به‌عنوان نقطه شروع برای گردش‌های کاری تولید ویدیو استفاده شود و پارامترهای عرض، ارتفاع، طول و اندازه دسته را قابل تنظیم می‌کند. ابعاد فضایی نهفته با ضریب ۸ کاهش می‌یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | عرض ویدیوی نهفته بر حسب پیکسل (پیش‌فرض: 1280، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی نهفته بر حسب پیکسل (پیش‌فرض: 704، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌ها در ویدیوی نهفته (پیش‌فرض: 121، باید بر 8 بخش‌پذیر باشد) | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهای نهفته که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 to 4096 |

تانسور نهفته از ۱۶ کانال استفاده می‌کند. ابعاد فضایی در مقایسه با ابعاد پیکسلی بر ۸ تقسیم می‌شوند (height // 8, width // 8)، و تعداد فریم‌ها به ((length - 1) // 8) + 1 فریم نهفته فشرده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | تانسور ویدیوی نهفته خالی تولیدشده با مقادیر صفر. شکل: (batch_size, 16, ((length - 1) // 8) + 1, height // 8, width // 8) | LATENT |
