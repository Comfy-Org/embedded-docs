# וידאו latent ריק של Cosmos

EmptyCosmosLatentVideo יוצר טנזור וידאו לטנטי ריק במידות שצוינו. הוא מייצר ייצוג לטנטי מלא באפסים שיכול לשמש כנקודת התחלה בתהליכי עבודה של יצירת וידאו, עם פרמטרים ניתנים להגדרה של רוחב, גובה, אורך וגודל אצווה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `width` | הרוחב של הווידאו הלטנטי בפיקסלים (ברירת מחדל: 1280, בצעדים של 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | הגובה של הווידאו הלטנטי בפיקסלים (ברירת מחדל: 704, בצעדים של 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו הלטנטי (ברירת מחדל: 121, בצעדים של 8) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הווידאו הלטנטיים ליצירה באצווה (ברירת מחדל: 1) | INT | לא | 1 עד 4096 |

הערה: הטנזור הלטנטי מוקטן מרחבית בפקטור של 8 הן בגובה והן ברוחב, ומכיל 16 ערוצים. מספר הפריימים הזמניים הלטנטיים מחושב כ-`((length - 1) // 8) + 1`.
