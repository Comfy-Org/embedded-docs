# فيديو كوزموس كامن فارغ

`EmptyCosmosLatentVideo` تنشئ موتر فيديو كامنًا فارغًا بالأبعاد المحددة. وتولّد تمثيلًا كامنًا مملوءًا بالأصفار يمكن استخدامه كنقطة بداية لسير عمل توليد الفيديو، مع معاملات قابلة للضبط للعرض والارتفاع والطول وحجم الدفعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `العرض` | عرض الفيديو الكامن بالبكسل (الافتراضي: 1280، الزيادات بمقدار 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الكامن بالبكسل (الافتراضي: 704، الزيادات بمقدار 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `المدة` | عدد الإطارات في الفيديو الكامن (الافتراضي: 121، الزيادات بمقدار 8) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم_الدُفعة` | عدد مقاطع الفيديو الكامنة التي سيتم توليدها في دفعة واحدة (الافتراضي: 1) | INT | لا | 1 إلى 4096 |

ملاحظة: يتم تقليل أبعاد الموتر الكامن مكانيًا بمعامل 8 في كل من الارتفاع والعرض، ويحتوي على 16 قناة. ويُحسب عدد الإطارات الزمنية الكامنة بالمعادلة `((length - 1) // 8) + 1`.
