# فيديو كوزموس كامن فارغ

تنشئ عقدة `EmptyCosmosLatentVideo` موتر فيديو كامنًا فارغًا بأبعاد محددة. تولّد تمثيلًا كامنًا مملوءًا بالأصفار يمكن استخدامه كنقطة بداية لسير عمل توليد الفيديو، مع معاملات قابلة للضبط للعرض والارتفاع والطول وحجم الدفعة. يتم اختزال الأبعاد المكانية للتمثيل الكامن بمعامل قدره 8.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `width` | عرض الفيديو الكامن بالبكسل (الافتراضي: 1280، يجب أن يكون قابلاً للقسمة على 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الكامن بالبكسل (الافتراضي: 704، يجب أن يكون قابلاً للقسمة على 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو الكامن (الافتراضي: 121، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 1 to MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات الكامنة التي سيتم توليدها في دفعة واحدة (الافتراضي: 1) | INT | نعم | 1 to 4096 |

يستخدم الموتر الكامن 16 قناة. تُقسَّم الأبعاد المكانية على 8 مقارنةً بأبعاد البكسل (height // 8, width // 8)، ويتم ضغط عدد الإطارات إلى ((length - 1) // 8) + 1 إطارًا كامنًا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `samples` | موتر الفيديو الكامن الفارغ المُولَّد بقيم صفرية. الشكل: (batch_size, 16, ((length - 1) // 8) + 1, height // 8, width // 8) | LATENT |
