# LTXV 時空引導（STG）

此節點藉由在每個取樣步驟執行一次額外傳遞，提升 LTXV 影片生成的空間細節與動作連貫性。在此傳遞期間，所選 transformer 區塊的自注意力會被降級為 value-passthrough，並引導生成結果遠離該降級後的結果。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要套用時空引導的基礎模型。模型會被複製，並將 post-CFG 引導函式附加到複本上。 | MODEL | 是 | — |
| `scale` | 套用於去噪結果的引導強度。設為 0 時，引導不會產生效果。（預設值：1.0） | FLOAT | 是 | 0.0 至 100.0 （步進值：0.01） |
| `blocks` | 要擾動的 transformer 區塊索引，以逗號分隔。僅會使用數值；其他任何字元都會被忽略。（預設值："29"） | STRING | 是 | — |
| `start_percent` | 引導開始的取樣流程比例。這是進階參數。（預設值：0.0） | FLOAT | 是 | 0.0 至 1.0 （步進值：0.001） |
| `end_percent` | 引導結束的取樣流程比例。這是進階參數。（預設值：1.0） | FLOAT | 是 | 0.0 至 1.0 （步進值：0.001） |

備註：引導只會套用於 `start_percent` 與 `end_percent` 之間的取樣區間。在該區間之外，會原樣傳回去噪後的原始結果。如果 `scale` 為 0，或 `blocks` 不含任何數值，則引導傳遞不會對取樣流程產生影響。
