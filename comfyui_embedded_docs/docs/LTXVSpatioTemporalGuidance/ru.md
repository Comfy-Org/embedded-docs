# LTXV Spatio-Temporal Guidance (STG)

Этот узел улучшает пространственную детализацию и согласованность движения при генерации видео LTXV, выполняя один дополнительный проход на каждом шаге сэмплирования. Во время этого прохода самовнимание выбранных блоков трансформера деградируется до сквозной передачи значения, и генерация направляется в сторону от этого деградированного результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Базовая модель, к которой применяется пространственно-временное управление. Модель клонируется, и к клону прикрепляется функция post-CFG-управления. | MODEL | Да | — |
| `scale` | Сила управления, применяемого к денойзенному результату. При значении 0 управление не оказывает эффекта. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 100.0 (шаг 0.01) |
| `blocks` | Индексы блоков трансформера, разделённые запятыми, которые нужно возмутить. Используются только числовые значения; любые другие символы игнорируются. (по умолчанию: "29") | STRING | Да | — |
| `start_percent` | Доля процесса сэмплирования, с которой начинается управление. Это расширенный параметр. (по умолчанию: 0.0) | FLOAT | Да | от 0.0 до 1.0 (шаг 0.001) |
| `end_percent` | Доля процесса сэмплирования, на которой управление завершается. Это расширенный параметр. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг 0.001) |

Примечание: Управление применяется только в течение интервала сэмплирования между `start_percent` и `end_percent`. Вне этого интервала исходный денойзенный результат возвращается без изменений. Если `scale` равен 0 или `blocks` не содержит числовых значений, проход с управлением не влияет на процесс сэмплирования.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Клонированная модель с прикреплённой функцией пространственно-временного управления. | MODEL |
