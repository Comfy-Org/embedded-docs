# LTXV Spatio-Temporal Guidance (STG)

Этот узел улучшает пространственную детализацию и согласованность движения при генерации видео LTXV, выполняя дополнительный проход на каждом шаге сэмплирования. Во время этого прохода самовнимание выбранных блоков трансформера деградирует до сквозной передачи значений, и генерация уводится от деградировавшего результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Базовая модель, к которой применяется пространственно-временное управление. Модель клонируется и модифицируется функцией управления после CFG. | MODEL | Да | — |
| `scale` | Сила управления, применяемого к результату после шумоподавления. При значении 0 управление не действует. (по умолчанию: 1.0) | FLOAT | Да | 0.0–100.0 (шаг 0.01) |
| `blocks` | Разделенные запятыми индексы блоков трансформера для возмущения. Используются только числовые значения; все остальные символы игнорируются. (по умолчанию: "29") | STRING | Да | — |
| `start_percent` | Доля процесса сэмплирования, с которой начинается управление. Это расширенный параметр. (по умолчанию: 0.0) | FLOAT | Да | 0.0–1.0 (шаг 0.001) |
| `end_percent` | Доля процесса сэмплирования, при которой заканчивается управление. Это расширенный параметр. (по умолчанию: 1.0) | FLOAT | Да | 0.0–1.0 (шаг 0.001) |

Примечание: Управление применяется только во время интервала сэмплирования между `start_percent` и `end_percent`. Если `scale` равен 0 или `blocks` не содержит числовых значений, управляемый проход не влияет на процесс сэмплирования.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Клонированная модель с присоединенной функцией пространственно-временного управления. | MODEL |
