# LTXV Spatio-Temporal Guidance (STG)

נקודת צומת זו משפרת את הפירוט המרחבי ואת קוהרנטיות התנועה של יצירת וידאו LTXV באמצעות הרצת מעבר נוסף בכל שלב דגימה. במהלך מעבר זה, הקשב העצמי של בלוקי ה-transformer הנבחרים מנוון להעברת ערך ישירה, והיצירה מכוונת הרחק מאותה תוצאה מנוונת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל הבסיסי שעליו להחיל הנחיה מרחבית-זמנית. המודל משוכפל ופונקציית הנחיה post-CFG מוצמדת לעותק. | MODEL | כן | — |
| `scale` | עוצמת ההנחיה המוחלת על התוצאה לאחר הסרת רעש. כאשר הערך מוגדר ל-0, להנחיה אין השפעה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 100.0 (צעד 0.01) |
| `blocks` | אינדקסים של בלוקי transformer שיש לשבש, מופרדים בפסיקים. נעשה שימוש רק בערכים מספריים; כל תו אחר מתעלמים ממנו. (ברירת מחדל: "29") | STRING | כן | — |
| `start_percent` | החלק מתהליך הדגימה שבו ההנחיה מתחילה. זהו פרמטר מתקדם. (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 עד 1.0 (צעד 0.001) |
| `end_percent` | החלק מתהליך הדגימה שבו ההנחיה מסתיימת. זהו פרמטר מתקדם. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד 0.001) |

הערה: ההנחיה מוחלת רק במהלך מרווח הדגימה שבין `start_percent` ל-`end_percent`. מחוץ למרווח זה, התוצאה המקורית לאחר הסרת רעש מוחזרת ללא שינוי. אם `scale` הוא 0 או אם `blocks` אינו מכיל ערכים מספריים, למעבר המודרך אין השפעה על תהליך הדגימה.
