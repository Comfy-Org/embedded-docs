# راهنمای فضایی-زمانی LTXV (STG)

این گره با اجرای یک پاس اضافی در هر مرحله نمونه‌برداری، جزئیات فضایی و انسجام حرکت تولید ویدیوی LTXV را بهبود می‌بخشد. در طی این پاس، خودتوجهی بلوک‌های ترنسفورمر انتخاب‌شده به حالت عبور مقدار تنزل می‌یابد و تولید از نتیجهٔ تنزل‌یافته دور می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل پایه برای اعمال هدایت مکانی-زمانی. این مدل کلون شده و با یک تابع هدایت پس از CFG اصلاح می‌شود. | MODEL | بله | — |
| `مقیاس` | میزان قدرت هدایت اعمال‌شده بر نتیجهٔ نویززدایی‌شده. وقتی روی 0 تنظیم شود، هدایت هیچ اثری ندارد. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 100.0 (گام 0.01) |
| `بلوک‌ها` | شاخص‌های بلوک ترنسفورمر برای اختلال، جدا شده با کاما. فقط مقادیر عددی استفاده می‌شوند؛ هر کاراکتر دیگر نادیده گرفته می‌شود. (پیش‌فرض: "29") | STRING | بله | — |
| `درصد شروع` | کسری از فرآیند نمونه‌برداری که هدایت از آنجا آغاز می‌شود. این یک پارامتر پیشرفته است. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.001) |
| `درصد پایان` | کسری از فرآیند نمونه‌برداری که هدایت در آنجا پایان می‌یابد. این یک پارامتر پیشرفته است. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.001) |

توجه: هدایت فقط در بازهٔ نمونه‌برداری بین `start_percent` و `end_percent` اعمال می‌شود. اگر `scale` برابر 0 باشد یا `blocks` حاوی هیچ مقدار عددی نباشد، پاس هدایت‌شده هیچ اثری بر فرآیند نمونه‌برداری ندارد.
