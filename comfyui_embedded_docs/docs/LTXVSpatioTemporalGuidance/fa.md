# راهنمای فضایی-زمانی LTXV (STG)

این گره با اجرای یک پاس اضافی در هر گام نمونه‌گیری، جزئیات فضایی و انسجام حرکتی تولید ویدئوی LTXV را بهبود می‌بخشد. در این پاس، خودتوجهی بلوک‌های ترنسفورمر انتخاب‌شده تا حد عبور مقدار تنزل داده می‌شود و تولید به‌گونه‌ای هدایت می‌شود که از آن نتیجه تنزل‌یافته فاصله بگیرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل پایه‌ای که راهنمایی فضایی-زمانی روی آن اعمال می‌شود. مدل کلون می‌شود و یک تابع راهنمایی پس از CFG به کلون متصل می‌گردد. | MODEL | بله | — |
| `scale` | قدرت راهنمایی اعمال‌شده روی نتیجه نویززدایی‌شده. وقتی روی 0 تنظیم شود، راهنمایی هیچ اثری ندارد. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 100.0 (گام 0.01) |
| `blocks` | اندیس‌های بلوک ترنسفورمر جدا شده با کاما برای اعمال اختلال. فقط مقادیر عددی استفاده می‌شوند؛ هر کاراکتر دیگر نادیده گرفته می‌شود. (پیش‌فرض: "29") | STRING | بله | — |
| `start_percent` | کسر فرایند نمونه‌گیری که راهنمایی از آن آغاز می‌شود. این یک پارامتر پیشرفته است. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.001) |
| `end_percent` | کسر فرایند نمونه‌گیری که راهنمایی در آن پایان می‌یابد. این یک پارامتر پیشرفته است. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.001) |

نکته: راهنمایی فقط در بازه نمونه‌گیری بین `start_percent` و `end_percent` اعمال می‌شود. خارج از آن بازه، نتیجه نویززدایی‌شده اصلی بدون تغییر برگردانده می‌شود. اگر `scale` برابر 0 باشد یا `blocks` هیچ مقدار عددی نداشته باشد، پاس راهنمایی‌شده هیچ اثری بر فرایند نمونه‌گیری ندارد.
