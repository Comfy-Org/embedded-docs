# Flux.1 הרחבת תמונה

מבצע Outpainting לתמונה בהתבסס על פרומפט. צומת זה מרחיב תמונה על ידי הוספת פיקסלים למעלה, למטה, משמאל ומימין, תוך יצירת תוכן חדש שתואם לתיאור הטקסט שסופק.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שיש להרחיב | IMAGE | כן | - |
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: "") | STRING | לא | - |
| `prompt_upsampling` | האם לבצע upsampling לפרומפט. אם פעיל, משנה אוטומטית את הפרומפט ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה תוצאה). (ברירת מחדל: False) | BOOLEAN | לא | - |
| `top` | מספר הפיקסלים להרחבה בחלק העליון של התמונה (ברירת מחדל: 0) | INT | לא | 0-2048 |
| `bottom` | מספר הפיקסלים להרחבה בחלק התחתון של התמונה (ברירת מחדל: 0) | INT | לא | 0-2048 |
| `left` | מספר הפיקסלים להרחבה בצד שמאל של התמונה (ברירת מחדל: 0) | INT | לא | 0-2048 |
| `right` | מספר הפיקסלים להרחבה בצד ימין של התמונה (ברירת מחדל: 0) | INT | לא | 0-2048 |
| `guidance` | עוצמת ההנחיה עבור תהליך יצירת התמונה (ברירת מחדל: 60) | FLOAT | לא | 1.5-100 |
| `steps` | מספר הצעדים עבור תהליך יצירת התמונה (ברירת מחדל: 50) | INT | לא | 15-50 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | לא | 0-18446744073709551615 |
