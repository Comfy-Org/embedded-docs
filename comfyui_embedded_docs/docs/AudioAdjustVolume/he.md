# כוונון עוצמת שמע

צומת AudioAdjustVolume משנה את עוצמת השמע באמצעות החלת התאמות עוצמת קול בדציבלים (dB). הוא מקבל קלט שמע ומחיל מקדם הגבר בהתאם לרמת עוצמת הקול שצוינה, כאשר ערכים חיוביים מגבירים את עוצמת הקול וערכים שליליים מחלישים אותה. הצומת מחזיר את השמע שהשתנה עם אותו קצב דגימה כמו המקורי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `audio` | קלט השמע לעיבוד | AUDIO | כן | - |
| `volume` | התאמת עוצמת קול בדציבלים (dB). 0 = ללא שינוי, +6 = כפול, -6 = חצי וכו' (ברירת מחדל: 1) | INT | כן | -100 עד 100 |
