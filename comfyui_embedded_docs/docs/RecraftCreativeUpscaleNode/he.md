# RecraftCreativeUpscaleNode

צומת Recraft Creative Upscale Image משפר תמונת רסטר על ידי הגדלת הרזולוציה שלה. הוא משתמש בתהליך של "הגדלה יצירתית" המתמקד בשיפור פרטים קטנים ופנים בתוך התמונה. פעולה זו מבוצעת באופן סינכרוני דרך API חיצוני.
