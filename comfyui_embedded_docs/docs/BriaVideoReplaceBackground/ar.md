# استبدال خلفية الفيديو بواسطة Bria

استبدال خلفية فيديو بصورة أو فيديو مُقدَّم باستخدام Bria. يحافظ الإخراج على دقة المقدمة ومعدل إطاراتها؛ ويتم تمديد الخلفية ذات نسبة العرض إلى الارتفاع المختلفة لتلائم الإطار، لذا قم بمطابقتها للحصول على نتائج غير مشوّهة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `video` | فيديو المقدمة الذي يتم استبدال خلفيته. | VIDEO | نعم | - |
| `background_image` | صورة الخلفية لتركيبها خلف المقدمة. قدّم إما صورة خلفية أو فيديو خلفية، وليس كلاهما. | IMAGE | لا | - |
| `background_video` | فيديو الخلفية لتركيبه خلف المقدمة. قدّم إما صورة خلفية أو فيديو خلفية، وليس كلاهما. | VIDEO | لا | - |
| `seed` | تتحكم البذرة في ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن البذرة. (الافتراضي: 0) | INT | نعم | 0 إلى 2147483647 |

**ملاحظة:** يجب عليك تقديم واحد فقط من `background_image` أو `background_video` — ليس الاثنين معًا، وليس عدم تقديم أي منهما. يجب ألا تتجاوز مدة كل من فيديو المقدمة وفيديو الخلفية 60 ثانية. إذا تم توفير صورة خلفية، فسيتم إزالة قناة ألفا (الشفافية) الخاصة بها قبل الرفع.
