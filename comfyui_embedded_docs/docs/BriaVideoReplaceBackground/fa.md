# Bria جایگزینی پس‌زمینه ویدیو

این گره پس‌زمینه یک ویدیو را با یک تصویر یا ویدیوی ارائه‌شده با استفاده از API بریا جایگزین می‌کند. خروجی، وضوح و نرخ فریم ویدیوی پیش‌زمینه را حفظ می‌کند؛ پس‌زمینه‌ای با نسبت تصویر متفاوت برای تطبیق کشیده می‌شود، بنابراین تطبیق نسبت‌های تصویر نتایج بدون اعوجاج تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | ویدیوی پیش‌زمینه که پس‌زمینه آن جایگزین می‌شود. | VIDEO | بله | - |
| `تصویر پس‌زمینه` | تصویر پس‌زمینه‌ای که پشت پیش‌زمینه ترکیب می‌شود. یا یک تصویر پس‌زمینه ارائه دهید یا یک ویدیوی پس‌زمینه، نه هر دو. | IMAGE | خیر | - |
| `ویدیوی پس‌زمینه` | ویدیوی پس‌زمینه‌ای که پشت پیش‌زمینه ترکیب می‌شود. یا یک تصویر پس‌زمینه ارائه دهید یا یک ویدیوی پس‌زمینه، نه هر دو. | VIDEO | خیر | - |
| `seed` | seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |

**توجه:** باید دقیقاً یکی از `background_image` یا `background_video` را ارائه دهید — نه هر دو و نه هیچ‌کدام. ویدیوی پیش‌زمینه و ویدیوی پس‌زمینه (در صورت استفاده) هر کدام باید 60 ثانیه یا کوتاه‌تر باشند. هنگام استفاده از `background_image`، کانال آلفای آن قبل از پردازش حذف می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی حاصل با پس‌زمینه جایگزین‌شده که به‌صورت MP4 (H.264) رمزگذاری می‌شود. | VIDEO |
