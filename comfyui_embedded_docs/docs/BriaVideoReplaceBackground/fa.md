# Bria جایگزینی پس‌زمینه ویدیو

با استفاده از Bria، پس‌زمینه یک ویدیو را با تصویر یا ویدیوی ارائه‌شده جایگزین کنید. خروجی، وضوح و نرخ فریم پیش‌زمینه را حفظ می‌کند؛ پس‌زمینه‌ای با نسبت ابعاد متفاوت برای تطبیق کشیده می‌شود، بنابراین برای نتیجه‌ای بدون اعوجاج، آن را هماهنگ کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | ویدیوی پیش‌زمینه که پس‌زمینه آن جایگزین می‌شود. | VIDEO | بله | - |
| `background_image` | تصویر پس‌زمینه برای ترکیب پشت پیش‌زمینه. یا یک تصویر پس‌زمینه یا یک ویدیوی پس‌زمینه ارائه دهید، نه هر دو. | IMAGE | خیر | - |
| `background_video` | ویدیوی پس‌زمینه برای ترکیب پشت پیش‌زمینه. یا یک تصویر پس‌زمینه یا یک ویدیوی پس‌زمینه ارائه دهید، نه هر دو. | VIDEO | خیر | - |
| `seed` | سید (Seed) کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید، غیرقطعی هستند. (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |

**نکته:** باید دقیقاً یکی از `background_image` یا `background_video` را ارائه دهید — نه هر دو و نه هیچ‌کدام. هر دو ویدیوی پیش‌زمینه و پس‌زمینه باید ۶۰ ثانیه یا کوتاه‌تر باشند. اگر تصویر پس‌زمینه ارائه شود، کانال آلفا (شفافیت) آن قبل از بارگذاری حذف می‌شود.
