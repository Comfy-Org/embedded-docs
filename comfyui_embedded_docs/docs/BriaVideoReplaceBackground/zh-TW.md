# Bria 影片更換背景

此節點使用 Bria 的 API，以提供的圖片或影片取代影片的背景。輸出會保留前景影片的解析度與影格率；寬高比不同的背景會被拉伸以符合，因此使用相同的寬高比可產生不變形的結果。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 前景影片，其背景將被替換。 | VIDEO | 是 | - |
| `背景圖片` | 合成至前景後方的背景圖片。請提供背景圖片或背景影片，兩者擇一，不可同時提供。 | IMAGE | 否 | - |
| `背景影片` | 合成至前景後方的背景影片。請提供背景圖片或背景影片，兩者擇一，不可同時提供。 | VIDEO | 否 | - |
| `種子` | 種子控制節點是否應重新執行；無論種子為何，結果皆為非確定性。（預設值：0） | INT | 是 | 0 至 2147483647 |

**注意：** 您必須確實提供 `background_image` 或 `background_video` 其中一項——不可兩者皆提供，也不可兩者皆不提供。前景影片與背景影片（若使用）各不得超過 60 秒。當使用 `background_image` 時，其 Alpha 通道會在處理前被移除。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `video` | 替換背景後產生的影片，編碼為 MP4（H.264）。 | VIDEO |
