# Bria Video Замена Фона

Замените фон видео на указанное изображение или видео с помощью Bria. Выходной файл сохраняет разрешение и частоту кадров переднего плана; фоновое изображение с другим соотношением сторон растягивается под размер, поэтому подбирайте его для получения неискажённого результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `video` | Основное видео, у которого заменяется фон. | VIDEO | Да | - |
| `background_image` | Фоновое изображение для наложения позади переднего плана. Укажите либо фоновое изображение, либо фоновое видео, но не оба. | IMAGE | Нет | - |
| `background_video` | Фоновое видео для наложения позади переднего плана. Укажите либо фоновое изображение, либо фоновое видео, но не оба. | VIDEO | Нет | - |
| `seed` | Сид (seed) управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

**Примечание:** Необходимо указать ровно один из параметров `background_image` или `background_video` — не оба и не ни одного. Продолжительность как основного, так и фонового видео должна составлять не более 60 секунд. Если указано фоновое изображение, его альфа-канал (прозрачность) удаляется перед загрузкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `video` | Результирующее видео с заменённым фоном. | VIDEO |
