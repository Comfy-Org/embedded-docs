# Bria Video Замена Фона

Этот узел заменяет фон видео на предоставленное изображение или видео с помощью API Bria. Выходное видео сохраняет разрешение и частоту кадров переднего плана; фон с другим соотношением сторон растягивается для соответствия, поэтому совпадение соотношений сторон обеспечивает неискажённый результат.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Видео переднего плана, у которого заменяется фон. | VIDEO | Да | - |
| `фон-изображение` | Изображение фона для компоновки позади переднего плана. Укажите либо фоновое изображение, либо фоновое видео, но не оба. | IMAGE | Нет | - |
| `фон-видео` | Фоновое видео для компоновки позади переднего плана. Укажите либо фоновое изображение, либо фоновое видео, но не оба. | VIDEO | Нет | - |
| `seed` | Управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

**Примечание:** Необходимо указать ровно один из параметров `background_image` или `background_video` — но не оба и не ни одного. Видео переднего плана и фоновое видео (если используется) должны быть длительностью не более 60 секунд. При использовании `background_image` его альфа-канал удаляется перед обработкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Итоговое видео с заменённым фоном, закодированное как MP4 (H.264). | VIDEO |
