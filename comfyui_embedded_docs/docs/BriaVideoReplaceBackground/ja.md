# Bria ビデオ背景置換

Briaを使用して、動画の背景を指定した画像または動画に置き換えます。出力は前景の解像度とフレームレートが維持されます。アスペクト比が異なる背景はフィットするように引き伸ばされるため、歪みのない結果を得るには背景を前景に合わせてください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `video` | 背景が置き換えられる前景動画。 | VIDEO | はい | - |
| `background_image` | 前景の背後に合成する背景画像。背景画像または背景動画のどちらか一方を指定してください。両方は指定できません。 | IMAGE | いいえ | - |
| `background_video` | 前景の背後に合成する背景動画。背景画像または背景動画のどちらか一方を指定してください。両方は指定できません。 | VIDEO | いいえ | - |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。（デフォルト：0） | INT | はい | 0 から 2147483647 |

**注意：** `background_image` または `background_video` のいずれか一方を正確に指定する必要があります。両方の指定はできず、どちらも指定しないこともできません。前景動画と背景動画はどちらも60秒以下である必要があります。背景画像を指定する場合、アップロード前にそのアルファ（透明度）チャンネルは削除されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 背景が置き換えられた結果の動画。 | VIDEO |
