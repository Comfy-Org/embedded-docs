# التعبئة التوليدية من Bria

تولّد هذه العقدة كائنات أو مشاهد داخل منطقة مقنّعة من صورة باستخدام Bria. وتحمّل الصورة والقناع، وترسل المطالبة إلى خدمة التعبئة التوليدية من Bria، وتنتظر اكتمال العملية، ثم تعيد الصورة المحرّرة. هذه عملية API مدفوعة (0.0429 دولار أمريكي لكل طلب).

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المُدخلة المراد تحريرها. | IMAGE | نعم | - |
| `mask` | تُملأ المناطق البيضاء بالمحتوى المولّد، بينما يتم الحفاظ على المناطق السوداء. يتم تحويل القناع إلى قيم ثنائية قبل الإرسال، لذا تُحتسب المناطق الملوّنة جزئيًا كمناطق بيضاء. يجب أن تكون له نسبة العرض إلى الارتفاع نفسها للصورة. | MASK | نعم | - |
| `prompt` | وصف لما يجب توليده داخل المنطقة المقنّعة. يجب أن يحتوي على حرف واحد على الأقل. (الافتراضي: "") | STRING | نعم | - |
| `negative_prompt` | وصف نصي للمحتوى الذي يجب تجنّبه في النتيجة المولّدة. إذا تُرك فارغًا، فلن يُرسل إلى API. (الافتراضي: "") | STRING | نعم | - |
| `refine_prompt` | ضبط المطالبة تلقائيًا للحصول على نتائج أفضل؛ عطّله لاستخدام المطالبة كما كُتبت تمامًا. (الافتراضي: true) | BOOLEAN | نعم | true<br>false |
| `seed` | البذرة الخاصة بعملية التوليد. (الافتراضي: 42) | INT | نعم | 1 إلى 2147483647 |
| `الإشراف` | إعدادات الإشراف. عند ضبطها على "true"، يتم تطبيق خيارات الإشراف أدناه. (الافتراضي: "false") | DYNAMIC_COMBO | نعم | "false"<br>"true" |

### مدخلات الإشراف (عندما `moderation` = "true")

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | يطبّق إشراف المحتوى على المطالبة. (الافتراضي: false) | BOOLEAN | لا | true<br>false |
| `visual_input_moderation` | يطبّق إشراف المحتوى على الصورة المُدخلة. (الافتراضي: false) | BOOLEAN | لا | true<br>false |
| `visual_output_moderation` | يطبّق إشراف المحتوى على الصورة الناتجة. (الافتراضي: false) | BOOLEAN | لا | true<br>false |

**ملاحظة:** يجب ألا تكون قيمة `prompt` فارغة. يجب أن تكون نسبة العرض إلى الارتفاع للقناع `mask` مطابقة لنسبة الصورة `image`. يتم تحويل القناع إلى قيم ثنائية عند عتامة 50%، لذا تُتجاهل المناطق المرسومة بعتامة أقل من النصف؛ وإذا لم يحتوِ القناع على مناطق بيضاء بعد التحويل الثنائي، فسوف تُطلق العقدة خطأً.
