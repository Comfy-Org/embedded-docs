# BriaGenFill

تولّد هذه العقدة كائنات أو مشاهد داخل منطقة مقنعة من الصورة باستخدام واجهة برمجة تطبيقات Bria. تقوم برفع الصورة والقناع، وترسل الموجّه إلى خدمة الملء التوليدي من Bria، وتنتظر اكتمال العملية، ثم تعيد الصورة المعدّلة. هذه عملية مدفوعة عبر واجهة برمجة التطبيقات (0.0429 دولارًا أمريكيًا لكل طلب).

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المراد تعديلها. | IMAGE | نعم | - |
| `mask` | تُملأ المناطق البيضاء بمحتوى مولّد، بينما تُحفظ المناطق السوداء. يتم تحويل القناع إلى ثنائي قبل الإرسال، لذا تُعتبر المناطق المطلية جزئيًا بيضاء. يجب أن تكون نسبة العرض إلى الارتفاع للقناع مطابقة لنسبة العرض إلى الارتفاع للصورة. | MASK | نعم | - |
| `prompt` | وصف لما سيتم توليده داخل المنطقة المقنعة. يجب أن يحتوي على حرف واحد على الأقل. | STRING | نعم | - |
| `negative_prompt` | موجّه يصف المحتوى الذي يجب تجنبه في النتيجة المولدة. إذا تُرك فارغًا، فلن يتم إرساله إلى الواجهة. | STRING | نعم | - |
| `refine_prompt` | اضبط الموجّه تلقائيًا للحصول على نتائج أفضل؛ عطّله لاستخدام الموجّه كما هو مكتوب تمامًا. (الافتراضي: true) | BOOLEAN | نعم | true<br>false |
| `seed` | القيمة الأساسية لعملية التوليد. (الافتراضي: 42) | INT | نعم | 1 إلى 2147483647 |
| `moderation` | إعدادات المراقبة للطلب. عند الضبط على "true"، يتم تطبيق خيارات المراقبة المتداخلة الموصوفة أدناه. (الافتراضي: "false") | COMBO | نعم | "false"<br>"true" |

ملاحظة: يجب ألا يكون `prompt` فارغًا، ويجب أن تكون نسبة العرض إلى الارتفاع للقناع `mask` مطابقة لنسبة العرض إلى الارتفاع للصورة `image`.

عندما يتم ضبط `moderation` على "true"، تتوفر الخيارات المنطقية المتداخلة التالية:
- `prompt_content_moderation` (الافتراضي: false): يطبّق مراقبة المحتوى على الموجّه.
- `visual_input_moderation` (الافتراضي: false): يطبّق مراقبة المحتوى على الصورة المدخلة.
- `visual_output_moderation` (الافتراضي: false): يطبّق مراقبة المحتوى على الصورة المخرجة.
