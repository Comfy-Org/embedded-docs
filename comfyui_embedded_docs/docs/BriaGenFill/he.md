# BriaGenFill

צומת זה יוצר אובייקטים או נוף בתוך אזור ממוסך בתמונה באמצעות Bria. הוא מעלה את התמונה והמסכה, שולח את הפרומפט לשירות המילוי הגנרטיבי של Bria, ממתין להשלמת הפעולה ומחזיר את התמונה שנערכה. זוהי פעולת API בתשלום (US$0.0429 לבקשה).

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט לעריכה. | IMAGE | כן | - |
| `mask` | אזורים לבנים ממולאים בתוכן שנוצר, ואזורים שחורים נשמרים. המסכה עוברת בינאריזציה לפני השליחה עם חיתוך של 50%: רק אזורים שצוירו באטימות מעל 50% נחשבים ללבנים. חייבת להיות בעלת יחס רוחב-גובה זהה לזה של התמונה. | MASK | כן | - |
| `prompt` | תיאור של מה ליצור בתוך האזור הממוסך. חייב להכיל לפחות תו אחד. (ברירת מחדל: "") | STRING | כן | - |
| `negative_prompt` | פרומפט המתאר תוכן שיש להימנע ממנו בתוצאה הנוצרת. אם נשאר ריק, הוא אינו נשלח ל-API. (ברירת מחדל: "") | STRING | כן | - |
| `refine_prompt` | התאם אוטומטית את הפרומפט לתוצאות טובות יותר; השבת כדי להשתמש בפרומפט בדיוק כפי שנכתב. (ברירת מחדל: true) | BOOLEAN | כן | true<br>false |
| `seed` | Seed עבור תהליך היצירה. (ברירת מחדל: 42) | INT | כן | 1 to 2147483647 |
| `moderation` | הגדרות מודרציה. כאשר הערך מוגדר ל-"true", אפשרויות המודרציה שלהלן מוחלות. (ברירת מחדל: "false") | DYNAMIC_COMBO | כן | "false"<br>"true" |

### קלטי מודרציה (כאשר `moderation` = "true")

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | מפעיל מודרציית תוכן על הפרומפט. (ברירת מחדל: false) | BOOLEAN | לא | true<br>false |
| `visual_input_moderation` | מפעיל מודרציית תוכן על תמונת הקלט. (ברירת מחדל: false) | BOOLEAN | לא | true<br>false |
| `visual_output_moderation` | מפעיל מודרציית תוכן על תמונת הפלט. (ברירת מחדל: false) | BOOLEAN | לא | true<br>false |

**הערה:** ה-`prompt` לא יכול להיות ריק. ה-`mask` חייב להיות בעל יחס רוחב-גובה זהה לזה של ה-`image`. ה-`mask` עובר בינאריזציה באטימות של 50%, כך שאזורים שצוירו באטימות נמוכה מחצי מתעלמים מהם; אם ה-`mask` אינו מכיל אזורים לבנים לאחר הבינאריזציה, הצומת מעלה שגיאה.
