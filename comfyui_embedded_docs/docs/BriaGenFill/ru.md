# BriaGenFill

Этот узел генерирует объекты или сцену внутри замаскированной области изображения с помощью Bria API. Он загружает изображение и маску, отправляет промпт в сервис генеративного заполнения Bria, ожидает завершения операции и возвращает отредактированное изображение. Это платная операция API (0,0429 долл. США за запрос).
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `image` | Входное изображение для редактирования. | IMAGE | Да | - |
| `mask` | Белые области заполняются сгенерированным содержимым, черные области сохраняются. Маска бинаризуется перед отправкой, поэтому частично закрашенные области считаются белыми. Должна иметь то же соотношение сторон, что и изображение. | MASK | Да | - |
| `prompt` | Описание того, что нужно сгенерировать внутри замаскированной области. Должно содержать минимум 1 символ. | STRING | Да | - |
| `negative_prompt` | Промпт, описывающий содержимое, которого следует избегать в сгенерированном результате. Если оставить пустым, не отправляется в API. | STRING | Да | - |
| `refine_prompt` | Автоматически корректировать промпт для лучших результатов; отключите, чтобы использовать промпт точно как написано. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `seed` | Сид (зерно) для процесса генерации. (по умолчанию: 42) | INT | Да | 1 to 2147483647 |
| `moderation` | Настройки модерации для запроса. Если установлено значение "true", применяются вложенные параметры модерации, описанные ниже. (по умолчанию: "false") | DYNAMIC_COMBO | Да | "false"<br>"true" |

### Входы модерации

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt_content_moderation` | применяет модерацию содержимого к промпту. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |
| `visual_input_moderation` | применяет модерацию содержимого к входному изображению. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |
| `visual_output_moderation` | применяет модерацию содержимого к выходному изображению. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `image` | The resulting image with the masked region filled by the generated content. | IMAGE |
