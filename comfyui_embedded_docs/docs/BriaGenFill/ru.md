# BriaGenFill

Этот узел генерирует объекты или сцену внутри замаскированной области изображения с помощью Bria API. Он загружает изображение и маску, отправляет промпт в сервис генеративного заполнения Bria, ожидает завершения операции и возвращает отредактированное изображение. Это платная операция API (0,0429 долл. США за запрос).

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для редактирования. | IMAGE | Да | - |
| `mask` | Белые области заполняются сгенерированным содержимым, черные области сохраняются. Маска бинаризуется перед отправкой, поэтому частично закрашенные области считаются белыми. Должна иметь то же соотношение сторон, что и изображение. | MASK | Да | - |
| `prompt` | Описание того, что нужно сгенерировать внутри замаскированной области. Должно содержать не менее 1 символа. | STRING | Да | - |
| `negative_prompt` | Промпт, описывающий содержимое, которого следует избегать в сгенерированном результате. Если оставить пустым, не отправляется в API. | STRING | Да | - |
| `refine_prompt` | Автоматически корректировать промпт для лучших результатов; отключите, чтобы использовать промпт точно как написано. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `seed` | Сид для процесса генерации. (по умолчанию: 42) | INT | Да | 1 до 2147483647 |
| `moderation` | Настройки модерации для запроса. Если установлено значение "true", применяются вложенные параметры модерации, описанные ниже. (по умолчанию: "false") | COMBO | Да | "false"<br>"true" |

Примечание: `prompt` не должен быть пустым, а `mask` должна иметь то же соотношение сторон, что и `image`.

Когда для `moderation` установлено значение "true", доступны следующие вложенные логические параметры:
- `prompt_content_moderation` (по умолчанию: false): применяет модерацию содержимого к промпту.
- `visual_input_moderation` (по умолчанию: false): применяет модерацию содержимого к входному изображению.
- `visual_output_moderation` (по умолчанию: false): применяет модерацию содержимого к выходному изображению.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Результирующее изображение с замаскированной областью, заполненной сгенерированным содержимым. | IMAGE |
