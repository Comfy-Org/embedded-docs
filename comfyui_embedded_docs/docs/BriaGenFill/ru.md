# Bria Generative Fill

Этот узел генерирует объекты или элементы окружения внутри маскированной области изображения с помощью Bria. Он загружает изображение и маску, отправляет промпт в сервис генеративного заполнения Bria, ожидает завершения операции и возвращает отредактированное изображение. Это платная операция API (US$0.0429 за запрос).

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для редактирования. | IMAGE | Да | - |
| `маска` | Белые области заполняются сгенерированным содержимым, чёрные области сохраняются. Перед отправкой маска бинаризуется, поэтому частично закрашенные области считаются белыми. Должна иметь то же соотношение сторон, что и изображение. | MASK | Да | - |
| `запрос` | Промпт с описанием того, что нужно сгенерировать внутри маскированной области. Должен содержать не менее 1 символа. (по умолчанию: "") | STRING | Да | - |
| `negative_prompt` | Промпт, описывающий содержимое, которого следует избегать в сгенерированном результате. Если оставить пустым, он не отправляется в API. (по умолчанию: "") | STRING | Да | - |
| `refine_prompt` | Автоматически корректировать промпт для лучших результатов; отключите, чтобы использовать промпт точно так, как он написан. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `seed` | Зерно для процесса генерации. (по умолчанию: 42) | INT | Да | 1–2147483647 |
| `модерация` | Настройки модерации. Если установлено значение "true", применяются параметры модерации ниже. (по умолчанию: "false") | DYNAMIC_COMBO | Да | "false"<br>"true" |

### Входы модерации (когда `moderation` = "true")

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | Применяет модерацию содержимого к промпту. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |
| `visual_input_moderation` | Применяет модерацию содержимого к входному изображению. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |
| `visual_output_moderation` | Применяет модерацию содержимого к выходному изображению. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |

**Примечание:** `prompt` не должен быть пустым. `mask` должен иметь то же соотношение сторон, что и `image`. Маска бинаризуется с порогом 50% непрозрачности, поэтому области, закрашенные с непрозрачностью менее 50%, игнорируются; если после бинаризации маска не содержит белых областей, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `image` | Результирующее изображение, в котором маскированная область заполнена сгенерированным содержимым. | IMAGE |
