# Bria 生成塗りつぶし

このノードは、Bria を使用して画像のマスクされた領域内にオブジェクトや風景を生成します。画像とマスクをアップロードし、プロンプトを Bria の生成塗りつぶし（generative fill）サービスに送信し、操作が完了するまで待機して、編集された画像を返します。これは有料の API 操作です（1リクエストあたり US$0.0429）。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 編集する入力画像です。 | IMAGE | はい | - |
| `mask` | 白い領域は生成されたコンテンツで塗りつぶされ、黒い領域は保持されます。マスクは送信前に二値化されるため、部分的に塗られた領域も白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | はい | - |
| `prompt` | マスクされた領域内に生成する内容の説明です。少なくとも 1 文字以上を含む必要があります。（デフォルト: ""） | STRING | はい | - |
| `negative_prompt` | 生成結果に含めたくない内容を記述するプロンプトです。空のままにすると、API に送信されません。（デフォルト: ""） | STRING | はい | - |
| `refine_prompt` | より良い結果を得るためにプロンプトを自動的に調整します。無効にすると、記述されたとおりにプロンプトを使用します。（デフォルト: true） | BOOLEAN | はい | true<br>false |
| `seed` | 生成プロセスのシード値です。（デフォルト: 42） | INT | はい | 1 to 2147483647 |
| `モデレーション` | モデレーション設定です。"true" に設定すると、以下のモデレーションオプションが適用されます。（デフォルト: "false"） | DYNAMIC_COMBO | はい | "false"<br>"true" |

### モデレーション入力（`moderation` = "true" の場合）

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | プロンプトにコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | いいえ | true<br>false |
| `visual_input_moderation` | 入力画像にコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | いいえ | true<br>false |
| `visual_output_moderation` | 出力画像にコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | いいえ | true<br>false |

**注意:** `prompt` は空にできません。`mask` は `image` と同じアスペクト比である必要があります。マスクは 50% の不透明度で二値化されるため、半分未満の不透明度で塗られた領域は無視されます。二値化後にマスクに白い領域が含まれていない場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされた領域が生成されたコンテンツで塗りつぶされた結果画像です。 | IMAGE |
