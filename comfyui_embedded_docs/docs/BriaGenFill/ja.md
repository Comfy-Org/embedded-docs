# BriaGenFill

このノードは、Bria APIを使用して、画像のマスクされた領域内にオブジェクトや風景を生成します。画像とマスクをアップロードし、プロンプトをBria generative fillサービスに送信して、操作の完了を待機し、編集された画像を返します。これは有料のAPI操作です（1リクエストあたりUS$0.0429）。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 編集対象の入力画像。 | IMAGE | はい | - |
| `mask` | 白い領域は生成されたコンテンツで埋められ、黒い領域は保持されます。マスクは送信前に2値化されるため、部分的に塗られた領域は白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | はい | - |
| `prompt` | マスクされた領域内に生成する内容の説明。少なくとも1文字以上含む必要があります。 | STRING | はい | - |
| `negative_prompt` | 生成結果で避けたい内容を説明するプロンプト。空のままにすると、APIに送信されません。 | STRING | はい | - |
| `refine_prompt` | より良い結果を得るためにプロンプトを自動調整します。無効にすると、プロンプトがそのまま使用されます。（デフォルト: true） | BOOLEAN | はい | true<br>false |
| `seed` | 生成プロセスのシード。（デフォルト: 42） | INT | はい | 1 〜 2147483647 |
| `moderation` | リクエストのモデレーション設定。「true」に設定すると、後述のネストされたモデレーションオプションが適用されます。（デフォルト: 「false」） | COMBO | はい | "false"<br>"true" |

注意: `prompt`は空にできません。また、`mask`は`image`と同じアスペクト比である必要があります。マスクは不透明度50%を基準に2値化されるため、半分未満の不透明度で描かれた領域は無視されます。2値化後にマスクに白い領域が含まれない場合、ノードはエラーを発生させます。

`moderation`が「true」に設定されている場合、次のネストされたブールオプションが利用できます：
- `prompt_content_moderation`（デフォルト: false）: プロンプトにコンテンツモデレーションを適用します。
- `visual_input_moderation`（デフォルト: false）: 入力画像にコンテンツモデレーションを適用します。
- `visual_output_moderation`（デフォルト: false）: 出力画像にコンテンツモデレーションを適用します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされた領域が生成されたコンテンツで埋められた結果画像。 | IMAGE |
