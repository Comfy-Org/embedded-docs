# پرکردن مولد Bria

این گره با استفاده از Bria اشیا یا مناظری را درون ناحیه ماسک‌شده یک تصویر تولید می‌کند. تصویر و ماسک را بارگذاری می‌کند، پرامپت را به سرویس پرکردن مولد Bria می‌فرستد، تا تکمیل عملیات صبر می‌کند و تصویر ویرایش‌شده را برمی‌گرداند. این یک عملیات API پرداختی است (US$0.0429 به ازای هر درخواست).

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای ویرایش. | IMAGE | بله | - |
| `mask` | نواحی سفید با محتوای تولیدشده پر می‌شوند و نواحی سیاه حفظ می‌شوند. ماسک پیش از ارسال با آستانه ۵۰٪ باینری می‌شود: فقط نواحی‌ای که با شفافیت بالای ۵۰٪ رنگ‌آمیزی شده‌اند سفید در نظر گرفته می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `prompt` | توضیح آنچه باید درون ناحیه ماسک‌شده تولید شود. باید حداقل ۱ کاراکتر داشته باشد. (پیش‌فرض: "") | STRING | بله | - |
| `negative_prompt` | یک پرامپت که محتوای مورد اجتناب در نتیجه تولیدشده را توصیف می‌کند. اگر خالی بماند، به API ارسال نمی‌شود. (پیش‌فرض: "") | STRING | بله | - |
| `refine_prompt` | پرامپت را به‌طور خودکار برای نتایج بهتر تنظیم می‌کند؛ برای استفاده دقیق از پرامپت همان‌طور که نوشته شده، غیرفعال کنید. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `seed` | Seed برای فرایند تولید. (پیش‌فرض: 42) | INT | بله | 1 تا 2147483647 |
| `moderation` | تنظیمات تعدیل محتوا. وقتی روی "true" تنظیم شود، گزینه‌های تعدیل محتوای زیر اعمال می‌شوند. (پیش‌فرض: "false") | DYNAMIC_COMBO | بله | "false"<br>"true" |

### ورودی‌های تعدیل محتوا (وقتی `moderation` = "true")

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | تعدیل محتوا را روی پرامپت اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |
| `visual_input_moderation` | تعدیل محتوا را روی تصویر ورودی اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |
| `visual_output_moderation` | تعدیل محتوا را روی تصویر خروجی اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |

**توجه:** `prompt` نباید خالی باشد. `mask` باید نسبت ابعاد یکسانی با `image` داشته باشد. ماسک در ۵۰٪ شفافیت باینری می‌شود، بنابراین نواحی‌ای که با شفافیت کمتر از نصف رنگ‌آمیزی شده‌اند نادیده گرفته می‌شوند؛ اگر ماسک پس از باینری‌سازی هیچ ناحیه سفیدی نداشته باشد، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر حاصل با ناحیه ماسک‌شده که با محتوای تولیدشده پر شده است. | IMAGE |
