# پرکردن مولد Bria

این گره با استفاده از Bria اشیا یا صحنه‌هایی را در ناحیه ماسک‌شدهٔ یک تصویر تولید می‌کند. تصویر و ماسک را بارگذاری می‌کند، پرامپت را به سرویس پرکردن مولد Bria می‌فرستد، منتظر تکمیل عملیات می‌ماند و تصویر ویرایش‌شده را برمی‌گرداند. این یک عملیات API پرداختی است (US$0.0429 برای هر درخواست).

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای ویرایش. | IMAGE | بله | - |
| `mask` | نواحی سفید با محتوای تولیدشده پر می‌شوند و نواحی سیاه حفظ می‌شوند. ماسک پیش از ارسال دودویی می‌شود، بنابراین نواحی نیمه‌رنگ‌آمیزی‌شده سفید در نظر گرفته می‌شوند. باید نسبت ابعاد یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `prompt` | توصیف آنچه باید در ناحیه ماسک‌شده تولید شود. باید حداقل ۱ کاراکتر داشته باشد. (پیش‌فرض: "") | STRING | بله | - |
| `negative_prompt` | پرامپتی که محتوایی را توصیف می‌کند که باید در نتیجه تولیدشده از آن پرهیز شود. اگر خالی بماند، به API فرستاده نمی‌شود. (پیش‌فرض: "") | STRING | بله | - |
| `refine_prompt` | پرامپت را برای نتایج بهتر به‌طور خودکار تنظیم می‌کند؛ برای استفاده از پرامپت دقیقاً همان‌طور که نوشته شده، آن را غیرفعال کنید. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `seed` | مقدار seed برای فرایند تولید. (پیش‌فرض: 42) | INT | بله | 1 تا 2147483647 |
| `تعدیل محتوا` | تنظیمات بازبینی محتوا. زمانی که روی "true" تنظیم شود، گزینه‌های بازبینی محتوای زیر اعمال می‌شوند. (پیش‌فرض: "false") | DYNAMIC_COMBO | بله | "false"<br>"true" |

### ورودی‌های بازبینی محتوا (زمانی که `moderation` = "true")

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | بازبینی محتوا را روی پرامپت اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |
| `visual_input_moderation` | بازبینی محتوا را روی تصویر ورودی اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |
| `visual_output_moderation` | بازبینی محتوا را روی تصویر خروجی اعمال می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |

**نکته:** `prompt` نباید خالی باشد. `mask` باید نسبت ابعاد یکسانی با `image` داشته باشد. ماسک در آستانهٔ ۵۰٪ کدری دودویی می‌شود، بنابراین نواحی‌ای که با کدری کمتر از نصف رنگ‌آمیزی شده‌اند نادیده گرفته می‌شوند؛ اگر ماسک پس از دودویی‌سازی هیچ ناحیه سفیدی نداشته باشد، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر حاصل با ناحیه ماسک‌شده که با محتوای تولیدشده پر شده است. | IMAGE |
