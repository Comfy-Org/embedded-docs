# BriaGenFill

این گره با استفاده از API بریا، اشیاء یا صحنه‌هایی را در ناحیه ماسک‌شده یک تصویر تولید می‌کند. تصویر و ماسک را آپلود کرده، پرامپت را به سرویس پر کردن مولد بریا ارسال می‌کند، منتظر تکمیل عملیات می‌ماند و تصویر ویرایش‌شده را بازمی‌گرداند. این یک عملیات پولی API است (۰٫۰۴۲۹ دلار آمریکا به ازای هر درخواست).

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `image` | تصویر ورودی برای ویرایش. | IMAGE | بله | - |
| `mask` | نواحی سفید با محتوای تولیدشده پر می‌شوند و نواحی سیاه حفظ می‌شوند. ماسک قبل از ارسال دودویی می‌شود، بنابراین نواحی که به صورت جزئی رنگ‌آمیزی شده‌اند سفید محسوب می‌شوند. باید نسبت تصویر یکسانی با تصویر داشته باشد. | MASK | بله | - |
| `prompt` | توضیحاتی درباره آنچه باید در ناحیه ماسک‌شده تولید شود. باید حداقل ۱ کاراکتر باشد. | STRING | بله | - |
| `negative_prompt` | پرامپتی که محتوای نامطلوب در نتیجه تولید را توصیف می‌کند. اگر خالی بماند، به API ارسال نمی‌شود. | STRING | بله | - |
| `refine_prompt` | پرامپت را به‌صورت خودکار برای نتایج بهتر تنظیم می‌کند؛ برای استفاده از پرامپت دقیقاً همان‌طور که نوشته شده، آن را غیرفعال کنید. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `seed` | دانه (Seed) برای فرایند تولید. (پیش‌فرض: 42) | INT | بله | 1 تا 2147483647 |
| `moderation` | تنظیمات پالایش محتوا برای درخواست. وقتی روی "true" تنظیم شود، گزینه‌های تو در توی پالایش که در زیر توضیح داده شده‌اند اعمال می‌شوند. (پیش‌فرض: "false") | COMBO | بله | "false"<br>"true" |

توجه: `prompt` نباید خالی باشد و `mask` باید نسبت تصویر یکسانی با `image` داشته باشد. ماسک با آستانه ۵۰٪ کدورت دودویی می‌شود؛ بنابراین نواحی‌ای که با کمتر از نصف کدورت رنگ‌آمیزی شده‌اند نادیده گرفته می‌شوند؛ اگر ماسک پس از دودویی‌سازی هیچ ناحیه سفیدی نداشته باشد، گره خطا برمی‌گرداند.

وقتی `moderation` روی "true" تنظیم شود، گزینه‌های بولی تو در توی زیر در دسترس هستند:
- `prompt_content_moderation` (پیش‌فرض: false): پالایش محتوا را روی پرامپت اعمال می‌کند.
- `visual_input_moderation` (پیش‌فرض: false): پالایش محتوا را روی تصویر ورودی اعمال می‌کند.
- `visual_output_moderation` (پیش‌فرض: false): پالایش محتوا را روی تصویر خروجی اعمال می‌کند.
