# Bria 生成式填充

此節點使用 Bria 在影像的遮罩區域內生成物件或景物。它會上傳影像與遮罩，將提示詞傳送至 Bria 生成式填補服務，等待操作完成，並回傳編輯後的影像。這是付費 API 操作（每筆請求 US$0.0429）。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要編輯的輸入影像。 | IMAGE | 是 | - |
| `遮罩` | 白色區域會填入生成的內容，黑色區域則會保留。遮罩在傳送前會先二值化，因此部分塗抹的區域會視為白色。必須與影像具有相同的長寬比。 | MASK | 是 | - |
| `提示詞` | 描述要在遮罩區域內生成什麼的提示詞。必須至少包含 1 個字元。（預設值：""） | STRING | 是 | - |
| `負面提示詞` | 描述生成結果中要避免內容的提示詞。若留空，則不會傳送至 API。（預設值：""） | STRING | 是 | - |
| `最佳化提示詞` | 自動調整提示詞以獲得更好的結果；停用後會完全依照撰寫的提示詞使用。（預設值：true） | BOOLEAN | 是 | true<br>false |
| `種子` | 生成過程的種子值。（預設值：42） | INT | 是 | 1 至 2147483647 |
| `內容審核` | 審核設定。當設為 "true" 時，會套用下方的審核選項。（預設值："false"） | DYNAMIC_COMBO | 是 | "false"<br>"true" |

### 審核輸入（當 `moderation` = "true" 時）

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 對提示詞套用內容審核。（預設值：false） | BOOLEAN | 否 | true<br>false |
| `visual_input_moderation` | 對輸入影像套用內容審核。（預設值：false） | BOOLEAN | 否 | true<br>false |
| `visual_output_moderation` | 對輸出影像套用內容審核。（預設值：false） | BOOLEAN | 否 | true<br>false |

**注意：** `prompt` 不得為空。`mask` 必須與 `image` 具有相同的長寬比。遮罩會以 50% 不透明度進行二值化，因此塗抹不透明度低於一半的區域會被忽略；若遮罩二值化後不含任何白色區域，節點會拋出錯誤。
