# Stability AI تحويل النص إلى صوت

يُولّد موسيقى ومؤثرات صوتية عالية الجودة من الأوصاف النصية. تستخدم هذه العقدة تقنية توليد الصوت من Stability AI لإنشاء محتوى صوتي بناءً على مطالباتك النصية.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | نموذج توليد الصوت المستخدم (الافتراضي: "stable-audio-2.5") | COMBO | نعم | `"stable-audio-2.5"` |
| `المطالبة` | الوصف النصي المستخدم لتوليد المحتوى الصوتي (الافتراضي: سلسلة فارغة) | STRING | نعم | - |
| `المدة` | يتحكم في مدة الصوت المُولّد بالثواني (الافتراضي: 190) | INT | لا | 1-190 |
| `البذرة` | البذرة العشوائية المستخدمة في التوليد (الافتراضي: 0) | INT | لا | 0-4294967294 |
| `الخطوات` | يتحكم في عدد خطوات أخذ العينات (الافتراضي: 8) | INT | لا | 4-8 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `audio` | ملف الصوت المُولّد بناءً على المطالبة النصية | AUDIO |
