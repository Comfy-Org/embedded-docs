# تبدیل اولین و آخرین فریم به ویدیو ByteDance

این گره با استفاده از یک پرامپت متنی همراه با تصاویر فریم اول و آخر، ویدیو تولید می‌کند. توضیح شما و دو فریم کلیدی را می‌گیرد تا یک توالی ویدیویی کامل بسازد که بین آن‌ها گذار انجام می‌شود. این گره گزینه‌های گوناگونی برای کنترل وضوح، نسبت ابعاد، مدت‌زمان و سایر پارامترهای تولید ویدیو فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدلی که برای تولید ویدیو استفاده می‌شود (پیش‌فرض: `"seedance-1-5-pro-251215"`). | COMBO | بله | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `prompt` | پرامپت متنی که برای تولید ویدیو استفاده می‌شود. نباید خالی باشد و نباید شامل کلیدواژه‌های پارامتر رزروشده (`resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`) باشد. | STRING | بله | - |
| `first_frame` | فریم اولی که برای ویدیو استفاده می‌شود. باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت ابعاد آن بین 0.4 و 2.5 باشد. | IMAGE | بله | - |
| `last_frame` | فریم آخری که برای ویدیو استفاده می‌شود. باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت ابعاد آن بین 0.4 و 2.5 باشد. | IMAGE | بله | - |
| `resolution` | وضوح ویدیوی خروجی. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | نسبت ابعاد ویدیوی خروجی. | COMBO | بله | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه. هنگام استفاده از `seedance-1-5-pro-251215`، حداقل مدت‌زمان 4 ثانیه است. (پیش‌فرض: 5) | INT | بله | 3 - 12 |
| `seed` | Seed مورد استفاده برای تولید. (پیش‌فرض: 0) | INT | خیر | 0 - 2147483647 |
| `camera_fixed` | مشخص می‌کند که آیا دوربین ثابت بماند یا نه. پلتفرم دستوری برای ثابت نگه داشتن دوربین به پرامپت شما اضافه می‌کند، اما اثر واقعی آن را تضمین نمی‌کند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `watermark` | آیا واترمارک «AI generated» به ویدیو اضافه شود یا نه. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `generate_audio` | این پارامتر برای هیچ مدلی به‌جز `seedance-1-5-pro-251215` نادیده گرفته می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** برای مدل `seedance-1-5-pro-251215`، مقدار `duration` باید 4 ثانیه یا بیشتر باشد. هر دو `first_frame` و `last_frame` باید بین 300x300 و 6000x6000 پیکسل باشند و نسبت ابعاد آن‌ها بین 0.4 و 2.5 باشد. اگر `prompt` شامل کلیدواژه‌های پارامتر رزروشده باشد، بررسی و رد می‌شود.
