# ByteDance First-Last-Frame לוידאו

צומת זה יוצר וידאו באמצעות פרומפט טקסט יחד עם תמונות פריים ראשון ואחרון. הוא לוקח את התיאור שלך ואת שני פריימי המפתח כדי ליצור רצף וידאו מלא שמבצע מעבר ביניהם. הצומת מספק אפשרויות שונות לשליטה ברזולוציה, ביחס רוחב-גובה, במשך ובפרמטרים אחרים של היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל המשמש ליצירת וידאו (ברירת מחדל: `"seedance-1-5-pro-251215"`). | COMBO | כן | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `prompt` | פרומפט הטקסט המשמש ליצירת הווידאו. אסור שיהיה ריק ואסור שיכיל מילות מפתח שמורות של פרמטרים (`resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`). | STRING | כן | - |
| `first_frame` | הפריים הראשון שישמש עבור הווידאו. חייב להיות בין 300x300 ל-6000x6000 פיקסלים, עם יחס רוחב-גובה בין 0.4 ל-2.5. | IMAGE | כן | - |
| `last_frame` | הפריים האחרון שישמש עבור הווידאו. חייב להיות בין 300x300 ל-6000x6000 פיקסלים, עם יחס רוחב-גובה בין 0.4 ל-2.5. | IMAGE | כן | - |
| `resolution` | הרזולוציה של סרטון הפלט. | COMBO | כן | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | יחס רוחב-גובה של סרטון הפלט. | COMBO | כן | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | משך סרטון הפלט בשניות. בעת שימוש ב-`seedance-1-5-pro-251215`, משך הזמן המינימלי הוא 4 שניות. (ברירת מחדל: 5) | INT | כן | 3 - 12 |
| `seed` | Seed שישמש ליצירה. (ברירת מחדל: 0) | INT | לא | 0 - 2147483647 |
| `camera_fixed` | מציין אם לקבע את המצלמה. הפלטפורמה מוסיפה הוראה לקבע את המצלמה לפרומפט שלך, אך אינה מבטיחה את האפקט בפועל. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `watermark` | האם להוסיף סימן מים של "AI generated" לוידאו. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `generate_audio` | מתעלמים מפרמטר זה בכל מודל מלבד `seedance-1-5-pro-251215`. (ברירת מחדל: False) | BOOLEAN | לא | - |

**הערה:** עבור המודל `seedance-1-5-pro-251215`, הפרמטר `duration` חייב להיות 4 שניות או יותר. גם `first_frame` וגם `last_frame` חייבים להיות בין 300x300 ל-6000x6000 פיקסלים ובעלי יחס רוחב-גובה בין 0.4 ל-2.5. ה-`prompt` נבדק ונפסל אם הוא מכיל מילות מפתח שמורות של פרמטרים.
