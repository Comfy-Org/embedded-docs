# ByteDance - Преобразование первого-последнего кадра в видео

Этот узел генерирует видео с использованием текстовой подсказки, а также изображений первого и последнего кадра. Он принимает ваше описание и два ключевых кадра, чтобы создать полную видеопоследовательность с переходом между ними. Узел предоставляет различные параметры для управления разрешением видео, соотношением сторон, длительностью и другими параметрами генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для генерации видео (по умолчанию: `"seedance-1-5-pro-251215"`). | COMBO | Да | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `промпт` | Текстовая подсказка, используемая для генерации видео. Не должна быть пустой и не должна содержать зарезервированные ключевые слова параметров (`resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`). | STRING | Да | - |
| `first_frame` | Первый кадр, используемый для генерации видео. Должен быть от 300x300 до 6000x6000 пикселей с соотношением сторон от 0.4 до 2.5. | IMAGE | Да | - |
| `last_frame` | Последний кадр, используемый для генерации видео. Должен быть от 300x300 до 6000x6000 пикселей с соотношением сторон от 0.4 до 2.5. | IMAGE | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | Длительность выходного видео в секундах. При использовании `seedance-1-5-pro-251215` минимальная длительность составляет 4 секунды. (по умолчанию: 5) | INT | Да | 3 - 12 |
| `seed` | Начальное значение для генерации. (по умолчанию: 0) | INT | Нет | 0 - 2147483647 |
| `camera_fixed` | Указывает, фиксировать ли камеру. Платформа добавляет инструкцию о фиксации камеры к вашей подсказке, но не гарантирует фактический эффект. (по умолчанию: False) | BOOLEAN | Нет | - |
| `watermark` | Добавлять ли водяной знак «AI generated» на видео. (по умолчанию: False) | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для любой модели, кроме `seedance-1-5-pro-251215`. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Для модели `seedance-1-5-pro-251215` значение `duration` должно быть 4 секунды или больше. И `first_frame`, и `last_frame` должны быть от 300x300 до 6000x6000 пикселей и иметь соотношение сторон от 0.4 до 2.5. `prompt` проверяется и отклоняется, если содержит зарезервированные ключевые слова параметров.
