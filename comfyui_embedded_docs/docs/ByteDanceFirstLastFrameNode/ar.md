# تحويل الإطار الأول-الأخير من ByteDance إلى فيديو

تولّد هذه العقدة فيديو باستخدام موجّه نصي مع صورتي الإطار الأول والأخير. تأخذ وصفك والإطارين الرئيسيين لإنشاء تسلسل فيديو كامل ينتقل بينهما. توفر العقدة خيارات متنوعة للتحكم في دقة الفيديو ونسبة العرض إلى الارتفاع والمدة ومعاملات التوليد الأخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المستخدم لتوليد الفيديو (القيمة الافتراضية: `"seedance-1-5-pro-251215"`). | COMBO | نعم | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `المطالبة النصية` | الموجّه النصي المستخدم لتوليد الفيديو. يجب ألا يكون فارغًا ويجب ألا يحتوي على كلمات مفتاحية محجوزة للمعاملات (`resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`). | STRING | نعم | - |
| `الإطار_الأول` | الإطار الأول الذي سيُستخدم في الفيديو. يجب أن يكون بين 300x300 و6000x6000 بكسل، وبنسبة عرض إلى ارتفاع بين 0.4 و2.5. | IMAGE | نعم | - |
| `الإطار_الأخير` | الإطار الأخير الذي سيُستخدم في الفيديو. يجب أن يكون بين 300x300 و6000x6000 بكسل، وبنسبة عرض إلى ارتفاع بين 0.4 و2.5. | IMAGE | نعم | - |
| `الدقة` | دقة الفيديو الناتج. | COMBO | نعم | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبة_الجانب` | نسبة العرض إلى الارتفاع للفيديو الناتج. | COMBO | نعم | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `المدة` | مدة الفيديو الناتج بالثواني. عند استخدام `seedance-1-5-pro-251215`، تكون المدة الدنيا 4 ثوانٍ. (القيمة الافتراضية: 5) | INT | نعم | 3 - 12 |
| `البذرة` | البذرة المستخدمة للتوليد. (القيمة الافتراضية: 0) | INT | لا | 0 - 2147483647 |

| `علامة_مائية` | ما إذا كانت ستُضاف علامة مائية "AI generated" إلى الفيديو. (القيمة الافتراضية: False) | BOOLEAN | لا | - |
| `توليد الصوت` | يُتجاهل هذا المعامل مع أي نموذج باستثناء `seedance-1-5-pro-251215`. (القيمة الافتراضية: False) | BOOLEAN | لا | - |

**ملاحظة:** بالنسبة لنموذج `seedance-1-5-pro-251215`، يجب أن تكون `duration` 4 ثوانٍ أو أكثر. يجب أن يكون كل من `first_frame` و`last_frame` بين 300x300 و6000x6000 بكسل وأن تكون نسبة العرض إلى الارتفاع بين 0.4 و2.5. يتم فحص `prompt` ورفضه إذا احتوى على كلمات مفتاحية محجوزة للمعاملات.
