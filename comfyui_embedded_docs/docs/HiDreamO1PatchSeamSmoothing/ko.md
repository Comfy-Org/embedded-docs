# HiDream-O1 Patch Seam Smoothing

## 개요

이 노드는 HiDream-O1 모델이 생성한 이미지에서 눈에 띄는 이음매(seam)를 줄입니다. 샘플링 과정의 후반부에 여러 개의 이동된 패치 그리드 위치에 걸쳐 모델 출력을 평균화하여 작동합니다. 즉, 모델을 약간 다른 이미지 정렬로 여러 번 실행하고 결과를 함께 혼합하여 패치 경계에서 나타날 수 있는 격자 모양 아티팩트를 상쇄합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 이음매 평활화 래퍼를 적용할 HiDream-O1 모델입니다. | MODEL | 예 | - |
| `start_percent` | 혼합이 켜지는 샘플링 진행률(0=시작, 1=종료)입니다 (기본값: 0.8). | FLOAT | 예 | 0.0 to 1.0 (step: 0.01) |
| `end_percent` | 혼합이 꺼지는 샘플링 진행률입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 to 1.0 (step: 0.01) |
| `pattern` | 이동 배치입니다. `single_shift`: 자연 패치 그리드에서 한 번 실행하고 나머지는 오프셋된 위치에서 실행합니다. `symmetric`: 모든 패스가 그리드 밖에서 실행되며, 이동이 원점을 기준으로 분할됩니다 (기본값: `"single_shift"`). | COMBO | 예 | `"single_shift"`<br>`"symmetric"` |
| `passes` | 게이트 적용 단계당 패스 수입니다. `2`/`4` = 고정. `ramp_*`: 샘플링이 종료에 가까워질수록 패스 수가 증가합니다 (이음매가 가장 잘 보이는 곳에서 더 많은 평활화가 적용됨) (기본값: `"2"`). | COMBO | 예 | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `blend` | `average`: 동일 가중치 평균입니다. `window`: 각 패스가 자신의 패치 경계에서 멀리 떨어진 영역에 더 높은 가중치를 부여하는 Hann 창 가중치 방식입니다. `median`: 픽셀별 중앙값으로, 랩어라운드 이상치 패스를 배제합니다 (기본값: `"average"`). | COMBO | 예 | `"average"`<br>`"window"`<br>`"median"` |
| `strength` | 자연 그리드 예측(0)과 평균화된 결과(1) 사이의 보간 강도입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 to 1.0 (step: 0.01) |

**제약 사항에 대한 참고 사항:**

- 평활화 효과는 `strength`가 0.0 이하이거나 `end_percent`가 `start_percent` 이하인 경우 적용되지 않습니다. 이 경우 노드는 모델을 변경하지 않은 채 반환합니다.
- `passes`의 램프 옵션(`ramp_2_4`, `ramp_2_4_8`)은 게이트 구간 내에서 샘플링이 `end_percent`로 진행됨에 따라 패스 수를 늘리므로, `start_percent`와 `end_percent`가 비어 있지 않은 구간을 정의할 때만 의미가 있습니다.
- 평균화된 결과는 이미지 경계에서 떨어진 부분에만 모델 출력에 다시 혼합됩니다. 마스크가 각 가장자리의 32픽셀 띠(4픽셀 페더 포함)에서는 원래 예측을 유지하여 이동된 패스로 인한 랩어라운드 오염을 방지합니다.
