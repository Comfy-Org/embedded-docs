# HiDreamO1PatchSeamSmoothing

צומת זה מפחית תפרים גלויים בתמונות שנוצרות על ידי מודל HiDream-O1 על ידי מיצוע הפלט של המודל על פני מספר מיקומים מוזזים של רשת patch במהלך החלק המאוחר של תהליך הדגימה. הוא מריץ את המודל מספר פעמים עם יישורים מעט שונים של התמונה וממזג את התוצאות יחד, מה שעוזר לקזז ארטיפקטים דמויי רשת שעלולים להופיע בגבולות ה-patch.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו להחיל החלקת תפרים. | MODEL | כן | - |
| `start_percent` | התקדמות הדגימה (0=התחלה, 1=סיום) שבה המיזוג נדלק. ברירת מחדל: 0.8 | FLOAT | כן | 0.0 to 1.0 (step: 0.01) |
| `end_percent` | התקדמות הדגימה שבה המיזוג נכבה. ברירת מחדל: 1.0 | FLOAT | כן | 0.0 to 1.0 (step: 0.01) |
| `pattern` | פריסת ההזזות. `single_shift`: מעבר אחד ברשת ה-patch הטבעית + מעברים אחרים מוזזים. `symmetric`: כל המעברים מחוץ לרשת, ההזזות מפוצלות סביב הראשית. ברירת מחדל: "single_shift" | COMBO | כן | `"single_shift"`<br>`"symmetric"` |
| `passes` | מספר המעברים בכל צעד מגודר. `2`/`4` = קבוע. `ramp_*`: מספר המעברים עולה ככל שהדגימה מתקרבת לסיום (יותר החלקה במקומות שבהם התפרים גלויים ביותר). ברירת מחדל: "2" | COMBO | כן | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `blend` | `average`: ממוצע במשקל שווה. `window`: שקלול בחלון Hann המעדיף כל מעבר כשהוא רחוק מגבולות ה-patch שלו. `median`: חציון לכל פיקסל, דוחה מעברים חריגים מסוג wraparound. ברירת מחדל: "average" | COMBO | כן | `"average"`<br>`"window"`<br>`"median"` |
| `strength` | אינטרפולציה בין החיזוי ברשת הטבעית (0) לבין התוצאה הממוצעת (1). ברירת מחדל: 1.0 | FLOAT | כן | 0.0 to 1.0 (step: 0.01) |

**הערה על אילוצי פרמטרים:**
- אפקט ההחלקה אינו מיושם אם `strength` הוא 0.0 או פחות, או אם `end_percent` קטן מ-`start_percent` או שווה לו. במקרים אלה הצומת מחזיר את המודל ללא שינוי.
- אפשרויות ה-ramp של הפרמטר `passes` (`ramp_2_4`, `ramp_2_4_8`) משמעותיות רק כאשר `end_percent` גדול מ-`start_percent`, מכיוון שמספר המעברים עולה ככל שהדגימה מתקדמת בטווח הזה.
