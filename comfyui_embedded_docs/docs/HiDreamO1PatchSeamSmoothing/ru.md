# Сглаживание швов патчей HiDream-O1

## Обзор

Этот узел уменьшает видимые швы на изображениях, сгенерированных моделью HiDream-O1, путём усреднения выходных данных модели по нескольким смещённым позициям сетки патчей на поздней стадии процесса сэмплирования. Он работает за счёт многократного запуска модели с немного разными выравниваниями изображения и смешивания результатов, что помогает устранять сетчатые артефакты, которые могут появляться на границах патчей.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель HiDream-O1, к которой применяется обёртка сглаживания швов. | MODEL | Да | - |
| `start_percent` | Прогресс сэмплирования (0=начало, 1=конец), при котором смешивание включается (по умолчанию: 0.8). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `end_percent` | Прогресс сэмплирования, при котором смешивание выключается (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `pattern` | Схема сдвигов. `single_shift`: один проход по естественной сетке патчей плюс остальные со смещением. `symmetric`: все проходы вне сетки, сдвиги распределены вокруг начала координат (по умолчанию: `"single_shift"`). | COMBO | Да | `"single_shift"`<br>`"symmetric"` |
| `passes` | Количество проходов на гейтированный шаг. `2`/`4` = фиксированное. `ramp_*`: количество проходов увеличивается по мере приближения сэмплирования к концу (больше сглаживания там, где швы наиболее заметны) (по умолчанию: `"2"`). | COMBO | Да | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `blend` | `average`: среднее с равными весами. `window`: взвешивание с окном Ханна, отдающее предпочтение каждому проходу вдали от границ его патчей. `median`: попиксельная медиана, отклоняющая проходы с выбросами из-за заворота (по умолчанию: `"average"`). | COMBO | Да | `"average"`<br>`"window"`<br>`"median"` |
| `strength` | Интерполяция между предсказанием на естественной сетке (0) и усреднённым результатом (1) (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

**Примечания об ограничениях:**

- Эффект сглаживания не применяется, если `strength` равно 0.0 или меньше, или если `end_percent` меньше или равен `start_percent`; в этих случаях узел возвращает модель без изменений.
- Варианты с наращиванием параметра `passes` (`ramp_2_4`, `ramp_2_4_8`) увеличивают количество проходов по мере продвижения сэмплирования к `end_percent` в пределах гейтированного диапазона, поэтому они имеют смысл только тогда, когда `start_percent` и `end_percent` задают непустой диапазон.
- Усреднённый результат смешивается с выходными данными модели только вдали от границ изображения: маска сохраняет исходное предсказание в 32-пиксельной полосе вдоль каждого края (с 4-пиксельной растушевкой), что позволяет избежать загрязнения из-за заворота, вызванного смещёнными проходами.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
