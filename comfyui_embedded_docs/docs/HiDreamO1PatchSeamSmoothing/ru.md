# Сглаживание швов патчей HiDream-O1

Этот узел уменьшает видимые швы на изображениях, генерируемых моделью HiDream-O1, путём усреднения выходных данных модели по нескольким сдвинутым позициям патч-сетки в поздней части процесса сэмплирования. Он несколько раз запускает модель с немного разными выравниваниями изображения и смешивает результаты, что помогает подавлять артефакты в виде сетки, которые могут появляться на границах патчей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяется сглаживание швов. | MODEL | Да | - |
| `начальный_процент` | Прогресс сэмплирования (0 = начало, 1 = конец), при котором смешивание ВКЛЮЧАЕТСЯ. По умолчанию: 0.8 | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `конечный_процент` | Прогресс сэмплирования, при котором смешивание ВЫКЛЮЧАЕТСЯ. По умолчанию: 1.0 | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `шаблон` | Схема сдвига. `single_shift`: один проход по естественной патч-сетке + остальные со смещением. `symmetric`: все проходы вне сетки, сдвиги симметрично распределены относительно начала координат. По умолчанию: "single_shift" | COMBO | Да | `"single_shift"`<br>`"symmetric"` |
| `проходы` | Количество проходов на каждый активированный шаг. `2`/`4` = фиксированное. `ramp_*`: количество проходов увеличивается по мере приближения сэмплирования к концу (больше сглаживания там, где швы наиболее заметны). По умолчанию: "2" | COMBO | Да | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `смешивание` | `average`: среднее с равными весами. `window`: взвешивание с окном Ханна, отдающее предпочтение каждому проходу вдали от границ его патчей. `median`: медиана по каждому пикселю, отбрасывающая проходы с выбросами из-за зацикливания. По умолчанию: "average" | COMBO | Да | `"average"`<br>`"window"`<br>`"median"` |
| `интенсивность` | Интерполяция между предсказанием по естественной сетке (0) и усреднённым результатом (1). По умолчанию: 1.0 | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

**Примечание об ограничениях параметров:**
- Эффект сглаживания не применяется, если `strength` равен 0.0 или меньше, либо если `end_percent` меньше или равен `start_percent`. В этих случаях узел возвращает модель без изменений.
- Опции `ramp_*` параметра `passes` (`ramp_2_4`, `ramp_2_4_8`) имеют смысл только когда `end_percent` больше `start_percent`, поскольку количество проходов увеличивается по мере прохождения сэмплирования через этот диапазон.
