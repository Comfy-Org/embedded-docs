# Сглаживание швов патчей HiDream-O1

Этот узел уменьшает видимые швы на изображениях, создаваемых моделью HiDream-O1, путем усреднения выходных данных модели по нескольким смещенным позициям сетки патчей на поздней стадии процесса сэмплирования. Он работает путем многократного запуска модели с немного различным выравниванием изображения и смешивания результатов, что помогает устранить сетчатые артефакты, которые могут появляться на границах патчей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель HiDream-O1, к которой применяется сглаживание швов. | MODEL | Да | - |
| `начальный_процент` | Прогресс сэмплирования (0=начало, 1=конец), при котором эффект сглаживания включается (по умолчанию: 0.8). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `конечный_процент` | Прогресс сэмплирования, при котором эффект сглаживания выключается (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `шаблон` | Расположение смещенных позиций сетки. `single_shift`: один проход по естественной сетке патчей плюс остальные со смещением. `symmetric`: все проходы вне сетки, со смещениями, распределенными вокруг начала координат (по умолчанию: `"single_shift"`). | COMBO | Да | `"single_shift"`<br>`"symmetric"` |
| `проходы` | Количество проходов (запусков модели) на каждый управляемый шаг. `2` и `4` — фиксированные значения. `ramp_2_4` и `ramp_2_4_8` увеличивают количество проходов по мере приближения сэмплирования к концу, обеспечивая более сильное сглаживание там, где швы наиболее заметны (по умолчанию: `"2"`). | COMBO | Да | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `смешивание` | Метод, используемый для объединения результатов каждого прохода. `average`: среднее с равными весами для всех проходов. `window`: использует окно Ханна, чтобы придавать больший вес центру каждого прохода, уменьшая краевые артефакты. `median`: берет медиану для каждого пикселя, что позволяет отбрасывать выбросы, вызванные заворотом (по умолчанию: `"average"`). | COMBO | Да | `"average"`<br>`"window"`<br>`"median"` |
| `интенсивность` | Управляет интерполяцией между исходным выходом модели (0.0) и полностью сглаженным результатом (1.0) (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |

**Примечание об ограничениях параметров:**
- Эффект сглаживания не будет применен, если `strength` меньше или равен 0.0, или если `end_percent` меньше или равен `start_percent`. В этих случаях узел возвращает модель без изменений.
- Опции ramp параметра `passes` (`ramp_2_4`, `ramp_2_4_8`) имеют смысл только тогда, когда `start_percent` и `end_percent` задают диапазон, поскольку количество проходов увеличивается по мере продвижения сэмплирования в этом диапазоне.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной оберткой сглаживания швов. | MODEL |
