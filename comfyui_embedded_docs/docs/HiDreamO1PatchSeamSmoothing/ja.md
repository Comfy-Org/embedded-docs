# HiDream-O1 パッチ継ぎ目スムージング

## 概要

このノードは、HiDream-O1 モデルが生成した画像の目に見えるシーム（継ぎ目）を低減します。サンプリング処理の後半で、モデルの出力を複数のシフトしたパッチグリッド位置で平均化します。モデルをわずかに異なる画像位置合わせで複数回実行し、その結果をブレンドすることで、パッチ境界に現れるグリッド状のアーティファクトを打ち消します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | シームスムージングラッパーを適用する HiDream-O1 モデル。 | MODEL | はい | - |
| `start_percent` | ブレンドが有効になるサンプリング進行度（0=開始、1=終了）。デフォルトは 0.8。 | FLOAT | はい | 0.0 ～ 1.0（ステップ: 0.01） |
| `end_percent` | ブレンドが無効になるサンプリング進行度。デフォルトは 1.0。 | FLOAT | はい | 0.0 ～ 1.0（ステップ: 0.01） |
| `pattern` | シフト配置。`single_shift`: 通常のパッチグリッド上の1回のパスに加えて、オフセットしたパスを実行します。`symmetric`: すべてのパスがオフグリッドで、シフトが原点を中心に分割されます。デフォルトは `"single_shift"`。 | COMBO | はい | `"single_shift"`<br>`"symmetric"` |
| `passes` | ゲートされたステップごとのパス数。`2` / `4` は固定。`ramp_*`: サンプリングが終了に近づくにつれてパス数が増加します（シームが最も目立つ場所でより強くスムージングされます）。デフォルトは `"2"`。 | COMBO | はい | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `blend` | `average`: 等加重平均。`window`: ハン窓による重み付けで、各パスをパッチ境界から遠ざける方向に重み付けします。`median`: ピクセル単位の中央値で、ラップアラウンドによる外れ値パスを除外します。デフォルトは `"average"`。 | COMBO | はい | `"average"`<br>`"window"`<br>`"median"` |
| `strength` | 自然グリッド予測（0）と平均化結果（1）の間の補間。デフォルトは 1.0。 | FLOAT | はい | 0.0 ～ 1.0（ステップ: 0.01） |

**制約に関する注意事項:**

- `strength` が 0.0 以下の場合、または `end_percent` が `start_percent` 以下の場合、スムージング効果は適用されません。この場合、ノードはモデルを変更せずに返します。
- `passes` のランプオプション（`ramp_2_4`、`ramp_2_4_8`）は、ゲートされた範囲内でサンプリングが `end_percent` に向かって進むにつれてパス数を増やします。そのため、`start_percent` と `end_percent` が空でない範囲を定義している場合にのみ意味を持ちます。
- 平均化された結果は、画像の端から離れた部分でのみモデル出力にブレンドし戻されます。マスクにより、各エッジに沿った32ピクセルの帯（4ピクセルのフェザー付き）では元の予測が保持され、シフトしたパスによるラップアラウンド汚染を回避します。
