# HiDream-O1 Patch Seam Smoothing

This node reduces visible seams in images generated by the HiDream-O1 model by averaging the model's output across multiple shifted patch-grid positions during the later part of the sampling process. It runs the model several times with slightly different image alignments and blends the results together, which helps cancel out the grid-like artifacts that can appear at patch boundaries.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `model` | Il modello a cui applicare lo smorzamento delle cuciture. | MODEL | Sì | - |
| `start_percent` | Progresso del campionamento (0=inizio, 1=fine) al quale la fusione si attiva. predefinito: 0.8 | FLOAT | Sì | 0.0 a 1.0 (passo: 0.01) |
| `end_percent` | Progresso del campionamento al quale la fusione si disattiva. predefinito: 1.0 | FLOAT | Sì | 0.0 a 1.0 (passo: 0.01) |
| `pattern` | Schema di spostamento. `single_shift`: una passata sulla griglia naturale delle patch + le altre con offset. `symmetric`: tutte le passate fuori griglia, spostamenti suddivisi attorno all'origine. predefinito: "single_shift" | COMBO | Sì | `"single_shift"`<br>`"symmetric"` |
| `passes` | Numero di passate per ogni passo in cui la fusione è attiva. `2`/`4` = fisse. `ramp_*`: il numero di passate aumenta man mano che il campionamento si avvicina alla fine (più smorzamento dove le cuciture sono più visibili). predefinito: "2" | COMBO | Sì | `"2"`<br>`"4"`<br>`"ramp_2_4"`<br>`"ramp_2_4_8"` |
| `blend` | `average`: media a pesi uguali. `window`: ponderazione con finestra di Hann che favorisce ogni passata lontano dai confini della propria patch. `median`: mediana per pixel, scarta le passate anomale da wraparound. predefinito: "average" | COMBO | Sì | `"average"`<br>`"window"`<br>`"median"` |
| `strength` | Interpolazione tra la previsione sulla griglia naturale (0) e il risultato mediato (1). predefinito: 1.0 | FLOAT | Sì | 0.0 a 1.0 (passo: 0.01) |

**Nota sui vincoli dei parametri:**
- L'effetto di smorzamento non viene applicato se `strength` è 0.0 o inferiore, oppure se `end_percent` è minore o uguale a `start_percent`. In questi casi il nodo restituisce il modello invariato.
- Le opzioni ramp del parametro `passes` (`ramp_2_4`, `ramp_2_4_8`) hanno senso solo quando `end_percent` è maggiore di `start_percent`, perché il numero di passate aumenta man mano che il campionamento avanza in tale intervallo.

## Output

| Nome output | Descrizione | Tipo di dati |
| --- | --- | --- |
| `model` | Il modello modificato con il wrapper di smorzamento delle cuciture applicato. | MODEL |
