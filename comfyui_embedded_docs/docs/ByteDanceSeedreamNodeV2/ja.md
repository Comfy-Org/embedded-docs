# ByteDance Seedream 4.5 & 5.0

このノードは、ByteDance の Seedream モデル（4.0、4.5、5.0 Lite、5.0 Pro）を使用して画像を作成または編集します。テキストプロンプトから新しい画像を生成したり、参照画像と一文の指示に基づいて既存の画像を編集したりできます。最大 4K までの解像度に対応しています。

### 注意事項

- カスタムの `width` と `height` の値は、`size_preset` が「Custom」に設定されている場合にのみ有効です。
- 解像度の制限（幅 × 高さに基づく）:
  - seedream 5.0 pro: 最小 0.92 MP、最大 4.19 MP。
  - seedream 5.0 lite および seedream-4-5-251128: 最小 3.68 MP。
  - seedream-4-0-250828: 最小 0.92 MP。
  - seedream 5.0 lite、seedream-4-5-251128、seedream-4-0-250828: 最大 16.78 MP。
- 参照画像のアスペクト比は 1:3 から 3:1 の間である必要があります。
- `max_images` が 1 より大きい場合（seedream 5.0 lite、seedream-4-5-251128、seedream-4-0-250828 で利用可能）、画像の合計数（参照画像と生成画像の合計）は 15 を超えることはできません。
- `thinking` はテキストから画像を生成する場合にのみ無効にできます。参照画像を指定する場合は必ず有効にする必要があります。
- seedream 5.0 pro は常に 1 枚の画像を生成し、`max_images` や `fail_on_partial` の入力は表示されません。
