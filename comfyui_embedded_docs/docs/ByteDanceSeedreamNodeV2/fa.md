# ByteDance Seedream ۴.۵ و ۵.۰

این گره با استفاده از مدل‌های Seedream شرکت ByteDance (نسخه‌های ۴.۰، ۴.۵، ۵.۰ لایت و ۵.۰ پرو) تصویر تولید یا ویرایش می‌کند. این گره تولید یکپارچه متن‌به‌تصویر و ویرایش دقیق تک‌جمله‌ای تصویر را تا وضوح 4K ارائه می‌دهد. این نسخهٔ قدیمی (V2) گره Seedream است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل Seedream برای استفاده در تولید. هر مدل قابلیت‌ها و قیمت‌گذاری متفاوتی دارد. | DYNAMIC_COMBO | بله | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | متن راهنمای (پرامپت) برای ایجاد یا ویرایش تصویر (پیش‌فرض: رشته خالی). | STRING | بله | N/A |
| `seed` | مقدار seed برای تولید (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `watermark` | آیا واترمارک «AI generated» به تصویر اضافه شود یا نه (پیش‌فرض: False). | BOOLEAN | بله | True / False |
| `thinking` | فعال‌سازی استدلال بهینه‌سازی پرامپت مدل (thinking) برای پیروی بهتر. می‌تواند زمان تولید را به‌طور قابل توجهی افزایش دهد — به‌ویژه در Seedream 5.0 Pro. فقط برای تولید متن‌به‌تصویر (نه زمانی که تصاویر مرجع ارائه می‌شوند) قابل غیرفعال‌سازی است (پیش‌فرض: True). | BOOLEAN | خیر | True / False |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | اسلات قابل رشد: ۱..N مورد را متصل کنید (مثلاً `image_1`, `image_2`, ...)؛ محدودیت تعداد به مدل انتخابی بستگی دارد (به بخش‌های مدل مراجعه کنید). تصویر(های) مرجع اختیاری برای تولید تصویر-به-تصویر یا مرجع چندگانه. بدون تصویر مرجع، گره در حالت متن‌به-تصویر کار می‌کند. | IMAGE | خیر | 0 تا 10 تصویر (`seedream 5.0 pro`, `seedream-4-5-251128`, `seedream-4-0-250828`)<br>0 تا 14 تصویر (`seedream 5.0 lite`) |

### نکاتی درباره محدودیت‌ها

- `width` و `height` فقط زمانی اعمال می‌شوند که `size_preset` روی `Custom` تنظیم شده باشد.
- تعداد کل تصاویر مرجع به‌علاوه تصاویر تولیدشده نمی‌تواند از ۱۵ بیشتر باشد.
- `thinking` فقط برای تولید متن‌به-تصویر قابل غیرفعال‌سازی است، نه زمانی که تصاویر مرجع ارائه شوند.
- Seedream 5.0 Pro از تولید دسته‌ای پشتیبانی نمی‌کند: همیشه یک تصویر واحد تولید می‌کند، بنابراین `max_images` و `fail_on_partial` برای این مدل در دسترس نیستند.
