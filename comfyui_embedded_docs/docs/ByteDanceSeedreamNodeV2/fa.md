# ByteDance Seedream 4.5 & 5.0 (قدیمی)

این گره با استفاده از مدل‌های Seedream شرکت ByteDance (نسخه‌های 4.0، 4.5، 5.0 Lite و 5.0 Pro) تصاویر را تولید یا ویرایش می‌کند. این گره تولید یکپارچه تصویر از متن و ویرایش دقیق تصویر با یک جمله را تا وضوح 4K فراهم می‌کند. این نسخه قدیمی (V2) گره Seedream است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل Seedream برای تولید. هر مدل قابلیت‌ها و قیمت‌گذاری متفاوتی دارد. | DYNAMIC_COMBO | بله | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | پرامپت متنی برای ایجاد یا ویرایش تصویر (پیش‌فرض: رشته خالی). | STRING | بله | N/A |
| `seed` | مقدار seed برای تولید (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `watermark` | این که واترمارک «AI generated» به تصویر اضافه شود یا نه (پیش‌فرض: False). | BOOLEAN | بله | True / False |
| `thinking` | استدلال بهینه‌سازی پرامپت ('thinking') را برای پیروی بهتر فعال می‌کند. می‌تواند زمان تولید را به‌طور قابل‌توجهی افزایش دهد — به‌ویژه در Seedream 5.0 Pro. فقط برای متن به تصویر می‌توان آن را غیرفعال کرد (نه زمانی که تصاویر مرجع ارائه شده‌اند) (پیش‌فرض: True). | BOOLEAN | خیر | True / False |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |

### نکاتی درباره محدودیت‌ها

- `width` و `height` فقط زمانی اعمال می‌شوند که `size_preset` روی `Custom` تنظیم شده باشد.
- تعداد کل تصاویر مرجع به‌همراه تصاویر تولیدشده نمی‌تواند از 15 فراتر رود.
- `thinking` فقط برای تولید متن به تصویر می‌تواند غیرفعال شود، نه زمانی که تصاویر مرجع ارائه شده‌اند.
- Seedream 5.0 Pro از تولید دسته‌ای پشتیبانی نمی‌کند: همیشه یک تصویر واحد تولید می‌کند، بنابراین `max_images` و `fail_on_partial` برای این مدل در دسترس نیستند.
