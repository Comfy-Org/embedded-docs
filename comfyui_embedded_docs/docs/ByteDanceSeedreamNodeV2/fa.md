# ByteDance Seedream ۴.۵ و ۵.۰

این گره با استفاده از مدل‌های ByteDance Seedream (4.0، 4.5، 5.0 Lite و 5.0 Pro) تصاویر را ایجاد یا ویرایش می‌کند. این گره تصاویر جدیدی از روی یک پرامپت متنی تولید می‌کند و می‌تواند تصاویر موجود را بر اساس تصاویر مرجع و یک دستورالعمل تک‌جمله‌ای ویرایش کند؛ همچنین از وضوح تا 4K پشتیبانی می‌کند.

## ورودی‌ها

انتخابگر `model` تعیین می‌کند کدام ورودی‌های مخصوص مدل در دسترس هستند. جدول‌های زیر ورودی‌های مشترک، ورودی‌های هر مدل و اسلات‌های قابل رشد تصویر مرجع را فهرست می‌کنند.

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل Seedream برای استفاده در تولید. هر مدل قابلیت‌ها، محدودیت‌ها و قیمت‌گذاری متفاوتی دارد. | DYNAMIC_COMBO | بله | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | پرامپت متنی برای ایجاد یا ویرایش تصویر. | STRING | بله | هر متنی (غیرخالی) |
| `seed` | مقدار Seed برای تولید (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `watermark` | آیا واترمارک «AI generated» به تصویر اضافه شود یا خیر (پیش‌فرض: False). | BOOLEAN | بله | True / False |
| `thinking` | قابلیت استدلال بهینه‌سازی پرامپت مدل را فعال می‌کند تا پایبندی به پرامپت بهتر شود («thinking»). می‌تواند زمان تولید را به‌طور قابل توجهی افزایش دهد — به‌ویژه در Seedream 5.0 Pro. فقط برای تبدیل متن به تصویر (text-to-image) می‌توان آن را غیرفعال کرد؛ نه زمانی که تصاویر مرجع ارائه شده باشند. (پیش‌فرض: True) | BOOLEAN | خیر | True / False |

### نکات

- مقادیر سفارشی `width` و `height` فقط زمانی اعمال می‌شوند که `size_preset` روی Custom تنظیم شده باشد.
- محدودیت‌های وضوح (بر اساس عرض × ارتفاع):
  - seedream 5.0 pro: حداقل 0.92 MP، حداکثر 4.19 MP.
  - seedream 5.0 lite و seedream-4-5-251128: حداقل 3.68 MP.
  - seedream-4-0-250828: حداقل 0.92 MP.
  - seedream 5.0 lite، seedream-4-5-251128 و seedream-4-0-250828: حداکثر 16.78 MP.
- تصاویر مرجع باید دارای نسبت تصویر بین 1:3 و 3:1 باشند.
- وقتی `max_images` بزرگ‌تر از 1 است (در seedream 5.0 lite، seedream-4-5-251128 و seedream-4-0-250828 در دسترس است)، تعداد کل تصاویر (تصاویر مرجع به‌علاوه تصاویر تولیدشده) نمی‌تواند از 15 بیشتر شود.
- `thinking` فقط برای تبدیل متن به تصویر (text-to-image) قابل غیرفعال کردن است؛ زمانی که تصاویر مرجع ارائه می‌شوند، باید فعال باشد.
- seedream 5.0 pro همیشه یک تصویر واحد تولید می‌کند و ورودی‌های `max_images` یا `fail_on_partial` را نمایش نمی‌دهد.
