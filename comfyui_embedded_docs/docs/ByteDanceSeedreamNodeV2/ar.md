# ByteDance Seedream 4.5 و5.0 (قديم)

تولّد هذه العقدة الصور أو تعدّلها باستخدام نماذج Seedream من ByteDance (الإصدارات 4.0 و4.5 و5.0 Lite و5.0 Pro). وتوفّر توليدًا موحّدًا من النص إلى الصورة وتحريرًا دقيقًا للصورة بجملة واحدة بدقة تصل إلى 4K. هذه هي النسخة القديمة (V2) من عقدة Seedream.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | إصدار نموذج Seedream المراد استخدامه للتوليد. لكل نموذج قدرات وأسعار مختلفة. | DYNAMIC_COMBO | نعم | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | المطالبة النصية لإنشاء صورة أو تعديلها (الافتراضي: سلسلة فارغة). | STRING | نعم | N/A |
| `seed` | البذرة المستخدمة للتوليد (الافتراضي: 0). | INT | نعم | من 0 إلى 2147483647 |
| `watermark` | ما إذا كان سيتم إضافة علامة مائية "AI generated" إلى الصورة (الافتراضي: False). | BOOLEAN | نعم | True / False |
| `thinking` | تمكين استدلال تحسين المطالبة ('thinking') لدى النموذج لتحقيق التزام أفضل. قد يزيد هذا بشكل كبير من زمن التوليد — لا سيما في Seedream 5.0 Pro. يمكن تعطيله فقط في وضع النص إلى الصورة (وليس عند توفير صور مرجعية) (الافتراضي: True). | BOOLEAN | لا | True / False |

### ملاحظات حول القيود

- لا يسري مفعول `width` و`height` إلا عندما يكون `size_preset` مضبوطًا على `Custom`.
- لا يمكن أن يتجاوز مجموع الصور المرجعية والصور المولدة 15.
- يمكن تعطيل `thinking` فقط في التوليد من النص إلى الصورة، وليس عند توفير صور مرجعية.
- لا يدعم Seedream 5.0 Pro التوليد الدفعي: فهو ينتج دائمًا صورة واحدة، لذا لا يتوفر `max_images` و`fail_on_partial` لهذا النموذج.
