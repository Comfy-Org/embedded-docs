# ByteDance Seedream 4.5 & 5.0 (מדור קודם)

צומת זה יוצר או עורך תמונות באמצעות מודלי Seedream של ByteDance (גרסאות 4.0, 4.5, 5.0 Lite ו-5.0 Pro). הוא מספק יצירת תמונות מאקסט (text-to-image) מאוחדת ועריכת תמונה מדויקת ממשפט בודד ברזולוציה של עד 4K. זוהי גרסת מדור קודם (V2) של צומת Seedream.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת מודל Seedream שבה יש להשתמש ליצירה. לכל מודל יכולות ותמחור שונים. | DYNAMIC_COMBO | כן | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | הנחיית טקסט ליצירה או עריכה של תמונה (ברירת מחדל: מחרוזת ריקה). | STRING | כן | N/A |
| `seed` | Seed לשימוש ביצירה (ברירת מחדל: 0). | INT | כן | 0 עד 2147483647 |
| `watermark` | האם להוסיף סימן מים "AI generated" לתמונה (ברירת מחדל: False). | BOOLEAN | כן | True / False |
| `thinking` | הפעל את תהליך החשיבה ('thinking') לאופטימיזציה של ההנחיה של המודל לצורך היצמדות טובה יותר. עשוי להאריך באופן ניכר את זמן היצירה — במיוחד ב-Seedream 5.0 Pro. ניתן להשבית רק עבור text-to-image (לא כאשר מסופקות תמונות עזר) (ברירת מחדל: True). | BOOLEAN | לא | True / False |

### הערות על אילוצים

- `width` ו-`height` נכנסים לתוקף רק כאשר `size_preset` מוגדר ל-`Custom`.
- סך תמונות העזר בתוספת התמונות שנוצרו לא יכול לעלות על 15.
- ניתן להשבית `thinking` רק עבור יצירת text-to-image, ולא כאשר מסופקות תמונות עזר.
- Seedream 5.0 Pro אינו תומך ביצירה באצווה: הוא תמיד מפיק תמונה אחת, ולכן `max_images` ו-`fail_on_partial` אינם זמינים עבור מודל זה.
