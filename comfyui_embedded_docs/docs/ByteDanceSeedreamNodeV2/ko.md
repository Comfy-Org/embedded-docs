# ByteDance Seedream 4.5 & 5.0

이 노드는 ByteDance Seedream 모델(4.0, 4.5, 5.0 Lite 및 5.0 Pro)을 사용하여 이미지를 생성하거나 편집합니다. 텍스트 프롬프트에서 새 이미지를 생성하고, 참조 이미지와 한 문장짜리 지시를 기반으로 기존 이미지를 편집할 수 있으며, 최대 4K 해상도를 지원합니다.

## 입력

`model` 선택기에 따라 사용 가능한 모델별 입력이 결정됩니다. 아래 표에는 공통 입력, 각 모델별 입력, 그리고 확장 가능한 참조 이미지 슬롯이 나와 있습니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 Seedream 모델 버전입니다. 각 모델은 서로 다른 기능, 제한 및 가격을 가지고 있습니다. | DYNAMIC_COMBO | 예 | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | 이미지를 생성하거나 편집하기 위한 텍스트 프롬프트입니다. | STRING | 예 | 모든 텍스트 (비어 있지 않아야 함) |
| `seed` | 생성에 사용할 시드입니다 (기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 이미지에 "AI 생성" 워터마크를 추가할지 여부입니다 (기본값: False). | BOOLEAN | 예 | True / False |
| `thinking` | 모델의 프롬프트 최적화 추론("thinking")을 활성화하여 지시 이행을 개선합니다. 생성 시간이 크게 늘어날 수 있으며, 특히 Seedream 5.0 Pro에서 두드러집니다. 텍스트-이미지 생성에서만 비활성화할 수 있습니다 (참조 이미지가 제공되면 비활성화 불가). (기본값: True) | BOOLEAN | 아니오 | True / False |

### seedream 5.0 pro 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | 권장 크기를 선택합니다. 아래의 너비와 높이를 사용하려면 Custom을 선택하세요. | COMBO | 예 | 모델별 프리셋 (Custom 포함) |
| `width` | 이미지에 대한 사용자 지정 너비입니다. `size_preset`이 Custom으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 to 3136 (step 2) |
| `height` | 이미지에 대한 사용자 지정 높이입니다. `size_preset`이 Custom으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 to 2496 (step 2) |

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|

### 참고 사항

- 사용자 지정 `width` 및 `height` 값은 `size_preset`이 Custom으로 설정된 경우에만 적용됩니다.
- 해상도 제한 (너비 × 높이 기준):
  - seedream 5.0 pro: 최소 0.92 MP, 최대 4.19 MP.
  - seedream 5.0 lite 및 seedream-4-5-251128: 최소 3.68 MP.
  - seedream-4-0-250828: 최소 0.92 MP.
  - seedream 5.0 lite, seedream-4-5-251128 및 seedream-4-0-250828: 최대 16.78 MP.
- 참조 이미지의 종횡비는 1:3에서 3:1 사이여야 합니다.
- `max_images`가 1보다 큰 경우 (seedream 5.0 lite, seedream-4-5-251128 및 seedream-4-0-250828에서 사용 가능), 총 이미지 수(참조 이미지와 생성 이미지의 합)는 15개를 초과할 수 없습니다.
- `thinking`은 텍스트-이미지 생성에서만 비활성화할 수 있습니다. 참조 이미지가 제공되면 반드시 활성화되어야 합니다.
- seedream 5.0 pro는 항상 단일 이미지를 생성하며 `max_images` 또는 `fail_on_partial` 입력을 표시하지 않습니다.
