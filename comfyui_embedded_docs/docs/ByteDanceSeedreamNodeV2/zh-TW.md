### 限制條件說明

- `width` 與 `height` 僅在 `size_preset` 設為 `Custom` 時生效。
- 參考圖像加上生成圖像的總數不得超過 15。
- `thinking` 僅能在文字轉圖像生成時停用，提供參考圖像時無法停用。
- Seedream 5.0 Pro 不支援批次生成：它始終產生單一圖像，因此 `max_images` 與 `fail_on_partial` 不適用於此模型。
