### 限制備註

- `width` 和 `height` 僅在 `size_preset` 設定為 `Custom` 時生效。
- 參考影像與生成的影像總數不得超過 15。
- `thinking` 僅能在文字轉影像生成時停用，不能在提供參考影像時停用。
- Seedream 5.0 Pro 不支援批次生成：它始終生成單張影像，因此 `max_images` 和 `fail_on_partial` 不適用於此模型。
