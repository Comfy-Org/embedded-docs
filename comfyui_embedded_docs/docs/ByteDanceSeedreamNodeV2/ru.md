# ByteDance Seedream 4.5 & 5.0 (устаревшая версия)

Этот узел генерирует или редактирует изображения с помощью моделей Seedream от ByteDance (версии 4.0, 4.5, 5.0 Lite и 5.0 Pro). Он обеспечивает унифицированную генерацию изображений по текстовому описанию и точное редактирование изображения с помощью одного предложения с разрешением до 4K. Это устаревшая (V2) версия узла Seedream.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Seedream, используемая для генерации. Каждая модель имеет разные возможности и стоимость. | DYNAMIC_COMBO | Да | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | Текстовое описание для создания или редактирования изображения (по умолчанию: пустая строка). | STRING | Да | N/A |
| `seed` | Зерно для генерации (по умолчанию: 0). | INT | Да | 0 до 2147483647 |
| `watermark` | Добавлять ли водяной знак «AI generated» на изображение (по умолчанию: False). | BOOLEAN | Да | True / False |
| `thinking` | Включает режим рассуждения («thinking») для оптимизации промпта моделью, что улучшает следование промпту. Может существенно увеличить время генерации — особенно для Seedream 5.0 Pro. Можно отключить только для генерации текст-в-изображение (но не когда предоставлены эталонные изображения) (по умолчанию: True). | BOOLEAN | Нет | True / False |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до N элементов (например, `image_1`, `image_2`, ...); ограничение количества зависит от выбранной модели (см. разделы моделей). Необязательные эталонные изображения для генерации изображение-в-изображение или мультиреференсной генерации. Без эталонных изображений узел работает в режиме текст-в-изображение. | IMAGE | Нет | 0 до 10 изображений (`seedream 5.0 pro`, `seedream-4-5-251128`, `seedream-4-0-250828`)<br>0 до 14 изображений (`seedream 5.0 lite`) |

### Примечания по ограничениям

- `width` и `height` применяются только когда `size_preset` установлен в `Custom`.
- Общее количество эталонных и сгенерированных изображений не может превышать 15.
- `thinking` можно отключить только для генерации текст-в-изображение, но не когда предоставлены эталонные изображения.
- Seedream 5.0 Pro не поддерживает пакетную генерацию: он всегда создаёт одно изображение, поэтому `max_images` и `fail_on_partial` недоступны для этой модели.
