# ByteDance Seedream 4.5 & 5.0

Этот узел генерирует или редактирует изображения с использованием моделей Seedream от ByteDance (версии 4.0, 4.5, 5.0 Lite и 5.0 Pro). Он обеспечивает унифицированную генерацию изображений по текстовому описанию и точное редактирование изображений по одному предложению с разрешением до 4K. Это унаследованная (V2) версия узла Seedream.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Seedream, используемая для генерации. Каждая модель имеет разные возможности и цены. | DYNAMIC_COMBO | Да | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | Текстовый запрос для создания или редактирования изображения (по умолчанию: пустая строка). | STRING | Да | Н/Д |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `watermark` | Добавлять ли водяной знак «AI generated» к изображению (по умолчанию: False). | BOOLEAN | Да | True / False |
| `thinking` | Включить оптимизацию запроса моделью («thinking») для лучшего соответствия. Может значительно увеличить время генерации — особенно на Seedream 5.0 Pro. Можно отключить только для генерации изображения по текстовому описанию (не при наличии эталонных изображений) (по умолчанию: True). | BOOLEAN | Нет | True / False |

### Входы `seedream 5.0 pro`

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | Выберите рекомендуемый размер. Выберите Custom, чтобы использовать указанные ниже ширину и высоту. | COMBO | Да | Доступно несколько предустановок для конкретной модели, включая `Custom` |
| `width` | Пользовательская ширина изображения. Значение работает только если `size_preset` установлен в `Custom` (по умолчанию: 2048). | INT | Да | от 1024 до 3136 (шаг 2) |
| `height` | Пользовательская высота изображения. Значение работает только если `size_preset` установлен в `Custom` (по умолчанию: 2048). | INT | Да | от 1024 до 2496 (шаг 2) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите 1..N элементов (например, `image_1`, `image_2`, ...); ограничение количества зависит от выбранной модели (см. разделы моделей). Необязательные эталонные изображения для генерации изображения по изображению или мультиэталонной генерации. При отсутствии эталонных изображений узел работает в режиме генерации по текстовому описанию. | IMAGE | Нет | от 0 до 10 изображений (`seedream 5.0 pro`, `seedream-4-5-251128`, `seedream-4-0-250828`)<br>от 0 до 14 изображений (`seedream 5.0 lite`) |

### Примечания по ограничениям

- `width` и `height` действуют только когда `size_preset` установлен в `Custom`.
- Общее количество эталонных и сгенерированных изображений не может превышать 15.
- `thinking` можно отключить только для генерации изображения по текстовому описанию, но не при наличии эталонных изображений.
- Seedream 5.0 Pro не поддерживает пакетную генерацию: он всегда создает одно изображение, поэтому `max_images` и `fail_on_partial` недоступны для этой модели.
