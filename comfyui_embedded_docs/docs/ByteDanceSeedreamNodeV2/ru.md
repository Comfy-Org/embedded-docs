# ByteDance Seedream 4.5 & 5.0

Этот узел создает или редактирует изображения с использованием моделей ByteDance Seedream (4.0, 4.5, 5.0 Lite и 5.0 Pro). Он генерирует новые изображения по текстовому запросу и может редактировать существующие изображения на основе референсных изображений и инструкции из одного предложения, поддерживая разрешение до 4K.

## Входы

Селектор `model` определяет, какие входные данные, специфичные для модели, доступны. В таблицах ниже перечислены общие входы, входы для каждой модели и расширяемые слоты референсных изображений.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Seedream для генерации. Каждая модель имеет разные возможности, ограничения и цены. | DYNAMIC_COMBO | Да | `"seedream 5.0 pro"`<br>`"seedream 5.0 lite"`<br>`"seedream-4-5-251128"`<br>`"seedream-4-0-250828"` |
| `prompt` | Текстовый запрос для создания или редактирования изображения. | STRING | Да | Любой текст (не пустой) |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | 0 to 2147483647 |
| `watermark` | Добавлять ли водяной знак «AI generated» к изображению (по умолчанию: False). | BOOLEAN | Да | True / False |
| `thinking` | Включить рассуждения модели по оптимизации запроса («мышление») для лучшего следования инструкциям. Может значительно увеличить время генерации — особенно на Seedream 5.0 Pro. Можно отключить только для режима «текст-в-изображение» (не при наличии референсных изображений). (по умолчанию: True) | BOOLEAN | Нет | True / False |

| `height` | Пользовательская высота изображения. Значение работает только если `size_preset` установлен в Custom (по умолчанию: 2048). | INT | Да | 1024 to 2496 (step 2) |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные референсные изображения для генерации image-to-image или мульти-референсной генерации. Расширяемый слот: подключите 1..N элементов (`image_1`, `image_2`, ..., `image_N`); максимальное количество зависит от выбранной модели (10 для seedream 5.0 pro, seedream-4-5-251128 и seedream-4-0-250828; 14 для seedream 5.0 lite). | IMAGE | Нет | 0 to 10<br>0 to 14 (seedream 5.0 lite) |

### Примечания

- Пользовательские значения `width` и `height` вступают в силу только когда `size_preset` установлен в Custom.
- Ограничения разрешения (на основе ширины × высоты):
  - seedream 5.0 pro: минимум 0.92 МП, максимум 4.19 МП.
  - seedream 5.0 lite и seedream-4-5-251128: минимум 3.68 МП.
  - seedream-4-0-250828: минимум 0.92 МП.
  - seedream 5.0 lite, seedream-4-5-251128 и seedream-4-0-250828: максимум 16.78 МП.
- Референсные изображения должны иметь соотношение сторон от 1:3 до 3:1.
- Когда `max_images` больше 1 (доступно на seedream 5.0 lite, seedream-4-5-251128 и seedream-4-0-250828), общее количество изображений (референсные плюс сгенерированные) не может превышать 15.
- `thinking` можно отключить только для создания изображения по текстовому запросу; при наличии референсных изображений он должен быть включен.
- seedream 5.0 pro всегда генерирует одно изображение и не показывает входы `max_images` или `fail_on_partial`.
