# LoopResult

LoopResult — это выходной узел только для разработчиков, который отмечает точку закрытия блока цикла. Он собирает значения, переданные в него по порядку (с именами `output0`, `output1` и так далее), и освобождает внешний блок выполнения, идентифицируемый по close ID. Поскольку определение отпечатков входных данных всегда возвращает NaN, узел считается всегда изменённым и перезапускается при каждом запуске.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `close_id` | Идентификатор закрываемого блока цикла; используется только первое значение из списка | STRING | Да | - |
| `output0`, `output1`, ... | Значения, собранные из блока цикла. Узел принимает любые дополнительные входы и собирает их в последовательном порядке, начиная с `output0`, останавливаясь на первом пропущенном индексе | Любой тип | Нет | - |

Примечание: Этот узел принимает все входы (`accept_all_inputs`). Любой вход, кроме `close_id`, рассматривается как собранное значение цикла и должен быть назван `output0`, `output1`, `output2` и т.д., без пропусков, чтобы быть включённым в результат.

## Выходы

Этот узел не возвращает никаких выходов. Он только освобождает внешний блок выполнения, связанный с `close_id`.
