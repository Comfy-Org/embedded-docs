# תוצאת לולאה

LoopResult הוא צומת פלט למפתחים בלבד המסמן את נקודת הסגירה של בלוק הלולאה. הוא אוסף את הערכים המועברים אליו לפי הסדר (בשמות `output0`, `output1`, וכן הלאה) ומשחרר את בלוק ההרצה החיצוני המזוהה באמצעות מזהה סגירה. מכיוון שטביעת האצבע של הקלט תמיד מחזירה NaN, הצומת נחשב כאילו השתנה תמיד ומורץ מחדש בכל הרצה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `close_id` | מזהה בלוק הלולאה שיש לסגור; נעשה שימוש רק בערך הראשון של הרשימה | STRING | כן | - |
| `output0`, `output1`, ... | ערכים שנאספים מבלוק הלולאה. הצומת מקבל קלטים נוספים כלשהם ומלקט אותם בסדר עוקב החל מ-`output0`, ונעצר באינדקס החסר הראשון | כל סוג | לא | - |

הערה: צומת זה מקבל את כל הקלטים (`accept_all_inputs`). כל קלט מעבר ל-`close_id` מטופל כערך לולאה שנאסף, ועליו להיקרא בשם `output0`, `output1`, `output2`, וכו', בלי פערים, כדי שייכלל בתוצאה.

## פלטים

צומת זה אינו מחזיר פלטים. הוא רק משחרר את בלוק ההרצה החיצוני המשויך ל-`close_id`.
