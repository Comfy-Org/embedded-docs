# Слияние моделей SD2

Узел ModelMergeSD2 объединяет две модели Stable Diffusion 2.x, смешивая их совпадающие компоненты, с отдельным весом для временного эмбеддинга, эмбеддинга меток и каждого входного, среднего и выходного блока. Структура блоков такая же, как в ModelMergeSD1, поэтому оба узла предоставляют одинаковый набор коэффициентов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель1` | Первая модель для объединения. Всё, что не вносит вторая модель, сохраняется из этой модели | MODEL | Да | - |
| `модель2` | Вторая модель для объединения. Её веса смешиваются согласно коэффициентам ниже | MODEL | Да | - |
| `time_embed.` | Коэффициент смешивания для слоя временного эмбеддинга (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `label_emb.` | Коэффициент смешивания для слоя эмбеддинга меток (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `input_blocks.0.` through `input_blocks.11.` | Коэффициент смешивания для каждого из 12 входных блоков (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `middle_block.0.` through `middle_block.2.` | Коэффициент смешивания для каждого из 3 средних блоков (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `output_blocks.0.` through `output_blocks.11.` | Коэффициент смешивания для каждого из 12 выходных блоков (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |
| `out.` | Коэффициент смешивания для выходного слоя (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |

Коэффициент 0.0 сохраняет компонент таким, каким он является в `model1`, коэффициент 1.0 полностью берёт его из `model2`, а промежуточные значения создают взвешенное смешивание. Оба входных значения должны быть моделями Stable Diffusion 2.x с одинаковой структурой блоков.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Объединённая модель, сочетающая оба входа согласно указанным коэффициентам | MODEL |
