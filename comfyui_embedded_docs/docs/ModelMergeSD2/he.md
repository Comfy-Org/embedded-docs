# ModelMergeSD2

צומת ModelMergeSD2 ממזגת שני מודלים של Stable Diffusion 2.x על ידי ערבוב הרכיבים התואמים שלהם, עם משקל נפרד עבור הטמעת הזמן, הטמעת התווית, וכל בלוק קלט, אמצע ופלט. מבנה הבלוקים זהה לזה שב-ModelMergeSD1, ולכן שני הצמתים חושפים את אותה קבוצת יחסים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model1` | המודל הראשון למיזוג. כל רכיב שהמודל השני אינו תורם לו נשמר מהמודל הזה | MODEL | כן | - |
| `model2` | המודל השני למיזוג. המשקלים שלו משולבים לפי היחסים שלהלן | MODEL | כן | - |
| `time_embed.` | יחס ערבוב עבור שכבת הטמעת הזמן (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `label_emb.` | יחס ערבוב עבור שכבת הטמעת התווית (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `input_blocks.0.` עד `input_blocks.11.` | יחס ערבוב עבור כל אחד מ-12 בלוקי הקלט (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `middle_block.0.` עד `middle_block.2.` | יחס ערבוב עבור כל אחד מ-3 בלוקי האמצע (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `output_blocks.0.` עד `output_blocks.11.` | יחס ערבוב עבור כל אחד מ-12 בלוקי הפלט (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `out.` | יחס ערבוב עבור שכבת הפלט (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |

יחס של 0.0 משאיר את הרכיב כפי שהוא ב-`model1`, יחס של 1.0 לוקח אותו כולו מ-`model2`, וערכים שביניהם יוצרים ערבוב משוקלל. שני הקלטים חייבים להיות מודלים של Stable Diffusion 2.x עם מבנה בלוקים זהה.
