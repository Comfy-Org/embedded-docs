# ModelMergeSD2

گره ModelMergeSD2 دو مدل Stable Diffusion 2.x را با ترکیب مؤلفه‌های متناظرشان ادغام می‌کند، با وزنی جداگانه برای جاسازی زمان، جاسازی برچسب و هر بلوک ورودی، میانی و خروجی. چیدمان بلوک‌ها همانند ModelMergeSD1 است؛ بنابراین هر دو گره مجموعه یکسانی از نسبت‌ها را ارائه می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model1` | اولین مدل برای ادغام. هر بخشی که مدل دوم در آن سهمی ندارد، از این مدل نگه داشته می‌شود | MODEL | بله | - |
| `model2` | دومین مدل برای ادغام. وزن‌های آن بر اساس نسبت‌های زیر ترکیب می‌شوند | MODEL | بله | - |
| `time_embed.` | نسبت ترکیب برای لایه جاسازی زمان (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `label_emb.` | نسبت ترکیب برای لایه جاسازی برچسب (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `input_blocks.0.` تا `input_blocks.11.` | نسبت ترکیب برای هر یک از 12 بلوک ورودی (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `middle_block.0.` تا `middle_block.2.` | نسبت ترکیب برای هر یک از 3 بلوک میانی (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `output_blocks.0.` تا `output_blocks.11.` | نسبت ترکیب برای هر یک از 12 بلوک خروجی (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `خروجی.` | نسبت ترکیب برای لایه خروجی (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |

نسبت 0.0 آن مؤلفه را همان‌طور که در `model1` است نگه می‌دارد، نسبت 1.0 آن را کاملاً از `model2` می‌گیرد، و مقادیر میان این دو یک ترکیب وزنی تولید می‌کنند. هر دو ورودی باید مدل‌های Stable Diffusion 2.x با ساختار بلوکی یکسان باشند.
