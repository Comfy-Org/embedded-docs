# ViduStartEndToVideoNode

הצומת Vidu Start End To Video Generation יוצר סרטון על ידי יצירת פריימים בין פריים התחלה לפריים סיום. הוא משתמש בהנחיית טקסט כדי להנחות את תהליך יצירת הווידאו ותומך במודלים שונים של וידאו עם הגדרות רזולוציה ותנועה שונות. הצומת מאמת שלפריימי ההתחלה והסיום יש יחסי רוחב-גובה תואמים לפני העיבוד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | שם המודל | COMBO | כן | `"viduq1"` |
| `first_frame` | פריים התחלה | IMAGE | כן | - |
| `end_frame` | פריים סיום | IMAGE | כן | - |
| `prompt` | תיאור טקסטואלי ליצירת וידאו | STRING | לא | - |
| `duration` | משך סרטון הפלט בשניות (ברירת מחדל: 5, קבוע על 5 שניות) | INT | לא | 5-5 |
| `seed` | Seed ליצירת וידאו (0 עבור אקראי) (ברירת מחדל: 0) | INT | לא | 0-2147483647 |
| `resolution` | הערכים הנתמכים עשויים להשתנות בהתאם למודל ולמשך (ברירת מחדל: "1080p") | COMBO | לא | `"1080p"` |
| `movement_amplitude` | משרעת התנועה של אובייקטים בפריים (ברירת מחדל: "auto") | COMBO | לא | `"auto"`<br>`"small"`<br>`"medium"`<br>`"large"` |

**הערה:** פריימי ההתחלה והסיום חייבים להיות בעלי יחסי רוחב-גובה תואמים (מאומת עם סבילות יחס של min_rel=0.8, max_rel=1.25).

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | קובץ הווידאו שנוצר | VIDEO |
