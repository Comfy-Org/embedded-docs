# OpenAIDalle2

تُنشئ الصور بشكل متزامن عبر نقطة نهاية DALL·E 2 من OpenAI. ترسل العقدة نصًا توجيهيًا إلى واجهة API DALL·E 2 من OpenAI وتعيد الصورة أو الصور الناتجة إلى ComfyUI. ويمكنها أيضًا تعديل صورة موجودة عند توفير كل من `image` و`mask` معًا.

## كيف يعمل

تتصل هذه العقدة بواجهة API DALL·E 2 من OpenAI لإنشاء صور بناءً على أوصاف نصية. عند تقديم نص توجيهي، ترسله العقدة إلى خوادم OpenAI التي تنشئ الصور المقابلة وتعيدها إلى ComfyUI. يمكن أن تعمل العقدة في وضعين: وضع توليد الصور القياسي باستخدام نص توجيهي فقط، أو وضع تعديل الصور عند توفير صورة وقناع معًا. في وضع التعديل، يستخدم القناع لتحديد الأجزاء من الصورة الأصلية التي ينبغي تعديلها مع إبقاء المناطق الأخرى دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `prompt` | نص توجيهي لـ DALL·E (الافتراضي: فارغ) | STRING | نعم | - |
| `seed` | لم يُنفذ بعد في الواجهة الخلفية (الافتراضي: 0) | INT | لا | 0 إلى 2147483647 |
| `size` | حجم الصورة (الافتراضي: "1024x1024") | COMBO | لا | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | عدد الصور المراد توليدها (الافتراضي: 1) | INT | لا | 1 إلى 8 |
| `image` | صورة مرجعية اختيارية لتعديل الصورة. | IMAGE | لا | - |
| `mask` | قناع اختياري للتعبئة الداخلية (سيتم استبدال المناطق البيضاء) | MASK | لا | - |

**ملاحظة:** يتم تفعيل وضع تعديل الصور فقط عند توفير كل من `image` و`mask` معًا. إذا تم توفير واحد منهما فقط، فسيتم رفع خطأ. يجب أن يكون حجم `mask` مطابقًا لحجم `image`؛ وإلا فسيتم رفع خطأ. في وضع التعديل، تشير المناطق البيضاء في القناع إلى المناطق التي سيتم استبدالها.
