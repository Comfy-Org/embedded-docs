# OpenAI DALL·E 2

OpenAI DALL·E 2 يُولّد الصور بشكل متزامن عبر نقطة نهاية DALL·E 2 الخاصة بـ OpenAI. قدّم موجهًا نصيًا لإنشاء صور جديدة، أو قدّم صورة وقناعًا معًا لتحرير صورة موجودة.

## آلية العمل

تتصل هذه العقدة بواجهة برمجة تطبيقات DALL·E 2 الخاصة بـ OpenAI لإنشاء صور بناءً على الأوصاف النصية. عند توفير موجه نصي، ترسله العقدة إلى خوادم OpenAI التي تولّد الصور المقابلة وتعيدها إلى ComfyUI. يمكن للعقدة العمل في وضعين: التوليد القياسي للصور باستخدام موجه نصي فقط، أو وضع تحرير الصور عند توفير كل من الصورة والقناع. في وضع التحرير، يُستخدَم القناع لتحديد أجزاء الصورة الأصلية التي يجب تعديلها مع إبقاء المناطق الأخرى دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | الموجه النصي لـ DALL·E (الافتراضي: فارغ) | STRING | نعم | - |
| `seed` | غير مطبّق بعد في النهاية الخلفية (الافتراضي: 0) | INT | لا | 0 إلى 2147483647 |
| `size` | حجم الصورة (الافتراضي: "1024x1024") | COMBO | لا | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | لا | 1 إلى 8 |
| `image` | صورة مرجعية اختيارية لتحرير الصور. | IMAGE | لا | - |
| `mask` | قناع اختياري للاستكمال (سيتم استبدال المناطق البيضاء) | MASK | لا | - |

ملاحظة: يجب توفير `image` و `mask` معًا. عند توفيرهما معًا، تتحول العقدة إلى وضع تحرير الصور. إذا تم توفير واحد فقط منهما، يتم إثارة خطأ. يجب أن يكون حجم `mask` مطابقًا لحجم `image`.
