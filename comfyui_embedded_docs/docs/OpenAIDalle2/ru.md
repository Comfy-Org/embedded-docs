# OpenAI DALL·E 2

OpenAI DALL·E 2 генерирует изображения синхронно через конечную точку OpenAI DALL·E 2. Укажите текстовый запрос для создания новых изображений или укажите и изображение, и маску для редактирования существующего изображения.

## Как это работает

Этот узел подключается к API OpenAI DALL·E 2 для создания изображений на основе текстовых описаний. Когда вы предоставляете текстовый запрос, узел отправляет его на серверы OpenAI, которые генерируют соответствующие изображения и возвращают их в ComfyUI. Узел может работать в двух режимах: стандартная генерация изображений с использованием только текстового запроса или режим редактирования изображения, когда предоставлены и изображение, и маска. В режиме редактирования маска используется для определения частей исходного изображения, которые должны быть изменены, с сохранением остальных областей без изменений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для DALL·E (по умолчанию: пусто) | STRING | Да | - |
| `seed` | Пока не реализовано в бэкенде (по умолчанию: 0) | INT | Нет | 0 to 2147483647 |
| `size` | Размер изображения (по умолчанию: "1024x1024") | COMBO | Нет | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | Сколько изображений генерировать (по умолчанию: 1) | INT | Нет | 1 to 8 |
| `image` | Необязательное исходное изображение для редактирования. | IMAGE | Нет | - |
| `mask` | Необязательная маска для инпейнтинга (белые области будут заменены) | MASK | Нет | - |

Примечание: `image` и `mask` должны быть указаны вместе. Когда указаны оба, узел переключается в режим редактирования изображения. Если указано только одно из них, возникает ошибка. `mask` должна быть того же размера, что и `image`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение(я) от DALL·E 2 | IMAGE |
