# OpenAIDalle2

Синхронно генерирует изображения через эндпоинт DALL·E 2 от OpenAI. Узел отправляет текстовый запрос в API DALL·E 2 от OpenAI и возвращает полученное изображение(я) в ComfyUI. Он также может редактировать существующее изображение, если вместе переданы и `image`, и `mask`.

## Как это работает

Этот узел подключается к API DALL·E 2 от OpenAI, чтобы создавать изображения на основе текстовых описаний. Когда вы предоставляете текстовый запрос, узел отправляет его на серверы OpenAI, которые генерируют соответствующие изображения и возвращают их в ComfyUI. Узел может работать в двух режимах: стандартная генерация изображений только по текстовому запросу или режим редактирования изображения, когда переданы и изображение, и маска. В режиме редактирования он использует маску, чтобы определить, какие части исходного изображения следует изменить, оставляя другие области без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовый запрос для DALL·E (по умолчанию: пусто) | STRING | Да | - |
| `seed` | пока не реализовано в бэкенде (по умолчанию: 0) | INT | Нет | от 0 до 2147483647 |
| `size` | Размер изображения (по умолчанию: "1024x1024") | COMBO | Нет | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | Сколько изображений сгенерировать (по умолчанию: 1) | INT | Нет | от 1 до 8 |
| `image` | Необязательное эталонное изображение для редактирования изображения. | IMAGE | Нет | - |
| `mask` | Необязательная маска для инпейнтинга (белые области будут заменены) | MASK | Нет | - |

**Примечание:** Режим редактирования изображения активируется только когда и `image`, и `mask` переданы вместе. Если передан только один из них, возникает ошибка. `mask` должен быть того же размера, что и `image`; в противном случае возникает ошибка. В режиме редактирования белые области маски указывают области, которые будут заменены.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Сгенерированное или отредактированное изображение(я) от DALL·E 2 | IMAGE |
