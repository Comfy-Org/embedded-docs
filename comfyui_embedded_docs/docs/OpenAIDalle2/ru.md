# OpenAI DALL·E 2

Генерирует изображения синхронно через конечную точку OpenAI DALL·E 2.

## Как это работает

Этот узел подключается к API OpenAI DALL·E 2 для создания изображений на основе текстовых описаний. Когда вы предоставляете текстовый запрос, узел отправляет его на серверы OpenAI, которые генерируют соответствующие изображения и возвращают их в ComfyUI. Узел может работать в двух режимах: стандартная генерация изображения с использованием только текстового запроса или режим редактирования изображения, когда указаны и изображение, и маска. В режиме редактирования узел использует маску для определения частей исходного изображения, которые должны быть изменены, сохраняя остальные области без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовый запрос для DALL·E (по умолчанию: пусто) | STRING | Да | - |
| `seed` | Ещё не реализовано в бэкенде (по умолчанию: 0) | INT | Нет | 0 до 2147483647 |
| `size` | Размер изображения (по умолчанию: "1024x1024") | COMBO | Нет | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | Сколько изображений генерировать (по умолчанию: 1) | INT | Нет | 1 до 8 |
| `image` | Необязательное эталонное изображение для редактирования изображения. | IMAGE | Нет | - |
| `mask` | Необязательная маска для инпейнтинга (белые области будут заменены) | MASK | Нет | - |

**Примечание:** Режим редактирования изображения активируется только когда `image` и `mask` предоставлены вместе. Если указан только один из них, возникает ошибка. `mask` должна быть того же размера, что и `image`; в противном случае возникает ошибка. В режиме редактирования белые области маски указывают на области, которые будут заменены.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Сгенерированное или отредактированное изображение(я) из DALL·E 2 | IMAGE |
