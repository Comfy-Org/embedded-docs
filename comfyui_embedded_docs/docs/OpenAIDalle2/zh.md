# OpenAI DALL·E 2

OpenAI DALL·E 2 通过 OpenAI 的 DALL·E 2 端点同步生成图像。提供文本提示即可创建新图像，或同时提供图像和蒙版以编辑现有图像。

## 工作原理

此节点连接到 OpenAI 的 DALL·E 2 API，根据文本描述创建图像。当您提供文本提示时，节点会将其发送到 OpenAI 的服务器，服务器生成相应的图像并将其返回给 ComfyUI。该节点支持两种模式：仅使用文本提示的标准图像生成模式，或同时提供图像和蒙版时的图像编辑模式。在编辑模式中，节点使用蒙版确定原始图像中需要修改的部分，同时保持其他区域不变。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | DALL·E 的文本提示（默认：空） | STRING | 是 | - |
| `seed` | 后端尚未实现（默认：0） | INT | 否 | 0 到 2147483647 |
| `size` | 图像尺寸（默认："1024x1024"） | COMBO | 否 | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | 要生成的图像数量（默认：1） | INT | 否 | 1 到 8 |
| `image` | 可选的参考图像，用于图像编辑。 | IMAGE | 否 | - |
| `mask` | 可选的蒙版，用于修复（白色区域将被替换） | MASK | 否 | - |

注意：`image` 和 `mask` 必须同时提供。当两者都提供时，节点将切换到图像编辑模式。如果仅提供其中之一，则会引发错误。`mask` 必须与 `image` 具有相同尺寸。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | DALL·E 2 生成或编辑后的图像 | IMAGE |
