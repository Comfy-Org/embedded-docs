# OpenAIDalle2

تولید تصاویر به‌صورت همگام از طریق نقطه پایانی DALL·E 2 شرکت OpenAI انجام می‌شود. این گره یک درخواست متنی را به API DALL·E 2 شرکت OpenAI می‌فرستد و تصویر(های) حاصل را به ComfyUI برمی‌گرداند. همچنین می‌تواند زمانی که هم `image` و هم `mask` با هم ارائه شوند، یک تصویر موجود را ویرایش کند.

## نحوه کار

این گره به API DALL·E 2 شرکت OpenAI متصل می‌شود تا بر اساس توصیف‌های متنی تصویر بسازد. وقتی یک درخواست متنی ارائه می‌دهید، گره آن را به سرورهای OpenAI می‌فرستد که تصاویر متناظر را تولید کرده و به ComfyUI برمی‌گردانند. این گره می‌تواند در دو حالت کار کند: تولید تصویر استاندارد تنها با استفاده از یک درخواست متنی، یا حالت ویرایش تصویر زمانی که هم تصویر و هم ماسک ارائه شوند. در حالت ویرایش، از ماسک استفاده می‌کند تا تعیین کند کدام بخش‌های تصویر اصلی باید تغییر کنند و سایر نواحی بدون تغییر بمانند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `prompt` | درخواست متنی برای DALL·E (پیش‌فرض: خالی) | STRING | بله | - |
| `seed` | هنوز در بک‌اند پیاده‌سازی نشده است (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |
| `size` | اندازه تصویر (پیش‌فرض: "1024x1024") | COMBO | خیر | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: 1) | INT | خیر | 1 تا 8 |
| `image` | تصویر مرجع اختیاری برای ویرایش تصویر. | IMAGE | خیر | - |
| `mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین می‌شوند) | MASK | خیر | - |

**توجه:** حالت ویرایش تصویر فقط زمانی فعال می‌شود که `image` و `mask` هر دو با هم ارائه شوند. اگر تنها یکی از آن‌ها ارائه شود، خطایی رخ می‌دهد. `mask` باید همان‌اندازه `image` باشد؛ در غیر این صورت خطایی رخ می‌دهد. در حالت ویرایش، نواحی سفید ماسک نشان‌دهنده مناطقی هستند که جایگزین خواهند شد.
