# OpenAI DALL·E 2

تصاویر را به‌صورت همگام از طریق نقطه‌اتصال DALL·E 2 شرکت OpenAI تولید می‌کند.

## نحوه کار

این گره به API دال‌ای ۲ اوپن‌ای‌آی متصل می‌شود تا بر اساس توضیحات متنی، تصویر ایجاد کند. وقتی یک متن ورودی ارائه می‌دهید، گره آن را به سرورهای اوپن‌ای‌آی ارسال می‌کند که تصاویر مربوطه را تولید کرده و به ComfyUI بازمی‌گردانند. گره می‌تواند در دو حالت کار کند: تولید تصویر استاندارد با استفاده از فقط یک متن ورودی، یا حالت ویرایش تصویر زمانی که هم تصویر و هم ماسک ارائه شوند. در حالت ویرایش، گره از ماسک برای تعیین بخش‌هایی از تصویر اصلی که باید تغییر کنند استفاده می‌کند و سایر نواحی را بدون تغییر نگه می‌دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `prompt` | متن ورودی برای DALL·E (پیش‌فرض: خالی) | STRING | بله | - |
| `seed` | هنوز در بک‌اند پیاده‌سازی نشده است (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |
| `size` | اندازه تصویر (پیش‌فرض: "1024x1024") | COMBO | خیر | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: 1) | INT | خیر | 1 تا 8 |
| `image` | تصویر مرجع اختیاری برای ویرایش تصویر. | IMAGE | خیر | - |
| `mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین خواهند شد) | MASK | خیر | - |

**نکته:** حالت ویرایش تصویر فقط زمانی فعال می‌شود که هر دو `image` و `mask` با هم ارائه شوند. اگر تنها یکی از آن‌ها ارائه شود، خطا برمی‌خیزد. `mask` باید هم‌اندازه `image` باشد؛ در غیر این صورت خطا رخ می‌دهد. در حالت ویرایش، نواحی سفید ماسک نشان‌دهنده مناطقی هستند که جایگزین خواهند شد.
