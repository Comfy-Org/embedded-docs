# OpenAI DALL·E 2

DALL·E 2 متعلق به OpenAI تصاویر را به‌صورت همزمان از طریق اندپوینت DALL·E 2 تولید می‌کند. برای ایجاد تصاویر جدید، یک پرامپت متنی ارائه دهید، یا برای ویرایش یک تصویر موجود، یک تصویر و یک ماسک را با هم ارائه دهید.

## نحوه عملکرد

این گره به API مربوط به DALL·E 2 شرکت OpenAI متصل می‌شود تا بر اساس توصیف‌های متنی تصویر ایجاد کند. وقتی یک پرامپت متنی ارائه می‌دهید، گره آن را به سرورهای OpenAI ارسال می‌کند؛ سرورها تصاویر متناظر را تولید کرده و به ComfyUI برمی‌گردانند. گره می‌تواند در دو حالت عمل کند: تولید استاندارد تصویر فقط با یک پرامپت متنی، یا حالت ویرایش تصویر وقتی که هم تصویر و هم ماسک ارائه می‌شوند. در حالت ویرایش، از ماسک برای تعیین بخش‌هایی از تصویر اصلی که باید تغییر کنند استفاده می‌شود؛ در حالی که سایر نواحی بدون تغییر باقی می‌مانند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن پرامپت برای DALL·E (پیش‌فرض: خالی) | STRING | بله | - |
| `seed` | هنوز در بک‌اند پیاده‌سازی نشده است (پیش‌فرض: 0) | INT | خیر | 0 to 2147483647 |
| `size` | اندازه تصویر (پیش‌فرض: "1024x1024") | COMBO | خیر | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | تعداد تصاویری که باید تولید شوند (پیش‌فرض: 1) | INT | خیر | 1 to 8 |
| `image` | تصویر مرجع اختیاری برای ویرایش تصویر. | IMAGE | خیر | - |
| `mask` | ماسک اختیاری برای ترمیم تصویر (inpainting)؛ ناحیه‌های سفید جایگزین خواهند شد | MASK | خیر | - |

نکته: `image` و `mask` باید با هم ارائه شوند. وقتی هر دو ارائه شوند، گره به حالت ویرایش تصویر تغییر می‌کند. اگر فقط یکی از آن‌ها ارائه شود، خطا ایجاد می‌شود. اندازه `mask` باید با `image` یکسان باشد.
