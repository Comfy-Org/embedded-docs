# OpenAI DALL·E 2

透過 OpenAI 的 DALL·E 2 端點同步產生圖片。

## 工作原理

此節點連線到 OpenAI 的 DALL·E 2 API，根據文字描述建立圖片。當您提供文字提示時，節點會將其傳送至 OpenAI 的伺服器，伺服器會產生對應的圖片並將其回傳至 ComfyUI。此節點可在兩種模式下運作：僅使用文字提示的標準圖片產生模式，或同時提供圖片與遮罩時的圖片編輯模式。在編輯模式下，它會使用遮罩來決定原始圖片的哪些部分應被修改，同時保持其他區域不變。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `提示詞` | 給 DALL·E 的文字提示（預設：空） | STRING | 是 | - |
| `種子` | 尚未在後端實作（預設：0） | INT | 否 | 0 至 2147483647 |
| `尺寸` | 圖片尺寸（預設："1024x1024"） | COMBO | 否 | "256x256"<br>"512x512"<br>"1024x1024" |
| `數量` | 要產生的圖片數量（預設：1） | INT | 否 | 1 至 8 |
| `參考影像` | 用於圖片編輯的選用參考圖片。 | IMAGE | 否 | - |
| `遮罩` | 用於局部重繪的選用遮罩（白色區域將被替換） | MASK | 否 | - |

**注意：** 僅當同時提供 `image` 和 `mask` 時，才會啟動圖片編輯模式。如果只提供其中一個，將引發錯誤。`mask` 必須與 `image` 尺寸相同，否則將引發錯誤。在編輯模式下，遮罩的白色區域表示將被替換的區域。
