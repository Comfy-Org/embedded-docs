# OpenAI DALL·E 2

OpenAI DALL·E 2 は、OpenAI の DALL·E 2 エンドポイントを介して画像を同期的に生成します。テキストプロンプトを指定して新しい画像を作成したり、画像とマスクの両方を指定して既存の画像を編集したりできます。

## 仕組み

このノードは、OpenAI の DALL·E 2 API に接続し、テキストによる説明に基づいて画像を作成します。テキストプロンプトを指定すると、ノードはそれを OpenAI のサーバーに送信し、サーバーが対応する画像を生成して ComfyUI に返します。このノードは、テキストプロンプトのみを使用した標準の画像生成モードと、画像とマスクの両方が指定された場合の画像編集モードの 2 つのモードで動作します。編集モードでは、マスクを使用して元の画像のどの部分を変更するかを決定し、他の領域は変更せずに保持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | DALL·E 用のテキストプロンプト（デフォルト: 空） | STRING | はい | - |
| `seed` | バックエンドではまだ実装されていません（デフォルト: 0） | INT | いいえ | 0 から 2147483647 |
| `size` | 画像サイズ（デフォルト: "1024x1024"） | COMBO | いいえ | "256x256"<br>"512x512"<br>"1024x1024" |
| `n` | 生成する画像の数（デフォルト: 1） | INT | いいえ | 1 から 8 |
| `image` | 画像編集用のオプションの参照画像。 | IMAGE | いいえ | - |
| `mask` | インペイント用のオプションのマスク（白い領域が置き換えられます） | MASK | いいえ | - |

注: `image` と `mask` は必ず一緒に指定する必要があります。両方が指定された場合、ノードは画像編集モードに切り替わります。どちらか一方のみが指定された場合は、エラーが発生します。`mask` は `image` と同じサイズである必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | DALL·E 2 によって生成または編集された画像 | IMAGE |
