# ByteDanceImageNode

צומת ByteDance Image יוצר תמונות באמצעות מודלים של ByteDance דרך API המבוסס על הנחיות טקסט. הוא מאפשר לך לבחור מודל, לציין ממדי תמונה ולשלוט בפרמטרים שונים של יצירה כגון seed ו-guidance scale. הצומת מתחבר לשירות יצירת התמונות של ByteDance ומחזיר את התמונה שנוצרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ByteDance שיש להשתמש בו ליצירת התמונה. נכון לעכשיו זמינה רק אפשרות מודל אחת. | STRING | כן | `"seedream-3-0-t2i-250415"` |
| `prompt` | הנחיית הטקסט המשמשת ליצירת התמונה. חייבת להיות באורך של לפחות תו אחד לאחר הסרת רווחים. | STRING | כן | - |
| `size_preset` | בחר גודל מומלץ. בחר Custom כדי להשתמש ברוחב ובגובה שלמטה. הפריסטים הזמינים מוגדרים על ידי הרשימה `RECOMMENDED_PRESETS`. | STRING | כן | ראו תיאור |
| `width` | רוחב מותאם אישית לתמונה. ערך זה משמש רק כאשר `size_preset` מוגדר ל-`Custom`. ברירת מחדל: 1024. | INT | כן | 512 to 2048 (step 64) |
| `height` | גובה מותאם אישית לתמונה. ערך זה משמש רק כאשר `size_preset` מוגדר ל-`Custom`. ברירת מחדל: 1024. | INT | כן | 512 to 2048 (step 64) |
| `seed` | ערך seed שיש להשתמש בו ליצירה. ברירת מחדל: 0. | INT | לא | 0 to 2147483647 (step 1) |
| `guidance_scale` | ערך גבוה יותר גורם לתמונה לפעול לפי ההנחיה בצורה צמודה יותר. ברירת מחדל: 2.5. | FLOAT | לא | 1.0 to 10.0 (step 0.01) |
| `watermark` | האם להוסיף סימן מים "AI generated" לתמונה. ברירת מחדל: False. זהו פרמטר מתקדם. | BOOLEAN | לא | True / False |

**הערה על פרמטרי גודל:** הפרמטרים `width` ו-`height` משמשים רק כאשר `size_preset` מוגדר ל-`Custom`. אם נבחר גודל מוגדר מראש, מידותיו גוברות על ערכי הרוחב והגובה המותאמים אישית. גם הרוחב וגם הגובה חייבים להיות בין 512 ל-2048 פיקסלים בעת שימוש במידות מותאמות אישית.
