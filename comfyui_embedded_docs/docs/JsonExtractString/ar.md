# استخراج سلسلة من JSON

تفحص عقدة JsonExtractString سلسلة نصية بحثًا عن أول كائن JSON صالح، وتستخرج القيمة المرتبطة بمفتاح محدد، محوّلة إلى سلسلة نصية. يتم تجاهل أي نص قبل كائن JSON أو بعده، لذا تعمل العقدة أيضًا مع كتل كود Markdown ومع ردود النماذج التي تغلّف JSON بنص إضافي. إذا لم يتم العثور على كائن JSON صالح، أو لم يتم العثور على المفتاح، أو كانت القيمة `null`، فتُعيد العقدة سلسلة نصية فارغة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `سلسلة_json` | النص المراد البحث فيه عن كائن JSON. يدعم هذا الحقل الإدخال متعدد الأسطر وقد يحتوي على نص نثري محيط أو أسوار كود Markdown. | STRING | نعم | N/A |
| `مفتاح` | المفتاح المحدد الذي تريد استخراج قيمته من كائن JSON. يدعم هذا الحقل الإدخال أحادي السطر فقط. | STRING | نعم | N/A |

**ملاحظة:** تستخرج العقدة القيم فقط من كائنات JSON (القواميس). تحاول كل `{` في الإدخال بالترتيب وتفكّ الترميز من أول موضع ينتج كائن JSON صالح، لذلك يتم تخطي النص البادئ أو اللاحق. إذا تعذّر فك ترميز أي كائن JSON أو لم يكن المفتاح المحدد موجودًا بداخله، يكون المخرَج سلسلة نصية فارغة. إذا كانت القيمة المرتبطة بالمفتاح هي `null`، فتُعيد العقدة أيضًا سلسلة نصية فارغة. تُعاد القيم التي ليست سلاسل نصية بتمثيلها النصي.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | القيمة النصية المستخرجة من JSON للمفتاح المحدد، أو سلسلة نصية فارغة إذا فشل الاستخراج. | STRING |
