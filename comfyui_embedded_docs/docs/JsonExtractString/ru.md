# Извлечь строку из JSON

Узел JsonExtractString сканирует текстовую строку в поисках первого корректного объекта JSON и извлекает значение, связанное с определённым ключом, преобразованное в строку. Любой текст до или после объекта JSON игнорируется, поэтому узел также работает с блоками кода Markdown и с ответами модели, в которых JSON обёрнут в дополнительный текст. Если корректный объект JSON не найден, ключ не найден или значение равно `null`, узел возвращает пустую строку.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `json_string` | Текст для поиска объекта JSON. Это поле поддерживает многострочный ввод и может содержать окружающий текст или блоки кода Markdown. | STRING | Да | N/A |
| `key` | Определённый ключ, значение которого нужно извлечь из объекта JSON. Это поле поддерживает только однострочный ввод. | STRING | Да | N/A |

**Примечание:** Узел извлекает значения только из объектов JSON (словарей). Он по порядку пробует каждый `{` во входных данных и декодирует с первой позиции, которая даёт корректный объект JSON, поэтому текст до и после пропускается. Если объект JSON не удаётся декодировать или указанный ключ в нём отсутствует, выходные данные — пустая строка. Если значение, связанное с ключом, равно `null`, узел также возвращает пустую строку. Значения, не являющиеся строками, возвращаются в виде их строкового представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Строковое значение, извлечённое из JSON для указанного ключа, или пустая строка, если извлечение не удалось. | STRING |
