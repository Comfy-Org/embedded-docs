# استخراج رشته از JSON

گره JsonExtractString یک رشته متنی را برای یافتن نخستین شیء JSON معتبر اسکن می‌کند و مقدار مرتبط با یک کلید مشخص را استخراج می‌کند، که به رشته تبدیل شده است. هر متنی پیش یا پس از شیء JSON نادیده گرفته می‌شود، بنابراین این گره روی بلوک‌های کد Markdown و نیز پاسخ‌های مدل که JSON را در متن اضافی می‌پیچند نیز کار می‌کند. اگر هیچ شیء JSON معتبری یافت نشود، کلید پیدا نشود، یا مقدار null باشد، گره یک رشته خالی برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `json_string` | متنی که باید برای یافتن یک شیء JSON جستجو شود. این فیلد از ورودی چندخطی پشتیبانی می‌کند و ممکن است شامل متن‌های اطراف یا حصارهای کد Markdown باشد. | STRING | بله | N/A |
| `key` | کلید مشخصی که می‌خواهید مقدار آن از شیء JSON استخراج شود. این فیلد فقط از ورودی تک‌خطی پشتیبانی می‌کند. | STRING | بله | N/A |

**توجه:** گره مقادیر را فقط از شیءهای JSON (دیکشنری‌ها) استخراج می‌کند. هر `{` را در ورودی به‌ترتیب امتحان می‌کند و از نخستین موقعیتی که یک شیء JSON معتبر تولید کند رمزگشایی می‌کند، بنابراین متن پیش یا پس از آن نادیده گرفته می‌شود. اگر هیچ شیء JSON قابل رمزگشایی نباشد یا کلید مشخص‌شده در آن وجود نداشته باشد، خروجی یک رشته خالی است. اگر مقدار مرتبط با کلید `null` باشد، گره نیز یک رشته خالی برمی‌گرداند. مقادیری که رشته نیستند به‌صورت نمایش رشته‌ای‌شان برگردانده می‌شوند.

## خروجی‌ها
