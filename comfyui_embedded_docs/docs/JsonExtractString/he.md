# JsonExtractString

הצומת JsonExtractString סורק מחרוזת טקסט אחר אובייקט JSON תקין ראשון ומחלץ את הערך המשויך למפתח מסוים, כשהוא מומר למחרוזת. כל טקסט לפני או אחרי אובייקט ה-JSON מתעלמים ממנו, כך שהצומת עובד גם על בלוקי קוד של Markdown וגם על תשובות מודל שעוטפות את ה-JSON בטקסט נוסף. אם לא נמצא אובייקט JSON תקין, המפתח לא נמצא, או הערך הוא `null`, הצומת מחזיר מחרוזת ריקה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `json_string` | הטקסט שבו יש לחפש אובייקט JSON. שדה זה תומך בקלט רב-שורתי ועשוי להכיל טקסט עוטף או גדרות קוד של Markdown. | STRING | כן | N/A |
| `key` | המפתח הספציפי שאת ערכו יש לחלץ מאובייקט ה-JSON. שדה זה תומך בקלט של שורה אחת בלבד. | STRING | כן | N/A |

**הערה:** הצומת מחלץ ערכים רק מאובייקטים של JSON (מילונים). הוא מנסה כל `{` בקלט לפי הסדר ומפענח מהמיקום הראשון שמניב אובייקט JSON תקין, כך שטקסט מוביל או נגרר מדולג. אם לא ניתן לפענח אובייקט JSON כלשהו או שהמפתח שצוין אינו קיים בו, הפלט הוא מחרוזת ריקה. אם הערך המשויך למפתח הוא `null`, הצומת גם מחזיר מחרוזת ריקה. ערכים שאינם מחרוזות מוחזרים כייצוג המחרוזתי שלהם.
