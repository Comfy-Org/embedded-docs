# LumaReferenceNode

צומת זה מחזיק תמונה וערך משקל לשימוש עם הצומת Luma Generate Image. הוא יוצר שרשרת ייחוס שניתן להעביר לצומתי Luma אחרים כדי להשפיע על יצירת התמונה. הצומת יכול להתחיל שרשרת ייחוס חדשה או להוסיף לשרשרת קיימת.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונה שתשמש כייחוס. | IMAGE | כן | - |
| `weight` | משקל ייחוס התמונה (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 - 1.0 |
| `luma_ref` | שרשרת ייחוס קיימת של Luma להוספה (אופציונלי). | LUMA_REF | לא | - |

## פלטים
