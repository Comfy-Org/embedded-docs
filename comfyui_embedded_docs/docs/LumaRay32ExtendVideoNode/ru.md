# Luma Ray 3.2 Продлить видео

Luma Ray 3.2 Extend Video продолжает предыдущую генерацию видео Luma Ray 3.2, создавая новый 5-секундный сегмент либо после исходного клипа (forward), либо до него (backward). Подключите выход `generation_id` более раннего узла Luma Ray 3.2, чтобы использовать этот клип как начальный кадр (forward) или конечный кадр (backward) расширения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `direction` | Forward продолжает после предыдущего клипа; backward добавляется перед ним. Forward использует исходный клип как начальный кадр; backward — как конечный. Выбор «Forward (continue after)» добавляет опцию `loop`. | DYNAMIC_COMBO | Да | "Forward (continue after)"<br>"Backward (lead-in before)" |
| `source_generation_id` | Идентификатор генерации предыдущего видео Ray 3.2 для расширения. Подключите выход `generation_id` другого узла Luma Ray 3.2. Это значение обязательно и не должно быть пустым. | STRING | Да | – |
| `prompt` | Текстовый промпт для нового контента. Должен содержать от 1 до 6000 символов. | STRING | Да | от 1 до 6000 символов |
| `resolution` | Разрешение выходного видео для расширенного сегмента. По умолчанию: «720p». | COMBO | Да | "540p"<br>"720p"<br>"1080p" |
| `seed` | Сид для определения необходимости повторного запуска узла; результаты недетерминированы независимо от сида. По умолчанию: 0. | INT | Да | 0 до 0xFFFFFFFFFFFFFFFF |

### Входы Forward (continue after)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `loop` | Зациклить расширенное видео бесшовно (только для расширения вперед). По умолчанию: False. | BOOLEAN | Нет | True<br>False |

### Входы Backward (lead-in before)

Это направление не добавляет дополнительных параметров.

**Примечание:** Расширения всегда имеют длительность 5 секунд. Параметр `loop` доступен только когда `direction` имеет значение «Forward (continue after)»; при использовании «Backward (lead-in before)» опция `loop` недоступна. Параметр `prompt` должен содержать от 1 до 6000 символов. Параметр `source_generation_id` обязателен и должен быть подключен из выхода `generation_id` предыдущего узла Luma Ray 3.2.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный 5-секундный расширенный видеофрагмент. | VIDEO |
| `generation_id` | Уникальный идентификатор этой генерации, который можно подключить к другому узлу Luma Ray 3.2 Extend Video для дальнейших расширений. | STRING |
