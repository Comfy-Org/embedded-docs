# Luma Ray 3.2 Продлить видео

Luma Ray 3.2 Extend Video продолжает предыдущую генерацию видео Luma Ray 3.2, создавая новый 5-секундный сегмент либо после исходного клипа (вперед), либо перед ним (назад). Подключите выход `generation_id` предыдущего узла Luma Ray 3.2, чтобы использовать этот клип как начальный кадр (вперед) или конечный кадр (назад) расширения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | Идентификатор генерации предыдущего видео Ray 3.2, которое нужно расширить. Подключите выход `generation_id` другого узла Luma Ray 3.2. Это значение обязательно и не должно быть пустым. | STRING | Да | – |
| `direction` | Прямое направление продолжает после предыдущего клипа; обратное добавляется перед ним. При выборе "Forward (continue after)" также доступна опция `loop`. | COMBO | Да | "Forward (continue after)"<br>"Backward (lead-in before)" |
| `loop` | Зациклить расширенное видео бесшовно (только при продлении вперед). Доступно только когда `direction` установлен в "Forward (continue after)". По умолчанию: False. | BOOLEAN | Нет | True<br>False |
| `prompt` | Текстовый запрос (промпт) для нового контента. Должен содержать от 1 до 6000 символов. | STRING | Да | – |
| `resolution` | Разрешение выходного сегмента расширенного видео. По умолчанию: "720p". | COMBO | Да | "540p"<br>"720p"<br>"1080p" |
| `seed` | Случайное зерно (seed) для воспроизводимых результатов генерации. | INT | Да | – |

**Примечание:** Параметр `loop` доступен только когда `direction` установлен в "Forward (continue after)". При использовании "Backward (lead-in before)" опция `loop` недоступна. `prompt` должен содержать от 1 до 6000 символов. `source_generation_id` обязателен и должен быть подключен к выходу `generation_id` предыдущего узла Luma Ray 3.2.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный 5-секундный сегмент расширенного видео. | VIDEO |
| `generation_id` | Уникальный идентификатор данной генерации, который можно подключить к другому узлу Luma Ray 3.2 Extend Video для дальнейших расширений. | STRING |
