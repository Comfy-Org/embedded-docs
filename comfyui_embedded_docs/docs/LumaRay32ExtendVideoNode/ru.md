# Luma Ray 3.2 Продлить видео

Luma Ray 3.2 Extend Video продолжает предыдущую генерацию видео Luma Ray 3.2, создавая новый 5-секундный сегмент либо после исходного клипа (forward), либо перед ним (backward). Подключите выход `generation_id` от более раннего узла Luma Ray 3.2, чтобы использовать этот клип в качестве начального кадра (forward) или конечного кадра (backward) расширения. Расширения всегда имеют длительность 5 секунд.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | Generation ID предыдущего видео Ray 3.2, которое нужно расширить. Подключите выход `generation_id` другого узла Luma Ray 3.2. По умолчанию: "" (пусто). Это значение обязательно и не должно быть пустым. | STRING | Да | – |
| `direction` | Forward продолжает после предыдущего клипа; Backward добавляется перед ним. Forward использует исходный клип как начальный кадр; Backward использует его как конечный кадр. Выбор "Forward (continue after)" добавляет опцию `loop`. | DYNAMIC_COMBO | Да | "Forward (continue after)"<br>"Backward (lead-in before)" |
| `prompt` | Текстовый промпт для нового содержимого. По умолчанию: "" (пусто). Должен содержать от 1 до 6000 символов. | STRING | Да | от 1 до 6000 символов |
| `resolution` | Выходное разрешение для расширенного видеосегмента. По умолчанию: "720p". | COMBO | Да | "540p"<br>"720p"<br>"1080p" |
| `seed` | Seed для определения, должен ли узел перезапуститься; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Да | от 0 до 0xFFFFFFFFFFFFFFFF (18446744073709551615) |

### Входы Forward (continue after)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `loop` | Зацикливать расширенное видео без разрывов (только для прямого расширения). По умолчанию: False. | BOOLEAN | Нет | True<br>False |

### Входы Backward (lead-in before)

Это направление не добавляет дополнительных параметров.

**Примечание:** Расширения всегда имеют длительность 5 секунд. Параметр `loop` доступен только когда `direction` имеет значение "Forward (continue after)"; при использовании "Backward (lead-in before)" опция `loop` недоступна. `prompt` должен содержать от 1 до 6000 символов. `source_generation_id` обязателен и должен быть подключён к выходу `generation_id` предыдущего узла Luma Ray 3.2.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный 5-секундный расширенный видеосегмент. | VIDEO |
| `generation_id` | Уникальный идентификатор этой генерации, который можно подключить к другому узлу Luma Ray 3.2 Extend Video для дальнейших расширений. | STRING |
