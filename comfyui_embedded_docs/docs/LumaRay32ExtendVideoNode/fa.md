# Luma Ray 3.2 گسترش ویدیو

Luma Ray 3.2 Extend Video با ایجاد یک بخش ۵ ثانیه‌ای جدید، پس از کلیپ اصلی (forward) یا قبل از آن (backward)، ویدیوی تولیدشده‌ی قبلی Luma Ray 3.2 را ادامه می‌دهد. خروجی `generation_id` را از یک گره‌ی قبلی Luma Ray 3.2 وصل کنید تا از آن کلیپ به‌عنوان فریم شروع (forward) یا فریم پایان (backward) در ادامه‌دهی استفاده شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `جهت` | Forward پس از کلیپ قبلی ادامه می‌دهد؛ backward قبل از آن قرار می‌گیرد. Forward از کلیپ منبع به‌عنوان فریم شروع استفاده می‌کند؛ backward از آن به‌عنوان فریم پایان استفاده می‌کند. انتخاب «Forward (continue after)» گزینه‌ی `loop` را اضافه می‌کند. | DYNAMIC_COMBO | بله | "Forward (continue after)"<br>"Backward (lead-in before)" |
| `source_generation_id` | شناسه‌ی تولید ویدیوی Ray 3.2 قبلی برای ادامه‌دهی. خروجی `generation_id` یک گره‌ی دیگر Luma Ray 3.2 را وصل کنید. این مقدار الزامی است و نباید خالی باشد. | STRING | بله | – |
| `پرامپت` | متن راهنمای (prompt) محتوای جدید. باید بین ۱ تا ۶۰۰۰ کاراکتر باشد. | STRING | بله | ۱ تا ۶۰۰۰ کاراکتر |
| `رزولوشن` | وضوح خروجی برای بخش ویدیوی ادامه‌یافته. پیش‌فرض: «720p». | COMBO | بله | "540p"<br>"720p"<br>"1080p" |
| `seed` | Seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از seed قطعی نیستند. پیش‌فرض: ۰. | INT | بله | 0 تا 0xFFFFFFFFFFFFFFFF |

### ورودی‌های Forward (continue after)

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `loop` | ویدیوی ادامه‌یافته را به‌صورت بی‌وقفه حلقه کنید (فقط برای ادامه‌دهی رو به جلو). پیش‌فرض: False. | BOOLEAN | خیر | True<br>False |

### ورودی‌های Backward (lead-in before)

این جهت پارامتر اضافی‌ای اضافه نمی‌کند.

**توجه:** ادامه‌ها (Extensions) همیشه ۵ ثانیه هستند. پارامتر `loop` تنها زمانی در دسترس است که `direction` برابر با «Forward (continue after)» باشد؛ هنگام استفاده از «Backward (lead-in before)»، گزینه‌ی `loop` در دسترس نیست. `prompt` باید بین ۱ تا ۶۰۰۰ کاراکتر باشد. `source_generation_id` الزامی است و باید از خروجی `generation_id` یک گره‌ی قبلی Luma Ray 3.2 متصل شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `VIDEO` | بخش ویدیوی ادامه‌یافته‌ی ۵ ثانیه‌ای تولیدشده. | VIDEO |
| `generation_id` | شناسه‌ی یکتای این تولید، که می‌تواند برای ادامه‌های بیشتر به یک گره‌ی دیگر Luma Ray 3.2 Extend Video متصل شود. | STRING |
