# LumaRay32ExtendVideoNode

Luma Ray 3.2 Extend Video با ایجاد یک بخش جدید ۵ ثانیه‌ای، چه بعد از کلیپ اصلی (رو به جلو) چه قبل از آن (رو به عقب)، تولید ویدیوی قبلی Luma Ray 3.2 را ادامه می‌دهد. خروجی `generation_id` یک گره Luma Ray 3.2 قبلی را متصل کنید تا آن کلیپ به‌عنوان فریم شروع (رو به جلو) یا پایان (رو به عقب) گسترش استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | شناسه تولید ویدیوی قبلی Ray 3.2 که باید گسترش یابد. خروجی `generation_id` گره Luma Ray 3.2 دیگری را متصل کنید. این مقدار الزامی است و نباید خالی باشد. | STRING | بله | - |
| `جهت` | رو به جلو بعد از کلیپ قبلی ادامه می‌یابد؛ رو به عقب قبل از آن اضافه می‌شود. انتخاب "Forward (continue after)" گزینه `loop` را نیز اضافه می‌کند. | COMBO | بله | "رو به جلو (ادامه پس از)"<br>"رو به عقب (پیش‌درآمد پیش از)" |
| `loop` | ویدیوی گسترش‌یافته را به‌صورت یکپارچه حلقه می‌زند (فقط گسترش رو به جلو). فقط زمانی در دسترس است که `direction` روی "Forward (continue after)" باشد. پیش‌فرض: False. | BOOLEAN | خیر | True<br>False |
| `پرامپت` | پرامپت متنی برای محتوای جدید. باید بین ۱ تا ۶۰۰۰ کاراکتر باشد. | STRING | بله | - |
| `رزولوشن` | وضوح خروجی برای بخش ویدیوی گسترش‌یافته. پیش‌فرض: "720p". | COMBO | بله | "540p"<br>"720p"<br>"1080p" |
| `seed` | دانه تصادفی (seed) برای نتایج تولید قابل تکرار. | INT | بله | - |

**توجه:** پارامتر `loop` تنها زمانی در دسترس است که `direction` روی "رو به جلو (ادامه پس از)" تنظیم شده باشد. هنگام استفاده از "رو به عقب (پیش‌درآمد پیش از)"، گزینه حلقه در دسترس نیست. `prompt` باید بین ۱ تا ۶۰۰۰ کاراکتر باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `VIDEO` | بخش ویدیوی تمدیدشده ۵ ثانیه‌ای تولیدشده. | VIDEO |
| `generation_id` | شناسه یکتای این تولید که می‌تواند برای تمدیدهای بیشتر به یک گره دیگر Luma Ray 3.2 Extend Video متصل شود. | STRING |
