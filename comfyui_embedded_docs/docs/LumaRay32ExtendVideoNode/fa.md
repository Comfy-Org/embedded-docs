# Luma Ray 3.2 گسترش ویدیو

Luma Ray 3.2 Extend Video یک تولید ویدئوی قبلی Luma Ray 3.2 را با ایجاد یک بخش 5 ثانیه‌ای جدید، یا پس از کلیپ اصلی (forward) یا پیش از آن (backward)، ادامه می‌دهد. خروجی `generation_id` را از یک گره Luma Ray 3.2 قبلی متصل کنید تا از آن کلیپ به‌عنوان فریم شروع (forward) یا فریم پایانی (backward) برای الحاق استفاده شود. الحاق‌ها همیشه 5 ثانیه طول دارند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | شناسه تولید ویدئوی Ray 3.2 قبلی برای الحاق. خروجی `generation_id` یک گره دیگر Luma Ray 3.2 را متصل کنید. پیش‌فرض: "" (خالی). این مقدار الزامی است و نباید خالی باشد. | STRING | بله | – |
| `جهت` | حالت Forward پس از کلیپ قبلی ادامه می‌دهد؛ حالت backward به ابتدای آن افزوده می‌شود. حالت Forward از کلیپ مبدأ به‌عنوان فریم شروع استفاده می‌کند؛ حالت backward از آن به‌عنوان فریم پایانی استفاده می‌کند. انتخاب "Forward (continue after)" گزینه `loop` را اضافه می‌کند. | DYNAMIC_COMBO | بله | "Forward (continue after)"<br>"Backward (lead-in before)" |
| `پرامپت` | پرامپت متنی برای محتوای جدید. پیش‌فرض: "" (خالی). باید بین 1 تا 6000 کاراکتر باشد. | STRING | بله | 1 تا 6000 کاراکتر |
| `رزولوشن` | رزولوشن خروجی برای بخش ویدئوی الحاق‌شده. پیش‌فرض: "720p". | COMBO | بله | "540p"<br>"720p"<br>"1080p" |
| `seed` | Seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج بدون توجه به مقدار seed غیرقطعی هستند. پیش‌فرض: 0. | INT | بله | 0 تا 0xFFFFFFFFFFFFFFFF (18446744073709551615) |

### ورودی‌های Forward (continue after)

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `loop` | ویدئوی الحاق‌شده را به‌صورت بدون درز حلقه‌ای می‌کند (فقط الحاق رو به جلو). پیش‌فرض: False. | BOOLEAN | خیر | True<br>False |

### ورودی‌های Backward (lead-in before)

این حالت هیچ پارامتر اضافه‌ای اضافه نمی‌کند.

**توجه:** الحاق‌ها همیشه 5 ثانیه هستند. پارامتر `loop` فقط زمانی در دسترس است که `direction` روی "Forward (continue after)" باشد؛ هنگام استفاده از "Backward (lead-in before)"، گزینه `loop` در دسترس نیست. `prompt` باید بین 1 تا 6000 کاراکتر باشد. `source_generation_id` الزامی است و باید از خروجی `generation_id` یک گره Luma Ray 3.2 قبلی متصل شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `VIDEO` | بخش ویدئوی 5 ثانیه‌ای الحاق‌شده تولیدشده. | VIDEO |
| `generation_id` | شناسه یکتای این تولید، که می‌توان آن را برای الحاق‌های بیشتر به یک گره Luma Ray 3.2 Extend Video دیگر متصل کرد. | STRING |
