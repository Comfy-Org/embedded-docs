# LumaRay32ExtendVideoNode

تواصل Luma Ray 3.2 Extend Video توليد فيديو سابق لـ Luma Ray 3.2 عن طريق إنشاء مقطع جديد مدته 5 ثوانٍ إما بعد المقطع الأصلي (للأمام) أو قبله (للخلف). قم بتوصيل مخرج `generation_id` من عقدة Luma Ray 3.2 سابقة لاستخدام هذا المقطع كإطار بداية (للأمام) أو نهاية (للخلف) للامتداد.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | معرف توليد فيديو Ray 3.2 السابق المراد تمديده. قم بتوصيل مخرج `generation_id` لعقدة Luma Ray 3.2 أخرى. هذه القيمة مطلوبة ويجب ألا تكون فارغة. | STRING | نعم | - |
| `الاتجاه` | الأمامي يستمر بعد المقطع السابق؛ الخلفي يُضاف قبله. اختيار "Forward (continue after)" يضيف أيضًا خيار `loop`. | COMBO | نعم | "أمامي (استمرار بعد)"<br>"خلفي (مقدمة قبل)" |
| `loop` | تكرار الفيديو الممتد بسلاسة (للتمديد الأمامي فقط). متاح فقط عندما يكون `الاتجاه` هو "Forward (continue after)". الافتراضي: False. | BOOLEAN | لا | صحيح<br>خطأ |
| `الموجه النصي` | النص التوجيهي للمحتوى الجديد. يجب أن يتراوح طوله بين 1 و6000 حرف. | STRING | نعم | - |
| `الدقة` | دقة الإخراج لمقطع الفيديو الممتد. الافتراضي: "720p". | COMBO | نعم | "540p"<br>"720p"<br>"1080p" |
| `البذرة` | بذرة عشوائية لإعادة إنتاج نتائج التوليد بشكل متكرر. | INT | نعم | - |

**ملاحظة:** المعامل `loop` متاح فقط عندما يكون `direction` مضبوطًا على "أمامي (استمرار بعد)". عند استخدام "خلفي (مقدمة قبل)"، لا يكون خيار الحلقة متاحًا. يجب أن يتراوح النص الوصفي `prompt` بين حرف واحد و6000 حرف.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `generation_id` | مقطع الفيديو الممتد المُنشأ لمدة 5 ثوانٍ. | VIDEO |
| `generation_id` | معرف فريد لهذا التوليد، يمكن توصيله بعقدة Luma Ray 3.2 Extend Video أخرى لمزيد من التمديدات. | STRING |
