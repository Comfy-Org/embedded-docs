# Применить операцию к латенту CFG

Узел LatentApplyOperationCFG применяет латентную операцию для изменения процесса управления кондиционированием в модели. Он работает путём перехвата выходов кондиционирования во время процесса семплирования CFG (classifier-free guidance) и применения указанной операции к латентным представлениям перед их использованием для генерации. Когда сэмплер создаёт два выхода кондиционирования, операция применяется к разности между ними, а затем второй выход добавляется обратно к результату.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой будет применена операция CFG | MODEL | Да | - |
| `операция` | Латентная операция, применяемая во время процесса семплирования CFG | LATENT_OPERATION | Да | - |

Примечание: Этот узел помечен как экспериментальный. Операция применяется к выходам кондиционирования модели во время процесса семплирования CFG. Когда присутствуют два выхода кондиционирования, операция применяется к разности между первым и вторым выходом, а второй выход добавляется обратно. Когда присутствует только один выход кондиционирования, операция применяется непосредственно к нему.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённой операцией CFG к процессу семплирования | MODEL |
