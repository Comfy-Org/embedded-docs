# Применить операцию к латенту CFG

Узел LatentApplyOperationCFG применяет латентную операцию внутри шага classifier-free guidance (CFG) процесса сэмплирования модели. Он перехватывает выходы conditioning, созданные до CFG, применяет подключённую операцию к латентным значениям и возвращает модель с этим изменённым поведением сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой будет применена операция CFG | MODEL | Да | - |
| `операция` | Латентная операция, применяемая во время процесса сэмплирования CFG | LATENT_OPERATION | Да | - |
| `start_percent` | Доля расписания удаления шума, с которой начинается применение операции; 0 соответствует началу расписания (по умолчанию: 0.0) | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |
| `end_percent` | Доля расписания удаления шума, на которой применение операции прекращается; 1 соответствует концу расписания (по умолчанию: 1.0) | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |

Примечание: Этот узел помечен как экспериментальный. Операция применяется к выходам conditioning модели во время процесса сэмплирования CFG. Когда присутствуют два выхода conditioning, операция применяется к разности между первым и вторым выходом, а второй выход прибавляется обратно к результату. Когда присутствует только один выход conditioning, операция применяется непосредственно к нему. Операция выполняется только между точками `start_percent` и `end_percent` расписания удаления шума, поэтому её можно ограничить частью расписания; вне этого интервала выходы кондиционирования возвращаются без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Изменённая модель с операцией CFG, применённой к её процессу сэмплирования | MODEL |
