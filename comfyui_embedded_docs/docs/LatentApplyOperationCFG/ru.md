# Применить операцию к латенту CFG

Узел LatentApplyOperationCFG применяет латентную операцию для изменения процесса управления кондиционированием в модели. Он работает путём перехвата выходов кондиционирования во время процесса выборки без классификатора (CFG) и применения указанной операции к латентным представлениям до их использования для генерации.

Когда модель создаёт два выхода кондиционирования (например, положительное и отрицательное кондиционирование), операция применяется к разности между ними, после чего второе кондиционирование добавляется обратно. Если имеется только один выход кондиционирования, операция применяется непосредственно к нему. Этот узел помечен как экспериментальный.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой будет применена операция CFG | MODEL | Да | - |
| `operation` | Латентная операция, применяемая в процессе выборки CFG | LATENT_OPERATION | Да | - |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с операцией CFG, применённой к её процессу выборки | MODEL |
