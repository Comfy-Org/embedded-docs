# ComfySoftSwitchNode

گره Soft Switch بر اساس یک شرط بولی، بین دو مقدار ورودی ممکن یکی را انتخاب می‌کند. وقتی `switch` true باشد، مقدار ورودی `on_true` و وقتی `switch` false باشد، مقدار ورودی `on_false` را خروجی می‌دهد. این گره به‌گونه‌ای طراحی شده است که تنبل (lazy) باشد؛ به این معنی که فقط ورودی موردنیاز را بر اساس وضعیت `switch` ارزیابی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `switch` | شرط بولی که تعیین می‌کند کدام ورودی عبور کند. وقتی true باشد، ورودی `on_true` انتخاب می‌شود. وقتی false باشد، ورودی `on_false` انتخاب می‌شود. | BOOLEAN | بله | true<br>false |
| `on_false` | مقداری که وقتی شرط `switch` برابر false باشد خروجی داده می‌شود. این ورودی اختیاری است، اما حداقل یکی از `on_false` یا `on_true` باید متصل باشد. | MATCH_TYPE | خیر |  |
| `on_true` | مقداری که وقتی شرط `switch` برابر true باشد خروجی داده می‌شود. این ورودی اختیاری است، اما حداقل یکی از `on_false` یا `on_true` باید متصل باشد. | MATCH_TYPE | خیر |  |

**توجه:** ورودی‌های `on_false` و `on_true` باید از یک نوع داده باشند، همان‌طور که توسط قالب داخلی گره تعریف شده است. حداقل یکی از این دو ورودی باید برای عملکرد گره متصل باشد. اگر فقط یک ورودی متصل باشد، همان مقدار بدون توجه به وضعیت `switch` به خروجی منتقل می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مقدار انتخاب‌شده. این مقدار با نوع داده ورودی متصل‌شده `on_false` یا `on_true` مطابقت خواهد داشت. | MATCH_TYPE |
