# ComfySoftSwitchNode

گره Soft Switch بین دو مقدار ورودی ممکن بر اساس یک شرط بولی یکی را انتخاب می‌کند. وقتی `switch` true باشد، مقدار ورودی `on_true` را خروجی می‌دهد و وقتی `switch` false باشد، مقدار ورودی `on_false` را خروجی می‌دهد. این گره به‌صورت تنبل (lazy) طراحی شده است، یعنی تنها ورودی‌ای را ارزیابی می‌کند که بر اساس وضعیت `switch` واقعاً مورد نیاز است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `switch` | شرط بولی که تعیین می‌کند کدام ورودی منتقل شود. وقتی true باشد، ورودی `on_true` انتخاب می‌شود. وقتی false باشد، ورودی `on_false` انتخاب می‌شود. | BOOLEAN | بله | True یا False |
| `on_false` | مقداری که وقتی شرط `switch` false است خروجی داده می‌شود. این ورودی اختیاری است، اما حداقل یکی از `on_false` یا `on_true` باید متصل شود. | MATCH_TYPE | خیر | همان نوع دادهٔ `on_true` |
| `on_true` | مقداری که وقتی شرط `switch` true است خروجی داده می‌شود. این ورودی اختیاری است، اما حداقل یکی از `on_false` یا `on_true` باید متصل شود. | MATCH_TYPE | خیر | همان نوع دادهٔ `on_false` |

**نکته:** ورودی‌های `on_false` و `on_true` باید از یک نوع داده باشند، همان‌گونه که توسط قالب داخلی گره تعریف شده است. حداقل یکی از این دو ورودی باید متصل شود، در غیر این صورت گره پیام اعتبارسنجی "At least one of on_false or on_true must be connected to Switch node" را برمی‌گرداند. از آنجا که این گره تنبل (lazy) است، وقتی تنها یک ورودی متصل باشد، گره همواره مقدار همان ورودی را بدون توجه به وضعیت `switch` خروجی می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مقدار انتخاب‌شده. با نوع دادهٔ ورودی متصل `on_false` یا `on_true` مطابقت دارد. وقتی هر دو ورودی متصل باشند، اگر `switch` true باشد `on_true` را خروجی می‌دهد و اگر `switch` false باشد `on_false` را خروجی می‌دهد. | MATCH_TYPE |
