# ComfySoftSwitchNode

Узел Soft Switch выбирает одно из двух возможных входных значений на основе булева условия. Он выводит значение из входа `on_true`, когда `switch` истинно, и значение из входа `on_false`, когда `switch` ложно. Этот узел разработан как ленивый, то есть он вычисляет только то входное значение, которое необходимо в зависимости от состояния переключателя.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `switch` | Булево условие, определяющее, какой вход пропустить. Если значение true, выбирается вход `on_true`. Если false, выбирается вход `on_false`. | BOOLEAN | Да | True or False |
| `on_false` | Значение, которое выводится, когда условие `switch` ложно. Этот вход необязателен, но хотя бы один из входов `on_false` или `on_true` должен быть подключён. | MATCH_TYPE | Нет | Same data type as `on_true` |
| `on_true` | Значение, которое выводится, когда условие `switch` истинно. Этот вход необязателен, но хотя бы один из входов `on_false` или `on_true` должен быть подключён. | MATCH_TYPE | Нет | Same data type as `on_false` |

**Примечание:** Входы `on_false` и `on_true` должны быть одного типа данных, как определено внутренним шаблоном узла. Для работы узла необходимо подключить хотя бы один из этих двух входов. Поскольку узел является ленивым, когда подключён только один вход, узел всегда выводит значение этого входа независимо от состояния `switch`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Выбранное значение. Оно соответствует типу данных подключённого входа `on_false` или `on_true`. Когда оба входа подключены, узел выводит `on_true`, если `switch` истинно, и `on_false`, если `switch` ложно. | MATCH_TYPE |
