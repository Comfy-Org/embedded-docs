# ComfySoftSwitchNode

Узел Soft Switch выбирает между двумя возможными входными значениями на основе логического условия. Он выводит значение из входа `on_true`, когда `switch` имеет значение true, и значение из входа `on_false`, когда `switch` имеет значение false. Этот узел работает по принципу ленивых вычислений, то есть вычисляет только тот вход, который необходим в зависимости от состояния `switch`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `switch` | Логическое условие, определяющее, какой вход передать. Если значение true, выбирается вход `on_true`. Если значение false, выбирается вход `on_false`. | BOOLEAN | Да | true<br>false |
| `on_false` | Значение, которое нужно вывести, когда условие `switch` ложно. Этот вход необязателен, но должен быть подключен хотя бы один из входов `on_false` или `on_true`. | MATCH_TYPE | Нет |  |
| `on_true` | Значение, которое нужно вывести, когда условие `switch` истинно. Этот вход необязателен, но должен быть подключен хотя бы один из входов `on_false` или `on_true`. | MATCH_TYPE | Нет |  |

**Примечание:** Входы `on_false` и `on_true` должны иметь один и тот же тип данных, как определено внутренним шаблоном узла. Для работы узла должен быть подключен хотя бы один из этих двух входов. Если подключен только один вход, его значение передается на выход независимо от состояния `switch`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Выбранное значение. Оно будет соответствовать типу данных подключенного входа `on_false` или `on_true`. | MATCH_TYPE |
