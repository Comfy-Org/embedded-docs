# ClipTextEncodeHunyuanDit

Узел `CLIPTextEncodeHunyuanDiT` преобразует текстовые описания в формат, понятный модели HunyuanDiT. Это расширенный узел кондишининга, предназначенный для двухтекстовой архитектуры энкодеров HunyuanDiT: он обрабатывает два отдельных текстовых входа через разные токенизаторы и объединяет их результаты в единый выходной кондишининг.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Экземпляр модели CLIP, используемый для токенизации и кодирования текста. Является ключевым для генерации кондишининга. | CLIP | Да | - |
| `bert` | Текстовый ввод для кодирования через токенизатор BERT. Предпочтительны фразы и ключевые слова. Поддерживает многострочные и динамические промпты. | STRING | Да | - |
| `mt5xl` | Текстовый ввод для кодирования через токенизатор mT5-XL. Поддерживает многострочные и динамические промпты (многоязычные). Можно использовать полные предложения и сложные описания. | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированный выходной кондишининг, объединяющий текст, токенизированный с помощью BERT и mT5-XL. Используется для дальнейшей обработки в задачах генерации. | CONDITIONING |
