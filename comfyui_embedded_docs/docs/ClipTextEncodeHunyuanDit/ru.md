# Кодирование текста CLIP HunyuanDiT

Узел `CLIPTextEncodeHunyuanDiT` преобразует текстовые описания в формат, понятный модели HunyuanDiT. Это расширенный узел conditioning, предназначенный для архитектуры с двумя текстовыми энкодерами HunyuanDiT: он обрабатывает два отдельных текстовых входа через разные токенизаторы и объединяет их в единый выход conditioning.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Экземпляр модели CLIP, используемый для токенизации и кодирования текста, что является основой для генерации conditioning. | CLIP | Да | - |
| `bert` | Текстовый вход для кодирования через токенизатор BERT. Предпочтительны фразы и ключевые слова. Поддерживает многострочные и динамические промпты. | STRING | Да | - |
| `mt5xl` | Текстовый вход для кодирования через токенизатор mT5-XL. Поддерживает многострочные и динамические промпты (многоязычные). Можно использовать полные предложения и сложные описания. | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированный выход conditioning, объединяющий текст, токенизированный как BERT, так и mT5-XL, используемый для дальнейшей обработки в задачах генерации. | CONDITIONING |
