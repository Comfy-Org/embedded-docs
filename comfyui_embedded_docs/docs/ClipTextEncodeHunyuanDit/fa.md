# ClipTextEncodeHunyuanDit

گره `CLIPTextEncodeHunyuanDiT` توضیحات متنی را به قالبی تبدیل می‌کند که مدل HunyuanDiT قادر به درک آن باشد. این یک گره پیشرفته‌ی conditioning است که برای معماری رمزگذار دوگانه‌ی HunyuanDiT طراحی شده و دو ورودی متنی جداگانه را از طریق توکنایزرهای مختلف پردازش کرده و نتایج آن‌ها را در یک خروجی conditioning واحد ترکیب می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | یک نمونه مدل CLIP که برای توکن‌سازی و رمزگذاری متن استفاده می‌شود و برای تولید شرایط (Conditioning) اساسی است. | CLIP | بله | - |
| `bert` | ورودی متن برای رمزگذاری از طریق توکنایزر BERT. عبارات و کلمات کلیدی را ترجیح می‌دهد. از پرامپت‌های چندخطی و پویا پشتیبانی می‌کند. | STRING | بله | - |
| `mt5xl` | ورودی متن برای رمزگذاری از طریق توکنایزر mT5-XL. از پرامپت‌های چندخطی و پویا (چندزبانه) پشتیبانی می‌کند. می‌تواند از جملات کامل و توصیفات پیچیده استفاده کند. | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | خروجی شرطی (Conditioning) رمزگذاری‌شده که ترکیبی از متن توکن‌شده‌ی BERT و mT5-XL است و برای پردازش‌های بعدی در وظایف تولید استفاده می‌شود. | CONDITIONING |
