# CLIPTextEncodeHunyuanDiT

```markdown
گره `CLIPTextEncodeHunyuanDiT` توصیف‌های متنی را به قالبی تبدیل می‌کند که مدل HunyuanDiT قادر به درک آن است. این یک گره شرط‌سازی پیشرفته است که برای معماری رمزگذار دوگانه متن HunyuanDiT طراحی شده و دو ورودی متنی جداگانه را از طریق توکنایزرهای مختلف پردازش کرده و آن‌ها را در یک خروجی شرط‌سازی واحد ترکیب می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | یک نمونه مدل CLIP که برای توکن‌سازی و رمزگذاری متن استفاده می‌شود و هسته اصلی تولید شرایط است. | CLIP | بله | - |
| `bert` | ورودی متنی برای رمزگذاری از طریق توکنایزر BERT. عبارات و کلیدواژه‌ها را ترجیح می‌دهد. از خطوط چندگانه و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `mt5xl` | ورودی متنی برای رمزگذاری از طریق توکنایزر mT5-XL. از خطوط چندگانه و پرامپت‌های پویا (چندزبانه) پشتیبانی می‌کند. می‌تواند از جملات کامل و توصیفات پیچیده استفاده کند. | STRING | بله | - |
```
