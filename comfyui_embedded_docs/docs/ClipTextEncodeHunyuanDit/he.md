# ClipTextEncodeHunyuanDit

הצומת `CLIPTextEncodeHunyuanDiT` ממיר תיאורי טקסט לפורמט שמודל HunyuanDiT יכול להבין. זהו צומת התניה מתקדם המיועד לארכיטקטורת מקודדי הטקסט הכפולה של HunyuanDiT, המעבד שני קלטי טקסט נפרדים באמצעות טוקנייזרים שונים ומשלב את תוצאותיהם לפלט התניה יחיד.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מופע של מודל CLIP המשמש לטוקניזציה ולקידוד טקסט, שהוא מרכזי ליצירת התניות. | CLIP | כן | - |
| `bert` | קלט טקסט לקידוד באמצעות הטוקנייזר של BERT. מעדיף ביטויים ומילות מפתח. תומך בפרומפטים מרובי שורות ודינמיים. | STRING | כן | - |
| `mt5xl` | קלט טקסט לקידוד באמצעות הטוקנייזר של mT5-XL. תומך בפרומפטים מרובי שורות ודינמיים (רב-לשוניים). יכול להשתמש במשפטים שלמים ובתיאורים מורכבים. | STRING | כן | - |
