# Booléen

Le nœud booléen offre un moyen simple de faire passer des valeurs booléennes (true/false) à travers votre workflow. Il prend une valeur booléenne en entrée et renvoie la même valeur inchangée, ce qui vous permet de contrôler les paramètres booléens d'autres nœuds.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `value` | La valeur booléenne à transmettre à travers le nœud | BOOLEAN | Oui | true<br>false |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La même valeur booléenne que celle fournie en entrée | BOOLEAN |
