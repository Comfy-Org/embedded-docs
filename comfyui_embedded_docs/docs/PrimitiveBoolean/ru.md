# Булево значение

Узел Boolean предоставляет простой способ передавать логические значения (true/false) через ваш рабочий процесс. Он принимает логическое входное значение и выводит то же самое значение без изменений, позволяя управлять логическими параметрами в других узлах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Логическое значение для передачи через узел | BOOLEAN | Да | true<br>false |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | То же логическое значение, которое было подано на вход | BOOLEAN |
