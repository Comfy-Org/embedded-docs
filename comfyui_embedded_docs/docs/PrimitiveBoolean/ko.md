# 논리값

Boolean 노드는 워크플로우에서 boolean(true/false) 값을 전달하는 간단한 방법을 제공합니다. boolean 입력 값을 받아 동일한 값을 변경 없이 출력하므로, 다른 노드의 boolean 매개변수를 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `value` | 노드를 통해 전달할 boolean 값 | BOOLEAN | 예 | true<br>false |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 입력으로 제공된 것과 동일한 boolean 값 | BOOLEAN |
