# رمزگذاری متن CLIP برای Lumina2

گره **CLIP Text Encode برای Lumina2** یک پرامپت سیستمی و یک پرامپت کاربر را با استفاده از مدل CLIP به یک embedding تبدیل می‌کند که می‌تواند مدل انتشار را برای تولید تصاویر خاص هدایت کند. این گره یک پرامپت سیستمی از پیش تعریف‌شده را با پرامپت متنی سفارشی شما ترکیب کرده و آن‌ها را از طریق مدل CLIP پردازش می‌کند تا داده‌های شرطی (conditioning) برای تولید تصویر ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `system_prompt` | Lumina2 دو نوع پرامپت سیستمی ارائه می‌دهد: «superior» تصاویری با هم‌ترازی بهتر تصویر-متن تولید می‌کند؛ «alignment» تصاویری با کیفیت بالا و بالاترین درجه هم‌ترازی تصویر-متن تولید می‌کند. | COMBO | بله | `"superior"`<br>`"alignment"` |
| `user_prompt` | متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | N/A |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن. | CLIP | بله | N/A |

**توجه:** ورودی `clip` الزامی است و نمی‌تواند None باشد. اگر ورودی clip نامعتبر باشد، گره خطایی نشان می‌دهد که مشخص می‌کند چک‌پوینت ممکن است حاوی CLIP یا مدل رمزگذار متن معتبر نباشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | یک شرطی‌سازی شامل متن رمزگذاری‌شده که برای هدایت مدل انتشار استفاده می‌شود. | CONDITIONING |
