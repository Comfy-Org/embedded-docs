# رمزگذاری متن CLIP برای Lumina2

این گره یک پرامپت سیستم و یک پرامپت کاربر را با استفاده از مدل CLIP به یک جاسازی (embedding) کد می‌کند که می‌تواند برای هدایت مدل انتشار به سمت تولید تصاویر خاص استفاده شود. این گره یک پرامپت سیستمی از پیش تعریف‌شده Lumina 2 را با پرامپت متنی سفارشی شما ترکیب کرده و آن‌ها را از طریق مدل CLIP پردازش می‌کند تا داده‌های شرطی برای تولید تصویر ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `پرامپت سیستمی` | Lumina2 دو نوع سیستم پرامپت ارائه می‌دهد: Superior: شما یک دستیار هستید که برای تولید تصاویر برتر با درجه عالی هم‌ترازی تصویر-متن بر اساس پرامپت‌های متنی یا پرامپت‌های کاربر طراحی شده‌اید. Alignment: شما یک دستیار هستید که برای تولید تصاویر باکیفیت با بالاترین درجه هم‌ترازی تصویر-متن بر اساس پرامپت‌های متنی طراحی شده‌اید. | COMBO | بله | `"superior"`<br>`"alignment"` |
| `پرامپت کاربر` | متن مورد نظر برای کدگذاری. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | N/A |
| `clip` | مدل CLIP مورد استفاده برای کدگذاری متن. | CLIP | بله | N/A |

**توجه:** ورودی `clip` الزامی است و نمی‌تواند None باشد. اگر ورودی clip نامعتبر باشد، گره خطایی صادر می‌کند که نشان می‌دهد چک‌پوینت ممکن است شامل مدل CLIP یا رمزگذار متن معتبر نباشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | یک conditioning شامل متن جاسازی‌شده که برای هدایت مدل انتشار استفاده می‌شود. | CONDITIONING |
