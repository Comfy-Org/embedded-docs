# CLIP Text Encode для Lumina2

Этот узел кодирует системный запрос и пользовательский запрос с помощью модели CLIP в эмбеддинг, который можно использовать для направления диффузионной модели на генерацию конкретных изображений. Он объединяет предопределённый системный запрос Lumina 2 с вашим пользовательским текстовым запросом и обрабатывает их через модель CLIP для создания данных кондиционирования для генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `system_prompt` | Lumina2 предоставляет два типа системных запросов: Superior: «Вы — ассистент, предназначенный для генерации превосходных изображений с высокой степенью соответствия изображения и текста на основе текстовых запросов или пользовательских запросов.» Alignment: «Вы — ассистент, предназначенный для генерации высококачественных изображений с наивысшей степенью соответствия изображения и текста на основе текстовых запросов.» | COMBO | Да | `"superior"`<br>`"alignment"` |
| `user_prompt` | Текст для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | N/A |
| `clip` | Модель CLIP, используемая для кодирования текста. | CLIP | Да | N/A |

**Примечание:** Вход `clip` является обязательным и не может быть None. Если вход `clip` недействителен, узел выдаст ошибку, указывающую на то, что контрольная точка может не содержать действительную модель CLIP или модель текстового энкодера.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Кондиционирование, содержащее текстовый эмбеддинг, используемый для управления диффузионной моделью. | CONDITIONING |
