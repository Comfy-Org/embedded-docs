# CLIP Text Encode для Lumina2

Узел CLIP Text Encode для Lumina2 кодирует системный запрос и пользовательский запрос с помощью модели CLIP в эмбеддинг, который может направлять диффузионную модель на генерацию конкретных изображений. Он объединяет предопределенный системный запрос с вашим пользовательским текстовым запросом и обрабатывает их через модель CLIP для создания данных кондиционирования для генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `system_prompt` | Lumina2 предоставляет два типа системных промптов: «superior» генерирует изображения с превосходным согласованием изображения и текста; «alignment» генерирует высококачественные изображения с наивысшей степенью согласования изображения и текста. | COMBO | Да | `"superior"`<br>`"alignment"` |
| `user_prompt` | Текст для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | N/A |
| `clip` | Модель CLIP, используемая для кодирования текста. | CLIP | Да | N/A |

**Примечание:** Вход `clip` обязателен и не может быть None. Если вход `clip` недействителен, узел выдаст ошибку, указывающую, что контрольная точка может не содержать действительную модель CLIP или текстового энкодера.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Кондиционирование, содержащее эмбеддинг текста, используемый для управления диффузионной моделью. | CONDITIONING |
