# MiniMax H3 Sigma Shift

مقادیر شیفت جریان ویدیو و صدا را برای مدل MiniMax H3 تنظیم می‌کند. شیفت ویدیو زمان‌بندی سیگمای نمونه‌بردار را کنترل می‌کند و هر دو مقدار شیفت به ترنسفورمر داخلی مدل منتقل می‌شوند که از آن‌ها برای استخراج زمان‌بندی صدا از شبکه پایه مشترک استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که پچ شیفت سیگما روی آن اعمال می‌شود. گره مدل را کلون می‌کند، بنابراین مدل اصلی بدون تغییر می‌ماند. | MODEL | بله | - |
| `شیفت ویدیو` | مقدار شیفت جریان ویدیو. این مقدار زمان‌بندی سیگمای نمونه‌بردار را هدایت می‌کند. پیش‌فرض: 12.0. | FLOAT | بله | 0.01 تا 100.0 |
| `شیفت صدا` | مقدار شیفت جریان صدا. این مقدار توسط مدل برای استخراج زمان‌بندی صدا استفاده می‌شود. پیش‌فرض: 3.0. | FLOAT | بله | 0.01 تا 100.0 |
