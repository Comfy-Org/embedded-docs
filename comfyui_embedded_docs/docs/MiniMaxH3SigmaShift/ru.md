# MiniMax H3 Sigma Shift

Задает значения сдвига видеопотока и аудиопотока для модели MiniMax H3. Сдвиг видео управляет сигма-расписанием сэмплера, а оба значения сдвига передаются во внутренний трансформатор модели, который использует их для вывода аудиорасписания из общей базовой сетки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, к которой применяется патч сдвига сигмы. Узел клонирует модель, поэтому исходная модель остается без изменений. | MODEL | Да | - |
| `shift_video` | Значение сдвига видеопотока. Управляет сигма-расписанием сэмплера. По умолчанию: 12.0. | FLOAT | Да | 0.01–100.0 |
| `shift_audio` | Значение сдвига аудиопотока. Используется моделью для вывода аудиорасписания. По умолчанию: 3.0. | FLOAT | Да | 0.01–100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Клонированная модель с примененными настройками сдвига сигмы для видео и аудио. | MODEL |
