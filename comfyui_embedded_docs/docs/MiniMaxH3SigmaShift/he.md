# MiniMax H3 Sigma Shift

קובע את ערכי הזזת זרימת הווידאו והאודיו עבור מודל MiniMax H3. הזזת הווידאו שולטת בלוח הזמנים של סיגמה של הדוגם, ושני ערכי ההזזה מועברים לטרנספורמר הפנימי של המודל, שמשתמש בהם כדי לגזור את לוח הזמנים של האודיו מרשת הבסיס המשותפת.
