# HeyGen Voice 1.0 Instant Clone Text to Speech

שכפול קול מהקלטה של דובר אחד והשמעת טקסט בו באמצעות HeyGen Voice 1.0. הצומת מעלה את ההקלטה, מבצע סינתזה של הדיבור ומחזיר אותו כאודיו, כך שצומת יחיד עובר מדגימת קול לדיבור מוכן.

בחירה של `model` חושפת את הפרמטרים הייחודיים לו: `audio`, `text`, `language`, `expressiveness_boost`, `recording_language`, `similarity`, `remove_background_noise` ו-`seed`.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש. `heygen-voice-1-turbo` מהיר יותר ועלותו נמוכה יותר (ברירת מחדל: `"heygen-voice-1"`). | DYNAMIC_COMBO | כן | `"heygen-voice-1"`<br>`"heygen-voice-1-turbo"` |
| `audio` | הקלטה של דובר אחד לשכפול. יש להשתמש בלפחות 10 שניות של דיבור ברור; רק 3 הדקות הראשונות משמשות. | AUDIO | כן | - |
| `text` | הטקסט להקראה, עד 5000 תווים. דיבור הארוך מ-12 דקות לערך נכשל, לכן יש לפצל טקסט סיני או יפני ארוך מאוד (ברירת מחדל: ריק). | STRING | כן | 1 עד 5000 תווים |
| `language` | שפת הטקסט. יש להגדיר אותה עבור שפות קרובות כמו סרבית או מלאית, שזיהוי אוטומטי עלול להתבלבל בהן (ברירת מחדל: `"auto"`). | COMBO | כן | `"auto"`<br>ערכות שפה מוגדרות מראש |
| `expressiveness_boost` | ערכים גבוהים יותר מגבירים את ההבעתיות; ערכים נמוכים יותר נשארים קרובים יותר לקול המקורי (ברירת מחדל: 0.5). | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.05) |
| `recording_language` | השפה המדוברת בהקלטה, אשר מצמצמת את השכפול לאותה שפה (ברירת מחדל: `"auto"`). | COMBO | כן | `"auto"`<br>ערכות שפה מוגדרות מראש |
| `similarity` | מידת הנאמנות של הקול להקלטה (ברירת מחדל: `"max"`). | COMBO | כן | `"medium"`<br>`"high"`<br>`"extra_high"`<br>`"max"` |
| `remove_background_noise` | ניקוי רעשי רקע בהקלטה לפני השכפול (ברירת מחדל: True). | BOOLEAN | כן | `True`<br>`False` |
| `seed` | ערך ה-seed קובע אם הצומת ירוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |

`text` חייב להכיל לפחות תו אחד ו-`audio` הוא חובה: הקלטה של כמה דוברים, או כזו רועשת מדי לשכפול, תניב קול באיכות ירודה. יש להגדיר את `recording_language` כאשר שפת הדגימה אינה ברורה.
