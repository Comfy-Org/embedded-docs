# HeyGen Voice 1.0 Instant Clone Text to Speech

Клонируйте голос по записи одного диктора и озвучивайте текст этим голосом с помощью HeyGen Voice 1.0. Узел загружает запись, синтезирует речь и возвращает её как аудио, поэтому один узел позволяет пройти путь от образца голоса до готовой речи.

При выборе `model` отображаются относящиеся к ней параметры: `audio`, `text`, `language`, `expressiveness_boost`, `recording_language`, `similarity`, `remove_background_noise` и `seed`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Используемая модель. `heygen-voice-1-turbo` работает быстрее и стоит дешевле (по умолчанию: `"heygen-voice-1"`). | DYNAMIC_COMBO | Да | `"heygen-voice-1"`<br>`"heygen-voice-1-turbo"` |
| `audio` | Запись одного диктора для клонирования. Используйте не менее 10 секунд чёткой речи; используются только первые 3 минуты. | AUDIO | Да | - |
| `text` | Текст для озвучивания, до 5000 символов. Речь длительностью более примерно 12 минут завершается ошибкой, поэтому очень длинный китайский или японский текст следует разбивать на части (по умолчанию: пусто). | STRING | Да | от 1 до 5000 символов |
| `language` | Язык текста. Указывайте его для близкородственных языков, таких как сербский или малайский, которые автоопределение может спутать (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>Несколько языковых предустановок |
| `expressiveness_boost` | Более высокие значения делают голос более выразительным; более низкие — ближе к исходному голосу (по умолчанию: 0.5). | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.05) |
| `recording_language` | Язык, на котором говорят в записи; ограничивает клонирование этим языком (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>Несколько языковых предустановок |
| `similarity` | Насколько точно голос соответствует записи (по умолчанию: `"max"`). | COMBO | Да | `"medium"`<br>`"high"`<br>`"extra_high"`<br>`"max"` |
| `remove_background_noise` | Очищать фоновый шум в записи перед клонированием (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `seed` | `seed` управляет тем, будет ли узел выполняться повторно; результаты недетерминированы независимо от `seed` (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

`text` должен содержать хотя бы один символ, а `audio` обязателен: запись нескольких дикторов или слишком шумная для клонирования запись даёт плохой голос. Указывайте `recording_language`, если язык образца неочевиден.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Текст, произнесённый клонированным голосом. | AUDIO |
