# HeyGen Voice 1.0 Instant Clone Text to Speech

یک صدا را از روی ضبط یک گوینده کلون کنید و متن را با آن و با HeyGen Voice 1.0 بگویید. این گره ضبط را بارگذاری می‌کند، گفتار را سنتز می‌کند و آن را به‌صورت صدا برمی‌گرداند؛ بنابراین یک گره تنها از یک نمونه صدا به گفتار نهایی می‌رسد.

با انتخاب `model` پارامترهای مخصوص آن نمایش داده می‌شوند: `audio`، `text`، `language`، `expressiveness_boost`، `recording_language`، `similarity`، `remove_background_noise` و `seed`.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. `heygen-voice-1-turbo` سریع‌تر است و هزینه کمتری دارد (پیش‌فرض: `"heygen-voice-1"`). | DYNAMIC_COMBO | بله | `"heygen-voice-1"`<br>`"heygen-voice-1-turbo"` |
| `audio` | ضبط یک گوینده برای کلون کردن. حداقل 10 ثانیه گفتار واضح استفاده کنید؛ فقط 3 دقیقه اول استفاده می‌شود. | AUDIO | بله | - |
| `text` | متنی که باید گفته شود، حداکثر 5000 کاراکتر. گفتار طولانی‌تر از حدود 12 دقیقه ناموفق می‌شود، بنابراین متن‌های بسیار طولانی چینی یا ژاپنی را تقسیم کنید (پیش‌فرض: خالی). | STRING | بله | 1 تا 5000 کاراکتر |
| `language` | زبان متن. آن را برای زبان‌های نزدیک به هم مانند صربی یا مالایی تنظیم کنید، که تشخیص خودکار ممکن است آن‌ها را اشتباه بگیرد (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>چندین پیش‌تنظیم زبان |
| `expressiveness_boost` | مقادیر بالاتر رساتر هستند؛ مقادیر پایین‌تر به صدای اصلی نزدیک‌تر می‌مانند (پیش‌فرض: 0.5). | FLOAT | بله | 0.0 تا 1.0 (گام: 0.05) |
| `recording_language` | زبانی که در ضبط صحبت می‌شود، که کلون را به آن زبان محدود می‌کند (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>چندین پیش‌تنظیم زبان |
| `similarity` | میزان نزدیکی صدا به ضبط (پیش‌فرض: `"max"`). | COMBO | بله | `"medium"`<br>`"high"`<br>`"extra_high"`<br>`"max"` |
| `remove_background_noise` | نویز پس‌زمینه در ضبط را پیش از کلون کردن پاک‌سازی کنید (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |
| `seed` | Seed کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

`text` باید حداقل یک کاراکتر داشته باشد و `audio` الزامی است: ضبط چند گوینده، یا ضبطی که برای کلون کردن بسیار پرنویز باشد، صدای ضعیفی تولید می‌کند. وقتی زبان نمونه واضح نیست، `recording_language` را تنظیم کنید.
