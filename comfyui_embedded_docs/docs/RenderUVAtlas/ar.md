# تصيير أطلس UV

يُصيّر تخطيط UV للشبكة كصورة. تُملأ كل منطقة UV متصلة (مخطط) بلون مميز، وتُحدَّد الحواف الحدودية للمخطط بخط أسود على خلفية رمادية داكنة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة ثلاثية الأبعاد التي سيُصيَّر تخطيط UV الخاص بها. يجب أن تحتوي الشبكة على إحداثيات UV؛ وإلا فسترفع العقدة الخطأ "mesh has no UVs to render. Run UnwrapMesh first." | MESH | نعم | - |
| `resolution` | العرض والارتفاع، بالبكسل، للصورة المربعة المُصيَّرة (الافتراضي: 1024). | INT | نعم | 64 إلى 4096 (الخطوة 64) |

ملاحظة: إذا كانت الشبكة تحتوي على بُعد دفعة (مصفوفات UV ثلاثية الأبعاد أو مصفوفات الأوجه)، فسيُصيَّر العنصر الأول فقط في الدفعة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | صورة أطلس UV المُصيَّرة، وتُعاد كدفعة من صورة واحدة. تُلوَّن كل منطقة UV، وتُحدَّد الحواف الحدودية للمخطط بخط أسود. | IMAGE |

> تم إنشاء هذه الوثيقة بواسطة الذكاء الاصطناعي. إذا وجدت أي أخطاء أو لديك اقتراحات للتحسين، فلا تتردد في المساهمة! [تحرير على GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/RenderUVAtlas/ar.md)
