# RenderUVAtlas

يعرض تخطيط الأشعة فوق البنفسجية (UV) لشبكة هندسية كصورة. تُملأ كل منطقة UV متصلة (مخطط) بلون مميز، وتُحدد حدود المخططات باللون الأسود على خلفية رمادية داكنة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة ثلاثية الأبعاد التي سيتم عرض تخطيط UV الخاص بها. يجب أن تحتوي الشبكة على إحداثيات UV؛ وإلا فسيتم رفع خطأ. | MESH | نعم | - |
| `resolution` | عرض وارتفاع الصورة المُقدَّمة بالبكسل (الافتراضي: 1024). | INT | نعم | 64 إلى 4096 (الخطوة 64) |

ملاحظة: إذا لم تحتوِ الشبكة على إحداثيات UV، يرفع العقدة الخطأ "mesh has no UVs to render. Run UnwrapMesh first." إذا كانت الشبكة تحتوي على بُعد دفعة (مصفوفات UV أو وجوه ثلاثية الأبعاد)، فسيتم عرض العنصر الأول فقط في الدفعة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `صورة` | صورة أطلس UV المُقدَّمة، مع تلوين كل مخطط وتحديد حواف حدود المخطط باللون الأسود. | IMAGE |
