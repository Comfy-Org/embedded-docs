# RenderUVAtlas

يعرض تخطيط UV للشبكة كصورة. تُملأ كل منطقة UV متصلة (مخطط) بلون مميز، وتُحدد حدود المخططات باللون الأسود على خلفية رمادية داكنة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة ثلاثية الأبعاد التي سيتم عرض تخطيط UV الخاص بها. يجب أن تحتوي الشبكة على إحداثيات UV؛ وإلا سيتم رفع خطأ. | MESH | نعم | - |
| `resolution` | عرض وارتفاع الصورة المعروضة بالبكسل (الافتراضي: 1024). | INT | نعم | 64 to 4096 (step 64) |

ملاحظة: إذا لم تكن للشبكة إحداثيات UV، تقوم العقدة برفع الخطأ "mesh has no UVs to render. Run UnwrapMesh first." إذا كانت الشبكة تحتوي على بُعد دفعة (مصفوفات UV ثلاثية الأبعاد أو مصفوفات الأوجه)، فسيتم عرض العنصر الأول فقط من الدفعة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | صورة أطلس UV المعروضة، مع تلوين كل مخطط وتحديد حواف حدود المخططات باللون الأسود. | IMAGE |
