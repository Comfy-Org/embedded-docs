# RenderUVAtlas

メッシュのUVレイアウトを画像としてレンダリングします。接続された各UV領域（チャート）は異なる色で塗りつぶされ、チャートの境界線は暗灰色の背景に黒で描画されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | UVレイアウトをレンダリングする3Dメッシュ。メッシュにはUV座標が必要です。UV座標がない場合はエラーが発生します。 | MESH | はい | - |
| `resolution` | レンダリング画像の幅と高さ（ピクセル単位）。デフォルトは1024です。 | INT | はい | 64～4096（ステップ64） |

注：メッシュにUV座標がない場合、ノードはエラー「mesh has no UVs to render. Run UnwrapMesh first.」を発生させます。メッシュにバッチ次元（3D UVまたはフェイス配列）が含まれる場合、バッチの最初のアイテムのみがレンダリングされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 各チャートが色分けされ、チャート境界エッジが黒で輪郭描画されたUVアトラス画像。 | IMAGE |
