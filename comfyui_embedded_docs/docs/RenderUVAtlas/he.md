# RenderUVAtlas

מרנדר את פריסת ה-UV של רשת כתמונה. כל אזור UV מחובר (chart) ממולא בצבע ייחודי, וקצוות הגבול של ה-chart מסומנים בקו שחור על רקע אפור כהה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | הרשת התלת-ממדית שפריסת ה-UV שלה תרונדר. לרשת חייבות להיות קואורדינטות UV; אחרת הצומת מעלה את השגיאה "mesh has no UVs to render. Run UnwrapMesh first." | MESH | כן | - |
| `resolution` | הרוחב והגובה, בפיקסלים, של התמונה המרובעת שתרונדר (ברירת מחדל: 1024). | INT | כן | 64 to 4096 (step 64) |

הערה: אם הרשת מכילה ממד אצווה (מערכי UV תלת-ממדיים או מערכי פאות), רק הפריט הראשון באצווה ירונדר.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `image` | תמונת אטלס ה-UV המרונדרת, המוחזרת כאצווה של תמונה בודדת. כל chart UV נצבע, וקצוות הגבול של ה-chart מסומנים בקו שחור. | IMAGE |
