# Рендер UV-атласа

Отрендеривает UV-развёртку меша в виде изображения. Каждый связный UV-регион (остров) заполняется отдельным цветом, а границы островов обводятся чёрным на тёмно-сером фоне.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-меш, для которого будет отрендерена UV-развёртка. Меш должен иметь UV-координаты; иначе узел выдаёт ошибку "mesh has no UVs to render. Run UnwrapMesh first." | MESH | Да | - |
| `resolution` | Ширина и высота в пикселях отрендеренного квадратного изображения (по умолчанию: 1024). | INT | Да | от 64 до 4096 (шаг 64) |

Примечание: Если меш содержит размерность пакета (3D-массивы UV или граней), рендерится только первый элемент пакета.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `image` | Отрендеренное изображение UV-атласа, возвращаемое как пакет из одного изображения. Каждый UV-остров окрашен, а границы островов обведены чёрным. | IMAGE |
