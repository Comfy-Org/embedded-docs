# RenderUVAtlas

Отрисовывает UV-разметку меша в виде изображения. Каждая связная UV-область (chart) заливается отдельным цветом, а границы областей обводятся чёрным на тёмно-сером фоне.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-меш, для которого будет отрисована UV-разметка. Меш должен иметь UV-координаты; в противном случае будет вызвана ошибка. | MESH | Да | - |
| `resolution` | Ширина и высота отображаемого изображения в пикселях (по умолчанию: 1024). | INT | Да | от 64 до 4096 (шаг 64) |

Примечание: Если меш не имеет UV-координат, узел вызывает ошибку «mesh has no UVs to render. Run UnwrapMesh first». Если меш содержит размерность пакета (3D-UV или массивы граней), отображается только первый элемент пакета.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отрисованное изображение UV-атласа, в котором каждая область (chart) закрашена своим цветом, а рёбра границ областей обведены чёрным. | IMAGE |
