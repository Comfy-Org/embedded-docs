# RenderUVAtlas

Отрисовывает UV-развёртку сетки в виде изображения. Каждая связная UV-область (chart) заливается отдельным цветом, а границы областей обведены чёрным на тёмно-сером фоне.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-сетка, UV-развёртка которой будет отрисована. Сетка должна иметь UV-координаты; в противном случае будет вызвана ошибка. | MESH | Да | - |
| `resolution` | Ширина и высота отрисованного изображения в пикселях (по умолчанию: 1024). | INT | Да | 64 до 4096 (step 64) |

Примечание: Если сетка не имеет UV-координат, узел вызывает ошибку «mesh has no UVs to render. Run UnwrapMesh first.» Если сетка содержит размерность пакета (3D-UV или массивы граней), отрисовывается только первый элемент пакета.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отрисованное изображение UV-атласа, в котором каждая область закрашена своим цветом, а границы областей обведены чёрным. | IMAGE |
