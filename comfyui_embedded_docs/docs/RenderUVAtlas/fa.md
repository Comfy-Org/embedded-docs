# RenderUVAtlas

رندر طرح UV شبکه (Mesh) به‌صورت تصویر. هر ناحیهٔ متصل UV (چارَت) با رنگ متمایزی پر می‌شود و مرز چارت‌ها با خط مشکی روی زمینهٔ خاکستری تیره مشخص می‌گردد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | شبکهٔ سه‌بعدی که طرح UV آن رندر خواهد شد. شبکه باید دارای مختصات UV باشد؛ در غیر این صورت خطا صادر می‌شود. | MESH | بله | - |
| `تفکیک‌پذیری` | عرض و ارتفاع تصویر رندر شده بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 64 تا 4096 (گام 64) |

توجه: اگر شبکه مختصات UV نداشته باشد، گره خطای «mesh has no UVs to render. Run UnwrapMesh first.» را صادر می‌کند. اگر شبکه دارای بُعد دسته‌ای (آرایه‌های UV سه‌بعدی یا وجه) باشد، فقط اولین آیتم در دسته رندر می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصویر` | تصویر اطلس UV رندر شده، که هر چارت رنگ‌آمیزی شده و یال‌های مرز چارت با خط مشکی مشخص شده‌اند. | IMAGE |
