# RenderUVAtlas

طرح UV مش را به‌صورت تصویر رندر می‌کند. هر ناحیه‌ی UV متصل (چارت) با یک رنگ متمایز پر می‌شود و مرزهای چارت‌ها روی پس‌زمینه‌ی خاکستری تیره با خط سیاه مشخص می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `mesh` | مش سه‌بعدی که طرح UV آن رندر خواهد شد. مش باید مختصات UV داشته باشد؛ در غیر این صورت خطا ایجاد می‌شود. | MESH | بله | - |
| `resolution` | عرض و ارتفاع تصویر رندر شده بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 64 تا 4096 (گام 64) |

توجه: اگر مش مختصات UV نداشته باشد، گره خطای «mesh has no UVs to render. Run UnwrapMesh first.» را برمی‌انگیزد. اگر مش دارای بُعد دسته (آرایه‌های UV سه‌بعدی یا وجه) باشد، فقط اولین آیتم در دسته رندر می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `image` | تصویر اطلس UV رندر شده، با هر چارت به‌رنگ و لبه‌های مرز چارت‌ها با خط سیاه مشخص شده‌اند. | IMAGE |
