# رندر اطلس UV

چیدمان UV یک مش را به‌صورت تصویر رندر می‌کند. هر ناحیه UV متصل (چارت) با رنگی متمایز پر می‌شود، و لبه‌های مرزی چارت با رنگ مشکی روی پس‌زمینه خاکستری تیره ترسیم می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش سه‌بعدی که چیدمان UV آن رندر می‌شود. مش باید مختصات UV داشته باشد؛ در غیر این صورت گره خطای "mesh has no UVs to render. Run UnwrapMesh first." را ایجاد می‌کند. | MESH | بله | - |
| `تفکیک‌پذیری` | عرض و ارتفاع، بر حسب پیکسل، تصویر مربعی رندرشده (پیش‌فرض: 1024). | INT | بله | 64 تا 4096 (گام 64) |

نکته: اگر مش شامل بُعد batch باشد (آرایه‌های UV سه‌بعدی یا آرایه‌های وجه)، فقط اولین مورد در batch رندر می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر اطلس UV رندرشده که به‌صورت یک batch تک‌تصویری برگردانده می‌شود. هر چارت UV رنگ‌آمیزی شده است، و لبه‌های مرزی چارت با رنگ مشکی ترسیم می‌شوند. | IMAGE |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/RenderUVAtlas/fa.md)
