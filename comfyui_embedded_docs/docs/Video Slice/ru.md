# Видеофрагмент

Узел Video Slice позволяет извлечь определённый сегмент из видео. Вы можете задать время начала и длительность, чтобы обрезать видео, или просто пропустить начальные кадры. Если запрошенная длительность превышает оставшуюся часть видео, узел может либо вернуть доступный фрагмент, либо вызвать ошибку.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `видео` | Входное видео для нарезки. | VIDEO | Да | - |
| `время начала` | Время начала в секундах (по умолчанию: 0.0). | FLOAT | Да | -1e5 до 1e5 |
| `длительность` | Длительность в секундах, или 0 для неограниченной длительности (по умолчанию: 0.0). | FLOAT | Да | 0.0 и выше |
| `строгая длительность` | Если True, то при невозможности указанной длительности будет вызвана ошибка (по умолчанию: False). | BOOLEAN | Да | - |

**Примечание:** Если видео не может быть нарезано для заданных `start_time` и `duration`, узел вызывает ошибку. Когда `strict_duration` равно False, узел возвращает доступную часть видео, если запрошенная длительность превышает оставшуюся длину; когда True — вместо этого вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Обрезанный сегмент видео. | VIDEO |
