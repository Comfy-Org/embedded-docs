# Видеофрагмент

Узел Video Slice позволяет извлечь определённый сегмент из видео. Вы можете задать время начала и продолжительность для обрезки видео или просто пропустить начальные кадры. Если запрошенная продолжительность превышает оставшуюся часть видео, узел может либо вернуть доступный фрагмент, либо вызвать ошибку.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Входное видео для нарезки. | VIDEO | Да | - |
| `start_time` | Время начала в секундах (по умолчанию: 0.0). | FLOAT | Нет | -1e5 to 1e5 |
| `duration` | Продолжительность в секундах; 0 означает неограниченную длительность (по умолчанию: 0.0). | FLOAT | Нет | 0.0 and above |
| `strict_duration` | Если True, то в случае, когда указанная длительность не может быть соблюдена, будет вызвана ошибка (по умолчанию: False). | BOOLEAN | Нет | - |

Примечание. Если `duration` равен 0, узел нарезает видео от `start_time` до конца видео. Если запрошенный сегмент не может быть создан — например, если `start_time` выходит за пределы конца видео — узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Обрезанный фрагмент видео. | VIDEO |
