# 비디오 슬라이스

Video Slice 노드를 사용하면 비디오에서 특정 구간을 추출할 수 있습니다. 시작 시간과 지속 시간을 정의하여 비디오를 자르거나, 시작 프레임을 건너뛸 수도 있습니다. 요청한 지속 시간이 남은 비디오보다 길면, 노드는 사용 가능한 부분을 반환하거나 오류를 발생시킬 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `video` | 슬라이스할 입력 비디오입니다. | VIDEO | 예 | - |
| `start_time` | 시작 시간(초)입니다 (기본값: 0.0). | FLOAT | 아니요 | -1e5 ~ 1e5 |
| `duration` | 지속 시간(초)입니다. 0이면 무제한 지속 시간을 의미합니다 (기본값: 0.0). | FLOAT | 아니요 | 0.0 이상 |
| `strict_duration` | True이면 지정된 지속 시간을 만들 수 없을 때 오류가 발생합니다 (기본값: False). | BOOLEAN | 아니요 | - |

참고: `duration`이 0이면 노드는 `start_time`부터 비디오 끝까지 슬라이스합니다. 요청한 구간을 만들 수 없는 경우(예: `start_time`이 비디오 끝을 초과하는 경우) 노드는 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `video` | 잘려진 비디오 구간입니다. | VIDEO |
