# برش ویدیو

گره Video Slice به شما امکان می‌دهد بخش خاصی از یک ویدیو را استخراج کنید. می‌توانید زمان شروع و مدت‌زمانی را برای برش ویدیو تعریف کنید، یا به سادگی فریم‌های ابتدایی را رد کنید. اگر مدت‌زمان درخواستی از ویدیوی باقی‌مانده بیشتر باشد، گره می‌تواند یا آنچه در دسترس است را برگرداند یا خطا ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `video` | ویدیوی ورودی که قرار است برش داده شود. | VIDEO | بله | - |
| `start_time` | زمان شروع بر حسب ثانیه (پیش‌فرض: 0.0). | FLOAT | خیر | -1e5 to 1e5 |
| `duration` | مدت‌زمان بر حسب ثانیه، یا 0 برای مدت‌زمان نامحدود (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 و بالاتر |
| `strict_duration` | اگر True باشد، وقتی مدت‌زمان مشخص‌شده ممکن نباشد، خطا ایجاد می‌شود (پیش‌فرض: False). | BOOLEAN | خیر | - |

توجه: وقتی `duration` برابر 0 باشد، گره از `start_time` تا انتهای ویدیو را برش می‌دهد. اگر بخش درخواستی قابل ساخته‌شدن نباشد — مثلاً به این دلیل که `start_time` بعد از پایان ویدیو است — گره خطا ایجاد می‌کند.
