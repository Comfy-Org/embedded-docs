# برش ویدیو

```markdown
گره Video Slice به شما امکان می‌دهد بخش مشخصی از یک ویدیو را استخراج کنید. می‌توانید زمان شروع و مدت‌زمان را برای برش ویدیو تعریف کنید، یا به سادگی فریم‌های ابتدایی را رد کنید. اگر مدت‌زمان درخواستی بیشتر از ویدیوی باقی‌مانده باشد، گره می‌تواند یا بخش موجود را برگرداند یا خطا صادر کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `ویدیو` | ویدیوی ورودی که قرار است برش داده شود. | VIDEO | بله | - |
| `زمان شروع` | زمان شروع بر حسب ثانیه (پیش‌فرض: 0.0). | FLOAT | بله | -1e5 تا 1e5 |
| `مدت زمان` | مدت‌زمان بر حسب ثانیه، یا 0 برای مدت‌زمان نامحدود (پیش‌فرض: 0.0). | FLOAT | بله | 0.0 و بالاتر |
| `مدت زمان دقیق` | اگر True باشد، وقتی مدت‌زمان مشخص‌شده ممکن نباشد، خطا صادر خواهد شد (پیش‌فرض: False). | BOOLEAN | بله | - |

**نکته:** اگر ویدیو برای `start_time` و `duration` داده‌شده قابل برش نباشد، گره خطا صادر می‌کند. وقتی `strict_duration` برابر False باشد، اگر مدت‌زمان درخواستی از طول باقی‌مانده بیشتر شود، گره بخش موجود ویدیو را برمی‌گرداند؛ وقتی True باشد، به جای آن خطا صادر می‌کند.
```
