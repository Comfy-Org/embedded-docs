# PixVerse V6: из текста в видео

PixVerse V6 Text to Video генерирует видео из текстовой подсказки с использованием модели PixVerse V6. Узел отправляет подсказку вместе с выбранными соотношением сторон, разрешением, длительностью и другими настройками в PixVerse, ждёт завершения генерации и затем возвращает полученное видео — включая встроенную аудиодорожку, когда генерация аудио включена.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель и настройки генерации. Выберите модель и настройте её параметры генерации. | DYNAMIC_COMBO | Да | "PixVerse V6" |

### Входы PixVerse V6

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Подсказка для генерации видео. (по умолчанию: "") | STRING | Да | 1–5000 символов |
| `aspect_ratio` | Соотношение сторон выходного видео. Выберите одно из соотношений сторон, поддерживаемых PixVerse V6. | COMBO | Да | Доступно несколько вариантов |
| `quality` | Разрешение выходного видео. Задаёт длинную сторону: 360p — 640px, 540p — 1024px, 720p — 1280px, 1080p — 1920px. (по умолчанию: "720p") | COMBO | Да | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | Длительность сгенерированного видео в секундах. (по умолчанию: 5) | INT | Да | 1–15 |
| `generate_audio` | Генерировать встроенную аудиодорожку вместе с видео. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `multi_clip` | Позволить модели разрезать видео на несколько планов вместо одного непрерывного дубля. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `seed` | Сид для генерации видео. PixVerse записывает его, но не воспроизводит запуск по нему. Поддерживает рандомизацию после генерации. (по умолчанию: 42) | INT | Да | 0–2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов в видео. (по умолчанию: "") | STRING | Нет | 0–2048 символов |
| `style` | Необязательный визуальный стиль, применяемый ко всему видео. (по умолчанию: "none") | COMBO | Нет | Доступно несколько вариантов |

**Примечание:** Параметр `prompt` обязателен и после удаления пробелов не должен быть пустым; его максимальная длина — 5000 символов. Параметр `negative_prompt` ограничен 2048 символами. Установка `style` в "none" (по умолчанию) означает, что визуальный стиль не применяется. `seed` записывается PixVerse, но не может быть использован для воспроизведения того же запуска. Узел ждёт, пока PixVerse завершит генерацию видео, а затем скачивает его; если запрос завершается ошибкой — например, потому что PixVerse уже достиг максимального количества одновременных генераций, на счёте провайдера закончились кредиты или модерация контента отклонила подсказку — узел возвращает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео. Если `generate_audio` включён, видео содержит встроенную аудиодорожку. | VIDEO |
