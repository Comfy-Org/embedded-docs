# PixVerse V6: из текста в видео

PixVerse V6 Text to Video создает видео по текстовому запросу с помощью модели V6 от PixVerse. Узел отправляет запрос вместе с выбранными вами разрешением, длительностью, соотношением сторон и другими настройками в PixVerse, ожидает завершения генерации, а затем возвращает полученное видео — включая встроенную аудиодорожку, если генерация звука включена.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|--------------|---------|
| `модель` | Модель и настройки генерации. Выберите модель и настройте параметры генерации. | DYNAMIC_COMBO | Да | "PixVerse V6" |

### Входы PixVerse V6

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|--------------|---------|
| `prompt` | Текстовый запрос для генерации видео. (по умолчанию: "") | STRING | Да | 1–5000 символов |
| `aspect_ratio` | Соотношение сторон выходного видео. Выберите одно из соотношений сторон, поддерживаемых PixVerse V6. | COMBO | Да | Доступно несколько вариантов |
| `quality` | Разрешение выходного видео. Задает длинную сторону: 360p — 640px, 540p — 1024px, 720p — 1280px, 1080p — 1920px. (по умолчанию: "720p") | COMBO | Да | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | Длительность создаваемого видео в секундах. (по умолчанию: 5) | INT | Да | 1–15 |
| `generate_audio` | Создать встроенную аудиодорожку вместе с видео. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `multi_clip` | Позволяет модели разрезать видео на несколько сцен вместо одного непрерывного плана. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `seed` | Сид для генерации видео. PixVerse сохраняет его, но не воспроизводит запуск на его основе. Поддерживает рандомизацию после генерации. (по умолчанию: 42) | INT | Да | 0–2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов в видео. (по умолчанию: "") | STRING | Нет | 0–2048 символов |
| `style` | Необязательный визуальный стиль, применяемый ко всему видео. (по умолчанию: "none") | COMBO | Нет | Доступно несколько вариантов |

**Примечание:** Параметр `prompt` обязателен и после удаления пробелов не должен быть пустым; его максимальная длина — 5000 символов. Параметр `negative_prompt` ограничен 2048 символами. Если для `style` задано значение "none" (по умолчанию), визуальный стиль не применяется. `seed` записывается PixVerse, но не может быть использован для воспроизведения того же запуска. Узел ожидает завершения генерации видео в PixVerse, а затем загружает его; если запрос не удается — например, потому что PixVerse уже достиг максимального количества одновременных генераций, на аккаунте провайдера закончились кредиты или модерация контента отклоняет запрос, — узел возвращает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Созданное видео. Если `generate_audio` включен, видео включает встроенную аудиодорожку. | VIDEO |
