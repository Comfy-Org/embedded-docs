# Сгладить нормали сетки

Вычисляет сглаженные нормали для каждой вершины меша и прикрепляет их. Меши без нормалей затеняются плоско (по граням) в программах просмотра glTF; этот узел делает их затенение сглаженным. При угле сгиба ниже 180 рёбра, более резкие, чем порог, сохраняются жёсткими за счёт разделения вершин вдоль них.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Входной меш для обработки. | MESH | Да | - |
| `crease_angle` | Рёбра, двугранный угол которых превышает это значение (в градусах), остаются жёсткими (вершины разделяются). 180 = полностью сглаженно; меньшее значение сохраняет резкие рёбра (например, ~30–60 для hard-surface). По умолчанию: 180.0. | FLOAT | Да | 0.0 до 180.0 (шаг: 1.0) |

Когда `crease_angle` равен 180 или больше, топология меша не изменяется. Когда задано значение ниже 180, вершины разделяются вдоль жёстких рёбер, что может увеличить количество вершин. При разделении вершин данные по вершинам (цвета, UV-координаты и касательные) дублируются в соответствии с новой раскладкой вершин, а результирующий меш перестраивается как пакет переменного размера.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входной меш с прикреплёнными сглаженными данными нормалей или с разделёнными вершинами и нормалями, когда задан угол сгиба. | MESH |
