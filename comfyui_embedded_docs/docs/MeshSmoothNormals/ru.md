# MeshSmoothNormals

Вычисляет сглаженные нормали по вершинам сетки и присоединяет их. Сетки без нормалей затеняются плоскими (по граням) в программах просмотра glTF; этот узел обеспечивает гладкое затенение. Если угол между гранями меньше 180, рёбра, превышающие порог, остаются острыми за счёт расщепления вершин вдоль них.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Входная сетка для обработки. | MESH | Да | - |
| `crease_angle` | Рёбра, двугранный угол которых превышает это значение (в градусах), остаются острыми (вершины разделяются). 180 = полное сглаживание; меньшие значения сохраняют острые рёбра (например, ~30–60 для жестких поверхностей). По умолчанию: 180.0. | FLOAT | Да | 0.0 до 180.0 (step 1.0) |

Когда `crease_angle` равен 180 или больше, топология сетки не изменяется. Если задано значение меньше 180, вершины разделяются вдоль острых рёбер, что может увеличить количество вершин.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `сетка` | Входная сетка с присоединёнными данными сглаженных нормалей или с разделёнными вершинами и нормалями при заданном угле между гранями. | MESH |
