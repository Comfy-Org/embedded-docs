# 平滑網格法線

為網格計算平滑的逐頂點法線並附加它們。沒有法線的網格在 glTF 檢視器中會以平面（逐面）著色；此節點可讓它們平滑著色。當折痕角度低於 180 時，比閾值更銳利的邊緣會透過沿著這些邊緣拆分頂點來保持硬邊。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要處理的輸入網格。 | MESH | 是 | - |
| `crease_angle` | 二面角超過此值（度）的邊緣會保持硬邊（頂點會被拆分）。180 = 完全平滑；較低值會保留銳利邊緣（例如硬表面約 30-60）。預設值：180.0。 | FLOAT | 是 | 0.0 至 180.0 （步進值：1.0） |

當 `crease_angle` 為 180 或更高時，網格拓撲保持不變。當設定低於 180 時，頂點會沿著硬邊拆分，這可能會增加頂點數量。當頂點被拆分時，逐頂點資料（顏色、UV 和切線）會被複製以符合新的頂點配置，且產生的網格會重建為可變大小的批次。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 已附加平滑法線資料的輸入網格；若設定了折痕角度，則為已拆分頂點與法線的網格。 | MESH |
