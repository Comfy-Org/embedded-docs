# MeshSmoothNormals

計算網格的平滑逐頂點法線並將其附加至網格。沒有法線的網格在 glTF 檢視器中會以平面（逐面）方式著色；此節點可讓它們平滑著色。當摺痕角度低於 180 度時，比閾值更銳利的邊緣會透過沿邊緣分割頂點來保持硬邊。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要處理的輸入網格。 | MESH | 是 | - |
| `crease_angle` | 二面角超過此值（度）的邊緣保持硬邊（頂點會被分割）。180 = 完全平滑；較低的值會保留銳利邊緣（例如硬表面約 30-60）。預設值：180.0。 | FLOAT | 是 | 0.0 to 180.0 (step 1.0) |

當 `crease_angle` 為 180 或更高時，網格拓撲保持不變。當設定低於 180 時，頂點會沿硬邊分割，這可能會增加頂點數量。
