# VaeSave

צומת VAESave מיועד לשמירת מודלי VAE יחד עם המטא-נתונים שלהם, כולל פרומפטים ומידע PNG נוסף, בתיקיית פלט מוגדרת. הוא מכיל את היכולת לבצע סריאליזציה של מצב המודל והמידע הנלווה לקובץ, ובכך מאפשר שימור ושיתוף של מודלים מאומנים.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `vae` | מודל ה-VAE שיש לשמור. פרמטר זה חיוני מכיוון שהוא מייצג את המודל שיש לבצע סריאליזציה של מצבו ולאחסנו. | VAE |
| `filename_prefix` | קידומת לשם הקובץ שבו יישמרו המודל והמטא-נתונים שלו. זה מאפשר אחסון מאורגן ושליפה קלה של מודלים. | STRING |
