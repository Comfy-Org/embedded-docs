# SplitImageToTileList

הצומת Split Image into List of Tiles מחלק תמונת קלט אחת לסדרה של מקטעים מלבניים קטנים יותר וחופפים המכונים אריחים. הוא יוצר רשימת אצווה של אריחים אלה, שניתן לעבד כל אחד מהם בנפרד באמצעות צמתים אחרים. ניתן לציין את הגודל של כל אריח ואת כמות החפיפה ביניהם.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט שיש לחלק לאריחים. | IMAGE | כן | - |
| `tile_width` | הרוחב של כל אריח פלט בפיקסלים (ברירת מחדל: 1024). | INT | כן | 64 עד 1048576 |
| `tile_height` | הגובה של כל אריח פלט בפיקסלים (ברירת מחדל: 1024). | INT | כן | 64 עד 1048576 |
| `overlap` | מספר הפיקסלים שבהם אריחים סמוכים חופפים זה לזה (ברירת מחדל: 128). | INT | כן | 0 עד 4096 |
