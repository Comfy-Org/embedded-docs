# 套用 Anima LLLite

AnimaLLLiteApply 會將輕量動畫補丁套用至擴散模型，實現可調整強度與時機的可控制圖像到圖像生成。它會整合預先配置的模型補丁、輸入圖像及可選遮罩，修改模型的注意力與 MLP 層，以影響生成過程。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要套用補丁的基礎擴散模型 | MODEL | 是 | |
| `模型補丁` | 要套用的預先配置動畫補丁 | MODEL_PATCH | 是 | |
| `影像` | 用於引導生成的參考圖像。僅使用前 3 個顏色通道（RGB） | IMAGE | 是 | |
| `強度` | 補丁效果的強度（預設：1.0，步長：0.01） | FLOAT | 是 | -10.0 至 10.0 |
| `起始百分比` | 補丁開始生效的去噪過程百分比（預設：0.0，步長：0.001） | FLOAT | 是 | 0.0 至 1.0 |
| `結束百分比` | 補丁停止生效的去噪過程百分比（預設：1.0，步長：0.001） | FLOAT | 是 | 0.0 至 1.0 |
| `遮罩` | 可選遮罩，用於將補丁效果限制在圖像的特定區域 | MASK | 否 | |

**參數限制注意事項：** 如果 `model_patch` 有 4 個輸入通道且未提供 `mask`，會自動建立零遮罩以符合圖像尺寸。如果 `model_patch` 沒有 4 個輸入通道，則會忽略 `mask` 參數並將其設為 `None`。僅使用輸入圖像的前 3 個顏色通道。此節點在 ComfyUI 中標記為實驗性。
