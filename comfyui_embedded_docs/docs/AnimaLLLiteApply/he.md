# AnimaLLLiteApply

AnimaLLLiteApply מחיל פאצ' אנימציה קל-משקל על מודל דיפוזיה, ומאפשר יצירת תמונה לתמונה מבוקרת עם עוצמה ותזמון ניתנים להתאמה. הוא משלב פאצ' מודל מוגדר מראש עם תמונת קלט ומסכה אופציונלית, ומשנה את שכבות הקשב וה-MLP של המודל כדי להשפיע על תהליך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל הדיפוזיה הבסיסי שעליו יש להחיל את הפאצ' | MODEL | כן | |
| `model_patch` | פאצ' האנימציה המוגדר מראש שיש להחיל | MODEL_PATCH | כן | |
| `image` | תמונת העזר להנחיית היצירה. נעשה שימוש רק ב-3 ערוצי הצבע הראשונים (RGB) | IMAGE | כן | |
| `strength` | עוצמת השפעת הפאצ' (ברירת מחדל: 1.0, צעד: 0.01) | FLOAT | כן | -10.0 עד 10.0 |
| `start_percent` | אחוז מתהליך הסרת הרעש שבו הפאצ' מתחיל להשפיע (ברירת מחדל: 0.0, צעד: 0.001) | FLOAT | כן | 0.0 עד 1.0 |
| `end_percent` | אחוז מתהליך הסרת הרעש שבו הפאצ' מפסיק להשפיע (ברירת מחדל: 1.0, צעד: 0.001) | FLOAT | כן | 0.0 עד 1.0 |
| `mask` | מסכה אופציונלית להגבלת השפעת הפאצ' לאזורים ספציפיים בתמונה | MASK | לא | |

**הערה בנוגע לאילוצי פרמטרים:** אם ל-`model_patch` יש 4 ערוצי קלט ולא סופקה `mask`, נוצרת אוטומטית מסכה של אפסים כדי להתאים לממדי התמונה. אם ל-`model_patch` אין 4 ערוצי קלט, הפרמטר `mask` לא נלקח בחשבון ומוגדר ל-`None`. נעשה שימוש רק ב-3 ערוצי הצבע הראשונים של תמונת הקלט. צומת זה מסומן כניסיוני ב-ComfyUI.
