# Применить Anima LLLite

AnimaLLLiteApply применяет облегчённый анимационный патч к диффузионной модели, обеспечивая управляемую генерацию «изображение-в-изображение» с регулируемой силой и временем воздействия. Он объединяет предварительно настроенный патч модели с входным изображением и необязательной маской, изменяя слои внимания и MLP модели, чтобы влиять на процесс генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Базовая диффузионная модель, к которой применяется патч | MODEL | Да | |
| `model_patch` | Предварительно настроенный анимационный патч для применения | MODEL_PATCH | Да | |
| `изображение` | Эталонное изображение для управления генерацией. Используются только первые 3 цветовых канала (RGB) | IMAGE | Да | |
| `интенсивность` | Сила эффекта патча (по умолчанию: 1.0, шаг: 0.01) | FLOAT | Да | от -10.0 до 10.0 |
| `начальный процент` | Процент процесса шумоподавления, на котором патч начинает действовать (по умолчанию: 0.0, шаг: 0.001) | FLOAT | Да | от 0.0 до 1.0 |
| `конечный процент` | Процент процесса шумоподавления, на котором патч перестаёт действовать (по умолчанию: 1.0, шаг: 0.001) | FLOAT | Да | от 0.0 до 1.0 |
| `маска` | Необязательная маска для ограничения эффекта патча определёнными областями изображения | MASK | Нет | |

**Примечание по ограничениям параметров:** Если у `model_patch` 4 входных канала и `mask` не задана, автоматически создаётся нулевая маска, соответствующая размерам изображения. Если у `model_patch` нет 4 входных каналов, параметр `mask` игнорируется и устанавливается в `None`. Используются только первые 3 цветовых канала входного изображения. Этот узел помечен как экспериментальный в ComfyUI.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Диффузионная модель с применённым анимационным патчем | MODEL |
