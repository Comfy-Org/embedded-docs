# تطبيق Anima LLLite

يقوم AnimaLLLiteApply بتطبيق تصحيح رسوم متحركة خفيف الوزن على نموذج الانتشار، مما يتيح توليدًا محكومًا من صورة إلى صورة بقوة وتوقيت قابلين للتعديل. وهو يدمج تصحيح نموذج مُهيأ مسبقًا مع صورة إدخال وقناع اختياري، مما يعدل طبقات الانتباه و MLP في النموذج للتأثير على عملية التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الانتشار الأساسي لتطبيق التصحيح عليه | MODEL | نعم | |
| `model_patch` | تصحيح الرسوم المتحركة المُهيأ مسبقًا لتطبيقه | MODEL_PATCH | نعم | |
| `image` | الصورة المرجعية لتوجيه التوليد. يتم استخدام أول 3 قنوات لونية فقط (RGB) | IMAGE | نعم | |
| `strength` | قوة تأثير التصحيح (الافتراضي: 1.0، الخطوة: 0.01) | FLOAT | نعم | -10.0 إلى 10.0 |
| `start_percent` | النسبة المئوية لعملية إزالة الضوضاء التي يبدأ عندها التصحيح في التأثير (الافتراضي: 0.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |
| `end_percent` | النسبة المئوية لعملية إزالة الضوضاء التي يتوقف عندها التصحيح عن التأثير (الافتراضي: 1.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |
| `mask` | قناع اختياري لتحديد تأثير التصحيح لمناطق معينة من الصورة | MASK | لا | |

**ملاحظة حول قيود المعاملات:** إذا كان `model_patch` يحتوي على 4 قنوات إدخال ولم يتم توفير `mask`، فسيتم إنشاء قناع صفري تلقائيًا ليتوافق مع أبعاد الصورة. إذا لم يكن `model_patch` يحتوي على 4 قنوات إدخال، فسيتم تجاهل المعامل `mask` وتعيينه إلى `None`. يتم استخدام أول 3 قنوات لونية فقط من صورة الإدخال. تم تمييز هذه العقدة كتجريبية في ComfyUI.
