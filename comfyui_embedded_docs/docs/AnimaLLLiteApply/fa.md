# اعمال Anima LLLite

AnimaLLLiteApply یک پچ انیمیشن سبک را روی یک مدل انتشار اعمال می‌کند و تولید تصویر به تصویر کنترل‌شده با قدرت و زمان‌بندی قابل تنظیم را ممکن می‌سازد. این گره یک پچ مدل از پیش پیکربندی‌شده را با یک تصویر ورودی و ماسک اختیاری ادغام می‌کند و لایه‌های توجه و MLP مدل را برای تأثیرگذاری بر فرآیند تولید تغییر می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل انتشار پایه‌ای که پچ باید روی آن اعمال شود | MODEL | بله | |
| `patch مدل` | پچ انیمیشن از پیش پیکربندی‌شده برای اعمال | MODEL_PATCH | بله | |
| `تصویر` | تصویر مرجع برای هدایت تولید. تنها ۳ کانال رنگی اول (RGB) استفاده می‌شوند | IMAGE | بله | |
| `شدت` | قدرت اثر پچ (پیش‌فرض: 1.0، گام: 0.01) | FLOAT | بله | -10.0 تا 10.0 |
| `درصد شروع` | درصد فرآیند نویززدایی که پچ در آن شروع به اثرگذاری می‌کند (پیش‌فرض: 0.0، گام: 0.001) | FLOAT | بله | 0.0 تا 1.0 |
| `درصد پایان` | درصد فرآیند نویززدایی که پچ در آن اثرگذاری را متوقف می‌کند (پیش‌فرض: 1.0، گام: 0.001) | FLOAT | بله | 0.0 تا 1.0 |
| `ماسک` | ماسک اختیاری برای محدود کردن اثر پچ به نواحی مشخصی از تصویر | MASK | خیر | |

**نکته درباره محدودیت‌های پارامترها:** اگر `model_patch` دارای ۴ کانال ورودی باشد و `mask` ارائه نشود، یک ماسک صفر به‌طور خودکار برای تطبیق با ابعاد تصویر ایجاد می‌شود. اگر `model_patch` دارای ۴ کانال ورودی نباشد، پارامتر `mask` نادیده گرفته می‌شود و روی `None` تنظیم می‌شود. تنها ۳ کانال رنگی اول تصویر ورودی استفاده می‌شوند. این گره در ComfyUI به‌عنوان آزمایشی علامت‌گذاری شده است.
