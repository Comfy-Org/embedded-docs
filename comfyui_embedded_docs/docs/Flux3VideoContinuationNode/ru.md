# Flux 3 Продолжение Видео

Этот узел продолжает существующий видеоклип с помощью FLUX 3: новый клип продолжается с финальных кадров предоставленного вами видео. Он загружает исходный клип, отправляет запрос и настройки в сервис генерации и возвращает полученное продолжение видео, когда оно будет готово.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Клип, который нужно продолжить. | VIDEO | Да | Один видеоклип |
| `prompt` | Что должно показывать продолжение; перед генерацией запрос интерпретируется и расширяется. (по умолчанию: "") | STRING | Да | Непустой текст (минимум 1 символ) |
| `aspect_ratio` | Соотношение сторон вывода. 'auto' выбирает его из запроса и входных данных. (по умолчанию: "auto") | COMBO | Да | "auto" (по умолчанию)<br>Несколько предопределенных вариантов |
| `duration` | Длительность клипа в секундах. 'auto' подбирает длину под содержимое. (по умолчанию: "auto") | COMBO | Да | "auto" (по умолчанию)<br>Числовые значения в секундах |
| `resolution` | Разрешение вывода. (по умолчанию: "720p") | COMBO | Да | "720p" (по умолчанию)<br>"1080p"<br>Другие предопределенные варианты |
| `generate_audio` | Создавать синхронизированное аудио (окружающие звуки, речь, эффекты). При выключении создаётся видео без аудиодорожки. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `safety_tolerance` | Допуск модерации, 0 — самый строгий. Для запросов, отправляющих изображения или видео, максимальное значение ограничено 2 независимо от того, что вы здесь укажете. (дополнительный параметр, по умолчанию: 2) | INT | Да | 0 - 4 (эффективный максимум: 2 для видеозапросов) |
| `seed` | Сид для определения необходимости повторного запуска узла; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. (дополнительный параметр, по умолчанию: 42) | INT | Да | 0 - 4294967295 (0xFFFFFFFF) |

### Примечания

- `prompt` должен содержать хотя бы один символ, иначе генерация завершится ошибкой. Хотя поле по умолчанию пустое, для запуска узла требуется непустой запрос.
- `safety_tolerance` принимает любое значение от 0 до 4, но поскольку этот узел отправляет видео в API, эффективный допуск ограничен 2 независимо от выбранного значения.
- Когда `duration` задано числом, оно преобразуется в целое количество секунд. Специальное значение «auto» позволяет сервису подобрать длину под содержимое.
- Точные списки опций для `aspect_ratio`, `duration` и `resolution` определяются внутренне узлом. Варианты разрешения включают как минимум «720p» (по умолчанию) и «1080p». Стоимость рассчитывается на основе выбранных `resolution` и `duration`; «1080p» тарифицируется по $0.7579 за секунду, а другие разрешения — по $0.5863 за секунду.
- Поля аутентификации и идентификации узла (`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`) скрыты и обрабатываются платформой автоматически.
