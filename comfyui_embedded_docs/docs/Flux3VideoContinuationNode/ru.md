# Flux3VideoContinuationNode

Этот узел продолжает существующий видеоклип с помощью FLUX 3, поэтому новый клип продолжается с финальных кадров предоставленного вами видео. Он загружает исходный клип, отправляет промпт и настройки в сервис генерации и возвращает готовое видео с продолжением, когда оно будет готово.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `video` | Клип для продолжения. | VIDEO | Да | Один видеоклип |
| `prompt` | Что должно показывать продолжение; промпт интерпретируется и расширяется перед генерацией. (по умолчанию: "") | STRING | Да | Непустой текст (минимум 1 символ) |
| `aspect_ratio` | Соотношение сторон вывода. 'auto' выбирает его на основе промпта и входных данных. (по умолчанию: "auto") | STRING | Да | Несколько предопределенных опций (по умолчанию: "auto") |
| `duration` | Длительность клипа в секундах. 'auto' подбирает длину под содержимое. (по умолчанию: "auto") | STRING | Да | "auto" (по умолчанию)<br>Числовые значения в секундах |
| `resolution` | Разрешение вывода. (по умолчанию: "720p") | STRING | Да | Несколько предопределенных опций (по умолчанию: "720p") |
| `generate_audio` | Генерировать синхронизированное аудио (окружающие звуки, речь, эффекты). Выключено — создает видео без звуковой дорожки. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `safety_tolerance` | Допуск модерации: 0 — самый строгий. Запросы, отправляющие изображения или видео, ограничены 2 независимо от установленного значения. (дополнительный параметр, по умолчанию: 2) | INT | Да | 0 - 4 (эффективный максимум: 2 для видеозапросов) |
| `seed` | Сид для определения необходимости повторного запуска узла; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. (дополнительный параметр, по умолчанию: 42) | INT | Да | 0 - 4294967295 (0xFFFFFFFF) |

### Примечания

- `prompt` должен содержать хотя бы один символ, иначе генерация не удастся. Хотя поле по умолчанию пустое, для запуска узла требуется непустой промпт.
- `safety_tolerance` принимает любое значение от 0 до 4, но поскольку этот узел отправляет видео в API, эффективный допуск ограничен 2 независимо от выбранного значения.
- Когда `duration` задано числом, оно преобразуется в целое число секунд. Специальное значение "auto" позволяет сервису подобрать длину в соответствии с содержимым.
- Точные списки опций для `aspect_ratio`, `duration` и `resolution` определяются внутри узла. Варианты разрешения включают как минимум "720p" (по умолчанию) и "1080p", который использует другую ценовую ставку.
- Поля аутентификации и идентификации узла (`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`) скрыты и обрабатываются платформой автоматически.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `video` | Сгенерированный клип-продолжение, созданный FLUX 3, который продолжается с конца исходного видео. | VIDEO |
