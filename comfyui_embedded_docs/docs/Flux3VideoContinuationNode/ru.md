# Flux 3 Продолжение Видео

Этот узел продолжает существующий видеоклип с помощью FLUX 3: новый клип продолжается с последних кадров предоставленного вами видео. Он загружает исходный клип, отправляет запрос и настройки в сервис генерации и возвращает полученное видео-продолжение, когда оно готово.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Клип, который нужно продолжить. Клипы площадью более 3840x2160 пикселей уменьшаются, чтобы уложиться в лимит. | VIDEO | Да | Один видеоклип |
| `prompt` | Что должно быть показано в продолжении; запрос интерпретируется и расширяется перед генерацией. (по умолчанию: "") | STRING | Да | Непустой текст (минимум 1 символ) |
| `aspect_ratio` | Соотношение сторон выходного видео. `auto` выбирает его на основе запроса и входов. (по умолчанию: "auto") | COMBO | Да | "auto" (по умолчанию)<br>Несколько предопределённых опций |
| `duration` | Длительность клипа в секундах. `auto` подбирает длину под содержимое. (по умолчанию: "auto") | COMBO | Да | "auto" (по умолчанию)<br>Числовые значения в секундах |
| `resolution` | Разрешение выходного видео. (по умолчанию: "720p") | COMBO | Да | "720p" (по умолчанию)<br>"1080p"<br>"1440p"<br>"2160p" |
| `generate_audio` | Создавать синхронизированный звук (окружающий, речь, эффекты). При выключении создаётся видео без звуковой дорожки. (по умолчанию: true) | BOOLEAN | Да | true<br>false |
| `safety_tolerance` | Допуск модерации, 0 — самый строгий. Запросы, отправляющие изображения или видео, ограничиваются значением 2 независимо от того, что вы укажете здесь. (расширенный параметр, по умолчанию: 2) | INT | Да | 0 - 4 (эффективный максимум: 2 для видеозапросов) |
| `seed` | Значение seed, определяющее, должен ли узел перезапуститься; FLUX 3 выбирает собственный seed, поэтому фактические результаты недетерминированы независимо от этого значения. (по умолчанию: 42) | INT | Да | 0 - 4294967295 (0xFFFFFFFF) |

### Примечания

- `prompt` должен содержать хотя бы один символ, иначе генерация завершится ошибкой. Хотя поле по умолчанию пустое, для запуска узла требуется непустой запрос.
- `safety_tolerance` принимает любое значение от 0 до 4, но поскольку этот узел отправляет видео в API, эффективный допуск ограничивается значением 2 независимо от выбранного значения.
- Когда `duration` задано числом, оно преобразуется в целое число секунд. Специальное значение "auto" позволяет сервису подобрать длину под содержимое.
- Точные списки опций для `aspect_ratio`, `duration` и `resolution` определяются внутри узла. `resolution` предлагает "720p" (по умолчанию), "1080p", "1440p" и "2160p". Стоимость рассчитывается исходя из выбранных `resolution` и `duration`: "720p" тарифицируется по $0.5863 в секунду, "1080p" — по $0.7579, "1440p" — по $0.9295, "2160p" — по $1.3585.
- `seed` только управляет тем, должен ли узел перезапуститься; он не отправляется в сервис генерации.
- Поля аутентификации и идентификации узла (`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`) скрыты и обрабатываются платформой автоматически.
