# ادامه ویدیو Flux 3

این گره یک کلیپ ویدیویی موجود را با FLUX 3 ادامه می‌دهد: کلیپ جدید از فریم‌های پایانی ویدیویی که ارائه می‌دهید ادامه می‌یابد. کلیپ منبع شما را بارگذاری می‌کند، پرامپت و تنظیمات را به سرویس تولید می‌فرستد و ویدیوی ادامه حاصل را پس از آماده‌شدن بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | کلیپی که باید ادامه یابد. | VIDEO | بله | یک کلیپ ویدیویی |
| `prompt` | آنچه ادامه باید نشان دهد؛ پرامپت پیش از تولید تفسیر و گسترش داده می‌شود. (پیش‌فرض: "") | STRING | بله | متن غیرخالی (حداقل 1 کاراکتر) |
| `aspect_ratio` | نسبت ابعاد خروجی. «auto» یکی را بر اساس پرامپت و ورودی‌ها انتخاب می‌کند. (پیش‌فرض: "auto") | COMBO | بله | "auto" (پیش‌فرض)<br>چندین گزینه از پیش تعریف‌شده |
| `duration` | طول کلیپ بر حسب ثانیه. «auto» طول را با محتوا متناسب می‌کند. (پیش‌فرض: "auto") | COMBO | بله | "auto" (پیش‌فرض)<br>مقادیر عددی بر حسب ثانیه |
| `resolution` | رزولوشن خروجی. (پیش‌فرض: "720p") | COMBO | بله | "720p" (پیش‌فرض)<br>"1080p"<br>سایر گزینه‌های از پیش تعریف‌شده |
| `generate_audio` | تولید صدای همگام‌شده (محیطی، گفتار، جلوه‌ها). خاموش بودن، ویدیویی بدون مسیر صوتی تولید می‌کند. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `safety_tolerance` | میزان تحمل پالایش محتوا، 0 سخت‌گیرانه‌ترین است. درخواست‌هایی که تصویر یا ویدیو ارسال می‌کنند، هر مقداری که اینجا تنظیم کنید، حداکثر روی 2 محدود می‌شوند. (پارامتر پیشرفته، پیش‌فرض: 2) | INT | بله | 0 - 4 (حداکثر مؤثر: 2 برای درخواست‌های ویدیویی) |
| `seed` | مقدار seed برای تعیین اینکه گره باید دوباره اجرا شود؛ FLUX 3 بذر خودش را انتخاب می‌کند، بنابراین نتایج واقعی صرف‌نظر از این مقدار غیرقطعی هستند. (پیش‌فرض: 42) | INT | بله | 0 - 4294967295 (0xFFFFFFFF) |

### نکات

- `prompt` باید حداقل یک کاراکتر داشته باشد، در غیر این صورت تولید شکست می‌خورد. اگرچه این فیلد به‌طور پیش‌فرض رشته خالی است، برای اجرای گره به پرامپت غیرخالی نیاز است.
- `safety_tolerance` هر مقداری از 0 تا 4 را می‌پذیرد، اما چون این گره یک ویدیو به API ارسال می‌کند، تحمل مؤثر مستقل از مقدار انتخاب‌شده روی 2 محدود می‌شود.
- وقتی `duration` روی یک عدد تنظیم شود، به تعداد صحیحی از ثانیه تبدیل می‌شود. مقدار ویژه "auto" به سرویس اجازه می‌دهد طول را با محتوا متناسب کند.
- فهرست‌های دقیق گزینه‌ها برای `aspect_ratio`، `duration` و `resolution` به‌صورت داخلی توسط گره تعریف می‌شوند. گزینه‌های رزولوشن حداقل شامل "720p" (پیش‌فرض) و "1080p" است. قیمت‌گذاری بر اساس `resolution` و `duration` انتخاب‌شده محاسبه می‌شود؛ "1080p" به‌ازای هر ثانیه 0.7579 دلار و سایر رزولوشن‌ها به‌ازای هر ثانیه 0.5863 دلار محاسبه می‌شوند.
- `seed` فقط کنترل می‌کند که گره دوباره اجرا شود یا نه؛ به سرویس تولید ارسال نمی‌شود.
- فیلدهای احراز هویت و شناسایی گره (`auth_token_comfy_org`، `api_key_comfy_org`، `unique_id`) پنهان هستند و به‌صورت خودکار توسط پلتفرم مدیریت می‌شوند.
