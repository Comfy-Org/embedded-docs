# Flux3VideoContinuationNode

این گره یک کلیپ ویدیویی موجود را با FLUX 3 ادامه می‌دهد، به‌طوری‌که کلیپ جدید از فریم‌های انتهایی ویدیوی ارائه‌شده ادامه می‌یابد. این گره کلیپ منبع شما را بارگذاری می‌کند، prompt و تنظیمات را به سرویس تولید ارسال می‌کند و پس از آماده‌شدن، ویدیوی ادامه‌یافته حاصل را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|----------|----------|--------|--------|
| `video` | کلیپی که باید ادامه داده شود. | VIDEO | بله | یک کلیپ ویدیویی |
| `prompt` | محتوایی که ادامه باید نشان دهد؛ این prompt قبل از تولید تفسیر و بسط داده می‌شود. (پیش‌فرض: "") | STRING | بله | متن غیرخالی (حداقل ۱ کاراکتر) |
| `aspect_ratio` | نسبت ابعاد خروجی. 'auto' یکی را از روی prompt و ورودی‌ها انتخاب می‌کند. (پیش‌فرض: "auto") | STRING | بله | چند گزینه از پیش تعریف‌شده (پیش‌فرض: "auto") |
| `duration` | طول کلیپ به ثانیه. 'auto' طول را با محتوا هماهنگ می‌کند. (پیش‌فرض: "auto") | STRING | بله | "auto" (پیش‌فرض)<br>مقادیر عددی به ثانیه |
| `resolution` | رزلوشن خروجی. (پیش‌فرض: "720p") | STRING | بله | چند گزینه از پیش تعریف‌شده (پیش‌فرض: "720p") |
| `generate_audio` | تولید صدای هماهنگ (محیطی، گفتار، افکت‌ها). غیرفعال بودن، ویدیویی بدون track صوتی تولید می‌کند. (پیش‌فرض: true) | BOOLEAN | بله | true<br>false |
| `safety_tolerance` | میزان تحمل نظارت (moderation)، 0 سخت‌گیرانه‌ترین حالت است. درخواست‌هایی که تصویر یا ویدیو ارسال می‌کنند، صرف‌نظر از مقداری که اینجا تنظیم کنید، در 2 محدود می‌شوند. (پارامتر پیشرفته، پیش‌فرض: 2) | INT | بله | 0 - 4 (حداکثر مؤثر: 2 برای درخواست‌های ویدیویی) |
| `seed` | دانه (seed) برای تعیین اینکه آیا گره دوباره اجرا شود؛ FLUX 3 دانه خودش را انتخاب می‌کند، بنابراین نتایج واقعی بدون توجه به این مقدار قطعی نیستند. (پارامتر پیشرفته، پیش‌فرض: 42) | INT | بله | 0 - 4294967295 (0xFFFFFFFF) |

### نکات

- `prompt` باید حداقل یک کاراکتر داشته باشد، در غیر این صورت تولید ناموفق خواهد بود. اگرچه این فیلد به‌صورت پیش‌فرض خالی است، برای اجرای گره به یک prompt غیرخالی نیاز است.
- `safety_tolerance` هر مقداری از 0 تا 4 را می‌پذیرد، اما چون این گره یک ویدیو به API ارسال می‌کند، تحمل مؤثر بدون توجه به مقدار انتخابی در 2 محدود است.
- وقتی `duration` به صورت عددی تنظیم شود، به یک عدد صحیح از ثانیه تبدیل می‌شود. مقدار ویژه "auto" به سرویس اجازه می‌دهد طول را با محتوا هماهنگ کند.
- فهرست دقیق گزینه‌ها برای `aspect_ratio`، `duration` و `resolution` به‌صورت داخلی توسط گره تعریف شده‌اند. گزینه‌های رزلوشن حداقل شامل "720p" (پیش‌فرض) و "1080p" هستند که از نرخ قیمت‌گذاری متفاوتی استفاده می‌کند.
- فیلدهای احراز هویت و شناسایی گره (`auth_token_comfy_org`، `api_key_comfy_org`، `unique_id`) پنهان هستند و به‌صورت خودکار توسط پلتفرم مدیریت می‌شوند.
