# ادامه ویدیو Flux 3

این گره یک کلیپ ویدیویی موجود را با FLUX 3 ادامه می‌دهد: کلیپ جدید از فریم‌های پایانی ویدیویی که ارائه می‌دهید ادامه پیدا می‌کند. این گره کلیپ منبع شما را بارگذاری می‌کند، prompt و تنظیمات را به سرویس تولید ارسال می‌کند و پس از آماده شدن، ویدیوی ادامه‌یافته حاصل را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | کلیپی که باید ادامه داده شود. | VIDEO | بله | یک کلیپ ویدیویی |
| `پرامپت` | آنچه ادامه باید نشان دهد؛ prompt قبل از تولید تفسیر و بسط داده می‌شود. (پیش‌فرض: "") | STRING | بله | متن غیرخالی (حداقل ۱ کاراکتر) |
| `نسبت تصویر` | نسبت تصویر خروجی. «auto» یکی را از روی prompt و ورودی‌ها انتخاب می‌کند. (پیش‌فرض: "auto") | COMBO | بله | "auto" (پیش‌فرض)<br>چندین گزینه از پیش تعریف‌شده |
| `مدت زمان` | طول کلیپ بر حسب ثانیه. «auto» طول را با محتوا هماهنگ می‌کند. (پیش‌فرض: "auto") | COMBO | بله | "auto" (پیش‌فرض)<br>مقادیر عددی به ثانیه |

| `بذر` | seed برای تعیین اینکه گره دوباره اجرا شود؛ FLUX 3 seed خودش را انتخاب می‌کند، بنابراین نتایج واقعی بدون توجه به این مقدار غیرقطعی هستند. (پارامتر پیشرفته، پیش‌فرض: ۴۲) | INT | بله | 0 - 4294967295 (0xFFFFFFFF) |

### یادداشت‌ها

- `prompt` باید حداقل یک کاراکتر داشته باشد، در غیر این صورت تولید شکست می‌خورد. اگرچه فیلد به‌صورت پیش‌فرض رشته خالی است، برای اجرای گره یک prompt غیرخالی الزامی است.
- `safety_tolerance` هر مقداری از ۰ تا ۴ را می‌پذیرد، اما چون این گره یک ویدیو به API ارسال می‌کند، تلورانس مؤثر بدون توجه به مقدار انتخابی روی ۲ محدود می‌شود.
- وقتی `duration` روی یک عدد تنظیم می‌شود، به یک عدد صحیح از ثانیه تبدیل می‌شود. مقدار ویژه «auto» به سرویس اجازه می‌دهد طول را با محتوا هماهنگ کند.
- فهرست دقیق گزینه‌ها برای `aspect_ratio`، `duration` و `resolution` به‌صورت داخلی توسط گره تعریف شده است. گزینه‌های رزولوشن حداقل شامل "720p" (پیش‌فرض) و "1080p" هستند. قیمت‌گذاری بر اساس `resolution` و `duration` انتخابی محاسبه می‌شود؛ "1080p" به نرخ $0.7579 بر ثانیه و سایر رزولوشن‌ها به نرخ $0.5863 بر ثانیه محاسبه می‌شوند.
- فیلدهای احراز هویت و شناسایی گره (`auth_token_comfy_org`، `api_key_comfy_org`، `unique_id`) مخفی هستند و به‌صورت خودکار توسط پلتفرم مدیریت می‌شوند.
