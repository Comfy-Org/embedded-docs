# הקלטת אודיו

הצומת RecordAudio טוען קובצי אודיו שהוקלטו או נבחרו דרך ממשק הקלטת האודיו. הוא מעבד את קובץ האודיו וממיר אותו לפורמט צורת גל שבו יכולים להשתמש צמתי עיבוד אודיו אחרים בזרימת העבודה. הצומת מזהה אוטומטית את קצב הדגימה ומכין את נתוני האודיו לעיבוד נוסף.
