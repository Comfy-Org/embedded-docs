# اعمال Conditioning مدل SeedVR2

این گره، شرطی‌سازی مثبت و منفی را از یک لاتنت VAE برای استفاده با مدل SeedVR2 می‌سازد. یک کانال ماسک به لاتنت اضافه می‌کند و سپس آن را با جاسازی‌های شرطی‌سازی مثبت و منفی داخلی مدل جفت می‌کند تا مقادیر شرطی‌سازی مورد نیاز برای نمونه‌برداری تولید شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل SeedVR2. | MODEL | بله | - |
| `vae_conditioning` | لاتنت VAE که شرطی‌سازی از آن ساخته می‌شود. نام نمایشی: latent. | LATENT | بله | - |

لاتنت `vae_conditioning` باید یک تنسور ۵-بعدی در چیدمان کانال-اول Comfy (B, C, T, H, W) با تعداد کانال‌های مورد انتظار VAE مدل SeedVR2 باشد. لاتنت‌های کانال-آخر با خطا رد می‌شوند. ورودی `model` باید یک مدل SeedVR2 معتبر با ساختار داخلی مورد انتظار باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت برای نمونه‌برداری. | CONDITIONING |
| `negative` | شرطی‌سازی منفی برای نمونه‌برداری. | CONDITIONING |
