# Применить SeedVR2 Conditioning

Этот узел создает положительное и отрицательное кондиционирование из латентного представления VAE для использования с моделью SeedVR2. Он проверяет форму входного латентного представления и структуру модели, затем формирует как положительное, так и отрицательное кондиционирование, которое направляет сэмплирование изображений или видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель SeedVR2. | MODEL | Да | - |
| `vae_conditioning` | Латентное представление VAE SeedVR2, из которого создается кондиционирование (отображаемое имя: latent). | LATENT | Да | - |

Примечание: Латентное представление `vae_conditioning` должно быть 5-D тензором в формате Comfy, где каналы располагаются первыми (B, C, T, H, W), где C — ожидаемое количество каналов VAE SeedVR2. Узел выдает ошибку, если латентное представление не является 5-D, если количество его каналов не совпадает или если оно, по-видимому, имеет порядок каналов последними (channel-last). Вход `model` должен быть моделью с ожидаемой структурой SeedVR2. Внутри узел добавляет постоянный канал маски к латентному представлению и присоединяет полученное условие как к пулу положительного, так и отрицательного кондиционирования.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование для сэмплирования. | CONDITIONING |
| `negative` | Отрицательное кондиционирование для сэмплирования. | CONDITIONING |
