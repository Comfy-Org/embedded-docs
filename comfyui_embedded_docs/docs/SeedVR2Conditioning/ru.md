# Применить SeedVR2 Conditioning

Формирует положительное и отрицательное кондиционирование из VAE-латента для использования с моделью SeedVR2. Проверяет входной латент и структуру модели, добавляет к латенту канал маски и возвращает оба выхода кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель SeedVR2. | MODEL | Да | - |
| `vae_conditioning` | Латент VAE SeedVR2, из которого строится кондиционирование (отображаемое имя: latent). | LATENT | Да | - |

Примечание: латент `vae_conditioning` должен быть 5-D тензором в формате Comfy с каналами в начале (B, C, T, H, W), где C — ожидаемое количество каналов VAE SeedVR2. Узел выдаёт ошибку, если латент не является 5-D, если количество каналов не совпадает или если тензор, судя по всему, имеет формат с каналами в конце. Вход `model` должен иметь ожидаемую структуру SeedVR2; узел определяет её внутреннюю диффузионную модель и считывает её положительное и отрицательное кондиционирование. Внутри узел добавляет к латенту константный канал маски и присоединяет полученное условие к обоим выходам — положительному и отрицательному кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование для сэмплирования. | CONDITIONING |
| `negative` | Отрицательное кондиционирование для сэмплирования. | CONDITIONING |
