# Применить SeedVR2 Conditioning

Этот узел создает позитивное и негативное кондиционирование из латентного представления VAE для использования с моделью SeedVR2. Он добавляет канал маски к латентному представлению, затем объединяет его со встроенными эмбеддингами позитивного и негативного кондиционирования модели, чтобы получить значения кондиционирования, необходимые для сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель SeedVR2. | MODEL | Да | - |
| `vae_conditioning` | Латентное представление VAE, из которого строится кондиционирование. Отображаемое имя: latent. | LATENT | Да | - |

Латентное представление `vae_conditioning` должно быть 5-D тензором в формате Comfy с расположением каналов в начале (B, C, T, H, W) и числом каналов, ожидаемых VAE модели SeedVR2. Латентные представления с каналами в конце отклоняются с ошибкой. Вход `model` должен быть допустимой моделью SeedVR2 с ожидаемой внутренней структурой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование для сэмплирования. | CONDITIONING |
| `negative` | Негативное кондиционирование для сэмплирования. | CONDITIONING |
