# تولید ویدیو با مرجع Grok

گره Grok Reference-to-Video یک ویدیو از روی متن prompt تولید می‌کند و از حداکثر هفت تصویر مرجع برای هدایت سبک و محتوای خروجی استفاده می‌کند. با مدل `grok-imagine-video-1.5` می‌توانید حداکثر سه مرجع صدای از پیش تعیین‌شده را نیز ضمیمه کنید و با استفاده از برچسب‌های `@ImageN` و `@AudioN` مستقیماً در prompt به تصاویر و صداها ارجاع دهید. گره درخواست را به یک API خارجی ارسال می‌کند، منتظر تکمیل تولید می‌ماند و ویدیوی حاصل را دانلود می‌کند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | مرجع صدای اختیاری از پیش تعیین‌شده؛ در prompt به صورت @Audio1 به آن ارجاع دهید. API فقط از این صداهای از پیش تعیین‌شده پشتیبانی می‌کند، نه صدای سفارشی (پیش‌فرض: none). | COMBO | خیر | گزینه‌های صدای از پیش تعیین‌شده، شامل `"none"` |
| `voice_2` | دومین مرجع صدای اختیاری؛ در prompt به صورت @Audio2 (پیش‌فرض: none). | COMBO | خیر | گزینه‌های صدای از پیش تعیین‌شده، شامل `"none"` |
| `voice_3` | سومین مرجع صدای اختیاری؛ در prompt به صورت @Audio3 (پیش‌فرض: none). | COMBO | خیر | گزینه‌های صدای از پیش تعیین‌شده، شامل `"none"` |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | اسلات قابل رشد: ۱ تا ۷ تصویر مرجع را برای هدایت تولید ویدیو متصل کنید. با `grok-imagine-video-1.5`، در prompt با @Image1 ... @Image7 به آن‌ها ارجاع دهید، که به ترتیب ورودی شماره‌گذاری می‌شوند؛ یک ورودی دسته‌ای به ازای هر تصویر یک بار شمارش می‌شود. | IMAGE | بله | 1 تا 7 images |

**توجه:** پارامترهای فرعی نمایش‌داده‌شده به `model` انتخاب‌شده بستگی دارند؛ `grok-imagine-video-1.5` ورودی‌های `voice_1`، `voice_2` و `voice_3` را اضافه می‌کند. حداقل یک تصویر مرجع الزامی است و حداکثر به ۷ تصویر محدود می‌شود (یک ورودی دسته‌ای به ازای هر تصویر یک بار شمارش می‌شود). با `grok-imagine-video-1.5`، prompt می‌تواند به تصاویر متصل به صورت `@Image1` ... `@Image7` و به اسلات‌های صدا به صورت `@Audio1`، `@Audio2`، `@Audio3` ارجاع دهد؛ یک `@image` یا `@audio` بدون شماره به اولین مورد اشاره می‌کند. `@AudioN` به ویجت `voice_N` اشاره دارد، نه ترتیب صداهای فعال. ارجاع به تصویری که متصل نیست یا اسلات صدایی که روی `none` تنظیم شده باعث خطا می‌شود. API فقط از صداهای از پیش تعیین‌شده پشتیبانی می‌کند، نه صدای سفارشی.
