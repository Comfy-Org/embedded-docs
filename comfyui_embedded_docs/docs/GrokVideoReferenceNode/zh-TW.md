# Grok 參考生成影片

Grok Reference-to-Video 節點會依據文字提示詞生成影片，使用最多七張參考影像來引導輸出的風格與內容。使用 `grok-imagine-video-1.5` 模型時，您還可以在提示詞中直接附加最多三個預設語音參考，並以 `@ImageN` 和 `@AudioN` 標籤參照影像與語音。此節點會將請求傳送至外部 API，等待生成完成後下載結果影片。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 所需影片的文字描述。必須為非空字串。 | STRING | 是 | N/A |
| `模型` | 用於影片生成的模型。 | COMBO | 是 | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `種子` | 用於判斷節點是否應重新執行的種子；無論種子為何，實際結果皆為非確定性（預設值：0）。 | INT | 否 | 0 至 2147483647 |

### Grok Imagine Video 1.5 輸入

當 `model` 設為 `grok-imagine-video-1.5` 時可用。

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | 選用的預設語音參考；在提示詞中以 @Audio1 參照。API 僅支援這些預設語音，不支援自訂音訊（預設值：無）。 | COMBO | 否 | 預設語音選項（包含 `"none"`） |
| `voice_2` | 選用的第二個語音參考；在提示詞中以 @Audio2 參照（預設值：無）。 | COMBO | 否 | 預設語音選項（包含 `"none"`） |
| `voice_3` | 選用的第三個語音參考；在提示詞中以 @Audio3 參照（預設值：無）。 | COMBO | 否 | 預設語音選項（包含 `"none"`） |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | `"480p"`<br>`"720p"` |
| `aspect_ratio` | 輸出影片的長寬比。 | COMBO | 是 | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | 輸出影片的持續時間（秒）（預設值：6）。 | INT | 是 | 1 至 15 |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可擴充插槽（Growable slot）：連接 1 至 7 張參考影像以引導影片生成。使用 `grok-imagine-video-1.5` 時，可在提示詞中以 @Image1 ... @Image7 參照這些影像，依輸入順序編號；批次輸入的每一張影像都會個別計算。 | IMAGE | 是 | 1 至 7 張影像 |

**注意：** 顯示的子參數取決於所選的 `model`；`grok-imagine-video-1.5` 會新增 `voice_1`、`voice_2` 和 `voice_3` 輸入。至少需要一張參考影像，總數上限為 7 張（批次輸入的每一張影像都會個別計算）。使用 `grok-imagine-video-1.5` 時，提示詞可參照已連接的影像為 `@Image1` ... `@Image7`，以及已啟用的語音為 `@Audio1`、`@Audio2`、`@Audio3`；參照未連接的影像或設為 `none` 的語音會導致錯誤。API 僅支援預設語音，不支援自訂音訊。
