# Grok 參考生成影片

Grok 參考轉影片節點會根據文字提示產生影片，使用最多七張參考影像來引導輸出的風格與內容。使用 `grok-imagine-video-1.5` 模型時，您還可以附加最多三個預設語音參考，並在提示中直接使用 `@ImageN` 和 `@AudioN` 標籤來引用影像與語音。該節點會將請求傳送至外部 API，等待生成完成後下載產生的影片。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片生成的模型。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `提示詞` | 所需影片的文字描述。必須是非空字串。 | STRING | 是 | N/A |
| `種子` | 種子值，用於決定節點是否應重新執行；無論種子值為何，實際結果都是非確定性的（預設值：0）。 | INT | 是 | 0 到 2147483647 |

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |

| `voice_3` | 可選的第三個語音參考；在提示中為 @Audio3（預設值：none）。 | COMBO | 否 | 預設語音選項，包括 `"none"` |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可擴充插槽：連接 1 到 7 張參考影像以引導影片生成。使用 `grok-imagine-video-1.5` 時，請在提示中依輸入順序將它們引用為 @Image1 ... @Image7；批次輸入每張影像計數一次。 | IMAGE | 是 | 1 到 7 張影像 |

**注意：** 顯示的子參數取決於所選的 `model`；`grok-imagine-video-1.5` 會新增 `voice_1`、`voice_2` 和 `voice_3` 輸入。至少需要一張參考影像，總數上限為 7 張（批次輸入每張影像計數一次）。使用 `grok-imagine-video-1.5` 時，提示可以將已連接的影像引用為 `@Image1` ... `@Image7`，將語音槽位引用為 `@Audio1`、`@Audio2`、`@Audio3`；未編號的 `@image` 或 `@audio` 指的是第一個。`@AudioN` 指的是 `voice_N` 控件，而不是已啟用語音的順序。引用未連接的影像或設定為 `none` 的語音槽位會導致錯誤。API 僅支援預設語音，不支援自訂音訊。
