# Grok Reference-to-Video

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для генерации видео. | DYNAMIC_COMBO | Да | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `запрос` | Текстовое описание желаемого видео. Должно быть непустой строкой. | STRING | Да | Н/Д |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | 0 до 2147483647 |

### Входы Grok Imagine Video 1.5

Доступно, когда `model` имеет значение `grok-imagine-video-1.5`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | Необязательный предустановленный голосовой референс; в запросе обращайтесь к нему как @Audio1. API поддерживает только эти предустановленные голоса, а не пользовательское аудио (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции, включая `"none"` |
| `voice_2` | Необязательный второй голосовой референс; в запросе @Audio2 (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции, включая `"none"` |
| `voice_3` | Необязательный третий голосовой референс; в запросе @Audio3 (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции, включая `"none"` |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 6). | INT | Да | 1 до 15 |

### Входы Grok Imagine Video

Доступно, когда `model` имеет значение `grok-imagine-video`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 6). | INT | Да | 2 до 10 |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до 7 эталонных изображений для управления генерацией видео. С `grok-imagine-video-1.5` обращайтесь к ним в запросе как @Image1 ... @Image7, нумерованных в порядке входа; пакетный вход учитывается по одному разу на каждое изображение. | IMAGE | Да | от 1 до 7 изображений |

**Примечание:** Отображаемые подпараметры зависят от выбранной `model`; `grok-imagine-video-1.5` добавляет входы `voice_1`, `voice_2` и `voice_3`. Требуется как минимум одно эталонное изображение, а общее количество ограничено 7 (пакетный вход учитывается по одному разу на каждое изображение). С `grok-imagine-video-1.5` в запросе можно ссылаться на подключенные изображения как `@Image1` ... `@Image7` и на голосовые слоты как `@Audio1`, `@Audio2`, `@Audio3`; ненумерованный `@image` или `@audio` относится к первому из них. `@AudioN` относится к виджету `voice_N`, а не к порядку включенных голосов. Ссылка на неподключенное изображение или голосовой слот со значением `none` вызывает ошибку. API поддерживает только предустановленные голоса, а не пользовательское аудио.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
