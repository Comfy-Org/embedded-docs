# Grok Reference-to-Video

Узел Grok Reference-to-Video генерирует видео по текстовому запросу, используя до семи референсных изображений для управления стилем и содержанием результата. С моделью `grok-imagine-video-1.5` вы также можете подключить до трёх предустановленных голосовых ссылок и ссылаться на изображения и голоса непосредственно в запросе с помощью тегов `@ImageN` и `@AudioN`. Узел отправляет запрос во внешний API, ожидает завершения генерации и загружает полученное видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для генерации видео. | DYNAMIC_COMBO | Да | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `запрос` | Текстовое описание желаемого видео. Должно быть непустой строкой. | STRING | Да | N/A |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |

### Входы Grok Imagine Video 1.5

Доступно, когда для `model` задано значение `grok-imagine-video-1.5`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | Необязательная предустановленная голосовая ссылка; указывайте на неё в запросе как @Audio1. API поддерживает только эти предустановленные голоса, а не пользовательское аудио (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции (включая `"none"`) |
| `voice_2` | Необязательная вторая голосовая ссылка; @Audio2 в запросе (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции (включая `"none"`) |
| `voice_3` | Необязательная третья голосовая ссылка; @Audio3 в запросе (по умолчанию: none). | COMBO | Нет | Предустановленные голосовые опции (включая `"none"`) |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 6). | INT | Да | от 1 до 15 |

### Входы Grok Imagine Video

Доступно, когда для `model` задано значение `grok-imagine-video`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 6). | INT | Да | от 2 до 10 |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до 7 референсных изображений для управления генерацией видео. С `grok-imagine-video-1.5` указывайте на них в запросе как @Image1 ... @Image7, нумерованных в порядке ввода; пакетный вход учитывается один раз на каждое изображение. | IMAGE | Да | от 1 до 7 изображений |

**Примечание:** Отображаемые подпараметры зависят от выбранной `model`; `grok-imagine-video-1.5` добавляет входы `voice_1`, `voice_2` и `voice_3`. Требуется как минимум одно референсное изображение, а общее количество ограничено 7 (пакетный вход учитывается один раз на каждое изображение). С `grok-imagine-video-1.5` в запросе можно ссылаться на подключённые изображения как `@Image1` ... `@Image7` и на включённые голоса как `@Audio1`, `@Audio2`, `@Audio3`; ссылка на неподключённое изображение или голос, установленный в `none`, вызывает ошибку. API поддерживает только предустановленные голоса, а не пользовательское аудио.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
