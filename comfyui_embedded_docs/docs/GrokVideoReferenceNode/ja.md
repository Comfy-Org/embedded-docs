# Grokリファレンス→ビデオ

Grok Reference-to-Video ノードは、テキストプロンプトから動画を生成し、最大7枚の参照画像を使用して出力のスタイルと内容をガイドします。`grok-imagine-video-1.5` モデルでは、最大3つのプリセット音声参照を追加でき、`@ImageN` タグと `@AudioN` タグを使用してプロンプト内で直接画像と音声を参照できます。ノードはリクエストを外部APIに送信し、生成が完了するまで待機して、結果の動画をダウンロードします。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用するモデル。 | DYNAMIC_COMBO | 必須 | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `プロンプト` | 生成したい動画のテキストによる説明。空でない文字列である必要があります。 | STRING | 必須 | N/A |
| `シード` | ノードを再実行する必要があるかどうかを判断するためのシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | 必須 | 0 〜 2147483647 |

### Grok Imagine Video 1.5 入力

`model` が `grok-imagine-video-1.5` に設定されている場合に利用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |

| `voice_2` | オプションの2番目の音声参照。プロンプト内で @Audio2 として参照します（デフォルト: none）。 | COMBO | 任意 | Preset voice options, including `"none"` |
| `voice_3` | オプションの3番目の音声参照。プロンプト内で @Audio3 として参照します（デフォルト: none）。 | COMBO | 任意 | Preset voice options, including `"none"` |
| `resolution` | 出力動画の解像度。 | COMBO | 必須 | `"480p"`<br>`"720p"` |
| `aspect_ratio` | 出力動画のアスペクト比。 | COMBO | 必須 | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能なスロット: 動画生成をガイドするために、1～7枚の参照画像を接続します。`grok-imagine-video-1.5` では、プロンプト内で @Image1 ... @Image7 として参照します。番号は入力順に対応し、バッチ入力は画像1枚ごとに1回としてカウントされます。 | IMAGE | 必須 | 1 〜 7 images |

**注記:** 表示されるサブパラメータは選択した `model` によって異なります。`grok-imagine-video-1.5` では、`voice_1`、`voice_2`、`voice_3` の入力が追加されます。参照画像は少なくとも1枚必要で、合計は最大7枚です（バッチ入力は画像1枚ごとに1回とカウントされます）。`grok-imagine-video-1.5` では、プロンプト内で接続した画像を `@Image1` ... `@Image7` として、音声スロットを `@Audio1`、`@Audio2`、`@Audio3` として参照できます。番号のない `@image` または `@audio` は最初のものを参照します。`@AudioN` は `voice_N` ウィジェットを指し、有効な音声の順序ではありません。接続されていない画像や `none` に設定された音声スロットを参照するとエラーが発生します。API はカスタム音声ではなく、プリセット音声のみをサポートしています。
