# Grokリファレンス→ビデオ

Grok Reference-to-Video ノードは、テキストプロンプトから動画を生成します。最大7枚の参照画像を使用して、出力のスタイルと内容をガイドします。`grok-imagine-video-1.5` モデルでは、最大3つのプリセット音声リファレンスを添付でき、プロンプト内で `@ImageN` タグと `@AudioN` タグを使用して画像と音声を直接参照できます。このノードはリクエストを外部 API に送信し、生成が完了するまで待機して、結果の動画をダウンロードします。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 生成したい動画のテキストによる説明です。空でない文字列である必要があります。 | STRING | はい | N/A |
| `モデル` | 動画生成に使用するモデルです。 | COMBO | はい | `"grok-imagine-video-1.5"`<br>`"grok-imagine-video"` |
| `シード` | ノードを再実行するかどうかを決定するシードです。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | いいえ | 0〜2147483647 |

### Grok Imagine Video 1.5 入力

`model` が `grok-imagine-video-1.5` に設定されている場合に使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | オプションのプリセット音声リファレンスです。プロンプト内で `@Audio1` として参照します。API はカスタム音声ではなく、これらのプリセット音声のみをサポートします（デフォルト: none）。 | COMBO | いいえ | プリセット音声オプション（`"none"` を含む） |
| `voice_2` | オプションの2つ目の音声リファレンスです。プロンプト内で `@Audio2` として参照します（デフォルト: none）。 | COMBO | いいえ | プリセット音声オプション（`"none"` を含む） |
| `voice_3` | オプションの3つ目の音声リファレンスです。プロンプト内で `@Audio3` として参照します（デフォルト: none）。 | COMBO | いいえ | プリセット音声オプション（`"none"` を含む） |
| `resolution` | 出力動画の解像度です。 | COMBO | はい | `"480p"`<br>`"720p"` |
| `aspect_ratio` | 出力動画のアスペクト比です。 | COMBO | はい | `"16:9"`<br>`"4:3"`<br>`"3:2"`<br>`"1:1"`<br>`"2:3"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | 出力動画の長さ（秒）です（デフォルト: 6）。 | INT | はい | 1〜15 |

### Grok Imagine Video 入力

`model` が `grok-imagine-video` に設定されている場合に使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 出力動画の解像度です。 | COMBO | はい | `"480p"`<br>`"720p"` |

| `duration` | 出力動画の長さ（秒）です（デフォルト: 6）。 | INT | はい | 2〜10 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能スロット: 動画生成をガイドするために、参照画像を1〜7枚接続します。`grok-imagine-video-1.5` の場合、プロンプト内で `@Image1` ... `@Image7` として参照します（番号は入力順です）。バッチ入力は画像1枚ごとに1回としてカウントされます。 | IMAGE | はい | 1〜7枚 |

**注：** 表示されるサブパラメータは選択した `model` によって異なります。`grok-imagine-video-1.5` では `voice_1`、`voice_2`、`voice_3` の入力が追加されます。参照画像は少なくとも1枚必要で、合計は7枚が上限です（バッチ入力は画像1枚ごとに1回としてカウントされます）。`grok-imagine-video-1.5` では、プロンプト内で接続済みの画像を `@Image1` ... `@Image7`、有効な音声を `@Audio1`、`@Audio2`、`@Audio3` として参照できます。接続されていない画像や `none` に設定された音声を参照するとエラーになります。API はカスタム音声ではなく、プリセット音声のみをサポートします。
