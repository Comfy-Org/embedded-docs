# Load LoRA (Text Encoder)

Применяет стек LoRA к текстовому энкодеру CLIP в одном узле. Каждая строка `loras` содержит файл LoRA, его силу и переключатель вкл/выкл, и строки применяются сверху вниз, так что каждая строка накладывает патч на результат строки выше. Файлы LoRA, которые изменяют текстовый энкодер, обычно также применяются к модели, поэтому этот узел обычно используется вместе с Load LoRA (Model) с теми же строками.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Текстовый энкодер CLIP, к которому будут применены LoRA. | CLIP | Да | - |
| `loras` | Расширяемая группа LoRA, применяемая к текстовому энкодеру в порядке строк (`loras.0`, `loras.1` и так далее). Добавьте по одной строке на каждую LoRA; каждая строка содержит файл, силу и переключатель вкл/выкл. | DYNAMIC_GROUP | Да | от 1 до 20 строк |

### Поля строки `loras`

Каждая строка повторяет следующие поля, и каждое поле обязательно в переданной строке.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `lora_name` | Имя файла LoRA для применения. | COMBO | Да | Доступны несколько вариантов |
| `strength` | Насколько сильно применять эту LoRA к текстовому энкодеру. `0` отключает её, а отрицательное значение инвертирует эффект. (по умолчанию: 1.0) | FLOAT | Да | от -100 до 100 (шаг 0.01) |
| `enabled` | Отключите, чтобы пропустить эту LoRA, не меняя её файл или силу. (по умолчанию: true) | BOOLEAN | Да | false / true |

### Ограничения параметров

- **Количество строк:** необходимо отправить хотя бы одну строку, принимается не более 20 строк, поэтому максимальный индекс строки — 19.
- **Пропускаемые строки:** строка пропускается, если её файл пуст, если `enabled` выключен или если `strength` равен `0`. Отрицательная сила передаётся дальше, а не пропускается.
- **Порядок строк:** строки применяются в порядке их следования, и каждая строка начинает с текстового энкодера, возвращённого предыдущей строкой.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CLIP` | Текстовый энкодер CLIP после применения строк LoRA, которые не были пропущены. | CLIP |
