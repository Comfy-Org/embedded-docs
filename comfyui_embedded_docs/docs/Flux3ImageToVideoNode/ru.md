# Flux3ImageToVideoNode

Flux 3 Image to Video оживляет от 1 до 10 изображений с помощью FLUX 3. Каждое изображение становится кадром клипа: одно изображение открывает клип, два превращают первое во второе, а остальные распределяются по клипу или привязываются к выбранным вами моментам времени.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Как сцена должна двигаться и звучать; промпт интерпретируется и расширяется перед генерацией. Должен содержать хотя бы один символ. | STRING | Да | Многострочный текст (по умолчанию: пусто) |
| `keyframes` | От 1 до 10 изображений в порядке воспроизведения. Каждое минимум 256x256 пикселей. Каждый ключевой кадр становится точкой в клипе. | IMAGE | Да | от 1 до 10 изображений |
| `placement` | `'spread across the clip'` позволяет FLUX 3 разместить изображения (одно открывает клип, два становятся его началом и концом); `'at times'` привязывает каждое изображение к выбранной вами секунде. | STRING | Да | `"spread across the clip"` (по умолчанию)<br>`"at times"` |
| `times` | По одному времени в секундах на каждое изображение, через запятую и по возрастанию, например: '0, 2.5, 5'. Обязательно, когда `placement` имеет значение `"at times"`. | STRING | Нет | Секунды через запятую (по умолчанию: "0") |
| `aspect_ratio` | Соотношение сторон вывода. 'auto' выбирает его на основе промпта и входных данных. | STRING | Да | `"auto"` (по умолчанию)<br>плюс другие доступные варианты |
| `duration` | Длительность клипа в секундах. 'auto' подбирает длину под содержимое. | STRING | Да | `"auto"` (по умолчанию)<br>плюс другие доступные варианты |
| `resolution` | Разрешение вывода. | STRING | Да | `"720p"` (по умолчанию)<br>`"1080p"` |
| `generate_audio` | Генерировать синхронизированный звук (окружение, речь, эффекты). Выключено создаёт видео без звуковой дорожки. | BOOLEAN | Да | true / false (по умолчанию: true) |
| `safety_tolerance` | Допуск модерации: 0 — самый строгий. Запросы с изображениями или видео ограничиваются значением 2 независимо от того, что вы здесь зададите. | INT | Да | от 0 до 4 (по умолчанию: 2, дополнительная настройка) |
| `seed` | Сид для определения необходимости повторного запуска узла; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. | INT | Да | от 0 до 4294967295 (по умолчанию: 42, with control-after-generate) |

Примечание: `keyframes` обязателен — узел выдаёт ошибку, если не подключено ни одного изображения ключевого кадра. Когда `placement` имеет значение `"spread across the clip"` и передано 3 или более изображений, `duration` должно быть задано явным значением (не `"auto"`); в противном случае узел выдаёт ошибку. Когда `placement` имеет значение `"at times"`, параметр `times` должен содержать по одному времени в секундах на каждое изображение в порядке возрастания. Запросы с изображениями ограничиваются допуском модерации 2 независимо от заданного значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип, созданный из изображений ключевых кадров с выбранными соотношением сторон, длительностью, разрешением и настройкой звука. | VIDEO |
