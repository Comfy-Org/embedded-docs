# Flux 3: Изображение в видео

Flux 3 Image to Video анимирует от 1 до 10 изображений с помощью FLUX 3. Каждое изображение становится кадром клипа: одно изображение открывает клип, два трансформируются из первого во второе, а большее количество распределяется по клипу или привязывается к выбранным вами моментам времени.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описывает, как сцена должна двигаться и звучать; промпт интерпретируется и расширяется перед генерацией. Должен содержать хотя бы один символ. | STRING | Да | Многострочный текст (по умолчанию: пусто) |
| `keyframes` | От 1 до 10 изображений в порядке воспроизведения. Каждое изображение должно быть не менее 256x256 пикселей. Расширяемый вход: подключайте изображения как `image_1`, `image_2` и так далее. | IMAGE | Да | от 1 до 10 изображений |
| `placement` | `"spread across the clip"` позволяет FLUX 3 разместить изображения: одно открывает клип, два становятся его началом и концом; `"at times"` привязывает каждое изображение к выбранной вами секунде. | DYNAMIC_COMBO | Да | `"spread across the clip"` (по умолчанию)<br>`"at times"` |
| `times` | По одному значению времени в секундах на каждое изображение, разделённые запятыми и возрастающие, например `"0, 2.5, 5"`. Отображается только когда `placement` имеет значение `"at times"`; для каждого ключевого изображения требуется одно значение времени. | STRING | Нет | Секунды, разделённые запятыми (по умолчанию: `"0"`) |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` выбирает его на основе промпта и входных данных. | COMBO | Да | `"auto"` (по умолчанию)<br>другие доступные соотношения сторон |
| `duration` | Длительность клипа в секундах. `"auto"` подбирает длительность под содержимое. | COMBO | Да | `"auto"` (по умолчанию)<br>другие доступные длительности |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"` (по умолчанию)<br>`"1080p"` |
| `generate_audio` | Генерировать синхронизированное аудио (окружающие звуки, речь, эффекты). При выключенном параметре создаётся видео без звуковой дорожки. | BOOLEAN | Да | true / false (по умолчанию: true) |
| `safety_tolerance` | Допуск модерации; 0 — самый строгий. Запросы, отправляющие изображения или видео, ограничиваются значением 2 независимо от того, какое значение вы зададите здесь. | INT | Да | от 0 до 4 (по умолчанию: 2, расширенная настройка) |
| `seed` | Сид, определяющий, нужно ли перезапускать узел; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. | INT | Да | от 0 до 4294967295 (по умолчанию: 42, control-after-generate) |

Примечание: `keyframes` должно содержать хотя бы одно изображение; узел выдаёт ошибку, если не подключено ни одного. Каждое ключевое изображение должно быть размером не менее 256x256 пикселей, а его соотношение сторон не может быть более экстремальным, чем 64:1.

Когда `placement` имеет значение `"spread across the clip"` и подключено 3 или более ключевых изображений, `duration` должно быть задано явным значением, а не `"auto"`; в противном случае узел выдаёт ошибку.

Когда `placement` имеет значение `"at times"`, параметр `times` должен содержать по одному значению времени в секундах для каждого изображения. Значения времени должны возрастать, не могут быть отрицательными, и последнее значение не может быть позже конца клипа (до 20 секунд, когда `duration` равно `"auto"`).

Поскольку этот узел отправляет изображения, `safety_tolerance` ограничен значением 2 независимо от заданного вами значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип, созданный из ключевых изображений с выбранным соотношением сторон, длительностью, разрешением и настройкой аудио. | VIDEO |
