# Flux 3: Изображение в видео

Flux 3 Image to Video анимирует от 1 до 10 изображений с помощью FLUX 3. Каждое изображение становится кадром клипа: одно изображение открывает его, два плавно переходят от первого ко второму, а большее количество распределяется по клипу или привязывается к выбранным вами моментам времени.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `placement` | "spread across the clip" позволяет FLUX 3 разместить изображения (одно открывает клип, два становятся его началом и концом); "at times" привязывает каждое изображение к выбранной вами секунде. | DYNAMIC_COMBO | Да | `"spread across the clip"` (по умолчанию)<br>`"at times"` |
| `prompt` | Как сцена должна двигаться и звучать; промпт интерпретируется и расширяется перед генерацией. Должен содержать хотя бы один символ. | STRING | Да | Многострочный текст (по умолчанию: пусто) |
| `aspect_ratio` | Соотношение сторон выходного видео. "auto" выбирает его на основе промпта и входных данных. | COMBO | Да | `"auto"` (по умолчанию)<br>другие доступные соотношения сторон |
| `duration` | Длина клипа в секундах. "auto" подбирает длину под содержимое. | COMBO | Да | `"auto"` (по умолчанию)<br>другие доступные длительности |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"` (по умолчанию)<br>`"1080p"` |
| `generate_audio` | Генерировать синхронизированный звук (окружающий, речь, эффекты). При выключении создаётся видео без звуковой дорожки. | BOOLEAN | Да | true / false (по умолчанию: true) |
| `safety_tolerance` | Допуск модерации, 0 — самый строгий. Запросы, отправляющие изображения или видео, ограничиваются значением 2 независимо от того, что вы здесь установите. | INT | Да | от 0 до 4 (по умолчанию: 2, расширенная настройка) |
| `seed` | Сид для определения, должен ли узел перезапуститься; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. | INT | Да | от 0 до 4294967295 (по умолчанию: 42, управление после генерации) |

### Входы spread across the clip

У этого варианта размещения нет дополнительных параметров.

### Входы at times

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `times` | Одно время в секундах на изображение, через запятую и по возрастанию, например "0, 2.5, 5". Появляется только когда `placement` имеет значение "at times"; для каждого изображения ключевого кадра требуется одно время. | STRING | Нет | Секунды через запятую (по умолчанию: "0") |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `keyframes` | Расширяемый слот: подключите от 1 до 10 изображений ключевых кадров в порядке воспроизведения, например `image_1`, `image_2` и так далее. Каждое изображение становится кадром клипа. Минимальный размер каждого — 256x256 пикселей; соотношение сторон не может быть экстремальнее 64:1. | IMAGE | Да | от 1 до 10 изображений |

Примечание: `keyframes` должен содержать хотя бы одно изображение; узел выдаёт ошибку, если ни одно не подключено. Каждое изображение ключевого кадра должно быть не меньше 256x256 пикселей, и его соотношение сторон не может быть экстремальнее 64:1.

Когда `placement` имеет значение "spread across the clip" и подключено 3 или более ключевых кадров, `duration` должно быть задано явным значением, а не "auto"; иначе узел выдаёт ошибку.

Когда `placement` имеет значение "at times", `times` должно задавать одно время в секундах на изображение. Времена должны возрастать, не могут быть отрицательными, а последнее время не может выходить за конец клипа (до 20 секунд, когда `duration` имеет значение "auto").

Поскольку этот узел отправляет изображения, `safety_tolerance` ограничивается значением 2 независимо от того, какое значение вы установите.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип, собранный из изображений ключевых кадров с выбранными соотношением сторон, длительностью, разрешением и настройкой звука. | VIDEO |
