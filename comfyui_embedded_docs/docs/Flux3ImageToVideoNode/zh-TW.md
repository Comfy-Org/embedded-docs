# Flux 3 圖像轉影片

Flux 3 Image to Video 使用 FLUX 3 將 1 到 10 張圖片動畫化。每張圖片都成為影片片段的一幀：一張圖片作為開場，兩張圖片則從第一張過渡到第二張，更多圖片則分散在整個片段中，或固定在您選擇的時間點。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 場景應如何移動和發聲；提示會在建構前被解讀和擴充。必須至少包含一個字元。 | STRING | 是 | 多行文字（預設：空白） |
| `關鍵畫格` | 依播放順序排列的 1 到 10 張圖片。每張至少 256x256 像素。可擴充輸入：依序連接圖片為 `image_1`、`image_2`，依此類推。 | IMAGE | 是 | 1 到 10 張圖片 |
| `放置方式` | `"spread across the clip"` 讓 FLUX 3 自動安排圖片（一張開場，兩張則分別作為片段的第一幀和最後一幀）；`"at times"` 則將每張圖片固定到您選擇的秒數。 | DYNAMIC_COMBO | 是 | `"spread across the clip"`（預設）<br>`"at times"` |
| `times` | 每張圖片對應一個以秒為單位的時間點，以逗號分隔且遞增，例如 `"0, 2.5, 5"`。僅在 `placement` 為 `"at times"` 時出現；每個關鍵影格圖片都需要一個時間點。 | STRING | 否 | 逗號分隔的秒數（預設：`"0"`） |
| `長寬比` | 輸出縱橫比。`"auto"` 會從提示和輸入中選擇一個。 | COMBO | 是 | `"auto"`（預設）<br>其他可用的縱橫比 |
| `時長` | 片段長度（秒）。`"auto"` 會根據內容調整長度。 | COMBO | 是 | `"auto"`（預設）<br>其他可用的長度 |
| `解析度` | 輸出解析度。 | COMBO | 是 | `"720p"`（預設）<br>`"1080p"` |
| `產生音訊` | 產生同步音訊（環境音、語音、特效）。關閉時產生的影片將不含音軌。 | BOOLEAN | 是 | true / false（預設：true） |
| `安全容忍度` | 內容審核容忍度，0 為最嚴格。凡傳送圖片或影片的請求，無論您在此設定什麼值，都會以 2 為上限。 | INT | 是 | 0 到 4（預設：2，進階設定） |
| `種子` | 用於決定節點是否應重新執行的種子；FLUX 3 會自行選取種子，因此無論此值為何，實際結果都不具有確定性。 | INT | 是 | 0 到 4294967295（預設：42，生成後控制） |

注意：`keyframes` 必須至少包含一張圖片；如果未連接任何圖片，節點將引發錯誤。每個關鍵影格圖片必須至少為 256x256 像素，且其縱橫比不得比 64:1 更極端。

當 `placement` 為 `"spread across the clip"` 且連接了 3 個或更多關鍵影格時，`duration` 必須設定為明確的值，而非 `"auto"`；否則節點將引發錯誤。

當 `placement` 為 `"at times"` 時，`times` 必須為每張圖片提供一個以秒為單位的時間點。時間點必須遞增、不得為負數，且最後一個時間點不得超過片段結尾（當 `duration` 為 `"auto"` 時，最長為 20 秒）。

由於此節點會傳送圖片，`safety_tolerance` 無論您設定何值，均以 2 為上限。
