# Flux 3 圖像轉影片

Flux 3 Image to Video 可將 1 到 10 張圖片搭配 FLUX 3 製作成動畫。每張圖片會成為片段中的一個畫面：一張圖片開啟片段，兩張圖片會從第一張變形到第二張，更多圖片則會分散於片段中，或固定在你選擇的時間點。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必需 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `放置方式` | "spread across the clip" 讓 FLUX 3 自行放置圖片（一張圖片開啟片段，兩張圖片成為片段的開頭與結尾）；"at times" 則會將每張圖片固定在你選擇的秒數。 | DYNAMIC_COMBO | 是 | `"spread across the clip"` (預設)<br>`"at times"` |
| `提示詞` | 場景應如何移動與發出聲音；提示詞會在生成前被解讀與擴展。必須至少包含一個字元。 | STRING | 是 | 多行文字 (預設: 空) |
| `長寬比` | 輸出長寬比。"auto" 會根據提示詞與輸入選擇一個長寬比。 | COMBO | 是 | `"auto"` (預設)<br>其他可用的長寬比 |
| `時長` | 片段長度（秒）。"auto" 會根據內容調整長度。 | COMBO | 是 | `"auto"` (預設)<br>其他可用的時長 |
| `解析度` | 輸出解析度。 | COMBO | 是 | `"720p"` (預設)<br>`"1080p"` |
| `產生音訊` | 產生同步音訊（環境音、語音、效果音）。關閉時會產生沒有音軌的影片。 | BOOLEAN | 是 | true / false (預設: true) |
| `安全容忍度` | 審核容忍度，0 為最嚴格。傳送圖片或影片的請求，無論此處設定為何，上限皆為 2。 | INT | 是 | 0 到 4 (預設: 2，進階設定) |

### at times 輸入

|-----------|-------------|-----------|----------|-------|
| `times` | 每張圖片對應一個時間（秒），以逗號分隔且遞增，例如 "0, 2.5, 5"。僅在 `placement` 為 "at times" 時出現；每個關鍵影格圖片都需要一個時間。 | STRING | 否 | 以逗號分隔的秒數 (預設: "0") |

### 參考輸入

| 參數 | 描述 | 資料類型 | 必需 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `關鍵畫格` | 可增長的插槽：依播放順序連接 1 到 10 張關鍵影格圖片，例如 `image_1`、`image_2` 等。每張圖片會成為片段中的一個畫面。每張圖片至少 256x256 像素；長寬比不得比 64:1 更極端。 | IMAGE | 是 | 1 到 10 張圖片 |

注意：`keyframes` 必須包含至少一張圖片；若未連接任何圖片，節點會引發錯誤。每張關鍵影格圖片必須至少為 256x256 像素，且其長寬比不得比 64:1 更極端。

當 `placement` 為 "spread across the clip" 且連接 3 張或更多關鍵影格時，`duration` 必須設為明確的值，不能是 "auto"；否則節點會引發錯誤。

當 `placement` 為 "at times" 時，`times` 必須為每張圖片提供一個時間（秒）。這些時間必須遞增、不能為負數，且最後一個時間不能超過片段的結尾（當 `duration` 為 "auto" 時，最長可達 20 秒）。

由於此節點會傳送圖片，無論你設定為何，`safety_tolerance` 的上限皆為 2。
