# تبدیل تصویر به ویدیو Flux 3

Flux 3 Image to Video، ۱ تا ۱۰ تصویر را با FLUX 3 به ویدیو تبدیل می‌کند. هر تصویر به یک فریم از کلیپ تبدیل می‌شود: یک تصویر آن را آغاز می‌کند، دو تصویر از اولی به دومی تغییر شکل می‌دهند، و تصاویر بیشتر در طول کلیپ پخش می‌شوند یا در زمان‌هایی که انتخاب می‌کنید تثبیت می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | نحوه حرکت و صدای صحنه؛ این دستور پیش از تولید تفسیر و بسط داده می‌شود. باید حداقل یک نویسه داشته باشد. | STRING | بله | متن چندخطی (پیش‌فرض: خالی) |
| `کی‌فریم‌ها` | 1 تا 10 تصویر، به ترتیب پخش. هر کدام حداقل 256×256 پیکسل. ورودی قابل گسترش: تصاویر را به صورت `image_1`، `image_2` و همین‌طور ادامه دهید. | IMAGE | بله | 1 تا 10 تصویر |
| `جای‌گذاری` | «"spread across the clip"» به FLUX 3 اجازه می‌دهد تصاویر را قرار دهد (یک تصویر کلیپ را آغاز می‌کند، دو تصویر شروع و پایان آن می‌شوند)؛ «"at times"» هر تصویر را به ثانیه‌ای که انتخاب می‌کنید می‌چسباند. | DYNAMIC_COMBO | بله | `"spread across the clip"` (پیش‌فرض)<br>`"at times"` |
| `times` | یک زمان بر حسب ثانیه برای هر تصویر، با کاما از هم جدا شده و صعودی، مثلاً «0, 2.5, 5». فقط وقتی ظاهر می‌شود که `placement` روی «"at times"» باشد؛ برای هر تصویر کلیدی یک زمان لازم است. | STRING | خیر | ثانیه‌های جدا شده با کاما (پیش‌فرض: «0») |
| `نسبت تصویر` | نسبت تصویر خروجی. «"auto"» یکی را از روی دستور و ورودی‌ها انتخاب می‌کند. | COMBO | بله | `"auto"` (پیش‌فرض)<br>سایر نسبت‌های تصویر موجود |
| `مدت زمان` | طول کلیپ بر حسب ثانیه. «"auto"» طول را متناسب با محتوا می‌کند. | COMBO | بله | `"auto"` (پیش‌فرض)<br>سایر مدت‌های موجود |
| `رزولوشن` | رزولوشن خروجی. | COMBO | بله | `"720p"` (پیش‌فرض)<br>`"1080p"` |
| `تولید صدا` | تولید صدای همگام (صدای محیط، گفتار، افکت‌ها). غیرفعال بودن، ویدیویی بدون نوار صدا تولید می‌کند. | BOOLEAN | بله | true / false (پیش‌فرض: true) |
| `درجه تحمل ایمنی` | تحمل نظارت محتوا، 0 سخت‌ترین حالت است. درخواست‌هایی که تصویر یا ویدیو ارسال می‌کنند، بدون توجه به این مقدار، حداکثر 2 هستند. | INT | بله | 0 تا 4 (پیش‌فرض: 2، تنظیم پیشرفته) |
| `بذر (Seed)` | دانه‌ای برای تعیین اینکه آیا گره دوباره اجرا شود؛ FLUX 3 دانه خودش را انتخاب می‌کند، بنابراین نتایج واقعی بدون توجه به این مقدار قطعی نیستند. | INT | بله | 0 تا 4294967295 (پیش‌فرض: 42، control-after-generate) |

توجه: `keyframes` باید حداقل یک تصویر داشته باشد؛ اگر هیچ تصویری متصل نباشد، گره خطا می‌دهد. هر تصویر کلیدی باید حداقل 256×256 پیکسل باشد و نسبت تصویر آن نمی‌تواند از 64:1 شدیدتر باشد.

وقتی `placement` روی «"spread across the clip"» باشد و 3 یا بیشتر فریم کلیدی متصل شده باشد، `duration` باید یک مقدار صریح باشد، نه «"auto"»؛ در غیر این صورت گره خطا می‌دهد.

وقتی `placement` روی «"at times"» باشد، `times` باید برای هر تصویر یک زمان بر حسب ثانیه ارائه دهد. زمان‌ها باید صعودی باشند، نمی‌توانند منفی باشند و آخرین زمان نمی‌تواند از پایان کلیپ گذشته باشد (حداکثر 20 ثانیه وقتی `duration` روی «"auto"» است).

از آنجا که این گره تصاویر ارسال می‌کند، `safety_tolerance` بدون توجه به مقداری که تنظیم کرده‌اید در 2 محدود می‌شود.
