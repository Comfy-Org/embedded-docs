# Flux3ImageToVideoNode

تقوم أداة Flux 3 Image to Video بتحريك من 1 إلى 10 صور باستخدام FLUX 3. تصبح كل صورة إطارًا من المقطع: صورة واحدة تفتحه، وصورتان تتحولان من الأولى إلى الثانية، والمزيد يتم توزيعه عبره أو تثبيته في أوقات تختارها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | كيف ينبغي أن تتحرك المشهد وتُصدر صوتًا؛ يتم تفسير المطالبة وتوسيعها قبل التوليد. يجب أن تحتوي على حرف واحد على الأقل. | STRING | نعم | نص متعدد الأسطر (الافتراضي: فارغ) |
| `keyframes` | من 1 إلى 10 صور، بترتيب التشغيل. الحد الأدنى 256×256 بكسل لكل صورة. كل إطار مفتاحي يصبح نقطة في المقطع. | IMAGE | نعم | من 1 إلى 10 صور |
| `placement` | وضع 'spread across the clip' يتيح لـ FLUX 3 وضع الصور (صورة تفتح المقطع، صورتان تصبحان بدايته ونهايته)؛ بينما 'at times' يثبّت كل صورة عند ثانية تختارها. | STRING | نعم | `"spread across the clip"` (الافتراضي)<br>`"at times"` |
| `times` | وقت واحد بالثواني لكل صورة، مفصول بفواصل وبترتيب تصاعدي، مثل '0, 2.5, 5'. مطلوب عندما يكون `placement` هو `"at times"`. | STRING | لا | ثوانٍ مفصولة بفواصل (الافتراضي: "0") |
| `aspect_ratio` | نسبة الأبعاد للمخرجات. يختار 'auto' واحدًا من المطالبة والمدخلات. | STRING | نعم | `"auto"` (الافتراضي)<br>بالإضافة إلى خيارات أخرى متاحة |
| `duration` | طول المقطع بالثواني. 'auto' يضبط الطول وفقًا للمحتوى. | STRING | نعم | `"auto"` (الافتراضي)<br>بالإضافة إلى خيارات أخرى متاحة |
| `resolution` | دقة المخرجات. | STRING | نعم | `"720p"` (الافتراضي)<br>`"1080p"` |
| `generate_audio` | توليد صوت متزامن (محيط، كلام، مؤثرات). يؤدي إيقاف التشغيل إلى إنتاج فيديو بدون مسار صوتي. | BOOLEAN | نعم | true / false (الافتراضي: true) |
| `safety_tolerance` | سماحية الأمان، 0 هي الأكثر صرامة. الطلبات التي ترسل صورًا أو فيديو تكون محدودة عند 2 مهما كان ما تضبطه هنا. | INT | نعم | 0 إلى 4 (الافتراضي: 2، إعداد متقدم) |
| `seed` | البذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ يختار FLUX 3 بذرته الخاصة، لذا تكون النتائج الفعلية غير حتمية بغض النظر عن هذه القيمة. | INT | نعم | 0 إلى 4294967295 (الافتراضي: 42، مع تحكم بعد التوليد) |

ملاحظة: `keyframes` مطلوب — ترفع العقدة خطأً إذا لم يتم توصيل صورة إطار مفتاحي. عندما يكون `placement` هو `"spread across the clip"` ويتم توفير 3 صور أو أكثر، يجب ضبط `duration` على قيمة صريحة (وليس `"auto"`)؛ وإلا ترفع العقدة خطأً. عندما يكون `placement` هو `"at times"`، يجب أن يوفر `times` وقتًا واحدًا بالثواني لكل صورة، بترتيب تصاعدي. الطلبات التي ترسل صورًا تكون محدودة عند سماحية أمان تبلغ 2 بغض النظر عن القيمة المضبوطة.
