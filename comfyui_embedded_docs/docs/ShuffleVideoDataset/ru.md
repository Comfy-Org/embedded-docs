# Перемешать Список Видео

Этот узел принимает список видео и произвольно переупорядочивает их. Для обеспечения воспроизводимой перетасовки используется случайное зерно (seed), поэтому одно и то же зерно всегда даёт одинаковый порядок на выходе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Список видео для перетасовки. | VIDEO | Yes | List of video inputs |
| `seed` | Случайное зерно для перетасовки (по умолчанию: 0). | INT | No | 0 to 18446744073709551615 |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Перетасованный список видео в случайном порядке. | VIDEO |
