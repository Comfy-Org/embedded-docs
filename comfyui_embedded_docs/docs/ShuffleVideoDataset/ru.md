# Перемешать Список Видео

Этот узел принимает список видео и произвольно переупорядочивает их. Для воспроизводимости перемешивания используется случайное зерно, поэтому одно и то же зерно всегда дает одинаковый порядок вывода.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Список видео для перетасовки. | VIDEO | Yes | List of video inputs |
| `seed` | Случайное зерно для перетасовки (по умолчанию: 0). | INT | No | 0 to 18446744073709551615 |
Примечание: значение зерна перед использованием сокращается по модулю 4294967295 (2^32 - 1). В результате зерна, отличающиеся на кратное 4294967295, дают одинаковый порядок вывода.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Перетасованный список видео в случайном порядке. | VIDEO |
