# 隨機排序影片清單

此節點接受一個影片列表，並隨機重新排序。它使用隨機種子使洗牌可重現，因此相同的種子總是產生相同的輸出順序。

## 輸入
| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 要進行隨機排序的影片列表。 | VIDEO | 是 | List of video inputs |
| `隨機種子` | 用於隨機排序的種子（預設值：0）。 | INT | 否 | 0 to 18446744073709551615 |
注意：種子值在使用前會按 4294967295（2^32 - 1）取模。因此，相差 4294967295 整數倍的種子會產生相同的輸出順序。
