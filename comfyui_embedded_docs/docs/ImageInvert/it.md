# ImageInvert

Il nodo `ImageInvert` è progettato per invertire i colori di un'immagine, trasformando efficacemente il valore di colore di ogni pixel nel suo colore complementare sulla ruota dei colori. Questa operazione è utile per creare immagini negative o per effetti visivi che richiedono l'inversione dei colori.

## Input

| Parametro | Descrizione | Tipo di dati |
| --- | --- | --- |
| `image` | Il parametro `image` rappresenta l'immagine di input da invertire. È fondamentale per specificare l'immagine di destinazione i cui colori devono essere invertiti, influenzando l'esecuzione del nodo e il risultato visivo del processo di inversione. | `IMAGE` |

## Output

| Parametro | Descrizione | Tipo di dati |
| --- | --- | --- |
| `image` | L'output è una versione invertita dell'immagine di input, con il valore di colore di ogni pixel trasformato nel suo colore complementare. | `IMAGE` |
