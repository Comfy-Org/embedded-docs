# Кондиционирование PixToPix

Узел InstructPixToPixConditioning подготавливает данные conditioning для редактирования изображений InstructPix2Pix, объединяя положительные и отрицательные текстовые подсказки с данными изображения. Он обрабатывает входные изображения через кодировщик VAE для создания скрытых представлений и присоединяет эти латентные представления к положительным и отрицательным данным conditioning. Узел автоматически обрабатывает размеры изображения, обрезая их до значений, кратных 8 пикселям, для совместимости с процессом кодирования VAE.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительные данные conditioning, содержащие текстовые подсказки и настройки для желаемых характеристик изображения | CONDITIONING | Да | - |
| `отрицательный` | Отрицательные данные conditioning, содержащие текстовые подсказки и настройки для нежелательных характеристик изображения | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входных изображений в латентные представления | VAE | Да | - |
| `пиксели` | Входное изображение для обработки и кодирования в латентное пространство | IMAGE | Да | - |

**Примечание:** Размеры входного изображения автоматически выравниваются с помощью центральной обрезки до значений, кратных 8 пикселям по ширине и высоте, чтобы обеспечить совместимость с процессом кодирования VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Положительные данные conditioning с прикреплённым латентным представлением изображения | CONDITIONING |
| `отрицательный` | Отрицательные данные conditioning с прикреплённым латентным представлением изображения | CONDITIONING |
| `латентный` | Пустой латентный тензор с теми же размерами, что и закодированное изображение | LATENT |
