# Кондиционирование PixToPix

Узел InstructPixToPixConditioning подготавливает данные conditioning для редактирования изображений InstructPix2Pix, объединяя положительные и отрицательные текстовые промпты с данными изображения. Он кодирует входное изображение через VAE в латентное представление и прикрепляет этот латент к положительному и отрицательному conditioning, а также возвращает соответствующий пустой латент. Размеры изображения автоматически обрезаются до значений, кратных 8 пикселям, чтобы VAE мог их обработать.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Данные положительного conditioning, содержащие текстовые промпты и настройки для желаемых характеристик изображения | CONDITIONING | Да | - |
| `отрицательный` | Данные отрицательного conditioning, содержащие текстовые промпты и настройки для нежелательных характеристик изображения | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входных изображений в латентные представления | VAE | Да | - |
| `пиксели` | Входное изображение для обработки и кодирования в латентное пространство | IMAGE | Да | - |

**Примечание:** Размеры входного изображения автоматически корректируются путём центральной обрезки до значений, кратных 8 пикселям, как по ширине, так и по высоте, чтобы обеспечить совместимость с процессом кодирования VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Данные положительного conditioning с прикреплённым латентом закодированного изображения как `concat_latent_image` | CONDITIONING |
| `negative` | Данные отрицательного conditioning с прикреплённым латентом закодированного изображения как `concat_latent_image` | CONDITIONING |
| `latent` | Латентный тензор из нулей с теми же размерами, что и закодированное изображение | LATENT |
