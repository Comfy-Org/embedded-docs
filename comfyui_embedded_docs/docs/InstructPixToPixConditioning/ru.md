# Кондиционирование PixToPix

Узел InstructPixToPixConditioning подготавливает данные conditioning для редактирования изображений InstructPix2Pix, объединяя входное изображение с положительным и отрицательным conditioning из текстовых подсказок. Он кодирует изображение с помощью VAE в скрытое представление, присоединяет это скрытое представление к обоим наборам conditioning и создает заполненное нулями скрытое представление с соответствующими размерами. Если ширина или высота изображения не кратна 8 пикселям, изображение автоматически обрезается перед кодированием.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные данные conditioning, содержащие текстовые подсказки и настройки для желаемых характеристик изображения. | CONDITIONING | Да | - |
| `negative` | Отрицательные данные conditioning, содержащие текстовые подсказки и настройки для нежелательных характеристик изображения. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения в скрытое представление. | VAE | Да | - |
| `pixels` | Входное изображение для обработки и кодирования в скрытое пространство. | IMAGE | Да | - |

**Примечание:** Входное изображение автоматически обрезается до кратного 8 пикселям по ширине и высоте с округлением вниз, чтобы обеспечить совместимость с процессом кодирования VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительные данные conditioning с присоединенным скрытым представлением закодированного изображения. | CONDITIONING |
| `negative` | Отрицательные данные conditioning с присоединенным скрытым представлением закодированного изображения. | CONDITIONING |
| `latent` | Заполненный нулями скрытый тензор с теми же размерами, что и закодированное изображение. | LATENT |
