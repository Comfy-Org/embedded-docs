# InstructPixToPixConditioning

הצומת InstructPixToPixConditioning מכין נתוני קונדישינינג לעריכת תמונות InstructPix2Pix על ידי שילוב הנחיות טקסט חיוביות ושליליות עם נתוני תמונה. הוא מקודד את תמונת הקלט דרך VAE לייצוג לטנטי ומצרף את הלטנט הזה גם לקונדישינינג החיובי וגם לקונדישינינג השלילי, ובמקביל מחזיר לטנט ריק תואם. ממדי התמונה נחתכים אוטומטית לכפולות של 8 פיקסלים כדי ש-VAE יוכל לעבד אותם.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | נתוני קונדישינינג חיוביים המכילים הנחיות טקסט והגדרות למאפיינים הרצויים של התמונה | CONDITIONING | כן | - |
| `negative` | נתוני קונדישינינג שליליים המכילים הנחיות טקסט והגדרות למאפיינים הלא רצויים של התמונה | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות קלט לייצוגים לטנטיים | VAE | כן | - |
| `pixels` | תמונת הקלט שיש לעבד ולקודד למרחב לטנטי | IMAGE | כן | - |

**הערה:** ממדי תמונת הקלט מותאמים אוטומטית באמצעות חיתוך ממרכז לכפולות של 8 פיקסלים הן ברוחב והן בגובה כדי להבטיח תאימות לתהליך הקידוד של VAE.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | נתוני קונדישינינג חיוביים עם הלטנט המקודד של התמונה מצורף בתור `concat_latent_image` | CONDITIONING |
| `negative` | נתוני קונדישינינג שליליים עם הלטנט המקודד של התמונה מצורף בתור `concat_latent_image` | CONDITIONING |
| `latent` | טנזור לטנטי של אפסים עם אותם ממדים כמו התמונה המקודדת | LATENT |
