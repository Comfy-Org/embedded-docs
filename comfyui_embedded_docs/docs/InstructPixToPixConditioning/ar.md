# تكوين توجيهي للبيكسل إلى بيكسل

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | بيانات تكييف إيجابية تحتوي على موجهات نصية وإعدادات لخصائص الصورة المرغوبة. | CONDITIONING | نعم | - |
| `negative` | بيانات تكييف سلبية تحتوي على موجهات نصية وإعدادات لخصائص الصورة غير المرغوبة. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير صورة الإدخال إلى تمثيل كامن. | VAE | نعم | - |
| `pixels` | صورة الإدخال التي سيتم معالجتها وتشفيرها إلى الفضاء الكامن. | IMAGE | نعم | - |

**ملاحظة:** يتم اقتصاص صورة الإدخال تلقائيًا إلى مضاعف لـ 8 بكسل في كل من العرض والارتفاع، مع التقريب إلى الأسفل، لضمان التوافق مع عملية تشفير VAE.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | بيانات تكييف إيجابية مع التمثيل الكامن للصورة المشفرة المرفق. | CONDITIONING |
| `negative` | بيانات تكييف سلبية مع التمثيل الكامن للصورة المشفرة المرفق. | CONDITIONING |
| `latent` | موتر كامن مملوء بالأصفار بنفس أبعاد الصورة المشفرة. | LATENT |
