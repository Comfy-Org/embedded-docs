# PixToPix条件付け

InstructPixToPixConditioning ノードは、入力画像とポジティブ／ネガティブのテキストプロンプト条件付けを組み合わせて、InstructPix2Pix 画像編集用の条件付けデータを準備します。画像を VAE でエンコードして潜在表現に変換し、その潜在表現を両方の条件付けセットに付与し、同じ寸法のゼロ埋め潜在表現を作成します。画像の幅または高さが 8 ピクセルの倍数でない場合、エンコード前に画像が自動的にクロップされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 望ましい画像特性のためのテキストプロンプトと設定を含むポジティブ条件付けデータです。 | CONDITIONING | はい | - |
| `negative` | 望ましくない画像特性のためのテキストプロンプトと設定を含むネガティブ条件付けデータです。 | CONDITIONING | はい | - |
| `vae` | 入力画像を潜在表現にエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `pixels` | 処理され、潜在空間にエンコードされる入力画像です。 | IMAGE | はい | - |

**注:** 入力画像は、VAE エンコード処理との互換性を確保するため、幅と高さの両方が 8 ピクセルの倍数になるように、切り捨てて自動的にクロップされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | エンコードされた画像の潜在表現が付加されたポジティブ条件付けデータです。 | CONDITIONING |
| `negative` | エンコードされた画像の潜在表現が付加されたネガティブ条件付けデータです。 | CONDITIONING |
| `latent` | エンコードされた画像と同じ寸法を持つゼロ埋めの潜在テンソルです。 | LATENT |
