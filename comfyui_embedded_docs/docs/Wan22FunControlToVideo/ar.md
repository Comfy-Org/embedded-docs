# Wan22FunControlToVideo

تُعدّ عقدة `Wan22FunControlToVideo` بيانات التوجيه (conditioning) ومُوتّرًا كامنًا (latent tensor) فارغًا لتوليد الفيديو باستخدام نموذج Wan للفيديو. تقوم بتشفير الصور المرجعية الاختيارية وفيديوهات التحكم إلى الفضاء الكامن، وتُرفقها بالتوجيه الإيجابي والسلبي، وتنشئ مُوتّرًا كامنًا مملوءًا بالأصفار بالأبعاد المكانية والزمانية الصحيحة للفيديو المطلوب.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخلات التوجيه الإيجابية لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | مدخلات التوجيه السلبية لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير الصور إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم_الدفعة` | عدد تسلسلات الفيديو المطلوب توليدها (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `صورة_مرجعية` | صورة مرجعية اختيارية توفر توجيهًا بصريًا للتوليد | IMAGE | لا | - |
| `فيديو_تحكم` | فيديو تحكم اختياري يوجّه عملية التوليد | IMAGE | لا | - |

**ملاحظة:** تتم معالجة معامل `length` بخطوات من 4 إطارات، وتقوم العقدة تلقائيًا بتطبيق القياس الزمني عند بناء الفضاء الكامن. عندما يتم توفير `ref_image`، يتم تشفير أول إطار فقط وإرفاقه بالتوجيه كمرجع كامن. عندما يتم توفير `control_video`، يتم قصّه إلى عدد إطارات `length`، ثم تشفيره ووضعه في اللاتنت المتسلسل (concat latent) المستخدم في التوجيه. يتم الإشارة إلى معامل `start_image` في منطق التنفيذ لكنه غير ظاهر في مخطط مدخلات العقدة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | توجيه إيجابي مع بيانات كامنة خاصة بالفيديو مضافة، بما في ذلك اللاتنت المتسلسل، والقناع، والمراجع الكامنة الاختيارية | CONDITIONING |
| `سلبي` | توجيه سلبي مع بيانات كامنة خاصة بالفيديو مضافة، بما في ذلك اللاتنت المتسلسل، والقناع، والمراجع الكامنة الاختيارية | CONDITIONING |
| `كامن` | مُوتّر كامن فارغ مُجهّز لتوليد الفيديو، بحجم يعتمد على حجم الدفعة، والقنوات الكامنة، والطول، والارتفاع، والعرض | LATENT |
