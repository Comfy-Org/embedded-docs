# Wan22FunControlToVideo

گره Wan22FunControlToVideo با استفاده از معماری مدل ویدیویی Wan، بازنمایی‌های شرطی‌سازی و لاتنت را برای تولید ویدیو آماده می‌کند. این گره ورودی‌های شرطی‌سازی مثبت و منفی را به همراه تصاویر مرجع اختیاری و ویدیوهای کنترلی پردازش می‌کند تا بازنمایی‌های فضای لاتنت لازم برای سنتز ویدیو را ایجاد کند. گره مقیاس‌گذاری مکانی و ابعاد زمانی را برای تولید داده‌های شرطی‌سازی مناسب برای مدل‌های ویدیویی مدیریت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر به فضای لاتنت | VAE | بله | - |
| `width` | عرض ویدیو خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیو خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های دنباله ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد دنباله‌های ویدیویی که تولید می‌شود (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `ref_image` | تصویر مرجع اختیاری برای ارائه راهنمایی بصری | IMAGE | خیر | - |
| `control_video` | ویدیوی کنترلی اختیاری برای هدایت فرآیند تولید | IMAGE | خیر | - |

**نکته:** پارامتر `length` در بلوک‌های ۴ فریمی پردازش می‌شود و گره به‌طور خودکار مقیاس‌گذاری زمانی فضای لاتنت را مدیریت می‌کند. هنگامی که `ref_image` ارائه شود، از طریق لاتنت‌های مرجع بر شرطی‌سازی تأثیر می‌گذارد. هنگامی که `control_video` ارائه شود، مستقیماً بر بازنمایی لاتنت الحاقی مورد استفاده در شرطی‌سازی اثر می‌گذارد. پارامتر `start_image` به‌عنوان ورودی در طرح این گره در معرض دید قرار نگرفته، اما در منطق اجرا به آن ارجاع داده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده با داده‌های لاتنت مخصوص ویدیو شامل لاتنت الحاقی، ماسک و لاتنت‌های مرجع اختیاری | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده با داده‌های لاتنت مخصوص ویدیو شامل لاتنت الحاقی، ماسک و لاتنت‌های مرجع اختیاری | CONDITIONING |
| `latent` | تانسور لاتنت خالی با ابعاد مناسب برای تولید ویدیو بر اساس اندازه دسته، کانال‌های لاتنت و مقیاس‌گذاری مکانی/زمانی | LATENT |
