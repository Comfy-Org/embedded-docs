# Wan22FunControlToVideo

Wan22FunControlToVideoノードは、Wanビデオモデルアーキテクチャを使用して、ビデオ生成用のコンディショニングと潜在表現を準備します。このノードは、ポジティブおよびネガティブのコンディショニング入力と、オプションの参照画像および制御ビデオを処理して、ビデオ合成に必要な潜在空間表現を作成します。ノードは空間スケーリングと時間的次元を処理し、ビデオモデルに適したコンディショニングデータを生成します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |

| `negative` | ビデオ生成をガイドするためのネガティブコンディショニング入力 | CONDITIONING | はい | - |

| `height` | 出力ビデオの高さ（ピクセル）（デフォルト：480、ステップ：16） | INT | はい | 16～MAX_RESOLUTION |
