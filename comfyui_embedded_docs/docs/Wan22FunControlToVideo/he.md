# Wan22FunControlToVideo

הצומת Wan22FunControlToVideo מכין נתוני קונדישנינג וטנזור latent ריק ליצירת וידאו עם מודל הווידאו Wan. הוא מקודד תמונות עזר ווידאו בקרה אופציונליים למרחב latent, מצרף אותם לקונדישנינג החיובי והשלילי, ויוצר טנזור latent מלא באפסים עם הממדים המרחביים והזמניים הנכונים עבור הווידאו המבוקש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט קונדישנינג חיובי להנחיית יצירת הווידאו | CONDITIONING | כן | - |
| `negative` | קלט קונדישנינג שלילי להנחיית יצירת הווידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות למרחב latent | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר רצפי הווידאו ליצירה (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `ref_image` | תמונת עזר אופציונלית המספקת הנחיה חזותית ליצירה | IMAGE | לא | - |
| `control_video` | וידאו בקרה אופציונלי המנחה את תהליך היצירה | IMAGE | לא | - |

**הערה:** הפרמטר `length` מעובד בצעדים של 4 פריימים, והצומת מחיל אוטומטית שינוי קנה מידה זמני בעת בניית מרחב ה-latent. כאשר מסופק `ref_image`, רק הפריים הראשון שלו מקודד (משונה ל-`width` x `height`) ומצורף לקונדישנינג כ-latent-ים של עזר. כאשר מסופק `control_video`, הוא נחתך ל-`length` פריימים, משונה, מקודד, ומוכנס ל-concat latent המשמש את הקונדישנינג. ה-latent המאוחד משוכפל לאורך ממד הערוצים, ופריסת הערוצים שלו תלויה במספר ערוצי ה-latent של ה-VAE (48 ערוצים משתמשים בפורמט Wan 2.2, אחרת בפורמט Wan 2.1). הפרמטר `start_image` מוזכר בלוגיקת הביצוע אך אינו נחשף בסכמת הקלט של הצומת, ולכן לא ניתן להגדיר אותו מממשק הצומת.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | קונדישנינג חיובי עם נתוני latent ייעודיים לווידאו, כולל concat latent, מסכה, ו-latent-ים של עזר אופציונליים | CONDITIONING |
| `negative` | קונדישנינג שלילי עם נתוני latent ייעודיים לווידאו, כולל concat latent, מסכה, ו-latent-ים של עזר אופציונליים | CONDITIONING |
| `latent` | טנזור latent ריק שהוכן ליצירת וידאו, בגודל המתאים לגודל האצווה, ערוצי latent, אורך, גובה ורוחב | LATENT |
