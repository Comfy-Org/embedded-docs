# Wan22FunControlToVideo

Узел Wan22FunControlToVideo подготавливает данные кондиционирования и пустой латентный тензор для генерации видео с помощью видеомодели Wan. Он кодирует опциональные эталонные изображения и управляющие видео в латентное пространство, присоединяет их к позитивному и негативному кондиционированию и создаёт заполненный нулями латентный тензор с правильной пространственной и временной размерностью для запрошенного видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видеопоследовательностей для генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `ref_image` | Опциональное эталонное изображение, служащее визуальным ориентиром для генерации | IMAGE | Нет | - |
| `control_video` | Опциональное управляющее видео, направляющее процесс генерации | IMAGE | Нет | - |

**Примечание:** Параметр `length` обрабатывается с шагом 4 кадра, а узел автоматически применяет временное масштабирование при построении латентного пространства. Когда указано `ref_image`, кодируется только его первый кадр, который присоединяется к кондиционированию в качестве эталонных латентных тензоров. Когда указано `control_video`, оно обрезается до `length` кадров, кодируется и помещается в конкатенированный латентный тензор, используемый кондиционированием. Параметр `start_image` упоминается в логике выполнения, но не представлен в схеме входных данных узла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование с добавленными видео-специфическими латентными данными, включая конкатенированный латентный тензор, маску и опциональные эталонные латентные тензоры | CONDITIONING |
| `negative` | Негативное кондиционирование с добавленными видео-специфическими латентными данными, включая конкатенированный латентный тензор, маску и опциональные эталонные латентные тензоры | CONDITIONING |
| `latent` | Пустой латентный тензор, подготовленный для генерации видео, размер которого соответствует размеру пакета, количеству латентных каналов, длине, высоте и ширине | LATENT |
