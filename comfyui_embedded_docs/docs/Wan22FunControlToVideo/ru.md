# Wan22FunControlToVideo

Узел Wan22FunControlToVideo подготавливает представления кондиционирования и латентные представления для генерации видео с использованием архитектуры видео-модели Wan. Он обрабатывает положительные и отрицательные входные кондиционирования, а также необязательные эталонные изображения и управляющие видео для создания необходимых представлений в латентном пространстве для синтеза видео. Узел выполняет пространственное масштабирование и управляет временными размерностями для генерации соответствующих данных кондиционирования для видео-моделей.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное входное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `negative` | Отрицательное входное кондиционирование для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видео-последовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео-последовательностей для генерации (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `ref_image` | Необязательное референсное изображение для визуального управления | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео для управления процессом генерации | IMAGE | Нет | - |

**Примечание:** Параметр `length` обрабатывается порциями по 4 кадра, и узел автоматически выполняет временное масштабирование для латентного пространства. Когда `ref_image` предоставлен, он влияет на кондиционирование через референсные латентные представления. Когда `control_video` предоставлен, он напрямую влияет на concat-латентное представление, используемое в кондиционировании. Параметр `start_image` не представлен как вход в схеме этого узла, но упоминается в логике выполнения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование с видео-специфичными латентными данными, включая concat-латент, маску и необязательные референсные латентные представления | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование с видео-специфичными латентными данными, включая concat-латент, маску и необязательные референсные латентные представления | CONDITIONING |
| `latent` | Пустой латентный тензор с соответствующими размерами для генерации видео на основе размера пакета, латентных каналов и пространственно-временного масштабирования | LATENT |
