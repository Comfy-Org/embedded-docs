# Wan22FunControlToVideo

Узел Wan22FunControlToVideo подготавливает данные кондиционирования и пустой латентный тензор для генерации видео с помощью видеомодели Wan. Он кодирует необязательные эталонные изображения и управляющие видео в латентное пространство, присоединяет их к положительному и отрицательному кондиционированию и создаёт заполненный нулями латентный тензор с корректными пространственными и временными размерами для запрошенного видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Вход положительного кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `negative` | Вход отрицательного кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `batch_size` | Количество генерируемых видеопоследовательностей (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `ref_image` | Необязательное эталонное изображение, которое обеспечивает визуальное управление для генерации | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое направляет процесс генерации | IMAGE | Нет | - |

**Примечание:** Параметр `length` обрабатывается с шагом 4 кадра, и узел автоматически применяет временное масштабирование при построении латентного пространства. Когда передан `ref_image`, кодируется только его первый кадр (масштабируется до `width` x `height`) и прикрепляется к кондиционированию как эталонные латенты. Когда передан `control_video`, он обрезается до `length` кадров, масштабируется, кодируется и помещается в concat-латент, используемый кондиционированием. Конкатенированный латент дублируется по размерности каналов, и его раскладка каналов зависит от количества латентных каналов VAE (48 каналов использует формат Wan 2.2, иначе формат Wan 2.1). Параметр `start_image` упоминается в логике выполнения, но не представлен во входной схеме узла, поэтому его нельзя задать через интерфейс узла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование с добавленными видеоспецифичными латентными данными, включая concat-латент, маску и необязательные эталонные латенты | CONDITIONING |
| `negative` | Отрицательное кондиционирование с добавленными видеоспецифичными латентными данными, включая concat-латент, маску и необязательные эталонные латенты | CONDITIONING |
| `latent` | Пустой латентный тензор, подготовленный для генерации видео, размер которого соответствует размеру пакета, латентным каналам, длине, высоте и ширине | LATENT |
