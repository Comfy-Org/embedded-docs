# Canny

從照片中擷取所有邊緣線條，就像用筆描繪照片一樣，勾勒出物體的輪廓與細節邊界。

## 工作原理

想像你是一位藝術家，需要用筆描繪一張照片。Canny 節點就像一位聰明的助手，協助你決定在哪裡畫線（邊緣），以及哪裡不畫。

這個過程就像一項篩選工作：

- **高閾值**是「必須畫線標準」：只有非常明顯且清晰的輪廓線才會被畫出，例如人物的臉部輪廓與建築框架
- **低閾值**是「絕對不畫線標準」：過於微弱的邊緣會被忽略，以避免畫出雜訊與無意義的線條
- **中間區域**：介於兩個標準之間的邊緣，如果連接到「必須畫線」的邊緣，就會一起被畫出；但如果它是孤立的，則不會被畫出

最終輸出是一張黑白影像，其中白色部分是被偵測到的邊緣線條，黑色部分則是沒有邊緣的區域。

**常見問題：**

- 邊緣斷裂：嘗試降低高閾值
- 雜訊過多：提高低閾值
- 遺漏重要細節：降低低閾值
- 邊緣過於粗糙：檢查輸入影像品質與解析度
