# ایزی‌کش

```markdown
گره EasyCache یک سیستم کش بومی برای مدل‌ها پیاده‌سازی می‌کند که با استفاده مجدد از مراحل محاسبه‌شدهٔ پیشین در طول فرآیند نمونه‌برداری، عملکرد را بهبود می‌بخشد. این گره قابلیت EasyCache را با آستانه‌های قابل تنظیم برای زمان شروع و پایان استفاده از کش در طول زمان‌بندی نمونه‌برداری به مدل اضافه می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که EasyCache به آن اضافه می‌شود. | MODEL | بله | - |
| `reuse_threshold` | آستانه استفاده مجدد از مراحل کش‌شده (پیش‌فرض: 0.2). | FLOAT | بله | 0.0 - 3.0 |
| `start_percent` | مرحله نسبی نمونه‌برداری برای شروع استفاده از EasyCache (پیش‌فرض: 0.15). | FLOAT | بله | 0.0 - 1.0 |
| `end_percent` | مرحله نسبی نمونه‌برداری برای پایان استفاده از EasyCache (پیش‌فرض: 0.95). | FLOAT | بله | 0.0 - 1.0 |
| `verbose` | آیا اطلاعات دقیق (verbose) ثبت شود (پیش‌فرض: False). | BOOLEAN | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model` | مدل همراه با EasyCache. | MODEL |
```
