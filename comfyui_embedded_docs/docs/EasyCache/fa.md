# ایزی‌کش

گره EasyCache یک سیستم کش بومی را به یک مدل انتشار اضافه می‌کند که با استفاده مجدد از نتایج گام‌های محاسبه‌شده قبلی به‌جای محاسبه دوباره هر گام، فرآیند نمونه‌گیری را سرعت می‌بخشد. این گره فقط بین نقطه شروع و پایان قابل‌تنظیم در فرآیند نمونه‌گیری فعال می‌شود و گام‌ها را زمانی رد می‌کند که تغییر تخمینی خروجی زیر آستانه تعیین‌شده توسط کاربر باقی بماند. این یک گره آزمایشی است که برای استفاده در اشکال‌زدایی پیشرفته در نظر گرفته شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که باید EasyCache به آن افزوده شود. | MODEL | بله | - |
| `آستانه استفاده مجدد` | آستانه برای استفاده مجدد از گام‌های کش‌شده (پیش‌فرض: 0.2). | FLOAT | بله | 0.0 - 3.0 |
| `درصد شروع` | گام نمونه‌گیری نسبی برای شروع استفاده از EasyCache (پیش‌فرض: 0.15). | FLOAT | بله | 0.0 - 1.0 |
| `درصد پایان` | گام نمونه‌گیری نسبی برای پایان استفاده از EasyCache (پیش‌فرض: 0.95). | FLOAT | بله | 0.0 - 1.0 |
| `گزارش‌گیری کامل` | این‌که اطلاعات مبسوط ثبت شود یا نه (پیش‌فرض: False). | BOOLEAN | بله | - |
