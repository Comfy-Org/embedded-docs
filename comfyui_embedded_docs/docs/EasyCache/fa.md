# ایزی‌کش

گره EasyCache یک سیستم کش بومی به مدل انتشار اضافه می‌کند که نمونه‌برداری را با استفاده مجدد از نتایج گام‌های محاسبه‌شدهٔ قبلی به جای محاسبهٔ مجدد هر گام، سرعت می‌بخشد. این گره فقط بین نقطهٔ شروع و پایان قابل‌تنظیم فرآیند نمونه‌برداری فعال می‌شود و وقتی تغییر برآوردی خروجی زیر آستانهٔ تعریف‌شده توسط کاربر باقی بماند، از گام‌ها صرف‌نظر می‌کند. این یک گرهٔ آزمایشی است که برای استفاده در اشکال‌زدایی پیشرفته در نظر گرفته شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که EasyCache به آن اضافه می‌شود. | MODEL | بله | - |
| `آستانه استفاده مجدد` | آستانهٔ استفاده مجدد از گام‌های کش‌شده (پیش‌فرض: 0.2). | FLOAT | بله | 0.0 - 3.0 |
| `درصد شروع` | گام نسبی نمونه‌برداری برای شروع استفاده از EasyCache (پیش‌فرض: 0.15). | FLOAT | بله | 0.0 - 1.0 |
| `درصد پایان` | گام نسبی نمونه‌برداری برای پایان استفاده از EasyCache (پیش‌فرض: 0.95). | FLOAT | بله | 0.0 - 1.0 |
| `گزارش‌گیری کامل` | آیا اطلاعات دقیق (verbose) ثبت شود؟ (پیش‌فرض: False). | BOOLEAN | بله | - |
