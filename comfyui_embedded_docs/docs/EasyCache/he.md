# EasyCache

צומת EasyCache מוסיף מערכת מטמון מובנית למודל דיפוזיה, שמאיצה את הדגימה על ידי שימוש חוזר בתוצאות משלבים שחושבו קודם, במקום לחשב מחדש כל שלב. הוא מופעל רק בין נקודת התחלה ונקודת סיום הניתנות להגדרה בתהליך הדגימה, ומדלג על שלבים כאשר השינוי המשוער בפלט נשאר מתחת לסף שהוגדר על ידי המשתמש. זהו צומת ניסיוני שמיועד לשימוש באיתור באגים מתקדם.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שאליו יש להוסיף את EasyCache. | MODEL | כן | - |
| `reuse_threshold` | הסף לשימוש חוזר בשלבים שמורים במטמון (ברירת מחדל: 0.2). | FLOAT | כן | 0.0 - 3.0 |
| `start_percent` | שלב הדגימה היחסי שממנו מתחיל השימוש ב-EasyCache (ברירת מחדל: 0.15). | FLOAT | כן | 0.0 - 1.0 |
| `end_percent` | שלב הדגימה היחסי שבו מסתיים השימוש ב-EasyCache (ברירת מחדל: 0.95). | FLOAT | כן | 0.0 - 1.0 |
| `verbose` | האם לתעד מידע מפורט (ברירת מחדל: False). | BOOLEAN | כן | - |
