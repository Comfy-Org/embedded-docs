# ذاكرة التخزين المؤقت السهلة

## المدخلات

تُنفّذ عقدة EasyCache نظام تخزين مؤقت (caching) أصليًا للنماذج لتحسين الأداء من خلال إعادة استخدام الخطوات المحسوبة مسبقًا أثناء عملية أخذ العينات. تضيف وظيفة EasyCache إلى النموذج مع عتبات قابلة للضبط لتحديد متى يبدأ استخدام التخزين المؤقت ومتى يتوقف أثناء الخط الزمني لأخذ العينات.

| المُعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|---------|
| `model` | النموذج الذي ستُضاف إليه وظيفة EasyCache. | MODEL | نعم | - |
| `reuse_threshold` | عتبة إعادة استخدام الخطوات المخزنة مؤقتًا (الافتراضي: 0.2). | FLOAT | نعم | 0.0 - 3.0 |
| `start_percent` | خطوة أخذ العينات النسبية لبدء استخدام EasyCache (الافتراضي: 0.15). | FLOAT | نعم | 0.0 - 1.0 |
| `end_percent` | خطوة أخذ العينات النسبية لإنهاء استخدام EasyCache (الافتراضي: 0.95). | FLOAT | نعم | 0.0 - 1.0 |
| `verbose` | ما إذا كان سيتم تسجيل معلومات تفصيلية (الافتراضي: False). | BOOLEAN | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model` | النموذج مع EasyCache. | MODEL |
