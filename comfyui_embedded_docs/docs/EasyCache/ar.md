# ذاكرة التخزين المؤقت السهلة

تضيف عقدة EasyCache نظام تخزين مؤقت أصليًا إلى نموذج الانتشار، مما يسرّع أخذ العينات عبر إعادة استخدام نتائج الخطوات المحسوبة مسبقًا بدلًا من إعادة حساب كل خطوة. وهي تُفعّل فقط بين نقطة بداية ونهاية قابلتين للضبط من عملية أخذ العينات، وتتخطى الخطوات عندما يبقى التغير المقدّر في المخرجات أقل من عتبة يحددها المستخدم. هذه عقدة تجريبية مخصصة لاستخدامات التصحيح المتقدمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المراد إضافة EasyCache إليه. | MODEL | نعم | - |
| `عتبة إعادة الاستخدام` | العتبة لإعادة استخدام الخطوات المخزنة مؤقتًا (الافتراضي: 0.2). | FLOAT | نعم | 0.0 - 3.0 |
| `نسبة البداية` | الخطوة النسبية لأخذ العينات لبدء استخدام EasyCache (الافتراضي: 0.15). | FLOAT | نعم | 0.0 - 1.0 |
| `نسبة النهاية` | الخطوة النسبية لأخذ العينات لإنهاء استخدام EasyCache (الافتراضي: 0.95). | FLOAT | نعم | 0.0 - 1.0 |
| `مفصل` | ما إذا كان سيتم تسجيل معلومات مفصلة (الافتراضي: False). | BOOLEAN | نعم | - |

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج بعد إضافة وظيفة EasyCache إليه. | MODEL |
