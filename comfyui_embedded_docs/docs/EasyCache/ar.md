# ذاكرة التخزين المؤقت السهلة

عقدة EasyCache تضيف نظام تخزين مؤقت أصليًا إلى نموذج الانتشار، مما يسرّع عملية أخذ العينات عن طريق إعادة استخدام النتائج من الخطوات المحسوبة سابقًا بدلًا من إعادة حساب كل خطوة. وهي تعمل فقط بين نقطة بداية ونهاية قابلة للتكوين في عملية أخذ العينات، وتتخطى الخطوات عندما يبقى التغيّر المتوقع في المخرجات دون حد يحدده المستخدم. هذه عقدة تجريبية مخصصة لاستخدامات التصحيح المتقدمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج الذي سيتم إضافة EasyCache إليه. | MODEL | نعم | - |
| `عتبة إعادة الاستخدام` | الحد الأدنى لإعادة استخدام الخطوات المخزنة (الافتراضي: 0.2). | FLOAT | نعم | 0.0 - 3.0 |
| `نسبة البداية` | خطوة أخذ العينات النسبية لبدء استخدام EasyCache (الافتراضي: 0.15). | FLOAT | نعم | 0.0 - 1.0 |
| `نسبة النهاية` | خطوة أخذ العينات النسبية لإنهاء استخدام EasyCache (الافتراضي: 0.95). | FLOAT | نعم | 0.0 - 1.0 |
| `مفصل` | ما إذا كان سيتم تسجيل معلومات مفصّلة (الافتراضي: False). | BOOLEAN | نعم | - |
