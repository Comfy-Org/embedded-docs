# EasyCache

Узел EasyCache добавляет в диффузионную модель встроенную систему кэширования, которая ускоряет семплирование за счет повторного использования результатов ранее вычисленных шагов вместо пересчета каждого шага. Он активируется только между настраиваемыми начальной и конечной точками процесса семплирования и пропускает шаги, когда предполагаемое изменение выходного результата остается ниже заданного пользователем порога. Это экспериментальный узел, предназначенный для продвинутой отладки.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой добавляется EasyCache. | MODEL | Да | - |
| `порог_повторного_использования` | Порог для повторного использования кэшированных шагов (по умолчанию: 0.2). | FLOAT | Да | 0.0 - 3.0 |
| `начальный_процент` | Относительный шаг семплирования для начала использования EasyCache (по умолчанию: 0.15). | FLOAT | Да | 0.0 - 1.0 |
| `конечный_процент` | Относительный шаг семплирования для окончания использования EasyCache (по умолчанию: 0.95). | FLOAT | Да | 0.0 - 1.0 |
| `подробный` | Определяет, следует ли записывать подробную информацию (по умолчанию: False). | BOOLEAN | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с добавленной функциональностью EasyCache. | MODEL |
