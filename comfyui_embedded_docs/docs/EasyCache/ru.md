# EasyCache

Узел EasyCache добавляет в модель диффузии встроенную систему кэширования, которая ускоряет сэмплирование за счёт повторного использования результатов ранее вычисленных шагов вместо пересчёта каждого шага. Он активируется только между настраиваемыми начальной и конечной точками процесса сэмплирования и пропускает шаги, когда оценённое изменение выходных данных остаётся ниже заданного пользователем порога. Это экспериментальный узел, предназначенный для продвинутой отладки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой нужно добавить EasyCache. | MODEL | Да | - |
| `порог_повторного_использования` | Порог для повторного использования кэшированных шагов (по умолчанию: 0.2). | FLOAT | Да | 0.0 - 3.0 |
| `начальный_процент` | Относительный шаг сэмплирования, с которого начинается использование EasyCache (по умолчанию: 0.15). | FLOAT | Да | 0.0 - 1.0 |
| `конечный_процент` | Относительный шаг сэмплирования, на котором заканчивается использование EasyCache (по умолчанию: 0.95). | FLOAT | Да | 0.0 - 1.0 |
| `подробный` | Нужно ли выводить подробную информацию в журнал (по умолчанию: False). | BOOLEAN | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с добавленной функциональностью EasyCache. | MODEL |
