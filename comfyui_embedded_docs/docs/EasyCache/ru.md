# EasyCache

Узел EasyCache реализует встроенную систему кэширования для моделей, повышающую производительность за счёт повторного использования ранее вычисленных шагов в процессе сэмплирования. Он добавляет функциональность EasyCache к модели с настраиваемыми порогами начала и окончания использования кэша во временной шкале сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель, к которой добавляется EasyCache. | MODEL | Да | - |
| `reuse_threshold` | Порог для повторного использования кэшированных шагов (по умолчанию: 0.2). | FLOAT | Да | 0.0 - 3.0 |
| `start_percent` | Относительный шаг сэмплирования для начала использования EasyCache (по умолчанию: 0.15). | FLOAT | Да | 0.0 - 1.0 |
| `end_percent` | Относительный шаг сэмплирования для окончания использования EasyCache (по умолчанию: 0.95). | FLOAT | Да | 0.0 - 1.0 |
| `verbose` | Определяет, выводить ли подробную информацию (по умолчанию: False). | BOOLEAN | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `model` | Модель с EasyCache. | MODEL |
