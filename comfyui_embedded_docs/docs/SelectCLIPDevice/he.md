# SelectCLIPDevice

## סקירה כללית

הצומת Select CLIP Device מאפשר לך לבחור באיזה התקן (CPU או GPU מסוים) פועל מקודד הטקסט CLIP. כברירת מחדל, ההתקן מוקצה על ידי טוען המודל, אך ניתן לעקוף זאת כדי להשתמש ב-CPU או ב-GPU מסוים. אם ההתקן המבוקש אינו קיים במחשב שלך, הצומת פשוט מעביר את ה-CLIP ללא שינוי ורושם הודעה במקום לגרום לשגיאה.
