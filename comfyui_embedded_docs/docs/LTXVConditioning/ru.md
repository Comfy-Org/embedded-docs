# Кондиционирование LTXV

Узел LTXVConditioning добавляет информацию о частоте кадров к положительным и отрицательным входам conditioning для моделей генерации видео. Он принимает существующие данные conditioning и применяет указанное значение частоты кадров к обоим наборам conditioning, делая их пригодными для обработки видеомоделями.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный conditioning-вход, который получит информацию о частоте кадров | CONDITIONING | Да | - |
| `negative` | Отрицательный conditioning-вход, который получит информацию о частоте кадров | CONDITIONING | Да | - |
| `frame_rate` | Значение частоты кадров, применяемое к обоим наборам conditioning (по умолчанию: 25.0) | FLOAT | Да | 0.0 - 1000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительный conditioning с примененной информацией о частоте кадров | CONDITIONING |
| `negative` | Отрицательный conditioning с примененной информацией о частоте кадров | CONDITIONING |
