# Кондиционирование LTXV

Узел LTXVConditioning добавляет информацию о частоте кадров к положительным и отрицательным входам кондишининга для моделей генерации видео. Он принимает существующие данные кондишининга и применяет указанное значение частоты кадров к обоим наборам кондишининга, делая их пригодными для обработки видеомоделями.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительный вход кондишининга, который получит информацию о частоте кадров | CONDITIONING | Да | - |
| `отрицательный` | Отрицательный вход кондишининга, который получит информацию о частоте кадров | CONDITIONING | Да | - |
| `частота_кадров` | Значение частоты кадров, применяемое к обоим наборам кондишининга (по умолчанию: 25.0) | FLOAT | Да | 0.0 - 1000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Положительный кондишининг с примененной информацией о частоте кадров | CONDITIONING |
| `отрицательный` | Отрицательный кондишининг с примененной информацией о частоте кадров | CONDITIONING |
