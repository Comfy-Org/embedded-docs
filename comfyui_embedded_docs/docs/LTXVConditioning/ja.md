# LTXV条件付け

LTXVConditioning ノードは、ビデオ生成モデル向けに、ポジティブおよびネガティブの両方のコンディショニング入力へフレームレート情報を追加します。既存のコンディショニングデータを受け取り、指定されたフレームレート値を両方のコンディショニングセットに適用することで、ビデオモデル処理に適したものにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | フレームレート情報が適用されるポジティブコンディショニング入力 | CONDITIONING | はい | - |
| `negative` | フレームレート情報が適用されるネガティブコンディショニング入力 | CONDITIONING | はい | - |
| `frame_rate` | 両方のコンディショニングセットに適用するフレームレート値（デフォルト: 25.0） | FLOAT | はい | 0.0 - 1000.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | フレームレート情報が適用されたポジティブコンディショニング | CONDITIONING |
| `negative` | フレームレート情報が適用されたネガティブコンディショニング | CONDITIONING |
