# Разделить AV-латент

Узел `LTXVSeparateAVLatent` принимает комбинированное аудиовизуальное скрытое представление (latent) и разделяет его на два отдельных латента: один для видео и один для аудио. Он работает с любой аудиовизуальной моделью, например LTXV или MiniMax H3.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `av_latent` | Комбинированное аудиовизуальное скрытое представление, которое требуется разделить. | LATENT | Да | N/A |

**Примечание:** Тензор `samples` входного латента должен содержать по крайней мере два элемента по первому измерению (размер пакета). Первый элемент используется для видеолатента, а второй — для аудиолатента. Если присутствует `noise_mask`, он разделяется аналогичным образом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video_latent` | Скрытое представление, содержащее разделённые видеоданные. | LATENT |
| `audio_latent` | Скрытое представление, содержащее разделённые аудиоданные. | LATENT |
