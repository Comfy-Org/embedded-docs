# Разделить AV-латент

Узел LTXVSeparateAVLatent разделяет объединённый аудиовизуальный латент на два отдельных латента: один содержит видеоданные, а другой — аудиоданные. Это работает с любой аудиовизуальной моделью, например LTXV или MiniMax H3. Тензор `samples` разделяется по первому измерению: первый элемент становится видеолатентом, а второй — аудиолатентом; если присутствует маска шума `noise_mask`, она разделяется таким же образом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `av_latent` | Объединённое аудиовизуальное латентное представление, которое нужно разделить на видеолатент и аудиолатент. | LATENT | Да | N/A |

**Примечание:** Тензор `samples` входного латента должен содержать не менее двух элементов по первому измерению (размер пакета). Первый элемент используется для видеолатента, второй — для аудиолатента. Если присутствует `noise_mask`, она разделяется аналогичным образом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video_latent` | Латентное представление, содержащее разделённые видеоданные. | LATENT |
| `audio_latent` | Латентное представление, содержащее разделённые аудиоданные. | LATENT |
