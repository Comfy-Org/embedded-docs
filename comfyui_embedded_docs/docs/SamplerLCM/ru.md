# SamplerLCM

Узел SamplerLCM предоставляет сэмплер LCM (Latent Consistency Model) с настраиваемыми параметрами шума для каждого шага. Параметр `s_noise` действует как множитель масштаба шума, используемого при обучении модели, что позволяет точно контролировать шум, применяемый на каждом шаге сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `s_noise` | Множитель шума на первом шаге (1.0 = соответствует обучению). По умолчанию: 1.0. | FLOAT | Да | 0.0 to 64.0 (step: 0.01) |
| `s_noise_end` | Множитель шума на последнем шаге. Установите равным `s_noise` для постоянного расписания. По умолчанию: 1.0. | FLOAT | Да | 0.0 to 64.0 (step: 0.01) |
| `noise_clip_std` | Ограничивает шум на каждом шаге значением ± N*std. 0 отключает. По умолчанию: 0.0. | FLOAT | Да | 0.0 to 10.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SAMPLER` | Сконфигурированный объект сэмплера LCM, готовый к использованию в рабочем процессе сэмплирования. | SAMPLER |
