# SamplerLCM

Узел SamplerLCM предоставляет сэмплер LCM (модель латентной согласованности) с настраиваемыми пошаговыми параметрами шума. Он позволяет управлять шумом, применяемым на каждом шаге процесса сэмплирования; `s_noise` — это множитель масштаба шума, использованного при обучении модели.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `s_noise` | Пошаговый множитель шума на первом шаге (1.0 = соответствует обучению). (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 64.0 (step: 0.01) |
| `s_noise_end` | Пошаговый множитель шума на последнем шаге. Установите равным `s_noise` для постоянного графика шума. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 64.0 (step: 0.01) |
| `noise_clip_std` | Ограничивает пошаговый шум в пределах +/- N*std. Значение 0 отключает. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 10.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SAMPLER` | Настроенный объект сэмплера LCM, готовый к использованию в рабочем процессе сэмплирования. | SAMPLER |
