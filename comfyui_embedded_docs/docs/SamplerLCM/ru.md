# SamplerLCM

Этот узел предоставляет сэмплер LCM (Latent Consistency Model) с настраиваемым шумом для каждого шага. Он позволяет управлять тем, сколько шума применяется во время сэмплирования: `s_noise` действует как множитель для масштаба шума, использованного при обучении модели, а уровень шума может изменяться от первого шага к последнему. Настроенный сэмплер затем можно подключить в рабочий процесс сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `s_noise` | Множитель шума на первом шаге (1.0 = соответствует обучению). По умолчанию: 1.0. | FLOAT | Да | от 0.0 до 64.0 (шаг: 0.01) |
| `s_noise_end` | Множитель шума на последнем шаге. Установите равным `s_noise` для постоянного расписания. По умолчанию: 1.0. | FLOAT | Да | от 0.0 до 64.0 (шаг: 0.01) |
| `noise_clip_std` | Ограничивает шум на каждом шаге значением +/- N*std. Значение 0 отключает. По умолчанию: 0.0. | FLOAT | Да | от 0.0 до 10.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SAMPLER` | Настроенный объект сэмплера LCM, готовый к использованию в рабочем процессе сэмплирования. | SAMPLER |
