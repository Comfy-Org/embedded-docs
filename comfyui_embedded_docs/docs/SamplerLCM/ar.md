# SamplerLCM

توفر عقدة SamplerLCM أداة أخذ عينات LCM (نموذج الاتساق الكامن) مع معاملات ضوضاء قابلة للضبط لكل خطوة. تتيح لك التحكم في الضوضاء المطبقة في كل خطوة من خطوات عملية أخذ العينات؛ `s_noise` هو مضاعِف لمقياس ضوضاء التدريب للنموذج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `s_noise` | مضاعِف الضوضاء لكل خطوة عند الخطوة الأولى (1.0 = مطابقة التدريب). (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 64.0 (step: 0.01) |
| `s_noise_end` | مضاعِف الضوضاء لكل خطوة عند الخطوة الأخيرة. اجعله مساويًا لـ `s_noise` للحصول على جدول ضوضاء ثابت. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 64.0 (step: 0.01) |
| `noise_clip_std` | قص الضوضاء لكل خطوة إلى ± N*std. القيمة 0 تعطيل. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 إلى 10.0 (step: 0.01) |
