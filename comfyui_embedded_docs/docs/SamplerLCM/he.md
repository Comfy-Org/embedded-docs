# SamplerLCM

צומת זה מספק דוגם LCM (Latent Consistency Model) עם רעש לכל צעד הניתן להתאמה. הוא מאפשר לך לשלוט בכמה רעש מוחל במהלך הדגימה: `s_noise` משמש כמכפיל על סולם רעש האימון של המודל, ורמת הרעש יכולה להשתנות מהצעד הראשון ועד הצעד האחרון. לאחר מכן ניתן לחבר את הדוגם המוגדר לזרימת עבודה של דגימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `s_noise` | מכפיל רעש לכל צעד בצעד הראשון (1.0 = תואם אימון). ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 64.0 (צעד: 0.01) |
| `s_noise_end` | מכפיל רעש לכל צעד בצעד האחרון. הגדר שווה ל-`s_noise` עבור לוח זמנים קבוע. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 64.0 (צעד: 0.01) |
| `noise_clip_std` | הגבל רעש לכל צעד ל-±N*std. 0 משבית. ברירת מחדל: 0.0. | FLOAT | כן | 0.0 עד 10.0 (צעד: 0.01) |
