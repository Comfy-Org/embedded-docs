# VOIDWarpedNoise

نویز همبستهٔ زمانی برای پاس دوم فرایند پالایش ویدیوی VOID تولید می‌کند. ویدیوی خروجی پاس ۱ را می‌گیرد و نویز گاوسی را در امتداد بردارهای جریان نوری وارپ می‌کند، تا نویز به‌طور سازگار با محتوای ویدیو حرکت کند. نویز وارپ‌شدهٔ حاصل به‌عنوان نهفتهٔ آغازین برای پاس ۲ استفاده می‌شود، که سازگاری زمانی را در خروجی نهایی بهبود می‌بخشد.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `optical_flow` | مدل جریان نوری از OpticalFlowLoader (RAFT-large). | OPTICAL_FLOW | بله | - |
| `video` | فریم‌های ویدیوی خروجی پاس ۱ [T, H, W, 3]. | IMAGE | بله | - |
| `width` | عرض هدف بر حسب پیکسل (پیش‌فرض: 672). ویدیوی ورودی پیش از تولید نویز به این عرض مقیاس‌بندی می‌شود، و عرض نهفته به‌صورت width ÷ 8 به دست می‌آید. | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `height` | ارتفاع هدف بر حسب پیکسل (پیش‌فرض: 384). ویدیوی ورودی پیش از تولید نویز به این ارتفاع مقیاس‌بندی می‌شود، و ارتفاع نهفته به‌صورت height ÷ 8 به دست می‌آید. | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `length` | تعداد فریم‌های پیکسلی. به سمت پایین گرد می‌شود تا latent_t زوج شود (الزام patch_size_t=2)، مثلاً 49 به 45 (پیش‌فرض: 45). | INT | بله | 1 تا MAX_RESOLUTION (گام 1) |
| `batch_size` | تعداد دنباله‌های نویز وارپ‌شدهٔ یکسان برای تولید (پیش‌فرض: 1). نویز تولیدشده این تعداد بار در امتداد بُعد batch تکرار می‌شود. | INT | بله | 1 تا 64 |

**نکته درباره پارامتر `length`:** مقدار `length` به‌طور خودکار به نزدیک‌ترین مقدار پایین‌تر گرد می‌شود که بُعد `latent_t` زوج تولید کند، همان‌گونه که مدل CogVideoX-Fun-V1.5 با محدودیت `patch_size_t=2` نیاز دارد (برای نمونه، 49 به 45 تبدیل می‌شود). گره هنگام رخ دادن این گرد کردن، هشدار ثبت می‌کند. فریم‌های فراتر از `length` تنظیم‌شده نادیده گرفته می‌شوند، و نویز به تعداد فریم نهفتهٔ حاصل بازنمونه‌برداری می‌شود.

**نکته درباره `width` و `height`:** این مقادیر هم برای تغییر اندازه فریم‌های ویدیوی ورودی (دوخطی، برش مرکزی) و هم برای تعیین رزولوشن نهفتهٔ نهایی (تقسیم بر 8) استفاده می‌شوند. اگر نویز تولیدشده با اندازه نهفتهٔ درخواستی مطابقت نداشته باشد، برای جا شدن تغییر اندازه داده می‌شود.
