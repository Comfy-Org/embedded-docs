# VOIDWarpedNoise

نویز همبسته‌ی زمانی برای مرحله‌ی دوم فرآیند پالایش ویدیوی VOID تولید می‌کند. این گره ویدیوی خروجی مرحله‌ی ۱ را دریافت کرده و نویز گاوسی را در امتداد بردارهای جریان نوری وارپ می‌کند؛ به این ترتیب نویزی می‌سازد که به‌صورت هماهنگ با محتوای ویدیو حرکت می‌کند. این نویز وارپ‌شده به‌عنوان latent آغازین برای مرحله‌ی ۲ استفاده می‌شود که سازگاری زمانی خروجی نهایی را بهبود می‌بخشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `optical_flow` | مدل جریان نوری از OpticalFlowLoader (RAFT-large). | OPTICAL_FLOW | بله | - |
| `video` | فریم‌های ویدیوی خروجی مرحله‌ی ۱ با ابعاد [T, H, W, 3]. | IMAGE | بله | - |
| `width` | عرض latent خروجی (پیش‌فرض: 672). | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `height` | ارتفاع latent خروجی (پیش‌فرض: 384). | INT | بله | 16 تا MAX_RESOLUTION (گام 8) |
| `length` | تعداد فریم‌های پیکسلی. برای زوج شدن `latent_t` به پایین گرد می‌شود (الزام `patch_size_t=2`)؛ به عنوان مثال 49 → 45 (پیش‌فرض: 45). | INT | بله | 1 تا MAX_RESOLUTION (گام 1) |
| `batch_size` | تعداد دنباله‌های نویز یکسان برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 64 |

**نکته‌ای درباره پارامتر `length`:** مقدار `length` به‌طور خودکار به نزدیک‌ترین مقدار معتبر پایین‌تر گرد می‌شود که بُعد `latent_t` را زوج تولید کند. این امر توسط محدودیت `patch_size_t=2` مدل CogVideoX-Fun-V1.5 الزامی است. در صورت وقوع گرد شدن، یک هشدار در لاگ ثبت می‌شود.
