# VOIDWarpedNoise

Генерирует темпорально коррелированный шум для второго прохода процесса улучшения видео VOID. Он принимает видео с выхода прохода 1 и деформирует гауссов шум вдоль векторов оптического потока, так что шум движется согласованно с содержимым видео. Полученный деформированный шум используется в качестве начального латента для прохода 2, что улучшает временную согласованность в итоговом выводе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `optical_flow` | Модель оптического потока из OpticalFlowLoader (RAFT-large). | OPTICAL_FLOW | Да | - |
| `video` | Кадры видео с выхода прохода 1 [T, H, W, 3]. | IMAGE | Да | - |
| `width` | Целевая ширина в пикселях (по умолчанию: 672). Входное видео масштабируется до этой ширины перед генерацией шума, а ширина латента вычисляется как width ÷ 8. | INT | Да | 16 до MAX_RESOLUTION (шаг 8) |
| `height` | Целевая высота в пикселях (по умолчанию: 384). Входное видео масштабируется до этой высоты перед генерацией шума, а высота латента вычисляется как height ÷ 8. | INT | Да | 16 до MAX_RESOLUTION (шаг 8) |
| `length` | Количество пиксельных кадров. Округляется вниз, чтобы сделать latent_t чётным (требование patch_size_t=2), например, 49 превращается в 45 (по умолчанию: 45). | INT | Да | 1 до MAX_RESOLUTION (шаг 1) |
| `batch_size` | Количество создаваемых одинаковых последовательностей деформированного шума (по умолчанию: 1). Сгенерированный шум повторяется столько раз вдоль размерности батча. | INT | Да | 1 до 64 |

**Примечание к параметру `length`:** Значение `length` автоматически округляется вниз до ближайшего значения, которое даёт чётную размерность `latent_t`, как требуется ограничением `patch_size_t=2` модели CogVideoX-Fun-V1.5 (например, 49 превращается в 45). Когда происходит такое округление, узел выводит предупреждение в лог. Кадры за пределами скорректированного `length` игнорируются, а шум пересэмплируется под получившееся количество латентных кадров.

**Примечание к `width` и `height`:** Эти значения используются как для изменения размера входящих кадров видео (билинейная интерполяция, центральное кадрирование), так и для определения итогового разрешения латента (деление на 8). Если сгенерированный шум не соответствует запрошенному размеру латента, он масштабируется до нужного размера.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `warped_noise` | 5D-тензор (B, C, T, H, W), содержащий гауссов шум, деформированный по оптическому потоку, готовый к использованию в качестве начального латента в VOID, проход 2. | LATENT |
