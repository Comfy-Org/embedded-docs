# VOIDWarpedNoise

Генерирует коррелированный во времени шум для второго прохода процесса улучшения видео VOID. Он берёт выходное видео из Pass 1 и деформирует гауссов шум вдоль векторов оптического потока, создавая шум, который движется согласованно с содержимым видео. Этот деформированный шум используется в качестве начального латентного представления для Pass 2, что улучшает временную согласованность конечного результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `optical_flow` | Модель оптического потока из OpticalFlowLoader (RAFT-large). | OPTICAL_FLOW | Да | - |
| `video` | Кадры выходного видео Pass 1 [T, H, W, 3]. | IMAGE | Да | - |
| `width` | Ширина выходного латентного представления (по умолчанию: 672). | INT | Да | 16 to MAX_RESOLUTION (step 8) |
| `height` | Высота выходного латентного представления (по умолчанию: 384). | INT | Да | 16 to MAX_RESOLUTION (step 8) |
| `length` | Количество пиксельных кадров. Округляется вниз, чтобы сделать `latent_t` чётным (требование `patch_size_t=2`), например, 49 → 45 (по умолчанию: 45). | INT | Да | 1 to MAX_RESOLUTION (step 1) |
| `batch_size` | Количество одинаковых последовательностей шума для генерации (по умолчанию: 1). | INT | Да | 1 до 64 |

**Примечание о параметре `length`:** Значение `length` автоматически округляется вниз до ближайшего допустимого значения, которое даёт чётное измерение `latent_t`. Это обусловлено ограничением `patch_size_t=2` модели CogVideoX-Fun-V1.5. При округлении записывается предупреждение.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `warped_noise` | 5D тензор (B, C, T, H, W), содержащий деформированный оптическим потоком гауссов шум, готовый к использованию в качестве начального латентного представления в Pass 2 VOID. | LATENT |
