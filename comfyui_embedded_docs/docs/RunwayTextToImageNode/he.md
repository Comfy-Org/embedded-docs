# RunwayTextToImageNode

צומת Runway Text to Image מייצר תמונות מפרומפטים טקסטואליים באמצעות מודל Gen 4 של Runway. ניתן לספק תיאור טקסטואלי ובאופן אופציונלי לכלול תמונת עזר כדי להנחות את תהליך יצירת התמונה. הצומת מטפל בתקשורת ה-API ומחזיר את התמונה שנוצרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי ליצירה (ברירת מחדל: "") | STRING | כן | - |
| `ratio` | יחס רוחב-גובה לתמונה הנוצרת | COMBO | כן | "16:9"<br>"1:1"<br>"21:9"<br>"2:3"<br>"3:2"<br>"4:5"<br>"5:4"<br>"9:16"<br>"9:21" |
| `reference_image` | תמונת עזר אופציונלית להנחות את היצירה | IMAGE | לא | - |

**הערה:** תמונת העזר חייבת להיות במידות שלא עולות על 7999x7999 פיקסלים וביחס רוחב-גובה בין 0.5 ל-2.0. כאשר מסופקת תמונת עזר, היא מנחה את תהליך יצירת התמונה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | התמונה שנוצרה על בסיס הפרומפט הטקסטואלי ותמונת העזר האופציונלית | IMAGE |
