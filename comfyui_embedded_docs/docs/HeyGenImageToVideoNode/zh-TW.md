# HeyGen Video 1.0 圖像轉影片

使用 HeyGen Video 1.0 將影像製作成具有同步對白與聲音的影片。連接的影像會作為第一幀，而生成的影片會保持其長寬比。在提示詞中描述應該發生什麼事，包括任何要說出的台詞。此節點會上傳影像、建立影片任務、等待任務完成，並傳回產生的影片。

### 參數限制

- **單張影像：** `image` 必須正好包含一張影像。連接批次會引發錯誤。
- **影像長寬比：** 影像的寬度不得超過其高度的 4 倍，高度不得超過其寬度的 4 倍（介於 1:4 和 4:1 之間）；否則執行會失敗。
- **必須提供提示詞：** 提示詞必須包含至少一個非空白字元，且最多 16000 個字元。
- **高解析度：** `resolution` 為 `"1080p"` 和 `"2k"` 時需要 16:9 或 9:16 的影像，因為影片會保持影像的長寬比。若是其他形狀，請裁切影像。
- **種子：** 種子僅決定此節點是否重新執行；使用相同種子無法重現結果。
