# HeyGen Video 1.0 圖像轉影片

使用 HeyGen Video 1.0 將影像製作成具有同步對話與聲音的影片。連接的影像會作為第一幀，且生成的影片會保留其長寬比。在提示詞中描述應該發生什麼事，包括任何台詞。此節點會上傳影像、建立影片任務、等待任務完成，並傳回生成的影片。

### 參數限制

- **單張影像：** `image` 必須恰好包含一張影像。連接批次會引發錯誤。
- **影像長寬比：** 影像的寬度不得超過高度的 4 倍，高度也不得超過寬度的 4 倍（介於 1:4 與 4:1 之間）；否則執行會失敗。
- **必須提供提示詞：** 提示詞必須包含至少一個非空白字元，且最多 16000 個字元。
- **種子：** 種子僅決定節點是否重新執行；即使使用相同的種子，結果也無法重現。
