# HeyGen Video 1.0 Image to Video

使用 HeyGen Video 1.0 將圖像動畫化為具有同步對話與聲音的影片。連接的圖像會用作第一幀，而產生的影片會維持其長寬比。請在 `prompt` 中描述應該發生的事情，包括任何台詞。此節點會上傳圖像、建立影片作業、等待作業完成，並傳回產生的影片。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於生成的模型版本。（預設：`"heygen-video-1"`） | DYNAMIC_COMBO | 是 | `"heygen-video-1"` |
| `image` | 影片的第一幀。必須剛好一張圖像；批次會被拒絕。裁切圖像可變更影片形狀，因為輸出會保留此圖像的長寬比。 | IMAGE | 是 | 1 張影像，長寬比 1:4 至 4:1 |
| `prompt` | 影片中發生內容的描述，包括任何對話。（預設：空字串） | STRING | 是 | 1 至 32000 個字元 |
| `duration` | 輸出影片的持續時間，以秒為單位。（預設：5） | INT | 是 | 5 至 15 |
| `resolution` | 輸出解析度。（預設：`"768p"`） | COMBO | 是 | `"768p"`<br>`"480p"` |
| `seed` | 用於生成的 `seed`。即使使用相同的 `seed`，不同次執行的結果仍可能不同。（預設：42） | INT | 是 | 0 至 4294967295 |

### 參數限制

- **單一圖像：** `image` 必須正好包含一張圖像。連接批次會引發錯誤。
- **圖像長寬比：** 圖像的寬度不得超過其高度的 4 倍，高度不得超過其寬度的 4 倍（介於 1:4 和 4:1 之間）；否則執行會失敗。
- **需要 `prompt`：** `prompt` 必須包含至少一個非空白字元，且最多 32000 個字元。
- **`seed`：** `seed` 只決定此節點是否重新執行；使用相同的 `seed` 無法重現結果。
