# HeyGen Video 1.0 이미지-비디오

HeyGen Video 1.0을 사용하여 이미지를 동기화된 대사 및 사운드가 포함된 비디오로 애니메이션화합니다. 연결된 이미지는 첫 프레임으로 사용되며, 생성된 비디오는 해당 종횡비를 유지합니다. 프롬프트에 발화 대사를 포함하여 어떤 일이 일어나야 하는지 설명합니다. 이 노드는 이미지를 업로드하고, 비디오 작업을 생성하며, 작업이 완료될 때까지 기다린 후 결과 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용되는 모델 버전입니다. (기본값: `"heygen-video-1"`) | DYNAMIC_COMBO | 예 | `"heygen-video-1"` |
| `image` | 비디오의 첫 프레임입니다. 정확히 이미지 1개가 필요하며, 배치는 거부됩니다. 출력이 이 이미지의 종횡비를 유지하므로 비디오의 형태를 변경하려면 이미지를 잘라야 합니다. | IMAGE | 예 | 이미지 1개, 종횡비 1:4 ~ 4:1 |
| `prompt` | 비디오에서 일어나는 일에 대한 설명으로, 모든 대사를 포함합니다. (기본값: 빈 문자열) | STRING | 예 | 1~16000자 |
| `duration` | 출력 비디오의 길이(초)입니다. `auto_duration`이 `"enabled"`일 때 무시됩니다. (기본값: 5) | INT | 예 | 5 ~ 30 |
| `resolution` | 출력 해상도입니다. (기본값: `"768p"`) | COMBO | 예 | `"768p"`<br>`"480p"`<br>`"1080p"`<br>`"2k"` |
| `seed` | 생성용 시드입니다. 동일한 시드로 실행해도 결과가 달라질 수 있습니다. (기본값: 42) | INT | 예 | 0 ~ 4294967295 |
| `auto_duration` | 활성화하면 비디오 길이가 프롬프트에 따옴표로 묶인 대사를 따르며(8~30초), `duration`은 무시됩니다. (기본값: `"disabled"`) | COMBO | 아니요 | `"disabled"`<br>`"enabled"` |

### 매개변수 제약 조건

- **단일 이미지:** `image`에는 정확히 이미지 1개가 포함되어야 합니다. 배치를 연결하면 오류가 발생합니다.
- **이미지 종횡비:** 이미지는 높이의 4배보다 넓지 않아야 하고 너비의 4배보다 높지 않아야 합니다(1:4 ~ 4:1). 그렇지 않으면 실행이 실패합니다.
- **프롬프트 필수:** 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 하며, 최대 16000자여야 합니다.
- **시드:** 시드는 노드의 재실행 여부만 결정하며, 동일한 시드로 결과를 재현할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 동기화된 대사와 사운드가 포함된 생성 비디오로, 입력 이미지의 종횡비를 따릅니다. | VIDEO |
