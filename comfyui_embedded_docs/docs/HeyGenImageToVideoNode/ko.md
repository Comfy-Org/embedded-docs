# HeyGen Video 1.0 이미지-비디오

HeyGen Video 1.0을 사용하여 이미지를 동기화된 대사와 사운드가 포함된 비디오로 애니메이션화합니다. 연결된 이미지는 첫 프레임으로 사용되며, 생성된 비디오는 해당 가로세로 비율을 유지합니다. 프롬프트에 발생해야 하는 일과 대사(있는 경우)를 설명해야 합니다. 이 노드는 이미지를 업로드하고, 비디오 작업을 생성하고, 완료될 때까지 기다린 후 결과 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용되는 모델 버전입니다. (기본값: `"heygen-video-1"`) | DYNAMIC_COMBO | 예 | `"heygen-video-1"` |
| `image` | 비디오의 첫 프레임입니다. 정확히 한 개의 이미지가 필요하며, 배치는 거부됩니다. 출력은 이 이미지의 가로세로 비율을 유지하므로 비디오의 형태를 변경하려면 이미지를 잘라야 합니다. | IMAGE | 예 | 1개 이미지, 가로세로 비율 1:4 ~ 4:1 |
| `prompt` | 비디오에서 일어나는 일에 대한 설명으로, 대사가 포함됩니다. (기본값: 빈 문자열) | STRING | 예 | 1 ~ 16000자 |
| `duration` | 출력 비디오의 길이(초)입니다. `auto_duration`이 `"enabled"`일 때는 무시됩니다. (기본값: 5) | INT | 예 | 5 ~ 30 |
| `resolution` | 출력 해상도입니다. 1080p 및 2k는 16:9 또는 9:16에서만 렌더링되므로 이미지가 해당 형태여야 하며, 먼저 잘라야 합니다. (기본값: `"768p"`) | COMBO | 예 | `"768p"`<br>`"480p"`<br>`"1080p"`<br>`"2k"` |
| `seed` | 생성용 시드입니다. 동일한 시드로도 실행할 때마다 결과가 달라질 수 있습니다. (기본값: 42) | INT | 예 | 0 ~ 4294967295 |
| `auto_duration` | 활성화하면 비디오 길이가 프롬프트에 인용된 대사를 따르며(8 ~ 30초), `duration`은 무시됩니다. (기본값: `"disabled"`) | COMBO | 아니오 | `"disabled"`<br>`"enabled"` |

### 매개변수 제약

- **단일 이미지:** `image`에는 정확히 하나의 이미지가 포함되어야 합니다. 배치를 연결하면 오류가 발생합니다.
- **이미지 가로세로 비율:** 이미지는 너비가 높이의 4배를 초과하지 않아야 하며, 높이가 너비의 4배를 초과하지 않아야 합니다(1:4 ~ 4:1). 그렇지 않으면 실행이 실패합니다.
- **프롬프트 필수:** 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 하며, 최대 16000자여야 합니다.
- **고해상도:** `resolution`의 `"1080p"` 및 `"2k"`는 비디오가 이미지의 가로세로 비율을 유지하므로 16:9 또는 9:16 이미지가 필요합니다. 다른 형태의 경우 이미지를 잘라야 합니다.
- **시드:** 시드는 노드의 재실행 여부만 결정하며, 동일한 시드로 결과를 재현할 수는 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 동기화된 대사와 사운드가 포함된 생성 비디오이며, 입력 이미지의 가로세로 비율을 따릅니다. | VIDEO |
