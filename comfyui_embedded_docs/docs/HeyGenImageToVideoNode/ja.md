# HeyGen Video 1.0 画像から動画

HeyGen Video 1.0 を使用して、画像をアニメーション化し、同期したセリフと音声付きの動画を生成します。接続された画像が最初のフレームとして使用され、生成された動画はそのアスペクト比を維持します。プロンプトには、発話されるセリフを含め、何が起こるべきかを記述してください。このノードは画像をアップロードし、動画ジョブを作成し、完了を待って、結果の動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルバージョン。（デフォルト: `"heygen-video-1"`） | DYNAMIC_COMBO | はい | `"heygen-video-1"` |
| `image` | 動画の最初のフレーム。画像は正確に 1 枚必要です。バッチは拒否されます。出力はこの画像のアスペクト比を維持するため、動画の形状を変更するには画像をトリミングしてください。 | IMAGE | はい | 1 枚の画像、アスペクト比 1:4～4:1 |
| `prompt` | 動画内で何が起こるかの説明。セリフを含みます。（デフォルト: 空文字列） | STRING | はい | 1～16000 文字 |
| `duration` | 出力動画の長さ（秒）。`auto_duration` が `"enabled"` の場合は無視されます。（デフォルト: 5） | INT | はい | 5～30 |
| `resolution` | 出力解像度。（デフォルト: `"768p"`） | COMBO | はい | `"768p"`<br>`"480p"`<br>`"1080p"`<br>`"2k"` |

| `auto_duration` | 有効にすると、動画の長さはプロンプト内で引用符に囲まれたセリフに従い（8～30 秒）、`duration` は無視されます。（デフォルト: `"disabled"`） | COMBO | いいえ | `"disabled"`<br>`"enabled"` |

### パラメータの制約

- **単一画像:** `image` には正確に 1 枚の画像を含める必要があります。バッチを接続するとエラーが発生します。
- **画像アスペクト比:** 画像の幅は高さの 4 倍以下、高さは幅の 4 倍以下である必要があります（1:4～4:1）。そうでない場合、実行は失敗します。
- **プロンプト必須:** プロンプトには少なくとも 1 つの空白以外の文字を含み、最大 16000 文字である必要があります。
- **シード:** シードはノードを再実行するかどうかのみを決定します。同じシードで結果を再現することはできません。
