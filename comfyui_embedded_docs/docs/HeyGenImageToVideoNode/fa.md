# HeyGen Video 1.0 Image to Video

یک تصویر را با استفاده از HeyGen Video 1.0 به ویدیویی با گفت‌وگوی همگام‌شده و صدا تبدیل کنید. تصویر متصل‌شده به‌عنوان فریم نخست استفاده می‌شود و ویدیوی تولیدشده نسبت ابعاد آن را حفظ می‌کند. آنچه باید رخ دهد، شامل هر جمله گفتاری، را در `prompt` توصیف کنید. این گره تصویر را بارگذاری می‌کند، کار ویدیو را ایجاد می‌کند، منتظر می‌ماند تا تمام شود و ویدیوی حاصل را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | نسخه مدل مورد استفاده برای تولید. (پیش‌فرض: `"heygen-video-1"`) | DYNAMIC_COMBO | بله | `"heygen-video-1"` |
| `image` | فریم نخست ویدیو. دقیقاً یک تصویر لازم است؛ یک batch رد می‌شود. تصویر را برش بزنید تا شکل ویدیو تغییر کند، زیرا خروجی نسبت ابعاد این تصویر را حفظ می‌کند. | IMAGE | بله | 1 تصویر، نسبت ابعاد 1:4 تا 4:1 |
| `prompt` | توضیح آنچه در ویدیو رخ می‌دهد، شامل هر گفت‌وگویی. (پیش‌فرض: رشته خالی) | STRING | بله | 1 تا 32000 کاراکتر |
| `duration` | مدت ویدیوی خروجی بر حسب ثانیه. (پیش‌فرض: 5) | INT | بله | 5 تا 15 |
| `resolution` | وضوح خروجی. (پیش‌فرض: `"768p"`) | COMBO | بله | `"768p"`<br>`"480p"`<br>`"2k"` |
| `seed` | Seed برای تولید. نتایج همچنان می‌توانند بین اجراها با همان seed متفاوت باشند. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |

### محدودیت‌های پارامتر

- **تصویر تک:** `image` باید دقیقاً شامل یک تصویر باشد. اتصال یک دسته (batch) خطا ایجاد می‌کند.
- **نسبت ابعاد تصویر:** تصویر نباید عرضش بیش از 4 برابر ارتفاعش باشد و نه ارتفاعش بیش از 4 برابر عرضش (بین 1:4 و 4:1)؛ در غیر این صورت اجرا شکست می‌خورد.
- **`prompt` الزامی:** `prompt` باید حداقل شامل یک کاراکتر غیرفاصله و حداکثر 32000 کاراکتر باشد.
- **Seed:** seed فقط تعیین می‌کند که آیا گره دوباره اجرا می‌شود؛ نتایج با همان seed قابل بازتولید نیستند.
