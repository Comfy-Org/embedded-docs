# HeyGen Video 1.0 图像转视频

使用 HeyGen Video 1.0 将图像制作成带有同步对话和声音的视频。连接的图像会用作第一帧，生成的视频将保持其宽高比。请在 `prompt` 中描述视频中应发生的事情，包括任何台词。此节点会上传图像、创建视频任务、等待任务完成，并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成的模型版本。（默认：`"heygen-video-1"`） | DYNAMIC_COMBO | 是 | `"heygen-video-1"` |
| `image` | 视频的第一帧。必须且只能有一张图像；传入批次会被拒绝。裁剪图像可改变视频的形状，因为输出会保持此图像的宽高比。 | IMAGE | 是 | 1 张图像，宽高比 1:4 到 4:1 |
| `prompt` | 对视频中所发生内容的描述，包括任何对话。（默认：空字符串） | STRING | 是 | 1 到 16000 个字符 |
| `duration` | 输出视频的时长，单位为秒。当 `auto_duration` 为 `"enabled"` 时忽略此项。（默认：5） | INT | 是 | 5 到 30 |
| `resolution` | 输出分辨率。（默认：`"768p"`） | COMBO | 是 | `"768p"`<br>`"480p"`<br>`"1080p"`<br>`"2k"` |
| `seed` | 用于生成的种子。即使种子相同，不同次运行的结果仍可能不同。（默认：42） | INT | 是 | 0 到 4294967295 |
| `auto_duration` | 启用后，视频长度会跟随提示词中引用的对话时长（8 到 30 秒），并忽略 `duration`。（默认：`"disabled"`） | COMBO | 否 | `"disabled"`<br>`"enabled"` |

### 参数约束

- **单张图像：** `image` 必须恰好包含一张图像。连接批次会引发错误。
- **图像宽高比：** 图像宽度不得超过其高度的 4 倍，高度也不得超过其宽度的 4 倍（介于 1:4 与 4:1 之间）；否则运行会失败。
- **提示词必填：** 提示词必须包含至少一个非空白字符，且最多 16000 个字符。
- **种子：** 种子仅决定节点是否重新运行；相同种子无法复现相同结果。
