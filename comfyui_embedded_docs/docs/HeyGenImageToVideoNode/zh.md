# HeyGen Video 1.0 图像转视频

使用 HeyGen Video 1.0 将图像制作成带有同步对话和声音的视频动画。连接的图像将用作第一帧，生成的视频会保持其宽高比。在提示词中描述应发生的内容，包括任何台词。该节点会上传图像、创建视频任务、等待其完成并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `model` | 用于生成的模型版本。（默认：`"heygen-video-1"`） | DYNAMIC_COMBO | 是 | `"heygen-video-1"` |
| `image` | 视频的第一帧。必须恰好包含一张图像；批次会被拒绝。裁剪图像以改变视频形状，因为输出会保持该图像的宽高比。 | IMAGE | 是 | 1 张图像，宽高比 1:4 到 4:1 |
| `prompt` | 对视频中发生内容的描述，包括任何对话。（默认：空字符串） | STRING | 是 | 1 到 16000 个字符 |

### 参数约束

- **单张图像：** `image` 必须恰好包含一张图像。连接批次会引发错误。
- **图像宽高比：** 图像的宽度不能超过其高度的 4 倍，高度不能超过其宽度的 4 倍（介于 1:4 和 4:1 之间）；否则运行会失败。
- **提示词必填：** 提示词必须至少包含一个非空白字符，并且最多包含 16000 个字符。
- **高分辨率：** `resolution` `"1080p"` 和 `"2k"` 需要 16:9 或 9:16 的图像，因为视频会保持图像的宽高比。对于其他形状，请裁剪图像。
- **种子：** 种子仅决定节点是否会重新运行；使用相同种子无法复现结果。
