# HeyGen Video 1.0 תמונה לווידאו

הפכו תמונה לסרטון עם דיאלוג וקול מסונכרנים באמצעות HeyGen Video 1.0. התמונה המחוברת משמשת כפריים הראשון, והסרטון שנוצר שומר על יחס הגובה-רוחב שלה. תארו ב-`prompt` מה אמור לקרות, כולל שורות מדוברות. הצומת מעלה את התמונה, יוצר את משימת הווידאו, ממתין לסיומה ומחזיר את הסרטון שנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת המודל המשמשת ליצירה. (ברירת מחדל: `"heygen-video-1"`) | DYNAMIC_COMBO | כן | `"heygen-video-1"` |
| `image` | הפריים הראשון של הסרטון. נדרשת תמונה אחת בדיוק; אצווה נדחית. חתכו את התמונה כדי לשנות את צורת הסרטון, מכיוון שהפלט שומר על יחס הגובה-רוחב של תמונה זו. | IMAGE | כן | תמונה אחת, יחס גובה-רוחב 1:4 עד 4:1 |
| `prompt` | תיאור של מה שקורה בסרטון, כולל דיאלוג כלשהו. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | 1 עד 32000 תווים |
| `duration` | משך סרטון הפלט בשניות. (ברירת מחדל: 5) | INT | כן | 5 עד 15 |
| `resolution` | רזולוציית הפלט. (ברירת מחדל: `"768p"`) | COMBO | כן | `"768p"`<br>`"480p"`<br>`"2k"` |
| `seed` | Seed ליצירה. התוצאות יכולות להשתנות בין הרצות גם עם אותו seed. (ברירת מחדל: 42) | INT | כן | 0 עד 4294967295 |

### אילוצי פרמטרים

- **תמונה בודדת:** `image` חייב להכיל תמונה אחת בדיוק. חיבור אצווה מעלה שגיאה.
- **יחס גובה-רוחב של התמונה:** התמונה לא יכולה להיות רחבה יותר מפי 4 מגובהה ולא גבוהה יותר מפי 4 מרוחבה (בין 1:4 ל-4:1); אחרת ההרצה נכשלת.
- **נדרש `prompt`:** ה-`prompt` חייב להכיל לפחות תו אחד שאינו רווח ולהכיל לכל היותר 32000 תווים.
- **`seed`:** ה-`seed` קובע רק אם הצומת ירוץ מחדש; התוצאות אינן ניתנות לשחזור עם אותו `seed`.
