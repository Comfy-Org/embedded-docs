# Tencent HY Image: Edit

Tencent HY Image: Edit 節點會使用騰訊的 Hunyuan Image 模型，根據文字指令編輯或合併參考影像。連接一至五張影像，在 `prompt` 中描述變更，並以 `@Image1`、`@Image2` 等方式參照這些影像。此節點會上傳參考影像、將請求傳送至 API，並回傳編輯後的結果。
