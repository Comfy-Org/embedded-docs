# Tencent HY Image: Edit

Узел Tencent HY Image: Edit редактирует или объединяет эталонные изображения по текстовой инструкции с помощью модели Hunyuan Image от Tencent. Подключите от одного до пяти изображений, опишите изменение в промпте и ссылайтесь на изображения как `@Image1`, `@Image2` и так далее. Узел загружает эталонные изображения, отправляет запрос к API и возвращает отредактированный результат.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для редактирования. Выбранная модель определяет, какие дополнительные входы отображаются. | DYNAMIC_COMBO | Да | `"hy-image-3.5-preview"` |

### Входы hy-image-3.5-preview

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает ссылки вида `@Image1` на подключённые изображения. Не должен быть пустым (по умолчанию: пусто). | STRING | Да | Любой текст |
| `aspect_ratio` | Соотношение сторон выходного изображения. `"auto"` использует соотношение сторон первого эталонного изображения и недоступно при 4K. Игнорируется, когда `resolution` имеет значение `"custom"`. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"` (по умолчанию: `"auto"`) |
| `resolution` | Пиксельная область выходного изображения: 1K — примерно 1024x1024, 2K — примерно 2048x2048, 4K — примерно 4096x4096. Всё, что выше 2K, рендерится в 2K и увеличивается моделью. Установите `"custom"`, чтобы использовать `width` и `height` вместо предустановленной области. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"`<br>`"custom"` (по умолчанию: `"2K"`) |
| `width` | Ширина выходного изображения в пикселях. Используется только когда `resolution` имеет значение `"custom"`. | INT | Да | 256-8192, шаг 16 (по умолчанию: 2048) |
| `height` | Высота выходного изображения в пикселях. Используется только когда `resolution` имеет значение `"custom"`. | INT | Да | 256-8192, шаг 16 (по умолчанию: 2048) |
| `seed` | Сид, используемый для генерации. Результаты всё равно различаются между запусками с одинаковым сидом. | INT | Да | 0-2147483647 (по умолчанию: 42) |
| `reference_detail` | Насколько детально модель видит эталонные изображения: `"standard"` допускает до 1024x1024 пикселей на изображение, `"high"` — до 2048x2048 и лучше сохраняет мелкий текст и тонкие детали, но работает дольше. Это расширенный параметр. | COMBO | Нет | `"standard"`<br>`"high"` (по умолчанию: `"standard"`) |
| `watermark` | Добавлять ли сгенерированный ИИ водяной знак к результату. Это расширенный параметр. | BOOLEAN | Нет | true<br>false (по умолчанию: false) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Эталонные изображения для редактирования или объединения. Расширяемый слот: подключите от 1 до 5 изображений (`image_1`–`image_5`). Ссылайтесь на них в промпте как `@Image1` ... `@Image5`, нумеруя в порядке входов; при пакетной подаче каждое изображение считается отдельно. | IMAGE | Да | 1-5 изображений |

`prompt` не должен быть пустым, а ссылка в промпте, например `@Image3`, вызывает ошибку, если подключено только 1 или 2 изображения. Всего можно использовать не более 5 эталонных изображений, при этом каждое изображение в пакете считается отдельно. При разрешении `"custom"` `width` и `height` должны быть кратны 16, а их произведение не должно превышать предельную площадь 4096 x 4096 пикселей (около 16,7 мегапикселя); подойдёт любое соотношение сторон, хотя примерно после 6:1 модель начинает повторять объект. Соотношение сторон `"auto"` работает только в пределах площади 2K, поэтому при 4K выберите явное соотношение сторон или используйте `"custom"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Отредактированное изображение, созданное из эталонных изображений и промпта. | IMAGE |
