# ComfyMathExpression

הצומת ComfyMathExpression מחשב נוסחה מתמטית שאתה כותב כטקסט. הנוסחה יכולה להתייחס לערכי הקלט של הצומת באמצעות שמות אותיות כגון `a`, `b`, `c`, וניתן להוסיף כמה ערכי קלט שדרושים דרך קבוצת `values` הניתנת להרחבה. תוצאת החישוב מוחזרת בו-זמנית כמספר נקודה צפה, מספר שלם וערך בוליאני.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `expression` | הנוסחה המתמטית שיש לחשב, כתובה כטקסט (לדוגמה `a + b`), תוך שימוש בשמות האותיות של ערכי הקלט כמשתנים. קלט רב-שורתי. (ברירת מחדל: "a + b") | STRING | כן | N/A |
| `values` | קבוצה ניתנת להרחבה של ערכי קלט המספקת את המשתנים עבור הביטוי. כל ערך שנוסף לקבוצה מקבל אוטומטית את שם האות הקטנה הבאה החל מ-`a` (`a`, `b`, `c`, ...), ולאחר מכן ניתן להשתמש בשם זה בתוך `expression`. כל פריט מקבל מספר (INT או FLOAT) או ערך בוליאני (TRUE/FALSE). | FLOAT, INT, BOOLEAN | כן | 1 עד 26 ערכים, בשמות `a` עד `z` |

### הערות ומגבלות

- `expression` לא יכול להיות ריק או להכיל רווחים בלבד.
- הביטוי חייב להניב תוצאה מספרית (INT או FLOAT) או תוצאה בוליאנית (TRUE/FALSE). תוצאות בוליאניות מטופלות כ-1 עבור TRUE ו-0 עבור FALSE. אם התוצאה היא מסוג אחר, כגון טקסט, הצומת מעלה שגיאה.
- התוצאה המספרית חייבת להיות סופית וניתנת להמרה למספר נקודה צפה. תוצאות גדולות מדי או שאינן סופיות גורמות לשגיאה.
- כל קבוצת ערכי הקלט זמינה גם בתוך הביטוי תחת שם המשתנה `values` (כרשימה), כך שביטויים כגון `sum(values)` אפשריים.
- הפונקציות המתמטיות הבאות זמינות בתוך הביטוי: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.
