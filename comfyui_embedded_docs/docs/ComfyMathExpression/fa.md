# عبارت ریاضی

گره ComfyMathExpression یک فرمول ریاضی را که به‌صورت متن می‌نویسید ارزیابی می‌کند. فرمول می‌تواند با استفاده از نام‌های حرفی مانند `a`، `b` و `c` به مقادیر ورودی گره ارجاع دهد و می‌توانید هر تعداد مقدار ورودی موردنیاز را از طریق گروه قابل‌گسترش `values` اضافه کنید. نتیجه محاسبه به‌طور هم‌زمان به‌صورت یک عدد اعشاری، یک عدد صحیح و یک مقدار بولی بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `عبارت` | فرمول ریاضی برای ارزیابی، به‌صورت متن نوشته می‌شود (برای مثال `a + b`)، و از نام‌های حرفی مقادیر ورودی به‌عنوان متغیر استفاده می‌کند. ورودی چندخطی. (پیش‌فرض: "a + b") | STRING | بله | N/A |
| `مقادیر` | گروه قابل‌گسترش مقادیر ورودی که متغیرهای `expression` را فراهم می‌کند. هر مقداری که به گروه اضافه شود، به‌طور خودکار نام حرف کوچک بعدی را از `a` شروع می‌کند (`a`، `b`، `c`، ...)، و سپس آن نام می‌تواند داخل `expression` استفاده شود. هر آیتم یک عدد (INT یا FLOAT) یا یک مقدار بولی (TRUE/FALSE) می‌پذیرد. | FLOAT, INT, BOOLEAN | بله | ۱ تا ۲۶ مقدار، با نام‌های `a` تا `z` |

### نکات و محدودیت‌ها

- `expression` نمی‌تواند خالی باشد یا فقط شامل فاصله باشد.
- عبارت باید به یک نتیجه عددی (INT یا FLOAT) یا یک نتیجه بولی (TRUE/FALSE) ارزیابی شود. نتایج بولی برای TRUE برابر ۱ و برای FALSE برابر ۰ در نظر گرفته می‌شوند. اگر نتیجه نوع دیگری باشد، مانند متن، گره خطا ایجاد می‌کند.
- نتیجه عددی باید متناهی و قابل تبدیل به float باشد. نتایجی که بیش‌ازحد بزرگ یا غیرمتناهی باشند باعث خطا می‌شوند.
- کل مجموعه مقادیر ورودی نیز درون `expression` تحت نام متغیر `values` (به‌صورت یک فهرست) در دسترس است، بنابراین عبارت‌هایی مانند `sum(values)` ممکن هستند.
- توابع ریاضی زیر درون `expression` در دسترس هستند: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `FLOAT` | نتیجه `expression` به‌صورت یک عدد اعشاری. | FLOAT |
| `INT` | نتیجه `expression` که به عدد صحیح تبدیل شده و بخش اعشاری آن حذف شده است. | INT |
| `BOOL` | نتیجه تبدیل‌شده به مقدار بولی: TRUE وقتی نتیجه عددی غیرصفر است، FALSE وقتی صفر است. | BOOLEAN |
