# Математическое выражение

Узел ComfyMathExpression вычисляет математическую формулу, которую вы записываете в виде текста. Формула может ссылаться на входные значения узла, используя буквенные имена, например `a`, `b`, `c`, и вы можете добавить столько входных значений, сколько необходимо, через расширяемую группу `values`. Результат вычисления возвращается одновременно как число с плавающей запятой, целое число и логическое значение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `выражение` | Математическая формула для вычисления, записанная в виде текста (например, `a + b`), с использованием буквенных имён входных значений в качестве переменных. Многострочный ввод. (по умолчанию: "a + b") | STRING | Да | N/A |
| `значения` | Расширяемая группа входных значений, предоставляющая переменные для выражения. Каждому значению, добавленному в группу, автоматически присваивается следующее строчное буквенное имя, начиная с `a` (`a`, `b`, `c`, ...), и затем это имя можно использовать внутри `expression`. Каждый элемент принимает число (INT или FLOAT) или логическое значение (TRUE/FALSE). | FLOAT, INT, BOOLEAN | Да | 1–26 значений, с именами от `a` до `z` |

### Примечания и ограничения

- `expression` не может быть пустым или содержать только пробельные символы.
- Выражение должно вычисляться в числовой результат (INT или FLOAT) или логический результат (TRUE/FALSE). Логические результаты обрабатываются как 1 для TRUE и 0 для FALSE. Если результат имеет другой тип, например текст, узел выдаёт ошибку.
- Числовой результат должен быть конечным и преобразуемым в число с плавающей запятой. Результаты, которые слишком велики или не являются конечными, вызывают ошибку.
- Весь набор входных значений также доступен внутри выражения под именем переменной `values` (как список), поэтому возможны выражения вроде `sum(values)`.
- Внутри выражения доступны следующие математические функции: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `FLOAT` | Результат выражения в виде числа с плавающей запятой. | FLOAT |
| `INT` | Результат выражения, преобразованный в целое число с усечением дробной части. | INT |
| `BOOL` | Результат, преобразованный в логическое значение: TRUE, когда числовой результат не равен нулю, и FALSE, когда он равен нулю. | BOOLEAN |
