# Создать видео

The Create Video node generates a video file from a sequence of images. You can set the playback speed in frames per second, optionally add audio, and choose the bit depth and color space of the resulting video.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Изображения, из которых создается видео. | IMAGE | Да | - |
| `кадров в секунду` | Количество кадров в секунду для скорости воспроизведения видео (по умолчанию: 30.0). | FLOAT | Да | 1.0 - 120.0 |
| `аудио` | Аудио для добавления в видео. | AUDIO | Нет | - |
| `bit_depth` | Значение "auto" использует 8-бит для sRGB и 10-бит для HDR. Явный выбор 8-бит или 10-бит не зависит от цветового пространства. (по умолчанию: "auto") | COMBO | Нет | `"auto"`<br>8<br>10 |
| `color_space` | Цветовое пространство входных изображений. HDR выбирает BT.2020/HLG, а HDR PQ выбирает BT.2020/PQ. (по умолчанию: "sRGB") | COMBO | Нет | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |

Примечание: Когда параметр `bit_depth` установлен в значение "auto", узел использует 10-бит для цветовых пространств HDR и HDR PQ, и 8-бит для sRGB.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео, содержащее входные изображения и необязательное аудио. | VIDEO |
