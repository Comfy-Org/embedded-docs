# Kling 4.0 影像轉影片

使用 Kling 4.0 模型從一組關鍵影格生成影片，並包含音訊。第一影格、最多八個中間影格與最後影格會依序送出；中間影格會均勻分佈於影片片段中，輸出會採用第一個關鍵影格的長寬比。可用於讓單張圖片動起來，或透過一系列關鍵時刻引導鏡頭。

### kling-4.0-flash 輸入

當 `model` 設為 `"kling-4.0-flash"` 時會顯示這些輸入。Flash 會讓單一第一影格產生動畫。

**限制與行為：**

* 總共最多可連接 10 個影格，包含第一影格、每個中間影格與最後影格。
* 影片會採用第一個關鍵影格的長寬比，因此不需要長寬比輸入。
* 每個影格必須至少為 300x300 像素，且長寬比介於 2:5 與 5:2 之間。
* 若提示詞提及 `@ImageN`，但連接的影格數少於 N，則會引發錯誤。
