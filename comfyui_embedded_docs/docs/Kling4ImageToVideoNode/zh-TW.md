# Kling 4.0 影像轉影片

使用 Kling 4.0 模型從一組關鍵幀生成影片，並包含音訊。第一幀、最多八個中間幀與最後一幀會依序送出，中間幀會均勻分佈於整個片段中，輸出會採用第一個關鍵幀的長寬比。可用於將單張影像製作成動畫，或透過一連串關鍵時刻引導鏡頭。

### kling-4.0-flash 輸入

當 `model` 設為 `"kling-4.0-flash"` 時會顯示這些輸入。Flash 會為單一第一幀製作動畫。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 影片起始的幀。 | IMAGE | 是 | - |
| `prompt` | 動作的選用描述。請以 `@Image1` 引用第一幀。預設：空字串。 | STRING | 是 | 多行文字 |
| `resolution` | 輸出影片的解析度。Flash 僅以 720p 渲染。預設：`"720p"`。 | COMBO | 是 | `"720p"` |
| `duration` | 生成影片的長度，以秒為單位。預設：5。 | INT | 是 | 3 至 20 |
| `seed` | 種子會控制節點是否應重新執行；無論種子為何，結果皆不具確定性。預設：42。 | INT | 是 | 0 至 2147483647 |

**限制與行為：**

* 總共最多可連接 10 幀，包含第一幀、每個中間幀與最後一幀。
* 影片會採用第一個關鍵幀的長寬比，因此不需要長寬比輸入。
* 每一幀至少須為 300x300 像素，且長寬比介於 2:5 至 5:2 之間。
* 當連接的幀數少於 N 時，提示詞中提及 `@ImageN` 會引發錯誤。
