# Kling 4.0 Image to Video

使用 Kling 4.0 模型從一組關鍵影格生成包含音訊的影片。第一影格、最多八個中間影格與最後影格會依序送出，中間影格會均勻分佈於片段中，且輸出會採用第一個關鍵影格的長寬比。可用於讓單張影像產生動畫，或透過一系列關鍵時刻引導鏡頭。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型選擇器。僅可使用 `"kling-4.0"`；選取後會顯示下方輸入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 輸入

當 `model` 設為 `"kling-4.0"` 時會顯示這些輸入。至少必須連接一個影格輸入。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 選用；影片起始的影格。 | IMAGE | 否 | - |
| `middle_frames` | 選用；用於第一影格與最後影格之間影格的可增長插槽，最多 8 個。這些影格會均勻分佈於片段中。 | AUTOGROW | 否 | 0 到 8 張影像 |
| `last_frame` | 選用；影片結束的影格。 | IMAGE | 否 | - |
| `prompt` | 選用；動作描述。請依第一影格、中間影格、最後影格的順序，以 `@Image1`、`@Image2` 等方式指稱已連接的影格。預設：空字串。 | STRING | 是 | 多行文字 |
| `resolution` | 輸出影片的解析度。預設：`"720p"`。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `duration` | 生成影片的長度，單位為秒。預設：5。 | INT | 是 | 3 到 30 |
| `seed` | 種子控制節點是否應重新執行；無論種子為何，結果皆不具確定性。預設：42。 | INT | 是 | 0 到 2147483647 |

**限制與行為：**

* 總共最多可連接 10 個影格，計算包含第一影格、每個中間影格與最後影格。
* 影片會採用第一個關鍵影格的長寬比，因此不需要長寬比輸入。
* 每個影格必須至少為 300x300 像素，且長寬比介於 2:5 與 5:2 之間。
* 當連接的影格數少於 N 時，若提示詞提及 `@ImageN` 會引發錯誤。
