# Kling 4.0 Image to Video

Генерирует видео из набора ключевых кадров с помощью модели Kling 4.0, включая аудио. Первый кадр, до восьми промежуточных кадров и последний кадр передаются по порядку; промежуточные кадры равномерно распределяются по клипу, а выходное видео принимает соотношение сторон первого ключевого кадра. Используйте это для анимации одного изображения или для управления сценой через последовательность ключевых моментов.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Селектор модели. Доступна только `"kling-4.0"`; при её выборе отображаются входы ниже. | DYNAMIC_COMBO | Да | `"kling-4.0"` |

### Входы kling-4.0

Эти входы появляются, когда `model` установлен в `"kling-4.0"`. Должен быть подключён хотя бы один из входов кадров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Необязательный кадр, с которого начинается видео. | IMAGE | Нет | - |
| `middle_frames` | Необязательные расширяемые слоты для кадров между первым и последним, до 8. Они равномерно распределяются по клипу. | AUTOGROW | Нет | от 0 до 8 изображений |
| `last_frame` | Необязательный кадр, на котором видео заканчивается. | IMAGE | Нет | - |
| `prompt` | Необязательное описание движения. Ссылайтесь на подключённые кадры как `@Image1`, `@Image2` и т. д. в порядке: первый кадр, промежуточные кадры, последний кадр. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 30 |
| `seed` | Параметр `seed` управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения и поведение:**

* Всего можно подключить не более 10 кадров, считая первый кадр, каждый промежуточный кадр и последний кадр.
* Видео наследует соотношение сторон первого ключевого кадра, поэтому вход для соотношения сторон не требуется.
* Каждый кадр должен быть не меньше 300x300 пикселей, а соотношение сторон должно быть в диапазоне от 2:5 до 5:2.
* Промпт, в котором упоминается `@ImageN`, вызывает ошибку, если подключено меньше N кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загружаемое от провайдера после завершения задачи. | VIDEO |
