# Kling 4.0 Изображение в видео

Генерирует видео из набора ключевых кадров с помощью модели Kling 4.0, включая аудио. Первый кадр, до восьми средних кадров и последний кадр отправляются по порядку; средние кадры равномерно распределяются по клипу, а выходное видео принимает соотношение сторон первого ключевого кадра. Используйте это для анимации одного изображения или для управления сценой через последовательность ключевых моментов.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Селектор модели. `"kling-4.0"` поддерживает до 1080p и 30 секунд; `"kling-4.0-flash"` ограничен 720p, 20 секундами и одним первым кадром. Выбор модели открывает соответствующие входы ниже. | DYNAMIC_COMBO | Да | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### Входы kling-4.0

Эти входы появляются, когда для `model` задано значение `"kling-4.0"`. Должен быть подключён хотя бы один из входов кадров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Необязательный кадр, с которого начинается видео. | IMAGE | Нет | - |
| `middle_frames` | Необязательные расширяемые слоты для кадров между первым и последним, до 8. Они равномерно распределяются по клипу. | AUTOGROW | Нет | от 0 до 8 изображений |
| `last_frame` | Необязательный кадр, которым заканчивается видео. | IMAGE | Нет | - |
| `prompt` | Необязательное описание движения. Ссылайтесь на подключённые кадры как `@Image1`, `@Image2` и так далее в порядке: первый кадр, средние кадры, последний кадр. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 30 |
| `seed` | Сид управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы kling-4.0-flash

Эти входы появляются, когда для `model` задано значение `"kling-4.0-flash"`. Flash анимирует один первый кадр.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Кадр, с которого начинается видео. | IMAGE | Да | - |
| `prompt` | Необязательное описание движения. Ссылайтесь на первый кадр как `@Image1`. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. Flash рендерит только 720p. По умолчанию: `"720p"`. | COMBO | Да | `"720p"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 20 |
| `seed` | Сид управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения и поведение:**

* Всего можно подключить не более 10 кадров, считая первый кадр, каждый средний кадр и последний кадр.
* Видео принимает соотношение сторон первого ключевого кадра, поэтому вход соотношения сторон не требуется.
* Каждый кадр должен быть не меньше 300x300 пикселей с соотношением сторон от 2:5 до 5:2.
* Промпт, в котором упоминается `@ImageN`, вызывает ошибку, если подключено меньше N кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загружаемое от провайдера после завершения задачи. | VIDEO |
