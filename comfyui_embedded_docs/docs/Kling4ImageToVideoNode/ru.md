# Kling 4.0 Изображение в видео

Создаёт видео из набора ключевых кадров с помощью модели Kling 4.0, включая аудио. Первый кадр, до восьми промежуточных кадров и последний кадр передаются по порядку; промежуточные кадры равномерно распределяются по клипу, а выходное видео наследует соотношение сторон первого ключевого кадра. Используйте его для анимации одного изображения или для управления сценой через последовательность ключевых моментов.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Селектор модели. `"kling-4.0"` поддерживает до 4K HDR и 30 секунд; `"kling-4.0-flash"` ограничена 720p, 20 секундами и одним первым кадром. При выборе модели ниже отображаются её входы. | DYNAMIC_COMBO | Да | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### Входы kling-4.0

Эти входы отображаются, когда для `model` задано значение `"kling-4.0"`. Должен быть подключён хотя бы один из входов кадров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Необязательный кадр, с которого начинается видео. | IMAGE | Нет | - |
| `middle_frames` | Необязательные расширяемые слоты для кадров между первым и последним, до 8. Они равномерно распределяются по клипу. | AUTOGROW | Нет | от 0 до 8 изображений |
| `last_frame` | Необязательный кадр, на котором заканчивается видео. | IMAGE | Нет | - |
| `prompt` | Необязательное описание движения. Ссылайтесь на подключённые кадры как `@Image1`, `@Image2` и т. д. в порядке: первый кадр, промежуточные кадры, последний кадр. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео; вариант с `HDR` в названии возвращает видео HDR. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"`<br>`"4k"`<br>`"1080p HDR"`<br>`"4k HDR"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 30 |
| `seed` | Параметр seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы kling-4.0-flash

Эти входы отображаются, когда для `model` задано значение `"kling-4.0-flash"`. Flash анимирует один первый кадр.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Кадр, с которого начинается видео. | IMAGE | Да | - |
| `prompt` | Необязательное описание движения. Ссылайтесь на первый кадр как `@Image1`. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. Flash поддерживает только 720p. По умолчанию: `"720p"`. | COMBO | Да | `"720p"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 20 |
| `seed` | Параметр seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения и поведение:**

* Всего можно подключить не более 10 кадров, считая первый кадр, каждый промежуточный кадр и последний кадр.
* Видео наследует соотношение сторон первого ключевого кадра, поэтому вход соотношения сторон не требуется.
* Каждый кадр должен быть не меньше 300x300 пикселей с соотношением сторон от 2:5 до 5:2.
* Если в prompt упоминается `@ImageN`, а подключено меньше N кадров, возникает ошибка.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загружаемое от провайдера после завершения задачи. | VIDEO |
