# Kling 4.0 תמונה לווידאו

מייצר וידאו מקבוצה של פריימי מפתח עם מודל Kling 4.0, כולל אודיו. הפריים הראשון, עד שמונה פריימים אמצעיים והפריים האחרון נשלחים לפי הסדר, פריימי הביניים מרווחים באופן אחיד לאורך הקליפ, והפלט מקבל את יחס הגובה-רוחב של פריים המפתח הראשון. השתמשו בו כדי להנפיש תמונה אחת או כדי לנווט צילום דרך רצף של רגעי מפתח.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `מודל` | בורר מודל. `"kling-4.0"` תומך עד 1080p ו-30 שניות; `"kling-4.0-flash"` מוגבל ל-720p, 20 שניות ולפריים ראשון יחיד. בחירת מודל מציגה את הקלטים שלו להלן. | DYNAMIC_COMBO | כן | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### קלטים של kling-4.0

קלטים אלה מופיעים כאשר `model` מוגדר ל-`"kling-4.0"`. לפחות אחד מקלטי הפריימים חייב להיות מחובר.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | פריים אופציונלי שבו הווידאו מתחיל. | IMAGE | לא | - |
| `middle_frames` | חריצים אופציונליים הניתנים להרחבה עבור פריימים בין הראשון לאחרון, עד 8. הם מרווחים באופן אחיד לאורך הקליפ. | AUTOGROW | לא | 0 עד 8 תמונות |
| `last_frame` | פריים אופציונלי שבו הווידאו מסתיים. | IMAGE | לא | - |
| `prompt` | תיאור אופציונלי של התנועה. התייחסו לפריימים המחוברים כ-`@Image1`, `@Image2` וכן הלאה, לפי הסדר: פריים ראשון, פריימים אמצעיים, פריים אחרון. ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `resolution` | רזולוציית וידאו הפלט. ברירת מחדל: `"720p"`. | COMBO | כן | `"720p"`<br>`"1080p"` |
| `duration` | אורך הווידאו שנוצר בשניות. ברירת מחדל: 5. | INT | כן | 3 עד 30 |
| `seed` | ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

### קלטים של kling-4.0-flash

קלטים אלה מופיעים כאשר `model` מוגדר ל-`"kling-4.0-flash"`. Flash מנפיש פריים ראשון יחיד.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | הפריים שבו הווידאו מתחיל. | IMAGE | כן | - |
| `prompt` | תיאור אופציונלי של התנועה. התייחסו לפריים הראשון כ-`@Image1`. ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `resolution` | רזולוציית וידאו הפלט. Flash מרנדר רק 720p. ברירת מחדל: `"720p"`. | COMBO | כן | `"720p"` |
| `duration` | אורך הווידאו שנוצר בשניות. ברירת מחדל: 5. | INT | כן | 3 עד 20 |
| `seed` | ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים והתנהגות:**

* ניתן לחבר בסך הכול עד 10 פריימים, כולל הפריים הראשון, כל פריים אמצעי והפריים האחרון.
* הווידאו מקבל את יחס הגובה-רוחב של פריים המפתח הראשון, ולכן אין צורך בקלט של יחס גובה-רוחב.
* כל פריים חייב להיות בגודל של לפחות 300x300 פיקסלים, עם יחס גובה-רוחב בין 2:5 ל-5:2.
* פרומפט שמזכיר `@ImageN` גורם לשגיאה כאשר מחוברים פחות מ-N פריימים.
