# Kling 4.0 תמונה לווידאו

יוצר סרטון מתוך קבוצה של פריימים מפתח באמצעות מודל Kling 4.0, כולל אודיו. הפריים הראשון, עד שמונה פריימים אמצעיים והפריים האחרון נשלחים לפי הסדר, הפריימים האמצעיים מרווחים באופן שווה לאורך הקליפ, והפלט מקבל את יחס הגובה-רוחב של פריים המפתח הראשון. השתמש בו כדי להנפיש תמונה אחת או כדי לכוון שוט דרך רצף של רגעי מפתח.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | בורר מודל. `"kling-4.0"` תומך בעד 4K HDR ובעד 30 שניות; `"kling-4.0-flash"` מוגבל ל-720p, ל-20 שניות ולפריים ראשון יחיד. בחירת מודל חושפת את הקלטים שלו בהמשך. | DYNAMIC_COMBO | כן | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### קלטים של kling-4.0

קלטים אלו מופיעים כאשר `model` מוגדר ל-`"kling-4.0"`. לפחות אחד מקלטי הפריימים חייב להיות מחובר.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | פריים אופציונלי שבו הסרטון מתחיל. | IMAGE | לא | - |
| `middle_frames` | משבצות אופציונליות הניתנות להרחבה עבור פריימים בין הראשון לאחרון, עד 8. הן מרווחות באופן שווה לאורך הקליפ. | AUTOGROW | לא | 0 עד 8 תמונות |
| `last_frame` | פריים אופציונלי שבו הסרטון מסתיים. | IMAGE | לא | - |
| `prompt` | תיאור אופציונלי של התנועה. התייחס לפריימים המחוברים בתור `@Image1`, `@Image2` וכך הלאה, לפי הסדר: פריים ראשון, פריימים אמצעיים, פריים אחרון. ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `resolution` | רזולוציית סרטון הפלט; אפשרות ששם שלה מכיל `HDR` מחזירה סרטון HDR. ברירת מחדל: `"720p"`. | COMBO | כן | `"720p"`<br>`"1080p"`<br>`"4k"`<br>`"1080p HDR"`<br>`"4k HDR"` |
| `duration` | אורך הסרטון שנוצר בשניות. ברירת מחדל: 5. | INT | כן | 3 עד 30 |
| `seed` | `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

### קלטים של kling-4.0-flash

קלטים אלו מופיעים כאשר `model` מוגדר ל-`"kling-4.0-flash"`. Flash יוצר אנימציה מפריים ראשון יחיד.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | הפריים שבו הסרטון מתחיל. | IMAGE | כן | - |
| `prompt` | תיאור אופציונלי של התנועה. התייחס לפריים הראשון בתור `@Image1`. ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `resolution` | רזולוציית סרטון הפלט. Flash מרנדר רק 720p. ברירת מחדל: `"720p"`. | COMBO | כן | `"720p"` |
| `duration` | אורך הסרטון שנוצר בשניות. ברירת מחדל: 5. | INT | כן | 3 עד 20 |
| `seed` | `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים והתנהגות:**

* לכל היותר ניתן לחבר 10 פריימים בסך הכול, כולל הפריים הראשון, כל פריים אמצעי והפריים האחרון.
* הסרטון מקבל את יחס הגובה-רוחב של פריים המפתח הראשון, לכן אין צורך בקלט של יחס גובה-רוחב.
* כל פריים חייב להיות בגודל של לפחות 300x300 פיקסלים, עם יחס גובה-רוחב בין 2:5 ל-5:2.
* פרומפט שמזכיר `@ImageN` מעלה שגיאה כאשר מחוברים פחות מ-N פריימים.
