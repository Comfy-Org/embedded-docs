# HeyGen 아바타 비디오

Generate a talking-presenter video from a HeyGen avatar. This node creates a video of an AI avatar speaking your provided text or lip-syncing to your own audio, using HeyGen's rendering engines.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `엔진` | 렌더링 엔진입니다. 각 선택 항목은 해당 엔진을 지원하는 아바타만 나열합니다. "auto"는 모든 아바타를 제공하며 각 아바타에 가장 적합한 엔진(Avatar IV 우선)을 선택합니다. Avatar V는 품질이 가장 높고, Avatar III는 가장 저렴합니다. | DYNAMIC_COMBO | 예 | `"auto"`<br>`"avatar_iv"`<br>`"avatar_iii"`<br>`"avatar_v"` |
| `커스텀 아바타 ID` | 선택적인 HeyGen 아바타 룩 ID입니다. 설정하면 위에서 선택한 아바타를 재정의합니다. HeyGen의 공개 룩 3,000여 개(또는 사용자의 비공개 아바타) 중 무엇이든 사용할 수 있습니다. 기본값: 빈 문자열. | STRING | 아니요 |  |
| `음성` | 텍스트 스크립트(HeyGen 텍스트 음성 변환) 또는 사용자 오디오로 아바타를 구동합니다. | DYNAMIC_COMBO | 예 | `"script"`<br>`"audio"` |
| `해상도` | 출력 비디오 해상도입니다. 기본값: `"1080p"`. | COMBO | 아니요 | `"720p"`<br>`"1080p"` |
| `화면 비율` | 출력 화면 비율입니다. "auto"는 아바타의 원본 영상을 따릅니다. 기본값: `"auto"`. | COMBO | 아니요 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `배경 색상` | 선택적인 단색 배경색(16진수 코드, 예: `"#00ff00"`)입니다. 비워 두면 아바타의 기본 배경이 사용됩니다. 값을 지정할 경우 `#`로 시작해야 합니다. 기본값: 빈 문자열. | STRING | 아니요 |  |
| `시드` | HeyGen에 전송되지 않습니다. 값을 변경하면 재실행을 강제합니다. 기본값: `42`. | INT | 아니요 | 최소: 0<br>최대: 2147483647 |

### `auto` 입력

`engine`이 `"auto"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | 비디오를 발표하는 아바타 룩입니다(HeyGen 공개 라이브러리에서 선별). 룩이 지원하는 최적의 엔진이 자동으로 선택됩니다. | COMBO | 예 | 선택 가능한 여러 옵션 |

### `avatar_iv` 입력

`engine`이 `"avatar_iv"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar IV 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 선택 가능한 여러 옵션 |

### `avatar_iii` 입력

`engine`이 `"avatar_iii"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar III 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 선택 가능한 여러 옵션 |

### `avatar_v` 입력

`engine`이 `"avatar_v"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar V 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 선택 가능한 여러 옵션 |

### `script` 입력

`speech`가 `"script"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text` | 아바타가 발화할 텍스트입니다(최대 5,000자). 생성된 음성은 최소 1초 이상이어야 합니다. 기본값: 빈 문자열. | STRING | 예 | 최소: 1자<br>최대: 5000자 |
| `voice` | 스크립트의 음성입니다. 기본 옵션은 HeyGen이 아바타에 할당한 음성을 사용합니다. | COMBO | 예 | `"(avatar's default voice)"`<br>일반 음성 옵션 다수 |
| `custom_voice_id` | 선택적인 HeyGen 음성 ID입니다. 설정하면 위에서 선택한 음성을 재정의합니다. HeyGen 라이브러리의 모든 음성(2,000개 이상)을 사용할 수 있습니다. 기본값: 빈 문자열. | STRING | 아니요 |  |
| `voice_speed` | 음성 속도 배율입니다. 기본값: `1.0`. | FLOAT | 아니요 | 최소: 0.5<br>최대: 1.5<br>단계: 0.05 |

### `audio` 입력

`speech`가 `"audio"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 아바타가 입모양을 맞출 오디오입니다. 최대 10분까지 지원합니다. | AUDIO | 예 |  |

참고: `speech`는 상호 배타적인 두 모드를 가진 소스 선택기입니다. `"script"` 모드에서는 `text`가 필수이며(1~5,000자), `custom_voice_id`가 제공되면 `voice`를 재정의합니다. `"audio"` 모드에서는 아바타가 제공된 오디오 클립에 입모양을 맞춥니다. `background_color`는 제공될 때 `#`로 시작하는 16진수 색상 코드여야 합니다. `custom_avatar_id`가 설정되면 `avatar` 선택을 재정의하며, 선택한 `engine`이 해당 아바타 룩에서 지원되어야 하고, 그렇지 않으면 오류가 발생합니다(`engine`이 `"auto"`인 경우 제외).
