# HeyGen 虚拟人视频

使用 HeyGen 的渲染引擎，从 HeyGen 虚拟形象生成一个会说话的主持人视频。此节点创建一段 AI 虚拟形象视频，该形象会讲述您提供的文本，或对您自己的音频进行口型同步。
