# HeyGen Аватар Видео

```markdown
Создайте видео с говорящим ведущим из аватара HeyGen. Этот узел создает видео с ИИ-аватаром, который произносит ваш текст или синхронизирует губы с вашим аудио, используя рендер-движки HeyGen.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `движок` | Рендер-движок; каждый вариант выбора показывает только аватары, которые его поддерживают. `"auto"` предлагает всех аватаров и автоматически выбирает лучший движок (предпочтительно Avatar IV). Avatar V — самое высокое качество, Avatar III — самый доступный. | DYNAMIC_COMBO | Да | `"auto"`<br>`"avatar_iv"`<br>`"avatar_iii"`<br>`"avatar_v"` |
| `custom_avatar_id` | Необязательный ID образа аватара HeyGen. Если задан, переопределяет выбранный выше аватар. Можно использовать любой из более чем 3000 публичных образов HeyGen (или ваши приватные аватары). По умолчанию: `""`. | STRING | Нет |  |
| `речь` | Управляйте аватаром с помощью текстового сценария (HeyGen text-to-speech) или собственного аудио. Отображаемое имя: «speech source». | DYNAMIC_COMBO | Да | `"script"`<br>`"audio"` |
| `разрешение` | Разрешение выходного видео. По умолчанию: `"1080p"`. | COMBO | Нет | `"720p"`<br>`"1080p"` |
| `соотношение сторон` | Соотношение сторон выходного видео. `"auto"` следует исходному материалу аватара. По умолчанию: `"auto"`. | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `цвет фона` | Необязательный сплошной цвет фона в виде hex-кода (например, `"#00ff00"`). Оставьте пустым, чтобы использовать собственный фон аватара. Если задан, значение должно начинаться с `#`. По умолчанию: `""`. | STRING | Нет |  |
| `seed` | Не отправляется в HeyGen; измените его, чтобы принудительно перезапустить. По умолчанию: `42`. | INT | Нет | Мин: 0<br>Макс: 2147483647 |

### Входы `auto`

Когда `engine` равен `"auto"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образ аватара для представления видео (подобран из публичной библиотеки HeyGen). Лучший движок, поддерживаемый этим образом, выбирается автоматически. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iv`

Когда `engine` равен `"avatar_iv"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, поддерживающие движок Avatar IV. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iii`

Когда `engine` равен `"avatar_iii"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, поддерживающие движок Avatar III. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_v`

Когда `engine` равен `"avatar_v"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, поддерживающие движок Avatar V. | COMBO | Да | Доступно несколько вариантов |

### Входы `script`

Когда `speech` равен `"script"`, доступны следующие подпараметры:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст для воспроизведения аватаром (до 5000 символов). Сгенерированная речь должна быть не короче 1 секунды. По умолчанию: `""`. | STRING | Да | Мин: 1 символ<br>Макс: 5000 символов |
| `voice` | Голос для сценария. Вариант по умолчанию использует голос, назначенный HeyGen для аватара. Игнорируется, если задан `custom_voice_id`. | COMBO | Да | `"(avatar's default voice)"`<br>Доступно несколько общих голосовых вариантов |
| `custom_voice_id` | Необязательный ID голоса HeyGen. Если задан, переопределяет выбранный выше голос. Можно использовать любой голос из библиотеки HeyGen (более 2000). По умолчанию: `""`. | STRING | Нет |  |
| `voice_speed` | Множитель скорости речи. По умолчанию: `1.0`. | FLOAT | Нет | Мин: 0.5<br>Макс: 1.5<br>Шаг: 0.05 |

### Входы `audio`

Когда `speech` равен `"audio"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для синхронизации губ аватара, до 10 минут. | AUDIO | Да |  |

Примечание: `engine` и `speech` являются селекторами, которые открывают разные подпараметры в зависимости от выбранного значения. Селектор `speech` имеет два взаимоисключающих режима: в режиме `"script"` требуется `text`; если указан `custom_voice_id`, он переопределяет `voice`. В режиме `"audio"` аватар синхронизирует губы с предоставленным аудиоклипом. `background_color` должен быть hex-кодом цвета, начинающимся с `#`, если он задан. Когда указан `custom_avatar_id`, он переопределяет выбор `avatar`, и выбранный `engine` должен поддерживаться этим образом аватара; в противном случае будет вызвана ошибка, если только `engine` не равен `"auto"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео с аватаром-ведущим. | VIDEO |
```
