# HeyGen Аватар Видео

Создание видео с говорящим ведущим на основе аватара HeyGen. Этот узел создаёт видео, на котором AI-аватар произносит заданный текст или синхронизирует губы с вашим аудио, используя механизмы рендеринга HeyGen.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `движок` | Механизм рендеринга; каждый вариант перечисляет только те аватары, которые его поддерживают. `"auto"` предлагает всех аватаров и автоматически выбирает для них наилучший механизм (предпочтительно Avatar IV). Avatar V обеспечивает наивысшую точность, Avatar III — самый доступный по цене. | DYNAMIC_COMBO | Да | `"auto"`<br>`"avatar_iv"`<br>`"avatar_iii"`<br>`"avatar_v"` |
| `custom_avatar_id` | Необязательный идентификатор внешности аватара HeyGen. Если задан, переопределяет выбранный выше аватар. Можно использовать любую из более чем 3000 публичных внешностей HeyGen (или ваших приватных аватаров). По умолчанию: пустая строка. | STRING | Нет |  |
| `речь` | Управление аватаром с помощью текстового сценария (HeyGen text-to-speech) или вашего собственного аудио. | DYNAMIC_COMBO | Да | `"script"`<br>`"audio"` |
| `разрешение` | Разрешение выходного видео. По умолчанию: `"1080p"`. | COMBO | Нет | `"720p"`<br>`"1080p"` |
| `соотношение сторон` | Соотношение сторон выходного видео. `"auto"` соответствует исходным кадрам аватара. По умолчанию: `"auto"`. | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `цвет фона` | Необязательный сплошной цвет фона в виде шестнадцатеричного кода (например, `"#00ff00"`). Оставьте пустым, чтобы использовать собственный фон аватара. Если задан, значение должно начинаться с `#`. По умолчанию: пустая строка. | STRING | Нет |  |
| `seed` | Не отправляется в HeyGen; измените его, чтобы принудительно запустить повторное выполнение. По умолчанию: `42`. | INT | Нет | Мин: 0<br>Макс: 2147483647 |

### Входы `auto`

Когда `engine` имеет значение `"auto"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Внешность аватара для презентации видео (подобранная из публичной библиотеки HeyGen). Лучший механизм, поддерживаемый этой внешностью, выбирается автоматически. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iv`

Когда `engine` имеет значение `"avatar_iv"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Внешности аватаров, поддерживающие механизм Avatar IV. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iii`

Когда `engine` имеет значение `"avatar_iii"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Внешности аватаров, поддерживающие механизм Avatar III. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_v`

Когда `engine` имеет значение `"avatar_v"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Внешности аватаров, поддерживающие механизм Avatar V. | COMBO | Да | Доступно несколько вариантов |

### Входы `script`

Когда `speech` имеет значение `"script"`, доступны следующие подпараметры:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст, который должен произнести аватар (до 5000 символов). Сгенерированная речь должна быть не короче 1 секунды. По умолчанию: пустая строка. | STRING | Да | Мин: 1 символ<br>Макс: 5000 символов |
| `voice` | Голос для сценария. Вариант по умолчанию использует голос, назначенный аватару в HeyGen. | COMBO | Да | `"(avatar's default voice)"`<br>Доступно несколько общих голосовых опций |
| `custom_voice_id` | Необязательный идентификатор голоса HeyGen. Если задан, переопределяет выбранный выше голос. Можно использовать любой голос из библиотеки HeyGen (более 2000). По умолчанию: пустая строка. | STRING | Нет |  |
| `voice_speed` | Множитель скорости речи. По умолчанию: `1.0`. | FLOAT | Нет | Мин: 0.5<br>Макс: 1.5<br>Шаг: 0.05 |

### Входы `audio`

Когда `speech` имеет значение `"audio"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для синхронизации губ аватара, до 10 минут. | AUDIO | Да |  |

Примечание: `speech` — это выбор источника с двумя взаимоисключающими режимами. В режиме `"script"` параметр `text` обязателен (от 1 до 5000 символов); если указан `custom_voice_id`, он переопределяет `voice`. В режиме `"audio"` аватар синхронизирует губы с предоставленным аудиоклипом. `background_color` при задании должен быть шестнадцатеричным кодом цвета, начинающимся с `#`. Когда задан `custom_avatar_id`, он переопределяет выбор `avatar`, и выбранный `engine` должен поддерживаться этой внешностью аватара; в противном случае возникает ошибка (если только `engine` не равен `"auto"`).
