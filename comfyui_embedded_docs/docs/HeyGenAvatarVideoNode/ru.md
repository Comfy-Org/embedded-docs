# HeyGen Аватар Видео

Создаёт видео с говорящим ведущим на основе аватара HeyGen. Этот узел создаёт видео, на котором ИИ-аватар произносит предоставленный вами текст или синхронизирует губы с вашим собственным аудио, используя движки рендеринга HeyGen.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `движок` | Движок рендеринга; каждый вариант перечисляет только тех аватаров, которые его поддерживают. `"auto"` предлагает всех аватаров и выбирает для них лучший движок (предпочтительно Avatar IV). Avatar V обеспечивает наивысшее качество, Avatar III — самый доступный. | DYNAMIC_COMBO | Да | `"auto"`<br>`"avatar_iv"`<br>`"avatar_iii"`<br>`"avatar_v"` |
| `custom_avatar_id` | Необязательный ID образа аватара HeyGen. Если задан, переопределяет аватар, выбранный выше. Можно использовать любой из более чем 3000 публичных образов HeyGen (или ваши приватные аватары). По умолчанию: `""`. | STRING | Нет |  |
| `речь` | Управляет аватаром с помощью текстового сценария (синтез речи HeyGen) или вашего собственного аудио. Отображаемое имя: «speech source». | DYNAMIC_COMBO | Да | `"script"`<br>`"audio"` |
| `разрешение` | Разрешение выходного видео. По умолчанию: `"1080p"`. | COMBO | Нет | `"720p"`<br>`"1080p"` |
| `соотношение сторон` | Соотношение сторон выходного видео. `"auto"` соответствует исходному видеоматериалу аватара. По умолчанию: `"auto"`. | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `цвет фона` | Необязательный сплошной цвет фона в виде hex-кода (например, `"#00ff00"`). Оставьте пустым, чтобы использовать собственный фон аватара. Если указан, значение должно начинаться с `#`. По умолчанию: `""`. | STRING | Нет |  |
| `seed` | Не отправляется в HeyGen; измените его, чтобы принудительно запустить повторно. По умолчанию: `42`. | INT | Нет | Мин.: 0<br>Макс.: 2147483647 |

### Входы `auto`

Когда `engine` имеет значение `"auto"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образ аватара для представления видео (выбранный из публичной библиотеки HeyGen). Лучший движок, который поддерживает этот образ, выбирается автоматически. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iv`

Когда `engine` имеет значение `"avatar_iv"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, которые поддерживают движок Avatar IV. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_iii`

Когда `engine` имеет значение `"avatar_iii"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, которые поддерживают движок Avatar III. | COMBO | Да | Доступно несколько вариантов |

### Входы `avatar_v`

Когда `engine` имеет значение `"avatar_v"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Образы аватаров, которые поддерживают движок Avatar V. | COMBO | Да | Доступно несколько вариантов |

### Входы `script`

Когда `speech` имеет значение `"script"`, доступны следующие подпараметры:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст, который аватар должен произнести (до 5000 символов). Сгенерированная речь должна быть длительностью не менее 1 секунды. По умолчанию: `""`. | STRING | Да | Мин.: 1 символ<br>Макс.: 5000 символов |
| `voice` | Голос для сценария. Вариант по умолчанию использует голос, назначенный аватару в HeyGen. Игнорируется, если задан `custom_voice_id`. | COMBO | Да | `"(avatar's default voice)"`<br>Доступно несколько общих вариантов голоса |
| `custom_voice_id` | Необязательный ID голоса HeyGen. Если задан, переопределяет голос, выбранный выше. Можно использовать любой голос из библиотеки HeyGen (более 2000). По умолчанию: `""`. | STRING | Нет |  |
| `voice_speed` | Множитель скорости речи. По умолчанию: `1.0`. | FLOAT | Нет | Мин.: 0.5<br>Макс.: 1.5<br>Шаг: 0.05 |

### Входы `audio`

Когда `speech` имеет значение `"audio"`, доступен следующий подпараметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио, под которое аватар будет синхронизировать губы, длительностью до 10 минут. | AUDIO | Да |  |

Примечание: `engine` и `speech` — это селекторы, которые показывают разные подпараметры в зависимости от выбранного значения. Селектор `speech` имеет два взаимоисключающих режима: в режиме `"script"` требуется `text`; если указан `custom_voice_id`, он переопределяет `voice`. В режиме `"audio"` аватар синхронизирует губы с предоставленным аудиоклипом. `background_color` при указании должен быть hex-кодом цвета, начинающимся с `#`. Если задан `custom_avatar_id`, он переопределяет выбор `avatar`, и выбранный `engine` должен поддерживаться этим образом аватара; в противном случае возникает ошибка, если только `engine` не имеет значение `"auto"`.
