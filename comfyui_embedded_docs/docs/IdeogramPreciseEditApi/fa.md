# Ideogram 4.5 Precise Edit

ویرایش یک تصویر با راهنمایی پرامپت متنی و با ویرایش دقیق Ideogram 4.5: فقط چیزی که پرامپت درخواست می‌کند تغییر می‌کند، پیکسل‌های دست‌نخورده یکسان می‌مانند، و خروجی اندازه تصویر ۱ را حفظ می‌کند. تصویر ۱ همان تصویری است که باید ویرایش شود و حداکثر ۴ تصویر دیگر می‌توانند به‌عنوان مرجع متصل شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که باید استفاده شود. (پیش‌فرض: `"ideogram-4.5"`) | DYNAMIC_COMBO | بله | `"ideogram-4.5"` |
| `images` | جای‌گاه قابل‌افزایش: تصویر ۱ همان تصویری است که باید ویرایش شود و تصاویر ۲ تا ۵ مرجع‌های اختیاری هستند (`image_1` ... `image_5`). در پرامپت با @Image1، @Image2، ... به آن‌ها ارجاع دهید؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود. هر تصویر باید نسبت ابعادی بین ۱:۶ و ۶:۱ داشته باشد. | IMAGE | بله | 1 تا 5 تصویر |
| `prompt` | دستورالعمل‌های ویرایش. از ارجاع‌های به‌سبک @Image1 به تصاویر متصل پشتیبانی می‌کند. (پیش‌فرض: رشته خالی) | STRING | بله | 1 تا 10000 کاراکتر |
| `quality` | سطح کیفیت. سطوح بالاتر هزینه بیشتری دارند و زمان بیشتری می‌برند. (پیش‌فرض: `"medium"`) | COMBO | بله | `"very_low"`<br>`"low"`<br>`"medium"`<br>`"high"` |
| `seed` | بذر تصادفی برای تولید. تصاویر، پرامپت، تنظیمات و بذر یکسان نتیجه یکسانی می‌دهند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

### محدودیت‌های پارامترها

- **تعداد تصاویر:** حداقل ۱ و حداکثر ۵ تصویر؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود. تصویر ۱ همان تصویری است که باید ویرایش شود و تصاویر ۲ تا ۵ مرجع هستند.
- **اندازه خروجی:** نتیجه اندازه تصویر ۱ را حفظ می‌کند، بنابراین این گره هیچ ورودی اندازه، عرض یا ارتفاع ندارد.
- **نسبت ابعاد تصویر:** هر تصویر نباید بیش از ۶ برابر ارتفاعش عرض داشته باشد و نه بیش از ۶ برابر عرضش ارتفاع (بین ۱:۶ و ۶:۱).
- **برچسب‌های پرامپت:** `@ImageN` بدون حساسیت به بزرگی و کوچکی حروف تطبیق داده می‌شود و نباید از تعداد تصاویر متصل بیشتر باشد؛ پرامپت باید شامل حداقل یک نویسه غیرفاصله باشد و حداکثر ۱۰۰۰۰ کاراکتر طول داشته باشد.
- **مقیاس‌بندی هنگام بارگذاری:** تصاویر بزرگ‌تر از حدود ۴ مگاپیکسل، یا بزرگ‌تر از ۴۶۰۸ پیکسل در ضلع بلند، پیش از ارسال کوچک‌سازی می‌شوند.
- **ایمنی محتوا:** اگر فیلتر ایمنی محتوای Ideogram نتیجه را مسدود کند، گره به‌جای بازگرداندن تصویر خطا می‌دهد.
