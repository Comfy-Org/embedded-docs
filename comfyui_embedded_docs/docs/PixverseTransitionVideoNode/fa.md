# ویدیوی انتقالی PixVerse

با استفاده از PixVerse API، ویدیوی انتقالی بین دو تصویر ورودی تولید می‌کند. شما یک تصویر شروع و یک تصویر پایان ارائه می‌دهید و گره با راهنمایی متن prompt و تنظیمات انتخابی شما، ویدیوی روانی می‌سازد که از یکی به دیگری انتقال می‌یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `فریم اول` | تصویر شروع برای انتقال ویدیو | IMAGE | بله | - |
| `فریم آخر` | تصویر پایان برای انتقال ویدیو | IMAGE | بله | - |
| `پرامپت` | فرمان تولید ویدیو (پیش‌فرض: رشته خالی) | STRING | بله | - |
| `کیفیت` | تنظیم کیفیت ویدیو (پیش‌فرض: `"540p"`) | COMBO | بله | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `مدت زمان (ثانیه)` | مدت‌زمان ویدیو بر حسب ثانیه | COMBO | بله | `5`<br>`8` |
| `حالت حرکت` | سبک حرکت برای انتقال (پیش‌فرض: `"normal"`) | COMBO | بله | `"normal"`<br>`"fast"` |
| `seed` | seed برای تولید ویدیو (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |
| `پرامپت منفی` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر (پیش‌فرض: رشته خالی) | STRING | خیر | - |

**نکته درباره محدودیت‌های پارامتر:** هنگام استفاده از کیفیت 1080p، حالت حرکت به‌طور خودکار روی `"normal"` تنظیم می‌شود و مدت‌زمان به 5 ثانیه محدود می‌گردد. برای هر مدت‌زمان غیر از 5 ثانیه، حالت حرکت نیز به‌طور خودکار روی `"normal"` تنظیم می‌شود.
