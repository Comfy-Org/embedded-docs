# بيكسفيرس فيديو الانتقال

يُنشئ فيديو انتقال بين صورتين للإدخال باستخدام واجهة برمجة تطبيقات PixVerse. يمكنك توفير صورة البداية وصورة النهاية، ويُنشئ العقدة فيديو سلسًا ينتقل من إحداهما إلى الأخرى، مسترشدًا بمطالبتك النصية والإعدادات التي اخترتها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `الإطار الأول` | الصورة الابتدائية لفيديو الانتقال | IMAGE | نعم | - |
| `الإطار الأخير` | الصورة النهائية لفيديو الانتقال | IMAGE | نعم | - |
| `النص المطلوب` | المطالبة الخاصة بتوليد الفيديو (الافتراضي: سلسلة فارغة) | STRING | نعم | - |
| `الجودة` | إعداد جودة الفيديو (الافتراضي: `"540p"`) | COMBO | نعم | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `مدة الثواني` | مدة الفيديو بالثواني | COMBO | نعم | `5`<br>`8` |
| `وضع الحركة` | نمط الحركة للانتقال (الافتراضي: `"normal"`) | COMBO | نعم | `"normal"`<br>`"fast"` |
| `البذرة` | القيمة الأولية لتوليد الفيديو (الافتراضي: 0) | INT | نعم | 0 إلى 2147483647 |
| `نص المطالبة السلبية` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: سلسلة فارغة) | STRING | لا | - |

**ملاحظة حول قيود المعاملات:** عند استخدام جودة 1080p، يتم ضبط نمط الحركة تلقائيًا على `"normal"` وتكون المدة محدودة بـ 5 ثوانٍ. بالنسبة لأي مدة غير 5 ثوانٍ، يتم ضبط نمط الحركة أيضًا تلقائيًا على `"normal"`.
