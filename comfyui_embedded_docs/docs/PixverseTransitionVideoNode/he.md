# PixverseTransitionVideoNode

מייצר סרטון מעבר בין שתי תמונות קלט באמצעות PixVerse API. אתה מספק תמונת התחלה ותמונת סיום, והצומת יוצר סרטון חלק שמבצע מעבר מאחת לאחרת, בהנחיית ההנחיה הטקסטואלית וההגדרות שבחרת.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `first_frame` | תמונת ההתחלה עבור מעבר הווידאו | IMAGE | כן | - |
| `last_frame` | תמונת הסיום עבור מעבר הווידאו | IMAGE | כן | - |
| `prompt` | הנחיה ליצירת הווידאו (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `quality` | הגדרת איכות הווידאו (ברירת מחדל: `"540p"`) | COMBO | כן | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration_seconds` | משך הווידאו בשניות | COMBO | כן | `5`<br>`8` |
| `motion_mode` | סגנון תנועה עבור המעבר (ברירת מחדל: `"normal"`) | COMBO | כן | `"normal"`<br>`"fast"` |
| `seed` | Seed ליצירת הווידאו (ברירת מחדל: 0) | INT | כן | 0 to 2147483647 |
| `negative_prompt` | תיאור טקסט אופציונלי של אלמנטים לא רצויים בתמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |

**הערה לגבי מגבלות פרמטרים:** בעת שימוש באיכות 1080p, מצב התנועה מוגדר אוטומטית ל־`"normal"` והמשך מוגבל ל־5 שניות. לכל משך שאינו 5 שניות, מצב התנועה גם מוגדר אוטומטית ל־`"normal"`.
