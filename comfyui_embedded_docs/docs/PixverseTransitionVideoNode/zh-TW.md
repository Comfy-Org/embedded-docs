# PixVerse 轉場影片

使用 PixVerse API 在兩張輸入圖片之間生成過渡影片。您提供起始圖片和結束圖片，節點會根據您的文字提示和所選設定，建立從一張圖片平滑過渡到另一張的影片。

## 輸入

| 參數 | 說明 | 資料型態 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `第一幀` | 影片過渡的起始圖片 | IMAGE | 是 | - |
| `最後一幀` | 影片過渡的結束圖片 | IMAGE | 是 | - |
| `提示詞` | 影片生成的提示詞（預設為空字串） | STRING | 是 | - |
| `品質` | 影片品質設定（預設：`"540p"`） | COMBO | 是 | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `持續秒數` | 影片持續時間（秒） | COMBO | 是 | `5`<br>`8` |
| `動作模式` | 過渡的動態樣式（預設：`"normal"`） | COMBO | 是 | `"normal"`<br>`"fast"` |
| `種子值` | 影片生成的種子（預設：0） | INT | 是 | 0 到 2147483647 |
| `負向提示詞` | 可選的圖片中不希望出現元素的文字描述（預設為空字串） | STRING | 否 | - |

**參數限制說明：** 使用 1080p 品質時，動態模式會自動設為 `"normal"`，且持續時間限制為 5 秒。對於任何非 5 秒的持續時間，動態模式也會自動設為 `"normal"`。

## 輸出

| --- | --- | --- |
