# Kling 4.0 Text to Video

Генерирует видео по текстовому промпту с помощью модели Kling 4.0, включая аудио. Этот узел отправляет промпт и настройки генерации в Kling API, ожидает завершения задачи и возвращает готовое видео. Используйте его, когда клип нужно создать только по описанию, без референсных медиа.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Селектор модели. Доступна только `"kling-4.0"`; при её выборе отображаются указанные ниже входы. | DYNAMIC_COMBO | Да | `"kling-4.0"` |

### Входы kling-4.0

Эти входы отображаются, когда для `model` установлено значение `"kling-4.0"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео для генерации. Должно содержать от 1 до 26000 символов. | STRING | Да | 1 до 26000 символов |
| `resolution` | Разрешение выходного видео. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. По умолчанию: `"16:9"`. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | 3 до 30 |
| `seed` | Параметр `seed` определяет, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загруженное от провайдера после завершения задачи. | VIDEO |
