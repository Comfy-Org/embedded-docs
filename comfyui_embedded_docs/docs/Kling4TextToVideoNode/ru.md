# Kling 4.0: текст в видео

Создаёт видео по текстовому запросу с помощью модели Kling 4.0, включая аудио. Этот узел отправляет запрос и настройки генерации в API Kling, ожидает завершения задачи и возвращает готовое видео. Используйте его, когда клип нужно создать только по описанию, без референсных медиафайлов.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Выбор модели. `"kling-4.0"` поддерживает до 4K HDR и 30 секунд; `"kling-4.0-flash"` ограничена 720p и 20 секундами. При выборе модели ниже отображаются соответствующие входы. | DYNAMIC_COMBO | Да | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### Входы kling-4.0

Эти входы появляются, когда `model` установлен в `"kling-4.0"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео для генерации. Должно содержать от 1 до 26000 символов. | STRING | Да | от 1 до 26000 символов |
| `resolution` | Разрешение выходного видео; параметр со словом `HDR` в названии возвращает HDR-видео. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"`<br>`"4k"`<br>`"1080p HDR"`<br>`"4k HDR"` |
| `aspect_ratio` | Соотношение сторон выходного видео. По умолчанию: `"16:9"`. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 30 |
| `seed` | Сид определяет, следует ли перезапускать узел; результаты недетерминированы независимо от сида. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы kling-4.0-flash

Эти входы появляются, когда `model` установлен в `"kling-4.0-flash"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео для генерации. Должно содержать от 1 до 26000 символов. | STRING | Да | от 1 до 26000 символов |
| `resolution` | Разрешение выходного видео. Flash генерирует только 720p. По умолчанию: `"720p"`. | COMBO | Да | `"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. По умолчанию: `"16:9"`. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 20 |
| `seed` | Сид определяет, следует ли перезапускать узел; результаты недетерминированы независимо от сида. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загруженное от провайдера после завершения задачи. | VIDEO |
