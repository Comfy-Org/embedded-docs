# Kling 4.0: текст в видео

Генерирует видео из текстового запроса с помощью модели Kling 4.0, включая аудио. Этот узел отправляет запрос и настройки генерации в Kling API, ожидает завершения задачи и возвращает готовое видео. Используйте его, когда клип нужно создать только по описанию, без референсных медиафайлов.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Выбор модели. `"kling-4.0"` поддерживает разрешение до 1080p и длительность до 30 секунд; `"kling-4.0-flash"` ограничен 720p и 20 секундами. При выборе модели ниже отображаются соответствующие входы. | DYNAMIC_COMBO | Да | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### Входы kling-4.0

Эти входы появляются, когда для `model` выбрано значение `"kling-4.0"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео для генерации. Должно содержать от 1 до 26000 символов. | STRING | Да | от 1 до 26000 символов |
| `resolution` | Разрешение выходного видео. По умолчанию: `"720p"`. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. По умолчанию: `"16:9"`. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 30 |
| `seed` | Сид определяет, следует ли повторно запускать узел; результаты недетерминированы независимо от сида. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы kling-4.0-flash

Эти входы появляются, когда для `model` выбрано значение `"kling-4.0-flash"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание видео для генерации. Должно содержать от 1 до 26000 символов. | STRING | Да | от 1 до 26000 символов |
| `resolution` | Разрешение выходного видео. Flash поддерживает только разрешение 720p. По умолчанию: `"720p"`. | COMBO | Да | `"720p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. По умолчанию: `"16:9"`. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | Длительность сгенерированного видео в секундах. По умолчанию: 5. | INT | Да | от 3 до 20 |
| `seed` | Сид определяет, следует ли повторно запускать узел; результаты недетерминированы независимо от сида. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, загруженное от провайдера после завершения задачи. | VIDEO |
