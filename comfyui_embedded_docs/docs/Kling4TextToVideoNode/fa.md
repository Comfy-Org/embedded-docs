# تبدیل متن به ویدیو Kling ۴.۰

تولید ویدیو از یک دستور متنی با مدل Kling 4.0، همراه با صدا. این گره دستور و تنظیمات تولید را به API Kling ارسال می‌کند، منتظر تکمیل وظیفه می‌ماند و ویدیوی نهایی را برمی‌گرداند. از آن زمانی استفاده کنید که باید یک کلیپ تنها از روی توضیحات، بدون رسانه مرجع، ساخته شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | انتخاب‌گر مدل. `"kling-4.0"` تا 1080p و 30 ثانیه را پشتیبانی می‌کند؛ `"kling-4.0-flash"` به 720p و 20 ثانیه محدود است. با انتخاب یک مدل، ورودی‌های آن در پایین نمایش داده می‌شوند. | DYNAMIC_COMBO | بله | `"kling-4.0"`<br>`"kling-4.0-flash"` |

### ورودی‌های kling-4.0

این ورودی‌ها زمانی نمایش داده می‌شوند که `model` روی `"kling-4.0"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی ویدیویی که باید تولید شود. باید بین 1 تا 26000 کاراکتر باشد. | STRING | بله | 1 تا 26000 کاراکتر |
| `resolution` | وضوح ویدیوی خروجی. پیش‌فرض: `"720p"`. | COMBO | بله | `"720p"`<br>`"1080p"` |
| `aspect_ratio` | نسبت تصویر ویدیوی خروجی. پیش‌فرض: `"16:9"`. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | مدت ویدیوی تولیدشده بر حسب ثانیه. پیش‌فرض: 5. | INT | بله | 3 تا 30 |
| `seed` | پارامتر `seed` کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به `seed` غیرقطعی هستند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

### ورودی‌های kling-4.0-flash

این ورودی‌ها زمانی نمایش داده می‌شوند که `model` روی `"kling-4.0-flash"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی ویدیویی که باید تولید شود. باید بین 1 تا 26000 کاراکتر باشد. | STRING | بله | 1 تا 26000 کاراکتر |
| `resolution` | وضوح ویدیوی خروجی. Flash فقط 720p را رندر می‌کند. پیش‌فرض: `"720p"`. | COMBO | بله | `"720p"` |
| `aspect_ratio` | نسبت تصویر ویدیوی خروجی. پیش‌فرض: `"16:9"`. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | مدت ویدیوی تولیدشده بر حسب ثانیه. پیش‌فرض: 5. | INT | بله | 3 تا 20 |
| `seed` | پارامتر `seed` کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به `seed` غیرقطعی هستند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |
