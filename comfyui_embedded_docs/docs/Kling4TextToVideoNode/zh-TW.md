# Kling 4.0 Text to Video

使用 Kling 4.0 模型根據文字提示生成包含音訊的影片。此節點會將提示與生成設定傳送至 Kling API，等待任務完成，並傳回完成的影片。當僅需根據描述建立片段、且沒有任何參考媒體時使用。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型選擇器。僅提供 `"kling-4.0"`；選取後會顯示下方輸入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 輸入

當 `model` 設為 `"kling-4.0"` 時，會顯示這些輸入。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成之影片的文字描述。長度必須介於 1 到 26000 個字元。 | STRING | 是 | 1 至 26000 個字元 |
| `resolution` | 輸出影片的解析度。預設值：`"720p"`。 | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `aspect_ratio` | 輸出影片的長寬比。預設值：`"16:9"`。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"21:9"` |
| `duration` | 生成影片的長度，單位為秒。預設值：5。 | INT | 是 | 3 至 30 |
| `seed` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果皆不具確定性。預設值：42。 | INT | 是 | 0 至 2147483647 |
