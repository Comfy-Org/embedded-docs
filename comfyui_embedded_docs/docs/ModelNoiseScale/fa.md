# ModelNoiseScale

این گره مقیاس نویز مورد استفاده در نمونه‌برداری مدل را تنظیم می‌کند. به شما امکان می‌دهد مقدار خاصی از مقیاس نویز را تعیین کنید که میزان نویز اعمال‌شده به فرآیند نمونه‌برداری مدل را کنترل می‌کند. گره مدل را شبیه‌سازی می‌کند و پیکربندی نمونه‌برداری آن را با مقیاس نویز جدید به‌روزرسانی می‌کند، در حالی که تنظیمات شیفت و ضریب موجود را حفظ می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که تنظیم مقیاس نویز روی آن اعمال می‌شود. | MODEL | بله | - |
| `noise_scale` | مقیاس نویز مطلق آموزش. برای مثال HiDream-O1 پایه: 8.0، dev: 7.5. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 to 64.0 (step: 0.01) |
