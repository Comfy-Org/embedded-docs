# ModelNoiseScale

## مرور کلی

این گره مقیاس نویز مورد استفاده در فرآیند نمونه‌برداری مدل را تنظیم می‌کند. به شما امکان می‌دهد مقدار مشخصی برای مقیاس نویز تعیین کنید که میزان نویز اعمال‌شده به فرآیند نمونه‌برداری مدل را کنترل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که تنظیم مقیاس نویز روی آن اعمال می‌شود. | MODEL | بله | - |
| `مقیاس نویز` | مقیاس نویز مطلق آموزش. به عنوان مثال HiDream-O1 base: 8.0، dev: 7.5. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 64.0 (step: 0.01) |
