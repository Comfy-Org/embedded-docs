# Масштаб шума модели

## Обзор

Этот узел регулирует масштаб шума, используемый при сэмплировании модели. Он позволяет задать конкретное значение масштаба шума, которое управляет количеством шума, применяемого в процессе сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяется регулировка масштаба шума. | MODEL | Да | - |
| `масштаб_шума` | Абсолютный масштаб шума обучения. Например, HiDream-O1 base: 8.0, dev: 7.5. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 64.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Модифицированная модель с применённым новым масштабом шума. | MODEL |
