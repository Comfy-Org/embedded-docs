# ModelNoiseScale

このノードは、モデルサンプリング中に使用されるノイズスケールを調整します。特定のノイズスケール値を設定することで、モデルのサンプリングプロセスに適用されるノイズ量を制御できます。このノードはモデルをクローンし、既存のシフト設定とマルチプライヤー設定を維持したまま、新しいノイズスケールでサンプリング設定を更新します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | ノイズスケール調整を適用するモデル。 | MODEL | はい | - |
| `noise_scale` | 絶対トレーニングノイズスケール。例：HiDream-O1 base: 8.0、dev: 7.5（デフォルト: 1.0）。 | FLOAT | はい | 0.0 to 64.0 (step: 0.01) |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 新しいノイズスケールが適用された修正済みモデル。 | MODEL |
