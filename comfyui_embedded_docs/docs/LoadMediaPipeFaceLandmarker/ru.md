# Загрузить MediaPipe Face Landmarker

Этот узел загружает модель MediaPipe Face Landmarker v2, которая позволяет обнаруживать лица и лицевые ориентиры (например, глаза, нос и рот) на изображениях. Загруженная модель содержит два варианта детекции (short и full), а также общие данные сетки, блендшейпы и каноническую геометрию для анализа лица.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Модель обнаружения лиц из каталога `models/detection/`. | COMBO | Да | Список доступных моделей в каталоге `models/detection/` |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| FACE_DETECTION_MODEL | Загруженный объект модели MediaPipe Face Landmarker, содержащий оба варианта детекции (short/full), общие данные сетки и блендшейпов, каноническую геометрию, наборы соединений лицевой топологии и патчи модели для управления GPU. | FACE_DETECTION_MODEL |

**Примечание:** Выходной объект является сложным объектом, который может использоваться другими узлами для задач обнаружения лиц и извлечения лицевых ориентиров. Он содержит два варианта детекции: «short» для обнаружения на близком расстоянии и «full» для обнаружения в полном диапазоне.
