# Загрузить MediaPipe Face Landmarker

Этот узел загружает модель MediaPipe Face Landmarker v2, которая обнаруживает лица и лицевые ориентиры (такие как глаза, нос и рот) на изображениях. Загруженная модель объединяет два варианта обнаружения (ближнего действия и полного диапазона) вместе с общими данными mesh, blendshapes и канонической геометрией, используемыми для анализа лица.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Модель обнаружения лиц из models/detection/. | COMBO | Да | Список доступных имён файлов моделей, найденных в каталоге `models/detection/` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `FACE_DETECTION_MODEL` | Загруженный объект модели FaceLandmarker, содержащий оба варианта обнаружения (short/full), наборы соединений для лицевой топологии, канонические данные и патчеры моделей для управления GPU. | FACE_DETECTION_MODEL |

**Примечание:** Выход представляет собой сложный объект, который может использоваться другими узлами для задач обнаружения лиц и извлечения ориентиров. Он содержит два варианта обнаружения: "short" для обнаружения на близком расстоянии и "full" для обнаружения в полном диапазоне.
