# Загрузить MediaPipe Face Landmarker

Загрузка модели обнаружения лиц (MediaPipe)

## Обзор

Этот узел загружает модель Face Landmarker v2 от MediaPipe, которая позволяет обнаруживать лица и их ключевые точки (глаза, нос, рот) на изображениях. Модель содержит два варианта детекции (ближнего и полного диапазона), а также общие данные сетки, блендшейпы и каноническую геометрию для анализа лица.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Модель обнаружения лиц из каталога models/detection/. | COMBO | Да | Список доступных моделей в каталоге `models/detection/` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `FACE_DETECTION_MODEL` | Загруженный объект модели FaceLandmarker, содержащий оба варианта детекции (ближний/полный), наборы соединений для топологии лица, канонические данные и патчи модели для управления GPU. | FACE_DETECTION_MODEL |

**Примечание:** Выходной объект является сложным и может использоваться другими узлами для задач обнаружения лиц и извлечения ключевых точек. Он содержит два варианта детекции: `"short"` — для обнаружения лиц на близком расстоянии и `"full"` — для обнаружения лиц в полном диапазоне.
