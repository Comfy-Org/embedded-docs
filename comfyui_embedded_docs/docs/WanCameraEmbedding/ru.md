# WanCameraEmbedding

Узел WanCameraEmbedding генерирует вложения траекторий камеры с использованием вложений Плюккера на основе параметров движения камеры. Он создает последовательность положений камеры, имитирующих различные движения камеры, и преобразует их в тензоры вложений, подходящие для конвейеров генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `поза_камеры` | Тип движения камеры для имитации (по умолчанию: "Static") | COMBO | Да | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `ширина` | Ширина выходного изображения в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного изображения в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Длина последовательности траектории камеры (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `скорость` | Скорость движения камеры (по умолчанию: 1.0, шаг: 0.1) | FLOAT | Нет | 0.0 до 10.0 |
| `fx` | Фокусное расстояние по оси x (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | 0.0 до 1.0 |
| `fy` | Фокусное расстояние по оси y (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | 0.0 до 1.0 |
| `cx` | Координата x главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | 0.0 до 1.0 |
| `cy` | Координата y главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | 0.0 до 1.0 |

Примечание: `fx`, `fy`, `cx` и `cy` — это дополнительные внутренние параметры камеры. Параметр `speed` масштабирует угол поворота и расстояние смещения выбранного движения камеры.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `вложение_камеры` | Сгенерированный тензор вложений камеры, содержащий последовательность траектории | TENSOR |
| `ширина` | Значение ширины, использованное для обработки | INT |
| `высота` | Значение высоты, использованное для обработки | INT |
| `длина` | Значение длины, использованное для обработки | INT |
