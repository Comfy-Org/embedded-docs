# WanCameraEmbedding

Этот узел генерирует эмбеддинг траектории камеры с использованием Plücker-эмбеддингов для выбранного пути камеры. Он строит последовательность поз камеры, имитируя такие движения, как панорамирование, масштабирование или вращение, и преобразует их в тензор эмбеддинга, который можно использовать в пайплайнах генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `поза_камеры` | Тип имитируемого движения камеры (по умолчанию: "Static") | COMBO | Да | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `ширина` | Ширина вывода в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота вывода в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Длина последовательности траектории камеры (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `скорость` | Скорость движения камеры (по умолчанию: 1.0, шаг: 0.1) | FLOAT | Нет | от 0.0 до 10.0 |
| `fx` | Параметр фокусного расстояния x (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | от 0.0 до 1.0 |
| `fy` | Параметр фокусного расстояния y (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | от 0.0 до 1.0 |
| `cx` | Координата x главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | от 0.0 до 1.0 |
| `cy` | Координата y главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | от 0.0 до 1.0 |

Примечание: `fx`, `fy`, `cx` и `cy` — это расширенные внутренние параметры камеры. Параметр `speed` масштабирует угол поворота и расстояние смещения выбранного движения камеры.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `camera_embedding` | Сгенерированный тензор эмбеддинга камеры, содержащий последовательность траектории | TENSOR |
| `width` | Значение ширины, использованное при обработке | INT |
| `height` | Значение высоты, использованное при обработке | INT |
| `length` | Значение длины, использованное при обработке | INT |
