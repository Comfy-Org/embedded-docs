# WanCameraEmbedding

Узел WanCameraEmbedding создаёт эмбеддинги траектории камеры на основе вложений Плюккера (Plücker embeddings) и параметров движения камеры. Он формирует последовательность позиций камеры, имитирующую различные движения камеры, и преобразует её в тензоры эмбеддингов, подходящие для конвейеров генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `camera_pose` | Тип движения камеры для имитации (по умолчанию: "Static") | COMBO | Да | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `width` | Ширина вывода в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `height` | Высота вывода в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `length` | Длина последовательности траектории камеры (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `speed` | Скорость движения камеры (по умолчанию: 1.0, шаг: 0.1) | FLOAT | Нет | от 0.0 до 10.0 |
| `fx` | Параметр фокусного расстояния x (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | от 0.0 до 1.0 |
| `fy` | Параметр фокусного расстояния y (по умолчанию: 0.5, шаг: 0.000000001) | FLOAT | Нет | от 0.0 до 1.0 |
| `cx` | Координата x главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | от 0.0 до 1.0 |
| `cy` | Координата y главной точки (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Нет | от 0.0 до 1.0 |

Примечание: `fx`, `fy`, `cx` и `cy` — дополнительные параметры. Параметр `length` использует шаг 4, поскольку первый кадр камеры внутренне повторяется, поэтому эффективная длина обрабатываемой последовательности становится `length + 3`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `camera_embedding` | Сгенерированный тензор эмбеддинга камеры, содержащий последовательность траектории | TENSOR |
| `width` | Значение ширины, использованное для обработки | INT |
| `height` | Значение высоты, использованное для обработки | INT |
| `length` | Значение длины, использованное для обработки | INT |
