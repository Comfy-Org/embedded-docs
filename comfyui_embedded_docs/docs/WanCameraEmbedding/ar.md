# تضمين_كاميرا_Wan

```markdown
تولّد عقدة WanCameraEmbedding تضمينات مسار الكاميرا باستخدام تضمينات بلوكر (Plücker) استنادًا إلى معاملات حركة الكاميرا. وهي تنشئ تسلسلًا من أوضاع الكاميرا تحاكي حركات الكاميرا المختلفة وتحوّلها إلى موترات تضمين مناسبة لخطوط أنابيب توليد الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `camera_pose` | نوع حركة الكاميرا التي سيتم محاكاتها (الافتراضي: "Static") | COMBO | نعم | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `width` | عرض المخرجات بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع المخرجات بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | طول تسلسل مسار الكاميرا (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `speed` | سرعة حركة الكاميرا (الافتراضي: 1.0، الخطوة: 0.1) | FLOAT | لا | 0.0 إلى 10.0 |
| `fx` | معامل البعد البؤري x (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `fy` | معامل البعد البؤري y (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `cx` | إحداثي النقطة الرئيسية x (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |
| `cy` | إحداثي النقطة الرئيسية y (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |

ملاحظة: المعاملات `fx` و`fy` و`cx` و`cy` هي معاملات متقدمة. يستخدم معامل `length` خطوة بمقدار 4 لأن إطار الكاميرا الأول يتكرر داخليًا، وبالتالي يصبح طول التسلسل الفعلي المُعالَج `length + 3`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `camera_embedding` | موتر تضمين الكاميرا المُولَّد الذي يحتوي على تسلسل المسار | TENSOR |
| `width` | قيمة العرض التي تم استخدامها للمعالجة | INT |
| `height` | قيمة الارتفاع التي تم استخدامها للمعالجة | INT |
| `length` | قيمة الطول التي تم استخدامها للمعالجة | INT |
```
