# تضمين_كاميرا_Wan

تنشئ عقدة WanCameraEmbedding تضمينات مسار الكاميرا باستخدام تضمينات Plücker استنادًا إلى معاملات حركة الكاميرا. وتقوم بإنشاء تسلسل من أوضاع الكاميرا لمحاكاة حركات كاميرا مختلفة وتحويلها إلى موترات تضمين مناسبة لخطوط إنتاج توليد الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `وضعية_الكاميرا` | نوع حركة الكاميرا المراد محاكاتها (الافتراضي: "Static") | COMBO | نعم | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `العرض` | عرض المخرجات بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع المخرجات بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | طول تسلسل مسار الكاميرا (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `السرعة` | سرعة حركة الكاميرا (الافتراضي: 1.0، الخطوة: 0.1) | FLOAT | لا | 0.0 إلى 10.0 |
| `fx` | معامل البعد البؤري x (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `fy` | معامل البعد البؤري y (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `cx` | إحداثي x للنقطة الرئيسية (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |
| `cy` | إحداثي y للنقطة الرئيسية (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |

ملاحظة: إن `fx` و`fy` و`cx` و`cy` هي معاملات داخلية متقدمة للكاميرا. يقوم معامل `speed` بقياس زاوية الدوران ومسافة الإزاحة لحركة الكاميرا المحددة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `تضمين_الكاميرا` | موتر تضمين الكاميرا المُنشأ الذي يحتوي على تسلسل المسار | TENSOR |
| `العرض` | قيمة العرض المستخدمة في المعالجة | INT |
| `الارتفاع` | قيمة الارتفاع المستخدمة في المعالجة | INT |
| `الطول` | قيمة الطول المستخدمة في المعالجة | INT |
