# تضمين_كاميرا_Wan

تولّد هذه العقدة تضمين مسار كاميرا باستخدام تضمينات Plücker لمسار الكاميرا الذي تختاره. وهي تبني تسلسلاً من أوضاع الكاميرا يحاكي حركات مثل التحريك الأفقي، أو التكبير/التصغير، أو التدوير، ثم تحوّلها إلى موتر تضمين يمكن استخدامه في مسارات توليد الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `camera_pose` | نوع حركة الكاميرا المراد محاكاتها (الافتراضي: "Static") | COMBO | نعم | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `width` | عرض المخرج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع المخرج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | طول تسلسل مسار الكاميرا (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `speed` | سرعة حركة الكاميرا (الافتراضي: 1.0، الخطوة: 0.1) | FLOAT | لا | 0.0 إلى 10.0 |
| `fx` | معامل البعد البؤري x (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `fy` | معامل البعد البؤري y (الافتراضي: 0.5، الخطوة: 0.000000001) | FLOAT | لا | 0.0 إلى 1.0 |
| `cx` | إحداثي x للنقطة الأساسية (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |
| `cy` | إحداثي y للنقطة الأساسية (الافتراضي: 0.5، الخطوة: 0.01) | FLOAT | لا | 0.0 إلى 1.0 |

ملاحظة: `fx` و`fy` و`cx` و`cy` هي معاملات كاميرا داخلية متقدمة. يضبط المعامل `speed` مقياس زاوية الدوران ومسافة الإزاحة لحركة الكاميرا المحددة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `camera_embedding` | موتر تضمين الكاميرا المُنشأ الذي يحتوي على تسلسل المسار | TENSOR |
| `width` | قيمة العرض التي استُخدمت في المعالجة | INT |
| `height` | قيمة الارتفاع التي استُخدمت في المعالجة | INT |
| `length` | قيمة الطول التي استُخدمت في المعالجة | INT |
