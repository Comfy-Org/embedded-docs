# WanCameraEmbedding

این گره با استفاده از جاسازی‌های Plücker برای مسیر دوربینی که انتخاب می‌کنید، یک جاسازی مسیر دوربین تولید می‌کند. این گره دنباله‌ای از وضعیت‌های دوربین می‌سازد که حرکت‌هایی مانند چرخش افقی، بزرگ‌نمایی یا چرخش را شبیه‌سازی می‌کند و آن‌ها را به یک تنسور جاسازی تبدیل می‌کند که می‌تواند در خطوط لوله تولید ویدئو استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `وضعیت دوربین` | نوع حرکت دوربین برای شبیه‌سازی (پیش‌فرض: "Static") | COMBO | بله | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `عرض` | عرض خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | طول دنباله مسیر دوربین (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `سرعت` | سرعت حرکت دوربین (پیش‌فرض: 1.0، گام: 0.1) | FLOAT | خیر | 0.0 تا 10.0 |
| `fx` | پارامتر فاصله کانونی x (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 تا 1.0 |
| `fy` | پارامتر فاصله کانونی y (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 تا 1.0 |
| `cx` | مختصات x نقطه اصلی (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 تا 1.0 |
| `cy` | مختصات y نقطه اصلی (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 تا 1.0 |

توجه: `fx`، `fy`، `cx` و `cy` پارامترهای پیشرفته ذاتی دوربین هستند. پارامتر `speed` زاویه چرخش و فاصله جابه‌جایی حرکت دوربین انتخاب‌شده را مقیاس‌بندی می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `camera_embedding` | تنسور جاسازی دوربین تولیدشده که شامل دنباله مسیر است | TENSOR |
| `width` | مقدار عرض استفاده‌شده برای پردازش | INT |
| `height` | مقدار ارتفاع استفاده‌شده برای پردازش | INT |
| `length` | مقدار طول استفاده‌شده برای پردازش | INT |
