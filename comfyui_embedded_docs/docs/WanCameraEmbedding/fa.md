# WanCameraEmbedding

گره WanCameraEmbedding با استفاده از جاسازی‌های Plücker بر اساس پارامترهای حرکت دوربین، جاسازی‌های مسیر حرکت دوربین را تولید می‌کند. این گره دنباله‌ای از موقعیت‌های دوربین را می‌سازد که حرکات مختلف دوربین را شبیه‌سازی می‌کنند و آن‌ها را به تنسورهای جاسازی مناسب برای خطوط لوله تولید ویدیو تبدیل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `وضعیت دوربین` | نوع حرکت دوربین برای شبیه‌سازی (پیش‌فرض: "Static") | COMBO | بله | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `عرض` | عرض خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | طول دنباله مسیر حرکت دوربین (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `سرعت` | سرعت حرکت دوربین (پیش‌فرض: 1.0، گام: 0.1) | FLOAT | خیر | 0.0 تا 10.0 |
| `fx` | پارامتر فاصله کانونی در جهت x (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 تا 1.0 |
| `fy` | پارامتر فاصله کانونی در جهت y (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 تا 1.0 |
| `cx` | مختصات x مرکز تصویر (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 تا 1.0 |
| `cy` | مختصات y مرکز تصویر (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 تا 1.0 |

توجه: `fx`، `fy`، `cx` و `cy` پارامترهای ذاتی پیشرفته دوربین هستند. پارامتر `speed` زاویه چرخش و میزان جابه‌جایی حرکت دوربین انتخاب‌شده را مقیاس‌بندی می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `بردار دوربین` | تنسور جاسازی دوربین تولیدشده حاوی دنباله مسیر حرکت | TENSOR |
| `عرض` | مقدار عرضی که برای پردازش استفاده شد | INT |
| `ارتفاع` | مقدار ارتفاعی که برای پردازش استفاده شد | INT |
| `طول` | مقدار طولی که برای پردازش استفاده شد | INT |
