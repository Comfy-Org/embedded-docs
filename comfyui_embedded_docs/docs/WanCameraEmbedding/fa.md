# WanCameraEmbedding

گره WanCameraEmbedding با استفاده از پارامترهای حرکت دوربین، جاسازی‌های مسیر دوربین را بر پایه جاسازی‌های پلوکر (Plücker) تولید می‌کند. این گره دنباله‌ای از وضعیت‌های دوربین را برای شبیه‌سازی حرکت‌های مختلف دوربین می‌سازد و آن‌ها را به تانسورهای جاسازی مناسب برای خطوط لوله تولید ویدیو تبدیل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `camera_pose` | نوع حرکت دوربین برای شبیه‌سازی (پیش‌فرض: "Static") | COMBO | بله | "Static"<br>"Pan Up"<br>"Pan Down"<br>"Pan Left"<br>"Pan Right"<br>"Zoom In"<br>"Zoom Out"<br>"Anti Clockwise (ACW)"<br>"ClockWise (CW)" |
| `width` | عرض خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | طول دنباله مسیر دوربین (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `speed` | سرعت حرکت دوربین (پیش‌فرض: 1.0، گام: 0.1) | FLOAT | خیر | 0.0 to 10.0 |
| `fx` | پارامتر فاصله کانونی x (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 to 1.0 |
| `fy` | پارامتر فاصله کانونی y (پیش‌فرض: 0.5، گام: 0.000000001) | FLOAT | خیر | 0.0 to 1.0 |
| `cx` | مختصات x نقطه اصلی (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 to 1.0 |
| `cy` | مختصات y نقطه اصلی (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | خیر | 0.0 to 1.0 |

توجه: پارامترهای `fx`، `fy`، `cx` و `cy` پارامترهای پیشرفته هستند. پارامتر `length` از گام ۴ استفاده می‌کند زیرا اولین فریم دوربین به‌صورت داخلی تکرار می‌شود، بنابراین طول مؤثر دنباله پردازش‌شده به `length + 3` تبدیل می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `camera_embedding` | تانسور جاسازی دوربین تولیدشده شامل دنباله مسیر | TENSOR |
| `width` | مقدار عرضی که برای پردازش استفاده شده است | INT |
| `height` | مقدار ارتفاعی که برای پردازش استفاده شده است | INT |
| `length` | مقدار طولی که برای پردازش استفاده شده است | INT |
