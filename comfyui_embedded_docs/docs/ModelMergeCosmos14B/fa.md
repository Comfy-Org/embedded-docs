# ModelMergeCosmos14B

گره **ModelMergeCosmos14B** دو مدل هوش مصنوعی را با رویکردی مبتنی بر بلوک که به‌طور ویژه برای معماری مدل Cosmos 14B طراحی شده است، ادغام می‌کند. این گره به شما امکان می‌دهد اجزای مختلف مدل‌ها را با تنظیم مقادیر وزن بین 0.0 و 1.0 برای هر بلوک مدل و لایه embedding ترکیب کنید.
