# ModelMergeCosmos14B

Узел **ModelMergeCosmos14B** объединяет две ИИ-модели с использованием подхода на основе блоков, специально разработанного для архитектуры модели Cosmos 14B. Он позволяет смешивать различные компоненты моделей, регулируя значения весов от 0.0 до 1.0 для каждого блока модели и слоя эмбеддингов.
