# دمج_نموذج_كوزموس14B

عقدة **ModelMergeCosmos14B** تدمج نموذجَي ذكاء اصطناعي باستخدام نهج قائم على الكتل مصمم خصيصًا لبنية نموذج Cosmos 14B. وهي تتيح لك مزج مكوّنات مختلفة من النموذجين عبر ضبط قيم الأوزان بين 0.0 و1.0 لكل كتلة نموذج وطبقة تضمين.
