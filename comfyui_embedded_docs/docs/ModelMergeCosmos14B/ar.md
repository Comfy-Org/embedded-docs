# دمج_نموذج_كوزموس14B

**ModelMergeCosmos14B** هي عقدة تدمج نموذجين من نماذج الذكاء الاصطناعي باستخدام نهج قائم على الكتل، مصمَّم خصيصًا لبنية نموذج Cosmos 14B. تتيح لك مزج المكونات المختلفة للنموذجين عبر ضبط قيم الأوزان بين 0.0 و1.0 لكل كتلة من كتل النموذج ولكل طبقة تضمين.
