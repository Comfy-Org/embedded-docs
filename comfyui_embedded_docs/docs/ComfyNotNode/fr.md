# Non

Le nœud Not effectue une opération logique NOT sur n'importe quelle valeur d'entrée. Il renvoie True lorsque la valeur d'entrée est considérée comme fausse (par exemple 0, une chaîne vide, None ou False) et renvoie False lorsque la valeur d'entrée est considérée comme vraie, selon les règles standard de Python en matière de véracité.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `value` | La valeur d'entrée à inverser. Tout type de données est accepté et évalué selon les règles de véracité de Python. | ANY | Oui | Toute valeur |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | L'inverse logique de la valeur d'entrée. Renvoie True si l'entrée est considérée comme fausse, False si l'entrée est considérée comme vraie. | BOOLEAN |
