# Non

Le nœud Not effectue une opération NON logique sur n’importe quelle valeur d’entrée. Il renvoie True si la valeur d’entrée est considérée comme fausse (par exemple 0, une chaîne vide, None ou False), et renvoie False si la valeur d’entrée est vraie. Il utilise les règles standard de Python pour déterminer la véracité.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
|-----------|-------------|-----------------|--------|-------|
| `value` | La valeur d’entrée à inverser. Tout type de données est accepté et évalué selon les règles de véracité de Python. | ANY | Oui | Toute valeur |

## Sorties

| Nom de sortie | Description | Type de données |
|---------------|-------------|-----------------|
| `output` | L’inverse logique de la valeur d’entrée. Renvoie True si l’entrée est fausse, False si l’entrée est vraie. | BOOLEAN |
