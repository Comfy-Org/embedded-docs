# ليس

تنفذ عقدة Not عملية NOT منطقية على أي قيمة إدخال. وتُرجع True عندما تُعتبر قيمة الإدخال زائفة (مثل 0، أو سلسلة نصية فارغة، أو None، أو False)، وتُرجع False عندما تكون قيمة الإدخال صحيحة، وفقًا لقواعد Python القياسية لتقييم الصحة المنطقية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `القيمة` | القيمة المدخلة المراد عكسها. يُقبل أي نوع بيانات ويُقيَّم باستخدام قواعد الصحة المنطقية في Python. | ANY | نعم | أي قيمة |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | المقلوب المنطقي لقيمة الإدخال. يُرجع True إذا كانت قيمة الإدخال زائفة، وFalse إذا كانت قيمة الإدخال صحيحة. | BOOLEAN |
