# No

El nodo Not realiza una operación lógica NOT sobre cualquier valor de entrada. Devuelve True si el valor de entrada se considera falso (como 0, cadena vacía, None, False), y devuelve False si el valor de entrada es verdadero. Utiliza las reglas estándar de Python para determinar la veracidad.

## Entradas

| Parámetro | Descripción | Tipo de dato | Requerido | Rango |
| --- | --- | --- | --- | --- |
| `valor` | El valor de entrada que se va a invertir. Se acepta cualquier tipo de dato y se evalúa usando las reglas de veracidad de Python. | ANY | Sí | Cualquier valor |

## Salidas

| Nombre de salida | Descripción | Tipo de dato |
| --- | --- | --- |
| `output` | La inversa lógica del valor de entrada. Devuelve True si la entrada es falsa, False si la entrada es verdadera. | BOOLEAN |
