# No

El nodo Not realiza una operación lógica NOT sobre cualquier valor de entrada. Devuelve True si el valor de entrada se considera falso (falsy) (como 0, una cadena vacía, None o False), y devuelve False si el valor de entrada es verdadero (truthy). Utiliza las reglas estándar de Python para determinar la veracidad.

## Entradas

| Parametro | Descripción | Tipo de datos | Requerido | Rango |
|-----------|-------------|---------------|-----------|-------|
| `value` | El valor de entrada que se va a invertir. Se acepta cualquier tipo de datos y se evalúa mediante las reglas de veracidad de Python. | ANY | Sí | Any value |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `output` | La inversa lógica del valor de entrada. Devuelve True si el valor de entrada es falsy; False si es truthy. | BOOLEAN |
