# نقیض

گره Not عملگر نقیض منطقی را بر روی هر مقدار ورودی انجام می‌دهد. اگر مقدار ورودی به‌عنوان falsy (مانند 0، رشته خالی، None، False) در نظر گرفته شود، مقدار True و اگر مقدار ورودی truthy باشد، مقدار False برمی‌گرداند. برای تعیین truthiness از قوانین استاندارد پایتون استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مقدار` | مقدار ورودی که باید معکوس شود. هر نوع داده‌ای پذیرفته می‌شود و با استفاده از قوانین truthiness پایتون ارزیابی می‌گردد. | ANY | بله | هر مقدار |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
| --- | --- | --- |
| `output` | معکوس منطقی مقدار ورودی. اگر ورودی falsy باشد True و اگر truthy باشد False برمی‌گرداند. | BOOLEAN |
