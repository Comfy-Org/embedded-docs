# نقیض

گره Not یک عملیات NOT منطقی را روی هر مقدار ورودی انجام می‌دهد. زمانی که مقدار ورودی نادرست (falsy) در نظر گرفته شود (مانند 0، یک رشته خالی، None یا False) مقدار True را برمی‌گرداند و زمانی که مقدار ورودی درست (truthy) باشد مقدار False را برمی‌گرداند؛ این رفتار از قواعد استاندارد پایتون برای درست‌نمایی (truthiness) پیروی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مقدار` | مقدار ورودی برای وارونه‌سازی. هر نوع داده‌ای پذیرفته می‌شود و با قواعد درست‌نمایی پایتون ارزیابی می‌گردد. | ANY | بله | هر مقدار |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | وارون منطقی مقدار ورودی. اگر ورودی نادرست (falsy) باشد True و اگر ورودی درست (truthy) باشد False را برمی‌گرداند. | BOOLEAN |
