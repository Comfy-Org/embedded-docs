# نقیض

گره Not عملیات منطقی NOT را بر روی هر مقدار ورودی انجام می‌دهد. اگر مقدار ورودی falsy در نظر گرفته شود (مانند 0، رشته خالی، None یا False)، مقدار True برمی‌گرداند و اگر مقدار ورودی truthy باشد، مقدار False برمی‌گرداند. این گره از قوانین استاندارد پایتون برای تعیین truthiness استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `value` | مقدار ورودی که باید معکوس شود. هر نوع داده‌ای پذیرفته می‌شود و با استفاده از قوانین truthiness پایتون ارزیابی می‌شود. | ANY | بله | هر مقدار |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | معکوس منطقی مقدار ورودی. اگر ورودی falsy باشد True و اگر ورودی truthy باشد False برمی‌گرداند. | BOOLEAN |
