# Не

Узел Not выполняет логическую операцию НЕ над любым входным значением. Он возвращает True, если входное значение считается ложным (например, 0, пустая строка, None, False), и возвращает False, если входное значение истинно. Используются стандартные правила Python для определения истинности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Входное значение для инвертирования. Принимается любой тип данных, оценка выполняется по правилам истинности Python. | ANY | Да | Любое значение |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Логическое инвертирование входного значения. Возвращает True, если вход ложный, и False, если вход истинный. | BOOLEAN |
