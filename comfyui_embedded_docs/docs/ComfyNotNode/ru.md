# Не

Узел Not выполняет логическую операцию NOT над любым входным значением. Он возвращает True, если входное значение считается ложным (например, 0, пустая строка, None или False), и возвращает False, если входное значение является истинным. Для определения истинности используются стандартные правила Python.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `value` | Входное значение, которое необходимо инвертировать. Принимается любой тип данных, оценка выполняется по правилам истинности Python. | ANY | Да | Любое значение |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Логическая инверсия входного значения. Возвращает True, если входное значение ложно, и False, если входное значение истинно. | BOOLEAN |
