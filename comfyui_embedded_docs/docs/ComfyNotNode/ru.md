# Не

Узел Not выполняет логическую операцию NOT над любым входным значением. Он возвращает True, когда входное значение считается ложным (например, 0, пустая строка, None или False), и возвращает False, когда входное значение истинно, следуя стандартным правилам Python для определения истинности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Входное значение, которое нужно инвертировать. Принимается любой тип данных, и значение оценивается по правилам истинности Python. | ANY | Да | Любое значение |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Логическая инверсия входного значения. Возвращает True, если входное значение ложно, и False, если входное значение истинно. | BOOLEAN |
