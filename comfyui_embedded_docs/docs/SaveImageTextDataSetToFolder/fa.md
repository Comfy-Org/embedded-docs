# ذخیره مجموعه تصویر و متن در پوشه

گره Save Image-Text (to Folder) یک مجموعه داده از جفت‌های تصویر و زیرنویس متنی را در پوشه‌ای داخل پوشه خروجی ComfyUI ذخیره می‌کند. هر تصویر به‌صورت یک فایل PNG نوشته می‌شود و زیرنویس متناظر آن به‌صورت یک فایل TXT با همان نام پایه ذخیره می‌شود؛ بنابراین هر تصویر همراه با توضیح خود ذخیره می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | فهرست تصاویر برای ذخیره. | IMAGE | بله | - |
| `متون` | فهرست زیرنویس‌های متنی برای ذخیره. این ورودی اختیاری است. | STRING | خیر | - |
| `نام پوشه` | نام پوشه‌ای برای ذخیره تصاویر (داخل پوشه خروجی). (پیش‌فرض: "dataset") | STRING | بله | - |
| `پیشوند نام فایل تصویر` | پیشوند نام فایل‌های تصویر ذخیره‌شده. (پیش‌فرض: "image") | STRING | بله | - |
| `حالت` | اینکه فایل‌های موجود بازنویسی شوند یا نام فایل‌ها برای جلوگیری از بازنویسی افزایش یابد. (پیش‌فرض: "overwrite") | COMBO | بله | "overwrite"<br>"increment" |

**توجه:** ورودی `images` یک فهرست است و گره هر دو `images` و `texts` را به‌صورت فهرست دریافت می‌کند. ورودی `texts` اختیاری است؛ اگر ارائه شود، باید فهرستی از زیرنویس‌های متنی باشد و همان تعداد آیتم‌های `images` را داشته باشد. هر زیرنویس به‌صورت یک فایل `.txt` متناظر با تصویر جفت‌شده‌اش ذخیره می‌شود. در حالت `overwrite`، فایل‌ها با نام `{filename_prefix}_{index}.png` نام‌گذاری می‌شوند و هر فایل موجود با همان نام را جایگزین می‌کنند. در حالت `increment`، یک شمارنده یکتا به نام فایل‌ها افزوده می‌شود تا فایل‌های موجود بازنویسی نشوند. `folder_name` باید به مسیری داخل پوشه خروجی اشاره کند؛ نام پوشه‌هایی که تلاش می‌کنند از آن خارج شوند (برای نمونه با `..`) رد می‌شوند.
