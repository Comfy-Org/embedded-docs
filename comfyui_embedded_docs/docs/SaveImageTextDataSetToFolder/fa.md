# ذخیره مجموعه تصویر و متن در پوشه

Save Image-Text (to Folder) یک گره خروجی است که مجموعه‌داده‌ای از تصاویر و زیرنویس‌های متنی جفت‌شده را در پوشه‌ای داخل دایرکتوری خروجی ComfyUI ذخیره می‌کند. هر تصویر به‌عنوان یک فایل PNG ذخیره می‌شود و وقتی زیرنویس‌ها ارائه شوند، برای هر تصویر یک فایل TXT با همان نام پایه ایجاد می‌شود. این قابلیت برای ساخت مجموعه‌داده‌های سازمان‌یافته از تصاویر تولیدشده و توضیحات آن‌ها مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | فهرستی از تصاویر برای ذخیره. | IMAGE | بله | - |
| `texts` | فهرستی از زیرنویس‌های متنی برای ذخیره. این ورودی اختیاری است. | STRING | خیر | - |
| `folder_name` | نام پوشه‌ای که تصاویر در آن ذخیره می‌شوند (داخل دایرکتوری خروجی). (پیش‌فرض: "dataset") | STRING | بله | - |
| `filename_prefix` | پیشوند برای نام فایل‌های تصویر ذخیره‌شده. (پیش‌فرض: "image") | STRING | بله | - |
| `mode` | مشخص می‌کند که فایل‌های موجود بازنویسی شوند یا نام فایل‌ها افزایش یابد تا از بازنویسی جلوگیری شود. (پیش‌فرض: "overwrite") | COMBO | بله | "overwrite"<br>"increment" |

**توجه:** ورودی `images` یک فهرست است. ورودی `texts` اختیاری است؛ اگر ارائه شود، باید فهرستی از زیرنویس‌های متنی باشد. زیرنویس‌ها به ترتیب با تصاویر جفت می‌شوند و هر زیرنویس به‌صورت یک فایل `.txt` با کدگذاری UTF-8 و با همان نام پایه تصویر متناظر ذخیره می‌شود (مثلاً `image_00000.txt` برای `image_00000.png`). اگر تعداد زیرنویس‌ها کمتر از تصاویر باشد، تصاویر باقی‌مانده بدون زیرنویس ذخیره می‌شوند؛ هر زیرنویس اضافی نادیده گرفته می‌شود.

ورودی‌هایی که مقدار پیش‌فرض دارند (`folder_name`, `filename_prefix`, `mode`) نیازی به اتصال ندارند؛ مقادیر پیش‌فرض آن‌ها به‌طور خودکار استفاده می‌شود.

وقتی `mode` روی `overwrite` (پیش‌فرض) تنظیم شود، تصاویر با نام‌هایی مانند `image_00000.png` ذخیره می‌شوند و هر فایل موجود با همان نام جایگزین می‌شود. وقتی `mode` روی `increment` تنظیم شود، یک شمارنده به‌طور خودکار افزایش‌یافته به نام فایل‌ها اضافه می‌شود تا فایل‌های موجود بازنویسی نشوند.

مقدار `folder_name` باید به مکانی در داخل دایرکتوری خروجی ComfyUI اشاره کند. نام پوشه‌هایی که سعی در خروج از دایرکتوری خروجی دارند (مثلاً با استفاده از `..`) رد می‌شوند.
