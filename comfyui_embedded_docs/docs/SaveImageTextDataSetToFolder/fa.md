# ذخیره مجموعه تصویر و متن در پوشه

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|---------|----------|-----------|----------|-------|
| `تصاویر` | فهرستی از تصاویر برای ذخیره. | IMAGE | بله | - |
| `متون` | فهرستی از شرح‌های متنی برای ذخیره. این ورودی اختیاری است. | STRING | خیر | - |
| `نام پوشه` | نام پوشه‌ای که تصاویر در آن ذخیره می‌شوند (داخل دایرکتوری خروجی). (پیش‌فرض: "dataset") | STRING | بله | - |
| `پیشوند نام فایل تصویر` | پیشوند نام فایل‌های تصویر ذخیره‌شده. (پیش‌فرض: "image") | STRING | بله | - |
| `حالت` | اینکه فایل‌های موجود بازنویسی شوند یا نام فایل‌ها افزایش یابد تا بازنویسی رخ ندهد. (پیش‌فرض: "overwrite") | COMBO | بله | "overwrite"<br>"increment" |

**نکته:** ورودی `images` یک فهرست است. ورودی `texts` اختیاری است؛ اگر ارائه شود، باید فهرستی از شرح‌های متنی باشد و تعداد آیتم‌های آن با `images` یکسان باشد. هر شرح به‌صورت یک فایل `.txt` متناظر با تصویر جفت‌شده ذخیره می‌شود. در حالت `overwrite`، فایل‌ها با نام `{filename_prefix}_{index}.png` نام‌گذاری می‌شوند و هر فایل موجود با همان نام را جایگزین می‌کنند. در حالت `increment`، یک شمارنده یکتا به نام فایل‌ها اضافه می‌شود تا فایل‌های موجود بازنویسی نشوند. `folder_name` باید به مسیری در داخل دایرکتوری خروجی اشاره کند؛ نام‌های پوشه‌ای که سعی در فرار از آن دارند (مثلاً با `..`) رد می‌شوند.
