# SaveImageTextDataSetToFolder

Save Image-Text (to Folder) שומר מערך נתונים של זוגות תמונה וכיתוב טקסט לתיקייה בתוך תיקיית הפלט של ComfyUI. כל תמונה נכתבת כקובץ PNG, והכיתוב המתאים לה נכתב כקובץ TXT עם אותו שם בסיס, כך שכל תמונה נשמרת כשהיא משויכת לתיאור שלה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | רשימת תמונות לשמירה. | IMAGE | כן | - |
| `texts` | רשימת כיתובי טקסט לשמירה. קלט זה אופציונלי. | STRING | לא | - |
| `folder_name` | שם התיקייה שאליה יש לשמור תמונות (בתוך תיקיית הפלט). (ברירת מחדל: "dataset") | STRING | כן | - |
| `filename_prefix` | קידומת לשמות קבצי התמונות הנשמרים. (ברירת מחדל: "image") | STRING | כן | - |
| `mode` | האם לדרוס קבצים קיימים או להוסיף מונה לשמות הקבצים כדי להימנע מדריסה. (ברירת מחדל: "overwrite") | COMBO | כן | "overwrite"<br>"increment" |

**הערה:** קלט `images` הוא רשימה, והצומת מקבל גם את `images` וגם את `texts` כרשימות. קלט `texts` הוא אופציונלי; אם הוא מסופק, עליו להיות רשימה של כיתובי טקסט ולהכיל את אותו מספר פריטים כמו `images`. כל כיתוב נשמר כקובץ `.txt` המתאים לתמונה המשויכת אליו. במצב `overwrite`, הקבצים נקראים `{filename_prefix}_{index}.png` ומחליפים קבצים קיימים עם אותו שם. במצב `increment`, מתווסף מונה ייחודי לשמות הקבצים כך שקבצים קיימים לא יידרסו. השם `folder_name` חייב להתפרש לנתיב בתוך תיקיית הפלט; שמות תיקיות שמנסים לצאת ממנה (לדוגמה באמצעות `..`) נדחים.
