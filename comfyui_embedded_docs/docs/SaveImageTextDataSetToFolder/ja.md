# 画像とテキストのデータセットをフォルダに保存

Save Image-Text (to Folder) は、画像とテキストキャプションのペアからなるデータセットを、ComfyUI の出力ディレクトリ内のフォルダに保存する出力ノードです。各画像は PNG ファイルとして保存され、キャプションが指定されている場合は、各画像と同じベース名の TXT ファイルが作成されます。これは、生成された画像とその説明文を整理したデータセットを構築するのに役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | 保存する画像のリスト。 | IMAGE | 必須 | - |
| `texts` | 保存するテキストキャプションのリスト。この入力はオプションです。 | STRING | 任意 | - |
| `folder_name` | 画像を保存するフォルダ名（出力ディレクトリ内）。（デフォルト："dataset"） | STRING | 必須 | - |
| `filename_prefix` | 保存される画像ファイル名のプレフィックス。（デフォルト："image"） | STRING | 必須 | - |
| `mode` | 既存ファイルを上書きするか、ファイル名を増分して上書きを回避するか。（デフォルト："overwrite"） | COMBO | 必須 | "overwrite"<br>"increment" |

**注記:** `images` 入力はリストです。`texts` 入力はオプションであり、指定する場合はテキストキャプションのリストにしてください。キャプションは画像と順番にペアリングされ、各キャプションは、ペアとなる画像と同じベース名の UTF-8 `.txt` ファイルとして保存されます（例：`image_00000.png` に対する `image_00000.txt`）。キャプションの数が画像より少ない場合、残りの画像はキャプションなしで保存されます。余分なキャプションは無視されます。

デフォルト値を持つ入力（`folder_name`、`filename_prefix`、`mode`）は接続する必要はありません。デフォルト値が自動的に使用されます。

`mode` が `overwrite`（デフォルト）に設定されている場合、画像は `image_00000.png` のような名前で保存され、同じ名前の既存ファイルを置き換えます。`mode` が `increment` に設定されている場合、ファイル名に自動的に増加するカウンタが追加されるため、既存ファイルは上書きされません。

`folder_name` の値は、ComfyUI の出力ディレクトリ内の場所に解決される必要があります。出力ディレクトリの外に逃げようとするフォルダ名（例：`..` を使用するもの）は拒否されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| - | このノードには出力がありません。ファイルシステムに直接ファイルを保存します。 | - |
