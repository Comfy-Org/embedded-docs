# حفظ مجموعة بيانات الصور والنصوص في مجلد

تحفظ عقدة Save Image-Text (to Folder) مجموعة بيانات من أزواج الصور والتعليقات النصية في مجلد داخل دليل مخرجات ComfyUI. تُكتب كل صورة كملف PNG، ويُكتب التعليق النصي المطابق لها كملف TXT يحمل نفس اسم الملف الأساسي، بحيث تنتهي كل صورة مقترنة بوصفها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | قائمة الصور المراد حفظها. | IMAGE | نعم | - |
| `texts` | قائمة التعليقات النصية المراد حفظها. هذا المدخل اختياري. | STRING | لا | - |
| `folder_name` | اسم المجلد الذي ستُحفظ فيه الصور (داخل دليل المخرجات). (الافتراضي: "dataset") | STRING | نعم | - |
| `filename_prefix` | بادئة أسماء ملفات الصور المحفوظة. (الافتراضي: "image") | STRING | نعم | - |
| `mode` | ما إذا كان سيتم استبدال الملفات الموجودة أو زيادة أسماء الملفات لتجنب الاستبدال. (الافتراضي: "overwrite") | COMBO | نعم | "overwrite"<br>"increment" |

**ملاحظة:** المدخل `images` عبارة عن قائمة، وتستقبل العقدة كلاً من `images` و`texts` كقوائم. المدخل `texts` اختياري؛ وإذا تم توفيره، فيجب أن يكون قائمة من التعليقات النصية وأن يحتوي على نفس عدد العناصر الموجودة في `images`. يُحفظ كل تعليق كملف `.txt` يقابل الصورة المقترنة به. في وضع `overwrite`، تُسمّى الملفات `{filename_prefix}_{index}.png` وتستبدل أي ملفات موجودة بالاسم نفسه. في وضع `increment`، يُضاف عدّاد فريد إلى أسماء الملفات حتى لا تُستبدل الملفات الموجودة. يجب أن يشير `folder_name` إلى مسار داخل دليل المخرجات؛ تُرفض أسماء المجلدات التي تحاول الخروج منه (على سبيل المثال باستخدام `..`).

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------|-----------|
| - | لا تُرجع هذه العقدة أي بيانات. بل تحفظ الملفات مباشرةً في نظام الملفات. | - |
