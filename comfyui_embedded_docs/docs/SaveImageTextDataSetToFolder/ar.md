# حفظ مجموعة بيانات الصور والنصوص في مجلد

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | قائمة الصور المطلوب حفظها. | IMAGE | نعم | - |
| `texts` | قائمة التعليقات النصية المطلوب حفظها. هذا المدخل اختياري. | STRING | لا | - |
| `folder_name` | اسم المجلد الذي ستُحفظ فيه الصور (داخل دليل الإخراج). (الافتراضي: "dataset") | STRING | نعم | - |
| `filename_prefix` | البادئة المستخدمة في أسماء ملفات الصور المحفوظة. (الافتراضي: "image") | STRING | نعم | - |
| `الوضع` | يحدد ما إذا كان سيتم استبدال الملفات الموجودة أو زيادة أرقام الملفات لتجنب الاستبدال. (الافتراضي: "overwrite") | COMBO | نعم | "overwrite"<br>"increment" |

**ملاحظة:** المدخل `images` عبارة عن قائمة. المدخل `texts` اختياري؛ إذا تم توفيره، فيجب أن يكون قائمة من التعليقات النصية ويحتوي على نفس عدد العناصر الموجودة في `images`. يُحفظ كل تعليق كملف `.txt` يقابل الصورة المرتبطة به. في وضع «overwrite»، تُسمى الملفات `{filename_prefix}_{index}.png` وتستبدل أي ملفات موجودة بنفس الاسم. في وضع «increment»، يُضاف عدّاد فريد إلى أسماء الملفات بحيث لا يتم استبدال الملفات الموجودة. يجب أن يُفضي `folder_name` إلى مسار داخل دليل الإخراج؛ ويُرفض أي اسم مجلد يحاول تجاوزه (على سبيل المثال باستخدام `..`).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| - | لا يُرجع هذا العقد أي بيانات. فهو يحفظ الملفات مباشرة إلى نظام الملفات. | - |
