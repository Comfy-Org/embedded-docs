# حفظ مجموعة بيانات الصور والنصوص في مجلد

حفظ الصورة والنص (إلى مجلد) هو عقدة إخراج تحفظ مجموعة بيانات من الصور المقترنة بالتسميات التوضيحية النصية إلى مجلد داخل دليل الإخراج الخاص بـ ComfyUI. يتم حفظ كل صورة كملف PNG، وعند توفير تسميات توضيحية، يتم إنشاء ملف TXT مطابق بنفس الاسم الأساسي لكل صورة. وهذا مفيد لبناء مجموعات بيانات منظمة من الصور المولّدة وأوصافها.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `images` | قائمة الصور المراد حفظها. | IMAGE | نعم | - |
| `texts` | قائمة التسميات التوضيحية النصية المراد حفظها. هذا الإدخال اختياري. | STRING | لا | - |
| `folder_name` | اسم المجلد الذي سيتم حفظ الصور فيه (داخل دليل الإخراج). (الافتراضي: "dataset") | STRING | نعم | - |
| `filename_prefix` | بادئة لأسماء ملفات الصور المحفوظة. (الافتراضي: "image") | STRING | نعم | - |
| `mode` | ما إذا كان سيتم استبدال الملفات الموجودة أو زيادة أسماء الملفات لتجنب الاستبدال. (الافتراضي: "overwrite") | COMBO | نعم | "overwrite"<br>"increment" |

**ملاحظة:** إدخال `images` عبارة عن قائمة. إدخال `texts` اختياري؛ إذا تم توفيره، فيجب أن يكون قائمة من التسميات التوضيحية النصية. يتم إقران التسميات التوضيحية بالصور بالترتيب، ويتم حفظ كل تسمية كملف `.txt` بترميز UTF-8 بنفس الاسم الأساسي للصورة المقترنة (على سبيل المثال، `image_00000.txt` لـ `image_00000.png`). إذا كان عدد التسميات التوضيحية أقل من عدد الصور، فسيتم حفظ الصور المتبقية بدون تسميات توضيحية؛ ويتم تجاهل أي تسميات إضافية.

المدخلات ذات القيم الافتراضية (`folder_name`, `filename_prefix`, `mode`) لا تحتاج إلى توصيل؛ يتم استخدام قيمها الافتراضية تلقائيًا.

عند تعيين `mode` إلى `overwrite` (الافتراضي)، يتم حفظ الصور بأسماء مثل `image_00000.png`، مع استبدال أي ملفات موجودة بنفس الاسم. عند تعيين `mode` إلى `increment`، تتم إضافة عداد يزداد تلقائيًا إلى أسماء الملفات بحيث لا يتم استبدال الملفات الموجودة.

يجب أن تشير قيمة `folder_name` إلى موقع داخل دليل الإخراج الخاص بـ ComfyUI. أسماء المجلدات التي تحاول الخروج من دليل الإخراج (على سبيل المثال، باستخدام `..`) يتم رفضها.
