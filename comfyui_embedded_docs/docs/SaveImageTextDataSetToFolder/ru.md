# Сохранить набор изображений и текстов в папку

Save Image-Text (to Folder) сохраняет набор пар «изображение — текстовая подпись» в папку внутри выходной директории ComfyUI. Каждое изображение записывается как PNG-файл, а соответствующая ему подпись — как TXT-файл с тем же базовым именем, поэтому каждое изображение оказывается в паре со своим описанием.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Список изображений для сохранения. | IMAGE | Да | - |
| `texts` | Список текстовых подписей для сохранения. Этот вход необязателен. | STRING | Нет | - |
| `folder_name` | Имя папки для сохранения изображений (внутри выходной директории). (по умолчанию: "dataset") | STRING | Да | - |
| `filename_prefix` | Префикс для имён сохраняемых файлов изображений. (по умолчанию: "image") | STRING | Да | - |
| `режим` | Перезаписывать существующие файлы или увеличивать имена файлов, чтобы избежать перезаписи. (по умолчанию: "overwrite") | COMBO | Да | "overwrite"<br>"increment" |

**Примечание:** Вход `images` является списком, и узел получает как `images`, так и `texts` в виде списков. Вход `texts` необязателен; если он указан, это должен быть список текстовых подписей, содержащий столько же элементов, сколько `images`. Каждая подпись сохраняется как файл `.txt`, соответствующий парному изображению. В режиме `overwrite` файлы именуются `{filename_prefix}_{index}.png` и заменяют любые существующие файлы с тем же именем. В режиме `increment` к именам файлов добавляется уникальный счётчик, чтобы существующие файлы не перезаписывались. `folder_name` должен разрешаться в путь внутри выходной директории; имена папок, которые пытаются выйти за её пределы (например, с помощью `..`), отклоняются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| - | Этот узел не возвращает данных. Он сохраняет файлы напрямую в файловую систему. | - |
