# Сохранить набор изображений и текстов в папку

Save Image-Text (to Folder) сохраняет список изображений и соответствующие им текстовые подписи в указанную папку внутри выходного каталога ComfyUI. Для каждого изображения, сохранённого в формате PNG, создаётся соответствующий TXT-файл с тем же базовым именем для хранения его подписи, что полезно для создания организованных наборов данных из сгенерированных изображений с их описаниями.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Список изображений для сохранения. | IMAGE | Да | - |
| `texts` | Список текстовых подписей для сохранения. Этот вход необязательный. | STRING | Нет | - |
| `folder_name` | Имя папки для сохранения изображений (внутри выходного каталога). (по умолчанию: "dataset") | STRING | Да | - |
| `filename_prefix` | Префикс для имён сохраняемых файлов изображений. (по умолчанию: "image") | STRING | Да | - |
| `режим` | Определяет, следует ли перезаписывать существующие файлы или увеличивать номера имён файлов, чтобы избежать перезаписи. (по умолчанию: "overwrite") | COMBO | Да | "overwrite"<br>"increment" |

**Примечание:** Вход `images` представляет собой список. Вход `texts` необязательный; если он задан, это должен быть список текстовых подписей, содержащий то же количество элементов, что и `images`. Каждая подпись сохраняется в виде `.txt`-файла, соответствующего связанному с ней изображению. В режиме `overwrite` файлы называются `{filename_prefix}_{index}.png` и заменяют любые существующие файлы с тем же именем. В режиме `increment` к именам файлов добавляется уникальный счётчик, чтобы существующие файлы не перезаписывались. `folder_name` должен указывать на путь внутри выходного каталога; имена папок, пытающиеся выйти за его пределы (например, с `..`), отклоняются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| - | Этот узел не возвращает данных. Он сохраняет файлы непосредственно в файловую систему. | - |
