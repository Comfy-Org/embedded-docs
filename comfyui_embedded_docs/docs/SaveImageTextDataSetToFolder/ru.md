# Сохранить набор изображений и текстов в папку

Узел Save Image-Text (to Folder) — это выходной узел, который сохраняет набор пар «изображение-текст» в папку внутри каталога вывода ComfyUI. Каждое изображение сохраняется как PNG-файл, а при наличии подписей для каждого изображения создается соответствующий TXT-файл с тем же базовым именем. Это полезно для создания организованных наборов данных сгенерированных изображений и их описаний.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Список изображений для сохранения. | IMAGE | Да | - |
| `texts` | Список текстовых подписей для сохранения. Этот вход необязательный. | STRING | Нет | - |
| `folder_name` | Имя папки для сохранения изображений (внутри каталога вывода). (по умолчанию: "dataset") | STRING | Да | - |
| `filename_prefix` | Префикс для имен сохраняемых файлов изображений. (по умолчанию: "image") | STRING | Да | - |
| `mode` | Определяет, следует ли перезаписывать существующие файлы или увеличивать имена файлов во избежание перезаписи. (по умолчанию: "overwrite") | COMBO | Да | "overwrite"<br>"increment" |

**Примечание:** вход `images` является списком. Вход `texts` необязателен; если он задан, это должен быть список текстовых подписей. Подписи сопоставляются с изображениями по порядку, и каждая подпись сохраняется как UTF-8 `.txt`-файл с тем же базовым именем, что и соответствующее изображение (например, `image_00000.txt` для `image_00000.png`). Если подписей меньше, чем изображений, оставшиеся изображения сохраняются без подписей; лишние подписи игнорируются.

Входы со значениями по умолчанию (`folder_name`, `filename_prefix`, `mode`) не обязательно подключать; их значения по умолчанию используются автоматически.

Когда для параметра `mode` установлено значение `overwrite` (по умолчанию), изображения сохраняются с именами вида `image_00000.png`, заменяя существующие файлы с тем же именем. Когда для параметра `mode` установлено значение `increment`, к именам файлов добавляется автоматически увеличивающийся счетчик, чтобы существующие файлы не перезаписывались.

Значение `folder_name` должно указывать на расположение внутри каталога вывода ComfyUI. Имена папок, которые пытаются выйти за пределы каталога вывода (например, с помощью `..`), отклоняются.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| - | У этого узла нет выходов. Он сохраняет файлы напрямую в файловую систему. | - |
