# PerturbedAttentionGuidance

گره PerturbedAttentionGuidance راهنمایی توجهِ برهم‌خورده را روی یک مدل انتشار اعمال می‌کند تا کیفیت تولید را بهبود بخشد. این گره فرآیند نویززدایی مدل را در طول نمونه‌برداری با مقایسهٔ پیش‌بینی شرطی عادی با پیش‌بینی‌ای که با استفاده از یک مکانیزم توجه ساده‌شده فقط با فرافکنی‌های مقدار (value) ساخته شده است، تنظیم می‌کند و سپس اختلافِ مقیاس‌شده را به نتیجه اضافه می‌کند. وقتی مقیاس روی 0 تنظیم شود، گره هیچ اثری ندارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل انتشاری که راهنمایی توجهِ برهم‌خورده روی آن اعمال می‌شود | MODEL | بله | - |
| `مقیاس` | قدرت اثر راهنمایی توجهِ برهم‌خورده (پیش‌فرض: 3.0). وقتی روی 0 تنظیم شود، گره هیچ اثری ندارد و نتیجهٔ نویززدایی‌شدهٔ اصلی را بازمی‌گرداند. | FLOAT | بله | 0.0 - 100.0 (گام: 0.01) |

## خروجی‌ها

| `model` | مدل اصلاح‌شده با راهنمایی توجهِ برهم‌خورده اعمال‌شده | MODEL |
