# 擾動注意力引導

PerturbedAttentionGuidance 節點會將擾動注意力引導套用至擴散模型，以提升生成品質。在取樣期間，它會進行一次額外預測，其中中間區塊的自注意力會由簡化版本取代，該版本直接傳遞 value 投影，然後將一般條件預測與此擾動預測之間的經縮放差異加到去雜訊結果中。將 `scale` 設為 0 會完全停用此效果。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要對其套用擾動注意力引導的擴散模型 | MODEL | 是 | - |
| `比例` | 擾動注意力引導效果的強度（預設：3.0）。設為 0 時，此節點不會產生任何效果，並原樣傳回原始去雜訊結果。 | FLOAT | 是 | 0.0 - 100.0 （步進值：0.01） |
