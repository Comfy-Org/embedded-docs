# 擾動注意力引導

PerturbedAttentionGuidance 節點將擾動注意力引導應用於擴散模型，以提升生成品質。它在採樣期間調整模型的去噪過程，方式是將正常的條件預測與使用僅包含值投影的簡化注意力機制所做的預測進行比較，然後將縮放後的差異加回結果中。當 `scale` 設定為 0 時，此節點不產生任何效果。
