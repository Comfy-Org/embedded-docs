# 교란 어텐션 유도 (PAG)

PerturbedAttentionGuidance 노드는 생성 품질을 향상시키기 위해 확산 모델에 섭동 어텐션 가이던스를 적용합니다. 이 노드는 샘플링 중 모델의 자기 어텐션 메커니즘을 값 투영에 초점을 맞춘 단순화된 버전으로 대체하여 수정합니다. 이 기법은 조건부 노이즈 제거 과정을 조정하여 생성된 이미지의 일관성과 품질을 향상시키는 데 도움이 됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 섭동 어텐션 가이던스를 적용할 확산 모델 | MODEL | 예 | - |
| `scale` | 섭동 어텐션 가이던스 효과의 강도(기본값: 3.0). 0으로 설정하면 노드가 효과를 내지 않으며 원래의 노이즈 제거 결과를 반환합니다. | FLOAT | 예 | 0.0 - 100.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 섭동 어텐션 가이던스가 적용된 수정된 모델 | MODEL |
