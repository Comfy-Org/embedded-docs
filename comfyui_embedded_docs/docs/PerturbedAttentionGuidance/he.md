# PerturbedAttentionGuidance

הצומת PerturbedAttentionGuidance מחיל הנחיית קשב מופרעת על מודל דיפוזיה כדי לשפר את איכות היצירה. במהלך הדגימה הוא מבצע חיזוי נוסף שבו הקשב העצמי של הבלוק האמצעי מוחלף בגרסה פשוטה שמעבירה את הטלות ה-value ישירות, ואז מוסיף לתוצאה המנוקה מרעש את ההפרש המוכפל ב-`scale` בין החיזוי המותנה הרגיל לבין החיזוי המופרע. הגדרת `scale` ל-0 מבטלת את ההשפעה לחלוטין.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל הדיפוזיה שעליו להחיל הנחיית קשב מופרעת | MODEL | כן | - |
| `scale` | עוצמת אפקט הנחיית הקשב המופרעת (ברירת מחדל: 3.0). כאשר מוגדר ל-0, לצומת אין השפעה והיא מחזירה את התוצאה המנוקה מרעש המקורית ללא שינוי. | FLOAT | כן | 0.0 - 100.0 (step: 0.01) |
