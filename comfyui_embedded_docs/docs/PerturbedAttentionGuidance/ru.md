# Направление с учётом возмущений

Узел PerturbedAttentionGuidance применяет управление с возмущённым вниманием (perturbed attention guidance) к диффузионной модели для повышения качества генерации. Во время сэмплирования он делает дополнительное предсказание, в котором self-attention среднего блока заменяется упрощённой версией, пропускающей проекции значений напрямую, после чего добавляет масштабированную разность между обычным условным предсказанием и этим возмущённым предсказанием к результату денойзинга. Установка `scale` в 0 полностью отключает эффект.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Диффузионная модель, к которой применяется управление с возмущённым вниманием | MODEL | Да | - |
| `масштаб` | Сила эффекта управления с возмущённым вниманием (по умолчанию: 3.0). При значении 0 узел не оказывает эффекта и возвращает исходный результат денойзинга без изменений. | FLOAT | Да | 0.0 - 100.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `model` | Модифицированная модель с патчем управления с возмущённым вниманием, прикреплённым к её процессу сэмплирования | MODEL |
