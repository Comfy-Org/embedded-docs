# Направление с учётом возмущений

Узел PerturbedAttentionGuidance применяет руководство по возмущённому вниманию к диффузионной модели для улучшения качества генерации. Он корректирует процесс шумоподавления модели во время сэмплирования, сравнивая обычное условное предсказание с предсказанием, полученным с использованием упрощённого механизма внимания, который использует только проекции значений, а затем добавляет масштабированную разность обратно к результату. Когда значение `scale` установлено на 0, узел не оказывает эффекта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Диффузионная модель, к которой применяется руководство по возмущённому вниманию | MODEL | Да | - |
| `масштаб` | Сила эффекта руководства по возмущённому вниманию (по умолчанию: 3.0). При значении 0 узел не оказывает эффекта и возвращает исходный результат шумоподавления. | FLOAT | Да | 0.0 - 100.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Модифицированная модель с применённым руководством по возмущённому вниманию | MODEL |
