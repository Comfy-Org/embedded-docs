# Направление с учётом возмущений

Узел PerturbedAttentionGuidance применяет направление возмущённого внимания (perturbed attention guidance) к диффузионной модели для повышения качества генерации. Он изменяет механизм самовнимания модели во время сэмплирования, заменяя его упрощённой версией, которая фокусируется на проекциях значений. Этот метод помогает улучшить согласованность и качество генерируемых изображений за счёт корректировки процесса условного шумоподавления.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется направление возмущённого внимания | MODEL | Да | - |
| `scale` | Сила эффекта направления возмущённого внимания (по умолчанию: 3.0). Если установлено значение 0, узел не оказывает эффекта и возвращает исходный результат шумоподавления. | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым направлением возмущённого внимания | MODEL |
