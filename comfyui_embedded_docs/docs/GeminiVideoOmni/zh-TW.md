# Google Gemini Omni（影片）

以下是翻譯後的繁體中文文檔：

使用 Google 的 Gemini Omni Flash 模型，根據文字提示生成帶有音訊的影片。可選擇性地提供參考圖片和/或影片來引導或編輯結果。請直接在提示中描述所需的長度（3-10 秒）和長寬比（16:9 或 9:16）。
