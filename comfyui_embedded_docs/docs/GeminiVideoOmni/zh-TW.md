# Google Gemini Omni（影片）

使用 Google 的 Gemini Omni Flash 模型，從文字提示生成帶有音訊的影片。可選擇提供參考圖片和/或影片來引導或編輯結果。請直接在提示中描述所需的長度（3-10 秒）和長寬比（16:9 或 9:16）。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成影片的 Gemini 影片模型。 | COMBO | 是 | "Omni Flash" |
| `seed` | 種子控制節點是否應重新執行；無論種子為何，結果皆為非確定性（預設值：42）。 | INT | 是 | 0 至 2147483647 |
| `prompt` | 描述要生成之影片的文字提示。去除前後空白後，至少需包含一個非空白字元。 | STRING | 是 | 去除空白後至少 1 個字元 |
| `images` | 可選的參考圖片，用於引導影片生成。總共最多 14 張圖片。 | IMAGE | 否 | 允許複數圖片（最多 14 張） |
| `videos` | 可選的參考影片，用於引導或編輯影片生成。最多 3 個影片，每個最長 10 秒。 | VIDEO | 否 | 允許複數影片（最多 3 個，每個最長 10 秒） |
| `temperature` | 控制生成過程中的隨機性（預設值：1.0）。 | FLOAT | 否 | 0.0 至 2.0 |
| `top_p` | 核心取樣參數（預設值：0.95）。 | FLOAT | 否 | 0.0 至 1.0 |

注意：
- 如果圖片輸入包含多個影格，每個影格都會計入最多 14 張圖片的限制。
- 當提供 `images` 或 `videos` 時，合併後的編碼媒體大小必須保持在約 90 MB 以下；否則節點會引發錯誤。
