# Google Gemini Omni（影片）

使用 Google 的 Gemini Omni Flash 模型，根據文字提示詞產生包含音訊的影片。可選擇提供參考影像及/或影片，以引導或編輯結果。請直接在提示詞中描述所需的長度（3-10 秒）與長寬比（16:9 或 9:16）。
