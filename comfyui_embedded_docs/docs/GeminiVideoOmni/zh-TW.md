# Google Gemini Omni（影片）

使用 Google 的 Gemini Omni Flash 模型，依據文字提示生成帶有音訊的影片。可選擇提供參考圖片和/或影片來引導或編輯結果。請直接在提示中描述所需的長度（3-10 秒）與長寬比（16:9 或 9:16）。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成影片的 Gemini 影片模型。 | COMBO | 是 | "Omni Flash" |
| `seed` | 種子（Seed）控制節點是否應重新執行；無論種子為何，結果都不具確定性（預設值：42）。 | INT | 是 | 0 到 2147483647 |

### Omni Flash 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述要生成的影片。請直接在提示中指定長度與長寬比，例如「一個 6 秒、16:9 的片段」。長度可為 3-10 秒；長寬比必須為 16:9（橫向）或 9:16（直向）。輸出為 720p、24 FPS，並包含音訊。 | STRING | 是 | 去除空白後最少 1 個字元 |
| `images` | 可擴充插槽：連接一個或多個參考圖片（`image_1`...`image_14`）以引導或製作影片動畫。總共最多 14 張圖片。 | IMAGE | 否 | 0 到 14 張圖片 |
| `videos` | 可擴充插槽：連接一個或多個參考影片（`video_1`...`video_3`）以引導或編輯。最多 3 個影片，每個最長 10 秒。 | VIDEO | 否 | 0 到 3 個影片，每個最長 10 秒 |

備註：
- 若圖片輸入包含多個影格，每個影格都會計入 14 張圖片的數量上限。
- 當提供參考圖片或影片時，編碼後的媒體總大小必須保持在約 90 MB 以下；否則節點會回報錯誤。
- 若未提供參考圖片或影片，節點僅依據文字提示生成影片。
