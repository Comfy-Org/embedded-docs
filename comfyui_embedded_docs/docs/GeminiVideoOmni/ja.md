# Google Gemini Omni（動画）

Google の Gemini Omni Flash モデルを使用して、テキストプロンプトから音声付き動画を生成します。必要に応じて参照画像や参照動画を提供し、結果をガイドまたは編集できます。希望する長さ（3〜10秒）とアスペクト比（16:9 または 9:16）をプロンプトに直接記述してください。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画の生成に使用する Gemini ビデオモデル。 | DYNAMIC_COMBO | 必須 | "Omni Flash" |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 42）。 | INT | 必須 | 0 〜 2147483647 |

### Omni Flash 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画を説明します。長さとアスペクト比をプロンプトに直接指定してください（例:「a 6-second clip in 16:9」）。長さは3〜10秒、アスペクト比は16:9（横向き）または9:16（縦向き）にしてください。出力は720p、24 FPS、音声付きです。 | STRING | 必須 | Minimum 1 character after stripping whitespace |
| `images` | 拡張可能スロット: 動画をガイドまたはアニメーション化するために、1つ以上の参照画像（`image_1`...`image_14`）を接続します。合計で最大14枚の画像。 | IMAGE | 任意 | 0 〜 14 images |
| `videos` | 拡張可能スロット: ガイドまたは編集のために、1つ以上の参照動画（`video_1`...`video_3`）を接続します。最大3本の動画で、各動画は最大10秒です。 | VIDEO | 任意 | 0 〜 3 videos, each max 10 seconds |
| `temperature` | ランダム性を制御します。値が低いほど焦点が絞られ決定論的になり、高いほど多様になります（デフォルト: 1.0）。 | FLOAT | 任意 | 0.0 〜 2.0 |
| `top_p` | Nucleus サンプリング: 累積確率が top_p に達する最小のトークンセットからサンプリングします（デフォルト: 0.95）。 | FLOAT | 任意 | 0.0 〜 1.0 |

注記:
- 画像入力に複数のフレームが含まれる場合、各フレームが最大14枚の画像にカウントされます。
- 参照画像または参照動画を提供する場合、エンコードされたメディアの合計サイズが約90 MB未満である必要があります。それ以外の場合はノードがエラーを発生させます。
- 参照画像も参照動画も提供しない場合、ノードはテキストプロンプトのみから動画を生成します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | Gemini モデルによって生成された、音声付きの動画。 | VIDEO |
| `STRING` | 推論や説明など、モデルからのテキスト応答。 | STRING |
