# Google Gemini Omni（動画）

Google の Gemini Omni Flash モデルを使用して、テキストプロンプトから音声付きの動画を生成します。オプションで参照画像や参照動画を提供して、結果をガイドまたは編集できます。希望する長さ（3〜10秒）とアスペクト比（16:9 または 9:16）は、プロンプトに直接記述してください。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画の生成に使用する Gemini ビデオモデルです。 | COMBO | はい | "Omni Flash" |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です（デフォルト: 42）。 | INT | はい | 0 to 2147483647 |

### Omni Flash 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画を記述します。長さとアスペクト比はプロンプトに直接指定してください。例: 「a 6-second clip in 16:9」のように指定します。長さは3〜10秒、アスペクト比は16:9（横）または9:16（縦）にしてください。出力は720p、24 FPS、音声付きです。 | STRING | はい | Minimum 1 character after stripping whitespace |
| `images` | 拡張可能なスロットです。動画をガイドまたはアニメーション化するために、参照画像（`image_1`...`image_14`）を1枚以上接続します。合計で最大14枚まで指定できます。 | IMAGE | いいえ | 0 to 14 images |
| `videos` | 拡張可能なスロットです。動画をガイドまたは編集するために、参照動画（`video_1`...`video_3`）を1つ以上接続します。最大3つまで指定でき、各動画は最大10秒です。 | VIDEO | いいえ | 0 to 3 videos, each max 10 seconds |
| `temperature` | ランダム性を制御します。値が低いほど焦点が定まり決定論的になり、値が高いほど多様になります（デフォルト: 1.0）。 | FLOAT | いいえ | 0.0 to 2.0 |
| `top_p` | Nucleusサンプリング: 累積確率が top_p に達する最小のトークンセットからサンプリングします（デフォルト: 0.95）。 | FLOAT | いいえ | 0.0 to 1.0 |

注意事項:
- 画像入力に複数のフレームが含まれる場合、各フレームが最大14枚の画像にカウントされます。
- 参照画像または参照動画を指定する場合、エンコード後のメディアの合計サイズが約90MB未満である必要があります。そうでない場合、ノードはエラーを発生させます。
- 参照画像や参照動画が指定されていない場合、ノードはテキストプロンプトのみから動画を生成します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | Gemini モデルによって生成された、音声付きの動画です。 | VIDEO |
| `STRING` | 推論や説明など、モデルからのテキスト応答です。 | STRING |
