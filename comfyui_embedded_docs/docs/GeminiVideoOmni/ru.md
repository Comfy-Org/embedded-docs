# Google Gemini Omni (Video)

Создайте видео со звуком по текстовому запросу с использованием модели Google Gemini Omni Flash. При необходимости укажите референсные изображения и/или видео для управления или редактирования результата. Укажите желаемую длительность (3–10 с) и соотношение сторон (16:9 или 9:16) непосредственно в запросе.

## Входные параметры

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Gemini, используемая для генерации видео. | COMBO | Да | "Omni Flash" |
| `seed` | Seed управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от значения seed (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |
| `prompt` | Текстовый запрос, описывающий видео для генерации. Должен содержать не менее одного непробельного символа после удаления ведущих и завершающих пробелов. | STRING | Да | Минимум 1 символ после удаления пробелов |
| `images` | Необязательные референсные изображения для управления генерацией видео. Максимум 14 изображений суммарно. | IMAGE | Нет | Допускается несколько изображений (макс. 14) |
| `videos` | Необязательные референсные видео для управления или редактирования генерации видео. Максимум 3 видео, каждое до 10 секунд. | VIDEO | Нет | Допускается несколько видео (макс. 3, каждое макс. 10 с) |
| `temperature` | Управляет случайностью при генерации (по умолчанию: 1.0). | FLOAT | Нет | от 0.0 до 2.0 |
| `top_p` | Параметр nucleus-сэмплирования (по умолчанию: 0.95). | FLOAT | Нет | от 0.0 до 1.0 |

Примечания:
- Если входное изображение содержит несколько кадров, каждый кадр учитывается в максимальном количестве 14 изображений.
- Когда указаны `images` или `videos`, суммарный размер закодированных медиаданных должен оставаться меньше примерно 90 МБ; в противном случае узел выдаст ошибку.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуком от модели Gemini. | VIDEO |
| `STRING` | Любой текстовый ответ от модели, например, рассуждения или пояснения. | STRING |
