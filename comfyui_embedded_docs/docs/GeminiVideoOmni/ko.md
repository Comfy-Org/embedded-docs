# Google Gemini Omni (Video)

Google의 Gemini Omni Flash 모델을 사용하여 텍스트 프롬프트에서 오디오가 포함된 비디오를 생성합니다. 선택적으로 참조 이미지 및/또는 비디오를 제공하여 결과를 안내하거나 편집할 수 있습니다. 원하는 길이(3~10초)와 화면 비율(16:9 또는 9:16)을 프롬프트에 직접 명시하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용되는 Gemini 비디오 모델입니다. | DYNAMIC_COMBO | 예 | "Omni Flash" |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

### Omni Flash 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 비디오를 설명하세요. 길이와 화면 비율을 프롬프트에 직접 명시하세요(예: '16:9의 6초 클립'). 길이는 3~10초, 화면 비율은 16:9(가로) 또는 9:16(세로)이어야 합니다. 출력은 720p, 24FPS이며 오디오가 포함됩니다. | STRING | 예 | 공백 제거 후 최소 1자 |
| `images` | 확장 가능한 슬롯: 비디오를 안내하거나 애니메이션화하려면 참조 이미지(`image_1`...`image_14`)를 하나 이상 연결하세요. 최대 14개까지 연결할 수 있습니다. | IMAGE | 아니요 | 0~14개 이미지 |
| `videos` | 확장 가능한 슬롯: 가이드 또는 편집을 위해 참조 비디오(`video_1`...`video_3`)를 하나 이상 연결하세요. 최대 3개, 각각 최대 10초 길이입니다. | VIDEO | 아니요 | 비디오 0~3개, 각각 최대 10초 |
| `temperature` | 무작위성을 제어합니다. 낮을수록 집중적이고 결정적이며, 높을수록 다양해집니다(기본값: 1.0). | FLOAT | 아니요 | 0.0 ~ 2.0 |
| `top_p` | 핵 샘플링: 누적 확률이 top_p에 도달하는 가장 작은 토큰 집합에서 샘플링합니다(기본값: 0.95). | FLOAT | 아니요 | 0.0 ~ 1.0 |

참고 사항:
- 이미지 입력에 여러 프레임이 포함된 경우 각 프레임이 최대 14개 이미지 한도에 포함됩니다.
- 참조 이미지나 비디오를 제공하는 경우 인코딩된 미디어 총 크기가 약 90MB 미만이어야 합니다. 그렇지 않으면 노드에서 오류가 발생합니다.
- 참조 이미지나 비디오를 제공하지 않으면 노드는 텍스트 프롬프트만으로 비디오를 생성합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | Gemini 모델에서 생성된 오디오가 포함된 비디오입니다. | VIDEO |
| `STRING` | 모델의 텍스트 응답(예: 추론 또는 설명)입니다. | STRING |
