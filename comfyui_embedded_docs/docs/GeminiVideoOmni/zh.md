# Google Gemini Omni（视频）

使用 Google 的 Gemini Omni Flash 模型，根据文本提示生成带音频的视频。可以选择提供参考图像和/或视频，以指导或编辑结果。在提示中直接描述所需长度（3-10 秒）和宽高比（16:9 或 9:16）。
