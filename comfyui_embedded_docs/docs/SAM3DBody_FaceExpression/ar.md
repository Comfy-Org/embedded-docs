# تعبير الوجه إلى جسم SAM3D

يضيف هذا العقد تعبيرات الوجه إلى جسم SAM3D عبر اكتشاف الوجوه في صورة باستخدام MediaPipe Face Landmarker، ومطابقة كل وجه مكتشف مع شخص مُتتبَّع، ورسم خرائط بليندشيبس ARKit الـ52 على معاملات التعبير ذات المحاور الـ72 في MHR. ثم يعيد تشغيل نموذج الجسم بحيث تتطابق رؤوس الشبكة ونقاط المفاتيح الناتجة مع التعبير الجديد.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | نموذج جسم SAM3D الذي يحتوي على كاشف معالم الوجه المستخدم لاكتشاف الوجوه وإعادة توليد شبكة الجسم. | SAM3D_BODY_MODEL | نعم | - |
| `mhr_pose_data` | بيانات الوضعية التي تحتوي على الأشخاص المتتبعين لكل إطار مع الصناديق المحيطة ونقاط المفاتيح ومعاملات التعبير. يطابق العقد كل وجه مكتشف مع شخص ويكتب معاملات التعبير المحدثة في هذه البيانات. | MHR_POSE_DATA | نعم | - |
| `image` | إطارات الصورة المستخدمة لاكتشاف الوجوه. إذا كانت دفعة الصور تحتوي على إطارات أقل من بيانات الوضعية، يتم إعادة استخدام الإطار الأخير للإطارات المتبقية. | IMAGE | نعم | - |
| `strength` | مضاعِف عام لجميع البليندشيبس. القيم >1 تبالغ في التأثير. الافتراضي: 1.0. | FLOAT | لا | 0.0 إلى 4.0 (step 0.05, default 1.0) |
| `mouth_strength` | مضاعِف لأشكال الفم/الفك. قيمة jawOpen من MediaPipe تتشبع قرب 1.0. الافتراضي: 1.0. | FLOAT | لا | 0.0 إلى 4.0 (step 0.05, default 1.0) |
| `eye_strength` | مضاعِف لأشكال العينين. نادرًا ما يتجاوز MediaPipe قيمة 0.5؛ غالبًا ما تكون الحاجة إلى 2-3 أضعاف. الافتراضي: 2.0. | FLOAT | لا | 0.0 إلى 4.0 (step 0.05, default 2.0) |
| `brow_strength` | مضاعِف لأشكال الحاجب/الخد/الازدراء. تُخرج MediaPipe قيمًا بين 0.1 و0.3 تقريبًا؛ يُنصح بـ 2-3 أضعاف. الافتراضي: 2.0. | FLOAT | لا | 0.0 إلى 4.0 (step 0.05, default 2.0) |
| `input_threshold` | منطقة ميتة على مخرجات MediaPipe الخام (أقل من القيمة = صفر، أعلى = إعادة تخطيط خطية). الافتراضي: 0.02. | FLOAT | لا | 0.0 إلى 0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | نافذة غاوسية على إشارة MediaPipe لكل إطار قبل تعيين MHR. يتأرجح ناتج MediaPipe الخام بنسبة 30-70% من إطار لآخر على الوجوه الثابتة. 1 = معطّل. استخدم قيمًا فردية. الافتراضي: 7. | INT | لا | 1 إلى 31 (step 2, default 7) |

ملاحظة: يُطبَّق طرح خط الأساس لكل مقطع فقط عندما يحتوي المقطع على 30 إطارًا على الأقل تحتوي على أشخاص مكتشفين. تُملأ فجوات الاكتشاف حتى 12 إطارًا لكل شخص عن طريق الاستيفاء.
