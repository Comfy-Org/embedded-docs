# Выражение лица для тела SAM3D

Этот узел добавляет мимику к телу SAM3D, обнаруживая лица на изображении с помощью MediaPipe Face Landmarker, сопоставляя каждое обнаруженное лицо с отслеживаемым человеком и преобразуя 52 блендшейпа ARKit в 72-осевые параметры выражения MHR. Затем он повторно запускает модель тела, чтобы выходные вершины и ключевые точки меша соответствовали новому выражению.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | Модель тела SAM3D, содержащая детектор ориентиров лица, используемый для обнаружения лиц и повторной генерации меша тела. | SAM3D_BODY_MODEL | Да | - |
| `mhr_pose_data` | Данные позы, содержащие отслеживаемых людей с ограничивающими рамками, ключевыми точками и параметрами выражения для каждого кадра. Узел сопоставляет каждое обнаруженное лицо с человеком и записывает обновленные параметры выражения в эти данные. | MHR_POSE_DATA | Да | - |
| `изображение` | Кадры изображения, используемые для обнаружения лиц. Если в пакете изображений меньше кадров, чем в данных позы, последний кадр повторно используется для оставшихся кадров. | IMAGE | Да | - |
| `сила` | Глобальный множитель для всех блендшейпов. >1 усиливает. По умолчанию: 1.0. | FLOAT | Нет | от 0.0 до 4.0 (step 0.05, default 1.0) |
| `mouth_strength` | Множитель для форм рта/челюсти. У MediaPipe параметр jawOpen насыщается около 1.0. По умолчанию: 1.0. | FLOAT | Нет | от 0.0 до 4.0 (step 0.05, default 1.0) |
| `eye_strength` | Множитель для форм глаз. MediaPipe редко превышает 0.5; часто требуется 2-3x. По умолчанию: 2.0. | FLOAT | Нет | от 0.0 до 4.0 (step 0.05, default 2.0) |
| `brow_strength` | Множитель для форм бровей/щек/усмешки. MediaPipe выдает около 0.1-0.3; 2-3x. По умолчанию: 2.0. | FLOAT | Нет | от 0.0 до 4.0 (step 0.05, default 2.0) |
| `input_threshold` | Мертвая зона на сыром выходе MediaPipe (ниже = ноль, выше = линейное переотображение). По умолчанию: 0.02. | FLOAT | Нет | от 0.0 до 0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | Окно Гаусса на покадровом сигнале MediaPipe перед сопоставлением MHR. Сырой выход MediaPipe колеблется на 30-70% от кадра к кадру на статичных лицах. 1 = отключено. Используйте нечетные значения. По умолчанию: 7. | INT | Нет | от 1 до 31 (step 2, default 7) |

Примечание: вычитание базового уровня для всего клипа применяется только в том случае, если в клипе содержится не менее 30 кадров с обнаруженными людьми. Пробелы обнаружения до 12 кадров на человека заполняются интерполяцией.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mhr_pose_data` | Обновленные данные позы. Параметры выражения каждого отслеживаемого человека заменяются сопоставленным выражением лица, а вершины и ключевые точки меша регенерируются для соответствия. | MHR_POSE_DATA |
