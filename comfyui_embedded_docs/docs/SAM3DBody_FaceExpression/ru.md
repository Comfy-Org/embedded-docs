# Выражение лица для тела SAM3D

Этот узел добавляет мимические выражения к телу SAM3D, обнаруживая лица на изображении с помощью MediaPipe Face Landmarker, сопоставляя каждое обнаруженное лицо с отслеживаемым человеком и отображая 52 блендшейпа ARKit на 72-осевые параметры выражения лица MHR. Затем он повторно запускает модель тела, чтобы вершины выходной сетки и ключевые точки отражали новое выражение лица.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | Модель тела SAM3D, содержащая детектор лицевых ориентиров, используемый для обнаружения лиц и повторной генерации сетки тела. | SAM3D_BODY_MODEL | Да | - |
| `mhr_pose_data` | Данные позы, содержащие отслеживаемых людей для каждого кадра с ограничивающими рамками, ключевыми точками и параметрами выражения лица. Узел сопоставляет каждое обнаруженное лицо с человеком и записывает обновлённые параметры выражения лица в эти данные. | MHR_POSE_DATA | Да | - |
| `изображение` | Кадры изображения, используемые для обнаружения лиц. Если в пакете изображений меньше кадров, чем в данных позы, последний кадр повторно используется для оставшихся кадров. | IMAGE | Да | - |
| `сила` | Глобальный множитель для всех блендшейпов. Значения >1 усиливают эффект. По умолчанию: 1.0. | FLOAT | Нет | 0.0–4.0 (шаг 0.05, по умолчанию 1.0) |
| `mouth_strength` | Множитель для форм рта/челюсти. jawOpen в MediaPipe насыщается вблизи 1.0. По умолчанию: 1.0. | FLOAT | Нет | 0.0–4.0 (шаг 0.05, по умолчанию 1.0) |
| `eye_strength` | Множитель для форм глаз. MediaPipe редко превышает 0.5; часто требуется увеличение в 2–3 раза. По умолчанию: 2.0. | FLOAT | Нет | 0.0–4.0 (шаг 0.05, по умолчанию 2.0) |
| `brow_strength` | Множитель для форм бровей/щек/усмешки. MediaPipe выдаёт ~0.1–0.3; в 2–3 раза. По умолчанию: 2.0. | FLOAT | Нет | 0.0–4.0 (шаг 0.05, по умолчанию 2.0) |
| `input_threshold` | Мёртвая зона для необработанного вывода MediaPipe (ниже = ноль, выше = линейное переназначение). По умолчанию: 0.02. | FLOAT | Нет | 0.0–0.5 (шаг 0.01, по умолчанию 0.02) |
| `blendshape_smooth_window` | Гауссово окно для покадрового сигнала MediaPipe перед сопоставлением с MHR. Необработанный вывод MediaPipe колеблется на 30–70% от кадра к кадру на статичных лицах. 1 = отключено. Используйте нечётные значения. По умолчанию: 7. | INT | Нет | 1–31 (шаг 2, по умолчанию 7) |

Примечание: Вычитание базовой линии для каждого клипа применяется только тогда, когда как минимум 30 кадров в клипе содержат обнаруженных людей. Пропуски обнаружения длительностью до 12 кадров на человека заполняются интерполяцией.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mhr_pose_data` | Обновлённые данные позы. Параметры выражения лица каждого отслеживаемого человека заменяются сопоставленным выражением лица, а вершины сетки и ключевые точки перегенерируются для соответствия. | MHR_POSE_DATA |
