# تبدیل حالت چهره به بدن SAM3D

این گره با تشخیص چهره‌ها در یک تصویر با استفاده از MediaPipe Face Landmarker، مطابقت دادن هر چهرهٔ تشخیص‌داده‌شده با یک شخص ردیابی‌شده، و نگاشت ۵۲ بلندشیپ ARKit بر روی پارامترهای بیان ۷۲ محوری MHR، حالات چهره را به بدنهٔ SAM3D اضافه می‌کند. سپس مدل بدنه را دوباره اجرا می‌کند تا رئوس مش و نقاط کلیدی خروجی با حالت جدید مطابقت داشته باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | مدل بدنهٔ SAM3D حاوی تشخیص‌دهندهٔ نقاط چهره که برای تشخیص چهره‌ها و بازتولید مش بدنه استفاده می‌شود. | SAM3D_BODY_MODEL | بله | - |
| `mhr_pose_data` | داده‌های وضعیت شامل افراد ردیابی‌شده در هر فریم با کادرهای محدودکننده، نقاط کلیدی و پارامترهای بیان. این گره هر چهرهٔ تشخیص‌داده‌شده را با یک شخص مطابقت می‌دهد و پارامترهای بیان به‌روزشده را در این داده‌ها می‌نویسد. | MHR_POSE_DATA | بله | - |
| `image` | فریم‌های تصویر مورد استفاده برای تشخیص چهره. اگر تعداد فریم‌های دسته تصویر کمتر از داده‌های وضعیت باشد، آخرین فریم برای فریم‌های باقی‌مانده مجدداً استفاده می‌شود. | IMAGE | بله | - |
| `strength` | ضریب سراسری روی همهٔ بلندشیپ‌ها. مقادیر بزرگ‌تر از ۱ باعث اغراق می‌شود. پیش‌فرض: ۱.۰. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 1.0) |
| `mouth_strength` | ضریب روی شکل‌های دهان/فک. مقدار jawOpen در MediaPipe نزدیک ۱.۰ اشباع می‌شود. پیش‌فرض: ۱.۰. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 1.0) |
| `eye_strength` | ضریب روی شکل‌های چشم. MediaPipe به‌ندرت از ۰.۵ فراتر می‌رود؛ معمولاً ۲ تا ۳ برابر نیاز است. پیش‌فرض: ۲.۰. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 2.0) |
| `brow_strength` | ضریب روی شکل‌های ابرو/گونه/پوزخند. خروجی MediaPipe حدود ۰.۱ تا ۰.۳ است؛ ۲ تا ۳ برابر. پیش‌فرض: ۲.۰. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 2.0) |
| `input_threshold` | ناحیهٔ مرده روی خروجی خام MediaPipe (مقادیر پایین‌تر صفر، بالاتر بازنگاشت خطی). پیش‌فرض: ۰.۰۲. | FLOAT | خیر | 0.0 تا 0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | پنجرهٔ گاوسی روی سیگنال هر فریم MediaPipe قبل از نگاشت MHR. خروجی خام MediaPipe در چهره‌های ثابت بین ۳۰ تا ۷۰٪ در فریم‌های متوالی نوسان می‌کند. ۱ = غیرفعال. از مقادیر فرد استفاده کنید. پیش‌فرض: ۷. | INT | خیر | 1 تا 31 (step 2, default 7) |

توجه: تفریق خط پایه به‌ازای هر کلیپ فقط زمانی اعمال می‌شود که حداقل ۳۰ فریم از کلیپ شامل افراد تشخیص‌داده‌شده باشد. شکاف‌های تشخیص تا ۱۲ فریم برای هر شخص با درون‌یابی پر می‌شوند.

## خروجی‌ها
