# تبدیل حالت چهره به بدن SAM3D

این گره با تشخیص چهره‌ها در یک تصویر به‌کمک MediaPipe Face Landmarker، تطبیق هر چهره تشخیص‌داده‌شده با یک فرد ردیابی‌شده، و نگاشت ۵۲ blendshape مربوط به ARKit روی پارامترهای حالت چهره ۷۲ محوره MHR، حالت‌های چهره را به یک بدنه SAM3D اضافه می‌کند. سپس مدل بدنه را دوباره اجرا می‌کند تا رئوس مش و نقاط کلیدی خروجی بازتاب‌دهنده حالت چهره جدید باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | مدل بدنه SAM3D شامل تشخیص‌دهنده نقاط شاخص چهره که برای تشخیص چهره‌ها و بازتولید مش بدنه استفاده می‌شود. | SAM3D_BODY_MODEL | بله | - |
| `mhr_pose_data` | داده وضعیت شامل افراد ردیابی‌شده در هر فریم به‌همراه کادرهای محدودکننده، نقاط کلیدی و پارامترهای حالت چهره. این گره هر چهره تشخیص‌داده‌شده را به یک فرد تطبیق می‌دهد و پارامترهای حالت چهره به‌روزشده را در این داده می‌نویسد. | MHR_POSE_DATA | بله | - |
| `image` | فریم‌های تصویر برای تشخیص چهره. اگر دسته تصویر فریم‌های کمتری از داده وضعیت داشته باشد، آخرین فریم برای فریم‌های باقی‌مانده دوباره استفاده می‌شود. | IMAGE | بله | - |
| `strength` | ضریب ضرب سراسری روی همه blendshapeها. بزرگ‌تر از ۱ اغراق‌آمیز می‌کند. پیش‌فرض: 1.0. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 1.0) |
| `mouth_strength` | ضریب ضرب روی شکل‌های دهان/فک. jawOpen در MediaPipe نزدیک ۱.۰ اشباع می‌شود. پیش‌فرض: 1.0. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 1.0) |
| `eye_strength` | ضریب ضرب روی شکل‌های چشم. MediaPipe به‌ندرت از ۰.۵ فراتر می‌رود؛ اغلب ۲ تا ۳ برابر لازم است. پیش‌فرض: 2.0. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 2.0) |
| `brow_strength` | ضریب ضرب روی شکل‌های ابرو/گونه/پوزخند. خروجی MediaPipe حدود ۰.۱ تا ۰.۳ است؛ ۲ تا ۳ برابر. پیش‌فرض: 2.0. | FLOAT | خیر | 0.0 تا 4.0 (step 0.05, default 2.0) |
| `input_threshold` | ناحیه مرده روی خروجی خام MediaPipe (زیر = صفر، بالای = نگاشت خطی مجدد). پیش‌فرض: 0.02. | FLOAT | خیر | 0.0 تا 0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | پنجره گاوسی روی سیگنال هر فریم MediaPipe پیش از نگاشت MHR. خروجی خام MediaPipe روی چهره‌های ساکن بین فریم‌ها ۳۰ تا ۷۰ درصد نوسان دارد. ۱ = غیرفعال. از مقادیر فرد استفاده کنید. پیش‌فرض: 7. | INT | خیر | 1 تا 31 (step 2, default 7) |

توجه: تفریق خط پایه به‌ازای هر کلیپ فقط زمانی اعمال می‌شود که حداقل ۳۰ فریم در کلیپ شامل افراد تشخیص‌داده‌شده باشد. شکاف‌های تشخیص تا حداکثر ۱۲ فریم برای هر فرد با درون‌یابی پر می‌شوند.

## خروجی‌ها
