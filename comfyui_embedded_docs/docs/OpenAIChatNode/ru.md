# OpenAI ChatGPT

Этот узел генерирует текстовые ответы с помощью модели OpenAI. Он отправляет ваш текстовый запрос и, при необходимости, изображения или файлы в модель OpenAI и возвращает сгенерированный текстовый ответ.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовые входы для модели, используемые для генерации ответа (по умолчанию: пусто) | STRING | Да | - |
| `сохранять_контекст` | Этот параметр устарел и не оказывает никакого эффекта (по умолчанию: False) | BOOLEAN | Да | - |
| `модель` | Модель, используемая для генерации ответа (по умолчанию: `gpt-5`) | COMBO | Да | `gpt-5.6-sol`<br>`gpt-5.6-terra`<br>`gpt-5.6-luna`<br>`gpt-5.5-pro`<br>`gpt-5.5`<br>`gpt-5`<br>`gpt-5-mini`<br>`gpt-5-nano`<br>`gpt-4.1`<br>`gpt-4.1-mini`<br>`gpt-4.1-nano`<br>`o4-mini`<br>`o3`<br>`o1-pro`<br>`o1` |
| `изображения` | Необязательное изображение (или изображения) для использования в качестве контекста для модели. Чтобы включить несколько изображений, можно использовать узел Batch Images | IMAGE | Нет | - |
| `файлы` | Необязательный файл (или файлы) для использования в качестве контекста для модели. Принимает входы от узла OpenAI Chat Input Files | OPENAI_INPUT_FILES | Нет | - |
| `расширенные_настройки` | Необязательная конфигурация для модели. Принимает входы от узла OpenAI Chat Advanced Options | OPENAI_CHAT_CONFIG | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output_text` | Текстовый ответ, сгенерированный моделью OpenAI | STRING |
