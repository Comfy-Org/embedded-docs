# OpenAI ChatGPT

این گره پاسخ‌های متنی را از یک مدل OpenAI تولید می‌کند. پرامپت متنی شما و در صورت نیاز تصاویر یا فایل‌ها را به یک مدل OpenAI ارسال می‌کند و پاسخ متنی تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ورودی‌های متنی به مدل که برای تولید پاسخ استفاده می‌شوند (پیش‌فرض: خالی) | STRING | بله | - |
| `persist_context` | این پارامتر منسوخ شده و تأثیری ندارد (پیش‌فرض: False) | BOOLEAN | بله | - |
| `model` | مدلی که برای تولید پاسخ استفاده می‌شود (پیش‌فرض: `gpt-5`) | COMBO | بله | `gpt-5.6-sol`<br>`gpt-5.6-terra`<br>`gpt-5.6-luna`<br>`gpt-5.5-pro`<br>`gpt-5.5`<br>`gpt-5`<br>`gpt-5-mini`<br>`gpt-5-nano`<br>`gpt-4.1`<br>`gpt-4.1-mini`<br>`gpt-4.1-nano`<br>`o4-mini`<br>`o3`<br>`o1-pro`<br>`o1` |
| `images` | تصویر(های) اختیاری برای استفاده به عنوان زمینه مدل. برای گنجاندن چند تصویر، می‌توانید از گره Batch Images استفاده کنید | IMAGE | خیر | - |
| `files` | فایل(های) اختیاری برای استفاده به عنوان زمینه مدل. ورودی‌ها را از گره OpenAI Chat Input Files می‌پذیرد | OPENAI_INPUT_FILES | خیر | - |
| `advanced_options` | پیکربندی اختیاری برای مدل. ورودی‌ها را از گره OpenAI Chat Advanced Options می‌پذیرد | OPENAI_CHAT_CONFIG | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output_text` | پاسخ متنی تولیدشده توسط مدل OpenAI | STRING |
