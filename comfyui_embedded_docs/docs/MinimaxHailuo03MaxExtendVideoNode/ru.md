# MiniMax H3 Max Extend Video

Этот узел продолжает видео новым видеоматериалом, используя промпт и необязательные эталонные аудио. Исходное видео загружается, продолжение генерируется, а результат возвращается либо как всё видео целиком, повторно отрендеренное, либо только как новый фрагмент. Доступны две модели: "MiniMax H3 Max" и "MiniMax H3 Max Turbo", которая дешевле в расчёте на единицу.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, используемая для продолжения видео. Обе модели предоставляют одинаковые входы, перечисленные ниже. | DYNAMIC_COMBO | Да | "MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |

### Входы модели

Эти входы применяются к обеим моделям.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Видео для продолжения длительностью от 1.625 до 60 секунд, размером до 50 МБ. Соотношение сторон должно быть от 0.4 до 2.5. | VIDEO | Да | 1.625–60 секунд |
| `prompt` | Что происходит далее. Опишите продолжение, а не исходное видео. Ссылайтесь на эталонные аудио как `@Audio1`..`@Audio3`, например: "@Audio1 для голоса". | STRING | Да | 1–50000 символов |
| `reference_audios` | Расширяемый слот: подключите до 3 аудиоклипов (`audio_1`...`audio_3`) для нового фрагмента видео; каждый — не менее 2 секунд, общая длительность — не более 14.5 секунд. | AUDIO | Нет | 0–3 клипа |
| `duration` | Количество секунд нового видеоматериала для добавления (по умолчанию: 5). | INT | Да | 1–15 |
| `resolution` | Разрешение выходного видео (по умолчанию: "768P"). | COMBO | Да | "480P"<br>"768P"<br>"1080P"<br>"2K" |
| `aspect_ratio` | Соотношение сторон выходного видео. "auto" соответствует исходному видео; остальные значения обрезают видео до выбранного соотношения (по умолчанию: "auto"). | COMBO | Да | "auto"<br>"21:9"<br>"16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16" |
| `output` | "extended" возвращает всё видео, повторно отрендеренное в выбранном разрешении, вместе с новым фрагментом. "continuation" возвращает только новый фрагмент, начиная с 1.6-секундного повтора окончания исходного видео (по умолчанию: "extended"). | COMBO | Да | "extended"<br>"continuation" |
| `prompt_expansion` | Переписывать промпт с использованием исходного видео, чтобы продолжение было согласованным. Отключите, чтобы получать воспроизводимые результаты для одного и того же `seed` (по умолчанию: true). | BOOLEAN | Нет | true<br>false |
| `seed` | Случайное зерно. Один и тот же запрос с одним и тем же `seed` даёт похожие, но не гарантированно идентичные результаты (по умолчанию: 42). | INT | Да | 0–4294967295 |

### Ограничения параметров

- При разрешении 2K выходной результат "extended" ограничен 45 секундами в сумме — исходное видео плюс новый фрагмент. Для более длинных клипов используйте "continuation" или меньшее разрешение.
- Каждый эталонный аудиоклип должен длиться не менее 2 секунд, а все вместе — не более 14.5 секунд.
