# MiniMax H3 Context Windows

Разделяет сэмплирование на перекрывающиеся контекстные окна, чтобы видео MiniMax H3 могло быть длиннее, чем окно однопроходной генерации модели. Окна размещаются на 17-кадровых чанках модели, что сохраняет согласованность сгенерированных видео и аудио на границах окон. Подключите возвращённую модель к сэмплеру вместо исходной модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой во время сэмплирования применяются контекстные окна. | MODEL | Да | - |
| `context_length` | Длина контекстного окна в реальных кадрах. Должна быть равна 17*n + 5 (по умолчанию: 124). | INT | Да | от 22 до 16384 (MAX_RESOLUTION), шаг 17 |
| `context_overlap` | Перекрытие контекстного окна в реальных кадрах. Должно быть равно 17*n + 5 (по умолчанию: 39). | INT | Да | 5 или выше, шаг 17 |
| `fuse_method` | Метод, используемый для объединения контекстных окон (по умолчанию: `"pyramid"`). | COMBO | Да | `"pyramid"`<br>`"relative"`<br>`"flat"`<br>`"overlap-linear"` |
| `freenoise` | Применять ли перемешивание шума FreeNoise, которое улучшает смешивание окон (по умолчанию: True, расширенный параметр). | BOOLEAN | Да | true<br>false |
| `split_conds_to_windows` | Разделять ли несколько кондиционирований (созданных ConditionCombine) по каждому окну на основе индекса региона (по умолчанию: False, расширенный параметр). | BOOLEAN | Да | true<br>false |

Обе длины задаются в реальных кадрах и перед сэмплированием преобразуются в латенты: `context_length` становится равным 2 латентам при 5 кадрах или меньше, иначе `((frames - 5) / 17) * 5 + 2`. `context_overlap` преобразуется таким же образом, а затем ограничивается значением `context_length` минус 5, поэтому перекрытие всегда оставляет полный чанк для продвижения. Узел всегда использует статическое расписание с шагом 1, применяет окна по временному измерению латентов и не добавляет кадр причинной фиксации, поскольку каждое окно начинается на границе чанка. `split_conds_to_windows` ожидает несколько кондиционирований, созданных узлом ConditionCombine.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с применённой конфигурацией контекстных окон. | MODEL |
