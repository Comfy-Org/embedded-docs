# Tripo: Импорт модели

Этот узел импортирует внешнюю 3D-модель в Tripo, чтобы другие узлы постобработки Tripo, такие как Texture, Rig и Convert, могли использовать её. Узел загружает модель и возвращает идентификатор задачи, определяющий импортированную модель. Рекомендуется GLB, поскольку текстуры сохраняются только при встраивании в файл, а наложение текстур на импортированную модель требует текстурного запроса.

## Входные данные

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-модель для импорта (GLB / FBX / OBJ / STL, до 150 МБ). Файлы OBJ и STL не содержат встроенных текстур. | FILE3D | Да | GLB<br>FBX<br>OBJ<br>STL<br>Любой 3D-формат |

**Примечание:** Поддерживаются только форматы GLB, FBX, OBJ и STL. GLTF (.gltf) не может быть импортирован, поскольку он ссылается на внешние файлы; используйте вместо этого однофайловый GLB. Файл модели должен быть не больше 150 МБ. Рекомендуется GLB, поскольку текстуры сохраняются после импорта только при встраивании в файл. Файлы OBJ и STL не содержат встроенных текстур. Наложение текстур на импортированную модель требует текстурного запроса.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | Идентификатор задачи, который идентифицирует импортированную модель для использования с узлами постобработки Tripo | MODEL_TASK_ID |
