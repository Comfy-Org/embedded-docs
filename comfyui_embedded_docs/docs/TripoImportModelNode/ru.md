# Tripo: Импорт модели

Этот узел импортирует внешнюю 3D-модель в Tripo, чтобы узлы постобработки Tripo, такие как Texture, Rig и Convert, могли её использовать. Узел загружает файл в Tripo и возвращает ID задачи, который идентифицирует импортированную модель для использования этими узлами. Рекомендуется GLB, поскольку текстуры сохраняются только при встраивании в файл, а для текстурирования импортированной модели требуется промпт текстуры. Этот узел бесплатен для использования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-модель для импорта (GLB / FBX / OBJ / STL, до 150 МБ). Файлы OBJ и STL не содержат встроенных текстур. | FILE3D | Да | GLB<br>FBX<br>OBJ<br>STL<br>Любой 3D-формат |

**Примечание:** Поддерживаются только форматы GLB, FBX, OBJ и STL. GLTF (.gltf) нельзя импортировать, поскольку он ссылается на внешние файлы; вместо этого экспортируйте единый файл GLB. Размер файла модели должен быть не более 150 МБ. Рекомендуется GLB, поскольку текстуры сохраняются при импорте только если они встроены в файл. Файлы OBJ и STL не содержат встроенных текстур. Для текстурирования импортированной модели требуется промпт текстуры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи, идентифицирующий импортированную модель, для использования с узлами постобработки Tripo | MODEL_TASK_ID |
