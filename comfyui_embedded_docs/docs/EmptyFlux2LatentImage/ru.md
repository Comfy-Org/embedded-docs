# Пустой Flux 2 latent

Узел Empty Flux 2 Latent создаёт пустое латентное представление, заполненное нулями. Оно используется как начальная точка для процесса удаления шума моделью Flux. Размеры латентного представления берутся из входных значений ширины и высоты, каждое из которых делится на 16.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина итогового изображения для генерации. Ширина латентного представления будет равна этому значению, разделённому на 16. Значение по умолчанию — 1024. | INT | Да | 16–16384 |
| `высота` | Высота итогового изображения для генерации. Высота латентного представления будет равна этому значению, разделённому на 16. Значение по умолчанию — 1024. | INT | Да | 16–16384 |
| `размер_пакета` | Количество латентных образцов для генерации в одном пакете. Значение по умолчанию — 1. | INT | Нет | 1–4096 |

**Примечание:** Входы `width` и `height` используют шаг 16, поэтому они должны быть кратны 16. Это связано с тем, что узел делит их на этот коэффициент для создания размеров латентного представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Форма — `[batch_size, 128, height // 16, width // 16]`. | LATENT |
