# Пустой Flux 2 latent

Узел **Empty Flux 2 Latent** создаёт пустое латентное представление. Он генерирует тензор, заполненный нулями, который служит отправной точкой для процесса денойзинга модели Flux. Размеры латентного представления определяются входными значениями ширины и высоты, уменьшенными в 16 раз.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина конечного изображения для генерации. Ширина латентного представления будет равна этому значению, делённому на 16. Значение по умолчанию: 1024. | INT | Да | 16–8192 |
| `высота` | Высота конечного изображения для генерации. Высота латентного представления будет равна этому значению, делённому на 16. Значение по умолчанию: 1024. | INT | Да | 16–8192 |
| `размер_пакета` | Количество латентных образцов для генерации в одном пакете. Значение по умолчанию: 1. | INT | Нет | 1–4096 |

**Примечание:** Входные значения `width` и `height` должны быть кратны 16, поскольку узел внутренне делит их на этот коэффициент для создания размеров латентного представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Форма: `[batch_size, 128, height // 16, width // 16]`. | LATENT |
