# Пустой Flux 2 latent

Узел EmptyFlux2LatentImage создает пустое латентное представление. Он генерирует тензор, заполненный нулями, который служит отправной точкой для процесса удаления шума модели Flux. Размеры латентного представления определяются входными значениями ширины и высоты, уменьшенными в 16 раз.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина конечного изображения для генерации. Ширина латентного представления будет равна этому значению, деленному на 16. Значение по умолчанию — 1024. | INT | Да | 16 to 16384 |
| `height` | Высота конечного изображения для генерации. Высота латентного представления будет равна этому значению, деленному на 16. Значение по умолчанию — 1024. | INT | Да | 16 to 16384 |
| `batch_size` | Количество латентных образцов для генерации в одном пакете. Значение по умолчанию — 1. | INT | Нет | 1 to 4096 |

**Примечание:** Входные значения `width` и `height` должны делиться на 16, так как узел внутренне делит их на этот коэффициент для создания размеров латентного представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Латентный тензор, заполненный нулями. Форма: `[batch_size, 128, height // 16, width // 16]`. | LATENT |
