# تصویر نهفته Flux 2 خالی

گره EmptyFlux2LatentImage یک نمایش نهفتهٔ خالی و تهی ایجاد می‌کند. این گره یک تنسور پر از صفر تولید می‌کند که به عنوان نقطهٔ شروع برای فرایند نویززدایی مدل Flux عمل می‌کند. ابعاد نهفته توسط عرض و ارتفاع ورودی تعیین می‌شود و با ضریب ۱۶ کوچک‌سازی می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `width` | عرض تصویر نهایی که باید تولید شود. عرض نهفته برابر با این مقدار تقسیم بر ۱۶ خواهد بود. مقدار پیش‌فرض ۱۰۲۴ است. | INT | بله | 16 تا 16384 |
| `height` | ارتفاع تصویر نهایی که باید تولید شود. ارتفاع نهفته برابر با این مقدار تقسیم بر ۱۶ خواهد بود. مقدار پیش‌فرض ۱۰۲۴ است. | INT | بله | 16 تا 16384 |
| `batch_size` | تعداد نمونه‌های نهفته‌ای که در یک دسته تولید می‌شوند. مقدار پیش‌فرض ۱ است. | INT | خیر | 1 تا 4096 |

**توجه:** ورودی‌های `width` و `height` باید بر ۱۶ بخش‌پذیر باشند، زیرا گره به‌صورت داخلی آن‌ها را بر این ضریب تقسیم می‌کند تا ابعاد نهفته را ایجاد کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | یک تنسور نهفته پر از صفر. شکل آن `[batch_size, 128, height // 16, width // 16]` است. | LATENT |
