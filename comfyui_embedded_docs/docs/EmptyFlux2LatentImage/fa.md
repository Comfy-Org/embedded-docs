# تصویر نهفته Flux 2 خالی

گره Empty Flux 2 Latent یک نمایش latent خالی پر از صفر ایجاد می‌کند. از آن به‌عنوان نقطه شروع برای فرایند نویززدایی مدل Flux استفاده می‌شود. ابعاد latent از عرض و ارتفاع ورودی گرفته می‌شوند و هر یک بر 16 تقسیم می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `عرض` | عرض تصویر نهایی برای تولید. عرض latent برابر این مقدار تقسیم بر 16 خواهد بود. مقدار پیش‌فرض 1024 است. | INT | بله | 16 تا 16384 |
| `ارتفاع` | ارتفاع تصویر نهایی برای تولید. ارتفاع latent برابر این مقدار تقسیم بر 16 خواهد بود. مقدار پیش‌فرض 1024 است. | INT | بله | 16 تا 16384 |
| `اندازه دسته` | تعداد نمونه‌های latent برای تولید در یک batch. مقدار پیش‌فرض 1 است. | INT | خیر | 1 تا 4096 |

**توجه:** ورودی‌های `width` و `height` از گام 16 استفاده می‌کنند، بنابراین باید بر 16 بخش‌پذیر باشند. دلیل این امر آن است که گره آن‌ها را بر این ضریب تقسیم می‌کند تا ابعاد latent را ایجاد کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | یک تنسور latent پر از صفر. شکل آن `[batch_size, 128, height // 16, width // 16]` است. | LATENT |
