# Tripo P1: تبدیل متن به مدل

Tripo P1 تبدیل متن به سه‌بعدی. این گره با استفاده از API مربوط به Tripo P1 یک مدل سه‌بعدی از توضیح متنی تولید می‌کند. برای ساخت مش‌های کم‌پالیگان و آماده بازی با توپولوژی پایدار بهینه شده است و برای کاربردهای بلادرنگ مناسب است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | کنترل می‌کند که مدل تولیدشده فقط شامل هندسه باشد یا رنگ/بافت‌های PBR را نیز داشته باشد. حالت `"Geometry only"` یک مش بدون بافت برمی‌گرداند. حالت `"Textured"` نقشه‌های رنگ/PBR را اضافه می‌کند و گزینه‌های بافت زیر را نمایان می‌سازد. | DYNAMIC_COMBO | بله | `"Geometry only"`<br>`"Textured"` |
| `prompt` | توضیح متنی مدل سه‌بعدی که می‌خواهید تولید کنید. حداکثر 1024 نویسه. الزامی است و نمی‌تواند خالی باشد. | STRING | بله | حداکثر 1024 نویسه |
| `negative_prompt` | توضیح متنی آنچه نمی‌خواهید در مدل تولیدشده باشد. حداکثر 255 نویسه. پیش‌فرض: تنظیم‌نشده. | STRING | خیر | حداکثر 255 نویسه |
| `image_seed` | یک مقدار seed برای کنترل تصادفی بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `face_limit` | تعداد وجه هدف، 48-20000. مقدار -1 به Tripo اجازه می‌دهد به‌صورت تطبیقی انتخاب کند. پیش‌فرض: -1. | INT | خیر | -1 تا 20000 |
| `model_seed` | یک مقدار seed برای کنترل تصادفی بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `auto_size` | خروجی را برای تقریب مترهای دنیای واقعی مقیاس‌بندی می‌کند. پیش‌فرض: False. | BOOLEAN | خیر | True / False |
| `export_uv` | بازکردن UV در حین تولید. برای اجراهای سریع‌تر فقط هندسه، خاموش کنید. پیش‌فرض: True. | BOOLEAN | خیر | True / False |
| `compress_geometry` | فشرده‌سازی هندسه meshopt (EXT_meshopt_compression) را اعمال می‌کند. فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ پیش از ویرایش از حالت فشرده خارج کنید. پیش‌فرض: False. | BOOLEAN | خیر | True / False |

### ورودی‌های حالت فقط هندسه

هنگامی که `output_mode` روی `"Geometry only"` تنظیم شده باشد، ورودی اضافی دیگری در دسترس نیست. پارامترهای مرتبط با بافت در این حالت به Tripo ارسال نمی‌شوند.

### ورودی‌های حالت بافت‌دار

این ورودی‌ها فقط زمانی ظاهر می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `pbr` | نقشه‌های PBR را شامل می‌شود. وقتی روشن باشد، بافت پایه نیز به‌اجبار روشن می‌شود. پیش‌فرض: True. | BOOLEAN | بله | True / False |
| `texture_quality` | پیش‌تنظیم کیفیت بافت. detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra. پیش‌فرض: "standard". | COMBO | بله | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | یک مقدار seed برای تولید بافت که برای کنترل تصادفی بودن استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل تولیدشده، که فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `model task_id` | شناسه یکتای وظیفه برای درخواست تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
