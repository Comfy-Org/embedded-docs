# Tripo P1: تحويل النص إلى نموذج

Tripo P1 من النص إلى ثلاثي الأبعاد. تولّد هذه العقدة نموذجًا ثلاثي الأبعاد من وصف نصي باستخدام Tripo P1 API. وهي مُحسّنة لإنشاء شبكات منخفضة المضلعات وجاهزة للألعاب ذات طوبولوجيا مستقرة، ما يجعلها مناسبة للتطبيقات الزمن الحقيقي.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `وضع الإخراج` | يتحكم فيما إذا كان النموذج المولَّد يحتوي على الهندسة فقط أو أيضًا على ألوان/خرائط PBR. "Geometry only" يعيد شبكة دون خرائط نسيج. "Textured" يضيف خرائط ألوان/PBR ويكشف خيارات النسيج أدناه. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `النص` | الوصف النصي للنموذج ثلاثي الأبعاد الذي تريد إنشاءه. حتى 1024 حرفًا. مطلوب ولا يمكن تركه فارغًا. | STRING | نعم | حتى 1024 حرفًا |
| `النص السلبي` | وصف نصي لما لا تريده في النموذج المولَّد. حتى 255 حرفًا. الافتراضي: غير مضبوط. | STRING | لا | حتى 255 حرفًا |
| `بذرة الصورة` | قيمة بذرة تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | 0 إلى 2147483647 |
| `حد الأوجه` | عدد الأوجه المستهدف، 48-20000. القيمة -1 تدع Tripo تختار تكيفيًا. الافتراضي: -1. | INT | لا | من -1 إلى 20000 |
| `بذرة النموذج` | قيمة بذرة تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | 0 إلى 2147483647 |
| `تغيير الحجم تلقائيًا` | قياس المخرجات لتقريب الأمتار الواقعية. الافتراضي: False. | BOOLEAN | لا | True / False |
| `تصدير UV` | فك UV أثناء التوليد. أوقفه لتشغيلات أسرع للهندسة فقط. الافتراضي: True. | BOOLEAN | لا | True / False |
| `ضغط الهندسة` | تطبيق ضغط الهندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن معاينة ComfyUI ثلاثية الأبعاد لا يمكنها عرضها؛ قم بفك الضغط قبل التحرير. الافتراضي: False. | BOOLEAN | لا | True / False |

### مدخلات الوضع Geometry only

لا تتوفر مدخلات إضافية عندما تكون `output_mode` مضبوطة على `"Geometry only"`. لا تُرسل المعاملات المتعلقة بالنسيج إلى Tripo في هذا الوضع.

### مدخلات الوضع Textured

تظهر هذه المدخلات فقط عندما تكون `output_mode` مضبوطة على `"Textured"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند تشغيله، يُفعَّل النسيج الأساسي أيضًا إجباريًا. الافتراضي: True. | BOOLEAN | نعم | True / False |
| `texture_quality` | إعداد جودة النسيج مسبقًا. detailed = نُسخ نسيج HD، extreme = نُسخ 8K Ultra. الافتراضي: "standard". | COMBO | نعم | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | قيمة بذرة لتوليد النسيج، تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | نعم | 0 إلى 2147483647 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف النموذج المولَّد، محتفظ به للتوافق مع الإصدارات السابقة فقط. | STRING |
| `model task_id` | معرّف المهمة الفريد لطلب توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولَّد بصيغة GLB. | FILE3DGLB |
