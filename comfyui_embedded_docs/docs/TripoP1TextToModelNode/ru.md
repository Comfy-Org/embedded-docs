# Tripo P1: Текст в Модель

Tripo P1 text-to-3D. Этот узел генерирует 3D-модель по текстовому описанию с помощью API Tripo P1. Он оптимизирован для создания низкополигональных мешей, готовых для игр, со стабильной топологией, что делает его подходящим для приложений реального времени.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | Управляет тем, содержит ли сгенерированная модель только геометрию или также цвет/PBR-текстуры. "Geometry only" возвращает не текстурированный меш. "Textured" добавляет цветовые/PBR-карты и открывает параметры текстурирования ниже. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. До 1024 символов. Обязательный, не может быть пустым. | STRING | Да | До 1024 символов |
| `negative_prompt` | Текстовое описание того, что вы не хотите видеть в сгенерированной модели. До 255 символов. По умолчанию: не задано. | STRING | Нет | До 255 символов |
| `image_seed` | Значение seed, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |
| `face_limit` | Целевое количество граней, 48–20000. -1 позволяет Tripo выбрать адаптивно. По умолчанию: -1. | INT | Нет | от -1 до 20000 |
| `model_seed` | Значение seed, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |
| `auto_size` | Масштабировать результат до приблизительных реальных размеров в метрах. По умолчанию: False. | BOOLEAN | Нет | True / False |
| `export_uv` | Выполнять UV-развёртку во время генерации. Отключите для более быстрых запусков только с геометрией. По умолчанию: True. | BOOLEAN | Нет | True / False |
| `compress_geometry` | Применять сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-просмотр ComfyUI не может их отображать; распакуйте перед редактированием. По умолчанию: False. | BOOLEAN | Нет | True / False |

### Входы только геометрии

Когда `output_mode` установлен в `"Geometry only"`, дополнительные входы недоступны. Параметры, связанные с текстурами, в этом режиме в Tripo не отправляются.

### Текстурированные входы

Эти входы появляются только когда `output_mode` установлен в `"Textured"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включать PBR-карты. Если включено, базовая текстура также принудительно включается. По умолчанию: True. | BOOLEAN | Да | True / False |
| `texture_quality` | Предустановка качества текстуры. detailed = HD-текстуры, extreme = 8K Ultra текстуры. По умолчанию: "standard". | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | Значение seed для генерации текстуры, используемое для управления случайностью. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла сгенерированной модели, оставлено только для обратной совместимости. | STRING |
| `model task_id` | Уникальный ID задачи для запроса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
