# Tripo P1: טקסט למודל

Tripo P1 ליצירת 3D מטקסט. צומת זה יוצר מודל תלת-ממדי מתיאור טקסטואלי באמצעות API של Tripo P1. הוא מותאם ליצירת רשתות low-poly, מוכנות למשחקים עם טופולוגיה יציבה, מה שהופך אותו למתאים לאפליקציות בזמן אמת.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | שולט האם המודל הנוצר מכיל רק גאומטריה או גם צבע/טקסטורות PBR. "Geometry only" מחזיר רשת ללא טקסטורה. "Textured" מוסיף מפות צבע/PBR וחושף את אפשרויות הטקסטורה שלהלן. | DYNAMIC_COMBO | כן | `"Geometry only"`<br>`"Textured"` |
| `prompt` | תיאור הטקסטואלי של המודל התלת-ממדי שברצונך ליצור. עד 1024 תווים. חובה ולא יכול להיות ריק. | STRING | כן | עד 1024 תווים |
| `negative_prompt` | תיאור טקסטואלי של מה שאינך רוצה במודל הנוצר. עד 255 תווים. ברירת מחדל: לא מוגדר. | STRING | לא | עד 255 תווים |
| `image_seed` | ערך seed המשמש לשליטה באקראיות. ברירת מחדל: 42. | INT | לא | 0 עד 2147483647 |
| `face_limit` | יעד מספר הפאות, 48-20000. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי. ברירת מחדל: -1. | INT | לא | -1 עד 20000 |
| `model_seed` | ערך seed המשמש לשליטה באקראיות. ברירת מחדל: 42. | INT | לא | 0 עד 2147483647 |
| `auto_size` | קנה מידה של הפלט לקירוב למטרים בעולם האמיתי. ברירת מחדל: False. | BOOLEAN | לא | True / False |
| `export_uv` | פריסת UV במהלך היצירה. כבה זאת להרצות מהירות יותר של גאומטריה בלבד. ברירת מחדל: True. | BOOLEAN | לא | True / False |
| `compress_geometry` | החלת דחיסת גאומטריה meshopt (EXT_meshopt_compression). קבצים קטנים יותר, אך תצוגת ה-3D של ComfyUI לא יכולה להציג אותם; יש להסיר את הדחיסה לפני עריכה. ברירת מחדל: False. | BOOLEAN | לא | True / False |

### קלטים של Geometry only

אין קלטים נוספים זמינים כאשר `output_mode` מוגדר ל-`"Geometry only"`. פרמטרים הקשורים לטקסטורה אינם נשלחים ל-Tripo במצב זה.

### קלטים של Textured

קלטים אלה מופיעים רק כאשר `output_mode` מוגדר ל-`"Textured"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `pbr` | כלול מפות PBR. כאשר מופעל, טקסטורת בסיס נכפית גם כן. ברירת מחדל: True. | BOOLEAN | כן | True / False |
| `texture_quality` | פריסט איכות טקסטורה. detailed = טקסטורות HD, extreme = טקסטורות 8K Ultra. ברירת מחדל: "standard". | COMBO | כן | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | ערך seed ליצירת טקסטורה, המשמש לשליטה באקראיות. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |
