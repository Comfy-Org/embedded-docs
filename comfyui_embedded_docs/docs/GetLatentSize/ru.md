# Get Image/Video Latent Size

Читает латент изображения или видео и возвращает его ширину, высоту, количество кадров и размер пакета, чтобы геометрию можно было повторно использовать без декодирования латента. Используйте его для задания размера шумовых масок, выравнивания разрешений или расчёта перекрытий при тайлинге сэмплера. Измеренные значения также отображаются на самом узле.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Латент изображения или видео для анализа. Если латент содержит несколько потоков, измеряется первый. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `width` | Ширина латента, в латентных ячейках, а не в пикселях. | INT |
| `height` | Высота латента, в латентных ячейках, а не в пикселях. | INT |
| `frames` | Количество кадров в латенте. У латентов изображений один кадр. | INT |
| `batch_size` | Количество латентов в пакете. | INT |
