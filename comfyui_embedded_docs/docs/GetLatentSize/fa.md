# Get Image/Video Latent Size

یک latent تصویر یا ویدئو را می‌خواند و عرض، ارتفاع، تعداد فریم و اندازه دسته (batch size) آن را برمی‌گرداند، تا بتوان بدون رمزگشایی latent از هندسه آن دوباره استفاده کرد. از آن برای تعیین اندازه ماسک‌های نویز، هم‌ترازی رزولوشن‌ها، یا محاسبه هم‌پوشانی‌ها هنگام کاشی‌بندی (tiling) یک سمپلر استفاده کنید. مقادیر اندازه‌گیری‌شده همچنین روی خود گره چاپ می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `latent` | latent تصویر یا ویدئویی که باید بررسی شود. وقتی latent شامل چند جریان باشد، اولین جریان اندازه‌گیری می‌شود. | LATENT | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `width` | عرض latent، بر حسب سلول‌های latent نه پیکسل. | INT |
| `height` | ارتفاع latent، بر حسب سلول‌های latent نه پیکسل. | INT |
| `frames` | تعداد فریم‌های latent. latentهای تصویری یک فریم دارند. | INT |
| `batch_size` | تعداد latentها در دسته. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetLatentSize/fa.md)
