# Get Image/Video Latent Size

קורא לטנט של תמונה או וידאו ומחזיר את הרוחב, הגובה, מספר הפריימים וגודל האצווה שלו, כך שניתן לעשות שימוש חוזר בגאומטריה בלי לפענח את הלטנט. השתמשו בו כדי לקבוע את הגודל של מסכות רעש, ליישר רזולוציות, או לחשב חפיפות בעת עבודה עם סמפלר באריחים. הערכים הנמדדים מודפסים גם על הצומת עצמו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `latent` | הלטנט של התמונה או הווידאו לבדיקה. כאשר הלטנט מכיל מספר זרמים, הראשון נמדד. | LATENT | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `width` | הרוחב של הלטנט, בתאי לטנט ולא בפיקסלים. | INT |
| `height` | הגובה של הלטנט, בתאי לטנט ולא בפיקסלים. | INT |
| `frames` | מספר הפריימים בלטנט. ללטנטים של תמונה יש פריים יחיד. | INT |
| `batch_size` | מספר הלטנטים באצווה. | INT |
