# Get Image/Video Latent Size

يقرأ الكامن الخاص بصورة أو فيديو ويعيد عرضه وارتفاعه وعدد إطاراته وحجم الدفعة، بحيث يمكن إعادة استخدام الأبعاد الهندسية دون فك ترميز الكامن. استخدمه لضبط أحجام أقنعة الضوضاء، أو مواءمة الدقات، أو حساب التداخلات عند تجزئة أداة أخذ العينات إلى بلاطات. تظهر القيم المقاسة أيضًا مطبوعة على العقدة نفسها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `latent` | الكامن الخاص بصورة أو فيديو المراد فحصه. عندما يحتوي الكامن على عدة تدفقات، يتم قياس التدفق الأول. | LATENT | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `width` | عرض الكامن، بوحدات خلايا الكامن بدلاً من البكسلات. | INT |
| `height` | ارتفاع الكامن، بوحدات خلايا الكامن بدلاً من البكسلات. | INT |
| `frames` | عدد الإطارات في الكامن. الكوامن الخاصة بالصور تحتوي على إطار واحد. | INT |
| `batch_size` | عدد الكوامن في الدفعة. | INT |
