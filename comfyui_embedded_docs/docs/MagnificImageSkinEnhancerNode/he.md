# Magnific Image Skin Enhancer

הצומת Magnific Image Skin Enhancer מיישם עיבוד בינה מלאכותית ייעודי על תמונות פורטרט כדי לשפר את מראה העור. הוא מציע שלושה מצבים נפרדים למטרות שיפור שונות: creative לאפקטים אמנותיים, faithful לשימור המראה המקורי, ו-flexible לשיפורים ממוקדים כמו תאורה או ריאליזם. הצומת מעלה את התמונה ל-API חיצוני לעיבוד ומחזיר את התוצאה המשופרת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הפורטרט לשיפור. | IMAGE | כן | - |
| `sharpen` | רמת עוצמת חידוד (ברירת מחדל: 0). | INT | לא | 0 to 100 |
| `smart_grain` | רמת עוצמת גריין חכם (ברירת מחדל: 2). | INT | לא | 0 to 100 |
| `mode` | מצב העיבוד שבו יש להשתמש. `"creative"` מיועד לשיפור אמנותי, `"faithful"` לשימור המראה המקורי, ו-`"flexible"` לאופטימיזציה ממוקדת. | COMBO | כן | `"creative"`<br>`"faithful"`<br>`"flexible"` |
| `skin_detail` | רמת שיפור פירוט העור. קלט זה זמין רק כאשר `mode` מוגדר ל-`"faithful"` (ברירת מחדל: 80). | INT | לא | 0 to 100 |
| `optimized_for` | יעד אופטימיזציה של השיפור. קלט זה זמין רק כאשר `mode` מוגדר ל-`"flexible"`. | COMBO | לא | `"enhance_skin"`<br>`"improve_lighting"`<br>`"enhance_everything"`<br>`"transform_to_real"`<br>`"no_make_up"` |

**אילוצים:**

* הצומת מקבל תמונת קלט אחת בדיוק.
* לתמונת הקלט חייבים להיות גובה ורוחב מינימליים של 160 פיקסלים.
* יחס הרוחב-גובה של תמונת הקלט חייב להיות בין 1:3 ל-3:1 (אימות לא קפדני).
* הפרמטר `skin_detail` פעיל רק כאשר `mode` מוגדר ל-`"faithful"`.
* הפרמטר `optimized_for` פעיל רק כאשר `mode` מוגדר ל-`"flexible"`.
