# Слияние моделей SD3_2B

Узел ModelMergeSD3_2B позволяет объединять две модели Stable Diffusion 3 2B путём смешивания их компонентов с настраиваемыми весами. Он обеспечивает индивидуальное управление слоями эмбеддингов и блоками трансформера, что позволяет создавать точно настроенные комбинации моделей для специализированных задач генерации.
