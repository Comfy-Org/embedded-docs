# ModelMergeSD3_2B

הצומת ModelMergeSD3_2B מאפשר למזג שני מודלים של Stable Diffusion 3 2B על ידי ערבוב הרכיבים שלהם עם משקלים הניתנים להתאמה. הוא מספק שליטה פרטנית על שכבות הטמעה, בלוקי Transformer והשכבה הסופית, ומאפשר שילובים מכווננים היטב של שני המודלים.
