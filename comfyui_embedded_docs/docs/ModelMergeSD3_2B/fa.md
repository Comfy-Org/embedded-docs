# ModelMergeSD3_2B

گره ModelMergeSD3_2B به شما امکان می‌دهد دو مدل Stable Diffusion 3 2B را با ترکیب اجزای آن‌ها با وزن‌های قابل تنظیم ادغام کنید. این گره کنترل جداگانه‌ای بر لایه‌های تعبیه و بلوک‌های ترنسفورمر فراهم می‌کند و ترکیب‌های ریزتنظیم‌شده‌ای از مدل را برای وظایف تولید تخصصی ممکن می‌سازد.
