# معاينة سحابة النقاط

```markdown
تتيح عقدة «Preview Point Cloud» عرض ملف سحابة نقاط ثلاثي الأبعاد (مثل ملف .ply) مباشرةً في واجهة ComfyUI دون حفظه في مجلد المخرجات. تكتب العقدة سحابة النقاط إلى ملف مؤقت، وتعرضها في نافذة معاينة ثلاثية الأبعاد، وتمرّر بيانات النموذج ومعلومات النموذج ومعلومات الكاميرا والعرض والارتفاع لمزيد من المعالجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ملف سحابة النقاط (.ply) | FILE3D | نعم | - |
| `model_3d_info` | معلومات حول النموذج ثلاثي الأبعاد. إدخال متقدم. عند عدم توصيله، يتم استخدام القيمة المخزنة في `viewport_state`. | LOAD3DMODELINFO | لا | - |
| `viewport_state` | حالة منفذ العرض الحالية، والتي يمكن أن تحتوي على معلومات الكاميرا ومعلومات النموذج المستخدمة للمعاينة. | LOAD3D | نعم | - |
| `camera_info` | معلومات الكاميرا للعرض ثلاثي الأبعاد. إدخال متقدم. عند عدم توصيله، يتم استخدام القيمة المخزنة في `viewport_state`. | LOAD3DCAMERA | لا | - |
| `width` | عرض نافذة المعاينة بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |
| `height` | ارتفاع نافذة المعاينة بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |

ملاحظة: عند عدم توصيل `camera_info` أو `model_3d_info`، تستخدم العقدة القيم المخزنة في `viewport_state`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_3d` | بيانات نموذج سحابة النقاط، تم تمريرها كما هي دون تغيير. | FILE3D |
| `model_3d_info` | معلومات حول النموذج ثلاثي الأبعاد المستخدم للمعاينة. | LOAD3DMODELINFO |
| `camera_info` | معلومات الكاميرا المستخدمة للعرض ثلاثي الأبعاد. | LOAD3DCAMERA |
| `width` | عرض نافذة المعاينة. | INT |
| `height` | ارتفاع نافذة المعاينة. | INT |
```
