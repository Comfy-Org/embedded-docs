# معاينة سحابة النقاط

عقدة معاينة سحابة النقاط تتيح لك عرض ملف سحابة نقاط ثلاثي الأبعاد مباشرةً في واجهة ComfyUI دون حفظه في دليل مخرجات ComfyUI. تقوم بحفظ سحابة النقاط في موقع مؤقت وعرضها في نافذة معاينة ثلاثية الأبعاد، مع تمرير بيانات النموذج ومعلومات الكاميرا وحالة منفذ العرض لمزيد من المعالجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `نموذج_ثلاثي_الأبعاد` | ملف سحابة النقاط (.ply) | FILE3D | نعم | - |
| `معلومات_النموذج_ثلاثي_الأبعاد` | معلومات حول النموذج ثلاثي الأبعاد | LOAD3DMODELINFO | لا | - |
| `حالة_منفذ_العرض` | حالة منفذ العرض الحالية | LOAD3D | نعم | - |
| `معلومات_الكاميرا` | معلومات الكاميرا للعرض ثلاثي الأبعاد | LOAD3DCAMERA | لا | - |
| `العرض` | عرض نافذة المعاينة (الافتراضي: 1024) | INT | نعم | من 1 إلى 4096 |
| `الارتفاع` | ارتفاع نافذة المعاينة (الافتراضي: 1024) | INT | نعم | من 1 إلى 4096 |

ملاحظة: عندما لا تكون `camera_info` أو `model_3d_info` متصلة، تعود العقدة إلى القيم المقابلة المخزنة في `viewport_state`. يُحفظ ملف سحابة النقاط في الدليل المؤقت لـ ComfyUI ولا يُكتب في دليل المخرجات. هذه عقدة إخراج، لذا تُستخدم أساسًا لعرض نتيجة المعاينة في الواجهة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `نموذج_ثلاثي_الأبعاد` | بيانات نموذج سحابة النقاط | FILE3D |
| `معلومات_النموذج_ثلاثي_الأبعاد` | معلومات حول النموذج ثلاثي الأبعاد | LOAD3DMODELINFO |
| `معلومات_الكاميرا` | معلومات الكاميرا للعرض ثلاثي الأبعاد | LOAD3DCAMERA |
| `العرض` | عرض نافذة المعاينة | INT |
| `الارتفاع` | ارتفاع نافذة المعاينة | INT |
