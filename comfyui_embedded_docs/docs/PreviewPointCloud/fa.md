# پیش‌نمایش Point Cloud

گره «پیش‌نمایش ابر نقاط» به شما امکان می‌دهد بدون ذخیره‌سازی در دایرکتوری خروجی، یک فایل ابر نقاط سه‌بعدی (مانند فایل `.ply`) را مستقیماً در رابط ComfyUI مشاهده کنید. این گره ابر نقاط را در یک فایل موقت می‌نویسد، آن را در پنجره پیش‌نمایش سه‌بعدی نمایش می‌دهد و داده‌های مدل، اطلاعات مدل، اطلاعات دوربین، عرض و ارتفاع را برای پردازش‌های بعدی عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | فایل ابر نقاط (.ply) | FILE3D | بله | - |
| `model_3d_info` | اطلاعات مربوط به مدل سه‌بعدی. ورودی پیشرفته. وقتی متصل نباشد، مقدار ذخیره‌شده در `viewport_state` استفاده می‌شود. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای دید، که می‌تواند شامل اطلاعات دوربین و اطلاعات مدل مورد استفاده برای پیش‌نمایش باشد. | LOAD3D | بله | - |
| `camera_info` | اطلاعات دوربین برای نمای سه‌بعدی. ورودی پیشرفته. وقتی متصل نباشد، مقدار ذخیره‌شده در `viewport_state` استفاده می‌شود. | LOAD3DCAMERA | خیر | - |
| `width` | عرض پنجره پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع پنجره پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

توجه: وقتی `camera_info` یا `model_3d_info` متصل نیستند، گره از مقادیر ذخیره‌شده در `viewport_state` استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | داده‌های مدل ابر نقاط، بدون تغییر عبور داده می‌شود. | FILE3D |
| `model_3d_info` | اطلاعات مدل سه‌بعدی مورد استفاده برای پیش‌نمایش. | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین مورد استفاده برای نمای سه‌بعدی. | LOAD3DCAMERA |
| `width` | عرض پنجره پیش‌نمایش. | INT |
| `height` | ارتفاع پنجره پیش‌نمایش. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/PreviewPointCloud/fa.md)
