# پیش‌نمایش Point Cloud

گره «پیش‌نمایش ابر نقاط» به شما امکان می‌دهد یک فایل ابر نقاط سه‌بعدی را مستقیماً در رابط ComfyUI مشاهده کنید، بدون اینکه آن را در پوشه خروجی ComfyUI ذخیره کنید. این گره ابر نقاط را در یک مکان موقت ذخیره کرده و آن را در یک پنجره پیش‌نمایش سه‌بعدی نمایش می‌دهد؛ همچنین داده‌های مدل، اطلاعات دوربین و وضعیت نمای دید را برای پردازش‌های بعدی عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | فایل ابر نقاط (.ply) | FILE3D | بله | - |
| `model_3d_info` | اطلاعات مربوط به مدل سه‌بعدی | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای دید | LOAD3D | بله | - |
| `camera_info` | اطلاعات دوربین برای نمای سه‌بعدی | LOAD3DCAMERA | خیر | - |
| `width` | عرض پنجره پیش‌نمایش (پیش‌فرض: 1024) | INT | بله | 1 تا 4096 |
| `height` | ارتفاع پنجره پیش‌نمایش (پیش‌فرض: 1024) | INT | بله | 1 تا 4096 |

نکته: وقتی `camera_info` یا `model_3d_info` متصل نباشند، گره به مقادیر متناظر ذخیره‌شده در `viewport_state` بازمی‌گردد. فایل ابر نقاط در پوشه موقت ComfyUI ذخیره می‌شود و در پوشه خروجی نوشته نمی‌شود. این یک گره خروجی است، بنابراین عمدتاً برای نمایش نتیجه پیش‌نمایش در رابط کاربری استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | داده‌های مدل ابر نقاط | FILE3D |
| `model_3d_info` | اطلاعات مربوط به مدل سه‌بعدی | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای نمای سه‌بعدی | LOAD3DCAMERA |
| `width` | عرض پنجره پیش‌نمایش | INT |
| `height` | ارتفاع پنجره پیش‌نمایش | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/PreviewPointCloud/fa.md)
