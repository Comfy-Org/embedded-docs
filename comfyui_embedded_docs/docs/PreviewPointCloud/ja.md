# ポイントクラウドのプレビュー

以下に、英語ドキュメントの日本語翻訳を示します。

---

Preview Point Cloud ノードを使用すると、出力ディレクトリに保存することなく、3D ポイントクラウドファイル（.ply ファイルなど）を ComfyUI インターフェース上で直接表示できます。このノードは、ポイントクラウドを一時ファイルに書き込み、3D プレビューウィンドウに表示し、モデルデータ、モデル情報、カメラ情報、幅、高さをそのまま後続の処理に渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ポイントクラウドファイル（.ply）です。 | FILE3D | はい | - |
| `model_3d_info` | 3D モデルに関する情報です。高度な入力です。接続されていない場合、`viewport_state` に保存されている値が使用されます。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | 現在のビューポートの状態です。プレビューに使用されるカメラ情報とモデル情報を含むことができます。 | LOAD3D | はい | - |
| `camera_info` | 3D ビューのカメラ情報です。高度な入力です。接続されていない場合、`viewport_state` に保存されている値が使用されます。 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビューウィンドウの幅（ピクセル単位、デフォルト: 1024）です。 | INT | はい | 1 to 4096 |
| `height` | プレビューウィンドウの高さ（ピクセル単位、デフォルト: 1024）です。 | INT | はい | 1 to 4096 |

注：`camera_info` または `model_3d_info` が接続されていない場合、ノードは `viewport_state` に保存されている値を使用します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | ポイントクラウドモデルデータです。変更されずにそのまま渡されます。 | FILE3D |
| `model_3d_info` | プレビューに使用される 3D モデルに関する情報です。 | LOAD3DMODELINFO |
| `camera_info` | 3D ビューに使用されるカメラ情報です。 | LOAD3DCAMERA |
| `width` | プレビューウィンドウの幅です。 | INT |
| `height` | プレビューウィンドウの高さです。 | INT |
