# PreviewPointCloud

הצומת Preview Point Cloud מאפשר להציג קובץ ענן נקודות תלת-ממדי בממשק ComfyUI בלי לשמור אותו בתיקיית הפלט של ComfyUI. הוא שומר את ענן הנקודות במיקום זמני ומציג אותו בחלון תצוגה מקדימה תלת-ממדי, ובמקביל מעביר הלאה את נתוני המודל, מידע המודל, מידע המצלמה וממדי התצוגה המקדימה לעיבוד נוסף.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | קובץ ענן נקודות (.ply) | FILE3D | כן | - |
| `model_3d_info` | מידע על המודל התלת-ממדי | LOAD3DMODELINFO | לא | - |
| `viewport_state` | המצב הנוכחי של אזור התצוגה התלת-ממדי | LOAD3D | כן | - |
| `camera_info` | מידע מצלמה עבור התצוגה התלת-ממדית | LOAD3DCAMERA | לא | - |
| `width` | רוחב חלון התצוגה המקדימה (ברירת מחדל: 1024) | INT | כן | 1 to 4096 |
| `height` | גובה חלון התצוגה המקדימה (ברירת מחדל: 1024) | INT | כן | 1 to 4096 |

הערה: `model_3d_info` ו-`camera_info` הם קלטים מתקדמים אופציונליים. כאשר הם אינם מחוברים, הצומת משתמש כברירת מחדל בערכים המתאימים המאוחסנים ב-`viewport_state`. קובץ ענן הנקודות נכתב לתיקייה הזמנית של ComfyUI ולא לתיקיית הפלט. זהו צומת פלט (טרמינלי), ולכן הוא משמש בעיקר להצגת התצוגה המקדימה בממשק.
