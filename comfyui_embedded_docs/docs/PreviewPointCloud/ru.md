# Предпросмотр облака точек

Узел Preview Point Cloud позволяет просматривать файл трехмерного облака точек непосредственно в интерфейсе ComfyUI без сохранения в выходной каталог ComfyUI. Он сохраняет облако точек во временное местоположение и отображает его в окне 3D-предпросмотра, а также передает данные модели, информацию о камере и состояние области просмотра для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл облака точек (.ply) | FILE3D | Да | - |
| `model_3d_info` | Информация о 3D-модели | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние области просмотра | LOAD3D | Да | - |
| `camera_info` | Информация о камере для 3D-вида | LOAD3DCAMERA | Нет | - |
| `width` | Ширина окна предпросмотра (по умолчанию: 1024) | INT | Да | 1 до 4096 |
| `height` | Высота окна предпросмотра (по умолчанию: 1024) | INT | Да | 1 до 4096 |

Примечание: Если `camera_info` или `model_3d_info` не подключены, узел использует соответствующие значения, сохраненные в `viewport_state`. Файл облака точек сохраняется во временный каталог ComfyUI и не записывается в выходной каталог. Это выходной узел, поэтому он в основном используется для отображения результата предпросмотра в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Данные модели облака точек | FILE3D |
| `model_3d_info` | Информация о 3D-модели | LOAD3DMODELINFO |
| `camera_info` | Информация о камере для 3D-вида | LOAD3DCAMERA |
| `width` | Ширина окна предпросмотра | INT |
| `height` | Высота окна предпросмотра | INT |
