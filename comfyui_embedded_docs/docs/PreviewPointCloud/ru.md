# Предпросмотр облака точек

Узел Preview Point Cloud позволяет просматривать файл трехмерного облака точек (например, файл .ply) непосредственно в интерфейсе ComfyUI, не сохраняя его в выходной каталог. Узел записывает облако точек во временный файл, отображает его в окне трехмерного просмотра и передает данные модели, информацию о модели, информацию о камере, ширину и высоту для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `model_3d` | Файл облака точек (.ply) | FILE3D | Да | - |
| `model_3d_info` | Информация о 3D-модели. Дополнительный вход. Если не подключен, используется значение, сохраненное в `viewport_state`. | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние области просмотра, которое может содержать информацию о камере и модели, используемую для предварительного просмотра. | LOAD3D | Да | - |
| `camera_info` | Информация о камере для трехмерного вида. Дополнительный вход. Если не подключен, используется значение, сохраненное в `viewport_state`. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 to 4096 |
| `height` | Высота окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 to 4096 |

Примечание: Если `camera_info` или `model_3d_info` не подключены, узел использует значения, сохраненные в `viewport_state`.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `model_3d` | Данные модели облака точек, передаются без изменений. | FILE3D |
| `model_3d_info` | Информация о 3D-модели, используемая для предварительного просмотра. | LOAD3DMODELINFO |
| `camera_info` | Информация о камере, используемая для трехмерного вида. | LOAD3DCAMERA |
| `width` | Ширина окна просмотра. | INT |
| `height` | Высота окна просмотра. | INT |
