# StringReplace

Il nodo StringReplace esegue operazioni di sostituzione di testo su stringhe di input. Cerca una sottostringa specificata all'interno del testo di input e sostituisce tutte le occorrenze con una sottostringa diversa. Questo nodo restituisce la stringa modificata con tutte le sostituzioni applicate.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `string` | La stringa di testo di input in cui verranno eseguite le sostituzioni | STRING | Sì | - |
| `find` | La sottostringa da cercare all'interno del testo di input | STRING | Sì | - |
| `replace` | Il testo sostitutivo che sostituirà tutte le occorrenze trovate | STRING | Sì | - |

## Output

| Nome output | Descrizione | Tipo di dato |
| --- | --- | --- |
| `output` | La stringa modificata con tutte le occorrenze del testo `find` sostituite dal testo `replace` | STRING |
