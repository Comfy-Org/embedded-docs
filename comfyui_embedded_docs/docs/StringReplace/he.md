# StringReplace

צומת StringReplace מבצע פעולות החלפת טקסט על מחרוזות קלט. הוא מחפש תת-מחרוזת מוגדרת בתוך טקסט הקלט ומחליף את כל המופעים שלה בתת-מחרוזת אחרת. צומת זה מחזיר את המחרוזת שהשתנתה לאחר החלת כל ההחלפות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת טקסט הקלט שעליה תבוצע ההחלפה | STRING | כן | - |
| `find` | תת-המחרוזת שיש לחפש בתוך טקסט הקלט | STRING | כן | - |
| `replace` | טקסט ההחלפה שיחליף את כל המופעים שנמצאו | STRING | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | המחרוזת שהשתנתה, כאשר כל המופעים של טקסט החיפוש הוחלפו בטקסט ההחלפה | STRING |
