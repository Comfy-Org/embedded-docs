# CFGZeroStar

צומת CFGZeroStar מיישם טכניקת סקיילינג הנחיה מיוחדת על מודלי דיפוזיה. הוא משנה את תהליך ההנחיה נטולת המסווג על ידי חישוב גורם קנה מידה מיטבי המבוסס על ההפרש בין תחזיות מותנות ובלתי מותנות. גישה זו מכווננת את הפלט הסופי כדי לספק שליטה משופרת בתהליך היצירה תוך שמירה על יציבות המודל.
