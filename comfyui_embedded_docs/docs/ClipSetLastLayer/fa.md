# ClipSetLastLayer

`CLIP Set Last Layer` یک گره اصلی در ComfyUI برای کنترل عمق پردازش مدل‌های CLIP است. این گره به کاربران امکان می‌دهد دقیقاً مشخص کنند که رمزگذار متنی CLIP در چه لایه‌ای پردازش را متوقف کند؛ این امر هم بر عمق درک متن و هم بر سبک تصاویر تولیدشده تأثیر می‌گذارد.

مدل CLIP را مانند یک مغز هوشمند ۲۴لایه تصور کنید:

- لایه‌های سطحی (۸-۱): حروف و کلمات پایه را تشخیص می‌دهند
- لایه‌های میانی (۱۶-۹): دستور زبان و ساختار جمله را درک می‌کنند
- لایه‌های عمیق (۲۴-۱۷): مفاهیم انتزاعی و معنای پیچیده را درمی‌یابند

`CLIP Set Last Layer` مانند یک **«کنترل‌کننده عمق تفکر»** عمل می‌کند:

- -1: استفاده از هر ۲۴ لایه (درک کامل)
- -2: توقف در لایه ۲۳ (کمی ساده‌شده)
- -12: توقف در لایه ۱۳ (درک متوسط)
- -24: استفاده از تنها لایه ۱ (درک پایه)

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که قرار است اصلاح شود | CLIP | بله | - |
| `stop_at_clip_layer` | مشخص می‌کند پردازش در کدام لایه متوقف شود. مقدار 1- یعنی استفاده از همه لایه‌ها و 24- یعنی استفاده از تنها لایه اول (پیش‌فرض: 1-). این یک پارامتر پیشرفته است. | INT | بله | 24- تا 1- (گام: 1) |

| نام خروجی | توضیحات | نوع داده |

## چرا آخرین لایه را تعیین کنیم

- **بهینه‌سازی عملکرد**: همان‌طور که برای درک جملات ساده نیازی به مدرک دکترا نیست، گاهی درک سطحی کافی و سریع‌تر است
- **کنترل سبک**: سطوح مختلف درک، سبک‌های هنری متفاوتی تولید می‌کنند
- **سازگاری**: برخی مدل‌ها ممکن است در لایه‌های خاص عملکرد بهتری داشته باشند
