# تنظیم آخرین لایه CLIP

CLIP Set Last Layer یک گره اصلی در ComfyUI برای کنترل عمق پردازش مدل‌های CLIP است. این گره به کاربران اجازه می‌دهد تا دقیقاً مشخص کنند که رمزگذار متن CLIP پردازش را در کجا متوقف کند؛ این موضوع هم بر عمق درک متن و هم بر سبک تصاویر تولیدشده تأثیر می‌گذارد.

مدل CLIP را به‌عنوان یک مغز هوشمند ۲۴لایه تصور کنید:

- لایه‌های سطحی (1-8): حروف و کلمات پایه را تشخیص می‌دهند
- لایه‌های میانی (9-16): دستور زبان و ساختار جمله را درک می‌کنند
- لایه‌های عمیق (17-24): مفاهیم انتزاعی و معناشناسی پیچیده را درک می‌کنند

`CLIP Set Last Layer` مانند یک **«کنترل‌کننده عمق تفکر»** عمل می‌کند:

- -1: استفاده از همه ۲۴ لایه (درک کامل)
- -2: توقف در لایه ۲۳ (کمی ساده‌شده)
- -12: توقف در لایه ۱۳ (درک متوسط)
- -24: استفاده فقط از لایه ۱ (درک پایه)

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که باید اصلاح شود | CLIP | بله | - |
| `stop_at_clip_layer` | مشخص می‌کند پردازش در کدام لایه متوقف شود. مقدار -1 از همه لایه‌ها استفاده می‌کند، در حالی که -24 فقط از لایه اول استفاده می‌کند (پیش‌فرض: -1) | INT | بله | -24 to -1 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `clip` | مدل CLIP اصلاح‌شده که لایه مشخص‌شده به‌عنوان آخرین لایه تنظیم شده است | CLIP |

## چرا آخرین لایه را تنظیم کنیم؟

- **بهینه‌سازی عملکرد**: همان‌طور که برای فهم جملات ساده نیازی به مدرک دکترا نیست، گاهی درک سطحی کافی و سریع‌تر است.
- **کنترل سبک**: سطوح مختلف درک، سبک‌های هنری متفاوتی تولید می‌کنند.
- **سازگاری**: برخی مدل‌ها ممکن است در لایه‌های خاصی عملکرد بهتری داشته باشند.
