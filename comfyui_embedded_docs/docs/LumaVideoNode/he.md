# LumaVideoNode

יוצר סרטוני וידאו באופן סינכרוני בהתבסס על פרומפט טקסט והגדרות פלט. צומת זה יוצר תוכן וידאו באמצעות תיאורי טקסט ופרמטרים שונים של יצירה, ומפיק את פלט הווידאו הסופי לאחר שתהליך היצירה מסתיים.

**הערה:** צומת זה מסומן כמיושן בקוד המקור. Luma תסיר את נקודות הקצה שצומת זה קורא להן ב-24 באוקטובר 2026, לכן השתמשו בצמתי Luma Ray 3.2 במקום.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת הווידאו (ברירת מחדל: מחרוזת ריקה). חייב להיות באורך של לפחות 3 תווים. | STRING | כן | - |
| `model` | מודל יצירת הווידאו שבו יש להשתמש. | COMBO | כן | `"ray-1-6"`<br>`"ray-2"` |
| `aspect_ratio` | יחס הרוחב-גובה של הווידאו שנוצר (ברירת מחדל: "16:9"). | COMBO | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"`<br>`"9:21"` |
| `resolution` | רזולוציית הפלט של הווידאו (ברירת מחדל: "540p"). פרמטר זה אינו נלקח בחשבון כאשר משתמשים במודל `ray-1-6`. | COMBO | כן | `"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration` | משך הווידאו שנוצר. פרמטר זה אינו נלקח בחשבון כאשר משתמשים במודל `ray-1-6`. | COMBO | כן | `"5s"`<br>`"9s"` |
| `loop` | האם הווידאו אמור לחזור על עצמו בלולאה (ברירת מחדל: False). | BOOLEAN | כן | - |
| `seed` | ערך Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-Seed (ברירת מחדל: 0). | INT | כן | 0 to 18446744073709551615 |
| `luma_concepts` | Camera Concepts אופציונליים לקביעת תנועת המצלמה באמצעות צומת Luma Concepts. | CUSTOM | לא | - |

**הערה:** כאשר משתמשים במודל `ray-1-6`, הפרמטרים `duration` ו-`resolution` אינם נלקחים בחשבון באופן אוטומטי ואינם משפיעים על היצירה.
