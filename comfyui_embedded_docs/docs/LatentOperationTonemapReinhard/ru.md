# Операция латента: тональная карта Рейнхарда

Этот узел создает латентную операцию, которая применяет тональную компрессию Reinhard к латентным векторам. Он нормализует каждый латентный вектор, измеряет общее распределение величины (среднее и стандартное отклонение), а затем сжимает экстремальные величины с помощью кривой Reinhard, при этом общая сила контролируется множителем. Узел помечен как экспериментальный (также доступен для поиска как "hdr latent").

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `множитель` | Управляет интенсивностью эффекта тональной компрессии (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 100.0 (шаг 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `operation` | Возвращает операцию тональной компрессии, которую можно применить к латентным векторам | LATENT_OPERATION |
