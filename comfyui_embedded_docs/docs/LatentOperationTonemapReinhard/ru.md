# Операция латента: тональная карта Рейнхарда

LatentOperationTonemapReinhard применяет тонемаппинг Рейнхарда к латентным векторам. Этот метод нормализует латентные векторы и корректирует их величину с помощью статистического подхода, основанного на среднем значении и стандартном отклонении величин, при этом интенсивность регулируется параметром-множителем.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `multiplier` | Управляет интенсивностью эффекта тонемаппинга (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 100.0 |

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `operation` | Возвращает операцию тонемаппинга, которую можно применить к латентным векторам | LATENT_OPERATION |
