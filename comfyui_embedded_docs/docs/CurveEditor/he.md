# CurveEditor

צומת Curve Editor מספק ממשק חזותי להתאמה ולכיוונון עדין של עקומה. באפשרותך לשנות את צורתה של עקומת קלט ישירות בממשק הצומת, ובאופן אופציונלי להציג היסטוגרמה לצדה לצורך עיון חזותי. הצומת תומך בפלט ביניים במהלך העריכה, כך שניתן לראות תוצאות בזמן אמת תוך ביצוע השינויים, ומייצר את העקומה שהשתנתה לשימוש בחלקים אחרים של זרימת העבודה שלך.
