# Редактор кривых

Узел Curve Editor предоставляет визуальный интерфейс для настройки и точной подгонки кривой. Вы можете изменять форму входной кривой непосредственно в интерфейсе узла и при необходимости отображать гистограмму рядом для визуальной справки. Узел поддерживает промежуточный вывод во время редактирования, позволяя видеть результаты в реальном времени по мере внесения изменений, и выводит изменённую кривую для использования в других частях вашего рабочего процесса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кривая` | Входная кривая для редактирования. | CURVE | Да | N/A |
| `гистограмма` | Необязательная гистограмма для отображения рядом с кривой в качестве визуальной справки. | HISTOGRAM | Нет | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `кривая` | Изменённая кривая после настроек, выполненных в интерфейсе узла. | CURVE |
