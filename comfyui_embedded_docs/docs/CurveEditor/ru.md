# Редактор кривых

Узел **Curve Editor** предоставляет визуальный интерфейс для настройки и точной подстройки кривой. Он позволяет изменять форму входной кривой и при желании визуализировать её распределение с помощью гистограммы. Узел выводит изменённую кривую для использования в других частях вашего рабочего процесса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `curve` | Входная кривая, которую необходимо отредактировать. | CURVE | Да | N/A |
| `histogram` | Необязательная гистограмма для отображения рядом с кривой в качестве визуальной справки. | HISTOGRAM | Нет | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `curve` | Отредактированная кривая после изменений, внесённых в интерфейсе узла. | CURVE |
