# Editor de Curva

O nó Curve Editor fornece uma interface visual para ajustar e refinar uma curva. Ele permite modificar o formato de uma curva de entrada e, opcionalmente, visualizar sua distribuição com um histograma. O nó gera a curva modificada para uso em outras partes do seu fluxo de trabalho.

## Entradas

| Parâmetro | Descrição | Tipo de Dados | Obrigatório | Faixa |
| --- | --- | --- | --- | --- |
| `curve` | A curva de entrada a ser editada. | CURVE | Sim | N/A |
| `histogram` | Um histograma opcional para exibir junto à curva como referência visual. | HISTOGRAM | Não | N/A |
