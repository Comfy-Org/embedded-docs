# Editor de curvas

El nodo Curve Editor proporciona una interfaz visual para ajustar y refinar una curva. Permite modificar la forma de una curva de entrada y, opcionalmente, visualizar su distribución con un histograma. El nodo devuelve la curva modificada para usarla en otras partes de su flujo de trabajo.

## Entradas

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
| --- | --- | --- | --- | --- |
| `curve` | La curva de entrada que se va a editar. | CURVE | Sí | N/A |
| `histogram` | Un histograma opcional para mostrar junto a la curva como referencia visual. | HISTOGRAM | No | N/A |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `curve` | La curva editada después de los ajustes realizados en la interfaz del nodo. | CURVE |
