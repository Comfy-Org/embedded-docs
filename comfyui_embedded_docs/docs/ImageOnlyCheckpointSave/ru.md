# Сохранить только checkpoint изображения

Этот узел сохраняет файл чекпоинта, который объединяет модель вместе с её энкодером CLIP vision и VAE. Файл записывается в формате safetensors в выходной каталог с использованием заданного префикса имени файла, что позволяет сохранить связанные с изображениями компоненты модели в виде одного чекпоинта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, сохраняемая в чекпоинте | MODEL | Да | - |
| `clip_vision` | Энкодер CLIP vision, сохраняемый в чекпоинте | CLIP_VISION | Да | - |
| `vae` | VAE (вариационный автоэнкодер), сохраняемый в чекпоинте | VAE | Да | - |
| `префикс_названия_файла` | Префикс имени выходного файла (по умолчанию: "checkpoints/ComfyUI") | STRING | Да | - |
| `prompt` | Скрытый параметр, который получает данные промпта рабочего процесса | PROMPT | Нет | - |
| `extra_pnginfo` | Скрытый параметр, который получает дополнительные метаданные PNG | EXTRA_PNGINFO | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| - | Этот узел не возвращает выходные данные | - |
