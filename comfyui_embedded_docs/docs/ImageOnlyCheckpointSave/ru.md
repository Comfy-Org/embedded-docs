# Сохранить только checkpoint изображения

Узел ImageOnlyCheckpointSave сохраняет файл контрольной точки, содержащий модель, энкодер CLIP vision и VAE. Он создаёт файл safetensors с указанным префиксом имени файла и сохраняет его в выходном каталоге. Этот узел специально предназначен для совместного сохранения компонентов модели, связанных с изображениями, в одном файле контрольной точки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, которая будет сохранена в контрольной точке | MODEL | Да | - |
| `clip_vision` | Энкодер CLIP vision, который будет сохранён в контрольной точке | CLIP_VISION | Да | - |
| `vae` | VAE (вариационный автокодировщик), который будет сохранён в контрольной точке | VAE | Да | - |
| `filename_prefix` | Префикс для имени выходного файла (по умолчанию: "checkpoints/ComfyUI") | STRING | Да | - |
| `prompt` | Скрытый параметр для данных промпта рабочего процесса | PROMPT | Нет | - |
| `extra_pnginfo` | Скрытый параметр для дополнительных метаданных PNG | EXTRA_PNGINFO | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| - | Этот узел не возвращает никаких выходных данных | - |
