# Сохранить только checkpoint изображения

Узел `ImageOnlyCheckpointSave` сохраняет файл контрольной точки, содержащий модель, энкодер CLIP vision и VAE. Он создает файл safetensors с указанным префиксом имени файла и сохраняет его в выходном каталоге. Этот узел специально предназначен для сохранения компонентов модели, связанных с изображением, вместе в одном файле контрольной точки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, сохраняемая в контрольной точке | MODEL | Да | - |
| `clip_vision` | Энкодер CLIP vision, сохраняемый в контрольной точке | CLIP_VISION | Да | - |
| `vae` | VAE (вариационный автокодировщик), сохраняемый в контрольной точке | VAE | Да | - |
| `префикс_названия_файла` | Префикс для имени выходного файла (по умолчанию: "checkpoints/ComfyUI") | STRING | Да | - |
| `prompt` | Скрытый параметр для данных промпта рабочего процесса | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные PNG | EXTRA_PNGINFO | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| - | Этот узел не возвращает никаких выходных данных | - |
