# ذخیره Checkpoint فقط تصویر

این گره یک فایل چک‌پوینت ذخیره می‌کند که مدل را همراه با رمزگذار بینایی CLIP و VAE آن در یک بسته قرار می‌دهد. فایل با قالب safetensors در پوشه خروجی و با استفاده از پیشوند نام فایل داده‌شده نوشته می‌شود، بنابراین اجزای مرتبط با تصویر یک مدل می‌توانند به‌صورت یک چک‌پوینت واحد ذخیره شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که باید در چک‌پوینت ذخیره شود | MODEL | بله | - |
| `clip_vision` | رمزگذار بینایی CLIP که باید در چک‌پوینت ذخیره شود | CLIP_VISION | بله | - |
| `vae` | VAE (خودرمزگذار متغیر) که باید در چک‌پوینت ذخیره شود | VAE | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "checkpoints/ComfyUI") | STRING | بله | - |
| `prompt` | پارامتر پنهانی که داده‌های prompt گردش کار را دریافت می‌کند | PROMPT | خیر | - |
| `extra_pnginfo` | پارامتر پنهانی که فراداده اضافی PNG را دریافت می‌کند | EXTRA_PNGINFO | خیر | - |
