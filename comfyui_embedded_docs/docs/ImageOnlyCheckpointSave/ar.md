# حفظ نقطة تحقق الصور فقط

تقوم عقدة ImageOnlyCheckpointSave بحفظ ملف نقطة تفتيش يحتوي على نموذج ومُشفر رؤية CLIP وVAE. وهي تنشئ ملف safetensors ببادئة اسم الملف المحددة وتخزّنه في مجلد الإخراج. صُممت هذه العقدة خصيصًا لحفظ مكونات النموذج المرتبطة بالصور معًا في ملف نقطة تفتيش واحد.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المطلوب حفظه في نقطة التفتيش | MODEL | نعم | - |
| `رؤية Clip` | مُشفر الرؤية CLIP المطلوب حفظه في نقطة التفتيش | CLIP_VISION | نعم | - |
| `VAE` | VAE (المشفر التلقائي المتغير) المطلوب حفظه في نقطة التفتيش | VAE | نعم | - |
| `بادئة اسم الملف` | بادئة اسم ملف الإخراج (الافتراضي: "checkpoints/ComfyUI") | STRING | نعم | - |
| `prompt` | معلمة مخفية لبيانات سير عمل الموجّه | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية بصيغة PNG | EXTRA_PNGINFO | لا | - |
