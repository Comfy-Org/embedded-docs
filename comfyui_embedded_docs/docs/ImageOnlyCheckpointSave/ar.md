# حفظ نقطة تحقق الصور فقط

يوفّر عقدة **ImageOnlyCheckpointSave** حفظ ملف نقطة تفتيش (checkpoint) يحتوي على نموذج ومُشَفِّر رؤية CLIP وشبكة VAE. تنشئ هذه العقدة ملفًا بصيغة safetensors بالبادئة المحددة لاسم الملف، وتخزّنه في مجلد الإخراج. صُمِّمت هذه العقدة خصيصًا لحفظ مكونات النموذج المرتبطة بالصور معًا في ملف نقطة تفتيش واحد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج المراد حفظه في ملف نقطة التفتيش | MODEL | نعم | - |
| `clip_vision` | مُشَفِّر رؤية CLIP المراد حفظه في ملف نقطة التفتيش | CLIP_VISION | نعم | - |
| `vae` | شبكة الترميز التلقائي التبايني (VAE) المراد حفظها في ملف نقطة التفتيش | VAE | نعم | - |
| `filename_prefix` | بادئة اسم ملف الإخراج (الافتراضي: "checkpoints/ComfyUI") | STRING | نعم | - |
| `prompt` | معامِل مخفي لبيانات موجه سير العمل | PROMPT | لا | - |
| `extra_pnginfo` | معامِل مخفي لبيانات وصفية إضافية لملفات PNG | EXTRA_PNGINFO | لا | - |
