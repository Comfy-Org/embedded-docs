# LoopIteration

이 노드는 루프 스타일 워크플로를 위한 반복 메타데이터를 제공합니다. 리스트 기반 입력을 받아 각 리스트의 첫 번째 요소를 그대로 전달하므로, 루프는 현재 인덱스, 첫 번째 단계인지 마지막 단계인지, 현재 리스트 항목, 그리고 실행 중인 반복 값을 추적할 수 있습니다. 캐시 동작은 `reuse_cache` 플래그로 제어됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 현재 반복의 인덱스로, 리스트로 제공됩니다. 첫 번째 요소가 출력으로 그대로 전달됩니다. | INT | 예 | - |
| `is_first` | 현재 반복이 첫 번째인지 여부를 나타내며, 리스트로 제공됩니다. 첫 번째 요소가 출력으로 그대로 전달됩니다. | BOOLEAN | 예 | - |
| `is_last` | 현재 반복이 마지막인지 여부를 나타내며, 리스트로 제공됩니다. 첫 번째 요소가 출력으로 그대로 전달됩니다. | BOOLEAN | 예 | - |
| `list_item` | 이번 반복을 위해 리스트에서 가져온 항목입니다. 선택 사항이며, 제공된 경우 첫 번째 요소가 출력으로 그대로 전달되고, 그렇지 않으면 None이 반환됩니다. | ANY | 아니요 | - |
| `current_iteration_value` | 현재 반복에서 전달되는 값입니다. 선택 사항이며, 제공된 경우 첫 번째 요소가 출력으로 그대로 전달되고, 그렇지 않으면 None이 반환됩니다. | ANY | 아니요 | - |
| `reuse_cache` | 결과를 캐시에서 재사용할 수 있는지 제어합니다. 활성화하면 노드가 안정적인 핑거프린트를 유지하므로 캐시된 결과를 재사용할 수 있습니다. 비활성화하면 일치하지 않는 핑거프린트가 생성되어 각 반복마다 노드가 다시 실행됩니다. | BOOLEAN | 예 | - |

참고: 이 노드는 리스트 입력이 활성화되어 있어 각 입력이 리스트로 도착할 것으로 예상하며, 노드는 각 리스트의 첫 번째 요소만 출력합니다. 또한 여기에 나열된 것 외의 추가 입력도 받을 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `iteration_index` | 현재 반복의 인덱스입니다. | INT |
| `is_first` | 현재 반복이 첫 번째인지 여부입니다. | BOOLEAN |
| `is_last` | 현재 반복이 마지막인지 여부입니다. | BOOLEAN |
| `list_item` | 이번 반복을 위해 리스트에서 가져온 항목이며, 항목이 제공되지 않은 경우 None입니다. | ANY |
| `current_iteration_value` | 현재 반복에서 전달되는 값이며, 값이 제공되지 않은 경우 None입니다. | ANY |
