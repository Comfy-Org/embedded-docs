# LoopIteration

此節點為迴圈式工作流程提供迭代中繼資料。它接收以列表為基礎的輸入，並傳遞每個列表的第一個元素，因此迴圈可以追蹤目前索引、是否為第一步或最後一步、目前列表項目，以及任何執行中的迭代值。快取行為由 `reuse_cache` 旗標控制。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 目前迭代的索引，以列表形式提供。第一個元素會傳遞至輸出。 | INT | 是 | - |
| `is_first` | 表示目前迭代是否為第一次，以列表形式提供。第一個元素會傳遞至輸出。 | BOOLEAN | 是 | - |
| `is_last` | 表示目前迭代是否為最後一次，以列表形式提供。第一個元素會傳遞至輸出。 | BOOLEAN | 是 | - |
| `list_item` | 此迭代從列表中取出的項目。可選；提供時，第一個元素會傳遞至輸出，否則傳回 None。 | ANY | 否 | - |
| `current_iteration_value` | 目前迭代所攜帶的值。可選；提供時，第一個元素會傳遞至輸出，否則傳回 None。 | ANY | 否 | - |
| `reuse_cache` | 控制結果是否可從快取重複使用。啟用時，節點會保留穩定的指紋，因此可重複使用快取結果。停用時，會產生不相符的指紋，因此節點會在每次迭代時重新執行。 | BOOLEAN | 是 | - |

注意：此節點支援列表輸入，表示每個輸入預期會以列表形式抵達，而節點只會輸出每個列表的第一個元素。它也可接受此處所列之外的額外輸入。
