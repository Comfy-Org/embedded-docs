# LoopIteration

此節點為迴圈式工作流程提供迭代中繼資料。它接收以清單為基礎的輸入，並傳遞每個清單的第一個元素，讓迴圈可以追蹤目前索引、是否為第一步或最後一步、目前的清單項目，以及任何執行中的迭代值。快取行為由 `reuse_cache` 旗標控制。此節點標記為僅限開發者使用。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 目前迭代的索引，以清單形式提供。第一個元素會傳遞至輸出。 | INT | 是 | - |
| `is_first` | 指出目前迭代是否為第一個，以清單形式提供。第一個元素會傳遞至輸出。 | BOOLEAN | 是 | - |
| `is_last` | 指出目前迭代是否為最後一個，以清單形式提供。第一個元素會傳遞至輸出。 | BOOLEAN | 是 | - |
| `list_item` | 此迭代從清單中取得的項目。選填；提供時會將第一個元素傳遞至輸出，否則傳回 None。 | ANY | 否 | - |
| `current_iteration_value` | 目前迭代所攜帶的值。選填；提供時會將完整值傳遞至輸出，否則傳回 None。 | ANY | 否 | - |
| `reuse_cache` | 控制是否可從快取重複使用結果。啟用時，節點會保留穩定的指紋，以便重複使用快取的結果。停用時，會產生不相符的指紋，使節點在每次迭代時重新執行。 | BOOLEAN | 是 | - |

注意：此節點已啟用清單輸入，表示每個輸入預期會以清單形式送達，而節點只會輸出每個清單的第一個元素（但 `current_iteration_value` 例外，會以清單形式傳遞）。它也會接受此處未列出的其他輸入。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `iteration_index` | 目前迭代的索引。 | INT |
| `is_first` | 目前迭代是否為第一個。 | BOOLEAN |
| `is_last` | 目前迭代是否為最後一個。 | BOOLEAN |
| `list_item` | 此迭代從清單中取得的項目；若未提供項目則為 None。 | ANY |
| `current_iteration_value` | 目前迭代所攜帶的值；若未提供值則為 None。此輸出會以清單形式傳回。 | ANY |
