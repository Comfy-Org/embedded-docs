# LoopIteration

このノードは、ループ形式のワークフロー向けにイテレーションメタデータを提供します。リストベースの入力を受け取り、各リストの最初の要素をそのまま出力します。これにより、ループは現在のインデックス、最初または最後のステップかどうか、現在のリスト項目、および実行中のイテレーション値を追跡できます。キャッシュ動作は `reuse_cache` フラグで制御されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 現在のイテレーションのインデックス。リストとして渡されます。最初の要素が出力にそのまま渡されます。 | INT | はい | - |
| `is_first` | 現在のイテレーションが最初のものであるかどうかを示します。リストとして渡されます。最初の要素が出力にそのまま渡されます。 | BOOLEAN | はい | - |
| `is_last` | 現在のイテレーションが最後のものであるかどうかを示します。リストとして渡されます。最初の要素が出力にそのまま渡されます。 | BOOLEAN | はい | - |
| `list_item` | このイテレーションでリストから取得された項目。任意です。指定された場合は最初の要素が出力にそのまま渡され、指定されない場合は None が返されます。 | ANY | いいえ | - |
| `current_iteration_value` | 現在のイテレーションによって保持される値。任意です。指定された場合は最初の要素が出力にそのまま渡され、指定されない場合は None が返されます。 | ANY | いいえ | - |
| `reuse_cache` | 結果をキャッシュから再利用できるかどうかを制御します。有効にすると、ノードは安定したフィンガープリントを保持するため、キャッシュされた結果を再利用できます。無効にすると、一致しないフィンガープリントが生成されるため、ノードは各イテレーションで再実行されます。 | BOOLEAN | はい | - |

注: このノードはリスト入力に対応しています。つまり、各入力はリストとして到着することが想定され、ノードは各リストの最初の要素のみを出力します。ここに記載されている以外の追加入力も受け付けます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `iteration_index` | 現在のイテレーションのインデックス。 | INT |
| `is_first` | 現在のイテレーションが最初のものであるかどうか。 | BOOLEAN |
| `is_last` | 現在のイテレーションが最後のものであるかどうか。 | BOOLEAN |
| `list_item` | このイテレーションでリストから取得された項目。項目が指定されなかった場合は None。 | ANY |
| `current_iteration_value` | 現在のイテレーションによって保持される値。値が指定されなかった場合は None。 | ANY |
