# LoopIteration

Этот узел предоставляет метаданные итерации для рабочих процессов циклического типа. Он принимает входы на основе списков и передаёт через себя первый элемент каждого списка, чтобы цикл мог отслеживать текущий индекс, является ли шаг первым или последним, текущий элемент списка и любое текущее значение итерации. Поведение кэширования управляется флагом `reuse_cache`. Этот узел помечен как только для разработчиков.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | Индекс текущей итерации, передаваемый в виде списка. Первый элемент передаётся на выход. | INT | Да | - |
| `is_first` | Указывает, является ли текущая итерация первой; передаётся в виде списка. Первый элемент передаётся на выход. | BOOLEAN | Да | - |
| `is_last` | Указывает, является ли текущая итерация последней; передаётся в виде списка. Первый элемент передаётся на выход. | BOOLEAN | Да | - |
| `list_item` | Элемент, взятый из списка для этой итерации. Необязательный; если указан, первый элемент передаётся на выход, иначе возвращается None. | ANY | Нет | - |
| `current_iteration_value` | Значение, переносимое текущей итерацией. Необязательный; если указан, полное значение передаётся на выход, иначе возвращается None. | ANY | Нет | - |
| `reuse_cache` | Управляет тем, может ли результат быть повторно использован из кэша. Когда включено, узел сохраняет стабильный отпечаток, чтобы кэшированные результаты можно было переиспользовать. Когда отключено, создаётся несовпадающий отпечаток, поэтому узел запускается заново на каждой итерации. | BOOLEAN | Да | - |

Примечание. Этот узел поддерживает списковые входы: каждый вход должен поступать в виде списка, а узел выводит только первый элемент каждого списка (кроме `current_iteration_value`, который передаётся как список). Он также принимает дополнительные входы помимо перечисленных здесь.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `iteration_index` | Индекс текущей итерации. | INT |
| `is_first` | Является ли текущая итерация первой. | BOOLEAN |
| `is_last` | Является ли текущая итерация последней. | BOOLEAN |
| `list_item` | Элемент, взятый из списка для этой итерации, или None, если элемент не был предоставлен. | ANY |
| `current_iteration_value` | Значение, переносимое текущей итерацией, или None, если значение не было предоставлено. Этот выход возвращается в виде списка. | ANY |
