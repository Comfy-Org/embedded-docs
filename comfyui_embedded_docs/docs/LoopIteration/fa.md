# LoopIteration

این گره فرادادهٔ تکرار را برای گردش‌کارهای حلقه‌ای فراهم می‌کند. ورودی‌های مبتنی بر فهرست را دریافت می‌کند و اولین عنصر هر فهرست را عبور می‌دهد، تا یک حلقه بتواند شاخص جاری، نخستین یا آخرین بودن گام، آیتم جاری فهرست، و هر مقدار تکرار در حال اجرا را ردیابی کند. رفتار کش توسط پرچم `reuse_cache` کنترل می‌شود. این گره با برچسب «فقط توسعه‌دهندگان» مشخص شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | شاخص تکرار جاری، که به‌صورت فهرست ارائه می‌شود. اولین عنصر به خروجی عبور داده می‌شود. | INT | بله | - |
| `is_first` | نشان می‌دهد که آیا تکرار جاری نخستین است یا نه، و به‌صورت فهرست ارائه می‌شود. اولین عنصر به خروجی عبور داده می‌شود. | BOOLEAN | بله | - |
| `is_last` | نشان می‌دهد که آیا تکرار جاری آخرین است یا نه، و به‌صورت فهرست ارائه می‌شود. اولین عنصر به خروجی عبور داده می‌شود. | BOOLEAN | بله | - |
| `list_item` | آیتمی که برای این تکرار از فهرست گرفته می‌شود. اختیاری؛ در صورت ارائه، اولین عنصر به خروجی عبور داده می‌شود، در غیر این صورت None برگردانده می‌شود. | ANY | خیر | - |
| `current_iteration_value` | مقداری که تکرار جاری حمل می‌کند. اختیاری؛ در صورت ارائه، کل مقدار به خروجی عبور داده می‌شود، در غیر این صورت None برگردانده می‌شود. | ANY | خیر | - |
| `reuse_cache` | کنترل می‌کند که آیا نتیجه می‌تواند از کش دوباره استفاده شود. وقتی فعال باشد، گره یک اثر انگشت پایدار نگه می‌دارد تا نتایج کش‌شده بتوانند دوباره استفاده شوند. وقتی غیرفعال باشد، یک اثر انگشت ناسازگار تولید می‌شود تا گره در هر تکرار دوباره اجرا شود. | BOOLEAN | بله | - |

نکته: این گره از ورودی فهرستی پشتیبانی می‌کند، یعنی انتظار می‌رود هر ورودی به‌صورت یک فهرست برسد و گره تنها اولین عنصر هر فهرست را خروجی می‌دهد (به‌جز `current_iteration_value` که به‌صورت فهرست عبور داده می‌شود). همچنین ورودی‌های بیشتری فراتر از موارد فهرست‌شده در اینجا می‌پذیرد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `iteration_index` | شاخص تکرار جاری. | INT |
| `is_first` | اینکه آیا تکرار جاری نخستین است یا نه. | BOOLEAN |
| `is_last` | اینکه آیا تکرار جاری آخرین است یا نه. | BOOLEAN |
| `list_item` | آیتم گرفته‌شده از فهرست برای این تکرار، یا None در صورتی که هیچ آیتمی ارائه نشده باشد. | ANY |
| `current_iteration_value` | مقداری که تکرار جاری حمل می‌کند، یا None در صورتی که هیچ مقداری ارائه نشده باشد. این خروجی به‌صورت یک فهرست برگردانده می‌شود. | ANY |
