# LoopIteration

این گره فرادادهٔ تکرار را برای گردش‌کارهای حلقه‌ای فراهم می‌کند. ورودی‌های مبتنی بر فهرست را دریافت می‌کند و نخستین عنصر هر فهرست را عبور می‌دهد، بنابراین یک حلقه می‌تواند نمایهٔ جاری، نخستین یا آخرین بودن گام، آیتم فهرست جاری و هر مقدار تکرار در حال اجرا را ردیابی کند. رفتار حافظه نهان با پرچم `reuse_cache` کنترل می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | نمایهٔ تکرار جاری که به‌صورت فهرست ارائه می‌شود. نخستین عنصر به خروجی عبور داده می‌شود. | INT | بله | - |
| `is_first` | نشان می‌دهد که آیا تکرار جاری نخستین مورد است یا نه؛ به‌صورت فهرست ارائه می‌شود. نخستین عنصر به خروجی عبور داده می‌شود. | BOOLEAN | بله | - |
| `is_last` | نشان می‌دهد که آیا تکرار جاری آخرین مورد است یا نه؛ به‌صورت فهرست ارائه می‌شود. نخستین عنصر به خروجی عبور داده می‌شود. | BOOLEAN | بله | - |
| `list_item` | آیتمی که برای این تکرار از فهرست گرفته می‌شود. اختیاری؛ در صورت ارائه، نخستین عنصر به خروجی عبور داده می‌شود، در غیر این صورت None بازگردانده می‌شود. | ANY | خیر | - |
| `current_iteration_value` | مقداری که تکرار جاری حمل می‌کند. اختیاری؛ در صورت ارائه، نخستین عنصر به خروجی عبور داده می‌شود، در غیر این صورت None بازگردانده می‌شود. | ANY | خیر | - |
| `reuse_cache` | کنترل می‌کند که آیا نتیجه ممکن است از حافظه نهان دوباره استفاده شود. وقتی فعال باشد، گره اثر انگشت پایداری نگه می‌دارد تا نتایج ذخیره‌شده در حافظه نهان قابل استفاده مجدد باشند. وقتی غیرفعال باشد، اثر انگشتی ناهمخوان تولید می‌شود تا گره در هر تکرار دوباره اجرا شود. | BOOLEAN | بله | - |

توجه: این گره قابلیت ورودی فهرستی دارد، یعنی انتظار می‌رود هر ورودی به‌صورت فهرست برسد و گره فقط نخستین عنصر هر فهرست را خروجی می‌دهد. همچنین ورودی‌های بیشتری فراتر از موارد فهرست‌شده در اینجا می‌پذیرد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `iteration_index` | نمایهٔ تکرار جاری. | INT |
| `is_first` | اینکه آیا تکرار جاری نخستین مورد است. | BOOLEAN |
| `is_last` | اینکه آیا تکرار جاری آخرین مورد است. | BOOLEAN |
| `list_item` | آیتمی که برای این تکرار از فهرست گرفته می‌شود، یا None هنگامی که هیچ آیتمی ارائه نشده است. | ANY |
| `current_iteration_value` | مقداری که تکرار جاری حمل می‌کند، یا None هنگامی که هیچ مقداری ارائه نشده است. | ANY |
