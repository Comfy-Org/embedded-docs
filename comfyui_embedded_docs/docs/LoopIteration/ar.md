# LoopIteration

توفر هذه العقدة بيانات وصفية للتكرار في سير العمل ذي النمط الحلقي. تستقبل مدخلات قائمة على القوائم وتمرّر العنصر الأول من كل قائمة، بحيث يمكن للحلقة تتبّع الفهرس الحالي، وما إذا كانت الخطوة الأولى أو الأخيرة، وعنصر القائمة الحالي، وأي قيمة تكرار جارية. يتم التحكم في سلوك الذاكرة المؤقتة عبر علامة `reuse_cache`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | فهرس التكرار الحالي، ويُقدَّم كقائمة. يتم تمرير العنصر الأول إلى المخرج. | INT | نعم | - |
| `is_first` | يشير إلى ما إذا كان التكرار الحالي هو الأول، ويُقدَّم كقائمة. يتم تمرير العنصر الأول إلى المخرج. | BOOLEAN | نعم | - |
| `is_last` | يشير إلى ما إذا كان التكرار الحالي هو الأخير، ويُقدَّم كقائمة. يتم تمرير العنصر الأول إلى المخرج. | BOOLEAN | نعم | - |
| `list_item` | العنصر المأخوذ من القائمة لهذا التكرار. اختياري؛ عند توفيره يتم تمرير العنصر الأول إلى المخرج، وإلا تُعاد قيمة None. | ANY | لا | - |
| `current_iteration_value` | القيمة التي يحملها التكرار الحالي. اختياري؛ عند توفيرها يتم تمرير العنصر الأول إلى المخرج، وإلا تُعاد قيمة None. | ANY | لا | - |
| `reuse_cache` | يتحكم في إمكانية إعادة استخدام النتيجة من الذاكرة المؤقتة. عند التمكين، تحتفظ العقدة ببصمة مستقرة بحيث يمكن إعادة استخدام النتائج المخزنة مؤقتًا. عند التعطيل، تُنتَج بصمة غير مطابقة بحيث تُعاد العقدة للتشغيل في كل تكرار. | BOOLEAN | نعم | - |

ملاحظة: هذه العقدة ممكّنة لمدخلات القوائم، ما يعني أن كل مدخل يُتوقع أن يصل كقائمة، وأن العقدة تُخرج فقط العنصر الأول من كل قائمة. كما تقبل مدخلات إضافية تتجاوز تلك المذكورة هنا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-----------|-----------|
| `iteration_index` | فهرس التكرار الحالي. | INT |
| `is_first` | ما إذا كان التكرار الحالي هو الأول. | BOOLEAN |
| `is_last` | ما إذا كان التكرار الحالي هو الأخير. | BOOLEAN |
| `list_item` | العنصر المأخوذ من القائمة لهذا التكرار، أو None عند عدم توفير عنصر. | ANY |
| `current_iteration_value` | القيمة التي يحملها التكرار الحالي، أو None عند عدم توفير قيمة. | ANY |
