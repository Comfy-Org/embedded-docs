# LoopIteration

此节点为循环式工作流提供迭代元数据。它接收基于列表的输入，并透传每个列表的第一个元素，因此循环可以跟踪当前索引、当前是否为第一步或最后一步、当前列表项以及任何正在运行的迭代值。缓存行为由 `reuse_cache` 标志控制。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 当前迭代的索引，以列表形式提供。第一个元素会被透传到输出。 | INT | 是 | - |
| `is_first` | 指示当前迭代是否为第一次迭代，以列表形式提供。第一个元素会被透传到输出。 | BOOLEAN | 是 | - |
| `is_last` | 指示当前迭代是否为最后一次迭代，以列表形式提供。第一个元素会被透传到输出。 | BOOLEAN | 是 | - |
| `list_item` | 本次迭代从列表中取出的项。可选；提供时，第一个元素会被透传到输出，否则返回 None。 | ANY | 否 | - |
| `current_iteration_value` | 当前迭代携带的值。可选；提供时，第一个元素会被透传到输出，否则返回 None。 | ANY | 否 | - |
| `reuse_cache` | 控制结果是否可以从缓存中重用。启用时，节点会保持稳定的指纹，以便缓存结果可以被重用。禁用时，会生成不匹配的指纹，使节点在每次迭代时重新运行。 | BOOLEAN | 是 | - |

注意：此节点启用了列表输入，这意味着每个输入都应以列表形式到达，并且节点仅输出每个列表的第一个元素。它还接受此处所列输入之外的额外输入。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `iteration_index` | 当前迭代的索引。 | INT |
| `is_first` | 当前迭代是否为第一次迭代。 | BOOLEAN |
| `is_last` | 当前迭代是否为最后一次迭代。 | BOOLEAN |
| `list_item` | 本次迭代从列表中取出的项；未提供项时返回 None。 | ANY |
| `current_iteration_value` | 当前迭代携带的值；未提供值时返回 None。 | ANY |
