# LoopIteration

צומת זה מספק מטא-נתוני איטרציה עבור תהליכי עבודה בסגנון לולאה. הוא מקבל קלטים מבוססי רשימה ומעביר הלאה את האיבר הראשון מכל רשימה, כך שלולאה יכולה לעקוב אחר האינדקס הנוכחי, האם זהו הצעד הראשון או האחרון, פריט הרשימה הנוכחי, וכל ערך איטרציה שוטף. התנהגות המטמון נשלטת על ידי הדגל `reuse_cache`. צומת זה מסומן כמפתחים בלבד.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | האינדקס של האיטרציה הנוכחית, מסופק כרשימה. האיבר הראשון מועבר לפלט. | INT | כן | - |
| `is_first` | מציין אם האיטרציה הנוכחית היא הראשונה, מסופק כרשימה. האיבר הראשון מועבר לפלט. | BOOLEAN | כן | - |
| `is_last` | מציין אם האיטרציה הנוכחית היא האחרונה, מסופק כרשימה. האיבר הראשון מועבר לפלט. | BOOLEAN | כן | - |
| `list_item` | הפריט שנלקח מהרשימה עבור איטרציה זו. אופציונלי; כאשר מסופק, האיבר הראשון מועבר לפלט, אחרת מוחזר None. | ANY | לא | - |
| `current_iteration_value` | הערך הנישא באיטרציה הנוכחית. אופציונלי; כאשר מסופק, הערך המלא מועבר לפלט, אחרת מוחזר None. | ANY | לא | - |
| `reuse_cache` | שולט אם ניתן להשתמש בתוצאה מהמטמון. כאשר מופעל, הצומת שומר על טביעת אצבע יציבה כך שניתן לעשות שימוש חוזר בתוצאות שמורות במטמון. כאשר מושבת, נוצרת טביעת אצבע שאינה תואמת כך שהצומת פועל מחדש בכל איטרציה. | BOOLEAN | כן | - |

הערה: צומת זה תומך בקלט רשימה, כלומר כל קלט צפוי להגיע כרשימה והצומת מוציא רק את האיבר הראשון מכל רשימה (למעט `current_iteration_value`, שמועבר כ�רשימה). הוא גם מקבל קלטים נוספים מעבר לאלה המפורטים כאן.
