# וידאו latent ריק של Hunyuan Video 1.0

הצומת `EmptyHunyuanLatentVideo` דומה לצומת `EmptyLatentImage`. ניתן להתייחס אליו כאל קנבס ריק ליצירת וידאו, כאשר רוחב, גובה ואורך מגדירים את מאפייני הקנבס, וגודל האצווה קובע את מספר הקנבסים ליצירה. צומת זה יוצר קנבסים ריקים המוכנים למשימות יצירת וידאו עוקבות.

## קלטים

| פרמטר | תיאור | סוג Comfy |
| --- | --- | --- |
| `width` | רוחב הווידאו, ברירת מחדל 848, מינימום 16, מקסימום `nodes.MAX_RESOLUTION`, גודל צעד 16. | `INT` |
| `height` | גובה הווידאו, ברירת מחדל 480, מינימום 16, מקסימום `nodes.MAX_RESOLUTION`, גודל צעד 16. | `INT` |
| `length` | אורך הווידאו, ברירת מחדל 25, מינימום 1, מקסימום `nodes.MAX_RESOLUTION`, גודל צעד 4. | `INT` |
| `batch_size` | גודל אצווה, ברירת מחדל 1, מינימום 1, מקסימום 4096. | `INT` |

## פלטים

| פרמטר | תיאור | סוג Comfy |
| --- | --- | --- |
| `samples` | דגימות וידאו סמויות (latent) שנוצרו, המכילות טנסורי אפס, המוכנות למשימות עיבוד ויצירה. | `LATENT` |
