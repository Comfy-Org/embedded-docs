# 画像データセットをフォルダに保存

このノードは、画像のリストをPNGファイルとしてComfyUIの出力ディレクトリ内の指定フォルダに保存します。このノードは非推奨です。既存のSave Imageノードと重複しており、そちらに置き換えられています。Save Imageノードでは、ファイル名プレフィックスで保存先フォルダを指定できます。このノードは、受信した各画像をカスタマイズ可能なファイル名プレフィックスを使用してディスクに書き込み、既存ファイルを上書きするか、上書きを避けるためにインクリメントされたファイル名を生成するかを選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | 保存する画像のリスト。 | IMAGE | はい | N/A |
| `folder_name` | 画像の保存先フォルダ名（出力ディレクトリ内）。デフォルト値は "dataset" です。 | STRING | いいえ | N/A |
| `filename_prefix` | 保存される画像ファイル名のプレフィックス。デフォルト値は "image" です。 | STRING | いいえ | N/A |
| `mode` | 既存ファイルを上書きするか、上書きを避けるためにファイル名をインクリメントするかを指定します。デフォルト値は "overwrite" です。 | COMBO | いいえ | "overwrite"<br>"increment" |

**注:** `images` 入力はリストであり、複数の画像を一度に受け取って処理できます。すべての入力はリストとして受信されます。`folder_name`、`filename_prefix`、`mode` については、接続されたリストの最初の値のみが使用されます。`folder_name` はComfyUIの出力ディレクトリ内のフォルダに解決される必要があります。これを外れるフォルダ名（例えば、".."、絶対パス、ドライブ文字を使用するもの）はエラーで拒否されます。画像は常にPNG形式で保存されます。`filename_prefix` パラメータは高度なオプションです。

## 出力

このノードにはデータ出力はありません。ファイルシステムへの保存操作を実行する出力ノードです。
