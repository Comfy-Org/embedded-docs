# ذخیره مجموعه تصاویر در پوشه

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | فهرست تصاویر برای ذخیره‌سازی. | IMAGE | بله | N/A |
| `folder_name` | نام پوشه‌ای که تصاویر در آن ذخیره می‌شوند (داخل دایرکتوری خروجی). مقدار پیش‌فرض «dataset» است. | STRING | خیر | N/A |
| `filename_prefix` | پیشوند برای نام فایل‌های تصویر ذخیره‌شده. مقدار پیش‌فرض «image» است. | STRING | خیر | N/A |
| `mode` | تعیین می‌کند که آیا فایل‌های موجود بازنویسی شوند یا نام فایل‌ها به‌صورت افزایشی تغییر کند تا از بازنویسی جلوگیری شود. مقدار پیش‌فرض «overwrite» است. | COMBO | خیر | "overwrite"<br>"increment" |

**نکته:** ورودی `images` یک فهرست است، به این معنی که می‌تواند چندین تصویر را به‌طور هم‌زمان دریافت و پردازش کند. همه ورودی‌ها به‌صورت فهرست دریافت می‌شوند؛ برای `folder_name`، `filename_prefix` و `mode` فقط اولین مقدار از فهرست متصل استفاده می‌شود. `folder_name` باید به پوشه‌ای درون دایرکتوری خروجی ComfyUI اشاره کند — نام پوشه‌هایی که از آن خارج می‌شوند (مثلاً با استفاده از «..»، مسیر مطلق یا حرف درایو) با خطا رد می‌شوند. تصاویر همیشه در قالب PNG ذخیره می‌شوند. پارامتر `filename_prefix` یک گزینه پیشرفته است.
