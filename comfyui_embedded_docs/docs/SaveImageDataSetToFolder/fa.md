# ذخیره مجموعه تصاویر در پوشه

این نود لیستی از تصاویر را در پوشه‌ای مشخص در دایرکتوری خروجی ComfyUI ذخیره می‌کند. هر تصویر را با استفاده از پیشوند نام فایل قابل‌تنظیم، به‌صورت فایل PNG روی دیسک می‌نویسد. این نود منسوخ شده و توسط نودهای Save Image موجود جایگزین شده است، جایی که پوشه مقصد را می‌توان در پیشوند نام فایل مشخص کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | فهرست تصاویر برای ذخیره‌سازی. | IMAGE | بله | N/A |
| `نام پوشه` | نام پوشه‌ای که تصاویر در آن ذخیره می‌شوند (داخل دایرکتوری خروجی). پیش‌فرض: "dataset". | STRING | خیر | N/A |
| `پیشوند نام فایل تصویر` | پیشوند برای نام فایل‌های تصویر ذخیره‌شده. پیش‌فرض: "image". پارامتر پیشرفته. | STRING | خیر | N/A |
| `حالت` | مشخص می‌کند که فایل‌های موجود بازنویسی شوند یا نام فایل‌ها افزایش یابد تا از بازنویسی جلوگیری شود. پیش‌فرض: "overwrite". | COMBO | خیر | "overwrite"<br>"increment" |

**نکات:**

- ورودی `images` یک لیست است، بنابراین می‌توان چندین تصویر را در یک اجرا ذخیره کرد.
- پارامترهای `folder_name`، `filename_prefix` و `mode` مقادیر اسکالر هستند؛ اگر لیستی متصل شود، فقط اولین مقدار از آن لیست استفاده می‌شود.
- `folder_name` باید به مکانی در داخل دایرکتوری خروجی ComfyUI اشاره کند. مقادیری که از دایرکتوری خروجی خارج می‌شوند (برای مثال، مسیرهای حاوی `..` یا مسیرهای مطلق) با خطا رد می‌شوند.
- در حالت "overwrite"، فایل‌ها به صورت `{prefix}_00000.png`، `{prefix}_00001.png` و غیره ذخیره می‌شوند و هر فایل موجود را جایگزین می‌کنند. در حالت "increment"، یک شمارنده در نام فایل درج می‌شود تا فایل‌های موجود بازنویسی نشوند.
