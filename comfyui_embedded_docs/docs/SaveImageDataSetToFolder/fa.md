# ذخیره مجموعه تصاویر در پوشه

این گره فهرستی از تصاویر را در پوشه‌ای مشخص داخل دایرکتوری خروجی ComfyUI ذخیره می‌کند. هر تصویر را به‌صورت فایل PNG روی دیسک می‌نویسد و از یک پیشوند نام فایل قابل تنظیم استفاده می‌کند. این گره منسوخ شده است و گره‌های Save Image موجود جایگزین آن شده‌اند؛ در آن‌ها می‌توان پوشه هدف را در پیشوند نام فایل مشخص کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | فهرست تصاویری که باید ذخیره شوند. | IMAGE | بله | N/A |
| `folder_name` | نام پوشه‌ای برای ذخیره تصاویر در آن (داخل دایرکتوری خروجی). پیش‌فرض: "dataset". | STRING | خیر | N/A |
| `filename_prefix` | پیشوند نام فایل‌های تصویر ذخیره‌شده. پیش‌فرض: "image". پارامتر پیشرفته. | STRING | خیر | N/A |
| `mode` | تعیین می‌کند فایل‌های موجود بازنویسی شوند یا نام فایل‌ها برای جلوگیری از بازنویسی افزایش یابند. پیش‌فرض: "overwrite". | COMBO | خیر | "overwrite"<br>"increment" |

**نکته‌ها:**

- ورودی `images` یک فهرست است، بنابراین می‌توان چندین تصویر را در یک اجرا ذخیره کرد.
- پارامترهای `folder_name`، `filename_prefix` و `mode` مقادیر اسکالر هستند؛ اگر فهرستی متصل باشد، فقط اولین مقدار آن فهرست استفاده می‌شود.
- `folder_name` باید به مکانی داخل دایرکتوری خروجی ComfyUI منتهی شود. مقادیری که از دایرکتوری خروجی خارج می‌شوند (برای مثال، مسیرهای حاوی `..` یا مسیرهای مطلق، حروف درایو، یا مسیرهایی که از طریق پیوند نمادین خارج می‌شوند) با خطا رد می‌شوند.
- در حالت "overwrite"، فایل‌ها با نام‌های `{prefix}_00000.png`، `{prefix}_00001.png` و به همین ترتیب ذخیره می‌شوند و هر فایل موجودی را جایگزین می‌کنند. در حالت "increment"، یک شمارنده در نام فایل درج می‌شود تا فایل‌های موجود بازنویسی نشوند.
- فقط خروجی PNG پشتیبانی می‌شود.
