# حفظ مجموعة بيانات الصور في مجلد

تقوم هذه العقدة بحفظ قائمة من الصور في مجلد محدد داخل دليل الإخراج الخاص بـ ComfyUI. وتكتب كل صورة إلى القرص كملف PNG باستخدام بادئة اسم ملف قابلة للتهيئة. هذه العقدة مهملة وتم استبدالها بعُقد Save Image الموجودة، حيث يمكن تحديد المجلد الهدف في بادئة اسم الملف.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | قائمة الصور المراد حفظها. | IMAGE | نعم | N/A |
| `folder_name` | اسم المجلد لحفظ الصور فيه (داخل دليل الإخراج). الافتراضي: "dataset". | STRING | لا | N/A |
| `filename_prefix` | بادئة أسماء ملفات الصور المحفوظة. الافتراضي: "image". معامل متقدم. | STRING | لا | N/A |
| `الوضع` | ما إذا كان سيتم استبدال الملفات الموجودة أو زيادة أسماء الملفات لتجنب الاستبدال. الافتراضي: "overwrite". | COMBO | لا | "overwrite"<br>"increment" |

**ملاحظات:**

- مدخل `images` عبارة عن قائمة، لذا يمكن حفظ صور متعددة في تشغيل واحد.
- المعاملات `folder_name` و`filename_prefix` و`mode` هي قيم قياسية؛ إذا تم توصيل قائمة، فسيتم استخدام القيمة الأولى فقط من تلك القائمة.
- يجب أن يُحلّ `folder_name` إلى موقع داخل دليل الإخراج الخاص بـ ComfyUI. يتم رفض القيم التي تخرج عن دليل الإخراج (على سبيل المثال، المسارات التي تحتوي على `..` أو المسارات المطلقة، أو أحرف محركات الأقراص، أو الهروب عبر الروابط الرمزية) مع خطأ.
- في وضع "overwrite"، يتم حفظ الملفات باسم `{prefix}_00000.png`، و`{prefix}_00001.png`، وهكذا، مع استبدال أي ملفات موجودة. في وضع "increment"، يتم إدراج عدّاد في اسم الملف حتى لا يتم استبدال الملفات الموجودة.
- يتم دعم إخراج PNG فقط.

## المخرجات

لا تحتوي هذه العقدة على أي مخرجات. إنها عقدة إخراج تنفذ عملية حفظ إلى نظام الملفات.
