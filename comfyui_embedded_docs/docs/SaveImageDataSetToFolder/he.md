# SaveImageDataSetToFolder

צומת זה שומר רשימה של תמונות לתיקייה שצוינה בתוך ספריית הפלט של ComfyUI. הוא כותב כל תמונה לדיסק כקובץ PNG תוך שימוש בקידומת שם קובץ הניתנת להגדרה. צומת זה מיושן והוחלף על ידי צומתי Save Image קיימים, שבהם ניתן לציין את תיקיית היעד בקידומת שם הקובץ.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | רשימת תמונות לשמירה. | IMAGE | כן | N/A |
| `folder_name` | שם התיקייה שאליה לשמור תמונות (בתוך ספריית הפלט). ברירת מחדל: "dataset". | STRING | לא | N/A |
| `filename_prefix` | קידומת לשמות קבצי התמונות הנשמרות. ברירת מחדל: "image". פרמטר מתקדם. | STRING | לא | N/A |
| `mode` | האם לדרוס קבצים קיימים או להעלות את מונה שמות הקבצים כדי להימנע מדריסה. ברירת מחדל: "overwrite". | COMBO | לא | "overwrite"<br>"increment" |

**הערות:**

- קלט `images` הוא רשימה, כך שניתן לשמור מספר תמונות בהרצה אחת.
- הפרמטרים `folder_name`, `filename_prefix` ו-`mode` הם ערכים סקלריים; אם מחובר אליהם רשימה, נעשה שימוש רק בערך הראשון מאותה רשימה.
- `folder_name` חייב להצביע על מיקום בתוך ספריית הפלט של ComfyUI. ערכים שחורגים מספריית הפלט (לדוגמה, נתיבים המכילים `..` או נתיבים מוחלטים, אותיות כונן, או בריחות דרך קישורים סימבוליים) נדחים עם שגיאה.
- במצב "overwrite", הקבצים נשמרים בשמות `{prefix}_00000.png`, `{prefix}_00001.png`, וכן הלאה, תוך החלפת קבצים קיימים. במצב "increment", מוכנס מונה לשם הקובץ כך שקבצים קיימים אינם נדרסים.
- נתמך פלט PNG בלבד.
