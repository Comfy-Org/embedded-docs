# Сохранить набор изображений в папку

Этот узел сохраняет список изображений в указанную папку внутри выходного каталога ComfyUI. Он записывает каждое изображение на диск в виде PNG-файла с настраиваемым префиксом имени файла. Этот узел устарел и заменён существующими узлами Save Image, в которых целевую папку можно указать в префиксе имени файла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `images` | Список изображений для сохранения. | IMAGE | Да | N/A |
| `folder_name` | Имя папки для сохранения изображений (внутри выходного каталога). По умолчанию: "dataset". | STRING | Нет | N/A |
| `filename_prefix` | Префикс для имён сохраняемых файлов изображений. По умолчанию: "image". Расширенный параметр. | STRING | Нет | N/A |
| `режим` | Определяет, следует ли перезаписывать существующие файлы или увеличивать имена файлов во избежание перезаписи. По умолчанию: "overwrite". | COMBO | Нет | "overwrite"<br>"increment" |

**Примечания:**

- Вход `images` представляет собой список, поэтому за один запуск можно сохранить несколько изображений.
- Параметры `folder_name`, `filename_prefix` и `mode` являются скалярными значениями; если подключён список, используется только первое значение из этого списка.
- Значение `folder_name` должно указывать на расположение внутри выходного каталога ComfyUI. Значения, выходящие за пределы выходного каталога (например, пути, содержащие `..`, или абсолютные пути), отклоняются с ошибкой.
- В режиме "overwrite" файлы сохраняются как `{prefix}_00000.png`, `{prefix}_00001.png` и т. д., заменяя существующие файлы. В режиме "increment" в имя файла вставляется счётчик, поэтому существующие файлы не перезаписываются.

## Выходы

Этот узел не имеет выходов. Он является выходным узлом, который выполняет операцию сохранения в файловую систему.
