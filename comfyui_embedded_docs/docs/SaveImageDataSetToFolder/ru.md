# Сохранить набор изображений в папку

Этот узел сохраняет список изображений в формате PNG в указанную папку внутри выходного каталога ComfyUI. Он устарел: он избыточен и заменён существующими узлами Save Image, где целевую папку можно указать в префиксе имени файла. Узел записывает каждое полученное изображение на диск, используя настраиваемый префикс имени файла, и может либо перезаписывать существующие файлы, либо создавать инкрементные имена файлов, чтобы избежать перезаписи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Список изображений для сохранения. | IMAGE | Да | N/A |
| `folder_name` | Имя папки для сохранения изображений (внутри выходного каталога). Значение по умолчанию — "dataset". | STRING | Нет | N/A |
| `filename_prefix` | Префикс для имён сохраняемых файлов изображений. Значение по умолчанию — "image". | STRING | Нет | N/A |
| `mode` | Определяет, перезаписывать ли существующие файлы или создавать инкрементные имена для избежания перезаписи. Значение по умолчанию — "overwrite". | COMBO | Нет | "overwrite"<br>"increment" |

**Примечание:** Вход `images` является списком, то есть он может принимать и обрабатывать несколько изображений одновременно. Все входы принимаются в виде списков; для `folder_name`, `filename_prefix` и `mode` используется только первое значение из подключённого списка. `folder_name` должен указывать на папку внутри выходного каталога ComfyUI — имена папок, выходящие за его пределы (например, с использованием "..", абсолютного пути или буквы диска), отклоняются с ошибкой. Изображения всегда сохраняются в формате PNG. Параметр `filename_prefix` является расширенной опцией.

## Выходы

Этот узел не имеет выходных данных. Это выходной узел, который выполняет операцию сохранения в файловую систему.
