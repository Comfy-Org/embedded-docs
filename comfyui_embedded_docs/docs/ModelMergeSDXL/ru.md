# Слияние моделей SDXL

Узел ModelMergeSDXL позволяет смешивать две SDXL-модели, регулируя влияние каждой из них на различные части архитектуры. Вы можете управлять тем, насколько каждая модель вносит вклад в эмбеддинги времени, эмбеддинги меток и различные блоки внутри структуры модели. В результате создаётся гибридная модель, объединяющая характеристики обеих входных моделей.

## Входы

| `model2` | Вторая SDXL-модель для смешивания | MODEL | Да | - |
| `time_embed.` | Вес смешивания для слоёв эмбеддингов времени (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |
