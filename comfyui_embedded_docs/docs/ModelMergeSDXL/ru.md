# Слияние моделей SDXL

Узел ModelMergeSDXL позволяет объединять две модели SDXL, регулируя влияние каждой модели на различные части архитектуры. Вы можете управлять тем, насколько каждая модель вносит вклад в эмбеддинги времени, эмбеддинги меток и различные блоки структуры модели. Это создаёт гибридную модель, сочетающую характеристики обеих входных моделей.
