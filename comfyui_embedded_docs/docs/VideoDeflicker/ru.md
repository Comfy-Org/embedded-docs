# Video Deflicker

Удаляет временное мерцание с обработанного видео, чтобы каждый кадр сохранял собственные детали, следуя движению соседних кадров. Предназначен для видеоматериала, который пульсирует после апскейла или покадровой обработки: подключите модель оптического потока и мерцающие кадры, а также при необходимости стабильную копию источника в качестве опорных кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `optical_flow` | Модель оптического потока из узла Load Optical Flow Model (torchvision RAFT-large). | OPTICAL_FLOW | Да | - |
| `изображения` | Мерцающие кадры для стабилизации, например видео, которое было увеличено или обработано покадрово. | IMAGE | Да | - |
| `направляющее видео` | Стабильные исходные кадры, движению которых нужно следовать, в любом разрешении. По умолчанию используется `images`, что удаляет меньше мерцания. Различия между соседними кадрами гида после компенсации движения тоже влияют на вес сглаживания: если гид меняется так, что поток этого не объясняет, сглаживание слабеет даже при верной оценке движения. | IMAGE | Нет | - |
| `сила` | Насколько сильно каждый кадр следует за соседними (по умолчанию: 1.0). Более высокие значения удаляют больше мерцания и сильнее смягчают мелкие детали; 0 возвращает кадры без изменений. | FLOAT | Да | от 0.0 до 100.0 (шаг: 0.1) |
| `направление` | Направление прохода. `bidirectional` усредняет прямой и обратный проходы, что позволяет избежать отставания от движения; `forward` выполняет один проход. (по умолчанию: `bidirectional`) | COMBO | Да | `"bidirectional"`<br>`"forward"` |
| `порог` | Изменения больше этого значения между кадром и его соседом с компенсацией движения считаются реальными и сглаживаются меньше (по умолчанию: 0.1). 0 сглаживает все изменения одинаково. | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

**Примечания:**

- Оптический поток считается по уменьшенной копии гида, поэтому совпадать по размеру с `images` не нужно; пиксели гида не попадают в результат.
- Кадры после более короткого из `images` и `guide` не обрабатываются. Если `guide` короче, оставшиеся кадры возвращаются без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Кадры без мерцания, того же размера и с тем же количеством кадров, что и `images`. | IMAGE |
