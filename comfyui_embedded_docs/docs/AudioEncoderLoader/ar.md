# محمل مشفر الصوت

## نظرة عامة

تقوم عقدة `AudioEncoderLoader` بتحميل نموذج مُرمِّز صوتي من ملف مخزَّن في مجلد `audio_encoders`. تأخذ اسم ملف نموذج مُرمِّز الصوت كمدخل، وتُعيد النموذج المُحمَّل، الذي يمكن بعد ذلك استخدامه في مهام معالجة الصوت ضمن سير العمل. إذا لم يحتوي الملف المحدد على نموذج مُرمِّز صوتي صالح، فإن العقدة تُصدر خطأً.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `اسم مشفر الصوت` | يحدد ملف نموذج مُرمِّز الصوت الذي سيتم تحميله من مجلد مُرمِّزات الصوت | COMBO | نعم | قائمة ملفات مُرمِّز الصوت المتاحة في مجلد `audio_encoders` |

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `audio_encoder` | نموذج مُرمِّز الصوت المُحمَّل، جاهز للاستخدام في سير عمل معالجة الصوت | AUDIO_ENCODER |
