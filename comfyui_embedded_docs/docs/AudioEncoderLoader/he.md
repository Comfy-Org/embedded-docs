# AudioEncoderLoader

## סקירה כללית

הצומת AudioEncoderLoader טוען מודל מקודד אודיו מקובץ המאוחסן בתיקיית `audio_encoders` שלך. הוא מקבל כשקלט את שם הקובץ של מודל מקודד אודיו ומחזיר את המודל שנטען, שאפשר להשתמש בו לאחר מכן במשימות עיבוד אודיו בזרימת העבודה שלך. אם הקובץ הנבחר אינו מכיל מודל מקודד אודיו חוקי, הצומת מעלה שגיאה.
