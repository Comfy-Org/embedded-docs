# Аудиоэнкодер - Загрузчик

Узел `AudioEncoderLoader` загружает модель аудиоэнкодера из файла в вашей папке audio encoders. Он принимает имя файла модели аудиоэнкодера в качестве входных данных и возвращает загруженную модель, которую затем можно использовать для задач обработки аудио в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio_encoder_name` | Выбирает, какой файл модели аудиоэнкодера загрузить | COMBO | Да | Список доступных файлов аудиоэнкодеров в папке audio_encoders |

Примечание: выбранный файл должен содержать допустимую модель аудиоэнкодера. Если файл недействителен и не содержит допустимой модели, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder` | Загруженная модель аудиоэнкодера, готовая к использованию в рабочих процессах обработки аудио | AUDIO_ENCODER |
