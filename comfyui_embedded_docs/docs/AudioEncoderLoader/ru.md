# Аудиоэнкодер - Загрузчик

Узел AudioEncoderLoader загружает модель аудиоэнкодера из файла в вашей папке audio_encoders. Он принимает имя файла модели аудиоэнкодера на вход и возвращает загруженную модель, которую можно использовать для задач обработки аудио в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `имя_аудио_энкодера` | Выбирает, какой файл модели аудиоэнкодера загрузить | COMBO | Да | Список доступных файлов аудиоэнкодеров в папке audio_encoders |

Примечание: Если выбранный файл не содержит допустимую модель аудиоэнкодера, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder` | Загруженная модель аудиоэнкодера, готовая к использованию в рабочих процессах обработки аудио | AUDIO_ENCODER |
