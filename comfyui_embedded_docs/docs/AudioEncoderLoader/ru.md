# Аудиоэнкодер - Загрузчик

## Обзор

Узел AudioEncoderLoader загружает модель аудиоэнкодера из файла, хранящегося в папке `audio_encoders`. Он принимает имя файла модели аудиоэнкодера в качестве входных данных и возвращает загруженную модель, которую затем можно использовать для задач обработки аудио в рабочем процессе. Если выбранный файл не содержит допустимую модель аудиоэнкодера, узел выдаёт ошибку.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `имя_аудио_энкодера` | Выбирает, какой файл модели аудиоэнкодера загрузить из папки `audio_encoders` | COMBO | Да | Список доступных файлов аудиоэнкодеров в папке `audio_encoders` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder` | Загруженная модель аудиоэнкодера, готовая к использованию в рабочих процессах обработки аудио | AUDIO_ENCODER |
