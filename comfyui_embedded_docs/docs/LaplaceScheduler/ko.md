# 라플라스 스케줄러

LaplaceScheduler 노드는 확산 샘플링에 사용하기 위해 라플라스 분포를 따르는 시그마 값의 시퀀스를 생성합니다. 라플라스 분포 매개변수를 사용하여 진행을 제어하면서 최대값에서 최소값으로 점진적으로 감소하는 노이즈 레벨 스케줄을 만듭니다. 이 스케줄러는 확산 모델의 노이즈 스케줄을 정의하기 위해 사용자 정의 샘플링 워크플로우에서 일반적으로 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `steps` | 스케줄의 샘플링 단계 수 (기본값: 20) | INT | 예 | 1 to 10000 |
| `sigma_max` | 스케줄 시작 시 최대 시그마 값 (기본값: 14.614642) | FLOAT | 예 | 0.0 to 5000.0 |
| `sigma_min` | 스케줄 종료 시 최소 시그마 값 (기본값: 0.0291675) | FLOAT | 예 | 0.0 to 5000.0 |
| `mu` | 라플라스 분포의 평균 매개변수 (기본값: 0.0) | FLOAT | 예 | -10.0 to 10.0 |
| `beta` | 라플라스 분포의 척도 매개변수 (기본값: 0.5) | FLOAT | 예 | 0.0 to 10.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `SIGMAS` | 라플라스 분포 스케줄을 따르는 시그마 값의 시퀀스 | SIGMAS |
