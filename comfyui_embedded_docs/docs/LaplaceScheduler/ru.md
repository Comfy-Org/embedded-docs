# Scheduler Лапласа

Узел LaplaceScheduler генерирует последовательность значений sigma в соответствии с распределением Лапласа для использования в диффузионном сэмплировании. Он создаёт график уровней шума, которые постепенно уменьшаются от максимального до минимального значения, используя параметры распределения Лапласа для управления этим процессом. Данный планировщик обычно применяется в пользовательских рабочих процессах сэмплирования для определения графика шума для диффузионных моделей.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `шаги` | Количество шагов сэмплирования в графике (по умолчанию: 20) | INT | Да | 1 до 10000 |
| `максимальное_сигма` | Максимальное значение sigma в начале графика (по умолчанию: 14.614642) | FLOAT | Да | 0.0 до 5000.0 |
| `минимальное_сигма` | Минимальное значение sigma в конце графика (по умолчанию: 0.0291675) | FLOAT | Да | 0.0 до 5000.0 |
| `мю` | Параметр среднего для распределения Лапласа (по умолчанию: 0.0) | FLOAT | Да | -10.0 до 10.0 |
| `бета` | Параметр масштаба для распределения Лапласа (по умолчанию: 0.5) | FLOAT | Да | 0.0 до 10.0 |

Примечание: `sigma_max`, `sigma_min`, `mu` и `beta` являются дополнительными параметрами.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SIGMAS` | Последовательность значений sigma, сформированная по графику распределения Лапласа | SIGMAS |
