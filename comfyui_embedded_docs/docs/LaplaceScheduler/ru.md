# Scheduler Лапласа

Узел LaplaceScheduler генерирует последовательность значений сигмы в соответствии с распределением Лапласа для использования в диффузионном сэмплировании. Он создаёт расписание уровней шума, которые постепенно уменьшаются от максимального до минимального значения, используя параметры распределения Лапласа для управления этим процессом. Этот планировщик часто используется в пользовательских рабочих процессах сэмплирования для задания расписания шума для диффузионных моделей.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `steps` | Количество шагов сэмплирования в расписании (по умолчанию: 20) | INT | Да | 1 to 10000 |
| `sigma_max` | Максимальное значение сигмы в начале расписания (по умолчанию: 14.614642) | FLOAT | Да | 0.0 to 5000.0 |
| `sigma_min` | Минимальное значение сигмы в конце расписания (по умолчанию: 0.0291675) | FLOAT | Да | 0.0 to 5000.0 |
| `mu` | Параметр среднего для распределения Лапласа (по умолчанию: 0.0) | FLOAT | Да | -10.0 to 10.0 |
| `beta` | Параметр масштаба для распределения Лапласа (по умолчанию: 0.5) | FLOAT | Да | 0.0 to 10.0 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SIGMAS` | Последовательность значений сигмы, следующая расписанию распределения Лапласа | SIGMAS |
