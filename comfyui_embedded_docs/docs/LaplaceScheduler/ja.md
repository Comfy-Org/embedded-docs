# ラプラススケジューラー

LaplaceScheduler ノードは、拡散サンプリングで使用するラプラス分布に従うシグマ値のシーケンスを生成します。このノードは、ラプラス分布のパラメータを使用して進行を制御しながら、最大値から最小値へと徐々に減少するノイズレベルのスケジュールを作成します。このスケジューラは、拡散モデルのノイズスケジュールを定義するために、カスタムサンプリングワークフローで一般的に使用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `steps` | スケジュール内のサンプリングステップ数です（デフォルト: 20） | INT | はい | 1 ～ 10000 |
| `sigma_max` | スケジュール開始時の最大シグマ値です（デフォルト: 14.614642） | FLOAT | はい | 0.0 ～ 5000.0 |
| `sigma_min` | スケジュール終了時の最小シグマ値です（デフォルト: 0.0291675） | FLOAT | はい | 0.0 ～ 5000.0 |
| `mu` | ラプラス分布の平均パラメータです（デフォルト: 0.0） | FLOAT | はい | -10.0 ～ 10.0 |
| `beta` | ラプラス分布のスケールパラメータです（デフォルト: 0.5） | FLOAT | はい | 0.0 ～ 10.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `SIGMAS` | ラプラス分布スケジュールに従うシグマ値のシーケンスです | SIGMAS |
