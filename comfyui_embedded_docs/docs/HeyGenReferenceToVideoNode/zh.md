# HeyGen Video 1.0 参考转视频

使用 HeyGen Video 1.0 根据文本提示生成带有同步对话和声音的视频，并可选地由已连接的参考素材进行引导。人物、产品或地点的图像、可复用的视频以及提供声音的音频片段都可以用作参考。在提示词中提及每个参考时，请使用 @Image1、@Video1 或 @Audio1，并按输入连接顺序按类型编号：这些标签会被改写为 HeyGen 期望的标签，若标签指向未连接的参考，则会引发错误。在没有任何参考图像或视频的情况下，此节点以文本生成视频模式运行。

### 参数约束

- **参考上限：** 参考总数最多为 15 个：最多 9 张图像、3 个视频和 3 个音频片段。连接更多参考会引发错误。
- **音频需要图像或视频：** 当未连接参考图像且未连接参考视频时，参考音频将被拒绝。
- **参考图像规则：** 每个 `reference_images` 输入必须恰好包含一张图像（批量输入将被拒绝），且每张图像的宽高比必须在 1:4 到 4:1 之间。
- **提示词标签：** `@ImageN`、`@VideoN` 和 `@AudioN` 的匹配不区分大小写。编号不得超过该类型已连接参考的数量，且去除空白字符后提示词必须非空。
- **模式：** 存在至少一张参考图像或一个参考视频时，请求为参考生成视频运行；完全不存在时则为纯文本生成视频运行。
- **1080p 和 2k 分辨率：** `resolution` 为 `"1080p"` 或 `"2k"` 时要求 `aspect_ratio` 为 `"16:9"` 或 `"9:16"`；只有在未连接参考图像且未连接参考视频时，这些分辨率才接受 `"auto"`。
- **时长：** 超过 15 秒的时长仅在没有参考图像或视频时可用，除非 `auto_duration` 为 `"enabled"`。
- **种子：** 种子仅决定节点是否重新运行；使用相同种子无法复现结果。
