# HeyGen Video 1.0 参考转视频

使用 HeyGen Video 1.0 根据文本提示生成具有同步对话和声音的视频，可选地由连接的参考素材引导。人物、产品或地点的图像、可复用的视频以及提供声音的音频片段都可以用作参考。在提示词中将每个参考称为 @Image1、@Video1 或 @Audio1，按类型根据输入连接顺序编号：这些标签会被重写为 HeyGen 期望的标签，而指向未连接参考的标签会引发错误。没有任何参考图像或视频时，节点以文本到视频生成方式运行。

### 参数约束

- **参考限制：** 最多总共 15 个参考：最多 9 张图像、3 个视频和 3 个音频片段。连接更多会引发错误。
- **音频需要图像或视频：** 当没有连接参考图像和参考视频时，参考音频会被拒绝。
- **参考图像规则：** 每个 `reference_images` 输入必须恰好包含一张图像（一批图像会被拒绝），且每张图像的宽高比必须在 1:4 到 4:1 之间。
- **提示词标签：** `@ImageN`、`@VideoN` 和 `@AudioN` 不区分大小写匹配。编号不得超过该类型已连接参考的数量，且去除空白后提示词必须非空。
- **模式：** 当至少有一张参考图像或一个参考视频时，请求为参考到视频运行；没有时则为纯文本到视频运行。
- **1080p 和 2k 分辨率：** `resolution` 为 `"1080p"` 或 `"2k"` 时，需要 `aspect_ratio` 为 `"16:9"` 或 `"9:16"`；只有在没有连接参考图像和参考视频时，这些分辨率才接受 `"auto"`。
- **时长：** 有参考图像或视频时，生成的视频保持在 15 秒或更短。更长的视频不需要参考图像或视频；`auto_duration` 只会让 `duration` 被忽略（根据对话为 8 到 30 秒，有参考时为 8 到 15 秒），并不会提高该上限。
- **种子：** 种子仅决定节点是否重新运行；相同种子下结果不可复现。
