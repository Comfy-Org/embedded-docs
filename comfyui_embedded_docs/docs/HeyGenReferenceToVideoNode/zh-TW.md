# HeyGen Video 1.0 參考資料轉影片

使用 HeyGen Video 1.0 從文字提示生成具同步對話與聲音的影片，並可選擇由已連接的參考素材引導。人物、產品或地點的影像、可重複使用的影片，以及提供聲音的音訊片段，皆可作為參考。請在提示中將每個參考標記為 @Image1、@Video1 或 @Audio1，並依輸入連接順序按類型編號：這些標籤會改寫成 HeyGen 預期的標籤，而指向未連接參考的標籤會引發錯誤。若沒有任何參考影像或影片，此節點會執行文字轉影片生成。

### 參數限制

- **參考數量限制：** 總共最多 15 個參考：最多 9 張影像、3 部影片與 3 個音訊片段。連接更多會引發錯誤。
- **音訊需要影像或影片：** 當未連接參考影像且未連接參考影片時，會拒絕參考音訊。
- **參考影像規則：** 每個 `reference_images` 輸入必須恰好包含一張影像（批次會被拒絕），且每張影像的長寬比必須介於 1:4 與 4:1 之間。
- **提示標籤：** `@ImageN`、`@VideoN` 與 `@AudioN` 會以不區分大小寫的方式比對。編號不得超過該類型已連接參考的數量，且提示在去除空白後必須非空。
- **模式：** 至少有一張參考影像或一部參考影片時，請求會是參考轉影片執行；若完全沒有，則是一般的文字轉影片執行。
- **1080p 與 2k 解析度：** `resolution` 為 `"1080p"` 或 `"2k"` 時，需要 `aspect_ratio` 為 `"16:9"` 或 `"9:16"`；只有在未連接參考影像且未連接參考影片時，這些解析度才接受 `"auto"`。
- **長度：** 超過 15 秒僅在沒有參考影像或影片時可用，除非 `auto_duration` 為 `"enabled"`。
- **種子：** 種子只決定節點是否重新執行；相同種子無法重現結果。
