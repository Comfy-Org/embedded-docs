# HeyGen Video 1.0 Reference to Video

使用 HeyGen Video 1.0，從文字提示生成具有同步對話與聲音的影片，並可選擇由已連接的參考素材引導。人物、產品或地點的圖像、可重複使用的影片，以及提供聲音的音訊片段，都可以用作參考。在提示中以 @Image1、@Video1 或 @Audio1 提及每個參考，並依輸入連接順序按類型編號：這些標籤會被改寫成 HeyGen 預期的標籤，而指向未連接參考的標籤會引發錯誤。在沒有任何參考圖像或影片時，此節點會以文字轉影片生成模式執行。

### 參數限制

- **參考限制：** 在 `reference_images`、`reference_videos` 和 `reference_audios` 中，總共最多可有 12 個參考；連接更多會引發錯誤。
- **音訊需要圖像或影片：** 當未連接任何參考圖像且未連接任何參考影片時，參考音訊會被拒絕。
- **參考圖像規則：** 每個 `reference_images` 輸入必須恰好包含一張圖像（批次會被拒絕），且每張圖像的長寬比必須介於 1:4 與 4:1 之間。
- **提示標籤：** `@ImageN`、`@VideoN` 和 `@AudioN` 的比對不區分大小寫。編號不得超過該類型已連接參考的數量，且提示在修剪空白後必須為非空。
- **模式：** 在至少有一個參考圖像或影片時，請求會是參考轉影片生成；在沒有任何參考時，則是一般的文字轉影片生成。
- **`seed`：** 種子只決定此節點是否重新執行；使用相同種子無法重現結果。
