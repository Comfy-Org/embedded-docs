# HeyGen Video 1.0 参照から動画

HeyGen Video 1.0 を使用し、テキストプロンプトからセリフと音声が同期した動画を生成します。接続した参照素材によってガイドすることもできます。人物・製品・場所の画像、再利用する動画、声を提供する音声クリップを参照として利用できます。プロンプト内では各参照を @Image1、@Video1、@Audio1 のように記述します。番号は種類ごとに、入力が接続された順に振られます。これらのタグは HeyGen が期待するラベルに書き換えられ、接続されていない参照を指すタグはエラーになります。参照画像も参照動画もない場合、このノードはテキストから動画への生成として動作します。

### パラメータの制約

- **参照数の上限：** 参照は合計で最大 15 個です。画像は最大 9 枚、動画は最大 3 本、音声クリップは最大 3 個です。それ以上接続するとエラーになります。
- **音声には画像または動画が必要：** 参照画像も参照動画も接続されていない場合、参照音声は拒否されます。
- **参照画像のルール：** 各 `reference_images` 入力には必ず 1 枚の画像のみを含める必要があり（バッチは拒否されます）、各画像のアスペクト比は 1:4～4:1 の範囲である必要があります。
- **プロンプトのタグ：** `@ImageN`、`@VideoN`、`@AudioN` は大文字と小文字を区別せずに照合されます。番号は、その種類で接続されている参照の数を超えてはならず、プロンプトは空白を除去した後に空でない必要があります。
- **モード：** 少なくとも 1 つの参照画像または参照動画がある場合、リクエストは参照から動画への生成（reference-to-video）になります。ない場合は通常のテキストから動画への生成です。
- **1080p と 2k の解像度：** `resolution` が `"1080p"` または `"2k"` の場合、`aspect_ratio` は `"16:9"` または `"9:16"` である必要があります。`"auto"` は、参照画像も参照動画も接続されていない場合に限り、これらの解像度で受け付けられます。
- **長さ：** 参照画像または参照動画がある場合、生成される動画は 15 秒以下になります。より長い動画には参照画像も参照動画も必要ありません。`auto_duration` は `duration` を無視させるだけであり（セリフから 8～30 秒、参照がある場合は 8～15 秒）、この上限を引き上げるものではありません。
- **シード：** シードはノードを再実行するかどうかを決めるだけであり、同じシードでも結果は再現されません。
