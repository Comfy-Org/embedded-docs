# HeyGen Video 1.0 参照から動画

HeyGen Video 1.0 を使用し、テキストプロンプトから同期した対話と音声を備えた動画を生成します。接続された参照素材によって任意にガイドできます。人物、製品、場所の画像、再利用する動画、声を提供する音声クリップをすべて参照として使用できます。プロンプト内で各参照を @Image1、@Video1、@Audio1 として言及してください。番号は、入力が接続された順に種類ごとに付けます。これらのタグは HeyGen が期待するラベルに書き換えられ、接続されていない参照を指すタグはエラーになります。参照画像も参照動画もない場合、ノードはテキストから動画への生成として実行されます。

### パラメータの制約

- **参照数の上限:** 合計で最大 15 個の参照です。画像は最大 9 枚、動画は最大 3 本、音声クリップは最大 3 個です。それ以上接続するとエラーになります。
- **音声には画像または動画が必要:** 参照画像も参照動画も接続されていない場合、参照音声は拒否されます。
- **参照画像のルール:** 各 `reference_images` 入力にはちょうど 1 枚の画像を含める必要があり（バッチは拒否されます）、各画像のアスペクト比は 1:4～4:1 の範囲である必要があります。
- **プロンプトタグ:** `@ImageN`、`@VideoN`、`@AudioN` は大文字と小文字を区別せずに照合されます。番号は、その種類で接続されている参照の数を超えてはならず、プロンプトは空白を除去した後に空でない必要があります。
- **モード:** 少なくとも 1 つの参照画像または参照動画がある場合、リクエストは参照から動画への実行です。ない場合は、通常のテキストから動画への実行です。
- **1080p と 2k の解像度:** `resolution` が `"1080p"` または `"2k"` の場合、`aspect_ratio` は `"16:9"` または `"9:16"` である必要があります。`"auto"` は、参照画像も参照動画も接続されていない場合に限り、これらの解像度で受け入れられます。
- **長さ:** 15 秒を超える長さは、`auto_duration` が `"enabled"` でない限り、参照画像も参照動画もない場合にのみ利用できます。
- **シード:** シードはノードを再実行するかどうかのみを決定します。同じシードでも結果は再現できません。
