# HeyGen Video 1.0 참조-비디오

HeyGen Video 1.0을 사용하여 텍스트 프롬프트로부터 동기화된 대사와 사운드가 포함된 비디오를 생성하며, 선택적으로 연결된 참조 자료의 안내를 받을 수 있습니다. 사람, 제품 또는 장소 이미지, 재사용할 동영상, 목소리를 제공하는 오디오 클립을 모두 참조로 사용할 수 있습니다. 프롬프트에서 각 참조를 @Image1, @Video1 또는 @Audio1로 언급하며, 입력이 연결된 순서에 따라 유형별로 번호가 매겨집니다. 이 태그는 HeyGen이 기대하는 레이블로 다시 작성되며, 연결되지 않은 참조를 가리키는 태그는 오류를 발생시킵니다. 참조 이미지나 동영상이 없으면 노드는 텍스트-투-비디오 생성으로 실행됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 모델 버전입니다. (기본값: `"heygen-video-1"`) | DYNAMIC_COMBO | 예 | `"heygen-video-1"` |
| `prompt` | 비디오에 대한 설명으로, 대사도 포함할 수 있습니다. 연결된 참조는 입력 순서에 따라 유형별로 번호가 매겨진 @Image1, @Video1, @Audio1로 참조하세요. (기본값: 빈 문자열) | STRING | 예 | 1~16000자 |
| `duration` | 출력 비디오의 길이(초)입니다. 15초 초과는 참조 이미지와 동영상이 없을 때만 사용할 수 있습니다. (기본값: 5) | INT | 예 | 5~30 |
| `resolution` | 출력 해상도입니다. 1080p 및 2k는 16:9 또는 9:16 화면 비율이 필요하며, 'auto'는 참조가 없을 때만 이 해상도에서 동작합니다. (기본값: `"768p"`) | COMBO | 예 | `"768p"`<br>`"480p"`<br>`"1080p"`<br>`"2k"` |
| `aspect_ratio` | 출력 화면 비율입니다. `"auto"`는 참조가 연결되지 않은 경우 16:9이며, 그렇지 않으면 첫 번째 참조 이미지를 따르고, 이미지가 연결되지 않은 경우에는 첫 번째 참조 동영상을 따릅니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"` |
| `seed` | 생성용 시드입니다. 동일한 시드를 사용해도 실행마다 결과가 달라질 수 있습니다. (기본값: 42) | INT | 예 | 0~4294967295 |
| `reference_images` | 확장 가능한 슬롯: 비디오에 사용할 사람, 제품 또는 장소 이미지입니다(`image_1` ... `image_9`). @Image1, @Image2, ...로 참조하세요. 각 입력은 정확히 하나의 이미지만 포함해야 하며, 각 이미지의 화면 비율은 1:4에서 4:1 사이여야 합니다. | IMAGE | 아니요 | 0~9개 이미지 |
| `reference_videos` | 확장 가능한 슬롯: 참조로 사용할 동영상입니다(`video_1` ... `video_3`). @Video1, @Video2, ...로 참조하세요. 총 최대 15초 분량의 영상만 사용됩니다. | VIDEO | 아니요 | 0~3개 동영상 |
| `reference_audios` | 확장 가능한 슬롯: 화자의 목소리와 같은 오디오 클립입니다(`audio_1` ... `audio_3`). @Audio1, @Audio2, ...로 참조하세요. 하나 이상의 참조 이미지 또는 동영상이 필요합니다. 목소리 참조에는 몇 초 분량의 깨끗한 음성이 필요하며, 약 2초보다 짧은 클립은 일반적으로 무시됩니다. | AUDIO | 아니요 | 0~3개 오디오 클립 |
| `auto_duration` | 활성화하면 비디오 길이가 프롬프트에 인용된 대사에 따라 결정되며(8~30초, 참조 이미지 또는 동영상이 있으면 8~15초), `duration`은 무시됩니다. (기본값: `"disabled"`) | COMBO | 아니요 | `"disabled"`<br>`"enabled"` |

### 매개변수 제약 사항

- **참조 제한:** 총 최대 15개의 참조를 사용할 수 있습니다. 이미지 최대 9개, 동영상 3개, 오디오 클립 3개입니다. 더 많이 연결하면 오류가 발생합니다.
- **오디오에는 이미지 또는 동영상 필요:** 참조 이미지와 참조 동영상이 모두 연결되지 않은 경우 참조 오디오는 거부됩니다.
- **참조 이미지 규칙:** 각 `reference_images` 입력은 정확히 하나의 이미지만 포함해야 하며(배치는 거부됨), 각 이미지의 화면 비율은 1:4에서 4:1 사이여야 합니다.
- **프롬프트 태그:** `@ImageN`, `@VideoN`, `@AudioN`은 대소문자를 구분하지 않고 일치합니다. 번호는 해당 유형에 연결된 참조 수를 초과해서는 안 되며, 프롬프트는 공백을 제거한 후 비어 있지 않아야 합니다.
- **모드:** 참조 이미지 또는 동영상이 하나 이상 있으면 참조-투-비디오 실행이고, 없으면 일반 텍스트-투-비디오 실행입니다.
- **1080p 및 2k 해상도:** `resolution`이 `"1080p"` 또는 `"2k"`인 경우 `aspect_ratio`가 `"16:9"` 또는 `"9:16"`이어야 하며, `"auto"`는 참조 이미지와 참조 동영상이 모두 연결되지 않은 경우에만 이 해상도에서 허용됩니다.
- **길이:** 참조 이미지 또는 동영상이 있으면 생성되는 비디오는 15초 이하로 유지됩니다. 더 긴 비디오에는 참조 이미지나 동영상이 필요하지 않습니다. `auto_duration`은 `duration`을 무시하게 만들 뿐이며(대사 기준 8~30초, 참조가 있으면 8~15초), 이 상한을 높이지는 않습니다.
- **시드:** 시드는 노드가 다시 실행되는지 여부만 결정하며, 동일한 시드로 결과를 재현할 수는 없습니다.
