# HeyGen Video 1.0 Reference to Video

Создайте видео с синхронизированным диалогом и звуком из текстового запроса с помощью HeyGen Video 1.0, при необходимости с опорой на подключённые референсные материалы. Изображения людей, товаров или мест, видео для повторного использования и аудиоклипы, задающие голос, — всё это можно использовать в качестве референсов. Указывайте каждый референс в запросе как @Image1, @Video1 или @Audio1, нумеруя их по типу в порядке подключения входов: эти теги переписываются в метки, которые ожидает HeyGen, а тег, указывающий на неподключённый референс, вызывает ошибку. Без какого-либо референсного изображения или видео узел работает как генерация видео по тексту.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Версия модели, используемая для генерации. (по умолчанию: `"heygen-video-1"`) | DYNAMIC_COMBO | Да | `"heygen-video-1"` |
| `prompt` | Описание видео, включая любые диалоги. Ссылайтесь на подключённые референсы как @Image1, @Video1, @Audio1, нумеруя их по типу в порядке входов. (по умолчанию: пустая строка) | STRING | Да | от 1 до 32000 символов |
| `duration` | Длительность выходного видео в секундах. (по умолчанию: 5) | INT | Да | от 5 до 15 |
| `resolution` | Выходное разрешение. (по умолчанию: `"768p"`) | COMBO | Да | `"768p"`<br>`"480p"` |
| `aspect_ratio` | Выходное соотношение сторон. `"auto"` — это 16:9, когда референсы не подключены; иначе используется соотношение первого референсного изображения или первого референсного видео, если изображения не подключены. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"`<br>`"21:9"` |
| `seed` | Сид для генерации. Результаты всё ещё могут различаться между запусками с одним и тем же сидом. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |
| `reference_images` | Расширяемый слот: изображения людей, товаров или мест для использования в видео (`image_1` ... `image_9`); ссылайтесь на них как @Image1, @Image2, ... Каждый вход должен содержать ровно одно изображение, и каждое изображение должно иметь соотношение сторон от 1:4 до 4:1. | IMAGE | Нет | от 0 до 9 изображений |
| `reference_videos` | Расширяемый слот: видео для использования в качестве референсов (`video_1` ... `video_3`); ссылайтесь на них как @Video1, @Video2, ... | VIDEO | Нет | от 0 до 3 видео |
| `reference_audios` | Расширяемый слот: аудиоклипы, например голос говорящего (`audio_1` ... `audio_3`); ссылайтесь на них как @Audio1, @Audio2, ... Требуется хотя бы одно референсное изображение или видео. Для голосового референса нужна пара секунд чистой речи; клипы короче примерно 2 секунд обычно игнорируются. | AUDIO | Нет | от 0 до 3 аудиоклипов |

### Ограничения параметров

- **Ограничение на референсы:** максимум 12 референсов суммарно по `reference_images`, `reference_videos` и `reference_audios`; подключение большего числа вызывает ошибку.
- **Для аудио нужно изображение или видео:** референсное аудио отклоняется, если не подключено ни референсное изображение, ни референсное видео.
- **Правила для референсных изображений:** каждый вход `reference_images` должен содержать ровно одно изображение (пакет отклоняется), и каждое изображение должно иметь соотношение сторон от 1:4 до 4:1.
- **Теги в запросе:** `@ImageN`, `@VideoN` и `@AudioN` сопоставляются без учёта регистра. Номер не должен превышать количество подключённых референсов этого типа, а запрос после удаления пробелов не должен быть пустым.
- **Режим:** при наличии хотя бы одного референсного изображения или видео запрос выполняется как генерация видео по референсу; без них — как обычная генерация видео по тексту.
- **Сид:** сид только определяет, будет ли узел перезапущен; результаты не воспроизводятся при одном и том же сиде.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео с синхронизированным диалогом и звуком. | VIDEO |
