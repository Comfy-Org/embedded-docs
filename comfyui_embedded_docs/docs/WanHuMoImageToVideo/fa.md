# WanHuMoImageToVideo

گره WanHuMoImageToVideo داده‌های شرطی‌سازی و یک latent ویدئوی خالی را برای خط لوله تولید ویدئوی Wan HuMo آماده می‌کند. این گره می‌تواند یک تصویر مرجع و جاسازی‌های صوتی را به ورودی‌های شرطی‌سازی مثبت و منفی متصل کند و یک latent پر از صفر با اندازه‌ای مبتنی بر `width`، `height`، `length` و `batch_size` درخواستی ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت که تولید ویدئو را به سمت محتوای مطلوب هدایت می‌کند. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی که تولید ویدئو را از محتوای ناخواسته دور می‌کند. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر مرجع به فضای latent. | VAE | بله | - |
| `width` | عرض فریم‌های ویدئوی خروجی بر حسب پیکسل. پیش‌فرض: 832. | INT | بله | 16 تا MAX_RESOLUTION، گام 16 |
| `height` | ارتفاع فریم‌های ویدئوی خروجی بر حسب پیکسل. پیش‌فرض: 480. | INT | بله | 16 تا MAX_RESOLUTION، گام 16 |
| `length` | تعداد فریم‌ها در دنباله ویدئوی تولیدشده. پیش‌فرض: 97. | INT | بله | 1 تا MAX_RESOLUTION، گام 4 |
| `batch_size` | تعداد دنباله‌های ویدئویی که هم‌زمان تولید می‌شوند. پیش‌فرض: 1. | INT | بله | 1 تا 4096 |
| `audio_encoder_output` | داده‌های رمزگذاری صوتی اختیاری که می‌تواند بر تولید ویدئو بر اساس محتوای صوتی تأثیر بگذارد. | AUDIOENCODEROUTPUT | خیر | - |
| `ref_image` | تصویر مرجع اختیاری که برای هدایت سبک و محتوای تولید ویدئو استفاده می‌شود. فقط اولین تصویر در دسته استفاده می‌شود. | IMAGE | خیر | - |

**توجه:** وقتی تصویر مرجع ارائه شود، اولین تصویر در دسته با درون‌یابی دوخطی به `width` و `height` درخواستی بزرگ‌نمایی می‌شود و با VAE رمزگذاری می‌گردد. آن latent مرجع به شرطی‌سازی مثبت متصل می‌شود، در حالی که یک latent پر از صفر با همان شکل به شرطی‌سازی منفی متصل می‌شود. وقتی `audio_encoder_output` ارائه شود، جاسازی‌های صوتی درون‌یابی می‌شوند و به شرطی‌سازی مثبت متصل می‌شوند، در حالی که یک جاسازی صوتی پر از صفر به شرطی‌سازی منفی متصل می‌شود. اگر هر یک از ورودی‌های اختیاری حذف شود، تنسورهای جایگزین پر از صفر استفاده می‌شوند: یک latent مرجع صفر با شکل `[batch_size, 16, 1, height // 8, width // 8]` و/یا جاسازی‌های صوتی صفر با شکل `[batch_size, latent_t + 1, 8, 5, 1280]`، که در آن `latent_t = ((length - 1) // 4) + 1`.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده با تصویر مرجع و/یا جاسازی‌های صوتی ادغام‌شده. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده با تصویر مرجع و/یا جاسازی‌های صوتی ادغام‌شده. | CONDITIONING |
| `latent` | نمایش latent مقداردهی‌شده با صفر برای دنباله ویدئو، با اندازه متناسب با `width`، `height`، `length` و `batch_size`. شکل: `[batch_size, 16, latent_t, height // 8, width // 8]`، که در آن `latent_t = ((length - 1) // 4) + 1`. | LATENT |
