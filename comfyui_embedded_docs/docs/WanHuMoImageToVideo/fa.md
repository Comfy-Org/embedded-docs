# WanHuMoImageToVideo

گره WanHuMoImageToVideo داده‌های شرطی‌سازی و فضای نهفته را برای تولید ویدئو از تصویر آماده می‌کند. این گره یک تنسور ویدئوی نهفته خالی ایجاد می‌کند، در صورت وجود تصویر مرجع، آن را با VAE کدگذاری می‌کند و در صورت وجود خروجی رمزگذار صدا، آن را به شرطی‌سازی همگام با ویدئو تبدیل می‌کند. گره دو جریان شرطی‌سازی مثبت و منفی و همچنین یک تنسور نهفته برای نمونه‌برداری بیشتر ویدئو تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت که تولید ویدئو را به سمت محتوای مورد نظر هدایت می‌کند. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی که تولید ویدئو را از محتوای ناخواسته دور می‌کند. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای کدگذاری تصویر مرجع در فضای نهفته. | VAE | بله | - |
| `width` | عرض فریم‌های ویدئوی خروجی به پیکسل (پیش‌فرض: 832؛ باید بر 16 بخش‌پذیر باشد). | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `height` | ارتفاع فریم‌های ویدئوی خروجی به پیکسل (پیش‌فرض: 480؛ باید بر 16 بخش‌پذیر باشد). | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `length` | تعداد فریم‌های دنباله ویدئوی تولیدشده (پیش‌فرض: 97؛ باید `(length - 1)` بر 4 بخش‌پذیر باشد). | INT | بله | 1 تا MAX_RESOLUTION (گام 4) |
| `batch_size` | تعداد دنباله‌های ویدئویی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `audio_encoder_output` | خروجی اختیاری رمزگذار صدا که برای تأثیرگذاری بر تولید ویدئو بر اساس محتوای صوتی استفاده می‌شود. | AUDIO_ENCODER_OUTPUT | خیر | - |
| `ref_image` | تصویر مرجع اختیاری که برای هدایت سبک و محتوای تولید ویدئو استفاده می‌شود. | IMAGE | خیر | - |

**نکته:** هنگامی که `ref_image` ارائه شود، به ابعاد `width` × `height` تغییر اندازه داده می‌شود، با `vae` کدگذاری می‌شود و به هر دو شرطی‌سازی مثبت و منفی به‌عنوان یک نهفته مرجع اضافه می‌شود. اگر تصویر مرجعی ارائه نشود، از نهفته‌های مرجع صفر استفاده می‌شود. اگر `audio_encoder_output` ارائه شود، جاسازی‌های صوتی آن پردازش و به هر دو جریان شرطی‌سازی به‌عنوان یک جاسازی صوتی اضافه می‌شوند؛ در غیر این صورت از یک جاسازی صوتی صفر استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت با اطلاعات نهفته مرجع و جاسازی صوتی اضافه‌شده. | CONDITIONING |
| `negative` | شرطی‌سازی منفی با اطلاعات نهفته مرجع و جاسازی صوتی اضافه‌شده. | CONDITIONING |
| `latent` | تنسور نهفته نشان‌دهنده دنباله ویدئو، که بر اساس `batch_size`، `length`، `height` و `width` با صفر مقداردهی شده است. | LATENT |
