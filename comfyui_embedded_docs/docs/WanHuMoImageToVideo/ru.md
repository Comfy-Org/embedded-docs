# WanHuMoImageToVideo

Узел WanHuMoImageToVideo подготавливает данные кондиционирования и латентное пространство для генерации видео из изображения. Он создаёт пустой латентный видеотензор, опционально кодирует референсное изображение с помощью VAE и опционально преобразует выходные данные аудиоэнкодера в кондиционирование, синхронизированное с видео. Узел выводит положительный и отрицательный потоки кондиционирования, а также латентный тензор для дальнейшего сэмплирования видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное входное кондиционирование, направляющее генерацию видео к желаемому содержимому. | CONDITIONING | Да | - |
| `negative` | Отрицательное входное кондиционирование, которое уводит генерацию видео от нежелательного содержимого. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования референсного изображения в латентное пространство. | VAE | Да | - |
| `width` | Ширина кадров выходного видео в пикселях (по умолчанию: 832; должно быть кратно 16). | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `height` | Высота кадров выходного видео в пикселях (по умолчанию: 480; должно быть кратно 16). | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `length` | Количество кадров в генерируемой видеопоследовательности (по умолчанию: 97; должно удовлетворять условию `(length - 1)` делится на 4). | INT | Да | 1 to MAX_RESOLUTION (step 4) |
| `batch_size` | Количество видеопоследовательностей, генерируемых одновременно (по умолчанию: 1). | INT | Да | 1 to 4096 |
| `audio_encoder_output` | Необязательный выход аудиоэнкодера, используемый для влияния на генерацию видео на основе аудиосодержимого. | AUDIO_ENCODER_OUTPUT | Нет | - |
| `ref_image` | Необязательное референсное изображение, используемое для управления стилем и содержимым генерации видео. | IMAGE | Нет | - |

**Примечание:** Когда `ref_image` указано, оно масштабируется до `width` x `height`, кодируется с помощью `vae` и добавляется как референсный латентный вектор и в положительное, и в отрицательное кондиционирование. Если референсное изображение не указано, используются нулевые референсные латентные векторы. Когда `audio_encoder_output` указано, его аудиоэмбеддинги обрабатываются и добавляются в оба потока кондиционирования как аудиоэмбеддинг; в противном случае используется нулевой аудиоэмбеддинг.

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование с добавленными референсным латентным вектором и аудиоэмбеддингом. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с добавленными референсным латентным вектором и аудиоэмбеддингом. | CONDITIONING |
| `latent` | Латентный тензор, представляющий видеопоследовательность, инициализированный нулями в соответствии с `batch_size`, `length`, `height` и `width`. | LATENT |
