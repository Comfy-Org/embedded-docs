# WanHuMoImageToVideo

Узел WanHuMoImageToVideo подготавливает данные кондиционирования и пустой латент для конвейера генерации видео Wan HuMo. Он может прикреплять эталонное изображение и аудиоэмбеддинги к входам положительного и отрицательного кондиционирования, а также создаёт заполненный нулями латент, размер которого определяется заданными `width`, `height`, `length` и `batch_size`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Вход положительного кондиционирования, который направляет генерацию видео в сторону желаемого содержимого. | CONDITIONING | Да | - |
| `негативный` | Вход отрицательного кондиционирования, который уводит генерацию видео от нежелательного содержимого. | CONDITIONING | Да | - |
| `VAE` | Модель VAE, используемая для кодирования эталонных изображений в латентное пространство. | VAE | Да | - |
| `ширина` | Ширина кадров выходного видео в пикселях. По умолчанию: 832. | INT | Да | от 16 до MAX_RESOLUTION, шаг 16 |
| `высота` | Высота кадров выходного видео в пикселях. По умолчанию: 480. | INT | Да | от 16 до MAX_RESOLUTION, шаг 16 |
| `длина` | Количество кадров в генерируемой видеопоследовательности. По умолчанию: 97. | INT | Да | от 1 до MAX_RESOLUTION, шаг 4 |
| `размер_пакета` | Количество видеопоследовательностей, генерируемых одновременно. По умолчанию: 1. | INT | Да | от 1 до 4096 |
| `выход_аудиокодера` | Необязательные данные аудиокодирования, которые могут влиять на генерацию видео в зависимости от аудиосодержимого. | AUDIOENCODEROUTPUT | Нет | - |
| `опорное_изображение` | Необязательное эталонное изображение, используемое для управления стилем и содержимым генерации видео. Используется только первое изображение в пакете. | IMAGE | Нет | - |

**Примечание:** Когда предоставлено эталонное изображение, первое изображение в пакете масштабируется до заданных `width` и `height` с помощью билинейной интерполяции и кодируется с помощью VAE. Этот эталонный латент прикрепляется к положительному кондиционированию, а заполненный нулями латент той же формы — к отрицательному кондиционированию. Когда предоставлен `audio_encoder_output`, аудиоэмбеддинги интерполируются и прикрепляются к положительному кондиционированию, а заполненный нулями аудиоэмбеддинг — к отрицательному кондиционированию. Если какой-либо из необязательных входов опущен, используются заполненные нулями тензоры-заполнители: нулевой эталонный латент формы `[batch_size, 16, 1, height // 8, width // 8]` и/или нулевые аудиоэмбеддинги формы `[batch_size, latent_t + 1, 8, 5, 1280]`, где `latent_t = ((length - 1) // 4) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённое положительное кондиционирование с включёнными эталонным изображением и/или аудиоэмбеддингами. | CONDITIONING |
| `negative` | Изменённое отрицательное кондиционирование с включёнными эталонным изображением и/или аудиоэмбеддингами. | CONDITIONING |
| `latent` | Инициализированное нулями латентное представление для видеопоследовательности, размеры которого соответствуют `width`, `height`, `length` и `batch_size`. Форма: `[batch_size, 16, latent_t, height // 8, width // 8]`, где `latent_t = ((length - 1) // 4) + 1`. | LATENT |
