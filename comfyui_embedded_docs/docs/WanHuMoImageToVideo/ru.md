# WanHuMoImageToVideo

Узел WanHuMoImageToVideo преобразует изображения в видео последовательности, генерируя скрытые представления для кадров видео. Он обрабатывает входные данные кондиционирования и может включать эталонные изображения и аудио-эмбеддинги для влияния на генерацию видео. Узел выводит модифицированные данные кондиционирования и скрытые представления, подходящие для синтеза видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительный вход кондиционирования, который направляет генерацию видео к желаемому содержимому | CONDITIONING | Да | - |
| `негативный` | Отрицательный вход кондиционирования, который отводит генерацию видео от нежелательного содержимого | CONDITIONING | Да | - |
| `VAE` | Модель VAE, используемая для кодирования эталонных изображений в скрытое пространство | VAE | Да | - |
| `ширина` | Ширина кадров выходного видео в пикселях (по умолчанию: 832, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота кадров выходного видео в пикселях (по умолчанию: 480, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в сгенерированной видео последовательности (по умолчанию: 97, должно быть таким, чтобы (length - 1) делилось на 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео последовательностей для одновременной генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `выход_аудиокодера` | Необязательные аудио-данные кодирования, которые могут влиять на генерацию видео на основе аудиоконтента | AUDIOENCODEROUTPUT | Нет | - |
| `опорное_изображение` | Необязательное эталонное изображение, используемое для управления стилем и содержанием генерации видео | IMAGE | Нет | - |

**Примечание:** Когда предоставлено эталонное изображение, оно кодируется в скрытое представление, которое присоединяется к положительному кондиционированию, в то время как заполненное нулями скрытое представление той же формы присоединяется к отрицательному кондиционированию. Когда предоставлен выход аудиоэнкодера, аудио-эмбеддинги интерполируются и присоединяются к положительному кондиционированию, в то время как заполненный нулями аудио-эмбеддинг присоединяется к отрицательному кондиционированию. Если необязательные входы опущены, заполненные нулями тензоры-заполнители используются как для эталонных скрытых представлений, так и для аудио-эмбеддингов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Модифицированное положительное кондиционирование с включением эталонного изображения и/или аудио-эмбеддингов | CONDITIONING |
| `негативный` | Модифицированное отрицательное кондиционирование с включением эталонного изображения и/или аудио-эмбеддингов | CONDITIONING |
| `латентный` | Скрытое представление для видео последовательности, инициализированное нулями и размером в соответствии с настройками `width`, `height` и `length` | LATENT |
