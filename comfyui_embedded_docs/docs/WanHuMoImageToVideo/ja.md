# WanHuMoImageToVideo

WanHuMoImageToVideo ノードは、画像から動画を生成するためのコンディショニングデータと潜在空間を準備します。このノードは、空の潜在ビデオテンソルを作成し、必要に応じて VAE で参照画像をエンコードし、必要に応じてオーディオエンコーダ出力をビデオタイミングのコンディショニングに変換します。出力は、ポジティブおよびネガティブのコンディショニングストリームと、さらなるビデオサンプリング用の潜在テンソルです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 動画生成を望ましいコンテンツへ導くポジティブコンディショニング入力です。 | CONDITIONING | はい | - |
| `negative` | 動画生成を望ましくないコンテンツから遠ざけるネガティブコンディショニング入力です。 | CONDITIONING | はい | - |
| `vae` | 参照画像を潜在空間にエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `width` | 出力ビデオフレームの幅（ピクセル単位）です（デフォルト: 832、16 で割り切れる必要があります）。 | INT | はい | 16 to MAX_RESOLUTION (step 16) |
| `height` | 出力ビデオフレームの高さ（ピクセル単位）です（デフォルト: 480、16 で割り切れる必要があります）。 | INT | はい | 16 to MAX_RESOLUTION (step 16) |
| `length` | 生成されるビデオシーケンスのフレーム数です（デフォルト: 97、`(length - 1)` が 4 で割り切れる必要があります）。 | INT | はい | 1 to MAX_RESOLUTION (step 4) |
| `batch_size` | 同時に生成するビデオシーケンスの数です（デフォルト: 1）。 | INT | はい | 1 to 4096 |
| `audio_encoder_output` | オーディオコンテンツに基づいて動画生成に影響を与えるための、オプションのオーディオエンコーダ出力です。 | AUDIO_ENCODER_OUTPUT | いいえ | - |
| `ref_image` | 動画生成のスタイルとコンテンツをガイドするための、オプションの参照画像です。 | IMAGE | いいえ | - |

**注記:** `ref_image` が指定された場合、`width` x `height` にリサイズされ、`vae` でエンコードされ、参照潜在としてポジティブおよびネガティブの両方のコンディショニングに追加されます。参照画像が指定されない場合は、ゼロ参照潜在が使用されます。`audio_encoder_output` が指定された場合、そのオーディオ埋め込みが処理され、オーディオ埋め込みとして両方のコンディショニングストリームに追加されます。それ以外の場合は、ゼロのオーディオ埋め込みが使用されます。
