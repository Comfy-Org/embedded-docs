# وان هو مو صورة إلى فيديو

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | إدخال تهيئة إيجابي يوجّه توليد الفيديو نحو المحتوى المرغوب. | CONDITIONING | نعم | - |
| `negative` | إدخال تهيئة سلبي يوجّه توليد الفيديو بعيدًا عن المحتوى غير المرغوب. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير الصورة المرجعية في الفضاء الكامن. | VAE | نعم | - |
| `width` | عرض إطارات الفيديو الناتج بالبكسل (الافتراضي: 832؛ يجب أن يكون قابلاً للقسمة على 16). | INT | نعم | 16 to MAX_RESOLUTION (step 16) |
| `height` | ارتفاع إطارات الفيديو الناتج بالبكسل (الافتراضي: 480؛ يجب أن يكون قابلاً للقسمة على 16). | INT | نعم | 16 to MAX_RESOLUTION (step 16) |
| `length` | عدد الإطارات في تسلسل الفيديو المُولَّد (الافتراضي: 97؛ يجب أن يحقق `(length - 1)` قابلية القسمة على 4). | INT | نعم | 1 to MAX_RESOLUTION (step 4) |
| `batch_size` | عدد تسلسلات الفيديو التي سيتم توليدها في وقت واحد (الافتراضي: 1). | INT | نعم | 1 to 4096 |
| `audio_encoder_output` | مخرج مشفّر الصوت الاختياري المستخدم للتأثير على توليد الفيديو بناءً على المحتوى الصوتي. | AUDIO_ENCODER_OUTPUT | لا | - |
| `ref_image` | صورة مرجعية اختيارية تُستخدم لتوجيه أسلوب ومحتوى توليد الفيديو. | IMAGE | لا | - |

**ملاحظة:** عند تقديم `ref_image`، يتم تغيير حجمها إلى `width` × `height`، وتشفيرها باستخدام `vae`، وإضافتها إلى كل من التهيئة الإيجابية والسلبية ككامن مرجعي. عندما لا يتم تقديم صورة مرجعية، يتم استخدام كوامن مرجعية صفرية. عند تقديم `audio_encoder_output`، تتم معالجة تضميناته الصوتية وإضافتها إلى مساري التهيئة كتضمين صوتي؛ وإلا يتم استخدام تضمين صوتي صفري.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تهيئة إيجابية مع إضافة معلومات الكامن المرجعي والتضمين الصوتي. | CONDITIONING |
| `negative` | تهيئة سلبية مع إضافة معلومات الكامن المرجعي والتضمين الصوتي. | CONDITIONING |
| `latent` | موتر كامن يمثل تسلسل الفيديو، مُهيأ بالأصفار وفقًا لكل من `batch_size` و`length` و`height` و`width`. | LATENT |
