# وان هو مو صورة إلى فيديو

تجهّز عقدة WanHuMoImageToVideo بيانات التكييف وتمثيلًا كامنًا فارغًا للفيديو من أجل خط أنابيب توليد فيديو Wan HuMo. ويمكنها إرفاق صورة مرجعية وتضمينات صوتية بمدخلات التكييف الإيجابي والسلبي، كما تنشئ تمثيلًا كامنًا معبأً بالأصفار بالحجم المحدد من العرض والارتفاع والطول وحجم الدفعة المطلوبة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مدخل التكييف الإيجابي الذي يوجّه توليد الفيديو نحو المحتوى المطلوب. | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي الذي يبعد توليد الفيديو عن المحتوى غير المرغوب فيه. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور المرجعية إلى الفضاء الكامن. | VAE | نعم | - |
| `width` | عرض إطارات الفيديو الناتج بالبكسل. الافتراضي: 832. | INT | نعم | 16 إلى MAX_RESOLUTION، الخطوة 16 |
| `height` | ارتفاع إطارات الفيديو الناتج بالبكسل. الافتراضي: 480. | INT | نعم | 16 إلى MAX_RESOLUTION، الخطوة 16 |
| `length` | عدد الإطارات في تسلسل الفيديو المُولَّد. الافتراضي: 97. | INT | نعم | 1 إلى MAX_RESOLUTION، الخطوة 4 |
| `batch_size` | عدد تسلسلات الفيديو المراد توليدها في وقت واحد. الافتراضي: 1. | INT | نعم | 1 إلى 4096 |
| `audio_encoder_output` | بيانات ترميز صوتي اختيارية يمكنها التأثير في توليد الفيديو بناءً على المحتوى الصوتي. | AUDIOENCODEROUTPUT | لا | - |
| `ref_image` | صورة مرجعية اختيارية تُستخدم لتوجيه نمط الفيديو ومحتواه. تُستخدم الصورة الأولى فقط في الدفعة. | IMAGE | لا | - |

**ملاحظة:** عند توفير صورة مرجعية، تُكبَّر الصورة الأولى في الدفعة إلى `width` و`height` المطلوبين باستخدام الاستيفاء ثنائي الخطوط، ثم تُرمَّز باستخدام VAE. ويُرفَق التمثيل الكامن المرجعي الناتج بالتكييف الإيجابي، بينما يُرفَق تمثيل كامن معبأ بالأصفار بالشكل نفسه بالتكييف السلبي. وعند توفير `audio_encoder_output`، تُجرى عملية استيفاء للتضمينات الصوتية وتُرفَق بالتكييف الإيجابي، بينما يُرفَق تضمين صوتي معبأ بالأصفار بالتكييف السلبي. وإذا حُذف أي من المدخلين الاختياريين، تُستخدم موترات بديلة معبأة بالأصفار: تمثيل كامن مرجعي معبأ بالأصفار بالشكل `[batch_size, 16, 1, height // 8, width // 8]` و/أو تضمينات صوتية معبأة بالأصفار بالشكل `[batch_size, latent_t + 1, 8, 5, 1280]`، حيث `latent_t = ((length - 1) // 4) + 1`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدّل مع دمج الصورة المرجعية و/أو التضمينات الصوتية. | CONDITIONING |
| `negative` | تكييف سلبي معدّل مع دمج الصورة المرجعية و/أو التضمينات الصوتية. | CONDITIONING |
| `latent` | تمثيل كامن مهيأ بالأصفار لتسلسل الفيديو، بحجم وفقًا لـ `width` و`height` و`length` و`batch_size`. الشكل: `[batch_size, 16, latent_t, height // 8, width // 8]`، حيث `latent_t = ((length - 1) // 4) + 1`. | LATENT |
