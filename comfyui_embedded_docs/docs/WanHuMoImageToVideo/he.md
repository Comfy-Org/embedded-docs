# WanHuMoImageToVideo

הצומת WanHuMoImageToVideo מכין נתוני התניה ולטנט ריק של וידאו עבור צינור יצירת הווידאו של Wan HuMo. הוא יכול לצרף תמונת עזר והטמעות אודיו לקלטי ההתניה החיובית והשלילית, והוא יוצר לטנט מלא באפסים שגודלו נגזר מהערכים המבוקשים של `width`, `height`, `length` ו-`batch_size`.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט התניה חיובית שמכוון את יצירת הווידאו לתוכן הרצוי. | CONDITIONING | כן | - |
| `negative` | קלט התניה שלילית שמרחיק את יצירת הווידאו מתוכן לא רצוי. | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות עזר למרחב לטנטי. | VAE | כן | - |
| `width` | רוחב פריימי הווידאו בפלט בפיקסלים. ברירת מחדל: 832. | INT | כן | 16 עד MAX_RESOLUTION, צעד 16 |
| `height` | גובה פריימי הווידאו בפלט בפיקסלים. ברירת מחדל: 480. | INT | כן | 16 עד MAX_RESOLUTION, צעד 16 |
| `length` | מספר הפריימים ברצף הווידאו הנוצר. ברירת מחדל: 97. | INT | כן | 1 עד MAX_RESOLUTION, צעד 4 |
| `batch_size` | מספר רצפי הווידאו ליצירה בו-זמנית. ברירת מחדל: 1. | INT | כן | 1 עד 4096 |
| `audio_encoder_output` | נתוני קידוד אודיו אופציונליים שיכולים להשפיע על יצירת הווידאו בהתאם לתוכן האודיו. | AUDIOENCODEROUTPUT | לא | - |
| `ref_image` | תמונת עזר אופציונלית המשמשת להנחות את הסגנון והתוכן של יצירת הווידאו. נעשה שימוש רק בתמונה הראשונה באצווה. | IMAGE | לא | - |

**הערה:** כאשר מסופקת תמונת עזר, התמונה הראשונה באצווה מוגדלת ל-`width` ול-`height` המבוקשים באמצעות אינטרפולציה בילינארית ומקודדת עם VAE. לטנט העזר הזה מצורף להתניה החיובית, בעוד שלטנט מלא באפסים בעל אותה צורה מצורף להתניה השלילית. כאשר מסופק `audio_encoder_output`, הטמעות האודיו עוברות אינטרפולציה ומצורפות להתניה החיובית, בעוד שהטמעת אודיו מלאה באפסים מצורפת להתניה השלילית. אם אחד מהקלטים האופציונליים מושמט, נעשה שימוש בטנסורי ממלא מקום מלאים באפסים: לטנט עזר מלא באפסים בצורה `[batch_size, 16, 1, height // 8, width // 8]` ו/או הטמעות אודיו מלאות באפסים בצורה `[batch_size, latent_t + 1, 8, 5, 1280]`, כאשר `latent_t = ((length - 1) // 4) + 1`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | התניה חיובית מותאמת עם תמונת עזר ו/או הטמעות אודיו משולבות. | CONDITIONING |
| `negative` | התניה שלילית מותאמת עם תמונת עזר ו/או הטמעות אודיו משולבות. | CONDITIONING |
| `latent` | ייצוג לטנטי מאותחל באפסים עבור רצף הווידאו, בגודל המתאים ל-`width`, `height`, `length` ו-`batch_size`. צורה: `[batch_size, 16, latent_t, height // 8, width // 8]`, כאשר `latent_t = ((length - 1) // 4) + 1`. | LATENT |
