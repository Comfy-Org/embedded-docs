# WanHuMo圖像轉影片

WanHuImageToVideo 節點透過產生影片幀的潛在表徵，將影像轉換為影片序列。它處理條件輸入，並可納入參考影像和音訊嵌入以影響影片生成。此節點輸出修改後的條件數據和適合影片合成的潛在表徵。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正面提示詞` | 引導影片生成朝向期望內容的正向條件輸入 | CONDITIONING | 是 | - |
| `負面提示詞` | 引導影片生成遠離不希望內容的負向條件輸入 | CONDITIONING | 是 | - |
| `VAE` | 用於將參考影像編碼到潛在空間的 VAE 模型 | VAE | 是 | - |
| `寬度` | 輸出影片幀的寬度（像素），預設值：832，必須可被 16 整除 | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 輸出影片幀的高度（像素），預設值：480，必須可被 16 整除 | INT | 是 | 16 to MAX_RESOLUTION |
| `長度` | 生成的影片序列中的幀數，預設值：97，必須滿足 (length - 1) 可被 4 整除 | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 同時生成的影片序列數量，預設值：1 | INT | 是 | 1 至 4096 |
| `音訊編碼器輸出` | 可選的音訊編碼數據，可根據音訊內容影響影片生成 | AUDIOENCODEROUTPUT | 否 | - |
| `參考圖像` | 可選的參考影像，用於引導影片生成的風格和內容 | IMAGE | 否 | - |

**注意：** 當提供參考影像時，它會被編碼成一個潛在張量，並附加到正向條件中；同時，一個相同形狀的零填充潛在張量會被附加到負向條件中。當提供音訊編碼器輸出時，音訊嵌入會被插值並附加到正向條件中，而一個零填充的音訊嵌入會被附加到負向條件中。如果省略這些可選輸入，則參考潛在張量和音訊嵌入都會使用零填充的佔位張量。
