# LumaImageModifyNode

משנה תמונות באופן סינכרוני בהתבסס על פרומפט טקסטואלי ויחס הגובה-רוחב של התמונה המקורית. צומת זה מקבל תמונת קלט ומשנה אותה בהתאם לפרומפט המסופק, תוך שימוש במשקל תמונה ניתן להגדרה כדי לשלוט במידת השינוי בתמונה המקורית.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שיש לשנות | IMAGE | כן | - |
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: "") | STRING | כן | - |
| `image_weight` | משקל התמונה; ככל שקרוב יותר ל-1.0, התמונה תשתנה פחות (ברירת מחדל: 0.1). באופן פנימי, ערך זה מתהפך (1.0 - image_weight) וממוגבל בין 0.0 ל-0.98. | FLOAT | לא | 0.0-0.98 |
| `model` | מודל Luma לשימוש בשינוי התמונה. למודלים שונים עלויות שונות. | STRING | כן | `"photon-flash-1"`<br>`"photon-1"`<br>`"photon"` |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא קשר ל-seed (ברירת מחדל: 0) | INT | לא | 0-18446744073709551615 |
