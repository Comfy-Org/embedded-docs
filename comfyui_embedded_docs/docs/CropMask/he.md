# חיתוך מסכה

צומת CropMask מיועד לחיתוך אזור מוגדר מתוך מסכה נתונה. הוא מאפשר למשתמשים להגדיר את אזור העניין על ידי ציון קואורדינטות וממדים, ובכך לחלץ חלק מהמסכה לעיבוד או לניתוח נוספים.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `mask` | קלט המסכה מייצג את תמונת המסכה שיש לחתוך. הוא הכרחי להגדרת האזור שיחולץ בהתאם לקואורדינטות ולממדים שצוינו. | MASK |
| `x` | קואורדינטת x מציינת את נקודת ההתחלה על הציר האופקי שממנה החיתוך אמור להתחיל. | INT |
| `y` | קואורדינטת y קובעת את נקודת ההתחלה על הציר האנכי עבור פעולת החיתוך. | INT |
| `width` | רוחב מגדיר את ההיקף האופקי של אזור החיתוך מנקודת ההתחלה. | INT |
| `height` | גובה מגדיר את ההיקף האנכי של אזור החיתוך מנקודת ההתחלה. | INT |

## פלטים
