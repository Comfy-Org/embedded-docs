# ModelMergeCosmosPredict2_2B

گره ModelMergeCosmosPredict2_2B دو مدل انتشار را با استفاده از رویکرد مبتنی بر بلوک و با کنترل دقیق بر اجزای مختلف مدل ادغام می‌کند. این گره به شما امکان می‌دهد بخش‌های خاصی از دو مدل را با تنظیم وزن‌های درون‌یابی برای تعبیه‌گرهای موقعیت، تعبیه‌گرهای زمان، بلوک‌های ترنسفورمر و لایه‌های نهایی ترکیب کنید. این امر کنترل دقیقی بر نحوه مشارکت اجزای معماری مختلف از هر مدل در نتیجه نهایی ادغام‌شده فراهم می‌کند.
