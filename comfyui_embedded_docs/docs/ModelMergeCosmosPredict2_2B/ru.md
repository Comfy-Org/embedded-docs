# ModelMergeCosmosPredict2_2B

Узел ModelMergeCosmosPredict2_2B объединяет две диффузионные модели, используя блочный подход с точным контролем над различными компонентами моделей. Он позволяет смешивать определённые части двух моделей, регулируя веса интерполяции для эмбеддеров позиции, эмбеддеров времени, блоков трансформера и финальных слоёв. Это обеспечивает точный контроль над тем, как различные архитектурные компоненты каждой модели влияют на итоговый объединённый результат.
