# ModelMergeCosmosPredict2_2B

Узел ModelMergeCosmosPredict2_2B объединяет две диффузионные модели на основе блочного подхода с детальным контролем над различными компонентами моделей. Он позволяет смешивать отдельные части двух моделей, регулируя веса интерполяции для позиционных эмбеддеров, временных эмбеддеров, трансформерных блоков и финальных слоёв. Это обеспечивает точный контроль над тем, как различные архитектурные компоненты каждой модели влияют на итоговый объединённый результат.
