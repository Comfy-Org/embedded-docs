# ModelMergeCosmosPredict2_2B

הצומת ModelMergeCosmosPredict2_2B ממזגת שני מודלי דיפוזיה באמצעות גישה מבוססת בלוקים עם שליטה עדינה ברכיבי מודל שונים. היא מאפשרת למזג חלקים ספציפיים משני מודלים על ידי התאמת משקלי אינטרפולציה עבור מטמיעי מיקום, מטמיעי זמן, בלוקי טרנספורמר ושכבות סופיות. זה מספק שליטה מדויקת באופן שבו רכיבים ארכיטקטוניים שונים מכל מודל תורמים לתוצאה הממוזגת הסופית.
