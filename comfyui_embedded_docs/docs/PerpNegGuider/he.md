# Perp-Neg Guider

הצומת PerpNegGuider יוצר מערכת הנחיה לשליטה ביצירת תמונות באמצעות התניה שלילית מאונכת. הוא מקבל קלטים של התניה חיובית, שלילית וריקה, ומחיל אלגוריתם הנחיה ייעודי שמחשב את כל שלושת חיזויי הרעש באצווה אחת לצורכי יעילות. צומת זה מיועד לבדיקות ניסיוניות ומספק שליטה עדינה בעוצמת ההנחיה ובקנה המידה השלילי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שיש להשתמש בו ליצירת הנחיה | MODEL | כן | - |
| `positive` | ההתניה החיובית שמכוונת את היצירה לעבר התוכן הרצוי | CONDITIONING | כן | - |
| `negative` | ההתניה השלילית שמכוונת את היצירה הרחק מתוכן לא רצוי | CONDITIONING | כן | - |
| `empty_conditioning` | ההתניה הריקה או הנייטרלית המשמשת כהתייחסות בסיס להנחיה שלילית מאונכת | CONDITIONING | כן | - |
| `cfg` | סולם ההנחיה ללא מסווג (classifier-free guidance) שקובע באיזו עוצמה ההתניה משפיעה על היצירה (ברירת מחדל: 8.0) | FLOAT | כן | 0.0 - 100.0 |
| `neg_scale` | גורם קנה המידה השלילי שמתאים את עוצמת האפקט השלילי המאונך (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 100.0 |
