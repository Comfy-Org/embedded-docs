# تبدیل متن به وکتور Recraft V4

گره «Recraft V4 Text to Vector» تصاویر گرافیک برداری مقیاس‌پذیر (SVG) را از روی یک توضیح متنی تولید می‌کند. این گره برای تولید تصاویر با استفاده از مدل‌های Recraft V4 و V4.1 به یک API خارجی متصل می‌شود. گره بر اساس پرامپت شما یک یا چند تصویر SVG خروجی می‌دهد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید استفاده می‌شود. انتخاب مدل، گزینه‌های `size` موجود را تغییر می‌دهد. | DYNAMIC_COMBO | بله | `"recraftv4_1_vector"`<br>`"recraftv4_1_utility_vector"`<br>`"recraftv4_1_pro_vector"`<br>`"recraftv4_1_utility_pro_vector"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `prompt` | پرامپت تولید تصویر. حداکثر ۱۰٬۰۰۰ کاراکتر. | STRING | بله | N/A |
| `negative_prompt` | این ورودی نادیده گرفته می‌شود: پرامپت منفی توسط مدل‌های Recraft V4 و V4.1 پشتیبانی نمی‌شود. | STRING | بله | N/A |
| `n` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: ۱). | INT | بله | 1 to 6 |
| `seed` | seed برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: ۰). | INT | بله | 0 to 18446744073709551615 |
| `recraft_controls` | کنترل‌های اضافی اختیاری بر تولید از طریق گره «Recraft Controls». | CUSTOM | خیر | N/A |

### ورودی‌های recraftv4_1_vector، recraftv4_1_utility_vector و recraftv4

این سه مدل گزینه‌های `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: `"1024x1024"`). | COMBO | بله | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |

### ورودی‌های recraftv4_1_pro_vector، recraftv4_1_utility_pro_vector و recraftv4_pro

این سه مدل گزینه‌های `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: `"2048x2048"`). | COMBO | بله | `"2048x2048"`<br>`"2304x1792"`<br>`"1792x2304"`<br>`"2432x1664"`<br>`"1664x2432"`<br>`"2688x1536"`<br>`"1536x2688"`<br>`"3072x1280"`<br>`"1280x3072"` |

**توجه:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کنند. مقدار `seed` نتایج قابل تکرار از API خارجی را تضمین نمی‌کند. ورودی `negative_prompt` نادیده گرفته می‌شود؛ زیرا مدل‌های Recraft V4 و V4.1 از پرامپت منفی پشتیبانی نمی‌کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) گرافیک برداری مقیاس‌پذیر (SVG) تولیدشده. | SVG |
