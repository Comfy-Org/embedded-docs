# تبدیل متن به وکتور Recraft V4

گره Recraft V4 Text to Vector با استفاده از مدل‌های Recraft V4 و V4.1 تصویرسازی‌های Scalable Vector Graphics (SVG) را از روی یک توصیف متنی تولید می‌کند. این گره برای تولید یک یا چند فایل SVG بر اساس پرامپت شما به Recraft API متصل می‌شود و می‌تواند یک سبک برداری موجود را اعمال کند یا سبک جدیدی از تصاویر مرجع بسازد — هنگامی که از تصاویر مرجع استفاده می‌شود، سبک ساخته‌شده به‌صورت یک `style_id` برای استفاده مجدد بازگردانده می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده برای تولید. مدل‌های recraftv4_styles برای تولید سازگار با سبک ساخته شده‌اند و همیشه به `style_id` یا `style_references` نیاز دارند. انتخاب مدل، گزینه‌های `size` موجود را تغییر می‌دهد. | DYNAMIC_COMBO | بله | `"recraftv4_1_vector"`<br>`"recraftv4_1_utility_vector"`<br>`"recraftv4_1_pro_vector"`<br>`"recraftv4_1_utility_pro_vector"`<br>`"recraftv4"`<br>`"recraftv4_pro"`<br>`"recraftv4_styles_vector"`<br>`"recraftv4_styles_pro_vector"` |
| `پرامپت` | پرامپت برای تولید تصویر. حداکثر 10,000 کاراکتر. | STRING | بله | N/A |
| `پرامپت منفی` | این ورودی نادیده گرفته می‌شود: پرامپت منفی توسط مدل‌های Recraft V4 و V4.1 پشتیبانی نمی‌شود. | STRING | بله | N/A |
| `تعداد` | تعداد تصاویر برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `بذر` | Seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `کنترل‌های Recraft` | کنترل‌های اضافی اختیاری روی تولید از طریق گره Recraft Controls. | CUSTOM | خیر | N/A |
| `style_id` | UUID یک سبک برداری Recraft V4 برای اعمال، مثلاً از گره Recraft V4 Create Style یا خروجی `style_id` یک اجرای قبلی. نمی‌تواند با `style_references` ترکیب شود. | STRING | خیر | N/A |
| `style_match` | میزان پیروی دقیق از سبک: `"precise"` آن را با جزئیات بازتولید می‌کند، `"flexible"` با ظاهر کلی مطابقت می‌کند. فقط زمانی استفاده می‌شود که سبکی ارائه شده باشد (پیش‌فرض: `"precise"`). | COMBO | خیر | `"precise"`<br>`"flexible"` |

### ورودی‌های recraftv4_1_vector، recraftv4_1_utility_vector، recraftv4، و recraftv4_styles_vector

این مدل‌ها گزینه‌های `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده. پیش‌فرض `"1024x1024"` است. | COMBO | بله | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |

### ورودی‌های recraftv4_1_pro_vector، recraftv4_1_utility_pro_vector، recraftv4_pro، و recraftv4_styles_pro_vector

این مدل‌ها گزینه‌های `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده. پیش‌فرض `"2048x2048"` است. | COMBO | بله | `"2048x2048"`<br>`"2304x1792"`<br>`"1792x2304"`<br>`"2432x1664"`<br>`"1664x2432"`<br>`"2688x1536"`<br>`"1536x2688"`<br>`"3072x1280"`<br>`"1280x3072"` |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `style_references` | تصاویر مرجع برای ساخت یک سبک برداری به‌صورت درجا (on the fly)، با هزینه‌ای اضافه بر تولید. سبک ساخته‌شده به‌صورت `style_id` برای استفاده مجدد بازگردانده می‌شود. نمی‌تواند با `style_id` ترکیب شود. | IMAGE | خیر | جایگاه قابل گسترش: اتصال 1..N تصویر مرجع (تا حداکثر گره) |

**توجه:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کند. مقدار `seed` نتایج قابل تکرار از API خارجی را تضمین نمی‌کند. مدل‌های `recraftv4_styles_vector` و `recraftv4_styles_pro_vector` همیشه به یک سبک نیاز دارند: یک `style_id` ارائه دهید یا حداقل یک تصویر `style_references` متصل کنید. `style_id` و `style_references` نمی‌توانند با هم استفاده شوند — ارائه هر دو خطا ایجاد می‌کند، و `style_id` باید یک UUID معتبر باشد. تعداد تصاویر مرجع سبک محدود است، و مجموع اندازه رمزگذاری‌شده آن‌ها نباید از 10 MB بیشتر شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) Scalable Vector Graphics (SVG) تولیدشده. | SVG |
| `style_id` | UUID سبک بازگردانده‌شده توسط Recraft API. هنگامی که تصاویر مرجع ارائه می‌شوند، سبک ساخته‌شده برای استفاده مجدد اینجا بازگردانده می‌شود؛ در غیر این صورت یک رشته خالی. | STRING |
