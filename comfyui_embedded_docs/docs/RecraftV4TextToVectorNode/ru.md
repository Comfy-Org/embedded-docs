# Recraft V4: текст в вектор

Узел Recraft V4 Text to Vector генерирует изображения в формате масштабируемой векторной графики (SVG) на основе текстового описания. Он подключается к внешнему API для генерации изображений с использованием моделей Recraft V4 и V4.1. Узел выводит одно или несколько SVG-изображений в зависимости от вашего запроса.

## Входы

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. Выбор модели изменяет доступные варианты `size`. | DYNAMIC_COMBO | Да | `"recraftv4_1_vector"`<br>`"recraftv4_1_utility_vector"`<br>`"recraftv4_1_pro_vector"`<br>`"recraftv4_1_utility_pro_vector"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `prompt` | Запрос для генерации изображения. Максимум 10 000 символов. | STRING | Да | N/A |
| `negative_prompt` | Этот вход игнорируется: негативный запрос не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | N/A |
| `n` | Количество генерируемых изображений (по умолчанию: 1). | INT | Да | 1 to 6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | 0 to 18446744073709551615 |
| `recraft_controls` | Необязательные дополнительные элементы управления генерацией через узел Recraft Controls. | CUSTOM | Нет | N/A |

### Входные параметры recraftv4_1_vector, recraftv4_1_utility_vector и recraftv4

Эти три модели используют одинаковые варианты `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения (по умолчанию: `"1024x1024"`). | COMBO | Да | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |

### Входные параметры recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector и recraftv4_pro

Эти три модели используют одинаковые варианты `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения (по умолчанию: `"2048x2048"`). | COMBO | Да | `"2048x2048"`<br>`"2304x1792"`<br>`"1792x2304"`<br>`"2432x1664"`<br>`"1664x2432"`<br>`"2688x1536"`<br>`"1536x2688"`<br>`"3072x1280"`<br>`"1280x3072"` |

**Примечание:** Параметр `size` является динамическим входом, доступные варианты которого зависят от выбранной модели `model`. Значение `seed` не гарантирует воспроизводимых результатов от внешнего API. Вход `negative_prompt` игнорируется, поскольку модели Recraft V4 и V4.1 не поддерживают негативные запросы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение (или изображения) в формате масштабируемой векторной графики (SVG). | SVG |
