# Recraft V4: текст в вектор

Узел Recraft V4 Text to Vector создает иллюстрации в формате Scalable Vector Graphics (SVG) на основе текстового описания. Он подключается к API Recraft для генерации изображений с использованием моделей Recraft V4 и V4.1 и выводит один или несколько SVG-файлов в соответствии с вашим запросом.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. Выбор модели изменяет доступные параметры `size`. | DYNAMIC_COMBO | Да | `"recraftv4_1_vector"`<br>`"recraftv4_1_utility_vector"`<br>`"recraftv4_1_pro_vector"`<br>`"recraftv4_1_utility_pro_vector"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `prompt` | Запрос для генерации изображения. Максимум 10 000 символов. | STRING | Да | Н/Д |
| `negative_prompt` | Этот вход игнорируется: отрицательный запрос не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | Н/Д |
| `n` | Количество генерируемых изображений (по умолчанию: 1). | INT | Да | от 1 до 6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `recraft_controls` | Дополнительное управление генерацией через узел Recraft Controls. | CUSTOM | Нет | Н/Д |

### Входы recraftv4_1_vector, recraftv4_1_utility_vector и recraftv4

Эти модели используют одинаковые параметры `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения. По умолчанию: `"1024x1024"`. | COMBO | Да | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |

### Входы recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector и recraftv4_pro

Эти модели используют одинаковые параметры `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения. По умолчанию: `"2048x2048"`. | COMBO | Да | `"2048x2048"`<br>`"2304x1792"`<br>`"1792x2304"`<br>`"2432x1664"`<br>`"1664x2432"`<br>`"2688x1536"`<br>`"1536x2688"`<br>`"3072x1280"`<br>`"1280x3072"` |

**Примечание:** Параметр `size` является динамическим входом, доступные опции которого меняются в зависимости от выбранной модели `model`. Значение `seed` не гарантирует воспроизводимых результатов от внешнего API.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение (изображения) в формате Scalable Vector Graphics (SVG). | SVG |
