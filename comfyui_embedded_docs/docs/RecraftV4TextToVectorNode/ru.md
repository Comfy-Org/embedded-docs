# Recraft V4: текст в вектор

Узел Recraft V4 Text to Vector генерирует иллюстрации в формате Scalable Vector Graphics (SVG) из текстового описания с использованием моделей Recraft V4 и V4.1. Он подключается к Recraft API для генерации одного или нескольких SVG-файлов на основе вашего запроса и может применить существующий векторный стиль или создать новый на основе эталонных изображений — при использовании эталонных изображений созданный стиль возвращается как `style_id` для повторного использования.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. Модели recraftv4_styles предназначены для генерации с согласованным стилем и всегда требуют style_id или style_references. Выбор модели изменяет доступные параметры `size`. | DYNAMIC_COMBO | Да | `"recraftv4_1_vector"`<br>`"recraftv4_1_utility_vector"`<br>`"recraftv4_1_pro_vector"`<br>`"recraftv4_1_utility_pro_vector"`<br>`"recraftv4"`<br>`"recraftv4_pro"`<br>`"recraftv4_styles_vector"`<br>`"recraftv4_styles_pro_vector"` |
| `prompt` | Запрос для генерации изображения. Максимум 10 000 символов. | STRING | Да | Н/Д |
| `negative_prompt` | Этот вход игнорируется: отрицательный запрос не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | Н/Д |
| `n` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `recraft_controls` | Дополнительные параметры управления генерацией через узел Recraft Controls. | CUSTOM | Нет | Н/Д |
| `style_id` | UUID векторного стиля Recraft V4 для применения, например, из узла Recraft V4 Create Style или из выхода style_id предыдущего запуска. Нельзя комбинировать со style_references. | STRING | Нет | Н/Д |
| `style_match` | Насколько точно следовать стилю: precise воспроизводит его детально, flexible соответствует общему виду. Используется только при наличии стиля (по умолчанию: "precise"). | COMBO | Нет | `"precise"`<br>`"flexible"` |

### Входы recraftv4_1_vector, recraftv4_1_utility_vector, recraftv4 и recraftv4_styles_vector

Эти модели используют одни и те же параметры `size`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения. По умолчанию: `"1024x1024"`. | COMBO | Да | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |

### Входы recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector, recraftv4_pro и recraftv4_styles_pro_vector

Эти модели используют одни и те же параметры `size`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения. По умолчанию: `"2048x2048"`. | COMBO | Да | `"2048x2048"`<br>`"2304x1792"`<br>`"1792x2304"`<br>`"2432x1664"`<br>`"1664x2432"`<br>`"2688x1536"`<br>`"1536x2688"`<br>`"3072x1280"`<br>`"1280x3072"` |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `style_references` | Эталонные изображения для создания векторного стиля на лету, тарифицируются дополнительно к генерации. Созданный стиль возвращается как style_id для повторного использования. Нельзя комбинировать со style_id. | IMAGE | Нет | Расширяемый слот: подключите от 1 до N эталонных изображений (до максимального количества для данного узла) |

**Примечание:** Параметр `size` является динамическим входом, доступные значения которого изменяются в зависимости от выбранной `model`. Значение `seed` не гарантирует воспроизводимых результатов от внешнего API. Модели `recraftv4_styles_vector` и `recraftv4_styles_pro_vector` всегда требуют стиль: укажите `style_id` или подключите хотя бы одно изображение `style_references`. `style_id` и `style_references` нельзя использовать вместе — указание обоих приводит к ошибке, и `style_id` должен быть допустимым UUID. Количество эталонных изображений ограничено, а их общий закодированный размер не должен превышать 10 МБ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное(ые) изображение(я) в формате Scalable Vector Graphics (SVG). | SVG |
| `style_id` | UUID стиля, возвращаемый Recraft API. Если предоставлены эталонные изображения, созданный стиль возвращается здесь для повторного использования; в противном случае — пустая строка. | STRING |
