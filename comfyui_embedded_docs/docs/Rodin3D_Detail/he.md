# Rodin3D_Detail

צומת Rodin 3D Detail יוצר נכסי תלת-ממד מפורטים באמצעות Rodin API. הוא מקבל תמונות קלט ומעבד אותן דרך שירות Rodin כדי ליצור מודלים תלת-ממדיים באיכות גבוהה עם גאומטריה וחומרים מפורטים. הצומת מטפל בכל זרימת העבודה, מיצירת משימה ועד הורדת קובץ המודל התלת-ממדי הסופי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `Images` | תמונות קלט המשמשות ליצירת מודל תלת-ממדי. נדרשת תמונה אחת לפחות, וניתן לספק עד 5 תמונות. | IMAGE | כן | - |
| `Seed` | ערך seed אקראי לתוצאות ניתנות לשחזור (ברירת מחדל: 0) | INT | לא | 0 עד 65535 |
| `Material_Type` | סוג החומר להחלה על המודל התלת-ממדי (ברירת מחדל: "PBR") | STRING | לא | `"PBR"`<br>`"Shaded"` |
| `Polygon_count` | מספר הפוליגונים המבוקש עבור המודל התלת-ממדי שנוצר. קובע את רמת איכות הרשת (ברירת מחדל: "18K-Quad") | STRING | לא | `"4K-Quad"`<br>`"8K-Quad"`<br>`"18K-Quad"`<br>`"50K-Quad"`<br>`"200K-Triangle"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `3D Model Path` | נתיב קובץ למודל התלת-ממדי שנוצר (למטרות תאימות לאחור בלבד) | STRING |
| `GLB` | המודל התלת-ממדי שנוצר בפורמט GLB | FILE3DGLB |
