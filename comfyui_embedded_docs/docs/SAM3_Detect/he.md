# SAM3 Detect

## סקירה כללית

הצומת SAM3 Detect מבצע זיהוי וסגמנטציה באוצר מילים פתוח באמצעות תיאורי טקסט, תיבות תוחמות או פרומפטים של נקודות. הוא יכול לזהות ולבצע סגמנטציה של אובייקטים בתמונה בהתאם למה שתתאר בטקסט, היכן שתצייר תיבות או היכן שתלחץ על נקודות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל SAM3 לשימוש לזיהוי וסגמנטציה | MODEL | כן | - |
| `image` | תמונת הקלט לעיבוד | IMAGE | כן | - |
| `conditioning` | התניה טקסטואלית מ-CLIPTextEncode. נדרש בעת שימוש בפרומפטים טקסטואליים לזיהוי | CONDITIONING | לא | - |
| `bboxes` | תיבות תוחמות שלבתוכן לבצע סגמנטציה. יכול להיות תיבה בודדת (מיושמת על כל הפריימים), רשימת תיבות (מיושמת על כל הפריימים), או רשימה של רשימות (תיבות לכל פריים). כאשר הן מסופקות ללא התניית טקסט, הצומת מבצע סגמנטציה בתוך כל תיבה | BOUNDING_BOX | לא | - |
| `positive_coords` | פרומפטים של נקודות חיוביות בפורמט JSON `[{"x": int, "y": int}, ...]` תוך שימוש בקואורדינטות פיקסלים. אלו נקודות שברצונך לכלול בסגמנטציה | STRING | לא | - |
| `negative_coords` | פרומפטים של נקודות שליליות בפורמט JSON `[{"x": int, "y": int}, ...]` תוך שימוש בקואורדינטות פיקסלים. אלו נקודות שברצונך להחריג מהסגמנטציה | STRING | לא | - |
| `threshold` | סף ביטחון לזיהויים מבוססי טקסט. נשמרים רק זיהויים עם ציונים מעל ערך זה (ברירת מחדל: 0.5) | FLOAT | לא | 0.0 to 1.0 |
| `refine_iterations` | מספר מעברי עידון של מפענח SAM. ערכים גבוהים יותר יכולים לשפר את איכות המסכה. יש להגדיר ל-0 כדי להשתמש במסכות גלאי גולמיות ללא עידון (ברירת מחדל: 2) | INT | לא | 0 to 5 |
| `individual_masks` | כאשר מופעל, מפיק מסכות נפרדות עבור כל אובייקט שזוהה במקום לשלב אותן למסכה אחת (ברירת מחדל: False) | BOOLEAN | לא | True/False |

### אילוצים והערות לגבי פרמטרים

- **פרומפטים טקסטואליים**: כדי להשתמש בזיהוי מבוסס טקסט, עליך לספק קלט `conditioning`. כאשר מסופקת התניית טקסט, הצומת מריץ זיהוי מונחה טקסט על התמונה.
- **פרומפטים של תיבות**: כאשר `bboxes` מסופקות ללא התניית טקסט, הצומת מבצע סגמנטציה של האזור בתוך כל תיבה תוחמת.
- **פרומפטים של נקודות**: כאשר מסופקים `positive_coords` או `negative_coords`, הצומת משתמש בסגמנטציה מבוססת נקודות. הנקודות מותאמות אוטומטית לרזולוציה הפנימית של המודל.
- **מספר סוגי פרומפטים**: ניתן לשלב סוגי פרומפטים שונים. לדוגמה, ניתן לספק גם התניית טקסט וגם תיבות תוחמות כדי להגביל את זיהוי הטקסט לאזורים מסוימים.
- **עיבוד באצווה**: הצומת תומך בתמונות באצווה. בעת עיבוד מספר פריימים, ניתן לספק תיבות תוחמות לכל פריים באמצעות פורמט רשימה של רשימות.
- **פורמט JSON לנקודות**: קואורדינטות נקודות חייבות להיות מסופקות כמחרוזות JSON תקינות בפורמט `[{"x": 100, "y": 200}, {"x": 150, "y": 250}]`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `masks` | מסכות סגמנטציה. כאשר `individual_masks` הוא False (ברירת מחדל), מחזיר מסכה משולבת אחת לכל פריים. כאשר True, מחזיר מסכות נפרדות עבור כל אובייקט שזוהה | MASK |
