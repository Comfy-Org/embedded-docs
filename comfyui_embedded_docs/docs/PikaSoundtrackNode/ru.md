# Pika Soundtrack

Этот узел создает синхронизированную звуковую дорожку для видео с помощью Pika. Видеоряд и длительность сохраняются; заменяется только аудио. Опишите желаемое звуковое сопровождение или оставьте инструкцию пустой, чтобы звук был сформирован по изображению.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Клип, для которого нужно создать звуковую дорожку. До 10 минут. | VIDEO | Да | - |
| `instruction` | Каким должно быть аудио: звуковые эффекты, атмосферные звуки, музыка или стиль. Оставьте пустым, чтобы звук был сформирован по изображению. По умолчанию: "" (пустая строка). | STRING | Да | от 0 до 10000 символов |
| `seed` | Сид для сэмплирования. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения:**

* Входное видео должно быть не длиннее 10 минут.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Входной клип с сгенерированной звуковой дорожкой вместо исходного аудио. | VIDEO |
