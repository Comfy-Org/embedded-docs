# Pika Soundtrack

این گره یک ترک صوتی همگام‌شده برای ویدیو با Pika تولید می‌کند. تصویر و مدت حفظ می‌شوند؛ فقط صدا جایگزین می‌شود. صدای موردنظر خود را توصیف کنید، یا دستور را خالی بگذارید تا از تصویر استخراج شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | کلیپی که باید برای آن ترک صوتی ساخته شود. حداکثر 10 دقیقه. | VIDEO | بله | - |
| `instruction` | آنچه صدا باید باشد: جلوه‌های صوتی، صدای محیط، موسیقی یا سبک. برای استخراج از تصویر خالی بگذارید. پیش‌فرض: "" (رشته خالی). | STRING | بله | 0 تا 10000 کاراکتر |
| `seed` | Seed برای نمونه‌گیری. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

**محدودیت‌ها:**

* ویدیوی ورودی باید 10 دقیقه یا کوتاه‌تر باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `VIDEO` | کلیپ ورودی با ترک صوتی تولیدشده به‌جای صدای اصلی. | VIDEO |
