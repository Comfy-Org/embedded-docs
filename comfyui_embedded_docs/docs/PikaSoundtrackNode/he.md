# Pika Soundtrack

צומת זה יוצר פסקול מסונכרן לסרטון עם Pika. התמונה והאורך נשמרים; רק האודיו מוחלף. תאר את הצליל הרצוי, או השאר את ההוראה ריקה כדי לגזור אותו מהתמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | הקליפ שעבורו יש לכתוב פסקול. עד 10 דקות. | VIDEO | כן | - |
| `instruction` | מה האודיו אמור להיות: אפקטי קול, אווירה, מוזיקה או סגנון. השאר ריק כדי לגזור אותו מהתמונה. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 0 עד 10000 תווים |
| `seed` | זרע לדגימה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים:**

* סרטון הקלט חייב להיות באורך 10 דקות או פחות.
