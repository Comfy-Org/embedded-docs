# TencentImageToModelNode

צומת זה משתמש ב-API של Tencent Hunyuan3D Pro כדי ליצור מודל תלת-ממדי מתמונה קלט אחת או יותר. הוא מעבד את התמונות, שולח אותן ל-API, ומחזיר את קבצי המודל התלת-ממדי שנוצרו בפורמטים GLB ו-OBJ, יחד עם מפות טקסטורה אופציונליות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת מודל Hunyuan3D שבה יש להשתמש. אפשרות LowPoly אינה זמינה עבור המודל `3.1`. | COMBO | כן | `"3.0"`<br>`"3.1"` |
| `image` | תמונת הקלט הראשית שמשמשת ליצירת המודל התלת-ממדי. חייבת להיות בגודל של לפחות 128x128 פיקסלים. | IMAGE | כן | - |
| `image_left` | תמונה אופציונלית של הצד השמאלי של האובייקט ליצירה מרובת-מבטים. חייבת להיות בגודל של לפחות 128x128 פיקסלים. | IMAGE | לא | - |
| `image_right` | תמונה אופציונלית של הצד הימני של האובייקט ליצירה מרובת-מבטים. חייבת להיות בגודל של לפחות 128x128 פיקסלים. | IMAGE | לא | - |
| `image_back` | תמונה אופציונלית של הצד האחורי של האובייקט ליצירה מרובת-מבטים. חייבת להיות בגודל של לפחות 128x128 פיקסלים. | IMAGE | לא | - |
| `face_count` | מספר הפאות (faces) היעד עבור המודל התלת-ממדי שנוצר (ברירת מחדל: 500000). | INT | כן | 3000 - 1500000 |
| `generate_type` | סוג המודל התלת-ממדי שיש ליצור. בחירת אפשרות חושפת פרמטרים נוספים קשורים. | DYNAMICCOMBO | כן | `"Normal"`<br>`"LowPoly"`<br>`"Geometry"` |
| `generate_type.pbr` | מפעיל יצירת חומרים בשיטת רינדור מבוסס פיזיקה (PBR). פרמטר זה מוצג רק כאשר `generate_type` מוגדר כ־"Normal" או "LowPoly" (ברירת מחדל: False). | BOOLEAN | לא | - |
| `generate_type.polygon_type` | סוג המצולע (polygon) שבו יש להשתמש עבור הרשת. פרמטר זה מוצג רק כאשר `generate_type` מוגדר כ־"LowPoly". | COMBO | לא | `"triangle"`<br>`"quadrilateral"` |
| `seed` | ערך seed עבור תהליך היצירה. ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 0). | INT | כן | 0 - 2147483647 |

**הערה:** כל תמונות הקלט חייבות להיות ברוחב ובגובה מינימליים של 128 פיקסלים. תמונות מוקטנות אוטומטית אם הן עולות על 4900 פיקסלים בצד הארוך ביותר שלהן.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | פלט מדור קודם לצורך תאימות לאחור. | STRING |
| `GLB` | המודל התלת-ממדי שנוצר בפורמט קובץ GLB (Binary GL Transmission Format). | FILE3DGLB |
| `OBJ` | המודל התלת-ממדי שנוצר בפורמט קובץ OBJ (Wavefront). | FILE3DOBJ |
| `texture_image` | תמונת הטקסטורה עבור המודל התלת-ממדי שנוצר. | IMAGE |
| `optional_metallic` | מפת מטאליות (metallic) עבור חומרי PBR. מחזיר תמונה שחורה אם אינה זמינה. | IMAGE |
| `optional_normal` | מפת נורמל (normal) עבור חומרי PBR. מחזיר תמונה שחורה אם אינה זמינה. | IMAGE |
| `optional_roughness` | מפת חספוס (roughness) עבור חומרי PBR. מחזיר תמונה שחורה אם אינה זמינה. | IMAGE |
