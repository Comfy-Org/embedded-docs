# Контекстные окна WAN (ручная настройка)

Узел Wan Context Windows (Manual) позволяет вручную настраивать контекстные окна для моделей, подобных Wan, с двумерной обработкой. Он применяет настройки контекстного окна во время сэмплирования, задавая длину окна, перекрытие, метод планирования и технику слияния, что дает вам контроль над тем, как модель обрабатывает различные контекстные области.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяются контекстные окна во время сэмплирования. | MODEL | Да | - |
| `context_length` | Длина контекстного окна в реальных кадрах. Должна быть 4*n + 1. (по умолчанию: 81) | INT | Да | 1 to 16384 (step 4) |
| `context_overlap` | Перекрытие контекстного окна в реальных кадрах. (по умолчанию: 30) | INT | Да | 0 or greater |
| `context_schedule` | Алгоритм планирования контекстных окон, зависящий от шага. (по умолчанию: "uniform_standard") | COMBO | Да | `"static_standard"`<br>`"uniform_standard"`<br>`"uniform_looped"`<br>`"batched"` |
| `context_stride` | Шаг контекстного окна; применимо только к равномерным расписаниям. (по умолчанию: 1) | INT | Да | 1 or greater |
| `closed_loop` | Замыкать ли цикл контекстного окна; применимо только к зацикленным расписаниям. (по умолчанию: False) | BOOLEAN | Да | True or False |
| `fuse_method` | Метод, используемый для слияния контекстных окон. (по умолчанию: "pyramid") | COMBO | Да | `"pyramid"`<br>`"gaussian"`<br>`"average"`<br>`"overlap"` |
| `freenoise` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон. (по умолчанию: True) | BOOLEAN | Да | True or False |
| `retain_first_frame` | Сохранять первый кадр I2V в каждом контекстном окне (может помочь сохранить исходный референс). (по умолчанию: False) | BOOLEAN | Да | True or False |
| `split_conds_to_windows` | Разделять ли несколько кондиционирований (созданных ConditionCombine) на каждое окно на основе индекса региона. (по умолчанию: False) | BOOLEAN | Да | True or False |

**Примечание:** `context_stride` влияет только на равномерные расписания, а `closed_loop` применяется только к зацикленным расписаниям. `context_length` должна соответствовать шаблону 4n + 1. Узел преобразует `context_length` и `context_overlap` из реальных кадров в единицы модели перед применением, обеспечивая минимум 1 для `context_length` и 0 для `context_overlap`. Входы `context_stride`, `closed_loop`, `freenoise` и `split_conds_to_windows` являются расширенными опциями.
