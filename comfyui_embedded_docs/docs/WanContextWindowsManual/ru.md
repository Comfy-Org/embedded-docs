# Контекстные окна WAN (ручная настройка)

Узел WAN Context Windows (Manual) позволяет вручную настраивать контекстные окна для видеомоделей Wan. Эти настройки применяются во время сэмплирования, давая вам контроль над длиной окна, перекрытием, планированием и методом слияния, используемыми при обработке видео моделью. Длина контекста и перекрытие задаются в реальных кадрах и внутренне преобразуются для 2D-обработки моделью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяются контекстные окна во время сэмплирования. | MODEL | Да | - |
| `длина_контекста` | Длина контекстного окна в реальных кадрах. Должна быть 4*n + 1 (по умолчанию: 81). | INT | Да | от 1 до 16384 (MAX_RESOLUTION), шаг 4 |
| `перекрытие_контекста` | Перекрытие контекстного окна в реальных кадрах (по умолчанию: 30). | INT | Да | 0 или выше |
| `расписание_контекста` | Алгоритм планирования контекстных окон, зависящий от шага (по умолчанию: "uniform_standard"). | COMBO | Да | `"static_standard"`<br>`"uniform_standard"`<br>`"uniform_looped"`<br>`"batched"` |
| `шаг_контекста` | Шаг контекстного окна; применим только к равномерным расписаниям (по умолчанию: 1). | INT | Да | 1 или выше |
| `замкнутый_цикл` | Замыкать ли цикл контекстного окна; применимо только к зацикленным расписаниям (по умолчанию: False). | BOOLEAN | Да | - |
| `метод_объединения` | Метод, используемый для слияния контекстных окон (по умолчанию: "pyramid"). | COMBO | Да | `"pyramid"`<br>`"gaussian"`<br>`"average"`<br>`"overlap"` |
| `freenoise` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон (по умолчанию: True). | BOOLEAN | Да | - |
| `сохранить первый кадр` | Сохранять первый кадр I2V в каждом контекстном окне (может помочь сохранить исходный референс) (по умолчанию: False). | BOOLEAN | Да | - |
| `разделить условия по окнам` | Разделять ли несколько кондишинов (созданных узлом ConditionCombine) по каждому окну на основе индекса региона (по умолчанию: False). | BOOLEAN | Да | - |

**Примечание:** `context_stride` влияет только на равномерные расписания, а `closed_loop` применим только к зацикленным расписаниям. Длина контекста и перекрытие задаются в реальных кадрах и автоматически преобразуются и ограничиваются минимальными допустимыми значениями во время обработки (`context_length` становится ((length - 1) / 4) + 1, `context_overlap` становится overlap / 4). `context_length` должна иметь форму 4*n + 1. `retain_first_frame` предназначен для использования в режиме «изображение-в-видео». `split_conds_to_windows` ожидает несколько кондишинов, созданных узлом ConditionCombine. Параметр `fuse_method` включает несколько опций помимо просто "pyramid".

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с примененной конфигурацией контекстных окон. | MODEL |
