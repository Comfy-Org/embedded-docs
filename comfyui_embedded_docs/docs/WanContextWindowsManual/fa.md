# پنجره‌های زمینه WAN (دستی)

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که در طول نمونه‌گیری، پنجره‌های زمینه روی آن اعمال می‌شود. | MODEL | بله | - |
| `طول پنجره زمینه` | طول پنجره زمینه بر حسب فریم‌های واقعی. باید به شکل 4*n + 1 باشد (پیش‌فرض: 81). | INT | بله | 1 تا 16384 (MAX_RESOLUTION)، گام 4 |
| `همپوشانی پنجره زمینه` | هم‌پوشانی پنجره زمینه بر حسب فریم‌های واقعی (پیش‌فرض: 30). | INT | بله | 0 یا بالاتر |
| `زمان‌بندی پنجره زمینه` | الگوریتم زمان‌بندی وابسته به گام برای پنجره‌های زمینه (پیش‌فرض: `"uniform_standard"`). | COMBO | بله | `"static_standard"`<br>`"uniform_standard"`<br>`"uniform_looped"`<br>`"batched"` |
| `گام پنجره زمینه` | گام پنجره زمینه؛ فقط برای زمان‌بندی‌های یکنواخت قابل استفاده است (پیش‌فرض: 1). | INT | بله | 1 یا بالاتر |
| `حلقه بسته` | آیا حلقه پنجره زمینه بسته شود؛ فقط برای زمان‌بندی‌های حلقه‌ای قابل استفاده است (پیش‌فرض: False). | BOOLEAN | بله | - |
| `روش ادغام` | روش مورد استفاده برای ادغام پنجره‌های زمینه (پیش‌فرض: `"pyramid"`). | COMBO | بله | `"pyramid"`<br>`"gaussian"`<br>`"average"`<br>`"overlap"` |
| `freenoise` | آیا درهم‌ریزی نویز FreeNoise اعمال شود؛ ترکیب پنجره‌ها را بهبود می‌بخشد (پیش‌فرض: True). | BOOLEAN | بله | - |
| `حفظ اولین فریم` | نگه‌داشتن اولین فریم I2V در هر پنجره زمینه (ممکن است به حفظ مرجع اولیه کمک کند) (پیش‌فرض: False). | BOOLEAN | بله | - |
| `تقسیم شرایط به پنجره‌ها` | آیا چندین conditioning (ایجاد شده توسط ConditionCombine) بر اساس شاخص منطقه به هر پنجره تقسیم شوند (پیش‌فرض: False). | BOOLEAN | بله | - |

**نکته:** `context_stride` فقط بر زمان‌بندی‌های یکنواخت تأثیر می‌گذارد و `closed_loop` فقط برای زمان‌بندی‌های حلقه‌ای اعمال می‌شود. طول و هم‌پوشانی زمینه بر حسب فریم‌های واقعی مشخص می‌شوند و در طول پردازش به‌صورت خودکار تبدیل و به حداقل مقادیر معتبر محدود می‌شوند (`context_length` به ((length - 1) / 4) + 1 و `context_overlap` به overlap / 4 تبدیل می‌شود). `context_length` باید به شکل 4*n + 1 باشد. `retain_first_frame` برای استفاده تصویر-به-ویدیو در نظر گرفته شده است. `split_conds_to_windows` انتظار چندین conditioning ایجاد شده توسط گره ConditionCombine را دارد. پارامتر `fuse_method` شامل چندین گزینه فراتر از فقط `"pyramid"` است.
