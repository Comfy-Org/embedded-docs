# AV Latentを結合

LTXVConcatAVLatentノードは、ビデオ潜在変数とオーディオ潜在変数を1つの結合潜在変数に統合し、LTXVやMiniMax H3などの音声・映像モデルで使用できるようにします。両方の入力の`samples`をまとめてバンドルし、いずれかの入力に`noise_mask`が含まれている場合は、それらのマスクも同様にバンドルします。ビデオ潜在変数がすでにAV潜在変数である場合、このノードはそのビデオストリームを保持し、オーディオストリームを指定されたオーディオ潜在変数で置き換えます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `video_latent` | ビデオデータの潜在表現。 | LATENT | はい |  |
| `audio_latent` | ビデオ潜在変数と組み合わせるオーディオデータの潜在表現。 | LATENT | はい |  |

**オーディオ長に関する注意:** `video_latent`がすでにAV潜在変数である場合、`audio_latent`は埋め込まれたオーディオストリームと、1つの次元を除くすべての次元で一致している必要があります。ノードは、その次元に沿ってオーディオをトリミングまたはゼロパディングし、既存のストリーム長に適合させます。パディングされた末尾はマスクされないまま残されるため、モデルがそれを生成できます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `latent` | ペアになったビデオとオーディオの`samples`を含む潜在変数。いずれかの入力が`noise_mask`を提供する場合、出力にはペアになった`noise_mask`も含まれます。欠落しているマスクは1に置き換えられます。 | LATENT |
