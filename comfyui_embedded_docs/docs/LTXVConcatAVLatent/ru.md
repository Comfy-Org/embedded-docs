# Объединить AV-латент

Узел LTXVConcatAVLatent объединяет видеолатент и аудиолатент в единый совместный латент для использования с аудиовизуальными моделями, такими как LTXV или MiniMax H3. Он объединяет `samples` из обоих входов вместе, и если любой из входов содержит `noise_mask`, эти маски также объединяются. Если видеолатент уже является AV-латентным, узел сохраняет его видеопоток и заменяет его аудиопоток предоставленным аудиолатентом.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `video_latent` | Латентное представление видеоданных. | LATENT | Да |  |
| `audio_latent` | Латентное представление аудиоданных для объединения с видеолатентом. | LATENT | Да |  |

**Примечание о длине аудио:** Когда `video_latent` уже является AV-латентным, `audio_latent` должен совпадать со встроенным аудиопотоком по всем измерениям, кроме одного. Узел обрезает или дополняет нулями аудио по этому измерению, чтобы соответствовать длине существующего потока. Дополненный хвост остаётся без маски, чтобы модель могла его сгенерировать.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Латент, содержащий парные видеоданные и аудиоданные `samples`. Если любой из входов предоставляет `noise_mask`, выход также содержит парный `noise_mask`; отсутствующая маска заменяется единицами. | LATENT |
