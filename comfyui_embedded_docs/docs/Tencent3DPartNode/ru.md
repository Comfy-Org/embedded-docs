# Hunyuan3D: 3D Part

Этот узел использует API Tencent Hunyuan3D для автоматического определения и создания компонентов 3D-модели на основе её структуры. Он принимает FBX-модель, обрабатывает её и возвращает новый FBX-файл.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-модель в формате FBX. Модель должна содержать менее 30000 граней. | FILE3D | Да | FBX, Any |
| `seed` | Сид управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Нет | 0 до 2147483647 |

**Примечание:** Входной параметр `model_3d` поддерживает только файлы в формате FBX. Если указан другой 3D-формат файла, узел вызовет ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `FBX` | Обработанная 3D-модель, возвращаемая в виде FBX-файла. | FILE3DFBX |
