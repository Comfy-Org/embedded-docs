# Hunyuan3D: 3D Part

Этот узел использует API Tencent Hunyuan3D для автоматического анализа 3D-модели и определения или генерации её компонентов на основе структуры модели. Он обрабатывает модель и возвращает новый FBX-файл.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-модель в формате FBX. Модель должна содержать менее 30 000 граней. | FILE3D | Да | FBX, Any |
| `seed` | Значение `seed` определяет, нужно ли перезапускать узел; результаты недетерминированы вне зависимости от seed. (по умолчанию: 0) | INT | Нет | 0 to 2147483647 |

**Примечание:** Входной параметр `model_3d` поддерживает только файлы в формате FBX. Если указан другой 3D-формат, узел выдаст ошибку.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `FBX` | Обработанная 3D-модель, возвращаемая в виде FBX-файла. | FILE3DFBX |
