# Hunyuan3D：3Dパーツ

このノードは、Tencent Hunyuan3D API を使用して3Dモデルを自動解析し、モデルの構造に基づいてそのコンポーネントを識別または生成します。モデルを処理し、新しいFBXファイルを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | FBX形式の3Dモデル。モデルは30000フェイス未満である必要があります。 | FILE3D | はい | FBX, Any |
| `seed` | シードは、ノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です。（デフォルト：0） | INT | いいえ | 0 to 2147483647 |

**注：** `model_3d` 入力はFBX形式のファイルのみをサポートします。異なる3Dファイル形式が指定された場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `FBX` | 処理された3Dモデル。FBXファイルとして返されます。 | FILE3DFBX |
