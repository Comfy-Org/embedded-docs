# Hunyuan3D: بخش سه‌بعدی

این گره از API تن‌سنت Hunyuan3D برای تحلیل خودکار یک مدل سه‌بعدی استفاده می‌کند و اجزای آن را بر اساس ساختار مدل شناسایی یا تولید می‌کند. این گره مدل را پردازش کرده و یک فایل FBX جدید بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | مدل سه‌بعدی در قالب FBX. مدل باید کمتر از ۳۰۰۰۰ وجه داشته باشد. | FILE3D | بله | FBX, Any |
| `seed` | عدد ثابت (Seed) کنترل می‌کند که گره آیا دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. (پیش‌فرض: 0) | INT | خیر | 0 to 2147483647 |

**توجه:** ورودی `model_3d` فقط از فایل‌های با قالب FBX پشتیبانی می‌کند. اگر قالب سه‌بعدی دیگری ارائه شود، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `FBX` | مدل سه‌بعدی پردازش‌شده، که به‌صورت فایل FBX بازگردانده می‌شود. | FILE3DFBX |
