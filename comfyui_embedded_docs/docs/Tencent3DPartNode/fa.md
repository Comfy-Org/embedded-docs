# Hunyuan3D: بخش سه‌بعدی

این گره از API شرکت Tencent Hunyuan3D استفاده می‌کند تا اجزای یک مدل سه‌بعدی را به‌طور خودکار بر اساس ساختار آن شناسایی و تولید کند. این گره یک مدل FBX را دریافت می‌کند، آن را پردازش کرده و یک فایل FBX جدید بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل سه‌بعدی` | مدل سه‌بعدی در قالب FBX. مدل باید کمتر از ۳۰۰۰۰ وجه داشته باشد. | FILE3D | بله | FBX, Any |
| `بذر` | مقدار seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از seed غیرقطعی هستند. (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

**نکته:** ورودی `model_3d` فقط از فایل‌های با فرمت FBX پشتیبانی می‌کند. اگر فرمت سه‌بعدی دیگری ارائه شود، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `FBX` | مدل سه‌بعدی پردازش‌شده، به‌صورت یک فایل FBX بازگردانده می‌شود. | FILE3DFBX |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Tencent3DPartNode/fa.md)
