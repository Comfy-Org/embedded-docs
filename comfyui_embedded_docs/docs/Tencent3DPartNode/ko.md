# Hunyuan3D: 3D 파트

이 노드는 Tencent Hunyuan3D API를 사용하여 3D 모델을 자동으로 분석하고 모델 구조를 기반으로 구성 요소를 식별하거나 생성합니다. 모델을 처리하고 새로운 FBX 파일을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | FBX 형식의 3D 모델입니다. 모델은 30000개 미만의 면을 가져야 합니다. | FILE3D | 예 | FBX, Any |
| `seed` | 시드는 노드가 다시 실행되어야 하는지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 0) | INT | 아니요 | 0 to 2147483647 |

**참고:** `model_3d` 입력은 FBX 형식의 파일만 지원합니다. 다른 3D 파일 형식이 제공되면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `FBX` | 처리된 3D 모델로, FBX 파일로 반환됩니다. | FILE3DFBX |
