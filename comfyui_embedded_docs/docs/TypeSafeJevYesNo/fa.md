# TypeSafe Jev (Yes/No)

گره TypeSafe Jev (Yes/No) یک پرسش بله/خیر دربارهٔ متن، تصاویر یا هر دوی متصل‌شده می‌پرسد و پاسخ را به‌صورت یک مقدار بولی برمی‌گرداند. `result` را به گره If/Else Switch متصل کنید تا جریان کار مسیریابی شود، یا `probability` را بخوانید تا بر اساس میزان اطمینان مدل تصمیم بگیرید. این یک گره API است: روی سرورهای Comfy اجرا می‌شود و به حساب Comfy.org با اعتبار نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | پرسش بله/خیری که متن و تصاویر متصل به آن پاسخ می‌دهند. آن را طوری بپرسید که «بله» همان حالتی باشد که می‌خواهید بر اساس آن اقدام کنید؛ وقتی چند سوکت تصویر دارید، از نام آن‌ها استفاده کنید، برای مثال `Does image_2 show the same person as image_1?` (پیش‌فرض: `Is there a person in the image?`). | STRING | بله | 1 تا 1000 نویسه |
| `threshold` | پاسخ «بله» است وقتی احتمال «بله» دست‌کم برابر این مقدار باشد (پیش‌فرض: 0.5). | FLOAT | بله | 0.01 تا 0.99 (گام: 0.01) |
| `images` | تصاویری که پرسش دربارهٔ آن‌هاست. در مجموع حداکثر 32 تصویر؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود. ضلع بلند هر تصویر بر اساس تعداد کل تصاویر محدود می‌شود: 1568 پیکسل برای حداکثر 4 تصویر، 1024 پیکسل برای حداکثر 8 تصویر، 768 پیکسل برای حداکثر 16 تصویر و 512 پیکسل برای حداکثر 32 تصویر؛ بنابراین دستهٔ بزرگ‌تر به معنای جزئیات کمتر در هر تصویر است. | AUTOGROW | خیر | 0 تا 32 تصویر |
| `text` | متنی که پرسش دربارهٔ آن است، مانند یک پرامپت یا پاسخ یک LLM. | STRING | خیر | 0 تا 3000 نویسه |

**نکته‌ها:**

- متن یا دست‌کم یک تصویر را متصل کنید؛ اگر هر دو خالی باشند، گره خطا می‌دهد.
- `result` وقتی `probability` دست‌کم برابر `threshold` باشد درست است، و `answer` همان حکم را به‌صورت `yes` یا `no` برمی‌گرداند.
- صورت‌حساب بر پایهٔ توکن است؛ نشان قیمت روی گره نرخ تقریبی را به ازای هر 1 میلیون توکن نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `result` | پاسخ به‌صورت یک مقدار بولی: درست وقتی احتمال «بله» دست‌کم برابر `threshold` باشد. | BOOLEAN |
| `answer` | پاسخ به‌صورت متن `yes` یا `no`. | STRING |
| `probability` | احتمال «بله»، از 0 (قطعاً خیر) تا 1 (قطعاً بله). | FLOAT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TypeSafeJevYesNo/fa.md)
