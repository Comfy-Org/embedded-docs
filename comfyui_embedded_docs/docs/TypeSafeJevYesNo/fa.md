# TypeSafe Jev (Yes/No)

گره TypeSafe Jev (Yes/No) یک پرسش بله یا خیر درباره متن، تصاویر یا هر دو مورد متصل می‌پرسد و پاسخ را به‌صورت یک مقدار بولی برمی‌گرداند. `result` را به گره If/Else Switch متصل کنید تا گردش‌کار مسیریابی شود، یا `probability` را بخوانید تا بر اساس میزان اطمینان مدل اقدام کنید. این یک گره API است و به حساب Comfy.org و کلید API نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev که استفاده می‌شود. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | پرسش بله یا خیری که متن و تصاویر متصل به آن پاسخ می‌دهند. آن را طوری بپرسید که «بله» همان حالتی باشد که بر اساس آن اقدام می‌کنید؛ اگر چند سوکت تصویر دارید، از نام آن‌ها استفاده کنید، مثلاً `Does image_2 show the same person as image_1?` (پیش‌فرض: `Is there a person in the image?`). | STRING | بله | 1 تا 1000 نویسه |
| `threshold` | پاسخ وقتی بله است که احتمال بله بودن حداقل این مقدار باشد (پیش‌فرض: 0.5). | FLOAT | بله | 0.01 تا 0.99 (گام 0.01) |
| `images` | تصاویری که پرسش درباره آن‌هاست. در مجموع حداکثر 32 تصویر؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود و بیش از 4 تصویر با اندازه کوچک‌تر ارسال می‌شوند. | AUTOGROW | خیر | 0 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند یک پرامپت یا پاسخ یک LLM. | STRING | خیر | 0 تا 3000 نویسه |

**نکته‌ها:**

- متن یا حداقل یک تصویر را متصل کنید؛ اگر هر دو خالی باشند، گره خطا می‌دهد.
- `result` وقتی true است که `probability` حداقل برابر `threshold` باشد، و `answer` همان حکم را به‌صورت `yes` یا `no` برمی‌گرداند.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره نرخ تقریبی به‌ازای هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `result` | پاسخ به‌صورت یک مقدار بولی: true وقتی احتمال بله بودن حداقل `threshold` باشد. | BOOLEAN |
| `answer` | پاسخ به‌صورت متن `yes` یا `no`. | STRING |
| `probability` | احتمال بله بودن، از 0 (قطعاً خیر) تا 1 (قطعاً بله). | FLOAT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TypeSafeJevYesNo/fa.md)
