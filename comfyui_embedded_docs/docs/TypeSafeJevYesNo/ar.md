# TypeSafe Jev (Yes/No)

تطرح عقدة TypeSafe Jev (Yes/No) سؤالاً بنعم أو لا حول النص أو الصور المتصلة، أو كليهما، وتعيد الإجابة على هيئة قيمة منطقية. صِل `result` بعقدة If/Else Switch لتوجيه سير العمل، أو اقرأ `probability` للتصرف بناءً على مدى ثقة النموذج. هذه عقدة API وتتطلب حساب Comfy.org ومفتاح API.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج Jev المراد استخدامه. يتوفر حالياً نموذج واحد فقط: `jev-1.14.0`. | COMBO | نعم | `"jev-1.14.0"` |
| `question` | السؤال بنعم أو لا الذي يجيب عنه النص والصور المتصلة. اطرحه بحيث تكون حالة "نعم" هي الحالة التي تريد التصرف بناءً عليها؛ عند وجود عدة منافذ صور، استخدم أسماءها، على سبيل المثال `Does image_2 show the same person as image_1?` (الافتراضي: `Is there a person in the image?`). | STRING | نعم | 1 إلى 1000 حرف |
| `threshold` | تكون الإجابة بنعم عندما يكون احتمال نعم على الأقل هذه القيمة (الافتراضي: 0.5). | FLOAT | نعم | 0.01 إلى 0.99 (خطوة 0.01) |
| `images` | الصور التي يدور حولها السؤال. حتى 32 صورة إجمالاً؛ يُحتسب الإدخال الدفعي مرة واحدة لكل صورة، وتُرسل أكثر من 4 صور بحجم أصغر. | AUTOGROW | لا | 0 إلى 32 صورة |
| `text` | النص الذي يدور حوله السؤال، مثل موجه أو استجابة LLM. | STRING | لا | 0 إلى 3000 حرف |

**ملاحظات:**

- صِل النص أو صورة واحدة على الأقل؛ تُطلق العقدة خطأً عندما يكون كلاهما فارغاً.
- يكون `result` صحيحاً عندما يكون `probability` على الأقل `threshold`، وتعيد `answer` الحكم نفسه على هيئة `yes` أو `no`.
- تعتمد الفوترة على الرموز (tokens)؛ تعرض شارة السعر على العقدة المعدل التقريبي لكل مليون رمز.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `result` | الإجابة كقيمة منطقية: صحيح عندما يكون احتمال نعم على الأقل `threshold`. | BOOLEAN |
| `answer` | الإجابة كنص `yes` أو `no`. | STRING |
| `probability` | احتمال نعم، من 0 (لا بالتأكيد) إلى 1 (نعم بالتأكيد). | FLOAT |
