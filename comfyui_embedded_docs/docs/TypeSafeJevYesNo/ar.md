# TypeSafe Jev (Yes/No)

تطرح عقدة TypeSafe Jev (نعم/لا) سؤالًا بالإجابة نعم أو لا حول نص أو صور متصلة أو كليهما، وتعيد الإجابة كقيمة منطقية. صِل `result` بعقدة If/Else Switch لتوجيه سير العمل، أو اقرأ `probability` للتصرف بناءً على مدى ثقة النموذج. هذه عقدة API: تعمل على خوادم Comfy وتتطلب حساب Comfy.org مع أرصدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج Jev المراد استخدامه. يتوفر حاليًا نموذج واحد فقط: `jev-1.14.0`. | COMBO | نعم | `"jev-1.14.0"` |
| `question` | السؤال الذي تجيب عنه النصوص والصور المتصلة بـ نعم أو لا. اطرحه بحيث تكون الحالة التي تريد التصرف بناءً عليها هي "نعم"؛ عند وجود عدة منافذ صور، استخدم أسماءها، على سبيل المثال `Does image_2 show the same person as image_1?` (الافتراضي: `Is there a person in the image?`). | STRING | نعم | 1 إلى 1000 حرف |
| `threshold` | تكون الإجابة نعم عندما تكون احتمالية نعم على الأقل هذه القيمة (الافتراضي: 0.5). | FLOAT | نعم | 0.01 إلى 0.99 (خطوة 0.01) |
| `images` | الصور التي يتعلق بها السؤال. حتى 32 صورة إجمالًا؛ يُحتسب الإدخال المجمّع مرة واحدة لكل صورة. يُقيَّد الجانب الطويل لكل صورة بالعدد الإجمالي للصور: 1568 بكسل لما يصل إلى 4 صور، و1024 بكسل لما يصل إلى 8، و768 بكسل لما يصل إلى 16، و512 بكسل لما يصل إلى 32، لذا تعني الدفعة الأكبر تفاصيل أقل في كل صورة. | AUTOGROW | لا | 0 إلى 32 صورة |
| `text` | النص الذي يتعلق به السؤال، مثل موجّه أو استجابة LLM. | STRING | لا | 0 إلى 3000 حرف |

**ملاحظات:**

- صِل نصًا أو صورة واحدة على الأقل؛ ترفع العقدة خطأً عندما يكون كلاهما فارغًا.
- تكون `result` بقيمة true عندما تكون `probability` على الأقل `threshold`، وتعيد `answer` الحكم نفسه بصيغة `yes` أو `no`.
- الفوترة قائمة على الرموز؛ تعرض شارة السعر على العقدة المعدل التقريبي لكل مليون رمز.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `result` | الإجابة كقيمة منطقية: true عندما تكون احتمالية نعم على الأقل `threshold`. | BOOLEAN |
| `answer` | الإجابة كنص `yes` أو `no`. | STRING |
| `probability` | احتمالية نعم، من 0 (لا بالتأكيد) إلى 1 (نعم بالتأكيد). | FLOAT |
