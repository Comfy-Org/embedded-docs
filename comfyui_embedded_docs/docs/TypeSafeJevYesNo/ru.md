# TypeSafe Jev (Yes/No)

Узел TypeSafe Jev (Yes/No) задаёт вопрос с ответом «да» или «нет» о подключённом тексте, изображениях или о том и другом вместе и возвращает ответ в виде логического значения. Подключите `result` к узлу If/Else Switch, чтобы управлять ветвлением рабочего процесса, или считайте `probability`, чтобы действовать с учётом уверенности модели. Это API-узел: он выполняется на серверах Comfy и требует учётной записи Comfy.org с кредитами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель Jev. Сейчас доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Вопрос с ответом «да» или «нет», на который отвечают подключённые текст и изображения. Формулируйте его так, чтобы «да» соответствовало случаю, по которому вы хотите действовать; если используется несколько слотов изображений, указывайте их имена, например `Does image_2 show the same person as image_1?` (по умолчанию: `Is there a person in the image?`). | STRING | Да | от 1 до 1000 символов |
| `threshold` | Ответ считается «да», если вероятность ответа «да» не меньше этого значения (по умолчанию: 0.5). | FLOAT | Да | от 0.01 до 0.99 (шаг 0.01) |
| `images` | Изображения, к которым относится вопрос. Всего до 32 изображений; вход с пакетом изображений учитывается отдельно для каждого изображения. Длинная сторона каждого изображения ограничивается в зависимости от общего количества изображений: 1568 px при количестве до 4 изображений, 1024 px — при количестве до 8, 768 px — при количестве до 16 и 512 px — при количестве до 32, поэтому больший пакет может снизить детализацию каждого изображения. | AUTOGROW | Нет | от 0 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Подключите текст или хотя бы одно изображение; если и текст, и изображения пусты, узел выдаёт ошибку.
- `result` равно true, если `probability` не меньше `threshold`, а `answer` возвращает тот же вердикт в виде `yes` или `no`.
- Оплата рассчитывается по токенам; значок цены на узле показывает приблизительную стоимость за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `result` | Ответ в виде логического значения: true, если вероятность ответа «да» не меньше `threshold`. | BOOLEAN |
| `answer` | Ответ в виде текста `yes` или `no`. | STRING |
| `probability` | Вероятность ответа «да»: от 0 (однозначно нет) до 1 (однозначно да). | FLOAT |
