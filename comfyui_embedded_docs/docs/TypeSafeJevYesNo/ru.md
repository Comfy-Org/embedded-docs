# TypeSafe Jev (Yes/No)

Узел TypeSafe Jev (Yes/No) задаёт вопрос «да/нет» по подключённому тексту, изображениям или и тому и другому и возвращает ответ в виде логического значения. Подключите `result` к узлу If/Else Switch, чтобы маршрутизировать рабочий процесс, или считывайте `probability`, чтобы действовать с учётом уверенности модели. Это API-узел, для него требуются учётная запись Comfy.org и API-ключ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель Jev. Сейчас доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Вопрос «да/нет», на который отвечают подключённые текст и изображения. Задайте его так, чтобы «да» означало тот случай, для которого нужно выполнить действие; при наличии нескольких сокетов изображений используйте их имена, например `Does image_2 show the same person as image_1?` (по умолчанию: `Is there a person in the image?`). | STRING | Да | от 1 до 1000 символов |
| `threshold` | Ответ считается «да», когда вероятность «да» не меньше этого значения (по умолчанию: 0.5). | FLOAT | Да | от 0.01 до 0.99 (шаг 0.01) |
| `images` | Изображения, к которым относится вопрос. Всего до 32 изображений; пакетный вход учитывается по одному разу на каждое изображение, а при более чем 4 изображениях они отправляются в меньшем размере. | AUTOGROW | Нет | от 0 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Подключите текст или хотя бы одно изображение; если и то и другое пусто, узел выдаёт ошибку.
- `result` имеет значение true, когда `probability` не меньше `threshold`, а `answer` возвращает тот же вердикт в виде `yes` или `no`.
- Оплата основана на токенах; значок цены на узле показывает приблизительную стоимость за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `result` | Ответ в виде логического значения: true, когда вероятность ответа «да» не меньше `threshold`. | BOOLEAN |
| `answer` | Ответ в виде текста `yes` или `no`. | STRING |
| `probability` | Вероятность ответа «да»: от 0 (определённо «нет») до 1 (определённо «да»). | FLOAT |
