# TypeSafe Jev (Yes/No)

TypeSafe Jev (Yes/No) ノードは、接続されたテキスト、画像、またはその両方について Yes/No の質問を行い、その回答をブール値として返します。`result` を If/Else Switch ノードに接続してワークフローを分岐させたり、`probability` を読み取ってモデルの確信度に基づいた処理を行ったりできます。これは API ノードです。Comfy のサーバー上で実行され、クレジットを保有する Comfy.org アカウントが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデルです。現在利用可能なモデルは 1 つだけです：`jev-1.14.0`。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 接続されたテキストと画像が答える Yes/No の質問です。yes の場合に実行したい処理となるように質問してください。複数の画像ソケットがある場合は、その名前を使用します。例えば `Does image_2 show the same person as image_1?` のように指定します（デフォルト：`Is there a person in the image?`）。 | STRING | はい | 1～1000 文字 |
| `threshold` | yes の確率がこの値以上の場合、回答は yes になります（デフォルト：0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問の対象となる画像です。合計で最大 32 枚まで指定できます。バッチ入力は画像 1 枚につき 1 回としてカウントされます。各画像の長辺は画像の総数によって制限されます。最大 4 枚の場合は 1568 px、最大 8 枚の場合は 1024 px、最大 16 枚の場合は 768 px、最大 32 枚の場合は 512 px となるため、バッチサイズが大きいほど各画像のディテールが低下する可能性があります。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキストです。プロンプトや LLM の応答などが該当します。 | STRING | いいえ | 0～3000 文字 |

**注意：**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合はノードがエラーを発生します。
- `probability` が `threshold` 以上の場合、`result` は true になり、`answer` は `yes` または `no` として同じ判定を返します。
- 課金はトークンベースです。ノード上の価格バッジには、100 万トークンあたりの概算レートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `result` | 回答をブール値で表します。yes の確率が `threshold` 以上の場合に true になります。 | BOOLEAN |
| `answer` | 回答を `yes` または `no` というテキストで表します。 | STRING |
| `probability` | yes の確率で、0（間違いなく no）から 1（間違いなく yes）までの値です。 | FLOAT |
