# TypeSafe Jev (Yes/No)

TypeSafe Jev (Yes/No) ノードは、接続されたテキスト、画像、またはその両方について「はい」か「いいえ」で答える質問を行い、回答をブール値として返します。`result` を If/Else Switch ノードに接続してワークフローを分岐させるか、`probability` を読み取ってモデルがどれだけ確信しているかに基づいて処理できます。これは API ノードです。Comfy のサーバー上で実行され、クレジット付きの Comfy.org アカウントが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデルです。現在利用可能なモデルは 1 つだけです：`jev-1.14.0`。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 接続されたテキストや画像が答える「はい」か「いいえ」の質問です。「はい」の場合に実行したい処理になるように質問してください。複数の画像ソケットがある場合は、それらの名前を使用します。例：`Does image_2 show the same person as image_1?`（デフォルト：`Is there a person in the image?`）。 | STRING | はい | 1～1000 文字 |
| `threshold` | 「はい」の確率がこの値以上の場合、回答は「はい」になります（デフォルト：0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問の対象となる画像です。合計 32 枚までです。バッチ入力は画像 1 枚につき 1 回として数えられます。各画像の長辺は総画像数によって上限が決まります。4 枚までなら 1568 px、8 枚までなら 1024 px、16 枚までなら 768 px、32 枚までなら 512 px です。したがって、バッチが大きいほど各画像の詳細は少なくなります。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキストです。プロンプトや LLM の応答などが該当します。 | STRING | いいえ | 0～3000 文字 |

**注意事項：**

- テキストまたは少なくとも 1 枚の画像を接続する必要があります。両方が空の場合、ノードはエラーを発生させます。
- `probability` が `threshold` 以上の場合、`result` は true になり、`answer` は同じ判定を `yes` または `no` として返します。
- 課金はトークンベースです。ノード上の料金バッジには、100 万トークンあたりの概算レートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `result` | ブール値としての回答です。「はい」の確率が `threshold` 以上の場合に true になります。 | BOOLEAN |
| `answer` | テキスト `yes` または `no` としての回答です。 | STRING |
| `probability` | 「はい」の確率で、0（間違いなくいいえ）から 1（間違いなくはい）までです。 | FLOAT |
