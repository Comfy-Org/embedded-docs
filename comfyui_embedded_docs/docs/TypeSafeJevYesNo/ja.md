# TypeSafe Jev (Yes/No)

TypeSafe Jev (Yes/No) ノードは、接続されたテキスト、画像、またはその両方について「はい」か「いいえ」で答える質問を投げかけ、その回答をブール値として返します。`result` を If/Else Switch ノードに接続してワークフローを分岐させるか、`probability` を読み取ってモデルがどれだけ確信しているかに基づいて処理できます。これは API ノードであり、Comfy.org アカウントと API キーが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデル。現在利用できるモデルは 1 つだけです：`jev-1.14.0`。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 接続されたテキストと画像が答える「はい/いいえ」の質問。質問は、はいの場合に実行したい処理になるように尋ねてください。複数の画像ソケットがある場合は、その名前を使用します。たとえば `Does image_2 show the same person as image_1?`（デフォルト：`Is there a person in the image?`）。 | STRING | はい | 1～1000 文字 |
| `threshold` | 「はい」の確率が少なくともこの値以上の場合に、回答は「はい」になります（デフォルト：0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問の対象となる画像。合計で最大 32 枚の画像を指定できます。バッチ入力は画像 1 枚ごとに 1 回として数えられ、4 枚を超える画像はより小さいサイズで送信されます。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキスト（プロンプトや LLM の応答など）。 | STRING | いいえ | 0～3000 文字 |

**注意：**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合、ノードはエラーを発生させます。
- `result` は `probability` が `threshold` 以上の場合に true になり、`answer` は同じ判定を `yes` または `no` として返します。
- 課金はトークン単位です。ノード上の料金バッジには、100 万トークンあたりのおおよその料金が表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `result` | ブール値としての回答：はいの確率が `threshold` 以上の場合に true。 | BOOLEAN |
| `answer` | テキスト `yes` または `no` としての回答。 | STRING |
| `probability` | はいの確率（0 は確実にいいえ、1 は確実にはい）。 | FLOAT |
