# TypeSafe Jev (Yes/No)

צומת TypeSafe Jev (Yes/No) שואל שאלת כן/לא לגבי טקסט, תמונות או שניהם המחוברים, ומחזיר את התשובה כערך בוליאני. חבר את `result` לצומת If/Else Switch כדי לנתב את זרימת העבודה, או קרא את `probability` כדי לפעול לפי מידת הביטחון של המודל. זהו צומת API: הוא פועל בשרתים של Comfy ודורש חשבון Comfy.org עם קרדיטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. כרגע זמין מודל אחד בלבד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | שאלת כן/לא שהטקסט והתמונות המחוברים עונים עליה. נסח אותה כך שהתשובה החיובית תהיה המקרה שעליו אתה פועל; כאשר יש מספר שקעי תמונות, השתמש בשמותיהם, לדוגמה `Does image_2 show the same person as image_1?` (ברירת מחדל: `Is there a person in the image?`). | STRING | כן | 1 עד 1000 תווים |
| `threshold` | התשובה חיובית כאשר ההסתברות לתשובה חיובית היא לפחות הערך הזה (ברירת מחדל: 0.5). | FLOAT | כן | 0.01 עד 0.99 (צעד 0.01) |
| `images` | התמונות שהשאלה עוסקת בהן. עד 32 תמונות בסך הכול; קלט באצווה נספר פעם אחת לכל תמונה. הצד הארוך של כל תמונה מוגבל לפי מספר התמונות הכולל: 1568 px עבור עד 4 תמונות, 1024 px עבור עד 8, 768 px עבור עד 16 ו-512 px עבור עד 32, כך שאצווה גדולה יותר יכולה להפחית את הפרטים בכל תמונה. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובה של LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חבר טקסט או לפחות תמונה אחת; הצומת מעלה שגיאה כאשר שניהם ריקים.
- `result` מחזיר true כאשר `probability` הוא לפחות `threshold`, ו-`answer` מחזיר את אותה הכרעה בתור `yes` או `no`.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל מיליון טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `result` | התשובה כערך בוליאני: true כאשר ההסתברות לתשובה חיובית היא לפחות `threshold`. | BOOLEAN |
| `answer` | התשובה כטקסט `yes` או `no`. | STRING |
| `probability` | ההסתברות לתשובה חיובית, מ-0 (בהחלט לא) עד 1 (בהחלט כן). | FLOAT |
