# TypeSafe Jev (Yes/No)

צומת TypeSafe Jev (Yes/No) שואל שאלת כן/לא על טקסט מחובר, תמונות או שניהם, ומחזיר את התשובה כערך בוליאני. חברו את `result` לצומת If/Else Switch כדי לנתב את זרימת העבודה, או קראו את `probability` כדי לפעול בהתאם למידת הביטחון של המודל. זהו צומת API ודורש חשבון Comfy.org ומפתח API.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. נכון לעכשיו זמין מודל אחד בלבד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | שאלת כן/לא שהטקסט והתמונות המחוברים עונים עליה. נסחו אותה כך ש"כן" יהיה המקרה שעליו אתם פועלים; כאשר יש כמה שקעי תמונות, השתמשו בשמותיהם, לדוגמה `Does image_2 show the same person as image_1?` (ברירת מחדל: `Is there a person in the image?`). | STRING | כן | 1 עד 1000 תווים |
| `threshold` | התשובה היא "כן" כאשר ההסתברות ל"כן" היא לפחות הערך הזה (ברירת מחדל: 0.5). | FLOAT | כן | 0.01 עד 0.99 (צעד 0.01) |
| `images` | התמונות שעליהן נשאלת השאלה. עד 32 תמונות בסך הכול; קלט באצווה נספר פעם אחת לכל תמונה, ויותר מ-4 תמונות נשלחות בגודל קטן יותר. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שעליו נשאלת השאלה, כגון פרומפט או תגובה של LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חברו טקסט או לפחות תמונה אחת; הצומת מעלה שגיאה כאשר שניהם ריקים.
- `result` הוא true כאשר `probability` הוא לפחות `threshold`, ו-`answer` מחזיר את אותה הכרעה בתור `yes` או `no`.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל 1M טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `result` | התשובה כערך בוליאני: true כאשר ההסתברות ל"כן" היא לפחות `threshold`. | BOOLEAN |
| `answer` | התשובה כטקסט `yes` או `no`. | STRING |
| `probability` | ההסתברות ל"כן", מ-0 (בהחלט לא) עד 1 (בהחלט כן). | FLOAT |
