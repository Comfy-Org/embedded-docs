# TypeSafe Jev (Yes/No)

צומת TypeSafe Jev (Yes/No) שואל שאלת כן/לא לגבי טקסט, תמונות או שניהם, ומחזיר את התשובה כערך בוליאני. חברו את `result` לצומת If/Else Switch כדי לנתב את זרימת העבודה, או קראו את `probability` כדי לפעול לפי מידת הביטחון של המודל. זהו צומת API: הוא פועל בשרתים של Comfy ודורש חשבון Comfy.org עם קרדיטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. נכון לעכשיו זמין רק מודל אחד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | שאלת הכן/לא שהטקסט והתמונות המחוברים עונים עליה. נסחו אותה כך ש"כן" יהיה המקרה שעליו אתם פועלים; כאשר יש כמה שקעי תמונה, השתמשו בשמותיהם, למשל `Does image_2 show the same person as image_1?` (ברירת מחדל: `Is there a person in the image?`). | STRING | כן | 1 עד 1000 תווים |
| `threshold` | התשובה היא "כן" כאשר ההסתברות ל"כן" היא לפחות הערך הזה (ברירת מחדל: 0.5). | FLOAT | כן | 0.01 עד 0.99 (צעד 0.01) |
| `images` | התמונות שהשאלה מתייחסת אליהן. עד 32 תמונות בסך הכול; קלט באצווה נספר פעם אחת לכל תמונה. הצלע הארוכה של כל תמונה מוגבלת לפי מספר התמונות הכולל: 1568 px לעד 4 תמונות, 1024 px לעד 8, 768 px לעד 16 ו-512 px לעד 32, כך שאצווה גדולה יותר משמעה פחות פירוט בכל תמונה. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שהשאלה מתייחסת אליו, כגון פרומפט או תגובה של LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חברו טקסט או לפחות תמונה אחת; הצומת מעלה שגיאה כאשר שניהם ריקים.
- `result` הוא true כאשר `probability` הוא לפחות `threshold`, ו-`answer` מחזיר את אותו פסק דין כ-`yes` או `no`.
- החיוב מבוסס טוקנים; תווית המחיר על הצומת מציגה את התעריף המשוער לכל מיליון טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `result` | התשובה כערך בוליאני: true כאשר ההסתברות ל"כן" היא לפחות `threshold`. | BOOLEAN |
| `answer` | התשובה כטקסט `yes` או `no`. | STRING |
| `probability` | ההסתברות ל"כן", מ-0 (בהחלט לא) עד 1 (בהחלט כן). | FLOAT |
