# Meshy: ریگ مدل

گره «Meshy: Rig Model» یک مدل سه‌بعدی از یک وظیفه قبلی Meshy دریافت می‌کند و به‌طور خودکار برای آن اسکلت‌بندی ایجاد می‌کند و شخصیت ریگ‌شده‌ای تولید می‌کند که قابل حالت‌دهی و انیمیشن‌سازی است. این گره مدل ریگ‌شده را در دو قالب فایل GLB و FBX خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | شناسه یکتای وظیفه از عملیات قبلی Meshy (مانند متن‌به‌سه‌بعدی یا تصویر‌به‌سه‌بعدی) که مدل موردنظر برای ریگ‌کردن را تولید کرده است. | STRING | بله | N/A |
| `height_meters` | ارتفاع تقریبی مدل شخصیت بر حسب متر. این به دقت مقیاس‌بندی و ریگ‌کردن کمک می‌کند (پیش‌فرض: 1.7). | FLOAT | بله | 0.1 تا 15.0 |
| `texture_image` | تصویر بافت رنگ پایه بازشده UV مدل. | IMAGE | خیر | N/A |

**نکته:** فرآیند ریگ‌کردن خودکار در حال حاضر برای مش‌های بدون بافت، دارایی‌های غیرانسان‌وار، یا دارایی‌های انسان‌وار با ساختار اندام و بدنه نامشخص مناسب نیست.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | یک خروجی قدیمی برای سازگاری با عقب، شامل نام فایل مدل GLB. | STRING |
| `شناسه وظیفه rig` | شناسه یکتای وظیفه برای این عملیات ریگ‌کردن، که می‌توان از آن برای ارجاع به نتیجه استفاده کرد. | STRING |
| `GLB` | مدل سه‌بعدی شخصیت ریگ‌شده ذخیره‌شده در قالب فایل GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی شخصیت ریگ‌شده ذخیره‌شده در قالب فایل FBX. | FILE3DFBX |
