# Meshy: ریگ مدل

گره Meshy: Rig Model یک مدل سه‌بعدی را از یک وظیفهٔ قبلی Meshy دریافت می‌کند و به‌طور خودکار برای آن اسکلت می‌سازد و یک کاراکتر ریگ‌شده تولید می‌کند که می‌توان آن را حالت‌دهی و انیمیت کرد. این گره مدل ریگ‌شده را در هر دو قالب فایل GLB و FBX خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | شناسهٔ وظیفهٔ یکتای یک عملیات قبلی Meshy (مثلاً text-to-3D یا image-to-3D) که مدل موردنظر برای ریگ‌کردن را تولید کرده است. | MESHY_TASK_ID | بله | N/A |
| `height_meters` | ارتفاع تقریبی مدل کاراکتر بر حسب متر. این مقدار به مقیاس‌بندی و دقت ریگ‌کردن کمک می‌کند (پیش‌فرض: 1.7). | FLOAT | بله | 0.1 تا 15.0 |
| `texture_image` | تصویر بافت رنگ پایهٔ UV بازشدهٔ مدل. | IMAGE | خیر | N/A |

**توجه:** فرایند ریگ‌کردن خودکار در حال حاضر برای مش‌های بدون بافت، دارایی‌های غیر انسان‌نما، یا دارایی‌های انسان‌نما با ساختار نامشخص اندام و بدن مناسب نیست.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | یک خروجی قدیمی که فقط برای سازگاری با نسخه‌های پیشین نگه داشته شده است و شامل نام فایل مدل GLB است. | STRING |
| `rig_task_id` | شناسهٔ وظیفهٔ یکتا برای این عملیات ریگ‌کردن، که می‌توان از آن برای ارجاع به نتیجه در گره‌های بعدی Meshy استفاده کرد. | MESHY_RIGGED_TASK_ID |
| `GLB` | مدل کاراکتر سه‌بعدی ریگ‌شده که در قالب فایل GLB ذخیره شده است. | FILE3DGLB |
| `FBX` | مدل کاراکتر سه‌بعدی ریگ‌شده که در قالب فایل FBX ذخیره شده است. | FILE3DFBX |
