# MeshyRigModelNode

צומת Meshy: Rig Model מקבל מודל תלת-ממדי ממשימת Meshy קודמת ויוצר עבורו שלד באופן אוטומטי, ומייצר דמות עם ריג שניתן להעמיד בתנוחות ולהנפיש. הצומת מוציא את המודל עם הריג הן בפורמט קובץ GLB והן בפורמט קובץ FBX.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | מזהה המשימה הייחודי מפעולת Meshy קודמת (לדוגמה, text-to-3D או image-to-3D) שיצרה את המודל שעבורו יש ליצור ריג. | MESHY_TASK_ID | כן | N/A |
| `height_meters` | הגובה המשוער של מודל הדמות במטרים. זה מסייע לדיוק בקנה מידה וביצירת ריג (ברירת מחדל: 1.7). | FLOAT | כן | 0.1 to 15.0 |
| `texture_image` | תמונת טקסטורת צבע הבסיס של המודל עם פריסת UV. | IMAGE | לא | N/A |

**הערה:** תהליך יצירת הריג האוטומטית אינו מתאים כרגע לרשתות תלת-ממד ללא טקסטורה, לנכסים שאינם דמויי אדם, או לנכסים דמויי אדם עם מבנה גפיים וגוף לא ברור.

## פלטים

| שם פלט | תיאור | סוג נתון |
|-------------|-------------|-----------|
| `model_file` | פלט מדור קודם הנשמר רק לצורך תאימות לאחור, ומכיל את שם הקובץ של מודל ה-GLB. | STRING |
| `rig_task_id` | מזהה המשימה הייחודי עבור פעולת יצירת הריג זו, שניתן להשתמש בו כדי להפנות לתוצאה בצמתי Meshy מאוחרים יותר. | MESHY_RIGGED_TASK_ID |
| `GLB` | מודל הדמות התלת-ממדי עם הריג, השמור בפורמט קובץ GLB. | FILE3DGLB |
| `FBX` | מודל הדמות התלת-ממדי עם הריג, השמור בפורמט קובץ FBX. | FILE3DFBX |
