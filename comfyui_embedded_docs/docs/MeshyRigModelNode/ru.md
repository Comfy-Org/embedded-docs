# Meshy: Скелетная Анимация Модели

Узел Meshy: Rig Model принимает 3D-модель из предыдущей задачи Meshy и автоматически создаёт для неё скелет, формируя персонажа с ригом, которого можно позировать и анимировать. Узел выводит модель с ригом в форматах GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | Уникальный ID задачи из предыдущей операции Meshy (например, text-to-3D или image-to-3D), в результате которой была создана модель для риггинга. | MESHY_TASK_ID | Да | N/A |
| `height_meters` | Приблизительная высота модели персонажа в метрах. Это помогает повысить точность масштабирования и риггинга (по умолчанию: 1.7). | FLOAT | Да | 0.1 до 15.0 |
| `texture_image` | Изображение базовой цветовой текстуры модели с UV-развёрткой. | IMAGE | Нет | N/A |

**Примечание:** Процесс автоматического риггинга в настоящее время не подходит для моделей без текстур, негуманоидных объектов или гуманоидных объектов с неясной структурой конечностей и тела.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Устаревший выход, сохранённый только для обратной совместимости, содержит имя файла GLB-модели. | STRING |
| `rig_task_id` | Уникальный ID задачи для этой операции риггинга, который можно использовать для ссылки на результат в последующих узлах Meshy. | MESHY_RIGGED_TASK_ID |
| `GLB` | Модель 3D-персонажа с ригом, сохранённая в формате GLB. | FILE3DGLB |
| `FBX` | Модель 3D-персонажа с ригом, сохранённая в формате FBX. | FILE3DFBX |
