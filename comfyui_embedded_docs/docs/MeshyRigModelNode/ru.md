# Meshy: Скелетная Анимация Модели

Узел **Meshy: Rig Model** принимает 3D-модель из предыдущей задачи Meshy и автоматически создаёт для неё скелет, формируя ригованного персонажа, которому можно задавать позы и анимировать. Узел выводит ригованную модель в двух форматах: GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | Уникальный идентификатор задачи из предыдущей операции Meshy (например, текст-в-3D или изображение-в-3D), в результате которой была создана модель для риггинга. | STRING | Да | N/A |
| `height_meters` | Приблизительная высота модели персонажа в метрах. Влияет на точность масштабирования и риггинга (по умолчанию: 1,7). | FLOAT | Да | от 0,1 до 15,0 |
| `texture_image` | Изображение базовой цветовой текстуры модели с развёрткой UV. | IMAGE | Нет | N/A |

**Примечание:** Процесс автоматического риггинга в настоящее время не подходит для моделей без текстур, негуманоидных ассетов, а также гуманоидных ассетов с нечёткой структурой конечностей и тела.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Устаревший выход для обратной совместимости, содержащий имя файла модели GLB. | STRING |
| `rig_task_id` | Уникальный идентификатор задачи для этой операции риггинга; используется для ссылки на результат. | STRING |
| `GLB` | Ригованная 3D-модель персонажа, сохранённая в формате GLB. | FILE3DGLB |
| `FBX` | Ригованная 3D-модель персонажа, сохранённая в формате FBX. | FILE3DFBX |
