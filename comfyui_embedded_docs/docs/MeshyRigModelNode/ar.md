# Meshy: تجهيز النموذج بالحركة

تأخذ عقدة Meshy: Rig Model نموذجًا ثلاثي الأبعاد من مهمة Meshy سابقة وتُنشئ له هيكلًا عظميًا تلقائيًا، مما ينتج شخصية مجهزة (Rigged) يمكن تحريكها وتوجيهها. تُخرج العقدة النموذج المجهز بصيغتي GLB و FBX.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | المعرّف الفريد لمهمة Meshy السابقة (مثل text-to-3D أو image-to-3D) التي أنشأت النموذج المراد تجهيزه. | STRING | نعم | لا ينطبق |
| `height_meters` | الارتفاع التقريبي لنموذج الشخصية بالأمتار. يساعد هذا في دقة التحجيم والتجهيز (الافتراضي: 1.7). | FLOAT | نعم | من 0.1 إلى 15.0 |
| `texture_image` | صورة نسيج اللون الأساسي المفككة (UV-unwrapped) للنموذج. | IMAGE | لا | لا ينطبق |

**ملاحظة:** عملية التجهيز التلقائي غير مناسبة حاليًا للشبكات غير المزودة بنسيج، أو الأصول غير البشرية، أو الأصول البشرية ذات بنية أطراف وأجسام غير واضحة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | مخرج قديم للتوافق مع الإصدارات السابقة، يحتوي على اسم ملف نموذج GLB. | STRING |
| `rig_task_id` | المعرّف الفريد لعملية التجهيز هذه، ويمكن استخدامه للإشارة إلى النتيجة. | STRING |
| `GLB` | نموذج الشخصية ثلاثي الأبعاد المجهز محفوظًا بصيغة GLB. | FILE3DGLB |
| `FBX` | نموذج الشخصية ثلاثي الأبعاد المجهز محفوظًا بصيغة FBX. | FILE3DFBX |
