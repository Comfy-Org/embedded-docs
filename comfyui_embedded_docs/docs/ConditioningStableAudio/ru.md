# ConditioningStableAudio

Узел ConditioningStableAudio добавляет информацию о времени к входам положительного и отрицательного кондиционирования для генерации аудио. Он задаёт время начала и общую длительность, которые помогают управлять тем, когда и как долго должен создаваться аудиоконтент. Этот узел изменяет существующие данные кондиционирования, добавляя аудиоспецифичные временные метаданные.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительный вход кондиционирования, который будет изменён с добавлением информации о времени аудио | CONDITIONING | Да | - |
| `отрицательный` | Отрицательный вход кондиционирования, который будет изменён с добавлением информации о времени аудио | CONDITIONING | Да | - |
| `секунды_начала` | Время начала генерации аудио в секундах (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1000.0 |
| `всего_секунд` | Общая длительность генерации аудио в секундах (по умолчанию: 47.0) | FLOAT | Да | 0.0 до 1000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Изменённое положительное кондиционирование с применённой информацией о времени аудио | CONDITIONING |
| `отрицательный` | Изменённое отрицательное кондиционирование с применённой информацией о времени аудио | CONDITIONING |
