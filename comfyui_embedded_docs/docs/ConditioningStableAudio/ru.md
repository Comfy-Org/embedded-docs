# ConditioningStableAudio

Узел ConditioningStableAudio добавляет информацию о времени как к положительным, так и к отрицательным входам conditioning для генерации аудио. Он устанавливает параметры времени начала и общей длительности, которые помогают управлять тем, когда и как долго должен генерироваться аудиоконтент. Этот узел изменяет существующие данные conditioning, добавляя аудио-специфические метаданные времени.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный вход conditioning, который будет изменён с добавлением информации о времени аудио | CONDITIONING | Да | — |
| `negative` | Отрицательный вход conditioning, который будет изменён с добавлением информации о времени аудио | CONDITIONING | Да | — |
| `seconds_start` | Время начала в секундах для генерации аудио (по умолчанию: 0.0) | FLOAT | Да | 0.0 to 1000.0 |
| `seconds_total` | Общая длительность в секундах для генерации аудио (по умолчанию: 47.0) | FLOAT | Да | 0.0 to 1000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённый положительный conditioning с применённой информацией о времени аудио | CONDITIONING |
| `negative` | Изменённый отрицательный conditioning с применённой информацией о времени аудио | CONDITIONING |
