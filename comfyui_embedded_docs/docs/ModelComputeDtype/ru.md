# ModelComputeDtype

Узел ModelComputeDtype изменяет вычислительный тип данных (точность), используемый моделью во время обработки. Он создает копию входной модели и применяет выбранную настройку точности, что может помочь оптимизировать использование памяти и производительность в зависимости от вашего оборудования. Это полезно для отладки и тестирования различных конфигураций точности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Входная модель для изменения с новым вычислительным типом данных | MODEL | Да | - |
| `dtype` | Вычислительный тип данных, применяемый к модели (по умолчанию: "default"). Этот параметр отмечен как расширенная настройка в интерфейсе. | COMBO | Да | "default"<br>"fp32"<br>"fp16"<br>"bf16" |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным новым вычислительным типом данных | MODEL |
