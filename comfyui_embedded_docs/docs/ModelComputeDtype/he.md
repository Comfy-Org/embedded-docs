# ModelComputeDtype

הצומת ModelComputeDtype משנה את סוג הנתונים החישובי (דיוק) שבו משתמש המודל במהלך העיבוד. הוא יוצר עותק של מודל הקלט ומחיל את הגדרת הדיוק שנבחרה, מה שיכול לעזור לייעל את השימוש בזיכרון ואת הביצועים בהתאם לחומרה שלך. זה שימושי לניפוי באגים ולבדיקה של תצורות דיוק שונות.
