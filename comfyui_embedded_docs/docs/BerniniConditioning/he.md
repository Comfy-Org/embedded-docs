# Bernini Conditioning

צומת BerniniConditioning מכין נתוני התניה עבור וידאו ותמונה למודל Wan2.2-A14B. הוא מקודד סרטוני מקור, סרטוני עזר ותמונות עזר באמצעות ה-VAE שסופק, ואז מצרף אותם לנתוני ההתניה בתור טוקנים בהקשר. המשימה מוסקת אוטומטית לפי אילו קלטים מחוברים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | נתוני התניה חיוביים | CONDITIONING | כן | - |
| `negative` | נתוני התניה שליליים | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד קלטי וידאו ותמונה | VAE | כן | - |
| `width` | רוחב הלטנט הפלט (ברירת מחדל: 832) | INT | כן | 16 to 8192 (step: 16) |
| `height` | גובה הלטנט הפלט (ברירת מחדל: 480) | INT | כן | 16 to 8192 (step: 16) |
| `length` | מספר הפריימים בלטנט הפלט (ברירת מחדל: 81) | INT | כן | 1 to 8192 (step: 4) |
| `batch_size` | מספר הסרטונים ליצירה באצווה אחת (ברירת מחדל: 1) | INT | כן | 1 to 4096 |
| `source_video` | סרטון מקור לעריכה או לשינוי סגנון (v2v, rv2v). משתנה לרוחב/גובה ונחתך לאורך. | IMAGE | לא | - |
| `reference_video` | סרטון להכנסה לתוך סרטון המקור (ads2v). נחתך לאורך ומשתנה תוך שמירה על יחס גובה-רוחב (הצד הארוך מוגבל ל-ref_max_size). | IMAGE | לא | - |
| `reference_images` | תמונות עזר המוזרקות בתור טוקנים בהקשר (r2v, rv2v). כל תמונה מקודדת בנפרד ביחס הגובה-רוחב המקורי שלה (הצד הארוך מוגבל ל-ref_max_size). ניתן לספק עד 8 תמונות. | IMAGE | לא | 0 to 8 images |
| `ref_max_size` | גודל מקסימלי לצד הארוך של reference_video ו-reference_images. משתנה תוך שמירה על יחס גובה-רוחב ומוצמד לכפולה של 16px (ברירת מחדל: 848). | INT | לא | 16 to 8192 (step: 16) |

**הערה:** המשימה מוסקת לפי אילו קלטים מחוברים:
- אין קלטים מחוברים → טקסט לווידאו (t2v)
- `source_video` בלבד → וידאו לווידאו (v2v)
- `source_video` + `reference_images` → עריכת וידאו מונחית תמונות עזר (rv2v)
- `reference_images` בלבד → מתמונות עזר לווידאו (r2v)
- `source_video` + `reference_video` → הכנסת תמונה/וידאו לתוך וידאו (ads2v)

זרמי ההקשר מצורפים בסדר קבוע: `source_video` (מזהה מקור 1), לאחר מכן `reference_video` (מזהה מקור 2), ואז כל תמונת עזר (מזהי מקור 3, 4, ...). קלט של תמונות עזר המכיל מספר תמונות תורם זרם אחד עבור כל תמונה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | התניה חיובית עם לטנטים של הקשר מצורפים | CONDITIONING |
| `negative` | התניה שלילית עם לטנטים של הקשר מצורפים | CONDITIONING |
| `latent` | טנזור לטנט ריק עם מידות התואמות לרוחב, גובה, אורך וגודל האצווה שצוינו | LATENT |
