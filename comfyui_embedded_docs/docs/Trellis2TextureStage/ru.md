# Trellis2TextureStage

Этот узел настраивает проход сэмплирования этапа текстурирования для генерации Trellis2. Он считывает раскладку координат и повоксельный латент формы из входного латента формы, создает пустой разреженный латент с 32 каналами в той же раскладке координат и прикрепляет необходимые метаданные этапа текстурирования к кондишинингу.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Позитивный кондишининг, используемый для прохода генерации текстур. К нему прикрепляются метаданные этапа текстурирования. | CONDITIONING | Да | - |
| `negative` | Негативный кондишининг, используемый для прохода генерации текстур. К нему прикрепляются метаданные этапа текстурирования. | CONDITIONING | Да | - |
| `shape_latent` | Словарь латента, созданный Trellis2ShapeStage или Trellis2UpsampleStage. Он должен содержать `coords` (раскладка координат, форма [N, 4]) и `samples` (повоксельный латент формы); `coord_resolution` и `model_frame` необязательны. | LATENT | Да | - |

Примечания:
- `shape_latent` должен быть выходом Trellis2ShapeStage или Trellis2UpsampleStage; он предоставляет раскладку координат и повоксельный латент формы, используемые проходом текстурирования.
- Раскладка координат проверяется: идентификаторы батчей в первом столбце `coords` должны быть неотрицательными и непрерывными, а общее количество строк должно соответствовать количеству координат.
- Когда `positive` содержит пакет проекционных признаков (кондишининг Pixal3D), а `shape_latent` включает `coord_resolution`, вычисляются проекционные признаки с разрешением текстуры 1024 и прикрепляются к кондишинингу.
- Система координат модели считывается из `shape_latent`; при её отсутствии по умолчанию используется `"y_up"`, если присутствуют проекционные признаки, и `"z_up"` в противном случае.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивный кондишининг с прикрепленными метаданными этапа текстурирования (режим генерации, координаты, количество координат, латент формы, система координат модели и проекционные признаки, если применимо). | CONDITIONING |
| `negative` | Негативный кондишининг с теми же прикрепленными метаданными этапа текстурирования. | CONDITIONING |
| `latent` | Новый пустой разреженный латент с 32 каналами и той же раскладкой координат, что и входной латент формы. Его словарь содержит `samples`, `type` ("trellis2"), `coords`, `coord_counts` и `model_frame`; `coord_resolution` добавляется, когда доступен. | LATENT |
