# Trellis2TextureStage

Этот узел настраивает проход выборки этапа текстурирования для генерации Trellis2. Он считывает координатную раскладку и повоксельный латент формы из входящего shape latent, создаёт пустой разреженный латент с 32 каналами в той же координатной раскладке и присоединяет необходимые метаданные этапа текстурирования к кондиционированию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное кондиционирование, используемое для прохода генерации текстуры. К нему присоединяются метаданные этапа текстурирования. | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование, используемое для прохода генерации текстуры. К нему присоединяются метаданные этапа текстурирования. | CONDITIONING | Да | - |
| `shape_latent` | Словарь латентного представления, созданный Trellis2ShapeStage или Trellis2UpsampleStage. Он должен содержать `coords` (координатная раскладка, форма [N, 4]) и `samples` (повоксельный латент формы); `coord_resolution` и `model_frame` необязательны. | LATENT | Да | - |

Примечания:
- `shape_latent` должен быть выходом Trellis2ShapeStage или Trellis2UpsampleStage; он предоставляет координатную раскладку и повоксельный латент формы, используемые в проходе текстурирования.
- Координатная раскладка проверяется: идентификаторы пакетов в первом столбце `coords` должны быть неотрицательными и непрерывными, а общее количество строк должно соответствовать количеству координат.
- Когда `positive` содержит пакет проекционных признаков (кондиционирование Pixal3D) и `shape_latent` включает `coord_resolution`, вычисляются проекционные признаки с разрешением текстуры 1024 и присоединяются к кондиционированию.
- Система координат модели считывается из `shape_latent`; при её отсутствии по умолчанию используется `"y_up"`, если присутствуют проекционные признаки, и `"z_up"` в противном случае.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с присоединёнными метаданными этапа текстурирования (режим генерации, координаты, количество координат, латент формы, система координат модели и проекционные признаки, если применимо). | CONDITIONING |
| `negative` | Отрицательное кондиционирование с теми же метаданными этапа текстурирования. | CONDITIONING |
| `latent` | Новый пустой разреженный латент с 32 каналами в той же координатной раскладке, что и входящий латент формы. Его словарь включает `samples`, `type` ("trellis2"), `coords`, `coord_counts` и `model_frame`; `coord_resolution` включается при наличии. | LATENT |
