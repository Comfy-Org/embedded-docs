# Trellis2TextureStage

Этот узел настраивает проход сэмплирования текстурного этапа для генерации Trellis2. Он читает раскладку координат и латент формы для каждого вокселя из входящего латента формы, создаёт пустой разреженный латент с 32 каналами с той же раскладкой координат и прикрепляет необходимые метаданные текстурного этапа к кондиционированию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное кондиционирование, используемое для прохода генерации текстуры. К нему прикрепляются метаданные текстурного этапа. | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование, используемое для прохода генерации текстуры. К нему прикрепляются метаданные текстурного этапа. | CONDITIONING | Да | - |
| `shape_latent` | Словарь латента, созданный Trellis2ShapeStage или Trellis2UpsampleStage. Он должен содержать `coords` (раскладку координат, форма [N, 4]) и `samples` (латент формы для каждого вокселя); `coord_resolution` и `model_frame` необязательны. | LATENT | Да | - |

Примечания:
- `shape_latent` должен быть выходом Trellis2ShapeStage или Trellis2UpsampleStage; он предоставляет раскладку координат и латент формы для каждого вокселя, используемый текстурным проходом.
- Раскладка координат проверяется: идентификаторы пакета (batch ids) в первом столбце `coords` должны быть неотрицательными и непрерывными, а общее число строк должно совпадать с количеством координат.
- Латент формы принимается либо как 4D разреженный тензор (который разворачивается вместе со своими координатами), либо уже в развёрнутой форме.
- Когда `positive` содержит пакет проекционных признаков (кондиционирование Pixal3D) и `shape_latent` включает `coord_resolution`, вычисляются проекционные признаки при разрешении текстуры 1024 и прикрепляются к кондиционированию.
- Фрейм модели считывается из `shape_latent`; если он отсутствует, по умолчанию используется `"y_up"`, если присутствуют проекционные признаки, и `"z_up"` в противном случае.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с прикреплёнными метаданными текстурного этапа (режим генерации, координаты, количество координат, латент формы, фрейм модели и проекционные признаки, когда применимо). | CONDITIONING |
| `negative` | Отрицательное кондиционирование с теми же прикреплёнными метаданными текстурного этапа. | CONDITIONING |
| `latent` | Новый пустой разреженный латент с 32 каналами с той же раскладкой координат, что и входящий латент формы. Его словарь включает `samples`, `type` ("trellis2"), `coords`, `coord_counts` и `model_frame`; `coord_resolution` включается при наличии. | LATENT |
