# MinimaxSubjectToVideoNode

يقوم هذا العقدة بإنشاء فيديو بشكل متزامن بناءً على صورة موضوع ونص وصفي باستخدام واجهة برمجة تطبيقات MiniMax. تأخذ هذه العقدة صورة لموضوع ووصفًا لإنشاء فيديو يقوم بتحريك ذلك الموضوع أو إظهاره وفقًا للنص الوصفي.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `subject` | صورة الموضوع المرجعي لتوليد الفيديو | IMAGE | نعم | - |
| `prompt_text` | نص وصفي لتوجيه عملية توليد الفيديو (الافتراضي: سلسلة فارغة) | STRING | نعم | - |
| `model` | النموذج المستخدم لتوليد الفيديو (الافتراضي: "S2V-01") | COMBO | لا | "S2V-01" |
| `seed` | البذرة العشوائية المستخدمة لإنشاء الضوضاء (الافتراضي: 0) | INT | لا | 0 إلى 18446744073709551615 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | الفيديو المُنشأ بناءً على صورة الموضوع المدخلة والنص الوصفي | VIDEO |
