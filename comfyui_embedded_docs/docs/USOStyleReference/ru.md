# USOStyleReference

Узел USOStyleReference применяет стилевой референс к модели, объединяя визуальные признаки CLIP с патчем модели, и возвращает пропатченную копию входной модели. Он предназначен для моделей Flux и помечен как экспериментальный. Информация о визуальном стиле объединяется с текстовым кондиционированием модели, чтобы влиять на генерацию.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая модель, к которой применяется патч стилевого референса. | MODEL | Да | - |
| `model_patch` | Патч модели, содержащий проекционную модель, используемую для кодирования признаков референсного изображения. | MODEL_PATCH | Да | - |
| `clip_vision_output` | Закодированные визуальные признаки, извлеченные из обработки референсного изображения моделью CLIP vision. | CLIP_VISION_OUTPUT | Да | - |

Примечание: `clip_vision_output` должен быть получен из модели CLIP vision, которая предоставляет полные скрытые состояния и предпоследнее скрытое состояние. Узел объединяет скрытые состояния: двадцатое с конца, одиннадцатое с конца и предпоследнее — в эмбеддинг стиля. `model_patch` должен предоставлять проекционную модель через свой атрибут `model`, которая преобразует эти визуальные признаки в эмбеддинг стиля. Во время сэмплирования эмбеддинг стиля добавляется в начало текстового кондиционирования, чтобы влиять на генерацию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным патчем стилевого референса. | MODEL |
