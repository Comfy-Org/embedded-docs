# USOStyleReference

Узел USOStyleReference применяет стилевой эталон к модели, объединяя признаки CLIP vision с патчем модели, и возвращает пропатченную копию входной модели. Визуальная информация о стиле объединяется с текстовым кондиционированием модели, чтобы влиять на генерацию. Этот узел предназначен для моделей Flux и помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая модель, к которой применяется патч стилевого эталона. | MODEL | Да | - |
| `model_patch` | Патч модели, содержащий проекционную модель, используемую для кодирования признаков эталонного изображения. | MODEL_PATCH | Да | - |
| `clip_vision_output` | Закодированные визуальные признаки, извлечённые в результате обработки эталонного изображения с помощью CLIP vision. | CLIP_VISION_OUTPUT | Да | - |

Примечание. `clip_vision_output` должен поступать из модели CLIP vision, которая предоставляет полные скрытые состояния и предпоследнее скрытое состояние. Узел объединяет скрытые состояния: 20-е с конца, 11-е с конца и предпоследнее — в эмбеддинг стиля. `model_patch` должен предоставлять проекционную модель через свой атрибут `model`, который преобразует эти признаки изображения в эмбеддинг стиля. Во время сэмплинга эмбеддинг стиля добавляется в начало текстового кондиционирования, чтобы влиять на генерацию, а соответствующие текстовые идентификаторы с нулевой позицией добавляются в начало текстовых идентификаторов, чтобы последовательность идентификаторов оставалась выровненной с расширенным кондиционированием.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым патчем стилевого эталона. | MODEL |
