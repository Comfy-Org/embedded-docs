# USOStyleReference

Узел USOStyleReference применяет информацию о стиле из референсного изображения к модели Flux. Он создаёт эмбеддинг стиля на основе выхода CLIP vision, затем модифицирует клон модели так, чтобы во время генерации эмбеддинг стиля вставлялся перед кондиционированием текстового промпта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая модель, к которой применяется патч стилевого референса | MODEL | Да | - |
| `model_patch` | Патч модели, содержащий информацию о стилевом референсе | MODEL_PATCH | Да | - |
| `clip_vision_output` | Закодированные визуальные признаки, извлечённые в процессе обработки CLIP vision. Узел объединяет скрытые состояния из слоёв -20 и -11 вместе с предпоследними скрытыми состояниями для создания эмбеддинга стиля | CLIP_VISION_OUTPUT | Да | - |

Примечание: все три входа обязательны. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым патчем стилевого референса | MODEL |
