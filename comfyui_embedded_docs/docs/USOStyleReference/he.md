# USOStyleReference

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הבסיס שעליו מוחל ה-patch של ייחוס הסגנון. | MODEL | כן | - |
| `model_patch` | ה-patch של המודל המכיל את מודל ההטלה המשמש לקידוד תכונות תמונת הייחוס. | MODEL_PATCH | כן | - |
| `clip_vision_output` | התכונות החזותיות המקודדות שחולצו מעיבוד CLIP vision של תמונת הייחוס. | CLIP_VISION_OUTPUT | כן | - |

הערה: ה-`clip_vision_output` חייב להגיע ממודל CLIP vision המספק את המצבים החבויים המלאים ואת המצב החבוי הלפני-אחרון. הצומת משלב את המצבים החבויים ה-20 מהסוף, ה-11 מהסוף והלפני-אחרון לתוך הטמעת הסגנון. ה-`model_patch` חייב לחשוף מודל הטלה דרך המאפיין `model` שלו, אשר ממיר את תכונות התמונה הללו להטמעת הסגנון. במהלך הדגימה, הטמעת הסגנון נוספת לפני ההתניה הטקסטואלית כדי שתוכל להשפיע על היצירה, ומזהי טקסט תואמים במיקום אפס נוספים לפני מזהי הטקסט כדי שרצף המזהים יישאר מיושר עם ההתניה המורחבת.
