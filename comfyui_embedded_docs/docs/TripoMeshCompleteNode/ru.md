# TripoMeshCompleteNode

Дополняет отсутствующие или незавершённые части уже сегментированной 3D-модели и восстанавливает повреждённые участки сетки. Принимает идентификатор задачи (task ID) результата сегментации сетки Tripo, запрашивает у Tripo завершение модели и ожидает окончания выполнения задания. Завершённые части возвращаются в виде файла GLB. При необходимости можно ограничить работу только определёнными именами частей.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|---------|
| `segment_task_id` | Идентификатор задачи сегментации сетки Tripo. Части сегментированной модели из этой задачи будут завершены. Подключите выход SEGMENT_TASK_ID предыдущего узла сегментации сетки Tripo. | SEGMENT_TASK_ID | Да | Single task ID |
| `part_names` | Разделённые запятыми имена частей для завершения. Пустое значение означает завершение всех частей. По умолчанию: пустая строка. Пробелы по краям имён удаляются, повторяющиеся имена игнорируются. | STRING | Нет | Free text or empty |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла завершённой модели. Этот выход существует только для обратной совместимости. | STRING |
| `task_id модели` | Идентификатор задачи завершения сетки Tripo. Может использоваться другими узлами Tripo, ожидающими идентификатор задачи модели, в качестве входных данных. | MODEL_TASK_ID |
| `GLB` | Завершённая 3D-модель с исправленными частями, выгруженная в виде файла GLB. | GLB |
