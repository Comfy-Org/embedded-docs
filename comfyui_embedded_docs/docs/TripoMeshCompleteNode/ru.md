# Tripo: Дополнение частей сетки

Завершает части сегментированной 3D-модели и восстанавливает отсутствующие или повреждённые области меша. Принимает ID задачи результата сегментации меша Tripo, запрашивает задание на завершение у Tripo и ожидает его завершения. При необходимости можно ограничить работу конкретными именами частей. Завершённая модель возвращается в виде GLB-файла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | ID задачи сегментации меша Tripo. Завершаются части сегментированной модели из этой задачи. Подключите выход SEGMENT_TASK_ID предыдущего узла сегментации меша Tripo. | SEGMENT_TASK_ID | Да | Один ID задачи |
| `part_names` | Имена частей через запятую для завершения. Если пусто — завершаются все части. По умолчанию: пустая строка. Лишние пробелы вокруг имён удаляются, а повторяющиеся имена игнорируются. | STRING | Нет | Произвольный текст или пусто |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла завершённой модели. Этот выход существует только для обратной совместимости. | STRING |
| `model task_id` | ID выполненной задачи Tripo на завершение меша. Может использоваться как вход другими узлами Tripo, которые ожидают ID задачи модели. | MODEL_TASK_ID |
| `GLB` | Завершённая 3D-модель с восстановленными частями, скачанная в виде GLB-файла. | GLB |
