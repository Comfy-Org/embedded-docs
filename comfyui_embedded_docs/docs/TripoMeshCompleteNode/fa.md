# Tripo: تکمیل بخش‌های مش

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | شناسه وظیفه یک وظیفه بخش‌بندی مش Tripo. بخش‌های مدل بخش‌بندی‌شده از این وظیفه تکمیل می‌شوند. خروجی SEGMENT_TASK_ID یک گره بخش‌بندی مش Tripo قبلی را متصل کنید. | SEGMENT_TASK_ID | بله | یک شناسه وظیفه |
| `part_names` | نام بخش‌های جدا شده با کاما برای تکمیل. خالی بودن باعث تکمیل همه بخش‌ها می‌شود. پیش‌فرض: رشته خالی. فاصله‌های اضافی اطراف نام‌ها حذف می‌شوند و نام‌های تکراری نادیده گرفته می‌شوند. | STRING | خیر | متن آزاد یا خالی |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل تکمیل‌شده. این خروجی فقط برای سازگاری با نسخه‌های قبلی وجود دارد. | STRING |
| `model task_id` | شناسه وظیفه وظیفه تکمیل مش Tripo. می‌تواند به‌عنوان ورودی توسط سایر گره‌های Tripo که انتظار شناسه وظیفه مدل را دارند استفاده شود. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تکمیل‌شده با بخش‌های ترمیم‌شده، که به‌صورت فایل GLB دانلود می‌شود. | GLB |
