# TripoMeshCompleteNode

```markdown
يُكمل الأجزاء المفقودة أو غير المكتملة من نموذج ثلاثي الأبعاد تم تقسيمه مسبقًا، ويُصلح المناطق المتضررة من الشبكة (Mesh). يستخدم معرّف المهمة الخاص بنتيجة تقسيم شبكة Tripo ويطلب من Tripo إكمال النموذج، ثم ينتظر حتى تنتهي المهمة. تُعاد الأجزاء المكتملة كملف GLB، ويمكنك اختياريًا قصر العمل على أسماء أجزاء محددة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | معرّف المهمة لمهمة تقسيم شبكة (Mesh) من Tripo. يتم إكمال أجزاء النموذج المُقسَّم الناتجة عن هذه المهمة. وصّل مخرج SEGMENT_TASK_ID من عقدة تقسيم شبكة Tripo السابقة. | SEGMENT_TASK_ID | نعم | معرّف مهمة واحد |
| `part_names` | أسماء الأجزاء المطلوب إكمالها مفصولة بفواصل. إذا تُرك الحقل فارغًا، يتم إكمال كل الأجزاء. القيمة الافتراضية: سلسلة فارغة. تُزال المسافات الزائدة حول الأسماء وتُتجاهل الأسماء المكررة. | STRING | لا | نص حر أو فارغ |

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model_file` | اسم ملف النموذج المكتمل. هذا المخرج موجود للتوافق مع الإصدارات السابقة فقط. | STRING |
| `معرّف مهمة النموذج task_id` | معرّف المهمة لمهمة إكمال شبكة Tripo المكتملة. يمكن استخدامه كمدخل لعُقد Tripo الأخرى التي تتوقع معرّف مهمة نموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المكتمل مع الأجزاء المُصلَحة، ويُحمَّل كملف GLB. | GLB |
```
