# Tripo: メッシュパーツを補完

セグメント化された3Dモデルの各部分を完成させ、メッシュの欠落部分や損傷部分を修復します。Tripoメッシュセグメンテーション結果のタスクIDを受け取り、Tripoに補完ジョブをリクエストし、完了するまで待機します。オプションで、特定のパート名に処理を限定することもできます。完成したモデルはGLBファイルとして返されます。

<Note>
Tripo はタスクの記録をサーバー上に 7 日間保持します（2026 年 12 月 1 日以降）。それより古いタスク ID は解決できなくなるため、保存したワークフローをこの期間の後に再実行すると、このノードで失敗します。続けるには、前段の Tripo ノードをもう一度実行して新しいタスク ID を作成するか、すでにダウンロードしたモデルを **Tripo: Import Model** で再インポートしてください。
</Note>

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | TripoメッシュセグメンテーションタスクのタスクID。このタスクでセグメント化されたモデルの各部分が補完されます。前のTripoメッシュセグメンテーションノードのSEGMENT_TASK_ID出力を接続してください。 | SEGMENT_TASK_ID | はい | 単一のタスクID |
| `part_names` | 補完するパート名をカンマ区切りで指定します。空の場合はすべてのパートを補完します。デフォルト：空文字列。名前の前後の余分なスペースは削除され、重複する名前は無視されます。 | STRING | いいえ | 自由テキストまたは空 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 完成したモデルのファイル名。この出力は後方互換性のためにのみ存在します。 | STRING |
| `model task_id` | 完成したTripoメッシュ補完タスクのタスクID。モデルタスクIDを想定する他のTripoノードへの入力として使用できます。 | MODEL_TASK_ID |
| `GLB` | 補修されたパートを含む完成済みの3Dモデル。GLBファイルとしてダウンロードされます。 | GLB |
