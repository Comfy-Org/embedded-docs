# PairConditioningSetDefaultAndCombine

Узел **PairConditioningSetDefaultAndCombine** устанавливает значения кондиционирования по умолчанию и объединяет их с входными данными кондиционирования. Он принимает положительные и отрицательные входы кондиционирования вместе с их версиями по умолчанию, затем обрабатывает их через систему хуков ComfyUI для получения итоговых выходов кондиционирования, включающих значения по умолчанию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Основной положительный вход кондиционирования для обработки | CONDITIONING | Да | - |
| `отрицательный` | Основной отрицательный вход кондиционирования для обработки | CONDITIONING | Да | - |
| `положительный_ПО_УМОЛЧАНИЮ` | Значения положительного кондиционирования по умолчанию, используемые как резервные | CONDITIONING | Да | - |
| `отрицательный_ПО_УМОЛЧАНИЮ` | Значения отрицательного кондиционирования по умолчанию, используемые как резервные | CONDITIONING | Да | - |
| `хуки` | Необязательная группа хуков для пользовательской логики обработки | HOOKS | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанное положительное кондиционирование с включенными значениями по умолчанию | CONDITIONING |
| `negative` | Обработанное отрицательное кондиционирование с включенными значениями по умолчанию | CONDITIONING |
