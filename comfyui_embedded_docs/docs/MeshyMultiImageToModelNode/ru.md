# Meshy: Мульти-изображение в модель

Этот узел использует Meshy API для создания 3D-модели на основе нескольких входных изображений. Он загружает предоставленные изображения, отправляет задачу на обработку и возвращает результирующие файлы 3D-модели (GLB и FBX) вместе с идентификатором задачи для справки.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Указывает версию модели ИИ для использования. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `should_remesh` | Определяет, обрабатывается ли сгенерированная сетка. Если задано значение `"false"`, узел возвращает необработанную треугольную сетку. Если задано значение `"true"`, отображаются настройки ремешинга, указанные ниже. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `symmetry_mode` | Управляет применением симметрии к сгенерированной модели. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | Определяет, создаются ли текстуры. Если задано значение `"false"`, этап текстурирования пропускается и возвращается сетка без текстур. Если задано значение `"true"`, отображаются настройки текстур, указанные ниже. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `pose_mode` | Укажите режим позы для сгенерированной модели. | COMBO | Да | `""` (пусто)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты не являются детерминированными независимо от seed. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

### Настройки ремешинга (видны, когда `should_remesh` установлен в `"true"`)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `topology` | Целевой тип полигонов для результата ремешинга. | COMBO | Нет | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для модели после ремешинга (по умолчанию: 300000). | INT | Нет | от 100 до 300000 |

### Настройки текстур (видны, когда `should_texture` установлен в `"true"`)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `enable_pbr` | Создавать PBR-карты (металличность, шероховатость, нормали) в дополнение к базовому цвету. (по умолчанию: False) | BOOLEAN | Нет | True / False |
| `texture_prompt` | Предоставьте текстовый промпт для управления процессом текстурирования. Максимум 600 символов. Не может использоваться одновременно с `texture_image`. (по умолчанию: пусто) | STRING | Нет | До 600 символов |
| `texture_image` | Одновременно можно использовать только одно из значений: `texture_image` или `texture_prompt`. | IMAGE | Нет | - |
| `texture_resolution` | Разрешение текстуры базового цвета. Более высокое разрешение позволяет захватить больше деталей поверхности. | COMBO | Нет | `"2k"`<br>`"4k"`<br>`"8k"` |

### Входы изображений

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Расширяемый слот: подключите от 2 до 4 входных изображений (`image_1`, `image_2`, `image_3`, `image_4`). Эти изображения используются для создания 3D-модели. | IMAGE | Да | от 2 до 4 изображений |

**Примечания**

* Для входа `images` необходимо предоставить от 2 до 4 изображений.
* Параметры `topology` и `target_polycount` активны только тогда, когда `should_remesh` установлен в `"true"`.
* Параметры `enable_pbr`, `texture_prompt`, `texture_image` и `texture_resolution` активны только тогда, когда `should_texture` установлен в `"true"`.
* `texture_prompt` и `texture_image` являются взаимоисключающими; вы не можете использовать оба одновременно. `texture_prompt` ограничен 600 символами.
* Значение `seed` не делает результаты детерминированными; его изменение просто приводит к повторному выполнению задачи генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model_file` | Имя файла сгенерированной GLB-модели. Этот выход предоставляется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. | FILE3DFBX |
