# Meshy: Мульти-изображение в модель

Этот узел использует Meshy API для генерации 3D-модели из нескольких входных изображений. Он загружает предоставленные изображения, отправляет задачу на обработку и возвращает полученные файлы 3D-модели (GLB и FBX) вместе с идентификатором задачи для справки.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Указывает версию модели ИИ для использования. | COMBO | Да | `"latest"` |
| `should_remesh` | Определяет, следует ли обрабатывать сгенерированную сетку. При значении `"false"` узел возвращает необработанную треугольную сетку. При значении `"true"` отображаются настройки пересоздания сетки, указанные ниже. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `symmetry_mode` | Управляет применением симметрии к сгенерированной модели. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | Определяет, создаются ли текстуры. Установка значения `"false"` пропускает этап текстурирования и возвращает сетку без текстур. При значении `"true"` отображаются настройки текстур, указанные ниже. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `pose_mode` | Задаёт режим позы для сгенерированной модели. | COMBO | Да | `""` (пусто)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Значение seed управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

### Настройки пересоздания сетки (видны, когда `should_remesh` установлен в `"true"`)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `topology` | Целевой тип полигонов для пересозданной сетки. | COMBO | Нет | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для пересозданной модели (по умолчанию: 300000). | INT | Нет | от 100 до 300000 |

### Настройки текстур (видны, когда `should_texture` установлен в `"true"`)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `enable_pbr` | Создание PBR-карт (metallic, roughness, normal) дополнительно к базовому цвету. (по умолчанию: False) | BOOLEAN | Нет | True / False |
| `texture_prompt` | Текстовый запрос для управления процессом текстурирования. Максимум 600 символов. Не может использоваться одновременно с `texture_image`. (по умолчанию: пусто) | STRING | Нет | - |
| `texture_image` | Одновременно можно использовать только одно из значений: `texture_image` или `texture_prompt`. | IMAGE | Нет | - |

### Входы изображений

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Расширяемый слот: подключите от 2 до 4 входных изображений (`image_1`, `image_2`, `image_3`, `image_4`). Эти изображения используются для генерации 3D-модели. | IMAGE | Да | от 2 до 4 изображений |

**Примечания**

* Для входа `images` необходимо предоставить от 2 до 4 изображений.
* Параметры `topology` и `target_polycount` активны только тогда, когда `should_remesh` установлен в `"true"`.
* Параметры `enable_pbr`, `texture_prompt` и `texture_image` активны только тогда, когда `should_texture` установлен в `"true"`.
* `texture_prompt` и `texture_image` взаимоисключающие; нельзя использовать оба одновременно. `texture_prompt` ограничен 600 символами.
* Значение `seed` не делает результаты детерминированными; его изменение просто заставляет узел заново запустить задачу генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model_file` | Имя файла сгенерированной GLB-модели. Этот выход предоставляется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. | FILE3DFBX |
