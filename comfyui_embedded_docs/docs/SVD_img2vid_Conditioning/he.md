# SVD_img2vid_Conditioning

צומת SVD_img2vid_Conditioning מכין נתוני התניה ליצירת וידאו באמצעות Stable Video Diffusion. הוא מקבל תמונה ראשונית ומעבד אותה דרך מקודדי CLIP vision ו-VAE כדי ליצור זוגות התניה חיוביים ושליליים, יחד עם חלל latent ריק ליצירת וידאו. צומת זה מגדיר את הפרמטרים הדרושים לשליטה בתנועה, קצב פריימים ורמות אוגמנטציה בווידאו הנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip_vision` | מודל CLIP vision לקידוד תמונת הקלט | CLIP_VISION | כן | - |
| `init_image` | תמונה ראשונית שתשמש כנקודת התחלה ליצירת וידאו | IMAGE | כן | - |
| `vae` | מודל VAE לקידוד התמונה לחלל latent | VAE | כן | - |
| `width` | רוחב הווידאו בפלט (ברירת מחדל: 1024, צעד: 8) | INT | כן | 16 to MAX_RESOLUTION |
| `height` | גובה הווידאו בפלט (ברירת מחדל: 576, צעד: 8) | INT | כן | 16 to MAX_RESOLUTION |
| `video_frames` | מספר הפריימים ליצירה בווידאו (ברירת מחדל: 14) | INT | כן | 1 to 4096 |
| `motion_bucket_id` | שולט בכמות התנועה בווידאו הנוצר (ברירת מחדל: 127) | INT | כן | 1 to 1023 |
| `fps` | פריימים לשנייה עבור הווידאו הנוצר (ברירת מחדל: 6) | INT | כן | 1 to 1024 |
| `augmentation_level` | רמת אוגמנטציית הרעש להחלה על תמונת הקלט (ברירת מחדל: 0.0, צעד: 0.01) | FLOAT | כן | 0.0 to 10.0 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | נתוני התניה חיוביים הכוללים הטמעות תמונה ופרמטרים של וידאו | CONDITIONING |
| `negative` | נתוני התניה שליליים עם הטמעות מאופסות ופרמטרים של וידאו | CONDITIONING |
| `latent` | טנזור חלל latent ריק המוכן ליצירת וידאו | LATENT |
