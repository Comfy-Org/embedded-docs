# 创建列表

Create List 节点将多个输入合并为一个顺序列表。它接受任意数量的相同数据类型输入，并按照连接顺序将它们拼接起来。此节点可用于准备数据批次，例如图像或文本，以供工作流中的其他节点处理。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `inputs` | 一组可增长的输入插槽。点击加号 (+) 图标可添加更多插槽，或连接项目后会自动创建新插槽。每个插槽可接受一个或多个项目，且所有插槽必须共享同一数据类型（例如，全部为 IMAGE 或全部为 STRING）。 | Varies（与连接的数据类型一致） | 是 | 任意数量的插槽；每个插槽接受一个或多个项目 |
