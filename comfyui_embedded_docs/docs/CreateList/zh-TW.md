# 建立清單

Create List 節點將多個輸入合併為單一有序列表。它接受任意數量的相同資料類型輸入，並按照它們連接的順序串接起來。此節點對於準備批次資料（例如圖像或文字）以在工作流程中由其他節點處理非常有用。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `輸入` | 可變數量的輸入插槽，名稱依次為 `input`、`input_2`、`input_3` 等。每個插槽接受相同資料類型的項目列表。您可以透過按一下加號 (+) 圖示來新增更多插槽。所有插槽必須使用相同的資料類型（例如全部為 IMAGE 或全部為 STRING）。 | Varies | 是 | 任意數量的插槽；每個插槽接受任意數量的項目 |

**注意：** 當您連接項目時，節點會自動建立新的輸入插槽。所有已連接的輸入必須共用相同的資料類型，節點才能正常運作。每個已連接的插槽提供一個項目列表，節點會按照插槽順序（`input`、然後 `input_2`、然後 `input_3`、……）合併這些列表。此節點也可在別名 "Image Iterator"、"Text Iterator" 和 "Iterator" 下搜尋。
