# 建立清單

Create List 節點會將多個輸入合併成單一且依序排列的清單。它接受任意數量的輸入槽，這些槽共享相同的資料類型，並依照槽連接的順序串接其項目。結果是一個包含所有已連接項目的清單。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `輸入` | 數量可變的輸入槽，名稱依序為 `input`、`input_2`、`input_3` 等。每個槽接受相同資料類型的項目清單（例如全部為 IMAGE 或全部為 STRING）。系統會視需要自動建立新的槽。此節點會依槽的順序串接這些清單。 | Any | 是 | 任意數量的槽；每個槽接受任意數量的項目 |

**注意：** 所有已連接的輸入必須共享相同的資料類型。每個已連接的槽會提供一個項目清單，而節點會依槽的順序（先 `input`，接著 `input_2`，再接著 `input_3`，...）合併這些清單。此節點也可透過別名 "Image Iterator"、"Text Iterator" 和 "Iterator" 搜尋。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
| --- | --- | --- |
| `list` | 單一清單，包含來自已連接輸入的所有項目，並依提供槽的順序串接。輸出資料類型會與輸入資料類型相符。 | Any |
