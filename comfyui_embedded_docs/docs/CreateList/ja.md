Create List ノードは、複数の入力を1つの順序付きリストに結合します。同じデータ型の任意の数の入力を受け取り、接続された順に連結します。このノードは、ワークフロー内の他のノードで処理するための画像やテキストなどのデータのバッチを準備するのに便利です。
