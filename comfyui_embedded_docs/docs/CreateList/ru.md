# Создать список

Узел Create List объединяет несколько входов в единый последовательный список. Он принимает любое количество входных слотов с одинаковым типом данных и конкатенирует их элементы в порядке подключения слотов. Результатом является один список, содержащий все подключённые элементы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `входные данные` | Переменное количество входных слотов с именами `input`, `input_2`, `input_3` и так далее. Каждый слот принимает список элементов одного типа данных (например, все IMAGE или все STRING). Новые слоты создаются автоматически по мере необходимости. Узел объединяет списки в порядке слотов. | Any | Да | Любое количество слотов; каждый слот принимает любое количество элементов |

**Примечание:** Все подключённые входы должны иметь один и тот же тип данных. Каждый подключённый слот предоставляет список элементов, и узел объединяет списки в порядке слотов (`input`, затем `input_2`, затем `input_3`, ...). Узел также можно найти по псевдонимам «Image Iterator», «Text Iterator» и «Iterator».

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `list` | Единый список, содержащий все элементы из подключённых входов, объединённые в порядке предоставления слотов. Тип данных выхода совпадает с типом данных входа. | Any |
