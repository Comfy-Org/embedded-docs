# Создать список

Узел **Create List** объединяет несколько входных значений в единый последовательный список. Он принимает произвольное количество входных значений одного типа данных и объединяет их в порядке подключения. Этот узел полезен для подготовки пакетов данных, например изображений или текста, для обработки другими узлами в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `inputs` | Расширяемый набор входных слотов. Добавляйте новые слоты, нажимая на значок плюс (+), или подключайте элементы — новые слоты будут созданы автоматически. Каждый слот принимает один или несколько элементов, и все слоты должны использовать один и тот же тип данных (например, все IMAGE или все STRING). | Зависит от подключенного типа данных | Да | Любое количество слотов; каждый слот принимает один или несколько элементов |

**Примечание:** Узел автоматически создает новые входные слоты по мере подключения элементов. Все подключенные входные значения должны иметь один и тот же тип данных для корректной работы узла, и выходной список будет иметь тот же тип.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `list` | Единый список, содержащий все элементы из подключенных входных слотов, объединенные в порядке их подключения. Тип выходных данных совпадает с типом входных данных. | Зависит от входного типа данных |
