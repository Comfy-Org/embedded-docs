# Создать список

Узел Create List объединяет несколько входов в единый последовательный список. Он принимает любое количество входов одного типа данных и объединяет их в порядке подключения. Этот узел полезен для подготовки пакетов данных, например изображений или текста, для последующей обработки другими узлами в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `входные данные` | Переменное количество входных слотов с именами `input`, `input_2`, `input_3` и так далее. Каждый слот принимает список элементов одного типа данных. Вы можете добавлять дополнительные слоты, нажимая значок плюс (+). Все слоты должны использовать один и тот же тип данных (например, все IMAGE или все STRING). | Различный | Да | Любое количество слотов; каждый слот принимает любое количество элементов |

**Примечание:** Узел автоматически создает новые входные слоты по мере подключения элементов. Все подключенные входы должны использовать один и тот же тип данных, чтобы узел работал корректно. Каждый подключенный слот предоставляет список элементов, и узел объединяет списки в порядке слотов (`input`, затем `input_2`, затем `input_3`, ...). Узел также доступен для поиска под псевдонимами "Image Iterator", "Text Iterator" и "Iterator".

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `список` | Единый список, содержащий все элементы из подключенных входов, объединенные в порядке их подачи. Тип данных выхода соответствует типу данных входа. | Различный |
