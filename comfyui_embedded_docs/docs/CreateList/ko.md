# 목록 만들기

Create List 노드는 여러 입력을 단일 순차 목록으로 결합합니다. 동일한 데이터 타입의 입력을 원하는 개수만큼 받아 연결된 순서대로 이어 붙입니다. 이 노드는 워크플로우의 다른 노드에서 처리할 이미지나 텍스트와 같은 데이터 배치를 준비하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `inputs` | 확장 가능한 입력 슬롯 세트입니다. 더하기(+) 아이콘을 클릭하여 슬롯을 추가하거나, 항목을 연결하면 새 슬롯이 자동으로 생성됩니다. 각 슬롯은 하나 이상의 항목을 수용하며, 모든 슬롯은 동일한 데이터 타입(예: 모두 IMAGE 또는 모두 STRING)을 공유해야 합니다. | 연결된 데이터 타입에 따라 다름 | 예 | 슬롯 수 제한 없음; 각 슬롯은 하나 이상의 항목 수용 |

**참고:** 항목을 연결하면 노드가 자동으로 새 입력 슬롯을 생성합니다. 노드가 올바르게 작동하려면 연결된 모든 입력이 동일한 데이터 타입을 공유해야 하며, 출력 목록도 동일한 타입을 갖습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `list` | 연결된 입력 슬롯의 모든 항목을 슬롯이 연결된 순서대로 이어 붙인 단일 목록입니다. 출력 데이터 타입은 입력 데이터 타입과 일치합니다. | 연결된 입력 데이터 타입에 따라 다름 |
