# Эталонный латент

Этот узел задает направляющий латент для модели редактирования. Он принимает данные `conditioning` и необязательный вход `latent`, затем изменяет `conditioning`, чтобы включить информацию об эталонном латенте. Если модель это поддерживает, вы можете последовательно соединить несколько узлов ReferenceLatent, чтобы задать несколько эталонных изображений.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные conditioning, которые будут изменены с использованием информации об эталонном латенте | CONDITIONING | Да | - |
| `latent` | Необязательные латентные данные для использования в качестве эталона для модели редактирования | LATENT | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Измененные данные conditioning, содержащие информацию об эталонном латенте | CONDITIONING |
