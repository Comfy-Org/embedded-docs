# Эталонный латент

Этот узел задаёт направляющий латент для модели редактирования. Он принимает данные кондиционирования и необязательный входной латент, а затем изменяет кондиционирование, добавляя в него информацию об эталонном латенте. Если модель это поддерживает, можно соединить в цепочку несколько узлов Set Reference Latent, чтобы задать несколько эталонных изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые нужно изменить, добавив информацию об эталонном латенте | CONDITIONING | Да | - |
| `латент` | Необязательные латентные данные, используемые как эталон для модели редактирования. Если не указаны, кондиционирование возвращается без изменений | LATENT | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изменённые данные кондиционирования, содержащие информацию об эталонном латенте | CONDITIONING |

## Примечания

- Эталонный латент хранится как список тензоров-образцов, поэтому последовательное подключение нескольких узлов Set Reference Latent добавляет дополнительные эталоны, а не заменяет предыдущий.
- Если `latent` не подключён, узел передаёт входящее `conditioning` дальше без изменений.
