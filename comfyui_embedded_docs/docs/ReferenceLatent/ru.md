# Эталонный латент

Этот узел задаёт направляющий латент для модели редактирования. Он принимает данные кондиционирования и необязательный латентный вход, после чего изменяет кондиционирование, добавляя информацию об эталонном латенте. Если модель это поддерживает, можно последовательно соединить несколько узлов ReferenceLatent, чтобы задать несколько эталонных изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые необходимо изменить, добавив информацию об эталонном латенте | CONDITIONING | Да | - |
| `латент` | Необязательные латентные данные, используемые как эталон для модели редактирования. Если не указано, кондиционирование возвращается без изменений | LATENT | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изменённые данные кондиционирования, содержащие информацию об эталонном латенте | CONDITIONING |
