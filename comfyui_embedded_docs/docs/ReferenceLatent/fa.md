# ReferenceLatent

این گره لاتنت راهنما را برای یک مدل ویرایش تنظیم می‌کند. داده‌های conditioning و یک ورودی `latent` اختیاری را دریافت می‌کند و سپس conditioning را طوری تغییر می‌دهد که اطلاعات لاتنت مرجع را شامل شود. اگر مدل از آن پشتیبانی کند، می‌توانید چندین گره Set Reference Latent را به‌صورت زنجیره‌ای متصل کنید تا چند تصویر مرجع تنظیم شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `conditioning` | داده‌های conditioning که باید با اطلاعات لاتنت مرجع تغییر کند | CONDITIONING | بله | - |
| `latent` | داده لاتنت اختیاری برای استفاده به‌عنوان مرجع مدل ویرایش. اگر ارائه نشود، conditioning بدون تغییر بازگردانده می‌شود | LATENT | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | داده‌های conditioning تغییر‌یافته که شامل اطلاعات لاتنت مرجع است | CONDITIONING |

## نکات

- لاتنت مرجع به‌صورت فهرستی از تنسورهای نمونه ذخیره می‌شود، بنابراین اتصال چند گره Set Reference Latent به‌صورت متوالی، مرجع‌های بیشتری را اضافه می‌کند، نه اینکه مرجع قبلی را جایگزین کند.
- وقتی هیچ `latent` متصل نباشد، گره `conditioning` ورودی را بدون تغییر عبور می‌دهد.
