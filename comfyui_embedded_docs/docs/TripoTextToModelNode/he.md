# Tripo: טקסט למודל (מדור קודם)

צומת מדור קודם זה מייצר מודלים תלת-ממדיים מוגמרים מתיאור טקסטואלי באמצעות ה-API של Tripo. הוא ממתין להשלמת היצירה ואז מחזיר את קובץ המודל, ובאופן אופציונלי עם טקסטורות וחומרי PBR. הוא מסומן כמיושן ונשמר עבור תהליכי עבודה ישנים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור טקסטואלי של המודל התלת-ממדי שיש ליצור (מרובה שורות). פרמטר זה נדרש ואינו יכול להיות ריק. | STRING | כן | - |
| `negative_prompt` | תיאור טקסטואלי של מה שיש להימנע ממנו במודל המיוצר (מרובה שורות). עד 255 תווים. נשלח ל-API רק כשהוא אינו ריק. | STRING | לא | עד 255 תווים |
| `model_version` | גרסת מודל Tripo לשימוש ביצירה (ברירת מחדל: v3_1_20260211). | COMBO | לא | אפשרויות מרובות זמינות |
| `style` | אינו נתמך עוד על ידי Tripo ומתעלמים ממנו. נשמר עבור תהליכי עבודה ישנים (ברירת מחדל: "None"). | COMBO | לא | אפשרויות מרובות זמינות |
| `texture` | צור מפות טקסטורה. כיבוי מחזיר גאומטריה חשופה ומתעלם מ-`pbr` (ברירת מחדל: True). | BOOLEAN | לא | true / false |
| `pbr` | מפות חומר PBR (צבע בסיס, מטאלי, חספוס, נורמל). מחייב `texture`; נכפה כבוי כאשר `texture` כבוי (ברירת מחדל: True). | BOOLEAN | לא | true / false |
| `image_seed` | ערך Seed המשמש לשלב יצירת התמונה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `model_seed` | ערך Seed המשמש לשלב יצירת המודל (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `texture_seed` | ערך Seed המשמש לשלב יצירת הטקסטורה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `texture_quality` | איכות הטקסטורות המיוצרות. detailed = טקסטורות HD, extreme = טקסטורות 8K Ultra (ברירת מחדל: standard). | COMBO | לא | "standard"<br>"detailed"<br>"extreme" |
| `face_limit` | מספר הפאות המרבי. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי (כ-1.4M פאות ב-v3.x standard, 2M ב-detailed). Tripo מגביל בשקט: v2.5 ל-500,000, רשתות quad ל-150,000. (ברירת מחדל: -1) | INT | לא | -1 עד 2000000 |
| `quad` | פלט רשת quad. Tripo מספק רשתות quad כ-FBX, כך שהתוצאה מגיעה בפלט FBX ופלט GLB נשאר ריק. (ברירת מחדל: False) | BOOLEAN | לא | true / false |
| `geometry_quality` | איכות הגאומטריה המיוצרת (ברירת מחדל: standard). | COMBO | לא | "standard"<br>"detailed" |
| `smart_low_poly` | רשת low-poly עם טופולוגיה נקייה בסגנון עבודת יד (500-20,000 פאות, quad 500-10,000). מתאים ביותר לנושאים פשוטים; נושאים מורכבים עלולים להיכשל. (ברירת מחדל: False) | BOOLEAN | לא | true / false |
| `auto_size` | מתאים את קנה המידה של מודלים עם טקסטורות לגודלם במציאות במטרים. Tripo שומר את הגודל כטרנספורמציית סצנה של המודל ומטמיע אותו כאשר המודל מומר, עובר ריגינג או ריטרגוט; מתעלמים ממנו ללא טקסטורה. (ברירת מחדל: True) | BOOLEAN | לא | true / false |

**הערות:**
- צומת זה מיושן ומסומן כצומת מדור קודם. הוא נשמר לתאימות לאחור עם תהליכי עבודה ישנים.
- הפרמטר `prompt` חובה: prompt ריק גורם לצומת להעלות שגיאה.
- `pbr` מחייב `texture`. כאשר `texture` כבוי, הצומת כופה `pbr` כבוי ומתעלם מערכו. גם ל-`auto_size` אין השפעה ללא `texture`.
- כאשר `smart_low_poly` מופעל ו-`face_limit` מוגדר לערך שאינו -1, מגבלת הפאות חייבת להיות בין 500 ל-20,000 עבור פלט משולשים, או בין 500 ל-10,000 כאשר `quad` מופעל; אחרת הצומת מעלה שגיאה.
- כאשר `quad` מופעל, רשת ה-quad המיוצרת מסופקת כ-FBX, כך שפלט FBX מאוכלס ופלט GLB נשאר ריק.
- הפרמטר `style` מתקבל אך מתעלמים ממנו.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | שם הקובץ של המודל התלת-ממדי המיוצר בתבנית `<task_id>.<format>`, נשמר לתאימות לאחור בלבד. | STRING |
| `model task_id` | מזהה המשימה הייחודי עבור תהליך יצירת המודל. | MODEL_TASK_ID |
| `GLB` | המודל התלת-ממדי המיוצר בפורמט GLB. ריק כאשר `quad` מופעל. | FILE3DGLB |
| `FBX` | המודל התלת-ממדי המיוצר בפורמט FBX. מאוכלס רק כאשר `quad` מופעל. | FILE3DFBX |
