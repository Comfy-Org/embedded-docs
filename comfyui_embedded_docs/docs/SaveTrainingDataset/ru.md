# Сохранить обучающий набор данных

Этот узел сохраняет подготовленный набор данных для обучения на жесткий диск вашего компьютера. Он принимает закодированные данные, которые включают латентные представления изображений и соответствующие текстовые условия, и организует их в несколько меньших файлов, называемых шардами, для упрощения управления. Узел автоматически создает папку в каталоге наборов данных и сохраняет как файлы данных шардов, так и файл метаданных, описывающий набор данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей латентов из MakeTrainingDataset. | LATENT | Да | N/A |
| `conditioning` | Список списков кондиционирования из MakeTrainingDataset. | CONDITIONING | Да | N/A |
| `folder_name` | Имя папки для сохранения набора данных внутри каталога наборов данных. Допускаются вложенные папки, например 'project/run1'. (по умолчанию: "training_dataset") | STRING | Да | N/A |
| `shard_size` | Количество образцов в файле шарда. (по умолчанию: 1000) | INT | Да | 1 to 100000 |

**Примечание:** Количество элементов в списке `latents` должно точно совпадать с количеством элементов в списке `conditioning`. Узел выдает ошибку, если эти количества не совпадают. `folder_name` должно указывать на подпапку каталога наборов данных: корневая папка наборов данных, а также любой путь, выходящий за ее пределы (например, '..' или абсолютный путь), отклоняются.

## Выходы

Этот узел не производит никаких выходных данных. Он сохраняет набор данных в виде пронумерованных файлов-шардов (например, `shard_0000.pkl`) и файла `metadata.json` внутри выбранной папки в каталоге наборов данных.
