# Сохранить обучающий набор данных

Этот узел сохраняет закодированный набор данных для обучения на диск для эффективной загрузки во время обучения. Он принимает латенты изображений и соответствующее текстовое кондиционирование, разбивает их на более мелкие файлы, называемые шардами, и сохраняет их в папке внутри каталога datasets. Он также записывает файл метаданных с описанием набора данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей латентов из MakeTrainingDataset. | LATENT | Да | N/A |
| `conditioning` | Список списков кондиционирования из MakeTrainingDataset. | CONDITIONING | Да | N/A |
| `folder_name` | Имя папки для сохранения набора данных внутри каталога datasets. Разрешены подпапки, например 'project/run1'. (по умолчанию: "training_dataset") | STRING | Да | N/A |
| `shard_size` | Количество образцов на файл-шард. (по умолчанию: 1000) | INT | Да | от 1 до 100000 |

**Примечание:** Количество элементов в `latents` должно точно совпадать с количеством элементов в `conditioning`; узел выдаёт ошибку, если эти количества не совпадают. Значение `folder_name` должно указывать на подпапку каталога datasets (например, `my_dataset`) — оно не может быть самим каталогом datasets, а имена папок, которые при разрешении оказываются за пределами каталога datasets, отклоняются. Параметр `shard_size` является расширенной настройкой.

## Выходы

Этот узел не создаёт никаких выходных данных. Его функция — сохранять файлы на диск. Каждый шард сохраняется как файл `shard_XXXX.pkl` в выбранной папке, а файл `metadata.json` фиксирует общее количество образцов, количество шардов и размер шарда.
