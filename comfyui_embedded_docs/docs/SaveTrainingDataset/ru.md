# Сохранить обучающий набор данных

Этот узел сохраняет закодированный набор обучающих данных на диск для эффективной загрузки во время обучения. Он принимает латентные представления изображений и соответствующие текстовые условия, разбивает их на меньшие файлы, называемые шардами, и сохраняет их в папке внутри каталога наборов данных. Он также записывает файл метаданных, описывающий набор данных.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `latents` | Список словарей латентных представлений из MakeTrainingDataset. | LATENT | Да | N/A |
| `conditioning` | Список списков кондиционирования из MakeTrainingDataset. | CONDITIONING | Да | N/A |
| `folder_name` | Имя папки для сохранения набора данных внутри каталога datasets. Допускаются вложенные папки, например 'project/run1'. (по умолчанию: "training_dataset") | STRING | Да | N/A |
| `shard_size` | Количество образцов в одном файле шарда. (по умолчанию: 1000) | INT | Да | 1 до 100000 |

**Примечание:** Количество элементов в `latents` должно точно соответствовать количеству элементов в `conditioning`; узел вызывает ошибку, если эти количества не совпадают. `folder_name` должно указывать на вложенную папку каталога datasets (например `my_dataset`) — это не может быть сам каталог datasets, а имена папок, которые будут разрешаться за пределами каталога datasets, отклоняются.

## Выходы

Этот узел не производит выходных данных. Его функция — сохранять файлы на ваш диск. Каждый шард сохраняется как файл `shard_XXXX.pkl` в выбранной папке, а файл `metadata.json` записывает общее количество образцов, количество шардов и размер шарда.
