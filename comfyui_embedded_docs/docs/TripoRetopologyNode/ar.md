# TripoRetopologyNode

Tripo: Retopology تأخذ نموذجًا ثلاثي الأبعاد عالي المضلعات تم إنشاؤه بواسطة عقدة Tripo سابقة، وتعيد بناءه كنسخة منخفضة المضلعات بطوبولوجيا نظيفة. تُرسل النموذج إلى خدمة إعادة بناء الطوبولوجيا (Retopology) من Tripo، وتنتظر اكتمال المهمة، ثم تنزّل النموذج المكتمل وتُعرّض معرّف مهمته لاستخدامه بواسطة عقد Tripo الأخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة النموذج المصدر عالي المضلعات. يقبل معرّف مهمة من عقدة توليد Tripo أو معرّف مهمة تجزئة من عقدة Tripo: Segment Model. | STRING | نعم | معرّف مهمة Tripo |
| `face_limit` | عدد الأوجه المستهدف: من 500 إلى 20,000 مثلث أو من 500 إلى 10,000 رباعي. القيمة -1 تترك الاختيار لـ Tripo. (الافتراضي: -1) | INT | نعم | -1 (تلقائي)<br>من 500 إلى 20,000 (مثلثات)<br>من 500 إلى 10,000 (رباعيات) |
| `quad` | إخراج شبكة رباعية المضلعات. تُسلّم Tripo الشبكات الرباعية بصيغة FBX، لذلك تصل النتيجة على مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | نعم | True<br>False (الافتراضي) |
| `bake` | ينقل القوام المصدر إلى الشبكة منخفضة المضلعات. (الافتراضي: True) | BOOLEAN | لا | True (الافتراضي)<br>False |
| `part_names` | أسماء الأجزاء من Tripo: Segment Model مفصولة بفواصل. الإدخال الفارغ يعالج النموذج بالكامل. (الافتراضي: "") | STRING | لا | أسماء أجزاء النموذج أو فارغ |

ملاحظة: عندما يتم تعيين `face_limit` إلى -1، يقرر Tripo عدد الأوجه تلقائيًا. عند تفعيل `quad`، يكون الحد الأقصى لعدد الأوجه هو 10,000 رباعي بدلاً من 20,000 مثلث، وتُقدَّم النتيجة بصيغة FBX (يبقى مخرج GLB فارغًا). عندما تكون `part_names` فارغة، تتم معالجة النموذج بالكامل.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | مخرج متوافق مع الإصدارات السابقة يحدد ملف النموذج المكتمل. يجب أن تستخدم سير العمل الأحدث مخرجي GLB أو FBX بدلاً من ذلك. | STRING |
| `معرّف مهمة النموذج` | معرّف مهمة نتيجة إعادة بناء الطوبولوجيا المكتملة. يمكن تمريره إلى عقد Tripo أخرى للإشارة إلى هذا النموذج. | STRING |
| `GLB` | النموذج منخفض المضلعات المُعاد بناؤه طوبولوجيًا بصيغة GLB. يكون فارغًا عند تفعيل `quad`. | GLB FILE |
| `FBX` | النموذج منخفض المضلعات المُعاد بناؤه طوبولوجيًا بصيغة FBX. يُعبأ هذا المخرج فقط عند تفعيل `quad`. | FBX FILE |
