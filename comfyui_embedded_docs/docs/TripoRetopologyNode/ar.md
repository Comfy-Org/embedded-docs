# Tripo: إعادة بناء الطوبولوجيا

تأخذ عقدة Tripo: Retopology نموذجًا ثلاثي الأبعاد عالي المضلعات جرى إنشاؤه بواسطة عقدة Tripo سابقة، وتعيد بناءه كنسخة منخفضة المضلعات ذات طوبولوجيا نظيفة. ترسل النموذج إلى خدمة إعادة الطوبولوجيا من Tripo، وتنتظر انتهاء المهمة، ثم تنزّل النموذج المكتمل وتتيح معرّف المهمة الخاص به لاستخدامه بواسطة عقد Tripo الأخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة النموذج المصدر عالي المضلعات. يقبل معرّف مهمة نموذج من عقدة توليد Tripo أو معرّف مهمة تقسيم من Tripo: Segment Model. | STRING | نعم | معرّف مهمة Tripo |
| `face_limit` | عدد الأوجه المستهدف: 500-20,000 مثلث أو 500-10,000 رباعيات. القيمة -1 تتيح لـ Tripo الاختيار. (افتراضي: -1) | INT | نعم | -1 (تلقائي)<br>500 إلى 20,000 (مثلثات)<br>500 إلى 10,000 (رباعيات) |
| `quad` | إخراج شبكة رباعية. تُسلّم Tripo الشبكات الرباعية بصيغة FBX، لذلك تصل النتيجة عبر مخرج FBX ويبقى مخرج GLB فارغًا. (افتراضي: False) | BOOLEAN | نعم | True<br>False (افتراضي) |
| `bake` | دمج خامات المصدر على الشبكة منخفضة المضلعات. (افتراضي: True) | BOOLEAN | لا | True (افتراضي)<br>False |
| `part_names` | أسماء الأجزاء مفصولة بفواصل من Tripo: Segment Model. فارغ يعني معالجة النموذج كاملًا. (افتراضي: "") | STRING | لا | أسماء أجزاء النموذج أو فارغ |

ملاحظة: عندما تُضبط `face_limit` على -1، يقرر Tripo عدد الأوجه تلقائيًا. عند تمكين `quad`، يكون الحد الأقصى لعدد الأوجه 10,000 رباعية بدلًا من 20,000 مثلث، وتُقدَّم النتيجة بصيغة FBX (يبقى مخرج GLB فارغًا). عندما تكون `part_names` فارغة، تتم معالجة النموذج كاملًا. إذا كانت `face_limit` أي قيمة غير -1 وخرجت عن النطاق المسموح به، ترفع العقدة خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | مخرج متوافق مع الإصدارات السابقة يحدد ملف النموذج المكتمل. ينبغي لسير العمل الأحدث استخدام مخرجات GLB أو FBX بدلًا منه. | STRING |
| `model task_id` | معرّف مهمة نتيجة إعادة الطوبولوجيا المكتملة. يمكن تمريره إلى عقد Tripo أخرى للإشارة إلى هذا النموذج. | STRING |
| `GLB` | النموذج منخفض المضلعات المعاد بناؤه طوبولوجيًا بصيغة GLB. فارغ عند تمكين `quad`. | GLB FILE |
| `FBX` | النموذج منخفض المضلعات المعاد بناؤه طوبولوجيًا بصيغة FBX. يُملأ فقط عند تمكين `quad`. | FBX FILE |
