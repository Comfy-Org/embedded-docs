# TripoRetopologyNode

Tripo: Retopology یک مدل سه‌بعدی با پلی‌گان بالا را که توسط یک گره قبلی Tripo تولید شده است می‌گیرد و آن را به‌صورت نسخه‌ای کم‌پلی‌گان با توپولوژی تمیز بازسازی می‌کند. این گره مدل را به سرویس بازسازی توپولوژی Tripo ارسال می‌کند، منتظر پایان وظیفه می‌ماند، سپس مدل تمام‌شده را دانلود کرده و شناسه وظیفه آن را برای استفاده در سایر گره‌های Tripo در دسترس قرار می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدل منبع با پلی‌گان بالا. یک شناسه وظیفه مدل از یک گره تولید Tripo یا یک شناسه وظیفه بخش از گره Tripo: Segment Model را می‌پذیرد. | STRING | بله | شناسه وظیفه Tripo |
| `face_limit` | تعداد وجه هدف: 500 تا 20,000 مثلث یا 500 تا 10,000 چهارضلعی. مقدار `-1` به Tripo اجازه می‌دهد انتخاب کند. (پیش‌فرض: `-1`) | INT | بله | `-1` (خودکار)<br>500 تا 20,000 (مثلث)<br>500 تا 10,000 (چهارضلعی) |
| `quad` | خروجی مش چهارضلعی. Tripo مش‌های چهارضلعی را به‌صورت FBX تحویل می‌دهد، بنابراین نتیجه روی خروجی FBX قرار می‌گیرد و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | بله | True<br>False (پیش‌فرض) |
| `bake` | بافت‌های منبع را روی مش کم‌پلی‌گان پخت می‌کند. (پیش‌فرض: True) | BOOLEAN | خیر | True (پیش‌فرض)<br>False |
| `part_names` | نام بخش‌ها با جداکننده کاما از گره Tripo: Segment Model. مقدار خالی کل مدل را پردازش می‌کند. (پیش‌فرض: "") | STRING | خیر | نام بخش‌های مدل یا خالی |

توجه: وقتی `face_limit` روی `-1` تنظیم شود، Tripo تعداد وجه را به‌صورت خودکار تعیین می‌کند. وقتی `quad` فعال باشد، حداکثر تعداد وجه به‌جای 20,000 مثلث، 10,000 چهارضلعی است و نتیجه به‌صورت FBX ارائه می‌شود (خروجی GLB خالی می‌ماند). وقتی `part_names` خالی باشد، کل مدل پردازش می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | خروجی سازگار با نسخه‌های قبلی که فایل مدل تکمیل‌شده را شناسایی می‌کند. گردش‌های کاری جدیدتر باید به‌جای آن از خروجی‌های GLB یا FBX استفاده کنند. | STRING |
| `task_id مدل` | شناسه وظیفه نتیجه بازسازی‌شده نهایی. برای ارجاع به این مدل می‌توان آن را به سایر گره‌های Tripo ارسال کرد. | STRING |
| `GLB` | مدل کم‌پلی‌گان بازسازی‌شده در قالب GLB. وقتی `quad` فعال باشد، خالی است. | GLB FILE |
| `FBX` | مدل کم‌پلی‌گان بازسازی‌شده در قالب FBX. فقط زمانی مقداردهی می‌شود که `quad` فعال باشد. | FBX FILE |
