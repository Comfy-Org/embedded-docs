# Tripo: بازتوپولوژی

Tripo: Retopology یک مدل سه‌بعدی پرحجم (high-poly) را که توسط یک گره Tripo پیشین ساخته شده است می‌گیرد و آن را به نسخه‌ای کم‌حجم (low-poly) با توپولوژی تمیز بازسازی می‌کند. این گره مدل را به سرویس بازساخت توپولوژی Tripo می‌فرستد، منتظر می‌ماند تا تسک تمام شود، سپس مدل نهایی را دانلود می‌کند و شناسه تسک آن را برای استفاده دیگر گره‌های Tripo در دسترس قرار می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه تسک مدل مبدأ پرحجم. یک شناسه تسک مدل از یک گره تولید Tripo یا یک شناسه تسک قطعه (segment) از Tripo: Segment Model را می‌پذیرد. | STRING | بله | شناسه تسک Tripo |
| `face_limit` | تعداد وجه هدف: 500 تا 20,000 مثلث یا 500 تا 10,000 چهارضلعی. مقدار -1 باعث می‌شود Tripo خودش انتخاب کند. (پیش‌فرض: -1) | INT | بله | -1 (خودکار)<br>500 تا 20,000 (مثلث)<br>500 تا 10,000 (چهارضلعی) |
| `quad` | خروجی مش چهارضلعی. Tripo مش‌های چهارضلعی را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه در خروجی FBX می‌آید و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | بله | True<br>False (پیش‌فرض) |
| `bake` | بافت‌های (texture) مبدأ را روی مش کم‌حجم بیک کنید. (پیش‌فرض: True) | BOOLEAN | خیر | True (پیش‌فرض)<br>False |
| `part_names` | نام قطعه‌ها جدا شده با کاما از Tripo: Segment Model. مقدار خالی کل مدل را پردازش می‌کند. (پیش‌فرض: "") | STRING | خیر | نام قطعه‌های مدل یا خالی |

نکته: وقتی `face_limit` روی -1 تنظیم شود، Tripo تعداد وجه را به‌صورت خودکار تعیین می‌کند. وقتی `quad` فعال باشد، حداکثر محدودیت وجه 10,000 چهارضلعی به‌جای 20,000 مثلث است و نتیجه به‌صورت FBX ارائه می‌شود (خروجی GLB خالی می‌ماند). وقتی `part_names` خالی باشد، کل مدل پردازش می‌شود. اگر `face_limit` هر مقداری غیر از -1 باشد و خارج از محدوده مجاز قرار بگیرد، گره خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | خروجی سازگار با نسخه‌های پیشین که فایل مدل تکمیل‌شده را مشخص می‌کند. گردش‌کارهای جدیدتر باید به‌جای آن از خروجی‌های GLB یا FBX استفاده کنند. | STRING |
| `model task_id` | شناسه تسک نتیجه نهایی بازساخت توپولوژی. می‌تواند به سایر گره‌های Tripo داده شود تا به این مدل ارجاع دهند. | STRING |
| `GLB` | مدل کم‌حجم بازساخته‌شده با توپولوژی جدید در قالب GLB. وقتی `quad` فعال باشد خالی است. | GLB FILE |
| `FBX` | مدل کم‌حجم بازساخته‌شده با توپولوژی جدید در قالب FBX. فقط وقتی `quad` فعال باشد پر می‌شود. | FBX FILE |
