# TripoRetopologyNode

Tripo: Ретопология принимает высокополигональную 3D-модель, созданную более ранним узлом Tripo, и перестраивает её в низкополигональную версию с чистой топологией. Модель отправляется в сервис ретопологии Tripo, ожидается завершение задачи, затем загружается готовая модель и предоставляется её идентификатор задачи для использования другими узлами Tripo.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Идентификатор задачи исходной высокополигональной модели. Принимает идентификатор задачи модели от узла генерации Tripo или идентификатор задачи сегмента от Tripo: Segment Model. | STRING | Да | Tripo task ID |
| `face_limit` | Целевое количество граней: 500–20 000 треугольников или 500–10 000 четырехугольников. -1 позволяет Tripo выбирать автоматически. (по умолчанию: -1) | INT | Да | -1 (automatic)<br>500 до 20,000 (triangles)<br>500 до 10,000 (quads) |
| `quad` | Выход четырехугольной сетки. Tripo поставляет четырехугольные сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остается пустым. (по умолчанию: False) | BOOLEAN | Да | True<br>False (default) |
| `bake` | Запечь исходные текстуры на низкополигональную сетку. (по умолчанию: True) | BOOLEAN | Нет | True (default)<br>False |
| `part_names` | Разделенные запятыми имена частей из Tripo: Segment Model. Пусто — обрабатывается вся модель. (по умолчанию: "") | STRING | Нет | Model part names or empty |

Примечание: Когда `face_limit` установлен в -1, Tripo выбирает количество граней автоматически. Когда `quad` включен, максимальное количество граней — 10 000 четырехугольников вместо 20 000 треугольников, и результат предоставляется в формате FBX (выход GLB остается пустым). Когда `part_names` пусто, обрабатывается вся модель.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Обратно совместимый выход, который идентифицирует завершенный файл модели. В новых рабочих процессах вместо него следует использовать выходы GLB или FBX. | STRING |
| `model task_id` | Идентификатор задачи завершенного результата ретопологии. Может быть передан другим узлам Tripo для ссылки на эту модель. | STRING |
| `GLB` | Ретопологизированная низкополигональная модель в формате GLB. Пусто, когда включен `quad`. | GLB FILE |
| `FBX` | Ретопологизированная низкополигональная модель в формате FBX. Заполняется только когда включен `quad`. | FBX FILE |
