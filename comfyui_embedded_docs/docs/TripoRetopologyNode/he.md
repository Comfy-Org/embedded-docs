# TripoRetopologyNode

Tripo: Retopology מקבל מודל תלת-ממד high-poly שהופק על ידי צומת Tripo קודם ובונה אותו מחדש כגרסת low-poly עם טופולוגיה נקייה. הוא שולח את המודל לשירות הרטופולוגיה של Tripo, ממתין לסיום המשימה, ואז מוריד את המודל המוגמר וחושף את מזהה המשימה שלו לשימוש על ידי צמתי Tripo אחרים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | מזהה המשימה של מודל המקור ה-high-poly. מקבל מזהה משימת מודל מצומת יצירה של Tripo או מזהה משימת סגמנט מ-Tripo: Segment Model. | STRING | כן | מזהה משימה של Tripo |
| `face_limit` | מספר הפאות הרצוי: 500-20,000 משולשים או 500-10,000 קוודים. -1 מאפשר ל-Tripo לבחור. (ברירת מחדל: -1) | INT | כן | -1 (automatic)<br>500 to 20,000 (triangles)<br>500 to 10,000 (quads) |
| `quad` | פלט רשת קווד. Tripo מספק רשתות קווד כקובצי FBX, כך שהתוצאה מגיעה לפלט ה-FBX ופלט ה-GLB נשאר ריק. (ברירת מחדל: False) | BOOLEAN | כן | True<br>False (default) |
| `bake` | בצע Bake של טקסטורות המקור אל רשת ה-low-poly. (ברירת מחדל: True) | BOOLEAN | לא | True (default)<br>False |
| `part_names` | שמות חלקים מופרדים בפסיקים מתוך Tripo: Segment Model. ערך ריק מעבד את המודל כולו. (ברירת מחדל: "") | STRING | לא | שמות חלקי מודל או ריק |

הערה: כאשר `face_limit` מוגדר לערך -1, Tripo קובע את מספר הפאות באופן אוטומטי. כאשר `quad` מופעל, מגבלת מספר הפאות המרבית היא 10,000 קוודים במקום 20,000 משולשים, והתוצאה מסופקת כקובץ FBX (פלט ה-GLB נשאר ריק). כאשר `part_names` ריק, המודל כולו מעובד. אם `face_limit` אינו -1 והוא מחוץ לטווח המותר, הצומת מחזיר שגיאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | פלט תואם לאחור שמזהה את קובץ המודל שהושלם. תהליכי עבודה חדשים יותר צריכים להשתמש בפלטי GLB או FBX במקום. | STRING |
| `model task_id` | מזהה המשימה של תוצאת הרטופולוגיה המוגמרת. ניתן להעבירו לצמתי Tripo אחרים כדי להפנות למודל זה. | STRING |
| `GLB` | מודל ה-low-poly שעבר רטופולוגיה בפורמט GLB. ריק כאשר `quad` מופעל. | GLB FILE |
| `FBX` | מודל ה-low-poly שעבר רטופולוגיה בפורמט FBX. מאוכלס רק כאשר `quad` מופעל. | FBX FILE |
