# تبدیل متن Quiver به SVG

گره Quiver Text to SVG یک تصویر گرافیک برداری مقیاس‌پذیر (SVG) را از توضیح متنی و با استفاده از مدل‌های Quiver AI تولید می‌کند. می‌توانید به‌صورت اختیاری تصاویر مرجع و دستورالعمل‌های سبک ارائه دهید تا فرآیند تولید را هدایت کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی خروجی SVG موردنظر. این دستور اصلی برای چیزی است که باید تولید شود. | STRING | بله | ناموجود |
| `instructions` | راهنمای سبک یا قالب‌بندی اضافی. این یک پارامتر پیشرفته و اختیاری است. | STRING | خیر | ناموجود |
| `reference_images` | حداکثر ۴ تصویر مرجع برای هدایت تولید. این یک ورودی اختیاری است. | IMAGE | خیر | 0 تا 4 تصویر |
| `model` | مدل مورد استفاده برای تولید SVG. انتخاب یک مدل پارامترهای اضافی مخصوص همان مدل را آشکار می‌کند: `temperature`، `top_p` و `presence_penalty`. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `seed` | مقدار seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند. پیش‌فرض: 0. | INT | بله | 0 تا 2147483647 |
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌بخشند و توکن‌های بیشتری مصرف می‌کنند. فقط توسط مدل‌های Arrow 2 استفاده می‌شود (پیش‌فرض: "high"). | COMBO | خیر | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |

**توجه:** ورودی `reference_images` حداکثر ۴ تصویر را می‌پذیرد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `SVG` | تصویر گرافیک برداری مقیاس‌پذیر (SVG) تولیدشده. | SVG |
