# Quiver Text to SVG

Узел Quiver Text to SVG создаёт изображение Scalable Vector Graphic (SVG) из текстового описания с использованием моделей Quiver AI. При необходимости можно предоставить эталонные изображения и инструкции по стилю, чтобы управлять процессом генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовое описание желаемого выходного SVG. Это основная инструкция для того, что нужно сгенерировать. | STRING | Да | N/A |
| `instructions` | Дополнительные указания по стилю или форматированию. Это необязательный расширенный параметр. | STRING | Нет | N/A |
| `reference_images` | До 4 эталонных изображений для управления генерацией. Это необязательный вход. | IMAGE | Нет | от 0 до 4 изображений |
| `model` | Модель для генерации SVG. При выборе модели отображаются дополнительные параметры, относящиеся к этой модели: `temperature`, `top_p` и `presence_penalty`. | DYNAMIC_COMBO | Да | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `seed` | `seed` для определения, следует ли перезапускать узел; фактические результаты недетерминированы независимо от `seed`. По умолчанию: 0. | INT | Да | от 0 до 2147483647 |
| `reasoning_effort` | Сколько рассуждений модель выполняет перед отрисовкой. Более высокие уровни повышают детализацию и требуют больше токенов. Используется только моделями Arrow 2 (по умолчанию: "high"). | COMBO | Нет | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |

**Примечание:** Вход `reference_images` принимает максимум 4 изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SVG` | Сгенерированное изображение Scalable Vector Graphic (SVG). | SVG |
