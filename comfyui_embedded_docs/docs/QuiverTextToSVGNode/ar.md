# Quiver تحويل نص إلى SVG (قديم)

تقوم عقدة Quiver Text to SVG بإنشاء صورة SVG (رسوميات متجهية قابلة للتحجيم) من وصف نصي باستخدام نماذج Quiver AI. يمكنك اختياريًا تقديم صور مرجعية وتعليمات نمط لتوجيه عملية التوليد.

**ملاحظة:** تم وضع علامة على هذه العقدة على أنها مهملة في الكود المصدري.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | وصف نصي لمخرجات SVG المطلوبة. هذه هي التعليمة الرئيسية لما يجب توليده. | STRING | نعم | N/A |
| `instructions` | إرشادات إضافية للنمط أو التنسيق. هذا معامل اختياري ومتقدم. | STRING | لا | N/A |
| `reference_images` | حتى 4 صور مرجعية لتوجيه عملية التوليد. هذا مدخل اختياري. | IMAGE | لا | 0 إلى 4 صور |
| `model` | النموذج المستخدم لتوليد SVG. يؤدي اختيار نموذج إلى إظهار معاملات إضافية خاصة بذلك النموذج: `temperature`، `top_p`، و`presence_penalty`. | DYNAMIC_COMBO | نعم | `"arrow-2"`<br>`"arrow-2-telos"` |
| `seed` | البذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة. القيمة الافتراضية: 0. | INT | نعم | 0 إلى 2147483647 |
| `reasoning_effort` | مقدار الاستدلال الذي يستغرقه النموذج قبل الرسم. المستويات الأعلى تحسّن التفاصيل وتستهلك رموزًا أكثر. تُستخدم فقط مع نماذج Arrow 2 (القيمة الافتراضية: `"high"`). | COMBO | لا | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |

**ملاحظة:** يقبل المدخل `reference_images` بحد أقصى 4 صور.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `SVG` | صورة SVG (رسوميات متجهية قابلة للتحجيم) المولدة. | SVG |
