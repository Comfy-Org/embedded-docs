# TypeSafe Jev (Score)

TypeSafe Jev (Score) ノードは、接続されたテキスト、画像、またはその両方を 1～10 で評価し、その評価をしきい値と比較します。`result` を If/Else Switch ノードに接続してスコアに基づいた処理を行ったり、`score` を読み取って生の評価値を使用したりできます。これは API ノードです。Comfy のサーバー上で実行され、クレジット付きの Comfy.org アカウントが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデル。現在利用できるモデルは `jev-1.14.0` の 1 つのみです。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 評価対象。1～10 のスケールで指定します。デフォルトのように、1 と 10 が何を意味するかを記述してください（デフォルト: `Rate the technical quality of the image from 1 (worst) to 10 (best).`）。 | STRING | はい | 1～1000 文字 |
| `threshold` | スコアがこの値以上の場合に `result` が true になります（デフォルト: 5.0）。 | FLOAT | はい | 1.0～10.0（ステップ 0.1） |
| `images` | 質問の対象となる画像。合計 32 枚までです。バッチ入力は画像 1 枚につき 1 回としてカウントされます。すべての画像の長辺は画像の総数によって制限されます。4 枚までなら 1568 px、8 枚までなら 1024 px、16 枚までなら 768 px、32 枚までなら 512 px です。そのため、バッチが大きいほど各画像の詳細は少なくなります。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキスト。プロンプトや LLM の応答などです。 | STRING | いいえ | 0～3000 文字 |

**注意:**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合、ノードはエラーを発生させます。
- スコアは 1～10 で報告され、スコアが `threshold` 以上の場合に `result` が true になります。
- 課金はトークンベースです。ノード上の価格バッジには、1M トークンあたりのおおよそのレートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `result` | `score` が `threshold` 以上の場合に true。 | BOOLEAN |
| `score` | 1（最悪）～10（最高）の評価値。 | FLOAT |
