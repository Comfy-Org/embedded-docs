# TypeSafe Jev (Score)

צומת TypeSafe Jev (Score) מדרג טקסט, תמונות או שניהם מחוברים מ-1 עד 10 ומשווה את הדירוג לסף. חבר `result` לצומת If/Else Switch כדי לפעול לפי הניקוד, או קרא את `score` כדי להשתמש בדירוג הגולמי. זהו צומת API ודורש חשבון Comfy.org ומפתח API.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. נכון לעכשיו זמין מודל אחד בלבד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | מה לדרג, בסולם מ-1 עד 10. ציין מה המשמעות של 1 ושל 10, כמו בברירת המחדל (ברירת מחדל: `Rate the technical quality of the image from 1 (worst) to 10 (best).`). | STRING | כן | 1 עד 1000 תווים |
| `threshold` | `result` הוא true כאשר הניקוד הוא לפחות ערך זה (ברירת מחדל: 5.0). | FLOAT | כן | 1.0 עד 10.0 (צעד: 0.1) |
| `images` | התמונות שהשאלה עוסקת בהן. עד 32 תמונות בסך הכל; קלט מקובץ נספר פעם אחת לכל תמונה, ויותר מ-4 תמונות נשלחות בגודל קטן יותר. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חבר טקסט או לפחות תמונה אחת; הצומת מחזיר שגיאה כאשר שניהם ריקים.
- הניקוד מדווח מ-1 עד 10, ו-`result` הוא true כאשר הוא לפחות `threshold`.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל 1M טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `result` | true כאשר `score` הוא לפחות `threshold`. | BOOLEAN |
| `score` | הדירוג מ-1 (הגרוע ביותר) עד 10 (הטוב ביותר). | FLOAT |
