# StabilityAudioToAudio

ממיר דגימות אודיו קיימות ליצירות חדשות באיכות גבוהה באמצעות הוראות טקסט. צומת זה מקבל קובץ אודיו כקלט ומשנה אותו בהתבסס על הנחיית הטקסט שלך כדי ליצור תוכן אודיו חדש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI שיש להשתמש בו לשינוי האודיו | COMBO | כן | "stable-audio-2.5" |
| `prompt` | הוראות טקסט המתארות כיצד לשנות את האודיו (ברירת מחדל: ריק, אורך מקסימלי: 10,000 תווים) | STRING | כן | |
| `audio` | האודיו חייב להיות באורך שבין 6 ל-190 שניות | AUDIO | כן | |
| `duration` | שולט במשך בשניות של האודיו שנוצר (ברירת מחדל: 190) | INT | לא | 1-190 |
| `seed` | ערך ה-seed האקראי המשמש ליצירה (ברירת מחדל: 0) | INT | לא | 0-4294967294 |
| `steps` | שולט במספר צעדי הדגימה (ברירת מחדל: 8) | INT | לא | 4-8 |
| `strength` | הפרמטר שולט במידת ההשפעה שיש לפרמטר האודיו על האודיו שנוצר (ברירת מחדל: 1.0) | FLOAT | לא | 0.01-1.0 |

**הערה:** האודיו בקלט חייב להיות באורך של בין 6 ל-190 שניות. לטקסט ההנחיה אורך מקסימלי של 10,000 תווים.
