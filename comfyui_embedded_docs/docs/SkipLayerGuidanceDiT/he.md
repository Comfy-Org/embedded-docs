# SkipLayerGuidanceDiT

משפר את ההנחיה לעבר מבנה מפורט על ידי שימוש בקבוצה נוספת של CFG שלילי עם שכבות מדולגות. גרסה גנרית זו של SkipLayerGuidance יכולה לשמש בכל מודל DiT והיא בהשראת Perturbed Attention Guidance. המימוש הניסיוני המקורי נוצר עבור SD3.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו להחיל הנחיית שכבות מדולגות | MODEL | כן | - |
| `double_layers` | מספרי שכבות מופרדים בפסיקים עבור בלוקים כפולים לדילוג (ברירת מחדל: "7, 8, 9") | STRING | כן | - |
| `single_layers` | מספרי שכבות מופרדים בפסיקים עבור בלוקים בודדים לדילוג (ברירת מחדל: "7, 8, 9") | STRING | כן | - |
| `scale` | מקדם קנה מידה של הנחיה (ברירת מחדל: 3.0) | FLOAT | כן | 0.0 - 10.0 |
| `start_percent` | אחוז התחלה להחלת ההנחיה (ברירת מחדל: 0.01) | FLOAT | כן | 0.0 - 1.0 |
| `end_percent` | אחוז סיום להחלת ההנחיה (ברירת מחדל: 0.15) | FLOAT | כן | 0.0 - 1.0 |
| `rescaling_scale` | מקדם קנה מידה לחישוב מחדש (rescaling) להתאמת גודל הפלט (ברירת מחדל: 0.0, כלומר ללא חישוב מחדש) | FLOAT | כן | 0.0 - 10.0 |

**הערה:** אם גם `double_layers` וגם `single_layers` ריקים (אינם מכילים מספרי שכבות), הצומת מחזיר את המודל המקורי ללא החלת הנחיה.
