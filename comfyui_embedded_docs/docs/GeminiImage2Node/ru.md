# Nano Banana Pro (Google Gemini Image)

Узел GeminiImage2Node создаёт или редактирует изображения с помощью модели Google Vertex AI Gemini. Вы задаёте текстовый промпт и, при необходимости, эталонные изображения или файлы; узел отправляет их в API и возвращает сгенерированное изображение, а также текстовый ответ, если это запрошено.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт, описывающий изображение для генерации или изменения. Укажите все ограничения, стили или детали, которым должна следовать модель. Промпт должен содержать по крайней мере один символ после удаления пробелов. | STRING | Да | N/A |
| `model` | Конкретная модель Gemini для генерации. Вариант «Nano Banana 2 (Gemini 3.1 Flash Image)» соответствует внутренней модели `gemini-3.1-flash-image`, а «gemini-3-pro-image-preview» — `gemini-3-pro-image`. | COMBO | Да | `"gemini-3-pro-image-preview"`<br>`"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `seed` | Когда seed зафиксирован на определённом значении, модель прилагает максимальные усилия для возврата одинакового ответа при повторных запросах. Детерминированный вывод не гарантируется. Кроме того, изменение модели или таких параметров, как температура, может вызывать различия в ответе даже при одном и том же seed. По умолчанию используется случайное значение seed. По умолчанию: 42. | INT | Да | от 0 до 18446744073709551615 |
| `aspect_ratio` | Если установлено значение «auto», соотношение сторон соответствует вашему входному изображению; если изображение не предоставлено, обычно генерируется изображение с соотношением сторон 16:9. По умолчанию: «auto». | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"` |
| `resolution` | Целевое разрешение выходного изображения. Для 2K/4K используется встроенный апскейлер Gemini. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"` |
| `response_modalities` | Выберите «IMAGE» для вывода только изображения или «IMAGE+TEXT», чтобы получить и сгенерированное изображение, и текстовый ответ. | COMBO | Да | `"IMAGE+TEXT"`<br>`"IMAGE"` |
| `images` | Необязательные эталонные изображения. Чтобы включить несколько изображений, используйте узел Batch Images (до 14). | IMAGE | Нет | N/A |
| `files` | Необязательные файлы, используемые в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | Нет | N/A |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию: предопределённый системный промпт для генерации изображений. | STRING | Нет | N/A |

**Ограничения:**

* Вход `images` поддерживает максимум 14 изображений. Если передано больше, возникает ошибка.
* Если передано более 10 изображений, первые 10 загружаются как URL-ссылки, а остальные отправляются внутри запроса.
* Вход `files` должен быть подключён к узлу, который выводит тип данных `GEMINI_INPUT_FILES`.
* Когда для `response_modalities` установлено значение «IMAGE», возвращается только изображение, а текстовый вывод остаётся пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение, сгенерированное или отредактированное моделью Gemini. | IMAGE |
| `string` | Текстовый ответ модели. Этот вывод будет пустым, если для `response_modalities` установлено значение «IMAGE». | STRING |
