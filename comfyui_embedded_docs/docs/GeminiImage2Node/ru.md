# Nano Banana Pro (Google Gemini Image)

Синхронно генерируйте или редактируйте изображения через Google Vertex AI Gemini API. Вы задаёте текстовый запрос и при необходимости можете прикрепить эталонные изображения или входные файлы Gemini. Узел возвращает сгенерированное изображение и, в зависимости от выбранного режима ответа, текстовый ответ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации или правки, которые нужно применить. Укажите любые ограничения, стили или детали, которым должна следовать модель. Запрос должен содержать хотя бы один символ после удаления пробельных символов. | STRING | Да | N/A |
| `model` | Модель Gemini, используемая для генерации. Опция "Nano Banana 2 (Gemini 3.1 Flash Image)" отправляется как `gemini-3.1-flash-image`; "gemini-3-pro-image-preview" отправляется как `gemini-3-pro-image`. | COMBO | Да | "gemini-3-pro-image-preview"<br>"Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | Когда `seed` зафиксирован на определённом значении, модель по мере возможности старается выдавать одинаковый ответ на повторные запросы. Детерминированный вывод не гарантируется. Кроме того, изменение модели или параметров, например температуры, может вызывать вариации в ответе даже при использовании одного и того же значения `seed`. По умолчанию используется случайное значение `seed`. По умолчанию: 42. | INT | Да | 0 до 18446744073709551615 |
| `aspect_ratio` | Если установлено значение 'auto', соответствует соотношению сторон входного изображения; если изображение не предоставлено, обычно генерируется изображение с соотношением сторон 16:9. По умолчанию: "auto". | COMBO | Да | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | Целевое разрешение выходного изображения. Для 2K/4K используется встроенный апскейлер Gemini. | COMBO | Да | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | Выберите 'IMAGE' для вывода только изображения или 'IMAGE+TEXT', чтобы возвращать и сгенерированное изображение, и текстовый ответ. Расширенная настройка. | COMBO | Да | "IMAGE+TEXT"<br>"IMAGE" |
| `images` | Необязательное(-ые) эталонное(-ые) изображение(-я). Чтобы включить несколько изображений, используйте узел Batch Images (до 14). | IMAGE | Нет | N/A |
| `files` | Необязательный(-ые) файл(ы) для использования в качестве контекста модели. Принимает входные данные от узла Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | Нет | N/A |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию: предопределённая системная инструкция для генерации изображений. Расширенная настройка. | STRING | Нет | N/A |

**Ограничения:**

* Вход `images` поддерживает максимум 14 изображений. Если передано больше, возникает ошибка.
* Если передано более 10 изображений, первые 10 загружаются как URL-ссылки, а остальные изображения отправляются встроенно в запрос.
* Вход `files` должен быть подключён к узлу, который выводит тип данных `GEMINI_INPUT_FILES`.
* Когда `response_modalities` имеет значение `"IMAGE"`, возвращается только изображение, а текстовый выход пуст.
* Вход `prompt` проверяется и должен содержать хотя бы один символ после удаления пробельных символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение, сгенерированное или отредактированное моделью Gemini. | IMAGE |
| `string` | Текстовый ответ модели. Этот выход пуст, если `response_modalities` имеет значение `"IMAGE"`. | STRING |
