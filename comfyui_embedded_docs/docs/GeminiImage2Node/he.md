# Nano Banana Pro (Google Gemini Image)

צור או ערוך תמונות באופן סינכרוני באמצעות Google Vertex AI Gemini API. אתה מספק פרומפט טקסטואלי ויכול לצרף באופן אופציונלי תמונות עזר או קובצי קלט של Gemini. הצומת מחזיר את התמונה שנוצרה, ובהתאם למצב התגובה שנבחר, גם תגובת טקסט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי המתאר את התמונה ליצירה או את העריכות להחלה. כלול אילוצים, סגנונות או פרטים כלשהם שעל המודל לפעול לפיהם. הפרומפט חייב להכיל לפחות תו אחד לאחר הסרת רווחים. | STRING | כן | N/A |
| `model` | מודל Gemini שיש להשתמש בו ליצירה. האפשרות "Nano Banana 2 (Gemini 3.1 Flash Image)" נשלחת בתור `gemini-3.1-flash-image`; "gemini-3-pro-image-preview" נשלחת בתור `gemini-3-pro-image`. | COMBO | כן | "gemini-3-pro-image-preview"<br>"Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | כאשר ה-seed קבוע לערך מסוים, המודל עושה מאמץ מיטבי לספק את אותה תגובה לבקשות חוזרות. אין הבטחה לפלט דטרמיניסטי. כמו כן, שינוי המודל או הגדרות פרמטרים, כגון temperature, עלול לגרום לשינויים בתגובה גם כאשר אתה משתמש באותו ערך seed. כברירת מחדל, נעשה שימוש בערך seed אקראי. ברירת מחדל: 42. | INT | כן | 0 עד 18446744073709551615 |
| `aspect_ratio` | אם מוגדר ל-'auto', מתאים ליחס הגובה-רוחב של תמונת הקלט שלך; אם לא מסופקת תמונה, בדרך כלל נוצרת תמונה ביחס 16:9. ברירת מחדל: "auto". | COMBO | כן | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | רזולוציית הפלט הרצויה. עבור 2K/4K נעשה שימוש במעלה הרזולוציה המובנה של Gemini. | COMBO | כן | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | בחר 'IMAGE' לפלט תמונה בלבד, או 'IMAGE+TEXT' כדי להחזיר גם את התמונה שנוצרה וגם תגובת טקסט. הגדרה מתקדמת. | COMBO | כן | "IMAGE+TEXT"<br>"IMAGE" |
| `images` | תמונות עזר אופציונליות. כדי לכלול מספר תמונות, השתמש בצומת Batch Images (עד 14). | IMAGE | לא | N/A |
| `files` | קובץ/קבצים אופציונליים לשימוש כהקשר עבור המודל. מקבל קלטים מצומת Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | לא | N/A |
| `system_prompt` | הוראות יסוד הקובעות את התנהגות ה-AI. ברירת מחדל: פרומפט מערכת מוגדר מראש ליצירת תמונות. הגדרה מתקדמת. | STRING | לא | N/A |

**אילוצים:**

* קלט `images` תומך במקסימום 14 תמונות. אם מסופקות יותר, נזרקת שגיאה.
* כאשר מסופקות יותר מ-10 תמונות, 10 הראשונות מועלות כהפניות URL והתמונות הנותרות נשלחות בתוך הבקשה.
* קלט `files` חייב להיות מחובר לצומת שמוציא את סוג הנתונים `GEMINI_INPUT_FILES`.
* כאשר `response_modalities` מוגדר ל-`"IMAGE"`, מוחזרת רק התמונה ופלט הטקסט ריק.
* קלט `prompt` עובר ולידציה וחייב להכיל לפחות תו אחד לאחר הסרת רווחים.
