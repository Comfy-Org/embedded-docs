# Nano Banana Pro (Google Gemini Image)

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنما (prompt) که تصویر مورد نظر برای تولید یا ویرایش‌های مورد نظر را توصیف می‌کند. محدودیت‌ها، سبک‌ها یا جزئیاتی که مدل باید دنبال کند را شامل شوید. پیش‌فرض: رشته خالی. | STRING | بله | N/A |
| `model` | مدل تصویری Gemini که باید استفاده شود. گزینه «Nano Banana 2 (Gemini 3.1 Flash Image)» به صورت `gemini-3.1-flash-image` به API ارسال می‌شود؛ «gemini-3-pro-image-preview» به صورت `gemini-3-pro-image` ارسال می‌شود. | COMBO | بله | `"gemini-3-pro-image-preview"`<br>`"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `seed` | هنگامی که seed روی مقدار خاصی ثابت شود، مدل تلاش می‌کند برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. تغییر مدل یا سایر تنظیمات پارامترها می‌تواند حتی با همان مقدار seed باعث تغییر در پاسخ شود. پیش‌فرض: 42. | INT | بله | 0 to 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد مورد نظر برای تصویر خروجی. اگر روی «auto» تنظیم شود، نسبت ابعاد تصویر ورودی شما را مطابقت می‌دهد؛ اگر تصویری ارائه نشود، معمولاً یک تصویر با نسبت 16:9 تولید می‌شود. پیش‌فرض: «auto». | COMBO | بله | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"` |
| `resolution` | رزولوشن هدف خروجی. برای 2K/4K از مقیاس‌کننده بومی Gemini استفاده می‌شود. | COMBO | بله | `"1K"`<br>`"2K"`<br>`"4K"` |
| `response_modalities` | برای خروجی فقط تصویر، گزینه «IMAGE» را انتخاب کنید، یا برای بازگرداندن تصویر تولیدشده و پاسخ متنی، «IMAGE+TEXT» را انتخاب کنید. | COMBO | بله | `"IMAGE+TEXT"`<br>`"IMAGE"` |
| `images` | تصویر(های) مرجع اختیاری که به عنوان زمینه بصری استفاده می‌شود. برای گنجاندن چند تصویر، از گره Batch Images (تا ۱۴ تصویر) استفاده کنید. | IMAGE | خیر | N/A |
| `files` | فایل(های) اختیاری برای استفاده به عنوان زمینه برای مدل. ورودی‌های گره Gemini Generate Content Input Files را می‌پذیرد. | GEMINI_INPUT_FILES | خیر | N/A |
| `system_prompt` | دستورالعمل‌های بنیادی که رفتار مدل را تعیین می‌کنند. پیش‌فرض: یک پرامپت سیستمی از پیش تعریف‌شده که به مدل دستور می‌دهد همیشه تصویر تولید کند. | STRING | خیر | N/A |

**محدودیت‌ها:**

* پرامپت (`prompt`) پس از حذف فاصله‌های ابتدا و انتها نباید خالی باشد؛ در غیر این صورت خطا ایجاد می‌شود.
* ورودی `images` حداکثر ۱۴ تصویر را می‌پذیرد. اگر بیش از ۱۴ تصویر ارائه شود، خطا ایجاد می‌شود.
* ورودی `files` باید به گره‌ای متصل شود که نوع داده `GEMINI_INPUT_FILES` را خروجی می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
