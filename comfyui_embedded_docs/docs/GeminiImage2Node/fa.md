# Nano Banana Pro (Google Gemini Image)

تصاویر را به‌صورت همگام از طریق API Gemini در Google Vertex AI تولید یا ویرایش کنید. شما یک پرامپت متنی ارائه می‌دهید و می‌توانید به‌صورت اختیاری تصاویر مرجع یا فایل‌های ورودی Gemini را پیوست کنید. این گره تصویر تولیدشده و بسته به حالت پاسخ انتخاب‌شده، یک پاسخ متنی بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی که تصویر موردنظر برای تولید یا ویرایش‌هایی که باید اعمال شوند را توصیف می‌کند. شامل هرگونه محدودیت، سبک یا جزئیاتی باشد که مدل باید دنبال کند. پرامپت باید پس از حذف فاصله‌های خالی حداقل شامل یک کاراکتر باشد. | STRING | بله | N/A |
| `model` | مدل Gemini برای تولید. گزینه «Nano Banana 2 (Gemini 3.1 Flash Image)» به‌عنوان `gemini-3.1-flash-image` ارسال می‌شود؛ «gemini-3-pro-image-preview» به‌عنوان `gemini-3-pro-image` ارسال می‌شود. | COMBO | بله | "gemini-3-pro-image-preview"<br>"Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `seed` | وقتی seed روی مقدار مشخصی ثابت شود، مدل نهایت تلاش خود را می‌کند تا برای درخواست‌های تکرارشده پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. همچنین، تغییر مدل یا تنظیمات پارامترها، مانند دما (temperature)، می‌تواند حتی با استفاده از مقدار seed یکسان باعث تغییراتی در پاسخ شود. به‌طور پیش‌فرض، یک مقدار seed تصادفی استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 18446744073709551615 |
| `aspect_ratio` | اگر روی «auto» تنظیم شود، با نسبت تصویر ورودی شما مطابقت می‌کند؛ اگر تصویری ارائه نشود، معمولاً یک تصویر با نسبت 16:9 تولید می‌شود. پیش‌فرض: "auto". | COMBO | بله | "auto"<br>"1:1"<br>"2:3"<br>"3:2"<br>"3:4"<br>"4:3"<br>"4:5"<br>"5:4"<br>"9:16"<br>"16:9"<br>"21:9" |
| `resolution` | رزولوشن خروجی هدف. برای 2K/4K از مقیاس‌کننده بومی Gemini استفاده می‌شود. | COMBO | بله | "1K"<br>"2K"<br>"4K" |
| `response_modalities` | «IMAGE» را برای خروجی فقط تصویر انتخاب کنید، یا «IMAGE+TEXT» را برای بازگرداندن هم تصویر تولیدشده و هم پاسخ متنی. تنظیم پیشرفته. | COMBO | بله | "IMAGE+TEXT"<br>"IMAGE" |
| `images` | تصویر(های) مرجع اختیاری. برای گنجاندن چندین تصویر، از گره Batch Images استفاده کنید (حداکثر 14). | IMAGE | خیر | N/A |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌هایی از گره Gemini Generate Content Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر | N/A |
| `system_prompt` | دستورالعمل‌های بنیادین که رفتار یک هوش مصنوعی را تعیین می‌کنند. پیش‌فرض: یک پرامپت سیستمی از پیش تعریف‌شده برای تولید تصویر. تنظیم پیشرفته. | STRING | خیر | N/A |

**محدودیت‌ها:**

* ورودی `images` حداکثر از 14 تصویر پشتیبانی می‌کند. اگر بیشتر ارائه شود، خطایی ایجاد می‌شود.
* وقتی بیش از 10 تصویر ارائه شود، 10 تصویر اول به‌عنوان ارجاع‌های URL بارگذاری می‌شوند و تصاویر باقی‌مانده به‌صورت درون‌خطی (inline) در درخواست ارسال می‌شوند.
* ورودی `files` باید به گره‌ای متصل شود که نوع داده `GEMINI_INPUT_FILES` را خروجی می‌دهد.
* وقتی `response_modalities` روی `"IMAGE"` تنظیم شود، فقط تصویر بازگردانده می‌شود و خروجی متنی خالی است.
* ورودی `prompt` اعتبارسنجی می‌شود و باید پس از حذف فاصله‌های خالی حداقل شامل یک کاراکتر باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویری که توسط مدل Gemini تولید یا ویرایش شده است. | IMAGE |
| `string` | پاسخ متنی مدل. اگر `response_modalities` روی `"IMAGE"` تنظیم شده باشد، این خروجی خالی است. | STRING |
