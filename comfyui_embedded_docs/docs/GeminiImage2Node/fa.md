# Nano Banana Pro (Google Gemini Image)

**محدودیت‌ها:**

* ورودی `images` حداکثر ۱۴ تصویر را پشتیبانی می‌کند. اگر بیش از این تعداد ارائه شود، خطا ایجاد می‌شود.
* وقتی بیش از ۱۰ تصویر ارائه شود، ۱۰ تصویر اول به‌عنوان ارجاع URL بارگذاری می‌شوند و تصاویر باقی‌مانده به‌صورت درون‌خطی (inline) در درخواست ارسال می‌شوند.
* ورودی `files` باید به گره‌ای متصل شود که نوع داده `GEMINI_INPUT_FILES` را خروجی می‌دهد.
* وقتی `response_modalities` روی "IMAGE" تنظیم شود، فقط تصویر بازگردانده می‌شود و خروجی متنی خالی است.
