# EmptyMiniMaxMusic3LatentAudio

Этот узел создает пустой (заполненный нулями) латентный аудио-тензор для модели MiniMax Music3. Он преобразует запрошенную длительность в секундах в соответствующие аудиокадры и создает пустой латент правильного размера, готовый к использованию в качестве отправной точки для генерации музыки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seconds` | Длительность аудиолатента в секундах (по умолчанию: 120.0). Значение преобразуется в аудиокадры и ограничивается поддерживаемыми пределами длительности модели. | FLOAT | Да | 0.04 до model maximum (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), шаг 0.04 |
| `batch_size` | Количество аудиолатентов для генерации в одном пакете (по умолчанию: 1). | INT | Да | 1 до 4096 |

Примечание: значение `seconds` округляется до ближайшего аудиокадра и ограничивается минимумом в 1 кадр и максимумом в `MAX_AUDIO_FRAMES` кадров, поэтому фактическая длина латента может незначительно отличаться от введенного точного значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Аудиолатентный тензор, заполненный нулями, формы (batch_size, 128, latent_length). Содержит метаданные, помечающие сэмпл как аудиоданные с коэффициентом временного понижения разрешения 512. | LATENT |
