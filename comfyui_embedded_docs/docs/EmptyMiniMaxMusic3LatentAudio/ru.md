# Пустой latent-аудио MiniMax Music3

Этот узел создаёт пустой (заполненный нулями) звуковой латент для модели MiniMax Music3. Он преобразует запрошенную длительность в секундах в соответствующее количество звуковых кадров и создаёт пустой латентный тензор нужного размера, готовый к использованию в качестве отправной точки для генерации музыки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seconds` | Длительность звукового латента в секундах (по умолчанию: 120.0). Значение преобразуется в звуковые кадры и ограничивается поддерживаемыми моделью пределами длительности. | FLOAT | Да | 0.04 до (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), шаг 0.04 |
| `batch_size` | Количество звуковых латентов для генерации в одном пакете (по умолчанию: 1). | INT | Да | 1 до 4096 |

Примечание: Значение `seconds` округляется до ближайшего звукового кадра и ограничивается минимумом в 1 кадр и максимумом в `MAX_AUDIO_FRAMES` кадров, поэтому фактическая длина латента может немного отличаться от введённого точного значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `LATENT` | Звуковой латентный тензор, заполненный нулями, формы (batch_size, 128, latent_length). Включает метаданные, которые помечают образец как звуковые данные с коэффициентом временного уменьшения 512. | LATENT |
