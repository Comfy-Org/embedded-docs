# صوت latent فارغ لـ MiniMax Music3

يقوم هذا العقد بإنشاء كامن صوتي فارغ (مملوء بالأصفار) لنموذج MiniMax Music3. وهو يحوّل المدة المطلوبة بالثواني إلى العدد المقابل من الإطارات الصوتية، وينتج موترًا كامنًا فارغًا بالحجم الصحيح، جاهزًا لاستخدامه كنقطة بداية لتوليد الموسيقى.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `seconds` | مدة الكامن الصوتي بالثواني (القيمة الافتراضية: 120.0). تُحوَّل القيمة إلى إطارات صوتية وتُقيَّد ضمن حدود المدة المدعومة في النموذج. | FLOAT | نعم | 0.04 إلى (MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND)، الخطوة 0.04 |
| `batch_size` | عدد الكوامن الصوتية المراد توليدها في دفعة واحدة (القيمة الافتراضية: 1). | INT | نعم | 1 إلى 4096 |

ملاحظة: تُقرَّب قيمة `seconds` إلى أقرب إطار صوتي وتُقيَّد بحد أدنى قدره إطار واحد وبحد أقصى قدره `MAX_AUDIO_FRAMES` إطارًا، لذلك قد يختلف طول الكامن الفعلي اختلافًا طفيفًا عن القيمة الدقيقة المُدخَلة.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `LATENT` | موتر كامن صوتي مملوء بالأصفار بالشكل (batch_size, 128, latent_length). يتضمّن بيانات وصفية تشير إلى أن العيّنة بيانات صوتية بنسبة تصغير زمني قدرها 512. | LATENT |
