# ترجمه ویدیو HeyGen

ویدیوی گفتاری را به زبان دیگری با شبیه‌سازی صدا و لب‌سینک ترجمه کنید. این گره صدای گویندهٔ اصلی را شبیه‌سازی می‌کند و دهان را برای هماهنگی با گفتار ترجمه‌شده دوباره جان‌بخشی می‌کند و نتیجه‌ای طبیعی به نظر می‌رسد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | ویدیویی که شامل گفتار برای ترجمه است. | VIDEO | بله | - |
| `زبان خروجی` | زبان هدف برای ویدیوی ترجمه‌شده. | COMBO | بله | "Arabic"<br>"Bengali"<br>"Chinese"<br>"Danish"<br>"Dutch"<br>"English"<br>"French"<br>"German"<br>"Greek"<br>"Hindi"<br>"Indonesian"<br>"Italian"<br>"Japanese"<br>"Korean"<br>"Malay"<br>"Polish"<br>"Portuguese"<br>"Russian"<br>"Spanish"<br>"Swedish"<br>"Tamil"<br>"Telugu"<br>"Thai"<br>"Turkish"<br>"Ukrainian"<br>"Vietnamese" |
| `حالت` | 'speed' سریع‌تر است؛ 'precision' لب‌سینک با کیفیت‌تر اما با هزینه بالاتر تولید می‌کند. (پیش‌فرض: "speed") | COMBO | بله | "speed"<br>"precision" |
| `فقط ترجمه صدا` | فقط ترک صوتی را تعویض می‌کند و حرکات اصلی دهان را حفظ می‌کند (بدون لب‌سینک). (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `تعداد گویندگان` | تعداد گویندگان در ویدیو. 0 = تشخیص خودکار. مقادیر بالای 0 به‌عنوان تعداد گویندگان به API ارسال می‌شوند. (پیش‌فرض: 0) | INT | خیر | 0 تا 10 |
| `seed` | به HeyGen ارسال نمی‌شود؛ آن را تغییر دهید تا اجرای مجدد انجام شود. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی ترجمه‌شده با اعمال شبیه‌سازی صدا و لب‌سینک. | VIDEO |
