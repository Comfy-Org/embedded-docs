# CombineHooksEight

عقدة دمج الخطافات [8] تدمج ما يصل إلى ثماني مجموعات خطافات مختلفة في مجموعة خطافات واحدة مدمجة. تستقبل هذه العقدة مدخلات خطافات متعددة وتدمجها باستخدام وظيفة دمج الخطافات في ComfyUI. يتيح لك ذلك توحيد تكوينات خطافات متعددة لمعالجة مبسطة في سير العمل المتقدمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | نوع الإدخال | القيمة الافتراضية | النطاق |
| --- | --- | --- | --- | --- | --- |
| `الخُطاف A` | مجموعة الخطافات الأولى المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف B` | مجموعة الخطافات الثانية المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف C` | مجموعة الخطافات الثالثة المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف D` | مجموعة الخطافات الرابعة المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف E` | مجموعة الخطافات الخامسة المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف F` | مجموعة الخطافات السادسة المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف G` | مجموعة الخطافات السابعة المراد دمجها | HOOKS | اختياري | لا شيء | - |
| `الخُطاف H` | مجموعة الخطافات الثامنة المراد دمجها | HOOKS | اختياري | لا شيء | - |

**ملاحظة:** جميع معاملات الإدخال اختيارية. ستقوم العقدة بدمج مجموعات الخطافات المقدمة فقط، متجاهلة أي مجموعات تُترك فارغة. يمكنك تقديم من مجموعة خطافات واحدة إلى ثماني مجموعات للدمج.
