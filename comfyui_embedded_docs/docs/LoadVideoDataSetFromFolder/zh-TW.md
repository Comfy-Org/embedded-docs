# 載入影片（資料夾）

從 ComfyUI 輸入目錄中的所選資料夾載入影片資料集，並將其作為延遲影片參考清單回傳。此節點載入影片資料集：影格僅在另一個節點實際需要時才進行解碼。支援的格式為 MP4、AVI、MOV、WEBM、MKV 和 FLV。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `資料夾` | 包含影片檔案的資料夾。 | COMBO | 是 | ComfyUI 輸入目錄中的所有可用子資料夾（動態填入） |

**注意：**所選資料夾必須是 ComfyUI 輸入目錄的子資料夾，且必須包含至少一個受支援的影片檔案。支援的副檔名為 MP4、AVI、MOV、WEBM、MKV 和 FLV。如果找不到受支援的影片檔案，或資料夾路徑解析到輸入目錄之外，節點將引發錯誤。

## 輸出

| 輸出名稱 | 描述 | 資料型別 |
|-------------|-------------|-----------|
| `影片` | 延遲影片參考清單，對應所選資料夾中的每個受支援影片檔案，依檔案名稱按字母順序排序。只有當輸出被另一個節點使用時，才會解碼影片影格。 | VIDEO (list) |
