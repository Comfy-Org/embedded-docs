# Загрузить Видео (из папки)

Загрузить набор видео из указанной папки в директории ввода ComfyUI. Узел сканирует папку на наличие поддерживаемых видеофайлов и возвращает ленивые ссылки — фактические кадры декодируются только при необходимости в последующих узлах.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `папка` | Папка, содержащая видеофайлы. Выберите одну из доступных подпапок в директории ввода ComfyUI. | STRING | Да | *(заполняется из подпапок ввода)* |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `videos` | Список ленивых ссылок на видео (по одной на файл). Кадры видео декодируются только тогда, когда выход используется другим узлом. | VIDEO |
