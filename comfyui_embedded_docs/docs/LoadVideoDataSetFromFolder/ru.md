# Загрузить Видео (из папки)

Загружает все поддерживаемые видеофайлы из выбранной папки в директории ввода ComfyUI и возвращает их в виде списка ссылок на видео. Этот узел возвращает ленивые ссылки на видео, поэтому кадры декодируются только тогда, когда они действительно нужны другому узлу.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `папка` | Папка, содержащая видеофайлы. Выберите одну из доступных подпапок в директории ввода ComfyUI. | STRING | Да | Все подпапки, доступные в директории ввода ComfyUI |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
**Примечание:** Выбранная папка должна содержать хотя бы один поддерживаемый видеофайл. Поддерживаемые расширения: MP4, AVI, MOV, WEBM, MKV и FLV. Если поддерживаемые видеофайлы не найдены, узел вызывает ошибку.
|------------|----------|------------|
| `videos` | Список ленивых ссылок на видео, по одной на каждый видеофайл в выбранной папке. Кадры видео декодируются только тогда, когда выход используется другим узлом. | VIDEO (list) |
