# Загрузить Видео (из папки)

Загружает набор видео из выбранной папки внутри входной директории ComfyUI и возвращает их в виде списка ленивых ссылок на видео. Этот узел загружает набор видео: кадры декодируются только тогда, когда они действительно нужны другому узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `папка` | Папка, содержащая видеофайлы. | COMBO | Да | Все подпапки, доступные во входной директории ComfyUI (заполняется динамически) |

**Примечание:** Выбранная папка должна быть подпапкой входной директории ComfyUI и содержать хотя бы один поддерживаемый видеофайл. Поддерживаемые расширения: MP4, AVI, MOV, WEBM, MKV и FLV. Если не найдено ни одного поддерживаемого видеофайла или если путь к папке оказывается за пределами входной директории, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `videos` | Список ленивых ссылок на видео, по одной для каждого поддерживаемого видеофайла в выбранной папке, отсортированный по имени файла в алфавитном порядке. Кадры видео декодируются только тогда, когда выход используется другим узлом. | VIDEO (list) |
