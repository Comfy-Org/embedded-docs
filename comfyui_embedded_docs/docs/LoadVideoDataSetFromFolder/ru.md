# Загрузить Видео (из папки)

Загружает набор видеоданных из выбранной папки внутри каталога ввода ComfyUI и возвращает их в виде списка ленивых ссылок на видео. Этот узел загружает набор видео: кадры декодируются только тогда, когда они действительно нужны другому узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `папка` | Папка, содержащая видеофайлы. | COMBO | Да | Все подпапки, доступные в каталоге ввода ComfyUI (заполняется динамически) |

**Примечание:** Выбранная папка должна быть подпапкой каталога ввода ComfyUI и содержать хотя бы один поддерживаемый видеофайл. Поддерживаемые расширения: MP4, AVI, MOV, WEBM, MKV и FLV. Если поддерживаемые видеофайлы не найдены или путь к папке выходит за пределы каталога ввода, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `видео` | Список ленивых ссылок на видео — по одной для каждого поддерживаемого видеофайла в выбранной папке, отсортированный по алфавиту по имени файла. Кадры видео декодируются только тогда, когда выходные данные потребляются другим узлом. | VIDEO (list) |
