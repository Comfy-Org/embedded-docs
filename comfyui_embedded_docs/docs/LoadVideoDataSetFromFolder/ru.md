# Загрузить Видео (из папки)

Загружает все поддерживаемые видеофайлы из выбранной папки внутри входного каталога ComfyUI и возвращает их в виде списка ссылок на видео. Этот узел возвращает «ленивые» ссылки на видео, поэтому кадры декодируются только тогда, когда они фактически требуются другому узлу. Поддерживаемые форматы: MP4, AVI, MOV, WEBM, MKV и FLV.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `folder` | Папка, содержащая видеофайлы. Выберите одну из доступных вложенных папок внутри входного каталога ComfyUI. | COMBO | Да | Все вложенные папки, доступные во входном каталоге ComfyUI |

**Примечание:** Выбранная папка должна содержать хотя бы один поддерживаемый видеофайл. Поддерживаемые расширения: MP4, AVI, MOV, WEBM, MKV и FLV. Если поддерживаемые видеофайлы не найдены, узел вызывает ошибку. Папка должна находиться внутри входного каталога ComfyUI; имена папок, пытающиеся выйти за его пределы (например, с помощью «..»), отклоняются с ошибкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `videos` | Список «ленивых» ссылок на видео: по одной для каждого видеофайла в выбранной папке. Кадры декодируются только тогда, когда выходные данные используются другим узлом. | VIDEO (list) |
