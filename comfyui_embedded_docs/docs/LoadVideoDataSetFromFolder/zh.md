# 加载视频（来自文件夹）

从 ComfyUI 输入目录中的选定文件夹加载所有支持的视频文件，并将它们作为视频引用列表返回。此节点返回惰性视频引用，因此帧仅在另一个节点实际需要时才会解码。支持的格式：MP4、AVI、MOV、WEBM、MKV 和 FLV。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `folder` | 包含视频文件的文件夹。从 ComfyUI 输入目录中的可用子文件夹中选择。 | COMBO | 是 | ComfyUI 输入目录中可用的所有子文件夹 |

**注意：** 所选文件夹必须至少包含一个支持的视频文件。支持的扩展名为 MP4、AVI、MOV、WEBM、MKV 和 FLV。如果未找到受支持的视频文件，节点将引发错误。文件夹必须解析为 ComfyUI 输入目录内的位置；尝试逃逸该目录的文件夹名称（例如包含“..”）将被拒绝并报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `videos` | 惰性视频引用列表，对应所选文件夹中的每个视频文件。帧仅在输出被另一个节点消费时才会解码。 | VIDEO (list) |
