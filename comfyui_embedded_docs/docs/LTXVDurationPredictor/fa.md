# پیش‌بینی‌کننده مدت زمان LTXV

این گره مدت‌زمان طبیعی نما را برای یک پرامپت با استفاده از سر مدت‌زمان LTX 2.4 پیش‌بینی می‌کند. مدت‌زمان پیش‌بینی‌شده را با استفاده از نرخ فریم و محدوده‌های حداقل/حداکثر مدت‌زمان داده‌شده، به تعداد فریم‌هایی تبدیل می‌کند که با شبکه فریم VAE سازگار باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای پیش‌پردازش تعبیه‌های متنی و اجرای سر مدت‌زمان استفاده می‌شود. | MODEL | بله | N/A |
| `مثبت` | شرطی‌سازی که تعبیه‌های متنی پرامپت و فراداده‌های لازم برای پیش‌بینی مدت‌زمان را فراهم می‌کند. | CONDITIONING | بله | N/A |
| `duration head` | سر مدت‌زمان LTX 2.4 که با ModelPatchLoader بارگذاری شده است. باید یک سر مدت‌زمان LTX باشد. | MODEL_PATCH | بله | N/A |
| `نرخ فریم` | نرخ فریم بر حسب فریم بر ثانیه که برای تبدیل ثانیه به فریم استفاده می‌شود (پیش‌فرض: 24.0). | FLOAT | بله | 1.0 تا 120.0 |
| `حداقل ثانیه` | حداقل مدت‌زمان بر حسب ثانیه که هنگام تبدیل پیش‌بینی به تعداد فریم استفاده می‌شود (پیش‌فرض: 1.0). | FLOAT | بله | 0.5 تا 120.0 |
| `حداکثر ثانیه` | حداکثر مدت‌زمان بر حسب ثانیه که هنگام تبدیل پیش‌بینی به تعداد فریم استفاده می‌شود (پیش‌فرض: 20.0). | FLOAT | بله | 0.5 تا 120.0 |

توجه: ورودی `duration_head` باید یک سر مدت‌زمان LTX 2.4 باشد که با ModelPatchLoader بارگذاری شده است. اگر مدل‌پچ متصل‌شده یک سر مدت‌زمان LTX نباشد، گره یک ValueError ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تعداد فریم‌ها` | مدت‌زمان پیش‌بینی‌شده که به تعداد فریم تبدیل و بر شبکه فریم 8k+1 وِئه هم‌تراز شده است. | INT |
| `ثانیه` | مدت‌زمان پیش‌بینی‌شده خام (بدون محدودیت). این مقدار قبل از هم‌ترازی با شبکه فریم است. | FLOAT |
