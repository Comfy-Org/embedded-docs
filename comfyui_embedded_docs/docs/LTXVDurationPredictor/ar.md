# LTXVDurationPredictor

تتنبأ هذه العقدة بالمدة الطبيعية للقطة بناءً على الموجه (prompt) باستخدام رأس مدة LTX 2.4. وتحوّل المدة المتوقعة إلى عدد إطارات يتوافق مع شبكة إطارات VAE، باستخدام معدل الإطارات المقدَّم وحدود المدة الدنيا والقصوى.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|---------|--------|--------------|--------|--------|
| `النموذج` | النموذج المستخدم لمعالجة تضمينات النص مسبقًا وتشغيل رأس المدة. | MODEL | نعم | N/A |
| `إيجابي` | التكييف الذي يوفر تضمينات النص للموجه والبيانات الوصفية للتنبؤ بالمدة. | CONDITIONING | نعم | N/A |
| `duration_head` | رأس مدة LTX 2.4 الذي تم تحميله باستخدام ModelPatchLoader. يجب أن يكون رأس مدة LTX. | MODEL_PATCH | نعم | N/A |
| `معدل الإطارات` | معدل الإطارات بالإطارات في الثانية المستخدم لتحويل الثواني إلى إطارات (الافتراضي: 24.0). | FLOAT | نعم | 1.0 إلى 120.0 |
| `الحد الأدنى للثواني` | الحد الأدنى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 1.0). | FLOAT | نعم | 0.5 إلى 120.0 |
| `الحد الأقصى للثواني` | الحد الأقصى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 20.0). | FLOAT | نعم | 0.5 إلى 120.0 |

ملاحظة: يجب أن يكون مدخل `duration_head` رأس مدة LTX 2.4 تم تحميله باستخدام ModelPatchLoader. إذا لم يكن الترقيع النموذجي المتصل رأس مدة LTX، ترفع العقدة خطأ ValueError.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|--------|--------------|
| `عدد الإطارات` | المدة المتوقعة محولة إلى عدد إطارات ومقربة إلى شبكة إطارات VAE ذات 8k+1. | INT |
| `الثواني` | المدة المتوقعة الخام (غير المقيدة). هذه هي القيمة قبل التقريب إلى شبكة الإطارات. | FLOAT |
