# متنبئ مدة LTXV

تتنبأ هذه العقدة بالمدة الطبيعية للقطة بناءً على الموجه باستخدام رأس مدة LTX 2.4. وتحوّل المدة المتوقعة إلى عدد إطارات يتوافق مع شبكة إطارات VAE، باستخدام معدل الإطارات المقدَّم والحدود الدنيا والقصوى للمدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم لمعالجة التضمينات النصية مسبقًا وتشغيل رأس المدة. | MODEL | نعم | N/A |
| `إيجابي` | التكييف الذي يوفّر التضمينات النصية للموجه والبيانات الوصفية للتنبؤ بالمدة. | CONDITIONING | نعم | N/A |
| `duration_head` | رأس مدة LTX 2.4 الذي تم تحميله عبر ModelPatchLoader. يجب أن يكون رأس مدة LTX. | MODEL_PATCH | نعم | N/A |
| `معدل الإطارات` | معدل الإطارات في الثانية المستخدم لتحويل الثواني إلى إطارات (الافتراضي: 24.0). | FLOAT | نعم | 1.0 إلى 120.0 |
| `الحد الأدنى للثواني` | الحد الأدنى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 1.0). | FLOAT | نعم | 0.5 إلى 120.0 |
| `الحد الأقصى للثواني` | الحد الأقصى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 20.0). | FLOAT | نعم | 0.5 إلى 120.0 |

ملاحظة: يجب أن يكون مدخل `duration_head` رأس مدة LTX 2.4 تم تحميله عبر ModelPatchLoader. إذا لم يكن ترقيع النموذج المتصل رأس مدة LTX، ترفع العقدة استثناء ValueError.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `عدد الإطارات` | المدة المتوقعة محوّلة إلى عدد إطارات ومحاذاة إلى شبكة الإطارات 8k+1 الخاصة بـ VAE. | INT |
| `الثواني` | المدة المتوقعة الأولية (غير مقيّدة). هذه هي القيمة قبل محاذاتها إلى شبكة الإطارات. | FLOAT |
