# LTXVDurationPredictor

Этот узел предсказывает естественную длительность сцены для промпта с помощью головы определения длительности LTX 2.4. Он преобразует предсказанную длительность в количество кадров, которое соответствует сетке кадров VAE, используя заданную частоту кадров и минимальное/максимальное ограничение длительности.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для предварительной обработки текстовых эмбеддингов и запуска головы длительности. | MODEL | Да | N/A |
| `positive` | Кондиционирование, которое предоставляет текстовые эмбеддинги промпта и метаданные для предсказания длительности. | CONDITIONING | Да | N/A |
| `duration_head` | Голова длительности LTX 2.4, загруженная с помощью ModelPatchLoader. Должна быть головой длительности LTX. | MODEL_PATCH | Да | N/A |
| `frame_rate` | Частота кадров в кадрах в секунду, используемая для преобразования секунд в кадры (по умолчанию: 24.0). | FLOAT | Да | 1.0 до 120.0 |
| `min_seconds` | Минимальная длительность в секундах, используемая при преобразовании предсказания в количество кадров (по умолчанию: 1.0). | FLOAT | Да | 0.5 до 120.0 |
| `max_seconds` | Максимальная длительность в секундах, используемая при преобразовании предсказания в количество кадров (по умолчанию: 20.0). | FLOAT | Да | 0.5 до 120.0 |

Примечание: вход `duration_head` должен быть головой длительности LTX 2.4, загруженной с помощью ModelPatchLoader. Если подключённый патч модели не является головой длительности LTX, узел вызывает ValueError.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `num_frames` | Предсказанная длительность, преобразованная в количество кадров и приведённая к сетке кадров VAE 8k+1. | INT |
| `seconds` | Сырая (без ограничений) предсказанная длительность. Это значение до приведения к сетке кадров. | FLOAT |
