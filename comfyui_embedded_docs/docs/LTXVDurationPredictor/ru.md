# LTXV Duration Predictor

Этот узел предсказывает естественную длительность кадра для запроса (prompt) с помощью головки длительности LTX 2.4. Он преобразует предсказанную длительность в количество кадров, соответствующее сетке кадров VAE, с использованием заданной частоты кадров и ограничений минимальной/максимальной длительности.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для предобработки текстовых эмбеддингов и запуска головки длительности. | MODEL | Да | N/A |
| `positive` | Кондиционирование, предоставляющее текстовые эмбеддинги запроса и метаданные для предсказания длительности. | CONDITIONING | Да | N/A |
| `duration_head` | Головка длительности LTX 2.4, загруженная через ModelPatchLoader. Должна быть головкой длительности LTX. | MODEL_PATCH | Да | N/A |
| `frame_rate` | Частота кадров в кадрах в секунду, используемая для преобразования секунд в кадры (по умолчанию: 24.0). | FLOAT | Да | 1.0 до 120.0 |
| `min_seconds` | Минимальная длительность в секундах, используемая при преобразовании предсказания в количество кадров (по умолчанию: 1.0). | FLOAT | Да | 0.5 до 120.0 |
| `max_seconds` | Максимальная длительность в секундах, используемая при преобразовании предсказания в количество кадров (по умолчанию: 20.0). | FLOAT | Да | 0.5 до 120.0 |

Примечание: вход `duration_head` должен быть головкой длительности LTX 2.4, загруженной с помощью ModelPatchLoader. Если подключённый модельный патч не является головкой длительности LTX, узел вызывает ошибку ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `num_frames` | Предсказанная длительность, преобразованная в количество кадров и приведённая к сетке кадров VAE 8k+1. | INT |
| `seconds` | Исходная (без ограничений) предсказанная длительность. Это значение до приведения к сетке кадров. | FLOAT |
