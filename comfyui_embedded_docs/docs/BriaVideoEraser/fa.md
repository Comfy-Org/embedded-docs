# BriaVideoEraser

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `video` | کلیپی که باید از آن حذف انجام شود. | VIDEO | بله | - |
| `mask` | یک ماسک برای هر فریم ویدیو؛ روی شیء مورد حذف سفید است. یا `mask` یا `mask_video` را ارائه دهید، نه هر دو. | MASK | خیر | - |
| `mask_video` | یک ویدیوی ماسک از قبل کدگذاری‌شده با همان ابعاد و تعداد فریم ویدیو. یا `mask` یا `mask_video` را ارائه دهید، نه هر دو. | VIDEO | خیر | - |
| `preserve_audio` | مسیر صوتی ورودی را نگه می‌دارد. پیش‌فرض: true. | BOOLEAN | خیر | `true`<br>`false` |

**نکات مربوط به محدودیت‌ها:**

- دقیقاً یکی از `mask` یا `mask_video` باید متصل باشد. اگر هیچ‌کدام ارائه نشود یا هر دو ارائه شوند، خطا ایجاد می‌شود.
- طول ویدیو باید حداکثر ۵.۱ ثانیه باشد و باید با نرخ ۲۰ تا ۳۰ فریم بر ثانیه اجرا شود. در صورت نیاز، زمان‌بندی کلیپ را با Get Video Components و Create Video تغییر دهید.
- ویدیو باید ابعاد پیکسلی زوج داشته باشد (عرض و ارتفاع بخش‌پذیر بر ۲). در غیر این صورت ابتدا آن را برش دهید یا مقیاس کنید.
- هنگام استفاده از `mask`، باید برای هر فریم ویدیو یک فریم ماسک داشته باشد و نسبت ابعاد آن با ویدیو مطابقت کند. ماسک‌ها با آستانه ۵۰٪ دودویی می‌شوند: نواحی‌ای که با کمتر از نیم شفافیت رنگ‌آمیزی شده‌اند نادیده گرفته می‌شوند و ماسک خالی خطا ایجاد می‌کند. اگر وضوح ماسک با ویدیو متفاوت باشد، به ابعاد ویدیو تغییر اندازه داده می‌شود.
- هنگام استفاده از `mask_video`، باید همان ابعاد و همان تعداد فریم ویدیو را داشته باشد.
