# FishAudioInstantVoiceClone

این گره با استفاده از Fish Audio API، صدای کلون‌شده خصوصی از ضبط‌های صوتی شما ایجاد می‌کند. شما یک یا چند نمونه صوتی ارائه می‌دهید و گره یک صدای سفارشی می‌سازد که می‌تواند بلافاصله برای تبدیل متن به گفتار استفاده شود. این گره 1 تا 20 ضبط را می‌پذیرد، با طول پیشنهادی 10 تا 30 ثانیه برای هر ضبط و سقف کل 270 ثانیه.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `files` | ضبط‌های صوتی برای کلون‌سازی صدا. این یک ورودی توسعه‌پذیر است: برای ارائه نمونه‌های صوتی، یک یا چند آیتم صوتی را متصل کنید (برای مثال `audio_1`، `audio_2`، ...). | AUDIO | بله | 1 تا 20 ضبط صوتی |
| `enhance_audio_quality` | کیفیت صدای مرجع را قبل از آموزش بهبود دهید (پیش‌فرض: True). | BOOLEAN | بله | True<br>False |

**نکته:** مجموع مدت زمان تمام صداهای مرجع باید کمتر از 270 ثانیه باشد. اگر مجموع مدت زمان به 270 ثانیه برسد یا بیشتر شود، گره خطا برمی‌گرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `voice` | صدای کلون‌شده تازه‌ساخته‌شده که با شناسه صدای یکتای بازگردانده‌شده توسط Fish Audio API مشخص می‌شود. این صدا می‌تواند برای تبدیل متن به گفتار استفاده شود. | FISHAUDIO_VOICE |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/FishAudioInstantVoiceClone/fa.md)
