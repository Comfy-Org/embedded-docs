# شبیه‌سازی فوری صدای Fish Audio

این گره یک صدای کلون‌شده خصوصی از ضبط‌های صوتی شما با استفاده از Fish Audio API می‌سازد. شما یک یا چند نمونه صوتی ارائه می‌دهید و گره یک صدای سفارشی می‌سازد که می‌تواند بلافاصله برای تبدیل متن به گفتار استفاده شود. این گره از ۱ تا ۲۰ ضبط را می‌پذیرد، با طول توصیه‌شده ۱۰ تا ۳۰ ثانیه برای هر ضبط و محدودیت مجموع ۲۷۰ ثانیه.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `files` | ضبط‌های صوتی برای کلون‌سازی صدا. این یک ورودی قابل گسترش است: یک یا چند آیتم صوتی (برای مثال `audio_1`، `audio_2`، ...) را متصل کنید تا نمونه‌های صوتی را ارائه دهید. | AUDIO | بله | 1 تا 20 ضبط |
| `enhance_audio_quality` | کیفیت صدای مرجع را پیش از آموزش بهبود می‌دهد (پیش‌فرض: True). | BOOLEAN | بله | True<br>False |

**توجه:** مجموع مدت‌زمان تمام صدای مرجع باید کمتر از ۲۷۰ ثانیه باشد. اگر مدت‌زمان مجموع به ۲۷۰ ثانیه برسد یا از آن فراتر رود، گره یک خطا برمی‌گرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `voice` | صدای کلون‌شده تازه‌ساخته‌شده، که با یک شناسه صدای یکتا که Fish Audio API بازمی‌گرداند مشخص می‌شود. این صدا می‌تواند برای تبدیل متن به گفتار استفاده شود. | FISHAUDIO_VOICE |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/FishAudioInstantVoiceClone/fa.md)
