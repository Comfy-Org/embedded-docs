# RotateMesh

旋轉 3D 網格，可透過世界軸使用 Euler XYZ 角度（以度為單位）或四元數進行旋轉。旋轉會套用至網格的頂點，法線和切線也會一併旋轉，使光影與著色保持正確。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mode` | 要使用的旋轉模式。`"euler_xyz"` 依序以 X、Y、Z 角度繞世界軸旋轉（以度為單位）。`"quaternion"` 使用 (w, x, y, z) 四元數，並會自動正規化。 | DYNAMIC_COMBO | 是 | `"euler_xyz"`<br>`"quaternion"` |
| `mesh` | 要旋轉的 3D 網格。 | MESH | 是 | — |

### euler_xyz 輸入

當 `mode` 設定為 `"euler_xyz"` 時，會出現這些輸入。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | 繞 X 軸旋轉的角度（以度為單位）。（預設值：0.0） | FLOAT | 否 | -360.0 至 360.0 (step: 0.1) |
| `angle_y` | 繞 Y 軸旋轉的角度（以度為單位）。（預設值：0.0） | FLOAT | 否 | -360.0 至 360.0 (step: 0.1) |
| `angle_z` | 繞 Z 軸旋轉的角度（以度為單位）。（預設值：0.0） | FLOAT | 否 | -360.0 至 360.0 (step: 0.1) |

### quaternion 輸入

當 `mode` 設定為 `"quaternion"` 時，會出現這些輸入。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `qw` | 四元數 (w, x, y, z) 的 W 分量。（預設值：1.0） | FLOAT | 否 | -1.0 至 1.0 (step: 0.001) |
| `qx` | 四元數 (w, x, y, z) 的 X 分量。（預設值：0.0） | FLOAT | 否 | -1.0 至 1.0 (step: 0.001) |
| `qy` | 四元數 (w, x, y, z) 的 Y 分量。（預設值：0.0） | FLOAT | 否 | -1.0 至 1.0 (step: 0.001) |
| `qz` | 四元數 (w, x, y, z) 的 Z 分量。（預設值：0.0） | FLOAT | 否 | -1.0 至 1.0 (step: 0.001) |

**注意：** 當 `mode` 為 `"euler_xyz"` 且三個角度皆為 0.0，或當 `mode` 為 `"quaternion"` 且四元數為單位四元數 (1, 0, 0, 0) 時，網格會原樣回傳。四元數會在使用前自動正規化；若其模長過於接近零，節點會拋出錯誤。
