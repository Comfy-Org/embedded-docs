# RotateMesh

3D メッシュを、Euler XYZ 角度（度単位）またはクォータニオンのいずれかを使用して、ワールド軸周りに回転させます。回転はメッシュの頂点に適用され、法線とタンジェントも回転するため、ライティングとシェーディングが正しく保たれます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mode` | 使用する回転モードです。`"euler_xyz"` はワールド軸周りの X → Y → Z の順に角度（度単位）を適用します。`"quaternion"` は自動的に正規化される (w, x, y, z) クォータニオンを使用します。 | DYNAMIC_COMBO | はい | `"euler_xyz"`<br>`"quaternion"` |
| `mesh` | 回転させる3Dメッシュです。 | MESH | はい | — |

### euler_xyz 入力

これらの入力は、`mode` が `"euler_xyz"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | X軸周りの回転角度（度単位）です。（デフォルト: 0.0） | FLOAT | いいえ | -360.0 to 360.0 (step: 0.1) |
| `angle_y` | Y軸周りの回転角度（度単位）です。（デフォルト: 0.0） | FLOAT | いいえ | -360.0 to 360.0 (step: 0.1) |
| `angle_z` | Z軸周りの回転角度（度単位）です。（デフォルト: 0.0） | FLOAT | いいえ | -360.0 to 360.0 (step: 0.1) |

### quaternion 入力

これらの入力は、`mode` が `"quaternion"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qw` | クォータニオン (w, x, y, z) の W 成分です。（デフォルト: 1.0） | FLOAT | いいえ | -1.0 to 1.0 (step: 0.001) |
| `qx` | クォータニオン (w, x, y, z) の X 成分です。（デフォルト: 0.0） | FLOAT | いいえ | -1.0 to 1.0 (step: 0.001) |
| `qy` | クォータニオン (w, x, y, z) の Y 成分です。（デフォルト: 0.0） | FLOAT | いいえ | -1.0 to 1.0 (step: 0.001) |
| `qz` | クォータニオン (w, x, y, z) の Z 成分です。（デフォルト: 0.0） | FLOAT | いいえ | -1.0 to 1.0 (step: 0.001) |

**注記:** `mode` が `"euler_xyz"` で3つの角度がすべて 0.0 の場合、または `mode` が `"quaternion"` でクォータニオンが単位クォータニオン (1, 0, 0, 0) の場合、メッシュは変更されずに返されます。クォータニオンは使用前に自動的に正規化されます。その大きさがゼロに近すぎる場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 回転されたメッシュです。頂点が回転され、法線は方向として回転されます。タンジェントは X、Y、Z 成分が回転され、W（handedness）成分は変更されません。 | MESH |
