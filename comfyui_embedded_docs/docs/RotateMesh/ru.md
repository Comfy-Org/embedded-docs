# Поворот меша

Поворачивает 3D-меш вокруг мировых осей с помощью углов Эйлера XYZ (в градусах) или кватерниона. В режиме Эйлера XYZ вращения применяются как X, затем Y, затем Z; в режиме кватерниона кватернион (w, x, y, z) автоматически нормализуется. Вращение применяется к вершинам меша, а нормали и касательные также поворачиваются, чтобы освещение и затенение оставались корректными.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mode` | Режим вращения. `"euler_xyz"` применяет вращение как углы X, затем Y, затем Z относительно мировых осей (в градусах). `"quaternion"` использует кватернион (w, x, y, z), который автоматически нормализуется. | DYNAMIC_COMBO | Да | `"euler_xyz"`<br>`"quaternion"` |
| `mesh` | 3D-меш для вращения. | MESH | Да | — |

### Входы euler_xyz

Эти входы появляются, когда для `mode` установлено значение `"euler_xyz"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | Вращение вокруг оси X в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (шаг: 0.1) |
| `angle_y` | Вращение вокруг оси Y в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (шаг: 0.1) |
| `angle_z` | Вращение вокруг оси Z в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (шаг: 0.1) |

### Входы quaternion

Эти входы появляются, когда для `mode` установлено значение `"quaternion"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qw` | W-компонент кватерниона (w, x, y, z). (по умолчанию: 1.0) | FLOAT | Нет | -1.0 до 1.0 (шаг: 0.001) |
| `qx` | X-компонент кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (шаг: 0.001) |
| `qy` | Y-компонент кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (шаг: 0.001) |
| `qz` | Z-компонент кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (шаг: 0.001) |

**Примечание:** Когда `mode` имеет значение `"euler_xyz"` и все три угла равны 0.0, или когда `mode` имеет значение `"quaternion"` и кватернион является единичным (1, 0, 0, 0), меш возвращается без изменений. Кватернион автоматически нормализуется перед использованием; если его модуль меньше 1e-8, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Повёрнутый меш. Вершины повёрнуты, а нормали повёрнуты как направления. У касательных компоненты X, Y, Z повёрнуты, тогда как компонент W (рукость) остаётся без изменений. | MESH |
