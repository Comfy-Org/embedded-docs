# RotateMesh

Поверните 3D-сетку вокруг мировых осей, используя углы Эйлера XYZ (в градусах) или кватернион. Вращение применяется к вершинам сетки, а нормали и касательные также вращаются, чтобы освещение и затенение оставались корректными.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mode` | Режим вращения. `"euler_xyz"` применяет вращение вокруг мировых осей в порядке X, затем Y, затем Z (в градусах). `"quaternion"` использует кватернион (w, x, y, z), который автоматически нормализуется. | DYNAMIC_COMBO | Да | `"euler_xyz"`<br>`"quaternion"` |
| `mesh` | 3D-сетка для вращения. | MESH | Да | — |

### Входы euler_xyz

Эти входы появляются, когда `mode` имеет значение `"euler_xyz"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | Вращение вокруг оси X в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (step: 0.1) |
| `angle_y` | Вращение вокруг оси Y в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (step: 0.1) |
| `angle_z` | Вращение вокруг оси Z в градусах. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (step: 0.1) |

### Входы quaternion

Эти входы появляются, когда `mode` имеет значение `"quaternion"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qw` | Компонент W кватерниона (w, x, y, z). (по умолчанию: 1.0) | FLOAT | Нет | -1.0 до 1.0 (step: 0.001) |
| `qx` | Компонент X кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (step: 0.001) |
| `qy` | Компонент Y кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (step: 0.001) |
| `qz` | Компонент Z кватерниона (w, x, y, z). (по умолчанию: 0.0) | FLOAT | Нет | -1.0 до 1.0 (step: 0.001) |

**Примечание:** Если `mode` имеет значение `"euler_xyz"` и все три угла равны 0.0, или если `mode` имеет значение `"quaternion"` и кватернион является единичным (1, 0, 0, 0), сетка возвращается без изменений. Кватернион автоматически нормализуется перед использованием; если его величина слишком близка к нулю, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `сетка` | Повернутая сетка. Вершины повернуты, а нормали повернуты как направления. Касательные имеют повернутые компоненты X, Y, Z, а компонент W (ориентация) остается без изменений. | MESH |
