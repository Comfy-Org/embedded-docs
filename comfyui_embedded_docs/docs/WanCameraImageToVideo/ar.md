# WanCameraImageToVideo

تقوم عقدة WanCameraImageToVideo بإعداد بيانات التوجيه (conditioning) والبيانات الكامنة (latent) لتوليد الفيديو من الصور. تأخذ هذه العقدة مطالبات التوجيه الإيجابية والسلبية، بالإضافة إلى صورة بداية اختيارية وضوابط كاميرا اختيارية، وتُخرج توجيهًا معدّلًا بالإضافة إلى موتر كامن فارغ جاهز ليملأه نموذج الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مطالبات التوجيه الإيجابية لتوليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | مطالبات التوجيه السلبية التي يجب تجنبها في توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لتشفير الصور إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم الدُفعة` | عدد مقاطع الفيديو التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `خرج رؤية CLIP` | مخرج رؤية CLIP اختياري لتوجيه إضافي | CLIP_VISION_OUTPUT | لا | - |
| `الصورة البداية` | صورة بداية اختيارية لتهيئة تسلسل الفيديو. عند توفيرها، ستكون الإطارات الأولى من الفيديو مبنية على هذه الصورة، مع تطبيق قناع لمزج إطارات البداية بالمحتوى المولّد. يتم تغيير حجم الصورة لمطابقة العرض والارتفاع المحددين. | IMAGE | لا | - |
| `شروط الكاميرا` | شروط تضمين الكاميرا اختيارية لتوليد الفيديو. عند توفيرها، تُطبق هذه الشروط على كل من التوجيه الإيجابي والسلبي. | WAN_CAMERA_EMBEDDING | لا | - |

**ملاحظة:** عند توفير `start_image`، يتم استخدام أول `length` إطارًا فقط من صورة الإدخال لتهيئة تسلسل الفيديو، وتقوم العقدة بتطبيق قناع لمزج إطارات البداية مع المحتوى المولّد. المعاملان `camera_conditions` و `clip_vision_output` اختياريان، لكن عند توفيرهما، يقومان بتعديل التوجيه لكل من المطالبات الإيجابية والسلبية.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | توجيه إيجابي معدّل مع تطبيق شروط الكاميرا، ومخرجات رؤية CLIP، و/أو بيانات صورة البداية | CONDITIONING |
| `سلبي` | توجيه سلبي معدّل مع تطبيق شروط الكاميرا، ومخرجات رؤية CLIP، و/أو بيانات صورة البداية | CONDITIONING |
| `كامن` | تمثيل كامن (latent) فارغ مولّد للفيديو لاستخدامه مع نماذج الفيديو. أبعاد الموتر الكامن هي [batch_size, 16, frames, height/8, width/8] حيث يتم حساب frames كـ ((length - 1) // 4) + 1. | LATENT |
