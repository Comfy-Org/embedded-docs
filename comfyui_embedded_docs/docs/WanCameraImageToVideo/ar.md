# WanCameraImageToVideo

يقوم **WanCameraImageToVideo** بتحضير بيانات التكييف والكامنة لتوليد الفيديو من الصور. يأخذ هذا العقدة مطالبات تكييف إيجابية وسلبية، بالإضافة إلى صور بداية اختيارية وعناصر تحكم بالكاميرا، ويُخرج تكييفًا معدلًا وموترًا كامنًا فارغًا جاهزًا ليقوم نموذج الفيديو بملئه.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مطالبات التكييف الإيجابية لتوليد الفيديو | CONDITIONING | نعم | - |
| `negative` | مطالبات التكييف السلبية التي يجب تجنبها في توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لتشفير الصور إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 to 4096 |
| `clip_vision_output` | خرج رؤية CLIP اختياري لتكييف إضافي | CLIP_VISION_OUTPUT | لا | - |
| `start_image` | صورة بداية اختيارية لتهيئة تسلسل الفيديو. عند توفيرها، ستستند الإطارات الأولى من الفيديو إلى هذه الصورة، مع تطبيق قناع لدمج إطارات البداية مع المحتوى المولّد. يتم تغيير حجم الصورة لتناسب العرض والارتفاع المحددين. | IMAGE | لا | - |
| `camera_conditions` | شروط تضمين الكاميرا اختيارية لتوليد الفيديو. عند توفيرها، تُطبَّق هذه الشروط على كل من التكييف الإيجابي والسلبي. | WAN_CAMERA_EMBEDDING | لا | - |

**ملاحظة:** عند توفير `start_image`، تستخدمه العقدة لتهيئة تسلسل الفيديو وتطبق قناعًا لدمج إطارات البداية مع المحتوى المولّد. معاملا `camera_conditions` و`clip_vision_output` اختياريان، ولكن عند توفيرهما، يقومان بتعديل التكييف لكل من المطالبات الإيجابية والسلبية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدل مع تطبيق شروط الكاميرا ومخرجات رؤية CLIP و/أو بيانات صورة البداية | CONDITIONING |
| `negative` | تكييف سلبي معدل مع تطبيق شروط الكاميرا ومخرجات رؤية CLIP و/أو بيانات صورة البداية | CONDITIONING |
| `latent` | تمثيل كامن فارغ مولّد للفيديو لاستخدامه مع نماذج الفيديو. أبعاد الموتر الكامن هي [batch_size, 16, frames, height/8, width/8] حيث يُحسب frames كالتالي: ((length - 1) // 4) + 1. | LATENT |
