# WanCameraImageToVideo

تُهيّئ عقدة WanCameraImageToVideo بيانات التكييف والبيانات الكامنة لتوليد فيديو متحكَّم فيه بالكاميرا من الصور. وتستقبل مطالبات تكييف إيجابية وسلبية، إلى جانب مدخلات اختيارية مثل صورة بداية، ومخرجات رؤية CLIP، وظروف الكاميرا، وتُخرج تكييفًا محدَّثًا بالإضافة إلى موتر كامن فارغ جاهز ليملأه نموذج الفيديو.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `positive` | مطالبات التكييف الإيجابية لتوليد الفيديو | CONDITIONING | نعم | - |
| `negative` | مطالبات التكييف السلبية التي يجب تجنبها في توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لترميز الصور إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات المراد توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `clip_vision_output` | مخرجات رؤية CLIP اختيارية لتكييف إضافي | CLIP_VISION_OUTPUT | لا | - |
| `start_image` | صورة بداية اختيارية لتهيئة تسلسل الفيديو. عند توفيرها، تُستخدم أول `length` إطارًا فقط، وتُغيَّر أبعاد الصورة لتطابق `width` و`height` المحددين. تُرمَّز الإطارات الأولى من التسلسل إلى الكامن وتُطبَّق قناع لدمج إطارات البداية مع المحتوى المولَّد. | IMAGE | لا | - |
| `camera_conditions` | ظروف تضمين الكاميرا الاختيارية لتوليد الفيديو. عند توفيرها، تُطبَّق هذه الظروف على كل من التكييف الإيجابي والسلبي. | WAN_CAMERA_EMBEDDING | لا | - |

**ملاحظة:** عند توفير `start_image`، تضبط العقدة قيمتي `concat_latent_image` و`concat_mask` على كل من تكييف `positive` و`negative`. معاملَا `camera_conditions` و`clip_vision_output` اختياريان، ولكن عند توفيرهما فإنهما يعدّلان التكييف لكل من المطالبات الإيجابية والسلبية.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدَّل مع تطبيق ظروف الكاميرا، ومخرجات رؤية CLIP، و/أو بيانات صورة البداية | CONDITIONING |
| `negative` | تكييف سلبي معدَّل مع تطبيق ظروف الكاميرا، ومخرجات رؤية CLIP، و/أو بيانات صورة البداية | CONDITIONING |
| `latent` | تمثيل كامن فارغ للفيديو لاستخدامه مع نماذج الفيديو. أبعاد الموتر الكامن هي [batch_size, 16, frames, height/8, width/8]، حيث تُحسب frames بالشكل ((length - 1) // 4) + 1. | LATENT |
