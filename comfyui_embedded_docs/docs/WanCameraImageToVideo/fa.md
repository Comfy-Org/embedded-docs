# WanCameraImageToVideo

گره WanCameraImageToVideo داده‌های شرطی‌سازی و latent را برای تولید ویدئو با کنترل دوربین از تصاویر آماده می‌کند. این گره پرامپت‌های شرطی‌سازی مثبت و منفی را همراه با ورودی‌های اختیاری مانند تصویر شروع، خروجی بینایی CLIP و شرایط دوربین می‌گیرد و شرطی‌سازی به‌روزرسانی‌شده به‌همراه یک تنسور latent خالی آماده برای پر کردن توسط مدل ویدئو خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت برای تولید ویدئو | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرطی‌سازی منفی برای اجتناب از آن‌ها در تولید ویدئو | CONDITIONING | بله | - |
| `vae` | مدل VAE برای کدگذاری تصاویر به فضای latent | VAE | بله | - |
| `عرض` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | تعداد فریم‌ها در دنباله ویدئو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدئوهایی که هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی clip vision` | خروجی بینایی CLIP اختیاری برای شرطی‌سازی بیشتر | CLIP_VISION_OUTPUT | خیر | - |
| `تصویر شروع` | تصویر شروع اختیاری برای مقداردهی اولیه به دنباله ویدئو. وقتی ارائه شود، فقط اولین `length` فریم استفاده می‌شود و تصویر تغییر اندازه می‌یابد تا با `width` و `height` مشخص‌شده مطابقت کند. فریم‌های اول دنباله در latent کدگذاری می‌شوند و یک ماسک اعمال می‌شود تا فریم‌های شروع با محتوای تولیدشده ترکیب شوند. | IMAGE | خیر | - |
| `شرایط دوربین` | شرایط جاسازی دوربین اختیاری برای تولید ویدئو. وقتی ارائه شود، این شرایط روی هر دو شرطی‌سازی مثبت و منفی اعمال می‌شود. | WAN_CAMERA_EMBEDDING | خیر | - |

**توجه:** وقتی `start_image` ارائه شود، گره مقادیر `concat_latent_image` و `concat_mask` را روی هر دو شرطی‌سازی `positive` و `negative` تنظیم می‌کند. پارامترهای `camera_conditions` و `clip_vision_output` اختیاری هستند، اما وقتی ارائه شوند، شرطی‌سازی را برای هر دو پرامپت مثبت و منفی تغییر می‌دهند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده با شرایط دوربین اعمال‌شده، خروجی بینایی CLIP و/یا داده تصویر شروع | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده با شرایط دوربین اعمال‌شده، خروجی بینایی CLIP و/یا داده تصویر شروع | CONDITIONING |
| `latent` | نمایش latent ویدئوی خالی برای استفاده با مدل‌های ویدئو. تنسور latent ابعاد [batch_size, 16, frames, height/8, width/8] را دارد، که در آن frames به‌صورت ((length - 1) // 4) + 1 محاسبه می‌شود. | LATENT |
