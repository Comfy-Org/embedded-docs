# WanCameraImageToVideo

گره WanCameraImageToVideo داده‌های شرطی‌سازی و latent را برای تولید ویدیو از تصاویر آماده می‌کند. این گره پرامپت‌های شرطی‌سازی مثبت و منفی را به همراه یک تصویر شروع اختیاری و کنترل‌های دوربین اختیاری دریافت می‌کند و شرطی‌سازی اصلاح‌شده را به همراه یک تنسور latent خالی که آمادهٔ پر شدن توسط مدل ویدیو است، خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرطی‌سازی منفی که در تولید ویدیو از آن‌ها اجتناب شود | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر به فضای نهفته (latent) | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌های دنباله‌ٔ ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدیوهایی که به‌طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی clip vision` | خروجی اختیاری CLIP vision برای شرطی‌سازی اضافی | CLIP_VISION_OUTPUT | خیر | - |
| `تصویر شروع` | تصویر شروع اختیاری برای مقداردهی اولیهٔ دنبالهٔ ویدیو. هنگامی که ارائه شود، اولین فریم‌های ویدیو بر اساس این تصویر خواهند بود و یک ماسک برای ترکیب فریم‌های شروع با محتوای تولیدشده اعمال می‌شود. تصویر برای مطابقت با عرض و ارتفاع مشخص‌شده تغییر اندازه می‌دهد. | IMAGE | خیر | - |
| `شرایط دوربین` | شرایط اختیاری جاسازی دوربین برای تولید ویدیو. هنگامی که ارائه شوند، این شرایط بر روی هر دو شرطی‌سازی مثبت و منفی اعمال می‌شوند. | WAN_CAMERA_EMBEDDING | خیر | - |

**توجه:** هنگامی که `start_image` ارائه می‌شود، تنها `length` فریم اول تصویر ورودی برای مقداردهی اولیهٔ دنبالهٔ ویدیو استفاده می‌شود و گره یک ماسک برای ترکیب این فریم‌های شروع با محتوای تولیدشده اعمال می‌کند. پارامترهای `camera_conditions` و `clip_vision_output` اختیاری هستند، اما وقتی ارائه شوند، شرطی‌سازی را برای هر دو پرامپت مثبت و منفی تغییر می‌دهند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده با اعمال شرایط دوربین، خروجی‌های CLIP vision و/یا داده‌های تصویر شروع | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده با اعمال شرایط دوربین، خروجی‌های CLIP vision و/یا داده‌های تصویر شروع | CONDITIONING |
| `latent` | بازنمایی latent ویدیوی خالی تولیدشده برای استفاده با مدل‌های ویدیو. تنسور latent دارای ابعاد [batch_size, 16, frames, height/8, width/8] است که frames به‌صورت ((length - 1) // 4) + 1 محاسبه می‌شود. | LATENT |
