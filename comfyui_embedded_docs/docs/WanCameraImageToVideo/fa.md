# WanCameraImageToVideo

WanCameraImageToVideo داده‌های conditioning و latent را برای تولید ویدیو از تصاویر آماده می‌کند. این گره پرامپت‌های conditioning مثبت و منفی را به همراه تصاویر شروع و کنترل‌های دوربین اختیاری دریافت می‌کند و conditioning اصلاح‌شده و یک تانسور latent خالی را خروجی می‌دهد که آماده است توسط یک مدل ویدیو تکمیل شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های conditioning مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `negative` | پرامپت‌های conditioning منفی برای اجتناب در تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر به فضای latent | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌ها در دنباله ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `clip_vision_output` | خروجی اختیاری CLIP vision برای اعمال conditioning اضافی | CLIP_VISION_OUTPUT | خیر | - |
| `start_image` | تصویر شروع اختیاری برای مقداردهی اولیه دنباله ویدیو. وقتی ارائه شود، فریم‌های ابتدایی ویدیو بر اساس این تصویر ساخته می‌شوند و یک ماسک برای ترکیب فریم‌های شروع با محتوای تولیدشده اعمال می‌گردد. تصویر به‌گونه‌ای تغییر اندازه داده می‌شود که با عرض و ارتفاع مشخص‌شده مطابقت داشته باشد. | IMAGE | خیر | - |
| `camera_conditions` | شرایط اختیاری embedding دوربین برای تولید ویدیو. وقتی ارائه شوند، این شرایط بر روی هر دو conditioning مثبت و منفی اعمال می‌شوند. | WAN_CAMERA_EMBEDDING | خیر | - |

**نکته:** وقتی `start_image` ارائه شود، گره از آن برای مقداردهی اولیه دنباله ویدیو استفاده می‌کند و ماسک‌گذاری را برای ترکیب فریم‌های شروع با محتوای تولیدشده اعمال می‌نماید. پارامترهای `camera_conditions` و `clip_vision_output` اختیاری هستند، اما در صورت ارائه، conditioning را برای هر دو پرامپت مثبت و منفی تغییر می‌دهند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | conditioning مثبت اصلاح‌شده با اعمال شرایط دوربین، خروجی‌های clip vision و/یا داده‌های تصویر شروع | CONDITIONING |
| `negative` | conditioning منفی اصلاح‌شده با اعمال شرایط دوربین، خروجی‌های clip vision و/یا داده‌های تصویر شروع | CONDITIONING |
| `latent` | نمایش latent ویدیویی خالی تولیدشده برای استفاده با مدل‌های ویدیو. تانسور latent دارای ابعاد [batch_size, 16, frames, height/8, width/8] است که frames به صورت ((length - 1) // 4) + 1 محاسبه می‌شود. | LATENT |
