# WanCameraImageToVideo

WanCameraImageToVideo подготавливает данные кондиционирования и латентное представление для генерации видео из изображений. Он принимает положительные и отрицательные промпты кондиционирования, а также опциональные стартовые изображения и управление камерой, и возвращает модифицированное кондиционирование и пустой латентный тензор, готовый для заполнения видеомоделью.

## Входные данные

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные промпты кондиционирования для генерации видео | CONDITIONING | Да | - |
| `negative` | Отрицательные промпты кондиционирования, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `vae` | VAE-модель для кодирования изображений в скрытое пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `clip_vision_output` | Дополнительный выход CLIP Vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `start_image` | Необязательное стартовое изображение для инициализации видеопоследовательности. Если оно задано, первые кадры видео будут основаны на этом изображении, а маска будет применена для смешивания стартовых кадров с генерируемым содержимым. Изображение масштабируется до указанных ширины и высоты. | IMAGE | Нет | - |
| `camera_conditions` | Необязательные условия эмбеддингов камеры для генерации видео. Если они заданы, эти условия применяются как к положительному, так и к отрицательному кондиционированию. | WAN_CAMERA_EMBEDDING | Нет | - |

**Примечание:** Если указан `start_image`, узел использует его для инициализации видеопоследовательности и применяет маскирование для смешивания стартовых кадров с генерируемым содержимым. Параметры `camera_conditions` и `clip_vision_output` необязательны, но при их наличии они изменяют кондиционирование как для положительных, так и для отрицательных промптов.

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование с применёнными условиями камеры, выходами CLIP Vision и/или данными стартового изображения | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование с применёнными условиями камеры, выходами CLIP Vision и/или данными стартового изображения | CONDITIONING |
| `latent` | Сгенерированное пустое латентное представление видео для использования с видеомоделями. Латентный тензор имеет размерности [batch_size, 16, frames, height/8, width/8], где frames вычисляется как ((length - 1) // 4) + 1. | LATENT |
