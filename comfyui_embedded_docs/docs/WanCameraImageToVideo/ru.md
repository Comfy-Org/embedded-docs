# WanCameraImageToVideo

Узел WanCameraImageToVideo подготавливает данные кондиционирования и латентные данные для генерации видео с управлением камерой на основе изображений. Он принимает позитивные и негативные промпты кондиционирования, а также необязательные входы, такие как начальное изображение, выход CLIP vision и условия камеры, и выдаёт обновлённое кондиционирование плюс пустой латентный тензор, готовый для заполнения видеомоделью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Позитивные промпты кондиционирования для генерации видео | CONDITIONING | Да | - |
| `негативный` | Негативные промпты кондиционирования, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `VAE` | Модель VAE для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `выход_clip_vision` | Необязательный выход CLIP vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное начальное изображение для инициализации видеопоследовательности. Если указано, используются только первые `length` кадров, а изображение масштабируется до заданных `width` и `height`. Первые кадры последовательности кодируются в латентное представление, и применяется маска для смешивания начальных кадров с сгенерированным содержимым. | IMAGE | Нет | - |
| `условия_камеры` | Необязательные условия встраивания камеры для генерации видео. Если указаны, эти условия применяются как к позитивному, так и к негативному кондиционированию. | WAN_CAMERA_EMBEDDING | Нет | - |

**Примечание:** Если указан `start_image`, узел устанавливает значения `concat_latent_image` и `concat_mask` в кондиционировании как для `positive`, так и для `negative`. Параметры `camera_conditions` и `clip_vision_output` являются необязательными, но если они предоставлены, они изменяют кондиционирование как для позитивного, так и для негативного промптов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённое позитивное кондиционирование с применёнными условиями камеры, выходом CLIP vision и/или данными начального изображения | CONDITIONING |
| `negative` | Изменённое негативное кондиционирование с применёнными условиями камеры, выходом CLIP vision и/или данными начального изображения | CONDITIONING |
| `latent` | Пустое латентное представление видео для использования с видеомоделями. Латентный тензор имеет размерности [batch_size, 16, frames, height/8, width/8], где frames вычисляется как ((length - 1) // 4) + 1. | LATENT |
