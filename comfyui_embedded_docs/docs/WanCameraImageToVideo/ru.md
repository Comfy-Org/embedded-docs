# WanCameraImageToVideo

Узел WanCameraImageToVideo подготавливает данные кондиционирования и латентное представление для генерации видео из изображений. Он принимает позитивные и негативные промпты кондиционирования, а также необязательное начальное изображение и необязательное управление камерой, и возвращает изменённое кондиционирование плюс пустой латентный тензор, готовый к заполнению видеомоделью.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Позитивные промпты кондиционирования для генерации видео | CONDITIONING | Да | - |
| `негативный` | Негативные промпты кондиционирования, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `VAE` | Модель VAE для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `выход_clip_vision` | Необязательный выход CLIP vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное начальное изображение для инициализации видеопоследовательности. Если оно задано, первые кадры видео будут созданы на основе этого изображения, при этом применяется маска для смешивания начальных кадров со сгенерированным содержимым. Изображение масштабируется до указанных ширины и высоты. | IMAGE | Нет | - |
| `условия_камеры` | Необязательные условия эмбеддинга камеры для генерации видео. Если они заданы, эти условия применяются как к позитивному, так и к негативному кондиционированию. | WAN_CAMERA_EMBEDDING | Нет | - |

**Примечание:** Если задано `start_image`, для инициализации видеопоследовательности используются только первые `length` кадров входного изображения, и узел применяет маску для смешивания этих начальных кадров со сгенерированным содержимым. Параметры `camera_conditions` и `clip_vision_output` необязательны, но при их наличии они изменяют кондиционирование как для позитивных, так и для негативных промптов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Изменённое позитивное кондиционирование с применёнными условиями камеры, выходами CLIP vision и/или данными начального изображения | CONDITIONING |
| `негативный` | Изменённое негативное кондиционирование с применёнными условиями камеры, выходами CLIP vision и/или данными начального изображения | CONDITIONING |
| `латентный` | Сгенерированное пустое латентное представление видео для использования с видеомоделями. Латентный тензор имеет размерности [batch_size, 16, frames, height/8, width/8], где frames вычисляется как ((length - 1) // 4) + 1. | LATENT |
