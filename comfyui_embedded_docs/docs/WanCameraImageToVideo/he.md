# WanCameraImageToVideo

הצומת WanCameraImageToVideo מכין נתוני התניה ונתונים לטנטיים ליצירת וידאו הנשלטת על ידי מצלמה מתוך תמונות. הוא מקבל פרומפטים להתניה חיובית ושלילית, יחד עם קלטים אופציונליים כגון תמונת התחלה, פלט CLIP vision ותנאי מצלמה, ומוציא התניה מעודכנת וכן טנזור לטנטי ריק המוכן לכך שמודל וידאו ימלא אותו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | פרומפטים להתניה חיובית ליצירת וידאו | CONDITIONING | כן | - |
| `negative` | פרומפטים להתניה שלילית שיש להימנע מהם ביצירת וידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE לקידוד תמונות למרחב לטנטי | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הסרטונים ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `clip_vision_output` | פלט CLIP vision אופציונלי להתניה נוספת | CLIP_VISION_OUTPUT | לא | - |
| `start_image` | תמונת התחלה אופציונלית לאתחול רצף הווידאו. כאשר היא מסופקת, משתמשים רק ב-`length` הפריימים הראשונים, והתמונה משתנה לגודל המתאים ל-`width` ול-`height` שצוינו. הפריימים הראשונים של הרצף מקודדים לייצוג הלטנטי ומוחלת מסכה כדי למזג את פריימי ההתחלה עם התוכן הנוצר. | IMAGE | לא | - |
| `camera_conditions` | תנאי הטמעת מצלמה אופציונליים ליצירת וידאו. כאשר הם מסופקים, תנאים אלה מוחלים גם על ההתניה החיובית וגם על השלילית. | WAN_CAMERA_EMBEDDING | לא | - |

**הערה:** כאשר `start_image` מסופק, הצומת מגדיר ערכי `concat_latent_image` ו-`concat_mask` גם על ההתניה של `positive` וגם על זו של `negative`. הפרמטרים `camera_conditions` ו-`clip_vision_output` הם אופציונליים, אך כאשר הם מסופקים, הם משנים את ההתניה הן עבור הפרומפטים החיוביים והן עבור השליליים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | התניה חיובית ששונתה עם תנאי מצלמה מיושמים, פלט CLIP vision ו/או נתוני תמונת התחלה | CONDITIONING |
| `negative` | התניה שלילית ששונתה עם תנאי מצלמה מיושמים, פלט CLIP vision ו/או נתוני תמונת התחלה | CONDITIONING |
| `latent` | ייצוג לטנטי ריק של וידאו לשימוש עם מודלי וידאו. לטנזור הלטנטי יש ממדים [batch_size, 16, frames, height/8, width/8], כאשר frames מחושב כ-((length - 1) // 4) + 1. | LATENT |
