# ByteDanceSeedAudio

Генерируйте речь, музыку, звуковые эффекты и диалоги нескольких говорящих из одного запроса с помощью ByteDance Seed Audio 1.0. Опишите голос(а), эмоции, атмосферу, фоновую музыку и звуковые эффекты в запросе, а также включите реплики для озвучивания. При желании выберите встроенный голос из набора, клонируйте голоса из 1–3 эталонных клипов (помеченных как @Audio1-3 в запросе) или создайте голос на основе изображения персонажа. До 2 минут аудио за один запуск.

## Входные данные

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `text_prompt` | Опишите голос(а), эмоции, темп, атмосферу, фоновую музыку и звуковые эффекты, а также включите реплики для озвучивания (для диалогов указывайте имена персонажей в тексте). В режиме «аудиореференс» ссылайтесь на подключенные клики по порядку как @Audio1, @Audio2, @Audio3. В многоязычной модели строка в кавычках может начинаться с диапазона временных меток, который управляет тем, когда и как долго она произносится, например `[5.5s:8.0s] Подожди меня!`. Пишите промпт на том же языке, что и строки для произнесения. Минимум 1 символ, Максимум 3000 символов. | STRING | Да | от 1 до 3000 символов |
  - **"audio reference"**: Требуется подключение хотя бы одного из `reference_audio_1`, `reference_audio_2` или `reference_audio_3`. Эталонные клипы должны подключаться по порядку, без пропусков. ### Ограничения параметров

- **Зависимости от режима референса**: Параметр `reference_mode` определяет, какие дополнительные входные данные обязательны:
  - **"text only"**: Дополнительные входные данные не требуются. Запрос не должен содержать теги @AudioN.
  - **"audio reference"**: Требуется подключение хотя бы одного из `reference_audio_1`, `reference_audio_2` или `reference_audio_3`. Эталонные клипы должны подключаться по порядку без пропусков (например, _1, затем _2, затем _3). Длительность каждого клипа ограничена 30 секундами. Запрос должен ссылаться на подключенные клипы с помощью тегов @Audio1, @Audio2, @Audio3.
  - **"image reference"**: Требуется подключение `reference_image`. Запрос не должен содержать теги @AudioN.
  - **"preset voice"**: Требуется выбор `preset_voice`. Запрос не должен содержать теги @AudioN (весь запрос озвучивается выбранным голосом).

- **Порядок аудиореференсов**: При использовании режима "audio reference" входные аудиоданные референсов должны подключаться последовательно, начиная с `reference_audio_1`, без пропусков. Например, можно подключить _1 и _2, но нельзя подключить _1 и _3 без _2.

- **Максимальное количество аудиотегов**: В режиме "audio reference" запрос может ссылаться на 1–3 аудиоклипа (@Audio1, @Audio2, @Audio3), и самый высокий тег @AudioN в запросе не может превышать количество подключенных входов аудиореференса.

- **Различия моделей**: Модель `seed-audio-1.0-multilingual` поддерживает 20 языков (английский, китайский, японский, корейский, мексиканский и кастильский испанский, индонезийский, немецкий, бразильский португальский, французский, тайский, вьетнамский, малайский, филиппинский, итальянский, русский, нидерландский, польский, турецкий, шведский), а также управление таймингом по предложениям с помощью временных меток в формате `[5.5s:8.0s]`. Модель `seed-audio-1.0` поддерживает только английский и китайский, без управления таймингом.
