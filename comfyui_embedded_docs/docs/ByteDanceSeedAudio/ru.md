# ByteDance Seed Audio 1.0

Генерируйте речь, музыку, звуковые эффекты и диалог нескольких говорящих из одного промпта с помощью ByteDance Seed Audio 1.0. Описывайте голос(а), эмоции, атмосферу, фоновую музыку и звуковые эффекты в промпте и включайте реплики для озвучивания. При необходимости выберите встроенный предустановленный голос, клонируйте голоса из до 3 эталонных клипов (с тегами @Audio1-3 в промпте) или получите голос из изображения персонажа. До 2 минут аудио за запуск. Многоязычная модель поддерживает 20 языков и управление таймингом на основе временных меток.

В режиме `"audio reference"` ссылайтесь на подключённые клипы по порядку как @Audio1, @Audio2, @Audio3. ### Ограничения параметров

- **Зависимости режима эталона**: параметр `reference_mode` определяет, какие другие входы обязательны:
  - **`"text only"`**: дополнительные входы не требуются. Промпт не должен содержать теги @AudioN.
  - **`"audio reference"`**: требуется подключить хотя бы один из `reference_audio_1`, `reference_audio_2` или `reference_audio_3`. Эталонные клипы должны быть подключены по порядку без пропусков. Максимальная длительность каждого клипа — 30 секунд. Если в промпте используются теги @AudioN, наибольший номер тега не должен превышать количество подключённых эталонных клипов.
  - **`"image reference"`**: требуется подключить `reference_image`. Теги @AudioN не используются; промпт должен содержать только текст для синтеза.
  - **`"preset voice"`**: требуется выбрать предустановленный голос. Весь промпт читается выбранным голосом; теги @AudioN не используются как ссылки, а теги вроде @Audio2 или выше отклоняются.

- **Порядок эталонного аудио**: в режиме `"audio reference"` входы эталонного аудио должны быть подключены последовательно, начиная с `reference_audio_1`, без пропусков. Например, можно подключить `reference_audio_1` и `reference_audio_2`, но нельзя `reference_audio_1` и `reference_audio_3` без `reference_audio_2`.

- **Максимальное количество аудиотегов**: в режиме `"audio reference"` можно подключить до 3 эталонных клипов (@Audio1, @Audio2, @Audio3), и наибольший тег @AudioN в промпте не может превышать количество подключённых входов эталонного аудио.

- **Различия моделей**: модель `seed-audio-1.0-multilingual` поддерживает 20 языков (английский, китайский, японский, корейский, мексиканский и кастильский варианты испанского, индонезийский, немецкий, бразильский португальский, французский, тайский, вьетнамский, малайский, филиппинский, итальянский, русский, нидерландский, польский, турецкий, шведский), а также управление таймингом по предложениям с использованием временных меток в формате `[5.5s:8.0s]`. Модель `seed-audio-1.0` поддерживает только английский и китайский, без управления таймингом.
