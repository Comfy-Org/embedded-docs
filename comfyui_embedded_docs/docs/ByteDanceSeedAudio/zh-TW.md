# ByteDanceSeedAudio

透過單一提示詞生成語音、音樂、音效及多說話者對話，使用位元組跳動 Seed Audio 1.0 模型。在提示詞中描述聲音、情緒、氛圍、背景音樂和音效，並包含要說出的台詞。可選擇內建預設聲音、從最多 3 個參考片段（在提示詞中標記為 @Audio1-3）複製聲音，或從角色圖片衍生聲音。每次執行最多可生成 2 分鐘音訊。

### 參數限制條件

- **參考模式依賴關係**：`reference_mode` 參數決定哪些其他輸入為必要：
  - **「僅文字」**：無需額外輸入。提示詞不得包含 @AudioN 標籤。
  - **「音訊參考」**：需要至少連接一個 `reference_audio_1`、`reference_audio_2` 或 `reference_audio_3`。參考片段必須按順序連接，中間不可中斷。每個片段最長 30 秒。如果在提示詞中使用 @AudioN 標籤，最高編號的標籤不得超過已連接的參考片段數量。
  - **「圖片參考」**：需要連接 `reference_image`。不使用 @AudioN 標籤；提示詞應僅包含要合成的文字。
  - **「預設聲音」**：需要選擇預設聲音。整個提示詞將以所選聲音朗讀；@AudioN 標籤不作為參考使用，@Audio2 或更高的標籤會被拒絕。

- **音訊參考順序**：使用「音訊參考」模式時，參考音訊輸入必須從 `reference_audio_1` 開始依序連接，中間不可中斷。例如，可以連接 _1 和 _2，但不能在沒有 _2 的情況下連接 _1 和 _3。

- **最大音訊標籤數量**：在「音訊參考」模式下，提示詞最多可引用 3 個音訊片段（@Audio1、@Audio2、@Audio3）。最高編號的標籤不得超過已連接的參考音訊輸入數量。

- **模型差異**：`seed-audio-1.0-multilingual` 模型支援 20 種語言（英語、中文、日語、韓語、墨西哥及卡斯提亞西班牙語、印尼語、德語、巴西葡萄牙語、法語、泰語、越南語、馬來語、菲律賓語、義大利語、俄語、荷蘭語、波蘭語、土耳其語、瑞典語），並支援使用 `[5.5s:8.0s]` 格式時間戳進行逐句時間控制。`seed-audio-1.0` 模型僅支援英語和中文，無時間控制。
