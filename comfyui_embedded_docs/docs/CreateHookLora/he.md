# צור Hook LoRA

הצומת Create Hook LoRA מייצר אובייקטי hook להחלת שינויי LoRA (התאמה בדרגה נמוכה) על מודלים. הוא טוען קובץ LoRA שצוין ויוצר hooks שיכולים לכוונן את עוצמות המודל וה-CLIP, ואז משלב hooks אלה עם כל hooks קיימים שמועברים אליו. הצומת מנהל ביעילות את טעינת ה-LoRA על ידי שמירה במטמון של קבצי LoRA שנטענו בעבר כדי למנוע פעולות מיותרות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `lora_name` | שם קובץ ה-LoRA לטעינה מתיקיית loras | STRING | כן | אפשרויות מרובות זמינות |
| `strength_model` | מכפיל העוצמה להתאמות המודל (ברירת מחדל: 1.0) | FLOAT | כן | -20.0 עד 20.0 |
| `strength_clip` | מכפיל העוצמה להתאמות ה-CLIP (ברירת מחדל: 1.0) | FLOAT | כן | -20.0 עד 20.0 |
| `prev_hooks` | קבוצת hooks קיימת אופציונלית לשילוב עם hooks החדשים של LoRA | HOOKS | לא | N/A |

**אילוצי פרמטרים:**

- אם גם `strength_model` וגם `strength_clip` מוגדרים ל-0, הצומת ידלג על יצירת hooks חדשים של LoRA ויחזיר את ה-hooks הקיימים ללא שינוי
- הצומת שומר במטמון את קובץ ה-LoRA האחרון שנטען כדי לייעל ביצועים כאשר אותו LoRA משמש שוב ושוב
