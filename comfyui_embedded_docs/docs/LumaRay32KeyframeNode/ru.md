# Luma Ray 3.2 Ключевой кадр

Этот узел привязывает направляющее изображение к определённой позиции на временной шкале выходного видео Luma Ray 3.2. Подключите этот узел ко входу "keyframes" узла Luma Ray 3.2 Keyframes to Video и объединяйте несколько ключевых кадров в цепочку, подключая необязательный вход "keyframes".

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Направляющее изображение, размещаемое в выбранный момент выходного видео. | IMAGE | Да | - |
| `position` | Способ размещения этого изображения на временной шкале выходного видео. | DYNAMIC_COMBO | Да | "Fraction of duration (0.0-1.0)"<br>"Absolute time (seconds)" |
| `keyframes` | Необязательные более ранние ключевые кадры для объединения в цепочку с текущим. | LUMA_RAY32_KEYFRAME | Нет | - |

### Входы Fraction of duration (0.0-1.0)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `fraction` | Где в выходном видео применяется это изображение (0.0 = начало, 1.0 = конец). По умолчанию: 0.0. | FLOAT | Да | 0.0 до 1.0 (шаг: 0.01) |

### Входы Absolute time (seconds)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seconds` | Время в секундах от начала выходного видео, в которое применяется это изображение. По умолчанию: 0.0. | FLOAT | Да | 0.0 до 10.0 (шаг: 0.1) |

Параметр `position` определяет, какое значение используется для размещения изображения на временной шкале. Отображается и используется только подпараметр, относящийся к выбранной опции: `fraction` для "Fraction of duration (0.0-1.0)" и `seconds` для "Absolute time (seconds)".

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `keyframes` | Цепочка ключевых кадров, которая включает новый ключевой кадр вместе с любыми необязательными более ранними ключевыми кадрами. | LUMA_RAY32_KEYFRAME |
