# Luma Ray 3.2 Ключевой кадр

Этот узел привязывает направляющее изображение к определенной позиции на временной шкале выходного видео Luma Ray 3.2. Подключите этот узел к входу `keyframes` узла Luma Ray 3.2 Keyframes to Video и объедините несколько ключевых кадров в цепочку, соединив необязательный вход `keyframes`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Направляющее изображение для размещения в выбранный момент выходного видео. | IMAGE | Да | - |
| `position` | Как разместить это изображение на временной шкале выходного видео. | DYNAMIC_COMBO | Да | "Fraction of duration (0.0-1.0)"<br>"Absolute time (seconds)" |
| `keyframes` | Необязательные предыдущие ключевые кадры для объединения в цепочку с данным. | LUMA_RAY32_KEYFRAME | Нет | - |

Если для параметра `position` выбрано значение "Fraction of duration (0.0-1.0)", вы можете указать значение `fraction` (по умолчанию: 0.0, диапазон: от 0.0 до 1.0, шаг: 0.01), которое определяет, где в выходном видео применяется это изображение (0.0 = начало, 1.0 = конец).

Если для параметра `position` выбрано значение "Absolute time (seconds)", вы можете указать значение `seconds` (по умолчанию: 0.0, диапазон: от 0.0 до 10.0, шаг: 0.1), которое определяет время в секундах от начала выходного видео, когда применяется это изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `keyframes` | Цепочка ключевых кадров, которая включает новый ключевой кадр вместе с любыми необязательными предыдущими ключевыми кадрами. | LUMA_RAY32_KEYFRAME |
