# オーディオプレビュー

PreviewAudio ノードを使用すると、オーディオを ComfyUI の出力ディレクトリに保存せずに、インターフェース上で直接プレビューできます。このノードはオーディオデータを入力として受け取り、結果を再生するためのオーディオプレイヤーウィジェットを表示します。入力オーディオが None の場合、ノードはエラーを発生させます。これは、ソース動画にオーディオトラックがない場合に発生する可能性があります。
