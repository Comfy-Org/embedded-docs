# Предварительное прослушивание аудио

Узел Preview Audio создаёт временный предпросмотр аудио, который можно воспроизвести прямо в интерфейсе, без сохранения аудио в каталог вывода ComfyUI. Он принимает аудиоданные на вход и создаёт виджет предпросмотра, позволяя пользователям прослушивать аудиовыходы без сохранения постоянных файлов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `аудио` | Аудиоданные для предпросмотра. Этот узел вызовет ошибку, если входное аудио равно None, что может произойти, когда исходное видео не имеет аудиодорожки. | AUDIO | Да | - |

**Примечание:** Если входное значение `audio` равно None, узел вызывает ValueError. Это может произойти, когда исходное видео не имеет аудиодорожки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `аудио` | Аудиоданные, переданные со входа, используемые для предпросмотра. | AUDIO |
| `ui` | Отображает виджет аудиоплеера в интерфейсе для предпросмотра аудио. | UI |
