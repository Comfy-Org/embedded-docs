# Предварительное прослушивание аудио

Узел Preview Audio позволяет прослушивать аудио прямо внутри ComfyUI, не сохраняя его в выходной каталог. Он получает аудиовход, проверяет, что аудиоданные действительно присутствуют, а затем воспроизводит их через плеер предпросмотра в интерфейсе, передавая те же аудиоданные дальше в качестве своего выхода.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `аудио` | Аудиоданные для предпросмотра. Если этот вход равен None, узел вызывает ValueError; это может произойти, когда в исходном видео нет аудиодорожки. | AUDIO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Аудиоданные, переданные без изменений со входа, чтобы узел можно было разместить в середине рабочего процесса. | AUDIO |
