# Предварительное прослушивание аудио

Узел PreviewAudio позволяет предварительно прослушать аудио прямо в интерфейсе без сохранения в выходной каталог ComfyUI. Он принимает аудиоданные на вход и отображает виджет аудиоплеера, который можно использовать для прослушивания результата. Если входное аудио равно None, узел вызывает ошибку; такая ситуация возможна, когда в исходном видео отсутствует аудиодорожка.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Аудиоданные для предварительного просмотра. Узел вызывает ошибку, если аудио равно None; такая ситуация возможна, когда в исходном видео отсутствует аудиодорожка. | AUDIO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Аудиоданные, переданные через узел. В интерфейсе отображается виджет аудиоплеера для предварительного прослушивания аудио. | AUDIO |
