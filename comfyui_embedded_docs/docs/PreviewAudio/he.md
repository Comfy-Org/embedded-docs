# PreviewAudio

צומת Preview Audio מאפשר לך להאזין לשמע ישירות בתוך ComfyUI מבלי לשמור אותו בתיקיית הפלט. הוא מקבל קלט שמע, בודק שאכן קיימים נתוני שמע, ואז מנגן אותם דרך נגן תצוגה מקדימה בממשק, תוך העברת אותו שמע הלאה כפלט שלו.
