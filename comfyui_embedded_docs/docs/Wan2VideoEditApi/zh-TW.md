# Wan 2.7 影片編輯

Wan2VideoEditApi 節點使用 Wan 2.7 模型，根據文字指令、參考圖片或風格轉換來編輯影片。它會處理輸入影片，並根據解析度、時間長度和寬高比等指定參數產生新影片。
