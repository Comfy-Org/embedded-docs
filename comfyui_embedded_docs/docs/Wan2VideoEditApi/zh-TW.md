# Wan 2.7 影片編輯

Wan2VideoEditApi 節點使用 Wan 2.7 模型，根據文字指令、參考圖片或風格轉換來編輯影片。它會處理輸入影片，並按照指定的參數（如解析度、時長和寬高比）生成新影片。
