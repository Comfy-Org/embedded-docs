# Wan 2.7 ビデオ編集

Wan2VideoEditApi ノードは、Wan 2.7 モデルを使用して、テキスト指示、参照画像、またはスタイル転送に基づいて動画を編集します。入力動画を処理し、解像度、長さ、アスペクト比などの指定されたパラメータに従って新しい動画を生成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画編集に使用するモデル。 | COMBO | はい | `"wan2.7-videoedit"` |
| `video` | 編集する動画。 | VIDEO | はい | - |
| `seed` | 生成に使用するシード値。（デフォルト: 0） | INT | いいえ | 0〜2147483647 |
| `audio_setting` | 'auto': モデルがプロンプトに基づいてオーディオを再生成するかどうかを決定します。'origin': 入力動画の元のオーディオを保持します。（デフォルト: "auto"） | COMBO | いいえ | `"auto"`<br>`"origin"` |
| `watermark` | 結果にAI生成の透かしを追加するかどうか。（デフォルト: False） | BOOLEAN | いいえ | - |

### wan2.7-videoedit 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編集指示またはスタイル転送の要件。（デフォルト: 空文字列） | STRING | はい | - |
| `resolution` | 出力動画の解像度。 | COMBO | はい | `"720P"`<br>`"1080P"` |
| `ratio` | アスペクト比。変更しない場合は、入力動画の比率に近似します。 | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | 出力の長さ（秒）。'auto' は入力動画の長さに合わせます。特定の値を指定すると、動画の先頭から切り取られます。（デフォルト: "auto"） | COMBO | はい | `"auto"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能スロット: 編集をガイドするために0〜4枚の画像（`image1`...`image4`）を接続します。wan2.7-videoedit モデルの場合は上限は4枚です。 | IMAGE | いいえ | 0〜4 個 |

**制約事項：**
*   `prompt` は少なくとも1文字以上である必要があります。
*   入力 `video` の長さは2秒から10秒の間である必要があります。
*   `reference_images` の拡張可能スロットは最大4枚まで受け付けます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | モデルによって生成された編集済み動画。 | VIDEO |
