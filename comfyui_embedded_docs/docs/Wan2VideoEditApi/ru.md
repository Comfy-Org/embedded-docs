# Wan 2.7 Редактирование видео

Узел Wan2VideoEditApi использует модель Wan 2.7 для редактирования видео на основе текстовых инструкций, референсных изображений или переноса стиля. Он обрабатывает входное видео и создает новое видео в соответствии с заданными параметрами, такими как разрешение, длительность и соотношение сторон.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для редактирования видео. | DYNAMIC_COMBO | Да | `"wan2.7-videoedit"` |
| `video` | Видео для редактирования. | VIDEO | Да | - |
| `seed` | Сид, используемый для генерации. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `audio_setting` | 'auto': модель сама решает, следует ли перегенерировать аудио на основе подсказки. 'origin': сохранить исходное аудио из входного видео. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"origin"` |
| `watermark` | Добавлять ли водяной знак, созданный ИИ, к результату. (по умолчанию: False) | BOOLEAN | Да | - |

### Входы wan2.7-videoedit

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию или требования к переносу стиля. (по умолчанию: пустая строка) | STRING | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `ratio` | Соотношение сторон. Если не изменено, приближается к соотношению сторон входного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Продолжительность вывода в секундах. 'auto' соответствует длительности входного видео. Конкретное значение обрезает видео с начала. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 0 до 4 изображений (`image1`...`image4`), чтобы направлять редактирование. Лимит количества — 4 для модели wan2.7-videoedit. | IMAGE | Нет | от 0 до 4 элементов |

**Ограничения:**
*   `prompt` должен содержать минимум 1 символ.
*   Входное `video` должно иметь длительность от 2 до 10 секунд.
*   Расширяемый слот `reference_images` принимает максимум 4 изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Отредактированное видео, сгенерированное моделью. | VIDEO |
