# OpenRouterLLMNode

צומת OpenRouter LLM שולח הנחיית טקסט לקבוצה מובחרת של מודלי שפה פופולריים הזמינים דרך שירות OpenRouter ומחזיר את תגובת הטקסט שנוצרה. הוא תומך במודלים מבית Anthropic (Claude), OpenAI (GPT), Google (Gemini), xAI (Grok), DeepSeek, Qwen, Mistral, Z.AI (GLM), Moonshot (Kimi) ו-Perplexity Sonar, ויכול לכלול באופן אופציונלי תמונות או סרטונים כקלטי עזר בבקשה.

## קלטים

כאשר נבחר מודל בבורר `model`, הצומת מציג ווידג'טים ייחודיים למודל מעל הקלטים המשותפים — מאמץ חשיבה, גודל חיפוש באינטרנט ו/או משבצות מדיה לעזר — בהתאם ליכולות המודל הנבחר.

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | קלט טקסט למודל. | STRING | כן | N/A |
| `model` | מודל OpenRouter המשמש ליצירת התגובה. | DYNAMIC_COMBO | כן | אפשרויות מרובות זמינות (ראו מקטעי המודלים שלהלן) |
| `seed` | Seed לדגימה. הגדר 0 כדי להשמיט. רוב המודלים מתייחסים לכך כרמז בלבד. (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |
| `system_prompt` | הוראות בסיס הקובעות את התנהגות המודל. (ברירת מחדל: "") | STRING | לא | N/A |

**הערות:**

- **מודלים זמינים:** אפשרויות המודלים הזמינות נבנות באופן דינמי וכוללות מודלים עם יכולות שונות. הרשימה המלאה של 34 מודלים היא:
  - Anthropic: `anthropic/claude-opus-5`, `anthropic/claude-opus-4.8`, `anthropic/claude-opus-4.7`, `anthropic/claude-fable-5`, `anthropic/claude-sonnet-5`, `anthropic/claude-haiku-4.5`
  - OpenAI: `openai/gpt-5.6-sol-pro`, `openai/gpt-5.6-sol`, `openai/gpt-5.6-terra-pro`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna-pro`, `openai/gpt-5.6-luna`, `openai/gpt-5.5-pro`, `openai/gpt-5.5`
  - Google: `google/gemini-3.5-flash`
  - xAI: `x-ai/grok-4.5`, `x-ai/grok-4.20`, `x-ai/grok-4.3`
  - DeepSeek: `deepseek/deepseek-v4-pro`, `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v3.2`
  - Qwen: `qwen/qwen3.6-max-preview`, `qwen/qwen3.6-plus`, `qwen/qwen3.6-flash`
  - Mistral: `mistralai/mistral-large-2512`, `mistralai/mistral-medium-3-5`
  - Z.AI: `z-ai/glm-4.6`, `z-ai/glm-5`
  - Moonshot: `moonshotai/kimi-k3`, `moonshotai/kimi-k2.6`, `moonshotai/kimi-k2-thinking`
  - Perplexity: `perplexity/sonar-pro`, `perplexity/sonar-reasoning-pro`, `perplexity/sonar-deep-research`

- **מגבלות תמונות ווידאו:** המספר המרבי של תמונות וסרטוני עזר תלוי במודל הנבחר. הצומת מעלה שגיאה אם המספר הכולל של התמונות או הסרטונים שסופקו עולה על המגבלה של המודל. מודלים ללא תמיכה בתמונות או בווידאו אינם מציגים את משבצות העזר המתאימות.

- **התנהגות חשיבה:** כאשר `reasoning_effort` מוגדר לכל ערך שאינו "off", הבקשה מבקשת מהספק לחשוב באופן פנימי מבלי להחזיר את עקבות החשיבה.

- **התנהגות Seed:** לפרמטר `seed` יש התנהגות "control_after_generate", כלומר ניתן להגדיר אותו להשתנות אוטומטית (למשל, אקראי, הגדלה או קבוע) לאחר כל הרצת צומת, בהתאם להגדרות הווידג'ט של המשתמש.

- **הנחיית מערכת:** הפרמטר `system_prompt` הוא אופציונלי ומסומן כפרמטר מתקדם בממשק המשתמש.

- **מקרי שגיאה:** הצומת מעלה שגיאה אם ההנחיה ריקה לאחר הסרת רווחים, אם OpenRouter מחזיר שגיאה, אם המודל הנבחר מסרב להגיב, או אם התגובה אינה מכילה אפשרויות או הודעה. תג מחיר על הצומת מציג הערכת עלות משוערת לכל 1K טוקנים בהתאם למודל הנבחר.
