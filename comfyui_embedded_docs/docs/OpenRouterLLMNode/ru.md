# OpenRouter LLM

Узел OpenRouter LLM отправляет текстовый запрос (и, при необходимости, изображения или видео) в подобранный набор языковых моделей, доступных через сервис OpenRouter, и возвращает сгенерированный текстовый ответ. Он поддерживает модели от Anthropic (Claude), OpenAI (GPT), Google (Gemini), xAI (Grok), DeepSeek, Qwen, Mistral, Z.AI (GLM), Moonshot (Kimi) и Perplexity Sonar, а также показывает специфичные для модели параметры, такие как уровень рассуждений и контекст веб-поиска, когда выбранная модель их поддерживает.

## Входы

Селектор `model` является динамическим: выбор модели открывает специфичные для неё виджеты (уровень рассуждений, контекст веб-поиска, слоты для изображений и видео) в дополнение к общим входам ниже.

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель OpenRouter, используемая для генерации ответа. Выбор модели открывает её специфичные входы (см. разделы моделей ниже). | DYNAMIC_COMBO | Да | 34 подобранных варианта моделей OpenRouter |
| `prompt` | Текстовый ввод для модели. Должен содержать хотя бы один непробельный символ. | STRING | Да | Многострочный текст |
| `seed` | Сид для сэмплирования. Установите 0, чтобы пропустить. Большинство моделей используют его только как подсказку. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет | Многострочный текст |

**Примечание о `seed`:** Этот параметр имеет поведение "control_after_generate", то есть его можно настроить на автоматическое изменение (например, случайное, инкремент или фиксированное) после каждого выполнения узла, в зависимости от настроек виджета пользователя.

**Примечание о `system_prompt`:** Этот параметр необязателен и помечен в пользовательском интерфейсе как дополнительный (advanced).

| Параметр | Описание | Тип данных | Обязательность | Диапазон |

| `images` | Необязательные референсные изображения — отправляются как URL. Расширяемый слот: подключайте `image_1` ... `image_N`, где N зависит от выбранной модели. | IMAGE | Нет | от 0 до N изображений (N = 8, 10 или 20 в зависимости от модели) |

**Примечание о возможностях и ограничениях моделей:**

- Поддержка изображений: до 20 изображений для моделей Anthropic Claude, OpenAI GPT, Google Gemini 3.5 Flash и xAI Grok; до 10 изображений для Qwen 3.6 Plus/Flash и Moonshot Kimi K3/K2.6; до 8 изображений для Mistral Large 2512 и Mistral Medium 3.5. Модели DeepSeek, Qwen 3.6 Max Preview, Z.AI GLM, Moonshot Kimi K2 Thinking и Perplexity Sonar не принимают изображения.
- Поддержка видео: только `google/gemini-3.5-flash`, `qwen/qwen3.6-plus` и `qwen/qwen3.6-flash` принимают видео, максимум 4 видео.
- Узел выдаёт ошибку, если подключено больше изображений или видео, чем поддерживает выбранная модель.
- Когда `reasoning_effort` установлен в "low", "medium" или "high", модель рассуждает внутренне, но не возвращает цепочку рассуждений; "off" полностью отключает рассуждения.
- Виджет `search_context_size` появляется только для моделей Perplexity Sonar. Виджеты `reasoning_effort` и `search_context_size` помечены как дополнительные параметры.
- Узел отображает значок приблизительной цены (долларов США за 1K токенов) на основе выбранной модели.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от выбранной модели OpenRouter. | STRING |

**Примечание об ошибках:** узел выдаёт ошибку, если OpenRouter возвращает ошибку API, пустой ответ (нет вариантов) или отказ от модели.
