# OpenRouter LLM

Узел OpenRouter LLM отправляет текстовый запрос выбранному набору популярных языковых моделей, доступных через сервис OpenRouter, и возвращает сгенерированный текстовый ответ. Он поддерживает модели Anthropic (Claude), OpenAI (GPT), Google (Gemini), xAI (Grok), DeepSeek, Qwen, Mistral, Z.AI (GLM), Moonshot (Kimi) и Perplexity Sonar, а также может опционально включать изображения или видео в качестве эталонных входов в запросе.

## Входы

Когда в селекторе `model` выбрана модель, узел отображает виджеты, специфичные для модели, поверх общих входов — уровень рассуждений, объём веб-поиска и/или слоты эталонных медиа — в зависимости от возможностей выбранной модели.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый ввод для модели. | STRING | Да | N/A |
| `model` | Модель OpenRouter, используемая для генерации ответа. | DYNAMIC_COMBO | Да | Доступно несколько вариантов (см. разделы моделей ниже) |
| `seed` | Сид для сэмплирования. Установите 0, чтобы не отправлять. Большинство моделей рассматривают его только как подсказку. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет | N/A |

**Примечания:**

- **Доступные модели:** Доступные варианты моделей формируются динамически и включают модели с разными возможностями. Полный список из 34 моделей:
  - Anthropic: `anthropic/claude-opus-5`, `anthropic/claude-opus-4.8`, `anthropic/claude-opus-4.7`, `anthropic/claude-fable-5`, `anthropic/claude-sonnet-5`, `anthropic/claude-haiku-4.5`
  - OpenAI: `openai/gpt-5.6-sol-pro`, `openai/gpt-5.6-sol`, `openai/gpt-5.6-terra-pro`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna-pro`, `openai/gpt-5.6-luna`, `openai/gpt-5.5-pro`, `openai/gpt-5.5`
  - Google: `google/gemini-3.5-flash`
  - xAI: `x-ai/grok-4.5`, `x-ai/grok-4.20`, `x-ai/grok-4.3`
  - DeepSeek: `deepseek/deepseek-v4-pro`, `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v3.2`
  - Qwen: `qwen/qwen3.6-max-preview`, `qwen/qwen3.6-plus`, `qwen/qwen3.6-flash`
  - Mistral: `mistralai/mistral-large-2512`, `mistralai/mistral-medium-3-5`
  - Z.AI: `z-ai/glm-4.6`, `z-ai/glm-5`
  - Moonshot: `moonshotai/kimi-k3`, `moonshotai/kimi-k2.6`, `moonshotai/kimi-k2-thinking`
  - Perplexity: `perplexity/sonar-pro`, `perplexity/sonar-reasoning-pro`, `perplexity/sonar-deep-research`

- **Ограничения на изображения и видео:** Максимальное количество эталонных изображений и видео зависит от выбранной модели. Узел выдаёт ошибку, если общее количество предоставленных изображений или видео превышает лимит модели. Модели без поддержки изображений или видео не отображают соответствующие слоты эталонных входов.

- **Поведение reasoning_effort:** Если `reasoning_effort` задан любым значением, кроме "off", запрос требует от провайдера выполнять рассуждения внутренне, не возвращая трассировку этих рассуждений.

- **Поведение seed:** Параметр `seed` имеет поведение "control_after_generate", то есть его можно настроить на автоматическое изменение (например, randomize, increment или fixed) после каждого выполнения узла, в зависимости от настроек виджета пользователя.

- **Системный промпт:** Параметр `system_prompt` является необязательным и помечен как расширенный параметр в пользовательском интерфейсе.

- **Случаи ошибок:** Узел выдаёт ошибку, если запрос пуст после удаления пробелов, если OpenRouter возвращает ошибку, если выбранная модель отказывается отвечать или если ответ не содержит choices или message. Значок стоимости на узле показывает приблизительную оценку затрат на 1K токенов в зависимости от выбранной модели.
