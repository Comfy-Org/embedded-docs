# OpenRouter LLM

عقدة OpenRouter LLM ترسل موجهًا نصيًا إلى مجموعة مختارة من نماذج اللغة الشائعة المتاحة عبر خدمة OpenRouter وتُرجع استجابة النص المُولَّدة. تدعم العقدة نماذج من Anthropic (Claude) وOpenAI (GPT) وGoogle (Gemini) وxAI (Grok) وDeepSeek وQwen وMistral وZ.AI (GLM) وMoonshot (Kimi) وPerplexity Sonar، ويمكنها اختياريًا تضمين الصور أو الفيديو كمدخلات مرجعية في الطلب.

## المدخلات

عند تحديد نموذج في محدد `model`، تعرض العقدة عناصر واجهة خاصة بالنموذج فوق المدخلات العامة — درجة التفكير، وحجم البحث على الويب، و/أو فتحات الوسائط المرجعية — اعتمادًا على قدرات النموذج المحدد.

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | النص المُدخل إلى النموذج. | STRING | نعم | N/A |
| `model` | نموذج OpenRouter المستخدم لتوليد الاستجابة. | DYNAMIC_COMBO | نعم | خيارات متعددة متاحة (انظر أقسام النماذج أدناه) |
| `seed` | بذرة العينة العشوائية. اضبطها على 0 لتجاهلها. تعامل معظم النماذج هذه القيمة كإشارة فقط. (الافتراضي: 0) | INT | نعم | 0 إلى 2147483647 |
| `system_prompt` | تعليمات أساسية تحدد سلوك النموذج. (الافتراضي: "") | STRING | لا | N/A |

**ملاحظات:**

- **النماذج المتاحة:** يتم بناء خيارات النماذج المتاحة ديناميكيًا وتتضمن نماذج بقدرات مختلفة. القائمة الكاملة للنماذج الـ34 هي:
  - Anthropic: `anthropic/claude-opus-5`، `anthropic/claude-opus-4.8`، `anthropic/claude-opus-4.7`، `anthropic/claude-fable-5`، `anthropic/claude-sonnet-5`، `anthropic/claude-haiku-4.5`
  - OpenAI: `openai/gpt-5.6-sol-pro`، `openai/gpt-5.6-sol`، `openai/gpt-5.6-terra-pro`، `openai/gpt-5.6-terra`، `openai/gpt-5.6-luna-pro`، `openai/gpt-5.6-luna`، `openai/gpt-5.5-pro`، `openai/gpt-5.5`
  - Google: `google/gemini-3.5-flash`
  - xAI: `x-ai/grok-4.5`، `x-ai/grok-4.20`، `x-ai/grok-4.3`
  - DeepSeek: `deepseek/deepseek-v4-pro`، `deepseek/deepseek-v4-flash`، `deepseek/deepseek-v3.2`
  - Qwen: `qwen/qwen3.6-max-preview`، `qwen/qwen3.6-plus`، `qwen/qwen3.6-flash`
  - Mistral: `mistralai/mistral-large-2512`، `mistralai/mistral-medium-3-5`
  - Z.AI: `z-ai/glm-4.6`، `z-ai/glm-5`
  - Moonshot: `moonshotai/kimi-k3`، `moonshotai/kimi-k2.6`، `moonshotai/kimi-k2-thinking`
  - Perplexity: `perplexity/sonar-pro`، `perplexity/sonar-reasoning-pro`، `perplexity/sonar-deep-research`

- **قيود الصور والفيديو:** يعتمد الحد الأقصى لعدد الصور والفيديو المرجعية على النموذج المحدد. ترفع العقدة خطأً إذا تجاوز العدد الإجمالي للصور أو الفيديو المقدمة حد النموذج. النماذج التي لا تدعم الصور أو الفيديو لا تُظهر فتحات المرجع المقابلة.

- **سلوك التفكير:** عندما تكون قيمة `reasoning_effort` مختلفة عن "off"، يطلب الطلب من المزوّد التفكير داخليًا دون إرجاع أثر التفكير.

- **سلوك البذرة:** تتميز معلمة `seed` بسلوك "control_after_generate"، مما يعني أنه يمكن ضبطها للتغيير تلقائيًا (مثل التبديل العشوائي، أو الزيادة، أو الثبات) بعد كل تنفيذ للعقدة، اعتمادًا على إعدادات عنصر التحكم لدى المستخدم.

- **موجه النظام:** معلمة `system_prompt` اختيارية ويتم وضع علامة عليها كمعلمة متقدمة في واجهة المستخدم.

- **حالات الخطأ:** ترفع العقدة خطأً إذا كان الموجه فارغًا بعد إزالة المسافات البيضاء، أو إذا أعاد OpenRouter خطأً، أو إذا رفض النموذج المحدد الاستجابة، أو إذا لم تحتوِ الاستجابة على أي خيارات أو رسالة. تُظهر شارة السعر على العقدة تقديرًا تقريبيًا للتكلفة لكل 1 ألف رمز بناءً على النموذج المحدد.
