# Разрез латента

Узел LatentCut извлекает определённый участок из латентных образцов вдоль выбранного измерения. Он вырезает часть латентного представления, задавая измерение (`x`, `y` или `t`), начальную позицию и объём извлечения. Узел поддерживает как положительную, так и отрицательную индексацию и автоматически корректирует объём извлечения, чтобы он оставался в пределах доступных границ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `сэмплы` | Входные латентные образцы, из которых выполняется извлечение | LATENT | Да | - |
| `измерение` | Измерение, по которому обрезаются латентные образцы. `"x"` обрезает по последней оси (обычно ширина), `"y"` — по предпоследней оси (обычно высота), а `"t"` — по третьей с конца оси (обычно кадры в видеолатентах) | COMBO | Да | "x"<br>"y"<br>"t" |
| `индекс` | Начальная позиция для обрезки (по умолчанию: 0). Положительные значения отсчитываются с начала, отрицательные — с конца. Узел ограничивает индекс допустимым диапазоном латентных образцов | INT | Да | от -16384 до 16384 |
| `количество` | Количество элементов для извлечения вдоль указанного измерения (по умолчанию: 1). Должно быть не менее 1. Узел автоматически уменьшает это значение, если оно выходило бы за пределы доступных данных после начального индекса | INT | Да | от 1 до 16384 |

Примечание: значения `index` и `amount` корректируются, чтобы соответствовать фактическому размеру латента вдоль выбранного измерения. Если `index` больше размера измерения, он ограничивается последней допустимой позицией. Если `index` отрицательный, его абсолютное значение ограничивается размером измерения, а `amount` ограничивается так, чтобы не выходить за конец данных.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Извлечённая часть латентных образцов | LATENT |
