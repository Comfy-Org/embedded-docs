# Разрез латента

Узел LatentCut извлекает определённый фрагмент из латентных сэмплов вдоль выбранного измерения. Он позволяет вырезать часть латентного представления, указав измерение (x, y или t), начальную позицию и количество элементов для извлечения. Узел поддерживает как положительную, так и отрицательную индексацию и автоматически корректирует количество извлекаемых элементов, чтобы оставаться в допустимых границах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Входные латентные сэмплы, из которых выполняется извлечение | LATENT | Да | - |
| `dim` | Измерение, вдоль которого выполняется разрезание латентных сэмплов | COMBO | Да | "x"<br>"y"<br>"t" |
| `index` | Начальная позиция для разреза (по умолчанию: 0). Положительные значения отсчитываются от начала, отрицательные — от конца. Узел автоматически ограничивает индекс, чтобы он оставался в допустимом диапазоне латентных сэмплов | INT | Да | от -16384 до 16384 |
| `amount` | Количество элементов для извлечения вдоль указанного измерения (по умолчанию: 1). Узел автоматически уменьшает это значение, если оно превышает доступные данные после начального индекса | INT | Да | от 1 до 16384 |

Примечание: `x` разрезает по последнему измерению тензора латентного представления, `y` — по предпоследнему, а `t` — по третьему с конца. Когда `index` положителен, он ограничивается последней допустимой позицией выбранного измерения; когда отрицателен — ограничивается так, чтобы не указывать на позицию раньше начала данных. Значение `amount` уменьшается всякий раз, когда запрошенный разрез выходит за пределы доступных данных.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Извлечённая часть латентных сэмплов | LATENT |
