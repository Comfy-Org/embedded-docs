# Разрез латента

Узел LatentCut извлекает определённый фрагмент из латентных сэмплов вдоль выбранной размерности. Он позволяет вырезать часть латентного представления, указав размерность (x, y или t), начальную позицию и количество извлекаемых элементов. Узел поддерживает как положительную, так и отрицательную индексацию и автоматически корректирует объём извлечения, чтобы он оставался в пределах доступных границ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `сэмплы` | Входные латентные сэмплы, из которых извлекается фрагмент | LATENT | Да | - |
| `измерение` | Размерность, вдоль которой выполняется вырезка латентных сэмплов. «x» — вырезка вдоль последней оси (обычно ширина), «y» — вдоль предпоследней оси (обычно высота), «t» — вдоль третьей с конца оси (обычно кадры в видеолатентных сэмплах) | COMBO | Да | "x"<br>"y"<br>"t" |
| `индекс` | Начальная позиция для вырезки (по умолчанию: 0). Положительные значения отсчитываются от начала, отрицательные — от конца. Узел автоматически ограничивает индекс допустимым диапазоном латентных сэмплов | INT | Да | -16384 до 16384 |
| `количество` | Количество элементов для извлечения вдоль указанной размерности (по умолчанию: 1). Узел автоматически уменьшает это значение, если оно превышает объём доступных данных после начального индекса | INT | Да | 1 до 16384 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Извлечённая часть латентных сэмплов | LATENT |
