# 潜在空間カット

LatentCut ノードは、選択した次元に沿って潜在サンプルから特定のセクションを抽出します。次元（x、y、または t）、開始位置、抽出量を指定することで、潜在表現の一部を切り出すことができます。このノードは正と負の両方のインデックスを処理し、抽出量を利用可能な範囲内に収まるように自動的に調整します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `samples` | 抽出元となる入力潜在サンプルです。 | LATENT | はい | - |
| `dim` | 潜在サンプルをカットする次元です。 | COMBO | はい | "x"<br>"y"<br>"t" |
| `index` | カットの開始位置です（デフォルト: 0）。正の値は先頭から数え、負の値は末尾から数えます。ノードは、インデックスが潜在サンプルの有効範囲内に収まるよう自動的にクランプします。 | INT | はい | -16384 to 16384 |
| `amount` | 指定した次元に沿って抽出する要素数です（デフォルト: 1）。開始インデックス以降の利用可能なデータを超える場合、ノードはこの値を自動的に減らします。 | INT | はい | 1 to 16384 |

注意：`x` は潜在テンソルの最後の次元に沿ってカットし、`y` は最後から2番目の次元に沿って、`t` は最後から3番目の次元に沿ってカットします。`index` が正の場合は、選択した次元の最後の有効位置にクランプされます。負の場合は、データの先頭より前を指さないようにクランプされます。`amount` は、要求されたカットが利用可能なデータを超える場合に減らされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 抽出された潜在サンプルの一部です。 | LATENT |
