# 潛空間切割

此節點從潛在樣本中沿選定維度提取特定區段。透過指定維度（x、y 或 t）、起始位置和提取數量，可以裁剪出潛在表示的一部分。節點同時處理正負索引，並自動調整提取數量以保持在可用範圍內。
