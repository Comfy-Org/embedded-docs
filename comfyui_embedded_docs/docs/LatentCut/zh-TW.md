# 潛空間切割

`LatentCut` 節點會沿著選定的維度從潛在樣本中擷取特定區段。它透過指定維度（`x`、`y` 或 `t`）、起始位置以及要擷取的數量，切出潛在表徵的一部分。此節點同時支援正向與負向索引，並會自動調整擷取數量，使其維持在可用範圍內。

| `維度` | 要沿著哪個維度切割潛在樣本。"x" 會沿著最後一個軸（通常是寬度）切割，"y" 沿著倒數第二個軸（通常是高度），而 "t" 沿著倒數第三個軸（通常是影片潛在樣本中的影格） | COMBO | 是 | "x"<br>"y"<br>"t" |
