# 潛空間切割

LatentCut 節點會沿著所選維度從潛在樣本中提取特定區段。您可以透過指定維度（x、y 或 t）、起始位置及要提取的數量，來裁切潛在表示的一部分。此節點同時支援正向與負向索引，並自動調整提取數量，以保持在可用的邊界範圍內。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `samples` | 要從中提取的輸入潛在樣本 | LATENT | 是 | - |
| `dim` | 沿其裁切潛在樣本的維度 | COMBO | 是 | "x"<br>"y"<br>"t" |
| `index` | 裁切的起始位置（預設：0）。正值從開頭計算，負值從結尾計算。節點會自動將索引限制在潛在樣本的有效範圍內 | INT | 是 | -16384 to 16384 |
| `amount` | 沿指定維度要提取的元素數量（預設：1）。如果此值會超出起始索引之後的可用資料，節點會自動減少此值 | INT | 是 | 1 to 16384 |

注意：`x` 沿潛在張量的最後一個維度裁切，`y` 沿倒數第二個維度，`t` 沿倒數第三個維度。當 `index` 為正值時，會被限制在所選維度的最後一個有效位置；為負值時，會被限制為不指向資料開頭之前的位置。每當要求的裁切範圍會超出可用資料時，`amount` 會被減少。

| --- | --- | --- |
