# LatentCut

LatentCut 노드는 선택한 차원을 따라 잠재 샘플에서 특정 구간을 추출합니다. 차원(x, y 또는 t), 시작 위치 및 추출할 양을 지정하여 잠재 표현의 일부를 잘라낼 수 있습니다. 이 노드는 양수 및 음수 인덱싱을 모두 처리하며 추출 양이 사용 가능한 범위 내에 유지되도록 자동으로 조정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `samples` | 추출할 입력 잠재 샘플 | LATENT | 예 | - |
| `dim` | 잠재 샘플을 자를 차원 | COMBO | 예 | "x"<br>"y"<br>"t" |
| `index` | 자르기 시작 위치(기본값: 0). 양수 값은 시작부터, 음수 값은 끝에서부터 계산합니다. 노드는 인덱스가 잠재 샘플의 유효한 범위 내에 머물도록 자동으로 제한합니다 | INT | 예 | -16384 to 16384 |
| `amount` | 지정된 차원을 따라 추출할 요소 수(기본값: 1). 시작 인덱스 이후의 사용 가능한 데이터를 초과하면 노드가 이 값을 자동으로 줄입니다 | INT | 예 | 1 to 16384 |

참고: `x`는 잠재 텐서의 마지막 차원을 따라 자르고, `y`는 마지막에서 두 번째 차원, `t`는 마지막에서 세 번째 차원을 따라 자릅니다. `index`가 양수이면 선택한 차원의 마지막 유효 위치로 제한되며, 음수이면 데이터의 시작 부분보다 앞을 가리키지 않도록 제한됩니다. 요청한 자르기가 사용 가능한 데이터를 초과하면 `amount`가 줄어듭니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 잠재 샘플에서 추출된 부분 | LATENT |
