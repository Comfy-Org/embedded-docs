# 潜在空间切割

LatentCut 节点沿选定维度从潜空间样本中提取特定部分。通过指定维度（`x`、`y` 或 `t`）、起始位置和提取数量，您可以裁剪出潜空间表示的一部分。该节点支持正数和负数索引，并会自动调整提取数量，以确保不超出可用边界。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `samples` | 要从中提取的输入潜空间样本 | LATENT | 是 | - |
| `dim` | 裁剪潜空间样本所沿的维度 | COMBO | 是 | "x"<br>"y"<br>"t" |
| `index` | 裁剪的起始位置（默认值：0）。正值从开头开始计数，负值从末尾开始计数。节点会自动将索引限制在潜空间样本的有效范围内 | INT | 是 | -16384 到 16384 |
| `amount` | 沿指定维度要提取的元素数量（默认值：1）。如果该值会超出起始索引之后可用数据范围，节点会自动减少此值 | INT | 是 | 1 到 16384 |

注意：`x` 沿潜空间张量的最后一个维度裁剪，`y` 沿倒数第二个维度裁剪，`t` 沿倒数第三个维度裁剪。当 `index` 为正值时，会被限制在所选维度的最后一个有效位置；当为负值时，会被限制为不会指向数据开头之前的位置。如果请求的裁剪范围会超出可用数据范围，`amount` 将相应减少。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 从潜空间样本中提取出的部分 | LATENT |
