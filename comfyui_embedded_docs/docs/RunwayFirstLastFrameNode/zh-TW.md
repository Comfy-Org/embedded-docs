# Runway 首尾幀轉影片

此 Runway 首尾幀轉影片節點使用起始幀、結束幀和文字提示生成影片。它會利用 Runway 的 gen3a_turbo 模型，在提供的兩個關鍵幀之間建立平滑過渡。當結束幀與起始幀完全不同，需要複雜轉場時，此節點特別有用。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於生成的文字提示（預設：空字串） | STRING | 是 | N/A |
| `起始幀` | 用於影片的起始幀 | IMAGE | 是 | N/A |
| `結束幀` | 用於影片的結束幀。僅適用於 gen3a_turbo。 | IMAGE | 是 | N/A |
| `持續時間` | 所生成影片的時長（秒）。較長的 10 秒時長讓生成過程有更多時間在起始幀與結束幀之間平滑過渡（預設："5"）。 | COMBO | 是 | `"5"`<br>`"10"` |
| `比例` | 所生成影片的寬高比（預設："768:1280"） | COMBO | 是 | `"768:1280"`<br>`"1280:768"` |
| `種子值` | 生成用的隨機種子。設為 0 以使用隨機種子（預設：0）。 | INT | 否 | 0 至 4294967295 |

**參數限制：**

- `prompt` 必須包含至少 1 個字元
- `start_frame` 和 `end_frame` 的最大尺寸皆必須為 7999x7999 像素
- `start_frame` 和 `end_frame` 的寬高比必須介於 0.5 與 2.0 之間
- 僅在使用 gen3a_turbo 模型時支援 `end_frame` 參數

**注意事項：**

- 生成費用是根據所選時長計算：每秒 USD 0.0715（5 秒為 USD 0.3575，10 秒為 USD 0.715）
- 此節點已標記為已棄用
