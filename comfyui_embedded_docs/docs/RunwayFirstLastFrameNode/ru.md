# Runway: Первый-Последний кадр в видео

Узел Runway First-Last-Frame to Video генерирует видео, используя начальный кадр, конечный кадр и текстовый запрос. Он создаёт плавный переход между двумя заданными ключевыми кадрами с помощью модели gen3a_turbo от Runway. Узел особенно полезен для сложных переходов, когда конечный кадр полностью отличается от начального.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Текстовый запрос для генерации (по умолчанию: пустая строка) | STRING | Да | Н/Д |
| `начальный_кадр` | Начальный кадр, используемый для видео | IMAGE | Да | Н/Д |
| `конечный_кадр` | Конечный кадр, используемый для видео. Поддерживается только для gen3a_turbo. | IMAGE | Да | Н/Д |
| `продолжительность` | Продолжительность создаваемого видео в секундах. Большая длительность (10 с) даёт генерации больше времени для плавного перехода между начальным и конечным кадрами (по умолчанию: "5"). | COMBO | Да | `"5"`<br>`"10"` |
| `соотношение` | Соотношение сторон для создаваемого видео (по умолчанию: "768:1280") | COMBO | Да | `"768:1280"`<br>`"1280:768"` |
| `сид` | Случайное зерно (seed) для генерации. Установите 0 для случайного зерна (по умолчанию: 0). | INT | Нет | 0–4294967295 |

**Ограничения параметров:**

- Параметр `prompt` должен содержать не менее 1 символа
- И `start_frame`, и `end_frame` должны иметь максимальные размеры 7999×7999 пикселей
- И `start_frame`, и `end_frame` должны иметь соотношение сторон от 0,5 до 2,0
- Параметр `end_frame` поддерживается только при использовании модели gen3a_turbo

**Примечания:**

- Стоимость генерации зависит от выбранной длительности: 0,0715 USD за секунду (0,3575 USD за 5 секунд, 0,715 USD за 10 секунд)
- Этот узел помечен как устаревший

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео, переход между начальным и конечным кадрами | VIDEO |
