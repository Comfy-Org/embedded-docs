# Runway: Первый-Последний кадр в видео

Узел Runway First-Last-Frame to Video генерирует видео, загружая первый и последний ключевые кадры вместе с текстовым запросом. Он создает плавные переходы между указанными начальным и конечным кадрами с помощью модели Runway Gen-3. Это особенно полезно для сложных переходов, когда конечный кадр значительно отличается от начального.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации (по умолчанию: пустая строка) | STRING | Да | N/A |
| `start_frame` | Начальный кадр для видео | IMAGE | Да | N/A |
| `end_frame` | Конечный кадр для видео. Поддерживается только для gen3a_turbo. | IMAGE | Да | N/A |
| `duration` | Длительность видео в секундах (по умолчанию: "5") | COMBO | Да | `"5"`<br>`"10"` |
| `ratio` | Соотношение сторон генерируемого видео (по умолчанию: "768:1280") | COMBO | Да | `"768:1280"`<br>`"1280:768"` |
| `seed` | Случайное зерно для генерации. Установите 0 для случайного зерна (по умолчанию: 0). | INT | Нет | 0 to 4294967295 |

**Ограничения параметров:**

- Параметр `prompt` должен содержать как минимум 1 символ
- Оба параметра `start_frame` и `end_frame` должны иметь максимальные размеры 7999x7999 пикселей
- Оба параметра `start_frame` и `end_frame` должны иметь соотношение сторон от 0.5 до 2.0
- Параметр `end_frame` поддерживается только при использовании модели gen3a_turbo

**Примечание:** Этот узел помечен как устаревший. Перед использованием ознакомьтесь с рекомендациями Runway по созданию видео с ключевыми кадрами на Gen-3: https://help.runwayml.com/hc/en-us/articles/34170748696595-Creating-with-Keyframes-on-Gen-3

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео с переходом между начальным и конечным кадрами | VIDEO |
