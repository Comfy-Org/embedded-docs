# Runway تبدیل اولین و آخرین فریم به ویدیو

گره Runway First-Last-Frame to Video با بارگذاری فریم‌های کلیدی اول و آخر به همراه یک متن فرمان، ویدیو تولید می‌کند. این گره با استفاده از مدل Gen-3 شرکت Runway، انتقال‌های نرمی بین فریم شروع و پایان ارائه‌شده ایجاد می‌کند. این قابلیت به‌ویژه برای انتقال‌های پیچیده‌ای که در آن فریم پایان تفاوت چشمگیری با فریم شروع دارد، مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن فرمان برای تولید (پیش‌فرض: رشته خالی) | STRING | بله | N/A |
| `start_frame` | فریم شروع برای استفاده در ویدیو | IMAGE | بله | N/A |
| `end_frame` | فریم پایان برای استفاده در ویدیو. فقط برای gen3a_turbo پشتیبانی می‌شود. | IMAGE | بله | N/A |
| `duration` | مدت زمان ویدیو به ثانیه (پیش‌فرض: "5") | COMBO | بله | `"5"`<br>`"10"` |
| `ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: "768:1280") | COMBO | بله | `"768:1280"`<br>`"1280:768"` |
| `seed` | مقدار seed تصادفی برای تولید. برای seed تصادفی روی 0 تنظیم کنید (پیش‌فرض: 0). | INT | خیر | 0 تا 4294967295 |

**محدودیت‌های پارامتر:**

- متن فرمان (`prompt`) باید حداقل دارای ۱ کاراکتر باشد
- هر دو `start_frame` و `end_frame` باید حداکثر ابعاد 7999x7999 پیکسل را داشته باشند
- هر دو `start_frame` و `end_frame` باید نسبت ابعاد بین 0.5 تا 2.0 داشته باشند
- پارامتر `end_frame` فقط هنگام استفاده از مدل gen3a_turbo پشتیبانی می‌شود

**نکته:** این گره به‌عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است. پیش از استفاده، راهنمای بهترین روش‌های Runway برای ایجاد با فریم‌های کلیدی در Gen-3 را مرور کنید: https://help.runwayml.com/hc/en-us/articles/34170748696595-Creating-with-Keyframes-on-Gen-3
