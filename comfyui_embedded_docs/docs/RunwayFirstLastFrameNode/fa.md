# Runway تبدیل اولین و آخرین فریم به ویدیو

گره Runway First-Last-Frame to Video با استفاده از یک فریم شروع، یک فریم پایان و یک متن راهنما (پرامپت)، ویدیو تولید می‌کند. این گره با استفاده از مدل gen3a_turbo شرکت Runway، انتقالی نرم بین دو فریم کلیدی ارائه‌شده ایجاد می‌کند. این ویژگی به‌ویژه برای انتقال‌های پیچیده‌ای مفید است که فریم پایان کاملاً با فریم شروع متفاوت است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | متن راهنما (پرامپت) برای تولید (پیش‌فرض: رشته خالی) | STRING | بله | ندارد |
| `فریم شروع` | فریم شروع برای استفاده در ویدیو | IMAGE | بله | ندارد |
| `فریم پایان` | فریم پایان برای استفاده در ویدیو. فقط برای gen3a_turbo پشتیبانی می‌شود. | IMAGE | بله | ندارد |
| `مدت زمان` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه. مدت‌زمان طولانی‌تر 10 ثانیه‌ای زمان بیشتری برای انتقال نرم بین فریم شروع و پایان به تولید می‌دهد (پیش‌فرض: "5"). | COMBO | بله | `"5"`<br>`"10"` |
| `نسبت تصویر` | نسبت تصویر برای ویدیوی تولیدشده (پیش‌فرض: "768:1280") | COMBO | بله | `"768:1280"`<br>`"1280:768"` |
| `seed` | دانه تصادفی برای تولید. برای دانه تصادفی، مقدار 0 را قرار دهید (پیش‌فرض: 0). | INT | خیر | 0 تا 4294967295 |

**محدودیت‌های پارامتر:**

- `prompt` باید حداقل 1 نویسه داشته باشد.
- هر دو `start_frame` و `end_frame` باید حداکثر ابعاد 7999x7999 پیکسل داشته باشند.
- هر دو `start_frame` و `end_frame` باید نسبت تصویری بین 0.5 و 2.0 داشته باشند.
- پارامتر `end_frame` فقط هنگام استفاده از مدل gen3a_turbo پشتیبانی می‌شود.

**نکات:**

- هزینه تولید بر اساس مدت زمان انتخاب‌شده محاسبه می‌شود: 0.0715 دلار بر ثانیه (0.3575 دلار برای 5 ثانیه، 0.715 دلار برای 10 ثانیه).
- این گره به عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است.
