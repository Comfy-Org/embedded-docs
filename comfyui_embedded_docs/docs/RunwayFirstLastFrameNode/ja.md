# Runway 最初-最後フレームから動画生成

Runway First-Last-Frame to Video ノードは、テキストプロンプトとともに最初と最後のキーフレームをアップロードしてビデオを生成します。Runway の Gen-3 モデルを使用して、指定された開始フレームと終了フレームの間の滑らかな遷移を作成します。これは、終了フレームが開始フレームと大きく異なる複雑な遷移に特に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成用のテキストプロンプト（デフォルト: 空文字列） | STRING | はい | N/A |
| `start_frame` | ビデオに使用する開始フレーム | IMAGE | はい | N/A |
| `end_frame` | ビデオに使用する終了フレーム。gen3a_turbo でのみサポートされています。 | IMAGE | はい | N/A |
| `duration` | ビデオの長さ（秒）（デフォルト: "5"） | COMBO | はい | `"5"`<br>`"10"` |
| `ratio` | 生成されるビデオのアスペクト比（デフォルト: "768:1280"） | COMBO | はい | `"768:1280"`<br>`"1280:768"` |
| `seed` | 生成用のランダムシード。ランダムシードにする場合は 0 に設定します（デフォルト: 0）。 | INT | いいえ | 0 から 4294967295 |

**パラメータの制約:**

- `prompt` は少なくとも 1 文字以上含む必要があります
- `start_frame` と `end_frame` の両方の最大寸法は 7999x7999 ピクセルである必要があります
- `start_frame` と `end_frame` の両方のアスペクト比は 0.5 から 2.0 の間である必要があります
- `end_frame` パラメータは、gen3a_turbo モデルを使用する場合にのみサポートされます

**注:** このノードは非推奨としてマークされています。使用前に、Gen-3 でキーフレームを使った作成に関する Runway のベストプラクティスを確認してください: https://help.runwayml.com/hc/en-us/articles/34170748696595-Creating-with-Keyframes-on-Gen-3

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 開始フレームと終了フレームの間を遷移する生成されたビデオ | VIDEO |
