# LatentAdd

Il nodo LatentAdd è progettato per l'addizione di due rappresentazioni latenti. Facilita la combinazione delle caratteristiche o proprietà codificate in queste rappresentazioni eseguendo una somma elemento per elemento.

## Input

| Parametro | Descrizione | Tipo di dati |
| --- | --- | --- |
| `samples1` | Il primo insieme di campioni latenti da sommare. Rappresenta uno degli input le cui caratteristiche devono essere combinate con un altro insieme di campioni latenti. | `LATENT` |
| `samples2` | Il secondo insieme di campioni latenti da sommare. Costituisce l'altro input le cui caratteristiche vengono combinate con il primo insieme di campioni latenti tramite una somma elemento per elemento. | `LATENT` |

## Output

| Parametro | Descrizione | Tipo di dati |
| --- | --- | --- |
| `latent` | Il risultato della somma elemento per elemento di due campioni latenti, che rappresenta un nuovo insieme di campioni latenti che combina le caratteristiche di entrambi gli input. | `LATENT` |
