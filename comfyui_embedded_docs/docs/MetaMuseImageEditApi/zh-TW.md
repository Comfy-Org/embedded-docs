# Meta Muse 圖片編輯

使用文字提示和 Meta 的 Muse Image 模型編輯或組合最多 10 張參考圖片。在提示中描述想要的編輯，並在需要時以 `@Image1`、`@Image2` 等方式指涉參考圖片。此節點會上傳參考圖片、呼叫 Meta Muse Image API，並將編輯後的結果以圖片形式回傳。

## 輸入

此節點由 `model` 選擇器控制。下方描述的模型特定輸入會在選取模型時出現，而您連接的參考圖片可以視需要增加或減少。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的模型。 | DYNAMIC_COMBO | 是 | "muse-image-1.0" |
