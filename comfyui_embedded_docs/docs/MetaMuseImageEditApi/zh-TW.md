# MetaMuseImageEditApi

使用文字提示詞與 Meta 的 Muse Image 模型，編輯或結合最多 10 張參考影像。在提示詞中描述所需的編輯，並在需要時以 `@Image1`、`@Image2` 等方式引用參考影像。此節點會上傳參考影像、呼叫 Meta Muse Image API，並將編輯結果以影像形式回傳。

## 輸入

此節點由 `model` 選擇器控制。當選取模型時，會出現下方所述該模型專屬的輸入；而您連接的參考影像可依需求增加或縮減。

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的模型。 | DYNAMIC_COMBO | 是 | "muse-image-1.0" |
