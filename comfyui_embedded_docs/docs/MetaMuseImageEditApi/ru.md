# Meta Muse Image: Редактирование

Редактирует или объединяет до 10 эталонных изображений с помощью текстовой подсказки и модели Muse Image от Meta. Опишите желаемое изменение в подсказке и, при необходимости, ссылайтесь на эталонные изображения как `@Image1`, `@Image2` и т. д. Узел загружает эталонные изображения, вызывает API Meta Muse Image и возвращает отредактированный результат в виде изображения.

## Входы

Узел управляется селектором `model`. Описанные ниже специфичные для модели входы появляются при выборе модели, а количество подключаемых эталонных изображений можно увеличивать или уменьшать по мере необходимости.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. | DYNAMIC_COMBO | Да | "muse-image-1.0" |

### Входы muse-image-1.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает ссылки на входные изображения в стиле `@Image1`. По умолчанию: пустая строка. Подсказка должна содержать хотя бы один символ. | STRING | Да | Любой текст длиной не менее 1 символа |
| `aspect_ratio` | Соотношение сторон выходного изображения. Изображения рендерятся с разрешением около 2,5 мегапикселя (1:1 — 1600x1600, 16:9 — 2048x1152); "auto" сохраняет соотношение сторон входного изображения. | COMBO | Да | "auto"<br>"1:1"<br>"3:2"<br>"2:3"<br>"4:3"<br>"3:4"<br>"5:4"<br>"4:5"<br>"16:9"<br>"9:16"<br>"21:9"<br>"9:21"<br>"2:1"<br>"1:2" |
| `reasoning_strength` | Насколько глубоко модель размышляет, планирует и самостоятельно уточняет результат перед рендерингом. | COMBO | Да | "high"<br>"low" |
| `enable_web_search` | Позволяет модели искать в интернете факты и актуальную информацию во время планирования изображения. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `enable_image_search` | Позволяет модели искать эталонные изображения во время планирования изображения. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `enable_shell` | Позволяет модели выполнять код во время планирования для точных макетов, графиков и диаграмм; если выключено, количественные значения и выравнивание аппроксимируются. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `seed` | Сид для определения, следует ли перезапускать узел; в API нет сида, поэтому фактические результаты недетерминированы независимо от этого значения. По умолчанию: 42. | INT | Да | 0–2147483647 (шаг 1) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 10 эталонных изображений (`image_1`–`image_10`) для редактирования или объединения. Ссылайтесь на них в подсказке как `@Image1`, `@Image2`, ..., с нумерацией в порядке входов; пакетный вход учитывается один раз на каждое изображение. | IMAGE | Да | от 1 до 10 эталонных изображений |

Примечание: подсказка не может быть пустой, и каждая ссылка `@ImageN` в ней должна соответствовать одному из подключённых изображений в порядке входов (например, `@Image1` — это первое подключённое эталонное изображение). Если подсказка ссылается на номер изображения, которое не подключено, или если подключено более 10 эталонных изображений, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное или объединённое изображение, возвращённое моделью Muse Image. Если API возвращает несколько изображений, они возвращаются пакетом. | IMAGE |
