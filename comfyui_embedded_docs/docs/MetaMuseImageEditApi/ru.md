# MetaMuseImageEditApi

Редактирует или объединяет до 10 эталонных изображений с помощью текстового запроса и модели Meta Muse Image. Опишите желаемое редактирование в запросе и, при необходимости, ссылайтесь на эталонные изображения как `@Image1`, `@Image2` и т. д. Узел загружает эталонные изображения, вызывает API Meta Muse Image и возвращает результат редактирования в виде изображения.

## Входы

Узел управляется селектором `model`. Описанные ниже входы, специфичные для модели, появляются при выборе модели, а подключаемые эталонные изображения можно добавлять или сокращать по мере необходимости.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования. | DYNAMIC_COMBO | Да | "muse-image-1.0" |

### Входы muse-image-1.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает ссылки на входные изображения в формате `@Image1`. По умолчанию: пустая строка. Запрос должен содержать не менее одного символа. | STRING | Да | Любой текст длиной не менее 1 символа |
| `aspect_ratio` | Соотношение сторон выходного изображения. Изображения рендерятся с разрешением около 2,5 мегапикселя (1:1 — 1600x1600, 16:9 — 2048x1152); значение "auto" сохраняет соотношение сторон входного изображения. | COMBO | Да | "auto"<br>"1:1"<br>"3:2"<br>"2:3"<br>"4:3"<br>"3:4"<br>"5:4"<br>"4:5"<br>"16:9"<br>"9:16"<br>"21:9"<br>"9:21"<br>"2:1"<br>"1:2" |
| `reasoning_strength` | Насколько интенсивно модель обдумывает, планирует и самостоятельно уточняет результат перед рендерингом. | COMBO | Да | "high"<br>"low" |
| `enable_web_search` | Позволяет модели искать в интернете факты и актуальную информацию при планировании изображения. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `enable_image_search` | Позволяет модели искать эталонные изображения при планировании изображения. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `enable_shell` | Позволяет модели запускать код при планировании для точных макетов, диаграмм и графиков; когда выключено, количества и выравнивание оцениваются приближенно. По умолчанию: true. | BOOLEAN | Да | true или false (по умолчанию: true) |
| `seed` | Сид, определяющий, должен ли узел запускаться повторно; у API нет сида, поэтому фактические результаты недетерминированы независимо от этого значения. По умолчанию: 42. | INT | Да | от 0 до 2147483647 (шаг 1) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 10 эталонных изображений (`image_1` – `image_10`) для редактирования или объединения. Ссылайтесь на них в запросе как `@Image1`, `@Image2`, ..., нумерованных в порядке подключения; при пакетной подаче каждое изображение из пакета учитывается как отдельное. | IMAGE | Да | от 1 до 10 эталонных изображений |

Примечание: запрос не может быть пустым, и каждая содержащаяся в нём ссылка `@ImageN` должна соответствовать одному из подключенных изображений в порядке их подключения (например, `@Image1` — это первое подключенное эталонное изображение). Если в запросе указан номер изображения, которое не подключено, или подключено более 10 эталонных изображений, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное или объединённое изображение, возвращённое моделью Muse Image. Если API возвращает несколько изображений, они возвращаются пакетом. | IMAGE |
