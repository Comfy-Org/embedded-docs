# עריכת תמונה Beeble SwitchX

עריכת תמונה בודדת עם Beeble SwitchX. צומת זה יכול להחליף כל דבר בסצנה (רקע, תאורה, תלבושת) תוך שמירה על הפיקסלים של הסובייקט המקורי. ספק תמונת עזר ו/או הנחיית טקסט כדי לתאר את המראה החדש. הרזולוציה המקסימלית היא בקירוב 2.77 מגה-פיקסלים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת המקור לעריכה. | IMAGE | כן | - |
| `prompt` | תיאור טקסטואלי של המראה החדש הרצוי (למשל, "אביר בשריון נוצץ"). | STRING | כן | - |
| `alpha_mode` | כיצד לטפל במסכת האלפא. "select" משתמש בפריים מפתח כדי לבחור את הסובייקט, "fill" מחליף את כל התמונה ללא מסכה נפרדת, "custom" משתמש במסכה שסופקה על ידי המשתמש. | COMBO | כן | `"select"`<br>`"fill"`<br>`"custom"` |
| `max_resolution` | הרזולוציה המקסימלית של תמונת הפלט. רזולוציה גבוהה יותר דורשת יותר קרדיטים. | COMBO | כן | `"1080p"`<br>`"720p"` |
| `seed` | ערך `seed` לשחזוריות. | INT | כן | - |
| `reference_image` | תמונת עזר אופציונלית להנחות את הסגנון או המראה של רכיבי הסצנה החדשים. | IMAGE | לא | - |

**הערה לגבי `alpha_mode`:** כאשר `alpha_mode` מוגדר ל-`"select"`, עליך לספק גם `alpha_keyframe` (תמונת פריים מפתח המשמשת לבחירת הסובייקט). כאשר הוא מוגדר ל-`"custom"`, עליך לספק `alpha_mask` (מסכה שיצר המשתמש). כאשר הוא מוגדר ל-`"fill"`, אין צורך בקלט אלפא.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `image` | התמונה הערוכה עם רכיבי הסצנה המוחלפים. | IMAGE |
| `alpha` | מסכת האלפא המשמשת את Beeble. ריקה במצב `"fill"`, שאין לו מסכה נפרדת. | MASK |
