# تكبير الصور Magnific (دقيق V2)

تقوم عقدة Magnific Image Upscale (Precise V2) بتكبير الصور بدقة عالية مع تحكم دقيق في الحدة والحبيبية وتعزيز التفاصيل. تعالج العقدة الصور عبر واجهة برمجة تطبيقات خارجية، وتدعم دقة إخراج قصوى تصل إلى 10060×10060 بكسل. توفر العقدة أنماط معالجة مختلفة، ويمكنها تلقائيًا تقليل دقة الإدخال إذا تجاوز الإخراج المطلوب الحد الأقصى المسموح به.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | صورة الإدخال التي سيتم تكبيرها. مطلوب صورة واحدة بالضبط. الأبعاد الدنيا هي 160×160 بكسل. يجب أن تكون نسبة الأبعاد بين 1:3 و3:1. | IMAGE | نعم | - |
| `عامل التكبير` | مضاعف التكبير المطلوب. | COMBO | نعم | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `النمط` | نمط المعالجة: sublime للاستخدام العام، photo للصور الفوتوغرافية، photo_denoiser للصور ذات التشويش. | COMBO | نعم | `"sublime"`<br>`"photo"`<br>`"photo_denoiser"` |
| `الحدة` | كثافة حدة الصورة. القيم الأعلى تزيد من وضوح الحواف ودقتها. الافتراضي: 7. | INT | لا | 0 إلى 100 |
| `تحسين الحبيبات الذكي` | تحسين ذكي للحبيبية/الملمس لمنع الصورة من أن تبدو ناعمة جدًا أو مصطنعة. الافتراضي: 7. | INT | لا | 0 إلى 100 |
| `تفاصيل فائقة` | يتحكم في التفاصيل الدقيقة والملمس والتفاصيل المتناهية الصغر المضافة أثناء التكبير. الافتراضي: 30. | INT | لا | 0 إلى 100 |
| `تصغير تلقائي` | تقليل دقة صورة الإدخال تلقائيًا إذا تجاوز الإخراج الحد الأقصى للدقة. الافتراضي: False. | BOOLEAN | لا | - |

**ملاحظة:** إذا تم تعطيل `auto_downscale` وكان حجم الإخراج المطلوب (أبعاد الإدخال × `scale_factor`) يتجاوز 10060×10060 بكسل، ستقوم العقدة بإطلاق خطأ. عند تمكين `auto_downscale`، ستحاول العقدة إيجاد عامل تكبير أمثل يحافظ على أقل قدر من فقدان الجودة.
