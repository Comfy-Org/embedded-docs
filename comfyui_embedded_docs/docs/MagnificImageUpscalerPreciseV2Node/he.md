# MagnificImageUpscalerPreciseV2Node

הצומת Magnific Image Upscale (Precise V2) מבצע הגדלת תמונה בנאמנות גבוהה עם שליטה עדינה בחדות, בגרעיניות ובשיפור פרטים. הוא מעבד תמונות דרך API חיצוני, ותומך ברזולוציית פלט מרבית של עד 10060×10060 פיקסלים. הצומת מציע סגנונות עיבוד שונים ויכול להקטין אוטומטית את הקלט אם הפלט המבוקש יעלה על הגודל המרבי המותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט להגדלה. נדרשת תמונה אחת בדיוק. ממדים מינימליים הם 160x160 פיקסלים. יחס הגובה-רוחב חייב להיות בין 1:3 ל-3:1. | IMAGE | כן | - |
| `scale_factor` | מכפיל ההגדלה הרצוי. | COMBO | כן | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `flavor` | סגנון עיבוד: sublime לשימוש כללי, photo עבור תצלומים, photo_denoiser עבור תצלומים רועשים. | COMBO | כן | `"sublime"`<br>`"photo"`<br>`"photo_denoiser"` |
| `sharpen` | עוצמת חדות התמונה. ערכים גבוהים יותר מגבירים הגדרת קצוות ובהירות. ברירת מחדל: 7. | INT | כן | 0 עד 100 |
| `smart_grain` | שיפור חכם של גרעיניות/מרקם כדי למנוע מהתמונה להיראות חלקה מדי או מלאכותית. ברירת מחדל: 7. | INT | כן | 0 עד 100 |
| `ultra_detail` | שולט בפרטים עדינים, במרקמים ובמיקרו-פרטים שנוספים במהלך ההגדלה. ברירת מחדל: 30. | INT | כן | 0 עד 100 |
| `auto_downscale` | הקטנה אוטומטית של תמונת הקלט אם הפלט יעלה על הרזולוציה המקסימלית. ברירת מחדל: False. זוהי הגדרה מתקדמת. | BOOLEAN | כן | - |

**הערה:** אם `auto_downscale` מושבת וגודל הפלט המבוקש (ממדי הקלט × `scale_factor`) עולה על 10060x10060 פיקסלים, הצומת יחזיר שגיאה. כאשר `auto_downscale` מופעל, הצומת ינסה למצוא מקדם הגדלה אופטימלי שממזער את אובדן האיכות.
