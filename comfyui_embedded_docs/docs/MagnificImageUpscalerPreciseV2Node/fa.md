# بزرگ‌نمایی تصویر Magnific (دقیق V2)

گره Magnific Image Upscale (Precise V2) بزرگنمایی تصویر با وفاداری بالا را با کنترل دقیق بر وضوح، دانه و افزایش جزئیات انجام می‌دهد. این گره تصاویر را از طریق یک API خارجی پردازش می‌کند و از حداکثر رزولوشن خروجی 10060×10060 پیکسل پشتیبانی می‌کند. گره سبک‌های پردازشی مختلفی ارائه می‌دهد و اگر خروجی درخواستی از حداکثر اندازه مجاز فراتر رود، می‌تواند به‌طور خودکار ورودی را کوچک‌مقیاس کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که قرار است بزرگنمایی شود. دقیقاً یک تصویر مورد نیاز است. حداقل ابعاد 160x160 پیکسل است. نسبت ابعاد باید بین 1:3 و 3:1 باشد. | IMAGE | بله | - |
| `ضریب بزرگ‌نمایی` | ضریب بزرگنمایی مورد نظر. | COMBO | بله | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `سبک پردازش` | سبک پردازش: sublime برای استفاده عمومی، photo برای عکس‌ها، photo_denoiser برای عکس‌های نویزدار. | COMBO | بله | `"sublime"`<br>`"photo"`<br>`"photo_denoiser"` |
| `وضوح` | شدت وضوح تصویر. مقادیر بالاتر تعریف لبه‌ها و شفافیت را افزایش می‌دهند. پیش‌فرض: 7. | INT | خیر | 0 تا 100 |
| `افزایش هوشمند دانه‌بندی` | تقویت هوشمند دانه/بافت برای جلوگیری از بیش از حد صاف یا مصنوعی به نظر رسیدن تصویر. پیش‌فرض: 7. | INT | خیر | 0 تا 100 |
| `جزئیات فوق‌العاده` | جزئیات ریز، بافت‌ها و ریزجزئیاتی را که در طول بزرگنمایی اضافه می‌شوند، کنترل می‌کند. پیش‌فرض: 30. | INT | خیر | 0 تا 100 |
| `کاهش خودکار ابعاد` | در صورت تجاوز خروجی از حداکثر رزولوشن، تصویر ورودی را به‌طور خودکار کوچک‌مقیاس می‌کند. پیش‌فرض: False. | BOOLEAN | خیر | - |

**نکته:** اگر `auto_downscale` غیرفعال باشد و اندازه خروجی درخواستی (ابعاد ورودی × `scale_factor`) از 10060x10060 پیکسل فراتر رود، گره خطا صادر می‌کند. وقتی `auto_downscale` فعال باشد، گره سعی می‌کند ضریب مقیاس بهینه‌ای بیابد که افت کیفیت را به حداقل برساند.
