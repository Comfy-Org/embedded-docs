# Magnific 影像放大（精確 V2）

Magnific Image Upscale (Precise V2) 節點可執行高保真度影像放大，並能精細控制銳利度、顆粒感與細節增強。此節點透過外部 API 處理影像，最高可支援 10060×10060 像素的輸出解析度。節點提供多種處理風格，若要求的輸出尺寸超過允許的最大值，也可自動縮小輸入影像。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要放大的輸入影像。需要恰好一張影像。最小尺寸為 160x160 像素。長寬比必須介於 1:3 與 3:1 之間。 | IMAGE | 是 | - |
| `放大倍率` | 期望的放大倍率。 | COMBO | 是 | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `處理風格` | 處理風格：sublime 適用於一般用途，photo 適用於照片，photo_denoiser 適用於有雜訊的照片。 | COMBO | 是 | `"sublime"`<br>`"photo"`<br>`"photo_denoiser"` |
| `銳利度` | 影像銳利度強度。數值越高，邊緣定義與清晰度越強。預設值：7。 | INT | 否 | 0 至 100 |
| `智慧顆粒` | 智慧型顆粒／紋理增強，避免影像看起來過於平滑或人工化。預設值：7。 | INT | 否 | 0 至 100 |
| `極致細節` | 控制放大過程中新增的精細細節、紋理與微細節。預設值：30。 | INT | 否 | 0 至 100 |
| `自動降尺寸` | 若輸出會超過最大解析度，自動縮小輸入影像。預設值：False。 | BOOLEAN | 否 | - |

**注意：** 若停用 `auto_downscale`，且要求的輸出尺寸（輸入尺寸 × `scale_factor`）超過 10060x10060 像素，節點將產生錯誤。啟用 `auto_downscale` 時，節點會嘗試找出能將品質損失降到最低的最佳縮放倍率。
