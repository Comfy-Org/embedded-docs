# Magnific Image Upscale (Precise V2)

Узел **Magnific Image Upscale (Precise V2)** выполняет высокоточное масштабирование изображений с тонкой настройкой резкости, зернистости и детализации. Он обрабатывает изображения через внешний API, поддерживая максимальное разрешение на выходе до 10060×10060 пикселей. Узел предлагает различные стили обработки и может автоматически уменьшать масштаб входного изображения, если запрошенный результат превышает максимально допустимый размер.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для масштабирования. Требуется ровно одно изображение. Минимальные размеры — 160x160 пикселей. Соотношение сторон должно быть от 1:3 до 3:1. | IMAGE | Да | - |
| `коэффициент увеличения` | Желаемый множитель масштабирования. | COMBO | Да | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `стиль обработки` | Стиль обработки: sublime для общего использования, photo для фотографий, photo_denoiser для шумных фотографий. | COMBO | Да | `"sublime"`<br>`"photo"`<br>`"photo_denoiser"` |
| `резкость` | Интенсивность резкости изображения. Более высокие значения увеличивают четкость краёв и ясность. По умолчанию: 7. | INT | Нет | 0 до 100 |
| `умная зернистость` | Интеллектуальное улучшение зернистости/текстуры для предотвращения слишком гладкого или искусственного вида изображения. По умолчанию: 7. | INT | Нет | 0 до 100 |
| `ультра-детализация` | Управляет тонкими деталями, текстурами и микро-деталями, добавляемыми при масштабировании. По умолчанию: 30. | INT | Нет | 0 до 100 |
| `автоматическое уменьшение` | Автоматически уменьшать масштаб входного изображения, если выходной размер превышает максимальное разрешение. По умолчанию: False. | BOOLEAN | Нет | - |

**Примечание:** Если `auto_downscale` отключен и запрошенный размер выходного изображения (размер входного изображения × `scale_factor`) превышает 10060x10060 пикселей, узел вызовет ошибку. Когда `auto_downscale` включен, узел попытается найти оптимальный коэффициент масштабирования, который минимизирует потерю качества.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Результирующее масштабированное изображение. | IMAGE |
