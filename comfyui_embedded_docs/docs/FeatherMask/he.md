# Feather Mask

הצומת `FeatherMask` מחיל אפקט ריכוך שוליים על הקצוות של מסכה נתונה, ומעביר את קצוות המסכה בצורה חלקה על ידי התאמת האטימות שלהם בהתאם למרחקים שצוינו מכל קצה. הדבר יוצר אפקט קצה רך ומשולב יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `mask` | המסכה שעליה יוחל אפקט ריכוך השוליים. היא קובעת את אזור התמונה שיושפע מריכוך השוליים. | MASK |
| `left` | מציין את המרחק מהקצה השמאלי שבתוכו יוחל אפקט ריכוך השוליים. | INT |
| `top` | מציין את המרחק מהקצה העליון שבתוכו יוחל אפקט ריכוך השוליים. | INT |
| `right` | מציין את המרחק מהקצה הימני שבתוכו יוחל אפקט ריכוך השוליים. | INT |
| `bottom` | מציין את המרחק מהקצה התחתון שבתוכו יוחל אפקט ריכוך השוליים. | INT |

## פלטים

| פרמטר | תיאור | סוג נתונים |
