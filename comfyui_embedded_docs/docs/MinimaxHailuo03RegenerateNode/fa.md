# MinimaxHailuo03RegenerateNode

این گره خروجی ویدیوی MiniMax H3 768P را با رزولوشن 2K بازپردازی می‌کند. ویدیوی منبع و پرامپت دقیقی که برای ساخت آن استفاده شده را بارگذاری می‌کند، یک وظیفه بازتولید MiniMax H3 شروع می‌کند و ویدیوی 2K بازپردازی‌شده را برمی‌گرداند. اگر تولید اصلی از فریم اول یا آخر یا رسانه مرجع استفاده کرده باشد، همان ورودی‌ها را پیوست کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای بازتولید ویدیو استفاده می‌شود. انتخاب این مدل، تنظیمات پرامپت، رزولوشن و رسانه مرجع را که در ادامه مستند شده‌اند نمایان می‌کند. | COMBO | بله | "MiniMax H3" |
| `prompt` | پرامپت دقیقی که برای تولید ویدیوی منبع استفاده شده است. نباید خالی باشد. | STRING | بله | Text |
| `resolution` | رزولوشن برای بازپردازی ویدیوی منبع. | COMBO | بله | "2K" |
| `reference_images` | تصاویر مرجع از تولید اصلی، به همان ترتیب. حداکثر ۹ تصویر. | IMAGE | خیر | 0-9 images |
| `reference_videos` | ویدیوهای مرجع از تولید اصلی، به همان ترتیب. حداکثر ۳ ویدیو، هر کدام ۲ تا ۱۵ ثانیه، در مجموع ۱۵ ثانیه. | VIDEO | خیر | 0-3 videos |
| `reference_audios` | ارجاع‌های صوتی از تولید اصلی، به همان ترتیب. حداکثر ۳ کلیپ، هر کدام ۲ تا ۱۵ ثانیه، در مجموع ۱۵ ثانیه. بدون تصویر یا ویدیوی مرجع قابل استفاده نیست. | AUDIO | خیر | 0-3 clips |
| `video` | ویدیوی خروجی MiniMax H3 768P که باید بازپردازی شود. خروجی تغییرنیافته یک گره ویدیوی MiniMax H3 را متصل کنید (۲۴ فریم بر ثانیه، ۴ تا ۱۵ ثانیه). خروجی‌های 2K قابل استفاده نیستند. | VIDEO | بله | 24 FPS, 4-15 seconds |
| `first_frame` | تصویر فریم اول از تولید اصلی، در صورت استفاده. | IMAGE | خیر | Image |
| `last_frame` | تصویر فریم آخر از تولید اصلی، در صورت استفاده. | IMAGE | خیر | Image |
| `watermark` | آیا واترمارک AIGC به ویدیو اضافه شود. پیش‌فرض false است. | BOOLEAN | بله | false / true |

### محدودیت‌ها

- ویدیوی `video` منبع باید خروجی تغییرنیافته MiniMax H3 768P باشد: عرض و ارتفاع قابل تقسیم بر ۳۲، حداکثر ۱,۰۳۲,۱۹۲ پیکسل کل، ۲۴ فریم بر ثانیه، و ۱۰۷ تا ۳۶۲ فریم در گام‌های ۱۷ (۴ تا ۱۵ ثانیه در ۲۴ فریم بر ثانیه). خروجی‌های 2K نمی‌توانند به عنوان منبع استفاده شوند.
- `first_frame` / `last_frame` و رسانه مرجع (`reference_images`، `reference_videos`، `reference_audios`) مانعه‌الجمع هستند. برای پرامپت تصویر به ویدیو از فریم‌ها استفاده کنید، یا برای پرامپت مرجع به ویدیو از رسانه مرجع استفاده کنید.
- `reference_audios` به حداقل یک ورودی `reference_images` یا `reference_videos` نیاز دارد.
- `reference_images`: هر تصویر باید نسبت ابعادی بین 0.4 و 2.5 داشته باشد و حداقل 256x256 پیکسل باشد.
- `reference_videos`: هر ویدیو باید 23.976 تا 60 فریم بر ثانیه و ۲ تا ۱۵ ثانیه طول داشته باشد؛ مدت زمان کل نباید از ۱۵ ثانیه تجاوز کند.
- `reference_audios`: هر کلیپ باید ۲ تا ۱۵ ثانیه طول داشته باشد؛ مدت زمان کل نباید از ۱۵ ثانیه تجاوز کند.
