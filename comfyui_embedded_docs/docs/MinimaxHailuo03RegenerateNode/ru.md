# MinimaxHailuo03RegenerateNode

Этот узел перерендеривает видеовыход MiniMax H3 768P в разрешении 2K. Он загружает исходное видео и точный промпт, использованный для его создания, запускает задание на перегенерацию MiniMax H3 и возвращает перерендеренное видео 2K. Если при исходной генерации использовались первый или последний кадры либо референсные медиафайлы, укажите те же входные данные.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для перегенерации видео. При выборе этой модели отображаются настройки промпта, разрешения и референсных материалов, описанные ниже. | COMBO | Да | "MiniMax H3" |
| `prompt` | Точный промпт, использованный для генерации исходного видео. Не должен быть пустым. | STRING | Да | Text |
| `resolution` | Разрешение, в котором будет перерендерено исходное видео. | COMBO | Да | "2K" |
| `reference_images` | Референсные изображения из исходной генерации, в том же порядке. До 9 изображений. | IMAGE | Нет | 0-9 images |
| `reference_videos` | Референсные видео из исходной генерации, в том же порядке. До 3 видео, каждое продолжительностью 2-15 секунд, суммарно 15 секунд. | VIDEO | Нет | 0-3 videos |
| `reference_audios` | Референсные аудио из исходной генерации, в том же порядке. До 3 клипов, каждый продолжительностью 2-15 секунд, суммарно 15 секунд. Не могут использоваться без референсного изображения или видео. | AUDIO | Нет | 0-3 clips |
| `video` | Видеовыход MiniMax H3 768P, который нужно перерендерить. Подключите немодифицированный выход узла видео MiniMax H3 (24 FPS, 4-15 секунд). Выходы 2K использовать нельзя. | VIDEO | Да | 24 FPS, 4-15 seconds |
| `first_frame` | Изображение первого кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Image |
| `last_frame` | Изображение последнего кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Image |
| `watermark` | Нужно ли добавлять на видео водяной знак AIGC. По умолчанию — false. | BOOLEAN | Да | false / true |

### Ограничения

- Исходное `video` должно быть немодифицированным выходом MiniMax H3 768P: ширина и высота должны делиться на 32, общее количество пикселей не более 1 032 192, 24 FPS, от 107 до 362 кадров с шагом 17 (от 4 до 15 секунд при 24 FPS). Выходы 2K не могут использоваться в качестве исходного видео.
- `first_frame` / `last_frame` и референсные материалы (`reference_images`, `reference_videos`, `reference_audios`) являются взаимоисключающими. Используйте кадры для промпта image-to-video или референсные материалы для промпта reference-to-video.
- Для `reference_audios` требуется хотя бы один вход `reference_images` или `reference_videos`.
- `reference_images`: каждое изображение должно иметь соотношение сторон от 0.4 до 2.5 и быть размером не менее 256x256 пикселей.
- `reference_videos`: каждое видео должно быть 23.976–60 FPS и длительностью 2–15 секунд; общая длительность не должна превышать 15 секунд.
- `reference_audios`: каждый клип должен быть длительностью 2–15 секунд; общая длительность не должна превышать 15 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Перерендеренное видео MiniMax H3 в разрешении 2K. | VIDEO |
