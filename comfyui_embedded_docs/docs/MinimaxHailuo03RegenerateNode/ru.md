# MinimaxHailuo03RegenerateNode

Этот узел повторно рендерит выходное видео MiniMax H3 768P в разрешение 2K. Он загружает немодифицированное видео 768P и точный промпт, использованный для его генерации, запускает задание повторной генерации MiniMax H3 и возвращает повторно отрендеренное видео 2K. Если в исходной генерации использовались первый или последний кадры или референсные материалы, присоедините те же входы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для повторной генерации видео. При выборе «MiniMax H3» отображаются настройки промпта, разрешения и референсных материалов. | COMBO | Да | "MiniMax H3" |
| `video` | Выходное видео MiniMax H3 768P для повторного рендеринга. Подключите немодифицированный выход видеоузла MiniMax H3 (24 FPS, 4–15 секунд). Выходы 2K использовать нельзя. | VIDEO | Да | 24 FPS, 4-15 seconds |
| `first_frame` | Изображение первого кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Image |
| `last_frame` | Изображение последнего кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Image |
| `watermark` | Добавлять ли AIGC-водяной знак к видео. По умолчанию false. | BOOLEAN | Да | false / true |

### Входы MiniMax H3

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Точный промпт, использованный для генерации исходного видео. Не должен быть пустым. | STRING | Да | Text (multiline) |
| `resolution` | Разрешение для повторного рендеринга исходного видео. | COMBO | Да | "2K" |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите `image_1` ... `image_9` (до 9 изображений). Референсные изображения из исходной генерации в том же порядке. | IMAGE | Нет | 0-9 images |
| `reference_videos` | Расширяемый слот: подключите `video_1` ... `video_3` (до 3 видео). Референсные видео из исходной генерации в том же порядке. | VIDEO | Нет | 0-3 videos |
| `reference_audios` | Расширяемый слот: подключите `audio_1` ... `audio_3` (до 3 клипов). Референсные аудио из исходной генерации в том же порядке. Нельзя использовать без референсного изображения или видео. | AUDIO | Нет | 0-3 clips |

### Ограничения

- Поле `prompt` не должно быть пустым.
- Исходный `video` должен быть немодифицированным выходом MiniMax H3 768P: 24 FPS, ширина и высота делятся на 32, не более 1 032 192 пикселей в сумме и 107–362 кадра с шагом 17 (4–15 секунд при 24 FPS). Выходы 2K нельзя использовать в качестве источника.
- `first_frame` и `last_frame` взаимоисключаются с референсными материалами (`reference_images`, `reference_videos`, `reference_audios`). Используйте кадры для промпта image-to-video или референсные материалы для промпта reference-to-video.
- Для `reference_audios` требуется хотя бы один вход `reference_images` или `reference_videos`.
- `first_frame`, `last_frame` и каждое `reference_image` должны иметь соотношение сторон от 0.4 до 2.5 и быть не менее 256×256 пикселей.
- `reference_videos`: каждое видео должно быть 23.976–60 FPS и длительностью 2–15 секунд; общая длительность не может превышать 15 секунд.
- `reference_audios`: каждый клип должен быть длительностью 2–15 секунд; общая длительность не может превышать 15 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Повторно отрендеренное видео MiniMax H3 в разрешении 2K. | VIDEO |
