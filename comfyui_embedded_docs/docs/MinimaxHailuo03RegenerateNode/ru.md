# MiniMax H3: перерендеринг в 2K

Этот узел повторно рендерит выходное видео MiniMax H3 768P в разрешении 2K. Он загружает неизменённое видео 768P и точный промпт, использованный для его генерации, запускает задание повторной генерации MiniMax H3 и возвращает повторно отрендеренное видео 2K. Если при исходной генерации использовались первый или последний кадры либо эталонные медиа, подключите те же входы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для повторной генерации видео. При выборе «MiniMax H3» отображаются настройки промпта, разрешения и эталонных медиа. | DYNAMIC_COMBO | Да | "MiniMax H3" |
| `video` | Выходное видео MiniMax H3 768P для повторного рендеринга. Подключите неизменённый выход видеоузла MiniMax H3 (24 FPS, 4–15 секунд). Выходы 2K использовать нельзя. | VIDEO | Да | 24 FPS, 4–15 секунд |
| `first_frame` | Изображение первого кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Изображение |
| `last_frame` | Изображение последнего кадра из исходной генерации, если оно использовалось. | IMAGE | Нет | Изображение |
| `watermark` | Добавлять ли водяной знак AIGC на видео. По умолчанию false. | BOOLEAN | Да | false / true |

### Входы MiniMax H3

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Точный промпт, использованный для генерации исходного видео. Не должен быть пустым. | STRING | Да | Текст (многострочный) |
| `resolution` | Разрешение, в котором нужно повторно отрендерить исходное видео. | COMBO | Да | "2K" |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите `image_1`–`image_9` (до 9 изображений). Эталонные изображения из исходной генерации, в том же порядке. | IMAGE | Нет | 0–9 изображений |
| `reference_videos` | Расширяемый слот: подключите `video_1`–`video_3` (до 3 видео). Эталонные видео из исходной генерации, в том же порядке. | VIDEO | Нет | 0–3 видео |
| `reference_audios` | Расширяемый слот: подключите `audio_1`–`audio_3` (до 3 аудиофрагментов). Эталонные аудио из исходной генерации, в том же порядке. Нельзя использовать без эталонного изображения или видео. | AUDIO | Нет | 0–3 аудиофрагмента |

### Ограничения

- Параметр `prompt` не должен быть пустым.
- Исходное `video` должно быть неизменённым выходом MiniMax H3 768P: 24 FPS, ширина и высота кратны 32, суммарное количество пикселей не более 1 032 192, а количество кадров — от 107 до 362 с шагом 17 (от 4 до 15 секунд при 24 FPS). Выходы 2K нельзя использовать в качестве источника.
- `first_frame` и `last_frame` взаимоисключающие с эталонными медиа (`reference_images`, `reference_videos`, `reference_audios`). Используйте кадры для промпта «изображение → видео» или эталонные медиа для промпта «эталон → видео».
- Для `reference_audios` требуется как минимум один вход `reference_images` или `reference_videos`.
- `first_frame`, `last_frame` и каждое `reference_image` должны иметь соотношение сторон от 0.4 до 2.5 и размер не менее 256x256 пикселей.
- `reference_videos`: каждое видео должно иметь частоту от 23.976 до 60 FPS и длительность 2–15 секунд; общая длительность не может превышать 15 секунд.
- `reference_audios`: каждый аудиофрагмент должен быть длительностью 2–15 секунд; общая длительность не может превышать 15 секунд.

## Выходы

|-------------|-------------|-----------|
| `video` | Повторно отрендеренное видео MiniMax H3 в разрешении 2K. | VIDEO |
