# MeshTextureToImage

Этот узел извлекает запечённые текстуры меша и возвращает их как отдельные изображения: базовый цвет, металличность, шероховатость, окклюзию и карту нормалей. Каналы текстур, которые не были запечены, возвращаются в виде нейтральных значений по умолчанию — белый для окклюзии и плоский синий для карты нормалей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Меш, из которого извлекаются запечённые текстуры. Меш должен иметь текстуру базового цвета; меши, имеющие только цвета вершин (например, после узла PaintMesh), не содержат текстуры и вызывают ошибку. | MESH | Да | — |

Примечание: меш должен иметь запечённую текстуру базового цвета. Если её нет, узел выдаёт ошибку и рекомендует сначала запустить BakeTextureFromVoxel. Если текстура металличности-шероховатости отсутствует, выходы `metallic` и `roughness` будут чёрными (0). Выход `occlusion` будет белым, если меш не содержит запечённой ambient occlusion. Выход `normal_map` будет плоским нейтрально-синим, если карта нормалей не была запечена.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `базовый цвет` | Текстура базового цвета меша в виде изображения. | IMAGE |
| `металличность` | Канал металличности из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Чёрный (0) означает неметаллический материал, белый (1) — полностью металлический. Чёрный, если текстура отсутствует. | IMAGE |
| `шероховатость` | Канал шероховатости из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Чёрный, если текстура отсутствует. | IMAGE |
| `окклюзия` | Канал ambient occlusion из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Белый (без окклюзии), если ambient occlusion не была запечена. | IMAGE |
| `карта нормалей` | Карта нормалей меша. Плоская нейтральная карта нормалей (0.5, 0.5, 1.0, выглядит как плоский синий цвет), если карта нормалей не была запечена. | IMAGE |
