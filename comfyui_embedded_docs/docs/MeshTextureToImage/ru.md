# Текстуры сетки в изображение

Этот узел извлекает запечённые текстуры меша и возвращает их в виде отдельных изображений: базового цвета, металличности, шероховатости, окклюзии и карты нормалей. Каналы текстуры, которые не были запечены, возвращаются в виде нейтральных значений по умолчанию — белый для окклюзии и однородный синий для карты нормалей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Меш, из которого извлекаются запечённые текстуры. У меша должна быть текстура базового цвета; меши, у которых есть только цвета вершин (например, после узла PaintMesh), не содержат текстуры, что вызывает ошибку. | MESH | Да | — |

Примечание: У меша должна быть запечённая текстура базового цвета. Если её нет, узел выдаёт ошибку и рекомендует сначала запустить BakeTextureFromVoxel. Если текстура metallic-roughness отсутствует, выходы `metallic` и `roughness` чёрные (0). Выход `occlusion` белый, если только меш не содержит запечённое ambient occlusion (у меша установлен флаг occlusion-in-metallic-roughness). Выход `normal_map` имеет однородный нейтральный синий цвет, если карта нормалей не была запечена.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_color` | Текстура базового цвета меша в виде изображения. | IMAGE |
| `metallic` | Канал металличности из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Чёрный (0) означает неметаллический, белый (1) — полностью металлический. Чёрный, если текстура отсутствует. | IMAGE |
| `roughness` | Канал шероховатости из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Чёрный, если текстура отсутствует. | IMAGE |
| `occlusion` | Канал ambient occlusion из текстуры occlusion-roughness-metallic меша в виде изображения в градациях серого. Белый (без затенения), если ambient occlusion не был запечён. | IMAGE |
| `normal_map` | Текстура карты нормалей меша. Однородная нейтральная карта нормалей (0.5, 0.5, 1.0, выглядит как однородный синий), если карта нормалей не была запечена. | IMAGE |
