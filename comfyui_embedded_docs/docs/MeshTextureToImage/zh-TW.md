# 網格紋理轉影像

此節點會擷取網格的烘焙紋理，並將它們以個別影像回傳：基礎顏色、金屬度、粗糙度、遮蔽和法線貼圖。未經烘焙的紋理通道會以中性預設值回傳——遮蔽為白色，法線貼圖為平坦藍色。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要從中擷取烘焙紋理的網格。此網格必須具有基礎顏色紋理；只有頂點顏色（例如在 PaintMesh 節點之後）的網格不含紋理，並會導致錯誤。 | MESH | 是 | — |

注意：此網格必須具有已烘焙的基礎顏色紋理。如果沒有，此節點會引發錯誤，並建議先執行 BakeTextureFromVoxel。當金屬度-粗糙度紋理缺少時，`metallic` 和 `roughness` 輸出為黑色（0）。除非網格包含烘焙的環境光遮蔽（已設定網格的 `occlusion-in-metallic-roughness` 旗標），否則 `occlusion` 輸出為白色。未烘焙法線貼圖時，`normal_map` 輸出為平坦的中性藍色。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `base_color` | 網格的基礎顏色紋理，以影像形式表示。 | IMAGE |
| `metallic` | 來自網格遮蔽-粗糙度-金屬度紋理的金屬度通道，以灰階影像表示。黑色（0）表示非金屬，白色（1）表示完全金屬。紋理缺少時為黑色。 | IMAGE |
| `roughness` | 來自網格遮蔽-粗糙度-金屬度紋理的粗糙度通道，以灰階影像表示。紋理缺少時為黑色。 | IMAGE |
