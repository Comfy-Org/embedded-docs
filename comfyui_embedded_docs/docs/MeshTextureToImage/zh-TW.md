# MeshTextureToImage

此節點會擷取網格的已烘焙紋理，並將其作為單獨的影像傳回：基礎顏色、金屬度、粗糙度、環境光遮蔽與法線貼圖。未經烘焙的紋理通道會以中性預設值傳回——環境光遮蔽為白色，法線貼圖為平坦的藍色。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要擷取已烘焙紋理的網格。此網格必須具有基礎顏色紋理；只有頂點顏色的網格（例如經由 PaintMesh 節點處理後）不包含紋理，並會導致錯誤。 | MESH | 是 | — |

注意：網格必須具有已烘焙的基礎顏色紋理。若無，節點會引發錯誤，並建議先執行 BakeTextureFromVoxel。當金屬度-粗糙度紋理缺失時，`metallic` 與 `roughness` 輸出為黑色（0）。除非網格包含已烘焙的環境光遮蔽，否則 `occlusion` 輸出為白色。若未烘焙法線貼圖，`normal_map` 輸出為平坦的中性藍色。
