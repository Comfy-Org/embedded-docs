# ByteDanceSeedreamNodeV3

ByteDance Seedream 4.5 и 5.0 создает изображения по текстовому запросу (text-to-image) или создает/редактирует изображения под управлением дополнительных эталонных изображений, используя модели ByteDance Seedream 4.0, 4.5 и 5.0 с разрешением до 4K. Узел отправляет запрос и любые эталонные изображения в API ByteDance, ожидает завершения задачи генерации и возвращает результирующий тензор или тензоры изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовый запрос для создания или редактирования изображения. Не должен быть пустым после удаления пробелов по краям. | STRING | Да | Многострочный текст |
| `модель` | Выбирает модель Seedream для использования. Каждая модель предоставляет свой набор подпараметров и ограничений ниже. | DYNAMIC_COMBO | Да | "seedream 5.0 pro"<br>"seedream 5.0 lite"<br>"seedream-4-5-251128"<br>"seedream-4-0-250828" |

### Входы Seedream 5.0 Pro (seedream 5.0 pro)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | Выберите рекомендуемый размер. Выберите Custom, чтобы использовать ширину и высоту ниже. По умолчанию: первый рекомендуемый пресет для этой модели. | COMBO | Нет | Model-specific recommended size presets<br>"Custom" |
| `width` | Пользовательская ширина изображения. Значение работает только если `size_preset` установлен в `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 3136 (step 2) |
| `height` | Пользовательская высота изображения. Значение работает только если `size_preset` установлен в `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 2496 (step 2) |
| `prompt_optimization` | Режим оптимизации запроса при предоставлении эталонных изображений: 'standard' обеспечивает более высокое качество, 'fast' — более короткое время генерации. По умолчанию: "standard". | COMBO | Нет | "standard"<br>"fast" |
| `seed` | Seed для генерации. По умолчанию: 42. | INT | Нет | 0 до 2147483647 |
| `watermark` | Добавлять ли водяной знак "AI generated" на изображение. По умолчанию: false. | BOOLEAN | Нет | true / false |
| `thinking` | Включить рассуждения модели по оптимизации запроса ('thinking') для лучшего следования запросу. Может существенно увеличить время генерации — особенно на Seedream 5.0 Pro. Может быть отключен только для text-to-image (не при предоставлении эталонных изображений). По умолчанию: true. | BOOLEAN | Нет | true / false |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: необязательные эталонные изображения для генерации image-to-image или с несколькими ссылками. Подключите изображения 1..N (например, `image_1`, `image_2`, ...); лимит количества зависит от модели (см. примечания ниже). Если подключенное изображение содержит пакет изображений, каждое изображение в пакете учитывается в лимите. | IMAGE | Нет | 0 до 10 (Seedream 5.0 Pro, Seedream 4.5, Seedream 4.0)<br>0 до 14 (Seedream 5.0 Lite) |

**Примечания:**

- `prompt` не должен быть пустым после удаления пробелов по краям.
- Максимальное количество эталонных изображений: 10 для Seedream 5.0 Pro, Seedream 4.5 и Seedream 4.0; 14 для Seedream 5.0 Lite.
- Каждое эталонное изображение должно иметь соотношение сторон от 1:3 до 3:1.
- Когда `max_images` больше 1 (недоступно на Seedream 5.0 Pro), общее количество эталонных и сгенерированных изображений не может превышать 15.
- `thinking` может быть отключен только для генерации text-to-image. При предоставлении эталонных изображений `thinking` должен быть включен.
- `width` и `height` используются только когда `size_preset` установлен в "Custom".
- `prompt_optimization` доступен только на Seedream 5.0 Pro.
- `max_images` и `fail_on_partial` доступны только на Seedream 5.0 Lite, Seedream 4.5 и Seedream 4.0; Seedream 5.0 Pro всегда запрашивает одно изображение.
- Требования к разрешению (ширина x высота):
  - Seedream 5.0 Pro: от 0.92MP (921,600 пикселей) до 4.19MP (4,194,304 пикселей).
  - Seedream 5.0 Lite и Seedream 4.5: не менее 3.68MP (3,686,400 пикселей).
  - Seedream 4.0: не менее 0.92MP (921,600 пикселей).
  - Все модели, кроме Pro: не более 16.78MP (16,777,216 пикселей).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Тензор сгенерированного изображения. Когда генерируется несколько изображений, они объединяются в один пакетный тензор IMAGE. | IMAGE |
