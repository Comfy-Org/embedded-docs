# ByteDance Seedream 4.5 & 5.0

ByteDance Seedream 4.5 и 5.0 генерирует изображения по текстовому промпту (текст-в-изображение) или генерирует/редактирует изображения на основе необязательных эталонных изображений, используя модели ByteDance Seedream 4.0, 4.5 и 5.0 с разрешением до 4K. Узел отправляет промпт и любые эталонные изображения в API ByteDance, ожидает завершения задачи генерации и возвращает результирующий тензор изображения или тензоры.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовый промпт для создания или редактирования изображения. Не должен быть пустым после удаления пробелов. | STRING | Да | Многострочный текст |
| `модель` | Выбирает используемую модель Seedream. Каждая модель имеет собственный набор подпараметров и ограничений ниже. | DYNAMIC_COMBO | Да | "seedream 5.0 pro"<br>"seedream 5.0 lite"<br>"seedream-4-5-251128"<br>"seedream-4-0-250828" |

### Входы Seedream 5.0 Pro (seedream 5.0 pro)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | Выберите рекомендуемый размер. Выберите Custom, чтобы использовать ширину и высоту ниже. По умолчанию: первый рекомендуемый пресет для этой модели. | COMBO | Нет | Рекомендуемые размеры для конкретной модели<br>"Custom" |
| `width` | Пользовательская ширина изображения. Значение применяется только если `size_preset` установлен в `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 3136 (шаг: 2) |
| `height` | Пользовательская высота изображения. Значение применяется только если `size_preset` установлен в `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 2496 (шаг: 2) |
| `prompt_optimization` | Режим оптимизации промпта при наличии эталонных изображений: "standard" обеспечивает более высокое качество, "fast" — меньшее время генерации. По умолчанию: "standard". | COMBO | Нет | "standard"<br>"fast" |
| `seed` | Сид для генерации. По умолчанию: 42. | INT | Нет | 0 до 2147483647 |
| `watermark` | Добавлять ли водяной знак «AI generated» на изображение. По умолчанию: false. | BOOLEAN | Нет | true / false |
| `thinking` | Включить рассуждение модели для оптимизации промпта ('thinking') для лучшего соответствия. Может существенно увеличить время генерации — особенно на Seedream 5.0 Pro. Можно отключить только для генерации по тексту (не когда предоставлены эталонные изображения). По умолчанию: true. | BOOLEAN | Нет | true / false |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: необязательное(ые) эталонное(ые) изображение(я) для преобразования изображения в изображение или генерации с несколькими эталонными изображениями. Подключите от 1 до N изображений (например, `image_1`, `image_2`, ...); ограничение количества зависит от модели (см. примечания ниже). Если подключённое изображение содержит пакет изображений, каждое изображение в пакете учитывается в лимите. | IMAGE | Нет | 0 до 10 (Seedream 5.0 Pro, Seedream 4.5, Seedream 4.0)<br>0 до 14 (Seedream 5.0 Lite) |

**Примечания:**

- `prompt` не должен быть пустым после удаления пробелов.
- Максимальное количество эталонных изображений: 10 для Seedream 5.0 Pro, Seedream 4.5 и Seedream 4.0; 14 для Seedream 5.0 Lite.
- Каждое эталонное изображение должно иметь соотношение сторон от 1:3 до 3:1.
- Когда `max_images` больше 1 (недоступно на Seedream 5.0 Pro), общее количество эталонных изображений плюс сгенерированных изображений не может превышать 15.
- `thinking` можно отключить только для генерации изображения по тексту. Когда предоставлены эталонные изображения, `thinking` должен быть включён.
- `width` и `height` используются только когда `size_preset` установлен в "Custom".
- `prompt_optimization` доступен только на Seedream 5.0 Pro.
- `max_images` и `fail_on_partial` доступны только на Seedream 5.0 Lite, Seedream 4.5 и Seedream 4.0; Seedream 5.0 Pro всегда запрашивает одно изображение.
- Требования к разрешению (ширина x высота):
  - Seedream 5.0 Pro: между 0.92MP (921,600 пикселей) и 4.19MP (4,194,304 пикселя).
  - Seedream 5.0 Lite и Seedream 4.5: не менее 3.68MP (3,686,400 пикселей).
  - Seedream 4.0: не менее 0.92MP (921,600 пикселей).
  - Все модели, кроме Pro: не более 16.78MP (16,777,216 пикселей).
