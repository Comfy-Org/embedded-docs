# ByteDance Seedream 4.5 & 5.0

ByteDance Seedream 4.5 & 5.0 генерирует изображения по текстовому запросу (text-to-image) или генерирует/редактирует изображения под управлением необязательных эталонных изображений, используя модели ByteDance Seedream 4.0, 4.5 и 5.0 с разрешением до 4K. Узел отправляет запрос и любые эталонные изображения в API ByteDance, ожидает завершения задачи генерации и возвращает результирующий тензор или тензоры изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовый запрос для создания или редактирования изображения. Не должен быть пустым после удаления пробельных символов. | STRING | Да | Многострочный текст |
| `модель` | Выбирает используемую модель Seedream. Для каждой модели ниже приведён собственный набор подпараметров и ограничений. | DYNAMIC_COMBO | Да | "seedream 5.0 pro"<br>"seedream 5.0 flash"<br>"seedream 5.0 lite"<br>"seedream-4-5-251128"<br>"seedream-4-0-250828" |

### Входы Seedream 5.0 Pro (seedream 5.0 pro)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | Выберите рекомендуемый размер. Выберите Custom, чтобы использовать значения ширины и высоты ниже. По умолчанию: первый рекомендуемый пресет для этой модели. | COMBO | Нет | Рекомендуемые предустановки размера для конкретной модели<br>"Custom" |
| `width` | Пользовательская ширина изображения. Значение применяется, только если для `size_preset` выбрано `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 4514 (шаг: 2) |
| `height` | Пользовательская высота изображения. Значение применяется, только если для `size_preset` выбрано `Custom`. По умолчанию: 2048. | INT | Нет | 1024 до 4514 (шаг: 2) |
| `prompt_optimization` | Режим оптимизации запроса, когда предоставлены эталонные изображения: 'standard' даёт более высокое качество, 'fast' — меньшее время генерации. По умолчанию: "standard". | COMBO | Нет | "standard"<br>"fast" |
| `seed` | Сид, используемый для генерации. По умолчанию: 42. | INT | Нет | 0 до 2147483647 |
| `watermark` | Добавлять ли водяной знак "AI generated" к изображению. По умолчанию: false. | BOOLEAN | Нет | true / false |
| `thinking` | Включить рассуждение модели по оптимизации запроса ('thinking') для лучшего соответствия. Может существенно увеличить время генерации — особенно в Seedream 5.0 Pro. Можно отключить только для генерации текст-в-изображение (text-to-image) (нельзя, когда предоставлены эталонные изображения). По умолчанию: true. | BOOLEAN | Нет | true / false |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: необязательное эталонное изображение(я) для генерации изображения по изображению (image-to-image) или мультиреференсной генерации. Подключите от 1 до N изображений (например, `image_1`, `image_2`, ...); ограничение количества зависит от модели (см. примечания ниже). Если подключённое изображение содержит пакет изображений, каждое изображение в пакете учитывается в лимите. | IMAGE | Нет | 0 до 10 (Seedream 5.0 Pro, Seedream 5.0 Flash, Seedream 4.5, Seedream 4.0)<br>0 до 14 (Seedream 5.0 Lite) |

**Примечания:**

- `prompt` не должен быть пустым после удаления пробельных символов.
- Максимальное количество эталонных изображений: 10 для Seedream 5.0 Pro, Seedream 5.0 Flash, Seedream 4.5 и Seedream 4.0; 14 для Seedream 5.0 Lite.
- Каждое эталонное изображение должно иметь соотношение сторон от 1:16 до 16:1.
- Когда `max_images` больше 1 (недоступно в Seedream 5.0 Pro или Seedream 5.0 Flash), общее количество эталонных изображений плюс сгенерированных изображений не может превышать 15.
- `thinking` можно отключить только для генерации текст-в-изображение. Когда предоставлены эталонные изображения, `thinking` должен быть включён. В Seedream 5.0 Flash нет входа `thinking`.
- `width` и `height` используются только когда для `size_preset` выбрано "Custom".
- `prompt_optimization` доступен только в Seedream 5.0 Pro.
- `max_images` и `fail_on_partial` доступны только в Seedream 5.0 Lite, Seedream 4.5 и Seedream 4.0; Seedream 5.0 Pro и Seedream 5.0 Flash всегда запрашивают одно изображение.
- Требования к разрешению (ширина x высота):
  - Seedream 5.0 Pro и Seedream 5.0 Flash: от 0.92MP (921,600 пикселей) до 4.62MP (4,624,220 пикселей).
  - Seedream 5.0 Lite и Seedream 4.5: не менее 3.68MP (3,686,400 пикселей).
  - Seedream 4.0: не менее 0.92MP (921,600 пикселей).
  - Seedream 5.0 Lite, Seedream 4.5 и Seedream 4.0: не более 16.78MP (16,777,216 пикселей).
