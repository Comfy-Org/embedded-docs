# YuE2GenerateMusic

יוצר טוקנים של מוזיקה והתניה אקוסטית מתוך סגנון, מילים ותווי ABC. הוא מחזיר את ההתניה ואת משך היצירה בשניות, אשר יש לספק לצומת Empty YuE2 Latent Audio. אם קלט ה-ABC נשאר ריק, המצב הנבחר מתעלם ומשתמשים אוטומטית במצב off.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל ה-CLIP המשמש לטוקניזציה ולקידוד של קלטי המוזיקה. | CLIP | כן | - |
| `style` | טקסט המתאר את הסגנון המוזיקלי. תומך בקלט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | טקסט רב-שורתי |
| `lyrics` | מילות השיר עבור המוזיקה שנוצרת. תומך בקלט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | טקסט רב-שורתי |
| `abc` | חברו את מחולל ABC או ספקו פרטיטורה ערוכה. השאירו ריק כדי להשתמש אוטומטית במצב off. ברירת מחדל: "" | STRING | כן | טקסט רב-שורתי |
| `seed` | זרע אקראי ליצירה. ברירת מחדל: 0 | INT | כן | 0 עד 18446744073709551615 |
| `mode` | full: יוצר מלודיה ואקורדים; melody: יוצר מלודיה בלבד, מומלץ לקאברים. ברירת מחדל: "full" | COMBO | כן | "full"<br>"melody" |
| `max_duration` | משך מרבי בשניות. מופחת אוטומטית עבור פרומפטים ארוכים; היצירה יכולה לעצור מוקדם יותר. ברירת מחדל: 360.0 | FLOAT | כן | 0.04 עד 900.0 |
| `temperature` | טמפרטורת דגימה ליצירה. ברירת מחדל: 1.0 (מתקדם) | FLOAT | כן | 0.0 עד 5.0 |
| `top_p` | סף הסתברות לדגימת גרעין. ברירת מחדל: 0.95 (מתקדם) | FLOAT | כן | 0.01 עד 1.0 |
| `top_k` | מגבלת דגימת Top-k. ברירת מחדל: 100 (מתקדם) | INT | כן | 1 עד 32768 |
| `repetition_penalty` | קנס המוחל על טוקנים חוזרים. ברירת מחדל: 1.2 (מתקדם) | FLOAT | כן | 0.01 עד 10.0 |
| `cfg_scale` | הנחיה אוטורגרסיבית עבור סגנון ומילים. 1.0 מנטרל CFG, בהתאמה לזרימת העבודה של ABC. השתמשו ב-1.01 כדי להתאים להנחיית מצב off המקורית. ברירת מחדל: 1.0 (מתקדם, אופציונלי) | FLOAT | לא | 0.0 עד 100.0 |

הערה: אם `abc` ריק או מכיל רק רווחים, הבחירה ב-`mode` מתעלמת ומשתמשים אוטומטית במצב off.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `CONDITIONING` | התניה אקוסטית שנוצרה מטוקני המוזיקה. | CONDITIONING |
| `seconds` | משך האודיו שנוצר בשניות. ספקו ערך זה לצומת Empty YuE2 Latent Audio. | FLOAT |
