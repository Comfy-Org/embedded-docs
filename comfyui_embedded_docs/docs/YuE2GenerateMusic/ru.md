# YuE2 Генерация музыки

Генерирует музыкальные токены и акустическое кондиционирование на основе стиля, текста песни и нотации ABC. Возвращает кондиционирование и сгенерированную длительность в секундах, которую следует передать узлу Empty YuE2 Latent Audio. Если вход `abc` оставить пустым, выбранный режим игнорируется и автоматически используется режим off.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации и кодирования музыкальных входных данных. | CLIP | Да | - |
| `style` | Текст, описывающий музыкальный стиль. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Многострочный текст |
| `lyrics` | Текст песни для сгенерированной музыки. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Многострочный текст |
| `abc` | Подключите генератор ABC или укажите отредактированную партитуру. Оставьте пустым, чтобы автоматически использовать режим off. по умолчанию: "" | STRING | Да | Многострочный текст |
| `seed` | Случайное зерно для генерации. по умолчанию: 0 | INT | Да | от 0 до 18446744073709551615 |
| `mode` | full: генерирует мелодию и аккорды; melody: генерирует только мелодию, рекомендуется для каверов. по умолчанию: "full" | COMBO | Да | "full"<br>"melody" |
| `max_duration` | Максимальная длительность в секундах. Автоматически уменьшается для длинных промптов; генерация может остановиться раньше. по умолчанию: 360.0 | FLOAT | Да | от 0.04 до 900.0 |
| `temperature` | Температура сэмплирования для генерации. по умолчанию: 1.0 (расширенный) | FLOAT | Да | от 0.0 до 5.0 |
| `top_p` | Порог вероятности нуклеарной выборки. по умолчанию: 0.95 (расширенный) | FLOAT | Да | от 0.01 до 1.0 |
| `top_k` | Ограничение top-k выборки. по умолчанию: 100 (расширенный) | INT | Да | от 1 до 32768 |
| `repetition_penalty` | Штраф, применяемый к повторяющимся токенам. по умолчанию: 1.2 (расширенный) | FLOAT | Да | от 0.01 до 10.0 |

Примечание: Если `abc` пуст или содержит только пробельные символы, выбор `mode` игнорируется и автоматически используется режим off.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Акустическое кондиционирование, сгенерированное из музыкальных токенов. | CONDITIONING |
| `seconds` | Длительность сгенерированного аудио в секундах. Передайте это значение узлу Empty YuE2 Latent Audio. | FLOAT |
