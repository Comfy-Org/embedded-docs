# YuE2 Генерация музыки

Генерирует музыкальные токены и акустическое кондиционирование на основе стиля, текста песни и ABC-нотации. Возвращает кондиционирование и сгенерированную длительность в секундах, которые следует передать в узел Empty YuE2 Latent Audio. Если вход ABC оставить пустым, выбранный режим игнорируется, и автоматически используется режим off.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | CLIP-модель, используемая для токенизации и кодирования музыкальных входов. | CLIP | Да | - |
| `стиль` | Текст, описывающий музыкальный стиль. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Многострочный текст |
| `текст песни` | Текст песни для генерируемой музыки. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Многострочный текст |
| `abc` | Подключите генератор ABC или предоставьте отредактированную партитуру. Оставьте пустым, чтобы автоматически использовать режим off. по умолчанию: "" | STRING | Да | Многострочный текст |
| `seed` | Случайное зерно для генерации. по умолчанию: 0 | INT | Да | 0 до 18446744073709551615 |
| `режим` | full: генерирует мелодию и аккорды; melody: генерирует только мелодию, рекомендуется для кавер-версий. по умолчанию: "full" | COMBO | Да | "full"<br>"melody" |
| `max_duration` | Максимальная длительность в секундах. Автоматически уменьшается для длинных промптов; генерация может остановиться раньше. по умолчанию: 360.0 | FLOAT | Да | 0.04 до 900.0 |
| `температура` | Температура сэмплирования для генерации. по умолчанию: 1.0 (расширенный) | FLOAT | Да | 0.0 до 5.0 |
| `top_p` | Порог вероятности ядерной выборки. по умолчанию: 0.95 (расширенный) | FLOAT | Да | 0.01 до 1.0 |
| `top_k` | Ограничение выборки top-k. по умолчанию: 100 (расширенный) | INT | Да | 1 до 32768 |
| `repetition_penalty` | Штраф, применяемый к повторяющимся токенам. по умолчанию: 1.2 (расширенный) | FLOAT | Да | 0.01 до 10.0 |
| `cfg_scale` | Авторегрессионное управление для стиля и текста песни. Значение 1.0 отключает CFG, что соответствует рабочему процессу ABC. Используйте 1.01, чтобы соответствовать исходному управлению в режиме off. по умолчанию: 1.0 (расширенный, необязательный) | FLOAT | Нет | 0.0 до 100.0 |

Примечание: Если `abc` пуст или содержит только пробельные символы, выбор `mode` игнорируется, и автоматически используется режим off.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Акустическое кондиционирование, сгенерированное из музыкальных токенов. | CONDITIONING |
| `seconds` | Сгенерированная длительность аудио в секундах. Передайте это значение в узел Empty YuE2 Latent Audio. | FLOAT |
