# تولید موسیقی YuE2

تولید توکن‌های موسیقی و شرطی‌سازی آکوستیک از سبک، متن ترانه و نت‌نویسی ABC. شرطی‌سازی و مدت‌زمان تولیدشده را بر حسب ثانیه برمی‌گرداند که باید به گره Empty YuE2 Latent Audio داده شود. اگر ورودی ABC خالی گذاشته شود، حالت انتخاب‌شده نادیده گرفته می‌شود و به‌طور خودکار از حالت off استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌سازی و رمزگذاری ورودی‌های موسیقی استفاده می‌شود. | CLIP | بله | - |
| `style` | متنی که سبک موسیقی را توصیف می‌کند. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `lyrics` | متن ترانه برای موسیقی تولیدشده. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `abc` | مولد ABC را متصل کنید یا یک نت ویرایش‌شده ارائه دهید. برای استفاده خودکار از حالت off، خالی بگذارید. پیش‌فرض: "" | STRING | بله | متن چندخطی |
| `seed` | دانه تصادفی برای تولید. پیش‌فرض: 0 | INT | بله | 0 تا 18446744073709551615 |
| `mode` | full: ملودی و آکورد تولید می‌کند؛ melody: فقط ملودی تولید می‌کند، برای کاورها توصیه می‌شود. پیش‌فرض: "full" | COMBO | بله | "full"<br>"melody" |
| `max_duration` | حداکثر مدت‌زمان بر حسب ثانیه. برای پرامپت‌های طولانی به‌طور خودکار کاهش می‌یابد؛ تولید می‌تواند زودتر متوقف شود. پیش‌فرض: 360.0 | FLOAT | بله | 0.04 تا 900.0 |
| `temperature` | دمای نمونه‌گیری برای تولید. پیش‌فرض: 1.0 (پیشرفته) | FLOAT | بله | 0.0 تا 5.0 |
| `top_p` | آستانه احتمال نمونه‌گیری هسته‌ای. پیش‌فرض: 0.95 (پیشرفته) | FLOAT | بله | 0.01 تا 1.0 |
| `top_k` | محدودیت نمونه‌گیری top-k. پیش‌فرض: 100 (پیشرفته) | INT | بله | 1 تا 32768 |
| `repetition_penalty` | جریمه اعمال‌شده روی توکن‌های تکراری. پیش‌فرض: 1.2 (پیشرفته) | FLOAT | بله | 0.01 تا 10.0 |

نکته: اگر `abc` خالی باشد یا فقط شامل فاصله باشد، انتخاب `mode` نادیده گرفته می‌شود و به‌طور خودکار از حالت off استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `CONDITIONING` | شرطی‌سازی آکوستیک تولیدشده از توکن‌های موسیقی. | CONDITIONING |
| `seconds` | مدت‌زمان صدای تولیدشده بر حسب ثانیه. این مقدار را به گره Empty YuE2 Latent Audio بدهید. | FLOAT |
