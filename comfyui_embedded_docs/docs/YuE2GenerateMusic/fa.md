# تولید موسیقی YuE2

توکن‌های موسیقی و شرطی‌سازی آکوستیک را از روی سبک، متن ترانه و نمادگذاری ABC تولید می‌کند. شرطی‌سازی و مدت‌زمان تولیدشده را بر حسب ثانیه برمی‌گرداند، که باید به گره Empty YuE2 Latent Audio داده شود. اگر ورودی ABC خالی بماند، حالت انتخاب‌شده نادیده گرفته می‌شود و حالت off به‌طور خودکار استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌سازی و رمزگذاری ورودی‌های موسیقی استفاده می‌شود. | CLIP | بله | - |
| `style` | متن توصیف‌کننده سبک موسیقی. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `lyrics` | متن ترانه برای موسیقی تولیدشده. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `abc` | مولد ABC را متصل کنید یا یک پارتیتور ویرایش‌شده وارد کنید. برای استفاده خودکار از حالت off خالی بگذارید. پیش‌فرض: "" | STRING | بله | متن چندخطی |
| `seed` | seed تصادفی برای تولید. پیش‌فرض: 0 | INT | بله | 0 تا 18446744073709551615 |
| `mode` | full: ملودی و آکوردها را تولید می‌کند؛ melody: فقط ملودی را تولید می‌کند، برای کاورها توصیه می‌شود. پیش‌فرض: "full" | COMBO | بله | "full"<br>"melody" |
| `max_duration` | حداکثر مدت بر حسب ثانیه. برای پرامپت‌های طولانی به‌طور خودکار کاهش می‌یابد؛ تولید می‌تواند زودتر متوقف شود. پیش‌فرض: 360.0 | FLOAT | بله | 0.04 تا 900.0 |
| `temperature` | دمای نمونه‌گیری برای تولید. پیش‌فرض: 1.0 (پیشرفته) | FLOAT | بله | 0.0 تا 5.0 |
| `top_p` | آستانه احتمال نمونه‌گیری هسته‌ای. پیش‌فرض: 0.95 (پیشرفته) | FLOAT | بله | 0.01 تا 1.0 |
| `top_k` | محدودیت نمونه‌گیری top-k. پیش‌فرض: 100 (پیشرفته) | INT | بله | 1 تا 32768 |
| `repetition_penalty` | جریمه اعمال‌شده به توکن‌های تکراری. پیش‌فرض: 1.2 (پیشرفته) | FLOAT | بله | 0.01 تا 10.0 |

توجه: اگر `abc` خالی باشد یا فقط فاصله و کاراکترهای سفید داشته باشد، انتخاب `mode` نادیده گرفته می‌شود و حالت off به‌طور خودکار استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `CONDITIONING` | شرطی‌سازی آکوستیک تولیدشده از توکن‌های موسیقی. | CONDITIONING |
| `seconds` | مدت‌زمان صوتی تولیدشده بر حسب ثانیه. این مقدار را به گره Empty YuE2 Latent Audio بدهید. | FLOAT |
