# تولید موسیقی YuE2

توکن‌های موسیقی و شرطی‌سازی آکوستیک را از سبک، متن ترانه و نت‌نگاری ABC تولید می‌کند. شرطی‌سازی و مدت‌زمان تولیدشده را بر حسب ثانیه برمی‌گرداند، که باید به گره Empty YuE2 Latent Audio داده شود. اگر ورودی ABC خالی گذاشته شود، حالت انتخاب‌شده نادیده گرفته می‌شود و حالت off به‌طور خودکار استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌ایز و رمزگذاری ورودی‌های موسیقی استفاده می‌شود. | CLIP | بله | - |
| `سبک` | متنی که سبک موسیقی را توصیف می‌کند. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `متن ترانه` | متن ترانه برای موسیقی تولیدشده. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `abc` | مولد ABC را متصل کنید یا یک نت ویرایش‌شده وارد کنید. برای استفاده خودکار از حالت off، خالی بگذارید. پیش‌فرض: "" | STRING | بله | متن چندخطی |
| `بذر` | بذر تصادفی برای تولید. پیش‌فرض: 0 | INT | بله | 0 تا 18446744073709551615 |
| `حالت` | full: ملودی و آکوردها را تولید می‌کند؛ melody: فقط ملودی را تولید می‌کند و برای کاورها توصیه می‌شود. پیش‌فرض: "full" | COMBO | بله | "full"<br>"melody" |
| `max_duration` | حداکثر مدت‌زمان بر حسب ثانیه. برای پرامپت‌های طولانی به‌طور خودکار کاهش می‌یابد؛ تولید می‌تواند زودتر متوقف شود. پیش‌فرض: 360.0 | FLOAT | بله | 0.04 تا 900.0 |
| `temperature` | دمای نمونه‌برداری برای تولید. پیش‌فرض: 1.0 (پیشرفته) | FLOAT | بله | 0.0 تا 5.0 |
| `top_p` | آستانه احتمال نمونه‌برداری هسته‌ای. پیش‌فرض: 0.95 (پیشرفته) | FLOAT | بله | 0.01 تا 1.0 |
| `top_k` | محدودیت نمونه‌برداری top-k. پیش‌فرض: 100 (پیشرفته) | INT | بله | 1 تا 32768 |
| `repetition_penalty` | جریمه اعمال‌شده بر توکن‌های تکراری. پیش‌فرض: 1.2 (پیشرفته) | FLOAT | بله | 0.01 تا 10.0 |
| `cfg_scale` | راهنمای خودرگرسیونی برای سبک و متن ترانه. مقدار 1.0، CFG را غیرفعال می‌کند و با گردش‌کار ABC مطابقت دارد. برای مطابقت با راهنمای اصلی حالت off از 1.01 استفاده کنید. پیش‌فرض: 1.0 (پیشرفته، اختیاری) | FLOAT | خیر | 0.0 تا 100.0 |

توجه: اگر `abc` خالی باشد یا فقط شامل فاصله/فضای خالی باشد، انتخاب `mode` نادیده گرفته می‌شود و حالت off به‌طور خودکار استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `CONDITIONING` | شرطی‌سازی آکوستیک تولیدشده از توکن‌های موسیقی. | CONDITIONING |
| `seconds` | مدت‌زمان صدای تولیدشده بر حسب ثانیه. این مقدار را به گره Empty YuE2 Latent Audio بدهید. | FLOAT |
