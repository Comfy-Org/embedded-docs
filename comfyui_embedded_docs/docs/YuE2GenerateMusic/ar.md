# YuE2 توليد الموسيقى

ينشئ رموزًا موسيقية وتكييفًا صوتيًا من نمط وكلمات وتدوين ABC. يعيد التكييف والمدة المولّدة بالثواني، والتي ينبغي تمريرها إلى عقدة Empty YuE2 Latent Audio. إذا تُرك إدخال ABC فارغًا، يُتجاهل الوضع المحدد ويُستخدم وضع الإيقاف تلقائيًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لتقسيم المدخلات الموسيقية إلى رموز وتشفيرها. | CLIP | نعم | - |
| `النمط` | نص يصف النمط الموسيقي. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | نص متعدد الأسطر |
| `كلمات الأغنية` | كلمات الموسيقى المولّدة. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | نص متعدد الأسطر |
| `abc` | اربط مولّد ABC أو قدّم نوتة موسيقية معدّلة. اتركه فارغًا لاستخدام وضع الإيقاف تلقائيًا. القيمة الافتراضية: "" | STRING | نعم | نص متعدد الأسطر |
| `البذرة` | بذرة عشوائية للتوليد. القيمة الافتراضية: 0 | INT | نعم | 0 إلى 18446744073709551615 |
| `الوضع` | full: يولّد اللحن والكوردات؛ melody: يولّد اللحن فقط، ويُوصى به لأعمال الكوفر. القيمة الافتراضية: "full" | COMBO | نعم | "full"<br>"melody" |
| `max_duration` | الحد الأقصى للمدة بالثواني. يُقلل تلقائيًا للمطالبات الطويلة؛ يمكن أن يتوقف التوليد مبكرًا. القيمة الافتراضية: 360.0 | FLOAT | نعم | 0.04 إلى 900.0 |
| `درجة الحرارة` | درجة حرارة أخذ العينات للتوليد. القيمة الافتراضية: 1.0 (متقدم) | FLOAT | نعم | 0.0 إلى 5.0 |
| `top_p` | عتبة احتمال أخذ العينات النووي. القيمة الافتراضية: 0.95 (متقدم) | FLOAT | نعم | 0.01 إلى 1.0 |
| `top_k` | حد أخذ العينات top-k. القيمة الافتراضية: 100 (متقدم) | INT | نعم | 1 إلى 32768 |
| `repetition_penalty` | عقوبة تُطبّق على الرموز المتكررة. القيمة الافتراضية: 1.2 (متقدم) | FLOAT | نعم | 0.01 إلى 10.0 |
| `cfg_scale` | توجيه انحداري تلقائي للنمط والكلمات. القيمة 1.0 تعطّل CFG، بما يطابق سير عمل ABC. استخدم 1.01 لمطابقة توجيه وضع الإيقاف الأصلي. القيمة الافتراضية: 1.0 (متقدم، اختياري) | FLOAT | لا | 0.0 إلى 100.0 |

ملاحظة: إذا كان `abc` فارغًا أو يحتوي على مسافات بيضاء فقط، يتم تجاهل اختيار `mode` ويُستخدم وضع الإيقاف تلقائيًا.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `CONDITIONING` | التكييف الصوتي المولّد من رموز الموسيقى. | CONDITIONING |
| `seconds` | مدة الصوت المولّد بالثواني. مرّر هذه القيمة إلى عقدة Empty YuE2 Latent Audio. | FLOAT |
