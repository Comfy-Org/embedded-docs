# YuE2 توليد الموسيقى

تولّد رموز الموسيقى وتهيئة صوتية من نمط وكلمات أغنية وتدوين ABC. تُرجع التهيئة والمدة المولّدة بالثواني، والتي ينبغي تمريرها إلى عقدة Empty YuE2 Latent Audio. إذا تُرك مدخل ABC فارغًا، يتم تجاهل الوضع المحدد ويُستخدم وضع off تلقائيًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لتحويل مدخلات الموسيقى إلى رموز وترميزها. | CLIP | نعم | - |
| `النمط` | نص يصف النمط الموسيقي. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | نص متعدد الأسطر |
| `كلمات الأغنية` | كلمات الأغنية للموسيقى المولّدة. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | نص متعدد الأسطر |
| `abc` | وصّل مولّد ABC أو وفّر نوتة موسيقية معدلة. اتركه فارغًا لاستخدام وضع off تلقائيًا. الافتراضي: "" | STRING | نعم | نص متعدد الأسطر |
| `البذرة` | بذرة عشوائية للتوليد. الافتراضي: 0 | INT | نعم | 0 إلى 18446744073709551615 |
| `الوضع` | full: يولّد اللحن والكوردات؛ melody: يولّد اللحن فقط، ويُوصى به لأغاني الكوفر. الافتراضي: "full" | COMBO | نعم | "full"<br>"melody" |
| `max_duration` | أقصى مدة بالثواني. يتم تقليلها تلقائيًا للمطالبات الطويلة؛ ويمكن أن يتوقف التوليد مبكرًا. الافتراضي: 360.0 | FLOAT | نعم | 0.04 إلى 900.0 |
| `درجة الحرارة` | درجة حرارة أخذ العينات للتوليد. الافتراضي: 1.0 (متقدم) | FLOAT | نعم | 0.0 إلى 5.0 |
| `top_p` | عتبة احتمال أخذ العينات النووية. الافتراضي: 0.95 (متقدم) | FLOAT | نعم | 0.01 إلى 1.0 |
| `top_k` | حد أخذ العينات Top-k. الافتراضي: 100 (متقدم) | INT | نعم | 1 إلى 32768 |
| `repetition_penalty` | عقوبة تُطبّق على الرموز المتكررة. الافتراضي: 1.2 (متقدم) | FLOAT | نعم | 0.01 إلى 10.0 |

ملاحظة: إذا كان `abc` فارغًا أو يحتوي على مسافات بيضاء فقط، يتم تجاهل اختيار `mode` ويُستخدم وضع off تلقائيًا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `CONDITIONING` | تهيئة صوتية مولّدة من رموز الموسيقى. | CONDITIONING |
| `seconds` | مدة الصوت المولّد بالثواني. مرّر هذه القيمة إلى عقدة Empty YuE2 Latent Audio. | FLOAT |
