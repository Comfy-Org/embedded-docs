# Загрузить кондиционирование

Этот узел загружает conditioning, ранее сохранённый с помощью узла Save Conditioning, или любой файл safetensors, содержащий тензор `conditioning`, из папки embeddings. Он также восстанавливает все дополнительные параметры и значения нумерованных списков, сохранённые вместе с conditioning.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `conditioning_name` | Файл для загрузки из папки embeddings. Список вариантов формируется из файлов, доступных в этой папке в данный момент. | COMBO | Да | Все файлы в папке embeddings |

**Примечание:** Выбранный файл должен содержать тензор `conditioning`. Все дополнительные ключи, сохранённые в файле, восстанавливаются: нумерованные ключи (например, `key.0`, `key.1`) группируются обратно в упорядоченные списки, а остальные ключи восстанавливаются как простые параметры. Дополнительные параметры считываются из метаданных `conditioning_options` файла, если они присутствуют.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Conditioning, загруженный из файла, вместе с восстановленными параметрами. | CONDITIONING |
