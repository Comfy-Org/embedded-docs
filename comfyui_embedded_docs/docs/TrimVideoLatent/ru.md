# TrimVideoLatent

Узел TrimVideoLatent удаляет кадры из начала латентного представления видео. Он принимает латентный видеосэмпл и отсекает указанное количество кадров с начала, возвращая оставшуюся часть видео. Это позволяет укоротить видеопоследовательности за счёт удаления начальных кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Входное латентное представление видео, содержащее кадры, которые требуется обрезать | LATENT | Да | - |
| `обрезать_на` | Количество кадров для удаления с начала видео (по умолчанию: 0) | INT | Да | от 0 до 99999 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Обрезанное латентное представление видео, из начала которого удалено указанное количество кадров | LATENT |
