# TrimVideoLatent

Узел TrimVideoLatent удаляет кадры из начала латентного представления видео. Он принимает латентный видео-сэмпл и отсекает указанное количество кадров с начала, возвращая оставшуюся часть видео. Это позволяет сократить видео последовательности за счёт удаления начальных кадров.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Входное латентное представление видео, содержащее кадры, которые необходимо обрезать | LATENT | Да | - |
| `trim_amount` | Количество кадров, которые нужно удалить с начала видео (по умолчанию: 0) | INT | Да | 0 to 99999 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Обрезанное латентное представление видео с удалённым указанным количеством кадров с начала | LATENT |
