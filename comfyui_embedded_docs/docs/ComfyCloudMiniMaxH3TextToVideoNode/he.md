# Comfy Cloud MiniMax H3 טקסט לווידאו [BETA]

מריץ את זרימת העבודה לטקסט-לווידאו של MiniMax H3 על GPU של Comfy Cloud ומחזיר וידאו עם פס קול תואם. התמונה והשמע מופקים באותו מעבר במקום להיות מדובבים בדיעבד. זהו צומת בטא, והחיוב הוא לפי שניות GPU.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `פרומפט` | תיאור הטקסט של הווידאו, כולל הצלילים שהשוט אמור לשאת. רווחים בתחילת הטקסט ובסופו מוסרים לפני השליחה. | STRING | כן | 1 עד 4096 תווים |
| `seed` | זרע אקראי שקובע את התוצאה שנוצרה (ברירת מחדל: 42). | INT | כן | 0 עד 18446744073709551615 |
| `aspect_ratio` | יחס רוחב-גובה של הווידאו שנוצר (ברירת מחדל: `"16:9"`). | COMBO | כן | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `resolution` | תקציב גודל פריים (ברירת מחדל: `"480p"`). 720p עולה בערך פי שניים בשניות GPU לעומת 480p. | COMBO | כן | `"480p"`<br>`"720p"` |
| `duration_seconds` | אורך בשניות (ברירת מחדל: 5). הצינור מכמת לצעדים של 17 פריימים בקצב של 24 fps, כך שהקליפ יהיה בסטייה של כשני שלישי שנייה מהערך הזה. | INT | כן | 5 עד 15 |
