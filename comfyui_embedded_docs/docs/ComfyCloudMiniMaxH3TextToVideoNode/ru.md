# Comfy Cloud MiniMax H3: текст в видео [БЕТА]

Запускает рабочий процесс преобразования текста в видео MiniMax H3 на GPU Comfy Cloud и возвращает видео с соответствующей звуковой дорожкой. Видео и звук создаются за один проход, а не накладываются позднее. Это бета-узел, тарификация ведётся по секундам GPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовое описание видео, включая звуки, которые должны сопровождать сцену. Пробельные символы в начале и конце удаляются перед отправкой. | STRING | Да | от 1 до 4096 символов |
| `сид` | Случайное зерно, управляющее сгенерированным результатом (по умолчанию: 42). | INT | Да | от 0 до 18446744073709551615 |
| `соотношение сторон` | Соотношение сторон сгенерированного видео (по умолчанию: `"16:9"`). | COMBO | Да | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `разрешение` | Ограничение размера кадра (по умолчанию: `"480p"`). 720p требует примерно вдвое больше GPU-секунд, чем 480p. | COMBO | Да | `"480p"`<br>`"720p"` |
| `длительность в секундах` | Длительность в секундах (по умолчанию: 5). Конвейер разбивает длительность на шаги по 17 кадров при 24 кадрах/с, поэтому фактическая длительность клипа будет отличаться от указанного значения не более чем примерно на две трети секунды. | INT | Да | от 5 до 15 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуковой дорожкой. | VIDEO |
