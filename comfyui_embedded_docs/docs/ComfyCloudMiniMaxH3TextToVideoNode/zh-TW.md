# Comfy Cloud MiniMax H3 文字轉影片 [BETA]

在 Comfy Cloud GPU 上執行 MiniMax H3 文字轉影片工作流程，並回傳附有對應配樂的影片。畫面與音訊在同一次生成中一併產出，而非事後再另行配音。此節點為 Beta 版本，依 GPU 秒數計費。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |

| `提示詞` | 影片的文字描述，包含該鏡頭應帶有的聲音。提交前會移除開頭與結尾的空白字元。 | STRING | 是 | 1 至 4096 個字元 |
| `種子` | 控制生成結果的隨機種子（預設值：42）。 | INT | 是 | 0 至 18446744073709551615 |
| `長寬比` | 生成影片的長寬比（預設值：`"16:9"`）。 | COMBO | 是 | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `解析度` | 畫面尺寸額度（預設值：`"480p"`）。720p 所耗費的 GPU 秒數約為 480p 的兩倍。 | COMBO | 是 | `"480p"`<br>`"720p"` |
