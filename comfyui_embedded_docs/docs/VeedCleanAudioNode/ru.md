# VEED Clean Audio

Удаляйте фоновый шум из речи с помощью VEED. Инструмент создан для речи на любом языке: шум под голосом очищается, паузы очищаются полностью, а музыка и звуковые эффекты удаляются, а не сохраняются. На выходе — моноаудио 48 кГц.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Запись речи длительностью менее 30 минут. | AUDIO | Да | До 1799 секунд |
| `strength` | Насколько сильно удаляется шум под речью. Меньшие значения сохраняют больше фонового шума помещения за голосом; паузы между словами всегда очищаются полностью, а значения выше значения по умолчанию меняют результат незначительно. (по умолчанию: 0.874) | FLOAT | Да | от 0.0 до 1.0 (шаг 0.001) |
| `loudness` | Нормализовать ли громкость выхода. `"normalize"` устанавливает выход на `target_lufs`; `"keep input level"` оставляет уровень без изменений. При выборе опции отображаются её параметры. (по умолчанию: `"normalize"`) | DYNAMIC_COMBO | Да | `"normalize"`<br>`"keep input level"` |
| `target_lufs` | Интегральная громкость выхода в LUFS. Пики ограничиваются на уровне -1.1 dBTP, поэтому при громких целевых значениях нормализация останавливается раньше (около -15 LUFS для типичной речи). Доступно, когда `loudness` имеет значение `"normalize"` (по умолчанию: -19.0). | FLOAT | Да | от -40.0 до -8.0 (шаг 0.1) |

Узел завершается с ошибкой, если запись длиннее 1799 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `AUDIO` | Очищенная речь в виде моноаудио 48 кГц. | AUDIO |
