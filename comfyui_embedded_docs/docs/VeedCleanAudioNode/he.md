# VEED Clean Audio

הסר רעש רקע מדיבור עם VEED. הוא מיועד לדיבור בכל שפה: רעש מתחת לקול מנוקה, הפסקות מנוקות לחלוטין, ומוזיקה ואפקטי קול מוסרים ולא נשמרים. הפלט הוא אודיו מונו ב-48 kHz.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `audio` | הקלטת דיבור, קצרה מ-30 דקות. | AUDIO | כן | עד 1799 שניות |
| `strength` | כמה רעש מוסר מתחת לדיבור. ערך נמוך יותר שומר על יותר רקע חדר מאחורי הקול; הפסקות בין מילים תמיד מנוקות לחלוטין, וערכים מעל ברירת המחדל משנים מעט. (ברירת מחדל: 0.874) | FLOAT | כן | 0.0 עד 1.0 (צעד 0.001) |
| `loudness` | האם לנרמל את עוצמת הפלט. `"normalize"` מגדיר את הפלט ל-`target_lufs`; `"keep input level"` משאיר את העוצמה כפי שהיא. בחירת אפשרות חושפת את הפרמטרים שלה. (ברירת מחדל: `"normalize"`) | DYNAMIC_COMBO | כן | `"normalize"`<br>`"keep input level"` |
| `target_lufs` | עוצמה משולבת של הפלט ב-LUFS. פסגות מוגבלות ל--1.1 dBTP, ולכן יעדי עוצמה גבוהים נעצרים מוקדם (כ--15 LUFS לדיבור טיפוסי). זמין כאשר `loudness` הוא `"normalize"` (ברירת מחדל: -19.0). | FLOAT | כן | -40.0 עד -8.0 (צעד 0.1) |

הצומת נעצר עם שגיאה כאשר ההקלטה ארוכה מ-1799 שניות.
