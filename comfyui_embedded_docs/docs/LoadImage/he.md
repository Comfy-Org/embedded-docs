# טעינת תמונה

צומת LoadImage נועד לטעון ולעבד מראש תמונות מנתיב שצוין. הוא מטפל בפורמטים של תמונות עם מספר פריימים, מיישם טרנספורמציות נדרשות כגון סיבוב בהתבסס על נתוני EXIF, מנרמל ערכי פיקסלים, ובאופן אופציונלי יוצר מסכה עבור תמונות עם ערוץ אלפא. צומת זה חיוני להכנת תמונות לעיבוד או לניתוח נוספים בתוך צינור עיבוד.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | הפרמטר `image` מציין את המזהה של התמונה שיש לטעון ולעבד. הוא חיוני לקביעת הנתיב לקובץ התמונה ובהמשך לטעינת התמונה עבור טרנספורמציה ונרמול. | COMBO[STRING] |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | התמונה המעובדת, עם ערכי פיקסלים מנורמלים וטרנספורמציות מיושמות לפי הצורך. היא מוכנה לעיבוד או לניתוח נוספים. | `IMAGE` |
| `mask` | פלט אופציונלי המספק מסכה עבור התמונה, שימושי בתרחישים שבהם התמונה כוללת ערוץ אלפא לשקיפות. | `MASK` |
