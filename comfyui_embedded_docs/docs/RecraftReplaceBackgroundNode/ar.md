# إعادة صياغة استبدال الخلفية

استبدال خلفية الصورة بناءً على المطالبة المقدمة. تستخدم هذه العقدة واجهة برمجة تطبيقات Recraft لإنشاء خلفيات جديدة لصورك وفقًا لوصفك النصي، مما يتيح لك تحويل الخلفية بالكامل مع الحفاظ على الكائن الرئيسي كما هو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة المراد معالجتها | IMAGE | نعم | - |
| `prompt` | مطالبة توليد الصورة (الافتراضي: فارغ) | STRING | نعم | - |
| `n` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | نعم | 1-6 |
| `seed` | البذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `recraft_style` | اختيار النمط الاختياري للخلفية المولدة. إذا لم يتم توفيره، يتم تعيين النمط الافتراضي إلى "realistic_image" | STYLEV3 | لا | - |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: فارغ) | STRING | لا | - |

**ملاحظة:** تتحكم المعامل `seed` في وقت إعادة تنفيذ العقدة ولكنه لا يضمن نتائج حتمية بسبب طبيعة واجهة البرمجة الخارجية.

**ملاحظة:** تتم معالجة كل صورة في دفعة الإدخال بشكل فردي؛ تُرجع العقدة `n` صورة بعد استبدال الخلفية لكل صورة إدخال.
