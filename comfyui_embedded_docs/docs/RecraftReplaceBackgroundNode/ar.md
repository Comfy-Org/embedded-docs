# إعادة صياغة استبدال الخلفية

استبدال خلفية الصورة بناءً على الموجّه المقدم. تستخدم هذه العقدة واجهة Recraft API لإنشاء خلفيات جديدة لصورك وفقًا لوصفك النصي، ما يتيح لك تغيير الخلفية بالكامل مع الحفاظ على العنصر الرئيسي سليمًا. تُعالج كل صورة في دفعة الإدخال بشكل منفصل، وتُدمج النتائج في دفعة إخراج واحدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المدخلة المراد معالجتها | IMAGE | نعم | - |
| `الوصف` | الموجّه لتوليد الصورة (الافتراضي: فارغ) | STRING | نعم | - |
| `عدد` | عدد الصور المراد توليدها (الافتراضي: 1) | INT | نعم | 1-6 |
| `بذرة` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `نمط إعادة الصياغة` | اختيار نمط اختياري للخلفية المولدة. إذا لم يُقدَّم، فسيتم افتراضيًا إلى نمط "realistic_image" | STYLEV3 | لا | - |
| `الوصف السلبي` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: فارغ) | STRING | لا | - |

**ملاحظات:**
- يتحكم المعامل `seed` في وقت إعادة تنفيذ العقدة، لكنه لا يضمن نتائج حتمية بسبب طبيعة واجهة API الخارجية.
- عندما لا يكون `recraft_style` موصولًا أو يُترك فارغًا، ترجع العقدة إلى نمط `realistic_image`.
- عندما يُترك `negative_prompt` فارغًا، لا يُرسل مع الطلب.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `IMAGE` | الصورة/الصور المولدة مع الخلفية المستبدلة. بالنسبة لكل صورة إدخال، يُحدد عدد النتائج المولدة بواسطة `n`. | IMAGE |
