# إعادة صياغة استبدال الخلفية

استبدال الخلفية في الصورة بناءً على المطالبة المقدمة. تستخدم هذه العقدة واجهة برمجة تطبيقات Recraft لإنشاء خلفيات جديدة لصورك وفقًا لوصفك النصي، مما يتيح لك تحويل الخلفية بالكامل مع الحفاظ على الموضوع الرئيسي دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المدخلة للمعالجة | IMAGE | نعم | - |
| `الوصف` | المطالبة الخاصة بتوليد الصورة (الافتراضي: فارغ) | STRING | نعم | - |
| `عدد` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | نعم | 1-6 |
| `بذرة` | القيمة المبدئية (Seed) لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن القيمة المبدئية (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `نمط إعادة الصياغة` | اختيار نمط اختياري للخلفية المُولّدة. إذا لم يتم توفيره، يكون الافتراضي هو نمط "realistic_image" | STYLEV3 | لا | - |
| `الوصف السلبي` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: فارغ) | STRING | لا | - |

**ملاحظة:** تتحكم المعلمة `seed` في موعد إعادة تنفيذ العقدة ولكنها لا تضمن نتائج حتمية بسبب طبيعة واجهة البرمجة الخارجية.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `IMAGE` | الصورة (الصور) المُولّدة بخلفية مستبدلة. لكل صورة مدخلة، يتم تحديد عدد النتائج المُولّدة بواسطة `n`. | IMAGE |
