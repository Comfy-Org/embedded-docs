# Recraft 背景置換

プロンプトに基づいて画像の背景を置き換えます。このノードは Recraft API を使用して、テキストの説明に応じて画像の新しい背景を生成し、主要な被写体を維持したまま背景を完全に変換できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 処理する入力画像 | IMAGE | はい | - |
| `prompt` | 画像生成のためのプロンプト（デフォルト: 空） | STRING | はい | - |
| `n` | 生成する画像の数（デフォルト: 1） | INT | はい | 1-6 |
| `seed` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0） | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 生成された背景のオプションのスタイル選択。指定しない場合、"realistic_image" スタイルがデフォルトです | STYLEV3 | いいえ | - |
| `negative_prompt` | 画像内の望ましくない要素のオプションのテキスト説明（デフォルト: 空） | STRING | いいえ | - |

**注:** `seed` パラメータはノードが再実行されるタイミングを制御しますが、外部 API の性質上、シードに関係なく決定的な結果を保証するものではありません。

**注:** 入力バッチ内の各画像は個別に処理されます。ノードは、入力画像ごとに `n` 個の背景置換画像を返します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 背景が置き換えられた生成画像 | IMAGE |
