# Recraft Замена Фона

Заменяет фон на изображении на основе предоставленного промпта. Этот узел использует Recraft API для генерации новых фонов для ваших изображений в соответствии с вашим текстовым описанием, позволяя полностью изменить фон, сохраняя основной объект нетронутым.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|-------------|---------|
| `изображение` | Входное изображение для обработки | IMAGE | Да | - |
| `промпт` | Промпт для генерации изображения (по умолчанию: пусто) | STRING | Да | - |
| `n` | Количество генерируемых изображений (по умолчанию: 1) | INT | Да | 1-6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерируемого фона. Если не указан, по умолчанию используется стиль "realistic_image" | STYLEV3 | Нет | - |
| `негативный_промпт` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: пусто) | STRING | Нет | - |

**Примечание:** Параметр `seed` управляет моментом повторного выполнения узла, но не гарантирует детерминированных результатов из-за особенностей внешнего API.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное(ые) изображение(я) с заменённым фоном. Для каждого входного изображения количество сгенерированных результатов определяется параметром `n`. | IMAGE |
