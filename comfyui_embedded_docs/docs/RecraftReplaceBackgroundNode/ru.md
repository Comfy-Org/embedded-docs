# Recraft Замена Фона

Замена фона на изображении на основе предоставленного запроса. Этот узел использует Recraft API для генерации новых фонов для ваших изображений в соответствии с вашим текстовым описанием, позволяя полностью изменить фон, сохраняя основной объект неизменным.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для обработки | IMAGE | Да | - |
| `prompt` | Текст запроса для генерации изображения (по умолчанию пусто) | STRING | Да | - |
| `n` | Количество изображений для генерации (по умолчанию 1) | INT | Да | 1-6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерируемого фона. Если не указан, по умолчанию используется стиль "realistic_image" | STYLEV3 | Нет | - |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию пусто) | STRING | Нет | - |

**Примечание:** Параметр `seed` управляет моментом повторного выполнения узла, но не гарантирует детерминированных результатов из-за особенностей внешнего API.

**Примечание:** Каждое изображение во входном пакете обрабатывается отдельно; узел возвращает `n` изображений с замененным фоном для каждого входного изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение (изображения) с замененным фоном | IMAGE |
