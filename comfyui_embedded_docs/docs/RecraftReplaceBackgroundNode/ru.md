# Recraft Замена Фона

Заменяет фон на изображении на основе предоставленного промпта. Этот узел использует API Recraft для генерации новых фонов для ваших изображений в соответствии с вашим текстовым описанием, позволяя полностью преобразовать фон, сохранив основной объект нетронутым. Каждое изображение во входном пакете обрабатывается отдельно, а результаты объединяются в один выходной пакет.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для обработки | IMAGE | Да | - |
| `промпт` | Промпт для генерации изображения (по умолчанию: пусто) | STRING | Да | - |
| `n` | Количество изображений для генерации (по умолчанию: 1) | INT | Да | 1-6 |
| `seed` | Параметр, определяющий, должен ли узел выполняться повторно; фактические результаты недетерминированы независимо от seed (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерируемого фона. Если не указан, по умолчанию используется стиль "realistic_image" | STYLEV3 | Нет | - |
| `негативный_промпт` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: пусто) | STRING | Нет | - |

**Примечания:**
- Параметр `seed` управляет тем, когда узел выполняется повторно, но не гарантирует детерминированные результаты из-за особенностей внешнего API.
- Если `recraft_style` не подключён или оставлен пустым, узел использует стиль `realistic_image`.
- Если `negative_prompt` оставлен пустым, он не отправляется с запросом.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированные изображения с заменённым фоном. Для каждого входного изображения количество сгенерированных результатов определяется параметром `n`. | IMAGE |
