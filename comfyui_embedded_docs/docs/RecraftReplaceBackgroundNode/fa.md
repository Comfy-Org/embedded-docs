# جایگزینی پس‌زمینه Recraft

پس‌زمینه تصویر را بر اساس پرامپت ارائه‌شده جایگزین می‌کند. این گره از API Recraft برای تولید پس‌زمینه‌های جدید برای تصاویر شما بر اساس توضیحات متنی‌تان استفاده می‌کند و به شما امکان می‌دهد پس‌زمینه را به‌طور کامل دگرگون کنید و در همان حال سوژه اصلی را دست‌نخورده نگه دارید. هر تصویر در دسته ورودی به‌صورت جداگانه پردازش می‌شود و نتایج در یک دسته خروجی واحد ترکیب می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای پردازش | IMAGE | بله | - |
| `prompt` | پرامپت برای تولید تصویر (پیش‌فرض: خالی) | STRING | بله | - |
| `n` | تعداد تصاویر برای تولید (پیش‌فرض: 1) | INT | بله | 1-6 |
| `seed` | مقدار `seed` برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از `seed` غیرقطعی هستند (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب سبک اختیاری برای پس‌زمینه تولیدشده. اگر ارائه نشود، به‌طور پیش‌فرض روی سبک `realistic_image` قرار می‌گیرد | STYLEV3 | خیر | - |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در یک تصویر (پیش‌فرض: خالی) | STRING | خیر | - |

**یادداشت‌ها:**
- پارامتر `seed` کنترل می‌کند که گره چه زمانی دوباره اجرا شود، اما به دلیل ماهیت API خارجی، نتایج قطعی را تضمین نمی‌کند.
- وقتی `recraft_style` متصل نباشد یا خالی بماند، گره به سبک `realistic_image` بازمی‌گردد.
- وقتی `negative_prompt` خالی بماند، همراه درخواست ارسال نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) تولیدشده با پس‌زمینه جایگزین‌شده. برای هر تصویر ورودی، تعداد نتایج تولیدشده توسط `n` تعیین می‌شود. | IMAGE |
