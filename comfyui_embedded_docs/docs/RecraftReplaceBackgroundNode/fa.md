# جایگزینی پس‌زمینه Recraft

جایگزینی پس‌زمینه تصویر بر اساس پرامپت ارائه‌شده. این گره از Recraft API برای تولید پس‌زمینه‌های جدید برای تصاویر شما طبق توضیحات متنی استفاده می‌کند و به شما امکان می‌دهد پس‌زمینه را کاملاً تغییر دهید در حالی که سوژه اصلی دست‌نخورده باقی می‌ماند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی برای پردازش | IMAGE | بله | - |
| `پرامپت` | پرامپت تولید تصویر (پیش‌فرض: خالی) | STRING | بله | - |
| `تعداد` | تعداد تصاویر برای تولید (پیش‌فرض: 1) | INT | بله | 1-6 |
| `seed` | دانه (Seed) برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `سبک Recraft` | انتخاب سبک اختیاری برای پس‌زمینه تولیدشده. اگر ارائه نشود، به‌صورت پیش‌فرض روی سبک «realistic_image» تنظیم می‌شود | STYLEV3 | خیر | - |
| `پرامپت منفی` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر (پیش‌فرض: خالی) | STRING | خیر | - |

**توجه:** پارامتر `seed` تعیین می‌کند که گره چه زمانی دوباره اجرا شود، اما به دلیل ماهیت API خارجی، نتایج قطعی را تضمین نمی‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) تولیدشده با پس‌زمینه جایگزین‌شده. برای هر تصویر ورودی، تعداد نتایج تولیدشده توسط `n` تعیین می‌شود. | IMAGE |
