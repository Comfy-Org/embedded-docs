# جایگزینی پس‌زمینه Recraft

پس‌زمینه تصویر را بر اساس دستور (prompt) ارائه‌شده جایگزین می‌کند. این گره از Recraft API برای تولید پس‌زمینه‌های جدید برای تصاویر شما با توجه به توصیف متنی‌تان استفاده می‌کند و به شما امکان می‌دهد پس‌زمینه را کاملاً تغییر دهید، در حالی که سوژه اصلی دست‌نخورده باقی می‌ماند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `image` | تصویر ورودی برای پردازش | IMAGE | بله | - |
| `prompt` | دستور (prompt) برای تولید تصویر (پیش‌فرض: خالی) | STRING | بله | - |
| `n` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: 1) | INT | بله | 1-6 |
| `seed` | مقدار seed برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی بدون در نظر گرفتن seed قطعی نیستند (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب سبک اختیاری برای پس‌زمینه تولیدشده. اگر ارائه نشود، به‌صورت پیش‌فرض از سبک "realistic_image" استفاده می‌شود | STYLEV3 | خیر | - |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر (پیش‌فرض: خالی) | STRING | خیر | - |

**نکته:** پارامتر `seed` تعیین می‌کند که گره چه زمانی دوباره اجرا شود، اما به دلیل ماهیت API خارجی، نتایج قطعی را تضمین نمی‌کند.

**نکته:** هر تصویر در دسته ورودی به‌صورت جداگانه پردازش می‌شود؛ گره برای هر تصویر ورودی، `n` تصویر با پس‌زمینه جایگزین‌شده برمی‌گرداند.
