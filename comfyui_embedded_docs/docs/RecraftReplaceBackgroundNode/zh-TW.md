| `提示詞` | 圖像生成的提示詞（預設：空） | STRING | 是 | - |
| `生成數量` | 要生成的圖像數量（預設：1） | INT | 是 | 1-6 |
| `種子值` | 決定節點是否應重新執行的種子；無論種子為何，實際結果都是非確定性的（預設：0） | INT | 是 | 0-18446744073709551615 |
