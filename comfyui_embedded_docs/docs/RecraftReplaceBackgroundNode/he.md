# ריקרפט החלפת רקע

החלפת רקע בתמונה, בהתאם לפרומפט שסופק. צומת זה משתמש ב-API של Recraft כדי ליצור רקעים חדשים עבור התמונות שלך בהתאם לתיאור הטקסטואלי שלך, ומאפשר לך לשנות לחלוטין את הרקע תוך שמירה על הנושא הראשי ללא פגע. כל תמונה באצוות הקלט מעובדת בנפרד, והתוצאות משולבות לאצוות פלט אחת.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט לעיבוד | IMAGE | כן | - |
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: ריק) | STRING | כן | - |
| `n` | מספר התמונות ליצירה (ברירת מחדל: 1) | INT | כן | 1-6 |
| `seed` | Seed לקביעה אם הצומת צריך להתבצע מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 0) | INT | כן | 0-18446744073709551615 |
| `recraft_style` | בחירת סגנון אופציונלית עבור הרקע שנוצר. אם לא סופק, ברירת המחדל היא סגנון "realistic_image" | STYLEV3 | לא | - |
| `negative_prompt` | תיאור טקסטואלי אופציונלי של אלמנטים לא רצויים בתמונה (ברירת מחדל: ריק) | STRING | לא | - |

**הערות:**
- הפרמטר `seed` קובע מתי הצומת מבוצע מחדש, אך אינו מבטיח תוצאות דטרמיניסטיות בשל אופי ה-API החיצוני.
- כאשר `recraft_style` אינו מחובר או נשאר ריק, הצומת חוזר לסגנון `realistic_image`.
- כאשר `negative_prompt` נשאר ריק, הוא אינו נשלח עם הבקשה.
