# Recraft 배경 교체

제공된 프롬프트를 기반으로 이미지의 배경을 교체합니다. 이 노드는 Recraft API를 사용하여 텍스트 설명에 따라 이미지의 새 배경을 생성하므로, 주요 피사체는 그대로 유지하면서 배경을 완전히 변환할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 처리할 입력 이미지 | IMAGE | 예 | - |
| `prompt` | 이미지 생성을 위한 프롬프트 (기본값: 비어 있음) | STRING | 예 | - |
| `n` | 생성할 이미지 수 (기본값: 1) | INT | 예 | 1-6 |
| `seed` | 노드를 다시 실행해야 하는지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다 (기본값: 0) | INT | 예 | 0-18446744073709551615 |
| `recraft_style` | 생성된 배경에 대한 선택적 스타일 선택입니다. 제공되지 않으면 기본적으로 "realistic_image" 스타일로 설정됩니다 | STYLEV3 | 아니요 | - |
| `negative_prompt` | 이미지에서 원하지 않는 요소에 대한 선택적 텍스트 설명 (기본값: 비어 있음) | STRING | 아니요 | - |

**참고:** `seed` 매개변수는 노드가 다시 실행되는 시점을 제어하지만, 외부 API의 특성상 결정적 결과를 보장하지는 않습니다.

**참고:** 입력 배치의 각 이미지는 개별적으로 처리되며, 노드는 입력 이미지 각각에 대해 배경이 교체된 `n`개의 이미지를 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 배경이 교체된 생성된 이미지(들) | IMAGE |
