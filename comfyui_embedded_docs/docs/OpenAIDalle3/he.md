# OpenAIDalle3

יוצר תמונות באופן סינכרוני דרך נקודת הקצה של DALL·E 3 מבית OpenAI. צומת זה מקבל פרומפט טקסטואלי ויוצר תמונות מתאימות באמצעות המודל DALL·E 3 של OpenAI, ומאפשר לציין איכות תמונה, סגנון ומידות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי עבור DALL·E (ברירת מחדל: "") | STRING | כן | - |
| `seed` | טרם מיושם בצד השרת (ברירת מחדל: 0) | INT | לא | 0 עד 2147483647 |
| `quality` | איכות תמונה (ברירת מחדל: "standard") | COMBO | לא | "standard"<br>"hd" |
| `style` | Vivid גורם למודל לנטות ליצירת תמונות היפר-ריאליסטיות ודרמטיות. Natural גורם למודל להפיק תמונות טבעיות יותר ובעלות מראה פחות היפר-ריאליסטי. (ברירת מחדל: "natural") | COMBO | לא | "natural"<br>"vivid" |
| `size` | גודל תמונה (ברירת מחדל: "1024x1024") | COMBO | לא | "1024x1024"<br>"1024x1792"<br>"1792x1024" |
