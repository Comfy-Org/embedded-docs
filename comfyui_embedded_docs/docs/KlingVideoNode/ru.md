# Kling 3.0 Видео

Этот узел создаёт видео с использованием модели Kling V3. Он поддерживает режим text-to-video, при котором видео создаётся из текстового описания, и режим image-to-video, при котором существующее изображение анимируется. Также доступны расширенные функции, такие как создание видеороликов из нескольких сегментов с отдельными промптами для каждой части (раскадровка) и опциональная генерация сопроводительного аудио.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `мульти-шот` | Генерирует серию видеосегментов с отдельными промптами и длительностями. При выборе опции раскадровки появляются дополнительные входы для промпта и длительности каждой раскадровки. | DYNAMIC_COMBO | Да | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `модель` | Модель и настройки генерации. Выбор модели открывает её подпараметры `model.resolution` и `model.aspect_ratio`. | DYNAMIC_COMBO | Да | `"kling-v3"`<br>`"kling-3.0-turbo"` |
| `генерировать аудио` | При включении узел генерирует аудио для видео. Примечание: `"kling-3.0-turbo"` всегда генерирует нативное аудио, поэтому этот переключатель игнорируется для данной модели. По умолчанию — True. | BOOLEAN | Да | True<br>False |
| `seed` | Seed управляет тем, следует ли перезапускать узел; результаты недетерминированы независимо от seed. По умолчанию — 0. | INT | Да | 0–2147483647 |
| `стартовый кадр` | Необязательное изображение начального кадра. При подключении переключает в режим image-to-video. | IMAGE | Нет | - |

| `соотношение сторон` | Соотношение сторон генерируемого видео. Игнорируется в режиме image-to-video. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |

### Входы Multi-shot

**Когда `multi_shot` установлен в `"disabled"`:**

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Основное текстовое описание видео. Должно содержать от 1 до 2500 символов. | STRING | Да | 1–2500 символов |
| `negative_prompt` | Текст, описывающий то, что не должно появляться в видео. Может быть пустым. | STRING | Нет | - |
| `duration` | Длительность видео в секундах. По умолчанию — 5. | INT | Да | 3–15 |

**Когда `multi_shot` установлен в опцию раскадровки (например, `"3 storyboards"`):**

Для каждого сегмента раскадровки N (от 1 до выбранного количества раскадровок) появляются следующие входы:

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Промпт для сегмента раскадровки N. Максимум 512 символов. | STRING | Да | 1–512 символов |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах. По умолчанию — 4. | INT | Да | 1–15 |

**Ограничения и поведение:**

- Режим text-to-video используется, когда `start_frame` не подключён; режим image-to-video используется, когда `start_frame` подключён. В режиме image-to-video параметр `model.aspect_ratio` игнорируется, а входное изображение должно быть не менее 300x300 пикселей с соотношением сторон от 1:2.5 до 2.5:1.
- В режиме раскадровки основные `prompt` и `negative_prompt` не используются. Суммарная длительность всех раскадровок должна составлять от 3 до 15 секунд.
- Для `kling-v3` каждая раскадровка отправляется в API как отдельный сегмент. Для `kling-3.0-turbo` промпты и длительности раскадровок объединяются в единый multi-shot промпт.
- Для `kling-3.0-turbo` параметр `generate_audio` игнорируется, так как эта модель всегда генерирует нативное аудио.

|-------------|-------------|-----------|
