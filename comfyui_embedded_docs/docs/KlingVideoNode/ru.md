# Kling 3.0 Видео

Этот узел генерирует видео с помощью модели Kling V3. Он поддерживает преобразование текста в видео, где видео создается из текстового описания, и преобразование изображения в видео, где анимируется существующее изображение. Он также может создавать многосегментные видео с использованием промптов раскадровки и опционально генерировать аудио.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `мульти-шот` | Генерирует серию видеосегментов с индивидуальными промптами и длительностями. При выборе опции раскадровки появляются дополнительные входы для промпта и длительности каждой раскадровки. | DYNAMIC_COMBO | Да | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `генерировать аудио` | Если включено, узел генерирует аудио для видео. Примечание: `"kling-3.0-turbo"` всегда генерирует собственное аудио, поэтому переключатель аудио игнорируется для этой модели. По умолчанию — True. | BOOLEAN | Да | True<br>False |
| `модель` | Настройки модели и генерации. При выборе модели отображаются её подпараметры разрешения и соотношения сторон. | DYNAMIC_COMBO | Да | `"kling-v3"`<br>`"kling-3.0-turbo"` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. По умолчанию — 0. | INT | Да | 0 до 2147483647 |
| `стартовый кадр` | Необязательное изображение начального кадра. При подключении переключается в режим преобразования изображения в видео. | IMAGE | Нет | - |

### Входы kling-v3

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `разрешение` | Разрешение генерируемого видео. По умолчанию — `"1080p"`. | COMBO | Да | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `соотношение сторон` | Соотношение сторон генерируемого видео. Игнорируется в режиме преобразования изображения в видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |

### Входы kling-3.0-turbo

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `разрешение` | Разрешение генерируемого видео. По умолчанию — `"720p"`. | COMBO | Да | `"1080p"`<br>`"720p"` |
| `соотношение сторон` | Соотношение сторон генерируемого видео. Игнорируется в режиме преобразования изображения в видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |

### Входы для нескольких сцен

**Когда `multi_shot` установлен в `"disabled"`:**

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Основное текстовое описание для видео. Должно быть от 1 до 2500 символов. | STRING | Да | 1 до 2500 characters |
| `negative_prompt` | Текст, описывающий, что не должно появляться в видео. Можно оставить пустым. | STRING | Нет | - |
| `duration` | Длительность видео в секундах. По умолчанию — 5. | INT | Да | 3 до 15 |

**Когда `multi_shot` установлен в опцию раскадровки (например, `"3 storyboards"`):**

Для каждого сегмента раскадровки N (от 1 до выбранного количества раскадровок) появляются следующие входы:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Промпт для сегмента раскадровки N. Максимум 512 символов. | STRING | Да | 1 до 512 characters |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах. По умолчанию — 4. | INT | Да | 1 до 15 |

**Ограничения и поведение:**

- Режим преобразования текста в видео используется, когда `start_frame` не подключен; режим преобразования изображения в видео используется, когда `start_frame` подключен. В режиме преобразования изображения в видео `model.aspect_ratio` игнорируется, а входное изображение должно быть не менее 300x300 пикселей с соотношением сторон от 1:2.5 до 2.5:1.
- В режиме раскадровки основные `prompt` и `negative_prompt` не используются. Общая сумма всех длительностей раскадровок должна быть от 3 до 15 секунд.
- `negative_prompt` используется только с `kling-v3`; он игнорируется, когда выбран `kling-3.0-turbo`.
- Для `kling-v3` каждая раскадровка отправляется в API как отдельный сегмент. Для `kling-3.0-turbo` промпты и длительности раскадровок объединяются в один мульти-шот промпт.
- Для `kling-3.0-turbo` `generate_audio` игнорируется, так как эта модель всегда генерирует собственное аудио.
