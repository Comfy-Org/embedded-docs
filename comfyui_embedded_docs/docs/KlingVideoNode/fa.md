# Kling 3.0 ویدیو

این گره ویدیوها را با استفاده از مدل Kling V3 تولید می‌کند. از حالت متن‌به‌ویدیو پشتیبانی می‌کند، که در آن ویدیو از روی توضیح متنی ساخته می‌شود، و حالت تصویر‌به‌ویدیو، که در آن یک تصویر موجود به حرکت درمی‌آید. همچنین ویژگی‌های پیشرفته‌ای مانند ایجاد ویدیوهای چندبخشی با پرامپت‌های جداگانه برای هر بخش (استوری‌بورد) و به‌صورت اختیاری تولید صدای همراه را ارائه می‌دهد.

### ورودی‌های چندبخشی

**زمانی که `multi_shot` روی `"disabled"` تنظیم شده باشد:**

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی اصلی برای ویدیو. باید بین 1 تا 2500 کاراکتر باشد. | STRING | بله | 1 تا 2500 کاراکتر |
| `negative_prompt` | متنی که توصیف می‌کند چه چیزی نباید در ویدیو ظاهر شود. می‌توان آن را خالی گذاشت. | STRING | خیر | - |
| `duration` | طول ویدیو بر حسب ثانیه. پیش‌فرض: 5. | INT | بله | 3 تا 15 |

**زمانی که `multi_shot` روی یک گزینه استوری‌بورد تنظیم شده باشد (مثلاً `"3 storyboards"`):**

برای هر بخش استوری‌بورد N (از 1 تا تعداد استوری‌بورد انتخاب‌شده)، ورودی‌های زیر ظاهر می‌شوند:

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | پرامپت برای بخش استوری‌بورد N. حداکثر 512 کاراکتر. | STRING | بله | 1 تا 512 کاراکتر |
| `storyboard_N_duration` | مدت‌زمان بخش استوری‌بورد N بر حسب ثانیه. پیش‌فرض: 4. | INT | بله | 1 تا 15 |

**محدودیت‌ها و رفتار:**

- هنگامی که `start_frame` متصل نباشد، حالت متن‌به‌ویدیو استفاده می‌شود؛ و هنگامی که `start_frame` متصل باشد، حالت تصویر‌به‌ویدیو استفاده می‌شود. در حالت تصویر‌به‌ویدیو، `model.aspect_ratio` نادیده گرفته می‌شود و تصویر ورودی باید حداقل 300×300 پیکسل با نسبت تصویر بین 1:2.5 و 2.5:1 باشد.
- در حالت استوری‌بورد، `prompt` و `negative_prompt` اصلی استفاده نمی‌شوند. مجموع کل مدت‌زمان‌های همه استوری‌بوردها باید بین 3 تا 15 ثانیه باشد.
- برای `kling-v3`، هر استوری‌بورد به‌عنوان یک بخش جداگانه به API ارسال می‌شود. برای `kling-3.0-turbo`، پرامپت‌ها و مدت‌زمان‌های استوری‌بورد در یک پرامپت multi-shot واحد ترکیب می‌شوند.
- برای `kling-3.0-turbo`، `generate_audio` نادیده گرفته می‌شود، زیرا این مدل همیشه صدای همراه تولید می‌کند.
