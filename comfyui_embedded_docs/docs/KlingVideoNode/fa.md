# Kling 3.0 ویدیو

این گره ویدیوها را با استفاده از مدل Kling V3 تولید می‌کند. از حالت متن‌به-ویدیو پشتیبانی می‌کند که در آن ویدیو از روی توضیح متنی ساخته می‌شود، و حالت تصویر-به-ویدیو که در آن یک تصویر موجود به حرکت درمی‌آید. همچنین ویژگی‌های پیشرفه‌ای مانند ایجاد ویدیوهای چندبخشی با prompt جداگانه برای هر بخش (storyboard) و تولید اختیاری صدای هم‌راه را ارائه می‌دهد.

### ورودی‌های چند-بخشی

**هنگامی که `multi_shot` روی `"disabled"` تنظیم شده است:**

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیح متنی اصلی برای ویدیو. باید بین ۱ تا ۲۵۰۰ کاراکتر باشد. | STRING | بله | 1 تا 2500 characters |
| `negative_prompt` | متنی که مشخص می‌کند چه چیزی نباید در ویدیو ظاهر شود. می‌تواند خالی بماند. | STRING | خیر | - |
| `duration` | طول ویدیو به ثانیه. پیش‌فرض: 5 است. | INT | بله | 3 تا 15 |

**هنگامی که `multi_shot` روی یک گزینه استوری‌بورد تنظیم شده است (مثلاً `"3 storyboards"`):**

برای هر بخش استوری‌بورد با شماره N (از ۱ تا تعداد استوری‌بورد انتخاب‌شده)، ورودی‌های زیر ظاهر می‌شوند:

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | prompt برای بخش N استوری‌بورد. حداکثر ۵۱۲ کاراکتر. | STRING | بله | 1 تا 512 characters |
| `storyboard_N_duration` | مدت‌زمان برای بخش N استوری‌بورد به ثانیه. پیش‌فرض: 4 است. | INT | بله | 1 تا 15 |

**محدودیت‌ها و رفتار:**

- حالت متن‌به-ویدیو زمانی استفاده می‌شود که `start_frame` متصل نباشد؛ حالت تصویر-به-ویدیو زمانی استفاده می‌شود که `start_frame` متصل باشد. در حالت تصویر-به-ویدیو، `model.aspect_ratio` نادیده گرفته می‌شود و تصویر ورودی باید حداقل 300x300 پیکسل با نسبت تصویر بین 1:2.5 و 2.5:1 باشد.
- در حالت استوری‌بورد، `prompt` اصلی و `negative_prompt` استفاده نمی‌شوند. مجموع مدت‌زمان همه بخش‌های استوری‌بورد باید بین ۳ تا ۱۵ ثانیه باشد.
- `negative_prompt` فقط با `kling-v3` استفاده می‌شود؛ زمانی که `kling-3.0-turbo` انتخاب شده باشد نادیده گرفته می‌شود.
- برای `kling-v3`، هر استوری‌بورد به‌صورت یک بخش جداگانه به API ارسال می‌شود. برای `kling-3.0-turbo`، promptها و مدت‌زمان‌های استوری‌بورد در یک prompt چند-بخشی واحد ترکیب می‌شوند.
- برای `kling-3.0-turbo`، `generate_audio` نادیده گرفته می‌شود زیرا این مدل همیشه صدای بومی تولید می‌کند.
