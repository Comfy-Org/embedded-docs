# Kling 3.0 视频

此节点使用 Kling V3 模型生成视频。它支持文本转视频模式（根据文本描述创建视频）和图生视频模式（对现有图像进行动画处理）。它还提供高级功能，例如为每个部分（分镜）使用独立提示创建多段视频，以及可选择生成配套音频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `多镜头` | 生成一系列具有独立提示和时长的视频片段。设置为某个分镜选项时，每个分镜的提示和时长对应的附加输入会出现。 | COMBO | 是 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `模型` | 模型和生成设置。选择模型后会显示其 `model.resolution` 和 `model.aspect_ratio` 子参数。 | COMBO | 是 | `"kling-v3"`<br>`"kling-3.0-turbo"` |

### 多镜头输入

**当 `multi_shot` 设置为 `"disabled"` 时：**

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频的主要文本描述。长度必须为 1 到 2500 个字符之间。 | STRING | 是 | 1 到 2500 characters |
| `negative_prompt` | 描述视频中不应出现内容的文本。可以为空。 | STRING | 否 | - |
| `duration` | 视频时长（秒）。默认值为 5。 | INT | 是 | 3 到 15 |

**当 `multi_shot` 设置为某个分镜选项（例如 `"3 storyboards"`）时：**

对于每个分镜片段 N（从 1 到所选分镜数量），会出现以下输入：

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分镜片段 N 的提示。最多 512 个字符。 | STRING | 是 | 1 到 512 characters |
| `storyboard_N_duration` | 分镜片段 N 的时长（秒）。默认值为 4。 | INT | 是 | 1 到 15 |

**限制与行为：**

- 当 `start_frame` 未连接时使用文本转视频模式；当 `start_frame` 已连接时使用图生视频模式。在图生视频模式下，`model.aspect_ratio` 会被忽略，且输入图像必须至少为 300x300 像素，宽高比在 1:2.5 到 2.5:1 之间。
- 在分镜模式下，主 `prompt` 和 `negative_prompt` 不会使用。所有分镜时长的总和必须在 3 到 15 秒之间。
- 对于 `kling-v3`，每个分镜会作为独立片段发送到 API。对于 `kling-3.0-turbo`，分镜提示和时长会合并为单个多镜头提示。
- 对于 `kling-3.0-turbo`，`generate_audio` 会被忽略，因为该模型始终生成原生音频。
