# Kling 3.0 ビデオ

このノードは、Kling V3モデルを使用して動画を生成します。テキスト記述から動画を作成するテキストから動画へのモードと、既存の画像をアニメーション化する画像から動画へのモードをサポートしています。また、各パートに個別のプロンプトを設定して複数セグメントの動画を作成する（ストーリーボード）、付随する音声をオプションで生成するなどの高度な機能も提供します。

### マルチショット入力

**`multi_shot`が`"disabled"`の場合:**

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画のメインテキスト説明です。1〜2500文字である必要があります。 | STRING | はい | 1 から 2500 文字 |
| `negative_prompt` | 動画に表示されるべきでない内容を説明するテキストです。空のままにすることができます。 | STRING | いいえ | - |
| `duration` | 動画の長さ（秒）です。デフォルトは5です。 | INT | はい | 3 から 15 |

**`multi_shot`がストーリーボードオプション（例：`"3 storyboards"`）に設定されている場合:**

各ストーリーボードセグメントN（1から選択したストーリーボード数まで）について、以下の入力が表示されます：

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメントNのプロンプトです。最大512文字です。 | STRING | はい | 1 から 512 文字 |
| `storyboard_N_duration` | ストーリーボードセグメントNの秒単位の長さです。デフォルトは4です。 | INT | はい | 1 から 15 |

**制約と動作:**

- `start_frame`が接続されていない場合はテキストから動画を生成するモード、`start_frame`が接続されている場合は画像から動画を生成するモードが使用されます。画像から動画を生成するモードでは、`model.aspect_ratio`は無視され、入力画像は300x300ピクセル以上で、アスペクト比が1:2.5から2.5:1の範囲である必要があります。
- ストーリーボードモードでは、メインの`prompt`と`negative_prompt`は使用されません。すべてのストーリーボードの長さの合計は3〜15秒である必要があります。
- `kling-v3`の場合、各ストーリーボードは個別のセグメントとしてAPIに送信されます。`kling-3.0-turbo`の場合、ストーリーボードのプロンプトと長さは単一のマルチショットプロンプトに結合されます。
- `kling-3.0-turbo`の場合、このモデルは常にネイティブオーディオを生成するため、`generate_audio`は無視されます。
