# Kling 3.0 影片

此節點使用 Kling V3 模型生成影片。它支援文字轉影片模式（從文字描述建立影片）以及圖片轉影片模式（讓既有圖片產生動態）。此外，它還提供進階功能，例如建立由多段影片片段組成、每個片段各有獨立提示詞的影片（分鏡），以及可選地生成配套音訊。

### Multi-shot 輸入

**當 `multi_shot` 設定為 `"disabled"` 時：**

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |

**當 `multi_shot` 設定為分鏡（storyboard）選項（例如 `"3 storyboards"`）時：**

對於每個分鏡片段 N（從 1 到所選的分鏡數量），會出現以下輸入：

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分鏡片段 N 的提示詞。最多 512 個字元。 | STRING | 是 | 1 至 512 個字元 |
| `storyboard_N_duration` | 分鏡片段 N 的時長（秒）。預設為 4。 | INT | 是 | 1 至 15 |

**限制與行為：**

- 當 `start_frame` 未連線時使用文字轉影片模式；當 `start_frame` 連線時使用圖片轉影片模式。在圖片轉影片模式中，`model.aspect_ratio` 會被忽略，且輸入圖片必須至少為 300x300 像素，長寬比介於 1:2.5 與 2.5:1 之間。
- 在分鏡模式中，主要 `prompt` 和 `negative_prompt` 不會被使用。所有分鏡時長的總和必須介於 3 到 15 秒之間。
- `negative_prompt` 僅在 `kling-v3` 中有效；選用 `kling-3.0-turbo` 時會被忽略。
- 對於 `kling-v3`，每個分鏡會以獨立片段的形式傳送至 API。對於 `kling-3.0-turbo`，分鏡提示詞和時長會組合成單一的多段提示詞。
- 對於 `kling-3.0-turbo`，`generate_audio` 會被忽略，因為此模型始終生成原生音訊。
