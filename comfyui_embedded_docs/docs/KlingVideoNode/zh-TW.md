# Kling 3.0 影片

此節點使用 Kling V3 模型生成影片。它支援文字轉影片模式（從文字描述建立影片）和影像轉影片模式（將現有影像動畫化）。它還提供進階功能，例如建立多段影片，並為每個部分（分鏡）提供獨立提示詞，以及可選擇生成伴隨音訊。

### 多段輸入

**當 `multi_shot` 設定為 `"disabled"` 時：**

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |

**當 `multi_shot` 設定為分鏡選項（例如 `"3 storyboards"`）時：**

對於每個分鏡段 N（從 1 到選定的分鏡數量），會出現以下輸入：

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分鏡段 N 的提示詞。最多 512 個字元。 | STRING | 是 | 1 至 512 characters |
| `storyboard_N_duration` | 分鏡段 N 的時長（以秒為單位）。預設為 4。 | INT | 是 | 1 至 15 |

**約束和行為：**

- 當 `start_frame` 未連線時，使用文字轉影片模式；當 `start_frame` 連線時，使用影像轉影片模式。在影像轉影片模式中，`model.aspect_ratio` 會被忽略，且輸入影像必須至少為 300x300 像素，長寬比介於 1:2.5 和 2.5:1 之間。
- 在分鏡模式中，主要的 `prompt` 和 `negative_prompt` 不會被使用。所有分鏡時長的總和必須介於 3 到 15 秒之間。
- 對於 `kling-v3`，每個分鏡會作為單獨的段傳送給 API。對於 `kling-3.0-turbo`，分鏡提示詞和時長會合併為單一的 multi-shot 提示詞。
- 對於 `kling-3.0-turbo`，`generate_audio` 會被忽略，因為此模型始終生成原生音訊。
