# Kling 3.0 影片

此節點使用 Kling V3 模型生成影片。它支援文字轉影片（從文字描述建立影片）與圖像轉影片（讓現有圖像動起來）。它也可以使用分鏡提示詞建立多片段影片，並可選擇生成音訊。

### 多分鏡輸入

**當 `multi_shot` 設為 `"disabled"` 時：**

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 影片的主要文字描述。長度必須介於 1 到 2500 個字元之間。 | STRING | 是 | 1 至 2500 characters |
| `negative_prompt` | 描述影片中不應出現內容的文字。可以留空。 | STRING | 否 | - |
| `duration` | 影片長度（秒）。預設為 5。 | INT | 是 | 3 至 15 |

**當 `multi_shot` 設為分鏡選項時（例如 `"3 storyboards"`）：**

對於每個分鏡片段 N（從 1 到所選的分鏡數量），會出現下列輸入：

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分鏡片段 N 的提示詞。最多 512 個字元。 | STRING | 是 | 1 至 512 characters |
| `storyboard_N_duration` | 分鏡片段 N 的時長（秒）。預設為 4。 | INT | 是 | 1 至 15 |

**限制與行為：**

- 當未連接 `start_frame` 時，會使用文字轉影片模式；當連接 `start_frame` 時，會使用圖像轉影片模式。在圖像轉影片模式中，`model.aspect_ratio` 會被忽略，且輸入圖像必須至少為 300x300 像素，長寬比介於 1:2.5 與 2.5:1 之間。
- 在分鏡模式中，主要 `prompt` 與 `negative_prompt` 不會被使用。所有分鏡時長的總和必須介於 3 到 15 秒之間。
- `negative_prompt` 僅與 `kling-v3` 搭配使用；選取 `kling-3.0-turbo` 時會忽略它。
- 對於 `kling-v3`，每個分鏡會作為獨立片段傳送至 API。對於 `kling-3.0-turbo`，分鏡提示詞與時長會合併為單一多分鏡提示詞。
- 對於 `kling-3.0-turbo`，`generate_audio` 會被忽略，因為此模型一律生成原生音訊。
