# ModelMergeCosmosPredict2_14B

Узел **ModelMergeCosmosPredict2_14B** объединяет две AI-модели, смешивая их внутренние компоненты. Он обеспечивает точный контроль над степенью влияния каждой части второй модели на итоговый объединённый результат с помощью регулируемых значений весов для конкретных слоёв и компонентов.
