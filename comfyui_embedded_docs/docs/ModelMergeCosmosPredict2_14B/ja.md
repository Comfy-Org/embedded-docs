# モデル統合コスモス予測2_14B

ModelMergeCosmosPredict2_14B ノードは、2 つの AI モデルの内部コンポーネントをブレンドしてマージします。特定のレイヤーとコンポーネントに調整可能な重み値を使用することで、2 番目のモデルの各部分が最終的なマージ結果にどの程度影響するかを正確に制御できます。
