# LTXV Загрузчик аудио VAE

Узел LTXV Audio VAE Loader загружает предварительно обученную модель аудио-вариационного автокодировщика (VAE) из файла контрольной точки. Узел считывает указанную контрольную точку, загружает её веса и метаданные и подготавливает модель к использованию в рабочих процессах генерации или обработки аудио в ComfyUI.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ckpt_name` | Контрольная точка аудио VAE для загрузки. Это раскрывающийся список, заполняемый всеми файлами, найденными в вашей папке `checkpoints` в ComfyUI. | COMBO | Да | Все файлы в папке `checkpoints`. Список формируется во время выполнения. |

Выбранный файл должен быть допустимой контрольной точкой аудио VAE LTXV. Узел сохраняет из файла только веса аудио VAE и вокодера и выдаёт ошибку, если загруженная модель не является допустимой VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `Audio VAE` | Загруженная модель аудио-вариационного автокодировщика (VAE), готовая к подключению к другим узлам обработки аудио. | VAE |
