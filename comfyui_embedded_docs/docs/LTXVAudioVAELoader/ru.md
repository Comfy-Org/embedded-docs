# LTXV Загрузчик аудио VAE

Узел LTXV Audio VAE Loader загружает предварительно обученную модель аудио-вариационного автоэнкодера (VAE) из файла контрольной точки. Он читает указанную контрольную точку, сохраняет веса audio VAE и вокодера и подготавливает модель для использования в рабочих процессах генерации или обработки аудио в ComfyUI.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ckpt_name` | Контрольная точка audio VAE для загрузки. Это раскрывающийся список, заполняемый всеми файлами, найденными в вашем каталоге `checkpoints` ComfyUI. | COMBO | Да | Все файлы в папке `checkpoints`. Список формируется во время выполнения. |

Выбранный файл должен быть допустимой контрольной точкой LTXV audio VAE. Узел сохраняет из файла только веса audio VAE и вокодера и выдаёт ошибку, если загруженная модель не является допустимой VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `Audio VAE` | Загруженная модель аудио-вариационного автоэнкодера, готовая к подключению к другим узлам обработки аудио. | VAE |
