# Flux.1 Kontext [max] Изображение

Создаёт или редактирует изображение с помощью Flux.1 Kontext [max] через BFL API на основе промпта и соотношения сторон. Если `input_image` подключён, промпт описывает редактирование; без него узел создаёт новое изображение только на основе промпта. Узел имеет те же входы, что и Flux.1 Kontext [pro] Image.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Промпт для генерации изображения. При наличии входного изображения укажите, что и как редактировать. | STRING | Да | - |
| `соотношение_сторон` | Соотношение сторон изображения; должно быть в диапазоне от 1:4 до 4:1 (по умолчанию: `"16:9"`). | STRING | Да | - |
| `направление` | Сила guidance для процесса генерации изображения (по умолчанию: 3.0). | FLOAT | Да | 0.1 до 99.0 (шаг: 0.1) |
| `шаги` | Количество шагов для процесса генерации изображения (по умолчанию: 50). | INT | Да | 1 до 150 |
| `сид` | Случайное значение seed, используемое для создания шума (по умолчанию: 1234). | INT | Да | 0 до 18446744073709551615 |
| `апсемплинг_промпта` | Выполнять ли апсемплинг промпта. Если включено, промпт автоматически изменяется для более творческой генерации, но результаты недетерминированы, поэтому одно и то же значение seed не даст в точности одинаковый результат (по умолчанию: `False`). Это расширенная настройка. | BOOLEAN | Да | True / False |
| `входное_изображение` | Необязательное изображение для редактирования. Если не указано, промпт проверяется на непустоту. | IMAGE | Нет | - |

**Примечание:** Узел отправляет запрос в BFL и периодически проверяет статус, пока изображение не будет готово. Запросы, отклонённые модерацией контента BFL, завершаются ошибкой, а не возвращают изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение. | IMAGE |
