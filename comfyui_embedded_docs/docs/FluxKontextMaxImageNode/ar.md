# Flux.1 Kontext [max] Image

تولّد هذه العقدة صورة أو تعدّلها باستخدام Flux.1 Kontext [max] عبر BFL API، بناءً على مطالبة ونسبة أبعاد. عند توصيل `input_image`، تصف المطالبة التعديل؛ ومن دونه، تولّد العقدة صورة جديدة من المطالبة وحدها. تعرض العقدة نفس المدخلات مثل Flux.1 Kontext [pro] Image.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `المطالبة` | المطالبة النصية لتوليد الصورة. عند وجود صورة إدخال، حدّد ما الذي يجب تعديله وكيفية تعديله. | STRING | نعم | - |
| `نسبة_العرض_إلى_الارتفاع` | نسبة أبعاد الصورة؛ يجب أن تكون بين 1:4 و4:1 (الافتراضي: `"16:9"`). | STRING | نعم | - |
| `الإرشاد` | قوة التوجيه لعملية توليد الصورة (الافتراضي: 3.0). | FLOAT | نعم | 0.1 إلى 99.0 (خطوة 0.1) |
| `الخطوات` | عدد الخطوات لعملية توليد الصورة (الافتراضي: 50). | INT | نعم | 1 إلى 150 |
| `البذرة` | البذرة العشوائية المستخدمة لإنشاء الضوضاء (الافتراضي: 1234). | INT | نعم | 0 إلى 18446744073709551615 |
| `رفع_دقة_المطالبة` | ما إذا كان سيتم إجراء تحسين تصاعدي على المطالبة. إذا كان مفعّلًا، يتم تعديل المطالبة تلقائيًا لتحقيق توليد أكثر إبداعًا، لكن النتائج تكون غير حتمية، لذا لن تُنتج البذرة نفسها النتيجة نفسها تمامًا (الافتراضي: `False`). هذا إعداد متقدم. | BOOLEAN | نعم | True / False |
| `الصورة_المدخلة` | صورة اختيارية للتعديل. عند عدم توفيرها، يتم التحقق من المطالبة للتأكد من أنها ليست فارغة. | IMAGE | لا | - |

**ملاحظة:** ترسل العقدة الطلب إلى BFL وتستعلم دوريًا حتى تصبح الصورة جاهزة. تفشل الطلبات التي ترفضها مراجعة المحتوى لدى BFL بدلًا من إرجاع صورة.
