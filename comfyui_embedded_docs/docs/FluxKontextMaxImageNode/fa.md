# Flux.1 Kontext [max] Image

با استفاده از Flux.1 Kontext [max] از طریق BFL API، بر اساس یک پرامپت و نسبت ابعاد، تصویری تولید یا ویرایش می‌کند. در صورت اتصال `input_image`، پرامپت نحوه ویرایش را توصیف می‌کند؛ بدون آن، گره تنها از روی پرامپت تصویری تازه تولید می‌کند. این گره همان ورودی‌های Flux.1 Kontext [pro] Image را ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | پرامپت برای تولید تصویر. در صورت وجود تصویر ورودی، مشخص کنید چه چیزی و چگونه ویرایش شود. | STRING | بله | - |
| `نسبت تصویر` | نسبت ابعاد تصویر؛ باید بین 1:4 و 4:1 باشد (پیش‌فرض: `"16:9"`). | STRING | بله | - |
| `راهنمایی` | قدرت راهنمایی برای فرآیند تولید تصویر (پیش‌فرض: 3.0). | FLOAT | بله | 0.1 تا 99.0 (گام: 0.1) |
| `گام‌ها` | تعداد گام‌های فرآیند تولید تصویر (پیش‌فرض: 50). | INT | بله | 1 تا 150 |
| `بذر` | بذر تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 1234). | INT | بله | 0 تا 18446744073709551615 |
| `افزایش وضوح پرامپت` | اینکه آیا روی پرامپت، بالاسازی (upsampling) انجام شود یا نه. در صورت فعال بودن، پرامپت به‌طور خودکار برای تولید خلاقانه‌تر تغییر می‌کند، اما نتایج غیرقطعی هستند؛ بنابراین همان بذر تصادفی نتیجه دقیقاً یکسانی تولید نمی‌کند (پیش‌فرض: `False`). این تنظیم پیشرفته است. | BOOLEAN | بله | True / False |
| `تصویر ورودی` | تصویر اختیاری برای ویرایش. اگر حذف شود، پرامپت اعتبارسنجی می‌شود تا مطمئن شوند خالی نیست. | IMAGE | خیر | - |

**توجه:** گره درخواست را به BFL می‌فرستد و تا آماده شدن تصویر، به‌طور مکرر وضعیت را بررسی می‌کند. درخواست‌هایی که در پالایش محتوای BFL رد شوند، به‌جای بازگرداندن تصویر، شکست می‌خورند.
