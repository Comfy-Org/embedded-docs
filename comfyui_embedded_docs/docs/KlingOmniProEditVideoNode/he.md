# KlingOmniProEditVideoNode

הצומת Kling Omni Edit Video (Pro) משתמש במודל AI כדי לערוך סרטון קיים בהתבסס על תיאור טקסטואלי. אתם מספקים סרטון מקור ופרומפט, והצומת יוצר סרטון חדש באותו אורך עם השינויים המבוקשים. הוא יכול להשתמש באופן אופציונלי בתמונות עזר כדי להנחות את הסגנון ולשמור על האודיו המקורי מסרטון המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_name` | מודל ה-AI שיש להשתמש בו לעריכת וידאו (ברירת מחדל: `"kling-v3-omni"`). | COMBO | כן | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | הנחיית טקסט המתארת את תוכן הסרטון. היא יכולה לכלול גם תיאורים חיוביים וגם שליליים. | STRING | כן |  |
| `video` | סרטון לעריכה. אורך סרטון הפלט יהיה זהה. | VIDEO | כן |  |
| `keep_original_sound` | קובע אם האודיו המקורי מסרטון הקלט נשמר בפלט (ברירת מחדל: True). | BOOLEAN | כן |  |
| `reference_images` | עד 4 תמונות עזר נוספות. | IMAGE | לא |  |
| `resolution` | הרזולוציה של סרטון הפלט (ברירת מחדל: `"1080p"`). | COMBO | לא | `"1080p"`<br>`"720p"` |
| `seed` | ערך ה-seed קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed (ברירת מחדל: 0). | INT | לא | 0 עד 2147483647 |

**אילוצים ומגבלות:**

* אורך ה-`prompt` חייב להיות בין 1 ל-2500 תווים.
* משך סרטון הקלט `video` חייב להיות בין 3.0 ל-10.05 שניות.
* מידות סרטון הקלט `video` חייבות להיות בין 720x720 ל-2160x2160 פיקסלים.
* ניתן לספק מקסימום 4 `reference_images` כאשר משתמשים בסרטון.
* כל `reference_image` חייב להיות בגודל של לפחות 300x300 פיקסלים.
* יחס הגובה-רוחב של כל `reference_image` חייב להיות בין 1:2.5 ל-2.5:1.
