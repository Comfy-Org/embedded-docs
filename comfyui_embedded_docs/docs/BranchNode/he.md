# Branch

הצומת Branch בוחר באחד מכמה קלטים מחוברים לפי שם ומעביר אותו לפלט. הוא פועל כמתג עצל: רק הענף הנבחר מוערך, כך ששאר הענפים יכולים להישאר לא מחוברים או להחזיק פלטים שאינך רוצה לחשב. כל חיבור חדש מוסיף קלט ענף נוסף, ניתן לשנות את שמות הקלטים בלחיצה כפולה עליהם, והענף הפעיל נבחר מתוך בורר `branch`.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `autogrow` | הענפים המחוברים. כל חיבור מוסיף קלט ענף חדש, עד 32; כל הענפים חייבים להשתמש באותו סוג נתון, והוא הופך לסוג הפלט. | AUTOGROW | כן | 1 עד 32 ענפים |
| `branch` | שם הענף המועבר לפלט. האפשרויות הן שמות קלטי הענפים המחוברים, וניתן לשנות שם של קלט על ידי לחיצה כפולה עליו. | STRING | כן | שמות הענפים המחוברים |
| `branch_names` | רשימה פנימית של שמות הענפים המחוברים, הנשמרת מסונכרנת על ידי ה-frontend. היא ממפה את השם הנבחר לענף שלו ואינה מיועדת לעריכה ידנית. | ARRAY | כן | - |

**הערה:** רק הענף הנבחר מתבקש, ולכן שאר הענפים אינם מוערכים. הצומת מעלה שגיאה כאשר השם הנבחר אינו מחובר.
