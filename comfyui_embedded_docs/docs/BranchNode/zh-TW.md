# Branch

Branch 會依名稱從數個已連接的輸入中選擇一個，並將其傳遞至輸出。它可作為惰性開關：只會評估被選取的分支，因此其他分支可以保持未連接，或保留你不想計算的輸出。每次新增連線都會增加一個分支輸入，輸入可透過雙擊重新命名，而使用中的分支則從 `branch` 選擇器中選擇。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `autogrow` | 已連接的分支。每次連線會新增一個分支輸入，最多 32 個；所有分支必須使用相同的資料類型，該類型會成為輸出類型。 | AUTOGROW | 是 | 1 至 32 個分支 |
| `branch` | 傳遞至輸出的分支名稱。選項為已連接分支輸入的名稱，且輸入可透過雙擊重新命名。 | STRING | 是 | 已連接分支的名稱 |
| `branch_names` | 已連接分支名稱的內部清單，由前端保持同步。它會將選取的名稱對應到其分支，不應手動編輯。 | ARRAY | 是 | - |

**注意：** 只會請求被選取的分支，因此不會評估其他分支。當選取的名稱未連接時，節點會引發錯誤。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
| --- | --- | --- |
| `output` | 所選分支的值，原樣傳遞。 | MATCH_TYPE |
