# Branch

Branch выбирает один из нескольких подключенных входов по имени и передает его на выход. Он работает как ленивый переключатель: вычисляется только выбранная ветвь, поэтому остальные ветви могут оставаться неподключенными или содержать выходы, которые вы не хотите вычислять. Каждое новое подключение добавляет еще один вход ветви; входы можно переименовать двойным щелчком по ним, а активная ветвь выбирается в селекторе `branch`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `autogrow` | Подключенные ветви. Каждое подключение добавляет новый вход ветви, до 32; все ветви должны использовать один и тот же тип данных, который становится типом выхода. | AUTOGROW | Да | от 1 до 32 ветвей |
| `branch` | Имя ветви, передаваемой на выход. Вариантами выбора являются имена подключенных входов ветвей; вход можно переименовать двойным щелчком по нему. | STRING | Да | Имена подключенных ветвей |
| `branch_names` | Внутренний список имен подключенных ветвей, синхронизируемый интерфейсом (frontend). Он сопоставляет выбранное имя с соответствующей ветвью и не предназначен для редактирования вручную. | ARRAY | Да | - |

**Примечание:** Запрашивается только выбранная ветвь, поэтому остальные ветви не вычисляются. Узел выдает ошибку, если выбранное имя не подключено.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Значение выбранной ветви, переданное без изменений. | MATCH_TYPE |
