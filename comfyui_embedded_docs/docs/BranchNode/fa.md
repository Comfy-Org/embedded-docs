# Branch

گره Branch یکی از چندین ورودی متصل را بر اساس نام انتخاب می‌کند و آن را به خروجی منتقل می‌کند. این گره مانند یک سوییچ تنبل عمل می‌کند: فقط شاخه انتخاب‌شده ارزیابی می‌شود، بنابراین سایر شاخه‌ها می‌توانند بدون اتصال بمانند یا خروجی‌هایی را نگه دارند که نمی‌خواهید محاسبه شوند. هر اتصال جدید یک ورودی شاخه دیگر اضافه می‌کند، نام ورودی‌ها با دوبار کلیک کردن روی آن‌ها قابل تغییر است، و شاخه فعال از انتخاب‌گر `branch` برگزیده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `autogrow` | شاخه‌های متصل. هر اتصال یک ورودی شاخه جدید اضافه می‌کند، حداکثر تا ۳۲ ورودی؛ همه شاخه‌ها باید از یک نوع داده یکسان استفاده کنند که همان نوع خروجی می‌شود. | AUTOGROW | بله | ۱ تا ۳۲ شاخه |
| `branch` | نام شاخه‌ای که به خروجی منتقل می‌شود. گزینه‌ها نام ورودی‌های شاخه متصل هستند و نام هر ورودی با دوبار کلیک کردن روی آن قابل تغییر است. | STRING | بله | نام شاخه‌های متصل |
| `branch_names` | فهرست داخلی نام شاخه‌های متصل که توسط فرانت‌اند همگام نگه داشته می‌شود. این فهرست نام انتخاب‌شده را به شاخه مربوطه نگاشت می‌کند و برای ویرایش دستی در نظر گرفته نشده است. | ARRAY | بله | - |

**توجه:** فقط شاخه انتخاب‌شده درخواست می‌شود، بنابراین سایر شاخه‌ها ارزیابی نمی‌شوند. وقتی نام انتخاب‌شده متصل نباشد، گره خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مقدار شاخه انتخاب‌شده که بدون تغییر منتقل می‌شود. | MATCH_TYPE |
