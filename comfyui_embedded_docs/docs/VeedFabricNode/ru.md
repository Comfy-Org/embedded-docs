# VEED Fabric 1.0

Превратите статичное изображение и речевую дорожку в говорящее видео с синхронизацией губ с помощью VEED Fabric. Узел работает с фотографиями, иллюстрациями и маскотами, если лицо хорошо видно; видео сохраняет соотношение сторон изображения и длится столько же, сколько аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель. При выборе модели отображаются специфичные для неё параметры: `image`, `audio` и `resolution`. | DYNAMIC_COMBO | Да | `"fabric-1.0"` |
| `image` | Изображение с чётко видимым лицом. Видео сохраняет его соотношение сторон. | IMAGE | Да | - |
| `audio` | Речь, под которую синхронизируются губы, до 300 секунд. Задаёт длительность видео. | AUDIO | Да | До 300 секунд |
| `resolution` | Класс размера выходного видео: около 0,4 мегапикселя при `"480p"` (864x480 при 16:9) и 0,9 мегапикселя при `"720p"` (1312x736 при 16:9). (по умолчанию: `"720p"`) | COMBO | Да | `"480p"`<br>`"720p"` |

Узел завершается с ошибкой, если речевая дорожка длиннее 300 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `VIDEO` | Говорящее видео: входное изображение, анимированное в соответствии с речевой дорожкой. | VIDEO |
