# 잠재 데이터 연산 (선명화)

LatentOperationSharpen 노드는 가우시안 커널을 사용하여 잠재 표현에 선명화 효과를 적용합니다. 이 노드는 잠재 데이터를 정규화하고, 사용자 정의 선명화 커널로 컨볼루션을 수행한 다음 원래의 휘도를 복원하는 방식으로 작동합니다. 이를 통해 잠재 공간 표현의 디테일과 에지가 향상됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `sharpen_radius` | 선명화 커널의 반지름입니다. 전체 커널 크기는 이 값의 두 배에 1을 더한 값으로 계산됩니다(기본값: 9). | INT | 예 | 1-31 |
| `sigma` | 가우시안 커널의 표준 편차입니다(기본값: 1.0). | FLOAT | 예 | 0.1-10.0 |
| `alpha` | 효과의 강도를 제어하는 선명화 강도 계수입니다(기본값: 0.1). | FLOAT | 예 | 0.0-5.0 |

모든 입력은 고급 매개변수입니다. 이 노드는 실험적 기능으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `operation` | 잠재 데이터에 적용할 수 있는 선명화 연산입니다. 이를 잠재 표현에 적용하면 원래 휘도가 보존된 선명화된 버전을 반환합니다. | LATENT_OPERATION |
