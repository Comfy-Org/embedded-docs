# تیز کردن Latent

گره LatentOperationSharpen یک عملیات تیز‌کردن برای نمایش‌های نهفته (latent representations) با استفاده از هسته گاوسی ایجاد می‌کند. این گره داده نهفته را نرمال‌سازی می‌کند، یک هسته تیز‌کردن سفارشی را از طریق کانولوشن اعمال می‌کند و سپس درخشندگی اصلی را بازیابی می‌کند. این کار جزئیات و لبه‌ها را در نمایش فضای نهفته تقویت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `شعاع تیز کردن` | شعاع هسته تیز‌کردن که اندازه ناحیه مورد استفاده برای تیز‌کردن را کنترل می‌کند (پیش‌فرض: 9) | INT | بله | 1-31 |
| `سیگما` | انحراف معیار هسته گاوسی که برای ساخت هسته تیز‌کردن استفاده می‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.1-10.0 |
| `آلفا` | ضریب شدت تیز‌کردن؛ مقادیر بالاتر اثر تیز‌کردن قوی‌تری تولید می‌کنند (پیش‌فرض: 0.1) | FLOAT | بله | 0.0-5.0 |

هر سه ورودی، پارامترهای پیشرفته هستند و مقادیر پیش‌فرض دارند، بنابراین می‌توان بدون تغییر آن‌ها از گره استفاده کرد. این گره به‌عنوان آزمایشی (experimental) علامت‌گذاری شده است.
