# تیز کردن Latent

گره LatentOperationSharpen یک عملیات تیزکردن برای بازنمایی‌های نهفته با استفاده از یک کرنل مبتنی بر گاوسی ایجاد می‌کند. داده‌های نهفته را نرمال‌سازی می‌کند، یک کرنل تیزکردن سفارشی را از طریق کانولوشن اعمال می‌کند و سپس روشنایی اصلی را بازمی‌گرداند، که جزئیات و لبه‌ها را در بازنمایی فضای نهفته بهبود می‌بخشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `sharpen_radius` | شعاع کرنل تیزکردن که اندازه ناحیه مورد استفاده برای تیزکردن را کنترل می‌کند (پیش‌فرض: 9) | INT | بله | 1-31 |
| `sigma` | انحراف معیار کرنل گاوسی که برای ساخت کرنل تیزکردن استفاده می‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.1-10.0 |
| `alpha` | ضریب شدت تیزکردن؛ مقادیر بالاتر اثر تیزکردن قوی‌تری تولید می‌کنند (پیش‌فرض: 0.1) | FLOAT | بله | 0.0-5.0 |

هر سه ورودی پارامترهای پیشرفته هستند و مقادیر پیش‌فرض دارند، بنابراین می‌توان از گره بدون تغییر آن‌ها استفاده کرد. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `operation` | یک عملیات تیزکردن را بازمی‌گرداند که می‌توان آن را روی داده‌های نهفته اعمال کرد | LATENT_OPERATION |
