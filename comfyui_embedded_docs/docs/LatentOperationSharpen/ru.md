# Операция латента: резкость

Узел LatentOperationSharpen создаёт операцию повышения резкости для латентных представлений с использованием ядра на основе гауссовой функции. Он нормализует латентные данные, применяет пользовательское ядро повышения резкости через свёртку, а затем восстанавливает исходную яркость, что улучшает детали и края в представлении латентного пространства.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `радиус_резкости` | Радиус ядра повышения резкости, который управляет размером области, используемой для повышения резкости (по умолчанию: 9) | INT | Да | 1-31 |
| `сигма` | Стандартное отклонение гауссова ядра, используемого для построения ядра повышения резкости (по умолчанию: 1.0) | FLOAT | Да | 0.1-10.0 |
| `альфа` | Коэффициент интенсивности повышения резкости; более высокие значения дают более сильный эффект повышения резкости (по умолчанию: 0.1) | FLOAT | Да | 0.0-5.0 |

Все три входа являются расширенными параметрами и имеют значения по умолчанию, поэтому узел можно использовать без их изменения. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `operation` | Возвращает операцию повышения резкости, которую можно применить к латентным данным | LATENT_OPERATION |
