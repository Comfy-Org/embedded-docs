# Операция латента: резкость

Узел LatentOperationSharpen применяет эффект повышения резкости к латентным представлениям с использованием гауссова ядра. Он работает путём нормализации латентных данных, применения свёртки с пользовательским ядром повышения резкости и последующего восстановления исходной яркости. Это улучшает детали и края в представлении латентного пространства.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `sharpen_radius` | Радиус ядра повышения резкости. Полный размер ядра вычисляется как удвоенное это значение плюс один (по умолчанию: 9). | INT | Да | 1-31 |
| `sigma` | Стандартное отклонение гауссова ядра (по умолчанию: 1.0). | FLOAT | Да | 0.1-10.0 |
| `alpha` | Коэффициент интенсивности повышения резкости, который управляет силой эффекта (по умолчанию: 0.1). | FLOAT | Да | 0.0-5.0 |

Все входы являются расширенными параметрами. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `operation` | Операция повышения резкости, которая может быть применена к латентным данным. Применение её к латентному представлению возвращает версию с повышенной резкостью и сохранённой исходной яркостью. | LATENT_OPERATION |
