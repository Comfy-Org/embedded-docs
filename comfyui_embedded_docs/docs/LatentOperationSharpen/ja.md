# 潜在操作シャープ化

LatentOperationSharpenノードは、ガウスカーネルを使用して潜在表現にシャープ化効果を適用します。潜在データを正規化し、カスタムシャープニングカーネルで畳み込みを適用してから、元の輝度を復元することで機能します。これにより、潜在空間表現の詳細とエッジが強調されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `sharpen_radius` | シャープニングカーネルの半径です。カーネル全体のサイズは、この値の2倍に1を加えたものとして計算されます（デフォルト: 9）。 | INT | はい | 1-31 |
| `sigma` | ガウスカーネルの標準偏差です（デフォルト: 1.0）。 | FLOAT | はい | 0.1-10.0 |
| `alpha` | 効果の強さを制御するシャープニング強度係数です（デフォルト: 0.1）。 | FLOAT | はい | 0.0-5.0 |

すべての入力は高度なパラメータです。このノードは実験的とマークされています。
