# Luma Ray 3.2: Ключевые кадры в видео

Этот узел генерирует видео, которое выполняет интерполяцию по последовательности опорных изображений, каждое из которых привязано к определённой позиции на временной шкале, с использованием Luma Ray 3.2. Постройте последовательность ключевых кадров с помощью узлов Luma Ray 3.2 Keyframe, соединив как минимум 2 ключевых кадра для задания анимации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео (по умолчанию: пустая строка). | STRING | Да | от 1 до 6000 символов |
| `resolution` | Разрешение выходного видео (по умолчанию: "720p"). | STRING | Да | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration` | Длительность генерируемого видео (по умолчанию: "5s"). | STRING | Да | `"5s"`<br>`"10s"` |
| `seed` | Сид для генерации случайных чисел для управления воспроизводимостью. | INT | Да | от 0 до 4294967295 |
| `keyframes` | Последовательность ключевых кадров из узлов Luma Ray 3.2 Keyframe (не менее 2). | LUMA_RAY32_KEYFRAME | Да | от 2 до 64 ключевых кадров |

**Примечание:** Последовательность ключевых кадров должна содержать не менее 2 и не более 64 ключевых кадров. Каждый ключевой кадр должен иметь отдельную позицию на временной шкале. Позиции ключевых кадров преобразуются в индексы кадров выходного видео на основе выбранной длительности (120 кадров для 5s, 240 кадров для 10s). Позиции ключевых кадров в режиме секунд не должны превышать общую длительность видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеовыход. | VIDEO |
| `generation_id` | Уникальный идентификатор запроса генерации. | STRING |
