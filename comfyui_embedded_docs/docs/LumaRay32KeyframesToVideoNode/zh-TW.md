# Luma Ray 3.2 關鍵影格轉影片

此節點使用 Luma Ray 3.2 產生一段影片，該影片會透過一系列引導影像進行插值，每張引導影像都錨定在時間軸上的特定位置。請使用 Luma Ray 3.2 Keyframe 節點建立關鍵影格序列，並連接至少 2 個關鍵影格來定義動畫。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於影片生成的文字提示（預設：空字串）。 | STRING | 是 | 1 至 6000 characters |
| `解析度` | 生成影片的輸出解析度（預設："720p"）。 | STRING | 是 | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `時長` | 生成影片的時長（預設："5s"）。 | STRING | 是 | `"5s"`<br>`"10s"` |
| `種子` | 用於隨機數生成的種子，以控制可重現性。 | INT | 是 | 0 至 4294967295 |
| `關鍵影格` | 來自 Luma Ray 3.2 Keyframe 節點的關鍵影格序列（至少 2 個）。 | LUMA_RAY32_KEYFRAME | 是 | 2 至 64 keyframes |

**注意：** 關鍵影格序列必須包含至少 2 個關鍵影格，且最多 64 個關鍵影格。每個關鍵影格在時間軸上必須有不同位置。關鍵影格位置會根據所選時長（5s 為 120 個影格，10s 為 240 個影格）解析為輸出影格索引。秒數模式中的關鍵影格位置不得超過影片總時長。
