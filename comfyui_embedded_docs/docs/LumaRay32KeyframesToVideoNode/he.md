# Luma Ray 3.2 פריימי מפתח לוידאו

צומת זה יוצר סרטון שמבצע אינטרפולציה דרך רצף של תמונות מנחות, כאשר כל אחת מהן מעוגנת למיקום ספציפי על ציר הזמן, באמצעות Luma Ray 3.2. בנו את רצף פריימי המפתח באמצעות צמתי Luma Ray 3.2 Keyframe, וחברו לפחות 2 פריימי מפתח כדי להגדיר את האנימציה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית טקסט ליצירת הסרטון (ברירת מחדל: מחרוזת ריקה). | STRING | כן | 1 עד 6000 תווים |
| `resolution` | רזולוציית הפלט של הסרטון שנוצר (ברירת מחדל: "720p"). | STRING | כן | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `duration` | משך הסרטון שנוצר (ברירת מחדל: "5s"). | STRING | כן | `"5s"`<br>`"10s"` |
| `seed` | Seed ליצירת מספרים אקראיים לשליטה בשחזוריות. | INT | כן | 0 עד 4294967295 |
| `keyframes` | רצף פריימי מפתח מצמתי Luma Ray 3.2 Keyframe (לפחות 2). | LUMA_RAY32_KEYFRAME | כן | 2 עד 64 פריימי מפתח |

**הערה:** רצף פריימי המפתח חייב להכיל לפחות 2 פריימי מפתח ולכל היותר 64 פריימי מפתח. לכל פריים מפתח חייבת להיות עמדה נפרדת על ציר הזמן. מיקומי פריימי המפתח מחושבים לאינדקסים של פריימים בפלט בהתאם למשך שנבחר (120 פריימים עבור 5s, 240 פריימים עבור 10s). מיקומי פריימי מפתח במצב שניות לא יעלו על משך הסרטון הכולל.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `video` | פלט הסרטון שנוצר. | VIDEO |
| `generation_id` | המזהה הייחודי לבקשת היצירה. | STRING |
