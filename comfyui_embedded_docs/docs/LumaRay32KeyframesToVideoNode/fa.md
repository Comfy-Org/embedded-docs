# Luma Ray 3.2 تبدیل کلیدفریم‌ها به ویدیو

این گره با استفاده از Luma Ray 3.2 ویدیویی تولید می‌کند که میان دنباله‌ای از تصاویر راهنما درون‌یابی می‌کند؛ هر تصویر به موقعیتی مشخص روی خط زمانی لنگر انداخته شده است. دنباله کی‌فریم را با استفاده از گره‌های Luma Ray 3.2 Keyframe بسازید و برای تعریف انیمیشن، حداقل ۲ کی‌فریم را به هم متصل کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | پرامپت متنی برای تولید ویدیو (پیش‌فرض: رشته خالی). | STRING | بله | 1 تا 6000 کاراکتر |
| `رزولوشن` | رزولوشن خروجی ویدیوی تولیدشده (پیش‌فرض: "720p"). | STRING | بله | `"360p"`<br>`"540p"`<br>`"720p"`<br>`"1080p"` |
| `مدت زمان` | مدت ویدیوی تولیدشده (پیش‌فرض: "5s"). | STRING | بله | `"5s"`<br>`"10s"` |
| `seed` | Seed برای تولید اعداد تصادفی به‌منظور کنترل بازتولیدپذیری. | INT | بله | 0 تا 4294967295 |
| `کلیدفریم‌ها` | دنباله کی‌فریم از گره‌های Luma Ray 3.2 Keyframe (حداقل ۲ عدد). | LUMA_RAY32_KEYFRAME | بله | 2 تا 64 کی‌فریم |

**توجه:** دنباله کی‌فریم باید شامل حداقل ۲ کی‌فریم و حداکثر ۶۴ کی‌فریم باشد. هر کی‌فریم باید موقعیتی متمایز روی خط زمانی داشته باشد. موقعیت‌های کی‌فریم بر اساس مدت انتخاب‌شده به شاخص‌های فریم خروجی نگاشت می‌شوند (۱۲۰ فریم برای 5s و ۲۴۰ فریم برای 10s). موقعیت‌های کی‌فریم در حالت ثانیه نباید از مدت کل ویدیو بیشتر شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | خروجی ویدیوی تولیدشده. | VIDEO |
| `generation_id` | شناسه یکتای درخواست تولید. | STRING |
