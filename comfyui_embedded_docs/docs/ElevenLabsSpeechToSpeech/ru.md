# ElevenLabs Speech to Speech

Узел ElevenLabs Speech to Speech преобразует входной аудиофайл из одного голоса в другой. Он использует ElevenLabs API для преобразования речи с сохранением исходного содержания и эмоционального тона аудио.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для преобразования речи в речь. Выбранная модель определяет доступные настройки голоса, перечисленные ниже. | DYNAMIC_COMBO | Да | `eleven_multilingual_sts_v2`<br>`eleven_english_sts_v2` |
| `голос` | Целевой голос для преобразования. Подключите из Voice Selector или Instant Voice Clone. | CUSTOM | Да | - |
| `аудио` | Исходное аудио для преобразования. | AUDIO | Да | - |
| `стабильность` | Стабильность голоса. Более низкие значения дают более широкий эмоциональный диапазон, более высокие — более последовательную, но потенциально монотонную речь (по умолчанию: 0.5). | FLOAT | Да | 0.0 - 1.0 |
| `формат_выхода` | Формат аудиовыхода (по умолчанию: "mp3_44100_192"). | COMBO | Да | `"mp3_44100_192"`<br>`"opus_48000_192"` |
| `seed` | Сид для воспроизводимости (по умолчанию: 0). | INT | Да | 0 - 4294967295 |
| `удалить_фоновый_шум` | Удаление фонового шума из входного аудио с помощью изоляции аудио (по умолчанию: False). | BOOLEAN | Да | - |

### Входы eleven_multilingual_sts_v2 и eleven_english_sts_v2

Обе модели имеют одинаковый набор настроек голоса, приведённый ниже.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `speed` | Скорость речи. 1.0 — нормальная, <1.0 — медленнее, >1.0 — быстрее (по умолчанию: 1.0). | FLOAT | Да | 0.7 - 1.3 |
| `similarity_boost` | Усиление сходства. Более высокие значения делают голос более похожим на исходный (по умолчанию: 0.75). | FLOAT | Да | 0.0 - 1.0 |
| `use_speaker_boost` | Усилить сходство с голосом исходного диктора (по умолчанию: False). | BOOLEAN | Да | - |
| `style` | Степень стилизации. Более высокие значения усиливают стилистическую выразительность, но могут снизить стабильность (по умолчанию: 0.0). | FLOAT | Да | 0.0 - 0.2 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Преобразованный аудиофайл в указанном формате вывода. | AUDIO |
