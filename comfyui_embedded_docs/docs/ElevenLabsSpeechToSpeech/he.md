# ElevenLabs דיבור לדיבור

צומת ElevenLabs Speech to Speech ממיר קובץ אודיו קלט מקול אחד לקול אחר. הוא משתמש ב-API של ElevenLabs כדי להמיר דיבור תוך שמירה על התוכן המקורי והטון הרגשי של האודיו.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש בהמרת דיבור-לדיבור. המודל הנבחר קובע את הגדרות הקול הזמינות המפורטות להלן. | DYNAMIC_COMBO | כן | `eleven_multilingual_sts_v2`<br>`eleven_english_sts_v2` |
| `voice` | קול היעד להמרה. יש לחבר מ-Voice Selector או Instant Voice Clone. | CUSTOM | כן | - |
| `audio` | אודיו המקור להמרה. | AUDIO | כן | - |
| `stability` | יציבות הקול. ערכים נמוכים יותר מספקים טווח רגשי רחב יותר, ערכים גבוהים יותר מפיקים דיבור עקבי יותר אך עשוי להיות מונוטוני (ברירת מחדל: 0.5). | FLOAT | כן | 0.0 - 1.0 |
| `output_format` | פורמט פלט האודיו. | COMBO | כן | `"mp3_44100_192"`<br>`"opus_48000_192"` |
| `seed` | ערך seed לשחזוריות (ברירת מחדל: 0). | INT | כן | 0 - 4294967295 |
| `remove_background_noise` | הסרת רעש רקע מאודיו הקלט באמצעות בידוד אודיו (ברירת מחדל: False). | BOOLEAN | כן | - |

### קלטים של eleven_multilingual_sts_v2 ו-eleven_english_sts_v2

שני המודלים מספקים את אותה קבוצת הגדרות הקול שלהלן.

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `speed` | מהירות דיבור. 1.0 הוא רגיל, <1.0 איטי יותר, >1.0 מהיר יותר (ברירת מחדל: 1.0). | FLOAT | כן | 0.7 - 1.3 |
| `similarity_boost` | חיזוק דמיון. ערכים גבוהים יותר הופכים את הקול לדומה יותר למקור (ברירת מחדל: 0.75). | FLOAT | כן | 0.0 - 1.0 |
| `use_speaker_boost` | הגברת הדמיון לקול הדובר המקורי (ברירת מחדל: False). | BOOLEAN | כן | - |
| `style` | הגזמה סגנונית. ערכים גבוהים יותר מגבירים ביטוי סגנוני אך עשויים להפחית יציבות (ברירת מחדל: 0.0). | FLOAT | כן | 0.0 - 0.2 |
