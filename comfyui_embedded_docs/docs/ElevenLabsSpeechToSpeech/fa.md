# تبدیل گفتار به گفتار ElevenLabs

گره ElevenLabs Speech to Speech یک فایل صوتی ورودی را از یک صدا به صدای دیگر تبدیل می‌کند. این گره از API سرویس ElevenLabs برای تبدیل گفتار استفاده می‌کند و محتوای اصلی و لحن احساسی صدا را حفظ می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تبدیل گفتار به گفتار استفاده می‌شود. مدل انتخابی تنظیمات صدای موجود را که در زیر فهرست شده‌اند تعیین می‌کند. | DYNAMIC_COMBO | بله | `eleven_multilingual_sts_v2`<br>`eleven_english_sts_v2` |
| `voice` | صدای هدف برای تبدیل. از Voice Selector یا Instant Voice Clone متصل کنید. | CUSTOM | بله | - |
| `audio` | صوتی منبع برای تبدیل. | AUDIO | بله | - |
| `stability` | پایداری صدا. مقادیر کمتر دامنه احساسی گسترده‌تری می‌دهند، مقادیر بالاتر گفتار یکنواخت‌تر اما احتمالاً خسته‌کننده‌تری تولید می‌کنند (پیش‌فرض: 0.5). | FLOAT | بله | 0.0 - 1.0 |
| `output_format` | قالب خروجی صوتی (پیش‌فرض: "mp3_44100_192"). | COMBO | بله | `"mp3_44100_192"`<br>`"opus_48000_192"` |
| `seed` | Seed برای تکرارپذیری (پیش‌فرض: 0). | INT | بله | 0 - 4294967295 |
| `remove_background_noise` | حذف نویز پس‌زمینه از صوتی ورودی با استفاده از جداسازی صوتی (پیش‌فرض: False). | BOOLEAN | بله | - |

### ورودی‌های eleven_multilingual_sts_v2 و eleven_english_sts_v2

هر دو مدل مجموعه یکسانی از تنظیمات صدا را در زیر ارائه می‌دهند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعت گفتار. 1.0 عادی است، <1.0 کندتر، >1.0 سریع‌تر (پیش‌فرض: 1.0). | FLOAT | بله | 0.7 - 1.3 |
| `similarity_boost` | تقویت شباهت. مقادیر بالاتر صدا را به صدای اصلی شبیه‌تر می‌کند (پیش‌فرض: 0.75). | FLOAT | بله | 0.0 - 1.0 |
| `use_speaker_boost` | تقویت شباهت به صدای گوینده اصلی (پیش‌فرض: False). | BOOLEAN | بله | - |
| `style` | اغراق در سبک. مقادیر بالاتر بیان سبکی را افزایش می‌دهند اما ممکن است پایداری را کاهش دهند (پیش‌فرض: 0.0). | FLOAT | بله | 0.0 - 0.2 |
