# تحويل الكلام إلى كلام من ElevenLabs

تقوم عقدة ElevenLabs لتحويل الكلام إلى كلام بتحويل ملف صوتي مُدخل من صوت إلى آخر. وتستخدم واجهة برمجة تطبيقات ElevenLabs لتحويل الكلام مع الحفاظ على المحتوى الأصلي والنبرة العاطفية للصوت.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم لتحويل الكلام إلى كلام. يحدد النموذج المحدد إعدادات الصوت المتاحة المذكورة أدناه. | DYNAMIC_COMBO | نعم | `eleven_multilingual_sts_v2`<br>`eleven_english_sts_v2` |
| `الصوت` | الصوت المستهدف للتحويل. قم بالتوصيل من محدد الصوت أو استنساخ الصوت الفوري. | CUSTOM | نعم | - |
| `الصوت` | الصوت المصدر الذي سيتم تحويله. | AUDIO | نعم | - |
| `الثبات` | استقرار الصوت. القيم الأقل تعطي نطاقًا عاطفيًا أوسع، والقيم الأعلى تنتج كلامًا أكثر اتساقًا ولكن قد يكون رتيبًا (الافتراضي: 0.5). | FLOAT | نعم | 0.0 - 1.0 |
| `صيغة الإخراج` | تنسيق إخراج الصوت (الافتراضي: "mp3_44100_192"). | COMBO | نعم | `"mp3_44100_192"`<br>`"opus_48000_192"` |
| `البذرة` | البذرة (Seed) لإمكانية التكرار (الافتراضي: 0). | INT | نعم | 0 - 4294967295 |
| `إزالة الضوضاء الخلفية` | إزالة الضوضاء الخلفية من الصوت المُدخل باستخدام عزل الصوت (الافتراضي: False). | BOOLEAN | نعم | - |

### مدخلات eleven_multilingual_sts_v2 و eleven_english_sts_v2

يوفر كلا النموذجين نفس مجموعة إعدادات الصوت أدناه.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `speed` | سرعة الكلام. 1.0 طبيعي، <1.0 أبطأ، >1.0 أسرع (الافتراضي: 1.0). | FLOAT | نعم | 0.7 - 1.3 |
| `similarity_boost` | تعزيز التشابه. القيم الأعلى تجعل الصوت أكثر تشابهًا مع الصوت الأصلي (الافتراضي: 0.75). | FLOAT | نعم | 0.0 - 1.0 |
| `use_speaker_boost` | تعزيز التشابه مع صوت المتحدث الأصلي (الافتراضي: False). | BOOLEAN | نعم | - |
| `style` | مبالغة الأسلوب. القيم الأعلى تزيد التعبير الأسلوبي ولكنها قد تقلل الاستقرار (الافتراضي: 0.0). | FLOAT | نعم | 0.0 - 0.2 |

| `audio` | ملف الصوت المحول بالتنسيق المحدد للإخراج. | AUDIO |
