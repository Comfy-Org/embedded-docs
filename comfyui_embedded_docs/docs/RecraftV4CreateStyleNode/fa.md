# ایجاد سبک Recraft V4

این گره یک سبک قابل‌استفاده مجدد از Recraft V4 از ۱ تا ۱۰ تصویر مرجع می‌سازد. شناسه سبک بازگردانده‌شده با هر مدل Recraft V4 و V4.1 از همان نوع خروجی کار می‌کند و می‌توان در مراحل بعدی تولید تصویر از آن استفاده مجدد کرد. اندازه کل تصاویر مرجع به ۱۰ مگابایت محدود است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نوع خروجی که سبک برای آن ساخته می‌شود: `recraftv4_styles` برای تصاویر شطرنجی، `recraftv4_styles_vector` برای SVG. | COMBO | بله | `"recraftv4_styles"`<br>`"recraftv4_styles_vector"` |
| `images` | تصاویر مرجعی که سبک را تعریف می‌کنند. مرجع‌های مشابه تطابق را دقیق‌تر می‌کنند و مرجع‌های متنوع آن را گسترده‌تر می‌کنند. شکاف قابل‌رشد: ۱ تا ۱۰ تصویر را وصل کنید (`image_1` تا `image_10`). | IMAGE | بله | ۱ تا ۱۰ تصویر |

### یادداشت‌ها

- حداقل یک تصویر مرجع الزامی است؛ اگر هیچ تصویری ارائه نشود، گره خطا می‌دهد.
- حداکثر ۱۰ تصویر مرجع مجاز است.
- اندازه کل رمزگذاری‌شده همه تصاویر مرجع نباید از ۱۰ مگابایت تجاوز کند؛ اگر این محدودیت رد شود، گره خطا می‌دهد.
- هر تصویر مرجع حداکثر به ۲۰۴۸×۲۰۴۸ پیکسل کوچک‌سازی و پیش از ارسال به Recraft API به‌صورت WebP رمزگذاری می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `style_id` | شناسه یکتای سبک ایجادشده، قابل‌استفاده با هر مدل Recraft V4 و V4.1 از همان نوع خروجی. | STRING |
