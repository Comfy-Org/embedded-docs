# TerminalLog

Der Node Terminal Log (Manager) wird hauptsächlich verwendet, um die Laufzeitinformationen von ComfyUI im Terminal innerhalb der ComfyUI-Oberfläche anzuzeigen. Um ihn zu verwenden, müssen Sie den `mode` auf **logging** setzen. Dadurch kann er während der Bildgenerierungsaufgabe entsprechende Protokollinformationen aufzeichnen. Wenn der `mode` auf **stop** gesetzt ist, werden keine Protokollinformationen aufgezeichnet.
Wenn Sie über Remote-Verbindungen oder Verbindungen im lokalen Netzwerk auf ComfyUI zugreifen und es verwenden, ist der Node Terminal Log (Manager) besonders nützlich. Er ermöglicht es Ihnen, Fehlermeldungen aus der CMD direkt in der ComfyUI-Oberfläche anzuzeigen, wodurch es einfacher wird, den aktuellen Betriebsstatus von ComfyUI zu verstehen.
