# TerminalLog

צומת Terminal Log (Manager) משמש בעיקר להצגת מידע התפעול של ComfyUI במסוף בתוך ממשק ComfyUI. כדי להשתמש בו, יש להגדיר את `mode` למצב **logging**. הדבר יאפשר לו לתעד מידע לוג מתאים במהלך משימת יצירת התמונה. אם `mode` מוגדר למצב **stop**, הוא לא יתעד מידע לוג.
כאשר ניגשים ומשתמשים ב-ComfyUI דרך חיבורים מרחוק או חיבורי רשת מקומית, צומת Terminal Log (Manager) הופך לשימושי במיוחד. הוא מאפשר להציג ישירות הודעות שגיאה מה-CMD בתוך ממשק ComfyUI, מה שמקל להבין את מצב הפעולה הנוכחי של ComfyUI.
