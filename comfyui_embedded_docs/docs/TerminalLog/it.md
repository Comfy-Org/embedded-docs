# TerminalLog

Il nodo Terminal Log (Manager) viene utilizzato principalmente per visualizzare le informazioni di esecuzione di ComfyUI nel terminale all'interno dell'interfaccia di ComfyUI. Per utilizzarlo, è necessario impostare `mode` sulla modalità **logging**. Ciò gli consentirà di registrare le informazioni di log corrispondenti durante l'attività di generazione delle immagini. Se `mode` è impostato sulla modalità **stop**, non registrerà informazioni di log.
Quando accedi e utilizzi ComfyUI tramite connessioni remote o connessioni di rete locale, il nodo Terminal Log (Manager) diventa particolarmente utile. Ti consente di visualizzare direttamente i messaggi di errore dal CMD all'interno dell'interfaccia di ComfyUI, rendendo più semplice comprendere lo stato attuale del funzionamento di ComfyUI.
