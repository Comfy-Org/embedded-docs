# GeminiImage

הצומת GeminiImage מייצר תגובות טקסט ותמונה ממודלי Gemini AI של Google. הוא מאפשר לספק קלטים מולטימודליים הכוללים הנחיות טקסט, תמונות וקבצים כדי ליצור פלטי טקסט ותמונה קוהרנטיים. הצומת מטפל בכל תקשורת ה-API וניתוח התגובות עם מודלי Gemini העדכניים ביותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | סוג קלט | ברירת מחדל | טווח |

| `prompt` | הנחיית טקסט ליצירה | STRING | חובה | "" | - |
| `model` | מודל Gemini שיש להשתמש בו ליצירת תגובות. | COMBO | חובה | gemini_2_5_flash_image_preview | `gemini_2_5_flash_image_preview`<br>`gemini_2_5_pro_exp_03_25`<br>`gemini_2_0_flash_exp_image_generation` |
| `seed` | כאשר `seed` מקובע לערך מסוים, המודל עושה מאמץ מירבי לספק את אותה תגובה לבקשות חוזרות. פלט דטרמיניסטי אינו מובטח. כמו כן, שינוי המודל או הגדרות פרמטר, כגון הטמפרטורה, יכול לגרום לשינויים בתגובה גם כאשר אתה משתמש באותו ערך `seed`. כברירת מחדל, נעשה שימוש בערך `seed` אקראי. | INT | חובה | 42 | 0 to 18446744073709551615 |
| `images` | תמונה/תמונות אופציונליות לשימוש כהקשר עבור המודל. כדי לכלול מספר תמונות, ניתן להשתמש בצומת Batch Images. | IMAGE | אופציונלי | ללא | - |
