# TripoSegmentNode

تقوم هذه العقدة بتقسيم نموذج ثلاثي الأبعاد إلى أجزاء منفصلة. وترسل النموذج إلى خدمة تقسيم Tripo، وتنتظر حتى اكتمال المهمة، ثم تُرجع النموذج المُقسَّم بتنسيق GLB مع قائمة مفصولة بفواصل بأسماء الأجزاء. تُغذّي أسماء الأجزاء هذه الخطوات اللاحقة مثل Tripo: Complete Mesh Parts وTripo: Retopology وTripo: Convert model.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | المعرّف الخاص بمهمة النموذج ثلاثي الأبعاد المراد تقسيمه إلى أجزاء. | MODEL_TASK_ID | نعم | N/A |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف الإخراج لنموذج GLB المُقسَّم. يُحتفظ به للتوافق مع الإصدارات السابقة فقط. | STRING |
| `مهمة task_id` | المعرّف الخاص بمهمة التقسيم التي أنتجت النتيجة. | SEGMENT_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُقسَّم، كملف GLB. | GLB |
| `part_names` | أسماء الأجزاء مفصولة بفواصل. | STRING |
