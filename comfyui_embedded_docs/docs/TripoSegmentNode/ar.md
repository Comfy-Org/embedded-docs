# Tripo: تقسيم النموذج

تقوم هذه العقدة بتقسيم نموذج ثلاثي الأبعاد إلى أجزاء فردية. ترسل النموذج إلى خدمة Tripo للتقسيم، وتنتظر اكتمال المهمة، ثم تعيد النموذج المقسّم بصيغة GLB إلى جانب قائمة بأسماء الأجزاء مفصولة بفواصل. تُغذّي أسماء الأجزاء هذه الخطوات اللاحقة مثل Tripo: Complete Mesh Parts وTripo: Retopology وTripo: Convert model.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف المهمة للنموذج ثلاثي الأبعاد المراد تقسيمه إلى أجزاء. | MODEL_TASK_ID | نعم | لا ينطبق |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف الإخراج لنموذج GLB المقسّم، بالصيغة `<task_id>.glb`. يُحتفظ به للتوافق مع الإصدارات السابقة فقط. | STRING |
| `segment task_id` | معرّف المهمة لمهمة التقسيم التي أنتجت النتيجة. | SEGMENT_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المقسّم، كملف GLB. | GLB |
| `part_names` | أسماء الأجزاء مفصولة بفواصل. | STRING |
