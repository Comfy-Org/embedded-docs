# Tripo: Сегментировать модель

Этот узел разделяет 3D-модель на отдельные части. Он отправляет модель в сервис сегментации Tripo, ожидает завершения задачи и возвращает сегментированную модель в формате GLB вместе со списком названий частей через запятую. Эти названия частей используются на последующих шагах, таких как Tripo: Complete Mesh Parts, Tripo: Retopology и Tripo: Convert model.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи 3D-модели, которую нужно сегментировать на части. | MODEL_TASK_ID | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя выходного файла сегментированной GLB-модели в формате `<task_id>.glb`. Оставлено только для обратной совместимости. | STRING |
| `segment task_id` | ID задачи сегментации, создавшей результат. | SEGMENT_TASK_ID |
| `GLB` | Сегментированная 3D-модель в виде GLB-файла. | GLB |
| `part_names` | Названия частей, разделённые запятыми. | STRING |
