# TripoSegmentNode

Этот узел разделяет 3D-модель на отдельные части. Он отправляет модель в сервис сегментации Tripo, ожидает завершения задания и возвращает сегментированную модель в формате GLB со списком названий частей, разделённых запятыми. Эти названия частей используются последующими шагами, такими как Tripo: Complete Mesh Parts, Tripo: Retopology и Tripo: Convert model.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Идентификатор задачи 3D-модели, которую требуется разделить на части. | MODEL_TASK_ID | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя выходного файла сегментированной GLB-модели. Оставлено только для обратной совместимости. | STRING |
| `segment task_id` | Идентификатор задания сегментации, которое создало этот результат. | SEGMENT_TASK_ID |
| `GLB` | Сегментированная 3D-модель в виде GLB-файла. | GLB |
| `part_names` | Названия частей, разделённые запятыми. | STRING |
