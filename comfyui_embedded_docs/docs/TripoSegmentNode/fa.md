# TripoSegmentNode

این گره یک مدل سه‌بعدی را به اجزای جداگانه تقسیم می‌کند. مدل را به سرویس تقسیم‌بندی Tripo ارسال می‌کند، منتظر پایان یافتن فرآیند می‌ماند و مدل تقسیم‌شده را در قالب GLB همراه با فهرستی از نام اجزا که با کاما جدا شده‌اند بازمی‌گرداند. این نام‌های اجزا به عنوان ورودی برای مراحل بعدی مانند Tripo: Complete Mesh Parts، Tripo: Retopology و Tripo: Convert model عمل می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدل سه‌بعدی که باید به اجزا تقسیم شود. | MODEL_TASK_ID | بله | N/A |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل خروجی مدل GLB تقسیم‌شده. فقط برای سازگاری با نسخه‌های قبلی نگهداری می‌شود. | STRING |
| `segment task_id` | شناسه وظیفه فرآیند تقسیم‌بندی که نتیجه را تولید کرده است. | SEGMENT_TASK_ID |
| `GLB` | مدل سه‌بعدی تقسیم‌شده، به صورت فایل GLB. | GLB |
| `part_names` | نام اجزا که با کاما جدا شده‌اند. | STRING |
