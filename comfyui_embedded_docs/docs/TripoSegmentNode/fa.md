# Tripo: بخش‌بندی مدل

این گره یک مدل سه‌بعدی را به قطعات جداگانه تقسیم می‌کند. مدل را به سرویس قطعه‌بندی Tripo می‌فرستد، منتظر می‌ماند تا وظیفه کامل شود، و مدل قطعه‌بندی‌شده را در قالب GLB همراه با فهرستی از نام قطعات جداشده با کاما برمی‌گرداند. این نام‌های قطعه به مراحل پایین‌دستی مانند Tripo: Complete Mesh Parts، Tripo: Retopology و Tripo: Convert model وارد می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدل سه‌بعدی که باید به قطعات تقسیم شود. | MODEL_TASK_ID | بله | N/A |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل خروجی مدل GLB قطعه‌بندی‌شده، به شکل `<task_id>.glb`. فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `segment task_id` | شناسه وظیفه فرایند قطعه‌بندی که این نتیجه را تولید کرده است. | SEGMENT_TASK_ID |
| `GLB` | مدل سه‌بعدی قطعه‌بندی‌شده، به‌صورت یک فایل GLB. | GLB |
| `part_names` | نام‌های قطعات، جداشده با کاما. | STRING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TripoSegmentNode/fa.md)
