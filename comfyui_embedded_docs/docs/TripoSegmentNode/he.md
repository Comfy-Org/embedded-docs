# Tripo: פילוח מודל

צומת זה מפצל מודל תלת-ממדי לחלקים בודדים. הוא שולח את המודל לשירות הפילוח של Tripo, ממתין לסיום העבודה, ומחזיר את המודל המפולח בפורמט GLB יחד עם רשימה מופרדת בפסיקים של שמות החלקים. שמות חלקים אלה משמשים כקלט לשלבים בהמשך כגון Tripo: Complete Mesh Parts, Tripo: Retopology ו-Tripo: Convert model.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | מזהה המשימה של המודל התלת-ממדי שיש לפצל לחלקים. | MODEL_TASK_ID | כן | N/A |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | שם קובץ הפלט של מודל ה-GLB המפולח, בצורה `<task_id>.glb`. נשמר לצורך תאימות לאחור בלבד. | STRING |
| `segment task_id` | מזהה המשימה של עבודת הפילוח שהפיקה את התוצאה. | SEGMENT_TASK_ID |
| `GLB` | המודל התלת-ממדי המפולח, כקובץ GLB. | GLB |
| `part_names` | שמות החלקים, מופרדים בפסיקים. | STRING |
