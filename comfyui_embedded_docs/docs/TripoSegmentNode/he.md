# Tripo: פילוח מודל

צומת זה מפצל מודל תלת-ממדי לחלקים בודדים. הוא שולח את המודל לשירות הפילוח של Tripo, ממתין לסיום העבודה, ומחזיר את המודל המפולח בפורמט GLB יחד עם רשימה מופרדת בפסיקים של שמות החלקים. שמות חלקים אלה משמשים כקלט לשלבים בהמשך כגון Tripo: Complete Mesh Parts, Tripo: Retopology ו-Tripo: Convert model.

<Note>
Tripo שומר רשומות משימה בשרתים שלו במשך 7 ימים (בתוקף מ-1 בדצמבר 2026). לא ניתן יותר לפענח מזהה משימה ישן מזה, ולכן הרצה חוזרת של תהליך עבודה שמור לאחר תקופה זו נכשלת בצומת הזה. כדי להמשיך, הריצו שוב את צומת Tripo הקודם כדי ליצור מזהה משימה חדש, או ייבאו מחדש את המודל שכבר הורדתם באמצעות **Tripo: ייבוא מודל**.
</Note>
