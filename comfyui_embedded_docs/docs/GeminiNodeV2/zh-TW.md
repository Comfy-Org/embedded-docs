# Google Gemini

使用 Google Gemini 模型生成文字回應。提供文字提示，並可選擇性地提供一或多張圖片、音訊片段、影片或檔案作為多模態上下文。

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於產生回應的 Gemini 模型。 | DYNAMIC_COMBO | 是 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 提供給模型的文字輸入。包含詳細指示、問題或上下文。必須包含至少一個非空白字元。(預設值："") | STRING | 是 |  |
| `seed` | 取樣用的隨機種子。設為 0 以使用隨機種子。不保證輸出具有確定性。(預設值：42) | INT | 是 | 0 至 2147483647 |
| `system_prompt` | 規範模型行為的基礎指示。(預設值："") | STRING | 否 |  |
