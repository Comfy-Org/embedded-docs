# Google Gemini

使用 Google 的 Gemini 模型生成文字回應。提供一個文字提示，並可選擇性地加入一或多張圖片、音訊片段、影片或檔案作為多模態上下文。

### 通用輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成回應的 Gemini 模型。 | COMBO | 是 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 提供給模型的文字輸入。包含詳細指示、問題或上下文。必須包含至少一個非空白字元。（預設值：""） | STRING | 是 |  |
| `seed` | 用於取樣的種子。設為 0 以使用隨機種子。不保證輸出具有確定性。（預設值：42） | INT | 是 | 0 to 2147483647 |
| `system_prompt` | 決定模型行為的基礎指示。（預設值：""） | STRING | 否 |  |

**注意：** 當附加媒體（圖片、音訊或影片）時，節點會將前 10 個媒體項目上傳至 ComfyAPI 儲存空間，並以 URL 形式傳遞；此 URL 配額由所有媒體類型共用，並依序消耗（先影片、再音訊、最後圖片）。其餘媒體則以 base64 資料進行內嵌編碼，合併的內嵌內容上限為 18 MB。若內嵌內容超過 18 MB，節點將拋出錯誤。`prompt` 參數必須包含至少一個非空白字元。將 `seed` 設為 0 會要求使用隨機種子。
