# Google Gemini

Google の Gemini モデルを使用してテキスト応答を生成します。テキストプロンプトに加えて、オプションで1つ以上の画像、音声クリップ、動画、またはファイルをマルチモーダルコンテキストとして提供できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `model` | 応答の生成に使用する Gemini モデルです。 | COMBO | はい | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力です。詳細な指示、質問、またはコンテキストを含めます。空白以外の文字を少なくとも1つ含める必要があります。（デフォルト: ""） | STRING | はい |  |
| `seed` | サンプリング用のシードです。0 に設定するとランダムなシードになります。決定論的な出力は保証されません。（デフォルト: 42） | INT | はい | 0 to 2147483647 |
| `system_prompt` | モデルの動作を規定する基本的な指示です。（デフォルト: ""） | STRING | いいえ |  |

### Gemini 3.5 Flash 入力

これらの入力は、`model` が `"Gemini 3.5 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `thinking_level` | 回答前にモデルが内部的にどの程度推論するかを指定します。HIGH は難しいタスクの品質を向上させますが、（思考用）トークンをより多く消費し、処理が遅くなります。（デフォルト: "MEDIUM"） | COMBO | はい | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | ランダム性を制御します。値が低いほど焦点が定まり決定的になり、値が高いほど創造的になります。（デフォルト: 1.0） | FLOAT | はい | 0.0 to 2.0 |
| `top_p` | ニュークリアスサンプリング：累積確率が top_p に達する最小のトークン集合からサンプリングします。（デフォルト: 0.95） | FLOAT | はい | 0.0 to 1.0 |
| `max_output_tokens` | モデルの内部思考を含む、生成する最大トークン数です。thinking_level が HIGH の場合、値が低いと回答の余地がなくなることがあります。応答が空、または途中で切れて返ってくる場合は、この値を上げてください。モデルは完了すると早期に停止するため、上限を高く設定しても、短い応答には追加コストはかかりません。（デフォルト: 32768） | INT | はい | 16 to 65536 |

### メディアとファイル入力

以下の入力は3つのモデルすべてで共有され、モデル固有の入力とともに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `images` | 拡張可能スロット：1〜16個の画像（`image_1` ... `image_16`）を接続できます。モデルのコンテキストとして使用するオプションの画像です。 | IMAGE | いいえ | 0 to 16 images |
| `audio` | 拡張可能スロット：1つの音声クリップ（`audio_1`）を接続できます。モデルのコンテキストとして使用するオプションの音声クリップです。 | AUDIO | いいえ | 0 to 1 clip |
| `video` | 拡張可能スロット：1つの動画クリップ（`video_1`）を接続できます。モデルのコンテキストとして使用するオプションの動画クリップです。 | VIDEO | いいえ | 0 to 1 clip |
| `files` | モデルのコンテキストとして使用するオプションのファイルです。Gemini Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ |  |

**注記：** メディア（画像、音声、または動画）が添付されている場合、ノードは最初の10個のメディアアイテムを ComfyAPI ストレージにアップロードし、URL として渡します。この URL 予算はすべてのメディアタイプで共有され、（動画、次に音声、その次に画像の順で）消費されます。残りのメディアは base64 データとしてインラインでエンコードされ、インラインペイロードの合計は最大 18 MB です。インラインペイロードが 18 MB を超える場合、ノードはエラーを発生させます。`prompt` パラメータには、空白以外の文字が少なくとも1つ含まれている必要があります。`seed` を 0 に設定すると、ランダムなシードが要求されます。

|--------|------|---------|
| `output` | Gemini モデルから生成されたテキスト応答です。モデルがテキストを生成しなかった場合は、文字列 "Empty response from Gemini model..." が返されます。 | STRING |
