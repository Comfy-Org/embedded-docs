# Google Gemini

Google の Gemini モデルを使用してテキスト応答を生成します。テキストプロンプトと、必要に応じて 1 つまたは複数の画像、音声クリップ、ビデオ、ファイルをマルチモーダルコンテキストとして提供します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用される Gemini モデル。 | DYNAMIC_COMBO | 必須 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力。詳細な指示、質問、コンテキストを含めます。少なくとも 1 つの空白以外の文字を含める必要があります。(デフォルト: "") | STRING | 必須 |  |
| `seed` | サンプリング用のシード。ランダムシードにするには 0 を設定します。決定的な出力は保証されません。(デフォルト: 42) | INT | 必須 | 0 〜 2147483647 |
| `system_prompt` | モデルの動作を決定する基盤となる指示。(デフォルト: "") | STRING | 任意 |  |

### Gemini 3.5 Flash 入力

これらの入力は、`model` が `"Gemini 3.5 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | 回答前にモデルが内部的に推論する度合い。HIGH は難しいタスクでの品質を向上させますが、(思考)トークンをより多く消費し、遅くなります。(デフォルト: "MEDIUM") | COMBO | 必須 | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | ランダム性を制御します。低いほど集中・決定論的になり、高いほど創造的になります。(デフォルト: 1.0) | FLOAT | 必須 | 0.0 〜 2.0 |
| `top_p` | Nucleus サンプリング: 累積確率が top_p に達する最小のトークン集合からサンプリングします。(デフォルト: 0.95) | FLOAT | 必須 | 0.0 〜 1.0 |
| `max_output_tokens` | モデルの内部思考を含む、生成する最大トークン数。thinking_level が HIGH の場合、値が低すぎると回答の余地がなくなることがあります。応答が空または途中で切れて返ってくる場合は、この値を上げてください。モデルは完了すると早期に停止するため、上限を高くしても短い応答で追加コストは発生しません。(デフォルト: 32768) | INT | 必須 | 16 〜 65536 |

### メディアおよびファイル入力

以下の入力は 3 つのモデルすべてに共通で、モデル固有の入力と一緒に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張スロット: 1～16 枚の画像 (`image_1` ... `image_16`) を接続します。モデルのコンテキストとして使用するオプションの画像。 | IMAGE | 任意 | 0 〜 16 images |
| `audio` | 拡張スロット: 1 つのオーディオクリップ (`audio_1`) を接続します。モデルのコンテキストとして使用するオプションのオーディオクリップ。 | AUDIO | 任意 | 0 〜 1 clip |
| `video` | 拡張スロット: 1 つのビデオクリップ (`video_1`) を接続します。モデルのコンテキストとして使用するオプションのビデオクリップ。 | VIDEO | 任意 | 0 〜 1 clip |
| `files` | モデルのコンテキストとして使用するオプションのファイル。Gemini Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | 任意 |  |

**注:** メディア（画像、音声、ビデオ）が添付されている場合、ノードは最初の 10 個のメディアアイテムを ComfyAPI ストレージにアップロードし、URL として渡します。この URL 予算はすべてのメディアタイプで共有され、ビデオ、音声、画像の順に消費されます。残りのメディアは base64 データとしてインラインエンコードされ、インラインの合計ペイロードの最大サイズは 18 MB です。インラインペイロードが 18 MB を超えると、ノードはエラーを発生させます。`prompt` パラメータには少なくとも 1 つの空白以外の文字を含める必要があります。`seed` を 0 に設定すると、ランダムシードが要求されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | Gemini モデルから生成されたテキスト応答。モデルがテキストを生成しない場合は、文字列 "Empty response from Gemini model..." が返されます。 | STRING |
