# Google Gemini

Google の Gemini モデルを使用してテキスト応答を生成します。テキストプロンプトを指定し、必要に応じて1つ以上の画像、オーディオクリップ、動画、またはファイルをマルチモーダルコンテキストとして指定できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用される Gemini モデル。 | DYNAMIC_COMBO | はい | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力です。詳細な指示、質問、またはコンテキストを含めます。空白以外の文字が少なくとも1文字含まれている必要があります。（デフォルト: ""） | STRING | はい |  |
| `seed` | サンプリング用のシードです。0 に設定するとランダムシードになります。決定論的な出力は保証されません。（デフォルト: 42） | INT | はい | 0～2147483647 |
| `system_prompt` | モデルの動作を規定する基本的な指示です。（デフォルト: ""） | STRING | いいえ |  |

### Gemini 3.8 Flash 入力

これらの入力は、`model` が `"Gemini 3.8 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | モデルが回答する前に内部でどれだけ深く推論するかを指定します。HIGH は難しいタスクの品質を向上させますが、より多くの（思考）トークンを消費し、遅くなります。（デフォルト: "MEDIUM"） | COMBO | はい | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `max_output_tokens` | 生成する最大トークン数（モデルの内部思考を含む）。thinking_level が HIGH の場合、値が低いと回答の余地がなくなることがあります。応答が空または切り詰められて返される場合は、この値を増やしてください。モデルは完了すると早期に停止するため、短い応答では上限を高くしても追加コストは発生しません。（デフォルト: 32768） | INT | はい | 16～65536 |

**注記:** このモデルは `temperature` または `top_p` のサンプリング制御を公開していません。

### メディアとファイルの入力

以下の入力はすべてのモデルで共有され、モデル固有の入力と並んで表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張可能スロット：1～16枚の画像（`image_1` ... `image_16`）を接続します。モデルのコンテキストとして使用する任意の画像。最大16枚。 | IMAGE | いいえ | 0～16 枚の画像 |
| `audio` | 拡張可能スロット：1つのオーディオクリップ（`audio_1`）を接続します。モデルのコンテキストとして使用する任意のオーディオクリップ。 | AUDIO | いいえ | 0～1 クリップ |
| `video` | 拡張可能スロット：1つの動画クリップ（`video_1`）を接続します。モデルのコンテキストとして使用する任意の動画クリップ。 | VIDEO | いいえ | 0～1 クリップ |
| `files` | モデルのコンテキストとして使用する任意のファイル。Gemini Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ |  |

**注記:** メディア（画像、オーディオ、または動画）が添付されている場合、ノードは最初の10件のメディア項目を ComfyAPI ストレージにアップロードし、URL として渡します。この URL の上限はすべてのメディアタイプで共有され、順番に消費されます（最初に動画、次にオーディオ、最後に画像）。残りのメディアは base64 データとしてインラインでエンコードされ、インラインの合計ペイロードは最大 18 MB です。インラインペイロードが 18 MB を超える場合、ノードはエラーを発生させます。`prompt` パラメータには、空白以外の文字が少なくとも1文字含まれている必要があります。`seed` を 0 に設定すると、ランダムシードが要求されます。
