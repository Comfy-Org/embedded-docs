# Google Gemini

با مدل‌های Gemini گوگل پاسخ‌های متنی تولید کنید. یک پرامپت متنی و به‌صورت اختیاری یک یا چند تصویر، کلیپ صوتی، ویدیو یا فایل را به‌عنوان زمینه چندوجهی ارائه دهید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل Gemini که برای تولید پاسخ استفاده می‌شود. | DYNAMIC_COMBO | بله | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | ورودی متنی برای مدل. شامل دستورالعمل‌های دقیق، پرسش‌ها یا زمینه باشد. باید حداقل شامل یک نویسه غیرفاصله باشد. (پیش‌فرض: "") | STRING | بله |  |
| `seed` | `seed` برای نمونه‌گیری. برای دانه تصادفی روی 0 تنظیم کنید. خروجی قطعی تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |
| `system_prompt` | دستورالعمل‌های پایه‌ای که رفتار مدل را تعیین می‌کنند. (پیش‌فرض: "") | STRING | خیر |  |

### ورودی‌های رسانه و فایل

ورودی‌های زیر بین همه مدل‌ها مشترک‌اند و در کنار ورودی‌های مخصوص هر مدل ظاهر می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `images` | جایگاه قابل‌گسترش: 1 تا 16 تصویر را متصل کنید (`image_1` ... `image_16`). تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. حداکثر 16 تصویر. | IMAGE | خیر | 0 تا 16 تصویر |
| `audio` | جایگاه قابل‌گسترش: یک کلیپ صوتی را متصل کنید (`audio_1`). کلیپ صوتی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | AUDIO | خیر | 0 تا 1 کلیپ |
| `video` | جایگاه قابل‌گسترش: یک کلیپ ویدیویی را متصل کنید (`video_1`). کلیپ ویدیویی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | VIDEO | خیر | 0 تا 1 کلیپ |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌هایی از گره Gemini Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر |  |

**توجه:** هنگامی که رسانه (تصویر، صدا یا ویدیو) پیوست می‌شود، گره اولین 10 مورد رسانه‌ای را در فضای ذخیره‌سازی ComfyAPI بارگذاری می‌کند و آن‌ها را به‌صورت URL ارسال می‌کند؛ این سهمیه URL بین همه انواع رسانه مشترک است و به‌ترتیب مصرف می‌شود (ابتدا ویدیو، سپس صدا، سپس تصاویر). هر رسانه باقی‌مانده به‌صورت درون‌خطی (inline) با داده base64 کدگذاری می‌شود، با حداکثر مجموع بار درون‌خطی برابر 18 مگابایت. اگر بار درون‌خطی از 18 مگابایت فراتر رود، گره خطا می‌دهد. پارامتر `prompt` باید حداقل شامل یک نویسه غیرفاصله باشد. تنظیم `seed` روی 0 درخواست دانه تصادفی می‌کند.
