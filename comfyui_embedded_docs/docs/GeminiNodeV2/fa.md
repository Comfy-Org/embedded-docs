# Google Gemini

با مدل‌های Gemini گوگل، پاسخ‌های متنی تولید کنید. یک متن ورودی و به‌صورت اختیاری، یک یا چند تصویر، کلیپ صوتی، ویدیو یا فایل را به‌عنوان زمینه چندحالته (multimodal) ارائه دهید.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل Gemini که برای تولید پاسخ استفاده می‌شود. | DYNAMIC_COMBO | بله | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `راهنما` | ورودی متنی به مدل. شامل دستورالعمل‌های دقیق، پرسش‌ها یا زمینه. باید حداقل شامل یک نویسه غیرفضایی باشد. (پیش‌فرض: "") | STRING | بله |  |
| `seed` | دانه (seed) برای نمونه‌برداری. برای دانه تصادفی، آن را روی 0 قرار دهید. خروجی قطعی تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |
| `system_prompt` | دستورالعمل‌های بنیادین که رفتار مدل را تعیین می‌کنند. (پیش‌فرض: "") | STRING | خیر |  |

### ورودی‌های Gemini 3.5 Flash

این ورودی‌ها زمانی ظاهر می‌شوند که `model` روی `"Gemini 3.5 Flash"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | میزان استدلال داخلی مدل پیش از پاسخ‌دهی. حالت HIGH کیفیت را در کارهای دشوار بهبود می‌بخشد اما توکن‌های بیشتری (تفکر) مصرف می‌کند و کندتر است. (پیش‌فرض: "MEDIUM") | COMBO | بله | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | کنترل تصادفی‌بودن. مقدار پایین‌تر، متمرکزتر/قطعی‌تر است؛ مقدار بالاتر، خلاقانه‌تر است. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 2.0 |
| `top_p` | نمونه‌برداری هسته (Nucleus sampling): از کوچک‌ترین مجموعه توکن نمونه‌برداری کن که احتمال تجمعی آن به top_p برسد. (پیش‌فرض: 0.95) | FLOAT | بله | 0.0 تا 1.0 |
| `max_output_tokens` | حداکثر توکن‌هایی که تولید می‌شوند، شامل تفکر داخلی مدل. با `thinking_level` برابر HIGH، مقدار کم ممکن است جایی برای پاسخ باقی نگذارد؛ اگر پاسخ‌ها خالی یا ناقص برگشتند، این مقدار را افزایش دهید. مدل وقتی تمام می‌کند زودتر متوقف می‌شود، بنابراین سقف بالاتر برای پاسخ‌های کوتاه هزینه اضافی ندارد. (پیش‌فرض: 32768) | INT | بله | 16 تا 65536 |

### ورودی‌های رسانه و فایل

ورودی‌های زیر بین هر سه مدل مشترک هستند و در کنار ورودی‌های مخصوص هر مدل ظاهر می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | اسلات قابل افزایش: از 1 تا 16 تصویر را متصل کنید (`image_1` ... `image_16`). تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. | IMAGE | خیر | 0 تا 16 تصویر |
| `audio` | اسلات قابل افزایش: یک کلیپ صوتی را متصل کنید (`audio_1`). کلیپ صوتی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | AUDIO | خیر | 0 تا 1 کلیپ |
| `video` | اسلات قابل افزایش: یک کلیپ ویدیویی را متصل کنید (`video_1`). کلیپ ویدیویی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | VIDEO | خیر | 0 تا 1 کلیپ |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌ها را از گره Gemini Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر |  |

**توجه:** وقتی رسانه (تصاویر، صدا یا ویدیو) متصل می‌شود، گره ابتدا 10 مورد رسانه را به ذخیره‌سازی ComfyAPI آپلود کرده و آن‌ها را به‌صورت URL ارسال می‌کند؛ این سهمیه URL بین همه انواع رسانه مشترک است و به ترتیب مصرف می‌شود (ابتدا ویدیو، سپس صدا، سپس تصاویر). هر رسانه باقی‌مانده به‌صورت داده base64 به‌صورت درون‌خطی کدگذاری می‌شود، با حداکثر بار ترکیبی درون‌خطی 18 مگابایت. اگر بار درون‌خطی بیش از 18 مگابایت شود، گره خطا صادر می‌کند. پارامتر `prompt` باید حداقل یک نویسه غیرفضایی داشته باشد. تنظیم `seed` روی 0 به‌معنای درخواست دانه تصادفی است.
