# Google Gemini

با مدل‌های Gemini گوگل پاسخ‌های متنی تولید کنید. یک درخواست متنی و به‌صورت اختیاری یک یا چند تصویر، کلیپ صوتی، ویدیو یا فایل را به‌عنوان زمینه چندوجهی ارائه دهید. این گره درخواست و هر رسانه پیوست‌شده را به مدل انتخاب‌شده می‌فرستد و پاسخ متنی مدل را برمی‌گرداند.

**نکته:** این گره در کد منبع به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

### ورودی‌های رسانه و فایل

ورودی‌های زیر میان همه مدل‌ها مشترک‌اند و در کنار ورودی‌های مخصوص مدل نمایش داده می‌شوند.

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | جایگاه قابل افزایش: 1 تا 16 تصویر را متصل کنید (`image_1` ... `image_16`). تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. حداکثر 16 تصویر. | IMAGE | خیر | 0 تا 16 تصویر |
| `audio` | جایگاه قابل افزایش: یک کلیپ صوتی را متصل کنید (`audio_1`). کلیپ صوتی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | AUDIO | خیر | 0 تا 1 کلیپ |
| `video` | جایگاه قابل افزایش: یک کلیپ ویدیویی را متصل کنید (`video_1`). کلیپ ویدیویی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | VIDEO | خیر | 0 تا 1 کلیپ |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌هایی از گره Gemini Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر |  |

**نکته:** وقتی رسانه (تصویر، صدا یا ویدیو) پیوست می‌شود، گره 10 مورد اول رسانه را در فضای ذخیره‌سازی ComfyAPI بارگذاری می‌کند و آن‌ها را به‌صورت URL ارسال می‌کند؛ این سهمیه URL میان همه انواع رسانه مشترک است و به ترتیب مصرف می‌شود (ابتدا ویدیو، سپس صدا، سپس تصاویر). هر رسانه باقی‌مانده به‌صورت درون‌خطی به‌شکل داده base64 کدگذاری می‌شود، با حداکثر بار درون‌خطی ترکیبی 18 MB. اگر بار درون‌خطی از 18 MB فراتر رود، گره خطا ایجاد می‌کند. پارامتر `prompt` باید حداقل شامل یک نویسه غیرفاصله باشد. تنظیم `seed` روی 0 درخواست بذر تصادفی می‌کند.
