# Google Gemini

پاسخ‌های متنی را با مدل‌های Gemini گوگل تولید کنید. یک prompt متنی و به‌صورت دلخواه، یک یا چند تصویر، کلیپ صوتی، ویدیو یا فایل را به‌عنوان زمینه چندوجهی (multimodal) ارائه دهید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل Gemini که برای تولید پاسخ استفاده می‌شود. | DYNAMIC_COMBO | بله | `"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `راهنما` | ورودی متنی به مدل. دستورالعمل‌ها، پرسش‌ها یا زمینه را با جزئیات وارد کنید. باید حداقل یک نویسه غیرخالی داشته باشد. (پیش‌فرض: "") | STRING | بله |  |
| `seed` | دانه (Seed) برای نمونه‌برداری. برای دانه تصادفی مقدار 0 را قرار دهید. خروجی قطعی تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

### ورودی‌های رسانه و فایل

ورودی‌های زیر بین هر چهار مدل مشترک هستند و در کنار ورودی‌های مخصوص هر مدل ظاهر می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | اسلات توسعه‌پذیر: ۱ تا ۱۶ تصویر را متصل کنید (`image_1` ... `image_16`). تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. حداکثر ۱۶ تصویر. | IMAGE | خیر | 0 تا 16 تصویر |
| `audio` | اسلات توسعه‌پذیر: یک کلیپ صوتی را متصل کنید (`audio_1`). کلیپ صوتی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | AUDIO | خیر | 0 تا 1 کلیپ |
| `video` | اسلات توسعه‌پذیر: یک کلیپ ویدیویی را متصل کنید (`video_1`). کلیپ ویدیویی اختیاری برای استفاده به‌عنوان زمینه برای مدل. | VIDEO | خیر | 0 تا 1 کلیپ |
| `files` | فایل‌(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌های گره Gemini Input Files را می‌پذیرد. | GEMINI_INPUT_FILES | خیر |  |

**نکته:** هنگامی که رسانه (تصاویر، صدا یا ویدیو) متصل می‌شود، گره ۱۰ مورد رسانه اول را در حافظه ComfyAPI بارگذاری کرده و آن‌ها را به‌صورت URL ارسال می‌کند؛ این سهمیه URL بین همه انواع رسانه مشترک است و به ترتیب مصرف می‌شود (ابتدا ویدیو، سپس صدا، سپس تصاویر). هر رسانه باقی‌مانده به‌صورت درون‌خطی (inline) با داده base64 کدگذاری می‌شود، با حداکثر بار ترکیبی درون‌خطی 18 مگابایت. اگر بار درون‌خطی از 18 مگابایت بیشتر شود، گره خطا ایجاد می‌کند. پارامتر `prompt` باید حداقل یک نویسه غیرخالی داشته باشد. تنظیم `seed` روی 0 درخواست دانه تصادفی می‌کند.
