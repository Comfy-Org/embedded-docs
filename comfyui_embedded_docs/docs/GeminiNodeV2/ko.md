# Google Gemini

Google의 Gemini 모델로 텍스트 응답을 생성합니다. 텍스트 프롬프트와 선택적으로 하나 이상의 이미지, 오디오 클립, 비디오 또는 파일을 멀티모달 컨텍스트로 제공하십시오.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 응답 생성에 사용되는 Gemini 모델입니다. | DYNAMIC_COMBO | 예 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 모델에 입력할 텍스트입니다. 자세한 지침, 질문 또는 맥락을 포함하십시오. 공백이 아닌 문자가 하나 이상 포함되어야 합니다. (기본값: "") | STRING | 예 |  |
| `seed` | 샘플링을 위한 시드입니다. 무작위 시드를 사용하려면 0으로 설정하십시오. 결정적 출력은 보장되지 않습니다. (기본값: 42) | INT | 예 | 0 ~ 2147483647 |
| `system_prompt` | 모델의 동작을 지정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 |  |

### Gemini 3.5 Flash 입력

이 입력은 `model`이 `"Gemini 3.5 Flash"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | 답변 전에 모델이 내부적으로 추론하는 강도입니다. HIGH는 어려운 작업에서 품질을 향상시키지만 더 많은 (추론) 토큰을 소비하고 속도가 느려집니다. (기본값: "MEDIUM") | COMBO | 예 | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | 무작위성을 제어합니다. 낮을수록 더 집중적/결정적이며, 높을수록 더 창의적입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 2.0 |
| `top_p` | 핵 샘플링: 누적 확률이 top_p에 도달하는 가장 작은 토큰 집합에서 샘플링합니다. (기본값: 0.95) | FLOAT | 예 | 0.0 ~ 1.0 |
| `max_output_tokens` | 모델의 내부 추론을 포함하여 생성할 최대 토큰 수입니다. thinking_level이 HIGH인 경우 값이 낮으면 답변을 위한 공간이 없을 수 있습니다. 응답이 비어 있거나 잘려서 반환되면 이 값을 늘리십시오. 모델은 작업 완료 시 조기 종료되므로 짧은 응답의 경우 상한을 높여도 추가 비용이 들지 않습니다. (기본값: 32768) | INT | 예 | 16 ~ 65536 |

### 미디어 및 파일 입력

다음 입력은 세 모델 모두에 공통되며 모델별 입력과 함께 나타납니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 1~16개의 이미지(`image_1` ... `image_16`)를 연결하십시오. 모델의 컨텍스트로 사용할 선택적 이미지입니다. | IMAGE | 아니요 | 0 ~ 16 images |
| `audio` | 확장 가능한 슬롯: 오디오 클립 하나(`audio_1`)를 연결하십시오. 모델의 컨텍스트로 사용할 선택적 오디오 클립입니다. | AUDIO | 아니요 | 0 ~ 1 clip |
| `video` | 확장 가능한 슬롯: 비디오 클립 하나(`video_1`)를 연결하십시오. 모델의 컨텍스트로 사용할 선택적 비디오 클립입니다. | VIDEO | 아니요 | 0 ~ 1 clip |
| `files` | 모델의 컨텍스트로 사용할 선택적 파일입니다. Gemini 입력 파일 노드의 입력을 허용합니다. | GEMINI_INPUT_FILES | 아니요 |  |

**참고:** 미디어(이미지, 오디오 또는 비디오)가 첨부되면 노드는 처음 10개의 미디어 항목을 ComfyAPI 저장소에 업로드하고 이를 URL로 전달합니다. 이 URL 예산은 모든 미디어 유형에 공유되며 순서대로 소비됩니다(비디오 먼저, 그 다음 오디오, 그 다음 이미지). 나머지 미디어는 base64 데이터로 인라인 인코딩되며, 최대 결합 인라인 페이로드는 18MB입니다. 인라인 페이로드가 18MB를 초과하면 노드에서 오류를 발생시킵니다. `prompt` 매개변수는 공백이 아닌 문자가 하나 이상 포함되어야 합니다. `seed`를 0으로 설정하면 무작위 시드를 요청합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `output` | Gemini 모델에서 생성된 텍스트 응답입니다. 모델이 텍스트를 생성하지 않으면 "Empty response from Gemini model..." 문자열이 반환됩니다. | STRING |
