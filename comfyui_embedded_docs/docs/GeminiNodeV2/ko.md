# Google Gemini

Google의 Gemini 모델을 사용하여 텍스트 응답을 생성합니다. 텍스트 프롬프트와 선택적으로 하나 이상의 이미지, 오디오 클립, 비디오 또는 파일을 멀티모달 컨텍스트로 제공하십시오.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 응답을 생성하는 데 사용되는 Gemini 모델입니다. | COMBO | 예 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 모델에 대한 텍스트 입력입니다. 자세한 지침, 질문 또는 컨텍스트를 포함하십시오. 공백이 아닌 문자가 하나 이상 포함되어야 합니다. (기본값: "") | STRING | 예 |  |
| `seed` | 샘플링을 위한 시드(seed)입니다. 무작위 시드를 원하면 0으로 설정하십시오. 결정적 출력은 보장되지 않습니다. (기본값: 42) | INT | 예 | 0 to 2147483647 |
| `system_prompt` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: "") | STRING | 아니오 |  |

### Gemini 3.5 Flash 입력

이 입력들은 `model`이 `"Gemini 3.5 Flash"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | 모델이 응답하기 전에 내부적으로 추론하는 정도입니다. HIGH는 어려운 작업에서 품질을 향상시키지만 더 많은 thinking 토큰을 소비하고 속도가 느립니다. (기본값: "MEDIUM") | COMBO | 예 | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | 무작위성을 제어합니다. 값이 낮을수록 더 집중적/결정적이며, 높을수록 더 창의적입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 2.0 |
| `top_p` | 핵 샘플링(nucleus sampling): 누적 확률이 top_p에 도달하는 가장 작은 토큰 집합에서 샘플링합니다. (기본값: 0.95) | FLOAT | 예 | 0.0 to 1.0 |
| `max_output_tokens` | 모델의 내부 추론을 포함하여 생성할 최대 토큰 수입니다. thinking_level이 HIGH인 경우 값이 낮으면 답변을 위한 공간이 남지 않을 수 있습니다. 응답이 비어 있거나 잘린 경우 이 값을 높이십시오. 모델은 작업이 완료되면 일찍 중지되므로 짧은 답변의 경우 상한을 높여도 추가 비용이 들지 않습니다. (기본값: 32768) | INT | 예 | 16 to 65536 |

### 미디어 및 파일 입력

다음 입력은 세 모델 모두에 공통되며 모델별 입력과 함께 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 슬롯: `image_1` ... `image_16`에 1~16개의 이미지를 연결할 수 있습니다. 모델의 컨텍스트로 사용할 선택적 이미지입니다. | IMAGE | 아니오 | 0 to 16 images |
| `audio` | 확장 슬롯: `audio_1`에 오디오 클립 하나를 연결할 수 있습니다. 모델의 컨텍스트로 사용할 선택적 오디오 클립입니다. | AUDIO | 아니오 | 0 to 1 clip |
| `video` | 확장 슬롯: `video_1`에 비디오 클립 하나를 연결할 수 있습니다. 모델의 컨텍스트로 사용할 선택적 비디오 클립입니다. | VIDEO | 아니오 | 0 to 1 clip |
| `files` | 모델의 컨텍스트로 사용할 선택적 파일입니다. Gemini Input Files 노드에서 입력을 받습니다. | GEMINI_INPUT_FILES | 아니오 |  |

**참고:** 미디어(이미지, 오디오 또는 비디오)가 첨부되면 노드는 처음 10개의 미디어 항목을 ComfyAPI 저장소에 업로드하여 URL로 전달합니다. 이 URL 예산은 모든 미디어 유형에 걸쳐 공유되며 비디오, 오디오, 이미지 순서로 사용됩니다. 나머지 미디어는 인라인으로 base64 데이터로 인코딩되며, 최대 결합 인라인 페이로드는 18MB입니다. 인라인 페이로드가 18MB를 초과하면 노드에서 오류를 발생시킵니다. `prompt` 매개변수는 공백이 아닌 문자를 하나 이상 포함해야 합니다. `seed`를 0으로 설정하면 무작위 시드를 요청합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Gemini 모델이 생성한 텍스트 응답입니다. 모델이 텍스트를 생성하지 않으면 "Empty response from Gemini model..." 문자열이 반환됩니다. | STRING |
