# Google Gemini

Генерируйте текстовые ответы с помощью моделей Google Gemini. Укажите текстовый запрос и, при необходимости, одно или несколько изображений, аудиоклипов, видео или файлов в качестве мультимодального контекста. Узел отправляет запрос и любые прикреплённые медиафайлы выбранной модели и возвращает текстовый ответ модели.

**Примечание:** В исходном коде этот узел помечен как устаревший.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель Gemini, используемая для генерации ответа. При выборе модели ниже отображается её собственный набор входов. | DYNAMIC_COMBO | Да | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `запрос` | Текстовый ввод для модели. Включите подробные инструкции, вопросы или контекст. (по умолчанию: "") | STRING | Да | Должен содержать хотя бы один непробельный символ |
| `seed` | Сид для сэмплирования. Установите 0 для случайного сида. Детерминированный вывод не гарантируется. (по умолчанию: 42) | INT | Да | от 0 до 2147483647 |
| `системный запрос` | Основополагающие инструкции, которые определяют поведение модели. (по умолчанию: "") | STRING | Нет |  |

### Входы Gemini 3.8 Flash

Эти входы появляются, когда для `model` выбрано значение `"Gemini 3.8 Flash"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | Насколько интенсивно модель рассуждает внутренне перед ответом. HIGH повышает качество на сложных задачах, но требует больше токенов (на мышление) и работает медленнее. (по умолчанию: "MEDIUM") | COMBO | Да | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая внутренние рассуждения модели. При `thinking_level` HIGH низкое значение может не оставить места для ответа; увеличьте его, если ответы возвращаются пустыми или обрезанными. Модель останавливается досрочно по завершении, поэтому более высокий лимит не увеличивает затраты для коротких ответов. (по умолчанию: 32768) | INT | Да | от 16 до 65536 |

**Примечание:** Эта модель не предоставляет элементы управления сэмплированием `temperature` или `top_p`.

### Входы мультимедиа и файлов

Следующие входы являются общими для всех моделей и отображаются вместе с входами, специфичными для модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 16 изображений (`image_1` ... `image_16`). Необязательные изображения для использования в качестве контекста модели. До 16 изображений. | IMAGE | Нет | от 0 до 16 изображений |
| `audio` | Расширяемый слот: подключите один аудиоклип (`audio_1`). Необязательный аудиоклип для использования в качестве контекста модели. | AUDIO | Нет | от 0 до 1 клипа |
| `video` | Расширяемый слот: подключите один видеоклип (`video_1`). Необязательный видеоклип для использования в качестве контекста модели. | VIDEO | Нет | от 0 до 1 клипа |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входы от узла Gemini Input Files. | GEMINI_INPUT_FILES | Нет |  |

**Примечание:** Когда прикреплены медиафайлы (изображения, аудио или видео), узел загружает первые 10 медиаэлементов в хранилище ComfyAPI и передаёт их как URL-адреса; этот лимит URL-адресов является общим для всех типов медиа и расходуется по порядку (сначала видео, затем аудио, затем изображения). Любые оставшиеся медиафайлы кодируются встроенно как данные base64, при этом максимальный суммарный размер встроенной полезной нагрузки составляет 18 МБ. Если размер встроенной полезной нагрузки превысит 18 МБ, узел выдаёт ошибку. Параметр `prompt` должен содержать хотя бы один непробельный символ. Установка `seed` в 0 запрашивает случайный сид.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Gemini. Если модель не создаёт текст, возвращается строка "Empty response from Gemini model...". | STRING |
