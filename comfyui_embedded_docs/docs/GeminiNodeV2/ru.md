# Google Gemini

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель Gemini, используемая для генерации ответа. | COMBO | Да | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `запрос` | Текстовый запрос для модели. Включайте подробные инструкции, вопросы или контекст. Должен содержать хотя бы один непробельный символ. (по умолчанию: "") | STRING | Да |  |
| `seed` | Сид для сэмплирования. Установите 0 для случайного сида. Детерминированный вывод не гарантируется. (по умолчанию: 42) | INT | Да | от 0 до 2147483647 |
| `системный запрос` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет |  |

### Входы Gemini 3.5 Flash

Эти входы появляются, когда `model` установлен на `"Gemini 3.5 Flash"`.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | Насколько интенсивно модель рассуждает перед ответом. HIGH повышает качество на сложных задачах, но требует больше токенов рассуждения и работает медленнее. (по умолчанию: "MEDIUM") | COMBO | Да | `"MINIMAL"`<br>`"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | Управляет случайностью. Более низкие значения дают более сфокусированный/детерминированный результат, более высокие — более креативный. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 2.0 |
| `top_p` | Ядерное сэмплирование: выборка из наименьшего множества токенов, чья совокупная вероятность достигает top_p. (по умолчанию: 0.95) | FLOAT | Да | от 0.0 до 1.0 |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая внутренние рассуждения модели. При thinking_level HIGH низкое значение может не оставить места для ответа; увеличьте его, если ответы возвращаются пустыми или обрезанными. Модель останавливается досрочно после завершения, поэтому более высокий лимит ничего не стоит для коротких ответов. (по умолчанию: 32768) | INT | Да | от 16 до 65536 |

### Медиа и файловые входы

Следующие входы являются общими для всех трёх моделей и появляются вместе с входами, специфичными для модели.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 16 изображений (`image_1` ... `image_16`). Необязательные изображения для использования в качестве контекста модели. | IMAGE | Нет | от 0 до 16 изображений |
| `audio` | Расширяемый слот: подключите один аудиоклип (`audio_1`). Необязательный аудиоклип для использования в качестве контекста модели. | AUDIO | Нет | от 0 до 1 клипа |
| `video` | Расширяемый слот: подключите один видеоклип (`video_1`). Необязательный видеоклип для использования в качестве контекста модели. | VIDEO | Нет | от 0 до 1 клипа |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входы от узла Gemini Input Files. | GEMINI_INPUT_FILES | Нет |  |

**Примечание:** Когда прикреплены медиафайлы (изображения, аудио или видео), узел загружает первые 10 медиаэлементов в хранилище ComfyAPI и передаёт их в виде URL-адресов; этот бюджет URL является общим для всех типов медиа и расходуется по порядку (сначала видео, затем аудио, затем изображения). Оставшиеся медиа кодируются встроенно в виде данных base64, с максимальной суммарной встроенной полезной нагрузкой 18 МБ. Если встроенная полезная нагрузка превысит 18 МБ, узел выдаст ошибку. Параметр `prompt` должен содержать хотя бы один непробельный символ. Установка `seed` в 0 запрашивает случайный сид.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Gemini. Если модель не создаёт текст, возвращается строка "Empty response from Gemini model...". | STRING |
