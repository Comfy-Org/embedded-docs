# Google Gemini

Генерируйте текстовые ответы с помощью моделей Google Gemini. Предоставьте текстовый запрос и, опционально, одно или несколько изображений, аудиоклипов, видео или файлов в качестве мультимодального контекста.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель Gemini, используемая для генерации ответа. | DYNAMIC_COMBO | Да | `"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `запрос` | Текстовый ввод для модели. Включайте подробные инструкции, вопросы или контекст. Должен содержать как минимум один непробельный символ. (по умолчанию: "") | STRING | Да |  |
| `seed` | Начальное число для семплирования. Установите 0 для случайного начального числа. Детерминированный вывод не гарантируется. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |
| `системный запрос` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет |  |

### Входы Gemini 3.7 Flash

Эти входы появляются, когда для параметра `model` установлено значение `"Gemini 3.7 Flash"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | Насколько интенсивно модель рассуждает перед ответом. Значение HIGH повышает качество на сложных задачах, но требует больше токенов (на рассуждение) и работает медленнее. (по умолчанию: "MEDIUM") | COMBO | Да | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `temperature` | Управляет случайностью. Более низкие значения дают более сфокусированные/детерминированные результаты, более высокие — более креативные. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 2.0 |
| `top_p` | Ядерная выборка: выбор из наименьшего множества токенов, чья совокупная вероятность достигает top_p. (по умолчанию: 0.95) | FLOAT | Да | 0.0 до 1.0 |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая внутренние рассуждения модели. При thinking_level HIGH низкое значение может не оставить места для ответа; увеличьте его, если ответы возвращаются пустыми или обрезанными. Модель останавливается досрочно по завершении, поэтому более высокий предел ничего не стоит для коротких ответов. (по умолчанию: 32768) | INT | Да | 16 до 65536 |

### Медиа- и файловые входы

Следующие входы являются общими для всех четырёх моделей и появляются вместе с входами, специфичными для моделей.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 16 изображений (`image_1` ... `image_16`). Необязательное изображение(я) для использования в качестве контекста модели. До 16 изображений. | IMAGE | Нет | 0 до 16 images |
| `audio` | Расширяемый слот: подключите один аудиоклип (`audio_1`). Необязательный аудиоклип для использования в качестве контекста модели. | AUDIO | Нет | 0 до 1 clip |
| `video` | Расширяемый слот: подключите один видеоклип (`video_1`). Необязательный видеоклип для использования в качестве контекста модели. | VIDEO | Нет | 0 до 1 clip |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входы от узла Gemini Input Files. | GEMINI_INPUT_FILES | Нет |  |

**Примечание:** Когда прикреплены медиафайлы (изображения, аудио или видео), узел загружает первые 10 медиаэлементов в хранилище ComfyAPI и передаёт их как URL-адреса; этот бюджет URL-адресов является общим для всех типов медиа и расходуется по порядку (сначала видео, затем аудио, затем изображения). Оставшиеся медиа кодируются встроенными данными base64, при этом максимальный суммарный размер встроенной полезной нагрузки составляет 18 МБ. Если встроенная полезная нагрузка превышает 18 МБ, узел вызовет ошибку. Параметр `prompt` должен содержать по крайней мере один непробельный символ. Установка `seed` в значение 0 запрашивает случайное начальное число.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Gemini. Если модель не выдаёт текст, возвращается строка "Empty response from Gemini model...". | STRING |
