# Google Gemini

使用 Google 的 Gemini 模型生成文本响应。提供一个文本提示，并可选择性地提供一个或多个图像、音频片段、视频或文件作为多模态上下文。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成响应的 Gemini 模型。 | DYNAMIC_COMBO | 是 | `"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 模型的文本输入。可包含详细指令、问题或上下文。必须至少包含一个非空白字符。（默认值：""） | STRING | 是 |  |

| `system_prompt` | 规定模型行为的基础指令。（默认值：""） | STRING | 否 |  |

### 媒体和文件输入

以下输入由上述三个模型共用，并与各模型专属输入一同显示。

**注意：** 当附加媒体（图像、音频或视频）时，节点会将前 10 个媒体项目上传到 ComfyAPI 存储，并以 URL 形式传递；此 URL 额度由所有媒体类型共享，并按顺序消耗（先是视频，然后是音频，最后是图像）。其余媒体将以内联 base64 数据的形式进行编码，内联负载的最大合计为 18 MB。如果内联负载超过 18 MB，节点将引发错误。`prompt` 参数必须至少包含一个非空白字符。将 `seed` 设置为 0 可请求随机种子。
