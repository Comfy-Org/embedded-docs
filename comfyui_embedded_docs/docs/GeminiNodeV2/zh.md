# Google Gemini

使用 Google 的 Gemini 模型生成文本回复。提供一个文本提示词，并可选地附带一张或多张图像、音频片段、视频或文件作为多模态上下文。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成回复的 Gemini 模型。 | DYNAMIC_COMBO | 是 | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 输入给模型的文本。请包含详细的指令、问题或上下文。必须至少包含一个非空白字符。（默认值：""） | STRING | 是 |  |
| `seed` | 采样种子。设置为 0 表示使用随机种子。不保证输出可复现。（默认值：42） | INT | 是 | 0 到 2147483647 |
| `system_prompt` | 用于规定模型行为的基础指令。（默认值：""） | STRING | 否 |  |
