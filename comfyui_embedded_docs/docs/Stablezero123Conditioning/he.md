# Stablezero123Conditioning

צומת זה מיועד לעיבוד והתניה של נתונים לשימוש במודלים StableZero123, תוך התמקדות בהכנת הקלט בפורמט ספציפי שתואם למודלים אלה ומותאם עבורם.

## קלטים

| פרמטר | תיאור | Comfy dtype |
| --- | --- | --- |
| `clip_vision` | מעבד נתונים חזותיים כדי להתאים לדרישות המודל, ומשפר את הבנת המודל בהקשר חזותי. | `CLIP_VISION` |
| `init_image` | משמש כקלט התמונה ההתחלתי עבור המודל, וקובע את קו הבסיס לפעולות נוספות מבוססות תמונה. | `IMAGE` |
| `vae` | משלב פלטים של מקודד אוטומטי וריאציוני, ומאפשר למודל ליצור או לשנות תמונות. | `VAE` |
| `width` | מציין את רוחב תמונת הפלט, ומאפשר שינוי גודל דינמי בהתאם לצורכי המודל. | `INT` |
| `height` | קובע את גובה תמונת הפלט, ומאפשר התאמה אישית של מידות הפלט. | `INT` |
| `batch_size` | שולט במספר התמונות המעובדות באצווה אחת, ומאפשר אופטימיזציה של יעילות החישוב. | `INT` |
| `elevation` | מכוונן את זווית הגובה עבור רינדור מודל תלת-ממדי, ומשפר את ההבנה המרחבית של המודל. | `FLOAT` |
| `azimuth` | משנה את זווית האזימוט להמחשת מודל תלת-ממדי, ומשפר את תפיסת הכיוון של המודל. | `FLOAT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | יוצר וקטורי התניה חיוביים, ומסייע בחיזוק מאפיינים חיוביים במודל. | `CONDITIONING` |
| `negative` | מייצר וקטורי התניה שליליים, ומסייע למודל להימנע ממאפיינים מסוימים. | `CONDITIONING` |
| `latent` | יוצר ייצוגים סמויים, ומאפשר למודל תובנות עמוקות יותר לגבי הנתונים. | `LATENT` |
