# Recraft V4: текст в изображение

Этот узел генерирует изображения по текстовым описаниям с использованием моделей ИИ Recraft V4 и V4.1. Он отправляет ваш промпт во внешний API и возвращает сгенерированные изображения. Вы можете управлять результатом, задавая модель, размер изображения и количество создаваемых изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. | DYNAMIC_COMBO | Да | `"recraftv4_1"`<br>`"recraftv4_1_utility"`<br>`"recraftv4_1_pro"`<br>`"recraftv4_1_utility_pro"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `prompt` | Промпт для генерации изображения. Максимум 10 000 символов. | STRING | Да | N/A |
| `negative_prompt` | Этот вход игнорируется: негативный промпт не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | N/A |
| `n` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `recraft_controls` | Необязательные дополнительные элементы управления генерацией через узел Recraft Controls. | CUSTOM | Нет | N/A |

### Входы recraftv4_1, recraftv4_1_utility и recraftv4

Общие для `recraftv4_1`, `recraftv4_1_utility` и `recraftv4`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения (по умолчанию: "1024x1024"). | COMBO | Да | Доступно несколько вариантов (стандартные размеры Recraft V4, включая "1024x1024") |

### Входы recraftv4_1_pro, recraftv4_1_utility_pro и recraftv4_pro

Общие для `recraftv4_1_pro`, `recraftv4_1_utility_pro` и `recraftv4_pro`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения (по умолчанию: "2048x2048"). | COMBO | Да | Доступно несколько вариантов (размеры Recraft V4 Pro, включая "2048x2048") |

**Примечание:** Параметр `size` является динамическим входом, доступные варианты которого зависят от выбранной модели `model`. Значение `seed` не гарантирует воспроизводимость результатов генерации изображений. Если вы используете идентификатор стиля из Infinite Style Library, убедитесь, что это не стиль Vector art, так как в этом случае может быть возвращён SVG-данные вместо изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. | IMAGE |
