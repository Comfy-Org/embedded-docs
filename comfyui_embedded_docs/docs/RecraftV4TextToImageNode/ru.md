# Recraft V4: текст в изображение

Генерирует изображения из текстовых промптов с использованием моделей Recraft V4 и V4.1. Он отправляет промпт и выбранные настройки в API Recraft и возвращает сгенерированное изображение или изображения. Если используются эталонные изображения стиля, также возвращается созданный ID стиля.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. Модели recraftv4_styles созданы для генерации с согласованным стилем и всегда требуют `style_id` или `style_references`. `recraftv4_1_flash` — самая быстрая и дешёвая модель, вообще не поддерживает стили. | DYNAMIC_COMBO | Да | "recraftv4_1"<br>"recraftv4_1_flash"<br>"recraftv4_1_utility"<br>"recraftv4_1_pro"<br>"recraftv4_1_utility_pro"<br>"recraftv4"<br>"recraftv4_pro"<br>"recraftv4_styles"<br>"recraftv4_styles_pro" |
| `prompt` | Промпт для генерации изображения. Максимум 10 000 символов. | STRING | Да | от 1 до 10000 символов |
| `negative_prompt` | Этот вход игнорируется: негативный промпт не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | N/A |
| `n` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 6 |
| `seed` | Сид для определения, нужно ли перезапускать узел; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `recraft_controls` | Необязательные дополнительные элементы управления генерацией через узел Recraft Controls. | CUSTOM | Нет | N/A |
| `style_id` | UUID стиля Recraft V4 для применения, например из узла Recraft V4 Create Style или выхода `style_id` предыдущего запуска. Нельзя комбинировать со `style_references` (по умолчанию: пусто). | STRING | Нет | Корректная строка UUID |
| `style_match` | Насколько точно следовать стилю: precise подробно воспроизводит его, flexible соответствует общему виду. Используется только когда задан стиль (по умолчанию: "precise"). | COMBO | Нет | "precise"<br>"flexible" |

### Входы recraftv4_1, recraftv4_1_flash, recraftv4_1_utility, recraftv4 и recraftv4_styles

Эти модели используют один и тот же параметр `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения (по умолчанию: "1024x1024"). | COMBO | Да | Доступно несколько вариантов (стандартные размеры Recraft V4; включает "1024x1024") |

### Входы recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_pro и recraftv4_styles_pro

Эти модели используют один и тот же параметр `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер сгенерированного изображения (по умолчанию: "2048x2048"). | COMBO | Да | Доступно несколько вариантов (размеры pro-моделей Recraft V4; включает "2048x2048") |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `style_references` | Эталонные изображения для создания стиля на лету, оплачиваются дополнительно к генерации. Созданный стиль возвращается как `style_id` для повторного использования. Нельзя комбинировать со `style_id`. Расширяемый слот: подключите от 1 до N изображений (`style_reference_1`, `style_reference_2`, ...). | IMAGE | Нет | от 0 до максимального количества эталонных изображений, разрешённого API Recraft; общий размер в закодированном виде не должен превышать 10 МБ |

**Примечание:** Параметр `size` — это динамический вход, доступные варианты которого меняются в зависимости от выбранной `model`. Модели `recraftv4_styles` и `recraftv4_styles_pro` всегда требуют стиль: подключите эталонные изображения стиля или укажите `style_id`. Входы `style_id` и `style_references` взаимоисключающие — укажите только один из них. `style_id` должен быть корректным UUID. Вход `style_match` используется только когда задан стиль. Эталонные изображения стиля оплачиваются дополнительно к генерации, и их общий размер в закодированном виде не должен превышать 10 МБ. Значение `seed` не гарантирует воспроизводимость выходных изображений. Если вы используете ID стиля из Infinite Style Library, убедитесь, что это не стиль Vector art, так как это может вернуть данные SVG вместо изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. | IMAGE |
| `style_id` | ID стиля, использованный или созданный в этой генерации. Когда предоставлены эталонные изображения стиля, созданный стиль возвращается здесь для повторного использования; пустая строка, если стиль не используется. | STRING |
