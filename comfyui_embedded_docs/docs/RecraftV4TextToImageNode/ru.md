# Recraft V4: текст в изображение

Recraft V4 Text to Image

Этот узел генерирует изображения по текстовым описаниям с помощью ИИ-моделей Recraft V4 и V4.1. Он отправляет ваш промпт во внешний API и возвращает сгенерированные изображения. Вы можете управлять результатом, указывая модель, размер изображения, количество изображений и, при необходимости, стиль — либо в виде сохранённого идентификатора стиля, либо на основе эталонных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации. Модели recraftv4_styles предназначены для генерации с сохранением единого стиля и всегда требуют style_id или style_references. | DYNAMIC_COMBO | Да | "recraftv4_1"<br>"recraftv4_1_utility"<br>"recraftv4_1_pro"<br>"recraftv4_1_utility_pro"<br>"recraftv4"<br>"recraftv4_pro"<br>"recraftv4_styles"<br>"recraftv4_styles_pro" |
| `prompt` | Промпт для генерации изображения. Максимум 10 000 символов. | STRING | Да | от 1 до 10 000 символов |
| `negative_prompt` | Этот вход игнорируется: негативный промпт не поддерживается моделями Recraft V4 и V4.1. | STRING | Да | Н/Д |
| `n` | Количество изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 6 |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
| `recraft_controls` | Необязательные дополнительные элементы управления генерацией через узел Recraft Controls. | CUSTOM | Нет | Н/Д |
| `style_id` | UUID применяемого стиля Recraft V4, например из узла Recraft V4 Create Style или из выхода style_id предыдущего запуска. Нельзя использовать вместе со style_references (по умолчанию: пусто). | STRING | Нет | Корректная строка UUID |
| `style_match` | Насколько точно следовать стилю: precise воспроизводит его детально, flexible соответствует общему виду. Используется только тогда, когда стиль задан (по умолчанию: "precise"). | COMBO | Нет | "precise"<br>"flexible" |

### Входы recraftv4_1, recraftv4_1_utility, recraftv4 и recraftv4_styles

Эти модели используют один и тот же параметр `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения (по умолчанию: "1024x1024"). | COMBO | Да | Доступно несколько вариантов (стандартные размеры Recraft V4, включая "1024x1024") |

### Входы recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_pro и recraftv4_styles_pro

Эти модели используют один и тот же параметр `size`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `size` | Размер генерируемого изображения (по умолчанию: "2048x2048"). | COMBO | Да | Доступно несколько вариантов (размеры Pro для Recraft V4, включая "2048x2048") |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `style_references` | Эталонные изображения для создания стиля на лету; тарифицируются дополнительно к генерации. Созданный стиль возвращается в виде style_id для повторного использования. Нельзя использовать вместе со style_id. Расширяемый слот: подключайте от 1 до N изображений (style_reference_1, style_reference_2, ...). | IMAGE | Нет | от 0 до максимального количества эталонных изображений, которое допускает Recraft API; суммарный закодированный размер не должен превышать 10 МБ |

**Примечание:** Параметр `size` — это динамический вход, доступные значения которого зависят от выбранного параметра `model`. Модели `recraftv4_styles` и `recraftv4_styles_pro` всегда требуют стиль: подключите эталонные изображения или укажите `style_id`. Входы `style_id` и `style_references` взаимоисключающие — укажите только один из них. Значение `style_id` должно быть корректным UUID. Вход `style_match` используется только при заданном стиле. Эталонные изображения тарифицируются дополнительно к генерации, а их суммарный закодированный размер не должен превышать 10 МБ. Значение `seed` не гарантирует воспроизводимость выходных изображений. Если вы используете идентификатор стиля из библиотеки Infinite Style Library, убедитесь, что это не стиль Vector art, поскольку в этом случае могут быть возвращены SVG-данные вместо изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное изображение или пакет изображений. | IMAGE |
| `style_id` | Идентификатор стиля, использованный или созданный при этой генерации. Если были переданы эталонные изображения, созданный стиль возвращается здесь для повторного использования; пустая строка, если стиль не использовался. | STRING |
