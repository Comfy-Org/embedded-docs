# تبدیل متن به تصویر Recraft V4

تصاویری را از پرامپت‌های متنی با استفاده از مدل‌های Recraft V4 و V4.1 تولید می‌کند. پرامپت و تنظیمات انتخاب‌شده را به Recraft API می‌فرستد و تصویر یا تصاویر تولیدشده را بازمی‌گرداند. اگر از تصاویر مرجع سبک استفاده شود، شناسه سبک ساخته‌شده نیز بازگردانده می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید استفاده می‌شود. مدل‌های recraftv4_styles برای تولید سازگار با سبک ساخته شده‌اند و همیشه به یک style_id یا style_references نیاز دارند. | DYNAMIC_COMBO | بله | "recraftv4_1"<br>"recraftv4_1_utility"<br>"recraftv4_1_pro"<br>"recraftv4_1_utility_pro"<br>"recraftv4"<br>"recraftv4_pro"<br>"recraftv4_styles"<br>"recraftv4_styles_pro" |
| `prompt` | پرامپت برای تولید تصویر. حداکثر 10,000 کاراکتر. | STRING | بله | 1 تا 10000 کاراکتر |
| `negative_prompt` | این ورودی نادیده گرفته می‌شود: پرامپت منفی توسط مدل‌های Recraft V4 و V4.1 پشتیبانی نمی‌شود. | STRING | بله | N/A |
| `n` | تعداد تصاویر برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `seed` | Seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از Seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `recraft_controls` | کنترل‌های اضافی اختیاری روی تولید از طریق گره Recraft Controls. | CUSTOM | خیر | N/A |
| `style_id` | UUID یک سبک Recraft V4 برای اعمال، مثلاً از گره Recraft V4 Create Style یا خروجی style_id یک اجرای قبلی. نمی‌توان آن را با style_references ترکیب کرد (پیش‌فرض: خالی). | STRING | خیر | رشته UUID معتبر |
| `style_match` | میزان نزدیکی به سبک: precise آن را با جزئیات بازتولید می‌کند، flexible با ظاهر کلی مطابقت می‌کند. فقط زمانی استفاده می‌شود که سبکی ارائه شده باشد (پیش‌فرض: "precise"). | COMBO | خیر | "precise"<br>"flexible" |

### ورودی‌های recraftv4_1، recraftv4_1_utility، recraftv4 و recraftv4_styles

این مدل‌ها پارامتر `size` مشترک دارند.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "1024x1024"). | COMBO | بله | گزینه‌های متعدد موجود است (اندازه‌های استاندارد Recraft V4؛ شامل "1024x1024") |

### ورودی‌های recraftv4_1_pro، recraftv4_1_utility_pro، recraftv4_pro و recraftv4_styles_pro

این مدل‌ها پارامتر `size` مشترک دارند.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "2048x2048"). | COMBO | بله | گزینه‌های متعدد موجود است (اندازه‌های Pro مربوط به Recraft V4؛ شامل "2048x2048") |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `style_references` | تصاویر مرجع برای ساخت سبک به‌صورت در لحظه، که علاوه بر تولید صورت‌حساب می‌شوند. سبک ساخته‌شده به‌عنوان style_id برای استفاده مجدد بازگردانده می‌شود. نمی‌توان آن را با style_id ترکیب کرد. اسلات قابل گسترش: 1..N تصویر را متصل کنید (style_reference_1، style_reference_2، ...). | IMAGE | خیر | 0 تا حداکثر تعداد تصاویر مرجع مجاز توسط Recraft API؛ اندازه رمزگذاری‌شده کل نباید از 10 MB بیشتر شود |

**توجه:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کند. مدل‌های `recraftv4_styles` و `recraftv4_styles_pro` همیشه به یک سبک نیاز دارند: تصاویر مرجع سبک را متصل کنید یا یک `style_id` ارائه دهید. ورودی‌های `style_id` و `style_references` متقابلاً انحصاری هستند — فقط یکی از آن‌ها را ارائه دهید. یک `style_id` باید UUID معتبر باشد. ورودی `style_match` فقط زمانی استفاده می‌شود که سبکی ارائه شده باشد. تصاویر مرجع سبک علاوه بر تولید صورت‌حساب می‌شوند و اندازه رمزگذاری‌شده کل آن‌ها نباید از 10 MB بیشتر شود. مقدار `seed` تضمین‌کننده خروجی‌های تصویری قابل بازتولید نیست. اگر از یک شناسه سبک از Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک هنری Vector نباشد، زیرا ممکن است به‌جای تصویر داده SVG برگرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `output` | تصویر تولیدشده یا دسته‌ای از تصاویر. | IMAGE |
| `style_id` | شناسه سبکی که در این تولید استفاده یا ایجاد شده است. وقتی تصاویر مرجع سبک ارائه می‌شوند، سبک ساخته‌شده برای استفاده مجدد اینجا بازگردانده می‌شود؛ رشته خالی وقتی هیچ سبکی استفاده نشده است. | STRING |
