# تبدیل متن به تصویر Recraft V4

Generates images from text prompts using Recraft V4 and V4.1 models. It sends the prompt and selected settings to the Recraft API and returns the generated image or images. If style reference images are used, the created style ID is also returned.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید استفاده می‌شود. مدل‌های recraftv4_styles برای تولید با سبک یکدست ساخته شده‌اند و همیشه به یک style_id یا style_references نیاز دارند. `recraftv4_1_flash` سریع‌ترین و ارزان‌ترین مدل است و هیچ سبکی را پشتیبانی نمی‌کند. | DYNAMIC_COMBO | بله | "recraftv4_1"<br>"recraftv4_1_flash"<br>"recraftv4_1_utility"<br>"recraftv4_1_pro"<br>"recraftv4_1_utility_pro"<br>"recraftv4"<br>"recraftv4_pro"<br>"recraftv4_styles"<br>"recraftv4_styles_pro" |

| `تعداد` | تعداد تصاویری که باید تولید شود (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `بذر` | Seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |

### ورودی‌های recraftv4_1، recraftv4_1_flash، recraftv4_1_utility، recraftv4 و recraftv4_styles

این مدل‌ها پارامتر `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "1024x1024"). | COMBO | بله | گزینه‌های متعدد موجود است (اندازه‌های استاندارد Recraft V4؛ شامل "1024x1024") |

### ورودی‌های recraftv4_1_pro، recraftv4_1_utility_pro، recraftv4_pro و recraftv4_styles_pro

این مدل‌ها پارامتر `size` یکسانی دارند.

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "2048x2048"). | COMBO | بله | گزینه‌های متعدد موجود است (اندازه‌های pro Recraft V4؛ شامل "2048x2048") |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `style_references` | تصاویر مرجع برای ساخت سبک به‌صورت درجا، که هزینه آن جدا از تولید محاسبه می‌شود. سبک ایجادشده به‌عنوان style_id برای استفاده مجدد بازگردانده می‌شود. نمی‌توان آن را با style_id ترکیب کرد. اسلات قابل گسترش: 1 تا N تصویر را متصل کنید (style_reference_1، style_reference_2، ...). | IMAGE | خیر | 0 تا حداکثر تعداد تصاویر مرجع مجاز توسط Recraft API؛ حجم کل کدشده نباید از 10 MB بیشتر شود |

**نکته:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کند. مدل‌های `recraftv4_styles` و `recraftv4_styles_pro` همیشه به یک سبک نیاز دارند: تصاویر مرجع سبک را متصل کنید یا یک `style_id` ارائه دهید. ورودی‌های `style_id` و `style_references` ناسازگار هستند — فقط یکی از آن‌ها را ارائه دهید. یک `style_id` باید UUID معتبر باشد. ورودی `style_match` فقط زمانی استفاده می‌شود که سبکی ارائه شده باشد. هزینه تصاویر مرجع سبک جدا از تولید محاسبه می‌شود و حجم کل کدشده آن‌ها نباید از 10 MB بیشتر شود. مقدار `seed` تضمینی برای تکرارپذیری خروجی‌های تصویر نمی‌دهد. اگر از یک شناسه سبک از Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک هنر وکتور (Vector art) نیست، چون ممکن است به‌جای تصویر داده SVG برگرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر تولیدشده یا دسته‌ای از تصاویر. | IMAGE |
| `style_id` | شناسه سبک استفاده‌شده یا ایجادشده توسط این تولید. وقتی تصاویر مرجع سبک ارائه می‌شوند، سبک ایجادشده برای استفاده مجدد اینجا بازگردانده می‌شود؛ وقتی هیچ سبکی استفاده نشود، رشته خالی است. | STRING |
