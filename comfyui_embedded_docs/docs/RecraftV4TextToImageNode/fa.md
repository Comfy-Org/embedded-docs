# تبدیل متن به تصویر Recraft V4

این گره با استفاده از مدل‌های هوش مصنوعی Recraft V4 و V4.1 تصاویر را از توصیف‌های متنی تولید می‌کند. این گره، prompt و تنظیمات تولید را به سرویس تولید تصویر Recraft ارسال کرده و تصویر یا تصاویر حاصل را بازمی‌گرداند. می‌توانید مدل، اندازه تصویر و تعداد تصاویر تولیدی را انتخاب کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید استفاده می‌شود. انتخاب مدل، گزینه‌های `size` در دسترس را تعیین می‌کند. | DYNAMIC_COMBO | بله | `"recraftv4_1"`<br>`"recraftv4_1_utility"`<br>`"recraftv4_1_pro"`<br>`"recraftv4_1_utility_pro"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `prompt` | Prompt برای تولید تصویر. حداکثر 10,000 کاراکتر. | STRING | بله | 1 تا 10000 کاراکتر |
| `negative_prompt` | این ورودی نادیده گرفته می‌شود: negative prompt توسط مدل‌های Recraft V4 و V4.1 پشتیبانی نمی‌شود. | STRING | بله | N/A |
| `n` | تعداد تصاویر برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `seed` | Seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `recraft_controls` | کنترل‌های اضافی اختیاری بر روی تولید از طریق گره Recraft Controls. | CUSTOM | خیر | N/A |

### ورودی‌های recraftv4_1، recraftv4_1_utility و recraftv4

مشترک بین مدل‌های `recraftv4_1`، `recraftv4_1_utility` و `recraftv4`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: 1024x1024). | COMBO | بله | گزینه‌های متعدد موجود (اندازه‌های استاندارد Recraft V4) |

### ورودی‌های recraftv4_1_pro، recraftv4_1_utility_pro و recraftv4_pro

مشترک بین مدل‌های `recraftv4_1_pro`، `recraftv4_1_utility_pro` و `recraftv4_pro`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: 2048x2048). | COMBO | بله | گزینه‌های متعدد موجود (اندازه‌های Pro Recraft V4) |

**نکات:**

- ورودی `size` هنگام انتخاب مدل ظاهر می‌شود و گزینه‌های موجود آن به مدل بستگی دارد: مدل‌های استاندارد (`recraftv4_1`، `recraftv4_1_utility`، `recraftv4`) یک مجموعه از اندازه‌ها را به اشتراک می‌گذارند، در حالی که مدل‌های Pro (`recraftv4_1_pro`، `recraftv4_1_utility_pro`، `recraftv4_pro`) مجموعه متفاوتی دارند.
- ورودی `negative_prompt` در رابط کاربری نمایش داده می‌شود اما به مدل ارسال نمی‌شود؛ negative prompt توسط مدل‌های Recraft V4 و V4.1 پشتیبانی نمی‌شوند.
- مقدار `seed` فقط تعیین می‌کند که هنگام تغییر مقدار، گره دوباره اجرا شود یا نه؛ نتایج واقعی تصویر بدون توجه به seed قطعی نیستند.
- اگر از طریق ورودی Recraft Controls از شناسه سبک موجود در Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک Vector art نباشد، زیرا ممکن است به جای تصویر، داده SVG بازگردانده شود.
