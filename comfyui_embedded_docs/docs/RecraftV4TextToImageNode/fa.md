# تبدیل متن به تصویر Recraft V4

متن به تصویر Recraft V4

این گره با استفاده از مدل‌های هوش مصنوعی Recraft V4 و V4.1، از توصیف‌های متنی تصویر تولید می‌کند. پرامپت شما را به یک API خارجی ارسال کرده و تصاویر تولیدشده را بازمی‌گرداند. می‌توانید خروجی را با تعیین مدل، اندازه تصویر، تعداد تصاویر و یک سبک اختیاری (چه به‌صورت شناسه سبک ذخیره‌شده و چه از روی تصاویر مرجع) کنترل کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید استفاده می‌شود. مدل‌های recraftv4_styles برای تولید با سبک پایدار ساخته شده‌اند و همیشه به style_id یا style_references نیاز دارند. | DYNAMIC_COMBO | بله | "recraftv4_1"<br>"recraftv4_1_utility"<br>"recraftv4_1_pro"<br>"recraftv4_1_utility_pro"<br>"recraftv4"<br>"recraftv4_pro"<br>"recraftv4_styles"<br>"recraftv4_styles_pro" |
| `پرامپت` | پرامپت تولید تصویر. حداکثر ۱۰٬۰۰۰ کاراکتر. | STRING | بله | 1 تا 10000 کاراکتر |
| `پرامپت منفی` | این ورودی نادیده گرفته می‌شود: مدل‌های Recraft V4 و V4.1 از negative prompt پشتیبانی نمی‌کنند. | STRING | بله | N/A |
| `تعداد` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `بذر` | Seed برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `کنترل‌های Recraft` | کنترل‌های اضافی اختیاری بر روی تولید از طریق گره Recraft Controls. | CUSTOM | خیر | N/A |
| `style_id` | UUID یک سبک Recraft V4 که اعمال شود، مثلاً از گره Recraft V4 Create Style یا خروجی style_id اجرای قبلی. نمی‌توان آن را با style_references ترکیب کرد (پیش‌فرض: خالی). | STRING | خیر | رشته UUID معتبر |
| `style_match` | میزان دقت در پیروی از سبک: precise آن را با جزئیات بازتولید می‌کند، flexible ظاهر کلی را مطابقت می‌دهد. تنها زمانی استفاده می‌شود که سبکی ارائه شده باشد (پیش‌فرض: «precise»). | COMBO | خیر | "precise"<br>"flexible" |

### ورودی‌های recraftv4_1، recraftv4_1_utility، recraftv4 و recraftv4_styles

این مدل‌ها پارامتر `size` مشترکی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: «1024x1024»). | COMBO | بله | گزینه‌های متعددی در دسترس است (اندازه‌های استاندارد Recraft V4، شامل «1024x1024») |

### ورودی‌های recraftv4_1_pro، recraftv4_1_utility_pro، recraftv4_pro و recraftv4_styles_pro

این مدل‌ها پارامتر `size` مشترکی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: «2048x2048»). | COMBO | بله | گزینه‌های متعددی در دسترس است (اندازه‌های حرفه‌ای Recraft V4، شامل «2048x2048») |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `style_references` | تصاویر مرجع برای ایجاد سبک به‌صورت زنده، که به هزینه تولید اضافه می‌شود. سبک ایجادشده به‌عنوان style_id برای استفاده مجدد بازگردانده می‌شود. نمی‌توان آن را با style_id ترکیب کرد. اسلات قابل افزایش: ۱ تا N تصویر را متصل کنید (style_reference_1، style_reference_2، ...). | IMAGE | خیر | 0 تا حداکثر تعداد تصاویر مرجع مجاز توسط Recraft API؛ مجموع اندازه کدگذاری‌شده نباید از 10 مگابایت تجاوز کند |

**نکته:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کند. مدل‌های `recraftv4_styles` و `recraftv4_styles_pro` همیشه به یک سبک نیاز دارند: تصاویر مرجع سبک را متصل کنید یا یک `style_id` ارائه دهید. ورودی‌های `style_id` و `style_references` متقابلاً انحصاری هستند — فقط یکی از آن‌ها را ارائه دهید. `style_id` باید یک UUID معتبر باشد. ورودی `style_match` تنها زمانی استفاده می‌شود که سبکی ارائه شده باشد. تصاویر مرجع سبک علاوه بر هزینه تولید، صورتحساب می‌شوند و مجموع اندازه کدگذاری‌شده آن‌ها نباید از 10 مگابایت تجاوز کند. مقدار `seed` خروجی‌های تصویر قابل تکرار را تضمین نمی‌کند. اگر از یک شناسه سبک از Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک Vector art نباشد، زیرا ممکن است به‌جای تصویر، داده SVG بازگرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر تولیدشده یا دسته‌ای از تصاویر. | IMAGE |
| `style_id` | شناسه سبک استفاده‌شده یا ایجادشده توسط این تولید. وقتی تصاویر مرجع سبک ارائه شده باشند، سبک ایجادشده برای استفاده مجدد در اینجا بازگردانده می‌شود؛ وقتی هیچ سبکی استفاده نشود، رشته خالی است. | STRING |
