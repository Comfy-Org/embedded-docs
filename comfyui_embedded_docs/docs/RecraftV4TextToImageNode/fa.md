# تبدیل متن به تصویر Recraft V4

این گره تصاویری را از توضیحات متنی با استفاده از مدل‌های هوش مصنوعی Recraft V4 و V4.1 تولید می‌کند. اعلان (prompt) شما را به یک API خارجی ارسال کرده و تصاویر تولیدشده را بازمی‌گرداند. می‌توانید با تعیین مدل، اندازه تصویر و تعداد تصاویر، خروجی را کنترل کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید استفاده می‌شود. | DYNAMIC_COMBO | بله | `"recraftv4_1"`<br>`"recraftv4_1_utility"`<br>`"recraftv4_1_pro"`<br>`"recraftv4_1_utility_pro"`<br>`"recraftv4"`<br>`"recraftv4_pro"` |
| `پرامپت` | اعلان (prompt) برای تولید تصویر. حداکثر 10,000 کاراکتر. | STRING | بله | N/A |
| `پرامپت منفی` | این ورودی نادیده گرفته می‌شود: مدل‌های Recraft V4 و V4.1 از اعلان منفی پشتیبانی نمی‌کنند. | STRING | بله | N/A |
| `تعداد` | تعداد تصاویر مورد نظر برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 6 |
| `بذر` | دانه (Seed) برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `کنترل‌های Recraft` | کنترل‌های اضافی اختیاری روی تولید از طریق گره Recraft Controls. | CUSTOM | خیر | N/A |

### ورودی‌های recraftv4_1، recraftv4_1_utility و recraftv4

مشترک بین `recraftv4_1`، `recraftv4_1_utility` و `recraftv4`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "1024x1024"). | COMBO | بله | چندین گزینه موجود است (اندازه‌های استاندارد Recraft V4، شامل "1024x1024") |

### ورودی‌های recraftv4_1_pro، recraftv4_1_utility_pro و recraftv4_pro

مشترک بین `recraftv4_1_pro`، `recraftv4_1_utility_pro` و `recraftv4_pro`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `size` | اندازه تصویر تولیدشده (پیش‌فرض: "2048x2048"). | COMBO | بله | چندین گزینه موجود است (اندازه‌های pro مربوط به Recraft V4، شامل "2048x2048") |

**نکته:** پارامتر `size` یک ورودی پویا است که گزینه‌های موجود آن بر اساس `model` انتخاب‌شده تغییر می‌کنند. مقدار `seed` خروجی‌های تصویر قابل تکرار را تضمین نمی‌کند. اگر از شناسه سبک از کتابخانه سبک بی‌نهایت (Infinite Style Library) استفاده می‌کنید، مطمئن شوید که سبک وکتور (Vector art) نباشد، زیرا ممکن است به جای تصویر، داده SVG بازگردانده شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر تولیدشده یا دسته‌ای از تصاویر. | IMAGE |
