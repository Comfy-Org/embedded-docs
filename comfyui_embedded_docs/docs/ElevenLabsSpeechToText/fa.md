# تبدیل گفتار به متن ElevenLabs

گره ElevenLabs Speech to Text با استفاده از API سرویس ElevenLabs، صدا را به متن تبدیل می‌کند. این گره از تشخیص خودکار زبان، جداسازی گوینده (شناسایی گویندگان مختلف) و برچسب‌گذاری رویدادهای صوتی (نشانه‌گذاری صداهایی مانند خنده یا موسیقی در متن رونویسی‌شده) پشتیبانی می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که برای رونویسی استفاده می‌شود. انتخاب این مدل پارامترهای اضافی را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"scribe_v2"` |
| `audio` | صدایی که باید رونویسی شود. | AUDIO | بله | - |
| `language_code` | کد زبان ISO-639-1 یا ISO-639-3 (مثلاً 'en'، 'es'، 'fra'). برای تشخیص خودکار، خالی بگذارید. (پیش‌فرض: "") | STRING | خیر | - |
| `num_speakers` | حداکثر تعداد گوینده‌هایی که باید پیش‌بینی شود. برای تشخیص خودکار، مقدار 0 را تنظیم کنید. (پیش‌فرض: 0) | INT | خیر | 0 - 32 |
| `seed` | Seed برای تکرارپذیری (قطعیت تضمین نمی‌شود). (پیش‌فرض: 1) | INT | خیر | 0 - 2147483647 |

### ورودی‌های Scribe v2

این پارامترها زمانی نمایش داده می‌شوند که مدل `"scribe_v2"` انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `tag_audio_events` | صداهایی مانند (خنده)، (موسیقی) و غیره را در متن رونویسی‌شده برچسب‌گذاری کنید. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `diarize` | مشخص کنید کدام گوینده در حال صحبت است. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `diarization_threshold` | حساسیت جداسازی گوینده. مقادیر پایین‌تر نسبت به تغییر گوینده حساس‌تر هستند. فقط زمانی استفاده می‌شود که `diarize` فعال باشد. (پیش‌فرض: 0.22) | FLOAT | خیر | 0.1 - 0.4 |
| `temperature` | کنترل تصادفی بودن. مقدار 0.0 از پیش‌فرض مدل استفاده می‌کند. مقادیر بالاتر تصادفی بودن را افزایش می‌دهند. (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 - 2.0 |
| `timestamps_granularity` | دقت زمانی برای کلمات رونویسی‌شده. (پیش‌فرض: "word") | COMBO | خیر | `"word"`<br>`"character"`<br>`"none"` |

**نکته:** هنگام فعال بودن `diarize`، نمی‌توان `num_speakers` را مقداری بزرگ‌تر از 0 تنظیم کرد. باید یا `diarize` را غیرفعال کنید یا `num_speakers` را روی 0 بگذارید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `text` | متن رونویسی‌شده از صدا. | STRING |
| `language_code` | کد زبان تشخیص‌داده‌شده برای صدا. | STRING |
| `words_json` | رشته‌ای با قالب JSON که شامل اطلاعات دقیق در سطح کلمه، از جمله زمان‌بندی و برچسب‌های گوینده (در صورت فعال بودن) است. | STRING |
