# ElevenLabs تحويل الكلام إلى نص

عقدة ElevenLabs لتحويل الكلام إلى نص تنسخ الصوت إلى نص باستخدام واجهة برمجة تطبيقات ElevenLabs. وهي تدعم الكشف التلقائي عن اللغة، وتقسيم المتحدثين (تحديد المتحدثين المختلفين)، ووسم الأحداث الصوتية (إضافة تعليقات توضيحية للأصوات مثل الضحك أو الموسيقى في النص المنسوخ).

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المستخدم للنسخ. تحديد هذا النموذج يعرض معاملات إضافية. | DYNAMIC_COMBO | نعم | `"scribe_v2"` |
| `الصوت` | الصوت المراد نسخه. | AUDIO | نعم | - |
| `رمز اللغة` | رمز اللغة ISO-639-1 أو ISO-639-3 (مثل: 'en'، 'es'، 'fra'). اتركه فارغًا للكشف التلقائي. (الافتراضي: "") | STRING | لا | - |
| `عدد المتحدثين` | الحد الأقصى لعدد المتحدثين المتوقعين. اضبطه على 0 للكشف التلقائي. (الافتراضي: 0) | INT | لا | 0 - 32 |
| `البذرة` | بذرة لإعادة إنتاج النتائج (القطع غير مضمون). (الافتراضي: 1) | INT | لا | 0 - 2147483647 |

### مدخلات Scribe v2

تظهر هذه المعاملات عند تحديد نموذج `"scribe_v2"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `tag_audio_events` | أضف تعليقات توضيحية للأصوات مثل (ضحك)، (موسيقى)، إلخ في النص المنسوخ. (الافتراضي: False) | BOOLEAN | لا | - |
| `diarize` | تعليق توضيحي يحدد المتحدث الذي يتحدث. (الافتراضي: False) | BOOLEAN | لا | - |
| `diarization_threshold` | حساسية فصل المتحدثين. القيم الأقل أكثر حساسية للتغيرات في المتحدثين. يُستخدم فقط عند تفعيل `diarize`. (الافتراضي: 0.22) | FLOAT | لا | 0.1 - 0.4 |
| `temperature` | التحكم في العشوائية. القيمة 0.0 تستخدم الإعداد الافتراضي للنموذج. القيم الأعلى تزيد العشوائية. (الافتراضي: 0.0) | FLOAT | لا | 0.0 - 2.0 |
| `timestamps_granularity` | دقة التوقيت لكلمات النص المنسوخ. (الافتراضي: "word") | COMBO | لا | `"word"`<br>`"character"`<br>`"none"` |

**ملاحظة:** لا يمكن ضبط `num_speakers` على قيمة أكبر من 0 عند تفعيل `diarize`. يجب إما تعطيل `diarize` أو ضبط `num_speakers` على 0.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `النص` | النص المنسوخ من الصوت. | STRING |
| `رمز اللغة` | رمز اللغة المكتشف للصوت. | STRING |
| `كلمات بصيغة JSON` | سلسلة بتنسيق JSON تحتوي على معلومات مفصلة على مستوى الكلمة، بما في ذلك الطوابع الزمنية وتسميات المتحدثين إذا تم تفعيلها. | STRING |
