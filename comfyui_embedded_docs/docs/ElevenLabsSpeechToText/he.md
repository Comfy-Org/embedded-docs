# ElevenLabsSpeechToText

צומת ElevenLabs Speech to Text מתמלל אודיו לטקסט באמצעות ה-API של ElevenLabs. הוא תומך בזיהוי שפה אוטומטי, דיאריזציה של דוברים (זיהוי דוברים שונים) ותיוג אירועי אודיו (סימון צלילים כמו צחוק או מוזיקה בתמלול).

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל לשימוש בתמלול. בחירת מודל זה חושפת פרמטרים נוספים. | DYNAMIC_COMBO | כן | `"scribe_v2"` |
| `audio` | האודיו לתמלול. | AUDIO | כן | - |
| `language_code` | קוד שפה ISO-639-1 או ISO-639-3 (למשל 'en', 'es', 'fra'). השאר ריק לזיהוי אוטומטי. (ברירת מחדל: "") | STRING | לא | - |
| `num_speakers` | המספר המרבי של דוברים לניבוי. הגדר ל-0 לזיהוי אוטומטי. (ברירת מחדל: 0) | INT | לא | 0 - 32 |
| `seed` | Seed לשחזוריות (דטרמיניזם אינו מובטח). (ברירת מחדל: 1) | INT | לא | 0 - 2147483647 |

### קלטים של Scribe v2

פרמטרים אלו מוצגים כאשר המודל `"scribe_v2"` נבחר.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `tag_audio_events` | סמן צלילים כמו (צחוק), (מוזיקה) וכו' בתמלול. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `diarize` | סמן איזה דובר מדבר. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `diarization_threshold` | רגישות להפרדת דוברים. ערכים נמוכים יותר רגישים יותר לשינויים בדובר. משמש רק כאשר `diarize` מופעל. (ברירת מחדל: 0.22) | FLOAT | לא | 0.1 - 0.4 |
| `temperature` | שליטה באקראיות. 0.0 משתמש בברירת המחדל של המודל. ערכים גבוהים יותר מגבירים את האקראיות. (ברירת מחדל: 0.0) | FLOAT | לא | 0.0 - 2.0 |
| `timestamps_granularity` | דיוק התזמון עבור מילים בתמלול. (ברירת מחדל: "word") | COMBO | לא | `"word"`<br>`"character"`<br>`"none"` |

**הערה:** לא ניתן להגדיר את `num_speakers` לערך גדול מ-0 כאשר `diarize` מופעל. עליך להשבית את `diarize` או להגדיר את `num_speakers` ל-0.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `text` | הטקסט המתומלל מהאודיו. | STRING |
| `language_code` | קוד השפה שזוהה באודיו. | STRING |
| `words_json` | מחרוזת בפורמט JSON המכילה מידע מפורט ברמת המילים, כולל חותמות זמן ותוויות דוברים אם הן מופעלות. | STRING |
