# 圖片添加雜訊

ImageAddNoise 節點會為輸入影像加入隨機雜訊。它使用指定的隨機種子來產生一致的雜訊圖案，並可控制雜訊效果的強度。產生的影像會維持與輸入相同的尺寸，但帶有額外加入的視覺紋理。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 將加入雜訊的輸入影像 | IMAGE | 是 | - |
| `seed` | 用於建立雜訊的隨機種子（預設：0）。此參數支援「生成後控制」功能。 | INT | 是 | 0 至 18446744073709551615 |
| `strength` | 控制雜訊效果的強度（預設：0.5，步長：0.01） | FLOAT | 是 | 0.0 至 1.0 |

**注意：** 雜訊值會加到影像上，並將結果截斷至 0.0–1.0 範圍。如果輸入影像具有 Alpha 通道（4 個通道），原始 Alpha 通道會保持不變——雜訊只會套用到色彩通道。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
| --- | --- | --- |
| `image` | 套用加入雜訊後的輸出影像 | IMAGE |
