# ImageAddNoise

Узел ImageAddNoise добавляет случайный шум к входному изображению. Он использует заданное случайное зерно (seed) для генерации согласованных шумовых паттернов и позволяет управлять интенсивностью эффекта шума. Результирующее изображение сохраняет те же размеры, что и входное, но с добавленной визуальной текстурой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Входное изображение, к которому будет добавлен шум | IMAGE | Да | - |
| `сид` | Случайное зерно, используемое для создания шума (по умолчанию: 0). Этот параметр поддерживает функциональность "control after generate". | INT | Да | 0 до 18446744073709551615 |
| `сила` | Управляет интенсивностью эффекта шума (по умолчанию: 0.5, шаг: 0.01) | FLOAT | Да | 0.0 до 1.0 |

**Примечание:** Значения шума добавляются к изображению, а результат ограничивается диапазоном 0.0–1.0. Если входное изображение имеет альфа-канал (4 канала), исходный альфа-канал сохраняется без изменений — шум применяется только к цветовым каналам.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Выходное изображение с добавленным шумом | IMAGE |
