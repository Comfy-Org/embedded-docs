# افزودن نویز به تصویر

گره ImageAddNoise نویز تصادفی به یک تصویر ورودی اضافه می‌کند. این گره از یک seed تصادفی مشخص برای تولید الگوهای نویز ثابت استفاده می‌کند و امکان کنترل شدت اثر نویز را فراهم می‌سازد. تصویر حاصل همان ابعاد ورودی را حفظ می‌کند، اما بافت بصری افزوده‌شده دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویر ورودی که نویز به آن اضافه می‌شود | IMAGE | بله | - |
| `seed` | seed تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). این پارامتر از قابلیت «کنترل پس از تولید» پشتیبانی می‌کند. | INT | بله | 0 تا 18446744073709551615 |
| `strength` | شدت اثر نویز را کنترل می‌کند (پیش‌فرض: 0.5، گام: 0.01) | FLOAT | بله | 0.0 تا 1.0 |

**توجه:** مقادیر نویز به تصویر اضافه می‌شوند و نتیجه به محدوده 0.0–1.0 برش داده می‌شود. اگر تصویر ورودی دارای کانال آلفا (۴ کانال) باشد، کانال آلفای اصلی بدون تغییر حفظ می‌شود — نویز فقط روی کانال‌های رنگی اعمال می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `image` | تصویر خروجی با نویز افزوده‌شده | IMAGE |
