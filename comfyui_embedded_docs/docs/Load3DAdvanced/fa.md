# بارگذاری ۳بعدی (پیشرفته)

گره Load 3D (Advanced) یک فایل مدل سه‌بعدی را از پوشه `input/3d` در ComfyUI بارگذاری می‌کند و داده‌های مدل را همراه با اطلاعات جای‌گذاری مدل و دوربین که در وضعیت نمای دید نمایشگر سه‌بعدی ثبت شده‌اند ارائه می‌دهد. از قالب‌های رایج فایل سه‌بعدی پشتیبانی می‌کند و به شما امکان می‌دهد عرض و ارتفاع رندر نمای دید را بر حسب پیکسل تنظیم کنید. این گره آزمایشی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_file` | فایل مدل سه‌بعدی برای بارگذاری. برای رد کردن بارگذاری فایل مدل، "none" را انتخاب کنید. فایل‌ها همچنین می‌توانند از طریق ویجت بارگذاری شوند. | COMBO | بله | `"none"`<br>فایل‌های مدل سه‌بعدی موجود در پوشه `input/3d` |
| `viewport_state` | وضعیت فعلی نمای دید شامل اطلاعات دوربین و مدل از نمایشگر سه‌بعدی. | LOAD3D | بله | - |
| `width` | عرض رندر نمای دید بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | حداقل: 1<br>حداکثر: 4096<br>پیش‌فرض: 1024<br>گام: 1 |
| `height` | ارتفاع رندر نمای دید بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | حداقل: 1<br>حداکثر: 4096<br>پیش‌فرض: 1024<br>گام: 1 |

**نکات مربوط به پارامترها:**
- پارامتر `model_file` فقط فایل‌هایی با پسوندهای زیر را فهرست می‌کند: .gltf، .glb، .obj، .fbx، .stl
- فایل‌ها باید در پوشه `input/3d` در نصب ComfyUI شما قرار گیرند؛ زیرپوشه‌ها نیز جست‌وجو می‌شوند و مسیر فایل‌ها به‌صورت نسبی نسبت به پوشه input نمایش داده می‌شود
- اگر `model_file` برابر "none" باشد، هیچ داده مدلی بارگذاری نمی‌شود و خروجی `model_3d` خالی خواهد بود
- اگر `model_file` روی فایلی تنظیم شود که وجود ندارد، گره یک خطای اعتبارسنجی برمی‌گرداند: "Invalid 3D model file: {model_file}"
- اگر `viewport_state` یک شیء وضعیت نمای دید معتبر نباشد، به‌عنوان خالی در نظر گرفته می‌شود؛ بنابراین `model_3d_info` به یک لیست خالی تبدیل می‌شود و `camera_info` خالی برگردانده می‌شود

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل مدل سه‌بعدی بارگذاری‌شده (glb/obj/stl/etc.). اگر هیچ فایل مدلی انتخاب نشده باشد، خالی است. | FILE3DANY |
| `model_3d_info` | جای‌گذاری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی Y-up). | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین نمای دید: موقعیت، هدف نگاه، بزرگ‌نمایی و نوع. | LOAD3DCAMERA |
| `width` | عرض رندر نمای دید بر حسب پیکسل. | INT |
| `height` | ارتفاع رندر نمای دید بر حسب پیکسل. | INT |
