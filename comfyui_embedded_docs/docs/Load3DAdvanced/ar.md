# تحميل ثلاثي الأبعاد (متقدم)

عُقدة Load 3D (Advanced) تحمّل ملف نموذج ثلاثي الأبعاد من دليل `input/3d` في ComfyUI، وتوفّر بيانات النموذج إلى جانب معلومات وضع النموذج والكاميرا الملتقطة في حالة منفذ العرض الخاصة بعارض 3D. وهي تدعم صيغ ملفات النماذج ثلاثية الأبعاد الشائعة وتتيح لك ضبط عرض وارتفاع التصيير لمنفذ العرض بالبكسل. هذه العقدة تجريبية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_file` | ملف النموذج ثلاثي الأبعاد المراد تحميله. اختر "none" لتخطي تحميل ملف نموذج. يمكن أيضًا رفع الملفات عبر الودجة. | COMBO | نعم | `"none"`<br>ملفات النماذج ثلاثية الأبعاد المتاحة في دليل `input/3d` |
| `viewport_state` | حالة منفذ العرض الحالية التي تحتوي على معلومات الكاميرا والنموذج من عارض 3D. | LOAD3D | نعم | - |
| `العرض` | عرض التصيير لمنفذ العرض بالبكسل (الافتراضي: 1024). | INT | نعم | الحد الأدنى: 1<br>الحد الأقصى: 4096<br>الافتراضي: 1024<br>الخطوة: 1 |
| `الارتفاع` | ارتفاع التصيير لمنفذ العرض بالبكسل (الافتراضي: 1024). | INT | نعم | الحد الأدنى: 1<br>الحد الأقصى: 4096<br>الافتراضي: 1024<br>الخطوة: 1 |

**ملاحظات حول المعاملات:**
- يسرد المعامل `model_file` فقط الملفات ذات الامتدادات التالية: .gltf, .glb, .obj, .fbx, .stl
- يجب وضع الملفات في دليل `input/3d` ضمن تثبيت ComfyUI لديك؛ يتم البحث في المجلدات الفرعية أيضًا، وتُعرض مسارات الملفات نسبةً إلى دليل الإدخال
- إذا كان `model_file` هو "none"، فلن يتم تحميل أي بيانات نموذج وسيكون المخرج `model_3d` فارغًا
- إذا تم تعيين `model_file` إلى ملف غير موجود، تُرجع العقدة خطأ تحقق: "Invalid 3D model file: {model_file}"
- إذا لم يكن `viewport_state` كائن حالة منفذ عرض صالحًا، فيُعامل كفارغ، وبالتالي يصبح `model_3d_info` قائمة فارغة وتُعاد `camera_info` فارغة

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_3d` | ملف النموذج ثلاثي الأبعاد المحمّل (glb/obj/stl/etc.). فارغ إذا لم يتم اختيار ملف نموذج. | FILE3DANY |
| `model_3d_info` | موضع كل نموذج في المشهد: الموضع، والدوران، والمقياس (فضاء عالمي بمحور Y لأعلى). | LOAD3DMODELINFO |
| `camera_info` | معلومات كاميرا منفذ العرض: الموضع، وهدف النظر، والتكبير، والنوع. | LOAD3DCAMERA |
| `width` | عرض التصيير لمنفذ العرض بالبكسل. | INT |
| `height` | ارتفاع التصيير لمنفذ العرض بالبكسل. | INT |
