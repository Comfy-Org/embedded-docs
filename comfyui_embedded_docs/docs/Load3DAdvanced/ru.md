# Загрузить 3D (расширено)

Узел Load 3D (Advanced) загружает файл 3D-модели из входного каталога ComfyUI и предоставляет данные модели вместе с информацией о камере и видовом окне. Он поддерживает распространённые форматы 3D-файлов и позволяет указать размеры выходного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_file` | Файл 3D-модели для загрузки. Выберите «none», чтобы пропустить загрузку модели. | STRING | Да | `"none"`<br>Список доступных 3D-файлов в каталоге `input/3d` |
| `viewport_state` | Текущее состояние видового окна, содержащее информацию о камере и модели из 3D-просмотрщика. | LOAD3D | Да | - |
| `width` | Ширина выходного изображения в пикселях (по умолчанию: 1024). | INT | Да | Мин.: 1<br>Макс.: 4096<br>Шаг: 1 |
| `height` | Высота выходного изображения в пикселях (по умолчанию: 1024). | INT | Да | Мин.: 1<br>Макс.: 4096<br>Шаг: 1 |

**Примечания к параметрам:**
- Параметр `model_file` показывает только файлы со следующими расширениями: .gltf, .glb, .obj, .fbx, .stl
- Файлы должны быть размещены в каталоге `input/3d` вашей установки ComfyUI
- Если для `model_file` установлено значение «none», данные 3D-модели не загружаются (выходной параметр `model_3d` будет пустым)
- Если для `model_file` установлено имя несуществующего файла, узел возвращает ошибку проверки: «Invalid 3D model file: {model_file}»

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Загруженные данные 3D-модели или пусто, если файл модели не выбран. | FILE3DANY |
| `model_3d_info` | Информация о загруженной 3D-модели из состояния видового окна. | LOAD3DMODELINFO |
| `camera_info` | Информация о камере из состояния видового окна. | LOAD3DCAMERA |
| `width` | Указанная ширина выходного изображения. | INT |
| `height` | Указанная высота выходного изображения. | INT |
