# Загрузить 3D (расширено)

Узел Load 3D (Advanced) загружает файл 3D-модели из каталога `input/3d` ComfyUI и предоставляет данные модели вместе с размещением модели и информацией о камере, сохранённой в состоянии области просмотра 3D-просмотрщика. Он поддерживает распространённые форматы 3D-файлов и позволяет задавать ширину и высоту рендеринга области просмотра в пикселях. Этот узел экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_file` | Загружаемый файл 3D-модели. Выберите "none", чтобы пропустить загрузку файла модели. Файлы также можно загрузить через виджет. | COMBO | Да | `"none"`<br>Доступные файлы 3D-моделей в каталоге `input/3d` |
| `viewport_state` | Текущее состояние области просмотра, содержащее информацию о камере и модели из 3D-просмотрщика. | LOAD3D | Да | - |
| `width` | Ширина рендеринга области просмотра в пикселях (по умолчанию: 1024). | INT | Да | Мин: 1<br>Макс: 4096<br>По умолчанию: 1024<br>Шаг: 1 |
| `height` | Высота рендеринга области просмотра в пикселях (по умолчанию: 1024). | INT | Да | Мин: 1<br>Макс: 4096<br>По умолчанию: 1024<br>Шаг: 1 |

**Примечания к параметрам:**
- Параметр `model_file` перечисляет только файлы со следующими расширениями: .gltf, .glb, .obj, .fbx, .stl
- Файлы должны быть помещены в каталог `input/3d` вашей установки ComfyUI; подпапки также просматриваются, а пути к файлам отображаются относительно каталога input
- Если `model_file` имеет значение "none", данные модели не загружаются, и выход `model_3d` будет пустым
- Если `model_file` указывает на несуществующий файл, узел возвращает ошибку проверки: "Invalid 3D model file: {model_file}"
- Если `viewport_state` не является допустимым объектом состояния области просмотра, он обрабатывается как пустой, поэтому `model_3d_info` становится пустым списком, а `camera_info` возвращается пустым

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Загруженный файл 3D-модели (glb/obj/stl/и т. д.). Пустой, если файл модели не выбран. | FILE3DANY |
| `model_3d_info` | Размещение каждой модели в сцене: положение, поворот и масштаб (мировое пространство с осью Y вверх). | LOAD3DMODELINFO |
| `camera_info` | Информация о камере области просмотра: положение, цель взгляда, зум и тип. | LOAD3DCAMERA |
| `width` | Ширина рендеринга области просмотра в пикселях. | INT |
| `height` | Высота рендеринга области просмотра в пикселях. | INT |
