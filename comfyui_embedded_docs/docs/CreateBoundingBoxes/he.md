# יצירת תיבות גבול

צומת זה מספק ממשק קנבס לציור תיבות תוחמות סביב אובייקטים או אזורי טקסט בתמונה. הוא מפיק קואורדינטות של תיבות תוחמות במרחב פיקסלים, נתוני רכיבים מובנים התואמים לתבנית פרומפט של Ideogram, ותמונת תצוגה מקדימה המציגה את התיבות המצוירות עם תוויות ופלטות צבעים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `background` | תמונה אופציונלית המשמשת כרקע בקנבס ובתצוגה המקדימה. | IMAGE | לא | - |
| `bboxes` | תיבות תוחמות, רכיבים, או מחרוזת JSON לאתחול הקנבס. ערך חדש במעלה הזרם מאתחל את הקנבס; עריכות שנעשו בקנבס מקבלות עדיפות ונשמרות עד שהערך במעלה הזרם משתנה שוב. | BOUNDING_BOX, ARRAY, STRING | לא | - |
| `width` | רוחב הקנבס ורשת הפיקסלים עבור התיבות התוחמות (ברירת מחדל: 1024). | INT | כן | 64 עד 16384 (צעד: 16) |
| `height` | גובה הקנבס ורשת הפיקסלים עבור התיבות התוחמות (ברירת מחדל: 1024). | INT | כן | 64 עד 16384 (צעד: 16) |
| `editor_state` | ציור תיבות תוחמות והגדרת סוג, טקסט, תיאור ופלטת צבעים לכל תיבה. התחל עם רכיב הרקע ראשון ורכיב החזית אחרון. | BOUNDING_BOXES | כן | - |
| `last_incoming` | מצב פנימי המנוהל על ידי הקנבס: ערך ה-bboxes במעלה הזרם שאיתחל אותו לאחרונה. השאר ריק כדי לאתחל מחדש את הקנבס מהקלט bboxes בהרצה הבאה. | BOUNDING_BOXES | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `preview` | תמונת RGB המציגה את הקנבס עם כל התיבות התוחמות מרונדרות, כולל תוויות, דוגמיות פלטת צבעים וטקסט תיאורי. | IMAGE |
| `bboxes` | רשימה של תיבות תוחמות בקואורדינטות פיקסלים, כאשר כל תיבה מכילה ערכי x, y, רוחב וגובה. | BOUNDING_BOX |
| `elements` | מערך מובנה של אובייקטי רכיבים, שכל אחד מכיל סוג, קואורדינטות תיבה תוחמת (מנורמלות 0-1000), טקסט (עבור סוג טקסט), תיאור ופלטת צבעים. | ARRAY |
