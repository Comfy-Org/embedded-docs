# Vidu Q4 Reference-to-Video Generation

Создайте видео из референсных изображений, необязательного референсного аудио и промпта с помощью модели Vidu Q4. Это вариант узлов генерации Vidu Q4 для преобразования референса в видео.

Выбор `model` открывает параметры, специфичные для этой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации видео. Выбор модели открывает специфичные для неё параметры: `reference_images`, `reference_audios`, `prompt`, `aspect_ratio`, `resolution`, `duration`, `audio` и `seed`. | DYNAMIC_COMBO | Да | `"Vidu Q4 Preview"` |
| `reference_images` | Расширяемый слот: подключите одно или несколько референсных изображений (`image_1`, `image_2`, ...) для генерируемого видео; каждое изображение в пакете учитывается в общем количестве. Ссылайтесь на них в промпте по порядку: изображение 1, изображение 2 и так далее. | IMAGE | Да | До 15 изображений |
| `reference_audios` | Расширяемый слот: подключите необязательные голосовые референсы (`audio_1`, `audio_2`, `audio_3`), каждый длительностью от 3 до 12 секунд. Используется только голос, а не слова: напишите диалог в промпте и назначьте голос по порядку, например `image 1 says "Hello!" in the voice from audio 1`. Требуется, чтобы параметр `audio` был включён. | AUDIO | Нет | До 3 клипов |
| `prompt` | Текстовое описание для генерации видео, до 5000 символов. Нужно для описания референсов, которые вы хотите использовать. | STRING | Да | Любой текст |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"3:4"`<br>`"4:3"` |
| `resolution` | Разрешение выходного видео (по умолчанию: `"720p"`). | COMBO | Да | `"540p"`<br>`"720p"`<br>`"1080p"`<br>`"2K"`<br>`"4K"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | 3–16 |
| `audio` | Если включено, выводит видео со звуком, включая диалоги и звуковые эффекты (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `seed` | Параметр `seed` управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. Этот параметр имеет функциональность "control after generate" (по умолчанию: 42). | INT | Да | 1–2147483647 |

**Примечание:** Всего можно использовать не более 15 референсных изображений, считая каждое изображение в пакете. Каждое изображение должно быть не менее 128x128 пикселей с соотношением сторон от 1:5 до 5:1. Референсное аудио требует, чтобы параметр `audio` был включён, иначе возникает ошибка.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированный видеофайл. | VIDEO |
