# המרת רישיות טקסט

הצומת Case Converter ממיר מחרוזות טקסט לפורמטים שונים של רישיות אותיות. הוא מקבל מחרוזת קלט וממיר אותה בהתאם למצב שנבחר, ומייצר מחרוזת פלט עם פורמט הרישיות שצוין. הצומת תומך בארבע אפשרויות שונות להמרת רישיות כדי לשנות את האותיות הגדולות/קטנות בטקסט שלך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת הטקסט שיש להמיר לפורמט רישיות אחר | STRING | כן | - |
| `mode` | מצב המרת הרישיות להחלה (ברירת מחדל: `"UPPERCASE"`) | STRING | כן | `"UPPERCASE"`<br>`"lowercase"`<br>`"Capitalize"`<br>`"Title Case"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | מחרוזת הקלט שהומרה לפורמט הרישיות שצוין | STRING |
