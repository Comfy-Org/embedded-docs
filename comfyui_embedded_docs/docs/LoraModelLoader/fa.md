# بارگذاری مدل LoRA

گره `LoraModelLoader` وزن‌های آموزش‌دیده LoRA (Low-Rank Adaptation) را روی یک مدل انتشار اعمال می‌کند. این گره با بارگذاری وزن‌های LoRA از یک مدل LoRA آموزش‌دیده و تنظیم قدرت تأثیر آن‌ها، مدل پایه را اصلاح می‌کند. این امکان را به شما می‌دهد که رفتار مدل‌های انتشار را بدون آموزش مجدد آن‌ها از ابتدا سفارشی‌سازی کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل انتشاری که LoRA روی آن اعمال می‌شود. | MODEL | بله | - |
| `lora` | مدل LoRA که باید روی مدل انتشار اعمال شود. | LORA_MODEL | بله | - |
| `strength_model` | میزان شدت تغییر مدل انتشار. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | -100.0 to 100.0 |
| `bypass` | هنگامی که فعال باشد، LoRA را در حالت بای‌پاس اعمال می‌کند بدون اینکه وزن‌های مدل پایه را تغییر دهد. برای آموزش و زمانی که وزن‌های مدل تخلیه شده‌اند مفید است (پیش‌فرض: False). | BOOLEAN | بله | True or False |

**نکته:** وقتی `strength_model` برابر 0 باشد، گره مدل اصلی را بدون اعمال هرگونه تغییر LoRA برمی‌گرداند.
