# بارگذاری مدل LoRA

گره LoraModelLoader وزن‌های LoRA (انطباق کم‌رتبه) آموزش‌دیده را بر روی یک مدل دیفیوژن اعمال می‌کند. این گره با بارگذاری وزن‌های LoRA از یک مدل LoRA آموزش‌دیده و تنظیم میزان تأثیر آن‌ها، مدل پایه را تغییر می‌دهد. این امکان به شما اجازه می‌دهد تا رفتار مدل‌های دیفیوژن را بدون آموزش مجدد از ابتدا سفارشی کنید؛ همچنین شامل حالت عبور (bypass) است که وزن‌های مدل پایه را بدون تغییر نگه می‌دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل دیفیوژنی که LoRA روی آن اعمال می‌شود. | MODEL | بله | - |
| `lora` | مدل LoRA که قرار است روی مدل دیفیوژن اعمال شود. | LORA_MODEL | بله | - |
| `قدرت_مدل` | میزان شدت تغییر مدل دیفیوژن. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | 100.0- تا 100.0 |
| `bypass` | هنگامی که فعال باشد، LoRA در حالت عبور بدون تغییر وزن‌های مدل پایه اعمال می‌شود. برای آموزش و زمانی که وزن‌های مدل تخلیه (offload) شده‌اند مفید است (پیش‌فرض: False). | BOOLEAN | بله | True یا False |

**نکته:** وقتی `strength_model` روی 0 تنظیم شود، گره مدل اصلی را بدون اعمال هیچ تغییر LoRA برمی‌گرداند.
