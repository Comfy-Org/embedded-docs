# Загрузить модель LoRA

Узел LoraModelLoader применяет обученные веса LoRA (низкоранговая адаптация) к диффузионной модели. Он изменяет базовую модель, загружая веса LoRA из обученной модели LoRA и регулируя силу их влияния. Это позволяет настраивать поведение диффузионных моделей без их переобучения с нуля, включая режим обхода, который оставляет веса базовой модели без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будет применена LoRA. | MODEL | Да | - |
| `lora` | Модель LoRA, применяемая к диффузионной модели. | LORA_MODEL | Да | - |
| `strength_model` | Насколько сильно изменять диффузионную модель. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 до 100.0 |
| `bypass` | Если включено, применяет LoRA в режиме обхода без изменения весов базовой модели. Полезно для обучения и когда веса модели выгружены (по умолчанию: False). | BOOLEAN | Да | True or False |

**Примечание:** Когда для `strength_model` установлено значение 0, узел возвращает исходную модель без применения каких-либо модификаций LoRA.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Измененная диффузионная модель с примененными весами LoRA. | MODEL |
