# Загрузить модель LoRA

Узел `LoraModelLoader` применяет обученные веса LoRA (низкоранговая адаптация) к диффузионной модели. Он изменяет базовую модель, загружая веса LoRA из обученной модели LoRA и регулируя силу их влияния. Это позволяет настраивать поведение диффузионных моделей без их переобучения с нуля.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Диффузионная модель, к которой будет применена LoRA. | MODEL | Да | - |
| `lora` | Модель LoRA для применения к диффузионной модели. | LORA_MODEL | Да | - |
| `strength_model` | Насколько сильно изменять диффузионную модель. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 to 100.0 |
| `bypass` | Когда включено, применяет LoRA в режиме обхода без изменения весов базовой модели. Полезно для обучения и когда веса модели выгружены (по умолчанию: False). | BOOLEAN | Да | True or False |

**Примечание:** Когда `strength_model` установлен в 0, узел возвращает исходную модель без применения каких-либо изменений LoRA.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `model` | Измененная диффузионная модель. | MODEL |
