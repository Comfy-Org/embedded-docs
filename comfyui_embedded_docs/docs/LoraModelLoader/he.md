# LoraModelLoader

צומת LoraModelLoader מחיל משקולות LoRA (התאמה בדרגה נמוכה) שאומנו על מודל דיפוזיה. הוא משנה את המודל הבסיסי על ידי טעינת משקולות LoRA ממודל LoRA מאומן והתאמת עוצמת ההשפעה שלהן. זה מאפשר לך להתאים את ההתנהגות של מודלי דיפוזיה בלי לאמן אותם מחדש מאפס, כולל מצב עקיפה שמשאיר את משקולות המודל הבסיסי ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה שאליו יוחל ה-LoRA. | MODEL | כן | - |
| `lora` | מודל ה-LoRA שיש להחיל על מודל הדיפוזיה. | LORA_MODEL | כן | - |
| `strength_model` | באיזו עוצמה לשנות את מודל הדיפוזיה. ערך זה יכול להיות שלילי (ברירת מחדל: 1.0). | FLOAT | כן | -100.0 to 100.0 |
| `bypass` | כשמופעל, מחיל LoRA במצב עקיפה בלי לשנות את משקולות המודל הבסיסי. שימושי לאימון וכאשר משקולות המודל מועברות לזיכרון חיצוני (ברירת מחדל: False). | BOOLEAN | כן | True or False |

**הערה:** כאשר `strength_model` מוגדר ל-0, הצומת מחזיר את המודל המקורי בלי להחיל שינויי LoRA כלשהם.
