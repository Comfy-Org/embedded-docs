# RelayVSRConditioning

RelayVSR Conditioning подготавливает кондиционирование и пустой латент для апскейла видео RelayVSR. RelayVSR запускает свою одношаговую модель Wan 2.2 только на каждом 15-м кадре клипа плюс на последнем, поэтому латент, который он возвращает, содержит только эти ключевые кадры. Затем VSR Decode заполняет кадры между ними.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель RelayVSR, загруженная с помощью Load Model: `relayvsr_x2_lightx2v_int8_convrot.safetensors` или `relayvsr_x4_int8_convrot.safetensors`. | MODEL | Да | N/A |
| `images` | Видео низкого качества в исходном разрешении. Коэффициент увеличения модели определяет итоговый размер результата. | IMAGE | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Кондиционирование, которое передаёт выбранные ключевые кадры в качестве подсказки низкого качества. | CONDITIONING |
| `latent` | Пустой латент с одним кадром на каждый ключевой кадр, готовый для сэмплера. | LATENT |

## Использование

Выполните сэмплирование `latent` за один шаг при CFG 1: в графе нет ни промпта, ни текстового энкодера. Передайте выход сэмплера, те же `images` и RelayVSR Flash VAE в VSR Decode и сохраняйте пару согласованной: модель x2 с декодером x2, модель x4 с декодером x4.

Сэмплируются только ключевые кадры, поэтому клип из 150 кадров превращается в латент из 11 кадров. Сэмплер работает с небольшой частью видео, а VSR Decode восстанавливает остальное.
