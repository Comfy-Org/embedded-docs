# VaeDecodeShapeTrellis

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `samples` | نمونه‌های latent برای رمزگشایی، شامل تنسور نمونه و داده‌های مختصات پراکنده. دیکشنری latent ممکن است شامل فیلدهای اختیاری نیز باشد: `coord_counts` برای شکل‌های دسته‌ای، `coord_resolution` برای کنترل رزولوشن مش، و `model_frame` برای جهت‌گیری مختصات. | LATENT | بله | None |
| `vae` | مدل VAE مورد استفاده برای رمزگشایی latent شکل به مش. | VAE | بله | None |

### نکاتی درباره `samples`

- ورودی `samples` یک دیکشنری latent است که باید شامل تنسور `samples` و مختصات پراکنده `coords` باشد.
- اگر `coord_counts` موجود باشد، باید یک تنسور یک‌بعدی از اعداد صحیح نامنفی باشد، و مجموع همه شمارش‌ها باید برابر با تعداد کل سطرهای مختصات باشد. هر شمارش نمایانگر یک شکل در دسته است.
- اگر `coord_resolution` ارائه شود، رزولوشن مش به‌صورت `coord_resolution * 16` محاسبه می‌شود. در غیر این صورت، از بافر رزولوشن داخلی VAE استفاده می‌شود (مقدار پیش‌فرض: 1024).
- اگر `model_frame` روی `"z_up"` تنظیم شده باشد، رأس‌های مش رمزگشایی‌شده از دستگاه مختصات Z-up به قرارداد Y-up مورد استفاده در glTF چرخانده می‌شوند. مقدار پیش‌فرض `"y_up"` است.
