# VaeDecodeShapeTrellis

این گره بازنمایی‌های نهفته شکل Trellis2 را به یک مش سه‌بعدی رمزگشایی می‌کند. برای این کار از یک VAE استفاده می‌کند که داده‌های نهفته شکل اسپارس را به هندسه مش تبدیل می‌کند و همچنین داده‌های تقسیم‌بندی شکل تولیدشده در حین رمزگشایی را خروجی می‌دهد. این گره از ورودی‌های نهفته تکی و دسته‌ای پشتیبانی می‌کند و به‌طور خودکار جهت‌گیری مش را با چارچوب مختصات مورد انتظار هماهنگ می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `samples` | نمونه‌های نهفته برای رمزگشایی، شامل تنسور نمونه‌ها و داده‌های مختصات اسپارس. دیکشنری نهفته همچنین ممکن است شامل فیلدهای اختیاری باشد: `coord_counts` برای شکل‌های دسته‌ای، `coord_resolution` برای کنترل رزولوشن مش، و `model_frame` برای جهت‌گیری مختصات. | LATENT | بله | None |
| `vae` | مدل VAE مورد استفاده برای رمزگشایی داده‌ی نهفته شکل به یک مش. | VAE | بله | None |

### نکاتی درباره `samples`

- ورودی `samples` یک دیکشنری نهفته است که باید شامل تنسور `samples` و مختصات اسپارس `coords` باشد.
- اگر `coord_counts` وجود داشته باشد، باید یک تنسور یک‌بعدی از اعداد صحیح نامنفی باشد و مجموع همه شمارش‌ها باید برابر با تعداد کل ردیف‌های مختصات باشد. هر شمارش نمایانگر یک شکل در دسته است.
- اگر `coord_resolution` ارائه شود، رزولوشن مش به‌صورت `coord_resolution * 16` محاسبه می‌شود. در غیر این صورت، بافر رزولوشن داخلی VAE استفاده می‌شود (مقدار پیش‌فرض: 1024).
- اگر `model_frame` روی `"z_up"` تنظیم شده باشد، رئوس مش رمزگشایی‌شده از دستگاه مختصات Z-up به قرارداد Y-up مورد استفاده در glTF چرخانده می‌شوند. مقدار پیش‌فرض `"y_up"` است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `mesh` | مش سه‌بعدی رمزگشایی‌شده، شامل موقعیت رئوس و اندیس‌های وجه. | MESH |
| `shape_subdivides` | داده‌های تقسیم‌بندی شکل تولیدشده در هر مرحله از فرآیند رمزگشایی. | SHAPE_SUBDIVIDES |
