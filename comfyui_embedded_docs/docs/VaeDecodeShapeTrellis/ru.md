# VaeDecodeShapeTrellis

Этот узел декодирует латентные представления формы Trellis2 в 3D-сетку. Он использует VAE для преобразования разреженных латентных данных формы в геометрию сетки, а также выводит данные подразбиения формы, сгенерированные во время декодирования. Узел поддерживает как одиночные, так и пакетные латентные входы и автоматически корректирует ориентацию сетки под ожидаемую систему координат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Латентные образцы для декодирования, включая тензор образцов и разреженные координатные данные. Латентный словарь также может содержать необязательные поля: `coord_counts` для пакетных форм, `coord_resolution` для управления разрешением сетки и `model_frame` для ориентации координат. | LATENT | Да | Нет |
| `vae` | Модель VAE, используемая для декодирования латента формы в сетку. | VAE | Да | Нет |

### Примечания к `samples`

- Вход `samples` — это латентный словарь, который должен содержать тензор `samples` и разреженные координаты `coords`.
- Если присутствует `coord_counts`, это должен быть одномерный тензор неотрицательных целых чисел, и сумма всех значений должна равняться общему числу строк координат. Каждое значение представляет одну форму в пакете.
- Если указан `coord_resolution`, разрешение сетки рассчитывается как `coord_resolution * 16`. В противном случае используется встроенный буфер разрешения VAE (значение по умолчанию: 1024).
- Если `model_frame` имеет значение `"z_up"`, вершины декодированной сетки поворачиваются из системы координат Z-up в соглашение Y-up, используемое glTF. Значение по умолчанию — `"y_up"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Декодированная 3D-сетка, содержащая позиции вершин и индексы граней. При декодировании нескольких форм сетки возвращаются как единый объединённый тензор, если все они имеют одинаковую форму, или как упакованный пакет переменного размера в противном случае. | MESH |
| `shape_subdivides` | Данные подразбиения формы, создаваемые на каждом этапе процесса декодирования. | SHAPE_SUBDIVIDES |
