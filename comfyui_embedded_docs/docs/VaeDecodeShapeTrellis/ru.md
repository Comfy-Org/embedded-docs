# VaeDecodeShapeTrellis

Этот узел декодирует скрытые представления формы Trellis2 в 3D-сетку. Он использует VAE для преобразования разреженных скрытых данных формы в геометрию сетки, а также выводит данные подразделения формы, полученные в процессе декодирования. Узел поддерживает как одиночные, так и пакетные скрытые входы и автоматически корректирует ориентацию сетки в соответствии с ожидаемой системой координат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Скрытые сэмплы для декодирования, включая тензор сэмплов и данные разреженных координат. Словарь скрытого представления может также содержать необязательные поля: `coord_counts` для пакетных форм, `coord_resolution` для управления разрешением сетки и `model_frame` для ориентации координат. | LATENT | Да | Нет |
| `vae` | Модель VAE, используемая для декодирования скрытого представления формы в сетку. | VAE | Да | Нет |

### Примечания к `samples`

- Вход `samples` представляет собой словарь скрытого представления, который должен содержать тензор `samples` и разреженные координаты `coords`.
- Если присутствует `coord_counts`, это должен быть одномерный тензор неотрицательных целых чисел, и сумма всех значений счётчиков должна равняться общему количеству строк координат. Каждое значение счётчика представляет одну форму в пакете.
- Если указан `coord_resolution`, разрешение сетки вычисляется как `coord_resolution * 16`. В противном случае используется встроенный буфер разрешения VAE (значение по умолчанию: 1024).
- Если `model_frame` установлен в `"z_up"`, вершины декодированной сетки поворачиваются из системы координат Z-up в принятое в glTF соглашение Y-up. Значение по умолчанию: `"y_up"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Декодированная 3D-сетка, содержащая позиции вершин и индексы граней. | MESH |
| `shape_subdivides` | Данные подразделения формы, полученные на каждом этапе процесса декодирования. | SHAPE_SUBDIVIDES |
