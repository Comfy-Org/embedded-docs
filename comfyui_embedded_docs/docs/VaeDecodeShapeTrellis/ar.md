# VaeDecodeShapeTrellis

يقوم هذا العقد بفك ترميز تمثيلات شكل Trellis2 الكامنة إلى شبكة ثلاثية الأبعاد. ويستخدم VAE لتحويل بيانات الشكل الكامنة المتفرقة إلى هندسة شبكية، كما يُخرج بيانات تقسيم الشكل الناتجة أثناء فك الترميز. يدعم العقد مدخلات كامنة فردية ومجمعة في دفعات، ويضبط تلقائيًا اتجاه الشبكة ليتوافق مع إطار الإحداثيات المتوقع.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `العينات` | العينات الكامنة المراد فك ترميزها، بما في ذلك موتر العينات وبيانات الإحداثيات المتفرقة. قد يحتوي قاموس البيانات الكامنة أيضًا على حقول اختيارية: `coord_counts` للأشكال المجمعة في دفعات، و`coord_resolution` للتحكم في دقة الشبكة، و`model_frame` لاتجاه الإحداثيات. | LATENT | نعم | None |
| `vae` | نموذج VAE المستخدم لفك ترميز الشكل الكامن إلى شبكة. | VAE | نعم | None |

### ملاحظات حول `samples`

- المدخل `samples` هو قاموس بيانات كامنة يجب أن يحتوي على موتر `samples` وإحداثيات `coords` المتفرقة.
- إذا كان `coord_counts` موجودًا، فيجب أن يكون موترًا أحادي الأبعاد من الأعداد الصحيحة غير السالبة، ويجب أن يساوي مجموع جميع القيم العدد الإجمالي لصفوف الإحداثيات. تمثل كل قيمة شكلًا واحدًا في الدفعة.
- إذا تم توفير `coord_resolution`، فسيتم حساب دقة الشبكة على أنها `coord_resolution * 16`. وإلا، يتم استخدام مخزن الدقة المدمج في VAE (القيمة الافتراضية: 1024).
- إذا تم ضبط `model_frame` على `"z_up"`، يتم تدوير رؤوس الشبكة المفككة من نظام إحداثيات Z-up إلى اصطلاح Y-up المستخدم بواسطة glTF. القيمة الافتراضية هي `"y_up"`.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `mesh` | الشبكة ثلاثية الأبعاد المفككة، وتحتوي على مواضع الرؤوس وفهارس الأوجه. عند فك ترميز أشكال متعددة، تُعاد الشبكات كموتر مكدس واحد إذا كانت جميعها تشترك في الشكل نفسه، أو كدفعة متغيرة الحجم معبأة بخلاف ذلك. | MESH |
| `shape_subdivides` | بيانات تقسيم الشكل الناتجة في كل مرحلة من مراحل عملية فك الترميز. | SHAPE_SUBDIVIDES |
