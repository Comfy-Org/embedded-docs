# VaeDecodeShapeTrellis

このノードは、Trellis2 のシェイプ潜在表現を 3D メッシュにデコードします。VAE を使用してスパースなシェイプ潜在データをメッシュジオメトリに変換し、デコード中に生成されたシェイプ細分割データも出力します。このノードは単一およびバッチ処理された潜在入力の両方をサポートし、メッシュの向きを期待される座標系に自動的に調整します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `samples` | デコード対象の潜在サンプル。サンプルテンソルとスパース座標データを含みます。潜在辞書には、オプションフィールドとしてバッチ形状用の `coord_counts`、メッシュ解像度を制御する `coord_resolution`、座標の向きを指定する `model_frame` を含めることもできます。 | LATENT | Yes | None |
| `vae` | シェイプ潜在表現をメッシュにデコードするために使用される VAE モデル。 | VAE | Yes | None |

### `samples` に関する注意事項

- `samples` 入力は潜在辞書であり、`samples` テンソルと `coords` スパース座標を含む必要があります。
- `coord_counts` が存在する場合、それは非負の整数からなる 1D テンソルである必要があり、すべてのカウントの合計が座標行の総数と一致しなければなりません。各カウントはバッチ内の 1 つの形状を表します。
- `coord_resolution` が指定されている場合、メッシュ解像度は `coord_resolution * 16` として計算されます。指定されていない場合は、VAE に組み込まれた解像度バッファが使用されます（デフォルト値: 1024）。
- `model_frame` が `"z_up"` に設定されている場合、デコードされたメッシュ頂点は Z-up 座標系から glTF で使用される Y-up 規則に回転されます。デフォルト値は `"y_up"` です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | デコードされた 3D メッシュ。頂点位置と面インデックスを含みます。 | MESH |
| `shape_subdivides` | デコード処理の各段階で生成されたシェイプ細分割データ。 | SHAPE_SUBDIVIDES |
