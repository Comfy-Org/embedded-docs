# ذخیره وزن‌های LoRA

گره SaveLoRA یک مدل LoRA (Low-Rank Adaptation) را در یک فایل ذخیره میکند. این گره مدل LoRA را به‌صورت یک فایل `.safetensors` در دایرکتوری خروجی می‌نویسد. می‌توانید یک پیشوند برای نام فایل و یک شمارنده گام اختیاری مشخص کنید؛ در صورت ارائه، شمارنده گام در نام فایل ذخیره‌شده گنجانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `lora` | مدل LoRA برای ذخیره‌سازی. از مدلی که لایه‌های LoRA به آن اعمال شده استفاده نکنید. | LORA_MODEL | بله | نامشخص |
| `prefix` | پیشوندی که برای فایل LoRA ذخیره‌شده استفاده می‌شود (پیش‌فرض: "loras/ComfyUI_trained_lora"). | STRING | بله | نامشخص |
| `steps` | اختیاری: تعداد گام‌هایی که LoRA برای آن‌ها آموزش دیده است؛ برای نام‌گذاری فایل ذخیره‌شده استفاده می‌شود. | INT | خیر | نامشخص |

**توجه:** ورودی `lora` باید یک مدل LoRA خالص باشد. از ارائه یک مدل پایه که لایه‌های LoRA به آن اعمال شده است خودداری کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| *None* | این گره هیچ داده‌ای به گردش کار خروجی نمی‌دهد. این یک گره خروجی است که فایلی را روی دیسک ذخیره می‌کند. | نامشخص |
