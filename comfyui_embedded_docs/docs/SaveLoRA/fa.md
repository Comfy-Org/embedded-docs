# ذخیره وزن‌های LoRA

The SaveLoRA node یک مدل LoRA (تطبیق کم‌رتبه) را در یک فایل ذخیره می‌کند. این گره یک مدل LoRA را به‌عنوان ورودی می‌گیرد و آن را در یک فایل `.safetensors` در پوشه خروجی می‌نویسد. می‌توانید یک پیشوند نام فایل و یک تعداد گام اختیاری را مشخص کنید تا در نام نهایی فایل گنجانده شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `lora` | مدل LoRA برای ذخیره. از مدلی که لایه‌های LoRA روی آن اعمال شده استفاده نکنید. | LORA_MODEL | بله | N/A |
| `prefix` | پیشوندی که برای فایل LoRA ذخیره‌شده استفاده می‌شود (پیش‌فرض: "loras/ComfyUI_trained_lora"). | STRING | بله | N/A |
| `steps` | اختیاری: تعداد گام‌هایی که LoRA برای آن‌ها آموزش دیده است، برای نام‌گذاری فایل ذخیره‌شده استفاده می‌شود. | INT | خیر | N/A |

**توجه:** ورودی `lora` باید یک مدل LoRA خالص باشد. مدل پایه‌ای که لایه‌های LoRA روی آن اعمال شده است ارائه نکنید.

**توجه:** فایل در پوشه خروجی ComfyUI با پسوند `.safetensors` ذخیره می‌شود. نام فایل از `prefix` و یک شمارنده با صفرهای پیشوندی (۵ رقم) ساخته می‌شود تا از بازنویسی فایل‌های موجود جلوگیری شود. وقتی `steps` ارائه شود، تعداد گام نیز در نام فایل گنجانده می‌شود (برای مثال، `1000_steps` برای ۱۰۰۰ گام).

**توجه:** این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
