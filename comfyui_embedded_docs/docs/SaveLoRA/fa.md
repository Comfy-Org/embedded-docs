# ذخیره وزن‌های LoRA

گره SaveLoRA یک مدل LoRA (Low-Rank Adaptation) را در یک فایل ذخیره می‌کند. این گره یک مدل LoRA را به عنوان ورودی می‌گیرد و آن را با پسوند `.safetensors` در پوشه خروجی می‌نویسد. می‌توانید یک پیشوند برای نام فایل و یک شمارنده گام اختیاری برای درج در نام نهایی فایل تعیین کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `LoRA` | مدل LoRA که باید ذخیره شود. از مدلی که لایه‌های LoRA به آن اعمال شده استفاده نکنید. | LORA_MODEL | بله | N/A |
| `پیشوند` | پیشوندی که برای فایل LoRA ذخیره‌شده استفاده می‌شود (پیش‌فرض: "loras/ComfyUI_trained_lora"). | STRING | بله | N/A |
| `گام‌ها` | اختیاری: تعداد گام‌هایی که LoRA برای آن‌ها آموزش دیده است و برای نام‌گذاری فایل ذخیره‌شده استفاده می‌شود. | INT | خیر | N/A |

**نکته:** ورودی `lora` باید یک مدل LoRA خالص باشد. مدل پایه‌ای که لایه‌های LoRA به آن اعمال شده است را ارائه ندهید.

**نکته:** فایل با پسوند `.safetensors` در پوشه خروجی ComfyUI ذخیره می‌شود. نام فایل از `prefix` و یک شمارنده با صفرهای پیشرو (۵ رقم) ساخته می‌شود تا از بازنویسی فایل‌های موجود جلوگیری شود. وقتی `steps` ارائه شود، تعداد گام‌ها نیز در نام فایل گنجانده می‌شود (مثلاً `1000_steps` برای ۱۰۰۰ گام).
