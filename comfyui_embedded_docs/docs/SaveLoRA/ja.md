# LoRA重みを保存

SaveLoRAノードは、LoRA（Low-Rank Adaptation）モデルをファイルに保存します。このノードは、LoRAモデルを出力ディレクトリに `.safetensors` ファイルとして書き込みます。ファイル名のプレフィックスとオプションのステップ数を指定できます。ステップ数を指定した場合、その数は保存されるファイル名に含まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `lora` | 保存するLoRAモデルです。LoRAレイヤーを含むモデルは使用しないでください。 | LORA_MODEL | はい | 該当なし |
| `prefix` | 保存されるLoRAファイルに使用するプレフィックス（デフォルト："loras/ComfyUI_trained_lora"）。 | STRING | はい | 該当なし |
| `steps` | オプション：LoRAがトレーニングされたステップ数。保存されるファイル名に使用されます。 | INT | いいえ | 該当なし |

**注記:** `lora` 入力は純粋なLoRAモデルでなければなりません。LoRAレイヤーが適用されたベースモデルを提供しないでください。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| *None* | このノードはワークフローにデータを出力しません。ファイルをディスクに保存する出力ノードです。 | 該当なし |
