# SaveLoRA

הצומת SaveLoRA שומר מודל LoRA (Low-Rank Adaptation) לקובץ. הוא מקבל מודל LoRA כקלט וכותב אותו לקובץ `.safetensors` בספריית הפלט. ניתן לציין קידומת לשם קובץ ומספר צעדים אופציונלי שייכלל בשם הקובץ הסופי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `lora` | מודל ה-LoRA לשמירה. אין להשתמש במודל עם שכבות LoRA. | LORA_MODEL | כן | N/A |
| `prefix` | הקידומת לשימוש עבור קובץ ה-LoRA הנשמר (ברירת מחדל: "loras/ComfyUI_trained_lora"). | STRING | כן | N/A |
| `steps` | אופציונלי: מספר הצעדים שאליהם אומן ה-LoRA, המשמש לשם הקובץ הנשמר. | INT | לא | N/A |

**הערה:** קלט `lora` חייב להיות מודל LoRA טהור. אין לספק מודל בסיס שעליו הוחלו שכבות LoRA.

**הערה:** הקובץ נשמר בספריית הפלט של ComfyUI עם סיומת `.safetensors`. שם הקובץ נבנה מ-`prefix` ומונה מרופד באפסים (5 ספרות) כדי למנוע דריסה של קבצים קיימים. כאשר מסופק `steps`, מספר הצעדים נכלל גם בשם הקובץ (לדוגמה, `1000_steps` עבור 1000 צעדים).

**הערה:** צומת זה מסומן כניסיוני.
