# Сохранить веса LoRA

Узел SaveLoRA сохраняет модель LoRA (Low-Rank Adaptation) в файл. Он принимает модель LoRA в качестве входа и записывает её в файл `.safetensors` в выходном каталоге. Вы можете указать префикс имени файла и необязательное количество шагов, которое будет включено в итоговое имя файла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `lora` | Модель LoRA для сохранения. Не используйте модель со слоями LoRA. | LORA_MODEL | Да | N/A |
| `prefix` | Префикс для имени сохраняемого файла LoRA (по умолчанию: "loras/ComfyUI_trained_lora"). | STRING | Да | N/A |
| `steps` | Необязательно: количество шагов, за которое обучалась LoRA; используется для имени сохраняемого файла. | INT | Нет | N/A |

**Примечание:** Вход `lora` должен быть чистой моделью LoRA. Не передавайте базовую модель, к которой применены слои LoRA.

**Примечание:** Файл сохраняется в выходном каталоге ComfyUI с расширением `.safetensors`. Имя файла формируется из `prefix` и счётчика с ведущими нулями (5 цифр), чтобы избежать перезаписи существующих файлов. Если указан `steps`, количество шагов также включается в имя файла (например, `1000_steps` для 1000 шагов).

**Примечание:** Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не выводит данные в рабочий процесс. Это выходной узел, который сохраняет файл на диск. | N/A |
