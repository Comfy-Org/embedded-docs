# Сохранить веса LoRA

Узел SaveLoRA сохраняет модель LoRA (низкоранговая адаптация) в файл. Он принимает модель LoRA на вход и записывает её в файл `.safetensors` в выходной каталог. Вы можете указать префикс имени файла и необязательное количество шагов для включения в итоговое имя файла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `lora` | Модель LoRA для сохранения. Не используйте модель со слоями LoRA. | LORA_MODEL | Да | N/A |
| `prefix` | Префикс для имени сохраняемого файла LoRA (по умолчанию: "loras/ComfyUI_trained_lora"). | STRING | Да | N/A |
| `steps` | Необязательно: количество шагов, в течение которых обучалась LoRA, используется для имени сохраняемого файла. | INT | Нет | N/A |

**Примечание:** Вход `lora` должен быть чистой моделью LoRA. Не подавайте базовую модель, к которой применены LoRA-слои.

**Примечание:** Файл сохраняется в выходной каталог ComfyUI с расширением `.safetensors`. Имя файла формируется из `prefix` и дополненного нулями счётчика (5 цифр), чтобы избежать перезаписи существующих файлов. Когда указан `steps`, количество шагов также включается в имя файла (например, `1000_steps` для 1000 шагов).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не передаёт никаких данных в рабочий процесс. Это выходной узел, который сохраняет файл на диск. | N/A |
