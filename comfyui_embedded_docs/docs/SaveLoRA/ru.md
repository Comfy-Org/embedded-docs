# Сохранить веса LoRA

Узел SaveLoRA сохраняет модель LoRA (Low-Rank Adaptation) в файл. Он записывает модель LoRA как файл `.safetensors` в выходную директорию. Вы можете указать префикс имени файла и необязательное количество шагов; если оно указано, количество шагов включается в имя сохраняемого файла.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `lora` | Модель LoRA для сохранения. Не используйте модель со слоями LoRA. | LORA_MODEL | Да | N/A |
| `prefix` | Префикс, используемый для имени сохраняемого файла LoRA (по умолчанию: "loras/ComfyUI_trained_lora"). | STRING | Да | N/A |
| `steps` | Необязательно: количество шагов, которое LoRA обучалась, используется для имени сохраняемого файла. | INT | Нет | N/A |

**Примечание:** Вход `lora` должен быть чистой моделью LoRA. Не подавайте базовую модель с применёнными к ней LoRA-слоями.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не выводит никаких данных в рабочий процесс. Это выходной узел, который сохраняет файл на диск. | N/A |
