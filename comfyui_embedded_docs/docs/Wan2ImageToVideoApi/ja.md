# Wan 2.7 画像から動画へ

Wan 2.7 Image to Video ノードは、最初のフレーム画像から始まる動画を生成します。オプションで最後のフレーム画像を提供して、その2つの間の遷移を作成したり、オーディオファイルを提供して動画の動きとタイミングをガイドしたりできます。このノードは、テキストの説明に基づいてシーンをアニメーション化するAIモデルを使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 動画生成に使用するAIモデルです。 | COMBO | 必須 | `"wan2.7-i2v"` |
| `first_frame` | 最初のフレーム画像です。出力のアスペクト比はこの画像から導出されます。 | IMAGE | 必須 | - |
| `last_frame` | 最後のフレーム画像です。モデルは最初のフレームから最後のフレームへ遷移する動画を生成します。 | IMAGE | 任意 | - |
| `audio` | 動画生成を駆動するためのオーディオです（例：リップシンク、ビートに合わせた動き）。長さは2秒～30秒です。提供されない場合、モデルは自動的に対応するBGMや効果音を生成します。 | AUDIO | 任意 | - |
| `seed` | 生成に使用するシードです（デフォルト: 0）。 | INT | 必須 | 0〜2147483647 |
| `prompt_extend` | AI支援によってプロンプトを拡張するかどうかです（デフォルト: True）。これは高度な設定です。 | BOOLEAN | 必須 | True<br>False |
| `watermark` | 結果にAI生成の透かしを追加するかどうかです（デフォルト: False）。これは高度な設定です。 | BOOLEAN | 必須 | True<br>False |

### wan2.7-i2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | 要素と視覚的特徴を説明するプロンプトです。英語と中国語に対応しています。 | STRING | 必須 | - |
| `negative_prompt` | 避けるべき内容を説明するネガティブプロンプトです。 | STRING | 必須 | - |
| `resolution` | 出力動画の解像度です。 | COMBO | 必須 | `"720P"`<br>`"1080P"` |
| `duration` | 生成される動画の長さ（秒）です（デフォルト: 5）。 | INT | 必須 | 2〜15 |

**注:** `audio` 入力には長さの制約があります。提供する場合、オーディオファイルは2秒から30秒の間でなければなりません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成された動画ファイルです。 | VIDEO |
