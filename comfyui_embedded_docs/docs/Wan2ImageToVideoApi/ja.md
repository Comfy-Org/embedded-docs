# Wan 2.7 画像から動画へ

Wan 2.7 Image to Video ノードは、最初のフレーム画像から始まるビデオを生成します。オプションで最後のフレーム画像を提供して2つのフレーム間の遷移を作成したり、オーディオファイルを提供してビデオの動きとタイミングをガイドしたりできます。このノードは、テキストの説明に基づいてシーンをアニメーション化するAIモデルを使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | ビデオ生成に使用するAIモデル。 | DYNAMIC_COMBO | 必須 | `"wan2.7-i2v"` |
| `first_frame` | 最初のフレーム画像。出力のアスペクト比はこの画像から取得されます。 | IMAGE | 必須 | - |
| `last_frame` | 最後のフレーム画像。モデルは最初のフレームから最後のフレームへ遷移するビデオを生成します。 | IMAGE | 任意 | - |
| `audio` | ビデオ生成を駆動するためのオーディオ（例：リップシンク、ビートに合わせたモーション）。長さ：2秒～30秒。提供しない場合、モデルは自動的に対応するBGMや効果音を生成します。 | AUDIO | 任意 | - |
| `seed` | 生成に使用するシード（デフォルト：0）。 | INT | 必須 | 0 〜 2147483647 |
| `prompt_extend` | AI支援でプロンプトを拡張するかどうか（デフォルト：True）。これは高度な設定です。 | BOOLEAN | 必須 | True<br>False |
| `watermark` | 結果にAI生成の透かしを追加するかどうか（デフォルト：False）。これは高度な設定です。 | BOOLEAN | 必須 | True<br>False |

### wan2.7-i2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model.prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。 | STRING | 必須 | - |
| `model.negative_prompt` | 回避すべき内容を説明するネガティブプロンプト。 | STRING | 必須 | - |
| `model.resolution` | 出力ビデオの解像度。 | COMBO | 必須 | `"720P"`<br>`"1080P"` |
| `model.duration` | 生成されるビデオの長さ（秒）（デフォルト：5）。 | INT | 必須 | 2 〜 15 |

**注記：** `audio` 入力には長さの制約があります。提供する場合、オーディオファイルは2秒以上30秒以下である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成されたビデオファイル。 | VIDEO |
