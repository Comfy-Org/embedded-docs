# Wan 2.7 Изображение в Видео

Узел Wan 2.7 Image to Video генерирует видео, начиная с первого кадра изображения. Можно дополнительно указать изображение последнего кадра, чтобы создать переход между ними, или предоставить аудиофайл, чтобы управлять движением и таймингом видео. Узел использует ИИ-модель для анимации сцены на основе вашего текстового описания.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель ИИ для генерации видео. | COMBO | Да | `"wan2.7-i2v"` |
| `first_frame` | Изображение первого кадра. Соотношение сторон выходного видео определяется этим изображением. | IMAGE | Да | - |
| `last_frame` | Изображение последнего кадра. Модель генерирует видео с переходом от первого кадра к последнему. | IMAGE | Нет | - |
| `audio` | Аудио для управления генерацией видео (например, синхронизация губ, движение в такт музыке). Длительность: 2–30 с. Если не указано, модель автоматически генерирует подходящую фоновую музыку или звуковые эффекты. | AUDIO | Нет | - |
| `seed` | Сид для генерации (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `prompt_extend` | Следует ли улучшать промпт с помощью ИИ-ассистента (по умолчанию: True). Это расширенная настройка. | BOOLEAN | Да | True<br>False |
| `watermark` | Следует ли добавлять водяной знак, сгенерированный ИИ, к результату (по умолчанию: False). Это расширенная настройка. | BOOLEAN | Да | True<br>False |

### wan2.7-i2v Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. | STRING | Да | - |
| `model.negative_prompt` | Негативный промпт, описывающий, чего следует избегать. | STRING | Да | - |
| `model.resolution` | Разрешение выходного видео. | COMBO | Да | `"720P"`<br>`"1080P"` |
| `model.duration` | Длительность генерируемого видео в секундах (по умолчанию: 5). | INT | Да | от 2 до 15 |

**Примечание:** Вход `audio` имеет ограничение по длительности. Если он указан, длительность аудиофайла должна составлять от 2 до 30 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
