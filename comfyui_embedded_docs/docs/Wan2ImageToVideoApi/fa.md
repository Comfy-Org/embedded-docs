# وان ۲.۷ تبدیل تصویر به ویدیو

گره Wan 2.7 Image to Video ویدیویی را با شروع از تصویر فریم اول تولید می‌کند. می‌توانید به‌صورت اختیاری تصویر فریم آخر را برای ایجاد انتقال بین این دو فراهم کنید، یا یک فایل صوتی برای هدایت حرکت و زمان‌بندی ویدیو ارائه دهید. این گره از یک مدل هوش مصنوعی برای متحرک‌سازی صحنه بر اساس توضیحات متنی شما استفاده می‌کند.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل هوش مصنوعی برای تولید ویدیو. | DYNAMIC_COMBO | بله | `"wan2.7-i2v"` |
| `فریم اول` | تصویر فریم اول. نسبت ابعاد خروجی از این تصویر گرفته می‌شود. | IMAGE | بله | - |
| `فریم آخر` | تصویر فریم آخر. مدل ویدیویی تولید می‌کند که از فریم اول به فریم آخر انتقال می‌یابد. | IMAGE | خیر | - |
| `صدا` | صدا برای هدایت تولید ویدیو (مثلاً همگام‌سازی لب، حرکت هماهنگ با ضرب). مدت: ۲ تا ۳۰ ثانیه. اگر ارائه نشود، مدل به‌طور خودکار موسیقی پس‌زمینه یا افکت‌های صوتی متناسب تولید می‌کند. | AUDIO | خیر | - |
| `بذر` | مقدار Seed برای استفاده در تولید (پیش‌فرض: ۰). | INT | بله | 0 تا 2147483647 |
| `گسترش پرامپت` | آیا پرامپت با کمک هوش مصنوعی تقویت شود (پیش‌فرض: True). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True<br>False |
| `واترمارک` | آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: False). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True<br>False |

### ورودی‌های wan2.7-i2v

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `پرامپت` | پرامپتی که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. | STRING | بله | - |
| `پرامپت منفی` | پرامپت منفی که توصیف می‌کند از چه چیزهایی اجتناب شود. | STRING | بله | - |
| `رزولوشن` | رزولوشن ویدیوی خروجی. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `مدت زمان` | طول ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: ۵). | INT | بله | 2 تا 15 |

**توجه:** ورودی `audio` محدودیت مدت‌زمان دارد. اگر ارائه شود، فایل صوتی باید بین ۲ تا ۳۰ ثانیه باشد.
