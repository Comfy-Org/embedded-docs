# وان ۲.۷ تبدیل تصویر به ویدیو

گره Wan 2.7 Image to Video ویدیویی تولید می‌کند که از یک تصویر فریم اول شروع می‌شود. می‌توانید به‌صورت اختیاری یک تصویر فریم آخر ارائه دهید تا انتقالی بین این دو ایجاد شود، یا یک فایل صوتی برای هدایت حرکت و زمان‌بندی ویدیو ارائه دهید. این گره از یک مدل هوش مصنوعی برای متحرک‌سازی صحنه بر اساس توضیح متنی شما استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل هوش مصنوعی برای تولید ویدیو. | DYNAMIC_COMBO | بله | `"wan2.7-i2v"` |
| `فریم اول` | تصویر فریم اول. نسبت ابعاد خروجی از این تصویر استخراج می‌شود. | IMAGE | بله | - |
| `فریم آخر` | تصویر فریم آخر. مدل ویدیویی تولید می‌کند که از فریم اول به فریم آخر انتقال می‌یابد. | IMAGE | خیر | - |
| `صدا` | صوت برای هدایت تولید ویدیو (مثلاً هم‌زمانی لب، حرکت هماهنگ با ضرب). مدت‌زمان: ۲ تا ۳۰ ثانیه. اگر ارائه نشود، مدل به‌طور خودکار موسیقی پس‌زمینه یا افکت‌های صوتی متناسب تولید می‌کند. | AUDIO | خیر | - |
| `بذر` | مقدار seed برای تولید (پیش‌فرض: ۰). | INT | بله | 0 تا 2147483647 |
| `گسترش پرامپت` | آیا پرامپت با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: True). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True<br>False |
| `واترمارک` | آیا به نتیجه، واترمارک تولیدشده توسط هوش مصنوعی اضافه شود (پیش‌فرض: False). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True<br>False |

### ورودی‌های wan2.7-i2v

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `prompt` | پرامپت توصیف‌کننده عناصر و ویژگی‌های بصری. از انگلیسی و چینی پشتیبانی می‌کند. (پیش‌فرض: خالی) | STRING | بله | - |
| `negative_prompt` | پرامپت منفی توصیف‌کننده مواردی که باید از آن‌ها اجتناب شود. (پیش‌فرض: خالی) | STRING | بله | - |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | `"720P"`<br>`"1080P"` |
| `duration` | طول ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: ۵). | INT | بله | 2 تا 15 |

**توجه:** ورودی `audio` محدودیت مدت‌زمان دارد. در صورت ارائه، فایل صوتی باید بین ۲ تا ۳۰ ثانیه باشد.
