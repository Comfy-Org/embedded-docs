# Wan2ImageToVideoApi

הצומת Wan 2.7 Image to Video יוצר סרטון החל מתמונת מסגרת ראשונה. באפשרותך לספק באופן אופציונלי תמונת מסגרת אחרונה כדי ליצור מעבר בין השתיים, או לספק קובץ אודיו כדי להנחות את התנועה והתזמון של הסרטון. הצומת משתמש במודל AI כדי להנפיש את הסצנה בהתבסס על תיאור הטקסט שלך.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל ה-AI לשימוש ליצירת הסרטון. | DYNAMIC_COMBO | כן | `"wan2.7-i2v"` |
| `first_frame` | תמונת מסגרת ראשונה. יחס הרוחב-גובה של הפלט נגזר מתמונה זו. | IMAGE | כן | - |
| `last_frame` | תמונת מסגרת אחרונה. המודל יוצר סרטון שמבצע מעבר מהמסגרת הראשונה לאחרונה. | IMAGE | לא | - |
| `audio` | אודיו להנחיית יצירת הסרטון (למשל, סנכרון שפתיים, תנועה בהתאמה לקצב). משך: 2 שניות עד 30 שניות. אם לא מסופק, המודל יוצר אוטומטית מוזיקת רקע או אפקטי קול מתאימים. | AUDIO | לא | - |
| `seed` | ערך seed לשימוש ביצירה (ברירת מחדל: 0). | INT | כן | 0 to 2147483647 |
| `prompt_extend` | האם לשפר את הפרומפט בסיוע AI (ברירת מחדל: True). זוהי הגדרה מתקדמת. | BOOLEAN | כן | True<br>False |
| `watermark` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה (ברירת מחדל: False). זוהי הגדרה מתקדמת. | BOOLEAN | כן | True<br>False |

### קלטים של wan2.7-i2v

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `prompt` | פרומפט המתאר את האלמנטים והמאפיינים החזותיים. תומך באנגלית ובסינית. (ברירת מחדל: ריק) | STRING | כן | - |
| `negative_prompt` | פרומפט שלילי המתאר ממה להימנע. (ברירת מחדל: ריק) | STRING | כן | - |
| `resolution` | הרזולוציה של סרטון הפלט. | COMBO | כן | `"720P"`<br>`"1080P"` |
| `duration` | אורך הסרטון שנוצר בשניות (ברירת מחדל: 5). | INT | כן | 2 to 15 |

**הערה:** לקלט `audio` יש מגבלת משך. אם הוא מסופק, קובץ האודיו חייב להיות באורך של בין 2 ל-30 שניות.
