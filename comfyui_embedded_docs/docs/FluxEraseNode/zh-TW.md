# Flux 擦除影像

從圖像中移除遮罩的物件，並重建背景。將遮罩塗在想要消除的區域上，此節點會以合理的背景內容填入該區域。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要處理的輸入圖像 | IMAGE | 是 | - |
| `mask` | 白色區域會被移除；黑色區域會被保留 | MASK | 是 | - |
| `膨脹像素` | 擴展遮罩邊界，確保完整覆蓋物件的邊緣（預設值：10） | INT | 是 | 0 至 25 |
| `seed` | 用於產生雜訊的隨機種子（預設值：0） | INT | 否 | 0 至 2147483647 |

**注意：** 輸入圖像的兩個維度都必須至少為 256x256 像素。遮罩會自動調整大小以符合圖像尺寸，且圖像的 Alpha 通道會在處理前被移除。

## 輸出

| 輸出名 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `IMAGE` | 移除遮罩物件並重建背景後的結果圖像 | IMAGE |
