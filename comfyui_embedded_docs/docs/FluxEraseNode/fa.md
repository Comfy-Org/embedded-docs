# حذف تصویر Flux

شیء ماسک‌شده را از تصویر حذف می‌کند و پس‌زمینه را بازسازی می‌کند. روی چیزی که می‌خواهید پاک شود ماسک بکشید و گره ناحیه را با محتوای پس‌زمینه‌ی محتمل پر می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای پردازش | IMAGE | بله | - |
| `mask` | نواحی سفید حذف می‌شوند؛ نواحی سیاه حفظ می‌شوند | MASK | بله | - |
| `dilate_pixels` | مرزهای ماسک را گسترش می‌دهد تا پوشش تمیزی از لبه‌های شیء تضمین شود (پیش‌فرض: 10) | INT | بله | 0 تا 25 |
| `seed` | دانه‌ی تصادفی (seed) مورد استفاده برای ایجاد نویز (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

**توجه:** تصویر ورودی باید حداقل در هر دو بعد، ۲۵۶×۲۵۶ پیکسل باشد. ماسک به‌طور خودکار تغییر اندازه می‌دهد تا با ابعاد تصویر مطابقت یابد و کانال آلفای تصویر قبل از پردازش حذف می‌شود.
