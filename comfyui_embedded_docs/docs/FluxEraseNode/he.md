# FluxEraseNode

מסיר מהתמונה אובייקט המכוסה במסכה ומשחזר את הרקע. צבעו את המסכה מעל מה שברצונכם למחוק, והצומת ממלא את האזור בתוכן רקע סביר.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט לעיבוד | IMAGE | כן | - |
| `mask` | אזורים לבנים מוסרים; אזורים שחורים נשמרים | MASK | כן | - |
| `dilate_pixels` | מרחיב את גבולות המסכה כדי להבטיח כיסוי נקי של קצוות האובייקט (ברירת מחדל: 10) | INT | כן | 0 to 25 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש (ברירת מחדל: 0) | INT | לא | 0 to 2147483647 |

**הערה:** תמונת הקלט חייבת להיות בגודל של לפחות 256x256 פיקסלים בכל מימד. המסכה משתנה אוטומטית לגודל המתאים למימדי התמונה, וערוץ האלפא של התמונה מוסר לפני העיבוד.
