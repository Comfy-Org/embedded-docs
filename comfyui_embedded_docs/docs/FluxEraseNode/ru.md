# Flux Удалить объект с изображения

Удаляет объект под маской из изображения и восстанавливает фон. Закрасьте маской то, что нужно стереть, и узел заполнит область правдоподобным содержимым фона.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для обработки | IMAGE | Да | - |
| `mask` | Белые области удаляются; черные области сохраняются | MASK | Да | - |
| `dilate_pixels` | Расширяет границы маски для обеспечения чистого покрытия краев объекта (по умолчанию: 10) | INT | Да | 0 до 25 |
| `seed` | Случайное зерно (seed), используемое для создания шума (по умолчанию: 0) | INT | Нет | 0 до 2147483647 |

**Примечание:** Входное изображение должно быть не менее 256x256 пикселей по обоим измерениям. Маска автоматически изменяется в соответствии с размером изображения, а альфа-канал изображения удаляется перед обработкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Результирующее изображение с удаленным объектом под маской и восстановленным фоном | IMAGE |
