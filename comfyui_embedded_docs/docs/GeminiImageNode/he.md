# Nano Banana (Google Gemini Image)

צומת GeminiImage מייצר תגובות טקסט ותמונה ממודלי Gemini AI של Google. הוא מאפשר לספק קלטים מולטימודליים הכוללים הנחיות טקסט, תמונות וקבצים כדי ליצור פלטי טקסט ותמונה קוהרנטיים. הצומת מטפל בכל תקשורת ה-API ובניתוח התגובות עם מודלי Gemini העדכניים ביותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | סוג קלט | ברירת מחדל | טווח |
| --- | --- | --- | --- | --- | --- |
| `prompt` | הנחיית טקסט ליצירה | STRING | נדרש | "" | - |
| `model` | מודל Gemini שיש להשתמש בו ליצירת תגובות | COMBO | נדרש | gemini_2_5_flash_image_preview | מודלי Gemini זמינים<br>אפשרויות שחולצו מ-enum של GeminiImageModel |
| `seed` | כאשר `seed` מקובע לערך מסוים, המודל עושה מאמץ מיטבי לספק את אותה התגובה לבקשות חוזרות. פלט דטרמיניסטי אינו מובטח. כמו כן, שינוי המודל או הגדרות פרמטרים, כגון temperature, יכול לגרום לשינויים בתגובה גם כאשר משתמשים באותו ערך `seed`. כברירת מחדל, נעשה שימוש בערך `seed` אקראי | INT | נדרש | 42 | 0 עד 18446744073709551615 |
| `images` | תמונה/תמונות אופציונליות לשימוש כהקשר עבור המודל. כדי לכלול מספר תמונות, ניתן להשתמש בצומת Batch Images | IMAGE | אופציונלי | None | - |
| `files` | קובץ/קבצים אופציונליים לשימוש כהקשר עבור המודל. מקבל קלטים מצומת Gemini Generate Content Input Files | GEMINI_INPUT_FILES | אופציונלי | None | - |

*הערה: הצומת כולל פרמטרים נסתרים (`auth_token`, `comfy_api_key`, `unique_id`) שמטופלים אוטומטית על ידי המערכת ואינם דורשים קלט מהמשתמש.*

## פלטים
