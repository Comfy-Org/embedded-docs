# CLIPTextEncodeControlnet

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنایز و رمزگذاری متن | CLIP | بله | - |
| `conditioning` | داده‌های شرطی‌سازی موجود که باید با پارامترهای کنترل‌نت تقویت شوند | CONDITIONING | بله | - |
| `text` | ورودی متنی که باید توسط مدل CLIP پردازش شود. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند | STRING | بله | - |

**توجه:** این گره برای عملکرد صحیح به هر سه ورودی (`clip`، `conditioning` و `text`) نیاز دارد. ورودی `text` از پرامپت‌های پویا و متن چندخطی برای پردازش منعطف متن پشتیبانی می‌کند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی‌سازی تقویت‌شده با پارامترهای کنترل‌نت cross-attention افزوده‌شده (`cross_attn_controlnet` و `pooled_output_controlnet`) که از رمزگذاری متنی CLIP استخراج شده‌اند | CONDITIONING |
