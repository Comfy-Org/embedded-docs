# Кодирование текста CLIP для Controlnet

Узел CLIPTextEncodeControlnet обрабатывает текстовый запрос с помощью модели CLIP и объединяет полученное текстовое кодирование с существующими данными кондиционирования. Он добавляет эмбеддинги, полученные из текста, к каждой записи кондиционирования в качестве параметров кросс-внимания ControlNet, формируя расширенный вывод кондиционирования для приложений ControlNet.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текста | CLIP | Да | - |
| `кондиционирование` | Существующие данные кондиционирования, которые будут объединены с текстовым кодированием CLIP | CONDITIONING | Да | - |
| `текст` | Текстовый запрос для обработки моделью CLIP. Поддерживает многострочный текст и динамические запросы | STRING | Да | - |

**Примечание:** Все три входа (`clip`, `conditioning` и `text`) обязательны для работы узла. Вход `text` поддерживает многострочный текст и динамические запросы для гибкой обработки текста. Данный узел помечен как экспериментальный в исходном коде.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Расширенные данные кондиционирования с добавленными параметрами кросс-внимания ControlNet (`cross_attn_controlnet` и `pooled_output_controlnet`), полученными из текстового кодирования CLIP | CONDITIONING |
