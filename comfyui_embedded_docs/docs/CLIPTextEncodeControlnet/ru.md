# Кодирование текста CLIP для Controlnet

Узел `CLIPTextEncodeControlnet` обрабатывает текстовый ввод с помощью модели CLIP и объединяет его с существующими данными conditioning для создания расширенного conditioning вывода для приложений controlnet. Он токенизирует входной текст, кодирует его через модель CLIP и добавляет полученные эмбеддинги к предоставленным данным conditioning в качестве параметров controlnet для кросс-внимания.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текста | CLIP | Да | - |
| `conditioning` | Существующие данные conditioning, которые будут расширены параметрами controlnet | CONDITIONING | Да | - |
| `text` | Текстовый ввод для обработки моделью CLIP. Поддерживает многострочный текст и динамические подсказки | STRING | Да | - |

**Примечание:** Для правильной работы этого узла требуются все три входа (`clip`, `conditioning` и `text`). Текстовый ввод `text` поддерживает динамические подсказки и многострочный текст для гибкой обработки текста. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Расширенные данные conditioning с добавленными параметрами controlnet для кросс-внимания (`cross_attn_controlnet` и `pooled_output_controlnet`), полученными из кодирования текста CLIP | CONDITIONING |
