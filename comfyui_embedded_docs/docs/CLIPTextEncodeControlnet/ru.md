# Кодирование текста CLIP для Controlnet

Узел CLIP Text Encode (Controlnet) кодирует текстовый промпт с помощью модели CLIP и добавляет полученное текстовое кодирование к существующим данным conditioning. Он сохраняет текстовые эмбеддинги как параметры перекрёстного внимания ControlNet внутри каждой записи conditioning, поэтому возвращаемые данные conditioning несут эту дополнительную информацию ControlNet.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текста | CLIP | Да | - |
| `кондиционирование` | Существующие данные conditioning, которые нужно объединить с текстовым кодированием CLIP | CONDITIONING | Да | - |
| `текст` | Текстовый промпт, который должен быть обработан моделью CLIP. Поддерживает многострочный текст и динамические промпты | STRING | Да | - |

**Примечание:** Все три входа (`clip`, `conditioning` и `text`) обязательны для работы этого узла. Вход `text` поддерживает многострочный текст и динамические промпты для гибкой обработки текста. В исходном коде этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Расширенные данные conditioning с добавленными параметрами перекрёстного внимания ControlNet (`cross_attn_controlnet` и `pooled_output_controlnet`), полученными из текстового кодирования CLIP | CONDITIONING |
