# ترميز نص CLIP لـ Controlnet

تقوم عقدة CLIP Text Encode (Controlnet) بترميز نص توجيهي باستخدام نموذج CLIP، ثم تضيف الترميز النصي الناتج إلى بيانات التكييف الموجودة. وتخزّن التضمينات النصية كمعاملات انتباه متقاطع خاصة بـ ControlNet داخل كل إدخال تكييف، بحيث تحمل بيانات التكييف المُعادة تلك المعلومات الإضافية الخاصة بـ ControlNet.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `CLIP` | نموذج CLIP المستخدم لتقطيع النص وترميزه | CLIP | نعم | - |
| `التهيئة` | بيانات التكييف الموجودة التي ستُدمج مع ترميز نص CLIP | CONDITIONING | نعم | - |
| `النص` | النص التوجيهي المراد معالجته بواسطة نموذج CLIP. يدعم النص متعدد الأسطر والنصوص التوجيهية الديناميكية | STRING | نعم | - |

**ملاحظة:** جميع المدخلات الثلاثة (`clip` و`conditioning` و`text`) مطلوبة لكي تعمل هذه العقدة. يدعم الإدخال `text` النص متعدد الأسطر والنصوص التوجيهية الديناميكية لمعالجة نصية مرنة. هذه العقدة موسومة كتجريبية في الشفرة المصدرية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | بيانات تكييف محسّنة مع معاملات الانتباه المتقاطع الخاصة بـ ControlNet المضافة (`cross_attn_controlnet` و`pooled_output_controlnet`) المشتقة من ترميز نص CLIP | CONDITIONING |
