# Bake Texture From Views

تصاویر رندرشده را دوباره روی چیدمان UV مش قرار می‌دهد. مش را با Render Mesh رندر کنید، تصاویر را ویرایش یا بازتولید کنید، سپس آن‌ها را با همان مش و دوربین‌ها بیک کنید. تکس‌ل‌هایی که هیچ نما آن‌ها را پوشش نمی‌دهد، بافت یا رنگ‌های رأس خود مش را حفظ می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `mesh` | مش با UV بازشده که رندر شده بود. | MESH | بله | - |
| `images` | یک تصویر به ازای هر دوربین، به ترتیب دوربین (Batch Images). هر رزولوشنی با نسبت ابعاد رندر؛ رزولوشن بالاتر بیک تیزتری می‌دهد. | IMAGE | بله | - |
| `camera_info` | دوربین‌هایی که تصاویر با آن‌ها رندر شده‌اند، همان‌طور که به Render Mesh متصل هستند. ریگ‌ها را با Batch Cameras به هم بپیوندید. None: نمای جلوی خودکارقاب‌شده Render Mesh. | LOAD3D_CAMERA | خیر | - |
| `resolution` | رزولوشن بافت مربعی. مقدار 0 اندازه بافت فعلی مش را حفظ می‌کند، یا اگر مش بافتی نداشته باشد 2048؛ در غیر این صورت بافت فعلی به آن بازنمونه‌برداری می‌شود. پیش‌فرض: 0. | INT | خیر | 0 تا 8192 (گام: 64) |
| `blend_exponent` | نماها با cos(زاویه دید)^توان وزن‌دهی می‌شوند. مقدار بالاتر به نمای روبه‌روتر بیشتر وزن می‌دهد (تیزتر، درزهای سخت‌تر)؛ مقدار پایین‌تر میانگین نماهای بیشتری را می‌گیرد (نرم‌تر). پیش‌فرض: 4.0. | FLOAT | خیر | 0.0 تا 32.0 (گام: 0.5) |
| `fill_unseen` | تکس‌ل‌هایی که هیچ نما آن‌ها را نمی‌بیند، رنگِ گسترش‌یافته از سطح دیده‌شده را به جای بافت یا رنگ‌های رأس خود مش می‌گیرند. وقتی نماها کل بافت را جایگزین می‌کنند از آن استفاده کنید. پیش‌فرض: false. | BOOLEAN | خیر | true<br>false |
| `mask` | نواحی ویرایش‌شده به ازای هر نما؛ فقط پیکسل‌های ماسک‌شده پروجکت می‌شوند. یک ماسک برای همه نماها اعمال می‌شود. | MASK | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `base_color` | بافت بیک‌شده، برای Apply Texture to Mesh. | IMAGE |
| `confidence` | برای هر تکس‌ل، اینکه بهترین نما چقدر روبه‌رو آن را دیده است؛ 0 یعنی دیده‌نشده. | MASK |

توجه: رندرهایی که با تبدیل مدل در نمایشگر (viewer model transform) ساخته می‌شوند با بیک هم‌تراز نمی‌شوند، و فقط اولین مش از یک دسته استفاده می‌شود.
