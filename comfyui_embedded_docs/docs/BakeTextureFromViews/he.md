# Bake Texture From Views

הפרויקט מרנדר תמונות חזרה לפריסת ה-UV של הרשת. רנדרו את הרשת עם Render Mesh, ערכו או צרו מחדש את התמונות, ואז אפו אותן עם אותה רשת ואותן מצלמות. טקסלים שאף מבט לא מכסה שומרים על הטקסטורה או צבעי הקודקודים של הרשת עצמה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `mesh` | הרשת שעברה פריסת UV ושעבורה בוצע רינדור. | MESH | כן | - |
| `images` | תמונה אחת לכל מצלמה, לפי סדר המצלמות (Batch Images). כל רזולוציה עם יחס הרוחב-גובה של הרינדור; רזולוציה גבוהה יותר נותנת אפייה חדה יותר. | IMAGE | כן | - |
| `camera_info` | המצלמות שאיתן בוצע רינדור התמונות, כפי שמחוברות ל-Render Mesh. חברו ריגים עם Batch Cameras. ללא: תצוגת החזית הממוסגרת אוטומטית של Render Mesh. | LOAD3D_CAMERA | לא | - |
| `resolution` | רזולוציית טקסטורה מרובעת. 0 שומר על גודל הטקסטורה הנוכחי של הרשת, או 2048 כשאין לה כזו; אחרת הטקסטורה הנוכחית נדגמת מחדש לגודל זה. ברירת מחדל: 0. | INT | לא | 0 עד 8192 (צעד: 64) |
| `blend_exponent` | המבטים מקבלים משקל לפי cos(view angle)^exponent. ערך גבוה מעדיף את המבט הישיר ביותר (חד יותר, תפרים קשים יותר); ערך נמוך ממצע יותר מבטים (רך יותר). ברירת מחדל: 4.0. | FLOAT | לא | 0.0 עד 32.0 (צעד: 0.5) |
| `fill_unseen` | טקסלים שאף מבט לא רואה מקבלים צבע שנצמח מהמשטח הנראה, במקום הטקסטורה של הרשת עצמה או צבעי הקודקודים. השתמשו בכך כאשר המבטים מחליפים את כל הטקסטורה. ברירת מחדל: false. | BOOLEAN | לא | true<br>false |
| `mask` | אזורים ערוכים לכל מבט; רק פיקסלים מסומנים במסכה מוקרנים. מסכה בודדת חלה על כל המבטים. | MASK | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `base_color` | הטקסטורה שנאפתה, עבור Apply Texture to Mesh. | IMAGE |
| `confidence` | לכל טקסל, עד כמה המבט הטוב ביותר ראה אותו חזיתית; 0 פירושו שלא נראה. | MASK |

הערה: רינדורים שנוצרו עם טרנספורמציית מודל של מציג לא מתיישרים עם האפייה, ורק הרשת הראשונה באצווה משמשת.
