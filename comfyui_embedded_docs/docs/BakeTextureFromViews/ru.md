# Bake Texture From Views

Проецирует отрендеренные изображения обратно на UV-развёртку меша. Отрендерите меш с помощью Render Mesh, отредактируйте или перегенерируйте изображения, затем запеките их с тем же мешем и камерами. Тексели, которые не покрывает ни один ракурс, сохраняют собственную текстуру меша или цвета вершин.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `mesh` | UV-развёрнутый меш, который был отрендерен. | MESH | Да | - |
| `images` | Одно изображение на камеру, в порядке камер (Batch Images). Любое разрешение с соотношением сторон рендера; более высокое даёт более чёткую запечку. | IMAGE | Да | - |
| `camera_info` | Камеры, с которыми были отрендерены изображения, в том виде, в каком они подключены к Render Mesh. Объединяйте риги с помощью Batch Cameras. Нет: автоматически кадрированный фронтальный вид Render Mesh. | LOAD3D_CAMERA | Нет | - |
| `resolution` | Квадратное разрешение текстуры. 0 сохраняет текущий размер текстуры меша или 2048, если текстуры нет; в противном случае текущая текстура пересэмплируется до него. По умолчанию: 0. | INT | Нет | от 0 до 8192 (шаг 64) |
| `blend_exponent` | Ракурсы взвешиваются по cos(угол ракурса)^экспонента. Более высокое значение отдаёт предпочтение наиболее фронтальному ракурсу (резче, жёстче швы); более низкое сильнее усредняет несколько ракурсов (мягче). По умолчанию: 4.0. | FLOAT | Нет | от 0.0 до 32.0 (шаг 0.5) |
| `fill_unseen` | Тексели, не видимые ни из одного ракурса, получают цвет, продлённый с видимой поверхности, вместо собственной текстуры меша или цветов вершин. Используйте, когда ракурсы заменяют всю текстуру. По умолчанию: false. | BOOLEAN | Нет | true<br>false |
| `mask` | Отредактированные области для каждого ракурса; проецируются только пиксели под маской. Одна маска применяется ко всем ракурсам. | MASK | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `base_color` | Запечённая текстура; предназначена для Apply Texture to Mesh. | IMAGE |
| `confidence` | Для каждого текселя — насколько фронтально его видел лучший ракурс; 0 означает, что он не виден. | MASK |

Примечание: рендеры, сделанные с преобразованием модели средствами просмотрщика, не совпадают с запечённой текстурой, и используется только первый меш из пакета.
