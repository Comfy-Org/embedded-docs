# Bake Texture From Views

يعيد إسقاط الصور المُصيَّرة على تخطيط UV الخاص بالشبكة. صيّر الشبكة باستخدام Render Mesh، ثم عدّل الصور أو أعد توليدها، ثم نفّذ عليها عملية الخبز (bake) باستخدام الشبكة والكاميرات نفسها. تحتفظ البكسلات النسيجية (texels) التي لا يغطيها أي منظر بنسيج الشبكة الخاص أو ألوان الرؤوس الخاصة بها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `mesh` | الشبكة المفكوكة UV التي تم تصييرها. | MESH | نعم | - |
| `images` | صورة واحدة لكل كاميرا، بترتيب الكاميرا (Batch Images). أي دقة بنسبة الأبعاد الخاصة بالتصيير؛ الدقة الأعلى تعطي نتيجة خبز أكثر حدة. | IMAGE | نعم | - |
| `camera_info` | الكاميرات التي صُيّرت بها الصور، كما هي موصولة بـ Render Mesh. اجمع الأطقم (rigs) باستخدام Batch Cameras. لا شيء: العرض الأمامي المؤطّر تلقائيًا من Render Mesh. | LOAD3D_CAMERA | لا | - |
| `resolution` | دقة النسيج المربعة. القيمة 0 تحافظ على حجم النسيج الحالي للشبكة، أو 2048 عندما لا يكون لديها نسيج؛ وبخلاف ذلك يُعاد أخذ عينات من النسيج الحالي إلى هذه الدقة. الافتراضي: 0. | INT | لا | 0 إلى 8192 (خطوة: 64) |
| `blend_exponent` | تُوزن المناظر بواسطة cos(زاوية العرض)^الأس. القيم الأعلى تفضّل العرض الأكثر مواجهة (أكثر حدة ودرزات أصعب)؛ والقيم الأقل تتوسط مزيدًا من المناظر (أنعم). الافتراضي: 4.0. | FLOAT | لا | 0.0 إلى 32.0 (خطوة: 0.5) |
| `fill_unseen` | تأخذ البكسلات النسيجية التي لا يراها أي منظر لونًا ممتدًا من السطح المرئي بدلًا من نسيج الشبكة الخاص أو ألوان الرؤوس. استخدمه عندما تستبدل المناظر النسيج بأكمله. الافتراضي: false. | BOOLEAN | لا | true<br>false |
| `mask` | المناطق المعدّلة لكل منظر؛ تُسقط البكسلات التي يغطيها القناع فقط. ينطبق قناع واحد على كل منظر. | MASK | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `base_color` | النسيج الناتج من الخبز، لاستخدامه مع Apply Texture to Mesh. | IMAGE |
| `confidence` | لكل بكسل نسيجي، مدى رؤية أفضل منظر له بشكل مباشر؛ 0 يعني غير مرئي. | MASK |

ملاحظة: عمليات التصيير التي تُجرى باستخدام تحويل نموذج العارض لا تتماشى مع نتيجة الخبز، وتُستخدم أول شبكة فقط من الدفعة.
