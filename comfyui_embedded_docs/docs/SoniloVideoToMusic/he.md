# Sonilo וידאו למוזיקה

יצירת מוזיקה מווידאו באמצעות מודל ה-AI של Sonilo. צומת זה מנתח את תוכן וידאו הקלט ויוצר קטע מוזיקה מתאים. הוא משתמש בשירות AI חיצוני כדי לעבד את הווידאו ולהפיק את האודיו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | וידאו קלט שממנו ליצור מוזיקה. משך מקסימלי: 6 דקות. | VIDEO | כן | - |
| `prompt` | פרומפט טקסטואלי אופציונלי להכוונת יצירת המוזיקה. השאר ריק לקבלת האיכות הטובה ביותר - המודל ינתח את תוכן הווידאו במלואו. (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `seed` | Seed לשחזוריות. נכון לעכשיו שירות Sonilo מתעלם ממנו, אך הוא נשמר לצורך עקביות הגרף. (ברירת מחדל: 0) | INT | לא | 0 to 18446744073709551615 |
