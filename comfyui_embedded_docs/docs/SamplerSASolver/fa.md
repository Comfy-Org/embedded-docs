# SamplerSASolver

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل انتشار مورد استفاده برای نمونه‌برداری | MODEL | بله | - |
| `eta` | ضریب مقیاس اندازه گام را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 10.0 |
| `sde_start_percent` | درصد شروع فرآیند نویززدایی که در آن نمونه‌برداری SDE آغاز می‌شود؛ با استفاده از برنامه زمان‌بندی نمونه‌برداری مدل به مقدار سیگما تبدیل می‌شود (پیش‌فرض: 0.2) | FLOAT | خیر | 0.0 - 1.0 |
| `sde_end_percent` | درصد پایان فرآیند نویززدایی که در آن نمونه‌برداری SDE متوقف می‌شود؛ با استفاده از برنامه زمان‌بندی نمونه‌برداری مدل به مقدار سیگما تبدیل می‌شود (پیش‌فرض: 0.8) | FLOAT | خیر | 0.0 - 1.0 |
| `s_noise` | میزان نویز اضافه‌شده در طول نمونه‌برداری را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 100.0 |
| `predictor_order` | مرتبه مؤلفه پیش‌بین در حل‌کننده (پیش‌فرض: 3) | INT | خیر | 1 - 6 |
| `corrector_order` | مرتبه مؤلفه تصحیح‌کننده در حل‌کننده (پیش‌فرض: 4) | INT | خیر | 0 - 6 |
| `use_pece` | روش PECE (پیش‌بینی-ارزیابی-تصحیح-ارزیابی) را فعال یا غیرفعال می‌کند | BOOLEAN | خیر | - |
| `simple_order_2` | محاسبات ساده‌شده مرتبه دوم را فعال یا غیرفعال می‌کند | BOOLEAN | خیر | - |

توجه: همه ورودی‌ها به جز `model` پارامترهای پیشرفته هستند که به‌طور پیش‌فرض در رابط کاربری گره پنهان شده‌اند.

|-------------|-------------|-----------|
| `sampler` | یک شیء نمونه‌بردار پیکربندی‌شده که می‌تواند با مدل‌های انتشار استفاده شود | SAMPLER |
