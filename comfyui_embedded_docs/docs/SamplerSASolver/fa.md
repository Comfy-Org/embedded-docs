# SamplerSASolver

گره SamplerSASolver یک الگوریتم نمونه‌برداری سفارشی برای مدل‌های انتشار پیاده‌سازی می‌کند. این گره از رویکرد پیش‌بین-اصلاح‌کننده با تنظیمات مرتبه قابل‌پیکربندی و پارامترهای معادله دیفرانسیل تصادفی (SDE) برای تولید نمونه‌ها از مدل ورودی استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل انتشار مورد استفاده برای نمونه‌برداری | MODEL | بله | - |
| `اتا` | ضریب مقیاس اندازه گام را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 10.0 |
| `درصد شروع SDE` | درصد شروع نمونه‌برداری SDE (پیش‌فرض: 0.2) | FLOAT | خیر | 0.0 - 1.0 |
| `درصد پایان SDE` | درصد پایان نمونه‌برداری SDE (پیش‌فرض: 0.8) | FLOAT | خیر | 0.0 - 1.0 |
| `s_noise` | میزان نویز اضافه‌شده در طول نمونه‌برداری را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 100.0 |
| `ترتیب پیش‌بینی‌کننده` | مرتبه مؤلفه پیش‌بین (predictor) در حل‌کننده (پیش‌فرض: 3) | INT | خیر | 1 - 6 |
| `ترتیب تصحیح‌کننده` | مرتبه مؤلفه اصلاح‌کننده (corrector) در حل‌کننده (پیش‌فرض: 4) | INT | خیر | 0 - 6 |
| `استفاده از PECE` | روش PECE (پیش‌بینی-ارزیابی-اصلاح-ارزیابی) را فعال یا غیرفعال می‌کند | BOOLEAN | خیر | - |
| `ترتیب ساده ۲` | محاسبات ساده‌شده مرتبه دوم را فعال یا غیرفعال می‌کند | BOOLEAN | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `sampler` | یک شیء نمونه‌بردار (sampler) پیکربندی‌شده که می‌تواند با مدل‌های انتشار استفاده شود | SAMPLER |
