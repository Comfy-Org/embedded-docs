# SamplerSASolver

گره SamplerSASolver یک نمونه‌گیر سفارشی برای مدل‌های انتشار (diffusion) ایجاد و پیکربندی می‌کند. این گره از الگوریتم نمونه‌گیری `sa_solver` با طرح predictor-corrector قابل تنظیم و تنظیمات معادله دیفرانسیل تصادفی (SDE) استفاده می‌کند و یک شیء نمونه‌گیر برمی‌گرداند که می‌توان آن را به یک گره نمونه‌گیری متصل کرد. مقادیر `sde_start_percent` و `sde_end_percent` با استفاده از برنامه نمونه‌گیری مدل متصل، به مقادیر سیگما تبدیل می‌شوند تا بازه‌ای را تعریف کنند که در آن مؤلفه تصادفی اعمال می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدل انتشار که برنامه نمونه‌گیری آن برای ساخت نمونه‌گیر استفاده می‌شود | MODEL | بله | - |
| `eta` | ضریب مقیاس اندازه گام حل‌کننده SDE را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 10.0 |
| `sde_start_percent` | درصد شروع فرایند نمونه‌گیری که مؤلفه تصادفی (SDE) از آنجا آغاز می‌شود؛ با استفاده از برنامه مدل به مقدار سیگما تبدیل می‌شود (پیش‌فرض: 0.2) | FLOAT | خیر | 0.0 - 1.0 |
| `sde_end_percent` | درصد پایان فرایند نمونه‌گیری که مؤلفه تصادفی (SDE) در آن متوقف می‌شود؛ با استفاده از برنامه مدل به مقدار سیگما تبدیل می‌شود (پیش‌فرض: 0.8) | FLOAT | خیر | 0.0 - 1.0 |
| `s_noise` | میزان نویز افزوده‌شده در طول نمونه‌گیری را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 100.0 |
| `predictor_order` | مرتبه مؤلفه پیش‌بین در حل‌کننده (پیش‌فرض: 3) | INT | خیر | 1 - 6 |
| `corrector_order` | مرتبه مؤلفه تصحیح‌کننده در حل‌کننده (پیش‌فرض: 4) | INT | خیر | 0 - 6 |
| `use_pece` | روش PECE (Predict-Evaluate-Correct-Evaluate) را فعال می‌کند (پیش‌فرض: غیرفعال) | BOOLEAN | خیر | - |
| `simple_order_2` | محاسبات ساده‌شده مرتبه دوم را فعال می‌کند (پیش‌فرض: غیرفعال) | BOOLEAN | خیر | - |

همه ورودی‌های اختیاری در رابط کاربری به‌عنوان پیشرفته علامت‌گذاری شده‌اند.
