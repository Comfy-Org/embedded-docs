# SamplerSASolver

تنفّذ عقدة SamplerSASolver خوارزمية أخذ عينات مخصصة لنماذج الانتشار. وتستخدم أسلوب التنبؤ والتصحيح مع إعدادات رتبة قابلة للتهيئة ومعاملات المعادلة التفاضلية العشوائية (SDE) لتوليد عينات من النموذج المُدخل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الانتشار المستخدم لأخذ العينات | MODEL | نعم | - |
| `eta` | يتحكم في عامل تحجيم حجم الخطوة (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 10.0 |
| `sde_start_percent` | النسبة المئوية لبداية عملية إزالة الضوضاء التي يبدأ عندها أخذ عينات SDE، وتُحوَّل إلى قيمة سيغما باستخدام جدول أخذ العينات الخاص بالنموذج (الافتراضي: 0.2) | FLOAT | لا | 0.0 - 1.0 |
| `sde_end_percent` | النسبة المئوية لنهاية عملية إزالة الضوضاء التي يتوقف عندها أخذ عينات SDE، وتُحوَّل إلى قيمة سيغما باستخدام جدول أخذ العينات الخاص بالنموذج (الافتراضي: 0.8) | FLOAT | لا | 0.0 - 1.0 |
| `s_noise` | يتحكم في مقدار الضوضاء المضافة أثناء أخذ العينات (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 100.0 |
| `predictor_order` | رتبة المكوّن المُنبئ في الحلّال (الافتراضي: 3) | INT | لا | 1 - 6 |
| `corrector_order` | رتبة المكوّن المُصحِّح في الحلّال (الافتراضي: 4) | INT | لا | 0 - 6 |
| `use_pece` | يعمل على تمكين أو تعطيل طريقة PECE (التنبؤ والتقييم والتصحيح والتقييم) | BOOLEAN | لا | - |
| `simple_order_2` | يعمل على تمكين أو تعطيل الحسابات المبسّطة من الدرجة الثانية | BOOLEAN | لا | - |

ملاحظة: جميع المدخلات باستثناء `model` هي معاملات متقدمة، مخفية افتراضيًا في واجهة العقدة.
