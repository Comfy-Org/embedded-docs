# SamplerSASolver

تُنشئ عقدة SamplerSASolver كائن sampler مخصّصًا لنماذج الانتشار وتُهيّئه. وهي تستخدم خوارزمية أخذ العينات `sa_solver` مع مخطط متنبئ-مصحح قابل للتهيئة وإعدادات المعادلة التفاضلية العشوائية (SDE)، وتُعيد كائن sampler يمكن توصيله بعقدة أخذ العينات. تُحوَّل قيمتا `sde_start_percent` و`sde_end_percent` إلى قيم sigma باستخدام جدول أخذ العينات للنموذج المتصل لتحديد الفاصل الذي يُطبَّق فيه المكوّن العشوائي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | نموذج الانتشار الذي يُستخدم جدول أخذ العينات الخاص به لبناء sampler | MODEL | نعم | - |
| `إيتا` | يتحكم في عامل قياس حجم الخطوة لمُحلّ SDE (القيمة الافتراضية: 1.0) | FLOAT | لا | 0.0 - 10.0 |
| `نسبة بدء SDE` | نسبة البداية في عملية أخذ العينات التي يبدأ عندها المكوّن العشوائي (SDE)؛ تُحوَّل إلى قيمة sigma باستخدام جدول النموذج (القيمة الافتراضية: 0.2) | FLOAT | لا | 0.0 - 1.0 |
| `نسبة انتهاء SDE` | نسبة النهاية في عملية أخذ العينات التي يتوقف عندها المكوّن العشوائي (SDE)؛ تُحوَّل إلى قيمة sigma باستخدام جدول النموذج (القيمة الافتراضية: 0.8) | FLOAT | لا | 0.0 - 1.0 |
| `الضوضاء s` | يتحكم في مقدار الضوضاء المضافة أثناء أخذ العينات (القيمة الافتراضية: 1.0) | FLOAT | لا | 0.0 - 100.0 |
| `ترتيب المتنبئ` | رتبة المكوّن المتنبئ في المُحلّ (القيمة الافتراضية: 3) | INT | لا | 1 - 6 |
| `ترتيب المصحح` | رتبة المكوّن المصحّح في المُحلّ (القيمة الافتراضية: 4) | INT | لا | 0 - 6 |
| `استخدام PECE` | يُفعّل طريقة PECE (Predict-Evaluate-Correct-Evaluate) (القيمة الافتراضية: معطّل) | BOOLEAN | لا | - |
| `الترتيب البسيط 2` | يُفعّل حسابات مبسّطة من الرتبة الثانية (القيمة الافتراضية: معطّل) | BOOLEAN | لا | - |

جميع المدخلات الاختيارية مُعلّمة كمتقدمة في الواجهة.
