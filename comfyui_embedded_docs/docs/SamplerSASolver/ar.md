# SamplerSASolver

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | نموذج الانتشار المستخدم في أخذ العينات | MODEL | نعم | - |
| `إيتا` | يتحكم في عامل قياس حجم الخطوة (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 10.0 |
| `نسبة بدء SDE` | النسبة المئوية لبداية أخذ العينات باستخدام SDE (الافتراضي: 0.2) | FLOAT | لا | 0.0 - 1.0 |
| `نسبة انتهاء SDE` | النسبة المئوية لنهاية أخذ العينات باستخدام SDE (الافتراضي: 0.8) | FLOAT | لا | 0.0 - 1.0 |
| `الضوضاء s` | يتحكم في مقدار الضوضاء المضافة أثناء أخذ العينات (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 100.0 |
| `ترتيب المتنبئ` | ترتيب مكوّن المتنبئ في المحلّل (الافتراضي: 3) | INT | لا | 1 - 6 |
| `ترتيب المصحح` | ترتيب مكوّن المصحح في المحلّل (الافتراضي: 4) | INT | لا | 0 - 6 |
| `استخدام PECE` | يقوم بتمكين أو تعطيل طريقة PECE (التنبؤ-التقييم-التصحيح-التقييم) | BOOLEAN | لا | - |
| `الترتيب البسيط 2` | يقوم بتمكين أو تعطيل الحسابات المبسطة من الدرجة الثانية | BOOLEAN | لا | - |
