# SamplerSASolver

הצומת SamplerSASolver יוצר ומגדיר sampler מותאם אישית עבור מודלי דיפוזיה. הוא משתמש באלגוריתם הדגימה "sa_solver" עם סכמת מנבא-מתקן (predictor-corrector) ניתנת להגדרה והגדרות משוואה דיפרנציאלית סטוכסטית (SDE), ומחזיר אובייקט sampler שניתן לחבר לצומת דגימה. הערכים `sde_start_percent` ו-`sde_end_percent` מומרים לערכי סיגמה באמצעות לוח זמני הדגימה של המודל המחובר, כדי להגדיר את המרווח שבו מיושם הרכיב הסטוכסטי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה שלו לוח זמני הדגימה משמש לבניית ה-sampler | MODEL | כן | - |
| `eta` | שולט במקדם קנה המידה של גודל הצעד של פותר ה-SDE (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 - 10.0 |
| `sde_start_percent` | אחוז ההתחלה של תהליך הדגימה שבו מתחיל הרכיב הסטוכסטי (SDE); מומר לערך סיגמה באמצעות לוח הזמנים של המודל (ברירת מחדל: 0.2) | FLOAT | לא | 0.0 - 1.0 |
| `sde_end_percent` | אחוז הסיום של תהליך הדגימה שבו מפסיק הרכיב הסטוכסטי (SDE); מומר לערך סיגמה באמצעות לוח הזמנים של המודל (ברירת מחדל: 0.8) | FLOAT | לא | 0.0 - 1.0 |
| `s_noise` | שולט בכמות הרעש שמתווספת במהלך הדגימה (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 - 100.0 |
| `predictor_order` | סדר רכיב המנבא בפותר (ברירת מחדל: 3) | INT | לא | 1 - 6 |
| `corrector_order` | סדר רכיב המתקן בפותר (ברירת מחדל: 4) | INT | לא | 0 - 6 |
| `use_pece` | מפעיל את שיטת PECE (Predict-Evaluate-Correct-Evaluate) (ברירת מחדל: מושבת) | BOOLEAN | לא | - |
| `simple_order_2` | מפעיל חישובי סדר שני מפושטים (ברירת מחדל: מושבת) | BOOLEAN | לא | - |

כל הקלטים האופציונליים מסומנים כאפשרויות מתקדמות בממשק.
