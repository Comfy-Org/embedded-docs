# SamplerSASolver

Узел SamplerSASolver создаёт и настраивает пользовательский сэмплер для диффузионных моделей. Он использует алгоритм сэмплирования "sa_solver" с настраиваемой схемой предиктор-корректор и настройками стохастического дифференциального уравнения (SDE), возвращая объект сэмплера, который можно подключить к узлу сэмплирования. Значения `sde_start_percent` и `sde_end_percent` преобразуются в значения sigma с использованием расписания сэмплирования подключённой модели, чтобы определить интервал, в котором применяется стохастическая компонента.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, чьё расписание сэмплирования используется для построения сэмплера | MODEL | Да | - |
| `эта` | Управляет коэффициентом масштабирования размера шага SDE-решателя (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 10.0 |
| `процент_начала_sde` | Начальный процент процесса сэмплирования, с которого начинается стохастическая (SDE) компонента; преобразуется в значение sigma с использованием расписания модели (по умолчанию: 0.2) | FLOAT | Нет | 0.0 - 1.0 |
| `процент_окончания_sde` | Конечный процент процесса сэмплирования, на котором стохастическая (SDE) компонента останавливается; преобразуется в значение sigma с использованием расписания модели (по умолчанию: 0.8) | FLOAT | Нет | 0.0 - 1.0 |
| `s_шум` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 100.0 |
| `порядок_предиктора` | Порядок компоненты-предиктора в решателе (по умолчанию: 3) | INT | Нет | 1 - 6 |
| `порядок_корректора` | Порядок компоненты-корректора в решателе (по умолчанию: 4) | INT | Нет | 0 - 6 |
| `использовать_pece` | Включает метод PECE (Predict-Evaluate-Correct-Evaluate) (по умолчанию: отключено) | BOOLEAN | Нет | - |
| `простой_порядок_2` | Включает упрощённые расчёты второго порядка (по умолчанию: отключено) | BOOLEAN | Нет | - |

Все необязательные входы помечены как расширенные в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера (использующий алгоритм `sa_solver`), который может использоваться узлами сэмплирования | SAMPLER |
