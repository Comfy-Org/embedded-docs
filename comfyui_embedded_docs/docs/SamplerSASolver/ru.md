# SamplerSASolver

Узел SamplerSASolver реализует пользовательский алгоритм сэмплирования для диффузионных моделей. Он использует подход предиктор-корректор с настраиваемыми параметрами порядка и параметрами стохастического дифференциального уравнения (SDE) для генерации сэмплов из входной модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Диффузионная модель, используемая для сэмплирования | MODEL | Да | - |
| `eta` | Управляет коэффициентом масштабирования шага (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 10.0 |
| `sde_start_percent` | Начальный процент процесса шумоподавления, где начинается SDE-сэмплирование, преобразуется в значение сигмы с использованием графика сэмплирования модели (по умолчанию: 0.2) | FLOAT | Нет | 0.0 - 1.0 |
| `sde_end_percent` | Конечный процент процесса шумоподавления, где прекращается SDE-сэмплирование, преобразуется в значение сигмы с использованием графика сэмплирования модели (по умолчанию: 0.8) | FLOAT | Нет | 0.0 - 1.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 100.0 |
| `predictor_order` | Порядок компонента предиктора в солвере (по умолчанию: 3) | INT | Нет | 1 - 6 |
| `corrector_order` | Порядок компонента корректора в солвере (по умолчанию: 4) | INT | Нет | 0 - 6 |
| `use_pece` | Включает или отключает метод PECE (Predict-Evaluate-Correct-Evaluate) | BOOLEAN | Нет | - |
| `simple_order_2` | Включает или отключает упрощенные вычисления второго порядка | BOOLEAN | Нет | - |

Примечание: все входные параметры, кроме `model`, являются дополнительными и по умолчанию скрыты в интерфейсе узла.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `sampler` | Сконфигурированный объект сэмплера, который можно использовать с диффузионными моделями | SAMPLER |
