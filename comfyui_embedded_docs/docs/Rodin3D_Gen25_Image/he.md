# Rodin3D_Gen25_Image

## סקירה כללית

צומת זה יוצר מודל תלת־ממדי מתמונה אחת עד חמש תמונות עזר באמצעות Rodin Gen-2.5 API. ניתן לבחור בין מצבי איכות Fast, Regular או Extreme-High כדי לאזן בין מהירות היצירה לעלות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | תמונה אחת עד חמש תמונות קלט. כאשר מסופקות מספר תמונות, התמונה הראשונה משמשת לחומרים. | IMAGE | כן | 1 עד 5 תמונות |
| `mode` | מצב איכות היצירה. מצבי איכות גבוהים יותר מפיקים תוצאות טובות יותר אך עולים יותר. | COMBO | כן | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `material` | סוג החומר עבור המודל התלת־ממדי שנוצר. | COMBO | כן | `"PBR"`<br>`"Matte"` |
| `geometry_file_format` | פורמט קובץ הפלט עבור הגאומטריה של המודל התלת־ממדי. | COMBO | כן | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `texture_mode` | מצב יצירת הטקסטורה. "Original" משמר את טקסטורות הקלט, "Clean" מסיר אותן, ו-"Style" מחיל טקסטורה מסוגננת. | COMBO | כן | `"Original"`<br>`"Clean"`<br>`"Style"` |
| `seed` | זרע אקראי לתוצאות ניתנות לשחזור. השתמש באותו זרע כדי לקבל את אותו פלט. | INT | כן | 0 עד 2147483647 |
| `TAPose` | האם להחיל T-pose על המודל שנוצר. | BOOLEAN | כן | True / False |
| `hd_texture` | האם ליצור מפת טקסטורה באיכות גבוהה. | BOOLEAN | כן | True / False |
| `texture_delight` | האם להסיר תאורה מתמונות הקלט לפני יצירת הטקסטורה. | BOOLEAN | כן | True / False |
| `use_original_alpha` | האם להשתמש בערוץ האלפא המקורי מתמונות הקלט. | BOOLEAN | כן | True / False |
| `addon_highpack` | האם ליצור גרסה בעלת מספר פוליגונים גבוה של המודל בנוסף לגרסה הסטנדרטית. | BOOLEAN | כן | True / False |
| `bbox_width` | הרוחב של תיבת התיחום עבור המודל שנוצר, בסנטימטרים. | INT | כן | 1 עד 1000 |
| `bbox_height` | הגובה של תיבת התיחום עבור המודל שנוצר, בסנטימטרים. | INT | כן | 1 עד 1000 |
| `bbox_length` | האורך של תיבת התיחום עבור המודל שנוצר, בסנטימטרים. | INT | כן | 1 עד 1000 |
| `height_cm` | הגובה של המודל שנוצר, בסנטימטרים. | INT | כן | 1 עד 300 |

**הערה לגבי מספר התמונות:** הצומת מקבל בין תמונה אחת ל־5 תמונות. אם תספק אצווה של תמונות (למשל, אצווה של 4 תמונות), כל תמונה באצווה מטופלת כתמונת קלט נפרדת. אספקה של יותר מ־5 תמונות תגרום לשגיאה.
