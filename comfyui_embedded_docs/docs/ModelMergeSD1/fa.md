# ModelMergeSD1

ModelMergeSD1 به شما امکان می‌دهد دو مدل Stable Diffusion 1.x را با تنظیم تأثیر مؤلفه‌های جداگانه آن‌ها در هم ادغام کنید. این گره یک وزن ترکیب جداگانه برای جاسازی زمان، جاسازی برچسب، هر بلوک ورودی، هر بلوک میانی، هر بلوک خروجی و لایه خروجی نهایی فراهم می‌کند و کنترل دقیقی بر نحوه ترکیب دو مدل ارائه می‌دهد.
