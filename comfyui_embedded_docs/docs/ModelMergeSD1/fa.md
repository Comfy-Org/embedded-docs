# ModelMergeSD1

گره ModelMergeSD1 دو مدل Stable Diffusion 1.x را با تنظیم میزان مشارکت هر مؤلفه مدل در نتیجه، با یکدیگر ترکیب می‌کند. این گره کنترل جداگانه‌ای بر روی جاسازی زمانی، جاسازی برچسب و هر بلوک ورودی، میانی و خروجی ارائه می‌دهد و امکان ادغام دقیق مدل را برای موارد استفاده خاص فراهم می‌کند.
