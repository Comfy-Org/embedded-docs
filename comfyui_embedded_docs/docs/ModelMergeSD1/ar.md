# دمج النموذج SD1

يتيح لك `ModelMergeSD1` دمج نموذجين من نماذج Stable Diffusion 1.x معًا عن طريق ضبط تأثير مكوناتهما الفردية. وهو يوفر وزن مزج منفصلًا لتضمين الوقت، وتضمين التسميات، وكل كتلة إدخال، وكل كتلة وسطى، وكل كتلة إخراج، وطبقة الإخراج النهائية، مما يتيح تحكمًا دقيقًا في كيفية دمج النموذجين.
