# Слияние моделей SD1

Узел ModelMergeSD1 смешивает две модели Stable Diffusion 1.x, регулируя вклад каждого компонента модели в результат. Он обеспечивает индивидуальное управление эмбеддингом времени, эмбеддингом меток, а также каждым входным, промежуточным и выходным блоком, что позволяет выполнять точную настройку слияния моделей для конкретных случаев использования.
