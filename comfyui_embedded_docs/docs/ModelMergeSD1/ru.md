# Слияние моделей SD1

ModelMergeSD1 позволяет смешивать две модели Stable Diffusion 1.x, регулируя влияние их отдельных компонентов. Он предоставляет отдельный вес смешивания для эмбеддинга времени, эмбеддинга меток, каждого входного блока, каждого среднего блока, каждого выходного блока и финального выходного слоя, что обеспечивает точный контроль над объединением двух моделей.
