# Load LoRA (Model)

Применяет стек LoRA к диффузионной модели в одном узле. Каждая строка `loras` содержит файл LoRA, его силу и переключатель вкл./выкл., а строки применяются сверху вниз, так что каждая строка патчит результат строки выше. Используйте этот узел вместо связывания нескольких отдельных загрузчиков LoRA в цепочку, когда рабочий процесс применяет длинный список LoRA к одной и той же модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будут применяться LoRA. | MODEL | Да | - |
| `loras` | Расширяемая группа LoRA, применяемых к модели в порядке строк (`loras.0`, `loras.1` и так далее). Добавьте по одной строке на каждый LoRA; каждая строка содержит файл, силу и переключатель вкл./выкл. | DYNAMIC_GROUP | Да | от 1 до 20 строк |

### Поля строки `loras`

Каждая строка повторяет следующие поля, и каждое поле обязательно в пределах отправленной строки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `lora_name` | Имя файла LoRA для применения. | COMBO | Да | Доступно несколько вариантов |
| `strength` | Насколько сильно применять этот LoRA. `0` отключает его, а отрицательное значение инвертирует эффект. (по умолчанию: 1.0) | FLOAT | Да | от -100 до 100 (шаг 0.01) |
| `enabled` | Выключите, чтобы пропустить этот LoRA без изменения его файла или силы. (по умолчанию: true) | BOOLEAN | Да | false / true |

### Ограничения параметров

- **Количество строк:** необходимо передать хотя бы одну строку, принимается не более 20 строк, поэтому максимальный индекс строки — 19.
- **Пропущенные строки:** строка пропускается, если её файл пуст, если `enabled` выключен или если `strength` равен `0`. Отрицательное значение `strength` передаётся, а не пропускается.
- **Порядок строк:** строки применяются в порядке их следования, и каждая строка начинает с модели, возвращённой предыдущей строкой.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Диффузионная модель со всеми применёнными включёнными строками LoRA. | MODEL |
