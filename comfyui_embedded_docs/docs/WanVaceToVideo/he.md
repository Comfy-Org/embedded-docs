# WanVaceToVideo

צומת WanVaceToVideo מכין נתוני קונדישנינג לווידאו עבור מודלים ליצירת וידאו מבוקרי VACE. הוא משלב קונדישנינג חיובי ושלילי עם וידאו בקרה אופציונלי, מסכות בקרה ותמונת עזר, מקודד אותם דרך VAE, ומוציא קונדישנינג מעודכן, טנסור לטנט ריק וערך קיצוץ.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט קונדישנינג חיובי להנחיית היצירה | CONDITIONING | כן | - |
| `negative` | קלט קונדישנינג שלילי להנחיית היצירה | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות ופריימים של וידאו | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר סרטוני הווידאו ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `strength` | עוצמת הקונדישנינג לבקרת VACE (ברירת מחדל: 1.0, צעד: 0.01). זו אינה עוצמת LoRA. משקלי LoRA מוחלים דרך צומתי LoRA נפרדים. | FLOAT | כן | 0.0 עד 1000.0 |
| `control_video` | וידאו קלט אופציונלי המשמש לקונדישנינג בקרה. אם לא מסופק, נוצר אוטומטית וידאו אפור ניטרלי. | IMAGE | לא | - |
| `control_masks` | מסכות אופציונליות שקובעות אילו חלקים של וידאו הבקרה פעילים. אם לא מסופקות, נעשה שימוש במסכה לבנה מלאה. | MASK | לא | - |
| `reference_image` | תמונת עזר אופציונלית לקונדישנינג נוסף. כאשר היא מסופקת, היא מקודדת ומתווספת לפני רצף הלטנט. נעשה שימוש בתמונה הראשונה בלבד. | IMAGE | לא | - |

**הערה:** כאשר `control_video` מסופק, הוא נחתך ל-`length` פריימים ומוגדל ל-`width` ול-`height` שצוינו; אם יש בו פחות פריימים מ-`length`, הפריימים החסרים מרופדים באפור ניטרלי (ערך 0.5). כאשר הוא לא מסופק, נוצר אוטומטית וידאו אפור ניטרלי של `length` פריימים. `control_masks` מוגדלות ל-`width` ול-`height` שצוינו, נחתכות ל-`length` פריימים, ומרופדות בערך 1.0 אם הן קצרות יותר. המסכה מפרידה את וידאו הבקרה לחלקים לא פעילים ופעילים, כל אחד מקודד ב-VAE ומשורשר לאורך מימד הערוצים; המסכה גם מוקטנת לרזולוציית הלטנט. כאשר `reference_image` מסופקת, התמונה הראשונה שלה מקודדת ב-VAE ומתווספת לפני רצף הלטנט, ו-`trim_latent` מדווח על מספר פריימי הלטנט שנוספו. מספר פריימי הלטנט מחושב כ-`((length - 1) // 4) + 1`, והממדים המרחביים של הלטנט הם `height / 8` ו-`width / 8`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | קונדישנינג חיובי עם נתוני בקרת וידאו (vace_frames, vace_mask, vace_strength) מוחלים | CONDITIONING |
| `negative` | קונדישנינג שלילי עם נתוני בקרת וידאו (vace_frames, vace_mask, vace_strength) מוחלים | CONDITIONING |
| `latent` | טנסור לטנט ריק המוכן ליצירת וידאו עם צורה [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | מספר פריימי הלטנט שיש לקצץ כאשר נעשה שימוש בתמונת עזר; 0 אם לא מסופקת תמונת עזר | INT |
