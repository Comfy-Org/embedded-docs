# WanVaceToVideo

گره WanVaceToVideo داده‌های شرطی‌سازی ویدیو را برای مدل‌های تولید ویدیو آماده می‌کند. این گره ورودی‌های شرطی‌سازی مثبت و منفی را به‌همراه ویدیوی کنترلی اختیاری، ماسک‌ها و تصویر مرجع دریافت کرده و آن‌ها را به نمایش‌های نهفته (latent) رمزگذاری می‌کند که تولید ویدیو را هدایت می‌کنند. این گره وظیفه افزایش مقیاس، padding، ماسک‌گذاری و رمزگذاری VAE را برای ساخت ساختار شرطی‌سازی مناسب برای مدل‌های ویدیویی بر عهده دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | ورودی شرطی‌سازی مثبت برای هدایت تولید | CONDITIONING | بله | - |
| `منفی` | ورودی شرطی‌سازی منفی برای هدایت تولید | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر و فریم‌های ویدیو | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `اندازه بچ` | تعداد ویدیوهایی که به‌طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `شدت` | شدت شرطی‌سازی برای کنترل VACE (پیش‌فرض: 1.0، گام: 0.01). این شدت LoRA نیست. وزن‌های LoRA از طریق گره‌های LoRA جداگانه اعمال می‌شوند. | FLOAT | بله | 0.0 تا 1000.0 |
| `ویدئوی کنترل` | ویدیوی ورودی اختیاری که برای شرطی‌سازی کنترلی استفاده می‌شود. اگر ارائه نشود، یک ویدیوی خاکستری خنثی به‌طور خودکار ساخته می‌شود. | IMAGE | خیر | - |
| `ماسک‌های کنترل` | ماسک‌های اختیاری که تعیین می‌کنند کدام بخش‌های ویدیوی کنترلی فعال هستند. اگر ارائه نشوند، یک ماسک تمام‌سفید استفاده می‌شود. | MASK | خیر | - |
| `تصویر مرجع` | تصویر مرجع اختیاری برای شرطی‌سازی اضافی. در صورت ارائه، رمزگذاری شده و به ابتدای دنباله نهفته اضافه می‌شود. | IMAGE | خیر | - |

**نکته:** هنگامی که `control_video` ارائه می‌شود، به تعداد فریم‌های `length` بریده شده و به `width` و `height` مشخص‌شده افزایش مقیاس می‌یابد؛ اگر تعداد فریم‌های آن کمتر از `length` باشد، فریم‌های از دست رفته با خاکستری خنثی (مقدار 0.5) پر می‌شوند. اگر ارائه نشود، یک ویدیوی خاکستری خنثی با `length` فریم به‌طور خودکار ساخته می‌شود. `control_masks` به `width` و `height` مشخص‌شده افزایش مقیاس یافته، به `length` فریم بریده می‌شوند و در صورت کوتاه‌تر بودن، با مقدار 1.0 پر می‌شوند. ماسک، ویدیوی کنترلی را به بخش‌های غیرفعال و واکنش‌پذیر جدا می‌کند که هر کدام به‌صورت جداگانه با VAE رمزگذاری و در امتداد بعد کانال به هم الحاق می‌شوند؛ همچنین ماسک به وضوح نهفته (latent resolution) کاهش مقیاس می‌یابد. وقتی `reference_image` ارائه شود، با VAE رمزگذاری شده و به ابتدای دنباله نهفته اضافه می‌شود. تعداد فریم‌های نهفته به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود و ابعاد فضایی نهفته برابر با `height / 8` و `width / 8` است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت با داده‌های کنترل ویدیو (vace_frames, vace_mask, vace_strength) اعمال‌شده | CONDITIONING |
| `منفی` | شرطی‌سازی منفی با داده‌های کنترل ویدیو (vace_frames, vace_mask, vace_strength) اعمال‌شده | CONDITIONING |
| `latent` | تانسور نهفته خالی آماده برای تولید ویدیو با شکل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | تعداد فریم‌های نهفته‌ای که هنگام استفاده از تصویر مرجع حذف می‌شوند؛ اگر تصویر مرجعی ارائه نشود، 0 | INT |
