# WanVaceToVideo

گره WanVaceToVideo داده‌های شرطی‌سازی ویدئو را برای مدل‌های تولید ویدئوی کنترل‌شده با VACE آماده می‌کند. این گره شرطی‌سازی مثبت و منفی را با یک ویدئوی کنترل اختیاری، ماسک‌های کنترل و یک تصویر مرجع ترکیب می‌کند، آن‌ها را از طریق یک VAE رمزگذاری می‌کند و شرطی‌سازی به‌روزرسانی‌شده، یک تنسور نهفته خالی و یک مقدار trim را خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت برای هدایت تولید | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی برای هدایت تولید | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر و فریم‌های ویدئو | VAE | بله | - |
| `width` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدئو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدئوهایی که هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `strength` | قدرت شرطی‌سازی برای کنترل VACE (پیش‌فرض: 1.0، گام: 0.01). این مقدار قدرت LoRA نیست. وزن‌های LoRA از طریق گره‌های جداگانه LoRA اعمال می‌شوند. | FLOAT | بله | 0.0 تا 1000.0 |
| `control_video` | ویدئوی ورودی اختیاری که برای شرطی‌سازی کنترل استفاده می‌شود. اگر ارائه نشود، یک ویدئوی خاکستری خنثی به‌طور خودکار ایجاد می‌شود. | IMAGE | خیر | - |
| `control_masks` | ماسک‌های اختیاری که تعیین می‌کنند کدام بخش‌های ویدئوی کنترل فعال هستند. اگر ارائه نشود، یک ماسک سفید کامل استفاده می‌شود. | MASK | خیر | - |
| `reference_image` | تصویر مرجع اختیاری برای شرطی‌سازی بیشتر. وقتی ارائه شود، رمزگذاری شده و به ابتدای توالی نهفته اضافه می‌شود. فقط اولین تصویر استفاده می‌شود. | IMAGE | خیر | - |

**توجه:** وقتی `control_video` ارائه شود، به `length` فریم برش داده می‌شود و به `width` و `height` مشخص‌شده بزرگ‌نمایی می‌شود؛ اگر تعداد فریم‌های آن کمتر از `length` باشد، فریم‌های گم‌شده با خاکستری خنثی (مقدار 0.5) پر می‌شوند. وقتی ارائه نشود، یک ویدئوی خاکستری خنثی با `length` فریم به‌طور خودکار ایجاد می‌شود. `control_masks` به `width` و `height` مشخص‌شده بزرگ‌نمایی می‌شوند، به `length` فریم برش داده می‌شوند و در صورت کوتاه‌تر بودن با مقدار 1.0 پر می‌شوند. ماسک ویدئوی کنترل را به بخش‌های غیرفعال و واکنشی تقسیم می‌کند؛ هر بخش با VAE رمزگذاری شده و در امتداد بعد کانال به هم متصل می‌شود؛ ماسک همچنین به تفکیک‌پذیری نهفته کاهش نمونه‌برداری می‌شود. وقتی `reference_image` ارائه شود، اولین تصویر آن با VAE رمزگذاری شده و به ابتدای توالی نهفته اضافه می‌شود، و `trim_latent` تعداد فریم‌های نهفته اضافه‌شده را گزارش می‌کند. تعداد فریم‌های نهفته به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود، و ابعاد مکانی نهفته `height / 8` و `width / 8` هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت با داده‌های کنترل ویدئو (vace_frames، vace_mask، vace_strength) اعمال‌شده | CONDITIONING |
| `negative` | شرطی‌سازی منفی با داده‌های کنترل ویدئو (vace_frames، vace_mask، vace_strength) اعمال‌شده | CONDITIONING |
| `latent` | تنسور نهفته خالی آماده برای تولید ویدئو با شکل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | تعداد فریم‌های نهفته‌ای که هنگام استفاده از تصویر مرجع باید برش داده شوند؛ اگر تصویر مرجعی ارائه نشود، 0 | INT |
