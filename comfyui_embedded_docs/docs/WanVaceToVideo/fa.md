# WanVaceToVideo

گره WanVaceToVideo داده‌های شرطی‌سازی ویدیو را برای مدل‌های تولید ویدیو پردازش می‌کند. این گره ورودی‌های شرطی‌سازی مثبت و منفی را به همراه داده‌های کنترل ویدیو دریافت می‌کند و نمایش‌های لاتنت را برای تولید ویدیو آماده می‌سازد. این گره تغییر اندازه ویدیو، ماسک‌گذاری و کدگذاری VAE را انجام می‌دهد تا ساختار شرطی‌سازی مناسب برای مدل‌های ویدیویی ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبت برای هدایت تولید | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی برای هدایت تولید | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای کدگذاری تصاویر و فریم‌های ویدیو | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به طور همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `strength` | قدرت شرطی برای کنترل VACE (پیش‌فرض: 1.0، گام: 0.01). این مقدار قدرت LoRA نیست. وزن‌های LoRA از طریق گره‌های LoRA جداگانه اعمال می‌شوند. | FLOAT | بله | 0.0 تا 1000.0 |
| `control_video` | ویدیوی ورودی اختیاری برای شرطی‌سازی کنترل. اگر ارائه نشود، یک ویدیوی خاکستری خنثی به صورت خودکار ساخته می‌شود. در صورت ارائه، به ابعاد `width` × `height` تغییر اندازه داده می‌شود و به اولین `length` فریم محدود می‌شود؛ اگر فریم‌های کمتری داشته باشد، فریم‌های از دست رفته با خاکستری خنثی پر می‌شوند. | IMAGE | خیر | - |
| `control_masks` | ماسک‌های اختیاری برای کنترل بخش‌هایی از ویدیو که باید تغییر کنند. اگر ارائه نشود، یک ماسک تمام‌سفید استفاده می‌شود. در صورت ارائه، ماسک به ابعاد `width` × `height` تغییر اندازه داده می‌شود، به `length` فریم محدود می‌شود و در صورت داشتن فریم‌های کمتر، با سفید پر می‌شود. | MASK | خیر | - |
| `reference_image` | تصویر مرجع اختیاری برای شرطی‌سازی اضافی. در صورت ارائه، به ابعاد `width` × `height` تغییر اندازه داده می‌شود، توسط VAE کدگذاری می‌شود و به ابتدای توالی لاتنت اضافه می‌شود. | IMAGE | خیر | - |

**نکته:** وقتی `control_video` ارائه می‌شود، به `width` و `height` مشخص‌شده تغییر اندازه می‌یابد. اگر `control_masks` ارائه شوند، آن‌ها نیز به همان ابعاد تغییر اندازه می‌یابند. `reference_image` در صورت ارائه از طریق VAE کدگذاری شده و به ابتدای توالی لاتنت اضافه می‌شود. پارامتر `length` تعداد فریم‌ها را تعیین می‌کند و طول لاتنت به صورت `((length - 1) // 4) + 1` محاسبه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت با داده‌های کنترل ویدیو (vace_frames، vace_mask، vace_strength) اعمال‌شده | CONDITIONING |
| `negative` | شرطی‌سازی منفی با داده‌های کنترل ویدیو (vace_frames، vace_mask، vace_strength) اعمال‌شده | CONDITIONING |
| `latent` | تانسور لاتنت خالی آماده برای تولید ویدیو با شکل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | تعداد فریم‌های لاتنت که هنگام استفاده از تصویر مرجع باید بریده شوند (در صورت عدم ارائه تصویر مرجع، 0) | INT |
