# وان Vace إلى فيديو

تُهيّئ عقدة WanVaceToVideo بيانات تكييف الفيديو لنماذج توليد الفيديو الخاضعة لتحكم VACE. وهي تدمج التكييف الإيجابي والسلبي مع فيديو تحكم اختياري، وأقنعة تحكم، وصورة مرجعية، وتُرمّزها عبر VAE، ثم تُخرج تكييفًا محدّثًا، وموتر latent فارغًا، وقيمة اقتطاع.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل التكييف الإيجابي لتوجيه التوليد | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السلبي لتوجيه التوليد | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور وإطارات الفيديو | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الطول` | عدد الإطارات في الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `حجم الدفعة` | عدد مقاطع الفيديو المراد توليدها في آنٍ واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `القوة` | قوة التكييف لتحكم VACE (الافتراضي: 1.0، الخطوة: 0.01). هذه ليست قوة LoRA. تُطبَّق أوزان LoRA عبر عُقد LoRA منفصلة. | FLOAT | نعم | 0.0 إلى 1000.0 |
| `فيديو التحكم` | فيديو إدخال اختياري يُستخدم لتكييف التحكم. إذا لم يُقدَّم، يُنشأ فيديو رمادي محايد تلقائيًا. | IMAGE | لا | - |
| `أقنعة التحكم` | أقنعة اختيارية تحدّد أجزاء فيديو التحكم النشطة. إذا لم تُقدَّم، يُستخدم قناع أبيض كامل. | MASK | لا | - |
| `صورة مرجعية` | صورة مرجعية اختيارية لتكييف إضافي. عند تقديمها، تُرمَّز وتُضاف في مقدمة تسلسل latent. تُستخدم الصورة الأولى فقط. | IMAGE | لا | - |

**ملاحظة:** عند تقديم `control_video`، يتم اقتطاعه إلى `length` إطارًا وتكبيره إلى `width` و`height` المحددين؛ وإذا كان يحتوي على إطارات أقل من `length`، تُحشى الإطارات الناقصة بالرمادي المحايد (القيمة 0.5). وعند عدم تقديمه، يُنشأ تلقائيًا فيديو رمادي محايد بعدد `length` من الإطارات. يتم تكبير `control_masks` إلى `width` و`height` المحددين، واقتطاعها إلى `length` إطارًا، وحشوها بالقيمة 1.0 إذا كانت أقصر. يفصل القناع فيديو التحكم إلى أجزاء غير نشطة وأجزاء متفاعلة، ويُرمَّز كل منها عبر VAE ويُدمج مع الآخر على بُعد القنوات؛ كما يتم تصغير القناع إلى دقة latent. عند تقديم `reference_image`، تُرمَّز صورته الأولى عبر VAE وتُضاف في مقدمة تسلسل latent، ويُبلّغ `trim_latent` عن عدد إطارات latent المُضافة. يُحسب عدد إطارات latent كـ `((length - 1) // 4) + 1`، وتكون الأبعاد المكانية لـ latent هي `height / 8` و`width / 8`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي مع تطبيق بيانات التحكم بالفيديو (vace_frames، vace_mask، vace_strength) | CONDITIONING |
| `negative` | تكييف سلبي مع تطبيق بيانات التحكم بالفيديو (vace_frames، vace_mask، vace_strength) | CONDITIONING |
| `latent` | موتر latent فارغ جاهز لتوليد الفيديو بالشكل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | عدد إطارات latent المراد اقتطاعها عند استخدام صورة مرجعية؛ 0 إذا لم تُقدَّم صورة مرجعية | INT |
