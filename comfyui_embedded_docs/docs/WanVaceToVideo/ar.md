# وان Vace إلى فيديو

تعالج عقدة WanVaceToVideo بيانات تهيئة الفيديو لنماذج توليد الفيديو. تأخذ مدخلات التهيئة الإيجابية والسلبية بالإضافة إلى بيانات التحكم في الفيديو وتُحضّر التمثيلات الكامنة (latent) لتوليد الفيديو. تعالج العقدة رفع دقة الفيديو، والأقنعة، وترميز VAE لإنشاء بنية التهيئة المناسبة لنماذج الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مدخل التهيئة الإيجابي لتوجيه عملية التوليد | CONDITIONING | نعم | - |
| `negative` | مدخل التهيئة السلبي لتوجيه عملية التوليد | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور وإطارات الفيديو | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات التي سيتم توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 to 4096 |
| `strength` | قوة التهيئة للتحكم في VACE (الافتراضي: 1.0، الخطوة: 0.01). هذه ليست قوة LoRA. يتم تطبيق أوزان LoRA عبر عقد LoRA منفصلة. | FLOAT | نعم | 0.0 to 1000.0 |
| `control_video` | فيديو إدخال اختياري للتهيئة التحكمية. إذا لم يتم توفيره، يتم إنشاء فيديو رمادي محايد تلقائيًا. عند توفيره، يتم رفع دقته إلى `width` × `height` ويُقتصر على أول `length` إطارًا؛ إذا كان يحتوي على إطارات أقل، يتم ملء الإطارات المفقودة بالرمادي المحايد. | IMAGE | لا | - |
| `control_masks` | أقنعة اختيارية للتحكم في أجزاء الفيديو التي سيتم تعديلها. إذا لم يتم توفيرها، يُستخدم قناع أبيض كامل. عند توفيرها، يتم رفع دقة القناع إلى `width` × `height`، ويُقتصر على `length` إطارًا، ويُملأ باللون الأبيض إذا كان يحتوي على إطارات أقل. | MASK | لا | - |
| `reference_image` | صورة مرجعية اختيارية لتهيئة إضافية. عند توفيرها، يتم رفع دقتها إلى `width` × `height`، وترميزها بواسطة VAE، وإضافتها إلى بداية تسلسل التمثيل الكامن (latent). | IMAGE | لا | - |

**ملاحظة:** عند توفير `control_video`، يتم رفع دقته إلى `width` و `height` المحددين. إذا تم توفير `control_masks`، يتم رفع دقتها لمطابقة الأبعاد نفسها. يتم ترميز `reference_image` عبر VAE وإضافتها إلى بداية تسلسل التمثيل الكامن عند توفيرها. تحدد المعلمة `length` عدد الإطارات، ويُحسب طول التمثيل الكامن على النحو التالي: `((length - 1) // 4) + 1`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تهيئة إيجابية مطبقة مع بيانات التحكم في الفيديو (vace_frames، vace_mask، vace_strength) | CONDITIONING |
| `negative` | تهيئة سلبية مطبقة مع بيانات التحكم في الفيديو (vace_frames، vace_mask، vace_strength) | CONDITIONING |
| `latent` | موتر كامن فارغ جاهز لتوليد الفيديو بالشكل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | عدد إطارات التمثيل الكامن التي يجب قصها عند استخدام صورة مرجعية (0 إذا لم يتم توفير صورة مرجعية) | INT |
