# وان Vace إلى فيديو

تُعد عقدة WanVaceToVideo بيانات تكييف الفيديو لنماذج توليد الفيديو. تأخذ مدخلات التكييف الإيجابية والسلبية بالإضافة إلى فيديو تحكم اختياري، وأقنعة، وصورة مرجعية، وتقوم بترميزها إلى تمثيلات كامنة لتوجيه توليد الفيديو. تتعامل العقدة مع رفع الدقة، والحشو، والأقنعة، وترميز VAE لبناء بنية التكييف المناسبة لنماذج الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل التكييف الإيجابي لتوجيه التوليد | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السلبي لتوجيه التوليد | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور وإطارات الفيديو | VAE | نعم | - |
| `العرض` | عرض فيديو الإخراج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع فيديو الإخراج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | عدد إطارات الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم الدفعة` | عدد الفيديوهات المراد توليدها في وقت واحد (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `القوة` | قوة التكييف للتحكم في VACE (الافتراضي: 1.0، الخطوة: 0.01). هذه ليست قوة LoRA. يتم تطبيق أوزان LoRA من خلال عُقد LoRA منفصلة. | FLOAT | نعم | 0.0 إلى 1000.0 |
| `فيديو التحكم` | فيديو إدخال اختياري يُستخدم للتكييف بالتحكم. إذا لم يتم توفيره، يتم إنشاء فيديو رمادي محايد تلقائيًا. | IMAGE | لا | - |
| `أقنعة التحكم` | أقنعة اختيارية تحدد أجزاء فيديو التحكم النشطة. إذا لم يتم توفيرها، يتم استخدام قناع أبيض كامل. | MASK | لا | - |
| `صورة مرجعية` | صورة مرجعية اختيارية لتكييف إضافي. عند توفيرها، يتم ترميزها وإضافتها في بداية التسلسل الكامن. | IMAGE | لا | - |

**ملاحظة:** عند توفير `control_video`، يتم اقتطاعه إلى `length` إطارًا ورفع دقته إلى `width` و `height` المحددين؛ إذا كان يحتوي على إطارات أقل من `length`، يتم حشو الإطارات المفقودة بالرمادي المحايد (القيمة 0.5). عندما لا يتم توفيره، يتم إنشاء فيديو رمادي محايد بعدد إطارات `length` تلقائيًا. يتم رفع دقة `control_masks` إلى `width` و `height` المحددين، واقتطاعها إلى `length` إطارًا، وحشوها بالقيمة 1.0 إذا كانت أقصر. يفصل القناع فيديو التحكم إلى أجزاء غير نشطة ومتفاعلة، ويتم ترميز كل منهما بواسطة VAE وربطهما على طول بُعد القنوات؛ كما يتم تقليل دقة القناع إلى دقة التسلسل الكامن. عند توفير `reference_image`، يتم ترميزه بواسطة VAE وإضافته في بداية التسلسل الكامن. يتم حساب عدد الإطارات الكامنة بالمعادلة `((length - 1) // 4) + 1`، والأبعاد المكانية الكامنة هي `height / 8` و `width / 8`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | تكييف إيجابي مع بيانات التحكم بالفيديو (vace_frames, vace_mask, vace_strength) المطبقة | CONDITIONING |
| `سلبي` | تكييف سلبي مع بيانات التحكم بالفيديو (vace_frames, vace_mask, vace_strength) المطبقة | CONDITIONING |
| `مضمر` | موتر كامن فارغ جاهز لتوليد الفيديو بالشكل [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `اقتطاع المضمر` | عدد الإطارات الكامنة التي يجب قصّها عند استخدام صورة مرجعية؛ 0 إذا لم يتم توفير صورة مرجعية | INT |
