# WanVaceToVideo

Узел WanVaceToVideo подготавливает данные кондиционирования видео для моделей генерации видео. Он принимает положительные и отрицательные входы кондиционирования, а также необязательные управляющее видео, маски и эталонное изображение, и кодирует их в скрытые представления, которые направляют генерацию видео. Узел выполняет масштабирование, дополнение, маскирование и VAE-кодирование для создания соответствующей структуры кондиционирования для видеомоделей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Вход положительного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `негативный` | Вход отрицательного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `интенсивность` | Сила условия для управления VACE (по умолчанию: 1.0, шаг: 0.01). Это не сила LoRA. Веса LoRA применяются через отдельные узлы LoRA. | FLOAT | Да | от 0.0 до 1000.0 |
| `control_video` | Необязательное входное видео, используемое для управляющего кондиционирования. Если не указано, автоматически создается нейтральное серое видео. | IMAGE | Нет | - |
| `control_masks` | Необязательные маски, определяющие, какие части управляющего видео активны. Если не указано, используется полностью белая маска. | MASK | Нет | - |
| `референсное_изображение` | Необязательное эталонное изображение для дополнительного кондиционирования. При наличии кодируется и добавляется в начало последовательности скрытых представлений. | IMAGE | Нет | - |

**Примечание:** Когда `control_video` указано, оно обрезается до `length` кадров и масштабируется до указанных `width` и `height`; если в нем меньше кадров, чем `length`, недостающие кадры дополняются нейтральным серым (значение 0.5). Если оно не указано, автоматически создается нейтральное серое видео из `length` кадров. `control_masks` масштабируются до указанных `width` и `height`, обрезаются до `length` кадров и дополняются значением 1.0, если они короче. Маска разделяет управляющее видео на неактивные и реактивные части, каждая из которых кодируется VAE и объединяется по размерности каналов; маска также уменьшается до разрешения скрытого представления. Когда указано `reference_image`, оно кодируется VAE и добавляется в начало последовательности скрытых представлений. Количество скрытых кадров вычисляется как `((length - 1) // 4) + 1`, а пространственные размеры скрытого представления равны `height / 8` и `width / 8`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Положительное кондиционирование с примененными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `негативный` | Отрицательное кондиционирование с примененными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `latent` | Пустой тензор скрытого представления, готовый для генерации видео, с формой [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `обрезанный_latent` | Количество скрытых кадров, которые нужно обрезать при использовании эталонного изображения; 0, если эталонное изображение не указано | INT |
