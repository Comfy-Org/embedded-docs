# WanVaceToVideo

Узел WanVaceToVideo обрабатывает данные кондиционирования видео для моделей генерации видео. Он принимает положительные и отрицательные входы кондиционирования вместе с данными управления видео и подготавливает латентные представления для генерации видео. Узел выполняет масштабирование видео, создание масок и VAE-кодирование для формирования соответствующей структуры кондиционирования для видеомоделей.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование для направления генерации | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование для направления генерации | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `length` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `batch_size` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `strength` | Сила условия для управления VACE (по умолчанию: 1.0, шаг: 0.01). Это не сила LoRA. Веса LoRA применяются через отдельные узлы LoRA. | FLOAT | Да | от 0.0 до 1000.0 |
| `control_video` | Необязательное входное видео для управляющего кондиционирования. Если не указано, автоматически создается нейтральное серое видео. При наличии оно масштабируется до `width` × `height` и ограничивается первыми `length` кадрами; если кадров меньше, недостающие кадры заполняются нейтральным серым. | IMAGE | Нет | - |
| `control_masks` | Необязательные маски для управления тем, какие части видео изменять. Если не указаны, используется полностью белая маска. При наличии маска масштабируется до `width` × `height`, ограничивается `length` кадрами и дополняется белым, если кадров меньше. | MASK | Нет | - |
| `reference_image` | Необязательное референсное изображение для дополнительного кондиционирования. При наличии оно масштабируется до `width` × `height`, кодируется с помощью VAE и добавляется в начало последовательности латентных векторов. | IMAGE | Нет | - |

**Примечание:** Если указан `control_video`, он масштабируется до указанных `width` и `height`. Если указаны `control_masks`, они масштабируются до тех же размеров. `reference_image` кодируется через VAE и добавляется в начало последовательности латентных векторов при его наличии. Параметр `length` определяет количество кадров, а длина латентной последовательности вычисляется как `((length - 1) // 4) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование с примененными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `negative` | Отрицательное кондиционирование с примененными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `latent` | Пустой латентный тензор, готовый для генерации видео, с формой [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | Количество латентных кадров для обрезки при использовании референсного изображения (0, если референсное изображение не предоставлено) | INT |
