# WanVaceToVideo

Узел WanVaceToVideo подготавливает данные кондиционирования видео для моделей генерации видео с управлением VACE. Он объединяет положительное и отрицательное кондиционирование с необязательным управляющим видео, управляющими масками и эталонным изображением, кодирует их через VAE и выводит обновлённое кондиционирование, пустой латентный тензор и значение обрезки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Вход положительного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `негативный` | Вход отрицательного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `интенсивность` | Сила кондиционирования для управления VACE (по умолчанию: 1.0, шаг: 0.01). Это не сила LoRA. Веса LoRA применяются через отдельные узлы LoRA. | FLOAT | Да | от 0.0 до 1000.0 |
| `control_video` | Необязательное входное видео, используемое для управляющего кондиционирования. Если оно не предоставлено, автоматически создаётся нейтральное серое видео. | IMAGE | Нет | - |
| `control_masks` | Необязательные маски, определяющие, какие части управляющего видео активны. Если они не предоставлены, используется полностью белая маска. | MASK | Нет | - |
| `референсное_изображение` | Необязательное эталонное изображение для дополнительного кондиционирования. Если оно предоставлено, оно кодируется и добавляется перед латентной последовательностью. Используется только первое изображение. | IMAGE | Нет | - |

**Примечание:** Когда указан `control_video`, он обрезается до `length` кадров и масштабируется до указанных `width` и `height`; если в нём меньше кадров, чем `length`, недостающие кадры дополняются нейтральным серым (значение 0.5). Если он не указан, автоматически создаётся нейтральное серое видео из `length` кадров. `control_masks` масштабируются до указанных `width` и `height`, обрезаются до `length` кадров и дополняются значением 1.0, если они короче. Маска разделяет управляющее видео на неактивную и реактивную части, каждая из которых кодируется через VAE и объединяется по размерности каналов; маска также понижается до латентного разрешения. Когда указан `reference_image`, его первое изображение кодируется через VAE и добавляется перед латентной последовательностью, а `trim_latent` сообщает количество добавленных латентных кадров. Количество латентных кадров вычисляется как `((length - 1) // 4) + 1`, а пространственные размеры латента — `height / 8` и `width / 8`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование с применёнными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `negative` | Отрицательное кондиционирование с применёнными данными управления видео (vace_frames, vace_mask, vace_strength) | CONDITIONING |
| `latent` | Пустой латентный тензор, готовый для генерации видео, с формой [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | Количество латентных кадров для обрезки при использовании эталонного изображения; 0, если эталонное изображение не предоставлено | INT |
