# UNetCrossAttentionMultiply

הצומת UNetCrossAttentionMultiply מחיל גורמי כפל על מנגנון הקשב הצולב (cross-attention) במודל UNet. הוא מאפשר לכוונן את רכיבי השאילתה (query), המפתח (key), הערך (value) והפלט (output) של שכבות הקשב הצולב, כדי להתנסות בהתנהגויות ואפקטים שונים של קשב.
