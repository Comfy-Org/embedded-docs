# WanSCAILToVideo

Узел WanSCAILToVideo подготавливает conditioning и пустое скрытое пространство (latent) для генерации видео с помощью моделей SCAIL и SCAIL-2. Он обрабатывает необязательные входные данные, такие как эталонные изображения, видео для позы, выходные данные CLIP vision, цветные маски идентичности и фрагменты предыдущих кадров, внедряя их в позитивный и негативный conditioning. Узел возвращает модифицированный conditioning и пустой латентный тензор заданных размеров видео, готовый к сэмплированию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `позитивный` | Входной позитивный conditioning. | CONDITIONING | Да | - |
| `негативный` | Входной негативный conditioning. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров. | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 512). Значения изменяются с шагом 32. | INT | Да | 32 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 896). Значения изменяются с шагом 32. | INT | Да | 32 to MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81). Значения изменяются с шагом 4. | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых за один батч (по умолчанию: 1). | INT | Да | 1 до 4096 |
| `видео_позы` | Видео, используемое для conditioning по позе. Будет уменьшено до половины разрешения основного видео. | IMAGE | Нет | - |
| `pose_video_mask` | Только для SCAIL-2. Цветное видео масок SAM3 для каждой идентичности, с тем же разрешением, что и `pose_video`. | IMAGE | Нет | - |
| `replacement_mode` | Только для SCAIL-2. False = режим анимации (`pose_video_mask` должен иметь чёрный фон). True = режим замены (`pose_video_mask` должен иметь белый фон). (по умолчанию: False) | BOOLEAN | Нет | - |
| `сила_позы` | Сила латентного представления позы. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 10.0 |
| `начало_позы` | Начальный шаг conditioning по позе. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 |
| `конец_позы` | Конечный шаг conditioning по позе. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 |
| `референсное_изображение` | Эталонное изображение. Первое изображение является основным эталоном (на него компонуются все идентичности). SCAIL-2: дополнительные изображения батча используются как дополнительные ракурсы (вид сзади, крупный план, перекрытый фон), каждому требуется соответствующая `reference_image_mask` в цвете этой идентичности. | IMAGE | Нет | - |
| `reference_image_mask` | Только для SCAIL-2. Цветная эталонная маска, по батчу соответствующая `reference_image` (первая — маска основного эталона, остальные — маски идентичностей для дополнительных `reference_image`). | IMAGE | Нет | - |
| `clip_vision_output` | Признаки CLIP vision для conditioning. Модель обучена с растягивающим масштабированием до соотношения сторон. | CLIP_VISION_OUTPUT | Нет | - |
| `video_frame_offset` | Суммарный выходной кадр, с которого начинается этот фрагмент. Подключите от выхода `video_frame_offset` предыдущего фрагмента. (по умолчанию: 0) | INT | Да | 0 to MAX_RESOLUTION |
| `previous_frame_count` | Конечные кадры из `previous_frames`, используемые как якорь. SCAIL-2 обучена на значении 5 (фрагменты по 81 кадру, шаг 76 кадров). (по умолчанию: 5) | INT | Да | 1 to MAX_RESOLUTION |
| `previous_frames` | Только для SCAIL-2. Полный декодированный результат предыдущего фрагмента. Только последние `previous_frame_count` кадров используются как якорь продолжения. | IMAGE | Нет | - |

**Примечание:** Входы `pose_video` и `pose_video_mask` обрезаются вместе до длины более короткого из них и обрабатываются только для первых `length` кадров. Если любой из входов короче `video_frame_offset` или равен ему, он игнорируется полностью. `pose_video` уменьшается до половины разрешения основного видео перед кодированием, а закодированное латентное представление позы умножается на `pose_strength` и применяется к conditioning только между шагами `pose_start` и `pose_end`. Если предоставлен `pose_video_mask`, цветное видео масок уменьшается до половины разрешения и преобразуется в 28-канальную управляющую маску, которая добавляется и в позитивный, и в негативный conditioning.

**Примечание:** Когда предоставлено `reference_image`, каждое изображение в батче кодируется индивидуально в латентное представление и внедряется в позитивный и негативный conditioning. Первое изображение является основным эталоном; дополнительные изображения используются как дополнительные ракурсы, каждому требуется соответствующая `reference_image_mask`. `reference_image_mask` используется только тогда, когда также предоставлено `reference_image`; когда заданы оба, из масок также строится 28-канальная эталонная маска, которая связывает эталонные кадры с идентичностями, и добавляется в conditioning. В режиме замены (`replacement_mode=True`) эталонное изображение компонуется на чёрном фоне с использованием маски эталонного изображения в качестве альфа-канала. Когда предоставлен `clip_vision_output`, он применяется и к позитивному, и к негативному conditioning.

**Примечание:** Когда предоставлены `previous_frames`, только последние `previous_frame_count` кадров используются как якорь продолжения, и `video_frame_offset` соответствующим образом корректируется (уменьшается на количество закреплённых кадров, с ограничением не ниже 0). Закреплённые кадры кодируются и записываются в начало выходного латентного представления, а также включается маска шума, чтобы эти кадры оставались неизменными во время генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `позитивный` | Модифицированный позитивный conditioning, который может содержать внедрённые латентные представления эталонных изображений, выход CLIP vision, латентные представления видео позы, управляющие маски, эталонные маски или латентные представления предыдущих кадров. | CONDITIONING |
| `негативный` | Модифицированный негативный conditioning, который может содержать внедрённые латентные представления эталонных изображений, выход CLIP vision, латентные представления видео позы, управляющие маски, эталонные маски или латентные представления предыдущих кадров. | CONDITIONING |
| `латентный` | Пустой латентный тензор формы `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. Когда предоставлены `previous_frames`, латентное представление частично заполняется закодированными предыдущими кадрами, и включается маска шума. | LATENT |
| `video_frame_offset` | Скорректированный offset + length. Подключите к следующему фрагменту для последовательной генерации видео. | INT |
