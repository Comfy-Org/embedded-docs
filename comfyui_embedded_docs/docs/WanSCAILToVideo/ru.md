# WanSCAILToVideo

Узел WanSCAILToVideo подготавливает кондиционирование и пустое латентное пространство для генерации видео с видеомоделями SCAIL и SCAIL-2. Он обрабатывает необязательные входы, такие как эталонные изображения, видео с позами, выходы CLIP vision, цветные маски идентичностей и фрагменты предыдущих кадров, встраивая их в позитивное и негативное кондиционирование. Узел выводит модифицированное кондиционирование и пустой латентный тензор указанных размеров видео, готовый для сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `позитивный` | Вход позитивного кондиционирования. | CONDITIONING | Да | - |
| `негативный` | Вход негативного кондиционирования. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров. | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 512). Значения изменяются с шагом 32. | INT | Да | 32 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 896). Значения изменяются с шагом 32. | INT | Да | 32 до MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81). Значения изменяются с шагом 4. | INT | Да | 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео для генерации в пакете (по умолчанию: 1). | INT | Да | 1 до 4096 |
| `видео_позы` | Видео, используемое для кондиционирования позы. Будет уменьшено до половины разрешения основного видео. | IMAGE | Нет | - |
| `pose_video_mask` | Только для SCAIL-2. Цветное видео-маска SAM3 по идентичностям с тем же разрешением, что и pose_video. | IMAGE | Нет | - |
| `replacement_mode` | Только для SCAIL-2. False = режим анимации (pose_video_mask должен иметь чёрный фон). True = режим замены (pose_video_mask должен иметь белый фон). (по умолчанию: False) | BOOLEAN | Нет | - |
| `сила_позы` | Сила латента позы. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 10.0 |
| `начало_позы` | Начальный шаг кондиционирования позы. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 |
| `конец_позы` | Конечный шаг кондиционирования позы. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 |
| `референсное_изображение` | Эталонное изображение. Первое изображение — основной эталон (на него компонуются все идентичности). SCAIL-2: дополнительные изображения пакета используются как дополнительные виды (вид сзади, крупный план, перекрытый фон), каждому из которых нужна соответствующая reference_image_mask в цвете этой идентичности. | IMAGE | Нет | - |
| `reference_image_mask` | Только для SCAIL-2. Цветная эталонная маска, пакет соответствует reference_image (первая = маска основного эталона, остальные = маски идентичностей для дополнительных reference_image). | IMAGE | Нет | - |
| `clip_vision_output` | Признаки CLIP vision для кондиционирования. Модель обучена с растягивающим изменением размера до соотношения сторон. | CLIP_VISION_OUTPUT | Нет | - |
| `video_frame_offset` | Совокупный выходной кадр, с которого начинается этот фрагмент. Подключите к выходу `video_frame_offset` предыдущего фрагмента. (по умолчанию: 0) | INT | Да | 0 до MAX_RESOLUTION |
| `previous_frame_count` | Хвостовые кадры из `previous_frames` для привязки. SCAIL-2 обучена на 5 (фрагменты по 81 кадру, шаг 76 кадров). (по умолчанию: 5). Значения изменяются с шагом 4. | INT | Да | 1 до MAX_RESOLUTION |
| `previous_frames` | Только для SCAIL-2. Полный декодированный выход предыдущего фрагмента. Только последние `previous_frame_count` кадров используются как якорь расширения. | IMAGE | Нет | - |

**Примечание:** Входы `pose_video` и `pose_video_mask` обрезаются совместно до длины более короткого из двух и обрабатываются только для первых `length` кадров. Если любой из входов короче или равен `video_frame_offset`, он полностью игнорируется. `pose_video` масштабируется вниз до половины разрешения основного видео перед кодированием, а закодированный латент позы умножается на `pose_strength` и применяется к кондиционированию только между шагами `pose_start` и `pose_end`. Если `pose_video_mask` предоставлен, цветное видео-маска масштабируется вниз до половинного разрешения и преобразуется в 28-канальную управляющую маску, которая добавляется как к позитивному, так и к негативному кондиционированию.

**Примечание:** Когда предоставлен `reference_image`, каждое изображение в пакете кодируется отдельно в латент и встраивается как в позитивное, так и в негативное кондиционирование. Первое изображение — основной эталон; дополнительные изображения используются как дополнительные виды, каждому из которых нужна соответствующая `reference_image_mask`. `reference_image_mask` используется только когда также предоставлен `reference_image`; когда заданы оба, из масок также строится 28-канальная эталонная маска, которая связывает эталонные кадры с идентичностями, и добавляется к кондиционированию. В режиме замены (`replacement_mode=True`) эталонное изображение компонуется на чёрном фоне с использованием эталонной маски изображения в качестве альфа-маски. Когда предоставлен `clip_vision_output`, он применяется как к позитивному, так и к негативному кондиционированию.

**Примечание:** Когда предоставлен `previous_frames`, используются только последние `previous_frame_count` кадров как якорь расширения, а `video_frame_offset` корректируется соответственно (уменьшается на количество привязанных кадров, с ограничением не ниже 0). Привязанные кадры кодируются и записываются в начало выходного латента, а также включается маска шума, чтобы эти кадры оставались неизменными во время генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Модифицированное позитивное кондиционирование, потенциально содержащее встроенные латенты эталонных изображений, выход CLIP vision, латенты видео позы, управляющие маски, эталонные маски или латенты предыдущих кадров. | CONDITIONING |
| `negative` | Модифицированное негативное кондиционирование, потенциально содержащее встроенные латенты эталонных изображений, выход CLIP vision, латенты видео позы, управляющие маски, эталонные маски или латенты предыдущих кадров. | CONDITIONING |
| `latent` | Пустой латентный тензор формы `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. Когда предоставлен `previous_frames`, латент частично заполняется закодированными предыдущими кадрами и включается маска шума. | LATENT |
| `video_frame_offset` | Скорректированное смещение + длина. Подключите к следующему фрагменту для последовательной генерации видео. | INT |
