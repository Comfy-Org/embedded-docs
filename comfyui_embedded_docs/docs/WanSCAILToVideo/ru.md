# WanSCAILToVideo

Узел WanSCAILToVideo подготавливает кондиционирование и пустое латентное пространство для генерации видео. Он обрабатывает необязательные входные данные, такие как референсные изображения, видео с позами, выходы CLIP vision и фрагменты предыдущих кадров, встраивая их в позитивное и негативное кондиционирование для видеомодели. Узел выводит модифицированное кондиционирование и пустой латентный тензор указанных размеров видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Входное позитивное кондиционирование. | CONDITIONING | Да | - |
| `negative` | Входное негативное кондиционирование. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений и видеокадров. | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 512). Настраивается с шагом 32. | INT | Да | от 32 до MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 896). Настраивается с шагом 32. | INT | Да | от 32 до MAX_RESOLUTION |
| `length` | Количество кадров в видео (по умолчанию: 81). Настраивается с шагом 4, начиная с 1. | INT | Да | от 1 до MAX_RESOLUTION |
| `batch_size` | Количество видео для генерации в одном пакете (по умолчанию: 1). | INT | Да | от 1 до 4096 |
| `pose_strength` | Сила латентного представления позы (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 10.0 |
| `pose_start` | Начальный шаг кондиционирования по позе (по умолчанию: 0.0). | FLOAT | Да | от 0.0 до 1.0 |
| `pose_end` | Конечный шаг кондиционирования по позе (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 1.0 |
| `video_frame_offset` | Совокупный выходной кадр, с которого начинается этот фрагмент. Подаётся с выхода `video_frame_offset` предыдущего фрагмента (по умолчанию: 0). | INT | Да | от 0 до MAX_RESOLUTION |
| `previous_frame_count` | Хвостовые кадры из `previous_frames` для привязки. SCAIL-2 обучена на значении 5 (фрагменты по 81 кадру, шаг 76 кадров) (по умолчанию: 5). | INT | Да | от 1 до MAX_RESOLUTION |
| `pose_video` | Видео, используемое для кондиционирования по позе. Будет уменьшено до половины разрешения основного видео. | IMAGE | Нет | - |
| `pose_video_mask` | Только для SCAIL-2. Цветное видео масок SAM3 по идентичностям с тем же разрешением, что и `pose_video`. | IMAGE | Нет | - |
| `replacement_mode` | Только для SCAIL-2. False = режим анимации (`pose_video_mask` должен иметь чёрный фон). True = режим замены (`pose_video_mask` должен иметь белый фон). По умолчанию: False. | BOOLEAN | Нет | - |
| `reference_image` | Референсное изображение. Первое изображение является основным референсом (на него компонуются все идентичности). SCAIL-2: дополнительные изображения в пакете используются как дополнительные ракурсы (вид сзади, крупный план, перекрытый фон); для каждого требуется соответствующая `reference_image_mask` в цвете этой идентичности. | IMAGE | Нет | - |
| `reference_image_mask` | Только для SCAIL-2. Цветная референсная маска, соответствующая по пакету `reference_image` (первая — маска основного референса, остальные — маски идентичностей для дополнительных `reference_image`). | IMAGE | Нет | - |
| `clip_vision_output` | Признаки CLIP vision для кондиционирования. Модель обучена с растягивающим изменением размера до соотношения сторон. | CLIP_VISION_OUTPUT | Нет | - |
| `previous_frames` | Только для SCAIL-2. Полностью декодированный выход предыдущего фрагмента. Только последние `previous_frame_count` кадров используются в качестве якоря продолжения. | IMAGE | Нет | - |

**Примечание:**

- Входные данные `pose_video` и `pose_video_mask` берутся начиная со смещения `video_frame_offset`; если в видео нет кадров после этого смещения, они игнорируются. Затем они обрезаются вместе до длины более короткого из двух и ограничиваются `length` кадрами. Перед кодированием `pose_video` уменьшается до половины разрешения основного видео.
- Вход `reference_image_mask` применяется только тогда, когда также задан `reference_image`. Каждое изображение в пакете `reference_image` кодируется отдельно как однокадровый латентный референс. В режиме замены (`replacement_mode=True`) референсные изображения компонуются на чёрном фоне с использованием маски референсного изображения в качестве альфа-маски.
- Когда задан `clip_vision_output`, он применяется как к позитивному, так и к негативному кондиционированию.
- Когда задан `previous_frames`, только последние `previous_frame_count` кадров используются в качестве якоря продолжения. Выходной латентный тензор частично заполняется кодированием этих кадров, в выходной латентный тензор включается шумовая маска, а значение `video_frame_offset` корректируется вычитанием количества сохранённых кадров (никогда не опускается ниже 0).

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Модифицированное позитивное кондиционирование, потенциально содержащее встроенные латентные представления референсных изображений, выход CLIP vision, латентные представления видео с позами, управляющие маски, референсные маски или латентные представления предыдущих кадров. | CONDITIONING |
| `negative` | Модифицированное негативное кондиционирование, потенциально содержащее встроенные латентные представления референсных изображений, выход CLIP vision, латентные представления видео с позами, управляющие маски, референсные маски или латентные представления предыдущих кадров. | CONDITIONING |
| `latent` | Пустой латентный тензор формы `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. Когда задан `previous_frames`, латентный тензор частично заполнен закодированными предыдущими кадрами, и в него включена шумовая маска. | LATENT |
| `video_frame_offset` | Скорректированное смещение + length. Подавайте в следующий фрагмент для последовательной генерации видео. | INT |
