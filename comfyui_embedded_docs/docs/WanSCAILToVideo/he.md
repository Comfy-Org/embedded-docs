# WanSCAILToVideo

צומת WanSCAILToVideo מכין קונדישנינג ומרחב latent ריק ליצירת וידאו עם מודלי הווידאו SCAIL ו-SCAIL-2. הוא מעבד קלטים אופציונליים כגון תמונות עזר, סרטוני תנוחה, פלטי CLIP vision, מסכות זהות צבעוניות וקטעי פריימים קודמים, ומטמיע אותם בקונדישנינג החיובי והשלילי. הצומת מפיק את הקונדישנינג שהשתנה וטנזור latent ריק במימדי הווידאו שצוינו, מוכן לדגימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | קלט הקונדישנינג החיובי. | CONDITIONING | כן | - |
| `negative` | קלט הקונדישנינג השלילי. | CONDITIONING | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד תמונות ופריימים של וידאו. | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 512). הערכים מתקדמים בצעדים של 32. | INT | כן | 32 to MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 896). הערכים מתקדמים בצעדים של 32. | INT | כן | 32 to MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו (ברירת מחדל: 81). הערכים מתקדמים בצעדים של 4. | INT | כן | 1 to MAX_RESOLUTION |
| `batch_size` | מספר הסרטונים ליצירה באצווה (ברירת מחדל: 1). | INT | כן | 1 to 4096 |
| `pose_video` | וידאו המשמש לקונדישנינג תנוחה. יוקטן לחצי מהרזולוציה של הווידאו הראשי. | IMAGE | לא | - |
| `pose_video_mask` | עבור SCAIL-2 בלבד. וידאו מסכת SAM3 צבעוני לפי זהות ברזולוציה זהה ל-pose_video. | IMAGE | לא | - |
| `replacement_mode` | עבור SCAIL-2 בלבד. False = מצב אנימציה (ל-pose_video_mask צריך להיות רקע שחור). True = מצב החלפה (ל-pose_video_mask צריך להיות רקע לבן). (ברירת מחדל: False) | BOOLEAN | לא | - |
| `pose_strength` | עוצמת ה-latent של התנוחה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 10.0 |
| `pose_start` | צעד ההתחלה של קונדישנינג התנוחה. (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 to 1.0 |
| `pose_end` | צעד הסיום של קונדישנינג התנוחה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 1.0 |
| `reference_image` | תמונת עזר. התמונה הראשונה היא תמונת העזר הראשית (משלבים עליה את כל הזהויות). SCAIL-2: תמונות אצווה נוספות משמשות כמבטים נוספים (מבט אחורי, תקריב, רקע מוסתר), כאשר כל אחת מהן זקוקה ל-reference_image_mask תואם בצבע של אותה זהות. | IMAGE | לא | - |
| `reference_image_mask` | עבור SCAIL-2 בלבד. מסכת עזר צבעונית, באצווה התואמת ל-reference_image (הראשונה = מסכת העזר הראשית, השאר = מסכות זהות עבור תמונות ה-reference_image הנוספות). | IMAGE | לא | - |
| `clip_vision_output` | מאפייני CLIP vision לקונדישנינג. המודל אומן עם שינוי גודל במתיחה ליחס גובה-רוחב. | CLIP_VISION_OUTPUT | לא | - |
| `video_frame_offset` | הפריים המצטבר בפלט שממנו מתחיל הקטע הזה. חבר מהפלט video_frame_offset של הקטע הקודם. (ברירת מחדל: 0) | INT | כן | 0 to MAX_RESOLUTION |
| `previous_frame_count` | פריימי הזנב של previous_frames שישמשו כעוגן. SCAIL-2 אומן על 5 (קטעים של 81 פריימים, צעד של 76 פריימים). (ברירת מחדל: 5). הערכים מתקדמים בצעדים של 4. | INT | כן | 1 to MAX_RESOLUTION |
| `previous_frames` | עבור SCAIL-2 בלבד. פלט מפוענח מלא של הקטע הקודם. רק previous_frame_count האחרונים משמשים כעוגן ההרחבה. | IMAGE | לא | - |

**הערה:** הקלטים `pose_video` ו-`pose_video_mask` נחתכים יחד לאורך הקצר מבין השניים, ומעובדים רק עבור `length` הפריימים הראשונים. אם אחד מהקלטים קצר מ-`video_frame_offset` או שווה לו, הוא מתעלם ממנו לחלוטין. `pose_video` מוקטן לחצי מהרזולוציה של הווידאו הראשי לפני הקידוד, וה-latent של התנוחה המקודד מוכפל ב-`pose_strength` ומוחל על הקונדישנינג רק בין צעדי ה-timestep `pose_start` ו-`pose_end`. אם מסופק `pose_video_mask`, וידאו המסכה הצבעוני מוקטן לחצי רזולוציה ומומר למסכת מניעה בת 28 ערוצים, שמתווספת גם לקונדישנינג החיובי וגם לשלילי.

**הערה:** כאשר מסופק `reference_image`, כל תמונה באצווה מקודדת בנפרד ל-latent ומוטמעת גם בקונדישנינג החיובי וגם בשלילי. התמונה הראשונה היא תמונת העזר הראשית; תמונות נוספות משמשות כמבטים נוספים, וכל אחת מהן זקוקה ל-`reference_image_mask` תואם. `reference_image_mask` משמשת רק כאשר גם `reference_image` מסופק; כאשר שניהם מסופקים, נבנית גם מסכת עזר בת 28 ערוצים שמקשרת את פריימי העזר לזהויות, מתוך המסכות, והיא מתווספת לקונדישנינג. במצב החלפה (`replacement_mode=True`), תמונת העזר משולבת על רקע שחור תוך שימוש במסכת תמונת העזר כמסכת אלפא. כאשר מסופק `clip_vision_output`, הוא מוחל על הקונדישנינג החיובי והשלילי כאחד.

**הערה:** כאשר מסופק `previous_frames`, רק `previous_frame_count` הפריימים האחרונים משמשים כעוגן ההרחבה, ו-`video_frame_offset` מותאם בהתאם (מופחת במספר הפריימים המעוגנים, ומוגבל ל-0). הפריימים המעוגנים מקודדים ונכתבים לתחילת ה-latent של הפלט, ומסכת רעש נכללת כך שהפריימים האלה נשמרים ללא שינוי במהלך היצירה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | הקונדישנינג החיובי שהשתנה, אשר עשוי להכיל ערכי latent של תמונות עזר מוטמעות, פלט CLIP vision, ערכי latent של וידאו תנוחה, מסכות מניעה, מסכות עזר או ערכי latent של פריימים קודמים. | CONDITIONING |
| `negative` | הקונדישנינג השלילי שהשתנה, אשר עשוי להכיל ערכי latent של תמונות עזר מוטמעות, פלט CLIP vision, ערכי latent של וידאו תנוחה, מסכות מניעה, מסכות עזר או ערכי latent של פריימים קודמים. | CONDITIONING |
| `latent` | טנזור latent ריק בצורה `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. כאשר מסופק `previous_frames`, ה-latent מתמלא חלקית בפריימים קודמים מקודדים ומסכת רעש נכללת. | LATENT |
| `video_frame_offset` | היסט מותאם + length. יש לחבר אל הקטע הבא ליצירת וידאו רציפה. | INT |
