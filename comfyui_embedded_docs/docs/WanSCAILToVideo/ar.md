# WanSCAILToVideo

تُجهّز عقدة WanSCAILToVideo التكييف ومساحة كامنة فارغة لتوليد الفيديو. تعالج المدخلات الاختيارية مثل الصور المرجعية، وفيديوهات الوضعية، ومخرجات رؤية CLIP، وشرائح الإطارات السابقة، وتدمجها في التكييف الإيجابي والسلبي لنموذج الفيديو. تُخرج العقدة التكييف المعدَّل وموترًا كامنًا فارغًا بأبعاد الفيديو المحددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `positive` | مدخل التكييف الإيجابي. | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور وإطارات الفيديو. | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 512). قابل للتعديل بخطوات مقدارها 32. | INT | نعم | 32 to MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 896). قابل للتعديل بخطوات مقدارها 32. | INT | نعم | 32 to MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو (الافتراضي: 81). قابل للتعديل بخطوات مقدارها 4 بدءًا من 1. | INT | نعم | 1 to MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو المطلوب توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 to 4096 |
| `pose_strength` | قوة الكامن الخاص بالوضعية (الافتراضي: 1.0). | FLOAT | نعم | 0.0 to 10.0 |
| `pose_start` | خطوة البداية لتكييف الوضعية (الافتراضي: 0.0). | FLOAT | نعم | 0.0 to 1.0 |
| `pose_end` | خطوة النهاية لتكييف الوضعية (الافتراضي: 1.0). | FLOAT | نعم | 0.0 to 1.0 |
| `video_frame_offset` | إطار الإخراج التراكمي الذي تبدأ عنده هذه الشريحة. يُوصَل من مخرج video_frame_offset للشريحة السابقة (الافتراضي: 0). | INT | نعم | 0 to MAX_RESOLUTION |
| `previous_frame_count` | الإطارات الخلفية من previous_frames المستخدمة كمرساة. تم تدريب SCAIL-2 على 5 (شرائح من 81 إطارًا، وخطوة مقدارها 76 إطارًا) (الافتراضي: 5). | INT | نعم | 1 to MAX_RESOLUTION |
| `pose_video` | فيديو يُستخدم لتكييف الوضعية. سيتم تصغيره إلى نصف دقة الفيديو الرئيسي. | IMAGE | لا | - |
| `pose_video_mask` | خاص بـ SCAIL-2 فقط. فيديو قناع SAM3 ملون لكل هوية بنفس دقة pose_video. | IMAGE | لا | - |
| `replacement_mode` | خاص بـ SCAIL-2 فقط. القيمة False = وضع الرسوم المتحركة (يجب أن تكون خلفية pose_video_mask سوداء). القيمة True = وضع الاستبدال (يجب أن تكون خلفية pose_video_mask بيضاء). الافتراضي: False. | BOOLEAN | لا | - |
| `reference_image` | الصورة المرجعية. الصورة الأولى هي المرجع الأساسي (يتم تركيب جميع الهويات عليها). SCAIL-2: تُستخدم صور إضافية من الدفعة كعروض إضافية (منظر خلفي، لقطة قريبة، خلفية مسدودة)، وكل منها يحتاج إلى reference_image_mask مطابق بلون تلك الهوية. | IMAGE | لا | - |
| `reference_image_mask` | خاص بـ SCAIL-2 فقط. قناع مرجعي ملون، يطابق batch الصورة المرجعية (الأول = قناع المرجع الأساسي، والباقي = أقنعة الهوية للصور المرجعية الإضافية). | IMAGE | لا | - |
| `clip_vision_output` | ميزات رؤية CLIP للتكييف. النموذج مُدرَّب على إعادة التحجيم بالتمديد لنسبة العرض إلى الارتفاع. | CLIP_VISION_OUTPUT | لا | - |
| `previous_frames` | خاص بـ SCAIL-2 فقط. الإخراج الكامل المفكوك للشريحة السابقة. يتم استخدام آخر previous_frame_count إطارات فقط كمرساة للتمديد. | IMAGE | لا | - |

**ملاحظة:**

- يتم تقطيع مدخلي `pose_video` و `pose_video_mask` بدءًا من `video_frame_offset`؛ إذا لم توجد إطارات في الفيديو بعد هذا الإزاحة، يتم تجاهله. بعد ذلك يتم اقتطاعهما معًا إلى أقصر الاثنين ويُحدَّ أقصى عدد الإطارات بـ `length`. يتم تصغير دقة `pose_video` إلى نصف دقة الفيديو الرئيسي قبل الترميز.
- يُطبَّق مدخل `reference_image_mask` فقط عندما يتم توفير `reference_image` أيضًا. يتم ترميز كل صورة في دفعة `reference_image` بشكل فردي كمرجع كامن بإطار واحد. في وضع الاستبدال (`replacement_mode=True`)، تُركَّب الصور المرجعية على خلفية سوداء باستخدام قناع الصورة المرجعية كقناة شفافية.
- عند توفير `clip_vision_output`، يتم تطبيقه على كل من التكييف الإيجابي والسلبي.
- عند توفير `previous_frames`، يتم استخدام آخر `previous_frame_count` إطارات فقط كمرساة للتمديد. يتم ملء الكامن الناتج جزئيًا بترميز هذه الإطارات، ويتم تضمين قناع ضوضاء في مخرج الكامن، ويتم ضبط `video_frame_offset` بطرح عدد الإطارات المحتفظ بها (لا ينخفض أبدًا عن 0).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | التكييف الإيجابي المعدَّل، الذي قد يحتوي على كامنات الصور المرجعية المدمجة، ومخرجات رؤية CLIP، وكامنات فيديو الوضعية، وأقنعة القيادة، وأقنعة مرجعية، أو كامنات الإطارات السابقة. | CONDITIONING |
| `negative` | التكييف السلبي المعدَّل، الذي قد يحتوي على كامنات الصور المرجعية المدمجة، ومخرجات رؤية CLIP، وكامنات فيديو الوضعية، وأقنعة القيادة، وأقنعة مرجعية، أو كامنات الإطارات السابقة. | CONDITIONING |
| `latent` | موتر كامن فارغ بالشكل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. عند توفير previous_frames، يتم ملء الكامن جزئيًا بإطارات سابقة مشفرة ويتم تضمين قناع ضوضاء. | LATENT |
| `video_frame_offset` | الإزاحة المعدَّلة + الطول. يُوصَل إلى الشريحة التالية لتوليد الفيديو بالتسلسل. | INT |
