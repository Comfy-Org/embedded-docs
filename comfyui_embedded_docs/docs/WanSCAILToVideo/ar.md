# WanSCAILToVideo

عقدة WanSCAILToVideo تهيّئ التكييف وفضاءً كامنًا فارغًا لتوليد الفيديو باستخدام نموذجي الفيديو SCAIL وSCAIL-2. وتعالج مدخلات اختيارية مثل الصور المرجعية، وفيديوهات الوضعية، ومخرجات رؤية CLIP، وأقنعة الهوية الملوّنة، ومقاطع الإطارات السابقة، وتضمّنها في التكييف الإيجابي والسلبي. وتخرج العقدة التكييف المعدّل وموترًا كامنًا فارغًا بأبعاد الفيديو المحددة، جاهزًا لأخذ العينات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `positive` | مدخل التكييف الإيجابي. | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور وإطارات الفيديو. | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 512). تتدرّج القيم بمقدار 32. | INT | نعم | 32 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 896). تتدرّج القيم بمقدار 32. | INT | نعم | 32 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو (الافتراضي: 81). تتدرّج القيم بمقدار 4. | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات المطلوب توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |
| `pose_video` | الفيديو المستخدم لتكييف الوضعية. سيتم تصغيره إلى نصف دقة الفيديو الرئيسي. | IMAGE | لا | - |
| `pose_video_mask` | خاص بـ SCAIL-2 فقط. فيديو قناع SAM3 ملوّن لكل هوية بالدقة نفسها التي يملكها `pose_video`. | IMAGE | لا | - |
| `replacement_mode` | خاص بـ SCAIL-2 فقط. False = وضع التحريك (يجب أن تكون خلفية `pose_video_mask` سوداء). True = وضع الاستبدال (يجب أن تكون خلفية `pose_video_mask` بيضاء). (الافتراضي: False) | BOOLEAN | لا | - |
| `pose_strength` | شدة الكامن الخاص بالوضعية. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 10.0 |
| `pose_start` | خطوة البداية لتكييف الوضعية. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `pose_end` | خطوة النهاية لتكييف الوضعية. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `reference_image` | الصورة المرجعية. الصورة الأولى هي المرجع الأساسي (ركّب كل الهويات عليها). SCAIL-2: تُستخدم صور الدفعة الإضافية كعروض إضافية (عرض خلفي، لقطة قريبة، خلفية محجوبة)، ويحتاج كل منها إلى `reference_image_mask` مطابق بلون تلك الهوية. | IMAGE | لا | - |
| `reference_image_mask` | خاص بـ SCAIL-2 فقط. قناع مرجعي ملوّن، دفعته تطابق `reference_image` (الأول = قناع المرجع الأساسي، والباقي = أقنعة هوية لصور `reference_image` الإضافية). | IMAGE | لا | - |
| `clip_vision_output` | ميزات رؤية CLIP للتكييف. تم تدريب النموذج باستخدام تغيير الحجم بالتمدد إلى نسبة العرض إلى الارتفاع. | CLIP_VISION_OUTPUT | لا | - |
| `video_frame_offset` | إطار الإخراج التراكمي الذي يبدأ عنده هذا المقطع. وصّل من مخرج `video_frame_offset` للمقطع السابق. (الافتراضي: 0) | INT | نعم | 0 إلى MAX_RESOLUTION |
| `previous_frame_count` | الإطارات الأخيرة من `previous_frames` التي سيتم تثبيتها كمرتكز. تم تدريب SCAIL-2 على 5 (مقاطع من 81 إطارًا، خطوة 76 إطارًا). (الافتراضي: 5). تتدرّج القيم بمقدار 4. | INT | نعم | 1 إلى MAX_RESOLUTION |
| `previous_frames` | خاص بـ SCAIL-2 فقط. الناتج الكامل بعد فك التشفير للمقطع السابق. تُستخدم فقط آخر `previous_frame_count` إطارًا كمرتكز للتمديد. | IMAGE | لا | - |

**ملاحظة:** يتم قص المدخلين `pose_video` و`pose_video_mask` معًا إلى الأقصر منهما، ويُعالجان فقط لأول `length` إطار. إذا كان أي منهما أقصر من أو يساوي `video_frame_offset`، فسيتم تجاهله بالكامل. يتم تصغير `pose_video` إلى نصف دقة الفيديو الرئيسي قبل الترميز، ويُضرب الكامن المشفّر للوضعية في `pose_strength` ويُطبّق على التكييف فقط بين خطوتي `pose_start` و`pose_end` الزمنيتين. إذا تم توفير `pose_video_mask`، يتم تصغير فيديو القناع الملوّن إلى نصف الدقة وتحويله إلى قناع قيادة من 28 قناة، يُضاف إلى كلٍ من التكييف الإيجابي والسلبي.

**ملاحظة:** عند توفير `reference_image`، يتم ترميز كل صورة في الدفعة على حدة إلى كامن وتضمينها في كلٍ من التكييف الإيجابي والسلبي. الصورة الأولى هي المرجع الأساسي؛ وتُستخدم الصور الإضافية كعروض إضافية، ويحتاج كل منها إلى `reference_image_mask` مطابق. لا يُستخدم `reference_image_mask` إلا عند توفير `reference_image` أيضًا؛ وعند توفير كليهما، يُبنى أيضًا من الأقنعة قناع مرجعي من 28 قناة يربط الإطارات المرجعية بالهويات ويُضاف إلى التكييف. في وضع الاستبدال (`replacement_mode=True`)، يتم تركيب الصورة المرجعية على خلفية سوداء باستخدام قناع الصورة المرجعية كقناع ألفا. عند توفير `clip_vision_output`، يُطبّق على كلٍ من التكييف الإيجابي والسلبي.

**ملاحظة:** عند توفير `previous_frames`، تُستخدم فقط آخر `previous_frame_count` إطارًا كمرتكز للتمديد، ويُعدّل `video_frame_offset` وفقًا لذلك (يُخفّض بعدد الإطارات المثبتة، مع تقييده عند 0). يتم ترميز الإطارات المثبتة وكتابتها في بداية الكامن الناتج، ويُضمّن قناع ضوضاء حتى تبقى تلك الإطارات دون تغيير أثناء التوليد.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | التكييف الإيجابي المعدّل، والذي قد يحتوي على كوامن صور مرجعية مضمّنة، أو مخرجات رؤية CLIP، أو كوامن فيديو الوضعية، أو أقنعة قيادة، أو أقنعة مرجعية، أو كوامن الإطارات السابقة. | CONDITIONING |
| `negative` | التكييف السلبي المعدّل، والذي قد يحتوي على كوامن صور مرجعية مضمّنة، أو مخرجات رؤية CLIP، أو كوامن فيديو الوضعية، أو أقنعة قيادة، أو أقنعة مرجعية، أو كوامن الإطارات السابقة. | CONDITIONING |
| `latent` | موتر كامن فارغ بالشكل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. عند توفير `previous_frames`، يُملأ الكامن جزئيًا بإطارات سابقة مشفّرة ويُضمّن قناع ضوضاء. | LATENT |
| `video_frame_offset` | الإزاحة المعدلة + الطول. وصّله إلى المقطع التالي لتوليد الفيديو التسلسلي. | INT |
