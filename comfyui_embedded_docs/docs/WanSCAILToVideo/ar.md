# WanSCAILToVideo

عقدة WanSCAILToVideo تُحضّر التكييف (conditioning) وفضاءًا كامنًا فارغًا لتوليد الفيديو باستخدام نماذج الفيديو SCAIL وSCAIL-2. تعالج هذه العقدة مدخلات اختيارية مثل الصور المرجعية، وفيديوهات الوضعية، ومخرجات CLIP البصرية، وأقنعة الهوية الملونة، وأجزاء الإطارات السابقة، وتضمّنها في التكييف الإيجابي والسلبي. تُخرج العقدة التكييف المعدَّل وموترًا كامنًا فارغًا بأبعاد الفيديو المحددة، جاهزًا لأخذ العينات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `إيجابي` | مدخل التكييف الإيجابي. | CONDITIONING | نعم | - |
| `سلبي` | مدخل التكييف السلبي. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير الصور وإطارات الفيديو. | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 512). تزداد القيم بخطوات مقدارها 32. | INT | نعم | 32 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 896). تزداد القيم بخطوات مقدارها 32. | INT | نعم | 32 to MAX_RESOLUTION |
| `الطول` | عدد الإطارات في الفيديو (الافتراضي: 81). تزداد القيم بخطوات مقدارها 4. | INT | نعم | 1 to MAX_RESOLUTION |
| `حجم الدفعة` | عدد الفيديوهات التي سيتم توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |
| `فيديو الوضعية` | فيديو يُستخدم لتكييف الوضعية (pose). سيتم تصغيره إلى نصف دقة الفيديو الرئيسي. | IMAGE | لا | - |
| `pose_video_mask` | خاص بـ SCAIL-2 فقط. فيديو قناع SAM3 الملون لكل هوية بنفس دقة pose_video. | IMAGE | لا | - |
| `replacement_mode` | خاص بـ SCAIL-2 فقط. False = وضع الرسوم المتحركة (يجب أن تكون خلفية pose_video_mask سوداء). True = وضع الاستبدال (يجب أن تكون خلفية pose_video_mask بيضاء). (الافتراضي: False) | BOOLEAN | لا | - |
| `قوة الوضعية` | قوة كامن الوضعية (pose latent). (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 10.0 |
| `بدء الوضعية` | خطوة البداية لتكييف الوضعية. (الافتراضي: 0.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `نهاية الوضعية` | خطوة النهاية لتكييف الوضعية. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `صورة مرجعية` | صورة مرجعية. الصورة الأولى هي المرجع الأساسي (تُركَّب عليها جميع الهويات). في SCAIL-2: تُستخدم صور إضافية من الدفعة كعروض إضافية (عرض خلفي، لقطة قريبة، خلفية محجوبة)، وتتطلب كل منها reference_image_mask مطابقًا بلون تلك الهوية. | IMAGE | لا | - |
| `reference_image_mask` | خاص بـ SCAIL-2 فقط. قناع مرجعي ملون، يطابق بالدفعة reference_image (الأول = قناع المرجع الأساسي، والباقي = أقنعة الهويات لـ reference_image الإضافية). | IMAGE | لا | - |
| `clip_vision_output` | ميزات CLIP البصرية للتكييف. تم تدريب النموذج مع تغيير الحجم بالتمدد إلى نسبة العرض إلى الارتفاع. | CLIP_VISION_OUTPUT | لا | - |
| `video_frame_offset` | إطار المخرجات التراكمي الذي تبدأ عنده هذه الدفعة. يُوصَل من مخرج video_frame_offset للدفعة السابقة. (الافتراضي: 0) | INT | نعم | 0 to MAX_RESOLUTION |
| `previous_frame_count` | الإطارات الختامية من previous_frames لتثبيتها. تم تدريب SCAIL-2 على 5 (دفعات من 81 إطارًا، خطوة 76 إطارًا). (الافتراضي: 5) | INT | نعم | 1 to MAX_RESOLUTION |
| `previous_frames` | خاص بـ SCAIL-2 فقط. المخرج الكامل المُفكك ترميزه للدفعة السابقة. يُستخدم فقط آخر previous_frame_count إطارات كمرساة للتمديد. | IMAGE | لا | - |

**ملاحظة:** يتم اقتطاع مدخلي `pose_video` و`pose_video_mask` معًا إلى أقصر الاثنين، وتتم معالجتهما فقط لأول `length` إطارًا. إذا كان أي من المدخلين أقصر من أو يساوي `video_frame_offset`، يتم تجاهله تمامًا. يتم تصغير `pose_video` إلى نصف دقة الفيديو الرئيسي قبل التشفير، ويُضرب كامن الوضعية المشفر بـ `pose_strength` ويُطبَّق على التكييف فقط بين خطوتَي `pose_start` و`pose_end`. إذا تم توفير `pose_video_mask`، يتم تصغير فيديو القناع الملون إلى نصف الدقة وتحويله إلى قناع تشغيل من 28 قناة، ويُضاف إلى كل من التكييف الإيجابي والسلبي.

**ملاحظة:** عند توفير `reference_image`، يتم ترميز كل صورة في الدفعة بشكل فردي إلى كامن ويتم تضمينها في كل من التكييف الإيجابي والسلبي. الصورة الأولى هي المرجع الأساسي؛ وتُستخدم الصور الإضافية كعروض إضافية، وتتطلب كل منها `reference_image_mask` مطابقًا. يُستخدم `reference_image_mask` فقط عند توفير `reference_image` أيضًا؛ وعند توفير كلاهما، يتم أيضًا بناء قناع مرجعي من 28 قناة يربط الإطارات المرجعية بالهويات من الأقنعة ويُضاف إلى التكييف. في وضع الاستبدال (`replacement_mode=True`)، يتم تركيب الصورة المرجعية على خلفية سوداء باستخدام قناع الصورة المرجعية كقناة شفافية (alpha matte). عند توفير `clip_vision_output`، يتم تطبيقه على كل من التكييف الإيجابي والسلبي.

**ملاحظة:** عند توفير `previous_frames`، يُستخدم فقط آخر `previous_frame_count` إطارًا كمرساة للتمديد، ويتم ضبط `video_frame_offset` وفقًا لذلك (يُقلل بمقدار عدد الإطارات المثبتة، مع تحديده عند 0). يتم ترميز الإطارات المثبتة وكتابتها في بداية الكامن الناتج، ويتم تضمين قناع ضوضاء بحيث تظل تلك الإطارات دون تغيير أثناء التوليد.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `إيجابي` | التكييف الإيجابي المعدل، والذي قد يحتوي على كامنات الصور المرجعية المضمنة، ومخرج CLIP البصري، وكامنات فيديو الوضعية، وأقنعة التشغيل، والأقنعة المرجعية، أو كامنات الإطارات السابقة. | CONDITIONING |
| `سلبي` | التكييف السلبي المعدل، والذي قد يحتوي على كامنات الصور المرجعية المضمنة، ومخرج CLIP البصري، وكامنات فيديو الوضعية، وأقنعة التشغيل، والأقنعة المرجعية، أو كامنات الإطارات السابقة. | CONDITIONING |
| `كامن` | موتر كامن فارغ ذو شكل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. عند توفير `previous_frames`، يكون الكامن مملوءًا جزئيًا بإطارات سابقة مشفرة ويتم تضمين قناع ضوضاء. | LATENT |
| `video_frame_offset` | الإزاحة المعدلة + الطول. يُوصَل إلى الدفعة التالية لتوليد فيديو تسلسلي. | INT |
