# WanSCAILToVideo

گره WanSCAILToVideo شرطی‌سازی و یک فضای نهفته خالی را برای تولید ویدیو با مدل‌های ویدیویی SCAIL و SCAIL-2 آماده می‌کند. ورودی‌های اختیاری مانند تصاویر مرجع، ویدیوهای ژست، خروجی‌های بینایی CLIP، ماسک‌های هویتی رنگی و قطعه‌های فریم قبلی را پردازش کرده و آن‌ها را در شرطی‌سازی مثبت و منفی جاسازی می‌کند. این گره شرطی‌سازی اصلاح‌شده و یک تنسور نهفته خالی با ابعاد ویدیوی مشخص را خروجی می‌دهد که برای نمونه‌گیری آماده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `positive` | ورودی شرطی‌سازی مثبت. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی. | CONDITIONING | بله | - |
| `vae` | مدل VAE که برای کدگذاری تصاویر و فریم‌های ویدیو استفاده می‌شود. | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 512). مقادیر با گام 32 تغییر می‌کنند. | INT | بله | 32 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 896). مقادیر با گام 32 تغییر می‌کنند. | INT | بله | 32 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیو (پیش‌فرض: 81). مقادیر با گام 4 تغییر می‌کنند. | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `pose_video` | ویدیوی مورد استفاده برای شرطی‌سازی ژست. به نصف رزولوشن ویدیوی اصلی کوچک می‌شود. | IMAGE | خیر | - |
| `pose_video_mask` | فقط SCAIL-2. ویدیوی ماسک SAM3 رنگی به‌ازای هر هویت، با همان رزولوشن `pose_video`. | IMAGE | خیر | - |
| `replacement_mode` | فقط SCAIL-2. False = حالت انیمیشن (`pose_video_mask` باید پس‌زمینه سیاه داشته باشد). True = حالت جایگزینی (`pose_video_mask` باید پس‌زمینه سفید داشته باشد). (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `pose_strength` | قدرت نهفته ژست. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 10.0 |
| `pose_start` | گام شروع شرطی‌سازی ژست. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 |
| `pose_end` | گام پایان شرطی‌سازی ژست. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |
| `reference_image` | تصویر مرجع. تصویر اول مرجع اصلی است (همه هویت‌ها روی آن ترکیب می‌شوند). SCAIL-2: تصاویر اضافی دسته به‌عنوان نماهای افزوده استفاده می‌شوند (نمای پشت، نمای نزدیک، پس‌زمینه پوشیده‌شده)، و هر کدام به یک `reference_image_mask` هم‌رنگ با هویت همان تصویر نیاز دارد. | IMAGE | خیر | - |
| `reference_image_mask` | فقط SCAIL-2. ماسک مرجع رنگی، هم‌دسته با `reference_image` (اولی = ماسک مرجع اصلی، بقیه = ماسک‌های هویت برای `reference_image`های افزوده). | IMAGE | خیر | - |
| `clip_vision_output` | ویژگی‌های بینایی CLIP برای شرطی‌سازی. مدل با تغییر اندازه کشیده‌شده به نسبت تصویر آموزش دیده است. | CLIP_VISION_OUTPUT | خیر | - |
| `video_frame_offset` | فریم خروجی تجمعی که این قطعه از آن شروع می‌شود. از خروجی `video_frame_offset` قطعه قبلی سیم‌کشی کنید. (پیش‌فرض: 0) | INT | بله | 0 تا MAX_RESOLUTION |
| `previous_frame_count` | فریم‌های انتهایی `previous_frames` برای لنگر انداختن. SCAIL-2 با مقدار 5 آموزش دیده است (قطعه‌های 81 فریمی، گام 76 فریمی). (پیش‌فرض: 5). مقادیر با گام 4 تغییر می‌کنند. | INT | بله | 1 تا MAX_RESOLUTION |
| `previous_frames` | فقط SCAIL-2. خروجی رمزگشایی‌شده کامل قطعه قبلی. فقط آخرین `previous_frame_count` فریم به‌عنوان لنگر توسعه استفاده می‌شود. | IMAGE | خیر | - |

**توجه:** ورودی‌های `pose_video` و `pose_video_mask` با هم تا کوتاه‌ترین آن دو بریده می‌شوند و فقط برای اولین `length` فریم پردازش می‌شوند. اگر هر یک از این ورودی‌ها کوتاه‌تر یا مساوی `video_frame_offset` باشد، کاملاً نادیده گرفته می‌شود. `pose_video` پیش از کدگذاری به نصف رزولوشن ویدیوی اصلی کوچک می‌شود و نهفته ژست کدشده در `pose_strength` ضرب شده و فقط بین گام‌های زمانی `pose_start` و `pose_end` روی شرطی‌سازی اعمال می‌شود. اگر `pose_video_mask` ارائه شود، ویدیوی ماسک رنگی به نصف رزولوشن کوچک شده و به یک ماسک هدایت‌کننده 28 کاناله تبدیل می‌شود که به هر دو شرطی‌سازی مثبت و منفی افزوده می‌گردد.

**توجه:** هنگامی که `reference_image` ارائه شود، هر تصویر در دسته به‌صورت جداگانه به یک نهفته کدگذاری شده و در هر دو شرطی‌سازی مثبت و منفی جاسازی می‌شود. تصویر اول مرجع اصلی است؛ تصاویر اضافی به‌عنوان نماهای افزوده استفاده می‌شوند و هر کدام به یک `reference_image_mask` منطبق نیاز دارند. `reference_image_mask` فقط زمانی استفاده می‌شود که `reference_image` نیز ارائه شده باشد؛ وقتی هر دو داده شوند، یک ماسک مرجع 28 کاناله که فریم‌های مرجع را به هویت‌ها پیوند می‌دهد نیز از ماسک‌ها ساخته شده و به شرطی‌سازی افزوده می‌شود. در حالت جایگزینی (`replacement_mode=True`)، تصویر مرجع با استفاده از ماسک تصویر مرجع به‌عنوان ماسک آلفا روی پس‌زمینه سیاه ترکیب می‌شود. هنگامی که `clip_vision_output` ارائه شود، روی هر دو شرطی‌سازی مثبت و منفی اعمال می‌گردد.

**توجه:** هنگامی که `previous_frames` ارائه شود، فقط آخرین `previous_frame_count` فریم به‌عنوان لنگر توسعه استفاده می‌شوند و `video_frame_offset` بر همین اساس تنظیم می‌شود (به اندازه تعداد فریم‌های لنگرشده کاهش می‌یابد و در 0 محدود می‌شود). فریم‌های لنگرشده کدگذاری شده و در ابتدای نهفته خروجی نوشته می‌شوند و یک ماسک نویز گنجانده می‌شود تا این فریم‌ها در طول تولید بدون تغییر بمانند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت اصلاح‌شده، که ممکن است شامل نهفته‌های تصویر مرجع جاسازی‌شده، خروجی بینایی CLIP، نهفته‌های ویدیوی ژست، ماسک‌های هدایت‌کننده، ماسک‌های مرجع یا نهفته‌های فریم قبلی باشد. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده، که ممکن است شامل نهفته‌های تصویر مرجع جاسازی‌شده، خروجی بینایی CLIP، نهفته‌های ویدیوی ژست، ماسک‌های هدایت‌کننده، ماسک‌های مرجع یا نهفته‌های فریم قبلی باشد. | CONDITIONING |
| `latent` | یک تنسور نهفته خالی با شکل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. هنگامی که `previous_frames` ارائه شود، نهفته تا حدی با فریم‌های قبلی کدگذاری‌شده پر می‌شود و یک ماسک نویز نیز گنجانده می‌شود. | LATENT |
| `video_frame_offset` | آفست تنظیم‌شده + `length`. برای تولید ویدیوی متوالی به قطعه بعدی سیم‌کشی کنید. | INT |
