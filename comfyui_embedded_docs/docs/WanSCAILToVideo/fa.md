# WanSCAILToVideo

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مثبت` | ورودی شرط‌دهی مثبت. | CONDITIONING | بله | - |
| `منفی` | ورودی شرط‌دهی منفی. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر و فریم‌های ویدیو. | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 512). مقادیر با گام 32 افزایش می‌یابند. | INT | بله | 32 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 896). مقادیر با گام 32 افزایش می‌یابند. | INT | بله | 32 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 81). مقادیر با گام 4 افزایش می‌یابند. | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدیوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `ویدئوی pose` | ویدیوی مورد استفاده برای شرط‌دهی ژست. به نصف وضوح ویدیوی اصلی کوچک‌سازی می‌شود. | IMAGE | خیر | - |
| `pose_video_mask` | فقط SCAIL-2. ویدیوی ماسک رنگی SAM3 به‌ازای هر هویت، با همان وضوح `pose_video`. | IMAGE | خیر | - |
| `replacement_mode` | فقط SCAIL-2. False = حالت انیمیشن (`pose_video_mask` باید پس‌زمینه سیاه داشته باشد). True = حالت جایگزینی (`pose_video_mask` باید پس‌زمینه سفید داشته باشد). (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `قدرت pose` | شدت لاتنت ژست. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 10.0 |
| `شروع pose` | گام شروع شرط‌دهی ژست. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 |
| `پایان pose` | گام پایان شرط‌دهی ژست. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |
| `تصویر مرجع` | تصویر مرجع. اولین تصویر، مرجع اصلی است (همه هویت‌ها را روی آن ترکیب کنید). SCAIL-2: تصاویر اضافی در دسته به‌عنوان نماهای اضافی (نمای پشت، نمای نزدیک، پس‌زمینه پوشیده) استفاده می‌شوند و هر یک به یک `reference_image_mask` همرنگ با هویت مربوطه نیاز دارد. | IMAGE | خیر | - |
| `reference_image_mask` | فقط SCAIL-2. ماسک مرجع رنگی، هم‌اندازه دسته با `reference_image` (اولی = ماسک مرجع اصلی، بقیه = ماسک‌های هویت برای `reference_image` اضافی). | IMAGE | خیر | - |
| `خروجی clip vision` | ویژگی‌های CLIP vision برای شرط‌دهی. مدل با تغییر اندازه کششی (stretch resize) به نسبت تصویر آموزش دیده است. | CLIP_VISION_OUTPUT | خیر | - |
| `video_frame_offset` | فریم خروجی تجمعی که این تکه از آن آغاز می‌شود. از خروجی `video_frame_offset` تکه قبلی متصل کنید. (پیش‌فرض: 0) | INT | بله | 0 to MAX_RESOLUTION |
| `previous_frame_count` | فریم‌های دم `previous_frames` برای لنگر انداختن. SCAIL-2 با 5 آموزش دیده است (تکه‌های 81 فریمی، گام 76 فریم). (پیش‌فرض: 5) | INT | بله | 1 to MAX_RESOLUTION |
| `previous_frames` | فقط SCAIL-2. خروجی کامل رمزگشایی‌شده تکه قبلی. فقط تعداد `previous_frame_count` فریم آخر به‌عنوان لنگر ادامه استفاده می‌شود. | IMAGE | خیر | - |

**نکته:** ورودی‌های `pose_video` و `pose_video_mask` همزمان به اندازه کوتاه‌ترین آن دو بریده می‌شوند و فقط برای `length` فریم اول پردازش می‌شوند. اگر هر یک از ورودی‌ها کوتاه‌تر یا مساوی `video_frame_offset` باشد، به‌طور کامل نادیده گرفته می‌شود. `pose_video` قبل از رمزگذاری به نصف وضوح ویدیوی اصلی کوچک‌سازی می‌شود و لاتنت ژست رمزگذاری‌شده در `pose_strength` ضرب شده و فقط بین گام‌های زمانی `pose_start` و `pose_end` روی شرط‌دهی اعمال می‌شود. اگر `pose_video_mask` ارائه شده باشد، ویدیوی ماسک رنگی به نصف وضوح کوچک‌سازی شده و به یک ماسک رانندگی 28 کاناله تبدیل می‌شود که به هر دو شرط‌دهی مثبت و منفی اضافه می‌گردد.

**نکته:** وقتی `reference_image` ارائه می‌شود، هر تصویر در دسته به‌صورت جداگانه در یک لاتنت رمزگذاری شده و در هر دو شرط‌دهی مثبت و منفی جاسازی می‌شود. اولین تصویر مرجع اصلی است؛ تصاویر اضافی به‌عنوان نماهای اضافی استفاده می‌شوند و هر یک به یک `reference_image_mask` همسان نیاز دارد. `reference_image_mask` فقط زمانی استفاده می‌شود که `reference_image` نیز ارائه شده باشد؛ وقتی هر دو داده شوند، یک ماسک مرجع 28 کاناله که فریم‌های مرجع را به هویت‌ها پیوند می‌دهد نیز از روی ماسک‌ها ساخته شده و به شرط‌دهی اضافه می‌شود. در حالت جایگزینی (`replacement_mode=True`)، تصویر مرجع با استفاده از ماسک تصویر مرجع به‌عنوان مات آلفا، روی پس‌زمینه سیاه ترکیب می‌شود. وقتی `clip_vision_output` ارائه می‌شود، روی هر دو شرط‌دهی مثبت و منفی اعمال می‌گردد.

**نکته:** وقتی `previous_frames` ارائه می‌شود، فقط `previous_frame_count` فریم آخر به‌عنوان لنگر ادامه استفاده می‌شوند و `video_frame_offset` به‌صورت متناظر تنظیم می‌شود (به تعداد فریم‌های لنگرشده کاهش می‌یابد و در صفر محدود می‌شود). فریم‌های لنگرشده رمزگذاری شده و در ابتدای لاتنت خروجی نوشته می‌شوند، و یک ماسک نویز نیز گنجانده می‌شود تا آن فریم‌ها در طول تولید بدون تغییر بمانند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مثبت` | شرط‌دهی مثبت اصلاح‌شده، که احتمالاً شامل لاتنت‌های تصویر مرجع جاسازی‌شده، خروجی CLIP vision، لاتنت‌های ویدیوی ژست، ماسک‌های رانندگی، ماسک‌های مرجع یا لاتنت‌های فریم قبلی است. | CONDITIONING |
| `منفی` | شرط‌دهی منفی اصلاح‌شده، که احتمالاً شامل لاتنت‌های تصویر مرجع جاسازی‌شده، خروجی CLIP vision، لاتنت‌های ویدیوی ژست، ماسک‌های رانندگی، ماسک‌های مرجع یا لاتنت‌های فریم قبلی است. | CONDITIONING |
| `latent` | یک تنسور لاتنت خالی به شکل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. وقتی `previous_frames` ارائه شود، لاتنت به‌طور جزئی با فریم‌های قبلی رمزگذاری‌شده پر می‌شود و یک ماسک نویز نیز گنجانده می‌شود. | LATENT |
| `video_frame_offset` | آفست تنظیم‌شده + طول. برای تولید ویدیوی ترتیبی به تکه بعدی متصل کنید. | INT |
