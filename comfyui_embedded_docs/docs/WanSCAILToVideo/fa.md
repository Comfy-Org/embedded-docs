# WanSCAILToVideo

گره `WanSCAILToVideo` شرطی‌سازی و یک فضای نهان خالی برای تولید ویدیو آماده می‌کند. این گره ورودی‌های اختیاری مانند تصاویر مرجع، ویدیوهای ژست، خروجی‌های CLIP vision و تکه‌های فریم قبلی را پردازش کرده و آن‌ها را در شرطی‌سازی مثبت و منفی برای یک مدل ویدیویی جاسازی می‌کند. خروجی این گره شامل شرطی‌سازی اصلاح‌شده و یک تانسور نهان خالی با ابعاد ویدیوی مشخص‌شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `positive` | ورودی شرطی‌سازی مثبت. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر و فریم‌های ویدیو. | VAE | بله | - |
| `width` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 512). قابل تنظیم در گام‌های 32. | INT | بله | 32 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 896). قابل تنظیم در گام‌های 32. | INT | بله | 32 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیو (پیش‌فرض: 81). قابل تنظیم در گام‌های 4، با شروع از 1. | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهای تولیدی در هر batch (پیش‌فرض: 1). | INT | بله | 1 to 4096 |
| `pose_strength` | قدرت latent مرتبط با ژست (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 to 10.0 |
| `pose_start` | گام شروع شرطی‌سازی ژست (پیش‌فرض: 0.0). | FLOAT | بله | 0.0 to 1.0 |
| `pose_end` | گام پایان شرطی‌سازی ژست (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 to 1.0 |
| `video_frame_offset` | شماره فریم خروجی تجمعی که این تکه از آن شروع می‌شود. مقدار را از خروجی `video_frame_offset` تکه قبلی وصل کنید (پیش‌فرض: 0). | INT | بله | 0 to MAX_RESOLUTION |
| `previous_frame_count` | فریم‌های انتهایی `previous_frames` که به‌عنوان لنگر ادامه استفاده می‌شوند. SCAIL-2 با مقدار 5 آموزش دیده است (تکه‌های 81 فریمی، گام 76 فریمی) (پیش‌فرض: 5). | INT | بله | 1 to MAX_RESOLUTION |
| `pose_video` | ویدیوی مورد استفاده برای شرطی‌سازی ژست. به نصف رزولوشن ویدیوی اصلی کوچک می‌شود. | IMAGE | خیر | - |
| `pose_video_mask` | فقط SCAIL-2. ویدیوی ماسک رنگی SAM3 به‌ازای هر هویت، با همان رزولوشن `pose_video`. | IMAGE | خیر | - |
| `replacement_mode` | فقط SCAIL-2. False = حالت انیمیشن (`pose_video_mask` باید پس‌زمینه سیاه داشته باشد). True = حالت جایگزینی (`pose_video_mask` باید پس‌زمینه سفید داشته باشد). پیش‌فرض: False. | BOOLEAN | خیر | - |
| `reference_image` | تصویر مرجع. نخستین تصویر، مرجع اصلی است (همه هویت‌ها روی آن ترکیب می‌شوند). در SCAIL-2: تصاویر اضافی batch به‌عنوان نماهای اضافی (نمای پشت، نمای نزدیک، پس‌زمینه پوشیده‌شده) استفاده می‌شوند و هر یک به `reference_image_mask` همرنگ همان هویت نیاز دارد. | IMAGE | خیر | - |
| `reference_image_mask` | فقط SCAIL-2. ماسک رنگی مرجع، با تعداد آیتم‌های batch مطابق `reference_image` (اولی = ماسک مرجع اصلی، بقیه = ماسک هویت برای تصاویر مرجع اضافی). | IMAGE | خیر | - |
| `clip_vision_output` | ویژگی‌های CLIP vision برای شرطی‌سازی. مدل با تغییر اندازه کششی به نسبت ابعاد آموزش دیده است. | CLIP_VISION_OUTPUT | خیر | - |
| `previous_frames` | فقط SCAIL-2. خروجی کامل رمزگشایی‌شده تکه قبلی. فقط آخرین `previous_frame_count` فریم به‌عنوان لنگر ادامه استفاده می‌شوند. | IMAGE | خیر | - |

**نکته:**

- ورودی‌های `pose_video` و `pose_video_mask` از موقعیت `video_frame_offset` به بعد برش می‌خورند؛ اگر ویدیو فریمی بعد از آن آفست نداشته باشد، نادیده گرفته می‌شود. سپس هر دو با هم تا کوتاه‌ترین طول کوتاه می‌شوند و به حداکثر `length` فریم محدود می‌شوند. `pose_video` قبل از رمزگذاری به نصف رزولوشن ویدیوی اصلی کوچک می‌شود.
- ورودی `reference_image_mask` فقط زمانی اعمال می‌شود که `reference_image` نیز ارائه شده باشد. هر تصویر در batch ورودی `reference_image` به‌صورت جداگانه به‌عنوان یک مرجع نهان تک‌فریمی رمزگذاری می‌شود. در حالت جایگزینی (`replacement_mode=True`)، تصاویر مرجع با استفاده از ماسک تصویر مرجع به‌عنوان مات آلفا روی پس‌زمینه سیاه ترکیب می‌شوند.
- وقتی `clip_vision_output` ارائه می‌شود، روی هر دو شرطی‌سازی مثبت و منفی اعمال می‌شود.
- وقتی `previous_frames` ارائه می‌شود، فقط آخرین `previous_frame_count` فریم به‌عنوان لنگر ادامه استفاده می‌شوند. تانسور نهان خروجی به‌صورت جزئی با رمزگذاری این فریم‌ها پر می‌شود، یک ماسک نویز در خروجی نهان گنجانده می‌شود و `video_frame_offset` با کم کردن تعداد فریم‌های نگه‌داشته‌شده تنظیم می‌شود (هرگز کمتر از 0 نمی‌شود).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت اصلاح‌شده، که احتمالاً حاوی latent های تصویر مرجع، خروجی CLIP vision، latent های ویدیوی ژست، ماسک‌های محرک، ماسک‌های مرجع یا latent های فریم قبلی است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده، که احتمالاً حاوی latent های تصویر مرجع، خروجی CLIP vision، latent های ویدیوی ژست، ماسک‌های محرک، ماسک‌های مرجع یا latent های فریم قبلی است. | CONDITIONING |
| `latent` | یک تانسور نهان خالی با شکل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`. وقتی `previous_frames` ارائه شود، تانسور نهان به‌صورت جزئی با فریم‌های قبلی رمزگذاری‌شده پر می‌شود و یک ماسک نویز در آن گنجانده می‌شود. | LATENT |
| `video_frame_offset` | آفست تنظیم‌شده + طول. برای تولید ویدیوی ترتیبی به تکه بعدی وصل کنید. | INT |
