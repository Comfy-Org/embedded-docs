# ترميز VAE (مبسط)

تقوم عقدة VAEEncodeTiled بمعالجة الصور عبر تقسيمها إلى بلاطات أصغر وترميزها باستخدام مشفّر تلقائي تبايني (Variational Autoencoder). يتيح هذا النهج القائم على البلاطات التعامل مع الصور الكبيرة التي قد تتجاوز حدود الذاكرة لولا ذلك. تدعم العقدة نماذج VAE الخاصة بالصور والفيديو، مع عناصر تحكم منفصلة للتجزئة إلى بلاطات بالنسبة للأبعاد المكانية والزمنية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `pixels` | بيانات الصورة المدخلة المراد ترميزها. | IMAGE | نعم | - |
| `vae` | نموذج المشفّر التلقائي التبايني المستخدم للترميز. | VAE | نعم | - |
| `tile_size` | حجم كل بلاطة للمعالجة المكانية (الافتراضي: 512). إعداد متقدم. | INT | نعم | 64-4096 (step: 64) |
| `overlap` | مقدار التداخل بين البلاطات المتجاورة (الافتراضي: 64). إعداد متقدم. | INT | نعم | 0-4096 (step: 32) |
| `temporal_size` | يُستخدم فقط مع نماذج VAE الخاصة بالفيديو: عدد الإطارات المراد ترميزها في المرة الواحدة (الافتراضي: 64). إعداد متقدم. | INT | نعم | 8-4096 (step: 4) |
| `temporal_overlap` | يُستخدم فقط مع نماذج VAE الخاصة بالفيديو: عدد الإطارات المراد تداخلها (الافتراضي: 8). إعداد متقدم. | INT | نعم | 4-4096 (step: 4) |

**ملاحظة:** المعاملان `temporal_size` و`temporal_overlap` لا يكونان ذوي صلة إلا عند استخدام نماذج VAE الخاصة بالفيديو، وليس لهما أي تأثير على نماذج VAE القياسية للصور.
