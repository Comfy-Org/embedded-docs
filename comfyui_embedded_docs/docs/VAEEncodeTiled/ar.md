# ترميز VAE (مبسط)

يعالج VAEEncodeTiled الصور عن طريق تقسيمها إلى أجزاء أصغر وترميزها باستخدام الترميز التلقائي التبايني (Variational Autoencoder). يسمح هذا الأسلوب القائم على الأجزاء بمعالجة الصور الكبيرة التي قد تتجاوز حدود الذاكرة. يدعم العقد كلاً من VAEs الخاصة بالصور والفيديو، مع عناصر تحكم منفصلة للتجزئة في الأبعاد المكانية والزمانية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `بكسلات` | بيانات الصورة المدخلة المطلوب ترميزها | IMAGE | نعم | - |
| `vae` | نموذج الترميز التلقائي التبايني (VAE) المستخدم في الترميز | VAE | نعم | - |
| `حجم القطعة` | حجم كل جزء للمعالجة المكانية (الافتراضي: 512) | INT | نعم | 64-4096 (step: 64) |
| `التداخل` | مقدار التداخل بين الأجزاء المتجاورة (الافتراضي: 64) | INT | نعم | 0-4096 (step: 32) |
| `الحجم الزمني` | يُستخدم فقط مع VAEs الخاصة بالفيديو: عدد الإطارات المطلوب ترميزها في المرة الواحدة (الافتراضي: 64) | INT | نعم | 8-4096 (step: 4) |
| `التداخل الزمني` | يُستخدم فقط مع VAEs الخاصة بالفيديو: عدد الإطارات المتداخلة (الافتراضي: 8) | INT | نعم | 4-4096 (step: 4) |

**ملاحظة:** يكون المعاملان `temporal_size` و `temporal_overlap` ذو صلة فقط عند استخدام VAEs الخاصة بالفيديو، وليس لهما أي تأثير على VAEs القياسية للصور.

## المخرجات

| --- | --- | --- |
