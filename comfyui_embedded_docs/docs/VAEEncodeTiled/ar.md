# ترميز VAE (مبسط)

تقوم عقدة `VAEEncodeTiled` بمعالجة الصور عن طريق تقسيمها إلى قطع أصغر وترميزها باستخدام مشفر تلقائي متغير (Variational Autoencoder - VAE). يتيح هذا الأسلوب التعامل مع الصور الكبيرة التي قد تتجاوز حدود الذاكرة. تدعم العقدة كلاً من مشفرات VAE للصور والفيديو، مع عناصر تحكم منفصلة للتقطيع في الأبعاد المكانية والزمانية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `pixels` | بيانات الصورة المدخلة التي سيتم ترميزها | IMAGE | نعم | - |
| `vae` | نموذج المشفر التلقائي المتغير المستخدم في الترميز | VAE | نعم | - |
| `tile_size` | حجم كل قطعة للمعالجة المكانية (الافتراضي: 512) | INT | نعم | 64-4096 (step: 64) |
| `overlap` | مقدار التداخل بين القطع المتجاورة (الافتراضي: 64) | INT | نعم | 0-4096 (step: 32) |
| `temporal_size` | يُستخدم فقط مع مشفرات VAE للفيديو: عدد الإطارات التي يتم ترميزها في المرة الواحدة (الافتراضي: 64) | INT | نعم | 8-4096 (step: 4) |
| `temporal_overlap` | يُستخدم فقط مع مشفرات VAE للفيديو: عدد الإطارات المتداخلة (الافتراضي: 8) | INT | نعم | 4-4096 (step: 4) |

**ملاحظة:** تكون المعاملان `temporal_size` و`temporal_overlap` ذوي صلة فقط عند استخدام مشفرات VAE للفيديو، وليس لهما أي تأثير على مشفرات VAE القياسية للصور.
