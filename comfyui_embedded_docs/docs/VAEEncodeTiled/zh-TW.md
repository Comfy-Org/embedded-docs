# VAE 編碼（分割區塊）

VAEEncodeTiled 透過將影像分割成較小的圖磚，並使用變分自動編碼器對其進行編碼來處理影像。這種分塊方式可處理原本可能超出記憶體限制的大型影像。此節點同時支援影像與影片 VAE，並針對空間與時間維度提供個別的分塊控制。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `像素` | 要編碼的輸入影像資料。 | IMAGE | 是 | - |
| `vae` | 用於編碼的變分自動編碼器模型。 | VAE | 是 | - |
| `區塊大小` | 空間處理時每個圖磚的大小（預設：512）。進階設定。 | INT | 是 | 64-4096 （步進值：64） |
| `重疊` | 相鄰圖磚之間的重疊量（預設：64）。進階設定。 | INT | 是 | 0-4096 （步進值：32） |
| `時間區塊大小` | 僅用於影片 VAE：一次編碼的影格數量（預設：64）。進階設定。 | INT | 是 | 8-4096 （步進值：4） |
| `時間重疊` | 僅用於影片 VAE：要重疊的影格數量（預設：8）。進階設定。 | INT | 是 | 4-4096 （步進值：4） |

**注意：** `temporal_size` 與 `temporal_overlap` 參數僅在使用影片 VAE 時相關，對標準影像 VAE 沒有影響。
