# Кодировать VAE (плитками)

VAEEncodeTiled обрабатывает изображения, разбивая их на более мелкие тайлы и кодируя их с помощью вариационного автоэнкодера. Такой тайловый подход позволяет обрабатывать большие изображения, которые иначе могли бы превысить ограничения памяти. Узел поддерживает VAE как для изображений, так и для видео, с отдельными настройками разбиения на тайлы для пространственных и временных измерений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `пиксели` | Входные данные изображения для кодирования. | IMAGE | Да | - |
| `vae` | Модель вариационного автоэнкодера, используемая для кодирования. | VAE | Да | - |
| `размер_плитки` | Размер каждого тайла для пространственной обработки (по умолчанию: 512). Расширенная настройка. | INT | Да | 64-4096 (шаг: 64) |
| `перекрытие` | Величина перекрытия между соседними тайлами (по умолчанию: 64). Расширенная настройка. | INT | Да | 0-4096 (шаг: 32) |
| `temporal_size` | Используется только для видео-VAE: количество кадров, кодируемых за один раз (по умолчанию: 64). Расширенная настройка. | INT | Да | 8-4096 (шаг: 4) |
| `temporal_overlap` | Используется только для видео-VAE: количество перекрывающихся кадров (по умолчанию: 8). Расширенная настройка. | INT | Да | 4-4096 (шаг: 4) |

**Примечание:** Параметры `temporal_size` и `temporal_overlap` актуальны только при использовании видео-VAE и не влияют на стандартные VAE для изображений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Закодированное латентное представление входного изображения. | LATENT |
