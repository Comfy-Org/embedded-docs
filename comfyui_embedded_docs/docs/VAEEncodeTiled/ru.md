# Кодировать VAE (плитками)

Узел VAEEncodeTiled обрабатывает изображения, разбивая их на более мелкие тайлы и кодируя их с помощью вариационного автокодировщика. Такой подход на основе тайлов позволяет обрабатывать большие изображения, которые в противном случае могут превысить ограничения памяти. Узел поддерживает VAE как для изображений, так и для видео, с отдельными параметрами управления тайлингом для пространственных и временных измерений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `pixels` | Входные данные изображения для кодирования | IMAGE | Да | - |
| `vae` | Модель вариационного автокодировщика, используемая для кодирования | VAE | Да | - |
| `tile_size` | Размер каждого тайла для пространственной обработки (по умолчанию: 512) | INT | Да | 64-4096 (шаг: 64) |
| `overlap` | Величина перекрытия между соседними тайлами (по умолчанию: 64) | INT | Да | 0-4096 (шаг: 32) |
| `temporal_size` | Используется только для видео VAE: количество кадров, кодируемых за один раз (по умолчанию: 64) | INT | Да | 8-4096 (шаг: 4) |
| `temporal_overlap` | Используется только для видео VAE: количество перекрывающихся кадров (по умолчанию: 8) | INT | Да | 4-4096 (шаг: 4) |

**Примечание:** Параметры `temporal_size` и `temporal_overlap` актуальны только при использовании видео VAE и не влияют на стандартные VAE для изображений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Закодированное латентное представление входного изображения | LATENT |
