# Кодировать VAE (плитками)

VAEEncodeTiled обрабатывает изображения, разбивая их на меньшие тайлы и кодируя их с помощью вариационного автоэнкодера. Такой подход с разбиением на тайлы позволяет работать с большими изображениями, которые в противном случае могут превысить ограничения памяти. Узел поддерживает как VAE для изображений, так и для видео, с отдельными элементами управления тайлами для пространственных и временных измерений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `пиксели` | Входные данные изображения для кодирования | IMAGE | Да | - |
| `vae` | Модель вариационного автоэнкодера, используемая для кодирования | VAE | Да | - |
| `размер_плитки` | Размер каждого тайла для пространственной обработки (по умолчанию: 512) | INT | Да | 64-4096 (шаг: 64) |
| `перекрытие` | Величина перекрытия между соседними тайлами (по умолчанию: 64) | INT | Да | 0-4096 (шаг: 32) |
| `temporal_size` | Используется только для видео VAE: количество кадров для кодирования за один раз (по умолчанию: 64) | INT | Да | 8-4096 (шаг: 4) |
| `temporal_overlap` | Используется только для видео VAE: количество перекрывающихся кадров (по умолчанию: 8) | INT | Да | 4-4096 (шаг: 4) |

**Примечание:** Параметры `temporal_size` и `temporal_overlap` актуальны только при использовании видео VAE и не влияют на стандартные VAE для изображений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Закодированное латентное представление входного изображения | LATENT |
