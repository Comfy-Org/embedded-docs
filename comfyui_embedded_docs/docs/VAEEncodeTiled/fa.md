# کدگذاری VAE (کاشی‌بندی‌شده)

VAEEncodeTiled تصاویر را با تقسیم آن‌ها به کاشی‌های کوچک‌تر و رمزگذاری با استفاده از یک خودرمزگذار تغییراتی پردازش می‌کند. این رویکرد کاشی‌بندی‌شده امکان پردازش تصاویر بزرگ را فراهم می‌کند که در غیر این صورت ممکن است از محدودیت‌های حافظه فراتر روند. این گره از VAEهای تصویری و ویدیویی پشتیبانی می‌کند و کنترل‌های جداگانه‌ای برای کاشی‌بندی در ابعاد مکانی و زمانی دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `pixels` | داده تصویر ورودی که باید رمزگذاری شود. | IMAGE | بله | - |
| `vae` | مدل خودرمزگذار تغییراتی که برای رمزگذاری استفاده می‌شود. | VAE | بله | - |
| `tile_size` | اندازه هر کاشی برای پردازش مکانی (پیش‌فرض: 512). تنظیم پیشرفته. | INT | بله | 64-4096 (گام: 64) |
| `overlap` | میزان هم‌پوشانی بین کاشی‌های مجاور (پیش‌فرض: 64). تنظیم پیشرفته. | INT | بله | 0-4096 (گام: 32) |
| `temporal_size` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌هایی که در هر بار رمزگذاری می‌شوند (پیش‌فرض: 64). تنظیم پیشرفته. | INT | بله | 8-4096 (گام: 4) |
| `temporal_overlap` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌های هم‌پوشان (پیش‌فرض: 8). تنظیم پیشرفته. | INT | بله | 4-4096 (گام: 4) |

**نکته:** پارامترهای `temporal_size` و `temporal_overlap` تنها هنگام استفاده از VAEهای ویدیویی مرتبط هستند و بر VAEهای استاندارد تصویری هیچ تأثیری ندارند.
