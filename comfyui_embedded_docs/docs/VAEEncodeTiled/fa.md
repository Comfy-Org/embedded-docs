# کدگذاری VAE (کاشی‌بندی‌شده)

گره `VAEEncodeTiled` تصاویر را با تقسیم آن‌ها به تایل‌های کوچک‌تر و رمزگذاری آن‌ها با استفاده از یک خودرمزنگار متغیر (VAE) پردازش می‌کند. این رویکرد تایل‌بندی امکان مدیریت تصاویر بزرگی را فراهم می‌کند که در غیر این صورت ممکن است از محدودیت‌های حافظه فراتر روند. این گره از هر دو نوع VAE تصویری و ویدیویی پشتیبانی می‌کند و کنترل‌های تایل‌بندی جداگانه‌ای برای ابعاد مکانی و زمانی دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `pixels` | داده‌های تصویر ورودی برای رمزگذاری | IMAGE | بله | - |
| `vae` | مدل خودرمزنگار متغیر (VAE) مورد استفاده برای رمزگذاری | VAE | بله | - |
| `tile_size` | اندازه هر تایل برای پردازش مکانی (پیش‌فرض: 512) | INT | بله | 64-4096 (گام: 64) |
| `overlap` | میزان همپوشانی بین تایل‌های مجاور (پیش‌فرض: 64) | INT | بله | 0-4096 (گام: 32) |
| `temporal_size` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌هایی که در هر بار رمزگذاری می‌شوند (پیش‌فرض: 64) | INT | بله | 8-4096 (گام: 4) |
| `temporal_overlap` | فقط برای VAEهای ویدیویی استفاده می‌شود: تعداد فریم‌های همپوشانی (پیش‌فرض: 8) | INT | بله | 4-4096 (گام: 4) |

**نکته:** پارامترهای `temporal_size` و `temporal_overlap` تنها هنگام استفاده از VAEهای ویدیویی مرتبط هستند و هیچ تأثیری بر VAEهای استاندارد تصویری ندارند.
