# کدگذاری VAE (کاشی‌بندی‌شده)

VAEEncodeTiled با تقسیم تصاویر به تایل‌های کوچک‌تر و کدگذاری آن‌ها با استفاده از خودرمزگذار متغیر (Variational Autoencoder)، آن‌ها را پردازش می‌کند. این رویکرد تایل‌بندی شده امکان مدیریت تصاویر بزرگ را فراهم می‌کند که در غیر این صورت ممکن است از محدودیت حافظه فراتر روند. این گره از هر دو خودرمزگذار تصویری و ویدیویی پشتیبانی می‌کند و دارای کنترل‌های تایل‌بندی جداگانه برای ابعاد مکانی و زمانی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `پیکسل‌ها` | داده‌های تصویر ورودی که باید کدگذاری شوند | IMAGE | بله | - |
| `vae` | مدل خودرمزگذار متغیر مورد استفاده برای کدگذاری | VAE | بله | - |
| `اندازه کاشی` | اندازه هر تایل برای پردازش مکانی (پیش‌فرض: 512) | INT | بله | 64-4096 (step: 64) |
| `همپوشانی` | میزان همپوشانی بین تایل‌های مجاور (پیش‌فرض: 64) | INT | بله | 0-4096 (step: 32) |
| `اندازه زمانی` | فقط برای خودرمزگذارهای ویدیویی استفاده می‌شود: تعداد فریم‌هایی که در هر بار کدگذاری می‌شوند (پیش‌فرض: 64) | INT | بله | 8-4096 (step: 4) |
| `همپوشانی زمانی` | فقط برای خودرمزگذارهای ویدیویی استفاده می‌شود: میزان فریم‌های همپوشانی (پیش‌فرض: 8) | INT | بله | 4-4096 (step: 4) |

**نکته:** پارامترهای `temporal_size` و `temporal_overlap` فقط هنگام استفاده از خودرمزگذارهای ویدیویی مرتبط هستند و هیچ تأثیری بر خودرمزگذارهای استاندارد تصویری ندارند.
