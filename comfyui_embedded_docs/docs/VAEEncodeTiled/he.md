# קידוד VAE (אריחים)

VAEEncodeTiled מעבד תמונות על ידי פיצולן לאריחים קטנים יותר וקידודן באמצעות מקודד אוטומטי משתנה (Variational Autoencoder). גישה מבוססת אריחים זו מאפשרת להתמודד עם תמונות גדולות שאחרת עלולות לחרוג ממגבלות הזיכרון. הצומת תומך הן ב-VAE לתמונות והן ב-VAE לווידאו, עם בקרות אריחים נפרדות עבור ממדים מרחביים וזמניים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `pixels` | נתוני תמונת הקלט שיש לקודד. | IMAGE | כן | - |
| `vae` | מודל המקודד האוטומטי המשתנה (VAE) המשמש לקידוד. | VAE | כן | - |
| `tile_size` | גודל כל אריח לעיבוד מרחבי (ברירת מחדל: 512). הגדרה מתקדמת. | INT | כן | 64-4096 (step: 64) |
| `overlap` | מידת החפיפה בין אריחים סמוכים (ברירת מחדל: 64). הגדרה מתקדמת. | INT | כן | 0-4096 (step: 32) |
| `temporal_size` | משמש רק עבור VAE לווידאו: מספר הפריימים לקידוד בכל פעם (ברירת מחדל: 64). הגדרה מתקדמת. | INT | כן | 8-4096 (step: 4) |
| `temporal_overlap` | משמש רק עבור VAE לווידאו: מספר הפריימים לחפיפה (ברירת מחדל: 8). הגדרה מתקדמת. | INT | כן | 4-4096 (step: 4) |

**הערה:** הפרמטרים `temporal_size` ו-`temporal_overlap` רלוונטיים רק בעת שימוש ב-VAE לווידאו ואין להם השפעה על VAE רגיל לתמונות.
