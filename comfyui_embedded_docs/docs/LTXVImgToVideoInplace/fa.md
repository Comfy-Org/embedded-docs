# LTXVImgToVideoInplace

گره `LTXVImgToVideoInplace` با رمزگذاری یک تصویر ورودی به فریم‌های ابتدایی، یک نمایش نهفته ویدیویی را شرطی می‌کند. این گره با استفاده از یک VAE تصویر را در فضای نهفته رمزگذاری کرده و سپس فریم‌های ابتدایی نمونه‌های ویدیوی نهفته را با این تصویر رمزگذاری‌شده جایگزین می‌کند. یک ماسک نویز اعمال می‌شود تا قدرت شرطی‌سازی مشخص کند که تصویر در طول تولید، چقدر بر آن فریم‌های ابتدایی تأثیر می‌گذارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
| --- | --- | --- | --- | --- |
| `vae` | مدل VAE که برای رمزگذاری تصویر ورودی در فضای نهفته استفاده می‌شود. | VAE | بله | - |
| `image` | تصویر ورودی که باید رمزگذاری شده و برای شرطی‌سازی نهفته ویدیو استفاده شود. | IMAGE | بله | - |
| `latent` | نمایش نهفته ویدیوی هدف که قرار است تغییر یابد. | LATENT | بله | - |
| `strength` | قدرت شرطی‌سازی تصویر رمزگذاری‌شده بر فریم‌های نهفته ابتدایی را کنترل می‌کند. مقدار 1.0 فریم‌های ابتدایی را کاملاً شرطی می‌کند، در حالی که مقادیر پایین‌تر شرطی‌سازی ضعیف‌تری اعمال می‌کنند. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 1.0 |
| `bypass` | شرطی‌سازی را دور می‌زند. وقتی فعال باشد، گره ورودی `latent` را بدون تغییر برمی‌گرداند. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**نکته:** تصویر `image` به‌طور خودکار (با درون‌یابی دوخطی) تغییر اندازه می‌دهد تا با ابعاد فضایی موردنیاز `vae` برای رمزگذاری، بر اساس عرض و ارتفاع ورودی `latent`، مطابقت یابد. تنها ۳ کانال رنگی اول (RGB) تصویر استفاده می‌شود؛ هر کانال آلفا نادیده گرفته می‌شود.
