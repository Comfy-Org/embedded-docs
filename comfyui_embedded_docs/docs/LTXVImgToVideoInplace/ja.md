# LTXVImgToVideoInplace

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `vae` | 入力画像を潜在空間にエンコードするために使用される VAE モデル。 | VAE | はい | - |
| `image` | エンコードされ、ビデオ潜在表現の条件付けに使用される入力画像。 | IMAGE | はい | - |
| `latent` | 変更対象となるターゲットの潜在ビデオ表現。 | LATENT | はい | - |
| `strength` | 初期潜在フレームに対するエンコードされた画像の条件付けの強さを制御します。値 1.0 は初期フレームを完全に条件付けし、それより低い値はより弱い条件付けを適用します。(デフォルト: 1.0) | FLOAT | いいえ | 0.0 - 1.0 |
| `bypass` | 条件付けをバイパスします。有効にすると、ノードは入力潜在表現をそのまま返します。(デフォルト: False) | BOOLEAN | いいえ | - |

**注:** `image` は、`latent` 入力の幅と高さに基づいて、`vae` がエンコードに必要とする空間次元に合わせて自動的にリサイズ（バイリニア補間）されます。画像の最初の 3 つのカラーチャンネル（RGB）のみが使用され、アルファチャンネルは無視されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `latent` | 変更された潜在ビデオ表現。更新されたサンプルと、初期フレームに条件付けの強さを適用する `noise_mask` が含まれます。 | LATENT |
