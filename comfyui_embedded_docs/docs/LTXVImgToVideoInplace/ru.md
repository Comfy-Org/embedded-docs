# LTXVImgToVideoInplace

Узел LTXVImgToVideoInplace выполняет кондиционирование латентного видео-представления, кодируя входное изображение в его начальные кадры. Процесс работает следующим образом: с помощью VAE изображение кодируется в скрытое пространство, после чего первые кадры латентных видео-сэмплов заменяются этим закодированным изображением. Применяется маска шума, поэтому сила кондиционирования определяет, насколько сильно изображение влияет на эти начальные кадры во время генерации.

## Входные параметры

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования входного изображения в скрытое пространство. | VAE | Да | - |
| `image` | Входное изображение, которое будет закодировано и использовано для кондиционирования видеолатента. | IMAGE | Да | - |
| `latent` | Целевое латентное видео-представление, которое требуется изменить. | LATENT | Да | - |
| `strength` | Управляет силой кондиционирования закодированного изображения на начальные латентные кадры. Значение 1.0 полностью кондиционирует начальные кадры, а более низкие значения создают более слабое кондиционирование. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 1.0 |
| `bypass` | Обходит кондиционирование. При включении узел возвращает входной латент без изменений. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** `image` будет автоматически изменён (билинейная интерполяция) для соответствия пространственным размерам, требуемым `vae` для кодирования, на основе ширины и высоты входного `latent`. Используются только первые 3 цветовых канала (RGB) изображения; любой альфа-канал игнорируется.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Изменённое латентное видео-представление. Содержит обновлённые сэмплы и `noise_mask`, который применяет силу кондиционирования к начальным кадрам. | LATENT |
