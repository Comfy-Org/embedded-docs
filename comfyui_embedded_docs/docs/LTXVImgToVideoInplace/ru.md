# LTXVImgToVideoInplace

LTXVImgToVideoInplace кодирует входное изображение в латентное пространство и помещает закодированные кадры в начало существующего латентного видео. Значение `strength` управляет тем, насколько сильно закодированное изображение влияет на начальные кадры, а когда включён `bypass`, входной латент возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования входного изображения в латентное пространство. | VAE | Да | - |
| `изображение` | Входное изображение, которое будет закодировано и использовано для управления латентным видео. | IMAGE | Да | - |
| `latent` | Целевое латентное представление видео, которое будет изменено. | LATENT | Да | - |
| `интенсивность` | Управляет тем, насколько сильно закодированное изображение влияет на начальные кадры латента. Значение 1.0 полностью обусловливает начальные кадры закодированным изображением, а более низкие значения влияют слабее. Маска шума для начальных кадров устанавливается равной `1.0 - strength`. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 1.0 |
| `обход` | Отключает обусловливание. Когда включён, узел возвращает входной латент без изменений. (по умолчанию: False) | BOOLEAN | Нет | True or False |

**Примечание:** Изображение `image` будет автоматически масштабировано до пространственных размеров, требуемых моделью `vae` для кодирования, на основе ширины и высоты входного латента `latent`. При кодировании используются только RGB-каналы изображения `image`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Результирующее латентное представление видео. Когда обходной режим отключён, оно содержит обновлённые `samples` и `noise_mask`, применяющий силу обусловливания к начальным кадрам. Когда обходной режим включён, возвращается входной латент без изменений. | LATENT |
