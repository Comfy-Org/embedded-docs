# LTXVImgToVideoInplace

LTXVImgToVideoInplace 노드는 입력 이미지를 초기 프레임으로 인코딩하여 비디오 잠재 표현을 조건화합니다. 이 노드는 VAE를 사용하여 이미지를 잠재 공간으로 인코딩한 다음, 인코딩된 이미지로 잠재 비디오 샘플의 첫 프레임을 대체하는 방식으로 작동합니다. 노이즈 마스크가 적용되어, 조건화 강도가 생성 중 이미지가 해당 초기 프레임에 미치는 영향을 제어합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `vae` | 입력 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `image` | 인코딩되어 비디오 잠재를 조건화하는 데 사용되는 입력 이미지입니다. | IMAGE | 예 | - |
| `latent` | 수정할 대상 잠재 비디오 표현입니다. | LATENT | 예 | - |
| `strength` | 인코딩된 이미지가 초기 잠재 프레임에 적용되는 조건화 강도를 제어합니다. 값 1.0은 초기 프레임을 완전히 조건화하며, 낮은 값은 더 약한 조건화를 적용합니다. (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 1.0 |
| `bypass` | 조건화를 우회합니다. 활성화하면 노드가 입력 잠재를 변경하지 않고 반환합니다. (기본값: False) | BOOLEAN | 아니요 | - |

**참고:** `image`는 `latent` 입력의 너비와 높이를 기준으로 `vae` 인코딩에 필요한 공간 차원과 일치하도록 자동으로 크기가 조정됩니다(이중 선형 보간). 이미지의 처음 3개 색상 채널(RGB)만 사용되며, 알파 채널은 무시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latent` | 수정된 잠재 비디오 표현입니다. 업데이트된 샘플과 초기 프레임에 조건화 강도를 적용하는 `noise_mask`를 포함합니다. | LATENT |
