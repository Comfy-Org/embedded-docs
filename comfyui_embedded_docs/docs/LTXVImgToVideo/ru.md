# LTXVImgToVideo

LTXVImgToVideo преобразует входное изображение в латентное представление видео для моделей генерации видео. Он изменяет размер изображения до запрошенной ширины и высоты, кодирует его с помощью VAE и помещает закодированные кадры в начало латентного представления видео, заполненного нулями. Параметр strength определяет, какая часть исходного содержимого изображения сохраняется или изменяется во время генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивные промпты кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `отрицательный` | Негативные промпты кондиционирования для избежания нежелательных элементов в видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения в латентное пространство | VAE | Да | - |
| `изображение` | Входное изображение, которое будет преобразовано в кадры видео | IMAGE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 768, шаг: 32) | INT | Нет | 64 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 512, шаг: 32) | INT | Нет | 64 to MAX_RESOLUTION |
| `длина` | Количество кадров в сгенерированном видео (по умолчанию: 97, шаг: 8) | INT | Нет | 9 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Нет | 1 до 4096 |
| `интенсивность` | Управление тем, какая часть исходного изображения сохраняется в первых кадрах сгенерированного видео. Значение 1.0 полностью сохраняет исходное изображение, тогда как 0.0 допускает максимальные изменения (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 |

Примечание: `width` и `height` изменяются с шагом 32 пикселя, а `length` — с шагом 8 кадров, что соответствует сжатию видео-латентного пространства (32x по пространственным измерениям и 8x по временному измерению). Видео-латент содержит ((length - 1) // 8) + 1 кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Положительное кондиционирование передается без изменений для использования со сгенерированным латентным представлением | CONDITIONING |
| `отрицательный` | Отрицательное кондиционирование передается без изменений для использования со сгенерированным латентным представлением | CONDITIONING |
| `латентный` | Видео-латентное представление, содержащее закодированные кадры изображения и шумовую маску, которая определяет, насколько сильно применяется кондиционирование во время генерации видео | LATENT |
