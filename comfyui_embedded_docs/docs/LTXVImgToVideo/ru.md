# LTXVImgToVideo

Узел LTXVImgToVideo подготавливает латентное представление для генерации видео из входного изображения. Изображение масштабируется до указанных ширины и высоты, кодируется с помощью VAE и помещается в первые кадры латентного представления. Шумовая маска создается с использованием `strength` для управления тем, какая часть исходного содержимого изображения сохраняется или изменяется, при этом положительное и отрицательное кондиционирование передаются без изменений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные кондиционирующие данные, передаваемые на вход и возвращаемые без изменений. | CONDITIONING | Да | - |
| `negative` | Отрицательные кондиционирующие данные, передаваемые на вход и возвращаемые без изменений. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения в латентное пространство. | VAE | Да | - |
| `image` | Входное изображение, которое масштабируется и кодируется для формирования начала латентного представления видео. | IMAGE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 768, шаг: 32). | INT | Да | 64 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 512, шаг: 32). | INT | Да | 64 to MAX_RESOLUTION |
| `length` | Количество кадров в генерируемом видео (по умолчанию: 97, шаг: 8). | INT | Да | 9 to MAX_RESOLUTION |
| `batch_size` | Количество видео для генерации в одном латентном батче (по умолчанию: 1). | INT | Да | 1 to 4096 |
| `strength` | Управляет тем, какая часть закодированного содержимого изображения сохраняется в первых кадрах латентного представления. Значение 1.0 полностью сохраняет исходное изображение, а 0.0 допускает максимальное изменение (по умолчанию: 1.0). | FLOAT | Да | 0.0 to 1.0 |

Примечание: `MAX_RESOLUTION` — это максимальное разрешение, допустимое в установке ComfyUI.

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительные кондиционирующие данные передаются без изменений. | CONDITIONING |
| `negative` | Отрицательные кондиционирующие данные передаются без изменений. | CONDITIONING |
| `latent` | Латентное представление видео, содержащее закодированное входное изображение в начале последовательности, а также шумовую маску на основе `strength`. | LATENT |
