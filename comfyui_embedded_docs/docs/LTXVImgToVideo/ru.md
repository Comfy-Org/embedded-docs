# LTXVImgToVideo

LTXVImgToVideo преобразует входное изображение в латентное представление видео для моделей генерации видео. Он изменяет размер изображения до заданных ширины и высоты, кодирует его с помощью VAE и размещает закодированные кадры в начале латента размера видео, заполненного нулями. Параметр `strength` определяет, какая часть исходного содержимого изображения сохраняется, а какая изменяется в процессе генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивные промпты кондиционирования для управления генерацией видео | CONDITIONING | Да | - |
| `отрицательный` | Негативные промпты кондиционирования для исключения определённых элементов в видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения в латентное пространство | VAE | Да | - |
| `изображение` | Входное изображение, которое будет преобразовано в видеокадры | IMAGE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 768, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 512, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `длина` | Количество кадров в генерируемом видео (по умолчанию: 97, шаг: 8) | INT | Да | от 9 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `интенсивность` | Управляет тем, насколько содержимое исходного изображения сохраняется в первых кадрах генерируемого видео. Значение 1.0 полностью сохраняет исходное изображение, а 0.0 допускает максимальное изменение (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 |

Примечание: `width` и `height` изменяются с шагом 32 пикселя, а `length` — с шагом 8 кадров, что соответствует сжатию латента видео (32x в пространственных измерениях и 8x во временном измерении). Латент видео содержит количество кадров, равное ((length - 1) // 8) + 1. Входное изображение масштабируется до `width` x `height` с помощью билинейного масштабирования с центральной обрезкой, и для кодирования используются только первые три канала.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование, передаваемое без изменений для использования со сгенерированным латентом | CONDITIONING |
| `negative` | Негативное кондиционирование, передаваемое без изменений для использования со сгенерированным латентом | CONDITIONING |
| `latent` | Латентное представление видео, содержащее закодированные кадры изображения и маску шума, которая управляет тем, насколько сильно кондиционирование применяется во время генерации видео | LATENT |
