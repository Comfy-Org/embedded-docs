# LTXV صورة إلى فيديو

تقوم عقدة LTXVImgToVideo بإعداد تمثيل كامن (latent) لتوليد فيديو من صورة إدخال. يتم تغيير حجم الصورة إلى العرض والارتفاع المطلوبين، وتشفيرها باستخدام VAE، ووضعها في الإطارات الكامنة الأولى. يتم إنشاء قناع ضوضاء باستخدام `strength` للتحكم في مقدار محتوى الصورة الأصلية الذي يتم الحفاظ عليه أو تعديله، ويتم تمرير التكييف الإيجابي والسلبي دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | بيانات التكييف الإيجابية المقدمة كمدخل وتُعاد دون تغيير. | CONDITIONING | نعم | - |
| `negative` | بيانات التكييف السلبية المقدمة كمدخل وتُعاد دون تغيير. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير صورة الإدخال إلى الفضاء الكامن. | VAE | نعم | - |
| `image` | صورة الإدخال التي يتم تغيير حجمها وتشفيرها لتشكيل بداية الفيديو الكامن. | IMAGE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 768، الخطوة: 32). | INT | نعم | 64 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 512، الخطوة: 32). | INT | نعم | 64 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في الفيديو المُولَّد (الافتراضي: 97، الخطوة: 8). | INT | نعم | 9 إلى MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو المراد توليدها في دفعة كامنة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |
| `strength` | يتحكم في مقدار محتوى الصورة المشفَّر الذي يتم الحفاظ عليه في الإطارات الكامنة الأولى. القيمة 1.0 تحافظ على الصورة الأصلية بالكامل، بينما تسمح القيمة 0.0 بأقصى قدر من التعديل (الافتراضي: 1.0). | FLOAT | نعم | 0.0 إلى 1.0 |

ملاحظة: `MAX_RESOLUTION` هو أقصى دقة تسمح بها تثبيتة ComfyUI.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي يُمرَّر دون تعديل. | CONDITIONING |
| `negative` | التكييف السلبي يُمرَّر دون تعديل. | CONDITIONING |
| `latent` | الفيديو الكامن الذي يحتوي على صورة الإدخال المشفَّرة في بداية التسلسل، بالإضافة إلى قناع ضوضاء بناءً على `strength`. | LATENT |
