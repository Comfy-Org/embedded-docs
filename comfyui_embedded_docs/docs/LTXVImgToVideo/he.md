# LTXVImgToVideo

LTXVImgToVideo ממיר תמונת קלט לייצוג לטנטי של וידאו עבור מודלים ליצירת וידאו. הוא משנה את גודל התמונה לרוחב ולגובה המבוקשים, מקודד אותה באמצעות VAE, וממקם את הפריימים המקודדים בתחילתו של לטנט בגודל וידאו של אפסים. בקרת `strength` קובעת כמה מתוכן התמונה המקורית נשמר לעומת שינוי במהלך יצירת הווידאו.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | הנחיות קונדישנינג חיוביות להכוונת יצירת הווידאו | CONDITIONING | כן | - |
| `negative` | הנחיות קונדישנינג שליליות להימנעות מאלמנטים מסוימים בווידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונת הקלט למרחב לטנטי | VAE | כן | - |
| `image` | תמונת קלט להמרה לפריימי וידאו | IMAGE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 768, צעד: 32) | INT | כן | 64 to MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 512, צעד: 32) | INT | כן | 64 to MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו שנוצר (ברירת מחדל: 97, צעד: 8) | INT | כן | 9 to MAX_RESOLUTION |
| `batch_size` | מספר סרטוני הווידאו ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 to 4096 |
| `strength` | שליטה במידת שימור תוכן התמונה המקורית בפריימים הראשונים של הווידאו שנוצר. ערך 1.0 משמר את התמונה המקורית לחלוטין, בעוד 0.0 מאפשר שינוי מקסימלי (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 1.0 |

הערה: `width` ו-`height` משתנים בצעדים של 32 פיקסלים, ו-`length` משתנה בצעדים של 8 פריימים, בהתאמה לדחיסת הלטנט של הווידאו (פי 32 בממדים המרחביים ופי 8 בממד הזמני). הלטנט של הווידאו מכיל ((length - 1) // 8) + 1 פריימים. תמונת הקלט משתנה לגודל `width` x `height` באמצעות שינוי גודל דו-לינארי עם חיתוך מהמרכז, ורק שלושת הערוצים הראשונים משמשים לקידוד.
