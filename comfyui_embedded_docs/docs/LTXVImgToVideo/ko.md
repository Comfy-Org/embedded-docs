# LTXV 비디오 생성 (이미지 → 비디오)

LTXVImgToVideo 노드는 입력 이미지로부터 비디오를 생성하기 위한 잠재 표현을 준비합니다. 이미지는 요청된 너비와 높이로 크기가 조정되고, VAE로 인코딩되어 첫 번째 잠재 프레임에 배치됩니다. `strength`를 사용하여 노이즈 마스크가 생성되며, 이를 통해 원본 이미지 내용 중 얼마나 많은 부분이 보존되거나 수정되는지 제어합니다. 긍정 및 부정 컨디셔닝은 변경 없이 그대로 전달됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 입력으로 제공되고 변경 없이 반환되는 긍정 컨디셔닝 데이터입니다. | CONDITIONING | 예 | - |
| `negative` | 입력으로 제공되고 변경 없이 반환되는 부정 컨디셔닝 데이터입니다. | CONDITIONING | 예 | - |
| `vae` | 입력 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `image` | 비디오 잠재 표현의 시작을 구성하기 위해 크기가 조정되고 인코딩되는 입력 이미지입니다. | IMAGE | 예 | - |
| `width` | 출력 비디오의 픽셀 단위 너비입니다 (기본값: 768, 단계: 32). | INT | 예 | 64 ~ MAX_RESOLUTION |
| `height` | 출력 비디오의 픽셀 단위 높이입니다 (기본값: 512, 단계: 32). | INT | 예 | 64 ~ MAX_RESOLUTION |
| `length` | 생성된 비디오의 프레임 수입니다 (기본값: 97, 단계: 8). | INT | 예 | 9 ~ MAX_RESOLUTION |
| `batch_size` | 하나의 잠재 배치에서 생성할 비디오 수입니다 (기본값: 1). | INT | 예 | 1 ~ 4096 |
| `strength` | 첫 번째 잠재 프레임에서 인코딩된 이미지 내용 중 얼마나 많은 부분이 보존되는지 제어합니다. 값이 1.0이면 원본 이미지를 완전히 보존하고, 0.0이면 최대한 수정할 수 있습니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 |

참고: `MAX_RESOLUTION`은 ComfyUI 설치에서 허용되는 최대 해상도입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 수정 없이 전달되는 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 수정 없이 전달되는 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 시퀀스 시작 부분에 인코딩된 입력 이미지를 포함하고 `strength` 기반 노이즈 마스크를 함께 포함하는 비디오 잠재 표현입니다. | LATENT |
