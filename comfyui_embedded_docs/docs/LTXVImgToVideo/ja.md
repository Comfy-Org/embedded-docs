# LTXV画像からビデオへ

LTXVImgToVideo ノードは、入力画像からビデオを生成するための潜在表現を準備します。画像は指定された幅と高さにリサイズされ、VAE でエンコードされた後、最初の潜在フレームに配置されます。`strength` を使用してノイズマスクが作成され、元の画像コンテンツのどの程度を保持または変更するかを制御します。ポジティブおよびネガティブのコンディショニングは、変更されずにそのまま渡されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 入力として提供され、そのまま返されるポジティブコンディショニングデータです。 | CONDITIONING | はい | - |
| `negative` | 入力として提供され、そのまま返されるネガティブコンディショニングデータです。 | CONDITIONING | はい | - |
| `vae` | 入力画像を潜在空間にエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `image` | リサイズおよびエンコードされ、ビデオ潜在表現の先頭を形成する入力画像です。 | IMAGE | はい | - |
| `width` | 出力ビデオの幅（ピクセル単位）（デフォルト: 768、ステップ: 32）。 | INT | はい | 64 to MAX_RESOLUTION |
| `height` | 出力ビデオの高さ（ピクセル単位）（デフォルト: 512、ステップ: 32）。 | INT | はい | 64 to MAX_RESOLUTION |
| `length` | 生成されるビデオのフレーム数（デフォルト: 97、ステップ: 8）。 | INT | はい | 9 to MAX_RESOLUTION |
| `batch_size` | 1つの潜在バッチで生成するビデオの数（デフォルト: 1）。 | INT | はい | 1 to 4096 |
| `strength` | 最初の潜在フレームに保持されるエンコード済み画像コンテンツの量を制御します。1.0 の場合は元の画像を完全に保持し、0.0 の場合は最大限の変更を可能にします（デフォルト: 1.0）。 | FLOAT | はい | 0.0 to 1.0 |

注: `MAX_RESOLUTION` は、ComfyUI インストール環境で許可される最大解像度です。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 変更されずにそのまま渡されるポジティブコンディショニングです。 | CONDITIONING |
| `negative` | 変更されずにそのまま渡されるネガティブコンディショニングです。 | CONDITIONING |
| `latent` | シーケンスの先頭にエンコードされた入力画像と、`strength` に基づくノイズマスクを含むビデオ潜在表現です。 | LATENT |
