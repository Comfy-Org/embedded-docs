# LTXV 圖片轉影片

LTXVImgToVideo 將輸入圖片轉換為影片潛在表示，供影片生成模型使用。它會將圖片調整為指定的寬度和高度，使用 VAE 進行編碼，並將編碼後的幀放置在一個影片大小的零值潛在張量的開頭。強度控制決定影片生成過程中，原始圖片內容有多少被保留、多少被修改。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正向` | 用於引導影片生成的正向條件提示 | CONDITIONING | 是 | - |
| `負向` | 用於避免影片中出現特定元素的負向條件提示 | CONDITIONING | 是 | - |
| `vae` | 用於將輸入圖片編碼到潛在空間的 VAE 模型 | VAE | 是 | - |
| `影像` | 要轉換為影片幀的輸入圖片 | IMAGE | 是 | - |
| `寬度` | 輸出影片的寬度（像素）（預設值：768，步長：32） | INT | 否 | 64 to MAX_RESOLUTION |
| `高度` | 輸出影片的高度（像素）（預設值：512，步長：32） | INT | 否 | 64 to MAX_RESOLUTION |
| `長度` | 生成影片的幀數（預設值：97，步長：8） | INT | 否 | 9 to MAX_RESOLUTION |
| `批次大小` | 同時生成的影片數量（預設值：1） | INT | 否 | 1 至 4096 |
| `強度` | 控制生成影片的前幾幀中保留原始圖片內容的程度。值為 1.0 時完全保留原始圖片，值為 0.0 時允許最大程度的修改（預設值：1.0） | FLOAT | 否 | 0.0 至 1.0 |

注意：`width` 和 `height` 以 32 像素為步長變化，`length` 以 8 幀為步長變化，這與影片潛在壓縮（空間維度 32 倍、時間維度 8 倍）相對應。影片潛在張量包含 ((length - 1) // 8) + 1 幀。
