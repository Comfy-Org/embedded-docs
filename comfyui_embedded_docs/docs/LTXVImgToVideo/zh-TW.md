# LTXV 圖片轉影片

LTXVImgToVideo 會將輸入影像轉換為影片生成模型所需的影片潛在表示。它會將影像調整為指定的 `width` 與 `height`，使用 VAE 進行編碼，並將編碼後的影格放置於影片尺寸的零值潛在表示開頭。`strength` 控制會決定在影片生成期間保留多少原始影像內容，以及允許修改的程度。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正向` | 用於引導影片生成的正向條件提示 | CONDITIONING | 是 | - |
| `負向` | 用於避免影片中出現特定元素的負向條件提示 | CONDITIONING | 是 | - |
| `vae` | 用於將輸入影像編碼至潛在空間的 VAE 模型 | VAE | 是 | - |
| `影像` | 要轉換為影片影格的輸入影像 | IMAGE | 是 | - |
| `寬度` | 輸出影片寬度，單位為像素（預設：768，步長：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `高度` | 輸出影片高度，單位為像素（預設：512，步長：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `長度` | 產生的影片影格數（預設：97，步長：8） | INT | 是 | 9 to MAX_RESOLUTION |
| `批次大小` | 同時產生的影片數量（預設：1） | INT | 是 | 1 至 4096 |
| `強度` | 控制產生的影片前幾個影格中保留多少原始影像內容。數值 1.0 會完整保留原始影像，而 0.0 允許最大程度的修改（預設：1.0） | FLOAT | 是 | 0.0 至 1.0 |

注意：`width` 與 `height` 以 32 像素為單位變動，`length` 則以 8 影格為單位變動，這與影片潛在表示的壓縮方式相符（空間維度為 32 倍，時間維度為 8 倍）。影片潛在表示包含 ((length - 1) // 8) + 1 個影格。輸入影像會使用雙線性縮放並搭配中心裁切，調整為 `width` x `height`，且僅使用前三個通道進行編碼。
