# LTXVImgToVideo

گره LTXVImgToVideo یک نمایش نهفته برای تولید ویدیو از یک تصویر ورودی آماده می‌کند. تصویر به عرض و ارتفاع درخواستی تغییر اندازه داده می‌شود، با VAE رمزگذاری می‌گردد و در فریم‌های نهفته اول قرار می‌گیرد. یک ماسک نویز با استفاده از `strength` ایجاد می‌شود تا میزان حفظ یا تغییر محتوای تصویر اصلی کنترل شود و شرطی‌سازی مثبت و منفی بدون تغییر عبور داده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | داده‌های شرطی‌سازی مثبت که به‌عنوان ورودی ارائه شده و بدون تغییر بازگردانده می‌شوند. | CONDITIONING | بله | - |
| `negative` | داده‌های شرطی‌سازی منفی که به‌عنوان ورودی ارائه شده و بدون تغییر بازگردانده می‌شوند. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر ورودی به فضای نهفته. | VAE | بله | - |
| `image` | تصویر ورودی که تغییر اندازه داده شده و رمزگذاری می‌شود تا آغازگر ویدیوی نهفته باشد. | IMAGE | بله | - |
| `width` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 768، گام: 32). | INT | بله | 64 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 512، گام: 32). | INT | بله | 64 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی تولیدشده (پیش‌فرض: 97، گام: 8). | INT | بله | 9 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که در یک دسته نهفته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `strength` | میزان حفظ محتوای تصویر رمزگذاری‌شده در فریم‌های نهفته اول را کنترل می‌کند. مقدار 1.0 تصویر اصلی را کاملاً حفظ می‌کند، در حالی که 0.0 حداکثر تغییر را مجاز می‌سازد (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 1.0 |

توجه: `MAX_RESOLUTION` حداکثر وضوح مجاز در نصب ComfyUI است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت بدون تغییر عبور داده شده است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی بدون تغییر عبور داده شده است. | CONDITIONING |
| `latent` | ویدیوی نهفته شامل تصویر ورودی رمزگذاری‌شده در ابتدای دنباله، همراه با ماسک نویز مبتنی بر `strength`. | LATENT |
