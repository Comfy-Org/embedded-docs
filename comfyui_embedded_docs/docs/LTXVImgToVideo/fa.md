# LTXVImgToVideo

LTXVImgToVideo یک تصویر ورودی را به بازنمایی latent ویدیو برای مدل‌های تولید ویدیو تبدیل می‌کند. این گره تصویر را به عرض و ارتفاع درخواستی تغییر اندازه می‌دهد، آن را با VAE کدگذاری می‌کند و فریم‌های کدگذاری‌شده را در ابتدای یک latent هم‌اندازه ویدیو که از صفرها ساخته شده قرار می‌دهد. کنترل strength تعیین می‌کند که چه مقدار از محتوای تصویر اصلی در طول تولید ویدیو حفظ شود یا تغییر کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی‌سازی منفی برای اجتناب از عناصر خاص در ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای کدگذاری تصویر ورودی به فضای latent | VAE | بله | - |
| `image` | تصویر ورودی که به فریم‌های ویدیو تبدیل می‌شود | IMAGE | بله | - |
| `width` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 768، گام: 32) | INT | خیر | 64 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 512، گام: 32) | INT | خیر | 64 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی تولیدشده (پیش‌فرض: 97، گام: 8) | INT | خیر | 9 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌صورت همزمان تولید می‌شوند (پیش‌فرض: 1) | INT | خیر | 1 تا 4096 |
| `strength` | کنترل میزان حفظ محتوای تصویر اصلی در فریم‌های اول ویدیوی تولیدشده. مقدار 1.0 تصویر اصلی را کاملاً حفظ می‌کند، در حالی که 0.0 حداکثر تغییر را مجاز می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 تا 1.0 |

توجه: `width` و `height` با گام‌های 32 پیکسل تغییر می‌کنند و `length` با گام 8 فریم تغییر می‌کند که با فشرده‌سازی latent ویدیو (32 برابر در ابعاد مکانی و 8 برابر در بعد زمانی) مطابقت دارد. latent ویدیو شامل ((length - 1) // 8) + 1 فریم است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت بدون تغییر عبور داده شده تا با latent تولیدشده استفاده شود | CONDITIONING |
| `negative` | شرطی‌سازی منفی بدون تغییر عبور داده شده تا با latent تولیدشده استفاده شود | CONDITIONING |
| `latent` | بازنمایی latent ویدیو شامل فریم‌های تصویر کدگذاری‌شده و یک ماسک نویز که کنترل می‌کند شرطی‌سازی چقدر قوی در طول تولید ویدیو اعمال شود | LATENT |
