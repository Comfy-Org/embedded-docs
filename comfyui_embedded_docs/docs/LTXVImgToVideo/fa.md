# LTXVImgToVideo

LTXVImgToVideo یک تصویر ورودی را به یک نمایش latent ویدیویی برای مدل‌های تولید ویدیو تبدیل می‌کند. تصویر را به عرض و ارتفاع درخواستی تغییر اندازه می‌دهد، آن را با VAE کدگذاری می‌کند و فریم‌های کدگذاری‌شده را در ابتدای یک latent هم‌اندازه ویدیو و پر از صفر قرار می‌دهد. کنترل `strength` تعیین می‌کند که در حین تولید ویدیو چه مقدار از محتوای تصویر اصلی حفظ شود و چه مقدار تغییر کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی‌سازی منفی برای پرهیز از عناصر خاص در ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای کدگذاری تصویر ورودی به فضای latent | VAE | بله | - |
| `image` | تصویر ورودی برای تبدیل به فریم‌های ویدیو | IMAGE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 768، گام: 32) | INT | بله | 64 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 512، گام: 32) | INT | بله | 64 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی تولیدشده (پیش‌فرض: 97، گام: 8) | INT | بله | 9 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `strength` | کنترل میزان حفظ محتوای تصویر اصلی در فریم‌های اول ویدیوی تولیدشده. مقدار 1.0 تصویر اصلی را کاملاً حفظ می‌کند، در حالی که 0.0 حداکثر تغییر را مجاز می‌داند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |

نکته: `width` و `height` با گام‌های 32 پیکسلی تغییر می‌کنند و `length` با گام‌های 8 فریمی تغییر می‌کند که با فشرده‌سازی latent ویدیو مطابقت دارد (32 برابر در ابعاد مکانی و 8 برابر در بعد زمانی). latent ویدیو شامل ((length - 1) // 8) + 1 فریم است. تصویر ورودی با استفاده از مقیاس‌بندی دوخطی همراه با برش مرکزی به `width` x `height` تغییر اندازه داده می‌شود و فقط سه کانال اول برای کدگذاری استفاده می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت بدون تغییر عبور داده می‌شود تا با latent تولیدشده استفاده شود | CONDITIONING |
| `negative` | شرطی‌سازی منفی بدون تغییر عبور داده می‌شود تا با latent تولیدشده استفاده شود | CONDITIONING |
| `latent` | نمایش latent ویدیو شامل فریم‌های تصویر کدگذاری‌شده و یک ماسک نویز که کنترل می‌کند شرطی‌سازی در حین تولید ویدیو با چه شدتی اعمال شود | LATENT |
