# EmptyAceStepLatentAudio

Узел The Empty Ace Step 1.0 Latent Audio создает пустые латентные аудио-сэмплы заданной продолжительности. Он генерирует пакет тихих аудио-латентов, заполненных нулями, где длина рассчитывается на основе входных секунд и параметров обработки аудио. Этот узел полезен для инициализации рабочих процессов обработки аудио, требующих латентных представлений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `секунды` | Продолжительность аудио в секундах (по умолчанию: 120.0, шаг: 0.1) | FLOAT | Да | 1.0 - 1000.0 |
| `размер_пакета` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Возвращает пустые латентные аудио-сэмплы, заполненные нулями. Выходные данные содержат тензор `samples` и поле `type`, установленное в "audio". | LATENT |
