# EmptyAceStepLatentAudio

Узел `EmptyAceStepLatentAudio` создаёт пустые латентные аудиосэмплы заданной длительности. Он генерирует пакет тихих аудиолатентов, заполненных нулями; длина вычисляется на основе входного параметра `seconds` и параметров обработки аудио. Этот узел полезен для инициализации рабочих процессов обработки аудио, требующих латентных представлений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `seconds` | Длительность аудио в секундах (по умолчанию: 120.0) | FLOAT | Да | 1.0 - 1000.0 (шаг 0.1) |
| `batch_size` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Возвращает пустые латентные аудиосэмплы, заполненные нулями. Выходные данные содержат тензор `samples` и поле `type` со значением "audio". | LATENT |

Примечание: длина латентного представления вычисляется из значения `seconds` с использованием внутренней частоты дискретизации 44100 Гц по формуле `int(seconds × 44100 / 512 / 8)` кадров. Результирующий латентный тензор полностью заполнен нулями.
