# EmptyAceStepLatentAudio

Узел Empty Ace Step 1.0 Latent Audio создаёт пустые латентные аудиосэмплы заданной длительности. Он заполняет пакет беззвучных (полностью нулевых) аудиолатентов, длина которых рассчитывается из входного параметра `seconds` с использованием параметров обработки аудио. Обычно используется для инициализации аудиорабочих процессов, которым требуется латентное представление в качестве начальной точки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `секунды` | Длительность аудио в секундах (по умолчанию: 120.0, шаг: 0.1) | FLOAT | Да | 1.0 - 1000.0 |
| `размер_пакета` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Возвращает пустые латентные аудиосэмплы, заполненные нулями. Выход содержит тензор `samples` и поле `type`, установленное в "audio". | LATENT |
