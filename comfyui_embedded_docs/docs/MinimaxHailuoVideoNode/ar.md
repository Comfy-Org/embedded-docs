# MiniMax Hailuo فيديو

ينشئ مقاطع فيديو من نصوص تعليمات (Prompts) باستخدام نموذج MiniMax Hailuo-02. يمكنك اختياريًا توفير صورة بداية كإطار أول لإنشاء فيديو يستمر من تلك الصورة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt_text` | نص تعليمات لتوجيه توليد الفيديو. | STRING | نعم | - |
| `seed` | البذرة العشوائية المستخدمة لتوليد الضوضاء (الافتراضي: 0). | INT | لا | 0 إلى 18446744073709551615 |
| `first_frame_image` | صورة اختيارية لاستخدامها كإطار أول لتوليد فيديو. | IMAGE | لا | - |
| `prompt_optimizer` | تحسين الموجه لرفع جودة التوليد عند الحاجة (الافتراضي: True). | BOOLEAN | لا | - |
| `duration` | مدة الفيديو المُخرَج بالثواني (الافتراضي: 6). | COMBO | لا | `6`<br>`10` |
| `resolution` | أبعاد عرض الفيديو. 1080p تعني 1920×1080، و768p تعني 1366×768 (الافتراضي: "768P"). | COMBO | لا | `"768P"`<br>`"1080P"` |

**ملاحظات:**
- يجب أن يكون `prompt_text` نصًا غير فارغ عند عدم توفير `first_frame_image`.
- عند استخدام نموذج MiniMax-Hailuo-02 بدقة 1080P، تكون المدة محدودة بـ 6 ثوانٍ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
