# MiniMax Hailuo فيديو

يولد مقاطع فيديو من نصوص الأوامر باستخدام نموذج MiniMax Hailuo-02. يمكنك اختياريًا توفير صورة بداية كإطار أول لإنشاء فيديو يستمر من تلك الصورة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `نص_المُوجِّه` | نص الأمر لتوجيه توليد الفيديو. | STRING | نعم | - |
| `بذرة` | البذرة العشوائية المستخدمة لإنشاء الضوضاء (الافتراضي: 0). | INT | لا | 0 إلى 18446744073709551615 |
| `صورة_الإطار_الأول` | صورة اختيارية تُستخدم كإطار أول لتوليد فيديو. | IMAGE | لا | - |
| `prompt_optimizer` | تحسين الأمر لتحسين جودة التوليد عند الحاجة (الافتراضي: True). | BOOLEAN | لا | True<br>False |
| `duration` | طول الفيديو الناتج بالثواني (الافتراضي: 6). | COMBO | لا | 6<br>10 |
| `resolution` | أبعاد عرض الفيديو. 1080p تعني 1920x1080، و768p تعني 1366x768 (الافتراضي: "768P"). | COMBO | لا | "768P"<br>"1080P" |

**ملاحظة:** عند تعيين `resolution` إلى "1080P"، يكون `duration` محصورًا في 6 ثوانٍ. وعند عدم توفير `first_frame_image`، يجب ألا يكون `prompt_text` فارغًا.
