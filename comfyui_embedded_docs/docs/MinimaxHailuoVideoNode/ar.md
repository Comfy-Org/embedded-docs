# MiniMax Hailuo فيديو

يولّد مقاطع فيديو من أوامر نصية باستخدام نموذج MiniMax Hailuo-02. يمكنك اختياريًا توفير صورة بداية لاستخدامها كالإطار الأول، مما ينشئ فيديو يستمر من تلك الصورة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt_text` | أمر نصي لتوجيه توليد الفيديو (الافتراضي: فارغ). | STRING | نعم | - |
| `seed` | البذرة العشوائية المستخدمة لإنشاء الضوضاء (الافتراضي: 0). | INT | لا | 0 إلى 18446744073709551615 |
| `first_frame_image` | صورة اختيارية لاستخدامها كالإطار الأول لتوليد فيديو. | IMAGE | لا | - |
| `prompt_optimizer` | تحسين الأمر لرفع جودة التوليد عند الحاجة (الافتراضي: True). | BOOLEAN | لا | True<br>False |
| `duration` | طول فيديو المخرجات بالثواني (الافتراضي: 6). | COMBO | لا | 6<br>10 |
| `resolution` | أبعاد عرض الفيديو. 1080p تعني 1920x1080، و768p تعني 1366x768 (الافتراضي: "768P"). | COMBO | لا | "768P"<br>"1080P" |

**ملاحظة:** عندما يتم ضبط `resolution` على "1080P"، يقتصر `duration` على 6 ثوانٍ. وعندما لا يتم توفير `first_frame_image`، يجب ألا يكون `prompt_text` فارغًا.
