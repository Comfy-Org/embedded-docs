# ویدئوی MiniMax Hailuo

ویدیوهایی را از پرامپت‌های متنی با استفاده از مدل MiniMax Hailuo-02 تولید می‌کند. می‌توانید به‌صورت اختیاری یک تصویر شروع ارائه دهید تا به‌عنوان فریم اول استفاده شود؛ این کار ویدیویی می‌سازد که از همان تصویر ادامه می‌یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt_text` | پرامپت متنی برای راهنمایی تولید ویدیو (پیش‌فرض: خالی). | STRING | بله | - |
| `seed` | بذر تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). | INT | خیر | 0 تا 18446744073709551615 |
| `first_frame_image` | تصویر اختیاری برای استفاده به‌عنوان فریم اول جهت تولید ویدیو. | IMAGE | خیر | - |
| `prompt_optimizer` | در صورت نیاز، پرامپت را بهینه می‌کند تا کیفیت تولید بهبود یابد (پیش‌فرض: True). | BOOLEAN | خیر | True<br>False |
| `duration` | طول ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 6). | COMBO | خیر | 6<br>10 |
| `resolution` | ابعاد نمایش ویدیو. 1080p برابر 1920x1080 و 768p برابر 1366x768 است (پیش‌فرض: "768P"). | COMBO | خیر | "768P"<br>"1080P" |

**توجه:** وقتی `resolution` روی "1080P" تنظیم شود، `duration` به 6 ثانیه محدود می‌شود. وقتی `first_frame_image` ارائه نشود، `prompt_text` نباید خالی باشد.
