# ویدئوی MiniMax Hailuo

ویدیوهایی از روی متن پرامپت با استفاده از مدل MiniMax Hailuo-02 تولید می‌کند. می‌توانید به‌طور اختیاری یک تصویر شروع به‌عنوان فریم اول ارائه دهید تا ویدیویی ایجاد شود که از آن تصویر ادامه یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt_text` | متن پرامپت برای هدایت تولید ویدیو. | STRING | بله | - |
| `seed` | دانه تصادفی (seed) مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). | INT | خیر | 0 to 18446744073709551615 |
| `first_frame_image` | تصویر اختیاری برای استفاده به‌عنوان فریم اول برای تولید ویدیو. | IMAGE | خیر | - |
| `prompt_optimizer` | بهینه‌سازی پرامپت برای بهبود کیفیت تولید در صورت نیاز (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `duration` | طول ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 6). | COMBO | خیر | `6`<br>`10` |
| `resolution` | ابعاد نمایش ویدیو. 1080p معادل 1920x1080 و 768p معادل 1366x768 است (پیش‌فرض: "768P"). | COMBO | خیر | `"768P"`<br>`"1080P"` |

**نکات:**
- مقدار `prompt_text` باید یک رشته غیرخالی باشد زمانی که `first_frame_image` ارائه نشده است.
- هنگام استفاده از مدل MiniMax-Hailuo-02 با وضوح 1080P، مدت‌زمان به 6 ثانیه محدود می‌شود.
