# ویدئوی MiniMax Hailuo

ویدیوها را از روی متن راهنما با استفاده از مدل MiniMax Hailuo-02 تولید می‌کند. می‌توانید به‌صورت اختیاری یک تصویر شروع به‌عنوان فریم اول ارائه دهید تا ویدیویی ساخته شود که از آن تصویر ادامه می‌یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `متن پرامپت` | متن راهنما برای جهت‌دهی به تولید ویدیو. | STRING | بله | - |
| `بذر` | دانه تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). | INT | خیر | 0 تا 18446744073709551615 |
| `تصویر فریم اول` | تصویر اختیاری برای استفاده به‌عنوان فریم اول جهت تولید ویدیو. | IMAGE | خیر | - |
| `بهینه‌ساز پرامپت` | بهینه‌سازی متن راهنما برای بهبود کیفیت تولید در صورت نیاز (پیش‌فرض: True). | BOOLEAN | خیر | True<br>False |
| `مدت زمان` | طول ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 6). | COMBO | خیر | 6<br>10 |
| `وضوح تصویر` | ابعاد نمایش ویدیو. وضوح 1080p معادل 1920x1080 و وضوح 768p معادل 1366x768 است (پیش‌فرض: "768P"). | COMBO | خیر | "768P"<br>"1080P" |

**نکته:** زمانی که `resolution` روی "1080P" تنظیم شده باشد، `duration` به ۶ ثانیه محدود می‌شود. زمانی که `first_frame_image` ارائه نشده باشد، `prompt_text` نباید خالی باشد.
