# MiniMax Hailuo Видео

Генерирует видео по текстовым запросам с использованием модели MiniMax Hailuo-02. Можно дополнительно указать начальное изображение в качестве первого кадра, чтобы создать видео, продолжающееся с этого изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_text` | Текстовый запрос для управления генерацией видео. | STRING | Да | - |
| `seed` | Случайное зерно (seed), используемое для создания шума (по умолчанию: 0). | INT | Нет | 0 to 18446744073709551615 |
| `first_frame_image` | Необязательное изображение, используемое в качестве первого кадра для генерации видео. | IMAGE | Нет | - |
| `prompt_optimizer` | Оптимизировать запрос для улучшения качества генерации при необходимости (по умолчанию: True). | BOOLEAN | Нет | - |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 6). | COMBO | Нет | `6`<br>`10` |
| `resolution` | Размеры отображаемого видео. 1080p — это 1920x1080, 768p — это 1366x768 (по умолчанию: "768P"). | COMBO | Нет | `"768P"`<br>`"1080P"` |

**Примечания:**
- `prompt_text` должна быть непустой строкой, если не указано `first_frame_image`.
- При использовании модели MiniMax-Hailuo-02 с разрешением 1080P длительность ограничена 6 секундами.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
