# MiniMax Hailuo Видео

Генерирует видео по текстовым запросам с использованием модели MiniMax Hailuo-02. Вы можете дополнительно указать начальное изображение в качестве первого кадра, чтобы создать видео, продолжающееся с этого изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `текстовый_промпт` | Текстовый запрос для управления генерацией видео. | STRING | Да | - |
| `сид` | Случайное зерно (seed), используемое для создания шума (по умолчанию: 0). | INT | Нет | 0 до 18446744073709551615 |
| `изображение_первого_кадра` | Необязательное изображение для использования в качестве первого кадра для генерации видео. | IMAGE | Нет | - |
| `оптимизатор_промпта` | Оптимизировать запрос для улучшения качества генерации при необходимости (по умолчанию: True). | BOOLEAN | Нет | True<br>False |
| `длительность` | Длительность выходного видео в секундах (по умолчанию: 6). | COMBO | Нет | 6<br>10 |
| `разрешение` | Размеры отображаемого видео. 1080p — это 1920x1080, 768p — 1366x768 (по умолчанию: "768P"). | COMBO | Нет | "768P"<br>"1080P" |

**Примечание:** Когда для `resolution` установлено значение "1080P", `duration` ограничено 6 секундами. Если `first_frame_image` не указано, `prompt_text` не должно быть пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
