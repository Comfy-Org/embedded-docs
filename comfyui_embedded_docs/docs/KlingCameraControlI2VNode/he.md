# KlingCameraControlI2VNode

צומת Kling Image to Video Camera Control הופך תמונות סטילס לסרטונים קולנועיים עם תנועות מצלמה מקצועיות. צומת מיוחד זה של image-to-video מאפשר לך לשלוט בפעולות מצלמה וירטואליות הכוללות זום, סיבוב, הזזה אופקית (pan), הטיה (tilt) ותצוגת גוף ראשון, תוך שמירה על מיקוד בתמונה המקורית שלך. בקרת מצלמה נתמכת כעת רק במצב pro עם המודל kling-v1-5 במשך של 5 שניות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | תמונת עזר - כתובת URL או מחרוזת מקודדת Base64, לא יכולה לעלות על 10MB, רזולוציה לא פחות מ-300x300px, יחס גובה-רוחב בין 1:2.5 ל-2.5:1. אין לכלול קידומת data:image ב-Base64. | IMAGE | כן | - |
| `prompt` | הנחיית טקסט חיובית המתארת את תוכן הווידאו הרצוי. אורך מקסימלי 500 תווים. | STRING | כן | - |
| `negative_prompt` | הנחיית טקסט שלילית המתארת מה להימנע ממנו בווידאו הנוצר. אורך מקסימלי 500 תווים. | STRING | כן | - |
| `cfg_scale` | שולט בחוזק הנחיית הטקסט. ערכים גבוהים יותר גורמים לפלט לעקוב מקרוב יותר אחר ההנחיה (ברירת מחדל: 0.75) | FLOAT | לא | 0.0 עד 1.0 |
| `aspect_ratio` | יחס הגובה-רוחב של הווידאו הנוצר (ברירת מחדל: "16:9") | COMBO | לא | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `camera_control` | ניתן ליצור באמצעות הצומת Kling Camera Controls. שולט בתנועת המצלמה ובתנועה במהלך יצירת הווידאו. | CAMERA_CONTROL | כן | - |
