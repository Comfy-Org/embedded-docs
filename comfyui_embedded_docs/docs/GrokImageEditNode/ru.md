# Grok Image Edit

Узел Grok Image Edit изменяет существующее изображение на основе текстового запроса. Он использует Grok API для генерации одного или нескольких новых изображений, являющихся вариациями входного изображения, в соответствии с вашим описанием. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель ИИ, используемая для редактирования изображений. | COMBO | Да | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | Входное изображение (изображения), которое необходимо отредактировать. | IMAGE | Да |  |
| `prompt` | Текстовый запрос, используемый для генерации изображения. Многострочный текст; должен содержать хотя бы один непробельный символ. | STRING | Да |  |
| `resolution` | Разрешение выходного изображения. | COMBO | Да | `"1K"`<br>`"2K"` |
| `number_of_images` | Количество редактируемых изображений для генерации (по умолчанию: 1). | INT | Да | 1 до 10 |
| `seed` | Seed для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Да | 0 до 2147483647 |
| `соотношение сторон` | Соотношение сторон выходного изображения. Допустимо только при подключении нескольких изображений ко входу `image` (по умолчанию: "auto"). | COMBO | Нет | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**Важные ограничения:**
- Вход `image` поддерживает до 3 изображений, за исключением случая использования модели `grok-imagine-image-pro`, которая поддерживает только 1 входное изображение.
- Параметр `aspect_ratio` можно установить в пользовательское значение (не "auto") только при подключении нескольких изображений ко входу `image`. Установка пользовательского соотношения сторон при одном входном изображении вызовет ошибку.
- Параметр `prompt` должен содержать хотя бы один непробельный символ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Отредактированные изображения, созданные узлом. Если создано более одного изображения, они объединяются в один пакет. | IMAGE |
