# Grok Image Edit

Узел Grok Image Edit изменяет существующее изображение на основе текстового запроса. Он использует API Grok для генерации одного или нескольких новых изображений, являющихся вариациями входного изображения, в соответствии с вашим описанием.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель ИИ для редактирования изображений. | COMBO | Да | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | Входное изображение(я) для редактирования. Поддерживается до 3 входных изображений, за исключением модели «pro», которая поддерживает только 1. | IMAGE | Да |  |
| `prompt` | Текстовый запрос, используемый для генерации изображения. Должен содержать не менее 1 символа после удаления пробелов. | STRING | Да |  |
| `resolution` | Разрешение выходного изображения. | COMBO | Да | `"1K"`<br>`"2K"` |
| `number_of_images` | Количество отредактированных изображений для генерации (по умолчанию: 1). | INT | Да | 1 to 10 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | 0 to 2147483647 |
| `aspect_ratio` | Соотношение сторон выходного изображения. Допустимо только при подключении нескольких изображений ко входу image. Если установлено значение «auto», соотношение сторон определяется автоматически (по умолчанию: «auto»). | COMBO | Нет | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**Важные ограничения:**
- Вход `image` поддерживает до 3 изображений, за исключением использования модели `grok-imagine-image-pro`, которая поддерживает только 1 входное изображение.
- Параметр `aspect_ratio` можно установить в пользовательское значение (не «auto») только при подключении нескольких изображений ко входу `image`. Установка пользовательского соотношения сторон при одном входном изображении вызовет ошибку.

**Примечание:** Этот узел устарел.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Отредактированное изображение(я), сгенерированное узлом. Если `number_of_images` больше 1, выходные данные объединяются в пакет. | IMAGE |
