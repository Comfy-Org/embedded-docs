# Grok Image Edit

Узел Grok Image Edit изменяет существующее изображение на основе текстового запроса. Он отправляет входное изображение (изображения) и ваше описание в Grok API и возвращает одно или несколько новых сгенерированных изображений, соответствующих запросу. Этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Конкретная модель ИИ для редактирования изображений. | COMBO | Да | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | Входное изображение (изображения) для редактирования. | IMAGE | Да |  |
| `prompt` | Текстовый запрос, используемый для генерации изображения. Многострочный текст; должен содержать хотя бы один непробельный символ. | STRING | Да |  |
| `resolution` | Разрешение выходного изображения. | COMBO | Да | `"1K"`<br>`"2K"` |
| `number_of_images` | Количество отредактированных изображений для генерации (по умолчанию: 1). | INT | Да | от 1 до 10 |
| `seed` | Сид для определения, должен ли узел перезапуститься; фактические результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `соотношение сторон` | Соотношение сторон выходного изображения. Допускается только когда к входу `image` подключено несколько изображений (по умолчанию: "auto"). | COMBO | Нет | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**Важные ограничения:**
- Вход `image` поддерживает до 3 изображений, за исключением использования модели `grok-imagine-image-pro`, которая поддерживает только 1 входное изображение.
- Параметр `aspect_ratio` можно установить в пользовательское значение (не "auto") только когда к входу `image` подключено несколько изображений. Установка пользовательского соотношения сторон с одним входным изображением приведёт к ошибке.
- Параметр `prompt` должен содержать хотя бы один непробельный символ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Отредактированные изображения, сгенерированные узлом. Если сгенерировано более одного изображения, изображения объединяются в один пакет. | IMAGE |
