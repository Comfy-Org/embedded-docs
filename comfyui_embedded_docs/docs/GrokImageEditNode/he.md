# GrokImageEditNode

צומת Grok Image Edit משנה תמונה קיימת בהתבסס על הנחיית טקסט. היא שולחת את תמונות הקלט ואת התיאור שלך אל Grok API ומחזירה תמונה אחת או יותר שנוצרו מחדש בהתאם להנחיה. צומת זה מסומן כמיושן (deprecated).

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI הספציפי שיש להשתמש בו לעריכת תמונות. | COMBO | כן | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | תמונות הקלט שיש לערוך. | IMAGE | כן |  |
| `prompt` | הנחיית הטקסט המשמשת ליצירת התמונה. טקסט רב-שורתי; חייב להכיל לפחות תו שאינו רווח. | STRING | כן |  |
| `resolution` | הרזולוציה של תמונת הפלט. | COMBO | כן | `"1K"`<br>`"2K"` |
| `number_of_images` | מספר התמונות הערוכות ליצירה (ברירת מחדל: 1). | INT | כן | 1 to 10 |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-Seed (ברירת מחדל: 0). | INT | כן | 0 to 2147483647 |
| `aspect_ratio` | יחס הרוחב-גובה של תמונת הפלט. מותר רק כאשר מספר תמונות מחוברות לקלט `image` (ברירת מחדל: "auto"). | COMBO | לא | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**אילוצים חשובים:**
- קלט `image` תומך בעד 3 תמונות, למעט בעת שימוש במודל `grok-imagine-image-pro`, שתומך בתמונת קלט אחת בלבד.
- ניתן להגדיר את הפרמטר `aspect_ratio` לערך מותאם אישית (לא "auto") רק כאשר מספר תמונות מחוברות לקלט `image`. הגדרת יחס רוחב-גובה מותאם אישית עם תמונת קלט אחת תגרום לשגיאה.
- הפרמטר `prompt` חייב להכיל לפחות תו שאינו רווח.
