# Grok画像編集

Grok Image Edit ノードは、テキストプロンプトに基づいて既存の画像を編集します。このノードは Grok API を使用して、入力画像のバリエーションとなる1つ以上の新しい画像を、指定された説明に従って生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像編集に使用する特定の AI モデル。 | COMBO | はい | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | 編集対象の入力画像。最大3枚まで対応しています。ただし、"pro" モデルでは1枚のみ対応しています。 | IMAGE | はい |  |
| `prompt` | 画像生成に使用するテキストプロンプト。空白を除去した後、1文字以上である必要があります。 | STRING | はい |  |
| `resolution` | 出力画像の解像度。 | COMBO | はい | `"1K"`<br>`"2K"` |
| `number_of_images` | 生成する編集済み画像の枚数（デフォルト: 1）。 | INT | はい | 1〜10 |
| `seed` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0〜2147483647 |
| `aspect_ratio` | 出力画像のアスペクト比。複数の画像が `image` 入力に接続されている場合にのみ設定できます。"auto" に設定すると、アスペクト比は自動的に決定されます（デフォルト: "auto"）。 | COMBO | いいえ | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**重要な制約:**
- `image` 入力は最大3枚の画像に対応しています。ただし、`grok-imagine-image-pro` モデルを使用する場合は、入力画像が1枚のみ対応しています。
- `aspect_ratio` パラメータは、複数の画像が `image` 入力に接続されている場合にのみ、カスタム値（"auto" 以外）を設定できます。1枚の入力画像でカスタムのアスペクト比を設定すると、エラーが発生します。

**注:** このノードは非推奨です。

## 出力

| 出力名 | 説明 | データ型 |
|-----------|-------------|-----------|
| `output` | ノードによって生成された編集済み画像。`number_of_images` が1より大きい場合、出力はバッチとして連結されます。 | IMAGE |
