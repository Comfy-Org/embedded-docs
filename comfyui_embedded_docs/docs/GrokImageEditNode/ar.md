# تعديل صورة Grok

### نظرة عامة

تقوم عقدة Grok Image Edit بتعديل صورة موجودة بناءً على موجه نصي. تستخدم واجهة برمجة تطبيقات Grok لتوليد صورة جديدة أو أكثر كنسخ مختلفة من الإدخال، مسترشدةً بوصفك.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المحدد لاستخدامه في تحرير الصورة. | COMBO | نعم | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | الصورة (الصور) المدخلة التي سيتم تعديلها. يدعم حتى 3 صور مدخلة، باستثناء نموذج "pro" الذي يدعم صورة واحدة فقط. | IMAGE | نعم |  |
| `prompt` | الموجه النصي المستخدم لتوليد الصورة. يجب ألا يقل عن حرف واحد بعد إزالة المسافات البيضاء. | STRING | نعم |  |
| `resolution` | دقة صورة المخرَج. | COMBO | نعم | `"1K"`<br>`"2K"` |
| `number_of_images` | عدد الصور المحررة المراد توليدها (الافتراضي: 1). | INT | نعم | 1 إلى 10 |
| `seed` | القيمة المبدئية لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن القيمة المبدئية (الافتراضي: 0). | INT | نعم | 0 إلى 2147483647 |
| `aspect_ratio` | نسبة العرض إلى الارتفاع لصورة المخرَج. يُسمح بتعيينها فقط عند توصيل صور متعددة بإدخال الصورة. إذا تم تعيينها على "auto"، يتم تحديد نسبة العرض إلى الارتفاع تلقائيًا (الافتراضي: "auto"). | COMBO | لا | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**قيود مهمة:**
- يدعم إدخال `image` حتى 3 صور، إلا عند استخدام نموذج `grok-imagine-image-pro` الذي يدعم صورة مدخلة واحدة فقط.
- لا يمكن تعيين معامل `aspect_ratio` إلى قيمة مخصصة (وليست "auto") إلا عند توصيل صور متعددة بإدخال `image`. سيؤدي تعيين نسبة عرض إلى ارتفاع مخصصة مع صورة مدخلة واحدة إلى حدوث خطأ.

**ملاحظة:** هذه العقدة مُهمَلة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الصورة (الصور) المعدلة التي تولدها العقدة. إذا كانت قيمة `number_of_images` أكبر من 1، يتم دمج المخرجات في دفعة واحدة. | IMAGE |
