# تعديل صورة Grok

تقوم عُقدة Grok Image Edit بتعديل صورة موجودة استنادًا إلى موجز نصي. تُرسل الصورة/الصور المُدخَلة ووصفك إلى Grok API وتُعيد صورة واحدة أو أكثر مُولّدة حديثًا تتبع الموجز. هذه العُقدة موسومة بأنها مُهمَلة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج AI المحدد المراد استخدامه لتعديل الصور. | COMBO | نعم | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | الصورة/الصور المُدخَلة المراد تعديلها. | IMAGE | نعم |  |
| `prompt` | الموجز النصي المستخدم لتوليد الصورة. نص متعدد الأسطر؛ يجب أن يحتوي على حرف واحد غير مسافة بيضاء على الأقل. | STRING | نعم |  |
| `resolution` | دقة الصورة الناتجة. | COMBO | نعم | `"1K"`<br>`"2K"` |
| `number_of_images` | عدد الصور المعدَّلة المراد توليدها (الافتراضي: 1). | INT | نعم | 1 إلى 10 |
| `seed` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العُقدة؛ النتائج الفعلية غير حتمية بصرف النظر عن البذرة (الافتراضي: 0). | INT | نعم | 0 إلى 2147483647 |
| `aspect_ratio` | نسبة الأبعاد للصورة الناتجة. مسموح بها فقط عند توصيل صور متعددة بمدخل `image` (الافتراضي: `"auto"`). | COMBO | لا | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**قيود مهمة:**
- يدعم المدخل `image` ما يصل إلى 3 صور، باستثناء عند استخدام نموذج `grok-imagine-image-pro`، الذي يدعم صورة مُدخَلة واحدة فقط.
- لا يمكن ضبط المعامل `aspect_ratio` على قيمة مخصصة (وليست `"auto"`) إلا عند توصيل صور متعددة بمدخل `image`. سيؤدي ضبط نسبة أبعاد مخصصة مع صورة مُدخَلة واحدة إلى حدوث خطأ.
- يجب أن يحتوي `prompt` على حرف واحد غير مسافة بيضاء على الأقل.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الصورة/الصور المعدَّلة التي تولدها العُقدة. إذا تم توليد أكثر من صورة واحدة، يتم دمج الصور في دفعة واحدة. | IMAGE |
