# ویرایش تصویر Grok

گره Grok Image Edit یک تصویر موجود را بر اساس یک پرامپت متنی تغییر می‌دهد. تصویر(های) ورودی و توضیح شما را به Grok API می‌فرستد و یک یا چند تصویر تازه‌تولیدشده که از پرامپت پیروی می‌کنند را برمی‌گرداند. این گره به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل هوش مصنوعی مشخصی که برای ویرایش تصویر استفاده می‌شود. | COMBO | بله | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `تصویر` | تصویر(های) ورودی که باید ویرایش شوند. | IMAGE | بله |  |
| `راهنما` | پرامپت متنی استفاده‌شده برای تولید تصویر. متن چندخطی؛ باید حداقل شامل یک کاراکتر غیرفاصله باشد. | STRING | بله |  |
| `وضوح` | رزولوشن تصویر خروجی. | COMBO | بله | `"1K"`<br>`"2K"` |
| `تعداد تصاویر` | تعداد تصاویر ویرایش‌شده برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 10 |
| `بذر` | Seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از Seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `نسبت تصویر` | نسبت ابعاد تصویر خروجی. فقط زمانی مجاز است که چند تصویر به ورودی `image` متصل باشند (پیش‌فرض: "auto"). | COMBO | خیر | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**محدودیت‌های مهم:**
- ورودی `image` از حداکثر ۳ تصویر پشتیبانی می‌کند، مگر هنگام استفاده از مدل `grok-imagine-image-pro` که فقط از ۱ تصویر ورودی پشتیبانی می‌کند.
- پارامتر `aspect_ratio` تنها زمانی می‌تواند روی یک مقدار سفارشی (نه "auto") تنظیم شود که چند تصویر به ورودی `image` متصل باشند. تنظیم نسبت ابعاد سفارشی با یک تصویر ورودی واحد باعث خطا می‌شود.
- `prompt` باید حداقل شامل یک کاراکتر غیرفاصله باشد.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) ویرایش‌شده تولیدشده توسط گره. اگر بیش از یک تصویر تولید شود، تصاویر در یک بچ واحد به هم متصل می‌شوند. | IMAGE |
