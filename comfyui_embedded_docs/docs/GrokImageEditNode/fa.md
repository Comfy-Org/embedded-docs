# ویرایش تصویر Grok

گره Grok Image Edit تصویری موجود را بر اساس یک متن راهنما (prompt) ویرایش می‌کند. این گره از Grok API برای تولید یک یا چند تصویر جدید استفاده می‌کند که با توجه به توصیف شما، تغییراتی از تصویر ورودی هستند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مشخص برای ویرایش تصویر. | COMBO | بله | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `image` | تصویر(های) ورودی برای ویرایش. حداکثر 3 تصویر ورودی را پشتیبانی می‌کند، به‌جز مدل «pro» که فقط 1 تصویر را پشتیبانی می‌کند. | IMAGE | بله |  |
| `prompt` | متن راهنمای استفاده‌شده برای تولید تصویر. باید حداقل 1 کاراکتر پس از حذف فاصله‌های ابتدا و انتها باشد. | STRING | بله |  |
| `resolution` | وضوح تصویر خروجی. | COMBO | بله | `"1K"`<br>`"2K"` |
| `number_of_images` | تعداد تصاویر ویرایش‌شده برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 10 |
| `seed` | مقدار Seed برای تعیین این‌که آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `aspect_ratio` | نسبت ابعاد تصویر خروجی. فقط زمانی می‌توان مقدار غیر از «auto» تنظیم کرد که چند تصویر به ورودی `image` متصل شده باشند. اگر روی «auto» تنظیم شود، نسبت ابعاد به‌طور خودکار تعیین می‌شود (پیش‌فرض: «auto»). | COMBO | خیر | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**محدودیت‌های مهم:**
- ورودی `image` حداکثر 3 تصویر را پشتیبانی می‌کند، به‌جز هنگام استفاده از مدل `grok-imagine-image-pro` که فقط 1 تصویر ورودی را پشتیبانی می‌کند.
- پارامتر `aspect_ratio` فقط زمانی می‌تواند روی یک مقدار سفارشی (غیر از «auto») تنظیم شود که چند تصویر به ورودی `image` متصل شده باشند. تنظیم نسبت ابعاد سفارشی با یک تصویر ورودی منجر به خطا می‌شود.

**نکته:** این گره منسوخ شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) ویرایش‌شده تولیدشده توسط گره. اگر `number_of_images` بزرگ‌تر از 1 باشد، خروجی‌ها در یک دسته (batch) به هم می‌پیوندند. | IMAGE |
