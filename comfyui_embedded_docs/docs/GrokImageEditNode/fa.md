# ویرایش تصویر Grok

گره Grok Image Edit تصویر موجود را بر اساس یک متن راهنما (prompt) ویرایش می‌کند. این گره از API گروک برای تولید یک یا چند تصویر جدید استفاده می‌کند که تغییراتی از ورودی هستند و توسط توصیف شما هدایت می‌شوند. این گره به عنوان منسوخ (deprecated) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `مدل` | مدل هوش مصنوعی خاص مورد استفاده برای ویرایش تصویر. | COMBO | بله | `"grok-imagine-image-quality"`<br>`"grok-imagine-image-pro"`<br>`"grok-imagine-image"` |
| `تصویر` | تصویر(های) ورودی که باید ویرایش شوند. | IMAGE | بله |  |
| `راهنما` | متن راهنمای مورد استفاده برای تولید تصویر. متن چندخطی؛ باید حداقل شامل یک نویسه غیر فاصله باشد. | STRING | بله |  |
| `وضوح` | وضوح تصویر خروجی. | COMBO | بله | `"1K"`<br>`"2K"` |
| `تعداد تصاویر` | تعداد تصاویر ویرایش‌شده برای تولید (پیش‌فرض: 1). | INT | بله | 1 تا 10 |
| `بذر` | مقدار seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | بله | 0 تا 2147483647 |
| `نسبت تصویر` | نسبت تصویر برای تصویر خروجی. فقط زمانی مجاز است که چند تصویر به ورودی image متصل شده باشند (پیش‌فرض: "auto"). | COMBO | خیر | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"9:16"`<br>`"16:9"`<br>`"9:19.5"`<br>`"19.5:9"`<br>`"9:20"`<br>`"20:9"`<br>`"1:2"`<br>`"2:1"` |

**محدودیت‌های مهم:**
- ورودی `image` تا ۳ تصویر را پشتیبانی می‌کند، به‌جز هنگام استفاده از مدل `grok-imagine-image-pro` که فقط ۱ تصویر ورودی را پشتیبانی می‌کند.
- پارامتر `aspect_ratio` فقط زمانی می‌تواند روی یک مقدار سفارشی (نه "auto") تنظیم شود که چند تصویر به ورودی `image` متصل شده باشند. تنظیم نسبت تصویر سفارشی با یک تصویر ورودی تنها باعث بروز خطا می‌شود.
- دستور `prompt` باید حداقل دارای یک نویسه غیر فاصله باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | تصویر(های) ویرایش‌شده تولید شده توسط گره. اگر بیش از یک تصویر تولید شود، تصاویر در یک دسته واحد (batch) به هم الحاق می‌شوند. | IMAGE |
