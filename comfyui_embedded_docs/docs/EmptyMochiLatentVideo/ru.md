# Пустой MochiLatentVideo

Узел `EmptyMochiLatentVideo` создаёт пустой латентный видео-тензор с заданными размерами. Он формирует заполненное нулями латентное представление, которое можно использовать в качестве отправной точки для рабочих процессов генерации видео. Узел позволяет задать ширину, высоту, длину и размер батча для латентного видео-тензора.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина латентного видео в пикселях (по умолчанию: 848, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота латентного видео в пикселях (по умолчанию: 480, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в латентном видео (по умолчанию: 25, должно удовлетворять условию, что `(length - 1)` делится на 6) | INT | Да | 7 to MAX_RESOLUTION |
| `batch_size` | Количество латентных видео для генерации в одном батче (по умолчанию: 1) | INT | Нет | 1 to 4096 |

**Примечание:** Узел сжимает пространственные и временные размерности входных данных. Латентные ширина и высота вычисляются как `width / 8` и `height / 8`, а временная размерность — как `((length - 1) // 6) + 1`. Параметр `length` должен удовлетворять условию, что `(length - 1)` делится на 6, то есть допустимые значения — 7, 13, 19, 25 и т.д. Результирующий латентный тензор имеет 12 каналов и итоговую форму `(batch_size, 12, ((length - 1) // 6) + 1, height // 8, width // 8)`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой латентный видео-тензор с заданными размерами, заполненный нулями | LATENT |
