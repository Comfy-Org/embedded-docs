# Пустой MochiLatentVideo

EmptyMochiLatentVideo создаёт пустой латентный тензор видео с размерами, которые вы задаёте. Он генерирует заполненное нулями латентное представление, которое можно использовать в качестве отправной точки для рабочих процессов генерации видео. Узел позволяет задать ширину, высоту, длину и размер пакета латентного тензора видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного видео в пикселях (по умолчанию: 848, значения увеличиваются с шагом 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота латентного видео в пикселях (по умолчанию: 480, значения увеличиваются с шагом 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в латентном видео (по умолчанию: 25, значения увеличиваются с шагом 6, начиная с 7) | INT | Да | от 7 до MAX_RESOLUTION |
| `размер_пакета` | Количество латентных видео для генерации в пакете (по умолчанию: 1) | INT | Нет | от 1 до 4096 |

**Примечание:** Фактические латентные размеры рассчитываются как width/8 и height/8, временное измерение рассчитывается как `((length - 1) // 6) + 1`, а тензор имеет 12 каналов. Поскольку `length` увеличивается с шагом 6, начиная с 7, допустимые значения — 7, 13, 19, 25 и так далее.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой латентный тензор видео с указанными размерами, содержащий все нули | LATENT |
