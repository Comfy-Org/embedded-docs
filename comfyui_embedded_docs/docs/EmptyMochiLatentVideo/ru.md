# Пустой MochiLatentVideo

EmptyMochiLatentVideo создает пустой тензор латентного видео с указанными вами размерами. Он генерирует латентное представление, заполненное нулями, которое можно использовать в качестве отправной точки для рабочих процессов генерации видео. Узел позволяет задать ширину, высоту, длину и размер пакета тензора латентного видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного видео в пикселях (по умолчанию: 848, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота латентного видео в пикселях (по умолчанию: 480, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в латентном видео (по умолчанию: 25, должно удовлетворять условию: `(length - 1)` делится на 6) | INT | Да | 7 to MAX_RESOLUTION |
| `размер_пакета` | Количество латентных видео для генерации в одном пакете (по умолчанию: 1) | INT | Нет | 1 до 4096 |

**Примечание:** Фактические размеры латентного тензора вычисляются как width/8 и height/8, временное измерение вычисляется как `((length - 1) // 6) + 1`, а тензор имеет 12 каналов. Параметр `length` должен удовлетворять условию, что `(length - 1)` делится на 6, то есть допустимые значения: 7, 13, 19, 25 и т. д.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Пустой тензор латентного видео с указанными размерами, содержащий все нули | LATENT |
