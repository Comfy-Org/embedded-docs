# ویدیوی نهفته خالی Mochi

گره EmptyMochiLatentVideo یک تنسور ویدیوی نهفتهٔ خالی با ابعاد مشخص می‌سازد. این گره یک نمایش نهفتهٔ پر از صفر تولید می‌کند که می‌تواند به‌عنوان نقطهٔ شروع برای گردش‌کارهای تولید ویدیو استفاده شود. گره به شما امکان می‌دهد عرض، ارتفاع، طول و اندازهٔ دسته را برای تنسور ویدیوی نهفته تعیین کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | عرض ویدیوی نهفته به پیکسل (پیش‌فرض: 848، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی نهفته به پیکسل (پیش‌فرض: 480، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیوی نهفته (پیش‌فرض: 25، باید به‌گونه‌ای باشد که `(length - 1)` بر 6 بخش‌پذیر باشد) | INT | بله | 7 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهای نهفته برای تولید در یک دسته (پیش‌فرض: 1) | INT | خیر | 1 تا 4096 |

**توجه:** این گره ابعاد مکانی و زمانی ورودی را فشرده می‌کند. عرض و ارتفاع نهفته به‌صورت `width / 8` و `height / 8` محاسبه می‌شوند و بُعد زمانی به‌صورت `((length - 1) // 6) + 1` محاسبه می‌شود. پارامتر `length` باید به‌گونه‌ای باشد که `(length - 1)` بر 6 بخش‌پذیر باشد؛ به این معنی که مقادیر معتبر عبارت‌اند از 7، 13، 19، 25 و غیره. تنسور نهفتهٔ حاصل 12 کانال دارد و شکل نهایی آن `(batch_size, 12, ((length - 1) // 6) + 1, height // 8, width // 8)` است.
