# TextEncodeJoyImageEdit

צומת זה מקודד פרומפט טקסטואלי ותמונות אופציונליות לנתוני קונדישנינג לשימוש עם מודלי JoyImage. הוא משלב מקודד טקסט CLIP עם קלטי תמונות אופציונליים כדי ליצור קונדישנינג עשיר שיכול להנחות משימות יצירת תמונות או עריכה.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל ה-CLIP המשמש לקידוד פרומפט הטקסט | CLIP | כן | - |
| `prompt` | פרומפט הטקסט לקידוד, עם תמיכה בקלט רב-שורתי ובפרומפטים דינמיים | STRING | כן | - |
| `vae` | מודל VAE לקידוד תמונות למרחב הלטנטי | VAE | לא | - |
| `images` | תמונות אופציונליות לכלול בקונדישנינג, עד מקסימום של 6 תמונות. כל תמונה מתחברת כקלט נפרד (image_0 עד image_5) | IMAGE | לא | 0 to 6 images |

קלט ה-`images` הוא קבוצת גדילה אוטומטית שמקבלת בין 0 ל-6 תמונות. כאשר לא מחוברות תמונות, הקונדישנינג מבוסס על פרומפט הטקסט בלבד.

## פלטים

| שם פלט | תיאור | סוג נתון |
|-------------|-------------|-----------|
| `CONDITIONING` | נתוני הקונדישנינג המקודדים המשלבים את פרומפט הטקסט וכל תמונה שסופקה | CONDITIONING |
