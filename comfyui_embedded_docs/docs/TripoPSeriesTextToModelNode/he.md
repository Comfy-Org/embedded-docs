# Tripo P2: טקסט למודל

יוצר מודל תלת-ממדי low-poly עם טופולוגיה נקייה מתוך פרומפט טקסטואלי באמצעות מודל P2 של Tripo. התוצאה מוחזרת כרשת משולשים (GLB) או, כאשר `model.quad` מופעל, כרשת שבה רוב הפאות מרובעות (FBX).

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Tripo מסדרת P-series לשימוש. בחירת מודל חושפת את הקלטים הייחודיים לו למטה. | DYNAMIC_COMBO | כן | `"P2"` |

### קלטים של P2

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model.prompt` | תיאור טקסטואלי של המודל התלת-ממדי ליצירה. חייב שלא להיות ריק, עד 1024 תווים (ברירת מחדל: ריק). | STRING | כן | עד 1024 תווים |
| `model.negative_prompt` | תיאור טקסטואלי של מה להימנע ממנו במודל הנוצר (ברירת מחדל: ריק). | STRING | לא | עד 255 תווים |
| `model.quad` | החזר רשת שבה רוב הפאות מרובעות בפלט FBX במקום רשת משולשים בפלט GLB (ברירת מחדל: False). | BOOLEAN | כן | True/False |
| `model.face_limit` | מספר הפאות המבוקש. `-1` נותן ל-Tripo לבחור. כאשר `model.quad` מופעל, המגבלה היא 48 עד 25,000, אחרת 48 עד 50,000 (ברירת מחדל: -1). | INT | כן | ‎-1, או 48 עד 50000 |
| `model.texture` | רזולוציית טקסטורת צבע בסיס: standard היא 2K, detailed 4K ו-extreme 8K. `"none"` מחזיר רשת ללא טקסטורה (ברירת מחדל: `"standard"`). | COMBO | כן | `"standard"`<br>`"detailed"`<br>`"extreme"`<br>`"none"` |
| `model.pbr` | הוסף מפות metallic, roughness ו-normal לצבע הבסיס. לא ייושם כאשר `model.texture` הוא `"none"` (ברירת מחדל: True). | BOOLEAN | כן | True/False |
| `model.model_seed` | Seed לגאומטריה (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |
| `model.image_seed` | Seed לתמונה ש-Tripo מצייר מהפרומפט לפני המידול (ברירת מחדל: 42). הגדרה מתקדמת. | INT | כן | 0 עד 2147483647 |
| `model.texture_seed` | Seed לטקסטורות (ברירת מחדל: 42). הגדרה מתקדמת. | INT | כן | 0 עד 2147483647 |
| `model.auto_size` | התאם את קנה המידה של המודל לגודלו במציאות במטרים באמצעות טרנספורם הסצנה שלו. לא ייושם כאשר `model.texture` הוא `"none"` (ברירת מחדל: False). הגדרה מתקדמת. | BOOLEAN | כן | True/False |
| `model.export_uv` | בצע פריסת UV לרשת כאשר היא ללא טקסטורה. רשתות עם טקסטורה תמיד נפרסות (ברירת מחדל: True). הגדרה מתקדמת. | BOOLEAN | כן | True/False |
| `model.compress_geometry` | החל דחיסת גאומטריה meshopt: קבצים קטנים בהרבה, אך תצוגת ה-3D של ComfyUI אינה יכולה להציג אותם. לא ייושם לרשתות מרובעים (ברירת מחדל: False). הגדרה מתקדמת. | BOOLEAN | כן | True/False |

**הערות:**

- `model.prompt` הוא חובה; `model.negative_prompt` הוא אופציונלי ומוגבל ל-255 תווים.
- `model.face_limit` הוא יעד ולא תקרה קשיחה, כך שהתוצאה יכולה להכיל יותר פאות מהמבוקש. `-1` משאיר את הבחירה ל-Tripo.
- `model.quad` קובע איזה פלט נושא את הרשת. כאשר הוא מופעל, המודל מגיע בפלט FBX ופלט GLB נשאר ריק; כאשר הוא מושבת, המודל מגיע ב-GLB ו-FBX נשאר ריק. הצומת מעלה שגיאה אם הפלט הריק הוא זה שחיברת.
- `model.texture`, `model.pbr`, `model.texture_seed` ו-`model.auto_size` חלים רק על מודלים עם טקסטורה: עם `"none"` הצומת לא שולח הגדרות טקסטורה ומחזיר גאומטריה חשופה.
- ל-`model.compress_geometry` אין השפעה על רשתות מרובעים.
