# Tripo P2: Текст в модель

Создаёт низкополигональную 3D-модель с чистой топологией по текстовому запросу с помощью модели P2 от Tripo. Результат возвращается в виде треугольной сетки (GLB) или, когда включён `model.quad`, в виде сетки с преобладанием четырёхугольников (FBX).

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель серии P от Tripo для использования. При выборе модели ниже отображаются её собственные входы. | DYNAMIC_COMBO | Да | `"P2"` |

### Входы P2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовое описание 3D-модели для генерации. Не должно быть пустым, до 1024 символов (по умолчанию: пусто). | STRING | Да | До 1024 символов |
| `negative_prompt` | Текстовое описание того, чего следует избегать в генерируемой модели (по умолчанию: пусто). | STRING | Нет | До 255 символов |
| `quad` | Возвращать сетку с преобладанием четырёхугольников на выходе FBX вместо треугольной сетки на выходе GLB (по умолчанию: False). | BOOLEAN | Да | True/False |
| `face_limit` | Целевое количество граней. `-1` позволяет Tripo выбрать самостоятельно. При включённом `model.quad` ограничение составляет от 48 до 25 000, иначе от 48 до 50 000 (по умолчанию: -1). | INT | Да | -1, или от 48 до 50 000 |
| `текстура` | Разрешение текстуры базового цвета: standard — 2K, detailed — 4K, extreme — 8K. `"none"` возвращает модель без текстуры (по умолчанию: `"standard"`). | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"`<br>`"none"` |
| `pbr` | Добавлять карты металличности, шероховатости и нормалей к базовому цвету. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: True). | BOOLEAN | Да | True/False |
| `model_seed` | Сид для геометрии (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |
| `image_seed` | Сид для изображения, которое Tripo создаёт по запросу перед моделированием (по умолчанию: 42). Расширенная настройка. | INT | Да | от 0 до 2147483647 |
| `texture_seed` | Сид для текстур (по умолчанию: 42). Расширенная настройка. | INT | Да | от 0 до 2147483647 |
| `auto_size` | Масштабировать модель до её реального размера в метрах через преобразование сцены (по умолчанию: False). Расширенная настройка. | BOOLEAN | Да | True/False |
| `export_uv` | Выполнять UV-развёртку сетки, когда она не имеет текстуры. Сетки с текстурами всегда разворачиваются (по умолчанию: True). Расширенная настройка. | BOOLEAN | Да | True/False |
| `compress_geometry` | Применять сжатие геометрии meshopt: файлы получаются значительно меньше, но 3D-предпросмотр ComfyUI не может их отображать. Игнорируется для четырёхугольных сеток (по умолчанию: False). Расширенная настройка. | BOOLEAN | Да | True/False |

**Примечания:**

- `model.prompt` обязателен; `model.negative_prompt` необязателен и ограничен 255 символами.
- `model.face_limit` — это целевое значение, а не жёсткое ограничение, поэтому результат может содержать больше граней, чем запрошено. `-1` оставляет выбор за Tripo.
- `model.quad` определяет, какой выход содержит сетку. Если он включён, модель поступает на выход FBX, а выход GLB остаётся пустым; если он отключён, модель поступает на выход GLB, а FBX остаётся пустым. Узел выдаёт ошибку, если вы подключили именно пустой выход.
- `model.texture`, `model.pbr`, `model.texture_seed` и `model.auto_size` применяются только к моделям с текстурами: при `"none"` узел не отправляет настройки текстур и возвращает только геометрию.
- `model.compress_geometry` не влияет на четырёхугольные сетки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model task_id` | Уникальный идентификатор задачи для запроса на генерацию модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пусто, когда включён `model.quad`. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только когда включён `model.quad`. | FILE3DFBX |
