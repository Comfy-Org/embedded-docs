# Tripo P2: متن به مدل

یک مدل سه‌بعدی کم‌چندضلعی (low-poly) با توپولوژی تمیز را از یک پرامپت متنی با استفاده از مدل P2 شرکت Tripo تولید می‌کند. نتیجه به‌صورت یک مش مثلثی (GLB) بازگردانده می‌شود، یا هنگامی که `model.quad` فعال باشد، به‌صورت یک مش غالب چهارضلعی (FBX).

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل سری P شرکت Tripo برای استفاده. با انتخاب یک مدل، ورودی‌های مخصوص آن در زیر نمایش داده می‌شود. | DYNAMIC_COMBO | بله | `"P2"` |

### ورودی‌های P2

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `پرامپت` | توضیح متنی مدل سه‌بعدی که باید تولید شود. نباید خالی باشد، حداکثر 1024 کاراکتر (پیش‌فرض: خالی). | STRING | بله | حداکثر 1024 کاراکتر |
| `پرامپت_منفی` | توضیح متنی چیزهایی که باید در مدل تولیدشده از آن‌ها پرهیز شود (پیش‌فرض: خالی). | STRING | خیر | حداکثر 255 کاراکتر |
| `چهارضلعی` | به‌جای مش مثلثی در خروجی GLB، یک مش غالب چهارضلعی در خروجی FBX برگردانده می‌شود (پیش‌فرض: False). | BOOLEAN | بله | True/False |
| `محدودیت_وجه` | تعداد وجه هدف. `-1` به Tripo اجازه می‌دهد انتخاب کند. با فعال بودن `model.quad` محدوده از 48 تا 25,000 است، در غیر این صورت از 48 تا 50,000 (پیش‌فرض: -1). | INT | بله | -1، یا 48 تا 50000 |
| `بافت` | وضوح بافت رنگ پایه: standard برابر 2K، detailed برابر 4K و extreme برابر 8K است. `"none"` یک مش بدون بافت برمی‌گرداند (پیش‌فرض: `"standard"`). | COMBO | بله | `"standard"`<br>`"detailed"`<br>`"extreme"`<br>`"none"` |
| `pbr` | نقشه‌های metallic، roughness و normal را به رنگ پایه اضافه می‌کند. وقتی `model.texture` برابر `"none"` باشد نادیده گرفته می‌شود (پیش‌فرض: True). | BOOLEAN | بله | True/False |
| `بذر_مدل` | بذر (seed) برای هندسه (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |
| `بذر_تصویر` | بذر (seed) برای تصویری که Tripo پیش از مدل‌سازی از پرامپت می‌سازد (پیش‌فرض: 42). تنظیم پیشرفته. | INT | بله | 0 تا 2147483647 |
| `بذر_بافت` | بذر (seed) برای بافت‌ها (پیش‌فرض: 42). تنظیم پیشرفته. | INT | بله | 0 تا 2147483647 |
| `اندازه_خودکار` | مدل را از طریق ترنسفورم صحنه به اندازه واقعی‌اش بر حسب متر مقیاس‌دهی می‌کند (پیش‌فرض: False). تنظیم پیشرفته. | BOOLEAN | بله | True/False |
| `خروجی_UV` | هنگامی که مش بدون بافت است، UV آن را باز می‌کند. مش‌های دارای بافت همیشه باز می‌شوند (پیش‌فرض: True). تنظیم پیشرفته. | BOOLEAN | بله | True/False |
| `فشرده‌سازی_هندسه` | فشرده‌سازی هندسه meshopt را اعمال می‌کند: فایل‌ها بسیار کوچک‌تر می‌شوند، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد. برای مش‌های چهارضلعی نادیده گرفته می‌شود (پیش‌فرض: False). تنظیم پیشرفته. | BOOLEAN | بله | True/False |

**یادداشت‌ها:**

- `model.prompt` الزامی است؛ `model.negative_prompt` اختیاری است و به 255 کاراکتر محدود می‌شود.
- `model.face_limit` یک هدف است نه یک سقف سخت، بنابراین نتیجه می‌تواند شامل وجه‌های بیشتری از مقدار درخواستی باشد. `-1` انتخاب را به Tripo واگذار می‌کند.
- `model.quad` تعیین می‌کند که کدام خروجی مش را حمل کند. با فعال بودن آن، مدل روی خروجی FBX می‌آید و خروجی GLB خالی می‌ماند؛ با غیرفعال بودن آن، مدل روی GLB می‌آید و FBX خالی می‌ماند. اگر خروجی خالی همانی باشد که به آن متصل کرده‌اید، گره خطا می‌دهد.
- `model.texture`، `model.pbr`، `model.texture_seed` و `model.auto_size` فقط برای مدل‌های دارای بافت اعمال می‌شوند: با `"none"` گره هیچ تنظیم بافت‌ای ارسال نمی‌کند و هندسه خالی برمی‌گرداند.
- `model.compress_geometry` روی مش‌های چهارضلعی اثری ندارد.

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |

| `FBX` | مدل سه‌بعدی تولیدشده در قالب FBX. فقط زمانی پر می‌شود که `model.quad` فعال باشد. | FILE3DFBX |
