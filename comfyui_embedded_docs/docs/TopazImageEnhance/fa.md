# افزایش کیفیت تصویر Topaz

گره Topaz Image Enhance بهبود تصویر و افزایش مقیاس در سطح استاندارد صنعتی ارائه می‌دهد. این گره یک تصویر ورودی واحد را با استفاده از مدل هوش مصنوعی مبتنی بر ابر پردازش می‌کند تا کیفیت، جزئیات و وضوح را بهبود بخشد. این گره کنترل دقیقی بر فرآیند بهبود ارائه می‌دهد، از جمله گزینه‌هایی برای راهنمایی خلاقانه، تمرکز بر سوژه و حفظ چهره.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|----------|-----------|---------|--------|
| `مدل` | مدل هوش مصنوعی مورد استفاده برای بهبود تصویر. | COMBO | بله | `"Reimagine"` |
| `تصویر` | تصویر ورودی برای بهبود. فقط یک تصویر پشتیبانی می‌شود. | IMAGE | بله | - |
| `پرامپت` | دستور متنی اختیاری برای راهنمایی خلاقانه در افزایش مقیاس (پیش‌فرض: خالی). | STRING | خیر | - |
| `شناسایی سوژه` | کنترل می‌کند که بهبود روی کدام بخش از تصویر تمرکز کند (پیش‌فرض: "All"). | COMBO | خیر | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `بهبود چهره` | در طول پردازش، چهره‌ها را (در صورت وجود) بهبود می‌دهد (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `خلاقیت در بهبود چهره` | سطح خلاقیت را برای بهبود چهره تنظیم می‌کند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 - 1.0 |
| `قدرت بهبود چهره` | کنترل می‌کند که چهره‌های بهبودیافته نسبت به پس‌زمینه چقدر شارپ باشند (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 - 1.0 |
| `برش برای پر کردن` | به‌طور پیش‌فرض، وقتی نسبت ابعاد خروجی متفاوت است، تصویر با نوارهای خالی (letterbox) نمایش داده می‌شود. برای برش تصویر و پر کردن ابعاد خروجی، این گزینه را فعال کنید (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `عرض خروجی` | مقدار صفر به معنای محاسبه خودکار است (معمولاً اندازه اصلی یا output_height اگر مشخص شده باشد) (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `ارتفاع خروجی` | مقدار صفر به معنای خروجی با همان ارتفاع اصلی یا عرض خروجی است (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `خلاقیت` | سطح خلاقیت کلی فرآیند بهبود را کنترل می‌کند (پیش‌فرض: 3). | INT | خیر | 1 - 9 |
| `حفظ چهره` | هویت چهره سوژه‌ها را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `حفظ رنگ` | رنگ‌های اصلی را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |

**توجه:** این گره فقط می‌تواند یک تصویر ورودی را پردازش کند. ارائه یک دسته از چند تصویر منجر به خطا خواهد شد.
