# افزایش کیفیت تصویر Topaz

گره Topaz Image Enhance ارتقای مقیاس و بهبود تصویر را در سطح استاندارد صنعتی فراهم می‌کند. این گره با استفاده از یک مدل هوش مصنوعی مبتنی بر ابر، یک تصویر ورودی را پردازش کرده و کیفیت، جزئیات و وضوح آن را بهبود می‌بخشد. کنترل دقیقی بر فرآیند بهبود ارائه می‌دهد، از جمله گزینه‌هایی برای هدایت خلاقانه، تمرکز روی سوژه و حفظ چهره.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی مورد استفاده برای بهبود تصویر. | COMBO | بله | `"Reimagine"` |
| `image` | تصویر ورودی که قرار است بهبود یابد. تنها یک تصویر پشتیبانی می‌شود. | IMAGE | بله | - |
| `prompt` | متن راهنمای اختیاری برای هدایت خلاقانه ارتقای مقیاس (پیش‌فرض: خالی). | STRING | خیر | - |
| `subject_detection` | کنترل می‌کند که بهبود روی کدام قسمت از تصویر تمرکز کند (پیش‌فرض: "All"). | COMBO | خیر | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | در طول پردازش، چهره‌ها را (در صورت وجود) بهبود می‌بخشد (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `face_enhancement_creativity` | سطح خلاقیت برای بهبود چهره را تعیین می‌کند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 - 1.0 |
| `face_enhancement_strength` | میزان وضوح چهره‌های بهبودیافته را نسبت به پس‌زمینه کنترل می‌کند (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 - 1.0 |
| `crop_to_fill` | به‌طور پیش‌فرض، وقتی نسبت ابعاد خروجی متفاوت باشد، تصویر به‌صورت letterbox (با نوارهای سیاه در بالا و پایین) نمایش داده می‌شود. برای برش تصویر و پر کردن ابعاد خروجی، این گزینه را فعال کنید (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `output_width` | مقدار صفر به معنای محاسبه خودکار است (معمولاً اندازه اصلی یا output_height در صورت مشخص شدن) (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `output_height` | مقدار صفر به معنای خروجی با همان ارتفاع اصلی یا عرض خروجی (output width) است (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `creativity` | سطح خلاقیت کلی فرآیند بهبود را کنترل می‌کند (پیش‌فرض: 3). | INT | خیر | 1 - 9 |
| `face_preservation` | هویت چهره سوژه‌ها را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `color_preservation` | رنگ‌های اصلی را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |

**نکته:** این گره تنها می‌تواند یک تصویر ورودی را پردازش کند. ارائه یک دسته از چند تصویر منجر به بروز خطا می‌شود.
