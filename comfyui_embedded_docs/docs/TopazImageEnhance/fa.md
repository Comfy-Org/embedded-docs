# افزایش کیفیت تصویر Topaz

گره Topaz Image Enhance ارتقای مقیاس و بهبود تصویر در سطح استانداردهای صنعتی را ارائه می‌دهد. این گره یک تصویر ورودی واحد را با استفاده از یک مدل هوش مصنوعی مبتنی بر ابر پردازش می‌کند تا کیفیت، جزئیات و وضوح را بهبود بخشد. این گره کنترل دقیقی بر فرایند بهبود فراهم می‌کند، از جمله گزینه‌هایی برای راهنمایی خلاقانه، تمرکز روی سوژه و حفظ چهره.

این گره یک نسخه قدیمی است و در رابط کاربری به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی برای بهبود تصویر. | COMBO | بله | `"Reimagine"` |
| `image` | تصویر ورودی برای بهبود. فقط یک تصویر پشتیبانی می‌شود. | IMAGE | بله | - |
| `prompt` | پرامپت متنی اختیاری برای راهنمایی ارتقای خلاقانه (پیش‌فرض: خالی). | STRING | خیر | - |
| `subject_detection` | کنترل می‌کند که بهبود روی کدام بخش تصویر تمرکز کند (پیش‌فرض: "All"). | COMBO | خیر | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | چهره‌ها (در صورت وجود) را در طول پردازش بهبود می‌دهد (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `face_enhancement_creativity` | سطح خلاقیت را برای بهبود چهره تنظیم می‌کند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 - 1.0 |
| `face_enhancement_strength` | کنترل می‌کند که چهره‌های بهبودیافته نسبت به پس‌زمینه چقدر واضح باشند (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 - 1.0 |
| `crop_to_fill` | به‌طور پیش‌فرض، وقتی نسبت ابعاد خروجی متفاوت باشد، تصویر با حاشیه نمایش داده می‌شود. برای برش تصویر جهت پر کردن ابعاد خروجی، این گزینه را فعال کنید (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `output_width` | مقدار صفر به معنای محاسبه خودکار است (معمولاً اندازه اصلی یا `output_height` در صورت مشخص بودن خواهد بود) (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `output_height` | مقدار صفر به معنای خروجی با همان ارتفاع اصلی یا عرض خروجی است (پیش‌فرض: 0). | INT | خیر | 0 - 32000 |
| `creativity` | سطح خلاقیت کلی بهبود را کنترل می‌کند (پیش‌فرض: 3). | INT | خیر | 1 - 9 |
| `face_preservation` | هویت چهره سوژه‌ها را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |
| `color_preservation` | رنگ‌های اصلی را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | - |

**توجه:** این گره فقط می‌تواند یک تصویر ورودی را پردازش کند. ارائه یک دسته شامل چند تصویر منجر به خطا می‌شود.
