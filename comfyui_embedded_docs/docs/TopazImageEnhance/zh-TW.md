# Topaz 影像增強

Topaz Image Enhance 節點提供業界標準的放大與影像增強功能。它使用雲端 AI 模型處理單一輸入影像，以提升品質、細節與解析度。此節點提供對增強過程的精細控制，包括創意引導、主體聚焦與臉部保留等選項。

此節點為舊版，並在介面中標記為已棄用。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影像增強的 AI 模型。 | COMBO | 是 | `"Reimagine"` |
| `影像` | 要增強的輸入影像。僅支援一張影像。 | IMAGE | 是 | - |
| `提示詞` | 用於創意放大引導的選用文字提示（預設：空）。 | STRING | 否 | - |
| `主體偵測` | 控制增強處理聚焦於影像的哪個部分（預設："All"）。 | COMBO | 否 | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `臉部增強` | 在處理期間增強臉部（若存在）（預設：True）。 | BOOLEAN | 否 | - |
| `臉部增強創意度` | 設定臉部增強的創意程度（預設：0.0）。 | FLOAT | 否 | 0.0 - 1.0 |
| `臉部增強強度` | 控制增強後的臉部相對於背景的銳利程度（預設：1.0）。 | FLOAT | 否 | 0.0 - 1.0 |
| `裁切填滿` | 預設情況下，當輸出長寬比不同時，影像會加上黑邊。啟用後會裁切影像以填滿輸出尺寸（預設：False）。 | BOOLEAN | 否 | - |
| `輸出寬度` | 值為 0 表示自動計算（通常會是原始尺寸；若有指定，則為 `output_height`）（預設：0）。 | INT | 否 | 0 - 32000 |
| `輸出高度` | 值為 0 表示輸出高度與原始高度或 `output_width` 相同（預設：0）。 | INT | 否 | 0 - 32000 |
| `創意度` | 控制增強的整體創意程度（預設：3）。 | INT | 否 | 1 - 9 |
| `臉部保留` | 保留主體的臉部身分特徵（預設：True）。 | BOOLEAN | 否 | - |
| `色彩保留` | 保留原始色彩（預設：True）。 | BOOLEAN | 否 | - |

**注意：** 此節點僅能處理單一輸入影像。提供包含多張影像的批次將會導致錯誤。
