# Topaz Улучшение изображения

Узел Topaz Image Enhance обеспечивает увеличение масштаба и улучшение изображений на уровне отраслевых стандартов. Он обрабатывает одно входное изображение с помощью облачной ИИ-модели для повышения качества, детализации и разрешения. Узел предоставляет тонкий контроль над процессом улучшения, включая параметры для творческого управления, выбора субъекта и сохранения лиц.

Этот узел является устаревшей версией и помечен в интерфейсе как deprecated.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | ИИ-модель, используемая для улучшения изображения. | COMBO | Да | `"Reimagine"` |
| `изображение` | Входное изображение, которое нужно улучшить. Поддерживается только одно изображение. | IMAGE | Да | - |
| `промпт` | Необязательная текстовая подсказка для управления творческим увеличением масштаба (по умолчанию: пустая). | STRING | Нет | - |
| `обнаружение объекта` | Управляет тем, на какую часть изображения будет направлено улучшение (по умолчанию: "All"). | COMBO | Нет | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `улучшение лица` | Улучшать лица (если они присутствуют) во время обработки (по умолчанию: True). | BOOLEAN | Нет | - |
| `креативность улучшения лица` | Задаёт уровень креативности для улучшения лиц (по умолчанию: 0.0). | FLOAT | Нет | 0.0 - 1.0 |
| `степень улучшения лица` | Управляет тем, насколько резкими будут улучшенные лица относительно фона (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 1.0 |
| `обрезать до заполнения` | По умолчанию, если соотношение сторон вывода отличается, изображение вписывается с добавлением полей. Включите, чтобы обрезать изображение для заполнения выходных размеров (по умолчанию: False). | BOOLEAN | Нет | - |
| `выходная ширина` | Нулевое значение означает автоматический расчёт (обычно это исходный размер или output_height, если он указан) (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `выходная высота` | Нулевое значение означает вывод с той же высотой, что и исходное изображение, или с шириной вывода (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `креативность` | Управляет общим уровнем креативности улучшения (по умолчанию: 3). | INT | Нет | 1 - 9 |
| `сохранение лица` | Сохранять черты лиц субъектов (по умолчанию: True). | BOOLEAN | Нет | - |
| `сохранение цвета` | Сохранять исходные цвета (по умолчанию: True). | BOOLEAN | Нет | - |

**Примечание:** Этот узел может обрабатывать только одно входное изображение. При передаче пакета из нескольких изображений возникнет ошибка.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Улучшенное выходное изображение. | IMAGE |
