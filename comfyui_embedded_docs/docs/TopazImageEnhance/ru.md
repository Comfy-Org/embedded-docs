# Topaz Улучшение изображения

Узел **Topaz Image Enhance** обеспечивает масштабирование и улучшение изображения, соответствующие отраслевым стандартам. Он обрабатывает одно входное изображение с помощью облачной модели ИИ, повышая качество, детализацию и разрешение. Узел предоставляет точный контроль над процессом улучшения, включая параметры творческого направления, фокусировки на объекте и сохранения лиц.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель ИИ, используемая для улучшения изображения. | COMBO | Да | `"Reimagine"` |
| `image` | Входное изображение для улучшения. Поддерживается только одно изображение. | IMAGE | Да | - |
| `prompt` | Необязательный текстовый промпт для творческого направления масштабирования (по умолчанию: пусто). | STRING | Нет | - |
| `subject_detection` | Управляет тем, на какую часть изображения направлено улучшение (по умолчанию: "All"). | COMBO | Нет | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | Улучшать лица (если они присутствуют) во время обработки (по умолчанию: True). | BOOLEAN | Нет | - |
| `face_enhancement_creativity` | Устанавливает уровень креативности для улучшения лиц (по умолчанию: 0.0). | FLOAT | Нет | 0.0 - 1.0 |
| `face_enhancement_strength` | Управляет резкостью улучшенных лиц относительно фона (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 1.0 |
| `crop_to_fill` | По умолчанию, когда соотношение сторон вывода отличается, изображение дополняется полями (letterbox). Включите эту опцию, чтобы обрезать изображение, заполняя выходные размеры (по умолчанию: False). | BOOLEAN | Нет | - |
| `output_width` | Нулевое значение означает автоматический расчет (обычно это исходный размер или `output_height`, если он задан) (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `output_height` | Нулевое значение означает вывод с той же высотой, что и у исходного изображения, или с шириной вывода (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `creativity` | Управляет общим уровнем креативности улучшения (по умолчанию: 3). | INT | Нет | 1 - 9 |
| `face_preservation` | Сохранять идентичность лиц объектов (по умолчанию: True). | BOOLEAN | Нет | - |
| `color_preservation` | Сохранять исходные цвета (по умолчанию: True). | BOOLEAN | Нет | - |

**Примечание:** Этот узел может обрабатывать только одно входное изображение. Подача пакета из нескольких изображений приведет к ошибке.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Улучшенное выходное изображение. | IMAGE |
