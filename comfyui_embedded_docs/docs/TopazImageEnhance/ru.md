# Topaz Улучшение изображения

Узел Topaz Image Enhance обеспечивает апскейлинг и улучшение изображения на уровне отраслевых стандартов. Он обрабатывает одно входное изображение с помощью облачной модели ИИ для повышения качества, детализации и разрешения. Узел предоставляет детальный контроль над процессом улучшения, включая параметры творческого руководства, фокусировки на объекте и сохранения лиц.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель ИИ, используемая для улучшения изображения. | COMBO | Да | `"Reimagine"` |
| `изображение` | Входное изображение для улучшения. Поддерживается только одно изображение. | IMAGE | Да | - |
| `промпт` | Необязательный текстовый промпт для творческого руководства апскейлингом (по умолчанию: пусто). | STRING | Нет | - |
| `обнаружение объекта` | Управляет тем, на какую часть изображения направлено улучшение (по умолчанию: "All"). | COMBO | Нет | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `улучшение лица` | Улучшать лица (если они присутствуют) во время обработки (по умолчанию: True). | BOOLEAN | Нет | - |
| `креативность улучшения лица` | Задайте уровень креативности для улучшения лиц (по умолчанию: 0.0). | FLOAT | Нет | 0.0 - 1.0 |
| `степень улучшения лица` | Управляет тем, насколько резкими будут улучшенные лица по сравнению с фоном (по умолчанию: 1.0). | FLOAT | Нет | 0.0 - 1.0 |
| `обрезать до заполнения` | По умолчанию изображение масштабируется с добавлением полей (letterbox), если выходное соотношение сторон отличается. Включите, чтобы обрезать изображение для заполнения размеров вывода (по умолчанию: False). | BOOLEAN | Нет | - |
| `выходная ширина` | Нулевое значение означает автоматический расчет (обычно это исходный размер или output_height, если он задан) (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `выходная высота` | Нулевое значение означает вывод с той же высотой, что и у оригинала, или с шириной вывода (по умолчанию: 0). | INT | Нет | 0 - 32000 |
| `креативность` | Управляет общим уровнем креативности улучшения (по умолчанию: 3). | INT | Нет | 1 - 9 |
| `сохранение лица` | Сохранять идентичность лиц субъектов (по умолчанию: True). | BOOLEAN | Нет | - |
| `сохранение цвета` | Сохранять исходные цвета (по умолчанию: True). | BOOLEAN | Нет | - |

**Примечание:** Этот узел может обрабатывать только одно входное изображение. Подача пакета из нескольких изображений приведет к ошибке.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Улучшенное выходное изображение. | IMAGE |
