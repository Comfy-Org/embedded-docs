# تحسين الصورة بواسطة Topaz

توفر عقدة Topaz Image Enhance تكبيرًا وتحسينًا للصور بمستوى المعايير الصناعية. فهي تعالج صورة إدخال واحدة باستخدام نموذج ذكاء اصطناعي قائم على السحابة لتحسين الجودة والتفاصيل والدقة. تقدم العقدة تحكمًا دقيقًا في عملية التحسين، بما في ذلك خيارات للتوجيه الإبداعي، والتركيز على الموضوع، والحفاظ على الوجه.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المستخدم لتحسين الصورة. | COMBO | نعم | `"Reimagine"` |
| `image` | صورة الإدخال المراد تحسينها. يتم دعم صورة واحدة فقط. | IMAGE | نعم | - |
| `prompt` | موجه نصي اختياري لتوجيه التكبير الإبداعي (الافتراضي: فارغ). | STRING | لا | - |
| `subject_detection` | يتحكم في أي جزء من الصورة يركز عليه التحسين (الافتراضي: "All"). | COMBO | لا | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | يحسّن الوجوه (إذا وُجدت) أثناء المعالجة (الافتراضي: True). | BOOLEAN | لا | - |
| `face_enhancement_creativity` | يضبط مستوى الإبداع لتحسين الوجه (الافتراضي: 0.0). | FLOAT | لا | 0.0 - 1.0 |
| `face_enhancement_strength` | يتحكم في درجة حدة الوجوه المحسّنة مقارنة بالخلفية (الافتراضي: 1.0). | FLOAT | لا | 0.0 - 1.0 |
| `crop_to_fill` | افتراضيًا، تُضاف أشرطة سوداء أعلى وأسفل الصورة عندما يختلف نسبة أبعاد الإخراج. قم بالتفعيل لقص الصورة لملء أبعاد الإخراج (الافتراضي: False). | BOOLEAN | لا | - |
| `output_width` | القيمة صفر تعني الحساب تلقائيًا (عادةً سيكون الحجم الأصلي أو `output_height` إذا تم التحديد) (الافتراضي: 0). | INT | لا | 0 - 32000 |
| `output_height` | القيمة صفر تعني الإخراج بنفس ارتفاع الصورة الأصلية أو عرض الإخراج (الافتراضي: 0). | INT | لا | 0 - 32000 |
| `creativity` | يتحكم في مستوى الإبداع الكلي للتحسين (الافتراضي: 3). | INT | لا | 1 - 9 |
| `face_preservation` | الحفاظ على الهوية الوجهية للأشخاص (الافتراضي: True). | BOOLEAN | لا | - |
| `color_preservation` | الحفاظ على الألوان الأصلية (الافتراضي: True). | BOOLEAN | لا | - |

**ملاحظة:** يمكن لهذه العقدة معالجة صورة إدخال واحدة فقط. سيؤدي توفير مجموعة من عدة صور إلى حدوث خطأ.
