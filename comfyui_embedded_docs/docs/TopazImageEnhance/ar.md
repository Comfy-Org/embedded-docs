# تحسين الصورة بواسطة Topaz

توفر عقدة Topaz Image Enhance تكبيرًا وتحسينًا للصورة بمستوى احترافي. تقوم بمعالجة صورة إدخال واحدة باستخدام نموذج ذكاء اصطناعي سحابي لتحسين الجودة والتفاصيل والدقة. تمنح العقدة تحكمًا دقيقًا في عملية التحسين، بما في ذلك خيارات التوجيه الإبداعي، والتركيز على الموضوع، والحفاظ على ملامح الوجه.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | نموذج الذكاء الاصطناعي المستخدم لتحسين الصورة. | COMBO | نعم | `"Reimagine"` |
| `الصورة` | صورة الإدخال المراد تحسينها. يتم دعم صورة واحدة فقط. | IMAGE | نعم | - |
| `الموجه` | موجه نصي اختياري لتوجيه التكبير الإبداعي (الافتراضي: فارغ). | STRING | لا | - |
| `اكتشاف الموضوع` | يتحكم في الجزء من الصورة الذي يركز عليه التحسين (الافتراضي: `"All"`). | COMBO | لا | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `تحسين الوجه` | تعزيز الوجوه (إذا كانت موجودة) أثناء المعالجة (الافتراضي: True). | BOOLEAN | لا | - |
| `إبداعية تحسين الوجه` | اضبط مستوى الإبداع لتعزيز الوجه (الافتراضي: 0.0). | FLOAT | لا | 0.0 - 1.0 |
| `قوة تحسين الوجه` | يتحكم في درجة وضوح الوجوه المعززة مقارنة بالخلفية (الافتراضي: 1.0). | FLOAT | لا | 0.0 - 1.0 |
| `قص لملء` | بشكل افتراضي، تُضاف أشرطة سوداء أعلى وأسفل الصورة عند اختلاف نسبة الأبعاد الناتجة. قم بالتفعيل لقص الصورة لملء أبعاد الإخراج (الافتراضي: False). | BOOLEAN | لا | - |
| `عرض الإخراج` | القيمة صفر تعني الحساب تلقائيًا (عادةً سيكون الحجم الأصلي أو output_height إذا تم تحديده) (الافتراضي: 0). | INT | لا | 0 - 32000 |
| `ارتفاع الإخراج` | القيمة صفر تعني الإخراج بنفس ارتفاع الأصل أو عرض الإخراج (الافتراضي: 0). | INT | لا | 0 - 32000 |
| `الإبداع` | يتحكم في مستوى الإبداع الكلي للتحسين (الافتراضي: 3). | INT | لا | 1 - 9 |
| `حفظ الوجه` | الحفاظ على الهوية الوجهية للأشخاص (الافتراضي: True). | BOOLEAN | لا | - |
| `حفظ الألوان` | الحفاظ على الألوان الأصلية (الافتراضي: True). | BOOLEAN | لا | - |

**ملاحظة:** يمكن لهذه العقدة معالجة صورة إدخال واحدة فقط. سيؤدي توفير مجموعة دفعة من صور متعددة إلى حدوث خطأ.

| اسم المخرج | الوصف | نوع البيانات |
