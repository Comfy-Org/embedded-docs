# تحسين الصورة بواسطة Topaz

توفّر عقدة Topaz Image Enhance رفعًا لدقة الصور وتحسينًا لها وفق المعايير الصناعية. تعالج صورة إدخال واحدة باستخدام نموذج ذكاء اصطناعي سحابي لتحسين الجودة والتفاصيل والدقة. وتوفّر العقدة تحكمًا دقيقًا في عملية التحسين، بما في ذلك خيارات للتوجيه الإبداعي وتركيز الموضوع والحفاظ على ملامح الوجه.

هذه العقدة إصدار قديم ومُعلّمة كمهملة في الواجهة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المستخدم لتحسين الصورة. | COMBO | نعم | `"Reimagine"` |
| `image` | صورة الإدخال المراد تحسينها. يتم دعم صورة واحدة فقط. | IMAGE | نعم | - |
| `prompt` | نص توجيهي اختياري لإرشاد رفع الدقة الإبداعي (القيمة الافتراضية: فارغ). | STRING | لا | - |
| `subject_detection` | يتحكم في الجزء الذي يركز عليه التحسين في الصورة (القيمة الافتراضية: `"All"`). | COMBO | لا | `"All"`<br>`"Foreground"`<br>`"Background"` |
| `face_enhancement` | تحسين الوجوه (إن وُجدت) أثناء المعالجة (القيمة الافتراضية: True). | BOOLEAN | لا | - |
| `face_enhancement_creativity` | تعيين مستوى الإبداع لتحسين الوجه (القيمة الافتراضية: 0.0). | FLOAT | لا | 0.0 - 1.0 |
| `face_enhancement_strength` | يتحكم في مدى حدة الوجوه المحسّنة مقارنةً بالخلفية (القيمة الافتراضية: 1.0). | FLOAT | لا | 0.0 - 1.0 |
| `crop_to_fill` | افتراضيًا، تُضاف أشرطة سوداء إلى الصورة (letterbox) عندما تختلف نسبة أبعاد الخرج. فعّل هذا الخيار لقص الصورة لملء أبعاد الخرج (القيمة الافتراضية: False). | BOOLEAN | لا | - |
| `output_width` | القيمة صفر تعني الحساب تلقائيًا (عادةً ستكون الحجم الأصلي أو `output_height` إذا تم تحديده) (القيمة الافتراضية: 0). | INT | لا | 0 - 32000 |
| `output_height` | القيمة صفر تعني الإخراج بالارتفاع نفسه مثل الأصل أو عرض الإخراج (القيمة الافتراضية: 0). | INT | لا | 0 - 32000 |
| `creativity` | يتحكم في مستوى الإبداع العام للتحسين (القيمة الافتراضية: 3). | INT | لا | 1 - 9 |
| `face_preservation` | الحفاظ على الهوية الوجهية للأشخاص (القيمة الافتراضية: True). | BOOLEAN | لا | - |
| `color_preservation` | الحفاظ على الألوان الأصلية (القيمة الافتراضية: True). | BOOLEAN | لا | - |

**ملاحظة:** يمكن لهذه العقدة معالجة صورة إدخال واحدة فقط. سيؤدي تقديم دفعة من عدة صور إلى حدوث خطأ.
