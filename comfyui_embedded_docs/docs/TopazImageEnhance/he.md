# TopazImageEnhance

הצומת Topaz Image Enhance מספק שיפור והגדלה של תמונות בסטנדרט תעשייתי. הוא מעבד תמונת קלט בודדת באמצעות מודל AI מבוסס ענן כדי לשפר איכות, פרטים ורזולוציה. הצומת מציע שליטה מדויקת בתהליך השיפור, כולל אפשרויות להנחיה יצירתית, מיקוד בנושא ושימור פנים.

צומת זה הוא גרסת מורשת והוא מסומן כ-deprecated בממשק.
