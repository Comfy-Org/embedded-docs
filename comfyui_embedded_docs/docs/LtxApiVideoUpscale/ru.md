# LTX Video Upscale

Увеличивает разрешение видео до 1080p, 4K или 8K, сохраняя его соотношение сторон, частоту кадров и аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `video` | Видео для увеличения разрешения, с короткой стороной не менее 480 пикселей и размером не более 7680x4320 в любой ориентации. До 2401 кадра для 1080p, 601 кадра для 4K и 241 кадра для 8K. | VIDEO | Да | - |
| `resolution` | Выходной размер: максимально возможный, помещающийся в 1920x1080, 3840x2160 или 7680x4320, с поворотом для портретных видео. По умолчанию: `"4k"`. | COMBO | Да | `"1080p"`<br>`"4k"`<br>`"8k"` |
| `seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Нет | от 0 до 4294967295 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Видео с увеличенным разрешением и сохранённым аудио. | VIDEO |
