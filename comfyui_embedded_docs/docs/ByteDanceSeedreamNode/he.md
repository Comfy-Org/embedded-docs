# ByteDance Seedream 4.5 & 5.0

הצומת ByteDance Seedream 4.5 & 5.0 מספק יכולות מאוחדות של יצירת תמונה מטקסט ועריכה מדויקת של משפט בודד ברזולוציה של עד 4K. הוא יכול ליצור תמונות חדשות מפרומפטים טקסטואליים או לערוך תמונות קיימות באמצעות הוראות טקסט. הצומת תומך גם ביצירת תמונה בודדת וגם ביצירה סדרתית של מספר תמונות קשורות.

**הערה:** צומת זה מסומן כמיושן בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל Seedream לשימוש ביצירה. | STRING | כן | "seedream 5.0 pro"<br>"seedream 5.0 lite"<br>"seedream-4-5-251128"<br>"seedream-4-0-250828" |
| `prompt` | הנחיית טקסט ליצירה או עריכה של תמונה. חייבת להכיל לפחות תו אחד. | STRING | כן | - |
| `image` | תמונת/תמונות קלט ליצירת תמונה-לתמונה. תמונת/תמונות עזר ליצירה עם עזר בודד או מרובה. מקסימום 14 תמונות עזר עבור seedream-5-0-260128, או 10 עבור מודלים אחרים. | IMAGE | לא | - |
| `size_preset` | בחר גודל מומלץ. בחר Custom כדי להשתמש ברוחב ובגובה שלמטה. | STRING | לא | אפשרויות מרובות זמינות |
| `width` | רוחב מותאם אישית לתמונה. הערך פועל רק אם `size_preset` מוגדר ל-`Custom`. ברירת מחדל: 2048. | INT | לא | 1024 עד 6240 (צעד 2) |
| `height` | גובה מותאם אישית לתמונה. הערך פועל רק אם `size_preset` מוגדר ל-`Custom`. ברירת מחדל: 2048. | INT | לא | 1024 עד 4992 (צעד 2) |
| `sequential_image_generation` | מצב יצירת תמונות קבוצתית. "disabled" מייצר תמונה בודדת. "auto" נותן למודל להחליט אם ליצור מספר תמונות קשורות (למשל, סצנות סיפור, וריאציות דמות). ברירת מחדל: "disabled". | STRING | לא | "disabled"<br>"auto" |
| `max_images` | מספר התמונות המקסימלי ליצירה כאשר `sequential_image_generation='auto'`. סך התמונות (קלט + נוצר) לא יכול לעלות על 15. ברירת מחדל: 1. | INT | לא | 1 עד 15 (צעד 1) |
| `seed` | Seed לשימוש ביצירה. ברירת מחדל: 0. | INT | לא | 0 עד 2147483647 (צעד 1) |
| `watermark` | האם להוסיף סימן מים 'AI generated' לתמונה. ברירת מחדל: False. | BOOLEAN | לא | - |
| `fail_on_partial` | אם מופעל, הפסק את הביצוע אם תמונות מבוקשות חסרות או מחזירות שגיאה. ברירת מחדל: True. | BOOLEAN | לא | - |

**הערות לגבי מגבלות הפרמטרים:**
- רזולוציית התמונה המינימלית תלויה במודל שנבחר: 3.68MP עבור מודלי seedream-4-5 ו-seedream-5-0, ו-0.92MP עבור מודלי seedream-4-0.
- רזולוציית התמונה המקסימלית היא 10.4MP עבור מו�דלי seedream-5-0 ו-16.78MP עבור מודלים אחרים.
- תמונות עזר חייבות להיות ביחס רוחב-גובה בין 1:3 ל-3:1.
- כאשר `sequential_image_generation` מוגדר ל-`auto`, סך תמונות הקלט בתוספת `max_images` לא יכול לעלות על 15.
- הפרמטרים `width` ו-`height` משמשים רק כאשר `size_preset` מוגדר ל-`Custom`.
