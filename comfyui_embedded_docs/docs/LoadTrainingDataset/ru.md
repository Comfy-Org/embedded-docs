# Загрузить обучающий набор данных

Этот узел загружает закодированный набор данных для обучения (латентные векторы и conditioning), который ранее был сохранён на диск. Он читает все файлы сегментов данных `shard_*.pkl` из выбранной папки набора данных в каталоге datasets и возвращает объединённые латентные векторы и данные conditioning для использования в рабочих процессах обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `folder_name` | Сохранённый набор данных для загрузки из каталога datasets. | COMBO | Да | Один вариант на каждую папку набора данных, найденную в каталоге datasets |

Примечание: варианты для `folder_name` создаются автоматически путём сканирования каталога datasets. Подпапка считается набором данных, если она содержит файл `metadata.json` или хотя бы один файл `.safetensors` (сканирование не заходит внутрь папки, которая соответствует этому условию). Выбранная папка набора данных ищется среди всех настроенных корневых каталогов datasets, и имя папки должно указывать на подпапку внутри одного из этих корневых каталогов. Узел читает все файлы с именем `shard_*.pkl` в выбранной папке в отсортированном порядке и выдаёт ошибку, если не найдено ни одного файла сегмента или если папку не удаётся найти.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список латентных словарей (выходной список), где каждый словарь содержит ключ `"samples"` с тензором. | LATENT |
| `conditioning` | Список списков conditioning (выходной список), где каждый внутренний список содержит данные conditioning для соответствующего образца. | CONDITIONING |
