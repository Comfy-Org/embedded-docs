# Загрузить обучающий набор данных

Этот узел загружает закодированный обучающий набор данных (латентные представления и кондиционирование), ранее сохранённый на диск. Он считывает все файлы шардов данных из выбранной папки набора данных в каталоге datasets и возвращает объединённые латентные векторы и данные кондиционирования для использования в рабочих процессах обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `folder_name` | Сохранённый набор данных для загрузки из каталога datasets. | COMBO | Да | Один вариант на каждую папку набора данных, найденную в каталоге datasets |

Примечание: параметры `folder_name` формируются автоматически путём сканирования каталога datasets. Подпапка считается набором данных, если она содержит файл `metadata.json` или хотя бы один файл `.safetensors`. Выбранная папка набора данных ищется во всех настроенных корневых каталогах datasets. Узел считывает все файлы с именем `shard_*.pkl` в выбранной папке и вызывает ошибку, если файлы шардов не найдены.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список латентных словарей, где каждый словарь содержит ключ `"samples"` с тензором. | LATENT |
| `conditioning` | Список списков кондиционирования, где каждый внутренний список содержит данные кондиционирования для соответствующего образца. | CONDITIONING |
