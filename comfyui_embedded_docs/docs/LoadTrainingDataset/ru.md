# Загрузить обучающий набор данных

Этот узел загружает закодированный обучающий набор данных (латентные представления и кондиционирование) с диска для использования в обучении. После выбора ранее сохранённой папки с набором данных он считывает все файлы шардов внутри неё и возвращает объединённые латентные векторы и данные кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `folder_name` | Сохранённый набор данных для загрузки из каталога datasets. | COMBO | Да | Динамически заполняется всеми папками наборов данных, найденными в зарегистрированных каталогах datasets. Перечисляются только папки, содержащие файл `metadata.json` или файлы `.safetensors`. |

**Примечание:** Выбранная папка с набором данных должна быть подпапкой зарегистрированного каталога datasets и должна содержать хотя бы один файл шарда с именем `shard_*.pkl`; в противном случае узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список словарей латентных представлений, загруженных из шардов набора данных, каждый из которых содержит тензор `samples`. | LATENT |
| `conditioning` | Список списков кондиционирования, загруженных из шардов набора данных, по одному на каждый пример. | CONDITIONING |
