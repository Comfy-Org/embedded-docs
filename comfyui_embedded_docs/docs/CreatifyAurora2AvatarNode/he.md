# Creatify Aurora 2.0 Avatar

Creatify Aurora 2.0 Avatar הופך תמונה אחת בתוספת קטע דיבור או שיר לווידאו מדבר או שר. אורך הווידאו זהה לאורך האודיו המחובר, והוא שומר על האודיו ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `תמונה` | תמונה של האדם שיש להנפיש. לפחות 256 פיקסלים בכל צד ויחס גובה-רוחב בין 1:4 ל-4:1; הווידאו שומר על יחס הגובה-רוחב של התמונה. | IMAGE | כן | - |
| `שמע` | דיבור או שיר שמניעים את הפה ואת אורך הווידאו. עד 60 שניות, או 14 שניות ב־`"2k"`; החיוב הוא לפי כל שנייה שהחלה. | AUDIO | כן | עד 60 שניות |
| `רזולוציה` | רזולוציית וידאו הפלט (ברירת מחדל: `"720p"`). | COMBO | כן | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"2k"` |
| `text_prompt` | סצנה, מצלמה, תאורה, הבעה או תנועה עבור הצילום. ערך ריק משאיר את התמונה כפי שהיא (ברירת מחדל: מחרוזת ריקה). | STRING | כן | טקסט כלשהו |
| `זרע` | הערך `seed` קובע אם הצומת יופעל מחדש. התוצאות אינן דטרמיניסטיות ללא תלות ב־`seed` (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |

**אילוצים:** תמונה שאחד מצדדיה קטן מ-256 פיקסלים, או שיחס הגובה-רוחב שלה מחוץ לטווח 1:4 עד 4:1, תגרום לשגיאה. אודיו ארוך מהמגבלה עבור הרזולוציה שנבחרה יידחה: 60 שניות בדרך כלל ו-14 שניות ב־`"2k"`.
