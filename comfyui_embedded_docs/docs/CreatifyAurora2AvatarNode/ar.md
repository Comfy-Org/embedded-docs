# Creatify Aurora 2.0 Avatar

يحوّل Creatify Aurora 2.0 Avatar صورة واحدة مع مقطع كلام أو أغنية إلى فيديو لشخص يتحدث أو يغني. يكون طول الفيديو مساويًا لطول الصوت المتصل، ويحتفظ بذلك الصوت دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة الشخص المراد تحريكه. لا يقل كل بُعد فيها عن 256 بكسل، وتكون نسبة العرض إلى الارتفاع بين 1:4 و4:1؛ يحافظ الفيديو على نسبة العرض إلى الارتفاع للصورة. | IMAGE | نعم | - |
| `audio` | كلام أو أغنية تحرّك الفم وتحدد طول الفيديو. حتى 60 ثانية، أو 14 ثانية عند `"2k"`؛ وتُحتسب التكلفة لكل ثانية تبدأ. | AUDIO | نعم | حتى 60 ثانية |
| `resolution` | دقة فيديو المخرجات (الافتراضي: `"720p"`). | COMBO | نعم | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"2k"` |
| `text_prompt` | المشهد أو الكاميرا أو الإضاءة أو التعبير أو الحركة للقطة. تركه فارغًا يبقي الصورة كما هي (الافتراضي: سلسلة فارغة). | STRING | نعم | أي نص |
| `seed` | تتحكم البذرة في ما إذا كانت العقدة ستُعاد تشغيلها. النتائج غير حتمية بغض النظر عن البذرة (الافتراضي: 42). | INT | نعم | 0 إلى 2147483647 |

**القيود:** تؤدي الصورة التي يقل أحد أبعادها عن 256 بكسل، أو التي تقع نسبة عرضها إلى ارتفاعها خارج النطاق 1:4 إلى 4:1، إلى رفع خطأ. يتم رفض الصوت الأطول من الحد المسموح به للدقة المختارة: 60 ثانية عادةً و14 ثانية عند `"2k"`.
