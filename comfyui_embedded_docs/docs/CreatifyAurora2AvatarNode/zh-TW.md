# Creatify Aurora 2.0 Avatar

Creatify Aurora 2.0 Avatar 可將單張照片加上一段語音或歌曲片段，轉換為說話或歌唱的影片。影片長度與所連接的音訊相同，且該音訊保持不變。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要製作動畫的人物照片。每邊至少 256 像素，長寬比介於 1:4 至 4:1 之間；影片會保持照片的長寬比。 | IMAGE | 是 | - |
| `audio` | 驅動嘴型與影片長度的語音或歌曲。最長 60 秒，在 `"2k"` 時為 14 秒；依已開始的秒數計費。 | AUDIO | 是 | 最多 60 秒 |
| `resolution` | 輸出影片的解析度（預設：`"720p"`）。 | COMBO | 是 | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"2k"` |
| `text_prompt` | 鏡頭的場景、攝影機、光線、表情或動作。留空則保持照片原樣（預設：空字串）。 | STRING | 是 | 任意文字 |
| `seed` | 種子控制節點是否重新執行。無論種子為何，結果均為非確定性的（預設：42）。 | INT | 是 | 0 至 2147483647 |

**限制：** 單邊小於 256 像素，或長寬比超出 1:4 至 4:1 的照片會引發錯誤。超過所選解析度上限的音訊會被拒絕：一般為 60 秒，`"2k"` 時為 14 秒。
