# Creatify Aurora 2.0 Avatar

Creatify Aurora 2.0 Avatar превращает одну фотографию вместе с речевым или музыкальным фрагментом в видео с говорящим или поющим человеком. Длительность видео совпадает с длительностью подключённого аудио, и это аудио остаётся неизменным.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Фотография человека для анимации. Не менее 256 пикселей по каждой стороне и соотношение сторон от 1:4 до 4:1; видео сохраняет соотношение сторон фотографии. | IMAGE | Да | - |
| `аудио` | Речь или песня, которые управляют движением рта и длительностью видео. До 60 секунд или 14 секунд при `"2k"`; оплата взимается за каждую начатую секунду. | AUDIO | Да | До 60 секунд |
| `разрешение` | Разрешение выходного видео (по умолчанию: `"720p"`). | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"2k"` |
| `text_prompt` | Сцена, камера, освещение, выражение лица или движение для кадра. Пустое значение оставляет фотографию без изменений (по умолчанию: пустая строка). | STRING | Да | Любой текст |
| `сид` | Параметр `seed` управляет тем, будет ли узел запускаться повторно. Результаты недетерминированы независимо от `seed` (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

**Ограничения:** если фотография меньше 256 пикселей по любой стороне или её соотношение сторон выходит за пределы от 1:4 до 4:1, возникает ошибка. Аудио длиннее лимита для выбранного разрешения отклоняется: 60 секунд в обычном режиме и 14 секунд при `"2k"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Видео с говорящим или поющим человеком вместе с подключённым аудио. | VIDEO |
