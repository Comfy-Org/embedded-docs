# חיתוך לטנט

צומת LatentCrop מיועד לביצוע פעולות חיתוך על ייצוגים לטנטיים של תמונות. הוא מאפשר לציין את מידות החיתוך ומיקומו, ובכך לאפשר שינויים ממוקדים במרחב הלטנטי.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `samples` | פרמטר `samples` מייצג את הייצוגים הלטנטיים שיש לחתוך. הוא חיוני להגדרת הנתונים שעליהם תבוצע פעולת החיתוך. | `LATENT` |
| `width` | מציין את רוחב אזור החיתוך. הוא משפיע ישירות על מידות ייצוג הלטנטי בפלט. | `INT` |
| `height` | מציין את גובה אזור החיתוך, ומשפיע על גודלו של ייצוג לטנטי החתוך המתקבל. | `INT` |
| `x` | קובע את קואורדינטת ה-x ההתחלתית של אזור החיתוך, ומשפיע על מיקום החיתוך בתוך ייצוג הלטנטי המקורי. | `INT` |
| `y` | קובע את קואורדינטת ה-y ההתחלתית של אזור החיתוך, ומגדיר את מיקום החיתוך בתוך ייצוג הלטנטי המקורי. | `INT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `latent` | הפלט הוא ייצוג לטנטי שונה שעבר את החיתוך שצוין. | `LATENT` |
