# צילום מצלמת רשת

צומת WebcamCapture לוכד תמונות מהתקן מצלמת רשת וממיר אותן לפורמט שניתן להשתמש בו בתוך זרימות העבודה של ComfyUI. הוא יורש מצומת LoadImage ומספק אפשרויות לשליטה בממדי הלכידה ובתזמון. כאשר הוא מופעל, הצומת יכול ללכוד תמונות חדשות בכל פעם שתור זרימת העבודה מעובד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | מקור הקלט של מצלמת הרשת שממנו יש ללכוד תמונות | WEBCAM | כן | - |
| `width` | הרוחב הרצוי עבור התמונה שנלכדה (ברירת מחדל: 0, משתמש ברזולוציה המקורית של מצלמת הרשת) | INT | כן | 0 עד MAX_RESOLUTION |
| `height` | הגובה הרצוי עבור התמונה שנלכדה (ברירת מחדל: 0, משתמש ברזולוציה המקורית של מצלמת הרשת) | INT | כן | 0 עד MAX_RESOLUTION |
| `capture_on_queue` | כאשר מופעל, לוכד תמונה חדשה בכל פעם שתור זרימת העבודה מעובד (ברירת מחדל: True) | BOOLEAN | כן | - |

**הערה:** כאשר גם `width` וגם `height` מוגדרים ל-0, הצומת משתמש ברזולוציה המקורית של מצלמת הרשת. הגדרת אחד מהממדים לערך שאינו אפס תשנה את גודל התמונה שנלכדה בהתאם.
