# CFG Гид

Узел CFGGuider создает систему управления процессом семплирования при генерации изображений. Он принимает модель вместе с положительным и отрицательным кондиционированием (conditioning), а затем применяет масштаб бесклассификаторного управления (classifier-free guidance), чтобы направлять генерацию к желаемому содержимому, избегая нежелательных элементов. Этот узел возвращает объект guider, который может использоваться узлами семплирования для управления направлением генерации изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, используемая для управления | MODEL | Да | - |
| `positive` | Положительное кондиционирование, направляющее генерацию к желаемому содержимому | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование, которое уводит генерацию от нежелательного содержимого | CONDITIONING | Да | - |
| `cfg` | Масштаб бесклассификаторного управления, определяющий, насколько сильно кондиционирование влияет на генерацию (по умолчанию: 8.0) | FLOAT | Да | 0.0 to 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Объект guider, который может быть передан узлам семплирования для управления процессом генерации | GUIDER |
