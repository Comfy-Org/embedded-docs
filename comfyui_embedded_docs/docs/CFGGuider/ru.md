# CFG Гид

Узел CFG Guider создает систему управления процессом семплирования при генерации изображений. Он принимает модель вместе с положительными и отрицательными conditioning, затем применяет коэффициент бесклассового управления (classifier-free guidance), чтобы направлять генерацию к желаемому контенту и избегать нежелательных элементов. Этот узел выводит объект guider, который можно использовать в узлах семплирования для управления направлением генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для управления генерацией | MODEL | Да | - |
| `положительный` | Положительное conditioning, направляющее генерацию к желаемому контенту | CONDITIONING | Да | - |
| `отрицательный` | Отрицательное conditioning, уводящее генерацию от нежелательного контента | CONDITIONING | Да | - |
| `cfg` | Коэффициент бесклассового управления, определяющий, насколько сильно conditioning влияет на генерацию (по умолчанию: 8.0) | FLOAT | Да | 0.0 до 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Объект guider, который можно передавать в узлы семплирования для управления процессом генерации | GUIDER |
