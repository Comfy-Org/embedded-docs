# CFGGuider

צומת CFG Guider יוצר מערכת הנחיה לשליטה בתהליך הדגימה ביצירת תמונות. הוא מקבל מודל יחד עם קלטי קונדישנינג חיוביים ושליליים, ולאחר מכן מחיל סקאלת הנחיה ללא מסווג (classifier-free guidance scale) כדי לכוון את היצירה לתוכן הרצוי תוך הימנעות מרכיבים לא רצויים. צומת זה פולט אובייקט guider שניתן להעביר לצומתי דגימה כדי לשלוט בכיוון יצירת התמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שישמש להנחיה | MODEL | כן | - |
| `positive` | הקונדישנינג החיובי שמכוון את היצירה לתוכן הרצוי | CONDITIONING | כן | - |
| `negative` | הקונדישנינג השלילי שמסיט את היצירה הרחק מתוכן לא רצוי | CONDITIONING | כן | - |
| `cfg` | סקאלת ההנחיה ללא מסווג שקובעת באיזו עוצמה הקונדישנינג משפיע על היצירה (ברירת מחדל: 8.0) | FLOAT | כן | 0.0 to 100.0 (step: 0.1) |
