# StabilityAudioInpaint

משנה חלק מדגימת אודיו קיימת באמצעות הוראות טקסט. צומת זה מאפשר לשנות קטעים ספציפיים באודיו על ידי אספקת פרומפטים תיאוריים, ובכך לבצע למעשה "inpainting" או ליצור מחדש קטעים נבחרים תוך שמירה על שאר האודיו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI לשימוש ב-inpainting של אודיו. | STRING | כן | `"stable-audio-2.5"` |
| `prompt` | תיאור טקסטואלי שמנחה כיצד יש לשנות את האודיו (ברירת מחדל: ריק). אורך מקסימלי הוא 10,000 תווים. | STRING | כן |  |
| `audio` | קובץ אודיו קלט לשנות. האודיו חייב להיות באורך שבין 6 ל-190 שניות. | AUDIO | כן |  |
| `duration` | שולט במשך בשניות של האודיו הנוצר (ברירת מחדל: 190). | INT | לא | 1 to 190 |
| `seed` | ה-seed האקראי המשמש ליצירה (ברירת מחדל: 0). | INT | לא | 0 to 4294967294 |
| `steps` | שולט במספר צעדי הדגימה (ברירת מחדל: 8). | INT | לא | 4 to 8 |
| `mask_start` | מיקום התחלה בשניות של קטע האודיו שיש לשנות (ברירת מחדל: 30). | INT | לא | 0 to 190 |
| `mask_end` | מיקום סיום בשניות של קטע האודיו שיש לשנות (ברירת מחדל: 190). | INT | לא | 0 to 190 |

**הערה:** הערך של `mask_end` חייב להיות גדול מהערך של `mask_start`. אורך קלט האודיו חייב להיות בין 6 ל-190 שניות.
