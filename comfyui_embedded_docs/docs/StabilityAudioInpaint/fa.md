# StabilityAudioInpaint

بخشی از یک نمونه صوتی موجود را با استفاده از دستورهای متنی تغییر می‌دهد. این گره به شما امکان می‌دهد بخش‌های مشخصی از صدا را با ارائهٔ درخواست‌های توصیفی تغییر دهید و در عمل بخش‌های انتخاب‌شده را «inpainting» یا بازتولید کنید، در حالی که بقیهٔ صدا حفظ می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل هوش مصنوعی برای استفاده در inpainting صدا. | STRING | بله | `"stable-audio-2.5"` |
| `prompt` | توضیح متنی که نحوهٔ تغییر صدا را هدایت می‌کند (پیش‌فرض: خالی). حداکثر طول ۱۰٬۰۰۰ نویسه است. | STRING | بله |  |
| `audio` | فایل صوتی ورودی برای تغییر. مدت‌زمان صدا باید بین ۶ و ۱۹۰ ثانیه باشد. | AUDIO | بله |  |
| `duration` | مدت‌زمان تولید صدا را بر حسب ثانیه کنترل می‌کند (پیش‌فرض: ۱۹۰). | INT | خیر | 1 تا 190 |
| `seed` | دانهٔ تصادفی مورد استفاده برای تولید (پیش‌فرض: ۰). | INT | خیر | 0 تا 4294967294 |
| `steps` | تعداد مراحل نمونه‌برداری را کنترل می‌کند (پیش‌فرض: ۸). | INT | خیر | 4 تا 8 |
| `mask_start` | موقعیت شروع بر حسب ثانیه برای بخش صوتی مورد تغییر (پیش‌فرض: ۳۰). | INT | خیر | 0 تا 190 |
| `mask_end` | موقعیت پایان بر حسب ثانیه برای بخش صوتی مورد تغییر (پیش‌فرض: ۱۹۰). | INT | خیر | 0 تا 190 |

**توجه:** مقدار `mask_end` باید بزرگ‌تر از مقدار `mask_start` باشد. صدای ورودی باید بین ۶ و ۱۹۰ ثانیه باشد.
