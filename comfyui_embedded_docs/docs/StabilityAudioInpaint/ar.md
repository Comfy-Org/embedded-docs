# StabilityAudioInpaint

تحوّل جزءًا من عينة صوتية موجودة باستخدام تعليمات نصية. تتيح لك هذه العقدة تعديل أقسام محددة من الصوت عبر تقديم أوامر وصفية، ما يؤدي فعليًا إلى «الاستكمال الداخلي» أو إعادة توليد الأجزاء المحددة مع الحفاظ على بقية الصوت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الذكاء الاصطناعي المراد استخدامه للاستكمال الداخلي للصوت. | STRING | نعم | `"stable-audio-2.5"` |
| `prompt` | وصف نصي يوجّه كيفية تحويل الصوت (الافتراضي: فارغ). الحد الأقصى للطول هو 10,000 حرف. | STRING | نعم |  |
| `audio` | ملف الصوت المُدخل المراد تحويله. يجب أن تكون مدة الصوت بين 6 و190 ثانية. | AUDIO | نعم |  |
| `duration` | يتحكم في مدة الصوت المُولَّد بالثواني (الافتراضي: 190). | INT | لا | 1 إلى 190 |
| `seed` | البذرة العشوائية المستخدمة للتوليد (الافتراضي: 0). | INT | لا | 0 إلى 4294967294 |
| `steps` | يتحكم في عدد خطوات أخذ العينات (الافتراضي: 8). | INT | لا | 4 إلى 8 |
| `mask_start` | موضع البداية بالثواني لمقطع الصوت المراد تحويله (الافتراضي: 30). | INT | لا | 0 إلى 190 |
| `mask_end` | موضع النهاية بالثواني لمقطع الصوت المراد تحويله (الافتراضي: 190). | INT | لا | 0 إلى 190 |

**ملاحظة:** يجب أن تكون قيمة `mask_end` أكبر من قيمة `mask_start`. يجب أن تكون مدة الصوت المُدخل بين 6 و190 ثانية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `audio` | مخرج الصوت المُحوَّل مع تعديل المقطع المحدد وفقًا للوصف النصي. | AUDIO |
