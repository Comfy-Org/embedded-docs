# StabilityAudioInpaint

使用文字指令轉換現有音訊樣本的一部分。此節點可讓您透過提供描述性提示來修改音訊的特定區段，有效地「內補」或重新生成選定部分，同時保留其餘音訊。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於音訊內補的 AI 模型。 | STRING | 是 | `"stable-audio-2.5"` |
| `prompt` | 引導音訊應如何轉換的文字描述（預設：空）。最大長度為 10,000 個字元。 | STRING | 是 |  |
| `audio` | 要轉換的輸入音訊檔案。音訊長度必須介於 6 到 190 秒之間。 | AUDIO | 是 |  |
| `duration` | 控制生成音訊的持續時間（秒）（預設：190）。 | INT | 否 | 1 至 190 |
| `seed` | 用於生成的隨機種子（預設：0）。 | INT | 否 | 0 至 4294967294 |
| `steps` | 控制取樣步驟數（預設：8）。 | INT | 否 | 4 至 8 |
| `mask_start` | 要轉換之音訊區段的起始位置（秒）（預設：30）。 | INT | 否 | 0 至 190 |
| `mask_end` | 要轉換之音訊區段的結束位置（秒）（預設：190）。 | INT | 否 | 0 至 190 |

**注意：** `mask_end` 值必須大於 `mask_start` 值。輸入音訊的長度必須介於 6 到 190 秒之間。
