# StabilityAudioInpaint

Преобразует часть существующего аудиосэмпла с помощью текстовых инструкций. Этот узел позволяет изменять определённые участки аудио, задавая описательные промпты, фактически выполняя «inpainting» или перегенерацию выбранных фрагментов, сохраняя остальное аудио без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | ИИ-модель, используемая для аудиоинпейнтинга. | STRING | Да | `"stable-audio-2.5"` |
| `prompt` | Текстовое описание, задающее, как должно быть преобразовано аудио (по умолчанию: пусто). Максимальная длина — 10 000 символов. | STRING | Да |  |
| `audio` | Входной аудиофайл для преобразования. Длительность аудио должна быть от 6 до 190 секунд. | AUDIO | Да |  |
| `duration` | Управляет длительностью генерируемого аудио в секундах (по умолчанию: 190). | INT | Нет | 1 до 190 |
| `seed` | Случайное зерно, используемое для генерации (по умолчанию: 0). | INT | Нет | 0 до 4294967294 |
| `steps` | Управляет количеством шагов сэмплирования (по умолчанию: 8). | INT | Нет | 4 до 8 |
| `mask_start` | Начальная позиция в секундах для преобразуемого участка аудио (по умолчанию: 30). | INT | Нет | 0 до 190 |
| `mask_end` | Конечная позиция в секундах для преобразуемого участка аудио (по умолчанию: 190). | INT | Нет | 0 до 190 |

**Примечание:** Значение `mask_end` должно быть больше значения `mask_start`. Длительность входного аудио должна быть от 6 до 190 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Преобразованный аудиовыход, в котором указанный участок изменён в соответствии с промптом. | AUDIO |
