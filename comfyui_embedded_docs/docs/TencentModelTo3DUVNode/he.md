# Hunyuan3D: מודל ל-UV

צומת זה משתמש ב-API של Tencent Hunyuan3D כדי לבצע פריסת UV על מודל תלת-ממד. הוא מקבל קובץ מודל תלת-ממד כקלט, שולח אותו ל-API לעיבוד, ומחזיר את המודל המעובד בפורמטים OBJ ו-FBX יחד עם תמונת טקסטורת UV שנוצרה. למודל הקלט חייבים להיות פחות מ-30,000 פאות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | מודל תלת-ממד לקלט (GLB, OBJ או FBX). למודל חייבים להיות פחות מ-30000 פאות. | FILE3D | כן | GLB<br>OBJ<br>FBX |
| `seed` | `seed` שולט בשאלה אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 1) | INT | לא | 0 עד 2147483647 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `OBJ` | קובץ מודל תלת-ממד מעובד בפורמט OBJ. | FILE3D |
| `FBX` | קובץ מודל תלת-ממד מעובד בפורמט FBX. | FILE3D |
| `uv_image` | תמונת טקסטורת ה-UV שנוצרה. | IMAGE |
