# AddNoise

צומת זה מוסיף רעש מבוקר לתמונת latent באמצעות מחולל רעש מוגדר וערכי sigma. הוא מעבד את הקלט דרך מערכת הדגימה של המודל כדי להחיל סקיילינג רעש המתאים לטווח ה-sigma הנתון, ומחזיר ייצוג latent חדש עם הרעש שהוחל. צומת זה מסומן כעת כניסיוני.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל המכיל פרמטרי דגימה ופונקציות עיבוד | MODEL | כן | - |
| `noise` | מחולל הרעש שמייצר את תבנית הרעש הבסיסית | NOISE | כן | - |
| `sigmas` | ערכי sigma השולטים בעוצמת סקיילינג הרעש. אם ריק, הצומת מחזיר את תמונת ה-latent המקורית ללא שינוי. כאשר מסופקים מספר ערכי sigma, סקייל הרעש מחושב כהפרש המוחלט בין ערך ה-sigma הראשון והאחרון. כאשר מסופק ערך sigma יחיד, ערך זה משמש ישירות כסקייל. | SIGMAS | כן | - |
| `latent_image` | ייצוג ה-latent הקלט שאליו יתווסף רעש. תמונות latent ריקות (המכילות אפסים בלבד) אינן מוזזות במהלך העיבוד. | LATENT | כן | - |
