# Добавить шум

Этот узел добавляет управляемый шум к латентному изображению, используя заданный генератор шума и значения сигма. Он обрабатывает входные данные через систему сэмплирования модели, чтобы применить масштабирование шума, соответствующее заданному диапазону сигма, и возвращает новое латентное представление с применённым шумом. В настоящее время этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, содержащая параметры сэмплирования и функции обработки | MODEL | Да | - |
| `шум` | Генератор шума, который создаёт базовый шаблон шума | NOISE | Да | - |
| `сигмы` | Значения сигма, управляющие интенсивностью масштабирования шума. Если пусто, узел возвращает исходное латентное изображение без изменений. Если указано несколько сигм, масштаб шума вычисляется как абсолютная разность между первым и последним значениями сигмы. Если указана только одна сигма, это значение используется непосредственно как масштаб. | SIGMAS | Да | - |
| `латентное_изображение` | Входное латентное представление, к которому будет добавлен шум. Пустые латентные изображения (содержащие только нули) не сдвигаются в процессе обработки. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Модифицированное латентное представление с добавленным шумом. Любые значения NaN или бесконечные значения в выходных данных преобразуются в нули для стабильности. | LATENT |
