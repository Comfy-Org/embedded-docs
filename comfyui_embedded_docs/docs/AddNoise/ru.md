# Добавить шум

Этот узел добавляет управляемый шум к латентному изображению, используя указанный генератор шума и значения сигма. Он обрабатывает входные данные через систему сэмплирования модели для применения масштабирования шума, соответствующего заданному диапазону сигма, и возвращает новое латентное представление с применённым шумом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, содержащая параметры сэмплирования и функции обработки | MODEL | Да | - |
| `noise` | Генератор шума, который создаёт базовый шумовой шаблон | NOISE | Да | - |
| `sigmas` | Значения сигма, управляющие интенсивностью масштабирования шума. Если пусто, узел возвращает исходное латентное изображение без изменений. Если указано несколько значений сигма, масштаб шума вычисляется как абсолютная разница между первым и последним значениями сигма. Если указано только одно значение сигма, оно используется непосредственно как масштаб. | SIGMAS | Да | - |
| `latent_image` | Входное латентное представление, к которому будет добавлен шум. Пустые латентные изображения (содержащие только нули) не смещаются в процессе обработки. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Модифицированное латентное представление с добавленным шумом. Любые значения NaN или бесконечные значения в выходных данных преобразуются в нули для обеспечения стабильности. | LATENT |
