# ノイズを追加

このノードは、指定されたノイズジェネレーターとシグマ値を使用して、潜在イメージに制御されたノイズを追加します。モデルのサンプリングシステムを介して入力を処理し、指定されたシグマ範囲に適したノイズスケーリングを適用して、ノイズが適用された新しい潜在表現を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | サンプリングパラメータと処理関数を含むモデル | MODEL | はい | - |
| `noise` | 基本ノイズパターンを生成するノイズジェネレーター | NOISE | はい | - |
| `sigmas` | ノイズスケーリングの強度を制御するシグマ値。空の場合、ノードは元の潜在イメージを変更せずに返します。複数のシグマが指定された場合、ノイズスケールは最初と最後のシグマ値の絶対差として計算されます。シグマが1つだけ指定された場合は、その値がそのままスケールとして使用されます。 | SIGMAS | はい | - |
| `latent_image` | ノイズが追加される入力潜在表現。空の潜在イメージ（ゼロのみを含む）は処理中にシフトされません。 | LATENT | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `LATENT` | ノイズが追加された変更済み潜在表現。出力内のNaNまたは無限大の値は、安定性のためにゼロに変換されます。 | LATENT |
