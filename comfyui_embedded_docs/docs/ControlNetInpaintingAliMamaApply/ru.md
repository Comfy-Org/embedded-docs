# Применить ControlNet для инпейнтинга AliMama

Узел ControlNetInpaintingAliMamaApply применяет кондиционирование ControlNet для задач инпейнтинга, объединяя положительное и отрицательное кондиционирование с управляющим изображением и маской. Он обрабатывает входное изображение и маску для создания модифицированного кондиционирования, которое направляет процесс генерации, позволяя точно контролировать, какие области изображения будут подвергнуты инпейнтингу. Узел поддерживает регулировку силы и управление временем для точной настройки влияния ControlNet на разных этапах процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительное кондиционирование, которое направляет генерацию к желаемому содержимому | CONDITIONING | Да | - |
| `отрицательный` | Отрицательное кондиционирование, которое направляет генерацию от нежелательного содержимого | CONDITIONING | Да | - |
| `control_net` | Модель ControlNet, которая обеспечивает дополнительный контроль над генерацией | CONTROL_NET | Да | - |
| `vae` | VAE (вариационный автокодировщик), используемый для кодирования и декодирования изображений | VAE | Да | - |
| `изображение` | Входное изображение, которое служит управляющим ориентиром для ControlNet | IMAGE | Да | - |
| `маска` | Маска, которая определяет, какие области изображения должны быть подвергнуты инпейнтингу | MASK | Да | - |
| `сила` | Сила эффекта ControlNet (по умолчанию: 1.0, шаг: 0.01) | FLOAT | Да | 0.0 до 10.0 |
| `процент_начала` | Дополнительный параметр. Начальная точка (в процентах), с которой влияние ControlNet начинается во время генерации (по умолчанию: 0.0, шаг: 0.001) | FLOAT | Да | 0.0 до 1.0 |
| `процент_конца` | Дополнительный параметр. Конечная точка (в процентах), на которой влияние ControlNet прекращается во время генерации (по умолчанию: 1.0, шаг: 0.001) | FLOAT | Да | 0.0 до 1.0 |

**Примечание:** Если в ControlNet включен параметр `concat_mask`, маска инвертируется и применяется к изображению перед обработкой, а инвертированная маска включается в дополнительные данные конкатенации, отправляемые в ControlNet.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированное положительное кондиционирование с примененным ControlNet для инпейнтинга | CONDITIONING |
| `отрицательный` | Модифицированное отрицательное кондиционирование с примененным ControlNet для инпейнтинга | CONDITIONING |
