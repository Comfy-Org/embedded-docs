# Применить ControlNet для инпейнтинга AliMama

Этот узел применяет conditioning от ControlNet для задач инпейнтинга, объединяя положительное и отрицательное conditioning с контрольным изображением и маской. Он обрабатывает изображение и маску для создания модифицированного conditioning, которое направляет процесс генерации, обеспечивая точный контроль над областями, подвергаемыми инпейнтингу. Узел также поддерживает управление силой и временными параметрами для регулировки влияния ControlNet во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное conditioning, которое направляет генерацию к желаемому содержимому. | CONDITIONING | Да | - |
| `negative` | Отрицательное conditioning, которое направляет генерацию от нежелательного содержимого. | CONDITIONING | Да | - |
| `control_net` | Модель ControlNet, обеспечивающая дополнительный контроль над генерацией. | CONTROL_NET | Да | - |
| `vae` | VAE, используемый для кодирования и декодирования изображений. | VAE | Да | - |
| `image` | Входное изображение, используемое в качестве контрольного руководства для ControlNet. | IMAGE | Да | - |
| `mask` | Маска, определяющая области изображения, которые должны быть инпейнчены. | MASK | Да | - |
| `strength` | Сила эффекта ControlNet (по умолчанию: 1.0). | FLOAT | Да | 0.0 to 10.0 |
| `start_percent` | Дополнительная опция. Доля процесса генерации, на которой начинается влияние ControlNet (по умолчанию: 0.0). | FLOAT | Да | 0.0 to 1.0 |
| `end_percent` | Дополнительная опция. Доля процесса генерации, на которой заканчивается влияние ControlNet (по умолчанию: 1.0). | FLOAT | Да | 0.0 to 1.0 |

**Примечание:** Если выбранный ControlNet имеет включенный `concat_mask`, значения маски инвертируются (1 - маска), измененная версия инвертированной маски применяется к изображению, и инвертированная маска включается в дополнительные данные конкатенации, передаваемые в ControlNet. Если `concat_mask` отключен, входной параметр `mask` не используется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное conditioning с примененным ControlNet для инпейнтинга. | CONDITIONING |
| `negative` | Модифицированное отрицательное conditioning с примененным ControlNet для инпейнтинга. | CONDITIONING |
