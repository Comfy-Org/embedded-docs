# Применить ControlNet для инпейнтинга AliMama

Узел ControlNetInpaintingAliMamaApply применяет кондиционирование ControlNet для задач инпейнтинга, комбинируя позитивное и негативное кондиционирование с управляющим изображением и маской. Он обрабатывает входное изображение и маску, чтобы создать изменённое кондиционирование, направляющее процесс генерации, позволяя контролировать, какие области изображения будут заполнены. Узел поддерживает регулировку силы и управление временными параметрами для тонкой настройки влияния ControlNet на разных этапах процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивное кондиционирование, которое направляет генерацию к желаемому содержимому | CONDITIONING | Да | - |
| `отрицательный` | Негативное кондиционирование, которое направляет генерацию в сторону от нежелательного содержимого | CONDITIONING | Да | - |
| `control_net` | Модель ControlNet, обеспечивающая дополнительный контроль над генерацией | CONTROL_NET | Да | - |
| `vae` | VAE (вариационный автоэнкодер), используемый для кодирования и декодирования изображений | VAE | Да | - |
| `изображение` | Входное изображение, служащее управляющим ориентиром для ControlNet | IMAGE | Да | - |
| `маска` | Маска, определяющая, какие области изображения должны быть подвергнуты инпейнтингу | MASK | Да | - |
| `сила` | Сила эффекта ControlNet (по умолчанию: 1.0, шаг: 0.01) | FLOAT | Да | 0.0 до 10.0 |
| `процент_начала` | Расширенный параметр. Начальная точка (в процентах), в которой влияние ControlNet начинается во время генерации (по умолчанию: 0.0, шаг: 0.001) | FLOAT | Да | 0.0 до 1.0 |
| `процент_конца` | Расширенный параметр. Конечная точка (в процентах), в которой влияние ControlNet прекращается во время генерации (по умолчанию: 1.0, шаг: 0.001) | FLOAT | Да | 0.0 до 1.0 |

**Примечание:** Когда в ControlNet включён `concat_mask`, маска инвертируется и применяется к изображению перед обработкой, а инвертированная маска включается в дополнительные данные конкатенации, отправляемые в ControlNet.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённое позитивное кондиционирование с применённым ControlNet для инпейнтинга | CONDITIONING |
| `negative` | Изменённое негативное кондиционирование с применённым ControlNet для инпейнтинга | CONDITIONING |
