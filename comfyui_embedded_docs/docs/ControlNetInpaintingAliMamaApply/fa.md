# ControlNetInpaintingAliMamaApply

این گره با ترکیب شرطی‌سازی مثبت و منفی با یک تصویر کنترلی و یک ماسک، شرطی‌سازی ControlNet را برای کارهای بازسازی (inpainting) اعمال می‌کند. این گره تصویر و ماسک را پردازش می‌کند تا شرطی‌سازی اصلاح‌شده‌ای ایجاد کند که فرآیند تولید را هدایت می‌کند و کنترل دقیقی بر روی نواحی که باید بازسازی شوند فراهم می‌آورد. همچنین این گره از کنترل‌های قدرت (strength) و زمان‌بندی برای تنظیم تأثیر ControlNet در طول تولید پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبت که تولید را به سمت محتوای مطلوب هدایت می‌کند. | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی که تولید را از محتوای ناخواسته دور می‌کند. | CONDITIONING | بله | - |
| `control_net` | مدل ControlNet که کنترل اضافی بر روی تولید فراهم می‌کند. | CONTROL_NET | بله | - |
| `vae` | VAE که برای رمزگذاری و رمزگشایی تصاویر استفاده می‌شود. | VAE | بله | - |
| `image` | تصویر ورودی که به عنوان راهنمای کنترلی برای ControlNet استفاده می‌شود. | IMAGE | بله | - |
| `mask` | ماسکی که مشخص می‌کند کدام نواحی از تصویر باید بازسازی شوند. | MASK | بله | - |
| `strength` | قدرت اثر ControlNet (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 to 10.0 |
| `start_percent` | گزینه پیشرفته. بخشی از فرآیند تولید که تأثیر ControlNet در آن آغاز می‌شود (پیش‌فرض: 0.0). | FLOAT | بله | 0.0 to 1.0 |
| `end_percent` | گزینه پیشرفته. بخشی از فرآیند تولید که تأثیر ControlNet در آن پایان می‌یابد (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 to 1.0 |

**نکته:** وقتی ControlNet انتخاب‌شده دارای `concat_mask` فعال باشد، مقادیر ماسک معکوس می‌شوند (1 - mask)، نسخه تغییر اندازه‌یافته ماسک معکوس روی تصویر اعمال می‌شود و ماسک معکوس در داده‌های الحاقی اضافی که به ControlNet ارسال می‌شود گنجانده می‌شود. اگر `concat_mask` غیرفعال باشد، ورودی `mask` استفاده نمی‌شود.
