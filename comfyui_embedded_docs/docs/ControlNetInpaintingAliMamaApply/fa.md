# ControlNetInpaintingAliMamaApply

گره «ControlNetInpaintingAliMamaApply» با ترکیب conditioning مثبت و منفی با تصویر کنترل و ماسک، کنترل ControlNet را برای کارهای inpainting اعمال می‌کند. این گره تصویر ورودی و ماسک را پردازش می‌کند تا conditioning اصلاح‌شده‌ای ایجاد کند که فرایند تولید را هدایت می‌کند و امکان کنترل دقیق بر نواحی‌ای از تصویر که باید inpaint شوند را فراهم می‌سازد. گره از تنظیم قدرت (strength) و کنترل‌های زمان‌بندی برای تنظیم دقیق تأثیر ControlNet در مراحل مختلف فرایند تولید پشتیبانی می‌کند.
