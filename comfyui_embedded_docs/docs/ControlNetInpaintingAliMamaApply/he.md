# ControlNetInpaintingAliMamaApply

צומת ControlNetInpaintingAliMamaApply מחיל התניה של ControlNet למשימות אינפיינטינג על ידי שילוב התניה חיובית ושלילית עם תמונת בקרה ומסכה. הוא מעבד את תמונת הקלט והמסכה כדי ליצור התניה מותאמת שמכוונת את תהליך היצירה, ומאפשר שליטה על אילו אזורים בתמונה יעברו אינפיינטינג. הצומת תומך בהתאמת עוצמה ובקרות תזמון כדי לכוונן את השפעת ControlNet בשלבים שונים של תהליך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | ההתניה החיובית שמכוונת את היצירה לתוכן הרצוי | CONDITIONING | כן | - |
| `negative` | ההתניה השלילית שמכוונת את היצירה הרחק מתוכן לא רצוי | CONDITIONING | כן | - |
| `control_net` | מודל ה-ControlNet שמספק שליטה נוספת על היצירה | CONTROL_NET | כן | - |
| `vae` | ה-VAE (מקודד אוטומטי וריאציוני) המשמש לקידוד ופענוח תמונות | VAE | כן | - |
| `image` | תמונת הקלט המשמשת כהנחיית בקרה עבור ה-ControlNet | IMAGE | כן | - |
| `mask` | המסכה שמגדירה אילו אזורים בתמונה צריכים לעבור אינפיינטינג | MASK | כן | - |
| `strength` | עוצמת השפעת ה-ControlNet (ברירת מחדל: 1.0, צעד: 0.01) | FLOAT | כן | 0.0 to 10.0 |
| `start_percent` | פרמטר מתקדם. נקודת ההתחלה (באחוזים) שבה השפעת ControlNet מתחילה במהלך היצירה (ברירת מחדל: 0.0, צעד: 0.001) | FLOAT | כן | 0.0 to 1.0 |
| `end_percent` | פרמטר מתקדם. נקודת הסיום (באחוזים) שבה השפעת ControlNet מפסיקה במהלך היצירה (ברירת מחדל: 1.0, צעד: 0.001) | FLOAT | כן | 0.0 to 1.0 |

**הערה:** כאשר `concat_mask` מופעל ב-ControlNet, המסכה מתהפכת ומוחלת על התמונה לפני העיבוד, והמסכה ההופכית נכללת בנתוני השרשור הנוספים הנשלחים ל-ControlNet.
