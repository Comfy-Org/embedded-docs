# تطبيق ControlNet للترميم - علي ماما

```markdown
تطبّق عقدة ControlNetInpaintingAliMamaApply تكييف ControlNet لمهام الترميم (inpainting) من خلال دمج التكييف الإيجابي والسلبي مع صورة التحكم والقناع. تعالج صورة الإدخال والقناع لإنشاء تكييف معدّل يوجّه عملية التوليد، مما يتيح تحكمًا دقيقًا في مناطق الصورة التي سيتم ترميمها. تدعم العقدة ضبط القوة (strength) وتحكمات التوقيت لضبط تأثير ControlNet بدقة خلال مراحل مختلفة من عملية التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التكييف الإيجابي الذي يوجّه التوليد نحو المحتوى المطلوب | CONDITIONING | نعم | - |
| `سلبي` | التكييف السلبي الذي يوجّه التوليد بعيدًا عن المحتوى غير المرغوب فيه | CONDITIONING | نعم | - |
| `شبكة التحكم` | نموذج ControlNet الذي يوفر تحكمًا إضافيًا في التوليد | CONTROL_NET | نعم | - |
| `VAE` | VAE (التشفير التلقائي المتغير) المستخدم لتشفير وفك تشفير الصور | VAE | نعم | - |
| `صورة` | صورة الإدخال التي تعمل كإرشاد تحكم لـ ControlNet | IMAGE | نعم | - |
| `قناع` | القناع الذي يحدد مناطق الصورة التي يجب ترميمها | MASK | نعم | - |
| `القوة` | قوة تأثير ControlNet (الافتراضي: 1.0، الخطوة: 0.01) | FLOAT | نعم | 0.0 إلى 10.0 |
| `نسبة البداية` | معامل متقدم. نقطة البداية (كنسبة مئوية) لبدء تأثير ControlNet أثناء التوليد (الافتراضي: 0.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |
| `نسبة النهاية` | معامل متقدم. نقطة النهاية (كنسبة مئوية) لتوقف تأثير ControlNet أثناء التوليد (الافتراضي: 1.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |

**ملاحظة:** عندما يكون `concat_mask` مفعّلاً في ControlNet، يتم عكس القناع وتطبيقه على الصورة قبل المعالجة، ويتم تضمين القناع المعكوس في بيانات الدمج الإضافية المرسلة إلى ControlNet.
```
