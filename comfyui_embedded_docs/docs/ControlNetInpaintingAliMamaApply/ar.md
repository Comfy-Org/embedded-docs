# تطبيق ControlNet للترميم - علي ماما

عُقدة ControlNetInpaintingAliMamaApply تطبّق تكييف ControlNet لمهام إعادة الرسم الداخلي (inpainting) عبر دمج التكييف الإيجابي والسلبي مع صورة تحكم وقناع. تعالج الصورة المدخلة والقناع لإنشاء تكييف معدّل يوجّه عملية التوليد، ما يتيح التحكم في المناطق التي ستُعاد رسمها داخل الصورة. تدعم العقدة ضبط القوة وعناصر التحكم الزمنية لضبط تأثير ControlNet بدقة خلال مراحل مختلفة من عملية التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التكييف الإيجابي الذي يوجّه التوليد نحو المحتوى المطلوب | CONDITIONING | نعم | - |
| `سلبي` | التكييف السلبي الذي يوجّه التوليد بعيدًا عن المحتوى غير المرغوب فيه | CONDITIONING | نعم | - |
| `شبكة التحكم` | نموذج ControlNet الذي يوفّر تحكمًا إضافيًا في عملية التوليد | CONTROL_NET | نعم | - |
| `VAE` | الـ VAE (المُشفّر التلقائي التبايني) المستخدم لتشفير الصور وفك تشفيرها | VAE | نعم | - |
| `صورة` | الصورة المدخلة التي تعمل كدليل تحكم لـ ControlNet | IMAGE | نعم | - |
| `قناع` | القناع الذي يحدد مناطق الصورة التي ينبغي إعادة رسمها داخليًا | MASK | نعم | - |
| `القوة` | قوة تأثير ControlNet (الافتراضي: 1.0، الخطوة: 0.01) | FLOAT | نعم | 0.0 إلى 10.0 |
| `نسبة البداية` | معامل متقدم. نقطة البداية (كنسبة مئوية) لبدء تأثير ControlNet أثناء التوليد (الافتراضي: 0.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |
| `نسبة النهاية` | معامل متقدم. نقطة النهاية (كنسبة مئوية) لتوقف تأثير ControlNet أثناء التوليد (الافتراضي: 1.0، الخطوة: 0.001) | FLOAT | نعم | 0.0 إلى 1.0 |

**ملاحظة:** عند تفعيل `concat_mask` في ControlNet، يتم عكس القناع وتطبيقه على الصورة قبل المعالجة، ويُضمَّن القناع المعكوس في بيانات الدمج الإضافية المُرسَلة إلى ControlNet.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي المعدّل بعد تطبيق ControlNet لإعادة الرسم الداخلي | CONDITIONING |
| `negative` | التكييف السلبي المعدّل بعد تطبيق ControlNet لإعادة الرسم الداخلي | CONDITIONING |
