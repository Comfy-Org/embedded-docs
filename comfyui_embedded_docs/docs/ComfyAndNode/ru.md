# И

Узел And выполняет логическую операцию AND над набором входных значений. Он возвращает `true`, только если все предоставленные значения считаются истинными согласно правилам истинности Python. Этот узел полезен для проверки того, что все несколько условий выполнены перед продолжением.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `values` | Расширяемый список значений для оценки. Узел требует хотя бы одно значение; вы можете добавить дополнительные слоты, нажав кнопку «+» на узле. Каждый слот принимает любой тип данных. | ANY | Да | 1 или более значений |

**Примечание:** Узел использует правила истинности Python для определения, является ли значение `true` или `false`. Например, пустая строка, число 0, пустой список и `None` считаются `false`. Все остальные значения считаются `true`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `BOOLEAN` | Возвращает `true`, если все входные значения истинны, в противном случае возвращает `false`. | BOOLEAN |
