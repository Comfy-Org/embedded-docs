# И

Узел And выполняет логическую операцию AND над группой входных значений. Он возвращает `true` только тогда, когда каждое подключённое значение считается истинным согласно правилам истинности Python, что делает его полезным для проверки одновременного выполнения нескольких условий.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значения` | Расширяемая группа значений для вычисления. Узел начинается с одного слота, и вы можете добавить новые, нажав кнопку «+» на узле. Принимает любой тип данных. | ANY | Да | Минимум 1 (без максимума) |

**Примечание:** Этот вход представляет собой расширяемую группу слотов. Слоты добавляются по отдельности (например, `value_1`, `value_2` и так далее), и должен присутствовать хотя бы один слот.

**Примечание:** Узел использует правила истинности Python, чтобы определить, является ли значение `true` или `false`. Например, пустая строка, число 0, пустой список и None считаются `false`. Все остальные значения считаются `true`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `BOOLEAN` | Возвращает `true`, если все входные значения истинны, иначе возвращает `false`. | BOOLEAN |
