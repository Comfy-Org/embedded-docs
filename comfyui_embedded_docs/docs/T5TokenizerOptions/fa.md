# گزینه‌های T5Tokenizer

گره T5TokenizerOptions به شما امکان می‌دهد تنظیمات توکنایزر را برای انواع مختلف مدل T5 پیکربندی کنید. این گره پارامترهای حداقل padding و حداقل طول را برای چندین نوع مدل T5 شامل t5xxl، pile_t5xl، t5base، mt5xl و umt5xxl تنظیم می‌کند. گره یک ورودی CLIP دریافت می‌کند و یک CLIP تغییر یافته با گزینه‌های توکنایزر اعمال‌شده بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP برای پیکربندی گزینه‌های توکنایزر | CLIP | بله | - |
| `min_padding` | حداقل مقدار padding برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | خیر | 0 تا 10000 |
| `min_length` | حداقل مقدار طول برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | خیر | 0 تا 10000 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مدل CLIP تغییر یافته با گزینه‌های توکنایزر به‌روزرسانی‌شده اعمال‌شده روی همه انواع T5 | CLIP |
