# گزینه‌های T5Tokenizer

گره T5TokenizerOptions تنظیمات توکنایزر را برای انواع مختلف مدل T5 پیکربندی می‌کند. این گره پارامترهای حداقل padding و حداقل طول را برای چندین نوع مدل T5 از جمله t5xxl، pile_t5xl، t5base، mt5xl و umt5xxl تنظیم می‌کند. گره یک ورودی CLIP دریافت می‌کند، تنظیمات را روی یک کپی از آن اعمال می‌کند و CLIP اصلاح‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که باید تنظیمات توکنایزر برای آن پیکربندی شود | CLIP | بله | - |
| `حداقل padding` | حداقل مقدار padding برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | بله | 0 تا 10000 |
| `حداقل طول` | حداقل مقدار طول برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | بله | 0 تا 10000 |

توجه: این گره در ComfyUI به عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مدل CLIP اصلاح‌شده با گزینه‌های توکنایزر به‌روزرسانی‌شده که روی همه انواع T5 اعمال شده است | CLIP |
