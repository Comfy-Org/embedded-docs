# گزینه‌های T5Tokenizer

## بررسی کلی

گره T5TokenizerOptions تنظیمات توکنایزر را برای انواع مختلف مدل T5 پیکربندی می‌کند. این گره پارامترهای حداقل پدینگ و حداقل طول را برای چندین گونه مدل T5 شامل t5xxl، pile_t5xl، t5base، mt5xl و umt5xxl تنظیم می‌کند. این گره یک ورودی CLIP می‌گیرد، تنظیمات را روی یک کپی از آن اعمال می‌کند و CLIP اصلاح‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP برای پیکربندی گزینه‌های توکنایزر | CLIP | بله | - |
| `min_padding` | حداقل مقدار پدینگ برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | بله | 0 تا 10000 |
| `min_length` | حداقل مقدار طول برای تنظیم روی همه انواع مدل T5 (پیش‌فرض: 0) | INT | بله | 0 تا 10000 |

توجه: این گره در ComfyUI به‌عنوان آزمایشی علامت‌گذاری شده است. تنظیمات به‌طور هم‌زمان روی همه انواع پشتیبانی‌شده T5 اعمال می‌شوند: t5xxl، pile_t5xl، t5base، mt5xl و umt5xxl. ورودی `clip` پیش از تغییر کلون می‌شود، بنابراین CLIP اصلی تغییر نمی‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مدل CLIP اصلاح‌شده با گزینه‌های توکنایزر به‌روزشده که روی همه انواع T5 اعمال شده است | CLIP |
