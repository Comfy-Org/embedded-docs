# T5TokenizerOptions

## Обзор

Узел T5TokenizerOptions настраивает параметры токенизатора для различных типов моделей T5. Он устанавливает параметры `min_padding` и `min_length` для нескольких вариантов модели T5, включая t5xxl, pile_t5xl, t5base, mt5xl и umt5xxl. Узел принимает на вход CLIP, применяет настройки к его копии и возвращает изменённый CLIP.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, для которой настраиваются параметры токенизатора | CLIP | Да | - |
| `минимальное_дополнение` | Минимальное значение паддинга, устанавливаемое для всех типов моделей T5 (по умолчанию: 0) | INT | Да | от 0 до 10000 |
| `минимальная_длина` | Минимальное значение длины, устанавливаемое для всех типов моделей T5 (по умолчанию: 0) | INT | Да | от 0 до 10000 |

Примечание: В ComfyUI этот узел помечен как экспериментальный. Настройки применяются сразу ко всем поддерживаемым вариантам T5: t5xxl, pile_t5xl, t5base, mt5xl и umt5xxl. Вход `clip` клонируется перед изменением, поэтому исходный CLIP не изменяется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изменённая модель CLIP с обновлёнными параметрами токенизатора, применёнными ко всем вариантам T5 | CLIP |
