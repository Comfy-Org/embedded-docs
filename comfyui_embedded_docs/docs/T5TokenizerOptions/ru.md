# T5TokenizerOptions

Узел T5TokenizerOptions позволяет настраивать параметры токенизатора для различных типов моделей T5. Он задает параметры минимального значения padding и минимальной длины для нескольких вариантов моделей T5, включая t5xxl, pile_t5xl, t5base, mt5xl и umt5xxl. Узел принимает входной CLIP и возвращает измененный CLIP с примененными указанными параметрами токенизатора.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, для которой настраиваются параметры токенизатора | CLIP | Да | - |
| `min_padding` | Минимальное значение padding, устанавливаемое для всех типов моделей T5 (по умолчанию: 0) | INT | Нет | 0 to 10000 |
| `min_length` | Минимальное значение длины, устанавливаемое для всех типов моделей T5 (по умолчанию: 0) | INT | Нет | 0 to 10000 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Модифицированная модель CLIP с примененными обновленными параметрами токенизатора для всех вариантов T5 | CLIP |
