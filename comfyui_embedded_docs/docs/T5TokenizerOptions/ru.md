# T5TokenizerOptions

Узел T5TokenizerOptions настраивает параметры токенизатора для различных типов моделей T5. Он задаёт минимальное значение padding и минимальную длину для нескольких вариантов моделей T5, включая t5xxl, pile_t5xl, t5base, mt5xl и umt5xxl. Узел принимает входной CLIP, применяет настройки к его копии и возвращает изменённый CLIP.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, для которой необходимо настроить параметры токенизатора | CLIP | Да | - |
| `минимальное_дополнение` | Минимальное значение padding, задаваемое для всех типов моделей T5 (по умолчанию: 0) | INT | Да | 0 до 10000 |
| `минимальная_длина` | Минимальная длина, задаваемая для всех типов моделей T5 (по умолчанию: 0) | INT | Да | 0 до 10000 |

Примечание: В ComfyUI этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изменённая модель CLIP с обновлёнными параметрами токенизатора, применёнными ко всем вариантам T5 | CLIP |
