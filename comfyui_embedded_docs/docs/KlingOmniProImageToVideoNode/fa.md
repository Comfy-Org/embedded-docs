# Kling Omni تبدیل تصویر به ویدیو (Pro)

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل مشخص Kling برای استفاده در تولید ویدئو (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک متن راهنما که محتوای ویدئو را توصیف می‌کند. این متن می‌تواند شامل توصیفات مثبت و منفی باشد. مکان‌نماهایی مانند `@image` یا `@video` (اختیاری با شماره) به‌طور خودکار به فرمت سازگار با API تبدیل می‌شوند. باید بین 1 تا 2500 کاراکتر باشد (در صورت فعال بودن استوری‌بوردها می‌تواند خالی باشد). هنگامی که استوری‌بوردها فعال هستند نادیده گرفته می‌شود. | STRING | بله | - |
| `aspect_ratio` | نسبت ابعاد مورد نظر برای ویدئوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدت‌زمان ویدئو بر حسب ثانیه، با یک لغزنده تنظیم می‌شود (پیش‌فرض: 5). | INT | بله | 3 تا 15 |
| `reference_images` | حداکثر 7 تصویر مرجع. هر تصویر باید حداقل 300×300 پیکسل باشد و نسبت ابعادی بین 1:2.5 و 2.5:1 داشته باشد. | IMAGE | بله | 1 تا 7 تصویر |
| `resolution` | وضوح خروجی ویدئو (پیش‌فرض: `"1080p"`). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | یک سری بخش‌های ویدئویی با متن‌های راهنما و مدت‌زمان‌های جداگانه تولید می‌کند. فقط برای `kling-v3-omni` پشتیبانی می‌شود. وقتی فعال باشد، `prompt` سراسری نادیده گرفته می‌شود و مجموع مدت‌زمان همه بخش‌های استوری‌بورد باید برابر با `duration` سراسری باشد (پیش‌فرض: `"disabled"`). | COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | صدا برای ویدئو تولید می‌کند. فقط برای `kling-v3-omni` پشتیبانی می‌شود (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های استوری‌بورد

هنگامی که `storyboards` فعال باشد، ورودی‌های زیر برای هر بخش استوری‌بورد انتخاب‌شده ظاهر می‌شوند. N از 1 تا تعداد انتخاب‌شده استوری‌بوردها متغیر است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | متن راهنما برای بخش N استوری‌بورد. حداکثر 512 کاراکتر. | STRING | خیر | 1 تا 512 کاراکتر |
| `storyboard_N_duration` | مدت‌زمان برای بخش N استوری‌بورد بر حسب ثانیه (پیش‌فرض: 4). | INT | خیر | 1 تا 15 |

**نکته:** ورودی `reference_images` حداکثر 7 تصویر را می‌پذیرد. اگر تعداد بیشتری ارائه شود، گره یک خطا ایجاد می‌کند. هر تصویر از نظر حداقل ابعاد و نسبت ابعادی بررسی می‌شود.

**محدودیت‌های خاص مدل:**
- `kling-video-o1` از مدت‌زمان‌های بیشتر از 10 ثانیه پشتیبانی نمی‌کند.
- `kling-video-o1` از تولید صدا پشتیبانی نمی‌کند.
- `kling-video-o1` از وضوح 4k پشتیبانی نمی‌کند.
- `kling-video-o1` از استوری‌بوردها پشتیبانی نمی‌کند.
