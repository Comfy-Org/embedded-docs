# Kling Omni تبدیل تصویر به ویدیو (Pro)

این گره از مدل Kling AI برای تولید ویدیو بر اساس یک متن راهنما و حداکثر هفت تصویر مرجع استفاده می‌کند. به شما امکان می‌دهد نسبت تصویر، مدت‌زمان و کیفیت ویدیو را کنترل کنید و در صورت تمایل از استوری‌بورد استفاده کنید یا صدا تولید کنید. گره درخواست را به یک API خارجی ارسال کرده و ویدیوی تولیدشده را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل خاص Kling که برای تولید ویدیو استفاده می‌شود (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | متن راهنمای توصیف‌کننده محتوای ویدیو. این می‌تواند شامل توصیفات مثبت و منفی باشد. زمانی که استوری‌بورد فعال باشد نادیده گرفته می‌شود. مکان‌نماهایی مانند `@image` یا `@video` (در صورت نیاز با شماره) به‌صورت خودکار به قالب سازگار با API تبدیل می‌شوند. باید بین ۱ تا ۲۵۰۰ کاراکتر باشد (زمانی که استوری‌بورد فعال است می‌تواند خالی باشد). | STRING | بله | ۱ تا ۲۵۰۰ کاراکتر |
| `aspect_ratio` | نسبت تصویر موردنظر برای ویدیوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدت‌زمان ویدیو بر حسب ثانیه که با اسلایدر تنظیم می‌شود (پیش‌فرض: ۵). | INT | بله | ۳ تا ۱۵ |
| `reference_images` | حداکثر ۷ تصویر مرجع. هر تصویر باید حداقل ۳۰۰×۳۰۰ پیکسل باشد و نسبت تصویری بین ۱:۲.۵ و ۲.۵:۱ داشته باشد. | IMAGE | بله | ۱ تا ۷ تصویر |
| `resolution` | کیفیت خروجی ویدیو (پیش‌فرض: `"1080p"`). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید یک سری بخش ویدیویی با راهنما و مدت‌زمان جداگانه. فقط برای `kling-v3-omni` پشتیبانی می‌شود. وقتی فعال باشد، `prompt` سراسری نادیده گرفته می‌شود و مجموع مدت‌زمان همه بخش‌های استوری‌بورد باید با `duration` سراسری برابر باشد (پیش‌فرض: `"disabled"`). | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | تولید صدا برای ویدیو. فقط برای `kling-v3-omni` پشتیبانی می‌شود (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | سیّد تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از سیّد غیرقطعی هستند (پیش‌فرض: ۰). | INT | خیر | ۰ تا ۲۱۴۷۴۸۳۶۴۷ |

### ورودی‌های استوری‌بورد

وقتی `storyboards` فعال باشد، ورودی‌های زیر برای هر بخش استوری‌بورد انتخابی ظاهر می‌شوند. N از ۱ تا تعداد استوری‌بورد انتخابی متغیر است.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | راهنمای بخش استوری‌بورد N. حداکثر ۵۱۲ کاراکتر. | STRING | بله | ۱ تا ۵۱۲ کاراکتر |
| `storyboard_N_duration` | مدت‌زمان بخش استوری‌بورد N بر حسب ثانیه (پیش‌فرض: ۴). | INT | بله | ۱ تا ۱۵ |

**توجه:** ورودی `reference_images` حداکثر ۷ تصویر را می‌پذیرد. اگر تعداد بیشتری ارائه شود، گره خطا می‌دهد. هر تصویر از نظر حداقل ابعاد و نسبت تصویر بررسی می‌شود.

**محدودیت‌های خاص مدل:**
- `kling-video-o1` از مدت‌زمان بیشتر از ۱۰ ثانیه پشتیبانی نمی‌کند.
- `kling-video-o1` از تولید صدا پشتیبانی نمی‌کند.
- `kling-video-o1` از کیفیت 4k پشتیبانی نمی‌کند.
- `kling-video-o1` از استوری‌بورد پشتیبانی نمی‌کند.
