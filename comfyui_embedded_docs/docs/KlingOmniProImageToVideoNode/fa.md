# Kling Omni تبدیل تصویر به ویدیو (Pro)

این گره از مدل Kling AI برای تولید ویدیو بر اساس یک پرامپت متنی و حداکثر هفت تصویر مرجع استفاده می‌کند. این امکان را به شما می‌دهد که نسبت ابعاد، مدت زمان و رزولوشن ویدیو را کنترل کنید و به‌صورت اختیاری از استوری‌بوردها استفاده کنید یا صدا تولید کنید. گره درخواست را به یک API خارجی ارسال می‌کند و ویدیوی تولیدشده را برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل مشخص Kling برای تولید ویدیو (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک پرامپت متنی که محتوای ویدیو را توصیف می‌کند. این می‌تواند شامل توصیف‌های مثبت و منفی باشد. وقتی استوری‌بوردها فعال باشند نادیده گرفته می‌شود. جای‌نگهدارهایی مانند `@image` یا `@video` (به‌صورت اختیاری شماره‌گذاری‌شده) به‌طور خودکار به قالب سازگار با API تبدیل می‌شوند. باید بین 1 و 2500 کاراکتر باشد (وقتی استوری‌بوردها فعال هستند می‌تواند خالی باشد). | STRING | بله | 1 تا 2500 کاراکتر (0 تا 2500 وقتی استوری‌بوردها فعال هستند) |
| `aspect_ratio` | نسبت ابعاد دلخواه برای ویدیوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | طول ویدیو بر حسب ثانیه که با یک لغزنده تنظیم می‌شود (پیش‌فرض: 5). | INT | بله | 3 تا 15 |
| `reference_images` | حداکثر 7 تصویر مرجع. هر تصویر باید حداقل 300x300 پیکسل باشد و نسبت ابعاد آن بین 1:2.5 و 2.5:1 باشد. | IMAGE | بله | 1 تا 7 تصویر |
| `resolution` | رزولوشن خروجی ویدیو (پیش‌فرض: `"1080p"`). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `storyboards` | تولید مجموعه‌ای از قطعات ویدیو با پرامپت‌ها و مدت‌زمان‌های جداگانه. فقط برای `kling-v3-omni` پشتیبانی می‌شود. وقتی فعال باشد، `prompt` سراسری نادیده گرفته می‌شود و مجموع مدت‌زمان همه قطعات استوری‌بورد باید برابر با `duration` سراسری باشد (پیش‌فرض: `"disabled"`). | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `generate_audio` | تولید صدا برای ویدیو. فقط برای `kling-v3-omni` پشتیبانی می‌شود (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | seed کنترل می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های استوری‌بورد

وقتی `storyboards` فعال باشد، ورودی‌های زیر برای هر قطعه استوری‌بورد انتخاب‌شده نمایش داده می‌شوند. N از 1 تا تعداد استوری‌بوردهای انتخاب‌شده متغیر است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | پرامپت برای قطعه استوری‌بورد N. حداکثر 512 کاراکتر. | STRING | بله | 1 تا 512 کاراکتر |
| `storyboard_N_duration` | مدت‌زمان برای قطعه استوری‌بورد N بر حسب ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 |

**توجه:** ورودی `reference_images` حداکثر 7 تصویر را می‌پذیرد. اگر بیشتر ارائه شود، گره خطا می‌دهد. هر تصویر از نظر حداقل ابعاد (300x300 پیکسل) و نسبت ابعاد (بین 1:2.5 و 2.5:1) اعتبارسنجی می‌شود.

**محدودیت‌های مخصوص مدل:**
- `kling-video-o1` از مدت‌زمان‌های بیشتر از 10 ثانیه پشتیبانی نمی‌کند.
- `kling-video-o1` از تولید صدا پشتیبانی نمی‌کند.
- `kling-video-o1` از رزولوشن 4k پشتیبانی نمی‌کند.
- `kling-video-o1` از استوری‌بوردها پشتیبانی نمی‌کند.

**محدودیت استوری‌بورد:** مجموع مدت‌زمان همه قطعات استوری‌بورد باید برابر با مقدار `duration` سراسری باشد. اگر مجموع مطابقت نداشته باشد، گره خطا می‌دهد.
