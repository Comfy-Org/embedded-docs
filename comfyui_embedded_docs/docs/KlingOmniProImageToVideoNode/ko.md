# Kling Omni 이미지에서 비디오로 (Pro)

이 노드는 Kling AI 모델을 사용하여 텍스트 프롬프트와 최대 7개의 참조 이미지를 기반으로 비디오를 생성합니다. 비디오의 종횡비, 길이, 해상도를 제어할 수 있으며 선택적으로 스토리보드를 사용하거나 오디오를 생성할 수 있습니다. 노드는 외부 API로 요청을 전송하고 생성된 비디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 비디오 생성에 사용할 특정 Kling 모델입니다 (기본값: "kling-v3-omni"). | COMBO | 예 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | 비디오 내용을 설명하는 텍스트 프롬프트입니다. 긍정적인 설명과 부정적인 설명을 모두 포함할 수 있습니다. `@image` 또는 `@video` 같은 자리 표시자(선택적으로 번호가 매겨짐)는 자동으로 API 호환 형식으로 변환됩니다. 1~2500자 사이여야 합니다 (스토리보드가 활성화된 경우 비어 있을 수 있습니다). 스토리보드가 활성화된 경우 무시됩니다. | STRING | 예 | - |
| `aspect_ratio` | 생성된 비디오의 원하는 종횡비입니다. | COMBO | 예 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | 슬라이더로 조정되는 비디오 길이(초)입니다 (기본값: 5). | INT | 예 | 3 ~ 15 |
| `reference_images` | 최대 7개의 참조 이미지입니다. 각 이미지는 최소 300x300 픽셀이어야 하며 종횡비가 1:2.5와 2.5:1 사이여야 합니다. | IMAGE | 예 | 1 ~ 7 images |
| `resolution` | 비디오의 출력 해상도입니다 (기본값: "1080p"). | COMBO | 아니요 | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `storyboards` | 개별 프롬프트와 길이를 가진 일련의 비디오 세그먼트를 생성합니다. `kling-v3-omni`에서만 지원됩니다. 활성화하면 전역 `prompt`는 무시되며 모든 스토리보드 세그먼트의 총 길이는 전역 `duration`과 같아야 합니다 (기본값: "disabled"). | COMBO | 아니요 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `generate_audio` | 비디오용 오디오를 생성합니다. `kling-v3-omni`에서만 지원됩니다 (기본값: false). | BOOLEAN | 아니요 | `true`<br>`false` |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다 (기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |

### 스토리보드 입력

`storyboards`가 활성화되면 선택된 각 스토리보드 세그먼트에 대해 다음 입력이 나타납니다. N은 1부터 선택된 스토리보드 수까지입니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 스토리보드 세그먼트 N의 프롬프트입니다. 최대 512자입니다. | STRING | 아니요 | 1 ~ 512 characters |
| `storyboard_N_duration` | 스토리보드 세그먼트 N의 길이(초)입니다 (기본값: 4). | INT | 아니요 | 1 ~ 15 |

**참고:** `reference_images` 입력은 최대 7개의 이미지를 허용합니다. 더 많이 제공되면 노드에서 오류가 발생합니다. 각 이미지는 최소 크기와 종횡비가 검증됩니다.

**모델별 제약 사항:**
- `kling-video-o1`은 10초보다 긴 길이를 지원하지 않습니다.
- `kling-video-o1`은 오디오 생성을 지원하지 않습니다.
- `kling-video-o1`은 4k 해상도를 지원하지 않습니다.
- `kling-video-o1`은 스토리보드를 지원하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일입니다. | VIDEO |
