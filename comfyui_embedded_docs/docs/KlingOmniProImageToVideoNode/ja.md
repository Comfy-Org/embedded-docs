# Kling Omni 画像からビデオへ (Pro)

このノードは、Kling AI モデルを使用して、テキストプロンプトと最大7枚の参照画像に基づいてビデオを生成します。ビデオのアスペクト比、長さ、解像度を制御でき、オプションでストーリーボードを使用したり、オーディオを生成したりできます。このノードはリクエストを外部 API に送信し、生成されたビデオを返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | ビデオ生成に使用する Kling モデルを指定します（デフォルト: `"kling-v3-omni"`）。 | COMBO | はい | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `プロンプト` | ビデオの内容を説明するテキストプロンプトです。肯定的な説明と否定的な説明の両方を含めることができます。`@image` や `@video`（必要に応じて番号付き）などのプレースホルダーは、API 互換の形式に自動的に変換されます。1〜2500 文字である必要があります（ストーリーボードが有効な場合は空にできます）。ストーリーボードが有効な場合は無視されます。 | STRING | はい | - |
| `アスペクト比` | 生成されるビデオの希望するアスペクト比です。 | COMBO | はい | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `継続時間` | ビデオの長さ（秒）です。スライダーで調整します（デフォルト: 5）。 | INT | はい | 3〜15 |
| `リファレンス画像` | 最大7枚の参照画像です。各画像は少なくとも300x300ピクセルで、アスペクト比が1:2.5〜2.5:1の範囲内である必要があります。 | IMAGE | はい | 1〜7枚 |
| `解像度` | ビデオの出力解像度です（デフォルト: `"1080p"`）。 | COMBO | いいえ | `"4k"`<br>`"1080p"`<br>`"720p"` |

| `シード` | seed はノードを再実行するかどうかを制御します。結果は seed に関係なく非決定的です（デフォルト: 0）。 | INT | いいえ | 0〜2147483647 |

### ストーリーボード入力

`storyboards` が有効な場合、選択した各ストーリーボードセグメントに対して以下の入力が表示されます。N は 1 から選択したストーリーボード数までの範囲です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメント N のプロンプトです。最大512文字です。 | STRING | いいえ | 1〜512文字 |
| `storyboard_N_duration` | ストーリーボードセグメント N の長さ（秒）です（デフォルト: 4）。 | INT | いいえ | 1〜15 |

**注記:** `reference_images` 入力は最大7枚の画像を受け付けます。それ以上指定すると、ノードはエラーを発生させます。各画像は最小寸法とアスペクト比が検証されます。

**モデル固有の制約:**
- `kling-video-o1` は10秒を超える長さには対応していません。
- `kling-video-o1` はオーディオ生成に対応していません。
- `kling-video-o1` は4k解像度に対応していません。
- `kling-video-o1` はストーリーボードに対応していません。
