# Kling Omni 圖像轉影片 (Pro)

此節點使用 Kling AI 模型，根據文字提示詞與最多七張參考圖片生成影片。它可讓您控制影片的長寬比、時長與解析度，並可選擇使用分鏡腳本或生成音訊。此節點會將請求傳送至外部 API，並傳回生成的影片。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 用於影片生成的特定 Kling 模型（預設：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br>`"kling-video-o1"` |

### 分鏡腳本輸入

當啟用 `storyboards` 時，每個選取的分鏡腳本片段會顯示以下輸入。N 的範圍從 1 到選取的分鏡腳本數量。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分鏡腳本片段 N 的提示詞。最多 512 個字元。 | STRING | 是 | 1 到 512 個字元 |
| `storyboard_N_duration` | 分鏡腳本片段 N 的時長（以秒為單位）（預設：4）。 | INT | 是 | 1 到 15 |

**注意：** `reference_images` 輸入最多接受 7 張圖片。若提供更多圖片，節點會引發錯誤。每張圖片都會驗證最小尺寸（300x300 像素）與長寬比（介於 1:2.5 與 2.5:1 之間）。

**模型特定限制：**
- `kling-video-o1` 不支援超過 10 秒的時長。
- `kling-video-o1` 不支援音訊生成。
- `kling-video-o1` 不支援 4k 解析度。
- `kling-video-o1` 不支援分鏡腳本。

**分鏡腳本限制：** 所有分鏡腳本片段的總時長必須等於全域 `duration` 值。若總和不相符，節點會引發錯誤。
