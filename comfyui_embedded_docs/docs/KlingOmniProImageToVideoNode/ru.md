# Kling Omni Изображение в Видео (Pro)

Этот узел использует модель Kling AI для генерации видео на основе текстового промпта и до семи референсных изображений. Он позволяет управлять соотношением сторон видео, его длительностью и разрешением, а также опционально использовать раскадровку или генерировать аудио. Узел отправляет запрос к внешнему API и возвращает сгенерированное видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling для генерации видео (по умолчанию: `"kling-v3-omni"`). | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовый промпт, описывающий содержимое видео. Может включать как положительные, так и отрицательные описания. Игнорируется, когда включена раскадровка. Заполнители, такие как `@image` или `@video` (при необходимости с номерами), автоматически преобразуются в формат, совместимый с API. Должен содержать от 1 до 2500 символов (может быть пустым, если включена раскадровка). | STRING | Да | от 1 до 2500 символов |
| `aspect_ratio` | Желаемое соотношение сторон для генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность видео в секундах, регулируется ползунком (по умолчанию: 5). | INT | Да | от 3 до 15 |
| `reference_images` | До 7 референсных изображений. Каждое изображение должно быть не менее 300×300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. | IMAGE | Да | от 1 до 7 изображений |
| `resolution` | Выходное разрешение видео (по умолчанию: `"1080p"`). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `раскадровки` | Генерирует серию видеосегментов с отдельными промптами и длительностями. Поддерживается только для `kling-v3-omni`. Когда эта опция включена, глобальный `prompt` игнорируется, а суммарная длительность всех сегментов раскадровки должна равняться глобальной `duration` (по умолчанию: `"disabled"`). | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `создать аудио` | Генерировать аудио для видео. Поддерживается только для `kling-v3-omni` (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | Значение seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |

### Входы раскадровки

Когда `storyboards` включена, для каждого выбранного сегмента раскадровки появляются следующие входы. N изменяется от 1 до выбранного количества раскадровок.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Промпт для сегмента раскадровки N. Максимум 512 символов. | STRING | Да | от 1 до 512 символов |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах (по умолчанию: 4). | INT | Да | от 1 до 15 |

**Примечание:** Вход `reference_images` принимает максимум 7 изображений. Если передано больше, узел возвращает ошибку. Каждое изображение проверяется на минимальные размеры и соотношение сторон.

**Ограничения для конкретных моделей:**
- `kling-video-o1` не поддерживает длительность более 10 секунд.
- `kling-video-o1` не поддерживает генерацию аудио.
- `kling-video-o1` не поддерживает разрешение 4k.
- `kling-video-o1` не поддерживает раскадровку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
