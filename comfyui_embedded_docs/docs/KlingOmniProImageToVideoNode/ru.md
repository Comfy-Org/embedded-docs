# Kling Omni Изображение в Видео (Pro)

Этот узел использует модель Kling AI для генерации видео на основе текстового запроса и до семи референсных изображений. Он позволяет управлять соотношением сторон, длительностью и разрешением видео, а также опционально использовать раскадровки или генерировать аудио. Узел отправляет запрос во внешний API и возвращает сгенерированное видео.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling, используемая для генерации видео (по умолчанию: `"kling-v3-omni"`). | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовый запрос, описывающий содержимое видео. Может включать как положительные, так и отрицательные описания. Заполнители, такие как `@image` или `@video` (опционально пронумерованные), автоматически преобразуются в совместимый с API формат. Должен содержать от 1 до 2500 символов (может быть пустым, если раскадровки включены). Игнорируется, когда раскадровки включены. | STRING | Да | - |
| `aspect_ratio` | Желаемое соотношение сторон генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность видео в секундах, настраивается с помощью ползунка (по умолчанию: 5). | INT | Да | от 3 до 15 |
| `reference_images` | До 7 референсных изображений. Каждое изображение должно быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. | IMAGE | Да | от 1 до 7 изображений |
| `resolution` | Выходное разрешение видео (по умолчанию: `"1080p"`). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `storyboards` | Генерирует серию видеосегментов с отдельными текстовыми запросами и длительностями. Поддерживается только для `kling-v3-omni`. Если включено, глобальный параметр `prompt` игнорируется, и общая длительность всех сегментов раскадровки должна равняться глобальному параметру `duration` (по умолчанию: `"disabled"`). | COMBO | Нет | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `generate_audio` | Генерирует аудио для видео. Поддерживается только для `kling-v3-omni` (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | Параметр seed управляет тем, следует ли узлу запускаться заново; результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |

### Входные параметры раскадровки

Когда параметр `storyboards` включен, для каждого выбранного сегмента раскадровки появляются следующие входные параметры. N изменяется от 1 до выбранного количества раскадровок.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Текстовый запрос для сегмента раскадровки N. Максимум 512 символов. | STRING | Нет | от 1 до 512 символов |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах (по умолчанию: 4). | INT | Нет | от 1 до 15 |

**Примечание:** Входной параметр `reference_images` принимает не более 7 изображений. Если передано больше, узел выдаёт ошибку. Каждое изображение проверяется на минимальные размеры и соотношение сторон.

**Ограничения для конкретных моделей:**
- `kling-video-o1` не поддерживает длительность более 10 секунд.
- `kling-video-o1` не поддерживает генерацию аудио.
- `kling-video-o1` не поддерживает разрешение 4k.
- `kling-video-o1` не поддерживает раскадровки.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
