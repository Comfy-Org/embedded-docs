# ReplaceText

צומת Replace Text מבצע החלפת טקסט פשוטה. הוא מחפש קטע טקסט מוגדר בתוך הקלט ומחליף כל מופע שלו בקטע טקסט חדש. הפעולה מוחלת על כל קלטי הטקסט המסופקים לצומת.

**הערה:** צומת זה הוצא משימוש והוחלף בצומת Replace Text האחר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `text` | הטקסט לעיבוד. | STRING | כן | - |
| `find` | הטקסט שיש לחפש (ברירת מחדל: מחרוזת ריקה). | STRING | כן | - |
| `replace` | הטקסט שישמש להחלפה (ברירת מחדל: מחרוזת ריקה). | STRING | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `text` | הטקסט המעובד, שבו כל המופעים של הטקסט `find` הוחלפו בטקסט `replace`. | STRING |
