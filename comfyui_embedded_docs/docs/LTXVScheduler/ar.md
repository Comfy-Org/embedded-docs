# LTXV المجدول

عقدة LTXVScheduler تولد قيم سيجما لعملية أخذ عينات مخصصة. تحسب جدول الضوضاء من عدد الرموز في الكامن المقدم، أو تستخدم القيمة الافتراضية 4096 رمزًا عندما لا يكون هناك كامن متصل، ويمكنها اختياريًا تمديد قيم سيجما بحيث تتطابق القيمة النهائية مع قيمة `terminal` المحددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `خطوات` | عدد خطوات أخذ العينات (الافتراضي: 20) | INT | نعم | 1-10000 |
| `الانزياح الأقصى` | قيمة الإزاحة القصوى المستخدمة في حساب سيجما (الافتراضي: 2.05) | FLOAT | نعم | 0.0-100.0 (الخطوة: 0.01) |
| `الانزياح الأساسي` | قيمة الإزاحة الأساسية المستخدمة في حساب سيجما (الافتراضي: 0.95) | FLOAT | نعم | 0.0-100.0 (الخطوة: 0.01) |
| `تمدد` | تمديد قيم سيجما لتكون في النطاق [terminal, 1] (الافتراضي: True) | BOOLEAN | نعم | True/False |
| `نهائي` | القيمة النهائية لقيم سيجما بعد التمديد (الافتراضي: 0.1). تُستخدم فقط عندما يكون `stretch` مُفعّلًا. | FLOAT | نعم | 0.0-0.99 (الخطوة: 0.01) |
| `كامن` | مدخل كامن اختياري يُستخدم لحساب عدد الرموز لتعديل سيجما. عندما لا يتم توفيره، يتم استخدام عدد رموز افتراضي قدره 4096. | LATENT | لا | - |

**ملاحظة:** عندما يكون `stretch` مُفعّلًا، يتم إعادة قياس قيم سيجما غير الصفرية بحيث تساوي آخر قيمة سيجما غير صفرية قيمة `terminal`.
