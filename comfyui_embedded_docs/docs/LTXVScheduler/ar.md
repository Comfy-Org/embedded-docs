# LTXV المجدول

تنشئ عقدة LTXVScheduler قيم سيغما (sigma) لعمليات أخذ العينات المخصصة. وتحسب معلمات جدول الضوضاء استنادًا إلى عدد الرموز (tokens) في الكامن المُدخل، وتُطبّق تحويلًا سينيًا (sigmoid) لإنشاء جدول أخذ العينات. ويمكن للعقدة اختياريًا تمديد قيم السيغما الناتجة لمطابقة قيمة نهائية محددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `خطوات` | عدد خطوات أخذ العينات (الافتراضي: 20) | INT | نعم | 1-10000 |
| `الانزياح الأقصى` | أقصى قيمة إزاحة لحساب السيغما (الافتراضي: 2.05) | FLOAT | نعم | 0.0-100.0 |
| `الانزياح الأساسي` | قيمة الإزاحة الأساسية لحساب السيغما (الافتراضي: 0.95) | FLOAT | نعم | 0.0-100.0 |
| `تمدد` | تمديد قيم السيغما لتكون في النطاق [terminal, 1] (الافتراضي: True) | BOOLEAN | نعم | True/False |
| `نهائي` | القيمة النهائية لقيم السيغما بعد التمديد (الافتراضي: 0.1) | FLOAT | نعم | 0.0-0.99 |
| `كامن` | إدخال كامن اختياري يُستخدم لحساب عدد الرموز لضبط السيغما | LATENT | لا | - |

**ملاحظة:** معامل `latent` اختياري. عند عدم توفيره، تستخدم العقدة عدد رموز افتراضي قدره 4096 في الحسابات.
