# LTXV المجدول

تقوم عقدة LTXVScheduler بتوليد قيم سيغما لعمليات أخذ العينات المخصصة. وهي تحسب معاملات جدول الضوضاء استنادًا إلى عدد التوكنات في اللاتنت المدخل، وتطبّق تحويلًا سيجمويديًا لإنشاء جدول أخذ العينات. يمكن للعقدة اختياريًا تمديد قيم سيغما الناتجة لمطابقة قيمة نهائية محددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `steps` | عدد خطوات أخذ العينات (الافتراضي: 20) | INT | نعم | 1-10000 |
| `max_shift` | الحد الأقصى لقيمة الإزاحة لحساب سيغما (الافتراضي: 2.05) | FLOAT | نعم | 0.0-100.0 |
| `base_shift` | قيمة الإزاحة الأساسية لحساب سيغما (الافتراضي: 0.95) | FLOAT | نعم | 0.0-100.0 |
| `stretch` | تمديد قيم سيغما لتكون في النطاق [terminal, 1] (الافتراضي: True) | BOOLEAN | نعم | True/False |
| `terminal` | القيمة النهائية لقيم سيغما بعد التمديد (الافتراضي: 0.1) | FLOAT | نعم | 0.0-0.99 |
| `latent` | مدخل لاتنت اختياري يُستخدم لحساب عدد التوكنات لضبط سيغما | LATENT | لا | - |

**ملاحظة:** معامل `latent` اختياري. عند عدم توفيره، تستخدم العقدة عدد توكنات افتراضيًا قدره 4096 في العمليات الحسابية.
