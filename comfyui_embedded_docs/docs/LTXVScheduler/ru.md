# Scheduler LTXV

Узел LTXVScheduler генерирует значения сигмы для пользовательских процессов сэмплирования. Он вычисляет параметры расписания шума на основе количества токенов во входном латентном представлении и применяет сигмоидальное преобразование для создания расписания сэмплирования. При необходимости узел может растянуть результирующие сигмы до указанного конечного значения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `steps` | Количество шагов сэмплирования (по умолчанию: 20) | INT | Да | 1-10000 |
| `max_shift` | Максимальное значение сдвига для вычисления сигмы (по умолчанию: 2.05) | FLOAT | Да | 0.0-100.0 |
| `base_shift` | Базовое значение сдвига для вычисления сигмы (по умолчанию: 0.95) | FLOAT | Да | 0.0-100.0 |
| `stretch` | Растянуть сигмы в диапазон [terminal, 1] (по умолчанию: True) | BOOLEAN | Да | True/False |
| `terminal` | Конечное значение сигм после растяжения (по умолчанию: 0.1) | FLOAT | Да | 0.0-0.99 |
| `latent` | Необязательное латентное представление, используемое для подсчёта количества токенов для корректировки сигмы | LATENT | Нет | - |

**Примечание:** Параметр `latent` является необязательным. Если он не указан, узел использует количество токенов по умолчанию, равное 4096, для расчётов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Сгенерированные значения сигмы для процесса сэмплирования | SIGMAS |
