# Scheduler LTXV

Узел LTXVScheduler генерирует значения sigma для пользовательского процесса сэмплирования. Он вычисляет график шума по количеству токенов в переданном латенте или использует значение по умолчанию 4096 токенов, когда латент не подключён, и может дополнительно растянуть значения sigma так, чтобы конечное значение соответствовало указанному значению `terminal`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `шаги` | Количество шагов сэмплирования (по умолчанию: 20) | INT | Да | 1-10000 |
| `максимальное_смещение` | Максимальное значение сдвига, используемое при расчёте sigma (по умолчанию: 2.05) | FLOAT | Да | 0.0-100.0 (шаг: 0.01) |
| `базовое_смещение` | Базовое значение сдвига, используемое при расчёте sigma (по умолчанию: 0.95) | FLOAT | Да | 0.0-100.0 (шаг: 0.01) |
| `растяжение` | Растянуть значения sigma, чтобы они находились в диапазоне [terminal, 1] (по умолчанию: True) | BOOLEAN | Да | True/False |
| `терминал` | Конечное значение sigma после растяжения (по умолчанию: 0.1). Используется только когда `stretch` включён. | FLOAT | Да | 0.0-0.99 (шаг: 0.01) |
| `скрытый` | Необязательный латентный вход, используемый для расчёта количества токенов для корректировки sigma. Если не указан, используется количество токенов по умолчанию — 4096. | LATENT | Нет | - |

**Примечание:** Когда `stretch` включён, ненулевые значения sigma масштабируются так, чтобы последнее ненулевое значение sigma было равно значению `terminal`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Значения sigma, сгенерированные для процесса сэмплирования | SIGMAS |
