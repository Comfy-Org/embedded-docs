# Scheduler LTXV

Узел LTXVScheduler генерирует значения сигм для пользовательских процессов сэмплирования. Он вычисляет параметры расписания шума на основе количества токенов во входном латентном представлении и применяет сигмоидальное преобразование для создания расписания сэмплирования. При необходимости узел может растянуть результирующие сигмы до заданного конечного значения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `шаги` | Количество шагов сэмплирования (по умолчанию: 20) | INT | Да | 1-10000 |
| `максимальное_смещение` | Максимальное значение сдвига для вычисления сигм (по умолчанию: 2.05) | FLOAT | Да | 0.0-100.0 |
| `базовое_смещение` | Базовое значение сдвига для вычисления сигм (по умолчанию: 0.95) | FLOAT | Да | 0.0-100.0 |
| `растяжение` | Растянуть сигмы в диапазон [terminal, 1] (по умолчанию: True) | BOOLEAN | Да | True/False |
| `терминал` | Конечное значение сигм после растяжения (по умолчанию: 0.1) | FLOAT | Да | 0.0-0.99 |
| `скрытый` | Необязательный вход `latent`, используемый для вычисления количества токенов для корректировки сигм | LATENT | Нет | - |

**Примечание:** Параметр `latent` является необязательным. Если он не указан, узел использует количество токенов по умолчанию, равное 4096, для вычислений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Сгенерированные значения сигм для процесса сэмплирования | SIGMAS |
