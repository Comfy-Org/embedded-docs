# LTXVScheduler

گره LTXVScheduler مقادیر سیگما را برای یک فرآیند نمونه‌گیری سفارشی تولید می‌کند. زمان‌بندی نویز را از تعداد توکن‌های latent ارائه‌شده محاسبه می‌کند، یا زمانی که هیچ latent متصل نیست از مقدار پیش‌فرض 4096 توکن استفاده می‌کند، و می‌تواند به‌صورت اختیاری مقادیر سیگما را بکشد تا مقدار نهایی با مقدار `terminal` مشخص‌شده مطابقت داشته باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `steps` | تعداد مراحل نمونه‌گیری (پیش‌فرض: 20) | INT | بله | 1-10000 |
| `max_shift` | حداکثر مقدار shift استفاده‌شده در محاسبه سیگما (پیش‌فرض: 2.05) | FLOAT | بله | 0.0-100.0 (step: 0.01) |
| `base_shift` | مقدار shift پایه استفاده‌شده در محاسبه سیگما (پیش‌فرض: 0.95) | FLOAT | بله | 0.0-100.0 (step: 0.01) |
| `stretch` | سیگماها را طوری بکشید که در بازه [terminal, 1] قرار گیرند (پیش‌فرض: True) | BOOLEAN | بله | True/False |
| `terminal` | مقدار پایانی سیگماها پس از کشش (پیش‌فرض: 0.1). فقط زمانی استفاده می‌شود که `stretch` فعال باشد. | FLOAT | بله | 0.0-0.99 (step: 0.01) |
| `latent` | ورودی اختیاری latent که برای محاسبه تعداد توکن‌ها جهت تنظیم سیگما استفاده می‌شود. اگر ارائه نشود، تعداد توکن پیش‌فرض 4096 استفاده می‌شود. | LATENT | خیر | - |

**توجه:** وقتی `stretch` فعال است، مقادیر غیرصفر سیگما دوباره مقیاس‌بندی می‌شوند تا آخرین سیگمای غیرصفر برابر مقدار `terminal` شود.
