# LTXVScheduler

گره LTXVScheduler مقادیر سیگما را برای فرآیندهای نمونه‌برداری سفارشی تولید می‌کند. این گره پارامترهای زمان‌بندی نویز را بر اساس تعداد توکن‌های موجود در latent ورودی محاسبه کرده و با اعمال یک تبدیل سیگموئید، زمان‌بندی نمونه‌برداری را می‌سازد. این گره به‌صورت اختیاری می‌تواند سیگماهای حاصل را به‌گونه‌ای کشش دهد که با مقدار پایانی مشخص‌شده مطابقت داشته باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `steps` | تعداد مراحل نمونه‌برداری (پیش‌فرض: 20) | INT | بله | 1-10000 |
| `max_shift` | حداکثر مقدار شیفت برای محاسبه سیگما (پیش‌فرض: 2.05) | FLOAT | بله | 0.0-100.0 |
| `base_shift` | مقدار شیفت پایه برای محاسبه سیگما (پیش‌فرض: 0.95) | FLOAT | بله | 0.0-100.0 |
| `stretch` | سیگماها را به بازه [terminal, 1] کشش بده (پیش‌فرض: True) | BOOLEAN | بله | True/False |
| `terminal` | مقدار پایانی سیگماها پس از کشش (پیش‌فرض: 0.1) | FLOAT | بله | 0.0-0.99 |
| `latent` | ورودی اختیاری latent که برای محاسبه تعداد توکن‌ها جهت تنظیم سیگما استفاده می‌شود | LATENT | خیر | - |

**نکته:** پارامتر `latent` اختیاری است. زمانی که ارائه نشود، گره از تعداد توکن پیش‌فرض 4096 برای محاسبات استفاده می‌کند.
