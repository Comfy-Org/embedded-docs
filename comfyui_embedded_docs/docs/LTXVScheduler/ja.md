# LTXVスケジューラー

LTXVSchedulerノードは、カスタムサンプリングプロセス用のシグマ値を生成します。入力された潜在変数のトークン数に基づいてノイズスケジュールパラメータを計算し、シグモイド変換を適用してサンプリングスケジュールを作成します。このノードは、必要に応じて結果のシグマを指定された終端値に一致するように拡張できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `steps` | サンプリングステップ数（デフォルト: 20） | INT | Yes | 1-10000 |
| `max_shift` | シグマ計算の最大シフト値（デフォルト: 2.05） | FLOAT | Yes | 0.0-100.0 |
| `base_shift` | シグマ計算のベースシフト値（デフォルト: 0.95） | FLOAT | Yes | 0.0-100.0 |
| `stretch` | シグマを [terminal, 1] の範囲になるように拡張します（デフォルト: True） | BOOLEAN | Yes | True/False |
| `terminal` | 拡張後のシグマの終端値（デフォルト: 0.1） | FLOAT | Yes | 0.0-0.99 |
| `latent` | シグマ調整用のトークン数を計算するために使用するオプションの潜在入力 | LATENT | No | - |

**注:** `latent` パラメータはオプションです。指定しない場合、ノードは計算にデフォルトのトークン数4096を使用します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `sigmas` | サンプリングプロセス用に生成されたシグマ値 | SIGMAS |
