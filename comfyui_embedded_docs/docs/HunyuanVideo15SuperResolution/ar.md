# HunyuanVideo15SuperResolution

تقوم عقدة **HunyuanVideo15SuperResolution** بإعداد بيانات التكييف لعملية رفع دقة الفيديو. فهي تأخذ تمثيلًا كامنًا (latent) لفيديو، واختياريًا صورة بداية، وتجمعها مع قيمة تضخيم الضوضاء وبيانات رؤية CLIP الاختيارية في تنسيق يمكن للنموذج استخدامه لتوليد مخرجات بدقة أعلى.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `positive` | مدخل التكييف الإيجابي الذي سيتم تعديله بدمج بيانات الكامن وتضخيم الضوضاء. | CONDITIONING | نعم | N/A |
| `negative` | مدخل التكييف السلبي الذي سيتم تعديله بدمج بيانات الكامن وتضخيم الضوضاء. | CONDITIONING | نعم | N/A |
| `vae` | الـ VAE المستخدم لتشفير `start_image` الاختيارية. مطلوب إذا تم توفير `start_image`. | VAE | لا | N/A |
| `start_image` | صورة بداية اختيارية توجه عملية رفع الدقة. إذا تم توفيرها، يتم تكبيرها وتشفيرها باستخدام `vae` ووضعها في بداية البيانات الكامنة للتكييف. | IMAGE | لا | N/A |
| `clip_vision_output` | تضمينات CLIP vision الاختيارية. عند توفيرها، تتم إضافتها إلى كل من التكييف الإيجابي والسلبي. | CLIP_VISION_OUTPUT | لا | N/A |
| `latent` | تمثيل الفيديو الكامن الذي سيتم دمجه في التكييف. | LATENT | نعم | N/A |
| `noise_augmentation` | قوة تضخيم الضوضاء المراد تطبيقها على التكييف (الافتراضي: 0.70). هذه معلمة متقدمة. | FLOAT | نعم | 0.0 - 1.0 (step 0.01) |

**ملاحظة:** إذا قدمت `start_image`، يجب عليك أيضًا توصيل `vae` لتشفيرها. يتم تكبير `start_image` تلقائيًا ليطابق الأبعاد المضمنة في `latent` المُدخل، ويستخدم VAE أول ثلاث قنوات لونية (RGB) فقط.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي المعدل، الذي يحتوي الآن على بيانات الكامن المدمجة وتضخيم الضوضاء وبيانات CLIP vision الاختيارية. | CONDITIONING |
| `negative` | التكييف السلبي المعدل، الذي يحتوي الآن على بيانات الكامن المدمجة وتضخيم الضوضاء وبيانات CLIP vision الاختيارية. | CONDITIONING |
| `latent` | التمثيل الكامن المُدخل، تم تمريره دون تغيير. | LATENT |
