# HunyuanVideo15SuperResolution

Узел HunyuanVideo15SuperResolution подготавливает данные conditioning для процесса суперразрешения видео. Он принимает латентное представление видео и, опционально, начальное изображение, и упаковывает их вместе с шумовой аугментацией и данными CLIP vision в формат, который может быть использован моделью для создания выходного изображения более высокого разрешения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Входное положительное conditioning, которое будет изменено с помощью латентных данных и аугментации. | CONDITIONING | Да | N/A |
| `отрицательный` | Входное отрицательное conditioning, которое будет изменено с помощью латентных данных и аугментации. | CONDITIONING | Да | N/A |
| `vae` | VAE, используемый для кодирования опционального `start_image`. Требуется, если предоставлен `start_image`. | VAE | Нет | N/A |
| `начальное изображение` | Опциональное начальное изображение для управления суперразрешением. Если оно предоставлено, оно увеличивается и кодируется в латентное состояние conditioning. | IMAGE | Нет | N/A |
| `clip_vision_output` | Опциональные эмбеддинги CLIP vision, добавляемые к conditioning. | CLIP_VISION_OUTPUT | Нет | N/A |
| `латентный` | Входное латентное представление видео, которое включается в conditioning. | LATENT | Да | N/A |
| `добавление шума` | Сила шумовой аугментации, применяемой к conditioning (по умолчанию: 0.70). Это продвинутый параметр. | FLOAT | Нет | 0.0 - 1.0 (step 0.01) |

**Примечание:** Если вы предоставляете `start_image`, вы также должны подключить `vae`, чтобы он мог быть закодирован. `start_image` автоматически увеличивается до 16-кратных пространственных размеров (ширины и высоты) входного `latent`, затем кодируется и помещается в латентное состояние conditioning. Для кодирования используются только RGB-каналы `start_image`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированное положительное conditioning, теперь содержащее конкатенированные латентные данные, шумовую аугментацию и опциональные данные CLIP vision. | CONDITIONING |
| `отрицательный` | Модифицированное отрицательное conditioning, теперь содержащее конкатенированные латентные данные, шумовую аугментацию и опциональные данные CLIP vision. | CONDITIONING |
| `латентный` | Входное латентное состояние передается без изменений. | LATENT |
