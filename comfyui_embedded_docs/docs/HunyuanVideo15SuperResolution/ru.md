# HunyuanVideo15SuperResolution

Узел HunyuanVideo15SuperResolution подготавливает данные conditioning для процесса суперразрешения видео. Он принимает латентное представление видео и, опционально, начальное изображение, и упаковывает их вместе со значением шумовой аугментации и опциональными данными CLIP vision в формат, который модель может использовать для создания выходного изображения с более высоким разрешением.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный входной conditioning, который будет модифицирован объединенными данными латентного представления и шумовой аугментации. | CONDITIONING | Да | N/A |
| `negative` | Отрицательный входной conditioning, который будет модифицирован объединенными данными латентного представления и шумовой аугментации. | CONDITIONING | Да | N/A |
| `vae` | VAE, используемый для кодирования опционального `start_image`. Требуется, если указан `start_image`. | VAE | Нет | N/A |
| `start_image` | Опциональное начальное изображение, которое направляет процесс суперразрешения. Если оно указано, оно увеличивается, кодируется с помощью `vae` и помещается в начало conditioning-латентного представления. | IMAGE | Нет | N/A |
| `clip_vision_output` | Опциональные эмбеддинги CLIP vision. При их наличии они добавляются и к положительному, и к отрицательному conditioning. | CLIP_VISION_OUTPUT | Нет | N/A |
| `latent` | Латентное представление видео, которое должно быть включено в conditioning. | LATENT | Да | N/A |
| `noise_augmentation` | Сила шумовой аугментации, применяемой к conditioning (по умолчанию: 0.70). Это расширенный параметр. | FLOAT | Да | 0.0 - 1.0 (step 0.01) |

**Примечание:** Если вы указываете `start_image`, вы также должны подключить `vae` для его кодирования. `start_image` автоматически увеличивается до размеров, подразумеваемых входным `latent`, и только первые три цветовых канала (RGB) используются VAE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированный положительный conditioning, теперь содержащий объединенные данные латентного представления, шумовой аугментации и опциональные данные CLIP vision. | CONDITIONING |
| `negative` | Модифицированный отрицательный conditioning, теперь содержащий объединенные данные латентного представления, шумовой аугментации и опциональные данные CLIP vision. | CONDITIONING |
| `latent` | Входное латентное представление, переданное без изменений. | LATENT |
