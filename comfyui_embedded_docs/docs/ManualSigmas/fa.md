# ManualSigmas

گره ManualSigmas به شما امکان می‌دهد تا یک توالی سفارشی از سطوح نویز (سیگماها) را برای فرایند نمونه‌گیری به‌صورت دستی تعریف کنید. شما فهرستی از اعداد را به‌صورت یک رشته وارد می‌کنید و گره آن‌ها را به یک تنسور SIGMAS تبدیل می‌کند که می‌تواند توسط سایر گره‌های نمونه‌گیری استفاده شود. این برای آزمون یا ایجاد زمان‌بندی‌های نویز خاص مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `sigmas` | رشته‌ای شامل مقادیر سیگما. گره همه اعداد را از این رشته استخراج می‌کند، شامل اعشاری و مقادیر منفی. برای مثال، "1, 0.5, 0.1" یا "1 0.5 0.1". پیش‌فرض: "1, 0.5". | STRING | بله | هر مقدار عددی جداشده با کاما یا فاصله |

توجه: این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
