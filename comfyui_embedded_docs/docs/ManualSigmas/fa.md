# ManualSigmas

گره ManualSigmas به شما امکان می‌دهد دنباله‌ای سفارشی از سطوح نویز (سیگماها) را برای فرآیند نمونه‌برداری به‌صورت دستی تعریف کنید. شما لیستی از اعداد را به‌صورت رشته وارد می‌کنید و گره آن‌ها را به یک تنسور تبدیل می‌کند که می‌تواند توسط سایر گره‌های نمونه‌برداری استفاده شود. این قابلیت برای آزمایش یا ایجاد برنامه‌های نویز خاص مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `sigmas` | رشته‌ای شامل مقادیر سیگما. گره تمام اعداد را از این رشته استخراج می‌کند. برای مثال، «1, 0.5, 0.1» یا «1 0.5 0.1». مقدار پیش‌فرض «1, 0.5» است. | STRING | بله | هر عددی که با کاما یا فاصله جدا شده باشد |
