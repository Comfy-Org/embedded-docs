# ManualSigmas

Узел ManualSigmas позволяет вручную задать пользовательскую последовательность уровней шума (сигм) для процесса сэмплирования. Вы вводите список чисел в виде строки, и узел преобразует их в тензор, который может использоваться другими узлами сэмплирования. Это полезно для тестирования или создания определённых расписаний шума.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `сигмы` | Строка, содержащая значения сигмы. Узел извлекает все числа из этой строки, включая десятичные и отрицательные значения. Например: "1, 0.5, 0.1" или "1 0.5 0.1". По умолчанию: "1, 0.5". | STRING | Да | Любые числовые значения, разделённые запятыми или пробелами |

Примечание: этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Тензор, содержащий последовательность значений сигмы, извлечённых из входной строки. | SIGMAS |
