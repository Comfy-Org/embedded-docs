# ManualSigmas

Узел ManualSigmas позволяет вручную задать свою последовательность уровней шума (сигм) для процесса семплирования. Вы вводите список чисел в виде строки, и узел преобразует их в тензор, который могут использовать другие узлы семплирования. Это полезно для тестирования или создания определённых графиков шума.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Строка, содержащая значения сигм. Узел извлечёт все числа из этой строки. Например, "1, 0.5, 0.1" или "1 0.5 0.1". Значение по умолчанию — "1, 0.5". | STRING | Да | Любые числа, разделённые запятыми или пробелами |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Тензор, содержащий последовательность значений сигм, извлечённых из входной строки. | SIGMAS |
