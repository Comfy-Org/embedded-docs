# הוסף שכבה

צומת Add Layer הופך תמונת קלט לשכבה וממקם אותה על קנבס, בין אם על ידי התחלת ערימת שכבות חדשה ובין אם על ידי הוספתה לערימה קיימת. ניתן להגדיר את שם השכבה, מיקומה, גודלה, סיבוב, אטימות, מצב מיזוג, סדר ערימה והיפוך אופקי או אנכי. צומת זה מסומן כניסויי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `layers` | ערימת שכבות שאליה יש להוסיף. השאר לא מחובר כדי להתחיל ערימה חדשה. | LAYERS | לא | — |
| `image` | תוכן השכבה בגודל המקורי שלה. אצווה מתרחבת לשכבות עוקבות. | IMAGE | כן | — |
| `mask` | מסכת שקיפות לשכבה זו. אזורים ממוסכים (ערך 1) נעשים שקופים, תוך הכפלה עם כל ערוץ אלפא שהתמונה כבר נושאת. | MASK | לא | — |
| `name` | שם השכבה המוצג בעורך הקומפוזיטור. (ברירת מחדל: "") | STRING | לא | — |
| `x` | מיקום אופקי ראשוני על הקנבס. (ברירת מחדל: 0) | INT | לא | -MAX_RESOLUTION עד MAX_RESOLUTION |
| `y` | מיקום אנכי ראשוני על הקנבס. (ברירת מחדל: 0) | INT | לא | -MAX_RESOLUTION עד MAX_RESOLUTION |
| `opacity` | אטימות ראשונית של השכבה. (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 עד 1.0 (צעד: 0.01) |
| `blend_mode` | מצב מיזוג ראשוני, מיושם מול השכבות שמתחת. בשכבה התחתונה מעל רקע שקוף כברירת מחדל, מצבים שאינם normal יוצרים שקיפות. (ברירת מחדל: "normal") | COMBO | לא | אפשרויות מרובות זמינות |
| `rotation` | סיבוב ראשוני במעלות, עם כיוון השעון. (ברירת מחדל: 0.0) | FLOAT | לא | -360.0 עד 360.0 (צעד: 1.0) |
| `width` | רוחב תצוגה ראשוני. 0 שומר על הרוחב המקורי של התמונה. (ברירת מחדל: 0) | INT | לא | 0 עד MAX_RESOLUTION |
| `height` | גובה תצוגה ראשוני. 0 שומר על הגובה המקורי של התמונה. (ברירת מחדל: 0) | INT | לא | 0 עד MAX_RESOLUTION |
| `z_index` | עקיפת סדר ערימה. שכבות ממוינות במיון יציב לפי z_index; ערכים שווים שומרים על סדר הרשימה. (ברירת מחדל: 0) | INT | לא | -1000 עד 1000 |
| `flip_h` | היפוך השכבה אופקית. (ברירת מחדל: False) | BOOLEAN | לא | false / true |
| `flip_v` | היפוך השכבה אנכית. (ברירת מחדל: False) | BOOLEAN | לא | false / true |

הערות:
- רק `image` הוא שדה חובה; כל שאר הקלטים אופציונליים.
- כאשר `layers` נשאר לא מחובר, נוצרת ערימת שכבות חדשה. כאשר ערימת שכבות מחוברת, השכבה החדשה נוספת אליה.
- אצווה של תמונות בקלט `image` יוצרת מספר שכבות עוקבות.
- ברירת המחדל של `width` ו-`height` היא 0, מה ששומר על הממדים המקוריים של התמונה. ערכים גדולים מ-0 עוקפים את גודל התצוגה.
- `opacity`, `blend_mode`, `rotation`, `width` ו-`height` מיושמים רק כאשר הם שונים מערכי ברירת המחדל שלהם.
- גודל הקנבס של ערימת שכבות מחוברת נשמר בפלט.
