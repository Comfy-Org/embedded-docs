# AddLayer

Узел Add Layer превращает входное изображение в слой и размещает его на холсте, либо создавая новый стек слоёв, либо добавляя его к существующему. Вы можете задать имя слоя, его положение, размер, поворот, непрозрачность, режим наложения, порядок в стеке и горизонтальное или вертикальное отражение. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `слои` | Стек слоёв, к которому нужно добавить слой. Оставьте неподключённым, чтобы создать новый стек. | LAYERS | Нет | — |
| `изображение` | Содержимое слоя в его исходном размере. Пакет изображений расширяется в последовательные слои. | IMAGE | Да | — |
| `маска` | Маска прозрачности для этого слоя. Области маски (значение 1) становятся прозрачными, перемножаясь с альфа-каналом, который уже есть у изображения. | MASK | Нет | — |
| `имя` | Имя слоя, отображаемое в редакторе композитора. (по умолчанию: "") | STRING | Нет | — |
| `x` | Начальное горизонтальное размещение на холсте. (по умолчанию: 0) | INT | Нет | -MAX_RESOLUTION до MAX_RESOLUTION |
| `y` | Начальное вертикальное размещение на холсте. (по умолчанию: 0) | INT | Нет | -MAX_RESOLUTION до MAX_RESOLUTION |
| `непрозрачность` | Начальная непрозрачность слоя. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 (шаг 0.01) |
| `режим смешивания` | Начальный режим наложения, применяемый к слоям ниже. На нижнем слое поверх прозрачного фона по умолчанию режимы, отличные от normal, создают прозрачность. (по умолчанию: "normal") | COMBO | Нет | Доступно несколько вариантов |
| `вращение` | Начальный поворот в градусах, по часовой стрелке. (по умолчанию: 0.0) | FLOAT | Нет | -360.0 до 360.0 (шаг 1.0) |
| `ширина` | Начальная ширина отображения. 0 сохраняет исходную ширину изображения. (по умолчанию: 0) | INT | Нет | 0 до MAX_RESOLUTION |
| `высота` | Начальная высота отображения. 0 сохраняет исходную высоту изображения. (по умолчанию: 0) | INT | Нет | 0 до MAX_RESOLUTION |
| `z-индекс` | Переопределение порядка в стеке. Слои стабильно сортируются по z_index; при равных значениях сохраняется их порядок в списке. (по умолчанию: 0) | INT | Нет | -1000 до 1000 |
| `отразить по горизонтали` | Отразить слой по горизонтали. (по умолчанию: False) | BOOLEAN | Нет | false / true |
| `отразить по вертикали` | Отразить слой по вертикали. (по умолчанию: False) | BOOLEAN | Нет | false / true |

Примечания:
- Только `image` является обязательным; все остальные входы необязательны.
- Если `layers` не подключён, создаётся новый стек слоёв. Если стек слоёв подключён, новый слой добавляется к нему.
- Пакет изображений на входе `image` создаёт несколько последовательных слоёв.
- `width` и `height` по умолчанию равны 0, что сохраняет исходные размеры изображения. Значения больше 0 переопределяют размер отображения.
- `opacity`, `blend_mode`, `rotation`, `width` и `height` применяются только тогда, когда они отличаются от значений по умолчанию.
- Размер холста подключённого стека слоёв сохраняется на выходе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `layers` | Стек слоёв с добавленным этим слоем. | LAYERS |
