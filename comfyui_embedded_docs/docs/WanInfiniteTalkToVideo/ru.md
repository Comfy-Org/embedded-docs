# WanInfiniteTalkToVideo

WanInfiniteTalkToVideo генерирует видеопоследовательности из аудиовхода. Он использует модель диффузии видео, обусловленную аудиопризнаками, извлечёнными из одного или двух говорящих, для создания скрытого представления видео с говорящей головой. Узел может генерировать новую последовательность или продолжать существующую, используя предыдущие кадры в качестве контекста движения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `режим` | Режим аудиовхода. `single_speaker` использует один аудиовход. `two_speakers` включает дополнительный аудиовход и маски, перечисленные в разделе «Входы для двух говорящих». | DYNAMIC_COMBO | Да | `"single_speaker"`<br>`"two_speakers"` |
| `модель` | Базовая модель диффузии видео. | MODEL | Да | - |
| `патч модели` | Патч модели, содержащий слои проекции аудио. | MODEL_PATCH | Да | - |
| `позитивный` | Позитивное кондиционирование для управления генерацией. | CONDITIONING | Да | - |
| `негативный` | Негативное кондиционирование для управления генерацией. | CONDITIONING | Да | - |
| `vae` | VAE, используемый для кодирования изображений в скрытое пространство и обратно. | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 832) | INT | Да | 16 - MAX_RESOLUTION (step 16) |
| `высота` | Высота выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 480) | INT | Да | 16 - MAX_RESOLUTION (step 16) |
| `длина` | Количество кадров для генерации. (по умолчанию: 81) | INT | Да | 1 - MAX_RESOLUTION (step 4) |
| `выход clip vision` | Необязательный вывод CLIP vision для дополнительного кондиционирования. | CLIP_VISION_OUTPUT | Нет | - |
| `стартовое изображение` | Необязательное стартовое изображение для инициализации видеопоследовательности. | IMAGE | Нет | - |
| `выход аудиоэнкодера 1` | Основной вывод аудиоэнкодера, содержащий признаки для первого говорящего. | AUDIO_ENCODER_OUTPUT | Да | - |
| `количество кадров движения` | Количество предыдущих кадров, используемых в качестве контекста движения. (по умолчанию: 9) | INT | Да | 1 - 33 |
| `масштаб аудио` | Коэффициент масштабирования, применяемый к аудиокондиционированию. (по умолчанию: 1.0) | FLOAT | Да | -10.0 - 10.0 |
| `предыдущие кадры` | Необязательные предыдущие кадры видео для продолжения. Последние `motion_frame_count` кадров используются в качестве контекста движения. | IMAGE | Нет | - |

### Входы для двух говорящих

Входы в этом разделе отображаются, когда для `mode` задано значение `"two_speakers"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio_encoder_output_2` | Второй вывод аудиоэнкодера, содержащий признаки для второго говорящего. | AUDIO_ENCODER_OUTPUT | Нет | - |
| `mask_1` | Маска для первого говорящего, обязательна при использовании двух аудиовходов. | MASK | Нет | - |
| `mask_2` | Маска для второго говорящего, обязательна при использовании двух аудиовходов. | MASK | Нет | - |

**Ограничения параметров:**

- Когда для `mode` задано значение `"two_speakers"`, для настройки второго говорящего требуются `audio_encoder_output_2`, `mask_1` и `mask_2`.
- Если указан `audio_encoder_output_2`, также должны быть указаны и `mask_1`, и `mask_2`.
- Если указаны и `mask_1`, и `mask_2`, также должен быть указан `audio_encoder_output_2`.
- Если указан `previous_frames`, он должен содержать по крайней мере столько кадров, сколько задано в `motion_frame_count`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `модель` | Модель с патчем и применённым аудиокондиционированием. | MODEL |
| `позитивный` | Позитивное кондиционирование, возможно изменённое с добавлением дополнительного контекста, такого как стартовое изображение или вывод CLIP vision. | CONDITIONING |
| `негативный` | Негативное кондиционирование, возможно изменённое с добавлением дополнительного контекста. | CONDITIONING |
| `latent` | Сгенерированная видеопоследовательность в скрытом пространстве. | LATENT |
| `обрезанное изображение` | Количество кадров с начала контекста движения, которые следует обрезать при продолжении последовательности. Равно `motion_frame_count`, если указан `previous_frames`, в противном случае — 0. | INT |
