# WanInfiniteTalkToVideo

Узел WanInfiniteTalkToVideo генерирует видеофрагмент с говорящим человеком из аудио. Он обусловливает видеодиффузионную модель аудиохарактеристиками одного или двух дикторов, при необходимости использует начальное изображение или предыдущие кадры в качестве контекста и возвращает пропатченную модель, conditioning и латентное видео для сэмплирования.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `mode` | Режим аудио. Выбор `"single_speaker"` использует один аудиовход. Выбор `"two_speakers"` добавляет входные параметры второго диктора, перечисленные ниже. | DYNAMIC_COMBO | Да | `"single_speaker"`<br>`"two_speakers"` |
| `model` | Базовая видеодиффузионная модель для модификации. | MODEL | Да | - |
| `model_patch` | Патч модели, содержащий слои проекции аудио. | MODELPATCH | Да | - |
| `positive` | Позитивное кондиционирование, используемое для управления генерацией видео. | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование, используемое для управления генерацией видео. | CONDITIONING | Да | - |
| `vae` | VAE, используемый для кодирования изображений и предыдущих кадров в латентное пространство. | VAE | Да | - |
| `width` | Ширина генерируемого видео в пикселях, с шагом 16. (по умолчанию: 832) | INT | Да | 16 - MAX_RESOLUTION (step 16) |
| `height` | Высота генерируемого видео в пикселях, с шагом 16. (по умолчанию: 480) | INT | Да | 16 - MAX_RESOLUTION (step 16) |
| `length` | Количество кадров для генерации. (по умолчанию: 81) | INT | Да | 1 - MAX_RESOLUTION (step 4) |
| `audio_encoder_output_1` | Выход аудиоэнкодера для первого диктора, содержащий аудиохарактеристики, используемые для кондиционирования. | AUDIOENCODEROUTPUT | Да | - |
| `start_image` | Необязательное начальное изображение, используемое для инициализации начала видео. Оно масштабируется до `width` и `height`. | IMAGE | Нет | - |
| `clip_vision_output` | Необязательный выход CLIP vision, добавляемый и к позитивному, и к негативному кондиционированию. | CLIPVISIONOUTPUT | Нет | - |
| `motion_frame_count` | Количество предыдущих кадров, используемых в качестве контекста движения. (по умолчанию: 9) | INT | Да | 1 - 33 (step 1) |
| `audio_scale` | Коэффициент масштабирования, применяемый к аудиокондиционированию. (по умолчанию: 1.0) | FLOAT | Да | -10.0 - 10.0 (step 0.01) |
| `previous_frames` | Необязательные предыдущие кадры видео, используемые для продолжения существующей последовательности. Узел использует последние `motion_frame_count` кадров в качестве контекста движения. | IMAGE | Нет | - |

### Входные параметры для одного диктора

Выбор `single_speaker` не добавляет никаких дополнительных входных параметров.

### Входные параметры для двух дикторов

Эти входные параметры доступны, когда `mode` имеет значение `"two_speakers"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio_encoder_output_2` | Выход аудиоэнкодера для второго диктора. Если он задан, `mask_1` и `mask_2` также должны быть заданы. | AUDIOENCODEROUTPUT | Нет | - |
| `mask_1` | Маска для первого диктора, обязательна при использовании двух аудиовходов. | MASK | Нет | - |
| `mask_2` | Маска для второго диктора, обязательна при использовании двух аудиовходов. | MASK | Нет | - |

**Ограничения параметров:**

- Если указан `audio_encoder_output_2`, оба параметра `mask_1` и `mask_2` также должны быть указаны.
- Если указаны оба параметра `mask_1` и `mask_2`, параметр `audio_encoder_output_2` также должен быть указан.
- Если указан `previous_frames`, он должен содержать как минимум столько кадров, сколько задано параметром `motion_frame_count`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Пропатченная модель с применёнными аудиокондиционированием и обёртками для сэмплирования. | MODEL |
| `positive` | Позитивное кондиционирование, возможно изменённое с учётом начального изображения или контекста CLIP vision. | CONDITIONING |
| `negative` | Негативное кондиционирование, возможно изменённое с учётом начального изображения или контекста CLIP vision. | CONDITIONING |
| `latent` | Латентный тензор с нулевой инициализацией, представляющий видео для генерации. | LATENT |
| `trim_image` | Количество кадров, которое нужно обрезать с начала при продолжении из предыдущих кадров; 0 при запуске новой последовательности. | INT |
