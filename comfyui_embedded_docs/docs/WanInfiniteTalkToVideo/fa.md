# WanInfiniteTalkToVideo

گره WanInfiniteTalkToVideo یک کلیپ ویدیویی چهره گویا از صدا تولید می‌کند. این گره یک مدل دیفیوژن ویدئو را بر اساس ویژگی‌های صوتی یک یا دو گوینده شرطی‌سازی می‌کند، به‌صورت اختیاری از یک تصویر شروع یا فریم‌های قبلی به‌عنوان زمینه استفاده می‌کند و یک مدل پچ‌شده، شرطی‌سازی و یک ویدئوی نهفته برای نمونه‌برداری برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `mode` | حالت صدا. انتخاب `"single_speaker"` از یک ورودی صوتی استفاده می‌کند. انتخاب `"two_speakers"` ورودی‌های گوینده دوم را که در زیر فهرست شده‌اند اضافه می‌کند. | DYNAMIC_COMBO | بله | `"single_speaker"`<br>`"two_speakers"` |
| `model` | مدل دیفیوژن ویدئوی پایه که قرار است پچ شود. | MODEL | بله | - |
| `model_patch` | پچ مدل شامل لایه‌های پروجکشن صوتی. | MODELPATCH | بله | - |
| `positive` | شرطی‌سازی مثبت مورد استفاده برای هدایت تولید ویدئو. | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی مورد استفاده برای هدایت تولید ویدئو. | CONDITIONING | بله | - |
| `vae` | VAE مورد استفاده برای رمزگذاری تصاویر و فریم‌های قبلی به فضای نهفته. | VAE | بله | - |
| `width` | عرض ویدئوی تولید شده بر حسب پیکسل، با گام‌های ۱۶. (پیش‌فرض: ۸۳۲) | INT | بله | 16 - MAX_RESOLUTION (step 16) |
| `height` | ارتفاع ویدئوی تولید شده بر حسب پیکسل، با گام‌های ۱۶. (پیش‌فرض: ۴۸۰) | INT | بله | 16 - MAX_RESOLUTION (step 16) |
| `length` | تعداد فریم‌هایی که تولید می‌شوند. (پیش‌فرض: ۸۱) | INT | بله | 1 - MAX_RESOLUTION (step 4) |
| `audio_encoder_output_1` | خروجی رمزگذار صوتی برای گوینده اول، شامل ویژگی‌های صوتی مورد استفاده برای شرطی‌سازی. | AUDIOENCODEROUTPUT | بله | - |
| `start_image` | تصویر شروع اختیاری که برای مقداردهی اولیه شروع ویدئو استفاده می‌شود. این تصویر به اندازه `width` و `height` تغییر اندازه داده می‌شود. | IMAGE | خیر | - |
| `clip_vision_output` | خروجی دید CLIP اختیاری که به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود. | CLIPVISIONOUTPUT | خیر | - |
| `motion_frame_count` | تعداد فریم‌های قبلی که به‌عنوان زمینه حرکت استفاده شود. (پیش‌فرض: ۹) | INT | بله | 1 - 33 (step 1) |
| `audio_scale` | ضریب مقیاس اعمال‌شده بر شرطی‌سازی صوتی. (پیش‌فرض: ۱.۰) | FLOAT | بله | -10.0 - 10.0 (step 0.01) |
| `previous_frames` | فریم‌های ویدئویی قبلی اختیاری که برای ادامه دادن یک سکانس موجود استفاده می‌شوند. گره از آخرین فریم‌های `motion_frame_count` به‌عنوان زمینه حرکت استفاده می‌کند. | IMAGE | خیر | - |

### ورودی‌های تک‌گوینده

انتخاب `single_speaker` هیچ ورودی اضافی اضافه نمی‌کند.

### ورودی‌های دو گوینده

این ورودی‌ها زمانی در دسترس هستند که `mode` برابر `"two_speakers"` باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `audio_encoder_output_2` | خروجی رمزگذار صوتی برای گوینده دوم. هنگام ارائه، `mask_1` و `mask_2` نیز باید ارائه شوند. | AUDIOENCODEROUTPUT | خیر | - |
| `mask_1` | ماسک گوینده اول، در صورت استفاده از دو ورودی صوتی الزامی است. | MASK | خیر | - |
| `mask_2` | ماسک گوینده دوم، در صورت استفاده از دو ورودی صوتی الزامی است. | MASK | خیر | - |

**محدودیت‌های پارامتر:**

- اگر `audio_encoder_output_2` ارائه شود، هر دو `mask_1` و `mask_2` نیز باید ارائه شوند.
- اگر هر دو `mask_1` و `mask_2` ارائه شوند، `audio_encoder_output_2` نیز باید ارائه شود.
- اگر `previous_frames` ارائه شود، باید حداقل به تعداد مشخص‌شده توسط `motion_frame_count` فریم داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `model` | مدل پچ‌شده با شرطی‌سازی صوتی و پوشش‌های نمونه‌برداری اعمال‌شده. | MODEL |
| `positive` | شرطی‌سازی مثبت، که احتمالاً با تصویر شروع یا زمینه دید CLIP اصلاح شده است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی، که احتمالاً با تصویر شروع یا زمینه دید CLIP اصلاح شده است. | CONDITIONING |
| `latent` | تانسور نهفته صفر-مقداردهی‌شده که ویدئوی قرار است تولید شود را نشان می‌دهد. | LATENT |
| `trim_image` | تعداد فریم‌هایی که هنگام ادامه از فریم‌های قبلی باید از ابتدا حذف شوند؛ ۰ هنگام شروع یک سکانس جدید. | INT |
