# WanInfiniteTalkToVideo

WanInfiniteTalkToVideo توالی‌های ویدیویی را از ورودی صوتی تولید می‌کند. این گره از یک مدل انتشار ویدیو استفاده می‌کند که با ویژگی‌های صوتی استخراج‌شده از یک یا دو گوینده شرطی شده است تا بازنمایی نهفته‌ای از یک ویدیوی سرِ سخنگو تولید کند. این گره می‌تواند یک توالی جدید تولید کند یا با استفاده از فریم‌های قبلی برای زمینه حرکتی، توالی موجود را گسترش دهد.

## ورودی‌ها

### ورودی‌های دو گوینده

ورودی‌های این بخش زمانی نمایش داده می‌شوند که `mode` روی `"two_speakers"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `audio_encoder_output_2` | خروجی دوم رمزگذار صوتی حاوی ویژگی‌های گوینده دوم. | AUDIO_ENCODER_OUTPUT | خیر | - |
| `mask_1` | ماسک گوینده اول، در صورت استفاده از دو ورودی صوتی الزامی است. | MASK | خیر | - |
| `mask_2` | ماسک گوینده دوم، در صورت استفاده از دو ورودی صوتی الزامی است. | MASK | خیر | - |

**محدودیت‌های پارامتر:**

- وقتی `mode` روی `"two_speakers"` تنظیم شده باشد، `audio_encoder_output_2`، `mask_1` و `mask_2` برای راه‌اندازی گوینده دوم الزامی هستند.
- اگر `audio_encoder_output_2` ارائه شود، هر دو `mask_1` و `mask_2` نیز باید ارائه شوند.
- اگر هر دو `mask_1` و `mask_2` ارائه شوند، `audio_encoder_output_2` نیز باید ارائه شود.
- اگر `previous_frames` ارائه شود، باید حداقل به تعداد مشخص‌شده توسط `motion_frame_count` فریم داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مدل` | مدل وصله‌شده با شرطی‌سازی صوتی اعمال‌شده. | MODEL |
| `مثبت` | شرطی‌سازی مثبت، که احتمالاً با زمینه اضافی مانند تصویر شروع یا خروجی بینایی CLIP اصلاح شده است. | CONDITIONING |
| `منفی` | شرطی‌سازی منفی، که احتمالاً با زمینه اضافی اصلاح شده است. | CONDITIONING |
| `latent` | توالی ویدیویی تولیدشده در فضای نهفته. | LATENT |
| `تصویر برش‌خورده` | تعداد فریم‌هایی از ابتدای زمینه حرکتی که هنگام گسترش یک توالی باید بریده شوند. زمانی که `previous_frames` ارائه شود برابر با `motion_frame_count` است، در غیر این صورت ۰. | INT |
