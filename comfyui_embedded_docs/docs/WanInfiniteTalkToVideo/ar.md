# WanInfiniteTalkToVideo

```markdown
تُولِّد عقدة WanInfiniteTalkToVideo مقطع فيديو لشخص يتحدث انطلاقًا من الصوت. وهي تُكيِّف نموذج انتشار الفيديو بناءً على ميزات صوتية من متحدث واحد أو اثنين، وتستخدم اختياريًا صورة بداية أو إطارات سابقة كسياق، وتُرجع نموذجًا مُرقَّعًا، وتكييفًا، وفيديو كامنًا لأخذ العينات.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `mode` | وضع الصوت. اختيار `"single_speaker"` يستخدم مدخل صوت واحد. اختيار `"two_speakers"` يضيف مدخلات المتحدث الثاني المدرجة أدناه. | DYNAMIC_COMBO | نعم | `"single_speaker"`<br>`"two_speakers"` |
| `model` | نموذج انتشار الفيديو الأساسي المراد ترقيعه. | MODEL | نعم | - |
| `model_patch` | ترقيع النموذج الذي يحتوي على طبقات إسقاط الصوت. | MODELPATCH | نعم | - |
| `positive` | التكييف الإيجابي المستخدم لتوجيه توليد الفيديو. | CONDITIONING | نعم | - |
| `negative` | التكييف السلبي المستخدم لتوجيه توليد الفيديو. | CONDITIONING | نعم | - |
| `vae` | شبكة التشفير المتغير (VAE) المستخدمة لترميز الصور والإطارات السابقة إلى الفضاء الكامن. | VAE | نعم | - |
| `width` | عرض الفيديو المولَّد بالبكسل، بزيادات قدرها 16. (الافتراضي: 832) | INT | نعم | 16 - MAX_RESOLUTION (step 16) |
| `height` | ارتفاع الفيديو المولَّد بالبكسل، بزيادات قدرها 16. (الافتراضي: 480) | INT | نعم | 16 - MAX_RESOLUTION (step 16) |
| `length` | عدد الإطارات المطلوب توليدها. (الافتراضي: 81) | INT | نعم | 1 - MAX_RESOLUTION (step 4) |
| `audio_encoder_output_1` | مخرج مشفِّر الصوت للمتحدث الأول، ويحتوي على الميزات الصوتية المستخدمة في التكييف. | AUDIOENCODEROUTPUT | نعم | - |
| `start_image` | صورة بداية اختيارية تُستخدم لتهيئة بداية الفيديو. يتم تغيير حجمها إلى `width` و `height`. | IMAGE | لا | - |
| `clip_vision_output` | مخرج رؤية CLIP اختياري يُضاف إلى كل من التكييف الإيجابي والسلبي. | CLIPVISIONOUTPUT | لا | - |
| `motion_frame_count` | عدد الإطارات السابقة المستخدمة كسياق حركة. (الافتراضي: 9) | INT | نعم | 1 - 33 (step 1) |
| `audio_scale` | عامل القياس المطبق على تكييف الصوت. (الافتراضي: 1.0) | FLOAT | نعم | -10.0 - 10.0 (step 0.01) |
| `previous_frames` | إطارات فيديو سابقة اختيارية تُستخدم لتمديد تسلسل موجود. تستخدم العقدة آخر `motion_frame_count` من الإطارات كسياق حركة. | IMAGE | لا | - |

### مدخلات المتحدث الفردي

اختيار `single_speaker` لا يضيف أي مدخلات إضافية.

### مدخلات متحدثين اثنين

تتوفر هذه المدخلات عندما يكون `mode` هو `"two_speakers"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `audio_encoder_output_2` | مخرج مشفِّر الصوت للمتحدث الثاني. عند توفيره، يجب أيضًا توفير `mask_1` و `mask_2`. | AUDIOENCODEROUTPUT | لا | - |
| `mask_1` | قناع للمتحدث الأول، مطلوب إذا تم استخدام مدخلي صوت. | MASK | لا | - |
| `mask_2` | قناع للمتحدث الثاني، مطلوب إذا تم استخدام مدخلي صوت. | MASK | لا | - |

**قيود المعاملات:**

- إذا تم توفير `audio_encoder_output_2`، فيجب أيضًا توفير كل من `mask_1` و `mask_2`.
- إذا تم توفير كل من `mask_1` و `mask_2`، فيجب أيضًا توفير `audio_encoder_output_2`.
- إذا تم توفير `previous_frames`، فيجب أن يحتوي على عدد إطارات لا يقل عن العدد المحدد بواسطة `motion_frame_count`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج المُرقَّع المطبق عليه تكييف الصوت وأغلفة أخذ العينات. | MODEL |
| `positive` | التكييف الإيجابي، الذي قد يكون معدَّلًا بسياق صورة البداية أو رؤية CLIP. | CONDITIONING |
| `negative` | التكييف السلبي، الذي قد يكون معدَّلًا بسياق صورة البداية أو رؤية CLIP. | CONDITIONING |
| `latent` | موتر كامن مُهيأ بقيم صفرية يمثل الفيديو الذي سيتم توليده. | LATENT |
| `trim_image` | عدد الإطارات المطلوب قصها من البداية عند التمديد من إطارات سابقة؛ ويساوي 0 عند بدء تسلسل جديد. | INT |
```
