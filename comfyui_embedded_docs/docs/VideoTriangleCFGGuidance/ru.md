# Направление Video Triangle CFG

Узел VideoTriangleCFGGuidance применяет к видеомодели треугольную схему масштабирования classifier-free guidance (CFG). Он изменяет масштаб кондиционирования с помощью треугольной волны, которая колеблется между `min_cfg` и исходным масштабом кондиционирования модели. Это создаёт динамическую схему управления, которая может помочь улучшить согласованность и качество генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Видеомодель, к которой нужно применить треугольное CFG-управление. | MODEL | Да | - |
| `мин_cfg` | Минимальное значение масштаба CFG для треугольной схемы. Этот параметр отображается в расширенном разделе интерфейса узла (по умолчанию: 1.0). | FLOAT | Да | 0.0 - 100.0 (step: 0.5, round: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым треугольным CFG-управлением. | MODEL |
