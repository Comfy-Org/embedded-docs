# Направление Video Triangle CFG

Узел VideoTriangleCFGGuidance применяет треугольный паттерн масштабирования бесклассификаторного направления (CFG) к видеомоделям. Он изменяет масштаб кондиционирования с течением времени, используя треугольную волновую функцию, которая колеблется между минимальным значением CFG и исходным масштабом кондиционирования. Это создает динамический паттерн направления, который может помочь улучшить согласованность и качество генерации видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Видеомодель, к которой применяется треугольное CFG-направление | MODEL | Да | - |
| `min_cfg` | Минимальное значение масштаба CFG для треугольного паттерна (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |

## Выходные параметры

| Имя выходного параметра | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным треугольным CFG-направлением | MODEL |
