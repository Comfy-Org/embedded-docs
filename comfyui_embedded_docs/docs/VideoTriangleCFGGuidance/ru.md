# Направление Video Triangle CFG

Узел VideoTriangleCFGGuidance применяет треугольный шаблон масштабирования бесклассификаторного управления (CFG) к видеомодели. Он изменяет масштаб кондиционирования во времени, используя треугольную волну, которая колеблется между `min_cfg` и исходным масштабом кондиционирования модели. Это создает динамический шаблон управления, который может помочь улучшить согласованность и качество генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Видеомодель, к которой применяется треугольное управление CFG | MODEL | Да | - |
| `мин_cfg` | Минимальное значение масштаба CFG для треугольного шаблона (по умолчанию: 1.0). Этот параметр отображается в расширенном разделе интерфейса узла. | FLOAT | Да | 0.0 - 100.0 (step: 0.5, round: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Измененная модель с примененным треугольным управлением CFG | MODEL |
