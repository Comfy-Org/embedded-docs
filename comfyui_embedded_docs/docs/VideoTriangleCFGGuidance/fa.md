# VideoTriangleCFGGuidance

گره VideoTriangleCFGGuidance یک الگوی مقیاس‌بندی راهنمایی بدون طبقه‌بند مثلثی را بر مدل‌های ویدیویی اعمال می‌کند. این گره مقیاس شرطی‌سازی را در طول زمان با استفاده از یک تابع موج مثلثی که بین حداقل مقدار CFG و مقیاس شرطی‌سازی اصلی نوسان می‌کند، تغییر می‌دهد. این کار یک الگوی راهنمایی پویا ایجاد می‌کند که می‌تواند به بهبود سازگاری و کیفیت تولید ویدیو کمک کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل ویدیویی که راهنمایی CFG مثلثی روی آن اعمال می‌شود | MODEL | بله | - |
| `min_cfg` | حداقل مقدار مقیاس CFG برای الگوی مثلثی (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 100.0 |
