# VideoTriangleCFGGuidance

گره VideoTriangleCFGGuidance یک الگوی مقیاس‌دهی مثلثی برای راهنمایی بدون طبقه‌بند (CFG) روی یک مدل ویدیو اعمال می‌کند. این گره مقیاس شرطی‌سازی را با استفاده از یک موج مثلثی که بین `min_cfg` و مقیاس شرطی‌سازی اصلی مدل نوسان می‌کند، تغییر می‌دهد. این کار یک الگوی راهنمایی پویا ایجاد می‌کند که می‌تواند به بهبود سازگاری و کیفیت تولید ویدیو کمک کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل ویدیویی که راهنمایی CFG مثلثی روی آن اعمال می‌شود. | MODEL | بله | - |
| `min_cfg` | حداقل مقدار مقیاس CFG برای الگوی مثلثی. این پارامتر در بخش پیشرفته رابط گره نمایش داده می‌شود (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 100.0 (گام: 0.5، گرد کردن: 0.01) |
