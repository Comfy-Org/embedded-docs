# پرو لباس مجازی Flux

این گره با پوشاندن لباسِ موجود در تصویر لباس ارائه‌شده به یک شخص، پرو مجازی انجام می‌دهد. تصاویر شخص و لباس را به سرویس BFL Flux VTO می‌فرستد؛ این سرویس تصویری واقع‌گرایانه از شخصی تولید می‌کند که آن لباس را پوشیده است. یک دستور متنی اختیاری می‌تواند نحوه تناسب یا ظاهر لباس را توصیف کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `person` | تصویر شخصی که باید لباس به او پوشانده شود. | IMAGE | بله | - |
| `garment` | تصویر لباسی که باید اعمال شود. | IMAGE | بله | - |
| `prompt` | دستور سبک‌دهی اختیاری به زبان طبیعی (مثلاً اینکه لباس چگونه باید اندازه/فرم داشته باشد). پیش‌فرض یک رشته خالی است. | STRING | خیر | - |
| `seed` | بذر تصادفی مورد استفاده برای ایجاد نویز. پیش‌فرض: 0. | INT | خیر | 0 تا 18446744073709551615 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر حاصل که شخص را با لباس ارائه‌شده نشان می‌دهد. | IMAGE |
