# پرو لباس مجازی Flux

این گره پروی مجازی را با پوشاندن لباس موجود در تصویر ارائه‌شده بر تن شخص انجام می‌دهد. این گره از BFL Flux VTO API برای تولید تصویری واقع‌گرایانه از شخص در حال پوشیدن لباس مشخص‌شده استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `person` | تصویر شخصی که قرار است لباس بر تن او پوشانده شود. | IMAGE | بله | - |
| `garment` | تصویر لباسی که قرار است اعمال شود. | IMAGE | بله | - |
| `prompt` | دستورالعمل اختیاری استایل‌دهی به زبان طبیعی (مثلاً نحوه‌ی فیت شدن لباس). (پیش‌فرض: خالی) | STRING | خیر | - |
| `seed` | مقدار seed تصادفی که برای ایجاد نویز استفاده می‌شود. (پیش‌فرض: 0) | INT | خیر | 0 تا 18446744073709551615 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر حاصل که شخص را در حال پوشیدن لباس ارائه‌شده نشان می‌دهد. | IMAGE |
