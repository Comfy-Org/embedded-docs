# Flux Virtual Try-On

צומת זה מבצע הלבשה וירטואלית (virtual try-on) על ידי הלבשת אדם בתמונת בגד שסופקה. הוא שולח את תמונות האדם והבגד לשירות BFL Flux VTO, אשר מייצר תמונה מציאותית של האדם הלובש את הבגד. ניתן להוסיף הנחיית טקסט אופציונלית כדי לתאר כיצד הבגד אמור להתאים או להיראות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `person` | תמונה של האדם שעליו להלביש. | IMAGE | כן | - |
| `garment` | תמונה של הבגד להחלה. | IMAGE | כן | - |
| `prompt` | הנחיית סטיילינג אופציונלית בשפה טבעית (למשל, כיצד הבגד אמור להתאים). ברירת המחדל היא מחרוזת ריקה. | STRING | לא | - |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. ברירת מחדל: 0. | INT | לא | 0 עד 18446744073709551615 |
