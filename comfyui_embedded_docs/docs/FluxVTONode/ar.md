# Flux تجربة الملابس الافتراضية

تنفذ هذه العقدة تجربة افتراضية للملابس عبر إلباس شخص صورة ملابس مقدمة. وتُرسل صور الشخص والملابس إلى خدمة BFL Flux VTO، التي تولّد صورة واقعية للشخص وهو يرتدي الملابس. ويمكن لتعليمة نصية اختيارية أن تصف كيف ينبغي أن تكون ملاءمة الملابس أو مظهرها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `person` | صورة الشخص المراد إلباسه. | IMAGE | نعم | - |
| `garment` | صورة الملابس المراد تطبيقها. | IMAGE | نعم | - |
| `prompt` | تعليمة اختيارية باللغة الطبيعية لتحديد المظهر (مثل كيفية ملاءمة الملابس). القيمة الافتراضية هي سلسلة نصية فارغة. | STRING | لا | - |
| `seed` | البذرة العشوائية المستخدمة لإنشاء الضوضاء. الافتراضي: 0. | INT | لا | 0 إلى 18446744073709551615 |

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة الناتجة التي تُظهر الشخص وهو يرتدي الملابس المقدمة. | IMAGE |
