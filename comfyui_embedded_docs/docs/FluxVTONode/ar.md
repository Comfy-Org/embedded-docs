# Flux تجربة الملابس الافتراضية

تقوم هذه العقدة بإجراء تجربة ارتداء افتراضية من خلال إلباس الشخص صورة قطعة ملابس مقدمة. وتستخدم واجهة برمجة التطبيقات BFL Flux VTO لإنشاء صورة واقعية للشخص وهو يرتدي قطعة الملابس المحددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الشخص` | صورة الشخص الذي سيتم إلباسه. | IMAGE | نعم | - |
| `الملابس` | صورة قطعة الملابس المراد تطبيقها. | IMAGE | نعم | - |
| `التعليمات` | تعليمات تنسيق اختيارية بلغة طبيعية (مثل كيفية ملاءمة الملابس). (الافتراضي: فارغ) | STRING | لا | - |
| `البذرة` | البذرة العشوائية المستخدمة لإنشاء الضوضاء. (الافتراضي: 0) | INT | لا | 0 إلى 18446744073709551615 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة الناتجة التي تظهر الشخص وهو يرتدي قطعة الملابس المقدمة. | IMAGE |
