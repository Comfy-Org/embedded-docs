# Flux Виртуальная примерка

Этот узел выполняет виртуальную примерку, надевая на человека одежду с предоставленного изображения. Он использует BFL Flux VTO API для создания реалистичного изображения человека в указанной одежде.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `person` | Изображение человека, которого нужно одеть. | IMAGE | Да | - |
| `garment` | Изображение одежды, которую нужно применить. | IMAGE | Да | - |
| `prompt` | Необязательная инструкция по стилю на естественном языке (например, как одежда должна сидеть). (по умолчанию: пусто) | STRING | Нет | - |
| `seed` | Случайное зерно, используемое для создания шума. (по умолчанию: 0) | INT | Нет | 0 до 18446744073709551615 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Результирующее изображение, показывающее человека в предоставленной одежде. | IMAGE |
