# Tripo: بافت‌دهی مدل (قدیمی)

گره Tripo: Texture model (Legacy) از طریق API Tripo به یک مدل سه‌بعدی Tripo موجود بافت اضافه می‌کند. شناسه وظیفه (task ID) مدلی را که توسط گره دیگری Tripo ساخته شده است می‌گیرد و پس از پایان یافتن کار بافت‌دهی، یک مدل GLB یا FBX بافت‌دار برمی‌گرداند. می‌توانید نقشه‌های متریال، کیفیت بافت، هم‌ترازی و seed را کنترل کنید و بافت‌ها را با یک prompt متنی، یک تصویر سبک یا تصاویر مرجع هدایت کنید. این گره نسخه‌ای قدیمی (legacy) از ابزار بافت‌دهی است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `شناسه وظیفه مدل` | شناسه وظیفه Tripo برای مدلی که باید بافت‌دهی شود. شناسه‌های وظیفه مدل و شناسه‌های وظیفه بخش‌بندی را می‌پذیرد. | MODEL_TASK_ID, SEGMENT_TASK_ID | بله | - |
| `بافت` | نادیده گرفته می‌شود: این گره همیشه بافت تولید می‌کند. برای گردش‌کارهای قدیمی‌تر نگه داشته شده است. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، فلزی، زبری، نرمال)؛ خاموش بودن آن یک بافت رنگ ساده می‌دهد. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `بذر بافت` | seed تصادفی برای تولید بافت. (پیش‌فرض: 42) | INT | خیر | 0 – 2147483647 |
| `کیفیت بافت` | کیفیت وضوح بافت: detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra. (پیش‌فرض: "standard"). هزینه تقریبی: standard $0.10، detailed $0.20، extreme $0.30. | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `تراز بافت` | روشی که برای هم‌ترازی بافت‌های تولیدشده با مدل استفاده می‌شود. (پیش‌فرض: "original_image") | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های واردشده (Tripo: Import Model) که هیچ تصویر مبدأی برای استنتاج رنگ‌ها ندارند الزامی است. نمی‌توان آن را با تصاویر مرجع ترکیب کرد. (پیش‌فرض: "") | STRING | خیر | - |
| `model_version` | مدل بافت: v3.0 برای مش‌های تولیدشده با v3.x، v2.5 برای مش‌های تولیدشده با v2.5. (پیش‌فرض: v3.0_20250812) | COMBO | خیر | گزینه‌های متعدد موجود است |
| `style_image` | تصویر مرجع برای سبک هنری بافت‌ها. فقط همراه با `texture_prompt` استفاده می‌شود. | IMAGE | خیر | - |
| `reference` | تصاویر مرجع که بافت‌ها را هدایت می‌کنند. نمی‌توان آن را با `texture_prompt` یا `style_image` ترکیب کرد. (پیش‌فرض: "none") | DYNAMIC_COMBO | خیر | "none"<br>"image"<br>"multiview" |
| `part_names` | نام‌های بخش جداشده با کاما از Tripo: Segment Model برای بافت‌دهی. اگر خالی باشد همه بخش‌ها بافت‌دهی می‌شوند. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع `image`

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"image"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | تصویر مرجع واحدی که بافت‌ها باید از آن پیروی کنند. | IMAGE | بله | - |

### ورودی‌های مرجع `multiview`

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"multiview"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image_front` | نمای جلو (۰°). | IMAGE | بله | - |
| `image_left` | نمای چپ (۹۰°). | IMAGE | بله | - |
| `image_back` | نمای پشت (۱۸۰°). | IMAGE | بله | - |
| `image_right` | نمای راست (۲۷۰°). | IMAGE | بله | - |

**توجه:** حالت‌های مرجع `"image"` و `"multiview"` نمی‌توانند با `texture_prompt` غیرخالی یا با `style_image` ترکیب شوند. ورودی `style_image` به یک `texture_prompt` غیرخالی نیاز دارد. وقتی `texture_prompt` خالی بماند، مدل مبدأ باید از قبل تصویر مبدأ خودش را داشته باشد (برای مثال، مدل‌های تولیدشده توسط text-to-model، image-to-model، multiview-to-model، یا یک وظیفه بافت‌دهی قبلی). مدل‌هایی که تصویر مبدأ ندارند — مانند مدل‌های واردشده، بخش‌بندی‌شده، تکمیل‌شده یا بازتوپولوژی‌شده — باید با یک `texture_prompt` بافت‌دهی شوند؛ تصاویر مرجع فقط برای مدل‌هایی پذیرفته می‌شوند که خود API Tripo آن‌ها را تولید کرده است. ورودی `part_names` را می‌توان خالی گذاشت تا همه بخش‌ها بافت‌دهی شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | فایل مدل تولیدشده (فقط برای سازگاری با نسخه‌های قبلی). | STRING |
| `model task_id` | شناسه وظیفه کار تکمیل‌شده تولید بافت، قابل استفاده به‌عنوان ورودی برای سایر گره‌های Tripo. | MODEL_TASK_ID |
| `GLB` | مدل بافت‌دار تولیدشده در قالب GLB. وقتی مبدأ یک مش چهارضلعی (quad) یا یک واردات FBX باشد خالی است. | FILE3DGLB |
| `FBX` | مدل بافت‌دار تولیدشده در قالب FBX. Tripo برای مش‌های چهارضلعی و واردات‌های FBX، FBX برمی‌گرداند؛ در غیر این صورت خالی است. | FILE3DFBX |
