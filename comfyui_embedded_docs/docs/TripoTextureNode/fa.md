# Tripo: مدل بافت

گره TripoTextureNode با استفاده از API تریپو (Tripo) مدل‌های سه‌بعدی بافت‌دار تولید می‌کند. این گره یک شناسه وظیفه مدل دریافت کرده و تولید بافت را با گزینه‌های مختلف شامل متریال‌های PBR، تنظیمات کیفیت بافت، روش‌های ترازبندی و راهنمای متنی اختیاری اعمال می‌کند. گره برای پردازش درخواست تولید بافت با API تریپو ارتباط برقرار کرده و در نهایت فایل مدل و شناسه وظیفه حاصل را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدلی که قرار است روی آن بافت اعمال شود | MODEL_TASK_ID | بله | - |
| `texture` | آیا بافت تولید شود (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `pbr` | آیا متریال‌های PBR (رندر مبتنی بر فیزیک) تولید شود (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `texture_seed` | دانه تصادفی برای تولید بافت (پیش‌فرض: 42) | INT | خیر | - |
| `texture_quality` | سطح کیفیت تولید بافت (پیش‌فرض: "standard"). گزینه "detailed" معادل 0.20 دلار آمریکا و گزینه "standard" معادل 0.10 دلار آمریکا هزینه دارد. | COMBO | خیر | "standard"<br>"detailed" |
| `texture_alignment` | روش ترازبندی بافت‌ها (پیش‌فرض: "original_image"). گزینه "original_image" بافت‌ها را با تصویر ورودی اصلی تراز می‌کند، در حالی که گزینه "geometry" آن‌ها را با هندسه سه‌بعدی تراز می‌کند. | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های وارداتی (Tripo: Import Model) که هیچ تصویر منبعی برای استنتاج رنگ ندارند، الزامی است. (جعبه متن چندخطی، پیش‌فرض: رشته خالی) | STRING | خیر | - |

*توجه: این گره به توکن‌های احراز هویت و کلیدهای API نیاز دارد که به‌صورت خودکار توسط سیستم مدیریت می‌شوند.*

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | فایل مدل تولیدشده با بافت‌های اعمال‌شده (فقط برای سازگاری عقب‌گرد) | STRING |
| `model task_id` | شناسه وظیفه برای پیگیری فرآیند تولید بافت | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB با بافت‌های اعمال‌شده | FILE3DGLB |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TripoTextureNode/fa.md)
