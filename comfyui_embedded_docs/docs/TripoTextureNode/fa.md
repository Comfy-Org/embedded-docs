# Tripo: مدل بافت

گره TripoTextureNode مدل‌های سه‌بعدی بافت‌دار را با استفاده از Tripo API تولید می‌کند. این گره یک شناسه وظیفه مدل را دریافت می‌کند و با گزینه‌های مختلف از جمله مواد PBR، تنظیمات کیفیت بافت و روش‌های ترازبندی، تولید بافت را اعمال می‌کند. این گره با Tripo API ارتباط برقرار می‌کند تا درخواست تولید بافت را پردازش کند و فایل مدل حاصل و شناسه وظیفه را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `شناسه وظیفه مدل` | شناسه وظیفه مدلی که باید روی آن بافت اعمال شود | MODEL_TASK_ID | بله | - |
| `بافت` | آیا بافت‌ها تولید شوند (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `PBR` | آیا مواد PBR (رندر بر پایه فیزیک) تولید شوند (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `بذر بافت` | دانه تصادفی برای تولید بافت (پیش‌فرض: 42) | INT | خیر | - |
| `کیفیت بافت` | سطح کیفیت برای تولید بافت (پیش‌فرض: "standard"). گزینه "detailed" 0.20 دلار آمریکا هزینه دارد، در حالی که "standard" 0.10 دلار آمریکا هزینه دارد. | COMBO | خیر | "standard"<br>"detailed" |
| `تراز بافت` | روش ترازبندی بافت‌ها (پیش‌فرض: "original_image"). گزینه "original_image" بافت‌ها را با تصویر ورودی اصلی تراز می‌کند، در حالی که "geometry" آن‌ها را با هندسه سه‌بعدی تراز می‌کند. | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های وارداتی (Tripo: Import Model) که تصویر منبعی برای استنتاج رنگ‌ها ندارند، ضروری است. (پیش‌فرض: "") | STRING | خیر | - |

*توجه: این گره به توکن‌های احراز هویت و کلیدهای API نیاز دارد که به‌طور خودکار توسط سیستم مدیریت می‌شوند.*

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل تولیدشده با بافت‌های اعمال‌شده (فقط برای سازگاری با نسخه‌های قبلی) | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه برای پیگیری فرآیند تولید بافت | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB با بافت‌های اعمال‌شده | FILE3DGLB |
