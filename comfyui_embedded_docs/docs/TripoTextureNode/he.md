# TripoTextureNode

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | מזהה המשימה (task ID) של Tripo עבור המודל שעבורו יש ליצור טקסטורות. מקבל מזהי משימות של מודלים ומזהי משימות של סגמנטציה. | MODEL_TASK_ID, SEGMENT_TASK_ID | כן | - |
| `texture` | מתעלמים ממנו: צומת זה תמיד יוצר טקסטורות. נשמר עבור תהליכי עבודה ישנים. (ברירת מחדל: True) | BOOLEAN | לא | true<br>false |
| `pbr` | מפות חומר PBR (צבע בסיס, מטאלי, חספוס, נורמל); כיבוי מפיק טקסטורת צבע אחיד. (ברירת מחדל: True) | BOOLEAN | לא | true<br>false |
| `texture_seed` | זרע אקראי ליצירת הטקסטורה. (ברירת מחדל: 42) | INT | לא | 0 – 2147483647 |
| `texture_quality` | איכות רזולוציית הטקסטורה: detailed = טקסטורות HD, extreme = טקסטורות 8K Ultra. (ברירת מחדל: "standard"). עלות משוערת: standard $0.10, detailed $0.20, extreme $0.30. | COMBO | לא | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | השיטה שבה מיושרות הטקסטורות שנוצרו למודל. (ברירת מחדל: "original_image") | COMBO | לא | "original_image"<br>"geometry" |
| `texture_prompt` | הנחיית טקסט אופציונלית ליצירת טקסטורות. נדרשת בפועל עבור מודלים מיובאים (Tripo: Import Model), אשר אינם נושאים תמונת מקור שממנה ניתן להסיק צבעים. לא ניתן לשלב עם תמונות עזר. (ברירת מחדל: "") | STRING | לא | - |
| `model_version` | מודל הטקסטורה: v3.0 עבור משים (meshes) שנוצרו עם v3.x, v2.5 עבור משים שנוצרו עם v2.5. (ברירת מחדל: v3.0_20250812) | COMBO | לא | אפשרויות מרובות זמינות |
| `style_image` | תמונת עזר עבור הסגנון האמנותי של הטקסטורות. משמשת רק יחד עם `texture_prompt`. | IMAGE | לא | - |
| `reference` | תמונות עזר שמנחות את הטקסטורות. לא ניתן לשלב עם `texture_prompt` או `style_image`. (ברירת מחדל: "none") | DYNAMIC_COMBO | לא | "none"<br>"image"<br>"multiview" |
| `part_names` | שמות חלקים מופרדים בפסיקים מתוך Tripo: Segment Model שעבורם יש ליצור טקסטורות. ריק יוצר טקסטורות עבור כל חלק. (ברירת מחדל: "") | STRING | לא | - |

### קלטי עזר של `image`

קלטים אלה זמינים כאשר `reference` מוגדר ל-`"image"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | תמונת עזר בודדת שהטקסטורות צריכות לפעול לפיה. | IMAGE | כן | - |

### קלטי עזר של `multiview`

קלטים אלה זמינים כאשר `reference` מוגדר ל-`"multiview"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image_front` | מבט חזית (0°). | IMAGE | כן | - |
| `image_left` | מבט שמאל (90°). | IMAGE | כן | - |
| `image_back` | מבט אחורי (180°). | IMAGE | כן | - |
| `image_right` | מבט ימין (270°). | IMAGE | כן | - |

**הערה:** לא ניתן לשלב את מצבי העזר `"image"` ו-`"multiview"` עם `texture_prompt` לא ריק או עם `style_image`. הקלט `style_image` דורש `texture_prompt` לא ריק. כאשר `texture_prompt` נשאר ריק, מודל המקור חייב כבר להכיל תמונת מקור משלו (לדוגמה, מודלים שנוצרו על ידי text-to-model, image-to-model, multiview-to-model, או משימת טקסטורה קודמת). מודלים שאינם נושאים תמונת מקור — כגון מודלים מיובאים, שעברו סגמנטציה, שהושלמו או שעברו רטופולוגיה — חייבים לקבל טקסטורות עם `texture_prompt`; תמונות עזר מתקבלות רק עבור מודלים ש-Tripo API עצמו יצר. ניתן להשאיר את הקלט `part_names` ריק כדי ליצור טקסטורות עבור כל חלק.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | קובץ המודל שנוצר (לצורך תאימות לאחור בלבד). | STRING |
| `model task_id` | מזהה המשימה (task ID) של משימת יצירת הטקסטורה שהושלמה, שמיש כקלט עבור צמתי Tripo אחרים. | MODEL_TASK_ID |
| `GLB` | המודל בעל הטקסטורות שנוצר בפורמט GLB. ריק כאשר המקור הוא מש מרובע (quad mesh) או ייבוא FBX. | FILE3DGLB |
| `FBX` | המודל בעל הטקסטורות שנוצר בפורמט FBX. Tripo מחזיר FBX עבור משים מרובעים וייבוא FBX; ריק אחרת. | FILE3DFBX |
