# Tripo: نموذج الملمس

تُنشئ عقدة TripoTextureNode نماذج ثلاثية الأبعاد مزوّدة بالأنسجة باستخدام واجهة برمجة تطبيقات Tripo. تأخذ معرف مهمة النموذج وتطبّق توليد الأنسجة مع خيارات متنوعة تشمل مواد PBR وإعدادات جودة النسيج وطرق المحاذاة. تتواصل العقدة مع واجهة برمجة تطبيقات Tripo لمعالجة طلب توليد النسيج وتُرجع ملف النموذج الناتج ومعرف المهمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `معرف_مهمة_النموذج` | معرف مهمة النموذج الذي سيتم تطبيق الأنسجة عليه | MODEL_TASK_ID | نعم | - |
| `الملمس` | ما إذا كان سيتم توليد الأنسجة (الافتراضي: True) | BOOLEAN | لا | - |
| `PBR` | ما إذا كان سيتم توليد مواد PBR (التصيير المستند إلى الفيزياء) (الافتراضي: True) | BOOLEAN | لا | - |
| `بذرة_الملمس` | البذرة العشوائية لتوليد الأنسجة (الافتراضي: 42) | INT | لا | - |
| `جودة_الملمس` | مستوى الجودة لتوليد الأنسجة (الافتراضي: "standard"). تكلفة خيار "detailed" 0.20 دولار أمريكي، بينما تكلف "standard" 0.10 دولار أمريكي. | COMBO | لا | "standard"<br>"detailed" |
| `محاذاة_الملمس` | طريقة محاذاة الأنسجة (الافتراضي: "original_image"). تقوم "original_image" بمحاذاة الأنسجة مع الصورة الأصلية المدخلة، بينما تقوم "geometry" بمحاذاتها مع الهندسة ثلاثية الأبعاد. | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري للأنسجة. مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model) التي لا تحمل صورة مصدر لاستنتاج الألوان منها. (الافتراضي: "") | STRING | لا | - |

*ملاحظة: تتطلب هذه العقدة رموز مصادقة ومفاتيح API يتم التعامل معها تلقائيًا بواسطة النظام.*

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف النموذج المُنشأ مع الأنسجة المطبقة (للتوافق مع الإصدارات السابقة فقط) | STRING |
| `معرّف مهمة النموذج` | معرف المهمة لتتبع عملية توليد الأنسجة | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُنشأ بتنسيق GLB مع الأنسجة المطبقة | FILE3DGLB |
