# Tripo: إكساء النموذج (قديم)

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `معرف_مهمة_النموذج` | مُعرّف مهمة Tripo الخاص بالنموذج المراد إضافة القوام إليه. يقبل مُعرّفات مهام النماذج ومُعرّفات مهام التقسيم. | MODEL_TASK_ID, SEGMENT_TASK_ID | نعم | - |
| `الملمس` | يتم تجاهله: تُنشئ هذه العقدة القوام دائمًا. مُحتفَظ به للتوافق مع سير العمل الأقدم. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `PBR` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، normal)؛ عند إيقافه يمنح قوامًا بلون موحّد. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `بذرة_الملمس` | بذرة عشوائية لتوليد القوام. (الافتراضي: 42) | INT | لا | 0 – 2147483647 |
| `جودة_الملمس` | جودة دقة القوام: detailed = قوام HD، extreme = قوام 8K فائق الدقة. (الافتراضي: "standard"). التكلفة التقريبية: standard 0.10$، detailed 0.20$، extreme 0.30$. | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `محاذاة_الملمس` | طريقة محاذاة القوام المُولّد مع النموذج. (الافتراضي: "original_image") | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري لإضافة القوام. مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model)، لأنها لا تحمل صورة مصدر لاستنتاج الألوان منها. لا يمكن دمجه مع الصور المرجعية. (الافتراضي: "") | STRING | لا | - |
| `model_version` | نموذج القوام: v3.0 للشبكات المُولّدة بالإصدار v3.x، وv2.5 للشبكات المُولّدة بالإصدار v2.5. (الافتراضي: v3.0_20250812) | COMBO | لا | خيارات متعددة متاحة |
| `style_image` | صورة مرجعية للأسلوب الفني للقوام. تُستخدم فقط مع `texture_prompt`. | IMAGE | لا | - |
| `reference` | الصور المرجعية التي توجّه القوام. لا يمكن دمجها مع `texture_prompt` أو `style_image`. (الافتراضي: "none") | DYNAMIC_COMBO | لا | "none"<br>"image"<br>"multiview" |
| `part_names` | أسماء الأجزاء مفصولة بفواصل من Tripo: Segment Model لإضافة القوام. إذا تُركت فارغة، يُضاف القوام إلى كل جزء. (الافتراضي: "") | STRING | لا | - |

### مدخلات `image` المرجعية

تتوفر هذه المدخلات عندما تكون قيمة `reference` مضبوطة على `"image"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | صورة مرجعية واحدة يجب أن يتبعها القوام. | IMAGE | نعم | - |

### مدخلات `multiview` المرجعية

تتوفر هذه المدخلات عندما تكون قيمة `reference` مضبوطة على `"multiview"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_front` | منظر أمامي (0°). | IMAGE | نعم | - |
| `image_left` | منظر أيسر (90°). | IMAGE | نعم | - |
| `image_back` | منظر خلفي (180°). | IMAGE | نعم | - |
| `image_right` | منظر أيمن (270°). | IMAGE | نعم | - |

**ملاحظة:** لا يمكن دمج وضعي المرجعية `"image"` و`"multiview"` مع `texture_prompt` غير فارغ أو مع `style_image`. يتطلب مدخل `style_image` أن يكون `texture_prompt` غير فارغ. عندما يُترك `texture_prompt` فارغًا، يجب أن يمتلك النموذج المصدر صورة مصدر خاصة به بالفعل (على سبيل المثال، نماذج أنتجتها عمليات text-to-model، أو image-to-model، أو multiview-to-model، أو مهمة إكساء سابقة). أما النماذج التي لا تحمل صورة مصدر — مثل النماذج المستوردة، أو المقسّمة، أو المكتملة، أو المعاد تشكيل طوبولوجيتها — فيجب إكساؤها باستخدام `texture_prompt`؛ ولا تُقبل الصور المرجعية إلا للنماذج التي ولّدتها واجهة Tripo API بنفسها. يمكن ترك مدخل `part_names` فارغًا لإكساء كل جزء.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | ملف النموذج المُولّد (للتوافق مع الإصدارات الأقدم فقط). | STRING |
| `model task_id` | مُعرّف المهمة لمهمة توليد القوام المكتملة، ويمكن استخدامه كمدخل لعُقد Tripo أخرى. | MODEL_TASK_ID |
| `GLB` | النموذج المُكسى المُولّد بصيغة GLB. يكون فارغًا عندما يكون المصدر شبكة quad أو استيراد FBX. | FILE3DGLB |
| `FBX` | النموذج المُكسى المُولّد بصيغة FBX. تُعيد Tripo صيغة FBX لشبكات quad وعمليات استيراد FBX؛ ويكون فارغًا بخلاف ذلك. | FILE3DFBX |
