# Tripo: نموذج الملمس

هذه العقدة `TripoTextureNode` تولّد نماذج ثلاثية الأبعاد مزوّدة بالنسيج باستخدام واجهة برمجة تطبيقات Tripo API. تأخذ معرّف مهمة النموذج وتطبّق عملية توليد النسيج مع خيارات متنوعة تشمل مواد PBR وإعدادات جودة النسيج وطرق المحاذاة وتوجيهًا نصيًا اختياريًا. تتواصل العقدة مع Tripo API لمعالجة طلب توليد النسيج وتُعيد ملف النموذج الناتج ومعرّف المهمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة النموذج الذي سيتم تطبيق النسيج عليه | MODEL_TASK_ID | نعم | - |
| `texture` | ما إذا كان سيتم توليد النسيج (الافتراضي: True) | BOOLEAN | لا | - |
| `pbr` | ما إذا كان سيتم توليد مواد PBR (التصيير المادي) (الافتراضي: True) | BOOLEAN | لا | - |
| `texture_seed` | البذرة العشوائية لتوليد النسيج (الافتراضي: 42) | INT | لا | - |
| `texture_quality` | مستوى جودة توليد النسيج (الافتراضي: "standard"). خيار "detailed" تبلغ تكلفته 0.20 دولارًا أمريكيًا، بينما تبلغ تكلفة "standard" 0.10 دولارًا أمريكيًا. | COMBO | لا | "standard"<br>"detailed" |
| `texture_alignment` | طريقة محاذاة النسيج (الافتراضي: "original_image"). تحاذي "original_image" النسيج مع الصورة الأصلية المدخلة، بينما تحاذيه "geometry" مع الهندسة ثلاثية الأبعاد. | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري لعملية التنسيج. وهو مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model) التي لا تحمل صورة مصدر يمكن استنتاج الألوان منها. (مربع نص متعدد الأسطر، الافتراضي: سلسلة فارغة) | STRING | لا | - |

*ملاحظة: تتطلب هذه العقدة رموز مصادقة ومفاتيح API يتم التعامل معها تلقائيًا بواسطة النظام.*

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | ملف النموذج الناتج مع النسيج المطبّق (لأغراض التوافق العكسي فقط) | STRING |
| `model task_id` | معرّف المهمة لتتبّع عملية توليد النسيج | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد الناتج بصيغة GLB مع النسيج المطبّق | FILE3DGLB |
