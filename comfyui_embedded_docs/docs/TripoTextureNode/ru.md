# Tripo: Модель текстур

Узел TripoTextureNode генерирует текстурированные 3D-модели с использованием Tripo API. Он принимает идентификатор задачи модели и применяет генерацию текстур с различными параметрами, включая материалы PBR, настройки качества текстур и методы выравнивания. Узел взаимодействует с Tripo API для обработки запроса на генерацию текстур и возвращает итоговый файл модели и идентификатор задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Идентификатор задачи модели, к которой нужно применить текстуры | MODEL_TASK_ID | Да | - |
| `texture` | Следует ли генерировать текстуры (по умолчанию: True) | BOOLEAN | Нет | - |
| `pbr` | Следует ли генерировать материалы PBR (физически корректный рендеринг) (по умолчанию: True) | BOOLEAN | Нет | - |
| `texture_seed` | Случайное зерно для генерации текстур (по умолчанию: 42) | INT | Нет | - |
| `texture_quality` | Уровень качества генерации текстур (по умолчанию: "standard"). Опция "detailed" стоит $0.20 USD, а "standard" — $0.10 USD. | COMBO | Нет | "standard"<br>"detailed" |
| `texture_alignment` | Метод выравнивания текстур (по умолчанию: "original_image"). "original_image" выравнивает текстуры по исходному входному изображению, а "geometry" — по 3D-геометрии. | COMBO | Нет | "original_image"<br>"geometry" |
| `texture_prompt` | Необязательное текстовое указание для текстурирования. На практике требуется для импортированных моделей (Tripo: Import Model), у которых нет исходного изображения для определения цветов. (по умолчанию: "") | STRING | Нет | - |

*Примечание: Для работы этого узла требуются токены аутентификации и API-ключи, которые автоматически обрабатываются системой.*

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Сгенерированный файл модели с примененными текстурами (только для обратной совместимости) | STRING |
| `task_id текстуры` | Идентификатор задачи для отслеживания процесса генерации текстур | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB с примененными текстурами | FILE3DGLB |
