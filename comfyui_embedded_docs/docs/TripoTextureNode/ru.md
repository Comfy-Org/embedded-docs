# Tripo: Текстурирование модели (устаревшее)

Этот узел в исходном коде помечен как устаревший (legacy); отображаемое имя — "Tripo: Texture model (Legacy)". Существующие таблицы параметров документации остаются актуальными для текущего исходного кода. Они сохранены, а статус legacy отмечен в обзоре.

Узел Tripo: Texture model (Legacy) добавляет текстуры к существующей 3D-модели Tripo через API Tripo. Он принимает ID задачи модели, созданной другим узлом Tripo, и после завершения задачи текстурирования возвращает текстурированную модель GLB или FBX. Можно управлять картами материалов, качеством текстурирования, выравниванием и seed, а также направлять текстурирование с помощью текстового промпта, изображения стиля или эталонных изображений. Этот узел — устаревшая версия инструмента текстурирования.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи Tripo модели, для которой нужно наложить текстуры. Принимает ID задач модели и ID задач сегментации. | MODEL_TASK_ID, SEGMENT_TASK_ID | Да | - |
| `texture` | Игнорируется: этот узел всегда генерирует текстуры. Сохранён для старых рабочих процессов. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `pbr` | PBR-карты материалов (base color, metallic, roughness, normal); при выключении создаётся обычная цветная текстура. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `texture_seed` | Случайное зерно для генерации текстур. (по умолчанию: 42) | INT | Нет | 0 – 2147483647 |
| `texture_quality` | Качество разрешения текстуры: detailed = HD-текстуры, extreme = 8K Ultra-текстуры. (по умолчанию: "standard"). Примерная стоимость: standard — $0.10, detailed — $0.20, extreme — $0.30. | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Метод выравнивания сгенерированных текстур относительно модели. (по умолчанию: "original_image") | COMBO | Нет | "original_image"<br>"geometry" |
| `texture_prompt` | Необязательное текстовое руководство для текстурирования. На практике обязательно для импортированных моделей (Tripo: Import Model), которые не содержат исходного изображения для определения цветов. Нельзя комбинировать с эталонными изображениями. (по умолчанию: "") | STRING | Нет | - |
| `model_version` | Модель текстурирования: v3.0 для сеток, созданных с v3.x, v2.5 для сеток, созданных с v2.5. (по умолчанию: v3.0_20250812) | COMBO | Нет | Доступно несколько вариантов |
| `style_image` | Эталонное изображение для художественного стиля текстур. Используется только вместе с `texture_prompt`. | IMAGE | Нет | - |
| `reference` | Эталонные изображения, задающие текстуры. Нельзя комбинировать с `texture_prompt` или `style_image`. (по умолчанию: "none") | DYNAMIC_COMBO | Нет | "none"<br>"image"<br>"multiview" |
| `part_names` | Имена частей, разделённые запятыми, из Tripo: Segment Model для текстурирования. Пустое значение — текстурировать каждую часть. (по умолчанию: "") | STRING | Нет | - |

### Эталонные входы `image`

Эти входы доступны, когда для `reference` установлено значение `"image"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | Одно эталонное изображение, которому должны соответствовать текстуры. | IMAGE | Да | - |

### Эталонные входы `multiview`

Эти входы доступны, когда для `reference` установлено значение `"multiview"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_front` | Вид спереди (0°). | IMAGE | Да | - |
| `image_left` | Вид слева (90°). | IMAGE | Да | - |
| `image_back` | Вид сзади (180°). | IMAGE | Да | - |
| `image_right` | Вид справа (270°). | IMAGE | Да | - |

**Примечание:** Режимы эталонных изображений `"image"` и `"multiview"` нельзя комбинировать с непустым `texture_prompt` или с `style_image`. Вход `style_image` требует непустого `texture_prompt`. Если `texture_prompt` оставлен пустым, исходная модель уже должна иметь собственное исходное изображение (например, модели, созданные с помощью text-to-model, image-to-model, multiview-to-model или более ранней задачи текстурирования). Модели без исходного изображения — например, импортированные, сегментированные, завершённые или ретопологизированные — необходимо текстурировать с помощью `texture_prompt`; эталонные изображения принимаются только для моделей, созданных самим API Tripo. Вход `part_names` можно оставить пустым, чтобы текстурировать каждую часть.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Сгенерированный файл модели (только для обратной совместимости). | STRING |
| `model task_id` | ID задачи завершённой задачи генерации текстуры; может использоваться как вход для других узлов Tripo. | MODEL_TASK_ID |
| `GLB` | Сгенерированная текстурированная модель в формате GLB. Пусто, если источник — quad-сетка или импорт FBX. | FILE3DGLB |
| `FBX` | Сгенерированная текстурированная модель в формате FBX. Tripo возвращает FBX для quad-сеток и импорта FBX; в остальных случаях пусто. | FILE3DFBX |
