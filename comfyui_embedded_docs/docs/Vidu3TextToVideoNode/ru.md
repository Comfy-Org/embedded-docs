# Vidu Q3: генерация видео по тексту

Узел Vidu Q3 Text-to-Video Generation создает видео на основе текстового описания. Он использует модель Vidu Q3 Pro или Q3 Turbo для генерации видеоконтента по вашему запросу, позволяя управлять длительностью видео, его разрешением, соотношением сторон и наличием аудиодорожки.

## Входы

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, используемая для генерации видео. Выбор модели открывает дополнительные параметры конфигурации: соотношение сторон, разрешение, длительность и аудио. | DYNAMIC_COMBO | Да | `"viduq3-pro"`<br>`"viduq3-turbo"` |
| `prompt` | Текстовое описание для генерации видео, максимальная длина — 2000 символов. | STRING | Да | N/A |
| `seed` | Значение seed для управления случайностью генерации (по умолчанию: 1). | INT | Да | от 0 до 2147483647 |

### Входы viduq3-pro и viduq3-turbo

Следующие параметры конфигурации являются общими для моделей `viduq3-pro` и `viduq3-turbo`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"3:4"`<br>`"4:3"`<br>`"1:1"` |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"720p"`<br>`"1080p"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | от 1 до 16 |
| `audio` | Если включено, выводит видео со звуком (включая диалоги и звуковые эффекты) (по умолчанию: False). | BOOLEAN | Да | True/False |

**Примечание:** Параметры `aspect_ratio`, `resolution`, `duration` и `audio` обязательны после выбора `model`, так как являются частью его конфигурации. Поле `prompt` не должно быть пустым и не может превышать 2000 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сгенерированный видеофайл. | VIDEO |
