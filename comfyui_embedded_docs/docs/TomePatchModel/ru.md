# Модель патча Tome

TomePatchModel применяет Token Merging (ToMe) к диффузионной модели, чтобы снизить вычислительные затраты при инференсе. Он работает путём объединения похожих токенов внутри механизма внимания модели, поэтому модель обрабатывает меньше токенов, сохраняя качество вывода практически неизменным.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется объединение токенов | MODEL | Да | - |
| `соотношение` | Доля токенов для объединения (по умолчанию: 0.3). Более высокие значения объединяют больше токенов, что может дать большее ускорение, но потенциально снизить качество. | FLOAT | Да | 0.0 - 1.0 |

Примечание: Если количество токенов в блоке внимания достаточно мало и понижающая дискретизация не требуется, функции объединения заменяются на no-op, и модель для этого блока работает без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым объединением токенов | MODEL |
