# Модель патча Tome

Узел TomePatchModel применяет Token Merging (ToMe) к диффузионной модели для снижения вычислительных требований во время инференса. Он работает путем выборочного объединения похожих токенов в механизме внимания, позволяя модели обрабатывать меньше токенов при сохранении качества изображения. Этот метод помогает ускорить генерацию без значительной потери качества.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется объединение токенов | MODEL | Да | - |
| `ratio` | Доля токенов для объединения (по умолчанию: 0.3, шаг: 0.01). Большие значения объединяют больше токенов, что дает большее ускорение, но потенциально снижает качество. | FLOAT | Да | 0.0 - 1.0 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным объединением токенов | MODEL |
