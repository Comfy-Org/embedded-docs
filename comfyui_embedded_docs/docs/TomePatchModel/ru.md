# Модель патча Tome

TomePatchModel применяет Token Merging (ToMe) к диффузионной модели, чтобы снизить вычислительные затраты во время инференса. Метод работает за счёт выборочного объединения похожих токенов в механизме внимания, что позволяет модели обрабатывать меньшее количество токенов, сохраняя при этом качество изображения. Эта техника ускоряет генерацию без значительной потери качества.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется объединение токенов | MODEL | Да | - |
| `соотношение` | Доля токенов для объединения (по умолчанию: 0.3). Более высокие значения объединяют больше токенов, что даёт большее ускорение, но потенциально снижает качество. | FLOAT | Да | 0.0 - 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым объединением токенов | MODEL |
