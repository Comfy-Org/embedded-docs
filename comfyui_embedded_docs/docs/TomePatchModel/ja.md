# トメパッチモデル

The TomePatchModel ノードは、拡散モデルに Token Merging (ToMe) を適用することで、推論時の計算リソースを削減します。このノードは、アテンションメカニズム内で類似したトークンを選択的にマージすることで、画像品質を維持しながらモデルが処理するトークン数を減らします。この技術により、品質を大きく損なうことなく生成を高速化できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | トークンマージを適用する拡散モデル | MODEL | はい | - |
| `ratio` | マージするトークンの比率（デフォルト: 0.3、ステップ: 0.01）。値が大きいほど多くのトークンがマージされ、高速化が向上しますが、品質が低下する可能性があります。 | FLOAT | はい | 0.0 - 1.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | トークンマージが適用された変更済みモデル | MODEL |
