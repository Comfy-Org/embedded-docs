# 토큰 병합(ToMe) 모델 패치

TomePatchModel 노드는 추론 중 계산 요구 사항을 줄이기 위해 확산 모델에 토큰 병합(ToMe)을 적용합니다. 이는 어텐션 메커니즘에서 유사한 토큰을 선택적으로 병합하여 작동하며, 모델이 이미지 품질을 유지하면서 더 적은 토큰을 처리할 수 있게 합니다. 이 기술은 품질 저하를 크게 유발하지 않으면서 생성 속도를 높이는 데 도움이 됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 토큰 병합을 적용할 확산 모델 | MODEL | 예 | - |
| `ratio` | 병합할 토큰의 비율(기본값: 0.3, 단계: 0.01). 값이 높을수록 더 많은 토큰이 병합되어 처리 속도는 증가하지만 품질은 저하될 수 있습니다. | FLOAT | 예 | 0.0 - 1.0 |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `model` | 토큰 병합이 적용된 수정된 모델 | MODEL |
