# پیش‌نمایش نمونه‌گیری TripoSplat

این گره مدل TripoSplat را به‌گونه‌ای اصلاح می‌کند که هنگام استفاده با گره استاندارد KSampler، پیش‌نمایش زنده‌ای از گاوسی اسپلت رمزگشایی‌شده در هر مرحله نمونه‌برداری نمایش داده شود. این کار با پوشش دادن تابع بازخوانی (callback) نمونه‌بردار انجام می‌شود تا خروجی مدل را پس از هر مرحله به تصویر پیش‌نمایش تبدیل کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل TripoSplat که برای پیش‌نمایش زنده اصلاح می‌شود | MODEL | بله | |
| `vae` | رمزگشای VAE مدل TripoSplat | VAE | بله | |
| `سطح octree` | عمق درخت هشت‌تایی (octree) برای رمزگشایی پیش‌نمایش (مقدار کمتر = ارزان‌تر/درشت‌تر). پیش‌فرض: 5 | INT | خیر | 2 تا 8 |
| `تعداد گوسین‌ها` | تعداد گاوسی‌های تولیدشده برای پیش‌نمایش (به مضرب ۳۲ گرد می‌شود). پیش‌فرض: 16384 | INT | خیر | 1024 تا 262144 (گام: 32) |
| `زاویه افقی (yaw)` | چرخش دوربین پیش‌نمایش بر حسب درجه. پیش‌فرض: 90.0 | FLOAT | خیر | -360.0 تا 360.0 (گام: 1.0) |
| `زاویه عمودی (pitch)` | زاویهٔ عمودی دوربین پیش‌نمایش بر حسب درجه. پیش‌فرض: 15.0 | FLOAT | خیر | -89.0 تا 89.0 (گام: 1.0) |
| `اندازه نقطه` | حداکثر شعاع اسپلت بر حسب پیکسل. اندازه هر گاوسی بر اساس مقیاس آن تنظیم و در این مقدار محدود می‌شود؛ مقدار کمتر = ریزتر/نوک‌تیزتر، مقدار بیشتر = درشت‌تر. پیش‌فرض: 3 | INT | خیر | 1 تا 16 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | مدل TripoSplat اصلاح‌شده با قابلیت پیش‌نمایش زنده افزوده‌شده | MODEL |
