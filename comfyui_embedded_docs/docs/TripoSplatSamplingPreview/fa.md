# پیش‌نمایش نمونه‌گیری TripoSplat

این گره یک مدل TripoSplat را به‌گونه‌ای وصله می‌کند که هنگام استفاده با گره استاندارد KSampler، پیش‌نمایش زنده‌ای از گاوسی‌اسپلت کدگشایی‌شده در هر مرحله نمونه‌برداری نمایش داده شود. این کار با پوشاندن تابع بازگشتی (callback) نمونه‌بردار انجام می‌شود تا خروجی مدل پس از هر مرحله به یک تصویر پیش‌نمایش کدگشایی شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل TripoSplat که برای پیش‌نمایش زنده وصله می‌شود | MODEL | بله | |
| `vae` | رمزگشای VAE مدل TripoSplat | VAE | بله | |
| `octree_level` | عمق درخت هشتی (Octree) برای کدگشایی پیش‌نمایش (مقدار کمتر = سریع‌تر/درشت‌تر). پیش‌فرض: 5 | INT | خیر | 2 تا 8 |
| `num_gaussians` | تعداد گاوسی‌های تولیدشده برای پیش‌نمایش (به مضربی از 32 گرد می‌شود). پیش‌فرض: 16384 | INT | خیر | 1024 تا 262144 (گام: 32) |
| `yaw` | زاویه چرخش (yaw) دوربین پیش‌نمایش بر حسب درجه. پیش‌فرض: 90.0 | FLOAT | خیر | -360.0 تا 360.0 (گام: 1.0) |
| `pitch` | زاویه شیب (pitch) دوربین پیش‌نمایش بر حسب درجه. پیش‌فرض: 15.0 | FLOAT | خیر | -89.0 تا 89.0 (گام: 1.0) |
| `point_size` | حداکثر شعاع اسپلت بر حسب پیکسل. هر گاوسی بر اساس مقیاس خود اندازه‌گیری می‌شود و به این مقدار محدود می‌شود؛ مقدار کمتر = ریزتر/نقطه‌ای‌تر، مقدار بیشتر = درشت‌تر. پیش‌فرض: 3 | INT | خیر | 1 تا 16 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | مدل TripoSplat وصله‌شده با قابلیت پیش‌نمایش زنده اضافه‌شده | MODEL |
