# TripoSplat サンプリングプレビュー

このノードは、TripoSplat モデルにパッチを適用し、標準の KSampler ノードで使用すると、各サンプリングステップでデコードされたガウシアンスプラットのライブプレビューが表示されるようにします。これは、サンプラーのコールバックをラップして、毎ステップ後にモデルの出力をプレビュー画像にデコードすることで機能します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ライブプレビュー用にパッチを適用する TripoSplat モデル | MODEL | はい | |
| `vae` | TripoSplat VAE デコーダー | VAE | はい | |
| `octree_level` | プレビューデコード用のオクツリー深度（低いほど軽量/粗くなります）。デフォルト: 5 | INT | いいえ | 2 to 8 |
| `num_gaussians` | プレビュー用に生成するガウシアンの数（32 の倍数に丸められます）。デフォルト: 16384 | INT | いいえ | 1024 to 262144 (step: 32) |
| `yaw` | プレビューカメラのヨー（度）。デフォルト: 90.0 | FLOAT | いいえ | -360.0 to 360.0 (step: 1.0) |
| `pitch` | プレビューカメラのピッチ（度）。デフォルト: 15.0 | FLOAT | いいえ | -89.0 to 89.0 (step: 1.0) |
| `point_size` | スプラットの最大半径（ピクセル）。各ガウシアンはそのスケールからサイズが決められ、ここで上限が設定されます。低いほど細かく/点状になり、高いほど塊状になります。デフォルト: 3 | INT | いいえ | 1 to 16 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MODEL` | ライブプレビュー機能が追加されたパッチ適用済みの TripoSplat モデル | MODEL |
