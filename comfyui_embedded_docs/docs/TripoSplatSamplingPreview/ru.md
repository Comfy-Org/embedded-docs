# TripoSplat Предпросмотр Сэмплирования

Этот узел модифицирует модель TripoSplat так, чтобы при использовании со стандартным узлом KSampler на каждом шаге сэмплирования отображался живой предпросмотр декодированного гауссова сплаттинга. Он работает путем обертки обратного вызова сэмплера для декодирования выходных данных модели в изображение предпросмотра после каждого шага.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель TripoSplat, которую нужно модифицировать для живого предпросмотра | MODEL | Да | |
| `vae` | Декодер VAE TripoSplat | VAE | Да | |
| `octree_level` | Глубина октодерева для декодирования предпросмотра (меньше = дешевле/грубее). По умолчанию: 5 | INT | Нет | 2 до 8 |
| `num_gaussians` | Количество гауссианов для предпросмотра (округляется до числа, кратного 32). По умолчанию: 16384 | INT | Нет | 1024 до 262144 (шаг: 32) |
| `yaw` | Угол рыскания камеры предпросмотра в градусах. По умолчанию: 90.0 | FLOAT | Нет | -360.0 до 360.0 (шаг: 1.0) |
| `pitch` | Угол наклона камеры предпросмотра в градусах. По умолчанию: 15.0 | FLOAT | Нет | -89.0 до 89.0 (шаг: 1.0) |
| `point_size` | Максимальный радиус сплата в пикселях. Каждый гауссиан масштабируется от своего размера и ограничивается этим значением; меньше = тоньше/мельче, больше = крупнее. По умолчанию: 3 | INT | Нет | 1 до 16 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Модифицированная модель TripoSplat с добавленной функцией живого предпросмотра | MODEL |
