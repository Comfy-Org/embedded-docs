# TripoSplat Предпросмотр Сэмплирования

Узел модифицирует модель TripoSplat таким образом, чтобы при использовании со стандартным узлом KSampler на каждом шаге сэмплирования отображался живой предпросмотр декодированного гауссова сплэта. Это достигается за счёт обёртки callback-функции сэмплера: вывод модели декодируется в изображение предпросмотра после каждого шага.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель TripoSplat для модификации с живым предпросмотром | MODEL | Да | |
| `vae` | Декодер VAE TripoSplat | VAE | Да | |
| `octree_level` | Глубина октодерева для декодирования предпросмотра (меньше = дешевле/грубее). По умолчанию: 5 | INT | Нет | 2 до 8 |
| `num_gaussians` | Количество гауссианов для предпросмотра (округляется до кратного 32). По умолчанию: 16384 | INT | Нет | 1024 до 262144 (step: 32) |
| `yaw` | Угол рыскания камеры предпросмотра в градусах. По умолчанию: 90.0 | FLOAT | Нет | -360.0 до 360.0 (step: 1.0) |
| `pitch` | Угол тангажа камеры предпросмотра в градусах. По умолчанию: 15.0 | FLOAT | Нет | -89.0 до 89.0 (step: 1.0) |
| `point_size` | Максимальный радиус сплэта в пикселях. Каждый гауссиан масштабируется от его размера и ограничивается здесь; меньше = тоньше/точечнее, больше = крупнее. По умолчанию: 3 | INT | Нет | 1 до 16 |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `MODEL` | Модифицированная модель TripoSplat с добавленной функциональностью живого предпросмотра | MODEL |
