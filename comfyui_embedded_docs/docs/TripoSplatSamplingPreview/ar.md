# معاينة أخذ عينات TripoSplat

يُعدّل هذا العقد نموذج TripoSplat بحيث عند استخدامه مع عقدة KSampler القياسية، تظهر معاينة مباشرة لعرض gaussian splat المُفكك في كل خطوة من خطوات أخذ العينات. يعمل ذلك عبر تغليف دالة الاستدعاء الخاصة بآخذ العينات لفك ترميز مخرجات النموذج إلى صورة معاينة بعد كل خطوة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | نموذج TripoSplat المراد تعديله للمعاينة المباشرة | MODEL | نعم | |
| `vae` | مفكك ترميز VAE الخاص بـ TripoSplat | VAE | نعم | |
| `مستوى octree` | عمق شجرة Octree لفك ترميز المعاينة (القيمة الأقل = أقل تكلفة/أكثر خشونة). الافتراضي: 5 | INT | لا | 2 إلى 8 |
| `عدد gaussians` | عدد عناصر gaussian لإنتاجها للمعاينة (مقرّبًا إلى مضاعف للعدد 32). الافتراضي: 16384 | INT | لا | 1024 إلى 262144 (step: 32) |
| `زاوية الانحراف` | زاوية الانعراج (yaw) لكاميرا المعاينة بالدرجات. الافتراضي: 90.0 | FLOAT | لا | -360.0 إلى 360.0 (step: 1.0) |
| `زاوية الميل` | زاوية الميل (pitch) لكاميرا المعاينة بالدرجات. الافتراضي: 15.0 | FLOAT | لا | -89.0 إلى 89.0 (step: 1.0) |
| `حجم النقطة` | أقصى نصف قطر للانبثاق (splat) بالبكسل. يُحدَّد حجم كل عنصر gaussian بناءً على مقياسه ويُقيَّد بهذا الحد؛ القيمة الأقل = أدق/أكثر نقطية، والقيمة الأعلى = أكثر تكتلًا. الافتراضي: 3 | INT | لا | 1 إلى 16 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `MODEL` | نموذج TripoSplat المعدّل مع إضافة وظيفة المعاينة المباشرة | MODEL |
