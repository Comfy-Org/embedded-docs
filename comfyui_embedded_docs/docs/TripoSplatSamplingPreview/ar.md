# معاينة أخذ عينات TripoSplat

تقوم هذه العقدة بتعديل نموذج TripoSplat بحيث عند استخدامه مع عقدة KSampler القياسية، يتم عرض معاينة حية لللطخات الغاوسية (Gaussian splats) المُفكِّك ترميزها عند كل خطوة من خطوات أخذ العينات. تعمل عبر تغليف استدعاء المُعيِّن (callback) لفك ترميز مخرجات النموذج إلى صورة معاينة بعد كل خطوة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج TripoSplat المراد تعديله للمعاينة الحية | MODEL | نعم | |
| `vae` | مفكك ترميز VAE الخاص بنموذج TripoSplat | VAE | نعم | |
| `octree_level` | عمق الشجرة الثمانية (Octree) لفك ترميز المعاينة (القيمة الأقل = أرخص وأخشونة). الافتراضي: 5 | INT | لا | 2 إلى 8 |
| `num_gaussians` | عدد اللطخات الغاوسية الناتجة للمعاينة (يُقرَّب إلى مضاعف 32). الافتراضي: 16384 | INT | لا | 1024 إلى 262144 (الخطوة: 32) |
| `yaw` | زاوية الانعراج (Yaw) لكاميرا المعاينة بالدرجات. الافتراضي: 90.0 | FLOAT | لا | -360.0 إلى 360.0 (الخطوة: 1.0) |
| `pitch` | زاوية الميل (Pitch) لكاميرا المعاينة بالدرجات. الافتراضي: 15.0 | FLOAT | لا | -89.0 إلى 89.0 (الخطوة: 1.0) |
| `point_size` | أقصى نصف قطر للطخة بالبكسل. يُحدِّد حجم كل لطخة غاوسية بناءً على مقياسها مع قصّه عند هذا الحد؛ القيمة الأقل = أدق وأكثر نعومة، والقيمة الأعلى = أكثر سمكًا. الافتراضي: 3 | INT | لا | 1 إلى 16 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `MODEL` | نموذج TripoSplat المُعدَّل مع إضافة وظيفة المعاينة الحية إليه | MODEL |
