# TripoSplat 샘플링 미리보기

이 노드는 TripoSplat 모델을 패치하여 표준 KSampler 노드와 함께 사용할 때 각 샘플링 단계마다 디코딩된 가우시안 스플랫의 라이브 미리보기가 표시되도록 합니다. 이는 샘플러의 콜백을 래핑하여 매 단계 후 모델의 출력을 미리보기 이미지로 디코딩하는 방식으로 작동합니다.

## 입력

| 파라미터 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 라이브 미리보기용으로 패치할 TripoSplat 모델입니다. | MODEL | 예 | |
| `vae` | TripoSplat VAE 디코더입니다. | VAE | 예 | |
| `octree_level` | 미리보기 디코딩을 위한 옥트리 깊이입니다. 값이 낮을수록 더 저렴하고 거칠게 표현됩니다. 기본값: 5 | INT | 아니요 | 2 to 8 |
| `num_gaussians` | 미리보기에 생성할 가우시안 수입니다(32의 배수로 반올림됨). 기본값: 16384 | INT | 아니요 | 1024 to 262144 (step: 32) |
| `yaw` | 미리보기 카메라의 요(yaw) 각도(도)입니다. 기본값: 90.0 | FLOAT | 아니요 | -360.0 to 360.0 (step: 1.0) |
| `pitch` | 미리보기 카메라의 피치(pitch) 각도(도)입니다. 기본값: 15.0 | FLOAT | 아니요 | -89.0 to 89.0 (step: 1.0) |
| `point_size` | 픽셀 단위의 최대 스플랫 반경입니다. 각 가우시안은 해당 스케일로 크기가 조정되며 여기서 제한됩니다. 값이 낮을수록 더 미세하고 점처럼 보이며, 높을수록 더 덩어리집니다. 기본값: 3 | INT | 아니요 | 1 to 16 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | 라이브 미리보기 기능이 추가된 패치된 TripoSplat 모델입니다. | MODEL |
