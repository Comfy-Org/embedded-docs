# חיתוך תמונה (מרכז)

הצומת Center Crop Images חותך תמונה ממרכזה לרוחב וגובה מוגדרים. הוא מחשב את האזור המרכזי של תמונת הקלט ומחלץ אזור מלבני במידות שהוגדרו. אם גודל החיתוך המבוקש גדול מהתמונה, החיתוך יוגבל לגבולות התמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט שיש לחתוך. | IMAGE | כן | - |
| `width` | הרוחב של אזור החיתוך (ברירת מחדל: 512). | INT | כן | 1 to 8192 |
| `height` | הגובה של אזור החיתוך (ברירת מחדל: 512). | INT | כן | 1 to 8192 |
