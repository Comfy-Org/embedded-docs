# ConvertStringToComboNode

O nó Convert String to Combo recebe uma string de texto como entrada e a converte em um tipo de dados Combo. Isso permite que você use um valor de texto como uma seleção para outros nós que exigem uma entrada Combo. Ele simplesmente passa o valor da string inalterado, mas altera seu tipo de dados.

## Entradas

| Parâmetro | Descrição | Tipo de Dado | Obrigatório | Intervalo |
| --- | --- | --- | --- | --- |
| `string` | A string de texto a ser convertida em um tipo Combo. | STRING | Sim | N/A |

## Saídas

| Nome da Saída | Descrição | Tipo de Dado |
| --- | --- | --- |
| `output` | A string de entrada, agora formatada como um tipo de dados Combo. | COMBO |
