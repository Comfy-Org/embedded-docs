# ConvertStringToComboNode

Der Node Convert String to Combo nimmt eine Textzeichenfolge als Eingabe und konvertiert sie in einen Combo-Datentyp. Dadurch können Sie einen Textwert als Auswahl für andere Nodes verwenden, die eine Combo-Eingabe erfordern. Der Zeichenfolgenwert wird einfach unverändert weitergegeben, aber sein Datentyp wird geändert.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
| --- | --- | --- | --- | --- |
| `string` | Die Textzeichenfolge, die in einen Combo-Typ konvertiert werden soll. | STRING | Ja | N/A |

## Ausgaben

| Ausgabename | Beschreibung | Datentyp |
| --- | --- | --- |
| `output` | Die Eingabezeichenfolge, jetzt als Combo-Datentyp formatiert. | COMBO |
