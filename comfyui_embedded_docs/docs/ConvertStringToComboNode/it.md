# ConvertStringToComboNode

Il nodo Convert String to Combo accetta una stringa di testo come input e la converte in un tipo di dati Combo. Ciò consente di utilizzare un valore di testo come selezione per altri nodi che richiedono un input Combo. Passa semplicemente il valore stringa senza modifiche, ma ne cambia il tipo di dati.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `string` | La stringa di testo da convertire in un tipo Combo. | STRING | Sì | N/A |

## Output

| Nome output | Descrizione | Tipo di dati |
| --- | --- | --- |
| `output` | La stringa di input, ora formattata come tipo di dati Combo. | COMBO |
