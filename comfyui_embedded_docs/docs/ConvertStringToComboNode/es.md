# ConvertStringToComboNode

El nodo Convert String to Combo toma una cadena de texto como entrada y la convierte en un tipo de datos Combo. Esto le permite utilizar un valor de texto como selección para otros nodos que requieren una entrada Combo. Simplemente pasa el valor de la cadena sin cambios, pero cambia su tipo de datos.

## Entradas

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
| --- | --- | --- | --- | --- |
| `string` | La cadena de texto que se convertirá en un tipo Combo. | STRING | Sí | N/A |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `output` | La cadena de entrada, ahora formateada como un tipo de datos Combo. | COMBO |
