# ConvertStringToComboNode

Le nœud Convert String to Combo prend une chaîne de texte en entrée et la convertit en un type de données Combo. Cela vous permet d'utiliser une valeur texte comme sélection pour d'autres nœuds qui nécessitent une entrée Combo. Il transmet simplement la valeur de chaîne inchangée, mais change son type de données.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `string` | La chaîne de texte à convertir en un type Combo. | STRING | Oui | N/A |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La chaîne d'entrée, désormais formatée comme un type de données Combo. | COMBO |
