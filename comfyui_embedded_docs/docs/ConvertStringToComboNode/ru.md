# ConvertStringToComboNode

Узел Convert String to Combo принимает текстовую строку на входе и преобразует её в тип данных Combo. Это позволяет использовать текстовое значение в качестве выбора для других узлов, которым требуется входной параметр Combo. Узел просто передаёт строковое значение без изменений, но меняет её тип данных.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `string` | Текстовая строка, которую необходимо преобразовать в тип Combo. | STRING | Да | Н/Д |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Входная строка, теперь оформленная как тип данных Combo. | COMBO |
