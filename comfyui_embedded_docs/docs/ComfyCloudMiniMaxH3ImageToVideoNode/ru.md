# Comfy Cloud MiniMax H3: изображение в видео [БЕТА]

Запускает воркфлоу преобразования изображения в видео MiniMax H3 на Comfy Cloud GPU и возвращает видео с соответствующим звуковым сопровождением. Исходное изображение становится первым кадром. Если подать последний кадр клипа обратно на вход, последовательность продолжится, поэтому последовательное выполнение нескольких запусков позволяет создать более длинный фрагмент видео. Это бета-узел, тарифицируемый по секундам использования GPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `первый кадр` | Изображение, с которого начинается видео. Перед запуском воркфлоу оно загружается с размером до 2048x2048 пикселей. | IMAGE | Да | - |
| `запрос` | Текстовое описание движения и звуков, которые должны присутствовать в видеофрагменте. Начальные и конечные пробельные символы удаляются перед отправкой. | STRING | Да | от 1 до 4096 символов |
| `сид` | Случайное зерно, управляющее сгенерированным результатом (по умолчанию: 42). | INT | Да | от 0 до 18446744073709551615 |
| `соотношение сторон` | Соотношение сторон сгенерированного видео (по умолчанию: `"1:1"`). | COMBO | Да | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `разрешение` | Бюджет размера кадра (по умолчанию: `"480p"`). 720p требует примерно вдвое больше GPU-секунд, чем 480p. | COMBO | Да | `"480p"`<br>`"720p"` |
| `длительность в секундах` | Длительность в секундах (по умолчанию: 5). Пайплайн квантует длительность шагами по 17 кадров при 24 кадрах/с, поэтому длительность клипа оказывается в пределах примерно двух третей секунды от этого значения. | INT | Да | от 5 до 15 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуковым сопровождением. | VIDEO |
