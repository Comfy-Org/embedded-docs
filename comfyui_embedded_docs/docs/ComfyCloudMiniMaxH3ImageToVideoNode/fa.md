# Comfy Cloud MiniMax H3 تصویر به ویدئو [BETA]

گردش‌کار تصویر-به-ویدئوی MiniMax H3 را روی یک GPU ابری Comfy اجرا می‌کند و ویدئویی همراه با موسیقی متن هماهنگ برمی‌گرداند. تصویر ثابت به فریم اول تبدیل می‌شود. اگر فریم پایانی یک کلیپ دوباره به ورودی داده شود، دنباله ادامه می‌یابد؛ بنابراین زنجیره‌کردن چند اجرا نمایی طولانی‌تر می‌سازد. این یک گره بتا است و بر اساس ثانیه GPU صورت‌حساب می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `فریم اول` | تصویری که ویدئو از آن شروع می‌شود. پیش از اجرای گردش‌کار، با حداکثر 2048x2048 پیکسل بارگذاری می‌شود. | IMAGE | بله | - |
| `پرامپت` | توضیح متنی حرکت و صداهایی که نما باید همراه داشته باشد. فاصله‌های سفید ابتدا و انتهای متن پیش از ارسال حذف می‌شوند. | STRING | بله | 1 تا 4096 نویسه |
| `بذر` | بذر تصادفی که نتیجه تولیدشده را کنترل می‌کند (پیش‌فرض: 42). | INT | بله | 0 تا 18446744073709551615 |
| `نسبت ابعاد` | نسبت ابعاد ویدئوی تولیدشده (پیش‌فرض: `"1:1"`). | COMBO | بله | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `وضوح` | سقف اندازه فریم (پیش‌فرض: `"480p"`). 720p تقریباً دو برابر 480p ثانیه GPU مصرف می‌کند. | COMBO | بله | `"480p"`<br>`"720p"` |
| `مدت به ثانیه` | طول بر حسب ثانیه (پیش‌فرض: 5). خط لوله به گام‌های 17 فریمی با نرخ 24 فریم بر ثانیه کوانتیزه می‌شود، بنابراین کلیپ با اختلافی حدود دو سوم ثانیه نسبت به این مقدار قرار می‌گیرد. | INT | بله | 5 تا 15 |
