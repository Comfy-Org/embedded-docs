# Comfy Cloud MiniMax H3 תמונה לווידאו [BETA]

מריץ את זרימת העבודה image-to-video של MiniMax H3 על GPU של Comfy Cloud ומחזיר סרטון עם פס קול מתאים. התמונה הדוממת הופכת לפריים הראשון. הזנת פריים הסיום של קליפ בחזרה ממשיכה את הרצף, כך ששרשור של כמה הרצות יוצר שוט ארוך יותר. זהו צומת בטא והוא מחויב לפי שניות GPU.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | התמונה שממנה הסרטון מתחיל. היא מועלית ברזולוציה של עד 2048x2048 פיקסלים לפני הרצת זרימת העבודה. | IMAGE | כן | - |
| `פרומפט` | תיאור טקסטואלי של התנועה והצלילים שהשוט אמור לשאת. רווחים בתחילה ובסוף מוסרים לפני השליחה. | STRING | כן | 1 עד 4096 תווים |
| `seed` | זרע אקראי השולט בתוצאה הנוצרת (ברירת מחדל: 42). | INT | כן | 0 עד 18446744073709551615 |
| `aspect_ratio` | יחס רוחב-גובה של הסרטון הנוצר (ברירת מחדל: `"1:1"`). | COMBO | כן | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `resolution` | תקציב גודל פריים (ברירת מחדל: `"480p"`). 720p עולה בערך פי שניים בשניות GPU לעומת 480p. | COMBO | כן | `"480p"`<br>`"720p"` |
| `duration_seconds` | אורך בשניות (ברירת מחדל: 5). הצינור מכמת לצעדים של 17 פריימים בקצב 24 fps, כך שהקליפ יתקבל בסטייה של כשתי שלישי שנייה מערך זה. | INT | כן | 5 עד 15 |
