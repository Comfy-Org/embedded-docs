# Comfy Cloud MiniMax H3 圖片轉影片 [BETA]

在 Comfy Cloud GPU 上執行 MiniMax H3 圖片轉影片工作流程，並傳回包含相符配樂的影片。靜態影像會成為第一幀。將片段結尾幀再次輸入可延續序列，因此串接多次執行即可建構更長的鏡頭。此為 Beta 節點，依 GPU 秒計費。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `第一影格` | 影片開始的影像。執行工作流程前，會將其上傳至最高 2048x2048 像素。 | IMAGE | 是 | - |
| `提示詞` | 描述鏡頭運動及應包含聲音的文字。提交前會移除開頭與結尾空白。 | STRING | 是 | 1 至 4096 個字元 |
| `種子` | 控制生成結果的隨機種子（預設值：42）。 | INT | 是 | 0 至 18446744073709551615 |
| `長寬比` | 生成影片的長寬比（預設值：`"1:1"`）。 | COMBO | 是 | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `解析度` | 影格尺寸額度（預設值：`"480p"`）。720p 的 GPU 秒成本約為 480p 的兩倍。 | COMBO | 是 | `"480p"`<br>`"720p"` |
