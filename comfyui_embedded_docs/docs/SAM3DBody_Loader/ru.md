# Загрузить модель тела SAM3D

Загружает модель SAM3D Body из файла контрольной точки, хранящегося в папке детектирования, и подготавливает её к использованию для 3D-детекции тела. Узел загружает веса модели, определяет и применяет настройки квантования, если они присутствуют, и оборачивает модель для автоматического управления памятью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|------------|--------------|----------|
| `model_file` | Файл контрольной точки SAM3D Body для загрузки. Файл должен находиться в папке детектирования. | COMBO | Да | Все файлы моделей, доступные в папке детектирования |

Примечание: файл модели должен находиться в папке детектирования. Загрузка завершится ошибкой, если ключи словаря состояния контрольной точки не соответствуют структуре модели SAM3D Body.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|------------|
| `sam3d_body_model` | Загруженная модель SAM3D Body, обёрнутая для автоматического управления памятью между GPU и CPU. Веса детекции рук удалены, поэтому модель специализирована только для детекции тела. | SAM3D_BODY_MODEL |
