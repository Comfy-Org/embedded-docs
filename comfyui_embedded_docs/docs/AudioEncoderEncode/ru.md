# Аудиоэнкодер - Кодирование

Узел AudioEncoderEncode обрабатывает аудиоданные, кодируя их с помощью модели аудиоэнкодера. Он принимает аудиовход и преобразует его в закодированное представление, которое может использоваться для дальнейшей обработки в конвейере кондиционирования. Этот узел преобразует необработанные аудиосигналы в формат, подходящий для приложений машинного обучения, работающих со звуком.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio_encoder` | Модель аудиоэнкодера, используемая для обработки аудиовхода | AUDIO_ENCODER | Да | - |
| `audio` | Аудиоданные, содержащие информацию о форме сигнала и частоте дискретизации | AUDIO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Закодированное аудиопредставление, созданное аудиоэнкодером | AUDIO_ENCODER_OUTPUT |
