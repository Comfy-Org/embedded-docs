# Аудиоэнкодер - Кодирование

Узел AudioEncoderEncode преобразует аудиоданные в закодированное представление с использованием модели аудиокодера. Он принимает аудиокодер и необработанный аудиовход, затем извлекает форму волны и частоту дискретизации из аудио для создания закодированного вывода, пригодного для дальнейшей обработки в конвейере кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `аудио_энкодер` | Модель аудиокодера, используемая для обработки аудиовхода | AUDIO_ENCODER | Да | - |
| `аудио` | Аудиоданные, содержащие информацию о форме волны и частоте дискретизации | AUDIO | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Закодированное аудиопредставление, созданное аудиокодером | AUDIO_ENCODER_OUTPUT |
