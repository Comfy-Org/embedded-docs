# Patina PBR Material Maps

Создаёт набор карт PBR-материала из существующего изображения текстуры: basecolor, normal, roughness, metalness и height. Включайте только нужные карты, так как каждая включённая карта увеличивает затраты. Используйте, чтобы дополнить текстуру, у которой ещё нет карт материала, или чтобы восстановить одну повреждённую карту.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Фотография или рендер, из которых нужно получить PBR-карты. | IMAGE | Да | - |
| `basecolor` | Сгенерировать карту basecolor (альбедо). По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `normal` | Сгенерировать карту normal. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `roughness` | Сгенерировать карту roughness. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `metalness` | Сгенерировать карту metalness. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `height` | Сгенерировать карту height (смещения). По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `seed` | Сид для воспроизводимого шумоподавления. По умолчанию: 42. | INT | Да | 0 до 2147483646 |
| `safety_checker` | Запускать проверку безопасности контента провайдера для запроса. Расширенная настройка. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `auto_downscale` | Автоматически уменьшать входное изображение, если его самая длинная сторона превышает 2048 пикселей (ограничение модели на входное изображение), сохраняя соотношение сторон; изображения меньшего размера остаются как есть. Отключите, чтобы вместо этого возникала ошибка при изображениях превышающего размера. Расширенная настройка. По умолчанию: True. | BOOLEAN | Нет | true<br>false |

**Ограничения и поведение:**

* Хотя бы одна карта должна быть включена, иначе запуск завершится ошибкой.
* Входное изображение ограничено 2048 пикселями по самой длинной стороне; либо позвольте `auto_downscale` уменьшить его, либо запуск завершится ошибкой при изображении превышающего размера.
* Каждая отключённая карта всё равно возвращает выход, но в виде изображения-заглушки 1x1, поэтому подключайте только те выходы, которые вы действительно сгенерировали.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `basecolor` | Сгенерированная карта basecolor (альбедо) или изображение-заглушка 1x1, если эта карта отключена. | IMAGE |
| `normal` | Сгенерированная карта normal или изображение-заглушка 1x1, если эта карта отключена. | IMAGE |
| `roughness` | Сгенерированная карта roughness или изображение-заглушка 1x1, если эта карта отключена. | IMAGE |
| `metalness` | Сгенерированная карта metalness или изображение-заглушка 1x1, если эта карта отключена. | IMAGE |
| `height` | Сгенерированная карта height (смещения) или изображение-заглушка 1x1, если эта карта отключена. | IMAGE |
