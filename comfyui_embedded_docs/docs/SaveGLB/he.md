# SaveGLB

הצומת SaveGLB שומר נתוני Mesh תלת-ממדיים או קלטי קובץ 3D בתיקיית הפלט. הוא מקבל נתוני Mesh ופורמטים נפוצים של קבצי 3D (GLB, GLTF, OBJ, FBX, STL, USDZ, PLY, SPLAT, SPZ, KSPLAT) ומייצא אותם עם קידומת שם הקובץ שצוינה. קלטי Mesh נכתבים כקבצי GLB, אחד לכל פריט באצווה, ואילו קלטי קובץ 3D נשמרים בפורמט המקורי שלהם.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Mesh או קובץ 3D לשמירה | MESH or FILE3D | כן | Mesh data<br>GLB<br>GLTF<br>OBJ<br>FBX<br>STL<br>USDZ<br>PLY<br>SPLAT<br>SPZ<br>KSPLAT<br>Any splat format<br>Any point cloud format<br>Any 3D file format |
| `filename_prefix` | הקידומת עבור שם קובץ הפלט (ברירת מחדל: "3d/ComfyUI"). הקידומת יכולה לכלול נתיב תת-תיקייה, כך שקבצים נשמרים כברירת מחדל תחת תת-התיקייה "3d" של תיקיית הפלט | STRING | לא | - |

הערה: כאשר הקלט `mesh` הוא קובץ 3D, הצומת שומר אותו עם סיומת הפורמט המקורית שלו (נעשה שימוש ב-GLB אם לקובץ אין פורמט). כאשר מדובר בנתוני mesh, כל פריט באצווה נשמר כקובץ `.glb` נפרד; פריטים ריקים (ללא קודקודים או פאות) מדולגים עם אזהרה. שמות קבצי הפלט עוקבים אחר התבנית `{filename_prefix}_{counter:05}_.{ext}` עם מונה שעולה. מטא-נתונים של זרימת עבודה (פרומפט ומידע PNG נוסף) מוטמעים בקבצים הנשמרים כאשר מטא-נתונים מופעלים.
