# حفظ GLB

تقوم عقدة SaveGLB بحفظ بيانات الشبكة ثلاثية الأبعاد أو مدخلات الملفات ثلاثية الأبعاد في دليل الإخراج. تقبل بيانات الشبكة وصيغ الملفات ثلاثية الأبعاد الشائعة (GLB, GLTF, OBJ, FBX, STL, USDZ, PLY, SPLAT, SPZ, KSPLAT) وتصدّرها ببادئة اسم الملف المحددة. تُكتب مدخلات الشبكة كملفات GLB، ملف واحد لكل عنصر في الدفعة، بينما تُحفظ مدخلات الملفات ثلاثية الأبعاد بصيغتها الأصلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الشبكة` | شبكة أو ملف ثلاثي الأبعاد للحفظ | MESH or FILE3D | نعم | Mesh data<br>GLB<br>GLTF<br>OBJ<br>FBX<br>STL<br>USDZ<br>PLY<br>SPLAT<br>SPZ<br>KSPLAT<br>Any splat format<br>Any point cloud format<br>Any 3D file format |
| `بادئة اسم الملف` | بادئة اسم ملف الإخراج (الافتراضي: "3d/ComfyUI"). يمكن أن تتضمن البادئة مسار مجلد فرعي، لذلك تُحفظ الملفات تحت المجلد الفرعي "3d" من دليل الإخراج افتراضيًا | STRING | لا | - |

ملاحظة: عندما يكون مدخل `mesh` ملفًا ثلاثي الأبعاد، تقوم العقدة بحفظه باستخدام امتداد صيغته الأصلية (يُستخدم GLB إذا لم يكن للملف صيغة). عندما تكون بيانات شبكة، يُحفظ كل عنصر في الدفعة كملف `.glb` منفصل؛ ويتم تخطي العناصر الفارغة (بدون رؤوس أو أوجه) مع تحذير. تتبع أسماء ملفات الإخراج النمط `{filename_prefix}_{counter:05}_.{ext}` مع عداد متزايد. تُضمّن بيانات تعريف سير العمل (الموجه ومعلومات PNG الإضافية) في الملفات المحفوظة عند تمكين البيانات التعريفية.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ui` | يعرض الملفات ثلاثية الأبعاد المحفوظة في واجهة المستخدم مع اسم الملف والمجلد الفرعي ومعلومات النوع | UI |
