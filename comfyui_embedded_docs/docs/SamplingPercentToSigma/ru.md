# SamplingPercentToSigma

Узел SamplingPercentToSigma преобразует значение процента сэмплирования в соответствующее значение сигмы, используя параметры сэмплирования модели. Он принимает процентное значение от 0.0 до 1.0 и сопоставляет его с подходящим значением сигмы в графике шума модели, с возможностью возврата либо вычисленной сигмы, либо фактических максимальных/минимальных значений сигмы на границах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, содержащая параметры сэмплирования, используемые для преобразования | MODEL | Да | - |
| `sampling_percent` | Процент сэмплирования для преобразования в сигму (по умолчанию: 0.0) | FLOAT | Да | 0.0 to 1.0 (step: 0.0001) |
| `return_actual_sigma` | Возвращать фактическое значение сигмы вместо значения, используемого для проверок интервалов. Это влияет только на результаты при 0.0 и 1.0. (по умолчанию: False) | BOOLEAN | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigma_value` | Преобразованное значение сигмы, соответствующее входному проценту сэмплирования | FLOAT |
