# SamplingPercentToSigma

Преобразует процент сэмплирования в соответствующее значение sigma с использованием настроек сэмплирования выбранной модели. Он сопоставляет процент в диапазоне от 0.0 до 1.0 с расписанием шума модели и при необходимости может возвращать фактическое максимальное или минимальное значение sigma модели на двух граничных точках.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, содержащая параметры сэмплирования, используемые для преобразования | MODEL | Да | - |
| `процент_дискретизации` | Процент сэмплирования для преобразования в значение sigma (по умолчанию: 0.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.0001) |
| `возвращать_фактическую_сигму` | Возвращать фактическое значение sigma вместо значения, используемого для проверок интервала. Это влияет только на результаты при 0.0 и 1.0. (по умолчанию: False) | BOOLEAN | Да | - |

Когда `return_actual_sigma` включён, `sampling_percent` со значением 0.0 возвращает максимальное значение sigma модели (sigma_max), а `sampling_percent` со значением 1.0 возвращает минимальное значение sigma (sigma_min). Для всех остальных процентов результат одинаков независимо от того, включена эта опция или нет.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigma_value` | Значение sigma, соответствующее входному проценту сэмплирования | FLOAT |
