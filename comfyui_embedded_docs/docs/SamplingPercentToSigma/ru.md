# SamplingPercentToSigma

Узел `SamplingPercentToSigma` преобразует значение процента сэмплинга в соответствующее значение сигмы, используя параметры сэмплинга модели. Он принимает значение процента от 0.0 до 1.0 и сопоставляет его с соответствующим значением сигмы в графике шума модели, с возможностью возврата либо вычисленного значения сигмы, либо фактических максимальных/минимальных значений сигмы на границах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, содержащая параметры сэмплинга, используемые для преобразования | MODEL | Да | - |
| `процент_дискретизации` | Процент сэмплинга для преобразования в сигму (по умолчанию: 0.0) | FLOAT | Да | 0.0–1.0 (шаг: 0.0001) |
| `возвращать_фактическую_сигму` | Возвращать фактическое значение сигмы вместо значения, используемого для проверки интервалов. Это влияет только на результаты при значениях 0.0 и 1.0. (по умолчанию: False) | BOOLEAN | Да | - |

Когда `return_actual_sigma` включён, `sampling_percent` со значением 0.0 возвращает максимальное значение сигмы модели (`sigma_max`), а `sampling_percent` со значением 1.0 возвращает минимальное значение сигмы (`sigma_min`). Для всех остальных процентов результат одинаков независимо от того, включена ли эта опция.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `значение сигмы` | Преобразованное значение сигмы, соответствующее входному проценту сэмплинга | FLOAT |
