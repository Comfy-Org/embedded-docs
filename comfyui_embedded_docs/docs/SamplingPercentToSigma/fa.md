# SamplingPercentToSigma

گره SamplingPercentToSigma یک مقدار درصد نمونه‌برداری را با استفاده از پارامترهای نمونه‌برداری مدل، به مقدار سیگمای متناظر تبدیل می‌کند. این گره یک مقدار درصد بین 0.0 و 1.0 دریافت کرده و آن را به مقدار سیگمای مناسب در برنامه نویز مدل نگاشت می‌کند؛ با گزینه‌هایی برای بازگرداندن یا سیگمای محاسبه‌شده یا مقادیر واقعی حداکثر/حداقل سیگما در مرزها.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که شامل پارامترهای نمونه‌برداری مورد استفاده برای تبدیل است | MODEL | بله | - |
| `sampling_percent` | درصد نمونه‌برداری برای تبدیل به سیگما (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (step: 0.0001) |
| `return_actual_sigma` | مقدار واقعی سیگما را به جای مقدار استفاده‌شده برای بررسی‌های بازه بازگردان. این فقط بر نتایج در 0.0 و 1.0 تأثیر می‌گذارد. (پیش‌فرض: False) | BOOLEAN | بله | - |

هنگامی که گزینه `return_actual_sigma` فعال باشد، `sampling_percent` برابر با 0.0 مقدار حداکثر سیگما (sigma_max) مدل را برمی‌گرداند و `sampling_percent` برابر با 1.0 مقدار حداقل سیگما (sigma_min) را برمی‌گرداند. برای سایر درصدها، نتیجه بدون توجه به فعال بودن یا نبودن این گزینه یکسان است.
