# SamplingPercentToSigma

تبدیل یک درصد نمونه‌گیری به مقدار سیگمای متناظر با استفاده از تنظیمات نمونه‌گیری مدل انتخاب‌شده. این گره یک درصد بین 0.0 و 1.0 را روی زمان‌بندی نویز مدل نگاشت می‌کند و می‌تواند به‌صورت اختیاری مقدار واقعی حداکثر یا حداقل سیگمای مدل را در دو نقطه انتهایی برگرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل حاوی پارامترهای نمونه‌گیری که برای تبدیل استفاده می‌شوند | MODEL | بله | - |
| `sampling_percent` | درصد نمونه‌گیری برای تبدیل به مقدار سیگما (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.0001) |
| `return_actual_sigma` | مقدار واقعی سیگما را به‌جای مقداری که برای بررسی‌های بازه استفاده می‌شود برگردانید. این گزینه فقط بر نتایج در 0.0 و 1.0 تأثیر می‌گذارد. (پیش‌فرض: False) | BOOLEAN | بله | - |

زمانی که `return_actual_sigma` فعال باشد، مقدار `sampling_percent` برابر 0.0 حداکثر مقدار سیگمای مدل (sigma_max) را برمی‌گرداند و مقدار `sampling_percent` برابر 1.0 حداقل مقدار سیگما (sigma_min) را برمی‌گرداند. برای سایر درصدها، نتیجه چه این گزینه فعال باشد و چه غیرفعال، یکسان است.
