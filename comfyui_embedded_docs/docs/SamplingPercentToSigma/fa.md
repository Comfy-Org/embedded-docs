# SamplingPercentToSigma

گره SamplingPercentToSigma یک مقدار درصد نمونه‌برداری را با استفاده از پارامترهای نمونه‌برداری مدل، به مقدار سیگمای متناظر تبدیل می‌کند. این گره یک مقدار درصد بین 0.0 و 1.0 دریافت کرده و آن را به مقدار سیگمای مناسب در برنامه نویز مدل نگاشت می‌کند، با گزینه‌هایی برای بازگرداندن سیگمای محاسبه‌شده یا مقادیر سیگمای حداکثر/حداقل واقعی در مرزها.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که شامل پارامترهای نمونه‌برداری مورد استفاده برای تبدیل است | MODEL | بله | - |
| `sampling_percent` | درصد نمونه‌برداری برای تبدیل به سیگما (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 to 1.0 (step: 0.0001) |
| `return_actual_sigma` | بازگرداندن مقدار سیگمای واقعی به جای مقداری که برای بررسی‌های بازه استفاده می‌شود. این فقط بر نتایج در 0.0 و 1.0 تأثیر می‌گذارد. (پیش‌فرض: False) | BOOLEAN | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `sigma_value` | مقدار سیگمای تبدیل‌شده متناظر با درصد نمونه‌برداری ورودی | FLOAT |
