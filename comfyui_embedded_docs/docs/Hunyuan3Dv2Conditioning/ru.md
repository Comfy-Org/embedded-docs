# Hunyuan3Dv2Conditioning

Узел Hunyuan3Dv2Conditioning обрабатывает выход модели CLIP vision для создания данных кондиционирования для 3D-моделей. Он извлекает эмбеддинги последнего скрытого состояния из выходных данных vision и создает пары положительного и отрицательного кондиционирования. Положительное кондиционирование использует фактические эмбеддинги, тогда как отрицательное кондиционирование использует нулевые эмбеддинги той же формы.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision_output` | Выход модели CLIP vision, содержащий визуальные эмбеддинги | CLIP_VISION_OUTPUT | Да | - |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительные данные кондиционирования, содержащие эмбеддинги CLIP vision | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования, содержащие нулевые эмбеддинги, совпадающие по форме с положительными эмбеддингами | CONDITIONING |
