# Hunyuan3Dv2Conditioning

Узел Hunyuan3Dv2Conditioning обрабатывает выходные данные CLIP vision для генерации данных кондиционирования для 3D-моделей. Он извлекает эмбеддинги последнего скрытого состояния из выходных данных vision и создает пары положительного и отрицательного кондиционирования. Положительное кондиционирование использует фактические эмбеддинги, а отрицательное — нулевые эмбеддинги той же формы.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `выход_clip_vision` | Выход модели CLIP vision, содержащий визуальные эмбеддинги | CLIP_VISION_OUTPUT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительные данные кондиционирования, содержащие эмбеддинги CLIP vision | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования, содержащие нулевые эмбеддинги, соответствующие по форме положительным эмбеддингам | CONDITIONING |
