# Meta Muse Image: Текст в изображение

Meta Muse Image Text to Image генерирует изображения из текстового промпта с использованием модели Muse Image от Meta. Модель размышляет о промпте перед рендерингом и может использовать веб-поиск, поиск изображений и выполнение кода при планировании изображения. Узел вызывает API Muse Image и возвращает полученное изображение или изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. | DYNAMIC_COMBO | Да | `"muse-image-1.0"` |

Выбор модели в списке отображает настройки, поддерживаемые этой моделью. Единственная доступная модель — `muse-image-1.0`; её настройки перечислены ниже.

### Входы muse-image-1.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий изображение. Модель размышляет о промпте и может использовать встроенный веб-поиск и поиск изображений перед рендерингом. | STRING | Да | Многострочный текст, минимум 1 символ |
| `aspect_ratio` | Соотношение сторон выходного изображения. Изображения рендерятся с разрешением около 2,5 мегапикселей (1:1 — 1600x1600, 16:9 — 2048x1152); "auto" позволяет модели выбрать его на основе промпта. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"5:4"`<br>`"4:5"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"`<br>`"2:1"`<br>`"1:2"` |
| `reasoning_strength` | Насколько сильно модель размышляет, планирует и самостоятельно уточняет результат перед рендерингом. | COMBO | Да | `"high"`<br>`"low"` |
| `enable_web_search` | Позволяет модели искать в интернете факты и актуальную информацию при планировании изображения. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `enable_image_search` | Позволяет модели искать эталонные изображения при планировании изображения. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `enable_shell` | Позволяет модели выполнять код во время планирования для точных макетов, графиков и диаграмм; при отключении количественные значения и выравнивание аппроксимируются. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `seed` | Сид определяет, должен ли узел перезапуститься; в API нет сида, поэтому фактические результаты недетерминированы независимо от этого значения. | INT | Да | 0 – 2147483647 (по умолчанию: 42) |

Примечание: Промпт должен содержать как минимум один символ. Когда для `aspect_ratio` установлено значение "auto", в API не отправляется явный размер, и модель определяет размер вывода по промпту. Параметр `seed` только управляет тем, когда узел перезапускается; он не отправляется в API, поэтому сгенерированные результаты недетерминированы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение, возвращённое API, декодируется и предоставляется как пакет изображений. Если ответ API содержит несколько изображений, они объединяются в один пакет. | IMAGE |
