# MetaMuseImageTextToImageApi

Meta Muse Image Text to Image генерирует изображения по текстовому запросу с помощью модели Muse Image от Meta. Модель анализирует запрос перед формированием изображения и может использовать веб-поиск, поиск изображений и выполнение кода при планировании изображения. Узел вызывает API Muse Image и возвращает полученное изображение или изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. | DYNAMIC_COMBO | Да | `"muse-image-1.0"` |

Выбор модели в списке показывает параметры, которые она поддерживает. Доступна только модель `muse-image-1.0`; её параметры перечислены ниже.

### Входы muse-image-1.0

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Запрос, описывающий изображение. Модель анализирует запрос и может использовать встроенные веб-поиск и поиск изображений перед формированием изображения. | STRING | Да | Многострочный текст, минимум 1 символ |
| `aspect_ratio` | Соотношение сторон выходного изображения. Изображения формируются с разрешением около 2,5 мегапикселя (1:1 — 1600x1600, 16:9 — 2048x1152); значение "auto" позволяет модели выбрать его на основе запроса. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"5:4"`<br>`"4:5"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"`<br>`"2:1"`<br>`"1:2"` |
| `reasoning_strength` | Степень размышлений, планирования и самоуточнения модели перед формированием изображения. | COMBO | Да | `"high"`<br>`"low"` |
| `enable_web_search` | Позволяет модели искать в интернете факты и актуальную информацию при планировании изображения. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `enable_image_search` | Позволяет модели искать эталонные изображения при планировании изображения. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `enable_shell` | Позволяет модели выполнять код при планировании для точных макетов, диаграмм и схем; когда выключено, количество и выравнивание вычисляются приблизительно. | BOOLEAN | Нет | True<br>False (по умолчанию: True) |
| `seed` | Сид, определяющий, нужно ли выполнять узел повторно; у API нет сида, поэтому фактические результаты недетерминированы независимо от этого значения. | INT | Да | 0 – 2147483647 (по умолчанию: 42) |

Примечание: запрос должен содержать минимум один символ. Если для `aspect_ratio` задано значение "auto", в API не отправляется явный размер, и модель определяет размер выходного изображения на основе запроса. Параметр `seed` управляет только тем, когда узел будет выполняться повторно; он не отправляется в API, поэтому полученные результаты недетерминированы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение, возвращённое API, декодированное и предоставленное в виде пакетного изображения. Если ответ API содержит несколько изображений, они объединяются в один пакет. | IMAGE |
