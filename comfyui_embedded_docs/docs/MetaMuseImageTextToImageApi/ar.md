# Meta Muse Image: تحويل النص إلى صورة

تقوم عقدة Meta Muse Image Text to Image بإنشاء الصور من موجّه نصي باستخدام نموذج Muse Image من Meta. يقوم النموذج بالاستدلال حول الموجّه قبل العرض، ويمكنه استخدام البحث في الويب، والبحث عن الصور، وتشغيل الكود أثناء التخطيط للصورة. تستدعي العقدة واجهة Muse Image API وتعيد الصورة أو الصور الناتجة.

## المدخلات

### المدخلات العامة

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المراد استخدامه. | DYNAMIC_COMBO | نعم | `"muse-image-1.0"` |

يؤدي تحديد نموذج في القائمة إلى عرض الإعدادات التي يدعمها ذلك النموذج. النموذج الوحيد المتاح هو `muse-image-1.0`؛ وإعداداته مدرجة أدناه.

### مدخلات muse-image-1.0

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجّه يصف الصورة. يُجري النموذج استدلالًا حول الموجّه، وقد يستخدم البحث المدمج في الويب والصور، قبل العرض. | STRING | نعم | نص متعدد الأسطر، بحد أدنى حرف واحد |
| `aspect_ratio` | نسبة أبعاد المخرجات. تُعرض الصور بدقة تبلغ حوالي 2.5 ميجابكسل (1:1 هي 1600x1600، و16:9 هي 2048x1152)؛ يترك "auto" للنموذج الاختيار انطلاقًا من الموجّه. | COMBO | نعم | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"5:4"`<br>`"4:5"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"`<br>`"2:1"`<br>`"1:2"` |
| `reasoning_strength` | مقدار ما يفكر فيه النموذج ويخطط له ويحسّنه ذاتيًا قبل العرض. | COMBO | نعم | `"high"`<br>`"low"` |
| `enable_web_search` | يتيح للنموذج البحث في الويب عن الحقائق والمعلومات الحية أثناء تخطيط الصورة. | BOOLEAN | لا | True<br>False (الافتراضي: True) |
| `enable_image_search` | يتيح للنموذج البحث عن صور مرجعية أثناء تخطيط الصورة. | BOOLEAN | لا | True<br>False (الافتراضي: True) |
| `enable_shell` | يتيح للنموذج تشغيل الكود أثناء التخطيط، من أجل تخطيطات ومخططات ورسوم بيانية دقيقة؛ وعند إيقافه، يتم تقريب الكميات والمحاذاة. | BOOLEAN | لا | True<br>False (الافتراضي: True) |
| `seed` | بذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ لا تحتوي واجهة API على بذرة، لذا تكون النتائج الفعلية غير حتمية بغض النظر عن هذه القيمة. | INT | نعم | 0 – 2147483647 (الافتراضي: 42) |

ملاحظة: يجب أن يحتوي الموجّه على حرف واحد على الأقل. عند ضبط `aspect_ratio` على "auto"، لا يتم إرسال حجم صريح إلى API، ويقرر النموذج حجم المخرجات انطلاقًا من الموجّه. تتحكم معلمة `seed` فقط في وقت إعادة تشغيل العقدة؛ ولا يتم إرسالها إلى API، لذا تكون النتائج المولّدة غير حتمية.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | الصورة المولّدة التي يعيدها API، بعد فك ترميزها وتقديمها كصورة ضمن دفعة. إذا احتوى رد API على عدة صور، يتم دمجها في دفعة واحدة. | IMAGE |
