# تبدیل متن به تصویر Meta Muse Image

Meta Muse Image Text to Image با استفاده از مدل Muse Image شرکت Meta، تصاویری را از یک پرامپت متنی تولید می‌کند. مدل پیش از رندر درباره پرامپت استدلال می‌کند و می‌تواند هنگام برنامه‌ریزی تصویر از جستجوی وب، جستجوی تصویر و اجرای کد استفاده کند. این گره API مدل Muse Image را فراخوانی می‌کند و تصویر یا تصاویر حاصل را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. | DYNAMIC_COMBO | بله | `"muse-image-1.0"` |

انتخاب یک مدل در فهرست، تنظیماتی را نشان می‌دهد که آن مدل پشتیبانی می‌کند. تنها مدل در دسترس `muse-image-1.0` است؛ تنظیمات آن در ادامه فهرست شده است.

### ورودی‌های muse-image-1.0

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که تصویر را توصیف می‌کند. مدل درباره پرامپت استدلال می‌کند و ممکن است پیش از رندر از جستجوی وب و تصویر داخلی خود استفاده کند. | STRING | بله | Multiline text, minimum 1 character |
| `aspect_ratio` | نسبت ابعاد خروجی. تصاویر با حدود 2.5 مگاپیکسل رندر می‌شوند (1:1 برابر 1600x1600 و 16:9 برابر 2048x1152 است)؛ `"auto"` به مدل اجازه می‌دهد آن را از روی پرامپت انتخاب کند. | COMBO | بله | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"5:4"`<br>`"4:5"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"`<br>`"2:1"`<br>`"1:2"` |
| `reasoning_strength` | میزان تفکر، برنامه‌ریزی و خودپالایش مدل پیش از رندر. | COMBO | بله | `"high"`<br>`"low"` |
| `enable_web_search` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی تصویر، برای یافتن واقعیت‌ها و اطلاعات زنده در وب جستجو کند. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `enable_image_search` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی تصویر، تصاویر مرجع را جستجو کند. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `enable_shell` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی برای چیدمان‌های دقیق، نمودارها و دیاگرام‌ها کد اجرا کند؛ در حالت خاموش، کمیت‌ها و تراز به‌صورت تقریبی تعیین می‌شوند. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `seed` | مقدار `seed` برای تعیین اینکه گره باید دوباره اجرا شود؛ API هیچ seedی ندارد، بنابراین نتایج واقعی صرف‌نظر از این مقدار غیرقطعی هستند. | INT | بله | 0 – 2147483647 (پیش‌فرض: 42) |

توجه: پرامپت باید حداقل یک کاراکتر داشته باشد. وقتی `aspect_ratio` روی `"auto"` تنظیم شود، هیچ اندازه صریحی به API فرستاده نمی‌شود و مدل اندازه خروجی را از روی پرامپت تعیین می‌کند. پارامتر `seed` فقط زمان اجرای مجدد گره را کنترل می‌کند؛ به API فرستاده نمی‌شود، بنابراین نتایج تولیدشده غیرقطعی هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر تولیدشده که توسط API بازگردانده شده است، رمزگشایی شده و به‌صورت یک تصویر دسته‌ای ارائه می‌شود. اگر پاسخ API شامل چند تصویر باشد، آن‌ها در یک دسته ترکیب می‌شوند. | IMAGE |
