# MetaMuseImageTextToImageApi

گره **Meta Muse Image Text to Image** با استفاده از مدل Muse Image متا، تصاویری را از یک پرامپت متنی تولید می‌کند. مدل پیش از رندر کردن درباره پرامپت استدلال می‌کند و می‌تواند هنگام برنامه‌ریزی تصویر از جستجوی وب، جستجوی تصویر و اجرای کد استفاده کند. این گره با فراخوانی API مدل Muse Image عمل کرده و تصویر یا تصاویر حاصل را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. | DYNAMIC_COMBO | بله | `"muse-image-1.0"` |

انتخاب یک مدل در فهرست، تنظیمات پشتیبانی‌شدهٔ آن مدل را نمایش می‌دهد. تنها مدل موجود `muse-image-1.0` است؛ تنظیمات آن در زیر فهرست شده است.

### ورودی‌های muse-image-1.0

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که تصویر را توصیف می‌کند. مدل درباره پرامپت استدلال می‌کند و پیش از رندر ممکن است از جستجوی وب و جستجوی تصویر داخلی خود استفاده کند. | STRING | بله | متن چندخطی، حداقل ۱ کاراکتر |
| `aspect_ratio` | نسبت ابعاد خروجی. تصاویر با حدود ۲.۵ مگاپیکسل رندر می‌شوند (۱:۱ معادل 1600x1600، 16:9 معادل 2048x1152)؛ گزینه «auto» به مدل اجازه می‌دهد از روی پرامپت انتخاب کند. | COMBO | بله | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"5:4"`<br>`"4:5"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"`<br>`"2:1"`<br>`"1:2"` |
| `reasoning_strength` | میزان تفکر، برنامه‌ریزی و خوداصلاحی مدل پیش از رندر. | COMBO | بله | `"high"`<br>`"low"` |
| `enable_web_search` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی تصویر، برای دریافت واقعیت‌ها و اطلاعات زنده در وب جستجو کند. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `enable_image_search` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی تصویر، به دنبال تصاویر مرجع بگردد. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `enable_shell` | به مدل اجازه می‌دهد هنگام برنامه‌ریزی، برای چیدمان‌های دقیق، نمودارها و دیاگرام‌ها کد اجرا کند؛ زمانی که خاموش باشد، مقادیر و ترازبندی تقریبی خواهند بود. | BOOLEAN | خیر | True<br>False (پیش‌فرض: True) |
| `seed` | مقدار seed برای تعیین اینکه آیا گره دوباره اجرا شود؛ API دارای seed نیست، بنابراین نتایج واقعی بدون توجه به این مقدار غیرقطعی هستند. | INT | بله | 0 – 2147483647 (پیش‌فرض: 42) |

توجه: پرامپت باید حداقل یک کاراکتر داشته باشد. وقتی `aspect_ratio` روی «auto» تنظیم شود، اندازهٔ صریحی به API ارسال نمی‌شود و مدل اندازهٔ خروجی را از روی پرامپت تعیین می‌کند. پارامتر `seed` فقط زمان اجرای مجدد گره را کنترل می‌کند؛ این پارامتر به API ارسال نمی‌شود، بنابراین نتایج تولیدشده غیرقطعی هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر تولیدشده که توسط API بازگردانده شده است؛ رمزگشایی شده و به‌صورت یک تصویر دسته‌ای (batched image) ارائه می‌شود. اگر پاسخ API شامل چند تصویر باشد، آن‌ها در یک دسته ترکیب می‌شوند. | IMAGE |
