# BriaRestorePhoto

Этот узел восстанавливает старые или повреждённые фотографии через API Bria. Он удаляет зерно, царапины и размытие, нейтрализует возрастные цветовые искажения, может обрезать картонные подложки и студийные рамки, а также перерисовывает лица. Результат повторно рендерится с разрешением около 1 мегапикселя, поэтому он не выравнивается попиксельно с входным изображением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Фотография для восстановления. Альфа-канал отбрасывается перед загрузкой. | IMAGE | Да | - |
| `модерация` | Настройки модерации для запроса. Выбор `"true"` открывает два дополнительных булевых переключателя; выбор `"false"` не отправляет флаги модерации. По умолчанию: `"false"`. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы модерации

Эти входы появляются только когда для `moderation` установлено значение `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию визуального содержимого входного изображения. По умолчанию: false. | BOOLEAN | Нет | true<br>false |
| `visual_output_moderation` | Включает модерацию визуального содержимого выходного изображения. По умолчанию: false. | BOOLEAN | Нет | true<br>false |

**Примечание:** Узел повторно рендерит весь кадр примерно в 1 мегапиксель, поэтому результат не выравнивается попиксельно с входным изображением. Чтобы увеличить изображение, используйте узел Bria Increase Resolution вместо этого узла.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Восстановленная фотография, возвращённая Bria. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
