# BriaRestorePhoto

این گره عکس‌های قدیمی یا آسیب‌دیده را از طریق API شرکت Bria ترمیم می‌کند. دانه‌دانگی، خراش‌ها و تاری را برطرف می‌کند، رنگ‌زدگی‌های ناشی از قدمت را خنثی می‌کند، ممکن است مقوای نگهدارنده و حاشیه‌های استودیویی را برش دهد و چهره‌ها را دوباره ترسیم کند. نتیجه با حدود ۱ مگاپیکسل دوباره رندر می‌شود؛ بنابراین از نظر پیکسلی با ورودی هم‌تراز نیست.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | عکسی که باید ترمیم شود. کانال آلفا پیش از بارگذاری حذف می‌شود. | IMAGE | بله | - |
| `moderation` | تنظیمات بازبینی برای درخواست. انتخاب `"true"` دو کلید بولی افزوده را آشکار می‌کند؛ انتخاب `"false"` هیچ پرچم بازبینی‌ای ارسال نمی‌کند. پیش‌فرض: `"false"`. | DYNAMIC_COMBO | بله | `"false"`<br>`"true"` |

### ورودی‌های بازبینی

این ورودی‌ها فقط زمانی ظاهر می‌شوند که `moderation` روی `"true"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | بازبینی محتوای بصری را برای تصویر ورودی فعال می‌کند. پیش‌فرض: false. | BOOLEAN | خیر | true<br>false |
| `visual_output_moderation` | بازبینی محتوای بصری را برای تصویر خروجی فعال می‌کند. پیش‌فرض: false. | BOOLEAN | خیر | true<br>false |

**توجه:** این گره کل کادر را با حدود ۱ مگاپیکسل دوباره رندر می‌کند، بنابراین نتیجه از نظر پیکسلی با ورودی هم‌تراز نیست. برای بزرگ‌کردن تصویر، به‌جای این گره از گره Bria Increase Resolution استفاده کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | عکس ترمیم‌شده‌ای که Bria برمی‌گرداند. | IMAGE |
| `structured_prompt` | توصیف ساختاریافته تصویر ویرایش‌شده، برای ویرایش بعدی با Bria FIBO Image Edit. | STRING |
