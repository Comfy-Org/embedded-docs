# Flux.2 [pro] Image

یک تصویر با Flux.2 [pro] از طریق API مربوط به BFL بر اساس یک پرامپت و ابعاد خروجی مشخص تولید می‌کند و به‌صورت اختیاری با تصاویر مرجع راهنمایی می‌شود.

**توجه:** این گره در کد منبع به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | پرامپت برای تولید یا ویرایش تصویر. | STRING | بله | - |
| `عرض` | عرض تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 256 تا 2048 (گام 32) |
| `ارتفاع` | ارتفاع تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 256 تا 2048 (گام 32) |
| `بذر` | دانه تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `افزایش وضوح پرامپت` | آیا روی پرامپت نمونه‌برداری افزایشی انجام شود یا خیر. در صورت فعال بودن، پرامپت به‌صورت خودکار برای تولید خلاقانه‌تر تغییر می‌کند (پیش‌فرض: `True`). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True / False |
| `تصاویر` | تصاویر مرجع اختیاری برای تولید تصویر به تصویر. هر تصویر قبل از بارگذاری حداکثر تا 2048x2048 پیکسل کوچک‌سازی می‌شود. | IMAGE | خیر | 0 تا 9 تصویر |

**محدودیت‌ها:**

* اتصال بیش از 9 تصویر مرجع خطا ایجاد می‌کند.
* هزینه اندازه خروجی بر مبنای مگاپیکسل محاسبه می‌شود، بنابراین مقادیر بزرگ‌تر `width` و `height` هزینه بیشتری دارند.
