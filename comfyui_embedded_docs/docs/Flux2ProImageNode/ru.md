# Flux.2 [pro] Image

Генерирует изображение с помощью Flux.2 [pro] через BFL API по промпту и явно заданным размерам выходного изображения, при необходимости с использованием эталонных изображений.

**Примечание:** В исходном коде этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт для генерации или редактирования изображения. | STRING | Да | - |
| `width` | Ширина генерируемого изображения в пикселях (по умолчанию: 1024). | INT | Да | 256 до 2048 (шаг: 32) |
| `height` | Высота генерируемого изображения в пикселях (по умолчанию: 768). | INT | Да | 256 до 2048 (шаг: 32) |
| `seed` | Случайное зерно, используемое для создания шума (по умолчанию: 0). | INT | Да | 0 до 18446744073709551615 |
| `prompt_upsampling` | Выполнять ли апсемплинг промпта. Если включено, промпт автоматически изменяется для более креативной генерации (по умолчанию: `True`). Это расширенная настройка. | BOOLEAN | Да | True / False |
| `images` | Необязательные эталонные изображения для генерации image-to-image. Каждое изображение перед загрузкой уменьшается максимум до 2048x2048 пикселей. | IMAGE | Нет | 0 до 9 изображений |

**Ограничения:**

* Подключение более 9 эталонных изображений вызывает ошибку.
* Выходное изображение тарифицируется за мегапиксель, поэтому большие значения `width` и `height` обходятся дороже.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение. | IMAGE |
