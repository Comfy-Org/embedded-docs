# Flux.2 [pro] صورة

يولّد صورة باستخدام Flux.2 [pro] عبر BFL API انطلاقًا من موجّه وأبعاد مخرجات صريحة، مع إمكانية الاستعانة بصور مرجعية اختياريًا.

**ملاحظة:** هذه العقدة موسومة بأنها مهمَلة في الشيفرة المصدرية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص` | الموجّه المستخدم لتوليد الصورة أو تعديلها. | STRING | نعم | - |
| `العرض` | عرض الصورة المولّدة بالبكسل (القيمة الافتراضية: 1024). | INT | نعم | 256 إلى 2048 (خطوة 32) |
| `الارتفاع` | ارتفاع الصورة المولّدة بالبكسل (القيمة الافتراضية: 768). | INT | نعم | 256 إلى 2048 (خطوة 32) |
| `البذرة` | البذرة العشوائية المستخدمة لإنشاء الضوضاء (القيمة الافتراضية: 0). | INT | نعم | 0 إلى 18446744073709551615 |
| `رفع دقة النص` | ما إذا كان سيتم إجراء رفع العينات على الموجّه. إذا كان مفعّلًا، يُعدَّل الموجّه تلقائيًا لتوليد أكثر إبداعًا (القيمة الافتراضية: `True`). هذا إعداد متقدم. | BOOLEAN | نعم | True / False |
| `الصور` | صور مرجعية اختيارية لتوليد صورة من صورة. تُصغَّر كل صورة إلى 2048x2048 بكسل كحد أقصى قبل الرفع. | IMAGE | لا | 0 إلى 9 صور |

**القيود:**

* توصيل أكثر من 9 صور مرجعية يؤدي إلى حدوث خطأ.
* يُحتسب حجم المخرجات لكل ميغابكسل، لذا فإن قيم `width` و`height` الأكبر تكلّف أكثر.
