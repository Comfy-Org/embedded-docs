# Flux.2 [pro] 圖像

透過 BFL API 使用 Flux.2 [pro] 根據提示詞與明確的輸出尺寸生成圖像，並可選擇以參考圖像作為引導。

**注意：** 此節點在原始碼中標記為已棄用。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於圖像生成或編輯的提示詞。 | STRING | 是 | - |
| `寬度` | 生成圖像的寬度（像素，預設值：1024）。 | INT | 是 | 256 至 2048 （步進值：32） |
| `高度` | 生成圖像的高度（像素，預設值：768）。 | INT | 是 | 256 至 2048 （步進值：32） |
| `隨機種子` | 用於建立雜訊的隨機種子（預設值：0）。 | INT | 是 | 0 至 18446744073709551615 |
| `提示詞升頻` | 是否對提示詞執行上採樣。若啟用，提示詞會自動修改以產生更具創意的生成結果（預設值：`True`）。這是進階設定。 | BOOLEAN | 是 | True / False |
| `參考圖像` | 用於圖像到圖像生成的可選參考圖像。每張圖像在上傳前會縮小至最多 2048x2048 像素。 | IMAGE | 否 | 0 至 9 張圖像 |

**限制：**

* 連接超過 9 張參考圖像會引發錯誤。
* 輸出尺寸按每百萬像素計費，因此較大的 `width` 和 `height` 值費用更高。
