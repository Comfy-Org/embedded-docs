# ИЛИ

Узел Or выполняет операцию логического ИЛИ над набором входных значений. Он возвращает `true`, если любое из предоставленных значений считается истинным в соответствии со стандартными правилами истинности Python.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значения` | Расширяемая коллекция значений для проверки на истинность. Каждый добавленный входной слот именуется `value_1`, `value_2` и так далее. Узел возвращает `true`, если любое из этих значений является истинным. | ANY | Да | 1 или более значений |

**Примечание:** Узел принимает минимум 1 входное значение. При необходимости вы можете добавить дополнительные входы с помощью функции авторасширения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `BOOLEAN` | Возвращает `true`, если хотя бы одно из входных значений является истинным; возвращает `false`, если все входные значения являются ложными. | BOOLEAN |
