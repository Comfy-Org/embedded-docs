# ИЛИ

Узел ComfyOrNode выполняет логическую операцию ИЛИ над набором входных значений. Он возвращает `true`, если хотя бы одно из предоставленных значений считается истинным согласно стандартным правилам истинности Python.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `value` | Значение для проверки на истинность. Вы можете указать несколько значений, добавив дополнительные входы. Узел возвращает `true`, если хотя бы одно из этих значений истинно. | ANY | Да | Минимум 1 значение; принимается несколько значений |

**Примечание:** Узел принимает минимум 1 входное значение. Вы можете добавлять дополнительные входы по мере необходимости с помощью функции авторасширения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `BOOLEAN` | Возвращает `true`, если хотя бы одно из входных значений истинно; возвращает `false`, если все входные значения ложны. | BOOLEAN |
