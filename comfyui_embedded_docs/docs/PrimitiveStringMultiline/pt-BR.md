# Texto (Multilinha)

O nó PrimitiveStringMultiline fornece um campo de entrada de texto multilinha para inserir e passar valores de string pelo seu fluxo de trabalho. Ele aceita entrada de texto com múltiplas linhas e gera o mesmo valor de string inalterado. Este nó é útil quando você precisa inserir conteúdo de texto mais longo ou texto formatado que abrange várias linhas.

## Entradas

| Parâmetro | Descrição | Tipo de Dado | Obrigatório | Intervalo |
| --- | --- | --- | --- | --- |
| `value` | O valor de texto de entrada que pode abranger múltiplas linhas | STRING | Sim | N/A |

## Saídas

| Nome da Saída | Descrição | Tipo de Dado |
| --- | --- | --- |
| `output` | O mesmo valor de string fornecido como entrada | STRING |
