# קלט טקסט

צומת Text (Multiline) מספק שדה קלט טקסט רב־שורתי להזנה ולהעברה של ערכי מחרוזת דרך זרימת העבודה שלך. הוא מקבל טקסט שמשתרע על פני מספר שורות ומוציא את אותו ערך מחרוזת ללא שינוי. צומת זה שימושי כאשר עליך לספק תוכן טקסט ארוך יותר או טקסט מעוצב מרובה שורות.
