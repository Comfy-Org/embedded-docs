# Chaîne (multiligne)

Le nœud PrimitiveStringMultiline fournit un champ de saisie de texte multiligne pour saisir et transmettre des valeurs de chaîne dans votre flux de travail. Il accepte une saisie de texte sur plusieurs lignes et renvoie la même valeur de chaîne sans modification. Ce nœud est utile lorsque vous avez besoin de saisir un contenu texte plus long ou un texte formaté s'étendant sur plusieurs lignes.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `value` | La valeur de saisie de texte qui peut s'étendre sur plusieurs lignes | STRING | Oui | N/A |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La même valeur de chaîne qui a été fournie en entrée | STRING |
