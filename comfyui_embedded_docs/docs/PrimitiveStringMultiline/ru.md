# Строка (многострочная)

Узел PrimitiveStringMultiline предоставляет многострочное текстовое поле для ввода и передачи строковых значений через ваш рабочий процесс. Он принимает многострочный текстовый ввод и возвращает то же строковое значение без изменений. Этот узел полезен, когда вам нужно ввести более длинное текстовое содержимое или форматированный текст, занимающий несколько строк.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Текстовое входное значение, которое может занимать несколько строк | STRING | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | То же строковое значение, которое было подано на вход | STRING |
