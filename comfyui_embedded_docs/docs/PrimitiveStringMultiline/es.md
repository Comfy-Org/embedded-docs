# Cadena (Multilínea)

El nodo PrimitiveStringMultiline proporciona un campo de entrada de texto multilínea para introducir y pasar valores de cadena a través de su flujo de trabajo. Acepta entrada de texto con múltiples líneas y genera el mismo valor de cadena sin cambios. Este nodo es útil cuando necesita ingresar contenido de texto más largo o texto formateado que abarca varias líneas.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `value` | El valor de texto de entrada que puede abarcar varias líneas | STRING | Sí | N/A |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `output` | El mismo valor de cadena que se proporcionó como entrada | STRING |
