# تبدیل متن به ویدیو PixVerse

ویدیوهایی بر اساس یک متن راهنما (prompt) و پارامترهای مختلف تولید می‌کند. این گره با استفاده از PixVerse API محتوای ویدیویی ایجاد می‌کند و امکان کنترل نسبت تصویر، کیفیت، مدت‌زمان، سبک حرکت و موارد دیگر را فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `پرامپت` | متن راهنما برای تولید ویدیو (پیش‌فرض: "") | STRING | بله | - |
| `نسبت تصویر` | نسبت تصویر برای ویدیوی تولیدشده | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `کیفیت` | تنظیم کیفیت ویدیو (پیش‌فرض: "540p") | COMBO | بله | `"540p"`<br>`"1080p"` |
| `مدت زمان (ثانیه)` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه | COMBO | بله | `"5"`<br>`"10"` |
| `حالت حرکت` | سبک حرکت برای تولید ویدیو | COMBO | بله | `"normal"`<br>`"fast"` |
| `seed` | seed برای تولید ویدیو (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |
| `پرامپت منفی` | توضیح متنی اختیاری درباره عناصر ناخواسته در تصویر (پیش‌فرض: "") | STRING | خیر | - |
| `قالب PixVerse` | یک الگوی اختیاری برای تأثیرگذاری بر سبک تولید، ساخته‌شده توسط گره «PixVerse Template» | CUSTOM | خیر | - |

**توجه:** `prompt` باید حداقل ۱ کاراکتر داشته باشد. هنگام استفاده از کیفیت 1080p، حالت حرکت به‌طور خودکار روی `normal` تنظیم می‌شود و مدت‌زمان به ۵ ثانیه محدود می‌شود. برای مدت‌زمان‌های غیر از ۵ ثانیه نیز حالت حرکت به‌طور خودکار روی `normal` تنظیم می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | فایل ویدیوی تولیدشده | VIDEO |
