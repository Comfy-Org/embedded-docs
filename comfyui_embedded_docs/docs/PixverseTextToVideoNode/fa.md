# تبدیل متن به ویدیو PixVerse

ویدیوهایی را از یک پرامپت متنی با استفاده از API PixVerse تولید می‌کند. این گره به شما امکان می‌دهد شکل، کیفیت، طول و سبک حرکت ویدیو را کنترل کنید و در صورت تمایل یک قالب سبک ذخیره‌شده را اعمال نمایید. درخواست را ارسال می‌کند، منتظر پایان تولید می‌ماند و ویدیوی نهایی را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت برای تولید ویدیو (پیش‌فرض: "") | STRING | بله | باید حداقل ۱ کاراکتر داشته باشد |
| `aspect_ratio` | نسبت ابعاد برای ویدیوی تولیدشده | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `quality` | تنظیم کیفیت ویدیو (پیش‌فرض: "540p") | COMBO | بله | `"540p"`<br>`"1080p"` |
| `duration_seconds` | مدت ویدیوی تولیدشده بر حسب ثانیه | COMBO | بله | `"5"`<br>`"10"` |
| `motion_mode` | سبک حرکت برای تولید ویدیو | COMBO | بله | `"normal"`<br>`"fast"` |
| `seed` | دانه (Seed) برای تولید ویدیو (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر (پیش‌فرض: "") | STRING | خیر | - |
| `pixverse_template` | قالب اختیاری برای تأثیرگذاری بر سبک تولید، ساخته‌شده توسط گره PixVerse Template | CUSTOM | خیر | - |

**توجه:** `prompt` باید حداقل ۱ کاراکتر داشته باشد. هنگامی که کیفیت 1080p انتخاب می‌شود، حالت حرکت به‌طور خودکار روی `normal` تنظیم می‌شود و مدت زمان به ۵ ثانیه محدود می‌گردد. برای هر مدت زمانی غیر از ۵ ثانیه، حالت حرکت نیز به‌طور خودکار روی `normal` تنظیم می‌شود.

|-------------|-------------|-----------|
| `output` | فایل ویدیوی تولیدشده | VIDEO |
