# PixVerse 文字轉影片

根據文字提示和各種生成參數產生影片。此節點使用 PixVerse API 建立影片內容，可控制長寬比、品質、持續時間、運動風格等。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於影片生成的提示詞（預設：""） | STRING | 是 | - |
| `長寬比` | 生成影片的長寬比 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `品質` | 影片品質設定（預設：「540p」） | COMBO | 是 | `"540p"`<br>`"1080p"` |
| `影片長度（秒）` | 生成影片的持續時間（秒） | COMBO | 是 | `"5"`<br>`"10"` |
| `動作模式` | 影片生成的運動風格 | COMBO | 是 | `"normal"`<br>`"fast"` |
| `種子值` | 用於影片生成的種子（預設：0） | INT | 是 | 0 至 2147483647 |
| `負向提示詞` | 可選的圖像中不希望出現元素的文字描述（預設：""） | STRING | 否 | - |
| `PixVerse 樣板` | 可選的樣板，用於影響生成風格，由 PixVerse Template 節點建立 | CUSTOM | 否 | - |

**注意：** `prompt` 必須至少包含 1 個字元。使用 1080p 品質時，運動模式會自動設定為 `normal`，且持續時間限制為 5 秒。對於非 5 秒的持續時間，運動模式也會自動設定為 `normal`。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 生成的影片檔案 | VIDEO |
