# PixVerse 文字轉影片

使用 PixVerse API 從文字提示生成影片。此節點可讓您控制影片的畫面比例、品質、長度與動態風格，並可選擇套用已儲存的風格範本。它會提交請求、等待生成完成，然後傳回完成的影片。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於影片生成的提示（預設值：""） | STRING | 是 | 必須包含至少 1 個字元 |
| `長寬比` | 生成影片的外觀比例 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `品質` | 影片品質設定（預設值："540p"） | COMBO | 是 | `"540p"`<br>`"1080p"` |
| `影片長度（秒）` | 生成影片的持續時間（秒） | COMBO | 是 | `"5"`<br>`"10"` |
| `動作模式` | 影片生成的動態風格 | COMBO | 是 | `"normal"`<br>`"fast"` |
| `種子值` | 影片生成的種子（預設值：0） | INT | 是 | 0 到 2147483647 |
| `負向提示詞` | 選填的文字描述，用於說明影像上不希望出現的元素（預設值：""） | STRING | 否 | - |
| `PixVerse 樣板` | 選填範本，可影響生成風格，由 PixVerse Template 節點建立 | CUSTOM | 否 | - |

**注意：** `prompt` 必須包含至少 1 個字元。當選取 1080p 品質時，動態模式會自動設為 `normal`，且持續時間限制為 5 秒。若持續時間不是 5 秒，動態模式也會自動設為 `normal`。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 生成的影片檔案 | VIDEO |
