# PixVerse טקסט לוידאו

יוצר סרטונים מתוך הנחיית טקסט באמצעות PixVerse API. הצומת מאפשר לשלוט בצורה, באיכות, באורך ובסגנון התנועה של הסרטון, ובאופן אופציונלי להחיל תבנית סגנון שמורה. הוא שולח את הבקשה, ממתין לסיום היצירה ומחזיר את הסרטון המוגמר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `הנחיה` | הנחיה ליצירת הסרטון (ברירת מחדל: "") | STRING | כן | חייב להכיל לפחות תו אחד |
| `יחס גובה-רוחב` | יחס רוחב-גובה עבור הסרטון הנוצר | COMBO | כן | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `איכות` | הגדרת איכות הסרטון (ברירת מחדל: "540p") | COMBO | כן | `"540p"`<br>`"1080p"` |
| `משך בשניות` | משך הסרטון הנוצר בשניות | COMBO | כן | `"5"`<br>`"10"` |
| `מצב תנועה` | סגנון תנועה ליצירת הסרטון | COMBO | כן | `"normal"`<br>`"fast"` |
| `seed` | Seed ליצירת הסרטון (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |
| `הנחיה שלילית` | תיאור טקסט אופציונלי של אלמנטים לא רצויים בתמונה (ברירת מחדל: "") | STRING | לא | - |
| `תבנית PixVerse` | תבנית אופציונלית להשפעה על סגנון היצירה, שנוצרה על ידי הצומת PixVerse Template | CUSTOM | לא | - |

**הערה:** `prompt` חייב להכיל לפחות תו אחד. כאשר נבחרת איכות 1080p, מצב התנועה מוגדר אוטומטית ל-`normal` והמשך מוגבל ל-5 שניות. עבור כל משך שאינו 5 שניות, מצב התנועה מוגדר גם הוא אוטומטית ל-`normal`.

| `output` | קובץ הסרטון שנוצר | VIDEO |
