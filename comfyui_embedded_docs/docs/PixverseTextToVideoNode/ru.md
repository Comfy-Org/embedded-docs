# PixVerse: текст в видео

Генерирует видео на основе текстового запроса и различных параметров генерации. Этот узел создает видеоконтент с помощью PixVerse API, позволяя управлять соотношением сторон, качеством, длительностью, стилем движения и другими параметрами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Запрос для генерации видео (по умолчанию: "") | STRING | Да | - |
| `aspect_ratio` | Соотношение сторон для сгенерированного видео | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `quality` | Настройка качества видео (по умолчанию: "540p") | COMBO | Да | `"540p"`<br>`"1080p"` |
| `duration_seconds` | Длительность сгенерированного видео в секундах | COMBO | Да | `"5"`<br>`"10"` |
| `motion_mode` | Стиль движения для генерации видео | COMBO | Да | `"normal"`<br>`"fast"` |
| `seed` | Сид для генерации видео (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: "") | STRING | Нет | - |
| `pixverse_template` | Необязательный шаблон для влияния на стиль генерации, созданный узлом PixVerse Template | CUSTOM | Нет | - |

**Примечание:** `prompt` должен содержать как минимум 1 символ. При использовании качества 1080p режим движения автоматически устанавливается в `normal`, а длительность ограничивается 5 секундами. Для длительности не равной 5 секундам режим движения также автоматически устанавливается в `normal`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл | VIDEO |
