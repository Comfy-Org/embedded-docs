# PixVerse: текст в видео

Создаёт видео из текстового запроса с помощью API PixVerse. Узел позволяет управлять форматом (соотношением сторон), качеством, длительностью и стилем движения видео, а также при необходимости применять сохранённый шаблон стиля. Он отправляет запрос, ожидает завершения генерации и возвращает готовое видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Запрос для генерации видео (по умолчанию: "") | STRING | Да | Должен содержать не менее 1 символа |
| `aspect_ratio` | Соотношение сторон генерируемого видео | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `quality` | Настройка качества видео (по умолчанию: "540p") | COMBO | Да | `"540p"`<br>`"1080p"` |
| `duration_seconds` | Длительность генерируемого видео в секундах | COMBO | Да | `"5"`<br>`"10"` |
| `motion_mode` | Стиль движения для генерации видео | COMBO | Да | `"normal"`<br>`"fast"` |
| `seed` | Начальное значение (seed) для генерации видео (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: "") | STRING | Нет | - |
| `pixverse_template` | Необязательный шаблон для влияния на стиль генерации, созданный узлом PixVerse Template | CUSTOM | Нет | - |

**Примечание:** `prompt` должен содержать не менее 1 символа. При выборе качества 1080p режим движения автоматически устанавливается на `normal`, а длительность ограничивается 5 секундами. Для любой длительности, отличной от 5 секунд, режим движения также автоматически устанавливается на `normal`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл | VIDEO |
