| `solver_type` | サンプリングに使用するソルバーの種類。拡散プロセスのノイズスケーリング動作を決定します（デフォルト: "ER-SDE"）。 | COMBO | はい | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |

- `eta` は "ER-SDE" と "Reverse-time SDE" の両方のソルバータイプに影響します。大きな値は無効な出力を引き起こす可能性があります。
