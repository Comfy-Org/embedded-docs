# SamplerER_SDE

Узел SamplerER_SDE предоставляет специализированные методы сэмплирования для диффузионных моделей, предлагая три типа решателей: ER-SDE, Reverse-time SDE и ODE. Он позволяет управлять стохастическим поведением и количеством вычислительных этапов процесса сэмплирования. Узел автоматически корректирует настройки шума при выборе решателя ODE или детерминированной конфигурации (`eta`=0).

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `solver_type` | Тип решателя, используемого для сэмплирования. Определяет поведение масштабирования шума в диффузионном процессе (по умолчанию: "ER-SDE"). | COMBO | Да | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |
| `max_stage` | Максимальное количество этапов процесса сэмплирования (по умолчанию: 3). Управляет вычислительной сложностью и качеством. Дополнительный параметр. | INT | Да | 1-3 |
| `eta` | Стохастическая интенсивность SDE.<br>При eta=0 они сводятся к детерминированному ODE.<br>Большие значения eta могут приводить к некорректным результатам. Если это происходит, попробуйте уменьшить это значение. (по умолчанию: 1.0). Дополнительный параметр. | FLOAT | Да | 0.0-10.0 |
| `s_noise` | Коэффициент масштабирования шума для процесса сэмплирования (по умолчанию: 1.0). Управляет количеством шума, применяемого во время сэмплирования. Дополнительный параметр. | FLOAT | Да | 0.0-100.0 |

**Ограничения параметров:**

- Когда `solver_type` имеет значение "ODE" или `eta` равно 0, узел принудительно устанавливает `s_noise` равным 0.0 и переключает решатель на "ODE".
- `eta` влияет на оба типа решателей: "ER-SDE" и "Reverse-time SDE". Большие значения могут приводить к некорректным результатам.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `sampler` | Сконфигурированный объект сэмплера, который можно использовать в конвейере сэмплирования с указанными настройками решателя. | SAMPLER |
