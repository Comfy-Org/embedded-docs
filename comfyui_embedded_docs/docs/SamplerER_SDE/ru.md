# SamplerER_SDE

Узел SamplerER_SDE предоставляет специализированные методы сэмплирования для диффузионных моделей, предлагая различные типы решателей: ER-SDE, Reverse-time SDE и ODE. Он позволяет управлять стохастическим поведением и количеством вычислительных этапов процесса сэмплирования. Узел автоматически настраивает параметры в зависимости от выбранного типа решателя, чтобы обеспечить корректную работу сэмплера.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `тип_решателя` | Тип решателя, используемый для сэмплирования. Определяет математический подход к диффузионному процессу (по умолчанию: "ER-SDE"). | COMBO | Да | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |
| `макс_этап` | Максимальное количество этапов процесса сэмплирования (по умолчанию: 3). Управляет вычислительной сложностью и качеством. | INT | Да | 1-3 |
| `эта` | Стохастическая сила SDE.<br>Когда eta=0, они сводятся к детерминированному ODE.<br>Большие значения eta могут привести к некорректным результатам. Если это происходит, попробуйте уменьшить это значение. (по умолчанию: 1.0) | FLOAT | Да | 0.0-10.0 (шаг: 0.01) |
| `s_шум` | Коэффициент масштабирования шума для процесса сэмплирования (по умолчанию: 1.0). Управляет количеством шума, применяемого во время сэмплирования. | FLOAT | Да | 0.0-100.0 (шаг: 0.01) |

**Ограничения параметров:**

- Когда `solver_type` установлен на "ODE" или когда `eta` равен 0, узел переключается в режим ODE и устанавливает `s_noise` в 0.0, независимо от значения, введенного для `s_noise`.
- Параметр `eta` управляет стохастической силой обоих типов решателей: "ER-SDE" и "Reverse-time SDE". Он не оказывает влияния, когда решатель работает в режиме ODE.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Сконфигурированный объект сэмплера, который можно использовать в конвейере сэмплирования с заданными настройками решателя. | SAMPLER |
