# SamplerER_SDE

گره SamplerER_SDE روش‌های نمونه‌برداری تخصصی برای مدل‌های دیفیوژن فراهم می‌کند و انواع مختلف حل‌کننده را ارائه می‌دهد: ER-SDE، Reverse-time SDE و ODE. این گره به شما امکان می‌دهد رفتار تصادفی و تعداد مراحل محاسباتی فرآیند نمونه‌برداری را کنترل کنید. گره به‌طور خودکار تنظیمات را بر اساس نوع حل‌کننده انتخابی تنظیم می‌کند تا نمونه‌بردار به‌درستی کار کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نوع حل‌کننده` | نوع حل‌کننده مورد استفاده برای نمونه‌برداری. رویکرد ریاضی فرآیند دیفیوژن را تعیین می‌کند (پیش‌فرض: "ER-SDE"). | COMBO | بله | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |
| `بیشترین مرحله` | حداکثر تعداد مراحل برای فرآیند نمونه‌برداری (پیش‌فرض: 3). پیچیدگی محاسباتی و کیفیت را کنترل می‌کند. | INT | بله | 1-3 |
| `اتا` | قدرت تصادفی SDEها.<br>وقتی eta=0 باشد، به ODE قطعی کاهش می‌یابند.<br>eta بزرگ ممکن است خروجی‌های نامعتبر ایجاد کند. اگر این اتفاق افتاد، مقدار را کاهش دهید. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0-10.0 (گام: 0.01) |
| `s_noise` | ضریب مقیاس نویز برای فرآیند نمونه‌برداری (پیش‌فرض: 1.0). مقدار نویز اعمال‌شده در طول نمونه‌برداری را کنترل می‌کند. | FLOAT | بله | 0.0-100.0 (گام: 0.01) |

**محدودیت‌های پارامتر:**

- وقتی `solver_type` روی "ODE" تنظیم شود یا `eta` برابر 0 باشد، گره به حالت ODE تغییر می‌کند و `s_noise` را بدون توجه به مقدار واردشده برای `s_noise` روی 0.0 تنظیم می‌کند.
- پارامتر `eta` قدرت تصادفی هر دو نوع حل‌کننده "ER-SDE" و "Reverse-time SDE" را کنترل می‌کند. زمانی که حل‌کننده در حالت ODE اجرا می‌شود، تأثیری ندارد.
