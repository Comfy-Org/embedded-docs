# SamplerER_SDE

گره SamplerER_SDE روش‌های نمونه‌برداری تخصصی برای مدل‌های انتشار ارائه می‌دهد و سه نوع حل‌کننده را در اختیار می‌گذارد: ER-SDE، Reverse-time SDE و ODE. این گره امکان کنترل بر رفتار تصادفی و تعداد مراحل محاسباتی فرآیند نمونه‌برداری را فراهم می‌کند. گره به‌صورت خودکار تنظیمات نویز را زمانی که حل‌کننده ODE یا پیکربندی قطعی (`eta`=0) انتخاب شده است، تنظیم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `solver_type` | نوع حل‌کننده مورد استفاده برای نمونه‌برداری. رفتار مقیاس‌گذاری نویز فرآیند انتشار را تعیین می‌کند (پیش‌فرض: "ER-SDE"). | COMBO | بله | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |
| `max_stage` | حداکثر تعداد مراحل فرآیند نمونه‌برداری (پیش‌فرض: 3). پیچیدگی محاسباتی و کیفیت را کنترل می‌کند. پارامتر پیشرفته. | INT | بله | 1-3 |
| `eta` | قدرت تصادفی SDEها.<br>وقتی eta=0 باشد، به ODE قطعی کاهش می‌یابند.<br>مقادیر بزرگ eta ممکن است خروجی‌های نامعتبر ایجاد کند. اگر این اتفاق افتاد، این مقدار را کاهش دهید. (پیش‌فرض: 1.0). پارامتر پیشرفته. | FLOAT | بله | 0.0-10.0 |
| `s_noise` | ضریب مقیاس‌گذاری نویز برای فرآیند نمونه‌برداری (پیش‌فرض: 1.0). میزان نویز اعمال‌شده در طول نمونه‌برداری را کنترل می‌کند. پارامتر پیشرفته. | FLOAT | بله | 0.0-100.0 |

**محدودیت‌های پارامتر:**

- وقتی `solver_type` برابر "ODE" یا `eta` برابر 0 باشد، گره `s_noise` را به 0.0 تنظیم می‌کند و حل‌کننده را به "ODE" تغییر می‌دهد.
- `eta` بر هر دو نوع حل‌کننده "ER-SDE" و "Reverse-time SDE" تأثیر می‌گذارد. مقادیر بزرگ ممکن است خروجی‌های نامعتبر ایجاد کند.
