# SamplerER_SDE

SamplerER_SDE 노드는 확산 모델을 위한 특화된 샘플링 방법을 제공하며, ER-SDE, Reverse-time SDE, ODE의 세 가지 솔버 유형을 지원합니다. 샘플링 프로세스의 확률적 동작과 계산 단계 수를 제어할 수 있습니다. ODE 솔버 또는 결정적 구성(`eta`=0)이 선택되면 노드가 노이즈 설정을 자동으로 조정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `solver_type` | 샘플링에 사용할 솔버 유형입니다. 확산 프로세스의 노이즈 스케일링 동작을 결정합니다 (기본값: "ER-SDE"). | COMBO | 예 | "ER-SDE"<br>"Reverse-time SDE"<br>"ODE" |
| `max_stage` | 샘플링 프로세스의 최대 단계 수입니다 (기본값: 3). 계산 복잡도와 품질을 제어합니다. 고급 매개변수입니다. | INT | 예 | 1-3 |
| `eta` | SDE의 확률적 강도입니다.<br>eta=0이면 SDE가 결정적 ODE로 환원됩니다.<br>eta 값이 크면 유효하지 않은 출력이 발생할 수 있습니다. 이 경우 값을 낮추어 보십시오. (기본값: 1.0). 고급 매개변수입니다. | FLOAT | 예 | 0.0-10.0 |
| `s_noise` | 샘플링 프로세스의 노이즈 스케일링 계수입니다 (기본값: 1.0). 샘플링 중 적용되는 노이즈의 양을 제어합니다. 고급 매개변수입니다. | FLOAT | 예 | 0.0-100.0 |

**매개변수 제약 조건:**

- `solver_type`이 "ODE"이거나 `eta`가 0이면, 노드는 `s_noise`를 0.0으로 강제하고 솔버를 "ODE"로 전환합니다.
- `eta`는 "ER-SDE" 및 "Reverse-time SDE" 솔버 유형 모두에 영향을 미칩니다. 값이 크면 유효하지 않은 출력이 발생할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `sampler` | 지정된 솔버 설정으로 샘플링 파이프라인에서 사용할 수 있는 구성된 샘플러 객체입니다. | SAMPLER |
