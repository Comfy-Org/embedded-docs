# StableCascade_Этап C_VAE Кодирование

Узел `StableCascade_StageC_VAEEncode` обрабатывает входное изображение через VAE-энкодер для создания скрытых представлений для модели Stable Cascade. Сначала он изменяет размер изображения на основе коэффициента сжатия и коэффициента уменьшения VAE, затем кодирует изображение с изменённым размером. Узел выводит два скрытых тензора: один для этапа C (фактический результат кодирования) и один для этапа B (заполнитель, заполненный нулями).

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение, которое должно быть закодировано в скрытое пространство | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображения | VAE | Да | - |
| `compression` | Коэффициент сжатия, применяемый к изображению перед кодированием. Размеры изображения делятся на это значение, затем умножаются на коэффициент уменьшения VAE (по умолчанию: 42) | INT | Нет | 4-128 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `stage_c` | Скрытое представление, закодированное для этапа C модели Stable Cascade | LATENT |
| `stage_b` | Заполнитель скрытого представления для этапа B. В настоящее время возвращает тензор, заполненный нулями, с размерами, вычисленными из размера входного изображения. | LATENT |
