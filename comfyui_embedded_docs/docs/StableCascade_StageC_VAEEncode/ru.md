# StableCascade_Этап C_VAE Кодирование

Узел StableCascade_StageC_VAEEncode обрабатывает входное изображение через VAE-энкодер для создания латентных представлений для модели Stable Cascade. Сначала он изменяет размер изображения на основе коэффициента сжатия и коэффициента уменьшения VAE, затем кодирует изменённое изображение. Узел выводит два латентных тензора: один для стадии C (фактический результат кодирования) и один для стадии B (заполнитель из нулей).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Входное изображение, которое будет закодировано в латентное пространство | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображения | VAE | Да | - |
| `сжатие` | Коэффициент сжатия, применяемый к изображению перед кодированием. Размеры изображения делятся на это значение, затем умножаются на коэффициент уменьшения VAE. Это расширенный параметр. (по умолчанию: 42) | INT | Нет | 4-128 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `этап_c` | Закодированное латентное представление для стадии C модели Stable Cascade | LATENT |
| `этап_b` | Заполнитель латентного представления для стадии B. В настоящее время возвращает тензор, заполненный нулями, с размерами, вычисленными из размера входного изображения. | LATENT |
