# StableCascade_StageC_VAEEncode

הצומת StableCascade_StageC_VAEEncode מעבד תמונת קלט באמצעות מקודד VAE כדי ליצור ייצוגים חבויים עבור מודל Stable Cascade. תחילה הוא משנה את גודל התמונה בהתאם לגורם דחיסה וליחס ההקטנה של ה-VAE, ולאחר מכן מקודד את התמונה ששונתה בגודלה. הצומת מפיק שני טנסורים חבויים: אחד עבור שלב C (תוצאת הקידוד בפועל) ואחד עבור שלב B (ממלא מקום מלא באפסים).

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט שיש לקודד למרחב החבוי | IMAGE | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד התמונה | VAE | כן | - |
| `compression` | גורם הדחיסה המוחל על התמונה לפני הקידוד. ממדי התמונה מחולקים בערך זה, ואז מוכפלים ביחס ההקטנה של ה-VAE. זהו פרמטר מתקדם. (ברירת מחדל: 42) | INT | כן | 4-128 (צעד: 1) |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `stage_c` | ייצוג חבוי מקודד עבור שלב C של מודל Stable Cascade | LATENT |
| `stage_b` | ייצוג חבוי ממלא מקום עבור שלב B. נכון לעכשיו מחזיר טנסור מלא באפסים עם ממדים המחושבים מגודל תמונת הקלט. | LATENT |
