# Google Gemini Decision (Yes/No)

Задайте вопрос с ответом «да/нет» о тексте, изображениях, аудио или видео, которые вы подключаете, и получите логическое значение для маршрутизации. Подключите `result` к узлу If/Else Switch, чтобы направить выполнение по одному из двух путей, и читайте `answer` и `probability`, когда нужно понять, почему модель ответила именно так.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для использования (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `вопрос` | Вопрос с ответом «да/нет» о том, что подключено, до 5000 символов. Формулируйте его так, чтобы «да» соответствовало случаю, на который вы реагируете (по умолчанию: "Is there a person in the image?"). | STRING | Да | от 1 до 5000 символов |
| `порог` | Вероятность ответа «да», при которой `result` становится true. Явные ответы «да» обычно имеют оценку около 0.85–0.92, поэтому порог 0.9 или больше отсеивает многие из них (по умолчанию: 0.5). | FLOAT | Да | от 0.01 до 0.99 (шаг 0.01) |
| `изображения` | Изображения, о которых нужно задать вопрос, до 16 в расширяемых слотах (`image_1` ... `image_16`). Пакетное изображение учитывается один раз для каждого изображения. | IMAGE | Нет | До 16 изображений |
| `аудио` | Аудиоклип, о котором нужно задать вопрос. | AUDIO | Нет | - |
| `видео` | Видеоклип, о котором нужно задать вопрос. | VIDEO | Нет | - |
| `текст` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Подключите хотя бы один из входов `text`, `images`, `audio` или `video`; узел выдаёт ошибку, если анализировать нечего. Если изображений несколько, называйте их `image_1`, `image_2` и т. д. в тексте вопроса: пакет разворачивается покадрово, поэтому номера учитывают отдельные кадры по слотам в порядке подключения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `result` | True, когда вероятность ответа «да» достигает `threshold`, и false в противном случае. | BOOLEAN |
| `answer` | Вердикт в виде строки `"yes"` или `"no"`, использующий тот же `threshold`, что и `result`. | STRING |
| `probability` | Вероятность ответа «да» в диапазоне от 0 до 1. | FLOAT |
