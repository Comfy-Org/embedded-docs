# Google Gemini Decision (Yes/No)

Задайте вопрос с ответом «да/нет» о подключённых тексте, изображениях, аудио или видео и получите логическое значение для маршрутизации. Подключите `result` к узлу If/Else Switch, чтобы направить запуск по одному из двух путей, а `answer` и `probability` читайте, когда нужно понять, почему модель ответила именно так.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `question` | Вопрос с ответом «да/нет» о том, что подключено, до 5000 символов. Формулируйте его так, чтобы «да» соответствовало случаю, для которого вы хотите выполнить действие (по умолчанию: "Is there a person in the image?"). | STRING | Да | от 1 до 5000 символов |
| `threshold` | Вероятность ответа «да», при которой `result` становится true. Явные ответы «да» обычно имеют оценку около 0.85–0.92, поэтому порог 0.9 или выше отсеивает многие из них (по умолчанию: 0.5). | FLOAT | Да | от 0.01 до 0.99 (шаг 0.01) |
| `images` | Изображения, о которых нужно задать вопрос, до 16 в расширяемых слотах (`image_1` ... `image_16`). Пакетное изображение учитывается отдельно для каждого изображения. | IMAGE | Нет | До 16 изображений |
| `audio` | Аудиоклип, о котором нужно задать вопрос. | AUDIO | Нет | - |
| `video` | Видеоклип, о котором нужно задать вопрос. | VIDEO | Нет | - |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Подключите хотя бы один из входов `text`, `images`, `audio` или `video`; узел выдаёт ошибку, если нет данных для анализа. При наличии нескольких изображений называйте их `image_1`, `image_2` и так далее в тексте вопроса.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `result` | Ответ в виде логического значения: true для «да», false для «нет». | BOOLEAN |
| `answer` | Ответ в виде строки `"yes"` или `"no"`. | STRING |
| `probability` | Вероятность ответа «да» от 0 до 1. | FLOAT |
