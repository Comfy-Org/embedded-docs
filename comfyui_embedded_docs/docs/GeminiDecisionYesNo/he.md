# Google Gemini Decision (Yes/No)

שאל שאלת כן/לא על הטקסט, התמונות, האודיו או הווידאו שאתה מחבר, וקבל ערך בוליאני שעל פיו תנתב. חבר את `result` לצומת If/Else Switch כדי לשלוח את ההרצה לאחד משני מסלולים, וקרא את `answer` ואת `probability` כשתרצה לראות מדוע המודל ענה כך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל לשימוש (ברירת מחדל: `"gemini-decision-1"`). | COMBO | כן | `"gemini-decision-1"` |
| `question` | שאלת כן/לא לגבי מה שמחובר, באורך של עד 5000 תווים. נסח אותה כך ש"כן" יהיה המקרה שעליו אתה פועל (ברירת מחדל: "Is there a person in the image?"). | STRING | כן | 1 עד 5000 תווים |
| `threshold` | הסתברות ל"כן" שבה `result` הופך ל-true. תשובות "כן" ברורות מקבלות ניקוד של בערך 0.85 עד 0.92, כך ש-0.9 או יותר דוחה רבות מהן (ברירת מחדל: 0.5). | FLOAT | כן | 0.01 עד 0.99 (צעד 0.01) |
| `images` | תמונות לשאול לגביהן, עד 16 לאורך החריצים הניתנים להרחבה (`image_1` ... `image_16`). תמונה באצווה נספרת פעם אחת לכל תמונה. | IMAGE | לא | עד 16 תמונות |
| `audio` | קליפ אודיו לשאול לגביו. | AUDIO | לא | - |
| `video` | קליפ וידאו לשאול לגביו. | VIDEO | לא | - |
| `text` | טקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM, באורך של עד 20000 תווים. | STRING | לא | עד 20000 תווים |

חבר לפחות אחד מ-`text`, `images`, `audio` או `video`; הצומת תעלה שגיאה כשאין במה להסתכל. עם כמה תמונות, תן להן שמות `image_1`, `image_2` וכן הלאה בתוך השאלה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `result` | התשובה כבוליאני: true עבור "yes", false עבור "no". | BOOLEAN |
| `answer` | התשובה כמחרוזת `"yes"` או `"no"`. | STRING |
| `probability` | הסתברות ל"yes" בין 0 ל-1. | FLOAT |
