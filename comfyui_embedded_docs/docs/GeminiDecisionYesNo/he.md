# Google Gemini Decision (Yes/No)

שאל שאלת כן/לא לגבי הטקסט, התמונות, השמע או הווידאו שאתה מחבר, וקבל ערך בוליאני שעליו ניתן לנתב. חבר את `result` לצומת If/Else Switch כדי להפנות את ההרצה לאחד משני נתיבים, וקרא את `answer` ואת `probability` כאשר אתה רוצה לראות מדוע המודל ענה כך.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-------|--------|------------|------|------|
| `model` | המודל לשימוש (ברירת מחדל: `"gemini-decision-1"`). | COMBO | כן | `"gemini-decision-1"` |
| `question` | שאלת כן/לא לגבי מה שמחובר, עד 5000 תווים. שאל אותה כך ש־"yes" יהיה המקרה שעליו אתה פועל (ברירת מחדל: "Is there a person in the image?"). | STRING | כן | 1 עד 5000 תווים |
| `threshold` | ההסתברות ל־"yes" שבה `result` הופך ל־True. תשובות "yes" ברורות מקבלות ציון של כ־0.85 עד 0.92, לכן 0.9 או יותר דוחה רבות מהן (ברירת מחדל: 0.5). | FLOAT | כן | 0.01 עד 0.99 (צעד 0.01) |
| `images` | תמונות לשאול עליהן, עד 16 תמונות על פני המשבצות הניתנות להרחבה (`image_1` ... `image_16`). תמונה באצווה נספרת פעם אחת לכל תמונה. | IMAGE | לא | עד 16 תמונות |
| `audio` | קטע שמע לשאול עליו. | AUDIO | לא | - |
| `video` | קטע וידאו לשאול עליו. | VIDEO | לא | - |
| `text` | טקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

חבר לפחות אחד מ־`text`, `images`, `audio` או `video`; הצומת מעלה שגיאה כשאין על מה להסתכל. כאשר יש מספר תמונות, תן להן שמות `image_1`, `image_2` וכן הלאה בתוך השאלה: אצווה נפרסת פריים אחר פריים, כך שהמספרים סופרים פריימים בודדים על פני המשבצות לפי סדר החיבור.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|---------|--------|------------|
| `result` | True כאשר ההסתברות ל־"yes" מגיעה ל־`threshold`, אחרת false. | BOOLEAN |
| `answer` | ההכרעה כמחרוזת `"yes"` או `"no"`, לפי אותו `threshold` כמו `result`. | STRING |
| `probability` | ההסתברות ל־"yes" בין 0 ל-1. | FLOAT |
