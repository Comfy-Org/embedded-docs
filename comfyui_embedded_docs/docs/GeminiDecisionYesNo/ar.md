# Google Gemini Decision (Yes/No)

اطرح سؤالًا من نوع نعم/لا حول النص أو الصور أو الصوت أو الفيديو الذي توصله، واحصل على قيمة منطقية (boolean) لتوجيه المسار بناءً عليها. صِل `result` بعقدة If/Else Switch لتوجيه التشغيل عبر أحد مسارين، واقرأ `answer` و`probability` عندما تريد معرفة سبب إجابة النموذج بهذه الطريقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم (الافتراضي: `"gemini-decision-1"`). | COMBO | نعم | `"gemini-decision-1"` |
| `السؤال` | سؤال نعم/لا حول ما تم توصيله، حتى 5000 حرف. اطرحه بحيث تكون حالة "نعم" هي الحالة التي تتصرف بناءً عليها (الافتراضي: "Is there a person in the image?"). | STRING | نعم | 1 إلى 5000 حرف |
| `العتبة` | احتمال "نعم" الذي عنده تصبح `result` مساوية لـ True. تحصل إجابات "نعم" الواضحة على نحو 0.85 إلى 0.92، لذا فإن 0.9 أو أكثر يرفض العديد منها (الافتراضي: 0.5). | FLOAT | نعم | 0.01 إلى 0.99 (خطوة 0.01) |
| `الصور` | الصور التي سيُسأل عنها، حتى 16 عبر الخانات القابلة للتوسيع (`image_1` ... `image_16`). تُحتسب الصورة الواردة ضمن حزمة (batch) مرة واحدة لكل صورة. | IMAGE | لا | حتى 16 صورة |
| `صوت` | مقطع صوتي يُسأل عنه. | AUDIO | لا | - |
| `فيديو` | مقطع فيديو يُسأل عنه. | VIDEO | لا | - |
| `نص` | النص الذي يدور حوله السؤال، مثل مطالبة أو استجابة LLM، حتى 20000 حرف. | STRING | لا | حتى 20000 حرف |

صِل واحدًا على الأقل من `text` أو `images` أو `audio` أو `video`؛ تُطلق العقدة خطأً عندما لا يوجد ما يمكن النظر إليه. عند وجود عدة صور، سمِّها `image_1` و`image_2` وهكذا داخل السؤال: تُوسَّع الحزمة إطارًا بإطار، لذا تُعدّ الأرقام الإطارات الفردية عبر الخانات بترتيب التوصيل.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `result` | True عندما يبلغ احتمال "نعم" قيمة `threshold`، وFalse بخلاف ذلك. | BOOLEAN |
| `answer` | الحكم كسلسلة نصية `"yes"` أو `"no"`، وفقًا لنفس `threshold` المستخدم في `result`. | STRING |
| `probability` | احتمال "نعم" بين 0 و1. | FLOAT |
