# Google Gemini Decision (Yes/No)

اطرح سؤالًا بنعم/لا حول النص أو الصور أو الصوت أو الفيديو الذي توصله، واحصل على قيمة منطقية (boolean) للتوجيه بناءً عليها. وصّل `result` بعقدة If/Else Switch لإرسال التشغيل عبر أحد مسارين، واقرأ `answer` و`probability` عندما تريد معرفة سبب إجابة النموذج بهذه الطريقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم (افتراضي: `"gemini-decision-1"`). | COMBO | نعم | `"gemini-decision-1"` |
| `question` | سؤال بنعم/لا حول ما تم توصيله، حتى 5000 حرف. اطرحه بحيث تكون حالة "yes" هي الحالة التي تريد التصرف بناءً عليها (افتراضي: "Is there a person in the image?"). | STRING | نعم | 1 إلى 5000 حرف |
| `threshold` | احتمال "yes" الذي عنده تصبح `result` صحيحة. الإجابات الواضحة بـ "yes" تحصل عادةً على نحو 0.85 إلى 0.92، لذا فإن 0.9 أو أكثر يرفض الكثير منها (افتراضي: 0.5). | FLOAT | نعم | 0.01 إلى 0.99 (خطوة: 0.01) |
| `images` | الصور المراد السؤال عنها، حتى 16 صورة عبر الفتحات القابلة للتوسيع (`image_1` ... `image_16`). تُحتسب الصورة المجمّعة مرة واحدة لكل صورة. | IMAGE | لا | حتى 16 صورة |
| `audio` | مقطع صوتي المراد السؤال عنه. | AUDIO | لا | - |
| `video` | مقطع فيديو المراد السؤال عنه. | VIDEO | لا | - |
| `text` | النص الذي يدور حوله السؤال، مثل موجّه أو استجابة LLM، حتى 20000 حرف. | STRING | لا | حتى 20000 حرف |

وصّل واحدًا على الأقل من `text` أو `images` أو `audio` أو `video`؛ تُطلق العقدة خطأً عندما لا يوجد شيء لفحصه. عند وجود عدة صور، سمِّها `image_1` و`image_2` وهكذا داخل السؤال.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `result` | الإجابة كقيمة منطقية: true لـ "yes"، وfalse لـ "no". | BOOLEAN |
| `answer` | الإجابة كنص `"yes"` أو `"no"`. | STRING |
| `probability` | احتمال "yes" بين 0 و1. | FLOAT |
