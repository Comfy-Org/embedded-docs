# Google Gemini Decision (Yes/No)

دربارهٔ متن، تصویر، صدا یا ویدیویی که متصل می‌کنید یک پرسش بله/خیر بپرسید و یک مقدار بولی برای مسیریابی دریافت کنید. خروجی `result` را به گره If/Else Switch متصل کنید تا اجرا را به یکی از دو مسیر بفرستید، و وقتی می‌خواهید ببینید چرا مدل چنین پاسخ داده است، `answer` و `probability` را بخوانید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده (پیش‌فرض: `"gemini-decision-1"`). | COMBO | بله | `"gemini-decision-1"` |
| `پرسش` | پرسش بله/خیر دربارهٔ آنچه متصل شده است، حداکثر 5000 نویسه. آن را طوری بپرسید که حالت «بله» همان حالتی باشد که بر اساس آن اقدام می‌کنید (پیش‌فرض: "Is there a person in the image?"). | STRING | بله | 1 تا 5000 نویسه |
| `آستانه` | احتمال «بله» که با رسیدن به آن `result` برابر true می‌شود. پاسخ‌های «بله» واضح حدود 0.85 تا 0.92 امتیاز می‌گیرند، بنابراین 0.9 یا بیشتر بسیاری از آن‌ها را رد می‌کند (پیش‌فرض: 0.5). | FLOAT | بله | 0.01 تا 0.99 (گام: 0.01) |
| `تصاویر` | تصاویری که دربارهٔ آن‌ها پرسیده می‌شود، تا 16 تصویر در جایگاه‌های قابل‌افزایش (`image_1` ... `image_16`). یک تصویر دسته‌ای به ازای هر تصویر یک بار شمرده می‌شود. | IMAGE | خیر | حداکثر 16 تصویر |
| `صوت` | کلیپ صوتی که دربارهٔ آن پرسیده می‌شود. | AUDIO | خیر | - |
| `ویدئو` | کلیپ ویدیویی که دربارهٔ آن پرسیده می‌شود. | VIDEO | خیر | - |
| `متن` | متنی که پرسش دربارهٔ آن است، مانند یک پرامپت یا پاسخ LLM، حداکثر 20000 نویسه. | STRING | خیر | حداکثر 20000 نویسه |

حداقل یکی از `text`، `images`، `audio` یا `video` را متصل کنید؛ اگر چیزی برای بررسی وجود نداشته باشد، گره خطا می‌دهد. وقتی چند تصویر دارید، آن‌ها را در پرسش `image_1`، `image_2` و به همین ترتیب نام‌گذاری کنید: یک دسته فریم‌به‌فریم باز می‌شود، بنابراین شماره‌ها فریم‌های جداگانه را در جایگاه‌ها به ترتیب اتصال می‌شمارند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `result` | زمانی true است که احتمال «بله» به `threshold` برسد، در غیر این صورت false است. | BOOLEAN |
| `answer` | نتیجه به‌صورت رشتهٔ `"yes"` یا `"no"`، با پیروی از همان `threshold` مربوط به `result`. | STRING |
| `probability` | احتمال «بله» بین 0 و 1. | FLOAT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GeminiDecisionYesNo/fa.md)
