# Google Gemini Decision (Yes/No)

یک پرسش بله/خیر دربارهٔ متن، تصاویر، صدا یا ویدئویی که متصل می‌کنید بپرسید و یک مقدار بولی برای مسیریابی دریافت کنید. برای فرستادن اجرای کار به یکی از دو مسیر، `result` را به گره If/Else Switch وصل کنید، و وقتی می‌خواهید ببینید چرا مدل آن‌گونه پاسخ داده است، `answer` و `probability` را بخوانید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که باید استفاده شود (پیش‌فرض: `"gemini-decision-1"`). | COMBO | بله | `"gemini-decision-1"` |
| `question` | پرسش بله/خیر دربارهٔ آنچه متصل شده است، حداکثر تا 5000 کاراکتر. آن را طوری بپرسید که «بله» همان حالتی باشد که بر اساس آن اقدام می‌کنید (پیش‌فرض: «آیا شخصی در تصویر وجود دارد؟»). | STRING | بله | 1 تا 5000 کاراکتر |
| `threshold` | احتمال «بله» که در آن `result` true می‌شود. پاسخ‌های «بله»ی واضح حدود 0.85 تا 0.92 امتیاز می‌گیرند، بنابراین 0.9 یا بیشتر بسیاری از آن‌ها را رد می‌کند (پیش‌فرض: 0.5). | FLOAT | بله | 0.01 تا 0.99 (گام 0.01) |
| `images` | تصاویری که باید درباره‌شان پرسیده شود، حداکثر 16 تصویر در جایگاه‌های قابل‌افزایش (`image_1` ... `image_16`). یک تصویر دسته‌ای برای هر تصویر یک بار شمرده می‌شود. | IMAGE | خیر | تا 16 تصویر |
| `audio` | کلیپ صوتی که باید درباره‌اش پرسیده شود. | AUDIO | خیر | - |
| `video` | کلیپ ویدئویی که باید درباره‌اش پرسیده شود. | VIDEO | خیر | - |
| `text` | متنی که پرسش دربارهٔ آن است، مانند یک پرامپت یا پاسخ LLM، حداکثر تا 20000 کاراکتر. | STRING | خیر | تا 20000 کاراکتر |

حداقل یکی از `text`، `images`، `audio` یا `video` را متصل کنید؛ وقتی چیزی برای بررسی وجود نداشته باشد، گره خطا می‌دهد. اگر چند تصویر دارید، آن‌ها را داخل پرسش با نام‌های `image_1`، `image_2` و به همین ترتیب مشخص کنید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `result` | پاسخ به‌صورت یک مقدار بولی: true برای «بله»، false برای «خیر». | BOOLEAN |
| `answer` | پاسخ به‌صورت رشتهٔ `"yes"` یا `"no"`. | STRING |
| `probability` | احتمال «بله» بین 0 و 1. | FLOAT |
