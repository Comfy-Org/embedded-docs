# Google Gemini Decision (Yes/No)

接続したテキスト、画像、音声、または動画についてはい/いいえで答える質問を行い、分岐に使用できるブール値を取得します。`result` を If/Else Switch ノードに接続すると、実行を 2 つのパスのいずれかに送ることができます。モデルがそのように回答した理由を確認したい場合は、`answer` と `probability` を読み取ってください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル（デフォルト：`"gemini-decision-1"`）。 | COMBO | はい | `"gemini-decision-1"` |
| `question` | 接続されている内容についてのはい/いいえで答える質問です。最大 5000 文字です。「yes」が実際に対処するケースになるように質問してください（デフォルト："Is there a person in the image?"）。 | STRING | はい | 1～5000 文字 |
| `threshold` | `result` が true になる「yes」の確率です。明確な「yes」の回答は約 0.85～0.92 のスコアになるため、0.9 以上にするとその多くが拒否されます（デフォルト：0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問の対象とする画像です。拡張可能なスロット（`image_1` ... `image_16`）全体で最大 16 枚です。バッチ化された画像は、画像ごとに 1 回としてカウントされます。 | IMAGE | いいえ | 最大 16 枚の画像 |
| `audio` | 質問の対象とする音声クリップです。 | AUDIO | いいえ | - |
| `video` | 質問の対象とする動画クリップです。 | VIDEO | いいえ | - |
| `text` | 質問の対象となるテキストです。プロンプトや LLM の応答など、最大 20000 文字です。 | STRING | いいえ | 最大 20000 文字 |

`text`、`images`、`audio`、`video` のうち少なくとも 1 つを接続してください。参照する対象がない場合、ノードはエラーを発生させます。画像が複数ある場合は、質問内で `image_1`、`image_2` などの名前を付けてください。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `result` | ブール値としての回答です。「yes」の場合は true、「no」の場合は false です。 | BOOLEAN |
| `answer` | 文字列 `"yes"` または `"no"` としての回答です。 | STRING |
| `probability` | 「yes」の確率（0～1）です。 | FLOAT |
