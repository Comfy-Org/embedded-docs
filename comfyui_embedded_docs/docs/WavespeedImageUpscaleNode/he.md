# WaveSpeed שדרוג תמונה

צומת WaveSpeed Image Upscale משתמש בשירות AI חיצוני כדי להעלות את הרזולוציה והאיכות של תמונה. הוא מקבל תמונת קלט אחת ומעלה אותה לרזולוציית יעד גבוהה יותר, כגון 2K, 4K או 8K, ומפיק תוצאה חדה ומפורטת יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ה-AI שיש להשתמש בו להעלאת רזולוציה. "SeedVR2" ו-"Ultimate" מציעים רמות איכות ותמחור שונות. | STRING | כן | `"SeedVR2"`<br>`"Ultimate"` |
| `image` | תמונת הקלט שיש להעלות ברזולוציה. נדרשת תמונה אחת בדיוק. | IMAGE | כן | |
| `target_resolution` | רזולוציית הפלט הרצויה עבור התמונה המוגדלת. | STRING | כן | `"2K"`<br>`"4K"`<br>`"8K"` |

**הערה:** צומת זה דורש תמונת קלט אחת בדיוק. אספקת אצווה של תמונות תגרום לשגיאה.
