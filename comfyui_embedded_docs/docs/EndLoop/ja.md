# EndLoop

End Loop はループブロックの終端を示します。ループ本体の最後のノードが生成した値を収集し、`accumulate` 設定に応じて最終イテレーションのみ、またはすべてのイテレーションを返します。また、次のイテレーションを開始できるよう、Start Loop に値を戻します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `output_value` | End Loop によって返される値です。accumulate に従って、最終イテレーションまたはすべてのイテレーションを返します。 | ANY | いいえ | 任意の値型 |
| `next_iteration_value` | 次のイテレーションのために End Loop から Start Loop へ戻される値です。 | ANY | いいえ | 任意の値型 |
| `accumulate` | 有効にすると、すべてのイテレーションから output_value を返します。それ以外の場合は最終イテレーションのみを返します。 | BOOLEAN | いいえ | `true`<br>`false`（デフォルト: `false`） |
| `terminations` | 各イテレーションで必ず実行する必要がある出力を接続します。それらの値は返されません。`termination_1`、`termination_2` などの名前を持つ追加可能なスロットです。 | ANY | いいえ | 0～50 スロット |

注：`terminations` は、最小 0、最大 50 接続の追加可能なスロットのリストです。ここに接続された値は各イテレーションでの実行を強制しますが、返される結果には含まれません。

注：このノードは入力リストノードであるため、その入力はすべてのループイテレーションから収集された値を受け取ります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `outputs` | 最終イテレーションの output_value、または accumulate が有効な場合にイテレーション全体で蓄積された値です。 | ANY（リスト） |
