# EndLoop

End Loop מסמן את סוף בלוק לולאה. הוא אוסף את הערך שנוצר על ידי הצומת האחרון בגוף הלולאה ומחזיר רק את האיטרציה האחרונה או את כל האיטרציות, בהתאם להגדרת `accumulate`, ובמקביל מעביר ערך בחזרה אל Start Loop כדי שהאיטרציה הבאה תוכל להתחיל.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `output_value` | הערך המוחזר על ידי End Loop. הוא מחזיר את האיטרציה האחרונה או את כל האיטרציות בהתאם ל-accumulate. | ANY | לא | כל סוג ערך |
| `next_iteration_value` | הערך הנשלח מ-End Loop בחזרה אל Start Loop עבור האיטרציה הבאה. | ANY | לא | כל סוג ערך |
| `accumulate` | החזר את output_value מכל איטרציה כאשר מופעל; אחרת החזר רק את האיטרציה האחרונה. | BOOLEAN | לא | `true`<br>`false` (ברירת מחדל: `false`) |
| `terminations` | חבר פלטים שחייבים לפעול בכל איטרציה. הערכים שלהם אינם מוחזרים. חריצים ניתנים להרחבה בשמות `termination_1`, `termination_2`, וכן הלאה. | ANY | לא | 0 עד 50 חריצים |

הערה: `terminations` הוא רשימה ניתנת להרחבה של חריצים עם מינימום של 0 ומקסימום של 50 חיבורים. ערכים המחוברים כאן מאלצים ביצוע בכל איטרציה אך אינם חלק מהתוצאה המוחזרת.

הערה: צומת זה הוא צומת רשימת קלטים, ולכן הקלטים שלו מקבלים את הערכים שנאספו מכל איטרציה של הלולאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `outputs` | הערך output_value של האיטרציה האחרונה, או ערכים שנצברו לאורך האיטרציות כאשר accumulate מופעל. | ANY (list) |
