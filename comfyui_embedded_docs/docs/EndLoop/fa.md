# EndLoop

End Loop پایان یک بلوک حلقه را مشخص می‌کند. مقداری را که آخرین گره در بدنه حلقه تولید می‌کند جمع‌آوری می‌کند و بسته به تنظیم `accumulate`، فقط تکرار نهایی یا همه تکرارها را برمی‌گرداند، و همزمان یک مقدار را به Start Loop بازمی‌گرداند تا تکرار بعدی آغاز شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `output_value` | مقداری که End Loop برمی‌گرداند. بسته به `accumulate`، تکرار نهایی یا همه تکرارها را برمی‌گرداند. | ANY | خیر | هر نوع مقدار |
| `next_iteration_value` | مقداری که از End Loop به Start Loop برای تکرار بعدی فرستاده می‌شود. | ANY | خیر | هر نوع مقدار |
| `accumulate` | هنگام فعال بودن، `output_value` را از هر تکرار برگردان؛ در غیر این صورت فقط تکرار نهایی را برگردان. | BOOLEAN | خیر | `true`<br>`false` (پیش‌فرض: `false`) |
| `terminations` | خروجی‌هایی را متصل کنید که باید در هر تکرار اجرا شوند. مقادیر آن‌ها برگردانده نمی‌شوند. اسلات‌های قابل‌افزایش با نام‌های `termination_1`، `termination_2` و به همین ترتیب. | ANY | خیر | 0 تا 50 اسلات |

توجه: `terminations` یک فهرست قابل‌افزایش از اسلات‌ها با حداقل 0 و حداکثر 50 اتصال است. مقادیری که اینجا متصل می‌شوند، اجرا را در هر تکرار اجباری می‌کنند اما بخشی از نتیجه برگردانده‌شده نیستند.

توجه: این گره یک گره فهرست ورودی است، بنابراین ورودی‌های آن مقادیر جمع‌آوری‌شده از هر تکرار حلقه را دریافت می‌کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `outputs` | مقدار `output_value` تکرار نهایی، یا مقادیر جمع‌آوری‌شده در طول تکرارها هنگام فعال بودن `accumulate`. | ANY (list) |
