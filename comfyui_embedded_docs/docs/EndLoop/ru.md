# EndLoop

End Loop обозначает конец блока цикла. Он собирает значение, созданное последним узлом в теле цикла, и возвращает либо только последнюю итерацию, либо каждую итерацию, в зависимости от настройки `accumulate`, а также передаёт значение обратно в Start Loop, чтобы могла начаться следующая итерация.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `output_value` | Значение, возвращаемое End Loop. Возвращает последнюю итерацию или все итерации в соответствии с accumulate. | ANY | Нет | Любой тип значения |
| `next_iteration_value` | Значение, отправляемое из End Loop обратно в Start Loop для следующей итерации. | ANY | Нет | Любой тип значения |
| `accumulate` | Если включено, возвращать output_value из каждой итерации; иначе возвращать только последнюю итерацию. | BOOLEAN | Нет | `true`<br>`false` (по умолчанию: `false`) |
| `terminations` | Подключите выходы, которые должны выполняться на каждой итерации. Их значения не возвращаются. Расширяемые слоты с именами `termination_1`, `termination_2` и так далее. | ANY | Нет | от 0 до 50 слотов |

Примечание: `terminations` — это расширяемый список слотов с минимумом 0 и максимумом 50 подключений. Значения, подключённые сюда, заставляют выполнять узел на каждой итерации, но не входят в возвращаемый результат.

Примечание: Этот узел является узлом списка входов, поэтому его входы получают собранные значения из каждой итерации цикла.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `outputs` | Значение `output_value` последней итерации или значения, накопленные за все итерации, когда включён accumulate. | ANY (list) |
