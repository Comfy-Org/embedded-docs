# EndLoop

تحدد عقدة End Loop نهاية كتلة الحلقة. تجمع القيمة التي أنتجتها العقدة الأخيرة في جسم الحلقة، وتُعيد إما التكرار النهائي فقط أو كل تكرار، حسب إعداد `accumulate`، مع تمرير قيمة أيضًا إلى Start Loop كي يبدأ التكرار التالي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `output_value` | القيمة التي تعيدها End Loop. تُعيد التكرار النهائي أو جميع التكرارات وفقًا لـ `accumulate`. | ANY | لا | أي نوع قيمة |
| `next_iteration_value` | القيمة المُرسَلة من End Loop عائدةً إلى Start Loop للتكرار التالي. | ANY | لا | أي نوع قيمة |
| `accumulate` | إرجاع `output_value` من كل تكرار عند تمكينه؛ وإلا يُعاد التكرار النهائي فقط. | BOOLEAN | لا | `true`<br>`false` (الافتراضي: `false`) |
| `terminations` | وصّل المخرجات التي يجب تنفيذها في كل تكرار. لا تُعاد قيمها. خانات قابلة للتوسعة بأسماء `termination_1`، `termination_2`، وهكذا. | ANY | لا | 0 إلى 50 خانة |

ملاحظة: `terminations` قائمة خانات قابلة للتوسعة بحد أدنى 0 وحد أقصى 50 اتصالًا. القيم الموصولة هنا تفرض التنفيذ في كل تكرار، لكنها ليست جزءًا من النتيجة المُعادة.

ملاحظة: هذه العقدة هي عقدة قائمة مدخلات، لذا تستقبل مدخلاتها القيم المجمّعة من كل تكرار في الحلقة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `outputs` | قيمة `output_value` الخاصة بالتكرار النهائي، أو القيم المجمّعة عبر التكرارات عند تمكين `accumulate`. | ANY (list) |
