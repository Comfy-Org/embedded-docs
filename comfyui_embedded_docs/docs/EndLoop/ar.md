# EndLoop

End Loop يحدد نهاية كتلة حلقة. يجمع القيمة الناتجة عن آخر عقدة في جسم الحلقة ويعيد إما التكرار النهائي فقط أو كل تكرار، حسب إعداد `accumulate`، مع تمرير قيمة أيضًا إلى Start Loop حتى يبدأ التكرار التالي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `output_value` | القيمة التي يعيدها End Loop. يعيد التكرار النهائي أو كل التكرارات وفقًا لـ accumulate. | ANY | لا | أي نوع قيمة |
| `next_iteration_value` | القيمة المُرسَلة من End Loop إلى Start Loop للتكرار التالي. | ANY | لا | أي نوع قيمة |
| `accumulate` | إرجاع output_value من كل تكرار عند التمكين؛ وإلا يتم إرجاع التكرار النهائي فقط. | BOOLEAN | لا | `true`<br>`false` (الافتراضي: `false`) |
| `terminations` | وصّل المخرجات التي يجب تنفيذها في كل تكرار. لا يتم إرجاع قيمها. خانات قابلة للتوسيع باسم `termination_1` و`termination_2` وهكذا. | ANY | لا | من 0 إلى 50 خانة |

ملاحظة: `terminations` هي قائمة خانات قابلة للتوسيع بحد أدنى 0 وحد أقصى 50 اتصالًا. القيم الموصولة هنا تفرض التنفيذ في كل تكرار ولكنها ليست جزءًا من النتيجة المُرجَعة.

ملاحظة: هذه العقدة هي عقدة قائمة مدخلات، لذا تستقبل مدخلاتها القيم المجمعة من كل تكرار في الحلقة.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `outputs` | قيمة output_value الخاصة بالتكرار النهائي، أو القيم المتراكمة عبر التكرارات عند تمكين accumulate. | ANY (list) |
