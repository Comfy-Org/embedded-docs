# LoraLoaderBypassModelOnly

צומת זה מחיל LoRA (Low-Rank Adaptation) על מודל כדי לשנות את התנהגותו, אך משפיע רק על רכיב המודל עצמו. הוא טוען קובץ LoRA מוגדר ומתאים את משקולות המודל בעוצמה נתונה, ומשאיר רכיבים אחרים כמו מקודד הטקסט CLIP ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הבסיס שעליו יוחלו התאמות ה-LoRA. | MODEL | כן | - |
| `lora_name` | שם קובץ ה-LoRA שיש לטעון ולהחיל. האפשרויות מאוכלסות מהקבצים בספריית `loras`. | STRING | כן | (רשימת קבצי LoRA זמינים) |
| `strength_model` | עוצמת ההשפעה של ה-LoRA על משקולות המודל. ערך חיובי מחיל את ה-LoRA, ערך שלילי מחיל את ההפוך, וערך 0 אינו משפיע (ברירת מחדל: 1.0). | FLOAT | כן | -100.0 עד 100.0 |
