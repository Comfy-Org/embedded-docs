# Kling تبدیل متن به ویدیو

گره تبدیل متن به ویدیوی Kling با استفاده از سرویس تولید ویدیوی Kling، متن‌های ورودی را به کلیپ‌های ویدیویی کوتاه تبدیل می‌کند. شما پرامپت‌های مثبت و منفی را همراه با تنظیماتی مانند نسبت تصویر، مقیاس پیکربندی و حالت تولید ارائه می‌دهید و گره، ویدیوی تولیدشده را همراه با شناسه و مدت‌زمان آن بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی مثبت که محتوای موردنظر ویدیو را توصیف می‌کند. ورودی چندخطی. نمی‌تواند خالی باشد. | STRING | بله | حداکثر ۲۵۰۰ کاراکتر |
| `negative_prompt` | پرامپت متنی منفی که مشخص می‌کند از چه چیزهایی در ویدیو اجتناب شود. ورودی چندخطی. می‌تواند خالی بماند. | STRING | بله | حداکثر ۲۵۰۰ کاراکتر |
| `cfg_scale` | مقدار مقیاس پیکربندی که کنترل می‌کند ویدیو چقدر از پرامپت پیروی کند (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 تا 1.0 |
| `aspect_ratio` | تنظیم نسبت تصویر ویدیو (پیش‌فرض: "16:9"). | COMBO | خیر | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `mode` | پیکربندی مورد استفاده برای تولید ویدیو با این قالب: حالت / مدت‌زمان / نام_مدل (پیش‌فرض: "pro mode / 5s duration / kling-v2-5-turbo"). حالت ۵ ثانیه‌ای 0.35 دلار آمریکا و حالت ۱۰ ثانیه‌ای 0.70 دلار آمریکا هزینه دارد. | COMBO | خیر | `"pro mode / 5s duration / kling-v2-5-turbo"`<br>`"pro mode / 10s duration / kling-v2-5-turbo"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | ویدیوی تولیدشده. | VIDEO |
| `video_id` | شناسه یکتای ویدیوی تولیدشده. | STRING |
| `duration` | اطلاعات مدت‌زمان ویدیوی تولیدشده. | STRING |
