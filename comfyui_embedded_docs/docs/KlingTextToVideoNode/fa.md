# Kling تبدیل متن به ویدیو

گره Kling Text to Video با استفاده از API تولید ویدیوی Kling، ویدیوهایی را از توصیف‌های متنی تولید می‌کند. این گره پرامپت و تنظیمات (نسبت ابعاد، حالت تولید و مقیاس CFG) را به API می‌فرستد، منتظر می‌ماند تا وظیفه تولید کامل شود، و سپس ویدیوی حاصل را همراه با شناسه و مدت‌زمان آن بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی مثبت | STRING | بله | حداکثر 2500 کاراکتر |
| `negative_prompt` | پرامپت متنی منفی | STRING | خیر | حداکثر 2500 کاراکتر |
| `cfg_scale` | مقدار مقیاس پیکربندی که کنترل می‌کند ویدیو تا چه اندازه از پرامپت پیروی کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 تا 1.0 |
| `aspect_ratio` | تنظیم نسبت ابعاد ویدیو (پیش‌فرض: "16:9") | COMBO | خیر | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | پیکربندی مورد استفاده برای تولید ویدیو با قالب: mode / duration / model_name (پیش‌فرض: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | خیر | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

توجه: پارامتر `prompt` الزامی است و نباید خالی باشد. هر دو پارامتر `prompt` و `negative_prompt` حداکثر به 2500 کاراکتر محدود هستند. گزینه `mode` با مدت 10 ثانیه هزینه بیشتری نسبت به گزینه 5 ثانیه دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `output` | خروجی ویدیوی تولیدشده | VIDEO |
| `video_id` | شناسه یکتا برای ویدیوی تولیدشده | STRING |
| `duration` | اطلاعات مدت‌زمان ویدیوی تولیدشده | STRING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/KlingTextToVideoNode/fa.md)
