# Kling: текст в видео

Узел Kling Text to Video преобразует текстовые промпты в короткие видеоклипы с помощью сервиса генерации видео Kling. Вы предоставляете положительные и отрицательные промпты, а также такие настройки, как соотношение сторон, масштаб конфигурации и режим генерации, а узел возвращает сгенерированное видео с его идентификатором и продолжительностью.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `prompt` | Положительный текстовый промпт, описывающий желаемое содержимое видео. Многострочный ввод. Не может быть пустым. | STRING | Да | Максимум 2500 символов |
| `negative_prompt` | Отрицательный текстовый промпт, описывающий, чего следует избегать в видео. Многострочный ввод. Может оставаться пустым. | STRING | Да | Максимум 2500 символов |
| `cfg_scale` | Значение масштаба конфигурации, которое контролирует, насколько точно видео следует промпту (по умолчанию: 1.0). | FLOAT | Нет | 0.0 to 1.0 |
| `aspect_ratio` | Настройка соотношения сторон видео (по умолчанию: "16:9"). | COMBO | Нет | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `mode` | Конфигурация для генерации видео в формате: режим / продолжительность / model_name (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo"). Режим 5s стоит 0,35 доллара США, режим 10s — 0,70 доллара США. | COMBO | Нет | `"pro mode / 5s duration / kling-v2-5-turbo"`<br>`"pro mode / 10s duration / kling-v2-5-turbo"` |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `output` | Сгенерированный видеовыход. | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео. | STRING |
| `duration` | Информация о продолжительности сгенерированного видео. | STRING |
