# Kling: текст в видео

Узел Kling Text to Video генерирует видео из текстовых описаний с помощью API генерации видео Kling. Он отправляет промпт и настройки (соотношение сторон, режим генерации и масштаб CFG) в API, ожидает завершения задачи генерации, а затем возвращает полученное видео вместе с его ID и длительностью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Положительный текстовый промпт | STRING | Да | Максимум 2500 символов |
| `negative_prompt` | Негативный текстовый промпт | STRING | Нет | Максимум 2500 символов |
| `cfg_scale` | Значение масштаба CFG, которое определяет, насколько точно видео следует промпту (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 |
| `aspect_ratio` | Настройка соотношения сторон видео (по умолчанию: "16:9") | COMBO | Нет | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | Конфигурация, используемая для генерации видео, в формате: mode / duration / model_name (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | Нет | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

Примечание: Параметр `prompt` является обязательным и не должен быть пустым. Как `prompt`, так и `negative_prompt` ограничены максимумом в 2500 символов. Опция `mode` с длительностью 10 секунд стоит дороже, чем опция с длительностью 5 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Информация о длительности сгенерированного видео | STRING |
