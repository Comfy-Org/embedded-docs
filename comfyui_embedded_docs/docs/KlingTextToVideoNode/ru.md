# Kling: текст в видео

Узел Kling Text to Video генерирует видео по текстовым описаниям с помощью API генерации видео Kling. Он отправляет в API запрос и настройки (соотношение сторон, режим генерации и масштаб CFG), ожидает завершения задачи генерации, а затем возвращает полученное видео вместе с его идентификатором и длительностью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Положительный текстовый запрос, описывающий желаемое содержимое видео | STRING | Да | Максимум 2500 символов |
| `negative_prompt` | Отрицательный текстовый запрос, описывающий, чего следует избегать в видео | STRING | Нет | Максимум 2500 символов |
| `cfg_scale` | Значение масштаба конфигурации, которое определяет, насколько точно видео следует запросу (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0 |
| `aspect_ratio` | Настройка соотношения сторон видео (по умолчанию: "16:9") | COMBO | Нет | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | Конфигурация для генерации видео в формате: режим / длительность / имя модели (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | Нет | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

Примечание: параметр `prompt` является обязательным и не должен быть пустым. Параметры `prompt` и `negative_prompt` ограничены максимумом 2500 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Информация о длительности сгенерированного видео | STRING |
