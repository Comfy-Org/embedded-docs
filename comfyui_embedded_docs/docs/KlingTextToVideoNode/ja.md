# Kling テキストからビデオへ

Kling Text to Video ノードは、Kling 動画生成サービスを使用して、テキストプロンプトを短い動画クリップに変換します。ポジティブプロンプトとネガティブプロンプトに加えて、アスペクト比、設定スケール、生成モードなどの設定を指定すると、ノードは生成された動画をその識別子と再生時間とともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成したい動画の内容を説明するポジティブなテキストプロンプトです。複数行での入力に対応しています。空にすることはできません。 | STRING | はい | 最大2500文字 |
| `negative_prompt` | 動画で避けたい内容を説明するネガティブなテキストプロンプトです。複数行での入力に対応しています。空のままにすることもできます。 | STRING | はい | 最大2500文字 |
| `cfg_scale` | 動画がプロンプトにどの程度忠実に従うかを制御する設定スケール値です（デフォルト: 1.0）。 | FLOAT | いいえ | 0.0 to 1.0 |
| `aspect_ratio` | 動画のアスペクト比設定です（デフォルト: "16:9"）。 | COMBO | いいえ | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `mode` | 形式「モード / 再生時間 / モデル名」に従った動画生成に使用する設定です（デフォルト: "pro mode / 5s duration / kling-v2-5-turbo"）。5秒モードはUSD 0.35、10秒モードはUSD 0.70の費用がかかります。 | COMBO | いいえ | `"pro mode / 5s duration / kling-v2-5-turbo"`<br>`"pro mode / 10s duration / kling-v2-5-turbo"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画の出力です。 | VIDEO |
| `video_id` | 生成された動画の一意の識別子です。 | STRING |
| `duration` | 生成された動画の再生時間情報です。 | STRING |
