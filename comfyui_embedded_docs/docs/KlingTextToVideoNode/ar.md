# كليينج تحويل النص إلى فيديو

تقوم عقدة Kling Text to Video بتحويل المطالبات النصية إلى مقاطع فيديو قصيرة باستخدام خدمة توليد الفيديو من Kling. يمكنك تقديم مطالبات موجبة وسالبة إلى جانب إعدادات مثل نسبة الأبعاد، ومقياس الإعداد، ووضع التوليد، وتقوم العقدة بإرجاع الفيديو المُولّد مع معرّفه ومدته.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | مطالبة نصية موجبة تصف محتوى الفيديو المطلوب. إدخال متعدد الأسطر. لا يمكن أن تكون فارغة. | STRING | نعم | 2500 حرف كحد أقصى |
| `negative_prompt` | مطالبة نصية سالبة تصف ما يجب تجنبه في الفيديو. إدخال متعدد الأسطر. يمكن تركها فارغة. | STRING | نعم | 2500 حرف كحد أقصى |
| `cfg_scale` | قيمة مقياس الإعداد التي تتحكم في مدى التزام الفيديو بالمطالبة (الافتراضي: 1.0). | FLOAT | لا | من 0.0 إلى 1.0 |
| `aspect_ratio` | إعداد نسبة أبعاد الفيديو (الافتراضي: "16:9"). | COMBO | لا | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `mode` | الإعداد المستخدم لتوليد الفيديو وفق الصيغة: الوضع / المدة / اسم النموذج (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo"). تبلغ تكلفة وضع 5 ثوانٍ 0.35 دولارًا أمريكيًا، بينما تبلغ تكلفة وضع 10 ثوانٍ 0.70 دولارًا أمريكيًا. | COMBO | لا | `"pro mode / 5s duration / kling-v2-5-turbo"`<br>`"pro mode / 10s duration / kling-v2-5-turbo"` |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | مخرج الفيديو المُولّد. | VIDEO |
| `video_id` | معرّف فريد للفيديو المُولّد. | STRING |
| `duration` | معلومات مدة الفيديو المُولّد. | STRING |
