# كليينج تحويل النص إلى فيديو

تُولّد عقدة Kling Text to Video مقاطع فيديو من الأوصاف النصية باستخدام واجهة برمجة تطبيقات توليد الفيديو Kling. وهي ترسل الموجّه والإعدادات (نسبة الأبعاد، ووضع التوليد، ومقياس CFG) إلى واجهة API، وتنتظر اكتمال مهمة التوليد، ثم تُعيد الفيديو الناتج مع مُعرّفه ومدته.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجّه نصي إيجابي | STRING | نعم | 2500 حرف كحد أقصى |
| `negative_prompt` | موجّه نصي سلبي | STRING | لا | 2500 حرف كحد أقصى |
| `cfg_scale` | قيمة مقياس الإعداد التي تتحكم في مدى التزام الفيديو بالموجّه (الافتراضي: 1.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `aspect_ratio` | إعداد نسبة أبعاد الفيديو (الافتراضي: "16:9") | COMBO | لا | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | التكوين المستخدم لتوليد الفيديو وفق التنسيق: mode / duration / model_name (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | لا | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

ملاحظة: المعامل `prompt` مطلوب ويجب ألا يكون فارغًا. يقتصر كل من `prompt` و`negative_prompt` على 2500 حرف كحد أقصى. خيار `mode` لمدة 10 ثوانٍ يكلّف أكثر من خيار 5 ثوانٍ.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | مخرجات الفيديو المولّد | VIDEO |
| `video_id` | معرّف فريد للفيديو المولّد | STRING |
| `duration` | معلومات المدة الخاصة بالفيديو المولّد | STRING |
