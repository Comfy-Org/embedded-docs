# كليينج تحويل النص إلى فيديو

عقدة **Kling Text to Video** تولّد مقاطع فيديو من الأوصاف النصية باستخدام واجهة برمجة التطبيقات API لتوليد الفيديو من Kling. ترسل هذه العقدة الموجه والإعدادات (نسبة العرض إلى الارتفاع، وضع التوليد، وقيمة مقياس CFG) إلى الواجهة، وتنتظر اكتمال مهمة التوليد، ثم تعيد الفيديو الناتج مع معرّفه ومدته.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجّه نصي إيجابي يصف محتوى الفيديو المطلوب | STRING | نعم | بحد أقصى 2500 حرف |
| `negative_prompt` | موجّه نصي سلبي يصف ما يجب تجنّبه في الفيديو | STRING | لا | بحد أقصى 2500 حرف |
| `cfg_scale` | قيمة مقياس الإعداد التي تتحكم في مدى التزام الفيديو بالموجّه (الافتراضي: 1.0) | FLOAT | لا | 0.0 إلى 1.0 |
| `aspect_ratio` | إعداد نسبة العرض إلى الارتفاع للفيديو (الافتراضي: "16:9") | COMBO | لا | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | الإعداد المستخدم لتوليد الفيديو وفقًا للتنسيق: mode / duration / model_name (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | لا | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

ملاحظة: المعامل `prompt` مطلوب ويجب ألا يكون فارغًا. يقتصر كل من `prompt` و`negative_prompt` على حد أقصى يبلغ 2500 حرف.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | مخرَج الفيديو المولّد | VIDEO |
| `video_id` | معرّف فريد للفيديو المولّد | STRING |
| `duration` | معلومات مدة الفيديو المولّد | STRING |
