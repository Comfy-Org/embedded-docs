# StartLoop

گره Start Loop یک ساختار حلقه‌ای را درون یک گردش‌کار آغاز می‌کند. بدنه حلقه متصل را یک بار در هر تکرار اجرا می‌کند و می‌تواند تکرارها را به سه روش شمارش کند: تعداد ثابت تکرار (simple)، یک بازه نمایه عددی (For)، یا یک گذر به ازای هر آیتم در یک فهرست (List). هر گذر نمایه جاری، پرچم‌های اولین/آخرین و یک مقدار حمل‌شده اختیاری را ارائه می‌دهد که می‌تواند از یک تکرار به تکرار بعدی منتقل شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mode` | حالت تکرار حلقه (پیش‌فرض: "simple"). حالت انتخاب‌شده تعیین می‌کند کدام پارامترهای اضافی نمایش داده شوند. | DYNAMIC_COMBO | بله | `"simple"`<br>`"For"`<br>`"List"` |
| `cache_iterations` | نتایج تکرارهای بدون‌تغییر را از اجراهای قبلی دوباره استفاده کن. برای اجرای دوباره هر تکرار، غیرفعالش کن. پیش‌فرض: false. | BOOLEAN | بله | true<br>false |
| `parent_iteration` | iteration_index را از یک Start Loop بیرونی متصل کنید تا این حلقه تودرتو شود. این ورودی فقط از طریق اتصال قابل تأمین است (یک پیوند الزامی است). | INT | خیر | هر عدد صحیح |
| `initial_iteration_value` | مقداری که در اولین تکرار به‌عنوان current_iteration_value ارائه می‌شود. | ANY (type-matched) | خیر | هر مقدار |

### ورودی‌های حالت Simple

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | تعداد دفعاتی که بدنه حلقه اجرا می‌شود. پیش‌فرض: 4. | INT | بله | حداقل 0 |

### ورودی‌های حالت For

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | نمایه اولین تکرار هنگام استفاده از حالت حلقه For. پیش‌فرض: 0. | INT | بله | هر عدد صحیح |
| `max_iteration` | مقدار توقف انحصاری برای iteration_index در حالت For. پیش‌فرض: 4. | INT | بله | حداکثر 0xffffffffffffffff |
| `step` | اندازه گام نمایه بین هر تکرار هنگام استفاده از حالت حلقه For. پیش‌فرض: 1. | INT | بله | حداقل 1 |

### ورودی‌های حالت List

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `list` | فهرست آیتم‌هایی که حلقه روی آن‌ها تکرار می‌شود. بدنه حلقه یک بار برای هر آیتم اجرا می‌شود. | ANY (type-matched list item) | بله | هر فهرست |

نکته‌ها:

- فقط پارامترهای متعلق به `mode` انتخاب‌شده فعلی نمایش داده شده و استفاده می‌شوند.
- در حالت Simple، نمایه‌های تکرار از 0 تا `num_iterations` منهای 1 اجرا می‌شوند. در حالت For، نمایه‌ها از `start_iteration_index` تا (اما نه شامل) `max_iteration` با افزایش `step` اجرا می‌شوند. در حالت List، یک تکرار برای هر آیتم در `list` اجرا می‌شود.
- `step` نباید 0 باشد؛ مقدار 0 باعث خطا می‌شود. مقادیر کمتر از 1 مجاز نیستند.
- اگر تعداد محاسبه‌شده تکرارها صفر باشد، خروجی `is_last` به‌صورت true گزارش می‌شود و بدنه حلقه اجرا نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `iteration_index` | نمایه تکرار جاری حلقه. | INT |
| `is_first` | در طول اولین تکرار حلقه true است. | BOOLEAN |
| `is_last` | در طول آخرین تکرار حلقه true است. | BOOLEAN |
| `list_item` | آیتم جاری از فهرست هنگام استفاده از حالت List. در حالت‌های Simple و For مقدار None است. | ANY (type-matched) |
| `current_iteration_value` | مقدار حمل‌شده در حلقه برای تکرار جاری: در اولین تکرار initial_iteration_value، سپس در هر تکرار بعدی next_iteration_value از End Loop. | ANY (type-matched) |
