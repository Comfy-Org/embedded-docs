# StartLoop

تبدأ عُقدة Start Loop بنية تكرارية داخل سير العمل. تُشغّل جسم الحلقة المتصل مرة واحدة لكل تكرار، ويمكنها عدّ التكرارات بثلاث طرق: عدد ثابت من المرات (simple)، أو نطاق مؤشر رقمي (For)، أو تمريرة واحدة لكل عنصر في قائمة (List). يعرض كل تمرير المؤشر الحالي، وعلامتي الأول/الأخير، وقيمة اختيارية محمولة يمكن تمريرها من تكرار إلى التالي.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mode` | وضع تكرار الحلقة (افتراضي: "simple"). يحدد الوضع المحدد المعاملات الإضافية التي ستظهر. | DYNAMIC_COMBO | نعم | `"simple"`<br>`"For"`<br>`"List"` |
| `cache_iterations` | إعادة استخدام نتائج التكرارات غير المتغيرة من عمليات التنفيذ السابقة. عطّله لتنفيذ كل تكرار مرة أخرى. افتراضي: false. | BOOLEAN | نعم | true<br>false |
| `parent_iteration` | صِل `iteration_index` من عُقدة Start Loop خارجية لتداخل هذه الحلقة. هذا المدخل إدخال قسري فقط (يتطلب رابطًا). | INT | لا | أي عدد صحيح |
| `initial_iteration_value` | القيمة التي تُعرض باسم `current_iteration_value` في التكرار الأول. | ANY (type-matched) | لا | أي قيمة |

### مدخلات الوضع البسيط

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | عدد مرات تنفيذ جسم الحلقة. افتراضي: 4. | INT | نعم | الحد الأدنى 0 |

### مدخلات وضع For

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | مؤشر التكرار الأول عند استخدام وضع حلقة For. افتراضي: 0. | INT | نعم | أي عدد صحيح |
| `max_iteration` | قيمة الإيقاف الحصرية لمؤشر `iteration_index` في وضع For. افتراضي: 4. | INT | نعم | الحد الأقصى 0xffffffffffffffff |
| `step` | حجم خطوة المؤشر بين كل تكرار عند استخدام وضع حلقة For. افتراضي: 1. | INT | نعم | الحد الأدنى 1 |

### مدخلات وضع List

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `list` | قائمة العناصر التي تتكرر عليها الحلقة. يُنفّذ جسم الحلقة مرة واحدة لكل عنصر. | ANY (type-matched list item) | نعم | أي قائمة |

ملاحظات:

- تظهر وتُستخدم فقط المعاملات التابعة لـ `mode` المحدد حاليًا.
- في الوضع البسيط، تمتد مؤشرات التكرار من 0 حتى `num_iterations` ناقص 1. في وضع For، تمتد المؤشرات من `start_iteration_index` حتى (من دون تضمين) `max_iteration`، وتزداد بمقدار `step`. في وضع List، يُنفّذ تكرار واحد لكل عنصر في `list`.
- يجب ألا تكون قيمة `step` مساوية لـ 0؛ فالقيمة 0 تؤدي إلى رفع خطأ. القيم الأقل من 1 غير مسموح بها.
- إذا كان عدد التكرارات المحسوب صفرًا، فسيُبلّغ عن المخرج `is_last` بالقيمة true ولن يُنفّذ جسم الحلقة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `iteration_index` | مؤشر تكرار الحلقة الحالي. | INT |
| `is_first` | true أثناء التكرار الأول للحلقة. | BOOLEAN |
| `is_last` | true أثناء التكرار الأخير للحلقة. | BOOLEAN |
| `list_item` | العنصر الحالي من القائمة عند استخدام وضع List. لا شيء في وضعي Simple وFor. | ANY (type-matched) |
| `current_iteration_value` | القيمة المحمولة عبر الحلقة للتكرار الحالي: `initial_iteration_value` في التكرار الأول، ثم `next_iteration_value` من End Loop في كل تكرار لاحق. | ANY (type-matched) |
