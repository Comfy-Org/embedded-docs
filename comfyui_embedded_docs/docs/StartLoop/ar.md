# StartLoop

عقدة Start Loop تبدأ بنية تكرارية داخل سير العمل. تُشغّل جسم الحلقة المتصل مرة واحدة لكل تكرار ويمكنها عدّ التكرارات بثلاث طرق: عدد ثابت من المرات (simple)، أو نطاق فهرس رقمي (For)، أو تمريرة واحدة لكل عنصر في قائمة (List). في كل تمريرة، يتم إتاحة الفهرس الحالي، وعلامات الأول/الأخير، وقيمة اختيارية محمولة يمكن تمريرها من تكرار إلى التالي.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mode` | وضع تكرار الحلقة (الافتراضي: "simple"). يحدد الوضع المحدد المعاملات الإضافية التي تظهر. | DYNAMIC_COMBO | نعم | `"simple"`<br>`"For"`<br>`"List"` |
| `cache_iterations` | إعادة استخدام نتائج التكرار غير المتغيرة من التنفيذات السابقة. عطّلها لتنفيذ كل تكرار مرة أخرى. الافتراضي: false. | BOOLEAN | لا | true<br>false |
| `parent_iteration` | اربط iteration_index من Start Loop خارجية لتداخل هذه الحلقة. هذا المدخل إجباري فقط (مطلوب رابط). | INT | لا | أي عدد صحيح |
| `initial_iteration_value` | القيمة التي تُتاح كـ current_iteration_value في التكرار الأول. | ANY (type-matched) | لا | أي قيمة |

### مدخلات الوضع البسيط

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | عدد مرات تنفيذ جسم الحلقة. الافتراضي: 4. | INT | نعم | الحد الأدنى 0 |

### مدخلات وضع For

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | فهرس التكرار الأول عند استخدام وضع For. الافتراضي: 0. | INT | نعم | أي عدد صحيح |
| `max_iteration` | قيمة التوقف الحصرية لـ iteration_index في وضع For. الافتراضي: 4. | INT | نعم | الحد الأقصى 0xffffffffffffffff |
| `step` | حجم خطوة الفهرس بين كل تكرار عند استخدام وضع For. الافتراضي: 1. | INT | نعم | الحد الأدنى 1 |

### مدخلات وضع List

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `list` | قائمة العناصر التي تتكرر عليها الحلقة. يُنفَّذ جسم الحلقة مرة واحدة لكل عنصر. | ANY (type-matched list item) | نعم | أي قائمة |

ملاحظات:

- يتم عرض واستخدام المعاملات التي تنتمي إلى `mode` المحدد حاليًا فقط.
- في الوضع Simple، تمتد فهارس التكرار من 0 حتى `num_iterations` ناقص 1. في وضع For، تمتد الفهارس من `start_iteration_index` حتى (ولكن ليس بما في ذلك) `max_iteration`، وتزداد بمقدار `step`. في وضع List، يتم تنفيذ تكرار واحد لكل عنصر في `list`.
- يجب ألا تكون قيمة `step` مساوية لـ 0؛ القيمة 0 ترفع خطأً. القيم الأقل من 1 غير مسموح بها.
- إذا كان عدد التكرارات المحسوب صفرًا، يتم الإبلاغ عن مخرج `is_last` كـ true ولا يتم تشغيل جسم الحلقة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `iteration_index` | فهرس تكرار الحلقة الحالي. | INT |
| `is_first` | تكون قيمته true خلال التكرار الأول للحلقة. | BOOLEAN |
| `is_last` | تكون قيمته true خلال التكرار الأخير للحلقة. | BOOLEAN |
| `list_item` | العنصر الحالي من القائمة عند استخدام وضع List. لا شيء (None) في وضعي Simple و For. | ANY (type-matched) |
| `current_iteration_value` | القيمة المحمولة عبر الحلقة للتكرار الحالي: initial_iteration_value في التكرار الأول، ثم next_iteration_value من End Loop في كل تكرار لاحق. | ANY (type-matched) |
