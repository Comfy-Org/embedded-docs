# StartLoop

הצומת Start Loop מתחיל מבנה לולאה בתוך זרימת עבודה. הוא מריץ את גוף הלולאה המחובר פעם אחת בכל איטרציה ויכול לספור איטרציות בשלוש דרכים: מספר קבוע של חזרות (simple), טווח אינדקסים מספרי (For), או מעבר אחד לכל פריט ברשימה (List). כל מעבר חושף את האינדקס הנוכחי, דגלי ראשון/אחרון, וערך נישא אופציונלי שניתן להעביר מאיטרציה אחת לבאה אחריה.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mode` | מצב איטרציית הלולאה (ברירת מחדל: "simple"). המצב הנבחר קובע אילו פרמטרים נוספים יוצגו. | DYNAMIC_COMBO | כן | `"simple"`<br>`"For"`<br>`"List"` |
| `cache_iterations` | עשה שימוש חוזר בתוצאות איטרציה שלא השתנו מהרצות קודמות. השבת כדי להריץ שוב כל איטרציה. ברירת מחדל: false. | BOOLEAN | כן | true<br>false |
| `parent_iteration` | חבר `iteration_index` מ-Start Loop חיצוני כדי לקנן את הלולאה הזו. קלט זה הוא קלט כפוי בלבד (נדרש קישור). | INT | לא | כל מספר שלם |
| `initial_iteration_value` | ערך שנחשף בתור `current_iteration_value` באיטרציה הראשונה. | ANY (type-matched) | לא | כל ערך |

### קלטים של מצב Simple

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | מספר הפעמים להריץ את גוף הלולאה. ברירת מחדל: 4. | INT | כן | מינימום 0 |

### קלטים של מצב For

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | האינדקס של האיטרציה הראשונה בעת שימוש במצב לולאת For. ברירת מחדל: 0. | INT | כן | כל מספר שלם |
| `max_iteration` | ערך העצירה הבלעדי עבור `iteration_index` במצב For. ברירת מחדל: 4. | INT | כן | מקסימום 0xffffffffffffffff |
| `step` | גודל צעד האינדקס בין כל איטרציה בעת שימוש במצב לולאת For. ברירת מחדל: 1. | INT | כן | מינימום 1 |

### קלטים של מצב List

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `list` | רשימת פריטים שהלולאה עוברת עליהם. גוף הלולאה מורץ פעם אחת לכל פריט. | ANY (type-matched list item) | כן | כל רשימה |

הערות:

- רק הפרמטרים השייכים ל-`mode` הנבחר כעת מוצגים ונמצאים בשימוש.
- במצב Simple, אינדקסי האיטרציה נעים מ-0 עד `num_iterations` פחות 1. במצב For, האינדקסים נעים מ-`start_iteration_index` עד (אך לא כולל) `max_iteration`, כאשר הם גדלים ב-`step`. במצב List, איטרציה אחת מורצת עבור כל פריט ב-`list`.
- `step` חייב שלא להיות 0; ערך של 0 מעורר שגיאה. ערכים קטנים מ-1 אסורים.
- אם מספר האיטרציות המחושב הוא אפס, הפלט `is_last` מדווח כ-true וגוף הלולאה אינו רץ.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `iteration_index` | האינדקס של איטרציית הלולאה הנוכחית. | INT |
| `is_first` | מתקבל true במהלך האיטרציה הראשונה של הלולאה. | BOOLEAN |
| `is_last` | מתקבל true במהלך האיטרציה האחרונה של הלולאה. | BOOLEAN |
| `list_item` | הפריט הנוכחי מהרשימה בעת שימוש במצב List. אין ערך במצבי Simple ו-For. | ANY (type-matched) |
| `current_iteration_value` | ערך נישא של הלולאה עבור האיטרציה הנוכחית: `initial_iteration_value` באיטרציה הראשונה, ולאחר מכן `next_iteration_value` מ-End Loop בכל איטרציה עוקבת. | ANY (type-matched) |
