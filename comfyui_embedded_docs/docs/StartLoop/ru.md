# StartLoop

Узел Start Loop запускает структуру цикла внутри рабочего процесса. Он выполняет подключённое тело цикла один раз за итерацию и может подсчитывать итерации тремя способами: фиксированное количество повторений (simple), числовой диапазон индексов (For) или один проход на каждый элемент списка (List). На каждом проходе доступны текущий индекс, флаги первого/последнего и необязательное переносимое значение, которое можно передавать с одной итерации на следующую.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `режим` | Режим итерации цикла (по умолчанию: "simple"). Выбранный режим определяет, какие дополнительные параметры отображаются. | DYNAMIC_COMBO | Да | `"simple"`<br>`"For"`<br>`"List"` |
| `кэшировать итерации` | Повторно использовать неизменённые результаты итераций из предыдущих выполнений. Отключите, чтобы выполнять каждую итерацию заново. По умолчанию: false. | BOOLEAN | Да | true<br>false |
| `родительская итерация` | Подключите iteration_index из внешнего Start Loop, чтобы вложить этот цикл. Этот вход поддерживает только принудительное подключение (требуется связь). | INT | Нет | Любое целое число |
| `начальное значение итерации` | Значение, доступное как current_iteration_value на первой итерации. | ANY (type-matched) | Нет | Любое значение |

### Входы режима Simple

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | Количество раз, которое нужно выполнить тело цикла. По умолчанию: 4. | INT | Да | Минимум 0 |

### Входы режима For

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | Индекс первой итерации при использовании режима цикла For. По умолчанию: 0. | INT | Да | Любое целое число |
| `max_iteration` | Верхняя граница (не включительно) для iteration_index в режиме For. По умолчанию: 4. | INT | Да | Максимум 0xffffffffffffffff |
| `step` | Размер шага индекса между итерациями при использовании режима цикла For. По умолчанию: 1. | INT | Да | Минимум 1 |

### Входы режима List

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `list` | Список элементов, по которым итерируется цикл. Тело цикла выполняется один раз для каждого элемента. | ANY (type-matched list item) | Да | Любой список |

Примечания:

- Отображаются и используются только параметры, относящиеся к текущему выбранному `mode`.
- В режиме Simple индексы итераций идут от 0 до `num_iterations` минус 1. В режиме For индексы идут от `start_iteration_index` до (но не включая) `max_iteration`, увеличиваясь на `step`. В режиме List выполняется одна итерация на каждый элемент в `list`.
- `step` не должен быть равен 0; значение 0 вызывает ошибку. Значения меньше 1 не допускаются.
- Если вычисленное количество итераций равно нулю, выход `is_last` сообщается как true, и тело цикла не выполняется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `iteration_index` | Индекс текущей итерации цикла. | INT |
| `is_first` | Значение true во время первой итерации цикла. | BOOLEAN |
| `is_last` | Значение true во время последней итерации цикла. | BOOLEAN |
| `list_item` | Текущий элемент из списка при использовании режима List. None в режимах Simple и For. | ANY (type-matched) |
| `current_iteration_value` | Значение, переносимое циклом для текущей итерации: initial_iteration_value на первой итерации, затем next_iteration_value из End Loop на каждой последующей итерации. | ANY (type-matched) |
