# StartLoop

Узел Start Loop запускает структуру цикла внутри рабочего процесса. Он выполняет подключённое тело цикла один раз за итерацию и может подсчитывать итерации тремя способами: фиксированное число повторений (simple), числовой диапазон индексов (For) или один проход на каждый элемент списка (List). На каждом проходе доступны текущий индекс, флаги первого/последнего и необязательное переносимое значение, которое можно передавать от одной итерации к следующей.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mode` | Режим итерации цикла (по умолчанию: "simple"). Выбранный режим определяет, какие дополнительные параметры отображаются. | DYNAMIC_COMBO | Да | `"simple"`<br>`"For"`<br>`"List"` |
| `cache_iterations` | Повторно использовать неизменённые результаты итераций из предыдущих выполнений. Отключите, чтобы выполнять каждую итерацию заново. По умолчанию: false. | BOOLEAN | Нет | true<br>false |
| `parent_iteration` | Подключите iteration_index от внешнего Start Loop, чтобы вложить этот цикл. Этот вход доступен только как принудительный вход (требуется связь). | INT | Нет | Любое целое число |
| `initial_iteration_value` | Значение, доступное как current_iteration_value на первой итерации. | ANY (type-matched) | Нет | Любое значение |

### Входы режима Simple

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | Количество раз выполнения тела цикла. По умолчанию: 4. | INT | Да | Минимум 0 |

### Входы режима For

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | Индекс первой итерации при использовании режима цикла For. По умолчанию: 0. | INT | Да | Любое целое число |
| `max_iteration` | Исключающее значение остановки для iteration_index в режиме For. По умолчанию: 4. | INT | Да | Максимум 0xffffffffffffffff |
| `step` | Размер шага индекса между итерациями при использовании режима цикла For. По умолчанию: 1. | INT | Да | Минимум 1 |

### Входы режима List

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `list` | Список элементов, по которым итерируется цикл. Тело цикла выполняется один раз для каждого элемента. | ANY (type-matched list item) | Да | Любой список |

Примечания:

- Показываются и используются только параметры, относящиеся к текущему выбранному `mode`.
- В режиме Simple индексы итераций идут от 0 до `num_iterations` минус 1. В режиме For индексы идут от `start_iteration_index` до (не включая) `max_iteration`, увеличиваясь на `step`. В режиме List выполняется одна итерация на каждый элемент в `list`.
- `step` не должен быть равен 0; значение 0 вызывает ошибку. Значения меньше 1 не допускаются.
- Если вычисленное количество итераций равно нулю, выход `is_last` считается true, и тело цикла не выполняется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `iteration_index` | Индекс текущей итерации цикла. | INT |
| `is_first` | Значение true во время первой итерации цикла. | BOOLEAN |
| `is_last` | Значение true во время последней итерации цикла. | BOOLEAN |
| `list_item` | Текущий элемент из списка при использовании режима List. В режимах Simple и For — None. | ANY (type-matched) |
| `current_iteration_value` | Переносимое значение цикла для текущей итерации: initial_iteration_value на первой итерации, затем next_iteration_value из End Loop на каждой последующей итерации. | ANY (type-matched) |
