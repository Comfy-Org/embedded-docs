# BriaReseason

Этот узел переносит изображение в другой сезон с помощью Bria. Вся сцена рендерится заново, поэтому пейзаж может измениться не только в пределах сезонных изменений. Bria заново рендерит весь кадр с разрешением около 1 мегапикселя, поэтому результат не совпадает с входным изображением попиксельно.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, которое нужно перенести в другой сезон. Перед отправкой изображения любой альфа-канал удаляется. | IMAGE | Да | - |
| `season` | Сезон, который нужно применить. | COMBO | Да | `"spring"`<br>`"summer"`<br>`"autumn"`<br>`"winter"` |
| `moderation` | Настройки модерации. Определяет, будут ли для этого запроса настроены параметры модерации контента. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы модерации

Эти параметры появляются, когда `moderation` установлен в `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию контента для входного изображения (по умолчанию: false). | BOOLEAN | Нет | true<br>false |
| `visual_output_moderation` | Включает модерацию контента для сгенерированного выходного изображения (по умолчанию: false). | BOOLEAN | Нет | true<br>false |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, заново отрендеренное в выбранном сезоне. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
