# ConvertArrayToString

הצומת Convert Array to String לוקח מערך (רשימה) של פריטים וממיר אותו למחרוזת JSON מעוצבת. הדבר שימושי כאשר יש צורך לבצע סריאליזציה של נתוני מערך לצורך תצוגה, רישום ביומן, או העברה למערכות אחרות שמצפות לקלט מסוג מחרוזת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `array` | המערך שיש להמיר למחרוזת JSON | ARRAY | כן | - |
| `indent` | מספר הרווחים לכל רמת הזחה. 0 מפיק מחרוזת קומפקטית בשורה אחת (ברירת מחדל: 2) | INT | לא | 0 עד 8 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `STRING` | המערך שהומר למחרוזת בפורמט JSON | STRING |
