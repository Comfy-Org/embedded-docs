# Recraft 影像修補

此節點會根據文字提示與遮罩，修改影像的特定區域。它使用 Recraft API 智慧地僅編輯遮罩區域，同時保持影像其餘部分不變。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要修改的輸入影像 | IMAGE | 是 | - |
| `遮罩` | 定義影像中哪些區域應被修改的遮罩 | MASK | 是 | - |
| `提示詞` | 影像生成提示詞（預設為空字串，最大長度：1000 字元） | STRING | 是 | - |
| `數量` | 要產生的影像數量（預設值：1，最小值：1，最大值：6） | INT | 是 | 1-6 |
| `種子` | 用於決定節點是否應重新執行的種子；無論種子為何，實際結果都是非確定性的（預設值：0） | INT | 是 | 0-18446744073709551615 |
| `Recraft 風格` | Recraft API 的選用風格參數。若未提供，預設為「realistic_image」風格 | STYLEV3 | 否 | - |
| `負向提示詞` | 圖片中不需要元素的選用文字描述（預設為空字串） | STRING | 否 | - |

*注意：`image` 與 `mask` 必須一起提供，才能進行修補操作。遮罩會自動調整大小以符合影像尺寸。`prompt` 會經過驗證，且最大長度為 1000 字元。如果使用了 Infinite Style Library 中的 `style_id`，請確保它不是向量藝術風格（Vector art style），因為這可能導致 API 回傳 SVG 資料而非影像。*
