# بازسازی تصویر Recraft

این گره نواحی خاصی از یک تصویر را بر اساس یک پرامپت متنی و یک ماسک تغییر می‌دهد. این گره از Recraft API برای ویرایش هوشمندانه فقط نواحی ماسک‌شده استفاده می‌کند و بقیه تصویر را بدون تغییر نگه می‌دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که باید تغییر کند | IMAGE | بله | - |
| `ماسک` | ماسکی که نواحی موردنظر برای تغییر در تصویر را مشخص می‌کند | MASK | بله | - |
| `پرامپت` | پرامپت برای تولید تصویر (پیش‌فرض: رشته خالی، حداکثر طول: 1000 کاراکتر) | STRING | بله | - |
| `تعداد` | تعداد تصاویری که باید تولید شود (پیش‌فرض: 1، حداقل: 1، حداکثر: 6) | INT | بله | 1-6 |
| `seed` | مقدار seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed نامعین هستند (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `سبک Recraft` | پارامتر سبک اختیاری برای Recraft API. اگر ارائه نشود، به‌طور پیش‌فرض از سبک «realistic_image» استفاده می‌شود | STYLEV3 | خیر | - |
| `پرامپت منفی` | توضیح متنی اختیاری از عناصر نامطلوب در یک تصویر (پیش‌فرض: رشته خالی) | STRING | خیر | - |

*توجه: برای عملکرد صحیح عملیات inpainting، باید `image` و `mask` با هم ارائه شوند. ماسک به‌طور خودکار تغییر اندازه داده می‌شود تا با ابعاد تصویر مطابقت یابد. `prompt` اعتبارسنجی می‌شود و حداکثر طول آن 1000 کاراکتر است. اگر از `style_id` موجود در کتابخانه سبک بینهایت استفاده می‌کنید، مطمئن شوید که سبک هنر وکتوری نباشد، زیرا ممکن است API به جای تصویر، داده SVG بازگرداند.*

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) اصلاح‌شده تولیدشده بر اساس پرامپت و ماسک. به ازای هر تصویر ورودی ضرب‌در پارامتر `n`، یک تصویر برمی‌گرداند | IMAGE |
