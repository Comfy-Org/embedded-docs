# بازسازی تصویر Recraft

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که قرار است اصلاح شود | IMAGE | بله | - |
| `mask` | ماسکی که مشخص می‌کند کدام نواحی از تصویر باید اصلاح شوند | MASK | بله | - |
| `prompt` | پرامپت تولید تصویر (پیش‌فرض: رشته خالی، حداکثر طول: ۱۰۰۰ کاراکتر) | STRING | بله | - |
| `n` | تعداد تصاویر مورد نظر برای تولید (پیش‌فرض: ۱، حداقل: ۱، حداکثر: ۶) | INT | بله | 1-6 |
| `seed` | دانه (Seed) برای تعیین این‌که گره دوباره اجرا شود یا نه؛ نتایج واقعی بدون توجه به seed قطعی نیستند (پیش‌فرض: ۰) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | پارامتر اختیاری سبک برای Recraft API. اگر ارائه نشود، به‌طور پیش‌فرض از سبک "realistic_image" استفاده می‌شود | STYLEV3 | خیر | - |
| `negative_prompt` | توضیح متنی اختیاری درباره عناصر ناخواسته در تصویر (پیش‌فرض: رشته خالی) | STRING | خیر | - |

*توجه: برای عملکرد inpainting، `image` و `mask` باید با هم ارائه شوند. اندازه ماسک به‌طور خودکار با ابعاد تصویر تطبیق داده می‌شود. `prompt` اعتبارسنجی می‌شود و حداکثر طول آن ۱۰۰۰ کاراکتر است. اگر از `style_id` از کتابخانه سبک بی‌نهایت (Infinite Style Library) استفاده می‌کنید، مطمئن شوید که سبک وکتور (Vector art) نباشد، زیرا ممکن است API به جای تصویر، داده SVG برگرداند.*
