# RecraftImageInpaintingNode

צומת זה משנה אזורים מסוימים בתמונה בהתבסס על הנחיית טקסט ומסכה. הוא משתמש ב-API של Recraft כדי לערוך באופן חכם רק את האזורים המסומנים במסכה, תוך שמירה על שאר התמונה ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שיש לשנות | IMAGE | כן | - |
| `mask` | המסכה שמגדירה אילו אזורים בתמונה יש לשנות | MASK | כן | - |
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: מחרוזת ריקה, אורך מקסימלי: 1000 תווים) | STRING | כן | - |
| `n` | מספר התמונות ליצירה (ברירת מחדל: 1, מינימום: 1, מקסימום: 6) | INT | כן | 1-6 |
| `seed` | ערך Seed שקובע אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-seed (ברירת מחדל: 0) | INT | כן | 0-18446744073709551615 |
| `recraft_style` | פרמטר סגנון אופציונלי עבור ה-API של Recraft. אם לא מסופק, ברירת המחדל היא סגנון "realistic_image" | STYLEV3 | לא | - |
| `negative_prompt` | תיאור טקסט אופציונלי של אלמנטים לא רצויים בתמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |

*הערה: יש לספק את `image` ואת `mask` יחד כדי שפעולת ה-inpainting תעבוד. המסכה תשתנה אוטומטית בגודלה כדי להתאים לממדי התמונה. ה-`prompt` מאומת ואורכו המקסימלי הוא 1000 תווים. אם משתמשים ב-`style_id` מתוך Infinite Style Library, יש לוודא שהוא אינו סגנון אמנות וקטורית, מכיוון שהדבר עלול לגרום ל-API להחזיר נתוני SVG במקום תמונה.*
