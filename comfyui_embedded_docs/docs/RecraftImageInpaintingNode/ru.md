# Восстановление изображения Recraft

Этот узел изменяет определённые области изображения на основе текстового запроса и маски. Он использует Recraft API для интеллектуального редактирования только замаскированных областей, оставляя остальную часть изображения без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для изменения | IMAGE | Да | - |
| `mask` | Маска, определяющая, какие области изображения должны быть изменены | MASK | Да | - |
| `prompt` | Запрос для генерации изображения (по умолчанию: пустая строка, максимальная длина: 1000 символов) | STRING | Да | - |
| `n` | Количество изображений для генерации (по умолчанию: 1, минимум: 1, максимум: 6) | INT | Да | 1-6 |
| `seed` | Сид для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный параметр стиля для Recraft API. Если не указан, по умолчанию используется стиль "realistic_image" | STYLEV3 | Нет | - |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: пустая строка) | STRING | Нет | - |

*Примечание: `image` и `mask` должны быть предоставлены вместе для работы операции инпейнтинга. Маска будет автоматически изменена до размеров изображения. `prompt` проверяется и имеет максимальную длину 1000 символов. Если используется `style_id` из Infinite Style Library, убедитесь, что это не стиль Vector art, так как это может привести к тому, что API вернёт SVG-данные вместо изображения.*

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изменённое(ые) изображение(я), сгенерированное(ые) на основе запроса и маски. Возвращает одно изображение для каждого входного изображения, умноженное на параметр `n` | IMAGE |
