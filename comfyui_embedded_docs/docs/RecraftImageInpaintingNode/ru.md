# Восстановление изображения Recraft

Этот узел изменяет отдельные области изображения на основе текстового запроса и маски. Он использует API Recraft для интеллектуального редактирования только замаскированных областей, сохраняя остальную часть изображения без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, которое нужно изменить | IMAGE | Да | - |
| `mask` | Маска, определяющая, какие области изображения следует изменить | MASK | Да | - |
| `запрос` | Текстовый запрос для генерации изображения (по умолчанию: пустая строка, максимальная длина: 1000 символов) | STRING | Да | - |
| `n` | Количество изображений для генерации (по умолчанию: 1, минимум: 1, максимум: 6) | INT | Да | 1-6 |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный параметр стиля для API Recraft. Если не указан, по умолчанию используется стиль realistic_image | STYLEV3 | Нет | - |
| `негативный запрос` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: пустая строка) | STRING | Нет | - |

*Примечание: `image` и `mask` должны передаваться вместе для работы операции инпейнтинга. Маска будет автоматически приведена к размерам изображения. `prompt` проверяется и имеет максимальную длину 1000 символов. Если используется `style_id` из библиотеки Infinite Style, убедитесь, что это не стиль векторной графики, поскольку это может привести к тому, что API вернет данные SVG вместо изображения.*

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Измененное изображение (изображения), сгенерированное на основе запроса и маски. Возвращает одно изображение на каждое входное изображение, умноженное на параметр `n` | IMAGE |
