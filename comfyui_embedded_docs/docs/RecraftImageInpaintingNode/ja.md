# Recraft画像インペインティング

このノードは、テキストプロンプトとマスクに基づいて、画像の特定の領域を修正します。Recraft API を使用して、マスクされた領域のみをインテリジェントに編集し、画像の残りの部分は変更しません。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 編集対象の入力画像 | IMAGE | はい | - |
| `mask` | 画像内の編集する領域を定義するマスク | MASK | はい | - |
| `prompt` | 画像生成用のプロンプト（デフォルト: 空文字列、最大長: 1000文字） | STRING | はい | - |
| `n` | 生成する画像の枚数（デフォルト: 1、最小: 1、最大: 6） | INT | はい | 1-6 |
| `seed` | ノードを再実行するか判定するためのシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0） | INT | はい | 0-18446744073709551615 |
| `recraft_style` | Recraft API 用のオプションのスタイルパラメータ。指定しない場合、「realistic_image」スタイルがデフォルトになります | STYLEV3 | いいえ | - |
| `negative_prompt` | 画像内の望ましくない要素のオプションのテキスト説明（デフォルト: 空文字列） | STRING | いいえ | - |

*注：インペインティング操作を機能させるには、`image` と `mask` を一緒に指定する必要があります。マスクは画像寸法に合わせて自動的にリサイズされます。`prompt` は検証され、最大長は1000文字です。Infinite Style Library の `style_id` を使用する場合、Vector アートスタイルではないことを確認してください。Vector アートスタイルを使用すると、API が画像の代わりに SVG データを返す可能性があります。*

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | プロンプトとマスクに基づいて生成された修正済み画像。入力画像ごとに、`n` パラメータを掛けた数の画像を返します。 | IMAGE |
