# إعادة صياغة ترميم الصورة

تعدّل هذه العقدة مناطق محددة من الصورة بناءً على موجه نصي وقناع. وتستخدم Recraft API لتعديل المناطق المغطاة بالقناع فقط بشكل ذكي مع إبقاء باقي الصورة دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المدخلة المراد تعديلها | IMAGE | نعم | - |
| `قناع` | القناع الذي يحدد مناطق الصورة التي يجب تعديلها | MASK | نعم | - |
| `الوصف` | الموجه النصي لتوليد الصورة (الافتراضي: سلسلة فارغة، الحد الأقصى للطول: 1000 حرف) | STRING | نعم | - |
| `عدد` | عدد الصور المراد توليدها (الافتراضي: 1، الحد الأدنى: 1، الحد الأقصى: 6) | INT | نعم | 1-6 |
| `بذرة` | البذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `نمط إعادة الصياغة` | معلمة النمط الاختيارية لواجهة Recraft API. إذا لم يتم توفيرها، تكون القيمة الافتراضية هي نمط "realistic_image" | STYLEV3 | لا | - |
| `الوصف السلبي` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: سلسلة فارغة) | STRING | لا | - |

*ملاحظة: يجب توفير `image` و `mask` معًا لكي تعمل عملية الاستكمال. سيتم تغيير حجم القناع تلقائيًا ليطابق أبعاد الصورة. يتم التحقق من `prompt` ويبلغ الحد الأقصى لطوله 1000 حرف. إذا تم استخدام `style_id` من مكتبة الأنماط اللانهائية، فتأكد من أنه ليس نمط فن متجهي، فقد يؤدي ذلك إلى قيام API بإرجاع بيانات SVG بدلاً من صورة.*

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصور المعدلة المولدة بناءً على الموجه النصي والقناع. تُرجع صورة واحدة لكل صورة مدخلة مضروبة في المعامل `n` | IMAGE |
