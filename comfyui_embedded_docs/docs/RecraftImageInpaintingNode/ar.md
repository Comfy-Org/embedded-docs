# إعادة صياغة ترميم الصورة

```markdown
تقوم هذه العقدة بتعديل مناطق محددة من الصورة بناءً على موجه نصي وقناع. تستخدم واجهة برمجة تطبيقات Recraft لتحرير المناطق المقنعة فقط بذكاء مع الحفاظ على بقية الصورة دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة التي سيتم تعديلها | IMAGE | نعم | - |
| `mask` | القناع الذي يحدد المناطق التي يجب تعديلها في الصورة | MASK | نعم | - |
| `prompt` | الموجه لتوليد الصورة (الافتراضي: سلسلة فارغة، الحد الأقصى للطول: 1000 حرف) | STRING | نعم | - |
| `n` | عدد الصور المطلوب توليدها (الافتراضي: 1، الحد الأدنى: 1، الحد الأقصى: 6) | INT | نعم | 1-6 |
| `seed` | بذرة لتحديد ما إذا كانت العقدة يجب أن تُعاد تشغيلها؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `recraft_style` | معامل نمط اختياري لواجهة برمجة تطبيقات Recraft. إذا لم يُقدَّم، فسيتم استخدام النمط الافتراضي "realistic_image" | STYLEV3 | لا | - |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: سلسلة فارغة) | STRING | لا | - |

*ملاحظة: يجب تقديم `image` و `mask` معًا حتى تعمل عملية الترميم الداخلي (inpainting). سيتم تغيير حجم القناع تلقائيًا ليتوافق مع أبعاد الصورة. يتم التحقق من `prompt` ويبلغ الحد الأقصى للطول 1000 حرف. إذا تم استخدام `style_id` من مكتبة الأنماط اللانهائية، فتأكد من أنه ليس نمط رسم متجهي، فقد يتسبب ذلك في إرجاع واجهة البرمجة لبيانات SVG بدلاً من صورة.*

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-----------|-------------|
| `image` | الصورة (الصور) المعدلة المولدة بناءً على الموجه والقناع. تُرجع صورة واحدة لكل صورة مدخلة مضروبة في معامل `n` | IMAGE |
```
