# Пользовательский сэмплер (Расширенный)

Узел `SamplerCustomAdvanced` выполняет продвинутое латентное сэмплирование с использованием пользовательских конфигураций шума, управления (guidance) и сэмплирования. Он обрабатывает латентное изображение через направляемый процесс сэмплирования с настраиваемой генерацией шума и расписаниями сигм, создавая как итоговый результат сэмплирования, так и очищенную от шума версию, когда это возможно.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `noise` | Генератор шума, который создает начальный шумовой паттерн и зерно (seed) для процесса сэмплирования. | NOISE | Да | - |
| `guider` | Модель управления (guidance), которая направляет процесс сэмплирования к желаемым результатам. | GUIDER | Да | - |
| `sampler` | Алгоритм сэмплирования, определяющий, как происходит перемещение по латентному пространству во время генерации. | SAMPLER | Да | - |
| `sigmas` | Расписание сигм, которое управляет уровнями шума на протяжении шагов сэмплирования. | SIGMAS | Да | - |
| `latent_image` | Начальное латентное представление, служащее отправной точкой для сэмплирования. Поддерживает необязательный `noise_mask` для выборочного удаления шума, а также необязательные ключи `downscale_ratio_spacial` и `downscale_ratio_temporal` для продвинутой обработки латентных представлений. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Итоговое латентное представление после завершения процесса сэмплирования. Все ключи `downscale_ratio_spacial` и `downscale_ratio_temporal` из входного латентного представления удаляются из этого результата. | LATENT |
| `denoised_output` | Очищенная от шума версия результата, когда процесс сэмплирования создает промежуточное чистое предсказание (x0); в противном случае возвращает то же, что и `output`. Когда доступно, это наилучшая оценка модели чистого латентного представления на каждом шаге. | LATENT |
