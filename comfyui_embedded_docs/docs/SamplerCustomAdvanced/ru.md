# Пользовательский сэмплер (Расширенный)

Узел SamplerCustomAdvanced выполняет расширенное сэмплирование в латентном пространстве с использованием пользовательских настроек шума, управления и сэмплирования. Он обрабатывает латентное изображение в процессе управляемого сэмплирования с настраиваемым генератором шума и расписанием сигм, создавая как итоговый сэмплированный выход, так и денойзированную версию, когда она доступна.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `шум` | Генератор шума, который задаёт начальный шаблон шума и seed для процесса сэмплирования | NOISE | Да | - |
| `гид` | Модель управления, которая направляет процесс сэмплирования к желаемому результату | GUIDER | Да | - |
| `сэмплер` | Алгоритм сэмплирования, определяющий, как латентное пространство обходится во время генерации | SAMPLER | Да | - |
| `сигмы` | Расписание сигм, которое управляет уровнями шума на протяжении шагов сэмплирования | SIGMAS | Да | - |
| `латентное_изображение` | Начальное латентное представление, служащее отправной точкой для сэмплирования. Поддерживает необязательный ключ `noise_mask` для выборочного денойзинга, а также необязательные ключи `downscale_ratio_spacial` и `downscale_ratio_temporal` для расширенной обработки латентов | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Итоговое сэмплированное латентное представление после завершения процесса сэмплирования. Любые ключи `downscale_ratio_spacial` или `downscale_ratio_temporal` из входного латента удаляются из этого выхода | LATENT |
| `denoised_output` | Денойзированная версия выхода, когда процесс сэмплирования создаёт промежуточный чистый прогноз (x0); в противном случае возвращает то же, что и `output`. Когда доступно, представляет наилучшую оценку моделью чистого латента | LATENT |
