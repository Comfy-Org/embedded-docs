# Пользовательский сэмплер (Расширенный)

Узел SamplerCustomAdvanced выполняет продвинутое семплирование в латентном пространстве с использованием пользовательского шума, направляющего воздействия (guidance) и конфигураций сэмплера. Он обрабатывает латентное изображение через процесс направленного семплирования с настраиваемой генерацией шума и расписанием сигм, формируя как итоговый результат семплирования, так и его версию после денойзинга, если она доступна.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `шум` | Генератор шума, который создаёт начальный шумовой паттерн и сид (seed) для процесса семплирования | NOISE | Да | - |
| `гид` | Модель направляющего воздействия, которая направляет процесс семплирования к желаемым результатам | GUIDER | Да | - |
| `сэмплер` | Алгоритм семплирования, определяющий способ перемещения по латентному пространству во время генерации | SAMPLER | Да | - |
| `сигмы` | Расписание сигм, управляющее уровнями шума на каждом шаге семплирования | SIGMAS | Да | - |
| `латентное_изображение` | Исходное латентное представление, служащее отправной точкой для семплирования. Поддерживает необязательный `noise_mask` для выборочного денойзинга, а также необязательные ключи `downscale_ratio_spacial` и `downscale_ratio_temporal` для расширенной обработки латентного пространства | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `выход` | Итоговое латентное представление после завершения процесса семплирования. Ключи `downscale_ratio_spacial` и `downscale_ratio_temporal` из входного латентного представления удаляются из этого результата | LATENT |
| `выход без шума` | Версия результата после денойзинга, если в процессе семплирования формируется промежуточное чистое предсказание (x0); в противном случае возвращается то же значение, что и `output`. При наличии этот результат представляет наилучшую оценку модели чистого латентного представления на каждом шаге | LATENT |
