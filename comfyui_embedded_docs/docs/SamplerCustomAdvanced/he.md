# SamplerCustomAdvanced

צומת SamplerCustomAdvanced מבצע דגימה מתקדמת במרחב לטנטי באמצעות רעש, הנחיה ותצורות דגימה מותאמות אישית. הוא מעבד תמונת latent דרך תהליך דגימה מונחה עם מחולל רעש ולוח סיגמות הניתנים להתאמה, ומייצר הן את פלט הדגימה הסופי והן גרסה מנוקה מרעש כאשר היא זמינה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `noise` | מחולל הרעש שמספק את תבנית הרעש הראשונית ואת ה-seed עבור תהליך הדגימה | NOISE | כן | - |
| `guider` | מודל ההנחיה שמכוון את תהליך הדגימה לעבר הפלט הרצוי | GUIDER | כן | - |
| `sampler` | אלגוריתם הדגימה שמגדיר כיצד נעים במרחב הלטנטי במהלך היצירה | SAMPLER | כן | - |
| `sigmas` | לוח הסיגמות ששולט ברמות הרעש לאורך שלבי הדגימה | SIGMAS | כן | - |
| `latent_image` | הייצוג הלטנטי ההתחלתי שמשמש כנקודת התחלה לדגימה. תומך במפתח אופציונלי `noise_mask` להסרת רעש סלקטיבית, ובמפתחות אופציונליים `downscale_ratio_spacial` ו-`downscale_ratio_temporal` לטיפול מתקדם ב-latent | LATENT | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | הייצוג הלטנטי המדוגם הסופי לאחר השלמת תהליך הדגימה. כל מפתחות `downscale_ratio_spacial` או `downscale_ratio_temporal` מה-latent בקלט מוסרים מהפלט הזה | LATENT |
| `denoised_output` | גרסה מנוקה מרעש של הפלט כאשר תהליך הדגימה מפיק חיזוי נקי ביניים (x0), אחרת מחזיר את אותו ערך כמו `output`. כאשר היא זמינה, זה מייצג את האומדן הטוב ביותר של המודל ל-latent הנקי | LATENT |
