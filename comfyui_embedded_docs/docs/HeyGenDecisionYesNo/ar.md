# HeyGen Decision (Yes/No)

اطرق سؤالاً بنعم/لا حول النص أو الصور أو الصوت أو الفيديو الذي توصّله واحصل على قيمة منطقية للتوجيه بناءً عليها. وصّل `result` بعقدة If/Else Switch للاختيار بين مسارين، واقرأ `answer` و`probability` لمعرفة مدى وضوح الإجابة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المراد استخدامه. `heygen-decision-1-turbo` أسرع وأقل تكلفة من `heygen-decision-1` (الافتراضي: `"heygen-decision-1"`). | COMBO | نعم | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | السؤال بنعم/لا حول ما تم توصيله، بحد أقصى 5000 حرف. اطرحه بحيث تكون حالة «yes» هي الحالة التي تتصرّف بناءً عليها (الافتراضي: "Is there a person in the image?"). | STRING | نعم | 1 إلى 5000 حرف |
| `threshold` | احتمالية «yes» التي عندها يصبح `result` مساويًا True؛ الإجابات الواضحة قريبة من 0 أو 1 (الافتراضي: 0.5). | FLOAT | نعم | 0.01 إلى 0.99 (خطوة 0.01) |
| `images` | الصور المراد السؤال عنها، بحد أقصى 4 إجمالًا، مع احتساب كل إطار في الدفعة. تُرقَّم من `image_1` إلى `image_4` بالترتيب عبر المنافذ. | IMAGE | لا | حتى 4 صور |
| `audio_1` | الصوت المراد السؤال عنه، بحد أقصى 30 دقيقة. | AUDIO | لا | حتى 30 دقيقة |
| `video_1` | الفيديو المراد السؤال عنه، بحد أقصى 60 ثانية. | VIDEO | لا | حتى 60 ثانية |
| `text` | النص الذي يدور حوله السؤال، مثل موجّه أو استجابة LLM، بحد أقصى 20000 حرف. | STRING | لا | حتى 20000 حرف |

وصّل واحدًا على الأقل من `text` أو `images` أو `audio_1` أو `video_1`، وأشِر إليها باسم المنفذ داخل السؤال، على سبيل المثال: «هل تُظهر image_2 الشخص نفسه كما في image_1؟».

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `result` | يكون True عندما تبلغ احتمالية «yes» قيمة `threshold`، ويكون False خلاف ذلك. | BOOLEAN |
| `answer` | الحكم كسلسلة نصية `"yes"` أو `"no"`، وفق نفس `threshold` المستخدم في `result`. | STRING |
| `probability` | احتمالية «yes» بين 0 و1. | FLOAT |
