# HeyGen Decision (Yes/No)

Задайте вопрос с ответом «да/нет» о тексте, изображениях, аудио или видео, которые вы подключаете, и получите логическое значение для маршрутизации. Подключите `result` к узлу If/Else Switch, чтобы выбрать один из двух путей, и прочитайте `answer` и `probability`, чтобы увидеть, насколько однозначным был ответ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. `heygen-decision-1-turbo` быстрее и дешевле, чем `heygen-decision-1` (по умолчанию: `"heygen-decision-1"`). | COMBO | Да | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | Вопрос с ответом «да/нет» о том, что подключено, до 5000 символов. Сформулируйте его так, чтобы «yes» соответствовал случаю, для которого вы выполняете действие (по умолчанию: "Is there a person in the image?"). | STRING | Да | от 1 до 5000 символов |
| `threshold` | Вероятность ответа «yes», при которой `result` становится true; однозначные ответы близки к 0 или 1 (по умолчанию: 0.5). | FLOAT | Да | от 0.01 до 0.99 (шаг 0.01) |
| `images` | Изображения, о которых задаётся вопрос; всего до 4, с учётом каждого кадра пакета. Они нумеруются от `image_1` до `image_4` по порядку по всем сокетам. | IMAGE | Нет | до 4 изображений |
| `audio_1` | Аудио, о котором задаётся вопрос, до 30 минут. | AUDIO | Нет | до 30 минут |
| `video_1` | Видео, о котором задаётся вопрос, до 60 секунд. | VIDEO | Нет | до 60 секунд |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | до 20000 символов |

Подключите хотя бы один из `text`, `images`, `audio_1` или `video_1` и ссылайтесь на них по имени сокета в вопросе, например: «Показан ли на image_2 тот же человек, что и на image_1?».

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `result` | Ответ в виде логического значения: true для «yes», false для «no». | BOOLEAN |
| `answer` | Ответ в виде строки `"yes"` или `"no"`. | STRING |
| `probability` | Вероятность ответа «yes» от 0 до 1. | FLOAT |
