# HeyGen Decision (Yes/No)

درباره متن، تصویر، صدا یا ویدیویی که متصل می‌کنید یک پرسش بله/خیر بپرسید و یک مقدار بولی برای مسیریابی دریافت کنید. `result` را به گره If/Else Switch متصل کنید تا بین دو مسیر انتخاب کنید، و `answer` و `probability` را بخوانید تا ببینید پاسخ چقدر واضح بوده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که باید استفاده شود. `heygen-decision-1-turbo` سریع‌تر و کم‌هزینه‌تر از `heygen-decision-1` است (پیش‌فرض: `"heygen-decision-1"`). | COMBO | بله | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | پرسش بله/خیر درباره آنچه متصل شده است، حداکثر 5000 کاراکتر. آن را طوری بپرسید که «بله» حالتی باشد که بر اساس آن اقدام می‌کنید (پیش‌فرض: "Is there a person in the image?"). | STRING | بله | 1 تا 5000 کاراکتر |
| `threshold` | احتمال «بله» که در آن `result` برابر true می‌شود؛ پاسخ‌های واضح نزدیک به 0 یا 1 هستند (پیش‌فرض: 0.5). | FLOAT | بله | 0.01 تا 0.99 (گام 0.01) |
| `images` | تصاویری که درباره آن‌ها پرسش می‌شود، در مجموع حداکثر 4 تصویر، با احتساب هر فریم از یک دسته. آن‌ها به‌ترتیب در سراسر سوکت‌ها با `image_1` تا `image_4` شماره‌گذاری می‌شوند. | IMAGE | خیر | حداکثر 4 تصویر |
| `audio_1` | صدایی که درباره آن پرسش می‌شود، حداکثر 30 دقیقه. | AUDIO | خیر | حداکثر 30 دقیقه |
| `video_1` | ویدیویی که درباره آن پرسش می‌شود، حداکثر 60 ثانیه. | VIDEO | خیر | حداکثر 60 ثانیه |
| `text` | متنی که پرسش درباره آن است، مانند یک پرامپت یا پاسخ LLM، حداکثر 20000 کاراکتر. | STRING | خیر | حداکثر 20000 کاراکتر |

حداقل یکی از `text`، `images`، `audio_1` یا `video_1` را متصل کنید و درون پرسش با نام سوکت به آن‌ها ارجاع دهید، برای مثال «آیا image_2 همان شخصی را نشان می‌دهد که image_1 نشان می‌دهد؟».

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `result` | پاسخ به‌صورت یک مقدار بولی: true برای «yes»، false برای «no». | BOOLEAN |
| `answer` | پاسخ به‌صورت رشته `"yes"` یا `"no"`. | STRING |
| `probability` | احتمال «yes» بین 0 و 1. | FLOAT |
