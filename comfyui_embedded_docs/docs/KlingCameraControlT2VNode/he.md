# KlingCameraControlT2VNode

צומת Kling Text to Video Camera Control הופך טקסט לווידאו קינמטי עם תנועות מצלמה מקצועיות המדמות צילום מציאותי. צומת זה תומך בשליטה בפעולות מצלמה וירטואליות, כולל זום, סיבוב, תנועה אופקית, הטיה ותצוגת גוף ראשון, תוך שמירה על מיקוד בטקסט המקורי שלך. משך, מצב ושם המודל קבועים מראש, מכיוון ששליטה במצלמה נתמכת רק במצב pro עם המודל kling-v1-5 ובמשך של 5 שניות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית טקסט חיובית | STRING | כן | - |
| `negative_prompt` | הנחיית טקסט שלילית | STRING | כן | - |
| `cfg_scale` | שולט במידת ההיצמדות של הפלט להנחיה (ברירת מחדל: 0.75) | FLOAT | לא | 0.0-1.0 |
| `aspect_ratio` | יחס הגובה-רוחב של הווידאו שנוצר (ברירת מחדל: "16:9") | COMBO | לא | "16:9"<br>"9:16"<br>"1:1"<br>"21:9"<br>"3:4"<br>"4:3" |
| `camera_control` | ניתן ליצור באמצעות הצומת Kling Camera Controls. שולט בתנועת המצלמה ובתנועה במהלך יצירת הווידאו. | CAMERA_CONTROL | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | הווידאו שנוצר עם אפקטי שליטה במצלמה | VIDEO |
| `video_id` | המזהה הייחודי של הווידאו שנוצר | STRING |
| `duration` | משך הווידאו שנוצר | STRING |
