# EmptyLatentHunyuan3Dv2

Узел EmptyLatentHunyuan3Dv2 создает пустые латентные тензоры, специально отформатированные для моделей трехмерной генерации Hunyuan3Dv2. Он генерирует пустые латентные пространства с правильными размерами и структурой, требуемыми архитектурой Hunyuan3Dv2, что позволяет начать процессы трехмерной генерации с нуля. Узел создает латентные тензоры, заполненные нулями, которые служат основой для последующих процессов трехмерной генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `разрешение` | Размер разрешения для латентного пространства (по умолчанию: 3072) | INT | Да | 1 - 8192 |
| `размер_пакета` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Возвращает латентный тензор, содержащий пустые образцы с тегом типа "hunyuan3dv2", отформатированные для трехмерной генерации Hunyuan3Dv2 | LATENT |
