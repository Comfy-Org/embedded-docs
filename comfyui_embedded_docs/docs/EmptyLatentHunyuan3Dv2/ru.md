# EmptyLatentHunyuan3Dv2

Этот узел создаёт пакет пустых (полностью нулевых) латентных образцов, отформатированных для моделей 3D-генерации Hunyuan3Dv2. Он создаёт латентный тензор корректной формы, который служит начальной точкой для рабочих процессов 3D-генерации, при этом латент помечается типом "hunyuan3dv2".

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `разрешение` | Размер разрешения создаваемого латентного пространства (по умолчанию: 3072) | INT | Да | 1 - 8192 |
| `размер_пакета` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Пустой латентный тензор формы [batch_size, 64, resolution], содержащий заполненные нулями образцы, помеченный типом "hunyuan3dv2" | LATENT |
