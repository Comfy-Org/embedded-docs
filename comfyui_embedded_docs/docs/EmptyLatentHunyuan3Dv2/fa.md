# نهفته Hunyuan 3D v2 خالی

گره EmptyLatentHunyuan3Dv2 تانسورهای نهفتهٔ خالی را ایجاد می‌کند که به‌طور خاص برای مدل‌های تولید سه‌بعدی Hunyuan3Dv2 قالب‌بندی شده‌اند. این گره فضاهای نهفتهٔ خالی را با ابعاد و ساختار صحیح مورد نیاز معماری Hunyuan3Dv2 تولید می‌کند و به شما امکان می‌دهد گردش‌های کاری تولید سه‌بعدی را از ابتدا شروع کنید. این گره تانسورهای نهفتهٔ پر از صفر تولید می‌کند که به‌عنوان پایه‌ای برای فرآیندهای بعدی تولید سه‌بعدی عمل می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
