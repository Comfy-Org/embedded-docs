# Split Image Channels

画像を赤、緑、青の各チャンネルに分割し、アルファチャンネルをマスクとして返します。各色の出力は3チャンネルのグレースケール画像であるため、通常の画像と同様にプレビューおよび保存できます。単一チャンネルの確認や編集、またはアルファチャンネルを持つ画像から透過情報を取り出すために使用します。Load Image で読み込んだ画像にはアルファチャンネルがありません。これは、そのアルファが別個の `MASK` 出力として公開されるためです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | 分割する画像です。単一チャンネル（グレースケール）の入力は拡張され、3 つの色出力すべてが同じデータを持つようになります。 | IMAGE | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `red` | 赤チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `green` | 緑チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `blue` | 青チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `alpha` | マスクとしてのアルファです。Load Image と同じ方法で反転されるため、1 は完全に透明なピクセルを示します。アルファチャンネルを持たない画像では、すべてゼロのマスクが返されます。 | MASK |
