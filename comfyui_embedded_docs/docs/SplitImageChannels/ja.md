# Split Image Channels

画像を赤、緑、青のチャンネルに分割し、アルファチャンネルをマスクとして返します。各色出力は 3 チャンネルのグレースケール画像であるため、通常の画像と同様にプレビューおよび保存できます。単一チャンネルの検査や編集、または画像からの透明度の抽出に使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | 分割する画像です。単一チャンネル（グレースケール）の入力は拡張され、3 つの色出力すべてに同じデータが含まれます。 | IMAGE | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `red` | 赤チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `green` | 緑チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `blue` | 青チャンネルです。3 チャンネルのグレースケール画像として出力されます。 | IMAGE |
| `alpha` | マスクとしてのアルファです。Load Image と同じ方法で反転されるため、1 は完全に透明なピクセルを示します。アルファチャンネルを持たない画像は、すべてゼロのマスクを返します。 | MASK |
