# Split Image Channels

تصویر را به کانال‌های قرمز، سبز و آبی تقسیم می‌کند و کانال آلفا را به‌صورت ماسک برمی‌گرداند. هر خروجی رنگ یک تصویر خاکستری سه‌کاناله است، بنابراین مانند یک تصویر معمولی پیش‌نمایش داده و ذخیره می‌شود. از آن برای بررسی یا ویرایش یک کانال، یا استخراج شفافیت از تصویر استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویری که باید تقسیم شود. ورودی تک‌کاناله (خاکستری) گسترش می‌یابد تا هر سه خروجی رنگ داده یکسانی داشته باشند. | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `red` | کانال قرمز، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `green` | کانال سبز، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `blue` | کانال آبی، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `alpha` | آلفا به‌صورت ماسک، به همان روش Load Image معکوس می‌شود، بنابراین مقدار 1 پیکسل‌های کاملاً شفاف را مشخص می‌کند. تصویری که کانال آلفا ندارد، ماسکی تماماً صفر برمی‌گرداند. | MASK |
