# Split Image Channels

یک تصویر را به کانال‌های قرمز، سبز و آبی آن تقسیم می‌کند و کانال آلفا را به‌صورت ماسک برمی‌گرداند. هر خروجی رنگ یک تصویر خاکستری سه‌کاناله است، بنابراین مانند یک تصویر معمولی پیش‌نمایش داده می‌شود و ذخیره می‌گردد. از آن برای بررسی یا ویرایش یک کانال خاص، یا استخراج شفافیت از تصویری که دارای کانال آلفاست استفاده کنید: تصاویر بارگذاری‌شده با Load Image هیچ کانال آلفایی ندارند، زیرا آلفای آن به‌صورت یک خروجی `MASK` جداگانه ارائه می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویری که باید تقسیم شود. ورودی تک‌کاناله (خاکستری) گسترش داده می‌شود تا هر سه خروجی رنگ داده یکسانی داشته باشند. | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `red` | کانال قرمز، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `green` | کانال سبز، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `blue` | کانال آبی، به‌صورت یک تصویر خاکستری سه‌کاناله. | IMAGE |
| `alpha` | آلفا به‌صورت ماسک، به همان روش Load Image معکوس می‌شود، بنابراین ۱ پیکسل‌های کاملاً شفاف را مشخص می‌کند. تصویری بدون کانال آلفا یک ماسک تمام‌صفر برمی‌گرداند. | MASK |
