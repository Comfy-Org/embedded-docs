# Split Image Channels

מפצל תמונה לערוצי האדום, הירוק והכחול שלה, ומחזיר את ערוץ האלפא כמסכה. כל פלט צבע הוא תמונת גווני אפור בת שלושה ערוצים, ולכן ניתן להציג אותה בתצוגה מקדימה ולשמור אותה כמו תמונה רגילה. השתמשו בו כדי לבדוק או לערוך ערוץ בודד, או כדי לחלץ שקיפות מתמונה הכוללת ערוץ אלפא: לתמונות הנטענות עם Load Image אין ערוץ כזה, מכיוון שהאלפא שלהן נחשפת כפלט `MASK` נפרד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | התמונה לפצל. קלט חד-ערוצי (גווני אפור) מורחב כך שכל שלושת פלטי הצבע נושאים את אותו מידע. | IMAGE | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `red` | ערוץ האדום, כתמונת גווני אפור בת שלושה ערוצים. | IMAGE |
| `green` | ערוץ הירוק, כתמונת גווני אפור בת שלושה ערוצים. | IMAGE |
| `blue` | ערוץ הכחול, כתמונת גווני אפור בת שלושה ערוצים. | IMAGE |
| `alpha` | אלפא כמסכה, הפוכה באותו אופן כמו ב-Load Image, כך ש-1 מסמן פיקסלים שקופים לחלוטין. תמונה ללא ערוץ אלפא מחזירה מסכה שכולה אפסים. | MASK |
