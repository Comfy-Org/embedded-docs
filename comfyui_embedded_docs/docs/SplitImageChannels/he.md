# Split Image Channels

מפצל תמונה לערוצי האדום, הירוק והכחול שלה, ומחזיר את ערוץ האלפא כמסכה. כל פלט צבע הוא תמונה בגווני אפור עם שלושה ערוצים, כך שהיא מוצגת בתצוגה מקדימה ונשמרת כמו תמונה רגילה. השתמשו בו כדי לבדוק או לערוך ערוץ בודד, או כדי לחלץ שקיפות מתוך תמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image` | התמונה לפיצול. קלט בעל ערוץ בודד (גווני אפור) מורחב כך שכל שלושת פלטי הצבע נושאים את אותם נתונים. | IMAGE | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `red` | ערוץ האדום, כתמונה תלת-ערוצית בגווני אפור. | IMAGE |
| `green` | ערוץ הירוק, כתמונה תלת-ערוצית בגווני אפור. | IMAGE |
| `blue` | ערוץ הכחול, כתמונה תלת-ערוצית בגווני אפור. | IMAGE |
| `alpha` | אלפא כמסכה, הפוכה באותו אופן כמו ב-Load Image, כך ש-1 מסמן פיקסלים שקופים לחלוטין. תמונה ללא ערוץ אלפא מחזירה מסכה של אפסים בלבד. | MASK |
