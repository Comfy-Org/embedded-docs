# Split Image Channels

이미지를 빨간색, 녹색, 파란색 채널로 분할하고 알파 채널을 마스크로 반환합니다. 각 색상 출력은 3채널 그레이스케일 이미지이므로 일반 이미지처럼 미리보기 및 저장할 수 있습니다. 단일 채널을 검사하거나 편집하거나, 알파 채널이 포함된 이미지에서 투명도를 추출하는 데 사용하세요. Load Image로 불러온 이미지에는 알파 채널이 없습니다. 해당 알파는 별도의 `MASK` 출력으로 노출되기 때문입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 분할할 이미지입니다. 단일 채널(그레이스케일) 입력은 확장되어 세 가지 색상 출력 모두 동일한 데이터를 갖습니다. | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `red` | 빨간색 채널이며, 3채널 그레이스케일 이미지입니다. | IMAGE |
| `green` | 녹색 채널이며, 3채널 그레이스케일 이미지입니다. | IMAGE |
| `blue` | 파란색 채널이며, 3채널 그레이스케일 이미지입니다. | IMAGE |
| `alpha` | Load Image와 동일한 방식으로 반전된 마스크 형태의 알파입니다. 따라서 1은 완전히 투명한 픽셀을 나타냅니다. 알파 채널이 없는 이미지는 모두 0인 마스크를 반환합니다. | MASK |
