# Split Image Channels

Разделяет изображение на красный, зелёный и синий каналы и возвращает альфа-канал в виде маски. Каждый цветовой выход представляет собой трёхканальное полутоновое изображение, поэтому оно отображается в предпросмотре и сохраняется как обычное изображение. Используйте этот узел для просмотра или редактирования отдельного канала либо для извлечения прозрачности из изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Изображение для разделения. Одноканальное (полутоновое) входное изображение расширяется так, чтобы все три цветовых выхода содержали одни и те же данные. | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `red` | Красный канал в виде трёхканального полутонового изображения. | IMAGE |
| `green` | Зелёный канал в виде трёхканального полутонового изображения. | IMAGE |
| `blue` | Синий канал в виде трёхканального полутонового изображения. | IMAGE |
| `alpha` | Альфа-канал в виде маски, инвертированный так же, как в Load Image, поэтому 1 обозначает полностью прозрачные пиксели. Для изображения без альфа-канала возвращается маска из нулей. | MASK |
