# Split Image Channels

Разбивает изображение на красный, зелёный и синий каналы и возвращает альфа-канал как маску. Каждый цветовой выход — это трёхканальное изображение в оттенках серого, поэтому оно отображается в предпросмотре и сохраняется как обычное изображение. Используйте его для просмотра или редактирования отдельного канала либо для извлечения прозрачности из изображения, содержащего альфа-канал: у изображений, загруженных через Load Image, альфа-канала нет, поскольку их альфа-канал выводится отдельным выходом `MASK`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Изображение для разделения. Одноканальный (в оттенках серого) вход расширяется, так что все три цветовых выхода содержат одни и те же данные. | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `red` | Красный канал в виде трёхканального изображения в оттенках серого. | IMAGE |
| `green` | Зелёный канал в виде трёхканального изображения в оттенках серого. | IMAGE |
| `blue` | Синий канал в виде трёхканального изображения в оттенках серого. | IMAGE |
| `alpha` | Альфа-канал в виде маски, инвертированный так же, как в Load Image, поэтому 1 обозначает полностью прозрачные пиксели. Для изображения без альфа-канала возвращается маска, полностью заполненная нулями. | MASK |
