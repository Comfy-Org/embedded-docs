# Сэмплер DPMPP_SDE

SamplerDPMPP_SDE создает сэмплер DPM++ SDE (стохастическое дифференциальное уравнение) для использования в процессе сэмплирования. Этот сэмплер предоставляет стохастический метод сэмплирования с настраиваемыми параметрами шума и выбором устройства. Он возвращает объект сэмплера, который можно использовать в конвейере сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет стохастичностью процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `r` | Параметр, влияющий на поведение сэмплирования (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 100.0 |
| `устройство_шума` | Выбирает устройство, на котором выполняются вычисления шума. При значении "cpu" создается сэмплер `dpmpp_sde`; при значении "gpu" создается сэмплер `dpmpp_sde_gpu` (по умолчанию: "gpu") | COMBO | Да | "gpu"<br>"cpu" |

Примечание: Все входы отмечены как дополнительные параметры. Выбор `noise_device` изменяет вариант создаваемого сэмплера: "cpu" соответствует `dpmpp_sde`, а "gpu" соответствует `dpmpp_sde_gpu`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера DPM++ SDE для использования в конвейерах сэмплирования | SAMPLER |
