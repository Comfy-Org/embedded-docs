# Сэмплер DPMPP_SDE

Узел SamplerDPMPP_SDE создает сэмплер DPM++ SDE (стохастическое дифференциальное уравнение) для использования в процессе сэмплирования. Этот сэмплер предоставляет стохастический метод сэмплирования с настраиваемыми параметрами шума и выбором устройства. Он возвращает объект сэмплера, который может быть использован в конвейере сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет стохастичностью процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `r` | Параметр, влияющий на поведение сэмплирования (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 100.0 |
| `noise_device` | Выбирает устройство, на котором выполняются вычисления шума (по умолчанию: "gpu"). Если установлено значение "cpu", используется стандартный сэмплер `dpmpp_sde`; если установлено значение "gpu", используется сэмплер `dpmpp_sde_gpu`. | COMBO | Да | "gpu"<br>"cpu" |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера DPM++ SDE для использования в конвейерах сэмплирования | SAMPLER |
