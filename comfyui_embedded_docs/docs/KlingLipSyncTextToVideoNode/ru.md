# Kling Синхронизация губ в видео с текстом

Узел Kling Lip Sync Text to Video синхронизирует движения губ в видеофайле с текстовой подсказкой. Он принимает входное видео и генерирует новое видео, в котором движения губ персонажа согласованы с предоставленным текстом. Узел использует синтез речи для создания естественной синхронизации речи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Входной видеофайл для синхронизации губ. Высота/ширина видео должна быть от 720px до 1920px, длительность — от 2s до 10s, а размер — не более 100MB. | VIDEO | Да | - |
| `текст` | Текстовое содержимое для генерации видео с синхронизацией губ. Обязательно, когда mode имеет значение text2video. Максимальная длина — 120 символов. | STRING | Да | - |
| `голос` | Выбор голоса для аудио с синхронизацией губ (по умолчанию: "Melody"). Включает варианты голосов на английском и китайском языках. | COMBO | Нет | "Melody"<br>"Sunny"<br>"Sage"<br>"Ace"<br>"Blossom"<br>"Peppy"<br>"Dove"<br>"Shine"<br>"Anchor"<br>"Lyric"<br>"Tender"<br>"Siren"<br>"Zippy"<br>"Bud"<br>"Sprite"<br>"Candy"<br>"Beacon"<br>"Rock"<br>"Titan"<br>"Grace"<br>"Helen"<br>"Lore"<br>"Crag"<br>"Prattle"<br>"Hearth"<br>"The Reader"<br>"Commercial Lady"<br>"阳光少年"<br>"懂事小弟"<br>"运动少年"<br>"青春少女"<br>"温柔小妹"<br>"元气少女"<br>"阳光男生"<br>"幽默小哥"<br>"文艺小哥"<br>"甜美邻家"<br>"温柔姐姐"<br>"职场女青"<br>"活泼男童"<br>"俏皮女童"<br>"稳重老爸"<br>"温柔妈妈"<br>"严肃上司"<br>"优雅贵妇"<br>"慈祥爷爷"<br>"唠叨爷爷"<br>"唠叨奶奶"<br>"和蔼奶奶"<br>"东北老铁"<br>"重庆小伙"<br>"四川妹子"<br>"潮汕大叔"<br>"台湾男生"<br>"西安掌柜"<br>"天津姐姐"<br>"新闻播报男"<br>"译制片男"<br>"撒娇女友"<br>"刀片烟嗓"<br>"乖巧正太" |
| `скорость_голоса` | Скорость речи. Допустимый диапазон: 0.8~2.0, с точностью до одного знака после запятой. (по умолчанию: 1) | FLOAT | Нет | 0.8-2.0 |

**Требования к видео:**

- Размер видеофайла не должен превышать 100MB
- Высота/ширина должна быть от 720px до 1920px
- Длительность должна быть от 2s до 10s

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео с аудио, синхронизированным с движением губ | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Информация о длительности сгенерированного видео | STRING |
