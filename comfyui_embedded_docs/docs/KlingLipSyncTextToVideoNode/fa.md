# همگام‌سازی لب Kling با ویدیو و متن

گره Kling Lip Sync Text to Video، حرکات دهان را در یک فایل ویدیویی برای هماهنگی با یک پرامپت متنی همگام‌سازی می‌کند. این گره یک ویدیوی ورودی می‌گیرد و ویدیوی جدیدی تولید می‌کند که در آن حرکات لب شخصیت با متن ارائه‌شده هم‌راستا شده است. این گره از سنتز صدا برای ایجاد همگام‌سازی گفتاری طبیعی استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `video` | فایل ویدیوی ورودی برای همگام‌سازی لب. ویدیو باید از نظر ارتفاع/عرض بین 720px و 1920px، از نظر مدت‌زمان بین 2s و 10s و حجم آن بیش از 100MB نباشد. | VIDEO | بله | - |
| `text` | محتوای متنی برای تولید ویدیوی همگام‌سازی لب. هنگامی که حالت text2video است الزامی است. حداکثر طول 120 کاراکتر است. | STRING | بله | - |
| `voice` | انتخاب صدا برای صدای همگام‌سازی لب (پیش‌فرض: "Melody"). شامل گزینه‌های صدای انگلیسی و چینی است. | COMBO | خیر | "Melody"<br>"Sunny"<br>"Sage"<br>"Ace"<br>"Blossom"<br>"Peppy"<br>"Dove"<br>"Shine"<br>"Anchor"<br>"Lyric"<br>"Tender"<br>"Siren"<br>"Zippy"<br>"Bud"<br>"Sprite"<br>"Candy"<br>"Beacon"<br>"Rock"<br>"Titan"<br>"Grace"<br>"Helen"<br>"Lore"<br>"Crag"<br>"Prattle"<br>"Hearth"<br>"The Reader"<br>"Commercial Lady"<br>"阳光少年"<br>"懂事小弟"<br>"运动少年"<br>"青春少女"<br>"温柔小妹"<br>"元气少女"<br>"阳光男生"<br>"幽默小哥"<br>"文艺小哥"<br>"甜美邻家"<br>"温柔姐姐"<br>"职场女青"<br>"活泼男童"<br>"俏皮女童"<br>"稳重老爸"<br>"温柔妈妈"<br>"严肃上司"<br>"优雅贵妇"<br>"慈祥爷爷"<br>"唠叨爷爷"<br>"唠叨奶奶"<br>"和蔼奶奶"<br>"东北老铁"<br>"重庆小伙"<br>"四川妹子"<br>"潮汕大叔"<br>"台湾男生"<br>"西安掌柜"<br>"天津姐姐"<br>"新闻播报男"<br>"译制片男"<br>"撒娇女友"<br>"刀片烟嗓"<br>"乖巧正太" |
| `voice_speed` | سرعت گفتار. محدوده معتبر: 0.8~2.0، با دقت یک رقم اعشار. (پیش‌فرض: 1) | FLOAT | خیر | 0.8-2.0 |

**الزامات ویدیو:**

- حجم فایل ویدیو نباید بیشتر از 100MB باشد
- ارتفاع/عرض باید بین 720px و 1920px باشد
- مدت‌زمان باید بین 2s و 10s باشد

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | ویدیوی تولیدشده با صدای همگام‌سازی‌شده با لب | VIDEO |
| `video_id` | شناسه یکتای ویدیوی تولیدشده | STRING |
| `duration` | اطلاعات مدت‌زمان ویدیوی تولیدشده | STRING |
