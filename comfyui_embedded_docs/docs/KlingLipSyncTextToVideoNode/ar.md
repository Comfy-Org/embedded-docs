# مزامنة شفاه كليغ مع النص

عُقدة Kling Lip Sync Text to Video تزامن حركات الفم في ملف فيديو لتتوافق مع نص توجيهي. تأخذ فيديو كإدخال وتُولِّد فيديو جديدًا تتم فيه محاذاة حركات شفاه الشخصية مع النص المُقدَّم. تستخدم العُقدة تركيب الصوت لإنشاء مزامنة كلام طبيعية المظهر.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `video` | ملف فيديو إدخال لمزامنة الشفاه. يجب أن يكون ارتفاع/عرض الفيديو بين 720px و1920px، ومدته بين 2s و10s، وحجمه لا يزيد عن 100MB. | VIDEO | نعم | - |
| `text` | المحتوى النصي لتوليد فيديو مزامنة الشفاه. مطلوب عندما يكون الوضع text2video. الحد الأقصى للطول 120 حرفًا. | STRING | نعم | - |
| `voice` | اختيار الصوت لمزامنة الشفاه (افتراضي: "Melody"). يتضمن خيارات أصوات إنجليزية وصينية. | COMBO | لا | "Melody"<br>"Sunny"<br>"Sage"<br>"Ace"<br>"Blossom"<br>"Peppy"<br>"Dove"<br>"Shine"<br>"Anchor"<br>"Lyric"<br>"Tender"<br>"Siren"<br>"Zippy"<br>"Bud"<br>"Sprite"<br>"Candy"<br>"Beacon"<br>"Rock"<br>"Titan"<br>"Grace"<br>"Helen"<br>"Lore"<br>"Crag"<br>"Prattle"<br>"Hearth"<br>"The Reader"<br>"Commercial Lady"<br>"阳光少年"<br>"懂事小弟"<br>"运动少年"<br>"青春少女"<br>"温柔小妹"<br>"元气少女"<br>"阳光男生"<br>"幽默小哥"<br>"文艺小哥"<br>"甜美邻家"<br>"温柔姐姐"<br>"职场女青"<br>"活泼男童"<br>"俏皮女童"<br>"稳重老爸"<br>"温柔妈妈"<br>"严肃上司"<br>"优雅贵妇"<br>"慈祥爷爷"<br>"唠叨爷爷"<br>"唠叨奶奶"<br>"和蔼奶奶"<br>"东北老铁"<br>"重庆小伙"<br>"四川妹子"<br>"潮汕大叔"<br>"台湾男生"<br>"西安掌柜"<br>"天津姐姐"<br>"新闻播报男"<br>"译制片男"<br>"撒娇女友"<br>"刀片烟嗓"<br>"乖巧正太" |
| `voice_speed` | معدل سرعة الكلام. النطاق الصالح: 0.8~2.0، بدقة منزلة عشرية واحدة. (افتراضي: 1) | FLOAT | لا | 0.8-2.0 |

**متطلبات الفيديو:**

- يجب ألا يزيد حجم ملف الفيديو عن 100MB
- يجب أن يكون الارتفاع/العرض بين 720px و1920px
- يجب أن تكون المدة بين 2s و10s

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | فيديو مُولَّد مع صوت متزامن مع حركة الشفاه | VIDEO |
| `video_id` | مُعرّف فريد للفيديو المُولَّد | STRING |
| `duration` | معلومات المدة للفيديو المُولَّد | STRING |
