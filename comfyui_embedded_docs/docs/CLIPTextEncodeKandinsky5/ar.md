# CLIPTextEncodeKandinsky5

تُعِدّ عقدة CLIP Text Encode (Kandinsky 5) المطالبات النصية لاستخدامها مع نموذج Kandinsky 5. تتلقى مدخلين نصيين منفصلين، وتقسّمهما إلى رموز باستخدام نموذج CLIP المزوّد، ثم تدمجهما في مخرَج CONDITIONING واحد يوجّه عملية توليد الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتقسيم المطالبات النصية إلى رموز وتشفيرها. | CLIP | نعم |  |
| `clip_l` | المطالبة النصية الأساسية. يدعم هذا الإدخال النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم |  |
| `qwen25_7b` | المطالبة النصية الثانوية. يدعم هذا الإدخال النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم |  |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | بيانات CONDITIONING المجمّعة الناتجة عن المطالبتين النصيتين، الجاهزة للتغذية في نموذج Kandinsky 5 لتوليد الصور. | CONDITIONING |
