# CLIPTextEncodeKandinsky5

عقدة **CLIP Text Encode (Kandinsky 5)** تُعدّ الموجّهات النصية لاستخدامها مع نموذج Kandinsky 5. تأخذ العقدة مدخلين نصيين منفصلين، وتقوم بترميزهما باستخدام نموذج CLIP المُقدم، ثم تدمجهما في مخرج توجيه واحد. يُستخدم هذا المخرج لتوجيه عملية توليد الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتحويل الموجّهات النصية إلى رموز وترميزها. | CLIP | نعم |  |
| `clip_l` | الموجّه النصي الأساسي. يدعم هذا الإدخال نصًا متعدد الأسطر وموجّهات ديناميكية. | STRING | نعم |  |
| `qwen25_7b` | الموجّه النصي الثانوي. يدعم هذا الإدخال نصًا متعدد الأسطر وموجّهات ديناميكية. | STRING | نعم |  |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | بيانات التوجيه المجمّعة الناتجة من كلا الموجّهين النصيين، وجاهزة للتغذية إلى نموذج Kandinsky 5 لتوليد الصور. | CONDITIONING |
