# CLIPTextEncodeKandinsky5

تُعد عقدة `CLIPTextEncodeKandinsky5` مطالبات النص لاستخدامها مع نموذج Kandinsky 5. تأخذ مدخلين نصيين منفصلين، وتقوم بترميزهما باستخدام نموذج CLIP المقدَّم، وتدمجهما في مخرجات توجيه واحدة. يُستخدم هذا المخرج لتوجيه عملية توليد الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لترميز وتحويل المطالبات النصية. | CLIP | نعم |  |
| `clip_l` | المطالبة النصية الأساسية. يدعم هذا المدخل النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم |  |
| `qwen25_7b` | مطالبة نصية ثانوية. يدعم هذا المدخل النص متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم |  |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | بيانات التوجيه المدمجة التي تم إنشاؤها من كلا المطالبتين النصيتين، وجاهزة للتغذية إلى نموذج Kandinsky 5 لتوليد الصور. | CONDITIONING |
