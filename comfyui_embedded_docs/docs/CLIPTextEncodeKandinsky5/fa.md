# CLIPTextEncodeKandinsky5

گره CLIP Text Encode (Kandinsky 5) پرامپت‌های متنی را برای استفاده با مدل Kandinsky 5 آماده می‌کند. این گره دو ورودی متنی جداگانه می‌گیرد، آن‌ها را با یک مدل CLIP ارائه‌شده توکنیزه می‌کند و در یک خروجی conditioning واحد ترکیب می‌کند که فرایند تولید تصویر را هدایت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکنیزه کردن و رمزگذاری پرامپت‌های متنی استفاده می‌شود. | CLIP | بله |  |
| `clip_l` | پرامپت متنی اصلی. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `qwen25_7b` | پرامپت متنی دوم. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی‌سازی ترکیب‌شده که از هر دو پرامپت متنی تولید می‌شود و آماده تغذیه به مدل Kandinsky 5 برای تولید تصویر است. | CONDITIONING |
