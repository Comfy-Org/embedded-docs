# CLIPTextEncodeKandinsky5

گره CLIPTextEncodeKandinsky5 متن‌های ورودی را برای استفاده با مدل Kandinsky 5 آماده می‌کند. این گره دو ورودی متنی جداگانه دریافت می‌کند، آن‌ها را با استفاده از مدل CLIP ارائه‌شده توکن‌سازی می‌کند و در یک خروجی شرطی‌سازی ترکیب می‌کند. این خروجی برای هدایت فرآیند تولید تصویر استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری متن‌های ورودی. | CLIP | بله |  |
| `clip_l` | متن‌ورودی اصلی. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `qwen25_7b` | یک متن‌ورودی ثانویه. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| CONDITIONING | داده‌های شرطی‌سازی ترکیبی تولیدشده از هر دو متن‌ورودی، آماده برای ورود به مدل Kandinsky 5 برای تولید تصویر. | CONDITIONING |
