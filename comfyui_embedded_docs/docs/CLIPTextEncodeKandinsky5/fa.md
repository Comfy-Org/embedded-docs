# CLIPTextEncodeKandinsky5

گره «رمزگذاری متن CLIP (Kandinsky 5)» متن‌های ورودی را برای استفاده با مدل Kandinsky 5 آماده می‌کند. این گره دو ورودی متنی جداگانه دریافت می‌کند، آن‌ها را با استفاده از مدل CLIP ارائه‌شده توکن‌سازی می‌کند، و آن‌ها را در یک خروجی شرطی واحد ترکیب می‌کند. این خروجی برای هدایت فرآیند تولید تصویر استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکن‌سازی و رمزگذاری متن‌های ورودی استفاده می‌شود. | CLIP | بله |  |
| `clip_l` | متن ورودی اصلی. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `qwen25_7b` | متن ورودی ثانویه. این ورودی از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی ترکیبی حاصل از هر دو متن ورودی، آماده برای ورود به مدل Kandinsky 5 جهت تولید تصویر. | CONDITIONING |
