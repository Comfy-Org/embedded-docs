# CLIPTextEncodeKandinsky5

הצומת CLIP Text Encode (Kandinsky 5) מכין פרומפטים טקסטואליים לשימוש עם מודל Kandinsky 5. הוא מקבל שני קלטי טקסט נפרדים, מבצע עליהם טוקניזציה באמצעות מודל CLIP שסופק, ומשלב אותם לפלט קונדישנינג יחיד שמנחה את תהליך יצירת התמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה ולקידוד של פרומפטי הטקסט. | CLIP | כן |  |
| `clip_l` | פרומפט הטקסט הראשי. קלט זה תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן |  |
| `qwen25_7b` | פרומפט הטקסט המשני. קלט זה תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן |  |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | נתוני הקונדישנינג המשולבים שנוצרו משני פרומפטי הטקסט, מוכנים להזנה למודל Kandinsky 5 ליצירת תמונות. | CONDITIONING |
