# CLIPTextEncodeKandinsky5

Узел `CLIPTextEncodeKandinsky5` подготавливает текстовые промпты для использования с моделью Kandinsky 5. Он принимает два отдельных текстовых входа, токенизирует их с помощью предоставленной модели CLIP и объединяет их в единый выходной сигнал кондиционирования. Этот выход используется для управления процессом генерации изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстовых промптов. | CLIP | Да |  |
| `clip_l` | Основной текстовый промпт. Этот вход поддерживает многострочный текст и динамические промпты. | STRING | Да |  |
| `qwen25_7b` | Вторичный текстовый промпт. Этот вход поддерживает многострочный текст и динамические промпты. | STRING | Да |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Объединённые данные кондиционирования, сгенерированные из обоих текстовых промптов и готовые для подачи в модель Kandinsky 5 для генерации изображений. | CONDITIONING |
