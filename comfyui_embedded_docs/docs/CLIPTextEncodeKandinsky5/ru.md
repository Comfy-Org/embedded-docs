# CLIPTextEncodeKandinsky5

Узел CLIP Text Encode (Kandinsky 5) подготавливает текстовые подсказки для использования с моделью Kandinsky 5. Он принимает два отдельных текстовых входа, токенизирует их с помощью предоставленной модели CLIP и объединяет их в единый выход conditioning, который направляет процесс генерации изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования текстовых подсказок. | CLIP | Да |  |
| `clip_l` | Основная текстовая подсказка. Этот вход поддерживает многострочный текст и динамические подсказки. | STRING | Да |  |
| `qwen25_7b` | Дополнительная текстовая подсказка. Этот вход поддерживает многострочный текст и динамические подсказки. | STRING | Да |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Объединённые данные conditioning, сгенерированные из обеих текстовых подсказок и готовые для подачи в модель Kandinsky 5 для генерации изображения. | CONDITIONING |
