# MeshyTextToModelNode

הצומת Meshy: Text to Model משתמש ב-API של Meshy כדי ליצור מודל תלת-ממדי מתיאור טקסטואלי. הוא שולח בקשה ל-API עם ההנחיה וההגדרות שלך, ואז ממתין להשלמת היצירה ומוריד את קבצי המודל שהתקבלו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מציין את גרסת מודל ה-AI לשימוש ביצירה. | COMBO | כן | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | התיאור הטקסטואלי של המודל התלת-ממדי שברצונך ליצור. חייב להיות באורך שבין 1 ל-600 תווים. ברירת המחדל היא מחרוזת ריקה. | STRING | כן | 1 - 600 תווים |
| `style` | הסגנון האמנותי עבור המודל התלת-ממדי שנוצר. | COMBO | כן | `"realistic"` |
| `should_remesh` | כאשר מוגדר ל-false, מחזיר רשת משולשת לא מעובדת. בחירה ב-`"true"` חושפת פרמטרים נוספים עבור טופולוגיה ומספר פוליגונים מטרה. | DYNAMIC_COMBO | כן | `"true"`<br>`"false"` |
| `topology` | סוג הפוליגון המטרה עבור המודל שעבר remesh. פרמטר זה זמין רק כאשר `should_remesh` מוגדר ל-`"true"`. | COMBO | לא* | `"triangle"`<br>`"quad"` |
| `target_polycount` | מספר הפוליגונים המטרה עבור המודל שעבר remesh. ברירת המחדל היא 300000. פרמטר זה זמין רק כאשר `should_remesh` מוגדר ל-`"true"`. | INT | לא* | 100 - 300000 |
| `symmetry_mode` | שולט בסימטריה במודל שנוצר. זהו פרמטר מתקדם. האפשרויות הן `"auto"`, `"on"` ו-`"off"`. | COMBO | כן | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | מציין את מצב התנוחה עבור המודל שנוצר. מחרוזת ריקה פירושה שלא מתבקשת תנוחה ספציפית. זהו פרמטר מתקדם. | COMBO | כן | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | הפרמטר `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. ברירת המחדל היא 0. | INT | כן | 0 - 2147483647 |
| `ultra_mode` | מבצע מעבר עידון נוסף עבור גאומטריה בנאמנות גבוהה יותר עם פירוט משטח עדין יותר. ברירת המחדל היא false. | BOOLEAN | כן | true<br>false |
| `ultra_resolution` | הרזולוציה של מעבר ה-ultra: `"2k"` מריץ אותו ב-2048³, `"4k"` ב-4096³ עבור פירוט המשטח העדין ביותר. 4k דורש את המודל `"meshy-7.1"` או `"latest"`. בשימוש רק כאשר `ultra_mode` מופעל (ברירת מחדל: `"2k"`). | COMBO | לא | `"2k"`<br>`"4k"` |

*הערה: הפרמטרים `topology` ו-`target_polycount` זמינים באופן מותנה. הם מופיעים רק כאשר הפרמטר `should_remesh` מוגדר ל-`"true"`.

כאשר `ultra_mode` מופעל, הפרמטר `model` חייב להיות מוגדר ל-`"meshy-7.1"`, `"meshy-7"` או `"latest"`; כל מודל אחר מעלה שגיאה. עם `"meshy-7"` מעבר ה-ultra תמיד רץ ב-2048³, ורזולוציית ה-ultra `"4k"` דורשת `"meshy-7.1"` או `"latest"`.

## פלטים
