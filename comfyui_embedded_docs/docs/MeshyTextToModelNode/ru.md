# Meshy: Текст в Модель

Узел Meshy: Text to Model использует Meshy API для генерации 3D-модели по текстовому описанию. Он отправляет запрос к API с вашим промптом и настройками, затем ожидает завершения генерации и загружает полученные файлы модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Указывает версию модели ИИ, используемую для генерации. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. Должно содержать от 1 до 600 символов. | STRING | Да | 1 - 600 символов |
| `style` | Художественный стиль генерируемой 3D-модели. | COMBO | Да | `"realistic"` |
| `should_remesh` | При значении false возвращается необработанная треугольная сетка. Выбор "true" открывает дополнительные параметры для топологии и целевого количества полигонов. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `topology` | Целевой тип полигонов для модели после ремешинга. Этот параметр доступен только тогда, когда `should_remesh` установлен в "true". | COMBO | Нет* | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для модели после ремешинга. По умолчанию — 300000. Этот параметр доступен только тогда, когда `should_remesh` установлен в "true". | INT | Нет* | 100 - 300000 |
| `symmetry_mode` | Управляет симметрией генерируемой модели. Это расширенный параметр. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | Задаёт режим позы для генерируемой модели. Пустая строка означает, что конкретная поза не запрашивается. Это расширенный параметр. | COMBO | Да | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Семя управляет тем, должен ли узел перезапускаться; результаты не являются детерминированными независимо от seed. По умолчанию — 0. | INT | Да | 0 - 2147483647 |
| `ультра-режим` | Выполняет дополнительный проход уточнения для геометрии более высокого качества с более тонкими деталями поверхности. По умолчанию — false. | BOOLEAN | Да | true<br>false |

*Примечание:* параметры `topology` и `target_polycount` доступны условно. Они появляются только тогда, когда параметр `should_remesh` установлен в "true".

Когда `ultra_mode` включён, параметр `model` должен быть установлен в `"meshy-7"` или `"latest"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Имя файла сгенерированной GLB-модели. Этот выход предоставлен для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированный файл 3D-модели в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированный файл 3D-модели в формате FBX. | FILE3DFBX |
