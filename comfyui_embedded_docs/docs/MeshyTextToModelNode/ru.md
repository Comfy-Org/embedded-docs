# Meshy: Текст в Модель

Узел Meshy: Text to Model использует Meshy API для создания 3D-модели по текстовому описанию. Он отправляет запрос к API с вашим промптом и настройками, затем ожидает завершения генерации и загружает полученные файлы модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Указывает версию модели ИИ для использования. В настоящее время доступна только версия "latest". | COMBO | Да | `"latest"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. Длина должна быть от 1 до 600 символов. | STRING | Да | - |
| `style` | Художественный стиль создаваемой 3D-модели. | COMBO | Да | `"realistic"`<br>`"sculpture"` |
| `should_remesh` | Управляет обработкой сгенерированной сетки. Если установлено значение "false", узел возвращает необработанную треугольную сетку. Выбор "true" открывает дополнительные параметры для топологии и количества полигонов. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `topology` | Целевой тип полигонов для модели после ремешинга. Этот параметр доступен только когда `should_remesh` установлен в "true". | COMBO | Нет* | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для модели после ремешинга. По умолчанию 300000. Этот параметр доступен только когда `should_remesh` установлен в "true". | INT | Нет* | 100 - 300000 |
| `symmetry_mode` | Управляет симметрией в создаваемой модели. Это расширенный параметр. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | Задает режим позы для создаваемой модели. Пустая строка означает, что конкретная поза не запрашивается. Это расширенный параметр. | COMBO | Да | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Сид управляет тем, следует ли перезапускать узел; результаты недетерминированы независимо от сида. По умолчанию 0. | INT | Да | 0 - 2147483647 |

*Примечание: параметры `topology` и `target_polycount` доступны условно. Они появляются только когда параметр `should_remesh` установлен в "true".

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Имя файла сгенерированной GLB-модели. Этот выход предоставляется для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированный файл 3D-модели в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированный файл 3D-модели в формате FBX. | FILE3DFBX |
