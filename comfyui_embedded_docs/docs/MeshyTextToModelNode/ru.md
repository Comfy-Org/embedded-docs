# Meshy: Текст в Модель

Узел Meshy: Text to Model использует Meshy API для генерации 3D-модели из текстового описания. Он отправляет запрос к API с вашим промптом и настройками, затем дожидается завершения генерации и скачивает полученные файлы модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Указывает версию AI-модели, используемую для генерации. | COMBO | Да | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. Длина должна быть от 1 до 600 символов. По умолчанию — пустая строка. | STRING | Да | 1 - 600 символов |
| `style` | Художественный стиль сгенерированной 3D-модели. | COMBO | Да | `"realistic"` |
| `should_remesh` | Если установлено значение false, возвращается необработанная треугольная сетка. Выбор "true" открывает дополнительные параметры для топологии и целевого количества полигонов. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `topology` | Целевой тип полигонов для модели после ремеширования. Этот параметр доступен только когда для `should_remesh` установлено значение "true". | COMBO | Нет* | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для модели после ремеширования. По умолчанию — 300000. Этот параметр доступен только когда для `should_remesh` установлено значение "true". | INT | Нет* | 100 - 300000 |
| `symmetry_mode` | Управляет симметрией в сгенерированной модели. Это расширенный параметр. Доступные опции: `"auto"`, `"on"` и `"off"`. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | Задает режим позы для сгенерированной модели. Пустая строка означает, что конкретная поза не запрашивается. Это расширенный параметр. | COMBO | Да | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Seed управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию — 0. | INT | Да | 0 - 2147483647 |
| `ультра-режим` | Запускает дополнительный проход уточнения для геометрии с более высокой точностью и более детальной поверхностью. По умолчанию — false. | BOOLEAN | Да | true<br>false |
| `ultra_resolution` | Разрешение ультра-прохода: `"2k"` выполняет его при 2048³, `"4k"` при 4096³ — для наиболее детализированной поверхности. `"4k"` требует модели `"meshy-7.1"` или `"latest"`. Используется только при включённом `ultra_mode` (по умолчанию: `"2k"`). | COMBO | Нет | `"2k"`<br>`"4k"` |

*Примечание: Параметры `topology` и `target_polycount` доступны условно. Они появляются только когда для параметра `should_remesh` установлено значение "true".

Когда `ultra_mode` включён, параметр `model` должен быть установлен в `"meshy-7.1"`, `"meshy-7"` или `"latest"`; любая другая модель вызывает ошибку. С `"meshy-7"` ультра-проход всегда выполняется при 2048³, а ультра-разрешение `"4k"` требует `"meshy-7.1"` или `"latest"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла сгенерированной GLB-модели. Этот выход предусмотрен для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированный файл 3D-модели в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированный файл 3D-модели в формате FBX. | FILE3DFBX |
