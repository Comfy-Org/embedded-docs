# Meshy: تحويل النص إلى نموذج

تستخدم عقدة Meshy: Text to Model واجهة Meshy API لتوليد نموذج ثلاثي الأبعاد من وصف نصي. ترسل طلبًا إلى الواجهة باستخدام الموجّه النصي والإعدادات الخاصة بك، ثم تنتظر اكتمال التوليد وتنزّل ملفات النموذج الناتجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | يحدد إصدار نموذج الذكاء الاصطناعي المستخدم للتوليد. | COMBO | نعم | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | الوصف النصي للنموذج ثلاثي الأبعاد الذي تريد توليده. يجب أن يتراوح طوله بين 1 و600 حرف. القيمة الافتراضية هي سلسلة نصية فارغة. | STRING | نعم | 1 - 600 حرف |
| `style` | النمط الفني للنموذج ثلاثي الأبعاد المولَّد. | COMBO | نعم | `"realistic"` |
| `should_remesh` | عند ضبطه على false، يعيد شبكة مثلثية غير معالجة. اختيار "true" يكشف عن معاملات إضافية للطوبولوجيا وعدد المضلعات المستهدف. | DYNAMIC_COMBO | نعم | `"true"`<br>`"false"` |
| `topology` | نوع المضلعات المستهدف للنموذج المعاد تشكيل شبكته. يتوفر هذا المعامل فقط عندما يتم ضبط `should_remesh` على "true". | COMBO | لا* | `"triangle"`<br>`"quad"` |
| `target_polycount` | العدد المستهدف للمضلعات للنموذج المعاد تشكيل شبكته. القيمة الافتراضية هي 300000. يتوفر هذا المعامل فقط عندما يتم ضبط `should_remesh` على "true". | INT | لا* | 100 - 300000 |
| `symmetry_mode` | يتحكم في التناظر داخل النموذج المولَّد. هذا معامل متقدم. الخيارات هي `"auto"`، و`"on"`، و`"off"`. | COMBO | نعم | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | يحدد وضع الوضعية للنموذج المولَّد. سلسلة نصية فارغة تعني عدم طلب وضعية محددة. هذا معامل متقدم. | COMBO | نعم | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | تتحكم البذرة فيما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن البذرة. القيمة الافتراضية هي 0. | INT | نعم | 0 - 2147483647 |
| `ultra_mode` | تشغيل تمريرة تنقيح إضافية لهندسة أعلى دقة مع تفاصيل سطح أدق. القيمة الافتراضية هي false. | BOOLEAN | نعم | true<br>false |
| `ultra_resolution` | دقة تمريرة ultra: يشغّلها `"2k"` عند 2048³ و`"4k"` عند 4096³ للحصول على أدق تفاصيل السطح. يتطلب `"4k"` طراز `"meshy-7.1"` أو `"latest"`. يُستخدم فقط عند تمكين `ultra_mode` (الافتراضي: `"2k"`). | COMBO | لا | `"2k"`<br>`"4k"` |

*ملاحظة: المعاملان `topology` و`target_polycount` متاحان بشكل شرطي. لا يظهران إلا عندما يتم ضبط المعامل `should_remesh` على "true".

عند تمكين `ultra_mode`، يجب ضبط المعامل `model` على `"meshy-7.1"` أو `"meshy-7"` أو `"latest"`؛ أي طراز آخر يؤدي إلى خطأ. مع `"meshy-7"` تُنفَّذ تمريرة ultra دائمًا عند 2048³، وتتطلب دقة ultra `"4k"` طراز `"meshy-7.1"` أو `"latest"`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف نموذج GLB المولَّد. يُوفَّر هذا المخرج للتوافق مع الإصدارات السابقة. | STRING |
| `meshy_task_id` | المعرّف الفريد لمهمة Meshy API. | MESHY_TASK_ID |
| `GLB` | ملف النموذج ثلاثي الأبعاد المولَّد بصيغة GLB. | FILE3DGLB |
| `FBX` | ملف النموذج ثلاثي الأبعاد المولَّد بصيغة FBX. | FILE3DFBX |
