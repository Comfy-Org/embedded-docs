# Meshy: تحويل النص إلى نموذج

تستخدم عقدة Meshy: Text to Model واجهة برمجة تطبيقات Meshy لإنشاء نموذج ثلاثي الأبعاد من وصف نصي. ترسل طلبًا إلى الواجهة مع النص الموجّه والإعدادات، ثم تنتظر اكتمال التوليد وتنزّل ملفات النموذج الناتجة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | يحدد إصدار نموذج الذكاء الاصطناعي المستخدم في التوليد. | COMBO | نعم | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | الوصف النصي للنموذج ثلاثي الأبعاد الذي تريد توليده. يجب أن يتراوح طوله بين 1 و600 حرف. | STRING | نعم | 1 - 600 حرف |
| `style` | النمط الفني للنموذج ثلاثي الأبعاد المُولَّد. | COMBO | نعم | `"realistic"` |
| `should_remesh` | عند التعيين إلى false، تُرجع شبكة مثلثية غير معالجة. تحديد "true" يُظهر معاملات إضافية للطوبولوجيا وعدد المضلعات المستهدف. | DYNAMIC_COMBO | نعم | `"true"`<br>`"false"` |
| `topology` | نوع المضلع المستهدف للنموذج المعاد بناؤه. هذا المعامل متاح فقط عندما يتم تعيين `should_remesh` إلى "true". | COMBO | لا* | `"triangle"`<br>`"quad"` |
| `target_polycount` | العدد المستهدف للمضلعات في النموذج المعاد بناؤه. الافتراضي هو 300000. هذا المعامل متاح فقط عندما يتم تعيين `should_remesh` إلى "true". | INT | لا* | 100 - 300000 |
| `symmetry_mode` | يتحكم في التماثل داخل النموذج المُولَّد. يُعد هذا معاملًا متقدمًا. | COMBO | نعم | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | يحدد وضع الوضعية للنموذج المُولَّد. تعني السلسلة الفارغة عدم طلب وضعية محددة. يُعد هذا معاملًا متقدمًا. | COMBO | نعم | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | يتحكم في ما إذا كانت العقدة ستعمل مرة أخرى؛ تكون النتائج غير حتمية بغض النظر عن قيمة البذرة. الافتراضي هو 0. | INT | نعم | 0 - 2147483647 |
| `ultra_mode` | يُنفّذ مرحلة تحسين إضافية للحصول على هندسة عالية الدقة مع تفاصيل سطح أدق. الافتراضي هو false. | BOOLEAN | نعم | true<br>false |

*ملاحظة: المعاملان `topology` و`target_polycount` متاحان بشكل شرطي. يظهران فقط عندما يتم تعيين المعامل `should_remesh` إلى "true".

عند تفعيل `ultra_mode`، يجب تعيين المعامل `model` إلى `"meshy-7"` أو `"latest"`.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-----------|-------------|
| `ملف النموذج` | اسم ملف نموذج GLB المُولَّد. يتم توفير هذا المخرَج للتوافق مع الإصدارات السابقة. | STRING |
| `معرّف مهمة meshy` | المعرّف الفريد لمهمة واجهة برمجة تطبيقات Meshy. | MESHY_TASK_ID |
| `GLB` | ملف النموذج ثلاثي الأبعاد المُولَّد بصيغة GLB. | FILE3DGLB |
| `FBX` | ملف النموذج ثلاثي الأبعاد المُولَّد بصيغة FBX. | FILE3DFBX |
