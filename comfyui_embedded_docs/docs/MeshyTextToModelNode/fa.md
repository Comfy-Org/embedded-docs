# Meshy: متن به مدل

گره **Meshy: Text to Model** از API سرویس Meshy برای تولید یک مدل سه‌بعدی از روی توضیحات متنی استفاده می‌کند. این گره درخواستی را با پرامپت و تنظیمات شما به API ارسال می‌کند، سپس منتظر تکمیل تولید می‌ماند و فایل‌های مدل حاصل را دانلود می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل هوش مصنوعی مورد استفاده برای تولید را مشخص می‌کند. | COMBO | بله | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | توضیحات متنی مدل سه‌بعدی که می‌خواهید تولید کنید. طول آن باید بین 1 تا 600 کاراکتر باشد. | STRING | بله | 1 - 600 کاراکتر |
| `style` | سبک هنری مدل سه‌بعدی تولیدشده. | COMBO | بله | `"realistic"` |
| `should_remesh` | هنگامی که روی false تنظیم شود، یک مش مثلثی پردازش‌نشده برمی‌گرداند. انتخاب "true" پارامترهای اضافی برای توپولوژی و تعداد چندضلعی هدف را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `topology` | نوع چندضلعی هدف برای مدل بازمش‌شده. این پارامتر تنها زمانی در دسترس است که `should_remesh` روی "true" تنظیم شده باشد. | COMBO | خیر* | `"triangle"`<br>`"quad"` |
| `target_polycount` | تعداد هدف چندضلعی‌ها برای مدل بازمش‌شده. پیش‌فرض 300000 است. این پارامتر تنها زمانی در دسترس است که `should_remesh` روی "true" تنظیم شده باشد. | INT | خیر* | 100 - 300000 |
| `symmetry_mode` | تقارن در مدل تولیدشده را کنترل می‌کند. این یک پارامتر پیشرفته است. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | حالت ژست را برای مدل تولیدشده مشخص می‌کند. رشته خالی به این معنی است که ژست خاصی درخواست نشده است. این یک پارامتر پیشرفته است. | COMBO | بله | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | سید کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید، غیرقطعی هستند. پیش‌فرض 0 است. | INT | بله | 0 - 2147483647 |
| `ultra_mode` | یک مرحله بهبود اضافی برای هندسه با وفاداری بالاتر و جزئیات سطح ریزتر اجرا می‌کند. پیش‌فرض false است. | BOOLEAN | بله | true<br>false |

*توجه: پارامترهای `topology` و `target_polycount` به‌صورت شرطی در دسترس هستند. آن‌ها فقط زمانی ظاهر می‌شوند که پارامتر `should_remesh` روی "true" تنظیم شده باشد.

هنگامی که `ultra_mode` فعال باشد، پارامتر `model` باید روی `"meshy-7"` یا `"latest"` تنظیم شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | نام فایل مدل GLB تولیدشده. این خروجی برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای وظیفه در API سرویس Meshy. | MESHY_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی تولیدشده در قالب FBX. | FILE3DFBX |
