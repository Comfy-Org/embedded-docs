# Meshy: متن به مدل

گره Meshy: Text to Model از Meshy API برای تولید مدل سه‌بعدی بر اساس توضیح متنی استفاده می‌کند. این گره درخواستی همراه با پرامپت و تنظیمات شما به API می‌فرستد، سپس منتظر تکمیل تولید می‌ماند و فایل‌های مدل نهایی را دانلود می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل هوش مصنوعی مورد استفاده را مشخص می‌کند. در حال حاضر فقط نسخه «latest» در دسترس است. | COMBO | بله | `"latest"` |
| `prompt` | توضیح متنی مدل سه‌بعدی است که می‌خواهید تولید کنید. طول آن باید بین 1 تا 600 کاراکتر باشد. | STRING | بله | - |
| `style` | سبک هنری مدل سه‌بعدی تولید شده. | COMBO | بله | `"realistic"`<br>`"sculpture"` |
| `should_remesh` | کنترل می‌کند که آیا مش تولید شده پردازش شود یا نه. وقتی روی «false» تنظیم شود، گره یک مش مثلثی پردازش‌نشده برمی‌گرداند. انتخاب «true» پارامترهای اضافی برای توپولوژی و تعداد چندضلعی (polycount) را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `topology` | نوع چندضلعی هدف برای مدل بازمش‌بندی‌شده. این پارامتر فقط زمانی در دسترس است که `should_remesh` روی «true» تنظیم شده باشد. | COMBO | خیر* | `"triangle"`<br>`"quad"` |
| `target_polycount` | تعداد چندضلعی هدف برای مدل بازمش‌بندی‌شده. پیش‌فرض 300000 است. این پارامتر فقط زمانی در دسترس است که `should_remesh` روی «true» تنظیم شده باشد. | INT | خیر* | 100 - 300000 |
| `symmetry_mode` | تقارن را در مدل تولید شده کنترل می‌کند. این یک پارامتر پیشرفته است. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | حالت ژست (Pose) مدل تولید شده را مشخص می‌کند. رشته خالی به این معنی است که ژست خاصی درخواست نشده است. این یک پارامتر پیشرفته است. | COMBO | بله | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | مقدار seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از seed غیرقطعی هستند. پیش‌فرض 0 است. | INT | بله | 0 - 2147483647 |

*توجه: پارامترهای `topology` و `target_polycount` به‌صورت شرطی در دسترس هستند. آن‌ها فقط زمانی ظاهر می‌شوند که پارامتر `should_remesh` روی «true» تنظیم شده باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | نام فایل مدل GLB تولید شده. این خروجی برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای وظیفه در Meshy API. | MESHY_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تولید شده در قالب GLB. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی تولید شده در قالب FBX. | FILE3DFBX |
