# Meshy: متن به مدل

گره Meshy: Text to Model از API Meshy برای تولید یک مدل سه‌بعدی از توضیحات متنی استفاده می‌کند. این گره درخواستی همراه با `prompt` و تنظیمات شما به API ارسال می‌کند، سپس منتظر می‌ماند تا فرآیند تولید کامل شود و فایل‌های مدل حاصل را دانلود می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل هوش مصنوعی مورد استفاده برای تولید را مشخص می‌کند. | COMBO | بله | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `prompt` | توضیح متنی مدل سه‌بعدی که می‌خواهید تولید شود. باید بین 1 و 600 کاراکتر باشد. مقدار پیش‌فرض رشته خالی است. | STRING | بله | 1 - 600 کاراکتر |
| `style` | سبک هنری مدل سه‌بعدی تولیدشده. | COMBO | بله | `"realistic"` |
| `should_remesh` | هنگامی که روی false تنظیم شود، یک مش مثلثی پردازش‌نشده برمی‌گرداند. انتخاب "true" پارامترهای اضافی برای `topology` و `target_polycount` را نمایان می‌کند. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `topology` | نوع چندضلعی هدف برای مدل remesh‌شده. این پارامتر فقط زمانی در دسترس است که `should_remesh` روی "true" تنظیم شده باشد. | COMBO | خیر* | `"triangle"`<br>`"quad"` |
| `target_polycount` | تعداد هدف چندضلعی‌ها برای مدل remesh‌شده. مقدار پیش‌فرض 300000 است. این پارامتر فقط زمانی در دسترس است که `should_remesh` روی "true" تنظیم شده باشد. | INT | خیر* | 100 - 300000 |
| `symmetry_mode` | تقارن را در مدل تولیدشده کنترل می‌کند. این یک پارامتر پیشرفته است. گزینه‌ها عبارت‌اند از `"auto"`، `"on"` و `"off"`. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `pose_mode` | حالت ژست (pose) مدل تولیدشده را مشخص می‌کند. رشته خالی به این معناست که ژست خاصی درخواست نشده است. این یک پارامتر پیشرفته است. | COMBO | بله | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | `seed` کنترل می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به `seed` غیرقطعی هستند. مقدار پیش‌فرض 0 است. | INT | بله | 0 - 2147483647 |
| `ultra_mode` | یک مرحله پالایش اضافی برای هندسه با وفاداری بالاتر و جزئیات سطح ریزتر اجرا می‌کند. مقدار پیش‌فرض false است. | BOOLEAN | بله | true<br>false |
| `ultra_resolution` | رزولوشن پاس ultra: `"2k"` آن را در 2048³ و `"4k"` در 4096³ برای ریزترین جزئیات سطح اجرا می‌کند. `"4k"` به مدل `"meshy-7.1"` یا `"latest"` نیاز دارد. فقط زمانی استفاده می‌شود که `ultra_mode` فعال باشد (پیش‌فرض: `"2k"`). | COMBO | خیر | `"2k"`<br>`"4k"` |

*توجه: پارامترهای `topology` و `target_polycount` به‌صورت شرطی در دسترس هستند. آن‌ها فقط زمانی ظاهر می‌شوند که پارامتر `should_remesh` روی "true" تنظیم شده باشد.

هنگامی که `ultra_mode` فعال باشد، پارامتر `model` باید روی `"meshy-7.1"`، `"meshy-7"` یا `"latest"` تنظیم شود؛ انتخاب هر مدل دیگری خطا ایجاد می‌کند. با `"meshy-7"` پاس ultra همیشه در 2048³ اجرا می‌شود و رزولوشن `"4k"` به `"meshy-7.1"` یا `"latest"` نیاز دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل GLB تولیدشده. این خروجی برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `meshy_task_id` | شناسه یکتای وظیفه API Meshy. | MESHY_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی تولیدشده در قالب FBX. | FILE3DFBX |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyTextToModelNode/fa.md)
