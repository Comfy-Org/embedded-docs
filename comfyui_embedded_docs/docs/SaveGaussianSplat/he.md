# שמירת Splat

צומת זה שומר קובץ Gaussian splat תלת-ממדי לספריית הפלט. הוא מטפל בתהליך שמירת הקובץ ומספק נתוני תצוגה מקדימה עבור חלון התצוגה התלת-ממדי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | קובץ Gaussian splat תלת-ממדי. | FILE3D | כן | SplatAny<br>PLY<br>SPLAT<br>SPZ<br>KSPLAT |
| `filename_prefix` | הקידומת עבור שם הקובץ שנשמר (ברירת מחדל: "3d/ComfyUI"). | STRING | כן | כל קידומת שם קובץ תקינה |
| `viewport_state` | מצב חלון התצוגה הנוכחי המכיל מידע על המצלמה והמודל. | LOAD3D | כן | - |
| `model_3d_info` | מידע נוסף על מודל תלת-ממדי עבור חלון התצוגה. | LOAD3DMODELINFO | לא | - |
| `camera_info` | מידע על המצלמה עבור תצוגה מקדימה בחלון התצוגה. | LOAD3DCAMERA | לא | - |
| `width` | רוחב התצוגה המקדימה (ברירת מחדל: 1024). | INT | כן | 1 עד 4096 |
| `height` | גובה התצוגה המקדימה (ברירת מחדל: 1024). | INT | כן | 1 עד 4096 |

הערה: אם `camera_info` או `model_3d_info` לא מסופקים, הצומת משתמש בערכים המתאימים מ-`viewport_state` כאשר הם זמינים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_3d` | קובץ ה-Gaussian splat התלת-ממדי שנשמר לספריית הפלט. | FILE3D |
| `model_3d_info` | מידע על מודל תלת-ממדי עבור חלון התצוגה. | LOAD3DMODELINFO |
| `camera_info` | מידע על המצלמה עבור תצוגה מקדימה בחלון התצוגה. | LOAD3DCAMERA |
| `width` | רוחב התצוגה המקדימה. | INT |
| `height` | גובה התצוגה המקדימה. | INT |
