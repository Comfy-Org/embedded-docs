# שמירת התניה

צומת זה שומר התניה אחת לתיקיית הפלט כקובץ safetensors. ניתן להעביר את הקובץ השמור לתיקיית models/embeddings ולטעון אותו מאוחר יותר עם Load Conditioning, למשל כדי לדלג על מקודד הטקסט. הצומת מעביר את ההתניה הלאה ללא שינוי, כך שניתן עדיין להשתמש בה בהמשך זרימת העבודה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | ההתניה לשמירה. נתמכת רשומת התניה אחת בלבד. | CONDITIONING | כן | - |
| `filename_prefix` | קידומת המשמשת לבניית שם קובץ הפלט. הקובץ נכתב לתיקיית הפלט עם מונה מספרי שמתווסף בסופו. ברירת מחדל: `conditioning/ComfyUI` | STRING | כן | - |

**הערות:**

- אם הקלט `conditioning` מכיל יותר מרשומה אחת (למשל לאחר שילוב התניות), הצומת מעלה שגיאה: "Save Conditioning supports a single conditioning entry, save it before combining."
- אפשרויות התניה שהן טנסורים, רשימות/טיפלים של טנסורים, ערכים בוליאניים, מספרים שלמים, מספרי נקודה צפה או מחרוזות נשמרות לצד ההתניה. אפשרויות שהן `None` מדולגות. כל סוג אפשרות אחר מעלה שגיאה המציינת שלא ניתן לשמור את האפשרות.
