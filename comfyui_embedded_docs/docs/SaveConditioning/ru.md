# Сохранить кондиционирование

Этот узел сохраняет один conditioning в папку output в виде файла safetensors. Сохранённый файл можно переместить в папку models/embeddings и позже загрузить с помощью Load Conditioning, например чтобы пропустить текстовый энкодер. Узел передаёт conditioning без изменений, поэтому его по-прежнему можно использовать позже в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | Conditioning для сохранения. Поддерживается только одна запись conditioning. | CONDITIONING | Да | - |
| `filename_prefix` | Префикс, используемый для формирования имени выходного файла. Файл записывается в папку output с добавленным числовым счётчиком. По умолчанию: `conditioning/ComfyUI` | STRING | Да | - |

**Примечания:**

- Если вход `conditioning` содержит более одной записи (например, после объединения conditioning), узел выдаёт ошибку: "Save Conditioning supports a single conditioning entry, save it before combining."
- Опции conditioning, которые являются тензорами, списками/кортежами тензоров, булевыми значениями, целыми числами, числами с плавающей запятой или строками, сохраняются вместе с conditioning. Опции со значением `None` пропускаются. Любой другой тип опции вызывает ошибку с сообщением о том, что опцию невозможно сохранить.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `conditioning` | Тот же conditioning, который был передан на вход, без изменений. | CONDITIONING |
