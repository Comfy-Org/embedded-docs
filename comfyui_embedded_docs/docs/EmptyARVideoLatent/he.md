# EmptyARVideoLatent

צומת EmptyARVideoLatent יוצר ייצוג לטנטי ריק ליצירת וידאו. הוא בונה טנזור של אפסים באמצעות הרוחב, הגובה, מספר הפריימים וגודל האצווה המבוקשים, אשר לאחר מכן ניתן להשתמש בו כדי לאתחל תהליך יצירת וידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `width` | הרוחב של פריימי הווידאו בפיקסלים (ברירת מחדל: 832) | INT | כן | 16 עד 8192 (צעד: 16) |
| `height` | הגובה של פריימי הווידאו בפיקסלים (ברירת מחדל: 480) | INT | כן | 16 עד 8192 (צעד: 16) |
| `length` | מספר הפריימים בווידאו (ברירת מחדל: 81) | INT | כן | 1 עד 1024 (צעד: 4) |
| `batch_size` | מספר הווידאו ליצירה באצווה בודדת (ברירת מחדל: 1) | INT | כן | 1 עד 64 |

הערה: גודל לטנט פנימי נגזר מקלטים אלה. `width` ו-`height` מחולקים ב-8, ומספר צעדי הזמן הלטנטיים מחושב כ-`((length - 1) // 4) + 1`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `LATENT` | טנזור לטנטי מלא באפסים, המייצג מרחב לטנטי ריק של וידאו עם הממדים, האורך וגודל האצווה שצוינו. צורת הטנזור היא [batch_size, 16, lat_t, height/8, width/8], כאשר lat_t = ((length - 1) // 4) + 1 הוא מספר צעדי הזמן הלטנטיים הנגזרים מהאורך המבוקש. | LATENT |
