# EmptyARVideoLatent

## Обзор

Узел EmptyARVideoLatent создает пустое, незаполненное латентное представление для генерации видео. Он используется для инициализации процесса генерации видео путем создания тензора из нулей с заданными размерами, соотношением сторон и длиной.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина видеокадров в пикселях (по умолчанию: 832) | INT | Да | от 16 до 8192 (шаг: 16) |
| `height` | Высота видеокадров в пикселях (по умолчанию: 480) | INT | Да | от 16 до 8192 (шаг: 16) |
| `length` | Количество кадров в видео (по умолчанию: 81) | INT | Да | от 1 до 1024 (шаг: 4) |
| `batch_size` | Количество видео, генерируемых за один пакет (по умолчанию: 1) | INT | Да | от 1 до 64 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Латентный тензор, заполненный нулями, представляющий пустое латентное пространство видео с указанными размерами, длиной и размером пакета. Форма тензора: [batch_size, 16, lat_t, height/8, width/8], где lat_t = ((length - 1) // 4) + 1 — количество латентных временных шагов, полученное из запрошенной длины. | LATENT |
