# EmptyARVideoLatent

Узел `EmptyARVideoLatent` создаёт пустое латентное представление для генерации видео. Он используется для инициализации процесса генерации видео, предоставляя тензор из нулей с заданными размерами, соотношением сторон и длиной.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина кадров видео в пикселях (по умолчанию: 832) | INT | Да | от 16 до 8192 (шаг: 16) |
| `height` | Высота кадров видео в пикселях (по умолчанию: 480) | INT | Да | от 16 до 8192 (шаг: 16) |
| `length` | Количество кадров в видео (по умолчанию: 81) | INT | Да | от 1 до 1024 (шаг: 4) |
| `batch_size` | Количество видео для генерации за один батч (по умолчанию: 1) | INT | Да | от 1 до 64 |

## Выходы

| Выход | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Латентный тензор, заполненный нулями, представляющий пустое латентное пространство видео с заданными размерами, длиной и размером батча. Форма тензора: [batch_size, 16, lat_t, height/8, width/8], где lat_t вычисляется из длины. | LATENT |
