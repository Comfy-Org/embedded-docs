# EmptyARVideoLatent

Узел EmptyARVideoLatent создает пустое латентное представление для генерации видео. Он строит тензор из нулей с заданными шириной, высотой, количеством кадров и размером пакета, который затем можно использовать для инициализации процесса генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина кадров видео в пикселях (по умолчанию: 832) | INT | Да | 16–8192 (шаг: 16) |
| `height` | Высота кадров видео в пикселях (по умолчанию: 480) | INT | Да | 16–8192 (шаг: 16) |
| `length` | Количество кадров в видео (по умолчанию: 81) | INT | Да | 1–1024 (шаг: 4) |
| `batch_size` | Количество видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1–64 |

Примечание: Внутренний размер латентного представления вычисляется из этих входных данных. `width` и `height` делятся на 8, а количество латентных временных шагов вычисляется как `((length - 1) // 4) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Латентный тензор, заполненный нулями, представляющий пустое латентное пространство видео с указанными размерами, длиной и размером пакета. Форма тензора — [batch_size, 16, lat_t, height/8, width/8], где lat_t = ((length - 1) // 4) + 1 — количество латентных временных шагов, полученное из заданной длины. | LATENT |
