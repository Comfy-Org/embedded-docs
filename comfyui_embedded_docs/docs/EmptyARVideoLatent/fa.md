# EmptyARVideoLatent

گره EmptyARVideoLatent یک نمایش نهفته (latent) خالی برای تولید ویدیو ایجاد می‌کند. این گره یک تنسور از صفرها با استفاده از عرض، ارتفاع، تعداد فریم و اندازه دسته درخواستی می‌سازد که سپس می‌تواند برای مقداردهی اولیه فرایند تولید ویدیو استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `عرض` | عرض فریم‌های ویدیو بر حسب پیکسل (پیش‌فرض: 832) | INT | بله | 16 تا 8192 (گام: 16) |
| `ارتفاع` | ارتفاع فریم‌های ویدیو بر حسب پیکسل (پیش‌فرض: 480) | INT | بله | 16 تا 8192 (گام: 16) |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 81) | INT | بله | 1 تا 1024 (گام: 4) |
| `اندازه دسته` | تعداد ویدیوهایی که در یک دسته واحد تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 64 |

نکته: اندازه نهفته داخلی از این ورودی‌ها استخراج می‌شود. `width` و `height` بر 8 تقسیم می‌شوند، و تعداد گام‌های زمانی نهفته به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `LATENT` | یک تنسور نهفته پر از صفر که نمایش یک فضای نهفته ویدیویی خالی با ابعاد، طول و اندازه دسته مشخص‌شده را دارد. شکل تنسور [batch_size, 16, lat_t, height/8, width/8] است، که در آن lat_t = ((length - 1) // 4) + 1 تعداد گام‌های زمانی نهفته محاسبه‌شده از طول درخواستی است. | LATENT |
