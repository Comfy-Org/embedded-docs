# Quiver Image to SVG

Векторизует растровое изображение в масштабируемую векторную графику (SVG) с помощью Quiver AI. Изображение отправляется в API Quiver AI, который возвращает результат векторизации.

Выбор `model` открывает параметры, специфичные для модели, перечисленные ниже.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для векторизации в SVG. | DYNAMIC_COMBO | Да | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `image` | Входное изображение для векторизации. | IMAGE | Да | N/A |
| `auto_crop` | Автоматически обрезать до доминирующего объекта. Расширенный параметр (по умолчанию: False). | BOOLEAN | Да | `True`<br>`False` |
| `target_size` | Квадратное изменение размера, применяемое к входному изображению перед векторизацией, в пикселях. Значение 0 сохраняет исходный размер, что обеспечивает более чистое векторизование, чем принудительное изменение размера; любое другое значение ниже 128 ограничивается до 128. Это не задаёт выходной холст; для этого используйте `width` и `height`. Расширенный параметр (по умолчанию: 0). | INT | Да | 0 до 4096 |
| `width` | Ширина выходного холста SVG (viewBox) в пользовательских единицах. Задайте оба параметра `width` и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любой из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | 0 до 8192 |
| `height` | Высота выходного холста SVG (viewBox) в пользовательских единицах. Задайте оба параметра `width` и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любой из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | 0 до 8192 |
| `seed` | Сид для определения, должен ли узел перезапуститься; фактические результаты недетерминированы независимо от значения сида. Этот параметр имеет функциональность «управление после генерации» (по умолчанию: 42). | INT | Да | 0 до 2147483647 |

### Входы, специфичные для модели

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | Сколько рассуждений модель выполняет перед отрисовкой. Более высокие уровни повышают детализацию и расходуют больше токенов. Используется только моделями `"arrow-2"` и `"arrow-2-telos"` (по умолчанию: `"high"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | Управление случайностью. Более высокие значения увеличивают случайность. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 2.0 (шаг: 0.1) |
| `top_p` | Параметр нуклеус-сэмплинга. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | 0.05 до 1.0 (шаг: 0.05) |
| `presence_penalty` | Штраф за присутствие токена. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 0.0). | FLOAT | Да | -2.0 до 2.0 (шаг: 0.1) |

**Примечание:** `target_size` применяется перед векторизацией и не изменяет выходной холст. Оставьте `width` или `height` равным 0, чтобы модель выбрала размер холста.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `SVG` | Векторизованный вывод SVG. | SVG |
