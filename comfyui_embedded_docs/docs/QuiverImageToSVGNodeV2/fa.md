# Quiver Image to SVG

یک تصویر رستری را با Quiver AI به یک گرافیک برداری مقیاس‌پذیر (SVG) تبدیل کنید. تصویر به API مربوط به Quiver AI ارسال می‌شود و نتیجه برداری‌شده بازگردانده می‌شود.

با انتخاب یک `model`، پارامترهای ویژه مدل که در زیر فهرست شده‌اند نمایش داده می‌شوند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای برداری‌سازی SVG. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `image` | تصویر ورودی برای برداری‌سازی. | IMAGE | بله | N/A |
| `auto_crop` | به‌طور خودکار برش به سوژه غالب. پارامتر پیشرفته (پیش‌فرض: False). | BOOLEAN | بله | `True`<br>`False` |
| `target_size` | تغییر اندازه مربعی که پیش از برداری‌سازی روی تصویر ورودی اعمال می‌شود، بر حسب پیکسل، از 128 تا 4096. مقدار 0 اندازه منبع را حفظ می‌کند، که نسبت به اعمال اجباری تغییر اندازه، برداری‌سازی تمیزتری ارائه می‌دهد. این پارامتر بوم خروجی را تعیین نمی‌کند؛ برای آن از `width` و `height` استفاده کنید. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 4096 |
| `width` | عرض بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت تصویر خروجی، هم `width` و هم `height` را تنظیم کنید؛ هرکدام را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بومی مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `height` | ارتفاع بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت تصویر خروجی، هم `width` و هم `height` را تنظیم کنید؛ هرکدام را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بومی مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `seed` | `seed` برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به مقدار `seed` غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

### ورودی‌های ویژه مدل

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌بخشد و توکن‌های بیشتری مصرف می‌کند. فقط توسط مدل‌های `"arrow-2"` و `"arrow-2-telos"` استفاده می‌شود (پیش‌فرض: `"high"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | کنترل تصادفی‌بودن. مقادیر بالاتر تصادفی‌بودن را افزایش می‌دهند. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 2.0 (گام: 0.1) |
| `top_p` | پارامتر نمونه‌گیری هسته‌ای (nucleus sampling). توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.05 تا 1.0 (گام: 0.05) |
| `presence_penalty` | جریمه حضور توکن. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 0.0). | FLOAT | بله | -2.0 تا 2.0 (گام: 0.1) |

**توجه:** `target_size` پیش از برداری‌سازی اعمال می‌شود و بوم خروجی را تغییر نمی‌دهد. `width` یا `height` را روی 0 بگذارید تا مدل اندازه بوم را انتخاب کند.
