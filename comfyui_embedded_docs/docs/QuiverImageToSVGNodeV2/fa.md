# Quiver Image to SVG

یک تصویر رستری را با Quiver AI به یک گرافیک برداری مقیاس‌پذیر (SVG) تبدیل کنید. تصویر به API شرکت Quiver AI فرستاده می‌شود و نتیجه برداری‌شده را بازمی‌گرداند.

انتخاب یک `model` پارامترهای مخصوص مدل را که در ادامه فهرست شده‌اند آشکار می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای برداری‌سازی SVG استفاده می‌شود. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `image` | تصویر ورودی برای برداری‌سازی. | IMAGE | بله | N/A |
| `auto_crop` | به‌طور خودکار به سوژه غالب برش می‌دهد. پارامتر پیشرفته (پیش‌فرض: False). | BOOLEAN | بله | `True`<br>`False` |
| `target_size` | تغییر اندازه مربعی که پیش از برداری‌سازی روی تصویر ورودی اعمال می‌شود، بر حسب پیکسل. مقدار 0 اندازه منبع را حفظ می‌کند، که تمیزتر از تحمیل تغییر اندازه برداری‌سازی می‌کند؛ هر مقدار دیگری کمتر از 128 به 128 محدود می‌شود. این مقدار بوم خروجی را تعیین نمی‌کند؛ برای آن از `width` و `height` استفاده کنید. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 4096 |
| `width` | عرض بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هر دو `width` و `height` را تنظیم کنید؛ یکی از آن دو را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `height` | ارتفاع بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هر دو `width` و `height` را تنظیم کنید؛ یکی از آن دو را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `seed` | مقدار seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از مقدار seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

### ورودی‌های مخصوص مدل

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌دهند و توکن‌های بیشتری هزینه می‌کنند. فقط توسط مدل‌های `"arrow-2"` و `"arrow-2-telos"` استفاده می‌شود (پیش‌فرض: `"high"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | کنترل تصادفی‌بودن. مقادیر بالاتر تصادفی‌بودن را افزایش می‌دهند. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 2.0 (گام 0.1) |
| `top_p` | پارامتر نمونه‌گیری هسته‌ای. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.05 تا 1.0 (گام 0.05) |
| `presence_penalty` | جریمه حضور توکن. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 0.0). | FLOAT | بله | -2.0 تا 2.0 (گام 0.1) |

**توجه:** `target_size` پیش از برداری‌سازی اعمال می‌شود و بوم خروجی را تغییر نمی‌دهد. `width` یا `height` را روی 0 بگذارید تا مدل اندازه بوم را انتخاب کند.
