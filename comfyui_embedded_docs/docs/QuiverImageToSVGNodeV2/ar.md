# Quiver Image to SVG

حوّل صورة نقطية إلى رسم متجهي قابل للتحجيم (SVG) باستخدام Quiver AI. تُرسَل الصورة إلى واجهة API الخاصة بـ Quiver AI، التي تُعيد النتيجة المتجهة.

يؤدي تحديد `model` إلى إظهار المعاملات الخاصة بالنموذج المدرجة أدناه.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم في التحويل المتجهي إلى SVG. | DYNAMIC_COMBO | نعم | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `image` | الصورة المدخلة المراد تحويلها إلى متجهات. | IMAGE | نعم | لا ينطبق |
| `auto_crop` | قصّ تلقائي إلى الموضوع المهيمن. معامل متقدم (الافتراضي: False). | BOOLEAN | نعم | `True`<br>`False` |
| `target_size` | تغيير حجم مربّع يُطبَّق على الصورة المدخلة قبل التحويل المتجهي، بوحدة البكسل. القيمة 0 تُبقي حجم المصدر، وهو ما ينتج تحويلًا متجهيًا أنظف من فرض تغيير الحجم؛ أي قيمة أخرى أقل من 128 يتم تقييدها إلى 128. لا يضبط هذا لوحة المخرجات؛ استخدم `width` و`height` لذلك. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 4096 |
| `width` | عرض لوحة SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم المخرجات ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، وهو ما يعطي عادةً لوحة مربعة. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 8192 |
| `height` | ارتفاع لوحة SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم المخرجات ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، وهو ما يعطي عادةً لوحة مربعة. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 8192 |
| `seed` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن قيمة البذرة. يمتلك هذا المعامل وظيفة "التحكم بعد التوليد" (الافتراضي: 42). | INT | نعم | 0 إلى 2147483647 |

### المدخلات الخاصة بالنموذج

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | مقدار الاستدلال الذي يبذله النموذج قبل الرسم. المستويات الأعلى تحسّن التفاصيل وتستهلك رموزًا أكثر. يُستخدم فقط مع نموذجَي `"arrow-2"` و`"arrow-2-telos"` (الافتراضي: `"high"`). | COMBO | نعم | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | التحكم في العشوائية. القيم الأعلى تزيد العشوائية. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 1.0). | FLOAT | نعم | 0.0 إلى 2.0 (خطوة 0.1) |
| `top_p` | معامل أخذ العينات النووية. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 1.0). | FLOAT | نعم | 0.05 إلى 1.0 (خطوة 0.05) |
| `presence_penalty` | عقوبة حضور الرموز. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 0.0). | FLOAT | نعم | -2.0 إلى 2.0 (خطوة 0.1) |

**ملاحظة:** يُطبَّق `target_size` قبل التحويل المتجهي ولا يغيّر لوحة المخرجات. اترك `width` أو `height` عند 0 ليختار النموذج حجم اللوحة.
