# Quiver Image to SVG

حوّل صورة نقطية إلى رسم متجهي قابل للتحجيم (SVG) باستخدام Quiver AI. تُرسَل الصورة إلى واجهة برمجة تطبيقات Quiver AI، التي تُعيد النتيجة المتجهة.

يؤدي اختيار `model` إلى إظهار المعاملات الخاصة بالنموذج المدرجة أدناه.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم لتحويل الصور إلى SVG متجهي. | DYNAMIC_COMBO | نعم | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `image` | الصورة المدخلة المراد تحويلها إلى متجهات. | IMAGE | نعم | N/A |
| `auto_crop` | اقتصاص تلقائي إلى العنصر المهيمن. معامل متقدم (الافتراضي: False). | BOOLEAN | نعم | `True`<br>`False` |
| `target_size` | تغيير حجم مربّع يُطبَّق على الصورة المدخلة قبل التحويل إلى متجهات، بالبكسل، من 128 إلى 4096. القيمة 0 تحتفظ بحجم المصدر، وهو ما يعطي تحويلًا إلى متجهات أكثر نظافة من فرض تغيير الحجم. لا يضبط هذا الإخراج لوحة الرسم الناتجة؛ استخدم `width` و`height` لذلك. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 4096 |
| `width` | عرض لوحة رسم SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم الإخراج ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، وهو ما يعطي عادةً لوحة رسم مربعة. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 8192 |
| `height` | ارتفاع لوحة رسم SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم الإخراج ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، وهو ما يعطي عادةً لوحة رسم مربعة. معامل متقدم (الافتراضي: 0). | INT | نعم | 0 إلى 8192 |
| `seed` | بذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن قيمة البذرة. يمتلك هذا المعامل وظيفة «التحكم بعد التوليد» (control after generate) (الافتراضي: 42). | INT | نعم | 0 إلى 2147483647 |

### المدخلات الخاصة بالنموذج

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | مقدار الاستدلال الذي يستهلكه النموذج قبل الرسم. المستويات الأعلى تحسّن التفاصيل وتستهلك عددًا أكبر من الرموز (tokens). يُستخدم فقط مع نموذجَي `"arrow-2"` و`"arrow-2-telos"` (الافتراضي: `"high"`). | COMBO | نعم | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | التحكم في العشوائية. القيم الأعلى تزيد العشوائية. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 1.0). | FLOAT | نعم | 0.0 إلى 2.0 (الخطوة 0.1) |
| `top_p` | معامل أخذ العينات النووي (nucleus sampling). لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 1.0). | FLOAT | نعم | 0.05 إلى 1.0 (الخطوة 0.05) |
| `presence_penalty` | عقوبة وجود الرموز (tokens). لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (الافتراضي: 0.0). | FLOAT | نعم | -2.0 إلى 2.0 (الخطوة 0.1) |

**ملاحظة:** يتم تطبيق `target_size` قبل التحويل إلى متجهات ولا يغيّر لوحة الرسم الناتجة. اترك `width` أو `height` عند 0 ليختار النموذج حجم لوحة الرسم.
