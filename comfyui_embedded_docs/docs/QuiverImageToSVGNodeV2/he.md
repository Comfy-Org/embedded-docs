# QuiverImageToSVGNodeV2

המר תמונת רסטר לגרפיקה וקטורית ניתנת להרחבה (SVG) עם Quiver AI. התמונה נשלחת ל-API של Quiver AI, שמחזיר את התוצאה הווקטורית.

**הערה:** Quiver מפסיקה את מודלי סדרת Arrow 1 ב-16 באוקטובר 2026, ולכן האפשרויות `arrow-1.1`, `arrow-1.1-max` ו-`arrow-preview` מפסיקות לעבוד לאחר תאריך זה. השתמשו ב-`arrow-2` או `arrow-2-telos` במקום.

בחירה ב-`model` חושפת את הפרמטרים הספציפיים למודל המפורטים להלן.

### קלטים ספציפיים למודל

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | כמה מאמץ חשיבה המודל משקיע לפני הציור. רמות גבוהות יותר משפרות את הפרטים וצורכות יותר טוקנים. משמש רק במודלים `"arrow-2"` ו-`"arrow-2-telos"` (ברירת מחדל: `"high"`). | COMBO | כן | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | שליטה באקראיות. ערכים גבוהים יותר מגבירים את האקראיות. לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 עד 2.0 (צעד 0.1) |
| `top_p` | פרמטר דגימת גרעין (nucleus sampling). לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 1.0). | FLOAT | כן | 0.05 עד 1.0 (צעד 0.05) |
| `presence_penalty` | קנס נוכחות טוקנים. לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 0.0). | FLOAT | כן | -2.0 עד 2.0 (צעד 0.1) |

**הערה:** `target_size` מוחל לפני הווקטוריזציה ואינו משנה את קנבס הפלט. השאר את `width` או `height` ב-0 כדי לתת למודל לבחור את גודל הקנבס.
