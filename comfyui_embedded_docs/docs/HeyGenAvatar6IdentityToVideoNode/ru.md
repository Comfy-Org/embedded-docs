# HeyGen Avatar 6 Identity to Video

Создайте говорящее видео с аватаром HeyGen с помощью Avatar 6. Выберите один из встроенных образов, поддерживающих Avatar 6, или вставьте собственный ID аватара HeyGen, затем управляйте им с помощью текстового сценария или собственного аудио.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Селектор модели. `"heygen-avatar-6-turbo"` — более дешёвый и быстрый уровень; обе модели принимают одинаковые входы и разрешения. | COMBO | Да | `"heygen-avatar-6"`<br>`"heygen-avatar-6-turbo"` |
| `avatar` | Образ аватара для отображения. 19 встроенных образов, поддерживающих Avatar 6, перечислены напрямую; `custom avatar` открывает `custom_avatar_id` для образа, созданного вами в HeyGen. | DYNAMIC_COMBO | Да | 19 встроенных образов<br>`custom avatar` |
| `speech` | Управляйте аватаром с помощью текстового сценария (синтез речи HeyGen) или собственного аудио. Отображаемое имя: источник речи. | DYNAMIC_COMBO | Да | `"script"`<br>`"audio"` |
| `resolution` | Разрешение выходного видео. По умолчанию: `"1080p"`. | COMBO | Да | `"1080p"`<br>`"2k"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` следует исходному материалу образа аватара. По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `motion_prompt` | Необязательное указание для жестов, выражения лица, позы и движения камеры. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `motion_expressiveness` | `"less"` даёт меньше и более мелкие жесты. Подсказка движения имеет приоритет там, где они пересекаются. По умолчанию: `"default"`. | COMBO | Да | `"less"`<br>`"default"` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы `custom avatar`

Эти входы появляются, когда для `avatar` выбрано `custom avatar`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `custom_avatar_id` | ID образа аватара HeyGen, поддерживающего Avatar 6, например созданного с помощью HeyGen Create Avatar. По умолчанию: пустая строка. | STRING | Да | - |

### Входы речи `script`

Эти входы появляются, когда для `speech` выбрано `"script"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст, который аватар должен произнести. По умолчанию: пустая строка. | STRING | Да | до 5000 символов |
| `voice` | Голос для сценария. Опция по умолчанию использует голос, назначенный аватару HeyGen; у аватаров, созданных с помощью HeyGen Create Avatar, голос отсутствует, поэтому выберите для них голос. | COMBO | Да | `"(avatar's default voice)"` плюс общий список голосов HeyGen |
| `custom_voice_id` | Необязательный ID голоса HeyGen. Если задан, переопределяет голос, выбранный выше. По умолчанию: пустая строка. | STRING | Нет | - |
| `voice_speed` | Множитель скорости речи. По умолчанию: 1.0. | FLOAT | Нет | от 0.5 до 1.5 (шаг 0.05) |

### Входы речи `audio`

Эти входы появляются, когда для `speech` выбрано `"audio"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Речь для аватара. Длительность видео соответствует аудио. | AUDIO | Да | от 0.5 секунды до 10 минут |

**Ограничения и поведение:**

* Для `custom avatar` требуется непустой ID аватара, иначе узел выдаёт ошибку.
* Сценарий ограничен 5000 символами, аудио — 10 минутами.
* Цена рассчитывается за секунду выходного видео и зависит от модели и разрешения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное говорящее видео, загружаемое из HeyGen после завершения рендеринга. | VIDEO |
