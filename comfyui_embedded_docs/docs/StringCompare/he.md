# StringCompare

צומת StringCompare משווה בין שתי מחרוזות טקסט באמצעות שיטות השוואה שונות. הוא יכול לבדוק אם מחרוזת אחת מתחילה במחרוזת אחרת, מסתיימת במחרוזת אחרת, או אם שתי המחרוזות זהות לחלוטין. ניתן לבצע את ההשוואה תוך התחשבות בהבדלי אותיות רישיות/קטנות או בלי להתחשב בהם.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `string_a` | המחרוזת הראשונה להשוואה | STRING | כן | - |
| `string_b` | המחרוזת השנייה שיש להשוות אליה | STRING | כן | - |
| `mode` | שיטת ההשוואה שבה יש להשתמש (ברירת מחדל: "Starts With") | COMBO | כן | "Starts With"<br>"Ends With"<br>"Equal" |
| `case_sensitive` | האם להתחשב בהבדלי אותיות רישיות/קטנות במהלך ההשוואה (ברירת מחדל: true) | BOOLEAN | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | מחזיר true אם תנאי ההשוואה מתקיים, אחרת false | BOOLEAN |
