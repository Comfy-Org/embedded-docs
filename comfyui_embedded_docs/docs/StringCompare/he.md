# השוואת טקסט

צומת StringCompare משווה בין שתי מחרוזות טקסט באמצעות שיטות השוואה שונות. הוא יכול לבדוק אם מחרוזת אחת מתחילה במחרוזת אחרת, מסתיימת במחרוזת אחרת, או אם שתי המחרוזות זהות לחלוטין. ניתן לבצע את ההשוואה תוך התחשבות בהבדלי אותיות רישיות/קטנות או בלי להתחשב בהם.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `מחרוזת א` | המחרוזת הראשונה להשוואה | STRING | כן | - |
| `מחרוזת ב` | המחרוזת השנייה שיש להשוות אליה | STRING | כן | - |
| `מצב` | שיטת ההשוואה שבה יש להשתמש (ברירת מחדל: "Starts With") | COMBO | כן | "Starts With"<br>"Ends With"<br>"Equal" |
| `תלוי רישיות` | האם להתחשב בהבדלי אותיות רישיות/קטנות במהלך ההשוואה (ברירת מחדל: true) | BOOLEAN | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | מחזיר true אם תנאי ההשוואה מתקיים, אחרת false | BOOLEAN |
