# LTXV Пустое латентное аудио

Узел LTXV Empty Latent Audio создаёт пакет пустых (заполненных нулями) латентных аудиотензоров. Он считывает конфигурацию подключённой модели Audio VAE, чтобы определить правильные размерности латентного пространства, такие как количество каналов и частотных бинов, и вычисляет, сколько аудиолатентов требуется, исходя из количества кадров и частоты кадров. Полученный пустой латент можно использовать в качестве отправной точки для рабочих процессов генерации или обработки аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `frames_number` | Количество кадров. Значение по умолчанию — 97. | INT | Да | 1 до 1000 |
| `frame_rate` | Количество кадров в секунду. Значение по умолчанию — 25.0. Этот вход принимает значения FLOAT или INT. | FLOAT | Да | 1.0 до 1000.0 |
| `batch_size` | Количество латентных аудиосэмплов в пакете. Значение по умолчанию — 1. | INT | Да | 1 до 4096 |
| `audio_vae` | Модель Audio VAE, из которой берётся конфигурация. Отображается как "Audio VAE". | VAE | Да | N/A |

**Примечание:** Вход `audio_vae` является обязательным. Узел выдаёт ошибку, если он не указан.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `Latent` | Пустой латентный аудиотензор с формой (batch_size, z_channels, num_audio_latents, audio_freq), где количество каналов и частотные бины берутся из Audio VAE, а количество аудиолатентов вычисляется из `frames_number` и `frame_rate`. Выход также содержит поле `type` со значением "audio". | LATENT |
