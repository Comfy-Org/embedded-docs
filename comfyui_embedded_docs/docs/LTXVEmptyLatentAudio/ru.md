# LTXV Пустое латентное аудио

Узел LTXV Empty Latent Audio создает пакет пустых (заполненных нулями) латентных аудио-тензоров. Он использует конфигурацию предоставленной модели Audio VAE для определения правильных размерностей латентного пространства, таких как количество каналов и частотных бинов. Количество аудио-латентов вычисляется из количества кадров и частоты кадров с помощью модели Audio VAE. Этот пустой латент служит отправной точкой для рабочих процессов генерации или манипуляции аудио в ComfyUI.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `frames_number` | Количество кадров. По умолчанию: 97. | INT | Да | 1 to 1000 |
| `frame_rate` | Количество кадров в секунду. Принимает значения с плавающей запятой или целые значения. По умолчанию: 25.0. | FLOAT (or INT) | Да | 1.0 to 1000.0 |
| `batch_size` | Количество образцов латентного аудио в пакете. По умолчанию: 1. | INT | Да | 1 to 4096 |
| `audio_vae` | Модель Audio VAE, из которой берётся конфигурация. | VAE | Да | N/A |

**Примечание:** Входной параметр `audio_vae` является обязательным. Узел выдаст ошибку, если он не будет предоставлен.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `Latent` | Пустой латентный аудио-тензор со структурой (batch_size, z_channels, num_audio_latents, audio_freq), настроенный в соответствии с входной моделью Audio VAE. Выход также содержит поле `type`, установленное в значение «audio». | LATENT |
