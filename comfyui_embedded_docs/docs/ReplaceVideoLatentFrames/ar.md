# استبدال إطارات latent للفيديو

تقوم عقدة ReplaceVideoLatentFrames بإدراج إطارات من فيديو لاتنت مصدر إلى فيديو لاتنت وجهة، بدءًا من فهرس إطار محدد. إذا لم يتم توفير اللاتنت المصدر، فسيتم إرجاع اللاتنت الوجهة دون تغيير. تتعامل العقدة مع الفهرسة السالبة وتصدر تحذيرًا إذا لم تتناسب الإطارات المصدر مع الوجهة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `destination` | اللاتنت الوجهة حيث سيتم استبدال الإطارات. | LATENT | نعم | - |
| `source` | اللاتنت المصدر الذي يوفر إطارات لإدراجها في اللاتنت الوجهة. إذا لم يتم توفيره، فسيتم إرجاع اللاتنت الوجهة دون تغيير. | LATENT | لا | - |
| `index` | فهرس إطار اللاتنت الابتدائي في اللاتنت الوجهة حيث سيتم وضع إطارات اللاتنت المصدر. القيم السالبة تُعد من النهاية (الافتراضي: 0). | INT | نعم | -MAX_RESOLUTION to MAX_RESOLUTION (step: 1) |

**القيود:**

* يجب أن يكون `index` ضمن حدود عدد إطارات اللاتنت الوجهة. إذا لم يكن كذلك، يتم تسجيل تحذير ويتم إرجاع الوجهة دون تغيير.
* يجب أن تتوافق إطارات اللاتنت المصدر مع إطارات اللاتنت الوجهة بدءًا من `index` المحدد. إذا لم تتوافق، يتم تسجيل تحذير ويتم إرجاع الوجهة دون تغيير.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `output` | فيديو اللاتنت الناتج بعد عملية استبدال الإطارات. | LATENT |
