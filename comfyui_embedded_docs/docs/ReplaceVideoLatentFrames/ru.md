# Заменить кадры видео latent

Узел `ReplaceVideoLatentFrames` вставляет кадры из исходного латентного видео в целевое латентное видео, начиная с указанного индекса кадра. Если исходный латент не предоставлен, целевой латент возвращается без изменений. Узел поддерживает отрицательную индексацию и выдаст предупреждение, если исходные кадры не помещаются в целевое видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `destination` | Целевой латент, в котором будут заменены кадры. | LATENT | Да | - |
| `source` | Исходный латент, предоставляющий кадры для вставки в целевой латент. Если не указан, целевой латент возвращается без изменений. | LATENT | Нет | - |
| `index` | Индекс начального латентного кадра в целевом латенте, в который будут помещены кадры исходного латента. Отрицательные значения отсчитываются от конца (по умолчанию: 0). | INT | Да | -MAX_RESOLUTION to MAX_RESOLUTION (step: 1) |

**Ограничения:**

* Значение `index` должно находиться в пределах количества кадров целевого латента. Если это не так, регистрируется предупреждение, и целевой латент возвращается без изменений.
* Кадры исходного латента должны помещаться в кадры целевого латента, начиная с указанного `index`. Если они не помещаются, регистрируется предупреждение, и целевой латент возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Результирующее латентное видео после операции замены кадров. | LATENT |
