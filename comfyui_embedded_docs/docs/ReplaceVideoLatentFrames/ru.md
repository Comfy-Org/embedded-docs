# Заменить кадры видео latent

ReplaceVideoLatentFrames заменяет диапазон кадров в целевом латентном видео кадрами из исходного латентного видео, начиная с указанного индекса кадра. Если исходный латент не предоставлен, целевой латент возвращается без изменений. Узел поддерживает отрицательные индексы и выводит предупреждение, если исходные кадры не помещаются в целевой латент.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `destination` | Целевой латент, в котором будут заменяться кадры. | LATENT | Да | - |
| `source` | Исходный латент, предоставляющий кадры для вставки в целевой латент. Если не указан, целевой латент возвращается без изменений. | LATENT | Нет | - |
| `index` | Начальный индекс кадра в целевом латенте, начиная с которого будут размещены кадры исходного латента. Отрицательные значения отсчитываются от конца (по умолчанию: 0). | INT | Да | -MAX_RESOLUTION to MAX_RESOLUTION |

**Ограничения:**

* Отрицательный `index` корректируется путём его добавления к количеству кадров целевого латента, то есть он отсчитывается назад от конца целевого латента.
* Если `index` указывает за пределы количества кадров целевого латента или если исходные кадры не помещаются в целевой латент начиная с `index`, выводится предупреждение и целевой латент возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Результирующее латентное видео после операции замены кадров. Если замена не может быть выполнена, целевой латент возвращается без изменений. | LATENT |
