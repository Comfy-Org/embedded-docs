# Загрузка модели оптического потока

## Обзор

Загружает модель оптического потока из папки `models/optical_flow/`. В настоящее время поддерживается только формат RAFT-large от torchvision, который используется узлом VOIDWarpedNoise. ComfyUI не загружает веса оптического потока автоматически; вы должны вручную поместить файл контрольной точки в каталог `models/optical_flow/`.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model_name` | Модель оптического потока для загрузки. Файлы должны быть размещены в папке `optical_flow`. Сейчас поддерживается только `raft_large.pth` от torchvision. | COMBO | Да | Список файлов в папке `models/optical_flow/` |

Выбранный файл должен быть контрольной точкой RAFT-large от torchvision. Узел проверяет, что файл содержит ожидаемые ключи RAFT (`feature_encoder.*`, `context_encoder.*` и `update_block.*`), и вызывает ValueError, если формат не распознан.

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `OPTICAL_FLOW` | Загруженная модель оптического потока, обёрнутая в ModelPatcher для использования с другими узлами. | OPTICAL_FLOW |
