# Загрузка модели оптического потока

Загружает модель оптического потока из папки `models/optical_flow/`. В настоящее время поддерживается только формат RAFT-large из torchvision, который используется узлом VOIDWarpedNoise. ComfyUI не загружает веса оптического потока автоматически; вы должны вручную поместить файл контрольной точки в каталог `models/optical_flow/`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model_name` | Модель оптического потока для загрузки. Файлы должны быть размещены в папке `optical_flow`. В настоящее время поддерживается только `raft_large.pth` из torchvision. | COMBO | Да | Список файлов в папке `models/optical_flow/` |

Примечание: выбранная контрольная точка должна быть state dict формата RAFT-large из torchvision, содержащим ключи с префиксами `feature_encoder.`, `context_encoder.` и `update_block.`. Если файл не соответствует этому формату, узел вызывает ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `OPTICAL_FLOW` | Загруженная модель оптического потока, переведённая в режим оценки и точность float32, обёрнутая в ModelPatcher для использования с другими узлами. | OPTICAL_FLOW |
