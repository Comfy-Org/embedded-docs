# Создать обучающий датасет

Этот узел подготавливает данные для обучения, кодируя изображения и текст. Он принимает список изображений и соответствующий список текстовых подписей, затем использует модель VAE для преобразования изображений в скрытые представления (латентные), а модель CLIP — для преобразования текста в данные кондиционирования. Результирующие пары латентных представлений и кондиционирования выводятся в виде списков, готовых к использованию в рабочих процессах обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Список изображений для кодирования. | IMAGE | Да | N/A |
| `vae` | Модель VAE для кодирования изображений в латентные представления. | VAE | Да | N/A |
| `clip` | Модель CLIP для кодирования текста в кондиционирование. | CLIP | Да | N/A |
| `тексты` | Список текстовых подписей. Может содержать n элементов (соответствует изображениям), 1 элемент (повторяется для всех) или быть пустым (используется пустая строка). | STRING | Нет | 0, 1 или n элементов (n = количество изображений) |

**Ограничения параметров:**

* Количество элементов в списке `texts` должно быть 0, 1 или точно соответствовать количеству элементов в списке `images`. Если оно равно 0, для всех изображений используется пустая строка. Если равно 1, этот единственный текст повторяется для всех изображений. Любая другая длина вызывает ошибку.
* Выходные списки `latents` и `conditioning` всегда содержат то же количество элементов, что и список `images`, поэтому каждое латентное представление сопоставляется с кондиционированием для соответствующей подписи.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список словарей латентных представлений. | LATENT |
| `conditioning` | Список списков кондиционирования. | CONDITIONING |
