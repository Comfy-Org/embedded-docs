# Создать обучающий датасет

Этот узел подготавливает данные для обучения, кодируя изображения и текст. Он принимает список изображений и соответствующий список текстовых подписей, затем использует модель VAE для преобразования изображений в латентные представления и модель CLIP для преобразования текста в данные кондиционирования. Результирующие пары латентных представлений и кондиционирования выводятся в виде списков, готовых к использованию в процессах обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Список изображений для кодирования. | IMAGE | Да | N/A |
| `vae` | Модель VAE для кодирования изображений в латентные представления. | VAE | Да | N/A |
| `clip` | Модель CLIP для кодирования текста в кондиционирование. | CLIP | Да | N/A |
| `texts` | Список текстовых подписей. Может иметь длину n (соответствует количеству изображений), 1 (повторяется для всех) или отсутствовать (используется пустая строка). | STRING | Нет | N/A |

**Ограничения параметров:**

* Количество элементов в списке `texts` должно быть равно 0, 1 или точно соответствовать количеству элементов в списке `images`. Если это 0, для всех изображений используется пустая строка. Если это 1, этот единственный текст повторяется для всех изображений. При любом другом значении узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список словарей латентных представлений. | LATENT |
| `conditioning` | Список списков кондиционирования. | CONDITIONING |
