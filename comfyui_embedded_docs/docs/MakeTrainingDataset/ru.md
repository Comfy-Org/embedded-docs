# Создать обучающий датасет

Этот узел подготавливает данные для обучения, кодируя изображения и текст. Он принимает список изображений и соответствующий список текстовых подписей, затем использует модель VAE для преобразования изображений в латентные представления и модель CLIP для преобразования текста в данные кондиционирования. Полученные спаренные латентные представления и кондиционирование выводятся в виде списков, готовых к использованию в рабочих процессах обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Список изображений для кодирования. | IMAGE | Да | N/A |
| `vae` | Модель VAE для кодирования изображений в латентные представления. | VAE | Да | N/A |
| `clip` | Модель CLIP для кодирования текста в кондиционирование. | CLIP | Да | N/A |
| `тексты` | Список текстовых подписей. Может иметь длину n (совпадающую с количеством изображений), 1 (повторяется для всех) или быть опущенным (используется пустая строка). | STRING | Нет | 0, 1 или n элементов (n = количество изображений) |

**Ограничения параметров:**

* Этот узел использует списочные входы: `images` и `texts` обрабатываются как списки, тогда как `vae` и `clip` принимают по одной модели каждый (используется первый элемент переданного списка).
* Количество элементов в списке `texts` должно быть 0, 1 или точно совпадать с количеством элементов в списке `images`. Если оно равно 0 или список опущен, для всех изображений используется пустая строка. Если оно равно 1, этот единственный текст повторяется для всех изображений. Любая другая длина вызывает ошибку.
* Выходные списки `latents` и `conditioning` всегда содержат столько же элементов, сколько список `images`, поэтому каждое латентное представление спарено с кондиционированием для соответствующей ему подписи.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latents` | Список латентных словарей. | LATENT |
| `conditioning` | Список списков кондиционирования. | CONDITIONING |
