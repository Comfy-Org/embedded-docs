# ایجاد دیتاست آموزش

این گره با رمزگذاری تصاویر و متن، داده‌ها را برای آموزش آماده می‌کند. این گره فهرستی از تصاویر و فهرست متناظری از زیرنویس‌های متنی را دریافت کرده، سپس از یک مدل VAE برای تبدیل تصاویر به بازنمایی‌های پنهان (لاتنت) و از یک مدل CLIP برای تبدیل متن به داده‌های کاندیشنینگ استفاده می‌کند. لاتنت‌ها و کاندیشنینگ‌های جفت‌شدهٔ حاصل، به‌صورت فهرست‌هایی خروجی داده می‌شوند و برای استفاده در گردش‌های کاری آموزش آماده هستند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `images` | فهرست تصاویر برای رمزگذاری. | IMAGE | بله | N/A |
| `vae` | مدل VAE برای رمزگذاری تصاویر به لاتنت. | VAE | بله | N/A |
| `clip` | مدل CLIP برای رمزگذاری متن به کاندیشنینگ. | CLIP | بله | N/A |
| `texts` | فهرست زیرنویس‌های متنی. می‌تواند طول n (مطابق با تصاویر)، 1 (برای همه تکرار شود) یا حذف‌شده باشد (از رشتهٔ خالی استفاده می‌شود). | STRING | خیر | N/A |

**محدودیت‌های پارامتر:**

* تعداد آیتم‌های فهرست `texts` باید 0، 1 یا دقیقاً برابر با تعداد آیتم‌های فهرست `images` باشد. اگر 0 باشد، یک رشتهٔ خالی برای همهٔ تصاویر استفاده می‌شود. اگر 1 باشد، همان متن تکی برای همهٔ تصاویر تکرار می‌شود. اگر تعداد هر چیز دیگری باشد، گره خطا صادر می‌کند.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
| --- | --- | --- |
| `latents` | فهرست دیکشنری‌های لاتنت. | LATENT |
| `conditioning` | فهرست فهرست‌های کاندیشنینگ. | CONDITIONING |
