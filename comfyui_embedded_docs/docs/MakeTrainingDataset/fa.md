# ایجاد دیتاست آموزش

این گره داده‌ها را برای آموزش با کدگذاری تصاویر و متن آماده می‌کند. یک فهرست از تصاویر و یک فهرست متناظر از شرح‌های متنی می‌گیرد، سپس از یک مدل VAE برای تبدیل تصاویر به لاتنت و از یک مدل CLIP برای تبدیل متن به داده‌های شرطی‌سازی استفاده می‌کند. لاتنت‌ها و شرطی‌سازی‌های جفت‌شدهٔ حاصل به‌صورت فهرست‌هایی خروجی داده می‌شوند و برای استفاده در گردش‌های کاری آموزش آماده‌اند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `تصاویر` | فهرستی از تصاویر برای کدگذاری. | IMAGE | بله | N/A |
| `vae` | مدل VAE برای کدگذاری تصاویر به لاتنت. | VAE | بله | N/A |
| `clip` | مدل CLIP برای کدگذاری متن به شرطی‌سازی. | CLIP | بله | N/A |
| `متون` | فهرستی از شرح‌های متنی. می‌تواند طول n (مطابق با تعداد تصاویر)، 1 (تکرار برای همه)، یا حذف‌شده (استفاده از رشته خالی) باشد. | STRING | خیر | 0، 1، یا n مورد (n = تعداد تصاویر) |

**محدودیت‌های پارامتر:**

- تعداد آیتم‌های فهرست `texts` باید 0، 1، یا دقیقاً برابر با تعداد آیتم‌های فهرست `images` باشد. اگر 0 باشد، یک رشته خالی برای همه تصاویر استفاده می‌شود. اگر 1 باشد، همان متن واحد برای همه تصاویر تکرار می‌شود. هر طول دیگری خطا ایجاد می‌کند.
- فهرست‌های خروجی `latents` و `conditioning` همیشه تعداد آیتم‌های یکسانی با فهرست `images` دارند، بنابراین هر لاتنت با شرطی‌سازی مربوط به شرح متناظر خود جفت می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `latents` | فهرستی از دیکشنری‌های لاتنت. | LATENT |
| `conditioning` | فهرستی از فهرست‌های شرطی‌سازی. | CONDITIONING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MakeTrainingDataset/fa.md)
