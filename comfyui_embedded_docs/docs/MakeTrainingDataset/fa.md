# ایجاد دیتاست آموزش

این گره با کدگذاری تصاویر و متن، داده‌ها را برای آموزش آماده می‌کند. فهرستی از تصاویر و فهرستی متناظر از توضیحات متنی را می‌گیرد، سپس با استفاده از مدل VAE تصاویر را به بازنمایی‌های نهفته (latent) و با استفاده از مدل CLIP متن را به داده‌های شرطی‌سازی (conditioning) تبدیل می‌کند. جفت‌های نهفته و شرطی‌سازی حاصل به‌صورت فهرست خروجی داده می‌شوند و برای استفاده در جریان‌های کاری آموزش آماده‌اند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `تصاویر` | فهرستی از تصاویر برای کدگذاری. | IMAGE | بله | N/A |
| `vae` | مدل VAE برای کدگذاری تصاویر به نهفته‌ها. | VAE | بله | N/A |
| `clip` | مدل CLIP برای کدگذاری متن به شرطی‌سازی. | CLIP | بله | N/A |
| `متون` | فهرستی از توضیحات متنی. می‌تواند به طول n (متناظر با تصاویر)، 1 (تکرار برای همه)، یا حذف‌شده (استفاده از رشته خالی) باشد. | STRING | خیر | 0، 1 یا n مورد (n = تعداد تصاویر) |

**محدودیت‌های پارامتر:**

* این گره از ورودی‌های فهرستی استفاده می‌کند: `images` و `texts` به‌صورت فهرست پردازش می‌شوند، در حالی که `vae` و `clip` هرکدام یک مدل واحد می‌پذیرند (از اولین مورد فهرست ارائه‌شده استفاده می‌شود).
* تعداد موارد در فهرست `texts` باید 0، 1 یا دقیقاً برابر با تعداد موارد در فهرست `images` باشد. اگر 0 باشد یا حذف شود، برای همه تصاویر از یک رشته خالی استفاده می‌شود. اگر 1 باشد، همان متن واحد برای همه تصاویر تکرار می‌شود. هر طول دیگری خطا ایجاد می‌کند.
* فهرست‌های خروجی `latents` و `conditioning` همیشه همان تعداد مورد فهرست `images` را دارند، بنابراین هر latent با conditioning متناظر با توضیح خود جفت می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `latents` | فهرستی از دیکشنری‌های نهفته. | LATENT |
| `conditioning` | فهرستی از فهرست‌های شرطی‌سازی. | CONDITIONING |
