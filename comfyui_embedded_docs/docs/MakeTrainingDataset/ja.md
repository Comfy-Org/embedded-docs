# トレーニングデータセットを作成

このノードは、画像とテキストをエンコードしてトレーニング用のデータを準備します。画像のリストと対応するテキストキャプションのリストを受け取り、VAEモデルを使用して画像を潜在表現に変換し、CLIPモデルを使用してテキストをconditioningデータに変換します。結果として得られるペアの潜在表現とconditioningはリストとして出力され、トレーニングワークフローで使用できる状態になります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | エンコードする画像のリストです。 | IMAGE | はい | N/A |
| `vae` | 画像を潜在表現にエンコードするためのVAEモデルです。 | VAE | はい | N/A |
| `clip` | テキストをconditioningにエンコードするためのCLIPモデルです。 | CLIP | はい | N/A |
| `texts` | テキストキャプションのリストです。長さはn（画像と一致）、1（すべてに繰り返し）、または省略可能（空文字列を使用）です。 | STRING | いいえ | N/A |

**パラメータ制約：**

* `texts` リストの項目数は、0、1、または `images` リストの項目数と正確に一致している必要があります。0の場合は、すべての画像に空文字列が使用されます。1の場合は、その単一のテキストがすべての画像に繰り返し使用されます。それ以外の数の場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `latents` | 潜在表現の辞書のリストです。 | LATENT |
| `conditioning` | conditioningリストのリストです。 | CONDITIONING |
