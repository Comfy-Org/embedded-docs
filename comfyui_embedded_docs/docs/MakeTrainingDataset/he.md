# יצירת מערך נתוני אימון

צומת זה מכין נתונים לאימון על ידי קידוד תמונות וטקסט. הוא מקבל רשימת תמונות ורשימה תואמת של כיתובי טקסט, ואז משתמש במודל VAE כדי להמיר את התמונות לייצוגים לטנטיים ובמודל CLIP כדי להמיר את הטקסט לנתוני התניה. התוצר — לטנטים והתניות בזוגות — מוצר כרשימות, מוכן לשימוש בזרימות עבודה לאימון.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `images` | רשימת תמונות לקידוד. | IMAGE | כן | N/A |
| `vae` | מודל VAE לקידוד תמונות ללטנטים. | VAE | כן | N/A |
| `clip` | מודל CLIP לקידוד טקסט להתניה. | CLIP | כן | N/A |
| `texts` | רשימת כיתובי טקסט. יכולה להיות באורך n (בהתאמה לתמונות), 1 (חוזרת עבור כולן), או להשמיט (משתמש במחרוזת ריקה). | STRING | לא | 0, 1, או n פריטים (n = מספר התמונות) |

**אילוצי פרמטרים:**

* צומת זה משתמש בקלטי רשימה: `images` ו-`texts` מעובדים כרשימות, בעוד `vae` ו-`clip` מקבלים מודל בודד כל אחד (נעשה שימוש בפריט הראשון ברשימה שסופקה).
* מספר הפריטים ברשימת `texts` חייב להיות 0, 1, או להתאים בדיוק למספר הפריטים ברשימת `images`. אם הוא 0 או שהפרמטר הושמט, משתמשים במחרוזת ריקה עבור כל התמונות. אם הוא 1, הטקסט הבודד הזה חוזר על עצמו עבור כל התמונות. כל אורך אחר מעורר שגיאה.
* רשימות הפלט `latents` ו-`conditioning` תמיד מכילות את אותו מספר פריטים כמו רשימת `images`, כך שכל לטנט מותאם להתניה של הכיתוב המתאים לו.

## פלטים
