# StableZero123_Conditioning_Batched

הצומת StableZero123_Conditioning_Batched מכין נתוני התניה ליצירת מודל תלת-ממדי מתמונת קלט בודדת. הוא מקודד את התמונה באמצעות מודל CLIP vision ו-VAE, משלב את התכונות החזותיות עם הטמעות מצלמה שנבנו מזוויות elevation ו-azimuth, ומייצר נתוני התניה חיוביים ושליליים וכן טנזור latent עבור batch של דגימות. כאשר `batch_size` גדול מ-1, זוויות ה-elevation וה-azimuth מוגדלות בערכי התוספת batch שלהן עבור כל פריט ב-batch.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | מודל CLIP vision המשמש לקידוד תמונת הקלט | CLIP_VISION | כן | - |
| `init_image` | תמונת הקלט הראשונית שיש לעבד ולקודד | IMAGE | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד פיקסלים של התמונה למרחב latent | VAE | כן | - |
| `width` | רוחב הפלט עבור התמונה המעובדת (ברירת מחדל: 256) | INT | כן | 16 עד MAX_RESOLUTION (צעד של 8) |
| `height` | גובה הפלט עבור התמונה המעובדת (ברירת מחדל: 256) | INT | כן | 16 עד MAX_RESOLUTION (צעד של 8) |
| `batch_size` | מספר דגימות ההתניה שיש לייצר ב-batch (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `elevation` | זווית elevation הראשונית של המצלמה במעלות (ברירת מחדל: 0.0) | FLOAT | כן | -180.0 עד 180.0 (צעד של 0.1) |
| `azimuth` | זווית azimuth הראשונית של המצלמה במעלות (ברירת מחדל: 0.0) | FLOAT | כן | -180.0 עד 180.0 (צעד של 0.1) |
| `elevation_batch_increment` | הכמות שבה יש להגדיל את elevation עבור כל פריט ב-batch (ברירת מחדל: 0.0). מסומן כקלט מתקדם. | FLOAT | כן | -180.0 עד 180.0 (צעד של 0.1) |
| `azimuth_batch_increment` | הכמות שבה יש להגדיל את azimuth עבור כל פריט ב-batch (ברירת מחדל: 0.0). מסומן כקלט מתקדם. | FLOAT | כן | -180.0 עד 180.0 (צעד של 0.1) |

**הערה:** הערכים של `width` ו-`height` חייבים להיות כפולות של 8, מכיוון שהצומת מחלק את הממדים הללו ב-8 באופן פנימי בעת בניית טנזור ה-latent.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | נתוני התניה חיוביים המכילים את הטמעות התמונה והטמעות המצלמה עבור כל פריט ב-batch | CONDITIONING |
| `negative` | נתוני התניה שליליים עם הטמעות מאותחלות לאפס | CONDITIONING |
| `latent` | טנזור latent מאותחל לאפס עם ממדים batch_size x 4 x height/8 x width/8, יחד עם מידע אינדוקס batch | LATENT |
