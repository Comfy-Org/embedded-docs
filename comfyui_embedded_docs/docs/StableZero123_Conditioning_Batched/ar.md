# تهيئة StableZero123 مجمعة

```markdown
تعمل عقدة `StableZero123_Conditioning_Batched` على تجهيز بيانات التكييف اللازمة لتوليد صور ثلاثية الأبعاد لكائن باستخدام نموذج Stable Zero123. تقوم بتشفير صورة الإدخال باستخدام نموذج رؤية CLIP وVAE، وتجمع ميزات الصورة مع زوايا الارتفاع والسمت للكاميرا لكل عنصر في الدفعة، وتُخرج تكييفًا موجبًا وسالبًا مع كامن فارغ. تعمل مدخلات زيادة الدفعة على رفع أو خفض زاوية الكاميرا لكل عنصر متتالٍ في الدفعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `clip_vision` | نموذج رؤية CLIP المستخدم لتشفير صورة الإدخال إلى تضمينات صورية | CLIP_VISION | نعم | - |
| `init_image` | صورة الإدخال الأولية التي سيتم معالجتها وتشفيرها | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير وحدات البكسل الخاصة بالصورة إلى الفضاء الكامن | VAE | نعم | - |
| `width` | العرض المستهدف للصورة المعالجة (الافتراضي: 256) | INT | نعم | 16 to MAX_RESOLUTION (step 8) |
| `height` | الارتفاع المستهدف للصورة المعالجة (الافتراضي: 256) | INT | نعم | 16 to MAX_RESOLUTION (step 8) |
| `batch_size` | عدد عينات التكييف المطلوب إنشاؤها في الدفعة (الافتراضي: 1) | INT | نعم | 1 to 4096 |
| `elevation` | زاوية ارتفاع الكاميرا الابتدائية بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 to 180.0 (step 0.1) |
| `azimuth` | زاوية سمت الكاميرا الابتدائية بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 to 180.0 (step 0.1) |
| `elevation_batch_increment` | المقدار المضاف إلى زاوية الارتفاع لكل عنصر متتالٍ في الدفعة (الافتراضي: 0.0، معامل متقدم) | FLOAT | نعم | -180.0 to 180.0 (step 0.1) |
| `azimuth_batch_increment` | المقدار المضاف إلى زاوية السمت لكل عنصر متتالٍ في الدفعة (الافتراضي: 0.0، معامل متقدم) | FLOAT | نعم | -180.0 to 180.0 (step 0.1) |

**ملاحظة:** يجب أن تكون قيمتا `width` و `height` مضاعفاتٍ للعدد 8 (تضمن خطوة الاختيار البالغة 8 ذلك) لأن العقدة تقسمهما على 8 لبناء أبعاد الكامن. بالنسبة لكل عنصر في الدفعة، تزداد قيمتا `elevation` و `azimuth` بمقدار `elevation_batch_increment` و `azimuth_batch_increment`، وبالتالي تحصل العناصر المتتالية في الدفعة على زوايا كاميرا متدرجة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف موجب يجمع بين تضمينات الصورة وتضمينات الكاميرا وصورة الإدخال المشفّرة، وتُستخدم جميعها في الربط أثناء التوليد | CONDITIONING |
| `negative` | تكييف سالب يستخدم تضمينات صورة مبدوءة بأصفار وكامنًا صفريًا لأغراض الربط | CONDITIONING |
| `latent` | موتر كامن فارغ بأبعاد (batch_size, 4, height/8, width/8) ومعلومات فهرس الدفعة | LATENT |
```
