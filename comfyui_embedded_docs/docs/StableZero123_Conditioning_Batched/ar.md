# تهيئة StableZero123 مجمعة

تُعدّ عقدة `StableZero123_Conditioning_Batched` بيانات التكييف (conditioning) لتوليد نموذج ثلاثي الأبعاد من صورة إدخال واحدة. تقوم بترميز الصورة باستخدام نموذج رؤية CLIP وVAE، وتدمج السمات البصرية مع تضمينات الكاميرا المبنية من زاويتي الارتفاع والسمت، وتنتج تكييفًا موجبًا وسالبًا بالإضافة إلى موتر كامن (latent tensor) لمجموعة من العينات. عندما تكون قيمة `batch_size` أكبر من 1، تزداد زاويتا الارتفاع والسمت بقيم الزيادة الخاصة بكل عنصر في الدفعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `رؤية المقطع` | نموذج رؤية CLIP المستخدم لترميز صورة الإدخال | CLIP_VISION | نعم | - |
| `الصورة الأصلية` | صورة الإدخال الأولية التي سيتم معالجتها وترميزها | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز بكسلات الصورة إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الصورة المعالجة (الافتراضي: 256) | INT | نعم | 16 to MAX_RESOLUTION (step of 8) |
| `الارتفاع` | ارتفاع الصورة المعالجة (الافتراضي: 256) | INT | نعم | 16 to MAX_RESOLUTION (step of 8) |
| `حجم الدفعة` | عدد عينات التكييف التي سيتم توليدها في الدفعة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `الارتفاع الزاوي` | زاوية الارتفاع الأولية للكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |
| `السمت` | زاوية السمت الأولية للكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |
| `زيادة دفعة الارتفاع الزاوي` | مقدار زيادة زاوية الارتفاع لكل عنصر في الدفعة (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |
| `زيادة دفعة السمت` | مقدار زيادة زاوية السمت لكل عنصر في الدفعة (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |

**ملاحظة:** يجب أن تكون قيمتا `width` و`height` مضاعفتين للرقم 8، حيث تقسم العقدة هذه الأبعاد على 8 داخليًا عند بناء الموتر الكامن.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `إيجابي` | بيانات التكييف الموجبة التي تحتوي على تضمينات الصورة وتضمينات الكاميرا لكل عنصر في الدفعة | CONDITIONING |
| `سلبي` | بيانات التكييف السالبة مع تضمينات مهيأة بالأصفار | CONDITIONING |
| `كامِن` | موتر كامن مهيأ بالأصفار بأبعاد `batch_size x 4 x height/8 x width/8`، مع معلومات فهرسة الدفعة | LATENT |
