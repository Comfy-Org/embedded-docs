# StableZero123 條件設定（批次）

StableZero123_Conditioning_Batched 節點準備用於從單一輸入圖像生成 3D 模型的條件資料。它使用 CLIP 視覺模型和 VAE 對圖像進行編碼，將視覺特徵與根據仰角和方位角建立的相機嵌入結合，並為一批樣本產生正向和負向條件資料以及潛在張量。當 `batch_size` 大於 1 時，仰角和方位角會根據批次增量值為批次中的每個項目增加。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | 用於對輸入圖像進行編碼的 CLIP 視覺模型 | CLIP_VISION | 是 | - |
| `初始影像` | 要處理和編碼的初始輸入圖像 | IMAGE | 是 | - |
| `vae` | 用於將圖像像素編碼到潛在空間的 VAE 模型 | VAE | 是 | - |
| `寬度` | 處理後圖像的輸出寬度（預設值：256） | INT | 是 | 16 to MAX_RESOLUTION (step of 8) |
| `高度` | 處理後圖像的輸出高度（預設值：256） | INT | 是 | 16 to MAX_RESOLUTION (step of 8) |
| `批次大小` | 批次中要生成的條件樣本數量（預設值：1） | INT | 是 | 1 至 4096 |
| `仰角` | 初始相機仰角（以度為單位）（預設值：0.0） | FLOAT | 是 | -180.0 至 180.0 |
| `方位角` | 初始相機方位角（以度為單位）（預設值：0.0） | FLOAT | 是 | -180.0 至 180.0 |
| `仰角批次遞增` | 每個批次項目的仰角增量（預設值：0.0） | FLOAT | 是 | -180.0 至 180.0 |
| `方位角批次遞增` | 每個批次項目的方位角增量（預設值：0.0） | FLOAT | 是 | -180.0 至 180.0 |

**注意：** `width` 和 `height` 值必須是 8 的倍數，因為節點在構建潛在張量時會在內部將這些維度除以 8。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `正向` | 包含每個批次項目的圖像嵌入和相機嵌入的正向條件資料 | CONDITIONING |
| `負向` | 具有零初始化嵌入的負向條件資料 | CONDITIONING |
| `潛在空間` | 具有維度 batch_size x 4 x height/8 x width/8 的零初始化潛在張量，以及批次索引資訊 | LATENT |
