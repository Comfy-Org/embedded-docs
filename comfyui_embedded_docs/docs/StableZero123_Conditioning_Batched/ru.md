# StableZero123_Кондиционирование_Пакетное

Узел StableZero123_Conditioning_Batched подготавливает данные кондиционирования для генерации 3D-модели из одного входного изображения. Он кодирует изображение с помощью модели CLIP vision и VAE, объединяет визуальные признаки с эмбеддингами камеры, построенными на основе углов возвышения и азимута, и формирует позитивное и негативное кондиционирование, а также латентный тензор для пакета образцов. Когда `batch_size` больше 1, углы возвышения и азимута увеличиваются на соответствующие значения приращения для каждого элемента пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `clip_vision` | Модель CLIP vision, используемая для кодирования входного изображения | CLIP_VISION | Да | - |
| `начальное_изображение` | Исходное входное изображение для обработки и кодирования | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования пикселей изображения в скрытое пространство | VAE | Да | - |
| `ширина` | Ширина выходного изображения (по умолчанию: 256) | INT | Да | 16 to MAX_RESOLUTION (step of 8) |
| `высота` | Высота выходного изображения (по умолчанию: 256) | INT | Да | 16 to MAX_RESOLUTION (step of 8) |
| `размер_пакета` | Количество образцов кондиционирования для генерации в пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `высота` | Начальный угол возвышения камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |
| `азимут` | Начальный азимутальный угол камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |
| `инкремент_высоты_пакета` | Величина приращения угла возвышения для каждого элемента пакета (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |
| `инкремент_азимута_пакета` | Величина приращения азимута для каждого элемента пакета (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |

**Примечание:** Значения `width` и `height` должны быть кратны 8, так как узел внутренне делит эти размеры на 8 при формировании латентного тензора.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `положительный` | Данные позитивного кондиционирования, содержащие эмбеддинги изображения и эмбеддинги камеры для каждого элемента пакета | CONDITIONING |
| `отрицательный` | Данные негативного кондиционирования с эмбеддингами, инициализированными нулями | CONDITIONING |
| `латентный` | Латентный тензор с нулевой инициализацией размером batch_size x 4 x height/8 x width/8, а также информация об индексации пакета | LATENT |
