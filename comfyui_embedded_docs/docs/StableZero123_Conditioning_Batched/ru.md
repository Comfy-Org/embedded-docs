# StableZero123_Кондиционирование_Пакетное

Узел **StableZero123_Conditioning_Batched** подготавливает данные conditioning, необходимые для генерации 3D-видов объекта с помощью модели Stable Zero123. Он кодирует входное изображение с помощью модели CLIP vision и VAE, объединяет признаки изображения с углами возвышения и азимута камеры для каждого элемента в пакете, а также возвращает положительное и отрицательное conditioning вместе с пустым latent. Приращения для пакета повышают или понижают угол камеры для каждого следующего элемента в пакете.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования входного изображения в эмбеддинги изображения | CLIP_VISION | Да | — |
| `init_image` | Исходное входное изображение для обработки и кодирования | IMAGE | Да | — |
| `vae` | Модель VAE, используемая для кодирования пикселей изображения в скрытое пространство (latent space) | VAE | Да | — |
| `width` | Целевая ширина обработанного изображения (по умолчанию: 256) | INT | Да | от 16 до MAX_RESOLUTION (шаг 8) |
| `height` | Целевая высота обработанного изображения (по умолчанию: 256) | INT | Да | от 16 до MAX_RESOLUTION (шаг 8) |
| `batch_size` | Количество образцов conditioning для генерации в пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `elevation` | Начальный угол возвышения камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | от -180.0 до 180.0 (шаг 0.1) |
| `azimuth` | Начальный угол азимута камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | от -180.0 до 180.0 (шаг 0.1) |
| `elevation_batch_increment` | Величина, добавляемая к углу возвышения для каждого следующего элемента в пакете (по умолчанию: 0.0, дополнительный параметр) | FLOAT | Да | от -180.0 до 180.0 (шаг 0.1) |
| `azimuth_batch_increment` | Величина, добавляемая к углу азимута для каждого следующего элемента в пакете (по умолчанию: 0.0, дополнительный параметр) | FLOAT | Да | от -180.0 до 180.0 (шаг 0.1) |

**Примечание:** Значения `width` и `height` должны быть кратны 8 (шаг выбора 8 обеспечивает это), поскольку узел делит их на 8 для построения размерностей latent. Для каждого элемента в пакете значения `elevation` и `azimuth` увеличиваются на `elevation_batch_increment` и `azimuth_batch_increment`, поэтому последовательные элементы пакета получают пошаговые углы камеры.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное conditioning, объединяющее эмбеддинги изображения, эмбеддинги камеры и закодированное входное изображение, используемое для конкатенации во время генерации | CONDITIONING |
| `negative` | Отрицательное conditioning с использованием нулевых эмбеддингов изображения и нулевого latent для конкатенации | CONDITIONING |
| `latent` | Пустой latent-тензор с размерами (batch_size, 4, height/8, width/8) и информацией об индексе пакета | LATENT |
