# Flux.1 Kontext [pro] Image

יוצר או עורך תמונה באמצעות Flux.1 Kontext [pro] דרך ה-API של BFL, בהתבסס על פרומפט ויחס-גובה-רוחב. כאשר `input_image` מחובר, הפרומפט מתאר את העריכה; ללא חיבור, הצומת יוצר תמונה חדשה מהפרומפט בלבד.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת התמונה. עם תמונת קלט, יש לציין מה ואיך לערוך. | STRING | כן | - |
| `aspect_ratio` | יחס-גובה-רוחב של התמונה; חייב להיות בין 1:4 ל-4:1 (ברירת מחדל: `"16:9"`). | STRING | כן | - |
| `guidance` | עוצמת ההנחיה עבור תהליך יצירת התמונה (ברירת מחדל: 3.0). | FLOAT | כן | 0.1 עד 99.0 (בצעדים של 0.1) |
| `steps` | מספר הצעדים עבור תהליך יצירת התמונה (ברירת מחדל: 50). | INT | כן | 1 עד 150 |
| `seed` | הזרע האקראי המשמש ליצירת הרעש (ברירת מחדל: 1234). | INT | כן | 0 עד 18446744073709551615 |
| `prompt_upsampling` | האם לבצע upsampling על הפרומפט. אם פעיל, הפרומפט משתנה אוטומטית ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות, כך שאותו seed לא יפיק בדיוק את אותה התוצאה (ברירת מחדל: `False`). זוהי הגדרה מתקדמת. | BOOLEAN | כן | True / False |
| `input_image` | תמונה אופציונלית לעריכה. כאשר מושמטת, הפרומפט נבדק כדי לוודא שאינו ריק. | IMAGE | לא | - |

**הערה:** הצומת שולח את הבקשה ל-BFL ומבצע סקירה חוזרת עד שהתמונה מוכנה. בקשות שנדחות על ידי מנגנון בקרת התוכן של BFL נכשלות במקום להחזיר תמונה.
