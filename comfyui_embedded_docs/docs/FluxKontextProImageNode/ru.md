# Flux.1 Kontext [pro] Изображение

Генерирует или редактирует изображение с помощью Flux.1 Kontext [pro] через BFL API на основе промпта и соотношения сторон. Если подключён `input_image`, промпт описывает редактирование; без него узел генерирует новое изображение только по промпту.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Промпт для генерации изображения. При наличии входного изображения укажите, что и как редактировать. | STRING | Да | - |
| `соотношение_сторон` | Соотношение сторон изображения; должно быть в диапазоне от 1:4 до 4:1 (по умолчанию: `"16:9"`). | STRING | Да | - |
| `guidance` | Сила управляющего воздействия для процесса генерации изображения (по умолчанию: 3.0). | FLOAT | Да | от 0.1 до 99.0 (шаг 0.1) |
| `steps` | Количество шагов для процесса генерации изображения (по умолчанию: 50). | INT | Да | от 1 до 150 |
| `seed` | Случайное зерно, используемое для создания шума (по умолчанию: 1234). | INT | Да | от 0 до 18446744073709551615 |
| `prompt_upsampling` | Выполнять ли апсемплинг промпта. Если включено, промпт автоматически изменяется для более креативной генерации, но результаты недетерминированы, поэтому один и тот же seed не даст в точности одинаковый результат (по умолчанию: `False`). Это расширенная настройка. | BOOLEAN | Да | True / False |
| `input_image` | Необязательное изображение для редактирования. Если не указано, промпт проверяется на непустоту. | IMAGE | Нет | - |

**Примечание:** Узел отправляет запрос в BFL и выполняет опрос до готовности изображения. Запросы, отклонённые модерацией контента BFL, завершаются ошибкой вместо возврата изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение. | IMAGE |
