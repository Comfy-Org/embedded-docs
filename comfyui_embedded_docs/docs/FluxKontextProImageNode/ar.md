# Flux.1 Kontext [pro] صورة

ينشئ صورة أو يعدّلها باستخدام Flux.1 Kontext [pro] عبر BFL API، استنادًا إلى موجه ونسبة أبعاد. عند توصيل `input_image`، يصف الموجه التعديل؛ ومن دونه، تولّد العقدة صورة جديدة من الموجه وحده.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص الموجه` | الموجه المستخدم لتوليد الصورة. عند وجود صورة إدخال، حدد ما الذي تريد تعديله وكيف. | STRING | نعم | - |
| `نسبة الأبعاد` | نسبة أبعاد الصورة؛ يجب أن تكون بين 1:4 و4:1 (الافتراضي: `"16:9"`). | STRING | نعم | - |
| `التوجيه` | قوة التوجيه لعملية توليد الصورة (الافتراضي: 3.0). | FLOAT | نعم | 0.1 إلى 99.0 (خطوة: 0.1) |
| `الخطوات` | عدد الخطوات لعملية توليد الصورة (الافتراضي: 50). | INT | نعم | 1 إلى 150 |
| `البذرة` | البذرة العشوائية المستخدمة لإنشاء التشويش (الافتراضي: 1234). | INT | نعم | 0 إلى 18446744073709551615 |
| `رفع دقة النص الموجه` | هل يتم إجراء رفع العينة (upsampling) على الموجه. عند تفعيله، يُعدّل الموجه تلقائيًا لتوليد أكثر إبداعًا، لكن النتائج غير حتمية، لذا لن تُنتج البذرة نفسها النتيجة نفسها تمامًا (الافتراضي: `False`). هذا إعداد متقدم. | BOOLEAN | نعم | True / False |
| `صورة الإدخال` | صورة اختيارية للتعديل. عند حذفها، يتم التحقق من الموجه للتأكد من أنه ليس فارغًا. | IMAGE | لا | - |

**ملاحظة:** ترسل العقدة الطلب إلى BFL وتستعلم بشكل متكرر حتى تصبح الصورة جاهزة. تفشل الطلبات التي ترفضها مراجعة المحتوى لدى BFL بدلًا من إرجاع صورة.
