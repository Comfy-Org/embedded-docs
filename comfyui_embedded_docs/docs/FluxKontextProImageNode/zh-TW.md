# Flux.1 Kontext [專業版] 影像

透過 BFL API 使用 Flux.1 Kontext [pro] 根據提示詞與長寬比產生或編輯影像。連接 `input_image` 時，提示詞會描述要進行的編輯；未連接時，節點僅根據提示詞生成全新影像。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於影像生成的提示詞。有輸入影像時，請指定要編輯的內容與方式。 | STRING | 是 | - |
| `長寬比` | 影像的長寬比；必須介於 1:4 與 4:1 之間（預設值：`"16:9"`）。 | STRING | 是 | - |
| `引導強度` | 影像生成過程的引導強度（預設值：3.0）。 | FLOAT | 是 | 0.1 至 99.0 （步進值：0.1） |
| `步數` | 影像生成過程的步數（預設值：50）。 | INT | 是 | 1 至 150 |
| `種子值` | 用於建立雜訊的隨機種子（預設值：1234）。 | INT | 是 | 0 至 18446744073709551615 |
| `提示詞上採樣` | 是否對提示詞執行上採樣。啟用時，提示詞會自動修改以獲得更具創意的生成結果，但結果不具確定性，因此相同的種子不會產生完全相同的結果（預設值：`False`）。這是進階設定。 | BOOLEAN | 是 | True / False |
| `輸入影像` | 要編輯的選用影像。省略時，會驗證提示詞以確保其不為空。 | IMAGE | 否 | - |

**注意：** 此節點會將請求傳送至 BFL，並輪詢直到影像準備就緒。遭 BFL 內容審核拒絕的請求會失敗，而不會傳回影像。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `IMAGE` | 產生或編輯後的影像。 | IMAGE |
