# Flux.1 Kontext [pro] Image

با استفاده از Flux.1 Kontext [pro] از طریق BFL API، بر اساس یک پرامپت و یک نسبت ابعاد، تصویری تولید یا ویرایش می‌کند. وقتی `input_image` متصل باشد، پرامپت ویرایش را توصیف می‌کند؛ در غیر این صورت، گره تنها از روی پرامپت تصویری تازه تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | پرامپت برای تولید تصویر. در صورت وجود تصویر ورودی، مشخص کنید چه چیزی و چگونه ویرایش شود. | STRING | بله | - |
| `نسبت تصویر` | نسبت ابعاد تصویر؛ باید بین 1:4 و 4:1 باشد (پیش‌فرض: `"16:9"`). | STRING | بله | - |
| `راهنمایی` | قدرت راهنمایی برای فرایند تولید تصویر (پیش‌فرض: 3.0). | FLOAT | بله | 0.1 تا 99.0 (گام: 0.1) |
| `گام‌ها` | تعداد گام‌های فرایند تولید تصویر (پیش‌فرض: 50). | INT | بله | 1 تا 150 |
| `بذر` | seed تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 1234). | INT | بله | 0 تا 18446744073709551615 |
| `افزایش وضوح پرامپت` | آیا نمونه‌برداری افزایشی روی پرامپت انجام شود. در صورت فعال بودن، پرامپت به‌طور خودکار برای تولید خلاقانه‌تر تغییر می‌کند، اما نتایج غیرقطعی هستند؛ بنابراین همان seed دقیقاً نتیجه یکسانی تولید نخواهد کرد (پیش‌فرض: `False`). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True / False |
| `تصویر ورودی` | تصویر اختیاری برای ویرایش. اگر حذف شود، پرامپت اعتبارسنجی می‌شود تا از خالی نبودن آن اطمینان حاصل شود. | IMAGE | خیر | - |

**نکته:** گره درخواست را به BFL می‌فرستد و تا آماده شدن تصویر به‌صورت دوره‌ای بررسی می‌کند. درخواست‌هایی که توسط پالایش محتوای BFL رد شوند، به‌جای بازگرداندن تصویر، شکست می‌خورند.
