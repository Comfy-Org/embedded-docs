# Получить 3D-компоненты

Get3DComponents преобразует файл 3D-модели (GLB, GLTF, OBJ или STL) в редактируемую сетку, которую можно использовать в узлах обработки сеток, таких как децимация, ремешинг, развёртка UV и запекание. Все узлы и примитивы сцены объединяются в одну сетку с применением их трансформаций, а текстуры и настройки материала берутся из первого материала. Это узел, обратный узлу MeshToFile3D.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл 3D-модели из узла Load 3D или другого 3D-узла. FBX/USDZ не поддерживаются — сначала преобразуйте в GLB. | File3DGLB<br>File3DGLTF<br>File3DOBJ<br>File3DSTL<br>File3DAny | Да | GLB<br>GLTF<br>OBJ<br>STL |

Примечание: файлы FBX и USDZ не поддерживаются и вызывают ошибку; сначала преобразуйте их в GLB или GLTF. Если 3D-файл содержит несколько материалов, сохраняются только текстуры и факторы материала первого материала (выводится предупреждение). Все примитивы сцены объединяются в одну сетку с применением их трансформаций. Этот узел является экспериментальным.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Редактируемая сетка, содержащая вершины, грани, UV-координаты, цвета вершин, нормали, касательные и информацию о материале (текстура, металличность-шероховатость, карта нормалей, эмиссия, флаг unlit), извлечённые из файла модели. | MESH |
