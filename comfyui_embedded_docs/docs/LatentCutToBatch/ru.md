# LatentCutToBatch

Узел LatentCutToBatch разделяет скрытое представление по выбранному измерению на несколько срезов и объединяет их в новый батч. Это позволяет обрабатывать различные части скрытого представления независимо.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Латентное представление, которое будет разделено и собрано в батч. | LATENT | Да | - |
| `dim` | Измерение, по которому разрезаются скрытые представления. `"t"` относится к временному измерению, `"x"` — к ширине, а `"y"` — к высоте. | COMBO | Да | `"t"`<br>`"x"`<br>`"y"` |
| `slice_size` | Размер каждого среза, вырезаемого по указанному измерению. Если размер измерения не делится на это значение без остатка, остаток отбрасывается. (по умолчанию: 1) | INT | Да | от 1 до 16384 (максимальное разрешение) |

Примечание. Если выбранное измерение является осью батча или каналов, входные данные возвращаются без изменений. Если `slice_size` больше размера измерения, всё измерение используется как один срез.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Результирующий латентный батч, содержащий нарезанные и сложенные в стек срезы. | LATENT |
