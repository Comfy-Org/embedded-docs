# LatentCutToBatch

Узел LatentCutToBatch разделяет латентное представление по выбранному измерению (времени, ширине или высоте) на срезы заданного размера и объединяет эти срезы в новый батч. Каждый срез становится отдельным элементом батча, поэтому разные части латентного образца можно обрабатывать независимо.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Латентное представление, которое нужно разделить и преобразовать в батч. | LATENT | Да | - |
| `dim` | Измерение, вдоль которого нужно разрезать латентные образцы. `"t"` относится к временному (кадровому) измерению, `"x"` — к ширине, `"y"` — к высоте. | COMBO | Да | `"t"`<br>`"x"`<br>`"y"` |
| `slice_size` | Размер каждого среза, вырезаемого из указанного измерения. Если размер измерения не делится на это значение без остатка, остаток отбрасывается. (по умолчанию: 1) | INT | Да | 1 до 16384 (max resolution) |

Примечание: Опция `"t"` действует только тогда, когда латент содержит временное измерение. Если выбранное измерение соответствует позиции батча или канала либо не существует (например, при выборе `"t"` для латента без кадров), узел возвращает входные данные без изменений. Если `slice_size` больше размера выбранного измерения, всё измерение используется как один срез. Если размер измерения не делится на `slice_size` без остатка, оставшаяся часть в конце отбрасывается. Размер выходного батча равен размеру входного батча, умноженному на количество срезов, а само разрезаемое измерение уменьшается до `slice_size`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Результирующий латентный батч, содержащий разрезанные и объединённые в батч образцы. | LATENT |
