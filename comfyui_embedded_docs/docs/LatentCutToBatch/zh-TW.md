# LatentCutToBatch

LatentCutToBatch 節點會沿著選定的維度（時間、寬度或高度）將潛在表示切成指定大小的切片，並將這些切片堆疊成新的批次。每個切片都會成為批次中的獨立項目，因此潛在樣本的不同部分可以獨立處理。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `樣本` | 要切分並批次處理的潛在表示。 | LATENT | 是 | - |
| `維度` | 沿著哪個維度切分潛在樣本。`"t"` 表示時間（影格）維度，`"x"` 表示寬度，`"y"` 表示高度。 | COMBO | 是 | `"t"`<br>`"x"`<br>`"y"` |
| `切片大小` | 要從指定維度切下的每個切片大小。如果該維度大小無法被此值整除，餘數會被丟棄。（預設值：1） | INT | 是 | 1 至 16384 (max resolution) |

注意：`"t"` 選項僅在潛在表示包含時間維度時才會生效。如果所選維度對應到批次或通道位置，或不存在（例如在沒有影格的潛在表示上選取 `"t"`），節點會回傳未變更的輸入。如果 `slice_size` 大於所選維度的大小，則會將整個維度作為單一切片。當維度大小無法被 `slice_size` 整除時，末尾剩餘的部分會被丟棄。輸出批次大小會是輸入批次大小乘以切片數量，而切片後的維度本身會縮減為 `slice_size`。
