# LatentCutToBatch

LatentCutToBatch 節點會沿著指定的維度（時間、寬度或高度）將潛在表示分割成指定大小的切片，並將它們堆疊成新的批次。每個切片都會成為批次中的獨立項目，因此潛在樣本的不同部分可以獨立處理。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `樣本` | 要分割並進行批次處理的潛在表示。 | LATENT | 是 | - |
| `維度` | 要沿其切割潛在樣本的維度。`"t"` 指的是時間（幀）維度，`"x"` 指的是寬度，`"y"` 指的是高度。 | COMBO | 是 | `"t"`<br>`"x"`<br>`"y"` |
| `切片大小` | 從指定維度切割的每個切片的大小。如果該維度的大小無法被此值整除，則丟棄餘數。（預設值：1） | INT | 是 | 1 至 16384（最大解析度） |

注意：只有在潛在表示包含時間維度時，`"t"` 選項才會生效。如果所選維度對應到批次或通道位置，或該維度不存在（例如在沒有幀的潛在表示上選擇 `"t"`），則節點會原封不動地回傳輸入。如果 `slice_size` 大於所選維度的大小，則整個維度會被視為單一切片。當維度大小無法被 `slice_size` 整除時，尾端多餘的部分會被丟棄。輸出批次大小為輸入批次大小乘以切片數量，而切片後的維度本身則縮減為 `slice_size`。
