# LatentCutToBatch

LatentCutToBatch 노드는 선택한 차원을 따라 잠재 표현을 여러 조각으로 분할하고 이를 새 배치로 스택합니다. 이를 통해 잠재 샘플의 서로 다른 부분을 독립적으로 처리할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `samples` | 분할 및 배치로 결합할 잠재 표현입니다. | LATENT | 예 | - |
| `dim` | 잠재 샘플을 분할할 차원입니다. `"t"`는 시간 차원, `"x"`는 너비, `"y"`는 높이를 나타냅니다. | COMBO | 예 | `"t"`<br>`"x"`<br>`"y"` |
| `slice_size` | 지정된 차원에서 분할할 각 조각의 크기입니다. 차원의 크기가 이 값으로 정확히 나누어떨어지지 않으면 나머지는 버려집니다. (기본값: 1) | INT | 예 | 1~16384 (최대 해상도) |

참고: 선택한 차원이 배치 또는 채널 축인 경우 입력이 변경 없이 반환됩니다. `slice_size`가 차원의 크기보다 크면 전체 차원이 단일 조각으로 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 슬라이스 및 스택된 샘플을 포함하는 결과 잠재 배치입니다. | LATENT |
