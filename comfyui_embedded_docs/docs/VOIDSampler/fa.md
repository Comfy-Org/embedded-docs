# VOIDSampler

## نمای کلی

گره VOIDSampler یک روش نمونه‌برداری DDIM تخصصی ارائه می‌دهد که به‌طور خاص برای مدل‌های ترمیم تصویر (inpainting) VOID طراحی شده است. این گره همان فرآیند نویززدایی مورد استفاده در آموزش مدل VOID را پیاده‌سازی می‌کند، بدون مقیاس‌گذاری نویز که KSamplerهای استاندارد اعمال می‌کنند. این گره برای استفاده با گره‌های `SamplerCustom` یا `SamplerCustomAdvanced` در نظر گرفته شده است و باید با `RandomNoise` یا `VOIDWarpedNoiseSource` جفت شود.

## ورودی‌ها

این گره هیچ پارامتر ورودی قابل تنظیمی ندارد. این یک نمونه‌بردار مستقل است که یک الگوریتم نمونه‌برداری DDIM ثابت را اعمال می‌کند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| *بدون ورودی* | این گره هیچ پارامتر ورودی نمی‌پذیرد. | - | - | - |

نکته: مدل‌های VOID با diffusers `CogVideoXDDIMScheduler` آموزش دیده‌اند که در فضای آلفا کار می‌کند و در آن انحراف معیار ورودی تقریباً ۱ است. KSampler استاندارد مقیاس‌گذاری نویز را اعمال می‌کند که حدود ۴۵۰۰ برابر ضرب می‌کند، که با این آموزش ناسازگار است. VOIDSampler از آن مقیاس‌گذاری صرف‌نظر می‌کند و قانون به‌روزرسانی DDIM را مستقیماً با استفاده از تبدیل سیگما به آلفا پیاده‌سازی می‌کند.
