# VOIDSampler

VOIDSampler یک نمونه‌بردار تخصصی DDIM برای مدل‌های ترمیم تصویر (inpainting) VOID است. این گره همان فرآیند نویززدایی را پیاده‌سازی می‌کند که VOID با آن آموزش دیده است، بدون مقیاس‌گذاری نویزی که KSamplerهای استاندارد اعمال می‌کنند. این گره را با SamplerCustom یا SamplerCustomAdvanced و همراه با RandomNoise یا VOIDWarpedNoiseSource استفاده کنید.

## ورودی‌ها

این گره هیچ پارامتر ورودی قابل پیکربندی‌ای ندارد. این یک نمونه‌بردار مستقل است که یک الگوریتم نمونه‌برداری DDIM ثابت را اعمال می‌کند.
