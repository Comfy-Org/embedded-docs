# VOIDSampler

## Обзор

Узел VOIDSampler предоставляет специализированный метод сэмплирования DDIM, разработанный специально для моделей inpainting VOID. Он реализует тот же процесс шумоподавления, который использовался при обучении моделей VOID, без масштабирования шума, применяемого в стандартных KSampler. Этот узел предназначен для использования с узлами SamplerCustom или SamplerCustomAdvanced, а также должен применяться в паре с RandomNoise или VOIDWarpedNoiseSource.

## Входы

Данный узел не имеет настраиваемых входных параметров. Это автономный сэмплер, который использует фиксированный алгоритм сэмплирования DDIM.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| *Нет входных данных* | Этот узел не принимает входные параметры. | - | - | - |

Примечание: модели VOID обучались с использованием diffusers CogVideoXDDIMScheduler, который работает в альфа-пространстве, где стандартное отклонение входных данных составляет приблизительно 1. Стандартный KSampler применяет масштабирование шума с коэффициентом примерно 4500x, что несовместимо с данным обучением. VOIDSampler пропускает это масштабирование и реализует правило обновления DDIM напрямую, используя преобразование «сигма-альфа».

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SAMPLER` | Объект сэмплера, реализующий алгоритм VOID DDIM, готовый к подключению к узлам SamplerCustom или SamplerCustomAdvanced. | SAMPLER |
