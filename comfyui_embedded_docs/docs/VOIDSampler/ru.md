# VOIDSampler

VOIDSampler — это специализированный сэмплер DDIM для моделей инпейнтинга VOID. Он реализует тот же процесс денойзинга, на котором был обучен VOID, без масштабирования шума, которое применяют стандартные сэмплеры KSampler. Используйте этот узел с SamplerCustom или SamplerCustomAdvanced в паре с RandomNoise или VOIDWarpedNoiseSource.

## Входы

У этого узла нет настраиваемых входных параметров. Это автономный сэмплер, применяющий фиксированный алгоритм сэмплирования DDIM.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| *Нет входов* | Этот узел не принимает никаких входных параметров. | - | - | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SAMPLER` | Объект сэмплера, реализующий алгоритм VOID DDIM, готовый для подключения к узлам SamplerCustom или SamplerCustomAdvanced. | SAMPLER |
