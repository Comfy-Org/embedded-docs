# SaveAnimatedWebp

צומת זה מיועד לשמירת רצף תמונות כקובץ WEBP מונפש. הוא מטפל באיחוד פריימים בודדים לאנימציה מלוכדת, מחיל מטא-נתונים שצוינו, ומבצע אופטימיזציה של הפלט בהתאם להגדרות איכות ודחיסה.

## קלטים

| שדה | תיאור | סוג נתונים |
| --- | --- | --- |
| `images` | רשימת תמונות לשמירה כפריימים ב-WEBP המונפש. פרמטר זה חיוני להגדרת התוכן החזותי של האנימציה. | `IMAGE` |
| `filename_prefix` | מציין את שם הבסיס של קובץ הפלט, שאליו יתווספו מונה וסיומת '.webp'. פרמטר זה חיוני לזיהוי ולארגון הקבצים הנשמרים. | `STRING` |
| `fps` | קצב הפריימים לשנייה של האנימציה, המשפיע על מהירות ההפעלה. | `FLOAT` |
| `lossless` | ערך בוליאני המציין האם להשתמש בדחיסה ללא אובדן, המשפיע על גודל הקובץ ואיכות האנימציה. | `BOOLEAN` |
| `quality` | ערך בין 0 ל-100 הקובע את רמת איכות הדחיסה, כאשר ערכים גבוהים יותר מניבים איכות תמונה טובה יותר אך קבצים גדולים יותר. | `INT` |
| `method` | מציין את שיטת הדחיסה לשימוש, שעשויה להשפיע על מהירות הקידוד וגודל הקובץ. | COMBO[STRING] |

## פלטים

| שדה | תיאור | סוג נתונים |
| --- | --- | --- |
| `ui` | מספק רכיב ממשק משתמש המציג את תמונות ה-WEBP המונפשות שנשמרו יחד עם המטא-נתונים שלהן, ומציין האם האנימציה מופעלת. | N/A |
