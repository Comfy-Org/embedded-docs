# Recraft Controlli

Crea i controlli Recraft per personalizzare la generazione Recraft. Questo nodo consente di configurare le impostazioni colore che verranno utilizzate durante il processo di generazione delle immagini Recraft.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
|-----------|-------------|-----------|----------|-------|
| `colors` | Impostazioni colore per gli elementi principali | COLOR | No | - |
| `background_color` | Impostazione del colore di sfondo | COLOR | No | - |

## Output

| Nome output | Descrizione | Tipo di dato |
|-------------|-------------|-----------|
| `recraft_controls` | I controlli Recraft configurati contenenti le impostazioni colore | CONTROLS |
