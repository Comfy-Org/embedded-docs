# RecraftControls

Erstellt Recraft Controls zum Anpassen der Recraft-Generierung. Dieser Node ermöglicht es Ihnen, Farbeinstellungen zu konfigurieren, die während des Recraft-Bildgenerierungsprozesses verwendet werden.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
|-----------|-------------|-----------|----------|-------|
| `colors` | Farbeinstellungen für die Hauptelemente | COLOR | Nein | - |
| `background_color` | Einstellung der Hintergrundfarbe | COLOR | Nein | - |

## Ausgaben

| Ausgabenname | Beschreibung | Datentyp |
|-------------|-------------|-----------|
| `recraft_controls` | Die konfigurierten Recraft Controls mit den Farbeinstellungen | CONTROLS |
