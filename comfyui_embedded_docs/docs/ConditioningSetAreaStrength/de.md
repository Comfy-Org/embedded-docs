# ConditioningSetAreaStrength

Dieser Node dient dazu, das Stärke-Attribut eines gegebenen Conditioning-Sets zu ändern, wodurch der Einfluss bzw. die Intensität der Konditionierung auf den Generierungsprozess angepasst werden kann.

## Eingaben

| Parameter | Beschreibung | Datentyp |
| --- | --- | --- |
| `CONDITIONING` | Das zu ändernde Conditioning-Set, das den aktuellen Zustand der Konditionierung repräsentiert, die den Generierungsprozess beeinflusst. | CONDITIONING |
| `strength` | Der auf das Conditioning-Set anzuwendende Stärkewert, der die Intensität seines Einflusses bestimmt. | `FLOAT` |

## Ausgaben

| Parameter | Beschreibung | Datentyp |
| --- | --- | --- |
| `CONDITIONING` | Das geänderte Conditioning-Set mit aktualisierten Stärkewerten für jedes Element. | CONDITIONING |
