# Conditioning (Imposta Intensità Area)

Questo nodo è progettato per modificare l'attributo strength di un determinato set di conditioning, consentendo la regolazione dell'influenza o dell'intensità del conditioning sul processo di generazione.

## Input

| Parametro | Descrizione | Tipo di dato |
| --- | --- | --- |
| `CONDITIONING` | Il set di conditioning da modificare, che rappresenta lo stato attuale del conditioning che influenza il processo di generazione. | CONDITIONING |
| `strength` | Il valore di strength da applicare al set di conditioning, che determina l'intensità della sua influenza. | `FLOAT` |

## Output

| Parametro | Descrizione | Tipo di dato |
| --- | --- | --- |
| `CONDITIONING` | Il set di conditioning modificato con i valori di strength aggiornati per ciascun elemento. | CONDITIONING |
