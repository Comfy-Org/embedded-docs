# SenseNova Interleave Decode

Преобразуйте историю interleave, оставленную SenseNova Conditioning, в пригодный для использования текст, изображения и рассуждения. Запустите этот узел в конце цикла при отключённой опции End Loop accumulate, чтобы собрать всё, что модель создала за один проход.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель SenseNova CLIP, используемая для декодирования сгенерированных токенов. | CLIP | Да | - |
| `conditioning` | Interleave-кондиционирование от SenseNova Conditioning. | CONDITIONING | Да | - |
| `samples` | Последний пиксельный латент KSampler; нужен, когда цикл завершился на запросе изображения. | LATENT | Нет | - |

**Ограничения и поведение:**

* Вход `conditioning` должен поступать из SenseNova Conditioning в задаче `interleave` или `self-correction`; в противном случае возникает ошибка.
* Когда модель ожидает изображение, подключите выход LATENT сэмплера к `samples`.
* Эталонные изображения, подключённые в начале запуска, исключаются из выходных данных; если изображение не было сгенерировано, потребители изображений пропускаются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `text` | Текст, декодированный из истории interleave, где маркеры изображений заменены пустыми строками. | STRING |
| `images` | Изображения, которые модель сгенерировала во время запуска. | IMAGE |
| `thinking` | Текст рассуждений модели, если она его сформировала. | STRING |
