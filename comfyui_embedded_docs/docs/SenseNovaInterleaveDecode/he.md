# SenseNova Interleave Decode

הפוך את היסטוריית האינטרליב שהותיר SenseNova Conditioning לטקסט, תמונות וחשיבה שמישים. הרץ אותו בסוף הלולאה, כאשר האפשרות End Loop accumulate מושבתת, כדי לאסוף את כל מה שהמודל הפיק במעבר אחד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל SenseNova CLIP המשמש לפענוח הטוקנים שנוצרו. | CLIP | כן | - |
| `conditioning` | קונדישנינג אינטרליב מ-SenseNova Conditioning. | CONDITIONING | כן | - |
| `samples` | הפלט הלטנטי האחרון של KSampler ברמת פיקסלים, הנדרש כאשר הלולאה הסתיימה בבקשת תמונה. | LATENT | לא | - |

**אילוצים והתנהגות:**

* הקונדישנינג חייב להגיע מ-SenseNova Conditioning במשימת `interleave` או `self-correction`; כל ערך אחר יגרום לשגיאה.
* כאשר המודל ממתין לתמונה, חבר את פלט ה-LATENT של הסמפלר אל `samples`.
* תמונות עזר המחוברות בתחילת ההרצה אינן נכללות בפלט, וצרכני תמונות מדולגים כאשר לא נוצרה תמונה.
