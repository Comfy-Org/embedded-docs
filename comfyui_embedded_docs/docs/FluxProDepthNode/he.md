# FluxProDepthNode

צומת זה יוצר תמונות תוך שימוש בתמונת בקרת עומק כהנחיה. הוא מקבל תמונת בקרה והנחיית טקסט, ולאחר מכן יוצר תמונה חדשה שעוקבת גם אחרי פרטי העומק מתמונת הבקרה וגם אחרי התיאור בהנחיה. הצומת מתחבר ל-API חיצוני כדי לבצע את תהליך יצירת התמונה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `control_image` | תמונת בקרת העומק המשמשת להנחיית יצירת התמונה | IMAGE | כן | - |
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `prompt_upsampling` | האם לבצע upsampling על ההנחיה. אם פעיל, משנה אוטומטית את ההנחיה ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה תוצאה). (ברירת מחדל: False) | BOOLEAN | לא | - |
| `skip_preprocessing` | האם לדלג על עיבוד מקדים; יש להגדיר כ-True אם `control_image` כבר עובדה לתמונת עומק, ו-False אם היא תמונה גולמית. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `guidance` | עוצמת ההנחיה עבור תהליך יצירת התמונה (ברירת מחדל: 15) | FLOAT | לא | 1-100 |
| `steps` | מספר הצעדים עבור תהליך יצירת התמונה (ברירת מחדל: 50) | INT | לא | 15-50 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | לא | 0-18446744073709551615 |
