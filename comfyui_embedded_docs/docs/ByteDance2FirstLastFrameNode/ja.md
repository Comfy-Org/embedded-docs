# ByteDance Seedance 2.0 ファースト・ラストフレームから動画生成

このノードは、ByteDance Seedance 2.5 または Seedance 2.0 モデルを使用して、必須の最初のフレーム画像と任意の最後のフレーム画像から動画を生成します。最初のフレームはクリップの開始を定義し、最後のフレーム（指定された場合）は終了を定義し、テキストプロンプトが動きを記述します。選択したモデルによって、利用可能な解像度、長さ、出力形式のオプションが決まります。

**制約と制限:**

*   `prompt` は必須で、少なくとも1文字以上の空白以外の文字を含む必要があります（先頭と末尾の空白は無視されます）。
*   最初のフレームのソースは正確に1つ指定する必要があります。`first_frame` 画像または `first_frame_asset_id` のいずれかです。両方を指定するとエラーが発生し、どちらも指定しない場合もエラーが発生します。
*   `last_frame` 画像と `last_frame_asset_id` は相互排他的です。両方とも省略できます。
*   アセットIDは、Active ステータスの既存の Seedance アセットを参照している必要があります。アセットがアクティブでない場合、または Image アセットでない場合は、エラーが発生します。
*   ローカル画像のアスペクト比は 0.4 から 2.5（2:5 から 5:2）の間である必要があります。
*   Seedance 2.0 モデルでは、ローカル画像は少なくとも 300x300 ピクセルである必要があります。画像は、選択した解像度と比率に対応する正確な出力サイズに自動的にリサイズされ、リクエストは比率 "adaptive" で送信されます。`ratio` が "adaptive" の場合、出力アスペクト比は最初のフレーム自身のアスペクト比から導出され、最も近いサポートされている比率に丸められます。ローカル画像の代わりにアセットIDを使用する場合は、選択した `ratio` の値が直接適用されます。
*   Seedance 2.5 では、またアセットIDを使用するすべてのモデルでは、画像は自動的に長辺が最大6000ピクセルに縮小され、各辺が300〜6000ピクセルである必要があります。
*   Seedance 2.5 は常に最初のフレームのアスペクト比を維持するため、このモデルには `ratio` 入力は表示されません。
*   長さの制限はモデルによって異なります。Seedance 2.5 は4〜30秒に対応し、Seedance 2.0、2.0 Fast、2.0 Mini は4〜15秒に対応します。
