# ByteDance Seedance 2.0 من الإطار الأول/الأخير إلى فيديو

تنشئ هذه العقدة فيديو من صورة الإطار الأول المطلوبة وصورة إطار أخير اختيارية باستخدام نماذج ByteDance Seedance. تصف الفيديو عبر نص موجه (prompt)؛ يوجّه الإطار الأول بداية الفيديو ويوجّه الإطار الأخير نهايته. وهي تدعم Seedance 2.5 وعائلة Seedance 2.0 (Seedance 2.0 وSeedance 2.0 Fast وSeedance 2.0 Mini).

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | Seedance 2.5 لأحدث نموذج، مع فيديوهات تصل إلى 30 ثانية وإخراج mp4/mov؛ وSeedance 2.0 لأقصى جودة ودقة 4k؛ وFast لتحسين السرعة؛ وMini لأسرع توليد وأقل تكلفة. تحديد نموذج يُظهر مدخلات خاصة به أدناه. | DYNAMIC_COMBO | نعم | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `الإطار الأول` | صورة الإطار الأول للفيديو. | IMAGE | لا | - |
| `الإطار الأخير` | صورة الإطار الأخير للفيديو. | IMAGE | لا | - |
| `first_frame_asset_id` | معرّف الأصل (asset_id) الخاص بـ Seedance لاستخدامه كإطار أول. حصري مع الإدخال الصوري `first_frame`. القيمة الافتراضية هي سلسلة فارغة. | STRING | لا | - |
| `last_frame_asset_id` | معرّف الأصل (asset_id) الخاص بـ Seedance لاستخدامه كإطار أخير. حصري مع الإدخال الصوري `last_frame`. القيمة الافتراضية هي سلسلة فارغة. | STRING | لا | - |
| `البذرة` | تتحكم البذرة (seed) في ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن البذرة. الافتراضي هو 0. | INT | نعم | 0 إلى 2147483647 |

**قيود المعاملات**

- يجب توفير الإطار الأول إما كصورة `first_frame` أو كمعرّف `first_frame_asset_id`. تقديم كلاهما يسبب خطأً؛ وعدم تقديم أي منهما يسبب خطأً أيضًا.
- الإدخالان `last_frame` و`last_frame_asset_id` اختياريان، ولكن لا يمكنك تقديمهما معًا لنفس الإطار.
- يجب أن تشير معرّفات الأصول إلى أصول Seedance Image موجودة ونشطة.
- إدخال `prompt` مطلوب ولا يمكن أن يكون فارغًا.
- مع `Seedance 2.5`، تكون نسبة أبعاد المخرجات دائمًا تكيفية (adaptive) وتتبع نسبة أبعاد الإطار الأول نفسها، لذا لا يظهر أي إدخال `ratio`.
- مع نماذج عائلة Seedance 2.0 وصور الإطارات المحلية، تُقتص الصور من المنتصف وتُغيَّر أبعادها إلى دقة ونسبة الإخراج المستهدفة قبل التوليد. عندما تكون `ratio` هي `adaptive`، تُستخدم أقرب نسبة مدعومة للصورة المُدخلة.
- يتم التحقق من صور الإطارات المحلية للتأكد من نسبة الأبعاد والأبعاد المدعومة؛ ويتم تقليل حجم الصور الكبيرة.
