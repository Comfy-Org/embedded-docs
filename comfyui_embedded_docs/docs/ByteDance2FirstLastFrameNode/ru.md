# ByteDance Seedance 2.0: от первого и последнего кадра к видео

Этот узел генерирует видео из обязательного изображения первого кадра и необязательного изображения последнего кадра с использованием моделей ByteDance Seedance. Вы описываете видео с помощью текстового промпта; первый кадр задает начало видео, а последний кадр — его конец. Поддерживаются Seedance 2.5 и семейство Seedance 2.0 (Seedance 2.0, Seedance 2.0 Fast и Seedance 2.0 Mini). При выборе модели `Seedance 2.5 Draft` вместо этого создается быстрое превью 480p; подключите полученный `draft_task_id` к узлу ByteDance Seedance 2.5 Draft to Final Video, чтобы отрендерить финальное видео 1080p.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|

Выбор модели показывает зависящие от модели входы ниже. | DYNAMIC_COMBO | Да | `"Seedance 2.5"`<br>`"Seedance 2.5 Draft"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |

**Ограничения параметров**

- Необходимо указать первый кадр либо как изображение `first_frame`, либо как `first_frame_asset_id`. Если указать оба, возникнет ошибка; если не указать ни один, также возникнет ошибка.
- Входы `last_frame` и `last_frame_asset_id` необязательны, но нельзя указывать оба для одного и того же кадра.
- ID ассетов должны ссылаться на существующие активные ассеты Seedance Image.
- Вход `prompt` обязателен и не может быть пустым.
- Каждый запуск возвращает ID своей задачи как `draft_task_id`, но только ID запуска `Seedance 2.5 Draft` может быть отрендерен узлом ByteDance Seedance 2.5 Draft to Final Video. При любой другой модели выход необходимо оставить неподключенным, иначе запуск завершится ошибкой.
- Для `Seedance 2.5` соотношение сторон выходного видео всегда адаптивное и следует собственному соотношению сторон первого кадра, поэтому вход `ratio` не отображается.
- Для моделей семейства Seedance 2.0 и локальных изображений кадров изображения перед генерацией обрезаются по центру и масштабируются до целевого разрешения и соотношения сторон выходного видео. Когда `ratio` имеет значение `adaptive`, используется ближайшее поддерживаемое соотношение сторон к входному изображению.
- Локальные изображения кадров проверяются на поддерживаемое соотношение сторон и размеры; изображения слишком большого размера уменьшаются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео. | VIDEO |
| `draft_task_id` | ID задачи, возвращенный запуском. Только запуск `Seedance 2.5 Draft` создает драфт, который может отрендерить узел ByteDance Seedance 2.5 Draft to Final Video; при любой другой модели выход необходимо оставить неподключенным, иначе запуск завершится ошибкой. | STRING |
