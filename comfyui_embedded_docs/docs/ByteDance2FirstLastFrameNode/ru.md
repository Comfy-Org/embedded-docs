# ByteDance Seedance 2.0: от первого и последнего кадра к видео

Этот узел генерирует видео из обязательного первого кадра изображения и опционального последнего кадра изображения с использованием моделей ByteDance Seedance 2.5 или Seedance 2.0. Первый кадр определяет начало клипа, последний кадр (если задан) определяет конец, а текстовый промпт описывает движение. Выбранная модель управляет доступными разрешениями, длительностями и опциями формата вывода.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации видео. Seedance 2.5 — новейшая модель с видео до 30 секунд и выводом в mp4/mov; Seedance 2.0 предлагает максимальное качество и 1080p/4k; Fast оптимизирована для скорости; Mini — самая быстрая и недорогая генерация. Выбор модели открывает её специфические входы ниже. | DYNAMIC_COMBO | Да | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `first_frame` | Изображение первого кадра для видео. Требуется одно из `first_frame` или `first_frame_asset_id`. | IMAGE | Нет | - |
| `last_frame` | Изображение последнего кадра для видео. | IMAGE | Нет | - |

### Общие для Seedance 2.0 Fast и Seedance 2.0 Mini

Эти две модели предоставляют те же входы, что и Seedance 2.0, за исключением того, что доступны только разрешения 480p и 720p.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео. По умолчанию — пустая строка. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `ratio` | Соотношение сторон выходного видео. По умолчанию — "adaptive". | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах (4-15). По умолчанию — 7. | INT | Да | 4 to 15 |
| `generate_audio` | Включить генерацию звука для выходного видео. По умолчанию — True. | BOOLEAN | Да | - |

**Ограничения и лимиты:**

*   `prompt` является обязательным и должен содержать хотя бы один непробельный символ (ведущие и завершающие пробелы игнорируются).
*   Необходимо указать ровно один источник первого кадра: либо изображение `first_frame`, либо `first_frame_asset_id`. Передача обоих вызывает ошибку, как и передача ни одного.
*   Изображение `last_frame` и `last_frame_asset_id` взаимоисключающие. Оба могут быть опущены.
*   Идентификаторы активов должны ссылаться на существующие активы Seedance со статусом Active. Если актив не активен или не является Image-активом, возникает ошибка.
*   Локальные изображения должны иметь соотношение сторон от 0.4 до 2.5 (от 2:5 до 5:2).
*   Для моделей Seedance 2.0 локальные изображения должны быть не менее 300x300 пикселей. Они автоматически изменяются до точных поддерживаемых размеров выходного изображения для выбранного разрешения и соотношения сторон, и запрос отправляется с соотношением "adaptive". Когда `ratio` равно "adaptive", соотношение сторон вывода определяется из собственного соотношения сторон первого кадра с округлением до ближайшего поддерживаемого соотношения. При использовании идентификаторов активов вместо локальных изображений выбранное значение `ratio` применяется напрямую.
*   Для Seedance 2.5, а также для любой модели при использовании идентификаторов активов изображения автоматически уменьшаются до максимальной стороны 6000 пикселей и должны быть от 300 до 6000 пикселей по каждому измерению.
*   Seedance 2.5 всегда сохраняет собственное соотношение сторон первого кадра, поэтому для этой модели не показывается вход `ratio`.
*   Лимиты длительности различаются в зависимости от модели: Seedance 2.5 поддерживает 4-30 секунд, а Seedance 2.0, 2.0 Fast и 2.0 Mini поддерживают 4-15 секунд.
