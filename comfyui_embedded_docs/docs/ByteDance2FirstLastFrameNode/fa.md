# ByteDance Seedance 2.0 تبدیل اولین-آخرین فریم به ویدیو

این گره با استفاده از مدل‌های ByteDance Seedance، از یک تصویر فریم اول الزامی و یک تصویر فریم آخر اختیاری ویدیو تولید می‌کند. شما ویدیو را با یک پرامپت متنی توصیف می‌کنید؛ فریم اول شروع ویدیو و فریم آخر پایان آن را هدایت می‌کند. از Seedance 2.5 و خانواده Seedance 2.0 (Seedance 2.0، Seedance 2.0 Fast و Seedance 2.0 Mini) پشتیبانی می‌کند. انتخاب مدل `Seedance 2.5 Draft` در عوض یک پیش‌نمایش سریع 480p رندر می‌کند؛ `draft_task_id` حاصل را به گره ByteDance Seedance 2.5 Draft to Final Video وصل کنید تا نسخه نهایی 1080p رندر شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | Seedance 2.5 برای جدیدترین مدل، ویدیوهایی تا 30 ثانیه و خروجی mp4؛ Seedance 2.5 Draft برای پیش‌نمایش سریع 480p که خروجی `draft_task_id` آن نسخه نهایی 1080p را در گره ByteDance Seedance 2.5 Draft to Final Video رندر می‌کند؛ Seedance 2.0 برای بالاترین کیفیت و 4k؛ Fast برای بهینه‌سازی سرعت؛ Mini برای سریع‌ترین و کم‌هزینه‌ترین تولید. انتخاب یک مدل، ورودی‌های مخصوص همان مدل را در ادامه نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"Seedance 2.5"`<br>`"Seedance 2.5 Draft"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `اولین فریم` | تصویر فریم اول برای ویدیو. | IMAGE | خیر | - |
| `آخرین فریم` | تصویر فریم آخر برای ویدیو. | IMAGE | خیر | - |
| `first_frame_asset_id` | asset_id مربوط به Seedance برای استفاده به‌عنوان فریم اول. با ورودی تصویر `first_frame` ناسازگار است. پیش‌فرض یک رشته خالی است. | STRING | خیر | - |
| `last_frame_asset_id` | asset_id مربوط به Seedance برای استفاده به‌عنوان فریم آخر. با ورودی تصویر `last_frame` ناسازگار است. پیش‌فرض یک رشته خالی است. | STRING | خیر | - |
| `seed` | `seed` کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به مقدار seed غیرقطعی هستند. پیش‌فرض 0 است. | INT | بله | 0 تا 2147483647 |
| `واترمارک` | این‌که آیا به ویدیو واترمارک اضافه شود. پیش‌فرض False است. | BOOLEAN | بله | False<br>True |

### ورودی‌های Seedance 2.5 Draft

| `ratio` | نسبت ابعاد ویدیوی خروجی. پیش‌فرض `adaptive` است، که نزدیک‌ترین نسبت پشتیبانی‌شده به نسبت ابعاد فریم ورودی را استفاده می‌کند. | COMBO | بله | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (4-15). پیش‌فرض 7 است. | INT | بله | 4 تا 15 |
| `generate_audio` | تولید صدا را برای ویدیوی خروجی فعال می‌کند. پیش‌فرض True است. | BOOLEAN | بله | False<br>True |

**محدودیت‌های پارامترها**

- باید فریم اول را یا به‌صورت تصویر `first_frame` یا به‌صورت `first_frame_asset_id` ارائه دهید. ارائه هر دو خطا ایجاد می‌کند؛ ارائه هیچ‌کدام نیز خطا ایجاد می‌کند.
- ورودی‌های `last_frame` و `last_frame_asset_id` اختیاری هستند، اما نمی‌توانید هر دو را برای یک فریم ارائه دهید.
- شناسه‌های Asset باید به Assetهای تصویری Seedance موجود و فعال ارجاع دهند.
- ورودی `prompt` الزامی است و نمی‌تواند خالی باشد.
- هر اجرا شناسه وظیفه خود را به‌صورت `draft_task_id` برمی‌گرداند، اما فقط شناسه اجرای `Seedance 2.5 Draft` می‌تواند توسط گره ByteDance Seedance 2.5 Draft to Final Video رندر شود. با هر مدل دیگری، خروجی باید بدون اتصال رها شود، در غیر این صورت اجرا شکست می‌خورد.
- با `Seedance 2.5`، نسبت ابعاد خروجی همیشه `adaptive` است و از نسبت ابعاد خود فریم اول پیروی می‌کند، بنابراین هیچ ورودی `ratio` نمایش داده نمی‌شود.
- با مدل‌های خانواده Seedance 2.0 و تصاویر فریم محلی، تصاویر قبل از تولید به‌صورت مرکزی برش خورده و به رزولوشن و نسبت خروجی هدف تغییر اندازه داده می‌شوند. وقتی `ratio` برابر `adaptive` است، نزدیک‌ترین نسبت پشتیبانی‌شده به تصویر ورودی استفاده می‌شود.
- تصاویر فریم محلی از نظر نسبت ابعاد و ابعاد پشتیبانی‌شده اعتبارسنجی می‌شوند؛ تصاویر بیش‌ازحد بزرگ کوچک‌سازی می‌شوند.
