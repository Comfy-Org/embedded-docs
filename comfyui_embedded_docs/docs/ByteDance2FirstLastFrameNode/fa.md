# ByteDance Seedance 2.0 تبدیل اولین-آخرین فریم به ویدیو

این گره با استفاده از مدل‌های ByteDance Seedance یک ویدیو از یک تصویر فریم اول الزامی و یک تصویر فریم آخر اختیاری تولید می‌کند. شما ویدیو را با یک پرامپت متنی توصیف می‌کنید؛ فریم اول آغاز ویدیو و فریم آخر پایان آن را هدایت می‌کند. از Seedance 2.5 و خانواده Seedance 2.0 (Seedance 2.0، Seedance 2.0 Fast و Seedance 2.0 Mini) پشتیبانی می‌کند. انتخاب مدل `Seedance 2.5 Draft` به‌جای آن یک پیش‌نمایش سریع 480p رندر می‌کند؛ `draft_task_id` حاصل را به گره ByteDance Seedance 2.5 Draft to Final Video متصل کنید تا نسخه نهایی 1080p رندر شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مدل` | Seedance 2.5 برای جدیدترین مدل، ویدیوهایی تا 30 ثانیه و خروجی mp4/mov؛ Seedance 2.5 Draft برای یک پیش‌نمایش سریع 480p که خروجی `draft_task_id` آن نسخه نهایی 1080p را در گره ByteDance Seedance 2.5 Draft to Final Video رندر می‌کند؛ Seedance 2.0 برای حداکثر کیفیت و 4k؛ Fast برای بهینه‌سازی سرعت؛ Mini برای سریع‌ترین تولید با کم‌ترین هزینه. انتخاب یک مدل، ورودی‌های مخصوص مدل را در ادامه نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"Seedance 2.5"`<br>`"Seedance 2.5 Draft"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `اولین فریم` | تصویر فریم اول برای ویدیو. | IMAGE | خیر | - |
| `آخرین فریم` | تصویر فریم آخر برای ویدیو. | IMAGE | خیر | - |
| `first_frame_asset_id` | Seedance asset_id برای استفاده به‌عنوان فریم اول. با ورودی تصویر `first_frame` ناسازگار است. پیش‌فرض رشته خالی است. | STRING | خیر | - |
| `last_frame_asset_id` | Seedance asset_id برای استفاده به‌عنوان فریم آخر. با ورودی تصویر `last_frame` ناسازگار است. پیش‌فرض رشته خالی است. | STRING | خیر | - |
| `seed` | `seed` کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. پیش‌فرض 0 است. | INT | بله | 0 تا 2147483647 |
| `واترمارک` | اینکه آیا واترمارک به ویدیو اضافه شود. پیش‌فرض False است. | BOOLEAN | بله | False<br>True |

| `duration` | مدت ویدیوی خروجی بر حسب ثانیه (4-30). پیش‌فرض 5 است. | INT | بله | 4 تا 30 |

### ورودی‌های Seedance 2.5 Draft

این ورودی‌ها زمانی ظاهر می‌شوند که `Seedance 2.5 Draft` انتخاب شده باشد. مجموعه پارامترها با Seedance 2.5 در بالا مطابقت دارد، با این تفاوت که `resolution` فقط `"480p"` را ارائه می‌دهد (پیش‌فرض `"480p"`).

**محدودیت‌های پارامترها**

- باید فریم اول را یا به‌صورت تصویر `first_frame` یا به‌صورت `first_frame_asset_id` ارائه دهید. ارائه هر دو خطا ایجاد می‌کند؛ ارائه هیچ‌کدام نیز خطا ایجاد می‌کند.
- ورودی‌های `last_frame` و `last_frame_asset_id` اختیاری هستند، اما نمی‌توانید هر دو را برای یک فریم ارائه دهید.
- شناسه‌های asset باید به دارایی‌های تصویری Seedance موجود و فعال ارجاع دهند.
- ورودی `prompt` الزامی است و نمی‌تواند خالی باشد.
- خروجی `draft_task_id` فقط توسط `Seedance 2.5 Draft` تولید می‌شود؛ با هر مدل دیگری باید بدون اتصال رها شود، در غیر این صورت اجرا شکست می‌خورد.
- با `Seedance 2.5`، نسبت ابعاد خروجی همیشه adaptive است و از نسبت ابعاد خود فریم اول پیروی می‌کند، بنابراین هیچ ورودی `ratio` نمایش داده نمی‌شود.
- با مدل‌های خانواده Seedance 2.0 و تصاویر فریم محلی، تصاویر قبل از تولید به‌صورت مرکزی برش داده شده و به رزولوشن و نسبت خروجی هدف تغییر اندازه داده می‌شوند. وقتی `ratio` برابر `adaptive` است، نزدیک‌ترین نسبت پشتیبانی‌شده به تصویر ورودی استفاده می‌شود.
- تصاویر فریم محلی از نظر نسبت ابعاد و ابعاد پشتیبانی‌شده اعتبارسنجی می‌شوند؛ تصاویر بزرگ‌تر از حد مجاز کوچک‌سازی می‌شوند.
