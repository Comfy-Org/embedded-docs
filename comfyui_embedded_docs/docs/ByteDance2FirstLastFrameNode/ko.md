# ByteDance Seedance 2.0 첫-마지막 프레임에서 비디오 생성

이 노드는 ByteDance Seedance 2.5 또는 Seedance 2.0 모델을 사용하여 필수 첫 프레임 이미지와 선택적 마지막 프레임 이미지로부터 비디오를 생성합니다. 첫 프레임은 클립의 시작을 정의하고, 마지막 프레임(제공된 경우)은 끝을 정의하며, 텍스트 프롬프트는 움직임을 설명합니다. 선택한 모델에 따라 사용 가능한 해상도, 재생 시간, 출력 형식 옵션이 결정됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용되는 모델입니다. Seedance 2.5는 최대 30초 비디오와 mp4/mov 출력을 지원하는 최신 모델입니다. Seedance 2.0은 최고 품질과 1080p/4k를 제공합니다. Fast는 속도에 최적화되어 있고, Mini는 가장 빠르고 저렴한 생성 방식입니다. 모델을 선택하면 아래에 해당 모델의 특정 입력 항목이 표시됩니다. | DYNAMIC_COMBO | 예 | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `first_frame` | 비디오의 첫 프레임 이미지입니다. `first_frame` 또는 `first_frame_asset_id` 중 하나는 필수입니다. | IMAGE | 아니요 | - |
| `last_frame` | 비디오의 마지막 프레임 이미지입니다. | IMAGE | 아니요 | - |
| `first_frame_asset_id` | 첫 프레임으로 사용할 Seedance asset_id입니다. `first_frame` 이미지 입력과 함께 사용할 수 없습니다. 기본값은 빈 문자열입니다. | STRING | 아니요 | - |
| `last_frame_asset_id` | 마지막 프레임으로 사용할 Seedance asset_id입니다. `last_frame` 이미지 입력과 함께 사용할 수 없습니다. 기본값은 빈 문자열입니다. | STRING | 아니요 | - |
| `seed` | 시드는 노드가 다시 실행되어야 하는지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값은 0입니다. | INT | 아니요 | 0 ~ 2147483647 |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다. 기본값은 False입니다. | BOOLEAN | 아니요 | - |

| `resolution` | 출력 비디오의 해상도입니다. 기본값은 "720p"입니다. | COMBO | 예 | `"480p"`<br>`"720p"` |
| `duration` | 출력 비디오의 재생 시간(초)입니다(4~30초). 기본값은 5입니다. | INT | 예 | 4 ~ 30 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화할지 여부입니다. 기본값은 True입니다. | BOOLEAN | 예 | - |
| `output_format` | 출력 비디오의 컨테이너 형식입니다. 기본값은 "mp4"입니다. | COMBO | 예 | `"mp4"` |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 공통

이 두 모델은 Seedance 2.0과 동일한 입력 항목을 제공하며, 다만 480p와 720p 해상도만 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. 기본값은 빈 문자열입니다. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br>`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값은 "adaptive"입니다. | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 재생 시간(초)입니다(4~15초). 기본값은 7입니다. | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화할지 여부입니다. 기본값은 True입니다. | BOOLEAN | 예 | - |

**제약 사항 및 한계:**

*   `prompt`는 필수 입력이며 공백 문자만이 아닌 최소 하나 이상의 문자를 포함해야 합니다(앞뒤 공백은 무시됨).
*   첫 프레임 소스는 정확히 하나만 제공해야 합니다. 즉 `first_frame` 이미지 또는 `first_frame_asset_id` 중 하나만 사용해야 합니다. 둘 다 제공하면 오류가 발생하고, 둘 다 제공하지 않아도 오류가 발생합니다.
*   `last_frame` 이미지와 `last_frame_asset_id`는 함께 사용할 수 없습니다. 둘 다 생략할 수 있습니다.
*   Asset ID는 Active 상태인 기존 Seedance 자산을 참조해야 합니다. 자산이 활성 상태가 아니거나 이미지 자산이 아닌 경우 오류가 발생합니다.
*   로컬 이미지의 화면 비율은 0.4~2.5(2:5~5:2) 사이여야 합니다.
*   Seedance 2.0 모델의 경우 로컬 이미지는 최소 300x300 픽셀이어야 합니다. 이미지는 선택한 해상도와 비율에 맞게 지원되는 정확한 출력 크기로 자동 조정되며, 요청은 "adaptive" 비율로 제출됩니다. `ratio`가 "adaptive"인 경우 출력 화면 비율은 첫 프레임 자체의 화면 비율에서 파생되며, 가장 가까운 지원 비율로 맞춰집니다. 로컬 이미지 대신 asset ID를 사용하는 경우 선택한 `ratio` 값이 직접 적용됩니다.
*   Seedance 2.5의 경우, 그리고 asset ID를 사용하는 모든 모델의 경우 이미지는 자동으로 최대 6000픽셀의 긴 변으로 축소되며 각 변의 길이는 300~6000픽셀 사이여야 합니다.
*   Seedance 2.5는 항상 첫 프레임 자체의 화면 비율을 유지하므로 이 모델에는 `ratio` 입력이 표시되지 않습니다.
*   재생 시간 제한은 모델에 따라 다릅니다. Seedance 2.5는 4~30초를 지원하고, Seedance 2.0, 2.0 Fast, 2.0 Mini는 4~15초를 지원합니다.
