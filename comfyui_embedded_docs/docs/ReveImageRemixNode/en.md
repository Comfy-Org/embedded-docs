# Reve Image Remix

The Reve Image Remix node uses the Reve API to generate a new image. It combines one or more reference images with a text prompt to create a new, remixed image based on the provided description. Two model versions are available, and optional postprocessing such as upscaling or background removal can be applied.

## Inputs

### Common Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Model version to use for remixing. Selecting a model reveals its aspect ratio and test-time scaling settings. | DYNAMIC_COMBO | Yes | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | Text description of the desired image. May include XML img tags to reference specific images by index, e.g. `<img>0</img>`, `<img>1</img>`, etc. (default: empty) | STRING | Yes | 1 to 2560 characters |
| `upscale` | Upscale the generated image. May add additional cost. When set to "enabled", an `upscale_factor` setting is revealed. (default: "disabled") | DYNAMIC_COMBO | No | `"disabled"`<br>`"enabled"` |
| `remove_background` | Remove the background from the generated image. May add additional cost. (default: false) | BOOLEAN | No | `true`<br>`false` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed. (default: 0) | INT | No | 0 to 2147483647 |

### Model Version Inputs (shared by `reve-remix@20250915` and `reve-remix-fast@20251030`)

Both model versions expose the same settings.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Aspect ratio of the output image. When set to "auto", the API decides the aspect ratio automatically. | COMBO | No | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Higher values produce better images but cost more credits. (default: 1; only values greater than 1 are applied) | INT | No | 1 to 5 (step 1) |

### Reference Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Growable slot: connect 1 to 6 reference images to use as a base for the remix (slots are named `image_1`, `image_2`, etc.). At least one reference image is required. | IMAGE | Yes | 1 to 6 images |

**Note:** The prompt must be between 1 and 2560 characters. When `upscale` is set to "enabled", the nested `upscale_factor` setting accepts 2, 3, or 4 (default: 2) and may add additional cost. Removing the background may also add additional cost.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | The new image generated by the Reve remix process. | IMAGE |
