# Reve画像リミックス

Reve Image Remix ノードは、Reve API を使用して新しい画像を生成します。1つ以上の参照画像とテキストプロンプトを組み合わせ、指定された説明に基づいて新しいリミックス画像を作成します。2つのモデルバージョンが利用可能で、アップスケーリングや背景除去などのオプションの後処理を適用できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | リミックスに使用するモデルバージョン。モデルを選択すると、そのアスペクト比とテスト時スケーリング設定が表示されます。 | DYNAMIC_COMBO | はい | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | 希望する画像のテキストによる説明。特定の画像をインデックスで参照するために、XML img タグ（例: `<img>0</img>`、`<img>1</img>` など）を含めることができます。（デフォルト: 空） | STRING | はい | 1～2560文字 |
| `upscale` | 生成された画像をアップスケールします。追加コストがかかる場合があります。"enabled" に設定すると、`upscale_factor` 設定が表示されます。（デフォルト: "disabled"） | DYNAMIC_COMBO | いいえ | `"disabled"`<br>`"enabled"` |
| `remove_background` | 生成された画像から背景を除去します。追加コストがかかる場合があります。（デフォルト: false） | BOOLEAN | いいえ | `true`<br>`false` |
| `seed` | シードはノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。（デフォルト: 0） | INT | いいえ | 0～2147483647 |

### モデルバージョン入力（`reve-remix@20250915` と `reve-remix-fast@20251030` で共通）

両方のモデルバージョンで同じ設定を使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 出力画像のアスペクト比。"auto" に設定すると、API がアスペクト比を自動的に決定します。 | COMBO | いいえ | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 値が大きいほど高品質な画像が生成されますが、より多くのクレジットを消費します。（デフォルト: 1。1より大きい値のみが適用されます） | INT | いいえ | 1～5（ステップ 1） |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能スロット: リミックスのベースとして使用する参照画像を1～6枚接続します（スロットは `image_1`、`image_2` などと名付けられています）。少なくとも1枚の参照画像が必要です。 | IMAGE | はい | 1～6枚 |

**注:** プロンプトは1～2560文字で指定する必要があります。`upscale` が "enabled" に設定されている場合、ネストされた `upscale_factor` 設定には 2、3、または 4（デフォルト: 2）を指定でき、追加コストがかかる場合があります。背景の除去にも追加コストがかかる場合があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | Reve リミックスプロセスによって生成された新しい画像。 | IMAGE |
