# ترکیب تصویر با Reve

گره Reve Image Remix از API شرکت Reve برای تولید یک تصویر جدید استفاده می‌کند. این گره یک یا چند تصویر مرجع را با یک راهنمای متنی ترکیب می‌کند تا تصویری جدید و بازترکیب‌شده بر اساس توضیحات داده‌شده ایجاد کند. دو نسخه از مدل در دسترس است و می‌توان پردازش‌های اختیاری مانند افزایش مقیاس یا حذف پس‌زمینه را اعمال کرد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدلی که برای بازترکیب استفاده می‌شود. انتخاب یک مدل، تنظیمات نسبت تصویر و مقیاس‌دهی در زمان آزمونِ آن را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | توضیح متنی تصویر موردنظر. می‌تواند شامل تگ‌های img مبتنی بر XML باشد تا تصاویر خاصی را بر اساس ایندکس ارجاع دهد، مثلاً `<img>0</img>`، `<img>1</img>` و غیره. (پیش‌فرض: خالی) | STRING | بله | 1 تا 2560 کاراکتر |
| `upscale` | افزایش مقیاس تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. وقتی روی «enabled» تنظیم شود، تنظیم `upscale_factor` نمایان می‌شود. (پیش‌فرض: «disabled») | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `remove_background` | حذف پس‌زمینه از تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. (پیش‌فرض: false) | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | Seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ صرف‌نظر از seed، نتایج غیرقطعی هستند. (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

### ورودی‌های نسخه مدل (مشترک بین `reve-remix@20250915` و `reve-remix-fast@20251030`)

هر دو نسخه مدل تنظیمات یکسانی را ارائه می‌دهند.

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | نسبت تصویر خروجی. وقتی روی «auto» تنظیم شود، API به‌طور خودکار نسبت تصویر را تعیین می‌کند. | COMBO | خیر | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما اعتبار بیشتری هزینه دارند. (پیش‌فرض: 1؛ فقط مقادیر بزرگ‌تر از 1 اعمال می‌شوند) | INT | خیر | 1 تا 5 (گام 1) |

### ورودی‌های مرجع

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | اسلات قابل‌افزایش: 1 تا 6 تصویر مرجع را برای استفاده به‌عنوان پایه بازترکیب متصل کنید (اسلات‌ها با نام‌های `image_1`، `image_2` و غیره نامگذاری شده‌اند). حداقل یک تصویر مرجع الزامی است. | IMAGE | بله | 1 تا 6 تصویر |

**توجه:** راهنما (prompt) باید بین 1 تا 2560 کاراکتر باشد. وقتی `upscale` روی «enabled» تنظیم شود، تنظیم تو در توی `upscale_factor` مقادیر 2، 3 یا 4 را می‌پذیرد (پیش‌فرض: 2) و ممکن است هزینه اضافی داشته باشد. حذف پس‌زمینه نیز ممکن است هزینه اضافی به همراه داشته باشد.
