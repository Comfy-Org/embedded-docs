# Reve Ремикс изображения

Узел Reve Image Remix использует API Reve для генерации нового изображения. Он объединяет одно или несколько референсных изображений с текстовым запросом, чтобы создать новое, ремикшированное изображение на основе заданного описания. Доступны две версии модели, а также может применяться необязательная постобработка, такая как увеличение масштаба или удаление фона.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели для ремикса. При выборе модели отображаются её настройки соотношения сторон и масштабирования на этапе тестирования. | DYNAMIC_COMBO | Да | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | Текстовое описание желаемого изображения. Может содержать XML-теги img для ссылки на конкретные изображения по индексу, например `<img>0</img>`, `<img>1</img>` и т.д. (по умолчанию: пусто) | STRING | Да | 1 to 2560 characters |
| `upscale` | Увеличивает масштаб сгенерированного изображения. Может привести к дополнительным затратам. При значении "enabled" появляется настройка `upscale_factor`. (по умолчанию: "disabled") | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удаляет фон сгенерированного изображения. Может привести к дополнительным затратам. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Нет | 0 to 2147483647 |

### Входы версий модели (общие для `reve-remix@20250915` и `reve-remix-fast@20251030`)

Обе версии модели предоставляют одинаковые настройки.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон выходного изображения. При значении "auto" API определяет соотношение сторон автоматически. | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Более высокие значения дают более качественные изображения, но требуют больше кредитов. (по умолчанию: 1; применяются только значения больше 1) | INT | Нет | 1 to 5 (step 1) |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до 6 референсных изображений, которые будут использоваться как основа для ремикса (слоты называются `image_1`, `image_2` и т.д.). Требуется как минимум одно референсное изображение. | IMAGE | Да | 1 to 6 images |

**Примечание:** Текст запроса должен содержать от 1 до 2560 символов. Когда `upscale` установлен в "enabled", вложенная настройка `upscale_factor` принимает значения 2, 3 или 4 (по умолчанию: 2) и может привести к дополнительным затратам. Удаление фона также может привести к дополнительным затратам.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Новое изображение, созданное в процессе ремикса Reve. | IMAGE |

Примечание: этот узел помечен как устаревший.
