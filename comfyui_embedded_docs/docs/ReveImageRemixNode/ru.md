# Reve Ремикс изображения

Узел Reve Image Remix использует API Reve для генерации нового изображения. Он объединяет одно или несколько эталонных изображений с текстовым запросом, чтобы создать новое, ремикшированное изображение на основе заданного описания.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели, используемой для ремикса. | DYNAMIC_COMBO | Да | `"reve-remix@20250915"`<br>`"reve-remix-fast@20251030"` |
| `prompt` | Текстовое описание желаемого изображения. Может содержать XML-теги img для ссылки на конкретные изображения по индексу, например `<img>0</img>`, `<img>1</img>` и т. д. (по умолчанию: пусто) | STRING | Да | от 1 до 2560 символов |
| `upscale` | Увеличить сгенерированное изображение. Может добавить дополнительную стоимость. (по умолчанию: "disabled") | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удалить фон с сгенерированного изображения. Может добавить дополнительную стоимость. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | Сид управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Нет | от 0 до 2147483647 |

### Входы модели (общие для reve-remix@20250915 и reve-remix-fast@20251030)

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон выходного изображения. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Более высокие значения дают изображения лучшего качества, но стоят больше кредитов. (по умолчанию: 1) | INT | Нет | от 1 до 5 |

### Входы увеличения (появляются, когда `upscale` имеет значение "enabled")

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | Коэффициент увеличения (2x, 3x или 4x). (по умолчанию: 2) | INT | Нет | от 2 до 4 |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до 6 изображений (`image_1`–`image_6`), чтобы использовать их в качестве визуальной основы для ремикса. Требуется как минимум одно эталонное изображение. | IMAGE | Да | от 1 до 6 изображений |

**Примечание:** Текст запроса должен содержать от 1 до 2560 символов. Когда для `aspect_ratio` установлено значение "auto", сервис определяет соотношение сторон выходного изображения. Значение `test_time_scaling`, равное 1, обеспечивает стандартную обработку; более высокие значения улучшают качество изображения, но потребляют больше кредитов. Виджет `upscale_factor` появляется только тогда, когда для `upscale` установлено значение "enabled". Результаты ремикса недетерминированы независимо от значения сида. Этот узел устарел.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Новое изображение, сгенерированное в процессе ремикса Reve. | IMAGE |
