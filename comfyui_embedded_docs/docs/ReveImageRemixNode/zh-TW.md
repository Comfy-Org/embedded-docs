# Reve 圖像混合

以下是英文文檔的繁體中文翻譯：

---

Reve Image Remix 節點使用 Reve API 來生成新影像。它將一張或多張參考影像與文字提示結合，根據提供的描述建立新的混合影像。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於混合的模型版本。 | DYNAMIC_COMBO | 是 | `"reve-remix@20250915"`<br>`"reve-remix-fast@20251030"` |
| `提示詞` | 目標影像的文字描述。可包含 XML img 標籤以按索引參照特定影像，例如 `<img>0</img>`、`<img>1</img>` 等。（預設：空白） | STRING | 是 | 1 至 2560 個字元 |
| `放大` | 放大生成的影像。可能產生額外費用。（預設："disabled"） | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"enabled"` |
| `去背` | 從生成的影像中移除背景。可能產生額外費用。（預設：false） | BOOLEAN | 否 | `true`<br>`false` |
| `種子` | 種子控制節點是否應重新執行；無論種子為何，結果皆為非確定性。（預設：0） | INT | 否 | 0 至 2147483647 |

### 模型輸入（由 reve-remix@20250915 和 reve-remix-fast@20251030 共用）

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 輸出影像的縱橫比。（預設："auto"） | COMBO | 是 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 數值越高產生的影像品質越好，但花費的點數越多。（預設：1） | INT | 否 | 1 至 5 |

### 放大輸入（當 `upscale` 設定為「enabled」時顯示）

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | 放大倍率（2x、3x 或 4x）。（預設：2） | INT | 否 | 2 至 4 |

### 參考輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `參考圖像` | 可擴充插槽：連接 1 至 6 張影像（`image_1` 至 `image_6`）作為混合的視覺基礎。至少需要一張參考影像。 | IMAGE | 是 | 1 至 6 張影像 |

**注意：** 提示必須包含 1 至 2560 個字元。當 `aspect_ratio` 設定為「auto」時，服務會自行決定輸出影像的縱橫比。`test_time_scaling` 值為 1 時套用標準處理；較高的值會改善影像品質，但消耗更多點數。`upscale_factor` 小工具僅在 `upscale` 設定為「enabled」時顯示。混合結果無論種子值為何皆為非確定性。此節點已棄用。
