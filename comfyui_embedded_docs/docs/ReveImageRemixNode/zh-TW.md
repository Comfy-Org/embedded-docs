# Reve 圖像混合

Reve Image Remix 節點使用 Reve API 來生成新影像。此節點將一張或多張參考影像與文字提示詞結合，根據提供的描述建立重新混合的新影像。提供兩種模型版本，並可套用放大或移除背景等選用的後處理。

## 輸入
### 通用輸入

| 參數 | 說明 | 資料型別 | 是否必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於重新混合的模型版本。選擇模型後，會顯示其長寬比與測試時縮放設定。 | DYNAMIC_COMBO | 是 | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | 所需影像的文字描述。可包含 XML img 標籤，以索引方式引用特定影像，例如 `<img>0</img>`、`<img>1</img>` 等。（預設值：空） | STRING | 是 | 1 至 2560 字元 |
| `upscale` | 放大生成的影像。可能會產生額外費用。設為「enabled」時，會顯示 `upscale_factor` 設定。（預設值：「disabled」） | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"enabled"` |
| `remove_background` | 移除生成影像的背景。可能會產生額外費用。（預設值：false） | BOOLEAN | 否 | `true`<br>`false` |
| `seed` | `seed` 控制節點是否應重新執行；無論種子設定為何，結果皆為非確定性。（預設值：0） | INT | 否 | 0 至 2147483647 |

### 模型版本輸入（由 `reve-remix@20250915` 和 `reve-remix-fast@20251030` 共用）

兩個模型版本皆提供相同的設定。

| 參數 | 說明 | 資料型別 | 是否必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 輸出影像的長寬比。設為「auto」時，API 會自動決定長寬比。 | COMBO | 否 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 數值越高，生成的影像品質越好，但會消耗更多點數。（預設值：1；僅套用大於 1 的數值） | INT | 否 | 1 至 5（步長 1） |

### 參考輸入

| 參數 | 說明 | 資料型別 | 是否必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可擴充插槽：連接 1 至 6 張參考影像作為重新混合的基礎（插槽命名為 `image_1`、`image_2` 等）。至少需要一張參考影像。 | IMAGE | 是 | 1 至 6 張影像 |
