# Reve 이미지 리믹스

Reve Image Remix 노드는 Reve API를 사용하여 새 이미지를 생성합니다. 하나 이상의 참조 이미지와 텍스트 프롬프트를 결합하여 제공된 설명에 기반한 새로운 리믹스 이미지를 만듭니다. 두 가지 모델 버전을 사용할 수 있으며, 업스케일링이나 배경 제거와 같은 선택적 후처리를 적용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 리믹싱에 사용할 모델 버전입니다. 모델을 선택하면 해당 모델의 종횡비 및 테스트 시점 스케일링(test-time scaling) 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | 원하는 이미지에 대한 텍스트 설명입니다. 특정 이미지를 인덱스로 참조하기 위해 XML img 태그를 포함할 수 있습니다(예: `<img>0</img>`, `<img>1</img>` 등). (기본값: 빈 문자열) | STRING | 예 | 1~2560자 |
| `upscale` | 생성된 이미지를 업스케일링합니다. 추가 비용이 발생할 수 있습니다. "enabled"로 설정하면 `upscale_factor` 설정이 표시됩니다. (기본값: "disabled") | DYNAMIC_COMBO | 아니오 | `"disabled"`<br>`"enabled"` |
| `remove_background` | 생성된 이미지에서 배경을 제거합니다. 추가 비용이 발생할 수 있습니다. (기본값: false) | BOOLEAN | 아니오 | `true`<br>`false` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 아니오 | 0~2147483647 |

### 모델 버전 입력 (`reve-remix@20250915` 및 `reve-remix-fast@20251030` 공통)

두 모델 버전 모두 동일한 설정을 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 출력 이미지의 종횡비입니다. "auto"로 설정하면 API가 종횡비를 자동으로 결정합니다. | COMBO | 아니오 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 값이 높을수록 더 나은 이미지를 생성하지만 더 많은 크레딧이 소모됩니다. (기본값: 1; 1보다 큰 값만 적용됨) | INT | 아니오 | 1~5 (단계 1) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 리믹스의 기준으로 사용할 참조 이미지를 1~6개 연결합니다(슬롯 이름은 `image_1`, `image_2` 등으로 지정됩니다). 참조 이미지는 최소 1개 이상 필요합니다. | IMAGE | 예 | 1~6개 이미지 |

**참고:** 프롬프트는 1~2560자 사이여야 합니다. `upscale`을 "enabled"로 설정하면 하위 설정인 `upscale_factor`에서 2, 3, 4 값을 허용하며(기본값: 2) 추가 비용이 발생할 수 있습니다. 배경 제거 역시 추가 비용이 발생할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Reve 리믹스 프로세스로 생성된 새 이미지입니다. | IMAGE |

참고: 이 노드는 더 이상 사용되지 않는(deprecated) 것으로 표시되어 있습니다.
