# Reve 图像混合

Reve 图像重混节点使用 Reve API 生成新图像。它将一个或多个参考图像与文本提示词相结合，根据提供的描述创建新的重混图像。提供两个模型版本，并可应用可选的后期处理，如放大或背景移除。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于重混的模型版本。选择模型后会显示其宽高比和测试时缩放设置。 | DYNAMIC_COMBO | 是 | `reve-remix@20250915`<br>`reve-remix-fast@20251030` |
| `prompt` | 对所需图像的文本描述。可包含 XML `<img>` 标签，通过索引引用特定图像，例如 `<img>0</img>`、`<img>1</img>` 等。（默认：空） | STRING | 是 | 1 至 2560 个字符 |
| `upscale` | 放大生成的图像。可能会增加额外费用。当设置为“enabled”时，会显示 `upscale_factor` 设置。（默认：“disabled”） | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"enabled"` |
| `remove_background` | 从生成的图像中移除背景。可能会增加额外费用。（默认：false） | BOOLEAN | 否 | `true`<br>`false` |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。（默认：0） | INT | 否 | 0 至 2147483647 |

### 模型版本输入（由 `reve-remix@20250915` 和 `reve-remix-fast@20251030` 共享）

两个模型版本公开相同的设置。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 输出图像的宽高比。当设置为“auto”时，API 会自动决定宽高比。 | COMBO | 否 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | 数值越高，生成的图像质量越好，但消耗的积分也越多。（默认：1；仅应用大于 1 的值） | INT | 否 | 1 至 5（步长 1） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接 1 到 6 张参考图像，作为重混的基础（插槽命名为 `image_1`、`image_2` 等）。至少需要一张参考图像。 | IMAGE | 是 | 1 至 6 张图像 |

**注意：** 提示词必须介于 1 到 2560 个字符之间。当 `upscale` 设置为“enabled”时，嵌套的 `upscale_factor` 设置接受 2、3 或 4（默认：2），并可能增加额外费用。移除背景也可能增加额外费用。
