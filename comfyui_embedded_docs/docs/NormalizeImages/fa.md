# نرمال‌سازی تصاویر

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که باید نرمال‌سازی شود. | IMAGE | بله | - |
| `mean` | مقدار میانگین برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `std` | انحراف معیار برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.001 - 1.0 |

این گره رنگ‌های یک تصویر ورودی را با تنظیم مقادیر پیکسل‌های آن بر اساس میانگین و انحراف معیار مشخص‌شده نرمال‌سازی می‌کند. از هر پیکسل میانگین کم می‌شود و سپس بر انحراف معیار تقسیم می‌شود؛ این یک گام رایج برای استانداردسازی داده‌های تصویری پیش از سایر پردازش‌ها است.

پارامترهای `mean` و `std` نرمال‌سازی اعمال‌شده بر تصویر ورودی را کنترل می‌کنند. مقدار پیش‌فرض هر دو پارامتر 0.5 است.

نکته: اگر تصویر ورودی دارای کانال آلفا (شفافیت) باشد، آن کانال نرمال‌سازی نمی‌شود. بدون تغییر به خروجی کپی می‌شود، زیرا آلفا شفافیت را ذخیره می‌کند نه رنگ را.

نکته: این گره با هر اندازه دسته (batch size) کار می‌کند، بنابراین می‌توان چندین تصویر را به‌طور همزمان پردازش کرد.
