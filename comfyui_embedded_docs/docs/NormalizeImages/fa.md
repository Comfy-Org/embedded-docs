# نرمال‌سازی تصاویر

این گره یک تصویر ورودی را با کسر مقدار میانگین مشخص از هر پیکسل و سپس تقسیم نتیجه بر انحراف معیار مشخص، نرمال‌سازی می‌کند. این یک مرحله پیش‌پردازش رایج برای استانداردسازی مقادیر پیکسل‌ها و آماده‌سازی داده تصویری برای پردازش بیشتر است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویر ورودی که باید نرمال‌سازی شود. | IMAGE | بله | - |
| `mean` | مقدار میانگین برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `std` | انحراف معیار برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.001 - 1.0 |

نکته: نرمال‌سازی به کل دسته تصویر به‌طور هم‌زمان اعمال می‌شود و هر اندازه دسته‌ای پشتیبانی می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `image` | تصویر حاصل پس از اعمال فرآیند نرمال‌سازی. | IMAGE |
