# 画像を正規化

このノードは、入力画像の各ピクセルから指定された平均値を減算し、指定された標準偏差で除算することで、画像を正規化します。これは、ピクセル値を標準化し、画像データを後続の処理に備えるための一般的な前処理ステップです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | 正規化する入力画像です。 | IMAGE | はい | - |
| `mean` | 正規化に使用する平均値です（デフォルト：0.5）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `std` | 正規化に使用する標準偏差です（デフォルト：0.5）。 | FLOAT | いいえ | 0.001 - 1.0 |

注：正規化は画像バッチ全体に一度に適用され、任意のバッチサイズに対応しています。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `image` | 正規化プロセスが適用された結果の画像です。 | IMAGE |
