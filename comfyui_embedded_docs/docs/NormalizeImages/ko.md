# 이미지 정규화

이 노드는 입력 이미지의 각 픽셀에서 지정된 평균값을 뺀 다음, 그 결과를 지정된 표준 편차로 나누어 입력 이미지를 정규화합니다. 이는 픽셀 값을 표준화하고 이미지 데이터를 추가 처리에 대비하기 위한 일반적인 전처리 단계입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 정규화할 입력 이미지입니다. | IMAGE | 필수 | - |
| `mean` | 정규화에 사용할 평균값입니다(기본값: 0.5). | FLOAT | 선택 | 0.0 - 1.0 |
| `std` | 정규화에 사용할 표준 편차입니다(기본값: 0.5). | FLOAT | 선택 | 0.001 - 1.0 |

참고: 정규화는 전체 이미지 배치에 한 번에 적용되며, 모든 배치 크기가 지원됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 정규화 과정이 적용된 후의 결과 이미지입니다. | IMAGE |
