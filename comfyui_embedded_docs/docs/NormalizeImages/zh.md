# 规格化图像

此节点通过从每个像素中减去指定的均值，然后将结果除以指定的标准差来对输入图像进行归一化处理。这是标准化像素值并为后续处理准备图像数据的一种常见预处理步骤。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 要归一化的输入图像。 | IMAGE | 是 | - |
| `mean` | 归一化的均值（默认值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `std` | 归一化的标准差（默认值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

注意：归一化将一次性应用于整个图像批次，支持任意批次大小。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `image` | 应用归一化处理后得到的图像。 | IMAGE |
