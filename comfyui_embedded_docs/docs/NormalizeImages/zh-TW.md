# 標準化圖片

此節點透過對每個像素減去指定的平均值，再除以指定的標準差，來對輸入圖像進行歸一化。這是標準化像素值並為進一步處理準備圖像數據的常見預處理步驟。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 要歸一化的輸入圖像。 | IMAGE | 是 | - |
| `mean` | 歸一化的平均值（預設值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `std` | 歸一化的標準差（預設值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

注意：歸一化會一次性套用至整個圖像批次，且支援任何批次大小。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
| --- | --- | --- |
| `image` | 經歸一化處理後得到的最終圖像。 | IMAGE |
