# 標準化圖片

此節點會根據指定的平均值與標準差調整輸入影像的像素值，以正規化其色彩。每個像素會先減去平均值，再除以標準差；這是在其他處理之前標準化影像資料的常見步驟。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要正規化的輸入影像。 | IMAGE | 是 | - |
| `平均值` | 正規化用的平均值（預設：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `標準差` | 正規化用的標準差（預設：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

`mean` 與 `std` 參數控制套用於輸入影像的正規化。這兩個參數的預設值皆為 0.5。

注意：如果輸入影像具有 alpha（透明度）通道，該通道不會被正規化。它會維持不變並複製到輸出，因為 alpha 儲存的是透明度而非色彩。

注意：此節點可處理任意批次大小，因此可一次處理多張影像。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `image` | 套用正規化處理後產生的影像。像素值會使用指定的平均值與標準差進行調整，且 alpha 通道（若存在）會被保留。 | IMAGE |
