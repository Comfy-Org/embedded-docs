# Нормализовать изображения

Этот узел нормализует цвета входного изображения, корректируя значения его пикселей на основе заданного среднего значения и стандартного отклонения. Из каждого пикселя вычитается среднее значение, а затем результат делится на стандартное отклонение — это распространённый шаг для стандартизации данных изображения перед другой обработкой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для нормализации. | IMAGE | Да | - |
| `среднее` | Среднее значение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.0 - 1.0 |
| `стандартное отклонение` | Стандартное отклонение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.001 - 1.0 |

Параметры `mean` и `std` управляют нормализацией, применяемой к входному изображению. Значение по умолчанию для обоих параметров — 0.5.

Примечание: Если входное изображение имеет альфа-канал (канал прозрачности), этот канал не нормализуется. Он копируется в выходные данные без изменений, поскольку альфа-канал хранит прозрачность, а не цвет.

Примечание: Узел работает с любым размером пакета, поэтому можно обрабатывать несколько изображений одновременно.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Результирующее изображение после применения процесса нормализации. Значения пикселей корректируются с использованием указанных среднего значения и стандартного отклонения, а альфа-канал (при наличии) сохраняется. | IMAGE |
