# Нормализовать изображения

Этот узел корректирует значения пикселей входного изображения с помощью математического процесса нормализации. Он вычитает заданное среднее значение из каждого пикселя, а затем делит результат на заданное стандартное отклонение. Это распространённый этап предварительной обработки для подготовки данных изображения для других моделей машинного обучения.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение для нормализации. | IMAGE | Да | - |
| `среднее` | Среднее значение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.0 - 1.0 |
| `стандартное отклонение` | Стандартное отклонение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.001 - 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Результирующее изображение после применения процесса нормализации. | IMAGE |
