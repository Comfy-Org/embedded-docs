# Нормализовать изображения

Этот узел нормализует входное изображение, вычитая заданное среднее значение из каждого пикселя и затем деля результат на заданное стандартное отклонение. Это распространённый этап предварительной обработки для стандартизации значений пикселей и подготовки данных изображения к дальнейшей обработке.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение, которое необходимо нормализовать. | IMAGE | Да | - |
| `mean` | Среднее значение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.0 - 1.0 |
| `std` | Стандартное отклонение для нормализации (по умолчанию: 0.5). | FLOAT | Нет | 0.001 - 1.0 |

Примечание: нормализация применяется ко всему пакету изображений сразу, поддерживается любой размер пакета.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Результирующее изображение после применения процесса нормализации. | IMAGE |
