# 3Dファイルを作成（スプラットから）

SplatToFile3D は、ガウシアンスプラットを File3D オブジェクトに変換し、Save または Preview 3D ノードで使用できるようにします。出力ファイル形式を選択できます。このノードはバッチごとに1アイテムのみをサポートします。複数のアイテムを受け取った場合は、最初のアイテムを使用し、警告をログに記録します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `splat` | ファイルにシリアライズするガウシアンスプラットデータ。バッチごとに1アイテムのみサポートされます。複数のアイテムが指定された場合は、最初のアイテムのみが使用されます。 | SPLAT | はい | - |
| `format` | 3Dファイルの出力ファイル形式。ply: 完全な球面調和関数を持つ標準の3Dガウシアンスプラット。ksplat: mkkellogg SplatBuffer（レベル0、非圧縮）、ベースカラーのみ。spz: Niantic gzip圧縮（約10倍小さい）、ベースカラーのみ（デフォルト: "ply"） | COMBO | はい | `"ply"`<br>`"ksplat"`<br>`"spz"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 選択された形式でシリアライズされたガウシアンスプラットデータを含むFile3Dオブジェクト。保存またはプレビューする準備ができています。 | FILE3D |
