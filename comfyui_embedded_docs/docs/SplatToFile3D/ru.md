# Создать 3D-файл (из Splat)

Узел SplatToFile3D преобразует гауссов сплат в объект File3D, который можно использовать с узлами Save или Preview 3D. Он поддерживает только один элемент в пакете и позволяет выбирать различные форматы выходных файлов для экспортируемых 3D-данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `splat` | Данные гауссова сплата для сериализации в файл | SPLAT | Да | - |
| `формат` | Формат выходного 3D-файла. ply: стандартный 3D Gaussian Splat с полными сферическими гармониками. ksplat: mkkellogg SplatBuffer (уровень 0, без сжатия), только базовый цвет. spz: сжатый gzip Niantic (примерно в 10 раз меньше), только базовый цвет (по умолчанию: "ply") | COMBO | Да | "ply"<br>"ksplat"<br>"spz" |

Примечание: этот узел поддерживает только один элемент в пакете. Если входной сплат содержит более одного элемента в пакете, узел выводит предупреждение и использует первый элемент. Если указан неподдерживаемый формат, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `3D-модель` | Объект File3D, содержащий сериализованные данные гауссова сплата в выбранном формате, готовый к сохранению или предпросмотру | FILE3D |
