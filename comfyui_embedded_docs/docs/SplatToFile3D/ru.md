# Создать 3D-файл (из Splat)

SplatToFile3D преобразует гауссов сплат в объект File3D, который можно использовать с узлами Save или Preview 3D. Вы можете выбрать формат выходного файла. Узел поддерживает только один элемент на батч; если он получает более одного элемента, он использует первый и записывает предупреждение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `splat` | Данные гауссова сплата для сериализации в файл. Поддерживается только один элемент на батч. Если предоставлено более одного элемента, используется только первый. | SPLAT | Да | - |
| `format` | Формат выходного файла для 3D-файла. ply: стандартный 3D Gaussian Splat с полными сферическими гармониками. ksplat: mkkellogg SplatBuffer (уровень 0, без сжатия), только базовый цвет. spz: сжатый Niantic gzip (~в 10 раз меньше), только базовый цвет (по умолчанию: "ply") | COMBO | Да | `"ply"`<br>`"ksplat"`<br>`"spz"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Объект File3D, содержащий сериализованные данные гауссова сплата в выбранном формате, готовый для сохранения или предпросмотра | FILE3D |
