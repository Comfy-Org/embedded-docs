# إنشاء ملف ثلاثي الأبعاد (من Splat)

```markdown
يحوّل العقدة SplatToFile3D بيانات السبلات الغاوسية إلى كائن File3D يمكن استخدامه مع عقد Save أو Preview ثلاثية الأبعاد. يمكنك اختيار تنسيق ملف الإخراج. يدعم العقدة عنصرًا واحدًا فقط لكل دفعة؛ إذا استقبل أكثر من عنصر، فإنه يستخدم العنصر الأول ويُسجّل تحذيرًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `splat` | بيانات السبلات الغاوسية المطلوب تحويلها إلى ملف. يُدعم عنصر واحد فقط لكل دفعة. إذا تم توفير أكثر من عنصر، يُستخدم العنصر الأول فقط. | SPLAT | نعم | - |
| `format` | تنسيق ملف الإخراج للملف ثلاثي الأبعاد. ply: سبلات غاوسي ثلاثي الأبعاد قياسي مع توافقيات كروية كاملة. ksplat: مخزن سبلات mkkellogg (المستوى 0، غير مضغوط)، اللون الأساسي فقط. spz: ملف Niantic مضغوط بـ gzip (أصغر بحوالي 10 مرات)، اللون الأساسي فقط (الافتراضي: `"ply"`) | COMBO | نعم | `"ply"`<br>`"ksplat"`<br>`"spz"` |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_3d` | كائن File3D يحتوي على بيانات السبلات الغاوسية المسلسلة بالتنسيق المحدد، جاهز للحفظ أو المعاينة | FILE3D |
```
