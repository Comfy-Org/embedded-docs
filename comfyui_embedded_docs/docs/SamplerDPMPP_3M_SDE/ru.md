# Сэмплер DPMPP_3M_SDE

Узел SamplerDPMPP_3M_SDE создает сэмплер DPM++ 3M SDE для использования в процессе сэмплирования. Этот сэмплер использует многошаговый метод стохастических дифференциальных уравнений третьего порядка с настраиваемыми параметрами шума. Узел позволяет выбрать, выполняются ли вычисления шума на GPU или CPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет стохастичностью процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `устройство_шума` | Выбирает устройство для вычислений шума: GPU или CPU (по умолчанию: "gpu") | COMBO | Да | "gpu"<br>"cpu" |

Примечание: все три входа являются расширенными параметрами.

Когда `noise_device` имеет значение "cpu", создается стандартный сэмплер `dpmpp_3m_sde`; когда значение "gpu" — GPU-ускоренный сэмплер `dpmpp_3m_sde_gpu`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера для использования в рабочих процессах сэмплирования | SAMPLER |
