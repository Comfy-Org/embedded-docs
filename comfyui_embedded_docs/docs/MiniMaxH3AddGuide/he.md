# MiniMaxH3AddGuide

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | ה-conditioning שאליו מצורף פריים המפתח המנחה. | CONDITIONING | כן | - |
| `vae` | VAE של וידאו, נדרש כאשר מחוברת תמונה. | VAE | לא | - |
| `audio_vae` | VAE של אודיו, נדרש כאשר מחובר אודיו. | VAE | לא | - |
| `latent` | ה-latent של אודיו-וידאו MiniMax H3 שמגדיר את סרטון היעד. חייב להיות MiniMax H3 AV latent (מקונן, עם שני טנסורים 5D, כאשר לטנסור הווידאו יש 24 ערוצים). | LATENT | כן | - |
| `image` | תמונה או פריימים של וידאו לעגינה. אצוות מרובות-פריימים מעוגנות כקליפ ונחתכות לאורכי הקליפ התקפים של המודל: 5, 22, 39... (17k + 5) פריימים. אצוות קצרות מ-5 פריימים משתמשות רק בתמונה הראשונה. | IMAGE | לא | - |
| `audio` | פס קול לעגינה החל מאותו אינדקס פריים, נחתך למשך הזמן שנותר של הווידאו. | AUDIO | לא | - |
| `frame_idx` | אינדקס הפריים שעליו לעגן את התמונה או את הפריים הראשון של הקליפ. ערכים שליליים נספרים מסוף הווידאו. (ברירת מחדל: 0) | INT | כן | -9999 עד 9999 |

**אילוצים:**
- יש לספק לפחות אחד מבין `image` או `audio`; אחרת הצומת מעלה שגיאה.
- `vae` נדרש כאשר `image` מחובר.
- `audio_vae` נדרש כאשר `audio` מחובר.
- אצוות `image` עם פחות מ-5 פריימים משתמשות רק בתמונה הראשונה; אצוות של 5 פריימים או יותר נחתכות לאורך קליפ תקף (5, 22, 39 וכו').
- `frame_idx` חייב למקם את פריים ההנחיה בתוך טווח הפריימים של הווידאו, וקליפ מרובה-פריימים חייב להיכנס כולו לווידאו; אחרת הצומת מעלה שגיאה.
- כאשר אודיו מחובר, אינדקס הפריים אינו יכול להיות מעבר לסוף רצועת האודיו של הווידאו.
