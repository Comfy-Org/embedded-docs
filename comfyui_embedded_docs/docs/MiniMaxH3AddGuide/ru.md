# Добавить направляющую для MiniMax H3

Этот узел закрепляет изображение, короткий клип, аудио или клип со звуковой дорожкой на любом кадре видео MiniMax H3. Он добавляет опорный ключевой кадр в кондиционирование по выбранному индексу кадра, и вы можете соединять в цепочку несколько таких узлов, чтобы закрепить несколько кадров в одном видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `позитивный` | Кондиционирование, к которому прикрепляется опорный ключевой кадр. | CONDITIONING | Да | - |
| `vae` | Видео VAE, необходим, когда подключено изображение. | VAE | Нет | - |
| `audio_vae` | Аудио VAE, необходим, когда подключено аудио. | VAE | Нет | - |
| `латентный` | Аудио-видео латент MiniMax H3, который определяет целевое видео. Должен быть AV-латентом MiniMax H3 (вложенным, с двумя 5D-тензорами, причём видео-тензор имеет 24 канала). | LATENT | Да | - |
| `image` | Изображение или видеокадры для закрепления. Многокадровые батчи закрепляются как клип и обрезаются до допустимых длин клипов модели: 5, 22, 39... (17k + 5) кадров. Батчи короче 5 кадров используют только первое изображение. | IMAGE | Нет | - |
| `audio` | Звуковая дорожка для закрепления, начинающаяся с того же индекса кадра и обрезаемая до оставшейся длительности видео. | AUDIO | Нет | - |
| `frame_idx` | Индекс кадра, на котором закрепляется изображение или первый кадр клипа. Отрицательные значения отсчитываются от конца видео. (по умолчанию: 0) | INT | Да | -9999 до 9999 |

**Ограничения:**
- Должен быть предоставлен хотя бы один из параметров `image` или `audio`; иначе узел выдаёт ошибку.
- `vae` обязателен, когда подключён `image`.
- `audio_vae` обязателен, когда подключён `audio`.
- Батчи `image` с менее чем 5 кадрами используют только первое изображение; батчи из 5 или более кадров обрезаются до допустимой длины клипа (5, 22, 39 и т.д.).
- `frame_idx` должен размещать опорный кадр в пределах диапазона кадров видео, а многокадровый клип должен целиком помещаться в видео; иначе узел выдаёт ошибку.
- Когда подключено аудио, индекс кадра не должен выходить за конец аудиодорожки видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондиционирование с добавленным опорным ключевым кадром, содержащее итоговый индекс кадра и, если они предоставлены, закодированные латенты изображения или аудио. | CONDITIONING |
