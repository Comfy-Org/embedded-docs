# MiniMaxH3AddGuide

Этот узел привязывает изображение, короткий клип, аудио или клип со звуковой дорожкой к любому выбранному кадру видео MiniMax H3. Он добавляет направляющий ключевой кадр в кондишининг на указанном индексе кадра, и вы можете соединить несколько таких узлов, чтобы привязать несколько кадров в одном видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `позитивный` | Кондишининг, к которому прикрепляется направляющий ключевой кадр. | CONDITIONING | Да | - |
| `латентный` | Аудио-видео латентное представление MiniMax H3, определяющее целевое видео. Должно быть AV-латентным представлением MiniMax H3 (вложенным, с двумя 5D тензорами по 24 канала каждый). | LATENT | Да | - |
| `frame_idx` | Индекс кадра, в котором закрепить изображение или первый кадр клипа. Отрицательные значения отсчитываются от конца видео. (по умолчанию: 0) | INT | Да | -9999 до 9999 |
| `vae` | Видео VAE, требуется при подключении изображения. | VAE | Нет | - |
| `audio_vae` | Аудио VAE, требуется при подключении аудио. | VAE | Нет | - |
| `image` | Изображение или видеокадры для закрепления. Многокадровые пакеты закрепляются как клип и обрезаются до допустимых длин клипа модели: 5, 22, 39... (17k + 5) кадров. Пакеты короче 5 кадров используют только первое изображение. | IMAGE | Нет | - |
| `audio` | Звуковая дорожка для закрепления, начиная с того же индекса кадра, обрезанная до оставшейся длительности видео. | AUDIO | Нет | - |

**Ограничения:**
- Необходимо предоставить хотя бы одно из `image` или `audio`; в противном случае узел вызовет ошибку.
- `vae` обязательно при подключении `image`.
- `audio_vae` обязательно при подключении `audio`.
- Пакеты `image` с количеством кадров менее 5 используют только первое изображение; пакеты из 5 и более кадров обрезаются до допустимой длины клипа (5, 22, 39 и т.д.).
- `frame_idx` должен размещать направляющий кадр в пределах диапазона кадров видео, а многокадровый клип должен полностью помещаться в видео; в противном случае узел вызовет ошибку.
- При подключении аудио индекс кадра не должен выходить за конец аудиодорожки видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондишининг с добавленным направляющим ключевым кадром, содержащий вычисленный индекс кадра и, при наличии, закодированные латентные представления изображения или аудио. | CONDITIONING |
