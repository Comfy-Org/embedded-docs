# 為 MiniMax H3 新增引導

此節點可將影像、短片段、音訊，或帶有音軌的片段錨定在 MiniMax H3 影片的任意影格上。它會依所選的影格索引，將引導關鍵影格加入 conditioning，且您可以串接數個此類節點，以在同一部影片中錨定數個影格。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 要附加引導關鍵影格的 conditioning。 | CONDITIONING | 是 | - |
| `vae` | 影片 VAE，連接影像時需要。 | VAE | 否 | - |
| `audio_vae` | 音訊 VAE，連接音訊時需要。 | VAE | 否 | - |
| `潛在` | 定義目標影片的 MiniMax H3 音訊-視訊 latent。必須是 MiniMax H3 AV latent（巢狀，包含兩個 5D 張量，其中影片張量具有 24 個通道）。 | LATENT | 是 | - |
| `image` | 要錨定的影像或影片影格。多影格批次會作為片段錨定，並裁剪至模型的有效片段長度：5、22、39...（17k + 5）個影格。少於 5 個影格的批次僅使用第一張影像。 | IMAGE | 否 | - |
| `audio` | 要從相同影格索引開始錨定的音軌，會裁剪至影片的剩餘時長。 | AUDIO | 否 | - |
| `frame_idx` | 要錨定影像或片段第一影格的影格索引。負值會從影片結尾開始計算。（預設值：0） | INT | 是 | -9999 至 9999 |

**限制條件：**
- 至少必須提供 `image` 或 `audio` 其中之一；否則節點會引發錯誤。
- 連接 `image` 時，必須提供 `vae`。
- 連接 `audio` 時，必須提供 `audio_vae`。
- 少於 5 個影格的 `image` 批次僅使用第一張影像；5 個或更多影格的批次會裁剪為有效片段長度（5、22、39 等）。
- `frame_idx` 必須將引導置於影片的影格範圍內，且多影格片段必須完全放入影片中；否則節點會引發錯誤。
- 連接音訊時，影格索引不得超過影片音軌的結尾。
