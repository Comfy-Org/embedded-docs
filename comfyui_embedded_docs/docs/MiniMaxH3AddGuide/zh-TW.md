# MiniMaxH3AddGuide

此節點將圖片、短片、音訊或帶有配樂的片段錨定在 MiniMax H3 影片的任意選定幀上。它會在指定的幀索引處為條件加入引導關鍵幀，而且您可以串接數個此類節點，以在同一部影片中錨定多個幀。

## 輸入
| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 引導關鍵幀所附加的條件。 | CONDITIONING | 是 | - |
| `latent` | 定義目標影片的 MiniMax H3 音訊-影片潛在變數。必須是 MiniMax H3 AV 潛在變數（巢狀結構，包含兩個各 24 通道的 5D 張量）。 | LATENT | 是 | - |
| `frame_idx` | 要將圖片或片段的第一個幀錨定所在的幀索引。負值會從影片結尾往回計算。（預設：0） | INT | 是 | -9999 至 9999 |
| `vae` | 影片 VAE，連接圖片時需要。 | VAE | 否 | - |
| `audio_vae` | 音訊 VAE，連接音訊時需要。 | VAE | 否 | - |
| `image` | 要錨定的圖片或影片幀。多幀批次會作為片段錨定，並裁剪至模型的有效片段長度：5、22、39...(17k + 5) 個幀。少於 5 個幀的批次只使用第一張圖片。 | IMAGE | 否 | - |
| `audio` | 要從相同幀索引開始錨定的配樂，並裁剪至影片的剩餘時間。 | AUDIO | 否 | - |

**限制：**
- 必須至少提供 `image` 或 `audio` 其中一項，否則節點會引發錯誤。
- 連接 `image` 時需要 `vae`。
- 連接 `audio` 時需要 `audio_vae`。
- 少於 5 個幀的 `image` 批次只使用第一張圖片；5 個或更多幀的批次會裁剪至有效的片段長度（5、22、39 等）。
- `frame_idx` 必須將引導放置在影片的幀範圍內，且多幀片段必須完整放入影片中，否則節點會引發錯誤。
- 連接音訊時，幀索引不得超出影片音訊軌的結尾。
