# Pika SFX

Этот узел генерирует звуковой эффект по текстовому описанию с помощью Pika. Опишите звук и его продолжительность, и узел вернёт аудиоклип.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Каким должен быть звуковой эффект. Не должен быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | от 1 до 4000 символов |
| `duration` | Длительность звукового эффекта в секундах. По умолчанию: 5.0. | FLOAT | Да | от 1.0 до 20.0 (шаг: 0.1) |
| `seed` | Сид для сэмплирования. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Сгенерированный звуковой эффект. | AUDIO |
