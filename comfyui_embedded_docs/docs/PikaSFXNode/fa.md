# Pika SFX

این گره با استفاده از Pika یک جلوه صوتی را از روی توضیح متنی تولید می‌کند. صدا و مدت‌زمان آن را توصیف کنید و گره یک قطعه صوتی برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | شرح جلوه صوتی مورد نظر. نباید خالی باشد. پیش‌فرض: `""` (رشته خالی). | STRING | بله | 1 تا 4000 کاراکتر |
| `duration` | مدت‌زمان جلوه صوتی بر حسب ثانیه. پیش‌فرض: 5.0. | FLOAT | بله | 1.0 تا 20.0 (گام: 0.1) |
| `seed` | مقدار seed برای نمونه‌گیری. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `AUDIO` | جلوه صوتی تولیدشده. | AUDIO |
