# Pika SFX

צומת זה יוצר אפקט קול מתיאור טקסטואלי באמצעות Pika. תארו את הקול ואת משך הזמן שהוא אמור להימשך, והצומת מחזיר קטע אודיו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה אמור להיות אפקט הקול. אין להשאיר ריק. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 1 עד 4000 תווים |
| `duration` | אורך אפקט הקול בשניות. ברירת מחדל: 5.0. | FLOAT | כן | 1.0 עד 20.0 (צעד: 0.1) |
| `seed` | Seed לדגימה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
