# TripoImageToModelNodeV2

הצומת Tripo: Image to Model ממיר תמונת ייחוס בודדת למודל תלת-ממדי באמצעות שירות image-to-model של Tripo. הוא מעלה את התמונה, שולח משימת יצירה, ממתין לסיום המשימה ומחזיר את קובץ התלת-ממד שנוצר יחד עם מזהה המשימה. זהו צומת API, ולכן הוא דורש מפתח Comfy API תקין.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הייחוס המשמשת ליצירת המודל התלת-ממדי. | IMAGE | כן | — |
| `model_version` | גרסת המודל שבה ישתמשו ליצירה. אם לא מוגדרת, הצומת נופל לברירת המחדל של Tripo, גרסה v3.1 (20260211). | COMBO | לא | רשימת גרסאות מודל של Tripo |
| `texture` | יצירת מפות טקסטורה. כיבוי מחזיר גאומטריה חשופה ומתעלם מ-`pbr` (ברירת מחדל: true). | BOOLEAN | לא | true<br>false |
| `pbr` | מפות חומר PBR (צבע בסיס, מטלי, חספוס, נורמל). דורש `texture` (ברירת מחדל: true). | BOOLEAN | לא | true<br>false |
| `model_seed` | ערך Seed המשמש לשלב יצירת הגאומטריה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `orientation` | הגדרת האוריינטציה המוחלת על המודל שנוצר (ברירת מחדל: DEFAULT). | COMBO | לא | אפשרויות אוריינטציה של Tripo, ברירת מחדל `DEFAULT` |
| `texture_seed` | ערך Seed המשמש לשלב יצירת הטקסטורה (ברירת מחדל: 42). | INT | לא | 0 עד 2147483647 |
| `texture_quality` | detailed = טקסטורות HD, extreme = טקסטורות 8K Ultra (ברירת מחדל: "standard"). | COMBO | לא | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | כיצד הטקסטורות מיושרות על הגאומטריה שנוצרה (ברירת מחדל: "original_image"). | COMBO | לא | "original_image"<br>"geometry" |
| `face_limit` | מספר הפאות המקסימלי. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי (כ-1.4M פאות ב-v3.x standard, 2M ב-detailed). Tripo מגביל בשקט: v2.5 ב-500,000, רשתות quad ב-150,000 (ברירת מחדל: -1). | INT | לא | -1 עד 2000000 |
| `quad` | פלט רשת quad. Tripo מספק רשתות quad כ-FBX, כך שהתוצאה מגיעה לפלט FBX ופלט GLB נשאר ריק (ברירת מחדל: false). | BOOLEAN | לא | true<br>false |
| `geometry_quality` | רמת האיכות של הגאומטריה שנוצרה (ברירת מחדל: "standard"). | COMBO | לא | "standard"<br>"detailed" |
| `smart_low_poly` | רשת low-poly עם טופולוגיה נקייה בסגנון עבודת יד (500-20,000 פאות, quad 500-10,000). מתאים ביותר לאובייקטים פשוטים; אובייקטים מורכבים עלולים להיכשל (ברירת מחדל: false). | BOOLEAN | לא | true<br>false |
| `auto_size` | מתאים את קנה המידה של מודלים עם טקסטורה לגודל המציאותי שלהם במטרים. Tripo שומר את הגודל כטרנספורם הסצנה של המודל וצורב אותו פנימה כאשר המודל מומר, מורכב עליו ריג או עובר retargeting; מתעלם ממנו כשאין טקסטורה (ברירת מחדל: true). | BOOLEAN | לא | true<br>false |

**הערות:**

- `image` הוא חובה; הצומת מעלה שגיאה אם לא סופקה תמונה.
- כאשר `smart_low_poly` מופעל ו-`face_limit` מוגדר לערך שאינו -1, המגבלה חייבת להיות בין 500 ל-20,000 עבור רשתות משולשים, או בין 500 ל-10,000 כאשר `quad` מופעל. ערכים אחרים מעלים שגיאה.
- כאשר `texture` מושבת, `pbr` נכפה לכבות ללא קשר להגדרה שלו, ול-`auto_size` אין השפעה.
- `face_limit` של -1 נשלח ל-Tripo בתור "no limit", ומאפשר לשירות לבחור באופן אדפטיבי.
- פורמט קובץ תלת-ממדי חדש שהצומת אינו יכול להחזיר (כל דבר שאינו GLB או FBX) גורם לשגיאה.
