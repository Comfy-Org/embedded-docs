# TripoImageToModelNodeV2

تقوم عقدة Tripo: Image to Model بتحويل صورة مرجعية واحدة إلى نموذج ثلاثي الأبعاد باستخدام خدمة الصورة إلى النموذج من Tripo. فهي ترفع الصورة، وترسل مهمة توليد، وتنتظر اكتمال المهمة، ثم تُعيد ملف النموذج ثلاثي الأبعاد الناتج مع معرّف المهمة. هذه عقدة API، لذا تتطلب مفتاح Comfy API صالحًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المرجعية المستخدمة لتوليد النموذج ثلاثي الأبعاد. | IMAGE | نعم | — |
| `إصدار النموذج` | إصدار النموذج المستخدم للتوليد. إذا تُرك دون تعيين، ترجع العقدة إلى إصدار Tripo v3.1 (20260211). | COMBO | لا | قائمة إصدارات نموذج Tripo |
| `النسيج` | توليد خرائط النسيج. عند الإيقاف يُرجع الهندسة المجردة ويتجاهل `pbr` (الافتراضي: true). | BOOLEAN | لا | true<br>false |
| `pbr` | خرائط مادة PBR (اللون الأساسي، المعدني، الخشونة، normal). يتطلب `texture` (الافتراضي: true). | BOOLEAN | لا | true<br>false |
| `بذرة النموذج` | البذرة المستخدمة في خطوة توليد الهندسة (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `الاتجاه` | إعداد الاتجاه المطبق على النموذج المولّد (الافتراضي: DEFAULT). | COMBO | لا | خيارات اتجاه Tripo، الافتراضي `DEFAULT` |
| `بذرة النسيج` | البذرة المستخدمة في خطوة توليد النسيج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `جودة النسيج` | detailed = نُسج HD، extreme = نُسج 8K فائقة (الافتراضي: "standard"). | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `محاذاة النسيج` | كيفية محاذاة النُسج على الهندسة المولّدة (الافتراضي: "original_image"). | COMBO | لا | "original_image"<br>"geometry" |
| `حد الأوجه` | الحد الأقصى لعدد الأوجه. القيمة -1 تدع Tripo تختار تكيفيًا (حوالي 1.4M وجه على v3.x standard، و2M عند detailed). تقوم Tripo بتقييد القيم بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000 (الافتراضي: -1). | INT | لا | -1 إلى 2000000 |
| `رباعي` | إخراج شبكة رباعية. تُسلّم Tripo الشبكات الرباعية بصيغة FBX، لذا يصل الناتج على مخرج FBX ويبقى مخرج GLB فارغًا (الافتراضي: false). | BOOLEAN | لا | true<br>false |
| `جودة الهندسة` | مستوى جودة الهندسة المولّدة (الافتراضي: "standard"). | COMBO | لا | "standard"<br>"detailed" |
| `متعدد الأضلاع منخفض ذكي` | شبكة منخفضة المضلعات بطوبولوجيا نظيفة بأسلوب مصنوع يدويًا (500-20,000 وجه، ورباعي 500-10,000). الأفضل للمواضيع البسيطة؛ وقد تفشل الموضوعات المعقدة (الافتراضي: false). | BOOLEAN | لا | true<br>false |
| `الحجم التلقائي` | تحجيم النماذج ذات النسيج إلى حجمها الواقعي بالأمتار. تخزّن Tripo الحجم كتحويل للمشهد في النموذج وتدمجه عند تحويل النموذج أو تجهيزه بهيكل أو إعادة استهدافه؛ ويُتجاهل عند عدم وجود نسيج (الافتراضي: true). | BOOLEAN | لا | true<br>false |

**ملاحظات:**

- `image` مطلوب؛ وترفع العقدة خطأً إذا لم يتم توفير صورة.
- عندما يكون `smart_low_poly` مُمكّنًا وتم تعيين `face_limit` إلى قيمة غير -1، يجب أن يكون الحد بين 500 و20,000 للشبكات المثلثية، أو بين 500 و10,000 عندما يكون `quad` مُمكّنًا. القيم الأخرى ترفع خطأً.
- عند تعطيل `texture`، يتم إجبار `pbr` على الإيقاف بغض النظر عن إعداده، ولا يكون لـ `auto_size` أي تأثير.
- يتم إرسال `face_limit` بالقيمة -1 إلى Tripo كـ "بلا حد"، ما يتيح للخدمة الاختيار تكيفيًا.
- أي صيغة ملف ثلاثي الأبعاد جديدة لا تستطيع العقدة إرجاعها (أي شيء غير GLB أو FBX) تسبب خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model task_id` | معرّف مهمة Tripo لوظيفة التوليد. | MODEL_TASK_ID |
| `GLB` | النموذج المولّد كملف GLB. يكون فارغًا عند تمكين `quad`. | FILE3DGLB |
| `FBX` | النموذج المولّد كملف FBX. يُملأ فقط عند تمكين `quad`. | FILE3DFBX |
