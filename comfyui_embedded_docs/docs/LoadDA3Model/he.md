# LoadDA3Model

צומת **Load Depth Anything 3** טוען מודל Depth Anything 3 מקובץ, ומכין אותו למשימות הערכת עומק. ניתן לבחור את קובץ המודל, ובאופן אופציונלי לבחור את הדיוק המספרי (סוג הנתונים) עבור משקולות המודל.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_name` | שם קובץ המודל Depth Anything 3 לטעינה. | STRING | כן | רשימת קבצי מודל זמינים בתיקיית `geometry_estimation` |
| `weight_dtype` | הדיוק המספרי (סוג הנתונים) עבור משקולות המודל. "default" משתמש בדיוק המקורי של המודל, "fp16" משתמש בנקודה צפה של 16 סיביות, "bf16" משתמש ב-bfloat16, ו-"fp32" משתמש בנקודה צפה של 32 סיביות. (ברירת מחדל: "default") | STRING | לא | `"default"`<br>`"fp16"`<br>`"bf16"`<br>`"fp32"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `DA3_MODEL` | מודל Depth Anything 3 שנטען, מוכן לשימוש בתהליכי עבודה של הערכת עומק. | DA3_MODEL |
