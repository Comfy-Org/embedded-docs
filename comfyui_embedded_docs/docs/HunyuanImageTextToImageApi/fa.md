# Tencent HY Image: Text to Image

گره Tencent HY Image: Text to Image با مدل Hunyuan Image شرکت Tencent یک تصویر را از یک توصیف متنی تولید می‌کند. پرامپت به API فرستاده می‌شود؛ API آن را پیش از رندر بازنویسی و گسترش می‌دهد و تصویر نهایی به‌صورت یک دسته تصویر بازگردانده می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید استفاده می‌شود. مدل انتخاب‌شده تعیین می‌کند چه ورودی‌های اضافی نمایش داده شوند. | DYNAMIC_COMBO | بله | `"hy-image-3.5-preview"` |

### ورودی‌های hy-image-3.5-preview

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | تصویری را که باید تولید شود توصیف می‌کند. مدل آن را پیش از رندر بازنویسی و گسترش می‌دهد. نباید خالی باشد (پیش‌فرض: خالی). | STRING | بله | هر متنی |
| `aspect_ratio` | نسبت ابعاد خروجی. `"auto"` باعث می‌شود مدل نسبت را از پرامپت انتخاب کند و در 4K در دسترس نیست. وقتی `resolution` برابر `"custom"` باشد نادیده گرفته می‌شود. | COMBO | بله | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"` (پیش‌فرض: `"auto"`) |
| `resolution` | مساحت پیکسلی تصویر: 1K حدوداً 1024x1024، 2K حدوداً 2048x2048 و 4K حدوداً 4096x4096 است. هر چیزی بالاتر از 2K در 2K رندر و توسط مدل بزرگ‌نمایی می‌شود. برای استفاده از `width` و `height` به‌جای یک مساحت از پیش تعیین‌شده، روی `"custom"` تنظیم کنید. | COMBO | بله | `"1K"`<br>`"2K"`<br>`"4K"`<br>`"custom"` (پیش‌فرض: `"2K"`) |
| `width` | عرض تصویر بر حسب پیکسل. فقط زمانی استفاده می‌شود که `resolution` برابر `"custom"` باشد. | INT | بله | 256-8192، با گام‌های 16 (پیش‌فرض: 2048) |
| `height` | ارتفاع تصویر بر حسب پیکسل. فقط زمانی استفاده می‌شود که `resolution` برابر `"custom"` باشد. | INT | بله | 256-8192، با گام‌های 16 (پیش‌فرض: 2048) |
| `seed` | بذر استفاده‌شده برای تولید. نتایج حتی با بذر یکسان نیز بین اجراها متفاوت می‌ماند. | INT | بله | 0-2147483647 (پیش‌فرض: 42) |
| `watermark` | اینکه آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود یا نه. این یک پارامتر پیشرفته است. | BOOLEAN | خیر | true<br>false (پیش‌فرض: false) |

`prompt` نباید خالی باشد. با resolution برابر `"custom"`، `width` و `height` باید هر دو مضرب 16 باشند و حاصل‌ضرب آن‌ها نباید از محدودیت مساحت 4096 x 4096 پیکسل (حدود 16.7 مگاپیکسل) فراتر رود؛ هر نسبت ابعادی کار می‌کند، هرچند فراتر از حدوداً 6:1 مدل شروع به تکرار سوژه می‌کند. نسبت ابعاد `"auto"` نیاز دارد که مدل اندازه‌ای انتخاب کند، بنابراین فقط در محدوده مساحت 2K کار می‌کند: در 4K، یک نسبت ابعاد مشخص انتخاب کنید یا از `"custom"` استفاده کنید.
