# Tencent HY Image: Text to Image

Узел Tencent HY Image: Text to Image генерирует изображение по текстовому описанию с помощью модели Hunyuan Image от Tencent. Промпт отправляется в API, который переписывает и расширяет его перед рендерингом, а готовое изображение возвращается в виде пакета изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, используемая для генерации. Выбранная модель определяет, какие дополнительные входы отображаются. | DYNAMIC_COMBO | Да | `"hy-image-3.5-preview"` |

### Входы hy-image-3.5-preview

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описывает изображение для генерации. Модель переписывает и расширяет его перед рендерингом. Не должен быть пустым (по умолчанию: пусто). | STRING | Да | Любой текст |
| `aspect_ratio` | Соотношение сторон выходного изображения. `"auto"` позволяет модели выбрать соотношение из промпта и недоступно при 4K. Игнорируется, когда `resolution` имеет значение `"custom"`. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"`<br>`"9:21"` (по умолчанию: `"auto"`) |
| `resolution` | Пиксельная область изображения: 1K — это примерно 1024x1024, 2K — примерно 2048x2048, 4K — примерно 4096x4096. Всё, что выше 2K, рендерится в 2K и масштабируется моделью. Установите `"custom"`, чтобы использовать `width` и `height` вместо предустановленной области. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"`<br>`"custom"` (по умолчанию: `"2K"`) |
| `width` | Ширина изображения в пикселях. Используется только когда `resolution` имеет значение `"custom"`. | INT | Да | 256-8192, шаг 16 (по умолчанию: 2048) |
| `height` | Высота изображения в пикселях. Используется только когда `resolution` имеет значение `"custom"`. | INT | Да | 256-8192, шаг 16 (по умолчанию: 2048) |
| `seed` | Сид, используемый для генерации. Результаты всё равно различаются между запусками с одним и тем же сидом. | INT | Да | 0-2147483647 (по умолчанию: 42) |
| `watermark` | Добавлять ли к результату водяной знак, созданный ИИ. Это расширенный параметр. | BOOLEAN | Нет | true<br>false (по умолчанию: false) |

`prompt` не должен быть пустым. При разрешении `"custom"` `width` и `height` должны быть кратны 16, а их произведение не должно превышать ограничение площади 4096 x 4096 пикселей (около 16,7 мегапикселя); подходит любое соотношение сторон, хотя при превышении примерно 6:1 модель начинает повторять объект. Для соотношения сторон `"auto"` модели нужно выбрать размер, поэтому оно работает только в пределах ограничения площади 2K: при 4K выберите явное соотношение сторон или используйте `"custom"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение. | IMAGE |
