# SUPIRApply

SUPIRApplyノードは、拡散モデルにSUPIRモデルパッチを適用します。このパッチを使用してモデルの動作を変更し、サンプリングプロセス中に入力画像からのガイダンスを組み込めるようにします。また、このノードは時間経過に伴うガイダンスの強さを調整するための制御を提供し、元の入力への忠実性を維持するためのオプション機能も含まれています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | SUPIRパッチが適用されるベース拡散モデル。 | MODEL | はい | - |
| `model_patch` | モデルの変更に必要な重みと設定を含むSUPIRモデルパッチ。 | MODELPATCH | はい | - |
| `vae` | 入力画像を潜在表現にエンコードするために使用されるVAE（Variational Autoencoder）。 | VAE | はい | - |
| `image` | 生成プロセスのガイドに使用される入力画像。最初の3つのカラーチャンネル（RGB）のみが使用されます。 | IMAGE | はい | - |
| `strength_start` | サンプリング開始時（高シグマ）の制御強度。画像ガイダンスの影響はこの値で始まります。（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 10.0 |
| `strength_end` | サンプリング終了時（低シグマ）の制御強度。開始値から線形に補間されます。画像ガイダンスの影響はこの値で終了します。（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 10.0 |
| `restore_cfg` | ノイズ除去出力を入力潜在変数に引き寄せます。値が大きいほど入力への忠実性が高くなります。0で無効にします。（デフォルト: 4.0） | FLOAT | いいえ | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | `restore_cfg`が無効になるシグマ閾値。（デフォルト: 0.05） | FLOAT | いいえ | 0.0 - 1.0 |

*注：* `image` 入力はRGBチャンネルのみを抽出して処理されます。アルファチャンネル付きの画像が指定された場合、アルファチャンネルは無視されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | SUPIRパッチが適用され、追加のポストCFG関数が設定された拡散モデル。 | MODEL |
