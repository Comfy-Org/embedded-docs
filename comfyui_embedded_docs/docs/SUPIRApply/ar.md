# SUPIRApply

تطبّق عقدة SUPIRApply رقعة نموذج SUPIR على نموذج الانتشار. تستخدم الرقعة لتعديل سلوك النموذج، مما يتيح له دمج التوجيه من صورة الإدخال أثناء عملية أخذ العينات. توفر العقدة أيضًا أدوات تحكم لضبط قوة هذا التوجيه بمرور الوقت، وتتضمن ميزة اختيارية للمساعدة في الحفاظ على المطابقة للمدخل الأصلي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج الانتشار الأساسي الذي ستُطبَّق عليه رقعة SUPIR. | MODEL | نعم | - |
| `model_patch` | رقعة نموذج SUPIR التي تحتوي على الأوزان والإعدادات لتعديل النموذج. | MODELPATCH | نعم | - |
| `vae` | المشفّر التلقائي المتغيّر (VAE) المستخدم لتشفير صورة الإدخال إلى تمثيل كامن. | VAE | نعم | - |
| `image` | صورة الإدخال المستخدمة لتوجيه عملية التوليد. يتم استخدام قنوات الألوان الثلاث الأولى فقط (RGB). | IMAGE | نعم | - |
| `strength_start` | قوة التحكم في بداية أخذ العينات (سيغما عالية). يبدأ تأثير توجيه الصورة عند هذه القيمة. (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 10.0 |
| `strength_end` | قوة التحكم في نهاية أخذ العينات (سيغما منخفضة). يتم الاستيفاء خطيًا من البداية. ينتهي تأثير توجيه الصورة عند هذه القيمة. (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 10.0 |
| `restore_cfg` | يسحب المخرجات بعد إزالة الضوضاء نحو الكامن المُدخل. القيم الأعلى تعني التزامًا أقوى بالإدخال. استخدم 0 لتعطيل هذه الميزة. (الافتراضي: 4.0) | FLOAT | لا | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | عتبة سيغما التي يتم عندها تعطيل `restore_cfg`. (الافتراضي: 0.05) | FLOAT | لا | 0.0 - 1.0 |

*ملاحظة:* يتم معالجة إدخال `image` لاستخراج قنوات RGB فقط. إذا تم توفير صورة تحتوي على قناة ألفا، فسيتم تجاهل قناة ألفا.
