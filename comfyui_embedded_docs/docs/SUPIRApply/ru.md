# SUPIRApply

Узел SUPIRApply применяет патч модели SUPIR к диффузионной модели. Он использует патч для изменения поведения модели, позволяя ей учитывать направляющее воздействие входного изображения в процессе сэмплирования. Узел также предоставляет средства управления для регулировки силы этого воздействия с течением времени и включает дополнительную функцию, помогающую сохранять соответствие исходному изображению.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая диффузионная модель, к которой будет применён патч SUPIR. | MODEL | Да | - |
| `model_patch` | Патч модели SUPIR, содержащий веса и конфигурацию для изменения модели. | MODELPATCH | Да | - |
| `vae` | VAE (вариационный автокодировщик), используемый для кодирования входного изображения в скрытое представление. | VAE | Да | - |
| `image` | Входное изображение, используемое для управления процессом генерации. Используются только первые три цветовых канала (RGB). | IMAGE | Да | - |
| `strength_start` | Сила управления в начале сэмплирования (высокая сигма). Влияние направляющего воздействия изображения начинается с этого значения. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |
| `strength_end` | Сила управления в конце сэмплирования (низкая сигма). Линейно интерполируется от начального значения. Влияние направляющего воздействия изображения заканчивается на этом значении. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |
| `restore_cfg` | Притягивает результат после шумоподавления к скрытому представлению входного изображения. Чем выше значение, тем сильнее соответствие входу. 0 — отключить. (по умолчанию: 4.0) | FLOAT | Да | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | Пороговое значение сигмы, ниже которого `restore_cfg` отключается. (по умолчанию: 0.05) | FLOAT | Да | 0.0 - 1.0 |

*Примечание:* входное изображение обрабатывается с извлечением только RGB-каналов. Если предоставлено изображение с альфа-каналом, альфа-канал игнорируется.

*Примечание:* `restore_cfg` действует только при значении больше 0. Установка значения 0 полностью отключает постобработку восстановления. При активном режиме коррекция применяется только пока текущее значение сигмы выше `restore_cfg_s_tmin`.

*Примечание:* этот узел помечен как экспериментальный в ComfyUI.
