# SUPIRApply

Узел SUPIRApply применяет патч модели SUPIR к диффузионной модели. Он использует патч для изменения поведения модели, позволяя учитывать управляющий сигнал от входного изображения в процессе сэмплирования. Узел также предоставляет элементы управления для регулировки силы этого управляющего сигнала во времени и включает опциональную функцию, помогающую сохранять точность соответствия исходному входу.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая диффузионная модель, к которой будет применён патч SUPIR. | MODEL | Да | - |
| `model_patch` | Патч модели SUPIR, содержащий веса и конфигурацию для модификации модели. | MODELPATCH | Да | - |
| `vae` | VAE (вариационный автоэнкодер), используемый для кодирования входного изображения в скрытое представление. | VAE | Да | - |
| `image` | Входное изображение, используемое для направления процесса генерации. Используются только первые три цветовых канала (RGB). | IMAGE | Да | - |
| `strength_start` | Сила управления в начале сэмплирования (высокая сигма). Влияние управляющего сигнала изображения начинается с этого значения. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 10.0 |
| `strength_end` | Сила управления в конце сэмплирования (низкая сигма). Линейно интерполируется от начального значения. Влияние управляющего сигнала изображения заканчивается на этом значении. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 10.0 |
| `restore_cfg` | Притягивает выход после удаления шума к входному скрытому представлению. Выше = сильнее точность соответствия входу. 0 для отключения. (по умолчанию: 4.0) | FLOAT | Нет | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | Порог сигмы, ниже которого restore_cfg отключается. (по умолчанию: 0.05) | FLOAT | Нет | 0.0 - 1.0 |

*Примечание:* Входное изображение `image` обрабатывается для извлечения только RGB-каналов. Если предоставлено изображение с альфа-каналом, альфа-канал игнорируется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Диффузионная модель с применённым патчем SUPIR и настроенными дополнительными функциями пост-CFG. | MODEL |
