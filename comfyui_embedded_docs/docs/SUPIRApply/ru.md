# SUPIRApply

Узел SUPIRApply применяет патч модели SUPIR к диффузионной модели. Он использует патч для изменения поведения модели, позволяя учитывать управляющее воздействие входного изображения в процессе сэмплирования. Узел также предоставляет элементы управления для изменения силы этого управляющего воздействия во времени и включает опциональную функцию, помогающую сохранять точность соответствия исходному входу.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая диффузионная модель, к которой будет применён патч SUPIR. | MODEL | Да | - |
| `model_patch` | Патч модели SUPIR, содержащий веса и конфигурацию для изменения модели. | MODEL_PATCH | Да | - |
| `vae` | VAE (вариационный автоэнкодер), используемый для кодирования входного изображения в латентное представление. | VAE | Да | - |
| `image` | Входное изображение, используемое для управления процессом генерации. Используются только первые три цветовых канала (RGB). | IMAGE | Да | - |
| `strength_start` | Сила управления в начале сэмплирования (высокая sigma). Влияние управления по изображению начинается с этого значения. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |
| `strength_end` | Сила управления в конце сэмплирования (низкая sigma). Линейно интерполируется от начального значения. Влияние управления по изображению заканчивается на этом значении. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |
| `restore_cfg` | Притягивает шумоподавлённый вывод к входному латенту. Чем выше значение, тем сильнее соответствие входу. 0 — отключено. (по умолчанию: 4.0, расширенная настройка) | FLOAT | Да | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | Порог sigma, ниже которого `restore_cfg` отключается. (по умолчанию: 0.05, расширенная настройка) | FLOAT | Да | 0.0 - 1.0 |

*Примечание:* Вход `image` обрабатывается так, чтобы извлечь только каналы RGB. Если предоставлено изображение с альфа-каналом, альфа-канал игнорируется.

*Примечание:* Если патч модели SUPIR предоставляет веса denoise-энкодера, входное изображение кодируется с использованием этих весов вместо обычного энкодера VAE.

*Примечание:* `restore_cfg` вступает в силу только при значении больше 0. Установка значения 0 полностью отключает постобработку восстановления. Когда параметр активен, коррекция применяется только пока текущее значение sigma выше `restore_cfg_s_tmin`.

*Примечание:* Этот узел помечен в ComfyUI как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Клонированная копия входной модели с применённым патчем SUPIR и настроенными дополнительными функциями post-CFG. | MODEL |
