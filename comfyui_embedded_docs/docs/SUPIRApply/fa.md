# SUPIRApply

گره SUPIRApply یک پچ مدل SUPIR را روی یک مدل دیفیوژن اعمال می‌کند. این گره با استفاده از پچ، رفتار مدل را تغییر می‌دهد و به آن امکان می‌دهد تا در طول فرآیند نمونه‌برداری، هدایت حاصل از یک تصویر ورودی را در خود ادغام کند. همچنین این گره کنترل‌هایی برای تنظیم شدت این هدایت در طول زمان ارائه می‌دهد و شامل یک ویژگی اختیاری برای کمک به حفظ وفاداری به ورودی اصلی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل دیفیوژن پایه که پچ SUPIR روی آن اعمال خواهد شد. | MODEL | بله | - |
| `model_patch` | پچ مدل SUPIR حاوی وزن‌ها و پیکربندی برای تغییر مدل. | MODELPATCH | بله | - |
| `vae` | خودرمزگذار متغیر (VAE) که برای رمزنگاری تصویر ورودی به یک نمایش نهان استفاده می‌شود. | VAE | بله | - |
| `image` | تصویر ورودی که برای هدایت فرآیند تولید استفاده می‌شود. فقط سه کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله | - |
| `strength_start` | شدت کنترل در شروع نمونه‌برداری (سیگمای بالا). تأثیر هدایت تصویر از این مقدار آغاز می‌شود. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 10.0 |
| `strength_end` | شدت کنترل در پایان نمونه‌برداری (سیگمای پایین). به‌صورت خطی از مقدار شروع درون‌یابی می‌شود. تأثیر هدایت تصویر در این مقدار پایان می‌یابد. (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 - 10.0 |
| `restore_cfg` | خروجی نویززدایی‌شده را به سمت نهان ورودی می‌کشد. مقدار بالاتر به معنای وفاداری بیشتر به ورودی است. برای غیرفعال‌سازی، 0 قرار دهید. (پیش‌فرض: 4.0) | FLOAT | خیر | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | آستانه سیگما که زیر آن `restore_cfg` غیرفعال می‌شود. (پیش‌فرض: 0.05) | FLOAT | خیر | 0.0 - 1.0 |

*توجه:* ورودی `image` پردازش می‌شود تا فقط کانال‌های RGB استخراج شوند. اگر تصویری با کانال آلفا ارائه شود، کانال آلفا نادیده گرفته می‌شود.
