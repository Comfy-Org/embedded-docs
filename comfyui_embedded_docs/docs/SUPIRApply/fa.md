# SUPIRApply

گره SUPIRApply یک وصله مدل SUPIR را روی یک مدل انتشار اعمال می‌کند. این وصله برای تغییر رفتار مدل استفاده می‌شود و به آن امکان می‌دهد تا در فرآیند نمونه‌برداری، از تصویر ورودی به‌عنوان راهنما بهره ببرد. این گره همچنین کنترل‌هایی برای تنظیم قدرت این راهنما در طول زمان فراهم می‌کند و شامل یک ویژگی اختیاری برای کمک به حفظ وفاداری به ورودی اصلی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل انتشار پایه‌ای که وصله SUPIR به آن اعمال می‌شود. | MODEL | بله | - |
| `model_patch` | وصله مدل SUPIR شامل وزن‌ها و پیکربندی برای اصلاح مدل. | MODELPATCH | بله | - |
| `vae` | وی‌ای‌ای (خودرمزنگار تغییراتی) که برای رمزگذاری تصویر ورودی به یک بازنمایی نهان استفاده می‌شود. | VAE | بله | - |
| `image` | تصویر ورودی که برای هدایت فرآیند تولید استفاده می‌شود. تنها سه کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله | - |
| `strength_start` | قدرت کنترل در آغاز نمونه‌برداری (سیگمای بالا). تأثیر راهنمای تصویر از این مقدار شروع می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |
| `strength_end` | قدرت کنترل در پایان نمونه‌برداری (سیگمای پایین). به‌صورت خطی از مقدار آغازین درون‌یابی می‌شود. تأثیر راهنمای تصویر تا این مقدار ادامه می‌یابد. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |
| `restore_cfg` | خروجی نویززدایی‌شده را به سمت نهان ورودی می‌کشد. مقدار بالاتر به معنای وفاداری قوی‌تر به ورودی است. 0 برای غیرفعال‌سازی. (پیش‌فرض: 4.0) | FLOAT | بله | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | آستانه سیگما که زیر آن `restore_cfg` غیرفعال می‌شود. (پیش‌فرض: 0.05) | FLOAT | بله | 0.0 - 1.0 |

*توجه:* ورودی `image` پردازش می‌شود تا تنها کانال‌های RGB استخراج شود. اگر تصویری با کانال آلفا ارائه شود، کانال آلفا نادیده گرفته می‌شود.

*توجه:* `restore_cfg` تنها زمانی اثر می‌کند که مقداری بزرگ‌تر از 0 تنظیم شود. تنظیم آن به 0 به‌طور کامل پردازش پسین بازیابی را غیرفعال می‌کند. وقتی فعال باشد، اصلاح فقط تا زمانی اعمال می‌شود که مقدار سیگمای فعلی بالاتر از `restore_cfg_s_tmin` باشد.

*توجه:* این گره در ComfyUI به‌عنوان آزمایشی علامت‌گذاری شده است.
