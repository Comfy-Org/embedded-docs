# SUPIRApply

گره SUPIRApply یک patch مدل SUPIR را روی یک مدل diffusion اعمال می‌کند. از این patch برای تغییر رفتار مدل استفاده می‌کند و به آن امکان می‌دهد تا در طول فرایند نمونه‌گیری از هدایت یک تصویر ورودی بهره ببرد. این گره همچنین کنترل‌هایی برای تنظیم قدرت این هدایت در طول زمان فراهم می‌کند و شامل یک ویژگی اختیاری برای کمک به حفظ وفاداری به ورودی اصلی است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل diffusion پایه که patch SUPIR روی آن اعمال می‌شود. | MODEL | بله | - |
| `model_patch` | patch مدل SUPIR شامل وزن‌ها و پیکربندی برای تغییر مدل. | MODEL_PATCH | بله | - |
| `vae` | VAE (خودرمزگذار متغیر) که برای رمزگذاری تصویر ورودی به یک بازنمایی latent استفاده می‌شود. | VAE | بله | - |
| `image` | تصویر ورودی که برای هدایت فرایند تولید استفاده می‌شود. فقط سه کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله | - |
| `strength_start` | قدرت کنترل در آغاز نمونه‌گیری (سیگما بالا). تأثیر هدایت تصویر از این مقدار شروع می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |
| `strength_end` | قدرت کنترل در پایان نمونه‌گیری (سیگما پایین). به‌صورت خطی از مقدار شروع درون‌یابی می‌شود. تأثیر هدایت تصویر در این مقدار پایان می‌یابد. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |
| `restore_cfg` | خروجی نویززدایی‌شده را به latent ورودی می‌کشد. مقدار بالاتر = وفاداری بیشتر به ورودی. 0 برای غیرفعال‌سازی. (پیش‌فرض: 4.0، تنظیم پیشرفته) | FLOAT | بله | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | آستانه سیگما که زیر آن `restore_cfg` غیرفعال می‌شود. (پیش‌فرض: 0.05، تنظیم پیشرفته) | FLOAT | بله | 0.0 - 1.0 |

*توجه:* ورودی `image` پردازش می‌شود تا فقط کانال‌های RGB استخراج شوند. اگر تصویری با کانال آلفا ارائه شود، کانال آلفا نادیده گرفته می‌شود.

*توجه:* اگر patch مدل SUPIR وزن‌های encoder نویززدایی را فراهم کند، تصویر ورودی با آن وزن‌ها به‌جای encoder معمول VAE رمزگذاری می‌شود.

*توجه:* `restore_cfg` فقط زمانی اثر می‌کند که روی مقداری بزرگ‌تر از 0 تنظیم شده باشد. تنظیم آن روی 0 پس‌پردازش بازیابی را کاملاً غیرفعال می‌کند. وقتی فعال باشد، اصلاح فقط تا زمانی اعمال می‌شود که مقدار سیگمای جاری بالاتر از `restore_cfg_s_tmin` باشد.

*توجه:* این گره در ComfyUI آزمایشی علامت‌گذاری شده است.
