# SUPIRApply

צומת SUPIRApply מחיל טלאי מודל SUPIR על מודל דיפוזיה. הוא משתמש בטלאי כדי לשנות את התנהגות המודל, ומאפשר לו לשלב הנחיה מתמונת קלט במהלך תהליך הדגימה. הצומת מספק גם פקדים להתאמת עוצמת ההנחיה לאורך זמן, וכולל תכונה אופציונלית שנועדה לסייע בשמירה על נאמנות לקלט המקורי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה הבסיסי שעליו יוחל טלאי SUPIR. | MODEL | כן | - |
| `model_patch` | טלאי מודל SUPIR המכיל את המשקלים והתצורה לשינוי המודל. | MODEL_PATCH | כן | - |
| `vae` | ה-VAE (מקודד אוטומטי וריאציוני) המשמש לקידוד תמונת הקלט לייצוג לטנטי. | VAE | כן | - |
| `image` | תמונת הקלט המשמשת להנחות את תהליך היצירה. נעשה שימוש רק בשלושת ערוצי הצבע הראשונים (RGB). | IMAGE | כן | - |
| `strength_start` | עוצמת הבקרה בתחילת הדגימה (סיגמא גבוהה). השפעת הנחיית התמונה מתחילה בערך זה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 10.0 |
| `strength_end` | עוצמת הבקרה בסוף הדגימה (סיגמא נמוכה). מבוצעת אינטרפולציה לינארית מהערך ההתחלתי. השפעת הנחיית התמונה מסתיימת בערך זה. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 10.0 |
| `restore_cfg` | מושך את הפלט המנוקה מרעש לעבר הלטנט של הקלט. ערך גבוה יותר = נאמנות חזקה יותר לקלט. 0 כדי להשבית. (ברירת מחדל: 4.0, הגדרה מתקדמת) | FLOAT | כן | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | סף סיגמא שמתחתיו `restore_cfg` מושבת. (ברירת מחדל: 0.05, הגדרה מתקדמת) | FLOAT | כן | 0.0 - 1.0 |

*הערה:* קלט `image` מעובד כך שיחולצו רק ערוצי ה-RGB. אם מסופקת תמונה עם ערוץ אלפא, מתעלמים מערוץ האלפא.

*הערה:* אם טלאי מודל SUPIR מספק משקלים למקודד דה-רעש, תמונת הקלט מקודדת באמצעות משקלים אלה במקום מקודד ה-VAE הרגיל.

*הערה:* `restore_cfg` נכנס לתוקף רק כאשר הוא מוגדר לערך גדול מ-0. הגדרתו ל-0 משביתה לחלוטין את עיבוד ה-restore שלאחר מכן. כשהוא פעיל, התיקון מוחל רק כל עוד ערך הסיגמא הנוכחי גבוה מ-`restore_cfg_s_tmin`.

*הערה:* צומת זה מסומן כניסיוני ב-ComfyUI.
