# Meshy: Texture Model

הצומת Meshy: Texture Model מחיל טקסטורות שנוצרו ב-AI על מודל תלת-ממד קיים. הוא משתמש במזהה משימה (task ID) ממשימת יצירה או המרה קודמת של Meshy 3D, ומנחה את תהליך יצירת הטקסטורה באמצעות הנחיית סגנון טקסטואלית או תמונת עזר. הצומת מחזיר את המודל עם הטקסטורה בפורמטים GLB ו-FBX.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | גרסת מודל ה-AI שבה יש להשתמש ליצירת הטקסטורה. | COMBO | כן | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | המזהה הייחודי (task ID) ממשימת יצירה או המרה קודמת של Meshy 3D. זה מספק את מודל התלת-ממד הבסיסי שעליו תיושם הטקסטורה. | MESHY_TASK_ID | כן | - |
| `enable_original_uv` | השתמש ב-UV המקוריים של המודל במקום ליצור UV חדשים. כאשר מופעל (ברירת מחדל: `True`), Meshy משמר טקסטורות קיימות מהמודל שהועלה. אם למודל אין UV מקוריים, איכות הפלט עשויה שלא להיות טובה כמו שהיא יכולה להיות. זוהי אפשרות מתקדמת. | BOOLEAN | כן | true / false |
| `pbr` | מאפשר פלט חומר מבוסס PBR (Physically Based Rendering) עבור המודל שמיושמת עליו טקסטורה (ברירת מחדל: `False`). זוהי אפשרות מתקדמת. | BOOLEAN | כן | true / false |
| `text_style_prompt` | תאר באמצעות טקסט את סגנון הטקסטורה הרצוי לאובייקט (ברירת מחדל: מחרוזת ריקה). מקסימום 600 תווים. לא ניתן להשתמש בו בו-זמנית עם `image_style`. | STRING | כן | - |
| `image_style` | תמונת 2D להנחיית תהליך יצירת הטקסטורה. לא ניתן להשתמש בה בו-זמנית עם `text_style_prompt`. | IMAGE | לא | - |
| `texture_resolution` | רזולוציית טקסטורת צבע הבסיס. רזולוציות גבוהות יותר לוכדות יותר פרטים של פני השטח. | COMBO | כן | `"2k"`<br>`"4k"`<br>`"8k"` |

**אילוצי פרמטרים:**

* עליך לספק `text_style_prompt` או `image_style`, אך לא ניתן לספק את שניהם בו-זמנית.
* `text_style_prompt` מוגבל למקסימום של 600 תווים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
