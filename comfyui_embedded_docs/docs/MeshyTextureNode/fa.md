# Meshy: مدل بافت

گره بافت‌دهی Meshy، بافت‌های تولیدشده با هوش مصنوعی را بر روی مدل سه‌بعدی اعمال می‌کند. این گره یک شناسه کار (task ID) از گره تولید یا تبدیل سه‌بعدی Meshy قبلی دریافت می‌کند و با استفاده از یک توصیف متنی یا یک تصویر مرجع، بافت‌های جدیدی برای مدل می‌سازد. خروجی این گره، مدل بافت‌دار در قالب‌های فایل GLB و FBX است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | نسخه مدل هوش مصنوعی مورد استفاده برای بافت‌دهی. | COMBO | بله | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | شناسه یکتا (task ID) از یک کار تولید یا تبدیل سه‌بعدی Meshy قبلی. این شناسه، مدل سه‌بعدی پایه را برای بافت‌دهی فراهم می‌کند. | MESHY_TASK_ID | بله | - |
| `فعال‌سازی UV اصلی` | استفاده از UV اصلی مدل به جای تولید UVهای جدید. وقتی فعال باشد (پیش‌فرض: `True`)، Meshy بافت‌های موجود از مدل بارگذاری‌شده را حفظ می‌کند. اگر مدل UV اصلی نداشته باشد، کیفیت خروجی ممکن است چندان خوب نباشد. این یک گزینه پیشرفته است. | BOOLEAN | خیر | true / false |
| `PBR` | خروجی متریال رندر مبتنی بر فیزیک (PBR) را برای مدل بافت‌دار فعال می‌کند (پیش‌فرض: `False`). این یک گزینه پیشرفته است. | BOOLEAN | خیر | true / false |
| `توضیح سبک بافت متنی` | سبک بافت مورد نظر خود را برای شیء با متن توصیف کنید. حداکثر ۶۰۰ کاراکتر. نمی‌توان همزمان با `image_style` استفاده شود. | STRING | خیر | - |
| `سبک تصویر` | یک تصویر دو بعدی برای هدایت فرآیند بافت‌دهی. نمی‌توان همزمان با `text_style_prompt` استفاده کرد. | IMAGE | خیر | - |
| `texture_resolution` | رزولوشن بافت رنگ پایه. رزولوشن‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. | COMBO | بله | `"2k"`<br>`"4k"`<br>`"8k"` |

**محدودیت‌های پارامتر:**

* شما باید یا `text_style_prompt` یا `image_style` را ارائه دهید، اما نمی‌توانید هر دو را همزمان داشته باشید.
* `text_style_prompt` به حداکثر ۶۰۰ کاراکتر محدود است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `فایل مدل` | نام فایل مدل GLB تولید شده. این خروجی فقط برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای کار برای این فرآیند بافت‌دهی که می‌توان از آن برای ارجاع به نتیجه استفاده کرد. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی بافت‌دار ذخیره‌شده در قالب فایل GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی بافت‌دار ذخیره‌شده در قالب فایل FBX. | FILE3DFBX |
