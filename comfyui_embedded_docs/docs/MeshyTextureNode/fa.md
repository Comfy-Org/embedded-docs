# Meshy: مدل بافت

گره Meshy: Texture Model بافت‌های تولیدشده با هوش مصنوعی را روی یک مدل سه‌بعدی موجود اعمال می‌کند. این گره از یک شناسه وظیفه (task ID) مربوط به یک وظیفه پیشین تولید یا تبدیل سه‌بعدی Meshy استفاده می‌کند و فرایند بافت‌دهی را با یک پرامپت سبک متنی یا یک تصویر مرجع هدایت می‌کند. این گره مدل بافت‌دار را در قالب‌های فایل GLB و FBX برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | نسخه مدل هوش مصنوعی برای بافت‌دهی. | COMBO | بله | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | شناسه یکتا (task ID) از یک وظیفه پیشین تولید یا تبدیل سه‌بعدی Meshy. این مورد مدل سه‌بعدی پایه را برای بافت‌دهی فراهم می‌کند. | MESHY_TASK_ID | بله | - |
| `enable_original_uv` | از UV اصلی مدل به‌جای تولید UVهای جدید استفاده شود. وقتی فعال باشد (پیش‌فرض: `True`)، Meshy بافت‌های موجود از مدل بارگذاری‌شده را حفظ می‌کند. اگر مدل UV اصلی نداشته باشد، کیفیت خروجی ممکن است به‌خوبی نباشد. این یک گزینه پیشرفته است. | BOOLEAN | بله | true / false |
| `pbr` | خروجی متریال مبتنی بر فیزیک (PBR) را برای مدل بافت‌دار فعال می‌کند (پیش‌فرض: `False`). این یک گزینه پیشرفته است. | BOOLEAN | بله | true / false |
| `text_style_prompt` | سبک بافت دلخواه شیء را با متن توصیف کنید (پیش‌فرض: رشته خالی). حداکثر ۶۰۰ کاراکتر. نمی‌تواند هم‌زمان با `image_style` استفاده شود. | STRING | بله | - |
| `image_style` | یک تصویر دوبعدی برای هدایت فرایند بافت‌دهی. نمی‌تواند هم‌زمان با `text_style_prompt` استفاده شود. | IMAGE | خیر | - |
| `texture_resolution` | وضوح بافت رنگ پایه. وضوح‌های بالاتر جزئیات سطح بیشتری را ثبت می‌کنند. | COMBO | بله | `"2k"`<br>`"4k"`<br>`"8k"` |

**محدودیت‌های پارامتر:**

* باید یا یک `text_style_prompt` ارائه دهید یا یک `image_style`، اما نمی‌توانید هر دو را هم‌زمان ارائه دهید.
* `text_style_prompt` حداکثر به ۶۰۰ کاراکتر محدود است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `model_file` | نام فایل مدل GLB تولیدشده. این خروجی فقط برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `meshy_task_id` | شناسه یکتای وظیفه برای این کار بافت‌دهی، که می‌تواند برای ارجاع به نتیجه استفاده شود. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی بافت‌دار ذخیره‌شده در قالب فایل GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی بافت‌دار ذخیره‌شده در قالب فایل FBX. | FILE3DFBX |
