# Meshy: Модель текстуры

Узел Meshy: Texture Model накладывает текстуры, сгенерированные ИИ, на существующую 3D-модель. Он использует ID задачи из предыдущей задачи генерации или конвертации Meshy 3D и управляет процессом текстурирования либо текстовым запросом стиля, либо эталонным изображением. Узел возвращает текстурированную модель в форматах файлов GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Версия ИИ-модели, используемая для текстурирования. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | Уникальный идентификатор (task ID) из предыдущей задачи генерации или конвертации Meshy 3D. Он предоставляет базовую 3D-модель для текстурирования. | MESHY_TASK_ID | Да | - |
| `enable_original_uv` | Использовать исходные UV-координаты модели вместо генерации новых UV. Если включено (по умолчанию: `True`), Meshy сохраняет существующие текстуры из загруженной модели. Если у модели нет исходных UV, качество результата может быть ниже. Это расширенная опция. | BOOLEAN | Да | true / false |
| `pbr` | Включает вывод материала с физически корректным рендерингом (PBR) для текстурированной модели (по умолчанию: `False`). Это расширенная опция. | BOOLEAN | Да | true / false |
| `text_style_prompt` | Опишите желаемый стиль текстуры объекта с помощью текста (по умолчанию: пустая строка). Максимум 600 символов. Нельзя использовать одновременно с `image_style`. | STRING | Да | - |
| `image_style` | 2D-изображение для управления процессом текстурирования. Нельзя использовать одновременно с `text_style_prompt`. | IMAGE | Нет | - |
| `разрешение текстуры` | Разрешение текстуры базового цвета. Более высокие разрешения передают больше деталей поверхности. | COMBO | Да | `"2k"`<br>`"4k"`<br>`"8k"` |

**Ограничения параметров:**

* Необходимо указать либо `text_style_prompt`, либо `image_style`, но нельзя указывать оба одновременно.
* `text_style_prompt` ограничен максимумом в 600 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model_file` | Имя файла сгенерированной модели GLB. Этот выход предоставляется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи для этого задания текстурирования, который можно использовать для ссылки на результат. | MESHY_TASK_ID |
| `GLB` | Текстурированная 3D-модель, сохранённая в формате файла GLB. | FILE3DGLB |
| `FBX` | Текстурированная 3D-модель, сохранённая в формате файла FBX. | FILE3DFBX |
