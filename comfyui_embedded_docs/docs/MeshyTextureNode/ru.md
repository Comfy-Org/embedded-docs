# Meshy: Модель текстуры

Узел Meshy: Texture Node применяет текстуры, созданные ИИ, к 3D-модели. Он принимает идентификатор задачи (task ID) от предыдущего узла генерации или преобразования Meshy 3D и использует либо текстовое описание, либо эталонное изображение для создания новых текстур для модели. Узел выводит модель с текстурами в форматах GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Версия модели ИИ, используемая для текстурирования. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `meshy_task_id` | Уникальный идентификатор (task ID) из предыдущей задачи генерации или преобразования Meshy 3D. Он задаёт базовую 3D-модель для текстурирования. | MESHY_TASK_ID | Да | - |
| `enable_original_uv` | Использовать исходные UV модели вместо создания новых. Когда включено (по умолчанию: `True`), Meshy сохраняет существующие текстуры загруженной модели. Если у модели нет исходных UV, качество результата может быть не таким хорошим. Это расширенная опция. | BOOLEAN | Нет | true / false |
| `pbr` | Включает вывод материалов на основе физически корректного рендеринга (PBR) для текстурированной модели (по умолчанию: `False`). Это расширенная опция. | BOOLEAN | Нет | true / false |
| `text_style_prompt` | Опишите желаемый стиль текстуры объекта с помощью текста. Максимум 600 символов. Не может использоваться одновременно с `image_style`. | STRING | Нет | - |
| `image_style` | 2D-изображение для управления процессом текстурирования. Не может использоваться одновременно с `text_style_prompt`. | IMAGE | Нет | - |
| `разрешение текстуры` | Разрешение текстуры основного цвета. Более высокие разрешения передают больше деталей поверхности. | COMBO | Да | `"2k"`<br>`"4k"`<br>`"8k"` |

**Ограничения параметров:**

* Необходимо указать либо `text_style_prompt`, либо `image_style`, но нельзя указывать оба одновременно.
* Параметр `text_style_prompt` ограничен максимумом 600 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `файл модели` | Имя файла сгенерированной GLB-модели. Этот выход предоставляется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи для этого задания текстурирования, который можно использовать для ссылки на результат. | MESHY_TASK_ID |
| `GLB` | Текстурированная 3D-модель, сохранённая в формате GLB. | FILE3DGLB |
| `FBX` | Текстурированная 3D-модель, сохранённая в формате FBX. | FILE3DFBX |
