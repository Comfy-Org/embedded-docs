# Meshy: نموذج النسيج

عقدة Meshy: Texture Model تطبّق خامات مُولّدة بالذكاء الاصطناعي على نموذج ثلاثي الأبعاد موجود. وتستخدم معرّف مهمة (task ID) من مهمة توليد أو تحويل ثلاثي الأبعاد سابقة في Meshy، وتوجّه عملية تطبيق الخامات إما عبر مطالبة نصية لنمط الخامة أو صورة مرجعية. وتُرجع العقدة النموذج المزوّد بالخامات بصيغتي ملفات GLB وFBX.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | إصدار نموذج الذكاء الاصطناعي المستخدم لتطبيق الخامات. | COMBO | نعم | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `معرّف مهمة Meshy` | المعرّف الفريد (task ID) من مهمة توليد أو تحويل ثلاثي الأبعاد سابقة في Meshy. يوفّر هذا النموذج ثلاثي الأبعاد الأساسي المطلوب تطبيق الخامات عليه. | MESHY_TASK_ID | نعم | - |
| `تفعيل UV الأصلي` | استخدام UV الأصلي للنموذج بدلاً من توليد UVs جديدة. عند التمكين (القيمة الافتراضية: `True`)، يحافظ Meshy على الخامات الموجودة من النموذج المرفوع. إذا لم يكن للنموذج UV أصلي، فقد لا تكون جودة المخرجات جيدة بالقدر نفسه. هذا خيار متقدم. | BOOLEAN | نعم | true / false |
| `PBR` | يمكّن إخراج مواد العرض القائم على الفيزياء (PBR) للنموذج المزوّد بالخامات (القيمة الافتراضية: `False`). هذا خيار متقدم. | BOOLEAN | نعم | true / false |
| `وصف نمط النسيج بالنص` | صِف نمط الخامة المطلوب للكائن باستخدام النص (القيمة الافتراضية: سلسلة نصية فارغة). الحد الأقصى 600 حرف. لا يمكن استخدامه في الوقت نفسه مع `image_style`. | STRING | نعم | - |
| `نمط الصورة` | صورة ثنائية الأبعاد لتوجيه عملية تطبيق الخامات. لا يمكن استخدامها في الوقت نفسه مع `text_style_prompt`. | IMAGE | لا | - |
| `texture_resolution` | دقة خامة اللون الأساسي. تلتقط الدقات الأعلى تفاصيل سطحية أكثر. | COMBO | نعم | `"2k"`<br>`"4k"`<br>`"8k"` |

**قيود المعاملات:**

* يجب تقديم إما `text_style_prompt` أو `image_style`، ولكن لا يمكن تقديمهما معًا في الوقت نفسه.
* يقتصر `text_style_prompt` على 600 حرف كحد أقصى.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model_file` | اسم ملف نموذج GLB الناتج. يُقدَّم هذا المخرَج للتوافق مع الإصدارات السابقة فقط. | STRING |
| `meshy_task_id` | المعرّف الفريد للمهمة الخاصة بعمل تطبيق الخامات هذا، ويمكن استخدامه للإشارة إلى النتيجة. | MESHY_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المزوّد بالخامات المحفوظ بصيغة ملف GLB. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المزوّد بالخامات المحفوظ بصيغة ملف FBX. | FILE3DFBX |
