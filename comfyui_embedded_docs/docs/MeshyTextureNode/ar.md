# Meshy: نموذج النسيج

تقوم عقدة **Meshy: Texture** بتطبيق أنسجة مُولَّدة بالذكاء الاصطناعي على نموذج ثلاثي الأبعاد. تأخذ هذه العقدة معرّف مهمة (Task ID) من عقدة توليد أو تحويل Meshy ثلاثية الأبعاد سابقة، وتستخدم إمّا وصفًا نصيًا أو صورة مرجعية لإنشاء أنسجة جديدة للنموذج. تُخرِج العقدة النموذج المنسوج بتنسيقي GLB وFBX.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | إصدار نموذج الذكاء الاصطناعي المستخدم للتنSiij. | COMBO | نعم | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `معرّف مهمة Meshy` | المعرّف الفريد (معرف المهمة) من مهمة توليد أو تحويل Meshy ثلاثية الأبعاد سابقة. يوفر هذا النموذج الأساسي ثلاثي الأبعاد الذي سيتم تنSiijه. | MESHY_TASK_ID | نعم | - |
| `تفعيل UV الأصلي` | استخدام الـ UV الأصلي للنموذج بدلاً من توليد UVs جديدة. عند التمكين (الافتراضي: `True`)، يحافظ Meshy على الأنسجة الموجودة من النموذج المرفوع. إذا لم يكن للنموذج UV أصلي، فقد لا تكون جودة المخرجات جيدة. هذا خيار متقدم. | BOOLEAN | لا | true / false |
| `PBR` | يتيح إخراج مادة العرض الفيزيائي (PBR) للنموذج المنسوج (الافتراضي: `False`). هذا خيار متقدم. | BOOLEAN | لا | true / false |
| `وصف نمط النسيج بالنص` | صِف نمط النسيج المطلوب للكائن باستخدام نص. الحد الأقصى 600 حرف. لا يمكن استخدامه في نفس الوقت مع `image_style`. | STRING | لا | - |
| `نمط الصورة` | صورة ثنائية الأبعاد لتوجيه عملية التنSiij. لا يمكن استخدامها في نفس الوقت مع `text_style_prompt`. | IMAGE | لا | - |
| `texture_resolution` | دقة نسيج اللون الأساسي. الدقة الأعلى تلتقط تفاصيل سطح أكثر. | COMBO | نعم | `"2k"`<br>`"4k"`<br>`"8k"` |

**قيود المعاملات:**

* يجب عليك توفير إمّا `text_style_prompt` أو `image_style`، لكن لا يمكنك توفيرهما معًا في نفس الوقت.
* يقتصر `text_style_prompt` على حد أقصى يبلغ 600 حرف.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `ملف النموذج` | اسم ملف نموذج GLB المُنشأ. يتم توفير هذا المخرج للتوافق مع الإصدارات السابقة فقط. | STRING |
| `معرّف مهمة meshy` | معرّف المهمة الفريد لمهمة التنSiij هذه، والذي يمكن استخدامه للإشارة إلى النتيجة. | MESHY_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المنسوج المحفوظ بتنسيق ملف GLB. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المنسوج المحفوظ بتنسيق ملف FBX. | FILE3DFBX |
