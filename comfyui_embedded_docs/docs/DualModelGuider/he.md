# Dual Model CFG Guider

צומת זה מאפשר לך להשתמש בשני מודלים שונים במהלך תהליך דגימת CFG מודרך: מודל אחד למעבר החיובי (המותנה) ומודל נפרד למעבר השלילי (הבלתי מותנה). כאשר לא מסופק מודל שלילי, הוא מתנהג כמו מנחה CFG רגיל המשתמש במודל יחיד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל המשמש למעבר החיובי (המותנה). | MODEL | כן | |
| `model_negative` | מודל המשמש למעבר השלילי (הבלתי מותנה). השתמש באותו מודל עבור CFG רגיל. | MODEL | לא | |
| `positive` | קלט ההתנייה החיובי. | CONDITIONING | כן | |
| `cfg` | ערך סקאלת CFG (ברירת מחדל: 4.0). | FLOAT | כן | 0.0 to 100.0 (step: 0.1) |
| `negative` | התנייה שלילית שמופעלת על המודל השלילי. השאר לא מחובר עבור מעבר בלתי מותנה ללא טקסט (תמונה בלבד). | CONDITIONING | לא | |
