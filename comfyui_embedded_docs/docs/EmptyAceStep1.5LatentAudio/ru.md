# EmptyAceStep1.5LatentAudio

Узел Empty Ace Step 1.5 Latent Audio создает пустой (тихий) аудиолатентный тензор для рабочих процессов генерации аудио. Он формирует латент с 64 каналами, временная длина которого рассчитывается из запрошенной длительности, и помечает его как аудиоданные для использования последующими аудиоузлами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `seconds` | Длительность генерируемого аудио в секундах (по умолчанию: 120.0). Длина латента вычисляется как `seconds * 48000 / 1920` с округлением до ближайшего целого числа. | FLOAT | Да | 1.0 - 1000.0 (шаг: 0.01) |
| `batch_size` | Количество латентных изображений в пакете (по умолчанию: 1). | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Пустой латентный тензор, представляющий тихое аудио. Тензор имеет форму [batch_size, 64, length], где length вычисляется из `seconds`. Выход также содержит идентификатор типа "audio" и значение `downscale_ratio_temporal`, равное 1764, которое используется для понижения разрешения по временной оси при обработке аудио. | LATENT |
