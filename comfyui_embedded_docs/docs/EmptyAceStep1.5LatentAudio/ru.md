# EmptyAceStep1.5LatentAudio

Узел **Empty Ace Step 1.5 Latent Audio** создаёт пустой латентный тензор, предназначенный для обработки аудио. Он генерирует беззвучный аудио-латент заданной длительности и размера пакета, который можно использовать в качестве отправной точки для рабочих процессов генерации аудио в ComfyUI. Узел вычисляет длину латента на основе количества секунд на входе и фиксированной частоты дискретизации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `seconds` | Длительность генерируемого аудио в секундах (по умолчанию: 120.0). | FLOAT | Да | 1.0 - 1000.0 |
| `batch_size` | Количество латентных изображений в пакете (по умолчанию: 1). | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Пустой латентный тензор, представляющий беззвучное аудио, с идентификатором типа «audio». Выходные данные также содержат значение `downscale_ratio_temporal`, равное 1764, которое используется для временного даунскейлинга при обработке аудио. | LATENT |
