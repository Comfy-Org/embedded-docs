# UnwrapMesh

יוצר אטלס UV עבור מש תלת-ממדי. משטח המש מפוצל לצ'ארטים, כל צ'ארט נפרש לשני ממדים, והצ'ארטים השטוחים נארזים לאטלס UV בטווח [0,1]. קודקודים על תפרי צ'ארטים משוכפלים (עותק אחד לכל צ'ארט, אותו מיקום, UV משלו), כך שמש הפלט יכול להכיל יותר קודקודים ממש הקלט, ומספר הפאות בפלט עשוי להיות שונה מזה שבקלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | מש הקלט לפריסה. מקבל מש בודד או אצווה של משים; אצוות מעובדות פריט אחד בכל פעם. | MESH | כן | — |
| `segmenter` | אלגוריתם יצירת צ'ארטים לשימוש. `pec`: יצירת צ'ארטים מהירה באמצעות parallel-edge-collapse על GPU. `adaptive`: CPU, איטי יותר. (ברירת מחדל: "pec") | COMBO | כן | "pec"<br>"adaptive" |
| `resolution` | רזולוציית אטלס יעד עבור קנה מידה אוטומטי של צפיפות טקסלים (0 = התאמה לתוכן). (ברירת מחדל: 1024) | INT | כן | 0 to 8192 (step 256) |
| `padding` | ריפוד טקסלים בין צ'ארטים. (ברירת מחדל: 1) | INT | כן | 0 to 16 |
| `weld_distance` | רדיוס מיזוג קודקודים חופפים כשבר מגודל המש (0 = אוטומטי). העלה לכ-0.001 אם מתקבלים צ'ארטים לכל משולש בנפרד (קלט לא מאוחה). (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 to 1.0 (step 0.0001) |

הערה: אם מש הקלט מכיל קודקודים לא מאוחים, הצומת עשוי להזהיר שצמידות הפאות נמוכה ולהפיק צ'ארטים של UV לכל פאה; הגדלת `weld_distance` מאחה קודקודים חופפים לפני הפרישה. פאות מנוונות (פאות שעושות שימוש חוזר באותו אינדקס קודקוד) מושמטות במהלך העיבוד.
