# Развёртка UV-сетки

Создаёт UV-атлас для 3D-сетки. Поверхность сетки разбивается на чарты, каждый чарт разворачивается в двухмерное пространство, а развёрнутые чарты упаковываются в UV-атлас в диапазоне [0,1]. Вершины на швах между чартами дублируются (по одной копии на чарт, с одинаковой позицией и собственными UV-координатами), поэтому выходная сетка может содержать больше вершин, чем входная, а количество граней на выходе может отличаться от входного.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная сетка для развёртки. Принимает одну сетку или батч сеток; батчи обрабатываются по одному элементу за раз. | MESH | Да | — |
| `segmenter` | Алгоритм разбиения на чарты. `pec`: быстрое создание чартов с параллельным сворачиванием рёбер на GPU. `adaptive`: CPU, медленнее. (по умолчанию: "pec") | COMBO | Да | "pec"<br>"adaptive" |
| `resolution` | Целевое разрешение атласа для авто-масштабирования плотности текселей (0 = подгонка под содержимое). (по умолчанию: 1024) | INT | Да | 0–8192 (шаг 256) |
| `padding` | Отступ в текселях между чартами. (по умолчанию: 1) | INT | Да | 0–16 |
| `weld_distance` | Радиус объединения совпадающих вершин как доля от габаритов сетки (0 = авто). Увеличьте до ~0.001, если получаете чарты для каждого треугольника (несваренные входные данные). (по умолчанию: 0.0) | FLOAT | Да | 0.0–1.0 (шаг 0.0001) |

Примечание: если входная сетка содержит несваренные вершины, узел может предупредить о низкой смежности граней и создать UV-чарты для каждой грани; увеличение `weld_distance` объединяет совпадающие вершины перед развёрткой. Вырожденные грани (грани, которые повторно используют один и тот же индекс вершины) отбрасываются во время обработки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входная сетка со сгенерированным UV-атласом в диапазоне [0,1]. Вершины на швах дублируются, поэтому количество вершин на выходе может превышать входное. Цвета вершин и текстура из входной сетки сохраняются. | MESH |
