# UnwrapMesh

Генерирует UV-атлас для 3D-сетки. Поверхность разбивается на чарты, каждый чарт уплощается в двумерное пространство, и результаты упаковываются в UV-атлас [0,1]. Вершины на границах чартов дублируются, поэтому результирующая сетка может содержать больше вершин, чем входная.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `mesh` | Входная сетка для развертки. Принимает одну сетку или пакет сеток. | MESH | Да | — |
| `segmenter` | Используемый алгоритм построения чартов. pec: быстрое построение чартов на GPU с параллельным схлопыванием рёбер. adaptive: CPU, медленнее. (по умолчанию: "pec") | COMBO | Да | "pec"<br>"adaptive" |
| `resolution` | Целевое разрешение атласа для автоматического масштабирования плотности текселей (0 = подгонять под содержимое). (по умолчанию: 1024) | INT | Да | 0 до 8192 (step 256) |
| `padding` | Отступ в текселях между чартами. (по умолчанию: 1) | INT | Да | 0 до 16 |
| `weld_distance` | Радиус слияния совпадающих вершин как доля от размера сетки (0 = автоматически). Увеличьте до ~0.001, если получаются отдельные чарты для каждого треугольника (несваренные вершины). (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 (step 0.0001) |

Примечание: если входная сетка содержит несваренные вершины (треугольный суп), узел может предупредить о низкой смежности граней и создать UV-чарты для каждой грани; увеличение `weld_distance` объединяет совпадающие вершины перед разверткой.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `mesh` | Входная сетка со сгенерированным UV-атласом в [0,1]. Вершины на швах дублируются, поэтому количество вершин на выходе может превышать входное. Цвета вершин и текстура из входной сетки сохраняются. | MESH |
