# UnwrapMesh

Создает UV-атлас для 3D-сетки. Поверхность разбивается на лоскуты, каждый лоскут разворачивается в двумерную плоскость, а результаты упаковываются в UV-атлас в диапазоне [0,1]. Вершины на границах лоскутов дублируются, поэтому выходная сетка может содержать больше вершин, чем входная.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная сетка для развертки. Принимает одну сетку или пакет сеток. | MESH | Да | — |
| `segmenter` | Алгоритм построения лоскутов. pec: быстрое построение лоскутов на GPU с параллельным схлопыванием ребер. adaptive: CPU, медленнее. (по умолчанию: "pec") | COMBO | Да | "pec"<br>"adaptive" |
| `resolution` | Целевое разрешение атласа для автоматического масштабирования по плотности текселей (0 = под содержимое). (по умолчанию: 1024) | INT | Да | 0 to 8192 (step 256) |
| `padding` | Отступ в текселях между лоскутами. (по умолчанию: 1) | INT | Да | 0 to 16 |
| `weld_distance` | Радиус слияния совпадающих вершин как доля размера сетки (0 = автоматически). Увеличьте до ~0.001, если получаются лоскуты по треугольникам (несваренная входная сетка). (по умолчанию: 0.0) | FLOAT | Да | 0.0 to 1.0 (step 0.0001) |

Примечание: если входная сетка содержит несваренные вершины (суп из треугольников), узел может предупредить о низкой смежности граней и создать UV-лоскуты по граням; увеличение `weld_distance` объединяет совпадающие вершины перед разверткой.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входная сетка с созданным UV-атласом в диапазоне [0,1]. Вершины на границах лоскутов дублируются, поэтому количество вершин на выходе может превышать входное. Цвета вершин и текстура входной сетки сохраняются. | MESH |
