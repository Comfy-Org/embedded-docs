# UnwrapMesh

生成一个 3D 网格的 UV 贴图集。表面被分割为多个图表（charts），每个图表被展开为二维平面，然后将结果打包到 [0,1] 的 UV 贴图集中。图表接缝处的顶点会被复制，因此输出网格可能包含比输入更多的顶点。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要展开的输入网格。接受单个网格或一批网格。 | MESH | 是 | — |
| `segmenter` | 使用的图表算法。pec：在 GPU 上进行快速的平行边折叠图表生成。adaptive：在 CPU 上运行，速度较慢。（默认值："pec"） | COMBO | 是 | "pec"<br>"adaptive" |
| `resolution` | 用于纹素密度自动缩放的目标贴图集分辨率（0 表示适应内容大小）。（默认值：1024） | INT | 是 | 0 到 8192（步长 256） |
| `padding` | 图表之间的纹素边距。（默认值：1） | INT | 是 | 0 到 16 |
| `weld_distance` | 重合顶点合并半径，以网格范围的分数表示（0 表示自动）。如果出现每个三角形一个图表的情况（未焊接的输入），请将其提高到约 0.001。（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0（步长 0.0001） |

注意：如果输入网格包含未焊接的顶点（三角形汤），节点可能会警告面邻接度较低，并生成逐面 UV 图表；增大 `weld_distance` 会在展开前合并重合顶点。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 已生成 [0,1] UV 贴图集的输入网格。接缝顶点会被复制，因此输出顶点数可能超过输入。输入网格的顶点颜色和纹理将被保留。 | MESH |
