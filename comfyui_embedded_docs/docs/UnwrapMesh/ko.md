# UnwrapMesh

3D 메시에 대한 UV 아틀라스를 생성합니다. 표면이 차트로 분할되고, 각 차트는 2차원으로 평면화된 후 결과가 [0,1] UV 아틀라스에 패킹됩니다. 차트 이음새의 정점은 복제되므로 출력 메시는 입력 메시보다 더 많은 정점을 포함할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 언랩할 입력 메시입니다. 단일 메시 또는 메시 배치를 허용합니다. | MESH | 예 | — |
| `segmenter` | 사용할 차트 생성 알고리즘입니다. pec: GPU에서 빠른 병렬 모서리 축소(parallel-edge-collapse) 차트 생성. adaptive: CPU, 더 느림. (기본값: "pec") | COMBO | 예 | "pec"<br>"adaptive" |
| `resolution` | 텍셀 밀도 자동 스케일을 위한 대상 아틀라스 해상도입니다 (0 = 콘텐츠에 맞춤). (기본값: 1024) | INT | 예 | 0 to 8192 (step 256) |
| `padding` | 차트 사이의 텍셀 패딩입니다. (기본값: 1) | INT | 예 | 0 to 16 |
| `weld_distance` | 일치하는 정점 병합 반경(메시 범위의 비율)입니다 (0 = 자동). 입력이 용접되지 않아 삼각형별 차트가 생성되는 경우 약 0.001로 높이십시오. (기본값: 0.0) | FLOAT | 예 | 0.0 to 1.0 (step 0.0001) |

참고: 입력 메시에 용접되지 않은 정점(삼각형 수프)이 포함된 경우, 노드가 면 인접성이 낮다고 경고하고 면별 UV 차트를 생성할 수 있습니다. `weld_distance`를 높이면 언랩 전에 일치하는 정점이 병합됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | [0,1] 범위의 UV 아틀라스가 생성된 입력 메시입니다. 이음새 정점은 복제되므로 출력 정점 수가 입력을 초과할 수 있습니다. 입력 메시의 정점 색상과 텍스처는 보존됩니다. | MESH |
