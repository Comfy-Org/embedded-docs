# UnwrapMesh

3DメッシュのUVアトラスを生成します。表面はチャートに分割され、各チャートは2次元に展開され、結果は[0,1] UVアトラスにパックされます。チャートのシーム上の頂点は複製されるため、出力メッシュには入力よりも多くの頂点が含まれる場合があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 展開する入力メッシュ。単一メッシュまたはメッシュのバッチを受け入れます。 | MESH | はい | — |
| `segmenter` | 使用するチャート化アルゴリズム。pec: GPU上での高速な並列エッジ折りたたみチャート化。adaptive: CPU、低速。(デフォルト: "pec") | COMBO | はい | "pec"<br>"adaptive" |
| `resolution` | テクセル密度の自動スケーリングのためのターゲットアトラス解像度（0 = コンテンツにフィット）。(デフォルト: 1024) | INT | はい | 0 to 8192 (step 256) |
| `padding` | チャート間のテクセルパディング。(デフォルト: 1) | INT | はい | 0 to 16 |
| `weld_distance` | メッシュ範囲に対する一致頂点のマージ半径の割合（0 = 自動）。三角形ごとのチャートが生成される場合（未溶接の入力）は約0.001に上げてください。(デフォルト: 0.0) | FLOAT | はい | 0.0 to 1.0 (step 0.0001) |

注記：入力メッシュに未溶接の頂点（三角形スープ）が含まれている場合、ノードは面の隣接性が低いことを警告し、面ごとのUVチャートを生成する可能性があります。`weld_distance`を増やすと、展開前に一致する頂点がマージされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 生成された[0,1]のUVアトラスを持つ入力メッシュ。シーム頂点は複製されるため、出力頂点数は入力を超える可能性があります。入力メッシュの頂点カラーとテクスチャは保持されます。 | MESH |
