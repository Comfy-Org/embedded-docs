# بازکردن UVهای مش

یک اطلس UV برای یک مش سه‌بعدی تولید می‌کند. سطح مش به چارت‌ها تقسیم می‌شود، هر چارت به دو بُعد مسطح می‌شود، و چارت‌های مسطح‌شده در یک اطلس UV در بازه [0,1] بسته‌بندی می‌شوند. راس‌های روی درزهای چارت تکثیر می‌شوند (یک نسخه به‌ازای هر چارت، با موقعیت یکسان و UV مخصوص خود)، بنابراین مش خروجی می‌تواند راس‌های بیشتری نسبت به مش ورودی داشته باشد و تعداد وجه‌های خروجی ممکن است با ورودی متفاوت باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش ورودی برای باز کردن UV. یک مش تکی یا دسته‌ای از مش‌ها را می‌پذیرد؛ دسته‌ها یک‌به‌یک پردازش می‌شوند. | MESH | بله | — |
| `بخش‌بند` | الگوریتم چارت‌بندی مورد استفاده. `pec`: چارت‌بندی سریع با فروپاشی موازی یال‌ها روی GPU. `adaptive`: CPU، کندتر. (پیش‌فرض: "pec") | COMBO | بله | "pec"<br>"adaptive" |
| `وضوح` | رزولوشن هدف اطلس برای مقیاس‌بندی خودکار چگالی تکسل (0 = برازش با محتوا). (پیش‌فرض: 1024) | INT | بله | 0 تا 8192 (گام 256) |
| `فاصله‌گذاری` | حاشیه تکسل بین چارت‌ها. (پیش‌فرض: 1) | INT | بله | 0 تا 16 |
| `weld_distance` | شعاع ادغام راس‌های هم‌مکان به‌صورت کسری از گستره مش (0 = خودکار). اگر چارت‌های به‌ازای هر مثلث (ورودی جوش‌نخورده) دریافت می‌کنید، آن را تا حدود 0.001 افزایش دهید. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.0001) |

نکته: اگر مش ورودی شامل راس‌های جوش‌نخورده باشد، گره ممکن است هشدار دهد که مجاورت وجه‌ها پایین است و چارت‌های UV به‌ازای هر وجه تولید کند؛ افزایش `weld_distance` راس‌های هم‌مکان را پیش از باز کردن UV ادغام می‌کند. وجه‌های تباهیده (وجه‌هایی که از همان اندیس راس دوباره استفاده می‌کنند) در حین پردازش حذف می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `mesh` | مش ورودی همراه با یک اطلس UV تولیدشده در بازه [0,1]. راس‌های درز تکثیر می‌شوند، بنابراین تعداد راس‌های خروجی می‌تواند از ورودی بیشتر شود. رنگ‌های راس و بافت مش ورودی حفظ می‌شوند. | MESH |
