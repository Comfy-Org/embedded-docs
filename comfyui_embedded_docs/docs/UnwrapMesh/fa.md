# UnwrapMesh

یک اطلس UV برای یک مش سه‌بعدی تولید می‌کند. سطح به چارت‌هایی تقسیم می‌شود، هر چارت در دو بُعد مسطح می‌شود و نتایج در یک اطلس UV واقع در بازه [0,1] بسته‌بندی می‌شوند. رأس‌های روی درزهای چارت تکراری می‌شوند، بنابراین مش خروجی می‌تواند رأس‌های بیشتری نسبت به ورودی داشته باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش ورودی برای بازکردن. یک مش واحد یا دسته‌ای از مش‌ها را می‌پذیرد. | MESH | بله | — |
| `segmenter` | الگوریتم چارت‌بندی برای استفاده. pec: چارت‌بندی سریع با فروپاشی لبه‌های موازی روی GPU. adaptive: روی CPU، کندتر. (پیش‌فرض: "pec") | COMBO | بله | "pec"<br>"adaptive" |
| `resolution` | وضوح هدف اطلس برای مقیاس‌بندی خودکار تراکم تکسِل (0 = مناسب‌سازی با محتوا). (پیش‌فرض: 1024) | INT | بله | 0 تا 8192 (گام 256) |
| `padding` | حاشیه تکسِل بین چارت‌ها. (پیش‌فرض: 1) | INT | بله | 0 تا 16 |
| `weld_distance` | شعاع ادغام رأس‌های هم‌مکان به‌صورت کسری از وسعت مش (0 = خودکار). اگر چارت‌های تک‌مثلثی دریافت کردید (ورودی جوش‌نخورده)، آن را تا حدود 0.001 افزایش دهید. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.0001) |

توجه: اگر مش ورودی حاوی رأس‌های جوش‌نخورده (سوپ مثلثی) باشد، گره ممکن است هشدار دهد که مجاورت وجه‌ها کم است و چارت‌های UV برای هر وجه تولید کند؛ افزایش `weld_distance` قبل از بازکردن، رأس‌های منطبق را ادغام می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `mesh` | مش ورودی به همراه اطلس UV تولیدشده در بازه [0,1]. رأس‌های درز تکراری می‌شوند، بنابراین تعداد رأس‌های خروجی می‌تواند از ورودی بیشتر شود. رنگ‌های رأس و بافت از مش ورودی حفظ می‌شوند. | MESH |
