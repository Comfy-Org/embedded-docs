# UnwrapMesh

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش ورودی برای باز کردن (unwrap). یک مش یا دسته‌ای از مش‌ها را می‌پذیرد. | MESH | بله | — |
| `بخش‌بند` | الگوریتم چارت‌بندی مورد استفاده. pec: چارت‌بندی سریع با فروپاشی لبه‌های موازی روی GPU. adaptive: روی CPU، کندتر. (پیش‌فرض: "pec") | COMBO | بله | "pec"<br>"adaptive" |
| `وضوح` | وضوح هدف اطلس برای مقیاس خودکار تراکم تکسِل (0 = متناسب با محتوا). (پیش‌فرض: 1024) | INT | بله | 0 تا 8192 (گام 256) |
| `فاصله‌گذاری` | فاصله تکسِل بین چارت‌ها. (پیش‌فرض: 1) | INT | بله | 0 تا 16 |
| `weld_distance` | شعاع ادغام رئوس منطبق به صورت کسری از گستره مش (0 = خودکار). اگر به دلیل ورودی ناجوش‌خورده، چارت‌های per-triangle دریافت کردید، آن را تا حدود 0.001 افزایش دهید. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.0001) |

توجه: اگر مش ورودی شامل رئوس جوش‌نخورده (سوپ مثلثی) باشد، گره ممکن است هشدار دهد که همجواری وجه کم است و چارت‌های UV به‌ازای هر وجه تولید کند؛ افزایش `weld_distance` باعث ادغام رئوس منطبق قبل از باز کردن می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مش` | مش ورودی به همراه اطلس UV تولیدشده در بازه [0,1]. رئوس روی درزها تکثیر می‌شوند، بنابراین تعداد رئوس خروجی می‌تواند از ورودی بیشتر باشد. رنگ رئوس و بافت مش ورودی حفظ می‌شوند. | MESH |
