# 展開網格 UV

為 3D 網格生成 UV 圖集。網格表面會分割成多個 UV 區塊，每個 UV 區塊會展平為二維，接著將展平後的 UV 區塊打包到 [0,1] UV 圖集中。UV 區塊接縫上的頂點會被複製（每個區塊各一份，位置相同，各自的 UV），因此輸出網格可能比輸入網格包含更多頂點，且輸出面的數量可能與輸入不同。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要展開的輸入網格。接受單一網格或網格批次；批次會一次處理一個項目。 | MESH | 是 | — |
| `分割器` | 要使用的 UV 分塊演算法。`pec`：在 GPU 上快速進行平行邊收縮的 UV 分塊。`adaptive`：CPU，速度較慢。（預設值："pec"） | COMBO | 是 | "pec"<br>"adaptive" |
| `解析度` | 目標圖集解析度，用於紋素密度自動縮放（0 = 符合內容大小）。（預設值：1024） | INT | 是 | 0 至 8192 （步進值：256） |
| `邊距` | UV 區塊之間的紋素間距。（預設值：1） | INT | 是 | 0 至 16 |
| `weld_distance` | 重合頂點合併半徑，以網格範圍的分數表示（0 = 自動）。如果得到逐三角形 UV 區塊（未焊接的輸入），請提高到約 0.001。（預設值：0.0） | FLOAT | 是 | 0.0 至 1.0 （步進值：0.0001） |

注意：如果輸入網格包含未焊接的頂點，此節點可能會警告面鄰接性偏低，並產生逐面的 UV 區塊；提高 `weld_distance` 會在展開前合併重合頂點。退化面（重複使用相同頂點索引的面）會在處理過程中被丟棄。
