# UnwrapMesh

为 3D 網格生成 UV 圖集。表面被分割成多個圖塊，每個圖塊被展平為二維，然後將結果打包到 [0,1] UV 圖集中。圖塊接縫處的頂點會被複製，因此輸出網格可能包含比輸入更多的頂點。

## 輸入

| 參數 | 描述 | 數據類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要展開的輸入網格。接受單個網格或一批網格。 | MESH | 是 | — |
| `分割器` | 要使用的圖塊演算法。pec: 在 GPU 上進行快速並行邊塌陷圖塊化。adaptive: CPU，較慢。(預設: "pec") | COMBO | 是 | "pec"<br>"adaptive" |
| `解析度` | 用於紋素密度自動縮放的目標圖集解析度 (0 = 適應內容)。(預設: 1024) | INT | 是 | 0 至 8192 (step 256) |
| `邊距` | 圖塊之間的紋素填充。(預設: 1) | INT | 是 | 0 至 16 |
| `weld_distance` | 重合頂點合併半徑，以網格範圍的比例表示 (0 = 自動)。如果出現逐三角形圖塊（未焊接輸入），請將此值提高到約 0.001。(預設: 0.0) | FLOAT | 是 | 0.0 至 1.0 (step 0.0001) |

注意：如果輸入網格包含未焊接的頂點（三角形湯），節點可能會警告面鄰接性較低，並產生逐面 UV 圖塊；增加 `weld_distance` 會在展開前合併重合頂點。
