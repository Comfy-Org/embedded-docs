# UnwrapMesh

為 3D 網格生成 UV 圖集。將表面分割為多個圖塊（charts），每個圖塊被展平為二維，然後將結果打包到 [0,1] 的 UV 圖集中。位於圖塊接縫上的頂點會被複製，因此輸出網格的頂點數可能多於輸入網格。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要展開的輸入網格。接受單一網格或一批網格。 | MESH | 是 | — |
| `segmenter` | 要使用的圖表生成演算法。pec：在 GPU 上進行快速平行邊緣收縮圖表生成。adaptive：CPU，較慢。（預設值："pec"） | COMBO | 是 | "pec"<br>"adaptive" |
| `resolution` | 用於紋素密度自動縮放的目標圖集解析度（0 = 適應內容）。（預設值：1024） | INT | 是 | 0 to 8192 (step 256) |
| `padding` | 圖塊之間的紋素邊距。（預設值：1） | INT | 是 | 0 to 16 |
| `weld_distance` | 重合頂點合併半徑，以網格範圍的分數表示（0 = 自動）。如果出現每個三角形獨立圖表（未合併的輸入），請提高到約 0.001。（預設值：0.0） | FLOAT | 是 | 0.0 to 1.0 (step 0.0001) |

注意：如果輸入網格包含未合併的頂點（三角形湯），節點可能會警告面鄰接性過低，並產生逐面 UV 圖表；增加 `weld_distance` 會在展開前合併重合頂點。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 帶有生成在 [0,1] 範圍內 UV 圖集的輸入網格。接縫頂點會被複製，因此輸出頂點數可能超過輸入。輸入網格的頂點顏色和紋理會被保留。 | MESH |
