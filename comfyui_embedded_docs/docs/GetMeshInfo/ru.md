# GetMeshInfo

Get Mesh Info сообщает количество вершин и граней в меше, а также атрибуты, которые он содержит (такие как UV, цвета вершин, нормали и текстуры). Отчёт отображается на узле и возвращается в виде текстового выхода, при этом сам меш передаётся без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Меш для проверки. Узел подсчитывает его вершины и грани, определяет наличие атрибутов и передаёт меш дальше без изменений. | MESH | Да | — |

Примечание: Когда вход содержит несколько мешей (пакет), в отчёте показываются общее количество вершин и граней для всего пакета, а также разбивка по каждому мешу. Для пакетов с нулевым дополнением используются значения счётчиков для каждого элемента, хранящиеся в данных меша.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `сетка` | Исходный меш, передаваемый без каких-либо изменений. | MESH |
| `сведения` | Многострочный текстовый отчёт с количеством вершин, количеством граней и обнаруженными атрибутами (uvs, vertex_colors, normals, tangents, texture, metallic_roughness, normal_map). Большие числа форматируются с разделителями разрядов, например "1,234,567 (1.23M)". Этот же текст отображается на узле. | STRING |
