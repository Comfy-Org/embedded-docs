# 取得網格資訊

Get Mesh Info 會報告網格中的頂點數與面數，以及其包含的屬性（例如 UV、頂點顏色、法線和紋理）。報告會顯示在節點上，並以文字輸出傳回，而網格本身則會保持不變地傳遞。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要檢查的網格。此節點會計算其頂點數與面數、偵測存在哪些屬性，並將網格保持不變地傳遞。 | MESH | 是 | — |

注意：當輸入包含多個網格（一個批次）時，報告會顯示整個批次的頂點與面總數，以及每個網格的明細。對於補零批次，會使用儲存在網格資料中的逐項計數。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 原始網格，未經任何修改直接傳遞。 | MESH |
| `info` | 多行文字報告，包含頂點數、面數和偵測到的屬性（uvs、vertex_colors、normals、tangents、texture、metallic_roughness、normal_map）。類似紋理的屬性會顯示其高度 × 寬度尺寸。較大的計數會以逗號格式化，例如「1,234,567 (1.23M)」或「12,345 (12.3K)」。相同文字會顯示在節點上。 | STRING |
