# OpenAI GPT صورة 2

يولّد الصور بشكل متزامن عبر نقطة نهاية GPT Image من OpenAI. يمكن للعقدة إنشاء صور جديدة من النصوص أو تعديل الصور الموجودة عند توفير صورة إدخال وقناع اختياري. تدعم نماذج gpt-image-1 وgpt-image-1.5 وgpt-image-2، وقد تم وضع علامة عليها كمهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص الوصفي` | نص موجه لـ GPT Image (الافتراضي: "") | STRING | نعم | - |
| `البذرة` | بذرة عشوائية للتوليد (الافتراضي: 0) - غير مطبّقة بعد في الخلفية | INT | لا | 0 إلى 2147483647 |
| `الجودة` | جودة الصورة، تؤثر على التكلفة وزمن التوليد (الافتراضي: "low") | COMBO | لا | "low"<br>"medium"<br>"high" |
| `الخلفية` | إرجاع الصورة مع الخلفية أو بدونها (الافتراضي: "auto") | COMBO | لا | "auto"<br>"opaque"<br>"transparent" |
| `الحجم` | حجم الصورة. اختر "Custom" لاستخدام العرض والارتفاع المخصصين (فقط لـ GPT Image 2) (الافتراضي: "auto") | COMBO | لا | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `عدد الصور` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | لا | 1 إلى 8 |
| `الصورة` | صورة مرجعية اختيارية لتحرير الصور | IMAGE | لا | - |
| `القناع` | قناع اختياري للتعبئة (سيتم استبدال المناطق البيضاء) | MASK | لا | - |
| `model` | نموذج GPT Image المطلوب استخدامه (الافتراضي: "gpt-image-2") | COMBO | لا | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | يُستخدم فقط عندما تكون `size` هي "Custom". يجب أن يكون مضاعفًا للرقم 16 (فقط لـ GPT Image 2) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840، الخطوة 16 |
| `custom_height` | يُستخدم فقط عندما تكون `size` هي "Custom". يجب أن يكون مضاعفًا للرقم 16 (فقط لـ GPT Image 2) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840، الخطوة 16 |

**قيود المعاملات:**

- عند توفير `image`، تتحول العقدة إلى وضع تحرير الصور.
- لا يمكن استخدام `mask` إلا عند توفير `image`.
- عند استخدام `mask`، تُدعم الصور المفردة فقط (يجب أن يكون حجم الدفعة 1).
- يجب أن يكون حجم `mask` و`image` متطابقًا.
- الدقة المخصصة (`size` = "Custom") مدعومة فقط بواسطة نموذج gpt-image-2.
- يجب أن يكون العرض والارتفاع المخصصان مضاعفين للرقم 16.
- يجب ألا تتجاوز نسبة العرض إلى الارتفاع للدقة المخصصة 3:1.
- يجب أن يتراوح إجمالي بكسل الدقة المخصصة بين 655,360 و8,294,400.
- الخلفية الشفافة غير مدعومة لنموذج gpt-image-2.
- الأحجام الأكبر من 1536x1024 (مثل 2048x2048، 3840x2160) مدعومة فقط بواسطة نموذج gpt-image-2.
- يدعم نموذجا `gpt-image-1` و`gpt-image-1.5` الأحجام `auto`، `1024x1024`، `1024x1536`، و`1536x1024` فقط.
