# OpenAI GPT صورة 2

يولّد الصور بشكل متزامن عبر نقطة نهاية GPT Image من OpenAI. يمكن لهذه العقدة إنشاء صور جديدة من النصوص أو تحرير الصور الموجودة عند توفير صورة إدخال وقناع اختياري. وهي تدعم عدة نماذج GPT Image، بما في ذلك gpt-image-1 وgpt-image-1.5 وgpt-image-2. هذه العقدة مهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | النص الموجّه لـ GPT Image (الافتراضي: "") | STRING | نعم | - |
| `seed` | بذرة عشوائية للتوليد (الافتراضي: 0) - غير مطبّقة بعد في الواجهة الخلفية | INT | لا | 0 إلى 2147483647 |
| `quality` | جودة الصورة، تؤثر على التكلفة ووقت التوليد (الافتراضي: "low") | COMBO | لا | "low"<br>"medium"<br>"high" |
| `background` | إرجاع الصورة مع أو بدون الخلفية (الافتراضي: "auto") | COMBO | لا | "auto"<br>"opaque"<br>"transparent" |
| `size` | حجم الصورة. اختر "Custom" لاستخدام العرض والارتفاع المخصصين (لـ GPT Image 2 فقط) (الافتراضي: "auto") | COMBO | لا | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | لا | 1 إلى 8 |
| `image` | صورة مرجعية اختيارية لتحرير الصور | IMAGE | لا | - |
| `mask` | قناع اختياري للرسم الداخلي (سيتم استبدال المناطق البيضاء) | MASK | لا | - |
| `model` | نموذج GPT Image المستخدم (الافتراضي: "gpt-image-2") | COMBO | لا | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | يُستخدم فقط عندما يكون `size` هو "Custom". يجب أن يكون مضاعفًا للرقم 16 (لـ GPT Image 2 فقط) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840 |
| `custom_height` | يُستخدم فقط عندما يكون `size` هو "Custom". يجب أن يكون مضاعفًا للرقم 16 (لـ GPT Image 2 فقط) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840 |

**قيود المعاملات:**

- عند توفير `image`، تتحول العقدة إلى وضع تحرير الصور
- يمكن استخدام `mask` فقط عند توفير `image`
- عند استخدام `mask`، تُدعم الصور المنفردة فقط (يجب أن يكون حجم الدفعة 1)
- يجب أن يكون حجم `mask` و`image` متطابقًا
- الدقة المخصصة (`size` = "Custom") مدعومة فقط بواسطة نموذج gpt-image-2
- يجب أن يكون العرض والارتفاع المخصصان مضاعفين للرقم 16
- يجب ألا تتجاوز نسبة الأبعاد للدقة المخصصة 3:1
- يجب أن يتراوح إجمالي وحدات البكسل للدقة المخصصة بين 655,360 و8,294,400
- الخلفية الشفافة غير مدعومة لنموذج gpt-image-2
- الأحجام الأكبر من 1536x1024 (مثل 2048x2048، 3840x2160) مدعومة فقط بواسطة نموذج gpt-image-2
