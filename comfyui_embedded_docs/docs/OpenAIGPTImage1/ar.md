# OpenAI GPT صورة 2

ينشئ الصور بشكل متزامن عبر نقطة نهاية GPT Image من OpenAI. يمكنه إنشاء صور جديدة من موجّه نصي أو تحرير صور موجودة عند توفير صورة إدخال وقناع اختياري. تدعم العقدة نماذج `gpt-image-1` و`gpt-image-1.5` و`gpt-image-2` وهي معلّمة على أنها مهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجّه نصي لـ GPT Image (الافتراضي: "") | STRING | نعم | - |
| `seed` | بذرة عشوائية للتوليد؛ لم تُنفّذ بعد في الواجهة الخلفية (الافتراضي: 0) | INT | لا | 0 إلى 2147483647 |
| `quality` | جودة الصورة، تؤثر في التكلفة وزمن التوليد (الافتراضي: "low") | COMBO | لا | "low"<br>"medium"<br>"high" |
| `background` | إرجاع الصورة مع خلفية أو بدونها (الافتراضي: "auto") | COMBO | لا | "auto"<br>"opaque"<br>"transparent" |
| `size` | حجم الصورة. اختر "Custom" لاستخدام العرض والارتفاع المخصصين (GPT Image 2 فقط) (الافتراضي: "auto") | COMBO | لا | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | عدد الصور المطلوب توليدها (الافتراضي: 1) | INT | لا | 1 إلى 8 |
| `image` | صورة مرجعية اختيارية لتحرير الصور | IMAGE | لا | - |
| `mask` | قناع اختياري لإعادة الرسم الداخلي (سيتم استبدال المناطق البيضاء) | MASK | لا | - |
| `model` | نموذج GPT Image المطلوب استخدامه (الافتراضي: "gpt-image-2") | COMBO | لا | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | يُستخدم فقط عندما تكون قيمة `size` هي "Custom". يجب أن يكون مضاعفًا للعدد 16 (GPT Image 2 فقط) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840، خطوة 16 |
| `custom_height` | يُستخدم فقط عندما تكون قيمة `size` هي "Custom". يجب أن يكون مضاعفًا للعدد 16 (GPT Image 2 فقط) (الافتراضي: 1024) | INT | لا | 1024 إلى 3840، خطوة 16 |

**قيود المعاملات:**

- عند توفير `image`، تستخدم العقدة نقطة نهاية تحرير الصور.
- لا يمكن استخدام `mask` إلا عند توفير `image`.
- عند استخدام `mask`، تُدعم الصور المفردة فقط (يجب أن يكون حجم الدفعة 1).
- يجب أن يكون حجم `mask` و`image` متطابقًا.
- الدقة المخصصة (`size` = "Custom") مدعومة فقط بواسطة نموذج `gpt-image-2`.
- يجب أن يكون العرض والارتفاع المخصصان مضاعفين للعدد 16.
- يجب ألا يتجاوز الضلع الأطول للدقة المخصصة 3840.
- يجب ألا تتجاوز نسبة أبعاد الدقة المخصصة 3:1.
- يجب أن يكون إجمالي البكسلات للدقة المخصصة بين 655,360 و8,294,400.
- الخلفية الشفافة غير مدعومة في نموذج `gpt-image-2`.
- تدعم نماذج `gpt-image-1` و`gpt-image-1.5` الأحجام `auto` و`1024x1024` و`1024x1536` و`1536x1024` فقط. أما الأحجام الأخرى فيدعمها نموذج `gpt-image-2` فقط.
