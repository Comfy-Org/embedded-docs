# OpenAI GPT صورة 2

يُنشئ الصور بشكل متزامن عبر نقطة نهاية GPT Image من OpenAI. يمكنه إنشاء صور جديدة من موجه نصي أو تعديل صور موجودة عند توفير صورة إدخال وقناع اختياري. تدعم العقدة نماذج `gpt-image-1` و`gpt-image-1.5` و`gpt-image-2` وهي موسومة بأنها مهملة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص الوصفي` | موجه نصي لـ GPT Image (القيمة الافتراضية: "") | STRING | نعم | - |
| `البذرة` | بذرة عشوائية للتوليد؛ لم تُنفّذ بعد في الواجهة الخلفية (القيمة الافتراضية: 0) | INT | لا | 0 إلى 2147483647 |
| `الجودة` | جودة الصورة، تؤثر على التكلفة ووقت التوليد (القيمة الافتراضية: "low") | COMBO | لا | "low"<br>"medium"<br>"high" |
| `الخلفية` | إرجاع الصورة مع خلفية أو بدونها (القيمة الافتراضية: "auto") | COMBO | لا | "auto"<br>"opaque"<br>"transparent" |
| `الحجم` | حجم الصورة. اختر "Custom" لاستخدام العرض والارتفاع المخصصين (لـ GPT Image 2 فقط) (القيمة الافتراضية: "auto") | COMBO | لا | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `عدد الصور` | عدد الصور المطلوب توليدها (القيمة الافتراضية: 1) | INT | لا | 1 إلى 8 |
| `الصورة` | صورة مرجعية اختيارية لتعديل الصور | IMAGE | لا | - |
| `القناع` | قناع اختياري لإعادة الرسم الداخلي (سيتم استبدال المناطق البيضاء) | MASK | لا | - |
| `model` | نموذج GPT Image المطلوب استخدامه (القيمة الافتراضية: "gpt-image-2") | COMBO | لا | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | يُستخدم فقط عندما تكون قيمة `size` هي "Custom". يجب أن يكون من مضاعفات 16 (لـ GPT Image 2 فقط) (القيمة الافتراضية: 1024) | INT | لا | 1024 إلى 3840، خطوة 16 |
| `custom_height` | يُستخدم فقط عندما تكون قيمة `size` هي "Custom". يجب أن يكون من مضاعفات 16 (لـ GPT Image 2 فقط) (القيمة الافتراضية: 1024) | INT | لا | 1024 إلى 3840، خطوة 16 |

**قيود المعاملات:**

- عند توفير `image`، تستخدم العقدة نقطة نهاية تعديل الصور.
- لا يمكن استخدام `mask` إلا عند توفير `image`.
- عند استخدام `mask`، تُدعم الصور المفردة فقط (يجب أن تكون حجم الدفعة 1).
- يجب أن يكون `mask` و`image` بالحجم نفسه.
- الدقة المخصصة (`size` = "Custom") مدعومة فقط بواسطة نموذج `gpt-image-2`.
- يجب أن يكون العرض والارتفاع المخصصان من مضاعفات 16.
- يجب ألا يتجاوز الضلع الأطول للدقة المخصصة 3840.
- يجب ألا تتجاوز نسبة أبعاد الدقة المخصصة 3:1.
- يجب أن يكون إجمالي البكسلات في الدقة المخصصة بين 655,360 و8,294,400.
- تدعم نماذج `gpt-image-1` و`gpt-image-1.5` فقط الأحجام `auto` و`1024x1024` و`1024x1536` و`1536x1024`. الأحجام الأخرى يدعمها فقط نموذج `gpt-image-2`.
