# OpenAI GPT Image 2

تصاویر را به‌صورت همگام از طریق نقطه پایانی GPT Image شرکت OpenAI تولید می‌کند. می‌تواند تصاویر جدیدی را از یک پرامپت متنی ایجاد کند یا زمانی که تصویر ورودی و ماسک اختیاری ارائه شوند، تصاویر موجود را ویرایش کند. این گره از مدل‌های `gpt-image-1`، `gpt-image-1.5` و `gpt-image-2` پشتیبانی می‌کند و به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی برای GPT Image (پیش‌فرض: "") | STRING | بله | - |
| `seed` | دانه تصادفی برای تولید؛ هنوز در بک‌اند پیاده‌سازی نشده است (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |
| `quality` | کیفیت تصویر؛ بر هزینه و زمان تولید تأثیر می‌گذارد (پیش‌فرض: "low") | COMBO | خیر | "low"<br>"medium"<br>"high" |
| `background` | بازگرداندن تصویر با پس‌زمینه یا بدون پس‌زمینه (پیش‌فرض: "auto") | COMBO | خیر | "auto"<br>"opaque"<br>"transparent" |
| `size` | اندازه تصویر. برای استفاده از عرض و ارتفاع سفارشی، "Custom" را انتخاب کنید (فقط GPT Image 2) (پیش‌فرض: "auto") | COMBO | خیر | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | تعداد تصاویری که باید تولید شود (پیش‌فرض: 1) | INT | خیر | 1 تا 8 |
| `image` | تصویر مرجع اختیاری برای ویرایش تصویر | IMAGE | خیر | - |
| `mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین می‌شوند) | MASK | خیر | - |
| `model` | مدل GPT Image برای استفاده (پیش‌فرض: "gpt-image-2") | COMBO | خیر | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | فقط زمانی استفاده می‌شود که `size` برابر "Custom" باشد. باید مضربی از 16 باشد (فقط GPT Image 2) (پیش‌فرض: 1024) | INT | خیر | 1024 تا 3840، گام 16 |
| `custom_height` | فقط زمانی استفاده می‌شود که `size` برابر "Custom" باشد. باید مضربی از 16 باشد (فقط GPT Image 2) (پیش‌فرض: 1024) | INT | خیر | 1024 تا 3840، گام 16 |

**محدودیت‌های پارامتر:**

- زمانی که `image` ارائه شود، گره از نقطه پایانی ویرایش تصویر استفاده می‌کند.
- `mask` فقط زمانی قابل استفاده است که `image` ارائه شده باشد.
- هنگام استفاده از `mask`، فقط تصاویر تک‌تایی پشتیبانی می‌شوند (اندازه دسته باید 1 باشد).
- `mask` و `image` باید هم‌اندازه باشند.
- رزولوشن سفارشی (`size` = "Custom") فقط توسط مدل `gpt-image-2` پشتیبانی می‌شود.
- عرض و ارتفاع سفارشی باید مضربی از 16 باشند.
- بلندترین لبه یک رزولوشن سفارشی باید 3840 یا کمتر باشد.
- نسبت ابعاد رزولوشن سفارشی نباید از 3:1 بیشتر شود.
- مجموع پیکسل‌های رزولوشن سفارشی باید بین 655,360 و 8,294,400 باشد.
- پس‌زمینه شفاف برای مدل `gpt-image-2` پشتیبانی نمی‌شود.
- مدل‌های `gpt-image-1` و `gpt-image-1.5` فقط از اندازه‌های `auto`، `1024x1024`، `1024x1536` و `1536x1024` پشتیبانی می‌کنند. سایر اندازه‌ها فقط توسط مدل `gpt-image-2` پشتیبانی می‌شوند.
