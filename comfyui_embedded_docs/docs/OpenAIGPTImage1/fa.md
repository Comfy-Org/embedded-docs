# OpenAI GPT Image 2

تصاویر را به‌صورت همزمان از طریق نقطه‌پایان GPT Image شرکت OpenAI تولید می‌کند. این گره می‌تواند از روی متن‌های راهنما، تصاویر جدیدی بسازد یا در صورت دریافت تصویر ورودی و ماسک اختیاری، تصاویر موجود را ویرایش کند. از چند مدل GPT Image از جمله gpt-image-1، gpt-image-1.5 و gpt-image-2 پشتیبانی می‌کند. این گره منسوخ شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنمای GPT Image (پیش‌فرض: "") | STRING | بله | - |
| `seed` | دانه (seed) تصادفی برای تولید (پیش‌فرض: 0) - هنوز در بک‌اند پیاده‌سازی نشده است | INT | خیر | 0 تا 2147483647 |
| `quality` | کیفیت تصویر؛ بر هزینه و زمان تولید تأثیر می‌گذارد (پیش‌فرض: "low") | COMBO | خیر | "low"<br>"medium"<br>"high" |
| `background` | بازگرداندن تصویر با یا بدون پس‌زمینه (پیش‌فرض: "auto") | COMBO | خیر | "auto"<br>"opaque"<br>"transparent" |
| `size` | اندازه تصویر. برای استفاده از عرض و ارتفاع سفارشی، گزینه «Custom» را انتخاب کنید (فقط GPT Image 2) (پیش‌فرض: "auto") | COMBO | خیر | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | تعداد تصاویری که تولید می‌شود (پیش‌فرض: 1) | INT | خیر | 1 تا 8 |
| `image` | تصویر مرجع اختیاری برای ویرایش تصویر | IMAGE | خیر | - |
| `mask` | ماسک اختیاری برای inpainting (ناحیه‌های سفید جایگزین خواهند شد) | MASK | خیر | - |
| `model` | مدل GPT Image مورد استفاده (پیش‌فرض: "gpt-image-2") | COMBO | خیر | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | فقط زمانی استفاده می‌شود که `size` برابر «Custom» باشد. باید مضربی از 16 باشد (فقط GPT Image 2) (پیش‌فرض: 1024) | INT | خیر | 1024 تا 3840 |
| `custom_height` | فقط زمانی استفاده می‌شود که `size` برابر «Custom» باشد. باید مضربی از 16 باشد (فقط GPT Image 2) (پیش‌فرض: 1024) | INT | خیر | 1024 تا 3840 |

**محدودیت‌های پارامتر:**

- هنگامی که `image` ارائه شود، گره به حالت ویرایش تصویر می‌رود.
- `mask` فقط زمانی قابل استفاده است که `image` ارائه شده باشد.
- هنگام استفاده از `mask`، فقط تصاویر تکی پشتیبانی می‌شوند (اندازه دسته باید 1 باشد).
- `mask` و `image` باید هم‌اندازه باشند.
- رزولوشن سفارشی (`size` = «Custom») فقط توسط مدل gpt-image-2 پشتیبانی می‌شود.
- عرض و ارتفاع سفارشی باید مضربی از 16 باشند.
- نسبت تصویر در رزولوشن سفارشی نباید از 3:1 بیشتر شود.
- مجموع پیکسل‌ها در رزولوشن سفارشی باید بین 655,360 و 8,294,400 باشد.
- پس‌زمینه شفاف برای مدل gpt-image-2 پشتیبانی نمی‌شود.
- اندازه‌های بزرگ‌تر از 1536x1024 (مانند 2048x2048، 3840x2160) فقط توسط مدل gpt-image-2 پشتیبانی می‌شوند.
