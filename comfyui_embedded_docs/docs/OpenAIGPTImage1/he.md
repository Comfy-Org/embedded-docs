# OpenAIGPTImage1

יוצר תמונות באופן סינכרוני דרך נקודת הקצה GPT Image של OpenAI. הוא יכול ליצור תמונות חדשות מתוך הנחיית טקסט או לערוך תמונות קיימות כאשר מסופקים תמונת קלט ומסכה אופציונלית. הצומת תומך במודלים `gpt-image-1`, `gpt-image-1.5` ו-`gpt-image-2` ומסומן כמיושן.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית טקסט עבור GPT Image (ברירת מחדל: "") | STRING | כן | - |
| `seed` | seed אקראי ליצירה; עדיין לא מיושם בצד השרת (ברירת מחדל: 0) | INT | לא | 0 עד 2147483647 |
| `quality` | איכות התמונה, משפיעה על העלות וזמן היצירה (ברירת מחדל: "low") | COMBO | לא | "low"<br>"medium"<br>"high" |
| `background` | החזרת תמונה עם רקע או ללא רקע (ברירת מחדל: "auto") | COMBO | לא | "auto"<br>"opaque"<br>"transparent" |
| `size` | גודל התמונה. יש לבחור "Custom" כדי להשתמש ברוחב ובגובה המותאמים אישית (GPT Image 2 only) (ברירת מחדל: "auto") | COMBO | לא | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | כמה תמונות ליצור (ברירת מחדל: 1) | INT | לא | 1 עד 8 |
| `image` | תמונת עזר אופציונלית לעריכת תמונה | IMAGE | לא | - |
| `mask` | מסכה אופציונלית ל-inpainting (אזורים לבנים יוחלפו) | MASK | לא | - |
| `model` | מודל GPT Image לשימוש (ברירת מחדל: "gpt-image-2") | COMBO | לא | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | משמש רק כאשר `size` הוא "Custom". חייב להיות כפולה של 16 (GPT Image 2 only) (ברירת מחדל: 1024) | INT | לא | 1024 עד 3840, step 16 |
| `custom_height` | משמש רק כאשר `size` הוא "Custom". חייב להיות כפולה של 16 (GPT Image 2 only) (ברירת מחדל: 1024) | INT | לא | 1024 עד 3840, step 16 |

**אילוצי פרמטרים:**

- כאשר `image` מסופק, הצומת משתמש בנקודת הקצה לעריכת תמונות.
- ניתן להשתמש ב-`mask` רק כאשר `image` מסופק.
- בעת שימוש ב-`mask`, נתמכות רק תמונות בודדות (גודל האצווה חייב להיות 1).
- `mask` ו-`image` חייבים להיות באותו גודל.
- רזולוציה מותאמת אישית (`size` = "Custom") נתמכת רק על ידי המודל `gpt-image-2`.
- רוחב וגובה מותאמים אישית חייבים להיות כפולות של 16.
- הקצה הארוך ביותר של רזולוציה מותאמת אישית חייב להיות 3840 או פחות.
- יחס הרוחב-גובה של רזולוציה מותאמת אישית לא יעלה על 3:1.
- סך הפיקסלים ברזולוציה מותאמת אישית חייב להיות בין 655,360 ל-8,294,400.
- המודלים `gpt-image-1` ו-`gpt-image-1.5` תומכים רק בגדלים `auto`, `1024x1024`, `1024x1536` ו-`1536x1024`. גדלים אחרים נתמכים רק על ידי המודל `gpt-image-2`.
