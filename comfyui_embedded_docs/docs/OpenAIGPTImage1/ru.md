# OpenAI GPT Image 2

Генерирует изображения синхронно через эндпоинт GPT Image от OpenAI. Он может создавать новые изображения из текстовой подсказки или редактировать существующие изображения, когда предоставлены входное изображение и необязательная маска. Узел поддерживает модели `gpt-image-1`, `gpt-image-1.5` и `gpt-image-2` и помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовая подсказка для GPT Image (по умолчанию: "") | STRING | Да | - |
| `seed` | Случайное зерно для генерации; пока не реализовано в бэкенде (по умолчанию: 0) | INT | Нет | 0–2147483647 |
| `quality` | Качество изображения; влияет на стоимость и время генерации (по умолчанию: "low") | COMBO | Нет | "low"<br>"medium"<br>"high" |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: "auto") | COMBO | Нет | "auto"<br>"opaque"<br>"transparent" |
| `size` | Размер изображения. Выберите "Custom", чтобы использовать пользовательские ширину и высоту (только для GPT Image 2) (по умолчанию: "auto") | COMBO | Нет | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | Сколько изображений сгенерировать (по умолчанию: 1) | INT | Нет | 1–8 |
| `image` | Необязательное эталонное изображение для редактирования изображения | IMAGE | Нет | - |
| `mask` | Необязательная маска для инпейнтинга (белые области будут заменены) | MASK | Нет | - |
| `model` | Используемая модель GPT Image (по умолчанию: "gpt-image-2") | COMBO | Нет | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | Используется только когда `size` имеет значение "Custom". Должно быть кратно 16 (только для GPT Image 2) (по умолчанию: 1024) | INT | Нет | 1024–3840, шаг 16 |
| `custom_height` | Используется только когда `size` имеет значение "Custom". Должно быть кратно 16 (только для GPT Image 2) (по умолчанию: 1024) | INT | Нет | 1024–3840, шаг 16 |

**Ограничения параметров:**

- Когда предоставлено `image`, узел использует эндпоинт редактирования изображений.
- `mask` можно использовать только когда предоставлено `image`.
- При использовании `mask` поддерживаются только одиночные изображения (размер пакета должен быть 1).
- `mask` и `image` должны быть одного размера.
- Пользовательское разрешение (`size` = "Custom") поддерживается только моделью `gpt-image-2`.
- Пользовательская ширина и высота должны быть кратны 16.
- Самая длинная сторона пользовательского разрешения должна быть 3840 или меньше.
- Соотношение сторон пользовательского разрешения не должно превышать 3:1.
- Общее количество пикселей пользовательского разрешения должно быть между 655,360 и 8,294,400.
- Прозрачный фон не поддерживается для модели `gpt-image-2`.
- Модели `gpt-image-1` и `gpt-image-1.5` поддерживают только размеры `auto`, `1024x1024`, `1024x1536` и `1536x1024`. Остальные размеры поддерживаются только моделью `gpt-image-2`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение(я). Несколько изображений возвращаются пакетом; если возвращённые изображения имеют разные размеры, они масштабируются до размера первого изображения. | IMAGE |
