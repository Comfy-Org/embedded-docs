# OpenAI GPT Image 2

Generates изображения синхронно через конечную точку OpenAI GPT Image. Узел может создавать новые изображения по текстовым запросам или редактировать существующие изображения при наличии входного изображения и необязательной маски. Поддерживает модели gpt-image-1, gpt-image-1.5 и gpt-image-2 и помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для GPT Image (по умолчанию: "") | STRING | Да | - |
| `seed` | Случайное зерно для генерации (по умолчанию: 0) — ещё не реализовано в бэкенде | INT | Нет | 0 до 2147483647 |
| `quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: "low") | COMBO | Нет | "low"<br>"medium"<br>"high" |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: "auto") | COMBO | Нет | "auto"<br>"opaque"<br>"transparent" |
| `size` | Размер изображения. Выберите "Custom", чтобы использовать произвольные ширину и высоту (только для GPT Image 2) (по умолчанию: "auto") | COMBO | Нет | "auto"<br>"1024x1024"<br>"1024x1536"<br>"1536x1024"<br>"2048x2048"<br>"2048x1152"<br>"1152x2048"<br>"3840x2160"<br>"2160x3840"<br>"Custom" |
| `n` | Сколько изображений сгенерировать (по умолчанию: 1) | INT | Нет | 1 до 8 |
| `image` | Необязательное исходное изображение для редактирования изображения | IMAGE | Нет | - |
| `mask` | Необязательная маска для инпейнтинга (белые области будут заменены) | MASK | Нет | - |
| `model` | Модель GPT Image для использования (по умолчанию: "gpt-image-2") | COMBO | Нет | "gpt-image-1"<br>"gpt-image-1.5"<br>"gpt-image-2" |
| `custom_width` | Используется только когда `size` равен "Custom". Должно быть кратным 16 (только для GPT Image 2) (по умолчанию: 1024) | INT | Нет | 1024 до 3840, step 16 |
| `custom_height` | Используется только когда `size` равен "Custom". Должно быть кратным 16 (только для GPT Image 2) (по умолчанию: 1024) | INT | Нет | 1024 до 3840, step 16 |

**Ограничения параметров:**

- При наличии `image` узел переключается в режим редактирования изображения.
- `mask` можно использовать только при наличии `image`.
- При использовании `mask` поддерживаются только одиночные изображения (размер пакета должен быть равен 1).
- `mask` и `image` должны быть одного размера.
- Произвольное разрешение (`size` = "Custom") поддерживается только моделью gpt-image-2.
- Произвольные ширина и высота должны быть кратны 16.
- Соотношение сторон произвольного разрешения не должно превышать 3:1.
- Общее количество пикселей произвольного разрешения должно быть от 655 360 до 8 294 400.
- Прозрачный фон не поддерживается для модели gpt-image-2.
- Размеры больше 1536x1024 (например, 2048x2048, 3840x2160) поддерживаются только моделью gpt-image-2.
- Модели `gpt-image-1` и `gpt-image-1.5` поддерживают только размеры `auto`, `1024x1024`, `1024x1536` и `1536x1024`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированные или отредактированные изображения | IMAGE |
