# ModelMergeCosmos7B

گره ModelMergeCosmos7B دو مدل هوش مصنوعی را با استفاده از ترکیب وزنی مؤلفه‌های خاص با یکدیگر ادغام می‌کند. این گره با تنظیم وزن‌های جداگانه برای تعبیه‌های موقعیت، بلوک‌های ترنسفورمر و لایه‌های نهایی، کنترل دقیقی بر نحوه ترکیب بخش‌های مختلف مدل‌ها فراهم می‌کند.
