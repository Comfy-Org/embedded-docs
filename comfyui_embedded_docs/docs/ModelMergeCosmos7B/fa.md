# ModelMergeCosmos7B

گره `ModelMergeCosmos7B` دو مدل هوش مصنوعی را با استفاده از ترکیب وزنی مؤلفه‌های خاص با یکدیگر ادغام می‌کند. این گره امکان کنترل دقیق نحوه ترکیب بخش‌های مختلف مدل‌ها را با تنظیم وزن‌های جداگانه برای جاسازی‌های موقعیت، بلوک‌های ترانسفورمر و لایه‌های نهایی فراهم می‌کند.
