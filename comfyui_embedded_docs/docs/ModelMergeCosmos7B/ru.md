# ModelMergeCosmos7B

Узел ModelMergeCosmos7B объединяет две модели ИИ методом взвешенного смешивания отдельных компонентов. Он позволяет точно контролировать, как различные части моделей комбинируются, регулируя индивидуальные веса для позиционных эмбеддеров, блоков трансформера и финальных слоёв.
