# OpenAI Sora - Видео

Узел OpenAIVideoSora2 генерирует видео с помощью моделей Sora от OpenAI. Он принимает текстовую подсказку вместе с необязательным одним эталонным изображением, отправляет запрос в OpenAI, ждёт завершения генерации и возвращает полученное видео. Поддерживаемые длительности и разрешения зависят от выбранной модели.

**УВЕДОМЛЕНИЕ О ПРЕКРАЩЕНИИ ПОДДЕРЖКИ:** OpenAI прекратит обслуживание API Sora v2 в сентябре 2026 года. В это время этот узел будет удалён из ComfyUI.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель OpenAI Sora для генерации видео (по умолчанию: "sora-2") | COMBO | Да | "sora-2"<br>"sora-2-pro" |
| `промпт` | Управляющий текст; может быть пустым, если присутствует входное изображение (по умолчанию: пустая строка) | STRING | Да | - |
| `размер` | Разрешение генерируемого видео (по умолчанию: "1280x720") | COMBO | Да | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `длительность` | Длительность генерируемого видео в секундах (по умолчанию: 8) | COMBO | Да | 4<br>8<br>12 |
| `изображение` | Необязательное входное эталонное изображение, используемое для генерации видео; поддерживается только одно изображение | IMAGE | Нет | - |
| `сид` | Начальное значение (seed), определяющее, следует ли перезапускать узел; фактические результаты недетерминированы независимо от seed (по умолчанию: 0) | INT | Нет | от 0 до 2147483647 |

**Ограничения и особенности:**

- Модель "sora-2" поддерживает только размеры "720x1280" и "1280x720"; выбор "1024x1792" или "1792x1024" с "sora-2" вызывает ошибку. Большие размеры доступны только с "sora-2-pro".
- Когда подключён `image`, он должен содержать ровно одно изображение; подключение более одного изображения вызывает ошибку.
- Результаты недетерминированы независимо от значения `seed`.
- Отображаемая оценка стоимости зависит от выбранных `model`, `size` и `duration`.
