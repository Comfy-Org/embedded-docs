# OpenAI Sora - ویدیو

گره OpenAIVideoSora2 با مدل‌های Sora شرکت OpenAI ویدیو تولید می‌کند. یک متن راهنما به همراه یک تصویر مرجع اختیاری دریافت می‌کند، درخواست را به OpenAI می‌فرستد، منتظر پایان تولید می‌ماند و ویدیوی حاصل را برمی‌گرداند. مدت‌زمان‌ها و وضوح‌های پشتیبانی‌شده به مدل انتخاب‌شده بستگی دارند.

**اطلاعیه منسوخ‌شدن:** OpenAI از سپتامبر ۲۰۲۶ ارائه‌دهی API مربوط به Sora v2 را متوقف می‌کند. این گره در آن زمان از ComfyUI حذف خواهد شد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل Sora شرکت OpenAI برای تولید ویدیو (پیش‌فرض: "sora-2") | COMBO | بله | "sora-2"<br>"sora-2-pro" |
| `prompt` | متن راهنما؛ در صورت وجود تصویر ورودی می‌تواند خالی باشد (پیش‌فرض: رشته خالی) | STRING | بله | - |
| `size` | وضوح ویدیوی تولیدشده (پیش‌فرض: "1280x720") | COMBO | بله | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `duration` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: 8) | COMBO | بله | 4<br>8<br>12 |
| `image` | تصویر مرجع ورودی اختیاری برای تولید ویدیو؛ فقط یک تصویر پشتیبانی می‌شود | IMAGE | خیر | - |
| `seed` | مقدار seed برای تعیین اینکه گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

**محدودیت‌ها و قیود:**

- مدل "sora-2" فقط از اندازه‌های "720x1280" و "1280x720" پشتیبانی می‌کند؛ انتخاب "1024x1792" یا "1792x1024" با "sora-2" خطا ایجاد می‌کند. اندازه‌های بزرگ‌تر فقط با "sora-2-pro" در دسترس هستند.
- وقتی تصویری متصل می‌شود، باید دقیقاً شامل یک تصویر باشد؛ اتصال بیش از یک تصویر خطا ایجاد می‌کند.
- نتایج بدون توجه به مقدار seed غیرقطعی هستند.
- برآورد قیمت نمایش‌داده‌شده به `model`، `size` و `duration` انتخاب‌شده بستگی دارد.
