# OpenAIVideoSora2

הצומת OpenAIVideoSora2 יוצר סרטונים באמצעות מודלי Sora של OpenAI. הוא מקבל הנחיית טקסט יחד עם תמונת עזר אחת אופציונלית, שולח את הבקשה ל-OpenAI, ממתין לסיום היצירה ומחזיר את הסרטון שנוצר. משכי הזמן והרזולוציות הנתמכים תלויים במודל הנבחר.

**הודעת התיישנות:** OpenAI תפסיק לספק את ה-API של Sora v2 בספטמבר 2026. צומת זה יוסר מ-ComfyUI במועד זה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל OpenAI Sora שישמש ליצירת הסרטון (ברירת מחדל: "sora-2") | COMBO | כן | "sora-2"<br>"sora-2-pro" |
| `prompt` | טקסט מנחה; עשוי להיות ריק אם קיימת תמונת קלט (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `size` | הרזולוציה של הסרטון שנוצר (ברירת מחדל: "1280x720") | COMBO | כן | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `duration` | משך הסרטון שנוצר בשניות (ברירת מחדל: 8) | COMBO | כן | 4<br>8<br>12 |
| `image` | תמונת עזר אופציונלית לקלט המשמשת ליצירת הסרטון; נתמכת תמונה אחת בלבד | IMAGE | לא | - |
| `seed` | זרע לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות בזרע (ברירת מחדל: 0) | INT | לא | 0 to 2147483647 |

**אילוצים ומגבלות:**

- המודל "sora-2" תומך רק בגדלים "720x1280" ו-"1280x720"; בחירה ב-"1024x1792" או "1792x1024" עם "sora-2" מעוררת שגיאה. הגדלים הגדולים יותר זמינים רק עם "sora-2-pro".
- כאשר מחוברת תמונה, עליה להכיל תמונה אחת בדיוק; חיבור יותר מתמונה אחת מעורר שגיאה.
- התוצאות אינן דטרמיניסטיות ללא תלות בערך ה-`seed`.
- אומדן המחיר המוצג תלוי ב-`model`, `size` ו-`duration` הנבחרים.
