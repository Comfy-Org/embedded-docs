# OpenAI Sora - Video

تولّد عقدة OpenAIVideoSora2 فيديوهات باستخدام نماذج Sora من OpenAI. تستقبل وصفًا نصيًا إلى جانب صورة مرجعية واحدة اختيارية، وترسل الطلب إلى OpenAI، وتنتظر اكتمال التوليد، ثم تعيد الفيديو الناتج. تعتمد المدد والدقات المدعومة على النموذج المحدد.

**إشعار الإيقاف:** ستتوقف OpenAI عن تقديم واجهة Sora v2 API في سبتمبر 2026. وستُزال هذه العقدة من ComfyUI في ذلك الوقت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج OpenAI Sora المستخدم لتوليد الفيديو (الافتراضي: "sora-2") | COMBO | نعم | "sora-2"<br>"sora-2-pro" |
| `prompt` | نص توجيهي؛ قد يكون فارغًا إذا كانت هناك صورة مُدخلة (الافتراضي: سلسلة فارغة) | STRING | نعم | - |
| `size` | دقة الفيديو المُولَّد (الافتراضي: "1280x720") | COMBO | نعم | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `duration` | مدة الفيديو المُولَّد بالثواني (الافتراضي: 8) | COMBO | نعم | 4<br>8<br>12 |
| `image` | صورة مرجعية اختيارية مُدخلة تُستخدم لتوليد الفيديو؛ يُدعم صورة واحدة فقط | IMAGE | لا | - |
| `seed` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | لا | 0 إلى 2147483647 |

**القيود والحدود:**

- نموذج "sora-2" يدعم فقط المقاسين "720x1280" و"1280x720"؛ اختيار "1024x1792" أو "1792x1024" مع "sora-2" يرفع خطأ. المقاسات الأكبر متاحة فقط مع "sora-2-pro".
- عند توصيل صورة، يجب أن تحتوي على صورة واحدة بالضبط؛ توصيل أكثر من صورة واحدة يرفع خطأ.
- النتائج غير حتمية بغض النظر عن قيمة البذرة.
- يعتمد تقدير السعر المعروض على `model` و`size` و`duration` المحددة.
