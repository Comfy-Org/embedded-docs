# BriaEraseForeground

Этот узел удаляет передний план изображения с помощью Bria и генерирует новый фон на его месте. Удаляется всё, что Bria определяет как передний план, а не только люди; незатронутые пиксели сохраняются. Результат повторно рендерится в стандартном размере, близком к 1 мегапикселю.

Это платный API-узел, который работает через сервис Bria, поэтому при каждом запуске используются ваши учётные данные Comfy API.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Изображение, у которого удаляется передний план и заменяется сгенерированным фоном. Отправляются только цветовые каналы; любой альфа-канал отбрасывается перед загрузкой. | IMAGE | Да | - |
| `модерация` | Настройки модерации. Выберите `"false"`, чтобы отправить изображение без флагов модерации, или `"true"`, чтобы показать переключатели модерации контента ниже. По умолчанию: `"false"`. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы `"false"`

Дополнительных входов нет. Запрос отправляется без флагов модерации контента.

### Входы `"true"`

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию контента для входного изображения. По умолчанию: false. | BOOLEAN | Да | true<br>false |
| `visual_output_moderation` | Включает модерацию контента для сгенерированного выходного изображения. По умолчанию: false. | BOOLEAN | Да | true<br>false |

### Примечания

- Выходные данные повторно рендерятся в стандартном размере, близком к 1 мегапикселю, поэтому возвращённое изображение может отличаться по размерам от входного.
- Этот узел является платным API-узлом; каждый запуск стоит примерно 0,0572 USD.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Входное изображение с удалённым передним планом и новым сгенерированным фоном на его месте. | IMAGE |
