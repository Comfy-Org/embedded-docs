# BriaEraseForeground

تزيل هذه العقدة مقدمة صورة باستخدام Bria وتولّد خلفية جديدة مكانها. تتم إزالة كل ما تحدده Bria كمقدمة، وليس الأشخاص فقط، مع الحفاظ على وحدات البكسل التي لم تُمَس. تُعاد معالجة النتيجة بحجم قياسي قريب من 1 ميغابكسل.

هذه عقدة API مدفوعة تعمل على خدمة Bria، لذلك تُستخدم بيانات اعتماد Comfy API الخاصة بك في كل تشغيل.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة التي تُزال مقدمتها وتُستبدل بخلفية مُولّدة. تُرسَل قنوات الألوان فقط؛ ويُتخلّص من أي قناة ألفا قبل الرفع. | IMAGE | نعم | - |
| `moderation` | إعدادات الإشراف. اختر `"false"` لإرسال الصورة دون علامات إشراف المحتوى، أو `"true"` لإظهار مفاتيح إشراف المحتوى أدناه. القيمة الافتراضية: `"false"`. | DYNAMIC_COMBO | نعم | `"false"`<br>`"true"` |

### مدخلات `"false"`

لا توجد مدخلات إضافية. يُرسَل الطلب دون علامات إشراف المحتوى.

### مدخلات `"true"`

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | يفعّل إشراف المحتوى على الصورة المُدخلة. القيمة الافتراضية: false. | BOOLEAN | نعم | true<br>false |
| `visual_output_moderation` | يفعّل إشراف المحتوى على الصورة الناتجة. القيمة الافتراضية: false. | BOOLEAN | نعم | true<br>false |

### ملاحظات

- يُعاد تصيير المخرج بحجم قياسي قريب من 1 ميغابكسل، لذلك قد تختلف أبعاد الصورة المُرجعة عن أبعاد الصورة المُدخلة.
- هذه العقدة عقدة API مدفوعة؛ تكلّف كل عملية تشغيل حوالي 0.0572 دولار أمريكي.
