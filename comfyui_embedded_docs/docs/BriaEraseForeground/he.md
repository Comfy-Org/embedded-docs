# Bria מחיקת חזית

צומת זה מסיר את החזית של תמונה עם Bria ומייצר רקע חדש במקומה. כל מה ש-Bria מזהה כחזית מוסר, לא רק אנשים, והפיקסלים שלא נגעו בהם נשמרים. התוצאה מרונדרת מחדש בגודל תקני הקרוב ל-1 מגה-פיקסל.

זהו צומת API בתשלום שפועל בשירות של Bria, ולכן פרטי הגישה של Comfy API שלך משמשים בכל הרצה.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שהחזית שלה מוסרת ומוחלפת ברקע שנוצר. נשלחים רק ערוצי הצבע; כל ערוץ אלפא מושלך לפני ההעלאה. | IMAGE | כן | - |
| `moderation` | הגדרות מודרציה. בחר `"false"` כדי לשלוח את התמונה ללא דגלי מודרציה, או `"true"` כדי לחשוף את מתגי מודרציית התוכן שלמטה. ברירת מחדל: `"false"`. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |

### קלטים של `"false"`

אין קלטים נוספים. הבקשה נשלחת ללא דגלי מודרציית תוכן.

### קלטים של `"true"`

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | מפעיל מודרציית תוכן על תמונת הקלט. ברירת מחדל: false. | BOOLEAN | כן | true<br>false |
| `visual_output_moderation` | מפעיל מודרציית תוכן על תמונת הפלט שנוצרה. ברירת מחדל: false. | BOOLEAN | כן | true<br>false |

### הערות

- הפלט מרונדר מחדש בגודל תקני הקרוב ל-1 מגה-פיקסל, כך שהתמונה המוחזרת עשויה להיות שונה בממדיה מהקלט.
- צומת זה הוא צומת API בתשלום; כל הרצה עולה כ-0.0572 דולר ארה"ב.
