# Сохранить модель

Узел ModelSave сохраняет модель в хранилище вашего компьютера в виде файла контрольной точки `.safetensors`. Он принимает модель на вход и записывает её в выходной каталог, используя указанный вами префикс имени файла. При наличии он также встраивает информацию о промпте рабочего процесса и дополнительные метаданные в сохраняемый файл.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель для сохранения на диск | MODEL | Да | - |
| `префикс_названия_файла` | Префикс имени файла и пути для сохраняемого файла модели (по умолчанию: "diffusion_models/ComfyUI") | STRING | Да | - |
| `prompt` | Информация о промпте рабочего процесса (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные рабочего процесса (предоставляются автоматически) | EXTRA_PNGINFO | Нет | - |

Примечание: имя сохраняемого файла формируется из значения `filename_prefix` с добавлением пятизначного счётчика (например, `diffusion_models/ComfyUI_00001_.safetensors`). Если файл с таким же префиксом уже существует, счётчик увеличивается, чтобы новый файл получил уникальное имя. При наличии в сохраняемый файл встраиваются промпт рабочего процесса, дополнительные метаданные и информация об архитектуре модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не возвращает никаких выходных значений | - |
