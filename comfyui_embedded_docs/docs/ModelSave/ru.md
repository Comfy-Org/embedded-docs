# Сохранить модель

Узел ModelSave сохраняет MODEL в хранилище вашего компьютера в виде файла контрольной точки `.safetensors`. Он записывает файл в выходной каталог ComfyUI, используя указанный вами префикс имени файла, и при наличии встраивает в сохранённый файл информацию о промпте рабочего процесса и метаданные модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, сохраняемая на диск | MODEL | Да | - |
| `префикс_названия_файла` | Префикс имени файла и пути для сохраняемого файла модели (по умолчанию: "diffusion_models/ComfyUI") | STRING | Да | - |
| `prompt` | Информация о промпте рабочего процесса (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные рабочего процесса (предоставляются автоматически) | EXTRA_PNGINFO | Нет | - |

Примечание: Сохраняемое имя файла формируется из значения `filename_prefix`, за которым следует пятизначный счётчик (например, `diffusion_models/ComfyUI_00001_.safetensors`). Если файл с таким же префиксом уже существует, счётчик увеличивается, чтобы новый файл получил уникальное имя. При наличии в сохранённый файл встраиваются промпт рабочего процесса, дополнительные метаданные и информация об архитектуре модели (например, Stable Diffusion XL, SDXL Refiner, Stable Video Diffusion или Stable Diffusion 3). Если сохранение метаданных отключено через настройки командной строки ComfyUI, промпт и дополнительные метаданные не записываются в файл.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не возвращает выходных значений | - |
