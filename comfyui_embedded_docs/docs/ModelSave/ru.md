# Сохранить модель

Узел ModelSave сохраняет обученные или измененные модели в хранилище вашего компьютера. Он принимает модель на вход и записывает ее в файл контрольной точки формата safetensors в выходную папку, используя указанный префикс имени файла. Информация о рабочем процессе и метаданные встраиваются в сохраняемый файл при их наличии.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, которую необходимо сохранить на диск | MODEL | Да | - |
| `filename_prefix` | Префикс имени файла и пути для сохраняемого файла модели (по умолчанию: "diffusion_models/ComfyUI"). При сохранении к имени добавляется счетчик (например, `ComfyUI_00000_.safetensors`). | STRING | Да | - |
| `prompt` | Информация о рабочем процессе (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительные метаданные рабочего процесса (предоставляются автоматически) | EXTRA_PNGINFO | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| *None* | Этот узел не возвращает никаких выходных значений | - |
