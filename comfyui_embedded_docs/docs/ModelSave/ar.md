# حفظ النموذج

تقوم عقدة ModelSave بحفظ النماذج المدربة أو المعدلة على وحدة تخزين جهاز الكمبيوتر لديك. تأخذ نموذجًا كمدخل وتكتبه في ملف نقطة تفتيش بصيغة safetensors داخل مجلد الإخراج، باستخدام بادئة اسم الملف التي تحددها. يتم تضمين معلومات موجه سير العمل والبيانات الوصفية في الملف المحفوظ عند توفرها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج المطلوب حفظه على القرص | MODEL | نعم | - |
| `filename_prefix` | بادئة اسم الملف والمسار الخاص بملف النموذج المحفوظ (الافتراضي: "diffusion_models/ComfyUI"). يتم إلحاق عداد بالاسم عند الحفظ (على سبيل المثال، `ComfyUI_00000_.safetensors`). | STRING | نعم | - |
| `prompt` | معلومات موجه سير العمل (يتم توفيرها تلقائيًا) | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية لسير العمل (يتم توفيرها تلقائيًا) | EXTRA_PNGINFO | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| *None* | لا تُرجع هذه العقدة أي قيم إخراج | - |
