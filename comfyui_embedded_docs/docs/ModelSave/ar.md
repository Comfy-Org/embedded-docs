# حفظ النموذج

الوثيقة المترجمة:

عقدة ModelSave تحفظ نموذجًا على تخزين جهاز الكمبيوتر كملف نقطة تفتيش بصيغة `.safetensors`. تأخذ نموذجًا كمدخل وتكتبه إلى دليل المخرجات باستخدام بادئة اسم الملف التي تحدّدها. وعند توفّرها، تقوم أيضًا بتضمين معلومات موجه سير العمل وبيانات وصفية إضافية داخل الملف المحفوظ.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج الذي سيتم حفظه على القرص | MODEL | نعم | - |
| `بادئة اسم الملف` | بادئة اسم الملف والمسار لملف النموذج المحفوظ (الافتراضي: "diffusion_models/ComfyUI") | STRING | نعم | - |
| `prompt` | معلومات موجه سير العمل (تُقدم تلقائيًا) | PROMPT | لا | - |
| `extra_pnginfo` | بيانات وصفية إضافية لسير العمل (تُقدم تلقائيًا) | EXTRA_PNGINFO | لا | - |

ملاحظة: يتم إنشاء اسم الملف المحفوظ من قيمة `filename_prefix` متبوعة بعدّاد من خمسة أرقام (مثل: `diffusion_models/ComfyUI_00001_.safetensors`). إذا كان هناك ملف بنفس البادئة موجود بالفعل، تتم زيادة العداد بحيث يحصل الملف الجديد على اسم فريد. وعند توفّرها، يتم تضمين موجه سير العمل والبيانات الوصفية الإضافية ومعلومات بنية النموذج في الملف المحفوظ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
