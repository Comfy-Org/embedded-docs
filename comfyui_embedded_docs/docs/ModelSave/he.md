# שמירת מודל

צומת ModelSave שומרת MODEL באחסון של המחשב שלך כקובץ צ'קפוינט `.safetensors`. היא כותבת את הקובץ לספריית הפלט של ComfyUI באמצעות קידומת שם הקובץ שתספק, ומטמיעה מידע על פרומפט של זרימת עבודה ומטא-נתוני מודל בקובץ הנשמר כאשר הם זמינים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שיש לשמור לדיסק | MODEL | כן | - |
| `filename_prefix` | קידומת שם הקובץ והנתיב עבור קובץ המודל הנשמר (ברירת מחדל: "diffusion_models/ComfyUI") | STRING | כן | - |
| `prompt` | מידע על פרומפט של זרימת עבודה (מסופק אוטומטית) | PROMPT | לא | - |
| `extra_pnginfo` | מטא-נתוני זרימת עבודה נוספים (מסופקים אוטומטית) | EXTRA_PNGINFO | לא | - |

הערה: שם הקובץ הנשמר נבנה מהערך של `filename_prefix` ואחריו מונה בן חמש ספרות (לדוגמה, `diffusion_models/ComfyUI_00001_.safetensors`). אם קובץ עם אותה קידומת כבר קיים, המונה מוגדל כך שהקובץ החדש יקבל שם ייחודי. כאשר הם זמינים, פרומפט זרימת העבודה, מטא-נתונים נוספים ומידע על ארכיטקטורת המודל (לדוגמה Stable Diffusion XL, SDXL Refiner, Stable Video Diffusion, או Stable Diffusion 3) מוטמעים בקובץ הנשמר. אם שמירת מטא-נתונים מושבתת דרך הגדרות שורת הפקודה של ComfyUI, הפרומפט והמטא-נתונים הנוספים לא נכתבים לקובץ.
