# ModelSave

گره ModelSave یک مدل را به‌عنوان یک فایل checkpoint با پسوند `.safetensors` در حافظه رایانه شما ذخیره می‌کند. این گره یک مدل را به‌عنوان ورودی می‌گیرد و با استفاده از پیشوند نام فایلی که مشخص می‌کنید، آن را در پوشه خروجی می‌نویسد. در صورت وجود، اطلاعات prompt گردش کار و فراداده‌های اضافی را نیز در فایل ذخیره‌شده جاسازی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که قرار است روی دیسک ذخیره شود | MODEL | بله | - |
| `پیشوند نام فایل` | پیشوند مسیر و نام فایل برای فایل مدل ذخیره‌شده (پیش‌فرض: "diffusion_models/ComfyUI") | STRING | بله | - |
| `prompt` | اطلاعات prompt گردش کار (به‌صورت خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده‌های اضافی گردش کار (به‌صورت خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

توجه: نام فایل ذخیره‌شده از مقدار `filename_prefix` و به دنبال آن یک شمارنده پنج‌رقمی ساخته می‌شود (برای مثال، `diffusion_models/ComfyUI_00001_.safetensors`). اگر فایلی با همان پیشوند از قبل وجود داشته باشد، شمارنده افزایش می‌یابد تا فایل جدید نام یکتایی بگیرد. در صورت وجود، prompt گردش کار، فراداده‌های اضافی و اطلاعات معماری مدل در فایل ذخیره‌شده جاسازی می‌شوند.
