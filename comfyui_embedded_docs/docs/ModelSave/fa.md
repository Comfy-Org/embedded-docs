# ModelSave

گره ModelSave یک MODEL را به‌صورت فایل چک‌پوینت `.safetensors` روی حافظه کامپیوتر شما ذخیره می‌کند. این گره فایل را با استفاده از پیشوند نام فایلی که ارائه می‌دهید در پوشه خروجی ComfyUI می‌نویسد و در صورت وجود، اطلاعات پرامپت گردش‌کار و فراداده‌های مدل را در فایل ذخیره‌شده جای می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که باید روی دیسک ذخیره شود | MODEL | بله | - |
| `پیشوند نام فایل` | پیشوند نام فایل و مسیر برای فایل مدل ذخیره‌شده (پیش‌فرض: "diffusion_models/ComfyUI") | STRING | بله | - |
| `prompt` | اطلاعات پرامپت گردش‌کار (به‌صورت خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده‌های اضافی گردش‌کار (به‌صورت خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

نکته: نام فایل ذخیره‌شده از مقدار `filename_prefix` به‌همراه یک شمارنده پنج‌رقمی ساخته می‌شود (برای مثال، `diffusion_models/ComfyUI_00001_.safetensors`). اگر فایلی با همان پیشوند از قبل وجود داشته باشد، شمارنده افزایش می‌یابد تا فایل جدید نامی یکتا بگیرد. در صورت موجود بودن، پرامپت گردش‌کار، فراداده‌های اضافی و اطلاعات معماری مدل (برای مثال Stable Diffusion XL، SDXL Refiner، Stable Video Diffusion، یا Stable Diffusion 3) در فایل ذخیره‌شده جاسازی می‌شوند. اگر ذخیره‌سازی فراداده از طریق تنظیمات خط فرمان ComfyUI غیرفعال شده باشد، پرامپت و فراداده‌های اضافی در فایل نوشته نمی‌شوند.
