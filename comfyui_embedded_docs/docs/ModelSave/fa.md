# ModelSave

گره ModelSave مدل‌های آموزش‌دیده یا اصلاح‌شده را در حافظه رایانه شما ذخیره می‌کند. این گره یک مدل را به‌عنوان ورودی دریافت کرده و آن را با استفاده از پیشوند نام فایل مشخص‌شده، به‌صورت یک فایل checkpoint از نوع safetensors در پوشه خروجی می‌نویسد. در صورت وجود، اطلاعات پرامپت و فراداده گردش کار در فایل ذخیره‌شده تعبیه می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که باید روی دیسک ذخیره شود | MODEL | بله | - |
| `filename_prefix` | پیشوند نام فایل و مسیر برای فایل مدل ذخیره‌شده (پیش‌فرض: "diffusion_models/ComfyUI"). یک شمارنده هنگام ذخیره‌سازی به نام اضافه می‌شود (مثلاً `ComfyUI_00000_.safetensors`). | STRING | بله | - |
| `prompt` | اطلاعات پرامپت گردش کار (به‌طور خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | فراداده‌های اضافی گردش کار (به‌طور خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| *None* | این گره هیچ مقدار خروجی برنمی‌گرداند | - |
