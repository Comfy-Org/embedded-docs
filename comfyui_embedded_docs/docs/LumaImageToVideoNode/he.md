# LumaImageToVideoNode

מייצר סרטונים באופן סינכרוני על בסיס פרומפט טקסטואלי ותמונות התחלה/סיום אופציונליות. צומת זה משתמש ב-API של Luma ליצירת סרטונים, ומאפשר להגדיר את תוכן הסרטון באמצעות פרומפט, ובאופן אופציונלי לציין את הפריים הראשון ו/או האחרון כדי לשלוט במבנה הסרטון.

**הערה:** צומת זה מסומן כמיושן בקוד המקור. Luma תסיר את נקודות הקצה שצומת זה קורא להן ב-24 באוקטובר 2026, לכן יש להשתמש בצמתי Luma Ray 3.2 במקום.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת הסרטון (ברירת מחדל: "") | STRING | כן | - |
| `model` | בוחר את מודל יצירת הסרטון מבין מודלי Luma הזמינים | COMBO | כן | `"ray-1-6"`<br>`"ray-2"` |
| `resolution` | רזולוציית הפלט עבור הסרטון המיוצר (ברירת מחדל: "540p"). פרמטר זה אינו בשימוש כאשר משתמשים במודל `ray-1-6`. | COMBO | כן | `"540p"`<br>`"720p"`<br>`"1080p"`<br>`"4k"` |
| `duration` | משך הסרטון המיוצר. פרמטר זה אינו בשימוש כאשר משתמשים במודל `ray-1-6`. | COMBO | כן | `"5s"`<br>`"9s"` |
| `loop` | האם הסרטון המיוצר אמור לחזור על עצמו בלולאה (ברירת מחדל: False) | BOOLEAN | כן | - |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 0) | INT | כן | 0 עד 18446744073709551615 |
| `first_image` | הפריים הראשון של הסרטון המיוצר. (אופציונלי) | IMAGE | לא | - |
| `last_image` | הפריים האחרון של הסרטון המיוצר. (אופציונלי) | IMAGE | לא | - |
| `luma_concepts` | מושגי מצלמה אופציונליים לקביעת תנועת המצלמה באמצעות צומת Luma Concepts. (אופציונלי) | CUSTOM | לא | - |

**הערה:** יש לספק לפחות אחד מהפרמטרים `first_image` או `last_image`. הצומת יזרוק חריגה אם שניהם חסרים. הפרמטרים `resolution` ו-`duration` אינם בשימוש כאשר `model` מוגדר ל-`ray-1-6`.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | קובץ הסרטון המיוצר | VIDEO |
