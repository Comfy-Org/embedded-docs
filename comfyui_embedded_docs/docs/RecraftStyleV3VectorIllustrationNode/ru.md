# RecraftStyleV3VectorIllustrationNode

Этот узел выбирает стиль для Recraft API, а именно категорию стиля векторной иллюстрации. При необходимости можно выбрать более конкретный подстиль внутри этой категории. Узел выводит объект конфигурации стиля, который можно передать другим узлам Recraft.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `substyle` | Более конкретный стиль внутри категории векторной иллюстрации. Доступные варианты — это подстили, определённые для стиля `vector_illustration` в Recraft API. Если подстиль не выбран, используется базовый стиль `vector_illustration`. | COMBO | Да | Доступно несколько вариантов (динамически загружаемый список подстилей для стиля `vector_illustration`) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `recraft_style` | Объект конфигурации стиля Recraft, содержащий выбранный стиль векторной иллюстрации и необязательный подстиль. Его можно подключить к другим узлам Recraft. | STYLEV3 |
