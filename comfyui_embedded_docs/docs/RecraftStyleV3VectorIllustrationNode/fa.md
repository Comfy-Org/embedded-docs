# RecraftStyleV3VectorIllustrationNode

این گره یک سبک برای API Recraft انتخاب می‌کند، به‌طور خاص دسته سبک تصویرسازی برداری. می‌توانید به‌صورت اختیاری یک زیرسبک دقیق‌تر در همان دسته انتخاب کنید. این گره یک شیء پیکربندی سبک خروجی می‌دهد که می‌توان آن را به سایر گره‌های Recraft پاس داد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `substyle` | یک سبک دقیق‌تر در دسته تصویرسازی برداری. گزینه‌های موجود همان زیرسبک‌هایی هستند که توسط API Recraft برای سبک `vector_illustration` تعریف شده‌اند. اگر زیرسبکی انتخاب نشود، از سبک پایه `vector_illustration` استفاده می‌شود. | COMBO | بله | گزینه‌های متعدد موجود است (فهرست زیرسبک به‌صورت پویا برای سبک `vector_illustration` بارگذاری می‌شود) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `recraft_style` | یک شیء پیکربندی سبک Recraft شامل سبک تصویرسازی برداری انتخاب‌شده و زیرسبک اختیاری. می‌توان آن را به سایر گره‌های Recraft متصل کرد. | STYLEV3 |
