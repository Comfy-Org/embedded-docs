# Meshy: Text to Model (Smart Topology)

צומת זה יוצר רשת משולשים מוכנה למשחק במספר פאות יעד עם Meshy T2.5. הטופולוגיה נבנית לפי מספר הפוליגונים המבוקש במקום לעבור דקימציה לאחר מכן, כך שהתוצאה מוכנה למנוע משחק ללא מעבר ריטופולוגיה נפרד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת המודל של Meshy שבה יש להשתמש ליצירה. | COMBO | כן | `"meshy-t2.5"` |
| `prompt` | התיאור בטקסט של מודל התלת-ממד שיש ליצור. | STRING | כן | 1 עד 800 תווים |
| `target_polycount` | מספר משולשים משוער ברשת שנוצרה. ברירת מחדל: 15000. | INT | כן | 100 עד 30000 |
| `pose_mode` | התנוחה של הדמות שנוצרה. מחרוזת ריקה מבקשת שלא תוחל תנוחה ספציפית. זוהי הגדרה מתקדמת. ברירת מחדל: `""` (מחרוזת ריקה). | COMBO | כן | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | ה-seed קובע אם הצומת יופעל מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים:**

* השדה `prompt` חייב להכיל בין 1 ל-800 תווים.
* `target_polycount` הוא מספר המשולשים שמהם נבנית הרשת, ולא מגבלה שמוחלת לאחר היצירה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `meshy_task_id` | המזהה הייחודי של משימת Meshy API. | MESHY_TASK_ID |
| `GLB` | מודל התלת-ממד שנוצר בפורמט GLB. | FILE3DGLB |
| `FBX` | מודל התלת-ממד שנוצר בפורמט FBX. | FILE3DFBX |
