# Meshy: Text to Model (Smart Topology)

Этот узел создаёт треугольную сетку, готовую для использования в игре, с целевым количеством граней с помощью Meshy T2.5. Топология строится сразу под запрошенное количество полигонов, а не упрощается после генерации, поэтому результат готов для игрового движка без отдельного прохода ретопологии.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Meshy, используемая для генерации. | COMBO | Да | `"meshy-t2.5"` |
| `prompt` | Текстовое описание 3D-модели для генерации. | STRING | Да | от 1 до 800 символов |
| `target_polycount` | Приблизительное количество треугольников в сгенерированной сетке. По умолчанию: 15000. | INT | Да | 100–30000 |
| `pose_mode` | Поза сгенерированного персонажа. Пустая строка означает, что конкретная поза не запрашивается. Это расширенная настройка. По умолчанию: `""` (пустая строка). | COMBO | Да | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Параметр `seed` управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Да | 0–2147483647 |

**Ограничения:**

* Параметр `prompt` должен содержать от 1 до 800 символов.
* `target_polycount` — это количество треугольников, из которого строится сетка, а не ограничение, применяемое после генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API. | MESHY_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. | FILE3DFBX |
