# Meshy: Text to Model (Smart Topology)

این گره با Meshy T2.5 یک مش مثلثی آماده برای بازی با تعداد وجه هدف تولید می‌کند. توپولوژی با تعداد چندضلعی درخواستی ساخته می‌شود، نه اینکه بعداً کاهش تعداد وجه (decimation) روی آن انجام شود؛ بنابراین نتیجه بدون نیاز به مرحله جداگانه بازتوپولوژی برای موتور بازی آماده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل Meshy که برای تولید استفاده می‌شود. | COMBO | بله | `"meshy-t2.5"` |
| `prompt` | توضیح متنی مدل سه‌بعدی برای تولید. | STRING | بله | 1 تا 800 کاراکتر |
| `target_polycount` | تعداد تقریبی مثلث‌ها در مش تولیدشده. پیش‌فرض: 15000. | INT | بله | 100 تا 30000 |
| `pose_mode` | ژست شخصیت تولیدشده. یک رشته خالی درخواست ژست خاصی نمی‌کند. این یک تنظیم پیشرفته است. پیش‌فرض: `""` (رشته خالی). | COMBO | بله | `""`<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Seed تعیین می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به Seed غیرقطعی هستند. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

**محدودیت‌ها:**

* `prompt` باید بین 1 تا 800 کاراکتر باشد.
* `target_polycount` تعداد مثلث‌هایی است که مش از آن ساخته می‌شود، نه محدودیتی که پس از تولید اعمال شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `meshy_task_id` | شناسه یکتای وظیفه API Meshy. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدشده در قالب FBX. | FILE3DFBX |
