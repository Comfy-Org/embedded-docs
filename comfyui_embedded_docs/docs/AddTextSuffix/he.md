# AddTextSuffix

צומת זה מוסיף סיומת מוגדרת לסוף מחרוזת טקסט קלט. הוא מקבל את הטקסט המקורי ואת הסיומת כקלטים, ולאחר מכן מחזיר את התוצאה המשולבת. **צומת זה מיושן** והוחלף על ידי הצומת Concatenate Text.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `text` | הטקסט המקורי שאליו תתווסף הסיומת. | STRING | כן |  |
| `suffix` | הסיומת להוספה לטקסט (ברירת מחדל: ""). | STRING | לא |  |
