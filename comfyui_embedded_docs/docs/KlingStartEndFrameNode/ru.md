# Kling: Кадры начала и конца в видео

Этот узел создаёт видеопоследовательность, которая плавно переходит между вашими начальным и конечным изображениями. Он генерирует все промежуточные кадры, чтобы обеспечить плавную трансформацию от первого кадра к последнему. Этот узел вызывает API преобразования изображения в видео, но поддерживает только те входные параметры, которые работают с полем запроса `image_tail`.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | Опорное изображение. URL или строка в кодировке Base64, размер не более 10 МБ, разрешение не менее 300×300 пикселей, соотношение сторон от 1:2.5 до 2.5:1. Base64 не должен включать префикс data:image. | IMAGE | Да | - |
| `end_frame` | Управление конечным кадром. URL или строка в кодировке Base64, размер не более 10 МБ, разрешение не менее 300×300 пикселей. Base64 не должен включать префикс data:image. | IMAGE | Да | - |
| `prompt` | Позитивный текстовый промпт | STRING | Да | - |
| `negative_prompt` | Негативный текстовый промпт | STRING | Да | - |
| `cfg_scale` | Управляет силой воздействия промпта (по умолчанию: 0.5) | FLOAT | Нет | 0.0-1.0 |
| `aspect_ratio` | Соотношение сторон для генерируемого видео (по умолчанию: "16:9") | COMBO | Нет | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | Конфигурация для генерации видео в формате: режим / длительность / имя_модели. (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo"). Все доступные опции используют pro mode с моделью kling-v2-5-turbo и отличаются только длительностью видео. | COMBO | Нет | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**Ограничения для изображений:**

- Оба изображения `start_frame` и `end_frame` должны быть предоставлены, и размер файла не должен превышать 10 МБ
- Минимальное разрешение: 300×300 пикселей для обоих изображений
- Соотношение сторон `start_frame` должно быть от 1:2.5 до 2.5:1
- Изображения в кодировке Base64 не должны включать префикс "data:image"

**Ограничения для промптов:**

- Положительный промпт не должен быть пустым
- И положительный, и отрицательный промпты ограничены 500 символами
- Если `negative_prompt` оставлен пустым, он не включается в запрос

**Стоимость:**

- "pro mode / 5s duration / kling-v2-5-turbo": $0.35 USD за генерацию
- "pro mode / 10s duration / kling-v2-5-turbo": $0.70 USD за генерацию

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Длительность сгенерированного видео | STRING |
