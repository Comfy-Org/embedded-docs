# Kling: Кадры начала и конца в видео

Этот узел создаёт видеопоследовательность, которая выполняет переход между заданными вами начальным и конечным изображениями. Он генерирует все промежуточные кадры, обеспечивая плавное преобразование от первого кадра к последнему. Этот узел вызывает API image-to-video, но поддерживает только те входные параметры, которые работают с полем запроса `image_tail`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | Референсное изображение — URL или строка в кодировке Base64, не должна превышать 10 МБ, разрешение не менее 300×300 пикселей, соотношение сторон от 1:2.5 до 2.5:1. В Base64 не должен включаться префикс data:image. | IMAGE | Да | - |
| `end_frame` | Референсное изображение — управление конечным кадром. URL или строка в кодировке Base64, не должна превышать 10 МБ, разрешение не менее 300×300 пикселей. В Base64 не должен включаться префикс data:image. | IMAGE | Да | - |
| `prompt` | Положительный текстовый промпт. Не должен быть пустым и не может превышать 500 символов. | STRING | Да | - |
| `negative_prompt` | Отрицательный текстовый промпт. Не может превышать 500 символов. Если оставить пустым, он не включается в запрос. | STRING | Да | - |
| `cfg_scale` | Управляет силой следования промпту (по умолчанию: 0.5). | FLOAT | Да | 0.0-1.0 |
| `aspect_ratio` | Соотношение сторон для сгенерированного видео (по умолчанию: "16:9"). | COMBO | Да | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | Конфигурация, используемая для генерации видео, в формате: mode / duration / model_name. (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | Да | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**Ограничения изображения:**

- Оба параметра `start_frame` и `end_frame` обязательны, а размер их файлов не должен превышать 10 МБ.
- Минимальное разрешение: 300×300 пикселей для обоих изображений.
- Соотношение сторон `start_frame` должно быть в диапазоне от 1:2.5 до 2.5:1.
- Изображения в кодировке Base64 не должны содержать префикс "data:image".

**Ограничения промпта:**

- `prompt` не должен быть пустым и не может превышать 500 символов.
- `negative_prompt` не может превышать 500 символов; если он пуст, он не отправляется с запросом.

**Примечания по режиму:**

- Оба варианта режима используют pro mode с моделью kling-v2-5-turbo и различаются только длительностью (5 секунд или 10 секунд).
- Стоимость за генерацию, как показано в ценовом бейдже узла: режим 5s стоит $0.35 USD, режим 10s — $0.70 USD.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность. | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео. | STRING |
| `duration` | Длительность сгенерированного видео. | STRING |
