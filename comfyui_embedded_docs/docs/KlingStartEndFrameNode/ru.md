# Kling: Кадры начала и конца в видео

Этот узел создаёт видеопоследовательность, которая выполняет переход между предоставленными вами начальным и конечным изображениями. Он генерирует все промежуточные кадры, обеспечивая плавную трансформацию от первого кадра к последнему. Узел вызывает API image-to-video, но поддерживает только те входные параметры, которые работают с полем запроса `image_tail`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | Эталонное изображение — URL или строка в кодировке Base64, размер не более 10 МБ, разрешение не менее 300×300 пикселей, соотношение сторон от 1:2.5 до 2.5:1. Base64 не должен содержать префикс data:image. | IMAGE | Да | - |
| `end_frame` | Эталонное изображение — управление конечным кадром. URL или строка в кодировке Base64, размер не более 10 МБ, разрешение не менее 300×300 пикселей. Base64 не должен содержать префикс data:image. | IMAGE | Да | - |
| `prompt` | Позитивный текстовый промпт. Не должен быть пустым и не может превышать 500 символов. | STRING | Да | - |
| `negative_prompt` | Негативный текстовый промпт. Не может превышать 500 символов. Если оставить пустым, он не будет включён в запрос. | STRING | Да | - |
| `cfg_scale` | Управляет степенью следования промпту (по умолчанию: 0.5) | FLOAT | Да | 0.0-1.0 |
| `aspect_ratio` | Соотношение сторон для генерируемого видео (по умолчанию: "16:9") | COMBO | Да | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | Конфигурация для генерации видео в формате: режим / длительность / название модели. (по умолчанию: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | Да | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**Ограничения на изображения:**

- Оба изображения `start_frame` и `end_frame` обязательны и не могут превышать 10 МБ.
- Минимальное разрешение: 300×300 пикселей для обоих изображений.
- Соотношение сторон `start_frame` должно быть от 1:2.5 до 2.5:1.
- Изображения в кодировке Base64 не должны включать префикс "data:image".

**Ограничения на промпт:**

- `prompt` не должен быть пустым и не может превышать 500 символов.
- `negative_prompt` не может превышать 500 символов; если он пуст, он не отправляется с запросом.

**Примечания о режимах:**

- Оба варианта режима используют pro mode с моделью kling-v2-5-turbo и отличаются только длительностью (5 или 10 секунд).
- Стоимость за одну генерацию, как показано на ценовом значке узла: режим 5s стоит $0.35 USD, а режим 10s — $0.70 USD.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированная видеопоследовательность | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Длительность сгенерированного видео | STRING |
