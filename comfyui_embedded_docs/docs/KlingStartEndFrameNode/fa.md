# Kling شروع-پایان فریم به ویدیو

این گره یک سکانس ویدیویی ایجاد می‌کند که بین تصویر شروع و پایان ارائه‌شده‌ی شما انتقال می‌دهد. تمام فریم‌های میانی را تولید می‌کند تا یک تبدیل نرم از فریم اول به فریم آخر به دست آید. این گره API تصویر-به-ویدیو را فراخوانی می‌کند، اما فقط از گزینه‌های ورودی پشتیبانی می‌کند که با فیلد درخواست `image_tail` سازگار باشند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | تصویر مرجع - رشته URL یا Base64، نمی‌تواند از 10MB بیشتر شود، وضوح کمتر از 300*300px نباشد، نسبت ابعاد بین 1:2.5 ~ 2.5:1. Base64 نباید پیشوند data:image را شامل شود. | IMAGE | بله | - |
| `end_frame` | تصویر مرجع - کنترل فریم پایانی. رشته URL یا Base64، نمی‌تواند از 10MB بیشتر شود، وضوح کمتر از 300*300px نباشد. Base64 نباید پیشوند data:image را شامل شود. | IMAGE | بله | - |
| `prompt` | پرامپت متنی مثبت. نباید خالی باشد و نمی‌تواند بیش از 500 کاراکتر باشد. | STRING | بله | - |
| `negative_prompt` | پرامپت متنی منفی. نمی‌تواند بیش از 500 کاراکتر باشد. اگر خالی بماند، از درخواست حذف می‌شود. | STRING | بله | - |
| `cfg_scale` | کنترل قدرت هدایت پرامپت (پیش‌فرض: 0.5) | FLOAT | بله | 0.0-1.0 |
| `aspect_ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: "16:9") | COMBO | بله | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | پیکربندی مورد استفاده برای تولید ویدیو با قالب: mode / duration / model_name. (پیش‌فرض: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | بله | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**محدودیت‌های تصویر:**

- هم `start_frame` و هم `end_frame` الزامی هستند و اندازه فایل آن‌ها نباید از 10MB بیشتر شود.
- حداقل وضوح: 300×300 پیکسل برای هر دو تصویر.
- نسبت ابعاد `start_frame` باید بین 1:2.5 و 2.5:1 باشد.
- تصاویر رمزگذاری‌شده با Base64 نباید پیشوند "data:image" را شامل شوند.

**محدودیت‌های پرامپت:**

- `prompt` نباید خالی باشد و نمی‌تواند بیش از 500 کاراکتر باشد.
- `negative_prompt` نمی‌تواند بیش از 500 کاراکتر باشد؛ زمانی که خالی است، با درخواست ارسال نمی‌شود.

**نکات حالت:**

- هر دو گزینه حالت از pro mode با مدل kling-v2-5-turbo استفاده می‌کنند و تنها در مدت‌زمان (5 ثانیه یا 10 ثانیه) متفاوت هستند.
- قیمت هر بار تولید، همانطور که در نشان قیمت گره نشان داده شده است: حالت 5 ثانیه‌ای 0.35 دلار آمریکا و حالت 10 ثانیه‌ای 0.70 دلار آمریکا هزینه دارد.

## خروجی‌ها
