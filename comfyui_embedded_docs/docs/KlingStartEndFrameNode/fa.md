# Kling شروع-پایان فریم به ویدیو

این گره یک توالی ویدیویی می‌سازد که بین تصاویر شروع و پایان ارائه‌شده توسط شما انتقال ایجاد می‌کند. همه فریم‌های میانی را تولید می‌کند تا تبدیلی نرم از اولین فریم به آخرین فریم ایجاد شود. این گره API تصویر به ویدیو را فراخوانی می‌کند، اما فقط از گزینه‌های ورودی پشتیبانی می‌کند که با فیلد درخواست `image_tail` کار می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | تصویر مرجع - URL یا رشته کدگذاری‌شده Base64، نباید از 10MB فراتر رود، رزولوشن کمتر از 300*300px نباشد، نسبت ابعاد بین 1:2.5 تا 2.5:1 باشد. Base64 نباید پیشوند data:image داشته باشد. | IMAGE | بله | - |
| `end_frame` | تصویر مرجع - کنترل فریم پایان. URL یا رشته کدگذاری‌شده Base64، نباید از 10MB فراتر رود، رزولوشن کمتر از 300*300px نباشد. Base64 نباید پیشوند data:image داشته باشد. | IMAGE | بله | - |
| `prompt` | پرامپت متنی مثبت. نباید خالی باشد و نمی‌تواند از 500 کاراکتر فراتر رود. | STRING | بله | - |
| `negative_prompt` | پرامپت متنی منفی. نمی‌تواند از 500 کاراکتر فراتر رود. اگر خالی بماند، از درخواست حذف می‌شود. | STRING | بله | - |
| `cfg_scale` | قدرت هدایت پرامپت را کنترل می‌کند (پیش‌فرض: 0.5). | FLOAT | بله | 0.0-1.0 |
| `aspect_ratio` | نسبت ابعاد ویدیوی تولیدشده (پیش‌فرض: "16:9"). | COMBO | بله | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | پیکربندی مورد استفاده برای تولید ویدیو با قالب: mode / duration / model_name. (پیش‌فرض: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | بله | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**محدودیت‌های تصویر:**

- هر دو `start_frame` و `end_frame` الزامی هستند و اندازه فایل آن‌ها نمی‌تواند از 10MB فراتر رود.
- حداقل رزولوشن: 300×300 پیکسل برای هر دو تصویر.
- نسبت ابعاد `start_frame` باید بین 1:2.5 و 2.5:1 باشد.
- تصاویر کدگذاری‌شده با Base64 نباید پیشوند "data:image" را داشته باشند.

**محدودیت‌های پرامپت:**

- `prompt` نباید خالی باشد و نمی‌تواند از 500 کاراکتر فراتر رود.
- `negative_prompt` نمی‌تواند از 500 کاراکتر فراتر رود؛ وقتی خالی باشد، همراه درخواست ارسال نمی‌شود.

**نکات حالت:**

- هر دو گزینه حالت از حالت pro با مدل kling-v2-5-turbo استفاده می‌کنند و تنها در مدت زمان (5 ثانیه یا 10 ثانیه) تفاوت دارند.
- قیمت هر تولید، همان‌طور که در نشان قیمت گره نمایش داده می‌شود: حالت 5s هزینه 0.35 دلار آمریکا و حالت 10s هزینه 0.70 دلار آمریکا دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
