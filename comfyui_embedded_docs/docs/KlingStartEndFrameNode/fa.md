# Kling شروع-پایان فریم به ویدیو

این گره یک توالی ویدیویی ایجاد می‌کند که بین تصاویر شروع و پایان ارائه‌شده‌ی شما انتقال می‌یابد. این گره تمام فریم‌های میانی را تولید می‌کند تا یک تبدیل نرم از فریم اول به فریم آخر ایجاد کند. این گره API تبدیل تصویر به ویدیو را فراخوانی می‌کند اما فقط گزینه‌های ورودی‌ای را پشتیبانی می‌کند که با فیلد درخواست `image_tail` کار می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | تصویر مرجع - رشته URL یا Base64، حداکثر ۱۰ مگابایت، وضوح کمتر از ۳۰۰×۳۰۰ پیکسل نباشد، نسبت تصویر بین ۱:۲.۵ تا ۲.۵:۱ باشد. Base64 نباید شامل پیشوند data:image باشد. | IMAGE | بله | - |
| `end_frame` | تصویر مرجع - کنترل فریم پایان. رشته URL یا Base64، حداکثر ۱۰ مگابایت، وضوح کمتر از ۳۰۰×۳۰۰ پیکسل نباشد. Base64 نباید شامل پیشوند data:image باشد. | IMAGE | بله | - |
| `prompt` | متن پرامپت مثبت | STRING | بله | - |
| `negative_prompt` | متن پرامپت منفی | STRING | بله | - |
| `cfg_scale` | قدرت هدایت پرامپت را کنترل می‌کند (پیش‌فرض: ۰.۵) | FLOAT | خیر | 0.0-1.0 |
| `aspect_ratio` | نسبت تصویر برای ویدیوی تولیدشده (پیش‌فرض: "16:9") | COMBO | خیر | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | پیکربندی مورد استفاده برای تولید ویدیو با فرمت: mode / duration / model_name. (پیش‌فرض: "pro mode / 5s duration / kling-v2-5-turbo"). همه گزینه‌های موجود از حالت pro با مدل kling-v2-5-turbo استفاده می‌کنند و فقط در مدت‌زمان ویدیو متفاوت هستند. | COMBO | خیر | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**محدودیت‌های تصویر:**

- هر دو `start_frame` و `end_frame` باید ارائه شوند و حجم فایل آن‌ها نباید بیشتر از ۱۰ مگابایت باشد
- حداقل وضوح: ۳۰۰×۳۰۰ پیکسل برای هر دو تصویر
- نسبت تصویر `start_frame` باید بین ۱:۲.۵ و ۲.۵:۱ باشد
- تصاویر Base64 نباید شامل پیشوند "data:image" باشند

**محدودیت‌های پرامپت:**

- پرامپت مثبت نباید خالی باشد
- هر دو پرامپت مثبت و منفی به ۵۰۰ کاراکتر محدود هستند
- اگر `negative_prompt` خالی باشد، از درخواست حذف می‌شود

**قیمت‌گذاری:**

- "pro mode / 5s duration / kling-v2-5-turbo": $0.35 USD به ازای هر تولید
- "pro mode / 10s duration / kling-v2-5-turbo": $0.70 USD به ازای هر تولید
