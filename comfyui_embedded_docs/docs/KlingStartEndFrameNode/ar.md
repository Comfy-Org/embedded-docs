# كليينج إطار البداية-النهاية إلى فيديو

يقوم هذا العقد بإنشاء تسلسل فيديو ينتقل بين صورتي البداية والنهاية المقدمتين. ويولّد جميع الإطارات بينهما لإنتاج تحوّل سلس من الإطار الأول إلى الإطار الأخير. يستدعي هذا العقد واجهة برمجة تطبيقات تحويل الصورة إلى فيديو، لكنه يدعم فقط خيارات الإدخال التي تعمل مع حقل الطلب `image_tail`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | صورة مرجعية - عنوان URL أو سلسلة مشفّرة بـ Base64، لا يتجاوز حجمها 10 ميغابايت، الدقة لا تقل عن 300×300 بكسل، نسبة الأبعاد بين 1:2.5 و 2.5:1. يجب ألا تتضمّن Base64 بادئة `data:image`. | IMAGE | نعم | - |
| `end_frame` | صورة مرجعية - التحكم في الإطار النهائي. عنوان URL أو سلسلة مشفّرة بـ Base64، لا يتجاوز حجمها 10 ميغابايت، الدقة لا تقل عن 300×300 بكسل. يجب ألا تتضمّن Base64 بادئة `data:image`. | IMAGE | نعم | - |
| `prompt` | الموجّه النصي الإيجابي. يجب ألا يكون فارغًا وألا يتجاوز 500 حرف. | STRING | نعم | - |
| `negative_prompt` | الموجّه النصي السلبي. لا يمكن أن يتجاوز 500 حرف. إذا تُرك فارغًا، يتم حذفه من الطلب. | STRING | نعم | - |
| `cfg_scale` | يتحكم في قوة توجيه الموجّه (الافتراضي: 0.5) | FLOAT | نعم | 0.0-1.0 |
| `aspect_ratio` | نسبة الأبعاد للفيديو المُنشأ (الافتراضي: "16:9") | COMBO | نعم | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | الإعداد المستخدم لتوليد الفيديو وفق التنسيق: الوضع / المدة / اسم النموذج. (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | نعم | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**قيود الصورة:**

- كل من `start_frame` و `end_frame` مطلوبان ولا يمكن أن يتجاوزا 10 ميغابايت في حجم الملف.
- الحد الأدنى للدقة: 300×300 بكسل لكلتا الصورتين.
- يجب أن تكون نسبة الأبعاد لـ `start_frame` بين 1:2.5 و 2.5:1.
- يجب ألا تتضمّن الصور المشفّرة بـ Base64 بادئة `data:image`.

**قيود الموجّه:**

- يجب ألا يكون `prompt` فارغًا وألا يتجاوز 500 حرف.
- لا يمكن أن يتجاوز `negative_prompt` 500 حرف؛ وعندما يكون فارغًا، لا يتم إرساله مع الطلب.

**ملاحظات حول الوضع:**

- يستخدم كلا خياري الوضع الوضع الاحترافي مع نموذج kling-v2-5-turbo ويختلفان فقط في المدة (5 ثوانٍ أو 10 ثوانٍ).
- التسعير لكل عملية توليد، كما هو موضّح في شارة سعر العقدة: وضع 5 ثوانٍ يكلف 0.35 دولارًا أمريكيًا ووضع 10 ثوانٍ يكلف 0.70 دولارًا أمريكيًا.
