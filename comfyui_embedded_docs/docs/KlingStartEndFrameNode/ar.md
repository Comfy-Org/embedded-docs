# كليينج إطار البداية-النهاية إلى فيديو

تنشئ هذه العقدة تسلسلًا فيديويًا ينتقل بين صورة البداية وصورة النهاية التي قدمتها. وتولّد جميع الإطارات الوسيطة لإنتاج تحوّل سلس من الإطار الأول إلى الإطار الأخير. تستدعي هذه العقدة واجهة برمجة تطبيقات تحويل الصورة إلى فيديو، لكنها تدعم فقط خيارات الإدخال التي تعمل مع حقل الطلب `image_tail`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | صورة مرجعية - عنوان URL أو سلسلة مشفرة بـ Base64، لا يمكن أن يتجاوز حجمها 10MB، ويجب ألا تقل الدقة عن 300*300px، ويجب أن تكون نسبة العرض إلى الارتفاع بين 1:2.5 ~ 2.5:1. يجب ألا تتضمن Base64 البادئة data:image. | IMAGE | نعم | - |
| `end_frame` | صورة مرجعية - التحكم في إطار النهاية. عنوان URL أو سلسلة مشفرة بـ Base64، لا يمكن أن يتجاوز حجمها 10MB، ويجب ألا تقل الدقة عن 300*300px. يجب ألا تتضمن Base64 البادئة data:image. | IMAGE | نعم | - |
| `prompt` | نص توجيهي إيجابي. يجب ألا يكون فارغًا وألا يتجاوز 500 حرف. | STRING | نعم | - |
| `negative_prompt` | نص توجيهي سلبي. لا يمكن أن يتجاوز 500 حرف. إذا تُرك فارغًا، يُحذف من الطلب. | STRING | نعم | - |
| `cfg_scale` | يتحكم في قوة توجيه النص (الافتراضي: 0.5). | FLOAT | نعم | 0.0-1.0 |
| `aspect_ratio` | نسبة العرض إلى الارتفاع للفيديو المُنشأ (الافتراضي: "16:9"). | COMBO | نعم | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | الإعداد المستخدم لتوليد الفيديو وفق التنسيق التالي: mode / duration / model_name. (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | نعم | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**قيود الصورة:**

- يجب توفير كل من `start_frame` و`end_frame`، وألا يتجاوز حجم كل ملف 10MB.
- الحد الأدنى للدقة: 300×300 بكسل لكلتا الصورتين.
- يجب أن تكون نسبة العرض إلى الارتفاع في `start_frame` بين 1:2.5 و2.5:1.
- يجب ألا تتضمن الصور المشفرة بـ Base64 البادئة "data:image".

**قيود النص التوجيهي:**

- يجب ألا يكون `prompt` فارغًا وألا يتجاوز 500 حرف.
- لا يمكن أن يتجاوز `negative_prompt` 500 حرف؛ وعندما يكون فارغًا، لا يُرسل مع الطلب.

**ملاحظات الوضع:**

- يستخدم كلا خياري الوضع النمط pro mode مع نموذج kling-v2-5-turbo، ويختلفان فقط في المدة (5 ثوانٍ أو 10 ثوانٍ).
- التسعير لكل عملية توليد، كما هو موضح في شارة سعر العقدة: يكلّف وضع 5s مبلغ 0.35 دولارًا أمريكيًا، ويكلّف وضع 10s مبلغ 0.70 دولارًا أمريكيًا.
