# كليينج إطار البداية-النهاية إلى فيديو

هذه العقدة تُنشئ تسلسلًا فيديويًا ينتقل بسلاسة بين الصورتين التي تقدّمها كصورة بداية وصورة نهاية. وهي تولّد جميع الإطارات الوسيطة لإنتاج تحوّل سلس من الإطار الأول إلى الإطار الأخير. تستدعي هذه العقدة واجهة برمجة التطبيقات الخاصة بتحويل الصورة إلى فيديو، ولكنها تدعم فقط خيارات الإدخال المتوافقة مع حقل الطلب `image_tail`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | صورة مرجعية - رابط URL أو سلسلة بترميز Base64، لا يتجاوز حجمها 10 ميجابايت، ودقة الوضوح لا تقل عن 300×300 بكسل، ونسبة العرض إلى الارتفاع بين 1:2.5 و 2.5:1. يجب ألا تتضمن سلسلة Base64 بادئة `data:image`. | IMAGE | نعم | - |
| `end_frame` | صورة مرجعية - التحكم في الإطار النهائي. رابط URL أو سلسلة بترميز Base64، لا يتجاوز حجمها 10 ميجابايت، ودقة الوضوح لا تقل عن 300×300 بكسل. يجب ألا تتضمن سلسلة Base64 بادئة `data:image`. | IMAGE | نعم | - |
| `prompt` | النص الموجّه الإيجابي | STRING | نعم | - |
| `negative_prompt` | النص الموجّه السلبي | STRING | نعم | - |
| `cfg_scale` | يتحكم في قوة توجيه النص الموجّه (الافتراضي: 0.5) | FLOAT | لا | 0.0-1.0 |
| `aspect_ratio` | نسبة العرض إلى الارتفاع للفيديو المُنشأ (الافتراضي: "16:9") | COMBO | لا | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | الإعداد المستخدم لتوليد الفيديو وفقًا للصيغة: mode / duration / model_name. (الافتراضي: "pro mode / 5s duration / kling-v2-5-turbo"). جميع الخيارات المتاحة تستخدم الوضع الاحترافي مع نموذج kling-v2-5-turbo وتختلف فقط في مدة الفيديو. | COMBO | لا | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**قيود الصورة:**

- يجب تقديم كل من `start_frame` و `end_frame`، ولا يتجاوز حجم كل منهما 10 ميجابايت
- الحد الأدنى لدقة الوضوح: 300×300 بكسل لكلتا الصورتين
- يجب أن تكون نسبة العرض إلى الارتفاع لـ `start_frame` بين 1:2.5 و 2.5:1
- يجب ألا تتضمن الصور المشفرة بترميز Base64 بادئة "data:image"

**قيود النص الموجّه:**

- يجب ألا يكون النص الموجّه الإيجابي فارغًا
- يقتصر كل من النص الموجّه الإيجابي والسلبي على 500 حرف
- إذا تُرك `negative_prompt` فارغًا، فسيتم حذفه من الطلب

**التسعير:**

- "pro mode / 5s duration / kling-v2-5-turbo": 0.35 دولار أمريكي لكل عملية توليد
- "pro mode / 10s duration / kling-v2-5-turbo": 0.70 دولار أمريكي لكل عملية توليد
