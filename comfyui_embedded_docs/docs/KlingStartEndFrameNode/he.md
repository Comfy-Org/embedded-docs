# Kling התחלה-סיום פריים לווידאו

צומת זה יוצר רצף וידאו שמבצע מעבר בין תמונות ההתחלה והסיום שסיפקת. הוא מייצר את כל הפריימים שביניהן כדי ליצור טרנספורמציה חלקה מהפריים הראשון לפריים האחרון. צומת זה קורא ל-API של image-to-video אך תומך רק באפשרויות הקלט שעובדות עם שדה הבקשה `image_tail`.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | תמונת ייחוס - כתובת URL או מחרוזת מקודדת Base64, לא יכולה לעלות על 10MB, רזולוציה לא פחות מ-300*300px, יחס גובה-רוחב בין 1:2.5 ~ 2.5:1. ב-Base64 אין לכלול את הקידומת data:image. | IMAGE | כן | - |
| `end_frame` | תמונת ייחוס - בקרת פריים סיום. כתובת URL או מחרוזת מקודדת Base64, לא יכולה לעלות על 10MB, רזולוציה לא פחות מ-300*300px. ב-Base64 אין לכלול את הקידומת data:image. | IMAGE | כן | - |
| `prompt` | פרומפט טקסט חיובי. לא יכול להיות ריק ולא יכול לעלות על 500 תווים. | STRING | כן | - |
| `negative_prompt` | פרומפט טקסט שלילי. לא יכול לעלות על 500 תווים. אם יישאר ריק, הוא יושמט מהבקשה. | STRING | כן | - |
| `cfg_scale` | שולט בעוצמת הכוונת הפרומפט (ברירת מחדל: 0.5). | FLOAT | כן | 0.0-1.0 |
| `aspect_ratio` | יחס גובה-רוחב של הווידאו המיוצר (ברירת מחדל: "16:9"). | COMBO | כן | "16:9"<br>"9:16"<br>"1:1" |
| `mode` | התצורה שבה יש להשתמש ליצירת הווידאו לפי הפורמט: mode / duration / model_name. (ברירת מחדל: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | כן | "pro mode / 5s duration / kling-v2-5-turbo"<br>"pro mode / 10s duration / kling-v2-5-turbo" |

**מגבלות תמונה:**

- גם `start_frame` וגם `end_frame` נדרשים ולא יכולים לעלות על 10MB בגודל הקובץ.
- רזולוציה מינימלית: 300×300 פיקסלים עבור שתי התמונות.
- יחס הגובה-רוחב של `start_frame` חייב להיות בין 1:2.5 ל-2.5:1.
- תמונות מקודדות Base64 לא צריכות לכלול את הקידומת "data:image".

**מגבלות פרומפט:**

- `prompt` לא יכול להיות ריק ולא יכול לעלות על 500 תווים.
- `negative_prompt` לא יכול לעלות על 500 תווים; כאשר הוא ריק, הוא לא נשלח עם הבקשה.

**הערות מצב:**

- שתי אפשרויות ה-mode משתמשות ב-pro mode עם המודל kling-v2-5-turbo ונבדלות רק במשך (5 שניות או 10 שניות).
- תמחור לכל יצירה, כפי שמוצג בתג המחיר של הצומת: מצב 5s עולה $0.35 USD ומצב 10s עולה $0.70 USD.
