# SetHookKeyframes

צומת Set Hook Keyframes מאפשר להחיל תזמון פריימי מפתח על קבוצות hook קיימות. הוא מקבל קבוצת hook, ובאופן אופציונלי מחיל מידע תזמון של פריימי מפתח כדי לשלוט מתי hooks שונים מורצים במהלך תהליך היצירה. כאשר מסופקים פריימי מפתח, הצומת משכפל את קבוצת ה-hook ומגדיר את תזמון פריימי המפתח בכל ה-hooks שבקבוצה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `hooks` | קבוצת ה-hook שאליה יוחל תזמון פריימי המפתח | HOOKS | כן | - |
| `hook_kf` | קבוצת פריימי מפתח אופציונלית המכילה מידע תזמון להרצת ה-hooks | HOOK_KEYFRAMES | לא | - |
