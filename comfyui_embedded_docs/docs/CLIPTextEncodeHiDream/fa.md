# CLIPTextEncodeHiDream

گره CLIPTextEncodeHiDream چهار ورودی متنی جداگانه را با استفاده از مدل‌های زبانی مختلف (CLIP-L، CLIP-G، T5-XXL و LLaMA) پردازش می‌کند و آن‌ها را در یک خروجی Conditioning ترکیب می‌کند. این گره هر ورودی متنی را با مدل مربوطه توکن‌سازی کرده و آن‌ها را با استفاده از رویکرد رمزگذاری زمان‌بندی‌شده با هم رمزگذاری می‌کند و با بهره‌گیری هم‌زمان از چندین مدل زبانی، شرطی‌سازی متنی پیچیده‌تری را ممکن می‌سازد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |
| `clip_l` | ورودی متن برای پردازش مدل CLIP-L. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `clip_g` | ورودی متن برای پردازش مدل CLIP-G. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متن برای پردازش مدل T5-XXL. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `llama` | ورودی متن برای پردازش مدل LLaMA. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |

**نکته:** هر چهار ورودی متن (`clip_l`، `clip_g`، `t5xxl` و `llama`) برای عملکرد صحیح الزامی هستند، زیرا هر یک از طریق فرآیند رمزگذاری زمان‌بندی‌شده به خروجی Conditioning نهایی کمک می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | خروجی Conditioning ترکیبی از تمام ورودی‌های متنی پردازش‌شده، رمزگذاری‌شده با استفاده از روش رمزگذاری زمان‌بندی‌شده | CONDITIONING |
