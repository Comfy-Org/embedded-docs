# CLIPTextEncodeHiDream

گره CLIPTextEncodeHiDream چهار ورودی متنی جداگانه را با استفاده از مدل‌های زبانی مختلف (CLIP-L، CLIP-G، T5-XXL و LLaMA) پردازش می‌کند و آن‌ها را در یک خروجی شرطی‌سازی ترکیب می‌کند. این گره هر ورودی متنی را با مدل متناظر آن توکنایز می‌کند و با استفاده از رویکرد رمزگذاری زمان‌بندی‌شده، آن‌ها را با هم رمزگذاری می‌کند و با بهره‌گیری همزمان از چندین مدل زبانی، شرطی‌سازی متنی دقیق‌تری را ممکن می‌سازد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنایز و رمزگذاری | CLIP | بله | - |
| `clip_l` | ورودی متنی برای پردازش مدل CLIP-L. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `clip_g` | ورودی متنی برای پردازش مدل CLIP-G. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متنی برای پردازش مدل T5-XXL. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `llama` | ورودی متنی برای پردازش مدل LLaMA. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |

**توجه:** هر چهار ورودی متنی (`clip_l`، `clip_g`، `t5xxl` و `llama`) برای عملکرد صحیح الزامی هستند، زیرا هر یک از طریق فرآیند رمزگذاری زمان‌بندی‌شده به خروجی نهایی شرطی‌سازی کمک می‌کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | خروجی شرطی‌سازی ترکیبی از تمام ورودی‌های متنی پردازش‌شده، که با استفاده از روش رمزگذاری زمان‌بندی‌شده رمزگذاری شده است | CONDITIONING |
