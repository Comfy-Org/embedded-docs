# קידוד טקסט CLIP (HiDream)

הצומת CLIPTextEncodeHiDream מעבד ארבעה קלטי טקסט נפרדים באמצעות מודלי שפה שונים (CLIP-L, CLIP-G, T5-XXL ו-LLaMA) ומשלב אותם לפלט קונדישנינג יחיד. הוא מבצע טוקניזציה לכל קלט טקסט עם המודל המתאים לו ומקודד אותם יחד באמצעות גישת קידוד מתוזמן, מה שמאפשר קונדישנינג טקסט מתוחכם יותר על ידי ניצול מספר מודלי שפה בו-זמנית.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה ולקידוד | CLIP | כן | - |
| `clip_l` | קלט טקסט לעיבוד במודל CLIP-L. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `clip_g` | קלט טקסט לעיבוד במודל CLIP-G. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `t5xxl` | קלט טקסט לעיבוד במודל T5-XXL. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |
| `llama` | קלט טקסט לעיבוד במודל LLaMA. תומך בטקסט רב-שורתי ובפרומפטים דינמיים. | STRING | כן | - |

**הערה:** כל ארבעת קלטי הטקסט (`clip_l`, `clip_g`, `t5xxl` ו-`llama`) נדרשים לתפקוד תקין, שכן כל אחד מהם תורם לפלט הקונדישנינג הסופי באמצעות תהליך הקידוד המתוזמן.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | פלט הקונדישנינג המשולב מכל קלטי הטקסט המעובדים, המקודד באמצעות שיטת הקידוד המתוזמן | CONDITIONING |
