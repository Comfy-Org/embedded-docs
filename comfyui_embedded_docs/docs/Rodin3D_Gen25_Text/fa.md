# Rodin 3D Gen-2.5 - تبدیل متن به مدل سه‌بعدی

## مرور کلی

تولید یک مدل سه‌بعدی از یک متن درخواست با استفاده از API Rodin Gen-2.5. می‌توانید بین حالت‌های مختلف کیفیت (Fast، Regular یا Extreme-High) برای توازن بین سرعت تولید و کیفیت خروجی انتخاب کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `متن ورودی` | متن درخواست برای مدل سه‌بعدی. | STRING | بله | 1 تا 1024 کاراکتر |
| `حالت` | حالت کیفیت و سرعت تولید. «Fast» سریع‌ترین است، «Extreme-High» بالاترین کیفیت را تولید می‌کند اما زمان بیشتری می‌برد. | COMBO | بله | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `جنس` | سبک متریال برای مدل سه‌بعدی تولیدشده. | COMBO | بله | `"PBR"`<br>`"Matte"`<br>`"Shiny"` |
| `فرمت فایل هندسه` | قالب فایل برای مدل سه‌بعدی خروجی. | COMBO | بله | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `حالت بافت` | حالت تولید بافت. «None» هیچ بافتی تولید نمی‌کند، «Generated» بافت‌های استاندارد ایجاد می‌کند، «Generated+HD» بافت‌های با کیفیت بالا ایجاد می‌کند. | COMBO | بله | `"None"`<br>`"Generated"`<br>`"Generated+HD"` |
| `seed` | دانه تصادفی برای نتایج قابل تکرار. استفاده از همان دانه با همان ورودی‌ها خروجی یکسانی تولید می‌کند. | INT | بله | 0 تا 2147483647 |
| `T/A pose` | آیا حالت T (دست‌های کشیده) به مدل تولیدشده اعمال شود. | BOOLEAN | بله | True یا False |
| `افزایش کیفیت بافت` | آیا بافت‌های با کیفیت بالا برای مدل تولید شود. | BOOLEAN | بله | True یا False |
| `حذف نورپردازی بافت` | آیا درخشش بافت (کیفیت بافت بهبودیافته) به مدل اعمال شود. | BOOLEAN | بله | True یا False |
| `افزونه HighPack` | آیا نسخه پرچندضلعی مدل علاوه بر نسخه استاندارد تولید شود. | BOOLEAN | بله | True یا False |
| `عرض جعبه محدودکننده` | عرض جعبه احاطه‌کننده بر حسب واحدهای جهانی. | INT | بله | 1 تا 1000 |
| `ارتفاع جعبه محدودکننده` | ارتفاع جعبه احاطه‌کننده بر حسب واحدهای جهانی. | INT | بله | 1 تا 1000 |
| `طول جعبه محدودکننده` | طول جعبه احاطه‌کننده بر حسب واحدهای جهانی. | INT | بله | 1 تا 1000 |
| `ارتفاع مدل (سانتی‌متر)` | ارتفاع مدل تولیدشده بر حسب سانتی‌متر. | INT | بله | 1 تا 300 |

**توجه:** پارامتر `prompt` باید بین 1 تا 1024 کاراکتر باشد. پارامتر `seed` در صورت عدم مشخص شدن، به‌طور پیش‌فرض 0 (تصادفی) است.
