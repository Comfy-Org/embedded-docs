# Rodin 3D Gen-2.5 - טקסט ל-3D

## סקירה כללית

צור מודל תלת-ממד מפרומפט טקסטואלי באמצעות ה-API של Rodin Gen-2.5. ניתן לבחור בין מצבי איכות שונים (Fast, Regular או Extreme-High) כדי לאזן בין מהירות היצירה לאיכות הפלט.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-------|-------|----------|------|------|
| `prompt` | פרומפט טקסטואלי למודל התלת-ממד. | STRING | כן | 1 עד 1024 תווים |
| `mode` | מצב איכות ומהירות היצירה. "Fast" הוא המהיר ביותר, "Extreme-High" מפיק את האיכות הגבוהה ביותר אך אורך יותר זמן. | COMBO | כן | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `material` | סגנון החומר עבור המודל התלת-ממדי שנוצר. | COMBO | כן | `"PBR"`<br>`"Matte"`<br>`"Shiny"` |
| `geometry_file_format` | פורמט הקובץ עבור מודל התלת-ממד הפלט. | COMBO | כן | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `texture_mode` | מצב יצירת טקסטורות. "None" לא מייצר טקסטורות, "Generated" יוצר טקסטורות סטנדרטיות, "Generated+HD" יוצר טקסטורות באיכות גבוהה במיוחד. | COMBO | כן | `"None"`<br>`"Generated"`<br>`"Generated+HD"` |
| `seed` | זרע אקראי לתוצאות ניתנות לשחזור. שימוש באותו זרע עם אותם קלטים יפיק את אותו פלט. | INT | כן | 0 עד 2147483647 |
| `TAPose` | האם להחיל תנוחת T (ידיים פרושות) על המודל שנוצר. | BOOLEAN | כן | True או False |
| `hd_texture` | האם ליצור טקסטורות באיכות גבוהה במיוחד עבור המודל. | BOOLEAN | כן | True או False |
| `texture_delight` | האם להחיל delight טקסטורה (איכות טקסטורה משופרת) על המודל. | BOOLEAN | כן | True או False |
| `addon_highpack` | האם ליצור גרסה בעלת מספר פוליגונים גבוה של המודל בנוסף לסטנדרטית. | BOOLEAN | כן | True או False |
| `bbox_width` | רוחב תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `bbox_height` | גובה תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `bbox_length` | אורך תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `height_cm` | גובה המודל שנוצר בסנטימטרים. | INT | כן | 1 עד 300 |

**הערה:** הפרמטר `prompt` חייב להיות באורך של בין 1 ל-1024 תווים. הפרמטר `seed` מוגדר כברירת מחדל ל-0 (אקראי) אם לא צוין.
