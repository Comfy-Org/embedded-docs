# Rodin 3D Gen-2.5 - טקסט ל-3D

## סקירה כללית

יצירת מודל תלת-ממדי מפרומפט טקסטואלי באמצעות ה-API של Rodin Gen-2.5. ניתן לבחור בין מצבי איכות שונים (Fast, Regular או Extreme-High) כדי לאזן בין מהירות היצירה לאיכות הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסטואלי עבור המודל התלת-ממדי. | STRING | כן | 1 עד 2500 תווים |
| `mode` | מצב איכות ומהירות היצירה. "Fast" הוא המהיר ביותר, "Extreme-High" מפיק את האיכות הגבוהה ביותר אך אורך יותר זמן. | COMBO | כן | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `material` | סגנון החומר של המודל התלת-ממדי המיוצר. | COMBO | כן | `"PBR"`<br>`"Matte"`<br>`"Shiny"` |
| `geometry_file_format` | פורמט הקובץ של המודל התלת-ממדי בפלט. | COMBO | כן | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `texture_mode` | מצב יצירת טקסטורות. "None" לא מייצר טקסטורות, "Generated" יוצר טקסטורות סטנדרטיות, "Generated+HD" יוצר טקסטורות באיכות גבוהה במיוחד. | COMBO | כן | `"None"`<br>`"Generated"`<br>`"Generated+HD"` |
| `seed` | זרע אקראי לתוצאות ניתנות לשחזור. שימוש באותו זרע עם אותם קלטים יפיק את אותה תוצאה. | INT | כן | 0 עד 2147483647 |
| `TAPose` | האם להחיל תנוחת T-pose (זרועות פרושות) על המודל המיוצר. | BOOLEAN | כן | True / False |
| `hd_texture` | האם ליצור טקסטורות באיכות גבוהה במיוחד עבור המודל. | BOOLEAN | כן | True / False |
| `texture_delight` | האם להחיל texture delight (איכות טקסטורה משופרת) על המודל. | BOOLEAN | כן | True / False |
| `addon_highpack` | האם ליצור גרסה בעלת מספר פוליגונים גבוה של המודל בנוסף לגרסה הסטנדרטית. | BOOLEAN | כן | True / False |
| `bbox_width` | רוחב תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `bbox_height` | הגובה של תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `bbox_length` | האורך של תיבת התיחום ביחידות עולם. | INT | כן | 1 עד 1000 |
| `height_cm` | הגובה של המודל המיוצר בסנטימטרים. | INT | כן | 1 עד 300 |

**הערה:** הפרמטר `prompt` חייב להיות באורך שבין 1 ל-2500 תווים. הפרמטר `seed` מוגדר כברירת מחדל ל-0 (אקראי) אם לא צוין.
