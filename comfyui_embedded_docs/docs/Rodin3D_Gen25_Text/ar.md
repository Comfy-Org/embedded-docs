# Rodin 3D Gen-2.5 - تحويل النص إلى نموذج ثلاثي الأبعاد

## نظرة عامة

إنشاء نموذج ثلاثي الأبعاد من نص موجه باستخدام Rodin Gen-2.5 API. يمكنك الاختيار بين أوضاع جودة مختلفة (Fast، Regular، أو Extreme-High) لموازنة سرعة الإنشاء وجودة المخرجات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الوصف النصي` | نص موجه للنموذج ثلاثي الأبعاد. | STRING | نعم | 1 إلى 1024 حرفًا |
| `الوضع` | وضع جودة وسرعة الإنشاء. "Fast" هو الأسرع، "Extreme-High" ينتج أعلى جودة لكنه يستغرق وقتًا أطول. | COMBO | نعم | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `الخامة` | نمط المادة للنموذج ثلاثي الأبعاد المُنشأ. | COMBO | نعم | `"PBR"`<br>`"Matte"`<br>`"Shiny"` |
| `صيغة ملف الهندسة` | صيغة ملف النموذج ثلاثي الأبعاد الناتج. | COMBO | نعم | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `وضع الخامة` | وضع إنشاء الملمس. "None" لا ينتج أي ملامس، "Generated" ينشئ ملامس قياسية، "Generated+HD" ينشئ ملامس عالية الدقة. | COMBO | نعم | `"None"`<br>`"Generated"`<br>`"Generated+HD"` |
| `البذرة` | بذرة عشوائية لنتائج قابلة للتكرار. استخدام نفس البذرة مع نفس المدخلات سينتج نفس المخرجات. | INT | نعم | 0 إلى 2147483647 |
| `وضعية T/A` | ما إذا كان سيتم تطبيق وضع T (الذراعان ممدودتان) على النموذج المُنشأ. | BOOLEAN | نعم | True / False |
| `خامة عالية الجودة` | ما إذا كان سيتم إنشاء ملامس عالية الدقة للنموذج. | BOOLEAN | نعم | True / False |
| `إزالة الإضاءة من الخامة` | ما إذا كان سيتم تطبيق تحسين الملمس (جودة ملمس معززة) على النموذج. | BOOLEAN | نعم | True / False |
| `إضافة HighPack` | ما إذا كان سيتم إنشاء نسخة عالية المضلعات من النموذج بالإضافة إلى النسخة القياسية. | BOOLEAN | نعم | True / False |
| `عرض الصندوق المحيط` | عرض الصندوق المحيط بوحدات العالم. | INT | نعم | 1 إلى 1000 |
| `ارتفاع الصندوق المحيط` | ارتفاع الصندوق المحيط بوحدات العالم. | INT | نعم | 1 إلى 1000 |
| `طول الصندوق المحيط` | طول الصندوق المحيط بوحدات العالم. | INT | نعم | 1 إلى 1000 |
| `الارتفاع (سم)` | ارتفاع النموذج المُنشأ بالسنتيمتر. | INT | نعم | 1 إلى 300 |

**ملاحظة:** يجب أن يكون طول المعامل `prompt` بين 1 و 1024 حرفًا. المعامل `seed` افتراضيًا 0 (عشوائي) إذا لم يُحدد.
