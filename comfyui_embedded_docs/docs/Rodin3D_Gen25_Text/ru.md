# Rodin 3D Gen-2.5 — Текст в 3D

## Обзор

Создайте 3D-модель по текстовому запросу с помощью API Rodin Gen-2.5. Вы можете выбрать один из режимов качества (Fast, Regular или Extreme-High), чтобы сбалансировать скорость генерации и качество результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для 3D-модели. | STRING | Да | от 1 до 1024 символов |
| `mode` | Режим качества и скорости генерации. «Fast» — самый быстрый; «Extreme-High» обеспечивает наивысшее качество, но занимает больше времени. | COMBO | Да | `"Fast"`<br>`"Regular"`<br>`"Extreme-High"` |
| `material` | Стиль материала для сгенерированной 3D-модели. | COMBO | Да | `"PBR"`<br>`"Matte"`<br>`"Shiny"` |
| `geometry_file_format` | Формат файла для выходной 3D-модели. | COMBO | Да | `"glb"`<br>`"obj"`<br>`"stl"`<br>`"usdz"` |
| `texture_mode` | Режим генерации текстур. «None» не создаёт текстуры, «Generated» создаёт стандартные текстуры, «Generated+HD» создаёт текстуры высокой чёткости. | COMBO | Да | `"None"`<br>`"Generated"`<br>`"Generated+HD"` |
| `seed` | Случайное зерно для воспроизводимых результатов. Использование одного и того же зерна с одинаковыми входными данными приведёт к одному и тому же результату. | INT | Да | от 0 до 2147483647 |
| `TAPose` | Применять ли T-позу (руки разведены в стороны) к сгенерированной модели. | BOOLEAN | Да | True / False |
| `hd_texture` | Создавать ли для модели текстуры высокой чёткости. | BOOLEAN | Да | True / False |
| `texture_delight` | Применять ли функцию texture delight (повышенное качество текстур) к модели. | BOOLEAN | Да | True / False |
| `addon_highpack` | Создавать ли высокополигональную версию модели в дополнение к стандартной. | BOOLEAN | Да | True / False |
| `bbox_width` | Ширина ограничивающей рамки в мировых единицах. | INT | Да | от 1 до 1000 |
| `bbox_height` | Высота ограничивающей рамки в мировых единицах. | INT | Да | от 1 до 1000 |
| `bbox_length` | Длина ограничивающей рамки в мировых единицах. | INT | Да | от 1 до 1000 |
| `height_cm` | Высота сгенерированной модели в сантиметрах. | INT | Да | от 1 до 300 |

**Примечание:** Длина параметра `prompt` должна составлять от 1 до 1024 символов. Если параметр `seed` не указан, по умолчанию используется 0 (случайное значение).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Сгенерированный файл 3D-модели в указанном формате. | FILE3DANY |
