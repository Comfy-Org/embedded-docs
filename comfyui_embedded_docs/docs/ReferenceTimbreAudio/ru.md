# ReferenceTimbreAudio

Этот узел задаёт эталонное аудио для процесса «ace step 1.5». Он принимает вход `conditioning` и, опционально, латентное представление аудио, после чего присоединяет эти латентные данные к conditioning, чтобы последующие узлы могли использовать их как латентные представления тембра эталонного аудио. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные conditioning, к которым будет присоединена информация об эталонном аудио. | CONDITIONING | Да |  |
| `latent` | Опциональное латентное представление эталонного аудио (по умолчанию: None). Если оно предоставлено, его сэмплы добавляются к conditioning как латентные представления тембра эталонного аудио. | LATENT | Нет |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Изменённые данные conditioning, теперь содержащие латентные представления тембра эталонного аудио, если был предоставлен опциональный вход `latent`. | CONDITIONING |
