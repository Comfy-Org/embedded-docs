# ReferenceTimbreAudio

Этот узел задаёт эталонный тембр аудио для использования в процессе «ace step 1.5». Он работает путём приёма conditioning-входа и, опционально, латентного представления аудио, после чего присоединяет эти латентные данные к conditioning для использования последующими узлами рабочего процесса. В настоящее время узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные conditioning, к которым будет присоединена информация об эталонном аудио. | CONDITIONING | Да |  |
| `latent` | Необязательное латентное представление эталонного аудио. Если оно указано, его сэмплы добавляются (присоединяются) к conditioning, чтобы использоваться как латентные представления тембра эталонного аудио. | LATENT | Нет |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Модифицированные данные conditioning, теперь содержащие латентные представления тембра эталонного аудио, если был указан необязательный вход `latent`. | CONDITIONING |
