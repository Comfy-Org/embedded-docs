# ReferenceTimbreAudio

Этот узел задает тембр эталонного аудио для использования в процессе "ace step 1.5". Он принимает входное кондиционирование и опциональное латентное представление аудио, затем присоединяет эти латентные данные к кондиционированию, чтобы последующие узлы рабочего процесса могли использовать их в качестве эталонного аудио. Если латентное представление не предоставлено, кондиционирование возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Данные кондиционирования, к которым будет присоединена информация об эталонном аудио. | CONDITIONING | Да |  |
| `latent` | Необязательное латентное представление эталонного аудио. При наличии его сэмплы добавляются к кондиционированию. | LATENT | Нет |  |

Когда `latent` предоставлен, его сэмплы добавляются к латентным представлениям тембра эталонного аудио в кондиционировании. Если `latent` не предоставлен, исходное кондиционирование передается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Измененные данные кондиционирования, теперь содержащие латентные представления тембра эталонного аудио, если был предоставлен дополнительный вход `latent`. Если латентное представление не предоставлено, исходное кондиционирование возвращается без изменений. | CONDITIONING |
