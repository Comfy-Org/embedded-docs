# Veo3FirstLastFrameNode

הצומת Veo3FirstLastFrameNode משתמש במודל Veo 3 של Google כדי ליצור וידאו על בסיס פרומפט טקסטואלי, עם פריים ראשון ופריים אחרון שסופקו, אשר מגדירים את ההתחלה ואת הסוף של רצף הווידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | תיאור טקסטואלי של הווידאו (ברירת מחדל: מחרוזת ריקה). | STRING | כן | N/A |
| `negative_prompt` | פרומפט טקסטואלי שלילי שמנחה מה להימנע ממנו בווידאו (ברירת מחדל: מחרוזת ריקה). | STRING | לא | N/A |
| `resolution` | הרזולוציה של וידאו הפלט. | COMBO | כן | `"720p"`<br>`"1080p"`<br>`"4k"` |
| `aspect_ratio` | יחס הגובה-רוחב של וידאו הפלט (ברירת מחדל: "16:9"). | COMBO | לא | `"16:9"`<br>`"9:16"` |
| `duration` | משך וידאו הפלט בשניות (ברירת מחדל: 8, צעד: 2). | INT | לא | 4 עד 8 |
| `seed` | Seed ליצירת הווידאו (ברירת מחדל: 0). | INT | לא | 0 עד 4294967295 |
| `first_frame` | פריים ההתחלה של הווידאו. | IMAGE | כן | N/A |
| `last_frame` | פריים הסיום של הווידאו. | IMAGE | כן | N/A |
| `model` | מודל ה-Veo הספציפי לשימוש ביצירה (ברירת מחדל: "veo-3.1-generate"). | COMBO | לא | `"veo-3.1-generate"`<br>`"veo-3.1-fast-generate"`<br>`"veo-3.1-lite"` |
| `generate_audio` | יצירת אודיו עבור הווידאו (ברירת מחדל: True). | BOOLEAN | לא | N/A |

**הערה:** המודל `veo-3.1-lite` אינו תומך ברזולוציית 4K. אם תבחרו ב-`veo-3.1-lite` וברזולוציית `4k`, תתרחש שגיאה.
