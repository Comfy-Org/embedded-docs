# MiniMax H3 參考轉影片

「MiniMax H3 Reference to Video」節點會建立 MiniMax H3 參考轉影片生成所需的文字條件化與空音訊-影片潛在表示。您提供提示詞以及可選的參考影像、影片和音訊片段，節點會將這些參考編碼為模型在生成時可使用的 token。提示詞使用 `<Picture i>`、`<Video k>` 和 `<Audio j>` 標籤來引用參考內容。

備註：

- 提示詞使用每種類型從 1 開始的標籤來引用參考媒體：影像用 `<Picture i>`，影片用 `<Video k>`，音訊用 `<Audio j>`。參考媒體會以固定順序呈現給模型：先是影像，接著是影片（每個音軌的 `<Audio j>` 標籤緊接在其 `<Video k>` 之前），最後是獨立音訊。
- 參考影片必須至少包含 5 個影格（24 fps 下約 0.2 秒），否則節點會回報錯誤。影片影格也會受限於所選的 `length`，並會修剪為支援的影格數。
- 要求的 `length` 會在建立潛在表示前對齊至支援的影格數。
