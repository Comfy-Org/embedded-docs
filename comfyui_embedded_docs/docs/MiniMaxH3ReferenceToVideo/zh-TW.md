# MiniMax H3 參考轉影片

MiniMax H3 Reference to Video 建立文字條件與空白影片潛在表示，用於 MiniMax H3 參考影片生成。您提供提示詞以及可選的參考圖片、影片與音訊片段，節點會將這些參考編碼為模型在生成時可使用的 token。提示詞使用 `<Picture i>`、`<Video k>` 與 `<Audio j>` 標籤來引用參考內容。

- 提示詞使用每種類型從 1 開始的標籤引用參考媒體：`<Picture i>` 代表圖片，`<Video k>` 代表影片，`<Audio j>` 代表音訊。參考內容以固定順序呈現給模型：先是圖片，接著是影片（每段配樂的 `<Audio j>` 標籤緊接在對應的 `<Video k>` 之前），最後是獨立音訊。
