# MiniMax H3 參考轉影片

MiniMax H3 Reference to Video 會建立 MiniMax H3 參考轉影片生成所需的文字條件與空白音訊視訊潛在表示。您提供提示詞，以及可選的參考圖片、影片與音訊片段，節點會將這些參考內容編碼成模型生成時可使用的條件。提示詞會使用 `<Picture i>`、`<Video k>` 和 `<Audio j>` 標籤來參照參考內容。

備註：

- 提示詞會使用每種類型從 1 開始計數的標籤來參照參考媒體：圖片使用 `<Picture i>`、影片使用 `<Video k>`、音訊使用 `<Audio j>`。參考內容會以固定順序提供給模型：先圖片，再影片（每條音訊軌的 `<Audio j>` 標籤會緊接在其 `<Video k>` 之前），最後是獨立音訊。
- 連接到 `ref_video_audio_N` 的音訊軌會與連接到 `ref_video_N` 的參考影片搭配使用。
- 參考影片必須包含至少 5 個影格（24 fps 下約 0.2 秒），否則節點會引發錯誤。超出所要求 `length` 的影格會被修剪，剩餘影格數會調整為模型支援的值。
- 所要求的 `length` 會在建立潛在表示之前對齊至支援的影格數。
- 若沒有 `vae`，參考圖片與影片只會對文字編碼器進行條件化（不會產生參考潛在表示）。若沒有 `audio_vae`，參考音訊只會對文字編碼器進行條件化。
