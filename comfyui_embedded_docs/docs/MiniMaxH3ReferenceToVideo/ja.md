# MiniMax H3 リファレンスから動画へ

MiniMax H3 Reference to Video は、MiniMax H3 のリファレンス・トゥ・ビデオ生成に必要なテキスト条件付け（text conditioning）と空のオーディオ・ビデオ潜在変数（latent）を作成します。プロンプトに加えて、オプションの参照画像・動画・音声クリップを指定すると、ノードはこれらの参照をモデルが生成中に使用できるトークンにエンコードします。プロンプトは、`<Picture i>`、`<Video k>`、`<Audio j>` タグで参照メディアを指定します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトのトークン化と参照メディアの条件付けトークンへのエンコードに使用されるCLIPモデル。 | CLIP | 必須 | |
| `vae` | 参照画像と参照動画フレームを潜在空間にエンコードするために使用されるVAE。 | VAE | 必須 | |
| `audio_vae` | 参照音声を潜在空間にエンコードするために使用されるVAE（32 kHzの音声サンプルレート）。 | VAE | 必須 | |
| `prompt` | 動画用のテキストプロンプト。参照メディアは `<Picture i>`、`<Video k>`、`<Audio j>` タグ（各タイプごとに1から始まる番号）で指定できます。複数行および動的プロンプトに対応しています。 | STRING | 必須 | |
| `width` | 生成される動画の幅（ピクセル単位、デフォルト: 1344）。 | INT | 必須 | 32 to 16384 (step 32) |
| `height` | 生成される動画の高さ（ピクセル単位、デフォルト: 768）。 | INT | 必須 | 32 to 16384 (step 32) |
| `length` | 24 fps でのフレーム数。124 = 約5秒、トレーニング範囲は約124〜362（デフォルト: 124）。 | INT | 必須 | 5 to 3600 (step 17) |
| `ref_image_size` | 参照画像のサイズ調整モード。`match` は各参照画像をアスペクト比を維持したまま、生成画像のピクセル面積に合わせて縮小のみ行います。`max` は参照パイプラインの2048pxの短辺を使用し、人物同一性の忠実度を最優先します。参照トークンはすべてのサンプリングステップで保持されるため、`max` は数倍遅くなることがあります（デフォルト: `match`）。 | COMBO | 必須 | `"match"`<br>`"max"` |
| `ref_images` | オプションの参照画像。各画像は、大きい場合は2048pxの短辺に縮小され、拡大はされません。複数の画像を指定できます。 | IMAGE | 任意 | 0 to 9 |
| `ref_videos` | オプションの参照動画フレーム（24 fps、2〜15秒）。複数の動画を指定できます。 | IMAGE | 任意 | 0 to 3 |
| `ref_video_audios` | インデックスによって参照動画とペアになるオプションのサウンドトラック。`ref_video_audio_N` は同じ番号の `ref_video_N` のサウンドトラックです。 | AUDIO | 任意 | 0 to 3 |
| `ref_audios` | オプションの単独参照音声クリップ。 | AUDIO | 任意 | 0 to 3 |

注記:
- プロンプトは、参照メディアを各タイプごとに1から始まるタグで指定します。`<Picture i>` は画像、`<Video k>` は動画、`<Audio j>` は音声を指します。参照メディアは、固定の順序でモデルに提示されます。最初に画像、次に動画（各サウンドトラックの `<Audio j>` ラベルは対応する `<Video k>` の直前）、最後に単独の音声の順です。
- 参照動画には少なくとも5フレーム（24 fpsで約0.2秒）が必要です。それ以外の場合、ノードはエラーを発生させます。動画フレームは選択された `length` に上限が設定され、サポートされているフレーム数に切り詰められます。
