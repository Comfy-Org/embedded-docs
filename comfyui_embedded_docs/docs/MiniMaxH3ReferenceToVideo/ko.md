# MiniMax H3 참조 → 비디오

MiniMax H3 Reference to Video 노드는 MiniMax H3 참조-투-비디오 생성에 필요한 텍스트 컨디셔닝과 빈 오디오-비디오 잠재 변수(latent)를 생성합니다. 프롬프트와 선택적 참조 이미지, 비디오, 오디오 클립을 제공하면 노드는 이러한 참조를 모델이 생성 중에 사용할 수 있는 토큰으로 인코딩합니다. 프롬프트는 `<Picture i>`, `<Video k>`, `<Audio j>` 태그를 사용하여 참조 미디어를 지칭합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 프롬프트를 토큰화하고 참조 미디어를 컨디셔닝 토큰으로 인코딩하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | |
| `vae` | 참조 이미지와 참조 비디오 프레임을 잠재 공간으로 인코딩하는 데 사용되는 VAE입니다. | VAE | 예 | |
| `audio_vae` | 참조 오디오를 잠재 공간으로 인코딩하는 데 사용되는 VAE입니다(32kHz 오디오 샘플 레이트). | VAE | 예 | |
| `prompt` | 비디오에 대한 텍스트 프롬프트입니다. 참조 미디어는 `<Picture i>`, `<Video k>`, `<Audio j>` 태그로 지정할 수 있습니다(각 유형별로 1부터 시작). 여러 줄 및 동적 프롬프트를 지원합니다. | STRING | 예 | |
| `width` | 생성되는 비디오의 픽셀 단위 너비입니다(기본값: 1344). | INT | 예 | 32 to 16384 (step 32) |
| `height` | 생성되는 비디오의 픽셀 단위 높이입니다(기본값: 768). | INT | 예 | 32 to 16384 (step 32) |
| `length` | 24fps에서의 프레임 수입니다. 124 = 약 5초, 학습된 범위는 약 124-362입니다(기본값: 124). | INT | 예 | 5 to 3600 (step 17) |
| `ref_image_size` | 참조 이미지 크기 조정 모드입니다. `match`는 각 참조 이미지를 가로세로 비율을 유지하면서 생성 픽셀 영역으로 축소만 합니다. `max`는 최상의 정체성 충실도를 위해 참조 파이프라인의 2048px 짧은 변을 사용합니다. 참조 토큰은 모든 샘플링 단계를 통과하므로 `max`는 몇 배 더 느릴 수 있습니다(기본값: `match`). | COMBO | 예 | `"match"`<br>`"max"` |
| `ref_images` | 선택적 참조 이미지입니다. 각 이미지는 더 큰 경우 2048px 짧은 변으로 축소되며 확대되지는 않습니다. 여러 이미지를 제공할 수 있습니다. | IMAGE | 아니요 | 0 to 9 |
| `ref_videos` | 24fps의 선택적 참조 비디오 프레임입니다(2-15초). 여러 비디오를 제공할 수 있습니다. | IMAGE | 아니요 | 0 to 3 |
| `ref_video_audios` | 참조 비디오와 인덱스로 짝을 이루는 선택적 사운드트랙입니다. `ref_video_audio_N`은 같은 번호의 `ref_video_N`의 사운드트랙입니다. | AUDIO | 아니요 | 0 to 3 |
| `ref_audios` | 선택적 독립 참조 오디오 클립입니다. | AUDIO | 아니요 | 0 to 3 |

참고:
- 프롬프트는 유형별로 1부터 시작하는 태그를 사용하여 참조 미디어를 지칭합니다. `<Picture i>`는 이미지, `<Video k>`는 비디오, `<Audio j>`는 오디오입니다. 참조는 이미지, 그 다음 비디오(각 사운드트랙의 `<Audio j>` 레이블은 해당 `<Video k>` 바로 앞에 위치), 마지막으로 독립 오디오 순서로 모델에 제공됩니다.
- 참조 비디오에는 최소 5프레임(24fps에서 약 0.2초)이 포함되어야 하며, 그렇지 않으면 노드에서 오류가 발생합니다. 비디오 프레임은 선택한 `length`로 제한되고 지원되는 프레임 수로 잘립니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 인코딩된 프롬프트와 MiniMax H3 모델이 사용하는 인코딩된 참조 이미지, 비디오 및 오디오 토큰을 포함하는 컨디셔닝입니다. | CONDITIONING |
| `latent` | 요청된 `width`, `height`, `length`(프레임 수)에 해당하는 빈 오디오-비디오 잠재 변수입니다. | LATENT |
