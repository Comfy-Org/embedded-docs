# MiniMax H3: референс в видео

Ниже приведён перевод документации на русский язык. Сохранены все параметры, типы данных, значения в диапазонах и имена выходов в исходном виде.

---

Узел MiniMax H3 Reference to Video создает текстовое кондиционирование и пустое латентное представление видео, необходимые для генерации видео по референсам с помощью MiniMax H3. Вы предоставляете промпт, а также дополнительные референсные изображения, видео и аудиоклипы. Узел кодирует эти референсы в токены, которые модель может использовать при генерации. Промпт обращается к референсам с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>`.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования референсных медиа в токены кондиционирования. | CLIP | Да | |
| `vae` | VAE, используемый для кодирования референсных изображений и кадров референсных видео в латентное пространство. | VAE | Да | |
| `audio_vae` | VAE, используемый для кодирования референсного аудио в латентное пространство (частота дискретизации аудио 32 кГц). | VAE | Да | |
| `prompt` | Текстовый промпт для видео. На референсные медиа можно ссылаться с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>` (нумерация с 1 для каждого типа). Поддерживает многострочные и динамические промпты. | STRING | Да | |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 1344). | INT | Да | 32 до 16384 (шаг 32) |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 768). | INT | Да | 32 до 16384 (шаг 32) |
| `длина` | Количество кадров при 24 кадрах/с; 124 = ~5 секунд, обученный диапазон — примерно 124–362 (по умолчанию: 124). | INT | Да | 5 до 3600 (шаг 17) |
| `размер_реф_изображения` | Режим масштабирования референсных изображений. `match` уменьшает каждое референсное изображение, сохраняя соотношение сторон, до площади пикселей генерации; `max` использует короткую сторону 2048px из конвейера референсов для наилучшей точности идентичности. Токены референсов присутствуют на каждом шаге сэмплирования, поэтому `max` может быть в несколько раз медленнее (по умолчанию: `match`). | COMBO | Да | `"match"`<br>`"max"` |
| `реф_изображения` | Дополнительные референсные изображения. Каждое изображение уменьшается до короткой стороны 2048px, если оно больше, и никогда не увеличивается. Можно указать несколько изображений. | IMAGE | Нет | 0 до 9 |
| `реф_видео` | Дополнительные кадры референсных видео при 24 кадрах/с (2–15 с). Можно указать несколько видео. | IMAGE | Нет | 0 до 3 |
| `реф_аудио_видео` | Дополнительные звуковые дорожки, сопоставленные с референсными видео по индексу; `ref_video_audio_N` — звуковая дорожка к видео с тем же номером `ref_video_N`. | AUDIO | Нет | 0 до 3 |
| `реф_аудио` | Дополнительные отдельные референсные аудиоклипы. | AUDIO | Нет | 0 до 3 |

Примечания:
- Промпт ссылается на референсные медиа с помощью тегов с нумерацией от 1 для каждого типа: `<Picture i>` для изображений, `<Video k>` для видео и `<Audio j>` для аудио. Референсы подаются модели в фиксированном порядке: сначала изображения, затем видео (при этом метка `<Audio j>` соответствующей звуковой дорожки располагается непосредственно перед `<Video k>`), затем отдельное аудио.
- Референсные видео должны содержать минимум 5 кадров (~0,2 секунды при 24 кадрах/с), иначе узел выдаст ошибку. Кадры видео также ограничиваются выбранным значением `length` и обрезаются до поддерживаемого количества кадров.

## Выходные параметры

| Выход | Описание | Тип данных |
|-------|----------|------------|
| `positive` | Кондиционирование, содержащее закодированный промпт вместе с закодированными токенами референсных изображений, видео и аудио, используемыми моделью MiniMax H3. | CONDITIONING |
| `latent` | Пустое латентное представление аудио-видео с запрошенными `ширина`, `высота` и `длина` (количество кадров). | LATENT |
