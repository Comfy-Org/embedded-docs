# MiniMax H3: референс в видео

MiniMax H3 Reference to Video создает текстовое кондиционирование и пустой аудио-видео latent, необходимые для генерации reference-to-video в MiniMax H3. Вы предоставляете промпт, а также необязательные референсные изображения, видео и аудиоклипы, а узел кодирует эти референсы в токены, которые модель может использовать при генерации. В промпте на референсы ссылаются с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования референсных медиаданных в токены кондиционирования. | CLIP | Да | |
| `vae` | VAE, используемый для кодирования референсных изображений и кадров референсных видео в латентное пространство. | VAE | Да | |
| `audio_vae` | VAE, используемый для кодирования референсного аудио в латентное пространство (частота дискретизации аудио — 32 кГц). | VAE | Да | |
| `prompt` | Текстовый промпт для видео. На референсные медиаданные можно ссылаться с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>` (индексация с 1 для каждого типа). Поддерживает многострочные и динамические промпты. | STRING | Да | |
| `width` | Ширина генерируемого видео в пикселях (по умолчанию: 1344). | INT | Да | 32–16384 (шаг 32) |
| `height` | Высота генерируемого видео в пикселях (по умолчанию: 768). | INT | Да | 32–16384 (шаг 32) |
| `length` | Количество кадров при 24 кадрах/с; 124 ≈ 5 с, обученный диапазон — примерно 124–362 (по умолчанию: 124). | INT | Да | 5–3600 (шаг 17) |
| `ref_image_size` | Режим масштабирования референсных изображений. `match` уменьшает каждое референсное изображение только в сторону уменьшения, сохраняя соотношение сторон, до площади пикселей генерации; `max` использует короткую сторону 2048px референсного конвейера для наилучшего сохранения идентичности. Токены референсов проходят через каждый шаг сэмплирования, поэтому режим `max` может работать в несколько раз медленнее (по умолчанию: `match`). | COMBO | Да | `"match"`<br>`"max"` |
| `ref_images` | Необязательные референсные изображения. Каждое изображение уменьшается до короткой стороны 2048px, если оно больше, и никогда не увеличивается. Можно указать несколько изображений. | IMAGE | Нет | 0–9 |
| `ref_videos` | Необязательные кадры референсных видео с частотой 24 кадра/с (2–15 с). Можно указать несколько видео. | IMAGE | Нет | 0–3 |
| `ref_video_audios` | Необязательные звуковые дорожки, сопоставляемые с референсными видео по индексу; `ref_video_audio_N` — это звуковая дорожка для `ref_video_N` с тем же номером. | AUDIO | Нет | 0–3 |
| `ref_audios` | Необязательные отдельные референсные аудиоклипы. | AUDIO | Нет | 0–3 |

Примечания:
- В промпте ссылки на референсные медиаданные задаются тегами с индексацией от 1 для каждого типа: `<Picture i>` для изображений, `<Video k>` для видео и `<Audio j>` для аудио. Референсы передаются модели в фиксированном порядке: сначала изображения, затем видео (метка `<Audio j>` каждой звуковой дорожки стоит непосредственно перед соответствующим ей `<Video k>`), затем отдельное аудио.
- Референсные видео должны содержать не менее 5 кадров (~0,2 секунды при 24 кадрах/с), в противном случае узел выдаёт ошибку. Кадры видео ограничиваются выбранным значением `length` и обрезаются до поддерживаемого количества кадров.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондиционирование, содержащее закодированный промпт вместе с закодированными токенами референсных изображений, видео и аудио, используемыми моделью MiniMax H3. | CONDITIONING |
| `latent` | Пустой аудио-видео latent с запрошенными значениями `width`, `height` и `length` (количество кадров). | LATENT |
