# MiniMax H3: референс в видео

MiniMax H3 Reference to Video создаёт текстовое кондиционирование и пустой аудио-видео латент, необходимые для генерации reference-to-video в MiniMax H3. Вы задаёте промпт, а также необязательные эталонные изображения, видео и аудиоклипы; узел кодирует эти эталонные материалы в кондиционирование, которое модель может использовать во время генерации. В промпте можно ссылаться на эталонные материалы с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования эталонных медиаданных в токены кондиционирования. | CLIP | Да | |
| `vae` | Видео VAE. Без него эталонные изображения/видео влияют только на текстовый энкодер. | VAE | Нет | |
| `audio_vae` | Аудио VAE. Без него эталонное аудио влияет только на текстовый энкодер. | VAE | Нет | |
| `prompt` | Текстовый промпт для видео. На эталонные медиаданные можно ссылаться с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>` (нумерация от 1 для каждого типа). Поддерживает многострочные и динамические промпты. | STRING | Да | |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 1344). | INT | Да | от 32 до 16384 (шаг 32) |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 768). | INT | Да | от 32 до 16384 (шаг 32) |
| `длина` | Количество кадров при 24 fps, (124 = ~5 с, диапазон обучения ~124–362) (по умолчанию: 124). | INT | Да | от 5 до 3600 (шаг 17) |
| `размер_реф_изображения` | Подбор размера эталонного изображения. `match` масштабирует каждое эталонное изображение (только уменьшение, с сохранением пропорций) до пиксельной площади генерации; `max` использует 2048 px по короткой стороне из эталонного пайплайна для наилучшей точности передачи идентичности. Эталонные токены проходят через каждый шаг сэмплирования, поэтому `max` может быть в несколько раз медленнее (по умолчанию: `match`). | COMBO | Да | `"match"`<br>`"max"` |
| `реф_изображения` | Расширяемый слот: подключите до 9 эталонных изображений (`ref_image_1` ... `ref_image_9`). Эталонное изображение (уменьшается до 2048 по короткой стороне, если оно больше; никогда не увеличивается). | IMAGE | Нет | от 0 до 9 |
| `реф_видео` | Расширяемый слот: подключите до 3 эталонных видео (`ref_video_1` ... `ref_video_3`). Кадры эталонного видео при 24 fps (2–15 с). | IMAGE | Нет | от 0 до 3 |
| `реф_аудио_видео` | Расширяемый слот: подключите до 3 звуковых дорожек (`ref_video_audio_1` ... `ref_video_audio_3`). Звуковая дорожка эталонного видео с тем же номером. | AUDIO | Нет | от 0 до 3 |
| `реф_аудио` | Расширяемый слот: подключите до 3 отдельных эталонных аудиоклипов (`ref_audio_1` ... `ref_audio_3`). Отдельное эталонное аудио. | AUDIO | Нет | от 0 до 3 |

Примечания:

- В промпте ссылки на эталонные медиаданные задаются тегами с нумерацией от 1 для каждого типа: `<Picture i>` для изображений, `<Video k>` для видео и `<Audio j>` для аудио. Эталонные материалы передаются модели в фиксированном порядке: изображения, затем видео (при этом метка `<Audio j>` каждой звуковой дорожки стоит непосредственно перед её `<Video k>`), затем отдельное аудио.
- Звуковая дорожка, подключённая к `ref_video_audio_N`, используется с эталонным видео, подключённым к `ref_video_N`.
- Эталонные видео должны содержать не менее 5 кадров (~0,2 секунды при 24 fps), иначе узел вызывает ошибку. Кадры сверх запрошенного `length` обрезаются, а оставшееся количество кадров приводится к значению, поддерживаемому моделью.
- Запрошенное значение `length` выравнивается до поддерживаемого количества кадров перед созданием латента.
- Без `vae` эталонные изображения и видео влияют только на текстовый энкодер (эталонные латенты не создаются). Без `audio_vae` эталонное аудио влияет только на текстовый энкодер.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондиционирование, содержащее закодированный промпт. Если предоставлены эталонные медиаданные и соответствующие VAE, оно также содержит закодированное эталонное изображение, видео и аудиосодержимое, используемое моделью MiniMax H3. | CONDITIONING |
| `latent` | Пустой аудио-видео латент с запрошенными `width`, `height` и `length` (количество кадров), включая выровненный видеолатент и аудиолатент. | LATENT |
