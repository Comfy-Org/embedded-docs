# MiniMax H3: референс в видео

MiniMax H3 Reference to Video создает текстовое кондиционирование (conditioning) и пустой аудио-видео латент, необходимые для генерации video по эталону (reference-to-video) в MiniMax H3. Вы предоставляете промпт, а также опциональные эталонные изображения, видео и аудиоклипы. Узел кодирует эти эталонные данные в токены, которые модель может использовать при генерации. Промпт ссылается на эталонные данные с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|-----------|------------|--------------|-----------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования эталонных медиаданных в токены кондиционирования. | CLIP | Да | |
| `vae` | VAE, используемая для кодирования эталонных изображений и кадров эталонных видео в латентное пространство. | VAE | Да | |
| `audio_vae` | VAE, используемая для кодирования эталонного аудио в латентное пространство. Аудио передискретизируется до частоты дискретизации аудио VAE (по умолчанию 32 кГц). | VAE | Да | |
| `prompt` | Текстовый промпт для видео. На эталонные медиаданные можно ссылаться с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>` (нумерация с 1 для каждого типа). Поддерживает многострочные и динамические промпты. | STRING | Да | |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 1344). | INT | Да | 32 до 16384 (step 32) |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 768). | INT | Да | 32 до 16384 (step 32) |
| `длина` | Количество кадров при 24 кадрах в секунду; 124 = ~5 секунд, обученный диапазон ~124-362 (по умолчанию: 124). | INT | Да | 5 до 3600 (step 17) |
| `размер_реф_изображения` | Определение размера эталонных изображений. `match` масштабирует каждое эталонное изображение только в сторону уменьшения, сохраняя соотношение сторон, до площади пикселей генерации; `max` использует короткий край 2048 пикселей из эталонного конвейера для наилучшей точности идентичности. Токены эталонных данных проходят через каждый шаг сэмплирования, поэтому `max` может быть в несколько раз медленнее (по умолчанию: `match`). | COMBO | Да | `"match"`<br>`"max"` |
| `реф_изображения` | Расширяемый слот: подключите от 1 до 9 эталонных изображений (`ref_image_1` ... `ref_image_9`). Каждое изображение уменьшается до короткого края 2048 пикселей, если оно больше, и никогда не увеличивается. | IMAGE | Нет | 0 до 9 |
| `реф_видео` | Расширяемый слот: подключите от 1 до 3 эталонных видео (`ref_video_1` ... `ref_video_3`). Кадры эталонного видео при 24 кадрах в секунду (2–15 с). | IMAGE | Нет | 0 до 3 |
| `реф_аудио_видео` | Расширяемый слот: подключите от 1 до 3 звуковых дорожек (`ref_video_audio_1` ... `ref_video_audio_3`). Звуковая дорожка эталонного видео с тем же номером. | AUDIO | Нет | 0 до 3 |
| `реф_аудио` | Расширяемый слот: подключите от 1 до 3 отдельных эталонных аудиоклипов (`ref_audio_1` ... `ref_audio_3`). | AUDIO | Нет | 0 до 3 |

Примечания:

- Промпт ссылается на эталонные медиаданные с помощью тегов с нумерацией от 1 для каждого типа: `<Picture i>` для изображений, `<Video k>` для видео и `<Audio j>` для аудио. Эталонные данные подаются в модель в фиксированном порядке: сначала изображения, затем видео (с меткой `<Audio j>` каждой звуковой дорожки непосредственно перед соответствующим `<Video k>`), затем отдельное аудио.
- Эталонные видео должны содержать не менее 5 кадров (~0,2 секунды при 24 кадрах в секунду), в противном случае узел вызовет ошибку. Кадры видео также ограничиваются выбранным значением `length` и обрезаются до поддерживаемого количества кадров.
- Запрошенное значение `length` выравнивается до поддерживаемого количества кадров перед созданием латента.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|-----------|------------|
| `позитивный` | Кондиционирование, содержащее закодированный промпт вместе с закодированными токенами эталонных изображений, видео и аудио, используемыми моделью MiniMax H3. | CONDITIONING |
| `latent` | Пустой аудио-видео латент с запрошенными `width`, `height` и `length` (количество кадров). | LATENT |
