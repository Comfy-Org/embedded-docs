# تبدیل مرجع به ویدیو MiniMax H3

MiniMax H3 Reference to Video، متن شرطی‌سازی (conditioning) و latent ویدیوی خالی موردنیاز برای تولید ویدیوی ارجاعی MiniMax H3 را می‌سازد. شما یک prompt به‌همراه تصاویر، ویدیوها و کلیپ‌های صوتی ارجاعی اختیاری ارائه می‌دهید و گره این ارجاع‌ها را به توکن‌هایی رمزگذاری می‌کند که مدل می‌تواند هنگام تولید از آن‌ها استفاده کند. prompt با تگ‌های `<Picture i>`، `<Video k>` و `<Audio j>` به ارجاع‌ها اشاره می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکنایز کردن prompt و رمزگذاری رسانه‌های ارجاعی به توکن‌های شرطی‌سازی استفاده می‌شود. | CLIP | بله | |
| `vae` | VAE که برای رمزگذاری تصاویر ارجاعی و فریم‌های ویدیوی ارجاعی به فضای latent استفاده می‌شود. | VAE | بله | |
| `audio_vae` | VAE که برای رمزگذاری صدای ارجاعی به فضای latent استفاده می‌شود (نرخ نمونه‌برداری صوتی ۳۲ کیلوهرتز). | VAE | بله | |
| `پرامپت` | متن prompt برای ویدیو. می‌توان با تگ‌های `<Picture i>`، `<Video k>` و `<Audio j>` به رسانه‌های ارجاعی اشاره کرد (شماره‌گذاری هر نوع از ۱ شروع می‌شود). از promptهای چندخطی و پویا پشتیبانی می‌کند. | STRING | بله | |
| `عرض` | عرض ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 1344). | INT | بله | 32 تا 16384 (گام 32) |
| `ارتفاع` | ارتفاع ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 32 تا 16384 (گام 32) |
| `طول` | تعداد فریم‌ها با نرخ ۲۴ فریم بر ثانیه؛ 124 ≈ حدود ۵ ثانیه، محدودهٔ آموزش‌دیده حدود 124 تا 362 است (پیش‌فرض: 124). | INT | بله | 5 تا 3600 (گام 17) |
| `اندازه تصویر مرجع` | حالت اندازه‌گذاری تصویر ارجاعی. `match` هر تصویر ارجاعی را فقط کوچک می‌کند و با حفظ نسبت ابعاد، آن را به مساحت پیکسلی خروجی تولید می‌رساند؛ `max` از لبهٔ کوتاه ۲۰۴۸ پیکسلی پایپلاین ارجاع برای بهترین وفاداری هویت استفاده می‌کند. توکن‌های ارجاعی در تمام مراحل نمونه‌برداری همراه هستند، بنابراین `max` می‌تواند چند برابر کندتر باشد (پیش‌فرض: `match`). | COMBO | بله | `"match"`<br>`"max"` |
| `تصاویر مرجع` | تصاویر ارجاعی اختیاری. اگر تصویری بزرگ‌تر باشد، به لبهٔ کوتاه ۲۰۴۸ پیکسل کوچک می‌شود و هرگز بزرگ‌نمایی نمی‌شود. می‌توان چند تصویر ارائه داد. | IMAGE | خیر | 0 تا 9 |
| `ویدیوهای مرجع` | فریم‌های ویدیوی ارجاعی اختیاری با نرخ ۲۴ فریم بر ثانیه (۲ تا ۱۵ ثانیه). می‌توان چند ویدیو ارائه داد. | IMAGE | خیر | 0 تا 3 |
| `صداهای ویدیوی مرجع` | صداهای اختیاری که بر اساس ایندکس با ویدیوهای ارجاعی جفت شده‌اند؛ `ref_video_audio_N` صدای `ref_video_N` همنام است. | AUDIO | خیر | 0 تا 3 |
| `صداهای مرجع` | کلیپ‌های صوتی ارجاعی مستقل اختیاری. | AUDIO | خیر | 0 تا 3 |

یادداشت‌ها:
- prompt با تگ‌های مبتنی بر شماره از ۱ برای هر نوع به رسانه‌های ارجاعی اشاره می‌کند: `<Picture i>` برای تصاویر، `<Video k>` برای ویدیوها، و `<Audio j>` برای صدا. ارجاع‌ها به ترتیب ثابتی به مدل ارائه می‌شوند: تصاویر، سپس ویدیوها (با برچسب `<Audio j>` مربوط به هر صدا، درست قبل از `<Video k>` آن)، و سپس صداهای مستقل.
- ویدیوهای ارجاعی باید حداقل ۵ فریم داشته باشند (حدود ۰٫۲ ثانیه با نرخ ۲۴ فریم بر ثانیه)، در غیر این صورت گره خطا صادر می‌کند. فریم‌های ویدیو همچنین به `length` انتخاب‌شده محدود می‌شوند و به تعداد فریم پشتیبانی‌شده برش می‌خورند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی حاوی prompt رمزگذاری‌شده به‌همراه توکن‌های تصویر، ویدیو و صدای ارجاعیِ رمزگذاری‌شده که توسط مدل MiniMax H3 استفاده می‌شوند. | CONDITIONING |
| `latent` | latent خالی صوتی-ویدیویی با `عرض`، `ارتفاع` و `طول` (تعداد فریم) درخواستی. | LATENT |
