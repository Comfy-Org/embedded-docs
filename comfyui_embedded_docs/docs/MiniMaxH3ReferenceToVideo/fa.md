# تبدیل مرجع به ویدیو MiniMax H3

گره «MiniMax H3 Reference to Video» شرطی‌سازی متنی و latent صوتی-ویدیویی خالی موردنیاز برای تولید ویدیو با ارجاع به MiniMax H3 را ایجاد می‌کند. شما یک پرامپت به همراه تصاویر، ویدیوها و کلیپ‌های صوتی مرجع اختیاری ارائه می‌دهید و گره این ارجاع‌ها را به توکن‌هایی رمزگذاری می‌کند که مدل هنگام تولید از آن‌ها استفاده می‌کند. پرامپت با برچسب‌های `<Picture i>`، `<Video k>` و `<Audio j>` به ارجاع‌ها اشاره می‌کند.

یادداشت‌ها:

- پرامپت با برچسب‌های شماره‌گذاری‌شده از ۱ برای هر نوع به رسانه‌های مرجع اشاره می‌کند: `<Picture i>` برای تصاویر، `<Video k>` برای ویدیوها و `<Audio j>` برای صدا. ارجاع‌ها به ترتیب ثابت به مدل ارائه می‌شوند: تصاویر، سپس ویدیوها (با برچسب `<Audio j>` هر موسیقی متن بلافاصله قبل از `<Video k>` مربوطه)، سپس صوتی مستقل.
- ویدیوهای مرجع باید حداقل ۵ فریم (حدود ۰.۲ ثانیه در ۲۴ فریم بر ثانیه) داشته باشند، در غیر این صورت گره خطا می‌دهد. فریم‌های ویدیو نیز به `length` انتخاب‌شده محدود می‌شوند و به تعداد فریم پشتیبانی‌شده برش می‌خورند.
- `length` درخواستی قبل از ایجاد latent با تعداد فریم پشتیبانی‌شده هم‌تراز می‌شود.
