# تبدیل مرجع به ویدیو MiniMax H3

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP مورد استفاده برای توکنایز کردن prompt و رمزگذاری رسانه‌های مرجع به توکن‌های conditioning. | CLIP | بله | |
| `vae` | VAE مورد استفاده برای رمزگذاری تصاویر مرجع و فریم‌های ویدیوی مرجع به فضای پنهان. | VAE | بله | |
| `audio_vae` | VAE مورد استفاده برای رمزگذاری صدای مرجع به فضای پنهان (نرخ نمونه‌برداری صوتی ۳۲ کیلوهرتز). | VAE | بله | |
| `prompt` | متن prompt برای ویدیو. رسانه‌های مرجع را می‌توان با برچسب‌های `<Picture i>`، `<Video k>` و `<Audio j>` (شماره‌گذاری ۱-پایه برای هر نوع) آدرس‌دهی کرد. از promptهای چندخطی و پویا پشتیبانی می‌کند. | STRING | بله | |
| `width` | عرض ویدیوی تولیدشده به پیکسل (پیش‌فرض: ۱۳۴۴). | INT | بله | 32 to 16384 (step 32) |
| `height` | ارتفاع ویدیوی تولیدشده به پیکسل (پیش‌فرض: ۷۶۸). | INT | بله | 32 to 16384 (step 32) |
| `length` | تعداد فریم در ۲۴ فریم‌برثانیه؛ ۱۲۴ = تقریباً ۵ ثانیه، محدوده آموزش‌دیده حدود ۱۲۴-۳۶۲ (پیش‌فرض: ۱۲۴). | INT | بله | 5 to 3600 (step 17) |
| `ref_image_size` | حالت اندازه‌گذاری تصویر مرجع. `match` هر تصویر مرجع را فقط کوچک می‌کند (بدون تغییر نسبت ابعاد) تا به ناحیه پیکسلی تولید برسد؛ `max` از لبه کوتاه ۲۰۴۸ پیکسلی خط لوله مرجع برای بهترین وفاداری هویت استفاده می‌کند. توکن‌های مرجع در هر مرحله نمونه‌برداری عبور می‌کنند، بنابراین `max` می‌تواند چند برابر کندتر باشد (پیش‌فرض: `match`). | COMBO | بله | `"match"`<br>`"max"` |
| `ref_images` | تصاویر مرجع اختیاری. هر تصویر اگر بزرگ‌تر باشد به لبه کوتاه ۲۰۴۸ پیکسل کوچک می‌شود و هرگز بزرگ‌نمایی نمی‌شود. می‌توان چندین تصویر ارائه کرد. | IMAGE | خیر | 0 to 9 |
| `ref_videos` | فریم‌های ویدیوی مرجع اختیاری با ۲۴ فریم‌برثانیه (۲ تا ۱۵ ثانیه). می‌توان چندین ویدیو ارائه کرد. | IMAGE | خیر | 0 to 3 |
| `ref_video_audios` | صداهای اختیاری که بر اساس ایندکس با ویدیوهای مرجع جفت می‌شوند؛ `ref_video_audio_N` صدای `ref_video_N` با شماره متناظر است. | AUDIO | خیر | 0 to 3 |
| `ref_audios` | کلیپ‌های صوتی مرجع مستقل اختیاری. | AUDIO | خیر | 0 to 3 |

نکات:
- این prompt به رسانه‌های مرجع با برچسب‌های ۱-پایه برای هر نوع اشاره می‌کند: `<Picture i>` برای تصاویر، `<Video k>` برای ویدیوها، و `<Audio j>` برای صدا. ارجاع‌ها به ترتیب ثابتی به مدل ارائه می‌شوند: تصاویر، سپس ویدیوها (با برچسب `<Audio j>` مربوط به هر صدا بلافاصله قبل از `<Video k>` متناظر آن)، و سپس صداهای مستقل.
- ویدیوهای مرجع باید حداقل ۵ فریم (حدود ۰٫۲ ثانیه در ۲۴ فریم‌برثانیه) داشته باشند، در غیر این صورت گره خطا برمی‌گرداند. تعداد فریم‌های ویدیو به `length` انتخابی سقف داده می‌شود و به یک تعداد فریم پشتیبانی‌شده برش می‌خورد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | Conditioning شامل prompt رمزگذاری‌شده به‌همراه توکن‌های تصویر، ویدیو و صوتی مرجع رمزگذاری‌شده که توسط مدل MiniMax H3 استفاده می‌شود. | CONDITIONING |
| `latent` | فضای پنهان صوتی‑ویدیویی خالی در `width`، `height` و `length` (تعداد فریم) درخواستی. | LATENT |
