# ハイパータイル

HyperTile ノードは、拡散モデルのアテンションメカニズムにタイル分割技術を適用し、画像生成時のメモリ使用量を最適化します。潜在空間をより小さなタイルに分割して個別に処理し、その後結果を再組み立てします。これにより、メモリ不足を起こさずに、より大きな画像サイズで作業することができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | HyperTile 最適化を適用する対象の拡散モデルです。 | MODEL | はい | - |
| `tile_size` | 処理対象のタイルサイズです（デフォルト: 256）。実際のタイルサイズは 8 の倍数に切り捨てられ、最小値は 32 です。 | INT | いいえ | 1 - 2048 |
| `swap_size` | ノードが画像の分割方法をランダムに選択する際に考慮される候補タイル分割数です。値が大きいほど、分割のバリエーションが増えます（デフォルト: 2）。 | INT | いいえ | 1 - 128 |
| `max_depth` | タイル分割を適用する最大深度レベル（解像度スケール）です。0 を指定すると、最高解像度でのみタイル分割が適用されます（デフォルト: 0）。 | INT | いいえ | 0 - 10 |
| `scale_depth` | 有効にすると、より深い深度レベルでタイルサイズが比例的にスケーリングされます。これにより、低解像度での品質維持に役立ちます（デフォルト: False）。 | BOOLEAN | いいえ | True / False |

注：`scale_depth` は、`max_depth` が 0 より大きい場合にのみ効果があります。最高解像度レベル（深度 0）ではタイルサイズは決してスケーリングされないためです。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | HyperTile 最適化が適用された変更済みモデルです。 | MODEL |
