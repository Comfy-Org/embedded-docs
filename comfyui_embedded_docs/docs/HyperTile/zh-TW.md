# HyperTile

HyperTile 節點對擴散模型中的注意力機制應用平鋪（tiling）技術，以在圖像生成期間最佳化記憶體使用。它將潛在空間劃分為較小的區塊並分別處理，然後重新組合結果。這使得可以在不耗盡記憶體的情況下處理更大的圖像尺寸。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要套用 HyperTile 最佳化的擴散模型 | MODEL | 是 | - |
| `切片尺寸` | 處理時目標區塊大小（預設值：256）。在內部，該值會被限制為最小值 32，然後除以 8 以獲得有效區塊大小。 | INT | 是 | 1 - 2048 |
| `交換區大小` | 控制處理過程中區塊的重新排列方式以提高效率。較大的值允許區塊大小有更多變化（預設值：2） | INT | 是 | 1 - 128 |
| `最大深度` | 套用平鋪的最大深度層級（解析度比例）。值為 0 時僅在最高解析度下套用平鋪（預設值：0） | INT | 是 | 0 - 10 |
| `縮放深度` | 啟用後，區塊大小會在更深的深度層級按比例縮放。這有助於在較低解析度下維持品質（預設值：False） | BOOLEAN | 是 | True / False |
