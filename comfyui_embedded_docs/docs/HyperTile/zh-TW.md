# HyperTile

HyperTile 會對擴散模型內部的注意力機制套用分塊技術，以降低圖像生成期間的記憶體使用量。它會將潛在空間分割成較小的圖塊，分別處理每個圖塊的注意力，然後重新組合結果。這讓使用者能夠處理更大的圖像尺寸，而不會耗盡記憶體。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要套用 HyperTile 最佳化的擴散模型 | MODEL | 是 | - |
| `切片尺寸` | 處理時要使用的目標圖塊大小（預設：256）。在內部，此數值會被限制為最小值 32，然後除以 8 以取得有效圖塊大小。 | INT | 是 | 1 - 2048 |
| `交換區大小` | 控制處理期間圖塊的重新排列方式，以提升效率。較大的數值可讓圖塊大小有更多變化（預設：2） | INT | 是 | 1 - 128 |
| `最大深度` | 要套用分塊的最大深度層級（解析度尺度）。數值為 0 時，僅在最高解析度套用分塊（預設：0） | INT | 是 | 0 - 10 |
| `縮放深度` | 啟用時，圖塊大小會隨更深的深度層級按比例縮放。這有助於在較低解析度下維持品質（預設：False） | BOOLEAN | 是 | True / False |

注意：`tile_size`、`swap_size`、`max_depth` 和 `scale_depth` 標記為進階輸入，因此只有在介面中啟用進階選項時才會顯示。
