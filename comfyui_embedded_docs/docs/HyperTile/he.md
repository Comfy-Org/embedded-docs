# HyperTile

HyperTile מיישם טכניקת ריצוף על מנגנון הקשב בתוך מודלי דיפוזיה כדי להפחית את השימוש בזיכרון במהלך יצירת תמונות. הוא מפצל את המרחב הלטנטי לאריחים קטנים יותר, מעבד את הקשב עבור כל אריח בנפרד, ולאחר מכן מרכיב מחדש את התוצאות. הדבר מאפשר לעבוד עם גדלי תמונה גדולים יותר בלי להיגמר מהזיכרון.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה שעבורו יש להחיל את אופטימיזציית HyperTile | MODEL | כן | - |
| `tile_size` | גודל האריח המיועד לעיבוד (ברירת מחדל: 256). באופן פנימי, הערך מוגבל למינימום של 32 ולאחר מכן מחולק ב-8 כדי לקבל את גודל האריח האפקטיבי. | INT | כן | 1 - 2048 |
| `swap_size` | שולט באופן שבו האריחים מסודרים מחדש במהלך העיבוד כדי לשפר את היעילות. ערכים גדולים יותר מאפשרים שונות רבה יותר בגדלי האריחים (ברירת מחדל: 2) | INT | כן | 1 - 128 |
| `max_depth` | רמת העומק המקסימלית (קנה מידה של רזולוציה) שעבורה יוחל ריצוף. ערך 0 מחיל ריצוף רק ברזולוציה הגבוהה ביותר (ברירת מחדל: 0) | INT | כן | 0 - 10 |
| `scale_depth` | כאשר מופעל, גודל האריח מותאם באופן פרופורציונלי ברמות עומק עמוקות יותר. הדבר יכול לעזור לשמור על איכות ברזולוציות נמוכות יותר (ברירת מחדל: False) | BOOLEAN | כן | True / False |

הערה: `tile_size`, `swap_size`, `max_depth` ו-`scale_depth` מסומנים כקלטים מתקדמים, ולכן הם מוצגים רק כאשר אפשרויות מתקדמות מופעלות בממשק.
