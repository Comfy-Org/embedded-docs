# 하이퍼 타일

HyperTile 노드는 확산 모델의 어텐션 메커니즘에 타일링 기법을 적용하여 이미지 생성 중 메모리 사용을 최적화합니다. 잠재 공간을 더 작은 타일로 나누어 개별적으로 처리한 다음 결과를 다시 조합합니다. 이를 통해 메모리가 부족하지 않고 더 큰 이미지 크기로 작업할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | HyperTile 최적화를 적용할 확산 모델 | MODEL | 예 | - |
| `tile_size` | 처리할 대상 타일 크기 (기본값: 256). 실제 타일 크기는 8의 배수로 내림되며 최소값은 32입니다. | INT | 아니오 | 1 - 2048 |
| `swap_size` | 노드가 이미지를 분할하는 방식을 무작위로 선택할 때 고려되는 후보 타일 분할 수. 값이 클수록 분할에 더 많은 변형이 허용됩니다 (기본값: 2) | INT | 아니오 | 1 - 128 |
| `max_depth` | 타일링을 적용할 최대 깊이 수준(해상도 척도). 값이 0이면 가장 높은 해상도에서만 타일링을 적용합니다 (기본값: 0) | INT | 아니오 | 0 - 10 |
| `scale_depth` | 활성화하면 더 깊은 깊이 수준에서 타일 크기가 비례적으로 조정됩니다. 저해상도에서 품질을 유지하는 데 도움이 될 수 있습니다 (기본값: False) | BOOLEAN | 아니오 | True / False |

참고: `scale_depth`는 `max_depth`가 0보다 큰 경우에만 효과가 있습니다. 가장 높은 해상도 수준(깊이 0)에서는 타일 크기가 절대 조정되지 않기 때문입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | HyperTile 최적화가 적용된 수정된 모델 | MODEL |
