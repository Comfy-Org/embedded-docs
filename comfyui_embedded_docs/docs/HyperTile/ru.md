# Гиперплитка

Узел HyperTile применяет технику мозаичного разбиения (tiling) к механизму внимания в диффузионных моделях для оптимизации использования памяти при генерации изображений. Он разделяет скрытое пространство на меньшие фрагменты и обрабатывает их отдельно, затем собирает результаты обратно. Это позволяет работать с изображениями большего размера без нехватки памяти.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется оптимизация HyperTile | MODEL | Да | - |
| `размер_плитки` | Целевой размер фрагмента для обработки (по умолчанию: 256). Внутренне значение ограничивается минимумом 32, затем делится на 8 для получения эффективного размера фрагмента. | INT | Да | 1 - 2048 |
| `размер_замены` | Управляет тем, как фрагменты переставляются во время обработки для повышения эффективности. Большие значения допускают большее разнообразие размеров фрагментов (по умолчанию: 2) | INT | Да | 1 - 128 |
| `максимальная_глубина` | Максимальный уровень глубины (масштаб разрешения) для применения мозаичного разбиения. Значение 0 применяет разбиение только на самом высоком разрешении (по умолчанию: 0) | INT | Да | 0 - 10 |
| `масштаб_глубины` | При включении размер фрагмента пропорционально масштабируется на более глубоких уровнях. Это может помочь сохранить качество при более низких разрешениях (по умолчанию: False) | BOOLEAN | Да | True / False |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной оптимизацией HyperTile | MODEL |
