# Гиперплитка

Узел HyperTile применяет технику тайлинга к механизму внимания в диффузионных моделях для оптимизации использования памяти при генерации изображений. Он разделяет латентное пространство на более мелкие тайлы и обрабатывает их по отдельности, затем собирает результаты обратно. Это позволяет работать с изображениями большего размера без нехватки памяти.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется оптимизация HyperTile | MODEL | Да | - |
| `tile_size` | Целевой размер тайла для обработки (по умолчанию: 256). Фактический размер тайла округляется вниз до кратного 8, с минимумом 32. | INT | Нет | 1 - 2048 |
| `swap_size` | Количество рассматриваемых вариантов разбиения на тайлы, когда узел случайным образом выбирает способ деления изображения. Большее значение допускает больше вариаций при разбиении (по умолчанию: 2) | INT | Нет | 1 - 128 |
| `max_depth` | Максимальный уровень глубины (масштаб разрешения) для применения тайлинга. Значение 0 применяет тайлинг только на самом высоком разрешении (по умолчанию: 0) | INT | Нет | 0 - 10 |
| `scale_depth` | Когда включено, размер тайла пропорционально масштабируется на более глубоких уровнях. Это может помочь сохранить качество при более низких разрешениях (по умолчанию: False) | BOOLEAN | Нет | True / False |

Примечание: `scale_depth` действует только когда `max_depth` больше 0, потому что на самом высоком уровне разрешения (глубина 0) размер тайла никогда не масштабируется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной оптимизацией HyperTile | MODEL |
