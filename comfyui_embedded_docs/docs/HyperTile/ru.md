# Гиперплитка

HyperTile применяет технику разбиения на плитки к механизму внимания внутри диффузионных моделей, чтобы снизить использование памяти во время генерации изображений. Он разделяет латентное пространство на меньшие плитки, обрабатывает внимание для каждой плитки отдельно, а затем собирает результаты обратно. Это позволяет работать с изображениями большего размера, не исчерпывая память.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется оптимизация HyperTile | MODEL | Да | - |
| `размер_плитки` | Целевой размер плитки для обработки (по умолчанию: 256). Внутри значение ограничивается минимальным значением 32, а затем делится на 8 для получения эффективного размера плитки. | INT | Да | 1 - 2048 |
| `размер_замены` | Управляет тем, как плитки перестраиваются во время обработки для повышения эффективности. Большие значения допускают большее разнообразие размеров плиток (по умолчанию: 2) | INT | Да | 1 - 128 |
| `максимальная_глубина` | Максимальный уровень глубины (масштаб разрешения), на котором применяется разбиение на плитки. Значение 0 применяет разбиение только на самом высоком разрешении (по умолчанию: 0) | INT | Да | 0 - 10 |
| `масштаб_глубины` | Если включено, размер плитки пропорционально масштабируется на более глубоких уровнях. Это может помочь сохранить качество при более низких разрешениях (по умолчанию: False) | BOOLEAN | Да | True / False |

Примечание: `tile_size`, `swap_size`, `max_depth` и `scale_depth` отмечены как расширенные входы, поэтому они отображаются только при включённых расширенных параметрах в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённой оптимизацией HyperTile | MODEL |
