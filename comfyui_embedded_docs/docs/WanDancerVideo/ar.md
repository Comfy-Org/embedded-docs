# WanDancerVideo

WanDancerVideo يُعدّ بيانات التوجيه (conditioning data) وموترًا كامنًا فارغًا لتوليد الفيديو باستخدام نموذج WanDancer. يستقبل التوجيه الإيجابي والسلبي، ويجمعهما اختياريًا مع صورة بداية، وقناع، وتضمينات رؤية CLIP، وخصائص صوتية للتحكم في الفيديو المُولَّد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | التوجيه الإيجابي لتوجيه توليد الفيديو. | CONDITIONING | نعم |  |
| `negative` | التوجيه السلبي لتوجيه توليد الفيديو. | CONDITIONING | نعم |  |
| `vae` | شبكة VAE المستخدمة لترميز صورة البداية إلى الفضاء الكامن. | VAE | نعم |  |
| `width` | عرض الفيديو المُولَّد بالبكسل (الافتراضي: 480). | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 16) |
| `height` | ارتفاع الفيديو المُولَّد بالبكسل (الافتراضي: 832). | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 16) |
| `length` | عدد الإطارات في الفيديو المُولَّد. يجب أن يبقى 149 لنموذج WanDancer (الافتراضي: 149). | INT | نعم | 1 إلى MAX_RESOLUTION (الخطوة: 4) |
| `clip_vision_output` | تضمينات رؤية CLIP للإطار الأول. | CLIP_VISION_OUTPUT | لا |  |
| `clip_vision_output_ref` | تضمينات رؤية CLIP للصورة المرجعية. | CLIP_VISION_OUTPUT | لا |  |
| `start_image` | الصورة (الصور) الأولية التي سيتم ترميزها، ويمكن أن تكون أي عدد من الإطارات. | IMAGE | لا |  |
| `mask` | قناع توجيه الصورة للصورة (الصور) الأولية. اللون الأبيض يُحتفظ به، والأسود يُولَّد. يُستخدم في التوليد الموضعي. | MASK | لا |  |
| `audio_encoder_output` | مخرجات مشفّر الصوت، وتوفّر الخصائص الصوتية ومعدل الإطارات ومقياس حقن الصوت لتوليد مشروط بالصوت. | AUDIO_ENCODER_OUTPUT | لا |  |

**ملاحظة حول قيود المعاملات:**
- عند توفير `start_image`، يتم تغيير حجمه إلى `width` × `height`، ويُقتصر على عدد إطارات `length`، ثم يُرمَّز إلى كامن (latent) يُرفق بكل من التوجيهين مع قناع دمج (concat mask).
- `mask` لا يؤثر إلا عند توفير `start_image` أيضًا. في القناع، المناطق البيضاء تُحتفظ بها والمناطق السوداء تُولَّد. عندما لا يتم توفير `mask`، تُستخدم منطقة صورة البداية كدليل توجيه وتُولَّد الإطارات المتبقية.
- `clip_vision_output_ref` يُطبَّق فقط عند توفير `clip_vision_output`.
- `audio_encoder_output` يرفق الخصائص الصوتية ومعدل الإطارات ومقياس حقن الصوت (الافتراضي 1.0) بكل من التوجيهين.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التوجيه الإيجابي مع أي بيانات إضافية مرفقة (كامن الربط، رؤية CLIP، الصوت). | CONDITIONING |
| `negative` | التوجيه السلبي مع أي بيانات إضافية مرفقة (كامن الربط، رؤية CLIP، الصوت). | CONDITIONING |
| `latent` | موتر كامن فارغ بأبعاد تطابق طول الفيديو وارتفاعه وعرضه المحددة. | LATENT |
