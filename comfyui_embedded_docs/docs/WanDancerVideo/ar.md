# WanDancerVideo

```markdown
تقوم عقدة WanDancerVideo بتجهيز بيانات التوجيه (conditioning) وموتر كامن فارغ لتوليد الفيديو باستخدام نموذج WanDancer. تقوم بإرفاق صور بداية اختيارية، وأقنعة، وتضمينات رؤية CLIP، وخصائص صوتية بالتوجيه الإيجابي والسلبي لتوجيه الفيديو المُولَّد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التوجيه الإيجابي لتوجيه توليد الفيديو. | CONDITIONING | نعم |  |
| `سلبي` | التوجيه السلبي لتوجيه توليد الفيديو. | CONDITIONING | نعم |  |
| `vae` | شبكة الترميز VAE المستخدمة لتشفير صورة البداية في الفضاء الكامن. | VAE | نعم |  |
| `العرض` | عرض الفيديو المُولَّد بالبكسل (الافتراضي: 480). | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 16) |
| `الارتفاع` | ارتفاع الفيديو المُولَّد بالبكسل (الافتراضي: 832). | INT | نعم | 16 إلى MAX_RESOLUTION (الخطوة: 16) |
| `الطول` | عدد الإطارات في الفيديو المُولَّد. يجب أن يظل 149 لـ WanDancer (الافتراضي: 149). | INT | نعم | 1 إلى MAX_RESOLUTION (الخطوة: 4) |
| `clip_vision_output` | تضمينات رؤية CLIP للإطار الأول. | CLIP_VISION_OUTPUT | لا |  |
| `clip_vision_output_ref` | تضمينات رؤية CLIP للصورة المرجعية. | CLIP_VISION_OUTPUT | لا |  |
| `الصورة الابتدائية` | الصورة (الصور) الأولية المراد تشفيرها، يمكن أن تكون أي عدد من الإطارات. | IMAGE | لا |  |
| `قناع` | قناع توجيه الصورة للصورة (الصور) الأولية. يُحتفظ بالمناطق البيضاء، وتُولَّد المناطق السوداء. يُستخدم للتوليدات المحلية. | MASK | لا |  |
| `مخرجات ترميز الصوت` | مخرجات مشفر صوتي توفر خصائص صوتية، ومعدل إطارات، وقيم حقن، تُرفق بالتوجيه عند توفيرها. | AUDIO_ENCODER_OUTPUT | لا |  |

### ملاحظات حول سلوك المعاملات

- المعامل `start_image` اختياري. عند توفيره، يُغيَّر حجمه إلى `width` و`height`، ويُشفَّر بواسطة `vae`، ويُرفق بالتوجيه الإيجابي والسلبي معًا. إذا كان `start_image` يحتوي على إطارات أكثر من `length`، تُحذف الإطارات الزائدة. وإذا كان يحتوي على إطارات أقل، تُملأ الإطارات المفقودة بقيم صفرية.
- المعامل `mask` له تأثير فقط عند توفير `start_image` أيضًا. تُحتفظ بالمناطق البيضاء، وتُولَّد المناطق السوداء.
- المعامل `clip_vision_output_ref` له تأثير فقط عند توفير `clip_vision_output` أيضًا.
- عند توفير `audio_encoder_output`، يرفق تضمينات الصوت، ومعدل الإطارات، ومقياس الحقن بالتوجيه الإيجابي والسلبي معًا.
```
