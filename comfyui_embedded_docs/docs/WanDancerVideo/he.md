# WanDancerVideo

צומת WanDancerVideo מכין נתוני התניה וטנזור latent ריק עבור יצירת וידאו עם מודל WanDancer. הוא מצרף תמונות התחלה אופציונליות, מסכות, הטמעות CLIP vision ותכונות אודיו להתניה החיובית והשלילית כדי שיוכלו להנחות את הווידאו הנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | ההתניה החיובית שמנחה את יצירת הווידאו. | CONDITIONING | כן |  |
| `negative` | ההתניה השלילית שמנחה את יצירת הווידאו. | CONDITIONING | כן |  |
| `vae` | ה-VAE המשמש לקידוד תמונת ההתחלה אל מרחב ה-latent. | VAE | כן |  |
| `width` | הרוחב של הווידאו הנוצר בפיקסלים (ברירת מחדל: 480). | INT | כן | 16 עד MAX_RESOLUTION (צעד: 16) |
| `height` | הגובה של הווידאו הנוצר בפיקסלים (ברירת מחדל: 832). | INT | כן | 16 עד MAX_RESOLUTION (צעד: 16) |
| `length` | מספר הפריימים בווידאו הנוצר. צריך להישאר 149 עבור WanDancer (ברירת מחדל: 149). | INT | כן | 1 עד MAX_RESOLUTION (צעד: 4) |
| `clip_vision_output` | הטמעות CLIP vision עבור הפריים הראשון. | CLIP_VISION_OUTPUT | לא |  |
| `clip_vision_output_ref` | הטמעות CLIP vision עבור תמונת העזר. | CLIP_VISION_OUTPUT | לא |  |
| `start_image` | התמונה או התמונות ההתחלתיות לקידוד, יכולות להיות בכל מספר פריימים. | IMAGE | לא |  |
| `mask` | מסכת התניה לתמונה או לתמונות ההתחלה. לבן נשמר, שחור נוצר. משמשת ליצירות מקומיות. | MASK | לא |  |
| `audio_encoder_output` | פלט מקודד אודיו המספק תכונות אודיו, קצב פריימים וערכי סקלת הזרקה, אשר מצורפים להתניה כאשר הוא מסופק. | AUDIO_ENCODER_OUTPUT | לא |  |

### הערות לגבי התנהגות הפרמטרים

- `start_image` הוא אופציונלי. כאשר הוא מסופק, הוא משתנה לגודל `width` ו-`height`, מקודד על ידי `vae`, ומצורף הן להתניה החיובית והן לשלילית. אם ל-`start_image` יש יותר פריימים מ-`length`, הפריימים הנוספים נזרקים. אם יש לו פחות פריימים, הפריימים החסרים ממולאים בערכי אפס.
- `mask` משפיע רק כאשר גם `start_image` מסופק. אזורים לבנים נשמרים, ואזורים שחורים נוצרים.
- `clip_vision_output_ref` משפיע רק כאשר גם `clip_vision_output` מסופק.
- `audio_encoder_output`, כאשר הוא מסופק, מצרף הטמעות אודיו, קצב פריימים וסקלת הזרקה הן להתניה החיובית והן לשלילית.
