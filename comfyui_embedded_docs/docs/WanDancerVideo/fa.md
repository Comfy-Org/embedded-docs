# WanDancerVideo

WanDancerVideo داده‌های شرطی‌سازی و یک تانسور لاتنت خالی را برای تولید ویدیو با مدل WanDancer آماده می‌کند. این گره شرطی‌سازی مثبت و منفی را دریافت می‌کند و به‌صورت اختیاری آن‌ها را با تصویر شروع، ماسک، بردارهای بینایی CLIP و ویژگی‌های صوتی ترکیب می‌کند تا ویدیوی تولیدشده کنترل شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی مثبت برای هدایت تولید ویدیو. | CONDITIONING | بله |  |
| `negative` | شرطی‌سازی منفی برای هدایت تولید ویدیو. | CONDITIONING | بله |  |
| `vae` | VAE مورد استفاده برای رمزگذاری تصویر شروع در فضای لاتنت. | VAE | بله |  |
| `width` | عرض ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 480). | INT | بله | 16 تا MAX_RESOLUTION (گام: 16) |
| `height` | ارتفاع ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 832). | INT | بله | 16 تا MAX_RESOLUTION (گام: 16) |
| `length` | تعداد فریم‌های ویدیوی تولیدشده. برای WanDancer باید روی 149 بماند (پیش‌فرض: 149). | INT | بله | 1 تا MAX_RESOLUTION (گام: 4) |
| `clip_vision_output` | بردارهای بینایی CLIP برای فریم اول. | CLIP_VISION_OUTPUT | خیر |  |
| `clip_vision_output_ref` | بردارهای بینایی CLIP برای تصویر مرجع. | CLIP_VISION_OUTPUT | خیر |  |
| `start_image` | تصویر(های) اولیه که باید رمزگذاری شوند؛ می‌تواند هر تعداد فریم باشد. | IMAGE | خیر |  |
| `mask` | ماسک شرطی‌سازی تصویر برای تصویر(های) شروع. ناحیه سفید حفظ می‌شود و ناحیه سیاه تولید می‌شود. برای تولیدهای موضعی استفاده می‌شود. | MASK | خیر |  |
| `audio_encoder_output` | خروجی یک رمزگذار صدا که ویژگی‌های صوتی، FPS و مقیاس تزریق صدا را برای تولید شرطی‌شده با صدا فراهم می‌کند. | AUDIO_ENCODER_OUTPUT | خیر |  |

**نکته درباره محدودیت‌های پارامتر:**
- وقتی `start_image` ارائه می‌شود، به ابعاد `width` × `height` تغییر اندازه می‌یابد، به `length` فریم محدود می‌شود و به یک لاتنت رمزگذاری می‌شود که همراه با یک ماسک الحاقی به هر دو شرطی‌سازی متصل می‌شود.
- `mask` فقط زمانی اثر می‌کند که `start_image` نیز ارائه شده باشد. در ماسک، نواحی سفید حفظ می‌شوند و نواحی سیاه تولید می‌شوند. وقتی `mask` ارائه نشود، ناحیه تصویر شروع به‌عنوان راهنمای شرطی‌سازی استفاده می‌شود و فریم‌های باقی‌مانده تولید می‌شوند.
- `clip_vision_output_ref` فقط زمانی اعمال می‌شود که `clip_vision_output` ارائه شده باشد.
- `audio_encoder_output` ویژگی‌های صوتی، FPS و یک مقیاس تزریق صدا (پیش‌فرض: 1.0) را به هر دو شرطی‌سازی اضافه می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت همراه با تمام داده‌های اضافی (لاتنت الحاقی، CLIP vision، صدا). | CONDITIONING |
| `negative` | شرطی‌سازی منفی همراه با تمام داده‌های اضافی (لاتنت الحاقی، CLIP vision، صدا). | CONDITIONING |
| `latent` | یک تانسور لاتنت خالی با ابعادی مطابق با طول، ارتفاع و عرض مشخص‌شده ویدیو. | LATENT |
