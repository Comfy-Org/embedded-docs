# WanDancerVideo

WanDancerVideo подготавливает данные кондиционирования и пустой латентный тензор для генерации видео с помощью модели WanDancer. Он принимает позитивное и негативное кондиционирование и опционально объединяет их с начальным изображением, маской, CLIP vision эмбеддингами и аудио-характеристиками для управления генерируемым видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование для управления генерацией видео. | CONDITIONING | Да |  |
| `negative` | Негативное кондиционирование для управления генерацией видео. | CONDITIONING | Да |  |
| `vae` | VAE, используемый для кодирования начального изображения в латентное пространство. | VAE | Да |  |
| `width` | Ширина генерируемого видео в пикселях (по умолчанию: 480). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `height` | Высота генерируемого видео в пикселях (по умолчанию: 832). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `length` | Количество кадров в генерируемом видео. Для WanDancer должно оставаться 149 (по умолчанию: 149). | INT | Да | 1 to MAX_RESOLUTION (step: 4) |
| `clip_vision_output` | CLIP vision эмбеддинги для первого кадра. | CLIP_VISION_OUTPUT | Нет |  |
| `clip_vision_output_ref` | CLIP vision эмбеддинги для эталонного изображения. | CLIP_VISION_OUTPUT | Нет |  |
| `start_image` | Начальное изображение(я) для кодирования, может быть любым количеством кадров. | IMAGE | Нет |  |
| `mask` | Маска кондиционирования изображения для начального изображения(й). Белые области сохраняются, черные генерируются. Используется для локальных генераций. | MASK | Нет |  |
| `audio_encoder_output` | Выход аудиоэнкодера, предоставляющий аудио-характеристики, FPS и масштаб встраивания аудио для генерации с аудио-кондиционированием. | AUDIO_ENCODER_OUTPUT | Нет |  |

**Примечание об ограничениях параметров:**
- Когда `start_image` указано, оно изменяет размер до `width` × `height`, ограничивается `length` кадрами и кодируется в латентное представление, которое прикрепляется к обоим кондиционированиям вместе с конкатенированной маской.
- `mask` действует только при указанном `start_image`. В маске белые области сохраняются, а черные генерируются. Если `mask` не указана, область начального изображения используется как направляющая кондиционирования, а остальные кадры генерируются.
- `clip_vision_output_ref` применяется только при указанном `clip_vision_output`.
- `audio_encoder_output` добавляет аудио-характеристики, FPS и масштаб встраивания аудио (по умолчанию 1.0) к обоим кондиционированиям.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование с прикрепленными дополнительными данными (concat latent, CLIP vision, audio). | CONDITIONING |
| `negative` | Негативное кондиционирование с прикрепленными дополнительными данными (concat latent, CLIP vision, audio). | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, соответствующими указанным длине, высоте и ширине видео. | LATENT |
