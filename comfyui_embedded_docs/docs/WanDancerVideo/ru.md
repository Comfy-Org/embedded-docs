# WanDancerVideo

Узел WanDancerVideo готовит данные кондиционирования и пустой латентный тензор для генерации видео с помощью модели WanDancer. Он добавляет необязательные начальные изображения, маски, эмбеддинги CLIP vision и аудио-признаки к положительному и отрицательному кондиционированию, чтобы они могли управлять генерируемым видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительное кондиционирование для управления генерацией видео. | CONDITIONING | Да |  |
| `негативный` | Отрицательное кондиционирование для управления генерацией видео. | CONDITIONING | Да |  |
| `vae` | VAE, используемый для кодирования начального изображения в латентное пространство. | VAE | Да |  |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 480). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 832). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `длина` | Количество кадров в генерируемом видео. Для WanDancer должно оставаться 149 (по умолчанию: 149). | INT | Да | 1 to MAX_RESOLUTION (step: 4) |
| `clip_vision_output` | Эмбеддинги CLIP vision для первого кадра. | CLIP_VISION_OUTPUT | Нет |  |
| `clip_vision_output_ref` | Эмбеддинги CLIP vision для эталонного изображения. | CLIP_VISION_OUTPUT | Нет |  |
| `начальное изображение` | Начальное изображение (изображения) для кодирования; может содержать любое количество кадров. | IMAGE | Нет |  |
| `маска` | Маска кондиционирования изображения для начального изображения (изображений). Белые области сохраняются, чёрные — генерируются. Используется для локальной генерации. | MASK | Нет |  |
| `audio_encoder_output` | Выход аудиоэнкодера, который предоставляет аудио-признаки, частоту кадров и значения масштаба инъекции; они добавляются к кондиционированию при наличии. | AUDIO_ENCODER_OUTPUT | Нет |  |

### Примечания о поведении параметров

- `start_image` необязателен. Если он задан, изображение масштабируется до `width` и `height`, кодируется с помощью `vae` и добавляется и к положительному, и к отрицательному кондиционированию. Если в `start_image` больше кадров, чем `length`, лишние кадры отбрасываются. Если кадров меньше, недостающие кадры заполняются нулевыми значениями.
- `mask` влияет на результат только в том случае, если `start_image` также задан. Белые области сохраняются, а чёрные — генерируются.
- `clip_vision_output_ref` влияет на результат только в том случае, если `clip_vision_output` также задан.
- `audio_encoder_output` при наличии добавляет аудио-эмбеддинги, частоту кадров и масштаб инъекции и к положительному, и к отрицательному кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Положительное кондиционирование с добавленными латентным представлением начального изображения, маской, данными CLIP vision или аудиоданными. | CONDITIONING |
| `негативный` | Отрицательное кондиционирование с добавленными латентным представлением начального изображения, маской, данными CLIP vision или аудиоданными. | CONDITIONING |
| `латентный` | Пустой латентный тензор, размер которого соответствует запрошенным длине, высоте и ширине видео. | LATENT |
