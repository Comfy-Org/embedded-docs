# LatentOperationBlend

צומת זה יוצר פעולת לטנט שממזגת לטנט לעבר לטנט ייחוס, ומחזיר את הפעולה הזו כך שניתן לחבר אותה לצמתים כגון Latent Apply Operation או Latent Apply Operation CFG. כאשר לייחוס יש גודל מרחבי שונה, הוא משתנה בגודלו להתאמה ללטנט היעד באמצעות אינטרפולציה של השכן הקרוב (nearest-neighbor), וייחוס עם אצווה קטנה יותר משוכפל כדי להתאים לגודל האצווה של היעד. עוצמה של 0 משאירה את הלטנט ללא שינוי. צומת זה מסומן כניסיוני.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `reference` | הלטנט שאליו ממזגים. הדגימות שלו מומרות להתקן ול-dtype של הלטנט המעובד, ואז משתנות בגודלן ומשוכפלות כדי להתאים לו. | LATENT | כן | - |
| `strength` | עד כמה למזג לעבר הייחוס: 0 משאיר את הלטנט ללא שינוי, 1 מתאים ללטנט הייחוס לאחר שינוי גודל (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 עד 1.0 (צעד 0.0001) |
