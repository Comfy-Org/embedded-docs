# Latent Operation Blend

Этот узел создаёт латентную операцию, которая смешивает латент с эталонным латентом и возвращает эту операцию, чтобы её можно было подключить к таким узлам, как Latent Apply Operation или Latent Apply Operation CFG. Если эталон имеет другой пространственный размер, он масштабируется до целевого латента с помощью интерполяции ближайшего соседа, а эталон с меньшим размером пакета повторяется, чтобы соответствовать целевому размеру пакета. Значение `strength`, равное 0, оставляет латент без изменений. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `reference` | Латент, с которым выполняется смешивание. Его сэмплы приводятся к устройству и типу данных обрабатываемого латента, затем масштабируются и повторяются, чтобы соответствовать ему. | LATENT | Да | - |
| `strength` | Насколько сильно смешивать с эталоном: 0 оставляет латент без изменений, 1 соответствует масштабированному эталонному латенту (по умолчанию: 1.0). | FLOAT | Да | 0.0–1.0 (шаг 0.0001) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `operation` | Операция смешивания, которую можно применить к сэмплам латента. | LATENT_OPERATION |
