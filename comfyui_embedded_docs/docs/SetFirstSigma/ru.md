# SetFirstSigma

Узел `SetFirstSigma` изменяет последовательность сигма, заменяя только её первое значение на пользовательское значение сигма. Он принимает существующую последовательность сигма и новое значение сигма, а затем возвращает новую последовательность сигма, в которой все значения, кроме первого, остаются неизменными.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `сигмы` | Входная последовательность значений сигма для изменения | SIGMAS | Да | - |
| `сигма` | Новое значение сигма, которое будет установлено как первый элемент последовательности (по умолчанию: 136.0) | FLOAT | Да | 0.0 - 20000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Модифицированная последовательность сигма, в которой первый элемент заменён пользовательским значением сигма | SIGMAS |
