# SetFirstSigma

Узел SetFirstSigma изменяет последовательность значений сигмы, заменяя первое значение сигмы в последовательности на пользовательское значение. Он принимает существующую последовательность сигмы и новое значение сигмы в качестве входных данных, затем возвращает новую последовательность сигмы, в которой изменен только первый элемент, а все остальные значения сигмы остаются без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Входная последовательность значений сигмы, которую нужно изменить | SIGMAS | Да | - |
| `sigma` | Новое значение сигмы, которое будет установлено как первый элемент последовательности (по умолчанию: 136.0) | FLOAT | Да | от 0.0 до 20000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sigmas` | Измененная последовательность сигмы, в которой первый элемент заменен на пользовательское значение сигмы | SIGMAS |
