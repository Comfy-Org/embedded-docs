# PolyexponentialScheduler

צומת PolyexponentialScheduler נועד ליצור רצף של רמות רעש (סיגמות) בהתבסס על לוח זמנים לרעש פולי-אקספוננציאלי. לוח זמנים זה הוא פונקציה פולינומית בלוגריתם של sigma, ומאפשר התקדמות גמישה וניתנת להתאמה אישית של רמות הרעש לאורך תהליך הדיפוזיה.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `steps` | מציין את מספר השלבים בתהליך הדיפוזיה, ומשפיע על רמת הפירוט של רמות הרעש שנוצרות. | INT |
| `sigma_max` | רמת הרעש המקסימלית, המגדירה את הגבול העליון של לוח הזמנים לרעש. | FLOAT |
| `sigma_min` | רמת הרעש המינימלית, המגדירה את הגבול התחתון של לוח הזמנים לרעש. | FLOAT |
| `rho` | פרמטר השולט בצורת לוח הזמנים לרעש הפולי-אקספוננציאלי, ומשפיע על אופן ההתקדמות של רמות הרעש בין ערכי המינימום והמקסימום. | FLOAT |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `sigmas` | הפלט הוא רצף של רמות רעש (סיגמות) המותאם ללוח הזמנים שצוין לרעש פולי-אקספוננציאלי. | SIGMAS |
