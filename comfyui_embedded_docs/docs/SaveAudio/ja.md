# オーディオを保存

SaveAudio ノードは、オーディオデータを FLAC 形式のファイルに保存します。オーディオ入力を取得し、指定されたファイル名プレフィックスを使用して出力ディレクトリに書き込み、同じオーディオを出力としてそのまま渡します。このノードは非推奨であり、現在の Save Audio ノードに置き換える必要があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 保存されるオーディオデータ | AUDIO | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス（デフォルト: "audio/ComfyUI"） | STRING | いいえ | - |

`audio` が None の場合、ノードはエラーを発生させます。これは、ソースビデオにオーディオトラックがない場合に発生する可能性があります。

`prompt` と `extra_pnginfo` パラメータは非表示であり、システムによって自動的に処理されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | ファイルに保存された同じオーディオデータ | AUDIO |
