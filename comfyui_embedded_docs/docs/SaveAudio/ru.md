# Сохранить аудио

Узел SaveAudio сохраняет аудиоданные в файл в формате FLAC. Он принимает аудиовход, записывает его в выходной каталог с указанным префиксом имени файла и передает те же аудиоданные на выход. Этот узел устарел и должен быть заменен текущим узлом Save Audio.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудиоданные для сохранения | AUDIO | Да | - |
| `filename_prefix` | Префикс имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |

Узел вызывает ошибку, если `audio` имеет значение None, что может произойти, когда в исходном видео отсутствует аудиодорожка.

Параметры `prompt` и `extra_pnginfo` являются скрытыми и обрабатываются системой автоматически.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Те же аудиоданные, которые были сохранены в файл | AUDIO |
