# Сохранить аудио

Этот узел сохраняет аудиоданные в файл в формате FLAC. Он принимает аудиовход и записывает его в выходной каталог, используя указанный префикс имени файла. Этот узел устарел и должен быть заменен текущим узлом Save Audio.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `аудио` | Аудиоданные для сохранения | AUDIO | Да | - |
| `префикс_названия_файла` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |

*Примечание: параметры `prompt` и `extra_pnginfo` скрыты и обрабатываются системой автоматически.*

Если вход `audio` не получает данных (например, когда в исходном видео отсутствует аудиодорожка), узел вызывает ошибку, и файл не сохраняется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `аудио` | Аудиоданные, переданные на вход, пропускаются через узел после сохранения файла | AUDIO |
