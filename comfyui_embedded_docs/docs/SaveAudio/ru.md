# Сохранить аудио

Этот узел сохраняет аудиоданные в файл в формате FLAC. Он принимает аудиовход и записывает его в выходной каталог с использованием указанного префикса имени файла, а также передаёт аудио на свой выход. Этот узел устарел, и его следует заменить текущим узлом Save Audio.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `аудио` | Аудиоданные для сохранения | AUDIO | Да | - |
| `префикс_названия_файла` | Префикс имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |

*Примечание: Параметры `prompt` и `extra_pnginfo` скрыты и автоматически обрабатываются системой.*

Если на вход `audio` не поступают данные (например, когда в исходном видео нет аудиодорожки), узел вызывает ошибку, и файл не сохраняется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `audio` | Аудиоданные, которые были поданы на вход и переданы дальше после сохранения файла | AUDIO |
