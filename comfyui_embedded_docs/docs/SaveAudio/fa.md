# ذخیره صدا (FLAC)

گره SaveAudio داده‌های صوتی را در قالب FLAC در یک فایل ذخیره می‌کند. این گره یک ورودی صوتی دریافت می‌کند، آن را با استفاده از پیشوند نام فایل مشخص‌شده در دایرکتوری خروجی می‌نویسد و همان `audio` را به‌عنوان خروجی خود عبور می‌دهد. این گره منسوخ شده است و باید با گره Save Audio فعلی جایگزین شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده صوتی که باید ذخیره شود | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |

اگر `audio` برابر None باشد، گره خطا ایجاد می‌کند؛ این اتفاق زمانی رخ می‌دهد که ویدیوی منبع هیچ آهنگ صوتی نداشته باشد.

پارامترهای `prompt` و `extra_pnginfo` پنهان هستند و به‌طور خودکار توسط سیستم مدیریت می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | همان داده صوتی که در فایل ذخیره شده است | AUDIO |
