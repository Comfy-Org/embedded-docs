# ذخیره صدا (FLAC)

این گره داده‌های صوتی را در قالب FLAC در یک فایل ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و با استفاده از پیشوند نام فایل مشخص‌شده، آن را در دایرکتوری خروجی می‌نویسد. این گره منسوخ شده است و باید با گره فعلی Save Audio جایگزین شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده‌های صوتی که باید ذخیره شوند | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |

*توجه: پارامترهای `prompt` و `extra_pnginfo` پنهان هستند و به‌طور خودکار توسط سیستم مدیریت می‌شوند.*

اگر ورودی `audio` داده‌ای دریافت نکند (مثلاً وقتی ویدیوی منبع تراک صوتی نداشته باشد)، گره یک خطا ایجاد می‌کند و هیچ فایلی ذخیره نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `صدا` | داده‌های صوتی که به ورودی ارائه شده بود، پس از ذخیره فایل عبور داده می‌شود | AUDIO |
