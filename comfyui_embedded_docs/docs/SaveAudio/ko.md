# 오디오 저장

SaveAudio 노드는 FLAC 형식의 파일에 오디오 데이터를 저장합니다. 이 노드는 오디오 입력을 받아 지정된 파일 이름 접두사를 사용하여 출력 디렉터리에 저장하고, 동일한 오디오를 출력으로 전달합니다. 이 노드는 더 이상 사용되지 않으므로 현재 Save Audio 노드로 대체해야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 저장할 오디오 데이터입니다. | AUDIO | 예 | - |
| `filename_prefix` | 출력 파일 이름의 접두사입니다 (기본값: "audio/ComfyUI") | STRING | 아니요 | - |

`audio`가 None인 경우 노드에서 오류가 발생합니다. 이는 소스 비디오에 오디오 트랙이 없을 때 발생할 수 있습니다.

`prompt` 및 `extra_pnginfo` 매개변수는 숨겨져 있으며 시스템에서 자동으로 처리됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 파일에 저장된 것과 동일한 오디오 데이터입니다. | AUDIO |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SaveAudio/ko.md)
