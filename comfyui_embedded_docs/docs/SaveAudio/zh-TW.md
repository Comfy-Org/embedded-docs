# 儲存音訊

此節點會將音訊資料儲存為 FLAC 格式的檔案。它接收音訊輸入，並使用指定的檔名前綴將其寫入輸出目錄，同時也會將音訊傳遞至其輸出。此節點已棄用，應替換為目前的 Save Audio 節點。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `音訊` | 要儲存的音訊資料 | AUDIO | 是 | - |
| `檔名前綴` | 輸出檔名的前綴（預設值："audio/ComfyUI"） | STRING | 否 | - |

*注意：`prompt` 和 `extra_pnginfo` 參數是隱藏的，並由系統自動處理。*

如果 `audio` 輸入未收到任何資料（例如來源影片沒有音軌），此節點會引發錯誤，且不會儲存任何檔案。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `audio` | 提供給輸入的音訊資料，會在檔案儲存後傳遞出去 | AUDIO |
