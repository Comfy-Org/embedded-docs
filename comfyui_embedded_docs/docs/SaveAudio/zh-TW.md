# 儲存音訊

此節點將音訊資料以 FLAC 格式儲存至檔案。它接受音訊輸入，並使用指定的檔案名稱前綴將其寫入輸出目錄。此節點已棄用，應以目前的 Save Audio 節點取代。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `音訊` | 要儲存的音訊資料 | AUDIO | 是 | - |
| `檔名前綴` | 輸出檔案名稱的前綴（預設值："audio/ComfyUI"） | STRING | 否 | - |

*注意：`prompt` 和 `extra_pnginfo` 參數為隱藏參數，由系統自動處理。*

如果 `audio` 輸入沒有收到任何資料（例如，當來源影片沒有音軌時），此節點會引發錯誤，且不會儲存任何檔案。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `audio` | 輸入所提供的音訊資料，在檔案儲存後原樣傳遞 | AUDIO |
