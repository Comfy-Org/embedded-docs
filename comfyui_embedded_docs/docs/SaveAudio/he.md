# שמור אודיו (FLAC) (מיושן)

צומת זה שומר נתוני אודיו לקובץ בפורמט FLAC. הוא מקבל קלט אודיו וכותב אותו לספריית הפלט באמצעות קידומת שם הקובץ שצוינה, וכן מעביר את האודיו הלאה אל הפלט שלו. צומת זה הוצא משימוש ויש להחליפו בצומת Save Audio הנוכחי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio` | נתוני האודיו שיש לשמור | AUDIO | כן | - |
| `filename_prefix` | הקידומת של שם קובץ הפלט (ברירת מחדל: "audio/ComfyUI") | STRING | לא | - |

*הערה: הפרמטרים `prompt` ו-`extra_pnginfo` מוסתרים ומטופלים אוטומטית על ידי המערכת.*

אם הקלט `audio` לא מקבל נתונים (למשל, כאשר לקובץ הווידאו המקור אין רצועת אודיו), הצומת מפעיל שגיאה ושום קובץ לא נשמר.

## פלטים
