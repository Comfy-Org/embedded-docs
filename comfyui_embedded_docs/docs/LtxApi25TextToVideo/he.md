# LtxApi25TextToVideo

LTX 2.5 Text To Video הוא צומת API שמייצר וידאו באיכות מקצועית מתיאור טקסטואלי באמצעות מודל LTX 2.5. אתם מספקים פרומפט ובוחרים הגדרות יצירה כגון דרגת המודל, משך, רזולוציה, קצב פריימים והאם לכלול אודיו; הצומת שולח את המשימה ל-API של LTX ומחזיר את הווידאו שנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | דרגת המודל LTX 2.5 לשימוש ליצירת וידאו. | STRING | כן | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `model.duration` | אורך הווידאו שנוצר. | INT | כן | מספר שלם |
| `model.resolution` | רזולוציית הפלט של הווידאו. האפשרויות הזמינות תלויות ב-`model` הנבחר. | STRING | כן | עם "LTX-2.5 (Fast)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840"<br>עם "LTX-2.5 (Pro)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920" |
| `model.fps` | קצב פריימים של הווידאו שנוצר (ברירת מחדל: 25). | INT | לא | מספר שלם |
| `model.generate_audio` | האם ליצור אודיו יחד עם הווידאו (ברירת מחדל: True). | BOOLEAN | לא | True<br>False |
| `prompt` | תיאור טקסטואלי של הווידאו ליצירה. נדרש פרומפט לא ריק באורך של עד 10,000 תווים (ברירת מחדל: ""). | STRING | כן | 1 עד 10000 תווים |
| `seed` | ערך seed המשמש ליצירה ניתנת לשחזור (ברירת מחדל: 42). | INT | לא | מספר שלם |

הערה: האפשרויות הזמינות של `model.resolution` תלויות ב-`model` הנבחר. "LTX-2.5 (Fast)" תומך ברזולוציות של עד 2160x3840, בעוד "LTX-2.5 (Pro)" תומך ברזולוציות של עד 1920x1080.
