# LTX 2.5 Текст в Видео

LTX 2.5 Text To Video — это API-узел, который создает видео профессионального качества по текстовому описанию с использованием модели LTX 2.5. Вы предоставляете текстовый запрос и выбираете параметры генерации, такие как уровень модели, продолжительность, разрешение, частота кадров и необходимость включения аудио; узел отправляет задачу в LTX API и возвращает полученное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Уровень модели LTX 2.5, используемый для генерации видео. | STRING | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `длительность` | Продолжительность создаваемого видео. | INT | Да | Целое число |
| `разрешение` | Выходное разрешение видео. Доступные варианты зависят от выбранной `model`. | STRING | Да | С "LTX-2.5 (Fast)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840"<br>С "LTX-2.5 (Pro)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920" |
| `fps` | Частота кадров создаваемого видео (по умолчанию: 25). | INT | Нет | Целое число |
| `генерировать аудио` | Определяет, нужно ли генерировать аудио вместе с видео (по умолчанию: True). | BOOLEAN | Нет | True<br>False |
| `промпт` | Текстовое описание видео для генерации. Требуется непустой запрос длиной до 10 000 символов (по умолчанию: ""). | STRING | Да | от 1 до 10000 символов |
| `seed` | Значение seed, используемое для воспроизводимой генерации (по умолчанию: 42). | INT | Нет | Целое число |

Примечание: Доступные варианты `model.resolution` зависят от выбранной `model`. «LTX-2.5 (Fast)» поддерживает разрешения до 2160x3840, а «LTX-2.5 (Pro)» — до 1920x1080.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Видео, возвращаемое LTX API, готовое к дальнейшему использованию в рабочем процессе. Если генерация аудио была включена, видео содержит синхронизированное аудио. | VIDEO |
