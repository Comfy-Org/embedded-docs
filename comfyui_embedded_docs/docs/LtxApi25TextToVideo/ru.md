# LtxApi25TextToVideo

LTX 2.5 Text To Video — это API-узел, который генерирует видео профессионального качества на основе текстового описания с использованием модели LTX 2.5. Вы предоставляете текстовое описание (промпт) и выбираете параметры генерации, такие как уровень модели, длительность, разрешение, частота кадров и необходимость включения аудио; узел отправляет задачу в LTX API и возвращает итоговое видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Уровень модели LTX 2.5, используемый для генерации видео. | STRING | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `model.duration` | Длительность генерируемого видео. | INT | Да | Целое число |
| `model.resolution` | Разрешение выходного видео. Доступные варианты зависят от выбранного `model`. | STRING | Да | Для "LTX-2.5 (Fast)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840"<br>Для "LTX-2.5 (Pro)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920" |
| `model.fps` | Частота кадров генерируемого видео (по умолчанию: 25). | INT | Нет | Целое число |
| `model.generate_audio` | Нужно ли генерировать аудио вместе с видео (по умолчанию: True). | BOOLEAN | Нет | True<br>False |
| `prompt` | Текстовое описание видео для генерации. Требуется непустой промпт длиной до 10 000 символов (по умолчанию: ""). | STRING | Да | от 1 до 10000 символов |
| `seed` | Значение seed, используемое для воспроизводимой генерации (по умолчанию: 42). | INT | Нет | Целое число |

Примечание: доступные варианты `model.resolution` зависят от выбранного `model`. "LTX-2.5 (Fast)" поддерживает разрешения до 2160x3840, а "LTX-2.5 (Pro)" — до 1920x1080.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, возвращаемое LTX API, готовое к дальнейшему использованию в рабочем процессе. Если генерация аудио была включена, видео содержит синхронизированное аудио. | VIDEO |
