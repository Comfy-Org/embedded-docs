# LTX 2.5 تحويل النص إلى فيديو

LTX 2.5 Text To Video هو عقدة API تولّد فيديوهات بجودة احترافية من وصف نصي باستخدام نموذج LTX 2.5. يمكنك تقديم موجه (prompt) واختيار إعدادات التوليد مثل فئة النموذج، والمدة، والدقة، ومعدل الإطارات، وما إذا كان سيتم تضمين الصوت؛ تقوم العقدة بإرسال المهمة إلى LTX API وتعيد الفيديو الناتج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | فئة نموذج LTX 2.5 المستخدمة لتوليد الفيديو. | STRING | نعم | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `المدة` | طول الفيديو المولّد. | INT | نعم | عدد صحيح |
| `الدقة` | دقة الفيديو الناتج. تعتمد الخيارات المتاحة على `model` المحدد. | STRING | نعم | مع "LTX-2.5 (Fast)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840"<br>مع "LTX-2.5 (Pro)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920" |
| `معدل الإطارات` | معدل إطارات الفيديو المولّد (الافتراضي: 25). | INT | لا | عدد صحيح |
| `توليد الصوت` | ما إذا كان سيتم توليد الصوت مع الفيديو (الافتراضي: True). | BOOLEAN | لا | True<br>False |
| `المطالبة` | الوصف النصي للفيديو المراد توليده. يجب ألا يكون فارغًا وأن يصل طوله إلى 10,000 حرف كحد أقصى (الافتراضي: ""). | STRING | نعم | من 1 إلى 10000 حرف |
| `البذرة` | قيمة البذرة المستخدمة لتوليد قابل لإعادة الإنتاج (الافتراضي: 42). | INT | لا | عدد صحيح |

ملاحظة: تعتمد خيارات `model.resolution` المتاحة على `model` المحدد. يدعم "LTX-2.5 (Fast)" دقة تصل إلى 2160x3840، بينما يدعم "LTX-2.5 (Pro)" دقة تصل إلى 1920x1080.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `video` | الفيديو المولّد المُعاد من LTX API، وجاهز لمزيد من الاستخدام في سير العمل. إذا كان توليد الصوت مفعّلًا، يتضمن الفيديو صوتًا متزامنًا. | VIDEO |
