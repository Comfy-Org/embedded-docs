# LTX ۲.۵ تبدیل متن به ویدیو

LTX 2.5 Text To Video یک گره API است که با استفاده از مدل LTX 2.5، ویدیوهایی با کیفیت حرفه‌ای از توصیف متنی تولید می‌کند. شما یک پرامپت ارائه می‌دهید و تنظیمات تولید مانند سطح مدل، مدت‌زمان، وضوح، نرخ فریم و گنجاندن صدا را انتخاب می‌کنید؛ گره وظیفه را به API LTX ارسال کرده و ویدیوی حاصل را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | سطح مدل LTX 2.5 برای تولید ویدیو. | STRING | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `مدت زمان` | مدت‌زمان ویدیوی تولیدشده. | INT | بله | عدد صحیح |
| `رزولوشن` | وضوح خروجی ویدیو. گزینه‌های موجود به `model` انتخاب‌شده بستگی دارند. | STRING | بله | با "LTX-2.5 (Fast)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840"<br>با "LTX-2.5 (Pro)":<br>"1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920" |
| `فریم بر ثانیه` | نرخ فریم ویدیوی تولیدشده (پیش‌فرض: 25). | INT | خیر | عدد صحیح |
| `تولید صوت` | آیا صدا همراه با ویدیو تولید شود (پیش‌فرض: True). | BOOLEAN | خیر | True<br>False |
| `پرامپت` | توصیف متنی ویدیوی موردنظر برای تولید. یک پرامپت غیرخالی تا ۱۰۰۰۰ کاراکتر الزامی است (پیش‌فرض: ""). | STRING | بله | 1 تا 10000 کاراکتر |
| `بذر` | مقدار seed برای تولید قابل تکرار (پیش‌فرض: 42). | INT | خیر | عدد صحیح |

توجه: گزینه‌های `model.resolution` موجود به `model` انتخاب‌شده بستگی دارند. "LTX-2.5 (Fast)" از وضوح‌ها تا 2160x3840 پشتیبانی می‌کند، در حالی که "LTX-2.5 (Pro)" از وضوح‌ها تا 1920x1080 پشتیبانی می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی تولیدشده که توسط API LTX بازگردانده شده و برای استفاده بیشتر در گردش کار آماده است. اگر تولید صدا فعال شده باشد، ویدیو شامل صدای همگام‌سازی‌شده است. | VIDEO |
