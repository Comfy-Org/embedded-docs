# عدد صحیح

گره PrimitiveInt راهی ساده برای کار با مقادیر صحیح در گردش کار شما فراهم می‌کند. این گره یک ورودی صحیح می‌گیرد و همان مقدار را خروجی می‌دهد؛ بنابراین برای انتقال پارامترهای صحیح بین گره‌ها یا تنظیم مقادیر عددی مشخص برای سایر عملیات مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `مقدار` | مقدار صحیحی که باید خروجی داده شود (پیش‌فرض: 0). این مقدار ثابت می‌ماند و پس از تولید به‌صورت خودکار تغییر نمی‌کند. | INT | بله | -9223372036854775807 تا 9223372036854775807 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | مقدار صحیح ورودی که بدون تغییر عبور داده می‌شود | INT |
