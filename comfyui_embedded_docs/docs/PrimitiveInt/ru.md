# Int

Узел `PrimitiveInt` предоставляет простой способ работы с целочисленными значениями в вашем рабочем процессе. Он принимает целочисленное значение и выводит то же самое значение, что делает его полезным для передачи целочисленных параметров между узлами или установки конкретных числовых значений для других операций.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `value` | Целочисленное значение для вывода (по умолчанию: 0) | INT | Да | -9223372036854775807 to 9223372036854775807 |

Примечание: Параметр `value` настроен на фиксированное поведение control-after-generate, поэтому значение не изменяется автоматически после каждой генерации.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Входное целочисленное значение, переданное без изменений | INT |
