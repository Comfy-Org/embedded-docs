# Int

Узел PrimitiveInt предоставляет простой способ работы с целочисленными значениями в вашем рабочем процессе. Он принимает целочисленное значение на входе и возвращает то же самое значение, что делает его полезным для передачи целочисленных параметров между узлами или задания конкретных числовых значений для других операций.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Целочисленное значение для вывода (по умолчанию: 0). Значение остаётся фиксированным и не изменяется автоматически после генерации. | INT | Да | -9223372036854775807 до 9223372036854775807 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Входное целочисленное значение передаётся без изменений | INT |
