# Int

Le nœud PrimitiveInt offre un moyen simple de travailler avec des valeurs entières dans votre flux de travail. Il prend une entrée entière et produit la même valeur, ce qui est utile pour transmettre des paramètres entiers entre les nœuds ou définir des valeurs numériques spécifiques pour d'autres opérations.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `valeur` | La valeur entière à produire (défaut : 0). La valeur reste fixe et ne change pas automatiquement après la génération. | INT | Oui | -9223372036854775807 à 9223372036854775807 |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La valeur entière d'entrée, transmise sans modification | INT |
