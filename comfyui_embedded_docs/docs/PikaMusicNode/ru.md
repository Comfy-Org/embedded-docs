# Pika Music

Этот узел генерирует музыку по текстовому описанию и необязательному тексту песни либо создаёт кавер-версию предоставленной вами песни с помощью Pika. Выберите `"text to music"`, чтобы создать новую песню заданной вами длительности, или `"cover"`, чтобы перезаписать песню с сохранением её длительности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mode` | Что делает узел: `"text to music"` создаёт новую песню, `"cover"` перезаписывает предоставленную песню. Каждый режим показывает свои входы ниже. По умолчанию: `"text to music"`. | DYNAMIC_COMBO | Да | `"text to music"`<br>`"cover"` |

### Входы Text to Music

Эти входы появляются, когда для `mode` установлено значение `"text to music"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Каким должно быть звучание музыки. Промпт не должен быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | от 1 до 4000 символов |
| `lyrics` | Необязательный текст песни. Разрешены теги секций, такие как `[Verse]` и `[Chorus]`. По умолчанию: "" (пустая строка). | STRING | Да | от 0 до 8000 символов |
| `duration` | Длительность песни в секундах. По умолчанию: 30.0. | FLOAT | Да | от 10.0 до 360.0 (шаг: 0.1) |
| `rewrite_prompt` | Расширять короткий или нечёткий промпт с помощью модели перед генерацией. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `seed` | Сид для сэмплирования. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы Cover

Эти входы появляются, когда для `mode` установлено значение `"cover"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `source_audio` | Песня для кавер-версии. Результат имеет такую же длительность, ограниченную диапазоном от 5 до 360 секунд. | AUDIO | Да | - |
| `prompt` | Каким должно быть звучание кавер-версии. Промпт не должен быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | от 1 до 4000 символов |
| `lyrics` | Необязательный текст песни. Разрешены теги секций, такие как `[Verse]` и `[Chorus]`. По умолчанию: "" (пустая строка). | STRING | Да | от 0 до 8000 символов |
| `rewrite_prompt` | Расширять короткий или нечёткий промпт с помощью модели перед генерацией. По умолчанию: False. | BOOLEAN | Да | true<br>false |
| `seed` | Сид для сэмплирования. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения:**

* Промпт должен содержать от 1 до 4000 символов, а текст песни — не более 8000 символов.
* Режим `"cover"` игнорирует `duration`: длительность выхода совпадает с длительностью `source_audio`, ограниченной диапазоном от 5 до 360 секунд.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Сгенерированная песня или кавер-версия предоставленной композиции. | AUDIO |
