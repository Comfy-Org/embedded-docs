# Pika Music

این گره با Pika از یک توصیف متنی و متن ترانه اختیاری موسیقی تولید می‌کند، یا آهنگی را که ارائه می‌دهید کاور می‌کند. برای ساخت آهنگ جدیدی با طولی که تعیین می‌کنید `"text to music"` را انتخاب کنید، یا برای بازضبط یک آهنگ با حفظ طول آن `"cover"` را انتخاب کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `mode` | کاری که گره انجام می‌دهد: `"text to music"` آهنگ جدیدی می‌سازد، `"cover"` آهنگ ارائه‌شده را بازضبط می‌کند. هر حالت ورودی‌های مخصوص خود را در ادامه نمایش می‌دهد. پیش‌فرض: `"text to music"`. | DYNAMIC_COMBO | بله | `"text to music"`<br>`"cover"` |

### ورودی‌های Text to Music

این ورودی‌ها زمانی ظاهر می‌شوند که `mode` روی `"text to music"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | اینکه موسیقی چه صدایی داشته باشد. نباید خالی باشد. پیش‌فرض: "" (رشته خالی). | STRING | بله | 1 تا 4000 کاراکتر |
| `lyrics` | متن ترانه اختیاری. برچسب‌های بخش مانند `[Verse]` و `[Chorus]` مجاز هستند. پیش‌فرض: "" (رشته خالی). | STRING | بله | 0 تا 8000 کاراکتر |
| `duration` | طول آهنگ بر حسب ثانیه. پیش‌فرض: 30.0. | FLOAT | بله | 10.0 تا 360.0 (گام: 0.1) |
| `rewrite_prompt` | پیش از تولید، پرامپت کوتاه یا مبهم را با یک مدل گسترش می‌دهد. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `seed` | بذر برای نمونه‌گیری. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

### ورودی‌های Cover

این ورودی‌ها زمانی ظاهر می‌شوند که `mode` روی `"cover"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `source_audio` | آهنگی که باید کاور شود. نتیجه همان طول را دارد و به 5 تا 360 ثانیه محدود می‌شود. | AUDIO | بله | - |
| `prompt` | اینکه کاور چه صدایی داشته باشد. نباید خالی باشد. پیش‌فرض: "" (رشته خالی). | STRING | بله | 1 تا 4000 کاراکتر |
| `lyrics` | متن ترانه اختیاری. برچسب‌های بخش مانند `[Verse]` و `[Chorus]` مجاز هستند. پیش‌فرض: "" (رشته خالی). | STRING | بله | 0 تا 8000 کاراکتر |
| `rewrite_prompt` | پیش از تولید، پرامپت کوتاه یا مبهم را با یک مدل گسترش می‌دهد. پیش‌فرض: False. | BOOLEAN | بله | true<br>false |
| `seed` | بذر برای نمونه‌گیری. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

**محدودیت‌ها:**

* پرامپت باید بین 1 تا 4000 کاراکتر باشد و متن ترانه حداکثر 8000 کاراکتر.
* حالت Cover مقدار `duration` را نادیده می‌گیرد: طول خروجی با طول `source_audio` مطابقت دارد و به 5 تا 360 ثانیه محدود می‌شود.
