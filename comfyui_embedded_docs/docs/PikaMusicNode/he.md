# Pika Music

צומת זה מייצר מוזיקה מתיאור טקסטואלי ומילות שיר אופציונליות, או יוצר קאבר לשיר שסיפקת, באמצעות Pika. בחר `"text to music"` כדי ליצור שיר חדש באורך שתגדיר, או `"cover"` כדי להקליט מחדש שיר ולשמור על אורכו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mode` | מה הצומת עושה: `"text to music"` יוצר שיר חדש, `"cover"` מקליט מחדש שיר שסופק. כל מצב חושף את הקלטים שלו למטה. ברירת מחדל: `"text to music"`. | DYNAMIC_COMBO | כן | `"text to music"`<br>`"cover"` |

### קלטים של טקסט למוזיקה

קלטים אלו מופיעים כאשר `mode` מוגדר ל־`"text to music"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | איך המוזיקה אמורה להישמע. לא יכול להיות ריק. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 1 עד 4000 תווים |
| `lyrics` | מילות שיר אופציונליות. תגי קטע כגון `[Verse]` ו־`[Chorus]` מותרים. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 0 עד 8000 תווים |
| `duration` | אורך השיר בשניות. ברירת מחדל: 30.0. | FLOAT | כן | 10.0 עד 360.0 (צעד: 0.1) |
| `rewrite_prompt` | הרחב פרומפט קצר או מעורפל באמצעות מודל לפני היצירה. ברירת מחדל: False. | BOOLEAN | כן | true<br>false |
| `seed` | זרע לדגימה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

### קלטים של קאבר

קלטים אלו מופיעים כאשר `mode` מוגדר ל־`"cover"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `source_audio` | השיר ליצירת קאבר. אורך התוצאה יהיה זהה, מוגבל ל־5 עד 360 שניות. | AUDIO | כן | - |
| `prompt` | איך הקאבר אמור להישמע. לא יכול להיות ריק. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 1 עד 4000 תווים |
| `lyrics` | מילות שיר אופציונליות. תגי קטע כגון `[Verse]` ו־`[Chorus]` מותרים. ברירת מחדל: "" (מחרוזת ריקה). | STRING | כן | 0 עד 8000 תווים |
| `rewrite_prompt` | הרחב פרומפט קצר או מעורפל באמצעות מודל לפני היצירה. ברירת מחדל: False. | BOOLEAN | כן | true<br>false |
| `seed` | זרע לדגימה. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים:**

* הפרומפט חייב להיות בין 1 ל־4000 תווים, ומילות השיר 8000 תווים או פחות.
* מצב `cover` מתעלם מ־`duration`: הפלט תואם את אורך `source_audio`, מוגבל ל־5 עד 360 שניות.
