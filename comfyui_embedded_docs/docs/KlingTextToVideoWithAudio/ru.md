# Kling Text to Video with Audio

Узел Kling Text to Video with Audio генерирует короткое видео из текстового описания. Он отправляет запрос в сервис Kling AI, который обрабатывает промпт и возвращает видеофайл. Узел также может генерировать сопровождающее аудио для видео на основе текста.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель ИИ для генерации видео. | COMBO | Да | `"kling-v2-6"` |
| `prompt` | Положительный текстовый промпт. Описание, используемое для генерации видео. Должно содержать от 1 до 2500 символов. | STRING | Да | - |
| `mode` | Рабочий режим генерации видео. | COMBO | Да | `"pro"` |
| `aspect_ratio` | Желаемое соотношение ширины к высоте для сгенерированного видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность видео в секундах. | COMBO | Да | `5`<br>`10` |
| `generate_audio` | Управляет тем, будет ли сгенерировано аудио для видео. При включении ИИ создаст звук на основе промпта (по умолчанию: `True`). | BOOLEAN | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
