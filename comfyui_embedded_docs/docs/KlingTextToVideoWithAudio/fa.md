# Kling تبدیل متن به ویدیو با صدا

گره Kling Text to Video with Audio یک ویدیوی کوتاه از یک توضیح متنی تولید می‌کند. این گره یک درخواست به سرویس Kling AI ارسال می‌کند که پرامپت را پردازش کرده و یک فایل ویدیو برمی‌گرداند. این گره همچنین می‌تواند بر اساس متن، صدای همراه برای ویدیو تولید کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل هوش مصنوعی مشخص برای استفاده در تولید ویدیو. | COMBO | بله | `"kling-v2-6"` |
| `prompt` | پرامپت متنی مثبت. توصیفی که برای تولید ویدیو استفاده می‌شود. باید بین ۱ تا ۲۵۰۰ نویسه باشد. | STRING | بله | - |
| `mode` | حالت عملیاتی برای تولید ویدیو. | COMBO | بله | `"pro"` |
| `aspect_ratio` | نسبت عرض به ارتفاع موردنظر برای ویدیوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | طول ویدیو بر حسب ثانیه. | COMBO | بله | `5`<br>`10` |
| `generate_audio` | کنترل می‌کند که آیا صدا برای ویدیو تولید شود یا نه. وقتی فعال باشد، هوش مصنوعی بر اساس پرامپت صدا می‌سازد (پیش‌فرض: `True`). | BOOLEAN | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | فایل ویدیوی تولیدشده. | VIDEO |
