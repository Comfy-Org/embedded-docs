# Пустой LatentAudio

Узел `EmptyLatentAudio` создаёт пустой латентный тензор для обработки аудио. Он генерирует пустое аудиолатентное представление с заданной длительностью и размером пакета, которое можно использовать в качестве отправной точки для рабочих процессов генерации или обработки аудио. Узел автоматически вычисляет соответствующие размерности латентного тензора на основе длительности аудио и частоты дискретизации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `seconds` | Длительность аудио в секундах (по умолчанию: 47.6) | FLOAT | Да | 1.0 - 1000.0 (step 0.1) |
| `batch_size` | Количество латентных изображений в пакете (по умолчанию: 1) | INT | Да | 1 - 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Возвращает пустой латентный тензор для обработки аудио с указанной длительностью и размером пакета. Тензор имеет форму [batch_size, 64, length], где length вычисляется на основе длительности аудио и частоты дискретизации. Выходные данные также содержат метаданные, указывающие тип "audio" и коэффициент временного понижения разрешения 2048. | LATENT |
