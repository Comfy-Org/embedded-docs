# ImageGrid

צומת Image Grid משלבת מספר תמונות לרשת או לקולאז' מסודרים. היא מקבלת רשימת תמונות ומסדרת אותן במספר עמודות שצוין, משנה את גודל כל תמונה כך שתתאים לגודל תא מוגדר, ומוסיפה ריפוד אופציונלי ביניהן. התוצאה היא תמונה חדשה אחת המכילה את כל תמונות הקלט בפריסת רשת.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `images` | רשימה של תמונות שיש לסדר ברשת. הצומת דורש לפחות תמונה אחת כדי לפעול. | IMAGE | כן | - |
| `columns` | מספר העמודות ברשת (ברירת מחדל: 4). | INT | לא | 1 - 20 |
| `cell_width` | הרוחב, בפיקסלים, של כל תא ברשת (ברירת מחדל: 256). | INT | לא | 32 - 2048 |
| `cell_height` | הגובה, בפיקסלים, של כל תא ברשת (ברירת מחדל: 256). | INT | לא | 32 - 2048 |
| `padding` | כמות הריפוד, בפיקסלים, שיש להציב בין תמונות ברשת (ברירת מחדל: 4). | INT | לא | 0 - 50 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | תמונת הפלט היחידה המכילה את כל תמונות הקלט המסודרות ברשת. | IMAGE |
