# Kling Omni Первый-Последний Кадр в Видео (Pro)

Этот узел использует новейшую модель Kling AI для генерации видео из начального кадра, необязательного конечного кадра или эталонных изображений. Он может создавать одно видео или многосегментную раскадровку с отдельными промптами и длительностями для каждого сегмента. Узел обрабатывает эти входные данные для создания видео заданной длины и разрешения с возможностью генерации аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling AI, используемая для генерации видео. | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовый промпт, описывающий содержимое видео. Может включать как положительные, так и отрицательные описания. Игнорируется при включенной раскадровке. | STRING | Да | - |
| `duration` | Желаемая длительность создаваемого видео в секундах (по умолчанию: 5). | INT | Да | 3 до 15 |
| `first_frame` | Начальный кадр для видеопоследовательности. | IMAGE | Да | - |
| `end_frame` | Необязательный конечный кадр видео. Его нельзя использовать одновременно с `reference_images`. Не работает с раскадровкой. | IMAGE | Нет | - |
| `reference_images` | До 6 дополнительных эталонных изображений. | IMAGE | Нет | - |
| `resolution` | Выходное разрешение для создаваемого видео (по умолчанию: "1080p"). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `раскадровки` | Создание серии видеосегментов с отдельными промптами и длительностями. Поддерживается только для `kling-v3-omni`. | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `создать аудио` | Генерация аудио для видео (по умолчанию: False). Поддерживается только для `kling-v3-omni`. | BOOLEAN | Нет | True / False |
| `seed` | Сид (seed) управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Нет | 0 до 2147483647 |

### Входы раскадровки

Когда параметр `storyboards` имеет значение, отличное от `"disabled"`, для каждого выбранного сегмента добавляются следующие входы (N меняется от 1 до выбранного количества раскадровок):

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Промпт для сегмента раскадровки N. Максимум 512 символов. (по умолчанию: "") | STRING | Да | - |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах (по умолчанию: 4). | INT | Да | 1 до 15 |

**Важные ограничения:**

* Вход `end_frame` нельзя использовать одновременно со входом `reference_images`.
* Вход `end_frame` нельзя использовать одновременно с раскадровкой.
* Модель `kling-video-o1` не поддерживает длительность более 10 секунд, генерацию аудио, разрешение 4k и раскадровку.
* Если для модели `kling-video-o1` не указаны `end_frame` или `reference_images`, параметр `duration` может быть задан только как 5 или 10 секунд.
* Все входные изображения (`first_frame`, `end_frame` и любые `reference_images`) должны иметь минимальный размер 300 пикселей по ширине и высоте.
* Соотношение сторон всех входных изображений должно быть от 1:2.5 до 2.5:1.
* Через вход `reference_images` можно передать не более 6 изображений.
* Текст `prompt` должен содержать от 1 до 2500 символов (при включенной раскадровке допускается 0 символов).
* В промпте можно ссылаться на входные изображения с помощью плейсхолдеров `@image`, `@image1`, `@image2` и т. д.; они автоматически преобразуются в совместимый с API формат ссылок на изображения.
* При включенной раскадровке суммарная длительность всех сегментов раскадровки должна равняться общему значению `duration`.
* Каждый промпт раскадровки должен содержать от 1 до 512 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
