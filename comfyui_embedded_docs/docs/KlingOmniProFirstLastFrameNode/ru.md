# Kling Omni Первый-Последний Кадр в Видео (Pro)

Этот узел использует последнюю модель Kling AI для генерации видео из начального кадра, необязательного конечного кадра или референсных изображений. Он может создавать одно видео или многосценную раскадровку с отдельными промптами и длительностями для каждого сегмента. Узел обрабатывает эти входные данные для получения видео заданной длины и разрешения с опциональной генерацией аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling AI, используемая для генерации видео. | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовый промпт, описывающий содержимое видео. Он может включать как положительные, так и отрицательные описания. Игнорируется, когда включены раскадровки. | STRING | Да | - |
| `duration` | Желаемая длительность генерируемого видео в секундах (по умолчанию: 5). | INT | Да | от 3 до 15 |
| `first_frame` | Начальное изображение для видеопоследовательности. | IMAGE | Да | - |
| `end_frame` | Необязательный конечный кадр для видео. Его нельзя использовать одновременно с `reference_images`. Не работает с раскадровками. | IMAGE | Нет | - |
| `reference_images` | До 6 дополнительных референсных изображений. | IMAGE | Нет | - |
| `resolution` | Выходное разрешение генерируемого видео (по умолчанию: "1080p"). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `storyboards` | Создание серии видеосегментов с отдельными промптами и длительностями. Поддерживается только для `kling-v3-omni`. При включении каждая раскадровка требует ввода промпта и длительности. | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `generate_audio` | Генерировать аудио для видео (по умолчанию: False). Поддерживается только для `kling-v3-omni`. | BOOLEAN | Нет | True / False |
| `seed` | Параметр seed определяет, должен ли узел запускаться заново; результаты недетерминированы независимо от значения seed (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |

### Входы раскадровки

Когда параметр `storyboards` имеет значение, отличное от `"disabled"`, для каждого выбранного сегмента добавляются следующие входные параметры (N изменяется от 1 до выбранного количества раскадровок):

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | Промпт для сегмента раскадровки N. Максимум 512 символов. (по умолчанию: "") | STRING | Да | - |
| `storyboard_N_duration` | Длительность сегмента раскадровки N в секундах (по умолчанию: 4). | INT | Да | от 1 до 15 |

**Важные ограничения:**

* Вход `end_frame` нельзя использовать одновременно с входом `reference_images`.
* Вход `end_frame` нельзя использовать одновременно с раскадровками.
* Модель `kling-video-o1` не поддерживает длительность более 10 секунд, генерацию аудио, разрешение 4k или раскадровки.
* Если не указать `end_frame` или `reference_images` с моделью `kling-video-o1`, параметр `duration` можно задать только равным 5 или 10 секундам.
* Все входные изображения (`first_frame`, `end_frame` и любые `reference_images`) должны иметь минимальный размер 300 пикселей по ширине и высоте.
* Соотношение сторон всех входных изображений должно быть от 1:2.5 до 2.5:1.
* Через вход `reference_images` можно передать не более 6 изображений.
* Текст `prompt` должен содержать от 1 до 2500 символов (0 символов допускается, когда включены раскадровки).
* Промпт может ссылаться на входные изображения с помощью плейсхолдеров `@image`, `@image1`, `@image2` и т. д.; они автоматически преобразуются в совместимый с API формат ссылки на изображение.
* Когда раскадровки включены, суммарная длительность всех сегментов раскадровки должна равняться глобальному значению `duration`.
* Каждый промпт раскадровки должен содержать от 1 до 512 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
