# Kling Omni ファースト・ラストフレームからビデオへ (Pro)

このノードは最新のKling AIモデルを使用して、開始フレーム、オプションの終了フレーム、または参照画像からビデオを生成します。単一のビデオ、または各セグメントに個別のプロンプトと長さを持つマルチショットストーリーボードを作成できます。このノードはこれらの入力を処理して、指定された長さと解像度のビデオを生成し、オプションでオーディオを生成することもできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | ビデオ生成に使用する特定のKling AIモデル。 | COMBO | はい | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `プロンプト` | ビデオの内容を説明するテキストプロンプト。ポジティブな説明とネガティブな説明の両方を含めることができます。ストーリーボードが有効な場合は無視されます。 | STRING | はい | - |
| `継続時間` | 生成されるビデオの希望の長さ（秒）。(デフォルト: 5) | INT | はい | 3 〜 15 |

### ストーリーボード入力

`storyboards` が `"disabled"` 以外の値に設定されている場合、選択された各セグメントに対して以下の入力が追加されます（Nは1から選択したストーリーボード数までの範囲です）：

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメントNのプロンプト。最大512文字。(デフォルト: "") | STRING | はい | - |
| `storyboard_N_duration` | ストーリーボードセグメントNの長さ（秒）。(デフォルト: 4) | INT | はい | 1 〜 15 |

**重要な制約事項：**

* `end_frame` 入力は `reference_images` 入力と同時に使用できません。
* `end_frame` 入力はストーリーボードと同時に使用できません。
* `kling-video-o1` モデルは、10秒を超える長さ、オーディオ生成、4k解像度、ストーリーボードをサポートしていません。
* `kling-video-o1` モデルで `end_frame` または `reference_images` を提供しない場合、`duration` は5秒または10秒のみに設定できます。
* すべての入力画像（`first_frame`、`end_frame`、およびすべての `reference_images`）は、幅と高さの両方が最低300ピクセルである必要があります。
* すべての入力画像のアスペクト比は、1:2.5から2.5:1の間である必要があります。
* `reference_images` 入力では、最大6枚の画像を提供できます。
* `prompt` テキストは1文字以上2500文字以下である必要があります（ストーリーボードが有効な場合は0文字が許可されます）。
* プロンプトは、プレースホルダー `@image`、`@image1`、`@image2` などを使用して入力画像を参照できます。これらは自動的にAPI互換の画像参照形式に変換されます。
* ストーリーボードが有効な場合、すべてのストーリーボードセグメントの合計時間は、グローバルな `duration` 値と等しくなければなりません。
* 各ストーリーボードプロンプトは1文字以上512文字以下である必要があります。
