# Kling Omni تبدیل اولین-آخرین فریم به ویدیو (Pro)

این گره از جدیدترین مدل Kling AI برای تولید ویدیو از یک فریم شروع، فریم پایان اختیاری یا تصاویر مرجع استفاده می‌کند. می‌تواند یک ویدیوی واحد یا یک استوری‌بورد چندصحنه‌ای با پرامپت و مدت‌زمان جداگانه برای هر بخش تولید کند. گره این ورودی‌ها را پردازش کرده و ویدیویی با طول و وضوح مشخص، همراه با تولید صوتی اختیاری، خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل خاص Kling AI که برای تولید ویدیو استفاده می‌شود. | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک پرامپت متنی که محتوای ویدیو را توصیف می‌کند. این می‌تواند شامل توضیحات مثبت و منفی باشد. وقتی استوری‌بورد فعال باشد، نادیده گرفته می‌شود. | STRING | بله | - |
| `duration` | مدت‌زمان دلخواه ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 |
| `first_frame` | تصویر شروع برای دنباله ویدیو. | IMAGE | بله | - |
| `end_frame` | فریم پایان اختیاری برای ویدیو. این نمی‌تواند همزمان با `reference_images` استفاده شود. با استوری‌بورد کار نمی‌کند. | IMAGE | خیر | - |
| `reference_images` | حداکثر ۶ تصویر مرجع اضافی. | IMAGE | خیر | - |
| `resolution` | وضوح خروجی ویدیوی تولیدشده (پیش‌فرض: "1080p"). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید یک سری بخش‌های ویدیویی با پرامپت و مدت‌زمان جداگانه. فقط برای `kling-v3-omni` پشتیبانی می‌شود. وقتی فعال باشد، هر استوری‌بورد نیاز به ورودی پرامپت و مدت‌زمان دارد. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | تولید صدا برای ویدیو (پیش‌فرض: False). فقط برای `kling-v3-omni` پشتیبانی می‌شود. | BOOLEAN | خیر | True / False |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های استوری‌بورد

وقتی `storyboards` روی مقداری غیر از `"disabled"` تنظیم شده باشد، ورودی‌های زیر برای هر بخش انتخاب‌شده اضافه می‌شوند (N از 1 تا تعداد انتخاب‌شده استوری‌بورد متغیر است):

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | پرامپت برای بخش استوری‌بورد N. حداکثر ۵۱۲ کاراکتر. (پیش‌فرض: "") | STRING | بله | - |
| `storyboard_N_duration` | مدت‌زمان بخش استوری‌بورد N بر حسب ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 |

**محدودیت‌های مهم:**

* ورودی `end_frame` نمی‌تواند همزمان با ورودی `reference_images` استفاده شود.
* ورودی `end_frame` نمی‌تواند همزمان با استوری‌بورد استفاده شود.
* مدل `kling-video-o1` از مدت‌زمان‌های بیشتر از ۱۰ ثانیه، تولید صدا، وضوح 4k یا استوری‌بورد پشتیبانی نمی‌کند.
* اگر با مدل `kling-video-o1` یک `end_frame` یا هیچ `reference_images` ارائه ندهید، `duration` فقط می‌تواند 5 یا 10 ثانیه باشد.
* همه تصاویر ورودی (`first_frame`، `end_frame` و هر `reference_images`) باید حداقل ابعاد ۳۰۰ پیکسل در عرض و ارتفاع داشته باشند.
* نسبت تصویر همه تصاویر ورودی باید بین 1:2.5 و 2.5:1 باشد.
* حداکثر ۶ تصویر را می‌توان از طریق ورودی `reference_images` ارائه کرد.
* متن `prompt` باید بین ۱ تا ۲۵۰۰ کاراکتر باشد (زمانی که استوری‌بورد فعال است، ۰ کاراکتر مجاز است).
* پرامپت می‌تواند با استفاده از placeholders مانند `@image`، `@image1`، `@image2` و غیره به تصاویر ورودی ارجاع دهد؛ این‌ها به‌طور خودکار به فرمت مرجع تصویر سازگار با API تبدیل می‌شوند.
* وقتی استوری‌بورد فعال باشد، مجموع مدت‌زمان همه بخش‌های استوری‌بورد باید برابر با مقدار سراسری `duration` باشد.
* هر پرامپت استوری‌بورد باید بین ۱ تا ۵۱۲ کاراکتر طول داشته باشد.
