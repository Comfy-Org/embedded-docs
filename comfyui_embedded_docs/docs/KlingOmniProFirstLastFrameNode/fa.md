# Kling Omni تبدیل اولین-آخرین فریم به ویدیو (Pro)

این گره از جدیدترین مدل Kling AI برای تولید ویدیو از یک فریم شروع، یک فریم پایان اختیاری یا تصاویر مرجع استفاده می‌کند. این گره می‌تواند یک ویدیوی تکی یا یک استوری‌بورد چندصحنه‌ای با پرامپت‌ها و مدت‌زمان‌های جداگانه برای هر بخش تولید کند. این گره ورودی‌ها را پردازش می‌کند تا ویدیویی با طول و وضوح مشخص، همراه با تولید صوتی اختیاری، تولید کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|-----------|-----------|----------|-------|
| `model_name` | مدل خاص Kling AI که برای تولید ویدیو استفاده می‌شود. | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک پرامپت متنی که محتوای ویدیو را توصیف می‌کند. این می‌تواند شامل توصیف‌های مثبت و منفی باشد. زمانی که استوری‌بورد فعال باشد نادیده گرفته می‌شود. | STRING | بله | - |
| `duration` | طول مورد نظر ویدیوی تولیدشده به ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 |
| `first_frame` | تصویر شروع برای دنباله ویدیو. | IMAGE | بله | - |
| `end_frame` | یک فریم پایان اختیاری برای ویدیو. این نمی‌تواند همزمان با `reference_images` استفاده شود. با استوری‌بورد کار نمی‌کند. | IMAGE | خیر | - |
| `reference_images` | حداکثر 6 تصویر مرجع اضافی. | IMAGE | خیر | - |
| `resolution` | وضوح خروجی برای ویدیوی تولیدشده (پیش‌فرض: "1080p"). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید یک سری بخش‌های ویدیویی با پرامپت‌ها و مدت‌زمان‌های جداگانه. فقط برای `kling-v3-omni` پشتیبانی می‌شود. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | تولید صدا برای ویدیو (پیش‌فرض: False). فقط برای `kling-v3-omni` پشتیبانی می‌شود. | BOOLEAN | خیر | True / False |
| `seed` | seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های استوری‌بورد

وقتی `storyboards` روی مقداری غیر از `"disabled"` تنظیم شود، ورودی‌های زیر برای هر بخش انتخابی اضافه می‌شوند (N از 1 تا تعداد انتخاب‌شده استوری‌بوردها متغیر است):

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|-----------|-----------|----------|-------|
| `storyboard_N_prompt` | پرامپت برای بخش استوری‌بورد N. حداکثر 512 کاراکتر. (پیش‌فرض: "") | STRING | بله | - |
| `storyboard_N_duration` | مدت‌زمان بخش استوری‌بورد N به ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 |

**محدودیت‌های مهم:**

* ورودی `end_frame` نمی‌تواند همزمان با ورودی `reference_images` استفاده شود.
* ورودی `end_frame` نمی‌تواند همزمان با استوری‌بوردها استفاده شود.
* مدل `kling-video-o1` از مدت‌زمان‌های بیشتر از 10 ثانیه، تولید صدا، وضوح 4k یا استوری‌بورد پشتیبانی نمی‌کند.
* اگر با مدل `kling-video-o1` مقدار `end_frame` یا `reference_images` ارائه ندهید، `duration` فقط می‌تواند روی 5 یا 10 ثانیه تنظیم شود.
* همه تصاویر ورودی (`first_frame`، `end_frame` و هر `reference_images`) باید حداقل ابعاد 300 پیکسل در هر دو عرض و ارتفاع داشته باشند.
* نسبت ابعاد همه تصاویر ورودی باید بین 1:2.5 و 2.5:1 باشد.
* حداکثر 6 تصویر می‌توانند از طریق ورودی `reference_images` ارائه شوند.
* متن `prompt` باید بین 1 تا 2500 کاراکتر طول داشته باشد (زمانی که استوری‌بوردها فعال هستند 0 کاراکتر مجاز است).
* پرامپت می‌تواند با استفاده از جایگزین‌هایی مانند `@image`، `@image1`، `@image2` و ... به تصاویر ورودی ارجاع دهد؛ این‌ها به‌طور خودکار به فرمت ارجاع تصویر سازگار با API تبدیل می‌شوند.
* وقتی استوری‌بوردها فعال هستند، مجموع مدت‌زمان همه بخش‌های استوری‌بورد باید با مقدار سراسری `duration` برابر باشد.
* هر پرامپت استوری‌بورد باید بین 1 تا 512 کاراکتر طول داشته باشد.
