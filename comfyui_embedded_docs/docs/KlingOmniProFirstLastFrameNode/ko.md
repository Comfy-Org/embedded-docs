# Kling Omni 첫-마지막 프레임에서 비디오로 (Pro)

이 노드는 최신 Kling AI 모델을 사용하여 시작 프레임, 선택적 종료 프레임 또는 참조 이미지로부터 비디오를 생성합니다. 각 세그먼트에 개별 프롬프트와 길이를 지정하여 단일 비디오 또는 멀티샷 스토리보드를 생성할 수 있습니다. 노드는 이러한 입력을 처리하여 지정된 길이와 해상도의 비디오를 생성하며, 선택적으로 오디오도 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 비디오 생성에 사용할 특정 Kling AI 모델입니다. | COMBO | 예 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `프롬프트` | 비디오 내용을 설명하는 텍스트 프롬프트입니다. 긍정적 설명과 부정적 설명을 모두 포함할 수 있습니다. 스토리보드가 활성화되면 무시됩니다. | STRING | 예 | - |
| `지속 시간` | 생성된 비디오의 원하는 길이(초)입니다(기본값: 5). | INT | 예 | 3 ~ 15 |
| `시작 프레임` | 비디오 시퀀스의 시작 이미지입니다. | IMAGE | 예 | - |
| `종료 프레임` | 비디오의 선택적 종료 프레임입니다. `reference_images`와 동시에 사용할 수 없습니다. 스토리보드에서는 작동하지 않습니다. | IMAGE | 아니요 | - |
| `참조 이미지` | 최대 6개의 추가 참조 이미지입니다. | IMAGE | 아니요 | - |
| `해상도` | 생성된 비디오의 출력 해상도입니다(기본값: "1080p"). | COMBO | 아니요 | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `스토리보드` | 개별 프롬프트와 길이를 가진 일련의 비디오 세그먼트를 생성합니다. `kling-v3-omni`에서만 지원됩니다. 활성화되면 각 스토리보드에는 프롬프트와 길이 입력이 필요합니다. | DYNAMIC_COMBO | 아니요 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `오디오 생성` | 비디오용 오디오를 생성합니다(기본값: False). `kling-v3-omni`에서만 지원됩니다. | BOOLEAN | 아니요 | True / False |
| `시드` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |

### 스토리보드 입력

`storyboards`가 `"disabled"` 이외의 값으로 설정되면 선택된 각 세그먼트에 대해 다음 입력이 추가됩니다(N은 1부터 선택한 스토리보드 수까지의 범위입니다):

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 스토리보드 세그먼트 N에 대한 프롬프트입니다. 최대 512자입니다. (기본값: "") | STRING | 예 | - |
| `storyboard_N_duration` | 스토리보드 세그먼트 N의 길이(초)입니다(기본값: 4). | INT | 예 | 1 ~ 15 |

**중요 제약 사항:**

* `end_frame` 입력은 `reference_images` 입력과 동시에 사용할 수 없습니다.
* `end_frame` 입력은 스토리보드와 동시에 사용할 수 없습니다.
* `kling-video-o1` 모델은 10초를 초과하는 길이, 오디오 생성, 4k 해상도 및 스토리보드를 지원하지 않습니다.
* `kling-video-o1` 모델에서 `end_frame` 또는 `reference_images`를 제공하지 않으면 `duration`은 5초 또는 10초로만 설정할 수 있습니다.
* 모든 입력 이미지(`first_frame`, `end_frame` 및 모든 `reference_images`)는 가로와 세로 모두 최소 300픽셀 이상이어야 합니다.
* 모든 입력 이미지의 종횡비는 1:2.5에서 2.5:1 사이여야 합니다.
* `reference_images` 입력을 통해 최대 6개의 이미지를 제공할 수 있습니다.
* `prompt` 텍스트는 1자에서 2500자 사이여야 합니다(스토리보드가 활성화된 경우 0자 허용).
* 프롬프트는 `@image`, `@image1`, `@image2` 등의 자리 표시자를 사용하여 입력 이미지를 참조할 수 있습니다. 이러한 자리 표시자는 API 호환 이미지 참조 형식으로 자동 변환됩니다.
* 스토리보드가 활성화되면 모든 스토리보드 세그먼트의 총 길이가 전체 `duration` 값과 같아야 합니다.
* 각 스토리보드 프롬프트는 1자에서 512자 사이여야 합니다.
