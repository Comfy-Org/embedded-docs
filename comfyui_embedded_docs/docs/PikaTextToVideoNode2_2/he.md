# PikaTextToVideoNode2_2

צומת Pika Text2Video v2.2 שולח הנחיית טקסט אל Pika API בגרסה 2.2 כדי ליצור וידאו. הוא ממיר את תיאור הטקסט שלך לווידאו באמצעות שירות יצירת הווידאו מבוסס הבינה המלאכותית של Pika. הצומת מאפשר לך להתאים אישית היבטים שונים של תהליך יצירת הווידאו, כולל יחס רוחב-גובה, משך ורזולוציה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `prompt_text` | התיאור הטקסטואלי הראשי שמתאר מה ברצונך ליצור בווידאו | STRING | כן | - |
| `negative_prompt` | טקסט המתאר מה אינך רוצה שיופיע בווידאו שנוצר | STRING | כן | - |
| `seed` | מספר השולט באקראיות היצירה לצורך תוצאות ניתנות לשחזור | INT | כן | - |
| `resolution` | הגדרת הרזולוציה עבור וידאו הפלט | STRING | כן | - |
| `duration` | משך הווידאו בשניות | INT | כן | - |
| `aspect_ratio` | יחס רוחב-גובה (רוחב / גובה) (ברירת מחדל: 1.7777777777777777) | FLOAT | לא | 0.4 - 2.5 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | קובץ הווידאו שנוצר שהוחזר מ-API של Pika | VIDEO |
