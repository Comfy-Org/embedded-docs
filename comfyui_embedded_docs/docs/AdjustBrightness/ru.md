# Регулировка яркости

Узел Adjust Brightness изменяет яркость входного изображения. Он работает путём умножения значения каждого пикселя на заданный коэффициент, а затем ограничивает полученные значения, чтобы они оставались в допустимом диапазоне. Коэффициент 1.0 оставляет изображение без изменений, значения ниже 1.0 делают его темнее, а значения выше 1.0 — ярче.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение для настройки. | IMAGE | Да | - |
| `коэффициент` | Коэффициент яркости. 1.0 = без изменений, <1.0 = темнее, >1.0 = ярче. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 2.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Выходное изображение с отрегулированной яркостью. | IMAGE |
