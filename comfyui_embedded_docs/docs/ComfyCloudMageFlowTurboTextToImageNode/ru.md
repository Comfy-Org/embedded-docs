# ComfyCloudMageFlowTurboTextToImageNode

Этот узел Comfy Cloud генерирует изображение по текстовому запросу с помощью рабочего процесса Mage-Flow Turbo (`mage-flow-turbo/text-to-image`). Он запускает дистиллированную версию модели Mage-Flow, которая создаёт изображение за 4 шага при значении cfg, равном 1, затрачивая примерно одну седьмую времени GPU по сравнению с полным проходом Mage-Flow. Это делает его вариантом, предназначенным для быстрой итерации.

## Входы

Сам класс узла не объявляет виджеты входов в доступном исходном коде; его схема входов наследуется от общего базового класса `_ComfyCloudMageFlowNode`, определение которого не включено в снимок исходного кода. Судя по описанию узла и названию рабочего процесса text-to-image, узел принимает текстовый запрос, описывающий изображение для генерации.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации. Точное имя параметра задаётся унаследованной схемой базового класса `_ComfyCloudMageFlowNode` и может отличаться от данной подписи. | STRING | Да | Произвольный текст |

Примечание: В определении унаследованного базового узла, недоступного в предоставленном исходном коде, могут существовать дополнительные входные параметры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, сгенерированное по текстовому запросу. | IMAGE |
