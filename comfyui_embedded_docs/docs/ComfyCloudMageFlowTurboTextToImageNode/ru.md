# Comfy Cloud Mage Flow Turbo Текст в изображение [БЕТА]

Этот узел Comfy Cloud генерирует изображение из текстового промпта с помощью рабочего процесса Mage-Flow Turbo (`mage-flow-turbo/text-to-image`). Он запускает дистиллированную версию модели Mage-Flow, которая создаёт изображение за 4 шага при значении cfg 1, затрачивая примерно одну седьмую времени GPU по сравнению с полным проходом Mage-Flow, что делает этот вариант предназначенным для быстрой итерации.

## Входы

Сам класс узла не объявляет виджеты входов в доступном исходном коде; его схема входов наследуется от общего базового класса `_ComfyCloudMageFlowNode`, определение которого не включено в снимок исходного кода. Судя по сводке узла и имени рабочего процесса text-to-image, узел принимает текстовый промпт, описывающий изображение для генерации.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт, описывающий изображение для генерации. Точное имя параметра задаётся унаследованной базовой схемой `_ComfyCloudMageFlowNode` и может отличаться от этой метки. | STRING | Да | Произвольный текст |

Примечание: В унаследованном определении базового узла могут существовать дополнительные входные параметры; оно недоступно в предоставленном исходном коде.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Изображение, сгенерированное из текстового промпта. | IMAGE |
