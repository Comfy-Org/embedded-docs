# VAEデコードオーディオ（タイル）

このノードは、圧縮されたオーディオ表現（潜在サンプル）を、Variational Autoencoder（VAE）を使用してオーディオ波形に変換します。メモリ使用量を管理するため、データをより小さな重なり合うセクション（タイル）に分割して処理することで、長いオーディオシーケンスの処理に適しています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `samples` | デコード対象のオーディオの圧縮された潜在表現。 | LATENT | はい | N/A |
| `vae` | デコードを実行するために使用されるVariational Autoencoderモデル。 | VAE | はい | N/A |
| `tile_size` | 各処理タイルのサイズ。オーディオはメモリを節約するために、この長さのセクションに分けてデコードされます（デフォルト: 512）。 | INT | はい | 32 ～ 8192 |
| `overlap` | 隣接するタイルが重なるサンプル数。タイル境界でのアーティファクトを軽減するのに役立ちます（デフォルト: 64）。 | INT | はい | 0 ～ 1024 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | デコードされたオーディオ波形。 | AUDIO |
