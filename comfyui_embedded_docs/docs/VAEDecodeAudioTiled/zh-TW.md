# VAE 解碼音訊（分塊）

此節點使用變分自編碼器（VAE）將壓縮的音頻表示（潛在樣本）轉換回音頻波形。它會以較小的重疊區段（tiles）處理資料，以管理記憶體使用量，適合處理較長音訊序列。解碼後的音訊也會進行正規化，以保持音量一致。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `樣本` | 要解碼的音訊之壓縮潛在表示。 | LATENT | 是 | N/A |
| `vae` | 用於執行解碼的變分自編碼器模型。 | VAE | 是 | N/A |
| `分塊大小` | 每個處理區段的大小。音訊會以此長度分段解碼，以節省記憶體（預設值：512）。 | INT | 是 | 32 至 8192 |
| `重疊` | 相鄰區段重疊的樣本數。這有助於減少區段邊界處的偽影（預設值：64）。 | INT | 是 | 0 至 1024 |
