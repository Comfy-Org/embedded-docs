# VAE декодирование аудио (плитками)

Этот узел преобразует сжатое аудиопредставление (латентные сэмплы) обратно в аудиоволновую форму с помощью вариационного автокодировщика (VAE). Он обрабатывает данные небольшими перекрывающимися секциями (тайлами) для экономии памяти, что делает его подходящим для обработки более длинных аудиопоследовательностей.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Сжатое латентное представление аудио для декодирования. | LATENT | Да | Н/Д |
| `vae` | Модель вариационного автокодировщика, используемая для выполнения декодирования. | VAE | Да | Н/Д |
| `tile_size` | Размер каждого обрабатываемого тайла. Аудио декодируется по частям такой длины для экономии памяти (по умолчанию: 512). | INT | Да | от 32 до 8192 |
| `overlap` | Количество сэмплов, на которые перекрываются соседние тайлы. Это помогает уменьшить артефакты на границах между тайлами (по умолчанию: 64). | INT | Да | от 0 до 1024 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Декодированная форма аудиосигнала. | AUDIO |
