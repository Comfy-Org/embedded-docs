# VAE декодирование аудио (плитками)

Этот узел преобразует сжатое аудиопредставление (латентные сэмплы) обратно в аудиосигнал с помощью вариационного автокодировщика (VAE). Данные обрабатываются небольшими перекрывающимися секциями (тайлами) для экономии памяти, что делает узел подходящим для обработки длинных аудиопоследовательностей. Декодированный звук также нормализуется для поддержания постоянного уровня громкости.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `образцы` | Сжатое латентное представление аудио для декодирования. | LATENT | Да | N/A |
| `vae` | Модель вариационного автокодировщика, используемая для декодирования. | VAE | Да | N/A |
| `размер плитки` | Размер каждого обрабатываемого тайла. Аудио декодируется секциями такой длины для экономии памяти (по умолчанию: 512). | INT | Да | 32 до 8192 |
| `перекрытие` | Количество сэмплов, на которое перекрываются соседние тайлы. Это помогает уменьшить артефакты на границах между тайлами (по умолчанию: 64). | INT | Да | 0 до 1024 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Декодированный аудиосигнал, включая информацию о частоте дискретизации. | AUDIO |

Частота дискретизации выходного сигнала берётся из входных `samples`, если они её содержат; в противном случае она считывается из модели VAE (по умолчанию 44100 Гц).
