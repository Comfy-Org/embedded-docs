# TypeSafe Jev (Choice)

TypeSafe Jev (Choice) ノードは、接続されたテキスト、画像、またはその両方に対して、独自のオプションから 1 つを選択します。`choice` を、入力にオプション名が含まれる Branch ノードに接続するか、`option_index` を使用して選択されたオプションの位置で切り替えます。これは API ノードであり、Comfy.org アカウントと API キーが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデル。現在利用できるモデルは 1 つだけです：`jev-1.14.0`。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | オプションが答える質問。複数の画像ソケットがある場合は、その名前を使用します。たとえば `Which season is shown in image_1?`（デフォルト：`What style is the image?`）。 | STRING | はい | 1～1000 文字 |
| `options` | 選択肢。1 行に 1 つずつ指定します。どのオプションにも当てはまらない入力用に、`other` などのオプションを追加します（デフォルト：`photo`、`illustration`、`3d render`、`anime`、`sketch`、`other` を 1 行に 1 つずつ）。 | STRING | はい | 2～50 個のオプション、各最大 40 文字 |
| `images` | 質問の対象となる画像。合計最大 32 枚。バッチ入力は画像 1 枚につき 1 回として数えられ、4 枚を超える画像はより小さいサイズで送信されます。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキスト。プロンプトや LLM の応答などです。 | STRING | いいえ | 0～3000 文字 |

**注意：**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合、ノードはエラーを発生させます。
- オプションが 2 個未満または 50 個を超える場合、オプションが 40 文字を超える場合、または 2 つのオプションが大文字小文字だけしか異ならない場合、ノードはエラーを発生させます。
- `option_index` は 0 から数えるため、リスト内の最初のオプションのインデックスは 0 です。
- 課金はトークンベースです。ノード上の料金バッジには、100 万トークンあたりの概算レートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `choice` | 選択されたオプション。`options` に表示されるとおりに正確に書き出されます。 | STRING |
| `option_index` | オプションリスト内での選択されたオプションの位置。0 から始まります。 | INT |
| `confidence` | Jev がどれだけ確信しているか。0（明確な勝者なし）から 1（確実）までです。 | FLOAT |
