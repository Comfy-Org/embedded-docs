# TypeSafe Jev (Choice)

TypeSafe Jev (Choice) ノードは、接続されたテキスト、画像、またはその両方に対して、独自の選択肢から 1 つを選びます。`choice` を、入力に選択肢名が設定された Branch ノードに接続するか、`option_index` を使用して選択された選択肢の位置に基づいて切り替えます。Branch ノードは最大 32 個の入力しか受け付けないため、それより多い選択肢を含むリストは `option_index` でのみルーティングできます。これは API ノードです。Comfy のサーバー上で実行され、クレジット付きの Comfy.org アカウントが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデル。現在利用可能なモデルは 1 つだけです: `jev-1.14.0`。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 選択肢が答える質問です。画像ソケットが複数ある場合は、それらの名前を使用します。例: `Which season is shown in image_1?`（デフォルト: `What style is the image?`）。 | STRING | はい | 1～1000 文字 |
| `options` | 選択対象のオプションです。1 行に 1 つ指定します。各行の先頭と末尾の空白は削除され、オプションは大文字と小文字を区別せずに一意である必要があるため、重複するオプションや大文字と小文字だけが異なる 2 つのオプションは拒否されます。どのオプションにも当てはまらない入力には、`other` などのオプションを追加してください（デフォルト: `photo`、`illustration`、`3d render`、`anime`、`sketch`、`other` を 1 行に 1 つずつ）。 | STRING | はい | 2～50 個のオプション、各最大 40 文字 |
| `images` | 質問の対象となる画像です。合計で最大 32 枚の画像です。バッチ入力は画像 1 枚につき 1 回としてカウントされます。各画像の長辺は画像の総数によって上限が決まります。最大 4 枚までは 1568 px、最大 8 枚までは 1024 px、最大 16 枚までは 768 px、最大 32 枚までは 512 px です。そのため、バッチが大きいほど各画像の詳細が減少する可能性があります。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキストです。プロンプトや LLM の応答などが該当します。 | STRING | いいえ | 0～3000 文字 |

**注記:**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合、ノードはエラーを発生させます。
- オプションが 2 個未満または 50 個を超える場合、オプションが 40 文字を超える場合、または大文字と小文字を区別せずに 2 つのオプションが同一である場合、ノードはエラーを発生させます。
- `option_index` は 0 から数えるため、リスト内の最初のオプションのインデックスは 0 です。
- 課金はトークン単位です。ノード上の料金バッジには、100 万トークンあたりの概算レートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `choice` | 選択されたオプションです。先頭と末尾の空白は削除されます。名前がその空白を保持している Branch 入力は一致しません。 | STRING |
| `option_index` | 選択されたオプションの、オプションリスト内での位置です。0 から始まります。 | INT |
| `confidence` | Jev がどの程度確信しているかを表します。0（明確な勝者なし）から 1（確実）までの値です。 | FLOAT |
