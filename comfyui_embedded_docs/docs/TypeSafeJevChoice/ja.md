# TypeSafe Jev (Choice)

TypeSafe Jev (Choice) ノードは、接続されたテキスト、画像、またはその両方に対して、独自のオプションから 1 つを選択します。`choice` を、入力にオプション名を持つ Branch ノードに接続するか、`option_index` を使用して選択されたオプションの位置で切り替えます。Branch ノードは最大 32 個の入力を受け取るため、それより多いオプションを含むリストは `option_index` でのみルーティングできます。これは API ノードです。Comfy のサーバー上で実行され、クレジット付きの Comfy.org アカウントが必要です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する Jev モデル。現在利用可能なモデルは `jev-1.14.0` の 1 つだけです。 | COMBO | はい | `"jev-1.14.0"` |
| `question` | 各オプションが答える質問。画像ソケットが複数ある場合は、それらの名前を使用します。例：`Which season is shown in image_1?`（デフォルト：`What style is the image?`）。 | STRING | はい | 1～1000 文字 |
| `options` | 選択肢。1 行に 1 つ指定します。各行の先頭と末尾の空白はトリムされ、オプションは大文字小文字を区別せず一意である必要があるため、同じオプションの繰り返しや、大文字小文字だけが異なる 2 つのオプションは拒否されます。どのオプションにも当てはまらない入力用に、`other` などのオプションを追加します（デフォルト：`photo`、`illustration`、`3d render`、`anime`、`sketch`、`other`、1 行に 1 つ）。 | STRING | はい | 2～50 個のオプション、各最大 40 文字 |
| `images` | 質問の対象となる画像。合計で最大 32 枚です。バッチ化された入力は画像ごとに 1 回として数えます。各画像の長辺は画像の総数に応じて上限が設定されます。最大 4 枚までは 1568 px、最大 8 枚までは 1024 px、最大 16 枚までは 768 px、最大 32 枚までは 512 px です。そのため、バッチが大きいほど各画像の詳細は少なくなります。 | AUTOGROW | いいえ | 0～32 枚の画像 |
| `text` | 質問の対象となるテキスト。プロンプトや LLM の応答などです。 | STRING | いいえ | 0～3000 文字 |

**注記：**

- テキストまたは少なくとも 1 枚の画像を接続してください。両方が空の場合、ノードはエラーを発生させます。
- オプションが 2 個未満または 50 個を超える場合、オプションが 40 文字を超える場合、または大文字小文字を区別せずに 2 つのオプションが同一である場合、ノードはエラーを発生させます。
- `option_index` は 0 から数えるため、一覧の最初のオプションのインデックスは 0 です。
- 課金はトークン単位です。ノード上の料金バッジには、100 万トークンあたりの概算レートが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `choice` | 選択されたオプション。先頭と末尾の空白はトリムされます。その空白を名前に保持している Branch 入力とは一致しません。 | STRING |
| `option_index` | 選択されたオプションのオプション一覧内の位置。0 から始まります。 | INT |
| `confidence` | Jev がどの程度確信しているかを 0（明確な勝者なし）から 1（確実）で示します。 | FLOAT |
