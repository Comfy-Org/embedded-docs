# TypeSafe Jev (Choice)

عقدة TypeSafe Jev (Choice) تختار إحدى خياراتك الخاصة للنص أو الصور المتصلة، أو كليهما. اربط `choice` بعقدة Branch تحمل مدخلاتها أسماء الخيارات، أو استخدم `option_index` للتبديل بناءً على موضع الخيار المختار. هذه عقدة API وتتطلب حساب Comfy.org ومفتاح API.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج Jev المراد استخدامه. يتوفر حاليًا نموذج واحد فقط: `jev-1.14.0`. | COMBO | نعم | `"jev-1.14.0"` |
| `question` | السؤال الذي تجيب عنه الخيارات. عند وجود عدة منافذ صور، استخدم أسماءها، على سبيل المثال `Which season is shown in image_1?` (الافتراضي: `What style is the image?`). | STRING | نعم | 1 إلى 1000 حرف |
| `options` | الخيارات التي يمكن الاختيار منها، خيار واحد في كل سطر. أضف خيارًا مثل `other` للمدخلات التي لا تناسب أيًا منها (الافتراضي: `photo`، `illustration`، `3d render`، `anime`، `sketch` و`other`، خيار واحد في كل سطر). | STRING | نعم | 2 إلى 50 خيارًا، بحد أقصى 40 حرفًا لكل خيار |
| `images` | الصور التي يتعلق بها السؤال. حتى 32 صورة إجمالًا؛ يُحتسب الإدخال المُجمَّع مرة واحدة لكل صورة، وتُرسَل أكثر من 4 صور بحجم أصغر. | AUTOGROW | لا | 0 إلى 32 صورة |
| `text` | النص الذي يتعلق به السؤال، مثل نص توجيهي أو استجابة LLM. | STRING | لا | 0 إلى 3000 حرف |

**ملاحظات:**

- اربط النص أو صورة واحدة على الأقل؛ تُطلق العقدة خطأً عندما يكون كلاهما فارغًا.
- تُطلق العقدة خطأً عند تقديم أقل من خيارين أو أكثر من 50 خيارًا، أو عندما يزيد طول أحد الخيارات على 40 حرفًا، أو عندما يختلف خياران فقط في حالة الأحرف.
- يبدأ عدّ `option_index` من 0، لذا يكون للخيار الأول في القائمة الفهرس 0.
- تعتمد الفوترة على الرموز (tokens)؛ وتعرض شارة السعر على العقدة المعدل التقريبي لكل مليون رمز.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `choice` | الخيار المختار، مكتوبًا تمامًا كما يظهر في `options`. | STRING |
| `option_index` | موضع الخيار المختار في قائمة الخيارات، بدءًا من 0. | INT |
| `confidence` | مدى تأكد Jev، من 0 (لا يوجد فائز واضح) إلى 1 (مؤكد). | FLOAT |
