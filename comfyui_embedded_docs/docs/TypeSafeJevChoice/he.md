# TypeSafe Jev (Choice)

צומת TypeSafe Jev (Choice) בוחר אחת מהאפשרויות שלך עבור טקסט, תמונות או שניהם, כשהם מחוברים. חברו את `choice` לצומת Branch שהקלטים שלו נושאים את שמות האפשרויות, או השתמשו ב-`option_index` כדי לבחור לפי המיקום של האפשרות שנבחרה. צומת Branch מקבל לכל היותר 32 קלטים, ולכן רשימה עם יותר אפשרויות מכך יכולה להיות מנותבת רק באמצעות `option_index`. זהו צומת API: הוא פועל בשרתים של Comfy ודורש חשבון Comfy.org עם קרדיטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev שיש להשתמש בו. נכון לעכשיו זמין מודל אחד בלבד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | השאלה שהאפשרויות עונות עליה. כאשר יש כמה חיבורי תמונות, השתמשו בשמותיהם, לדוגמה `Which season is shown in image_1?` (ברירת מחדל: `What style is the image?`). | STRING | כן | 1 עד 1000 תווים |
| `options` | האפשרויות לבחירה, אחת בכל שורה. רווחים מובילים וסוגרים נחתכים מכל שורה, והאפשרויות חייבות להיות ייחודיות ללא תלות ברישיות, כך שאפשרות חוזרת או שתי אפשרויות שנבדלות רק ברישיות נדחות. הוסיפו אפשרות כגון `other` עבור קלטים שאינם מתאימים לאף אחת מהן (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch` ו-`other`, אחת בכל שורה). | STRING | כן | 2 עד 50 אפשרויות, עד 40 תווים כל אחת |
| `images` | התמונות שהשאלה עוסקת בהן. עד 32 תמונות בסך הכול; קלט באצווה נספר פעם אחת עבור כל תמונה. הצד הארוך של כל תמונה מוגבל לפי המספר הכולל של התמונות: 1568 px עבור עד 4 תמונות, 1024 px עבור עד 8, 768 px עבור עד 16 ו-512 px עבור עד 32, כך שאצווה גדולה יותר יכולה להפחית את הפרטים בכל תמונה. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובה של LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חברו טקסט או לפחות תמונה אחת; הצומת מעלה שגיאה כאשר שניהם ריקים.
- הצומת מעלה שגיאה כאשר ניתנות פחות מ-2 או יותר מ-50 אפשרויות, כאשר אפשרות ארוכה מ-40 תווים, או כאשר שתי אפשרויות זהות ללא תלות ברישיות.
- `option_index` נספר מ-0, כך שלאפשרות הראשונה ברשימה יש אינדקס 0.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל מיליון טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `choice` | האפשרות שנבחרה, כאשר רווחים מובילים וסוגרים נחתכים. קלט של Branch ששמו שומר על הרווחים הללו לא יתאים. | STRING |
| `option_index` | מיקום האפשרות שנבחרה ברשימת האפשרויות, החל מ-0. | INT |
| `confidence` | מידת הביטחון של Jev, מ-0 (אין מנצח ברור) עד 1 (ודאי). | FLOAT |
