# TypeSafe Jev (Choice)

צומת TypeSafe Jev (Choice) בוחר אחת מהאפשרויות שלך עבור טקסט מקושר, תמונות, או שניהם. חבר את `choice` לצומת Branch שקלטיו נושאים את שמות האפשרויות, או השתמש ב־`option_index` כדי לבחור לפי מיקום האפשרות הנבחרת. זהו צומת API והוא דורש חשבון Comfy.org ומפתח API.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל Jev לשימוש. נכון לעכשיו זמין מודל אחד בלבד: `jev-1.14.0`. | COMBO | כן | `"jev-1.14.0"` |
| `question` | השאלה שהאפשרויות עונות עליה. כאשר קיימים מספר חיבורי תמונה, השתמש בשמותיהם, לדוגמה `Which season is shown in image_1?` (ברירת מחדל: `What style is the image?`). | STRING | כן | 1 עד 1000 תווים |
| `options` | האפשרויות לבחירה, אחת בכל שורה. הוסף אפשרות כגון `other` עבור קלטים שאינם מתאימים לאף אחת מהן (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch` ו־`other`, אחת בכל שורה). | STRING | כן | 2 עד 50 אפשרויות, עד 40 תווים כל אחת |
| `images` | התמונות שהשאלה עוסקת בהן. עד 32 תמונות בסך הכול; קלט מרוכז נספר פעם אחת לכל תמונה, ותמונות מעל 4 נשלחות בגודל קטן יותר. | AUTOGROW | לא | 0 עד 32 תמונות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM. | STRING | לא | 0 עד 3000 תווים |

**הערות:**

- חבר טקסט או לפחות תמונה אחת; הצומת מחזיר שגיאה כאשר שניהם ריקים.
- הצומת מחזיר שגיאה כאשר ניתנות פחות מ־2 או יותר מ־50 אפשרויות, כאשר אפשרות ארוכה מ־40 תווים, או כאשר שתי אפשרויות נבדלות רק באותיות גדולות/קטנות.
- `option_index` נספר מ־0, כך שהאפשרות הראשונה ברשימה היא בעלת האינדקס 0.
- החיוב מבוסס טוקנים; תג המחיר על הצומת מציג את התעריף המשוער לכל 1M טוקנים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `choice` | האפשרות הנבחרת, בדיוק כפי שהיא מופיעה ב־`options`. | STRING |
| `option_index` | המיקום של האפשרות הנבחרת ברשימת האפשרויות, החל מ־0. | INT |
| `confidence` | מידת הביטחון של Jev, מ־0 (אין מנצח ברור) ועד 1 (ודאי). | FLOAT |
