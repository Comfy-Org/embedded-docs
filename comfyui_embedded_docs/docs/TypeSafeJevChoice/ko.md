# TypeSafe Jev (Choice)

TypeSafe Jev (Choice) 노드는 연결된 텍스트, 이미지 또는 둘 다에 대해 사용자 지정 옵션 중 하나를 선택합니다. `choice`를 입력에 옵션 이름이 있는 Branch 노드에 연결하거나, `option_index`를 사용해 선택된 옵션의 위치에 따라 전환하십시오. Branch 노드는 최대 32개의 입력을 받으므로, 옵션이 그보다 많은 목록은 `option_index`로만 라우팅할 수 있습니다. 이 노드는 API 노드입니다. Comfy 서버에서 실행되며 크레딧이 있는 Comfy.org 계정이 필요합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 Jev 모델입니다. 현재 사용 가능한 모델은 `jev-1.14.0` 하나뿐입니다. | COMBO | 예 | `"jev-1.14.0"` |
| `question` | 옵션이 답하는 질문입니다. 이미지 소켓이 여러 개인 경우 해당 이름을 사용하십시오. 예: `Which season is shown in image_1?` (기본값: `What style is the image?`). | STRING | 예 | 1~1000자 |
| `options` | 선택할 옵션으로, 한 줄에 하나씩 입력합니다. 각 줄의 앞뒤 공백은 제거되며, 옵션은 대소문자를 구분하지 않고 고유해야 하므로 반복된 옵션이나 대소문자만 다른 두 옵션은 거부됩니다. 어느 옵션에도 해당하지 않는 입력을 위해 `other`와 같은 옵션을 추가하십시오(기본값: `photo`, `illustration`, `3d render`, `anime`, `sketch` 및 `other`, 한 줄에 하나씩). | STRING | 예 | 2~50개 옵션, 각 최대 40자 |
| `images` | 질문의 대상이 되는 이미지입니다. 총 최대 32개 이미지입니다. 배치 입력은 이미지당 한 번으로 계산됩니다. 모든 이미지의 긴 변은 총 이미지 수에 따라 제한됩니다: 최대 4개 이미지의 경우 1568 px, 최대 8개 이미지의 경우 1024 px, 최대 16개 이미지의 경우 768 px, 최대 32개 이미지의 경우 512 px이므로, 배치가 클수록 각 이미지의 세부 묘사가 줄어들 수 있습니다. | AUTOGROW | 아니요 | 0~32개 이미지 |
| `text` | 질문의 대상이 되는 텍스트입니다(예: 프롬프트 또는 LLM 응답). | STRING | 아니요 | 0~3000자 |

**참고:**

- 텍스트 또는 이미지를 하나 이상 연결하십시오. 둘 다 비어 있으면 노드에서 오류가 발생합니다.
- 옵션이 2개 미만이거나 50개 초과로 제공되면, 옵션이 40자를 초과하면, 또는 대소문자를 구분하지 않았을 때 두 옵션이 같으면 노드에서 오류가 발생합니다.
- `option_index`는 0부터 계산되므로 목록의 첫 번째 옵션 인덱스는 0입니다.
- 청구는 토큰 기반이며, 노드의 가격 배지에는 100만 토큰당 대략적인 요금이 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `choice` | 선택된 옵션으로, 앞뒤 공백이 제거됩니다. 해당 공백을 유지하는 Branch 입력 이름은 일치하지 않습니다. | STRING |
| `option_index` | 옵션 목록에서 선택된 옵션의 위치이며, 0부터 시작합니다. | INT |
| `confidence` | Jev가 얼마나 확신하는지를 나타내며, 0(명확한 선택 없음)에서 1(확실함)까지입니다. | FLOAT |
