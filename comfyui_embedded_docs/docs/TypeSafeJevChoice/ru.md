# TypeSafe Jev (Choice)

Узел TypeSafe Jev (Choice) выбирает один из ваших собственных вариантов для подключённого текста, изображений или того и другого. Подключите `choice` к узлу Branch, входы которого содержат имена вариантов, или используйте `option_index`, чтобы переключаться по позиции выбранного варианта. Узел Branch принимает не более 32 входов, поэтому список с большим числом вариантов можно направлять только через `option_index`. Это API-узел: он выполняется на серверах Comfy и требует учётную запись Comfy.org с кредитами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель Jev, которую нужно использовать. Сейчас доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Вопрос, на который отвечают варианты. При наличии нескольких сокетов изображений используйте их имена, например `Which season is shown in image_1?` (по умолчанию: `What style is the image?`). | STRING | Да | от 1 до 1000 символов |
| `options` | Варианты для выбора, по одному на строку. Начальные и конечные пробелы в каждой строке обрезаются; варианты должны быть уникальными без учёта регистра, поэтому повторяющийся вариант или два варианта, отличающиеся только регистром, отклоняются. Добавьте вариант вроде `other` для входов, которые не подходят ни под один из них (по умолчанию: `photo`, `illustration`, `3d render`, `anime`, `sketch` и `other`, по одному на строку). | STRING | Да | от 2 до 50 вариантов, до 40 символов каждый |
| `images` | Изображения, к которым относится вопрос. Всего до 32 изображений; пакетный вход учитывается по одному разу на изображение. Длинная сторона каждого изображения ограничивается в зависимости от общего числа изображений: 1568 px при до 4 изображений, 1024 px при до 8, 768 px при до 16 и 512 px при до 32, поэтому больший пакет может снизить детализацию каждого изображения. | AUTOGROW | Нет | от 0 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Подключите текст или хотя бы одно изображение; узел выдаёт ошибку, если и то и другое пусто.
- Узел выдаёт ошибку, если задано меньше 2 или больше 50 вариантов, если вариант длиннее 40 символов или если два варианта совпадают без учёта регистра.
- `option_index` считается с 0, поэтому первый вариант в списке имеет индекс 0.
- Оплата основана на токенах; значок цены на узле показывает приблизительную ставку за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `choice` | Выбранный вариант с обрезанными начальными и конечными пробелами. Вход Branch, в имени которого сохранены эти пробелы, не совпадёт. | STRING |
| `option_index` | Позиция выбранного варианта в списке вариантов, начиная с 0. | INT |
| `confidence` | Насколько Jev уверен, от 0 (нет явного победителя) до 1 (полная уверенность). | FLOAT |
