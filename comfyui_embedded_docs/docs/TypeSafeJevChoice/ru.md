# TypeSafe Jev (Choice)

Узел TypeSafe Jev (Choice) выбирает один из ваших собственных вариантов для подключённого текста, изображений или и того, и другого. Подключите `choice` к узлу Branch, входы которого содержат имена вариантов, или используйте `option_index`, чтобы переключаться по позиции выбранного варианта. Это API-узел; для него требуются учётная запись Comfy.org и ключ API.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель Jev. Сейчас доступна только одна модель: `jev-1.14.0`. | COMBO | Да | `"jev-1.14.0"` |
| `question` | Вопрос, на который отвечают варианты. При наличии нескольких входов изображений используйте их имена, например `Which season is shown in image_1?` (по умолчанию: `What style is the image?`). | STRING | Да | от 1 до 1000 символов |
| `options` | Варианты для выбора, по одному на строку. Добавьте вариант, например `other`, для входов, которые не подходят ни под один из них (по умолчанию: `photo`, `illustration`, `3d render`, `anime`, `sketch` и `other`, по одному на строку). | STRING | Да | от 2 до 50 вариантов, до 40 символов каждый |
| `images` | Изображения, к которым относится вопрос. Всего до 32 изображений; пакетный вход считается один раз для каждого изображения, а более 4 изображений отправляются в уменьшенном размере. | AUTOGROW | Нет | от 0 до 32 изображений |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM. | STRING | Нет | от 0 до 3000 символов |

**Примечания:**

- Подключите текст или хотя бы одно изображение; узел выдаёт ошибку, если оба пусты.
- Узел выдаёт ошибку, если указано меньше 2 или больше 50 вариантов, если вариант длиннее 40 символов или если два варианта различаются только регистром букв.
- `option_index` считается с 0, поэтому первый вариант в списке имеет индекс 0.
- Оплата основана на токенах; значок цены на узле показывает приблизительную ставку за 1 млн токенов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `choice` | Выбранный вариант, записанный точно так, как он указан в `options`. | STRING |
| `option_index` | Позиция выбранного варианта в списке вариантов, начиная с 0. | INT |
| `confidence` | Насколько Jev уверен: от 0 (нет явного победителя) до 1 (полная уверенность). | FLOAT |
