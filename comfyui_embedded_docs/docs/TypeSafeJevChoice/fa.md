# TypeSafe Jev (Choice)

گره TypeSafe Jev (Choice) یکی از گزینه‌های خودتان را برای متن، تصاویر یا هر دوی متصل‌شده انتخاب می‌کند. `choice` را به یک گره Branch متصل کنید که ورودی‌هایش نام گزینه‌ها را دارند، یا از `option_index` برای جابه‌جایی بر اساس موقعیت گزینه انتخاب‌شده استفاده کنید. یک گره Branch حداکثر 32 ورودی می‌پذیرد، بنابراین فهرستی با گزینه‌های بیش از این تعداد فقط از طریق `option_index` قابل هدایت است. این یک گره API است: روی سرورهای Comfy اجرا می‌شود و به حساب Comfy.org دارای اعتبار نیاز دارد.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | پرسشی که گزینه‌ها به آن پاسخ می‌دهند. با چند سوکت تصویر، از نام آن‌ها استفاده کنید، برای مثال `Which season is shown in image_1?` (پیش‌فرض: `What style is the image?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `options` | گزینه‌هایی برای انتخاب، هر کدام در یک خط. فاصله‌های ابتدا و انتهای هر خط حذف می‌شوند و گزینه‌ها باید با صرف‌نظر از بزرگی و کوچکی حروف یکتا باشند؛ بنابراین یک گزینه تکراری یا دو گزینه که فقط در بزرگی و کوچکی حروف تفاوت دارند رد می‌شوند. گزینه‌ای مانند `other` برای ورودی‌هایی که با هیچ‌کدام از آن‌ها سازگار نیستند اضافه کنید (پیش‌فرض: `photo`، `illustration`، `3d render`، `anime`، `sketch` و `other`، هر کدام در یک خط). | STRING | بله | 2 تا 50 گزینه، حداکثر 40 کاراکتر برای هر گزینه |
| `images` | تصاویری که پرسش درباره آن‌هاست. در مجموع حداکثر 32 تصویر؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود. ضلع بلند هر تصویر با تعداد کل تصاویر محدود می‌شود: 1568 پیکسل برای حداکثر 4 تصویر، 1024 پیکسل برای حداکثر 8 تصویر، 768 پیکسل برای حداکثر 16 تصویر و 512 پیکسل برای حداکثر 32 تصویر؛ بنابراین یک دسته بزرگ‌تر می‌تواند جزئیات هر تصویر را کاهش دهد. | AUTOGROW | خیر | 0 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند یک پرامپت یا پاسخ LLM. | STRING | خیر | 0 تا 3000 کاراکتر |

**نکته‌ها:**

- متن یا حداقل یک تصویر را متصل کنید؛ اگر هر دو خالی باشند، گره خطا می‌دهد.
- اگر کمتر از 2 یا بیشتر از 50 گزینه داده شود، اگر یک گزینه بیش از 40 کاراکتر باشد، یا اگر دو گزینه با صرف‌نظر از بزرگی و کوچکی حروف یکسان باشند، گره خطا می‌دهد.
- `option_index` از 0 شمارش می‌شود، بنابراین اولین گزینه در فهرست شاخص 0 دارد.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره، نرخ تقریبی به ازای هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
| --- | --- | --- |
| `choice` | گزینه انتخاب‌شده، با حذف فاصله‌های ابتدا و انتها. ورودی Branch که نامش آن فاصله‌ها را نگه دارد، مطابقت نخواهد کرد. | STRING |
| `option_index` | موقعیت گزینه انتخاب‌شده در فهرست گزینه‌ها، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (بدون برنده واضح) تا 1 (قطعی). | FLOAT |
