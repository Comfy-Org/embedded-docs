# TypeSafe Jev (Choice)

گره TypeSafe Jev (Choice) یکی از گزینه‌های خود شما را برای متن، تصاویر یا هر دو انتخاب می‌کند. `choice` را به یک گره Branch متصل کنید که ورودی‌های آن نام گزینه‌ها را حمل می‌کنند، یا از `option_index` برای سوییچ بر اساس موقعیت گزینه انتخاب‌شده استفاده کنید. یک گره Branch حداکثر 32 ورودی می‌گیرد؛ بنابراین فهرستی با گزینه‌های بیشتر از این تعداد فقط با `option_index` قابل مسیریابی است. این یک گره API است: روی سرورهای Comfy اجرا می‌شود و به حساب Comfy.org با اعتبار نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | پرسشی که گزینه‌ها به آن پاسخ می‌دهند. وقتی چند سوکت تصویر دارید، از نام آن‌ها استفاده کنید، برای مثال `Which season is shown in image_1?` (پیش‌فرض: `What style is the image?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `options` | گزینه‌هایی برای انتخاب، هر کدام در یک خط. فضای خالی ابتدا و انتهای هر خط حذف می‌شود، و گزینه‌ها باید بدون در نظر گرفتن بزرگی و کوچکی حروف یکتا باشند؛ بنابراین گزینه تکراری یا دو گزینه‌ای که فقط در بزرگی و کوچکی حروف تفاوت دارند رد می‌شوند. یک گزینه مانند `other` برای ورودی‌هایی که با هیچ‌کدام از گزینه‌ها جور نیستند اضافه کنید (پیش‌فرض: `photo`، `illustration`، `3d render`، `anime`، `sketch` و `other`، هر کدام در یک خط). | STRING | بله | 2 تا 50 گزینه، حداکثر 40 کاراکتر برای هر گزینه |
| `images` | تصاویری که پرسش درباره آن‌هاست. در مجموع حداکثر 32 تصویر؛ یک ورودی دسته‌ای به ازای هر تصویر یک بار شمرده می‌شود. ضلع بلند هر تصویر بر اساس تعداد کل تصاویر محدود می‌شود: 1568 پیکسل برای حداکثر 4 تصویر، 1024 پیکسل برای حداکثر 8 تصویر، 768 پیکسل برای حداکثر 16 تصویر و 512 پیکسل برای حداکثر 32 تصویر؛ بنابراین دسته بزرگ‌تر یعنی جزئیات کمتر در هر تصویر. | AUTOGROW | خیر | 0 تا 32 تصویر |
| `text` | متنی که پرسش درباره آن است، مانند یک پرامپت یا پاسخ یک LLM. | STRING | خیر | 0 تا 3000 کاراکتر |

**نکته‌ها:**

- متن یا حداقل یک تصویر متصل کنید؛ وقتی هر دو خالی باشند، گره خطا می‌دهد.
- گره زمانی خطا می‌دهد که کمتر از 2 یا بیشتر از 50 گزینه داده شود، یک گزینه بیش از 40 کاراکتر باشد، یا دو گزینه بدون در نظر گرفتن بزرگی و کوچکی حروف یکسان باشند.
- `option_index` از 0 شروع می‌شود، بنابراین اولین گزینه در فهرست اندیس 0 دارد.
- صورت‌حساب بر پایه توکن است؛ برچسب قیمت روی گره نرخ تقریبی هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `choice` | گزینه انتخاب‌شده، با حذف فضای خالی ابتدا و انتها. ورودی Branch که نام آن این فاصله‌ها را حفظ کند، مطابقت پیدا نمی‌کند. | STRING |
| `option_index` | موقعیت گزینه انتخاب‌شده در فهرست گزینه‌ها، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (بدون برنده مشخص) تا 1 (قطعی). | FLOAT |
