# TypeSafe Jev (Choice)

گره TypeSafe Jev (Choice) یکی از گزینه‌های خودتان را برای متن، تصاویر یا هر دوی متصل‌شده انتخاب می‌کند. `choice` را به یک گره Branch متصل کنید که ورودی‌هایش نام گزینه‌ها را حمل می‌کنند، یا از `option_index` برای انتخاب بر اساس موقعیت گزینه انتخاب‌شده استفاده کنید. این یک گره API است و به حساب Comfy.org و کلید API نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدل Jev برای استفاده. در حال حاضر فقط یک مدل موجود است: `jev-1.14.0`. | COMBO | بله | `"jev-1.14.0"` |
| `question` | سؤالی که گزینه‌ها به آن پاسخ می‌دهند. با چند سوکت تصویر، از نام آن‌ها استفاده کنید، برای نمونه `Which season is shown in image_1?` (پیش‌فرض: `What style is the image?`). | STRING | بله | 1 تا 1000 کاراکتر |
| `options` | گزینه‌هایی برای انتخاب، هر کدام در یک خط. گزینه‌ای مانند `other` برای ورودی‌هایی که با هیچ‌کدام مطابقت ندارند اضافه کنید (پیش‌فرض: `photo`، `illustration`، `3d render`، `anime`، `sketch` و `other`، هر کدام در یک خط). | STRING | بله | 2 تا 50 گزینه، حداکثر 40 کاراکتر برای هر گزینه |
| `images` | تصاویری که سؤال درباره آن‌هاست. در مجموع حداکثر 32 تصویر؛ ورودی دسته‌ای به ازای هر تصویر یک بار شمرده می‌شود و بیش از 4 تصویر با اندازه کوچک‌تری ارسال می‌شود. | AUTOGROW | خیر | 0 تا 32 تصویر |
| `text` | متنی که سؤال درباره آن است، مانند یک پرامپت یا پاسخ LLM. | STRING | خیر | 0 تا 3000 کاراکتر |

**یادداشت‌ها:**

- متن یا حداقل یک تصویر را متصل کنید؛ وقتی هر دو خالی باشند، گره خطا می‌دهد.
- گره زمانی خطا می‌دهد که کمتر از 2 یا بیشتر از 50 گزینه داده شود، یکی از گزینه‌ها بیش از 40 کاراکتر باشد، یا دو گزینه فقط در بزرگی/کوچکی حروف تفاوت داشته باشند.
- `option_index` از 0 شروع می‌شود، بنابراین اولین گزینه در فهرست اندیس 0 دارد.
- صورت‌حساب بر پایه توکن است؛ نشان قیمت روی گره نرخ تقریبی به ازای هر 1 میلیون توکن را نشان می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `choice` | گزینه انتخاب‌شده، دقیقاً همان‌طور که در `options` آمده نوشته می‌شود. | STRING |
| `option_index` | موقعیت گزینه انتخاب‌شده در فهرست گزینه‌ها، با شروع از 0. | INT |
| `confidence` | میزان اطمینان Jev، از 0 (بدون برنده مشخص) تا 1 (قطعی). | FLOAT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TypeSafeJevChoice/fa.md)
