# Recraft Векторизация Изображения

Создаёт SVG-векторную графику из входного изображения. Этот узел преобразует растровые изображения в масштабируемый векторный формат, отправляя каждое изображение в Recraft API и возвращая результаты в одном выходе SVG. Этот выход содержит отдельный SVG-документ для каждого обработанного изображения; документы не объединяются в один.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для преобразования в формат SVG. Поддерживает пакетную обработку нескольких изображений. | IMAGE | Да | - |
| `версия` | Версия векторизатора: `v1` — стандартная версия, а `v1_pro` (Vectorizer Pro) даёт более чистые SVG с плавными кривыми, прямыми линиями и острыми углами; лучше всего подходит для надписей и сложных форм (по умолчанию: "v1"). | COMBO | Нет | "v1"<br>"v1_pro" |
| `shape_stacking` | Способ наложения фигур в SVG: `hierarchical` накладывает фигуры друг на друга; `cut_out` создаёт фигуры, которые никогда не перекрываются, для плоттеров, виниловых резаков и трафаретной печати (по умолчанию: "hierarchical"). | COMBO | Нет | "hierarchical"<br>"cut_out" |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SVG` | Сгенерированная векторная графика. Единый выход SVG содержит отдельный SVG-документ для каждого обработанного изображения. | SVG |
