# Recraft ベクトル化画像

入力画像から SVG ベクターグラフィックを生成します。このノードは、各画像を Recraft API に送信し、結果を単一の SVG 出力として返すことで、ラスター画像をスケーラブルなベクター形式に変換します。その出力には、処理された画像ごとに個別の SVG ドキュメントが含まれます。ドキュメントは 1 つに統合されません。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | SVG 形式に変換する入力画像です。複数の画像のバッチ処理をサポートします。 | IMAGE | はい | - |
| `バージョン` | ベクタライザーのバージョンです。`v1` は標準バージョンで、`v1_pro`（Vectorizer Pro）は滑らかな曲線、直線、鋭い角を備えたよりクリーンな SVG を提供し、レタリングや複雑な形状に最適です（デフォルト: "v1"）。 | COMBO | いいえ | "v1"<br>"v1_pro" |
| `shape_stacking` | SVG 内でシェイプをどのように重ねるかです。`hierarchical` はシェイプを互いに重ねて階層化します。`cut_out` は重なり合わないシェイプを作成し、プロッター、ビニールカッター、スクリーン印刷に適しています（デフォルト: "hierarchical"）。 | COMBO | いいえ | "hierarchical"<br>"cut_out" |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | 生成されたベクターグラフィックです。単一の SVG 出力には、処理された画像ごとに個別の SVG ドキュメントが含まれます。 | SVG |
