# وکتورسازی تصویر Recraft

از یک تصویر ورودی، گرافیک برداری SVG تولید می‌کند. این گره با ارسال هر تصویر به Recraft API و بازگرداندن نتایج در یک خروجی SVG واحد، تصاویر رستری را به قالب برداری مقیاس‌پذیر تبدیل می‌کند. آن خروجی برای هر تصویر پردازش‌شده یک سند SVG جداگانه نگه می‌دارد؛ اسناد در یک سند ادغام نمی‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی برای تبدیل به قالب SVG. از پردازش دسته‌ای چندین تصویر پشتیبانی می‌کند. | IMAGE | بله | - |
| `version` | نسخهٔ برداری‌ساز: `v1` نسخهٔ استاندارد است، و `v1_pro` (Vectorizer Pro) SVGهای تمیزتری با منحنی‌های نرم، خطوط مستقیم و گوشه‌های تیز ارائه می‌دهد، که برای حروف‌نگاری و اشکال پیچیده بهترین است (پیش‌فرض: "v1"). | COMBO | خیر | "v1"<br>"v1_pro" |
| `shape_stacking` | نحوهٔ چیدمان اشکال در SVG: `hierarchical` اشکال را روی هم لایه‌بندی می‌کند؛ `cut_out` اشکالی می‌سازد که هرگز هم‌پوشانی ندارند، مناسب برای پلاترها، برش‌دهنده‌های وینیل و چاپ سیلک (پیش‌فرض: "hierarchical"). | COMBO | خیر | "hierarchical"<br>"cut_out" |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `SVG` | گرافیک برداری تولیدشده. خروجی SVG واحد برای هر تصویر پردازش‌شده یک سند SVG جداگانه نگه می‌دارد. | SVG |
