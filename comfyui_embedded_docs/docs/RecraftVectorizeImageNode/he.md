# Recraft וקטוריזציה לתמונה

מייצר גרפיקה וקטורית SVG מתמונת קלט. צומת זה ממיר תמונות רסטר לפורמט וקטורי ניתן להגדלה על ידי שליחת כל תמונה ל-Recraft API והחזרת התוצאות בפלט SVG יחיד. פלט זה מכיל מסמך SVG נפרד עבור כל תמונה שעובדה; המסמכים אינם ממוזגים למסמך אחד.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `תמונה` | תמונת הקלט להמרה לפורמט SVG. תומך בעיבוד אצווה של מספר תמונות. | IMAGE | כן | - |
| `version` | גרסת הווקטוריזר: `v1` היא הגרסה הסטנדרטית, ו-`v1_pro` (Vectorizer Pro) מפיקה קובצי SVG נקיים יותר עם עקומות חלקות, קווים ישרים ופינות חדות, וטובה במיוחד לכיתוב ולצורות מורכבות (ברירת מחדל: "v1"). | COMBO | לא | "v1"<br>"v1_pro" |
| `shape_stacking` | אופן הערמת הצורות ב-SVG: `hierarchical` מערים צורות זו על גבי זו; `cut_out` יוצר צורות שאינן חופפות לעולם, עבור פלוטרים, חותכי ויניל והדפסת מסך (ברירת מחדל: "hierarchical"). | COMBO | לא | "hierarchical"<br>"cut_out" |
