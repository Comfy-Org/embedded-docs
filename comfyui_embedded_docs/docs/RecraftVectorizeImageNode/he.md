# RecraftVectorizeImageNode

יוצר גרפיקה וקטורית SVG מתמונת קלט. צומת זה ממיר תמונות רסטר לפורמט וקטורי ניתן להרחבה בכך שהוא שולח כל תמונה ל-Recraft API ומשלב את התוצאות לפלט SVG יחיד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט להמרה לפורמט SVG. תומך בעיבוד באצווה של מספר תמונות. | IMAGE | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `SVG` | פלט הגרפיקה הווקטורית שנוצר, המשלב את כל התמונות המעובדות למסמך SVG יחיד. | SVG |
