# إعادة صياغة تحويل الصورة إلى متجه

يُنشئ رسومات متجهية SVG من صورة إدخال. تحوّل هذه العقدة الصور النقطية إلى صيغة متجهية قابلة للتحجيم عن طريق إرسال كل صورة إلى واجهة Recraft API وإرجاع النتائج في مخرج SVG واحد. يحتوي هذا المخرج على مستند SVG منفصل لكل صورة تتم معالجتها؛ ولا يتم دمج المستندات في مستند واحد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المدخلة المراد تحويلها إلى صيغة SVG. تدعم المعالجة بالدفعات لعدة صور. | IMAGE | نعم | - |
| `version` | إصدار أداة التجهيز المتجهي: `v1` هو الإصدار القياسي، و`v1_pro` (Vectorizer Pro) ينتج ملفات SVG أنظف بمنحنيات ناعمة وخطوط مستقيمة وزوايا حادة، وهو الأنسب للخطوط والأشكال المعقدة (افتراضي: "v1"). | COMBO | لا | "v1"<br>"v1_pro" |
| `shape_stacking` | كيفية تكديس الأشكال في SVG: `hierarchical` يضع الأشكال في طبقات فوق بعضها البعض؛ `cut_out` ينشئ أشكالًا لا تتداخل أبدًا، وهو مناسب لأجهزة الرسم وقاطعات الفينيل والطباعة بالشاشة الحريرية (افتراضي: "hierarchical"). | COMBO | لا | "hierarchical"<br>"cut_out" |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `SVG` | الرسومات المتجهية المُنشأة. يحتوي مخرج SVG الواحد على مستند SVG منفصل لكل صورة تتم معالجتها. | SVG |
