# إعادة صياغة تحويل الصورة إلى متجه

يولّد رسومات SVG متجهة من صورة إدخال. تحوّل هذه العقدة الصور النقطية إلى تنسيق متجهي قابل للتحجيم عن طريق إرسال كل صورة إلى Recraft API ودمج النتائج في مخرج SVG واحد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | صورة الإدخال المراد تحويلها إلى تنسيق SVG. يدعم المعالجة الدفعية لعدة صور. | IMAGE | نعم | - |
| `version` | إصدار أداة التوجيه المتجهي: `v1` هو الإصدار القياسي، و`v1_pro` (Vectorizer Pro) يعطي ملفات SVG أنظف مع منحنيات ناعمة وخطوط مستقيمة وزوايا حادة، وهو الأفضل للخطوط والأشكال المعقدة (الافتراضي: "v1"). | COMBO | لا | "v1"<br>"v1_pro" |
| `shape_stacking` | كيفية تكديس الأشكال في SVG: `hierarchical` يكدس الأشكال فوق بعضها البعض؛ `cut_out` يجعل الأشكال لا تتداخل أبدًا، وهو مناسب لراسمات البلوتير وقاطعات الفينيل والطباعة بالشاشة الحريرية (الافتراضي: "hierarchical"). | COMBO | لا | "hierarchical"<br>"cut_out" |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `SVG` | مخرج الرسومات المتجهة الناتج، الذي يجمع كل الصور المعالجة في مستند SVG واحد. | SVG |
