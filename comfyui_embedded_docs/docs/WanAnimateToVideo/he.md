# WanAnimateToVideo

WanAnimateToVideo מכין נתוני התניה ולטנט ראשוני ליצירת וידאו מונפש עם Wan, תוך שימוש בקלטים כגון תמונת ייחוס, תנוחה, פנים, רקע ותנועה אופציונלית ממקטע קודם. הוא תומך גם ביצירת סרטונים ארוכים יותר במקטעים על ידי קריאה ועדכון של ערך `video_frame_offset`. צומת זה מסומן כניסיוני.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | התניה חיובית להכוונת היצירה לעבר תוכן רצוי. | CONDITIONING | כן | - |
| `negative` | התניה שלילית להרחקת היצירה מתוכן לא רצוי. | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד קלטי תמונה ווידאו למרחב לטנטי. | VAE | כן | - |
| `width` | רוחב הווידאו הנוצר בפיקסלים (ברירת מחדל: 832, צעד: 16). | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה הווידאו הנוצר בפיקסלים (ברירת מחדל: 480, צעד: 16). | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ליצירה (ברירת מחדל: 77, צעד: 4). | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הסרטונים ליצירה באצווה אחת (ברירת מחדל: 1). | INT | כן | 1 עד 4096 |
| `clip_vision_output` | פלט ראייה CLIP אופציונלי שמתווסף גם להתניה החיובית וגם לשלילית. | CLIP_VISION_OUTPUT | לא | - |
| `reference_image` | תמונת ייחוס המשמשת כנקודת התחלה חזותית עבור הווידאו הנוצר. אם לא סופקה, נעשה שימוש בתמונה שחורה. | IMAGE | לא | - |
| `face_video` | קלט וידאו המספק הכוונה להבעות פנים. הוא משתנה בגודלו ל-512x512 ומותאם פנימית לטווח -1.0 עד 1.0. | IMAGE | לא | - |
| `pose_video` | קלט וידאו המספק הכוונה לתנוחה ולתנועה. | IMAGE | לא | - |
| `continue_motion_max_frames` | מספר הפריימים המקסימלי המועבר מרצף תנועה קודם (ברירת מחדל: 5, צעד: 4). | INT | כן | 1 עד MAX_RESOLUTION |
| `background_video` | וידאו רקע המשמש למילוי חלקים שאינם דמות בפריימים. | IMAGE | לא | - |
| `character_mask` | מסכה המגדירה אזורי דמות, ומשמשת להפרדת הדמות מהרקע. | MASK | לא | - |
| `continue_motion` | פריימי תנועה קודמים שמהם ממשיכים, תוך שמירה על עקביות זמנית עם מקטעים שנוצרו קודם לכן. | IMAGE | לא | - |
| `video_frame_offset` | כמות הפריימים לדילוג בכל קלטי הווידאו. משמש ליצירת סרטונים ארוכים יותר לפי מקטע. יש לחבר לפלט `video_frame_offset` של הצומת הקודם כדי להאריך וידאו. (ברירת מחדל: 0, צעד: 1) | INT | כן | 0 עד MAX_RESOLUTION |

**אילוצי פרמטרים:**

- כאשר `continue_motion` מסופק, נעשה שימוש רק ב-`continue_motion_max_frames` הפריימים האחרונים שלו.
- קלטי וידאו (`face_video`, `pose_video`, `background_video`, `character_mask`) מוזזים על ידי `video_frame_offset` לפני השימוש. אם ההיסט גדול או שווה למספר הפריימים של הקלט, מתעלמים מאותו קלט, למעט `character_mask` בעל פריים בודד.
- אם ל-`character_mask` יש רק פריים אחד, אותו פריים חוזר על עצמו בכל פריים של הפלט.
- כאשר `pose_video` קצר מ-`length`, הפריים האחרון שלו חוזר על עצמו כדי למלא את הפריימים הנותרים; אורך הפלט אינו משתנה.
- אם `clip_vision_output` מסופק, הוא מתווסף גם להתניה החיובית וגם לשלילית.
- אם `reference_image` לא מסופקת, נעשה שימוש בתמונת ברירת מחדל שחורה (כל הערכים אפס).
- אם `continue_motion` לא מסופק, פריימי התנועה הראשוניים ממולאים בפריימים אפורים קבועים (עוצמה 0.5).
- כאשר משתמשים ב-`continue_motion`, `video_frame_offset` מוקטן במספר הפריימים המועברים לפני חישוב היסט המקטע הבא, כך שפריימים חופפים אינם מעובדים פעמיים.
- `background_video` ממלא את פריימי התנועה לאחר מקטע תנועת הייחוס; הוא אינו מחליף את תמונת הייחוס או את פריימי `continue_motion` המועברים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | התניה חיובית ששונתה עם הקשר וידאו נוסף, כולל פלט ראייה CLIP, לטנט של וידאו תנוחה, פיקסלים של וידאו פנים, תמונת לטנט משורשרת ומסכה משורשרת. | CONDITIONING |
| `negative` | התניה שלילית ששונתה עם הקשר וידאו נוסף, כולל פלט ראייה CLIP, לטנט של וידאו תנוחה, פיקסלים של פנים ריקים, תמונת לטנט משורשרת ומסכה משורשרת. | CONDITIONING |
| `latent` | טנסור לטנט ראשוני (כל הדגימות אפס) עבור הווידאו הנוצר, עם הצורה `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `trim_latent` | מספר פריימי הלטנט שיש לחתוך מתחילת הלטנט, בהתאמה לפריימי תמונת הייחוס. | INT |
| `trim_image` | מספר פריימי התמונה שיש לחתוך מההתחלה, בהתאמה לפריימי תנועת הייחוס. | INT |
| `video_frame_offset` | היסט הפריימים המעודכן לשימוש עבור המקטע הבא, בהתבסס על היסט הקלט ומספר הפריימים שעובדו. | INT |
