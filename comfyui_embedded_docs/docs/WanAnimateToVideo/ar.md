# WanAnimateToVideo

```markdown
WanAnimateToVideo

يقوم WanAnimateToVideo بتجهيز بيانات التكييف (Conditioning) وكامن أولي (Latent) لتوليد فيديوهات متحركة باستخدام Wan، وذلك من خلال مدخلات مثل صورة مرجعية، ووضعية (Pose)، ووجه، وخلفية، وحركة اختيارية من مقطع سابق. كما يدعم توليد فيديوهات أطول على شكل مقاطع عن طريق قراءة وتحديث قيمة `video_frame_offset`. هذه العقدة مُعلَّمة بأنها تجريبية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التوجيه الإيجابي (Positive Conditioning) لتوجيه التوليد نحو المحتوى المرغوب. | CONDITIONING | نعم | - |
| `سلبي` | التوجيه السلبي (Negative Conditioning) لتوجيه التوليد بعيدًا عن المحتوى غير المرغوب فيه. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير مدخلات الصور والفيديو إلى الفضاء الكامن (Latent Space). | VAE | نعم | - |
| `العرض` | عرض الفيديو المُولَّد بالبكسل (الافتراضي: 832، الخطوة: 16). | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو المُولَّد بالبكسل (الافتراضي: 480، الخطوة: 16). | INT | نعم | 16 إلى MAX_RESOLUTION |

| `صورة_مرجعية` | صورة مرجعية تُستخدم كنقطة بداية للمظهر في الفيديو المُولَّد. إذا لم يتم توفيرها، يُستخدم صورة سوداء. | IMAGE | لا | - |

| `فيديو_الوضعية` | مدخل فيديو يوفّر توجيهًا للوضعية والحركة. | IMAGE | لا | - |

| `فيديو_الخلفية` | فيديو خلفية يُستخدم لملء الأجزاء غير المتعلقة بالشخصية في الإطارات. | IMAGE | لا | - |
| `قناع_الشخصية` | قناع يحدد مناطق الشخصية، ويُستخدم لفصل الشخصية عن الخلفية. | MASK | لا | - |
| `مواصلة_الحركة` | إطارات حركة سابقة للمتابعة منها، للحفاظ على الاتساق الزمني مع المقاطع المُولَّدة سابقًا. | IMAGE | لا | - |
| `إزاحة_إطار_الفيديو` | مقدار الإطارات المراد تخطيها في جميع فيديوهات الإدخال. يُستخدم لتوليد مقاطع فيديو أطول عبر التقطيع. اربطه بمخرج `video_frame_offset` من العقدة السابقة لتوسيع الفيديو. (الافتراضي: 0، الخطوة: 1) | INT | نعم | 0 إلى MAX_RESOLUTION |

**قيود المعاملات:**

- عند توفير `continue_motion`، يتم استخدام آخر `continue_motion_max_frames` إطار منه فقط.
- يتم إزاحة فيديوهات الإدخال (`face_video`، `pose_video`، `background_video`، `character_mask`) بواسطة `video_frame_offset` قبل الاستخدام. إذا كانت قيمة الإزاحة أكبر من أو تساوي عدد إطارات الإدخال، يتم تجاهل هذا الإدخال، باستثناء `character_mask` ذو الإطار الواحد.
- إذا كان `character_mask` يحتوي على إطار واحد فقط، يتم تكرار هذا الإطار لكل إطار من إطارات المخرجات.
- عندما يكون `pose_video` أقصر من `length`، يتم تكرار إطاره الأخير لملء الإطارات المتبقية؛ ولا يتغير طول المخرجات.
- إذا تم توفير `clip_vision_output`، فإنه يُضاف إلى كل من التوجيه الإيجابي والسلبي.
- إذا لم يتم توفير `reference_image`، يتم استخدام صورة سوداء (جميع القيم صفر) كمرجع افتراضي.
- إذا لم يتم توفير `continue_motion`، يتم ملء إطارات الحركة الأولية بإطارات رمادية ثابتة (كثافة 0.5).
- عند استخدام `continue_motion`، يتم تقليل `video_frame_offset` بعدد الإطارات المنقولة قبل حساب إزاحة المقطع التالي، بحيث لا تتم معالجة الإطارات المتداخلة مرتين.
- يملأ `background_video` إطارات الحركة بعد جزء المرجع-الحركة؛ ولا يستبدل الصورة المرجعية أو إطارات `continue_motion` المنقولة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | التوجيه الإيجابي المعدّل مع سياق فيديو إضافي، بما في ذلك مخرج رؤية CLIP، وكامن فيديو الوضعية، وبكسلات فيديو الوجه، والصورة الكامنة الملحّقة، والقناع الملحّق. | CONDITIONING |
| `سلبي` | التوجيه السلبي المعدّل مع سياق فيديو إضافي، بما في ذلك مخرج رؤية CLIP، وكامن فيديو الوضعية، وبكسلات وجه فارغة، والصورة الكامنة الملحّقة، والقناع الملحّق. | CONDITIONING |
| `كامن` | موتر كامن أولي (عينات جميعها صفر) للفيديو المُولَّد، بالشكل `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `قص_الكامن` | عدد الإطارات الكامنة التي يجب قصّها من بداية الكامن، وهو ما يقابل إطارات الصورة المرجعية. | INT |
| `قص_الصورة` | عدد إطارات الصورة التي يجب قصّها من البداية، وهو ما يقابل إطارات الحركة المرجعية. | INT |
| `إزاحة_إطار_الفيديو` | إزاحة الإطارات المحدّثة لاستخدامها في المقطع التالي، استنادًا إلى إزاحة الإدخال وعدد الإطارات المعالجة. | INT |
```
