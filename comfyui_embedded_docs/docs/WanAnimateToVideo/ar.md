# WanAnimateToVideo

تقوم هذه العقدة التجريبية بتجهيز توليد فيديو Wan من خلال دمج صورة مرجعية مع فيديوهات اختيارية للوضعية والوجه والخلفية. كما تبني بيانات التكييف وموتر فيديو كامنًا فارغًا للتوليد اللاحق، وتُرجِع معلومات إزاحة الإطارات التي تساعد على تمديد الفيديوهات الموجودة على شكل أجزاء.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `positive` | التكييف الإيجابي لتوجيه التوليد نحو المحتوى المطلوب. | CONDITIONING | نعم | - |
| `negative` | التكييف السلبي لإبعاد التوليد عن المحتوى غير المرغوب فيه. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير وفك تشفير بيانات الصور. | VAE | نعم | - |
| `width` | عرض فيديو الإخراج بالبكسل (الافتراضي: 832، الخطوة: 16). | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع فيديو الإخراج بالبكسل (الافتراضي: 480، الخطوة: 16). | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات المطلوب توليدها (الافتراضي: 77، الخطوة: 4). | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد الفيديوهات المطلوب توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |
| `clip_vision_output` | مخرج نموذج رؤية CLIP اختياري يُستخدم كتكييف إضافي لكل من التكييف الإيجابي والسلبي. | CLIP_VISION_OUTPUT | لا | - |
| `reference_image` | صورة مرجعية تُستخدم كنقطة بداية للتوليد. إذا لم يتم توفيرها، تُستخدم صورة سوداء (جميع قيمها أصفار). | IMAGE | لا | - |
| `face_video` | فيديو يوفّر توجيهًا لتعابير الوجه. عند معالجته، يُعاد تحجيمه إلى 512×512 ويُطبَّع إلى النطاق من -1.0 إلى 1.0. | IMAGE | لا | - |
| `pose_video` | فيديو يوفّر توجيهًا للوضعية والحركة. إذا كان أقصر من `length`، فسيتم حشوه بآخر إطار له. | IMAGE | لا | - |
| `continue_motion_max_frames` | الحد الأقصى لعدد الإطارات التي يتم الاستمرار بها من حركة سابقة. يُستخدم فقط آخر هذا العدد من إطارات `continue_motion` (الافتراضي: 5، الخطوة: 4). | INT | نعم | 1 إلى MAX_RESOLUTION |
| `background_video` | فيديو الخلفية الذي يتم دمجه مع المحتوى المُولَّد. | IMAGE | لا | - |
| `character_mask` | قناع يحدد مناطق الشخصية للمعالجة الانتقائية. إذا كان القناع يحتوي على إطار واحد فقط، يتم تكراره عبر جميع الإطارات. | MASK | لا | - |
| `continue_motion` | تسلسل الحركة السابق المستخدم للحفاظ على الاتساق الزمني عند تمديد فيديو. يُستخدم فقط آخر `continue_motion_max_frames` إطارات. | IMAGE | لا | - |
| `video_frame_offset` | عدد الإطارات التي يتم التقدّم بها في جميع فيديوهات الإدخال. يُستخدم لتوليد فيديوهات أطول عبر الأجزاء. اربطه بمخرج `video_frame_offset` من العقدة السابقة لتمديد الفيديو (الافتراضي: 0، الخطوة: 1). | INT | نعم | 0 إلى MAX_RESOLUTION |

**قيود المعاملات:**

- عند توفير `pose_video`، يتم حشو فيديو الوضعية الأقصر بآخر إطار له ليطابق `length`. يحتوي المصدر على علامة `trim_to_pose_video`، معطّلة حاليًا، والتي كانت ستقصّر الإخراج بدلاً من ذلك ليطابق طول فيديو الوضعية.
- يُعاد تحجيم `face_video` إلى 512×512 ويُطبَّع إلى النطاق من -1.0 إلى 1.0.
- يقتصر `continue_motion` على آخر `continue_motion_max_frames` إطارات. عند استخدام `continue_motion`، يتم تقليل `video_frame_offset` بعدد الإطارات المأخوذة، لكنه لا يقل أبدًا عن 0.
- يتم إزاحة فيديوهات الإدخال (`face_video`، `pose_video`، `background_video`، `character_mask`) بمقدار `video_frame_offset`. إذا كانت الإزاحة أكبر من أو تساوي طولها، يتم تجاهل الإدخال، باستثناء `character_mask` ذي الإطار الواحد الذي يُكرَّر دائمًا.
- عند توفير `clip_vision_output`، يتم تطبيقه على كل من التكييف الإيجابي والسلبي.
- إذا لم يتم توفير `reference_image`، تُستخدم صورة سوداء (جميع قيمها أصفار) كمرجع.
- إذا لم يتم توفير `continue_motion`، تُستخدم إطارات رمادية بقيمة بكسل 0.5 لجزء الحركة.
- يستخدم `width` و`height` خطوة مقدارها 16؛ والأبعاد الكامنة المقابلة هي `width / 8` و`height / 8`.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدَّل يتضمن دائمًا الصورة الكامنة المدمجة والقناع المدمج. إذا تم توفير `clip_vision_output` أو `pose_video` أو `face_video`، تُضاف قيمها أيضًا. | CONDITIONING |
| `negative` | تكييف سلبي معدَّل يتضمن دائمًا الصورة الكامنة المدمجة والقناع المدمج. إذا تم توفير `clip_vision_output` أو `pose_video` أو `face_video`، تُضاف قيمها أيضًا؛ وتُضبط وحدات بكسل فيديو الوجه على -1.0. | CONDITIONING |
| `latent` | موتر كامن فارغ مُهيأ بأصفار، بأبعاد `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `trim_latent` | عدد الإطارات الكامنة التي يجب قصّها من البداية، وهي تقابل الإطارات الكامنة للصورة المرجعية. | INT |
| `trim_image` | عدد إطارات الصورة التي يجب قصّها من البداية، وهي تقابل إطارات الحركة المرجعية. | INT |
| `video_frame_offset` | إزاحة الإطارات المحدَّثة لتوليد الفيديو على شكل أجزاء، وتساوي إزاحة الإدخال المعدَّلة مضافًا إليها الطول المُولَّد. | INT |
