# WanAnimateToVideo

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `positive` | شرایط‌دهی مثبت برای هدایت تولید به سمت محتوای مطلوب. | CONDITIONING | بله | - |
| `negative` | شرایط‌دهی منفی برای دور کردن تولید از محتوای ناخواسته. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری و رمزگشایی داده‌های تصویر. | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16). | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16). | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های موردنظر برای تولید (پیش‌فرض: 77، گام: 4). | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که در یک دسته تولید می‌شود (پیش‌فرض: 1). | INT | بله | 1 to 4096 |
| `clip_vision_output` | خروجی اختیاری مدل بینایی CLIP که به‌عنوان شرایط‌دهی اضافی برای هر دو شرایط‌دهی مثبت و منفی استفاده می‌شود. | CLIP_VISION_OUTPUT | خیر | - |
| `reference_image` | تصویر مرجع که به‌عنوان نقطه شروع تولید استفاده می‌شود. اگر ارائه نشود، یک تصویر سیاه (همه صفر) استفاده می‌شود. | IMAGE | خیر | - |
| `face_video` | ویدیویی که راهنمای حالت چهره را فراهم می‌کند. هنگام پردازش، به اندازه 512x512 تغییر اندازه داده شده و به بازه 1.0- تا 1.0 نرمال‌سازی می‌شود. | IMAGE | خیر | - |
| `pose_video` | ویدیویی که راهنمای ژست و حرکت را فراهم می‌کند. اگر کوتاه‌تر از `length` باشد، با آخرین فریم خود پر می‌شود. | IMAGE | خیر | - |
| `continue_motion_max_frames` | حداکثر تعداد فریم‌هایی که از یک حرکت قبلی ادامه داده می‌شود. فقط به همین تعداد فریم آخر از `continue_motion` استفاده می‌شود (پیش‌فرض: 5، گام: 4). | INT | بله | 1 to MAX_RESOLUTION |
| `background_video` | ویدیوی پس‌زمینه برای ترکیب با محتوای تولیدشده. | IMAGE | خیر | - |
| `character_mask` | ماسکی که نواحی شخصیت را برای پردازش انتخابی تعریف می‌کند. اگر ماسک فقط یک فریم داشته باشد، در تمام فریم‌ها تکرار می‌شود. | MASK | خیر | - |
| `continue_motion` | دنباله حرکت قبلی که برای حفظ پیوستگی زمانی هنگام گسترش ویدیو استفاده می‌شود. فقط آخرین فریم‌های `continue_motion_max_frames` استفاده می‌شود. | IMAGE | خیر | - |
| `video_frame_offset` | میزان جابه‌جایی فریم در تمام ویدیوهای ورودی. برای تولید ویدیوهای طولانی‌تر به‌صورت تکه‌تکه استفاده می‌شود. برای گسترش یک ویدیو، به خروجی `video_frame_offset` گره قبلی متصل کنید. (پیش‌فرض: 0، گام: 1) | INT | بله | 0 to MAX_RESOLUTION |

**محدودیت‌های پارامتر:**

- وقتی `pose_video` ارائه شود، ویدیوی ژست کوتاه‌تر با آخرین فریم خود تا رسیدن به `length` پر می‌شود. کد منبع شامل یک پرچم `trim_to_pose_video` است که در حال حاضر غیرفعال است و در صورت فعال بودن، خروجی را برای مطابقت با طول ویدیوی ژست کوتاه می‌کرد.
- `face_video` به اندازه 512x512 تغییر اندازه داده شده و به بازه 1.0- تا 1.0 نرمال‌سازی می‌شود.
- `continue_motion` به آخرین فریم‌های `continue_motion_max_frames` محدود می‌شود. وقتی `continue_motion` استفاده شود، `video_frame_offset` به اندازه تعداد فریم‌های گرفته‌شده کاهش می‌یابد، اما هرگز کمتر از 0 نمی‌شود.
- ویدیوهای ورودی (`face_video`، `pose_video`، `background_video`، `character_mask`) با `video_frame_offset` جابه‌جا می‌شوند. اگر مقدار جابه‌جایی بزرگ‌تر یا مساوی طول آن‌ها باشد، ورودی نادیده گرفته می‌شود؛ به‌جز `character_mask` تک‌فریمی که همیشه تکرار می‌شود.
- وقتی `clip_vision_output` ارائه شود، به هر دو شرایط‌دهی مثبت و منفی اعمال می‌شود.
- اگر `reference_image` ارائه نشود، یک تصویر سیاه (همه صفر) به‌عنوان مرجع استفاده می‌شود.
- اگر `continue_motion` ارائه نشود، برای بخش حرکت، فریم‌های خاکستری با مقدار پیکسل 0.5 استفاده می‌شود.
- `width` و `height` گام 16 دارند؛ ابعاد نهفته متناظر برابر `width / 8` و `height / 8` است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرایط‌دهی مثبت اصلاح‌شده که همیشه شامل تصویر نهفته الحاق‌شده و ماسک الحاق‌شده است. اگر `clip_vision_output`، `pose_video` یا `face_video` ارائه شده باشند، مقادیر آن‌ها نیز اضافه می‌شود. | CONDITIONING |
| `negative` | شرایط‌دهی منفی اصلاح‌شده که همیشه شامل تصویر نهفته الحاق‌شده و ماسک الحاق‌شده است. اگر `clip_vision_output`، `pose_video` یا `face_video` ارائه شده باشند، مقادیر آن‌ها نیز اضافه می‌شود؛ پیکسل‌های ویدیوی چهره روی 1.0- تنظیم می‌شوند. | CONDITIONING |
| `latent` | تانسور نهفته خالی که با صفر مقداردهی اولیه شده و شکل `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]` دارد. | LATENT |
| `trim_latent` | تعداد فریم‌های نهفته‌ای که باید از ابتدا حذف شوند، متناظر با فریم‌های نهفته تصویر مرجع. | INT |
| `trim_image` | تعداد فریم‌های تصویری که باید از ابتدا حذف شوند، متناظر با فریم‌های حرکت مرجع. | INT |
| `video_frame_offset` | آفست فریم به‌روزشده برای تولید ویدیوی تکه‌تکه، برابر با آفست ورودی تنظیم‌شده به‌علاوه طول تولیدشده. | INT |
