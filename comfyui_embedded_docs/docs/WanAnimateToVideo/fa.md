# WanAnimateToVideo

WanAnimateToVideo داده‌های شرطی‌سازی و یک latent اولیه را برای تولید ویدیوهای متحرک با Wan آماده می‌کند. این گره از ورودی‌هایی مانند تصویر مرجع، ژست، چهره، پس‌زمینه و حرکت اختیاری از تکه قبلی استفاده می‌کند. همچنین با خواندن و به‌روزرسانی مقدار `video_frame_offset`، امکان تولید ویدیوهای طولانی‌تر به‌صورت تکه‌تکه فراهم می‌شود. این گره به‌عنوان آزمایشی (experimental) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت برای هدایت تولید به سمت محتوای مطلوب. | CONDITIONING | بله | - |
| `منفی` | شرطی‌سازی منفی برای دور کردن تولید از محتوای ناخواسته. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری ورودی‌های تصویر و ویدیو به فضای latent. | VAE | بله | - |
| `عرض` | عرض ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 832، گام: 16). | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی تولیدشده بر حسب پیکسل (پیش‌فرض: 480، گام: 16). | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌هایی که تولید می‌شوند (پیش‌فرض: 77، گام: 4). | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدیوهایی که در یک batch تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |
| `خروجی clip vision` | خروجی اختیاری CLIP vision که به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود. | CLIP_VISION_OUTPUT | خیر | - |
| `تصویر مرجع` | تصویر مرجع که به‌عنوان نقطه شروع ظاهری ویدیوی تولیدشده استفاده می‌شود. اگر ارائه نشود، یک تصویر سیاه استفاده می‌شود. | IMAGE | خیر | - |
| `ویدیوی چهره` | ورودی ویدیویی که راهنمای حالت چهره را فراهم می‌کند. این ورودی به‌صورت داخلی به 512x512 تغییر اندازه داده می‌شود و به محدوده -1.0 تا 1.0 مقیاس می‌شود. | IMAGE | خیر | - |
| `ویدیوی ژست` | ورودی ویدیویی که راهنمای ژست و حرکت را فراهم می‌کند. | IMAGE | خیر | - |
| `حداکثر فریم‌های ادامه حرکت` | حداکثر تعداد فریم‌هایی که از یک دنباله حرکت قبلی به مرحله بعد منتقل می‌شوند (پیش‌فرض: 5، گام: 4). | INT | بله | 1 to MAX_RESOLUTION |
| `ویدیوی پس‌زمینه` | ویدیوی پس‌زمینه که برای پر کردن بخش‌های غیرشخصیت در فریم‌ها استفاده می‌شود. | IMAGE | خیر | - |
| `ماسک کاراکتر` | ماسکی که نواحی شخصیت را تعریف می‌کند و برای جداسازی شخصیت از پس‌زمینه به کار می‌رود. | MASK | خیر | - |
| `ادامه حرکت` | فریم‌های حرکت قبلی برای ادامه دادن، به‌منظور حفظ سازگاری زمانی با تکه‌های تولیدشده قبلی. | IMAGE | خیر | - |
| `افست فریم ویدیو` | میزان آفست فریم در تمام ویدیوهای ورودی. برای تولید ویدیوهای طولانی‌تر به‌صورت تکه‌تکه استفاده می‌شود. برای ادامه دادن یک ویدیو، آن را به خروجی `video_frame_offset` گره قبلی متصل کنید. (پیش‌فرض: 0، گام: 1) | INT | بله | 0 to MAX_RESOLUTION |

**محدودیت‌های پارامتر:**

- وقتی `continue_motion` ارائه شود، فقط آخرین `continue_motion_max_frames` فریم از آن استفاده می‌شود.
- ورودی‌های ویدیویی (`face_video`, `pose_video`, `background_video`, `character_mask`) قبل از استفاده به اندازه `video_frame_offset` جابه‌جا (offset) می‌شوند. اگر offset بزرگ‌تر یا مساوی تعداد فریم‌های آن ورودی باشد، آن ورودی نادیده گرفته می‌شود، به‌جز `character_mask` تک‌فریمی.
- اگر `character_mask` فقط یک فریم داشته باشد، آن فریم برای تک‌تک فریم‌های خروجی تکرار می‌شود.
- وقتی `pose_video` کوتاه‌تر از `length` باشد، آخرین فریم آن برای پر کردن فریم‌های باقی‌مانده تکرار می‌شود؛ طول خروجی تغییر نمی‌کند.
- اگر `clip_vision_output` ارائه شود، به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود.
- اگر `reference_image` ارائه نشود، یک تصویر سیاه (همه مقادیر صفر) به‌عنوان مرجع پیش‌فرض استفاده می‌شود.
- اگر `continue_motion` ارائه نشود، فریم‌های اولیه حرکت با فریم‌های خاکستری ثابت (شدت 0.5) پر می‌شوند.
- وقتی از `continue_motion` استفاده می‌شود، `video_frame_offset` به تعداد فریم‌های انتقال‌یافته کاهش می‌یابد و سپس offset تکه بعدی محاسبه می‌شود؛ بنابراین فریم‌های همپوشان دوبار پردازش نمی‌شوند.
- `background_video` فریم‌های حرکت را بعد از بخش حرکت مرجع پر می‌کند؛ این ورودی جایگزین تصویر مرجع یا فریم‌های انتقال‌یافته `continue_motion` نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده با زمینه ویدیویی اضافی، شامل خروجی CLIP vision، latent ویدیوی pose، پیکسل‌های ویدیوی چهره، تصویر latent الحاق‌شده و ماسک الحاق‌شده. | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده با زمینه ویدیویی اضافی، شامل خروجی CLIP vision، latent ویدیوی pose، پیکسل‌های خالی چهره، تصویر latent الحاق‌شده و ماسک الحاق‌شده. | CONDITIONING |
| `latent` | تانسور latent اولیه (با همه نمونه‌های صفر) برای ویدیوی تولیدشده، با شکل `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `trim_latent` | تعداد فریم‌های latent که باید از ابتدای latent حذف (trim) شوند؛ متناظر با فریم‌های تصویر مرجع. | INT |
| `برش تصویر` | تعداد فریم‌های تصویری که باید از ابتدا حذف شوند؛ متناظر با فریم‌های حرکت مرجع. | INT |
| `افست فریم ویدیو` | آفست فریم به‌روزشده برای استفاده در تکه بعدی، بر اساس offset ورودی و تعداد فریم‌های پردازش‌شده. | INT |
