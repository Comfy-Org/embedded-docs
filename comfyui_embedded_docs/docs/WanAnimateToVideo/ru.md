# WanAnimateToVideo

WanAnimateToVideo подготавливает данные кондиционирования и начальный латент для генерации анимированных видео с помощью Wan, используя такие входы, как эталонное изображение, поза, лицо, фон и опциональное движение из предыдущего фрагмента. Он также поддерживает генерацию более длинных видео по фрагментам, считывая и обновляя значение `video_frame_offset`. Этот узел помечен как экспериментальный.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование для направления генерации к желаемому содержимому. | CONDITIONING | Да | - |
| `негативный` | Негативное кондиционирование для увода генерации от нежелательного содержимого. | CONDITIONING | Да | - |
| `VAE` | Модель VAE, используемая для кодирования входных изображений и видео в латентное пространство. | VAE | Да | - |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 832, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 480, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров для генерации (по умолчанию: 77, шаг: 4). | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых за один батч (по умолчанию: 1). | INT | Да | 1 до 4096 |
| `выход_clip_vision` | Необязательный выход CLIP vision, добавляемый как к позитивному, так и к негативному кондиционированию. | CLIP_VISION_OUTPUT | Нет | - |
| `эталонное_изображение` | Эталонное изображение, используемое как отправная точка внешнего вида для генерируемого видео. Если не указано, используется чёрное изображение. | IMAGE | Нет | - |
| `видео_лица` | Видео, задающее мимику лица. Внутренне изменяется до размера 512x512 и масштабируется в диапазон от -1.0 до 1.0. | IMAGE | Нет | - |
| `видео_позы` | Видео, задающее позу и движение. | IMAGE | Нет | - |
| `максимум_кадров_продолжения_движения` | Максимальное количество кадров, переносимое из предыдущей последовательности движения (по умолчанию: 5, шаг: 4). | INT | Да | 1 to MAX_RESOLUTION |
| `фоновое_видео` | Фоновое видео, используемое для заполнения частей кадров, не относящихся к персонажу. | IMAGE | Нет | - |
| `маска_персонажа` | Маска, определяющая области персонажа, используется для отделения персонажа от фона. | MASK | Нет | - |
| `продолжение_движения` | Предыдущие кадры движения, чтобы продолжить с них, сохраняя временную согласованность с ранее сгенерированными фрагментами. | IMAGE | Нет | - |
| `смещение_кадров_видео` | Величина смещения кадров во всех входных видео. Используется для генерации более длинных видео по фрагментам. Подключите к выходу `video_frame_offset` предыдущего узла для удлинения видео. (по умолчанию: 0, шаг: 1) | INT | Да | 0 to MAX_RESOLUTION |

**Ограничения параметров:**

- Если указан `continue_motion`, используются только его последние `continue_motion_max_frames` кадров.
- Входные видео (`face_video`, `pose_video`, `background_video`, `character_mask`) смещаются на `video_frame_offset` перед использованием. Если смещение больше или равно количеству кадров входного видео, этот вход игнорируется, за исключением `character_mask`, состоящей из одного кадра.
- Если `character_mask` содержит только один кадр, этот кадр повторяется для каждого кадра выходного видео.
- Если длина `pose_video` меньше значения `length`, его последний кадр повторяется для заполнения оставшихся кадров; длина выходного видео не изменяется.
- Если задан `clip_vision_output`, он добавляется как к позитивному, так и к негативному кондиционированию.
- Если `reference_image` не указано, в качестве эталона по умолчанию используется чёрное изображение (все нулевые значения).
- Если `continue_motion` не указан, начальные кадры движения заполняются однотонными серыми кадрами (интенсивность 0.5).
- При использовании `continue_motion`, `video_frame_offset` уменьшается на количество перенесённых кадров перед вычислением смещения следующего фрагмента, чтобы перекрывающиеся кадры не обрабатывались дважды.
- `background_video` заполняет кадры движения после части с эталонным движением; он не заменяет эталонное изображение или перенесённые кадры `continue_motion`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Модифицированное позитивное кондиционирование с дополнительным видеоконтекстом, включая выход CLIP vision, латентное представление видео с позой, пиксели видео с лицом, конкатенированное латентное изображение и конкатенированную маску. | CONDITIONING |
| `негативный` | Модифицированное негативное кондиционирование с дополнительным видеоконтекстом, включая выход CLIP vision, латентное представление видео с позой, пиксели пустого лица, конкатенированное латентное изображение и конкатенированную маску. | CONDITIONING |
| `латентный` | Начальный латентный тензор (все нулевые сэмплы) для генерируемого видео, имеющий форму `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `обрезка_латентного` | Количество латентных кадров для обрезки с начала латентного тензора, соответствующее кадрам эталонного изображения. | INT |
| `обрезка_изображения` | Количество кадров изображения для обрезки с начала, соответствующее кадрам эталонного движения. | INT |
| `смещение_кадров_видео` | Обновлённое смещение кадров для использования в следующем фрагменте, основанное на входном смещении и количестве обработанных кадров. | INT |
