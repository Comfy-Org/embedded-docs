# WanAnimateToVideo

Этот экспериментальный узел подготавливает генерацию видео Wan, объединяя референсное изображение с необязательными видео позы, лица и фона. Он формирует данные кондиционирования и пустой латентный тензор видео для последующей генерации, а также возвращает информацию о смещении кадров, которая помогает расширять существующие видео по частям.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное кондиционирование для направления генерации к желаемому содержимому. | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование для увода генерации от нежелательного содержимого. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования и декодирования данных изображений. | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров для генерации (по умолчанию: 77, шаг: 4). | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для генерации в одном батче (по умолчанию: 1). | INT | Да | 1 to 4096 |
| `clip_vision_output` | Необязательный выход модели CLIP Vision, используемый как дополнительное кондиционирование и для позитивного, и для негативного кондиционирования. | CLIP_VISION_OUTPUT | Нет | - |
| `reference_image` | Референсное изображение, используемое как отправная точка генерации. Если не задано, используется чёрное изображение (все нули). | IMAGE | Нет | - |
| `face_video` | Видео, задающее мимику. При обработке оно масштабируется до 512x512 и нормализуется в диапазон от -1.0 до 1.0. | IMAGE | Нет | - |
| `pose_video` | Видео, задающее позу и движение. Если оно короче, чем `length`, оно дополняется последним кадром. | IMAGE | Нет | - |
| `continue_motion_max_frames` | Максимальное количество кадров для продолжения из предыдущего движения. Из `continue_motion` используются только последние кадры в этом количестве (по умолчанию: 5, шаг: 4). | INT | Да | 1 to MAX_RESOLUTION |
| `background_video` | Фоновое видео для совмещения с генерируемым содержимым. | IMAGE | Нет | - |
| `character_mask` | Маска, определяющая области персонажа для выборочной обработки. Если маска содержит только один кадр, она повторяется для всех кадров. | MASK | Нет | - |
| `continue_motion` | Предыдущая последовательность движения, используемая для сохранения временно́й согласованности при расширении видео. Используются только последние `continue_motion_max_frames` кадров. | IMAGE | Нет | - |
| `video_frame_offset` | Число кадров, на которое нужно сместиться во всех входных видео. Используется для генерации более длинных видео по частям. Подключите к выходу `video_frame_offset` предыдущего узла для расширения видео. (по умолчанию: 0, шаг: 1) | INT | Да | 0 to MAX_RESOLUTION |

**Ограничения параметров:**

- Если указан `pose_video`, более короткое видео с позой дополняется последним кадром до соответствия `length`. В исходном коде есть флаг `trim_to_pose_video`, в настоящее время отключённый, который вместо этого сокращал бы выходные данные до длины видео с позой.
- `face_video` масштабируется до 512x512 и нормализуется в диапазон от -1.0 до 1.0.
- `continue_motion` ограничивается последними `continue_motion_max_frames` кадрами. При использовании `continue_motion` значение `video_frame_offset` уменьшается на количество взятых кадров, но никогда не опускается ниже 0.
- Входные видео (`face_video`, `pose_video`, `background_video`, `character_mask`) смещаются на величину `video_frame_offset`. Если смещение больше или равно их длине, входные данные игнорируются, за исключением однокадровой маски `character_mask`, которая всегда повторяется.
- Когда указан `clip_vision_output`, он применяется и к позитивному, и к негативному кондиционированию.
- Если `reference_image` не задан, в качестве референса используется чёрное изображение (все нули).
- Если `continue_motion` не задан, для части движения используются серые кадры со значением пикселя 0.5.
- `width` и `height` используют шаг 16; соответствующие латентные размеры равны `width / 8` и `height / 8`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное позитивное кондиционирование, которое всегда включает конкатенированное латентное изображение и конкатенированную маску. Если указаны `clip_vision_output`, `pose_video` или `face_video`, их значения также добавляются. | CONDITIONING |
| `negative` | Модифицированное негативное кондиционирование, которое всегда включает конкатенированное латентное изображение и конкатенированную маску. Если указаны `clip_vision_output`, `pose_video` или `face_video`, их значения также добавляются; пиксели видео с лицом устанавливаются в -1.0. | CONDITIONING |
| `latent` | Пустой латентный тензор, инициализированный нулями, с формой `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`. | LATENT |
| `trim_latent` | Количество латентных кадров для обрезки с начала, соответствующее латентным кадрам референсного изображения. | INT |
| `trim_image` | Количество кадров изображения для обрезки с начала, соответствующее референсным кадрам движения. | INT |
| `video_frame_offset` | Обновлённое смещение кадров для генерации видео по частям, равное скорректированному входному смещению плюс длина сгенерированного видео. | INT |
