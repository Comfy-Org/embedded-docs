# Преобразование цвета в RGB Int

Узел **ColorToRGBInt** преобразует цвет, заданный в шестнадцатеричном формате (например, `#FF5733`), в одно целочисленное значение RGB. Он извлекает красную, зеленую и синюю компоненты из строки цвета, объединяет их в одно целое число, а также возвращает исходное шестнадцатеричное представление и значение альфа-канала (непрозрачности).

## Входы

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `цвет` | Значение цвета в шестнадцатеричном формате `#RRGGBB` или `#RRGGBBAA`. Должно содержать 7 или 9 символов и начинаться с `#`. | COLOR | Да | `#RRGGBB`<br>`#RRGGBBAA` |

**Примечание:** Входная строка `color` должна соответствовать формату `#RRGGBB` или `#RRGGBBAA`. Если её длина не равна 7 или 9 символам, она не начинается с `#` или содержит недопустимые шестнадцатеричные символы, узел вызывает ошибку.

## Выходы

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `rgb_int` | Вычисленное целочисленное значение RGB, полученное по формуле: `(Red * 65536) + (Green * 256) + Blue`. | INT |
| `hex` | Шестнадцатеричная строка цвета в формате `#RRGGBB`. Если во входных данных был альфа-канал, он удаляется из этого вывода. | COLOR |
| `alpha` | Значение альфа-канала (непрозрачности) от 0.0 до 1.0. Равно 1.0, когда входное значение имеет формат `#RRGGBB`, или значению альфа-канала, делённому на 255, когда входное значение имеет формат `#RRGGBBAA`. | FLOAT |
