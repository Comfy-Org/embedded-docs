# Преобразование цвета в RGB Int

Узел **ColorToRGBInt** преобразует цвет, заданный в шестнадцатеричном формате (например, `#FF5733`), в одно целочисленное значение RGB. Он извлекает красную, зелёную и синюю составляющие из строки цвета и объединяет их в одно целое число, а также возвращает шестнадцатеричное представление. Цвета с альфа-каналом (`#RRGGBBAA`) также поддерживаются, при этом значение альфа-канала возвращается отдельно.

## Входные параметры

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `color` | Цвет в шестнадцатеричном формате `#RRGGBB` или `#RRGGBBAA`. Длина строки должна быть ровно 7 или 9 символов, и она должна начинаться с `#`. | COLOR | Да | `#RRGGBB`<br>`#RRGGBBAA` |

**Примечание:** Входная строка `color` должна точно соответствовать формату `#RRGGBB` или `#RRGGBBAA`. Если длина строки не составляет 7 или 9 символов, она не начинается с `#` или содержит символы, не являющиеся допустимыми шестнадцатеричными цифрами, узел вызывает ошибку.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `rgb_int` | Вычисленное целочисленное значение RGB по формуле: `(Red * 65536) + (Green * 256) + Blue`. | INT |
| `hex` | Шестнадцатеричная строка цвета в формате `#RRGGBB`. Если входное значение содержит альфа-канал, он удаляется из этого выходного значения. | COLOR |
| `alpha` | Значение альфа-канала (непрозрачности) в виде числа от 0.0 до 1.0. Для входных цветов с альфа-каналом (`#RRGGBBAA`) это двухзначное значение альфа, делённое на 255. Для цветов без альфа-канала — 1.0. | FLOAT |
