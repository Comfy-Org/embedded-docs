# カラーをRGB整数に変換

**ColorToRGBInt** ノードは、16進形式（`#FF5733` など）で指定された色を単一のRGB整数値に変換します。色文字列から赤、緑、青の各成分を取得し、それらを1つの整数に結合して、16進表現を返します。アルファチャンネル（`#RRGGBBAA`）を持つ色もサポートされており、アルファ値は別途返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `color` | 16進形式 `#RRGGBB` または `#RRGGBBAA` の色値。正確に7文字または9文字の長さで、`#` で始まる必要があります。 | COLOR | はい | `#RRGGBB`<br>`#RRGGBBAA` |

**注記:** 入力 `color` 文字列は、形式 `#RRGGBB` または `#RRGGBBAA` に正確に従う必要があります。文字列が7文字または9文字の長さでない場合、`#` で始まらない場合、または有効な16進数字でない文字を含む場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `rgb_int` | 式 `(Red * 65536) + (Green * 256) + Blue` から導出されたRGB整数値。 | INT |
| `hex` | `#RRGGBB` 形式の16進色文字列。入力にアルファチャンネルが含まれる場合、この出力からは除外されます。 | COLOR |
| `alpha` | 0.0 から 1.0 の数値としてのアルファ（不透明度）値。アルファチャンネル（`#RRGGBBAA`）を持つ入力色の場合、2桁のアルファ値を 255 で割った値です。アルファチャンネルのない色の場合は 1.0 です。 | FLOAT |
