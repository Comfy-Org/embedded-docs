# 색상을 RGB 정수로 변환

**ColorToRGBInt** 노드는 16진수 형식(예: `#FF5733`)으로 지정된 색상을 단일 RGB 정수 값으로 변환합니다. 색상 문자열에서 빨간색, 녹색, 파란색 구성 요소를 추출하여 하나의 정수로 결합하고, 16진수 표현을 반환합니다. 알파 채널(`#RRGGBBAA`)이 포함된 색상도 지원되며, 알파 값은 별도로 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `color` | `#RRGGBB` 또는 `#RRGGBBAA` 형식의 색상 값입니다. 정확히 7자 또는 9자여야 하며 `#`로 시작해야 합니다. | COLOR | 예 | `#RRGGBB`<br>`#RRGGBBAA` |

**참고:** 입력 `color` 문자열은 `#RRGGBB` 또는 `#RRGGBBAA` 형식을 정확히 따라야 합니다. 문자열이 7자 또는 9자가 아니거나, `#`로 시작하지 않거나, 유효한 16진수 숫자가 아닌 문자가 포함된 경우 노드는 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `rgb_int` | 공식 `(Red * 65536) + (Green * 256) + Blue`에서 파생된 계산된 RGB 정수 값입니다. | INT |
| `hex` | `#RRGGBB` 형식의 16진수 색상 문자열입니다. 입력에 알파 채널이 포함된 경우 이 출력에서는 알파 채널이 제거됩니다. | COLOR |
| `alpha` | 0.0에서 1.0 사이의 숫자로 표현되는 알파(불투명도) 값입니다. 알파 채널(`#RRGGBBAA`)이 있는 입력 색상의 경우 두 자리 알파 값을 255로 나눈 값입니다. 알파 채널이 없는 색상의 경우 1.0입니다. | FLOAT |
