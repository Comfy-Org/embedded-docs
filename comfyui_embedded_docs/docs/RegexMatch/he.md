# RegexMatch

הצומת RegexMatch בודק אם מחרוזת טקסט מכילה התאמה לתבנית ביטוי רגולרי נתונה. הוא מחפש במחרוזת הקלט ומחזיר תוצאה פשוטה של כן/לא שמציינת אם התבנית נמצאה במקום כלשהו בטקסט. ניתן להתאים את אופן החיפוש באמצעות הפעלת אפשרויות כמו התאמה ללא תלות ברישיות או מצב מרובה שורות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת הטקסט שבה יש לחפש התאמות | STRING | כן | - |
| `regex_pattern` | תבנית הביטוי הרגולרי שיש להתאים מול המחרוזת | STRING | כן | - |
| `case_insensitive` | האם להתעלם מרישיות בעת ההתאמה (ברירת מחדל: True) | BOOLEAN | לא | - |
| `multiline` | האם להפעיל מצב מרובה שורות להתאמת ביטוי רגולרי (ברירת מחדל: False) | BOOLEAN | לא | - |
| `dotall` | האם להפעיל מצב dotall להתאמת ביטוי רגולרי (ברירת מחדל: False) | BOOLEAN | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `matches` | מחזיר True אם תבנית הביטוי הרגולרי מתאימה לחלק כלשהו ממחרוזת הקלט, אחרת False | BOOLEAN |
