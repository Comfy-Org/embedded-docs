# GITS 스케줄러

GITSScheduler 노드는 GITS 샘플링 방법에서 사용되는 시그마(노이즈 레벨) 스케줄을 생성합니다. `coeff` 매개변수와 `steps` 수를 기반으로 미리 정의된 노이즈 레벨 테이블을 선택하며, `denoise` 값이 1.0 미만인 경우 스케줄을 선택적으로 줄입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `coeff` | 스케줄을 구성하는 데 사용할 미리 정의된 노이즈 레벨 테이블을 선택하는 계수입니다. 값은 소수점 둘째 자리로 반올림됩니다(기본값: 1.20) | FLOAT | 예 | 0.80 - 1.50 |
| `steps` | 시그마를 생성할 총 샘플링 단계 수입니다(기본값: 10) | INT | 예 | 2 - 1000 |
| `denoise` | 사용되는 단계 수를 줄이는 디노이징 요소입니다(기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |

**참고:** `denoise`가 0.0으로 설정되면 노드는 빈 텐서를 반환합니다. `denoise`가 1.0보다 작으면 실제 사용되는 단계 수는 `round(steps * denoise)`로 계산됩니다. 단계 수가 20 이하인 경우 노드는 미리 정의된 노이즈 레벨을 직접 사용하고, 단계 수가 20보다 큰 경우 로그-선형 보간을 사용하여 미리 정의된 노이즈 레벨을 원하는 단계 수로 확장합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `sigmas` | 노이즈 스케줄에 대해 생성된 시그마 값입니다. | SIGMAS |
