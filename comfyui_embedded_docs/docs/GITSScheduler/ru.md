# GITSScheduler

Узел GITSScheduler генерирует график сигм (уровень шума), используемый методом выборки GITS. Он выбирает предопределённую таблицу уровней шума на основе параметра `coeff` и количества `steps`, при необходимости сокращая график, когда используется значение `denoise` ниже 1.0.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `coeff` | Коэффициент, который выбирает, какая предопределённая таблица уровней шума используется для построения графика. Значение округляется до 2 знаков после запятой (по умолчанию: 1.20) | FLOAT | Да | 0.80 - 1.50 |
| `steps` | Общее количество шагов выборки, для которых генерируются сигмы (по умолчанию: 10) | INT | Да | 2 - 1000 |
| `denoise` | Коэффициент шумоподавления, уменьшающий количество используемых шагов (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

**Примечание:** Когда `denoise` установлен в 0.0, узел возвращает пустой тензор. Когда `denoise` меньше 1.0, фактическое количество используемых шагов вычисляется как `round(steps * denoise)`. Для шагов до 20 узел использует предопределённые уровни шума напрямую; для шагов более 20 используется логарифмически-линейная интерполяция для расширения предопределённых уровней шума до желаемого количества шагов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `sigmas` | Сгенерированные значения сигм для графика шума | SIGMAS |
