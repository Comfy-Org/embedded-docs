# GITSScheduler

Узел GITSScheduler генерирует сигмы графика шума для метода сэмплирования GITS (Generative Iterative Time Steps). Он вычисляет значения сигм на основе коэффициента и количества шагов, с необязательным фактором денойзинга, который может уменьшить общее количество используемых шагов. Узел использует предопределённые уровни шума и интерполяцию для создания итогового графика сигм.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `коэфф` | Значение коэффициента, управляющее кривой графика шума (по умолчанию: 1.20). Значение округляется до двух знаков после запятой и определяет, какая предопределённая таблица уровней шума будет использована. | FLOAT | Да | 0.80 - 1.50 (шаг 0.05) |
| `шаги` | Общее количество шагов сэмплирования, для которых генерируются сигмы (по умолчанию: 10) | INT | Да | 2 - 1000 |
| `шумоподавление` | Фактор денойзинга, уменьшающий количество используемых шагов (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

**Примечание:** Если `denoise` равен 0.0 или меньше, узел возвращает пустой тензор. Когда `denoise` меньше 1.0, фактическое количество используемых шагов вычисляется как `round(steps * denoise)`, и сохраняется только соответствующая конечная часть графика. Для количества шагов от 2 до 20 узел выбирает подходящий предопределённый график шума. Для шагов больше 20 узел использует лог-линейную интерполяцию для расширения предопределённых уровней шума до требуемого количества шагов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `sigmas` | Сгенерированные значения сигм для графика шума. Для N шагов возвращается N+1 значений сигм, при этом последняя сигма устанавливается в 0. | SIGMAS |
