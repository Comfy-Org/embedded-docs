# GITSScheduler

Узел GITSScheduler генерирует сигмы расписания шума для метода сэмплирования GITS (Generative Iterative Time Steps). Он вычисляет значения сигм на основе параметра коэффициента и количества шагов, с коэффициентом удаления шума, который может уменьшать общее количество используемых шагов. Узел использует предопределённые уровни шума и интерполяцию для создания итогового расписания сигм.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `коэфф` | Расширенный параметр. Значение коэффициента, управляющее кривой расписания шума (по умолчанию: 1.20). Значение округляется до двух знаков после запятой и определяет, какая предопределённая таблица уровней шума используется. | FLOAT | Да | 0.80 - 1.50 (шаг 0.05) |
| `шаги` | Общее количество шагов сэмплирования, для которых генерируются сигмы (по умолчанию: 10). | INT | Да | 2 - 1000 |
| `шумоподавление` | Коэффициент удаления шума, уменьшающий количество используемых шагов (по умолчанию: 1.0). | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |

**Примечание:** Если `denoise` равен 0.0 или меньше, узел возвращает пустой тензор. Если `denoise` меньше 1.0, фактическое количество используемых шагов вычисляется как `round(steps * denoise)`, и сохраняется только последняя соответствующая часть расписания. Для количества шагов от 2 до 20 узел выбирает подходящее предопределённое расписание шума. Для количества шагов больше 20 узел использует лог-линейную интерполяцию, чтобы расширить предопределённые уровни шума до нужного количества шагов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `sigmas` | Сгенерированные значения сигм для расписания шума. Для N шагов сэмплирования возвращается N+1 значений сигм, при этом последняя сигма устанавливается в 0. | SIGMAS |
