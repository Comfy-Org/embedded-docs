# GITSスケジューラー

GITSScheduler ノードは、GITS サンプリング手法で使用されるシグマ（ノイズレベル）スケジュールを生成します。`coeff` パラメータと `steps` の数に基づいて事前定義されたノイズレベルテーブルを選択し、`denoise` 値が 1.0 未満の場合にはスケジュールを任意でトリミングします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `coeff` | スケジュールの構築に使用する事前定義ノイズレベルテーブルを選択する係数です。値は小数点以下2桁に丸められます（デフォルト: 1.20） | FLOAT | Yes | 0.80 - 1.50 |
| `steps` | シグマを生成するためのサンプリングステップの総数です（デフォルト: 10） | INT | Yes | 2 - 1000 |
| `denoise` | 使用するステップ数を減らすノイズ除去係数です（デフォルト: 1.0） | FLOAT | Yes | 0.0 - 1.0 |

**注記:** `denoise` が 0.0 に設定されている場合、ノードは空のテンソルを返します。`denoise` が 1.0 未満の場合、実際に使用されるステップ数は `round(steps * denoise)` として計算されます。ステップ数が20までの場合は、ノードは事前定義されたノイズレベルをそのまま使用します。ステップ数が20を超える場合は、対数線形補間を使用して、事前定義されたノイズレベルを目的のステップ数に拡張します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `sigmas` | ノイズスケジュール用に生成されたシグマ値です。 | SIGMAS |
