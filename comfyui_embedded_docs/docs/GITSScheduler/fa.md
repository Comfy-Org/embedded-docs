# برنامه‌ریز GITS

گره GITSScheduler برنامه‌ی سیگما (سطح نویز) مورد استفاده در روش نمونه‌برداری GITS را تولید می‌کند. این گره بر اساس پارامتر `coeff` و تعداد `steps`، یک جدول سطح نویز از پیش تعریف‌شده را انتخاب می‌کند و در صورت استفاده از مقدار `denoise` کمتر از 1.0، برنامه را به صورت اختیاری کوتاه می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `coeff` | ضریبی که مشخص می‌کند کدام جدول سطح نویز از پیش تعریف‌شده برای ساخت برنامه استفاده شود. مقدار به 2 رقم اعشار گرد می‌شود (پیش‌فرض: 1.20) | FLOAT | بله | 0.80 - 1.50 |
| `steps` | تعداد کل مراحل نمونه‌برداری برای تولید سیگماها (پیش‌فرض: 10) | INT | بله | 2 - 1000 |
| `denoise` | ضریب نویززدایی که تعداد مراحل استفاده‌شده را کاهش می‌دهد (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |

**توجه:** وقتی `denoise` برابر 0.0 باشد، گره یک تنسور خالی برمی‌گرداند. وقتی `denoise` کمتر از 1.0 باشد، تعداد واقعی مراحل استفاده‌شده به صورت `round(steps * denoise)` محاسبه می‌شود. برای مراحل تا 20، گره مستقیماً از سطوح نویز از پیش تعریف‌شده استفاده می‌کند؛ برای مراحل بیشتر از 20، از درون‌یابی لگاریتمی-خطی برای گسترش سطوح نویز از پیش تعریف‌شده تا تعداد مراحل مورد نظر استفاده می‌کند.
