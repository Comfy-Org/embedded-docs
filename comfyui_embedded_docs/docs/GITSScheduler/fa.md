# برنامه‌ریز GITS

گره GITSScheduler سیگماهای زمان‌بندی نویز را برای روش نمونه‌گیری GITS (Generative Iterative Time Steps) تولید می‌کند. این گره مقادیر سیگما را بر اساس پارامتر `coeff` و تعداد گام‌ها محاسبه می‌کند، همراه با یک ضریب نویززدایی که می‌تواند تعداد کل گام‌های استفاده‌شده را کاهش دهد. این گره از سطوح نویز از پیش تعریف‌شده و درون‌یابی برای ساخت زمان‌بندی نهایی سیگما استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ضریب` | پارامتر پیشرفته. مقدار ضریب که منحنی زمان‌بندی نویز را کنترل می‌کند (پیش‌فرض: 1.20). مقدار به دو رقم اعشار گرد می‌شود و تعیین می‌کند کدام جدول سطوح نویز از پیش تعریف‌شده استفاده شود. | FLOAT | بله | 0.80 - 1.50 (گام 0.05) |
| `گام‌ها` | تعداد کل گام‌های نمونه‌گیری برای تولید سیگماها (پیش‌فرض: 10). | INT | بله | 2 - 1000 |
| `کاهش نویز` | ضریب نویززدایی که تعداد گام‌های استفاده‌شده را کاهش می‌دهد (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 - 1.0 (گام 0.01) |

**توجه:** وقتی `denoise` برابر 0.0 یا کمتر باشد، گره یک تانسور خالی برمی‌گرداند. وقتی `denoise` کمتر از 1.0 باشد، تعداد واقعی گام‌های استفاده‌شده به‌صورت `round(steps * denoise)` محاسبه می‌شود و فقط بخش انتهایی متناظر از زمان‌بندی نگه داشته می‌شود. برای گام‌های بین 2 و 20، گره یک زمان‌بندی نویز از پیش تعریف‌شده متناظر را انتخاب می‌کند. برای گام‌های بزرگ‌تر از 20، گره از درون‌یابی لگاریتمی-خطی برای گسترش سطوح نویز از پیش تعریف‌شده به تعداد گام‌های دلخواه استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `sigmas` | مقادیر سیگمای تولیدشده برای زمان‌بندی نویز. برای N گام نمونه‌گیری، N+1 مقدار سیگما برگردانده می‌شود و آخرین سیگما برابر 0 تنظیم می‌شود. | SIGMAS |
