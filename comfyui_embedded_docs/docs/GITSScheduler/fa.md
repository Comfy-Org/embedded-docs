# برنامه‌ریز GITS

گره GITSScheduler سیگماهای زمان‌بندی نویز را برای روش نمونه‌برداری GITS (مراحل زمانی تکراری مولد) تولید می‌کند. این گره مقادیر سیگما را بر اساس پارامتر ضریب و تعداد گام‌ها محاسبه می‌کند و یک ضریب نویززدایی اختیاری دارد که می‌تواند تعداد کل گام‌های استفاده‌شده را کاهش دهد. این گره از سطوح نویز از پیش تعریف‌شده و درونیابی برای ایجاد زمان‌بندی نهایی سیگما استفاده می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ضریب` | مقدار ضریبی که منحنی زمان‌بندی نویز را کنترل می‌کند (پیش‌فرض: 1.20). این مقدار به دو رقم اعشار گرد می‌شود و تعیین می‌کند کدام جدول سطوح نویز از پیش تعریف‌شده استفاده شود. | FLOAT | بله | 0.80 - 1.50 (step 0.05) |
| `گام‌ها` | تعداد کل گام‌های نمونه‌برداری که سیگماها برای آن‌ها تولید می‌شوند (پیش‌فرض: 10) | INT | بله | 2 - 1000 |
| `کاهش نویز` | ضریب نویززدایی که تعداد گام‌های استفاده‌شده را کاهش می‌دهد (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |

**توجه:** وقتی `denoise` صفر یا کمتر باشد، گره یک تنسور خالی برمی‌گرداند. وقتی `denoise` کمتر از 1.0 باشد، تعداد واقعی گام‌های استفاده‌شده به صورت `round(steps * denoise)` محاسبه می‌شود و فقط بخش پایانی متناظر از زمان‌بندی حفظ می‌شود. برای گام‌های بین 2 تا 20، گره یک زمان‌بندی نویز از پیش تعریف‌شده منطبق را انتخاب می‌کند. برای گام‌های بزرگ‌تر از 20، گره از درونیابی لگاریتمی-خطی برای گسترش سطوح نویز از پیش تعریف‌شده به تعداد گام‌های موردنظر استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `sigmas` | مقادیر سیگمای تولیدشده برای زمان‌بندی نویز. برای N گام، N+1 مقدار سیگما برگردانده می‌شود و آخرین سیگما برابر 0 قرار می‌گیرد. | SIGMAS |
