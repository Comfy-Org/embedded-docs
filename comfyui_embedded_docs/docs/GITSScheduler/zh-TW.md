# GITSScheduler

GITSScheduler 節點會為 GITS（Generative Iterative Time Steps）取樣方法產生雜訊排程 sigmas。它會根據係數參數與步驟數計算 sigma 值，並可透過降噪因子減少使用的總步驟數。此節點使用預定義的雜訊等級與插值來建立最終的 sigma 排程。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `coeff` | 進階參數。控制雜訊排程曲線的係數值（預設：1.20）。此值會四捨五入至小數點後兩位，並用來選擇要使用哪個預定義雜訊等級表。 | FLOAT | 是 | 0.80 - 1.50 （步進值：0.05） |
| `步驟數` | 要為其產生 sigmas 的取樣步驟總數（預設：10）。 | INT | 是 | 2 - 1000 |
| `去雜訊強度` | 降噪因子，可減少使用的步驟數（預設：1.0）。 | FLOAT | 是 | 0.0 - 1.0 （步進值：0.01） |

**注意：** 當 `denoise` 為 0.0 或更低時，節點會傳回空張量。當 `denoise` 小於 1.0 時，實際使用的步驟數會以 `round(steps * denoise)` 計算，且僅保留排程中最後對應的部分。對於 2 到 20 之間的步驟，節點會選取相符的預定義雜訊排程。對於大於 20 的步驟，節點會使用對數線性插值，將預定義雜訊等級延伸至所需的步驟數。
