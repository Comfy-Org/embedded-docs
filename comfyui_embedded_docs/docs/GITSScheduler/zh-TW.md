# GITSScheduler

GITSScheduler 節點為 GITS（生成式迭代時間步）採樣方法生成噪聲調度 sigma 值。它根據係數參數和步數計算 sigma 值，並可選擇使用去噪因子來減少所使用的總步數。該節點使用預定義的噪聲級別和插值來建立最終的 sigma 調度。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `coeff` | 控制噪聲調度曲線的係數值（預設值：1.20）。此值四捨五入到小數點後兩位，並選擇所使用的預定義噪聲級別表。 | FLOAT | 是 | 0.80 - 1.50（步長 0.05） |
| `步驟數` | 要為其生成 sigma 值的採樣步驟總數（預設值：10） | INT | 是 | 2 - 1000 |
| `去雜訊強度` | 用於減少所使用步驟數的去噪因子（預設值：1.0） | FLOAT | 是 | 0.0 - 1.0 |

**注意：** 當 `denoise` 為 0.0 或更小時，節點會回傳空張量。當 `denoise` 小於 1.0 時，實際使用的步驟數計算為 `round(steps * denoise)`，且僅保留調度中對應的最後部分。對於 2 到 20 之間的步數，節點會選擇相符的預定義噪聲調度。對於大於 20 的步數，節點使用對數線性插值將預定義噪聲級別擴展到所需的步數。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `sigmas` | 為噪聲調度生成的 sigma 值。對於 N 個步驟，會回傳 N+1 個 sigma 值，且最後一個 sigma 設為 0。 | SIGMAS |
