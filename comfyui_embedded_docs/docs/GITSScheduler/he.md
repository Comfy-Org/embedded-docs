# GITSScheduler

צומת GITSScheduler מייצר סיגמות של לוח זמני רעש עבור שיטת הדגימה GITS (Generative Iterative Time Steps). הוא מחשב ערכי סיגמה על בסיס פרמטר מקדם ומספר צעדים, עם מקדם הסרת רעש שיכול להפחית את מספר הצעדים הכולל שבהם נעשה שימוש. הצומת משתמש ברמות רעש מוגדרות מראש ובאינטרפולציה כדי ליצור את לוח הזמנים הסופי של הסיגמות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `coeff` | פרמטר מתקדם. ערך המקדם ששולט בעקומת לוח זמני הרעש (ברירת מחדל: 1.20). הערך מעוגל לשתי ספרות עשרוניות וקובע באיזו טבלת רמות רעש מוגדרת מראש נעשה שימוש. | FLOAT | כן | 0.80 - 1.50 (step 0.05) |
| `steps` | המספר הכולל של צעדי דגימה שעבורם ייווצרו סיגמות (ברירת מחדל: 10). | INT | כן | 2 - 1000 |
| `denoise` | מקדם הסרת רעש שמפחית את מספר הצעדים שבהם נעשה שימוש (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 - 1.0 (step 0.01) |

**הערה:** כאשר `denoise` הוא 0.0 או פחות, הצומת מחזיר טנסור ריק. כאשר `denoise` קטן מ-1.0, מספר הצעדים בפועל שבהם נעשה שימוש מחושב כ-`round(steps * denoise)`, ורק החלק המתאים האחרון של לוח הזמנים נשמר. עבור מספר צעדים שבין 2 ל-20, הצומת בוחר לוח זמני רעש מוגדר מראש תואם. עבור מספר צעדים גדול מ-20, הצומת משתמש באינטרפולציה לוג-לינארית כדי להרחיב את רמות הרעש המוגדרות מראש למספר הצעדים הרצוי.
