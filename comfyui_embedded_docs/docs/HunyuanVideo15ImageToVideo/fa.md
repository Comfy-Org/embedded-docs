# HunyuanVideo15ImageToVideo

گره HunyuanVideo15ImageToVideo داده‌های شرطی‌سازی و فضای نهان را برای تولید ویدیو بر اساس مدل HunyuanVideo 1.5 آماده می‌کند. این گره یک نمایش نهان اولیه برای دنباله ویدیو ایجاد می‌کند و به‌صورت اختیاری می‌تواند یک تصویر شروع یا خروجی CLIP vision را برای هدایت فرآیند تولید یکپارچه کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی مثبت که توصیف می‌کنند ویدیو باید شامل چه چیزهایی باشد. | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرطی منفی که توصیف می‌کنند ویدیو باید از چه چیزهایی اجتناب کند. | CONDITIONING | بله | - |
| `vae` | مدل VAE (خودرمزنگار تغییری‌پذیر) که برای رمزگذاری تصویر شروع به فضای نهان استفاده می‌شود. | VAE | بله | - |
| `عرض` | عرض فریم‌های ویدیوی خروجی به پیکسل. باید بر 16 بخش‌پذیر باشد. (پیش‌فرض: 848) | INT | بله | 16 to MAX_RESOLUTION, step: 16 |
| `ارتفاع` | ارتفاع فریم‌های ویدیوی خروجی به پیکسل. باید بر 16 بخش‌پذیر باشد. (پیش‌فرض: 480) | INT | بله | 16 to MAX_RESOLUTION, step: 16 |
| `طول` | تعداد کل فریم‌ها در دنباله ویدیو. مقادیر با گام‌های 4 از 1 افزایش می‌یابند (1، 5، 9، 13، ...). (پیش‌فرض: 33) | INT | بله | 1 to MAX_RESOLUTION, step: 4 |
| `اندازه دسته` | تعداد دنباله‌های ویدیویی که در یک دسته تولید می‌شوند. (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `تصویر شروع` | یک تصویر شروع اختیاری برای مقداردهی اولیه تولید ویدیو. اگر ارائه شود، رمزگذاری شده و برای شرطی‌سازی فریم‌های اول استفاده می‌شود. تنها `length` فریم اول از تصویر استفاده می‌شود. | IMAGE | خیر | - |
| `خروجی clip vision` | تعبیه‌های CLIP vision اختیاری برای ارائه شرطی‌سازی بصری اضافی برای تولید. | CLIP_VISION_OUTPUT | خیر | - |

**توجه:** وقتی `start_image` ارائه می‌شود، به‌طور خودکار با درون‌یابی دوخطی به `width` و `height` مشخص‌شده تغییر اندازه می‌دهد. اولین `length` فریم از دسته تصویر استفاده می‌شود و تنها 3 کانال رنگی اول هر فریم رمزگذاری می‌شوند. سپس تصویر رمزگذاری‌شده به‌عنوان `concat_latent_image` همراه با `concat_mask` متناظر به هر دو شرطی‌سازی `positive` و `negative` اضافه می‌شود. ماسک برای فریم‌های پوشش‌داده‌شده توسط تصویر شروع 0.0 و برای فریم‌های باقی‌مانده 1.0 تنظیم می‌شود. وقتی `clip_vision_output` ارائه می‌شود، آن نیز به هر دو شرطی‌سازی `positive` و `negative` اضافه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده، که اکنون ممکن است شامل تصویر شروع رمزگذاری‌شده یا خروجی CLIP vision باشد. | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده، که اکنون ممکن است شامل تصویر شروع رمزگذاری‌شده یا خروجی CLIP vision باشد. | CONDITIONING |
| `latent` | یک تنسور نهان خالی با ابعاد پیکربندی‌شده برای اندازه دسته، طول ویدیو، عرض و ارتفاع مشخص‌شده. | LATENT |
