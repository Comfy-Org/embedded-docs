# HunyuanVideo15ImageToVideo

گره `HunyuanVideo15ImageToVideo` داده‌های شرطی‌سازی و فضای نهان را برای تولید ویدیو بر اساس مدل HunyuanVideo 1.5 آماده می‌کند. این گره یک نمایش نهان اولیه برای یک دنباله ویدیویی ایجاد می‌کند و به‌صورت اختیاری می‌تواند یک تصویر شروع یا خروجی CLIP vision را برای هدایت فرآیند تولید ادغام کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت که مشخص می‌کنند ویدیو باید چه چیزهایی را شامل شود. | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی‌سازی منفی که مشخص می‌کنند ویدیو باید از چه چیزهایی اجتناب کند. | CONDITIONING | بله | - |
| `vae` | مدل VAE (خودرمزنگار تغییراتی) که برای رمزگذاری تصویر شروع به فضای نهان استفاده می‌شود. | VAE | بله | - |
| `width` | عرض فریم‌های ویدیوی خروجی به پیکسل. باید بر ۱۶ بخش‌پذیر باشد. (پیش‌فرض: 848) | INT | بله | 16 to MAX_RESOLUTION, step: 16 |
| `height` | ارتفاع فریم‌های ویدیوی خروجی به پیکسل. باید بر ۱۶ بخش‌پذیر باشد. (پیش‌فرض: 480) | INT | بله | 16 to MAX_RESOLUTION, step: 16 |
| `length` | تعداد کل فریم‌ها در دنباله ویدیویی. این مقدار به گام‌های ۴ افزایش می‌یابد. (پیش‌فرض: 33) | INT | بله | 1 to MAX_RESOLUTION, step: 4 |
| `batch_size` | تعداد دنباله‌های ویدیویی که در یک دسته تولید می‌شوند. (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `start_image` | یک تصویر شروع اختیاری برای مقداردهی اولیه تولید ویدیو. اگر ارائه شود، رمزگذاری شده و برای شرطی‌سازی فریم‌های اول استفاده می‌شود. فقط اولین `length` فریم از تصویر استفاده می‌شود. | IMAGE | خیر | - |
| `clip_vision_output` | جاسازی‌های بینایی CLIP اختیاری برای فراهم کردن شرطی‌سازی بصری اضافی برای تولید. | CLIP_VISION_OUTPUT | خیر | - |

**نکته:** هنگامی که `start_image` ارائه می‌شود، به‌طور خودکار با استفاده از درون‌یابی دوخطی (bilinear interpolation) به ابعاد مشخص‌شده `width` و `height` تغییر اندازه می‌دهد و فقط کانال‌های RGB آن استفاده می‌شوند. اولین `length` فریم از دسته تصویر استفاده می‌شود. سپس تصویر رمزگذاری‌شده به هر دو شرطی‌سازی `positive` و `negative` به‌عنوان `concat_latent_image` با یک `concat_mask` متناظر اضافه می‌شود. مقدار ماسک برای فریم‌هایی که توسط تصویر شروع پوشش داده شده‌اند 0.0 و برای فریم‌های باقی‌مانده 1.0 است. هنگامی که `clip_vision_output` ارائه شود، آن نیز به هر دو شرطی‌سازی `positive` و `negative` اضافه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده، که ممکن است اکنون شامل تصویر شروع رمزگذاری‌شده یا خروجی CLIP vision باشد. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده، که ممکن است اکنون شامل تصویر شروع رمزگذاری‌شده یا خروجی CLIP vision باشد. | CONDITIONING |
| `latent` | یک تانسور نهان خالی با ابعادی که برای اندازه دسته، طول ویدیو، عرض و ارتفاع مشخص‌شده پیکربندی شده است. | LATENT |
