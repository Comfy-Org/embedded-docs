# HunyuanVideo15ImageToVideo

Узел HunyuanVideo15ImageToVideo подготавливает данные кондиционирования и скрытого пространства для генерации видео на основе модели HunyuanVideo 1.5. Он создаёт начальное скрытое представление видеопоследовательности и может дополнительно интегрировать стартовое изображение или выход CLIP vision для управления процессом генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивные промпты кондиционирования, описывающие, что должно содержать видео. | CONDITIONING | Да | - |
| `negative` | Негативные промпты кондиционирования, описывающие, чего видео должно избегать. | CONDITIONING | Да | - |
| `vae` | Модель VAE (вариационного автокодировщика), используемая для кодирования стартового изображения в скрытое пространство. | VAE | Да | - |
| `width` | Ширина кадров выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 848) | INT | Да | 16 to MAX_RESOLUTION, step: 16 |
| `height` | Высота кадров выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 480) | INT | Да | 16 to MAX_RESOLUTION, step: 16 |
| `length` | Общее количество кадров в видеопоследовательности. Значения увеличиваются с шагом 4, начиная с 1 (1, 5, 9, 13, ...). (по умолчанию: 33) | INT | Да | 1 to MAX_RESOLUTION, step: 4 |
| `batch_size` | Количество видеопоследовательностей, генерируемых за один пакет. (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `start_image` | Необязательное стартовое изображение для инициализации генерации видео. Если задано, оно кодируется и используется для кондиционирования первых кадров. Используются только первые `length` кадров изображения. | IMAGE | Нет | - |
| `clip_vision_output` | Необязательные эмбеддинги CLIP vision для дополнительного визуального кондиционирования генерации. | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Когда указано `start_image`, оно автоматически масштабируется в соответствии с заданными `width` и `height` с помощью билинейной интерполяции. Используются первые `length` кадров пакета изображений, и кодируются только первые 3 цветовых канала каждого кадра. Закодированное изображение затем добавляется и к `positive`, и к `negative` кондиционированию как `concat_latent_image` с соответствующей маской `concat_mask`. Маска устанавливается в 0.0 для кадров, охваченных стартовым изображением, и в 1.0 для остальных кадров. Когда указан `clip_vision_output`, он также добавляется и к `positive`, и к `negative` кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённое позитивное кондиционирование, которое теперь может включать закодированное стартовое изображение или выход CLIP vision. | CONDITIONING |
| `negative` | Изменённое негативное кондиционирование, которое теперь может включать закодированное стартовое изображение или выход CLIP vision. | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, настроенными под указанные размер пакета, длину видео, ширину и высоту. | LATENT |
