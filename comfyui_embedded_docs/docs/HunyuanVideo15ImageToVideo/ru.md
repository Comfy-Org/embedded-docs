# HunyuanVideo15ImageToVideo

Узел `HunyuanVideo15ImageToVideo` подготавливает данные кондиционирования и латентного пространства для генерации видео на основе модели HunyuanVideo 1.5. Он создает начальное латентное представление для видеопоследовательности и может опционально интегрировать стартовое изображение или выход CLIP vision для направления процесса генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные промпты кондиционирования, описывающие, что должно содержаться в видео. | CONDITIONING | Да | - |
| `negative` | Отрицательные промпты кондиционирования, описывающие, чего видео должно избегать. | CONDITIONING | Да | - |
| `vae` | Модель VAE (вариационный автоэнкодер), используемая для кодирования стартового изображения в латентное пространство. | VAE | Да | - |
| `width` | Ширина кадров выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 848) | INT | Да | 16 to MAX_RESOLUTION, step: 16 |
| `height` | Высота кадров выходного видео в пикселях. Должна быть кратна 16. (по умолчанию: 480) | INT | Да | 16 to MAX_RESOLUTION, step: 16 |
| `length` | Общее количество кадров в видеопоследовательности. Значение увеличивается с шагом 4. (по умолчанию: 33) | INT | Да | 1 to MAX_RESOLUTION, step: 4 |
| `batch_size` | Количество видеопоследовательностей для генерации за один пакет. (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `start_image` | Необязательное стартовое изображение для инициализации генерации видео. Если оно указано, оно кодируется и используется для кондиционирования первых кадров. Используются только первые `length` кадров изображения. | IMAGE | Нет | - |
| `clip_vision_output` | Необязательные эмбеддинги CLIP vision для предоставления дополнительного визуального кондиционирования при генерации. | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Когда предоставлено `start_image`, оно автоматически масштабируется до указанных `width` и `height` с помощью билинейной интерполяции, и используются только его RGB-каналы. Используются первые `length` кадров пакета изображений. Затем закодированное изображение добавляется и к `positive`, и к `negative` кондиционированию как `concat_latent_image` с соответствующим `concat_mask`. Маска устанавливается в 0.0 для кадров, покрытых стартовым изображением, и в 1.0 для остальных кадров. Когда предоставлено `clip_vision_output`, оно также добавляется и к `positive`, и к `negative` кондиционированию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование, которое теперь может включать закодированное стартовое изображение или выход CLIP vision. | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование, которое теперь может включать закодированное стартовое изображение или выход CLIP vision. | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, настроенными под указанные размер пакета, длину видео, ширину и высоту. | LATENT |
