# HunyuanVideo15ImageToVideo

הצומת HunyuanVideo15ImageToVideo מכין נתוני התניה ומרחב latent ליצירת וידאו בהתבסס על המודל HunyuanVideo 1.5. הוא יוצר ייצוג latent ראשוני עבור רצף וידאו, ויכול לשלב באופן אופציונלי תמונת התחלה או פלט ראיית CLIP כדי להנחות את תהליך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | הנחיות ההתניה החיוביות שמתארות מה הווידאו צריך להכיל. | CONDITIONING | כן | - |
| `negative` | הנחיות ההתניה השליליות שמתארות ממה הווידאו צריך להימנע. | CONDITIONING | כן | - |
| `vae` | מודל VAE (Variational Autoencoder) המשמש לקידוד תמונת ההתחלה למרחב ה-latent. | VAE | כן | - |
| `width` | רוחב פריימי הווידאו בפלט בפיקסלים. חייב להיות מתחלק ב-16. (ברירת מחדל: 848) | INT | כן | 16 עד MAX_RESOLUTION, צעד: 16 |
| `height` | גובה פריימי הווידאו בפלט בפיקסלים. חייב להיות מתחלק ב-16. (ברירת מחדל: 480) | INT | כן | 16 עד MAX_RESOLUTION, צעד: 16 |
| `length` | מספר הפריימים הכולל ברצף הווידאו. הערכים גדלים בצעדים של 4 החל מ-1 (1, 5, 9, 13, ...). (ברירת מחדל: 33) | INT | כן | 1 עד MAX_RESOLUTION, צעד: 4 |
| `batch_size` | מספר רצפי הווידאו ליצירה באצווה אחת. (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `start_image` | תמונת התחלה אופציונלית לאתחול יצירת הווידאו. אם מסופקת, היא מקודדת ומשמשת להתניית הפריימים הראשונים. רק `length` הפריימים הראשונים של התמונה משמשים. | IMAGE | לא | - |
| `clip_vision_output` | הטמעות ראיית CLIP אופציונליות כדי לספק התניה חזותית נוספת ליצירה. | CLIP_VISION_OUTPUT | לא | - |

**הערה:** כאשר מסופקת `start_image`, היא משתנה אוטומטית לגודל המתאים ל-`width` ול-`height` שצוינו באמצעות אינטרפולציה דו-לינארית. משתמשים ב-`length` הפריימים הראשונים של אצוות התמונה, ורק 3 ערוצי הצבע הראשונים של כל פריים מקודדים. לאחר מכן התמונה המקודדת מתווספת גם לנתוני ההתניה של `positive` וגם לנתוני ההתניה של `negative` בתור `concat_latent_image` עם `concat_mask` מתאים. המסכה מוגדרת ל-0.0 עבור הפריימים שמכוסים על ידי תמונת ההתחלה ול-1.0 עבור שאר הפריימים. כאשר מסופק `clip_vision_output`, הוא מתווסף גם לנתוני ההתניה של `positive` וגם לנתוני ההתניה של `negative`.

## פלטים

| שם פלט | תיאור | סוג נתונים |

| `positive` | נתוני ההתניה החיוביים שהשתנו, אשר עשויים כעת לכלול את תמונת ההתחלה המקודדת או את פלט ראיית CLIP. | CONDITIONING |
