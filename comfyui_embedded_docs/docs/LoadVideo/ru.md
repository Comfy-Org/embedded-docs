# Загрузить видео

Узел Load Video загружает видеофайлы из входного каталога и делает их доступными для обработки в рабочем процессе. Он считывает видеофайлы из назначенной входной папки и выводит их как видеоданные, которые можно подключить к другим узлам обработки видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `файл` | Видеофайл для загрузки из входного каталога. Раскрывающийся список динамически заполняется всеми видеофайлами, найденными в папке ввода ComfyUI, а новые видеофайлы можно загружать напрямую через диалог выбора файлов. | COMBO | Да | Доступно несколько вариантов (все видеофайлы во входном каталоге) |

**Примечание:** Доступные варианты для параметра `file` динамически заполняются из видеофайлов, присутствующих во входном каталоге. Отображаются только файлы, соответствующие поддерживаемым типам видео, а список отсортирован по алфавиту. Вы также можете загрузить новый видеофайл напрямую через интерфейс выбора файлов узла. Если ранее выбранный видеофайл больше не найден, узел сообщает об ошибке недопустимого файла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Загруженные видеоданные, которые можно передать другим узлам обработки видео для дальнейшей обработки или анализа. | VIDEO |

**Примечание:** Узел также создаёт предпросмотр загруженного видео, который отображается непосредственно на узле.
