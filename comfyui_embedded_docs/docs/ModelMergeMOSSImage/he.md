# ModelMergeMOSSImage

הצומת ModelMergeMOSSImage ממזג שני מודלי MOSS לתמונות על ידי שילוב המשקלים התואמים שלהם בלוק אחר בלוק, כך שחלק אחד מהתוצאה יכול להגיע ממודל בסיס והשאר ממודל מכוונן עדין (fine-tune) או ממודל שני. לכל רכיב מרכזי בארכיטקטורה יש יחס משלו: מטמיע הווידאו, מטמיע הטקסט, הטמעת הזמן, מודולציית הבלוק המשותפת, כל 42 שכבות הטרנספורמר וראשי הפלט.

| `model2` | המודל השני למיזוג. המשקלים שלו משולבים לפי היחסים שלהלן | MODEL | כן | - |

יחס של 0.0 משאיר את הרכיב כפי שהוא ב-`model1`, יחס של 1.0 לוקח אותו כולו מ-`model2`, וערכים שביניהם יוצרים מיזוג משוקלל. שני הקלטים חייבים להיות מודלי MOSS לתמונות עם אותה ארכיטקטורה; משקלים שאינם תואמים לאף אחד מהקידומות שלמעלה משתמשים ביחס של `video_embedder.`.
