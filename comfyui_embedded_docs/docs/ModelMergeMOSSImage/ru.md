# ModelMergeMOSSImage

Узел ModelMergeMOSSImage объединяет две модели изображений MOSS, смешивая их совпадающие веса блок за блоком, поэтому одна часть результата может происходить из базовой модели, а остальная — из дообученной или второй модели. Каждый основной компонент архитектуры имеет собственный коэффициент: видеоэмбеддер, текстовый эмбеддер, эмбеддинг времени, общая модуляция блоков, все 42 слоя трансформера и выходные головы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model1` | Первая модель для объединения. Всё, что не вносит вторая модель, берётся из этой модели | MODEL | Да | - |
| `model2` | Вторая модель для объединения. Её веса смешиваются в соответствии с коэффициентами ниже | MODEL | Да | - |
| `video_embedder.` | Коэффициент смешивания для блока видеоэмбеддера (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `text_embedder.proj.` | Коэффициент смешивания для проекционного слоя текстового эмбеддера (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `text_embedder.blocks.0.` и `text_embedder.blocks.1.` | Коэффициент смешивания для каждого из двух блоков текстового эмбеддера (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `time_embedding.` | Коэффициент смешивания для блока эмбеддинга времени (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `shared_block_modulation.` | Коэффициент смешивания для общего слоя модуляции, используемого блоками трансформера (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| с `layers.0.` по `layers.41.` | Коэффициент смешивания для каждого из 42 слоёв трансформера (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `final_norm_video.` | Коэффициент смешивания для финальной нормализации видеопотока (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `final_linear_video.` | Коэффициент смешивания для финального линейного слоя видеопотока (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |
| `video_head_modulation.` | Коэффициент смешивания для слоя модуляции выходной головы видео (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |

Коэффициент 0.0 оставляет этот компонент таким, как в `model1`, коэффициент 1.0 полностью берёт его из `model2`, а промежуточные значения создают взвешенное смешивание. Оба входа должны быть моделями изображений MOSS с одинаковой архитектурой; веса, не соответствующие ни одному из префиксов выше, используют коэффициент `video_embedder.`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Объединённая модель, сочетающая оба входа в соответствии с указанными коэффициентами | MODEL |
