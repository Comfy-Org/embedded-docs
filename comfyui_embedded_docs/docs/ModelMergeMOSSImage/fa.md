# ModelMergeMOSSImage

گره ModelMergeMOSSImage دو مدل تصویری MOSS را با ترکیب وزن‌های متناظرشان به‌صورت بلوک‌به‌بلوک ادغام می‌کند؛ بنابراین بخشی از نتیجه می‌تواند از یک مدل پایه و بقیه از یک فاین‌تیون یا مدل دوم بیاید. هر مؤلفه اصلی معماری نسبت اختلاط خود را دارد: تعبیه‌گر ویدئو، تعبیه‌گر متن، تعبیه زمان، مدولاسیون مشترک بلوک، هر 42 لایه ترانسفورمر و سرهای خروجی.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model1` | اولین مدل برای ادغام. هر بخشی که مدل دوم در آن مشارکت ندارد از این مدل حفظ می‌شود | MODEL | بله | - |
| `model2` | دومین مدل برای ادغام. وزن‌های آن بر اساس نسبت‌های زیر ترکیب می‌شوند | MODEL | بله | - |
| `video_embedder.` | نسبت اختلاط برای بلوک تعبیه‌گر ویدئو (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `text_embedder.proj.` | نسبت اختلاط برای لایه پروجکشن تعبیه‌گر متن (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `text_embedder.blocks.0.` و `text_embedder.blocks.1.` | نسبت اختلاط برای هر یک از دو بلوک تعبیه‌گر متن (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `time_embedding.` | نسبت اختلاط برای بلوک تعبیه زمان (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `shared_block_modulation.` | نسبت اختلاط برای لایه مدولاسیون مشترک که توسط بلوک‌های ترانسفورمر استفاده می‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `layers.0.` تا `layers.41.` | نسبت اختلاط برای هر یک از 42 لایه ترانسفورمر (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_norm_video.` | نسبت اختلاط برای نرمال‌سازی نهایی جریان ویدئو (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `final_linear_video.` | نسبت اختلاط برای لایه خطی نهایی جریان ویدئو (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |
| `video_head_modulation.` | نسبت اختلاط برای لایه مدولاسیون سر خروجی ویدئو (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |

نسبت 0.0 آن مؤلفه را همان‌گونه که در `model1` است نگه می‌دارد، نسبت 1.0 آن را به‌طور کامل از `model2` می‌گیرد و مقادیر میان این دو یک ترکیب وزنی تولید می‌کنند. هر دو ورودی باید مدل‌های تصویری MOSS با معماری یکسان باشند؛ وزن‌هایی که با هیچ‌یک از پیشوندهای بالا مطابقت ندارند به نسبت `video_embedder.` برمی‌گردند.
