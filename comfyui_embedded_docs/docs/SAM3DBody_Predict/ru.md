# Запустить предсказание тела SAM3D

SAM3D Body Prediction выполняет оценку 3D-позы тела и рук на входных изображениях, обнаруживая одного или нескольких людей на кадр. Для улучшения обнаружения могут быть предоставлены данные отслеживания или ограничивающие рамки; если ни то, ни другое не задано, узел возвращается к полноэкранному обнаружению одного человека.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | Модель тела SAM3D для предсказания. | SAM3D_BODY_MODEL | Да | — |
| `изображение` | Изображение или пакет изображений для выполнения предсказания позы тела. | IMAGE | Да | — |
| `track_data` | Данные отслеживания из SAM3 Video Track, необходимые для обнаружения нескольких человек. | SAM3_TRACK_DATA | Нет | — |
| `bboxes` | Покадровые ограничивающие рамки, используемые для улучшения обнаружения. Могут использоваться как альтернатива данным отслеживания. | BBOX | Нет | — |
| `run_hand_refinement` | Улучшает позу рук ценой дополнительного времени вывода и использования памяти. По умолчанию: true. | BOOLEAN | Нет | true<br>false |
| `fov` | Вертикальное поле зрения (FoV) в градусах. Влияет на предсказанную глубину и абсолютный масштаб. 0 = запасной вариант ~53° (16:9). По умолчанию: 0.0. | FLOAT | Нет | 0.0 or greater |
| `batch_size` | Максимальное количество кадров человека для обработки в одном пакете. Большие значения используют больше видеопамяти для более быстрого вывода. По умолчанию: 64. | INT | Нет | от 1 до 512 |

Примечание: Если предоставлены `track_data`, они имеют приоритет над `bboxes`. Если ни `track_data`, ни `bboxes` не предоставлены, узел возвращается к полноэкранному обнаружению одного человека. Ограничивающие рамки могут быть предоставлены для одного кадра (применяются к каждому кадру) или для каждого кадра.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mhr_pose_data` | Пакет данных о позе тела, содержащий результаты обнаружения позы по кадрам, геометрию лица, размер входного изображения, канонические цвета вершин и маску вершин рук. | MHR_POSE_DATA |
