# RenderSplat

רנדר גאוסיאן ספלאט כתמונה באמצעות רסטרייזר EWA אנאיזוטרופי עם ספלאטים אליפטיים מכוונים, החלקת קצוות, ורינדור ממוין לפי עומק מלפנים לאחור. המצלמה מגיעה מקלט camera_info, או שניתן להשאירו ריק כדי למסגר את הספלאט אוטומטית. הגדר frames גדול מ-1 עבור אצוות תמונות של סבסוב (turntable) להזנה לצומת Video.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `splat` | נתוני גאוסיאן ספלאט לרנדור | SPLAT | כן | - |
| `width` | רוחב תמונת הפלט (ברירת מחדל: 1024) | INT | כן | 64 עד 2048 (צעד: 8) |
| `height` | גובה תמונת הפלט (ברירת מחדל: 1024) | INT | כן | 64 עד 2048 (צעד: 8) |
| `frames` | מספר הפריימים לרנדור. -1, 0 או 1 מייצר תמונה סטטית בודדת. ערכים גדולים מ-1 יוצרים אנימציית סבסוב שבה המצלמה מקיפה בסיבוב מלא של 360 מעלות. ערכים שליליים מקיפים בכיוון ההפוך (ברירת מחדל: 1) | INT | כן | -240 עד 240 |
| `splat_scale` | מכפיל על טביעת הרגל המוקרנת של כל ספלאט. ערכים נמוכים יותר מייצרים נקודות חדות יותר, ערכים גבוהים יותר מייצרים משטחים רכים ומלאים יותר (ברירת מחדל: 1.0) | FLOAT | כן | 0.1 עד 5.0 (צעד: 0.05) |
| `sharpen` | שולט בחדות של ספלאטים חופפים. ערך של 1.0 נותן מיזוג נכון פיזיקלית. ערכים מעל 1.0 מטים כל פיקסל לכיוון הספלאט הדומיננטי (הקרוב) שלו כדי לקבל טקסטורה חדה יותר בלי לכווץ ספלאטים או לפתוח רווחים (ברירת מחדל: 2.0) | FLOAT | כן | 1.0 עד 8.0 (צעד: 0.5) |
| `headlight_shading` | הצללה דיפוזית ממקור אור במיקום המצלמה, באמצעות הנורמלים של משטחי הספלאט (surfel). מחשיך משטחים שפונים הרחק מהמבט כדי לחשוף צורה ועקמומיות. 0 נותן אלבדו שטוח, 1 נותן הצללה חזקה ביותר (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 עד 3.0 (צעד: 0.05) |
| `opacity_threshold` | מסנן גאוסיאנים עם אטימות מתחת לסף זה, מה שמסיר צפים חלשים (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.01) |
| `render_style` | מה שתמונת הפלט מציגה. האפשרויות הן: color (רינדור צבע מלא), clay (הצללה בגוון אלבדו ניטרלי), depth (אובייקטים קרובים מופיעים בהירים), normal (מפת נורמלים של OpenGL) (ברירת מחדל: "color") | COMBO | כן | "color"<br>"clay"<br>"depth"<br>"normal" |
| `background` | צבע רקע אחיד לרנדור (ברירת מחדל: #000000) | COLOR | כן | - |
| `bg_image` | לוחית רקע אופציונלית המשולבת מאחורי הספלאט. דורסת את צבע הרקע האחיד. משתנה לגודל הרנדור. אצווה של תמונות משמשת לכל פריים, תמונה בודדת משמשת לכל הפריימים. עובד רק עם סגנונות הרנדור color ו-clay | IMAGE | לא | - |
| `camera_info` | מצלמה שממנה לרנדר. יכולה להגיע מצומת Load3D, Preview3D או Create Camera Info. אם ריק, הספלאט ממוסגר אוטומטית מתצוגת 3/4 כברירת מחדל | CAMERA_3D | לא | - |
