# ClipVisionEncode

צומת `CLIP Vision Encode` הוא צומת לקידוד תמונות ב-ComfyUI, המשמש להמרת תמונות קלט לוקטורי מאפיינים חזותיים באמצעות מודל CLIP Vision. צומת זה הוא גשר חשוב המחבר בין הבנת תמונות וטקסט, ונמצא בשימוש נרחב במגוון תהליכי עבודה של יצירה ועיבוד תמונות באמצעות AI.

**פונקציונליות הצומת**

- **חילוץ מאפיינים מתמונה**: ממיר תמונות קלט לוקטורי מאפיינים רב-ממדיים
- **גישור מולטימודלי**: מספק בסיס לעיבוד משותף של תמונות וטקסט
- **יצירה מותנית**: מספק תנאים חזותיים ליצירה מותנית מבוססת תמונה

## קלטים

| שם פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `clip_vision` | מודל CLIP Vision, הנטען בדרך כלל באמצעות הצומת CLIPVisionLoader | CLIP_VISION |
| `image` | תמונת הקלט שיש לקודד | IMAGE |
| `crop` | שיטת חיתוך התמונה, אפשרויות: center (חיתוך מרכז), none (ללא חיתוך) | רשימה נפתחת |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| CLIP_VISION_OUTPUT | מאפיינים חזותיים מקודדים | CLIP_VISION_OUTPUT |

אובייקט הפלט הזה מכיל:

- `last_hidden_state`: המצב החבוי האחרון
- `image_embeds`: וקטור הטמעת תמונה
- `penultimate_hidden_states`: המצב החבוי שלפני האחרון
- `mm_projected`: תוצאת היטל מולטימודלי (אם זמינה)
