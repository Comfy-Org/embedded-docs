# VAE 編碼音訊

VAEEncodeAudio 節點使用變分自編碼器（VAE）將音訊資料轉換為潛在表示。它接收音訊輸入，並透過 VAE 處理以產生壓縮的潛在樣本，這些樣本可用於進一步的音訊生成或操作任務。節點會視需要自動重新取樣音訊，以符合 VAE 預期的取樣率，再進行編碼。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `音訊` | 要編碼的音訊資料，包含波形與取樣率資訊 | AUDIO | 是 | - |
| `vae` | 用於將音訊編碼至潛在空間的變分自編碼器模型 | VAE | 是 | - |

**注意：** 若輸入音訊的原始取樣率與 VAE 預期的取樣率（預設：44100 Hz）不同，節點會自動重新取樣以符合該值。若輸入音訊為 None（例如來源影片沒有音訊軌），節點將引發錯誤。

## 輸出

| 輸出名 | 描述 | 資料類型 |
| --- | --- | --- |
| `LATENT` | 編碼後的音訊潛在表示，包含壓縮樣本 | LATENT |
