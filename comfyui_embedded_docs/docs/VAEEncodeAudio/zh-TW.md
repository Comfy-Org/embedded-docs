# VAE 編碼音訊

VAE Encode Audio 節點使用變分自編碼器（VAE）將音訊資料轉換為潛在表示。它會透過 VAE 處理傳入的音訊，產生壓縮的潛在樣本，可用於進一步的音訊生成或操控任務。若音訊的取樣率與 VAE 預期的取樣率不同，音訊會在編碼前自動重新取樣。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `音訊` | 要編碼的音訊資料，包含波形與取樣率資訊 | AUDIO | 是 | - |
| `vae` | 用於將音訊編碼至潛在空間的變分自編碼器模型 | VAE | 是 | - |

**注意：** 若原始取樣率與 VAE 預期的取樣率（預設：44100 Hz）不同，音訊輸入會自動重新取樣以符合該值。若輸入音訊為 None（例如來源影片沒有音訊軌），節點將會擲出錯誤。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
| --- | --- | --- |
| `LATENT` | 潛在空間中編碼後的音訊表示，包含壓縮後的樣本 | LATENT |
