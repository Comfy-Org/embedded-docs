# VAE编码（音频）

VAEEncodeAudio 节点使用变分自编码器（VAE）将音频数据转换为潜在表示。它接收音频输入，通过 VAE 处理生成压缩的潜在样本，可用于进一步的音频生成或处理任务。该节点在编码前会自动将音频重采样以匹配 VAE 的预期采样率（如有需要）。

## 输入

| 参数 | 说明 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `audio` | 要编码的音频数据，包含波形和采样率信息 | AUDIO | 是 | - |
| `vae` | 用于将音频编码到潜在空间的变分自编码器模型 | VAE | 是 | - |

**注意：** 如果输入音频的原始采样率与 VAE 的预期采样率（默认：44100 Hz）不同，节点会自动重采样以匹配。如果输入音频为 None（例如源视频没有音轨），节点将引发错误。

## 输出

| 输出名 | 说明 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 编码后的潜在空间音频表示，包含压缩样本 | LATENT |
