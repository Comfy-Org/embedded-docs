# Кодировать аудио VAE

Узел VAE Encode Audio преобразует аудиоданные в латентное представление с помощью вариационного автоэнкодера (VAE). Он обрабатывает входящий звук через VAE, создавая сжатые латентные сэмплы, которые можно использовать для дальнейшей генерации или обработки аудио. Если частота дискретизации аудио отличается от ожидаемой частоты дискретизации VAE, аудио автоматически передискретизируется перед кодированием.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `аудио` | Аудиоданные для кодирования, содержащие информацию о форме волны и частоте дискретизации | AUDIO | Да | - |
| `vae` | Модель вариационного автоэнкодера, используемая для кодирования аудио в латентное пространство | VAE | Да | - |

**Примечание:** Если исходная частота дискретизации входного аудио отличается от ожидаемой частоты дискретизации VAE (по умолчанию: 44100 Hz), аудио автоматически передискретизируется до этого значения. Если входное аудио равно None (например, когда в исходном видео нет аудиодорожки), узел вызовет ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Закодированное представление аудио в латентном пространстве, содержащее сжатые сэмплы | LATENT |
