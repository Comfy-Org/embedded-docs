# Кодировать аудио VAE

Узел `VAEEncodeAudio` преобразует аудиоданные в латентное представление с помощью вариационного автокодировщика (VAE). Он принимает аудиовход и обрабатывает его через VAE для создания сжатых латентных сэмплов, которые можно использовать для последующей генерации или манипуляции аудио. При необходимости узел автоматически передискретизирует аудио в соответствии с ожидаемой частотой дискретизации VAE перед кодированием.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `аудио` | Аудиоданные для кодирования, содержащие информацию о форме сигнала и частоте дискретизации | AUDIO | Да | - |
| `vae` | Модель вариационного автокодировщика, используемая для кодирования аудио в латентное пространство | VAE | Да | - |

**Примечание:** Аудиовход автоматически передискретизируется в соответствии с ожидаемой частотой дискретизации VAE (по умолчанию: 44100 Гц), если исходная частота дискретизации отличается от этого значения. Если входное аудио равно None (например, в исходном видео нет звуковой дорожки), узел вызовет ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Закодированное аудиопредставление в латентном пространстве, содержащее сжатые сэмплы | LATENT |
