# کدگذاری VAE صوتی

گره VAE Encode Audio داده‌های صوتی را با استفاده از یک خودرمزگذار واریاسیونی (VAE) به بازنمایی نهفته تبدیل می‌کند. این گره صدای ورودی را از طریق VAE پردازش می‌کند تا نمونه‌های نهفته فشرده‌شده‌ای تولید کند که می‌توان از آن‌ها برای تولید یا دست‌کاری بیشتر صدا استفاده کرد. اگر نرخ نمونه‌برداری صدا با نرخ نمونه‌برداری مورد انتظار VAE متفاوت باشد، صدا پیش از رمزگذاری به‌صورت خودکار نمونه‌برداری مجدد می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `audio` | داده‌های صوتی برای رمزگذاری، شامل اطلاعات شکل موج و نرخ نمونه‌برداری | AUDIO | بله | - |
| `vae` | مدل خودرمزگذار واریاسیونی که برای رمزگذاری صدا در فضای نهفته استفاده می‌شود | VAE | بله | - |

**توجه:** اگر نرخ نمونه‌برداری اصلی صدا با نرخ نمونه‌برداری مورد انتظار VAE (پیش‌فرض: 44100 Hz) متفاوت باشد، ورودی صوتی به‌صورت خودکار برای تطابق با این نرخ نمونه‌برداری مجدد می‌شود. اگر ورودی صوتی None باشد (برای مثال، وقتی ویدیوی مبدأ فاقد ترک صوتی است)، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `LATENT` | بازنمایی صوتی رمزگذاری‌شده در فضای نهفته، شامل نمونه‌های فشرده‌شده | LATENT |
