# Comfy Cloud MiniMax H3 Первый-последний кадр в видео [БЕТА]

Запускает рабочий процесс MiniMax H3 для первого и последнего кадров на GPU Comfy Cloud и возвращает движение между двумя ключевыми кадрами с соответствующей звуковой дорожкой. Укажите начальный и конечный кадры, и модель заполнит фрагмент между ними. Последний кадр необязателен: если его не указывать, движение будет развиваться от первого кадра. Это бета-узел, тарифицируется по секундам GPU.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | Изображение, с которого начинается видео. Перед запуском рабочего процесса оно загружается с размером до 2048x2048 пикселей. | IMAGE | Да | - |
| `последний кадр` | Необязательный конечный кадр. Если он подключён, сгенерированное движение заканчивается на этом изображении; без него движение будет развиваться от `first_frame`. | IMAGE | Нет | - |
| `prompt` | Текстовое описание движения и звуков, которые должны присутствовать во фрагменте. Пробелы в начале и конце удаляются перед отправкой. | STRING | Да | От 1 до 4096 символов |
| `seed` | Случайное зерно, управляющее сгенерированным результатом (по умолчанию: 42). | INT | Да | От 0 до 18446744073709551615 |
| `aspect_ratio` | Соотношение сторон сгенерированного видео (по умолчанию: `"1:1"`). | COMBO | Да | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `resolution` | Бюджет размера кадра (по умолчанию: `"480p"`). 720p стоит примерно вдвое больше GPU-секунд, чем 480p. | COMBO | Да | `"480p"`<br>`"720p"` |
| `duration_seconds` | Длительность в секундах (по умолчанию: 5). Пайплайн квантует значение шагами по 17 кадров при 24 fps, поэтому итоговый клип отклоняется от указанного значения не более чем примерно на две трети секунды. | INT | Да | От 5 до 15 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуковой дорожкой. | VIDEO |
