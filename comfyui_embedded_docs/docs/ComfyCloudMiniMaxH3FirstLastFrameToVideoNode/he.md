# Comfy Cloud MiniMax H3 מפריים ראשון ואחרון לווידאו [BETA]

מריץ את זרימת העבודה first-last frame של MiniMax H3 על GPU של Comfy Cloud ומחזיר את התנועה בין שני פריימי מפתח עם פס קול תואם. מספקים לו את פריים הפתיחה ופריים הסיום, והמודל ממלא את השוט שביניהם. הפריים האחרון הוא אופציונלי: אם משמיטים אותו, התנועה נעה הרחק מהפריים הראשון במקום. זהו צומת בטא, והחיוב מתבצע לפי שניות GPU.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | התמונה שממנה מתחיל הווידאו. היא מועלית ברזולוציה של עד 2048x2048 פיקסלים לפני הרצת זרימת העבודה. | IMAGE | כן | - |
| `last_frame` | פריים סיום אופציונלי. כאשר הוא מחובר, התנועה שנוצרת מסתיימת בתמונה הזו; ללא חיבור, התנועה נעה הרחק מ-`first_frame`. | IMAGE | לא | - |
| `prompt` | תיאור טקסטואלי של התנועה והצלילים שהשוט אמור לשאת. רווחים בתחילת ובסוף הטקסט מוסרים לפני השליחה. | STRING | כן | 1 עד 4096 תווים |
| `seed` | זרע אקראי שקובע את התוצאה הנוצרת (ברירת מחדל: 42). | INT | כן | 0 עד 18446744073709551615 |
| `aspect_ratio` | יחס רוחב-גובה של הווידאו הנוצר (ברירת מחדל: `"1:1"`). | COMBO | כן | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `resolution` | תקציב גודל פריים (ברירת מחדל: `"480p"`). 720p עולה בערך פי שניים בשניות GPU לעומת 480p. | COMBO | כן | `"480p"`<br>`"720p"` |
| `duration_seconds` | אורך בשניות (ברירת מחדל: 5). התהליך מכמת לצעדים של 17 פריימים ב-24 fps, ולכן אורך הקליפ יתקבל בסטייה של כשני שלישי שנייה מהערך הזה. | INT | כן | 5 עד 15 |
