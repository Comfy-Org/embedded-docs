# Comfy Cloud MiniMax H3 فریم اول-آخر به ویدیو [بتا]

گردش‌کار فریم اول و آخر MiniMax H3 را روی GPU ابری Comfy Cloud اجرا می‌کند و حرکت میان دو فریم کلیدی را همراه با موسیقی متن هماهنگ برمی‌گرداند. فریم آغازین و پایانی را به آن بدهید تا مدل نمای میان آن‌ها را پر کند. فریم آخر اختیاری است: اگر آن را وارد نکنید، حرکت به‌جای آن از فریم اول به سمت جلو ادامه پیدا می‌کند. این گره بتاست و هزینه آن بر اساس ثانیه‌های GPU محاسبه می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | تصویری که ویدئو از آن شروع می‌شود. پیش از اجرای گردش‌کار، با حداکثر ابعاد 2048x2048 پیکسل بارگذاری می‌شود. | IMAGE | بله | - |
| `فریم آخر` | فریم پایانی اختیاری. اگر متصل شود، حرکت تولیدشده روی این تصویر پایان می‌یابد؛ بدون آن، حرکت از `first_frame` به سمت جلو ادامه پیدا می‌کند. | IMAGE | خیر | - |
| `prompt` | توصیف متنی حرکت و صداهایی که نما باید همراه داشته باشد. فاصله‌های سفید ابتدا و انتها پیش از ارسال حذف می‌شوند. | STRING | بله | 1 تا 4096 نویسه |
| `seed` | seed تصادفی که نتیجه تولیدشده را کنترل می‌کند (پیش‌فرض: 42). | INT | بله | 0 تا 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد ویدئوی تولیدشده (پیش‌فرض: `"1:1"`). | COMBO | بله | `"1:1"`<br>`"3:4"`<br>`"2:3"`<br>`"3:2"`<br>`"4:3"`<br>`"16:9"`<br>`"9:16"`<br>`"21:9"` |
| `resolution` | بودجه اندازه فریم (پیش‌فرض: `"480p"`). 720p تقریباً دو برابر 480p هزینه ثانیه GPU دارد. | COMBO | بله | `"480p"`<br>`"720p"` |
| `duration_seconds` | مدت بر حسب ثانیه (پیش‌فرض: 5). خط پردازش آن را به گام‌های 17 فریمی با 24 fps کوانتیزه می‌کند؛ در نتیجه طول کلیپ حدود دو سوم ثانیه با این مقدار اختلاف خواهد داشت. | INT | بله | 5 تا 15 |
