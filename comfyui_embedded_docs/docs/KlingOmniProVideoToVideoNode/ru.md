# Kling Omni Video to Video (Pro)

Этот узел использует модель Kling AI для генерации нового видео на основе входного видео и необязательных эталонных изображений. Вы задаёте текстовую подсказку с описанием желаемого содержимого, и узел преобразует эталонное видео соответствующим образом. Он также может использовать до четырёх дополнительных эталонных изображений для управления стилем и содержимым результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling для генерации видео (по умолчанию: "kling-v3-omni"). | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовая подсказка, описывающая содержимое видео. Может включать как положительные, так и отрицательные описания. | STRING | Да | N/A |
| `aspect_ratio` | Желаемое соотношение сторон генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность генерируемого видео в секундах (по умолчанию: 3). | INT | Да | 3 до 10 |
| `reference_video` | Видео, используемое в качестве эталона. | VIDEO | Да | N/A |
| `keep_original_sound` | Определяет, сохраняется ли звук из эталонного видео в выходном видео (по умолчанию: True). | BOOLEAN | Да | N/A |
| `reference_images` | До 4 дополнительных эталонных изображений. | IMAGE | Нет | N/A |
| `resolution` | Разрешение генерируемого видео (по умолчанию: "1080p"). | COMBO | Нет | `"1080p"`<br>`"720p"` |
| `seed` | Определяет, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Нет | 0 до 2147483647 |

**Ограничения параметров:**

* Значение `prompt` должно содержать от 1 до 2500 символов.
* Длительность `reference_video` должна составлять от 3.0 до 10.05 секунды.
* Размеры `reference_video` должны быть от 720x720 до 2160x2160 пикселей.
* Можно указать не более 4 `reference_images`. Каждое изображение должно быть не меньше 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Новое сгенерированное видео. | VIDEO |
