# Kling Omni 影片轉影片（專業版）

此節點使用 Kling AI 模型，根據輸入影片與選用參考圖片生成新影片。您提供描述所需內容的文字提示詞，節點會據此轉換參考影片。它也可以納入最多四張額外參考圖片，以引導輸出的風格與內容。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 用於影片生成的特定 Kling 模型（預設："kling-v3-omni"）。 | COMBO | 是 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `提示詞` | 描述影片內容的文字提示詞。可同時包含正向與負向描述。 | STRING | 是 | N/A |
| `長寬比` | 生成影片的期望長寬比。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `時長` | 生成影片的長度，以秒為單位（預設：3）。 | INT | 是 | 3 至 10 |
| `參考影片` | 用作參考的影片。 | VIDEO | 是 | N/A |
| `保留原始聲音` | 決定是否在輸出中保留參考影片的音訊（預設：True）。 | BOOLEAN | 是 | N/A |
| `參考圖片` | 最多 4 張額外參考圖片。 | IMAGE | 否 | N/A |
| `解析度` | 生成影片的解析度（預設："1080p"）。 | COMBO | 否 | `"1080p"`<br>`"720p"` |
| `seed` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果皆不具確定性（預設：0）。 | INT | 否 | 0 至 2147483647 |

**參數限制：**

* `prompt` 的長度必須介於 1 到 2500 個字元之間。
* `reference_video` 的持續時間必須介於 3.0 到 10.05 秒之間。
* `reference_video` 的尺寸必須介於 720x720 到 2160x2160 像素之間。
* 最多可以提供 4 張 `reference_images`。每張圖片必須至少為 300x300 像素，且長寬比介於 1:2.5 到 2.5:1 之間。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `output` | 新生成的影片。 | VIDEO |
