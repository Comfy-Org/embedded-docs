# MiniMax H3 이미지 → 비디오

MiniMax H3 Image to Video는 MiniMax H3 모델로 비디오를 생성하는 데 필요한 컨디셔닝과 빈 잠재를 준비합니다. 이 노드는 텍스트 프롬프트와 선택적으로 비디오의 첫 번째 및/또는 마지막 프레임 이미지를 받아 모델 입력으로 변환합니다. 키프레임 이미지는 크기가 조정되고 인코딩된 후 비디오의 시작과 끝에서 컨디셔닝에 첨부됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 프롬프트를 토큰화하고 키프레임 이미지를 컨디셔닝으로 인코딩하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 |  |
| `vae` | 키프레임 이미지가 제공될 때 키프레임 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 |  |
| `prompt` | 생성할 비디오를 설명하는 텍스트 프롬프트입니다. 여러 줄 및 동적 프롬프트를 지원합니다. | STRING | 예 |  |
| `width` | 비디오의 너비(픽셀 단위)입니다. 기본값은 1344입니다. | INT | 예 | 32 to MAX_RESOLUTION (step 32) |
| `height` | 비디오의 높이(픽셀 단위)입니다. 기본값은 768입니다. | INT | 예 | 32 to MAX_RESOLUTION (step 32) |
| `length` | 24fps 기준 프레임 수로, 모델의 17k+5 그리드에 맞게 올림 처리됩니다. (124 ≈ 약 5초, 학습 범위는 약 124~362이며, 더 길면 테스트되지 않았습니다.) 기본값은 124입니다. | INT | 예 | 5 to 3600 (step 17) |
| `first_frame` | 비디오의 첫 번째 프레임으로 사용되는 선택적 이미지입니다. 전체 캔버스 크기로 늘어나므로 종횡비가 유지되지 않습니다. 입력 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니요 |  |
| `last_frame` | 비디오의 마지막 프레임으로 사용되는 선택적 이미지입니다. 종횡비를 유지하면서 캔버스를 덮도록 크롭됩니다. 입력 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니요 |  |

`first_frame` 및/또는 `last_frame`이 제공되면 키프레임 이미지가 VAE로 인코딩되어 각각 0번째 프레임과 마지막 프레임의 컨디셔닝에 첨부됩니다. 둘 다 제공되지 않으면 이 노드는 프롬프트만으로 작동합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `positive` | MiniMax H3 모델용으로 인코딩된 프롬프트와, 키프레임 이미지가 제공된 경우 비디오의 첫 번째 및 마지막 프레임에 배치된 인코딩된 키프레임을 포함하는 컨디셔닝입니다. | CONDITIONING |
| `latent` | 요청된 너비, 높이 및 프레임 수에 따라 생성될 비디오와 그에 수반되는 오디오 트랙을 나타내는 빈 잠재입니다. | LATENT |
