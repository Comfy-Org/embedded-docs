# MiniMax H3 Image to Video

צומת זה מכין את ה-conditioning וה-latent הריקים הדרושים ליצירת וידאו עם מודל MiniMax H3. הוא מקבל פרומפט טקסטואלי, ובאופן אופציונלי תמונות עבור הפריים הראשון ו/או האחרון של הווידאו, וממיר אותם לקלטי המודל. תמונות מפתח משתנות בגודלן, מקודדות ומצורפות ל-conditioning בתחילת הווידאו ובסופו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל CLIP המשמש לביצוע טוקניזציה של הפרומפט וקידוד תמונות המפתח ל-conditioning. | CLIP | כן |  |
| `vae` | מודל VAE המשמש לקידוד תמונות המפתח למרחב latent כאשר מסופקות תמונות מפתח. | VAE | כן |  |
| `prompt` | פרומפט טקסטואלי המתאר את הווידאו שיש ליצור. תומך במספר שורות ובפרומפטים דינמיים. | STRING | כן |  |
| `width` | רוחב הווידאו בפיקסלים (ברירת מחדל: 1344). | INT | כן | 32 עד MAX_RESOLUTION (צעד 32) |
| `height` | גובה הווידאו בפיקסלים (ברירת מחדל: 768). | INT | כן | 32 עד MAX_RESOLUTION (צעד 32) |
| `length` | מספר הפריימים בקצב 24 fps, מעוגל כלפי מעלה לרשת 17k+5 של המודל (124 = ~5 שנ'; טווח האימון הוא ~124-362, ארוך יותר לא נבדק) (ברירת מחדל: 124). | INT | כן | 5 עד 3600 (צעד 17) |
| `first_frame` | תמונה אופציונלית המשמשת כפריים הראשון של הווידאו. היא נמתחת לגודל הקנבס המלא, כך שיחס הגובה-רוחב שלה אינו נשמר. משתמשים רק בתמונה הראשונה מקבוצת הקלט. | IMAGE | לא |  |
| `last_frame` | תמונה אופציונלית המשמשת כפריים האחרון של הווידאו. היא נחתכת כדי לכסות את הקנבס תוך שמירה על יחס הגובה-רוחב שלה. משתמשים רק בתמונה הראשונה מקבוצת הקלט. | IMAGE | לא |  |

כאשר מסופקים `first_frame` ו/או `last_frame`, תמונות המפתח מקודדות עם VAE ומצורפות ל-conditioning בפריים 0 ובפריים האחרון, בהתאמה. כאשר אף אחד מהם לא מסופק, הצומת פועל על סמך הפרומפט בלבד. ה-`length` המבוקש מעוגל כלפי מעלה למספר הפריימים החוקי הקרוב (17k + 5), כך שמספר הפריימים האפקטיבי עשוי להיות מעט גבוה מהמבוקש.

ה-latent של אודיו-וידאו נוצר כזוג ריק התואם את ה-`width`, ה-`height` ומספר הפריימים המעוגל המבוקשים. חלק האודיו נקבע לפי אותו מספר פריימים בקצב של 40 פריימי אודיו לשנייה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | Conditioning המכיל את הפרומפט המקודד וכאשר מסופקות תמונות מפתח, גם את תמונות המפתח המקודדות ומספר הפריימים עבור מודל MiniMax H3. | CONDITIONING |
| `latent` | latent אודיו-וידאו ריק המייצג את התוכן שיש ליצור, עם הרוחב, הגובה ומספר הפריימים המבוקשים. | LATENT |
