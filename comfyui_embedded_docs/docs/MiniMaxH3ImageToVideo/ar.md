# تحويل صورة MiniMax H3 إلى فيديو

هذه العقدة تُحضّر التكييف (conditioning) والكامن الفارغ (latent) اللازمين لتوليد فيديو باستخدام نموذج MiniMax H3. تأخذ نصًا وصفيًا، وبشكل اختياري صورًا للإطار الأول و/أو الأخير من الفيديو، وتحوّلها إلى مدخلات النموذج. يتم تغيير حجم صور الإطارات المفتاحية، وترميزها، ثم إرفاقها بالتكييف في بداية الفيديو ونهايته.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|---------|
| `clip` | نموذج CLIP المستخدم لتقطيع النص إلى رموز وترميز صور الإطارات المفتاحية إلى تكييف. | CLIP | نعم |  |
| `vae` | نموذج VAE المستخدم لترميز صور الإطارات المفتاحية إلى فضاء كامن عند توفّر صور الإطارات المفتاحية. | VAE | نعم |  |
| `prompt` | نص وصفي يصف الفيديو المراد توليده. يدعم عدة أسطر وموجهات ديناميكية. | STRING | نعم |  |
| `العرض` | عرض الفيديو بالبكسل (الافتراضي: 1344). | INT | نعم | 32 إلى MAX_RESOLUTION (الخطوة 32) |
| `الارتفاع` | ارتفاع الفيديو بالبكسل (الافتراضي: 768). | INT | نعم | 32 إلى MAX_RESOLUTION (الخطوة 32) |
| `الطول` | عدد الإطارات عند 24 إطارًا في الثانية، ويُقرَّب لأعلى إلى شبكة 17k+5 الخاصة بالنموذج (124 = حوالي 5 ثوانٍ؛ النطاق المُدرَّب حوالي 124-362، وما هو أطول لم يُختبر) (الافتراضي: 124). | INT | نعم | 5 إلى 3600 (الخطوة 17) |
| `الإطار الأول` | صورة اختيارية تُستخدم كإطار أول للفيديو. يتم تمديدها إلى حجم اللوحة الكامل، لذلك لا يتم الحفاظ على نسبة العرض إلى الارتفاع. يتم استخدام الصورة الأولى فقط من دفعة الإدخال. | IMAGE | لا |  |
| `الإطار الأخير` | صورة اختيارية تُستخدم كإطار أخير للفيديو. يتم قصّها لتغطية اللوحة مع الحفاظ على نسبة العرض إلى الارتفاع. يتم استخدام الصورة الأولى فقط من دفعة الإدخال. | IMAGE | لا |  |

عند توفير `first_frame` و/أو `last_frame`، يتم ترميز صور الإطارات المفتاحية باستخدام VAE وإرفاقها بالتكييف عند الإطار 0 وعند الإطار الأخير، على التوالي. وعند عدم توفير أي منهما، تعمل العقدة من النص وحده.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|--------------|
| `إيجابي` | تكييف يحتوي على النص المُرمّز، وعند توفير صور الإطارات المفتاحية، يحتوي أيضًا على الإطارات المفتاحية المُرمّزة وعدد الإطارات لنموذج MiniMax H3. | CONDITIONING |
| `latent` | كامن فارغ يمثل الفيديو المراد توليده، بالأبعاد المطلوبة (العرض والارتفاع) وعدد الإطارات المطلوب. | LATENT |
