# تحويل صورة MiniMax H3 إلى فيديو

هذه العقدة تجهّز التهيئة الشرطية والكامن الفارغ اللازمين لإنشاء فيديو باستخدام نموذج MiniMax H3. تأخذ مطالبة نصية، واختياريًا صورًا للإطار الأول و/أو الأخير من الفيديو، وتحوّلها إلى مدخلات النموذج. يتم تغيير حجم صور الإطارات المفتاحية وترميزها وإرفاقها بالتهيئة الشرطية في بداية الفيديو ونهايته.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لترميز المطالبة إلى رموز (tokenize) وترميز صور الإطارات المفتاحية إلى التهيئة الشرطية. | CLIP | نعم |  |
| `vae` | نموذج VAE المستخدم لترميز صور الإطارات المفتاحية إلى الفضاء الكامن عند توفير صور الإطارات المفتاحية. | VAE | نعم |  |
| `prompt` | مطالبة نصية تصف الفيديو المطلوب إنشاؤه. تدعم أسطرًا متعددة والمطالبات الديناميكية. | STRING | نعم |  |
| `العرض` | عرض الفيديو بالبكسل (الافتراضي: 1344). | INT | نعم | 32 to MAX_RESOLUTION (خطوة: 32) |
| `الارتفاع` | ارتفاع الفيديو بالبكسل (الافتراضي: 768). | INT | نعم | 32 to MAX_RESOLUTION (خطوة: 32) |
| `الطول` | عدد الإطارات عند 24 إطارًا في الثانية، ويُقرّب لأعلى إلى شبكة النموذج 17k+5 (124 = ~5 ثوانٍ؛ النطاق المدرّب هو ~124-362، والقيم الأطول غير مختبرة) (الافتراضي: 124). | INT | نعم | 5 إلى 3600 (خطوة: 17) |
| `الإطار الأول` | صورة اختيارية تُستخدم كأول إطار في الفيديو. يتم تمديدها إلى حجم اللوحة الكامل، لذا لا يتم الحفاظ على نسبة أبعادها. تُستخدم فقط الصورة الأولى من دفعة الإدخال. | IMAGE | لا |  |
| `الإطار الأخير` | صورة اختيارية تُستخدم كآخر إطار في الفيديو. يتم قصّها لتغطية اللوحة مع الحفاظ على نسبة أبعادها. تُستخدم فقط الصورة الأولى من دفعة الإدخال. | IMAGE | لا |  |

عند توفير `first_frame` و/أو `last_frame`، يتم ترميز صور الإطارات المفتاحية باستخدام VAE وإرفاقها بالتهيئة الشرطية عند الإطار 0 وعند الإطار الأخير على التوالي. وعندما لا يتم توفير أي منهما، تعمل العقدة اعتمادًا على المطالبة وحدها. يتم تقريب `length` المطلوب لأعلى إلى أقرب عدد إطارات صالح (17k + 5)، لذا قد يكون عدد الإطارات الفعلي أعلى قليلاً من المطلوب.

يتم إنشاء الكامن الصوتي والمرئي كزوج فارغ يطابق `width` و`height` المطلوبين وعدد الإطارات المقرّب. يتم تحديد حجم الجزء الصوتي من عدد الإطارات نفسه بمعدل 40 إطارًا صوتيًا في الثانية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | التهيئة الشرطية التي تحتوي على المطالبة المرمّزة، وعند توفير صور الإطارات المفتاحية، تحتوي على الإطارات المفتاحية المرمّزة وعدد الإطارات لنموذج MiniMax H3. | CONDITIONING |
| `latent` | الكامن الصوتي والمرئي الفارغ الذي يمثل المحتوى المطلوب إنشاؤه، بالعرض والارتفاع وعدد الإطارات المطلوبة. | LATENT |
