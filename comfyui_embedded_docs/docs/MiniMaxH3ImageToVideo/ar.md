# تحويل صورة MiniMax H3 إلى فيديو

تُحضّر هذه العقدة التكييف (conditioning) والكامن الفارغ (latent) اللازمين لتوليد فيديو باستخدام نموذج MiniMax H3. تأخذ نصًا وصفيًا (prompt)، وصورًا اختيارية للإطار الأول و/أو الأخير من الفيديو، وتحوّلها إلى مدخلات للنموذج. تُغيَّر أبعاد صور الإطارات الرئيسية، وتُرمَّز، ثم تُرفق بالتكييف في بداية الفيديو ونهايته.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لتقطيع النص وترميز الصور الرئيسية إلى تكييف. | CLIP | نعم |  |
| `vae` | نموذج VAE المستخدم لترميز الصور الرئيسية إلى الفضاء الكامن عند توفير صور الإطارات الرئيسية. | VAE | نعم |  |
| `prompt` | النص الوصفي الذي يصف الفيديو المراد توليده. يدعم أسطرًا متعددة ونصوصًا ديناميكية. | STRING | نعم |  |
| `العرض` | عرض الفيديو بالبكسل (الافتراضي: 1344). | INT | نعم | 32 to MAX_RESOLUTION (step 32) |
| `الارتفاع` | ارتفاع الفيديو بالبكسل (الافتراضي: 768). | INT | نعم | 32 to MAX_RESOLUTION (step 32) |
| `الطول` | عدد الإطارات بمعدل 24 إطارًا في الثانية، ويُقرَّب لأعلى إلى شبكة 17k+5 الخاصة بالنموذج (124 ≈ 5 ثوانٍ؛ النطاق المدرب هو حوالي 124-362، وطول المدة الزائدة لم يُختبر) (الافتراضي: 124). | INT | نعم | 5 إلى 3600 (step 17) |
| `الإطار الأول` | صورة اختيارية تُستخدم كأول إطار في الفيديو. تُمدَّد إلى كامل مساحة اللوحة، لذلك لا تُحافظ على نسبة العرض إلى الارتفاع. يُستخدم أول صورة فقط من دفعة الإدخال. | IMAGE | لا |  |
| `الإطار الأخير` | صورة اختيارية تُستخدم كآخر إطار في الفيديو. تُقصّ لتغطية اللوحة مع الحفاظ على نسبة العرض إلى الارتفاع. يُستخدم أول صورة فقط من دفعة الإدخال. | IMAGE | لا |  |

عند توفير `first_frame` و/أو `last_frame`، تُرمَّز صور الإطارات الرئيسية باستخدام VAE وتُرفق بالتكييف عند الإطار 0 وعند الإطار الأخير، على التوالي. وفي حالة عدم توفير أي منهما، تعمل العقدة على النص الوصفي وحده. ويُقرَّب `length` المطلوب إلى أعلى إلى أقرب عدد إطارات صالح (17k + 5)، لذا قد يكون عدد الإطارات الفعلي أعلى قليلاً من المطلوب.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `إيجابي` | تكييف يحتوي على النص المشفَّر، وعند توفير صور الإطارات الرئيسية، يحتوي أيضًا على الإطارات الرئيسية المشفَّرة وعدد الإطارات الخاص بنموذج MiniMax H3. | CONDITIONING |
| `latent` | كامن صوتي-فيديو فارغ يمثل المحتوى المراد توليده، بالعرض والارتفاع وعدد الإطارات المطلوبة. | LATENT |
