# تحويل صورة MiniMax H3 إلى فيديو

MiniMax H3 Image to Video يُحضّر التكييف (conditioning) والفضاء الكامن الفارغ اللازمين لتوليد فيديو باستخدام نموذج MiniMax H3. يأخذ العقدة (Node) مطالبة نصية، وبشكل اختياري صورًا للإطار الأول و/أو الأخير من الفيديو، ويحوّلها إلى مدخلات النموذج. يتم تغيير حجم صور الإطارات المفتاحية، وترميزها، وإرفاقها بالتكييف في بداية الفيديو ونهايته.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لتحويل المطالبة إلى رموز (tokenize) وترميز صور الإطارات المفتاحية إلى تكييف. | CLIP | نعم |  |
| `vae` | نموذج VAE المستخدم لترميز صور الإطارات المفتاحية إلى الفضاء الكامن عند توفّر صور الإطارات المفتاحية. | VAE | نعم |  |
| `prompt` | مطالبة نصية تصف الفيديو المراد إنشاؤه. تدعم عدة أسطر والمطالبات الديناميكية. | STRING | نعم |  |
| `width` | عرض الفيديو بالبكسل (الافتراضي: 1344). | INT | نعم | 32 إلى MAX_RESOLUTION (الخطوة 32) |
| `height` | ارتفاع الفيديو بالبكسل (الافتراضي: 768). | INT | نعم | 32 إلى MAX_RESOLUTION (الخطوة 32) |
| `length` | عدد الإطارات عند 24 إطارًا في الثانية، ويُقرَّب لأعلى وفقًا لشبكة النموذج 17k+5 (124 ≈ 5 ثوانٍ؛ النطاق المُدرَّب عليه حوالي 124-362، وما زاد عن ذلك غير مُختبَر) (الافتراضي: 124). | INT | نعم | 5 إلى 3600 (الخطوة 17) |
| `first_frame` | صورة اختيارية تُستخدم كإطار أول للفيديو. يتم تمديدها لملء حجم اللوحة بالكامل، لذلك لا يتم الحفاظ على نسبة العرض إلى الارتفاع. يُستخدم فقط أول صورة من مجموعة الإدخال. | IMAGE | لا |  |
| `last_frame` | صورة اختيارية تُستخدم كإطار أخير للفيديو. يتم قصها لتغطية اللوحة مع الحفاظ على نسبة العرض إلى الارتفاع. يُستخدم فقط أول صورة من مجموعة الإدخال. | IMAGE | لا |  |

عند توفير `first_frame` و/أو `last_frame`، يتم ترميز صور الإطارات المفتاحية بواسطة VAE وإرفاقها بالتكييف عند الإطار 0 وفي الإطار الأخير، على التوالي. عندما لا يتم توفير أي منهما، تعمل العقدة من المطالبة وحدها.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | تكييف يحتوي على المطالبة المشفرة، وعند توفير صور الإطارات المفتاحية، الإطارات المفتاحية المشفرة الموضوعة في الإطار الأول والأخير من الفيديو لنموذج MiniMax H3. | CONDITIONING |
| `latent` | فضاء كامن فارغ يمثل الفيديو والمسار الصوتي المصاحب له المراد إنشاؤه، بالعرض والارتفاع وعدد الإطارات المطلوبة. | LATENT |
