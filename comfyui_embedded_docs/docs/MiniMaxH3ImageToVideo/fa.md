# تبدیل تصویر به ویدیو MiniMax H3

این گره، conditioning و latent خالی لازم برای تولید ویدیو با مدل MiniMax H3 را آماده می‌کند. این گره یک prompt متنی و در صورت نیاز، تصاویری برای فریم اول و/یا آخر ویدیو دریافت کرده و آن‌ها را به ورودی‌های مدل تبدیل می‌کند. تصاویر کلیدی (keyframe) تغییر اندازه داده شده، کدگذاری می‌شوند و در ابتدا و انتهای ویدیو به conditioning متصل می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکنایز کردن prompt و کدگذاری تصاویر کلیدی به conditioning استفاده می‌شود. | CLIP | بله |  |
| `vae` | مدل VAE که در صورت ارائه تصاویر کلیدی، برای کدگذاری این تصاویر به فضای latent استفاده می‌شود. | VAE | بله |  |
| `پرامپت` | متن prompt توصیف‌کننده ویدیویی که تولید می‌شود. از چند خط و promptهای پویا پشتیبانی می‌کند. | STRING | بله |  |
| `عرض` | عرض ویدیو به پیکسل (پیش‌فرض: 1344). | INT | بله | 32 to MAX_RESOLUTION (step 32) |
| `ارتفاع` | ارتفاع ویدیو به پیکسل (پیش‌فرض: 768). | INT | بله | 32 to MAX_RESOLUTION (step 32) |
| `طول` | تعداد فریم در 24 فریم بر ثانیه، به سمت بالا به نزدیک‌ترین مقدار معتبر در الگوی 17k+5 مدل گرد می‌شود (124 ≈ ~5 ثانیه؛ محدوده آموزش‌دیده حدود 124-362 است؛ مقادیر طولانی‌تر آزمایش نشده‌اند) (پیش‌فرض: 124). | INT | بله | 5 تا 3600 (step 17) |
| `اولین فریم` | تصویر اختیاری که به عنوان فریم اول ویدیو استفاده می‌شود. این تصویر به اندازه کل بوم کشیده می‌شود، بنابراین نسبت تصویر آن حفظ نمی‌شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |
| `آخرین فریم` | تصویر اختیاری که به عنوان فریم آخر ویدیو استفاده می‌شود. این تصویر به‌گونه‌ای برش داده می‌شود که کل بوم را بپوشاند و در عین حال نسبت تصویر آن حفظ شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |

هنگامی که `first_frame` و/یا `last_frame` ارائه شوند، تصاویر کلیدی با VAE کدگذاری شده و به ترتیب به conditioning در فریم 0 و فریم نهایی متصل می‌شوند. اگر هیچ‌کدام ارائه نشود، این گره تنها از روی prompt کار می‌کند. مقدار درخواستی `length` به نزدیک‌ترین تعداد فریم معتبر (17k + 5) به سمت بالا گرد می‌شود، بنابراین تعداد فریم مؤثر ممکن است کمی بیشتر از مقدار درخواستی باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مثبت` | Conditioning شامل prompt کدگذاری‌شده و، در صورت ارائه تصاویر کلیدی، فریم‌های کلیدی کدگذاری‌شده و تعداد فریم برای مدل MiniMax H3. | CONDITIONING |
| `latent` | latent خالی صوتی-تصویری که محتوای موردنظر برای تولید را با عرض، ارتفاع و تعداد فریم درخواستی نمایش می‌دهد. | LATENT |
