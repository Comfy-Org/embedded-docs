# تبدیل تصویر به ویدیو MiniMax H3

این گره، conditioning و latent خالی موردنیاز برای تولید ویدئو با مدل MiniMax H3 را آماده می‌کند. یک prompt متنی و به‌صورت اختیاری تصاویری برای اولین و/یا آخرین فریم ویدئو دریافت می‌کند و آن‌ها را به ورودی‌های مدل تبدیل می‌کند. تصاویر کی‌فریم تغییر اندازه داده می‌شوند، رمزگذاری می‌شوند و در ابتدا و انتهای ویدئو به conditioning متصل می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌سازی prompt و رمزگذاری تصاویر کی‌فریم به conditioning استفاده می‌شود. | CLIP | بله |  |
| `vae` | مدل VAE که هنگام ارائه تصاویر کی‌فریم، برای رمزگذاری آن‌ها به فضای latent استفاده می‌شود. | VAE | بله |  |
| `prompt` | prompt متنی که ویدئوی موردنظر برای تولید را توصیف می‌کند. از چند خط و promptهای پویا پشتیبانی می‌کند. | STRING | بله |  |
| `width` | عرض ویدئو بر حسب پیکسل (پیش‌فرض: 1344). | INT | بله | 32 تا MAX_RESOLUTION (گام 32) |
| `height` | ارتفاع ویدئو بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 32 تا MAX_RESOLUTION (گام 32) |
| `length` | تعداد فریم در 24 fps، که به نزدیک‌ترین مقدار بالاتر در شبکه 17k+5 مدل گرد می‌شود (124 = ~5s؛ محدوده آموزش‌دیده حدود 124-362 است؛ مقادیر طولانی‌تر آزمایش نشده‌اند) (پیش‌فرض: 124). | INT | بله | 5 تا 3600 (گام 17) |
| `first_frame` | تصویر اختیاری که به عنوان اولین فریم ویدئو استفاده می‌شود. تا اندازه کامل بوم کشیده می‌شود، بنابراین نسبت تصویر آن حفظ نمی‌شود. تنها اولین تصویر از batch ورودی استفاده می‌شود. | IMAGE | خیر |  |
| `last_frame` | تصویر اختیاری که به عنوان آخرین فریم ویدئو استفاده می‌شود. برای پوشش بوم برش داده می‌شود و در همان حال نسبت تصویر آن حفظ می‌شود. تنها اولین تصویر از batch ورودی استفاده می‌شود. | IMAGE | خیر |  |

وقتی `first_frame` و/یا `last_frame` ارائه شوند، تصاویر کی‌فریم با VAE رمزگذاری می‌شوند و به‌ترتیب در فریم 0 و فریم نهایی به conditioning متصل می‌شوند. وقتی هیچ‌یک ارائه نشود، گره تنها بر اساس prompt کار می‌کند. مقدار درخواستی `length` به نزدیک‌ترین تعداد فریم معتبر بالاتر (17k + 5) گرد می‌شود؛ بنابراین تعداد فریم مؤثر ممکن است کمی بیشتر از مقدار درخواستی باشد.

latent صوتی-تصویری به‌صورت یک جفت خالی منطبق با `width`، `height` و تعداد فریم گردشده ایجاد می‌شود. بخش صوتی بر اساس همان تعداد فریم و با 40 فریم صوتی در ثانیه اندازه‌گذاری می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | conditioning حاوی prompt رمزگذاری‌شده و، در صورت ارائه تصاویر کی‌فریم، کی‌فریم‌های رمزگذاری‌شده و تعداد فریم برای مدل MiniMax H3. | CONDITIONING |
| `latent` | latent خالی صوتی-تصویری که نمایانگر محتوای موردتولید است، با عرض، ارتفاع و تعداد فریم درخواستی. | LATENT |
