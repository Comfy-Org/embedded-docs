# تبدیل تصویر به ویدیو MiniMax H3

این گره، شرطیسازی و لاتنت خالی موردنیاز برای تولید ویدیو با مدل MiniMax H3 را آماده میکند. این گره یک پرامپت متنی و بهصورت اختیاری، تصاویری برای فریم اول و/یا آخر ویدیو دریافت کرده و آنها را به ورودیهای مدل تبدیل میکند. تصاویر کلیدفریم تغییر اندازه داده میشوند، کدگذاری شده و در ابتدا و انتهای ویدیو به شرطیسازی متصل میشوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکنایز کردن پرامپت و کدگذاری تصاویر کلیدفریم به شرطیسازی استفاده می‌شود. | CLIP | بله |  |
| `vae` | مدل VAE که در صورت ارائه تصاویر کلیدفریم، برای کدگذاری آن‌ها به فضای لاتنت استفاده می‌شود. | VAE | بله |  |
| `پرامپت` | پرامپت متنی که ویدیوی موردنظر برای تولید را توصیف می‌کند. از چند خط و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله |  |
| `عرض` | عرض ویدیو بر حسب پیکسل (پیش‌فرض: 1344). | INT | بله | 32 تا MAX_RESOLUTION (گام 32) |
| `ارتفاع` | ارتفاع ویدیو بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 32 تا MAX_RESOLUTION (گام 32) |
| `طول` | تعداد فریم در ۲۴ فریم بر ثانیه، که به سمت بالا به شبکه 17k+5 مدل گرد می‌شود (۱۲۴ ≈ ۵ ثانیه؛ محدوده آموزش‌دیده تقریباً ۱۲۴ تا ۳۶۲ است؛ مقادیر بیشتر آزمایش نشده‌اند) (پیش‌فرض: ۱۲۴). | INT | بله | 5 تا 3600 (گام 17) |
| `اولین فریم` | تصویر اختیاری که به‌عنوان فریم اول ویدیو استفاده می‌شود. به اندازه کل بوم کشیده می‌شود، بنابراین نسبت تصویر آن حفظ نمی‌شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |
| `آخرین فریم` | تصویر اختیاری که به‌عنوان فریم آخر ویدیو استفاده می‌شود. برای پوشش کامل بوم بریده می‌شود و نسبت تصویر آن حفظ می‌شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |

هنگامی که `first_frame` و/یا `last_frame` ارائه شوند، تصاویر کلیدفریم با VAE کدگذاری شده و به‌ترتیب به شرطی‌سازی در فریم ۰ و فریم نهایی متصل می‌شوند. وقتی هیچ‌کدام ارائه نشوند، گره تنها با پرامپت کار می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| positive | شرطی‌سازی حاوی پرامپت کدگذاری‌شده و، در صورت ارائه تصاویر کلیدفریم، کلیدفریم‌های کدگذاری‌شده و تعداد فریم برای مدل MiniMax H3. | CONDITIONING |
| latent | لاتنت خالی نمایانگر ویدیوی موردنظر برای تولید، با عرض، ارتفاع و تعداد فریم درخواستی. | LATENT |
