# تبدیل تصویر به ویدیو MiniMax H3

### MiniMax H3 Image to Video

گره MiniMax H3 Image to Video، آماده‌سازی conditioning و latent خالی موردنیاز برای تولید ویدیو با مدل MiniMax H3 را انجام می‌دهد. این گره یک متن prompt و در صورت نیاز، تصاویری برای فریم اول و/یا آخر ویدیو دریافت کرده و آن‌ها را به ورودی‌های مدل تبدیل می‌کند. تصاویر کلیدفریم تغییر اندازه داده شده، کدگذاری شده و در ابتدا و انتهای ویدیو به conditioning متصل می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌سازی prompt و کدگذاری تصاویر کلیدفریم به conditioning استفاده می‌شود. | CLIP | بله |  |
| `vae` | مدل VAE که برای کدگذاری تصاویر کلیدفریم به فضای latent در هنگام ارائه تصاویر کلیدفریم استفاده می‌شود. | VAE | بله |  |
| `prompt` | متن prompt توصیف‌کننده ویدیوی موردنظر برای تولید. از چند خط و promptهای پویا پشتیبانی می‌کند. | STRING | بله |  |
| `width` | عرض ویدیو به پیکسل (پیش‌فرض: 1344). | INT | بله | 32 to MAX_RESOLUTION (step 32) |
| `height` | ارتفاع ویدیو به پیکسل (پیش‌فرض: 768). | INT | بله | 32 to MAX_RESOLUTION (step 32) |
| `length` | تعداد فریم در 24 فریم بر ثانیه، به شبکه 17k+5 مدل گرد می‌شود (124 ≈ 5 ثانیه؛ محدوده آموزش‌دیده حدود 124-362 است، بیشتر از آن آزمایش نشده) (پیش‌فرض: 124). | INT | بله | 5 to 3600 (step 17) |
| `first_frame` | تصویر اختیاری که به عنوان فریم اول ویدیو استفاده می‌شود. به اندازه کامل بوم کشیده می‌شود، بنابراین نسبت تصویر آن حفظ نمی‌شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |
| `last_frame` | تصویر اختیاری که به عنوان فریم آخر ویدیو استفاده می‌شود. به گونه‌ای برش می‌خورد که بوم را بپوشاند و نسبت تصویر آن حفظ شود. فقط اولین تصویر از دسته ورودی استفاده می‌شود. | IMAGE | خیر |  |

هنگامی که `first_frame` و/یا `last_frame` ارائه شوند، تصاویر کلیدفریم با VAE کدگذاری شده و به ترتیب در فریم ۰ و فریم پایانی به conditioning متصل می‌شوند. اگر هیچ‌کدام ارائه نشوند، گره تنها بر اساس prompt کار می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | Conditioning حاوی prompt کدگذاری‌شده و، در صورت ارائه تصاویر کلیدفریم، کلیدفریم‌های کدگذاری‌شده در فریم‌های اول و آخر ویدیو برای مدل MiniMax H3. | CONDITIONING |
| `latent` | latent خالی نمایانگر ویدیو و ترک صوتی همراه آن که قرار است تولید شود، با عرض، ارتفاع و تعداد فریم درخواستی. | LATENT |
