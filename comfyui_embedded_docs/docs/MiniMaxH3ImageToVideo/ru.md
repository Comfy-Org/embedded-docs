# MiniMax H3: изображение в видео

Этот узел подготавливает conditioning и пустой latent, необходимые для генерации видео с помощью модели MiniMax H3. Он принимает текстовый промпт и, при необходимости, изображения для первого и/или последнего кадра видео и преобразует их во входы модели. Изображения ключевых кадров изменяются в размере, кодируются и прикрепляются к conditioning в начале и конце видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | CLIP-модель, используемая для токенизации промпта и кодирования изображений ключевых кадров в conditioning. | CLIP | Да |  |
| `vae` | VAE-модель, используемая для кодирования изображений ключевых кадров в латентное пространство, когда предоставлены изображения ключевых кадров. | VAE | Да |  |
| `prompt` | Текстовый промпт, описывающий видео для генерации. Поддерживает несколько строк и динамические промпты. | STRING | Да |  |
| `ширина` | Ширина видео в пикселях (по умолчанию: 1344). | INT | Да | от 32 до MAX_RESOLUTION (шаг 32) |
| `высота` | Высота видео в пикселях (по умолчанию: 768). | INT | Да | от 32 до MAX_RESOLUTION (шаг 32) |
| `длина` | Количество кадров при 24 кадрах/с, округляемое вверх до сетки 17k+5 модели (124 = ~5 с; обученный диапазон — ~124-362, более длинные значения не тестировались) (по умолчанию: 124). | INT | Да | от 5 до 3600 (шаг 17) |
| `первый_кадр` | Необязательное изображение, используемое как первый кадр видео. Оно растягивается до полного размера холста, поэтому его пропорции не сохраняются. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |
| `последний_кадр` | Необязательное изображение, используемое как последний кадр видео. Оно обрезается так, чтобы покрыть холст, сохраняя пропорции. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |

Когда указаны `first_frame` и/или `last_frame`, изображения ключевых кадров кодируются с помощью VAE и прикрепляются к conditioning в кадре 0 и в последнем кадре соответственно. Если ни одно из них не указано, узел работает только с промптом. Запрошенное значение `length` округляется вверх до ближайшего допустимого количества кадров (17k + 5), поэтому фактическое количество кадров может быть немного больше запрошенного.

Аудио-видео latent создаётся как пустая пара, соответствующая запрошенным `width`, `height` и округлённому количеству кадров. Размер аудиочасти рассчитывается из того же количества кадров при 40 аудиокадрах в секунду.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Conditioning, содержащий закодированный промпт и, когда предоставлены изображения ключевых кадров, закодированные ключевые кадры и количество кадров для модели MiniMax H3. | CONDITIONING |
| `latent` | Пустой аудио-видео latent, представляющий генерируемое содержимое, с запрошенными шириной, высотой и количеством кадров. | LATENT |
