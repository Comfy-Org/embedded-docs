# MiniMax H3: изображение в видео

MiniMax H3 Image to Video подготавливает кондиционирование и пустой латент, необходимые для генерации видео с помощью модели MiniMax H3. Он принимает текстовый запрос и, опционально, изображения для первого и/или последнего кадра видео и преобразует их во входные данные модели. Ключевые кадры изменяются, кодируются и добавляются к кондиционированию в начале и конце видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации запроса и кодирования ключевых кадров изображений в кондиционирование. | CLIP | Да |  |
| `vae` | Модель VAE, используемая для кодирования ключевых кадров изображений в латентное пространство, когда предоставлены изображения ключевых кадров. | VAE | Да |  |
| `prompt` | Текстовый запрос, описывающий видео для генерации. Поддерживает многострочный ввод и динамические запросы. | STRING | Да |  |
| `width` | Ширина видео в пикселях (по умолчанию: 1344). | INT | Да | от 32 до MAX_RESOLUTION (шаг 32) |
| `height` | Высота видео в пикселях (по умолчанию: 768). | INT | Да | от 32 до MAX_RESOLUTION (шаг 32) |
| `length` | Количество кадров при 24 кадрах в секунду, округляется вверх до сетки модели 17k+5 (124 = ~5 с; обученный диапазон ~124-362, более длинные не тестировались) (по умолчанию: 124). | INT | Да | от 5 до 3600 (шаг 17) |
| `first_frame` | Необязательное изображение, используемое в качестве первого кадра видео. Оно растягивается на весь размер холста, поэтому его соотношение сторон не сохраняется. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |
| `last_frame` | Необязательное изображение, используемое в качестве последнего кадра видео. Оно обрезается так, чтобы заполнить холст, сохраняя при этом соотношение сторон. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |

Когда предоставлены `first_frame` и/или `last_frame`, изображения ключевых кадров кодируются с помощью VAE и добавляются к кондиционированию на кадре 0 и на последнем кадре соответственно. Если ни одно из них не предоставлено, узел работает только на основе запроса.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондиционирование, содержащее закодированный запрос и, при наличии изображений ключевых кадров, закодированные ключевые кадры, расположенные на первом и последнем кадрах видео для модели MiniMax H3. | CONDITIONING |
| `latent` | Пустой латент, представляющий видео и сопутствующую аудиодорожку для генерации, с запрошенными шириной, высотой и количеством кадров. | LATENT |
