# MiniMax H3: изображение в видео

Этот узел подготавливает conditioning и пустой latent, необходимые для генерации видео с помощью модели MiniMax H3. Он принимает текстовый промпт и, опционально, изображения для первого и/или последнего кадра видео и преобразует их во входные данные модели. Изображения ключевых кадров изменяются по размеру, кодируются и прикрепляются к conditioning в начале и конце видео.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования изображений ключевых кадров в conditioning. | CLIP | Да |  |
| `vae` | Модель VAE, используемая для кодирования изображений ключевых кадров в латентное пространство, когда предоставлены изображения ключевых кадров. | VAE | Да |  |
| `prompt` | Текстовый промпт, описывающий видео для генерации. Поддерживает несколько строк и динамические промпты. | STRING | Да |  |
| `ширина` | Ширина видео в пикселях (по умолчанию: 1344). | INT | Да | 32 до MAX_RESOLUTION (шаг 32) |
| `высота` | Высота видео в пикселях (по умолчанию: 768). | INT | Да | 32 до MAX_RESOLUTION (шаг 32) |
| `длина` | Количество кадров при 24 кадрах в секунду, округляется вверх до сетки модели 17k+5 (124 = ~5 с; обученный диапазон ~124-362, более длинные не тестировались) (по умолчанию: 124). | INT | Да | 5 до 3600 (шаг 17) |
| `первый_кадр` | Необязательное изображение, используемое в качестве первого кадра видео. Оно растягивается на весь размер холста, поэтому его соотношение сторон не сохраняется. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |
| `последний_кадр` | Необязательное изображение, используемое в качестве последнего кадра видео. Оно обрезается, чтобы заполнить холст, сохраняя соотношение сторон. Используется только первое изображение из входного пакета. | IMAGE | Нет |  |

Когда предоставлены `first_frame` и/или `last_frame`, изображения ключевых кадров кодируются с помощью VAE и присоединяются к conditioning на кадре 0 и на последнем кадре соответственно. Если не предоставлено ни одного, узел работает только на основе промпта.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `позитивный` | Conditioning, содержащее закодированный промпт и, когда предоставлены изображения ключевых кадров, закодированные ключевые кадры и количество кадров для модели MiniMax H3. | CONDITIONING |
| `latent` | Пустой latent, представляющий видео для генерации, с запрошенными шириной, высотой и количеством кадров. | LATENT |
