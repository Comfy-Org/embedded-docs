# MiniMax H3 圖片轉影片

此節點準備使用 MiniMax H3 模型生成影片所需的條件（conditioning）與空潛在變量（latent）。它接受文字提示，以及可選的影片首幀和/或末幀圖像，並將它們轉換為模型輸入。關鍵幀圖像會被調整大小、編碼，並在影片開頭與結尾附加至條件中。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用於對提示進行分詞，並將關鍵幀圖像編碼為條件的 CLIP 模型。 | CLIP | 是 |  |
| `vae` | 在提供關鍵幀圖像時，用於將關鍵幀圖像編碼至潛在空間的 VAE 模型。 | VAE | 是 |  |
| `提示詞` | 描述要生成影片的文字提示。支援多行與動態提示。 | STRING | 是 |  |
| `寬度` | 影片的寬度（像素），預設值：1344。 | INT | 是 | 32 至 MAX_RESOLUTION (步長 32) |
| `高度` | 影片的高度（像素），預設值：768。 | INT | 是 | 32 至 MAX_RESOLUTION (步長 32) |
| `長度` | 以 24 fps 計的幀數，會對齊至模型的 17k+5 網格（124 約為 5 秒；訓練範圍約為 124-362，更長未測試），預設值：124。 | INT | 是 | 5 至 3600 (步長 17) |
| `首幀` | 可選的圖像，用作影片的第一幀。它會被拉伸至整個畫布大小，因此不保留長寬比。僅使用輸入批次中的第一張圖像。 | IMAGE | 否 |  |
| `末幀` | 可選的圖像，用作影片的最後一幀。它會被裁剪以覆蓋畫布，同時保留其長寬比。僅使用輸入批次中的第一張圖像。 | IMAGE | 否 |  |

當提供了 `first_frame` 和/或 `last_frame` 時，關鍵幀圖像會使用 VAE 編碼，並分別附加至第 0 幀與最後一幀的條件中。當兩者皆未提供時，節點僅依據提示運作。
