# MiniMax H3 圖片轉影片

此節點準備使用 MiniMax H3 模型生成影片所需的 conditioning 和空的 latent。它接受文字提示，以及可選的影片首幀和/或尾幀圖像，並將其轉換為模型輸入。關鍵幀圖像會被調整大小、編碼，並附加到影片開頭和結尾的 conditioning 中。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `clip` | CLIP 模型，用於將提示詞進行分詞，並將關鍵幀圖像編碼到 conditioning 中。 | CLIP | 是 |  |
| `vae` | 當提供關鍵幀圖像時，用於將關鍵幀圖像編碼到潛在空間（latent space）的 VAE 模型。 | VAE | 是 |  |
| `提示詞` | 描述要生成之影片的文字提示。支援多行和動態提示。 | STRING | 是 |  |
| `寬度` | 影片的寬度（像素，預設值：1344）。 | INT | 是 | 32 至 MAX_RESOLUTION（步長 32） |
| `高度` | 影片的高度（像素，預設值：768）。 | INT | 是 | 32 至 MAX_RESOLUTION（步長 32） |
| `長度` | 以 24 fps 計算的幀數，會向上對齊至模型的 17k+5 格（124 ≈ 5 秒；訓練範圍約為 124-362，超出範圍未經測試）（預設值：124）。 | INT | 是 | 5 至 3600（步長 17） |
| `首幀` | 可選圖像，用作影片的首幀。此圖像會被拉伸至完整畫布大小，因此不會保留其寬高比。僅使用輸入批次中的第一張圖像。 | IMAGE | 否 |  |
| `末幀` | 可選圖像，用作影片的尾幀。此圖像會以保留寬高比的方式裁剪並覆蓋畫布。僅使用輸入批次中的第一張圖像。 | IMAGE | 否 |  |

當提供 `first_frame` 和/或 `last_frame` 時，關鍵幀圖像會使用 VAE 進行編碼，並分別附加到第 0 幀和最後一幀的 conditioning 中。若兩者皆未提供，則此節點僅根據提示詞進行運作。請求的 `length` 會向上對齊至最接近的有效幀數（17k + 5），因此實際幀數可能會略高於請求值。
