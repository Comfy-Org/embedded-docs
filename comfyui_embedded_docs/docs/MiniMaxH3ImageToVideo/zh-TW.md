# MiniMax H3 圖片轉影片

此節點會準備使用 MiniMax H3 模型生成影片所需的條件資料與空白潛在空間。它接收文字提示，以及可選的影片第一影格及/或最後影格影像，並將其轉換為模型輸入。關鍵影格影像會經過縮放、編碼，並在影片開頭與結尾附加到條件資料。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用於將提示分詞，並將關鍵影格影像編碼為條件資料的 CLIP 模型。 | CLIP | 是 |  |
| `vae` | 當提供關鍵影格影像時，用於將關鍵影格影像編碼至潛在空間的 VAE 模型。 | VAE | 是 |  |
| `提示詞` | 描述要生成影片的文字提示。支援多行與動態提示。 | STRING | 是 |  |
| `寬度` | 影片寬度，單位為像素（預設：1344）。 | INT | 是 | 32 to MAX_RESOLUTION （步進值：32） |
| `高度` | 影片高度，單位為像素（預設：768）。 | INT | 是 | 32 to MAX_RESOLUTION （步進值：32） |
| `長度` | 以 24 fps 計算的影格數，會向上對齊至模型的 17k+5 網格（124 = 約 5 秒；訓練範圍為約 124-362，更長未經測試）（預設：124）。 | INT | 是 | 5 至 3600 （步進值：17） |
| `首幀` | 可選影像，用作影片的第一影格。它會拉伸至完整畫布大小，因此不會保留其長寬比。僅使用輸入批次中的第一張影像。 | IMAGE | 否 |  |
| `末幀` | 可選影像，用作影片的最後影格。它會裁切以覆蓋畫布，同時保留其長寬比。僅使用輸入批次中的第一張影像。 | IMAGE | 否 |  |

當提供 `first_frame` 及/或 `last_frame` 時，關鍵影格影像會使用 VAE 編碼，並分別附加到第 0 影格與最後影格的條件資料。當兩者皆未提供時，此節點只根據提示運作。請求的 `length` 會向上對齊至最接近的有效影格數（17k + 5），因此實際影格數可能略高於請求值。

音訊-視訊潛在空間會建立為空白配對，其尺寸符合請求的 `width`、`height` 以及對齊後的影格數。音訊部分的尺寸則依據相同影格數，以每秒 40 個音訊影格來計算。
