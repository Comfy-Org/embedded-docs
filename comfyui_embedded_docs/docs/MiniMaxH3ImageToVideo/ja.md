# MiniMax H3 画像から動画へ

MiniMax H3 Image to Video は、MiniMax H3 モデルでビデオを生成するために必要な条件付け（conditioning）と空の潜在変数を準備します。テキストプロンプトと、オプションでビデオの最初フレームおよび/または最後フレームの画像を受け取り、それらをモデル入力に変換します。キーフレーム画像はリサイズされ、エンコードされ、ビデオの先頭と末尾の条件付けに添付されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトをトークン化し、キーフレーム画像を条件付けにエンコードするために使用されるCLIPモデル。 | CLIP | はい |  |
| `vae` | キーフレーム画像が提供された場合に、キーフレーム画像を潜在空間にエンコードするために使用されるVAEモデル。 | VAE | はい |  |
| `prompt` | 生成するビデオを説明するテキストプロンプト。複数行と動的プロンプトに対応しています。 | STRING | はい |  |
| `width` | ビデオの幅（ピクセル単位）（デフォルト: 1344）。 | INT | はい | 32 to MAX_RESOLUTION (step 32) |
| `height` | ビデオの高さ（ピクセル単位）（デフォルト: 768）。 | INT | はい | 32 to MAX_RESOLUTION (step 32) |
| `length` | 24fpsでのフレーム数。モデルの17k+5グリッドに切り上げられます（124 = 約5秒。トレーニングされた範囲は約124〜362で、より長い場合は未テスト）（デフォルト: 124）。 | INT | はい | 5 to 3600 (step 17) |
| `first_frame` | ビデオの最初のフレームとして使用されるオプションの画像。キャンバス全体のサイズに引き伸ばされるため、アスペクト比は保持されません。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |
| `last_frame` | ビデオの最後のフレームとして使用されるオプションの画像。アスペクト比を保ちながらキャンバスを覆うようにクロップされます。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |

`first_frame` や `last_frame` が提供された場合、キーフレーム画像はVAEでエンコードされ、それぞれフレーム0と最終フレームの条件付けに添付されます。どちらも提供されない場合、ノードはプロンプトのみで動作します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | エンコードされたプロンプトと、キーフレーム画像が提供された場合は、ビデオの最初と最後のフレームに配置されたエンコード済みキーフレームを含む、MiniMax H3モデル用の条件付け。 | CONDITIONING |
| `latent` | 要求された幅、高さ、フレーム数を持つ、生成対象のビデオとそれに付随するオーディオトラックを表す空の潜在変数。 | LATENT |
