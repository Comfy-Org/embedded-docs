# PatchModelAddDownscale (Kohya Deep Shrink)

گره PatchModelAddDownscale عملکرد Kohya Deep Shrink را با اعمال عملیات کاهش‌مقیاس و افزایش‌مقیاس بر روی بلوک‌های خاصی از مدل پیاده‌سازی می‌کند. این گره وضوح ویژگی‌های میانی را در طول پردازش کاهش می‌دهد و سپس آن‌ها را به اندازه اصلی بازمی‌گرداند؛ این کار می‌تواند عملکرد را بهبود بخشد و کیفیت را حفظ کند. این گره امکان کنترل دقیق بر زمان و نحوه انجام این عملیات مقیاس‌بندی را در طول اجرای مدل فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که پچ کاهش‌مقیاس روی آن اعمال می‌شود | MODEL | بله | - |
| `block_number` | شماره بلوک خاصی که کاهش‌مقیاس روی آن اعمال می‌شود (پیش‌فرض: 3) | INT | خیر | 1-32 |
| `downscale_factor` | عاملی که ویژگی‌ها بر اساس آن کاهش مقیاس می‌یابند (پیش‌فرض: 2.0) | FLOAT | خیر | 0.1-9.0 |
| `start_percent` | نقطه شروع در فرآیند نویززدایی که کاهش‌مقیاس از آنجا آغاز می‌شود (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0-1.0 |
| `end_percent` | نقطه پایان در فرآیند نویززدایی که کاهش‌مقیاس در آنجا متوقف می‌شود (پیش‌فرض: 0.35) | FLOAT | خیر | 0.0-1.0 |
| `downscale_after_skip` | آیا کاهش‌مقیاس پس از اتصالات پرشی اعمال شود (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `downscale_method` | روش درون‌یابی مورد استفاده برای عملیات کاهش‌مقیاس | COMBO | خیر | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
| `upscale_method` | روش درون‌یابی مورد استفاده برای عملیات افزایش‌مقیاس | COMBO | خیر | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
