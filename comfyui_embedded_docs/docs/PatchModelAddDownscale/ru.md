# Добавить уменьшение модели патча (Kohya Deep Shrink)

Узел `PatchModelAddDownscale` реализует функциональность Kohya Deep Shrink, применяя операции уменьшения и увеличения масштаба к определённым блокам модели. Он снижает разрешение промежуточных признаков во время обработки, а затем восстанавливает их до исходного размера, что может повысить производительность при сохранении качества. Узел позволяет точно контролировать, когда и как выполняются эти операции масштабирования во время выполнения модели.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяется патч уменьшения масштаба | MODEL | Да | - |
| `block_number` | Номер конкретного блока, к которому будет применено уменьшение масштаба (по умолчанию: 3) | INT | Нет | 1-32 |
| `downscale_factor` | Коэффициент, на который уменьшаются признаки (по умолчанию: 2.0) | FLOAT | Нет | 0.1-9.0 |
| `start_percent` | Начальная точка процесса шумоподавления, с которой начинается уменьшение масштаба (по умолчанию: 0.0) | FLOAT | Нет | 0.0-1.0 |
| `end_percent` | Конечная точка процесса шумоподавления, на которой уменьшение масштаба останавливается (по умолчанию: 0.35) | FLOAT | Нет | 0.0-1.0 |
| `downscale_after_skip` | Применять ли уменьшение масштаба после пропускных соединений (по умолчанию: True) | BOOLEAN | Нет | - |
| `downscale_method` | Метод интерполяции, используемый для операций уменьшения масштаба | COMBO | Нет | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
| `upscale_method` | Метод интерполяции, используемый для операций увеличения масштаба | COMBO | Нет | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым патчем уменьшения масштаба | MODEL |
