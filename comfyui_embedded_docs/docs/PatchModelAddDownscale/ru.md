# Добавить уменьшение модели патча (Kohya Deep Shrink)

PatchModelAddDownscale (Kohya Deep Shrink) применяет технику Kohya Deep Shrink к модели, уменьшая промежуточные признаки в выбранном блоке и затем масштабируя их обратно до исходного размера. Уменьшение происходит только в выбранной части процесса удаления шума, что позволяет снизить вычислительные затраты, сохраняя конечный результат близким к исходному.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяется патч уменьшения масштаба | MODEL | Да | - |
| `номер_блока` | Конкретный номер блока, в котором будет применяться уменьшение масштаба (по умолчанию: 3) | INT | Да | 1-32 |
| `коэффициент_уменьшения` | Коэффициент, на который уменьшается масштаб признаков (по умолчанию: 2.0) | FLOAT | Да | 0.1-9.0 |
| `начальный_процент` | Начальная точка в процессе удаления шума, с которой начинается уменьшение масштаба (по умолчанию: 0.0) | FLOAT | Да | 0.0-1.0 |
| `конечный_процент` | Конечная точка в процессе удаления шума, в которой уменьшение масштаба прекращается (по умолчанию: 0.35) | FLOAT | Да | 0.0-1.0 |
| `уменьшение_после_пропуска` | Применять ли уменьшение масштаба после skip-соединений (по умолчанию: True) | BOOLEAN | Да | - |
| `метод_уменьшения` | Метод интерполяции, используемый для операций уменьшения масштаба (по умолчанию: "bicubic") | COMBO | Да | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
| `метод_увеличения` | Метод интерполяции, используемый для операций увеличения масштаба (по умолчанию: "bicubic") | COMBO | Да | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |

Патч уменьшения масштаба применяется только тогда, когда текущий шаг удаления шума попадает в диапазон, заданный `start_percent` и `end_percent`, и только в блоке, выбранном параметром `block_number`. Когда `downscale_after_skip` включён, патч применяется после skip-соединения; когда отключён — до skip-соединения. После этого признаки масштабируются обратно до исходного размера, но только если текущий размер признаков больше не совпадает с размером, зафиксированным перед уменьшением масштаба.

Параметры `block_number`, `start_percent`, `end_percent` и `downscale_after_skip` отмечены как расширенные параметры в интерфейсе узла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применённым патчем уменьшения масштаба | MODEL |
