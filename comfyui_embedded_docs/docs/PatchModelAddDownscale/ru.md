# Добавить уменьшение модели патча (Kohya Deep Shrink)

PatchModelAddDownscale (Kohya Deep Shrink) реализует технику Kohya Deep Shrink, применяя операции уменьшения и увеличения масштаба к определённым блокам модели. Она снижает разрешение промежуточных признаков во время обработки, а затем восстанавливает их до исходного размера, что позволяет повысить производительность при сохранении качества. Узел обеспечивает точный контроль над тем, когда и как эти операции масштабирования выполняются во время работы модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяется патч уменьшения масштаба | MODEL | Да | - |
| `номер_блока` | Номер конкретного блока, где будет применяться уменьшение масштаба (по умолчанию: 3) | INT | Да | 1-32 |
| `коэффициент_уменьшения` | Коэффициент уменьшения масштаба признаков (по умолчанию: 2.0) | FLOAT | Да | 0.1-9.0 |
| `начальный_процент` | Начальная точка в процессе шумоподавления, где начинается уменьшение масштаба (по умолчанию: 0.0) | FLOAT | Да | 0.0-1.0 |
| `конечный_процент` | Конечная точка в процессе шумоподавления, где уменьшение масштаба прекращается (по умолчанию: 0.35) | FLOAT | Да | 0.0-1.0 |
| `уменьшение_после_пропуска` | Применять ли уменьшение масштаба после пропускных соединений (по умолчанию: True) | BOOLEAN | Да | - |
| `метод_уменьшения` | Метод интерполяции, используемый для операций уменьшения масштаба | COMBO | Да | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
| `метод_увеличения` | Метод интерполяции, используемый для операций увеличения масштаба | COMBO | Да | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |

Патч уменьшения масштаба применяется только тогда, когда текущий шаг шумоподавления попадает в диапазон, заданный `start_percent` и `end_percent`, и только на блоке, выбранном `block_number`. Когда `downscale_after_skip` включён, патч применяется после пропускного соединения; когда выключен — до пропускного соединения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Изменённая модель с применённым патчем уменьшения масштаба | MODEL |
