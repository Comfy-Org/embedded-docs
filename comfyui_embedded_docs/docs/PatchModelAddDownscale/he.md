# PatchModelAddDownscale

PatchModelAddDownscale (Kohya Deep Shrink) מיישם את טכניקת Kohya Deep Shrink על מודל על ידי כיווץ מאפייני ביניים בבלוק נבחר ואז החזרתם לגודלם המקורי. הכיווץ מתרחש רק במהלך חלק נבחר מתהליך הסרת הרעש, מה שיכול להפחית את עלות העיבוד תוך שמירה על התוצאה הסופית קרובה למקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו להחיל את תיקון הקטנת קנה המידה | MODEL | כן | - |
| `block_number` | מספר הבלוק הספציפי שבו תוחל הקטנת קנה המידה (ברירת מחדל: 3) | INT | כן | 1-32 |
| `downscale_factor` | המקדם שבו יוקטנו המאפיינים (ברירת מחדל: 2.0) | FLOAT | כן | 0.1-9.0 |
| `start_percent` | נקודת ההתחלה בתהליך הסרת הרעש שבה מתחילה הקטנת קנה המידה (ברירת מחדל: 0.0) | FLOAT | כן | 0.0-1.0 |
| `end_percent` | נקודת הסיום בתהליך הסרת הרעש שבה מפסיקה הקטנת קנה המידה (ברירת מחדל: 0.35) | FLOAT | כן | 0.0-1.0 |
| `downscale_after_skip` | האם להחיל הקטנת קנה מידה לאחר חיבורי דילוג (ברירת מחדל: True) | BOOLEAN | כן | - |
| `downscale_method` | שיטת האינטרפולציה המשמשת לפעולות הקטנת קנה מידה (ברירת מחדל: "bicubic") | COMBO | כן | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |
| `upscale_method` | שיטת האינטרפולציה המשמשת לפעולות הגדלת קנה מידה (ברירת מחדל: "bicubic") | COMBO | כן | "bicubic"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bislerp" |

תיקון הקטנת קנה המידה מוחל רק כאשר שלב הסרת הרעש הנוכחי נמצא בטווח המוגדר על ידי `start_percent` ו-`end_percent`, ורק בבלוק הנבחר על ידי `block_number`. כאשר `downscale_after_skip` מופעל, התיקון מוחל לאחר חיבור הדילוג; כאשר הוא מושבת, הוא מוחל לפני חיבור הדילוג. לאחר מכן המאפיינים מוחזרים לגודלם המקורי, אך רק כאשר גודל המאפיינים הנוכחי אינו תואם עוד לגודל שנרשם לפני הקטנת קנה המידה.

הפרמטרים `block_number`, `start_percent`, `end_percent`, ו-`downscale_after_skip` מסומנים כאפשרויות מתקדמות בממשק הצומת.
