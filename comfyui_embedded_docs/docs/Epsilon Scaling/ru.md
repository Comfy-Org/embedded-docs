# Масштабирование эпсилон

Данный узел реализует метод Epsilon Scaling из исследовательской статьи «Elucidating the Exposure Bias in Diffusion Models» (arxiv.org/abs/2308.15321v6). Этот метод масштабирует предсказанный шум во время процесса семплирования, что помогает снизить экспозиционное смещение (exposure bias) и может улучшить качество генерируемых изображений. В данной реализации используется «равномерное расписание» (uniform schedule), рекомендованное авторами статьи за практичность и эффективность.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой будет применён патч масштабирования эпсилон. | MODEL | Да | - |
| `коэффициент_масштабирования` | Коэффициент, на который масштабируется предсказанный шум. Значение больше 1.0 уменьшает шум, а значение меньше 1.0 увеличивает его (по умолчанию: 1.005). Это дополнительный параметр. | FLOAT | Нет | 0.5 - 1.5 (шаг: 0.001) |

Примечание: если для `scaling_factor` установлено значение 0, узел автоматически заменяет его очень малым значением (1e-9), чтобы предотвратить деление на ноль. Минимальное значение 0.5 в интерфейсе обычно предотвращает возникновение такой ситуации.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная версия входной модели, к процессу семплирования которой применена функция масштабирования эпсилон. | MODEL |
