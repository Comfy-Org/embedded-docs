# Масштабирование эпсилон

Этот узел реализует метод масштабирования эпсилон (Epsilon Scaling) из исследовательской статьи «Elucidating the Exposure Bias in Diffusion Models» (arxiv.org/abs/2308.15321v6). Он работает путём масштабирования предсказанного шума в процессе сэмплирования, чтобы уменьшить смещение экспозиции (exposure bias), что может привести к повышению качества генерируемых изображений. В данной реализации используется «равномерное расписание» (uniform schedule), рекомендованное авторами статьи за его практичность и эффективность.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой будет применён патч масштабирования эпсилон. | MODEL | Да | - |
| `scaling_factor` | Коэффициент, на который масштабируется предсказанный шум. Значение больше 1.0 уменьшает предсказанный шум, а значение меньше 1.0 увеличивает его (по умолчанию: 1.005). | FLOAT | Да | 0.5 - 1.5 (step: 0.001) |

Примечание: параметр `scaling_factor` защищён от нулевого значения, чтобы предотвратить деление на ноль. В интерфейсе задано минимальное значение 0.5, поэтому такая ситуация не может возникнуть при обычном использовании.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная копия входной модели с применённой функцией масштабирования эпсилон к её процессу сэмплирования. Исходная модель остаётся без изменений. | MODEL |
