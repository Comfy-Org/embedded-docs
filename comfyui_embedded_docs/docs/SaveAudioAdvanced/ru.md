# Сохранить аудио (расширенно)

Сохраняет входное аудио в ваш каталог вывода ComfyUI. Этот узел позволяет экспортировать аудио в различных форматах, включая FLAC, MP3 и Opus, с настраиваемыми параметрами качества.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для сохранения. | AUDIO | Да | - |
| `filename_prefix` | Префикс для сохраняемого файла. Может содержать токены форматирования, такие как %date:yyyy-MM-dd%. (по умолчанию: "audio/ComfyUI") | STRING | Да | - |
| `format` | Формат файла, в котором сохраняется аудио. | DYNAMIC_COMBO | Да | "flac"<br>"mp3"<br>"opus" |

### Входы MP3

Когда выбран формат "mp3", становится доступна следующая настройка.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `quality` | Качество кодирования выходного файла MP3. (по умолчанию: "V0") | COMBO | Нет | "V0"<br>"128k"<br>"320k" |

### Входы Opus

Когда выбран формат "opus", становится доступна следующая настройка.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `quality` | Качество кодирования выходного файла Opus. (по умолчанию: "128k") | COMBO | Нет | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

Примечание: настройка `quality` доступна только при выборе соответствующего формата. Если выбран формат "flac", дополнительная настройка качества недоступна.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `аудио` | Входное аудио, переданное без изменений после сохранения. | AUDIO |

Узел также возвращает информацию пользовательского интерфейса, содержащую информацию о сохраненном аудиофайле.
