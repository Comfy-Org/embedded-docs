# Сохранить аудио (расширенно)

Сохраняет входное аудио в вашу выходную директорию ComfyUI. Вы можете экспортировать аудио в форматах FLAC, MP3 или Opus с возможностью выбора качества для файлов MP3 и Opus.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `format` | Формат файла, в котором будет сохранено аудио. | DYNAMIC_COMBO | Да | "flac"<br>"mp3"<br>"opus" |
| `audio` | Сохраняемое аудио. | AUDIO | Да | - |
| `filename_prefix` | Префикс для сохраняемого файла. Может содержать токены форматирования, например %date:yyyy-MM-dd%. (по умолчанию: "audio/ComfyUI") | STRING | Да | - |

### Входные параметры flac

Формат `flac` не требует дополнительных настроек.

### Входные параметры mp3

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `quality` | Качество кодирования для файлов MP3. (по умолчанию: "V0") | COMBO | Да | "V0"<br>"128k"<br>"320k" |

### Входные параметры opus

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `quality` | Качество кодирования для файлов Opus. (по умолчанию: "128k") | COMBO | Да | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

**Примечание:** Параметр `quality` отображается только когда `format` задан как `mp3` или `opus`. Если значение `quality` не указано, аудио сохраняется с качеством по умолчанию для выбранного формата.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Входное аудио, передаваемое далее после сохранения. | AUDIO |
| `ui` | UI-выход, содержащий информацию о сохранённом аудиофайле. | UI |
