# 오디오 저장 (고급)

오디오 저장 (고급)

입력 오디오를 ComfyUI 출력 디렉터리에 저장합니다. FLAC, MP3 또는 Opus 형식으로 오디오를 내보낼 수 있으며, MP3 및 Opus 파일의 경우 품질 설정을 선택할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `format` | 오디오를 저장할 파일 형식입니다. | DYNAMIC_COMBO | 예 | "flac"<br>"mp3"<br>"opus" |
| `audio` | 저장할 오디오입니다. | AUDIO | 예 | - |
| `filename_prefix` | 저장할 파일의 접두사입니다. %date:yyyy-MM-dd%와 같은 형식 토큰을 포함할 수 있습니다. (기본값: "audio/ComfyUI") | STRING | 예 | - |

### flac 입력

`flac` 형식은 추가 설정이 필요하지 않습니다.

### mp3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `quality` | MP3 파일의 인코딩 품질입니다. (기본값: "V0") | COMBO | 예 | "V0"<br>"128k"<br>"320k" |

### opus 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `quality` | Opus 파일의 인코딩 품질입니다. (기본값: "128k") | COMBO | 예 | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

**참고:** `quality` 설정은 `format`이 `mp3` 또는 `opus`인 경우에만 표시됩니다. `quality` 값이 제공되지 않으면 선택한 형식의 기본 품질로 오디오가 저장됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 저장된 후 전달되는 입력 오디오입니다. | AUDIO |
| `ui` | 저장된 오디오 파일 정보를 포함하는 UI 출력입니다. | UI |
