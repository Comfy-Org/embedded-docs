# 儲存音訊（進階）

將輸入音訊儲存至您的 ComfyUI 輸出目錄。此節點允許您以多種格式匯出音訊，包括 FLAC、MP3 和 Opus，並可設定品質參數。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 要儲存的音訊。 | AUDIO | 是 | - |
| `filename_prefix` | 要儲存檔案的字首。可包含格式化權杖，例如 %date:yyyy-MM-dd%。 (預設值："audio/ComfyUI") | STRING | 是 | - |
| `format` | 儲存音訊的檔案格式。 | DYNAMIC_COMBO | 是 | "flac"<br>"mp3"<br>"opus" |

### MP3 輸入

當選取「mp3」作為格式時，以下設定將可使用。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 輸出 MP3 檔案的編碼品質。 (預設值："V0") | COMBO | 否 | "V0"<br>"128k"<br>"320k" |

### Opus 輸入

當選取「opus」作為格式時，以下設定將可使用。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 輸出 Opus 檔案的編碼品質。 (預設值："128k") | COMBO | 否 | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

注意：`quality` 設定僅在選取相符的格式時可用。當選取「flac」時，沒有額外的品質設定可用。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `audio` | 輸入音訊，在儲存後原封不動地傳遞。 | AUDIO |

此節點也會傳回包含已儲存音訊檔案資訊的 UI 資訊。
