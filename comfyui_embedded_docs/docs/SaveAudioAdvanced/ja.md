オーディオ保存（詳細）

入力オーディオを ComfyUI の出力ディレクトリに保存します。FLAC、MP3、Opus 形式でオーディオを書き出すことができ、MP3 と Opus ファイルには選択可能な品質設定があります。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `format` | オーディオを保存するファイル形式。 | DYNAMIC_COMBO | はい | "flac"<br>"mp3"<br>"opus" |
| `audio` | 保存するオーディオ。 | AUDIO | はい | - |
| `filename_prefix` | 保存するファイルのプレフィックス。%date:yyyy-MM-dd% などのフォーマットトークンを含めることができます。（デフォルト："audio/ComfyUI"） | STRING | はい | - |

### flac 入力

`flac` 形式には追加設定は必要ありません。

### mp3 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `quality` | MP3 ファイルのエンコード品質。（デフォルト："V0"） | COMBO | はい | "V0"<br>"128k"<br>"320k" |

### opus 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `quality` | Opus ファイルのエンコード品質。（デフォルト："128k"） | COMBO | はい | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

**注：** `quality` 設定は、`format` が `mp3` または `opus` の場合にのみ表示されます。`quality` の値が指定されていない場合、選択された形式のデフォルト品質でオーディオが保存されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | 保存後、そのまま渡される入力オーディオ。 | AUDIO |
| `ui` | 保存されたオーディオファイル情報を含む UI 出力。 | UI |
