# KSamplerAdvanced

צומת KSamplerAdvanced נועד לשפר את תהליך הדגימה על ידי אספקת תצורות וטכניקות מתקדמות. מטרתו להציע אפשרויות מתוחכמות יותר ליצירת דגימות ממודל, ולשפר את הפונקציונליות הבסיסית של KSampler.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `model` | מגדיר את המודל שממנו יש ליצור דגימות, ותופס תפקיד מכריע בתהליך הדגימה. | MODEL |
| `add_noise` | קובע האם יש להוסיף רעש לתהליך הדגימה, ומשפיע על המגוון והאיכות של הדגימות שנוצרות. | COMBO[STRING] |
| `noise_seed` | מגדיר את ה-seed ליצירת רעש, ומבטיח יכולת שחזור בתהליך הדגימה. | INT |
| `steps` | מגדיר את מספר הצעדים בתהליך הדגימה, ומשפיע על רמת הפירוט והאיכות של הפלט. | INT |
| `cfg` | שולט בגורם ההתניה, ומשפיע על הכיוון והמרחב של תהליך הדגימה. | FLOAT |
| `sampler_name` | בוחר את הדוגם הספציפי שיש להשתמש בו, ומאפשר התאמה אישית של טכניקת הדגימה. | COMBO[STRING] |
| `scheduler` | בוחר את המתזמן לשליטה בתהליך הדגימה, ומשפיע על ההתקדמות והאיכות של הדגימות. | COMBO[STRING] |
| `positive` | מגדיר את ההתניה החיובית כדי לכוון את הדגימה לעבר תכונות רצויות. | CONDITIONING |
| `negative` | מגדיר את ההתניה השלילית כדי להרחיק את הדגימה מתכונות מסוימות. | CONDITIONING |
| `latent_image` | מספק את התמונה הלטנטית ההתחלתית שבה יש להשתמש בתהליך הדגימה, ומשמשת כנקודת התחלה. | LATENT |
| `start_at_step` | קובע את צעד ההתחלה של תהליך הדגימה, ומאפשר שליטה על התקדמות הדגימה. | INT |
| `end_at_step` | מגדיר את צעד הסיום של תהליך הדגימה, ומגדיר את היקף הדגימה. | INT |
| `return_with_leftover_noise` | מציין האם להחזיר את הדגימה עם רעש עודף, ומשפיע על המראה של הפלט הסופי. | COMBO[STRING] |
