# MinimaxHailuo03ReferenceNode

تقوم هذه العقدة بتوليد فيديو باستخدام نموذج MiniMax H3، وذلك باستخدام صور وفيديوهات وصوتيات مرجعية لتهيئة النتيجة. يُشار إلى المراجع في الوصف النصي حسب ترتيب الربط: "Image 1" و"Image 2" و"Video 1" و"Audio 1" وهكذا.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم لتوليد الفيديو (الافتراضي: "MiniMax H3"). اختيار "MiniMax H3" يوفر الإعدادات التالية: `prompt`، `duration`، `resolution`، `ratio`، `reference_images`، `reference_videos`، و`reference_audios`. | STRING | نعم | "MiniMax H3" |
| `prompt` | وصف نصي للفيديو المراد توليده. يمكن الإشارة إلى الوسائط المرجعية حسب ترتيب الربط، على سبيل المثال "Image 1" أو "Image 2" أو "Video 1" أو "Audio 1". | STRING | نعم | الحد الأدنى للطول: حرف واحد |
| `duration` | مدة الفيديو المُولَّد بالثواني. | INT | نعم | تتوفر خيارات متعددة |
| `resolution` | دقة الفيديو المُولَّد. | STRING | نعم | تتوفر خيارات متعددة |
| `ratio` | نسبة العرض إلى الارتفاع للفيديو المُولَّد. | STRING | نعم | تتوفر خيارات متعددة |
| `reference_images` | صور مرجعية للموضوع أو النمط، يُشار إليها في الوصف النصي كـ "Image 1".."Image 9" حسب ترتيب الربط. حتى 9 صور. | IMAGE | لا | 0 إلى 9 صور |
| `reference_videos` | فيديوهات مرجعية للحركة أو المشهد، يُشار إليها في الوصف النصي كـ "Video 1".."Video 3" حسب ترتيب الربط. حتى 3 فيديوهات، مدة كل منها 2-15 ثانية، وبإجمالي 15 ثانية. | VIDEO | لا | 0 إلى 3 فيديوهات |
| `reference_audios` | مراجع صوتية، يُشار إليها في الوصف النصي كـ "Audio 1".."Audio 3" حسب ترتيب الربط. حتى 3 مقاطع، مدة كل منها 2-15 ثانية، وبإجمالي 15 ثانية. لا يمكن استخدامها بدون صورة مرجعية أو فيديو مرجعي. | AUDIO | لا | 0 إلى 3 مقاطع |
| `البذرة` | بذرة عشوائية. نفس الطلب مع نفس البذرة يعطي نتائج متشابهة، لكنها ليست مضمونة التطابق (الافتراضي: 42). | INT | نعم | 0 إلى 4294967295 |
| `علامة مائية` | ما إذا كان سيتم إضافة علامة مائية AIGC إلى الفيديو (الافتراضي: false). | BOOLEAN | لا | true<br>false |

### قيود المعاملات

- يجب توفير صورة مرجعية واحدة على الأقل أو فيديو مرجعي واحد. لا يُقبل الصوت المرجعي وحده.
- يجب أن تكون نسبة العرض إلى الارتفاع لكل صورة مرجعية بين 0.4 و 2.5 تقريبًا (2:5 إلى 5:2)، وبحد أدنى للعرض والارتفاع يبلغ 256 بكسل.
- يجب أن تتراوح مدة كل فيديو مرجعي بين 2 و 15 ثانية، مع معدل إطارات بين 23.976 و 60 إطارًا في الثانية (FPS). لا يمكن أن تتجاوز المدة الإجمالية لجميع الفيديوهات المرجعية 15 ثانية.
- يجب أن تتراوح مدة كل مقطع صوتي مرجعي بين 2 و 15 ثانية. لا يمكن أن تتجاوز المدة الإجمالية لجميع المقاطع الصوتية المرجعية 15 ثانية.
