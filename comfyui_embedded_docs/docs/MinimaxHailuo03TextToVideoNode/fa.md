# MinimaxHailuo03TextToVideoNode

این گره ویدیویی را از روی یک متن (prompt) با استفاده از مدل MiniMax H3 تولید می‌کند. متن را همراه با تنظیمات ویدیو مانند رزولوشن، مدت‌زمان و نسبت تصویر به API مینی‌ماکس ارسال می‌کند و ویدیوی حاصل را به‌عنوان خروجی برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `model` | مدل مورد استفاده برای تولید ویدیو. (پیش‌فرض: "MiniMax H3"). این انتخاب همچنین شامل متن prompt، رزولوشن، مدت‌زمان و تنظیمات نسبت تصویر برای ویدیوی تولیدشده است. | COMBO | بله | `"MiniMax H3"` |
| `seed` | دانه تصادفی. درخواست یکسان با دانه یکسان، نتایج مشابه اما نه لزوماً یکسان می‌دهد. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |
| `watermark` | آیا به ویدیو واترمارک AIGC اضافه شود یا نه. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |

نکته: متن prompt موجود در گزینه `model` باید حداقل یک کاراکتر غیرفضایی داشته باشد. قیمت تخمینی نمایش‌داده‌شده برای این گره بر اساس مدت‌زمان انتخابی ویدیو محاسبه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `VIDEO` | ویدیوی تولیدشده از روی متن prompt ارائه‌شده. | VIDEO |
