# تبدیل متن به ویدیو MiniMax H3

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید ویدئو استفاده می‌شود. (پیش‌فرض: `"MiniMax H3"`). انتخاب این مدل همچنین تنظیمات پرامپت متنی، وضوح، نسبت تصویر و مدت‌زمان ویدئوی تولیدشده را فراهم می‌کند (به بخش ورودی‌های MiniMax H3 در پایین مراجعه کنید). | COMBO | بله | `"MiniMax H3"` |
| `seed` | دانه تصادفی. درخواست یکسان با دانه یکسان نتایج مشابهی می‌دهد، هرچند یکسانی قطعی تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |
| `watermark` | آیا به ویدئو واترمارک AIGC اضافه شود یا نه. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |

### ورودی‌های MiniMax H3

این تنظیمات هنگامی ظاهر می‌شوند که مدل «MiniMax H3» انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی برای تولید ویدئو. | STRING | بله | هر متنی |
| `resolution` | وضوح ویدئوی خروجی. | COMBO | بله | `"768P"`<br>`"2K"` |
| `ratio` | نسبت تصویر ویدئوی خروجی. (پیش‌فرض: `"16:9"`) | COMBO | بله | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | مدت‌زمان ویدئوی خروجی بر حسب ثانیه. (پیش‌فرض: 5) | INT | بله | 4 تا 15 |

توجه: پرامپت متنی موجود در گزینه `model` باید حداقل شامل یک نویسه غیرفضایی باشد. قیمت تخمینی نمایش‌داده‌شده برای این گره بر اساس وضوح و مدت‌زمان انتخاب‌شده محاسبه می‌شود.
