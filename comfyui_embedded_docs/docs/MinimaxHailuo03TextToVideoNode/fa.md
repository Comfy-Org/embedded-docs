# تبدیل متن به ویدیو MiniMax H3

این گره با استفاده از مدل MiniMax H3 از یک متن پرامپت، ویدیو تولید می‌کند. این گره متن را همراه با تنظیمات ویدیو مانند رزولوشن، نسبت تصویر و مدت‌زمان به MiniMax API ارسال می‌کند، منتظر تکمیل وظیفه تولید می‌ماند و ویدیوی حاصل را برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای تولید ویدیو استفاده می‌شود. (پیش‌فرض: "MiniMax H3"). انتخاب این مدل همچنین تنظیمات متن پرامپت، رزولوشن، نسبت تصویر و مدت‌زمان ویدیوی تولیدشده را فراهم می‌کند (به ورودی‌های MiniMax H3 در زیر مراجعه کنید). | DYNAMIC_COMBO | بله | `"MiniMax H3"` |
| `seed` | سید تصادفی. درخواست یکسان با سید یکسان نتایج مشابهی به همراه دارد، اما یکسان بودن آن تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |
| `واترمارک` | آیا یک واترمارک AIGC به ویدیو اضافه شود یا نه. (پیش‌فرض: false) | BOOLEAN | خیر | true<br>false |

### ورودی‌های MiniMax H3

این تنظیمات زمانی ظاهر می‌شوند که مدل "MiniMax H3" انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن پرامپت برای تولید ویدیو. | STRING | بله | Any text |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | "768P"<br>"2K" |
| `ratio` | نسبت تصویر ویدیوی خروجی. (پیش‌فرض: "16:9") | COMBO | بله | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (4-15). (پیش‌فرض: 5) | INT | بله | 4 تا 15 |

توجه: متن پرامپت موجود در گزینه `model` باید حداقل شامل یک نویسه غیرفاصله باشد. قیمت تخمینی نمایش‌داده‌شده برای این گره بر اساس رزولوشن و مدت‌زمان ویدیوی انتخاب‌شده محاسبه می‌شود.
