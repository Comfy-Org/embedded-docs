# MiniMax H3 文生影片

此節點使用 MiniMax H3 模型，根據文字提示生成影片。它會將文字以及影片設定（如解析度、長寬比和持續時間）發送至 MiniMax API，等待生成任務完成，然後傳回生成的影片。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片生成的模型。（預設值："MiniMax H3"）。選擇此模型也會提供生成影片的文字提示、解析度、比例和持續時間設定（請參閱下方的 MiniMax H3 輸入）。 | COMBO | 是 | `"MiniMax H3"` |
| `隨機種子` | 隨機種子。使用相同種子的相同請求會產生相似但不保證完全相同的結果。（預設值：42） | INT | 是 | 0 到 4294967295 |
| `浮水印` | 是否在影片中加入 AIGC 浮水印。（預設值：false） | BOOLEAN | 否 | true<br>false |

### MiniMax H3 輸入

當選取「MiniMax H3」模型時，會顯示這些設定。

| 參數 | 描述 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用於影片生成的文字提示。 | STRING | 是 | 任意文字 |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "768P"<br>"2K" |
| `ratio` | 輸出影片的長寬比。（預設值："16:9"） | COMBO | 是 | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | 輸出影片的持續時間（秒）。（預設值：5） | INT | 是 | 4 到 15 |

注意：`model` 選項中包含的文字提示必須至少包含一個非空白字元。此節點顯示的預估價格是根據選取的解析度和影片持續時間計算。
