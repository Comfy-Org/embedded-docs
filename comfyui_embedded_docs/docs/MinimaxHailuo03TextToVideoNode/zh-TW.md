# MiniMax H3 文生影片

此節點使用 MiniMax H3 模型，依據文字提示產生影片。它會將文字以及解析度、寬高比、時長等影片設定傳送至 MiniMax API，等待生成任務完成，然後回傳產生的影片。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於影片生成的模型（預設值："MiniMax H3"）。選取此模型也會提供所生成影片的文字提示、解析度、寬高比和時長設定（請參閱下方的 MiniMax H3 輸入）。 | DYNAMIC_COMBO | 是 | `"MiniMax H3"` |
| `隨機種子` | 隨機種子。使用相同種子的相同請求會產生相似但不保證完全相同的結果。（預設值：42） | INT | 是 | 0 至 4294967295 |
| `浮水印` | 是否在影片中加入 AIGC 浮水印。（預設值：false） | BOOLEAN | 否 | true<br>false |

### MiniMax H3 輸入

這些設定會在選取「MiniMax H3」模型時出現。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用於影片生成的文字提示。 | STRING | 是 | 任意文字 |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "768P"<br>"2K" |
| `ratio` | 輸出影片的寬高比。（預設值："16:9"） | COMBO | 是 | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | 輸出影片的時長（秒）（4-15）。（預設值：5） | INT | 是 | 4 至 15 |

注意：`model` 選項中包含的文字提示必須至少包含一個非空白字元。此節點顯示的估計費用是根據所選解析度和影片時長計算的。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `VIDEO` | 根據提供的文字提示產生的影片。 | VIDEO |
