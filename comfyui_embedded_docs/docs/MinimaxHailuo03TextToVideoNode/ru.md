# MiniMax H3: Текст в видео

Этот узел генерирует видео из текстового промпта с использованием семейства моделей MiniMax H3: MiniMax H3, MiniMax H3 Max и MiniMax H3 Max Turbo. Вы выбираете модель, вводите текстовый промпт и настраиваете такие параметры, как разрешение, соотношение сторон и длительность. Узел отправляет запрос в API MiniMax, ожидает завершения задачи генерации и возвращает полученное видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для генерации видео (по умолчанию: "MiniMax H3"). При выборе модели также отображаются настройки, специфичные для этой модели, описанные в разделах ниже. | DYNAMIC_COMBO | Да | "MiniMax H3"<br>"MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |
| `seed` | Случайное зерно. Один и тот же запрос с одинаковым seed даёт похожие, но не гарантированно идентичные результаты (по умолчанию: 42). | INT | Да | 0 до 4294967295 |
| `водяной знак` | Добавлять ли водяной знак AIGC к видео (по умолчанию: false). При включении поддерживается только модель "MiniMax H3". | BOOLEAN | Нет | true<br>false |

### Входы MiniMax H3

Эти настройки отображаются, когда выбрана модель "MiniMax H3".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео. Должен содержать как минимум один непробельный символ. | STRING | Да | Any text |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9"). | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Длительность выходного видео в секундах (4-15) (по умолчанию: 5). | INT | Да | 4 до 15 |

### Входы MiniMax H3 Max и MiniMax H3 Max Turbo

Эти настройки являются общими для моделей "MiniMax H3 Max" и "MiniMax H3 Max Turbo" и отображаются при выборе любой из этих моделей.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео. Должен содержать как минимум один непробельный символ и может иметь длину до 50 000 символов. | STRING | Да | До 50 000 символов |
| `resolution` | Разрешение выходного видео (по умолчанию: "768P"). | COMBO | Да | "480P"<br>"768P" |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9"). | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Длительность выходного видео в секундах (5-15) (по умолчанию: 5). | INT | Да | 5 до 15 |
| `prompt_expansion_mode` | Насколько интенсивно переписывается промпт перед генерацией (по умолчанию: "balanced"). | COMBO | Да | "balanced"<br>"quality" |

### Примечания

- Для всех моделей промпт должен содержать как минимум один непробельный символ.
- Настройка `watermark` поддерживается только моделью "MiniMax H3". Включение её с "MiniMax H3 Max" или "MiniMax H3 Max Turbo" приводит к ошибке.
- Модели "MiniMax H3 Max" и "MiniMax H3 Max Turbo" ограничивают длину промпта до 50 000 символов.
- Ограничения по разрешению и длительности зависят от выбранной модели: "MiniMax H3" поддерживает разрешение "768P" и "2K" и видео длительностью 4-15 секунд, тогда как "MiniMax H3 Max" и "MiniMax H3 Max Turbo" поддерживают разрешение "480P" и "768P" и видео длительностью 5-15 секунд.
- Оценочная стоимость, отображаемая для этого узла, рассчитывается на основе выбранной модели, разрешения и длительности.
