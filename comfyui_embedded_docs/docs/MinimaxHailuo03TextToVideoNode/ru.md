# MinimaxHailuo03TextToVideoNode

Этот узел генерирует видео на основе текстового запроса с использованием модели MiniMax H3. Он отправляет текст вместе с настройками видео, такими как разрешение, длительность и соотношение сторон, в API MiniMax и возвращает полученное видео в качестве выходного результата.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `model` | Модель для генерации видео. (по умолчанию: "MiniMax H3"). Этот выбор также включает текстовый запрос, настройки разрешения, длительности и соотношения сторон для генерируемого видео. | COMBO | Да | `"MiniMax H3"` |
| `seed` | Случайное зерно (seed). Один и тот же запрос с одним и тем же зерном дает похожие, но не гарантированно идентичные результаты. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |
| `watermark` | Добавлять ли водяной знак AIGC к видео. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |

Примечание: текстовый запрос, включенный в параметр `model`, должен содержать хотя бы один непробельный символ. Расчетная цена, отображаемая для этого узла, вычисляется на основе выбранной длительности видео.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `VIDEO` | Сгенерированное видео, созданное на основе предоставленного текстового запроса. | VIDEO |
