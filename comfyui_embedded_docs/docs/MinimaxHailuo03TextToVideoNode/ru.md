# MiniMax H3: Текст в видео

Этот узел генерирует видео по текстовому запросу с использованием модели MiniMax H3. Он отправляет текст вместе с настройками видео, такими как разрешение, соотношение сторон и продолжительность, в API MiniMax, ожидает завершения задачи генерации и возвращает итоговое видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для генерации видео. (по умолчанию: "MiniMax H3"). Выбор этой модели также предоставляет настройки текстового запроса, разрешения, соотношения сторон и продолжительности для генерируемого видео (см. Входы MiniMax H3 ниже). | DYNAMIC_COMBO | Да | `"MiniMax H3"` |
| `seed` | Случайное зерно. Одинаковый запрос с одинаковым зерном дает похожие, но не гарантированно идентичные результаты. (по умолчанию: 42) | INT | Да | 0 до 4294967295 |
| `водяной знак` | Добавлять ли водяной знак AIGC к видео. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |

### Входы MiniMax H3

Эти настройки появляются при выборе модели "MiniMax H3".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. | STRING | Да | Любой текст |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `ratio` | Соотношение сторон выходного видео. (по умолчанию: "16:9") | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Продолжительность выходного видео в секундах (4-15). (по умолчанию: 5) | INT | Да | 4 до 15 |

Примечание: текстовый запрос, включенный в опцию `model`, должен содержать хотя бы один непробельный символ. Оценочная стоимость, показанная для этого узла, рассчитывается на основе выбранного разрешения и продолжительности видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео, созданное на основе предоставленного текстового запроса. | VIDEO |
