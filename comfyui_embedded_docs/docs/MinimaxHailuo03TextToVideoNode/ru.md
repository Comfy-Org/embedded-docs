# MiniMax H3: Текст в видео

Этот узел генерирует видео по текстовому запросу с помощью модели MiniMax H3. Он отправляет текст вместе с настройками видео, такими как разрешение, соотношение сторон и длительность, в API MiniMax, ожидает завершения задачи генерации и возвращает полученное видео.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `модель` | Модель для генерации видео. (по умолчанию: `"MiniMax H3"`). Выбор этой модели также предоставляет настройки текстового запроса, разрешения, соотношения сторон и длительности для генерируемого видео (см. ниже «Входные параметры MiniMax H3»). | DYNAMIC_COMBO | Да | `"MiniMax H3"` |
| `seed` | Случайное зерно. Одинаковый запрос с одним и тем же зерном даёт похожие, но не гарантированно одинаковые результаты. (по умолчанию: 42) | INT | Да | 0–4294967295 |
| `водяной знак` | Добавлять ли к видео AIGC-водяной знак. (по умолчанию: false) | BOOLEAN | Нет | true<br>false |

### Входные параметры MiniMax H3

Эти параметры появляются при выборе модели «MiniMax H3».

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `prompt` | Текстовый запрос для генерации видео. | STRING | Да | Любой текст |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `ratio` | Соотношение сторон выходного видео. (по умолчанию: "16:9") | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Длительность выходного видео в секундах. (по умолчанию: 5) | INT | Да | от 4 до 15 |

Примечание: Текстовый запрос, включённый в параметр `model`, должен содержать минимум один непробельный символ. Оценочная стоимость, отображаемая для этого узла, рассчитывается на основе выбранного разрешения и длительности видео.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `VIDEO` | Сгенерированное видео, созданное на основе предоставленного текстового запроса. | VIDEO |
