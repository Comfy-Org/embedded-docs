# Fish Audio 文字轉語音

此節點使用 Fish Audio 文字轉語音模型，將書寫文字轉換為語音。它支援嵌入文字中的情感提示（s2.1-pro 上的 [happy]、[whispering]；s1 上的 (happy)），以及當連接多個語音時，使用 @Voice1/@Voice2 標籤進行多說話者對話。提供兩種模型：s2.1-pro 支援最多五個語音與多說話者對話；s1 則使用單一選用語音。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `text` | 要轉換為語音的文字。連接兩個或更多語音時，請用 @Voice1、@Voice2 等標記說話者切換。（預設：空） | STRING | 是 | 任何非空文字 |
| `model` | 用於文字轉語音的模型。 | DYNAMIC_COMBO | 是 | "s2.1-pro"<br>"s1" |
| `seed` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果皆非確定性。（預設：42） | INT | 是 | 0 至 2147483647 |

**注意：** `text` 輸入不得為空。說話者標籤（@Voice1、@Voice2 等）不區分大小寫，且必須指向已連接的語音；標記未連接的語音會引發錯誤。連接兩個或更多語音時，文字必須至少引用每個已連接的語音一次，否則節點會回報缺少標籤。在 s2.1-pro 上，連接 0 個語音會使用預設語音，1 個語音會單獨使用該語音，2 個或更多語音會啟用多說話者對話。在 s1 上，會使用單一選用語音，未連接時則使用預設語音。情感提示可放在文字中：s2.1-pro 上的 [happy] 和 [whispering]，以及 s1 上的 (happy)。
