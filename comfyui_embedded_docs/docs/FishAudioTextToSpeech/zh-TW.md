# FishAudioTextToSpeech

此節點使用 Fish Audio 文字轉語音模型，將書面文字轉換為口語音訊。它支援文字中嵌入的情緒提示（s2.1-pro 使用 [happy]、[whispering]；s1 使用 (happy)），並在連接多個語音時，透過 @Voice1/@Voice2 標籤實現多人對話。提供兩個模型：s2.1-pro 最多支援五個語音及多人對話；s1 使用單一可選語音。
