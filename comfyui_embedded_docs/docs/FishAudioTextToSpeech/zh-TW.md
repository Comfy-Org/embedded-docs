# FishAudioTextToSpeech

此節點使用 Fish Audio 文字轉語音模型，將書面文字轉換為口語音訊。支援文字中嵌入的情緒提示（s2.1-pro 上的 `[happy]`、`[whispering]`；s1 上的 `(happy)`），並在連接多個聲音時使用 `@Voice1`/`@Voice2` 標籤進行多說話人對話。提供兩種模型：s2.1-pro 支援最多五個聲音和多說話人對話，s1 使用單一可選聲音。

|-----------|-------------|-----------|----------|-------|
| `text` | 要轉換為語音的文字。連接兩個或更多聲音時，使用 `@Voice1`、`@Voice2` 等標記說話人變更。不可為空白。（預設值：空白） | STRING | 是 | Any non-empty text |

**注意：** `text` 輸入不可為空白。說話人標籤（`@Voice1`、`@Voice2` 等）不區分大小寫，且必須指向已連接的聲音；標記未連接的聲音會引發錯誤。當連接兩個或更多聲音時，文字必須至少提及每個已連接的聲音一次，否則節點會回報缺少的標籤。在 s2.1-pro 上，連接 0 個聲音會使用預設聲音，連接 1 個聲音則僅使用該聲音，連接 2 個或更多聲音會啟用多說話人對話。在 s1 上，使用單一可選聲音，保持未連接則使用預設聲音。情緒提示可放置在文字中：s2.1-pro 使用 `[happy]` 和 `[whispering]`，s1 使用 `(happy)`。
