# Fish Audio 文字轉語音

此節點使用 Fish Audio 文字轉語音模型，將書寫文字轉換為語音音訊。它支援內嵌於文字中的提示：s2.1-pro 上的 `[happy]` 與 `[whispering]`、s1 上的 `(happy)`，以及 drama-3 上的自然語言 `[directions]` 加上 `<whisper>...</whisper>` 詞語標籤。當連接多個語音時，多講者對話會使用 @Voice1/@Voice2 標籤。共有三種模型可用：drama-3 與 s2.1-pro 皆支援最多五個語音及多講者對話，而 s1 則使用單一選用語音。

**注意：** `text` 輸入不得為空。講者標籤（@Voice1、@Voice2 等）不分大小寫，且必須指向已連接的語音；標記未連接的語音會引發錯誤。當連接兩個以上的語音時，文字必須至少各引用每個已連接的語音一次，否則此節點會回報缺少的標籤。在 drama-3 與 s2.1-pro 上，連接 0 個語音會使用隨機語音，連接 1 個語音會單獨使用該語音，連接 2 個以上語音則啟用多講者對話。在 s1 上，會使用單一選用語音，未連接時則使用隨機語音。可將提示置於文字中：s2.1-pro 上的 `[happy]` 與 `[whispering]`、s1 上的 `(happy)`，以及 drama-3 上的自然語言 `[directions]` 與 `<whisper>...</whisper>` 詞語標籤。
