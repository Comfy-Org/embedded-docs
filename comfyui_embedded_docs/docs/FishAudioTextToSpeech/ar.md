# Fish Audio تحويل النص إلى كلام

تحوّل هذه العقدة النص المكتوب إلى صوت منطوق باستخدام نماذج تحويل النص إلى كلام من Fish Audio. تدعم إشارات مضمّنة في النص: [happy] و[whispering] على s2.1-pro، و(happy) على s1، و[directions] باللغة الطبيعية بالإضافة إلى وسوم الكلمات `<whisper>...</whisper>` على drama-3. يستخدم الحوار متعدد المتحدثين وسوم @Voice1/@Voice2 عند اتصال عدة أصوات. تتوفر ثلاثة نماذج: drama-3 و s2.1-pro، وكلاهما يدعم حتى خمسة أصوات والحوار متعدد المتحدثين، وs1، الذي يستخدم صوتًا اختياريًا واحدًا.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | النص المطلوب تحويله إلى كلام. عند اتصال صوتين أو أكثر، حدّد تغييرات المتحدث باستخدام @Voice1، @Voice2، إلخ. (الافتراضي: فارغ) | STRING | نعم | أي نص غير فارغ |
| `model` | النموذج المستخدم لتحويل النص إلى كلام. | DYNAMIC_COMBO | نعم | "drama-3"<br>"s2.1-pro"<br>"s1" |
| `seed` | يتحكم `seed` فيما إذا كان يجب إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن `seed`. (الافتراضي: 42) | INT | نعم | 0 إلى 2147483647 |

### مدخلات drama-3 و s2.1-pro

تظهر هذه المدخلات عند تحديد النموذج `drama-3` أو `s2.1-pro`. مجموعات المعاملات متطابقة.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `voices` | خانة قابلة للتوسيع: وصّل من 0 إلى 5 عناصر صوت (`voice_1`، `voice_2`، ...). الأصوات المستخدمة في التركيب. اتركها فارغة لصوت عشوائي. عند وجود صوتين أو أكثر، حدّد تغييرات المتحدث في النص باستخدام @Voice1، @Voice2، إلخ. | FISHAUDIO_VOICE | لا | 0 إلى 5 أصوات |
| `temperature` | التعبيرية. القيم الأعلى أكثر تنوعًا، والقيم الأدنى أكثر ثباتًا. (الافتراضي: 0.7) | FLOAT | نعم | 0.0 إلى 1.0 |
| `top_p` | التنوع عبر أخذ عينات النواة. (الافتراضي: 0.7) | FLOAT | نعم | 0.01 إلى 1.0 |
| `speed` | سرعة التحدث. 1.0 عادي، أقل من 1.0 أبطأ، أكبر من 1.0 أسرع. (الافتراضي: 1.0) | FLOAT | نعم | 0.5 إلى 2.0 |
| `volume` | ضبط مستوى الصوت بالديسيبل. 0 يعني عدم التغيير. (الافتراضي: 0.0) | FLOAT | نعم | -10.0 إلى 10.0 |
| `normalize` | تطبيع الأرقام والنص للإنجليزية والصينية، مما يحسّن استقرار الأرقام والتواريخ. (الافتراضي: true) | BOOLEAN | نعم | true / false |

### مدخلات s1

تظهر هذه المدخلات عند تحديد نموذج s1.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `voice` | صوت التركيب. اتركه غير متصل لصوت عشوائي. | FISHAUDIO_VOICE | لا | صوت واحد اختياري |
| `temperature` | التعبيرية. القيم الأعلى أكثر تنوعًا، والقيم الأدنى أكثر ثباتًا. (الافتراضي: 0.7) | FLOAT | نعم | 0.0 إلى 1.0 |
| `top_p` | التنوع عبر أخذ عينات النواة. (الافتراضي: 0.7) | FLOAT | نعم | 0.01 إلى 1.0 |
| `speed` | سرعة التحدث. 1.0 عادي، أقل من 1.0 أبطأ، أكبر من 1.0 أسرع. (الافتراضي: 1.0) | FLOAT | نعم | 0.5 إلى 2.0 |
| `volume` | ضبط مستوى الصوت بالديسيبل. 0 يعني عدم التغيير. (الافتراضي: 0.0) | FLOAT | نعم | -10.0 إلى 10.0 |
| `normalize` | تطبيع الأرقام والنص للإنجليزية والصينية، مما يحسّن استقرار الأرقام والتواريخ. (الافتراضي: true) | BOOLEAN | نعم | true / false |

**ملاحظة:** يجب ألا يكون مدخل `text` فارغًا. وسوم المتحدثين (@Voice1، @Voice2، إلخ) غير حساسة لحالة الأحرف ويجب أن تشير إلى صوت متصل؛ الإشارة إلى صوت غير متصل تؤدي إلى خطأ. عند اتصال صوتين أو أكثر، يجب أن يشير النص إلى كل صوت متصل مرة واحدة على الأقل، وإلا فستبلغ العقدة عن الوسوم المفقودة. على drama-3 و s2.1-pro، يؤدي توصيل 0 أصوات إلى استخدام صوت عشوائي، ويستخدم توصيل صوت واحد ذلك الصوت وحده، ويمكّن توصيل صوتين أو أكثر الحوار متعدد المتحدثين. على s1، يُستخدم صوت واحد اختياري، وتركه غير متصل يستخدم صوتًا عشوائيًا. يمكن وضع الإشارات في النص: [happy] و[whispering] على s2.1-pro، و(happy) على s1، و[directions] باللغة الطبيعية ووسوم الكلمات `<whisper>...</whisper>` على drama-3.
