# Fish Audio המרת טקסט לדיבור

צומת זה ממיר טקסט כתוב לאודיו מדובר באמצעות מודלים של Fish Audio לטקסט לדיבור. הוא תומך ברמזי רגש המוטמעים בטקסט ([happy], [whispering] ב-s2.1-pro; (happy) ב-s1) ובדיאלוג רב-דוברים באמצעות תגיות @Voice1/@Voice2 כאשר מספר קולות מחוברים. שני מודלים זמינים: s2.1-pro, אשר תומך בעד חמישה קולות ובדיאלוג רב-דוברים, ו-s1, אשר משתמש בקול אופציונלי יחיד.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `text` | הטקסט להמרה לדיבור. כאשר שני קולות או יותר מחוברים, סמן החלפות דובר עם @Voice1, @Voice2 וכו'. (ברירת מחדל: ריק) | STRING | כן | כל טקסט לא ריק |
| `model` | מודל לשימוש עבור טקסט לדיבור. | DYNAMIC_COMBO | כן | "s2.1-pro"<br>"s1" |
| `seed` | `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. (ברירת מחדל: 42) | INT | כן | 0 עד 2147483647 |

### קלטים של s2.1-pro

קלטים אלה מופיעים כאשר נבחר המודל s2.1-pro.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `voices` | חריץ מתרחב: חבר 0 עד 5 פריטי קול (`voice_1`, `voice_2`, ...). קולות לסינתזה. השאר ריק עבור קול ברירת המחדל. עם שני קולות או יותר, סמן החלפות דובר בטקסט באמצעות @Voice1, @Voice2 וכו'. | FISHAUDIO_VOICE | לא | 0 עד 5 קולות |
| `temperature` | רמת הבעה. ערכים גבוהים יותר מגוונים יותר, ערכים נמוכים יותר עקביים יותר. (ברירת מחדל: 0.7) | FLOAT | כן | 0.0 עד 1.0 |
| `top_p` | גיוון באמצעות דגימת גרעין (nucleus sampling). (ברירת מחדל: 0.7) | FLOAT | כן | 0.01 עד 1.0 |
| `speed` | קצב דיבור. 1.0 הוא רגיל, <1.0 איטי יותר, >1.0 מהיר יותר. (ברירת מחדל: 1.0) | FLOAT | כן | 0.5 עד 2.0 |
| `volume` | התאמת עוצמת קול בדציבלים. 0 הוא ללא שינוי. (ברירת מחדל: 0.0) | FLOAT | כן | -10.0 עד 10.0 |
| `normalize` | מנרמל מספרים וטקסט עבור אנגלית וסינית, ומשפר את היציבות של מספרים ותאריכים. (ברירת מחדל: true) | BOOLEAN | כן | true / false |

### קלטים של s1

קלטים אלה מופיעים כאשר נבחר המודל s1.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `voice` | קול לסינתזה. השאר לא מחובר עבור קול ברירת המחדל. | FISHAUDIO_VOICE | לא | קול בודד אופציונלי |
| `temperature` | רמת הבעה. ערכים גבוהים יותר מגוונים יותר, ערכים נמוכים יותר עקביים יותר. (ברירת מחדל: 0.7) | FLOAT | כן | 0.0 עד 1.0 |
| `top_p` | גיוון באמצעות דגימת גרעין (nucleus sampling). (ברירת מחדל: 0.7) | FLOAT | כן | 0.01 עד 1.0 |
| `speed` | קצב דיבור. 1.0 הוא רגיל, <1.0 איטי יותר, >1.0 מהיר יותר. (ברירת מחדל: 1.0) | FLOAT | כן | 0.5 עד 2.0 |
| `volume` | התאמת עוצמת קול בדציבלים. 0 הוא ללא שינוי. (ברירת מחדל: 0.0) | FLOAT | כן | -10.0 עד 10.0 |
| `normalize` | מנרמל מספרים וטקסט עבור אנגלית וסינית, ומשפר את היציבות של מספרים ותאריכים. (ברירת מחדל: true) | BOOLEAN | כן | true / false |

**הערה:** הקלט `text` חייב שלא להיות ריק. תגיות דובר (@Voice1, @Voice2 וכו') אינן תלויות רישיות וחייבות להתייחס לקול מחובר; תיוג קול שאינו מחובר מעלה שגיאה. כאשר שני קולות או יותר מחוברים, הטקסט חייב להתייחס לכל קול מחובר לפחות פעם אחת, אחרת הצומת מדווח על התגיות החסרות. ב-s2.1-pro, חיבור 0 קולות משתמש בקול ברירת המחדל, קול אחד משתמש באותו קול בלבד, ו-2 קולות או יותר מפעילים דיאלוג רב-דוברים. ב-s1, נעשה שימוש בקול אופציונלי יחיד, והשארתו לא מחוברת משתמשת בקול ברירת המחדל. ניתן למקם רמזי רגש בטקסט: [happy] ו-[whispering] ב-s2.1-pro, ו-(happy) ב-s1.
