# تبدیل متن به گفتار Fish Audio

این گره متن نوشته‌شده را با استفاده از مدل‌های تبدیل متن به گفتار Fish Audio به صدای گفتاری تبدیل می‌کند. از نشانه‌های جاسازی‌شده در متن پشتیبانی می‌کند: [happy] و [whispering] روی s2.1-pro، (happy) روی s1، و [directions] به زبان ساده به‌همراه برچسب‌های واژگانی `<whisper>...</whisper>` روی drama-3. گفت‌وگوی چندگوینده وقتی چند صدا متصل باشد از برچسب‌های @Voice1/@Voice2 استفاده می‌کند. سه مدل در دسترس است: drama-3 و s2.1-pro که هر دو از حداکثر پنج صدا و گفت‌وگوی چندگوینده پشتیبانی می‌کنند، و s1 که از یک صدای اختیاری استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | متن برای تبدیل به گفتار. وقتی دو صدا یا بیشتر متصل است، تغییر گوینده را با @Voice1، @Voice2 و غیره مشخص کنید. (پیش‌فرض: خالی) | STRING | بله | هر متن غیرخالی |
| `model` | مدل مورد استفاده برای تبدیل متن به گفتار. | DYNAMIC_COMBO | بله | "drama-3"<br>"s2.1-pro"<br>"s1" |
| `seed` | `seed` تعیین می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به seed قطعی نیستند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

### ورودی‌های drama-3 و s2.1-pro

این ورودی‌ها زمانی نمایش داده می‌شوند که مدل `drama-3` یا `s2.1-pro` انتخاب شده باشد. مجموعه پارامترها یکسان است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voices` | جای‌گاه قابل‌افزایش: 0 تا 5 آیتم صدا (`voice_1`، `voice_2`، ...) را متصل کنید. صداهای مورد استفاده برای سنتز. برای صدای تصادفی خالی بگذارید. با دو صدا یا بیشتر، تغییر گوینده را در متن با @Voice1، @Voice2 و غیره مشخص کنید. | FISHAUDIO_VOICE | خیر | 0 تا 5 صدا |
| `temperature` | رسایی. مقادیر بالاتر متنوع‌تر و مقادیر پایین‌تر یکنواخت‌تر هستند. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌گیری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 عادی، <1.0 کندتر، >1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم صدا بر حسب دسی‌بل. 0 بدون تغییر. (پیش‌فرض: 0.0) | FLOAT | بله | -10.0 تا 10.0 |
| `normalize` | نرمال‌سازی اعداد و متن برای انگلیسی و چینی، که پایداری اعداد و تاریخ‌ها را بهبود می‌دهد. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

### ورودی‌های s1

این ورودی‌ها زمانی نمایش داده می‌شوند که مدل s1 انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voice` | صدای مورد استفاده برای سنتز. برای صدای تصادفی متصل نکنید. | FISHAUDIO_VOICE | خیر | تک صدای اختیاری |
| `temperature` | رسایی. مقادیر بالاتر متنوع‌تر و مقادیر پایین‌تر یکنواخت‌تر هستند. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌گیری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 عادی، <1.0 کندتر، >1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم صدا بر حسب دسی‌بل. 0 بدون تغییر. (پیش‌فرض: 0.0) | FLOAT | بله | -10.0 تا 10.0 |
| `normalize` | نرمال‌سازی اعداد و متن برای انگلیسی و چینی، که پایداری اعداد و تاریخ‌ها را بهبود می‌دهد. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

**توجه:** ورودی `text` نباید خالی باشد. برچسب‌های گوینده (@Voice1، @Voice2 و غیره) به بزرگی و کوچکی حروف حساس نیستند و باید به صدای متصل‌شده اشاره کنند؛ برچسب‌زدن صدایی که متصل نیست خطا ایجاد می‌کند. وقتی دو صدا یا بیشتر متصل است، متن باید حداقل یک بار به هر صدای متصل اشاره کند، در غیر این صورت گره برچسب‌های جاافتاده را گزارش می‌دهد. روی drama-3 و s2.1-pro، اتصال 0 صدا از صدای تصادفی استفاده می‌کند، 1 صدا فقط از همان صدا استفاده می‌کند، و 2 صدا یا بیشتر گفت‌وگوی چندگوینده را فعال می‌کند. روی s1، یک صدای اختیاری استفاده می‌شود و اگر متصل نباشد از صدای تصادفی استفاده می‌شود. نشانه‌ها را می‌توان در متن قرار داد: [happy] و [whispering] روی s2.1-pro، (happy) روی s1، و [directions] به زبان ساده و برچسب‌های واژگانی `<whisper>...</whisper>` روی drama-3.
