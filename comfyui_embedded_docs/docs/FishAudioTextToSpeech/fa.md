# تبدیل متن به گفتار Fish Audio

این گره متن نوشته‌شده را با استفاده از مدل‌های تبدیل متن به گفتار Fish Audio به صدای گفتاری تبدیل می‌کند. این گره از نشانه‌های احساسی جای‌گرفته‌شده در متن ([happy]، [whispering] در s2.1-pro؛ (happy) در s1) و گفتگوی چندگوینده با برچسب‌های @Voice1/@Voice2 هنگام اتصال چند صدا پشتیبانی می‌کند. دو مدل در دسترس است: s2.1-pro، که از حداکثر پنج صدا و گفتگوی چندگوینده پشتیبانی می‌کند، و s1، که از یک صدای اختیاری استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | متنی که باید به گفتار تبدیل شود. با اتصال دو یا چند صدا، تغییر گوینده را با @Voice1، @Voice2 و غیره مشخص کنید. (پیش‌فرض: خالی) | STRING | بله | هر متن غیرخالی |
| `model` | مدل مورد استفاده برای تبدیل متن به گفتار. | DYNAMIC_COMBO | بله | "s2.1-pro"<br>"s1" |
| `seed` | مقدار seed کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به seed غیرقطعی هستند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

### ورودی‌های s2.1-pro

این ورودی‌ها زمانی ظاهر می‌شوند که مدل s2.1-pro انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voices` | جایگاه قابل افزایش: 0 تا 5 آیتم صدا (`voice_1`، `voice_2`، ...) را متصل کنید. صداها برای سنتز. برای صدای پیش‌فرض خالی بگذارید. با دو یا چند صدا، تغییر گوینده را در متن با @Voice1، @Voice2 و غیره مشخص کنید. | FISHAUDIO_VOICE | خیر | 0 تا 5 صدا |
| `temperature` | بیان احساسی. مقادیر بالاتر متنوع‌تر و مقادیر پایین‌تر باثبات‌تر هستند. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌گیری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 عادی است، کمتر از 1.0 کندتر، بیشتر از 1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم بلندی صدا بر حسب دسی‌بل. 0 یعنی بدون تغییر. (پیش‌فرض: 0.0) | FLOAT | بله | -10.0 تا 10.0 |
| `normalize` | اعداد و متن را برای انگلیسی و چینی نرمال‌سازی می‌کند و پایداری اعداد و تاریخ‌ها را بهبود می‌بخشد. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

### ورودی‌های s1

این ورودی‌ها زمانی ظاهر می‌شوند که مدل s1 انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voice` | صدای مورد استفاده برای سنتز. برای صدای پیش‌فرض متصل نگذارید. | FISHAUDIO_VOICE | خیر | یک صدای اختیاری |
| `temperature` | بیان احساسی. مقادیر بالاتر متنوع‌تر و مقادیر پایین‌تر باثبات‌تر هستند. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌گیری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 عادی است، کمتر از 1.0 کندتر، بیشتر از 1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم بلندی صدا بر حسب دسی‌بل. 0 یعنی بدون تغییر. (پیش‌فرض: 0.0) | FLOAT | بله | -10.0 تا 10.0 |
| `normalize` | اعداد و متن را برای انگلیسی و چینی نرمال‌سازی می‌کند و پایداری اعداد و تاریخ‌ها را بهبود می‌بخشد. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

**توجه:** ورودی `text` نباید خالی باشد. برچسب‌های گوینده (@Voice1، @Voice2 و غیره) به بزرگی و کوچکی حروف حساس نیستند و باید به صدای متصل‌شده اشاره کنند؛ برچسب زدن به صدایی که متصل نیست، خطا ایجاد می‌کند. هنگامی که دو یا چند صدا متصل هستند، متن باید حداقل یک بار به هر صدای متصل ارجاع دهد، در غیر این صورت گره برچسب‌های جاافتاده را گزارش می‌کند. در s2.1-pro، اتصال 0 صدا از صدای پیش‌فرض استفاده می‌کند، 1 صدا فقط از همان صدا استفاده می‌کند، و 2 صدا یا بیشتر گفتگوی چندگوینده را فعال می‌کند. در s1، یک صدای اختیاری واحد استفاده می‌شود و اگر آن را متصل نگذارید، از صدای پیش‌فرض استفاده می‌شود. نشانه‌های احساسی را می‌توان در متن قرار داد: [happy] و [whispering] در s2.1-pro، و (happy) در s1.
