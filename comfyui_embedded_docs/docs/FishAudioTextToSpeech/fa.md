# FishAudioTextToSpeech

این گره با استفاده از مدل‌های تبدیل متن به گفتار Fish Audio، متن نوشته‌شده را به گفتار صوتی تبدیل می‌کند. این گره از نشانه‌های احساسات تعبیه‌شده در متن پشتیبانی می‌کند ([happy]، [whispering] در s2.1-pro؛ (happy) در s1) و گفتگوی چند‌نفره با برچسب‌های @Voice1/@Voice2 زمانی که چند صدا متصل باشند. دو مدل در دسترس است: s2.1-pro که تا پنج صدا و گفتگوی چند‌نفره را پشتیبانی می‌کند، و s1 که از یک صدای اختیاری واحد استفاده می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text` | متن مورد نظر برای تبدیل به گفتار. وقتی دو یا چند صدا متصل باشند، تغییر گوینده را با @Voice1، @Voice2 و غیره مشخص کنید. نباید خالی باشد. (پیش‌فرض: خالی) | STRING | بله | هر متن غیرخالی |
| `model` | مدل مورد استفاده برای تبدیل متن به گفتار. | DYNAMIC_COMBO | بله | "s2.1-pro"<br>"s1" |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed قطعی نیستند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

### ورودی‌های s2.1-pro

این ورودی‌ها زمانی ظاهر می‌شوند که مدل s2.1-pro انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voices` | اسلات قابل گسترش: ۱ تا ۵ آیتم صدا را متصل کنید (`voice_1`، `voice_2`، ...). صداها برای سنتز. برای صدای پیش‌فرض خالی بگذارید. با دو یا چند صدا، تغییر گوینده را در متن با @Voice1، @Voice2 و غیره علامت‌گذاری کنید. | FISHAUDIO_VOICE | خیر | 0 تا 5 صدا |
| `temperature` | بیانگری. مقادیر بالاتر متنوع‌تر، مقادیر پایین‌تر سازگارتر. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌برداری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 طبیعی، <1.0 آهسته‌تر، >1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم بلندی صدا بر حسب دسی‌بل. 0 به معنای بدون تغییر است. (پیش‌فرض: 0.0) | FLOAT | بله | 10.0- تا 10.0 |
| `normalize` | عادی‌سازی اعداد و متن برای انگلیسی و چینی، بهبود پایداری برای اعداد و تاریخ‌ها. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

### ورودی‌های s1

این ورودی‌ها زمانی ظاهر می‌شوند که مدل s1 انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `voice` | صدای مورد استفاده برای سنتز. برای صدای پیش‌فرض بدون اتصال بگذارید. | FISHAUDIO_VOICE | خیر | یک صدای اختیاری |
| `temperature` | بیانگری. مقادیر بالاتر متنوع‌تر، مقادیر پایین‌تر سازگارتر. (پیش‌فرض: 0.7) | FLOAT | بله | 0.0 تا 1.0 |
| `top_p` | تنوع از طریق نمونه‌برداری هسته‌ای. (پیش‌فرض: 0.7) | FLOAT | بله | 0.01 تا 1.0 |
| `speed` | سرعت گفتار. 1.0 طبیعی، <1.0 آهسته‌تر، >1.0 سریع‌تر. (پیش‌فرض: 1.0) | FLOAT | بله | 0.5 تا 2.0 |
| `volume` | تنظیم بلندی صدا بر حسب دسی‌بل. 0 به معنای بدون تغییر است. (پیش‌فرض: 0.0) | FLOAT | بله | 10.0- تا 10.0 |
| `normalize` | عادی‌سازی اعداد و متن برای انگلیسی و چینی، بهبود پایداری برای اعداد و تاریخ‌ها. (پیش‌فرض: true) | BOOLEAN | بله | true / false |

**نکته:** ورودی `text` نباید خالی باشد. برچسب‌های گوینده (@Voice1، @Voice2 و غیره) به بزرگی/کوچکی حروف حساس نیستند و باید به یک صدای متصل اشاره کنند؛ اشاره به صدایی که متصل نیست خطا ایجاد می‌کند. وقتی دو یا چند صدا متصل باشند، متن باید حداقل یک بار به هر صدای متصل اشاره کند، در غیر این صورت گره برچسب‌های از دست رفته را گزارش می‌دهد. در s2.1-pro، اتصال صفر صدا از صدای پیش‌فرض استفاده می‌کند، یک صدا فقط از همان صدا استفاده می‌کند، و دو یا چند صدا گفتگوی چند‌نفره را فعال می‌کنند. در s1، از یک صدای اختیاری واحد استفاده می‌شود و بدون اتصال، صدای پیش‌فرض استفاده می‌شود. نشانه‌های احساسات را می‌توان در متن قرار داد: [happy] و [whispering] در s2.1-pro، و (happy) در s1.
