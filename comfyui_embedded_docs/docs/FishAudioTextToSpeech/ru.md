# Fish Audio: текст в речь

Этот узел преобразует письменный текст в озвученную речь с помощью моделей Fish Audio для синтеза речи. Он поддерживает метки, встроенные в текст: [happy] и [whispering] на s2.1-pro, (happy) на s1, а также обычные текстовые [directions] и теги слов `<whisper>...</whisper>` на drama-3. Диалог нескольких говорящих использует теги @Voice1/@Voice2, когда подключено несколько голосов. Доступны три модели: drama-3 и s2.1-pro — обе поддерживают до пяти голосов и диалог нескольких говорящих, а s1 использует один необязательный голос.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст для преобразования в речь. Если подключено два или более голоса, отмечайте смену говорящего с помощью @Voice1, @Voice2 и т. д. (по умолчанию: пусто) | STRING | Да | Любой непустой текст |
| `model` | Модель для синтеза речи. | DYNAMIC_COMBO | Да | "drama-3"<br>"s2.1-pro"<br>"s1" |
| `seed` | `seed` управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от `seed`. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |

### Входы drama-3 и s2.1-pro

Эти входы появляются, когда выбрана модель `drama-3` или `s2.1-pro`. Наборы параметров идентичны.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voices` | Расширяемый слот: подключите от 0 до 5 голосовых элементов (`voice_1`, `voice_2`, ...). Голоса для синтеза. Оставьте пустым для случайного голоса. При двух или более голосах отмечайте смену говорящего в тексте с помощью @Voice1, @Voice2 и т. д. | FISHAUDIO_VOICE | Нет | 0 до 5 голосов |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — более стабильный результат. (по умолчанию: 0.7) | FLOAT | Да | 0.0 до 1.0 |
| `top_p` | Разнообразие с помощью ядерной выборки. (по умолчанию: 0.7) | FLOAT | Да | 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормальная, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, повышая стабильность для чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

### Входы s1

Эти входы появляются, когда выбрана модель s1.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voice` | Голос для синтеза. Оставьте неподключённым для случайного голоса. | FISHAUDIO_VOICE | Нет | Один необязательный голос |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — более стабильный результат. (по умолчанию: 0.7) | FLOAT | Да | 0.0 до 1.0 |
| `top_p` | Разнообразие с помощью ядерной выборки. (по умолчанию: 0.7) | FLOAT | Да | 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормальная, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, повышая стабильность для чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

**Примечание:** Вход `text` не должен быть пустым. Теги говорящих (@Voice1, @Voice2 и т. д.) нечувствительны к регистру и должны указывать на подключённый голос; указание голоса, который не подключён, вызывает ошибку. Когда подключено два или более голоса, текст должен ссылаться на каждый подключённый голос хотя бы один раз, иначе узел сообщит об отсутствующих тегах. На drama-3 и s2.1-pro подключение 0 голосов использует случайный голос, 1 голос использует только этот голос, а 2 или более голосов включают диалог нескольких говорящих. На s1 используется один необязательный голос; если его не подключить, используется случайный голос. Метки можно размещать в тексте: [happy] и [whispering] на s2.1-pro, (happy) на s1, а также обычные текстовые [directions] и теги слов `<whisper>...</whisper>` на drama-3.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированная речь в виде аудиофайла. | AUDIO |
