# FishAudioTextToSpeech

Этот узел преобразует письменный текст в речь с помощью моделей текст-в-речь Fish Audio. Он поддерживает эмоциональные подсказки, встроенные в текст ([happy], [whispering] для s2.1-pro; (happy) для s1), и многоголосый диалог с использованием тегов @Voice1/@Voice2, когда подключено несколько голосов. Доступны две модели: s2.1-pro, которая поддерживает до пяти голосов и многоголосый диалог, и s1, которая использует один опциональный голос.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст для преобразования в речь. При подключении двух и более голосов отмечайте смену говорящего с помощью @Voice1, @Voice2 и т. д. Не должен быть пустым. (по умолчанию: пусто) | STRING | Да | Любой непустой текст |
| `model` | Модель для преобразования текста в речь. | DYNAMIC_COMBO | Да | "s2.1-pro"<br>"s1" |
| `seed` | Силд определяет, должен ли узел перезапускаться; результаты недетерминированы независимо от силда. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |

### Входы s2.1-pro

Эти входы появляются при выборе модели s2.1-pro.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voices` | Расширяемый слот: подключите от 1 до 5 голосовых элементов (`voice_1`, `voice_2`, ...). Голоса для синтеза. Оставьте пустым для голоса по умолчанию. При подключении двух и более голосов отмечайте смену говорящего в тексте с помощью @Voice1, @Voice2 и т. д. | FISHAUDIO_VOICE | Нет | от 0 до 5 голосов |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — больше согласованности. (по умолчанию: 0.7) | FLOAT | Да | 0.0 до 1.0 |
| `top_p` | Разнообразие с помощью семплирования по ядру (nucleus sampling). (по умолчанию: 0.7) | FLOAT | Да | 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормально, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, повышая стабильность для чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

### Входы s1

Эти входы появляются при выборе модели s1.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voice` | Голос для синтеза. Оставьте неподключенным для голоса по умолчанию. | FISHAUDIO_VOICE | Нет | Один необязательный голос |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — больше согласованности. (по умолчанию: 0.7) | FLOAT | Да | 0.0 до 1.0 |
| `top_p` | Разнообразие с помощью семплирования по ядру (nucleus sampling). (по умолчанию: 0.7) | FLOAT | Да | 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормально, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, повышая стабильность для чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

**Примечание:** Вход `text` не должен быть пустым. Теги говорящего (@Voice1, @Voice2 и т. д.) не чувствительны к регистру и должны ссылаться на подключенный голос; указание неподключенного голоса вызывает ошибку. При подключении двух и более голосов текст должен упоминать каждый подключенный голос хотя бы один раз, иначе узел сообщит об отсутствующих тегах. В s2.1-pro подключение 0 голосов использует голос по умолчанию, 1 голос — только этот голос, а 2 и более голосов включают многоголосый диалог. В s1 используется один необязательный голос, и если он не подключен, используется голос по умолчанию. Эмоциональные подсказки можно размещать в тексте: [happy] и [whispering] для s2.1-pro и (happy) для s1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированная речь в виде аудиофайла. | AUDIO |
