# Fish Audio: текст в речь

Этот узел преобразует письменный текст в речь с помощью моделей преобразования текста в речь Fish Audio. Он поддерживает эмоциональные подсказки, встроенные в текст ([happy], [whispering] в s2.1-pro; (happy) в s1), и диалог нескольких говорящих с использованием тегов @Voice1/@Voice2, когда подключено несколько голосов. Доступны две модели: s2.1-pro, которая поддерживает до пяти голосов и диалог нескольких говорящих, и s1, использующая один необязательный голос.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст для преобразования в речь. При подключении двух или более голосов отмечайте смену говорящего с помощью @Voice1, @Voice2 и т. д. (по умолчанию: пусто) | STRING | Да | Любой непустой текст |
| `model` | Модель для преобразования текста в речь. | DYNAMIC_COMBO | Да | "s2.1-pro"<br>"s1" |
| `seed` | Seed управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. (по умолчанию: 42) | INT | Да | от 0 до 2147483647 |

### Входы s2.1-pro

Эти входы появляются, когда выбрана модель s2.1-pro.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voices` | Расширяемый слот: подключите от 0 до 5 голосовых элементов (`voice_1`, `voice_2`, ...). Голоса для синтеза. Оставьте пустым для голоса по умолчанию. При двух или более голосах отмечайте смену говорящего в тексте с помощью @Voice1, @Voice2 и т. д. | FISHAUDIO_VOICE | Нет | от 0 до 5 голосов |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — более стабильный результат. (по умолчанию: 0.7) | FLOAT | Да | от 0.0 до 1.0 |
| `top_p` | Разнообразие за счёт нуклеарной выборки. (по умолчанию: 0.7) | FLOAT | Да | от 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормальная, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | от 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | от -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, что повышает стабильность чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

### Входы s1

Эти входы появляются, когда выбрана модель s1.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `voice` | Голос для синтеза. Оставьте неподключённым для голоса по умолчанию. | FISHAUDIO_VOICE | Нет | Необязательный одиночный голос |
| `temperature` | Выразительность. Более высокие значения дают больше разнообразия, более низкие — более стабильный результат. (по умолчанию: 0.7) | FLOAT | Да | от 0.0 до 1.0 |
| `top_p` | Разнообразие за счёт нуклеарной выборки. (по умолчанию: 0.7) | FLOAT | Да | от 0.01 до 1.0 |
| `speed` | Скорость речи. 1.0 — нормальная, <1.0 — медленнее, >1.0 — быстрее. (по умолчанию: 1.0) | FLOAT | Да | от 0.5 до 2.0 |
| `volume` | Регулировка громкости в децибелах. 0 — без изменений. (по умолчанию: 0.0) | FLOAT | Да | от -10.0 до 10.0 |
| `normalize` | Нормализовать числа и текст для английского и китайского языков, что повышает стабильность чисел и дат. (по умолчанию: true) | BOOLEAN | Да | true / false |

**Примечание:** Вход `text` не должен быть пустым. Теги говорящего (@Voice1, @Voice2 и т. д.) нечувствительны к регистру и должны ссылаться на подключённый голос; указание голоса, который не подключён, вызывает ошибку. Когда подключены два или более голосов, текст должен ссылаться на каждый подключённый голос как минимум один раз, иначе узел сообщит об отсутствующих тегах. В s2.1-pro подключение 0 голосов использует голос по умолчанию, 1 голос использует только этот голос, а 2 или более голосов включают диалог нескольких говорящих. В s1 используется один необязательный голос; если его не подключить, используется голос по умолчанию. Эмоциональные подсказки можно размещать в тексте: [happy] и [whispering] в s2.1-pro и (happy) в s1.

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированная речь в виде аудиофайла. | AUDIO |
