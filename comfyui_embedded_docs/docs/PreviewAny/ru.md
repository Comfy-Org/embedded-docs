# Предпросмотр любого

PreviewAny преобразует любое входное значение в читаемый текст, чтобы вы могли его просмотреть. Строки передаются без изменений, числа и логические значения становятся обычным текстом, а другие типы данных, когда возможно, сериализуются в JSON (с возвратом к их простой строковой форме, если сериализация не удаётся). Полученный текст отображается в пользовательском интерфейсе и также возвращается как строковый выход для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `источник` | Принимает входные данные любого типа для отображения в предпросмотре. Если значение не предоставлено, предпросмотр показывает 'None'. | ANY | Да | Любой тип данных |

**Поведение при преобразовании**

- Значения типа STRING отображаются точно в том виде, в каком были предоставлены.
- Значения типа INT, FLOAT или BOOLEAN преобразуются в обычный текст.
- Любое другое непустое значение преобразуется в текст JSON с отступом в 4 пробела; если это преобразование не удаётся, узел возвращается к простому текстовому представлению значения. Если и это не удаётся, предпросмотр показывает сообщение 'source exists, but could not be serialized.'
- Если значение не подключено или значение пустое, предпросмотр показывает 'None'.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `result` | Входное значение, преобразованное в текстовый формат. Этот же текст также отображается в пользовательском интерфейсе. | STRING |
