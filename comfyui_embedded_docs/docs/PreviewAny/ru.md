# Предпросмотр любого

`PreviewAny` преобразует любое входное значение в читаемый текст, чтобы вы могли его просмотреть. Строки передаются без изменений, числа и логические значения становятся обычным текстом, а другие типы данных сериализуются в JSON, когда это возможно (если сериализация не удаётся, используется обычное строковое представление). Полученный текст отображается в пользовательском интерфейсе, а также возвращается в виде строкового вывода для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `источник` | Принимает любой тип входных данных для отображения в предпросмотре. Если значение не указано, предпросмотр показывает «None». | ANY | Да | Любой тип данных |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `result` | Входное значение, преобразованное в текстовый формат. Этот же текст отображается в пользовательском интерфейсе. | STRING |
