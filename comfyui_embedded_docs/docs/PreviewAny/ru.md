# Предпросмотр любого

Узел PreviewAny принимает любое входное значение и отображает его в виде читаемого текста в интерфейсе. Он предназначен для проверки и отладки значений в любой точке рабочего процесса: строки отображаются как есть, числа и логические значения преобразуются в текст, а другие объекты форматируются как JSON. Преобразованный текст также передается в виде строкового выхода, чтобы его можно было использовать другими узлами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `source` | Значение для предварительного просмотра в виде текста. Принимает любой тип данных. Строки передаются без изменений; числа и логические значения преобразуются в текст; другие значения сериализуются в JSON с отступами. Если сериализация в JSON не удается, используется простое строковое представление значения, а если и оно не удается, отображается текст «source exists, but could not be serialized». | ANY | Да | Любой тип данных |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `UI Text Display` | Отображает входные данные, преобразованные в текст, в пользовательском интерфейсе. Этот же текст также возвращается в виде строкового выхода для дальнейшей обработки другими узлами. | STRING |
