# پیش‌نمایش به صورت متن

گره PreviewAny هر مقدار ورودی را می‌پذیرد و آن را به‌صورت متن خوانا در رابط کاربری نمایش می‌دهد. این گره برای بازرسی و اشکال‌زدایی مقادیر در هر نقطه‌ای از گردش کار طراحی شده است: رشته‌ها به‌صورت اصلی نمایش داده می‌شوند، اعداد و مقادیر بولی به متن تبدیل می‌شوند و سایر اشیاء به‌صورت JSON قالب‌بندی می‌شوند. متن تبدیل‌شده همچنین به‌عنوان خروجی رشته‌ای ارسال می‌شود تا توسط سایر گره‌ها قابل استفاده باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `source` | مقداری که به‌صورت متن پیش‌نمایش می‌شود. هر نوع داده‌ای را می‌پذیرد. رشته‌ها بدون تغییر عبور داده می‌شوند؛ اعداد و مقادیر بولی به متن تبدیل می‌شوند؛ سایر مقادیر به JSON با تورفتگی (indentation) سریال‌سازی می‌شوند. اگر سریال‌سازی JSON ناموفق باشد، نمایش رشته‌ای ساده مقدار استفاده می‌شود و اگر آن نیز ناموفق بود، متن «source exists, but could not be serialized.» نمایش داده می‌شود. | ANY | بله | هر نوع داده‌ای |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `UI Text Display` | داده ورودی را به متن تبدیل‌شده در رابط کاربری نمایش می‌دهد. همان متن همچنین به‌عنوان خروجی رشته‌ای برای پردازش بیشتر توسط سایر گره‌ها بازگردانده می‌شود. | STRING |
