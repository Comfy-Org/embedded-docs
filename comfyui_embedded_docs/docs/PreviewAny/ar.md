# معاينة أي

يقوم PreviewAny بتحويل أي قيمة إدخال إلى نص قابل للقراءة حتى تتمكن من فحصه. تمر السلاسل النصية دون تغيير، وتتحول الأرقام والقيم المنطقية إلى نص عادي، وتُسلسل أنواع البيانات الأخرى إلى JSON عند الإمكان (مع الرجوع إلى صيغتها النصية العادية إذا فشلت التسلسل). يُعرض النص الناتج في واجهة المستخدم ويُعاد أيضًا كمخرج نصي للمعالجة الإضافية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `المصدر` | يقبل أي نوع بيانات كمدخل لعرض المعاينة. إذا لم يتم توفير قيمة، تعرض المعاينة 'None'. | ANY | نعم | أي نوع بيانات |

**سلوك التحويل**

- تُعرض القيم من النوع STRING كما هي تمامًا.
- تُحوَّل القيم من النوع INT أو FLOAT أو BOOLEAN إلى نص عادي.
- تُحوَّل أي قيمة أخرى غير فارغة إلى نص JSON بمسافة بادئة مقدارها 4 مسافات؛ وإذا فشل هذا التحويل، تتراجع العقدة إلى الصيغة النصية العادية للقيمة. إذا فشل ذلك أيضًا، تعرض المعاينة الرسالة 'source exists, but could not be serialized.'
- إذا لم تكن هناك قيمة موصولة أو كانت القيمة فارغة، تعرض المعاينة 'None'.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `result` | قيمة الإدخال المحوَّلة إلى صيغة نصية. يُعرض النص نفسه أيضًا في واجهة المستخدم. | STRING |
