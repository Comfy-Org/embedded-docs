# プレビュー任意

The PreviewAny ノードは、任意の入力値を受け取り、それを読み取り可能なテキストとしてインターフェースに表示します。ワークフローの任意の時点で値を検査・デバッグするために設計されています。文字列はそのまま表示され、数値とブール値はテキストに変換され、その他のオブジェクトは JSON としてフォーマットされます。変換されたテキストは文字列出力としても渡されるため、他のノードで使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `source` | テキストとしてプレビューする値。あらゆるデータ型を受け付けます。文字列はそのまま渡され、数値とブール値はテキストに変換され、その他の値はインデント付き JSON にシリアライズされます。JSON シリアライズに失敗した場合は、値の単純な文字列表現が使用され、それも失敗した場合は「source exists, but could not be serialized.」というテキストが表示されます。 | ANY | はい | 任意のデータ型 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| UI Text Display | 入力データをテキストに変換したものをユーザーインターフェースに表示します。同じテキストは、他のノードでさらに処理するための文字列出力としても返されます。 | STRING |
