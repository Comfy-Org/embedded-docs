# 미리보기 아무거나

PreviewAny 노드는 모든 입력 값을 받아 인터페이스에서 읽을 수 있는 텍스트로 표시합니다. 이 노드는 워크플로우의 어느 지점에서든 값을 검사하고 디버깅하기 위해 설계되었습니다. 문자열은 그대로 표시되고, 숫자와 부울은 텍스트로 변환되며, 기타 객체는 JSON으로 형식화됩니다. 변환된 텍스트는 문자열 출력으로도 전달되어 다른 노드에서 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `source` | 텍스트로 미리 볼 값을 지정합니다. 모든 데이터 타입을 허용합니다. 문자열은 변경 없이 그대로 전달되며, 숫자와 부울은 텍스트로 변환되고, 기타 값은 들여쓰기된 JSON으로 직렬화됩니다. JSON 직렬화에 실패하면 값의 일반 문자열 표현이 사용되며, 이 역시 실패하면 "source exists, but could not be serialized."라는 텍스트가 표시됩니다. | ANY | 예 | 모든 데이터 타입 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `UI Text Display` | 입력 데이터가 텍스트로 변환된 결과를 사용자 인터페이스에 표시합니다. 동일한 텍스트는 문자열 출력으로도 반환되어 다른 노드에서 추가 처리에 사용할 수 있습니다. | STRING |
