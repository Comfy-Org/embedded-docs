# PikaStartEndFrameNode2_2

הצומת PikaFrames v2.2 יוצר וידאו על ידי שילוב הפריים הראשון והאחרון שלך. אתם מעלים שתי תמונות כדי להגדיר את נקודות ההתחלה והסיום, וה-AI יוצר מעבר חלק ביניהן כדי להפיק וידאו שלם.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `image_start` | התמונה הראשונה לשילוב. | IMAGE | כן | - |
| `image_end` | התמונה האחרונה לשילוב. | IMAGE | כן | - |
| `prompt_text` | הנחיית טקסט המתארת את תוכן הווידאו הרצוי. | STRING | כן | - |
| `negative_prompt` | טקסט המתאר ממה להימנע בווידאו. | STRING | כן | - |
| `seed` | ערך seed אקראי לצורך עקביות ביצירה. | INT | כן | - |
| `resolution` | רזולוציית הווידאו של הפלט. | STRING | כן | - |
| `duration` | משך הווידאו הנוצר. | INT | כן | - |
