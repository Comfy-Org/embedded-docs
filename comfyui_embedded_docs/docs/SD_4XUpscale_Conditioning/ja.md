# SD_4X拡大条件付け

SD_4XUpscale_Conditioning ノードは、拡散モデルを使用して画像をアップスケールするためのコンディショニングデータを準備します。入力画像とコンディショニングデータを受け取り、スケーリングとノイズ増強を適用して、アップスケール処理を導く修正されたコンディショニングを作成します。このノードは、ポジティブおよびネガティブのコンディショニングとともに、アップスケールされた寸法に対応する潜在表現を出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | アップスケールする入力画像 | IMAGE | はい | - |
| `positive` | 生成を望ましい内容に導くポジティブコンディショニングデータ | CONDITIONING | はい | - |
| `negative` | 生成を望ましくない内容から遠ざけるネガティブコンディショニングデータ | CONDITIONING | はい | - |
| `scale_ratio` | 入力画像に適用されるスケーリング係数（デフォルト: 4.0） | FLOAT | はい | 0.0 - 10.0 |
| `noise_augmentation` | アップスケール処理中に追加するノイズの量（デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |

ターゲットとなるアップスケール後の寸法は、入力画像の寸法に `scale_ratio` を乗算して計算されます。コンディショニングに埋め込まれた画像と出力潜在表現は、どちらもそのターゲット寸法の4分の1のサイズで作成されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | アップスケール情報が適用された修正済みポジティブコンディショニング | CONDITIONING |
| `negative` | アップスケール情報が適用された修正済みネガティブコンディショニング | CONDITIONING |
| `latent` | アップスケールされた寸法に一致する空の潜在表現 | LATENT |
