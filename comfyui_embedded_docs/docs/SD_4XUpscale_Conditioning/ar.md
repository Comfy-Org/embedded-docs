# تحسين SD 4X

تعمل عقدة `SD_4XUpscale_Conditioning` على تجهيز بيانات التوجيه لرفع دقة الصور باستخدام نماذج الانتشار. وهي تأخذ صور الإدخال وبيانات التوجيه، ثم تطبق القياس وزيادة الضوضاء لإنشاء توجيه معدّل يوجه عملية رفع الدقة. تُخرج العقدة كلاً من التوجيه الإيجابي والسلبي إلى جانب تمثيلات كامنة للأبعاد المرفوعة الدقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `الصور` | صور الإدخال المراد رفع دقتها | IMAGE | نعم | - |
| `إيجابي` | بيانات التوجيه الإيجابية التي توجه التوليد نحو المحتوى المطلوب | CONDITIONING | نعم | - |
| `سلبي` | بيانات التوجيه السلبية التي تبعد التوليد عن المحتوى غير المرغوب فيه | CONDITIONING | نعم | - |
| `نسبة المقياس` | عامل القياس المطبق على صور الإدخال (الافتراضي: 4.0) | FLOAT | لا | 0.0 - 10.0 |
| `تعزيز الضجيج` | مقدار الضوضاء المضافة أثناء عملية رفع الدقة (الافتراضي: 0.0) | FLOAT | لا | 0.0 - 1.0 |

ملاحظة: `noise_augmentation` هو معامل متقدم، يظهر في واجهة العقدة تحت مفتاح التبديل «Advanced».

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | توجيه إيجابي معدل مع تطبيق معلومات رفع الدقة | CONDITIONING |
| `سلبي` | توجيه سلبي معدل مع تطبيق معلومات رفع الدقة | CONDITIONING |
| `كامن` | تمثيل كامن فارغ يطابق أبعاد رفع الدقة | LATENT |
