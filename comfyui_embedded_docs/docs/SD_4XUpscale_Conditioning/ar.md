# تحسين SD 4X

تُهيّئ عقدة SD_4XUpscale_Conditioning بيانات التكييف لرفع دقة الصور باستخدام نماذج الانتشار. تقوم بقياس الصور المدخلة وفق نسبة مختارة، وتضيف تحسينًا اختياريًا للضجيج، وتعيد التكييف الإيجابي والسلبي المعدّلين مع latent فارغ بالحجم المرفوع.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `الصور` | الصور المدخلة المراد رفع دقتها. | IMAGE | نعم | - |
| `إيجابي` | بيانات التكييف الإيجابي التي توجّه التوليد نحو المحتوى المطلوب. | CONDITIONING | نعم | - |
| `سلبي` | بيانات التكييف السلبي التي توجّه التوليد بعيدًا عن المحتوى غير المرغوب فيه. | CONDITIONING | نعم | - |
| `نسبة المقياس` | المعامل المضروب في أبعاد الصورة المدخلة عند إعداد التكييف وlatent بالحجم المرفوع (القيمة الافتراضية: 4.0). | FLOAT | نعم | 0.0 - 10.0 (خطوة: 0.01) |
| `تعزيز الضجيج` | مقدار الضجيج المضاف أثناء عملية رفع الدقة (القيمة الافتراضية: 0.0). | FLOAT | نعم | 0.0 - 1.0 (خطوة: 0.001) |

ملاحظة: `noise_augmentation` معامل متقدم، يظهر في واجهة العقدة ضمن مفتاح "Advanced".

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف إيجابي معدّل بعد تطبيق بيانات الصورة المكبّرة وفق النسبة وإعدادات تحسين الضجيج. | CONDITIONING |
| `negative` | تكييف سلبي معدّل بعد تطبيق بيانات الصورة المكبّرة وفق النسبة وإعدادات تحسين الضجيج. | CONDITIONING |
| `latent` | تمثيل latent فارغ يطابق الأبعاد المرفوعة. | LATENT |
