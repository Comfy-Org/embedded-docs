# تحسين SD 4X

### SD_4XUpscale_Conditioning

تقوم عقدة SD_4XUpscale_Conditioning بإعداد بيانات التوجيه (conditioning) لتكبير حجم الصور باستخدام نماذج الانتشار. تأخذ الصور المدخلة وبيانات التوجيه، ثم تطبق التحجيم وزيادة الضوضاء لإنشاء توجيه معدل يوجه عملية التكبير. تخرج العقدة كلاً من التوجيه الإيجابي والسلبي مع تمثيلات كامنة (latent) للأبعاد المكبرة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `images` | الصور المدخلة التي سيتم تكبيرها | IMAGE | نعم | - |
| `positive` | بيانات التوجيه الإيجابية التي توجه التوليد نحو المحتوى المطلوب | CONDITIONING | نعم | - |
| `negative` | بيانات التوجيه السلبية التي تبتعد بالتوليد عن المحتوى غير المرغوب فيه | CONDITIONING | نعم | - |
| `scale_ratio` | عامل التحجيم المطبق على الصور المدخلة (الافتراضي: 4.0) | FLOAT | نعم | 0.0 - 10.0 |
| `noise_augmentation` | مقدار الضوضاء المضافة أثناء عملية التكبير (الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |

يتم حساب الأبعاد المستهدفة للتكبير بضرب أبعاد الصورة المدخلة في `scale_ratio`. يتم إنشاء الصورة المدمجة في التوجيه والناتج الكامن عند ربع تلك الأبعاد المستهدفة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | توجيه إيجابي معدّل مع تطبيق معلومات التكبير | CONDITIONING |
| `negative` | توجيه سلبي معدّل مع تطبيق معلومات التكبير | CONDITIONING |
| `latent` | تمثيل كامن فارغ يطابق الأبعاد المكبرة | LATENT |
