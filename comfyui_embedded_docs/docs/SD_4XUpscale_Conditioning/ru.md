# SD_4XUpscale_Conditioning

Узел SD_4XUpscale_Conditioning подготавливает данные conditioning для масштабирования изображений с помощью диффузионных моделей. Он принимает входные изображения и данные conditioning, затем применяет масштабирование и шумовую аугментацию для создания модифицированных данных conditioning, которые направляют процесс масштабирования. Узел выводит как положительные, так и отрицательные данные conditioning, а также латентные представления для масштабированных размеров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Входные изображения для масштабирования | IMAGE | Да | - |
| `положительный` | Положительные данные conditioning, направляющие генерацию к желаемому содержимому | CONDITIONING | Да | - |
| `отрицательный` | Отрицательные данные conditioning, уводящие генерацию от нежелательного содержимого | CONDITIONING | Да | - |
| `коэффициент_масштабирования` | Коэффициент масштабирования, применяемый к входным изображениям (по умолчанию: 4.0) | FLOAT | Нет | 0.0 - 10.0 |
| `шумовое_увеличение` | Количество шума, добавляемого в процессе масштабирования (по умолчанию: 0.0) | FLOAT | Нет | 0.0 - 1.0 |

Примечание: `noise_augmentation` — это дополнительный параметр, отображаемый в интерфейсе узла под переключателем "Advanced".

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированные положительные данные conditioning с применённой информацией о масштабировании | CONDITIONING |
| `отрицательный` | Модифицированные отрицательные данные conditioning с применённой информацией о масштабировании | CONDITIONING |
| `латентный` | Пустое латентное представление, соответствующее масштабированным размерам | LATENT |
