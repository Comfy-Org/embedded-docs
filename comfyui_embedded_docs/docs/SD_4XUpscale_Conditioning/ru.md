# SD_4XUpscale_Conditioning

Узел `SD_4XUpscale_Conditioning` подготавливает данные conditioning для масштабирования изображений с использованием диффузионных моделей. Он принимает входные изображения и данные conditioning, затем применяет масштабирование и шумовую аугментацию для создания модифицированного conditioning, которое направляет процесс масштабирования. Узел выводит как положительное, так и отрицательное conditioning, а также латентные представления для масштабированных размеров.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Входные изображения для масштабирования | IMAGE | Да | - |
| `positive` | Положительные данные conditioning, направляющие генерацию к желаемому содержимому | CONDITIONING | Да | - |
| `negative` | Отрицательные данные conditioning, отталкивающие генерацию от нежелательного содержимого | CONDITIONING | Да | - |
| `scale_ratio` | Коэффициент масштабирования, применяемый к входным изображениям (по умолчанию: 4.0) | FLOAT | Да | 0.0 - 10.0 |
| `noise_augmentation` | Количество шума, добавляемого в процессе масштабирования (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |

Целевые размеры масштабирования вычисляются умножением размеров входного изображения на `scale_ratio`. Изображение, встроенное в conditioning, и выходной latent создаются в одну четверть от этих целевых размеров.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное conditioning с примененной информацией о масштабировании | CONDITIONING |
| `negative` | Модифицированное отрицательное conditioning с примененной информацией о масштабировании | CONDITIONING |
| `latent` | Пустое латентное представление, соответствующее масштабированным размерам | LATENT |
