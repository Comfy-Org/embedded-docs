# SD_4XUpscale_Conditioning

Узел SD_4XUpscale_Conditioning подготавливает данные кондиционирования для увеличения изображений с помощью диффузионных моделей. Он масштабирует входные изображения с выбранным коэффициентом, добавляет опциональную аугментацию шума и возвращает изменённые положительное и отрицательное кондиционирование вместе с пустым латентным представлением для увеличенного размера.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Входные изображения для увеличения. | IMAGE | Да | - |
| `положительный` | Данные положительного кондиционирования, направляющие генерацию к желаемому содержимому. | CONDITIONING | Да | - |
| `отрицательный` | Данные отрицательного кондиционирования, уводящие генерацию от нежелательного содержимого. | CONDITIONING | Да | - |
| `коэффициент_масштабирования` | Множитель, применяемый к размерам входного изображения при подготовке кондиционирования и латентного представления для увеличения (по умолчанию: 4.0). | FLOAT | Да | 0.0 - 10.0 (шаг: 0.01) |
| `шумовое_увеличение` | Количество шума, добавляемого в процессе увеличения (по умолчанию: 0.0). | FLOAT | Да | 0.0 - 1.0 (шаг: 0.001) |

Примечание: `noise_augmentation` — это расширенный параметр, отображаемый в интерфейсе узла под переключателем «Дополнительно».

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Изменённые данные положительного кондиционирования с применёнными масштабированными данными изображения и настройками аугментации шума. | CONDITIONING |
| `negative` | Изменённые данные отрицательного кондиционирования с применёнными масштабированными данными изображения и настройками аугментации шума. | CONDITIONING |
| `latent` | Пустое латентное представление, соответствующее увеличенным размерам. | LATENT |
