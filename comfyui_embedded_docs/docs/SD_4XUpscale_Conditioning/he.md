# SD_4XUpscale_Conditioning

הצומת SD_4XUpscale_Conditioning מכין נתוני התניה להגדלת תמונות ברזולוציה עם מודלי דיפוזיה. הוא מגדיל את תמונות הקלט ביחס נבחר, מוסיף תוספת רעש אופציונלית, ומחזיר נתוני התניה חיוביים ושליליים מותאמים יחד עם latent ריק בגודל המוגדל.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `images` | תמונות קלט שיש להגדיל ברזולוציה. | IMAGE | כן | - |
| `positive` | נתוני התניה חיוביים שמכוונים את היצירה לתוכן הרצוי. | CONDITIONING | כן | - |
| `negative` | נתוני התניה שליליים שמרחיקים את היצירה מתוכן לא רצוי. | CONDITIONING | כן | - |
| `scale_ratio` | מכפיל המוחל על ממדי תמונת הקלט בעת הכנת נתוני ההתניה וה-latent המוגדלים (ברירת מחדל: 4.0). | FLOAT | כן | 0.0 - 10.0 (step 0.01) |
| `noise_augmentation` | כמות הרעש להוספה במהלך תהליך ההגדלה (ברירת מחדל: 0.0). | FLOAT | כן | 0.0 - 1.0 (step 0.001) |

הערה: `noise_augmentation` הוא פרמטר מתקדם, המוצג בממשק הצומת תחת מתג "מתקדם".

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | נתוני התניה חיוביים מותאמים עם נתוני התמונה המוגדלים והגדרות תוספת הרעש מיושמות. | CONDITIONING |
| `negative` | נתוני התניה שליליים מותאמים עם נתוני התמונה המוגדלים והגדרות תוספת הרעש מיושמות. | CONDITIONING |
| `latent` | ייצוג latent ריק התואם לממדים המוגדלים. | LATENT |
