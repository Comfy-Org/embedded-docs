# SamplerDPMPP_2M_SDE

گره SamplerDPMPP_2M_SDE یک نمونه‌بردار DPM++ 2M SDE برای مدل‌های انتشار ایجاد می‌کند. این نمونه‌بردار از حل‌کننده‌های معادله دیفرانسیل مرتبه دوم همراه با معادلات دیفرانسیل تصادفی برای تولید نمونه‌ها استفاده می‌کند. انواع مختلف حل‌کننده و گزینه‌های مدیریت نویز را برای کنترل فرایند نمونه‌برداری فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نوع حل‌گر` | نوع حل‌کننده معادله دیفرانسیل برای استفاده در فرایند نمونه‌برداری (پیش‌فرض: "midpoint") | COMBO | بله | `"midpoint"`<br>`"heun"` |
| `eta` | میزان تصادفی‌بودن فرایند نمونه‌برداری را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 100.0 |
| `s_noise` | میزان نویز افزوده‌شده در طول نمونه‌برداری را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 100.0 |
| `دستگاه نویز` | دستگاهی که محاسبات نویز روی آن انجام می‌شود. وقتی روی "cpu" تنظیم شود، نمونه‌بردار از تولید نویز مبتنی بر CPU استفاده می‌کند؛ وقتی روی "gpu" تنظیم شود، برای عملکرد بالقوه سریع‌تر از تولید نویز مبتنی بر GPU استفاده می‌کند (پیش‌فرض: "gpu") | COMBO | بله | `"gpu"`<br>`"cpu"` |

توجه: `eta`، `s_noise` و `noise_device` به‌عنوان پارامترهای پیشرفته علامت‌گذاری شده‌اند و در بخش پیشرفته رابط کاربری گره ظاهر می‌شوند.
