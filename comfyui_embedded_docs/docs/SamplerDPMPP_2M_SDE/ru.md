# Сэмплер DPMPP_2M_SDE

Узел `SamplerDPMPP_2M_SDE` создаёт сэмплер DPM++ 2M SDE для диффузионных моделей. Этот сэмплер сочетает многошаговый решатель второго порядка со стохастическим дифференциальным уравнением (SDE) для генерации сэмплов. Он предоставляет различные типы решателей и параметры обработки шума для управления процессом сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `solver_type` | Тип решателя дифференциальных уравнений, используемого во время сэмплирования: "midpoint" или "heun" (по умолчанию: "midpoint") | COMBO | Да | "midpoint"<br>"heun" |
| `eta` | Управляет степенью стохастичности (случайности) в процессе сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `noise_device` | Устройство, используемое для вычислений шума. "gpu" выполняет генерацию шума на GPU для потенциально более высокой производительности; "cpu" использует CPU (по умолчанию: "gpu") | COMBO | Да | "gpu"<br>"cpu" |

Примечание: когда `noise_device` установлен в "cpu", узел создаёт сэмплер `dpmpp_2m_sde`. Когда установлен в "gpu", он создаёт вариант `dpmpp_2m_sde_gpu`, который выполняет вычисления, связанные с шумом, на GPU.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, готовый к использованию в конвейере сэмплирования | SAMPLER |
