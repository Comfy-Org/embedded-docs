# Сэмплер DPMPP_2M_SDE

Узел SamplerDPMPP_2M_SDE создаёт сэмплер DPM++ 2M SDE для диффузионных моделей. Этот сэмплер использует решатели дифференциальных уравнений второго порядка со стохастическими дифференциальными уравнениями для генерации образцов. Он предоставляет различные типы решателей и параметры обработки шума для управления процессом сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `тип_решателя` | Тип решателя дифференциальных уравнений, используемый в процессе сэмплирования (по умолчанию: "midpoint") | COMBO | Да | `"midpoint"`<br>`"heun"` |
| `eta` | Управляет стохастичностью процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет количеством шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `устройство_шума` | Устройство, на котором выполняются расчёты шума. Если задано значение "cpu", сэмплер использует генерацию шума на базе CPU; если задано "gpu", используется генерация шума на базе GPU, что потенциально повышает производительность (по умолчанию: "gpu") | COMBO | Да | `"gpu"`<br>`"cpu"` |

Примечание: `eta`, `s_noise` и `noise_device` помечены как расширенные параметры и отображаются в расширенном разделе интерфейса узла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, готовый к использованию в конвейере сэмплирования | SAMPLER |
