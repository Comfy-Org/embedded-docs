# Kling 4.0 編輯影片

使用 Kling 4.0 模型，透過文字提示詞編輯現有影片，並可選擇以參考影片和參考影像作為引導。結果會保留輸入影片的長度。可用於改變片段中發生的事件、重新調整風格，或在維持原始時間軸不變的情況下替換元素。

**限制與行為：**

* 輸入影片與每部參考影片的長度必須為 3 至 30 秒（使用 `kling-4.0-flash` 時為 3 至 20 秒），至少 700x700 像素、最高 4553x4553 像素，總像素不得超過 8,294,400，長寬比介於 2:5 至 5:2 之間，影格率至少 24 fps。所有影片合計亦不得超過相同的限制。
* 每張參考影像必須至少為 300x300 像素，長寬比介於 2:5 至 5:2 之間，且最多可連接 10 張影像。
* 若提示詞提及 `@VideoN` 或 `@ImageN`，但該類輸入連接的數量少於 N，則會產生錯誤。
