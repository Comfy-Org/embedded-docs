# Kling 4.0 Edit Video

使用 Kling 4.0 模型，透過文字提示詞編輯現有影片，並可選擇使用參考影片與參考圖片作為引導。結果會保留輸入影片的長度。可用於改變片段中發生的事、重新調整風格，或在保持原始時間軸不變的情況下替換元素。

**限制與行為：**

* 輸入影片與每段參考影片的長度必須為 3 到 30 秒，解析度至少 700x700、至多 4553x4553 像素，總像素不得超過 8,294,400，長寬比介於 2:5 與 5:2 之間，且影格率至少 24 fps。所有影片合計不得超過 30 秒。
* 每張參考圖片必須至少 300x300 像素，長寬比介於 2:5 與 5:2 之間，且最多可連接 10 張圖片。
* 若提示詞提及 `@VideoN` 或 `@ImageN`，但連接的同類輸入少於 N 個，則會引發錯誤。
