# Kling 4.0 編輯影片

**限制與行為：**

* 輸入影片和每部參考影片的長度必須為 3 至 30 秒（使用 `kling-4.0-flash` 時為 3 至 20 秒），解析度至少 700x700、最多 4553x4553 像素，總像素不得超過 8,294,400，長寬比介於 2:5 與 5:2 之間，影格率至少 24 fps。所有影片合計不得超過相同的限制。
* 每張參考影像的解析度至少 300x300 像素，長寬比介於 2:5 與 5:2 之間，且最多可連接 10 張影像。
* 若提示詞提及 `@VideoN` 或 `@ImageN`，但該類型連接的輸入少於 N 個，則會引發錯誤。
