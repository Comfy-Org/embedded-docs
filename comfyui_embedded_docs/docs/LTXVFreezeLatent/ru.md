# LTXV Заморозить латент

Узел LTXV Freeze Latent устанавливает маску шума латента в ноль, что сохраняет этот латент чистым и неизменным во время сэмплирования. Он работает как с видео-, так и с аудиолатентами, поэтому латент можно заморозить перед его конкатенацией с другими или когда его вообще не нужно денойзить.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `latent` | Видео- или аудиолатент для заморозки. Аудио имеет размерность 4D; видео — 5D. | LATENT | Да | N/A |

### Ограничения

- Латент должен содержать обычный тензор. Конкатенированный аудио-видеолатент не принимается; его сначала нужно разделить с помощью узла Separate AV Latent.
- Поддерживаются только 4D-латенты (аудио) и 5D-латенты (видео). Любая другая форма вызывает ошибку.
- Генерируемая маска шума создаётся из нулей на том же устройстве, что и входной тензор. Для видеолатентов маска имеет форму (batch, 1, frames, 1, 1); для аудиолатентов — форму (batch, 1, frames, 1).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `latent` | Входной латент с добавленной маской шума из нулей, поэтому во время сэмплирования он остаётся чистым. | LATENT |
