# ערבב רשימת תמונות

הצומת Shuffle Dataset מקבל רשימת תמונות ומשנה את סדרן באופן אקראי. הוא משתמש בערך `seed` כדי לשלוט באקראיות, וכך מאפשר לשחזר את אותו סדר ערבוב. זה שימושי לאקראיות סדר התמונות במערך נתונים לפני עיבוד.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `images` | רשימת התמונות שיש לערבב. | IMAGE | כן | - |
| `seed` | זרע אקראי. (ברירת מחדל: 0) | INT | לא | 0 עד 18446744073709551615 |
