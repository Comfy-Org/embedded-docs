# Google Gemini Decision (Pick Image)

اختر أفضل صورة من دفعة. وصّل `index` بـ Get Image from Batch للاحتفاظ بالصورة المختارة، بحيث لا يعمل بقية سير العمل إلا على الصورة المختارة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم (افتراضي: `"gemini-decision-1"`). | COMBO | نعم | `"gemini-decision-1"` |
| `السؤال` | الصورة التي يجب اختيارها (افتراضي: "Which image best matches the prompt in text? If there is no text, which image has the best quality?"). | STRING | نعم | 1 إلى 5000 حرف |
| `الصور` | الصور التي يمكن الاختيار منها، على شكل دفعة أو دفعة واحدة من الإطارات. | IMAGE | نعم | 2 إلى 64 صورة |
| `النص` | النص الذي يتعلق به السؤال، مثل النص التوجيهي الذي أُنشئت منه الصور، حتى 20000 حرف. | STRING | لا | حتى 20000 حرف |

تحتاج العقدة إلى 2 إلى 64 صورة، وتُصدر خطأً عند وجود صورة واحدة. وصّل `text` عندما ينبغي أن يتبع الاختيار نصًا توجيهيًا بدلًا من جودة الصورة وحدها.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `index` | موضع الصورة المختارة في الدفعة، بدءًا من 0. | INT |
| `confidence` | درجة الثقة في الاختيار، بين 0 و1. | FLOAT |
