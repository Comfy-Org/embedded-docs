# Google Gemini Decision (Pick Image)

Выберите лучшее изображение из пакета. Подключите `index` к Get Image from Batch, чтобы сохранить выбранное изображение, тогда остальная часть рабочего процесса будет выполняться только для выбранного варианта.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `question` | Какое изображение выбрать (по умолчанию: "Какое изображение лучше всего соответствует текстовому промпту? Если текста нет, у какого изображения лучшее качество?"). | STRING | Да | от 1 до 5000 символов |
| `images` | Изображения для выбора в виде пакета или одного пакета кадров. | IMAGE | Да | от 2 до 64 изображений |
| `text` | Текст, к которому относится вопрос, например промпт, по которому были созданы изображения, до 20000 символов. | STRING | Нет | До 20000 символов |

Узлу требуется от 2 до 64 изображений, и он выдаёт ошибку при одном изображении. Подключите `text`, если выбор должен основываться на промпте, а не только на качестве изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `index` | Позиция выбранного изображения в пакете, начиная с 0. | INT |
| `confidence` | Уверенность в выборе, от 0 до 1. | FLOAT |
