# Google Gemini Decision (Pick Image)

בחר את התמונה הטובה ביותר מתוך אצווה. חבר את `index` אל Get Image from Batch כדי לשמור את התמונה שנבחרה, כך ששאר זרימת העבודה תרוץ רק על התמונה שנבחרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `מודל` | המודל לשימוש (ברירת מחדל: `"gemini-decision-1"`). | COMBO | כן | `"gemini-decision-1"` |
| `שאלה` | איזו תמונה לבחור (ברירת מחדל: "Which image best matches the prompt in text? If there is no text, which image has the best quality?"). | STRING | כן | 1 עד 5000 תווים |
| `תמונות` | התמונות שמהן לבחור, כאצווה או כאצווה בודדת של פריימים. | IMAGE | כן | 2 עד 64 תמונות |
| `טקסט` | הטקסט שהשאלה עוסקת בו, כגון הפרומפט שממנו נוצרו התמונות, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

הצומת דורש 2 עד 64 תמונות ומעלה שגיאה כאשר יש תמונה בודדת. חבר את `text` כאשר הבחירה צריכה להתבסס על פרומפט ולא רק על איכות התמונה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `index` | מיקום התמונה שנבחרה באצווה, החל מ-0. | INT |
| `confidence` | רמת הביטחון בבחירה, בין 0 ל-1. | FLOAT |
