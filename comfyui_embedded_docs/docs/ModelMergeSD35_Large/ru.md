# Слияние моделей SD35_Large

Узел ModelMergeSD35_Large позволяет смешивать две модели Stable Diffusion 3.5 Large, регулируя влияние различных компонентов модели. Он обеспечивает точный контроль над тем, какой вклад вносит каждая часть второй модели в итоговую объединённую модель, от слоёв эмбеддингов до совместных блоков и финального слоя.
