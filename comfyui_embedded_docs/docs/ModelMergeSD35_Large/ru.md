# Слияние моделей SD35_Large

Узел ModelMergeSD35_Large объединяет две модели Stable Diffusion 3.5 Large, смешивая определённые внутренние компоненты второй модели с первой. Каждый компонент имеет независимое значение смешивания, что обеспечивает точный контроль над тем, насколько сильно этот компонент влияет на итоговую объединённую модель.
