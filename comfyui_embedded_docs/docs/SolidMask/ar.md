# قناع صلب

تقوم عقدة SolidMask بإنشاء قناع موحد بقيمة محددة عبر مساحته بالكامل. صُممت هذه العقدة لإنشاء أقنعة ذات أبعاد وكثافة محددة، وهي مفيدة في مهام متنوعة لمعالجة الصور وإنشاء الأقنعة.

## المدخلات

| المعامل | الوصف | نوع البيانات |
| --- | --- | --- |
| `القيمة` | يحدد قيمة الكثافة للقناع، مما يؤثر على مظهره العام وفائدته في العمليات اللاحقة. | FLOAT |
| `العرض` | يحدد عرض القناع المُنشأ، مما يؤثر بشكل مباشر على حجمه ونسبة أبعاده. | INT |
| `الارتفاع` | يضبط ارتفاع القناع المُنشأ، مما يؤثر على حجمه ونسبة أبعاده. | INT |

## المخرجات

| المعامل | الوصف | نوع البيانات |
| --- | --- | --- |
| `mask` | يُخرج قناعًا موحدًا بالأبعاد والقيمة المحددين. | MASK |
