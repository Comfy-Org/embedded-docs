# יצירת מסכה אחידה

צומת SolidMask יוצר מסכה אחידה עם ערך מוגדר בכל שטחה. הוא מיועד ליצירת מסכות במידות ובעוצמה מסוימות, ושימושי במגוון משימות של עיבוד תמונה ויצירת מסכות.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `value` | מציין את ערך העוצמה של המסכה, ומשפיע על המראה הכללי שלה ועל השימושיות שלה בפעולות עוקבות. | FLOAT |
| `width` | קובע את הרוחב של המסכה המיוצרת, ומשפיע ישירות על גודלה ועל יחס הרוחב-גובה שלה. | INT |
| `height` | מגדיר את הגובה של המסכה המיוצרת, ומשפיע על גודלה ועל יחס הרוחב-גובה שלה. | INT |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `mask` | מוציא מסכה אחידה עם המידות והערך שצוינו. | MASK |
