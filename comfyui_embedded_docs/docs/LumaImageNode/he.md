# Luma טקסט לתמונה

יוצר תמונות באופן סינכרוני על בסיס הנחיית טקסט ויחס גובה-רוחב. צומת זה יוצר תמונות באמצעות תיאורי טקסט ומאפשר לך לשלוט בממדי התמונה ובסגנון דרך קלטי עזר שונים, כולל תמונות דמות וסגנון.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: מחרוזת ריקה). חייבת להיות באורך של לפחות 3 תווים. | STRING | כן | - |
| `model` | בחירת מודל ליצירת תמונה. למודלים שונים עלויות שונות. | COMBO | כן | `photon-flash-1`<br>`photon-1`<br>`photon` |
| `aspect_ratio` | יחס גובה-רוחב עבור התמונה הנוצרת (ברירת מחדל: `16:9`) | COMBO | כן | `16:9`<br>`1:1`<br>`4:3`<br>`3:2`<br>`21:9`<br>`9:16`<br>`3:4`<br>`2:3`<br>`9:21` |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-Seed (ברירת מחדל: 0) | INT | כן | 0 עד 18446744073709551615 |
| `style_image_weight` | משקל תמונת הסגנון. מתעלמים ממנו אם לא מסופק `style_image` (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 עד 1.0 |
| `image_luma_ref` | חיבור צומת Luma Reference כדי להשפיע על היצירה באמצעות תמונות קלט; ניתן להביא בחשבון עד 4 תמונות. | LUMA_REF | לא | - |
| `style_image` | תמונת עזר לסגנון; תשמש תמונה אחת בלבד. | IMAGE | לא | - |
| `character_image` | תמונות עזר לדמות; יכול להיות אצווה של מספר תמונות, ניתן להביא בחשבון עד 4 תמונות. | IMAGE | לא | - |

**אילוצי פרמטרים:**

- `prompt` חייב להיות באורך של לפחות 3 תווים לאחר הסרת רווחים.
- הפרמטר `image_luma_ref` יכול לקבל עד 4 תמונות עזר.
- הפרמטר `character_image` יכול לקבל עד 4 תמונות עזר לדמות.
- הפרמטר `style_image` מקבל רק תמונת עזר אחת לסגנון.
- הפרמטר `style_image_weight` משמש רק כאשר מסופק `style_image`.
