# Wan22ImageToVideoLatent

Wan22ImageToVideoLatent יוצר ייצוגי לטנט של וידאו מתמונות. הוא מפיק מרחב לטנט ריק של וידאו עם הרוחב, הגובה, אורך הפריימים וגודל האצווה שצוינו, ויכול לקודד באופן אופציונלי רצף תמונות התחלה לתוך הפריימים הראשונים. כאשר מסופקת תמונת התחלה, הצומת מקודד אותה למרחב הלטנטי ויוצר מסכת רעש מתאימה שמסמנת אילו אזורים יש להסיר מהם רעש במהלך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `vae` | מודל ה-VAE המשמש לקידוד תמונת ההתחלה למרחב לטנטי | VAE | כן | - |
| `width` | הרוחב של סרטון הפלט בפיקסלים (ברירת מחדל: 1280, צעד: 32) | INT | כן | 32 עד MAX_RESOLUTION |
| `height` | הגובה של סרטון הפלט בפיקסלים (ברירת מחדל: 704, צעד: 32) | INT | כן | 32 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו (ברירת מחדל: 49, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הלטנטים של וידאו ליצירה (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `start_image` | רצף תמונות התחלה אופציונלי לקידוד לתוך הפריימים הראשונים של הלטנט של הווידאו (משתמש ב-`length` הפריימים הראשונים) | IMAGE | לא | - |

**הערה:** כאשר `start_image` מסופק, רצף התמונות מוגדל ל-`width` ול-`height` היעד, מקודד עם ה-VAE, ומוצב בפריימים הראשונים של הלטנט. מסכת הרעש עבור פריימים אלה מוגדרת ל-0 (נשמרים), בעוד שלשאר הפריימים יש ערך מסכה של 1 (מיועדים להסרת רעש). ללטנט תמיד יש 48 ערוצים, ממדים מרחביים של `height / 16` על `width / 16`, וממד זמני של `((length - 1) // 4) + 1`. `width` ו-`height` חייבים להיות מתחלקים ב-16 (נאכף על ידי הצעד של 32), ו-`length` מגדיל את הממד הזמני בצעדים של 4.

כאשר `start_image` אינו מסופק, מוחזר לטנט ריק לחלוטין ללא מסכת רעש, וקלט `batch_size` אינו מיושם על אותו לטנט ריק.
