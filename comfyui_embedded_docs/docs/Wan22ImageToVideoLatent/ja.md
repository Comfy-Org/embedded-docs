# Wan22ImageToVideoLatent

Wan22ImageToVideoLatent ノードは、Wan 2.2 の動画生成に使用される潜在表現（latent）の入力を準備します。指定された幅・高さ・フレーム数で空の動画用潜在表現を作成し、開始画像が指定された場合は、その画像を潜在表現の最初のフレームにエンコードします。また、画像で既に埋められているフレームと、まだ生成が必要なフレームを示すノイズマスクも出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `vae` | 開始画像を潜在空間にエンコードするために使用される VAE モデル | VAE | はい | - |
| `width` | 出力動画の幅（ピクセル単位）（初期値：1280、ステップ：32） | INT | はい | 32 から MAX_RESOLUTION |
| `height` | 出力動画の高さ（ピクセル単位）（初期値：704、ステップ：32） | INT | はい | 32 から MAX_RESOLUTION |
| `length` | 動画のフレーム数（初期値：49、ステップ：4） | INT | はい | 1 から MAX_RESOLUTION |
| `batch_size` | 並列に生成する動画用潜在表現の数（初期値：1） | INT | はい | 1 から 4096 |
| `start_image` | 動画用潜在表現の最初のフレームに配置される、オプションの画像または画像シーケンス。最初の `length` フレームのみが使用されます。画像は VAE によってエンコードされる前に、バイリニアリサンプリングとセンタークロップによって `width` x `height` にリサイズされます。 | IMAGE | いいえ | - |

**注記：** 潜在表現の空間次元は `width / 16` および `height / 16` であるため、`width` と `height` は 16 で割り切れる必要があります。潜在表現の時間次元は `((length - 1) // 4) + 1` として計算され、チャンネル数は 48 です。`start_image` が指定された場合、エンコードされた画像が潜在表現の最初のフレームを埋め、`noise_mask` はそれらのフレームでは 0、残りのフレームでは 1 に設定されます。これにより、サンプラーは画像のフレームを変更せずに維持し、残りを生成するように指示されます。`start_image` が指定されない場合、潜在表現はゼロで埋められ、ノイズマスクは含まれません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `LATENT` | 生成された動画用潜在表現。`batch_size` 回繰り返されます。`start_image` が指定された場合、画像がエンコードされたフレーム（0）と生成するフレーム（1）を示す `noise_mask` も含まれます。 | LATENT |
