# Wan22ImageToVideoLatent

Узел Wan22ImageToVideoLatent подготавливает латентное представление (latent) для генерации видео Wan 2.2. Он создает пустое видеолатентное представление с указанными шириной, высотой и количеством кадров, а при наличии стартового изображения кодирует его в первые кадры латентного представления. Также узел выводит маску шума (noise mask), которая отмечает, какие кадры уже заполнены изображением, а какие еще необходимо сгенерировать.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования стартового изображения в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 1280, шаг: 32) | INT | Да | 32 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 704, шаг: 32) | INT | Да | 32 to MAX_RESOLUTION |
| `length` | Количество кадров в видео (по умолчанию: 49, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видеолатентных представлений, генерируемых параллельно (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `start_image` | Необязательное изображение или последовательность изображений, помещаемых в первые кадры видеолатентного представления. Используются только первые `length` кадров. Изображение масштабируется до размера `width` x `height` с помощью билинейной интерполяции и центрального кадрирования перед кодированием VAE. | IMAGE | Нет | - |

**Примечание:** Пространственная размерность латентного представления равна `width / 16` и `height / 16`, поэтому `width` и `height` должны делиться на 16. Временная размерность латентного представления вычисляется как `((length - 1) // 4) + 1`, и оно имеет 48 каналов. Если предоставлено `start_image`, закодированное изображение заполняет первые кадры латентного представления, а `noise_mask` устанавливается в 0 для этих кадров и в 1 для остальных, что указывает сэмплеру оставить кадры изображения неизменными и сгенерировать остальные. Если `start_image` не предоставлено, латентное представление заполняется нулями и маска шума не включается.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Сгенерированное видеолатентное представление, повторенное `batch_size` раз. Если предоставлено `start_image`, оно также содержит `noise_mask`, отмечающий кадры, кодированные изображением (0), и кадры для генерации (1). | LATENT |
