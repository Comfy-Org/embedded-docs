# Wan22ImageToVideoLatent

Wan22ImageToVideoLatent создаёт латентные представления видео из изображений. Он генерирует пустое латентное пространство видео с указанными шириной, высотой, длиной последовательности кадров и размером батча, а также может опционально закодировать начальную последовательность изображений в первые кадры. Когда стартовое изображение предоставлено, узел кодирует его в латентное пространство и создаёт соответствующую маску шума, которая отмечает области, которые должны быть денойзированы во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования стартового изображения в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 1280, шаг: 32) | INT | Да | 32 до MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 704, шаг: 32) | INT | Да | 32 до MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 49, шаг: 4) | INT | Да | 1 до MAX_RESOLUTION |
| `batch_size` | Количество латентных представлений видео для генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `start_image` | Необязательная начальная последовательность изображений для кодирования в первые кадры латента видео (использует первые `length` кадров) | IMAGE | Нет | - |

**Примечание:** Когда `start_image` предоставлен, последовательность изображений масштабируется до целевых `width` и `height`, кодируется с помощью VAE и помещается в первые кадры латента. Маска шума для этих кадров устанавливается в 0 (сохраняется), тогда как для остальных кадров значение маски равно 1 (должны быть денойзированы). Латент всегда имеет 48 каналов, пространственные размеры `height / 16` на `width / 16` и временное измерение `((length - 1) // 4) + 1`. `width` и `height` должны делиться на 16 (обеспечивается шагом 32), а `length` увеличивает временное измерение с шагом 4.

Когда `start_image` не предоставлен, возвращается полностью пустой латент без маски шума, и вход `batch_size` не применяется к этому пустому латенту.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированное латентное представление видео, повторённое для каждого элемента в батче | LATENT |
| `noise_mask` | Маска шума, указывающая, какие области должны быть денойзированы (значение 1), а какие сохраняют закодированное стартовое изображение (значение 0) | LATENT |

Оба поля возвращаются вместе внутри одного выхода LATENT.
