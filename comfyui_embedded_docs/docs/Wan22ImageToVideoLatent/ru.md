# Wan22ImageToVideoLatent

Wan22ImageToVideoLatent создает латентные представления видео из изображений. Он генерирует пустое латентное пространство видео с указанными шириной, высотой, количеством кадров и размером батча, а также может при необходимости кодировать стартовую последовательность изображений в начальные кадры. Когда стартовое изображение задано, узел кодирует его в латентное пространство и создает соответствующую маску шума, которая отмечает области, подлежащие денойзингу во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования стартового изображения в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 1280, шаг: 32) | INT | Да | 32 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 704, шаг: 32) | INT | Да | 32 to MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 49, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество генерируемых видео-латентов (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `start_image` | Необязательная стартовая последовательность изображений для кодирования в начальные кадры видео-латента (используются первые `length` кадров) | IMAGE | Нет | - |

**Примечание:** Когда `start_image` предоставлено, последовательность изображений масштабируется до целевых значений `width` и `height`, кодируется с помощью VAE и помещается в первые кадры латента. Значение маски шума для этих кадров устанавливается в 0 (сохраняются), а остальные кадры имеют значение маски 1 (подлежат денойзингу). Латентное представление всегда имеет 48 каналов, пространственные размеры `height / 16` × `width / 16` и временное измерение `((length - 1) // 4) + 1`. `width` и `height` должны делиться на 16 (обеспечивается шагом 32), а `length` увеличивает временное измерение с шагом 4.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированное латентное представление видео, повторяющееся для каждого элемента в батче | LATENT |
| `noise_mask` | Маска шума, указывающая, какие области следует денойзить (значение 1), а какие сохраняют закодированное стартовое изображение (значение 0) | LATENT |

Оба поля возвращаются вместе в составе одного выхода типа LATENT.
