# FluxKontextMultiReferenceLatentMethod

Узел FluxKontextMultiReferenceLatentMethod обновляет данные кондиционирования, сохраняя в них выбранный метод эталонных латентов. Сохранённый метод затем используется, когда эталонные латенты обрабатываются на последующих шагах генерации. Этот узел помечен как экспериментальный и относится к системе кондиционирования Flux.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые нужно изменить с помощью метода эталонных латентов | CONDITIONING | Да | - |
| `метод_референтных_латентов` | Метод, используемый для обработки эталонных латентов. Если выбрано значение, содержащее "uxo" или "uso", перед сохранением оно преобразуется в "uxo". Этот параметр помечен как расширенный. | COMBO | Да | `"offset"`<br>`"index"`<br>`"uxo/uno"`<br>`"index_timestep_zero"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Изменённые данные кондиционирования с применённым методом эталонных латентов | CONDITIONING |
