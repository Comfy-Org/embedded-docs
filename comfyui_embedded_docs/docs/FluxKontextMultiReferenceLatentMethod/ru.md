# FluxKontextMultiReferenceLatentMethod

Узел `FluxKontextMultiReferenceLatentMethod` изменяет данные кондиционирования, задавая конкретный метод эталонных латентных представлений. Он добавляет выбранный метод к входу `conditioning`, что влияет на обработку эталонных латентных представлений на последующих этапах генерации. Этот узел помечен как экспериментальный и является частью системы кондиционирования Flux.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `кондиционирование` | Данные кондиционирования, которые будут изменены с помощью метода эталонных латентных представлений | CONDITIONING | Да | - |
| `метод_референтных_латентов` | Метод, используемый для обработки эталонных латентных представлений. Если выбрано значение `"uxo"` или `"uso"`, оно будет преобразовано в `"uxo"`. Этот параметр отмечен как расширенный. | COMBO | Да | `"offset"`<br>`"index"`<br>`"uxo/uno"`<br>`"index_timestep_zero"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Изменённые данные кондиционирования с применённым методом эталонных латентных представлений | CONDITIONING |
