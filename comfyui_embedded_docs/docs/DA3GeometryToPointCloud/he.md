# DA3GeometryToPointCloud

המר מפת עומק מאובייקט DA3_GEOMETRY לענן נקודות תלת-ממד. הוא מחיל סינון בהתבסס על מסכות ביטחון ושמיים, וממיר את הנקודות למערכת קואורדינטות עולמית משותפת המתאימה לסצנות מרובות מבטים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | אובייקט DA3_GEOMETRY המכיל נתוני עומק ומפות תמונה, ביטחון ושמיים אופציונליות | DA3_GEOMETRY | כן | - |
| `batch_index` | איזו תמונה מתוך אצווה להמיר (ברירת מחדל: 0) | INT | כן | 0 to 4096 |
| `confidence_threshold` | החרג פיקסלים שערך הביטחון המנורמל שלהם לפי תמונה נמוך מערך זה (0 = שמור הכול). משמש כאשר לגאומטריה יש מפת ביטחון (מודלים Small/Base). (ברירת מחדל: 0.1) | FLOAT | כן | 0.0 to 1.0 |
| `use_sky_mask` | החרג פיקסלים בעלי הסתברות שמיים (הסתברות שמיים >= 0.5). משמש כאשר לגאומטריה יש מפת שמיים (מודלים Mono/Metric). (ברירת מחדל: True) | BOOLEAN | כן | True or False |
| `downsample` | קח כל פיקסל N-י (1 = רזולוציה מלאה). ערכים גבוהים יותר מניבים פחות נקודות ועיבוד מהיר יותר. (ברירת מחדל: 1) | INT | כן | 1 to 16 |

**הערות:**
- `batch_index` חייב להיות קטן מגודל האצווה של גאומטריית הקלט; אחרת הצומת מעלה שגיאה.
- אם הסינון מסיר את כל הפיקסלים, הצומת מעלה שגיאה. הפחתת `confidence_threshold` או השבתת `use_sky_mask` יכולה למנוע זאת.
- `confidence_threshold` מיושם רק כאשר הגאומטריה כוללת מפת ביטחון (מודלים Small/Base).
- `use_sky_mask` מיושם רק כאשר הגאומטריה כוללת מפת שמיים (מודלים Mono/Metric).
- כאשר `downsample` גדול מ-1, הפרמטרים הפנימיים של המצלמה מותאמים בהתאם כך שהנקודות המוקרנות יישארו נכונות.
