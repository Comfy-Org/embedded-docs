# FLUX 3 Max Text to Video

FLUX 3 Max Text to Video генерирует видео с синхронизированным аудио из текстового промпта. Промпт интерпретируется и расширяется FLUX 3 Max перед рендерингом; узел ждёт завершения рендеринга и возвращает готовый клип.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Что должен показывать клип, простым языком. Для многослойного аудио описывайте окружающие звуки, музыку и речь отдельно (по умолчанию: пусто). | STRING | Да | Многострочный текст |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` соответствует 16:9 для текстовых промптов (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"21:9"`<br>`"2:1"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"` |
| `duration` | Длительность клипа в секундах (по умолчанию: `"5"`). | COMBO | Да | `"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"`<br>`"11"`<br>`"12"`<br>`"13"`<br>`"14"`<br>`"15"`<br>`"16"`<br>`"17"`<br>`"18"`<br>`"19"`<br>`"20"` |
| `resolution` | Разрешение выходного видео (по умолчанию: `"720p"`). | COMBO | Да | `"720p"`<br>`"1080p"` |
| `reasoning_level` | Насколько глубоко модель анализирует и расширяет промпт перед генерацией. `"high"` занимает больше времени; цена та же (по умолчанию: `"high"`). | COMBO | Да | `"low"`<br>`"high"` |
| `generate_audio` | Генерировать синхронизированное аудио. При выключении создаётся видео без аудиодорожки (по умолчанию: true). | BOOLEAN | Да | `true`<br>`false` |
| `seed` | Сид, управляющий повторным запуском узла. Результаты недетерминированы независимо от этого значения (по умолчанию: 42). | INT | Да | 0 до 2147483646 |

Примечание: `prompt` должен содержать хотя бы один символ. Отображаемая цена основана на `resolution` и `duration`: 720p стоит $0.060775 в секунду, а 1080p — $0.103675 в секунду до 7 ноября 2026 года; после этой даты — $0.2431 и $0.4147 в секунду соответственно. Общая ориентировочная стоимость клипа отображается в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип с синхронизированным аудио, когда `generate_audio` включён. | VIDEO |
