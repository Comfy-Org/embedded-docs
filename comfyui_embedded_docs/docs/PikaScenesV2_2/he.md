# PikaScenesV2_2

צומת PikaScenes v2.2 משלבת מספר תמונות ליצירת וידאו שמשלב אובייקטים מכל תמונות הקלט. ניתן להעלות עד חמש תמונות שונות כרכיבים וליצור וידאו באיכות גבוהה שממזג אותן בצורה חלקה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `prompt_text` | תיאור טקסטואלי של מה ליצור | STRING | כן | - |
| `negative_prompt` | תיאור טקסטואלי של מה להימנע ממנו ביצירה | STRING | כן | - |
| `seed` | ערך זרע אקראי ליצירה | INT | כן | - |
| `resolution` | רזולוציית הפלט עבור הווידאו | STRING | כן | - |
| `duration` | משך הווידאו שנוצר | INT | כן | - |
| `ingredients_mode` | מצב לשילוב רכיבים (ברירת מחדל: "creative") | STRING | לא | "creative"<br>"precise" |
| `aspect_ratio` | יחס רוחב-גובה (רוחב / גובה) (ברירת מחדל: 1.778) | FLOAT | לא | 0.4 - 2.5 |
| `image_ingredient_1` | תמונה שתשמש כרכיב ליצירת וידאו | IMAGE | לא | - |
| `image_ingredient_2` | תמונה שתשמש כרכיב ליצירת וידאו | IMAGE | לא | - |
| `image_ingredient_3` | תמונה שתשמש כרכיב ליצירת וידאו | IMAGE | לא | - |
| `image_ingredient_4` | תמונה שתשמש כרכיב ליצירת וידאו | IMAGE | לא | - |
| `image_ingredient_5` | תמונה שתשמש כרכיב ליצירת וידאו | IMAGE | לא | - |

**הערה:** ניתן לספק עד 5 רכיבי תמונה, אך נדרשת לפחות תמונה אחת כדי ליצור וידאו. הצומת תשתמש בכל התמונות שסופקו כדי ליצור את הרכב הווידאו הסופי.
