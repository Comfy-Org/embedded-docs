# מיזוג שמע

צומת AudioMerge משלב שתי רצועות אודיו באמצעות הנחת צורות הגל שלהן זו על זו. הוא מתאים אוטומטית את קצבי הדגימה של שני קלטי האודיו ומתאים את אורכם כך שיהיו שווים לפני המיזוג. הצומת מספק מספר שיטות מתמטיות לשילוב אותות האודיו ומבטיח שהפלט יישאר ברמות עוצמת קול מקובלות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `audio1` | קלט האודיו הראשון למיזוג | AUDIO | כן | - |
| `audio2` | קלט האודיו השני למיזוג | AUDIO | כן | - |
| `merge_method` | השיטה המשמשת לשילוב צורות הגל של האודיו. | COMBO | כן | `"add"`<br>`"mean"`<br>`"subtract"`<br>`"multiply"` |
