# WanFirstLastFrameToVideo

Узел `WanFirstLastFrameToVideo` создаёт кондиционирование видео, объединяя начальный и конечный кадры с текстовыми подсказками. Он формирует латентное представление для генерации видео, кодируя первый и последний кадры, применяя маски для управления процессом генерации и подключая признаки CLIP vision при их наличии. Этот узел подготавливает позитивное и негативное кондиционирование для видеомоделей, чтобы создавать согласованные последовательности между заданными начальной и конечной точками.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивное текстовое кондиционирование для направления генерации видео | CONDITIONING | Да | - |
| `negative` | Негативное текстовое кондиционирование для направления генерации видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `clip_vision_start_image` | Признаки CLIP vision, извлечённые из начального изображения | CLIP_VISION_OUTPUT | Нет | - |
| `clip_vision_end_image` | Признаки CLIP vision, извлечённые из конечного изображения | CLIP_VISION_OUTPUT | Нет | - |
| `start_image` | Начальный кадр видеопоследовательности | IMAGE | Нет | - |
| `end_image` | Конечный кадр видеопоследовательности | IMAGE | Нет | - |

**Примечание:** Когда указаны оба изображения `start_image` и `end_image`, узел создаёт видеопоследовательность с переходом между этими двумя кадрами. `start_image` обрезается до первых `length` кадров, а `end_image` — до последних `length` кадров перед обработкой. Если указано только одно из них, недостающая сторона заполняется нейтральными серыми кадрами. Маска установлена в 0 там, где присутствуют начальный и конечный кадры, и в 1 в остальных местах. Параметры `clip_vision_start_image` и `clip_vision_end_image` необязательны; когда указаны оба, их признаки CLIP vision объединяются и применяются и к позитивному, и к негативному кондиционированию. Когда указан только один, используются только его признаки.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Позитивное кондиционирование с применённым кодированием видеокадров и признаками CLIP vision | CONDITIONING |
| `negative` | Негативное кондиционирование с применённым кодированием видеокадров и признаками CLIP vision | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, соответствующими указанным параметрам видео | LATENT |
