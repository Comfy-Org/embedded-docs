# WanFirstLastFrameToVideo

Узел WanFirstLastFrameToVideo подготавливает кондиционирование для генерации видео, объединяя начальный и конечный кадры с текстовыми запросами. Он кодирует изображения кадров в латентное пространство, создаёт маску, которая сообщает видеомодели, какие кадры уже известны, и присоединяет признаки CLIP vision, если они предоставлены. Узел возвращает обновлённое позитивное и негативное кондиционирование, а также пустой латентный тензор, определяющий размер и длину генерируемого видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивное текстовое кондиционирование, используемое для управления генерацией видео. | CONDITIONING | Да | - |
| `отрицательный` | Негативное текстовое кондиционирование, используемое для управления генерацией видео. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования объединённых изображений кадров в латентное пространство. | VAE | Да | - |
| `ширина` | Ширина генерируемого видео в пикселях (по умолчанию: 832, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота генерируемого видео в пикселях (по умолчанию: 480, шаг: 16). | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4). | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1). | INT | Да | 1 до 4096 |
| `clip_vision_start_image` | Признаки CLIP vision, извлечённые из начального изображения. Если указаны оба входа CLIP vision — начальный и конечный, их признаки объединяются. | CLIP_VISION_OUTPUT | Нет | - |
| `clip_vision_end_image` | Признаки CLIP vision, извлечённые из конечного изображения. Если указаны оба входа CLIP vision — начальный и конечный, их признаки объединяются. | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Начальное изображение кадра для видеопоследовательности. Используются его первые `length` кадров, масштабированные до `width` × `height`. | IMAGE | Нет | - |
| `конечное_изображение` | Конечное изображение кадра для видеопоследовательности. Используются его последние `length` кадров, масштабированные до `width` × `height`. | IMAGE | Нет | - |

**Примечание:** Если указано хотя бы одно из изображений `start_image` или `end_image`, узел создаёт объединённую последовательность кадров, в которой заполняются начальный и конечный кадры, а остальные кадры используют нейтральный серый заполнитель (0.5). Маска помечает заполненные области как известные, а области заполнителя — как неизвестные, что позволяет видеомодели генерировать промежуточные кадры. Если указано начальное изображение, известная область также расширяется на 3 дополнительных кадра за пределами изображения. Одно и то же закодированное изображение кадра и маска добавляются и к `positive`, и к `negative` кондиционированию. Если указаны оба входа CLIP vision, их скрытые состояния конкатенируются; если указан только один, он используется как есть. Длина латентного видео вычисляется из `length` после временного сжатия: `((length - 1) // 4) + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Позитивное кондиционирование с присоединёнными закодированным изображением кадра, маской и (если указано) признаками CLIP vision. | CONDITIONING |
| `отрицательный` | Негативное кондиционирование с присоединёнными закодированным изображением кадра, маской и (если указано) признаками CLIP vision. | CONDITIONING |
| `latent` | Пустой латентный тензор (все нули), форма которого соответствует заданным размеру батча, длине видео и разрешению. | LATENT |
