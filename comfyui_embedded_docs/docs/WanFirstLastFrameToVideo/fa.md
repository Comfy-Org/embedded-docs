# WanFirstLastFrameToVideo

گره WanFirstLastFrameToVideo با ترکیب فریم‌های شروع و پایان با متن‌های prompt، شرطی‌سازی ویدیو ایجاد می‌کند. این گره با رمزگذاری فریم اول و آخر، اعمال ماسک برای هدایت فرآیند تولید، و ترکیب ویژگی‌های بینایی CLIP در صورت وجود، یک نمایش نهان (latent) برای تولید ویدیو می‌سازد. این گره هر دو شرطی‌سازی مثبت و منفی را برای مدل‌های ویدیویی آماده می‌کند تا دنباله‌ای منسجم بین نقاط شروع و پایان مشخص‌شده تولید شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | شرطی‌سازی متنی مثبت برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی متنی منفی برای هدایت تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر به فضای نهان | VAE | بله | - |
| `width` | عرض ویدیوی خروجی (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌ها در دنباله ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `clip_vision_start_image` | ویژگی‌های بینایی CLIP استخراج‌شده از تصویر شروع | CLIP_VISION_OUTPUT | خیر | - |
| `clip_vision_end_image` | ویژگی‌های بینایی CLIP استخراج‌شده از تصویر پایان | CLIP_VISION_OUTPUT | خیر | - |
| `start_image` | تصویر فریم شروع برای دنباله ویدیو | IMAGE | خیر | - |
| `end_image` | تصویر فریم پایان برای دنباله ویدیو | IMAGE | خیر | - |

**توجه:** وقتی هر دو `start_image` و `end_image` ارائه شوند، گره دنباله ویدیویی ایجاد می‌کند که بین این دو فریم انتقال می‌یابد. قبل از پردازش، `start_image` به تعداد `length` فریم ابتدایی و `end_image` به تعداد `length` فریم انتهایی برش داده می‌شود. اگر فقط یکی از آن‌ها ارائه شود، سمت missing با فریم‌های خاکستری خنثی پر می‌شود. ماسک در جایی که فریم‌های شروع و پایان وجود دارند روی 0 و در سایر نقاط روی 1 تنظیم می‌شود. پارامترهای `clip_vision_start_image` و `clip_vision_end_image` اختیاری هستند؛ وقتی هر دو ارائه شوند، ویژگی‌های بینایی CLIP آن‌ها ترکیب شده و به هر دو شرطی‌سازی مثبت و منفی اعمال می‌شود. وقتی فقط یکی ارائه شود، از ویژگی‌های همان یکی به‌تنهایی استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |

| `latent` | تانسور نهان خالی با ابعادی مطابق با پارامترهای ویدیویی مشخص‌شده | LATENT |
