# وان إطار أول وآخر إلى فيديو

تُجهّز عقدة WanFirstLastFrameToVideo التكييف لتوليد الفيديو من خلال دمج إطار البداية وإطار النهاية مع المطالبات النصية. تقوم بتشفير صور الإطارات إلى الفضاء الكامن، وإنشاء قناع يخبر نموذج الفيديو بالإطارات المعروفة مسبقًا، وإرفاق ميزات CLIP vision عندما تكون متوفرة. تُخرج العقدة تكييفًا موجبًا وسالبًا محدَّثًا بالإضافة إلى كامن فارغ يحدد حجم وطول الفيديو المراد توليده.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | التكييف النصي الموجب المستخدم لتوجيه توليد الفيديو. | CONDITIONING | نعم | - |
| `سلبي` | التكييف النصي السالب المستخدم لتوجيه توليد الفيديو. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير صور الإطارات المجمعة إلى الفضاء الكامن. | VAE | نعم | - |
| `العرض` | عرض الفيديو المُولَّد بالبكسل (الافتراضي: 832، الخطوة: 16). | INT | نعم | 16 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو المُولَّد بالبكسل (الافتراضي: 480، الخطوة: 16). | INT | نعم | 16 to MAX_RESOLUTION |
| `الطول` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4). | INT | نعم | 1 to MAX_RESOLUTION |
| `حجم الدفعة` | عدد مقاطع الفيديو المراد توليدها في وقت واحد (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |
| `صورة بداية رؤية الكليب` | ميزات CLIP vision المستخرجة من صورة البداية. إذا تم توفير كل من مدخلي CLIP vision للبداية والنهاية، يتم دمج ميزاتهما. | CLIP_VISION_OUTPUT | لا | - |
| `صورة نهاية رؤية الكليب` | ميزات CLIP vision المستخرجة من صورة النهاية. إذا تم توفير كل من مدخلي CLIP vision للبداية والنهاية، يتم دمج ميزاتهما. | CLIP_VISION_OUTPUT | لا | - |
| `صورة البداية` | صورة إطار البداية لتسلسل الفيديو. يتم استخدام أول `length` إطارًا منها وتغيير حجمها إلى `width` × `height`. | IMAGE | لا | - |
| `صورة النهاية` | صورة إطار النهاية لتسلسل الفيديو. يتم استخدام آخر `length` إطارًا منها وتغيير حجمها إلى `width` × `height`. | IMAGE | لا | - |

**ملاحظة:** عند توفير واحدة على الأقل من `start_image` أو `end_image`، تقوم العقدة ببناء تسلسل إطارات مدمج حيث يتم ملء إطاري البداية والنهاية، وتستخدم الإطارات المتبقية عنصرًا رماديًا محايدًا (0.5). يُنشئ القناع مناطق مملوءة كمعروفة ومناطق العنصر البديل كغير معروفة، مما يسمح لنموذج الفيديو بتوليد الإطارات الوسيطة. عند توفير صورة بداية، تمتد المنطقة المعروفة أيضًا بمقدار 3 إطارات إضافية بعد الصورة. يتم إرفاق نفس صورة الإطار المشفرة والقناع بكل من التكييف الموجب (`positive`) والتكييف السالب (`negative`). إذا تم توفير كل من مدخلي CLIP vision، يتم تسلسل حالاتهما المخفية؛ وإذا تم توفير واحد فقط، يُستخدم بمفرده. يُشتق طول الفيديو الكامن من `length` بعد الضغط الزمني: `((length - 1) // 4) + 1`.
