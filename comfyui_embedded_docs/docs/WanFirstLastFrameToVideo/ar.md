# وان إطار أول وآخر إلى فيديو

سوف أترجم الوثيقة إلى العربية مع الالتزام بالقواعد المحددة.

---

تنشئ عقدة WanFirstLastFrameToVideo تهيئة الفيديو من خلال دمج إطارات البداية والنهاية مع مطالبات نصية. وهي تولّد تمثيلًا كامنًا لتوليد الفيديو عن طريق ترميز الإطارين الأول والأخير، وتطبيق أقنعة لتوجيه عملية التوليد، وإدماج ميزات رؤية CLIP عند توفّرها. تُحضّر هذه العقدة كلاً من التهيئة الإيجابية والسلبية لنماذج الفيديو لتوليد تسلسلات مترابطة بين نقطتي البداية والنهاية المحددتين.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | تهيئة نصية إيجابية لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `negative` | تهيئة نصية سلبية لتوجيه توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض فيديو الإخراج (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع فيديو الإخراج (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو المراد توليدها في نفس الوقت (الافتراضي: 1) | INT | نعم | 1 to 4096 |
| `clip_vision_start_image` | ميزات رؤية CLIP المستخرجة من صورة البداية | CLIP_VISION_OUTPUT | لا | - |
| `clip_vision_end_image` | ميزات رؤية CLIP المستخرجة من صورة النهاية | CLIP_VISION_OUTPUT | لا | - |
| `start_image` | صورة الإطار الأول لتسلسل الفيديو | IMAGE | لا | - |
| `end_image` | صورة الإطار الأخير لتسلسل الفيديو | IMAGE | لا | - |

**ملاحظة:** عند توفير كل من `start_image` و `end_image`، تنشئ العقدة تسلسل فيديو ينتقل بين هذين الإطارين. يتم اقتصاص `start_image` إلى أول `length` إطارات، ويتم اقتصاص `end_image` إلى آخر `length` إطارات قبل المعالجة. إذا تم توفير أحدهما فقط، يتم ملء الجانب المفقود بإطارات رمادية محايدة. يتم ضبط القناع على 0 حيث توجد إطارات البداية والنهاية، وعلى 1 في الأماكن الأخرى. المعاملان `clip_vision_start_image` و `clip_vision_end_image` اختياريان؛ عند توفيرهما معًا، يتم دمج ميزات CLIP الخاصة بهما وتطبيقها على كل من التهيئة الإيجابية والسلبية. عند توفير أحدهما فقط، يتم استخدام ميزاته بمفردها.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تهيئة إيجابية مع تطبيق ترميز إطار الفيديو وميزات رؤية CLIP | CONDITIONING |
| `negative` | تهيئة سلبية مع تطبيق ترميز إطار الفيديو وميزات رؤية CLIP | CONDITIONING |
| `latent` | موتر كامن فارغ بأبعاد مطابقة لمعاملات الفيديو المحددة | LATENT |
