# WanFirstLastFrameToVideo

הצומת WanFirstLastFrameToVideo מכין קונדישנינג ליצירת וידאו על ידי שילוב פריים התחלה ופריים סיום עם פרומפטים טקסטואליים. הוא מקודד את תמונות הפריים למרחב latent, יוצר מסכה שאומרת למודל הווידאו אילו פריימים כבר ידועים, ומצרף תכונות CLIP vision כאשר הן מסופקות. הצומת מוציא קונדישנינג חיובי ושלילי מעודכנים וכן latent ריק שמגדיר את הגודל והאורך של הווידאו שיש ליצור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קונדישנינג טקסט חיובי המשמש להנחיית יצירת הווידאו. | CONDITIONING | כן | - |
| `negative` | קונדישנינג טקסט שלילי המשמש להנחיית יצירת הווידאו. | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות הפריים המשולבות למרחב latent. | VAE | כן | - |
| `width` | רוחב הווידאו הנוצר בפיקסלים (ברירת מחדל: 832, צעד: 16). | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה הווידאו הנוצר בפיקסלים (ברירת מחדל: 480, צעד: 16). | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו (ברירת מחדל: 81, צעד: 4). | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר סרטוני הווידאו ליצירה בבת אחת (ברירת מחדל: 1). | INT | כן | 1 עד 4096 |
| `clip_vision_start_image` | תכונות CLIP vision שחולצו מתמונת ההתחלה. אם מסופקים גם קלטי CLIP vision של ההתחלה וגם של הסיום, התכונות שלהם משולבות. | CLIP_VISION_OUTPUT | לא | - |
| `clip_vision_end_image` | תכונות CLIP vision שחולצו מתמונת הסיום. אם מסופקים גם קלטי CLIP vision של ההתחלה וגם של הסיום, התכונות שלהם משולבות. | CLIP_VISION_OUTPUT | לא | - |
| `start_image` | תמונת פריים ההתחלה עבור רצף הווידאו. הפריימים הראשונים שלה, שמספרם `length`, משמשים ומכווננים לגודל `width` × `height`. | IMAGE | לא | - |
| `end_image` | תמונת פריים הסיום עבור רצף הווידאו. הפריימים האחרונים שלה, שמספרם `length`, משמשים ומכווננים לגודל `width` × `height`. | IMAGE | לא | - |

**הערה:** כאשר לפחות אחד מהפרמטרים `start_image` או `end_image` מסופק, הצומת בונה רצף פריימים משולב שבו פריימי ההתחלה והסיום ממולאים והפריימים הנותרים משתמשים בממלא מקום אפור ניטרלי (0.5). מסכה מסמנת את האזורים הממולאים כידועים ואת אזורי ממלא המקום כלא ידועים, ומאפשרת למודל הווידאו ליצור את הפריימים שביניהם. כאשר מסופקת תמונת התחלה, האזור הידוע מתרחב גם ב-3 פריימים נוספים מעבר לתמונה. אותה תמונת פריים מקודדת ואותה מסכה מצורפות הן לקונדישנינג `positive` והן לקונדישנינג `negative`. אם שני קלטי CLIP vision מסופקים, מצבי ה-hidden שלהם משורשרים; אם רק אחד מסופק, הוא משמש כשלעצמו. אורך ה-latent של הווידאו נגזר מ-`length` לאחר דחיסה זמנית: `((length - 1) // 4) + 1`.
