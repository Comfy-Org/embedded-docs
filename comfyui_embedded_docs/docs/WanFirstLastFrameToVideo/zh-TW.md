# Wan 首尾影格轉影片

WanFirstLastFrameToVideo 節點透過結合起始幀與結束幀及文字提示，為影片生成準備條件。它會將幀影像編碼至潛在空間，建立一個遮罩來告知影片模型哪些幀是已知的，並在提供 CLIP 視覺特徵時附加這些特徵。此節點輸出更新後的正向與負向條件，以及一個定義待生成影片大小與長度的空潛在張量。

**注意：** 當 `start_image` 或 `end_image` 至少提供其中一個時，節點會建立一個合併的幀序列，其中起始幀與結束幀會被填入，其餘幀使用中性灰預留值（0.5）。遮罩會將已填入的區域標記為已知，將預留區域標記為未知，使影片模型得以生成中間幀。當提供起始影像時，已知區域會在影像之外額外延伸 3 幀。相同的編碼後幀影像與遮罩會附加到 `positive` 與 `negative` 條件。如果同時提供兩個 CLIP 視覺輸入，其隱藏狀態會串接；如果只提供其中一個，則單獨使用。潛在影片長度會依時間壓縮由 `length` 推導得出：`((length - 1) // 4) + 1`。
