# ModelMergeWAN2_1

ModelMergeWAN2_1ノードは、重み付き平均を使用して2つのWAN2.1モデルの各コンポーネントをブレンドし、マージします。1.3Bモデル（30ブロック）や14Bモデル（40ブロック）など、さまざまなモデルサイズに対応しており、追加の画像埋め込みコンポーネントを含む画像から動画へのモデルを特別に処理します。モデルの各コンポーネントは個別に重みを設定でき、2つの入力モデル間のブレンド比率を制御できます。
