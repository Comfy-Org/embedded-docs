# ModelMergeWAN2_1

Узел `ModelMergeWAN2_1` объединяет две модели WAN2.1, смешивая их компоненты с помощью взвешенных средних. Он поддерживает модели разных размеров, включая модели 1.3B с 30 блоками и модели 14B с 40 блоками, с особой обработкой для моделей «изображение-в-видео», которые содержат дополнительный компонент эмбеддинга изображения. Каждый компонент моделей может иметь индивидуальный вес для управления соотношением смешивания между двумя входными моделями.
