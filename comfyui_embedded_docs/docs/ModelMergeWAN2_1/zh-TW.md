# 模型合併 (WAN2.1)

ModelMergeWAN2_1 節點透過使用加權平均混合兩個 WAN2.1 模型的元件來合併它們。它支援不同的模型大小，包括具有 30 個區塊的 1.3B 模型和具有 40 個區塊的 14B 模型，並特別處理包含額外影像嵌入元件的影像轉視訊模型。每個元件都可以單獨設定權重，以控制兩個輸入模型之間的混合比例。
