# ByteDance2ReferenceNodeV2

ByteDance Seedance 2.5 Reference to Video создаёт, редактирует или продлевает видео с помощью моделей ByteDance Seedance (Seedance 2.5, 2.0, 2.0 Fast и 2.0 Mini), руководствуясь текстовым запросом и дополнительными эталонными изображениями, видео, аудио или ранее загруженными ресурсами библиотеки. Узел загружает эталоны, отправляет задачу генерации, ожидает завершения и возвращает готовый видеофайл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Селектор модели. Seedance 2.5 — новейшая модель, видео до 30 секунд и вывод в формате mp4/mov; Seedance 2.0 — максимальное качество и 4k; Fast — оптимизация скорости; Mini — самая быстрая и недорогая генерация. Выбор модели изменяет отображаемые ниже виджеты ввода. | DYNAMIC_COMBO | Да | "Seedance 2.5"<br>"Seedance 2.0"<br>"Seedance 2.0 Fast"<br>"Seedance 2.0 Mini" |
| `сид` | Сид управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от сида. По умолчанию: 0. | INT | Да | 0 до 2147483647 |
| `водяной знак` | Добавлять ли водяной знак на видео. По умолчанию: False. Расширенная настройка. | BOOLEAN | Да | true<br>false |

### Входы Seedance 2.5

Эти входы появляются, когда для `model` установлено значение "Seedance 2.5".

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. Заключайте произносимые реплики в двойные кавычки, чтобы управлять генерируемым диалогом. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: 720p. | COMBO | Да | "480p"<br>"720p"<br>"1080p" |
| `ratio` | Соотношение сторон выходного видео. По умолчанию: 16:9. | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9"<br>"adaptive" |
| `duration` | Длительность выходного видео в секундах (4–30). По умолчанию: 5. | INT | Да | 4 до 30 |
| `generate_audio` | Включить генерацию аудио для выходного видео. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `task_type` | Что делать с эталонными медиа. Каждое значение, кроме auto, проверяется при отправке задачи, поэтому несоответствующие настройки приводят к ошибке до начала генерации.
auto: модель определяет задачу по запросу и входным данным, а конфликтующие с её интерпретацией настройки приводят к ошибке только после начала генерации.
reference: создать новое видео под руководством эталонных изображений, видео и аудио.
edit: изменить подключённое эталонное видео (добавить, удалить, заменить); на выходе сохраняется собственная длительность и соотношение сторон исходного клипа, а виджеты duration и ratio игнорируются.
extend: продолжить подключённое эталонное видео вперёд или назад; в запросе следует указать "extend forward", "extend backward" или "continue", соотношение сторон наследуется из исходного клипа, а выходные данные содержат только вновь созданный сегмент заданной длительности, а не исходный клип. По умолчанию: auto. | COMBO | Да | "auto"<br>"reference"<br>"edit"<br>"extend" |
| `output_format` | Формат контейнера выходного видео. По умолчанию: mp4. | COMBO | Да | "mp4" |

### Эталонные входы

Эти расширяемые эталонные слоты доступны для всех моделей. Максимальное количество слотов различается в зависимости от модели: Seedance 2.5 поддерживает до 30 изображений, 10 видео, 10 аудио и 30 ресурсов; Seedance 2.0, 2.0 Fast и 2.0 Mini поддерживают до 9 изображений, 3 видео, 3 аудио и 9 ресурсов.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите 1..N эталонных изображений, которые управляют выходным результатом. Ограничение количества зависит от модели (см. разделы моделей). Изображения проверяются на соответствие соотношению сторон (от 0,4 до 2,5) и автоматически уменьшаются до максимальной стороны 6000 пикселей. | IMAGE | Нет | 1..9 слотов (семейство Seedance 2.0)<br>1..30 слотов (Seedance 2.5) |
| `reference_videos` | Расширяемый слот: подключите 1..N эталонных видео. Ограничение количества зависит от модели (см. разделы моделей). Каждое видео должно быть не короче 1,8 секунды и должно соответствовать ограничениям по пикселям для выбранной модели и разрешения. | VIDEO | Нет | 1..3 слота (семейство Seedance 2.0)<br>1..10 слотов (Seedance 2.5) |
| `reference_audios` | Расширяемый слот: подключите 1..N эталонных аудиодорожек. Ограничение количества зависит от модели (см. разделы моделей). Каждое аудио должно быть не короче 1,8 секунды. | AUDIO | Нет | 1..3 слота (семейство Seedance 2.0)<br>1..10 слотов (Seedance 2.5) |
| `reference_assets` | Расширяемый слот: подключите 1..N строк идентификаторов ресурсов для медиа, уже загруженных в виртуальную библиотеку Seedance. Каждый ресурс должен иметь статус Active. Вы можете ссылаться на ресурс в запросе с помощью токенов, таких как `asset1` или `asset 1`; узел заменяет их на позиционную метку ресурса (например, "Image 2" или "Video 1"). | STRING | Нет | 1..9 слотов (семейство Seedance 2.0)<br>1..30 слотов (Seedance 2.5) |
| `auto_downscale` | Автоматически уменьшать эталонные видео, превышающие пиксельный бюджет модели для выбранного разрешения. Соотношение сторон сохраняется; видео, уже укладывающиеся в лимиты, не изменяются. По умолчанию: True. | BOOLEAN | Нет | true<br>false |
| `auto_upscale` | Автоматически увеличивать разрешение эталонных видео, которые не достигают минимального количества пикселей для выбранного разрешения. Соотношение сторон сохраняется; видео, уже удовлетворяющие минимуму, не изменяются. Примечание: увеличение разрешения низкокачественного источника не добавляет реальных деталей и может привести к генерации более низкого качества. По умолчанию: False. Расширенная настройка. | BOOLEAN | Нет | true<br>false |

**Примечание:** Для работы узла требуется хотя бы одно эталонное изображение, видео или ресурс (Seedance 2.5 также принимает ссылки только на аудио). Эталонные видео и аудио должны быть не короче 1,8 секунды каждое, а суммарная длительность всех эталонных видео (и отдельно всех эталонных аудио) не должна превышать максимальное общее количество секунд для выбранной модели. Эталонные изображения должны иметь соотношение сторон примерно от 2:5 до 5:2 (от 0,4 до 2,5), быть не менее 300x300 пикселей и автоматически уменьшаться до максимальной стороны 6000 пикселей. Параметры `task_type` "edit" и "extend" доступны только для Seedance 2.5, и оба требуют хотя бы одного эталонного видео; при использовании "edit" выходное видео сохраняет собственную длительность и соотношение сторон исходного клипа, а виджеты `duration` и `ratio` игнорируются; при использовании "extend" выходные данные содержат только вновь созданный сегмент заданной длительности. На указанные ресурсы должен распространяться статус Active, иначе задача завершится ошибкой.
