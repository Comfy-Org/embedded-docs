# ByteDance Seedance 2.5: референс в видео

ByteDance Seedance 2.5 Reference to Video генерирует, редактирует или расширяет видео с помощью моделей ByteDance Seedance (Seedance 2.5, 2.0, 2.0 Fast и 2.0 Mini) по текстовой подсказке и необязательным эталонным изображениям, видео, аудио или ранее загруженным библиотечным ассетам. Он загружает эталонные материалы, отправляет задачу генерации, ожидает завершения и возвращает готовый видеофайл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Селектор модели. Seedance 2.5 — для новейшей модели, видео длительностью до 30 секунд и вывода в mp4/mov; Seedance 2.0 — для максимального качества и 4k; Fast — для оптимизации скорости; Mini — для самой быстрой и самой дешёвой генерации. Выбор модели изменяет отображаемые ниже виджеты входов. | DYNAMIC_COMBO | Да | "Seedance 2.5"<br>"Seedance 2.0"<br>"Seedance 2.0 Fast"<br>"Seedance 2.0 Mini" |
| `сид` | Seed управляет тем, следует ли перезапускать узел; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Да | от 0 до 2147483647 |
| `водяной знак` | Добавлять ли водяной знак к видео. По умолчанию: False. Расширенная настройка. | BOOLEAN | Да | true<br>false |

### Входы Seedance 2.5

Эти входы отображаются, когда для `model` выбрано значение "Seedance 2.5".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовая подсказка для генерации видео. Заключайте произносимые реплики в двойные кавычки, чтобы управлять сгенерированным диалогом. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: 720p. | COMBO | Да | "480p"<br>"720p"<br>"1080p" |
| `ratio` | Соотношение сторон выходного видео. По умолчанию: 16:9. | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9"<br>"adaptive" |
| `duration` | Длительность выходного видео в секундах (4-30). По умолчанию: 5. | INT | Да | от 4 до 30 |
| `generate_audio` | Включить генерацию аудио для выходного видео. По умолчанию: True. | BOOLEAN | Да | true<br>false |
| `task_type` | Что делать с эталонными медиа. Все значения, кроме auto, проверяются при отправке задачи, поэтому несовместимые настройки дают сбой до начала генерации.<br>auto: модель определяет задачу по подсказке и входным данным, а настройки, противоречащие её трактовке, дают сбой только после начала генерации.<br>reference: сгенерировать новое видео на основе эталонных изображений, видео и аудио.<br>edit: изменить подключённое эталонное видео (добавить, удалить, заменить); выход сохраняет собственную длительность и соотношение сторон исходного клипа, а виджеты `duration` и `ratio` игнорируются.<br>extend: продолжить подключённое эталонное видео вперёд или назад; в подсказке должно быть указано "extend forward", "extend backward" или "continue", соотношение сторон следует за исходным клипом, а выход содержит только новый сгенерированный сегмент заданной вами длительности, а не исходный клип. По умолчанию: auto. | COMBO | Да | "auto"<br>"reference"<br>"edit"<br>"extend" |
| `output_format` | Формат контейнера выходного видео. По умолчанию: mp4. | COMBO | Да | "mp4" |

### Эталонные входы

Эти расширяемые эталонные слоты доступны для всех моделей. Максимальное количество слотов зависит от модели: Seedance 2.5 поддерживает до 30 изображений, 10 видео, 10 аудио и 30 ассетов; Seedance 2.0, 2.0 Fast и 2.0 Mini поддерживают до 9 изображений, 3 видео, 3 аудио и 9 ассетов.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите от 1 до N эталонных изображений, которые направляют вывод. Ограничение количества зависит от модели (см. разделы моделей). Изображения проверяются на соотношение сторон (0.4–2.5) и автоматически уменьшаются до максимальной стороны 6000 пикселей. | IMAGE | Нет | 1..9 слотов (семейство Seedance 2.0)<br>1..30 слотов (Seedance 2.5) |
| `reference_videos` | Расширяемый слот: подключите от 1 до N эталонных видео. Ограничение количества зависит от модели (см. разделы моделей). Каждое видео должно быть длительностью не менее 1.8 секунды и соответствовать ограничениям по пикселям для выбранной модели и разрешения. | VIDEO | Нет | 1..3 слотов (семейство Seedance 2.0)<br>1..10 слотов (Seedance 2.5) |
| `reference_audios` | Расширяемый слот: подключите от 1 до N эталонных аудиодорожек. Ограничение количества зависит от модели (см. разделы моделей). Каждое аудио должно быть длительностью не менее 1.8 секунды. | AUDIO | Нет | 1..3 слотов (семейство Seedance 2.0)<br>1..10 слотов (Seedance 2.5) |
| `reference_assets` | Расширяемый слот: подключите от 1 до N строк ID ассетов для медиа, уже загруженных в виртуальную библиотеку Seedance. Каждый ассет должен быть Active. Вы можете ссылаться на ассет в подсказке с помощью токенов, таких как `asset1` или `asset 1`; узел заменяет их на позиционную метку ассета (например, "Image 2" или "Video 1"). | STRING | Нет | 1..9 слотов (семейство Seedance 2.0)<br>1..30 слотов (Seedance 2.5) |
| `auto_downscale` | Автоматически уменьшать масштаб эталонных видео, которые превышают бюджет пикселей модели для выбранного разрешения. Соотношение сторон сохраняется; видео, уже находящиеся в пределах ограничений, не изменяются. По умолчанию: True. | BOOLEAN | Нет | true<br>false |
| `auto_upscale` | Автоматически увеличивать масштаб эталонных видео, которые ниже минимального количества пикселей модели для выбранного разрешения. Соотношение сторон сохраняется; видео, уже соответствующие минимуму, не изменяются. Примечание: увеличение масштаба источника с низким разрешением не добавляет реальных деталей и может привести к генерации более низкого качества. По умолчанию: False. Расширенная настройка. | BOOLEAN | Нет | true<br>false |

**Примечание:** Для запуска узла требуется хотя бы одно эталонное изображение, видео или ассет (Seedance 2.5 также принимает эталонные материалы только из аудио). Эталонные видео и аудио должны иметь длительность не менее 1.8 секунды каждое, а суммарная длительность всех эталонных видео (и отдельно всех эталонных аудио) не должна превышать максимальное общее количество секунд для выбранной модели. Эталонные изображения должны иметь соотношение сторон примерно от 2:5 до 5:2 (0.4–2.5), быть не менее 300x300 пикселей и автоматически уменьшаются до максимальной стороны 6000 пикселей. Опции `task_type` "edit" и "extend" доступны только с Seedance 2.5, и обе требуют хотя бы одного эталонного видео; при использовании "edit" выход сохраняет собственную длительность и соотношение сторон исходного клипа, а виджеты `duration` и `ratio` игнорируются, а при использовании "extend" выход содержит только новый сгенерированный сегмент заданной вами длительности. Эталонные ассеты должны иметь статус Active, иначе задача завершится с ошибкой.
