# Sonilo: Текст в музыку

Узел Sonilo Text to Music генерирует музыку на основе текстового описания с помощью ИИ-модели Sonilo. Вы предоставляете запрос с описанием желаемой музыки, и узел отправляет запрос в сервис Sonilo для создания аудиофайла. Также можно указать целевую длительность генерируемой музыки.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос с описанием музыки для генерации. Должен содержать от 1 до 1000 символов. | STRING | Да | от 1 до 1000 символов |
| `duration` | Целевая длительность в секундах. Максимум: 6 минут. По умолчанию: 30. | INT | Нет | от 1 до 360 |
| `seed` | Сид для воспроизводимости. В настоящее время игнорируется сервисом Sonilo, но сохранён для согласованности графа. По умолчанию: 0. | INT | Нет | от 0 до 18446744073709551615 |

**Примечание:** Входной параметр `seed` предусмотрен для согласованности рабочего процесса, но в настоящее время не влияет на вывод сервиса Sonilo.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированная музыка в виде аудиофайла. | AUDIO |
