# Sonilo: Текст в музыку

Узел Sonilo Text to Music генерирует музыку на основе текстового описания с помощью ИИ-модели Sonilo. Вы предоставляете текстовый запрос, описывающий желаемую музыку, и узел отправляет запрос в сервис Sonilo для создания аудиофайла. Вы можете задать целевую длительность генерируемого клипа.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий музыку для генерации. Должен содержать от 1 до 1000 символов после удаления пробелов. | STRING | Да | N/A |
| `duration` | Целевая длительность в секундах. Максимум: 6 минут. По умолчанию: 30. | INT | Нет | 1 до 360 |
| `seed` | Сид для воспроизводимости. В настоящее время игнорируется сервисом Sonilo, но сохраняется для согласованности графа. По умолчанию: 0. | INT | Нет | 0 до 18446744073709551615 |

**Примечания:**
- Входной параметр `seed` предусмотрен для согласованности рабочего процесса, но в настоящее время не влияет на результат работы сервиса Sonilo.
- Использование тарифицируется по ставке $0.0025 за каждую секунду запрошенного `duration`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированная музыка в виде аудиофайла. | AUDIO |
