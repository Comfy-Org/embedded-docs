# تبدیل متن به موسیقی با Sonilo

گره Sonilo Text to Music با استفاده از مدل هوش مصنوعی Sonilo، موسیقی را از یک توضیح متنی تولید می‌کند. شما توضیحی از موسیقی موردنظر خود ارائه می‌دهید و گره برای ایجاد یک فایل صوتی، درخواستی به سرویس Sonilo ارسال می‌کند. می‌توانید مدت‌زمان هدف را برای کلیپ تولیدشده تعیین کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن توضیحی درباره موسیقی که باید تولید شود. باید پس از حذف فاصله‌های ابتدا و انتها، شامل ۱ تا ۱۰۰۰ کاراکتر باشد. | STRING | بله | نامعتبر |
| `duration` | مدت‌زمان هدف بر حسب ثانیه. حداکثر: ۶ دقیقه. پیش‌فرض: ۳۰. | INT | خیر | ۱ تا ۳۶۰ |
| `seed` | دانه (Seed) برای بازتولیدپذیری. در حال حاضر توسط سرویس Sonilo نادیده گرفته می‌شود، اما برای سازگاری گراف حفظ می‌شود. پیش‌فرض: ۰. | INT | خیر | ۰ تا ۱۸۴۴۶۷۴۴۰۷۳۷۰۹۵۵۱۶۱۵ |

**نکات:**
- ورودی `seed` برای سازگاری گردش کار ارائه شده است، اما در حال حاضر بر خروجی سرویس Sonilo تأثیر نمی‌گذارد.
- استفاده از سرویس به ازای هر ثانیه از `duration` درخواستی، ۰.۰۰۲۵ دلار هزینه دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | موسیقی تولیدشده به‌صورت یک فایل صوتی. | AUDIO |
