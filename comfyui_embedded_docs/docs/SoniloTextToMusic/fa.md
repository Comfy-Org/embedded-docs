# تبدیل متن به موسیقی با Sonilo

گره **Sonilo Text to Music** با استفاده از مدل هوش مصنوعی سونی‌لو، موسیقی را بر اساس توصیف متنی تولید می‌کند. شما متنی را که موسیقی موردنظر را توصیف می‌کند وارد می‌کنید و گره درخواستی به سرویس سونی‌لو ارسال کرده و یک فایل صوتی می‌سازد. همچنین می‌توانید مدت‌زمان هدف موسیقی تولیدشده را مشخص کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن راهنما برای توصیف موسیقی موردنظر برای تولید. باید بین ۱ تا ۱۰۰۰ کاراکتر باشد. | STRING | بله | ۱ تا ۱۰۰۰ کاراکتر |
| `duration` | مدت‌زمان هدف بر حسب ثانیه. حداکثر: ۶ دقیقه. پیش‌فرض: ۳۰. | INT | خیر | ۱ تا ۳۶۰ |
| `seed` | مقدار Seed برای بازتولیدپذیری. در حال حاضر توسط سرویس سونی‌لو نادیده گرفته می‌شود، اما برای سازگاری گراف حفظ شده است. پیش‌فرض: ۰. | INT | خیر | ۰ تا ۱۸۴۴۶۷۴۴۰۷۳۷۰۹۵۵۱۶۱۵ |

**توجه:** ورودی `seed` برای سازگاری جریان کار ارائه شده است اما در حال حاضر بر خروجی سرویس سونی‌لو تأثیری ندارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | موسیقی تولیدشده به‌صورت یک فایل صوتی. | AUDIO |
