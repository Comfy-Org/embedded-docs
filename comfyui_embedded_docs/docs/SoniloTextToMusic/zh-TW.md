# Sonilo 文字轉音樂

Sonilo Text to Music 節點使用 Sonilo 的 AI 模型，根據文字描述生成音樂。你提供一段描述所需音樂的提示詞，節點會向 Sonilo 服務傳送請求以建立音訊檔案。你可以為生成的片段設定目標時長。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述要生成音樂的文字提示詞。去除空白後必須包含 1 到 1000 個字元。 | STRING | 是 | 1 至 1000 characters |
| `duration` | 目標時長，以秒為單位。最長：6 分鐘。預設值：30。 | INT | 否 | 1 至 360 |
| `seed` | 用於確保可重現性的種子。Sonilo 服務目前會忽略此參數，但保留它是為了工作流程圖的一致性。預設值：0。 | INT | 否 | 0 至 18446744073709551615 |

**備註：**
- 提供 `seed` 輸入是為了工作流程的一致性，但目前不會影響 Sonilo 服務的輸出。
- `prompt` 輸入為必填且不得為空；節點會驗證其在去除空白後至少包含 1 個字元，且不超過 1000 個字元。
- 使用費用以所請求 `duration` 的每秒 $0.0025 計費。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `audio` | 生成的音樂，以音訊檔案形式呈現。 | AUDIO |
