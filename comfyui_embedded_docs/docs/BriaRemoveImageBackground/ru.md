# Bria Удалить фон изображения

Этот узел удаляет фон с изображения с помощью сервиса Bria RMBG 2.0. Он отправляет изображение во внешний API для обработки и возвращает результат с удалённым фоном.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `модерация` | Настройки модерации. Если установлено значение `"true"`, становятся доступны дополнительные параметры модерации. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |
| `изображение` | Входное изображение, с которого будет удалён фон. | IMAGE | Да | - |
| `seed` | Сид управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от сида. По умолчанию: `0`. | INT | Да | 0 to 2147483647 |

### Входы модерации

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `visual_input_moderation` | Включает модерацию визуального содержимого входного изображения. Этот параметр доступен только когда `moderation` установлен в `"true"`. По умолчанию: `False`. | BOOLEAN | Нет | - |
| `visual_output_moderation` | Включает модерацию визуального содержимого выходного изображения. Этот параметр доступен только когда `moderation` установлен в `"true"`. По умолчанию: `True`. | BOOLEAN | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `image` | The processed image with its background removed. | IMAGE |
