# Bria Удалить фон изображения

Этот узел удаляет фон с изображения с помощью сервиса Bria RMBG 2.0. Он отправляет изображение во внешний API для обработки и возвращает результат с удалённым фоном.

## Входы

Селектор `moderation` открывает дополнительные параметры модерации, когда для него установлено значение `"true"`.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, из которого будет удалён фон. | IMAGE | Да | - |
| `модерация` | Настройки модерации. Когда установлено значение `"true"`, становятся доступны дополнительные параметры модерации. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |
| `seed` | Параметр `seed` управляет тем, должен ли узел повторно выполняться; результаты недетерминированы независимо от seed. По умолчанию: `0`. | INT | Да | 0 до 2147483647 |

### Входы Moderation "true"

Эти параметры появляются только когда для `moderation` установлено значение `"true"`. Опция `"false"` не добавляет дополнительных входов.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | Включает модерацию визуального содержимого для входного изображения. По умолчанию: `False`. | BOOLEAN | Нет | - |
| `visual_output_moderation` | Включает модерацию визуального содержимого для выходного изображения. По умолчанию: `True`. | BOOLEAN | Нет | - |

**Примечание:** Параметры `visual_input_moderation` и `visual_output_moderation` зависят от параметра `moderation`. Они активны только когда для `moderation` установлено значение `"true"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Обработанное изображение с удалённым фоном. | IMAGE |
