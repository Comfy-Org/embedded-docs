# حذف پس‌زمینه تصویر Bria

این گره پس‌زمینه را از یک تصویر با استفاده از سرویس Bria RMBG 2.0 حذف می‌کند. تصویر را برای پردازش به یک API خارجی می‌فرستد و نتیجه را با پس‌زمینهٔ حذف‌شده برمی‌گرداند.

## ورودی‌ها

انتخاب‌گر `moderation` هنگام تنظیم روی `"true"` گزینه‌های نظارت بیشتری را آشکار می‌کند.

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که پس‌زمینه از آن حذف می‌شود. | IMAGE | بله | - |
| `moderation` | تنظیمات نظارت. وقتی روی `"true"` تنظیم شود، گزینه‌های نظارت بیشتری در دسترس قرار می‌گیرند. | DYNAMIC_COMBO | بله | `"false"`<br>`"true"` |
| `seed` | مقدار `seed` کنترل می‌کند که گره دوباره اجرا شود یا نه؛ نتایج بدون توجه به `seed` غیرقطعی هستند. پیش‌فرض: `0`. | INT | بله | 0 تا 2147483647 |

### ورودی‌های Moderation "true"

این پارامترها فقط زمانی ظاهر می‌شوند که `moderation` روی `"true"` تنظیم شده باشد. گزینه `"false"` هیچ ورودی اضافه‌ای اضافه نمی‌کند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | نظارت بر محتوای بصری را روی تصویر ورودی فعال می‌کند. پیش‌فرض: `False`. | BOOLEAN | خیر | - |
| `visual_output_moderation` | نظارت بر محتوای بصری را روی تصویر خروجی فعال می‌کند. پیش‌فرض: `True`. | BOOLEAN | خیر | - |

**توجه:** پارامترهای `visual_input_moderation` و `visual_output_moderation` به پارامتر `moderation` وابسته هستند. آن‌ها فقط زمانی فعال هستند که `moderation` روی `"true"` تنظیم شده باشد.

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر پردازش‌شده با پس‌زمینهٔ حذف‌شده. | IMAGE |
