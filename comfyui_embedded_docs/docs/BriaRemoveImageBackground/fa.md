# حذف پس‌زمینه تصویر Bria

این گره پس‌زمینه تصویر را با استفاده از سرویس Bria RMBG 2.0 حذف می‌کند. تصویر را برای پردازش به یک API خارجی ارسال می‌کند و نتیجه را با پس‌زمینه حذف‌شده بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که پس‌زمینه از آن حذف خواهد شد. | IMAGE | بله | - |
| `مدیریت محتوا` | تنظیمات نظارت. وقتی روی `"true"` تنظیم شود، گزینه‌های نظارت اضافی در دسترس قرار می‌گیرند. | COMBO | خیر | `"false"`<br>`"true"` |
| `visual_input_moderation` | نظارت بر محتوای بصری روی تصویر ورودی را فعال می‌کند. این پارامتر فقط زمانی در دسترس است که `moderation` روی `"true"` تنظیم شده باشد. پیش‌فرض: `False`. | BOOLEAN | خیر | - |
| `visual_output_moderation` | نظارت بر محتوای بصری روی تصویر خروجی را فعال می‌کند. این پارامتر فقط زمانی در دسترس است که `moderation` روی `"true"` تنظیم شده باشد. پیش‌فرض: `True`. | BOOLEAN | خیر | - |
| `seed` | seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. پیش‌فرض: `0`. | INT | خیر | 0 تا 2147483647 |

**توجه:** پارامترهای `visual_input_moderation` و `visual_output_moderation` به پارامتر `moderation` وابسته هستند. آن‌ها فقط زمانی فعال هستند که `moderation` روی `"true"` تنظیم شده باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر پردازش‌شده با پس‌زمینه حذف‌شده. | IMAGE |
