# حذف پس‌زمینه تصویر Bria

این گره پس‌زمینه تصویر را با استفاده از سرویس Bria RMBG 2.0 حذف می‌کند. تصویر را برای پردازش به یک API خارجی ارسال می‌کند و نتیجه را با پس‌زمینه حذف‌شده بازمی‌گرداند.
## ورودیها

### ورودیهای مشترک

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `moderation` | تنظیمات نظارت. وقتی روی `"true"` تنظیم شود، گزینه‌های نظارت اضافی در دسترس قرار می‌گیرند. | DYNAMIC_COMBO | بله | `"false"`<br>`"true"` |
| `image` | تصویر ورودی که پس‌زمینه از آن حذف خواهد شد. | IMAGE | بله | - |
| `seed` | seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. پیش‌فرض: `0`. | INT | بله | 0 to 2147483647 |

### ورودیهای نظارت

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `visual_input_moderation` | نظارت بر محتوای بصری روی تصویر ورودی را فعال می‌کند. این پارامتر فقط زمانی در دسترس است که `moderation` روی `"true"` تنظیم شده باشد. پیش‌فرض: `False`. | BOOLEAN | خیر | - |
| `visual_output_moderation` | نظارت بر محتوای بصری روی تصویر خروجی را فعال می‌کند. این پارامتر فقط زمانی در دسترس است که `moderation` روی `"true"` تنظیم شده باشد. پیش‌فرض: `True`. | BOOLEAN | خیر | - |

## خروجیها

| نام خروجی | توضیحات | نوع داده |
|---|---|---|
| `image` | The processed image with its background removed. | IMAGE |
