# Bria הסרת רקע מתמונה

צומת זה מסיר את הרקע מתמונה באמצעות שירות Bria RMBG 2.0. הוא שולח את התמונה ל-API חיצוני לעיבוד ומחזיר את התוצאה כאשר הרקע הוסר.

## קלטים

הבורר `moderation` חושף אפשרויות מודרציה נוספות כאשר הוא מוגדר ל-`"true"`.

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שממנה יוסר הרקע. | IMAGE | כן | - |
| `moderation` | הגדרות מודרציה. כאשר הן מוגדרות ל-`"true"`, נפתחות אפשרויות מודרציה נוספות. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |
| `seed` | `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. ברירת מחדל: `0`. | INT | כן | 0 עד 2147483647 |

### קלטים של Moderation "true"

פרמטרים אלה מופיעים רק כאשר `moderation` מוגדר ל-`"true"`. האפשרות `"false"` אינה מוסיפה קלטים נוספים.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | מאפשר מודרציה של תוכן חזותי בתמונת הקלט. ברירת מחדל: `False`. | BOOLEAN | לא | - |
| `visual_output_moderation` | מאפשר מודרציה של תוכן חזותי בתמונת הפלט. ברירת מחדל: `True`. | BOOLEAN | לא | - |

**הערה:** הפרמטרים `visual_input_moderation` ו-`visual_output_moderation` תלויים בפרמטר `moderation`. הם פעילים רק כאשר `moderation` מוגדר ל-`"true"`.
