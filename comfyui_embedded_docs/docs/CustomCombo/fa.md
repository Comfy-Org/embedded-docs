# ترکیب سفارشی

گره Custom Combo به شما امکان می‌دهد یک منوی کشویی سفارشی با فهرست گزینه‌های متنی خود ایجاد کنید. این گره عمدتاً فرانت‌اند است و یک نمایش بک‌اند برای تضمین سازگاری در گردش کار شما فراهم می‌کند. هنگامی که گزینه‌ای را از منوی کشویی انتخاب می‌کنید، گره آن متن را به‌صورت رشته و موقعیت ایندکس آن را خروجی می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
| --- | --- | --- | --- | --- |
| `choice` | گزینه متنی انتخاب‌شده از منوی کشویی سفارشی. فهرست گزینه‌های موجود توسط کاربر در رابط کاربری فرانت‌اند گره تعریف می‌شود. | COMBO | بله | User-defined |
| `index` | یک مقدار صحیح که می‌تواند برای مشخص کردن یک ایندکس استفاده شود. پیش‌فرض: 0. | INT | خیر | Any integer |

**توجه:** اعتبارسنجی ورودی این گره به‌طور عمدی غیرفعال شده است. این به شما امکان می‌دهد هر گزینه متنی سفارشی را که می‌خواهید در فرانت‌اند تعریف کنید، بدون اینکه بک‌اند بررسی کند که انتخاب شما از یک فهرست از پیش تعریف‌شده است. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `STRING` | رشته متنی گزینه انتخاب‌شده از کومبوی سفارشی. | STRING |
| `INDEX` | موقعیت ایندکس گزینه انتخاب‌شده در فهرست کشویی. | INT |
