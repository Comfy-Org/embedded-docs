# 自訂組合

Custom Combo 節點允許您建立一個自訂下拉式選單，其中包含您自己的文字選項清單。這是一個以前端為主的節點，同時具備後端實作以保持您的工作流程相容性。當您從下拉式選單中選取一個選項時，節點會輸出該選項的文字字串及其索引位置。

## 輸入
| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `選項` | 從自訂下拉式選單中選取的文字選項。可用選項清單由使用者在節點的前端介面中定義。 | COMBO | 是 | 使用者定義 |
| `index` | 可用於指定索引的整數值。預設值：0。 | INT | 否 | 任意整數（預設值：0） |

**注意：** 此節點輸入的驗證功能已刻意停用。這允許您在前端撰寫任何自訂文字選項，而後端不會檢查您的選取是否符合預先定義的清單。除了組合下拉式選單之外的控制項完全在前端定義。此節點被標記為實驗性。

## 輸出
| 輸出名稱 | 說明 | 資料型別 |
|-------------|-------------|-----------|
| `STRING` | 從自訂下拉式選單中選取之選項的文字字串。 | STRING |
| `INDEX` | 所選選項在下拉式選單中的索引位置。 | INT |
