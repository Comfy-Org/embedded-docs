# Пользовательская комбинация

Узел **Custom Combo** позволяет создать собственный раскрывающийся список с вашим набором текстовых вариантов. Это узел, ориентированный на фронтенд, который также имеет представление в бэкенде для обеспечения совместимости в рамках вашего рабочего процесса. Когда вы выбираете вариант из раскрывающегося списка, узел выводит этот текст в виде строки и его позицию в списке.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `choice` | Текстовый вариант, выбранный из пользовательского раскрывающегося списка. Список доступных вариантов определяется пользователем в интерфейсе узла. | COMBO | Да | Задаётся пользователем |
| `index` | Целое число, которое можно использовать для указания индекса. По умолчанию: 0. | INT | Нет | Любое целое число |

**Примечание.** Проверка входных данных этого узла намеренно отключена. Это позволяет вам задавать любые нужные текстовые варианты в интерфейсе без проверки бэкендом, относится ли ваш выбор к предопределённому списку. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `STRING` | Текстовая строка варианта, выбранного в настраиваемом раскрывающемся списке. | STRING |
| `INDEX` | Порядковый номер выбранного варианта в раскрывающемся списке. | INT |
