# Пользовательская комбинация

Узел Custom Combo позволяет создать собственное выпадающее меню с вашим списком текстовых опций. Это узел, ориентированный на фронтенд, но он включает бэкенд-представление для сохранения совместимости с вашим рабочим процессом. Когда вы выбираете опцию из выпадающего списка, узел выводит этот текст в виде строки и его позицию (индекс).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `выбор` | Текстовая опция, выбранная из выпадающего списка. Список доступных опций определяется пользователем в интерфейсе узла (фронтенд). | COMBO | Да | User-defined |
| `index` | Целочисленное значение, которое можно использовать для указания индекса. По умолчанию: 0. | INT | Нет | Любое целое число (по умолчанию: 0) |

**Примечание:** Проверка входных данных этого узла намеренно отключена. Это позволяет вам записывать любые пользовательские текстовые опции во фронтенде без проверки бэкендом соответствия вашего выбора предопределенному списку. Виджеты, отличные от выпадающего списка, полностью определяются во фронтенде. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовая строка опции, выбранной из пользовательского комбинированного списка. | STRING |
| `ИНДЕКС` | Индексная позиция выбранной опции в выпадающем списке. | INT |
