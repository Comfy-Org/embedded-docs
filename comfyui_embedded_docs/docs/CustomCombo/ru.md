# Пользовательская комбинация

Узел Custom Combo позволяет определить собственный список текстовых вариантов для выпадающего меню вместо выбора из фиксированных значений. Это узел, ориентированный в первую очередь на фронтенд, но также имеющий представление на бэкенде, поэтому воркфлоу, содержащие его, остаются совместимыми. При выборе варианта узел выводит выбранный текст и его индексную позицию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `выбор` | Текстовый вариант, выбранный из пользовательского выпадающего списка. Список доступных вариантов определяется пользователем в интерфейсе фронтенда узла. | COMBO | Да | Определяется пользователем |
| `index` | Целочисленное значение, которое можно использовать для указания индекса. По умолчанию: 0. | INT | Нет | Любое целое число (по умолчанию: 0) |

**Примечание:** Проверка входных данных этого узла намеренно отключена. Это позволяет писать любые пользовательские текстовые варианты во фронтенде без проверки бэкендом того, соответствует ли ваш выбор предопределённому списку. Виджеты, отличные от выпадающего списка combo, полностью определяются во фронтенде. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовая строка варианта, выбранного в пользовательском поле со списком. | STRING |
| `INDEX` | Индексная позиция выбранного варианта в выпадающем списке. | INT |
