# توليفة مخصصة

عقدة **Custom Combo** تتيح لك إنشاء قائمة منسدلة مخصصة تحتوي على قائمتك الخاصة من الخيارات النصية. وهي عقدة تركّز على الواجهة الأمامية، وتتضمن تمثيلًا خلفيًا للحفاظ على توافق سير العمل لديك. عند تحديد خيار من القائمة المنسدلة، تُخرج العقدة ذلك النص كسلسلة نصية وموضعه الفهرس.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `اختيار` | الخيار النصي المحدد من القائمة المنسدلة المخصصة. يتم تحديد قائمة الخيارات المتاحة بواسطة المستخدم في واجهة العقدة الأمامية. | COMBO | نعم | يحدده المستخدم |
| `index` | قيمة عددية صحيحة يمكن استخدامها لتحديد فهرس. الافتراضي: 0. | INT | لا | أي عدد صحيح (الافتراضي: 0) |

**ملاحظة:** تم تعطيل التحقق من مدخلات هذه العقدة عن قصد. يتيح لك هذا كتابة أي خيارات نصية مخصصة في الواجهة الأمامية دون أن يقوم الجزء الخلفي بالتحقق مما إذا كان اختيارك يطابق قائمة محددة مسبقًا. الأدوات الأخرى غير القائمة المنسدلة محددة بالكامل في الواجهة الأمامية. هذه العقدة مصنفة على أنها تجريبية.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `STRING` | السلسلة النصية للخيار المحدد من صندوق القائمة المنسدلة المخصص. | STRING |
| `الفهرس` | موضع الفهرس للخيار المحدد في القائمة المنسدلة. | INT |
