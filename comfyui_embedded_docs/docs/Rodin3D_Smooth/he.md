# Rodin 3D יצירה - יצירה חלקה

הצומת Rodin 3D Smooth יוצר נכסי תלת-ממד באמצעות Rodin API על ידי עיבוד תמונות קלט והמרתן למודלים תלת-ממדיים חלקים. הוא מקבל מספר תמונות כקלט ומפיק קובץ מודל תלת-ממדי שניתן להוריד. הצומת מטפל בכל תהליך היצירה, כולל יצירת משימה, בדיקת סטטוס והורדת קבצים, באופן אוטומטי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `Images` | תמונות קלט לשימוש ביצירת מודל תלת-ממדי. ניתן לספק מספר תמונות (עד 5). | IMAGE | כן | - |
| `Seed` | ערך seed אקראי לעקביות היצירה (ברירת מחדל: 0). | INT | לא | 0 to 65535 |
| `Material_Type` | סוג החומר להחלה על המודל התלת-ממדי (ברירת מחדל: "PBR"). | STRING | לא | "PBR"<br>"Shaded" |
| `Polygon_count` | מספר הפוליגונים הרצוי עבור המודל התלת-ממדי הנוצר. קובע את איכות הרשת ורמת הפירוט (ברירת מחדל: "18K-Quad"). | STRING | לא | "4K-Quad"<br>"8K-Quad"<br>"18K-Quad"<br>"50K-Quad"<br>"200K-Triangle" |

**הערה:** הצומת מקבל עד 5 תמונות קלט. אם לא מסופקות תמונות, תתרחש שגיאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `3D Model Path` | נתיב קובץ למודל התלת-ממדי שהורד (לצורכי תאימות לאחור בלבד). | STRING |
| `GLB` | המודל התלת-ממדי שנוצר בפורמט GLB. | FILE3DGLB |
