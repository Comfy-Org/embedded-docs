# VAE Compute Dtype

צומת זה מגדיר את dtype החישוב שבו VAE משתמש בעת קידוד או פענוח, מבלי לשנות את שאר גרף המודל. הוא מחזיר עותק של VAE הקלט עם הדיוק המבוקש, כך שזרימת עבודה יכולה להריץ ענף אחד בדיוק גבוה יותר בעוד שאחרים נשארים ללא שינוי. "default" שומר על dtype החישוב שבו VAE הקלט כבר משתמש.
