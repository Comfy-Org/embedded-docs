# VAE Compute Dtype

Этот узел задаёт dtype вычислений, используемый при кодировании или декодировании VAE, не изменяя остальную часть графа модели. Он возвращает копию входного VAE с запрошенной точностью, поэтому рабочий процесс может запускать одну ветвь с более высокой точностью, пока другие остаются без изменений. «default» сохраняет текущий dtype вычислений, уже используемый входным VAE.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | VAE, который нужно настроить. Узел работает с копией, поэтому подключённый VAE не изменяется. | VAE | Да | - |
| `dtype` | dtype вычислений для кодирования и декодирования VAE. «default» сохраняет dtype вычислений входного VAE (по умолчанию: «default»). | COMBO | Да | "default"<br>"fp32"<br>"fp16"<br>"bf16" |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `vae` | Копия VAE с применённым выбранным dtype вычислений. | VAE |
