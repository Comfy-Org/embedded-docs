# ModelSamplingContinuousV

הצומת ModelSamplingContinuousV מתאים את התנהגות הדגימה של מודל על ידי החלת דגימת V-prediction רציפה. הוא יוצר שיבוט של מודל הקלט ומגדיר אותו עם ערכי sigma מינימליים ומקסימליים מותאמים אישית, לצורך שליטה מדויקת יותר בתהליך הדגימה.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל הקלט שיש לשנות באמצעות דגימת V-prediction רציפה | MODEL | כן | - |
| `sampling` | שיטת הדגימה להחלה; נכון לעכשיו V-prediction היא האפשרות הזמינה היחידה (ברירת מחדל: `"v_prediction"`) | COMBO | כן | `"v_prediction"` |
| `sigma_max` | ערך ה-sigma המקסימלי לדגימה (פרמטר מתקדם, ברירת מחדל: 500.0, צעד: 0.001) | FLOAT | כן | 0.0 - 1000.0 |
| `sigma_min` | ערך ה-sigma המינימלי לדגימה (פרמטר מתקדם, ברירת מחדל: 0.03, צעד: 0.001) | FLOAT | כן | 0.0 - 1000.0 |
