# ModelSamplingContinuousV

گره ModelSamplingContinuousV رفتار نمونه‌برداری یک مدل را با اعمال نمونه‌برداری پیوسته V-prediction تنظیم می‌کند. این گره یک کپی از مدل ورودی ایجاد کرده و آن را با مقادیر سیگما بیشینه و کمینه سفارشی برای کنترل دقیق‌تر فرآیند نمونه‌برداری پیکربندی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل ورودی که باید با نمونه‌برداری پیوسته V-prediction اصلاح شود | MODEL | بله | - |
| `نمونه‌برداری` | روش نمونه‌برداری مورد استفاده؛ در حال حاضر V-prediction تنها گزینه موجود است (پیش‌فرض: `"v_prediction"`) | COMBO | بله | `"v_prediction"` |
| `سیگما بیشینه` | بیشینه مقدار سیگما برای نمونه‌برداری (پارامتر پیشرفته، پیش‌فرض: 500.0) | FLOAT | بله | 0.0 - 1000.0 |
| `سیگما کمینه` | کمینه مقدار سیگما برای نمونه‌برداری (پارامتر پیشرفته، پیش‌فرض: 0.03) | FLOAT | بله | 0.0 - 1000.0 |

|-------------|-------------|-----------|
| `model` | مدل اصلاح‌شده با اعمال نمونه‌برداری پیوسته V-prediction | MODEL |
