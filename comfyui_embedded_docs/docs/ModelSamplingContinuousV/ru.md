# Выборка модели Continuous V

Узел ModelSamplingContinuousV изменяет поведение модели при сэмплировании, применяя непрерывное сэмплирование с V-предсказанием. Он создает клон входной модели и настраивает его с пользовательскими минимальным и максимальным значениями сигмы для более точного контроля процесса сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Входная модель, которую необходимо изменить с помощью непрерывного V-предсказания | MODEL | Да | - |
| `выборка` | Применяемый метод сэмплирования; в настоящее время доступен только вариант V-предсказания (по умолчанию: `"v_prediction"`) | COMBO | Да | `"v_prediction"` |
| `sigma_max` | Максимальное значение сигмы для сэмплирования (дополнительный параметр, по умолчанию: 500.0) | FLOAT | Да | 0.0 - 1000.0 |
| `sigma_min` | Минимальное значение сигмы для сэмплирования (дополнительный параметр, по умолчанию: 0.03) | FLOAT | Да | 0.0 - 1000.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Измененная модель с примененным непрерывным V-предсказанием | MODEL |
