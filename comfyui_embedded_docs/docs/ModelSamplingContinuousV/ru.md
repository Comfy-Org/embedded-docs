# Выборка модели Continuous V

Узел `ModelSamplingContinuousV` изменяет поведение выборки модели, применяя параметры непрерывного V-предсказания. Он создает клон входной модели и настраивает его с помощью пользовательских параметров диапазона сигма для расширенного управления выборкой. Это позволяет пользователям точно настраивать процесс выборки, задавая конкретные минимальные и максимальные значения сигма.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Входная модель, которая будет изменена с помощью непрерывной выборки V-prediction | MODEL | Да | - |
| `sampling` | Применяемый метод выборки. В настоящее время поддерживается только V-prediction. | COMBO | Да | `"v_prediction"` |
| `sigma_max` | Максимальное значение сигма для выборки (по умолчанию: 500.0) | FLOAT | Да | 0.0 – 1000.0 (шаг 0.001) |
| `sigma_min` | Минимальное значение сигма для выборки (по умолчанию: 0.03) | FLOAT | Да | 0.0 – 1000.0 (шаг 0.001) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной непрерывной выборкой V-prediction | MODEL |
