# Batch Cameras

Объединяет камеры и орбиты камер в один список камер в порядке входов. Render Mesh и Render Splat рендерят по одному изображению для каждой камеры из списка — именно так создаётся многовидовой рендер.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `cameras` | Расширяемый слот для камер из Create Camera Info, Create Camera Orbit или вьюера. Список камер учитывается как все камеры в нём. | AUTOGROW | Да | от 1 до 50 камер |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `camera_info` | Один список камер, содержащий все входные камеры, в порядке входов. | LOAD3D_CAMERA |
