# Breeze Voice Localize

Создаёт копию голоса, который естественно говорит на другом языке, вместо чтения на иностранном языке с исходным акцентом. Копия сохраняется в вашей учётной записи и возвращается вместе с аудиопревью.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voice` | Голос Breeze для копирования. | BREEZE_VOICE | Да | - |
| `language` | Язык, на котором говорит новый голос. По умолчанию: `"English"`. | COMBO | Да | Доступно несколько вариантов |
| `seed` | Управляет тем, будет ли узел запущен повторно; результаты недетерминированы независимо от seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voice` | Локализованная копия голоса, имя которой формируется из исходного голоса и языка. | BREEZE_VOICE |
| `preview` | Аудиопревью локализованного голоса. | AUDIO |
