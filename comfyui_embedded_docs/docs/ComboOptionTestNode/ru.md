# ComboOptionTestNode

Этот узел принимает два выбранных значения из комбинированных списков и передаёт их без изменений напрямую на свои выходы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `combo` | Первое выбранное значение из набора трёх тестовых опций. | COMBO | Да | `"option1"`<br>`"option2"`<br>`"option3"` |
| `combo2` | Второе выбранное значение из другого набора трёх тестовых опций. | COMBO | Да | `"option4"`<br>`"option5"`<br>`"option6"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output_1` | Возвращает значение, выбранное в первом комбинированном списке (`combo`), без изменений. | COMBO |
| `output_2` | Возвращает значение, выбранное во втором комбинированном списке (`combo2`), без изменений. | COMBO |
