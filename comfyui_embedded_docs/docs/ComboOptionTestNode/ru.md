# ComboOptionTestNode

The ComboOptionTestNode — это логический узел, предназначенный для проверки и передачи значений из комбинированных списков. Он принимает два входа комбинированных списков, каждый с заданным набором опций, и выводит выбранные значения напрямую, без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `combo` | Первый выбор из набора из трёх тестовых опций. | COMBO | Да | `"option1"`<br>`"option2"`<br>`"option3"` |
| `combo2` | Второй выбор из другого набора из трёх тестовых опций. | COMBO | Да | `"option4"`<br>`"option5"`<br>`"option6"` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output_1` | Выводит значение, выбранное из первого комбинированного списка (`combo`). | COMBO |
| `output_2` | Выводит значение, выбранное из второго комбинированного списка (`combo2`). | COMBO |
