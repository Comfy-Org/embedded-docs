# StableCascade_Суперразрешение Controlnet

Узел StableCascade_SuperResolutionControlnet подготавливает входные данные для обработки суперразрешения Stable Cascade. Он принимает входное изображение и кодирует его с помощью VAE для создания входных данных ControlNet, а также формирует заполненные нулями латентные представления для этапа C и этапа B конвейера Stable Cascade.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Входное изображение для обработки суперразрешением. При кодировании используются только первые 3 цветовых канала (RGB) изображения. | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения. | VAE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `вход_controlnet` | Представление изображения, закодированное VAE, подходящее для входа ControlNet. | IMAGE |
| `этап_c` | Заглушка (заполненное нулями) латентное представление для этапа C обработки Stable Cascade, с 16 каналами и пространственными размерами, равными размеру входного изображения, делённому на 16. | LATENT |
| `этап_b` | Заглушка (заполненное нулями) латентное представление для этапа B обработки Stable Cascade, с 4 каналами и пространственными размерами, равными размеру входного изображения, делённому на 2. | LATENT |
