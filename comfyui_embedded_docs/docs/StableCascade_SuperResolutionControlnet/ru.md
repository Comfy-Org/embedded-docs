# StableCascade_Суперразрешение Controlnet

Этот узел входит в экспериментальную группу Stable Cascade. Он подготавливает входные данные для обработки сверхвысокого разрешения (super-resolution) Stable Cascade, кодируя входное изображение с помощью VAE для создания входных данных controlnet и генерируя пустые (заполненные нулями) латентные заполнители для stage C и stage B конвейера Stable Cascade.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображение` | Входное изображение, обрабатываемое для сверхвысокого разрешения. Для кодирования используются только первые 3 цветовых канала (RGB) изображения. | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения | VAE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `controlnet_input` | Представление изображения, закодированное с помощью VAE, подходящее для входных данных controlnet | IMAGE |
| `stage_c` | Пустое (заполненное нулями) латентное представление-заполнитель для stage C обработки Stable Cascade, с 16 каналами и размерами, основанными на размере входного изображения, делённом на 16 | LATENT |
| `stage_b` | Пустое (заполненное нулями) латентное представление-заполнитель для stage B обработки Stable Cascade, с 4 каналами и размерами, основанными на размере входного изображения, делённом на 2 | LATENT |
