# StableCascade_Суперразрешение Controlnet

Узел StableCascade_SuperResolutionControlnet подготавливает входные данные для обработки сверхразрешения Stable Cascade. Он принимает входное изображение и кодирует его с помощью VAE для создания входных данных controlnet, а также генерирует заполнители скрытых представлений для этапа C и этапа B конвейера Stable Cascade.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение для обработки сверхразрешения | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования входного изображения | VAE | Да | - |

Примечание: при кодировании с помощью VAE используются только первые три цветовых канала входного изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `controlnet_input` | Закодированное представление изображения, подходящее для входных данных controlnet | IMAGE |
| `stage_c` | Заполнитель скрытого представления для этапа C обработки Stable Cascade, размеры которого зависят от размера входного изображения, разделенного на 16 | LATENT |
| `stage_b` | Заполнитель скрытого представления для этапа B обработки Stable Cascade, размеры которого зависят от размера входного изображения, разделенного на 2 | LATENT |
