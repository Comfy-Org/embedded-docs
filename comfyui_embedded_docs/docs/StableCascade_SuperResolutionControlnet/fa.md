# StableCascade_SuperResolutionControlnet

گره StableCascade_SuperResolutionControlnet ورودی‌های پردازش فوق‌تفکیک Stable Cascade را آماده می‌کند. این گره یک تصویر ورودی دریافت کرده و با استفاده از یک VAE آن را برای ایجاد ورودی کنترل‌نت رمزگذاری می‌کند و همچنین نمایش‌های نهفتهٔ مکان‌نما را برای مرحله C و مرحله B خط لوله Stable Cascade تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `تصویر` | تصویر ورودی که برای فوق‌تفکیک پردازش می‌شود. تنها ۳ کانال رنگی اول (RGB) تصویر برای رمزگذاری استفاده می‌شود. | IMAGE | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر ورودی | VAE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `controlnet_input` | نمایش تصویر رمزگذاری‌شده با VAE که برای ورودی کنترل‌نت مناسب است | IMAGE |
| `stage_c` | نمایش نهفتهٔ مکان‌نما (با مقادیر صفر) برای مرحله C پردازش Stable Cascade، با ۱۶ کانال و ابعادی بر اساس اندازه تصویر ورودی تقسیم بر ۱۶ | LATENT |
| `stage_b` | نمایش نهفتهٔ مکان‌نما (با مقادیر صفر) برای مرحله B پردازش Stable Cascade، با ۴ کانال و ابعادی بر اساس اندازه تصویر ورودی تقسیم بر ۲ | LATENT |
