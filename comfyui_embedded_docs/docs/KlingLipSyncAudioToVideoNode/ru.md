# Kling синхронизация губ в видео с аудио

Узел Kling Lip Sync Audio to Video синхронизирует движения губ в видеофайле с аудиосодержимым аудиофайла. Этот узел анализирует голосовые паттерны в аудио и корректирует мимику в видео, чтобы создать реалистичную синхронизацию губ. Для процесса требуются как видео, содержащее отчётливо различимое лицо, так и аудиофайл с чётко различимым вокалом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Видеофайл, содержащий лицо, для которого требуется синхронизация губ | VIDEO | Да | - |
| `аудио` | Аудиофайл, содержащий вокал для синхронизации с видео | AUDIO | Да | - |
| `язык голоса` | Язык голоса в аудиофайле (по умолчанию: "en") | COMBO | Да | `"en"`<br>`"zh"`<br>`"es"`<br>`"fr"`<br>`"de"`<br>`"it"`<br>`"pt"`<br>`"pl"`<br>`"tr"`<br>`"ru"`<br>`"nl"`<br>`"cs"`<br>`"ar"`<br>`"ja"`<br>`"hu"`<br>`"ko"` |

**Важные ограничения:**

- Размер аудиофайла не должен превышать 5 МБ
- Размер видеофайла не должен превышать 100 МБ
- Размеры видео должны быть от 720px до 1920px по высоте/ширине
- Длительность видео должна быть от 2 до 10 секунд
- Аудио должно содержать чётко различимый вокал
- Видео должно содержать отчётливо различимое лицо

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Обработанное видео с синхронизированными движениями губ | VIDEO |
| `video_id` | Уникальный идентификатор обработанного видео | STRING |
| `duration` | Длительность обработанного видео | STRING |
