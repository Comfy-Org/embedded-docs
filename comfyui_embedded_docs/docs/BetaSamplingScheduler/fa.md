# BetaSamplingScheduler

گره BetaSamplingScheduler دنباله‌ای از سطوح نویز (سیگماها) ایجاد می‌کند که نحوه حذف نویز را در طول فرآیند نمونه‌برداری در تولید تصویر کنترل می‌کنند. این گره از الگوریتم زمان‌بندی بتا استفاده می‌کند و تنظیمات `alpha` و `beta` شکل برنامه نویز را تنظیم می‌کنند. سیگماهای تولید شده به یک نمونه‌بردار منتقل می‌شوند تا فرآیند نویززدایی را هدایت کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل مورد استفاده برای نمونه‌برداری، که شیء نمونه‌برداری مدل را فراهم می‌کند. | MODEL | Yes | - |
| `steps` | تعداد گام‌های نمونه‌برداری برای تولید سیگماها (پیش‌فرض: 20). | INT | Yes | 1 تا 10000 |
| `alpha` | پارامتر Alpha برای زمان‌بندی بتا، کنترل‌کننده منحنی زمان‌بندی (پیش‌فرض: 0.6). پارامتر پیشرفته. | FLOAT | Yes | 0.0 تا 50.0 |
| `beta` | پارامتر Beta برای زمان‌بندی بتا، کنترل‌کننده منحنی زمان‌بندی (پیش‌فرض: 0.6). پارامتر پیشرفته. | FLOAT | Yes | 0.0 تا 50.0 |
