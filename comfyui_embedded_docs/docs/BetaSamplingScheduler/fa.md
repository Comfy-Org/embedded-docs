# BetaSamplingScheduler

گره BetaSamplingScheduler با استفاده از الگوریتم زمان‌بندی بتا، دنباله‌ای از سطوح نویز (سیگما) را برای فرآیند نمونه‌برداری تولید می‌کند. این گره یک مدل و پارامترهای پیکربندی را دریافت می‌کند تا زمان‌بندی نویز سفارشی‌ای ایجاد کند که فرآیند نویززدایی را در طول تولید تصویر کنترل می‌کند. این زمان‌بند امکان تنظیم دقیق مسیر کاهش نویز را از طریق پارامترهای آلفا و بتا فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل مورد استفاده برای نمونه‌برداری که شیء نمونه‌برداری مدل را فراهم می‌کند | MODEL | بله | - |
| `گام‌ها` | تعداد مراحل نمونه‌برداری برای تولید سیگماها (پیش‌فرض: 20) | INT | بله | 1 تا 10000 |
| `آلفا` | پارامتر آلفا برای زمان‌بند بتا که منحنی زمان‌بندی را کنترل می‌کند (پیش‌فرض: 0.6، پارامتر پیشرفته) | FLOAT | بله | 0.0 تا 50.0 |
| `بتا` | پارامتر بتا برای زمان‌بند بتا که منحنی زمان‌بندی را کنترل می‌کند (پیش‌فرض: 0.6، پارامتر پیشرفته) | FLOAT | بله | 0.0 تا 50.0 |
