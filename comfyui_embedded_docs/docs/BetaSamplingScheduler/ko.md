# 베타 샘플링 스케줄러

BetaSamplingScheduler 노드는 이미지 생성 중 샘플링 프로세스에서 노이즈가 제거되는 방식을 제어하는 일련의 노이즈 수준(시그마)을 생성합니다. 베타 스케줄링 알고리즘을 사용하며, `alpha` 및 `beta` 설정으로 노이즈 스케줄의 형태를 조정합니다. 생성된 시그마는 샘플러에 전달되어 디노이징 프로세스를 안내합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 샘플링에 사용되는 모델로, 모델 샘플링 객체를 제공합니다. | MODEL | 예 | - |
| `steps` | 시그마를 생성할 샘플링 단계 수입니다 (기본값: 20). | INT | 예 | 1 to 10000 |
| `alpha` | 베타 스케줄러의 알파 매개변수로, 스케줄링 곡선을 제어합니다 (기본값: 0.6). 고급 매개변수입니다. | FLOAT | 예 | 0.0 to 50.0 |
| `beta` | 베타 스케줄러의 베타 매개변수로, 스케줄링 곡선을 제어합니다 (기본값: 0.6). 고급 매개변수입니다. | FLOAT | 예 | 0.0 to 50.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `SIGMAS` | 샘플링 프로세스에 사용되는 일련의 노이즈 수준(시그마)입니다. | SIGMAS |
