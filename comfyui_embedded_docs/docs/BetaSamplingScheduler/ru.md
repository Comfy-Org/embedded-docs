# Scheduler выборки Бета

Узел BetaSamplingScheduler генерирует последовательность уровней шума (сигм) для процесса сэмплирования с использованием бета-алгоритма планирования. Он принимает модель и параметры конфигурации для создания настраиваемого графика шума, который управляет процессом удаления шума при генерации изображений. Этот планировщик позволяет точно настраивать траекторию снижения шума с помощью параметров alpha и beta.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для сэмплирования, которая предоставляет объект сэмплирования модели | MODEL | Да | - |
| `шаги` | Количество шагов сэмплирования, для которых генерируются сигмы (по умолчанию: 20) | INT | Да | 1 до 10000 |
| `альфа` | Параметр alpha для бета-планировщика, управляющий кривой планирования (по умолчанию: 0.6, дополнительный параметр) | FLOAT | Да | 0.0 до 50.0 |
| `бета` | Параметр beta для бета-планировщика, управляющий кривой планирования (по умолчанию: 0.6, дополнительный параметр) | FLOAT | Да | 0.0 до 50.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SIGMAS` | Последовательность уровней шума (сигм), используемая в процессе сэмплирования | SIGMAS |
