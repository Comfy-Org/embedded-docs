# Scheduler выборки Бета

Узел BetaSamplingScheduler создаёт последовательность уровней шума (сигм), определяющую, как шум удаляется в процессе сэмплирования при генерации изображений. Он использует алгоритм бета-планирования, а параметры `alpha` и `beta` регулируют форму графика шума. Сгенерированные сигмы передаются сэмплеру для управления процессом удаления шума.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, используемая для сэмплирования; предоставляет объект сэмплирования модели. | MODEL | Да | - |
| `steps` | Количество шагов сэмплирования, для которых генерируются сигмы (по умолчанию: 20). | INT | Да | от 1 до 10000 |
| `alpha` | Параметр alpha для бета-планировщика, управляющий кривой планирования (по умолчанию: 0.6). Для опытных пользователей. | FLOAT | Да | от 0.0 до 50.0 |
| `beta` | Параметр beta для бета-планировщика, управляющий кривой планирования (по умолчанию: 0.6). Для опытных пользователей. | FLOAT | Да | от 0.0 до 50.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `SIGMAS` | Последовательность уровней шума (сигм), используемая в процессе сэмплирования. | SIGMAS |
