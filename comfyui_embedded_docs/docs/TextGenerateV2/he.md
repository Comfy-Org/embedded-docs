# Generate Text

צומת Generate Text משתמש במודל CLIP כדי לייצר טקסט מפרומפט. בניגוד לצומת הישן יותר עם צירוף יחיד, הוא מקבל ערימות מתרחבות של תמונות, סרטונים וקבצי אודיו כהקשר נוסף, כך שניתן להזין סט עזר שלם בצומת אחד. ניתן לשלוט באורך הפלט, האם נעשה שימוש בדגימה, והאם חלים תבנית הצ'אט ומצב החשיבה של המודל עצמו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה של הפרומפט ולייצור הטקסט. | CLIP | כן | - |
| `prompt` | הפרומפט המנחה את הייצור. תומך במספר שורות ובפרומפטים דינמיים (ברירת מחדל: מחרוזת ריקה). | STRING | כן | - |
| `images` | קבוצה מתרחבת של עד 50 תמונות, `image1` עד `image50`, המשמשת כהקשר חזותי עבור המודל. | AUTOGROW | לא | 0 עד 50 תמונות |
| `videos` | קבוצה מתרחבת של עד 100 קלטי וידאו, `video1` עד `video100`. כל סרטון הוא אצווה של פריימים הנחשבת לקצב של 24 FPS ומדוללת ל-1 FPS באופן פנימי. | AUTOGROW | לא | 0 עד 100 סרטונים |
| `audios` | קבוצה מתרחבת של עד 100 קלטי אודיו, `audio1` עד `audio100`, המשמשת כהקשר אודיו עבור המודל. | AUTOGROW | לא | 0 עד 100 קבצי אודיו |
| `max_length` | מספר הטוקנים המקסימלי לייצור (ברירת מחדל: 512). | INT | כן | 1 עד 32768 |
| `sampling_mode` | `on` דוגם את הפלט וחושף את פרמטרי הדגימה שלהלן. `off` מייצר באופן חמדני ללא דגימה אקראית. | DYNAMIC_COMBO | כן | `"on"`<br>`"off"` |
| `thinking` | הפעל מצב חשיבה אם המודל תומך בו (ברירת מחדל: False). | BOOLEAN | לא | True או False |
| `use_default_template` | השתמש בפרומפט המערכת המובנה או בתבנית הצ'אט אם למודל יש כזו (ברירת מחדל: True). פרמטר מתקדם. | BOOLEAN | לא | True או False |
| `mtp` | פענוח ספקולטיבי עם ראש חיזוי ריבוי טוקנים של נקודת השמירה. אין לו השפעה ללא משקולות MTP. `"auto"` מתאים את עומק ורוחב הטיוטה להתאמות הטוקנים הנצפות ולעלות הביצוע, `"2"` עד `"5"` מקבעים עומק טיוטה קבוע, ומצבי `tree` מקבעים גם רוחב וגם עומק. הפלט הנדגם נשאר מופץ כראוי אך שונה מפלט ללא MTP עבור אותו seed (ברירת מחדל: `"auto"`). | COMBO | לא | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"tree2s1"`<br>`"tree2s2"`<br>`"tree3s1"`<br>`"tree4s1m8"` |
| `system_prompt` | מחליף את פרומפט המערכת בתבנית הצ'אט של המודל. מתעלם כאשר לא משתמשים בתבנית ברירת המחדל. חברו קלט STRING במקום להקליד בצומת (ברירת מחדל: ריק). | STRING | לא | - |

### פרמטרי דגימה (כאשר `sampling_mode` הוא `"on"`)

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `temperature` | שולט באקראיות של הפלט. ערכים נמוכים יותר הופכים את הפלט ליותר צפוי, ערכים גבוהים יותר הופכים אותו ליותר יצירתי (ברירת מחדל: 0.7). | FLOAT | כן | 0.01 עד 2.0 |
| `top_k` | מגביל את מאגר הדגימה ל-K הטוקנים הבאים הסבירים ביותר. ערך 0 מבטל את המסנן (ברירת מחדל: 64). | INT | כן | 0 עד 1000 |
| `top_p` | דגימת גרעין: שומר על הקבוצה הקטנה ביותר של טוקנים סבירים ביותר שסכום ההסתברות שלהם מגיע לערך זה (ברירת מחדל: 0.95). | FLOAT | כן | 0.0 עד 1.0 |
| `min_p` | ההסתברות המינימלית שטוקן חייב להגיע אליה כדי להישאר במאגר (ברירת מחדל: 0.05). | FLOAT | כן | 0.0 עד 1.0 |
| `repetition_penalty` | מעניש טוקנים שכבר נוצרו כדי להפחית חזרתיות. ערך 1.0 אינו מחיל ענישה (ברירת מחדל: 1.05). | FLOAT | כן | 0.0 עד 5.0 |
| `presence_penalty` | מעניש טוקנים חדשים בהתאם לשאלה אם הופיעו בטקסט עד כה, ומעודד את המודל לעבור לנושאים חדשים (ברירת מחדל: 0.0). | FLOAT | כן | 0.0 עד 5.0 |
| `seed` | מספר המשמש לאתחול מחולל המספרים האקראיים לתוצאות משוחזרות (ברירת מחדל: 0). | INT | כן | 0 עד 18446744073709551615 |

**הערה:** פרמטרי הדגימה שלעיל קיימים רק כאשר `sampling_mode` הוא `"on"`. עם `"off"` הצומת מייצר טקסט ללא דגימה אקראית והפרמטרים מוסתרים.

**הערה:** כאשר הפלט של המודל פותח בלוק חשיבה עם `<think>`, הצומת מפצל אותו: `generated_text` נושא את התשובה ו-`thinking` נושא את החשיבה עם תג הפתיחה מוסר. אחרת `generated_text` נושא את כל מה שהמודל ייצר ו-`thinking` ריק. חשיבה שנחתכה על ידי `max_length` נשארת ב-`generated_text`.
