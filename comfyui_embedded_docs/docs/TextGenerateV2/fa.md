# Generate Text

گره Generate Text از یک مدل CLIP برای تولید متن از یک پرامپت استفاده می‌کند. برخلاف گره قدیمی تک‌پیوست، پشته‌های قابل‌افزایشی از تصویرها، ویدئوها و فایل‌های صوتی را به‌عنوان زمینه اضافی می‌پذیرد، بنابراین می‌توانید کل مجموعه مرجع را در یک گره وارد کنید. طول خروجی، استفاده یا عدم استفاده از نمونه‌برداری، و اعمال یا عدم اعمال قالب چت و حالت تفکر خود مدل را کنترل می‌کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکن‌سازی پرامپت و تولید متن استفاده می‌شود. | CLIP | بله | - |
| `prompt` | پرامپتی که تولید را هدایت می‌کند. از چند خط و پرامپت‌های پویا پشتیبانی می‌کند (پیش‌فرض: رشته خالی). | STRING | بله | - |
| `images` | گروه قابل‌افزایشی از حداکثر 50 تصویر، `image1` تا `image50`، که به‌عنوان زمینه بصری برای مدل استفاده می‌شود. | AUTOGROW | خیر | 0 تا 50 تصویر |
| `videos` | گروه قابل‌افزایشی از حداکثر 100 ورودی ویدئو، `video1` تا `video100`. هر ویدئو دسته‌ای از فریم‌هاست که فرض می‌شود 24 FPS است و به‌صورت داخلی با نرخ نرخ فریم مدل نمونه‌برداری می‌شود. | AUTOGROW | خیر | 0 تا 100 ویدئو |
| `audios` | گروه قابل‌افزایشی از حداکثر 100 ورودی صوتی، `audio1` تا `audio100`، که به‌عنوان زمینه صوتی برای مدل استفاده می‌شود. | AUTOGROW | خیر | 0 تا 100 فایل صوتی |
| `max_length` | حداکثر تعداد توکن‌های تولیدشده (پیش‌فرض: 512). | INT | بله | 1 تا 32768 |
| `sampling_mode` | `on` خروجی را نمونه‌برداری می‌کند و پارامترهای نمونه‌برداری زیر را نمایان می‌کند. `off` به‌صورت حریصانه و بدون نمونه‌برداری تصادفی تولید می‌کند. | DYNAMIC_COMBO | بله | `"on"`<br>`"off"` |
| `thinking` | اگر مدل پشتیبانی کند، در حالت تفکر کار می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True یا False |
| `use_default_template` | اگر مدل دارای پرامپت سیستمی یا قالب چت داخلی است، از آن استفاده می‌کند (پیش‌فرض: True). پارامتر پیشرفته. | BOOLEAN | خیر | True یا False |
| `mtp` | رمزگشایی گمانه‌زنانه با سر پیش‌بینی چندتوکنی چک‌پوینت. بدون وزن‌های MTP اثری ندارد. `"auto"` عمق و پهنای پیش‌نویس را با توجه به تطابق‌های مشاهده‌شده توکن و هزینه اجرا تطبیق می‌دهد، `"2"` تا `"5"` یک عمق پیش‌نویس ثابت را تثبیت می‌کنند، و حالت‌های `tree` هم پهن و هم عمق را تثبیت می‌کنند. خروجی نمونه‌برداری‌شده توزیع صحیح خود را حفظ می‌کند اما برای یک seed یکسان با خروجی غیر-MTP متفاوت است (پیش‌فرض: `"auto"`). | COMBO | خیر | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"tree2s1"`<br>`"tree2s2"`<br>`"tree3s1"`<br>`"tree4s1m8"` |
| `system_prompt` | پرامپت سیستمی را در قالب چت مدل جایگزین می‌کند. زمانی که از قالب پیش‌فرض استفاده نمی‌شود نادیده گرفته می‌شود. به‌جای تایپ در گره، یک ورودی STRING متصل کنید (پیش‌فرض: خالی). | STRING | خیر | - |

### پارامترهای نمونه‌برداری (زمانی که `sampling_mode` برابر `"on"` است)

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `temperature` | تصادفی بودن خروجی را کنترل می‌کند. مقادیر کمتر خروجی را قابل‌پیش‌بینی‌تر و مقادیر بیشتر آن را خلاقانه‌تر می‌کند (پیش‌فرض: 0.7). | FLOAT | بله | 0.01 تا 2.0 |
| `top_k` | استخر نمونه‌برداری را به K توکن بعدیِ محتمل‌تر محدود می‌کند. مقدار 0 فیلتر را غیرفعال می‌کند (پیش‌فرض: 64). | INT | بله | 0 تا 1000 |
| `top_p` | نمونه‌برداری هسته‌ای: کوچک‌ترین مجموعه از محتمل‌ترین توکن‌ها را نگه می‌دارد که احتمال تجمعی آن‌ها به این مقدار برسد (پیش‌فرض: 0.95). | FLOAT | بله | 0.0 تا 1.0 |
| `min_p` | حداقل احتمالی که یک توکن باید برای ماندن در استخر به آن برسد (پیش‌فرض: 0.05). | FLOAT | بله | 0.0 تا 1.0 |
| `repetition_penalty` | توکن‌هایی را که قبلاً تولید شده‌اند جریمه می‌کند تا تکرار کاهش یابد. مقدار 1.0 هیچ جریمه‌ای اعمال نمی‌کند (پیش‌فرض: 1.05). | FLOAT | بله | 0.0 تا 5.0 |
| `presence_penalty` | توکن‌های جدید را بر اساس اینکه تاکنون در متن ظاهر شده‌اند یا نه جریمه می‌کند و مدل را به حرکت به موضوعات جدید تشویق می‌کند (پیش‌فرض: 0.0). | FLOAT | بله | 0.0 تا 5.0 |
| `seed` | عددی که برای مقداردهی اولیه مولد اعداد تصادفی جهت نتایج قابل‌تکرار استفاده می‌شود (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |

**توجه:** پارامترهای نمونه‌برداری بالا فقط زمانی وجود دارند که `sampling_mode` برابر `"on"` باشد. با `"off"` گره متن را بدون نمونه‌برداری تصادفی تولید می‌کند و پارامترها پنهان می‌شوند.

**توجه:** وقتی خروجی مدل یک بلوک استدلال را با `<think>` باز می‌کند، گره آن را تفکیک می‌کند: `generated_text` پاسخ را در خود دارد و `thinking` استدلال را با حذف تگ آغازین در خود دارد. در غیر این صورت، `generated_text` همه‌چیزهایی را که مدل تولید کرده است در خود دارد و `thinking` خالی است. استدلالی که با `max_length` قطع شده باشد در `generated_text` باقی می‌ماند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `generated_text` | متنی که مدل تولید کرده است، با جدا شدن هر بلوک استدلال به خروجی `thinking`. | STRING |
| `thinking` | بلوک استدلالی که مدل تولید کرده است، با حذف تگ آغازین `<think>`. زمانی خالی است که مدل هیچ بلوک استدلالی تولید نکرده باشد. | STRING |
