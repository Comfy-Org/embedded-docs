# Generate Text

Узел Generate Text использует модель CLIP для создания текста по запросу. В отличие от старого узла с одним вложением, он принимает расширяемые наборы изображений, видео и аудиофайлов в качестве дополнительного контекста, поэтому вы можете передать целый набор референсов в одном узле. Вы управляете длиной вывода, использованием сэмплирования, а также применением собственного шаблона чата модели и режима размышления.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации запроса и генерации текста. | CLIP | Да | - |
| `prompt` | Запрос, направляющий генерацию. Поддерживает многострочный текст и динамические запросы (по умолчанию: пустая строка). | STRING | Да | - |
| `images` | Расширяемая группа до 50 изображений, от `image1` до `image50`, используемая как визуальный контекст для модели. | AUTOGROW | Нет | от 0 до 50 изображений |
| `videos` | Расширяемая группа до 100 видеовходов, от `video1` до `video100`. Каждое видео — это пакет кадров, предполагаемо с частотой 24 кадра/с, внутренне субдискретизированный до 1 кадра/с. | AUTOGROW | Нет | от 0 до 100 видео |
| `audios` | Расширяемая группа до 100 аудиовходов, от `audio1` до `audio100`, используемая как аудиоконтекст для модели. | AUTOGROW | Нет | от 0 до 100 аудиофайлов |
| `max_length` | Максимальное количество токенов для генерации (по умолчанию: 512). | INT | Да | от 1 до 32768 |
| `sampling_mode` | `on` включает сэмплирование вывода и отображает параметры сэмплирования ниже. `off` выполняет жадную генерацию без случайного сэмплирования. | DYNAMIC_COMBO | Да | `"on"`<br>`"off"` |
| `thinking` | Работать в режиме размышления, если модель его поддерживает (по умолчанию: False). | BOOLEAN | Нет | True или False |
| `use_default_template` | Использовать встроенный системный запрос или шаблон чата, если он есть у модели (по умолчанию: True). Дополнительный параметр. | BOOLEAN | Нет | True или False |
| `mtp` | Спекулятивное декодирование с использованием головы многотокенного предсказания из контрольной точки. Не имеет эффекта без весов MTP. `"auto"` адаптирует глубину и ширину черновика к наблюдаемым совпадениям токенов и стоимости выполнения, `"2"`–`"5"` задают фиксированную глубину черновика, а режимы `tree` фиксируют и ширину, и глубину. Сэмплированный вывод остается корректно распределенным, но отличается от вывода без MTP для того же seed (по умолчанию: `"auto"`). | COMBO | Нет | `"auto"`<br>`"off"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"tree2s1"`<br>`"tree2s2"`<br>`"tree3s1"`<br>`"tree4s1m8"` |
| `system_prompt` | Заменяет системный запрос в шаблоне чата модели. Игнорируется, если шаблон по умолчанию не используется. Подключите вход STRING вместо ввода в узле (по умолчанию: пусто). | STRING | Нет | - |

### Параметры сэмплирования (когда `sampling_mode` имеет значение `"on"`)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `temperature` | Управляет случайностью вывода. Меньшие значения делают вывод более предсказуемым, большие — более креативным (по умолчанию: 0.7). | FLOAT | Да | от 0.01 до 2.0 |
| `top_k` | Ограничивает пул сэмплирования K наиболее вероятными следующими токенами. Значение 0 отключает фильтр (по умолчанию: 64). | INT | Да | от 0 до 1000 |
| `top_p` | Ядерное сэмплирование: сохраняет наименьший набор наиболее вероятных токенов, совокупная вероятность которых достигает этого значения (по умолчанию: 0.95). | FLOAT | Да | от 0.0 до 1.0 |
| `min_p` | Минимальная вероятность, которую должен достичь токен, чтобы остаться в пуле (по умолчанию: 0.05). | FLOAT | Да | от 0.0 до 1.0 |
| `repetition_penalty` | Штрафует токены, которые уже были сгенерированы, чтобы уменьшить повторения. Значение 1.0 не применяет штраф (по умолчанию: 1.05). | FLOAT | Да | от 0.0 до 5.0 |
| `presence_penalty` | Штрафует новые токены в зависимости от того, появлялись ли они в тексте ранее, побуждая модель переходить к новым темам (по умолчанию: 0.0). | FLOAT | Да | от 0.0 до 5.0 |
| `seed` | Число, используемое для инициализации генератора случайных чисел для воспроизводимых результатов (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |

**Примечание:** Параметры сэмплирования выше существуют только когда `sampling_mode` имеет значение `"on"`. При `"off"` узел генерирует текст без случайного сэмплирования, и параметры скрыты.

**Примечание:** Когда вывод модели открывает блок рассуждений с помощью `<think>`, узел разделяет его: `generated_text` содержит ответ, а `thinking` содержит рассуждение с удаленным открывающим тегом. В противном случае `generated_text` содержит все, что сгенерировала модель, а `thinking` пуст. Рассуждение, обрезанное из-за `max_length`, остается в `generated_text`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `generated_text` | Текст, сгенерированный моделью, с любым блоком рассуждений, выделенным в выход `thinking`. | STRING |
| `thinking` | Блок рассуждений, созданный моделью, с удаленным открывающим тегом `<think>`. Пуст, если модель не создала блок рассуждений. | STRING |
