# شرطی‌سازی (تنظیم ناحیه با درصد برای ویدیو)

گره‌ی `ConditioningSetAreaPercentageVideo` داده‌های شرطی‌سازی (conditioning) را با تعریف ناحیه‌ای خاص و محدوده‌ی زمانی برای تولید ویدیو تغییر می‌دهد. این امکان را به شما می‌دهد که موقعیت، اندازه و مدت‌زمان ناحیه‌ای را که شرطی‌سازی روی آن اعمال می‌شود، با استفاده از مقادیر درصدی نسبت به ابعاد کلی تعیین کنید. این ویژگی برای متمرکز کردن تولید روی بخش‌های خاصی از یک توالی ویدیویی مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `conditioning` | داده‌های شرطی‌سازی که باید تغییر کنند | CONDITIONING | بله | - |
| `width` | عرض ناحیه به‌صورت درصدی از عرض کل (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |
| `height` | ارتفاع ناحیه به‌صورت درصدی از ارتفاع کل (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |
| `temporal` | مدت‌زمان زمانی ناحیه به‌صورت درصدی از طول کل ویدیو (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 1.0 |
| `x` | موقعیت شروع افقی ناحیه به‌صورت درصد (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `y` | موقعیت شروع عمودی ناحیه به‌صورت درصد (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `z` | موقعیت شروع زمانی ناحیه به‌صورت درصدی از خط زمانی ویدیو (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `strength` | ضریب قدرت اعمال‌شده بر شرطی‌سازی درون ناحیه‌ی تعریف‌شده (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 10.0 |

توجه: همه‌ی مقادیر اندازه و موقعیت، درصدهای نرمال‌شده (0.0 تا 1.0) نسبت به ابعاد کلی و خط زمانی ویدیو هستند.
