# УсловныйНаборПроцентПлощадиВидео

Узел ConditioningSetAreaPercentageVideo изменяет данные кондиционирования, определяя конкретную область и временной регион для генерации видео. Он использует процентные значения относительно общих размеров, чтобы задать положение, размер и длительность области, к которой применяется кондиционирование. Это полезно для фокусировки генерации на определённых частях видеопоследовательности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `условие` | Данные кондиционирования, которые будут изменены | CONDITIONING | Да | - |
| `ширина` | Ширина области в процентах от общей ширины (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `высота` | Высота области в процентах от общей высоты (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `временной` | Временная длительность области в процентах от общей длины видео (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `x` | Начальная горизонтальная позиция области в процентах (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `y` | Начальная вертикальная позиция области в процентах (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `z` | Начальная временная позиция области в процентах от временной шкалы видео (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `сила` | Множитель силы, применяемый к кондиционированию в пределах заданной области (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 (шаг 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `conditioning` | Изменённые данные кондиционирования с применёнными заданной областью и настройками силы | CONDITIONING |
