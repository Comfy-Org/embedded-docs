# УсловныйНаборПроцентПлощадиВидео

Узел `ConditioningSetAreaPercentageVideo` изменяет данные conditioning, определяя конкретную область и временной регион для генерации видео. Он позволяет задавать положение, размер и длительность области, где будет применяться conditioning, используя процентные значения относительно общих размеров. Это полезно для фокусировки генерации на определённых частях видеопоследовательности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | Данные conditioning, которые необходимо изменить | CONDITIONING | Да | - |
| `width` | Ширина области в процентах от общей ширины (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |
| `height` | Высота области в процентах от общей высоты (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |
| `temporal` | Временная длительность области в процентах от общей длины видео (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |
| `x` | Горизонтальная начальная позиция области в процентах (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `y` | Вертикальная начальная позиция области в процентах (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `z` | Временная начальная позиция области в процентах от временной шкалы видео (по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `strength` | Множитель силы, применяемый к conditioning в пределах заданной области (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 10.0 |

Примечание: все значения размера и положения являются нормализованными процентами (0.0–1.0) относительно общих размеров видео и временной шкалы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `conditioning` | Изменённые данные conditioning с применением заданной области и настроек силы | CONDITIONING |
