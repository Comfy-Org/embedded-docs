# 비디오 조건 (비율로 영역 설정)

ConditioningSetAreaPercentageVideo 노드는 비디오 생성을 위한 특정 영역과 시간적 범위를 정의하여 컨디셔닝 데이터를 수정합니다. 이 노드를 사용하면 전체 크기 대비 백분율 값을 사용하여 컨디셔닝이 적용될 영역의 위치, 크기 및 기간을 설정할 수 있습니다. 이를 통해 비디오 시퀀스의 특정 부분에 생성을 집중하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | 수정할 컨디셔닝 데이터 | CONDITIONING | 예 | - |
| `width` | 전체 너비 대비 영역의 너비를 백분율로 나타낸 값 (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |
| `height` | 전체 높이 대비 영역의 높이를 백분율로 나타낸 값 (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |
| `temporal` | 전체 비디오 길이 대비 영역의 시간적 지속 기간을 백분율로 나타낸 값 (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |
| `x` | 영역의 수평 시작 위치를 백분율로 나타낸 값 (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `y` | 영역의 수직 시작 위치를 백분율로 나타낸 값 (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `z` | 비디오 타임라인 대비 영역의 시간적 시작 위치를 백분율로 나타낸 값 (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `strength` | 정의된 영역 내에서 컨디셔닝에 적용되는 강도 배율 (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 |

참고: 모든 크기 및 위치 값은 전체 비디오 크기와 타임라인을 기준으로 하는 정규화된 백분율(0.0~1.0)입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `conditioning` | 지정된 영역 및 강도 설정이 적용된 수정된 컨디셔닝 데이터 | CONDITIONING |
