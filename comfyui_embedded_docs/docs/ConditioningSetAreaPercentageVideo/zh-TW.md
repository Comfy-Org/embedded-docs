# 條件設定（影片區域百分比）

ConditioningSetAreaPercentageVideo 節點透過定義影片生成中的特定區域與時間範圍來修改條件數據。它使用相對於整體尺寸的百分比值，來設定套用條件的區域位置、大小與持續時間。此功能有助於將生成過程聚焦在影片序列的特定部分。
