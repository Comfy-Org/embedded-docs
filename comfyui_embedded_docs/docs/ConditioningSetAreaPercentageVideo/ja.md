# ビデオの条件設定エリアのパーセンテージ

ConditioningSetAreaPercentageVideo ノードは、ビデオ生成用の特定の領域と時間的範囲を定義することで、conditioning データを変更します。全体の寸法に対するパーセンテージ値を使用して、conditioning が適用される領域の位置、サイズ、および期間を設定できます。これは、ビデオシーケンスの特定の部分に生成を集中させる場合に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | 変更対象のconditioningデータ | CONDITIONING | はい | - |
| `width` | 全体の幅に対する領域の幅のパーセンテージ（デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 |
| `height` | 全体の高さに対する領域の高さのパーセンテージ（デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 |
| `temporal` | ビデオ全体の長さに対する領域の時間的な長さのパーセンテージ（デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 |
| `x` | 領域の水平方向の開始位置のパーセンテージ（デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `y` | 領域の垂直方向の開始位置のパーセンテージ（デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `z` | ビデオのタイムラインに対する領域の時間的な開始位置のパーセンテージ（デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `strength` | 定義された領域内のconditioningに適用される強度の乗数（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 |

注: すべてのサイズと位置の値は、ビデオ全体の寸法とタイムラインに対する正規化されたパーセンテージ（0.0〜1.0）です。
