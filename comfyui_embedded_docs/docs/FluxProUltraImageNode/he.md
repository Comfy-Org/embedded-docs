# FluxProUltraImageNode

יוצר תמונות באמצעות Flux Pro 1.1 Ultra דרך API בהתבסס על פרומפט ורזולוציה. צומת זה מתחבר לשירות חיצוני כדי ליצור תמונות בהתאם לתיאור הטקסטואלי שלך ולממדים שצוינו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `prompt_upsampling` | האם לבצע upsampling על הפרומפט. אם פעיל, משנה אוטומטית את הפרומפט ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה תוצאה). (ברירת מחדל: False) | BOOLEAN | לא | - |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | לא | 0 to 18446744073709551615 |
| `aspect_ratio` | יחס גובה-רוחב של התמונה; חייב להיות בין 1:4 ל-4:1. (ברירת מחדל: "16:9") | STRING | לא | - |
| `raw` | כאשר True, יוצר תמונות פחות מעובדות ובעלות מראה טבעי יותר. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `image_prompt` | תמונת עזר אופציונלית להנחיית היצירה | IMAGE | לא | - |
| `image_prompt_strength` | מיזוג בין הפרומפט לפרומפט התמונה. (ברירת מחדל: 0.1) | FLOAT | לא | 0.0 to 1.0 |

**הערה:** הפרמטר `aspect_ratio` חייב להיות בין 1:4 ל-4:1. כאשר `image_prompt` מסופק, `image_prompt_strength` הופך לפעיל ושולט במידת ההשפעה של תמונת העזר על הפלט הסופי. אם `image_prompt` אינו מסופק, הפרמטר `prompt` נבדק כדי לוודא שהוא אינו ריק.
