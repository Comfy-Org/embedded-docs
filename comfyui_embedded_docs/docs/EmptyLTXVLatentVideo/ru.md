# Пустой LTXVLatentVideo

Узел EmptyLTXVLatentVideo создаёт пустой (заполненный нулями) латентный тензор видео, используя указанные вами ширину, высоту, длину и размер пакета. Он даёт пустую начальную точку для рабочих процессов генерации видео LTXV, при этом размеры латента автоматически сжимаются относительно запрошенного размера видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного тензора видео (по умолчанию: 768, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `высота` | Высота латентного тензора видео (по умолчанию: 512, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `длина` | Количество кадров в латентном видео (по умолчанию: 97, шаг: 8) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество латентных видео, генерируемых в одном пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |

Примечание: Латентное видео сжимается по сравнению с запрошенными размерами: пространственные размерности (ширина и высота) делятся на 32, а количество кадров (длина) делится на 8 и округляется вверх до ближайшего целого числа. Значения шага для ширины, высоты и длины помогают сохранять эти деления целочисленными.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный пустой латентный тензор с нулевыми значениями в указанных размерностях вместе с пространственным коэффициентом понижения масштаба, равным 32 | LATENT |
