# Пустой LTXVLatentVideo

Узел EmptyLTXVLatentVideo создает пустой латентный тензор для обработки видео. Он генерирует пустую стартовую точку с заданными шириной, высотой, длиной и размером пакета, которую можно использовать в качестве входных данных для рабочих процессов генерации видео. Узел создает латентное представление, заполненное нулями, чьи пространственные размеры в 32 раза меньше заданных ширины и высоты, а количество кадров сжато в 8 раз.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного видеотензора (по умолчанию: 768, шаг: 32) | INT | Да | 64 to MAX_RESOLUTION |
| `высота` | Высота латентного видеотензора (по умолчанию: 512, шаг: 32) | INT | Да | 64 to MAX_RESOLUTION |
| `длина` | Количество кадров в латентном видео (по умолчанию: 97, шаг: 8) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество латентных видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |

Примечание: Латентное видео сжимается относительно входных размеров: пространственные размеры (ширина и высота) делятся на 32, а количество кадров (длина) делится на 8 и округляется в большую сторону до ближайшего целого числа. Значения шага для ширины, высоты и длины помогают обеспечить целочисленность этих делений.

## Выходы

| Имя выхода | Описание | Тип данных |
