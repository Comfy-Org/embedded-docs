# Пустой LTXVLatentVideo

Узел EmptyLTXVLatentVideo создает пустой латентный тензор для генерации видео. Он создает нулевое латентное представление с заданными шириной, высотой, длиной и размером пакета, готовое к использованию в качестве отправной точки в видео-процессах LTXV. Латентное представление хранит видео в сжатой форме: пространственные размеры делятся на 32, а количество кадров уменьшается в 8 раз.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина латентного видео в пикселях (по умолчанию: 768, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `height` | Высота латентного видео в пикселях (по умолчанию: 512, шаг: 32) | INT | Да | от 64 до MAX_RESOLUTION |
| `length` | Количество кадров в латентном видео (по умолчанию: 97, шаг: 8) | INT | Да | от 1 до MAX_RESOLUTION |
| `batch_size` | Количество латентных видео для генерации в одном пакете (по умолчанию: 1) | INT | Нет | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный пустой латентный тензор, заполненный нулями. Латентное представление также содержит значение `downscale_ratio_spacial` равное 32, которое описывает пространственное уменьшение масштаба, примененное к ширине и высоте. | LATENT |
