# וידאו latent ריק של LTXV

הצומת EmptyLTXVLatentVideo יוצר טנזור וידאו סמוי (latent) ריק (מלא באפסים) באמצעות ה-`width`, ה-`height`, ה-`length` וגודל ה-batch (`batch_size`) שאתה מציין. הוא מספק נקודת התחלה ריקה לתהליכי יצירת וידאו LTXV, כאשר ממדי ה-latent נדחסים אוטומטית ביחס לגודל הווידאו המבוקש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `width` | הרוחב של טנזור הווידאו הסמוי (ברירת מחדל: 768, צעד: 32) | INT | כן | 64 עד MAX_RESOLUTION |
| `height` | הגובה של טנזור הווידאו הסמוי (ברירת מחדל: 512, צעד: 32) | INT | כן | 64 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו הסמוי (ברירת מחדל: 97, צעד: 8) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר סרטוני הווידאו הסמויים ליצירה באצווה (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |

הערה: הווידאו הסמוי נדחס בהשוואה לממדים המבוקשים: הממדים המרחביים (רוחב וגובה) מחולקים ב-32, ומספר הפריימים (`length`) מחולק ב-8 ומעוגל כלפי מעלה למספר השלם הקרוב. ערכי הצעד של `width`, `height` ו-`length` עוזרים לשמור על חלוקות אלה ללא שארית.
