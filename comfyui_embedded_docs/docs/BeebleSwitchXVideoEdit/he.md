# Beeble SwitchX Video Edit

ערוך סרטון עם Beeble SwitchX. צומת זה יכול להחליף כל דבר בסצנה (רקע, תאורה, תלבושת) תוך שמירה על הפיקסלים והתנועה של הסובייקט המקורי. ספק תמונת עזר ו/או הנחיית טקסט כדי לתאר את המראה החדש. מקסימום 240 פריימים, מקסימום כ-2.77 מגה-פיקסלים לפריים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | סרטון הקלט שיש לערוך. | VIDEO | כן | N/A |
| `prompt` | תיאור טקסטואלי של המראה החדש הרצוי לסצנה. | STRING | כן | N/A |
| `alpha_mode` | מצב מסכת האלפא. מצב "fill" אינו כולל מסכה נפרדת וממלא את כל הפריים. מצב "select" משתמש בתמונת פריים מפתח בודדת כדי להגדיר את האזור לעריכה. מצב "custom" משתמש בסרטון אלפא מלא כדי להגדיר את האזור לעריכה פריים אחר פריים. | COMBO | כן | `"fill"`<br>`"select"`<br>`"custom"` |
| `max_resolution` | הרזולוציה המקסימלית עבור סרטון הפלט (ברירת מחדל: "1080p"). | COMBO | כן | `"720p"`<br>`"1080p"` |
| `seed` | ערך seed לשחזוריות. שימוש באותו seed עם אותם קלטים יפיק את אותה תוצאה. | INT | כן | 0 עד 2147483647 |
| `reference_image` | תמונת עזר אופציונלית שמתארת את המראה החדש הרצוי לסצנה. | IMAGE | לא | N/A |

### פרטי מצב אלפא

הפרמטר `alpha_mode` קובע אילו חלקים בסרטון נערכים:

- **fill**: כל פריים בסרטון נערך. לא מיוצרת מסכת אלפא נפרדת.
- **select**: אתה מספק תמונת פריים מפתח בודדת שמגדירה את האזור לעריכה. הצומת ישתמש בכך כדי לקבוע אילו חלקים בסרטון לשנות.
- **custom**: אתה מספק סרטון אלפא מלא שמגדיר את האזור לעריכה פריים אחר פריים. זה נותן לך שליטה מדויקת על אילו חלקים בכל פריים נערכים.

בעת שימוש במצב `select`, עליך לספק את התמונה `alpha_keyframe`. בעת שימוש במצב `custom`, עליך לספק את הסרטון `alpha_mask`.
