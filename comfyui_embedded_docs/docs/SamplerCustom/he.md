# SamplerCustom

צומת SamplerCustom נועד לספק מנגנון דגימה גמיש וניתן להתאמה אישית עבור יישומים שונים. הוא מאפשר למשתמשים לבחור ולהגדיר אסטרטגיות דגימה שונות המותאמות לצרכים הספציפיים שלהם, ובכך משפר את יכולת ההסתגלות והיעילות של תהליך הדגימה.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `model` | סוג הקלט 'model' מציין את המודל שישמש לדגימה, וממלא תפקיד קריטי בקביעת התנהגות הדגימה והפלט. | `MODEL` |
| `add_noise` | סוג הקלט 'add_noise' מאפשר למשתמשים לציין האם יש להוסיף רעש לתהליך הדגימה, מה שמשפיע על המגוון והמאפיינים של הדגימות שנוצרות. | `BOOLEAN` |
| `noise_seed` | סוג הקלט 'noise_seed' מספק זרע ליצירת הרעש, ומבטיח יכולת שחזור ועקביות בתהליך הדגימה בעת הוספת רעש. | `INT` |
| `cfg` | סוג הקלט 'cfg' מגדיר את התצורה עבור תהליך הדגימה, ומאפשר כוונון עדין של פרמטרי הדגימה והתנהגותה. | `FLOAT` |
| `positive` | סוג הקלט 'positive' מייצג מידע התניה חיובי, ומכוון את תהליך הדגימה ליצירת דגימות התואמות מאפיינים חיוביים שצוינו. | `CONDITIONING` |
| `negative` | סוג הקלט 'negative' מייצג מידע התניה שלילי, ומסיט את תהליך הדגימה מיצירת דגימות שמציגות מאפיינים שליליים שצוינו. | `CONDITIONING` |
| `sampler` | סוג הקלט 'sampler' בוחר את אסטרטגיית הדגימה הספציפית שיש להשתמש בה, ומשפיע ישירות על אופי ואיכות הדגימות שנוצרות. | `SAMPLER` |
| `sigmas` | סוג הקלט 'sigmas' מגדיר את רמות הרעש שישמשו בתהליך הדגימה, ומשפיע על חקירת מרחב הדגימה ועל המגוון של הפלט. | `SIGMAS` |
| `latent_image` | סוג הקלט 'latent_image' מספק תמונת latent התחלתית לתהליך הדגימה, ומשמש כנקודת התחלה ליצירת דגימות. | `LATENT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | הפלט 'output' מייצג את התוצאה העיקרית של תהליך הדגימה, ומכיל את הדגימות שנוצרו. | `LATENT` |
| `denoised_output` | הפלט 'denoised_output' מייצג את הדגימות לאחר שהוחל עליהן תהליך הסרת רעש, מה שעשוי לשפר את הבהירות והאיכות של הדגימות שנוצרו. | `LATENT` |
