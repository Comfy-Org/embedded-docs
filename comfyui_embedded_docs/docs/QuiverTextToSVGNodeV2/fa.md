# Quiver Text to SVG

با Quiver AI یک گرافیک برداری مقیاس‌پذیر (SVG) از یک درخواست متنی تولید کنید. تصاویر مرجع و دستورالعمل‌های سبک اختیاری می‌توانند راهنمای تولید باشند.

انتخاب یک `model` پارامترهای مخصوص مدل را که در زیر فهرست شده‌اند نمایان می‌کند، و حداکثر تعداد تصاویر مرجع نیز به مدل انتخاب‌شده بستگی دارد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید SVG استفاده می‌شود. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | توضیح متنی خروجی SVG مورد نظر. باید حداقل یک نویسه داشته باشد (پیش‌فرض: خالی). | STRING | بله | هر متنی |
| `instructions` | راهنمایی سبک یا قالب‌بندی اضافی. پارامتر پیشرفتهٔ اختیاری (پیش‌فرض: خالی). | STRING | خیر | هر متنی |
| `reference_images` | جایگاه قابل‌افزایش: یک یا چند تصویر مرجع اختیاری (`ref_1`، `ref_2`، ...) را متصل کنید که راهنمای تولید هستند. حداکثر تعداد تصاویر به مدل انتخاب‌شده بستگی دارد. | IMAGE | خیر | حداکثر 14<br>حداکثر 4 |
| `width` | عرض بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هر دو `width` و `height` را تنظیم کنید؛ هرکدام را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `height` | ارتفاع بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هر دو `width` و `height` را تنظیم کنید؛ هرکدام را روی 0 بگذارید تا مدل انتخاب کند، که معمولاً بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: 0). | INT | بله | 0 تا 8192 |
| `seed` | مقدار seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به مقدار seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

### ورودی‌های مخصوص مدل

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌دهد و توکن‌های بیشتری مصرف می‌کند. فقط توسط مدل‌های `"arrow-2"` و `"arrow-2-telos"` استفاده می‌شود (پیش‌فرض: `"high"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | کنترل تصادفی‌بودن. مقادیر بالاتر تصادفی‌بودن را افزایش می‌دهد. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.0 تا 2.0 (گام 0.1) |
| `top_p` | پارامتر نمونه‌گیری هسته‌ای. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 1.0). | FLOAT | بله | 0.05 تا 1.0 (گام 0.05) |
| `presence_penalty` | جریمه حضور توکن. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: 0.0). | FLOAT | بله | -2.0 تا 2.0 (گام 0.1) |

**توجه:** حداکثر تعداد `reference_images` برای مدل‌های `"arrow-2"`، `"arrow-2-telos"` و `"arrow-1.1-max"` برابر 14 و برای `"arrow-1.1"` و `"arrow-preview"` برابر 4 است. `width` یا `height` را روی 0 بگذارید تا مدل اندازه بوم را انتخاب کند.
