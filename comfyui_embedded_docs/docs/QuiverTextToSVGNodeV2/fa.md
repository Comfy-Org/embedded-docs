# Quiver Text to SVG

با Quiver AI یک گرافیک برداری مقیاس‌پذیر (SVG) از یک پرامپت متنی تولید کنید. تصاویر مرجع و دستورالعمل‌های سبک اختیاری می‌توانند تولید را هدایت کنند.

با انتخاب یک `model` پارامترهای مخصوص مدل که در ادامه فهرست شده‌اند نمایش داده می‌شوند، و حداکثر تعداد تصاویر مرجع نیز به مدل انتخاب‌شده بستگی دارد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید SVG. | DYNAMIC_COMBO | بله | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | توضیح متنی خروجی SVG مطلوب. باید حداقل یک نویسه غیرفاصله داشته باشد (پیش‌فرض: خالی). | STRING | بله | هر متنی |
| `instructions` | راهنمایی اضافی سبک یا قالب‌بندی. پارامتر پیشرفته اختیاری (پیش‌فرض: خالی). | STRING | خیر | هر متنی |
| `reference_images` | اسلات قابل توسعه: یک یا چند تصویر مرجع اختیاری (`ref_1`، `ref_2`، ...) را متصل کنید که تولید را هدایت می‌کنند. حداکثر تعداد تصاویر به مدل انتخاب‌شده بستگی دارد. | IMAGE | خیر | حداکثر ۱۴<br>حداکثر ۴ |
| `width` | عرض بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هم `width` و هم `height` را تنظیم کنید؛ هر یک را در ۰ بگذارید تا مدل انتخاب کند، که معمولاً یک بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: ۰). | INT | بله | ۰ تا ۸۱۹۲ |
| `height` | ارتفاع بوم SVG خروجی (viewBox)، بر حسب واحدهای کاربر. برای کنترل اندازه و نسبت ابعاد خروجی، هم `width` و هم `height` را تنظیم کنید؛ هر یک را در ۰ بگذارید تا مدل انتخاب کند، که معمولاً یک بوم مربعی می‌دهد. پارامتر پیشرفته (پیش‌فرض: ۰). | INT | بله | ۰ تا ۸۱۹۲ |
| `seed` | مقدار seed برای تعیین این‌که گره باید دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از مقدار seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: ۴۲). | INT | بله | ۰ تا ۲۱۴۷۴۸۳۶۴۷ |

### ورودی‌های مخصوص مدل

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | میزان استدلالی که مدل پیش از ترسیم صرف می‌کند. سطوح بالاتر جزئیات را بهبود می‌بخشند و توکن‌های بیشتری مصرف می‌کنند. فقط توسط مدل‌های `"arrow-2"` و `"arrow-2-telos"` استفاده می‌شود (پیش‌فرض: `"high"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | کنترل تصادفی‌بودن. مقادیر بالاتر تصادفی‌بودن را افزایش می‌دهند. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: ۱.۰). | FLOAT | بله | ۰.۰ تا ۲.۰ (گام ۰.۱) |
| `top_p` | پارامتر نمونه‌گیری هسته‌ای (nucleus sampling). توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: ۱.۰). | FLOAT | بله | ۰.۰۵ تا ۱.۰ (گام ۰.۰۵) |
| `presence_penalty` | جریمه حضور توکن. توسط مدل `"arrow-2-telos"` استفاده نمی‌شود. پارامتر پیشرفته (پیش‌فرض: ۰.۰). | FLOAT | بله | -۲.۰ تا ۲.۰ (گام ۰.۱) |

**توجه:** حداکثر تعداد `reference_images` برای `"arrow-2"`، `"arrow-2-telos"` و `"arrow-1.1-max"` برابر ۱۴ است و برای `"arrow-1.1"` و `"arrow-preview"` برابر ۴ است. `width` یا `height` را در ۰ بگذارید تا مدل اندازه بوم را انتخاب کند.
