# Quiver Text to SVG

Quiver AI を使用して、テキストプロンプトからスケーラブルベクターグラフィック（SVG）を生成します。オプションの参照画像とスタイル指示で生成をガイドできます。

`model` を選択すると、以下に示すモデル固有のパラメータが表示され、参照画像の最大数も選択したモデルによって異なります。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | SVG 生成に使用するモデル。 | DYNAMIC_COMBO | はい | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | 生成したい SVG 出力のテキスト記述。少なくとも 1 つの空白以外の文字を含む必要があります（デフォルト: 空）。 | STRING | はい | 任意のテキスト |
| `instructions` | 追加のスタイルまたはフォーマットのガイダンス。オプションの詳細パラメータ（デフォルト: 空）。 | STRING | いいえ | 任意のテキスト |
| `reference_images` | 拡張可能なスロット: 生成をガイドする 1 つ以上のオプションの参照画像（`ref_1`、`ref_2`、...）を接続します。画像の最大数は、選択したモデルによって異なります。 | IMAGE | いいえ | 最大14<br>最大4 |
| `width` | 出力 SVG キャンバス（viewBox）の幅（ユーザー単位）。`width` と `height` の両方を設定して出力サイズとアスペクト比を制御します。どちらか一方を 0 のままにするとモデルが選択し、通常は正方形のキャンバスになります。詳細パラメータ（デフォルト: 0）。 | INT | はい | 0 〜 8192 |
| `height` | 出力 SVG キャンバス（viewBox）の高さ（ユーザー単位）。`width` と `height` の両方を設定して出力サイズとアスペクト比を制御します。どちらか一方を 0 のままにするとモデルが選択し、通常は正方形のキャンバスになります。詳細パラメータ（デフォルト: 0）。 | INT | はい | 0 〜 8192 |
| `seed` | ノードを再実行するかどうかを決定するためのシード。実際の結果はシード値に関係なく非決定的です。このパラメータには「生成後の制御」機能があります（デフォルト: 42）。 | INT | はい | 0 〜 2147483647 |

### モデル固有の入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | モデルが描画前に費やす推論の量。レベルが高いほど詳細が向上し、より多くのトークンを消費します。`"arrow-2"` および `"arrow-2-telos"` モデルのみで使用されます（デフォルト: `"high"`）。 | COMBO | はい | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | ランダム性の制御。値が高いほどランダム性が増します。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータ（デフォルト: 1.0）。 | FLOAT | はい | 0.0 〜 2.0 （ステップ 0.1） |
| `top_p` | Nucleus サンプリングパラメータ。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータ（デフォルト: 1.0）。 | FLOAT | はい | 0.05 〜 1.0 （ステップ 0.05） |
| `presence_penalty` | トークンの存在ペナルティ。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータ（デフォルト: 0.0）。 | FLOAT | はい | -2.0 〜 2.0 （ステップ 0.1） |

**注:** `reference_images` の最大数は、`"arrow-2"`、`"arrow-2-telos"`、`"arrow-1.1-max"` では 14 で、`"arrow-1.1"` と `"arrow-preview"` では 4 です。`width` または `height` を 0 のままにすると、モデルにキャンバスサイズを選択させます。
