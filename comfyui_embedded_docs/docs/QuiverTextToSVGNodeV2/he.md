# QuiverTextToSVGNodeV2

צור גרפיקת וקטור ניתנת להרחבה (SVG) מתוך הנחיית טקסט עם Quiver AI. תמונות עזר והוראות סגנון אופציונליות יכולות להנחות את היצירה.

בחירת `model` חושפת את הפרמטרים הספציפיים למודל המפורטים להלן, והמספר המרבי של תמונות עזר תלוי גם הוא במודל הנבחר.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש ליצירת SVG. | DYNAMIC_COMBO | כן | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | תיאור טקסטואלי של פלט ה-SVG הרצוי. חייב להכיל לפחות תו אחד (ברירת מחדל: ריק). | STRING | כן | כל טקסט |
| `instructions` | הנחיות נוספות לסגנון או לעיצוב. פרמטר מתקדם אופציונלי (ברירת מחדל: ריק). | STRING | לא | כל טקסט |
| `reference_images` | חריץ הניתן להרחבה: חבר תמונת עזר אופציונלית אחת או יותר (`ref_1`, `ref_2`, ...) שמנחות את היצירה. המספר המרבי של תמונות תלוי במודל הנבחר. | IMAGE | לא | עד 14<br>עד 4 |
| `width` | רוחב קנבס ה-SVG של הפלט (viewBox), ביחידות משתמש. הגדר גם את `width` וגם את `height` כדי לשלוט בגודל הפלט וביחס הגובה-רוחב; השאר כל אחד מהם ב-0 כדי לתת למודל לבחור, מה שלרוב נותן קנבס מרובע. פרמטר מתקדם (ברירת מחדל: 0). | INT | כן | 0 עד 8192 |
| `height` | גובה קנבס ה-SVG של הפלט (viewBox), ביחידות משתמש. הגדר גם את `width` וגם את `height` כדי לשלוט בגודל הפלט וביחס הגובה-רוחב; השאר כל אחד מהם ב-0 כדי לתת למודל לבחור, מה שלרוב נותן קנבס מרובע. פרמטר מתקדם (ברירת מחדל: 0). | INT | כן | 0 עד 8192 |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות בערך ה-seed. לפרמטר זה יש פונקציונליות של "שליטה לאחר יצירה" (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |

### קלטים ספציפיים למודל

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | כמה מאמץ חשיבה המודל משקיע לפני הציור. רמות גבוהות יותר משפרות את הפרטים ודורשות יותר טוקנים. בשימוש רק במודלים `"arrow-2"` ו-`"arrow-2-telos"` (ברירת מחדל: `"high"`). | COMBO | כן | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | בקרת אקראיות. ערכים גבוהים יותר מגבירים את האקראיות. לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 עד 2.0 (צעד 0.1) |
| `top_p` | פרמטר דגימת גרעין (nucleus sampling). לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 1.0). | FLOAT | כן | 0.05 עד 1.0 (צעד 0.05) |
| `presence_penalty` | קנס נוכחות טוקנים. לא בשימוש במודל `"arrow-2-telos"`. פרמטר מתקדם (ברירת מחדל: 0.0). | FLOAT | כן | -2.0 עד 2.0 (צעד 0.1) |

**הערה:** המספר המרבי של `reference_images` הוא 14 עבור `"arrow-2"`, `"arrow-2-telos"`, ו-`"arrow-1.1-max"`, ו-4 עבור `"arrow-1.1"` ו-`"arrow-preview"`. השאר את `width` או `height` ב-0 כדי לתת למודל לבחור את גודל הקנבס.
