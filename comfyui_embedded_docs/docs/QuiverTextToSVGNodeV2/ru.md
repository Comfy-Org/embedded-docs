# Quiver Text to SVG

Создайте масштабируемую векторную графику (SVG) из текстового запроса с помощью Quiver AI. Необязательные эталонные изображения и инструкции по стилю могут направлять генерацию.

При выборе `model` отображаются параметры, специфичные для модели, перечисленные ниже, а максимальное количество эталонных изображений также зависит от выбранной модели.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации SVG. | DYNAMIC_COMBO | Да | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | Текстовое описание желаемого выходного SVG. Должно содержать хотя бы один непробельный символ (по умолчанию: пусто). | STRING | Да | Любой текст |
| `instructions` | Дополнительные указания по стилю или форматированию. Необязательный расширенный параметр (по умолчанию: пусто). | STRING | Нет | Любой текст |
| `reference_images` | Расширяемый слот: подключите одно или несколько необязательных эталонных изображений (`ref_1`, `ref_2`, ...), которые направляют генерацию. Максимальное количество изображений зависит от выбранной модели. | IMAGE | Нет | До 14<br>До 4 |
| `width` | Ширина холста выходного SVG (viewBox) в пользовательских единицах. Установите и `width`, и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любое из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | 0 до 8192 |
| `height` | Высота холста выходного SVG (viewBox) в пользовательских единицах. Установите и `width`, и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любое из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | 0 до 8192 |
| `seed` | Сид для определения, должен ли узел выполняться повторно; фактические результаты недетерминированы независимо от значения сида. Этот параметр имеет функциональность «control after generate» (по умолчанию: 42). | INT | Да | 0 до 2147483647 |

### Входы, специфичные для модели

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | Сколько рассуждений модель затрачивает перед рисованием. Более высокие уровни улучшают детализацию и требуют больше токенов. Используется только моделями `"arrow-2"` и `"arrow-2-telos"` (по умолчанию: `"high"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | Управление случайностью. Более высокие значения увеличивают случайность. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 2.0 (шаг 0.1) |
| `top_p` | Параметр нуклеусной выборки. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | 0.05 до 1.0 (шаг 0.05) |
| `presence_penalty` | Штраф за присутствие токенов. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 0.0). | FLOAT | Да | -2.0 до 2.0 (шаг 0.1) |

**Примечание:** Максимальное количество `reference_images` — 14 для `"arrow-2"`, `"arrow-2-telos"` и `"arrow-1.1-max"`, и 4 для `"arrow-1.1"` и `"arrow-preview"`. Оставьте `width` или `height` равным 0, чтобы модель выбрала размер холста.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SVG` | Сгенерированный выходной SVG. | SVG |
