# Quiver Text to SVG

Создайте масштабируемую векторную графику (SVG) из текстовой подсказки с помощью Quiver AI. Необязательные эталонные изображения и инструкции по стилю могут направлять генерацию.

Выбор `model` раскрывает перечисленные ниже параметры, зависящие от модели, а максимальное количество эталонных изображений также зависит от выбранной модели.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации SVG. | DYNAMIC_COMBO | Да | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | Текстовое описание желаемого выходного SVG. Должен содержать хотя бы один символ (по умолчанию: пусто). | STRING | Да | Любой текст |
| `instructions` | Дополнительные указания по стилю или форматированию. Необязательный расширенный параметр (по умолчанию: пусто). | STRING | Нет | Любой текст |
| `reference_images` | Расширяемый слот: подключите одно или несколько необязательных эталонных изображений (`ref_1`, `ref_2`, ...), которые направляют генерацию. Максимальное количество изображений зависит от выбранной модели. | IMAGE | Нет | До 14<br>До 4 |
| `width` | Ширина выходного холста SVG (viewBox) в пользовательских единицах. Задайте и `width`, и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любое из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | от 0 до 8192 |
| `height` | Высота выходного холста SVG (viewBox) в пользовательских единицах. Задайте и `width`, и `height`, чтобы управлять размером и соотношением сторон выходного изображения; оставьте любое из них равным 0, чтобы модель выбрала сама, что обычно даёт квадратный холст. Расширенный параметр (по умолчанию: 0). | INT | Да | от 0 до 8192 |
| `seed` | `seed` определяет, следует ли повторно запускать узел; фактические результаты недетерминированы независимо от значения seed. Этот параметр имеет функциональность «управление после генерации» (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

### Входы, зависящие от модели

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | Сколько рассуждений модель выполняет перед отрисовкой. Более высокие уровни улучшают детализацию и требуют больше токенов. Используется только моделями `"arrow-2"` и `"arrow-2-telos"` (по умолчанию: `"high"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | Управление случайностью. Более высокие значения увеличивают случайность. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | от 0.0 до 2.0 (шаг 0.1) |
| `top_p` | Параметр нуклеусной выборки. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 1.0). | FLOAT | Да | от 0.05 до 1.0 (шаг 0.05) |
| `presence_penalty` | Штраф за присутствие токенов. Не используется моделью `"arrow-2-telos"`. Расширенный параметр (по умолчанию: 0.0). | FLOAT | Да | от -2.0 до 2.0 (шаг 0.1) |

**Примечание:** Максимальное количество `reference_images` составляет 14 для `"arrow-2"`, `"arrow-2-telos"` и `"arrow-1.1-max"`, а 4 для `"arrow-1.1"` и `"arrow-preview"`. Оставьте `width` или `height` равным 0, чтобы модель выбрала размер холста.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `SVG` | Сгенерированный вывод SVG. | SVG |
