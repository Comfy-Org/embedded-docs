# Quiver Text to SVG

أنشئ رسمًا متجهيًا قابلًا للتوسع (SVG) من موجز نصي باستخدام Quiver AI. يمكن لصور المرجع الاختيارية وتعليمات النمط أن توجّه عملية الإنشاء.

يؤدي تحديد `model` إلى إظهار المعاملات الخاصة بالنموذج المدرجة أدناه، كما يعتمد الحد الأقصى لعدد صور المرجع أيضًا على النموذج المحدد.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم لإنشاء SVG. | DYNAMIC_COMBO | نعم | `"arrow-2"`<br>`"arrow-2-telos"`<br>`"arrow-1.1"`<br>`"arrow-1.1-max"`<br>`"arrow-preview"` |
| `prompt` | وصف نصي لمخرجات SVG المطلوبة. يجب أن يحتوي على حرف واحد على الأقل (القيمة الافتراضية: فارغ). | STRING | نعم | أي نص |
| `instructions` | إرشادات إضافية للنمط أو التنسيق. معامل متقدم اختياري (القيمة الافتراضية: فارغ). | STRING | لا | أي نص |
| `reference_images` | خانة قابلة للتوسعة: صِل صورة مرجعية اختيارية واحدة أو أكثر (`ref_1`، `ref_2`، ...) توجّه عملية الإنشاء. يعتمد الحد الأقصى لعدد الصور على النموذج المحدد. | IMAGE | لا | حتى 14<br>حتى 4 |
| `width` | عرض لوحة SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم المخرجات ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، ما يمنح عادةً لوحة مربعة. معامل متقدم (القيمة الافتراضية: 0). | INT | نعم | 0 إلى 8192 |
| `height` | ارتفاع لوحة SVG الناتجة (viewBox)، بوحدات المستخدم. اضبط كلاً من `width` و`height` للتحكم في حجم المخرجات ونسبة العرض إلى الارتفاع؛ اترك أيًّا منهما عند 0 ليختار النموذج، ما يمنح عادةً لوحة مربعة. معامل متقدم (القيمة الافتراضية: 0). | INT | نعم | 0 إلى 8192 |
| `seed` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن قيمة البذرة. يمتلك هذا المعامل وظيفة "التحكم بعد التوليد" (القيمة الافتراضية: 42). | INT | نعم | 0 إلى 2147483647 |

### مدخلات خاصة بالنموذج

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | مقدار جهد الاستدلال الذي يبذله النموذج قبل الرسم. المستويات الأعلى تحسّن التفاصيل وتستهلك مزيدًا من التوكنات. يُستخدم فقط مع نموذجي `"arrow-2"` و`"arrow-2-telos"` (القيمة الافتراضية: `"high"`). | COMBO | نعم | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"` |
| `temperature` | التحكم في العشوائية. القيم الأعلى تزيد العشوائية. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (القيمة الافتراضية: 1.0). | FLOAT | نعم | 0.0 إلى 2.0 (الخطوة 0.1) |
| `top_p` | معامل أخذ العينات النووي. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (القيمة الافتراضية: 1.0). | FLOAT | نعم | 0.05 إلى 1.0 (الخطوة 0.05) |
| `presence_penalty` | عقوبة وجود التوكن. لا يُستخدم مع نموذج `"arrow-2-telos"`. معامل متقدم (القيمة الافتراضية: 0.0). | FLOAT | نعم | -2.0 إلى 2.0 (الخطوة 0.1) |

**ملاحظة:** الحد الأقصى لعدد `reference_images` هو 14 لـ `"arrow-2"` و`"arrow-2-telos"` و`"arrow-1.1-max"`، و4 لـ `"arrow-1.1"` و`"arrow-preview"`. اترك `width` أو `height` عند 0 ليختار النموذج حجم اللوحة.
