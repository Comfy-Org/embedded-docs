# Pixal3DMultiViewConditioning

צומת Pixal3D Multi-View Conditioning בונה נתוני התניה ממערך מצלמה במסלול קבוע: תצוגות front, left, back ו-right במרווח 90 מעלות זו מזו, המשמשות בדיוק כפי שהן ממוסגרות. חבר לפחות תצוגה מרובעת אחת של האובייקט והוא יכין התניה חיובית ושלילית תואמת עבור מודלי Pixal3D.

### הערות

- לפחות תצוגה אחת חייבת להיות מחוברת; הצומת מעלה שגיאה אם כל ארבעת קלטי התצוגה ריקים.
- התצוגה המחוברת הראשונה, לפי הסדר front, left, back, right, מטופלת כחזית, והמש ממוצב לתצוגה זו. אם התצוגה המחוברת הראשונה אינה `front`, נרשמת אזהרה שאומרת שהמש ימוצב כשתצוגה זו היא החזית שלו.
- התצוגות נקראות לפי הסדר front, left, back, right, וממוקמות על המסלול בזוויות האזימוט הקבועות שלהן ביחס לתצוגה המחוברת הראשונה.
- עבור תצוגות קלט עם ערוץ אלפא, האלפא מיושם מעל שחור. תצוגות שאינן בגודל 1024 x 1024 משתנות לגודל 1024 x 1024.
- גודל האצווה נלקח מהתצוגה המחוברת הראשונה. אם לתצוגות המחוברות יש גדלי אצווה שונים, הקטנות יותר ממוחזרות כדי להתאים.
