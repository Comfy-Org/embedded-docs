# Pixal3D 多視角條件化

Pixal3D Multi-View Conditioning 節點會從固定環繞攝影機裝置建構條件資料：前、左、後、右視角彼此間隔 90 度，並完全依照取景使用。連接至少一個物體的方形視角，它便會為 Pixal3D 模型準備相符的正向與負向條件。

### 備註

- 至少必須連接一個視角；若四個視角輸入皆為空，節點會引發錯誤。
- 第一個連接的視角（依 `front`、`left`、`back`、`right` 順序）會被視為正面，網格會以該視角擺姿。若第一個連接的視角不是 `front`，系統會記錄警告，指出網格將以該視角作為正面進行擺姿。
- 視角會依 `front`、`left`、`back`、`right` 的順序讀取，並以相對於第一個連接視角的固定方位角放置在環繞軌道上。
- 帶有 alpha 通道的輸入視角會將 alpha 套用於黑色背景上。非 1024 x 1024 的視角會調整大小為 1024 x 1024。
- 批次大小取自第一個連接的視角。若已連接的視角批次大小不同，較小者會循環重複以配合。
