# شرطی‌سازی چندنما در Pixal3D

گره Pixal3D Multi-View Conditioning داده‌های conditioning را از یک ریگ دوربین مداری ثابت می‌سازد: نماهای جلو، چپ، پشت و راست که با فاصله ۹۰ درجه از هم قرار گرفته‌اند و دقیقاً همان‌طور که قاب‌بندی شده‌اند استفاده می‌شوند. حداقل یک نمای مربعی از شیء را متصل کنید تا conditioning مثبت و منفی متناظر برای مدل‌های Pixal3D آماده شود.

### نکات

- حداقل یک نما باید متصل باشد؛ اگر هر چهار ورودی نما خالی باشند، گره خطا می‌دهد.
- اولین نمای متصل‌شده، به ترتیب جلو، چپ، پشت، راست، به‌عنوان جلو در نظر گرفته می‌شود و مش به سمت آن نما پوز می‌شود. اگر اولین نمای متصل‌شده `front` نباشد، هشداری ثبت می‌شود مبنی بر اینکه مش با آن نما به‌عنوان جلوی خود پوز خواهد شد.
- نماها به ترتیب جلو، چپ، پشت، راست خوانده می‌شوند و روی مدار با آزیموت‌های ثابت خود نسبت به اولین نمای متصل‌شده قرار می‌گیرند.
- نماهای ورودی دارای کانال آلفا، آلفا روی مشکی اعمال می‌شود. نماهایی که 1024 x 1024 نیستند به 1024 x 1024 تغییر اندازه داده می‌شوند.
- اندازه دسته (batch size) از اولین نمای متصل‌شده گرفته می‌شود. اگر نماهای متصل‌شده اندازه‌های دسته متفاوتی داشته باشند، نماهای با اندازه کوچک‌تر برای تطبیق به‌صورت چرخشی تکرار می‌شوند.
