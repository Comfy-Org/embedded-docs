# EmptyChromaRadianceLatentImage

عقدة EmptyChromaRadianceLatentImage تنشئ صورة كامنة فارغة بالأبعاد التي تحددها، لاستخدامها في سير عمل chroma radiance. وهي تنتج موترًا مملوءًا بالأصفار يعمل كنقطة انطلاق لعمليات الفضاء الكامن، مما يتيح لك تحديد العرض والارتفاع وحجم الدفعة للصورة الكامنة الفارغة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `العرض` | عرض الصورة الكامنة بالبكسل (الافتراضي: 1024) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الصورة الكامنة بالبكسل (الافتراضي: 1024) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `حجم_الدفعة` | عدد الصور الكامنة المطلوب توليدها في دفعة واحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |

ملاحظة: يتم تعريف `width` و`height` بخطوة مقدارها 16، لذا تُضبط القيم من مضاعفات 16.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `samples` | موتر الصورة الكامنة الفارغة المُولَّد والمملوء بالأصفار، بالشكل batch_size x 3 x height x width | LATENT |
