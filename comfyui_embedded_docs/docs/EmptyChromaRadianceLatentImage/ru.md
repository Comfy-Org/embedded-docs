# EmptyChromaRadianceLatentImage

Узел EmptyChromaRadianceLatentImage создаёт пустое латентное изображение с указанными вами размерами для использования в рабочих процессах chroma radiance. Он создаёт тензор, заполненный нулями, который служит отправной точкой для операций в латентном пространстве, позволяя вам задавать ширину, высоту и размер пакета пустого латентного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 до MAX_RESOLUTION |
| `высота` | Высота латентного изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 до MAX_RESOLUTION |
| `размер_пакета` | Количество латентных изображений для генерации в пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |

Примечание: `width` и `height` задаются с шагом 16, поэтому значения корректируются до кратных 16.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный тензор пустого латентного изображения, заполненный нулями, с формой batch_size x 3 x height x width | LATENT |
