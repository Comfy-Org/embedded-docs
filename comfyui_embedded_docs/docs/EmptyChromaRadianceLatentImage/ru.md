# EmptyChromaRadianceLatentImage

Узел EmptyChromaRadianceLatentImage создает пустое латентное изображение с заданными размерами для использования в рабочих процессах chroma radiance. Он генерирует тензор, заполненный нулями, который служит отправной точкой для операций в латентном пространстве. Узел позволяет задать ширину, высоту и размер пакета пустого латентного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина латентного изображения в пикселях (по умолчанию: 1024, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота латентного изображения в пикселях (по умолчанию: 1024, должно делиться на 16) | INT | Да | 16 to MAX_RESOLUTION |
| `размер_пакета` | Количество латентных изображений, генерируемых в одном пакете (по умолчанию: 1) | INT | Нет | 1 до 4096 |

Примечание: `width` и `height` задаются с шагом 16, поэтому они должны быть кратны 16.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный пустой тензор латентного изображения, заполненный нулями, с формой batch_size x 3 x height x width | LATENT |
