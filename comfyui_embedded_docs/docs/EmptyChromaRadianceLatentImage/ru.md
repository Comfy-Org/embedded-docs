# EmptyChromaRadianceLatentImage

Узел `EmptyChromaRadianceLatentImage` создаёт пустое латентное изображение с заданными размерами для использования в рабочих процессах chroma radiance. Он генерирует тензор, заполненный нулями (содержащий 3 цветовых канала), который служит отправной точкой для операций в латентном пространстве. Узел позволяет задать ширину, высоту и размер пакета пустого латентного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина латентного изображения в пикселях (по умолчанию: 1024, должно делиться на 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `height` | Высота латентного изображения в пикселях (по умолчанию: 1024, должно делиться на 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `batch_size` | Количество латентных изображений для генерации в одном пакете (по умолчанию: 1) | INT | Нет | от 1 до 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированный тензор пустого латентного изображения с заданными размерами, заполненный нулями | LATENT |
