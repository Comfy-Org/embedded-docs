# Просмотр 3D (расширенный)

Этот узел обеспечивает расширенный предпросмотр 3D-модели с выводом информации о камере и модели. Он предпросматривает файл 3D-модели без сохранения в выходной каталог ComfyUI, записывая модель во временный файл для отображения в интерфейсе. Данные модели, информация о модели, информация о камере и размеры области просмотра также передаются для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл 3D-модели из вышестоящего 3D-узла. | FILE3D | Да | GLB, GLTF, FBX, OBJ, STL, USDZ или любой поддерживаемый 3D-формат |
| `model_3d_info` | Необязательные метаданные с информацией о модели. | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние области просмотра, содержащее информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная конфигурация камеры для 3D-просмотра. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина предпросмотра в пикселях. | INT | Да | от 1 до 4096 (по умолчанию: 1024) |
| `height` | Высота предпросмотра в пикселях. | INT | Да | от 1 до 4096 (по умолчанию: 1024) |

Примечание. Если `camera_info` не подключено, узел использует значение `camera_info` из `viewport_state`. Если `model_3d_info` не подключено, узел использует значение `model_3d_info` из `viewport_state` или пустой список, если состояние области просмотра не содержит его.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Файл 3D-модели, переданный из входного параметра. | FILE3D |
| `model_3d_info` | Метаданные информации о модели, взятые из входного параметра или из состояния области просмотра. | LOAD3DMODELINFO |
| `camera_info` | Конфигурация камеры, взятая из входного параметра или из состояния области просмотра. | LOAD3DCAMERA |
| `width` | Ширина предпросмотра в пикселях. | INT |
| `height` | Высота предпросмотра в пикселях. | INT |
