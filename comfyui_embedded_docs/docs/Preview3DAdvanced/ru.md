# Просмотр 3D (расширенный)

Этот узел отображает предпросмотр 3D-модели в интерфейсе без сохранения файла в выходную директорию ComfyUI. Он сохраняет модель во временный файл и передаёт данные модели, информацию о модели, информацию о камере и размеры предпросмотра для дальнейшей обработки ниже по конвейеру.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `3D-модель` | Файл 3D-модели из вышестоящего 3D-узла. | FILE3D | Да | GLB, GLTF, FBX, OBJ, STL, USDZ или любой поддерживаемый 3D-формат |
| `model_3d_info` | Необязательные метаданные информации о модели. Расширенная опция. | LOAD3DMODELINFO | Нет | - |
| `состояние области просмотра` | Текущее состояние видового экрана, содержащее информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная конфигурация камеры для 3D-вида. Расширенная опция. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина предпросмотра в пикселях. По умолчанию: 1024. | INT | Да | от 1 до 4096 |
| `height` | Высота предпросмотра в пикселях. По умолчанию: 1024. | INT | Да | от 1 до 4096 |

Примечание: Если `camera_info` или `model_3d_info` не подключены, их значения берутся из `viewport_state` при наличии. Если `viewport_state` не содержит информации о модели, `model_3d_info` по умолчанию принимает пустой список. Если `viewport_state` не является словарём, он обрабатывается как пустой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Файл 3D-модели, переданный из входа. | FILE3D |
| `camera_info` | Метаданные информации о модели, либо из входа, либо из состояния видового экрана. | LOAD3DMODELINFO |
| `model_3d_info` | Конфигурация камеры, либо из входа, либо из состояния видового экрана. | LOAD3DCAMERA |
| `width` | Ширина предпросмотра в пикселях. | INT |
| `height` | Высота предпросмотра в пикселях. | INT |
