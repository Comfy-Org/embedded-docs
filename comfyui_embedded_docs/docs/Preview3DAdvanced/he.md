# Preview3DAdvanced

צומת זה מציג תצוגה מקדימה של מודל תלת-ממדי בממשק המשתמש מבלי לשמור את הקובץ בתיקיית הפלט של ComfyUI. הוא שומר את המודל בקובץ זמני ומעביר הלאה את נתוני המודל, מידע המודל, מידע המצלמה וממדי התצוגה המקדימה לעיבוד נוסף בהמשך.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | קובץ מודל תלת-ממדי מצומת תלת-ממד במעלה הזרם. | FILE3D | כן | GLB, GLTF, FBX, OBJ, STL, USDZ, או כל פורמט תלת-ממדי נתמך |
| `model_3d_info` | מיקום של כל מודל בסצנה: מיקום, סיבוב וקנה מידה (מרחב עולם עם Y כלפי מעלה). אופציונלי. אפשרות מתקדמת. | LOAD3DMODELINFO | לא | - |
| `viewport_state` | מצב חלון התצוגה הנוכחי המכיל מידע על המצלמה והמודל. | LOAD3D | כן | - |
| `camera_info` | מידע מצלמת חלון התצוגה: מיקום, מטרת מבט (look-at), זום וסוג. אופציונלי. אפשרות מתקדמת. | LOAD3DCAMERA | לא | - |
| `width` | רוחב רינדור של חלון התצוגה בפיקסלים. ברירת מחדל: 1024. | INT | כן | 1 עד 4096 |
| `height` | גובה רינדור של חלון התצוגה בפיקסלים. ברירת מחדל: 1024. | INT | כן | 1 עד 4096 |

הערה: כאשר `camera_info` או `model_3d_info` אינם מחוברים, הערכים שלהם נלקחים מ-`viewport_state` כאשר הם זמינים. אם `viewport_state` אינו מכיל מידע על מצלמה, `camera_info` הוא None. אם ל-`viewport_state` אין מידע על מודל, `model_3d_info` מוגדר כברירת מחדל לרשימה ריקה. אם `viewport_state` אינו מילון, הוא מטופל כריק.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_3d` | קובץ מודל תלת-ממדי (glb/obj/stl/וכו') מצומת תלת-ממד במעלה הזרם, מועבר ללא שינוי. | FILE3D |
| `model_3d_info` | מיקום של כל מודל בסצנה: מיקום, סיבוב וקנה מידה (מרחב עולם עם Y כלפי מעלה). משתמש בערך הקלט, או חוזר לערך המאוחסן ב-`viewport_state`. | LOAD3DMODELINFO |
| `camera_info` | מידע מצלמת חלון התצוגה: מיקום, מטרת מבט (look-at), זום וסוג. משתמש בערך הקלט, או חוזר לערך המאוחסן ב-`viewport_state`. | LOAD3DCAMERA |
| `width` | רוחב רינדור של חלון התצוגה בפיקסלים. | INT |
| `height` | גובה רינדור של חלון התצוגה בפיקסלים. | INT |
