# پیش‌نمایش سه‌بعدی (پیشرفته)

این گره پیش‌نمایش پیش‌رفته‌ای از مدل سه‌بعدی با خروجی اطلاعات دوربین و مدل ارائه می‌دهد. فایل مدل سه‌بعدی را بدون ذخیره‌سازی در پوشه خروجی ComfyUI پیش‌نمایش می‌کند و مدل را برای نمایش در رابط کاربری در یک فایل موقت می‌نویسد. داده‌های مدل، اطلاعات مدل، اطلاعات دوربین و ابعاد نمای دید نیز برای پردازش بیشتر در مراحل بعدی عبور داده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | فایل مدل سه‌بعدی از یک گره سه‌بعدی بالادستی. | FILE3D | بله | GLB، GLTF، FBX، OBJ، STL، USDZ، یا هر فرمت سه‌بعدی پشتیبانی‌شده |
| `model_3d_info` | فراداده اختیاری اطلاعات مدل. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای دید شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `camera_info` | پیکربندی اختیاری دوربین برای نمای سه‌بعدی. | LOAD3DCAMERA | خیر | - |
| `width` | عرض پیش‌نمایش به پیکسل. | INT | بله | 1 تا 4096 (پیش‌فرض: 1024) |
| `height` | ارتفاع پیش‌نمایش به پیکسل. | INT | بله | 1 تا 4096 (پیش‌فرض: 1024) |

نکته: وقتی `camera_info` متصل نباشد، گره از مقدار `camera_info` موجود در `viewport_state` استفاده می‌کند. وقتی `model_3d_info` متصل نباشد، گره از مقدار `model_3d_info` موجود در `viewport_state` استفاده می‌کند، یا اگر وضعیت نمای دید شامل آن نباشد، از یک لیست خالی استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل مدل سه‌بعدی عبور داده شده از ورودی. | FILE3D |
| `model_3d_info` | فراداده اطلاعات مدل، از ورودی یا از وضعیت نمای دید. | LOAD3DMODELINFO |
| `camera_info` | پیکربندی دوربین، از ورودی یا از وضعیت نمای دید. | LOAD3DCAMERA |
| `width` | عرض پیش‌نمایش به پیکسل. | INT |
| `height` | ارتفاع پیش‌نمایش به پیکسل. | INT |
