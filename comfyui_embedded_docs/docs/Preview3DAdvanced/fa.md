# پیش‌نمایش سه‌بعدی (پیشرفته)

این گره پیش‌نمایش مدل سه‌بعدی را در رابط کاربری نمایش می‌دهد بدون اینکه فایل را در پوشه خروجی ComfyUI ذخیره کند. مدل را در یک فایل موقت ذخیره کرده و داده مدل، اطلاعات مدل، اطلاعات دوربین و ابعاد پیش‌نمایش را برای پردازش بیشتر در مراحل بعدی عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل ۳بعدی` | فایل مدل سه‌بعدی از یک گره سه‌بعدی بالادستی. | FILE3D | بله | GLB، GLTF، FBX، OBJ، STL، USDZ، یا هر فرمت سه‌بعدی پشتیبانی‌شده |
| `اطلاعات مدل سه‌بعدی` | فراداده اطلاعات مدل اختیاری. گزینه پیشرفته. | LOAD3DMODELINFO | خیر | - |
| `وضعیت نمای دید` | وضعیت فعلی نمای دید شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `اطلاعات دوربین` | پیکربندی اختیاری دوربین برای نمای سه‌بعدی. گزینه پیشرفته. | LOAD3DCAMERA | خیر | - |
| `عرض` | عرض پیش‌نمایش بر حسب پیکسل. پیش‌فرض: ۱۰۲۴. | INT | بله | 1 تا 4096 |
| `ارتفاع` | ارتفاع پیش‌نمایش بر حسب پیکسل. پیش‌فرض: ۱۰۲۴. | INT | بله | 1 تا 4096 |

توجه: وقتی `camera_info` یا `model_3d_info` متصل نیستند، مقادیر آن‌ها در صورت وجود از `viewport_state` گرفته می‌شود. اگر `viewport_state` اطلاعات مدل نداشته باشد، `model_3d_info` به‌صورت پیش‌فرض یک لیست خالی در نظر گرفته می‌شود. اگر `viewport_state` یک دیکشنری نباشد، به‌عنوان خالی در نظر گرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی عبور داده‌شده از ورودی. | FILE3D |
| `اطلاعات دوربین` | فراداده اطلاعات مدل، یا از ورودی یا از وضعیت نمای دید. | LOAD3DMODELINFO |
| `اطلاعات مدل سه‌بعدی` | پیکربندی دوربین، یا از ورودی یا از وضعیت نمای دید. | LOAD3DCAMERA |
| `عرض` | عرض پیش‌نمایش بر حسب پیکسل. | INT |
| `ارتفاع` | ارتفاع پیش‌نمایش بر حسب پیکسل. | INT |
