# MediaPipeFaceMeshVisualize

## סקירה כללית

מצייר נקודות ציון של פנים וקווי חיבור (רשת פנים) מעל תמונת קלט. צומת זה משתמש בנתוני נקודות הציון שנוצרו על ידי צומת זיהוי פנים כדי להמחיש את מאפייני הפנים שזוהו, כגון עיניים, אף, פה ומתאר הפנים.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `face_landmarks` | נתוני נקודות הציון של הפנים מצומת זיהוי. | FACE_LANDMARKS | כן |  |
| `image` | התמונה שעליה יש לצייר את הרשת. אם לא מחובר, ישמש קנבס שחור בגודל זהה לתוצאת הזיהוי. | IMAGE | לא |  |
| `connections` | קובע אילו חלקים מרשת הפנים לצייר. `"all"` מצייר את הרשת המלאה (אליפסה, עיניים, גבות, שפתיים, קשתיות, אף). `"fill"` מצייר מצולע מלא של אליפסת הפנים (מסכת צללית). `"custom"` מאפשר להפעיל או לכבות כל מאפיין בנפרד. (ברירת מחדל: `"all"`) | COMBO | כן | `"all"`<br>`"fill"`<br>`"custom"` |
| `color` | הצבע של קווי הרשת והנקודות. (ברירת מחדל: `#00ff00`) | COLOR | כן |  |
| `thickness` | עובי קווי הרשת בפיקסלים. הגדרה ל-0 מנטרלת ציור קווים. (ברירת מחדל: 1) | INT | כן | 0 עד 8 |
| `point_size` | רדיוס נקודות הציון בפיקסלים. הגדרה ל-0 מנטרלת ציור נקודות. (ברירת מחדל: 2) | INT | כן | 0 עד 16 |

**הערה לגבי הפרמטר `connections`:** כאשר נבחר `"custom"`, יופיעו קלטים בוליאניים נוספים עבור כל מאפיין פנים (למשל, `face_oval`, `lips`, `left_eye`, `right_eye`, `left_eyebrow`, `right_eyebrow`, `left_iris`, `right_iris`, `nose`, `tesselation`). רק המאפיינים שתפעיל יצוירו.
