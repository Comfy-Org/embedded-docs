# پیش‌نمایش Splat

گره PreviewGaussianSplat به شما امکان میدهد یک فایل سهبعدی gaussian splat را مستقیماً در رابط ComfyUI پیشنمایش کنید، بدون اینکه آن را در دایرکتوری خروجی ذخیره کنید. این گره فایل را بهطور موقت در یک پوشه موقت نگه میدارد، آن را در یک پنجره پیشنمایش سهبعدی نمایش میدهد و دادههای مدل، اطلاعات دوربین و اندازه پیشنمایش را به گرههای دیگر منتقل میکند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | یک فایل سه‌بعدی gaussian splat. | FILE3D | بله | splat, ply, spz, ksplat |
| `model_3d_info` | اطلاعات فراداده اختیاری درباره مدل سه‌بعدی. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای دید سه‌بعدی، شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `camera_info` | اطلاعات اختیاری دوربین برای پیش‌نمایش. | LOAD3DCAMERA | خیر | - |
| `width` | عرض رندر پیش‌نمایش به پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع رندر پیش‌نمایش به پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

نکته: وقتی `camera_info` یا `model_3d_info` ارائه نشده‌اند، گره به‌جای آن از مقادیر متناظر در `viewport_state` استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل سه‌بعدی gaussian splat ورودی، بدون تغییر عبور داده شده است. | FILE3D |
| `model_3d_info` | اطلاعات فراداده درباره مدل سه‌بعدی، چه از ورودی و چه از وضعیت نمای دید. | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای پیش‌نمایش، چه از ورودی و چه از وضعیت نمای دید. | LOAD3DCAMERA |
| `width` | عرض رندر پیش‌نمایش. | INT |
| `height` | ارتفاع رندر پیش‌نمایش. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/PreviewGaussianSplat/fa.md)
