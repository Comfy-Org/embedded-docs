# پیش‌نمایش Splat

گره PreviewGaussianSplat یک فایل گاوسی اسپلت سه‌بعدی را در یک پنجره پیش‌نمایش نمایش می‌دهد بدون اینکه آن را در دایرکتوری خروجی ComfyUI ذخیره کند. این گره یک فایل مدل سه‌بعدی در قالب‌های مختلف گاوسی اسپلت را می‌پذیرد، یک کپی موقت برای پیش‌نمایش ذخیره می‌کند و داده‌های مدل را برای پردازش بیشتر در گردش کار عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | یک فایل سه‌بعدی گاوسی اسپلت. | FILE3D | بله | splat<br>ply<br>spz<br>ksplat |
| `model_3d_info` | اطلاعات فراداده اختیاری درباره مدل سه‌بعدی. وقتی متصل نباشد، گره از اطلاعات مدل در `viewport_state` استفاده می‌کند. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای سه‌بعدی، شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `camera_info` | اطلاعات دوربین اختیاری برای پیش‌نمایش. وقتی متصل نباشد، گره از اطلاعات دوربین در `viewport_state` استفاده می‌کند. | LOAD3DCAMERA | خیر | - |
| `width` | عرض رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

نکته: وقتی `camera_info` یا `model_3d_info` ارائه نشوند، گره به اطلاعات دوربین و مدل ذخیره‌شده در `viewport_state` بازمی‌گردد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل گاوسی اسپلت سه‌بعدی ورودی که بدون تغییر عبور داده شده است. | FILE3D |
| `model_3d_info` | اطلاعات فراداده درباره مدل سه‌بعدی؛ یا از ورودی دریافت شده یا از وضعیت نمای مشتق شده است. | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای پیش‌نمایش؛ یا از ورودی دریافت شده یا از وضعیت نمای مشتق شده است. | LOAD3DCAMERA |
| `width` | عرض رندر پیش‌نمایش. | INT |
| `height` | ارتفاع رندر پیش‌نمایش. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/PreviewGaussianSplat/fa.md)
