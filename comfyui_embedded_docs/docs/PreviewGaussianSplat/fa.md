# پیش‌نمایش Splat

گره PreviewGaussianSplat یک فایل اسپلات گاوسی سه‌بعدی را در پنجره پیش‌نمایش نمایش می‌دهد، بدون اینکه آن را در پوشه خروجی ComfyUI ذخیره کند. این گره یک فایل مدل سه‌بعدی در قالب‌های مختلف اسپلات گاوسی می‌پذیرد، یک نسخه موقت برای پیش‌نمایش ذخیره می‌کند، و داده مدل را برای پردازش‌های بعدی در گردش‌کار عبور می‌دهد. این گره به‌عنوان آزمایشی علامت‌گذاری شده است و به‌عنوان یک گره خروجی عمل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | یک فایل اسپلات گاوسی سه‌بعدی. | FILE3D | بله | splat<br>ply<br>spz<br>ksplat |
| `model_3d_info` | اطلاعات فراداده اختیاری درباره مدل سه‌بعدی. وقتی متصل نباشد، گره از اطلاعات مدل موجود در `viewport_state` استفاده می‌کند. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای سه‌بعدی، شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `camera_info` | اطلاعات اختیاری دوربین برای پیش‌نمایش. وقتی متصل نباشد، گره از اطلاعات دوربین موجود در `viewport_state` استفاده می‌کند. | LOAD3DCAMERA | خیر | - |
| `width` | عرض رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

توجه: وقتی `camera_info` یا `model_3d_info` ارائه نشوند، گره به اطلاعات دوربین و مدل ذخیره‌شده در `viewport_state` بازمی‌گردد. اگر `viewport_state` یک شیء وضعیت نمای معتبر نباشد، به‌صورت خالی در نظر گرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل اسپلات گاوسی سه‌بعدی ورودی، بدون تغییر عبور داده می‌شود. | FILE3D |
| `model_3d_info` | اطلاعات فراداده درباره مدل سه‌بعدی، چه از ورودی گرفته شده باشد و چه از وضعیت نما استخراج شده باشد. | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای پیش‌نمایش، چه از ورودی گرفته شده باشد و چه از وضعیت نما استخراج شده باشد. | LOAD3DCAMERA |
| `width` | عرض رندر پیش‌نمایش. | INT |
| `height` | ارتفاع رندر پیش‌نمایش. | INT |
