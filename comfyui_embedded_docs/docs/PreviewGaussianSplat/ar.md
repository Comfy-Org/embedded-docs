# معاينة Splat

تُتيح لك عقدة **PreviewGaussianSplat** معاينة ملف سبلات غاوسي ثلاثي الأبعاد مباشرةً في واجهة ComfyUI دون حفظه في مجلد الإخراج. تقوم بتخزين الملف مؤقتًا في مجلد مؤقت، وتعرضه في نافذة معاينة ثلاثية الأبعاد، وتمرر بيانات النموذج ومعلومات الكاميرا وحجم المعاينة إلى العقد الأخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|---------|
| `model_3d` | ملف سبلات غاوسي ثلاثي الأبعاد. | FILE3D | نعم | splat, ply, spz, ksplat |
| `model_3d_info` | معلومات وصفية اختيارية حول النموذج ثلاثي الأبعاد. | LOAD3DMODELINFO | لا | - |
| `viewport_state` | الحالة الحالية لعارض العرض ثلاثي الأبعاد، بما في ذلك معلومات الكاميرا والنموذج. | LOAD3D | نعم | - |
| `camera_info` | معلومات كاميرا اختيارية للمعاينة. | LOAD3DCAMERA | لا | - |
| `width` | عرض عرض المعاينة بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |
| `height` | ارتفاع عرض المعاينة بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |

ملاحظة: عندما لا يتم توفير `camera_info` أو `model_3d_info`، تستخدم العقدة القيم المقابلة من `viewport_state` بدلاً من ذلك.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_3d` | ملف سبلات غاوسي ثلاثي الأبعاد المُدخل، ويتم تمريره دون تغيير. | FILE3D |
| `model_3d_info` | معلومات وصفية حول النموذج ثلاثي الأبعاد، إما من المُدخل أو من حالة عارض العرض. | LOAD3DMODELINFO |
| `camera_info` | معلومات الكاميرا للمعاينة، إما من المُدخل أو من حالة عارض العرض. | LOAD3DCAMERA |
| `width` | عرض عرض المعاينة. | INT |
| `height` | ارتفاع عرض المعاينة. | INT |
