# معاينة Splat

```markdown
تعرض عقدة PreviewGaussianSplat ملف غاوسيان سبلات ثلاثي الأبعاد في نافذة معاينة دون حفظه في دليل مخرجات ComfyUI. تقبل ملف نموذج ثلاثي الأبعاد بصيغ غاوسيان سبلات المختلفة، وتحفظ نسخة مؤقتة للمعاينة، وتمرر بيانات النموذج للمعالجة اللاحقة في سير العمل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `نموذج_ثلاثي_الأبعاد` | ملف غاوسيان سبلات ثلاثي الأبعاد. | FILE3D | نعم | splat<br>ply<br>spz<br>ksplat |
| `معلومات_النموذج_ثلاثي_الأبعاد` | معلومات بيانات وصفية اختيارية حول النموذج ثلاثي الأبعاد. عند عدم توصيله، تستخدم العقدة معلومات النموذج من `viewport_state`. | LOAD3DMODELINFO | لا | - |
| `حالة_منفذ_العرض` | الحالة الحالية لمنفذ العرض ثلاثي الأبعاد، بما في ذلك معلومات الكاميرا والنموذج. | LOAD3D | نعم | - |
| `معلومات_الكاميرا` | معلومات كاميرا اختيارية للمعاينة. عند عدم توصيلها، تستخدم العقدة معلومات الكاميرا من `viewport_state`. | LOAD3DCAMERA | لا | - |
| `العرض` | عرض العرض المعاين بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |
| `الارتفاع` | ارتفاع العرض المعاين بالبكسل (الافتراضي: 1024). | INT | نعم | 1 إلى 4096 |

ملاحظة: عند عدم توفير `camera_info` أو `model_3d_info`، تلجأ العقدة إلى معلومات الكاميرا والنموذج المخزنة في `viewport_state`.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `نموذج_ثلاثي_الأبعاد` | ملف غاوسيان سبلات ثلاثي الأبعاد المُدخل، ويُمرَّر كما هو دون تغيير. | FILE3D |
| `معلومات_النموذج_ثلاثي_الأبعاد` | معلومات بيانات وصفية حول النموذج ثلاثي الأبعاد، سواء من المدخلات أو المستمدة من حالة منفذ العرض. | LOAD3DMODELINFO |
| `معلومات_الكاميرا` | معلومات كاميرا للمعاينة، سواء من المدخلات أو المستمدة من حالة منفذ العرض. | LOAD3DCAMERA |
| `العرض` | عرض العرض المعاين. | INT |
| `الارتفاع` | ارتفاع العرض المعاين. | INT |
```
