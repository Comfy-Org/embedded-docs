# Предпросмотр Splat

Узел PreviewGaussianSplat отображает 3D-файл гауссовых сплатов в окне предпросмотра, не сохраняя его в выходной каталог ComfyUI. Он принимает файл 3D-модели в различных форматах гауссовых сплатов, сохраняет временную копию для предпросмотра и передаёт данные модели дальше для обработки в рабочем процессе. Этот узел помечен как экспериментальный и работает как выходной узел.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-файл гауссовых сплатов. | FILE3D | Да | splat<br>ply<br>spz<br>ksplat |
| `model_3d_info` | Необязательные метаданные о 3D-модели. Если не подключено, узел использует информацию о модели из `viewport_state`. | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние 3D-окна просмотра, включая информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная информация о камере для предпросмотра. Если не подключено, узел использует информацию о камере из `viewport_state`. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |
| `height` | Высота рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |

Примечание: Если `camera_info` или `model_3d_info` не предоставлены, узел использует резервную информацию о камере и модели, хранящуюся в `viewport_state`. Если `viewport_state` не является допустимым объектом состояния окна просмотра, он считается пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Входной 3D-файл гауссовых сплатов, переданный без изменений. | FILE3D |
| `model_3d_info` | Метаданные о 3D-модели: либо из входных данных, либо полученные из состояния окна просмотра. | LOAD3DMODELINFO |
| `camera_info` | Информация о камере для предпросмотра: либо из входных данных, либо полученная из состояния окна просмотра. | LOAD3DCAMERA |
| `width` | Ширина рендера предпросмотра. | INT |
| `height` | Высота рендера предпросмотра. | INT |
