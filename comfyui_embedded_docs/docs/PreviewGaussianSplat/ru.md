# Предпросмотр Splat

Узел PreviewGaussianSplat позволяет предпросматривать 3D-файл гауссова сплата прямо в интерфейсе ComfyUI без сохранения его в выходной каталог. Он временно сохраняет файл во временной папке, отображает его в окне 3D-предпросмотра и передаёт данные модели, информацию о камере и размер предпросмотра другим узлам.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D-файл гауссова сплата. | FILE3D | Да | splat, ply, spz, ksplat |
| `model_3d_info` | Необязательные метаданные о 3D-модели. | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние 3D-вьюпорта, включая информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная информация о камере для предпросмотра. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 to 4096 |
| `height` | Высота рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 to 4096 |

Примечание: если `camera_info` или `model_3d_info` не заданы, узел использует соответствующие значения из `viewport_state`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Входной 3D-файл гауссова сплата, переданный без изменений. | FILE3D |
| `model_3d_info` | Метаданные о 3D-модели — либо из входных данных, либо из состояния вьюпорта. | LOAD3DMODELINFO |
| `camera_info` | Информация о камере для предпросмотра — либо из входных данных, либо из состояния вьюпорта. | LOAD3DCAMERA |
| `width` | Ширина рендера предпросмотра. | INT |
| `height` | Высота рендера предпросмотра. | INT |
