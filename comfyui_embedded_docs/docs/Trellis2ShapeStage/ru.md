# Trellis2ShapeStage

Этот узел настраивает первый проход генерации формы в конвейере Trellis2. Он принимает плотный структурный воксель, созданный VaeDecodeStructureTrellis2, извлекает разреженные координаты заполненных вокселей, создаёт пустой разреженный латент и присоединяет метаданные шага сэмплирования к кондиционированию, чтобы модель могла считывать их во время сэмплирования. Для второго прохода формы после повышения разрешения используйте Trellis2UpsampleStage, который объединяет каскад и настройку этапа второго прохода.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `positive` | Положительное кондиционирование, подготавливаемое для этапа формы. Это может быть стандартное кондиционирование Trellis2 или кондиционирование Pixal3D, предоставляющее набор проекционных признаков; когда проекционные признаки присутствуют, они вычисляются для выбранного этапа и присоединяются к выходному кондиционированию. | CONDITIONING | Да | Любое кондиционирование Trellis2 или Pixal3D |
| `negative` | Отрицательное кондиционирование, подготавливаемое для этапа формы. К нему присоединяются те же метаданные этапа формы, что и к положительному кондиционированию. | CONDITIONING | Да | Любое кондиционирование Trellis2 или Pixal3D |
| `voxel` | Плотный структурный воксель из VaeDecodeStructureTrellis2. | VOXEL | Да | Любая воксельная сетка; разрешение сетки (вокселей на ось) выбирает этап конвейера |

### Примечания

- Разрешение воксельной сетки выбирает этап конвейера: при разрешении 32 или ниже используется режим `shape_generation_512` с этапом `shape_512`; при разрешении больше 32 используется режим `shape_generation` с этапом `shape_1024`.
- Воксель должен содержать по крайней мере один заполненный воксель; пустой воксель вызывает ошибку. Индексы пакета, полученные из вокселя, должны быть неотрицательными и непрерывными.
- Когда положительное кондиционирование содержит `proj_feat_pack` (предоставляемый кондиционированием Pixal3D), проекционные признаки вычисляются для выбранного этапа, и модельный фрейм выходного латента устанавливается в `y_up`. В противном случае проекционные признаки не присоединяются, а модельный фрейм устанавливается в `z_up`.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `positive` | Положительное кондиционирование с присоединёнными метаданными этапа формы: режим генерации, разреженные координаты, количество координат для каждого элемента пакета и проекционные признаки, если исходное кондиционирование их предоставляет. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с теми же присоединёнными метаданными этапа формы. | CONDITIONING |
| `latent` | Пустой разреженный латент-тензор (форма: размер пакета, 32, количество токенов, 1) вместе с извлечёнными разреженными координатами, количеством координат для каждого элемента пакета, разрешением координат, маркером типа `trellis2` и ориентацией модельного фрейма. | LATENT |
