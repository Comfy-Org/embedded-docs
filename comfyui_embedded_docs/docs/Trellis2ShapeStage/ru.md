# Trellis2ShapeStage

Этот узел выполняет настройку первого прохода генерации формы в конвейере Trellis2. Он принимает плотный структурный воксель, полученный от VaeDecodeStructureTrellis2, извлекает разреженные координаты заполненных вокселей, создаёт пустой разреженный латентный тензор и прикрепляет метаданные сэмплирования к кондиционированию, чтобы модель могла считать их во время сэмплирования. Для второго прохода формы после апсемплинга используйте Trellis2UpsampleStage — этот узел объединяет каскад и настройку второго этапа.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Позитивное кондиционирование для подготовки к этапу формы. Может быть стандартным кондиционированием Trellis2 или кондиционированием Pixal3D, которое предоставляет пакет проекционных признаков; если проекционные признаки присутствуют, они вычисляются для выбранного этапа и прикрепляются к выходному кондиционированию. | CONDITIONING | Да | Любое кондиционирование Trellis2 или Pixal3D |
| `negative` | Негативное кондиционирование для подготовки к этапу формы. К нему прикрепляются те же метаданные этапа формы, что и к позитивному кондиционированию. | CONDITIONING | Да | Любое кондиционирование Trellis2 или Pixal3D |
| `voxel` | Плотный структурный воксель от VaeDecodeStructureTrellis2. | VOXEL | Да | Любая воксельная сетка; разрешение сетки (вокселей на ось) определяет этап конвейера |

### Примечания

- Разрешение воксельной сетки определяет этап конвейера: разрешение 32 или ниже использует режим `shape_generation_512` с этапом `shape_512`; разрешение выше 32 использует режим `shape_generation` с этапом `shape_1024`.
- Воксель должен содержать хотя бы один заполненный воксель; пустой воксель вызывает ошибку. Индексы пакетов, полученные из вокселя, должны быть неотрицательными и непрерывными.
- Если кондиционирование `positive` содержит `proj_feat_pack` (как в случае с кондиционированием Pixal3D), проекционные признаки вычисляются для выбранного этапа, а система координат выходного латентного тензора устанавливается в `y_up`. В противном случае проекционные признаки не прикрепляются, а система координат устанавливается в `z_up`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование с прикреплёнными метаданными этапа формы: режим генерации, разреженные координаты, количество координат для каждого пакета и проекционные признаки, если они предоставлены исходным кондиционированием. | CONDITIONING |
| `negative` | Негативное кондиционирование с теми же прикреплёнными метаданными этапа формы. | CONDITIONING |
| `latent` | Пустой разреженный латентный тензор (форма: размер пакета, 32, количество токенов, 1) вместе с извлечёнными разреженными координатами, количеством координат для каждого пакета, разрешением координат, маркером типа `trellis2` и ориентацией системы координат модели. | LATENT |
