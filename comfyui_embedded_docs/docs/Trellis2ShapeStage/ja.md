# Trellis2ShapeStage

このノードは、Trellis2パイプラインの最初のシェイプ生成サンプリングパスをセットアップします。`VaeDecodeStructureTrellis2` が生成した密な構造ボクセルを受け取り、占有ボクセルのスパース座標を抽出し、空のスパース潜在変数を作成して、サンプリング中にモデルが読み取れるようにサンプリングメタデータを条件付けに添付します。アップサンプリング後の2回目のシェイプパスには、カスケードと2回目のパスのステージ設定を組み合わせる `Trellis2UpsampleStage` を代わりに使用してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | シェイプステージ用に準備するポジティブな条件付けです。標準のTrellis2条件付け、または投影特徴パックを供給するPixal3D条件付けを指定できます。投影特徴が存在する場合、それらは選択されたステージ用に計算され、出力条件付けに添付されます。 | CONDITIONING | Yes | 任意のTrellis2またはPixal3D条件付け |
| `negative` | シェイプステージ用に準備するネガティブな条件付けです。ポジティブ条件付けと同じシェイプステージメタデータが、これにも添付されます。 | CONDITIONING | Yes | 任意のTrellis2またはPixal3D条件付け |
| `voxel` | `VaeDecodeStructureTrellis2` からの密な構造ボクセルです。 | VOXEL | Yes | 任意のボクセルグリッド。グリッド解像度（軸ごとのボクセル数）によってパイプラインステージが選択されます。 |

### 注記

- ボクセルグリッドの解像度によってパイプラインステージが選択されます。解像度が32以下の場合は `shape_generation_512` モードと `shape_512` ステージが使用され、32より大きい場合は `shape_generation` モードと `shape_1024` ステージが使用されます。
- ボクセルには少なくとも1つの占有ボクセルが含まれている必要があります。空のボクセルはエラーを発生させます。ボクセルから導出されるバッチインデックスは、非負かつ連続していなければなりません。
- `positive` 条件付けに `proj_feat_pack`（Pixal3D条件付けによって提供される）が含まれている場合、選択されたステージの投影特徴が計算され、出力潜在変数のモデルフレームは `y_up` に設定されます。それ以外の場合、投影特徴は添付されず、モデルフレームは `z_up` に設定されます。

| 出力名 | 説明 | データ型 |
