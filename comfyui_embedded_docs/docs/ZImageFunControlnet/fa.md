# ZImageFunControlnet

گره ZImageFunControlnet یک شبکه کنترل تخصصی را برای تأثیرگذاری بر فرآیند تولید یا ویرایش تصویر به کار می‌گیرد. این گره از یک مدل پایه، یک وصله مدل و یک VAE استفاده می‌کند و به شما امکان می‌دهد شدت اثر کنترل را تنظیم کنید. این گره می‌تواند با یک تصویر پایه، یک تصویر ترمیم و یک ماسک برای ویرایش‌های هدفمندتر کار کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل پایه‌ای که برای فرآیند تولید استفاده می‌شود. | MODEL | بله | - |
| `model_patch` | یک مدل وصله تخصصی که راهنمایی شبکه کنترل را اعمال می‌کند. | MODEL_PATCH | بله | - |
| `vae` | رمزگذار متغیر خودکار (VAE) که برای رمزگذاری و رمزگشایی تصاویر استفاده می‌شود. | VAE | بله | - |
| `strength` | شدت تأثیر شبکه کنترل. مقادیر مثبت اثر را اعمال می‌کنند، در حالی که مقادیر منفی می‌توانند آن را معکوس کنند (پیش‌فرض: 1.0). | FLOAT | بله | -10.0 to 10.0 |
| `image` | یک تصویر پایه اختیاری برای هدایت فرآیند تولید. | IMAGE | خیر | - |
| `inpaint_image` | تصویری اختیاری که به‌طور خاص برای ترمیم نواحی تعیین‌شده توسط یک ماسک استفاده می‌شود. | IMAGE | خیر | - |
| `mask` | ماسکی اختیاری که مشخص می‌کند کدام نواحی از تصویر باید ویرایش یا ترمیم شوند. | MASK | خیر | - |

**توجه:** پارامتر `inpaint_image` معمولاً همراه با یک `mask` برای مشخص کردن محتوای ترمیم استفاده می‌شود. رفتار گره ممکن است بسته به ورودی‌های اختیاری ارائه‌شده تغییر کند (به عنوان مثال، استفاده از `image` برای راهنمایی یا استفاده از `image`، `mask` و `inpaint_image` برای ترمیم).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `model` | مدلی با وصله شبکه کنترل اعمال‌شده، آماده استفاده در خط لوله نمونه‌گیری. | MODEL |
| `positive` | شرط‌گذاری مثبت که احتمالاً توسط ورودی‌های شبکه کنترل اصلاح شده است. | CONDITIONING |
| `negative` | شرط‌گذاری منفی که احتمالاً توسط ورودی‌های شبکه کنترل اصلاح شده است. | CONDITIONING |
