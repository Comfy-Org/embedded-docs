# ZImageFunControlnet

ZImageFunControlnet یک پچ شبکه کنترل را روی مدل پایه اعمال می‌کند تا بتواند فرآیند تولید یا ویرایش تصویر را هدایت کند. این گره یک مدل، یک پچ مدل و یک VAE را ترکیب می‌کند و به شما امکان می‌دهد میزان تأثیر اثر کنترل بر نتیجه را کنترل کنید. ورودی‌های اختیاری تصویر، تصویر inpainting و ماسک امکان ویرایش‌های هدفمندتر را فراهم می‌کنند. این گره با پچ‌های Z-Image ControlNet و پچ‌های Qwen Image 2.1 Fun ControlNet که از طریق گره Load Model Patch بارگذاری می‌شوند کار می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل پایه‌ای که در فرآیند تولید استفاده می‌شود. | MODEL | بله | - |
| `patch مدل` | یک مدل پچ تخصصی که راهنمایی شبکه کنترل را اعمال می‌کند. | MODEL_PATCH | بله | - |
| `vae` | خودرمزگذار متغیر (VAE) که برای رمزگذاری و رمزگشایی تصاویر استفاده می‌شود. | VAE | بله | - |
| `شدت` | شدت تأثیر شبکه کنترل. مقادیر مثبت اثر را اعمال می‌کنند، در حالی که مقادیر منفی می‌توانند آن را معکوس کنند (پیش‌فرض: 1.0). | FLOAT | بله | -10.0 تا 10.0 (گام 0.01) |
| `تصویر` | یک تصویر پایه اختیاری برای هدایت فرآیند تولید. | IMAGE | خیر | - |
| `تصویر inpaint` | یک تصویر اختیاری که به‌طور خاص برای inpainting نواحی تعریف‌شده توسط ماسک استفاده می‌شود. | IMAGE | خیر | - |
| `ماسک` | یک ماسک اختیاری که تعیین می‌کند کدام نواحی تصویر باید ویرایش یا inpainting شوند. | MASK | خیر | - |
| `start_percent` | نقطه‌ای در فرآیند نویززدایی، به‌صورت کسری از کل مراحل نمونه‌گیری، که شبکه کنترل در آن شروع به اثرگذاری می‌کند (پیش‌فرض: 0.0). | FLOAT | خیر | 0.0 تا 1.0 (گام 0.001) |
| `end_percent` | نقطه‌ای در فرآیند نویززدایی که شبکه کنترل در آن اثرگذاری را متوقف می‌کند (پیش‌فرض: 1.0). | FLOAT | خیر | 0.0 تا 1.0 (گام 0.001) |

**توجه:** پارامتر `inpaint_image` معمولاً همراه با یک `mask` برای تعیین محتوای inpainting استفاده می‌شود. رفتار گره ممکن است بر اساس ورودی‌های اختیاری ارائه‌شده تغییر کند (مثلاً استفاده از `image` برای راهنمایی یا استفاده از `image`، `mask` و `inpaint_image` برای inpainting). مقادیر `start_percent` و `end_percent` شبکه کنترل را به یک بازه از فرآیند نویززدایی محدود می‌کنند و خارج از آن بازه، مدل بدون پچ نمونه‌گیری می‌شود. اگر `strength` برابر 0 باشد، یا اگر هیچ‌یک از `image`، `inpaint_image` و `mask` متصل نباشد، گره مدل پایه را بدون تغییر برمی‌گرداند. برای پچ‌های Z-Image Control، ماسک ارائه‌شده پیش از استفاده معکوس می‌شود (1.0 - mask)، در حالی که پچ Qwen Image 2.1 Fun ControlNet از ماسک همان‌طور که داده شده استفاده می‌کند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
