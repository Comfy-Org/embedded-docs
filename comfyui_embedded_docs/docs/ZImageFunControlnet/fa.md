# ZImageFunControlnet

ZImageFunControlnet یک وصلهٔ شبکهٔ کنترل را روی یک مدل پایه اعمال می‌کند تا بتواند فرایند تولید یا ویرایش تصویر را هدایت کند. این گره یک مدل، یک وصلهٔ مدل و یک VAE را ترکیب می‌کند و به شما امکان می‌دهد میزان تأثیر اثر کنترل بر نتیجه را کنترل کنید. ورودی‌های اختیاری تصویر، تصویر ترمیم و ماسک امکان ویرایش‌های هدفمندتر را فراهم می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل پایه‌ای که برای فرایند تولید استفاده می‌شود. | MODEL | بله | - |
| `patch مدل` | یک وصلهٔ مدل تخصصی که هدایت شبکهٔ کنترل را اعمال می‌کند. | MODEL_PATCH | بله | - |
| `vae` | خودرمزگذار متغیر که برای رمزگذاری و رمزگشایی تصاویر استفاده می‌شود. | VAE | بله | - |
| `شدت` | قدرت نفوذ شبکهٔ کنترل. مقادیر مثبت اثر را اعمال می‌کنند، در حالی که مقادیر منفی می‌توانند آن را معکوس کنند (پیش‌فرض: 1.0). | FLOAT | بله | -10.0 تا 10.0 (گام 0.01) |
| `تصویر` | یک تصویر پایهٔ اختیاری برای هدایت فرایند تولید. | IMAGE | خیر | - |
| `تصویر inpaint` | یک تصویر اختیاری که به‌طور ویژه برای ترمیم نواحی تعریف‌شده توسط ماسک استفاده می‌شود. | IMAGE | خیر | - |
| `ماسک` | یک ماسک اختیاری که مشخص می‌کند کدام نواحی تصویر باید ویرایش یا ترمیم شوند. | MASK | خیر | - |

**توجه:** پارامتر `inpaint_image` معمولاً همراه با `mask` استفاده می‌شود تا محتوای موردنیاز برای ترمیم را مشخص کند. رفتار گره ممکن است بر اساس ورودی‌های اختیاری ارائه‌شده تغییر کند (مثلاً استفاده از `image` برای هدایت، یا استفاده از `image`، `mask` و `inpaint_image` برای ترمیم).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `model` | مدل با وصلهٔ شبکهٔ کنترل اعمال‌شده، آمادهٔ استفاده در خط لولهٔ نمونه‌گیری. | MODEL |
| `positive` | شرطی‌سازی مثبت، که ممکن است توسط ورودی‌های شبکهٔ کنترل تغییر کرده باشد. | CONDITIONING |
| `negative` | شرطی‌سازی منفی، که ممکن است توسط ورودی‌های شبکهٔ کنترل تغییر کرده باشد. | CONDITIONING |
