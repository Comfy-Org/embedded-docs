# ZImageFunControlnet

ZImageFunControlnet یک شبکه کنترلی تخصصی را به کار می‌گیرد تا بر فرآیند تولید یا ویرایش تصویر تأثیر بگذارد. این گره از یک مدل پایه، یک وصله‌ی مدل و یک VAE استفاده می‌کند و به شما امکان می‌دهد قدرت اثر کنترلی را تنظیم کنید. این گره می‌تواند با یک تصویر پایه، یک تصویر مخصوص نقاشی‌داخلی (inpainting) و یک ماسک برای ویرایش‌های هدفمندتر کار کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل پایه‌ای که برای فرآیند تولید استفاده می‌شود. | MODEL | بله | - |
| `patch مدل` | یک مدل وصله‌ای تخصصی که هدایت شبکه کنترلی را اعمال می‌کند. | MODEL_PATCH | بله | - |
| `vae` | خودرمزگذار تغییراتی (Variational Autoencoder) که برای رمزگذاری و رمزگشایی تصاویر استفاده می‌شود. | VAE | بله | - |
| `شدت` | قدرت تأثیر شبکه کنترلی. مقادیر مثبت اثر را اعمال می‌کنند و مقادیر منفی می‌توانند آن را معکوس کنند (پیش‌فرض: 1.0). | FLOAT | بله | 10.0- تا 10.0 |
| `تصویر` | یک تصویر پایه اختیاری برای هدایت فرآیند تولید. | IMAGE | خیر | - |
| `تصویر inpaint` | یک تصویر اختیاری که به‌طور خاص برای نقاشی‌داخلی در نواحی تعریف‌شده توسط ماسک استفاده می‌شود. | IMAGE | خیر | - |
| `ماسک` | یک ماسک اختیاری که مشخص می‌کند کدام نواحی از تصویر باید ویرایش یا نقاشی‌داخلی شوند. | MASK | خیر | - |

**توجه:** پارامتر `inpaint_image` معمولاً همراه با یک `mask` برای مشخص کردن محتوای نقاشی‌داخلی استفاده می‌شود. رفتار گره ممکن است بر اساس اینکه کدام ورودی‌های اختیاری ارائه شده‌اند تغییر کند (مثلاً استفاده از `image` برای هدایت یا استفاده از `image`، `mask` و `inpaint_image` برای نقاشی‌داخلی).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `model` | مدلی که وصله شبکه کنترلی روی آن اعمال شده و برای استفاده در خط لوله نمونه‌برداری آماده است. | MODEL |
| `positive` | شرطی‌سازی مثبت که احتمالاً توسط ورودی‌های شبکه کنترلی اصلاح شده است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی که احتمالاً توسط ورودی‌های شبکه کنترلی اصلاح شده است. | CONDITIONING |
