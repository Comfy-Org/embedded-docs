# ZImageFunControlnet

ZImageFunControlnet يطبّق رقعة شبكة تحكم على نموذج أساسي حتى يتمكن من توجيه عملية توليد الصور أو تحريرها. وهو يجمع بين نموذج، ورقعة نموذج، وVAE، ويتيح لك التحكم في مدى قوة تأثير التحكم على النتيجة. كما تسمح مدخلات الصورة الاختيارية وصورة الترميم الداخلي والقناع بإجراء تعديلات أكثر استهدافًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج الأساسي المستخدم في عملية التوليد. | MODEL | نعم | - |
| `model_patch` | نموذج رقعة متخصص يطبّق توجيه شبكة التحكم. | MODEL_PATCH | نعم | - |
| `vae` | المُرمِّز التلقائي التبايني المستخدم لتشفير الصور وفك تشفيرها. | VAE | نعم | - |
| `strength` | قوة تأثير شبكة التحكم. القيم الموجبة تطبّق التأثير، بينما يمكن للقيم السالبة عكسه (افتراضي: 1.0). | FLOAT | نعم | -10.0 إلى 10.0 (خطوة: 0.01) |
| `image` | صورة أساسية اختيارية لتوجيه عملية التوليد. | IMAGE | لا | - |
| `inpaint_image` | صورة اختيارية تُستخدم خصيصًا لترميم المناطق المحددة بواسطة قناع. | IMAGE | لا | - |
| `mask` | قناع اختياري يحدد المناطق التي ينبغي تحريرها أو ترميمها في الصورة. | MASK | لا | - |

**ملاحظة:** يُستخدم المعامل `inpaint_image` عادةً مع `mask` لتحديد المحتوى الخاص بالترميم الداخلي. قد يتغير سلوك العقدة بناءً على المدخلات الاختيارية المقدمة (مثل استخدام `image` للتوجيه، أو استخدام `image` و`mask` و`inpaint_image` للترميم الداخلي).

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج بعد تطبيق رقعة شبكة التحكم عليه، وجاهز للاستخدام في مسار أخذ العينات. | MODEL |
| `positive` | التكييف الإيجابي، مع احتمال تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
| `negative` | التكييف السلبي، مع احتمال تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
