# ZImageFunControlnet

عقدة ZImageFunControlnet تطبّق شبكة تحكم متخصصة للتأثير على عملية توليد الصور أو تحريرها. تستخدم نموذجًا أساسيًا، ونموذج تصحيح، وVAE، مما يتيح لك ضبط قوة تأثير التحكم. يمكن لهذه العقدة العمل مع صورة أساسية، وصورة ملء (inpainting)، وقناع لإجراء تعديلات أكثر استهدافًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج الأساسي المستخدم في عملية التوليد. | MODEL | نعم | - |
| `model_patch` | نموذج تصحيح متخصص يطبّق توجيه شبكة التحكم. | MODEL_PATCH | نعم | - |
| `vae` | التشفير التلقائي المتغير (Variational Autoencoder) المستخدم لتشفير وفك تشفير الصور. | VAE | نعم | - |
| `strength` | قوة تأثير شبكة التحكم. القيم الموجبة تطبّق التأثير، بينما القيم السالبة يمكن أن تعكسه (الافتراضي: 1.0). | FLOAT | نعم | -10.0 إلى 10.0 |
| `image` | صورة أساسية اختيارية لتوجيه عملية التوليد. | IMAGE | لا | - |
| `inpaint_image` | صورة اختيارية تُستخدم خصيصًا لملء المناطق المحددة بواسطة قناع. | IMAGE | لا | - |
| `mask` | قناع اختياري يحدد مناطق الصورة التي يجب تحريرها أو ملؤها. | MASK | لا | - |

**ملاحظة:** يُستخدم معامل `inpaint_image` عادةً بالتزامن مع `mask` لتحديد المحتوى المراد ملؤه. قد يتغير سلوك العقدة بناءً على المدخلات الاختيارية المقدمة (على سبيل المثال، استخدام `image` للتوجيه أو استخدام `image` و`mask` و`inpaint_image` للملء).

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج مع تطبيق تصحيح شبكة التحكم، جاهز للاستخدام في خط أنابيب أخذ العينات. | MODEL |
| `positive` | الشرط الموجب (positive conditioning)، وربما تم تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
| `negative` | الشرط السالب (negative conditioning)، وربما تم تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
