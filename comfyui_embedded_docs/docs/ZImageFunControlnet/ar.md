# ZImageFunControlnet

ZImageFunControlnet يطبّق رقعة شبكة تحكم على نموذج أساسي حتى يتمكن من توجيه عملية توليد الصور أو تحريرها. فهو يجمع بين نموذج، ورقعة نموذج، و VAE، ويتيح لك التحكم في مدى قوة تأثير التحكم في النتيجة. تسمح المدخلات الاختيارية للصورة، وصورة الترميم الداخلي، والقناع بإجراء تعديلات أكثر استهدافًا. تعمل العقدة مع رقع Z-Image ControlNet ومع رقع Qwen Image 2.1 Fun ControlNet المحمّلة عبر عقدة Load Model Patch.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج الأساسي المستخدم في عملية التوليد. | MODEL | نعم | - |
| `تصحيح النموذج` | نموذج رقعة متخصص يطبق توجيه شبكة التحكم. | MODEL_PATCH | نعم | - |
| `vae` | المرمّز التلقائي التبايني المستخدم لترميز وفك ترميز الصور. | VAE | نعم | - |
| `القوة` | قوة تأثير شبكة التحكم. القيم الموجبة تطبق التأثير، بينما يمكن للقيم السالبة عكسه (الافتراضي: 1.0). | FLOAT | نعم | -10.0 إلى 10.0 (خطوة 0.01) |
| `الصورة` | صورة أساسية اختيارية لتوجيه عملية التوليد. | IMAGE | لا | - |
| `صورة التلوين` | صورة اختيارية تُستخدم تحديدًا لترميم المناطق المحددة بواسطة قناع. | IMAGE | لا | - |
| `القناع` | قناع اختياري يحدد مناطق الصورة التي ينبغي تحريرها أو ترميمها. | MASK | لا | - |
| `start_percent` | النقطة في عملية إزالة الضوضاء، كنسبة من إجمالي خطوات أخذ العينات، التي تبدأ عندها شبكة التحكم في التأثير (الافتراضي: 0.0). | FLOAT | لا | 0.0 إلى 1.0 (خطوة 0.001) |
| `end_percent` | النقطة في عملية إزالة الضوضاء التي تتوقف عندها شبكة التحكم عن التأثير (الافتراضي: 1.0). | FLOAT | لا | 0.0 إلى 1.0 (خطوة 0.001) |

**ملاحظة:** يُستخدم المعامل `inpaint_image` عادةً مع `mask` لتحديد المحتوى المراد ترميمه. قد يتغير سلوك العقدة بناءً على المدخلات الاختيارية المزوّدة (على سبيل المثال، استخدام `image` للتوجيه أو استخدام `image` و`mask` و`inpaint_image` للترميم). تقيّد قيمتا `start_percent` و`end_percent` شبكة التحكم بنافذة من عملية إزالة الضوضاء، وخارج تلك النافذة يتم أخذ عينات من النموذج دون الرقعة. إذا كانت قيمة `strength` تساوي 0، أو إذا لم يتم توصيل أي من `image` و`inpaint_image` و`mask`، تُرجع العقدة النموذج الأساسي دون تغيير. بالنسبة لرقع Z-Image Control، يتم عكس القناع المزوّد (1.0 - mask) قبل الاستخدام، بينما تستخدم رقعة Qwen Image 2.1 Fun ControlNet القناع كما هو. تم تصنيف هذه العقدة على أنها تجريبية.
