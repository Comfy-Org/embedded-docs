# ZImageFunControlnet

ZImageFunControlnet يطبّق شبكة تحكم متخصصة للتأثير على عملية توليد الصور أو تحريرها. يستخدم نموذجًا أساسيًا، ونموذج ترقيع، وVAE، مما يتيح لك ضبط قوة تأثير التحكم. يمكن لهذه العقدة العمل مع صورة أساسية، وصورة تعبئة، وقناع لإجراء تعديلات أكثر دقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج الأساسي المستخدم في عملية التوليد. | MODEL | نعم | - |
| `تصحيح النموذج` | نموذج ترقيع متخصص يطبق توجيه شبكة التحكم. | MODEL_PATCH | نعم | - |
| `vae` | المشفر التلقائي المتغير المستخدم لتشفير الصور وفك تشفيرها. | VAE | نعم | - |
| `القوة` | قوة تأثير شبكة التحكم. القيم الموجبة تطبّق التأثير، بينما القيم السالبة يمكن أن تعكسه (الافتراضي: 1.0). | FLOAT | نعم | -10.0 إلى 10.0 |
| `الصورة` | صورة أساسية اختيارية لتوجيه عملية التوليد. | IMAGE | لا | - |
| `صورة التلوين` | صورة اختيارية تُستخدم خصيصًا لتعبئة المناطق المحددة بواسطة قناع. | IMAGE | لا | - |
| `القناع` | قناع اختياري يحدد مناطق الصورة التي يجب تحريرها أو تعبئتها. | MASK | لا | - |

**ملاحظة:** عادةً ما يُستخدم معامل `inpaint_image` بالتزامن مع `mask` لتحديد المحتوى المراد تعبئته. قد يتغير سلوك العقدة بناءً على المدخلات الاختيارية المقدمة (مثل استخدام `image` للتوجيه أو استخدام `image` و`mask` و`inpaint_image` للتعبئة).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `model` | النموذج مع تطبيق ترقيع شبكة التحكم، جاهز للاستخدام في خط أنابيب أخذ العينات. | MODEL |
| `positive` | الشرط الموجب، وربما تم تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
| `negative` | الشرط السالب، وربما تم تعديله بواسطة مدخلات شبكة التحكم. | CONDITIONING |
