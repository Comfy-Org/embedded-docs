# ZImageFunControlnet

ZImageFunControlnet 노드는 특수 제어 네트워크를 적용하여 이미지 생성 또는 편집 프로세스에 영향을 줍니다. 이 노드는 기본 모델, 모델 패치 및 VAE를 사용하며, 제어 효과의 강도를 조정할 수 있습니다. 또한 기본 이미지, 인페인팅 이미지 및 마스크와 함께 작동하여 보다 정밀한 편집을 수행할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 생성 프로세스에 사용되는 기본 모델입니다. | MODEL | 예 | - |
| `model_patch` | 제어 네트워크의 안내를 적용하는 특수 패치 모델입니다. | MODEL_PATCH | 예 | - |
| `vae` | 이미지 인코딩 및 디코딩에 사용되는 변분 오토인코더(VAE)입니다. | VAE | 예 | - |
| `strength` | 제어 네트워크의 영향 강도입니다. 양수 값은 효과를 적용하며, 음수 값은 효과를 반전시킬 수 있습니다 (기본값: 1.0). | FLOAT | 예 | -10.0 to 10.0 |
| `image` | 생성 프로세스를 안내하는 선택적 기본 이미지입니다. | IMAGE | 아니요 | - |
| `inpaint_image` | 마스크로 정의된 영역을 인페인팅하는 데 특별히 사용되는 선택적 이미지입니다. | IMAGE | 아니요 | - |
| `mask` | 이미지에서 편집하거나 인페인팅할 영역을 정의하는 선택적 마스크입니다. | MASK | 아니요 | - |

**참고:** `inpaint_image` 매개변수는 일반적으로 `mask`와 함께 사용되어 인페인팅할 내용을 지정합니다. 노드의 동작은 제공되는 선택적 입력에 따라 달라질 수 있습니다 (예: `image`를 사용한 안내, 또는 `image`, `mask`, `inpaint_image`를 사용한 인페인팅).

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `model` | 제어 네트워크 패치가 적용된 모델로, 샘플링 파이프라인에서 사용할 준비가 되었습니다. | MODEL |
| `positive` | 제어 네트워크 입력에 의해 수정될 수 있는 포지티브 컨디셔닝입니다. | CONDITIONING |
| `negative` | 제어 네트워크 입력에 의해 수정될 수 있는 네거티브 컨디셔닝입니다. | CONDITIONING |
