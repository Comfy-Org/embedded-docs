# ZImageFunControlnet

ZImageFunControlnet מחיל patch של רשת בקרה על מודל בסיס כדי שיוכל להנחות את תהליך יצירת התמונה או העריכה. הוא משלב מודל, patch של מודל ו-VAE, ומאפשר לשלוט בעוצמת ההשפעה של אפקט הבקרה על התוצאה. קלטים אופציונליים של תמונה, תמונת inpainting ומסכה מאפשרים עריכות ממוקדות יותר. הצומת עובד עם patches של Z-Image ControlNet ועם patches של Qwen Image 2.1 Fun ControlNet הנטענים דרך הצומת Load Model Patch.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל הבסיסי המשמש בתהליך היצירה. | MODEL | כן | - |
| `model_patch` | מודל patch ייעודי שמחיל את ההנחיה של רשת הבקרה. | MODEL_PATCH | כן | - |
| `vae` | ה-VAE (Variational Autoencoder) המשמש לקידוד ופענוח תמונות. | VAE | כן | - |
| `strength` | עוצמת ההשפעה של רשת הבקרה. ערכים חיוביים מחילים את האפקט, בעוד ערכים שליליים יכולים להפוך אותו (ברירת מחדל: 1.0). | FLOAT | כן | -10.0 עד 10.0 (צעד 0.01) |
| `image` | תמונת בסיס אופציונלית להנחיית תהליך היצירה. | IMAGE | לא | - |
| `inpaint_image` | תמונה אופציונלית המשמשת במיוחד לאזורי inpainting המוגדרים על ידי מסכה. | IMAGE | לא | - |
| `mask` | מסכה אופציונלית שמגדירה אילו אזורים בתמונה יש לערוך או לבצע בהם inpainting. | MASK | לא | - |
| `start_percent` | הנקודה בתהליך ה-denoising, כחלק יחסי מכלל צעדי הדגימה, שבה רשת הבקרה מתחילה להשפיע (ברירת מחדל: 0.0). | FLOAT | לא | 0.0 עד 1.0 (צעד 0.001) |
| `end_percent` | הנקודה בתהליך ה-denoising שבה רשת הבקרה מפסיקה להשפיע (ברירת מחדל: 1.0). | FLOAT | לא | 0.0 עד 1.0 (צעד 0.001) |

**הערה:** הפרמטר `inpaint_image` משמש בדרך כלל יחד עם `mask` כדי לציין את התוכן עבור inpainting. התנהגות הצומת עשויה להשתנות בהתאם לקלטים האופציונליים שסופקו (למשל, שימוש ב-`image` להנחיה או שימוש ב-`image`, `mask` ו-`inpaint_image` עבור inpainting). הערכים `start_percent` ו-`end_percent` מגבילים את רשת הבקרה לחלון בתהליך ה-denoising, ומחוץ לחלון זה המודל נדגם ללא ה-patch. אם `strength` הוא 0, או אם אף אחד מ-`image`, `inpaint_image` ו-`mask` אינו מחובר, הצומת מחזיר את מודל הבסיס ללא שינוי. עבור patches של Z-Image Control, מסכה שסופקה עוברת היפוך (1.0 - mask) לפני השימוש, בעוד ש-patch של Qwen Image 2.1 Fun ControlNet משתמש במסכה כפי שהיא. צומת זה מסומן כניסיוני.
