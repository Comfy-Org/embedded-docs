# ZImageFunControlnet

Узел ZImageFunControlnet применяет специализированную управляющую сеть для воздействия на процесс генерации или редактирования изображения. Он использует базовую модель, патч модели и VAE, позволяя регулировать силу управляющего воздействия. Этот узел может работать с базовым изображением, изображением для инпейнтинга и маской для более точечного редактирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая модель, используемая в процессе генерации. | MODEL | Да | - |
| `model_patch` | Специализированная патч-модель, которая применяет управление со стороны управляющей сети. | MODEL_PATCH | Да | - |
| `vae` | Вариационный автокодировщик, используемый для кодирования и декодирования изображений. | VAE | Да | - |
| `strength` | Сила влияния управляющей сети. Положительные значения применяют эффект, отрицательные — могут инвертировать его (по умолчанию: 1.0). | FLOAT | Да | -10.0 to 10.0 |
| `image` | Необязательное базовое изображение для управления процессом генерации. | IMAGE | Нет | - |
| `inpaint_image` | Необязательное изображение, используемое специально для инпейнтинга областей, заданных маской. | IMAGE | Нет | - |
| `mask` | Необязательная маска, определяющая, какие области изображения следует редактировать или заполнять с помощью инпейнтинга. | MASK | Нет | - |

**Примечание:** Параметр `inpaint_image` обычно используется вместе с `mask` для указания содержимого для инпейнтинга. Поведение узла может изменяться в зависимости от того, какие необязательные входы предоставлены (например, использование `image` для управления или использование `image`, `mask` и `inpaint_image` для инпейнтинга).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с применённым патчем управляющей сети, готовая к использованию в пайплайне сэмплирования. | MODEL |
| `positive` | Положительное кондиционирование, потенциально изменённое входами управляющей сети. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, потенциально изменённое входами управляющей сети. | CONDITIONING |
