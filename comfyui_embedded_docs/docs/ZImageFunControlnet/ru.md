# ZImageFunControlnet

ZImageFunControlnet применяет патч управляющей сети к базовой модели, чтобы направлять процесс генерации или редактирования изображения. Он объединяет модель, патч модели и VAE и позволяет управлять тем, насколько сильно управляющий эффект влияет на результат. Необязательные входы изображения, изображения для inpainting и маски позволяют выполнять более целенаправленные правки. Узел работает с патчами Z-Image ControlNet и с патчами Qwen Image 2.1 Fun ControlNet, загружаемыми через узел Load Model Patch.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Базовая модель, используемая для процесса генерации. | MODEL | Да | - |
| `model_patch` | Специализированный патч модели, который применяет направляющее воздействие управляющей сети. | MODEL_PATCH | Да | - |
| `vae` | Вариационный автоэнкодер, используемый для кодирования и декодирования изображений. | VAE | Да | - |
| `интенсивность` | Сила влияния управляющей сети. Положительные значения применяют эффект, а отрицательные могут его инвертировать (по умолчанию: 1.0). | FLOAT | Да | от -10.0 до 10.0 (шаг 0.01) |
| `изображение` | Необязательное базовое изображение для направления процесса генерации. | IMAGE | Нет | - |
| `inpaint_изображение` | Необязательное изображение, используемое специально для областей inpainting, определённых маской. | IMAGE | Нет | - |
| `mask` | Необязательная маска, которая определяет, какие области изображения следует редактировать или восстанавливать с помощью inpainting. | MASK | Нет | - |
| `start_percent` | Точка в процессе удаления шума, как доля от общего числа шагов сэмплирования, в которой управляющая сеть начинает действовать (по умолчанию: 0.0). | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |
| `end_percent` | Точка в процессе удаления шума, в которой управляющая сеть перестаёт действовать (по умолчанию: 1.0). | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |

**Примечание:** Параметр `inpaint_image` обычно используется вместе с `mask`, чтобы указать содержимое для inpainting. Поведение узла может меняться в зависимости от того, какие необязательные входы предоставлены (например, использование `image` для управления или использование `image`, `mask` и `inpaint_image` для inpainting). Значения `start_percent` и `end_percent` ограничивают управляющую сеть окном процесса удаления шума, а вне этого окна модель сэмплируется без патча. Если `strength` равен 0 или ни один из `image`, `inpaint_image` и `mask` не подключён, узел возвращает базовую модель без изменений. Для патчей Z-Image Control предоставленная маска инвертируется (1.0 - mask) перед использованием, тогда как патч Qwen Image 2.1 Fun ControlNet использует маску как есть. Этот узел помечен как экспериментальный.
