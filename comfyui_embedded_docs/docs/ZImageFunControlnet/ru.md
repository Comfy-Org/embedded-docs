# ZImageFunControlnet

ZImageFunControlnet применяет патч управляющей сети к базовой модели, чтобы он мог управлять процессом генерации или редактирования изображения. Он объединяет модель, патч модели и VAE и позволяет управлять тем, насколько сильно эффект управления влияет на результат. Необязательные входы изображения, изображения для инпейнтинга и маски позволяют выполнять более целенаправленные правки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Базовая модель, используемая для процесса генерации. | MODEL | Да | - |
| `model_patch` | Специализированный патч модели, который применяет управляющее воздействие управляющей сети. | MODEL_PATCH | Да | - |
| `vae` | Вариационный автоэнкодер, используемый для кодирования и декодирования изображений. | VAE | Да | - |
| `интенсивность` | Сила влияния управляющей сети. Положительные значения применяют эффект, а отрицательные могут его инвертировать (по умолчанию: 1.0). | FLOAT | Да | от -10.0 до 10.0 (шаг 0.01) |
| `изображение` | Необязательное базовое изображение для управления процессом генерации. | IMAGE | Нет | - |
| `inpaint_изображение` | Необязательное изображение, используемое специально для инпейнтинга областей, определённых маской. | IMAGE | Нет | - |
| `mask` | Необязательная маска, определяющая, какие области изображения следует редактировать или заполнять. | MASK | Нет | - |

**Примечание:** Параметр `inpaint_image` обычно используется вместе с `mask` для указания содержимого для инпейнтинга. Поведение узла может меняться в зависимости от того, какие необязательные входы предоставлены (например, использование `image` для управления или использование `image`, `mask` и `inpaint_image` для инпейнтинга).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с применённым патчем управляющей сети, готовая к использованию в конвейере сэмплирования. | MODEL |
| `positive` | Положительное кондиционирование, потенциально изменённое входами управляющей сети. | CONDITIONING |
| `negative` | Отрицательное кондиционирование, потенциально изменённое входами управляющей сети. | CONDITIONING |
