# ZImageFunControlnet

ZImageFunControlnet применяет специализированную управляющую сеть (control network) для воздействия на процесс генерации или редактирования изображений. Он использует базовую модель, патч модели и VAE, что позволяет регулировать силу управляющего воздействия. Этот узел может работать с базовым изображением, изображением для инпейнтинга и маской для более точечного редактирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Базовая модель, используемая в процессе генерации. | MODEL | Да | - |
| `model_patch` | Специализированный патч модели, применяющий направляющее воздействие управляющей сети. | MODEL_PATCH | Да | - |
| `vae` | Вариационный автокодировщик (VAE), используемый для кодирования и декодирования изображений. | VAE | Да | - |
| `интенсивность` | Сила влияния управляющей сети. Положительные значения применяют эффект, отрицательные — инвертируют его (по умолчанию: 1.0). | FLOAT | Да | -10.0 до 10.0 |
| `изображение` | Необязательное базовое изображение для направления процесса генерации. | IMAGE | Нет | - |
| `inpaint_изображение` | Необязательное изображение, используемое специально для инпейнтинга областей, заданных маской. | IMAGE | Нет | - |
| `mask` | Необязательная маска, определяющая области изображения, которые следует редактировать или инпейнтить. | MASK | Нет | - |

**Примечание:** Параметр `inpaint_image` обычно используется вместе с `mask`, чтобы указать содержимое для инпейнтинга. Поведение узла может изменяться в зависимости от того, какие необязательные входы предоставлены (например, использование `image` для направления генерации или использование `image`, `mask` и `inpaint_image` для инпейнтинга).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с применённым патчем управляющей сети, готовая к использованию в конвейере сэмплирования. | MODEL |
| `positive` | Позитивное кондиционирование, возможно изменённое входными данными управляющей сети. | CONDITIONING |
| `negative` | Негативное кондиционирование, возможно изменённое входными данными управляющей сети. | CONDITIONING |
