# SheetSage2AudioToABC

צומת זה מתמלל מלודיות ווקאליות ואינסטרומנטליות ממוזיקה לסימון ABC, פורמט מבוסס טקסט לכתיבת תווים מוזיקליים. הוא מנתח את האודיו המחובר ומחזיר את הסימון המתקבל כטקסט, שאותו ניתן להזין לצומת YuE2 Generate Music באמצעות המצב המתאים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio_encoder` | מודל מקודד האודיו המשמש לניתוח האודיו והפקת סימון ABC. | AUDIO_ENCODER | כן | - |
| `audio` | אודיו המוזיקה לתמלול לסימון ABC. | AUDIO | כן | - |
| `mode` | שולט במה שמתומלל. "full" יוצר מלודיה ואקורדים; "melody" יוצר מלודיה בלבד, מומלץ לקאברים. | COMBO | כן | `"melody"`<br>`"full"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `abc` | המוזיקה המתומללת בסימון ABC, מוחזרת כרשימת מחרוזות. יש לחבר זאת לצומת YuE2 Generate Music ולהשתמש במצב המתאים. | STRING |
