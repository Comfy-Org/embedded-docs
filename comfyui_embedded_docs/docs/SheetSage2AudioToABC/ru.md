# SheetSage2: аудио в ABC

Этот узел транскрибирует вокальные и инструментальные мелодии из музыки в ABC-нотацию — текстовый формат для записи музыкальных партитур. Он анализирует подключённое аудио и возвращает полученную нотацию в виде текста, которую затем можно подать в узел YuE2 Generate Music, используя соответствующий режим.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio_encoder` | Модель аудиоэнкодера, используемая для анализа аудио и создания ABC-нотации. | AUDIO_ENCODER | Да | - |
| `audio` | Музыкальное аудио для транскрибирования в ABC-нотацию. | AUDIO | Да | - |
| `mode` | Управляет тем, что транскрибируется. "full" создаёт мелодию и аккорды; "melody" создаёт только мелодию, рекомендуется для каверов. | COMBO | Да | `"melody"`<br>`"full"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `abc` | Транскрибированная музыка в ABC-нотации, возвращаемая в виде списка строк. Подключите её к узлу YuE2 Generate Music и используйте соответствующий режим. | STRING |
