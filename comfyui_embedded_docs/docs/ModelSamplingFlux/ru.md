# Выборка модели Flux

Узел ModelSamplingFlux применяет сэмплирование Flux к заданной модели, вычисляя параметр сдвига на основе размеров изображения. Он создает специализированную конфигурацию сэмплирования, которая корректирует поведение модели в соответствии с указанными шириной, высотой и параметрами сдвига, а затем возвращает измененную модель с примененными новыми настройками сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяется сэмплирование Flux | MODEL | Да | - |
| `макс_сдвиг` | Максимальное значение сдвига для вычисления сэмплирования (по умолчанию: 1.15) | FLOAT | Да | 0.0 - 100.0 (шаг 0.01) |
| `базовый_сдвиг` | Базовое значение сдвига для вычисления сэмплирования (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 100.0 (шаг 0.01) |
| `ширина` | Ширина целевого изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 - MAX_RESOLUTION (шаг 8) |
| `высота` | Высота целевого изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 - MAX_RESOLUTION (шаг 8) |

`max_shift` и `base_shift` являются дополнительными параметрами. Сдвиг, применяемый к конфигурации сэмплирования, вычисляется на основе размеров изображения: латентное разрешение вычисляется как `width × height / 256`, а значение сдвига интерполируется между `base_shift` при латентном разрешении 256 и `max_shift` при латентном разрешении 4096.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной конфигурацией сэмплирования Flux | MODEL |
