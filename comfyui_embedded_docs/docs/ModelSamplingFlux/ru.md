# Выборка модели Flux

Узел `ModelSamplingFlux` применяет сэмплирование Flux к заданной модели, вычисляя параметр сдвига на основе размеров изображения. Он создает специализированную конфигурацию сэмплирования, которая корректирует поведение модели в соответствии с указанными шириной, высотой и параметрами сдвига, а затем возвращает измененную модель с примененными новыми настройками сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяется сэмплирование Flux | MODEL | Да | - |
| `max_shift` | Максимальное значение сдвига для вычисления сэмплирования (по умолчанию: 1.15) | FLOAT | Да | 0.0 - 100.0 |
| `base_shift` | Базовое значение сдвига для вычисления сэмплирования (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 100.0 |
| `width` | Ширина целевого изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 - MAX_RESOLUTION |
| `height` | Высота целевого изображения в пикселях (по умолчанию: 1024) | INT | Да | 16 - MAX_RESOLUTION |

Эффективное значение сдвига интерполируется между `base_shift` и `max_shift` на основе размера latent, полученного из `width` и `height`. Значение `step` равно 0.01 для `max_shift` и `base_shift`, и 8 для `width` и `height`. Параметры `max_shift` и `base_shift` помечены как расширенные опции в пользовательском интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененной конфигурацией сэмплирования Flux | MODEL |
