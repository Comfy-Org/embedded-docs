# HappyHorse تبدیل متن به ویدیو


ویدیویی بر اساس یک پرامپت متنی با استفاده از مدل HappyHorse تولید می‌کند. این گره پرامپت و تنظیمات شما را به API هَپی‌هورس ارسال می‌کند، منتظر می‌ماند تا ویدیو تولید شود و سپس نتیجه را دانلود می‌کند.
## ورودیها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `model` | مدل HappyHorse مورد استفاده برای تولید، همراه با زیرپارامترهای آن. انتخاب یک مدل تعیین می‌کند که کدام زیرپارامترها در دسترس هستند (به بخش‌های مدل در زیر مراجعه کنید). | DYNAMIC_COMBO | بله | "happyhorse-1.1-t2v"<br>"happyhorse-1.0-t2v" |
| `seed` | دانه (Seed) مورد استفاده برای تولید. استفاده از همان دانه با همان ورودی‌ها نتیجه یکسانی تولید می‌کند. (پیش‌فرض: 0). | INT | بله | 0 to 2147483647 |
| `watermark` | آیا به نتیجه، واترمارک تولیدشده با هوش مصنوعی اضافه شود. (پیش‌فرض: False). | BOOLEAN | بله | True / False |

### ورودی‌های happyhorse-1.1-t2v

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `prompt` | پرامپتی که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. (پیش‌فرض: ""). | STRING | بله | - |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | "720P"<br>"1080P" |
| `ratio` | نسبت تصویر ویدیوی خروجی. | COMBO | بله | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9"<br>"9:21"<br>"5:4"<br>"4:5" |
| `duration` | طول ویدیو بر حسب ثانیه. (پیش‌فرض: 5، حداقل: 3، حداکثر: 15، گام: 1). | INT | بله | 3 to 15 |
