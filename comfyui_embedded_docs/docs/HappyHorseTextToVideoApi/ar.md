# HappyHorse تحويل نص إلى فيديو

يولّد فيديو استنادًا إلى وصف نصي باستخدام نموذج HappyHorse. يرسل هذا العقد وصفك وإعداداتك إلى واجهة برمجة تطبيقات HappyHorse، وينتظر اكتمال إنشاء الفيديو، ثم ينزّل النتيجة.

## المدخلات

### المدخلات المشتركة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | نموذج HappyHorse المستخدم في التوليد، مع معامِلاته الفرعية. يحدد اختيار النموذج المعامِلات الفرعية المتاحة (انظر أقسام النماذج أدناه). | DICT | نعم | "happyhorse-1.1-t2v"<br>"happyhorse-1.0-t2v" |
| `البذرة` | البذرة المستخدمة في التوليد. استخدام نفس البذرة مع نفس المدخلات ينتج نفس النتيجة. (الافتراضي: 0). | INT | نعم | 0 إلى 2147483647 |
| `علامة مائية` | ما إذا كان سيتم إضافة علامة مائية مولّدة بالذكاء الاصطناعي إلى النتيجة. (الافتراضي: False). | BOOLEAN | لا | True / False |

### مدخلات happyhorse-1.1-t2v

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الموجه` | وصف يوضح العناصر والخصائص البصرية. يدعم اللغتين الإنجليزية والصينية. (الافتراضي: ""). | STRING | نعم | - |
| `الدقة` | دقة الفيديو الناتج. | STRING | نعم | "720P"<br>"1080P" |
| `النسبة` | نسبة العرض إلى الارتفاع للفيديو الناتج. | STRING | نعم | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9"<br>"9:21"<br>"5:4"<br>"4:5" |
| `المدة` | مدة الفيديو بالثواني. (الافتراضي: 5، الحد الأدنى: 3، الحد الأقصى: 15، الخطوة: 1). | INT | نعم | 3 إلى 15 |
