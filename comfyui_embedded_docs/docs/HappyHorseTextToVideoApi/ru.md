# HappyHorse: текст в видео

Генерирует видео на основе текстового промпта с использованием модели HappyHorse. Этот узел отправляет ваш промпт и настройки в API HappyHorse, ожидает генерации видео, а затем загружает результат.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель HappyHorse, используемая для генерации, вместе с её подпараметрами. Выбор модели определяет, какие подпараметры доступны (см. разделы моделей ниже). | DYNAMIC_COMBO | Да | "happyhorse-1.1-t2v"<br>"happyhorse-1.0-t2v" |
| `seed` | Сид, используемый для генерации. Использование одного и того же сида с одинаковыми входными данными даст один и тот же результат. (по умолчанию: 0). | INT | Да | 0 to 2147483647 |
| `watermark` | Определяет, нужно ли добавлять к результату водяной знак, созданный ИИ. (по умолчанию: False). | BOOLEAN | Да | True / False |

### happyhorse-1.1-t2v Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. (по умолчанию: ""). | STRING | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон выходного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9"<br>"9:21"<br>"5:4"<br>"4:5" |
| `duration` | Длительность видео в секундах. (по умолчанию: 5, мин: 3, макс: 15, шаг: 1). | INT | Да | 3 to 15 |

### happyhorse-1.0-t2v Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. (по умолчанию: ""). | STRING | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон выходного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | Длительность видео в секундах. (по умолчанию: 5, мин: 3, макс: 15, шаг: 1). | INT | Да | 3 to 15 |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `VIDEO` | The generated video file. | VIDEO |
