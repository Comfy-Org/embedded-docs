# HappyHorse טקסט לווידאו

יוצר סרטון על בסיס הנחיית טקסט באמצעות מודל HappyHorse. צומת זה שולח את ההנחיה וההגדרות שלך ל-API של HappyHorse, ממתין ליצירת הסרטון, ולאחר מכן מוריד את התוצאה.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל HappyHorse המשמש ליצירה, יחד עם תת-הפרמטרים שלו. בחירת מודל קובעת אילו תת-פרמטרים זמינים (ראו מקטעי המודלים למטה). | DYNAMIC_COMBO | כן | "happyhorse-1.1-t2v"<br>"happyhorse-1.0-t2v" |
| `seed` | ה-seed שיש להשתמש בו ליצירה. שימוש באותו seed עם אותם קלטים יניב את אותה תוצאה. (ברירת מחדל: 0). | INT | כן | 0 עד 2147483647 |
| `watermark` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה. (ברירת מחדל: False). | BOOLEAN | כן | True / False |
