# HappyHorse 文字轉影片

此節點使用 HappyHorse 模型根據文字提示生成影片。它會將您的提示和設定傳送到 HappyHorse API，等待影片生成完成，然後下載結果。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於生成的 HappyHorse 模型及其子參數。選擇模型會決定可用的子參數（請參閱下方各模型區段）。 | DYNAMIC_COMBO | 是 | "happyhorse-1.1-t2v"<br>"happyhorse-1.0-t2v" |
| `seed` | 用於生成的隨機種子。使用相同的種子與相同的輸入會產生相同的結果。（預設值：0）。 | INT | 是 | 0 至 2147483647 |
| `watermark` | 是否在結果中加入 AI 生成的浮水印。（預設值：False）。 | BOOLEAN | 是 | True / False |

### happyhorse-1.1-t2v 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素與視覺特徵的提示。支援英文和中文。（預設值：""）。 | STRING | 是 | - |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "720P"<br>"1080P" |
| `ratio` | 輸出影片的長寬比。 | COMBO | 是 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4"<br>"21:9"<br>"9:21"<br>"5:4"<br>"4:5" |
| `duration` | 影片長度（秒）。（預設值：5，最小值：3，最大值：15，步長：1）。 | INT | 是 | 3 至 15 |

### happyhorse-1.0-t2v 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素與視覺特徵的提示。支援英文和中文。（預設值：""）。 | STRING | 是 | - |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "720P"<br>"1080P" |
| `ratio` | 輸出影片的長寬比。 | COMBO | 是 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | 影片長度（秒）。（預設值：5，最小值：3，最大值：15，步長：1）。 | INT | 是 | 3 至 15 |

注意：提示不得為空；若未提供提示則會引發錯誤。兩個模型皆支援 3 至 15 秒的影片長度。`happyhorse-1.1-t2v` 模型提供額外的長寬比（`21:9`、`9:21`、`5:4`、`4:5`），這些是 `happyhorse-1.0-t2v` 所沒有的。
