# CFG正規化

CFGNormは、拡散モデルにおけるクラシファイアフリーガイダンス（CFG）プロセスに正規化手法を適用します。条件付き出力と無条件出力のノルムを比較してデノイズされた予測のスケールを調整し、その後、強度乗数を適用して効果を制御します。これにより、ガイダンススケーリングの極端な値を防ぎ、生成プロセスを安定化させます。`pre_cfg`が有効な場合、再スケーリングはサンプラーのCFG結合の前に結合ノイズに適用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | CFG正規化を適用する拡散モデル | MODEL | はい | - |
| `strength` | CFGスケーリングに適用される正規化効果の強度を制御します（デフォルト: 1.0） | FLOAT | はい | 0.0～100.0（ステップ 0.01） |
| `pre_cfg` | trueの場合、サンプラーのCFG結合**前**に結合ノイズを再スケーリングします。クランプは行わないため、増幅される可能性があります。Lensなどのモデルで使用されるノルムスケーリングCFGと一致します。デフォルトのfalseでは、元のpost-CFG x0空間の減衰専用動作が維持されます。（デフォルト: False） | BOOLEAN | いいえ | True<br>False |

注：デフォルトのpost-CFGモードでは、再スケーリング係数は0.0から1.0の間でクランプされます。そのため、予測スケールを減衰（縮小）することしかできません。`pre_cfg`を有効にすると、クランプは適用されないため、結合ノイズを増幅できます。このモードでは、`strength`の値を1.0以外に設定すると、結果は標準の線形CFGに向かってブレンドされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `patched_model` | CFG正規化がサンプリングプロセスに適用された変更済みモデルを返します | MODEL |
