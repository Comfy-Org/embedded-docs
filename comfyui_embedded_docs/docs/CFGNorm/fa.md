# CFGNorm

CFGNorm نحوه اعمال راهنمایی بدون طبقه‌بند (CFG) در مدل‌های انتشار را با مقایسه اندازه (نُرم) پیش‌بینی شرطی با پیش‌بینی هدایت‌شده و مقیاس‌بندی مجدد نتیجه تنظیم می‌کند. مقدار `strength` میزان اعمال این تنظیم را کنترل می‌کند. به‌طور پیش‌فرض، مقیاس‌بندی فقط خروجی راهنما را تضعیف می‌کند، اما فعال کردن `pre_cfg` نویز ترکیب‌شده را پیش از ترکیب CFG در سمپلر و بدون محدودسازی مقیاس‌بندی مجدد می‌کند، که می‌تواند نتیجه را تقویت کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل انتشار برای اعمال نرمال‌سازی CFG روی آن | MODEL | بله | - |
| `strength` | شدت اثر نرمال‌سازی اعمال‌شده بر مقیاس‌بندی CFG را کنترل می‌کند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 100.0 (گام 0.01) |
| `pre_cfg` | اگر true باشد، نویز ترکیب‌شده را پیش از ترکیب CFG در سمپلر و بدون محدودسازی مقیاس‌بندی مجدد می‌کند (می‌تواند تقویت کند). با CFG مقیاس‌بندی‌شده با نُرم که مدل‌هایی مانند Lens استفاده می‌کنند مطابقت دارد. مقدار پیش‌فرض false رفتار اصلی پس از CFG در فضای x0 را حفظ می‌کند که فقط تضعیف‌کننده است. (پیش‌فرض: False) | BOOLEAN | خیر | true / false |

توجه: این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
