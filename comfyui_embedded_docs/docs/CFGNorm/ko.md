# CFGNorm

CFGNorm은 확산 모델의 classifier-free guidance(CFG) 과정에 정규화 기법을 적용합니다. 조건부 및 무조건부 출력의 노름(norm)을 비교하여 노이즈 제거 예측의 스케일을 조정한 다음, 강도 배율을 적용하여 효과를 제어합니다. 이는 가이던스 스케일링에서 극단적인 값이 발생하는 것을 방지하여 생성 과정을 안정화하는 데 도움이 됩니다. `pre_cfg`가 활성화된 경우, 재스케일링은 대신 샘플러의 CFG 결합 이전에 결합된 노이즈에 적용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | CFG 정규화를 적용할 확산 모델 | MODEL | 예 | - |
| `strength` | CFG 스케일링에 적용되는 정규화 효과의 강도를 제어합니다 (기본값: 1.0) | FLOAT | 예 | 0.0 to 100.0 (step 0.01) |
| `pre_cfg` | true인 경우 샘플러의 CFG 결합 **이전에** 결합된 노이즈를 클램핑 없이 재스케일링합니다 (증폭될 수 있음). Lens와 같은 모델에서 사용되는 노름-스케일 CFG와 일치합니다. 기본값 false는 원래의 사후-CFG x0 공간 감쇠 전용 동작을 유지합니다. (기본값: False) | BOOLEAN | 아니요 | True<br>False |

참고: 기본 사후-CFG 모드에서는 재스케일링 계수가 0.0과 1.0 사이로 클램핑되므로 예측 스케일을 감쇠(감소)시키기만 할 수 있습니다. `pre_cfg`가 활성화되면 클램핑이 적용되지 않으므로 결합된 노이즈가 증폭될 수 있습니다. 이 모드에서는 `strength` 값이 1.0이 아닌 경우 결과가 표준 선형 CFG 쪽으로 혼합됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `patched_model` | 샘플링 과정에 CFG 정규화가 적용된 수정된 모델을 반환합니다 | MODEL |
