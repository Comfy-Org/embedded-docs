# CFGNorm

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется нормализация CFG | MODEL | Да | - |
| `интенсивность` | Управляет интенсивностью эффекта нормализации, применяемого к масштабированию CFG (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 100.0 |
| `pre_cfg` | Если true, изменяет масштаб объединенного шума ДО объединения CFG в сэмплере, без ограничения (может усиливать). Соответствует CFG с масштабированием по норме, используемому такими моделями, как Lens. По умолчанию false сохраняет исходное поведение только ослабления в пространстве x0 после CFG. (по умолчанию: False) | BOOLEAN | Нет | true / false |

Примечание: Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `исправленная_модель` | Возвращает измененную модель с примененной нормализацией CFG к ее процессу сэмплирования | MODEL |
