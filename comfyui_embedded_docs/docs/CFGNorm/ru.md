# CFGNorm

CFGNorm регулирует применение classifier-free guidance (CFG) в диффузионных моделях, сравнивая норму условного предсказания с предсказанием с guidance и изменяя масштаб результата. Значение `strength` управляет степенью применения корректировки. По умолчанию масштабирование только ослабляет выход guidance, тогда как включение `pre_cfg` изменяет масштаб объединённого шума ДО CFG-объединения сэмплера без ограничения, что может усилить результат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется нормализация CFG | MODEL | Да | - |
| `интенсивность` | Управляет интенсивностью эффекта нормализации, применяемого к масштабированию CFG (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 100.0 (шаг 0.01) |
| `pre_cfg` | Если true, изменяет масштаб объединённого шума ДО CFG-объединения сэмплера, без ограничения (может усиливать). Соответствует CFG с масштабированием по норме, используемому в таких моделях, как Lens. Значение по умолчанию false сохраняет исходное поведение только ослабления в пространстве x0 после CFG. (по умолчанию: False) | BOOLEAN | Нет | true / false |

Примечание: этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `patched_model` | Возвращает изменённую модель с нормализацией CFG, применённой к процессу её сэмплирования | MODEL |
