# CFGNorm

CFGNorm применяет технику нормализации к процессу управления без классификатора (CFG) в диффузионных моделях. Она регулирует масштаб денойзированного предсказания путём сравнения норм условного и безусловного выходов, а затем применяет множитель силы для контроля эффекта. Это помогает стабилизировать процесс генерации, предотвращая экстремальные значения в масштабировании управления. Когда `pre_cfg` включен, пересчёт вместо этого применяется к объединённому шуму до комбинирования CFG в сэмплере.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется нормализация CFG | MODEL | Да | - |
| `strength` | Управляет интенсивностью эффекта нормализации, применяемого к масштабированию CFG (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 100.0 (step 0.01) |
| `pre_cfg` | Если true, пересчитать объединённый шум ДО комбинирования CFG в сэмплере, без ограничения (может усиливать). Соответствует нормированному по масштабу CFG, используемому такими моделями, как Lens. По умолчанию false сохраняет исходное поведение после CFG в пространстве x0 с только ослаблением. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

Примечание: В режиме по умолчанию после CFG коэффициент пересчёта ограничен диапазоном от 0.0 до 1.0, поэтому он может только ослаблять (уменьшать) масштаб предсказания. Когда `pre_cfg` включен, ограничение не применяется, поэтому объединённый шум может быть усилен. В этом режиме значение `strength`, отличное от 1.0, смешивает результат обратно к стандартному линейному CFG.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `patched_model` | Возвращает модифицированную модель с применённой к её процессу сэмплирования нормализацией CFG | MODEL |
