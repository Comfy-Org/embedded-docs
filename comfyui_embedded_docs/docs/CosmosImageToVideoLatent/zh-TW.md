# Cosmos 圖片轉影片潛在編碼

The CosmosImageToVideoLatent 節點會從輸入影像建立影片潛在表示。它會以要求的寬度、高度和幀數建立一個空白影片潛在，然後可選擇性地將起始影像編碼到前幾個幀，和/或將結束影像編碼到最後幾個幀。當提供影像時，它也會產生噪聲遮罩，使編碼後的幀在生成過程中保持固定。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `vae` | 用於將影像編碼到影片潛在空間的 VAE 模型。 | VAE | 是 | - |
| `寬度` | 輸出影片的寬度（像素，預設值：1280）。 | INT | 是 | 16 to MAX_RESOLUTION (step: 16) |
| `高度` | 輸出影片的高度（像素，預設值：704）。 | INT | 是 | 16 to MAX_RESOLUTION (step: 16) |
| `長度` | 影片中的總幀數（預設值：121）。 | INT | 是 | 1 to MAX_RESOLUTION (step: 8) |
| `批次大小` | 要生成的影片潛在數量（預設值：1）。 | INT | 是 | 1 至 4096 |
| `起始影像` | 可選的影像或影像序列，將編碼到影片的開頭。 | IMAGE | 否 | - |
| `結束圖片` | 可選的影像或影像序列，將編碼到影片的結尾。 | IMAGE | 否 | - |

**注意：**
- 當未提供 `start_image` 或 `end_image` 時，節點會回傳沒有噪聲遮罩的空白潛在。
- 當提供 `start_image` 時，它會被編碼到潛在的前幾個幀，且這些幀會標記為噪聲遮罩值 0（保留）。當提供 `end_image` 時，它會被編碼到最後幾個幀，且這些幀會標記為噪聲遮罩值 0。其餘幀的遮罩值保持為 1。
- 該潛在具有 16 個通道，其空間維度為 `height / 8` 乘以 `width / 8`。潛在幀數為 `((length - 1) // 8) + 1`。
- `batch_size` 會重複該潛在，且若存在噪聲遮罩，也會重複噪聲遮罩。

## 輸出

| 輸出名 | 描述 | 資料類型 |
| --- | --- | --- |
