# CosmosImageToVideoLatent

צומת CosmosImageToVideoLatent יוצר ייצוג לטנט של וידאו מתמונות קלט. הוא בונה לטנט וידאו ריק עם הרוחב, הגובה ומספר הפריימים המבוקשים, ואז מקודד באופן אופציונלי תמונת התחלה לפריימים הראשונים ו/או תמונת סיום לפריימים האחרונים. כאשר מסופקות תמונות, הוא גם יוצר מסכת רעש כך שהפריימים המקודדים יישארו קבועים במהלך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `vae` | מודל ה-VAE המשמש לקידוד התמונות למרחב הלטנט של הווידאו. | VAE | כן | - |
| `width` | רוחב סרטון הפלט בפיקסלים (ברירת מחדל: 1280). | INT | כן | 16 עד MAX_RESOLUTION (צעד: 16) |
| `height` | גובה סרטון הפלט בפיקסלים (ברירת מחדל: 704). | INT | כן | 16 עד MAX_RESOLUTION (צעד: 16) |
| `length` | מספר הפריימים הכולל בסרטון (ברירת מחדל: 121). | INT | כן | 1 עד MAX_RESOLUTION (צעד: 8) |
| `batch_size` | מספר הלטנטים של וידאו ליצירה (ברירת מחדל: 1). | INT | כן | 1 עד 4096 |
| `start_image` | תמונה אופציונלית או רצף תמונות לקידוד בתחילת הסרטון. | IMAGE | לא | - |
| `end_image` | תמונה אופציונלית או רצף תמונות לקידוד בסוף הסרטון. | IMAGE | לא | - |

**הערה:**
- כאשר לא מסופק `start_image` ולא `end_image`, הצומת מחזיר לטנט ריק ללא מסכת רעש.
- כאשר `start_image` מסופק, הוא מקודד לפריימים הראשונים של הלטנט והפריימים האלה מסומנים בערך 0 במסכת הרעש (משומרים). כאשר `end_image` מסופק, הוא מקודד לפריימים האחרונים והפריימים האלה מסומנים בערך 0 במסכת הרעש. יתר הפריימים שומרים על ערך מסכה של 1.
- ללטנט יש 16 ערוצים, והממדים המרחביים שלו הם `height / 8` על `width / 8`. מספר פריימי הלטנט הוא `((length - 1) // 8) + 1`.
- `batch_size` משכפל את הלטנט, וכאשר מסכת רעש קיימת, גם אותה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `latent` | הלטנט הווידאו שנוצר, המכיל את תמונות ההתחלה ו/או הסיום המקודדות האופציונליות, וכאשר תמונות מסופקות, מסכת רעש תואמת עם ערך 0 בפריימים המשומרים. | LATENT |
