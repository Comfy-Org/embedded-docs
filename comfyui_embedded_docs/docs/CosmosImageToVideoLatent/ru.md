# CosmosImageToVideoLatent

Узел `CosmosImageToVideoLatent` создает видео-latent для генерации из изображения в видео. Он начинается с пустого latent и при необходимости может закодировать начальное и/или конечное изображение в первые или последние кадры видеопоследовательности. Когда изображения предоставлены, узел также генерирует шумовую маску, которая помечает закодированные кадры как фиксированные во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования входных изображений в скрытое пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 1280) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `height` | Высота выходного видео в пикселях (по умолчанию: 704) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 121) | INT | Да | 1 to MAX_RESOLUTION (step 8) |
| `batch_size` | Количество видео-latent для генерации в выходном батче (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `start_image` | Необязательное изображение или последовательность изображений для кодирования в начале видеопоследовательности | IMAGE | Нет | - |
| `end_image` | Необязательное изображение или последовательность изображений для кодирования в конце видеопоследовательности | IMAGE | Нет | - |

**Примечание:** Когда ни `start_image`, ни `end_image` не предоставлены, узел возвращает пустой latent без шумовой маски. Если предоставлено хотя бы одно изображение, включается `noise_mask`: кадры latent, закодированные из предоставленных изображений, имеют значение маски 0 (остаются фиксированными), а остальные кадры имеют значение маски 1 (подлежат генерации). Изображения масштабируются до целевых значений `width` и `height` перед кодированием, а количество кадров, взятых из входного изображения, равно его размеру батча, но не более `length`. Latent имеет 16 каналов, пространственные размеры `width / 8` и `height / 8`, а также `((length - 1) // 8) + 1` кадров. Когда изображения предоставлены, latent и его шумовая маска повторяются `batch_size` раз для формирования выходного батча.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | LATENT, содержащий видео-latent `samples` и, если предоставлены `start_image` или `end_image`, `noise_mask`, помечающий закодированные кадры как фиксированные | LATENT |
