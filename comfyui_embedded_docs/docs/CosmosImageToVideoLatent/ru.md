# CosmosImageToVideoLatent

Узел CosmosImageToVideoLatent создаёт латентное представление видео из входных изображений. Он строит пустое латентное представление видео с заданными шириной, высотой и количеством кадров, а затем опционально кодирует начальное изображение в начальные кадры и/или конечное изображение в конечные кадры. Когда изображения предоставлены, он также генерирует маску шума, чтобы закодированные кадры оставались фиксированными во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство видео. | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 1280). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 704). | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `длина` | Общее количество кадров в видео (по умолчанию: 121). | INT | Да | 1 to MAX_RESOLUTION (step: 8) |
| `размер_пакета` | Количество видео-латентов для генерации (по умолчанию: 1). | INT | Да | 1 до 4096 |
| `начальное_изображение` | Необязательное изображение или последовательность изображений для кодирования в начале видео. | IMAGE | Нет | - |
| `конечное_изображение` | Необязательное изображение или последовательность изображений для кодирования в конце видео. | IMAGE | Нет | - |

**Примечание:**
- Если не предоставлены ни `start_image`, ни `end_image`, узел возвращает пустой латент без маски шума.
- Если предоставлен `start_image`, он кодируется в первые кадры латента, и эти кадры помечаются значением маски шума 0 (сохранены). Если предоставлен `end_image`, он кодируется в последние кадры, и эти кадры помечаются значением маски шума 0. Остальные кадры сохраняют значение маски 1.
- Латент имеет 16 каналов, а его пространственные размеры составляют `height / 8` на `width / 8`. Количество латентных кадров равно `((length - 1) // 8) + 1`.
- `batch_size` повторяет латент, а также маску шума, если она присутствует.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `latent` | Сгенерированный видеолатент, содержащий необязательные закодированные начальные и/или конечные изображения и, при наличии изображений, соответствующую маску шума со значением 0 на сохраненных кадрах. | LATENT |
