# StabilityUpscaleFastNode

Esegue rapidamente l'upscaling di un'immagine tramite una chiamata all'API di Stability, portandola a 4 volte la dimensione originale. Questo nodo è specificamente pensato per l'upscaling di immagini di bassa qualità o compresse, inviandole al servizio di upscaling rapido di Stability AI.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
|-----------|-------------|--------------|--------------|------------|
| `image` | L'immagine di input da upscalare | IMAGE | Sì | - |

## Output

| Nome output | Descrizione | Tipo di dato |
|-------------|-------------|--------------|
| `output` | L'immagine upscalata restituita dall'API di Stability AI | IMAGE |
