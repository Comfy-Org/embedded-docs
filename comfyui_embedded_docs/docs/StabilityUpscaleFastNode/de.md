# StabilityUpscaleFastNode

Skaliert ein Bild schnell über einen Stability-API-Aufruf auf das 4-fache seiner ursprünglichen Größe hoch. Dieser Node ist speziell dafür vorgesehen, Bilder mit niedriger Qualität oder komprimierte Bilder hochzuskalieren, indem sie an den schnellen Hochskalierungsdienst von Stability AI gesendet werden.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
|-----------|-------------|-----------|----------|-------|
| `image` | Das Eingabebild, das hochskaliert werden soll | IMAGE | Ja | - |

## Ausgaben

| Ausgabename | Beschreibung | Datentyp |
|-------------|-------------|-----------|
| `output` | Das hochskalierte Bild, das von der Stability AI API zurückgegeben wird | IMAGE |
