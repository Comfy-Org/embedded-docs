# إضافة نص على الصورة

يقوم هذا العقد برسم نص فوق صورة أو دفعة من الصور. ينشئ تراكبًا نصيًا باستخدام حجم خط قابل للضبط، ولون، وموضع عمودي، ومحاذاة أفقية، وحدود خارجية سوداء اختيارية، ثم يدمج التراكب مع بكسلات الصورة الأصلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `images` | الصورة المدخلة أو دفعة الصور التي سيُرسم النص عليها | IMAGE | نعم | |
| `text` | النص المراد تركيبه فوق الصورة (الافتراضي: ""). يدعم عدة أسطر: يتم تحويل تسلسلي الهروب `\n` و `\t` إلى أسطر جديدة وعلامات جدولة، ويتم لف الأسطر الطويلة تلقائيًا لتناسب عرض الصورة. | STRING | نعم | |
| `font_size` | حجم الخط كنسبة مئوية من ارتفاع الصورة (الافتراضي: 5.0) | FLOAT | نعم | 0.5 إلى 50.0 (خطوة: 0.5) |
| `color` | لون النص (الافتراضي: "#ffffff") | COLOR | نعم | |
| `position` | الموضع العمودي للنص على الصورة (الافتراضي: "top") | COMBO | نعم | "top"<br>"bottom" |
| `align` | المحاذاة الأفقية للنص (الافتراضي: "left") | COMBO | نعم | "left"<br>"center"<br>"right" |
| `outline` | رسم حدود خارجية سوداء حول النص (الافتراضي: True) | BOOLEAN | نعم | |

ملاحظة: إذا كان `text` فارغًا أو يحتوي على مسافات بيضاء فقط، يُرجع العقد الصور المدخلة دون تغيير. يُرسم التراكب النصي مرة واحدة ويُطبّق على كل صورة في الدفعة. إذا كانت كتلة النص المرسومة أطول من مساحة الصورة المتاحة، يتم تقليل حجم الخط تلقائيًا حتى يتناسب أو يصل إلى الحد الأدنى للحجم.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `images` | الصور المدخلة مع تركيب التراكب النصي فوقها | IMAGE |
