# הוספת טקסט על גבי תמונה

צומת זה מצייר טקסט על גבי תמונה בודדת או על קבוצת תמונות. הוא יוצר שכבת טקסט עליונה תוך שימוש בגודל גופן, צבע, מיקום אנכי, יישור אופקי ומסגרת שחורה אופציונלית הניתנים להגדרה, ולאחר מכן משלב את השכבה עם פיקסלי התמונה המקורית.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `images` | תמונת הקלט או קבוצת התמונות עליהן לצייר טקסט | IMAGE | כן | |
| `text` | הטקסט לשכבה על גבי התמונה (ברירת מחדל: ""). תומך במספר שורות: רצפי הבריחה `\n` ו-`\t` מומרים לשורות חדשות ולטאבים, ושורות ארוכות נשברות אוטומטית כך שיתאימו לרוחב התמונה. | STRING | כן | |
| `font_size` | גודל הגופן כאחוז מגובה התמונה (ברירת מחדל: 5.0) | FLOAT | כן | 0.5 עד 50.0 (צעד 0.5) |
| `color` | צבע הטקסט (ברירת מחדל: "#ffffff") | COLOR | כן | |
| `position` | המיקום האנכי של הטקסט בתמונה (ברירת מחדל: "top") | COMBO | כן | "top"<br>"bottom" |
| `align` | היישור האופקי של הטקסט (ברירת מחדל: "left") | COMBO | כן | "left"<br>"center"<br>"right" |
| `outline` | ציור מסגרת שחורה סביב הטקסט (ברירת מחדל: True) | BOOLEAN | כן | |

הערה: אם `text` ריק או מכיל רווחים לבנים בלבד, הצומת מחזיר את תמונות הקלט ללא שינוי. שכבת הטקסט מעובדת פעם אחת ומיושמת על כל תמונה בקבוצה. אם גוש הטקסט המעובד גבוה מהאזור הזמין בתמונה, גודל הגופן מוקטן אוטומטית עד שהוא מתאים או מגיע לגודל מינימלי.
