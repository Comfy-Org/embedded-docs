# افزودن متن به تصویر

این گره متن را روی یک تصویر یا دسته‌ای از تصاویر رسم می‌کند. این گره با استفاده از اندازه قلم، رنگ، موقعیت عمودی، ترازبندی افقی و حاشیه مشکی اختیاری قابل‌تنظیم، یک هم‌گذاری متنی می‌سازد و سپس آن را با پیکسل‌های تصویر اصلی ترکیب می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | تصویر ورودی یا دسته‌ای از تصاویر برای رسم متن روی آن‌ها | IMAGE | بله | |
| `متن` | متنی که باید روی تصویر هم‌گذاری شود (پیش‌فرض: ""). از چند خط پشتیبانی می‌کند: دنباله‌های فرار `\n` و `\t` به خط جدید و تب تبدیل می‌شوند، و خطوط بلند به‌صورت خودکار برای جا شدن در عرض تصویر شکسته می‌شوند. | STRING | بله | |
| `اندازه فونت` | اندازه قلم به‌عنوان درصدی از ارتفاع تصویر (پیش‌فرض: 5.0) | FLOAT | بله | 0.5 تا 50.0 (گام 0.5) |
| `رنگ` | رنگ متن (پیش‌فرض: "#ffffff") | COLOR | بله | |
| `موقعیت` | موقعیت عمودی متن روی تصویر (پیش‌فرض: "top") | COMBO | بله | "top"<br>"bottom" |
| `تراز` | ترازبندی افقی متن (پیش‌فرض: "left") | COMBO | بله | "left"<br>"center"<br>"right" |
| `حاشیه` | رسم حاشیه مشکی دور متن (پیش‌فرض: True) | BOOLEAN | بله | |

نکته: اگر `text` خالی باشد یا فقط شامل کاراکترهای فاصله باشد، گره تصاویر ورودی را بدون تغییر برمی‌گرداند. هم‌گذاری متن یک‌بار رندر می‌شود و روی هر تصویر در دسته اعمال می‌گردد. اگر بلوک متن رندرشده از ناحیه موجود تصویر بلندتر باشد، اندازه قلم به‌صورت خودکار کاهش می‌یابد تا جا شود یا به حداقل اندازه برسد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `images` | تصاویر ورودی با هم‌گذاری متن ترکیب‌شده روی آن‌ها | IMAGE |
