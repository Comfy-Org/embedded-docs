# 繪製文字覆蓋

此節點會在影像或一批影像上方繪製文字。它會使用可設定的字型大小、顏色、垂直位置、水平對齊方式，以及選用的黑色外框來建立文字疊加層，然後將疊加層與原始影像像素合併。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `圖片` | 要繪製文字的輸入影像或一批影像 | IMAGE | 是 | |
| `文字` | 要疊加在影像上的文字（預設值：""）。支援多行：`\n` 和 `\t` 逸出序列會轉換為換行與定位字元，且過長的行會自動換行以符合影像寬度。 | STRING | 是 | |
| `字型大小` | 以影像高度百分比表示的字型大小（預設值：5.0） | FLOAT | 是 | 0.5 至 50.0 （步進值：0.5） |
| `顏色` | 文字的顏色（預設值："#ffffff"） | COLOR | 是 | |
| `位置` | 文字在影像上的垂直位置（預設值："top"） | COMBO | 是 | "top"<br>"bottom" |
| `對齊` | 文字的水平對齊方式（預設值："left"） | COMBO | 是 | "left"<br>"center"<br>"right" |
| `外框` | 在文字周圍繪製黑色外框（預設值：True） | BOOLEAN | 是 | |

注意：如果 `text` 為空或僅包含空白，節點會原樣回傳輸入影像。文字疊加層只會渲染一次，並套用至批次中的每張影像。如果渲染出的文字區塊高於可用的影像區域，字型大小會自動縮小，直到能放入或達到最小尺寸為止。
