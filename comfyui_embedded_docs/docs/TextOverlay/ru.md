# Наложение текста

Этот узел наносит текст поверх изображения или пакета изображений. Он создаёт текстовое наложение с настраиваемым размером шрифта, цветом, вертикальным положением, горизонтальным выравниванием и необязательной чёрной обводкой, а затем объединяет наложение с исходными пикселями изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Входное изображение или пакет изображений, на которые нужно нанести текст | IMAGE | Да | |
| `текст` | Текст для наложения на изображение (по умолчанию: ""). Поддерживает несколько строк: escape-последовательности `\n` и `\t` преобразуются в переносы строк и табуляции, а длинные строки автоматически переносятся, чтобы уместиться в ширину изображения. | STRING | Да | |
| `размер_шрифта` | Размер шрифта в процентах от высоты изображения (по умолчанию: 5.0) | FLOAT | Да | от 0.5 до 50.0 (шаг 0.5) |
| `цвет` | Цвет текста (по умолчанию: "#ffffff") | COLOR | Да | |
| `позиция` | Вертикальное положение текста на изображении (по умолчанию: "top") | COMBO | Да | "top"<br>"bottom" |
| `выравнивание` | Горизонтальное выравнивание текста (по умолчанию: "left") | COMBO | Да | "left"<br>"center"<br>"right" |
| `контур` | Рисовать чёрную обводку вокруг текста (по умолчанию: True) | BOOLEAN | Да | |

Примечание: Если `text` пуст или содержит только пробельные символы, узел возвращает входные изображения без изменений. Текстовое наложение отрисовывается один раз и применяется к каждому изображению в пакете. Если отрисованный текстовый блок выше доступной области изображения, размер шрифта автоматически уменьшается, пока он не поместится или не достигнет минимального размера.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Входные изображения с наложенным поверх текстом | IMAGE |
