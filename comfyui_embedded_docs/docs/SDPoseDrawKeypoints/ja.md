# SDPoseDrawKeypoints

SDPoseDrawKeypoints ノードは、ポーズ推定データ（キーポイント）を受け取り、空白のキャンバス上に視覚的なスケルトンとして描画します。このノードを使用すると、体、頭、手、顔、足など、ポーズのさまざまな部分を選択的に描画でき、線の太さや点のサイズもカスタマイズできます。生成された画像は、可視化や、ポーズ画像を必要とする他のノードへの入力として使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `keypoints` | 描画するポーズキーポイントデータ。このデータは通常、ポーズ検出ノードから取得されます。 | POSE_KEYPOINT | はい | - |
| `draw_body` | 主要なボディスケルトンを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `draw_hands` | 手のキーポイントを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `draw_face` | 顔のキーポイントを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `draw_feet` | 足のキーポイントを描画するかどうかを制御します（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `stick_width` | ボディスケルトンの描画に使用する線の太さ（デフォルト: 4）。 | INT | いいえ | 1 to 10 |
| `face_point_size` | 顔のキーポイントを描画するための点のサイズ（デフォルト: 3）。 | INT | いいえ | 1 to 10 |
| `score_threshold` | キーポイントが描画されるために必要な最小信頼スコア。この値未満のスコアのキーポイントは無視されます（デフォルト: 0.3）。 | FLOAT | いいえ | 0.0 to 1.0 |
| `draw_head` | 頭部のキーポイント（鼻、目、耳）と頭部の接続を描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |

**注:** `keypoints` 入力が空または `None` の場合、ノードは空白の 64x64 画像を出力します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 描画されたポーズキーポイントを含む画像。画像の寸法は、入力キーポイントデータで指定された `canvas_height` および `canvas_width` と一致します。 | IMAGE |
