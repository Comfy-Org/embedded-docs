# SDPoseDrawKeypoints

Узел SDPoseDrawKeypoints принимает данные оценки позы (ключевые точки) и отображает их в виде визуального скелета на пустом холсте. Он позволяет выборочно отрисовывать различные части позы, такие как тело, голова, руки, лицо и ноги, с настраиваемой шириной линий и размером точек. Полученное изображение можно использовать для визуализации или как входные данные для других узлов, которым требуется изображение позы.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `keypoints` | Данные ключевых точек позы для отрисовки. Обычно эти данные поступают от узла обнаружения позы. | POSE_KEYPOINT | Да | - |
| `draw_body` | Управляет отрисовкой основного скелета тела (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_hands` | Управляет отрисовкой ключевых точек рук (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_face` | Управляет отрисовкой ключевых точек лица (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_feet` | Управляет отрисовкой ключевых точек ног (по умолчанию: False). | BOOLEAN | Нет | - |
| `stick_width` | Ширина линий, используемых для отрисовки скелета тела (по умолчанию: 4). | INT | Нет | 1 to 10 |
| `face_point_size` | Размер точек, используемых для отрисовки ключевых точек лица (по умолчанию: 3). | INT | Нет | 1 to 10 |
| `score_threshold` | Минимальный порог уверенности, который должна иметь ключевая точка, чтобы быть отрисованной. Ключевые точки с оценкой ниже этого значения игнорируются (по умолчанию: 0.3). | FLOAT | Нет | 0.0 to 1.0 |
| `draw_head` | Управляет отрисовкой ключевых точек головы (нос, глаза, уши) и соединений головы (по умолчанию: True). | BOOLEAN | Нет | - |

**Примечание:** Если входной параметр `keypoints` пуст или равен `None`, узел выведет пустое изображение размером 64x64.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изображение с отрисованными ключевыми точками позы. Размеры изображения соответствуют значениям `canvas_height` и `canvas_width`, указанным во входных данных ключевых точек. | IMAGE |
