# SDPoseDrawKeypoints

Узел SDPoseDrawKeypoints принимает данные оценки позы (ключевые точки) и отображает их в виде визуального скелета на пустом холсте. Он позволяет выборочно отрисовывать различные части позы — тело, голову, руки, лицо и ступни — с настраиваемой толщиной линий и размером точек. Полученное изображение можно использовать для визуализации или в качестве входных данных для других узлов, которым требуется изображение позы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `keypoints` | Данные ключевых точек позы для отрисовки. Обычно поступают из узла обнаружения позы и могут содержать один или несколько кадров. | POSE_KEYPOINT | Да | - |
| `draw_body` | Управляет отрисовкой основного скелета тела (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_hands` | Управляет отрисовкой ключевых точек рук (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_face` | Управляет отрисовкой ключевых точек лица (по умолчанию: True). | BOOLEAN | Нет | - |
| `draw_feet` | Управляет отрисовкой ключевых точек ступней (по умолчанию: False). | BOOLEAN | Нет | - |
| `stick_width` | Ширина линий, используемых для отрисовки скелета тела и головы (по умолчанию: 4). | INT | Нет | 1 до 10 |
| `face_point_size` | Размер точек, используемых для отрисовки ключевых точек лица (по умолчанию: 3). | INT | Нет | 1 до 10 |
| `score_threshold` | Минимальный порог уверенности, необходимый для отрисовки ключевой точки. Точки со значением ниже этого порога игнорируются (по умолчанию: 0.3). | FLOAT | Нет | 0.0 до 1.0 |
| `рисовать_голову` | Управляет отрисовкой ключевых точек головы (нос, глаза, уши) (по умолчанию: True). | BOOLEAN | Нет | - |

**Примечание:** Если вход `keypoints` пуст или равен `None`, узел выведет пустое изображение 64x64.

**Примечание:** `draw_body` и `draw_head` работают независимо. Если `draw_head` отключён, ключевые точки головы не отрисовываются, даже если `draw_body` включён. Если `draw_body` отключён, но `draw_head` включён, отрисовываются только ключевые точки головы и точка шеи. Если оба параметра отключены, ключевые точки тела и головы не отрисовываются.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Изображение с отрисованными ключевыми точками позы. Размер изображения соответствует значениям `canvas_height` и `canvas_width`, указанным во входных данных ключевых точек. Если входные данные содержат несколько кадров, возвращается пакет изображений. | IMAGE |
