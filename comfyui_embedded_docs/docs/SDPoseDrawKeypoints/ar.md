# SDPoseDrawKeypoints

تستقبل عقدة SDPoseDrawKeypoints بيانات تقدير الوضعية (النقاط الرئيسية) وترسمها كهيكل عظمي مرئي على لوحة فارغة. وهي تتيح لك رسم أجزاء مختلفة من الوضعية بشكل انتقائي، مثل الجسم والرأس واليدين والوجه والقدمين، مع إمكانية تخصيص عرض الخطوط وأحجام النقاط. ويمكن استخدام الصورة الناتجة للعرض المرئي أو كمدخل لعقد أخرى تتطلب صورة وضعية.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `النقاط الرئيسية` | بيانات النقاط الرئيسية للوضعية التي سيتم رسمها. تأتي هذه البيانات عادةً من عقدة كشف الوضعية ويمكن أن تحتوي على إطار واحد أو أكثر. | POSE_KEYPOINT | نعم | - |
| `رسم الجسم` | يتحكم في ما إذا كان يتم رسم الهيكل العظمي للجسم (الافتراضي: True). | BOOLEAN | لا | - |
| `رسم اليدين` | يتحكم في ما إذا كان يتم رسم نقاط اليدين (الافتراضي: True). | BOOLEAN | لا | - |
| `رسم الوجه` | يتحكم في ما إذا كان يتم رسم نقاط الوجه (الافتراضي: True). | BOOLEAN | لا | - |
| `رسم القدمين` | يتحكم في ما إذا كان يتم رسم نقاط القدمين (الافتراضي: False). | BOOLEAN | لا | - |
| `عرض الخط` | عرض الخطوط المستخدمة لرسم الهيكل العظمي للجسم والرأس (الافتراضي: 4). | INT | لا | 1 إلى 10 |
| `حجم نقطة الوجه` | حجم النقاط المستخدمة لرسم نقاط الوجه (الافتراضي: 3). | INT | لا | 1 إلى 10 |
| `عتبة الدرجات` | الحد الأدنى لدرجة الثقة التي يجب أن تحققها النقطة الرئيسية حتى يتم رسمها. يتم تجاهل النقاط ذات الدرجات الأقل من هذه القيمة (الافتراضي: 0.3). | FLOAT | لا | 0.0 إلى 1.0 |
| `رسم الرأس` | يتحكم في ما إذا كان يتم رسم نقاط الرأس (الأنف والعينين والأذنين) (الافتراضي: True). | BOOLEAN | لا | - |

**ملاحظة:** إذا كان مدخل `keypoints` فارغًا أو يساوي `None`، فستقوم العقدة بإخراج صورة فارغة بحجم 64×64.

**ملاحظة:** يعمل `draw_body` و`draw_head` بشكل مستقل. عند تعطيل `draw_head`، لا يتم رسم نقاط الرأس حتى إذا كان `draw_body` مفعّلاً. عند تعطيل `draw_body` مع تفعيل `draw_head`، يتم رسم نقاط الرأس ونقطة الرقبة فقط. إذا تم تعطيل كلاهما، فلن يتم رسم أي نقاط للجسم أو الرأس.
