# RecraftTextToImageNode

יוצר תמונות באופן סינכרוני בהתבסס על פרומפט ורזולוציה. צומת זה מתחבר ל-API של Recraft כדי ליצור תמונות מתיאורי טקסט עם מידות מוגדרות ופרמטרי סגנון ובקרה אופציונליים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט ליצירת התמונה. (ברירת מחדל: "") | STRING | כן | 1-1000 תווים |
| `size` | גודל התמונה שנוצרה. (ברירת מחדל: "1024x1024") | COMBO | כן | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | מספר התמונות ליצירה. (ברירת מחדל: 1) | INT | כן | 1-6 |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-Seed. (ברירת מחדל: 0) | INT | כן | 0-18446744073709551615 |
| `recraft_style` | בחירת סגנון אופציונלית ליצירת תמונה. כאשר לא מסופקת, ברירת המחדל היא סגנון "realistic_image". | RECRAFT_STYLE | לא | אפשרויות מרובות זמינות |
| `negative_prompt` | תיאור טקסט אופציונלי של אלמנטים לא רצויים בתמונה. (ברירת מחדל: "") | STRING | לא | - |
| `recraft_controls` | בקרות נוספות אופציונליות על היצירה באמצעות צומת Recraft Controls. | RECRAFT_CONTROLS | לא | אפשרויות מרובות זמינות |

**הערה:** הפרמטר `seed` קובע רק מתי הצומת ירוץ מחדש, אך אינו הופך את יצירת התמונה לדטרמיניסטית. התמונות שייווצרו בפועל ישתנו גם עם אותו ערך Seed.

**הערה:** הפרמטר `prompt` חייב להיות באורך שבין 1 ל-1000 תווים.

**הערה:** אם אתה משתמש ב-`style_id` מ-Infinite Style Library, ודא שהוא אינו סגנון Vector art, מכיוון שהדבר יחזיר נתוני SVG במקום תמונה ויגרום לשגיאה.

**הערה:** זהו צומת API בתשלום. העלות היא $0.0572 לכל תמונה שנוצרת, בהתבסס על הערך של `n`.
