# تبدیل متن به تصویر Recraft

تصاویر را به‌صورت همزمان بر اساس پرامپت و وضوح (resolution) تولید می‌کند. این گره به API سرویس Recraft متصل می‌شود تا تصاویر را از روی توضیحات متنی با ابعاد مشخص و پارامترهای اختیاری سبک و کنترل ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `prompt` | پرامپت تولید تصویر. (پیش‌فرض: "") | STRING | بله | - |
| `size` | اندازه تصویر تولیدشده. (پیش‌فرض: "1024x1024") | COMBO | بله | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | تعداد تصاویر برای تولید. (پیش‌فرض: 1) | INT | بله | 1-6 |
| `seed` | مقدار seed برای تعیین اینکه گره دوباره اجرا شود یا نه؛ نتایج واقعی بدون توجه به seed قطعی نیستند. (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب اختیاری سبک برای تولید تصویر. وقتی ارائه نشود، به‌صورت پیش‌فرض از سبک تصویر واقع‌گرایانه استفاده می‌شود. | RECRAFT_STYLE | خیر | چند گزینه در دسترس |
| `negative_prompt` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر. (پیش‌فرض: "") | STRING | خیر | - |
| `recraft_controls` | کنترل‌های اختیاری اضافی برای تولید از طریق گره Recraft Controls. | RECRAFT_CONTROLS | خیر | چند گزینه در دسترس |

**توجه:** پارامتر `seed` فقط تعیین می‌کند که گره چه زمانی دوباره اجرا شود، اما تولید تصویر را قطعی نمی‌کند. تصاویر خروجی واقعی حتی با مقدار seed یکسان نیز متفاوت خواهند بود.

**توجه:** پارامتر `prompt` باید طولی بین ۱ تا ۱۰۰۰ کاراکتر داشته باشد.

**توجه:** اگر از `style_id` از کتابخانه بی‌نهایت سبک (Infinite Style Library) استفاده می‌کنید، مطمئن شوید که سبک وکتور (Vector art) نباشد، زیرا این کار داده SVG را به‌جای تصویر برمی‌گرداند و باعث خطا می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) تولیدشده به‌صورت خروجی تنسور دسته‌ای (batched). وقتی چند تصویر تولید می‌شود (n > 1)، آن‌ها در امتداد بعد دسته (batch) به هم می‌پیوندند. | IMAGE |
