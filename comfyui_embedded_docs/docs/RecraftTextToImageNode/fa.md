# تبدیل متن به تصویر Recraft

تصاویر را به‌صورت همزمان بر اساس دستور متنی و وضوح تولید می‌کند. این گره به Recraft API متصل می‌شود تا از توضیحات متنی با ابعاد مشخص و پارامترهای اختیاری سبک و کنترل، تصویر بسازد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | دستور متنی برای تولید تصویر. (پیش‌فرض: "") | STRING | بله | - |
| `اندازه` | اندازه تصویر تولیدشده. (پیش‌فرض: "1024x1024") | COMBO | بله | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `تعداد` | تعداد تصاویری که باید تولید شود. (پیش‌فرض: 1) | INT | بله | 1-6 |
| `seed` | Seed برای تعیین اینکه آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed قطعی نیستند. (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب سبک اختیاری برای تولید تصویر. وقتی ارائه نشود، به‌طور پیش‌فرض از سبک "realistic_image" استفاده می‌شود. | RECRAFT_STYLE | خیر | چند گزینه موجود است |
| `پرامپت منفی` | توضیح متنی اختیاری درباره عناصر نامطلوب در تصویر. (پیش‌فرض: "") | STRING | خیر | - |
| `recraft_controls` | کنترل‌های اضافی اختیاری روی تولید از طریق گره Recraft Controls. | RECRAFT_CONTROLS | خیر | چند گزینه موجود است |

**توجه:** پارامتر `seed` فقط کنترل می‌کند که گره چه زمانی دوباره اجرا شود، اما تولید تصویر را قطعی نمی‌کند. تصاویر خروجی واقعی حتی با همان مقدار seed نیز متفاوت خواهند بود.

**توجه:** پارامتر `prompt` باید بین 1 تا 1000 نویسه طول داشته باشد.

**توجه:** اگر از `style_id` از کتابخانه Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک از نوع Vector art نباشد، زیرا این کار داده SVG را به جای تصویر برمی‌گرداند و باعث خطا می‌شود.

**توجه:** این یک گره API پولی است. هزینه هر تصویر تولیدشده ۰٫۰۴ دلار است و بر اساس مقدار `n` محاسبه می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر(های) تولیدشده به‌صورت خروجی تنسور دسته‌ای. وقتی چند تصویر تولید می‌شود (n > 1)، آن‌ها در امتداد بعد دسته به هم متصل می‌شوند. | IMAGE |
