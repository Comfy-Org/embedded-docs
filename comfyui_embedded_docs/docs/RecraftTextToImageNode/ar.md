# إعادة صياغة نص إلى صورة

يولّد الصور بشكل متزامن بناءً على النص الموجّه (prompt) والدقة. تتصل هذه العقدة بواجهة برمجة تطبيقات Recraft لإنشاء صور من أوصاف نصية بأبعاد محددة ومعلمات نمط وتحكم اختيارية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | النص الموجّه لتوليد الصورة. (الافتراضي: "") | STRING | نعم | - |
| `size` | حجم الصورة المولّدة. (الافتراضي: "1024x1024") | COMBO | نعم | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | عدد الصور المراد توليدها. (الافتراضي: 1) | INT | نعم | 1-6 |
| `seed` | البذرة (seed) لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بغض النظر عن قيمة البذرة. (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `recraft_style` | اختيار نمط اختياري لتوليد الصورة. عندما لا يتم توفيره، يتم استخدام نمط الصورة الواقعي افتراضيًا. | RECRAFT_STYLE | لا | تتوفر خيارات متعددة |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة. (الافتراضي: "") | STRING | لا | - |
| `recraft_controls` | تحكمات إضافية اختيارية في التوليد عبر عقدة Recraft Controls. | RECRAFT_CONTROLS | لا | تتوفر خيارات متعددة |

**ملاحظة:** تتحكم معاملة `seed` فقط في موعد إعادة تشغيل العقدة، لكنها لا تجعل توليد الصورة حتميًا. ستختلف الصور الفعلية الناتجة حتى مع نفس قيمة البذرة.

**ملاحظة:** يجب أن يتراوح طول معامل `prompt` بين 1 و1000 حرف.

**ملاحظة:** إذا كنت تستخدم `style_id` من مكتبة الأنماط اللانهائية (Infinite Style Library)، فتأكد من أنه ليس نمط فن المتجهات (Vector art)، لأن ذلك سيعيد بيانات SVG بدلاً من صورة ويسبب خطأ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
