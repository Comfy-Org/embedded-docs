# Recraft: текст в изображение

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Запрос для генерации изображения. (по умолчанию: "") | STRING | Да | - |
| `size` | Размер генерируемого изображения. (по умолчанию: "1024x1024") | COMBO | Да | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | Количество изображений для генерации. (по умолчанию: 1) | INT | Да | 1-6 |
| `seed` | Сид, определяющий, должен ли узел выполняться заново; фактические результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерации изображения. Если не указан, по умолчанию используется стиль "realistic_image". | RECRAFT_STYLE | Нет | Доступно несколько вариантов |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении. (по умолчанию: "") | STRING | Нет | - |
| `recraft_controls` | Необязательные дополнительные параметры управления генерацией через узел Recraft Controls. | RECRAFT_CONTROLS | Нет | Доступно несколько вариантов |

**Примечание:** Параметр `seed` управляет только тем, когда узел выполняется заново, но не делает генерацию изображений детерминированной. Фактические выходные изображения будут различаться даже при одинаковом значении seed.

**Примечание:** Параметр `prompt` должен содержать от 1 до 1000 символов.

**Примечание:** Если вы используете `style_id` из Infinite Style Library, убедитесь, что это не стиль Vector art, так как в этом случае вместо изображения будут возвращены SVG-данные, что приведёт к ошибке.

**Примечание:** Это платный API-узел. Стоимость составляет $0.04 за одно сгенерированное изображение, исходя из значения `n`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение(я) в виде пакетного тензора. Если генерируется несколько изображений (n > 1), они объединяются по размерности пакета. | IMAGE |
