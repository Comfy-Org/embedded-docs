# Recraft 文字轉圖像

根據提示詞和解析度同步生成影像。此節點連接到 Recraft API，以指定的尺寸以及可選的樣式和控制參數，從文字描述建立影像。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 影像生成的提示詞。(預設值："") | STRING | 是 | - |
| `尺寸` | 生成影像的尺寸。(預設值："1024x1024") | COMBO | 是 | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `數量` | 要生成的影像數量。(預設值：1) | INT | 是 | 1-6 |
| `種子` | 決定節點是否應重新執行的種子值；無論種子值為何，實際結果都是非確定性的。(預設值：0) | INT | 是 | 0-18446744073709551615 |
| `recraft_style` | 影像生成的可選樣式選擇。未提供時，預設為 "realistic_image" 樣式。 | RECRAFT_STYLE | 否 | 提供多種選項 |
| `負向提示詞` | 影像上不希望出現之元素的選用文字描述。(預設值："") | STRING | 否 | - |
| `Recraft 控制` | 透過 Recraft Controls 節點對生成過程進行的選用額外控制。 | RECRAFT_CONTROLS | 否 | 提供多種選項 |

**注意：**`seed` 參數僅控制節點重新執行的時機，不會使影像生成具有確定性。即使使用相同的種子值，實際輸出的影像也會有所不同。

**注意：**`prompt` 參數的長度必須介於 1 到 1000 個字元之間。

**注意：**如果您使用 Infinite Style Library 中的 `style_id`，請確保它不是向量藝術（Vector art）樣式，因為這會回傳 SVG 資料而非影像，並導致錯誤。

**注意：**這是一個付費 API 節點。每個生成影像的費用為 $0.04 美元，取決於 `n` 值。
