# Recraft 文字轉圖像

根據提示和解析度同步生成影像。此節點連線至 Recraft API，可從文字描述建立影像，並指定尺寸以及可選的樣式和控制參數。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 影像生成的提示。（預設：""） | STRING | 是 | - |
| `size` | 生成影像的尺寸。（預設："1024x1024"） | COMBO | 是 | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | 要生成的影像數量。（預設：1） | INT | 是 | 1-6 |
| `seed` | 用於判斷節點是否應重新執行的種子；無論種子為何，實際結果皆非確定性。（預設：0） | INT | 是 | 0-18446744073709551615 |
| `recraft_style` | 影像生成的選用樣式選擇。若未提供，則預設為寫實影像樣式。 | RECRAFT_STYLE | 否 | 有多個選項可用 |
| `negative_prompt` | 影像上不希望出現元素的選用文字描述。（預設：""） | STRING | 否 | - |
| `recraft_controls` | 透過 Recraft Controls 節點對生成進行的選用額外控制。 | RECRAFT_CONTROLS | 否 | 有多個選項可用 |

**注意：**`seed` 參數僅控制節點重新執行的時機，並不會使影像生成具有確定性。即使使用相同的種子值，實際輸出的影像也會有所不同。

**注意：**`prompt` 參數的長度必須介於 1 到 1000 個字元之間。

**注意：**如果您使用來自 Infinite Style Library 的 `style_id`，請確保它不是向量藝術樣式，因為這會回傳 SVG 資料而非影像，並導致錯誤。
