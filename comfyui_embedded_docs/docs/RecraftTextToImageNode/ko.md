# Recraft 이미지 생성 (텍스트 → 이미지)

프롬프트와 해상도를 기반으로 이미지를 동기적으로 생성합니다. 이 노드는 Recraft API에 연결하여 지정된 크기와 선택적 스타일 및 제어 매개변수를 사용해 텍스트 설명에서 이미지를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 이미지 생성을 위한 프롬프트입니다. (기본값: "") | STRING | 예 | - |
| `size` | 생성된 이미지의 크기입니다. (기본값: "1024x1024") | COMBO | 예 | "1024x1024"<br>"1152x896"<br>"896x1152"<br>"1216x832"<br>"832x1216"<br>"1344x768"<br>"768x1344"<br>"1536x640"<br>"640x1536" |
| `n` | 생성할 이미지 수입니다. (기본값: 1) | INT | 예 | 1-6 |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 무관하게 비결정적입니다. (기본값: 0) | INT | 예 | 0-18446744073709551615 |
| `recraft_style` | 이미지 생성을 위한 선택적 스타일 선택입니다. 제공되지 않으면 사실적인 이미지 스타일로 기본 설정됩니다. | RECRAFT_STYLE | 아니오 | 여러 옵션 사용 가능 |
| `negative_prompt` | 이미지에서 원치 않는 요소에 대한 선택적 텍스트 설명입니다. (기본값: "") | STRING | 아니오 | - |
| `recraft_controls` | Recraft Controls 노드를 통한 생성에 대한 선택적 추가 제어입니다. | RECRAFT_CONTROLS | 아니오 | 여러 옵션 사용 가능 |

**참고:** `seed` 매개변수는 노드가 재실행되는 시점만 제어하며 이미지 생성을 결정적으로 만들지는 않습니다. 동일한 시드 값을 사용하더라도 실제 출력 이미지는 달라질 수 있습니다.

**참고:** `prompt` 매개변수의 길이는 1자 이상 1000자 이하여야 합니다.

**참고:** Infinite Style Library의 `style_id`를 사용하는 경우 해당 스타일이 벡터 아트 스타일이 아닌지 확인하시기 바랍니다. 벡터 아트 스타일인 경우 이미지 대신 SVG 데이터가 반환되어 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지를 배치 텐서 출력으로 제공합니다. 여러 이미지가 생성되는 경우(n > 1) 배치 차원을 따라 연결됩니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/RecraftTextToImageNode/ko.md)
