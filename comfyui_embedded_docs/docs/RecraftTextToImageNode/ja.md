# Recraft テキストから画像へ

プロンプトと解像度に基づいて画像を同期的に生成します。このノードは Recraft API に接続し、指定された寸法とオプションのスタイル・コントロールパラメータを使用して、テキスト記述から画像を作成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 画像生成のプロンプトです。（デフォルト: `""`） | STRING | はい | - |
| `size` | 生成される画像のサイズです。（デフォルト: `"1024x1024"`） | COMBO | はい | `"1024x1024"`<br>`"1152x896"`<br>`"896x1152"`<br>`"1216x832"`<br>`"832x1216"`<br>`"1344x768"`<br>`"768x1344"`<br>`"1536x640"`<br>`"640x1536"` |
| `n` | 生成する画像の数です。（デフォルト: `1`） | INT | はい | 1-6 |
| `seed` | ノードを再実行するかどうかを決定するシードです。実際の結果はシードに関係なく非決定的です。（デフォルト: `0`） | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 画像生成のためのオプションのスタイル選択です。指定しない場合、リアルな画像スタイルがデフォルトになります。 | RECRAFT_STYLE | いいえ | 複数のオプションがあります |
| `negative_prompt` | 画像上に望ましくない要素のオプションのテキスト説明です。（デフォルト: `""`） | STRING | いいえ | - |
| `recraft_controls` | Recraft Controls ノードによる生成へのオプションの追加コントロールです。 | RECRAFT_CONTROLS | いいえ | 複数のオプションがあります |

**注記:** `seed` パラメータはノードが再実行されるタイミングのみを制御し、画像生成を決定的にしません。同じシード値でも、実際の出力画像は変動します。

**注記:** `prompt` パラメータの長さは 1 文字以上 1000 文字以下である必要があります。

**注記:** Infinite Style Library の `style_id` を使用する場合、Vector アートスタイルではないことを確認してください。Vector アートスタイルの場合は、画像の代わりに SVG データが返され、エラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成された画像を、バッチテンソル出力として返します。複数の画像が生成された場合（`n` > 1）、バッチ次元に沿って連結されます。 | IMAGE |
