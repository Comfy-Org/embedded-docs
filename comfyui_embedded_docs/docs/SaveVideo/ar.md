# حفظ الفيديو

عقدة `SaveVideo` تحفظ فيديو الإدخال في دليل الإخراج الخاص بـ ComfyUI. تتيح لك اختيار بادئة اسم الملف، وتنسيق الفيديو، وبرنامج الترميز، وتقوم تلقائيًا بإنشاء اسم ملف فريد عن طريق إضافة عداد. افتراضيًا، تخزن العقدة أيضًا بيانات وصفية لسير العمل في الفيديو المحفوظ.

## المدخلات

### المدخلات الشائعة

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `codec` | الترميز الذي سيُستخدم للفيديو. اختيار `h264` يُظهر خيارات ترميز إضافية (الافتراضي: "auto"). | DYNAMIC_COMBO | Yes | "auto"<br>"h264" |
| `video` | الفيديو المراد حفظه. | VIDEO | Yes | - |
| `filename_prefix` | بادئة اسم الملف المراد حفظه. قد تتضمن معلومات تنسيق مثل `%date:yyyy-MM-dd%` أو `%Empty Latent Image.width%` لتضمين قيم من العقد (الافتراضي: "video/ComfyUI"). | STRING | Yes | - |
| `format` | التنسيق الذي سيُحفظ به الفيديو. يحدد امتداد الملف للفيديو المحفوظ (الافتراضي: "auto"). | COMBO | Yes | "auto"<br>"mp4"<br>"webm"<br>"mkv"<br>"gif" |

### مدخلات h264

تظهر هذه المدخلات عندما يتم تعيين `codec` إلى `h264`.

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `encoding` | وضع الترميز لـ H.264. يحافظ الخيار التلقائي على تدفقات H.264 المتوافقة. يطبق "إعادة الترميز" قيمة CRF مخصصة (الافتراضي: "auto"). | DYNAMIC_COMBO | No | "auto"<br>"re-encode" |
| `crf` | القيم الأقل تنتج جودة أعلى وملفات أكبر. متاح فقط عندما يتم تعيين `encoding` إلى `re-encode` (الافتراضي: 23.0). | FLOAT | Yes (only when `encoding` is `re-encode`) | 0.0 to 51.0 (step: 1.0) |

ملاحظة: إذا كانت `filename_prefix` تتضمن مجلدات، على سبيل المثال `video/ComfyUI`، فسيتم حفظ الفيديو داخل ذلك المجلد الفرعي من دليل الإخراج. يُنشأ اسم الملف من البادئة مع عداد مضاف، على سبيل المثال `ComfyUI_00001_.mp4`، لذلك لا يتم استبدال الملفات الموجودة.

ملاحظة: عند تمكين البيانات الوصفية، تقوم العقدة بتضمين موجه سير العمل والبيانات الوصفية الإضافية في الفيديو المحفوظ. يمكن تعطيل البيانات الوصفية عن طريق تشغيل ComfyUI مع الوسيط `--disable-metadata`.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `video` | الفيديو الذي تم حفظه، وهو نفسه من الإدخال. | VIDEO |
| `ui` | معاينة لملف الفيديو المحفوظ، بما في ذلك مسار الملف ومعلومات المجلد الفرعي للعرض في الواجهة. | PREVIEW_VIDEO |
