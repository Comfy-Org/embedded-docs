# Сохранить видео

Узел Save Video сохраняет входное видео в ваш выходной каталог ComfyUI. Вы можете выбрать префикс имени файла, формат контейнера, видеокодек и параметры кодирования, такие как качество. Узел автоматически генерирует уникальное имя файла с помощью счётчика и может встраивать метаданные рабочего процесса в сохраняемый файл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `видео` | Видео для сохранения. | VIDEO | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может включать информацию форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для подстановки значений из узлов (по умолчанию: `video/ComfyUI`). | STRING | Да | - |
| `формат` | Выходной контейнер. Авто использует MP4 для Auto/H.264 и WebM для AV1. MP4, MKV и WebM выбирают конкретный контейнер. Выбор формата также определяет, какие параметры кодека доступны (по умолчанию: `auto`). | DYNAMIC_COMBO | Да | `"auto"`<br>`"mp4"`<br>`"mkv"`<br>`"webm"` |
| `кодек` | Выходной видеокодек. Авто сохраняет совместимый исходный поток. Перекодирование H.264 и AV1 поддерживает SDR, HDR (HLG) и HDR PQ. Появляется после выбора формата (по умолчанию: `auto`). | DYNAMIC_COMBO | Нет | `"auto"`<br>`"h264"`<br>`"av1"` |

### Входы H.264

Эти входы появляются, когда `codec` имеет значение `"h264"`, и доступны с форматами `auto`, `mp4` и `mkv`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Автоматический режим сохраняет совместимые потоки H.264. Перекодирование применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 23.0). | FLOAT | Нет | от 0.0 до 51.0 |

### Входы AV1

Эти входы появляются, когда `codec` имеет значение `"av1"`, и доступны с форматами `auto`, `mp4`, `mkv` и `webm`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Автоматический режим сохраняет совместимые потоки AV1. Перекодирование применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 30.0). | FLOAT | Нет | от 0.0 до 63.0 |

Примечание. Когда `format` имеет значение `"auto"`, сохраняемый контейнер выбирается автоматически: `av1` создает WebM, а `auto` и `h264` — MP4. Формат `webm` допускает только кодеки `auto` и `av1`. Когда `codec` имеет значение `"auto"`, исходный видеопоток сохраняется без перекодирования. Сохраняемый файл использует счётчик в суффиксе, чтобы избежать перезаписи существующих файлов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `видео` | Входное видео без изменений. | VIDEO |
| `ui` | Предварительный просмотр сохранённого видеофайла, включая путь к файлу и информацию о подпапке для отображения в интерфейсе. | PREVIEW_VIDEO |
