# Сохранить видео

Узел SaveVideo сохраняет входное видео в выходной каталог ComfyUI. Он позволяет выбрать префикс имени файла, формат видео и кодек, а также автоматически создаёт уникальное имя файла, добавляя счётчик. По умолчанию узел также сохраняет метаданные рабочего процесса в сохраняемом видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `codec` | Кодек для видео. Выбор `h264` открывает дополнительные параметры кодирования (по умолчанию: "auto"). | DYNAMIC_COMBO | Да | "auto"<br>"h264" |
| `video` | Видео для сохранения. | VIDEO | Да | - |
| `filename_prefix` | Префикс имени файла для сохранения. Может содержать форматирующую информацию, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для включения значений из узлов (по умолчанию: "video/ComfyUI"). | STRING | Да | - |
| `format` | Формат сохраняемого видео. Определяет расширение файла сохраняемого видео (по умолчанию: "auto"). | COMBO | Да | "auto"<br>"mp4"<br>"webm"<br>"mkv"<br>"gif" |

### Входы h264

Эти входы появляются, когда `codec` установлен в `h264`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Режим кодирования для H.264. Автоматический режим сохраняет совместимые потоки H.264. Повторное кодирование применяет пользовательский CRF (по умолчанию: "auto"). | DYNAMIC_COMBO | Нет | "auto"<br>"re-encode" |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. Доступно только когда `encoding` равен `re-encode` (по умолчанию: 23.0). | FLOAT | Да (только когда `encoding` равен `re-encode`) | от 0.0 до 51.0 (шаг: 1.0) |

Примечание: Если `filename_prefix` содержит папки, например `video/ComfyUI`, видео сохраняется внутри этой подпапки выходного каталога. Имя файла создаётся из префикса с добавленным счётчиком, например `ComfyUI_00001_.mp4`, поэтому существующие файлы не перезаписываются.

Примечание: Когда метаданные включены, узел встраивает промпт рабочего процесса и дополнительные метаданные в сохраняемое видео. Метаданные можно отключить, запустив ComfyUI с аргументом `--disable-metadata`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сохранённое видео, переданное со входа. | VIDEO |
| `ui` | Предпросмотр сохранённого видеофайла, включая путь к файлу и информацию о подпапке для отображения в интерфейсе. | PREVIEW_VIDEO |
