# Сохранить видео

Узел Save Video сохраняет входное видео в выходной каталог ComfyUI. Можно выбрать префикс имени файла, формат контейнера, видеокодек и параметры кодирования, такие как качество. Узел автоматически создаёт уникальное имя файла с помощью счётчика и может встраивать метаданные рабочего процесса в сохраняемый файл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `видео` | Видео для сохранения. | VIDEO | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может содержать информацию форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, чтобы включить значения из узлов (по умолчанию: `video/ComfyUI`). | STRING | Да | - |
| `формат` | Выходной контейнер. Auto использует MP4 для Auto/H.264 и WebM для AV1. MP4, MKV и WebM выбирают конкретный контейнер. Выбор формата также определяет, какие параметры кодека доступны (по умолчанию: `auto`). | DYNAMIC_COMBO | Да | `"auto"`<br>`"mp4"`<br>`"mkv"`<br>`"webm"` |
| `кодек` | Выходной видеокодек. Auto сохраняет совместимый исходный поток. Перекодирование H.264 и AV1 поддерживает SDR, HDR (HLG) и HDR PQ. Этот селектор вложен в выбранный формат (по умолчанию: `auto`). | DYNAMIC_COMBO | Нет | `"auto"`<br>`"h264"`<br>`"av1"` (недоступно с форматом `webm`) |

### Входы H.264

Эти входы отображаются, когда `codec` имеет значение `"h264"`, и доступны для форматов `auto`, `mp4` и `mkv`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Automatic сохраняет совместимые потоки H.264. Re-encode применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения дают более высокое качество и больший размер файла. Отображается, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 23.0). | FLOAT | Нет | 0.0–51.0 |

### Входы AV1

Эти входы отображаются, когда `codec` имеет значение `"av1"`, и доступны для форматов `auto`, `mp4`, `mkv` и `webm`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Automatic сохраняет совместимые потоки AV1. Re-encode применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения дают более высокое качество и больший размер файла. Отображается, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 30.0). | FLOAT | Нет | 0.0–63.0 |

Примечание: Когда `format` имеет значение `"auto"`, сохраняемый контейнер выбирается автоматически: `av1` создаёт WebM, а `auto` и `h264` создают MP4. Формат `webm` допускает только кодеки `auto` и `av1`. Когда `codec` имеет значение `"auto"`, исходный видеопоток сохраняется без перекодирования. Сохранённый файл использует суффикс со счётчиком, чтобы избежать перезаписи существующих файлов. Расширение файла определяется итоговым контейнером. Метаданные рабочего процесса (промпт и дополнительная информация об узлах) встраиваются в сохраняемый файл, если сохранение метаданных не отключено при запуске.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Входное видео без изменений. | VIDEO |
| `ui` | Предпросмотр сохранённого видеофайла, включая путь к файлу и информацию о подпапке для отображения в интерфейсе. | PREVIEW_VIDEO |
