# Сохранить видео

Узел Save Video сохраняет входное видео в выходной каталог ComfyUI. Вы можете выбрать префикс имени файла, контейнерный формат, видеокодек и параметры кодирования, такие как качество и цветовое пространство. Узел автоматически управляет именами файлов с нарастающим счётчиком и может встраивать метаданные рабочего процесса в сохраняемый файл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `видео` | Видео для сохранения. | VIDEO | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может содержать информацию форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для включения значений из узлов (по умолчанию: "video/ComfyUI"). | STRING | Да | - |
| `формат` | Выходной контейнер. Auto сохраняет исходный контейнер, когда это возможно; MP4, MKV и WebM выбирают конкретный контейнер (по умолчанию: "auto"). | DYNAMIC_COMBO | Да | `"auto"`<br>`"mp4"`<br>`"mkv"`<br>`"webm"` |
| `кодек` | Выходной видеокодек. Auto сохраняет совместимый исходный поток. Перекодирование H.264 и AV1 поддерживает SDR, HDR (HLG) и HDR PQ. Отображается, когда выбран формат (по умолчанию: "auto"). | DYNAMIC_COMBO | Нет | `"auto"`<br>`"h264"`<br>`"av1"` |

### Входы H.264

Эти входы появляются, когда `codec` имеет значение `"h264"`. Этот кодек доступен с форматами `auto`, `mp4` и `mkv`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Авто сохраняет совместимые потоки H.264. Перекодирование применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 23.0). | FLOAT | Нет | от 0.0 до 51.0 |
| `color_space` | Auto использует sRGB для видео, созданных из изображений, и сохраняет распознанные цвета на загруженных видео. sRGB записывает SDR BT.709/sRGB. HDR записывает 10-битный BT.2020/HLG; HDR PQ записывает BT.2020/PQ. Остальные входные пиксели уже должны использовать выбранное цветовое пространство. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: "auto"). | COMBO | Нет | `"auto"`<br>`"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |

### Входы AV1

Эти входы появляются, когда `codec` имеет значение `"av1"`. Этот кодек доступен с форматами `auto`, `mp4`, `mkv` и `webm`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `encoding` | Авто сохраняет совместимые потоки AV1. Перекодирование применяет пользовательские параметры кодирования. | DYNAMIC_COMBO | Нет | `"auto"`<br>`"re-encode"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: 30.0). | FLOAT | Нет | от 0.0 до 63.0 |
| `color_space` | Auto использует sRGB для видео, созданных из изображений, и сохраняет распознанные цвета на загруженных видео. sRGB записывает SDR BT.709/sRGB. HDR записывает 10-битный BT.2020/HLG; HDR PQ записывает BT.2020/PQ. Остальные входные пиксели уже должны использовать выбранное цветовое пространство. Появляется, когда `encoding` имеет значение `"re-encode"` (по умолчанию: "auto"). | COMBO | Нет | `"auto"`<br>`"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |

Примечание: формат `webm` поддерживает только кодеки `auto` и `av1`. Когда `format` имеет значение `"auto"`, исходный контейнер сохраняется, когда это возможно. Когда `color_space` имеет значение `"auto"`, явное цветовое пространство не применяется, и цветовое пространство определяется автоматически.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `видео` | Входное видео, без изменений. | VIDEO |
| `ui` | Предварительный просмотр сохранённого видеофайла, включая путь к файлу и информацию о подпапке для отображения в интерфейсе. | PREVIEW_VIDEO |
