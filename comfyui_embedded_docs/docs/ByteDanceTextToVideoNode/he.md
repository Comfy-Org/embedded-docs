# ByteDanceTextToVideoNode

צומת ByteDance Text to Video יוצר סרטון באמצעות מודלים של ByteDance דרך API בהתבסס על הנחיית טקסט. אתם מספקים הנחיה ובוחרים הגדרות כגון המודל, הרזולוציה, יחס הגובה-רוחב והמשך; הצומת שולח את בקשת היצירה ומחזיר את הסרטון שנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל ByteDance המשמש ליצירת הסרטון (ברירת מחדל: `"seedance-1-0-pro-fast-251015"`). | COMBO | כן | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `prompt` | הנחיית הטקסט המשמשת ליצירת הסרטון. | STRING | כן | - |
| `resolution` | הרזולוציה של סרטון הפלט. | COMBO | כן | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | יחס הגובה-רוחב של סרטון הפלט. | COMBO | כן | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | משך סרטון הפלט בשניות (ברירת מחדל: 5). | INT | כן | 3 עד 12 |
| `seed` | ערך Seed לשימוש ביצירה (ברירת מחדל: 0). | INT | לא | 0 עד 2147483647 |
| `camera_fixed` | מציין אם לקבע את המצלמה. הפלטפורמה מוסיפה הנחיה לקבע את המצלמה להנחיה שלכם, אך אינה מבטיחה את האפקט בפועל (ברירת מחדל: False). | BOOLEAN | לא | - |
| `watermark` | האם להוסיף לסרטון סימן מים של "AI generated" (ברירת מחדל: False). | BOOLEAN | לא | - |
| `generate_audio` | מתעלמים מפרמטר זה בכל מודל מלבד `seedance-1-5-pro-251215` (ברירת מחדל: False). | BOOLEAN | לא | - |

**אילוצי פרמטרים:**

- פרמטר `prompt` חייב להכיל לפחות תו אחד לאחר הסרת רווחים.
- פרמטר `prompt` אינו יכול להכיל את פרמטרי הטקסט הבאים: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- הצומת בונה את ההנחיה הסופית על ידי הוספת ההגדרות שנבחרו של `resolution`, `aspect_ratio`, `duration`, `seed`, `camera_fixed` ו־`watermark` לטקסט ההנחיה.
- פרמטר `duration` מוגבל לערכים שבין 3 ל־12 שניות. עבור המודל `seedance-1-5-pro-251215`, משך הזמן המינימלי הנתמך הוא 4 שניות.
- פרמטר `seed` מקבל ערכים מ־0 עד 2,147,483,647.
- לפרמטר `generate_audio` יש השפעה רק כאשר `model` מוגדר ל־`seedance-1-5-pro-251215`; מתעלמים ממנו בכל שאר המודלים.
