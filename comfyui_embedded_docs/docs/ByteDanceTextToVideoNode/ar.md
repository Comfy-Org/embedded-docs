# ByteDance نص إلى فيديو

عقدة ByteDance Text to Video لتوليد فيديو باستخدام نماذج ByteDance عبر واجهة برمجة التطبيقات (API) بناءً على موجه نصي. يمكنك تقديم موجه واختيار إعدادات مثل النموذج، الدقة، نسبة الأبعاد، والمدة؛ حيث تُرسل العقدة طلب التوليد وتُرجع الفيديو المُولَّد.

**ملاحظة:** تم وضع علامة على هذه العقدة على أنها مهملة في الكود المصدري.

**ملاحظة:** ستوقف BytePlus نموذج Seedance 1.5 Pro في 11 نوفمبر 2026، لذا لم تعد هذه العقدة توفره وتتوقف سير العمل المحفوظة به عن العمل. استخدم `seedance-1-0-pro-250528` أو `seedance-1-0-pro-fast-251015` أو [عقدة شريك Seedance 2.5](https://docs.comfy.org/ar/tutorials/partner-nodes/bytedance/seedance-2-5) بدلاً منه.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | نموذج ByteDance المستخدم لتوليد الفيديو (الافتراضي: `"seedance-1-0-pro-fast-251015"`). | COMBO | نعم | `"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `النص الموجه` | الموجه النصي المستخدم لتوليد الفيديو. | STRING | نعم | - |
| `الدقة` | دقة الفيديو الناتج. | COMBO | نعم | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبة العرض إلى الارتفاع` | نسبة الأبعاد للفيديو الناتج. | COMBO | نعم | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `المدة` | مدة الفيديو الناتج بالثواني (الافتراضي: 5). | INT | نعم | 3 إلى 12 |
| `البذرة` | البذرة (Seed) المستخدمة في التوليد (الافتراضي: 0). | INT | لا | 0 إلى 2147483647 |
| `الكاميرا ثابتة` | يحدد ما إذا كان سيتم تثبيت الكاميرا. تُلحق المنصة تعليمة تثبيت الكاميرا بالموجه الخاص بك، ولكنها لا تضمن التأثير الفعلي (الافتراضي: False). | BOOLEAN | لا | - |
| `علامة مائية` | ما إذا كان سيتم إضافة علامة مائية "AI generated" إلى الفيديو (الافتراضي: False). | BOOLEAN | لا | - |
| `توليد الصوت` | يضيف مسارًا صوتيًا مُنشأ بالذكاء الاصطناعي. تتجاهل النماذج المتبقية هذا الإدخال (الافتراضي: False). | BOOLEAN | لا | - |

**قيود المعاملات:**

- يجب أن يحتوي معامل `prompt` على حرف واحد على الأقل بعد إزالة المسافات البيضاء.
- لا يمكن أن يحتوي معامل `prompt` على المعاملات النصية التالية: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- تقوم العقدة ببناء الموجه النهائي بإلحاق الإعدادات المحددة لـ `resolution` و`aspect_ratio` و`duration` و`seed` و`camera_fixed` و`watermark` بنص الموجه.
- يقتصر معامل `duration` على قيم بين 3 و12 ثانية.
- يقبل معامل `seed` القيم من 0 إلى 2,147,483,647.
- يُقبل المعامل `generate_audio` للتوافق، لكن النماذج المتبقية تتجاهله.
