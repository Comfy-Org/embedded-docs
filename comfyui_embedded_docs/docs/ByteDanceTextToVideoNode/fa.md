# تبدیل متن به ویدیو ByteDance

گره ByteDance Text to Video با استفاده از مدل‌های ByteDance و از طریق یک API، بر پایه یک پرامپت متنی ویدیو تولید می‌کند. شما یک پرامپت ارائه می‌دهید و تنظیماتی مانند مدل، رزولوشن، نسبت تصویر و مدت‌زمان را انتخاب می‌کنید؛ گره درخواست تولید را ارسال می‌کند و ویدیوی تولیدشده را برمی‌گرداند.

**نکته:** این گره در کد منبع به‌عنوان منسوخ‌شده علامت‌گذاری شده است.

**توجه:** BytePlus مدل Seedance 1.5 Pro را در ۱۱ نوامبر ۲۰۲۶ متوقف می‌کند، بنابراین این گره دیگر آن را ارائه نمی‌دهد و ورک‌فلوهای ذخیره‌شده با آن از کار می‌افتند. به‌جای آن از `seedance-1-0-pro-250528`، `seedance-1-0-pro-fast-251015` یا [گره شریک Seedance 2.5](https://docs.comfy.org/fa/tutorials/partner-nodes/bytedance/seedance-2-5) استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل ByteDance برای تولید ویدیو (پیش‌فرض: `"seedance-1-0-pro-fast-251015"`). | COMBO | بله | `"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `پرامپت` | پرامپت متنی برای تولید ویدیو. | STRING | بله | - |
| `وضوح` | رزولوشن ویدیوی خروجی. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبت تصویر` | نسبت تصویر ویدیوی خروجی. | COMBO | بله | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `مدت زمان` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 12 |
| `بذر` | مقدار seed برای تولید (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |
| `ثابت بودن دوربین` | مشخص می‌کند که دوربین ثابت باشد یا نه. پلتفرم یک دستور برای ثابت نگه‌داشتن دوربین به پرامپت شما اضافه می‌کند، اما اثر واقعی را تضمین نمی‌کند (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `واترمارک` | آیا واترمارک «تولیدشده با هوش مصنوعی» به ویدیو اضافه شود (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `تولید صدا` | یک قطعه صوتی ساخته‌شده با هوش مصنوعی اضافه می‌کند. مدل‌های باقی‌مانده این ورودی را نادیده می‌گیرند (پیش‌فرض: False). | BOOLEAN | خیر | - |

**محدودیت‌های پارامترها:**

- پارامتر `prompt` باید پس از حذف فاصله‌های سفید حداقل 1 کاراکتر داشته باشد.
- پارامتر `prompt` نمی‌تواند شامل متن‌های پارامتری زیر باشد: "resolution"، "ratio"، "duration"، "seed"، "camerafixed"، "watermark".
- گره پرامپت نهایی را با افزودن تنظیمات انتخاب‌شده `resolution`، `aspect_ratio`، `duration`، `seed`، `camera_fixed` و `watermark` به متن پرامپت می‌سازد.
- پارامتر `duration` فقط به مقادیر بین 3 و 12 ثانیه محدود است.
- پارامتر `seed` مقادیر 0 تا 2,147,483,647 را می‌پذیرد.
- پارامتر `generate_audio` برای سازگاری پذیرفته می‌شود، اما مدل‌های باقی‌مانده آن را نادیده می‌گیرند.
