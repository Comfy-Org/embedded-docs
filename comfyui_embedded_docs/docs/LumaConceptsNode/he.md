# LumaConceptsNode

מכיל אחד או יותר קונספטים של מצלמה לשימוש עם הצמתים Luma Text to Video ו-Luma Image to Video. צומת זה מאפשר לך לבחור עד ארבעה קונספטים של מצלמה ובאופן אופציונלי לשלב אותם עם שרשראות קונספטים קיימות.

**הערה:** צומת זה מסומן כמיושן בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `concept1` | בחירת קונספט המצלמה הראשון מתוך קונספטי Luma הזמינים | STRING | כן | אפשרויות מרובות זמינות<br>כולל אפשרות "None" |
| `concept2` | בחירת קונספט המצלמה השני מתוך קונספטי Luma הזמינים | STRING | כן | אפשרויות מרובות זמינות<br>כולל אפשרות "None" |
| `concept3` | בחירת קונספט המצלמה השלישי מתוך קונספטי Luma הזמינים | STRING | כן | אפשרויות מרובות זמינות<br>כולל אפשרות "None" |
| `concept4` | בחירת קונספט המצלמה הרביעי מתוך קונספטי Luma הזמינים | STRING | כן | אפשרויות מרובות זמינות<br>כולל אפשרות "None" |
| `luma_concepts` | קונספטים אופציונליים של מצלמה להוספה לאלו שנבחרו כאן | LUMA_CONCEPTS | לא | N/A |

**הערה:** ניתן להגדיר את כל פרמטרי הקונספט (`concept1` עד `concept4`) כ-"None" אם אינך רוצה להשתמש בכל ארבע משבצות הקונספט. הצומת ימזג כל `luma_concepts` שסופק עם הקונספטים שנבחרו כדי ליצור שרשרת קונספטים משולבת.
