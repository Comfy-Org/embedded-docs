# Pikadditions

צומת Pikadditions מאפשר לך להוסיף כל אובייקט או תמונה לסרטון שלך. אתה מעלה סרטון ומציין מה תרצה להוסיף כדי ליצור תוצאה משולבת בצורה חלקה. צומת זה משתמש ב-Pika API כדי להכניס תמונות לסרטונים עם שילוב שנראה טבעי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `video` | הסרטון שאליו יש להוסיף תמונה. | VIDEO | כן | - |
| `image` | התמונה להוספה לסרטון. | IMAGE | כן | - |
| `prompt_text` | תיאור טקסטואלי של מה להוסיף לסרטון. | STRING | כן | - |
| `negative_prompt` | תיאור טקסטואלי של מה להימנע ממנו בסרטון. | STRING | כן | - |
| `seed` | ערך seed אקראי לתוצאות ניתנות לשחזור. | INT | כן | 0 עד 4294967295 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | הסרטון המעובד עם התמונה שהוכנסה. | VIDEO |
