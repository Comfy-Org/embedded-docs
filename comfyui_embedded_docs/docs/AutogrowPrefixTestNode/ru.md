# AutogrowPrefixTestNode

The AutogrowPrefixTestNode — это логический узел, предназначенный для проверки функции автоматического расширения входов. Он принимает динамическое количество входных значений с плавающей точкой, объединяет их в строку, разделённую запятыми, и выводит эту строку.

## Входы

| Параметр | Описание | Тип данных | Требуемый | Диапазон |
| --- | --- | --- | --- | --- |
| `autogrow` | Динамическая группа входов, принимающая значения с плавающей точкой. Группа может содержать от 1 до 10 таких входов, и узел обрабатывает все предоставленные значения. | FLOAT | Да | 1 to 10 inputs |

**Примечание:** Вход `autogrow` — это специальный динамический вход, который можно расширять, добавляя дополнительные входы с плавающей точкой вплоть до 10. Минимальное количество — 1 вход. Значения `min` и `max` в этом узле определяют допустимое количество входов в группе, а не диапазон значений каждого отдельного числа с плавающей точкой.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Строка, содержащая все входные значения с плавающей точкой, разделённые запятыми. | STRING |
