# IdeogramV3

צומת Ideogram V3 מייצר תמונות באמצעות מודל Ideogram V3. הוא תומך הן ביצירת תמונות רגילה מפרומפטים טקסטואליים והן בעריכת תמונות כאשר מסופקים גם תמונה וגם מסכה. הצומת מציע בקרות שונות עבור יחס גובה-רוחב, רזולוציה, מהירות יצירה ותמונות עזר אופציונליות לדמות.

| `character_mask` | מסכה אופציונלית לתמונת עזר לדמות | MASK | לא | - |

**אילוצי פרמטרים:**

- כאשר מסופקים גם `image` וגם `mask`, הצומת עובר למצב עריכה
- אם מסופק רק אחד מבין `image` או `mask`, תתרחש שגיאה
- `character_mask` מחייב ש-`character_image` יהיה קיים
- הפרמטר `aspect_ratio` מתעלמים ממנו כאשר `resolution` אינו מוגדר ל-"Auto"
- אזורים לבנים במסכה יוחלפו במהלך אינפיינטינג
- מסכת הדמות ותמונת הדמות חייבות להיות באותו גודל
