# MOSS-Image Color/Depth Control

מוסיף את מפות אזורי הצבע והעומק של מתאם בקרת צבע/עומק של MOSS-Image ל-conditioning. חברו את ה-conditioning החיובי והשלילי, VAE, ואחת משתי המפות או שתיהן: המפות מקודדות ל-latents, מחוברות לאות בקרת צבע/עומק, ומוצמדות ל-conditioning עבור החלק של הדגימה שתבחרו. השתמשו בו יחד עם מתאם בקרת MOSS-Image שנטען דרך טוען LoRA.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | conditioning חיובי שאליו מוצמד אות הבקרה. | CONDITIONING | כן | N/A |
| `negative` | conditioning שלילי שאליו מוצמד אות הבקרה. | CONDITIONING | כן | N/A |
| `vae` | VAE המשמש לקידוד המפות ל-latents. | VAE | כן | N/A |
| `color_map` | צבע אחיד אחד לכל אזור, בגודל הפלט. הצבעים משמשים רק כמזהי אזור. | IMAGE | לא | N/A |
| `depth_map` | מפת עומק בגודל הפלט, כאשר קרוב מוצג בלבן. | IMAGE | לא | N/A |
| `strength` | מכפיל את תרומת המפות לטוקנים של התמונה. 0.0 זהה להיעדר מפות, 1.0 הוא החוזק שאומן (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 עד 10.0 (צעד 0.01) |
| `start_percent` | אחוז הדגימה שבו הבקרה מתחילה (ברירת מחדל: 0.0). | FLOAT | כן | 0.0 עד 1.0 (צעד 0.001) |
| `end_percent` | אחוז הדגימה שבו הבקרה מסתיימת. סיום מוקדם שומר על הפריסה והעומק בעוד יתר שלבי הדגימה מרפים את הצורות (ברירת מחדל: 1.0). | FLOAT | כן | 0.0 עד 1.0 (צעד 0.001) |

**הערה:** חברו לפחות אחת מהמפות `color_map` ו-`depth_map`; ללא אף אחת מהן, הצומת מחזיר את ה-conditioning ללא שינוי. מפה חסרה מוחלפת באפסים, כך שתצורות עם צבע בלבד ועם עומק בלבד עובדות שתיהן. כאשר שתי המפות נבדלות בגודלן, הקטנה יותר מוגדלת לגודל של האחרת. צומת זה מסומן כניסיוני ב-ComfyUI.
