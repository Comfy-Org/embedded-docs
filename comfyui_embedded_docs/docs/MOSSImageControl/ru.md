# MOSS-Image Color/Depth Control

Добавляет карты цветовых областей и глубины адаптера управления цветом/глубиной MOSS-Image к кондиционированию. Подключите положительное и отрицательное кондиционирование, VAE и одну или обе карты: карты кодируются в латенты, объединяются в сигнал управления цветом/глубиной и прикрепляются к кондиционированию для выбранной вами части сэмплирования. Используйте вместе с адаптером управления MOSS-Image, загруженным через загрузчик LoRA.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное кондиционирование, к которому прикрепляется сигнал управления. | CONDITIONING | Да | N/A |
| `negative` | Отрицательное кондиционирование, к которому прикрепляется сигнал управления. | CONDITIONING | Да | N/A |
| `vae` | VAE, используемый для кодирования карт в латенты. | VAE | Да | N/A |
| `color_map` | Один сплошной цвет на область, в размере выходного изображения. Цвета служат только идентификаторами областей. | IMAGE | Нет | N/A |
| `depth_map` | Карта глубины в размере выходного изображения; близкие участки — белые. | IMAGE | Нет | N/A |
| `strength` | Масштабирует вклад карт в токены изображения. 0.0 — то же самое, что без карт, 1.0 — сила, заданная при обучении (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 10.0 (шаг: 0.01) |
| `start_percent` | Процент сэмплирования, на котором начинается управление (по умолчанию: 0.0). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.001) |
| `end_percent` | Процент сэмплирования, на котором управление заканчивается. Досрочное завершение сохраняет компоновку и глубину, тогда как остальные шаги ослабляют формы (по умолчанию: 1.0). | FLOAT | Да | 0.0 до 1.0 (шаг: 0.001) |

**Примечание:** Подключите хотя бы одну из карт `color_map` и `depth_map`; без любой из них узел возвращает входные кондиционирования без изменений. Отсутствующая карта заменяется нулями, поэтому работают оба варианта: только с цветом и только с глубиной. Если размеры двух карт различаются, меньшая масштабируется до размера другой. В ComfyUI этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с прикреплённым сигналом управления. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с прикреплённым сигналом управления. | CONDITIONING |
