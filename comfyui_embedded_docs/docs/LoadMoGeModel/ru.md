# Загрузить MoGe модель

Загружает модель MoGe (монокулярная геометрия) из файла и подготавливает её к использованию в задачах оценки геометрии. Этот узел читает файл модели из папки `geometry_estimation` и инициализирует модель MoGe с её обученными весами.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `model_name` | Название файла модели MoGe для загрузки. Выберите один из доступных файлов модели в вашей установке ComfyUI. | COMBO | Да | Список доступных файлов модели в папке `geometry_estimation` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MOGE_MODEL` | Загруженный экземпляр модели MoGe, готовый к использованию в рабочих процессах оценки геометрии. | MOGE_MODEL |
