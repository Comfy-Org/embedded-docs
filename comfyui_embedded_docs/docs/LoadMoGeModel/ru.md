# Загрузить MoGe модель

Загружает модель MoGe (Monocular Geometry) из файла и подготавливает её к использованию в задачах оценки геометрии. Узел считывает выбранный файл модели из папки `geometry_estimation` и инициализирует модель MoGe с сохранёнными весами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model_name` | Имя файла модели MoGe для загрузки. Выберите из файлов моделей, доступных в папке `geometry_estimation` вашей установки ComfyUI. | COMBO | Да | Список доступных файлов моделей в папке `geometry_estimation` |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MOGE_MODEL` | Загруженный экземпляр модели MoGe, готовый к использованию в рабочих процессах оценки геометрии. | MOGE_MODEL |
