# TextEncodeHunyuanVideo_ImageToVideo

گره TextEncodeHunyuanVideo_ImageToVideo داده‌های شرطی (conditioning) را برای تولید ویدئو از تصویر با ترکیب یک پرامپت متنی با اطلاعات بصری از یک تصویر مرجع ایجاد می‌کند. این گره از یک مدل CLIP برای پردازش هم embedding های متن و هم embedding های تصویر از خروجی CLIP vision استفاده می‌کند و سپس توکن‌هایی تولید می‌کند که این دو منبع را بر اساس تنظیم `image_interleave` ترکیب می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری. | CLIP | بله | - |
| `خروجی بینایی clip` | embedding های بصری از یک مدل CLIP vision که زمینه تصویر را برای تصویر مرجع فراهم می‌کنند. | CLIP_VISION_OUTPUT | بله | - |
| `پرامپت` | توضیحات متنی برای هدایت تولید ویدئو. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. پرامپت با استفاده از یک قالب قالب‌بندی می‌شود که از مدل می‌خواهد ویدئو را بر اساس تصویر مرجع توصیف کند و جنبه‌هایی مانند محتوای اصلی، جزئیات اشیاء، اقدامات، پس‌زمینه و زوایای دوربین را پوشش دهد. | STRING | بله | - |
| `درهم‌تنیدگی تصویر` | میزان تأثیر تصویر در مقایسه با پرامپت متنی. عدد بالاتر به معنای تأثیر بیشتر پرامپت متنی است. (پیش‌فرض: 2) | INT | بله | 1-512 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی که اطلاعات متن و تصویر را برای تولید ویدئو ترکیب می‌کند. | CONDITIONING |
