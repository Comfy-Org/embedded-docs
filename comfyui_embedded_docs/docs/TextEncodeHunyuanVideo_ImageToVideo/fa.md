# TextEncodeHunyuanVideo_ImageToVideo

گره TextEncodeHunyuanVideo_ImageToVideo با ترکیب پرامپت‌های متنی با جاسازی‌های تصویر، داده‌های کاندیشنینگ را برای تولید ویدیو ایجاد می‌کند. این گره از مدل CLIP برای پردازش همزمان ورودی متنی و اطلاعات بصری حاصل از خروجی بینایی CLIP استفاده می‌کند، سپس توکن‌هایی تولید می‌کند که این دو منبع را بر اساس تنظیمات مشخص‌شده image interleave با یکدیگر ترکیب می‌کنند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنیزاسیون و کدگذاری | CLIP | بله | - |
| `clip_vision_output` | جاسازی‌های بصری از مدل بینایی CLIP که زمینه تصویری را فراهم می‌کنند | CLIP_VISION_OUTPUT | بله | - |
| `prompt` | توضیح متنی برای هدایت تولید ویدیو. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. پرامپت با استفاده از قالبی قالب‌بندی می‌شود که از مدل می‌خواهد ویدیو را بر اساس تصویر مرجع توصیف کند، جنبه‌هایی مانند محتوای اصلی، جزئیات اشیاء، اقدامات، پس‌زمینه و زاویه دوربین را پوشش می‌دهد. | STRING | بله | - |
| `image_interleave` | میزان تأثیر تصویر در مقایسه با پرامپت متنی. عدد بالاتر به معنای تأثیر بیشتر از پرامپت متنی است. (پیش‌فرض: 2، پارامتر پیشرفته) | INT | بله | 1-512 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های کاندیشنینگ که اطلاعات متن و تصویر را برای تولید ویدیو ترکیب می‌کند | CONDITIONING |
