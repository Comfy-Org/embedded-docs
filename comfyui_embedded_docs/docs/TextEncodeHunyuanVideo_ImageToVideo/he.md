# TextEncodeHunyuanVideo_ImageToVideo

הצומת TextEncodeHunyuanVideo_ImageToVideo יוצר נתוני התניה ליצירת וידאו מתמונה על ידי שילוב פרומפט טקסטואלי עם מידע חזותי מתמונת עזר. הוא משתמש במודל CLIP כדי לעבד הן את הטקסט והן את ההטמעות של התמונה מפלט CLIP vision, ואז מייצר טוקנים שממזגים את שני המקורות בהתאם להגדרה `image_interleave`.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה ולקידוד. | CLIP | כן | - |
| `clip_vision_output` | ההטמעות החזותיות ממודל CLIP vision המספקות הקשר תמונתי לתמונת העזר. | CLIP_VISION_OUTPUT | כן | - |
| `prompt` | תיאור הטקסט שינחה את יצירת הווידאו. תומך בקלט רב-שורתי ובפרומפטים דינמיים. הפרומפט מעוצב באמצעות תבנית שמבקשת מהמודל לתאר את הווידאו בהתבסס על תמונת העזר, תוך כיסוי היבטים כמו תוכן ראשי, פרטי אובייקטים, פעולות, רקע וזוויות מצלמה. | STRING | כן | - |
| `image_interleave` | מידת ההשפעה של התמונה לעומת פרומפט הטקסט. מספר גבוה יותר משמעו השפעה רבה יותר מפרומפט הטקסט. זוהי הגדרה מתקדמת (ברירת מחדל: 2). | INT | כן | 1-512 |
