# TextEncodeHunyuanVideo_ImageToVideo

Узел TextEncodeHunyuanVideo_ImageToVideo создаёт данные кондиционирования для генерации видео из изображения, объединяя текстовый промпт с визуальной информацией из эталонного изображения. Для обработки текста и эмбеддингов изображения из выхода модели CLIP vision используется модель CLIP, после чего генерируются токены, смешивающие эти два источника в соответствии с настройкой `image_interleave`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования. | CLIP | Да | - |
| `выход clip_vision` | Визуальные эмбеддинги из модели CLIP vision, которые предоставляют контекст изображения для эталонного изображения. | CLIP_VISION_OUTPUT | Да | - |
| `подсказка` | Текстовое описание для управления генерацией видео. Поддерживает многострочный ввод и динамические промпты. Промпт форматируется с помощью шаблона, который предлагает модели описать видео на основе эталонного изображения, охватывая такие аспекты, как основное содержание, детали объектов, действия, фон и ракурсы камеры. | STRING | Да | - |
| `перемежение изображения` | Насколько изображение влияет на результат по сравнению с текстовым промптом. Большее значение означает большее влияние текстового промпта. (по умолчанию: 2) | INT | Да | 1-512 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные кондиционирования, объединяющие текстовую и визуальную информацию для генерации видео. | CONDITIONING |
