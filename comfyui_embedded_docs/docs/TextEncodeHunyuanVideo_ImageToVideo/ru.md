# TextEncodeHunyuanVideo_ImageToVideo

Узел TextEncodeHunyuanVideo_ImageToVideo создает данные кондиционирования для генерации видео, объединяя текстовые подсказки с эмбеддингами изображений. Он использует модель CLIP для обработки как текстового ввода, так и визуальной информации из выхода CLIP vision, а затем генерирует токены, которые смешивают эти два источника в соответствии с заданной настройкой image interleave.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Yes | - |
| `clip_vision_output` | Визуальные эмбеддинги из модели CLIP vision, которые обеспечивают контекст изображения | CLIP_VISION_OUTPUT | Yes | - |
| `prompt` | Текстовое описание для управления генерацией видео. Поддерживает многострочный ввод и динамические промпты. Промпт форматируется с использованием шаблона, который предлагает модели описать видео на основе референсного изображения, охватывая такие аспекты, как основное содержание, детали объектов, действия, фон и ракурсы камеры. | STRING | Yes | - |
| `image_interleave` | Насколько изображение влияет на результат по сравнению с текстовым промптом. Большее значение означает большее влияние текстового промпта. (по умолчанию: 2, расширенный параметр) | INT | Yes | 1-512 |

## Выходы

| Выход | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные кондиционирования, которые объединяют текстовую и графическую информацию для генерации видео | CONDITIONING |
