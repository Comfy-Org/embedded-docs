# HeyGen تحويل النص إلى كلام

قم بتوليف صوت الكلام من النص باستخدام محرك HeyGen Starfish لتحويل النص إلى كلام. تتضمن هذه العقدة أشهر أصوات HeyGen عبر 17 لغة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text` | النص المراد توليفه (حتى 5000 حرف). يجب أن تكون مدة الكلام المولد ثانية واحدة على الأقل. | STRING | نعم | 1 to 5000 characters |
| `voice` | الصوت المستخدم (منسق من أشهر أصوات HeyGen المتوافقة مع Starfish). | STRING | نعم | Multiple options available |
| `custom_voice_id` | معرّف صوت HeyGen اختياري. عند تعيينه، يتجاوز الصوت المحدد أعلاه. يجب أن يدعم الصوت محرك Starfish (الافتراضي: فارغ). | STRING | لا | Any valid HeyGen voice ID |
| `speed` | مضاعف سرعة الكلام (الافتراضي: 1.0). | FLOAT | لا | 0.5 to 2.0 (step: 0.05) |
| `ssml` | يعامل النص كترميز SSML (للتحكم في التوقفات والتأكيد والنطق) (الافتراضي: False). | BOOLEAN | لا | True / False |
| `seed` | لا يُرسل إلى HeyGen؛ غيّره لإجبار إعادة التشغيل (الافتراضي: 42). | INT | لا | 0 to 2147483647 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `AUDIO` | الصوت الكلامي المُولَّف الناتج من نص الإدخال. | AUDIO |
