# HeyGen Text to Speech

סנתז אודיו של דיבור מתוך טקסט באמצעות מנוע Starfish TTS של HeyGen. צומת זה כולל את הקולות הפופולריים ביותר של HeyGen ב-17 שפות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `text` | טקסט לסנתוז (עד 5000 תווים). הדיבור שנוצר חייב להיות באורך של שנייה אחת לפחות. | STRING | כן | 1 to 5000 characters |
| `voice` | קול לשימוש (נבחר מקרב הקולות הפופולריים ביותר של HeyGen התואמים ל-Starfish). | STRING | כן | Multiple options available |
| `custom_voice_id` | מזהה קול אופציונלי של HeyGen. כאשר מוגדר, הוא עוקף את הקול שנבחר לעיל. הקול חייב לתמוך במנוע Starfish (ברירת מחדל: ריק). | STRING | לא | Any valid HeyGen voice ID |
| `speed` | מכפיל מהירות דיבור (ברירת מחדל: 1.0). | FLOAT | לא | 0.5 to 2.0 (step: 0.05) |
| `ssml` | התייחס לטקסט כאל סימון SSML (עבור הפסקות, הדגשה ושליטה בהגייה) (ברירת מחדל: False). | BOOLEAN | לא | True / False |
| `seed` | לא נשלח אל HeyGen; שנה אותו כדי לכפות הרצה מחדש (ברירת מחדל: 42). | INT | לא | 0 to 2147483647 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `AUDIO` | אודיו הדיבור המסונתז שנוצר מטקסט הקלט. | AUDIO |
