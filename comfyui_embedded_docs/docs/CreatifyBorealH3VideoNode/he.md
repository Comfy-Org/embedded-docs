# Creatify Boreal-H3 Video

Creatify Boreal-H3 Video הופך פרומפט טקסט לסרטון עם סאונד, בעזרת מודל H3 שעבר אימון-המשך (post-training) של Creatify, אשר נבנה עבור פרסומות וידאו. חברו פריים ראשון כדי להנפיש תמונה סטטית, ובאופן אופציונלי פריים אחרון כדי לסיים את הצילום על תמונה נבחרת.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט טקסט המתאר את הסרטון. חייב להכיל לפחות תו אחד שאינו רווח. | STRING | כן | טקסט כלשהו שאינו ריק |
| `first_frame` | התמונה שממנה הסרטון מתחיל. כאשר היא מחוברת, השאירו את `aspect_ratio` על `"auto"` כדי שהסרטון ילך אחרי התמונה. | IMAGE | לא | - |
| `last_frame` | התמונה שבה הסרטון מסתיים. דורשת `first_frame` מחובר. | IMAGE | לא | - |
| `resolution` | הרזולוציה של סרטון הפלט (ברירת מחדל: `"768p"`). | COMBO | כן | `"768p"`<br>`"1088p"`<br>`"2k"` |
| `aspect_ratio` | יחס הגובה-רוחב של סרטון הפלט. `"auto"` הולך אחרי הפריים הראשון כאשר כזה מחובר; במקרה כזה השאירו אותו על `"auto"` (ברירת מחדל: `"auto"`). | COMBO | כן | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | אורך הסרטון בשניות (ברירת מחדל: 5). בערך `"2k"` המקסימום הוא 14 שניות. | INT | כן | 1 עד 15 (צעד 1) |
| `prompt_enhancement` | כיצד Creatify משכתב את הפרומפט לפני הרינדור: `"auto"` ו-`"ads"` הופכים אותו לפרומפט של פרסומת וידאו ויכולים להוסיף שורות דיבור, `"general"` משכתב אותו עבור כל סרטון אחר, `"none"` מרנדר אותו כפי שנכתב (ברירת מחדל: `"auto"`). | COMBO | כן | `"auto"`<br>`"ads"`<br>`"general"`<br>`"none"` |
| `seed` | ה-Seed קובע אם הצומת תרוץ מחדש. Creatify בוחר את האקראיות שלו בעצמו, ולכן אותם קלטים נותנים את אותו הסרטון רק כאשר `prompt_enhancement` מוגדר ל-`"none"` (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |

**אילוצים:** עם `first_frame` יחס הגובה-רוחב תמיד מגיע מהתמונה, ולכן כל ערך אחר של `aspect_ratio` יגרום לשגיאה. `last_frame` ללא `first_frame` נדחה, ו-`duration` מעל 14 שניות נדחה כאשר הערך הוא `"2k"`.
