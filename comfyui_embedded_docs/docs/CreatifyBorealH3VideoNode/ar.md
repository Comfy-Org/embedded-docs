# Creatify Boreal-H3 Video

يحوّل Creatify Boreal-H3 Video موجهًا نصيًا إلى فيديو مع صوت، باستخدام نموذج H3 المدرَّب لاحقًا من Creatify والمصمّم لإعلانات الفيديو. صِل إطارًا أولًا لتحريك صورة ثابتة، واختياريًا إطارًا أخيرًا لإنهاء اللقطة على صورة مختارة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | موجه نصي يصف الفيديو. يجب أن يحتوي على حرف واحد غير مسافة بيضاء على الأقل. | STRING | نعم | أي نص غير فارغ |
| `first_frame` | الصورة التي يبدأ منها الفيديو. عند توصيلها، أبقِ `aspect_ratio` على `"auto"` كي يتبع الفيديو الصورة. | IMAGE | لا | - |
| `last_frame` | الصورة التي ينتهي عندها الفيديو. تتطلب توصيل `first_frame`. | IMAGE | لا | - |
| `resolution` | دقة فيديو الإخراج (افتراضي: `"768p"`). | COMBO | نعم | `"768p"`<br>`"1088p"`<br>`"2k"` |
| `aspect_ratio` | نسبة أبعاد فيديو الإخراج. تتبع `"auto"` الإطار الأول عند توصيله؛ اتركها على `"auto"` في هذه الحالة (افتراضي: `"auto"`). | COMBO | نعم | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | طول الفيديو بالثواني (افتراضي: 5). عند `"2k"` يكون الحد الأقصى 14 ثانية. | INT | نعم | 1 إلى 15 (خطوة 1) |
| `prompt_enhancement` | كيفية إعادة كتابة Creatify للموجه قبل العرض: `"auto"` و`"ads"` تحوّلانه إلى موجه إعلان فيديو ويمكن أن تضيفا جملًا منطوقة، و`"general"` تعيد كتابته لأي فيديو آخر، و`"none"` تعرضه كما هو مكتوب (افتراضي: `"auto"`). | COMBO | نعم | `"auto"`<br>`"ads"`<br>`"general"`<br>`"none"` |
| `seed` | تحدد البذرة ما إذا كانت العقدة ستُعاد تشغيلها. لا تُرسل أي بذرة إلى Boreal-H3، لذا قد تؤدي إعادة التشغيل بالمدخلات نفسها إلى إنتاج فيديو مختلف (افتراضي: 42). | INT | نعم | 0 إلى 2147483647 |

**القيود:** عند وجود `first_frame`، تأتي نسبة الأبعاد دائمًا من الصورة، لذا فإن أي قيمة أخرى لـ `aspect_ratio` ترفع خطأً. يُرفض `last_frame` بدون `first_frame`، ويُرفض `duration` الأكبر من 14 ثانية عند `"2k"`.
