# Creatify Boreal-H3 Video

Creatify Boreal-H3 Video преобразует текстовый промпт в видео со звуком, используя дообученную H3-модель Creatify, созданную для видеорекламы. Подключите первый кадр, чтобы анимировать неподвижное изображение, и при необходимости последний кадр, чтобы завершить ролик на выбранном изображении.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовый промпт, описывающий видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | Любой непустой текст |
| `первый кадр` | Изображение, с которого начинается видео. Если оно подключено, оставляйте `aspect_ratio` в значении `"auto"`, чтобы видео соответствовало изображению. | IMAGE | Нет | - |
| `последний кадр` | Изображение, на котором заканчивается видео. Требует подключенного `first_frame`. | IMAGE | Нет | - |
| `разрешение` | Разрешение выходного видео (по умолчанию: `"768p"`). | COMBO | Да | `"768p"`<br>`"1088p"`<br>`"2k"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` соответствует первому кадру, если он подключен; в этом случае оставляйте значение `"auto"` (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `длительность` | Длительность видео в секундах (по умолчанию: 5). При `"2k"` максимум составляет 14 секунд. | INT | Да | от 1 до 15 (шаг 1) |
| `улучшение промпта` | Как Creatify переписывает промпт перед рендерингом: `"auto"` и `"ads"` превращают его в промпт для видеорекламы и могут добавлять озвучиваемые реплики, `"general"` переписывает его для любого другого видео, `"none"` рендерит его как есть (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"ads"`<br>`"general"`<br>`"none"` |
| `сид` | Сид определяет, будет ли узел выполняться повторно. В Boreal-H3 сид не передается, поэтому повторный запуск с теми же входными данными может создать другое видео (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

**Ограничения:** при наличии `first_frame` соотношение сторон всегда берется из изображения, поэтому любое другое значение `aspect_ratio` вызывает ошибку. `last_frame` без `first_frame` отклоняется, а `duration` больше 14 секунд отклоняется при `"2k"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуком. | VIDEO |
