# Creatify Boreal-H3 Video

Creatify Boreal-H3 Video превращает текстовый промпт в видео со звуком, используя дообученную модель H3 от Creatify, предназначенную для видеорекламы. Подключите первый кадр, чтобы анимировать неподвижное изображение, и при необходимости последний кадр, чтобы завершить сцену на выбранном изображении.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт, описывающий видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | Любой непустой текст |
| `first_frame` | Изображение, с которого начинается видео. Когда оно подключено, оставляйте `aspect_ratio` в значении `"auto"`, чтобы видео следовало за изображением. | IMAGE | Нет | - |
| `last_frame` | Изображение, на котором заканчивается видео. Требует подключённого `first_frame`. | IMAGE | Нет | - |
| `resolution` | Разрешение выходного видео (по умолчанию: `"768p"`). | COMBO | Да | `"768p"`<br>`"1088p"`<br>`"2k"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` следует за первым кадром, если он подключён; в этом случае оставьте значение `"auto"` (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | Длительность видео в секундах (по умолчанию: 5). При `"2k"` максимум составляет 14 секунд. | INT | Да | от 1 до 15 (шаг 1) |
| `prompt_enhancement` | Как Creatify переписывает промпт перед рендерингом: `"auto"` и `"ads"` превращают его в промпт для видеорекламы и могут добавить реплики, `"general"` переписывает его для любого другого видео, `"none"` рендерит его как есть (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"ads"`<br>`"general"`<br>`"none"` |
| `seed` | `seed` управляет тем, будет ли узел запускаться повторно. Creatify выбирает собственную случайность, поэтому одинаковые входные данные дают одинаковое видео только если для `prompt_enhancement` задано `"none"` (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

**Ограничения:** при наличии `first_frame` соотношение сторон всегда берётся из изображения, поэтому любое другое значение `aspect_ratio` вызывает ошибку. `last_frame` без `first_frame` отклоняется, а `duration` больше 14 секунд отклоняется при `"2k"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `VIDEO` | Сгенерированное видео со звуком. | VIDEO |
