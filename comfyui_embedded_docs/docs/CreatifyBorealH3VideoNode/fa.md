# Creatify Boreal-H3 Video

Creatify Boreal-H3 Video یک پرامپت متنی را با استفاده از مدل H3 پس‌آموزش‌دیدهٔ Creatify که برای تبلیغات ویدیویی ساخته شده است، به ویدیویی همراه با صدا تبدیل می‌کند. یک فریم اول را متصل کنید تا یک تصویر ثابت را به حرکت درآورید، و به‌صورت اختیاری یک فریم آخر را متصل کنید تا نمای پایانی روی تصویر انتخابی قرار گیرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی که ویدیو را توصیف می‌کند. باید حداقل یک نویسه غیرفاصله داشته باشد. | STRING | بله | هر متن غیرخالی |
| `first_frame` | تصویری که ویدیو از آن شروع می‌شود. وقتی متصل است، `aspect_ratio` را روی `"auto"` نگه دارید تا ویدیو از تصویر پیروی کند. | IMAGE | خیر | - |
| `last_frame` | تصویری که ویدیو روی آن پایان می‌یابد. نیازمند اتصال `first_frame` است. | IMAGE | خیر | - |
| `resolution` | رزولوشن ویدیوی خروجی (پیش‌فرض: `"768p"`). | COMBO | بله | `"768p"`<br>`"1088p"`<br>`"2k"` |
| `aspect_ratio` | نسبت ابعاد ویدیوی خروجی. `"auto"` وقتی تصویر اول متصل باشد از آن پیروی می‌کند؛ در این حالت آن را روی `"auto"` بگذارید (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:3"`<br>`"3:4"` |
| `duration` | طول ویدیو بر حسب ثانیه (پیش‌فرض: 5). در `"2k"` حداکثر 14 ثانیه است. | INT | بله | 1 تا 15 (گام 1) |
| `prompt_enhancement` | نحوه بازنویسی پرامپت توسط Creatify پیش از رندر: `"auto"` و `"ads"` آن را به یک پرامپت تبلیغ ویدیویی تبدیل می‌کنند و می‌توانند خطوط گفتاری اضافه کنند، `"general"` آن را برای هر ویدیوی دیگری بازنویسی می‌کند، `"none"` آن را همان‌طور که نوشته شده رندر می‌کند (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"ads"`<br>`"general"`<br>`"none"` |
| `seed` | `seed` کنترل می‌کند که گره دوباره اجرا شود یا نه. Creatify تصادفی‌بودن خودش را انتخاب می‌کند، بنابراین ورودی‌های یکسان فقط زمانی همان ویدیو را می‌دهند که `prompt_enhancement` روی `"none"` تنظیم شده باشد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

**محدودیت‌ها:** با یک `first_frame` نسبت ابعاد همیشه از تصویر گرفته می‌شود، بنابراین هر مقدار دیگر برای `aspect_ratio` خطا ایجاد می‌کند. یک `last_frame` بدون `first_frame` رد می‌شود، و `duration` بالای 14 ثانیه در `"2k"` رد می‌شود.
