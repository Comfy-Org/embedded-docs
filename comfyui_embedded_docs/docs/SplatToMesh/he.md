# חילוץ רשת מ-Splat

צומת זה ממיר splat גאוסיאני תלת-ממדי למשטח מש צבעוני. הוא פועל על ידי רסטור הגאוסיאנים אל רשת צפיפות, חילוץ משטח איזו ברמת צפיפות נבחרת, ולאחר מכן הפעלת החלקה וניקוי אופציונליים כדי להפיק מש משולשים נקי וצבעוני.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `splat` | ה-splat הגאוסיאני של הקלט להמרה למש | SPLAT | כן | - |
| `resolution` | רזולוציית רשת הצפיפות לאורך הציר הארוך ביותר. ערכים גבוהים יותר מפיקים פרטי משטח עדינים יותר אך דורשים יותר VRAM וזמן עיבוד (גדל עם resolution^3). ברירת מחדל: 384 | INT | כן | 64 - 768 (step 16) |
| `kernel` | רוחב חצי מקסימלי של splat בווקסלים. כל גאוסיאן עובר רסטור על חלון שגודלו לפי 3-sigma שלו, ומוגבל לערך הזה. surfels קטנים נשארים זולים בעוד שגדולים אינם נחתכים. העלה אם splats דלילים מותירים פערים. ברירת מחדל: 5 | INT | כן | 1 - 8 |
| `smooth` | מספר איטרציות של החלקת מש Taubin. מחליק את המשטח בלי לכווץ אותו (משמר נפח), בניגוד לטשטוש הצפיפות. 0 פירושו ללא החלקה. ברירת מחדל: 0 | INT | כן | 0 - 60 |
| `level` | רמת משטח איזו. נבחרת אוטומטית על ידי סף Otsu; ערך זה מטה את הבחירה האוטומטית (1.0 = אוטומטי, ערכים נמוכים יותר מפיקים משטחים שמנים/מחוברים יותר, ערכים גבוהים יותר מפיקים משטחים דקים/הדוקים יותר). ברירת מחדל: 0.4 | FLOAT | כן | 0.0 - 2.0 (step 0.01) |
| `min_component` | משליך רכיבים מחוברים קטנים ממספר הקודקודים הזה. מסיר גושי ציפה מנותקים ואת הקליפה הפנימית של קירות כפולים. 0 שומר על כל הרכיבים. ברירת מחדל: 500 | INT | כן | 0 - 100000 (step 50) |
| `min_opacity` | מתעלם מגאוסיאנים חלשים מהערך הזה לפני יצירת המש. ברירת מחדל: 0.02 | FLOAT | כן | 0.0 - 1.0 (step 0.01) |
| `color_sharpen` | מחדד את טקסטורת הקודקודים. 1.0 נותן מיזוג נכון פיזיקלית; ערכים גבוהים יותר מטים את הצבע של כל ווקסל לעבר הגאוסיאן הדומיננטי שלו במקום למצע את השכנים (מפחית מריחה של הטקסטורה). משפיע על הצבע בלבד, לא על הגאומטריה. ברירת מחדל: 2.0 | FLOAT | כן | 1.0 - 8.0 (step 0.5) |

## פלטים

| שם פלט | תיאור | סוג נתונים |
