# ImageScaleBy

הצומת ImageScaleBy מיועד להגדלת תמונות במקדם קנה מידה מוגדר באמצעות שיטות אינטרפולציה שונות. הוא מאפשר התאמה גמישה של גודל התמונה, כדי לענות על צורכי הגדלה שונים.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | תמונת הקלט שיש להגדיל. פרמטר זה חיוני מכיוון שהוא מספק את תמונת הבסיס שעוברת את תהליך ההגדלה. | `IMAGE` |
| `upscale_method` | מציין את שיטת האינטרפולציה שיש להשתמש בה להגדלה. בחירת השיטה יכולה להשפיע על האיכות והמאפיינים של התמונה המוגדלת. | COMBO[STRING] |
| `scale_by` | המקדם שבו התמונה תוגדל. הוא קובע את הגידול בגודל תמונת הפלט ביחס לתמונת הקלט. | `FLOAT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | התמונה המוגדלת, שגדולה מתמונת הקלט בהתאם למקדם קנה המידה ולשיטת האינטרפולציה שצוינו. | `IMAGE` |
