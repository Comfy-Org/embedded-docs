# LTX ۲.۵ تبدیل صوت به ویدیو

این گره با استفاده از مدل LTX 2.5 ویدیویی تولید می‌کند که یک قطعه صوتی را دنبال می‌کند. صدا مدت‌زمان ویدیو را تعیین می‌کند (بین 2 و 20 ثانیه)، و می‌توانید به‌صورت اختیاری تصویری را برای استفاده به‌عنوان فریم اول ارائه دهید. ویدیو از طریق سرویس API مدل LTX 2.5 تولید می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `صوت` | قطعه صوتی که ویدیو را هدایت می‌کند. طول آن (2-20 ثانیه) مدت‌زمان ویدیو را تعیین می‌کند. | AUDIO | بله | 2-20 ثانیه |
| `مدل` | نسخه مدل LTX 2.5 که باید استفاده شود. انتخاب یک مدل، زیرگزینه `resolution` مربوط به آن مدل را نیز نمایش می‌دهد. | COMBO | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `resolution` | رزولوشن خروجی ویدیوی تولیدشده. این زیرگزینه زیر `model` انتخاب‌شده نمایش داده می‌شود (پیش‌فرض: "1920x1080"). هر دو مدل گزینه‌های رزولوشن یکسانی ارائه می‌دهند. | COMBO | بله | "1920x1080"<br>"1080x1920" |
| `پرامپت` | توضیح متنی که محتوای ویدیوی تولیدشده را راهنمایی می‌کند (پیش‌فرض: ""). باید حداقل 1 کاراکتر و حداکثر 10000 کاراکتر داشته باشد. | STRING | بله | 1-10000 کاراکتر |
| `بذر` | عددی که تصادفی‌بودن تولید را کنترل می‌کند. `seed` یکسان نتیجه یکسان تولید می‌کند (پیش‌فرض: 42). | INT | بله | هر عدد صحیح |
| `تصویر` | فریم اول اختیاری برای استفاده در ویدیو. فقط یک تصویر پشتیبانی می‌شود. | IMAGE | خیر | یک تصویر |

نکات مربوط به محدودیت‌ها:
- مدت‌زمان صدا باید بین 2 و 20 ثانیه باشد؛ اگر خارج از این محدوده باشد، گره خطا می‌دهد.
- پرامپت الزامی است و نمی‌تواند خالی باشد؛ باید بین 1 و 10000 کاراکتر باشد.
- وقتی `image` ارائه می‌شود، فقط یک تصویر ورودی پذیرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی تولیدشده که با قطعه صوتی ارائه‌شده هدایت می‌شود. | VIDEO |
