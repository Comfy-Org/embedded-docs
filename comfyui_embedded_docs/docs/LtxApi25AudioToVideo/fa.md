# LTX ۲.۵ تبدیل صوت به ویدیو

این گره ویدیویی تولید می‌کند که از یک تراک صوتی پیروی می‌کند و از مدل LTX 2.5 استفاده می‌کند. مدت‌زمان ویدیو توسط صدا تعیین می‌شود (بین 2 تا 20 ثانیه) و می‌توانید به‌صورت اختیاری یک تصویر به‌عنوان فریم اول ارائه دهید. ویدیو از طریق سرویس API مدل LTX 2.5 تولید می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `صوت` | تراک صوتی که ویدیو را هدایت می‌کند. طول آن (2-20 ثانیه) مدت‌زمان ویدیو را تعیین می‌کند. | AUDIO | بله | 2-20 ثانیه |
| `مدل` | نسخه مدل LTX 2.5 که باید استفاده شود. وضوح ویدیو (1920x1080 یا 1080x1920) همراه با مدل انتخاب می‌شود؛ هر دو مدل گزینه‌های وضوح یکسانی ارائه می‌دهند. | COMBO | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `پرامپت` | یک توصیف متنی که محتوای ویدیوی تولیدشده را هدایت می‌کند (پیش‌فرض: ""). باید حداقل 1 کاراکتر و حداکثر 10000 کاراکتر داشته باشد. | STRING | بله | 1-10000 کاراکتر |
| `بذر` | عددی که تصادفی‌بودن تولید را کنترل می‌کند. همان seed نتیجه یکسانی تولید می‌کند (پیش‌فرض: 42). | INT | بله | هر عدد صحیح |
| `تصویر` | فریم اول اختیاری که برای ویدیو استفاده می‌شود. فقط یک تصویر پشتیبانی می‌شود. | IMAGE | خیر | یک تصویر |

نکات مربوط به محدودیت‌ها:
- مدت‌زمان صدا باید بین 2 تا 20 ثانیه باشد؛ اگر خارج از این محدوده باشد، گره خطا صادر می‌کند.
- prompt الزامی است و نمی‌تواند خالی باشد؛ باید بین 1 تا 10000 کاراکتر باشد.
- هنگامی که `image` ارائه می‌شود، فقط یک تصویر ورودی پذیرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `video` | ویدیوی تولیدشده که توسط تراک صوتی ارائه‌شده هدایت می‌شود. | VIDEO |
