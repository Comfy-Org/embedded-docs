# LTX 2.5 音訊轉影片

此節點使用 LTX 2.5 模型生成一段跟隨音訊軌道的影片。音訊會決定影片長度（2 到 20 秒），你也可以選擇提供一張圖片作為第一幀。影片是透過 LTX 2.5 API 服務生成。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `音訊` | 驅動影片的音訊軌道。其長度（2-20 秒）會設定影片長度。 | AUDIO | 是 | 2-20 seconds |
| `模型` | 要使用的 LTX 2.5 模型版本。選擇模型後，也會顯示該模型的 `resolution` 子選項。 | COMBO | 是 | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `resolution` | 生成影片的輸出解析度。此子選項會顯示在所選 `model` 下方（預設值："1920x1080"）。兩個模型提供相同的解析度選項。 | COMBO | 是 | "1920x1080"<br>"1080x1920" |
| `提示詞` | 用於引導生成影片內容的文字描述（預設值：""）。必須至少包含 1 個字元，最多 10000 個字元。 | STRING | 是 | 1-10000 characters |
| `種子` | 控制生成隨機性的數字。相同的 `seed` 會產生相同的結果（預設值：42）。 | INT | 是 | Any integer |
| `影像` | 可選的影片第一幀。僅支援一張圖片。 | IMAGE | 否 | Single image |

限制注意事項：
- 音訊長度必須介於 2 到 20 秒之間；若超出此範圍，節點會引發錯誤。
- `prompt` 為必填且不能為空；長度必須介於 1 到 10000 個字元之間。
- 提供 `image` 時，僅接受單一輸入圖片。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `video` | 由所提供音訊軌道驅動的生成影片。 | VIDEO |
