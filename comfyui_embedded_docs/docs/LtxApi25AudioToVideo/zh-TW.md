# LtxApi25AudioToVideo

此節點使用 LTX 2.5 模型根據音訊軌跡生成影片。音訊決定影片的持續時間（2 到 20 秒），您也可以選擇提供一張圖片作為第一個畫面。影片透過 LTX 2.5 API 服務生成。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `音訊` | 驅動影片的音訊軌跡。其長度（2-20 秒）設定影片的持續時間。 | AUDIO | 是 | 2-20 seconds |
| `模型` | 要使用的 LTX 2.5 模型版本。解析度與模型一起選擇；兩種型號提供相同的解析度選項（1920x1080 或 1080x1920）。 | COMBO | 是 | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `提示詞` | 引導生成影片內容的文字描述（預設：""）。必須至少包含 1 個字元，最多 10000 個字元。 | STRING | 是 | 1-10000 characters |
| `種子` | 控制生成隨機性的數字。相同的種子會產生相同的結果（預設：42）。 | INT | 是 | Any integer |
| `影像` | 可選的影片第一個畫面。僅支援一張圖片。 | IMAGE | 否 | Single image |

約束說明：
- 音訊持續時間必須在 2 到 20 秒之間；如果超出此範圍，節點會引發錯誤。
- 提示詞為必填項，不能為空。
- 當提供 `image` 時，僅接受單一輸入圖片。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `video` | 由提供的音訊軌跡驅動的生成影片。 | VIDEO |
