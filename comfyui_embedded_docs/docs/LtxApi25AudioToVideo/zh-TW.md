# LTX 2.5 音訊轉影片

此節點使用 LTX 2.5 模型生成一個跟隨音訊軌道的影片。音訊決定影片的長度（介於 2 到 20 秒之間），您可以選擇提供一張圖片作為第一幀。影片是透過 LTX 2.5 API 服務生成的。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `音訊` | 驅動影片的音訊軌道。其長度（2-20 秒）決定影片的持續時間。 | AUDIO | 是 | 2-20 seconds |
| `模型` | 要使用的 LTX 2.5 模型版本。影片解析度（1920x1080 或 1080x1920）與模型一起選擇；兩種模型都提供相同的解析度選項。 | COMBO | 是 | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `提示詞` | 引導生成影片內容的文字描述（預設：""）。至少包含 1 個字元，最多 10000 個字元。 | STRING | 是 | 1-10000 characters |
| `種子` | 控制生成隨機性的數字。相同的種子會產生相同的結果（預設：42）。 | INT | 是 | Any integer |
| `影像` | 可選的影片首幀圖片。僅支援一張圖片。 | IMAGE | 否 | Single image |

關於限制的說明：
- 音訊的持續時間必須介於 2 到 20 秒之間；若超出此範圍，節點會引發錯誤。
- 提示詞為必填，不能為空；必須介於 1 到 10000 個字元之間。
- 當提供 `image` 時，僅接受單一輸入圖片。

## 輸出
