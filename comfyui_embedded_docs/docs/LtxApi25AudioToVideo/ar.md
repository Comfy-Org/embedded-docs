# LTX 2.5 تحويل الصوت إلى فيديو

تقوم هذه العقدة بإنشاء فيديو يتبع مسارًا صوتيًا باستخدام نموذج LTX 2.5. يحدد الصوت مدة الفيديو (بين 2 و20 ثانية)، ويمكنك اختياريًا توفير صورة لاستخدامها كإطار أول. يتم إنشاء الفيديو عبر خدمة API الخاصة بـ LTX 2.5.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصوت` | المسار الصوتي الذي يحرك الفيديو. يحدد طوله (2-20 ثانية) مدة الفيديو. | AUDIO | نعم | 2-20 ثانية |
| `النموذج` | إصدار نموذج LTX 2.5 الذي سيتم استخدامه. يتم تحديد دقة الفيديو (1920x1080 أو 1080x1920) مع اختيار النموذج؛ يقدم كلا النموذجين نفس خيارات الدقة. | COMBO | نعم | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `المطالبة` | وصف نصي يوجه محتوى الفيديو المُنشأ (الافتراضي: ""). يجب أن يحتوي على حرف واحد على الأقل وبحد أقصى 10000 حرف. | STRING | نعم | 1-10000 حرف |
| `البذرة` | رقم يتحكم في العشوائية أثناء التوليد. نفس البذرة تنتج نفس النتيجة (الافتراضي: 42). | INT | نعم | أي عدد صحيح |
| `الصورة` | إطار أول اختياري يُستخدم للفيديو. يتم دعم صورة واحدة فقط. | IMAGE | لا | صورة واحدة |

ملاحظات حول القيود:
- يجب أن تتراوح مدة الصوت بين 2 و20 ثانية؛ تقوم العقدة بإصدار خطأ إذا كانت خارج هذا النطاق.
- الوصف النصي إلزامي ولا يمكن أن يكون فارغًا؛ يجب أن يتراوح بين 1 و10000 حرف.
- يتم قبول صورة إدخال واحدة فقط عند توفير `image`.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `video` | الفيديو المُنشأ الذي يحركه المسار الصوتي المقدم. | VIDEO |
