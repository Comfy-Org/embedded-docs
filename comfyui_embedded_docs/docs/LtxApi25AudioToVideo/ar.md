# LtxApi25AudioToVideo

هذه العقدة تُنشئ فيديو يتزامن مع مسار صوتي باستخدام نموذج LTX 2.5. يحدد الصوت مدة الفيديو (بين 2 و20 ثانية)، ويمكنك اختياريًا تقديم صورة لاستخدامها كإطار أول. يتم إنشاء الفيديو عبر خدمة API الخاصة بـ LTX 2.5.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `audio` | المسار الصوتي الذي يحرك الفيديو. يحدد طوله (2-20 ثانية) مدة الفيديو. | AUDIO | نعم | 2-20 ثانية |
| `model` | إصدار نموذج LTX 2.5 المطلوب استخدامه. تُختار الدقة مع النموذج؛ يوفر كلا النموذجين نفس خيارات الدقة (1920x1080 أو 1080x1920). | COMBO | نعم | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `prompt` | وصف نصي يوجه محتوى الفيديو المُنشأ (الافتراضي: ""). يجب أن يحتوي على حرف واحد على الأقل وبحد أقصى 10000 حرف. | STRING | نعم | 1-10000 حرف |
| `seed` | رقم يتحكم في عشوائية التوليد. نفس الرقم ينتج نفس النتيجة (الافتراضي: 42). | INT | نعم | أي عدد صحيح |
| `image` | إطار أول اختياري يُستخدم للفيديو. يتم دعم صورة واحدة فقط. | IMAGE | لا | صورة واحدة |

ملاحظات حول القيود:
- يجب أن تكون مدة الصوت بين 2 و20 ثانية؛ تُظهر العقدة خطأً إذا كانت خارج هذا النطاق.
- الحقل `prompt` مطلوب ولا يمكن أن يكون فارغًا.
- يتم قبول صورة إدخال واحدة فقط عند توفير `image`.

## المخرجات
