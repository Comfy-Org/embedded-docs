# LTX 2.5 המרת אודיו לוידאו

צומת זה יוצר סרטון שעוקב אחר רצועת אודיו באמצעות מודל LTX 2.5. האודיו קובע את משך הסרטון (בין 2 ל-20 שניות), ובאפשרותך לספק תמונה שתשמש כפריים הראשון. הסרטון נוצר דרך שירות ה-API של LTX 2.5.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio` | רצועת אודיו שמניעה את הסרטון. אורכה (2-20 שניות) קובע את משך הסרטון. | AUDIO | כן | 2-20 שניות |
| `model` | גרסת המודל LTX 2.5 לשימוש. בחירת מודל גם חושפת את תת-האפשרות `resolution` עבור אותו מודל. | COMBO | כן | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `resolution` | רזולוציית הפלט של הסרטון הנוצר. תת-אפשרות זו מוצגת תחת ה-`model` שנבחר (ברירת מחדל: "1920x1080"). שני המודלים מציעים את אותן אפשרויות רזולוציה. | COMBO | כן | "1920x1080"<br>"1080x1920" |
| `prompt` | תיאור טקסטואלי שמנחה את התוכן של הסרטון הנוצר (ברירת מחדל: ""). חייב להכיל לפחות תו אחד ולכל היותר 10000 תווים. | STRING | כן | 1-10000 תווים |
| `seed` | מספר ששולט באקראיות של היצירה. אותו seed מפיק את אותה תוצאה (ברירת מחדל: 42). | INT | כן | כל מספר שלם |
| `image` | פריים ראשון אופציונלי לשימוש בסרטון. נתמכת תמונה אחת בלבד. | IMAGE | לא | תמונה בודדת |

הערות לגבי אילוצים:
- משך האודיו חייב להיות בין 2 ל-20 שניות; הצומת תעלה שגיאה אם הוא מחוץ לטווח זה.
- ה-`prompt` נדרש ואינו יכול להיות ריק; הוא חייב להיות באורך שבין 1 ל-10000 תווים.
- רק תמונת קלט אחת מתקבלת כאשר מסופק `image`.
