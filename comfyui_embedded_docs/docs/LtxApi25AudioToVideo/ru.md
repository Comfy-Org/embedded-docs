# LTX 2.5 Аудио в Видео

Этот узел генерирует видео, соответствующее аудиодорожке, с использованием модели LTX 2.5. Аудио определяет продолжительность видео (от 2 до 20 секунд); при необходимости можно указать изображение для первого кадра. Видео создаётся через API-сервис LTX 2.5.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `аудио` | Аудиодорожка, управляющая видео. Её длина (2–20 секунд) задаёт продолжительность видео. | AUDIO | Да | 2–20 секунд |
| `модель` | Версия модели LTX 2.5. Разрешение видео (1920x1080 или 1080x1920) выбирается вместе с моделью; обе модели предлагают одинаковые варианты разрешения. | COMBO | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `промпт` | Текстовое описание, определяющее содержание генерируемого видео (по умолчанию: ""). Должно содержать минимум 1 и максимум 10000 символов. | STRING | Да | 1–10000 символов |
| `seed` | Число, управляющее случайностью генерации. Одинаковый seed даёт одинаковый результат (по умолчанию: 42). | INT | Да | Любое целое число |
| `изображение` | Необязательный первый кадр для видео. Поддерживается только одно изображение. | IMAGE | Нет | Одно изображение |

Примечания к ограничениям:
- Длительность аудио должна быть от 2 до 20 секунд; узел выдаёт ошибку, если значение выходит за этот диапазон.
- Prompt обязателен и не может быть пустым; его длина должна составлять от 1 до 10000 символов.
- При передаче `image` принимается только одно входное изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео на основе предоставленной аудиодорожки. | VIDEO |
