# LTX 2.5 Аудио в Видео

Этот узел генерирует видео, которое следует за аудиодорожкой, используя модель LTX 2.5. Аудио определяет длительность видео (от 2 до 20 секунд), и при желании можно предоставить изображение для использования в качестве первого кадра. Видео генерируется через сервис API LTX 2.5.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `аудио` | Аудиодорожка, управляющая видео. Её длина (2–20 секунд) задаёт длительность видео. | AUDIO | Да | 2–20 секунд |
| `модель` | Версия модели LTX 2.5 для использования. Выбор модели также открывает подопцию `resolution` для этой модели. | COMBO | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `resolution` | Выходное разрешение генерируемого видео. Эта подопция отображается под выбранной `model` (по умолчанию: "1920x1080"). Обе модели предлагают одинаковые варианты разрешения. | COMBO | Да | "1920x1080"<br>"1080x1920" |
| `промпт` | Текстовое описание, направляющее содержание генерируемого видео (по умолчанию: ""). Должно содержать не менее 1 символа и не более 10000 символов. | STRING | Да | 1–10000 символов |
| `seed` | Число, управляющее случайностью генерации. Одинаковый seed даёт одинаковый результат (по умолчанию: 42). | INT | Да | Любое целое число |
| `изображение` | Необязательный первый кадр для видео. Поддерживается только одно изображение. | IMAGE | Нет | Одно изображение |

Примечания по ограничениям:
- Длительность аудио должна быть от 2 до 20 секунд; узел выдаёт ошибку, если она выходит за этот диапазон.
- `prompt` обязателен и не может быть пустым; его длина должна быть от 1 до 10000 символов.
- При указании `image` принимается только одно входное изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, управляемое предоставленной аудиодорожкой. | VIDEO |
