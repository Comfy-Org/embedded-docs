# sync.so Talking Image

דיוקן נייח מונפש לסרטון מדבר המונע על ידי אודיו דיבור, באמצעות המודל sync-3 של sync.so. משך הפלט תואם את משך האודיו, והעלות משתנה בהתאם למשך הפלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונה בודדת עם פנים הנראות בבירור, עד 4K (4096x2160). | IMAGE | כן | נדרשת תמונה אחת בדיוק |
| `audio` | אודיו דיבור שמניע את הווידאו המדבר; משך הפלט תואם לו. ניתן לחבר כאן כל צומת TTS כדי להניע את האנימציה מטקסט. | AUDIO | כן | משך מקסימלי: 600 שניות |
| `prompt` | הנחיה אופציונלית לאופן שבו הדיוקן מקבל חיים, למשל 'גרמו לנבדק לחייך ולהביט למצלמה'. השאירו ריק לתנועת דיבור טבעית. (ברירת מחדל: "") | STRING | לא | טקסט רב־שורתי |
| `seed` | קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. (ברירת מחדל: 0) | INT | לא | 0 עד 2147483647 |
| `model` | מודל יצירה של sync.so. קלט תמונה הוא בלעדי ל-sync-3. | COMBO | כן | `"sync-3"` |
| `speaker_selection` | איזה פנים להנפיש כאשר מספר אנשים נראים. `default`: תנו למודל להחליט. `coordinates`: כוונו לפנים בפיקסל (`speaker_x`, `speaker_y`) בתמונה. זיהוי אוטומטי אינו נתמך עבור תמונות. (ברירת מחדל: "default") | COMBO | לא | `"default"`<br>`"coordinates"` |
| `speaker_x` | קואורדינטת X בפיקסלים של פני הדובר. משמשת רק כאשר `speaker_selection` הוא `"coordinates"`. (ברירת מחדל: 0) | INT | לא | 0 עד 4096 |
| `speaker_y` | קואורדינטת Y בפיקסלים של פני הדובר. משמשת רק כאשר `speaker_selection` הוא `"coordinates"`. (ברירת מחדל: 0) | INT | לא | 0 עד 4096 |
| `auto_downscale` | בצע הקטנה אוטומטית של התמונה אם היא חורגת ממגבלת הקלט של 4K (4096x2160); קואורדינטות הדובר מותאמות בהתאם. כאשר האפשרות מושבתת, תמונה גדולה מדי תגרום לשגיאה במקום זאת. (ברירת מחדל: True) | BOOLEAN | לא | True<br>False |

**הערה:** הפרמטרים `speaker_x` ו-`speaker_y` משמשים רק כאשר `speaker_selection` מוגדר ל-`"coordinates"`. כאשר `auto_downscale` מופעל, קואורדינטות הדובר מותאמות אוטומטית בהתאם לממדי התמונה המוקטנת.
