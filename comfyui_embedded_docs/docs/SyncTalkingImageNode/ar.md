# صورة متحدثة sync.so

حرّك صورة شخصية ثابتة إلى فيديو ناطق مدفوعًا بالصوت الكلامي، باستخدام نموذج sync-3 من sync.so. تطابق مدة المخرج مدة الصوت، وتتدرج التكلفة مع مدة المخرج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة واحدة مع وجه واضح، بدقة تصل إلى 4K (4096x2160). | IMAGE | نعم | مطلوب صورة واحدة بالضبط |
| `audio` | صوت كلام يقود الفيديو الناطق؛ تطابق مدة المخرج مدة الصوت. اربط أي عقدة TTS هنا لقيادة الحركة من النص. | AUDIO | نعم | الحد الأقصى للمدة: 600 ثانية |
| `prompt` | توجيه اختياري لكيفية ظهور الصورة الشخصية بحركة، مثل: 'اجعل الشخص يبتسم وينظر إلى الكاميرا'. اتركه فارغًا لحركة كلام طبيعية. (الافتراضي: "") | STRING | لا | نص متعدد الأسطر |
| `seed` | تتحكم البذرة في ما إذا كانت العقدة ستعيد التشغيل؛ النتائج غير حتمية بغض النظر عن البذرة. (الافتراضي: 0) | INT | لا | من 0 إلى 2147483647 |
| `model` | نموذج توليد sync.so. إدخال الصورة حصري لـ sync-3. | COMBO | نعم | `"sync-3"` |
| `speaker_selection` | أي وجه سيتم تحريكه عند ظهور عدة أشخاص. `default`: دع النموذج يقرر. `coordinates`: استهدف الوجه عند البكسل (`speaker_x`, `speaker_y`) في الصورة. الاكتشاف التلقائي غير مدعوم للصور. (الافتراضي: "default") | COMBO | لا | `"default"`<br>`"coordinates"` |
| `speaker_x` | إحداثي X بالبكسل لوجه المتحدث. يُستخدم فقط عندما يكون `speaker_selection` هو `"coordinates"`. (الافتراضي: 0) | INT | لا | من 0 إلى 4096 |
| `speaker_y` | إحداثي Y بالبكسل لوجه المتحدث. يُستخدم فقط عندما يكون `speaker_selection` هو `"coordinates"`. (الافتراضي: 0) | INT | لا | من 0 إلى 4096 |
| `auto_downscale` | تصغير الصورة تلقائيًا إذا تجاوزت حد الإدخال 4K (4096x2160)؛ يتم قياس إحداثيات المتحدث لتتناسب. عند التعطيل، تظهر رسالة خطأ للصورة الأكبر من الحد المسموح. (الافتراضي: True) | BOOLEAN | لا | True<br>False |

**ملاحظة:** تُستخدم المعاملات `speaker_x` و `speaker_y` فقط عندما يتم تعيين `speaker_selection` إلى `"coordinates"`. عند تفعيل `auto_downscale`، يتم تلقائيًا قياس إحداثيات المتحدث لتتناسب مع أبعاد الصورة المصغرة.
