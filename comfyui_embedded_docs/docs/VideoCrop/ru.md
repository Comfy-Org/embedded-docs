# VideoCrop

Этот узел обрезает видео до выбранной прямоугольной области, оставляя только ту часть, которая находится внутри этого прямоугольника. Он также создаёт предпросмотр обрезанного видео, чтобы вы могли увидеть результат. Если ширина и высота обрезки равны нулю, видео остаётся без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|-------------|-------------|---------------|--------|
| `video` | Исходное видео, которое будет обрезано. | VIDEO | Да | Любое видео |
| `crop` | Область обрезки в пикселях. Нулевая ширина/высота сохраняет полный кадр. Прямоугольник обрезки содержит значения `x`, `y`, `width` и `height`, все со значением по умолчанию 0. | VIDEO_EDIT | Да | `x` ≥ 0<br>`y` ≥ 0<br>`width` ≥ 0<br>`height` ≥ 0<br>Все значения по умолчанию равны 0 |

Примечание: Область обрезки описывается в пиксельных координатах. Когда ширина и высота равны 0, обрезка не применяется, и узел выводит полное входное видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Видео, обрезанное до выбранной прямоугольной области. Когда ширина и высота обрезки равны 0, на выходе получается полное входное видео. Обрезанный результат также сохраняется как временный MP4-файл и отображается в виде предпросмотра видео. | VIDEO |
