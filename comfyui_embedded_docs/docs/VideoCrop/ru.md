# Обрезка видео

Этот узел обрезает видео до прямоугольной области, заданной в пикселях, сохраняя только область внутри этого прямоугольника. Он сохраняет временный MP4-предпросмотр обрезанного результата и выводит обрезанное видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Исходное видео, которое будет обрезано. | VIDEO | Да | Любое видео |
| `crop` | Область обрезки в пикселях. При нулевой ширине/высоте сохраняется полный кадр. Прямоугольник обрезки предоставляет значения `x`, `y`, `width` и `height`, все по умолчанию равны 0. | VIDEO_EDIT | Да | `x` ≥ 0<br>`y` ≥ 0<br>`width` ≥ 0<br>`height` ≥ 0<br>Все значения по умолчанию равны 0 |

Примечание: Область обрезки описывается в пиксельных координатах. Когда ширина и высота равны 0, обрезка не применяется, и узел выводит полное входное видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `video` | Видео, обрезанное до выбранной прямоугольной области. Когда ширина и высота обрезки равны 0, выходом является полное входное видео. Обрезанный результат также сохраняется как временный MP4-файл и отображается в виде видеопредпросмотра. | VIDEO |
