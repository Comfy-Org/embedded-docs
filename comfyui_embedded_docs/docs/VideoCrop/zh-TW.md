# VideoCrop

此節點會將影片裁切至選取的矩形區域，僅保留該矩形內的部分。同時也會建立裁切後影片的預覽，方便您查看結果。若裁切的寬度與高度皆為零，則會保留完整影片不變。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 將被裁切的來源影片。 | VIDEO | 是 | 任何影片 |
| `裁切` | 以像素為單位的裁切區域。寬度／高度為零時保留完整畫面。裁切矩形提供 `x`、`y`、`width` 與 `height` 值，全部預設為 0。 | VIDEO_EDIT | 是 | `x` ≥ 0<br>`y` ≥ 0<br>`width` ≥ 0<br>`height` ≥ 0<br>所有值預設為 0 |

注意：裁切區域以像素座標描述。當寬度與高度皆為 0 時，不進行裁切，節點輸出完整的輸入影片。

| 輸出名稱 | 說明 | 資料型別 |
|-------------|-------------|-----------|
