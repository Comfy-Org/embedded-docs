# 裁切影片

此節點將影片裁剪為以像素定義的矩形區域，僅保留該矩形內的區域。它會將裁剪結果儲存為暫存的 MP4 預覽，並輸出裁剪後的影片。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 將要裁剪的來源影片。 | VIDEO | 是 | 任何影片 |
| `裁切` | 以像素為單位的裁剪區域。寬度/高度為零時會保留完整畫面。裁剪矩形提供 `x`、`y`、`width` 和 `height` 值，且全部預設為 0。 | VIDEO_EDIT | 是 | `x` ≥ 0<br>`y` ≥ 0<br>`width` ≥ 0<br>`height` ≥ 0<br>所有值預設為 0 |

注意：裁剪區域是以像素座標描述。當寬度和高度為 0 時，不會套用裁剪，且節點會輸出完整的輸入影片。
