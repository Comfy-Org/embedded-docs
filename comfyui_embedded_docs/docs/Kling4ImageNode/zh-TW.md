# Kling 4.0 Image

使用 Kling 4.0 根據文字提示詞與最多 10 張參考影像來生成或編輯影像。可要求單張影像，或讓節點回傳一系列保持相同角色與風格的相關影像。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增長的參考影像槽位（`image_1` ... `image_10`）。在提示詞中以 `@Image1`、`@Image2` 等引用它們。 | AUTOGROW | 否 | 0 至 10 張影像 |
| `prompt` | 影像的描述。將已連接的影像以 `@Image1`、`@Image2`、…… 引用。預設：空字串。 | STRING | 是 | 多行文字 |
| `resolution` | 輸出影像的解析度。預設：`"2K"`。 | COMBO | 是 | `"2K"`<br>`"4K"`<br>`"8K"` |
| `aspect_ratio` | 輸出影像的長寬比。`"auto"` 會跟隨參考影像；否則跟隨提示詞。預設：`"auto"`。 | COMBO | 是 | `"auto"`<br>`"9:16"`<br>`"2:3"`<br>`"3:4"`<br>`"1:1"`<br>`"4:3"`<br>`"3:2"`<br>`"16:9"`<br>`"21:9"` |
| `series_amount` | 生成一系列相關影像，並保持相同角色與風格。`"auto"` 會讓模型選擇 2 至 10 張影像。預設：`"disabled"`。 | COMBO | 是 | `"disabled"`<br>`"auto"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `seed` | `seed` 控制節點是否應重新執行；無論 `seed` 為何，結果都是非確定性的。預設：42。 | INT | 是 | 0 至 2147483647 |

**限制與行為：**

* 最多可連接 10 張參考影像。
* 每張影像必須至少為 300x300 像素，且長寬比介於 2:5 與 5:2 之間。
* 若提示詞提及 `@ImageN`，但連接的影像少於 N 張，則會引發錯誤。
* 當 `series_amount` 設為 `"disabled"` 時，節點會回傳一張影像；任何其他值則會回傳一批該數量的影像。
* 每次呼叫的價格會隨解析度、參考影像數量以及系列中的影像數量而變動。
