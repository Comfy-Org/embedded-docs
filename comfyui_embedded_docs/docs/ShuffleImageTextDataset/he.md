# ערבב זוגות תמונה-טקסט

צומת זה מערבב יחד רשימה של תמונות ורשימה של טקסטים, תוך שמירה על הזיווגים ביניהם ללא שינוי. הוא משתמש בזרע אקראי כדי לקבוע את סדר הערבוב, וכך מבטיח שאותן רשימות קלט יעורבבו באותו אופן בכל פעם שהזרע משמש שוב.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `images` | רשימת תמונות לערבוב. | IMAGE | כן | - |
| `texts` | רשימת טקסטים לערבוב. | STRING | כן | - |
| `seed` | זרע אקראי. סדר הערבוב נקבע לפי ערך זה (ברירת מחדל: 0). | INT | לא | 0 עד 18446744073709551615 |

**הערה:** קלטי `images` ו-`texts` חייבים להיות רשימות באותו אורך. הצומת יזווג את התמונה הראשונה עם הטקסט הראשון, את התמונה השנייה עם הטקסט השני, וכן הלאה, לפני ערבוב הזוגות יחד.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `images` | רשימת התמונות המעורבבת. | IMAGE |
| `texts` | רשימת הטקסטים המעורבבת, תוך שמירה על הזיווגים המקוריים שלהם עם התמונות. | STRING |
