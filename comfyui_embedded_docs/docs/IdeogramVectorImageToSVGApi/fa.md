# Ideogram Vector Image to SVG

این گره تصویر را با Ideogram Vector به یک SVG قابل ویرایش تبدیل می‌کند. نتیجه نشانه‌گذاری برداری است نه تصویر رستری؛ بنابراین شکل‌های ترسیم‌شده در یک ویرایشگر برداری قابل ویرایش باقی می‌مانند. نواحی شفاف تصویری که کانال آلفا دارد شفاف می‌مانند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که باید استفاده شود. پیش‌فرض: `"ideogram-vector-1"`. | DYNAMIC_COMBO | بله | `"ideogram-vector-1"` |
| `image` | تصویری که باید تبدیل شود. ورودی دسته‌ای به‌صورت تصویر به تصویر تبدیل می‌شود و SVGهای حاصل با هم بازگردانده می‌شوند. | IMAGE | بله | - |
| `mode` | حالت `"simple"` شکل‌های کمتر و بزرگ‌تری را ردیابی می‌کند؛ حالت `"default"` جزئیات ریزتری را حفظ می‌کند. پیش‌فرض: `"default"`. | COMBO | بله | `"simple"`<br>`"default"` |

**محدودیت‌ها:**

* تصاویری که بزرگ‌ترین ضلع آن‌ها بیش از 2048 پیکسل است، پیش از بارگذاری کوچک‌سازی می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `SVG` | تصویر تبدیل‌شده به‌صورت نشانه‌گذاری برداری قابل ویرایش. | SVG |
