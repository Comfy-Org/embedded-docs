# Ideogram Vector Image to SVG

צומת זה ממיר תמונה ל-SVG הניתן לעריכה באמצעות Ideogram Vector. התוצאה היא מארקאפ וקטורי ולא תמונת רסטר, כך שהצורות המתוואות נשארות ניתנות לעריכה בעורך וקטורי. אזורים שקופים בתמונה עם ערוץ אלפא נשארים שקופים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש. ברירת מחדל: `"ideogram-vector-1"`. | DYNAMIC_COMBO | כן | `"ideogram-vector-1"` |
| `image` | התמונה להמרה. קלט באצווה מומר תמונה-תמונה, וקובצי ה-SVG המתקבלים מוחזרים יחד. | IMAGE | כן | - |
| `mode` | `"simple"` מתווה פחות צורות וגדולות יותר; `"default"` שומר על פרטים עדינים יותר. ברירת מחדל: `"default"`. | COMBO | כן | `"simple"`<br>`"default"` |

**אילוצים:**

* תמונות שהצד הארוך שלהן גדול מ-2048 פיקסלים מוקטנות לפני ההעלאה.
