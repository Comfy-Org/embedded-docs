# Ideogram Vector Image to SVG

Этот узел преобразует изображение в редактируемый SVG с помощью Ideogram Vector. Результатом является векторная разметка, а не растровое изображение, поэтому трассированные фигуры остаются редактируемыми в векторном редакторе. Прозрачные области изображения с альфа-каналом остаются прозрачными.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Используемая модель. По умолчанию: `"ideogram-vector-1"`. | DYNAMIC_COMBO | Да | `"ideogram-vector-1"` |
| `image` | Изображение для преобразования. Пакетный вход обрабатывается изображение за изображением, а полученные SVG возвращаются вместе. | IMAGE | Да | - |
| `mode` | `"simple"` трассирует меньшее количество более крупных фигур; `"default"` сохраняет более мелкие детали. По умолчанию: `"default"`. | COMBO | Да | `"simple"`<br>`"default"` |

**Ограничения:**

* Изображения, у которых длина самой длинной стороны превышает 2048 пикселей, масштабируются в меньшую сторону перед загрузкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `SVG` | Преобразованное изображение в виде редактируемой векторной разметки. | SVG |
