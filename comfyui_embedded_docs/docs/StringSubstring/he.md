# StringSubstring

הצומת StringSubstring מחלץ קטע טקסט ממחרוזת גדולה יותר. הוא מקבל מיקום התחלה ומיקום סיום כדי להגדיר את הקטע שברצונך לחלץ, ולאחר מכן מחזיר את הטקסט שבין שני המיקומים הללו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `string` | מחרוזת הטקסט של הקלט שממנה יש לחלץ. תומכת בטקסט רב-שורתי. | STRING | כן | - |
| `start` | אינדקס מיקום ההתחלה של תת-המחרוזת. התו הראשון נמצא באינדקס 0. | INT | כן | - |
| `end` | אינדקס מיקום הסיום של תת-המחרוזת. התו באינדקס זה אינו נכלל בתוצאה. | INT | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | תת-המחרוזת שחולצה מטקסט הקלט, ומכילה את כל התווים ממיקום `start` ועד (אך לא כולל) מיקום `end`. | STRING |
