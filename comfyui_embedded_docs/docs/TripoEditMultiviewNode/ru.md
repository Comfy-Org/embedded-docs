# TripoEditMultiviewNode

Tripo: Edit Multiview редактирует четыре вида результата узла Tripo: Image to Multiview, используя отдельную текстовую инструкцию для каждого вида. Виды без инструкции остаются без изменений. Отредактированные изображения предназначены для подключения к узлу Tripo: Multiview to Model для создания 3D-модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | Task ID результата Tripo: Image to Multiview, виды которого будут отредактированы. | MULTIVIEW_TASK_ID | Да | Task ID |
| `front_prompt` | Текстовая инструкция, описывающая изменение, применяемое к переднему виду. Если поле пустое, передний вид остаётся без изменений. По умолчанию: пусто. | STRING | Нет | Multiline text |
| `left_prompt` | Текстовая инструкция, описывающая изменение, применяемое к левому виду. Если поле пустое, левый вид остаётся без изменений. По умолчанию: пусто. | STRING | Нет | Multiline text |
| `back_prompt` | Текстовая инструкция, описывающая изменение, применяемое к заднему виду. Если поле пустое, задний вид остаётся без изменений. По умолчанию: пусто. | STRING | Нет | Multiline text |
| `right_prompt` | Текстовая инструкция, описывающая изменение, применяемое к правому виду. Если поле пустое, правый вид остаётся без изменений. По умолчанию: пусто. | STRING | Нет | Multiline text |

Примечание: как минимум одна из четырёх текстовых инструкций (`front_prompt`, `left_prompt`, `back_prompt`, `right_prompt`) должна содержать непустой текст; в противном случае узел выдаст ошибку. Значение `multiview_task_id` должно быть получено из узла Tripo: Image to Multiview. Отредактированный набор видов нельзя редактировать повторно.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `front` | Отредактированное изображение переднего вида. | IMAGE |
| `слева` | Отредактированное изображение левого вида. | IMAGE |
| `сзади` | Отредактированное изображение заднего вида. | IMAGE |
| `справа` | Отредактированное изображение правого вида. | IMAGE |
