# TripoEditMultiviewNode

Tripo: Edit Multiview چهار نمای نتیجهٔ Tripo: Image to Multiview را با استفاده از یک دستور متنی جداگانه برای هر نما ویرایش می‌کند. نماهایی که دستوری نداشته باشند، بدون تغییر می‌مانند. تصاویر ویرایش‌شده برای اتصال به Tripo: Multiview to Model و ایجاد یک مدل سه‌بعدی در نظر گرفته شده‌اند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | شناسهٔ وظیفهٔ نتیجهٔ Tripo: Image to Multiview که نماهای آن ویرایش خواهند شد. | MULTIVIEW_TASK_ID | بله | شناسه وظیفه |
| `front_prompt` | دستور متنی که ویرایش موردنظر برای نمای جلو را توصیف می‌کند. اگر خالی باشد، نمای جلو بدون تغییر می‌ماند. پیش‌فرض: خالی. | STRING | خیر | متن چندخطی |
| `left_prompt` | دستور متنی که ویرایش موردنظر برای نمای چپ را توصیف می‌کند. اگر خالی باشد، نمای چپ بدون تغییر می‌ماند. پیش‌فرض: خالی. | STRING | خیر | متن چندخطی |
| `back_prompt` | دستور متنی که ویرایش موردنظر برای نمای عقب را توصیف می‌کند. اگر خالی باشد، نمای عقب بدون تغییر می‌ماند. پیش‌فرض: خالی. | STRING | خیر | متن چندخطی |
| `right_prompt` | دستور متنی که ویرایش موردنظر برای نمای راست را توصیف می‌کند. اگر خالی باشد، نمای راست بدون تغییر می‌ماند. پیش‌فرض: خالی. | STRING | خیر | متن چندخطی |

توجه: حداقل یکی از چهار دستور (`front_prompt`, `left_prompt`, `back_prompt`, `right_prompt`) باید دارای متن غیرخالی باشد؛ در غیر این صورت گره خطا صادر می‌کند. `multiview_task_id` باید از گره Tripo: Image to Multiview گرفته شده باشد. یک مجموعهٔ multiview ویرایش‌شده را نمی‌توان دوباره ویرایش کرد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `front` | تصویر ویرایش‌شدهٔ نمای جلو. | IMAGE |
| `چپ` | تصویر ویرایش‌شدهٔ نمای چپ. | IMAGE |
| `پشت` | تصویر ویرایش‌شدهٔ نمای عقب. | IMAGE |
| `راست` | تصویر ویرایش‌شدهٔ نمای راست. | IMAGE |
