# Tripo: Edit Multiview

ویرایش نماهای یک نتیجه‌ی Tripo: Image to Multiview را با استفاده از یک دستور متنی جداگانه برای هر نما انجام می‌دهد. نماهایی که دستوری ندارند بدون تغییر می‌مانند. تصاویر ویرایش‌شده برای اتصال به Tripo: Multiview to Model و ساخت یک مدل سه‌بعدی در نظر گرفته شده‌اند؛ مجموعه‌ی چندنمایی ویرایش‌شده را نمی‌توان دوباره ویرایش کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | شناسه وظیفه‌ی نتیجه‌ی Tripo: Image to Multiview که نماهای آن ویرایش خواهند شد. باید از گره Tripo: Image to Multiview بیاید. | MULTIVIEW_TASK_ID | بله | شناسه وظیفه |
| `front_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای جلو را توصیف می‌کند. وقتی خالی باشد، نمای جلو بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `left_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای چپ را توصیف می‌کند. وقتی خالی باشد، نمای چپ بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `back_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای پشت را توصیف می‌کند. وقتی خالی باشد، نمای پشت بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `right_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای راست را توصیف می‌کند. وقتی خالی باشد، نمای راست بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |

توجه: حداقل یکی از چهار پرامپت (`front_prompt`، `left_prompt`، `back_prompt`، `right_prompt`) باید متن غیرخالی داشته باشد؛ متنی که فقط شامل فاصله باشد به‌عنوان خالی در نظر گرفته می‌شود، و اگر همه‌ی پرامپت‌ها خالی باشند، گره خطا می‌دهد.

توجه: هزینه برای هر نمایی که دستور ویرایش دارد تقریباً 0.05 دلار آمریکا است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `front` | تصویر نمای جلوی ویرایش‌شده. | IMAGE |
| `left` | تصویر نمای چپ ویرایش‌شده. | IMAGE |
| `back` | تصویر نمای پشت ویرایش‌شده. | IMAGE |
| `right` | تصویر نمای راست ویرایش‌شده. | IMAGE |
