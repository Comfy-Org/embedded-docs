# TripoEditMultiviewNode

עורך את המבטים של תוצאת Tripo: Image to Multiview באמצעות הוראת טקסט נפרדת לכל מבט. מבטים ללא הוראה נשארים ללא שינוי. התמונות הערוכות מיועדות להיות מחוברות אל Tripo: Multiview to Model כדי ליצור מודל תלת-ממדי; לא ניתן לערוך שוב מערך רב-מבטי שעבר עריכה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | מזהה המשימה של תוצאת Tripo: Image to Multiview שהמבטים שלה יערכו. חייב להגיע מהצומת Tripo: Image to Multiview. | MULTIVIEW_TASK_ID | כן | מזהה משימה |
| `front_prompt` | הוראת טקסט המתארת את העריכה להחלה על המבט הקדמי. כאשר ריק, המבט הקדמי נשאר ללא שינוי. ברירת מחדל: מחרוזת ריקה. | STRING | לא | טקסט רב-שורתי |
| `left_prompt` | הוראת טקסט המתארת את העריכה להחלה על המבט השמאלי. כאשר ריק, המבט השמאלי נשאר ללא שינוי. ברירת מחדל: מחרוזת ריקה. | STRING | לא | טקסט רב-שורתי |
| `back_prompt` | הוראת טקסט המתארת את העריכה להחלה על המבט האחורי. כאשר ריק, המבט האחורי נשאר ללא שינוי. ברירת מחדל: מחרוזת ריקה. | STRING | לא | טקסט רב-שורתי |
| `right_prompt` | הוראת טקסט המתארת את העריכה להחלה על המבט הימני. כאשר ריק, המבט הימני נשאר ללא שינוי. ברירת מחדל: מחרוזת ריקה. | STRING | לא | טקסט רב-שורתי |

הערה: לפחות אחד מארבעת הפרומפטים (`front_prompt`, `left_prompt`, `back_prompt`, `right_prompt`) חייב להכיל טקסט לא ריק; טקסט הכולל רק רווחים נחשב לריק, ואם כל הפרומפטים ריקים, הצומת מעלה שגיאה.

הערה: העלות היא כ-0.05 דולר ארה"ב לכל מבט שיש עבורו הוראת עריכה.
