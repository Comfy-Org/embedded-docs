# TripoEditMultiviewNode

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | معرف المهمة لنتيجة Tripo: Image to Multiview التي سيتم تحرير مشاهداتها. | MULTIVIEW_TASK_ID | نعم | Task ID |
| `front_prompt` | تعليمات نصية تصف التعديل المطلوب تطبيقه على المنظر الأمامي. عند تركه فارغًا، يبقى المنظر الأمامي دون تغيير. الافتراضي: فارغ. | STRING | لا | نص متعدد الأسطر |
| `left_prompt` | تعليمات نصية تصف التعديل المطلوب تطبيقه على المنظر الأيسر. عند تركه فارغًا، يبقى المنظر الأيسر دون تغيير. الافتراضي: فارغ. | STRING | لا | نص متعدد الأسطر |
| `back_prompt` | تعليمات نصية تصف التعديل المطلوب تطبيقه على المنظر الخلفي. عند تركه فارغًا، يبقى المنظر الخلفي دون تغيير. الافتراضي: فارغ. | STRING | لا | نص متعدد الأسطر |
| `right_prompt` | تعليمات نصية تصف التعديل المطلوب تطبيقه على المنظر الأيمن. عند تركه فارغًا، يبقى المنظر الأيمن دون تغيير. الافتراضي: فارغ. | STRING | لا | نص متعدد الأسطر |

ملاحظة: يجب أن يحتوي أحد التلقيمات الأربعة على الأقل (`front_prompt`، `left_prompt`، `back_prompt`، `right_prompt`) على نص غير فارغ؛ وإلا سيرفع العقدة خطأً. يجب أن يكون `multiview_task_id` قادمًا من عقدة Tripo: Image to Multiview. لا يمكن تحرير مجموعة المشاهدات المحررة مرة أخرى.
