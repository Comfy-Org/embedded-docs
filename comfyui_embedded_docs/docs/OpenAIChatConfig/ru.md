# Расширенные настройки OpenAI ChatGPT

Узел OpenAIChatConfig определяет дополнительные параметры, которые управляют тем, как узел OpenAI Chat формирует ответы. Он позволяет задать стратегию усечения, ограничить количество выходных токенов, предоставить пользовательские инструкции и выбрать, сколько усилий модель должна приложить к рассуждению перед ответом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `усечение` | Стратегия усечения, используемая для ответа модели. auto: Если контекст этого ответа и предыдущих превышает размер контекстного окна модели, модель усечёт ответ, чтобы уложиться в контекстное окно, удаляя входные элементы из середины диалога. disabled: Если ответ модели превысит размер контекстного окна модели, запрос завершится ошибкой 400 (по умолчанию: "auto") | COMBO | Да | "auto"<br>"disabled" |
| `макс_выходные_токены` | Верхняя граница количества токенов, которые могут быть сгенерированы для ответа, включая видимые выходные токены и токены рассуждений (по умолчанию: 4096) | INT | Нет | 16 до 16384 |
| `инструкции` | Инструкции для модели о том, как формировать ответ (поддерживается многострочный ввод) | STRING | Нет | - |
| `reasoning_effort` | Сколько усилий модель прикладывает к рассуждению перед ответом. "default" оставляет выбор модели. Поддерживаемые уровни различаются в зависимости от модели: GPT-6 Astra low-max, GPT-5.6 none-max (без minimal), GPT-5.5 none-xhigh, GPT-5.5 Pro medium-xhigh, GPT-5 minimal-high, серия o low-high; GPT-4.1 не поддерживает рассуждения. Неподдерживаемые уровни отклоняются до отправки запроса. (по умолчанию: "default") | COMBO | Нет | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

Примечание. Хотя `top_p` и `temperature` указаны как свойства в спецификации API, они поддерживаются не всеми моделями и поэтому не представлены как входы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | Объект конфигурации, содержащий указанные дополнительные настройки, для использования с узлами OpenAI Chat | OPENAI_CHAT_CONFIG |
