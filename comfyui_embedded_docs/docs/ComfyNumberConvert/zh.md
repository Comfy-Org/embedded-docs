# 数字转换

数字转换节点可将各种输入数据类型转换为数值。它接受整数、浮点数、字符串或布尔值类型的单个输入，并产生两个输出：一个浮点数和一个整数。这在将文本或逻辑值转换为工作流中其他数学或处理节点可用的格式时非常有用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `value` | 要转换为数值输出的值。接受整数、浮点数、文本字符串或真/假布尔值。 | INT, FLOAT, STRING, BOOLEAN | 是 | 不适用 |

**注意：** 当输入为字符串时，它不能为空，并且必须包含有效的数字表示形式（例如，`"123"`、`"3.14"`）。节点会对空字符串、无法解析为数字的文本，或非有限值（如 `"inf"` 或 `"nan"`）报错。对于布尔输入，`true` 转换为 1.0（FLOAT）和 1（INT），而 `false` 转换为 0.0（FLOAT）和 0（INT）。对于浮点输入，整数输出通过截断小数部分获得。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `FLOAT` | 转换为浮点数的输入值。 | FLOAT |
| `INT` | 转换为整数的输入值。对于浮点输入，这执行截断操作。 | INT |
