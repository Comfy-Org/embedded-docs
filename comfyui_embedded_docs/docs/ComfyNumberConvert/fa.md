# تبدیل عدد

گره Number Convert انواع مختلف داده ورودی را به مقادیر عددی تبدیل می‌کند. این گره یک ورودی از نوع عدد صحیح، عدد اعشاری، رشته یا بولی را می‌پذیرد و دو خروجی تولید می‌کند: یک عدد اعشاری و یک عدد صحیح. این کار برای تبدیل متن یا مقادیر منطقی به قالبی مفید است که بتواند توسط سایر گره‌های ریاضی یا پردازشی در گردش‌کار شما استفاده شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `value` | مقداری که باید به خروجی‌های عددی تبدیل شود. یک عدد صحیح، یک عدد اعشاری، یک رشته متنی، یا یک بولی درست/نادرست را می‌پذیرد. | INT, FLOAT, STRING, BOOLEAN | بله | N/A |

**توجه:** وقتی ورودی یک رشته است، باید خالی نباشد و شامل نمایش معتبری از یک عدد باشد (مثلاً `"123"`، `"3.14"`). گره برای رشته‌های خالی، متنی که نمی‌توان آن را به‌عنوان عدد تجزیه کرد، یا مقادیری که متناهی نیستند (مانند `"inf"` یا `"nan"`) خطا ایجاد می‌کند. برای ورودی‌های بولی، `true` به 1.0 (FLOAT) و 1 (INT) تبدیل می‌شود، در حالی که `false` به 0.0 (FLOAT) و 0 (INT) تبدیل می‌شود. برای ورودی‌های اعشاری و برای رشته‌هایی که شامل یک عدد اعشاری هستند، خروجی عدد صحیح با حذف بخش اعشاری به‌دست می‌آید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `FLOAT` | مقدار ورودی که به یک عدد اعشاری تبدیل شده است. | FLOAT |
| `INT` | مقدار ورودی که به یک عدد صحیح تبدیل شده است. برای ورودی‌های اعشاری و رشته‌های اعشاری، این کار حذف بخش اعشاری را انجام می‌دهد. | INT |
