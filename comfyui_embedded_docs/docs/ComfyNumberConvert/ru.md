# Преобразование числа

Узел Number Convert преобразует различные типы входных данных в числовые значения. Он принимает одно значение типа integer, float, string или boolean и формирует два выходных результата: число с плавающей точкой и целое число. Это полезно для преобразования текстовых или логических значений в формат, который могут использовать другие математические или обрабатывающие узлы вашего рабочего процесса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `value` | Значение, которое необходимо преобразовать в числовые выходные результаты. Принимает целое число, число с плавающей точкой, текстовую строку или логическое значение true/false. | INT, FLOAT, STRING, BOOLEAN | Да | Н/П |

**Примечание:** Если входные данные являются строкой, она не должна быть пустой и должна содержать корректное числовое представление (например, `"123"`, `"3.14"`). Узел вызывает ошибку для пустых строк, текста, который не может быть разобран как число, или значений, не являющихся конечными (например, `"inf"` или `"nan"`). Для логических входных значений `true` преобразуется в 1.0 (FLOAT) и 1 (INT), а `false` — в 0.0 (FLOAT) и 0 (INT). Для входных значений с плавающей точкой целочисленный выходной результат получается путём отбрасывания дробной части.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `FLOAT` | Входное значение, преобразованное в число с плавающей точкой. | FLOAT |
| `INT` | Входное значение, преобразованное в целое число. Для входных значений с плавающей точкой выполняется отбрасывание дробной части. | INT |
