# Преобразование числа

Узел **Number Convert** преобразует различные типы входных данных в числовые значения. Он принимает один вход типа integer, float, string или boolean и создаёт два выхода: число с плавающей точкой и целое число. Это полезно для преобразования текстовых или логических значений в формат, который может использоваться другими математическими или обрабатывающими узлами в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Значение, которое нужно преобразовать в числовые выходные данные. Принимает целое число, число с плавающей точкой, текстовую строку или логическое значение true/false. | INT, FLOAT, STRING, BOOLEAN | Да | N/A |

**Примечание:** Когда входное значение является строкой, она не должна быть пустой и должна содержать корректное представление числа (например, `"123"`, `"3.14"`). Узел выдаст ошибку для пустых строк, текста, который невозможно разобрать как число, или значений, не являющихся конечными (например, `"inf"` или `"nan"`). Для логических входов `true` преобразуется в 1.0 (FLOAT) и 1 (INT), а `false` — в 0.0 (FLOAT) и 0 (INT). Для входов с плавающей точкой и для строк, содержащих десятичное число, целочисленный выход получается путём отбрасывания дробной части.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `FLOAT` | Входное значение, преобразованное в число с плавающей точкой. | FLOAT |
| `INT` | Входное значение, преобразованное в целое число. Для входов с плавающей точкой выполняется отбрасывание дробной части. | INT |
