# 數值轉換

Number Convert 節點可將各種輸入資料型別轉換為數值。它接受單一輸入，型別可為整數、浮點數、字串或布林值，並產生兩個輸出：一個浮點數和一個整數。這在將文字或邏輯值轉換為可供工作流程中其他數學或處理節點使用的格式時非常有用。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `數值` | 要轉換為數值輸出的值。接受整數、浮點數、文字字串或 true/false 布林值。 | INT, FLOAT, STRING, BOOLEAN | 是 | N/A |

**注意：** 當輸入為字串時，它不得為空，且必須包含有效的數字表示（例如 `"123"`、`"3.14"`）。對於空字串、無法解析為數字的文字，或不是有限數值的值（如 `"inf"` 或 `"nan"`），節點將引發錯誤。對於布林輸入，`true` 轉換為 1.0（FLOAT）和 1（INT），而 `false` 轉換為 0.0（FLOAT）和 0（INT）。對於浮點輸入以及包含小數的字串，整數輸出是透過截斷小數部分取得的。

## 輸出

| 輸出名稱 | 描述 | 資料型別 |
| --- | --- | --- |
| `FLOAT` | 輸入值轉換為浮點數。 | FLOAT |
| `INT` | 輸入值轉換為整數。對於浮點輸入，這會執行截斷。 | INT |
