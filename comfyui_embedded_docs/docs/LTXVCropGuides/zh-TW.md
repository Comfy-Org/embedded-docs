# LTXV 裁剪引導

LTXVCropGuides 節點會從影片生成工作流程中移除關鍵影格引導資料。它會計算正向條件中記錄的關鍵影格數量，從潛在樣本與雜訊遮罩的尾端裁切對應數量的影格，並清除兩個條件輸入中的關鍵影格索引與引導注意力項目。當找不到任何關鍵影格時，條件輸入會原樣返回，而潛在表示則會以複製的樣本張量及其雜訊遮罩傳遞。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正向` | 正向條件輸入，包含用於生成的引導資訊。其持有的關鍵影格數量決定會從潛在表示中裁切多少影格。 | CONDITIONING | 是 | - |
| `負向` | 負向條件輸入，包含生成時應避免內容的引導資訊。其關鍵影格資料會與正向條件一起清除。 | CONDITIONING | 是 | - |
| `潛在空間` | 潛在表示，包含影像樣本與雜訊遮罩資料。當存在關鍵影格時，末尾的關鍵影格畫面會從樣本與雜訊遮罩中移除。 | LATENT | 是 | - |

注意：只有在正向條件中偵測到關鍵影格索引時才會進行裁切。若未偵測到任何關鍵影格，正向與負向條件會原樣返回，而潛在表示仍會以複製的樣本張量與明確的雜訊遮罩返回（如果輸入潛在表示沒有雜訊遮罩，則會建立一個全為 1 的遮罩）。
