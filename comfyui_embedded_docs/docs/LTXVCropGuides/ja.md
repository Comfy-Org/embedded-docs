# LTXVCropGuides

LTXVCropGuides ノードは、キーフレーム情報を除去し、潜在表現の次元を調整することで、ビデオ生成用のコンディショニング入力と潜在入力を処理します。潜在画像とノイズマスクをクロップしてキーフレームセクションを除外し、ポジティブおよびネガティブのコンディショニング入力からキーフレームインデックスをクリアします。これにより、キーフレームガイダンスを必要としないビデオ生成ワークフロー向けにデータを準備します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 生成のためのガイダンス情報を含むポジティブなコンディショニング入力です。 | CONDITIONING | はい | - |
| `negative` | 生成時に避けるべきガイダンス情報を含むネガティブなコンディショニング入力です。 | CONDITIONING | はい | - |
| `latent` | 画像サンプルとノイズマスクデータを含む潜在表現です。 | LATENT | はい | - |

注: ポジティブコンディショニングにキーフレームインデックスが含まれていない場合、ノードは `positive`、`negative`、および `latent` 入力を変更せずに返します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | キーフレームインデックスとガイドアテンションエントリがクリアされた、処理済みのポジティブコンディショニングです。 | CONDITIONING |
| `negative` | キーフレームインデックスとガイドアテンションエントリがクリアされた、処理済みのネガティブコンディショニングです。 | CONDITIONING |
| `latent` | キーフレームセクションが除去され、サンプルとノイズマスクが調整された、クロップ済みの潜在表現です。 | LATENT |
