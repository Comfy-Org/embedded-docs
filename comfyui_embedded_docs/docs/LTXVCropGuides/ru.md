# LTXVCropGuides

Узел LTXVCropGuides обрабатывает входные данные кондиционирования и латентного представления для генерации видео, удаляя информацию о ключевых кадрах и корректируя размеры латента. Он обрезает латентное изображение и маску шума, чтобы исключить секции ключевых кадров, очищая при этом индексы ключевых кадров и записи управления вниманием как в положительном, так и в отрицательном кондиционировании. Это подготавливает данные для рабочих процессов генерации видео, не требующих управления ключевыми кадрами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Положительное кондиционирование, содержащее информацию для управления генерацией. Его индексы ключевых кадров определяют, сколько кадров будет обрезано из латента. | CONDITIONING | Да | - |
| `отрицательный` | Отрицательное кондиционирование, содержащее информацию о том, чего следует избегать при генерации. Его данные ключевых кадров очищаются вместе с положительным кондиционированием. | CONDITIONING | Да | - |
| `скрытое пространство` | Латентное представление, содержащее образцы изображения и данные маски шума. Когда в положительном кондиционировании присутствуют ключевые кадры, последние кадры, соответствующие ключевым кадрам, удаляются как из образцов, так и из маски шума. | LATENT | Да | - |

Примечание: Обрезка происходит только тогда, когда положительное кондиционирование содержит индексы ключевых кадров. Если ключевые кадры не обнаружены, положительное и отрицательное кондиционирование передаются без изменений вместе с латентом.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Обработанное положительное кондиционирование с очищенными индексами ключевых кадров и записями управления вниманием | CONDITIONING |
| `отрицательный` | Обработанное отрицательное кондиционирование с очищенными индексами ключевых кадров и записями управления вниманием | CONDITIONING |
| `скрытое пространство` | Обрезанное латентное представление с скорректированными образцами и маской шума после удаления секций ключевых кадров | LATENT |
