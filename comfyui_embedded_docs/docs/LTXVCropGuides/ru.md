# LTXVCropGuides

Узел LTXVCropGuides удаляет данные управления по ключевым кадрам из рабочего процесса генерации видео. Он подсчитывает ключевые кадры, записанные в позитивном conditioning, обрезает соответствующее количество кадров с конца сэмплов латента и маски шума, а также очищает индекс ключевых кадров и записи guide attention в обоих conditioning-входах. Если ключевые кадры не найдены, conditioning-входы возвращаются без изменений, а латент передаётся дальше с клонированным тензором сэмплов и его маской шума.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивный conditioning-вход, содержащий информацию управления для генерации. Количество хранящихся в нём ключевых кадров определяет, сколько кадров будет обрезано из латента. | CONDITIONING | Да | - |
| `отрицательный` | Негативный conditioning-вход, содержащий информацию управления о том, чего следует избегать при генерации. Его данные ключевых кадров очищаются вместе с позитивным conditioning. | CONDITIONING | Да | - |
| `скрытое пространство` | Латентное представление, содержащее сэмплы изображения и данные маски шума. Если присутствуют ключевые кадры, конечные кадры ключевых кадров удаляются как из сэмплов, так и из маски шума. | LATENT | Да | - |

Примечание: Обрезка выполняется только тогда, когда в позитивном conditioning обнаружены индексы ключевых кадров. Если ключевые кадры не обнаружены, позитивный и негативный conditioning возвращаются без изменений, а латент всё равно возвращается с клонированным тензором сэмплов и явной маской шума (если во входном латенте её нет, создаётся маска из всех единиц).

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанный позитивный conditioning с очищенными индексами ключевых кадров и записями guide attention | CONDITIONING |
| `negative` | Обработанный негативный conditioning с очищенными индексами ключевых кадров и записями guide attention | CONDITIONING |
| `latent` | Обрезанное латентное представление со скорректированными сэмплами и маской шума, из которого удалены секции ключевых кадров | LATENT |
