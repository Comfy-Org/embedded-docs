# LTXVCropGuides

Узел LTXVCropGuides обрабатывает входные данные кондиционирования и латентного представления для генерации видео, удаляя информацию о ключевых кадрах и корректируя размеры латентного представления. Он обрезает латентное изображение и маску шума, чтобы исключить секции ключевых кадров, одновременно очищая индексы ключевых кадров в положительном и отрицательном кондиционировании. Это подготавливает данные для рабочих процессов генерации видео, не требующих управления ключевыми кадрами.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Входные данные положительного кондиционирования, содержащие информацию управления для генерации | CONDITIONING | Да | - |
| `negative` | Входные данные отрицательного кондиционирования, содержащие информацию управления о том, чего следует избегать при генерации | CONDITIONING | Да | - |
| `latent` | Латентное представление, содержащее семплы изображения и данные маски шума | LATENT | Да | - |

Примечание: если положительное кондиционирование не содержит индексов ключевых кадров, узел возвращает входные данные `positive`, `negative` и `latent` без изменений.

## Выходы

| Выход | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанное положительное кондиционирование с очищенными индексами ключевых кадров и записями направляющего внимания | CONDITIONING |
| `negative` | Обработанное отрицательное кондиционирование с очищенными индексами ключевых кадров и записями направляющего внимания | CONDITIONING |
| `latent` | Обрезанное латентное представление с изменёнными семплами и маской шума, из которого удалены секции ключевых кадров | LATENT |
