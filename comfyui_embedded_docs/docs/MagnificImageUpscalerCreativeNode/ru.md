# Magnific Image Upscale (Creative)

Этот узел использует сервис Magnific AI для увеличения и творческого улучшения изображения. Он позволяет направлять улучшение с помощью текстового промпта, выбирать определённый стиль для оптимизации и управлять различными аспектами творческого процесса, такими как детализация, сходство с оригиналом и сила стилизации. Узел выводит увеличенное изображение с выбранным коэффициентом (2x, 4x, 8x или 16x) при максимальном размере вывода 25,3 мегапикселя.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для увеличения и улучшения. | IMAGE | Да | - |
| `промпт` | Текстовое описание для направления творческого улучшения изображения. По умолчанию — пустая строка (в этом случае промпт не отправляется). | STRING | Да | - |
| `коэффициент увеличения` | Коэффициент, на который увеличиваются размеры изображения. | COMBO | Да | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `оптимизировано для` | Стиль или тип содержимого, для которого оптимизируется процесс улучшения. | COMBO | Да | `"standard"`<br>`"soft_portraits"`<br>`"hard_portraits"`<br>`"art_n_illustration"`<br>`"videogame_assets"`<br>`"nature_n_landscapes"`<br>`"films_n_photography"`<br>`"3d_renders"`<br>`"science_fiction_n_horror"` |
| `креативность` | Управляет уровнем творческой интерпретации, применяемой к изображению (по умолчанию: 0). | INT | Да | -10 до 10 |
| `HDR` | Уровень чёткости и детализации (по умолчанию: 0). | INT | Да | -10 до 10 |
| `сходство` | Уровень сходства с исходным изображением (по умолчанию: 0). | INT | Да | -10 до 10 |
| `фрактальность` | Сила промпта и детализированность на квадратный пиксель (по умолчанию: 0). | INT | Да | -10 до 10 |
| `движок` | Конкретный AI-движок для обработки. Это расширенный параметр. | COMBO | Да | `"automatic"`<br>`"magnific_illusio"`<br>`"magnific_sharpy"`<br>`"magnific_sparkle"` |
| `автоматическое уменьшение` | Автоматически уменьшать входное изображение, если выходной размер превысит максимальный лимит пикселей (по умолчанию: False). Это расширенный параметр. | BOOLEAN | Да | - |

**Ограничения:**

* Вход `image` должен содержать ровно одно изображение.
* Входное изображение должно иметь минимальную высоту и ширину 160 пикселей.
* Соотношение сторон входного изображения должно быть в диапазоне от 1:3 до 3:1.
* Итоговый размер вывода (размеры входного изображения, умноженные на `scale_factor`) не может превышать 25 300 000 пикселей. Если этот лимит будет превышен:
  - Если `auto_downscale` включён, узел автоматически уменьшает размер входного изображения (дополнительное уменьшение ограничивается максимум 2x) или использует меньший `scale_factor`, чтобы вывод оставался в пределах лимита.
  - Если `auto_downscale` отключён, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Творчески улучшенное и увеличенное выходное изображение. | IMAGE |
