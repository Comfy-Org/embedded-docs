# Magnific Image Upscale (Creative)

Этот узел использует сервис Magnific AI для масштабирования и творческого улучшения изображения. Он позволяет задать направление улучшения с помощью текстового запроса, выбрать конкретный стиль для оптимизации и управлять различными аспектами творческого процесса, такими как детализация, сходство с оригиналом и сила стилизации. Узел выводит увеличенное изображение с выбранным коэффициентом (2x, 4x, 8x или 16x) при максимальном размере выходного изображения 25,3 мегапикселя.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для масштабирования и улучшения. | IMAGE | Да | - |
| `промпт` | Текстовое описание для направления творческого улучшения изображения. Необязательно (по умолчанию: пусто). | STRING | Нет | - |
| `коэффициент увеличения` | Коэффициент увеличения размеров изображения. | COMBO | Да | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `оптимизировано для` | Стиль или тип содержимого, для которого оптимизируется процесс улучшения. | COMBO | Да | `"standard"`<br>`"soft_portraits"`<br>`"hard_portraits"`<br>`"art_n_illustration"`<br>`"videogame_assets"`<br>`"nature_n_landscapes"`<br>`"films_n_photography"`<br>`"3d_renders"`<br>`"science_fiction_n_horror"` |
| `креативность` | Управляет уровнем творческой интерпретации, применяемой к изображению (по умолчанию: 0). | INT | Нет | -10 до 10 |
| `HDR` | Уровень четкости и детализации (по умолчанию: 0). | INT | Нет | -10 до 10 |
| `сходство` | Степень сходства с исходным изображением (по умолчанию: 0). | INT | Нет | -10 до 10 |
| `фрактальность` | Сила влияния запроса и сложность на квадратный пиксель (по умолчанию: 0). | INT | Нет | -10 до 10 |
| `движок` | Конкретный ИИ-движок для обработки. Это расширенный параметр. | COMBO | Да | `"automatic"`<br>`"magnific_illusio"`<br>`"magnific_sharpy"`<br>`"magnific_sparkle"` |
| `автоматическое уменьшение` | Автоматически уменьшать входное изображение, если выходное превысит максимальное ограничение по пикселям (по умолчанию: False). Это расширенный параметр. | BOOLEAN | Нет | - |

**Ограничения:**

* Входное изображение `image` должно быть ровно одним изображением.
* Входное изображение должно иметь минимальную высоту и ширину 160 пикселей.
* Соотношение сторон входного изображения должно быть от 1:3 до 3:1.
* Конечный размер выходного изображения (размеры входного изображения, умноженные на `scale_factor`) не может превышать 25 300 000 пикселей. Если этот предел будет превышен:
  - Когда `auto_downscale` включен, узел автоматически уменьшает размер входного изображения (не более чем в 2 раза) или использует меньший `scale_factor`, чтобы выходное изображение оставалось в пределах лимита.
  - Когда `auto_downscale` выключен, узел вызывает ошибку.
