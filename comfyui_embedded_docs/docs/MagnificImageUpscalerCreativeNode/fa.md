# بزرگ‌نمایی تصویر Magnific (خلاقانه)

این گره از سرویس Magnific AI برای بزرگ‌نمایی و بهبود خلاقانه تصویر استفاده می‌کند. به شما امکان می‌دهد فرایند بهبود را با یک پرامپت متنی هدایت کنید، سبک یا نوع محتوای مشخصی را برای بهینه‌سازی انتخاب کنید، و جنبه‌های مختلف فرایند خلاقانه مانند جزئیات، شباهت به تصویر اصلی و شدت سبک‌پردازی را کنترل کنید. این گره تصویری بزرگ‌نمایی‌شده را با ضریب انتخابی شما (2x، 4x، 8x یا 16x) خروجی می‌دهد، با حداکثر اندازه خروجی 25.3 مگاپیکسل.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای بزرگ‌نمایی و بهبود. | IMAGE | بله | - |
| `prompt` | توضیح متنی برای هدایت بهبود خلاقانه تصویر. پیش‌فرض یک رشته خالی است (در این حالت هیچ پرامپتی ارسال نمی‌شود). | STRING | بله | - |
| `scale_factor` | ضریبی که ابعاد تصویر با آن بزرگ‌نمایی می‌شود. | COMBO | بله | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `optimized_for` | سبک یا نوع محتوایی که فرایند بهبود برای آن بهینه‌سازی می‌شود. | COMBO | بله | `"standard"`<br>`"soft_portraits"`<br>`"hard_portraits"`<br>`"art_n_illustration"`<br>`"videogame_assets"`<br>`"nature_n_landscapes"`<br>`"films_n_photography"`<br>`"3d_renders"`<br>`"science_fiction_n_horror"` |
| `creativity` | سطح تفسیر خلاقانه اعمال‌شده روی تصویر را کنترل می‌کند (پیش‌فرض: 0). | INT | بله | ‎-10 تا 10 |
| `hdr` | سطح وضوح و جزئیات (پیش‌فرض: 0). | INT | بله | ‎-10 تا 10 |
| `resemblance` | سطح شباهت به تصویر اصلی (پیش‌فرض: 0). | INT | بله | ‎-10 تا 10 |
| `fractality` | شدت پرامپت و پیچیدگی در هر پیکسل مربع (پیش‌فرض: 0). | INT | بله | ‎-10 تا 10 |
| `engine` | موتور AI مشخصی که برای پردازش استفاده می‌شود. این یک پارامتر پیشرفته است. | COMBO | بله | `"automatic"`<br>`"magnific_illusio"`<br>`"magnific_sharpy"`<br>`"magnific_sparkle"` |
| `auto_downscale` | اگر خروجی از حداکثر مجاز پیکسل فراتر برود، تصویر ورودی را به‌صورت خودکار کاهش مقیاس می‌دهد (پیش‌فرض: False). این یک پارامتر پیشرفته است. | BOOLEAN | بله | - |

**محدودیت‌ها:**

* ورودی `image` باید دقیقاً یک تصویر باشد.
* تصویر ورودی باید حداقل ارتفاع و عرض 160 پیکسل داشته باشد.
* نسبت ابعاد تصویر ورودی باید بین 1:3 و 3:1 باشد.
* اندازه خروجی نهایی (ابعاد ورودی ضرب‌در `scale_factor`) نمی‌تواند از 25,300,000 پیکسل فراتر رود. اگر از این حد فراتر رود:
  - وقتی `auto_downscale` فعال باشد، گره به‌صورت خودکار اندازه تصویر ورودی را کاهش می‌دهد (کاهش مقیاس اضافی حداکثر تا 2x محدود می‌شود) یا از `scale_factor` پایین‌تری استفاده می‌کند تا خروجی در محدوده مجاز باقی بماند.
  - وقتی `auto_downscale` غیرفعال باشد، گره خطا ایجاد می‌کند.
