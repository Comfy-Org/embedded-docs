# بزرگ‌نمایی تصویر Magnific (خلاقانه)

این گره از سرویس Magnific AI برای بزرگ‌نمایی و بهبود خلاقانه تصویر استفاده می‌کند. به شما امکان می‌دهد با یک توصیف متنی، بهبود را هدایت کنید، سبک خاصی را برای بهینه‌سازی انتخاب کنید، و جنبه‌های مختلف فرآیند خلاقانه مانند جزئیات، شباهت به تصویر اصلی و قدرت سبک‌پردازی را کنترل کنید. گره یک تصویر بزرگ‌شده را در ضریب انتخابی شما (2x، 4x، 8x یا 16x) با حداکثر اندازه خروجی ۲۵.۳ مگاپیکسل ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که باید بزرگ‌نمایی و بهبود یابد. | IMAGE | بله | - |
| `پرامپت` | یک توصیف متنی برای هدایت بهبود خلاقانه تصویر. این پارامتر اختیاری است (پیش‌فرض: خالی). | STRING | خیر | - |
| `ضریب بزرگ‌نمایی` | عاملی که ابعاد تصویر بر اساس آن بزرگ‌نمایی می‌شود. | COMBO | بله | `"2x"`<br>`"4x"`<br>`"8x"`<br>`"16x"` |
| `بهینه‌سازی برای` | سبک یا نوع محتوایی که فرآیند بهبود برای آن بهینه‌سازی می‌شود. | COMBO | بله | `"standard"`<br>`"soft_portraits"`<br>`"hard_portraits"`<br>`"art_n_illustration"`<br>`"videogame_assets"`<br>`"nature_n_landscapes"`<br>`"films_n_photography"`<br>`"3d_renders"`<br>`"science_fiction_n_horror"` |
| `خلاقیت` | سطح تفسیر خلاقانه اعمال‌شده بر تصویر را کنترل می‌کند (پیش‌فرض: 0). | INT | خیر | -10 تا 10 |
| `HDR` | سطح وضوح و جزئیات را کنترل می‌کند (پیش‌فرض: 0). | INT | خیر | -10 تا 10 |
| `شباهت` | سطح شباهت به تصویر اصلی را کنترل می‌کند (پیش‌فرض: 0). | INT | خیر | -10 تا 10 |
| `فرکتالیتی` | شدت اثر توصیف متنی و پیچیدگی در هر پیکسل مربع را کنترل می‌کند (پیش‌فرض: 0). | INT | خیر | -10 تا 10 |
| `موتور` | موتور هوش مصنوعی مشخصی که برای پردازش استفاده می‌شود. این یک پارامتر پیشرفته است. | COMBO | بله | `"automatic"`<br>`"magnific_illusio"`<br>`"magnific_sharpy"`<br>`"magnific_sparkle"` |
| `کاهش خودکار ابعاد` | در صورت تجاوز خروجی از حداکثر محدودیت پیکسل، تصویر ورودی را به‌طور خودکار کوچک‌نمایی می‌کند (پیش‌فرض: False). این یک پارامتر پیشرفته است. | BOOLEAN | خیر | - |

**محدودیت‌ها:**

* ورودی `image` باید دقیقاً یک تصویر باشد.
* تصویر ورودی باید حداقل ارتفاع و عرض ۱۶۰ پیکسل داشته باشد.
* نسبت تصویر ورودی باید بین 1:3 و 3:1 باشد.
* اندازه نهایی خروجی (ابعاد ورودی ضرب‌در `scale_factor`) نمی‌تواند از ۲۵,۳۰۰,۰۰۰ پیکسل تجاوز کند. اگر این محدودیت نقض شود:
  - هنگامی که `auto_downscale` فعال باشد، گره به‌طور خودکار اندازه تصویر ورودی را کاهش می‌دهد (حداکثر 2 برابر) یا از `scale_factor` کمتری استفاده می‌کند تا خروجی در محدوده باقی بماند.
  - هنگامی که `auto_downscale` غیرفعال باشد، گره خطا ایجاد می‌کند.
