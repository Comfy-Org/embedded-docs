# Google Gemini

تتيح هذه العقدة للمستخدمين التفاعل مع نماذج Gemini AI من Google لإنشاء ردود نصية. يمكنك توفير أنواع متعددة من المدخلات، بما في ذلك النصوص والصور والصوت والفيديو والملفات، لتكون سياقًا للنموذج حتى يُنشئ ردودًا أكثر ملاءمة ومعنى. تتولى العقدة تلقائيًا جميع عمليات الاتصال بواجهة API وتحليل الاستجابات.

**ملاحظة:** هذه العقدة مُعلّمة كمهجورة في الكود المصدري.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | مدخلات نصية إلى النموذج، تُستخدم لإنشاء رد. يمكنك تضمين تعليمات مفصلة أو أسئلة أو سياق للنموذج. القيمة الافتراضية: سلسلة فارغة. | STRING | نعم | - |
| `model` | نموذج Gemini المستخدم لإنشاء الردود. القيمة الافتراضية: gemini-3-1-pro. | COMBO | نعم | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | عند تثبيت `seed` على قيمة محددة، يبذل النموذج قصارى جهده لتقديم الرد نفسه للطلبات المتكررة. لا يُضمن الحصول على مخرجات حتمية. كذلك، قد يؤدي تغيير النموذج أو إعدادات المعاملات، مثل درجة الحرارة، إلى اختلافات في الرد حتى عند استخدام قيمة `seed` نفسها. افتراضيًا، تُستخدم قيمة `seed` عشوائية. القيمة الافتراضية: 42. | INT | نعم | من 0 إلى 18446744073709551615 |
| `images` | صورة/صور اختيارية تُستخدم كسياق للنموذج. لتضمين صور متعددة، يمكنك استخدام عقدة Batch Images. القيمة الافتراضية: لا شيء. | IMAGE | لا | - |
| `audio` | صوت اختياري يُستخدم كسياق للنموذج. القيمة الافتراضية: لا شيء. | AUDIO | لا | - |
| `video` | فيديو اختياري يُستخدم كسياق للنموذج. القيمة الافتراضية: لا شيء. | VIDEO | لا | - |
| `files` | ملف/ملفات اختيارية تُستخدم كسياق للنموذج. تقبل مدخلات من عقدة Gemini Generate Content Input Files. القيمة الافتراضية: لا شيء. | GEMINI_INPUT_FILES | لا | - |
| `system_prompt` | تعليمات أساسية تحدد سلوك الذكاء الاصطناعي. القيمة الافتراضية: سلسلة فارغة. هذا معامل متقدم. | STRING | لا | - |

تُستخدم جميع الصور المتصلة كسياق. عند توفير أكثر من 10 صور، تُرفع أول 10 صور كمراجع ملفات، وتُرسل الصور المتبقية ضمنيًا إلى API.

تستخدم العقدة اسم النموذج المحدد كما هو مذكور في القائمة؛ وتُربط بعض الإدخالات داخليًا بمعرّفات نموذج API الحالية الخاصة بها قبل إرسال الطلب.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-----------|-----------|
| `STRING` | الرد النصي الذي ينشئه نموذج Gemini. إذا لم ينتج النموذج أي نص، تُرجع العقدة "Empty response from Gemini model...". | STRING |
