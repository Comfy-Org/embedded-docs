# Google Gemini

تتيح هذه العقدة للمستخدمين التفاعل مع نماذج Gemini AI من Google لتوليد استجابات نصية. يمكنك توفير أنواع متعددة من المدخلات بما في ذلك النصوص والصور والصوت والفيديو والملفات كسياق للنموذج لتوليد استجابات أكثر صلة وذات معنى. تتولى العقدة جميع اتصالات API وتحليل الاستجابات تلقائيًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | مدخلات نصية إلى النموذج، تُستخدم لتوليد استجابة. يمكنك تضمين تعليمات مفصلة أو أسئلة أو سياق للنموذج. الافتراضي: سلسلة فارغة. | STRING | نعم | - |
| `model` | نموذج Gemini المستخدم لتوليد الاستجابات. الافتراضي: gemini-3-1-pro. | COMBO | نعم | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | عندما يتم تثبيت البذرة (seed) على قيمة محددة، يبذل النموذج قصارى جهده لتقديم نفس الاستجابة للطلبات المتكررة. الإخراج الحتمي غير مضمون. أيضًا، تغيير النموذج أو إعدادات المعلمات مثل درجة الحرارة قد يسبب اختلافات في الاستجابة حتى عند استخدام نفس قيمة البذرة. افتراضيًا، يتم استخدام قيمة بذرة عشوائية. الافتراضي: 42. | INT | نعم | 0 إلى 18446744073709551615 |
| `images` | صورة (أو صور) اختيارية تُستخدم كسياق للنموذج. لتضمين صور متعددة، يمكنك استخدام عقدة Batch Images. الافتراضي: لا يوجد. | IMAGE | لا | - |
| `audio` | صوت اختياري يُستخدم كسياق للنموذج. الافتراضي: لا يوجد. | AUDIO | لا | - |
| `video` | فيديو اختياري يُستخدم كسياق للنموذج. الافتراضي: لا يوجد. | VIDEO | لا | - |
| `files` | ملف (أو ملفات) اختيارية تُستخدم كسياق للنموذج. يقبل مدخلات من عقدة Gemini Generate Content Input Files. الافتراضي: لا يوجد. | GEMINI_INPUT_FILES | لا | - |
| `system_prompt` | تعليمات أساسية تملي سلوك الذكاء الاصطناعي. الافتراضي: سلسلة فارغة. هذه معلمة متقدمة. | STRING | لا | - |

ملاحظة: هذه العقدة مُعلَّمة على أنها مهملة.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `STRING` | الاستجابة النصية التي يولدها نموذج Gemini. إذا لم يُرجع النموذج أي نص، تُخرج العقدة "Empty response from Gemini model...". | STRING |
