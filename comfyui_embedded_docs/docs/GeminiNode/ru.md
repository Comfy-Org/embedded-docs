# Google Gemini

Этот узел позволяет пользователям взаимодействовать с ИИ-моделями Gemini от Google для генерации текстовых ответов. Вы можете предоставить несколько типов входных данных, включая текст, изображения, аудио, видео и файлы, в качестве контекста, чтобы модель генерировала более релевантные и осмысленные ответы. Узел автоматически обрабатывает всё взаимодействие с API и разбор ответов.

**Примечание:** В исходном коде этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовые входные данные для модели, используемые для генерации ответа. Вы можете включить подробные инструкции, вопросы или контекст для модели. По умолчанию: пустая строка. | STRING | Да | - |
| `модель` | Модель Gemini, используемая для генерации ответов. По умолчанию: gemini-3-1-pro. | COMBO | Да | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `сид` | Когда seed зафиксирован на определённом значении, модель старается по возможности выдавать одинаковый ответ на повторные запросы. Детерминированный вывод не гарантируется. Кроме того, изменение модели или настроек параметров, таких как temperature, может вызывать вариации ответа даже при использовании одного и того же значения seed. По умолчанию используется случайное значение seed. По умолчанию: 42. | INT | Да | от 0 до 18446744073709551615 |
| `изображения` | Необязательные изображения для использования в качестве контекста для модели. Чтобы включить несколько изображений, можно использовать узел Batch Images. По умолчанию: нет. | IMAGE | Нет | - |
| `аудио` | Необязательное аудио для использования в качестве контекста для модели. По умолчанию: нет. | AUDIO | Нет | - |
| `видео` | Необязательное видео для использования в качестве контекста для модели. По умолчанию: нет. | VIDEO | Нет | - |
| `файлы` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. По умолчанию: нет. | GEMINI_INPUT_FILES | Нет | - |
| `system_prompt` | Основополагающие инструкции, которые определяют поведение ИИ. По умолчанию: пустая строка. Это расширенный параметр. | STRING | Нет | - |

Все подключённые изображения используются в качестве контекста. Если предоставлено более 10 изображений, первые 10 загружаются как файловые ссылки, а остальные изображения отправляются в API встроенно.

Узел использует выбранное имя модели, как указано в списке; некоторые записи внутренне сопоставляются с их текущими идентификаторами API-моделей перед отправкой запроса.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовый ответ, сгенерированный моделью Gemini. Если модель не создаёт текст, узел возвращает "Empty response from Gemini model...". | STRING |
