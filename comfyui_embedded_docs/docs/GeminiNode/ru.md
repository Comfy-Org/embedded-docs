# Google Gemini

Этот узел позволяет пользователям взаимодействовать с моделями Google Gemini AI для генерации текстовых ответов. Вы можете предоставлять несколько типов входных данных, включая текст, изображения, аудио, видео и файлы в качестве контекста для модели, чтобы генерировать более релевантные и осмысленные ответы. Узел автоматически обрабатывает все взаимодействия с API и разбор ответов.

**Примечание:** Данный узел помечен как устаревший в исходном коде.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовые входные данные для модели, используемые для генерации ответа. Вы можете включать подробные инструкции, вопросы или контекст для модели. По умолчанию: пустая строка. | STRING | Да | - |
| `модель` | Модель Gemini, используемая для генерации ответов. По умолчанию: gemini-3-1-pro. | COMBO | Да | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `сид` | Когда значение seed зафиксировано, модель прилагает все усилия, чтобы обеспечить одинаковый ответ для повторных запросов. Детерминированный вывод не гарантируется. Кроме того, изменение модели или настроек параметров, таких как температура, может вызывать изменения в ответе даже при использовании одного и того же значения seed. По умолчанию используется случайное значение seed. По умолчанию: 42. | INT | Да | 0 до 18446744073709551615 |
| `изображения` | Необязательное изображение (изображения) для использования в качестве контекста для модели. Чтобы включить несколько изображений, вы можете использовать узел Batch Images. По умолчанию: нет. | IMAGE | Нет | - |
| `аудио` | Необязательное аудио для использования в качестве контекста для модели. По умолчанию: нет. | AUDIO | Нет | - |
| `видео` | Необязательное видео для использования в качестве контекста для модели. По умолчанию: нет. | VIDEO | Нет | - |
| `файлы` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. По умолчанию: нет. | GEMINI_INPUT_FILES | Нет | - |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию: пустая строка. Это параметр расширенного уровня. | STRING | Нет | - |

Все подключенные изображения используются в качестве контекста. Если передано более 10 изображений, первые 10 загружаются как файловые ссылки, а остальные изображения отправляются непосредственно в API.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовый ответ, сгенерированный моделью Gemini. Если модель не создает текст, узел возвращает «Empty response from Gemini model...». | STRING |
