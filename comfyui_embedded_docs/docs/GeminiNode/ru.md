# Google Gemini

Этот узел позволяет пользователям взаимодействовать с моделями Google Gemini AI для генерации текстовых ответов. Вы можете предоставлять различные типы входных данных, включая текст, изображения, аудио, видео и файлы, в качестве контекста для модели, чтобы генерировать более релевантные и осмысленные ответы. Узел автоматически обрабатывает все API-взаимодействия и разбор ответов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовые входные данные для модели, используемые для генерации ответа. Вы можете включать подробные инструкции, вопросы или контекст для модели. По умолчанию: пустая строка. | STRING | Да | - |
| `model` | Модель Gemini для генерации ответов. По умолчанию: gemini-3-1-pro. | COMBO | Да | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | Когда seed фиксирован на определенном значении, модель прилагает все усилия, чтобы обеспечить одинаковый ответ на повторные запросы. Детерминированный вывод не гарантируется. Кроме того, изменение модели или настроек параметров, таких как температура, может вызвать изменения в ответе, даже если вы используете то же значение seed. По умолчанию используется случайное значение seed. По умолчанию: 42. | INT | Да | 0 to 18446744073709551615 |
| `images` | Необязательные изображения для использования в качестве контекста для модели. Чтобы включить несколько изображений, вы можете использовать узел Batch Images. По умолчанию: нет. | IMAGE | Нет | - |
| `audio` | Необязательное аудио для использования в качестве контекста для модели. По умолчанию: нет. | AUDIO | Нет | - |
| `video` | Необязательное видео для использования в качестве контекста для модели. По умолчанию: нет. | VIDEO | Нет | - |
| `files` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. По умолчанию: нет. | GEMINI_INPUT_FILES | Нет | - |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию: пустая строка. Это расширенный параметр. | STRING | Нет | - |

Примечание: этот узел помечен как устаревший.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `STRING` | Текстовый ответ, сгенерированный моделью Gemini. Если модель не возвращает текст, узел выводит "Empty response from Gemini model...". | STRING |
