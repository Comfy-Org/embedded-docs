# Google Gemini

צומת זה מאפשר למשתמשים לתקשר עם מודלי Gemini AI של Google כדי ליצור תגובות טקסט. ניתן לספק סוגים מרובים של קלטים, כולל טקסט, תמונות, אודיו, וידאו וקבצים, כהקשר עבור המודל כדי ליצור תגובות רלוונטיות ומשמעותיות יותר. הצומת מטפל באופן אוטומטי בכל התקשורת עם ה-API וניתוח התגובות.

**הערה:** צומת זה מסומן כמיושן בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | קלטי טקסט עבור המודל, המשמשים ליצירת תגובה. ניתן לכלול הוראות מפורטות, שאלות או הקשר עבור המודל. ברירת מחדל: מחרוזת ריקה. | STRING | כן | - |
| `model` | מודל Gemini שיש להשתמש בו ליצירת תגובות. ברירת מחדל: gemini-3-1-pro. | COMBO | כן | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | כאשר ה-seed מוגדר לערך מסוים, המודל עושה מאמץ מרבי לספק את אותה תגובה לבקשות חוזרות. פלט דטרמיניסטי אינו מובטח. כמו כן, שינוי המודל או הגדרות פרמטר, כגון temperature, יכול לגרום לשינויים בתגובה גם כאשר משתמשים באותו ערך seed. כברירת מחדל, נעשה שימוש בערך seed אקראי. ברירת מחדל: 42. | INT | כן | 0 עד 18446744073709551615 |
| `images` | תמונה/תמונות אופציונליות לשימוש כהקשר עבור המודל. כדי לכלול מספר תמונות, ניתן להשתמש בצומת Batch Images. ברירת מחדל: ללא. | IMAGE | לא | - |
| `audio` | אודיו אופציונלי לשימוש כהקשר עבור המודל. ברירת מחדל: ללא. | AUDIO | לא | - |
| `video` | וידאו אופציונלי לשימוש כהקשר עבור המודל. ברירת מחדל: ללא. | VIDEO | לא | - |
| `files` | קובץ/קבצים אופציונליים לשימוש כהקשר עבור המודל. מקבל קלטים מהצומת Gemini Generate Content Input Files. ברירת מחדל: ללא. | GEMINI_INPUT_FILES | לא | - |
| `system_prompt` | הוראות בסיסיות שמכתיבות את התנהגות ה-AI. ברירת מחדל: מחרוזת ריקה. זהו פרמטר מתקדם. | STRING | לא | - |

כל התמונות המחוברות משמשות כהקשר. כאשר מסופקות יותר מ-10 תמונות, 10 הראשונות מועלות כהפניות לקבצים והתמונות הנותרות נשלחות באופן מוטבע ל-API.

הצומת משתמש בשם המודל שנבחר כפי שהוא מופיע ברשימה; חלק מהרשומות ממופות פנימית למזהי מודל ה-API הנוכחיים שלהן לפני שליחת הבקשה.
