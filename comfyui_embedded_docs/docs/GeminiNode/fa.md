# Google Gemini

این گره به کاربران امکان می‌دهد با مدل‌های هوش مصنوعی Gemini گوگل تعامل کنند و پاسخ‌های متنی تولید کنند. شما می‌توانید انواع مختلفی از ورودی‌ها از جمله متن، تصویر، صوت، ویدئو و فایل‌ها را به‌عنوان زمینه (context) برای مدل فراهم کنید تا پاسخ‌های مرتبط‌تر و معنادارتری تولید شود. این گره به‌طور خودکار تمام ارتباطات API و تجزیه و تحلیل پاسخ را مدیریت می‌کند.

**توجه:** این گره در کد منبع به‌عنوان منسوخ (deprecated) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | ورودی‌های متنی به مدل که برای تولید پاسخ استفاده می‌شوند. می‌توانید دستورالعمل‌های دقیق، سؤال‌ها یا زمینه را برای مدل وارد کنید. پیش‌فرض: رشته خالی. | STRING | بله | - |
| `مدل` | مدل Gemini که برای تولید پاسخ‌ها استفاده می‌شود. پیش‌فرض: gemini-3-1-pro. | COMBO | بله | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | وقتی seed روی یک مقدار ثابت تنظیم شود، مدل بهترین تلاش خود را می‌کند تا برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. همچنین تغییر مدل یا تنظیمات پارامترهایی مانند دما (temperature) می‌تواند باعث تغییر در پاسخ شود حتی اگر از همان مقدار seed استفاده کنید. به‌طور پیش‌فرض، یک مقدار seed تصادفی استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 18446744073709551615 |
| `تصاویر` | تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. برای گنجاندن چند تصویر می‌توانید از گره Batch Images استفاده کنید. پیش‌فرض: None. | IMAGE | خیر | - |
| `صوت` | صوت اختیاری برای استفاده به‌عنوان زمینه برای مدل. پیش‌فرض: None. | AUDIO | خیر | - |
| `ویدئو` | ویدئوی اختیاری برای استفاده به‌عنوان زمینه برای مدل. پیش‌فرض: None. | VIDEO | خیر | - |
| `فایل‌ها` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌ها را از گره Gemini Generate Content Input Files می‌پذیرد. پیش‌فرض: None. | GEMINI_INPUT_FILES | خیر | - |

همه تصاویر متصل به‌عنوان زمینه استفاده می‌شوند. وقتی بیش از ۱۰ تصویر ارائه شود، ۱۰ تصویر اول به‌عنوان ارجاع فایل بارگذاری می‌شوند و تصاویر باقی‌مانده به‌صورت درون‌خطی (inline) به API ارسال می‌شوند.
