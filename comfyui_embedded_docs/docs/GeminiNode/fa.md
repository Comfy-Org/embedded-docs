# Google Gemini

این گره به کاربران امکان می‌دهد تا با مدل‌های هوش مصنوعی Gemini گوگل تعامل کنند و پاسخ‌های متنی تولید کنند. شما می‌توانید انواع مختلفی از ورودی‌ها از جمله متن، تصویر، صدا، ویدیو و فایل‌ها را به‌عنوان زمینه (context) برای مدل فراهم کنید تا پاسخ‌های مرتبط‌تر و معنادارتری تولید شود. این گره به‌طور خودکار تمام ارتباطات API و تجزیه‌وتحلیل پاسخ‌ها را مدیریت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ورودی‌های متنی به مدل، که برای تولید پاسخ استفاده می‌شوند. می‌توانید دستورالعمل‌های دقیق، سؤال‌ها یا زمینه را برای مدل در این قسمت قرار دهید. پیش‌فرض: رشته خالی. | STRING | بله | - |
| `model` | مدل Gemini که برای تولید پاسخ‌ها استفاده می‌شود. پیش‌فرض: gemini-3-1-pro. | COMBO | بله | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | وقتی seed روی یک مقدار مشخص ثابت شود، مدل بهترین تلاش خود را می‌کند تا برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. همچنین تغییر مدل یا تنظیمات پارامتر، مانند دما (temperature)، می‌تواند حتی با استفاده از همان مقدار seed باعث تغییر در پاسخ شود. به‌طور پیش‌فرض، از یک مقدار seed تصادفی استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 18446744073709551615 |
| `images` | تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. برای گنجاندن چند تصویر، می‌توانید از گره Batch Images استفاده کنید. پیش‌فرض: None. | IMAGE | خیر | - |
| `audio` | صدای اختیاری برای استفاده به‌عنوان زمینه برای مدل. پیش‌فرض: None. | AUDIO | خیر | - |
| `video` | ویدیوی اختیاری برای استفاده به‌عنوان زمینه برای مدل. پیش‌فرض: None. | VIDEO | خیر | - |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌های گره Gemini Generate Content Input Files را می‌پذیرد. پیش‌فرض: None. | GEMINI_INPUT_FILES | خیر | - |
| `system_prompt` | دستورالعمل‌های بنیادین که رفتار هوش مصنوعی را تعیین می‌کنند. پیش‌فرض: رشته خالی. این یک پارامتر پیشرفته است. | STRING | خیر | - |

توجه: این گره به‌عنوان منسوخ‌شده (deprecated) علامت‌گذاری شده است.
