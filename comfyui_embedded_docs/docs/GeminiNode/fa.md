# Google Gemini

این گره به کاربران امکان می‌دهد با مدل‌های هوش مصنوعی Gemini شرکت Google تعامل کرده و پاسخ‌های متنی تولید کنند. می‌توانید چندین نوع ورودی شامل متن، تصویر، صدا، ویدئو و فایل را به‌عنوان زمینه در اختیار مدل قرار دهید تا پاسخ‌های مرتبط‌تر و معنادارتری تولید کند. این گره تمام ارتباطات API و تجزیه پاسخ را به‌صورت خودکار انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | ورودی‌های متنی به مدل که برای تولید پاسخ استفاده می‌شوند. می‌توانید دستورالعمل‌های دقیق، پرسش‌ها یا زمینه را برای مدل بنویسید. پیش‌فرض: رشته خالی. | STRING | بله | - |
| `مدل` | مدل Gemini برای تولید پاسخ‌ها. پیش‌فرض: gemini-3-1-pro. | COMBO | بله | "gemini-2.5-pro"<br>"gemini-2.5-flash"<br>"gemini-3-pro-preview"<br>"gemini-3-1-pro"<br>"gemini-3-1-flash-lite" |
| `seed` | وقتی seed روی یک مقدار مشخص ثابت می‌شود، مدل نهایت تلاش خود را می‌کند تا برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد. خروجی قطعی تضمین نمی‌شود. همچنین، تغییر مدل یا تنظیمات پارامتر مانند temperature می‌تواند حتی هنگام استفاده از همان مقدار seed باعث تغییراتی در پاسخ شود. به‌طور پیش‌فرض، از یک مقدار seed تصادفی استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 18446744073709551615 |
| `تصاویر` | تصویر(های) اختیاری برای استفاده به‌عنوان زمینه مدل. برای افزودن چندین تصویر می‌توانید از گره Batch Images استفاده کنید. پیش‌فرض: None. | IMAGE | خیر | - |
| `صوت` | صوتی اختیاری برای استفاده به‌عنوان زمینه مدل. پیش‌فرض: None. | AUDIO | خیر | - |
| `ویدئو` | ویدئوی اختیاری برای استفاده به‌عنوان زمینه مدل. پیش‌فرض: None. | VIDEO | خیر | - |
| `فایل‌ها` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه مدل. ورودی‌هایی از گره Gemini Generate Content Input Files را می‌پذیرد. پیش‌فرض: None. | GEMINI_INPUT_FILES | خیر | - |
| `system_prompt` | دستورالعمل‌های پایه‌ای که رفتار هوش مصنوعی را تعیین می‌کنند. پیش‌فرض: رشته خالی. این یک پارامتر پیشرفته است. | STRING | خیر | - |

همه تصاویر متصل‌شده به‌عنوان زمینه استفاده می‌شوند. وقتی بیش از ۱۰ تصویر ارائه شود، ۱۰ تصویر اول به‌عنوان ارجاع فایل بارگذاری می‌شوند و تصاویر باقی‌مانده به‌صورت درون‌خطی به API فرستاده می‌شوند.

این گره از نام مدل انتخاب‌شده همان‌طور که در فهرست آمده استفاده می‌کند؛ برخی ورودی‌ها پیش از ارسال درخواست، به‌صورت داخلی به شناسه‌های مدل API فعلی آن‌ها نگاشت می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `STRING` | پاسخ متنی تولیدشده توسط مدل Gemini. اگر مدل متنی تولید نکند، گره "Empty response from Gemini model..." را برمی‌گرداند. | STRING |
