# BriaExpandImage

Bria Expand Image расширяет изображение за его исходные границы, генерируя новый контент с помощью Bria. Вы можете выбрать целевое соотношение сторон, произвольное соотношение или задать холст с ручным размещением исходного изображения. Расширение можно направлять текстовым промптом; если промпт оставить пустым, Bria сгенерирует его автоматически.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для расширения. | IMAGE | Да | — |
| `expand_mode` | Целевая форма расширенного изображения: предустановленное соотношение сторон, произвольное соотношение или ручное размещение исходного изображения на холсте. Режим `manual` — единственный, который позволяет получить холст с соотношением сторон выше 1:2. Выбор `custom_ratio` открывает параметры `ratio_width` и `ratio_height`. Выбор `manual` открывает параметры холста и размещения изображения. | DYNAMIC_COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | Ширина целевого соотношения: 21 и 9 дают 21:9. По умолчанию: 21. | INT | Условно | 1–100 |
| `ratio_height` | Высота целевого соотношения: 21 и 9 дают 21:9. Bria принимает только соотношения ширины к высоте от 0.5 до 3.0, поэтому всё, что выше 1:2, требует режима `manual`. По умолчанию: 9. | INT | Условно | 1–100 |
| `canvas_width` | Ширина выходного холста в пикселях. По умолчанию: 1000. | INT | Условно | 64–5000 |
| `canvas_height` | Высота выходного холста в пикселях. По умолчанию: 1000. | INT | Условно | 64–5000 |
| `image_width` | Ширина исходного изображения внутри холста. По умолчанию: 500. | INT | Условно | 1–5000 |
| `image_height` | Высота исходного изображения внутри холста. По умолчанию: 500. | INT | Условно | 1–5000 |
| `image_x` | X-позиция верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Условно | -5000–5000 |
| `image_y` | Y-позиция верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Условно | -5000–5000 |
| `prompt` | Необязательное описание расширяемой сцены; если пусто, Bria генерирует его на основе изображения. По умолчанию: пустая строка. | STRING | Нет | Любая строка |
| `negative_prompt` | Необязательный негативный промпт для расширения. По умолчанию: пустая строка. | STRING | Нет | Любая строка |
| `seed` | Сид для процесса случайной генерации. По умолчанию: 42. | INT | Нет | 1–2147483647 |
| `moderation` | Настройки модерации. Если установлено `true`, отображаются дополнительные параметры модерации. | DYNAMIC_COMBO | Нет | `"false"`<br>`"true"` |
| `prompt_content_moderation` | Если включено, проверяет содержимое промпта. По умолчанию: false. Доступно только когда `moderation` установлено в `true`. | BOOLEAN | Условно | true/false |
| `visual_input_moderation` | Если включено, проверяет визуальный вход. По умолчанию: false. Доступно только когда `moderation` установлено в `true`. | BOOLEAN | Условно | true/false |
| `visual_output_moderation` | Если включено, проверяет визуальный выход. По умолчанию: false. Доступно только когда `moderation` установлено в `true`. | BOOLEAN | Условно | true/false |

Когда `expand_mode` равен `custom_ratio`, параметры `ratio_width` и `ratio_height` задают целевое соотношение сторон. Bria принимает только соотношения ширины к высоте от 0.5 до 3.0. Если соотношение выходит за этот диапазон, возникает ошибка, и вместо этого следует использовать режим `manual`.

Когда `expand_mode` равен `manual`, исходное изображение размещается на холсте с заданным размером и положением. Изображение может выходить за пределы холста, и в этом случае выступающая часть обрезается.

Когда `moderation` установлено в `true`, три логических параметра модерации отправляются в Bria. Когда `moderation` установлено в `false`, они игнорируются.

## Выходные параметры

| Выходное имя | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Расширенное изображение, сгенерированное Bria. | IMAGE |
| `prompt` | Промпт, использованный для расширения; автоматически сгенерированный Bria, когда входной промпт пуст. | STRING |
