# BriaExpandImage

Bria Expand Image расширяет изображение за его исходные границы, генерируя новое содержимое с помощью Bria. Он позволяет выбрать целевое соотношение сторон, произвольное соотношение или задать холст с ручным размещением исходного изображения. Расширение можно направлять текстовым запросом, а если запрос оставить пустым, Bria сгенерирует его автоматически.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `изображение` | Входное изображение для расширения. | IMAGE | Да | — |
| `expand_mode` | Целевая форма расширенного изображения: предустановленное соотношение сторон, произвольное соотношение или ручное размещение исходного изображения на холсте. Ручной режим — единственный, который может достичь холста выше, чем 1:2. Выбор `custom_ratio` открывает `ratio_width` и `ratio_height`. Выбор `manual` открывает параметры холста и размещения изображения. | DYNAMIC_COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | Ширина целевого соотношения: 21 и 9 дают 21:9. По умолчанию: 21. | INT | Условно | 1–100 |
| `ratio_height` | Высота целевого соотношения: 21 и 9 дают 21:9. Bria принимает только соотношения ширины к высоте от 0.5 до 3.0, поэтому все, что выше 1:2, требует ручного режима. По умолчанию: 9. | INT | Условно | 1–100 |
| `canvas_width` | Ширина выходного холста в пикселях. По умолчанию: 1000. | INT | Условно | 64–5000 |
| `canvas_height` | Высота выходного холста в пикселях. По умолчанию: 1000. | INT | Условно | 64–5000 |
| `image_width` | Ширина исходного изображения внутри холста. По умолчанию: 500. | INT | Условно | 1–5000 |
| `image_height` | Высота исходного изображения внутри холста. По умолчанию: 500. | INT | Условно | 1–5000 |
| `image_x` | Позиция X верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Условно | -5000–5000 |
| `image_y` | Позиция Y верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Условно | -5000–5000 |
| `запрос` | Необязательное описание расширенной сцены; если пусто, Bria генерирует его из изображения. По умолчанию: пустая строка. | STRING | Нет | Любая строка |
| `negative_prompt` | Необязательный негативный запрос для расширения. По умолчанию: пустая строка. | STRING | Нет | Любая строка |
| `seed` | Зерно для процесса случайной генерации. По умолчанию: 42. | INT | Нет | 1–2147483647 |
| `модерация` | Настройки модерации. Если установлено `true`, отображаются дополнительные параметры модерации. | DYNAMIC_COMBO | Нет | `"false"`<br>`"true"` |
| `prompt_content_moderation` | Если включено, модерирует содержимое запроса. По умолчанию: false. Доступно только когда `moderation` установлено `true`. | BOOLEAN | Условно | true/false |
| `visual_input_moderation` | Если включено, модерирует визуальный вход. По умолчанию: false. Доступно только когда `moderation` установлено `true`. | BOOLEAN | Условно | true/false |
| `visual_output_moderation` | Если включено, модерирует визуальный выход. По умолчанию: false. Доступно только когда `moderation` установлено `true`. | BOOLEAN | Условно | true/false |

Когда `expand_mode` установлен в `custom_ratio`, параметры `ratio_width` и `ratio_height` определяют целевое соотношение сторон. Bria принимает только соотношения ширины к высоте от 0.5 до 3.0. Если соотношение выходит за этот диапазон, возникает ошибка, и вместо этого следует использовать режим `manual`.

Когда `expand_mode` установлен в `manual`, исходное изображение размещается на холсте с указанным размером и позицией. Изображение может выходить за пределы холста, и в этом случае выступающая часть обрезается.

Когда `moderation` установлено `true`, три булевых параметра модерации отправляются в Bria. Когда `moderation` установлено `false`, они игнорируются.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Расширенное изображение, сгенерированное Bria. | IMAGE |
| `запрос` | Запрос, использованный для расширения; автоматически генерируется Bria, если входной запрос пуст. | STRING |
