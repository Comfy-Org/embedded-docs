# Bria Expand Image

Bria Expand Image расширяет изображение за пределы его исходных границ, генерируя новое содержимое с помощью Bria. Он позволяет выбрать целевое соотношение сторон, пользовательское соотношение или определить холст с ручным размещением исходного изображения. Расширение можно направлять текстовым промптом; если оставить промпт пустым, Bria автоматически сгенерирует его.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, которое нужно расширить. | IMAGE | Да | — |
| `expand_mode` | Целевая форма расширенного изображения: предустановленное соотношение сторон, пользовательское соотношение или ручное размещение исходного изображения на холсте. Ручной режим — единственный режим, который может создать холст, более вытянутый по высоте, чем 1:2. Выбор `custom_ratio` показывает `ratio_width` и `ratio_height`. Выбор `manual` показывает параметры холста и размещения изображения. | DYNAMIC_COMBO | Да | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `запрос` | Необязательное описание расширяемой сцены; если пусто, Bria генерирует его на основе изображения. По умолчанию: пустая строка. | STRING | Да | Любая строка |
| `negative_prompt` | Необязательный негативный промпт для расширения. По умолчанию: пустая строка. | STRING | Да | Любая строка |
| `seed` | Сид для процесса случайной генерации. По умолчанию: 42. | INT | Да | 1–2147483647 |
| `модерация` | Настройки модерации. При значении `true` отображаются дополнительные параметры модерации. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы пользовательского соотношения

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ratio_width` | Сторона ширины целевого соотношения: 21 и 9 дают 21:9. По умолчанию: 21. | INT | Да | 1–100 |
| `ratio_height` | Сторона высоты целевого соотношения: 21 и 9 дают 21:9. Bria принимает только отношение ширины к высоте от 0.5 до 3.0, поэтому всё, что более вытянуто по высоте, чем 1:2, требует ручного режима. По умолчанию: 9. | INT | Да | 1–100 |

### Входы ручного режима

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `canvas_width` | Ширина выходного холста в пикселях. По умолчанию: 1000. | INT | Да | 64–5000 |
| `canvas_height` | Высота выходного холста в пикселях. По умолчанию: 1000. | INT | Да | 64–5000 |
| `image_width` | Ширина исходного изображения внутри холста. По умолчанию: 500. | INT | Да | 1–5000 |
| `image_height` | Высота исходного изображения внутри холста. По умолчанию: 500. | INT | Да | 1–5000 |
| `image_x` | Позиция X верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Да | -5000–5000 |
| `image_y` | Позиция Y верхнего левого угла изображения внутри холста; может выходить за пределы холста, обрезая изображение. По умолчанию: 250. | INT | Да | -5000–5000 |

### Входы модерации

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | Если включено, модерирует содержимое промпта. По умолчанию: false. Доступно только когда `moderation` имеет значение `true`. | BOOLEAN | Да | true/false |
| `visual_input_moderation` | Если включено, модерирует визуальный вход. По умолчанию: false. Доступно только когда `moderation` имеет значение `true`. | BOOLEAN | Да | true/false |
| `visual_output_moderation` | Если включено, модерирует визуальный выход. По умолчанию: false. Доступно только когда `moderation` имеет значение `true`. | BOOLEAN | Да | true/false |

Предустановленные варианты соотношения сторон (`1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`) не имеют дополнительных входов.

Когда `expand_mode` имеет значение `custom_ratio`, `ratio_width` и `ratio_height` задают целевое соотношение сторон. Bria принимает только отношения ширины к высоте от 0.5 до 3.0. Если соотношение выходит за этот диапазон, возникает ошибка, и вместо этого следует использовать режим `manual`.

Когда `expand_mode` имеет значение `manual`, исходное изображение размещается на холсте с указанным размером и позицией. Изображение может выходить за пределы холста; в этом случае внешняя часть обрезается.

Когда `moderation` имеет значение `true`, три булевых параметра модерации отправляются в Bria. Когда `moderation` имеет значение `false`, они игнорируются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Расширенное изображение, сгенерированное Bria. | IMAGE |
| `prompt` | Промпт, использованный для расширения; автоматически генерируется Bria, когда входной промпт пуст. | STRING |
