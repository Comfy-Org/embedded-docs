# BriaExpandImage

گره Bria Expand Image تصویری را فراتر از مرزهای اصلی‌اش با تولید محتوای جدید توسط Bria گسترش می‌دهد. این گره به شما امکان می‌دهد نسبت تصویر هدف، نسبت سفارشی، یا بوم‌بندی با قرارگیری دستی تصویر اصلی را انتخاب کنید. گسترش را می‌توان با یک متن راهنما هدایت کرد؛ اگر متن راهنما خالی بماند، Bria به‌صورت خودکار یکی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی برای گسترش. | IMAGE | بله | — |
| `expand_mode` | شکل هدف تصویر گسترش‌یافته: نسبت تصویر از پیش تعیین‌شده، نسبت سفارشی، یا قرارگیری دستی تصویر اصلی روی بوم. حالت Manual تنها حالتی است که می‌تواند به بومی بلندتر از 1:2 برسد. انتخاب `custom_ratio` پارامترهای `ratio_width` و `ratio_height` را نمایان می‌کند. انتخاب `manual` پارامترهای بوم و جای‌گذاری تصویر را نمایان می‌کند. | DYNAMIC_COMBO | بله | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | عرض نسبت هدف: 21 و 9 نسبت 21:9 می‌دهند. پیش‌فرض: 21. | INT | مشروط | 1–100 |
| `ratio_height` | ارتفاع نسبت هدف: 21 و 9 نسبت 21:9 می‌دهند. Bria تنها نسبت‌های عرض به ارتفاع بین 0.5 و 3.0 را می‌پذیرد، بنابراین هر چیزی بلندتر از 1:2 به حالت manual نیاز دارد. پیش‌فرض: 9. | INT | مشروط | 1–100 |
| `canvas_width` | عرض بوم خروجی بر حسب پیکسل. پیش‌فرض: 1000. | INT | مشروط | 64–5000 |
| `canvas_height` | ارتفاع بوم خروجی بر حسب پیکسل. پیش‌فرض: 1000. | INT | مشروط | 64–5000 |
| `image_width` | عرض تصویر اصلی داخل بوم. پیش‌فرض: 500. | INT | مشروط | 1–5000 |
| `image_height` | ارتفاع تصویر اصلی داخل بوم. پیش‌فرض: 500. | INT | مشروط | 1–5000 |
| `image_x` | موقعیت X گوشه بالا-چپ تصویر داخل بوم؛ ممکن است خارج از بوم قرار گیرد و تصویر برش بخورد. پیش‌فرض: 250. | INT | مشروط | -5000–5000 |
| `image_y` | موقعیت Y گوشه بالا-چپ تصویر داخل بوم؛ ممکن است خارج از بوم قرار گیرد و تصویر برش بخورد. پیش‌فرض: 250. | INT | مشروط | -5000–5000 |
| `prompt` | توضیح اختیاری صحنه گسترش‌یافته؛ وقتی خالی باشد، Bria از روی تصویر تولید می‌کند. پیش‌فرض: رشته خالی. | STRING | خیر | هر رشته‌ای |
| `negative_prompt` | یک متن راهنمای منفی اختیاری برای گسترش. پیش‌فرض: رشته خالی. | STRING | خیر | هر رشته‌ای |
| `seed` | دانه (seed) برای فرآیند تولید تصادفی. پیش‌فرض: 42. | INT | خیر | 1–2147483647 |
| `moderation` | تنظیمات نظارت. وقتی روی `true` تنظیم شود، گزینه‌های نظارت اضافی نمایش داده می‌شوند. | DYNAMIC_COMBO | خیر | `"false"`<br>`"true"` |
| `prompt_content_moderation` | در صورت فعال‌بودن، محتوای prompt را نظارت می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` روی `true` باشد. | BOOLEAN | مشروط | true/false |
| `visual_input_moderation` | در صورت فعال‌بودن، ورودی بصری را نظارت می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` روی `true` باشد. | BOOLEAN | مشروط | true/false |
| `visual_output_moderation` | در صورت فعال‌بودن، خروجی بصری را نظارت می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` روی `true` باشد. | BOOLEAN | مشروط | true/false |

وقتی `expand_mode` برابر با `custom_ratio` باشد، `ratio_width` و `ratio_height` نسبت تصویر هدف را تعریف می‌کنند. Bria فقط نسبت‌های عرض به ارتفاع بین 0.5 و 3.0 را می‌پذیرد. اگر نسبت خارج از این محدوده باشد، خطا رخ می‌دهد و باید به‌جای آن از حالت `manual` استفاده شود.

وقتی `expand_mode` برابر با `manual` باشد، تصویر اصلی با اندازه و موقعیت مشخص روی بوم قرار می‌گیرد. تصویر ممکن است بیرون از بوم کشیده شود؛ در این صورت بخش بیرونی برش می‌خورد.

وقتی `moderation` روی `true` باشد، هر سه مقدار بولی نظارت به Bria ارسال می‌شوند. وقتی `moderation` روی `false` باشد، نادیده گرفته می‌شوند.
