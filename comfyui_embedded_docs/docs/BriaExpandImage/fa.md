# BriaExpandImage

Bria Expand Image با تولید محتوای جدید توسط Bria، تصویر را فراتر از مرزهای اصلی‌اش گسترش می‌دهد. این گره به شما امکان می‌دهد نسبت ابعاد هدف، نسبت سفارشی، یا یک بوم با قرارگیری دستی تصویر اصلی را انتخاب کنید. گسترش را می‌توان با یک متن راهنما (prompt) هدایت کرد؛ اگر متن راهنما خالی بماند، Bria به‌طور خودکار یکی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که قرار است گسترش یابد. | IMAGE | بله | — |
| `expand_mode` | شکل هدف تصویر گسترش‌یافته: نسبت ابعاد از پیش تعیین‌شده، نسبت سفارشی، یا قرارگیری دستی تصویر اصلی روی بوم. حالت manual تنها حالتی است که می‌تواند به بوم بلندتر از 1:2 دست یابد. انتخاب `custom_ratio` پارامترهای `ratio_width` و `ratio_height` را نمایش می‌دهد. انتخاب `manual` پارامترهای بوم و جای‌گذاری تصویر را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | سمت عرض نسبت هدف: 21 و 9 نسبت 21:9 را می‌سازند. پیش‌فرض: 21. | INT | شرطی | 1–100 |
| `ratio_height` | سمت ارتفاع نسبت هدف: 21 و 9 نسبت 21:9 را می‌سازند. Bria فقط نسبت عرض/ارتفاع بین 0.5 و 3.0 را می‌پذیرد، بنابراین هر چیزی بلندتر از 1:2 به حالت manual نیاز دارد. پیش‌فرض: 9. | INT | شرطی | 1–100 |
| `canvas_width` | عرض بوم خروجی بر حسب پیکسل. پیش‌فرض: 1000. | INT | شرطی | 64–5000 |
| `canvas_height` | ارتفاع بوم خروجی بر حسب پیکسل. پیش‌فرض: 1000. | INT | شرطی | 64–5000 |
| `image_width` | عرض تصویر اصلی داخل بوم. پیش‌فرض: 500. | INT | شرطی | 1–5000 |
| `image_height` | ارتفاع تصویر اصلی داخل بوم. پیش‌فرض: 500. | INT | شرطی | 1–5000 |
| `image_x` | موقعیت X گوشه بالا-چپ تصویر داخل بوم؛ ممکن است خارج از بوم قرار گیرد و تصویر برش بخورد. پیش‌فرض: 250. | INT | شرطی | -5000–5000 |
| `image_y` | موقعیت Y گوشه بالا-چپ تصویر داخل بوم؛ ممکن است خارج از بوم قرار گیرد و تصویر برش بخورد. پیش‌فرض: 250. | INT | شرطی | -5000–5000 |
| `prompt` | توضیح اختیاری صحنه گسترش‌یافته؛ وقتی خالی باشد، Bria یکی را از روی تصویر تولید می‌کند. پیش‌فرض: رشته خالی. | STRING | خیر | هر رشته‌ای |
| `negative_prompt` | یک متن راهنمای منفی (negative prompt) اختیاری برای گسترش. پیش‌فرض: رشته خالی. | STRING | خیر | هر رشته‌ای |
| `seed` | مقدار seed برای فرآیند تولید تصادفی. پیش‌فرض: 42. | INT | خیر | 1–2147483647 |
| `moderation` | تنظیمات تعدیل محتوا. وقتی روی `true` تنظیم شود، گزینه‌های تعدیل اضافی نمایش داده می‌شوند. | DYNAMIC_COMBO | خیر | `"false"`<br>`"true"` |
| `prompt_content_moderation` | در صورت فعال بودن، محتوای متن راهنما را تعدیل می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` برابر `true` باشد. | BOOLEAN | شرطی | true/false |
| `visual_input_moderation` | در صورت فعال بودن، ورودی تصویری را تعدیل می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` برابر `true` باشد. | BOOLEAN | شرطی | true/false |
| `visual_output_moderation` | در صورت فعال بودن، خروجی تصویری را تعدیل می‌کند. پیش‌فرض: false. فقط زمانی در دسترس است که `moderation` برابر `true` باشد. | BOOLEAN | شرطی | true/false |

وقتی `expand_mode` برابر `custom_ratio` باشد، `ratio_width` و `ratio_height` نسبت ابعاد هدف را تعریف می‌کنند. Bria فقط نسبت عرض به ارتفاع بین 0.5 و 3.0 را می‌پذیرد. اگر نسبت خارج از این محدوده باشد، خطایی ایجاد می‌شود و باید از حالت `manual` استفاده کرد.

وقتی `expand_mode` برابر `manual` باشد، تصویر اصلی با اندازه و موقعیت مشخص‌شده روی بوم قرار می‌گیرد. تصویر ممکن است از بوم بیرون بزند؛ در این صورت بخش خارج از بوم برش داده می‌شود.

وقتی `moderation` برابر `true` باشد، هر سه مقدار بولی تعدیل به Bria ارسال می‌شوند. وقتی `moderation` برابر `false` باشد، این مقادیر نادیده گرفته می‌شوند.
