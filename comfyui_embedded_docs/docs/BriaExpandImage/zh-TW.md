# Bria 擴展影像

Bria Expand Image 透過使用 Bria 生成新內容，將影像擴展到其原始邊界之外。它可讓您選擇目標長寬比、自訂比例，或定義畫布並手動放置原始影像。擴展可透過文字提示詞引導，若提示詞留空，Bria 會自動生成一個。

## 輸入

|-----------|-------------|-----------|----------|-------|

### 審核輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 若啟用，會審核提示詞內容。預設值：false。僅在 `moderation` 為 `true` 時可用。 | BOOLEAN | 是 | true/false |
| `visual_input_moderation` | 若啟用，會審核視覺輸入。預設值：false。僅在 `moderation` 為 `true` 時可用。 | BOOLEAN | 是 | true/false |
| `visual_output_moderation` | 若啟用，會審核視覺輸出。預設值：false。僅在 `moderation` 為 `true` 時可用。 | BOOLEAN | 是 | true/false |

預設長寬比選項（`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`）沒有其他輸入。

當 `expand_mode` 為 `custom_ratio` 時，`ratio_width` 和 `ratio_height` 會定義目標長寬比。Bria 只接受介於 0.5 與 3.0 之間的寬高比。若比例超出此範圍，會引發錯誤，此時應改用 `manual` 模式。

當 `expand_mode` 為 `manual` 時，原始影像會以指定的大小與位置放置在畫布上。影像可能延伸到畫布之外，此時畫布外的部分會被裁切。

當 `moderation` 為 `true` 時，這三個審核布林值會傳送給 Bria。當 `moderation` 為 `false` 時，它們會被忽略。
