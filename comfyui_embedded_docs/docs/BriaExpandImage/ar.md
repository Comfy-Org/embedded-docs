# BriaExpandImage

توسّع أداة Bria Expand Image الصورة خارج حدودها الأصلية عن طريق توليد محتوى جديد باستخدام Bria. تتيح لك اختيار نسبة أبعاد مستهدفة، أو نسبة مخصّصة، أو تحديد لوحة رسم مع وضع يدوي للصورة الأصلية. يمكن توجيه عملية التوسيع باستخدام نص وصفي (prompt)، وستقوم Bria بتوليد نص تلقائيًا إذا تُرك حقل النص فارغًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة التي سيتم توسيعها. | IMAGE | نعم | — |
| `expand_mode` | الشكل المستهدف للصورة الموسعة: نسبة أبعاد محددة مسبقًا، أو نسبة مخصّصة، أو وضع يدوي للصورة الأصلية على لوحة رسم. الوضع اليدوي هو الوضع الوحيد الذي يمكنه الوصول إلى لوحة رسم أطول من 1:2. اختيار `custom_ratio` يُظهر `ratio_width` و`ratio_height`. اختيار `manual` يُظهر معاملات لوحة الرسم وموضع الصورة. | DYNAMIC_COMBO | نعم | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | جانب العرض في النسبة المستهدفة: الرقمان 21 و9 يعطيان 21:9. الافتراضي: 21. | INT | شرطي | 1–100 |
| `ratio_height` | جانب الارتفاع في النسبة المستهدفة: الرقمان 21 و9 يعطيان 21:9. تقبل Bria فقط نسب العرض/الارتفاع بين 0.5 و3.0، لذا فإن أي نسبة أطول من 1:2 تتطلب الوضع اليدوي. الافتراضي: 9. | INT | شرطي | 1–100 |
| `canvas_width` | عرض لوحة الرسم الناتجة بالبكسل. الافتراضي: 1000. | INT | شرطي | 64–5000 |
| `canvas_height` | ارتفاع لوحة الرسم الناتجة بالبكسل. الافتراضي: 1000. | INT | شرطي | 64–5000 |
| `image_width` | عرض الصورة الأصلية داخل لوحة الرسم. الافتراضي: 500. | INT | شرطي | 1–5000 |
| `image_height` | ارتفاع الصورة الأصلية داخل لوحة الرسم. الافتراضي: 500. | INT | شرطي | 1–5000 |
| `image_x` | موضع X للزاوية العلوية اليسرى للصورة داخل لوحة الرسم؛ قد يقع خارج لوحة الرسم، مما يؤدي إلى اقتصاص الصورة. الافتراضي: 250. | INT | شرطي | -5000–5000 |
| `image_y` | موضع Y للزاوية العلوية اليسرى للصورة داخل لوحة الرسم؛ قد يقع خارج لوحة الرسم، مما يؤدي إلى اقتصاص الصورة. الافتراضي: 250. | INT | شرطي | -5000–5000 |
| `prompt` | وصف اختياري للمشهد الموسّع؛ عندما يكون فارغًا، تقوم Bria بتوليده من الصورة. الافتراضي: سلسلة فارغة. | STRING | لا | أي سلسلة نصية |
| `negative_prompt` | نص سلبي اختياري لعملية التوسيع. الافتراضي: سلسلة فارغة. | STRING | لا | أي سلسلة نصية |
| `seed` | بذرة التوليد العشوائي للعملية. الافتراضي: 42. | INT | لا | 1–2147483647 |
| `moderation` | إعدادات الإشراف (الاعتدال). عند التعيين على `true`، تظهر خيارات إشراف إضافية. | DYNAMIC_COMBO | لا | `"false"`<br>`"true"` |
| `prompt_content_moderation` | إذا تم التفعيل، يقوم بإشراف محتوى النص. الافتراضي: false. متاح فقط عندما يكون `moderation` هو `true`. | BOOLEAN | شرطي | true/false |
| `visual_input_moderation` | إذا تم التفعيل، يقوم بإشراف المدخلات المرئية. الافتراضي: false. متاح فقط عندما يكون `moderation` هو `true`. | BOOLEAN | شرطي | true/false |
| `visual_output_moderation` | إذا تم التفعيل، يقوم بإشراف المخرجات المرئية. الافتراضي: false. متاح فقط عندما يكون `moderation` هو `true`. | BOOLEAN | شرطي | true/false |

عندما تكون قيمة `expand_mode` هي `custom_ratio`، فإن `ratio_width` و`ratio_height` يحددان نسبة أبعاد مستهدفة. تقبل Bria فقط نسب العرض إلى الارتفاع بين 0.5 و3.0. إذا كانت النسبة خارج هذا النطاق، يتم إصدار خطأ ويجب استخدام الوضع `manual` بدلاً من ذلك.

عندما تكون قيمة `expand_mode` هي `manual`، يتم وضع الصورة الأصلية على لوحة رسم بالحجم والموضع المحددين. قد تمتد الصورة خارج لوحة الرسم، وفي هذه الحالة يتم اقتصاص الجزء الخارجي.

عندما تكون قيمة `moderation` هي `true`، يتم إرسال القيم المنطقية الثلاث للإشراف إلى Bria. وعندما تكون `moderation` هي `false`، يتم تجاهلها.
