# BriaExpandImage

```markdown
تعمل عقدة Bria Expand Image على توسيع صورة تتجاوز حدودها الأصلية عن طريق توليد محتوى جديد باستخدام Bria. تتيح لك اختيار نسبة أبعاد مستهدفة، أو نسبة مخصصة، أو تحديد لوحة قماشية مع وضع يدوي للصورة الأصلية. يمكن توجيه عملية التوسيع باستخدام موجه نصي، وستقوم Bria بتوليد موجه تلقائيًا إذا تُرك حقل الموجه فارغًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة التي سيتم توسيعها. | IMAGE | نعم | — |
| `expand_mode` | الشكل المستهدف للصورة الموسعة: نسبة أبعاد محددة مسبقًا، أو نسبة مخصصة، أو وضع يدوي للصورة الأصلية على لوحة قماشية. الوضع اليدوي هو الوضع الوحيد الذي يمكنه الوصول إلى لوحة قماشية أطول من 1:2. يؤدي اختيار `custom_ratio` إلى إظهار `ratio_width` و`ratio_height`. يؤدي اختيار `manual` إلى إظهار معاملات اللوحة القماشية وموضع الصورة. | DYNAMIC_COMBO | نعم | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `ratio_width` | جانب العرض من النسبة المستهدفة: 21 و9 يعطيان 21:9. الافتراضي: 21. | INT | شرطي | 1–100 |
| `ratio_height` | جانب الارتفاع من النسبة المستهدفة: 21 و9 يعطيان 21:9. تقبل Bria فقط نسب العرض إلى الارتفاع بين 0.5 و3.0، لذا فإن أي نسبة أطول من 1:2 تتطلب الوضع اليدوي. الافتراضي: 9. | INT | شرطي | 1–100 |
| `canvas_width` | عرض لوحة القماش الناتجة بالبكسل. الافتراضي: 1000. | INT | شرطي | 64–5000 |
| `canvas_height` | ارتفاع لوحة القماش الناتجة بالبكسل. الافتراضي: 1000. | INT | شرطي | 64–5000 |
| `image_width` | عرض الصورة الأصلية داخل اللوحة القماشية. الافتراضي: 500. | INT | شرطي | 1–5000 |
| `image_height` | ارتفاع الصورة الأصلية داخل اللوحة القماشية. الافتراضي: 500. | INT | شرطي | 1–5000 |
| `image_x` | موضع X للزاوية العلوية اليسرى للصورة داخل اللوحة القماشية؛ قد يقع خارج اللوحة القماشية، مما يؤدي إلى قص جزء من الصورة. الافتراضي: 250. | INT | شرطي | -5000–5000 |
| `image_y` | موضع Y للزاوية العلوية اليسرى للصورة داخل اللوحة القماشية؛ قد يقع خارج اللوحة القماشية، مما يؤدي إلى قص جزء من الصورة. الافتراضي: 250. | INT | شرطي | -5000–5000 |
| `prompt` | وصف اختياري للمشهد الموسع؛ عندما يكون فارغًا، تقوم Bria بتوليده من الصورة. الافتراضي: سلسلة فارغة. | STRING | لا | أي سلسلة نصية |
| `negative_prompt` | موجه سلبي اختياري للتوسيع. الافتراضي: سلسلة فارغة. | STRING | لا | أي سلسلة نصية |
| `seed` | بذرة عملية التوليد العشوائي. الافتراضي: 42. | INT | لا | 1–2147483647 |
| `moderation` | إعدادات الرقابة. عند التعيين إلى `true`، تظهر خيارات رقابة إضافية. | DYNAMIC_COMBO | لا | `"false"`<br>`"true"` |
| `prompt_content_moderation` | إذا تم تفعيله، يتم فحص محتوى الموجه. الافتراضي: `false`. متاح فقط عندما تكون `moderation` بقيمة `true`. | BOOLEAN | شرطي | true/false |
| `visual_input_moderation` | إذا تم تفعيله، يتم فحص المدخلات المرئية. الافتراضي: `false`. متاح فقط عندما تكون `moderation` بقيمة `true`. | BOOLEAN | شرطي | true/false |
| `visual_output_moderation` | إذا تم تفعيله، يتم فحص المخرجات المرئية. الافتراضي: `false`. متاح فقط عندما تكون `moderation` بقيمة `true`. | BOOLEAN | شرطي | true/false |

عندما تكون `expand_mode` بقيمة `custom_ratio`، فإن `ratio_width` و`ratio_height` يحددان نسبة أبعاد مستهدفة. تقبل Bria فقط نسب العرض إلى الارتفاع بين 0.5 و3.0. إذا كانت النسبة خارج هذا النطاق، يتم رفع خطأ ويجب استخدام الوضع `manual` بدلاً من ذلك.

عندما تكون `expand_mode` بقيمة `manual`، يتم وضع الصورة الأصلية على لوحة قماشية بالحجم والموضع المحددين. قد تمتد الصورة خارج اللوحة القماشية، وفي هذه الحالة يتم قص الجزء الخارجي.

عندما تكون `moderation` بقيمة `true`، يتم إرسال القيم المنطقية للرقابة الثلاث إلى Bria. وعندما تكون `moderation` بقيمة `false`، يتم تجاهلها.
```
