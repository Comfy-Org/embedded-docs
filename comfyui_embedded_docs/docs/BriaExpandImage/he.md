# הרחבת תמונה של Bria

הצומת Bria Expand Image מרחיב תמונה מעבר לגבולותיה המקוריים על ידי יצירת תוכן חדש עם Bria. הוא מאפשר לבחור יחס רוחב-גובה ליעד, יחס מותאם אישית, או להגדיר קנבס עם מיקום ידני של התמונה המקורית. ניתן להנחות את ההרחבה באמצעות פרומפט טקסטואלי, ו-Bria תייצר פרומפט כזה אוטומטית אם הפרומפט יישאר ריק.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט להרחבה. | IMAGE | כן | — |
| `expand_mode` | צורת היעד של התמונה המורחבת: יחס רוחב-גובה מוגדר מראש, יחס מותאם אישית, או מיקום ידני של התמונה המקורית על קנבס. מצב ידני הוא המצב היחיד שיכול להגיע לקנבס גבוה מ-1:2. בחירה ב-`custom_ratio` חושפת את `ratio_width` ואת `ratio_height`. בחירה ב-`manual` חושפת את פרמטרי הקנבס ומיקום התמונה. | DYNAMIC_COMBO | כן | `"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"custom_ratio"`<br>`"manual"` |
| `prompt` | תיאור אופציונלי של הסצנה המורחבת; כאשר ריק, Bria מייצרת פרומפט מהתמונה. ברירת מחדל: מחרוזת ריקה. | STRING | כן | כל מחרוזת |
| `negative_prompt` | פרומפט שלילי אופציונלי להרחבה. ברירת מחדל: מחרוזת ריקה. | STRING | כן | כל מחרוזת |
| `seed` | ערך Seed עבור תהליך היצירה האקראית. ברירת מחדל: 42. | INT | כן | 1–2147483647 |
| `moderation` | הגדרות מודרציה. כאשר מוגדר ל-`true`, מוצגות אפשרויות מודרציה נוספות. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |

### קלטים של יחס מותאם אישית

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `ratio_width` | צד הרוחב של יחס היעד: 21 ו-9 נותנים 21:9. ברירת מחדל: 21. | INT | כן | 1–100 |
| `ratio_height` | צד הגובה של יחס היעד: 21 ו-9 נותנים 21:9. Bria מקבלת רק יחס רוחב/גובה בין 0.5 ל-3.0, כך שכל יחס גבוה מ-1:2 דורש את מצב `manual`. ברירת מחדל: 9. | INT | כן | 1–100 |

|-----------|-------------|-----------|----------|-------|
| `canvas_width` | רוחב קנבס הפלט בפיקסלים. ברירת מחדל: 1000. | INT | כן | 64–5000 |
| `canvas_height` | גובה קנבס הפלט בפיקסלים. ברירת מחדל: 1000. | INT | כן | 64–5000 |
| `image_width` | רוחב התמונה המקורית בתוך הקנבס. ברירת מחדל: 500. | INT | כן | 1–5000 |
| `image_height` | גובה התמונה המקורית בתוך הקנבס. ברירת מחדל: 500. | INT | כן | 1–5000 |
| `image_x` | מיקום X של הפינה השמאלית העליונה של התמונה בתוך הקנבס; עשוי להיות מחוץ לקנבס, ואז התמונה נחתכת. ברירת מחדל: 250. | INT | כן | -5000–5000 |
| `image_y` | מיקום Y של הפינה השמאלית העליונה של התמונה בתוך הקנבס; עשוי להיות מחוץ לקנבס, ואז התמונה נחתכת. ברירת מחדל: 250. | INT | כן | -5000–5000 |

### קלטי מודרציה

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | אם מופעל, מבצע מודרציה של תוכן הפרומפט. ברירת מחדל: false. זמין רק כאשר `moderation` הוא `true`. | BOOLEAN | כן | true/false |
| `visual_input_moderation` | אם מופעל, מבצע מודרציה של הקלט החזותי. ברירת מחדל: false. זמין רק כאשר `moderation` הוא `true`. | BOOLEAN | כן | true/false |
| `visual_output_moderation` | אם מופעל, מבצע מודרציה של הפלט החזותי. ברירת מחדל: false. זמין רק כאשר `moderation` הוא `true`. | BOOLEAN | כן | true/false |

לאפשרויות יחס רוחב-גובה מוגדרות מראש (`1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`) אין קלטים נוספים.

כאשר `expand_mode` הוא `custom_ratio`, `ratio_width` ו-`ratio_height` מגדירים יחס רוחב-גובה ליעד. Bria מקבלת רק יחסי רוחב-גובה בין 0.5 ל-3.0. אם היחס מחוץ לטווח זה, נזרקת שגיאה ויש להשתמש במצב `manual` במקום.

כאשר `expand_mode` הוא `manual`, התמונה המקורית ממוקמת על קנבס בגודל ובמיקום שצוינו. התמונה עשויה לחרוג מגבולות הקנבס, ובמקרה כזה החלק שמחוץ לקנבס נחתך.

כאשר `moderation` הוא `true`, שלושת הערכים הבוליאניים של המודרציה נשלחים ל-Bria. כאשר `moderation` הוא `false`, הם לא נלקחים בחשבון.
