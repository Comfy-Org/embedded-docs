# MultiGPU_Options

## סקירה כללית

צומת זה מאפשר לך לציין את הביצועים היחסיים של כל GPU בעת שימוש במספר כרטיסים גרפיים במהירויות שונות. הוא יוצר קבוצה של אפשרויות GPU שניתן להשתמש בהן כדי לפזר עבודה בין התקנים, אם כי חלוקת עומס העבודה מבוססת המהירות בפועל טרם מיושמת בגרסה הנוכחית.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `device_index` | מספר האינדקס של התקן ה-GPU להגדרה (ברירת מחדל: 0) | INT | כן | 0 עד 64 |
| `relative_speed` | המהירות היחסית של GPU זה לעומת אחרים, המשמשת לחלוקת עומס עבודה (ברירת מחדל: 1.0, צעד: 0.01) | FLOAT | כן | 0.0 עד unlimited |
| `gpu_options` | קבוצת אפשרויות GPU קיימת שאליה יש להוסיף את האפשרויות של התקן זה. אם לא סופקה, נוצרת קבוצה חדשה | GPU_OPTIONS | לא | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `GPU_OPTIONS` | קבוצה של אפשרויות GPU המכילה את הגדרות ההתקן המוגדרות, שניתן להעביר לצמתים אחרים לפעולות מרובות GPU | GPU_OPTIONS |

**הערה:** הפרמטר `relative_speed` מוגדר אך עדיין אינו בשימוש על ידי מתזמן פנימי לצורך חלוקת עבודה בין GPUs. ביישום הנוכחי, העבודה מחולקת באופן שווה בין כל ההתקנים ללא קשר למהירויות היחסיות שלהם.
