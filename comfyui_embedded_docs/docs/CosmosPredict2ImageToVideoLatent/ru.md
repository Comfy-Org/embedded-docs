# CosmosPredict2ImageToVideoLatent

Создаёт видеолатенты для рабочего процесса Cosmos Predict2 image-to-video. Узел может создать пустой видеолатент заданного размера и длины или вставить закодированные начальное и/или конечное изображения в последовательность, чтобы эти кадры сохранялись во время генерации. Любое переданное изображение масштабируется до заданных `width` и `height` и кодируется предоставленным VAE перед размещением в начале и/или конце последовательности латентов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования начального и конечного изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 848, должна быть кратна 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, должна быть кратна 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 93) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видеопоследовательностей для генерации (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `начальное_изображение` | Необязательное начальное изображение для видеопоследовательности | IMAGE | Нет | - |
| `конечное_изображение` | Необязательное конечное изображение для видеопоследовательности | IMAGE | Нет | - |

**Примечание.** Если ни `start_image`, ни `end_image` не предоставлены, узел просто возвращает пустой латент запрошенного размера и длины. Если предоставлено одно или оба изображения, они масштабируются до `width` и `height`, кодируются с помощью `vae` и размещаются в начале и/или конце последовательности латентов. Соответствующие области отмечаются в маске шума, чтобы они сохранялись во время генерации. Закодированные латенты преобразуются с использованием формата латентов Wan 2.1, а полученный латент и маска повторяются `batch_size` раз.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Сгенерированный видеолатент, содержащий `samples` (последовательность видеолатентов) и, если указано хотя бы одно из `start_image` или `end_image`, `noise_mask`, которая отмечает кадры, которые должны сохраняться во время генерации | LATENT |
