# CosmosPredict2ImageToVideoLatent

CosmosPredict2ImageToVideoLatent создает латентные представления видео из изображений для генерации видео. Узел может генерировать пустое латентное представление видео или включать начальное и конечное изображения для создания видеопоследовательностей с заданными размерами и длительностью. Узел выполняет кодирование изображений в соответствующий формат латентного пространства для обработки видео.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 848, должна быть кратна 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, должна быть кратна 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 93, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видеопоследовательностей для генерации (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `начальное_изображение` | Необязательное начальное изображение для видеопоследовательности | IMAGE | Нет | - |
| `конечное_изображение` | Необязательное конечное изображение для видеопоследовательности | IMAGE | Нет | - |

**Примечание:** Когда не заданы ни `start_image`, ни `end_image`, узел генерирует пустое латентное представление видео. Когда задано одно или оба изображения, они масштабируются до размеров `width` и `height`, кодируются в латентное пространство и размещаются в начале и/или в конце видеопоследовательности, а соответствующие области помечаются в маске шума, чтобы они сохранялись при генерации. Полученные латентное представление и маска повторяются `batch_size` раз.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированное латентное представление видео, содержащее закодированную видеопоследовательность | LATENT |
| `noise_mask` | Маска, указывающая, какие части латентного представления следует сохранить при генерации. Присутствует только тогда, когда задано хотя бы одно из изображений `start_image` или `end_image`. | LATENT |
