# CosmosPredict2ImageToVideoLatent

Узел `CosmosPredict2ImageToVideoLatent` создает латентные представления видео из изображений для генерации видео. Он может генерировать пустое латентное видео или включать начальное и конечное изображения для создания видеопоследовательностей с заданными размерами и длительностью. Узел выполняет кодирование изображений в соответствующий формат латентного пространства для обработки видео.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 848, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION (step 16) |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 93) | INT | Да | 1 to MAX_RESOLUTION (step 4) |
| `batch_size` | Количество видеопоследовательностей для генерации (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `start_image` | Необязательное начальное изображение для видеопоследовательности | IMAGE | Нет | - |
| `end_image` | Необязательное конечное изображение для видеопоследовательности | IMAGE | Нет | - |

**Примечание:** Если не указаны ни `start_image`, ни `end_image`, узел генерирует пустое латентное видео. Когда изображения предоставлены, они кодируются и размещаются в начале и/или в конце видеопоследовательности с соответствующим маскированием.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `samples` | Сгенерированное латентное представление видео, содержащее закодированную видеопоследовательность | LATENT |
| `noise_mask` | Маска, указывающая, какие части латентного представления должны быть сохранены во время генерации | LATENT |
