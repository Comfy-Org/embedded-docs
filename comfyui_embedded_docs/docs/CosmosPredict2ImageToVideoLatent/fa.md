# CosmosPredict2ImageToVideoLatent

گره CosmosPredict2ImageToVideoLatent بازنمایی‌های ویدئویی نهفته را از تصاویر برای تولید ویدئو ایجاد می‌کند. این گره می‌تواند یک ویدئوی نهفته خالی تولید کند یا تصاویر شروع و پایان را برای ایجاد توالی‌های ویدئویی با ابعاد و مدت‌زمان مشخص ترکیب نماید. این گره رمزگذاری تصاویر را به قالب فضای نهفته مناسب برای پردازش ویدئو انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصاویر به فضای نهفته | VAE | بله | - |
| `width` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 848، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `height` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION (گام 16) |
| `length` | تعداد فریم‌های توالی ویدئو (پیش‌فرض: 93) | INT | بله | 1 تا MAX_RESOLUTION (گام 4) |
| `batch_size` | تعداد توالی‌های ویدئویی که باید تولید شود (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `start_image` | تصویر شروع اختیاری برای توالی ویدئو | IMAGE | خیر | - |
| `end_image` | تصویر پایان اختیاری برای توالی ویدئو | IMAGE | خیر | - |

**نکته:** هنگامی که نه `start_image` و نه `end_image` ارائه شوند، گره یک ویدئوی نهفته خالی تولید می‌کند. هنگامی که تصاویر ارائه شوند، رمزگذاری شده و با ماسک‌گذاری مناسب در ابتدا و/یا انتهای توالی ویدئو قرار می‌گیرند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `samples` | بازنمایی ویدئوی نهفته تولیدشده شامل توالی ویدئوی رمزگذاری‌شده | LATENT |
| `noise_mask` | ماسکی که مشخص می‌کند کدام بخش‌های فضای نهفته باید در طول تولید حفظ شوند | LATENT |
