# Разделить SeedVR2 latent

Этот узел разделяет видео-латент SeedVR2 на меньшие временные фрагменты, которые могут обрабатываться по одному в рамках доступной видеопамяти. Он автоматически вычисляет оптимальный размер фрагмента на основе вашей памяти GPU или позволяет указать размер фрагмента вручную, и выводит фрагменты в порядке последовательности для обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `latent` | Латенты SeedVR2, закодированные VAE, которые необходимо разделить. Должен быть 5-мерным тензором (B, C, T, H, W) с ожидаемым числом каналов латентов SeedVR2. | LATENT | Да | - |
| `temporal_overlap` | Кадры латентов, общие между соседними фрагментами и перекрестно смешиваемые при слиянии; 0 означает отсутствие перекрытия (по умолчанию: 0). Эффективное перекрытие ограничено значением на единицу меньше числа кадров латента во фрагменте. | INT | Нет | от 0 до 16384 |
| `chunking_mode` | Ручной режим использует frames_per_chunk точно; автоматический режим предсказывает наибольший фрагмент, помещающийся в свободную видеопамять. | COMBO | Да | "auto"<br>"manual" |

Когда для `chunking_mode` установлено значение "manual", становится доступен дополнительный параметр:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `frames_per_chunk` | Пиксельные кадры на временной фрагмент (4n+1: 1, 5, 9, 13, 17, 21, ...); интерфейс увеличивает с шагом 4 (по умолчанию: 21). | INT | Да | от 1 до 16384 |

Примечание: Параметр `frames_per_chunk` отображается только когда для `chunking_mode` установлено значение "manual". Значение должно удовлетворять формуле `(frames_per_chunk - 1) % 4 == 0`, то есть быть одним из: 1, 5, 9, 13, 17, 21 и т.д. Входной латент должен быть 5-мерным и содержать ожидаемое число каналов латентов SeedVR2; в противном случае узел вызывает ошибку. Если общее число пиксельных кадров в латенте равно или меньше выбранного размера фрагмента (или автоматически вычисленного размера), узел возвращает исходный латент как единый фрагмент без перекрытия.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `latents` | Временные фрагменты в порядке последовательности. | LATENT |
| `temporal_overlap` | Эффективное перекрытие кадров латентов между соседними фрагментами, для узла Merge SeedVR2 Latents. | INT |
