# بذر

گره Seed یک مقدار صحیح ارائه می‌دهد که می‌تواند به‌عنوان seed برای کنترل تکرارپذیری عملیات تصادفی در سایر گره‌ها استفاده شود. با ارائه یک مقدار شروع ثابت، به ثابت نگه داشتن نتایج تولیدشده در صورت نیاز کمک می‌کند.
