# Seed

צומת Seed מספק ערך שלם שיכול לשמש כ-seed לשליטה בשחזוריות של פעולות אקראיות בצמתים אחרים. על ידי אספקת ערך התחלתי עקבי, הוא עוזר לשמור על תוצאות שנוצרו כניתנות לשחזור בעת הצורך.
