# Seed

Узел Seed предоставляет целочисленное значение, которое можно использовать в качестве seed для управления воспроизводимостью случайных операций в других узлах. Предоставляя согласованное начальное значение, он помогает сохранять повторяемость результатов генерации при необходимости.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seed` | Значение seed для использования. Опция control after generate определяет, остаётся ли значение фиксированным или изменяется после каждой генерации; в этом узле она установлена на fixed. | INT | Да | 0 до 9223372036854775807 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `seed` | Сгенерированное значение seed. | INT |
