# Seed

Узел Seed предоставляет целочисленное значение, которое можно использовать в качестве seed (зерна) для управления воспроизводимостью случайных операций в других узлах. Задавая постоянное начальное значение, он помогает сохранять повторяемость сгенерированных результатов, когда это необходимо.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `seed` | Значение seed, которое необходимо использовать. Опция «control after generate» определяет, остаётся ли значение фиксированным или изменяется после каждой генерации; в этом узле оно зафиксировано. | INT | Да | 0 to 9223372036854775807 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `seed` | Сгенерированное значение seed. | INT |
