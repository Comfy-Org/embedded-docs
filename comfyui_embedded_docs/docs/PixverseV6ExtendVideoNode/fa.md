# PixVerse V6 گسترش ویدیو

این گره، ویدیوی موجود را با استفاده از مدل PixVerse V6 ادامه می‌دهد و به‌صورت اختیاری یک آهنگ صوتی بومی همراه با ادامه تولید می‌کند. ویدیوی منبع باید کوتاه‌تر از ۴۰ ثانیه و در هیچ‌یک از ابعاد بزرگ‌تر از ۱۹۲۰ پیکسل نباشد. خروجی، وضوح ویدیوی منبع را حفظ می‌کند؛ بنابراین تنظیم کیفیت، نحوه رندر شدن ادامه را کنترل می‌کند نه اندازه فریم را.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `video` | ویدیویی که قرار است ادامه یابد. | VIDEO | بله | کمتر از ۴۰ ثانیه؛ حداکثر ۱۹۲۰ پیکسل عرض و ارتفاع |
| `model` | مدل و تنظیمات تولید. | DYNAMIC_COMBO | بله | "PixVerse V6" |

### ورودی‌های PixVerse V6

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `prompt` | پرامپتی که نحوه ادامه ویدیو را توصیف می‌کند. (پیش‌فرض: خالی) | STRING | بله | ۱ تا ۵۰۰۰ کاراکتر |
| `quality` | کیفیت رندر ادامه تولیدشده: 1080p به‌وضوح بهتر از 540p یا 360p به نظر می‌رسد. هرگز تغییر اندازه نمی‌دهد - خروجی وضوح ویدیوی منبع را حفظ می‌کند. (پیش‌فرض: "720p") | COMBO | بله | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | طول ویدیوی تولیدشده بر حسب ثانیه. (پیش‌فرض: ۵) | INT | بله | ۱ تا ۱۵ |
| `generate_audio` | یک آهنگ صوتی بومی همراه با ویدیو تولید کن. (پیش‌فرض: true) | BOOLEAN | بله | true / false |
| `seed` | Seed برای تولید ویدیو. PixVerse آن را ثبت می‌کند اما اجرایی را از روی آن بازتولید نمی‌کند. (پیش‌فرض: ۴۲) | INT | بله | 0–2147483647 |
| `negative_prompt` | یک توصیف متنی اختیاری از عناصر نامطلوب در ویدیو. (پیش‌فرض: خالی) | STRING | خیر | حداکثر ۲۰۴۸ کاراکتر |
| `style` | یک سبک بصری اختیاری که به کل ویدیو اعمال می‌شود. (پیش‌فرض: "none") | COMBO | خیر | گزینه‌های متعددی موجود است؛ «none» پیش‌فرض است. |

**توجه:** ویدیوی `video` منبع باید کوتاه‌تر از ۴۰ ثانیه و حداکثر ۱۹۲۰ پیکسل در هر دو عرض و ارتفاع باشد؛ ویدیوهای طولانی‌تر یا بزرگ‌تر رد می‌شوند. خروجی تولیدشده وضوح ویدیوی منبع را حفظ می‌کند، بنابراین `quality` وفاداری رندر را تغییر می‌دهد، نه اندازه فریم خروجی را. `prompt` الزامی است و باید بین ۱ تا ۵۰۰۰ کاراکتر پس از حذف فاصله‌های ابتدا و انتها باشد. `negative_prompt` در صورت ارائه به ۲۰۴۸ کاراکتر محدود می‌شود. `seed` توسط PixVerse ثبت می‌شود اما نمی‌توان از آن برای بازتولید همان اجرا استفاده کرد.
