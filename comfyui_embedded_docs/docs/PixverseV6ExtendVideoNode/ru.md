# PixVerse V6: продление видео

Этот узел продолжает существующее видео с использованием модели PixVerse V6, опционально генерируя встроенную аудиодорожку вместе с продолжением. Исходное видео должно быть короче 40 секунд и не превышать 1920 пикселей по любой из сторон. Выходное видео сохраняет разрешение исходного видео, поэтому параметр качества управляет тем, насколько хорошо отрисовано продолжение, а не размером кадра.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Видео для продолжения. | VIDEO | Да | Менее 40 секунд; не более 1920 пикселей по ширине и высоте |
| `model` | Модель и параметры генерации. | DYNAMIC_COMBO | Да | "PixVerse V6" |

### Входы PixVerse V6

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Подсказка, описывающая, как видео должно продолжиться. (по умолчанию: пусто) | STRING | Да | 1–5000 символов |
| `quality` | Качество рендеринга генерируемого продолжения: 1080p выглядит заметно лучше, чем 540p или 360p. Параметр никогда не изменяет размер — выходное видео сохраняет разрешение исходного видео. (по умолчанию: "720p") | COMBO | Да | "360p"<br>"540p"<br>"720p"<br>"1080p" |
| `duration_seconds` | Длительность генерируемого видео в секундах. (по умолчанию: 5) | INT | Да | 1–15 |
| `generate_audio` | Генерировать встроенную аудиодорожку вместе с видео. (по умолчанию: true) | BOOLEAN | Да | true / false |
| `seed` | Сид для генерации видео. PixVerse записывает его, но не воспроизводит запуск на его основе. (по умолчанию: 42) | INT | Да | 0–2147483647 |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов в видео. (по умолчанию: пусто) | STRING | Нет | До 2048 символов |
| `style` | Необязательный визуальный стиль, применяемый ко всему видео. (по умолчанию: "none") | COMBO | Нет | Доступно несколько опций; по умолчанию — "none" |

**Примечание:** Исходное `video` должно быть короче 40 секунд и не более 1920 пикселей по ширине и высоте; более длинные или крупные видео отклоняются. Выходной результат сохраняет разрешение исходного видео, поэтому `quality` меняет качество рендеринга, а не размер выходного кадра. Параметр `prompt` обязателен и должен содержать от 1 до 5000 символов после обрезки пробелов. `negative_prompt`, если задан, ограничен 2048 символами. `seed` записывается PixVerse, но не может быть использован для воспроизведения того же запуска.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное продолжение видео с тем же разрешением, что и исходное видео. | VIDEO |
