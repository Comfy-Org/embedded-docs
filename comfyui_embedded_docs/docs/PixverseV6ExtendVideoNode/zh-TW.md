# PixVerse V6 延伸影片

此節點使用 PixVerse V6 模型延續現有影片，並可選擇在延續的同時生成原生音軌。來源影片必須短於 40 秒，且任一邊不得超過 1920 像素。輸出保持來源影片的解析度，因此品質設定控制的是延續畫面的渲染精細度，而非畫面尺寸。

| `模型` | 模型與生成設定。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述影片應如何延續的提示詞。（預設值：空） | STRING | 是 | 1–5000 個字元 |
