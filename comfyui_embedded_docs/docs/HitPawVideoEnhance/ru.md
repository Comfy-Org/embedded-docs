# HitPaw Video Enhance

Узел HitPaw Video Enhance использует внешний API для улучшения качества видео. Он увеличивает разрешение видео с низким разрешением до более высокого, удаляет визуальные артефакты и снижает уровень шума. Стоимость обработки рассчитывается за каждую секунду входного видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель ИИ, используемая для улучшения видео. При выборе модели появляется вложенный параметр `resolution`. Доступные модели и поддерживаемые ими разрешения различаются. | DYNAMIC_COMBO | Да | `"Portrait Restore Model (1x)"`<br>`"Portrait Restore Model (2x)"`<br>`"General Restore Model (1x)"`<br>`"General Restore Model (2x)"`<br>`"General Restore Model (4x)"`<br>`"Ultra HD Model (2x)"`<br>`"Generative Model (1x)"` |
| `видео` | Входной видеофайл для улучшения. | VIDEO | Да | Н/Д |

### Входы Portrait Restore, General Restore и Ultra HD Model

Эти параметры разрешения являются общими для Portrait Restore Model (1x), Portrait Restore Model (2x), General Restore Model (1x), General Restore Model (2x), General Restore Model (4x) и Ultra HD Model (2x).

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `разрешение` | Целевое разрешение улучшенного видео. При выборе `"original"` сохраняется разрешение входного видео. | COMBO | Да | `"original"`<br>`"720p"`<br>`"1080p"`<br>`"2K/QHD"`<br>`"4K/UHD"`<br>`"8K"` |

### Входы Generative Model (1x)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `разрешение` | Целевое разрешение улучшенного видео. При выборе `"original"` сохраняется разрешение входного видео. Опция `"8K"` недоступна для этой модели. | COMBO | Да | `"original"`<br>`"720p"`<br>`"1080p"`<br>`"2K/QHD"`<br>`"4K/UHD"` |

**Примечания:**

* Длительность входного `video` должна составлять от 0.5 секунды до 60 минут (3600 секунд).
* Выбранное `resolution` должно быть не меньше размеров входного видео. Для квадратных видео оно должно быть не меньше ширины и высоты видео. Для неквадратных видео оно должно быть не меньше меньшей стороны видео. Если целевое разрешение меньше, возникает ошибка. При выборе `"original"` сохраняется разрешение входного видео.
* Когда выбрано разрешение, отличное от `"original"`, неквадратные видео масштабируются так, чтобы их меньшая сторона соответствовала выбранному разрешению, с сохранением соотношения сторон. Квадратные видео масштабируются так, чтобы обе стороны соответствовали квадратному целевому размеру выбранного разрешения (например, `"4K/UHD"` создаёт 2048×2048).
