# Предварительный просмотр слияния моделей Mochi

Этот узел объединяет две модели ИИ блочным методом с детальным контролем над различными компонентами модели. Он позволяет смешивать модели, регулируя веса интерполяции для конкретных секций, включая позиционные частоты, слои эмбеддингов и отдельные блоки трансформера. Процесс слияния объединяет архитектуры и параметры обеих входных моделей в соответствии с указанными значениями весов.
