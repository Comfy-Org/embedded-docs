# Предварительный просмотр слияния моделей Mochi

Этот узел объединяет две модели Mochi AI, используя подход на основе блоков с детальным контролем над различными компонентами модели. Он позволяет смешивать модели, регулируя веса интерполяции для конкретных секций, включая позиционные частоты, слои эмбеддингов и каждый из 48 отдельных блоков трансформера. Процесс объединения комбинирует архитектуры и параметры обеих входных моделей в соответствии с заданными значениями весов.
