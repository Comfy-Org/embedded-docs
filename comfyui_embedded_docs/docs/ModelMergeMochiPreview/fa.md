# ModelMergeMochiPreview

این گره دو مدل هوش مصنوعی را با استفاده از رویکرد مبتنی بر بلوک و با کنترل دقیق بر روی اجزای مختلف مدل، ادغام می‌کند. این گره به شما امکان می‌دهد با تنظیم وزن‌های درون‌یابی برای بخش‌های خاص شامل فرکانس‌های موقعیتی، لایه‌های جاسازی و بلوک‌های ترانسفورمر جداگانه، مدل‌ها را ترکیب کنید. فرآیند ادغام، معماری و پارامترهای هر دو مدل ورودی را با توجه به مقادیر وزن مشخص‌شده، ترکیب می‌کند.
