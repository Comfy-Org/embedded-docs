# ModelMergeMochiPreview

این گره دو مدل Mochi AI را با استفاده از رویکردی مبتنی بر بلوک و با کنترل دقیق بر اجزای مختلف مدل ادغام می‌کند. این امکان را به شما می‌دهد تا مدل‌ها را با تنظیم وزن‌های درون‌یابی برای بخش‌های خاص، از جمله فرکانس‌های موقعیتی، لایه‌های تعبیه‌سازی و هر یک از ۴۸ بلوک ترنسفورمر جداگانه، ترکیب کنید. فرایند ادغام، معماری‌ها و پارامترهای هر دو مدل ورودی را بر اساس مقادیر وزن مشخص‌شده ترکیب می‌کند.
