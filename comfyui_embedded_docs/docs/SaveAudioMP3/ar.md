# حفظ الصوت (MP3)

تحفظ عقدة SaveAudioMP3 بيانات الصوت في ملف MP3. تأخذ إدخالًا صوتيًا وتصدّره إلى دليل الإخراج باسم ملف وإعداد جودة قابلين للتخصيص، مع التعامل مع تسمية الملفات وتحويل صيغة MP3 تلقائيًا. **هذه العقدة مهملة وقد تتم إزالتها في الإصدارات المستقبلية.**

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصوت` | بيانات الصوت المراد حفظها كملف MP3 | AUDIO | نعم | - |
| `بادئة اسم الملف` | بادئة اسم ملف الإخراج (الافتراضي: "audio/ComfyUI") | STRING | لا | - |
| `الجودة` | إعداد جودة الصوت لملف MP3 (الافتراضي: "V0") | COMBO | لا | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | بيانات المطالبة الداخلية، يوفّرها النظام تلقائيًا | PROMPT | لا | - |
| `extra_pnginfo` | معلومات PNG إضافية، يوفّرها النظام تلقائيًا | EXTRA_PNGINFO | لا | - |

**ملاحظة:** إذا كانت قيمة الإدخال `audio` تساوي `None` (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي)، فإن العقدة ترفع استثناء `ValueError`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `audio` | بيانات الصوت التي حُفظت في ملف MP3 | AUDIO |
