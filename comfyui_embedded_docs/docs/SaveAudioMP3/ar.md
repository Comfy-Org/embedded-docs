# حفظ الصوت (MP3)

عقدة SaveAudioMP3 تحفظ بيانات الصوت كملف MP3. تأخذ مدخلًا صوتيًا وتصدّره إلى مجلد الإخراج مع إعدادات اسم ملف وجودة قابلة للتخصيص، وتتعامل مع تسمية الملف وتحويل تنسيق MP3 تلقائيًا. **هذه العقدة مُهجَرة وقد تتم إزالتها في الإصدارات المستقبلية.**

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصوت` | بيانات الصوت التي سيتم حفظها كملف MP3 | AUDIO | نعم | - |
| `بادئة اسم الملف` | البادئة لاسم ملف الإخراج (الافتراضي: "audio/ComfyUI") | STRING | لا | - |
| `الجودة` | إعداد جودة الصوت لملف MP3 (الافتراضي: "V0") | COMBO | لا | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | بيانات التلقين الداخلية، يتم توفيرها تلقائيًا بواسطة النظام | PROMPT | لا | - |
| `extra_pnginfo` | معلومات PNG إضافية، يتم توفيرها تلقائيًا بواسطة النظام | EXTRA_PNGINFO | لا | - |

**ملاحظة:** إذا كانت قيمة الإدخال `audio` هي None (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي)، تُثير العقدة خطأ ValueError.
