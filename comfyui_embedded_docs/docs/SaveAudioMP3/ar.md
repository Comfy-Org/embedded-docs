# حفظ الصوت (MP3)

عقدة SaveAudioMP3 تقوم بحفظ البيانات الصوتية كملف MP3. تأخذ مدخلًا صوتيًا وتكتبه إلى مجلد الإخراج مع بادئة اسم ملف قابلة للتخصيص وإعداد جودة. هذه العقدة مهملة وقد تُزال في الإصدارات المستقبلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | المدى |
|-----------|-------------|-----------|----------|-------|
| `audio` | البيانات الصوتية التي سيتم حفظها كملف MP3 | AUDIO | نعم | - |
| `filename_prefix` | بادئة اسم ملف الإخراج (الافتراضي: "audio/ComfyUI") | STRING | لا | - |
| `quality` | إعداد جودة ترميز MP3 (الافتراضي: "V0"). يستخدم V0 معدل بت متغير لجودة عالية؛ بينما يستخدم 128k و320k معدلي بت ثابتين بمقدار 128 و320 كيلوبت في الثانية | COMBO | لا | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | بيانات موجه داخلية، يتم توفيرها تلقائيًا بواسطة النظام | PROMPT | لا | - |
| `extra_pnginfo` | معلومات PNG إضافية، يتم توفيرها تلقائيًا بواسطة النظام | EXTRA_PNGINFO | لا | - |

**ملاحظة:** إذا كان مدخل `audio` هو None (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي)، فإن العقدة ترفع خطأ ValueError.
