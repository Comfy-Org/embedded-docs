# שמור אודיו (MP3) (מיושן)

הצומת SaveAudioMP3 שומר נתוני אודיו כקובץ MP3. הוא מקבל קלט אודיו ומייצא אותו לספריית הפלט עם שם קובץ והגדרת איכות הניתנים להתאמה, ומטפל אוטומטית בשמות קבצים ובהמרה לפורמט MP3. **צומת זה מיושן ועשוי להיות מוסר בגרסאות עתידיות.**

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio` | נתוני האודיו שיישמרו כקובץ MP3 | AUDIO | כן | - |
| `filename_prefix` | הקידומת עבור שם קובץ הפלט (ברירת מחדל: "audio/ComfyUI") | STRING | לא | - |
| `quality` | הגדרת איכות האודיו עבור קובץ ה-MP3 (ברירת מחדל: "V0") | COMBO | לא | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | נתוני הנחיה פנימיים, מסופקים אוטומטית על ידי המערכת | PROMPT | לא | - |
| `extra_pnginfo` | מידע PNG נוסף, מסופק אוטומטית על ידי המערכת | EXTRA_PNGINFO | לא | - |

**הערה:** אם הקלט `audio` הוא None (לדוגמה, כאשר לקובץ הווידאו המקור אין רצועת אודיו), הצומת מעלה ValueError.
