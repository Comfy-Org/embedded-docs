# Сохранить аудио (MP3)

Узел SaveAudioMP3 сохраняет аудиоданные в файл MP3. Он принимает аудиовход и экспортирует его в выходной каталог с настраиваемыми параметрами имени файла и качества, автоматически обрабатывая присвоение имени файла и преобразование в формат MP3. **Этот узел устарел и может быть удален в будущих версиях.**

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `аудио` | Аудиоданные для сохранения в файл MP3 | AUDIO | Да | - |
| `префикс_имени_файла` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |
| `качество` | Настройка качества аудио для файла MP3 (по умолчанию: "V0") | COMBO | Нет | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | Внутренние данные промпта, автоматически предоставляются системой | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная информация PNG, автоматически предоставляется системой | EXTRA_PNGINFO | Нет | - |

**Примечание:** Если входной параметр `audio` имеет значение None (например, когда в исходном видео отсутствует аудиодорожка), узел вызывает ошибку ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `аудио` | Аудиоданные, сохраненные в файл MP3 | AUDIO |
