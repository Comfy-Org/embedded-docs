# Сохранить аудио (MP3)

Узел SaveAudioMP3 сохраняет аудиоданные в виде MP3-файла. Он принимает аудиовход и экспортирует его в выходной каталог с настраиваемым именем файла и настройкой качества, автоматически обрабатывая именование файлов и преобразование в формат MP3. **Этот узел устарел и может быть удалён в будущих версиях.**

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `аудио` | Аудиоданные для сохранения в виде MP3-файла | AUDIO | Да | - |
| `префикс_имени_файла` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |
| `качество` | Настройка качества аудио для MP3-файла (по умолчанию: "V0") | COMBO | Нет | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | Внутренние данные промпта, автоматически предоставляемые системой | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная информация PNG, автоматически предоставляемая системой | EXTRA_PNGINFO | Нет | - |

**Примечание:** Если входные данные `audio` имеют значение None (например, когда в исходном видео нет аудиодорожки), узел вызывает ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `audio` | Аудиоданные, сохранённые в MP3-файл | AUDIO |
