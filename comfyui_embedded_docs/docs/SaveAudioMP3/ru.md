# Сохранить аудио (MP3)

Узел SaveAudioMP3 сохраняет аудиоданные в файл MP3. Он принимает аудиовход и записывает его в выходной каталог с настраиваемым префиксом имени файла и параметром качества. Этот узел устарел и может быть удалён в будущих версиях.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `audio` | Аудиоданные для сохранения в файл MP3 | AUDIO | Да | - |
| `filename_prefix` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |
| `quality` | Настройка качества кодирования MP3 (по умолчанию: "V0"). V0 использует переменный битрейт для высокого качества; 128k и 320k используют фиксированные битрейты 128 и 320 кбит/с | COMBO | Нет | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | Внутренние данные промпта, автоматически предоставляемые системой | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная PNG-информация, автоматически предоставляемая системой | EXTRA_PNGINFO | Нет | - |

**Примечание:** Если вход `audio` равен None (например, когда исходное видео не содержит аудиодорожки), узел вызывает исключение ValueError.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `audio` | Аудиоданные, которые были сохранены в файл MP3 | AUDIO |
