# ذخیره صدا (MP3)

گره SaveAudioMP3 داده‌های صوتی را به‌عنوان یک فایل MP3 ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و آن را با تنظیمات قابل‌شخصی‌سازی نام فایل و کیفیت، به دایرکتوری خروجی صادر می‌کند و به‌طور خودکار نام‌گذاری فایل و تبدیل فرمت MP3 را مدیریت می‌نماید. **این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.**

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده صوتی که قرار است به‌عنوان فایل MP3 ذخیره شود | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |
| `quality` | تنظیم کیفیت صوتی برای فایل MP3 (پیش‌فرض: "V0") | COMBO | خیر | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | داده‌های داخلی prompt که به‌طور خودکار توسط سیستم فراهم می‌شود | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG که به‌طور خودکار توسط سیستم فراهم می‌شود | EXTRA_PNGINFO | خیر | - |

**توجه:** اگر ورودی `audio` برابر None باشد (مثلاً زمانی که ویدیوی منبع ترک صوتی ندارد)، گره یک ValueError ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `صدا` | داده صوتی که به‌عنوان فایل MP3 ذخیره شده است | AUDIO |
