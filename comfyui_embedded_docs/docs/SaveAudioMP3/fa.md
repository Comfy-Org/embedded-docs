# ذخیره صدا (MP3)

گره SaveAudioMP3 داده‌های صوتی را به‌صورت یک فایل MP3 ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و آن را با نام فایل و تنظیم کیفیت قابل‌سفارشی‌سازی در پوشه خروجی صادر می‌کند و نام‌گذاری فایل و تبدیل قالب MP3 را به‌طور خودکار انجام می‌دهد. **این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.**

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده‌های صوتی که باید به‌عنوان فایل MP3 ذخیره شوند | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |
| `quality` | تنظیم کیفیت صدا برای فایل MP3 (پیش‌فرض: "V0") | COMBO | خیر | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | داده‌های پرامپت داخلی، که به‌طور خودکار توسط سیستم ارائه می‌شود | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG، که به‌طور خودکار توسط سیستم ارائه می‌شود | EXTRA_PNGINFO | خیر | - |

**توجه:** اگر ورودی `audio` برابر None باشد (برای مثال، زمانی که ویدیوی منبع هیچ قطعه صوتی ندارد)، گره یک ValueError ایجاد می‌کند.
