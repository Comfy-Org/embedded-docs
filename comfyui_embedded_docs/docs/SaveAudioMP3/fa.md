# ذخیره صدا (MP3)

گره SaveAudioMP3 داده‌های صوتی را به‌عنوان یک فایل MP3 ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و آن را با پیشوند نام فایل قابل تنظیم و تنظیم کیفیت مشخص، در دایرکتوری خروجی می‌نویسد. این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده صوتی که به‌عنوان فایل MP3 ذخیره می‌شود | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |
| `quality` | تنظیم کیفیت رمزگذاری MP3 (پیش‌فرض: "V0"). V0 از نرخ بیت متغیر برای کیفیت بالا استفاده می‌کند؛ 128k و 320k از نرخ‌های بیت ثابت 128 و 320 کیلوبیت بر ثانیه استفاده می‌کنند | COMBO | خیر | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | داده‌های داخلی پرامپت که به‌طور خودکار توسط سیستم فراهم می‌شود | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG که به‌طور خودکار توسط سیستم فراهم می‌شود | EXTRA_PNGINFO | خیر | - |

**توجه:** اگر ورودی `audio` هیچ (None) باشد (مثلاً وقتی ویدیوی منبع فاقد آهنگ صوتی است)، گره یک ValueError ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `audio` | داده صوتی که به‌عنوان فایل MP3 ذخیره شده است | AUDIO |
