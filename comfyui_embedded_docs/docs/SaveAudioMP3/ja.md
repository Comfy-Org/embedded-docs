# オーディオ保存 (MP3)

以下に日本語訳を示します。

---

SaveAudioMP3ノードは、音声データをMP3ファイルとして保存します。音声入力を受け取り、カスタマイズ可能なファイル名プレフィックスと品質設定を使用して出力ディレクトリに書き込みます。このノードは非推奨であり、将来のバージョンで削除される可能性があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | MP3ファイルとして保存される音声データです | AUDIO | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス（デフォルト: "audio/ComfyUI"） | STRING | いいえ | - |
| `quality` | MP3エンコード品質の設定（デフォルト: "V0"）。V0は高品質の可変ビットレートを使用します。128kと320kはそれぞれ128kbpsと320kbpsの固定ビットレートを使用します | COMBO | いいえ | `"V0"`<br>`"128k"`<br>`"320k"` |
| `prompt` | システムによって自動的に提供される内部プロンプトデータです | PROMPT | いいえ | - |
| `extra_pnginfo` | システムによって自動的に提供される追加のPNG情報です | EXTRA_PNGINFO | いいえ | - |

**注意:** `audio`入力がNoneの場合（例えば、ソース動画に音声トラックがない場合）、ノードはValueErrorを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | MP3ファイルとして保存された音声データです | AUDIO |
