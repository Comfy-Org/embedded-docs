# هموارسازی دادهٔ پوز بدن SAM3D

Smooth SAM3D Body Pose Data با میانگین‌گیری حرکت در طول زمان، لرزش فریم‌به‌فریم را در توالی‌های حالت بدنه سه‌بعدی کاهش می‌دهد. این گره هموارسازی کاملی روی داده‌های دوربین و ظاهر اعمال می‌کند، اما در مورد هندسه مش زمانی که سوژه به‌سرعت می‌چرخد عقب‌نشینی می‌کند تا چرخش‌های سریع تخت/مسطح نشوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | توالی داده‌های حالت MHR برای هموارسازی، شامل پارامترهای مدل، پارامترهای شکل، پارامترهای بیان، چیدمان نقاط کلیدی MHR70 و داده‌های مش مرتبط. | MHR_POSE_DATA | بله | — |
| `شدت` | شدت هموارسازی. 0 = خام، 1 = هموار. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.05) |
| `روش` | gaussian: میانگین وزنی متقارن، بهترین هموارساز عمومی.<br>savgol: برازش چندجمله‌ای لغزان، قله‌های تیز را حفظ می‌کند. (پیش‌فرض: "savgol") | COMBO | بله | "gaussian"<br>"savgol" |
| `پنجره` | پنجره زمانی بر حسب فریم (مقادیر فرد). (پیش‌فرض: 7) | INT | بله | 1 تا 51 (مقادیر فرد، گام 2) |
| `rotation_threshold_degrees` | هموارسازی را برای این نرخ چرخش ریشه (درجه/فریم) غیرفعال می‌کند تا چرخش‌های سریع حفظ شوند. ۳۰ درجه برای بیشتر محتوا مناسب است؛ مقادیر پایین ممکن است هموارسازی را روی لرزش معمولی غیرفعال کنند و بی‌سروصدا کیفیت را تحت تأثیر قرار دهند. 0 = غیرفعال. (پیش‌فرض: 30.0) | FLOAT | بله | 0.0 تا 90.0 (گام 1.0) |

توجه: وقتی `strength` برابر 0.0 یا کمتر باشد، یا `window` برابر 1 یا کمتر باشد، گره داده ورودی را بدون تغییر برمی‌گرداند. ورودی باید حداقل ۲ فریم و داده نقاط کلیدی داشته باشد؛ در غیر این صورت گره داده ورودی را بدون تغییر برمی‌گرداند. وقتی `rotation_threshold_degrees` برابر 0.0 باشد، کاهش هموارسازی مبتنی بر چرخش غیرفعال می‌شود.
