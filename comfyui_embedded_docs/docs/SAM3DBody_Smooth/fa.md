# هموارسازی دادهٔ پوز بدن SAM3D

گره Smooth SAM3D Body Pose Data لرزش فریم‌به‌فریم را در دنباله‌ای از پوزهای بدن سه‌بعدی با میانگین‌گیری حرکت در طول زمان کاهش می‌دهد. داده‌های دوربین و ظاهر به‌طور کامل هموار می‌شوند، در حالی که هندسه مش وقتی سوژه سریع می‌چرخد کمتر هموار می‌شود تا چرخش‌های سریع مسطح نشوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | دنباله داده‌های پوز MHR برای هموارسازی، شامل پارامترهای مدل، پارامترهای شکل، پارامترهای حالت چهره، چیدمان نقاط کلیدی MHR70 و داده‌های مش مرتبط. | MHR_POSE_DATA | بله | — |
| `strength` | قدرت هموارسازی. 0 = خام، 1 = هموارشده. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.05) |
| `method` | gaussian: میانگین وزنی متقارن، بهترین هموارکننده همه‌منظوره.<br>savgol: برازش چندجمله‌ای لغزان، قله‌های تیز را حفظ می‌کند. (پیش‌فرض: "savgol") | COMBO | بله | "gaussian"<br>"savgol" |
| `window` | پنجره زمانی بر حسب فریم (مقادیر فرد). (پیش‌فرض: 7) | INT | بله | 1 تا 51 (مقادیر فرد، گام 2) |
| `rotation_threshold_degrees` | هموارسازی را برای این نرخ چرخش ریشه (درجه/فریم) غیرفعال می‌کند تا چرخش‌های سریع حفظ شوند. 30° برای بیشتر محتوا مناسب است؛ مقادیر پایین ممکن است هموارسازی را روی لرزش‌های معمولی غیرفعال کنند و بی‌سروصدا بر کیفیت اثر بگذارند. 0 = غیرفعال. (پیش‌فرض: 30.0) | FLOAT | بله | 0.0 تا 90.0 (گام 1.0) |

نکته: وقتی `strength` برابر 0.0 یا کمتر باشد، یا `window` برابر 1 یا کمتر باشد، گره داده ورودی را بدون تغییر بازمی‌گرداند. ورودی باید حداقل 2 فریم و داده نقاط کلیدی داشته باشد؛ در غیر این صورت گره داده ورودی را بدون تغییر بازمی‌گرداند. وقتی `rotation_threshold_degrees` برابر 0.0 باشد، کاهش هموارسازی مبتنی بر چرخش غیرفعال می‌شود.
