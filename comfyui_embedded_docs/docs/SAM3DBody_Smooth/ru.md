# Сглаживание данных позы тела SAM3D

Smooth SAM3D Body Pose Data уменьшает покадровое дрожание в последовательности 3D-поз тела путём усреднения движения во времени. Данные камеры и внешнего вида сглаживаются полностью, а геометрия сетки сглаживается меньше, когда объект быстро вращается, поэтому быстрые вращения не уплощаются.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | Последовательность данных позы MHR для сглаживания, содержащая параметры модели, параметры формы, параметры выражения, раскладку ключевых точек MHR70 и связанные данные сетки. | MHR_POSE_DATA | Да | — |
| `сила` | Сила сглаживания. 0 = без сглаживания, 1 = сглажено. (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 (шаг 0.05) |
| `метод` | gaussian: симметричное взвешенное среднее, лучший универсальный сглаживатель.<br>savgol: скользящая полиномиальная аппроксимация, сохраняет резкие пики. (по умолчанию: "savgol") | COMBO | Да | "gaussian"<br>"savgol" |
| `окно` | Временное окно в кадрах (нечётные значения). (по умолчанию: 7) | INT | Да | 1 до 51 (нечётные значения, шаг 2) |
| `rotation_threshold_degrees` | Отключает сглаживание при такой скорости поворота корня (градус/кадр), чтобы сохранить быстрые вращения. 30° подходит для большинства контента; низкие значения могут отключать сглаживание при обычном дрожании и незаметно ухудшать качество. 0 = отключено. (по умолчанию: 30.0) | FLOAT | Да | 0.0 до 90.0 (шаг 1.0) |

Примечание: Если `strength` равно 0.0 или меньше, или `window` равно 1 или меньше, узел возвращает входные данные без изменений. Входные данные должны содержать как минимум 2 кадра и данные ключевых точек; в противном случае узел возвращает входные данные без изменений. Если `rotation_threshold_degrees` равно 0.0, механизм ослабления сглаживания на основе вращения отключается.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mhr_pose_data` | Сглаженная последовательность данных позы MHR с уменьшенным покадровым дрожанием. | MHR_POSE_DATA |
