# Сглаживание данных позы тела SAM3D

Smooth SAM3D Body Pose Data уменьшает дрожание между кадрами в последовательностях 3D-поз тела за счет усреднения движения во времени. Он применяет полное сглаживание к данным камеры и внешности, при этом ослабляя сглаживание геометрии сетки при быстром вращении объекта, чтобы быстрые вращения не уплощались.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | Последовательность данных позы MHR для сглаживания, содержащая параметры модели, параметры формы, параметры выражения, раскладку ключевых точек MHR70 и связанные данные сетки. | MHR_POSE_DATA | Да | — |
| `сила` | Сила сглаживания. 0 = без сглаживания, 1 = полное сглаживание. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (step 0.05) |
| `метод` | gaussian: симметричное взвешенное среднее, лучший универсальный сглаживатель.<br>savgol: скользящая полиномиальная подгонка, сохраняет резкие пики. (по умолчанию: "savgol") | COMBO | Да | "gaussian"<br>"savgol" |
| `окно` | Временное окно в кадрах (нечетные значения). (по умолчанию: 7) | INT | Да | от 1 до 51 (odd values, step 2) |
| `rotation_threshold_degrees` | Отключает сглаживание при такой скорости вращения корня (градус/кадр), чтобы сохранить быстрые вращения. 30° подходит для большинства контента; низкие значения могут отключить сглаживание на обычном дрожании и незаметно повлиять на качество. 0 = отключено. (по умолчанию: 30.0) | FLOAT | Да | от 0.0 до 90.0 (step 1.0) |

Примечание: Когда `strength` меньше или равен 0.0, или `window` меньше или равен 1, узел возвращает входные данные без изменений. Входные данные должны содержать как минимум 2 кадра и данные ключевых точек; в противном случае узел возвращает входные данные без изменений. Когда `rotation_threshold_degrees` равен 0.0, ослабление сглаживания на основе вращения отключено.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mhr_pose_data` | Сглаженная последовательность данных позы MHR с уменьшенным дрожанием между кадрами. | MHR_POSE_DATA |
