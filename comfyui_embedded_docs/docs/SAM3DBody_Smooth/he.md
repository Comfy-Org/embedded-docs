# SAM3DBody_Smooth

הצומת Smooth SAM3D Body Pose Data מפחית רעידות בין פריימים ברצף של תנוחות גוף תלת-ממדיות על ידי מיצוע התנועה לאורך זמן. נתוני מצלמה ומראה מוחלקים במלואם, ואילו גאומטריית ה-mesh מוחלקת פחות כאשר הנבדק מסתובב במהירות, כך שסיבובים מהירים אינם נשטחים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | רצף נתוני תנוחת MHR שיש להחליק, המכיל פרמטרי מודל, פרמטרי צורה, פרמטרי הבעה, פריסת נקודות מפתח MHR70 ונתוני mesh קשורים. | MHR_POSE_DATA | כן | — |
| `strength` | עוצמת החלקה. 0 = גולמי, 1 = מוחלק. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 עד 1.0 (צעד 0.05) |
| `method` | gaussian: ממוצע משוקלל סימטרי, המחליק הכללי-תכליתי הטוב ביותר.<br>savgol: התאמת פולינום נעה, משמרת פסגות חדות. (ברירת מחדל: "savgol") | COMBO | כן | "gaussian"<br>"savgol" |
| `window` | חלון זמני בפריימים (ערכים אי-זוגיים). (ברירת מחדל: 7) | INT | כן | 1 עד 51 (ערכים אי-זוגיים, צעד 2) |
| `rotation_threshold_degrees` | משבית החלקה עבור קצב סיבוב השורש הזה (מעלות/פריים) כדי לשמר סיבובים מהירים. 30° מתאים לרוב התוכן; ערכים נמוכים עלולים להשבית החלקה על רעידות רגילות ולפגוע באיכות בשקט. 0 = השבתה. (ברירת מחדל: 30.0) | FLOAT | כן | 0.0 עד 90.0 (צעד 1.0) |

הערה: כאשר `strength` הוא 0.0 או נמוך יותר, או כאשר `window` הוא 1 או נמוך יותר, הצומת מחזיר את נתוני הקלט ללא שינוי. הקלט חייב להכיל לפחות 2 פריימים ונתוני נקודות מפתח; אחרת הצומת מחזיר את נתוני הקלט ללא שינוי. כאשר `rotation_threshold_degrees` הוא 0.0, הפחתת ההחלקה מבוססת הסיבוב מושבתת.
