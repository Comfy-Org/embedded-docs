# GetImageSize

GetImageSize liest ein Eingabebild und gibt dessen Breite, Höhe und Batch-Größe zurück. Der Node zeigt diese gemessenen Werte auch direkt auf der Node-Oberfläche an.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
|-----------|-------------|-----------|----------|-------|
| `image` | Das Eingabebild, aus dem Breite, Höhe und Batch-Größe extrahiert werden | IMAGE | Ja | - |

## Ausgaben

| Ausgabename | Beschreibung | Datentyp |
|-------------|-------------|-----------|
| `width` | Die Breite des Eingabebilds in Pixeln | INT |
| `height` | Die Höhe des Eingabebilds in Pixeln | INT |
| `batch_size` | Die Anzahl der im Eingabe-Batch enthaltenen Bilder | INT |
