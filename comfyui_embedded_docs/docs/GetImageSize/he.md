# קבל גודל תמונה

GetImageSize קורא תמונת קלט ומחזיר את הרוחב, הגובה וגודל האצווה שלה. הצומת גם מציג את הערכים הנמדדים ישירות בממשק הצומת.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שממנה מחולצים הרוחב, הגובה וגודל האצווה | IMAGE | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `width` | רוחב תמונת הקלט בפיקסלים | INT |
| `height` | גובה תמונת הקלט בפיקסלים | INT |
| `batch_size` | מספר התמונות באצוות הקלט | INT |
