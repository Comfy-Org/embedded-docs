# ByteDanceImageEditNode

گره ByteDance Image Edit به شما امکان می‌دهد تصاویر را با استفاده از مدل‌های هوش مصنوعی ByteDance از طریق یک API تغییر دهید. شما یک تصویر ورودی و یک پرامپت متنی ارائه می‌دهید که تغییرات موردنظر را توصیف می‌کند، و گره تصویر را مطابق دستورالعمل‌های شما پردازش می‌کند. گره ارتباط با API را به‌صورت خودکار مدیریت می‌کند و تصویر ویرایش‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | نوع ورودی | پیش‌فرض | محدوده |
| --- | --- | --- | --- | --- | --- |
| `model` | نام مدل | MODEL | COMBO | seededit_3 | گزینه‌های Image2ImageModelName |
| `image` | تصویر پایه برای ویرایش | IMAGE | IMAGE | - | - |
| `prompt` | دستورالعمل ویرایش تصویر | STRING | STRING | "" | - |
| `seed` | مقدار seed برای تولید | INT | INT | 0 | 0-2147483647 |
| `guidance_scale` | مقدار بالاتر باعث می‌شود تصویر بیشتر از پرامپت پیروی کند | FLOAT | FLOAT | 5.5 | 1.0-10.0 |
| `watermark` | اینکه آیا واترمارک «AI generated» به تصویر اضافه شود یا نه | BOOLEAN | BOOLEAN | True | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `IMAGE` | تصویر ویرایش‌شده‌ای که از API ByteDance بازگردانده می‌شود | IMAGE |
