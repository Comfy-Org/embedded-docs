# ByteDanceImageEditNode

Узел ByteDance Image Edit позволяет изменять изображения с помощью ИИ-моделей ByteDance через API. Вы предоставляете входное изображение и текстовую подсказку с описанием желаемых изменений, а узел обрабатывает изображение в соответствии с вашими инструкциями. Узел автоматически выполняет взаимодействие с API и возвращает отредактированное изображение.

## Входы

| Параметр | Описание | Тип данных | Тип входа | По умолчанию | Диапазон |
| --- | --- | --- | --- | --- | --- |
| `model` | Имя модели | MODEL | COMBO | seededit_3 | Image2ImageModelName options |
| `image` | Базовое изображение для редактирования | IMAGE | IMAGE | - | - |
| `prompt` | Инструкция для редактирования изображения | STRING | STRING | "" | - |
| `seed` | Seed для генерации | INT | INT | 0 | 0-2147483647 |
| `guidance_scale` | Более высокое значение заставляет изображение точнее следовать подсказке | FLOAT | FLOAT | 5.5 | 1.0-10.0 |
| `watermark` | Добавлять ли водяной знак "AI generated" на изображение | BOOLEAN | BOOLEAN | True | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Отредактированное изображение, возвращённое из ByteDance API | IMAGE |
