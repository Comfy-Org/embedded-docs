# Загрузить набор изображений из папки

Этот узел загружает несколько изображений из выбранной подпапки в основной входной директории ComfyUI и возвращает их в виде списка. Он сканирует выбранную папку на наличие файлов изображений в форматах PNG, JPG, JPEG или WEBP, что полезно для пакетной обработки или подготовки наборов данных изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `folder` | Папка, из которой загружаются изображения. Варианты — это подпапки, находящиеся в основной входной директории ComfyUI. | COMBO | Да | Доступно несколько вариантов |

Примечание: выбранная папка должна быть подпапкой основной входной директории ComfyUI; любое значение, указывающее на путь вне этой директории, отклоняется. Загружаются только файлы с расширениями .png, .jpg, .jpeg или .webp, при этом проверка расширения не учитывает регистр. Если в выбранной папке нет допустимых файлов изображений, узел вызывает ошибку. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Список загруженных изображений. Узел загружает все допустимые файлы изображений (PNG, JPG, JPEG, WEBP), найденные в выбранной папке. | IMAGE |
