# Загрузить набор изображений из папки

Этот узел загружает набор изображений из выбранной папки и возвращает их в виде списка. Папка должна быть подпапкой внутри основной директории ввода ComfyUI. Поддерживаемые форматы изображений: PNG, JPG, JPEG и WEBP.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `folder` | Папка для загрузки изображений. Доступные варианты — подпапки, присутствующие в основной директории ввода ComfyUI. Значения, указывающие за пределы этой директории (например, с использованием ".."), отклоняются. | COMBO | Да | *Доступно несколько вариантов* — подпапки, присутствующие в директории ввода ComfyUI |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Список загруженных изображений. Узел загружает все допустимые файлы изображений (PNG, JPG, JPEG, WEBP), найденные в выбранной папке, и возвращает их в виде списка. Если в папке нет поддерживаемых файлов изображений, возникает ошибка. | IMAGE |
