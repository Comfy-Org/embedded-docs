# Загрузить набор изображений из папки

Этот узел загружает несколько изображений из выбранной подпапки в основном входном каталоге ComfyUI и возвращает их в виде списка. Он сканирует выбранную папку на наличие файлов изображений в форматах PNG, JPG, JPEG или WEBP, что делает его полезным для пакетной обработки или подготовки наборов изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `folder` | Папка, из которой загружаются изображения. Вариантами являются подпапки, присутствующие в основном входном каталоге ComfyUI. | COMBO | Да | Доступно несколько вариантов |

Примечание: Выбранная папка должна быть подпапкой основного входного каталога ComfyUI; любое значение, которое разрешается за его пределами (например, с использованием `..`, абсолютных путей, букв диска или символьных ссылок), отклоняется. Загружаются только файлы с расширениями .png, .jpg, .jpeg или .webp, причём проверка расширения не учитывает регистр. Загруженные изображения преобразуются в RGB и масштабируются в диапазон 0-1. Если выбранная папка не содержит допустимых файлов изображений, узел выдаёт ошибку. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Список загруженных изображений. Узел загружает все допустимые файлы изображений (PNG, JPG, JPEG, WEBP), найденные в выбранной папке. | IMAGE |
