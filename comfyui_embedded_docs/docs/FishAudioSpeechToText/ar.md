# تحويل الكلام إلى نص من Fish Audio

تقوم هذه العقدة بتحويل الصوت إلى نص باستخدام خدمة Fish Audio لتحويل الكلام إلى نص. وتكتشف لغة الصوت تلقائيًا، ويمكنها اختياريًا إرجاع مقاطع بطوابع زمنية على مستوى الكلمة بصيغة JSON.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `audio` | الصوت المراد تحويله إلى نص. | AUDIO | نعم | — |
| `language` | تلميح للغة وفق ISO 639-1 (مثل 'en'، 'zh'). يتم اكتشاف اللغة تلقائيًا بغض النظر عن ذلك. الافتراضي: "" (سلسلة فارغة). | STRING | لا | أي رمز لغة ISO 639-1، مثل `en`، `zh`؛ سلسلة فارغة للكشف التلقائي |
| `precise_timestamps` | إرجاع مقاطع بطوابع زمنية على مستوى الكلمة. الافتراضي: false. | BOOLEAN | لا | true أو false |

ملاحظة: المعامل `language` هو مجرد تلميح — يتم اكتشاف اللغة دائمًا تلقائيًا من الصوت. عندما تكون قيمة `precise_timestamps` هي false (القيمة الافتراضية)، لا تُرجَع طوابع زمنية على مستوى الكلمة؛ وعندما تكون true، تتضمن المقاطع المُخرجة طوابع زمنية على مستوى الكلمة.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `text` | النص الناتج عن تحويل الصوت إلى نص. | STRING |
| `language_code` | رمز اللغة وفق ISO 639-1 المكتشف للصوت. | STRING |
| `segments_json` | سلسلة JSON تحتوي على مقاطع النص المحوّل. تتضمن طوابع زمنية على مستوى الكلمة عند تمكين `precise_timestamps`. | STRING |
