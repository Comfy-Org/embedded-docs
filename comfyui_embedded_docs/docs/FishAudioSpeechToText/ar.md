# FishAudioSpeechToText

هذه العقدة تحوّل الصوت إلى نص باستخدام خدمة تحويل الكلام إلى نص من Fish Audio. تكتشف لغة الصوت تلقائيًا، ويمكنها اختياريًا إرجاع مقاطع مع طوابع زمنية على مستوى الكلمة بصيغة JSON.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `audio` | الصوت المراد تحويله إلى نص. | AUDIO | نعم | — |
| `language` | تلميح اللغة وفقًا لمعيار ISO 639-1 (مثل 'en'، 'zh'). يتم اكتشاف اللغة تلقائيًا في جميع الحالات. الافتراضي: "" (سلسلة فارغة). | STRING | لا | أي رمز لغة ISO 639-1، مثل `en`، `zh`؛ سلسلة فارغة للاكتشاف التلقائي |
| `precise_timestamps` | إرجاع مقاطع زمنية على مستوى الكلمة. الافتراضي: false. | BOOLEAN | لا | true أو false |

ملاحظة: معامل `language` هو مجرد تلميح — يتم دائمًا اكتشاف اللغة تلقائيًا من الصوت. عندما تكون قيمة `precise_timestamps` هي false (الافتراضي)، لا يتم إرجاع الطوابع الزمنية على مستوى الكلمة؛ وعندما تكون true، تتضمن مقاطع الإخراج طوابع زمنية على مستوى الكلمة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `text` | النص المحوَّل. | STRING |
| `language_code` | رمز اللغة ISO 639-1 المكتشف للصوت. | STRING |
| `segments_json` | سلسلة JSON تحتوي على مقاطع التحويل. تتضمن طوابع زمنية على مستوى الكلمة عند تفعيل `precise_timestamps`. | STRING |
