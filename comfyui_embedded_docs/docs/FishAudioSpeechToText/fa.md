# تبدیل گفتار به متن Fish Audio

این گره با استفاده از سرویس تبدیل گفتار به متن Fish Audio، صدا را به متن رونویسی می‌کند. این گره زبان صدا را به‌طور خودکار تشخیص می‌دهد و می‌تواند به‌صورت اختیاری بخش‌های زمان‌بندی‌شده در سطح کلمه را به شکل JSON برگرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | صدا برای رونویسی. | AUDIO | بله | — |
| `language` | راهنمای زبان ISO 639-1 (مثلاً 'en'، 'zh'). زبان بدون توجه به این مورد به‌طور خودکار تشخیص داده می‌شود. پیش‌فرض: "" (رشته خالی). | STRING | خیر | هر کد زبان ISO 639-1، مثلاً `en`، `zh`؛ رشته خالی برای تشخیص خودکار |
| `precise_timestamps` | بخش‌های زمان‌بندی‌شده در سطح کلمه را برمی‌گرداند. پیش‌فرض: false. | BOOLEAN | خیر | true or false |

توجه: پارامتر `language` فقط یک راهنماست — زبان همیشه به‌طور خودکار از صدا تشخیص داده می‌شود. وقتی `precise_timestamps` برابر false باشد (حالت پیش‌فرض)، برچسب‌های زمانی در سطح کلمه برگردانده نمی‌شوند؛ وقتی true باشد، بخش‌های خروجی شامل برچسب‌های زمانی در سطح کلمه هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `text` | متن رونویسی‌شده. | STRING |
| `language_code` | کد زبان ISO 639-1 تشخیص‌داده‌شده برای صدا. | STRING |
| `segments_json` | رشتهٔ JSON حاوی بخش‌های رونویسی. هنگامی که `precise_timestamps` فعال باشد، برچسب‌های زمانی در سطح کلمه را شامل می‌شود. | STRING |
