# FishAudioSpeechToText

این گره با استفاده از سرویس تبدیل گفتار به متن Fish Audio، صدا را به متن رونویسی می‌کند. زبان صدا به‌طور خودکار تشخیص داده می‌شود و در صورت تمایل، می‌تواند بخش‌های زمانی در سطح کلمه را به صورت JSON بازگرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | صدایی که باید رونویسی شود. | AUDIO | بله | — |
| `language` | راهنمای زبان ISO 639-1 (مثلاً 'en'، 'zh'). زبان در هر صورت به‌طور خودکار تشخیص داده می‌شود. پیش‌فرض: "" (رشته خالی). | STRING | خیر | هر کد زبان ISO 639-1، مانند `en`، `zh`؛ رشته خالی برای تشخیص خودکار |
| `precise_timestamps` | بازگرداندن بخش‌های زمانی در سطح کلمه. پیش‌فرض: false. | BOOLEAN | خیر | true یا false |

نکته: پارامتر `language` فقط یک راهنما است — زبان همیشه از روی صدا به‌طور خودکار تشخیص داده می‌شود. وقتی `precise_timestamps` برابر false باشد (پیش‌فرض)، برچسب‌های زمانی سطح کلمه بازگردانده نمی‌شوند؛ وقتی true باشد، بخش‌های خروجی شامل برچسب‌های زمانی سطح کلمه هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `text` | متن رونویسی‌شده. | STRING |
| `language_code` | کد زبان ISO 639-1 تشخیص‌داده‌شده برای صدا. | STRING |
| `segments_json` | رشته JSON شامل بخش‌های رونویسی. وقتی `precise_timestamps` فعال باشد، برچسب‌های زمانی سطح کلمه را شامل می‌شود. | STRING |
