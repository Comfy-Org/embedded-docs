# FishAudioSpeechToText

Этот узел преобразует аудио в текст с помощью сервиса распознавания речи Fish Audio. Он автоматически определяет язык аудио и может опционально возвращать посегментные временные метки на уровне слов в формате JSON.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для транскрибации. | AUDIO | Да | — |
| `language` | Подсказка языка в формате ISO 639-1 (например, 'en', 'zh'). Язык в любом случае определяется автоматически. По умолчанию: "" (пустая строка). | STRING | Нет | Любой код языка ISO 639-1, например, `en`, `zh`; пустая строка для автоматического определения |
| `precise_timestamps` | Возвращать посегментные временные метки на уровне слов. По умолчанию: false. | BOOLEAN | Нет | true или false |

Примечание: Параметр `language` является лишь подсказкой — язык всегда определяется автоматически по аудио. Когда `precise_timestamps` имеет значение false (по умолчанию), временные метки на уровне слов не возвращаются; когда true, выходные сегменты включают временные метки на уровне слов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `text` | Транскрибированный текст. | STRING |
| `language_code` | Код языка ISO 639-1, определенный для аудио. | STRING |
| `segments_json` | JSON-строка, содержащая сегменты транскрибации. Включает временные метки на уровне слов, когда `precise_timestamps` включен. | STRING |
