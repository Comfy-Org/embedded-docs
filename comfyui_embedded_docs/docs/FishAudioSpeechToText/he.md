# Fish Audio דיבור לטקסט

צומת זה מתמלל אודיו לטקסט באמצעות שירות דיבור-לטקסט של Fish Audio. הוא מזהה אוטומטית את שפת האודיו, ובאופן אופציונלי יכול להחזיר מקטעים עם חותמות זמן ברמת מילה כ-JSON.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio` | אודיו לתמלול. | AUDIO | כן | — |
| `language` | רמז לשפה לפי ISO 639-1 (לדוגמה 'en', 'zh'). השפה מזוהה אוטומטית בכל מקרה. ברירת מחדל: "" (מחרוזת ריקה). | STRING | לא | כל קוד שפה ISO 639-1, למשל `en`, `zh`; מחרוזת ריקה לזיהוי אוטומטי |
| `precise_timestamps` | להחזיר מקטעים עם חותמות זמן ברמת מילה. ברירת מחדל: false. | BOOLEAN | לא | true או false |

הערה: הפרמטר `language` הוא רק רמז — השפה תמיד מזוהה אוטומטית מהאודיו. כאשר `precise_timestamps` הוא false (ברירת המחדל), חותמות זמן ברמת מילה לא מוחזרות; כאשר true, מקטעי הפלט כוללים חותמות זמן ברמת מילה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `text` | הטקסט המתומלל. | STRING |
| `language_code` | קוד השפה ISO 639-1 שזוהה עבור האודיו. | STRING |
| `segments_json` | מחרוזת JSON המכילה את מקטעי התמלול. כוללת חותמות זמן ברמת מילה כאשר `precise_timestamps` מופעל. | STRING |
