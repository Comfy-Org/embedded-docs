# Сохранить изображение

Узел SaveImage сохраняет полученные изображения в ваш каталог `ComfyUI/output`. Каждое изображение сохраняется в виде PNG-файла, и в него могут быть встроены метаданные рабочего процесса, например промпт, для последующего использования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Изображения для сохранения. | IMAGE | Да | - |
| `filename_prefix` | Префикс для сохраняемого файла. Может содержать форматирующую информацию, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для подстановки значений из узлов (по умолчанию: "ComfyUI"). | STRING | Да | - |
| `prompt` | Скрытый вход, предоставляемый автоматически ComfyUI: данные промпта, встраиваемые в сохранённый PNG-файл как метаданные. | PROMPT | Нет | - |
| `extra_pnginfo` | Скрытый вход, предоставляемый автоматически ComfyUI: дополнительная информация о рабочем процессе, встраиваемая в сохранённый PNG-файл как метаданные. | EXTRA_PNGINFO | Нет | - |

Каждое изображение сохраняется как PNG-файл. В имени сохраняемого файла `%batch_num%` в префиксе заменяется на номер батча изображения, а также добавляется дополненный нулями счётчик.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Те же самые изображения, которые были сохранены, передаются дальше для использования другими узлами. | IMAGE |
| `ui` | Результат интерфейса, содержащий список сохранённых изображений с их именами файлов, вложенными папками и типом, отображаемый в интерфейсе ComfyUI. | UI_RESULT |
