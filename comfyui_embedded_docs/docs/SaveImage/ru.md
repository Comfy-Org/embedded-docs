# Сохранить изображение

Узел SaveImage сохраняет входные изображения в формате PNG в вашу выходную директорию ComfyUI. Он может встраивать метаданные рабочего процесса, такие как промпт, в каждый сохраненный файл, и возвращает изображения без изменений, чтобы их можно было использовать в других узлах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Изображения для сохранения. | IMAGE | Да | - |
| `префикс_названия_файла` | Префикс для сохраняемого файла. Может включать информацию о форматировании, такую как `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, для включения значений из узлов (по умолчанию: "ComfyUI"). | STRING | Да | - |

Узел также получает два скрытых входа: `prompt` и `extra_pnginfo`, которые автоматически заполняются ComfyUI с помощью промпта рабочего процесса и дополнительной PNG-информации. Когда метаданные включены, эта информация встраивается как текстовые метаданные в каждый сохраненный PNG-файл.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Исходные входные изображения, возвращенные без изменений после сохранения на диск. | IMAGE |
| `ui` | Результат, предназначенный только для интерфейса, содержащий список сохраненных файлов изображений (имя файла, подпапка и тип) для отображения во фронтенде. | UI_RESULT |
