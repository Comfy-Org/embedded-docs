# Сохранить изображение

Узел SaveImage сохраняет входные изображения как файлы PNG в выходной каталог ComfyUI. Он может встраивать метаданные рабочего процесса, такие как промпт, в каждый сохраняемый файл и возвращает изображения без изменений, чтобы их могли использовать другие узлы.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Изображения для сохранения. | IMAGE | Да | - |
| `префикс_названия_файла` | Префикс имени сохраняемого файла. Может содержать информацию о форматировании, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`, чтобы включить значения из узлов (по умолчанию: "ComfyUI"). | STRING | Да | - |

Узел также получает два скрытых входа, `prompt` и `extra_pnginfo`, которые автоматически заполняются ComfyUI промптом рабочего процесса и дополнительной информацией PNG. Когда метаданные включены, эта информация встраивается как текстовые метаданные в каждый сохраняемый PNG-файл.

Имя файла для каждого сохраняемого изображения формируется из `filename_prefix`, необязательного заполнителя `%batch_num%`, который заменяется на позицию изображения в пакете, и пятизначного счётчика, например `ComfyUI_00001_.png`. Изображения записываются с уровнем сжатия PNG 4.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Исходные входные изображения, возвращаемые без изменений после сохранения на диск. | IMAGE |
| `ui` | Результат только для интерфейса, содержащий список сохранённых файлов изображений (имя файла, подпапка и тип) для отображения во фронтенде. | UI_RESULT |
