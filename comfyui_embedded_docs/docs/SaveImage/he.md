# שמירת תמונה

צומת SaveImage שומר את תמונות הקלט כקובצי PNG בתיקיית הפלט של ComfyUI. הוא יכול להטביע מטא-דאטה של זרימת העבודה, כגון הפרומפט, בכל קובץ נשמר, והוא מחזיר את התמונות ללא שינוי כך שניתן עדיין להשתמש בהן בצמתים אחרים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `images` | התמונות לשמירה. | IMAGE | כן | - |
| `filename_prefix` | הקידומת לקובץ לשמירה. עשויה לכלול מידע עיצוב כגון `%date:yyyy-MM-dd%` או `%Empty Latent Image.width%` כדי לכלול ערכים מצמתים (ברירת מחדל: "ComfyUI"). | STRING | כן | - |

הצומת מקבל גם שני קלטים נסתרים, `prompt` ו-`extra_pnginfo`, שמאוכלסים אוטומטית על ידי ComfyUI עם הפרומפט של זרימת העבודה ומידע PNG נוסף. כאשר מטא-דאטה מופעלת, מידע זה מוטבע כמטא-דאטה טקסטואלית בכל קובץ PNG שנשמר.

שם הקובץ עבור כל תמונה נשמרת נבנה מ-`filename_prefix`, מציין מקום אופציונלי `%batch_num%` שמוחלף במיקומה של התמונה באצווה, ומונה בן חמש ספרות, לדוגמה `ComfyUI_00001_.png`. התמונות נכתבות ברמת דחיסת PNG 4.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `images` | תמונות הקלט המקוריות, מוחזרות ללא שינוי לאחר שמירתן לדיסק. | IMAGE |
| `ui` | תוצאה לממשק משתמש בלבד, המכילה את רשימת קובצי התמונות שנשמרו (שם קובץ, תיקיית משנה וסוג) להצגה בממשק המשתמש. | UI_RESULT |
