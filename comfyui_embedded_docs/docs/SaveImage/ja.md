# 画像を保存

SaveImage ノードは、受け取った画像を `ComfyUI/output` ディレクトリに保存します。各画像は PNG ファイルとして保存され、保存されたファイルにプロンプトなどのワークフローメタデータを埋め込んで、後で参照できるようにすることができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `images` | 保存する画像です。 | IMAGE | はい | - |
| `filename_prefix` | 保存するファイルのプレフィックスです。ノードの値を含めるための `%date:yyyy-MM-dd%` や `%Empty Latent Image.width%` などの書式情報を含めることができます（デフォルト: "ComfyUI"）。 | STRING | はい | - |
| `prompt` | 非表示の入力で、ComfyUI によって自動的に提供されます。保存された PNG ファイルにメタデータとして埋め込まれるプロンプトデータです。 | PROMPT | いいえ | - |
| `extra_pnginfo` | 非表示の入力で、ComfyUI によって自動的に提供されます。保存された PNG ファイルにメタデータとして埋め込まれる追加のワークフロー情報です。 | EXTRA_PNGINFO | いいえ | - |

各画像は PNG ファイルとして保存されます。保存されるファイル名では、プレフィックス内の `%batch_num%` が画像のバッチ番号に置き換えられ、ゼロ埋めされたカウンタが追加されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `images` | 保存された画像と同じものです。他のノードで使用できるようにそのまま渡されます。 | IMAGE |
| `ui` | UI 結果です。保存された画像のファイル名、サブフォルダ、タイプのリストを含み、ComfyUI インターフェースに表示されます。 | UI_RESULT |
