# ذخیره تصویر

گره SaveImage تصاویر دریافتی را در شاخه `ComfyUI/output` شما ذخیره می‌کند. هر تصویر را به‌صورت یک فایل PNG ذخیره کرده و می‌تواند فراداده‌های گردش کار، مانند prompt، را برای مراجعات بعدی در فایل ذخیره‌شده جاسازی کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
| --- | --- | --- | --- | --- |
| `images` | تصاویری که باید ذخیره شوند. | IMAGE | بله | - |
| `filename_prefix` | پیشوند فایل برای ذخیره‌سازی. این می‌تواند شامل اطلاعات قالب‌بندی مانند `%date:yyyy-MM-dd%` یا `%Empty Latent Image.width%` باشد تا مقادیری از گره‌ها را در بر بگیرد (پیش‌فرض: "ComfyUI"). | STRING | بله | - |
| `prompt` | ورودی پنهان که به‌طور خودکار توسط ComfyUI ارائه می‌شود: داده‌های prompt به‌عنوان فراداده در فایل PNG ذخیره‌شده جاسازی می‌شوند. | PROMPT | خیر | - |
| `extra_pnginfo` | ورودی پنهان که به‌طور خودکار توسط ComfyUI ارائه می‌شود: اطلاعات اضافی گردش کار به‌عنوان فراداده در فایل PNG ذخیره‌شده جاسازی می‌شوند. | EXTRA_PNGINFO | خیر | - |

هر تصویر به‌صورت یک فایل PNG ذخیره می‌شود. در نام فایل ذخیره‌شده، `%batch_num%` در پیشوند با شماره دسته تصویر جایگزین می‌شود و یک شمارنده با صفرهای پیش‌رونده به انتهای آن اضافه می‌گردد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `images` | همان تصاویری که ذخیره شده‌اند، به‌صورت عبوری برای استفاده در سایر گره‌ها منتقل می‌شوند. | IMAGE |
| `ui` | نتیجه UI شامل فهرستی از تصاویر ذخیره‌شده به همراه نام فایل، زیرپوشه‌ها و نوع آن‌ها که در رابط ComfyUI نمایش داده می‌شود. | UI_RESULT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/SaveImage/fa.md)
