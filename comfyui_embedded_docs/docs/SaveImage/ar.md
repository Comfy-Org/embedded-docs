# حفظ الصورة

تقوم عقدة SaveImage بحفظ الصور التي تستقبلها إلى دليل `ComfyUI/output` الخاص بك. تحفظ كل صورة كملف PNG، ويمكنها تضمين بيانات وصفية لسير العمل، مثل الاستعلام، في الملف المحفوظ للرجوع إليها في المستقبل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `images` | الصور المراد حفظها. | IMAGE | نعم | - |
| `filename_prefix` | بادئة اسم الملف المراد حفظه. قد تتضمن معلومات تنسيق مثل `%date:yyyy-MM-dd%` أو `%Empty Latent Image.width%` لتضمين قيم من العقد (الافتراضي: "ComfyUI"). | STRING | نعم | - |
| `prompt` | إدخال مخفي، يوفره ComfyUI تلقائيًا: بيانات الاستعلام المضمّنة كبيانات وصفية في ملف PNG المحفوظ. | PROMPT | لا | - |
| `extra_pnginfo` | إدخال مخفي، يوفره ComfyUI تلقائيًا: معلومات إضافية حول سير العمل مضمّنة كبيانات وصفية في ملف PNG المحفوظ. | EXTRA_PNGINFO | لا | - |

تُحفظ كل صورة كملف PNG. في اسم الملف المحفوظ، يُستبدل `%batch_num%` في البادئة برقم دفعة الصورة، ويُضاف عداد معبأ بالأصفار في نهايته.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `images` | الصور نفسها التي تم حفظها، تمر عبر العقدة بحيث يمكن استخدامها بواسطة عقد أخرى. | IMAGE |
| `ui` | نتيجة واجهة المستخدم تحتوي على قائمة الصور المحفوظة مع أسماء ملفاتها ومجلداتها الفرعية ونوعها، معروضة في واجهة ComfyUI. | UI_RESULT |
