# Kling 4.0 Long Image

使用 Kling 4.0 生成一張長圖：完整的網頁設計，或電商產品詳情頁。選擇符合你所需版面的 `skill`，節點便會顯示該版面對應的輸入。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `技能` | 要生成的版面。`"webpage"` 會圍繞選用的樣式影像與主體設計完整頁面；`"ecommerce"` 則根據產品照片建構產品詳情頁。 | DYNAMIC_COMBO | 是 | `"webpage"`<br>`"ecommerce"` |

### `webpage` 輸入

當 `skill` 設為 `"webpage"` 時會顯示這些輸入。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `style_image` | 選用的視覺樣式與版面參考。以 `@Image1` 引用。 | IMAGE | 否 | 單張圖片 |
| `subject_image` | 選用的主體，會予以保留並圍繞其設計頁面。以 `@Image2` 引用。 | IMAGE | 否 | 單張圖片 |
| `prompt` | 選用的頁面描述。以 `@Image1` 引用樣式影像、`@Image2` 引用主體影像，並指定頁面文字所使用的語言，例如「所有可見文字必須僅使用英文」。預設：空字串。 | STRING | 是 | 多行文字 |
| `resolution` | 輸出影像的解析度。預設：`"1K"`。 | COMBO | 是 | `"1K"`<br>`"2K"` |
| `seed` | `seed` 控制節點是否應重新執行；無論種子為何，結果皆不具決定性。預設：42。 | INT | 是 | 0 至 2147483647 |

### `ecommerce` 輸入

當 `skill` 設為 `"ecommerce"` 時會顯示這些輸入。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `product_images` | 產品照片的可擴充輸入槽（`image_1` ... `image_3`）。在提示詞中以 `@Image1`、`@Image2`、`@Image3` 引用。 | AUTOGROW | 是 | 1 至 3 張影像 |
| `prompt` | 選用的頁面描述。以 `@Image1`、`@Image2`、`@Image3` 引用產品影像。預設：空字串。 | STRING | 是 | 多行文字 |
| `length` | 生成頁面的長度。預設：`"medium"`。 | COMBO | 是 | `"short"`<br>`"medium"`<br>`"long"` |
| `resolution` | 輸出影像的解析度。預設：`"1K"`。 | COMBO | 是 | `"1K"`<br>`"2K"` |
| `seed` | `seed` 控制節點是否應重新執行；無論種子為何，結果皆不具決定性。預設：42。 | INT | 是 | 0 至 2147483647 |

**限制與行為：**

* 在 `ecommerce` 中最多可連接 3 張產品影像。
* 每張影像至少須為 300x300 像素，長寬比介於 2:5 至 5:2 之間。
* 使用 `webpage` 時，若提示詞提及 `@Image1` 或 `@Image2`，而該影像未連接，便會引發錯誤。
* 每次呼叫的價格取決於 `skill`、解析度，以及（在 `ecommerce` 情況下）頁面長度。
