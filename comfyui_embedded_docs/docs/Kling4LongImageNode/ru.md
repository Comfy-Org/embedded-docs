# Kling 4.0 Long Image

Создайте одно длинное изображение с помощью Kling 4.0: полный дизайн веб-страницы или страницу с подробной информацией о товаре для интернет-магазина. Выберите `skill`, соответствующий нужному макету, и узел отобразит входы этого макета.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `навык` | Макет для генерации. `"webpage"` создаёт полную страницу на основе необязательного изображения стиля и объекта; `"ecommerce"` создаёт страницу с подробной информацией о товаре из фотографий товара. | DYNAMIC_COMBO | Да | `"webpage"`<br>`"ecommerce"` |

### Входы `webpage`

Эти входы появляются, когда для `skill` задано значение `"webpage"`.

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `style_image` | Необязательный референс для визуального стиля и макета. Ссылайтесь на него как на `@Image1`. | IMAGE | Нет | Одно изображение |
| `subject_image` | Необязательный объект, который нужно сохранить и вокруг которого строится страница. Ссылайтесь на него как на `@Image2`. | IMAGE | Нет | Одно изображение |
| `prompt` | Необязательное описание страницы. Ссылайтесь на изображение стиля как на `@Image1`, а на изображение объекта — как на `@Image2`, и укажите язык текста страницы, например: «Весь видимый текст должен быть только на английском языке». По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного изображения. По умолчанию: `"1K"`. | COMBO | Да | `"1K"`<br>`"2K"` |
| `seed` | `seed` управляет тем, нужно ли повторно запускать узел; результаты недетерминированы независимо от `seed`. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

### Входы `ecommerce`

Эти входы появляются, когда для `skill` задано значение `"ecommerce"`.

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `product_images` | Расширяемые слоты для фотографий товара (`image_1` ... `image_3`). Ссылайтесь на них в промпте как на `@Image1`, `@Image2`, `@Image3`. | AUTOGROW | Да | от 1 до 3 изображений |
| `prompt` | Необязательное описание страницы. Ссылайтесь на изображения товара как на `@Image1`, `@Image2`, `@Image3`. По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `length` | Длина генерируемой страницы. По умолчанию: `"medium"`. | COMBO | Да | `"short"`<br>`"medium"`<br>`"long"` |
| `resolution` | Разрешение выходного изображения. По умолчанию: `"1K"`. | COMBO | Да | `"1K"`<br>`"2K"` |
| `seed` | `seed` управляет тем, нужно ли повторно запускать узел; результаты недетерминированы независимо от `seed`. По умолчанию: 42. | INT | Да | от 0 до 2147483647 |

**Ограничения и поведение:**

* В `ecommerce` можно подключить не более 3 изображений товара.
* Каждое изображение должно иметь размер не менее 300x300 пикселей с соотношением сторон от 2:5 до 5:2.
* В режиме `webpage` промпт, в котором упоминается `@Image1` или `@Image2`, вызывает ошибку, если это изображение не подключено.
* Стоимость вызова зависит от `skill`, разрешения и, для `ecommerce`, длины страницы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное длинное изображение, загружаемое из Kling после завершения задачи. | IMAGE |
