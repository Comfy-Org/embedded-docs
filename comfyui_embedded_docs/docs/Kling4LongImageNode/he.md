# Kling 4.0 Long Image

צור תמונה אחת גבוהה עם Kling 4.0: עיצוב עמוד אינטרנט מלא, או עמוד פרטים למוצר בסחר אלקטרוני. בחר את ה-`skill` שמתאים לפריסה הרצויה, והצומת יציג את הקלטים של אותה פריסה.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `מיומנות` | הפריסה ליצירה. `"webpage"` מעצב עמוד מלא סביב תמונת סגנון ונושא אופציונליים; `"ecommerce"` בונה עמוד פרטי מוצר מתוך תמונות מוצר. | DYNAMIC_COMBO | כן | `"webpage"`<br>`"ecommerce"` |

### קלטים של `webpage`

קלטים אלה מופיעים כאשר `skill` מוגדר ל-`"webpage"`.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `style_image` | הפניה אופציונלית לסגנון החזותי ולפריסה. יש להתייחס אליה כ-`@Image1`. | IMAGE | לא | תמונה בודדת |
| `subject_image` | נושא אופציונלי לשימור ולעיצוב העמוד סביבו. יש להתייחס אליו כ-`@Image2`. | IMAGE | לא | תמונה בודדת |
| `prompt` | תיאור אופציונלי של העמוד. יש להתייחס לתמונת הסגנון כ-`@Image1` ולתמונת הנושא כ-`@Image2`, ולציין את השפה של טקסט העמוד, לדוגמה: "כל הטקסט הנראה חייב להיות באנגלית בלבד." ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `resolution` | רזולוציית תמונת הפלט. ברירת מחדל: `"1K"`. | COMBO | כן | `"1K"`<br>`"2K"` |
| `seed` | ה-seed קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

### קלטים של `ecommerce`

קלטים אלה מופיעים כאשר `skill` מוגדר ל-`"ecommerce"`.

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `product_images` | חריצים הניתנים להרחבה עבור תמונות המוצר (`image_1` ... `image_3`). יש להתייחס אליהם בפרומפט כ-`@Image1`, `@Image2`, `@Image3`. | AUTOGROW | כן | 1 עד 3 תמונות |
| `prompt` | תיאור אופציונלי של העמוד. יש להתייחס לתמונות המוצר כ-`@Image1`, `@Image2`, `@Image3`. ברירת מחדל: מחרוזת ריקה. | STRING | כן | טקסט רב-שורתי |
| `length` | אורך העמוד הנוצר. ברירת מחדל: `"medium"`. | COMBO | כן | `"short"`<br>`"medium"`<br>`"long"` |
| `resolution` | רזולוציית תמונת הפלט. ברירת מחדל: `"1K"`. | COMBO | כן | `"1K"`<br>`"2K"` |
| `seed` | ה-seed קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא קשר ל-seed. ברירת מחדל: 42. | INT | כן | 0 עד 2147483647 |

**אילוצים והתנהגות:**

* ניתן לחבר לכל היותר 3 תמונות מוצר ב-`ecommerce`.
* כל תמונה חייבת להיות בגודל של לפחות 300x300 פיקסלים, עם יחס רוחב-גובה בין 2:5 ל-5:2.
* ב-`webpage`, פרומפט שמזכיר את `@Image1` או `@Image2` מעלה שגיאה כאשר התמונה המתאימה אינה מחוברת.
* מחיר הקריאה תלוי ב-skill, ברזולוציה, וב-`ecommerce` גם באורך העמוד.
