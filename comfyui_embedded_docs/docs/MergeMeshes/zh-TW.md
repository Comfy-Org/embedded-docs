# MergeMeshes

MergeMeshes 透過堆疊多個網格輸入的頂點、面、UV 座標與頂點顏色，並調整面索引，將它們合併為單一連續網格。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `meshes` | 可擴充插槽：連接 2 至 50 個網格物件（命名為 `mesh_1`、`mesh_2`、...、`mesh_50`）。所有已連接的網格會合併為一個輸出網格。 | MESH | 是 | 2 至 50 meshes |

**注意：** 僅使用每個輸入網格批次中的第一個網格項目。如果任何輸入網格具有 UV 資料，輸出將包含 UV，而沒有 UV 的網格會獲得填零的 UV 值。如果任何輸入網格具有頂點顏色，輸出將包含頂點顏色；沒有顏色的網格會獲得白色（數值 1）顏色，且顏色通道會填補至輸入中最大的通道數。僅保留第一個有提供紋理的輸入中的紋理；其他紋理會被丟棄。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `mesh` | 合併後的網格，包含所有輸入的頂點、面、UV 與顏色，組合成單一網格。 | MESH |
