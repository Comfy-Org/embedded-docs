# 合併網格

MergeMeshes 會將多個網格輸入合併為單一網格，方式是堆疊它們的頂點、面、UV 座標與頂點顏色，並偏移面索引，讓所有部分能正確接合成一個連續網格。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `meshes` | 可增長的插槽：連接 2 到 50 個網格物件（命名為 `mesh_1`、`mesh_2`、...、`mesh_50`）。所有連接的網格會合併為一個輸出網格。 | MESH | 是 | 2 至 50 meshes |

**注意：** 必須至少提供一個網格，否則節點會引發錯誤。每個輸入網格批次中只會使用第一個網格項目。合併前會將輸入網格移至 CPU。如果任何輸入網格具有 UV 資料，則輸出會包含 UV，而沒有 UV 的網格會獲得填零的 UV 值。如果任何輸入網格具有頂點顏色，則輸出會包含頂點顏色；沒有顏色的網格會獲得白色（值 1）顏色，且顏色通道會填充至輸入中找到的最大通道數。只會保留第一個提供紋理的輸入其紋理；其他紋理會被捨棄。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
|-------------|-----------|-----------|
| `mesh` | 合併後的網格，包含所有輸入頂點、面、UV 與顏色，並組合成一個網格。 | MESH |
