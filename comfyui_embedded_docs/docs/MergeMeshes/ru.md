# MergeMeshes

MergeMeshes объединяет несколько входных mesh в один mesh, складывая их вершины, грани, UV-координаты и цвета вершин, а также корректируя индексы граней, чтобы результат представлял собой единый непрерывный mesh.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетки` | Расширяемый слот: подключите от 2 до 50 mesh-объектов (с именами `mesh_1`, `mesh_2`, ..., `mesh_50`). Все подключенные mesh объединяются в один выходной mesh. | MESH | Да | от 2 до 50 mesh |

**Примечание:** Используется только первый элемент mesh из пакета каждого входного mesh. Если хотя бы один входной mesh содержит UV-данные, выходные данные включают UV, а mesh без UV получают UV-значения, заполненные нулями. Если хотя бы один входной mesh имеет цвета вершин, выходные данные включают цвета вершин; mesh без цветов получают белый цвет (значение 1), а цветовые каналы дополняются до наибольшего количества каналов, обнаруженного среди входных данных. Сохраняется только текстура от первого входного mesh, у которого она есть; дополнительные текстуры отбрасываются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `сетка` | Объединенный mesh, содержащий все входные вершины, грани, UV и цвета, объединенные в один mesh. | MESH |
