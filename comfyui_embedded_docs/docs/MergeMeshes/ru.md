# Объединить сетки

MergeMeshes объединяет несколько входных мешей в один меш, складывая их вершины, грани, UV-координаты и цвета вершин, а также смещая индексы граней так, чтобы все части правильно соединялись в один непрерывный меш.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетки` | Расширяемый слот: подключите от 2 до 50 mesh-объектов (с именами `mesh_1`, `mesh_2`, ..., `mesh_50`). Все подключённые меши объединяются в один выходной меш. | MESH | Да | от 2 до 50 мешей |

**Примечание:** Необходимо предоставить хотя бы один меш; иначе узел выдаёт ошибку. Используется только первый mesh-элемент из батча каждого входного меша. Перед объединением входные меши перемещаются на CPU. Если какой-либо входной меш содержит UV-данные, выходной меш включает UV, а меши без UV получают UV-значения, заполненные нулями. Если какой-либо входной меш содержит цвета вершин, выходной меш включает цвета вершин; меши без цветов получают белые цвета (значение 1), а цветовые каналы дополняются до наибольшего количества каналов, обнаруженного среди входных данных. Сохраняется только текстура из первого входа, который её предоставляет; дополнительные текстуры отбрасываются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Объединённый меш, содержащий все входные вершины, грани, UV и цвета, скомбинированные в один меш. | MESH |
