# دمج الشبكات

يدمج MergeMeshes مدخلات شبكية متعددة في شبكة واحدة عن طريق تكديس رؤوسها وأوجهها وإحداثيات UV وألوان رؤوسها، وإزاحة مؤشرات الأوجه بحيث تنضم جميع الأجزاء بشكل صحيح إلى شبكة واحدة متصلة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `meshes` | فتحة قابلة للتوسيع: صِل من 2 إلى 50 كائن شبكة (بأسماء `mesh_1`، `mesh_2`، ...، `mesh_50`). يتم دمج جميع الشبكات المتصلة في شبكة مخرجة واحدة. | MESH | نعم | 2 إلى 50 meshes |

**ملاحظة:** يجب توفير شبكة واحدة على الأقل؛ وإلا فإن العقدة تُطلق خطأً. يُستخدم فقط أول عنصر شبكة من دفعة كل شبكة إدخال. تُنقل شبكات الإدخال إلى CPU قبل الدمج. إذا كانت أي شبكة إدخال تحتوي على بيانات UV، فسيضم المخرج قيم UV، وستتلقى الشبكات التي لا تحتوي على UV قيم UV معبأة بالأصفار. إذا كانت أي شبكة إدخال تحتوي على ألوان رؤوس، فسيضم المخرج ألوان الرؤوس؛ وستتلقى الشبكات التي لا تحتوي على ألوان لونًا أبيض (القيمة 1)، وستُحشى قنوات الألوان لتصل إلى أكبر عدد قنوات موجود بين المدخلات. يُحتفظ فقط بالنسيج (texture) من أول إدخال يوفره؛ وتُهمَل النُسج الإضافية.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `mesh` | الشبكة المدموجة التي تحتوي على جميع رؤوس المدخلات وأوجهها وقيم UV وألوانها مجتمعة في شبكة واحدة. | MESH |
