# MiniMax Image to Video

יוצר וידאו באופן סינכרוני בהתבסס על תמונה ופרומפט, ופרמטרים אופציונליים באמצעות ה-API של MiniMax. צומת זה מקבל תמונת קלט ותיאור טקסטואלי כדי ליצור רצף וידאו, עם אפשרויות מודל והגדרות תצורה שונות זמינות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונה שתשמש כפריים הראשון של יצירת הווידאו | IMAGE | כן | - |
| `prompt_text` | פרומפט טקסטואלי להנחיית יצירת הווידאו (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `model` | מודל לשימוש עבור יצירת וידאו (ברירת מחדל: "I2V-01") | COMBO | כן | "I2V-01-Director"<br>"I2V-01"<br>"I2V-01-live" |
| `seed` | ערך ה-seed האקראי המשמש ליצירת הרעש (ברירת מחדל: 0) | INT | לא | 0 עד 18446744073709551615 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | פלט הווידאו שנוצר | VIDEO |
