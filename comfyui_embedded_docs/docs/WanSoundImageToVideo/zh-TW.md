# 萬聲圖像轉影片

WanSoundImageToVideo 節點可從影像生成影片內容，並可選擇加入音訊條件。它接受正向與負向條件提示，以及 VAE 模型來建立影片潛在表示，並可結合參考影像、音訊編碼、控制影片與動態參考，以引導影片生成過程。
