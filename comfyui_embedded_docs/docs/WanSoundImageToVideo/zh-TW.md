# 萬聲圖像轉影片

WanSoundImageToVideo 節點會為 Wan 聲音轉影片生成準備條件與空的 latent 影片張量。它可選擇性地納入音訊編碼、參考影像、控制影片與動作參考，以引導生成的影片。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正面提示` | 正向條件提示詞，用於引導生成影片中應出現的內容 | CONDITIONING | 是 | - |
| `負面提示` | 負向條件提示詞，用於指定生成影片中應避免的內容 | CONDITIONING | 是 | - |
| `VAE` | 用於將參考影像、動作參考與控制影片影格編碼為 latent 表示的 VAE 模型 | VAE | 是 | - |
| `寬度` | 輸出影片的寬度，單位為像素（預設：832，步長：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 輸出影片的高度，單位為像素（預設：480，步長：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `長度` | 生成影片的影格數（預設：77，步長：4） | INT | 是 | 1 to MAX_RESOLUTION |

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
| --- | --- | --- |
