# WanSoundImageToVideo

WanSoundImageToVideo ノードは、オプションのオーディオ条件付けを使用して、画像からのビデオ生成を準備します。ポジティブおよびネガティブのコンディショニングプロンプトとVAEモデルを受け取り、コンディショニング入力と空の潜在テンソルを構築します。また、参照画像、オーディオエンコーディング、コントロールビデオ、モーション参照を組み込んで、ビデオ生成プロセスをガイドできます。
