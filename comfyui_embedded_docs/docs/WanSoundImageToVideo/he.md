# WanSoundImageToVideo

הצומת WanSoundImageToVideo מכין קונדישנינג וטנזור לטנט ריק של וידאו עבור יצירת וידאו מקול של Wan. הוא יכול לשלב באופן אופציונלי קידוד אודיו, תמונת עזר, וידאו בקרה ורפרנס תנועה כדי להנחות את הווידאו המיוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | פרומפטים של קונדישנינג חיובי שמנחים איזה תוכן צריך להופיע בווידאו המיוצר | CONDITIONING | כן | - |
| `negative` | פרומפטים של קונדישנינג שלילי שמציינים איזה תוכן יש להימנע ממנו בווידאו המיוצר | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות עזר, רפרנסים לתנועה ופריימים של וידאו בקרה לייצוגים לטנטיים | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו המיוצר (ברירת מחדל: 77, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר סרטוני הווידאו ליצירה בו-זמנית (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `audio_encoder_output` | קידוד אודיו אופציונלי שיכול להשפיע על יצירת הווידאו בהתאם למאפייני הצליל. כאשר הוא מסופק, מאפייני האודיו עוברים אינטרפולציה ומשמשים להתניית יצירת הווידאו. | AUDIO_ENCODER_OUTPUT | לא | - |
| `ref_image` | תמונת עזר אופציונלית המספקת הכוונה חזותית לתוכן הווידאו. התמונה מוגדלת להתאמה לרוחב ולגובה שצוינו, ואז מקודדת לייצוג לטנטי. רק התמונה הראשונה בקלט משמשת כעזר. | IMAGE | לא | - |
| `control_video` | וידאו בקרה אופציונלי שמנחה את התנועה והמבנה של הווידאו המיוצר. הווידאו מוגדל ומקודד, ואז משמש להתניית הפלט. רק `length` הפריימים הראשונים משמשים. | IMAGE | לא | - |
| `ref_motion` | רפרנס תנועה אופציונלי המספק הכוונה לדפוסי תנועה בווידאו. אם בקלט יש יותר מ-73 פריימים, ישמשו רק 73 האחרונים. אם מסופקים פחות מ-73 פריימים, הרצף מרופד בפריימים ניטרליים. | IMAGE | לא | - |

הערה: כל הקלטים האופציונליים יכולים לשמש בנפרד או יחד. הצומת משנה את הקונדישנינג `positive` ו-`negative` שסופק, בהתאם לכך אילו קלטים אופציונליים מחוברים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | קונדישנינג חיובי מעובד ששונה עבור יצירת וידאו, כולל הטמעות אודיו, לטנטים של עזר, רפרנסים לתנועה וקונדישנינג של וידאו בקרה כאשר הקלטים האופציונליים המתאימים מסופקים | CONDITIONING |
| `negative` | קונדישנינג שלילי מעובד ששונה עבור יצירת וידאו, כולל הטמעות אודיו (מוגדרות לאפס), לטנטים של עזר, רפרנסים לתנועה וקונדישנינג של וידאו בקרה כאשר הקלטים האופציונליים המתאימים מסופקים | CONDITIONING |
| `latent` | טנזור לטנט ריק של וידאו המשמש כנקודת התחלה ליצירה. לטנזור הלטנט צורה `[batch_size, 16, latent_t, height/8, width/8]`, כאשר `latent_t` מחושב כ-`((length - 1) // 4) + 1`. | LATENT |
