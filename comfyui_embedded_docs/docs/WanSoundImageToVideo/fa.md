# وان‌ساند ایمیج تو ویدیو

گره WanSoundImageToVideo محتوای ویدیویی را از تصاویر با شرطی‌سازی صوتی اختیاری تولید می‌کند. این گره پرامپت‌های شرطی‌سازی مثبت و منفی را همراه با یک مدل VAE دریافت می‌کند تا نهان‌های ویدیو را ایجاد کند و می‌تواند از تصاویر مرجع، رمزگذاری صوتی، ویدیوهای کنترلی و مراجع حرکت برای هدایت فرآیند تولید ویدیو استفاده کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت که محتوای موردنظر برای نمایش در ویدیوی تولیدی را هدایت می‌کنند | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرطی‌سازی منفی که مشخص می‌کنند از چه محتوایی در ویدیوی تولیدی باید اجتناب شود | CONDITIONING | بله | - |
| `vae` | مدل VAE که برای رمزگذاری و رمزگشایی بازنمایی‌های نهان ویدیو استفاده می‌شود | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 832، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 480، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیوی تولیدی (پیش‌فرض: 77، باید بر 4 بخش‌پذیر باشد) | INT | بله | 1 تا MAX_RESOLUTION |
| `اندازه بچ` | تعداد ویدیوهایی که به‌طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی انکودر صوتی` | رمزگذاری اختیاری صدا که می‌تواند بر اساس ویژگی‌های صوتی بر تولید ویدیو تأثیر بگذارد. در صورت ارائه، ویژگی‌های صوتی درون‌یابی شده و برای شرطی‌سازی تولید ویدیو استفاده می‌شوند. | AUDIO_ENCODER_OUTPUT | خیر | - |
| `تصویر مرجع` | تصویر مرجع اختیاری که راهنمای بصری برای محتوای ویدیو فراهم می‌کند. تصویر برای مطابقت با عرض و ارتفاع مشخص‌شده بزرگ‌نمایی می‌شود و سپس به یک بازنمایی نهان رمزگذاری می‌گردد. فقط اولین تصویر ورودی به‌عنوان مرجع استفاده می‌شود. | IMAGE | خیر | - |
| `کنترل ویدیو` | ویدیوی کنترلی اختیاری که حرکت و ساختار ویدیوی تولیدی را هدایت می‌کند. ویدیو بزرگ‌نمایی و رمزگذاری می‌شود و سپس برای شرطی‌سازی خروجی استفاده می‌گردد. فقط `length` فریم اول استفاده می‌شود. | IMAGE | خیر | - |
| `حرکت مرجع` | مرجع حرکت اختیاری که الگوهای حرکتی در ویدیو را راهنمایی می‌کند. اگر ورودی بیش از 73 فریم داشته باشد، فقط 73 فریم آخر استفاده می‌شود. اگر کمتر از 73 فریم ارائه شود، دنباله با فریم‌های خنثی پر می‌شود. | IMAGE | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت پردازش‌شده که برای تولید ویدیو اصلاح شده است، شامل تعبیه‌های صوتی، نهان‌های مرجع، مراجع حرکت و شرطی‌سازی ویدیوی کنترلی | CONDITIONING |
| `منفی` | شرطی‌سازی منفی پردازش‌شده که برای تولید ویدیو اصلاح شده است، شامل تعبیه‌های صوتی (صفر شده)، نهان‌های مرجع، مراجع حرکت و شرطی‌سازی ویدیوی کنترلی | CONDITIONING |
| `latent` | بازنمایی ویدیوی تولیدشده در فضای نهان که می‌تواند به فریم‌های نهایی ویدیو رمزگشایی شود. تنسور نهان دارای شکل [batch_size, 16, latent_t, height/8, width/8] است که در آن latent_t از پارامتر length مشتق می‌شود | LATENT |
