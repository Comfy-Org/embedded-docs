# وان‌ساند ایمیج تو ویدیو

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت که مشخص می‌کنند چه محتوایی باید در ویدیوی تولیدشده ظاهر شود | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی‌سازی منفی که مشخص می‌کنند چه محتوایی باید در ویدیوی تولیدشده اجتناب شود | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری و رمزگشایی بازنمایی‌های لاتنت ویدیو | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION (step: 16) |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، باید بر 16 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION (step: 16) |
| `length` | تعداد فریم‌های ویدیوی تولیدشده (پیش‌فرض: 77، باید بر 4 بخش‌پذیر باشد) | INT | بله | 1 to MAX_RESOLUTION (step: 4) |
| `batch_size` | تعداد ویدیوهایی که به طور هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `audio_encoder_output` | رمزگذاری صوتی اختیاری که می‌تواند بر اساس ویژگی‌های صدا بر تولید ویدیو تأثیر بگذارد. وقتی ارائه شود، ویژگی‌های صوتی درون‌یابی شده و برای شرطی‌سازی تولید ویدیو استفاده می‌شوند. | AUDIOENCODEROUTPUT | خیر | - |
| `ref_image` | تصویر مرجع اختیاری که راهنمای بصری برای محتوای ویدیو فراهم می‌کند. تصویر برای مطابقت با عرض و ارتفاع مشخص‌شده افزایش مقیاس می‌یابد و سپس به یک بازنمایی لاتنت رمزگذاری می‌شود. فقط اولین تصویر در دسته ورودی استفاده می‌شود. | IMAGE | خیر | - |
| `control_video` | ویدیوی کنترلی اختیاری که حرکت و ساختار ویدیوی تولیدشده را هدایت می‌کند. ویدیو افزایش مقیاس یافته و رمزگذاری می‌شود و سپس برای شرطی‌سازی خروجی استفاده می‌گردد. فقط `length` فریم ابتدایی استفاده می‌شود. | IMAGE | خیر | - |
| `ref_motion` | مرجع حرکت اختیاری که الگوهای حرکت در ویدیو را هدایت می‌کند. اگر ورودی بیش از 73 فریم داشته باشد، فقط 73 فریم آخر استفاده می‌شود. اگر کمتر از 73 فریم ارائه شود، دنباله با فریم‌های خنثی پر می‌شود. | IMAGE | خیر | - |

**نکته:** ورودی‌های اختیاری (`audio_encoder_output`، `ref_image`، `control_video`، `ref_motion`) می‌توانند به طور مستقل یا ترکیبی استفاده شوند. شرطی‌سازی ویدیوی کنترلی همیشه اعمال می‌شود؛ وقتی `control_video` ارائه نشود، یک ویدیوی کنترلی خالی (صفر) استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت پردازش‌شده که برای تولید ویدیو تغییر یافته است. هنگامی که ورودی‌های اختیاری مربوطه ارائه شوند، این خروجی شامل جاسازی‌های صوتی، لاتنت‌های مرجع، مراجع حرکت و شرطی‌سازی ویدیوی کنترلی می‌شود. | CONDITIONING |
| `negative` | شرطی‌سازی منفی پردازش‌شده که برای تولید ویدیو تغییر یافته است. هنگامی که ورودی‌های اختیاری مربوطه ارائه شوند، این خروجی شامل جاسازی‌های صوتی (با مقدار صفر)، لاتنت‌های مرجع، مراجع حرکت و شرطی‌سازی ویدیوی کنترلی می‌شود. | CONDITIONING |
| `latent` | تانسور لاتنت خالی که نقطه شروع تولید ویدیو است. شکل لاتنت `[batch_size, 16, latent_t, height/8, width/8]` است که در آن `latent_t = ((length - 1) // 4) + 1`. | LATENT |
