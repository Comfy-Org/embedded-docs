# وان‌ساند ایمیج تو ویدیو

گره WanSoundImageToVideo شرطی‌سازی و یک تنسور ویدئویی نهفته خالی را برای تولید ویدئو از صدا در Wan آماده می‌کند. این گره می‌تواند به‌صورت اختیاری کدگذاری صدا، تصویر مرجع، ویدئوی کنترل و مرجع حرکت را برای هدایت ویدئوی تولیدشده ادغام کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرطی‌سازی مثبت که تعیین می‌کنند چه محتوایی باید در ویدئوی تولیدشده ظاهر شود | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرطی‌سازی منفی که مشخص می‌کنند از چه محتوایی در ویدئوی تولیدشده باید اجتناب شود | CONDITIONING | بله | - |
| `vae` | مدل VAE که برای کدگذاری تصاویر مرجع، مراجع حرکت و فریم‌های ویدئوی کنترل به بازنمایی‌های نهفته استفاده می‌شود | VAE | بله | - |
| `عرض` | عرض ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدئوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدئوی تولیدشده (پیش‌فرض: 77، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `اندازه بچ` | تعداد ویدئوهایی که هم‌زمان تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی انکودر صوتی` | کدگذاری اختیاری صدا که می‌تواند بر تولید ویدئو بر اساس ویژگی‌های صوتی تأثیر بگذارد. در صورت ارائه، ویژگی‌های صوتی درون‌یابی شده و برای شرطی‌سازی تولید ویدئو استفاده می‌شوند. | AUDIO_ENCODER_OUTPUT | خیر | - |
| `تصویر مرجع` | تصویر مرجع اختیاری که راهنمایی بصری برای محتوای ویدئو فراهم می‌کند. تصویر برای تطابق با عرض و ارتفاع مشخص‌شده بزرگ‌نمایی می‌شود و سپس به یک بازنمایی نهفته کدگذاری می‌گردد. فقط اولین تصویر از ورودی به‌عنوان مرجع استفاده می‌شود. | IMAGE | خیر | - |
| `کنترل ویدیو` | ویدئوی کنترل اختیاری که حرکت و ساختار ویدئوی تولیدشده را هدایت می‌کند. ویدئو بزرگ‌نمایی و کدگذاری می‌شود و سپس برای شرطی‌سازی خروجی به کار می‌رود. فقط `length` فریم اول استفاده می‌شوند. | IMAGE | خیر | - |
| `حرکت مرجع` | مرجع حرکت اختیاری که راهنمایی برای الگوهای حرکتی در ویدئو فراهم می‌کند. اگر ورودی بیش از 73 فریم داشته باشد، فقط 73 فریم آخر استفاده می‌شوند. اگر کمتر از 73 فریم ارائه شود، توالی با فریم‌های خنثی پر می‌شود. | IMAGE | خیر | - |

توجه: همه ورودی‌های اختیاری می‌توانند به‌صورت مستقل یا همراه با یکدیگر استفاده شوند. این گره شرطی‌سازی ارائه‌شده `positive` و `negative` را بر اساس ورودی‌های اختیاری متصل‌شده تغییر می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت پردازش‌شده که برای تولید ویدئو تغییر یافته است، شامل جاسازی‌های صوتی، نهفته‌های مرجع، مراجع حرکت و شرطی‌سازی ویدئوی کنترل در صورت ارائه ورودی‌های اختیاری مربوطه | CONDITIONING |
| `negative` | شرطی‌سازی منفی پردازش‌شده که برای تولید ویدئو تغییر یافته است، شامل جاسازی‌های صوتی (تنظیم‌شده روی صفر)، نهفته‌های مرجع، مراجع حرکت و شرطی‌سازی ویدئوی کنترل در صورت ارائه ورودی‌های اختیاری مربوطه | CONDITIONING |
| `latent` | تنسور ویدئویی نهفته خالی که به‌عنوان نقطه شروع تولید استفاده می‌شود. تنسور نهفته دارای شکل `[batch_size, 16, latent_t, height/8, width/8]` است، که در آن `latent_t` به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود. | LATENT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/WanSoundImageToVideo/fa.md)
