# WanSoundImageToVideo

Узел WanSoundImageToVideo подготавливает генерацию видео из изображений с возможным аудио-кондиционированием. Он принимает позитивные и негативные кондиционирующие промпты вместе с моделью VAE для создания кондиционирующих входов и пустого латентного тензора, а также может включать эталонные изображения, аудио-кодирование, управляющие видео и ссылки на движение для управления процессом генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Позитивные кондиционирующие промпты, которые определяют, какое содержимое должно появляться в генерируемом видео | CONDITIONING | Да | - |
| `negative` | Негативные кондиционирующие промпты, которые указывают, какого содержимого следует избегать в генерируемом видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования и декодирования латентных представлений видео | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, должна делиться на 16) | INT | Да | 16 to MAX_RESOLUTION (step: 16) |
| `length` | Количество кадров в генерируемом видео (по умолчанию: 77, должно делиться на 4) | INT | Да | 1 to MAX_RESOLUTION (step: 4) |
| `batch_size` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `audio_encoder_output` | Необязательное аудио-кодирование, которое может влиять на генерацию видео на основе характеристик звука. При наличии аудио-признаки интерполируются и используются для кондиционирования генерации видео. | AUDIOENCODEROUTPUT | Нет | - |
| `ref_image` | Необязательное эталонное изображение, которое обеспечивает визуальное руководство для содержимого видео. Изображение увеличивается до указанных ширины и высоты, затем кодируется в латентное представление. Используется только первое изображение из входного пакета. | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое направляет движение и структуру генерируемого видео. Видео увеличивается и кодируется, затем используется для кондиционирования выходных данных. Используются только первые `length` кадров. | IMAGE | Нет | - |
| `ref_motion` | Необязательная ссылка на движение, которая обеспечивает руководство по паттернам движения в видео. Если на входе более 73 кадров, используются только последние 73. Если предоставлено менее 73 кадров, последовательность дополняется нейтральными кадрами. | IMAGE | Нет | - |

**Примечание:** Необязательные входы (`audio_encoder_output`, `ref_image`, `control_video`, `ref_motion`) могут использоваться независимо или в комбинации. Кондиционирование управляющим видео применяется всегда; если `control_video` не предоставлен, используется пустое (нулевое) управляющее видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанное позитивное кондиционирование, модифицированное для генерации видео. При наличии соответствующих необязательных входов оно включает аудио-вложения, эталонные латентные представления, ссылки на движение и кондиционирование управляющим видео. | CONDITIONING |
| `negative` | Обработанное негативное кондиционирование, модифицированное для генерации видео. При наличии соответствующих необязательных входов оно включает аудио-вложения (обнуленные), эталонные латентные представления, ссылки на движение и кондиционирование управляющим видео. | CONDITIONING |
| `latent` | Пустой латентный тензор, который служит отправной точкой для генерации видео. Латентный тензор имеет форму [batch_size, 16, latent_t, height/8, width/8], где latent_t = ((length - 1) // 4) + 1. | LATENT |
