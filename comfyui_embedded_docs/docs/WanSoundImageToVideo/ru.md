# WanSoundImageToVideo

Узел WanSoundImageToVideo подготавливает conditioning и пустой латентный тензор видео для генерации видео по звуку Wan. Он может дополнительно учитывать аудиокодирование, эталонное изображение, управляющее видео и эталон движения для направления генерируемого видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Позитивные conditioning-промпты, задающие, какое содержимое должно появиться в генерируемом видео | CONDITIONING | Да | - |
| `негативный` | Негативные conditioning-промпты, указывающие, какого содержимого следует избегать в генерируемом видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования эталонных изображений, эталонов движения и кадров управляющего видео в латентные представления | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в генерируемом видео (по умолчанию: 77, шаг: 4) | INT | Да | 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых одновременно (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `выход_аудиокодера` | Необязательное аудиокодирование, которое может влиять на генерацию видео на основе характеристик звука. Если оно предоставлено, аудиопризнаки интерполируются и используются для кондиционирования генерации видео. | AUDIO_ENCODER_OUTPUT | Нет | - |
| `ref_image` | Необязательное эталонное изображение, которое обеспечивает визуальную ориентацию для содержимого видео. Изображение масштабируется до указанных ширины и высоты, затем кодируется в латентное представление. В качестве эталона используется только первое изображение из входа. | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое задаёт движение и структуру генерируемого видео. Видео масштабируется и кодируется, а затем используется для кондиционирования выходных данных. Используются только первые `length` кадров. | IMAGE | Нет | - |
| `ref_motion` | Необязательный эталон движения, который задаёт шаблоны перемещения в видео. Если на входе больше 73 кадров, используются только последние 73. Если предоставлено меньше 73 кадров, последовательность дополняется нейтральными кадрами. | IMAGE | Нет | - |

Примечание: Все необязательные входы можно использовать независимо или вместе. Узел изменяет переданные `positive` и `negative` conditioning в зависимости от того, какие необязательные входы подключены.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанный позитивный conditioning, изменённый для генерации видео, включая аудиоэмбеддинги, эталонные латентные представления, эталоны движения и conditioning управляющего видео, когда предоставлены соответствующие необязательные входы | CONDITIONING |
| `negative` | Обработанный негативный conditioning, изменённый для генерации видео, включая аудиоэмбеддинги (установленные в ноль), эталонные латентные представления, эталоны движения и conditioning управляющего видео, когда предоставлены соответствующие необязательные входы | CONDITIONING |
| `latent` | Пустой латентный тензор видео, используемый в качестве начальной точки для генерации. Латентный тензор имеет форму `[batch_size, 16, latent_t, height/8, width/8]`, где `latent_t` вычисляется как `((length - 1) // 4) + 1`. | LATENT |
