# WanSoundImageToVideo

Узел WanSoundImageToVideo генерирует видеоконтент из изображений с возможностью аудио-кондиционирования. Он принимает позитивные и негативные кондиционирующие подсказки вместе с моделью VAE для создания латентных представлений видео, а также может использовать референсные изображения, аудиокодирование, управляющие видео и референсы движения для управления процессом генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Позитивные кондиционирующие подсказки, которые определяют, какое содержимое должно появиться в генерируемом видео | CONDITIONING | Да | - |
| `негативный` | Негативные кондиционирующие подсказки, указывающие, какого содержимого следует избегать в генерируемом видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования и декодирования латентных представлений видео | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, должна быть кратна 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в генерируемом видео (по умолчанию: 77, должно быть кратно 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео для одновременной генерации (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `выход_аудиокодера` | Необязательное аудиокодирование, которое может влиять на генерацию видео на основе характеристик звука. При его наличии аудио-признаки интерполируются и используются для кондиционирования генерации видео. | AUDIO_ENCODER_OUTPUT | Нет | - |
| `ref_image` | Необязательное референсное изображение, обеспечивающее визуальное руководство для содержимого видео. Изображение увеличивается до указанных ширины и высоты, затем кодируется в латентное представление. Используется только первое изображение входного набора. | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое направляет движение и структуру генерируемого видео. Видео увеличивается и кодируется, затем используется для кондиционирования выходного результата. Используются только первые `length` кадров. | IMAGE | Нет | - |
| `ref_motion` | Необязательный референс движения, обеспечивающий ориентиры для паттернов движения в видео. Если вход содержит более 73 кадров, используются только последние 73. Если предоставлено менее 73 кадров, последовательность дополняется нейтральными кадрами. | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанное позитивное кондиционирование, изменённое для генерации видео, включающее аудио-вложения, референсные латентные представления, референсы движения и кондиционирование управляющим видео | CONDITIONING |
| `negative` | Обработанное негативное кондиционирование, изменённое для генерации видео, включающее аудио-вложения (обнулённые), референсные латентные представления, референсы движения и кондиционирование управляющим видео | CONDITIONING |
| `latent` | Сгенерированное представление видео в латентном пространстве, которое может быть декодировано в итоговые видеокадры. Тензор латентного представления имеет форму [batch_size, 16, latent_t, height/8, width/8], где latent_t вычисляется из параметра length | LATENT |
