# TextEncodeQwenImage21

הצומת TextEncodeQwenImage21 מקודד פרומפט ופרומפט שלילי עבור מודל Qwen-Image 2.1, עם אפשרות לצרף תמונות עזר. תמונות העזר נראות על ידי מקודד הטקסט, וכאשר VAE מחובר, הן גם מקודדות כ-latents המשובצים ברצף, כך שה-conditioning נושא גם את הוראת הטקסט וגם את ההפניה החזותית. הצומת מחזיר conditioning חיובי ושלילי יחד עם latent ריק בגודל תמונת העזר הראשונה, מוכן לדגימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מקודד הטקסט של Qwen-Image 2.1 המשמש לטוקניזציה ולקידוד הפרומפטים. | CLIP | כן | - |
| `prompt` | פרומפט טקסטואלי המתאר את התמונה שיש ליצור או את העריכה שיש להחיל. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | כל טקסט |
| `negative_prompt` | פרומפט טקסטואלי המתאר ממה התוצאה צריכה להימנע. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | כל טקסט |
| `vae` | VAE המשמש לקידוד תמונות העזר ל-latents של תמונות עזר. כאשר הוא מושמט, תמונות העזר משפיעות על התוצאה רק דרך מקודד הטקסט. | VAE | לא | - |
| `resolution` | תמונות העזר משתנות לגודל של בערך `resolution` x `resolution` פיקסלים, בכפולות של 32, תוך שמירה על יחס רוחב-גובה. 0 שומר על כל תמונת עזר בגודלה שלה, מעוגל לכפולה של 32 (ברירת מחדל: 1024). | INT | כן | 0 עד 4096 (צעד 32) |
| `images` | תמונות עזר, הנראות על ידי מקודד הטקסט ומשובצות ברצף כ-latents של VAE. חריץ ניתן להרחבה: חבר עד 16 תמונות (`image_1` ... `image_16`). | IMAGE | לא | 0 עד 16 תמונות |

פלט ה-latent הריק מותאם בגודלו לתמונת העזר הראשונה המחוברת, או ל-`resolution` כאשר לא מחוברת תמונת עזר. יש לדגום ב-latent שהצומת מחזיר: כל גודל אחר משנה את העריכה. כאשר VAE מחובר, אותם latents של תמונות העזר מצורפים גם ל-conditioning החיובי וגם לשלילי, כך שצעד דגימה יחיד יכול לבצע דנואיזינג לשניהם.
