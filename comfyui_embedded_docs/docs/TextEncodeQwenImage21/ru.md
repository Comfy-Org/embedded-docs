# TextEncodeQwenImage21

Узел TextEncodeQwenImage21 кодирует промпт и негативный промпт для модели Qwen-Image 2.1, при необходимости прикрепляя референсные изображения. Референсные изображения видит текстовый энкодер, а при подключённом VAE они также кодируются в латенты, которые вставляются в последовательность, поэтому кондиционирование несёт как текстовую инструкцию, так и визуальный референс. Узел возвращает положительное и отрицательное кондиционирование вместе с пустым латентом, размер которого соответствует первому референсному изображению, готовым к сэмплированию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Текстовый энкодер Qwen-Image 2.1, используемый для токенизации и кодирования промптов. | CLIP | Да | - |
| `prompt` | Текстовый промпт, описывающий изображение для генерации или правку, которую нужно применить. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Любой текст |
| `negative_prompt` | Текстовый промпт, описывающий, чего результат должен избегать. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Любой текст |
| `vae` | VAE, используемый для кодирования референсных изображений в референсные латенты. Если не указан, референсные изображения влияют на результат только через текстовый энкодер. | VAE | Нет | - |
| `resolution` | Референсные изображения изменяются до примерно `resolution` x `resolution` пикселей, кратно 32, с сохранением соотношения сторон. 0 сохраняет каждое референсное изображение в его собственном размере, округлённом до кратного 32 (по умолчанию: 1024). | INT | Да | 0–4096 (шаг 32) |
| `images` | Референсные изображения, которые видит текстовый энкодер и которые вставляются в последовательность как латенты VAE. Расширяемый слот: можно подключить до 16 изображений (`image_1` ... `image_16`). | IMAGE | Нет | 0–16 изображений |

Пустой латент на выходе имеет размер первого подключённого референсного изображения или `resolution`, если референсное изображение не подключено. Сэмплируйте с латентом, который возвращает этот узел: любой другой размер смещает правку. Когда VAE подключён, одни и те же референсные латенты прикрепляются как к положительному, так и к отрицательному кондиционированию, поэтому один шаг сэмплера может денойзить оба.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Закодированное кондиционирование для промпта, несущее референсные латенты, когда VAE подключён. | CONDITIONING |
| `отрицательный` | Закодированное кондиционирование для негативного промпта, с теми же референсными латентами. | CONDITIONING |
| `латент` | Пустой латент размером с первое референсное изображение или 1024 x 1024, если референсное изображение не подключено. | LATENT |
