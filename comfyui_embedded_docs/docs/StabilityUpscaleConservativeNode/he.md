# StabilityUpscaleConservativeNode

הגדל תמונה ברזולוציית 4K עם שינויים מזעריים. צומת זה משתמש בהגדלה השמרנית של Stability AI כדי להעלות את רזולוציית התמונה תוך שמירה על התוכן המקורי וביצוע שינויים עדינים בלבד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שיש להגדיל | IMAGE | כן | - |
| `prompt` | מה שתרצו לראות בתמונת הפלט. פרומפט חזק ותיאורי שמגדיר בבירור אלמנטים, צבעים ונושאים יוביל לתוצאות טובות יותר. (ברירת מחדל: מחרוזת ריקה) | STRING | כן | - |
| `creativity` | שולט בסבירות ליצירת פרטים נוספים שאינם תלויים במידה רבה בתמונת האתחול. (ברירת מחדל: 0.35) | FLOAT | כן | 0.2 - 0.5 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | כן | 0 - 4294967294 |
| `negative_prompt` | מילות מפתח של מה שאינכם רוצים לראות בתמונת הפלט. זוהי תכונה מתקדמת. (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
