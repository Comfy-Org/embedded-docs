# קידוד טקסט CLIP (PixArt Alpha)

מקודד טקסט ומגדיר את התניית הרזולוציה עבור PixArt Alpha. צומת זה מעבד קלט טקסט ומוסיף מידע של רוחב וגובה כדי ליצור נתוני התניה במיוחד עבור מודלים של PixArt Alpha. הוא אינו חל על מודלים של PixArt Sigma.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `width` | מידת הרוחב עבור התניית רזולוציה (ברירת מחדל: 1024) | INT | כן | 0 עד MAX_RESOLUTION |
| `height` | מידת הגובה עבור התניית רזולוציה (ברירת מחדל: 1024) | INT | כן | 0 עד MAX_RESOLUTION |
| `text` | קלט טקסט שיש לקודד. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `clip` | מודל CLIP המשמש לטוקניזציה ולקידוד | CLIP | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `CONDITIONING` | נתוני התניה מקודדים עם טוקנים של טקסט ומידע על רזולוציה | CONDITIONING |
