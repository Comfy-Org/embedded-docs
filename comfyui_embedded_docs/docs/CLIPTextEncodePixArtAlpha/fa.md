# CLIPTextEncodePixArtAlpha

متن را رمزگذاری کرده و تنظیمات وضوح را برای PixArt Alpha اعمال می‌کند. این گره ورودی متنی را پردازش کرده و اطلاعات عرض و ارتفاع را برای ایجاد داده‌های شرطی‌سازی مخصوص مدل‌های PixArt Alpha اضافه می‌کند. این گره برای مدل‌های PixArt Sigma اعمال نمی‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `عرض` | بعد عرض برای شرطی‌سازی وضوح (پیش‌فرض: 1024) | INT | بله | 0 to MAX_RESOLUTION |
| `ارتفاع` | بعد ارتفاع برای شرطی‌سازی وضوح (پیش‌فرض: 1024) | INT | بله | 0 to MAX_RESOLUTION |
| `متن` | ورودی متنی که باید رمزگذاری شود. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `CONDITIONING` | داده‌های شرطی‌سازی رمزگذاری‌شده حاوی توکن‌های متنی و اطلاعات وضوح | CONDITIONING |
