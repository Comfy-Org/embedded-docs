# CLIPTextEncodePixArtAlpha

متن را رمزگذاری کرده و کاندیشنینگ وضوح را برای PixArt Alpha تنظیم می‌کند. این گره ورودی متنی را پردازش کرده و اطلاعات عرض و ارتفاع را برای ایجاد داده کاندیشنینگ مخصوص مدل‌های PixArt Alpha اضافه می‌کند. برای مدل‌های PixArt Sigma کاربرد ندارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | بعد عرض برای کاندیشنینگ وضوح (پیش‌فرض: 1024) | INT | بله | 0 to MAX_RESOLUTION |
| `height` | بعد ارتفاع برای کاندیشنینگ وضوح (پیش‌فرض: 1024) | INT | بله | 0 to MAX_RESOLUTION |
| `text` | ورودی متنی که باید رمزگذاری شود، از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند | STRING | بله | - |
| `clip` | مدل CLIP که برای توکن‌سازی و رمزگذاری استفاده می‌شود | CLIP | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده کاندیشنینگ رمزگذاری‌شده به همراه توکن‌های متنی و اطلاعات وضوح | CONDITIONING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/CLIPTextEncodePixArtAlpha/fa.md)
