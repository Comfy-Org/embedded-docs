# ترميز نص CLIP لـ PixArt Alpha

يقوم هذا العقدة بترميز النص وضبط شروط الدقة (resolution conditioning) لنموذج PixArt Alpha. تعالج هذه العقدة إدخال النص وتضيف معلومات العرض والارتفاع لإنشاء بيانات التكييف (conditioning) المخصصة لنماذج PixArt Alpha تحديدًا. لا تنطبق على نماذج PixArt Sigma.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `العرض` | بُعد العرض لتكييف الدقة (الافتراضي: 1024) | INT | نعم | 0 إلى MAX_RESOLUTION |
| `الارتفاع` | بُعد الارتفاع لتكييف الدقة (الافتراضي: 1024) | INT | نعم | 0 إلى MAX_RESOLUTION |
| `النص` | النص المراد ترميزه. يدعم الإدخال متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `CLIP` | نموذج CLIP المستخدم في الترميز وتحويل النص إلى رموز | CLIP | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `CONDITIONING` | بيانات التكييف المرمزة مع رموز النص ومعلومات الدقة | CONDITIONING |
