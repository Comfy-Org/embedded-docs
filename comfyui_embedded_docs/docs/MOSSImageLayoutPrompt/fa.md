# MOSS-Image Layout Prompt

پرامپت چیدمانی را می‌سازد که MOSS-Image آن را می‌خواند. عناصر ترسیم‌شده در گره Create Bounding Boxes را می‌گیرد و یک چیدمان JSON با یک درایه برای هر کادر تولید می‌کند: برچسب آن، کپشن آن، و مستطیل آن در فضای پیکسلی بوم هدف. `width` و `height` را روی اندازه تصویری که قصد تولید آن را دارید تنظیم کنید، سپس خروجی را به ورودی پرامپتِ رمزگذار متن متصل کنید. اگر هیچ عنصری متصل نباشد، متن پرامپت بدون تغییر بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `prompt` | توضیح کل تصویر. به‌عنوان کپشن چیدمان استفاده می‌شود. | STRING | بله | - |
| `element` | عناصری که باید قرار گیرند، برگرفته از گره Create Bounding Boxes. هر کادر کپشن خود را ارائه می‌کند؛ کادرهای متنی نیز متن خود را ارائه می‌دهند، و کادرهایی که پالت رنگ دارند آن را حفظ می‌کنند. | ARRAY | بله | - |
| `width` | عرض تصویر تولیدشده بر حسب پیکسل. کادرها به این شبکه پیکسلی تبدیل می‌شوند، بنابراین از اندازه تصویری که قصد تولید آن را دارید استفاده کنید (پیش‌فرض: 1024). | INT | بله | 16 تا 16384 (گام 16) |
| `height` | ارتفاع تصویر تولیدشده بر حسب پیکسل. کادرها به این شبکه پیکسلی تبدیل می‌شوند، بنابراین از اندازه تصویری که قصد تولید آن را دارید استفاده کنید (پیش‌فرض: 1024). | INT | بله | 16 تا 16384 (گام 16) |
| `character_boxes` | شماره کادرهایی که باید به‌جای اشیاء به‌عنوان شخصیت برچسب‌گذاری شوند، همان‌طور که در پیش‌نمایش Create Bounding Boxes برچسب خورده‌اند، مثلاً «1, 3». هر عددی در رشته خوانده می‌شود، بنابراین هر جداکننده‌ای کار می‌کند (پیش‌فرض: خالی). | STRING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `prompt` | پرامپت چیدمان: یک شیء JSON شامل کپشن، یک درایه برای هر کادر، و قالب مختصات کادر. وقتی هیچ عنصری متصل نباشد، متن ورودی بدون تغییر عبور داده می‌شود. | STRING |

## نکات

مستطیل‌های کادر از Create Bounding Boxes به‌صورت مختصات نرمال‌شده بین 0 و 1000 می‌آیند و در چیدمان به‌صورت پیکسل نسبت به مرکز بوم، با ترتیب `yxyx` نوشته می‌شوند. بنابراین مقادیر `width` و `height` باید با تصویری که تولید می‌کنید مطابقت داشته باشند، در غیر این صورت کادرها در جای اشتباه قرار می‌گیرند.

کادری که متن دارد همیشه به‌عنوان متن برچسب‌گذاری می‌شود، کادری که شماره‌اش در `character_boxes` فهرست شده است به‌عنوان شخصیت برچسب می‌خورد، و هر کادر دیگر به‌عنوان شیء برچسب‌گذاری می‌شود.
