# MOSS-Image Layout Prompt

בונה את פרומפט הפריסה ש-MOSS-Image קורא. הוא מקבל את האלמנטים שצוירו בצומת Create Bounding Boxes ומפיק פריסת JSON עם רשומה אחת לכל תיבה: התווית שלה, הכיתוב שלה, והמלבן שלה במרחב הפיקסלים של קנבס היעד. יש להגדיר את `width` ואת `height` לגודל התמונה שאתם מתכננים ליצור, ואז לחבר את הפלט לקלט ה-prompt של מקודד הטקסט. כאשר אין אלמנטים מחוברים, טקסט ה-prompt מוחזר ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `prompt` | תיאור של התמונה כולה. הוא הופך לכיתוב של הפריסה. | STRING | כן | - |
| `element` | האלמנטים להצבה, נלקחים מצומת Create Bounding Boxes. כל תיבה תורמת את הכיתוב שלה; תיבות טקסט תורמות גם את הטקסט שלהן, ותיבות שנושאות פלטת צבעים שומרות עליה. | ARRAY | כן | - |
| `width` | רוחב התמונה המיוצרת בפיקסלים. התיבות מומרות לרשת הפיקסלים הזו, לכן יש להשתמש בגודל התמונה שאתם מתכננים ליצור (ברירת מחדל: 1024). | INT | כן | 16 עד 16384 (צעד: 16) |
| `height` | גובה התמונה המיוצרת בפיקסלים. התיבות מומרות לרשת הפיקסלים הזו, לכן יש להשתמש בגודל התמונה שאתם מתכננים ליצור (ברירת מחדל: 1024). | INT | כן | 16 עד 16384 (צעד: 16) |
| `character_boxes` | מספרי התיבות שיש לתייג כדמויות במקום כאובייקטים, כפי שסומנו בתצוגה המקדימה של Create Bounding Boxes, לדוגמה "1, 3". כל מספר במחרוזת נקרא, כך שכל מפריד עובד (ברירת מחדל: ריק). | STRING | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `prompt` | פרומפט הפריסה: אובייקט JSON המכיל את הכיתוב, רשומה אחת לכל תיבה, ואת פורמט הקואורדינטות של התיבה. טקסט הקלט מועבר כמו שהוא כאשר אין אלמנטים מחוברים. | STRING |

## הערות

מלבני התיבות מגיעים מ-Create Bounding Boxes כקואורדינטות מנורמלות בין 0 ל-1000 ונכתבים לפריסה בפיקסלים ביחס למרכז הקנבס, בסדר `yxyx`. לכן ערכי `width` ו-`height` חייבים להתאים לתמונה שאתם יוצרים, אחרת התיבות ינחתו במקום הלא נכון.

תיבה שמכילה טקסט תמיד מתויגת כטקסט, תיבה שמספרה מופיע ב-`character_boxes` מתויגת כדמות, וכל תיבה אחרת מתויגת כאובייקט.
