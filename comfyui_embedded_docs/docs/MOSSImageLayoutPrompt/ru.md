# MOSS-Image Layout Prompt

Формирует промпт макета, который читает MOSS-Image. Он принимает элементы, нарисованные в узле Create Bounding Boxes, и выдаёт JSON-макет с одной записью на каждый бокс: его метку, его подпись и его прямоугольник в пиксельном пространстве целевого холста. Установите `width` и `height` равными размеру изображения, которое вы планируете сгенерировать, затем подключите выход к входу промпта текстового энкодера. Если элементы не подключены, текст промпта возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Описание всего изображения. Оно становится подписью макета. | STRING | Да | - |
| `element` | Элементы для размещения, взятые из узла Create Bounding Boxes. Каждый бокс вносит свою подпись; текстовые боксы также вносят свой текст, а боксы, содержащие цветовую палитру, сохраняют её. | ARRAY | Да | - |
| `width` | Ширина генерируемого изображения в пикселях. Боксы преобразуются в эту пиксельную сетку, поэтому используйте размер изображения, которое вы планируете сгенерировать (по умолчанию: 1024). | INT | Да | от 16 до 16384 (шаг 16) |
| `height` | Высота генерируемого изображения в пикселях. Боксы преобразуются в эту пиксельную сетку, поэтому используйте размер изображения, которое вы планируете сгенерировать (по умолчанию: 1024). | INT | Да | от 16 до 16384 (шаг 16) |
| `character_boxes` | Номера боксов, которые следует пометить как персонажей, а не как объекты, как отмечено в предпросмотре Create Bounding Boxes, например "1, 3". Каждое число в строке считывается, поэтому подходит любой разделитель (по умолчанию: пусто). | STRING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `prompt` | Промпт макета: JSON-объект, содержащий подпись, одну запись на каждый бокс и формат координат бокса. Входной текст передаётся без изменений, если элементы не подключены. | STRING |

## Примечания

Прямоугольники боксов поступают из Create Bounding Boxes в виде нормализованных координат в диапазоне от 0 до 1000 и записываются в макет в пикселях относительно центра холста в порядке `yxyx`. Поэтому значения `width` и `height` должны соответствовать изображению, которое вы генерируете, иначе боксы окажутся не на своём месте.

Бокс, содержащий текст, всегда помечается как текст; бокс, номер которого указан в `character_boxes`, помечается как персонаж; а все остальные боксы помечаются как объекты.
