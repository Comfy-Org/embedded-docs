# MOSS-Image Layout Prompt

يبني موجّه التخطيط الذي يقرأه MOSS-Image. يأخذ العناصر المرسومة في عقدة Create Bounding Boxes ويُخرج تخطيطًا بصيغة JSON يتضمن مُدخلًا واحدًا لكل صندوق: تصنيفه، وتسميته التوضيحية، ومستطيله في مساحة البكسل للوحة الهدف. اضبط `width` و`height` على حجم الصورة التي تخطط لتوليدها، ثم صِل الخرج بمدخل الموجّه الخاص بمشفّر النص. عند عدم توصيل أي عناصر، يُعاد نص الموجّه دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `prompt` | وصف الصورة بأكملها. يصبح التسمية التوضيحية للتخطيط. | STRING | نعم | - |
| `element` | العناصر المطلوب وضعها، المأخوذة من عقدة Create Bounding Boxes. يُدرج كل صندوق تسميته التوضيحية؛ كما تُدرج الصناديق النصية نصها، وتحتفظ الصناديق التي تحمل لوحة ألوان بلوحة الألوان. | ARRAY | نعم | - |
| `width` | عرض الصورة المولَّدة بالبكسل. تُحوَّل الصناديق إلى شبكة البكسل هذه، لذا استخدم حجم الصورة التي تخطط لتوليدها (الافتراضي: 1024). | INT | نعم | 16 إلى 16384 (الخطوة 16) |
| `height` | ارتفاع الصورة المولَّدة بالبكسل. تُحوَّل الصناديق إلى شبكة البكسل هذه، لذا استخدم حجم الصورة التي تخطط لتوليدها (الافتراضي: 1024). | INT | نعم | 16 إلى 16384 (الخطوة 16) |
| `character_boxes` | أرقام الصناديق التي يجب وسمها كشخصيات بدلًا من كائنات، كما هي موسومة في معاينة Create Bounding Boxes، مثل "1, 3". يُقرأ كل رقم في السلسلة، لذا يعمل أي فاصل (الافتراضي: فارغ). | STRING | نعم | - |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `prompt` | موجّه التخطيط: كائن JSON يحتوي على التسمية التوضيحية، ومُدخل واحد لكل صندوق، وصيغة إحداثيات الصندوق. يُمرَّر نص الإدخال كما هو عند عدم توصيل أي عناصر. | STRING |

## ملاحظات

تصل مستطيلات الصناديق من Create Bounding Boxes كإحداثيات مُطبّعة بين 0 و1000، وتُكتب في التخطيط بوحدات البكسل نسبةً إلى مركز اللوحة، بترتيب `yxyx`. لذلك يجب أن تطابق قيمتا `width` و`height` الصورةَ التي تولّدها، وإلا فستهبط الصناديق في المكان الخاطئ.

الصندوق الذي يحتوي نصًا يُوسم دائمًا كنص، والصندوق الذي يرد رقمه في `character_boxes` يُوسم كشخصية، وكل صندوق آخر يُوسم ككائن.
