# フレーム補間

フレーム補間ノードは、画像シーケンス内の既存フレーム間に新しいフレームを生成し、実質的にフレームレートを向上させます。AIモデルを使用して中間フレームがどのように見えるべきかを予測し、滑らかなスローモーション効果の作成や、ビデオの滑らかさの向上に使用できます。連続する各フレームペアに対して、ノードは `multiplier - 1` 個の新しいフレームを生成し、それらを元のフレーム間に挿入します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `interp_model` | 中間フレーム生成に使用するフレーム補間モデル（例：RIFE や FILM モデル） | INTERP_MODEL | はい | - |
| `images` | 補間対象となる連続画像（フレーム）のバッチ。少なくとも2枚の画像が必要です。2枚未満の場合、ノードは入力画像をそのまま返します。 | IMAGE | はい | - |
| `multiplier` | フレーム数を乗算する係数。たとえば、multiplier が 2 の場合、フレーム数は2倍になります。（デフォルト：2） | INT | はい | 2 to 16 |

注：入力画像バッチには少なくとも2フレームを含める必要があります。補間は連続するフレームペア間で行われるためです。出力の総フレーム数は `(入力フレーム数 - 1) * multiplier + 1` になります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | 元のフレーム間に補間フレームが挿入された新しい画像バッチ。より滑らかなシーケンスになります。出力フレームの総数は `(入力フレーム数 - 1) * multiplier + 1` です。 | IMAGE |
