# Интерполяция кадров

Узел Frame Interpolate создаёт новые кадры между существующими в последовательности изображений, эффективно увеличивая частоту кадров. Он использует AI-модель для предсказания того, как должны выглядеть промежуточные кадры, что можно применять для создания плавных эффектов замедленного движения или для повышения плавности видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель интерполяции` | Модель интерполяции кадров, используемая для генерации промежуточных кадров | INTERP_MODEL | Да | - |
| `изображения` | Пакет последовательных изображений (кадров), между которыми нужно выполнить интерполяцию. Требуется не менее 2 изображений. Если предоставлено менее 2 кадров, узел возвращает входные изображения без изменений. | IMAGE | Да | - |
| `множитель` | Количество раз, на которое умножается число кадров. Например, множитель 2 удваивает количество кадров. (по умолчанию: 2) | INT | Да | 2 до 16 |

**Примечание:** Узел требует как минимум 2 входных кадра и значение `multiplier` не менее 2. Если любое из условий не выполнено, входные изображения возвращаются без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Новый пакет изображений с интерполированными кадрами, вставленными между исходными кадрами, что обеспечивает более плавную последовательность. Общее количество выходных кадров равно `(number of input frames - 1) * multiplier + 1`. | IMAGE |
