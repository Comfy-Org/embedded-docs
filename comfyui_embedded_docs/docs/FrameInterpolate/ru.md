# Интерполяция кадров

Узел Frame Interpolate создает новые кадры между существующими в последовательности изображений, эффективно увеличивая частоту кадров. Он использует модель ИИ для прогнозирования того, как должны выглядеть промежуточные кадры, что может быть использовано для создания плавных эффектов замедленного движения или для повышения плавности видео. Для каждой последовательной пары кадров узел генерирует `multiplier - 1` новых кадров и вставляет их между оригиналами.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `interp_model` | Модель интерполяции кадров, используемая для генерации промежуточных кадров (например, модели RIFE или FILM) | INTERP_MODEL | Да | - |
| `images` | Пакет последовательных изображений (кадров) для интерполяции. Требуется как минимум 2 изображения; если их меньше, узел возвращает входные изображения без изменений. | IMAGE | Да | - |
| `multiplier` | Коэффициент, на который умножается количество кадров. Например, множитель 2 удваивает число кадров. (по умолчанию: 2) | INT | Да | 2 to 16 |

Примечание: входной пакет изображений должен содержать как минимум 2 кадра, поскольку интерполяция выполняется между последовательными парами кадров. Общее количество кадров на выходе равно `(количество входных кадров - 1) * multiplier + 1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Новый пакет изображений с интерполированными кадрами, вставленными между исходными кадрами, что дает более плавную последовательность. Общее количество выходных кадров равно `(количество входных кадров - 1) * multiplier + 1`. | IMAGE |
