# Интерполяция кадров

Узел Frame Interpolate создает новые кадры между существующими в последовательности изображений, эффективно увеличивая частоту кадров. Он использует модель ИИ для прогнозирования того, как должны выглядеть промежуточные кадры, что можно использовать для создания эффектов плавного замедления или повышения плавности видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель интерполяции` | Модель интерполяции кадров, используемая для генерации промежуточных кадров | INTERP_MODEL | Да | - |
| `изображения` | Пакет последовательных изображений (кадров) для интерполяции между ними. Требуется как минимум 2 изображения. Если предоставлено менее 2 кадров, узел возвращает входные изображения без изменений. | IMAGE | Да | - |
| `множитель` | Количество раз, на которое умножается число кадров. Например, множитель 2 удваивает количество кадров. (по умолчанию: 2) | INT | Да | 2 до 16 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `IMAGE` | Новый пакет изображений с интерполированными кадрами, вставленными между исходными кадрами, что дает более плавную последовательность. Общее количество выходных кадров равно `(количество входных кадров - 1) * multiplier + 1`. | IMAGE |
