# میان‌یابی فریم

گره «درون‌یابی فریم» (Frame Interpolate) فریم‌های جدیدی بین فریم‌های موجود در یک دنباله از تصاویر ایجاد می‌کند و به‌طور مؤثر نرخ فریم را افزایش می‌دهد. این گره از یک مدل هوش مصنوعی برای پیش‌بینی ظاهر فریم‌های میانی استفاده می‌کند که می‌توان از آن برای ایجاد افکت‌های اسلوموشن نرم یا افزایش نرمی ویدیو بهره برد. برای هر جفت فریم متوالی، گره `multiplier - 1` فریم جدید تولید کرده و آن‌ها را بین فریم‌های اصلی درج می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `interp_model` | مدل درون‌یابی فریم که برای تولید فریم‌های میانی استفاده می‌شود (به‌عنوان مثال، مدل‌های RIFE یا FILM) | INTERP_MODEL | بله | - |
| `images` | دسته‌ای از تصاویر متوالی (فریم‌ها) برای درون‌یابی بین آن‌ها. حداقل به ۲ تصویر نیاز دارد؛ اگر تعداد کمتری ارائه شود، گره تصاویر ورودی را بدون تغییر برمی‌گرداند. | IMAGE | بله | - |
| `multiplier` | عاملی که تعداد فریم‌ها در آن ضرب می‌شود. برای مثال، ضریب ۲ تعداد فریم‌ها را دو برابر می‌کند. (پیش‌فرض: ۲) | INT | بله | 2 to 16 |

توجه: دسته تصاویر ورودی باید حداقل شامل ۲ فریم باشد، زیرا درون‌یابی بین جفت‌های متوالی فریم انجام می‌شود. تعداد کل فریم‌های خروجی برابر است با `(number of input frames - 1) * multiplier + 1`.

| `IMAGE` | دسته‌ای جدید از تصاویر که فریم‌های درون‌یابی‌شده بین فریم‌های اصلی درج شده‌اند و در نتیجه دنباله‌ای نرم‌تر ایجاد می‌شود. تعداد کل فریم‌های خروجی برابر است با `(number of input frames - 1) * multiplier + 1`. | IMAGE |
