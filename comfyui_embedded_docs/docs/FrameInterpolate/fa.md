# میان‌یابی فریم

گره Frame Interpolate فریم‌های جدیدی بین فریم‌های موجود در یک دنباله تصاویر ایجاد می‌کند و عملاً نرخ فریم را افزایش می‌دهد. این گره از یک مدل هوش مصنوعی برای پیش‌بینی شکل فریم‌های میانی استفاده می‌کند؛ قابلیتی که می‌تواند برای ساخت افکت‌های اسلوموشن نرم یا افزایش نرمی یک ویدیو به کار رود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `interp_model` | مدل درون‌یابی فریم که برای تولید فریم‌های میانی استفاده می‌شود | INTERP_MODEL | بله | - |
| `تصاویر` | دسته‌ای از تصاویر متوالی (فریم‌ها) برای درون‌یابی بین آن‌ها. حداقل به ۲ تصویر نیاز دارد. اگر کمتر از ۲ فریم ارائه شود، گره تصاویر ورودی را بدون تغییر برمی‌گرداند. | IMAGE | بله | - |
| `ضریب` | تعداد دفعات ضرب شدن تعداد فریم‌ها. برای مثال، ضریب ۲ تعداد فریم‌ها را دو برابر می‌کند. (پیش‌فرض: 2) | INT | بله | 2 تا 16 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `IMAGE` | دسته‌ای جدید از تصاویر که فریم‌های درون‌یابی‌شده بین فریم‌های اصلی درج شده‌اند و در نتیجه دنباله‌ای نرم‌تر ایجاد می‌شود. تعداد کل فریم‌های خروجی برابر با `(number of input frames - 1) * multiplier + 1` است. | IMAGE |
