# 帧插值

帧插值节点在图像序列中的现有帧之间创建新帧，从而有效提高帧率。它使用 AI 模型预测中间帧应该是什么样的，可用于创建平滑的慢动作效果或提高视频的流畅度。对于每一对连续帧，该节点会生成 `multiplier - 1` 个新帧，并将其插入到原始帧之间。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `interp_model` | 用于生成中间帧的帧插值模型（例如 RIFE 或 FILM 模型） | INTERP_MODEL | 是 | - |
| `images` | 一批需要插值的连续图像（帧）。至少需要 2 张图像；如果提供的图像少于 2 张，节点将原样返回输入图像。 | IMAGE | 是 | - |
| `multiplier` | 帧数倍增的倍数。例如，倍数为 2 时，帧数将翻倍。（默认值：2） | INT | 是 | 2 到 16 |

注意：输入图像批次必须至少包含 2 帧，因为插值是在连续帧对之间进行的。输出中的总帧数为 `(输入帧数 - 1) * multiplier + 1`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `IMAGE` | 一个新的图像批次，其中插值帧已插入原始帧之间，从而得到更平滑的序列。输出总帧数为 `(输入帧数 - 1) * multiplier + 1`。 | IMAGE |
