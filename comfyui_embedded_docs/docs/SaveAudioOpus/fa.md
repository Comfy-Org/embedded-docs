# ذخیره صدا (Opus)

گره SaveAudioOpus داده‌های صوتی را در قالب Opus در یک فایل ذخیره می‌کند و به شما امکان می‌دهد کیفیت رمزگذاری (نرخ بیت) و پیشوند نام فایل را برای فایل خروجی انتخاب کنید. این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده صوتی که باید به‌صورت فایل Opus ذخیره شود. اگر این مقدار None باشد، خطای ValueError رخ می‌دهد (برای مثال، زمانی که ویدئوی منبع فاقد ترک صوتی است). | AUDIO | بله | - |
| `filename_prefix` | پیشوندی که برای نام فایل خروجی استفاده می‌شود (پیش‌فرض: "audio/ComfyUI"). | STRING | خیر | - |
| `quality` | نرخ بیت مورد استفاده برای رمزگذاری فایل Opus؛ مقادیر بالاتر کیفیت بهتر اما فایل‌های بزرگ‌تر تولید می‌کنند (پیش‌فرض: "128k"). | COMBO | خیر | `"64k"`<br>`"96k"`<br>`"128k"`<br>`"192k"`<br>`"320k"` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | داده صوتی که در فایل Opus ذخیره شد. | AUDIO |
