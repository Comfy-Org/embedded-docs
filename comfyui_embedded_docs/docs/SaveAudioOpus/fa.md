# ذخیره صدا (Opus)

گره SaveAudioOpus داده‌های صوتی را در قالب Opus در یک فایل ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و آن را با تنظیمات کیفیت قابل‌پیکربندی به‌صورت یک فایل Opus فشرده‌شده خروجی می‌دهد. این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده صوتی که به‌عنوان فایل Opus ذخیره می‌شود. اگر این مقدار None باشد (مثلاً وقتی ویدیوی منبع هیچ تراک صوتی نداشته باشد)، یک ValueError برانگیخته می‌شود. | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |
| `quality` | نرخ بیت مورد استفاده برای رمزگذاری فایل Opus؛ مقادیر بالاتر کیفیت بهتری تولید می‌کنند اما فایل بزرگ‌تری ایجاد می‌کنند (پیش‌فرض: "128k") | COMBO | خیر | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `صدا` | داده صوتی که در فایل Opus ذخیره شده است | AUDIO |
