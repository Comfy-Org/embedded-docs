# ذخیره صدا (Opus)

گره SaveAudioOpus داده‌های صوتی را در قالب فایل Opus ذخیره می‌کند. این گره یک ورودی صوتی دریافت کرده و آن را به‌عنوان یک فایل Opus فشرده با تنظیمات کیفیت قابل‌تنظیم صادر می‌کند. این گره منسوخ شده است و ممکن است در نسخه‌های آینده حذف شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `audio` | داده‌های صوتی که باید به‌صورت فایل Opus ذخیره شوند. اگر هیچ داده صوتی ارائه نشود (مثلاً وقتی ویدیوی منبع فاقد ترک صوتی باشد)، گره خطا صادر می‌کند. | AUDIO | بله | - |
| `filename_prefix` | پیشوند نام فایل خروجی (پیش‌فرض: "audio/ComfyUI") | STRING | خیر | - |
| `quality` | تنظیم کیفیت (نرخ بیت) برای فایل Opus (پیش‌فرض: "128k") | COMBO | خیر | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | داده‌های صوتی ورودی که پس از ذخیره فایل Opus روی دیسک بازگردانده می‌شوند. | AUDIO |
