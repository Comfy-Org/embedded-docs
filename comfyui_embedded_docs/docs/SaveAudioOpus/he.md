# שמור אודיו (Opus) (מיושן)

הצומת SaveAudioOpus שומר נתוני אודיו לקובץ בפורמט Opus, ומאפשר לך לבחור את איכות הקידוד (קצב סיביות) ואת קידומת שם הקובץ עבור הקובץ המיוצא. צומת זה מיושן ועשוי להיות מוסר בגרסאות עתידיות.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `audio` | נתוני האודיו שיש לשמור כקובץ Opus. נזרק ValueError אם הערך הוא None (לדוגמה, כאשר לסרטון המקור אין רצועת אודיו). | AUDIO | כן | - |
| `filename_prefix` | הקידומת המשמשת עבור שם קובץ הפלט (ברירת מחדל: "audio/ComfyUI"). | STRING | לא | - |
| `quality` | קצב הסיביות המשמש לקידוד קובץ Opus; ערכים גבוהים יותר מפיקים איכות טובה יותר אך קבצים גדולים יותר (ברירת מחדל: "128k"). | COMBO | לא | `"64k"`<br>`"96k"`<br>`"128k"`<br>`"192k"`<br>`"320k"` |
