# Сохранить аудио (Opus)

Узел SaveAudioOpus сохраняет аудиоданные в файл формата Opus, позволяя выбрать качество кодирования (битрейт) и префикс имени файла для экспортируемого файла. Этот узел устарел и может быть удалён в будущих версиях.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудиоданные, которые нужно сохранить в файл Opus. Если значение равно None (например, когда в исходном видео нет звуковой дорожки), возникает ValueError. | AUDIO | Да | - |
| `префикс_имени_файла` | Префикс, используемый для имени выходного файла (по умолчанию: "audio/ComfyUI"). | STRING | Нет | - |
| `качество` | Битрейт, используемый для кодирования файла Opus; более высокие значения обеспечивают лучшее качество, но увеличивают размер файлов (по умолчанию: "128k"). | COMBO | Нет | `"64k"`<br>`"96k"`<br>`"128k"`<br>`"192k"`<br>`"320k"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Аудиоданные, которые были сохранены в файл Opus. | AUDIO |
