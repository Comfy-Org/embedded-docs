# Сохранить аудио (Opus)

Узел SaveAudioOpus сохраняет аудиоданные в файл в формате Opus. Он принимает аудиовход и экспортирует его в сжатый Opus-файл с настраиваемыми параметрами качества. Этот узел устарел и может быть удален в будущих версиях.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|-------------|-------------|----------------|----------|
| `audio` | Аудиоданные для сохранения в файл Opus. Вызывается исключение ValueError, если значение равно None (например, когда исходное видео не имеет аудиодорожки). | AUDIO | Да | - |
| `префикс_имени_файла` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |
| `качество` | Битрейт, используемый для кодирования Opus-файла; более высокие значения обеспечивают лучшее качество, но увеличивают размер файла (по умолчанию: "128k") | COMBO | Нет | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-------------|
| `аудио` | Аудиоданные, сохраненные в Opus-файл | AUDIO |
