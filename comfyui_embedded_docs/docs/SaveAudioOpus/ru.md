# Сохранить аудио (Opus)

Узел SaveAudioOpus сохраняет аудиоданные в файл формата Opus. Он принимает аудиовход и экспортирует его в сжатый файл Opus с настраиваемыми параметрами качества. Этот узел устарел и может быть удален в будущих версиях.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудиоданные, сохраняемые в файл Opus. Узел вызывает ошибку, если аудио не предоставлено (например, когда исходное видео не имеет аудиодорожки). | AUDIO | Да | - |
| `filename_prefix` | Префикс для имени выходного файла (по умолчанию: "audio/ComfyUI") | STRING | Нет | - |
| `quality` | Настройка качества (битрейта) аудио для файла Opus (по умолчанию: "128k") | COMBO | Нет | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Входные аудиоданные, возвращаемые после сохранения файла Opus на диск. | AUDIO |
