# حفظ الصوت (Opus)

تقوم عقدة SaveAudioOpus بحفظ البيانات الصوتية في ملف بصيغة Opus. تأخذ مدخلًا صوتيًا وتُصدّره كملف Opus مضغوط مع إعدادات جودة قابلة للتخصيص. هذه العقدة مُهمَلة وقد تتم إزالتها في الإصدارات المستقبلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صوت` | البيانات الصوتية التي سيتم حفظها كملف Opus. يتم رفع ValueError إذا كانت هذه القيمة None (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي). | AUDIO | نعم | - |
| `بادئة اسم الملف` | البادئة المستخدمة لاسم ملف الإخراج (الافتراضي: "audio/ComfyUI") | STRING | لا | - |
| `الجودة` | معدل البت المستخدم لتشفير ملف Opus؛ القيم الأعلى تُنتج جودة أفضل ولكن ملفات أكبر (الافتراضي: "128k") | COMBO | لا | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `الصوت` | البيانات الصوتية التي تم حفظها في ملف Opus | AUDIO |
