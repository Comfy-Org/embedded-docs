# حفظ الصوت (Opus)

تحفظ عقدة SaveAudioOpus بيانات الصوت في ملف بصيغة Opus، مما يتيح لك اختيار جودة الترميز (معدل البت) وبادئة اسم الملف للملف المُصدَّر. هذه العقدة مهملة وقد تُزال في الإصدارات المستقبلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صوت` | بيانات الصوت المراد حفظها في ملف Opus. يُرفع ValueError إذا كانت هذه القيمة None (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي). | AUDIO | نعم | - |
| `بادئة اسم الملف` | البادئة المستخدمة لاسم ملف الإخراج (الافتراضي: "audio/ComfyUI"). | STRING | لا | - |
| `الجودة` | معدل البت المستخدم لترميز ملف Opus؛ القيم الأعلى تنتج جودة أفضل ولكن ملفات أكبر (الافتراضي: "128k"). | COMBO | لا | `"64k"`<br>`"96k"`<br>`"128k"`<br>`"192k"`<br>`"320k"` |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `audio` | بيانات الصوت التي حُفظت في ملف Opus. | AUDIO |
