# حفظ الصوت (Opus)

تقوم عقدة SaveAudioOpus بحفظ البيانات الصوتية في ملف بصيغة Opus. تأخذ مدخلًا صوتيًا وتصدّره كملف Opus مضغوط مع إعدادات جودة قابلة للتكوين. هذه العقدة مهملة وقد تتم إزالتها في الإصدارات المستقبلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `audio` | البيانات الصوتية التي سيتم حفظها كملف Opus. ترفع العقدة خطأً إذا لم يتم توفير صوت (على سبيل المثال، عندما لا يحتوي الفيديو المصدر على مسار صوتي). | AUDIO | نعم | - |
| `filename_prefix` | البادئة لاسم ملف الإخراج (الافتراضي: "audio/ComfyUI") | STRING | لا | - |
| `quality` | إعداد جودة الصوت (معدل البت) لملف Opus (الافتراضي: "128k") | COMBO | لا | "64k"<br>"96k"<br>"128k"<br>"192k"<br>"320k" |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `audio` | البيانات الصوتية المُدخلة، تُعاد بعد حفظ ملف Opus على القرص. | AUDIO |
