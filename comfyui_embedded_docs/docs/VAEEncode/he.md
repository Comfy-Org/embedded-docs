# VaeEncode

צומת זה מיועד לקידוד תמונות לייצוג במרחב לטנטי באמצעות מודל VAE מוגדר. הוא מפשט את מורכבות תהליך הקידוד, ומספק דרך ישירה להמיר תמונות לייצוגים הלטנטיים שלהן.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `pixels` | הפרמטר 'pixels' מייצג את נתוני התמונה שיש לקודד למרחב הלטנטי. הוא ממלא תפקיד מכריע בקביעת ייצוג הפלט הלטנטי בכך שהוא משמש כקלט הישיר לתהליך הקידוד. | `IMAGE` |
| `vae` | הפרמטר 'vae' מגדיר את מודל המקודד האוטומטי הווריאציוני (VAE) שישמש לקידוד נתוני התמונה למרחב לטנטי. הוא חיוני להגדרת מנגנון הקידוד והמאפיינים של הייצוג הלטנטי שנוצר. | VAE |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `latent` | הפלט הוא ייצוג במרחב לטנטי של תמונת הקלט, אשר אוגד את המאפיינים החיוניים שלה בצורה דחוסה. | `LATENT` |
