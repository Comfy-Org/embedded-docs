# RemeshMesh

Remesh Mesh 通过围绕原始表面采样窄带距离场，并使用双重轮廓法（Dual Contouring）提取表面，以干净、均匀的镶嵌面重建网格。这可以规范化混乱、非流形或自相交的拓扑，并且应在 Decimate Mesh 之前运行，以便达到精确的面数。处理过程在当前计算设备上运行，输出网格保持焊接状态。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要重新网格化的输入网格。 | MESH | 是 | — |
| `resolution` | 体素网格分辨率（输出密度）。256 约对应 100k 面，512 约对应 1M 面。若需精确面数，请在其后使用 Decimate Mesh。（默认值：512） | INT | 是 | 32 - 2048 |
| `sign_mode` | 用于表面提取的有符号距离模式。"udf" 对杂乱/非流形输入具有鲁棒性；"sdf" 可通过 QEF（二次误差函数）恢复锐利特征，生成干净的单表面，但要求输入具有一致的绕向。选择模式后，将显示该模式的特定子选项。（默认值："udf"） | DYNAMIC_COMBO | 是 | "udf"<br>"sdf" |
| `band` | 窄带宽度（以体素为单位）。在 UDF 模式下还会偏移表面。（高级，默认值：1.0） | FLOAT | 是 | 0.5 - 4.0 |
| `project_back` | 将顶点线性插值回原始表面（0 = 纯双重轮廓，1 = 完全吸附）。（高级，默认值：0.0） | FLOAT | 是 | 0.0 - 1.0 |
| `fix_poles` | 折叠价为 3 的顶点对（消除 DC 的 T 型连接伪影）。（高级，默认值：false） | BOOLEAN | 是 | true / false |
| `smooth_iters` | Taubin 平滑迭代次数（0 = 关闭）。2-3 次可消除 DC 的阶梯状伪影；更高值会过度平滑 QEF 边缘。（默认值：0） | INT | 是 | 0 - 20 |
| `drop_small_components` | 删除面数低于最大组件面数此比例的组件。0 表示禁用。（高级，默认值：0.01） | FLOAT | 是 | 0.0 - 0.5 |
| `precluster_max_verts` | 在进行场查询前限制输入顶点数；超过该值的输入会先被聚类简化至该值。可防止超大网格造成内存不足（OOM）。（高级，默认值：20,000,000） | INT | 是 | 0 - 100,000,000 |

### "udf" 模式输入

当 `sign_mode` 设置为 `"udf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 使用 QEF（二次误差函数）进行双顶点放置，以获得更锐利的边缘。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_inverted_components` | 删除内法向（负体积）闭合组件——即 UDF 的内壳层。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_enclosed_components` | 删除位于最大组件包围盒内且未通过点对网格射线投射测试的组件。若存在合理嵌套部件，请禁用。（默认值：false） | BOOLEAN | 否 | true / false |

### "sdf" 模式输入

当 `sign_mode` 设置为 `"sdf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 选择 QEF（二次误差函数）双顶点放置（可恢复锐利特征）或跨边质心放置。（默认值：true） | BOOLEAN | 否 | true / false |
| `manifold` | 流形双重轮廓法：对多薄片（multi-sheet）情况，每个体素使用 1-4 个双顶点。速度较慢。（默认值：false） | BOOLEAN | 否 | true / false |

注意：`qef` 选项的默认值取决于所选模式——在 "udf" 模式下为 false，在 "sdf" 模式下为 true。当 `precluster_max_verts` 大于 0 且输入网格的顶点数超过该值时，会在场查询前将网格聚类简化至该目标值。处理完成后，节点会在节点上显示输入到输出的面数变化（例如：`faces: 1.23M → 200K (-84%)`）。
