# مش‌بندی مجدد مش (DC باند باریک)

Remesh Mesh یک مش را با نمونه‌برداری از یک میدان فاصله باریک‌باند حول سطح اصلی و استخراج آن با Dual Contouring، با تسلاسیون تمیز و یکنواخت بازسازی می‌کند. این کار توپولوژی به‌هم‌ریخته، غیرمنیفولد یا خودمتقاطع را نرمال می‌کند و برای اجرا پیش از Decimate Mesh به‌منظور رسیدن به تعداد وجه دقیق در نظر گرفته شده است. پردازش روی دستگاه محاسباتی فعال اجرا می‌شود و مش خروجی جوش‌خورده باقی می‌ماند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش ورودی برای بازمش‌سازی. | MESH | بله | — |
| `تفکیک‌پذیری` | وضوح شبکه وکسل (چگالی خروجی). ۲۵۶ ≈ ۱۰۰ هزار وجه، ۵۱۲ ≈ ۱ میلیون وجه. برای تعداد وجه دقیق، پس از آن از Decimate Mesh استفاده کنید. (پیش‌فرض: 512) | INT | بله | 32 - 2048 |
| `sign_mode` | حالت استخراج سطح. «udf» در برابر ورودی به‌هم‌ریخته/غیرمنیفولد مقاوم است؛ «sdf» یک سطح تمیز و یکپارچه با بازیابی لبه‌های تیز QEF (تابع خطای درجه دوم) تولید می‌کند، اما به جهت‌گیری (winding) سازگار نیاز دارد. انتخاب یک حالت، زیرگزینه‌های اختصاصی آن را نشان می‌دهد. (پیش‌فرض: "udf") | DYNAMIC_COMBO | بله | "udf"<br>"sdf" |
| `باند` | عرض باند باریک بر حسب واحد وکسل. در حالت UDF سطح را نیز آفست می‌کند. (پیشرفته، پیش‌فرض: 1.0) | FLOAT | بله | 0.5 - 4.0 |
| `project_back` | رئوس را به‌صورت خطی به سمت سطح اصلی درون‌یابی می‌کند (۰ = DC خالص، ۱ = اسنپ‌شده). (پیشرفته، پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `fix_poles` | جفت‌رئوس‌های با ظرفیت ۳ (آرتیفکت T-junction در DC) را ادغام/فروپاش می‌کند. (پیشرفته، پیش‌فرض: false) | BOOLEAN | بله | true / false |
| `smooth_iters` | تعداد تکرارهای هموارسازی Taubin (۰ = خاموش). ۲-۳ آرتیفکت‌های پله‌ای DC را تمیز می‌کند؛ مقادیر بالاتر لبه‌های QEF را بیش‌ازحد هموار می‌کنند. (پیش‌فرض: 0) | INT | بله | 0 - 20 |
| `drop_small_components` | اجزایی را که کوچک‌تر از این کسر از تعداد وجه بزرگ‌ترین جزء هستند حذف می‌کند. ۰ غیرفعال می‌کند. (پیشرفته، پیش‌فرض: 0.01) | FLOAT | بله | 0.0 - 0.5 |
| `precluster_max_verts` | حداکثر تعداد رئوس ورودی را قبل از کوئری‌های میدان محدود می‌کند؛ ورودی‌های بیشتر از این مقدار ابتدا با کاهش خوشه‌ای به آن هدف کاهش می‌یابند. از OOM در مش‌های عظیم جلوگیری می‌کند. (پیشرفته، پیش‌فرض: 20,000,000) | INT | بله | 0 - 100,000,000 |

### ورودی‌های حالت «udf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"udf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه QEF (تابع خطای درجه دوم) برای لبه‌های تیزتر. (پیشرفته، پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_inverted_components` | اجزای بسته با نرمال رو به داخل (حجم منفی) را حذف می‌کند — پوسته داخلی UDF. (پیشرفته، پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_enclosed_components` | اجزایی را که داخل bbox بزرگ‌ترین جزء هستند و در ریکست نقطه-در-مش رد می‌شوند حذف می‌کند. برای قطعات تودرتوی معتبر غیرفعال کنید. (پیشرفته، پیش‌فرض: false) | BOOLEAN | خیر | true / false |

### ورودی‌های حالت «sdf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"sdf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه QEF (تابع خطای درجه دوم) (بازیابی لبه‌های تیز) در مقابل مرکزوار تقاطع لبه. (پیش‌فرض: true) | BOOLEAN | خیر | true / false |
| `manifold` | Dual Contouring منیفولد: ۱ تا ۴ رأس دوگانه در هر وکسل برای موارد چند-ورقی. کندتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

نکته: گزینه `qef` بسته به حالت انتخاب‌شده پیش‌فرض متفاوتی دارد — در حالت «udf» برابر false و در حالت «sdf» برابر true است. وقتی `precluster_max_verts` بزرگ‌تر از ۰ باشد و مش ورودی رئوس بیشتری از این مقدار داشته باشد، مش قبل از کوئری‌های میدان با کاهش خوشه‌ای تا آن هدف کاهش می‌یابد. پس از پردازش، گره تغییر تعداد وجه ورودی به خروجی را روی خود نمایش می‌دهد (برای مثال، "faces: 1.23M → 200K (-84%)").
