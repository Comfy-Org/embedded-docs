# RemeshMesh

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش ورودی برای بازسازی. | MESH | بله | — |
| `resolution` | تفکیک‌پذیری شبکه وکسل (تراکم خروجی). 256 ~ ۱۰۰ هزار وجه، 512 ~ ۱ میلیون وجه. برای تعداد وجه دقیق، پس از آن از گره Decimate Mesh استفاده کنید. (پیش‌فرض: 512) | INT | بله | 32 - 2048 |
| `sign_mode` | حالت فاصله علامت‌دار مورد استفاده برای استخراج سطح. حالت «udf» در برابر ورودی‌های نامرتب/غیر-منیفلد مقاوم است؛ حالت «sdf» یک سطح تمیز و تک‌لایه با بازیابی ویژگی‌های تیز به‌وسیله QEF (تابع خطای درجه دوم) تولید می‌کند، اما به پیچش (winding) سازگار نیاز دارد. انتخاب هر حالت، زیرگزینه‌های مخصوص به آن را نمایش می‌دهد. (پیش‌فرض: «udf») | DYNAMIC_COMBO | بله | «udf»<br>«sdf» |
| `band` | عرض نوار باریک بر حسب واحد وکسل. در حالت UDF، سطح را نیز جابه‌جا می‌کند. (پیشرفته، پیش‌فرض: 1.0) | FLOAT | بله | 0.5 - 4.0 |
| `project_back` | رئوس را به‌صورت خطی به سمت سطح اصلی درون‌یابی می‌کند (0 = صرفاً DC، 1 = چسبیده به سطح). (پیشرفته، پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `fix_poles` | جفت‌های رأس با ظرفیت ۳ (valence-3) را جمع می‌کند (اثر اتصال T (T-junction) در DC). (پیشرفته، پیش‌فرض: false) | BOOLEAN | بله | true / false |
| `smooth_iters` | تکرارهای هموارسازی تائوبین (0 = غیرفعال). 2-3 تکرار، آثار پلکانی DC را پاک می‌کند؛ مقادیر بالاتر لبه‌های QEF را بیش از حد هموار می‌کنند. (پیش‌فرض: 0) | INT | بله | 0 - 20 |
| `drop_small_components` | اجزایی را که کمتر از این کسر از تعداد وجه بزرگ‌ترین جزء هستند، حذف می‌کند. مقدار 0 غیرفعال می‌کند. (پیشرفته، پیش‌فرض: 0.01) | FLOAT | بله | 0.0 - 0.5 |
| `precluster_max_verts` | تعداد رئوس ورودی را قبل از پرس‌وجوهای میدان محدود می‌کند؛ ورودی‌های بالاتر از این مقدار ابتدا با روش کاهش خوشه‌ای (cluster-decimation) به همین مقدار کاهش می‌یابند. از اتمام حافظه (OOM) در مش‌های بزرگ جلوگیری می‌کند. (پیشرفته، پیش‌فرض: 20,000,000) | INT | بله | 0 - 100,000,000 |

### ورودی‌های حالت «udf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"udf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه با QEF (تابع خطای درجه دوم) برای لبه‌های تیزتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_inverted_components` | اجزای بسته با نرمال رو به داخل (حجم منفی) — پوسته داخلی UDF — را حذف می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_enclosed_components` | اجزای داخل جعبه محیطی (bbox) بزرگ‌ترین جزء را که در رای‌کست نقطه-در-مش (point-in-mesh raycast) مردود می‌شوند، حذف می‌کند. برای قطعات تو در تو معتبر، غیرفعال کنید. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

### ورودی‌های حالت «sdf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"sdf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه با QEF (تابع خطای درجه دوم) (ویژگی‌های تیز را بازیابی می‌کند) در مقابل مرکز تلاقی لبه (edge-crossing centroid). (پیش‌فرض: true) | BOOLEAN | خیر | true / false |
| `manifold` | کانتورینگ دوگانه منیفلد (Manifold Dual Contouring): 1 تا 4 رأس دوگانه در هر وکسل برای موارد چند-لایه. کندتر است. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

توجه: گزینه `qef` بسته به حالت انتخاب‌شده پیش‌فرض متفاوتی دارد — در حالت «udf» مقدار false و در حالت «sdf» مقدار true. هنگامی که `precluster_max_verts` بزرگ‌تر از 0 باشد و مش ورودی تعداد رئوس بیشتری از این مقدار داشته باشد، پیش از پرس‌وجوهای میدان، مش با روش کاهش خوشه‌ای به همان هدف کاهش می‌یابد. پس از پردازش، گره تغییر تعداد وجه ورودی به خروجی را روی خود نمایش می‌دهد (مثلاً: «faces: 1.23M → 200K (-84%)»).
