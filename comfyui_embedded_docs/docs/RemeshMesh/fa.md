# RemeshMesh

Remesh Mesh با نمونه‌برداری از یک میدان فاصله‌ی نوار باریک در اطراف سطح اصلی و استخراج آن با Dual Contouring، مشی با تسلیشن تمیز و یکنواخت بازسازی می‌کند. این کار توپولوژی به‌هم‌ریخته، غیر-منیفلد یا خود-متقاطع را نرمال‌سازی می‌کند و برای رسیدن به تعداد وجه دقیق باید پیش از Decimate Mesh اجرا شود. پردازش روی دستگاه محاسباتی فعال انجام می‌شود و مش خروجی یکپارچه (welded) باقی می‌ماند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش ورودی برای بازسازی. | MESH | بله | — |
| `resolution` | وضوح شبکه وکسل (چگالی خروجی). 256 ~ 100 هزار وجه، 512 ~ 1 میلیون. برای تعداد وجه دقیق، سپس Decimate Mesh را اجرا کنید. (پیش‌فرض: 512) | INT | بله | 32 - 2048 |
| `sign_mode` | حالت فاصله‌ی علامت‌دار برای استخراج سطح. «udf» در برابر ورودی‌های به‌هم‌ریخته/غیر-منیفلد مقاوم است؛ «sdf» سطح تک‌لایه‌ی تمیزی با بازیابی لبه‌های تیز QEF (تابع خطای درجه دوم) تولید می‌کند، اما به جهت‌گیری سازگار (winding) نیاز دارد. انتخاب هر حالت، زیرگزینه‌های مخصوص به آن را نمایش می‌دهد. (پیش‌فرض: «udf») | DYNAMIC_COMBO | بله | "udf"<br>"sdf" |
| `band` | پهنای نوار باریک بر حسب واحد وکسل. در حالت UDF سطح را نیز جابه‌جا می‌کند. (پیشرفته، پیش‌فرض: 1.0) | FLOAT | بله | 0.5 - 4.0 |
| `project_back` | رأس‌ها را به‌طور خطی به سمت سطح اصلی درونیابی می‌کند (0 = Dual Contouring خالص، 1 = چسبیده به سطح). (پیشرفته، پیش‌فرض: 0.0) | FLOAT | بله | 0.0 - 1.0 |
| `fix_poles` | جفت رأس‌های با والانس ۳ را ادغام می‌کند (نابهنجاری T-junction در Dual Contouring). (پیشرفته، پیش‌فرض: false) | BOOLEAN | بله | true / false |
| `smooth_iters` | تکرارهای هموارسازی Taubin (0 = غیرفعال). ۲ تا ۳ اثر پلکانی Dual Contouring را پاک می‌کند؛ مقادیر بالاتر لبه‌های QEF را بیش‌ازحد هموار می‌کنند. (پیش‌فرض: 0) | INT | بله | 0 - 20 |
| `drop_small_components` | مؤلفه‌هایی را که تعداد وجه‌شان کمتر از این کسر از تعداد وجه بزرگ‌ترین مؤلفه است حذف می‌کند. 0 آن را غیرفعال می‌کند. (پیشرفته، پیش‌فرض: 0.01) | FLOAT | بله | 0.0 - 0.5 |
| `precluster_max_verts` | سقف تعداد رأس ورودی را پیش از پرس‌وجوهای میدان تعیین می‌کند؛ ورودی‌های بالاتر از این مقدار ابتدا با خوشه‌بندی تا همان حد کاهش می‌یابند. از کمبود حافظه (OOM) در مش‌های بزرگ جلوگیری می‌کند. (پیشرفته، پیش‌فرض: 20,000,000) | INT | بله | 0 - 100,000,000 |

### ورودی‌های حالت «udf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی «udf» تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | جانمایی رأس دوگانه با QEF (تابع خطای درجه دوم) برای لبه‌های تیزتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_inverted_components` | مؤلفه‌های بسته با نرمال رو به داخل (حجم منفی) — پوسته داخلی UDF — را حذف می‌کند. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_enclosed_components` | مؤلفه‌هایی را که داخل bbox بزرگ‌ترین مؤلفه قرار دارند و در raycast نقطه‌-در-مش ناموفق‌اند حذف می‌کند. برای قطعات درونی قانونی، آن را غیرفعال کنید. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

### ورودی‌های حالت «sdf»

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی «sdf» تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | جانمایی رأس دوگانه با QEF (بازیابی لبه‌های تیز) در مقابل مرکز ثقل حاصل از برخورد با یال‌ها. (پیش‌فرض: true) | BOOLEAN | خیر | true / false |
| `manifold` | Dual Contouring منیفلد: ۱ تا ۴ رأس دوگانه در هر وکسل برای حالت‌های چندلایه. کندتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

نکته: گزینه‌ی `qef` بسته به حالت انتخابی، پیش‌فرض متفاوتی دارد — در حالت «udf» مقدار false و در حالت «sdf» مقدار true. وقتی `precluster_max_verts` بزرگ‌تر از 0 باشد و مش ورودی تعداد رأس‌های بیشتری از این مقدار داشته باشد، پیش از پرس‌وجوهای میدان، مش با خوشه‌بندی تا همان هدف کاهش می‌یابد. پس از پردازش، گره تغییر تعداد وجه ورودی به خروجی را روی خود نمایش می‌دهد (مثلاً «faces: 1.23M → 200K (-84%)»).
