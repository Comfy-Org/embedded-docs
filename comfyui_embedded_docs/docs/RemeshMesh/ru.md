# RemeshMesh

Remesh Mesh восстанавливает сетку с чистой равномерной тесселяцией путем выборки узкополосного поля расстояний вокруг исходной поверхности и извлечения его с помощью Dual Contouring (двойного контуринга). Это нормализует неупорядоченную, non-manifold или самопересекающуюся топологию и должно выполняться перед Decimate Mesh для достижения точного количества граней. Обработка выполняется на активном вычислительном устройстве, и выходная сетка остается сваренной (welded).

## Входы

### Общие входы

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Входная сетка для ремешинга. | MESH | Да | — |
| `разрешение` | Разрешение воксельной сетки (плотность выходных данных). 256 ~ 100 тысяч граней, 512 ~ 1 млн. Для точного количества граней используйте последующий Decimate Mesh. (по умолчанию: 512) | INT | Да | 32 - 2048 |
| `sign_mode` | Режим знакового расстояния, используемый для извлечения поверхности. «udf» устойчив к неупорядоченным/non-manifold входным данным; «sdf» создает чистую единую поверхность с восстановлением острых особенностей с помощью QEF (Quadratic Error Function), но требует согласованной ориентации граней. Выбор режима отображает его конкретные подпараметры. (по умолчанию: «udf») | DYNAMIC_COMBO | Да | "udf"<br>"sdf" |
| `полоса` | Ширина узкой полосы в воксельных единицах. В режиме UDF также смещает поверхность. (дополнительно, по умолчанию: 1.0) | FLOAT | Да | 0.5 - 4.0 |
| `project_back` | Линейная интерполяция вершин к исходной поверхности (0 = чистый DC, 1 = привязка). (дополнительно, по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `fix_poles` | Схлопывание пар вершин с валентностью 3 (артефакт T-образного стыка в DC). (дополнительно, по умолчанию: false) | BOOLEAN | Да | true / false |
| `smooth_iters` | Количество итераций сглаживания Таубина (0 = выключено). 2–3 устраняют ступенчатые артефакты DC; большее значение чрезмерно сглаживает ребра QEF. (по умолчанию: 0) | INT | Да | 0 - 20 |
| `drop_small_components` | Удаляет компоненты ниже этой доли от количества граней самого большого компонента. 0 отключает. (дополнительно, по умолчанию: 0.01) | FLOAT | Да | 0.0 - 0.5 |
| `precluster_max_verts` | Ограничение количества входных вершин перед запросами поля; входные данные выше этого значения сначала подвергаются кластерной децимации до этого предела. Предотвращает нехватку памяти (OOM) на огромных сетках. (дополнительно, по умолчанию: 20,000,000) | INT | Да | 0 - 100,000,000 |

### Входы режима "udf"

Эти параметры появляются, когда для `sign_mode` установлено значение `"udf"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойных вершин с помощью QEF (Quadratic Error Function) для более четких ребер. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_inverted_components` | Удаляет замкнутые компоненты с нормалью внутрь (отрицательным объемом) — внутреннюю оболочку UDF. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_enclosed_components` | Удаляет компоненты внутри ограничивающей рамки самого большого компонента, которые не проходят трассировку луча на попадание в сетку. Отключите для допустимых вложенных частей. (по умолчанию: false) | BOOLEAN | Нет | true / false |

### Входы режима "sdf"

Эти параметры появляются, когда для `sign_mode` установлено значение `"sdf"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойных вершин с помощью QEF (Quadratic Error Function) (восстанавливает острые особенности) вместо центроида пересечения ребра. (по умолчанию: true) | BOOLEAN | Нет | true / false |
| `manifold` | Многообразие Dual Contouring: 1–4 двойных вершин на воксель для случаев с несколькими листами. Медленнее. (по умолчанию: false) | BOOLEAN | Нет | true / false |

Примечание: параметр `qef` имеет разное значение по умолчанию в зависимости от выбранного режима — false в режиме "udf", true в режиме "sdf". Когда `precluster_max_verts` больше 0 и входная сетка содержит больше вершин, чем это значение, сетка подвергается кластерной децимации до этого целевого значения перед запросами поля. После обработки узел отображает изменение количества граней от входа к выходу на самом узле (например, "faces: 1.23M → 200K (-84%)").

## Выходы

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `mesh` | Перестроенная сетка с равномерной тесселяцией и сваренной топологией. Цвета вершин сохраняются, если они присутствуют на входе; любые UV, нормали и касательные не переносятся. | MESH |
