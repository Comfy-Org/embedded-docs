# Ремешинг сетки (узкополосный DC)

Remesh Mesh перестраивает сетку с чистой, однородной тесселяцией, сэмплируя узкополосное поле расстояний вокруг исходной поверхности и извлекая её с помощью Dual Contouring. Это нормализует запутанную, не-многообразную (non-manifold) или самопересекающуюся топологию, и его следует запускать перед Decimate Mesh, чтобы достичь точного количества граней. Обработка выполняется на активном вычислительном устройстве, а выходная сетка остаётся сваренной.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Входная сетка для перестроения. | MESH | Да | — |
| `разрешение` | Разрешение воксельной сетки (плотность выходной модели). 256 ~ 100 тыс. граней, 512 ~ 1 млн. Для точного количества граней далее используйте Decimate Mesh. (по умолчанию: 512) | INT | Да | 32 - 2048 |
| `sign_mode` | Режим извлечения поверхности. "udf" устойчив к запутанному/не-многообразному входу; "sdf" создаёт чистую единую поверхность с восстановлением острых особенностей с помощью QEF (квадратичной функции ошибки), но требует согласованной намотки. При выборе режима отображаются его специфические подопции. (по умолчанию: "udf") | DYNAMIC_COMBO | Да | "udf"<br>"sdf" |
| `полоса` | Ширина узкой полосы в воксельных единицах. В режиме UDF также смещает поверхность. (расширенный параметр, по умолчанию: 1.0) | FLOAT | Да | 0.5 - 4.0 |
| `project_back` | Линейно интерполировать вершины к исходной поверхности (0 = чистый DC, 1 = привязаны). (расширенный параметр, по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `fix_poles` | Схлопывать пары вершин валентности 3 (артефакт T-образного соединения DC). (расширенный параметр, по умолчанию: false) | BOOLEAN | Да | true / false |
| `smooth_iters` | Количество итераций сглаживания Таубина (0 = выключено). 2-3 устраняют ступенчатые артефакты DC; большее значение чрезмерно сглаживает рёбра QEF. (по умолчанию: 0) | INT | Да | 0 - 20 |
| `drop_small_components` | Удалять компоненты, размер которых ниже указанной доли от количества граней самого большого компонента. 0 отключает. (расширенный параметр, по умолчанию: 0.01) | FLOAT | Да | 0.0 - 0.5 |
| `precluster_max_verts` | Ограничивает количество вершин на входе перед запросами к полю; входные данные с большим количеством сначала кластерно децимируются до этого значения. Предотвращает нехватку памяти (OOM) на огромных сетках. (расширенный параметр, по умолчанию: 20,000,000) | INT | Да | 0 - 100,000,000 |

### Входы режима "udf"

Эти параметры появляются, когда `sign_mode` установлен в `"udf"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойственных вершин с помощью QEF (квадратичной функции ошибки) для более острых рёбер. (расширенный параметр, по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_inverted_components` | Удалять замкнутые компоненты с внутренними нормалями (отрицательным объёмом) — внутреннюю оболочку UDF. (расширенный параметр, по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_enclosed_components` | Удалять компоненты внутри bbox самого большого компонента, не проходящие проверку point-in-mesh raycast. Отключите для допустимых вложенных частей. (расширенный параметр, по умолчанию: false) | BOOLEAN | Нет | true / false |

### Входы режима "sdf"

Эти параметры появляются, когда `sign_mode` установлен в `"sdf"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойственных вершин с помощью QEF (квадратичной функции ошибки) (восстанавливает острые особенности) вместо центроида пересечения рёбер. (по умолчанию: true) | BOOLEAN | Нет | true / false |
| `manifold` | Manifold Dual Contouring: 1-4 двойственных вершин на воксель для случаев с несколькими листами. Медленнее. (по умолчанию: false) | BOOLEAN | Нет | true / false |

Примечание: У опции `qef` значение по умолчанию зависит от выбранного режима — false в режиме "udf", true в режиме "sdf". Когда `precluster_max_verts` больше 0 и входная сетка содержит больше вершин, чем это значение, сетка сначала кластерно децимируется до этого целевого значения перед запросами к полю. После обработки узел отображает изменение количества граней от входа к выходу (например, "faces: 1.23M → 200K (-84%)").

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `mesh` | Перестроенная сетка с однородной тесселяцией и сваренной топологией. Цвета вершин сохраняются, если присутствуют на входе; UV-координаты, нормали и тангенсы не переносятся. | MESH |
