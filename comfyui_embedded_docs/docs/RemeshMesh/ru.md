# RemeshMesh

```markdown
Remesh Mesh перестраивает сетку с чистой равномерной тесселяцией, дискретизируя узкополосное поле расстояний вокруг исходной поверхности и извлекая её с помощью Dual Contouring. Это нормализует запутанную, non-manifold или самопересекающуюся топологию. Узел предназначен для запуска перед Decimate Mesh для достижения точного количества граней. Обработка выполняется на активном вычислительном устройстве, и выходная сетка остаётся сваренной (welded).

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная сетка для перестроения. | MESH | Да | — |
| `resolution` | Разрешение воксельной сетки (плотность выходной сетки). 256 ~ 100 тыс. граней, 512 ~ 1 млн. Для точного количества граней запустите после этого Decimate Mesh. (по умолчанию: 512) | INT | Да | 32 - 2048 |
| `sign_mode` | Режим знакового расстояния, используемый для извлечения поверхности. Режим `"udf"` устойчив к запутанным/non-manifold входным данным; режим `"sdf"` создаёт чистую единую поверхность с восстановлением острых особенностей через QEF (квадратичную функцию ошибок), но требует согласованной ориентации обмотки. Выбор режима открывает его специфические подпараметры. (по умолчанию: `"udf"`) | DYNAMIC_COMBO | Да | `"udf"`<br>`"sdf"` |
| `band` | Ширина узкой полосы в вокселях. В режиме UDF также смещает поверхность. (дополнительно, по умолчанию: 1.0) | FLOAT | Да | 0.5 - 4.0 |
| `project_back` | Линейная интерполяция вершин в направлении исходной поверхности (0 = чистый DC, 1 = привязка). (дополнительно, по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `fix_poles` | Схлопывание пар вершин с валентностью 3 (артефакт T-образных соединений DC). (дополнительно, по умолчанию: false) | BOOLEAN | Да | true / false |
| `smooth_iters` | Итерации сглаживания Таубина (0 = выкл.). 2–3 устраняют ступенчатые артефакты DC; более высокие значения излишне сглаживают рёбра QEF. (по умолчанию: 0) | INT | Да | 0 - 20 |
| `drop_small_components` | Отбрасывать компоненты, размер которых меньше этой доли количества граней самого большого компонента. 0 отключает. (дополнительно, по умолчанию: 0.01) | FLOAT | Да | 0.0 - 0.5 |
| `precluster_max_verts` | Ограничение количества входных вершин до запросов поля; входные данные, превышающие это значение, сначала децимируются до него с помощью кластерной децимации. Предотвращает переполнение памяти (OOM) на огромных сетках. (дополнительно, по умолчанию: 20,000,000) | INT | Да | 0 - 100,000,000 |

### Входы режима `"udf"`

Эти параметры появляются, когда `sign_mode` установлен в `"udf"`.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF (квадратичная функция ошибок) размещение двойных вершин для более острых рёбер. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_inverted_components` | Отбрасывать замкнутые компоненты с нормалями внутрь (отрицательный объём) — внутреннюю оболочку UDF. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_enclosed_components` | Отбрасывать компоненты внутри ограничивающей рамки (bbox) самого большого компонента, которые не проходят лучевой тест на принадлежность точки сетке. Отключите для допустимых вложенных частей. (по умолчанию: false) | BOOLEAN | Нет | true / false |

### Входы режима `"sdf"`

Эти параметры появляются, когда `sign_mode` установлен в `"sdf"`.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF (квадратичная функция ошибок) размещение двойных вершин (восстанавливает острые особенности) вместо центроида пересечения рёбер. (по умолчанию: true) | BOOLEAN | Нет | true / false |
| `manifold` | Многообразие (Manifold) Dual Contouring: 1–4 двойных вершины на воксель для случаев с несколькими листами. Медленнее. (по умолчанию: false) | BOOLEAN | Нет | true / false |

Примечание: параметр `qef` имеет разные значения по умолчанию в зависимости от выбранного режима — false в режиме `"udf"`, true в режиме `"sdf"`. Когда `precluster_max_verts` больше 0 и входная сетка имеет больше вершин, чем это значение, сетка сначала децимируется до этого целевого значения с помощью кластерной децимации перед запросами поля. После обработки узел отображает изменение количества граней от входа к выходу (например, `"faces: 1.23M → 200K (-84%)"`).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Перестроенная сетка с равномерной тесселяцией и сваренной топологией. Цвета вершин сохраняются, если они присутствуют на входе; любые UV, нормали и касательные не переносятся. | MESH |
```
