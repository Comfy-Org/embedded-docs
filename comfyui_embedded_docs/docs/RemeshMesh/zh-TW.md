# RemeshMesh

Remesh Mesh 透過在原始表面周圍取樣窄帶距離場，並使用 Dual Contouring（雙輪廓）提取，以乾淨且均勻的鑲嵌來重建網格。這能正規化混亂、非流形或自相交的拓撲，且應在 Decimate Mesh 之前執行，以達到精確的面數。處理會在作用中的計算設備上執行，輸出網格會保持焊接狀態。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|

### "udf" 模式輸入

當 `sign_mode` 設定為 `"udf"` 時，會顯示這些參數。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 用於更銳利邊緣的 QEF（二次誤差函數）雙頂點放置。（預設值：false） | BOOLEAN | 否 | true / false |
| `drop_inverted_components` | 丟棄法線向內（負體積）的封閉元件——即 UDF 內殼。（預設值：false） | BOOLEAN | 否 | true / false |
| `drop_enclosed_components` | 丟棄位於最大元件包圍盒內且無法通過「點在網格內」光線投射檢測的元件。若存在合法的巢狀零件，請停用此選項。（預設值：false） | BOOLEAN | 否 | true / false |

### "sdf" 模式輸入

當 `sign_mode` 設定為 `"sdf"` 時，會顯示這些參數。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差函數）雙頂點放置（還原銳利特徵）對比邊交叉質心。（預設值：true） | BOOLEAN | 否 | true / false |
| `manifold` | 流形雙輪廓：每個體素 1-4 個雙頂點，用於多層案例。速度較慢。（預設值：false） | BOOLEAN | 否 | true / false |

注意：`qef` 選項的預設值會因選取的模式而不同——在「udf」模式中為 false，在「sdf」模式中為 true。當 `precluster_max_verts` 大於 0 且輸入網格的頂點數超過此值時，網格會在欄位查詢前先以叢集減面至該目標。處理完成後，節點會顯示輸入到輸出的面數變化（例如：「faces: 1.23M → 200K (-84%)」）。
