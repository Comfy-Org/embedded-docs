# RemeshMesh

Remesh Mesh 會在原始表面周圍取樣窄頻帶距離場，再以 Dual Contouring 將其萃取，藉此重建出拓撲乾淨且均勻細分的網格。此操作可正規化雜亂、非流形或自相交的拓撲結構，並應在 Decimate Mesh 之前執行，以達到精確的面數。處理會在目前作用中的計算裝置上執行，且輸出網格會保持焊接狀態。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要重新網格化的輸入網格。 | MESH | 是 | — |
| `resolution` | 體素網格解析度（輸出密度）。256 約為 10 萬面，512 約為 100 萬面。若要精確的面數，請接著使用 Decimate Mesh。（預設值：512） | INT | 是 | 32 - 2048 |
| `sign_mode` | 用於表面萃取的符號距離模式。「udf」對雜亂/非流形輸入具有穩健性；「sdf」則透過 QEF（二次誤差函數）銳利特徵還原產生乾淨的單一表面，但需要一致的繞序。選取任一模式會顯示其特定的子選項。（預設值："udf"） | DYNAMIC_COMBO | 是 | "udf"<br>"sdf" |
| `band` | 以體素為單位的窄頻帶寬度。在 UDF 模式下也會偏移表面。（進階，預設值：1.0） | FLOAT | 是 | 0.5 - 4.0 |
| `project_back` | 將頂點向原始表面線性插值（0 = 純 DC，1 = 吸附）。（進階，預設值：0.0） | FLOAT | 是 | 0.0 - 1.0 |
| `fix_poles` | 收合價數為 3 的頂點對（DC T 形接點偽影）。（進階，預設值：false） | BOOLEAN | 是 | true / false |
| `smooth_iters` | Taubin 平滑迭代次數（0 = 關閉）。2-3 次可清除 DC 階梯狀偽影；更高次數會過度平滑 QEF 邊緣。（預設值：0） | INT | 是 | 0 - 20 |

### "udf" 模式輸入

當 `sign_mode` 設為「udf」時，會顯示這些參數。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差函數）雙頂點放置，可產生更銳利的邊緣。（預設值：false） | BOOLEAN | 否 | true / false |
| `drop_inverted_components` | 丟棄法線朝內（負體積）的封閉元件——即 UDF 的內部殼層。（預設值：false） | BOOLEAN | 否 | true / false |
| `drop_enclosed_components` | 丟棄位於最大元件 bbox 內、但未通過「點位於網格內」射線投射檢查的元件。若為合法的巢狀零件，請停用此選項。（預設值：false） | BOOLEAN | 否 | true / false |

### "sdf" 模式輸入

當 `sign_mode` 設為「sdf」時，會顯示這些參數。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差函數）雙頂點放置（還原銳利特徵），而非邊緣交叉質心。（預設值：true） | BOOLEAN | 否 | true / false |
| `manifold` | 流形 Dual Contouring：在多片（multi-sheet）情況下，每個體素產生 1-4 個雙頂點。速度較慢。（預設值：false） | BOOLEAN | 否 | true / false |

注意：`qef` 選項的預設值會依所選模式而不同——在「udf」模式下為 false，在「sdf」模式下為 true。當 `precluster_max_verts` 大於 0，且輸入網格的頂點數超過此值時，網格會先在欄位查詢前以叢集減面處理至該目標。處理完成後，節點會顯示輸入到輸出的面數變化（例如："faces: 1.23M → 200K (-84%)"）。
