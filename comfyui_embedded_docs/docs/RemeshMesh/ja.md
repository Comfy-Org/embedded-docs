# RemeshMesh

<!-- 日本語翻訳 -->

Remesh Mesh は、元のサーフェス周辺の狭帯域距離場をサンプリングし、デュアルコンタリングで抽出することで、クリーンで均一なテッセレーションを持つメッシュを再構築します。これにより、乱れた非多様体や自己交差するトポロジーが正規化され、正確な面数を達成するために Decimate Mesh の前に実行することを意図しています。処理はアクティブな計算デバイス上で実行され、出力メッシュはウェルドされた状態を維持します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | リメッシュする入力メッシュ。 | MESH | はい | — |
| `resolution` | ボクセルグリッド解像度（出力密度）。256で約10万面、512で約100万面。正確な面数を求める場合は、Decimate Mesh を続けて実行してください。（デフォルト: 512） | INT | はい | 32 - 2048 |
| `sign_mode` | サーフェス抽出に使用する符号付き距離モード。"udf" は乱れた/非多様体の入力に対して堅牢です。"sdf" は QEF（二次誤差関数）によるシャープな特徴の再現を伴うクリーンな単一サーフェスを生成しますが、一貫した巻き方向が必要です。モードを選択すると、そのモード固有のサブオプションが表示されます。（デフォルト: "udf"） | DYNAMIC_COMBO | はい | "udf"<br>"sdf" |

| `smooth_iters` | Taubin スムージングの反復回数（0 = オフ）。2〜3でDCの階段状アーティファクトを除去します。それ以上ではQEFのエッジを過度にスムージングします。（デフォルト: 0） | INT | はい | 0 - 20 |

### "udf" モード入力

これらのパラメータは、`sign_mode` が `"udf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差関数）によるデュアル頂点配置で、よりシャープなエッジを実現します。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_inverted_components` | 内向き法線（負の体積）を持つ閉じたコンポーネント（UDFの内側シェル）を破棄します。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_enclosed_components` | 最大コンポーネントのバウンディングボックス内にあり、メッシュ内ポイントのレイキャストを通過しないコンポーネントを破棄します。正当な入れ子部品の場合は無効にしてください。（デフォルト: false） | BOOLEAN | いいえ | true / false |

### "sdf" モード入力

これらのパラメータは、`sign_mode` が `"sdf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差関数）によるデュアル頂点配置（シャープな特徴を復元）と、エッジ交差セントロイドの比較。（デフォルト: true） | BOOLEAN | いいえ | true / false |
| `manifold` | マニフォールドデュアルコンタリング：多層シートの場合、ボクセルあたり1〜4個のデュアル頂点を使用します。低速です。（デフォルト: false） | BOOLEAN | いいえ | true / false |

注：`qef` オプションのデフォルト値は選択されたモードによって異なります。「udf」モードでは false、「sdf」モードでは true です。`precluster_max_verts` が 0 より大きく、入力メッシュの頂点数がこの値を超える場合、フィールドクエリの前にメッシュはクラスタ間引きでその目標値まで減らされます。処理後、ノードには入力から出力への面数の変化が表示されます（例：「faces: 1.23M → 200K (-84%)」）。
