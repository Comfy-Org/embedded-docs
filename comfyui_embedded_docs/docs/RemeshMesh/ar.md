# RemeshMesh

## Remesh Mesh

تعيد عقدة Remesh Mesh بناء الشبكة بتقسيم نظيف وموحد عبر أخذ عينات من حقل مسافة ضيق النطاق حول السطح الأصلي واستخراجه باستخدام الكفاف المزدوج (Dual Contouring). يؤدي ذلك إلى تطبيع البنية غير المنتظمة أو غير المتعددة الأسطح (non-manifold) أو المتقاطعة ذاتيًا، وهي مصممة للتشغيل قبل عقدة Decimate Mesh للوصول إلى عدد دقيق من الوجوه. تُنفَّذ المعالجة على جهاز الحوسبة النشط، وتبقى الشبكة الناتجة ملحومة.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الشبكة` | الشبكة المدخلة المراد إعادة تشكيلها. | MESH | نعم | — |
| `الدقة` | دقة شبكة فوكسل (كثافة الإخراج). 256 ~ 100k وجه، 512 ~ 1M. للوصول إلى عدد وجوه دقيق، اتبع ذلك بعقدة Decimate Mesh. (الافتراضي: 512) | INT | نعم | 32 - 2048 |
| `sign_mode` | وضع المسافة الموقّعة المستخدم لاستخراج السطح. الوضع "udf" قوي مع المدخلات غير المنتظمة/غير المتعددة الأسطح؛ بينما يُنتج الوضع "sdf" سطحًا واحدًا نظيفًا مع استرجاع الحواف الحادة عبر QEF (دالة الخطأ التربيعية)، لكنه يتطلب تناسق اتجاه اللف. يؤدي تحديد وضع إلى إظهار خياراته الفرعية المحددة. (الافتراضي: "udf") | DYNAMIC_COMBO | نعم | "udf"<br>"sdf" |
| `النطاق` | عرض النطاق الضيق بوحدات فوكسل. في وضع UDF يعمل أيضًا على إزاحة السطح. (متقدم، الافتراضي: 1.0) | FLOAT | نعم | 0.5 - 4.0 |
| `project_back` | استيفاء خطي للقمم نحو السطح الأصلي (0 = DC نقي، 1 = ملتصق). (متقدم، الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `fix_poles` | طي أزواج القمم ذات التكافؤ 3 (قطعة أثرية من التقاطع T في DC). (متقدم، الافتراضي: false) | BOOLEAN | نعم | true / false |
| `smooth_iters` | تكرارات تنعيم Taubin (0 = إيقاف). 2-3 تنظّف القطع الأثرية الشبيهة بالسلالم من DC؛ والقيم الأعلى تفرط في تنعيم حواف QEF. (الافتراضي: 0) | INT | نعم | 0 - 20 |
| `drop_small_components` | إسقاط المكونات الأقل من هذا الكسر من عدد وجوه الأكبر. القيمة 0 تعطيل. (متقدم، الافتراضي: 0.01) | FLOAT | نعم | 0.0 - 0.5 |
| `precluster_max_verts` | حد أقصى لعدد القمم المدخلة قبل استعلامات المجال؛ المدخلات التي تتجاوز هذا الحد تُخفَّض عن طريق التجزيء العنقودي إليها أولًا. يمنع نفاد الذاكرة على الشبكات الضخمة. (متقدم، الافتراضي: 20,000,000) | INT | نعم | 0 - 100,000,000 |

### مدخلات وضع "udf"

تظهر هذه المعاملات عندما يكون `sign_mode` مضبوطًا على `"udf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع القمم المزدوجة عبر QEF (دالة الخطأ التربيعية) لحواف أكثر حدة. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_inverted_components` | إسقاط المكونات المغلقة ذات الاتجاه الداخلي (الحجم السالب) — الغلاف الداخلي لـ UDF. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_enclosed_components` | إسقاط المكونات داخل الصندوق المحيط (bbox) للأكبر التي تفشل في اختبار التقاطع الشعاعي داخل الشبكة. عطّل هذا الخيار للأجزاء المتداخلة المشروعة. (الافتراضي: false) | BOOLEAN | لا | true / false |

### مدخلات وضع "sdf"

تظهر هذه المعاملات عندما يكون `sign_mode` مضبوطًا على `"sdf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع القمم المزدوجة عبر QEF (دالة الخطأ التربيعية) (يستعيد الحواف الحادة) مقابل النقطة المركزية لتقاطع الحافة. (الافتراضي: true) | BOOLEAN | لا | true / false |
| `manifold` | الكفاف المزدوج متعدد الأسطح: 1-4 قمم مزدوجة لكل فوكسل للحالات متعددة الطبقات. أبطأ. (الافتراضي: false) | BOOLEAN | لا | true / false |

ملاحظة: الخيار `qef` له افتراضي مختلف اعتمادًا على الوضع المحدد — false في وضع "udf"، وtrue في وضع "sdf". عندما تكون قيمة `precluster_max_verts` أكبر من 0 وكانت الشبكة المدخلة تحتوي على قمم أكثر من هذه القيمة، تُخفَّض الشبكة عن طريق التجزيء العنقودي إلى ذلك الهدف قبل استعلامات المجال. بعد المعالجة، تعرض العقدة تغيير عدد الوجوه من الإدخال إلى الإخراج على العقدة (مثل: "faces: 1.23M → 200K (-84%)").
