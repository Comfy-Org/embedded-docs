# RemeshMesh

يعيد Remesh Mesh بناء الشبكة بتقسيم نظيف وموحد عبر أخذ عينات من حقل مسافة ضيق النطاق حول السطح الأصلي واستخراجه باستخدام الكنتور المزدوج (Dual Contouring). ويعمل هذا على تطبيع الطوبولوجيا الفوضوية أو غير المتعددة الأسطح أو ذاتية التقاطع، وهو مصمم ليعمل قبل عقدة Decimate Mesh للوصول إلى عدد أوجه دقيق. تتم المعالجة على جهاز الحوسبة النشط وتبقى الشبكة الناتجة ملحومة.

## المدخلات

### المدخلات الشائعة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة المدخلة المراد إعادة بنائها. | MESH | نعم | — |
| `resolution` | دقة شبكة الفوكسل (كثافة الإخراج). 256 ~ 100 ألف وجه، 512 ~ مليون وجه. للحصول على عدد دقيق من الأوجه، تابع مع Decimate Mesh. (الافتراضي: 512) | INT | نعم | 32 - 2048 |
| `sign_mode` | وضع المسافة الموقعة المستخدم لاستخراج السطح. «udf» قوي مع المدخلات الفوضوية/غير المتعددة الأسطح؛ وينتج «sdf» سطحًا واحدًا نظيفًا مع استرداد الحواف الحادة عبر QEF (دالة الخطأ التربيعي)، لكنه يحتاج إلى لفّ متسق. تحديد وضع يكشف عن خياراته الفرعية الخاصة. (الافتراضي: «udf») | DYNAMIC_COMBO | نعم | "udf"<br>"sdf" |
| `band` | عرض النطاق الضيق بوحدات الفوكسل. في وضع UDF يزيح السطح أيضًا. (متقدم، الافتراضي: 1.0) | FLOAT | نعم | 0.5 - 4.0 |
| `project_back` | استيفاء خطي للرؤوس نحو السطح الأصلي (0 = DC نقي، 1 = ملتصق). (متقدم، الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `fix_poles` | طيّ أزواج الرؤوس ذات التكافؤ 3 (أثر تقاطع T في DC). (متقدم، الافتراضي: false) | BOOLEAN | نعم | true / false |
| `smooth_iters` | تكرارات تنعيم Taubin (0 = معطل). من 2 إلى 3 ينظف آثار السلالم في DC؛ القيم الأعلى تفرط في تنعيم حواف QEF. (الافتراضي: 0) | INT | نعم | 0 - 20 |
| `drop_small_components` | إسقاط المكونات الأقل من هذا الكسر من عدد أوجه الأكبر. القيمة 0 تعطيل. (متقدم، الافتراضي: 0.01) | FLOAT | نعم | 0.0 - 0.5 |
| `precluster_max_verts` | تحديد عدد رؤوس الإدخال قبل استعلامات الحقل؛ المدخلات التي تتجاوز هذا العدد تخضع أولًا لتقليل عنقودي. يمنع نفاد الذاكرة على الشبكات الضخمة. (متقدم، الافتراضي: 20,000,000) | INT | نعم | 0 - 100,000,000 |

### مدخلات وضع "udf"

تظهر هذه المعاملات عندما يتم ضبط `sign_mode` على `"udf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع قمة مزدوجة عبر QEF (دالة الخطأ التربيعي) لحواف أكثر حدة. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_inverted_components` | إسقاط المكونات المغلقة ذات الاتجاه الداخلي (سالب الحجم) — القشرة الداخلية لـ UDF. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_enclosed_components` | إسقاط المكونات داخل الصندوق المحيط بالأكبر التي تفشل في اختبار الشعاع (تحديد النقطة داخل الشبكة). عطّله للأجزاء المتداخلة المشروعة. (الافتراضي: false) | BOOLEAN | لا | true / false |

### مدخلات وضع "sdf"

تظهر هذه المعاملات عندما يتم ضبط `sign_mode` على `"sdf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع قمة مزدوجة عبر QEF (دالة الخطأ التربيعي) (يستعيد الحواف الحادة) مقابل النقطة المركزية لعبور الحواف. (الافتراضي: true) | BOOLEAN | لا | true / false |
| `manifold` | الكنتور المزدوج المتعدد الأسطح (Manifold Dual Contouring): من 1 إلى 4 رؤوس مزدوجة لكل فوكسل لحالات الأغلفة المتعددة. أبطأ. (الافتراضي: false) | BOOLEAN | لا | true / false |

ملاحظة: الخيار `qef` له إعداد افتراضي مختلف حسب الوضع المحدد — false في وضع "udf"، true في وضع "sdf". عندما يكون `precluster_max_verts` أكبر من 0 وكانت الشبكة المدخلة تحتوي على رؤوس أكثر من هذه القيمة، تُختزل الشبكة عنقوديًا إلى ذلك الهدف قبل استعلامات الحقل. بعد المعالجة، تعرض العقدة تغيير عدد الأوجه من الإدخال إلى الإخراج على العقدة (مثل: "الأوجه: 1.23M → 200K (-84%)").

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
