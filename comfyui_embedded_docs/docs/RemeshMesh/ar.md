# إعادة تشكيل الشبكة (DC للنطاق الضيق)

تعيد عقدة Remesh Mesh بناء شبكة عبر أخذ عينات من حقل مسافة ذي نطاق ضيق حول السطح الأصلي واستخلاصه باستخدام Dual Contouring، ما يمنحها تبليطًا نظيفًا وموحدًا. يعمل هذا على تطبيع الطوبولوجيا الفوضوية أو غير المتنوعة أو ذاتية التقاطع، ويُقصد به أن يُشغَّل قبل عقدة Decimate Mesh للوصول إلى عدد أوجه دقيق. تتم المعالجة على جهاز الحساب النشط وتبقى شبكة المخرجات ملحومة.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | شبكة الإدخال المراد إعادة تشكيلها. | MESH | نعم | — |
| `resolution` | دقة شبكة الفوكسل (كثافة المخرجات). 256 ~ 100 ألف وجه، 512 ~ 1 مليون. للحصول على عدد أوجه دقيق، اتبعها بعقدة Decimate Mesh. (الافتراضي: 512) | INT | نعم | 32 - 2048 |
| `sign_mode` | وضع استخلاص السطح. "udf" مقاوم للمدخلات الفوضوية/غير المتنوعة؛ بينما "sdf" ينتج سطحًا واحدًا نظيفًا مع استعادة الميزات الحادة عبر QEF (دالة الخطأ التربيعي)، لكنه يحتاج إلى اتجاه لف متسق. اختيار وضع يكشف خياراته الفرعية الخاصة. (الافتراضي: "udf") | DYNAMIC_COMBO | نعم | "udf"<br>"sdf" |
| `band` | عرض النطاق الضيق بوحدات الفوكسل. في وضع UDF يزيح السطح أيضًا. (متقدم، الافتراضي: 1.0) | FLOAT | نعم | 0.5 - 4.0 |
| `project_back` | استيفاء خطي للرؤوس نحو السطح الأصلي (0 = DC خالص، 1 = ملتصق). (متقدم، الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `fix_poles` | دمج أزواج الرؤوس ذات التكافؤ 3 (تشوه تقاطع T في DC). (متقدم، الافتراضي: false) | BOOLEAN | نعم | true / false |
| `smooth_iters` | تكرارات تنعيم Taubin (0 = معطّل). 2-3 ينظف تشوهات DC الشبيهة بالدرج؛ القيم الأعلى تفرط في تنعيم حواف QEF. (الافتراضي: 0) | INT | نعم | 0 - 20 |
| `drop_small_components` | إسقاط المكونات التي تقل عن هذه النسبة من عدد أوجه أكبر مكوّن. القيمة 0 تعطّل ذلك. (متقدم، الافتراضي: 0.01) | FLOAT | نعم | 0.0 - 0.5 |
| `precluster_max_verts` | حد أقصى لعدد رؤوس الإدخال قبل استعلامات الحقل؛ المدخلات التي تتجاوز هذا الحد تُقلَّص عنقوديًا إليه أولًا. يمنع نفاد الذاكرة (OOM) مع الشبكات الضخمة. (متقدم، الافتراضي: 20,000,000) | INT | نعم | 0 - 100,000,000 |

### مدخلات وضع "udf"

تظهر هذه المعاملات عندما تكون قيمة `sign_mode` مضبوطة على `"udf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | تموضع الرؤوس المزدوجة QEF (دالة الخطأ التربيعي) للحصول على حواف أكثر حدة. (متقدم، الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_inverted_components` | إسقاط المكونات المغلقة ذات العمودي للداخل (حجم سالب) — القشرة الداخلية لـ UDF. (متقدم، الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_enclosed_components` | إسقاط المكونات الواقعة داخل الصندوق المحيط لأكبر مكوّن والتي تفشل في اختبار شعاع نقطة داخل الشبكة. عطّله للأجزاء المتداخلة المشروعة. (متقدم، الافتراضي: false) | BOOLEAN | لا | true / false |

### مدخلات وضع "sdf"

تظهر هذه المعاملات عندما تكون قيمة `sign_mode` مضبوطة على `"sdf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | تموضع الرؤوس المزدوجة QEF (دالة الخطأ التربيعي) (يستعيد الميزات الحادة) مقابل مركز الثقل عند تقاطع الحواف. (الافتراضي: true) | BOOLEAN | لا | true / false |
| `manifold` | Manifold Dual Contouring: 1-4 رؤوس مزدوجة/فوكسل في الحالات متعددة الطبقات. أبطأ. (الافتراضي: false) | BOOLEAN | لا | true / false |

ملاحظة: يختلف الافتراضي الخاص بخيار `qef` حسب الوضع المحدد — false في وضع "udf"، وtrue في وضع "sdf". عندما تكون قيمة `precluster_max_verts` أكبر من 0 وتحتوي شبكة الإدخال على رؤوس أكثر من هذه القيمة، تُقلَّص الشبكة عنقوديًا وصولًا إلى هذا الهدف قبل استعلامات الحقل. بعد المعالجة، تعرض العقدة تغيّر عدد الأوجه من الإدخال إلى الإخراج على العقدة (على سبيل المثال، "faces: 1.23M → 200K (-84%)").

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `mesh` | الشبكة المعاد تشكيلها بتبليط موحد وطوبولوجيا ملحومة. تُحفظ ألوان الرؤوس عند وجودها في الإدخال؛ ولا يتم نقل أي UVs أو المتجهات العمودية أو المماسات. | MESH |
