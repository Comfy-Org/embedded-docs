# יצירת רשת מחדש (DC ברצועה צרה)

Remesh Mesh בונה מחדש מש עם טסלציה אחידה ונקייה על ידי דגימה של שדה מרחק פס-צר סביב המשטח המקורי וחילוצו באמצעות Dual Contouring. זה מנרמל טופולוגיה מבולגנת, לא-מניפולדית או עם חיתוך עצמי, ונועד להיות מופעל לפני Decimate Mesh כדי להגיע למספר פאות מדויק. העיבוד פועל על התקן החישוב הפעיל ומש הפלט נשאר מרותך.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | מש הקלט שעליו לבצע רימש. | MESH | כן | — |
| `resolution` | רזולוציית גריד ווקסלים (צפיפות הפלט). 256 ~ 100k פאות, 512 ~ 1M. למספר פאות מדויק, יש להמשיך עם Decimate Mesh. (ברירת מחדל: 512) | INT | כן | 32 - 2048 |
| `sign_mode` | מצב חילוץ משטח. "udf" עמיד לקלט מבולגן/לא-מניפולדי; "sdf" מפיק משטח יחיד נקי עם שחזור תכונות חדות באמצעות QEF (פונקציית שגיאה ריבועית), אך דורש סדר ליפוף עקבי. "solid" בונה גוף אטום יחיד מקלט מבולגן: חיתוך גרף גלובלי פנים/חוץ (CelloCut) מסיר קליפות כפולות וסוגר חורים קטנים. איטי יותר. בחירת מצב חושפת את תתי-האפשרויות הספציפיות שלו. (ברירת מחדל: "udf") | DYNAMIC_COMBO | כן | "udf"<br>"sdf"<br>"solid" |
| `band` | רוחב הפס הצר ביחידות ווקסל. במצב UDF גם יוצר היסט למשטח. במצב solid זהו רדיוס הסגירה: קמטים מוחלקים ופערים מגושרים בגודל הזה, והמשטח נמצא חצי ווקסל החוצה. (מתקדם, ברירת מחדל: 1.0) | FLOAT | כן | 0.5 - 4.0 |
| `project_back` | בצע אינטרפולציה לינארית של קודקודים לכיוון המשטח המקורי (0 = DC טהור, 1 = מוצמד). (מתקדם, ברירת מחדל: 0.0) | FLOAT | כן | 0.0 - 1.0 |
| `fix_poles` | כווץ זוגות קודקודים בעלי valence 3 (ארטיפקט צומת T של DC). (מתקדם, ברירת מחדל: false) | BOOLEAN | כן | true / false |
| `smooth_iters` | איטרציות החלקת Taubin (0 = כבוי). 2-3 מנקה ארטיפקטים דמויי מדרגות של DC; ערכים גבוהים יותר מחליקים יתר על המידה קצוות QEF. (ברירת מחדל: 0) | INT | כן | 0 - 20 |
| `drop_small_components` | השמט רכיבים מתחת לשבר זה ממספר הפאות של הרכיב הגדול ביותר. 0 מבטל. (מתקדם, ברירת מחדל: 0.01) | FLOAT | כן | 0.0 - 0.5 |
| `precluster_max_verts` | הגבל את מספר קודקודי הקלט לפני שאילתות השדה; קלטים מעל ערך זה עוברים תחילה דצימציית אשכולות (cluster-decimation) לערך הזה. מונע OOM במשים עצומים. (מתקדם, ברירת מחדל: 20,000,000) | INT | כן | 0 - 100,000,000 |

### קלטים של מצב "udf"

פרמטרים אלה מופיעים כאשר `sign_mode` מוגדר ל `"udf"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `qef` | מיקום קודקודים באמצעות QEF (פונקציית שגיאה ריבועית): קצוות חדים בקלט של משטחים קשים וקמטים משוננים בקלט אורגני. (מתקדם, ברירת מחדל: false) | BOOLEAN | לא | true / false |
| `drop_inverted_components` | השמט רכיבים סגורים בעלי נורמל כלפי פנים (נפח שלילי) — הקליפה הפנימית של UDF. (מתקדם, ברירת מחדל: false) | BOOLEAN | לא | true / false |
| `drop_enclosed_components` | השמט רכיבים בתוך ה-bbox של הרכיב הגדול ביותר שנכשלים בבדיקת raycast של נקודה בתוך מש. יש להשבית עבור חלקים מקוננים לגיטימיים. (מתקדם, ברירת מחדל: false) | BOOLEAN | לא | true / false |

### קלטים של מצב "sdf"

פרמטרים אלה מופיעים כאשר `sign_mode` מוגדר ל `"sdf"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `qef` | מיקום קודקוד דואלי באמצעות QEF (פונקציית שגיאה ריבועית) (משחזר תכונות חדות) לעומת צנטרואיד של חציית קצוות. (ברירת מחדל: true) | BOOLEAN | לא | true / false |
| `manifold` | Manifold Dual Contouring: 1-4 קודקודים דואליים/ווקסל במקרים של ריבוי יריעות. איטי יותר. (ברירת מחדל: false) | BOOLEAN | לא | true / false |

### קלטים של מצב "solid"

פרמטרים אלה מופיעים כאשר `sign_mode` מוגדר ל `"solid"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `fill` | עלות סגירת פתח ביחס להיצמדות למשטח. ערך נמוך סוגר פתחים גדולים יותר (0 שם מכסה על כוס); ערך גבוה סוגר רק חורים וסדקים קטנים. (ברירת מחדל: 20.0) | FLOAT | לא | 0.0 - 1000.0 |
| `qef` | מיקום קודקודים באמצעות QEF (פונקציית שגיאה ריבועית): קצוות חדים בקלט של משטחים קשים וקמטים משוננים בקלט אורגני. (מתקדם, ברירת מחדל: false) | BOOLEAN | לא | true / false |

הערה: ברירת המחדל של האפשרות `qef` שונה בהתאם למצב הנבחר — false במצבים "udf" ו-"solid", true במצב "sdf". כאשר `precluster_max_verts` גדול מ-0 ולמש הקלט יש יותר קודקודים מערך זה, המש עובר דצימציית אשכולות (cluster-decimation) עד לערך היעד הזה לפני שאילתות השדה. לאחר העיבוד, הצומת מציג את השינוי במספר הפאות מקלט לפלט על הצומת (לדוגמה, "faces: 1.23M → 200K (-84%)").
