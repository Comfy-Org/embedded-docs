# KlingSingleImageVideoEffectNode

گره افکت ویدیوی تک‌تصویری Kling ویدیوهایی با افکت‌های ویژه مختلف بر اساس یک تصویر مرجع ایجاد می‌کند. این گره افکت‌ها و صحنه‌های بصری گوناگونی را اعمال می‌کند تا تصاویر ثابت را به محتوای ویدیویی پویا تبدیل کند. این گره از صحنه‌های افکت، گزینه‌های مدل و مدت‌زمان‌های مختلف ویدیو پشتیبانی می‌کند تا به نتیجه بصری دلخواه برسد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر مرجع. URL یا رشته کدشده با Base64 (بدون پیشوند data:image). حجم فایل نمی‌تواند از 10MB بیشتر باشد، وضوح نباید کمتر از 300x300px باشد، نسبت ابعاد باید بین 1:2.5 تا 2.5:1 باشد | IMAGE | بله | - |
| `effect_scene` | نوع صحنه افکت ویژه برای اعمال به تولید ویدیو. برخی افکت‌ها ممکن است قیمت متفاوتی داشته باشند. | COMBO | بله | `"dizzydizzy"`<br>`"bloombloom"`<br>`"neon"`<br>`"cartoon"`<br>`"sketch"`<br>`"oil"`<br>`"watercolor"`<br>`"3d"` |
| `model_name` | نسخه مدل مشخص برای استفاده در تولید افکت ویدیو. | COMBO | بله | `"kling-v1-5"`<br>`"kling-v1-6"` |
| `duration` | طول ویدیوی تولیدشده بر حسب ثانیه. | COMBO | بله | `"5"`<br>`"10"` |

**توجه:** پارامتر `effect_scene` بر قیمت‌گذاری این گره تأثیر می‌گذارد. افکت‌های `dizzydizzy` و `bloombloom` برای هر تولید 0.49 دلار آمریکا هزینه دارند، در حالی که سایر افکت‌ها برای هر تولید 0.28 دلار آمریکا هزینه دارند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `output` | ویدیوی تولیدشده با افکت‌های اعمال‌شده | VIDEO |
| `video_id` | شناسه یکتای ویدیوی تولیدشده | STRING |
| `duration` | مدت‌زمان ویدیوی تولیدشده | STRING |
