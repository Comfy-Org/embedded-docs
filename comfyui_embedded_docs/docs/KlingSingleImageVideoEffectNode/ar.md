# KlingSingleImageVideoEffectNode

تُنشئ عقدة Kling Single Image Video Effect مقاطع فيديو بتأثيرات خاصة مختلفة استنادًا إلى صورة مرجعية واحدة. وتطبّق تأثيرات بصرية ومشاهد متنوعة لتحويل الصور الثابتة إلى محتوى فيديو ديناميكي. تدعم العقدة مشاهد تأثيرات مختلفة، وخيارات نماذج، ومدد فيديو متعددة لتحقيق النتيجة البصرية المطلوبة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المرجعية. رابط URL أو سلسلة مُرمّزة بـ Base64 (بدون بادئة data:image). يجب ألا يتجاوز حجم الملف 10MB، وألا تقل الدقة عن 300x300px، وأن تكون نسبة العرض إلى الارتفاع بين 1:2.5 و2.5:1 | IMAGE | نعم | - |
| `effect_scene` | نوع مشهد التأثير الخاص المراد تطبيقه على توليد الفيديو. قد يكون لبعض التأثيرات تسعير مختلف. | COMBO | نعم | `"dizzydizzy"`<br>`"bloombloom"`<br>`"neon"`<br>`"cartoon"`<br>`"sketch"`<br>`"oil"`<br>`"watercolor"`<br>`"3d"` |
| `model_name` | إصدار النموذج المحدد المستخدم لتوليد تأثير الفيديو. | COMBO | نعم | `"kling-v1-5"`<br>`"kling-v1-6"` |
| `duration` | طول الفيديو المولّد بالثواني. | COMBO | نعم | `"5"`<br>`"10"` |

**ملاحظة:** يؤثر المعامل `effect_scene` على تسعير العقدة. يكلف التأثيران `dizzydizzy` و`bloombloom` مبلغ $0.49 USD لكل عملية توليد، بينما تكلف جميع التأثيرات الأخرى $0.28 USD لكل عملية توليد.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الفيديو المولّد مع التأثيرات المطبّقة | VIDEO |
| `video_id` | المعرّف الفريد للفيديو المولّد | STRING |
| `duration` | مدة الفيديو المولّد | STRING |
