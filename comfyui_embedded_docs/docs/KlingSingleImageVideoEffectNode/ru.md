# KlingSingleImageVideoEffectNode

Узел Kling Single Image Video Effect создаёт видео с различными специальными эффектами на основе одного эталонного изображения. Он применяет разные визуальные эффекты и сцены для преобразования статических изображений в динамический видеоконтент. Узел поддерживает различные сцены эффектов, варианты моделей и длительности видео для достижения желаемого визуального результата.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Эталонное изображение. URL или строка в кодировке Base64 (без префикса data:image). Размер файла не должен превышать 10 МБ, разрешение не менее 300x300 px, соотношение сторон от 1:2.5 до 2.5:1 | IMAGE | Да | - |
| `effect_scene` | Тип сцены специального эффекта, применяемого при генерации видео. Некоторые эффекты могут иметь другую стоимость. | COMBO | Да | `"dizzydizzy"`<br>`"bloombloom"`<br>`"neon"`<br>`"cartoon"`<br>`"sketch"`<br>`"oil"`<br>`"watercolor"`<br>`"3d"` |
| `model_name` | Конкретная версия модели, используемая для генерации видеоэффекта. | COMBO | Да | `"kling-v1-5"`<br>`"kling-v1-6"` |
| `duration` | Длительность сгенерированного видео в секундах. | COMBO | Да | `"5"`<br>`"10"` |

**Примечание:** Параметр `effect_scene` влияет на стоимость узла. Эффекты `dizzydizzy` и `bloombloom` стоят $0.49 USD за генерацию, тогда как все остальные эффекты стоят $0.28 USD за генерацию.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео с применёнными эффектами | VIDEO |
| `video_id` | Уникальный идентификатор сгенерированного видео | STRING |
| `duration` | Длительность сгенерированного видео | STRING |
