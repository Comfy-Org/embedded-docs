# Перемешать Пары Видео-Текст

Этот узел случайным образом перемешивает порядок пар видео-текст, сохраняя соответствие каждого видео своему тексту. Он принимает два списка одинаковой длины и применяет одну и ту же случайную перестановку к обоим, гарантируя, что исходные пары сохраняются после перемешивания.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Список видео для перемешивания. | VIDEO | Да | Список видеоэлементов |
| `тексты` | Список текстов для перемешивания. | STRING | Да | Список текстовых строк |
| `seed` | Случайное зерно для управления порядком перемешивания (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |
Примечание: `videos` и `texts` должны иметь одинаковую длину, поскольку узел сопоставляет каждое видео с текстом в той же позиции и сохраняет эти пары при перемешивании.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Перемешанные видео в новом случайном порядке. | VIDEO |
| `тексты` | Перемешанные тексты в том же новом порядке, что и видео. | STRING |
