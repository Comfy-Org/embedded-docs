# ערבוב זוגות וידאו-טקסט

צומת זה מערבב באופן אקראי את הסדר של זוגות וידאו-טקסט ברשימה, תוך שמירה על כל סרטון משויך לטקסט המתאים לו. הוא מקבל שתי רשימות באורך שווה ומחיל את אותה תמורה אקראית על שתיהן, כך שהשיוך המקורי נשמר לאחר הערבוב. ערך `seed` שולט בסדר הערבוב כך שניתן לשחזר את התוצאות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `videos` | רשימת סרטונים לערבוב. | VIDEO | כן | רשימת פריטי וידאו |
| `texts` | רשימת טקסטים לערבוב (הכיתובים המשויכים לסרטונים). | STRING | כן | רשימת מחרוזות טקסט |
| `seed` | ערך seed אקראי הקובע את סדר הערבוב (ברירת מחדל: 0). | INT | כן | 0 עד 18446744073709551615 |

הערה: `videos` ו-`texts` חייבים להיות באותו אורך, מכיוון שהצומת משייך כל סרטון לטקסט באותו מיקום ושומר על שיוך זה בעת הערבוב. באופן פנימי, ערך ה-`seed` מצומצם באמצעות מודולו 4294967295 (2^32 - 1) לפני יצירת הסדר האקראי, כך שערכי `seed` גדולים מאוד עשויים להפיק אותו ערבוב כמו ערכים קטנים יותר.
