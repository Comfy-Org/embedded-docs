# درهم‌ریختن جفت‌های ویدیو-متن

این گره به‌طور تصادفی ترتیب جفت‌های ویدیو-متن را بر هم می‌زند، به‌طوری‌که هر ویدیو با متن متناظر خود جفت باقی بماند. این گره دو لیست با طول یکسان دریافت می‌کند و یک جای‌جای تصادفی (پرمیوتیشن) یکسان را به هر دو اعمال می‌کند و تضمین می‌کند که جفت‌های اصلی پس از برهم‌زدن حفظ شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `ویدیوها` | فهرستی از ویدیوها برای برهم‌زدن. | VIDEO | بله | فهرست موارد ویدیویی |
| `متن‌ها` | فهرستی از متون برای برهم‌زدن. | STRING | بله | فهرست رشته‌های متنی |
| `seed` | دانه تصادفی برای کنترل ترتیب برهم‌زدن (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
