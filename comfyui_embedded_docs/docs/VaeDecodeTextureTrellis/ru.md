# VaeDecodeTextureTrellis

Этот узел декодирует текстурный латент Trellis2 в цвета вокселей с помощью VAE. Входной латент содержит разреженные образцы признаков с координатами; узел восстанавливает цвет для каждого вокселя и возвращает результат в виде воксельной сетки, которую последующие узлы, такие как PaintMesh, могут использовать для окрашивания 3D-сетки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Текстурный латент для декодирования. Содержит признаки образцов и разреженные координаты, а также может включать необязательные метаданные, такие как количество координат, система координат модели и разрешение координат. | LATENT | Да | — |
| `vae` | VAE Trellis2, используемый для декодирования текстурного латента в цвета вокселей. | VAE | Да | — |
| `shape_subdivides` | Информация о форме, используемая для управления реконструкцией с более высокой детализацией во время декодирования. Помогает сохранять согласованность структуры при более высоких разрешениях. | SHAPE_SUBDIVIDES | Да | — |

Примечание: если латент `samples` содержит количество координат, эти значения должны быть неотрицательными, их сумма должна совпадать с числом строк координат, и каждый пакет должен содержать ровно ожидаемое количество строк; в противном случае узел выдаёт ошибку. Если система координат модели латента — "z_up", декодированные координаты вокселей преобразуются в Y-up, чтобы они совпадали с вершинами сетки. Если указано разрешение координат, разрешение выходной текстуры равно этому значению, умноженному на 16; в противном случае оно определяется по наибольшей координате вокселя и округляется вверх до одного из значений 256, 512, 1024, 1536 или 2048 (1024, если координаты недоступны).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `voxel_colors` | Декодированные данные вокселей, содержащие координаты, цветовые признаки и разрешение текстуры. Каждый воксель имеет 6 цветовых каналов: базовый цвет (RGB), металличность, шероховатость и альфа, все в диапазоне [0, 1]. Потребители вершинных цветов, такие как PaintMesh, используют первые 3 канала. | VOXEL |
