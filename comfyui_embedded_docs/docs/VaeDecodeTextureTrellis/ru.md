# VaeDecodeTextureTrellis

Этот узел декодирует латент текстуры Trellis2 в цвета вокселей с помощью VAE. Входной латент содержит разреженные сэмплы признаков с координатами; узел восстанавливает цвет для каждого вокселя и возвращает результат в виде воксельной сетки, которую последующие узлы, такие как PaintMesh, могут использовать для раскрашивания 3D-меша.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Латент текстуры для декодирования. Содержит признаки сэмплов и разреженные координаты, а также может включать необязательные метаданные, такие как количество координат (`coord_counts`), система координат модели (`model_frame`, по умолчанию: "y_up") и разрешение координат (`coord_resolution`). | LATENT | Да | — |
| `vae` | Trellis2 VAE, используемый для декодирования латента текстуры в цвета вокселей. | VAE | Да | — |
| `shape_subdivides` | Информация о форме, используемая для управления восстановлением с более высокой детализацией во время декодирования. Помогает сохранять согласованность структуры при более высоких разрешениях. | SHAPE_SUBDIVIDES | Да | — |

Примечание. Если латент `samples` содержит `coord_counts`, значения счётчиков должны быть неотрицательными, их сумма должна совпадать с числом строк координат, и каждый батч должен содержать ровно ожидаемое число строк; в противном случае узел выдаёт ошибку. Если `model_frame` латента равен "z_up", декодированные координаты вокселей переназначаются в Y-up, чтобы они совпадали с вершинами меша. Если указан `coord_resolution`, выходное разрешение текстуры равно этому значению, умноженному на 16. В противном случае оно выводится из наибольшей координаты вокселя плюс один, округляется вверх до одного из значений 256, 512, 1024, 1536 или 2048; если требуемое значение превышает 2048, используется это большее значение. Если координаты недоступны, разрешение по умолчанию равно 1024.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `voxel_colors` | Декодированные данные вокселей, содержащие координаты, цветовые признаки и разрешение текстуры. Каждый воксель имеет 6 цветовых каналов: базовый цвет (RGB), металличность, шероховатость и альфа, все в диапазоне [0, 1]. Потребители вершинных цветов, такие как PaintMesh, используют первые 3 канала. | VOXEL |
