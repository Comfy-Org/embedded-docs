# VaeDecodeTextureTrellis

此節點使用 VAE 將 Trellis2 紋理潛在變量解碼為體素顏色。輸入的潛在變量包含帶有座標的稀疏特徵樣本；節點會重建每個體素的顏色，並將結果以體素網格形式返回，供下游節點（如 PaintMesh）用於為 3D 網格著色。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 要解碼的紋理潛在變量。它包含樣本特徵和稀疏座標，並可能包含選用的中繼資料，例如座標計數、模型座標系和座標解析度。 | LATENT | 是 | — |
| `vae` | 用於將紋理潛在變量解碼為體素顏色的 Trellis2 VAE。 | VAE | 是 | — |
| `shape_subdivides` | 用於在解碼過程中引導高細節重建的形狀資訊。有助於在較高解析度下保持結構一致性。 | SHAPE_SUBDIVIDES | 是 | — |

注意：當 `samples` 潛在變量包含座標計數時，計數必須為非負數，其總和必須等於座標列數，且每個批次必須恰好具有預期的列數；否則節點會引發錯誤。如果潛在變量的模型座標系為 "z_up"，則解碼後的體素座標會重新對應至 Y-up，以便與網格頂點對齊。若提供了座標解析度，則輸出紋理解析度為該數值乘以 16；否則會從最大的體素座標推斷，並無條件進位至 256、512、1024、1536 或 2048 其中之一（若無可用座標則為 1024）。

## 輸出

| 輸出名 | 描述 | 資料類型 |
|-------------|-------------|-----------|
