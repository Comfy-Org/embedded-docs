# VaeDecodeTextureTrellis

此節點使用 VAE 將 Trellis2 紋理潛在空間（latent）解碼為體素顏色。輸入的潛在空間包含帶有座標的稀疏特徵樣本；此節點會重建每個體素的顏色，並將結果以體素網格的形式回傳，下游節點（例如 PaintMesh）可使用該網格來為 3D 模型上色。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `樣本` | 待解碼的紋理潛在空間。它包含樣本特徵與稀疏座標，並可能包含選用中繼資料，例如座標數量、模型框架（model frame）與座標解析度。 | LATENT | 是 | — |
| `vae` | 用於將紋理潛在空間解碼為體素顏色的 Trellis2 VAE。 | VAE | 是 | — |
| `形狀細分` | 用於在解碼過程中引導更高細節重建的形狀資訊。有助於在較高解析度下保持結構一致性。 | SHAPE_SUBDIVIDES | 是 | — |

注意：當 `samples` 潛在空間包含座標數量時，這些數量必須為非負數，其總數必須與座標列數相符，且每個批次必須正好包含預期的列數；否則節點會引發錯誤。如果潛在空間的模型框架為 "z_up"，解碼後的體素座標會重新對應至 Y-up，以便與網格頂點對齊。當提供座標解析度時，輸出紋理解析度為該數值乘以 16；否則會從最大的體素座標推斷，並無條件進位至 256、512、1024、1536 或 2048 其中之一（若沒有可用座標則為 1024）。

## 輸出
