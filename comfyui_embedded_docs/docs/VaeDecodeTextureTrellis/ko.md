# VaeDecodeTextureTrellis

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 디코딩할 텍스처 잠재(latent)입니다. 샘플 피처와 희소 좌표를 포함하며, 좌표 개수, 모델 프레임, 좌표 해상도와 같은 선택적 메타데이터도 포함할 수 있습니다. | LATENT | 예 | — |
| `vae` | 텍스처 잠재(latent)를 복셀 색상으로 디코딩하는 데 사용되는 Trellis2 VAE입니다. | VAE | 예 | — |
| `shape_subdivides` | 디코딩 중 더 높은 세부 묘사 재구성을 안내하는 데 사용되는 형태 정보입니다. 더 높은 해상도에서 구조 일관성을 유지하는 데 도움이 됩니다. | SHAPE_SUBDIVIDES | 예 | — |

참고: `samples` 잠재(latent)에 좌표 개수가 포함된 경우, 개수는 0 이상이어야 하며 총합은 좌표 행 수와 일치해야 하고 각 배치에는 정확히 예상된 수의 행이 있어야 합니다. 그렇지 않으면 노드가 오류를 발생시킵니다. 잠재(latent)의 모델 프레임이 "z_up"이면 디코딩된 복셀 좌표는 메시 정점과 정렬되도록 Y-up으로 다시 매핑됩니다. 좌표 해상도가 제공되면 출력 텍스처 해상도는 해당 값에 16을 곱한 값입니다. 그렇지 않으면 가장 큰 복셀 좌표에서 추론되며 256, 512, 1024, 1536 또는 2048 중 하나로 올림됩니다(사용 가능한 좌표가 없으면 1024).

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `voxel_colors` | 좌표, 색상 피처, 텍스처 해상도를 포함하는 디코딩된 복셀 데이터입니다. 각 복셀에는 베이스 컬러(RGB), 메탈릭, 러프니스, 알파의 6개 색상 채널이 있으며 모든 값은 [0, 1] 범위입니다. PaintMesh와 같은 정점 색상 소비자는 처음 3개 채널을 사용합니다. | VOXEL |
