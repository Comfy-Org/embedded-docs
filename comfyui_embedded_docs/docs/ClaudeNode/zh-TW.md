### 參數限制

- **影像數量限制：** 每個請求最多可提供 20 張影像。連接超過 20 張影像會觸發錯誤。
- **提示詞必填：** 提示詞必須包含至少一個非空白字元。空白提示詞會觸發驗證錯誤。
- **溫度處理：** 當啟用思考時，Anthropic API 要求不設定溫度（預設為 1.0）。Opus 5、Opus 4.8、Fable 5 與 Sonnet 5 不提供溫度參數。Opus 4.7 會忽略 `temperature`，任何將 `reasoning_effort` 設為 `"low"`、`"medium"` 或 `"high"` 的模型也會忽略它。
- **推理/思考行為：** `reasoning_effort` 設定控制是否啟用思考。Opus 5 與 Fable 5 一律啟用推理。Haiku 4.5 不支援推理。當啟用思考時，節點會為選取的模型使用適當的思考模式，可能是自適應（adaptive）或基於預算（budget-based）。在預算模式中，推理 token 預算會設上限，以便為實際回應保留至少 1024 個 token。
- **安全性拒絕：** 如果 Claude 因安全考量拒絕回應請求，節點會拋出錯誤，要求您改寫提示詞或嘗試不同的模型。
- **輸出文字：** 輸出中不包含思考與推理區塊；僅回傳產生的文字。
