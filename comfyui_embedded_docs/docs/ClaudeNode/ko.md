# Anthropic Claude

Anthropic Claude 모델에서 텍스트 응답을 생성합니다. 이 노드는 텍스트 프롬프트와 선택적 이미지를 Claude 모델에 전송하고 생성된 텍스트 응답을 반환합니다.

## 입력

`model` 매개변수는 동적 선택기입니다. 모델을 선택하면 토큰 한도, 온도, 추론 노력과 같은 모델별 추가 설정이 그 아래에 표시됩니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 모델에 전달할 텍스트 입력입니다. 공백을 제거한 후에도 비어 있지 않아야 합니다. (기본값: 빈 문자열) | STRING | 예 | N/A |
| `model` | 응답 생성에 사용되는 Claude 모델입니다. | DYNAMIC_COMBO | 예 | `"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 0) | INT | 예 | 0 to 2147483647 |
| `images` | 모델의 컨텍스트로 사용할 선택적 이미지입니다. 확장 가능한 슬롯: `image_1`부터 `image_20`까지 연결할 수 있으며 최대 20개의 이미지를 지원합니다. (기본값: 없음) | IMAGE | 아니요 | 0 to 20 images |
| `system_prompt` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: 빈 문자열) | STRING | 아니요 | N/A |

### Opus 5 및 Fable 5 입력

Opus 5 및 Fable 5 모델에 공통으로 적용됩니다. 이 모델들은 항상 확장 사고(extended thinking)를 사용하며 온도 설정을 노출하지 않습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다(활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 to 64000 |
| `reasoning_effort` | 확장 사고 노력 수준입니다. 이 모델에서는 추론이 항상 활성화됩니다. (기본값: "high") | COMBO | 예 | `"low"`<br>`"medium"`<br>`"high"` |

### Opus 4.8 및 Sonnet 5 입력

Opus 4.8 및 Sonnet 5 모델에 공통으로 적용됩니다. 이 모델들은 온도 설정을 노출하지 않습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다(활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 to 64000 |
| `reasoning_effort` | 확장 사고 노력 수준입니다. "off"는 추론을 비활성화합니다. (기본값: "off") | COMBO | 예 | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Opus 4.7, Opus 4.6, Sonnet 4.6 및 Sonnet 4.5 입력

Opus 4.7, Opus 4.6, Sonnet 4.6, Sonnet 4.5 모델에 공통으로 적용됩니다. Opus 4.7의 경우 온도 입력이 표시되지만 무시되며, API는 기본값 1.0을 사용합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다(활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 to 64000 |
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 1.0은 무작위성이 가장 높습니다. Opus 4.7 및 reasoning_effort가 설정된 모든 모델에서는 무시됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 1.0 (step 0.01) |
| `reasoning_effort` | 확장 사고 노력 수준입니다. "off"는 추론을 비활성화합니다. (기본값: "off") | COMBO | 예 | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Haiku 4.5 입력

이 모델은 확장 사고를 지원하지 않으므로 `reasoning_effort` 설정을 사용할 수 없습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다(활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 to 64000 |
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 1.0은 무작위성이 가장 높습니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 1.0 (step 0.01) |

### 매개변수 제약 조건

- 요청당 최대 20개의 이미지를 제공할 수 있습니다. 업로드된 이미지의 총 픽셀 수는 1568 × 1568 픽셀로 제한됩니다.
- Opus 5, Fable 5, Opus 4.8 및 Sonnet 5에서는 온도를 구성할 수 없습니다. 온도 입력을 사용할 수 있는 경우 Opus 4.7과 `reasoning_effort`가 "off" 이외의 값으로 설정된 모든 모델에서는 무시됩니다.
- Opus 5와 Fable 5에서는 추론이 항상 활성화되므로 이 모델들의 `reasoning_effort` 옵션에는 "off"가 포함되지 않습니다. Haiku 4.5 모델은 확장 사고를 지원하지 않으므로 `reasoning_effort` 설정이 없습니다.
- Claude가 안전상의 이유로 요청에 응답하지 않으면 노드는 텍스트를 반환하는 대신 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Claude 모델에서 생성된 텍스트 응답입니다. 표시 가능한 텍스트가 생성되지 않으면 출력은 `"Empty response from Claude model."`입니다. 사고(thinking) 또는 추론(reasoning) 블록은 출력에 포함되지 않습니다. | STRING |
