# Anthropic Claude

Генерирует текстовые ответы с помощью моделей Claude от Anthropic. Укажите текстовый запрос и, при необходимости, одно или несколько изображений для мультимодального контекста; узел вернёт сгенерированный моделью текстовый ответ.

## Входы

Входы сгруппированы в общие настройки, настройки для конкретной модели, которые появляются при выборе модели, и необязательные эталонные изображения.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Claude, используемая для генерации ответа. При выборе модели ниже отображаются настройки, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"Opus 5.5"`<br>`"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5.1"`<br>`"Fable 5"`<br>`"Sonnet 5.5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `prompt` | Текстовый ввод для модели. (по умолчанию: пустая строка) | STRING | Да | N/A |
| `seed` | `seed` управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от `seed`. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Основополагающие инструкции, определяющие поведение модели. (по умолчанию: пустая строка) | STRING | Нет | N/A |

### Входы Opus 5.5, Opus 5, Fable 5.1 и Fable 5

Эти четыре модели используют одинаковые настройки. Они не предоставляют настройку temperature, и рассуждения всегда включены.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | от 1024 до 64000 (Opus 5.5)<br>от 4096 до 64000 (Opus 5, Fable 5.1, Fable 5) |
| `reasoning_effort` | Усилие расширенного мышления. Рассуждения всегда включены для этой модели. (по умолчанию: "high") | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |

### Входы Opus 4.8, Sonnet 5.5 и Sonnet 5

Эти три модели используют одинаковые настройки. Они не предоставляют настройку temperature.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | от 1024 до 64000 (Sonnet 5.5)<br>от 4096 до 64000 (Opus 4.8, Sonnet 5) |
| `reasoning_effort` | Усилие расширенного мышления. `"off"` отключает рассуждения. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |

### Входы Opus 4.7, Opus 4.6, Sonnet 4.6 и Sonnet 4.5

Эти четыре модели используют одинаковые настройки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминированный результат, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда задан `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `reasoning_effort` | Усилие расширенного мышления. `"off"` отключает рассуждения. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

`reasoning_effort` предлагает `"off"`, `"low"`, `"medium"` и `"high"` для всех четырёх моделей. Opus 4.7, Opus 4.6 и Sonnet 4.6 дополнительно принимают `"max"`, а Opus 4.7 также принимает `"xhigh"`.

### Входы Haiku 4.5

Эта модель не предоставляет настройку `reasoning_effort`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминированный результат, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда задан `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные изображения для использования в качестве контекста для модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов (`image_1` ... `image_20`). | IMAGE | Нет | от 0 до 20 изображений |

### Ограничения параметров

- **Ограничение на изображения:** За один запрос можно предоставить максимум 20 изображений. Подключение более 20 изображений вызывает ошибку.
- **Обязательный `prompt`:** `prompt` должен содержать хотя бы один непробельный символ. Пустой `prompt` вызывает ошибку валидации.
- **Обработка temperature:** Когда мышление включено, Anthropic API требует, чтобы temperature была не задана (по умолчанию она равна 1.0). Opus 5.5, Opus 5, Opus 4.8, Fable 5.1, Fable 5, Sonnet 5.5 и Sonnet 5 не предоставляют настройку temperature. Opus 4.7 игнорирует `temperature`, и любая модель, у которой `reasoning_effort` установлен в значение, отличное от `"off"`, также игнорирует её.
- **Поведение рассуждений/мышления:** Настройка `reasoning_effort` управляет тем, включено ли мышление. В Opus 5.5, Opus 5, Fable 5.1 и Fable 5 рассуждения всегда включены. Haiku 4.5 не поддерживает рассуждения. Когда мышление включено, узел использует подходящий режим мышления для выбранной модели: адаптивный или основанный на бюджете. В режиме бюджета бюджет токенов рассуждений ограничивается так, чтобы оставить не менее 1024 токенов для фактического ответа. Когда `reasoning_effort` установлен в `"off"` для Sonnet 5.5, запрос использует мышление `between_tools` вместо отключённого мышления, поэтому ответ всё равно не содержит рассуждений.
- **Минимум `max_tokens`:** `max_tokens` принимает значения от 1024 для Opus 5.5 и Sonnet 5.5 и от 4096 для всех остальных моделей.
- **Отказ по соображениям безопасности:** Если Claude отказывается отвечать на запрос по соображениям безопасности, узел вызывает ошибку с предложением переформулировать prompt или попробовать другую модель.
- **Выходной текст:** Блоки мышления и рассуждений не включаются в выходные данные; возвращается только сгенерированный текст.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Claude. Блоки мышления/рассуждений не включаются. Если текст не сгенерирован, возвращается "Empty response from Claude model." | STRING |
