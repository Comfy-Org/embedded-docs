# Anthropic Claude

Генерирует текстовые ответы с помощью моделей Claude от Anthropic. Укажите текстовый запрос и, при необходимости, одно или несколько изображений для мультимодального контекста, и узел вернёт сгенерированный моделью текстовый ответ.

## Входы

Входы сгруппированы в общие настройки, настройки, специфичные для модели, которые появляются при выборе модели, и необязательные эталонные изображения.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Claude, используемая для генерации ответа. При выборе модели ниже отображаются настройки, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"Opus 5.5"`<br>`"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5.1"`<br>`"Fable 5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `prompt` | Текстовый ввод для модели. (по умолчанию: пустая строка) | STRING | Да | Н/Д |
| `seed` | `seed` управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от значения `seed`. (по умолчанию: 0) | INT | Да | 0–2147483647 |
| `system_prompt` | Основополагающие инструкции, определяющие поведение модели. (по умолчанию: пустая строка) | STRING | Нет | Н/Д |

### Входы Opus 5.5, Opus 5, Fable 5.1 и Fable 5

Эти четыре модели используют одни и те же настройки. Они не предоставляют настройку температуры, и рассуждение всегда включено.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | 4096–64000 |
| `reasoning_effort` | Усилие расширенного мышления. Для этой модели рассуждение всегда включено. (по умолчанию: "high") | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |

### Входы Opus 4.8 и Sonnet 5

Эти две модели используют одни и те же настройки. Они не предоставляют настройку температуры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | 4096–64000 |
| `reasoning_effort` | Усилие расширенного мышления. `"off"` отключает рассуждение. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |

### Входы Opus 4.7, Opus 4.6, Sonnet 4.6 и Sonnet 4.5

Эти четыре модели используют одни и те же настройки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | 4096–64000 |
| `temperature` | Управляет степенью случайности. 0.0 — детерминированный результат, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда задан `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | 0.0–1.0 (шаг: 0.01) |
| `reasoning_effort` | Усилие расширенного мышления. `"off"` отключает рассуждение. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

`reasoning_effort` поддерживает `"off"`, `"low"`, `"medium"` и `"high"` для всех четырёх моделей. Opus 4.7, Opus 4.6 и Sonnet 4.6 дополнительно принимают `"max"`, а Opus 4.7 также принимает `"xhigh"`.

### Входы Haiku 4.5

Эта модель не предоставляет настройку `reasoning_effort`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включает токены рассуждений, когда они включены). (по умолчанию: 32768) | INT | Да | 4096–64000 |
| `temperature` | Управляет степенью случайности. 0.0 — детерминированный результат, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда задан `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | 0.0–1.0 (шаг: 0.01) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные изображения, используемые в качестве контекста для модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов (`image_1` ... `image_20`). | IMAGE | Нет | 0–20 изображений |

### Ограничения параметров

- **Ограничение изображений:** За один запрос можно передать не более 20 изображений. Подключение более 20 изображений вызывает ошибку.
- **Обязательность запроса:** Запрос должен содержать хотя бы один непробельный символ. Пустой запрос вызывает ошибку валидации.
- **Обработка температуры:** Когда мышление включено, API Anthropic требует, чтобы температура была не задана (по умолчанию она равна 1.0). Opus 5.5, Opus 5, Opus 4.8, Fable 5.1, Fable 5 и Sonnet 5 не предоставляют настройку температуры. Opus 4.7 игнорирует `temperature`, а любая модель, у которой `reasoning_effort` установлен в значение, отличное от `"off"`, также игнорирует её.
- **Поведение рассуждения/мышления:** Настройка `reasoning_effort` управляет тем, включено ли мышление. У Opus 5.5, Opus 5, Fable 5.1 и Fable 5 рассуждение всегда включено. Haiku 4.5 не поддерживает рассуждение. Когда мышление включено, узел использует подходящий режим мышления для выбранной модели — адаптивный или основанный на бюджете. В режиме бюджета бюджет токенов рассуждения ограничивается так, чтобы оставить как минимум 1024 токена для фактического ответа.
- **Отказ по соображениям безопасности:** Если Claude отказывается отвечать на запрос по соображениям безопасности, узел вызывает ошибку с предложением переформулировать запрос или попробовать другую модель.
- **Выходной текст:** Блоки мышления и рассуждения не включаются в вывод; возвращается только сгенерированный текст.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ модели Claude. Блоки мышления/рассуждения не включаются. Если текст не сгенерирован, возвращает "Empty response from Claude model." | STRING |
