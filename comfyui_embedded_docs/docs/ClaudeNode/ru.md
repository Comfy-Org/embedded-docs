# Anthropic Claude

Генерирует текстовые ответы с помощью модели Anthropic Claude. Этот узел отправляет текстовый запрос и необязательные изображения в модель Claude и возвращает сгенерированный текстовый ответ.

## Входные параметры

Параметр `model` — динамический селектор: при выборе модели под ним появляются дополнительные настройки, зависящие от модели, такие как лимит токенов, температура и уровень рассуждений.

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый ввод для модели. Должен быть непустым после удаления пробельных символов. (по умолчанию: пустая строка) | STRING | Да | N/A |
| `model` | Модель Claude, используемая для генерации ответа. | DYNAMIC_COMBO | Да | `"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `seed` | Seed управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Да | 0 to 2147483647 |
| `images` | Необязательные изображения для использования в качестве контекста для модели. Расширяемый слот: подключайте `image_1`–`image_20`; до 20 изображений. (по умолчанию: нет) | IMAGE | Нет | 0 to 20 images |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: пустая строка) | STRING | Нет | N/A |

### Входные параметры Opus 5 и Fable 5

Общие для Opus 5 и Fable 5. Эти модели всегда используют расширенное мышление и не предоставляют настройку температуры.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждений, если они включены). (по умолчанию: 32768) | INT | Да | 4096 to 64000 |
| `reasoning_effort` | Уровень усилий расширенного мышления. Для этой модели рассуждения всегда включены. (по умолчанию: "high") | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |

### Входные параметры Opus 4.8 и Sonnet 5

Общие для Opus 4.8 и Sonnet 5. Эти модели не предоставляют настройку температуры.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждений, если они включены). (по умолчанию: 32768) | INT | Да | 4096 to 64000 |
| `reasoning_effort` | Уровень усилий расширенного мышления. Значение "off" отключает рассуждения. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Входные параметры Opus 4.7, Opus 4.6, Sonnet 4.6 и Sonnet 4.5

Общие для Opus 4.7, Opus 4.6, Sonnet 4.6 и Sonnet 4.5. Для Opus 4.7 поле температуры отображается, но игнорируется, а API использует значение по умолчанию 1.0.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждений, если они включены). (по умолчанию: 32768) | INT | Да | 4096 to 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминированный результат, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, если задан `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 1.0 (step 0.01) |
| `reasoning_effort` | Уровень усилий расширенного мышления. Значение "off" отключает рассуждения. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Входные параметры Haiku 4.5

Эта модель не поддерживает расширенное мышление, поэтому параметр `reasoning_effort` недоступен.

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждений, если они включены). (по умолчанию: 32768) | INT | Да | 4096 to 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминированный результат, 1.0 — максимальная случайность. (по умолчанию: 1.0) | FLOAT | Да | 0.0 to 1.0 (step 0.01) |

### Ограничения параметров

- В одном запросе можно передать до 20 изображений. Общее количество пикселей загружаемых изображений ограничено 1568 × 1568 пикселей.
- Температура не настраивается для Opus 5, Fable 5, Opus 4.8 и Sonnet 5. Когда поле температуры доступно, оно игнорируется для Opus 4.7 и для любой модели, если `reasoning_effort` установлен в значение, отличное от "off".
- Рассуждения всегда включены для Opus 5 и Fable 5, поэтому варианты `reasoning_effort` для этих моделей не включают "off". Модель Haiku 4.5 не поддерживает расширенное мышление и поэтому не имеет параметра `reasoning_effort`.
- Если Claude отказывается отвечать на запрос по соображениям безопасности, узел вызывает ошибку вместо возврата текста.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ модели Claude. Если видимый текст не сгенерирован, на выходе будет `"Empty response from Claude model."`. Блоки мышления или рассуждений не включаются в выходные данные. | STRING |
