# Anthropic Claude

Generate text responses from Anthropic's Claude models. Provide a text prompt and optionally one or more images for multimodal context, and the node returns the model's generated text response.

## Входы

Входы сгруппированы в общие настройки, настройки конкретной модели, которые появляются при выборе модели, и необязательные эталонные изображения.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Claude, используемая для генерации ответа. Выбор модели отображает настройки конкретной модели ниже. | DYNAMIC_COMBO | Да | `"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `prompt` | Текстовый ввод для модели. (по умолчанию: пустая строка) | STRING | Да | N/A |
| `seed` | Сид управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от сида. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `system_prompt` | Базовые инструкции, определяющие поведение модели. (по умолчанию: пустая строка) | STRING | Нет | N/A |

### Входы Opus 5 и Fable 5

Эти две модели имеют одинаковые настройки. Они не предоставляют настройку температуры, и рассуждение всегда включено.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждения, если они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `reasoning_effort` | Уровень расширенного мышления. Рассуждение всегда включено для этой модели. (по умолчанию: "high") | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |

### Входы Opus 4.8 и Sonnet 5

Эти две модели имеют одинаковые настройки. Они не предоставляют настройку температуры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждения, если они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `reasoning_effort` | Уровень расширенного мышления. `"off"` отключает рассуждение. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Входы Opus 4.7, Opus 4.6, Sonnet 4.6 и Sonnet 4.5

Эти четыре модели имеют одинаковые настройки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждения, если они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминировано, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда установлен `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |
| `reasoning_effort` | Уровень расширенного мышления. `"off"` отключает рассуждение. (по умолчанию: "off") | COMBO | Да | `"off"`<br>`"low"`<br>`"medium"`<br>`"high"` |

### Входы Haiku 4.5

Эта модель не предоставляет настройку `reasoning_effort`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | Максимальное количество токенов для генерации (включая токены рассуждения, если они включены). (по умолчанию: 32768) | INT | Да | от 4096 до 64000 |
| `temperature` | Управляет случайностью. 0.0 — детерминировано, 1.0 — максимальная случайность. Игнорируется для Opus 4.7 и любой модели, когда установлен `reasoning_effort`. (по умолчанию: 1.0) | FLOAT | Да | от 0.0 до 1.0 (шаг: 0.01) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные изображения для использования в качестве контекста для модели. До 20 изображений. Расширяемый слот: подключите от 1 до 20 элементов (`image_1` ... `image_20`). | IMAGE | Нет | от 0 до 20 изображений |

### Ограничения параметров

- **Лимит изображений:** Максимум 20 изображений можно передать за один запрос. Подключение более 20 изображений вызывает ошибку.
- **Требование к запросу:** Запрос должен содержать хотя бы один непробельный символ. Пустой запрос вызывает ошибку валидации.
- **Обработка температуры:** Когда мышление включено, Anthropic API требует, чтобы температура не была задана (по умолчанию она равна 1.0). Opus 5, Opus 4.8, Fable 5 и Sonnet 5 не предоставляют настройку температуры. Opus 4.7 игнорирует `temperature`, и любая модель с `reasoning_effort`, установленным на `"low"`, `"medium"` или `"high"`, также игнорирует её.
- **Поведение рассуждения/мышления:** Настройка `reasoning_effort` управляет включением мышления. Opus 5 и Fable 5 всегда имеют включённое рассуждение. Haiku 4.5 не поддерживает рассуждение. Когда мышление включено, узел использует соответствующий режим мышления для выбранной модели: адаптивный или основанный на бюджете. В бюджетном режиме бюджет токенов рассуждения ограничивается, чтобы оставить не менее 1024 токенов для фактического ответа.
- **Отказ по соображениям безопасности:** Если Claude отказывается отвечать на запрос по соображениям безопасности, узел выдаёт ошибку с просьбой переформулировать запрос или попробовать другую модель.
- **Выходной текст:** Блоки мышления и рассуждений не включаются в выходные данные; возвращается только сгенерированный текст.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ модели Claude. Блоки мышления/рассуждений не включены. Если текст не сгенерирован, возвращается «Empty response from Claude model». | STRING |
