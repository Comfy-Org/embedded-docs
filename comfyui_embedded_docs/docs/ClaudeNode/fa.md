# Anthropic Claude

تولید پاسخ‌های متنی از مدل‌های Claude شرکت Anthropic. یک prompt متنی و به‌صورت اختیاری یک یا چند تصویر برای زمینه چندوجهی ارائه دهید، و گره پاسخ متنی تولیدشده توسط مدل را برمی‌گرداند.

## ورودی‌ها

ورودی‌ها به تنظیمات مشترک، تنظیمات مخصوص مدل که هنگام انتخاب یک مدل ظاهر می‌شوند، و تصاویر مرجع اختیاری گروه‌بندی شده‌اند.

### ورودی‌های Opus 4.7، Opus 4.6، Sonnet 4.6 و Sonnet 4.5

این چهار مدل تنظیمات یکسانی دارند.

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | حداکثر تعداد توکن برای تولید (شامل توکن‌های استدلال هنگام فعال بودن). (پیش‌فرض: 32768) | INT | بله | 4096 تا 64000 |
| `temperature` | میزان تصادفی‌بودن را کنترل می‌کند. 0.0 قطعی است، 1.0 بیشترین تصادفی‌بودن است. برای Opus 4.7 و هر مدلی که `reasoning_effort` برای آن تنظیم شده باشد نادیده گرفته می‌شود. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 (گام: 0.01) |

`reasoning_effort` روی هر چهار مدل مقادیر `"off"`، `"low"`، `"medium"` و `"high"` را ارائه می‌دهد. Opus 4.7، Opus 4.6 و Sonnet 4.6 علاوه بر این `"max"` را نیز می‌پذیرند، و Opus 4.7 همچنین `"xhigh"` را می‌پذیرد.

| پارامتر | توضیح | نوع داده | الزامی | محدوده |

| `تصاویر` | تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. حداکثر 20 تصویر. جایگاه قابل گسترش: 1 تا 20 مورد را متصل کنید (`image_1` ... `image_20`). | IMAGE | خیر | 0 تا 20 تصویر |

### محدودیت‌های پارامتر

- **محدودیت تصویر:** حداکثر 20 تصویر را می‌توان در هر درخواست ارائه کرد. اتصال بیش از 20 تصویر باعث بروز خطا می‌شود.
- **الزامی بودن `prompt`:** `prompt` باید حداقل شامل یک نویسه غیرفاصله باشد. یک prompt خالی باعث خطای اعتبارسنجی می‌شود.
- **مدیریت temperature:** وقتی تفکر فعال است، API آنتروپیک نیاز دارد که temperature تنظیم نشده باشد (به‌صورت پیش‌فرض 1.0 است). Opus 5.5، Opus 5، Opus 4.8، Fable 5.1، Fable 5 و Sonnet 5 تنظیم temperature را ارائه نمی‌دهند. Opus 4.7 مقدار `temperature` را نادیده می‌گیرد، و هر مدلی که `reasoning_effort` آن روی مقداری غیر از `"off"` تنظیم شده باشد نیز آن را نادیده می‌گیرد.
- **رفتار استدلال/تفکر:** تنظیم `reasoning_effort` کنترل می‌کند که تفکر فعال باشد یا نه. Opus 5.5، Opus 5، Fable 5.1 و Fable 5 همیشه استدلال فعال دارند. Haiku 4.5 از استدلال پشتیبانی نمی‌کند. وقتی تفکر فعال است، گره از حالت تفکر مناسب برای مدل انتخاب‌شده استفاده می‌کند، یا تطبیقی یا مبتنی بر بودجه. در حالت بودجه، بودجه توکن استدلال محدود می‌شود تا حداقل 1024 توکن برای پاسخ واقعی باقی بماند.
- **امتناع به دلایل ایمنی:** اگر Claude به دلایل ایمنی از پاسخ دادن به درخواست امتناع کند، گره خطایی ایجاد می‌کند و از شما می‌خواهد که prompt را بازنویسی کنید یا مدل دیگری را امتحان کنید.
- **متن خروجی:** بلوک‌های تفکر و استدلال در خروجی گنجانده نمی‌شوند؛ فقط متن تولیدشده بازگردانده می‌شود.
