# Anthropic Claude

پاسخ‌های متنی را از مدل‌های Claude شرکت Anthropic تولید کنید. یک پرامپت متنی و به‌صورت اختیاری یک یا چند تصویر برای زمینه چندوجهی ارائه دهید، و گره پاسخ متنی تولیدشدهٔ مدل را برمی‌گرداند.

## ورودی‌ها

ورودی‌ها در قالب تنظیمات مشترک، تنظیمات مخصوص مدل که هنگام انتخاب یک مدل نمایش داده می‌شوند، و تصاویر مرجع اختیاری گروه‌بندی شده‌اند.

### محدودیت‌های پارامترها

- **حد تصویر:** حداکثر 20 تصویر می‌توان در هر درخواست ارائه کرد. اتصال بیش از 20 تصویر خطا ایجاد می‌کند.
- **الزامی بودن پرامپت:** پرامپت باید حداقل یک نویسه غیر از فاصله داشته باشد. پرامپت خالی خطای اعتبارسنجی ایجاد می‌کند.
- **مدیریت temperature:** وقتی تفکر فعال است، API شرکت Anthropic نیاز دارد که temperature تنظیم نشده باشد (به‌طور پیش‌فرض 1.0 است). Opus 5.5، Opus 5، Opus 4.8، Fable 5.1، Fable 5، Sonnet 5.5 و Sonnet 5 تنظیم temperature را ارائه نمی‌دهند. Opus 4.7 مقدار `temperature` را نادیده می‌گیرد، و هر مدلی که `reasoning_effort` آن روی مقداری غیر از `"off"` تنظیم شده باشد نیز آن را نادیده می‌گیرد.
- **رفتار استدلال/تفکر:** تنظیم `reasoning_effort` کنترل می‌کند که آیا تفکر فعال است یا نه. Opus 5.5، Opus 5، Fable 5.1 و Fable 5 همیشه استدلال فعال دارند. Haiku 4.5 از استدلال پشتیبانی نمی‌کند. وقتی تفکر فعال است، گره از حالت تفکر مناسب برای مدل انتخاب‌شده استفاده می‌کند، یا تطبیقی (adaptive) یا مبتنی بر بودجه (budget-based). در حالت بودجه، بودجه توکن استدلال محدود می‌شود تا حداقل 1024 توکن برای پاسخ واقعی باقی بماند. وقتی `reasoning_effort` روی `"off"` در Sonnet 5.5 باشد، درخواست به‌جای تفکر غیرفعال از تفکر `between_tools` استفاده می‌کند، بنابراین پاسخ همچنان هیچ استدلالی ندارد.
- **حداقل max_tokens:** `max_tokens` مقادیری از 1024 را در Opus 5.5 و Sonnet 5.5 می‌پذیرد، و از 4096 در سایر مدل‌ها.
- **امتناع ایمنی:** اگر Claude به دلایل ایمنی از پاسخ به درخواست امتناع کند، گره خطایی ایجاد می‌کند و از شما می‌خواهد پرامپت را بازنویسی کنید یا مدل دیگری را امتحان کنید.
- **متن خروجی:** بلوک‌های تفکر و استدلال در خروجی گنجانده نمی‌شوند؛ فقط متن تولیدشده برگردانده می‌شود.
