# Anthropic Claude

Anthropic Claude モデルからテキスト応答を生成します。このノードは、テキストプロンプトとオプションの画像を Claude モデルに送信し、生成されたテキスト応答を返します。

## 入力

`model` パラメータは動的セレクタです。モデルを選択すると、トークン上限、temperature、推論努力などのモデル固有の設定がその下に表示されます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | モデルへのテキスト入力です。空白を除去した後も空ではない必要があります。(デフォルト: 空文字列) | STRING | 必須 | N/A |
| `model` | 応答の生成に使用する Claude モデルです。 | DYNAMIC_COMBO | 必須 | `"Opus 5"`<br>`"Opus 4.8"`<br>`"Fable 5"`<br>`"Sonnet 5"`<br>`"Opus 4.7"`<br>`"Opus 4.6"`<br>`"Sonnet 4.6"`<br>`"Sonnet 4.5"`<br>`"Haiku 4.5"` |
| `seed` | `seed` はノードを再実行するかどうかを制御します。結果はシードの値に関係なく非決定的です。(デフォルト: 0) | INT | 必須 | 0 to 2147483647 |

Opus 5 と Fable 5 で共通です。これらのモデルは常に拡張思考を使用し、temperature 設定はありません。

| `max_tokens` | 生成するトークンの最大数です（有効な場合は推論トークンを含みます）。(デフォルト: 32768) | INT | 必須 | 4096 to 64000 |

### Opus 4.7、Opus 4.6、Sonnet 4.6、Sonnet 4.5 入力

Opus 4.7、Opus 4.6、Sonnet 4.6、Sonnet 4.5 で共通です。Opus 4.7 では、temperature 入力は表示されますが無視され、API はデフォルト値の 1.0 を使用します。

| `temperature` | ランダム性を制御します。0.0 は決定的、1.0 は最もランダムです。(デフォルト: 1.0) | FLOAT | 必須 | 0.0 to 1.0 (step 0.01) |

### パラメータの制約

- 1回のリクエストで最大20枚の画像を指定できます。アップロードする画像の合計ピクセル数は 1568 × 1568 ピクセルに制限されます。
- temperature は Opus 5、Fable 5、Opus 4.8、Sonnet 5 では設定できません。temperature 入力が利用できる場合でも、Opus 4.7 と、`reasoning_effort` が "off" 以外に設定されているすべてのモデルでは無視されます。
- 推論は Opus 5 と Fable 5 では常に有効なため、これらのモデルの `reasoning_effort` オプションには "off" は含まれません。Haiku 4.5 モデルは拡張思考をサポートしていないため、`reasoning_effort` 設定はありません。
- Claude が安全性の理由でリクエストへの回答を拒否した場合、ノードはテキストを返す代わりにエラーを発生させます。
