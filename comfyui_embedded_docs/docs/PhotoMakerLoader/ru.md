# Загрузчик PhotoMaker

Узел PhotoMakerLoader загружает модель PhotoMaker из доступных файлов моделей. Он считывает указанный файл модели и подготавливает ID-энкодер PhotoMaker для использования в задачах генерации изображений на основе идентичности. Этот узел помечен как экспериментальный и предназначен для тестирования.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `photomaker_model_name` | Имя файла модели PhotoMaker для загрузки. Доступные параметры определяются файлами моделей, присутствующими в папке `photomaker`. | COMBO | Да | Несколько доступных вариантов |

Примечание: выбранный файл модели должен существовать в папке `photomaker`. Узел вызывает ошибку, если указанный файл не найден.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `photomaker_model` | Загруженная модель PhotoMaker, содержащая ID-энкодер, готовая к использованию в операциях кодирования идентичности. | PHOTOMAKER |
