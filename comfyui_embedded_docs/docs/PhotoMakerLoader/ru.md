# Загрузчик PhotoMaker

Узел PhotoMakerLoader загружает модель PhotoMaker из доступных файлов моделей. Он считывает указанный файл модели и подготавливает ID-энкодер PhotoMaker для использования в задачах генерации изображений на основе идентичности. Этот узел помечен как экспериментальный и предназначен для целей тестирования.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `название_модели_photomaker` | Название файла модели PhotoMaker для загрузки. Доступные варианты определяются файлами моделей, присутствующими в папке `photomaker`. | COMBO | Да | Доступно несколько вариантов (динамически заполняется из папки `photomaker`) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `photomaker_model` | Загруженная модель PhotoMaker, содержащая ID-энкодер, готовая к использованию в операциях кодирования идентичности. | PHOTOMAKER |
