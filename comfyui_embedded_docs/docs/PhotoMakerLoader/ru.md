# Загрузчик PhotoMaker

Узел PhotoMakerLoader загружает модель PhotoMaker из доступных файлов моделей. Он читает выбранный файл, загружает веса ID-энкодера и подготавливает ID-энкодер PhotoMaker для использования в задачах генерации изображений на основе идентичности. Этот узел помечен как экспериментальный и предназначен для тестирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название_модели_photomaker` | Имя загружаемого файла модели PhotoMaker. Доступные варианты определяются файлами моделей, присутствующими в папке `photomaker`. | COMBO | Да | Доступно несколько вариантов (динамически заполняется из папки `photomaker`) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `photomaker_model` | Загруженная модель PhotoMaker, содержащая ID-энкодер и готовая к использованию в операциях кодирования идентичности. | PHOTOMAKER |
