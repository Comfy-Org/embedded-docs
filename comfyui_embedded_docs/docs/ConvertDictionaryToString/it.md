# ConvertDictionaryToString

Questo nodo converte un dizionario (una raccolta di coppie chiave-valore) in una stringa di testo in formato JSON. È possibile controllare il livello di indentazione per rendere l'output più leggibile o compatto.

## Input

| Parametro | Descrizione | Tipo di dati | Obbligatorio | Intervallo |
|-----------|-------------|--------------|--------------|------------|
| `dictionary` | Il dizionario da convertire in una stringa | DICT | Sì | - |
| `indent` | Spazi per livello di indentazione. 0 produce una stringa compatta su una sola riga (predefinito: 2) | INT | No | 0 to 8 |

## Output

| Nome output | Descrizione | Tipo di dati |
|-------------|-------------|--------------|
| `STRING` | Il dizionario convertito in una stringa formattata JSON | STRING |
