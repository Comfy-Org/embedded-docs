# המרת מילון למחרוזת

הצומת הזה ממיר מילון (אוסף של זוגות מפתח-ערך) למחרוזת טקסט בפורמט JSON. ניתן לשלוט ברמת ההזחה כדי להפוך את הפלט לקריא יותר או קומפקטי יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `dictionary` | המילון להמרה למחרוזת | DICT | כן | - |
| `indent` | רווחים לכל רמת הזחה. 0 מייצר מחרוזת קומפקטית בשורה אחת (ברירת מחדל: 2) | INT | לא | 0 to 8 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `STRING` | המילון שהומר למחרוזת בפורמט JSON | STRING |
