# Получить параметры IC-LoRA

Этот узел считывает метаданные из модели, загруженной с помощью LoRA, для извлечения параметров IC-LoRA, таких как коэффициент уменьшения эталонного изображения. Он выводит эти параметры в виде структурированного объекта, который можно подключить к узлу LTXVAddGuide, если LoRA требует особой обработки направляющих.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `iclora_model` | Прямой выход из LoRA Loader для конкретной IC-LoRA, из которой нужно извлечь метаданные. | MODEL | Да | N/A |

Примечание: Если в метаданных LoRA отсутствует запись `reference_downscale_factor`, узел выводит значение по умолчанию 1. Если запись присутствует, коэффициент округляется и устанавливается на минимальное значение 1.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `iclora_parameters` | Параметры IC-LoRA, извлечённые из метаданных LoRA (например, `reference_downscale_factor`). Подключите к LTXVAddGuide, если LoRA требует особой обработки направляющих. | IC_LORA_PARAMETERS |
