# Получить параметры IC-LoRA

## Обзор

Этот узел извлекает параметры IC-LoRA из метаданных модели, загруженной с LoRA. Он считывает метаданные safetensors, чтобы найти такие значения, как коэффициент понижения масштаба опорного изображения, и выводит их в виде структурированного объекта параметров, который можно подключить к узлу LTXVAddGuide для специальной обработки направляющих. Если метаданные отсутствуют или коэффициент понижения масштаба не может быть прочитан, значение по умолчанию равно 1; когда значение найдено, оно округляется и ограничивается минимумом 1.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `iclora_model` | Прямой выход из загрузчика LoRA для конкретной IC-LoRA, из метаданных которой нужно извлечь информацию. | MODEL | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `iclora_parameters` | Параметры IC-LoRA, извлеченные из метаданных LoRA (например, reference_downscale_factor). Подключите к LTXVAddGuide, если LoRA требует специальной обработки направляющих. | IC_LORA_PARAMETERS |
