# Reve 이미지 편집

Reve Image Edit 노드는 텍스트 설명을 기반으로 기존 이미지를 수정할 수 있게 합니다. Reve API를 사용하여 사용자의 지침을 해석하고 제공된 이미지에 요청된 변경 사항을 적용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 편집할 이미지입니다. | IMAGE | 예 | - |
| `edit_instruction` | 이미지 편집 방법에 대한 텍스트 설명입니다. 최대 2560자까지 입력할 수 있습니다. (기본값: "") | STRING | 예 | 1~2560자 |
| `model` | 편집에 사용할 모델 버전입니다. | DYNAMIC_COMBO | 예 | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `upscale` | 생성된 이미지를 업스케일합니다. 추가 비용이 발생할 수 있습니다. (기본값: "disabled") | DYNAMIC_COMBO | 아니요 | `"disabled"`<br>`"enabled"` |
| `remove_background` | 생성된 이미지에서 배경을 제거합니다. 추가 비용이 발생할 수 있습니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br>`false` |
| `seed` | 시드는 노드가 다시 실행되는지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 아니요 | 0~2147483647 |

### 모델 입력

`reve-edit@20250915` 및 `reve-edit-fast@20251030` 모델에서 공유됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model.aspect_ratio` | 출력 이미지의 종횡비입니다. `"auto"`로 설정하면 종횡비가 자동으로 결정됩니다. (기본값: "auto") | COMBO | 아니요 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `model.test_time_scaling` | 값이 높을수록 더 좋은 이미지를 생성하지만 더 많은 크레딧이 소모됩니다. (기본값: 1) | INT | 아니요 | 1~5 |

### 업스케일 입력

`upscale`이 `"enabled"`로 설정된 경우에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | 업스케일 배율(2x, 3x 또는 4x)입니다. (기본값: 2) | INT | 아니요 | 2~4 |

**참고:** `upscale.upscale_factor` 매개변수는 `upscale`이 `"enabled"`로 설정된 경우에만 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 지침에 따라 생성된 편집 이미지입니다. | IMAGE |

**참고:** 이 노드는 더 이상 사용되지 않는(deprecated) 것으로 표시되어 있습니다.
