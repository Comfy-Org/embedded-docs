# Reve Редактирование изображения

Узел Reve Image Edit изменяет существующее изображение на основе текстовой инструкции на естественном языке. Он отправляет входное изображение и вашу инструкцию в API Reve, который возвращает новое изображение с применёнными запрошенными изменениями.

## Входы

Селектор `model` определяет, какие входы, специфичные для модели, отображаются. Селектор `upscale` управляет доступностью поля коэффициента увеличения.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для редактирования. | IMAGE | Да | - |
| `edit_instruction` | Текстовое описание того, как отредактировать изображение. Максимум 2560 символов. | STRING | Да | - |
| `model` | Версия модели для использования при редактировании. | DYNAMIC_COMBO | Да | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `upscale` | Увеличить масштаб сгенерированного изображения. Может добавить дополнительную стоимость. (по умолчанию: "disabled") | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удалить фон с сгенерированного изображения. Может добавить дополнительную стоимость. (по умолчанию: False) | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | seed управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от значения seed. (по умолчанию: 0) | INT | Нет | 0 до 2147483647 |

### Входы модели (общие для `reve-edit@20250915` и `reve-edit-fast@20251030`)

Обе версии модели предоставляют одинаковые входы, специфичные для модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон выходного изображения. Если установлено значение "auto", соотношение сторон определяется автоматически. | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `test_time_scaling` | Расширенная опция. Более высокие значения дают лучшие изображения, но стоят больше кредитов. (по умолчанию: 1) | INT | Нет | 1 до 5 |

### Входы увеличения масштаба (когда `upscale` установлен в "enabled")

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | Коэффициент увеличения (2x, 3x или 4x). (по умолчанию: 2) | INT | Нет | 2 до 4 |

**Примечание:**

- `upscale.upscale_factor` применяется только когда `upscale` установлен в "enabled". Увеличение масштаба и удаление фона могут быть включены вместе или независимо.
- `edit_instruction` не должно быть пустым и не может превышать 2560 символов.
- Когда `model.aspect_ratio` установлен в "auto", фиксированное соотношение сторон не отправляется в API, и соотношение сторон выбирается автоматически.
- `model.test_time_scaling` отправляется в API только когда его значение больше 1; значение по умолчанию 1 сохраняет поведение API по умолчанию.
- Результаты недетерминированы независимо от значения seed; seed только управляет тем, будет ли узел выполняться повторно.
- Этот узел помечен как устаревший.
- Приблизительная стоимость в долларах США (согласно значку цены узла): `$0.01001` для `reve-edit-fast@20251030`; `$0.0572` для `reve-edit@20250915` без увеличения масштаба; `$0.0686` с 2x увеличением, `$0.0819` с 3x увеличением и `$0.0991` с 4x увеличением.

|-------------|-------------|-----------|
| `image` | Отредактированное изображение, сгенерированное на основе инструкции. | IMAGE |
