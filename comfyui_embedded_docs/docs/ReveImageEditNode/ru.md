# Reve Редактирование изображения

Узел Reve Image Edit позволяет изменять существующее изображение на основе текстового описания. Он использует API Reve для интерпретации ваших инструкций и применения запрошенных изменений к предоставленному изображению.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для редактирования. | IMAGE | Да | - |
| `edit_instruction` | Текстовое описание того, как редактировать изображение. Максимум 2560 символов. (по умолчанию: "") | STRING | Да | от 1 до 2560 символов |
| `model` | Версия модели для редактирования. | DYNAMIC_COMBO | Да | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `upscale` | Увеличить масштаб сгенерированного изображения. Может повлечь дополнительные расходы. (по умолчанию: "disabled") | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"enabled"` |
| `remove_background` | Удалить фон из сгенерированного изображения. Может повлечь дополнительные расходы. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `seed` | `seed` управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Нет | от 0 до 2147483647 |

### Входы модели

Общие для моделей `reve-edit@20250915` и `reve-edit-fast@20251030`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model.aspect_ratio` | Соотношение сторон выходного изображения. При значении `"auto"` соотношение сторон определяется автоматически. (по умолчанию: "auto") | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `model.test_time_scaling` | Более высокие значения дают лучшие изображения, но требуют больше кредитов. (по умолчанию: 1) | INT | Нет | от 1 до 5 |

### Входы увеличения масштаба

Отображается, когда `upscale` установлен в `"enabled"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | Коэффициент увеличения масштаба (2x, 3x или 4x). (по умолчанию: 2) | INT | Нет | от 2 до 4 |

**Примечание:** Параметр `upscale.upscale_factor` появляется только тогда, когда `upscale` установлен в `"enabled"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение, созданное на основе инструкции. | IMAGE |

**Примечание:** Этот узел помечен как устаревший.
