# ویرایش تصویر با Reve

گره Reve Image Edit تصویر موجود را بر اساس یک دستور متنی به زبان طبیعی تغییر می‌دهد. این گره تصویر ورودی و دستور شما را به Reve API ارسال می‌کند و این API تصویری جدید با ویرایش‌های درخواستی اعمال‌شده بازمی‌گرداند.

## ورودی‌ها

انتخابگر `model` تعیین می‌کند که کدام ورودی‌های مخصوص مدل نمایش داده شوند. انتخابگر `upscale` کنترل می‌کند که آیا فیلد ضریب بزرگنمایی در دسترس باشد.

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویری که باید ویرایش شود. | IMAGE | بله | - |
| `دستور ویرایش` | توضیح متنی نحوه ویرایش تصویر. حداکثر 2560 کاراکتر. | STRING | بله | - |
| `مدل` | نسخه مدلی که برای ویرایش استفاده می‌شود. | DYNAMIC_COMBO | بله | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `افزایش وضوح` | بزرگنمایی تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. (پیش‌فرض: "disabled") | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `حذف پس‌زمینه` | حذف پس‌زمینه از تصویر تولیدشده. ممکن است هزینه اضافی داشته باشد. (پیش‌فرض: False) | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

### ورودی‌های مدل (مشترک بین `reve-edit@20250915` و `reve-edit-fast@20251030`)

هر دو نسخه مدل، ورودی‌های مختص مدل یکسانی را ارائه می‌دهند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `نسبت ابعاد` | نسبت ابعاد تصویر خروجی. وقتی روی "auto" تنظیم شود، نسبت ابعاد به‌طور خودکار تعیین می‌شود. | COMBO | خیر | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `مقیاس‌دهی زمان تست` | گزینه پیشرفته. مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما اعتبار بیشتری هزینه می‌کنند. (پیش‌فرض: 1) | INT | خیر | 1 تا 5 |

### ورودی‌های بزرگنمایی (زمانی که `upscale` روی "enabled" تنظیم شده باشد)

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | ضریب بزرگنمایی (2x، 3x، یا 4x). (پیش‌فرض: 2) | INT | خیر | 2 تا 4 |

**نکته:**

- `upscale.upscale_factor` فقط زمانی اعمال می‌شود که `upscale` روی "enabled" تنظیم شده باشد. بزرگنمایی و حذف پس‌زمینه می‌توانند با هم یا به‌طور مستقل فعال شوند.
- `edit_instruction` نباید خالی باشد و نمی‌تواند از 2560 کاراکتر بیشتر شود.
- وقتی `model.aspect_ratio` روی "auto" تنظیم شود، هیچ نسبت ابعاد ثابتی به API ارسال نمی‌شود و نسبت ابعاد به‌طور خودکار انتخاب می‌شود.
- `model.test_time_scaling` فقط زمانی به API ارسال می‌شود که مقدار آن بزرگتر از 1 باشد؛ مقدار پیش‌فرض 1 رفتار پیش‌فرض API را حفظ می‌کند.
- نتایج بدون توجه به مقدار seed غیرقطعی هستند؛ seed فقط کنترل می‌کند که آیا گره دوباره اجرا می‌شود.
- این گره به‌عنوان منسوخ (deprecated) علامت‌گذاری شده است.
- هزینه تقریبی به دلار (طبق نشان قیمت گره): `$0.01001` برای `reve-edit-fast@20251030`؛ `$0.0572` برای `reve-edit@20250915` بدون بزرگنمایی؛ `$0.0686` با بزرگنمایی 2x، `$0.0819` با بزرگنمایی 3x، و `$0.0991` با بزرگنمایی 4x.
