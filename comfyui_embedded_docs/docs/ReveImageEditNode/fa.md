# ویرایش تصویر با Reve

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که باید ویرایش شود. | IMAGE | بله | - |
| `edit_instruction` | توصیف متنی نحوه ویرایش تصویر. حداکثر ۲۵۶۰ کاراکتر. (پیش‌فرض: "") | STRING | بله | 1 تا 2560 کاراکتر |
| `model` | نسخه مدل مورد استفاده برای ویرایش. | DYNAMIC_COMBO | بله | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `upscale` | تصویر تولیدشده را افزایش مقیاس می‌دهد. ممکن است هزینه اضافی داشته باشد. (پیش‌فرض: "disabled") | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"enabled"` |
| `remove_background` | پس‌زمینه را از تصویر تولیدشده حذف می‌کند. ممکن است هزینه اضافی داشته باشد. (پیش‌فرض: false) | BOOLEAN | خیر | `true`<br>`false` |
| `seed` | مقدار seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج صرف‌نظر از seed قطعی نیستند. (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

### ورودی‌های مدل

مشترک بین مدل‌های `reve-edit@20250915` و `reve-edit-fast@20251030`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.aspect_ratio` | نسبت تصویر خروجی. وقتی روی `"auto"` تنظیم شود، نسبت تصویر به‌طور خودکار تعیین می‌شود. (پیش‌فرض: "auto") | COMBO | خیر | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `model.test_time_scaling` | مقادیر بالاتر تصاویر بهتری تولید می‌کنند اما هزینه اعتبار بیشتری دارند. (پیش‌فرض: 1) | INT | خیر | 1 تا 5 |

### ورودی‌های افزایش مقیاس

زمانی نمایش داده می‌شود که `upscale` روی `"enabled"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | ضریب افزایش مقیاس (2x، 3x یا 4x). (پیش‌فرض: 2) | INT | خیر | 2 تا 4 |

**توجه:** پارامتر `upscale.upscale_factor` فقط زمانی ظاهر می‌شود که `upscale` روی `"enabled"` تنظیم شده باشد.
