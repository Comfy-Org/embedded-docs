# Reve 圖像編輯

Reve Image Edit 節點會根據自然語言文字指令修改現有圖片。它會將輸入圖片和您的指令傳送至 Reve API，該 API 會傳回套用所要求編輯的新圖片。

## 輸入
`model` 選擇器決定顯示哪些模型特定輸入。`upscale` 選擇器控制放大係數輸入是否可用。

### 通用輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `圖像` | 要編輯的圖片。 | IMAGE | 是 | - |
| `編輯指令` | 如何編輯圖片的文字說明。最多 2560 個字元。 | STRING | 是 | - |
| `模型` | 用於編輯的模型版本。 | DYNAMIC_COMBO | 是 | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `放大` | 放大產生的圖片。可能會增加額外費用。（預設值："disabled"） | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"enabled"` |
| `去背` | 從產生的圖片中移除背景。可能會增加額外費用。（預設值：False） | BOOLEAN | 否 | `true`<br>`false` |
| `種子` | 種子控制節點是否應重新執行；無論種子為何，結果都是非確定性的。（預設值：0） | INT | 否 | 0 至 2147483647 |

### 模型輸入（由 `reve-edit@20250915` 和 `reve-edit-fast@20251030` 共用）

兩個模型版本都公開相同的模型特定輸入。

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `長寬比` | 輸出圖片的長寬比。設定為 "auto" 時，會自動決定長寬比。 | COMBO | 否 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `測試時縮放` | 進階選項。較高的值會產生更好的圖片，但花費更多點數。（預設值：1） | INT | 否 | 1 至 5 |

### 放大輸入（當 `upscale` 設定為 "enabled" 時）

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | 放大係數（2x、3x 或 4x）。（預設值：2） | INT | 否 | 2 至 4 |

**注意：**

- `upscale.upscale_factor` 僅在 `upscale` 設定為 "enabled" 時適用。放大和背景移除可以同時或獨立啟用。
- `edit_instruction` 不得為空，且不能超過 2560 個字元。
- 當 `model.aspect_ratio` 設定為 "auto" 時，不會將固定的長寬比傳送至 API，而是自動選擇長寬比。
- `model.test_time_scaling` 僅在其值大於 1 時傳送至 API；預設值 1 保留 API 的預設行為。
- 無論種子值為何，結果都是非確定性的；種子僅控制節點是否重新執行。
- 此節點已標記為已棄用。
- 約略費用（美元，依節點的價格徽章）：`reve-edit-fast@20251030` 為 `$0.01001`；`reve-edit@20250915` 未放大為 `$0.0572`；2x 放大為 `$0.0686`，3x 放大為 `$0.0819`，4x 放大為 `$0.0991`。
