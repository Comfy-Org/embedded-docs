# Reve画像編集

Reve Image Edit ノードを使用すると、テキストによる説明に基づいて既存の画像を変更できます。Reve API を使用して指示を解釈し、提供された画像に要求された変更を適用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 編集する画像。 | IMAGE | 必須 | - |
| `edit_instruction` | 画像の編集方法を説明するテキスト。最大2560文字。（デフォルト: ""） | STRING | 必須 | 1 to 2560 characters |
| `model` | 編集に使用するモデルバージョン。 | DYNAMIC_COMBO | 必須 | `"reve-edit@20250915"`<br>`"reve-edit-fast@20251030"` |
| `upscale` | 生成された画像をアップスケールします。追加コストがかかる場合があります。（デフォルト: "disabled"） | DYNAMIC_COMBO | 任意 | `"disabled"`<br>`"enabled"` |
| `remove_background` | 生成された画像から背景を削除します。追加コストがかかる場合があります。（デフォルト: false） | BOOLEAN | 任意 | `true`<br>`false` |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です。（デフォルト: 0） | INT | 任意 | 0 to 2147483647 |

### モデル入力

`reve-edit@20250915` モデルと `reve-edit-fast@20251030` モデルで共有されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model.aspect_ratio` | 出力画像のアスペクト比。`"auto"` に設定すると、アスペクト比が自動的に決定されます。（デフォルト: "auto"） | COMBO | 任意 | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"1:1"` |
| `model.test_time_scaling` | 値が大きいほど高品質な画像が生成されますが、クレジットの消費量が多くなります。（デフォルト: 1） | INT | 任意 | 1 to 5 |

### アップスケール入力

`upscale` が `"enabled"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | アップスケール倍率（2倍、3倍、または4倍）。（デフォルト: 2） | INT | 任意 | 2 to 4 |

**注:** `upscale.upscale_factor` パラメータは、`upscale` が `"enabled"` に設定されている場合にのみ表示されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 指示に基づいて生成された編集後画像。 | IMAGE |
