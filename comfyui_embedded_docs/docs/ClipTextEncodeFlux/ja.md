# CLIPテキストエンコードフラックス

`CLIPTextEncodeFlux` は、Flux アーキテクチャ向けに設計されたテキストエンコードノードです。このノードは、2つの異なるテキスト入力を別々のエンコーダー（CLIP-L と T5XXL）で処理し、ガイダンススケールと組み合わせて、画像生成のための統合された条件付け出力を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | Flux アーキテクチャをサポートする CLIP モデルです。CLIP-L エンコーダーと T5XXL エンコーダーの両方を含みます。 | CLIP | はい | - |
| `clip_l` | CLIP-L エンコーダーで処理されるテキスト入力です。スタイルやテーマなどの簡潔なキーワード記述に適しています。複数行入力と動的プロンプトに対応しています。 | STRING | はい | - |
| `t5xxl` | T5XXL エンコーダーで処理されるテキスト入力です。複雑なシーンや詳細を表現する、詳細な自然言語記述に適しています。複数行入力と動的プロンプトに対応しています。 | STRING | はい | - |
| `guidance` | 生成プロセスにおけるテキスト条件の影響を制御します。値が大きいほど、テキストにより厳密に従います。デフォルト: 3.5。 | FLOAT | はい | 0.0 - 100.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `CONDITIONING` | 両方のエンコーダーからの結合された埋め込みとガイダンス値を含み、条件付き画像生成に使用されます。 | CONDITIONING |
