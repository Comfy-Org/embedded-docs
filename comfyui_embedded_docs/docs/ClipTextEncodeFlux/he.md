# ClipTextEncodeFlux

`CLIPTextEncodeFlux` הוא צומת קידוד טקסט המיועד לארכיטקטורת Flux. הוא מעבד שני קלטי טקסט נפרדים באמצעות מקודדים שונים—CLIP-L ו-T5XXL—ומשלב אותם עם סולם הנחיה כדי להפיק פלט התניה מאוחד ליצירת תמונות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל CLIP התומך בארכיטקטורת Flux, כולל גם מקודדי CLIP-L וגם T5XXL. | CLIP | כן | - |
| `clip_l` | קלט טקסט המעובד על ידי מקודד CLIP-L. מתאים לתיאורי מילות מפתח תמציתיים, כגון סגנון או נושא. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `t5xxl` | קלט טקסט המעובד על ידי מקודד T5XXL. מתאים לתיאורי שפה טבעית מפורטים, המבטאים סצנות ופרטים מורכבים. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `guidance` | שולט בהשפעה של תנאי הטקסט על תהליך היצירה. ערכים גבוהים יותר משמעותם היצמדות מחמירה יותר לטקסט. ברירת מחדל: 3.5. ניתן לכוונן במרווחים של 0.1. | FLOAT | כן | 0.0 - 100.0 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | מכיל את ההטמעות הממוזגות משני המקודדים ומפרמטר ה-guidance, המשמש ליצירת תמונות מותנית. | CONDITIONING |
