# ClipTextEncodeFlux

`CLIPTextEncodeFlux` — это расширенный узел кодирования текста, разработанный для архитектуры Flux. Он обрабатывает два отдельных текстовых входа через разные энкодеры — CLIP-L и T5XXL — и объединяет их с коэффициентом направленности (guidance), формируя единый выходной conditioning для генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, поддерживающая архитектуру Flux, включая энкодеры CLIP-L и T5XXL. | CLIP | Да | - |
| `clip_l` | Текстовый ввод, обрабатываемый энкодером CLIP-L. Подходит для кратких ключевых описаний, таких как стиль или тема. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `t5xxl` | Текстовый ввод, обрабатываемый энкодером T5XXL. Подходит для подробных описаний на естественном языке, выражающих сложные сцены и детали. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `руководство` | Управляет влиянием текстовых условий на процесс генерации. Более высокие значения означают более строгое следование тексту. По умолчанию: 3.5. Регулируется с шагом 0.1. | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Содержит объединенные эмбеддинги из обоих энкодеров и параметр guidance, используемые для условной генерации изображений. | CONDITIONING |
