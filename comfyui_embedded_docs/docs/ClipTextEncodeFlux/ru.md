# Кодирование текста CLIP Flux

`CLIPTextEncodeFlux` — это узел кодирования текста, предназначенный для архитектуры Flux. Он обрабатывает два отдельных текстовых входа через разные кодировщики — CLIP-L и T5XXL — и объединяет их с коэффициентом направленности (guidance), формируя единое условие (conditioning) для генерации изображений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, поддерживающая архитектуру Flux, включающую кодировщики CLIP-L и T5XXL. | CLIP | Да | - |
| `clip_l` | Текстовый ввод, обрабатываемый кодировщиком CLIP-L. Подходит для кратких ключевых описаний, таких как стиль или тема. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `t5xxl` | Текстовый ввод, обрабатываемый кодировщиком T5XXL. Подходит для подробных описаний на естественном языке, передачи сложных сцен и деталей. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `guidance` | Управляет влиянием текстовых условий на процесс генерации. Более высокие значения означают более строгое следование тексту. По умолчанию: 3.5. | FLOAT | Да | 0.0 - 100.0 |

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Содержит объединенные эмбеддинги обоих кодировщиков и значение guidance, используемые для условной генерации изображений. | CONDITIONING |
