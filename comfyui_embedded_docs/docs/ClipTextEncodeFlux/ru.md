# ClipTextEncodeFlux

`CLIPTextEncodeFlux` — это узел текстового кодирования, разработанный для архитектуры Flux. Он обрабатывает два отдельных текстовых входа через разные энкодеры — CLIP-L и T5XXL — и объединяет их с масштабом guidance, формируя единый выход conditioning для генерации изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, поддерживающая архитектуру Flux, включая оба энкодера CLIP-L и T5XXL. | CLIP | Да | - |
| `clip_l` | Текстовый вход, обрабатываемый энкодером CLIP-L. Подходит для кратких описаний ключевыми словами, например стиля или темы. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `t5xxl` | Текстовый вход, обрабатываемый энкодером T5XXL. Подходит для подробных описаний на естественном языке, выражающих сложные сцены и детали. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | - |
| `руководство` | Управляет влиянием текстовых условий на процесс генерации. Более высокие значения означают более строгое следование тексту. По умолчанию: 3.5. Регулируется с шагом 0.1. | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Содержит объединённые эмбеддинги от обоих энкодеров и параметр guidance, используемые для условной генерации изображений. | CONDITIONING |
