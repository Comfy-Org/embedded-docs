# ClipTextEncodeFlux

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `CLIP` | نموذج CLIP يدعم بنية Flux، ويتضمن كلا المُرمِّزين CLIP-L و T5XXL. | CLIP | نعم | - |
| `CLIP-L` | إدخال نصي يعالجه مُرمِّز CLIP-L. مناسب للأوصاف المختصرة بالكلمات المفتاحية، مثل الأسلوب أو الموضوع. يدعم الإدخال متعدد الأسطر والطلبات الديناميكية. | STRING | نعم | - |
| `T5-XXL` | إدخال نصي يعالجه مُرمِّز T5XXL. مناسب للأوصاف التفصيلية باللغة الطبيعية، للتعبير عن المشاهد والتفاصيل المعقدة. يدعم الإدخال متعدد الأسطر والطلبات الديناميكية. | STRING | نعم | - |
| `التوجيه` | يتحكم في تأثير شروط النص على عملية التوليد. القيم الأعلى تعني التزامًا أكثر صرامة بالنص. الافتراضي: 3.5. قابل للتعديل بزيادات قدرها 0.1. | FLOAT | نعم | 0.0 - 100.0 |
