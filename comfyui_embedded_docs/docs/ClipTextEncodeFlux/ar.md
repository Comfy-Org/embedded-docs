# ترميز نص CLIP لـ Flux

`CLIPTextEncodeFlux` هو عقدة ترميز نصي مصممة لبنية Flux. تعالج مدخلين نصيين منفصلين عبر مشفرين مختلفين — CLIP-L و T5XXL — وتجمعهما مع مقياس التوجيه لإنتاج مخرجات تكييف موحدة لتوليد الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP يدعم بنية Flux، ويتضمن كلا المشفرين CLIP-L و T5XXL. | CLIP | نعم | - |
| `clip_l` | نص الإدخال الذي يعالجه مشفر CLIP-L. مناسب للأوصاف الموجزة بالكلمات المفتاحية، مثل الأسلوب أو الموضوع. يدعم الإدخال متعدد الأسطر والموجّهات الديناميكية. | STRING | نعم | - |
| `t5xxl` | نص الإدخال الذي يعالجه مشفر T5XXL. مناسب للأوصاف التفصيلية باللغة الطبيعية، للتعبير عن المشاهد والتفاصيل المعقدة. يدعم الإدخال متعدد الأسطر والموجّهات الديناميكية. | STRING | نعم | - |
| `guidance` | يتحكم في تأثير شروط النص على عملية التوليد. القيم الأعلى تعني التزامًا أكثر صرامة بالنص. الافتراضي: 3.5. | FLOAT | نعم | 0.0 - 100.0 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | يحتوي على التضمينات المجمعة من كلا المشفرين وقيمة التوجيه، ويُستخدم لتوليد الصور الشرطية. | CONDITIONING |
