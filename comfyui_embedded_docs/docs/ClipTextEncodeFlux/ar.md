# ClipTextEncodeFlux

`CLIPTextEncodeFlux` هي عقدة ترميز نصي مصممة لمعمارية Flux. تعالج مدخلين نصيين منفصلين عبر مُرمِّزَين مختلفين—CLIP-L وT5XXL—وتدمجهما مع مقياس توجيه لإنتاج مخرج تهيئة موحّد لتوليد الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP يدعم معمارية Flux، بما في ذلك كلا المُرمِّزين CLIP-L وT5XXL. | CLIP | نعم | - |
| `clip_l` | مدخل نصي يعالجه مُرمِّز CLIP-L. مناسب للأوصاف المختصرة بالكلمات المفتاحية، مثل النمط أو الموضوع. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `t5xxl` | مدخل نصي يعالجه مُرمِّز T5XXL. مناسب للأوصاف التفصيلية باللغة الطبيعية، للتعبير عن مشاهد وتفاصيل معقدة. يدعم الإدخال متعدد الأسطر والمطالبات الديناميكية. | STRING | نعم | - |
| `guidance` | يتحكم في تأثير الشروط النصية على عملية التوليد. القيم الأعلى تعني التزامًا أكثر صرامة بالنص. الافتراضي: 3.5. قابل للتعديل بزيادات مقدارها 0.1. | FLOAT | نعم | 0.0 - 100.0 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `CONDITIONING` | يحتوي على التضمينات المدمجة من كلا المُرمِّزين ومعامل التوجيه، ويُستخدم لتوليد الصور الشرطي. | CONDITIONING |
