# ClipTextEncodeFlux

`CLIPTextEncodeFlux` یک گره رمزگذاری متن است که برای معماری Flux طراحی شده است. این گره دو ورودی متنی جداگانه را از طریق رمزگذارهای مختلف — CLIP-L و T5XXL — پردازش می‌کند و آن‌ها را همراه با مقیاس guidance ترکیب می‌کند تا یک خروجی conditioning یکپارچه برای تولید تصویر ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | یک مدل CLIP که از معماری Flux پشتیبانی می‌کند و شامل هر دو رمزگذار CLIP-L و T5XXL است. | CLIP | بله | - |
| `clip_l` | ورودی متنی که توسط رمزگذار CLIP-L پردازش می‌شود. مناسب برای توصیف‌های کوتاه کلیدواژه‌ای، مانند سبک یا تم. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متنی که توسط رمزگذار T5XXL پردازش می‌شود. مناسب برای توصیف‌های دقیق به زبان طبیعی، بیان صحنه‌ها و جزئیات پیچیده. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `راهنما` | میزان تأثیر شرایط متنی بر فرایند تولید را کنترل می‌کند. مقادیر بالاتر به معنای پایبندی سخت‌گیرانه‌تر به متن است. پیش‌فرض: 3.5. قابل تنظیم با گام‌های 0.1. | FLOAT | بله | 0.0 - 100.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | شامل تعبیه‌های ادغام‌شده از هر دو رمزگذار و پارامتر guidance است که برای تولید تصویر شرطی استفاده می‌شود. | CONDITIONING |
