# ClipTextEncodeFlux

`CLIPTextEncodeFlux` یک گره رمزگذاری متن پیشرفته است که برای معماری Flux طراحی شده است. این گره دو ورودی متنی جداگانه را از طریق رمزگذارهای متفاوت—CLIP-L و T5XXL—پردازش می‌کند و آن‌ها را با یک مقیاس راهنما (guidance) ترکیب می‌کند تا خروجی شرطی یکپارچه‌ای برای تولید تصویر ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که از معماری Flux پشتیبانی می‌کند و شامل هر دو رمزگذار CLIP-L و T5XXL است. | CLIP | بله | - |
| `clip_l` | ورودی متنی که توسط رمزگذار CLIP-L پردازش می‌شود. مناسب برای توصیف‌های کلیدواژه‌ای مختصر، مانند سبک یا تم. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متنی که توسط رمزگذار T5XXL پردازش می‌شود. مناسب برای توصیف‌های دقیق زبان طبیعی، بیان صحنه‌ها و جزئیات پیچیده. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `راهنما` | کنترل میزان تأثیر شرایط متنی بر فرآیند تولید. مقادیر بالاتر به معنای پایبندی سخت‌گیرانه‌تر به متن است. پیش‌فرض: 3.5. قابل تنظیم در گام‌های 0.1. | FLOAT | بله | 0.0 - 100.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | شامل بردارهای تعبیه ترکیب‌شده از هر دو رمزگذار و پارامتر guidance است که برای تولید تصویر شرطی استفاده می‌شود. | CONDITIONING |
