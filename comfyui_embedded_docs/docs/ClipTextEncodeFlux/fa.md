# CLIPTextEncodeFlux

`CLIPTextEncodeFlux` یک گره رمزگذاری متن است که برای معماری Flux طراحی شده است. این گره دو ورودی متنی جداگانه را از طریق رمزگذارهای متفاوت—CLIP-L و T5XXL—پردازش می‌کند و آن‌ها را با یک مقیاس هدایت (guidance) ترکیب می‌کند تا یک خروجی شرطی یکپارچه برای تولید تصویر ایجاد کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که از معماری Flux پشتیبانی می‌کند و شامل هر دو رمزگذار CLIP-L و T5XXL است. | CLIP | بله | - |
| `clip_l` | ورودی متنی که توسط رمزگذار CLIP-L پردازش می‌شود. برای توصیف‌های کلیدی مختصر، مانند سبک یا موضوع، مناسب است. از ورودی چندخطی و درخواست‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متنی که توسط رمزگذار T5XXL پردازش می‌شود. برای توصیف‌های دقیق زبان طبیعی، بیان صحنه‌ها و جزئیات پیچیده مناسب است. از ورودی چندخطی و درخواست‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `guidance` | میزان تأثیر شرایط متنی بر فرآیند تولید را کنترل می‌کند. مقادیر بالاتر به معنای پایبندی دقیق‌تر به متن است. پیش‌فرض: 3.5. | FLOAT | بله | 0.0 - 100.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | شامل جاسازی‌های ترکیب‌شده از هر دو رمزگذار و مقدار هدایت است که برای تولید تصویر شرطی استفاده می‌شود. | CONDITIONING |
