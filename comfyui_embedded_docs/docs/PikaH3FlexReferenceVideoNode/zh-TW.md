# Pika H3 Flex Reference to Video

此節點會產生或編輯帶有同步音訊的影片，並以參考影像、影片和音訊片段作為引導。Pika H3 Flex 是 Pika 經後訓練的 MiniMax H3 模型。連接參考項目，並在提示詞中依連接順序以 `@Image1`、`@Video1` 或 `@Audio1` 來引用它們。至少需要一個參考影像或影片，且總共最多可連接 12 個參考項目。

**限制條件：**

* 至少需要一個參考影像或影片。
* 總共最多可連接 12 個參考項目，影像、影片和音訊片段合併計算。
* 每個參考影片和音訊片段長度必須為 2 至 15 秒；影片總長度必須為 15 秒或以下，音訊片段總長度也必須為 15 秒或以下。
* 提示詞長度必須介於 1 至 8000 個字元之間。
* 引用未連接的插槽（例如在只提供兩張影像時引用 `@Image3`）會引發錯誤。
