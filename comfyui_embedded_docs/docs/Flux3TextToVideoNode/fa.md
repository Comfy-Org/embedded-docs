# تبدیل متن به ویدیو Flux 3

با استفاده از FLUX 3، ویدیویی با صدای همگام‌شده از یک پرامپت متنی تولید می‌کند. این گره پرامپت شما را به سرویس FLUX 3 می‌فرستد، منتظر می‌ماند تا تولید کامل شود و کلیپ ویدیویی نهایی را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | آنچه می‌خواهید، به زبان ساده؛ پرامپت پیش از تولید تفسیر و گسترش داده می‌شود. برای صدای لایه‌ای، صدای محیطی، موسیقی و گفتار را جداگانه توصیف کنید. (پیش‌فرض: "") | STRING | بله | متن چندخطی |
| `aspect_ratio` | نسبت ابعاد خروجی. 'auto' یکی را از پرامپت و ورودی‌ها انتخاب می‌کند. (پیش‌فرض: "auto") | COMBO | بله | چندین گزینه موجود است، از جمله `"auto"` |
| `duration` | طول کلیپ بر حسب ثانیه. 'auto' طول را متناسب با محتوا تنظیم می‌کند. (پیش‌فرض: "auto") | COMBO | بله | چندین گزینه موجود است، از جمله `"auto"` |
| `resolution` | رزولوشن خروجی. (پیش‌فرض: "720p") | COMBO | بله | `"720p"`<br>`"1080p"` |
| `generate_audio` | صدای همگام‌شده (محیطی، گفتار، جلوه‌ها) را تولید می‌کند. خاموش بودن آن ویدیویی بدون مسیر صوتی تولید می‌کند. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `safety_tolerance` | تحمل نظارت محتوایی، 0 سخت‌گیرانه‌ترین است. درخواست‌هایی که تصویر یا ویدیو ارسال می‌کنند، هر مقداری که اینجا تعیین کنید، حداکثر روی 2 محدود می‌شوند. (پیش‌فرض: 2) | INT | بله | 0 تا 4 |
| `seed` | Seed برای تعیین اینکه گره باید دوباره اجرا شود؛ FLUX 3 خودش seed را انتخاب می‌کند، بنابراین نتایج واقعی بدون توجه به این مقدار غیرقطعی هستند. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |

توجه: `safety_tolerance` یک ورودی پیشرفته است. ورودی `seed` شامل کنترل‌های Control After Generate در رابط کاربری است. قیمت نمایش‌داده‌شده بر اساس `resolution` و `duration` است: HD (720p) با نرخ $0.2431 در هر ثانیه و FHD (1080p) با نرخ $0.4147 در هر ثانیه محاسبه می‌شود. وقتی مدت‌زمان ثابتی انتخاب شود، هزینه تخمینی کل کلیپ نمایش داده می‌شود؛ وقتی `duration` روی "auto" باشد، نرخ هر ثانیه نمایش داده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | کلیپ ویدیویی تولیدشده، همراه با صدای همگام‌شده وقتی `generate_audio` فعال است. | VIDEO |
