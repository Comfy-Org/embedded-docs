# تبدیل متن به ویدیو Flux 3

ویدئویی با صدای همگام‌شده از روی یک پرامپت متنی با استفاده از FLUX 3 تولید می‌کند. این گره پرامپت شما را به سرویس FLUX 3 ارسال می‌کند، منتظر پایان تولید می‌ماند و کلیپ ویدئویی تکمیل‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | آنچه می‌خواهید، به زبان ساده؛ پرامپت پیش از تولید تفسیر و گسترش می‌یابد. صدای محیط، موسیقی و گفتار را به‌طور جداگانه برای صدای لایه‌ای توصیف کنید. (پیش‌فرض: "") | STRING | بله | متن چندخطی |
| `نسبت تصویر` | نسبت تصویر خروجی. 'auto' یکی را از روی پرامپت و ورودی‌ها انتخاب می‌کند. (پیش‌فرض: "auto") | COMBO | بله | چند گزینه موجود است، از جمله `"auto"` |
| `مدت زمان` | طول کلیپ بر حسب ثانیه. 'auto' طول را با محتوا هماهنگ می‌کند. (پیش‌فرض: "auto") | COMBO | بله | چند گزینه موجود است، از جمله `"auto"` |
| `رزولوشن` | وضوح خروجی. (پیش‌فرض: "720p") | COMBO | بله | `"720p"`<br>`"1080p"` |
| `تولید صدا` | تولید صدای همگام‌شده (محیط، گفتار، افکت‌ها). خاموش بودن، ویدئویی بدون ترک صوتی تولید می‌کند. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `درجه تحمل ایمنی` | تلورانس پالایش، 0 سخت‌گیرانه‌ترین است. درخواست‌هایی که تصویر یا ویدئو ارسال می‌کنند، صرف‌نظر از مقدار اینجا، در 2 محدود می‌شوند. (پیش‌فرض: 2) | INT | بله | 0 تا 4 |
| `بذر (Seed)` | سید برای تعیین این که گره دوباره اجرا شود؛ FLUX 3 سید خودش را انتخاب می‌کند، بنابراین نتایج واقعی بدون توجه به این مقدار قطعی نیستند. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |

توجه: ورودی `seed` شامل کنترل‌های Control After Generate در رابط کاربری است. قیمت نمایش‌داده‌شده بر اساس `resolution` و `duration` است: HD (720p) به‌ازای هر ثانیه ۰٫۲۴۳۱ دلار و FHD (1080p) به‌ازای هر ثانیه ۰٫۴۱۴۷ دلار محاسبه می‌شود. وقتی مدت‌زمان ثابت انتخاب شود، کل هزینه تخمینی برای کلیپ نشان داده می‌شود؛ وقتی `duration` روی "auto" است، نرخ هر ثانیه نمایش داده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | کلیپ ویدئویی تولیدشده، همراه با صدای همگام‌شده وقتی `generate_audio` فعال باشد. | VIDEO |
