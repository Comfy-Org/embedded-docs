# Flux 3: Текст в видео

Создаёт видео с синхронизированным звуком из текстового запроса с помощью FLUX 3. Узел отправляет ваш запрос в сервис FLUX 3, ожидает завершения генерации и возвращает готовый видеоклип.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Что вы хотите получить, простыми словами; запрос интерпретируется и расширяется перед генерацией. Описывайте окружающий звук, музыку и речь отдельно для многослойного аудио. (по умолчанию: "") | STRING | Да | Многострочный текст |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` выбирает его на основе запроса и входных данных. (по умолчанию: "auto") | COMBO | Да | Доступно несколько вариантов, включая `"auto"` |
| `duration` | Длительность клипа в секундах. `"auto"` подбирает длительность под содержимое. (по умолчанию: "auto") | COMBO | Да | Доступно несколько вариантов, включая `"auto"` |
| `resolution` | Разрешение выходного видео. (по умолчанию: "720p") | COMBO | Да | `"720p"`<br>`"1080p"` |
| `generate_audio` | Генерировать синхронизированный звук (окружающий, речь, эффекты). При выключении создаётся видео без звуковой дорожки. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `safety_tolerance` | Допуск модерации, 0 — самый строгий. Для запросов, которые отправляют изображения или видео, значение ограничивается 2, что бы вы здесь ни указали. (по умолчанию: 2) | INT | Да | от 0 до 4 |
| `seed` | Seed для определения, должен ли узел перезапуститься; FLUX 3 выбирает собственный seed, поэтому фактические результаты недетерминированы независимо от этого значения. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |

Примечание: `safety_tolerance` — это расширенный вход. Вход `seed` включает элементы управления Control After Generate в интерфейсе. Отображаемая цена зависит от `resolution` и `duration`: HD (720p) тарифицируется по $0.2431 в секунду, а FHD (1080p) — по $0.4147 в секунду. Если выбрана фиксированная длительность, показывается общая оценочная стоимость клипа; если `duration` имеет значение "auto", показывается стоимость за секунду.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип с синхронизированным звуком, когда `generate_audio` включён. | VIDEO |
