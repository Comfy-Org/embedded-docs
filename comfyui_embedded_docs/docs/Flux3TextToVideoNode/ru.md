# Flux3TextToVideoNode

Генерирует видео с синхронизированным звуком по текстовому запросу с помощью FLUX 3. Узел отправляет ваш запрос в сервис FLUX 3, ожидает завершения генерации и возвращает готовый видеоклип.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Что вы хотите получить, простым языком; запрос интерпретируется и расширяется перед генерацией. Опишите фоновые звуки, музыку и речь отдельно для многослойного аудио. (по умолчанию: "") | STRING | Да | Multiline text |
| `aspect_ratio` | Соотношение сторон выходного видео. Значение 'auto' выбирает его автоматически на основе запроса и входных параметров. (по умолчанию: "auto") | STRING | Да | Доступно несколько вариантов, including `"auto"` |
| `duration` | Длительность клипа в секундах. 'auto' подбирает длительность под содержимое. (по умолчанию: "auto") | STRING | Да | Доступно несколько вариантов, including `"auto"` |
| `resolution` | Разрешение выходного видео. (по умолчанию: "720p") | STRING | Да | `"720p"`<br>`"1080p"` |
| `generate_audio` | Генерирует синхронизированный звук (фоновые звуки, речь, эффекты). При выключении создаётся видео без звуковой дорожки. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `safety_tolerance` | Допустимый уровень модерации: 0 — самый строгий. Запросы с изображениями или видео ограничиваются значением 2 независимо от того, что вы здесь зададите. (по умолчанию: 2) | INT | Да | 0 до 4 |
| `seed` | Сид, определяющий, следует ли узлу запускаться заново; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. (по умолчанию: 42) | INT | Да | 0 до 4294967295 |

Примечание: входной параметр `seed` включает в интерфейсе элементы управления Control After Generate. Отображаемая цена зависит от `resolution` и `duration`: HD (720p) тарифицируется по $0.2431 за секунду, FHD (1080p) — по $0.4147 за секунду. Когда выбрана фиксированная длительность, показывается общая расчётная стоимость клипа; когда `duration` равно "auto", отображается тариф за секунду.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип с синхронизированным звуком, если `generate_audio` включён. | VIDEO |
