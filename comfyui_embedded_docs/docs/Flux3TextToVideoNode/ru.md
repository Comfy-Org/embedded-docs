# Flux 3: Текст в видео

Generates a video with synchronized audio from a text prompt using FLUX 3. The node sends your prompt to the FLUX 3 service, waits for the generation to finish, and returns the completed video clip.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Что вы хотите, на простом языке; запрос интерпретируется и расширяется перед генерацией. Описывайте фоновый звук, музыку и речь отдельно для многослойного аудио. (по умолчанию: "") | STRING | Да | Многострочный текст |
| `aspect_ratio` | Соотношение сторон выходного видео. 'auto' выбирает его из запроса и входных данных. (по умолчанию: "auto") | COMBO | Да | Доступно несколько вариантов, включая `"auto"` |
| `duration` | Длительность клипа в секундах. 'auto' подбирает длину под содержимое. (по умолчанию: "auto") | COMBO | Да | Доступно несколько вариантов, включая `"auto"` |
| `resolution` | Разрешение выходного видео. (по умолчанию: "720p") | COMBO | Да | `"720p"`<br>`"1080p"` |
| `generate_audio` | Генерировать синхронизированное аудио (фон, речь, эффекты). Выкл. создает видео без звуковой дорожки. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `safety_tolerance` | Допуск модерации, 0 — самый строгий. Запросы, отправляющие изображения или видео, ограничены 2 независимо от того, что вы здесь укажете. (по умолчанию: 2) | INT | Да | от 0 до 4 |
| `seed` | Сид для определения необходимости повторного запуска узла; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |

Примечание: вход `seed` включает элементы управления Control After Generate в интерфейсе. Отображаемая цена зависит от `resolution` и `duration`: HD (720p) тарифицируется по $0,2431 в секунду, а FHD (1080p) — по $0,4147 в секунду. Когда выбрана фиксированная длительность, показывается общая расчетная стоимость клипа; когда `duration` — "auto", показывается тариф за секунду.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеоклип с синхронизированным аудио, когда `generate_audio` включен. | VIDEO |
