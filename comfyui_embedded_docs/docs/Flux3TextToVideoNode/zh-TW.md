# Flux 3 文字轉影片

使用 FLUX 3 從文字提示產生具有同步音訊的影片。此節點會將您的提示傳送到 FLUX 3 服務，等待生成完成，然後回傳完整的影片片段。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 您想要內容的純文字描述；提示會在生成前被解讀與擴充。請分別描述環境音、音樂和語音，以獲得分層音訊。(預設值："") | STRING | 是 | 多行文字 |
| `長寬比` | 輸出長寬比。'auto' 會從提示和輸入中選取一個。(預設值："auto") | COMBO | 是 | 提供多個選項，包括 `"auto"` |
| `時長` | 片段長度（秒）。'auto' 會根據內容調整長度。(預設值："auto") | COMBO | 是 | 提供多個選項，包括 `"auto"` |
| `解析度` | 輸出解析度。(預設值："720p") | COMBO | 是 | `"720p"`<br>`"1080p"` |
| `產生音訊` | 產生同步音訊（環境音、語音、特效）。關閉時會產生沒有音訊軌的影片。(預設值：True) | BOOLEAN | 是 | True<br>False |
| `安全容忍度` | 審核容許度，0 最嚴格。傳送圖片或影片的請求無論您在此設定為何，上限皆為 2。(預設值：2) | INT | 是 | 0 至 4 |
| `種子` | 用於決定節點是否重新執行的種子；FLUX 3 會自行選取種子，因此無論此值為何，實際結果都是非確定性的。(預設值：42) | INT | 是 | 0 至 4294967295 |

注意：`seed` 輸入在 UI 中包含「生成後控制」控制項。顯示的價格是根據 `resolution` 和 `duration` 計算：HD (720p) 每秒收費 $0.2431，FHD (1080p) 每秒收費 $0.4147。當選擇固定長度時，會顯示影片片段的估計總成本；當 `duration` 為 "auto" 時，則顯示每秒費率。
