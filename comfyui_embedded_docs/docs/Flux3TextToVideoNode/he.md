# Flux 3 טקסט לוידאו

יוצר וידאו עם אודיו מסונכרן מתוך פרומפט טקסט באמצעות FLUX 3. הצומת שולח את הפרומפט שלך לשירות FLUX 3, ממתין לסיום היצירה, ומחזיר את קטע הווידאו המוגמר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה שאתה רוצה, בשפה פשוטה; הפרומפט מפוענח ומורחב לפני היצירה. תאר צלילי רקע, מוזיקה ודיבור בנפרד עבור אודיו רב-שכבתי. (ברירת מחדל: "") | STRING | כן | טקסט מרובה שורות |
| `aspect_ratio` | יחס רוחב-גובה של הפלט. 'auto' בוחר אחד מתוך הפרומפט והקלטים. (ברירת מחדל: "auto") | COMBO | כן | אפשרויות מרובות זמינות, כולל `"auto"` |
| `duration` | אורך הקטע בשניות. 'auto' מתאים את האורך לתוכן. (ברירת מחדל: "auto") | COMBO | כן | אפשרויות מרובות זמינות, כולל `"auto"` |
| `resolution` | רזולוציית הפלט. (ברירת מחדל: "720p") | COMBO | כן | `"720p"`<br>`"1080p"` |
| `generate_audio` | יצירת אודיו מסונכרן (רקע, דיבור, אפקטים). כיבוי מייצר וידאו ללא רצועת אודיו. (ברירת מחדל: True) | BOOLEAN | כן | True<br>False |
| `safety_tolerance` | סובלנות לסינון תוכן, 0 היא המחמירה ביותר. בקשות ששולחות תמונות או וידאו מוגבלות ל-2, לא משנה מה תגדיר כאן. (ברירת מחדל: 2) | INT | כן | 0 עד 4 |
| `seed` | ערך seed לקביעה אם הצומת צריך לרוץ מחדש; FLUX 3 בוחר seed משלו, כך שהתוצאות בפועל אינן דטרמיניסטיות ללא קשר לערך זה. (ברירת מחדל: 42) | INT | כן | 0 עד 4294967295 |

הערה: `safety_tolerance` הוא קלט מתקדם. קלט `seed` כולל בקרות Control After Generate בממשק המשתמש. המחיר המוצג מבוסס על `resolution` ו-`duration`: HD (720p) מחויב ב-$0.2431 לשנייה ו-FHD (1080p) ב-$0.4147 לשנייה. כאשר נבחר משך קבוע, מוצגת העלות הכוללת המשוערת של הקטע; כאשר `duration` הוא "auto", מוצג התעריף לשנייה.
