# Flux 3 تحويل نص إلى فيديو

Generates a video with synchronized audio from a text prompt using FLUX 3. The node sends your prompt to the FLUX 3 service, waits for the generation to finish, and returns the completed video clip.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ما تريده بلغة بسيطة؛ يتم تفسير النص وتوسيعه قبل التوليد. صف الصوت المحيط والموسيقى والكلام بشكل منفصل للحصول على صوت متعدد الطبقات. (الافتراضي: "") | STRING | نعم | نص متعدد الأسطر |
| `aspect_ratio` | نسبة أبعاد المخرج. يختار 'auto' واحدة مناسبة من النص والمدخلات. (الافتراضي: "auto") | COMBO | نعم | خيارات متعددة متاحة، بما في ذلك `"auto"` |
| `duration` | طول المقطع بالثواني. يضبط 'auto' الطول ليتناسب مع المحتوى. (الافتراضي: "auto") | COMBO | نعم | خيارات متعددة متاحة، بما في ذلك `"auto"` |
| `resolution` | دقة المخرج. (الافتراضي: "720p") | COMBO | نعم | `"720p"`<br>`"1080p"` |
| `generate_audio` | توليد صوت متزامن (محيط، كلام، مؤثرات). عند الإيقاف ينتج فيديو بدون مسار صوتي. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `safety_tolerance` | درجة تسامح الرقابة، 0 هي الأكثر صرامة. الطلبات التي ترسل صورًا أو فيديو تكون محدودة بـ 2 مهما كان الإعداد هنا. (الافتراضي: 2) | INT | نعم | 0 إلى 4 |
| `seed` | بذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ تختار FLUX 3 بذرتها الخاصة، لذا تكون النتائج الفعلية غير حتمية بغض النظر عن هذه القيمة. (الافتراضي: 42) | INT | نعم | 0 إلى 4294967295 |

ملاحظة: يتضمن مدخل `seed` عناصر تحكم "التحكم بعد التوليد" في الواجهة. يعتمد السعر المعروض على `resolution` و `duration`: تُحتسب الدقة HD (720p) بمبلغ 0.2431 دولارًا لكل ثانية، والدقة FHD (1080p) بمبلغ 0.4147 دولارًا لكل ثانية. عند اختيار مدة ثابتة، يُعرض إجمالي التكلفة التقديرية للمقطع؛ وعندما تكون `duration` بقيمة "auto"، يُعرض السعر لكل ثانية.
