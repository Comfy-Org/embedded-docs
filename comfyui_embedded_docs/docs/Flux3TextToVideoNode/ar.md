# Flux3TextToVideoNode

ينشئ فيديو مع صوت متزامن من مطالبة نصية باستخدام FLUX 3. ترسل العقدة مطالبتك إلى خدمة FLUX 3، وتنتظر حتى انتهاء التوليد، وتُرجع مقطع الفيديو المكتمل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ما تريده، بلغة بسيطة؛ يتم تفسير المطالبة وتوسيعها قبل التوليد. صِف الصوت المحيط والموسيقى والكلام بشكل منفصل للحصول على صوت متعدد الطبقات. (الافتراضي: "") | STRING | نعم | نص متعدد الأسطر |
| `aspect_ratio` | نسبة العرض إلى الارتفاع للمخرجات. يختار الخيار 'auto' نسبة من المطالبة والمدخلات. (الافتراضي: "auto") | STRING | نعم | خيارات متعددة متاحة، بما في ذلك `"auto"` |
| `duration` | طول المقطع بالثواني. يضبط الخيار 'auto' الطول ليتناسب مع المحتوى. (الافتراضي: "auto") | STRING | نعم | خيارات متعددة متاحة، بما في ذلك `"auto"` |
| `resolution` | دقة المخرجات. (الافتراضي: "720p") | STRING | نعم | `"720p"`<br>`"1080p"` |
| `generate_audio` | توليد صوت متزامن (محيط، كلام، مؤثرات). يؤدي إيقاف التشغيل إلى إنتاج فيديو بدون مسار صوتي. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `safety_tolerance` | درجة تحمل الاعتدال، 0 هي الأكثر صرامة. الطلبات التي ترسل صورًا أو فيديو تكون محدودة عند 2 مهما كانت القيمة التي تعينها هنا. (الافتراضي: 2) | INT | نعم | من 0 إلى 4 |
| `seed` | البذرة لتحديد ما إذا كان يجب إعادة تشغيل العقدة؛ يختار FLUX 3 بذرته الخاصة، لذا تكون النتائج الفعلية غير حتمية بغض النظر عن هذه القيمة. (الافتراضي: 42) | INT | نعم | من 0 إلى 4294967295 |

ملاحظة: يتضمن مدخل `seed` عناصر تحكم "التحكم بعد التوليد" في واجهة المستخدم. يعتمد السعر المعروض على `resolution` و `duration`: يتم احتساب HD (720p) بمبلغ 0.2431 دولارًا في الثانية و FHD (1080p) بمبلغ 0.4147 دولارًا في الثانية. عند اختيار مدة ثابتة، يُعرض إجمالي التكلفة التقديرية للمقطع؛ وعندما تكون `duration` هي "auto"، يُعرض معدل كل ثانية.
