# تبدیل تصویر به ویدیو PixVerse

ویدیوها را بر اساس یک تصویر ورودی و متن راهنما تولید می‌کند. این گره یک تصویر دریافت کرده و با اعمال تنظیمات حرکت و کیفیت مشخص‌شده، تصویر ثابت را به یک سکانس متحرک تبدیل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `تصویر` | تصویر ورودی برای تبدیل به ویدیو | IMAGE | بله | - |
| `پرامپت` | متن راهنمای تولید ویدیو | STRING | بله | - |
| `کیفیت` | تنظیم کیفیت ویدیو (پیش‌فرض: res_540p) | COMBO | بله | `res_540p`<br>`res_1080p` |
| `مدت (ثانیه)` | مدت زمان ویدیوی تولیدشده بر حسب ثانیه | COMBO | بله | `dur_2`<br>`dur_5`<br>`dur_10` |
| `حالت حرکت` | سبک حرکتی اعمال‌شده برای تولید ویدیو | COMBO | بله | `normal`<br>`fast`<br>`slow`<br>`zoom_in`<br>`zoom_out`<br>`pan_left`<br>`pan_right`<br>`pan_up`<br>`pan_down`<br>`tilt_up`<br>`tilt_down`<br>`roll_clockwise`<br>`roll_counterclockwise` |
| `بذر` | seed برای تولید ویدیو (پیش‌فرض: 0) | INT | بله | 0-2147483647 |
| `پرامپت منفی` | توضیحات متنی اختیاری درباره عناصر ناخواسته در تصویر | STRING | خیر | - |
| `قالب PixVerse` | یک قالب اختیاری برای تأثیر بر سبک تولید، ایجاد شده توسط گره PixVerse Template | CUSTOM | خیر | - |

**نکته:** هنگام استفاده از کیفیت 1080p، حالت حرکت به‌طور خودکار روی normal تنظیم می‌شود و مدت زمان به ۵ ثانیه محدود می‌گردد. برای مدت‌های زمانی غیر از ۵ ثانیه نیز حالت حرکت به‌طور خودکار روی normal تنظیم می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `output` | ویدیوی تولیدشده بر اساس تصویر ورودی و پارامترها | VIDEO |
