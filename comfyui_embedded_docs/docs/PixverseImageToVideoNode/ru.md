# PixVerse: изображение в видео

Генерирует видео на основе входного изображения и текстового запроса. Этот узел принимает изображение и создает анимированное видео, применяя заданные настройки движения и качества, чтобы преобразовать статическое изображение в движущуюся последовательность.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для преобразования в видео | IMAGE | Да | - |
| `промпт` | Запрос для генерации видео | STRING | Да | - |
| `качество` | Настройка качества видео (по умолчанию: res_540p) | COMBO | Да | `res_540p`<br>`res_1080p` |
| `длительность_секунды` | Продолжительность сгенерированного видео в секундах | COMBO | Да | `dur_2`<br>`dur_5`<br>`dur_10` |
| `режим движения` | Стиль движения, применяемый при генерации видео | COMBO | Да | `normal`<br>`fast`<br>`slow`<br>`zoom_in`<br>`zoom_out`<br>`pan_left`<br>`pan_right`<br>`pan_up`<br>`pan_down`<br>`tilt_up`<br>`tilt_down`<br>`roll_clockwise`<br>`roll_counterclockwise` |
| `seed` | Сид для генерации видео (по умолчанию: 0) | INT | Да | 0-2147483647 |
| `негативный промпт` | Необязательное текстовое описание нежелательных элементов на изображении | STRING | Нет | - |
| `pixverse_template` | Необязательный шаблон, влияющий на стиль генерации, созданный узлом PixVerse Template | CUSTOM | Нет | - |

**Примечание:** При использовании качества 1080p режим движения автоматически устанавливается на normal, а продолжительность ограничена 5 секундами. Для продолжительности, отличной от 5 секунд, режим движения также автоматически устанавливается на normal.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео на основе входного изображения и параметров | VIDEO |
