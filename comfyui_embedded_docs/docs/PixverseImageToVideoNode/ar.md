# بيكسفيرس صورة إلى فيديو

تولّد هذه العقدة فيديو من صورة ثابتة وموجّه نصي باستخدام PixVerse. تقوم العقدة برفع الصورة المدخلة، وتطبيق إعدادات الجودة والمدة والحركة المحددة، ثم تعيد الفيديو الناتج بعد انتهاء التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة المطلوب تحويلها إلى فيديو | IMAGE | نعم | - |
| `prompt` | الموجّه لتوليد الفيديو (الافتراضي: سلسلة نصية فارغة) | STRING | نعم | - |
| `quality` | إعداد جودة الفيديو (الافتراضي: res_540p) | COMBO | نعم | `res_540p`<br>`res_1080p` |
| `duration_seconds` | مدة الفيديو المولّد بالثواني | COMBO | نعم | `dur_2`<br>`dur_5`<br>`dur_10` |
| `motion_mode` | نمط الحركة المطبق على توليد الفيديو | COMBO | نعم | `normal`<br>`fast`<br>`slow`<br>`zoom_in`<br>`zoom_out`<br>`pan_left`<br>`pan_right`<br>`pan_up`<br>`pan_down`<br>`tilt_up`<br>`tilt_down`<br>`roll_clockwise`<br>`roll_counterclockwise` |
| `seed` | البذرة المستخدمة لتوليد الفيديو (الافتراضي: 0) | INT | نعم | 0-2147483647 |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: سلسلة نصية فارغة) | STRING | لا | - |
| `pixverse_template` | قالب اختياري للتأثير على أسلوب التوليد، يُنشأ بواسطة عقدة PixVerse Template | CUSTOM | لا | - |

**ملاحظة:** عند استخدام جودة 1080p، يتم تعيين وضع الحركة تلقائيًا إلى normal وتقتصر المدة على 5 ثوانٍ. وبالنسبة للمدد التي تختلف عن 5 ثوانٍ، يتم أيضًا تعيين وضع الحركة تلقائيًا إلى normal.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | الفيديو المولّد بناءً على الصورة المدخلة والمعاملات | VIDEO |
