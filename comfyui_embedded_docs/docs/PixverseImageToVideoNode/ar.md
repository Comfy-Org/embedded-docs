# بيكسفيرس صورة إلى فيديو

يُنشئ مقاطع فيديو استنادًا إلى صورة إدخال ومطالبة نصية. تأخذ هذه العقدة صورةً وتُنشئ مقطع فيديو متحركًا من خلال تطبيق إعدادات الحركة والجودة المحددة لتحويل الصورة الثابتة إلى تسلسل متحرك.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|---------|--------|---------------|--------|--------|
| `الصورة` | صورة الإدخال المراد تحويلها إلى فيديو | IMAGE | نعم | - |
| `النص المطلوب` | المطالبة النصية لتوليد الفيديو | STRING | نعم | - |
| `الجودة` | إعداد جودة الفيديو (الافتراضي: res_540p) | COMBO | نعم | `res_540p`<br>`res_1080p` |
| `مدة الثواني` | مدة الفيديو المُولَّد بالثواني | COMBO | نعم | `dur_2`<br>`dur_5`<br>`dur_10` |
| `وضع الحركة` | نمط الحركة المطبَّق على توليد الفيديو | COMBO | نعم | `normal`<br>`fast`<br>`slow`<br>`zoom_in`<br>`zoom_out`<br>`pan_left`<br>`pan_right`<br>`pan_up`<br>`pan_down`<br>`tilt_up`<br>`tilt_down`<br>`roll_clockwise`<br>`roll_counterclockwise` |
| `البذرة` | قيمة البذرة (Seed) لتوليد الفيديو (الافتراضي: 0) | INT | نعم | 0-2147483647 |
| `نص المطالبة السلبية` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة | STRING | لا | - |
| `قالب بيكسفيرس` | قالب اختياري للتأثير على نمط التوليد، تم إنشاؤه بواسطة عقدة PixVerse Template | CUSTOM | لا | - |

**ملاحظة:** عند استخدام جودة 1080p، يتم تعيين نمط الحركة تلقائيًا إلى normal وتكون المدة محدودة بـ 5 ثوانٍ. بالنسبة للمدد غير 5 ثوانٍ، يتم أيضًا تعيين نمط الحركة تلقائيًا إلى normal.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|------------|--------|--------------|
| `output` | فيديو مُولَّد استنادًا إلى صورة الإدخال والمعاملات | VIDEO |
