# QwenImageDiffsynthControlnet

Узел QwenImageDiffsynthControlnet применяет патч управляющей сети диффузионного синтеза для изменения поведения базовой модели. Он использует входное изображение и опциональную маску для управления процессом генерации модели с регулируемой силой воздействия, создавая пропатченную модель, которая учитывает влияние управляющей сети для более контролируемого синтеза изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Базовая модель, к которой применяется патч управляющей сети | MODEL | Да | - |
| `model_patch` | Патч управляющей сети, применяемый к базовой модели | MODEL_PATCH | Да | - |
| `vae` | VAE (вариационный автокодировщик), используемый в процессе диффузии | VAE | Да | - |
| `image` | Входное изображение, используемое для управления сетью (используются только RGB-каналы) | IMAGE | Да | - |
| `strength` | Сила влияния управляющей сети (по умолчанию: 1.0) | FLOAT | Да | от -10.0 до 10.0 (шаг: 0.01) |
| `mask` | Опциональная маска, определяющая области, где должна применяться управляющая сеть (внутренне инвертируется) | MASK | Нет | - |

**Примечание:** Если маска задана, она автоматически инвертируется (1.0 - маска) и изменяет свою форму в соответствии с размерами, ожидаемыми при обработке управляющей сетью. Если патч модели относится к типу ZImage Control, патч применяется как к шумовому рефайнеру, так и к двойным блокам; для стандартной управляющей сети DiffSynth применяется только патч двойных блоков.
