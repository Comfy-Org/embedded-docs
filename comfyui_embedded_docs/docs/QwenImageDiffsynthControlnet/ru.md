# QwenImageDiffsynthControlnet

QwenImageDiffsynthControlnet применяет патч сети управления диффузионным синтезом к базовой модели. Он использует входное изображение и необязательную маску для управления процессом генерации модели с регулируемой силой воздействия, создавая модифицированную модель, которая учитывает влияние сети управления для более контролируемого синтеза изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Базовая модель, к которой применяется патч сети управления | MODEL | Да | - |
| `патч_модели` | Модель патча сети управления для применения к базовой модели | MODEL_PATCH | Да | - |
| `vae` | VAE (вариационный автокодировщик), используемый в процессе диффузии | VAE | Да | - |
| `изображение` | Входное изображение, используемое для управления сетью управления. Используются только первые три цветовых канала (RGB); все дополнительные каналы отбрасываются | IMAGE | Да | - |
| `интенсивность` | Сила влияния сети управления (по умолчанию: 1.0) | FLOAT | Да | -10.0 до 10.0 |
| `маска` | Необязательная маска, определяющая области, где должна применяться сеть управления. Маска инвертируется внутренне перед использованием | MASK | Нет | - |

**Примечание:** Если маска предоставлена, она автоматически инвертируется (1.0 - mask) и изменяет форму в соответствии с ожидаемыми размерами для обработки сетью управления. Узел использует различные внутренние методы обработки в зависимости от того, является ли патч модели типом ZImage Control или стандартной сетью управления DiffSynth. Этот узел помечен как экспериментальный.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененным патчем сети управления диффузионным синтезом | MODEL |
