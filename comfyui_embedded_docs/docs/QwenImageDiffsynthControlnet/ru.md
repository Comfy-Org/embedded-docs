# QwenImageDiffsynthControlnet

QwenImageDiffsynthControlnet применяет патч управляющей сети диффузионного синтеза к базовой модели. Он использует входное изображение и необязательную маску для управления процессом генерации модели с настраиваемой силой, создавая пропатченную модель, которая включает влияние управляющей сети для более контролируемого синтеза изображений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Базовая модель, к которой применяется патч управляющей сети | MODEL | Да | - |
| `патч_модели` | Модель-патч управляющей сети, применяемая к базовой модели | MODEL_PATCH | Да | - |
| `vae` | VAE (вариационный автоэнкодер), используемый в процессе диффузии | VAE | Да | - |
| `изображение` | Входное изображение, используемое для управления управляющей сетью. Используются только первые три цветовых канала (RGB); все дополнительные каналы отбрасываются | IMAGE | Да | - |
| `интенсивность` | Сила влияния управляющей сети (по умолчанию: 1.0) | FLOAT | Да | от -10.0 до 10.0 (шаг 0.01) |
| `маска` | Необязательная маска, определяющая области, где должна применяться управляющая сеть. Для патчей DiffSynth и Z-Image маска перед использованием инвертируется внутренне | MASK | Нет | - |
| `start_percent` | Точка в процессе удаления шума, выраженная как доля от общего числа шагов сэмплирования, в которой управляющая сеть начинает действовать (по умолчанию: 0.0) | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |
| `end_percent` | Точка в процессе удаления шума, в которой управляющая сеть перестаёт действовать (по умолчанию: 1.0) | FLOAT | Нет | от 0.0 до 1.0 (шаг 0.001) |

**Примечание:** Значения `start_percent` и `end_percent` ограничивают работу управляющей сети окном процесса удаления шума; вне этого окна модель сэмплируется без патча. Если для `strength` задано значение 0, узел возвращает базовую модель без изменений. Если маска предоставлена, она инвертируется (1.0 - mask) и приводится к нужной форме для путей Z-Image Control и стандартного DiffSynth, тогда как патч Qwen Image 2.1 Fun ControlNet использует маску как есть. Узел выбирает внутреннюю реализацию патча из загруженного патча модели, поэтому одни и те же входы ведут себя немного по-разному для Z-Image Control, Qwen Image 2.1 Fun ControlNet и стандартных чекпоинтов DiffSynth. Этот узел помечен как экспериментальный.
