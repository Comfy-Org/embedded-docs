# QwenImageDiffsynthControlnet

QwenImageDiffsynthControlnet یک پچ شبکه کنترلی سنتز دیفیوژن را روی مدل پایه اعمال می‌کند. این گره از یک تصویر ورودی و یک ماسک اختیاری برای هدایت فرآیند تولید مدل با شدت قابل تنظیم استفاده می‌کند و مدلی پچ‌شده تولید می‌کند که تأثیر شبکه کنترلی را برای سنتز تصویر کنترل‌شده‌تر در خود دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل پایه که با شبکه کنترلی پچ می‌شود | MODEL | بله | - |
| `patch مدل` | مدل پچ شبکه کنترلی که روی مدل پایه اعمال می‌شود | MODEL_PATCH | بله | - |
| `vae` | VAE (خودرمزگذار متغیر) مورد استفاده در فرآیند دیفیوژن | VAE | بله | - |
| `تصویر` | تصویر ورودی که برای هدایت شبکه کنترلی استفاده می‌شود. فقط سه کانال رنگی اول (RGB) استفاده می‌شود؛ هر کانال اضافی نادیده گرفته می‌شود | IMAGE | بله | - |
| `شدت` | شدت تأثیر شبکه کنترلی (پیش‌فرض: 1.0) | FLOAT | بله | 10.0- تا 10.0 |
| `ماسک` | ماسک اختیاری که نواحی اعمال شبکه کنترلی را مشخص می‌کند. ماسک به‌صورت داخلی قبل از استفاده معکوس می‌شود | MASK | خیر | - |

**نکته:** وقتی ماسک ارائه می‌شود، به‌صورت خودکار معکوس شده (1.0 - ماسک) و تغییر شکل می‌یابد تا با ابعاد مورد انتظار برای پردازش شبکه کنترلی مطابقت یابد. این گره بسته به اینکه مدل پچ از نوع ZImage Control یا شبکه کنترلی استاندارد DiffSynth باشد، از روش‌های پردازش داخلی متفاوتی استفاده می‌کند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
