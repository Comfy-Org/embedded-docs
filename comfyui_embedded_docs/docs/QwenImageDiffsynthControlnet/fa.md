# QwenImageDiffsynthControlnet

گره `QwenImageDiffsynthControlnet` یک وصله شبکۀ کنترلی سنتز انتشار را اعمال می‌کند تا رفتار مدل پایه را تغییر دهد. این گره از یک ورودی تصویر و ماسک اختیاری برای هدایت فرآیند تولید مدل با شدت قابل‌تنظیم استفاده می‌کند و مدلی وصله‌شده ایجاد می‌کند که تأثیر شبکه‌های کنترلی را برای سنتز تصویر کنترل‌شده‌تر در خود دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل پایه‌ای که قرار است با شبکه کنترلی وصله شود | MODEL | بله | - |
| `model_patch` | مدل وصله شبکه کنترلی که روی مدل پایه اعمال می‌شود | MODEL_PATCH | بله | - |
| `vae` | VAE (خودرمزگذار متغیر) مورد استفاده در فرآیند انتشار | VAE | بله | - |
| `image` | تصویر ورودی برای هدایت شبکه کنترلی (فقط کانال‌های RGB استفاده می‌شوند) | IMAGE | بله | - |
| `strength` | شدت تأثیر شبکه کنترلی (پیش‌فرض: 1.0) | FLOAT | بله | 10.0- تا 10.0 (گام: 0.01) |
| `mask` | ماسک اختیاری که نواحی اعمال شبکه کنترلی را مشخص می‌کند (داخلی معکوس می‌شود) | MASK | خیر | - |

**توجه:** وقتی ماسک ارائه می‌شود، به‌طور خودکار معکوس می‌شود (1.0 - mask) و به ابعاد مورد انتظار پردازش شبکه کنترلی تغییر شکل می‌یابد. وقتی وصله مدل از نوع ZImage Control باشد، وصله هم بر روی پالایشگر نویز و هم بر روی بلوک‌های دوگانه اعمال می‌شود؛ برای یک شبکه کنترلی استاندارد DiffSynth، فقط وصله بلوک دوگانه اعمال می‌شود.
