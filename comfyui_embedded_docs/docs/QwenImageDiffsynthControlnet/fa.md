# QwenImageDiffsynthControlnet

QwenImageDiffsynthControlnet یک وصله شبکه کنترل سنتز انتشار را به مدل پایه اعمال می‌کند. این گره از یک تصویر ورودی و یک ماسک اختیاری برای هدایت فرایند تولید مدل با شدت قابل تنظیم استفاده می‌کند و مدل وصله‌شده‌ای تولید می‌کند که تأثیر شبکه کنترل را برای سنتز تصویر کنترل‌شده‌تر در خود دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
| --- | --- | --- | --- | --- |
| `مدل` | مدل پایه برای وصله‌شدن با شبکه کنترل | MODEL | بله | - |
| `patch مدل` | وصله شبکه کنترل برای اعمال روی مدل پایه | MODEL_PATCH | بله | - |
| `vae` | VAE (خودرمزگذار متغیری) مورد استفاده در فرایند انتشار | VAE | بله | - |
| `تصویر` | تصویر ورودی مورد استفاده برای هدایت شبکه کنترل. فقط سه کانال رنگی اول (RGB) استفاده می‌شود؛ هر کانال اضافی دیگری دور انداخته می‌شود | IMAGE | بله | - |
| `شدت` | شدت تأثیر شبکه کنترل (پیش‌فرض: 1.0) | FLOAT | بله | -10.0 تا 10.0 (گام 0.01) |
| `ماسک` | ماسک اختیاری که نواحی اعمال شبکه کنترل را تعیین می‌کند. برای وصله‌های DiffSynth و Z-Image، ماسک پیش از استفاده به‌صورت داخلی معکوس می‌شود | MASK | خیر | - |
| `start_percent` | نقطه‌ای در فرایند نویززدایی، به‌صورت کسری از کل گام‌های نمونه‌برداری، که شبکه کنترل در آن شروع به اثرگذاری می‌کند (پیش‌فرض: 0.0) | FLOAT | خیر | 0.0 تا 1.0 (گام 0.001) |
| `end_percent` | نقطه‌ای در فرایند نویززدایی که شبکه کنترل در آن اثرگذاری را متوقف می‌کند (پیش‌فرض: 1.0) | FLOAT | خیر | 0.0 تا 1.0 (گام 0.001) |

**توجه:** مقادیر `start_percent` و `end_percent` شبکه کنترل را به بازه‌ای از فرایند نویززدایی محدود می‌کنند؛ خارج از آن بازه، مدل بدون وصله نمونه‌برداری می‌شود. اگر `strength` روی 0 تنظیم شود، گره مدل پایه را بدون تغییر برمی‌گرداند. هنگامی که ماسکی ارائه شود، معکوس (1.0 - mask) و برای مسیرهای Z-Image Control و DiffSynth استاندارد تغییر شکل داده می‌شود، در حالی که وصله Qwen Image 2.1 Fun ControlNet از ماسک همان‌گونه که داده شده استفاده می‌کند. این گره پیاده‌سازی داخلی وصله خود را از وصله مدل بارگذاری‌شده انتخاب می‌کند، بنابراین ورودی‌های یکسان برای Z-Image Control، Qwen Image 2.1 Fun ControlNet و چک‌پوینت‌های DiffSynth استاندارد رفتار کمی متفاوت دارند. این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
