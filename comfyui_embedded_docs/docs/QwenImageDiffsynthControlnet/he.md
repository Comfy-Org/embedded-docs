# הפעל Qwen Image DiffSynth ControlNet

QwenImageDiffsynthControlnet מחיל טלאי רשת בקרה לסינתזת דיפוזיה על מודל בסיס. הוא משתמש בתמונת קלט ובמסכה אופציונלית כדי להנחות את תהליך היצירה של המודל בעוצמה ניתנת להתאמה, ומייצר מודל שעליו הוחל טלאי שמשלב את השפעת רשת הבקרה לסינתזת תמונה מבוקרת יותר.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הבסיס שעליו יש להחיל את טלאי רשת הבקרה | MODEL | כן | - |
| `model_patch` | מודל טלאי רשת הבקרה שיש להחיל על מודל הבסיס | MODEL_PATCH | כן | - |
| `vae` | ה-VAE (מקודד אוטומטי וריאציוני) המשמש בתהליך הדיפוזיה | VAE | כן | - |
| `image` | תמונת הקלט המשמשת להנחות את רשת הבקרה. רק שלושת ערוצי הצבע הראשונים (RGB) משמשים; ערוצים נוספים נזרקים | IMAGE | כן | - |
| `strength` | עוצמת ההשפעה של רשת הבקרה (ברירת מחדל: 1.0) | FLOAT | כן | -10.0 to 10.0 (step 0.01) |
| `mask` | מסכה אופציונלית המגדירה אזורים שבהם יש להחיל את רשת הבקרה. עבור טלאי DiffSynth ו-Z-Image המסכה מתהפכת באופן פנימי לפני השימוש | MASK | לא | - |
| `start_percent` | הנקודה בתהליך הסרת הרעש, כשבר מהשלבים הכוללים של הדגימה, שבה רשת הבקרה מתחילה להשפיע (ברירת מחדל: 0.0) | FLOAT | לא | 0.0 to 1.0 (step 0.001) |
| `end_percent` | הנקודה בתהליך הסרת הרעש שבה רשת הבקרה מפסיקה להשפיע (ברירת מחדל: 1.0) | FLOAT | לא | 0.0 to 1.0 (step 0.001) |

**הערה:** הערכים `start_percent` ו-`end_percent` מגבילים את רשת הבקרה לחלון בתהליך הסרת הרעש; מחוץ לחלון זה המודל נדגם ללא הטלאי. אם `strength` מוגדר ל-0, הצומת מחזיר את מודל הבסיס ללא שינוי. כאשר מסופקת מסכה, היא מתהפכת (1.0 - mask) ומעוצבת מחדש עבור מסלולי Z-Image Control ו-DiffSynth הסטנדרטיים, בעוד שטלאי Qwen Image 2.1 Fun ControlNet משתמש במסכה כפי שהיא. הצומת בוחר את מימוש הטלאי הפנימי שלו ממודל הטלאי הנטען, כך שאותם קלטים מתנהגים מעט שונה עבור Z-Image Control, Qwen Image 2.1 Fun ControlNet, ונקודות ביקורת DiffSynth סטנדרטיות. צומת זה מסומן כניסיוני.
