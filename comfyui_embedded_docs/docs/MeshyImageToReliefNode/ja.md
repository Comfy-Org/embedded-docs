# Meshy: Image to Relief

このノードは、写真を 3D プリント、レーザー彫刻、CNC 彫刻用の浅浮き彫りモデルと 16 ビット深度マップに変換します。明るい背景上の暗い図柄が盛り上がり、明るい領域は低く保たれます。接続した出力のみが生成・ダウンロードされるため、モデル出力を接続しない場合、タスクは深度マップのみを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | レリーフに変換する写真。明るい背景上の暗い図柄が盛り上がります。アップロード前に透明部分は削除されるため、透明なロゴはあらかじめ白い背景に合成してください。 | IMAGE | はい | 単一画像 |
| `relief_type` | 彫刻プリセット。`"low"` はレーザー彫刻、CNC 加工、銘板向けの浅い彫刻です。`"high"` は 3D プリント品向けのより深い彫刻です。プリセットは `carving_depth_mm` の値を選択します。 | DYNAMIC_COMBO | はい | `"low"`<br>`"high"` |
| `carving_depth_mm` | 彫刻の深さ（ミリメートル）。`relief_type` が設定されている場合に使用できます（デフォルト: `"low"` では 3.0、`"high"` では 6.0）。 | FLOAT | はい | 0.1～60.0（ステップ 0.1） |
| `size_mm` | モデル上での写真の長辺の長さ（ミリメートル）。曲げを適用する前の平らな状態で測定します（デフォルト: 60.0）。 | FLOAT | はい | 20.0～250.0（ステップ 1.0） |
| `carving_mode` | `"emboss"` は写真の手前側の部分を盛り上げ、`"engrave"` はそれらを彫り込みます。 | COMBO | はい | `"emboss"`<br>`"engrave"` |
| `base` | `"plate"` はレリーフの下にベースプレートを保持し、`"none"` は背景を切り取ってプレートを作成しません。オプションを選択すると、そのパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"plate"`<br>`"none"` |
| `base_thickness_mm` | ベースプレートの厚さ（ミリメートル）。`base` が `"plate"` の場合に使用できます（デフォルト: 1.0）。 | FLOAT | はい | 0.1～10.0（ステップ 0.1） |
| `removal_threshold` | 0～1 の深度マップ上で、この深さを下回る背景を切り取ります。0.3 では胸像が全体として保たれ、0.8 では断片に分かれます。`base` が `"none"` の場合に使用できます（デフォルト: 0.01）。 | FLOAT | はい | 0.01～1.0（ステップ 0.01） |
| `bend` | `"convex"` は前面を外側へ膨らませ、`"concave"` は内側へ湾曲させ、`"off"` はレリーフを平らに保ちます。曲げを選択すると、`bend_axis` と `bend_angle` が表示されます。 | DYNAMIC_COMBO | はい | `"off"`<br>`"convex"`<br>`"concave"` |
| `bend_axis` | `"xz"` は左右の端を反らせ、`"yz"` は上下の端を反らせます。`bend` が `"convex"` または `"concave"` の場合に使用できます。 | COMBO | はい | `"xz"`<br>`"yz"` |
| `bend_angle` | 曲げが及ぶ円弧の角度（度）。360 にするとレリーフが閉じて円筒になります。`bend` が `"convex"` または `"concave"` の場合に使用できます（デフォルト: 60.0）。 | FLOAT | はい | 1.0～360.0（ステップ 1.0） |
| `seed` | ノードを再実行するかどうかを制御するシードです。結果はシードにかかわらず非決定的です。前回の実行後に接続した出力を生成するには、この値を変更してください（デフォルト: 42）。 | INT | はい | 0～2147483647 |
| `mesh_resolution` | 写真の長辺方向のメッシュ点数。1024 では GLB が約 50 MB、STL が約 105 MB、2048 では約 200 MB と 420 MB になります。曲げを適用するとこれらのサイズは 2 倍になります。（デフォルト: 1024、詳細オプション） | INT | はい | 512～2048 |
| `color_mapping` | GLB、OBJ、FBX、USDZ ファイルを写真で彩色します。STL と 3MF は白のままです。（デフォルト: False、詳細オプション） | BOOLEAN | はい | True または False |

**注:** モデル形式は、その出力が接続されている場合にのみ生成およびダウンロードされます。モデル出力を接続しない場合、タスクは深度マップのみを返します。また、`preview` のみを接続した場合も、サムネイル用にモデルは生成されますが、モデルファイルは返されません。`depth_map` は 16 ビットの全範囲を保持します。Save Image (Advanced) はそれを 16 ビット PNG として書き出します。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `GLB` | GLB 形式でダウンロードされるレリーフモデル。 | FILE3DGLB |
| `STL` | STL 形式でダウンロードされるレリーフモデル。 | FILE3DSTL |
| `OBJ` | OBJ 形式でダウンロードされるレリーフモデル。 | FILE3DOBJ |

| `preview` | 完成したレリーフに対して Meshy がレンダリングしたサムネイル。 | IMAGE |
