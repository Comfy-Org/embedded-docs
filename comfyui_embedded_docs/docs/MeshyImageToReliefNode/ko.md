# Meshy: Image to Relief

이 노드는 사진을 부조(bas-relief) 모델과 16비트 뎁스 맵으로 변환하여 3D 프린팅, 레이저 각인, CNC 조각에 사용할 수 있게 합니다. 밝은 배경 위의 어두운 그림은 융기되고, 밝은 영역은 낮게 유지됩니다. 연결한 출력만 생성 및 다운로드되므로, 모델 출력을 연결하지 않으면 작업은 뎁스 맵만 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 부조로 변환할 사진입니다. 밝은 배경 위의 어두운 그림이 융기됩니다. 업로드 전에 투명도가 제거되므로, 투명한 로고는 먼저 흰색 배경 위에 평탄화해야 합니다. | IMAGE | 예 | 단일 이미지 |
| `relief_type` | 조각 프리셋입니다. `"low"`는 레이저 각인, CNC 작업 및 명판용 얕은 조각이며, `"high"`는 3D 프린팅 부품용으로 더 깊습니다. 이 프리셋은 `carving_depth_mm` 값을 선택합니다. | DYNAMIC_COMBO | 예 | `"low"`<br>`"high"` |
| `carving_depth_mm` | 밀리미터 단위의 조각 깊이입니다. `relief_type`이 설정되면 사용할 수 있습니다(기본값: `"low"`의 경우 3.0, `"high"`의 경우 6.0). | FLOAT | 예 | 0.1 ~ 60.0 (단계: 0.1) |
| `size_mm` | 모델에서 사진의 긴 변 길이를 밀리미터로 나타낸 값이며, 굽힘 전 평면 상태에서 측정합니다(기본값: 60.0). | FLOAT | 예 | 20.0 ~ 250.0 (단계: 1.0) |
| `carving_mode` | `"emboss"`는 사진에서 더 가까운 부분을 융기시키고, `"engrave"`는 그 부분을 파냅니다. | COMBO | 예 | `"emboss"`<br>`"engrave"` |
| `base` | `"plate"`는 부조 아래에 베이스 플레이트를 유지하고, `"none"`은 배경을 잘라내고 플레이트를 만들지 않습니다. 옵션을 선택하면 해당 매개변수가 나타납니다. | DYNAMIC_COMBO | 예 | `"plate"`<br>`"none"` |
| `base_thickness_mm` | 밀리미터 단위의 베이스 플레이트 두께입니다. `base`가 `"plate"`일 때 사용할 수 있습니다(기본값: 1.0). | FLOAT | 예 | 0.1 ~ 10.0 (단계: 0.1) |
| `removal_threshold` | 0 ~ 1 뎁스 맵에서 배경이 잘려나가는 기준 깊이입니다. 0.3은 흉상을 온전하게 유지하고, 0.8은 조각으로 분해합니다. `base`가 `"none"`일 때 사용할 수 있습니다(기본값: 0.01). | FLOAT | 예 | 0.01 ~ 1.0 (단계: 0.01) |
| `bend` | `"convex"`는 앞면을 바깥으로 볼록하게 만들고, `"concave"`는 안쪽으로 휘게 하며, `"off"`는 부조를 평평하게 유지합니다. 굽힘을 선택하면 `bend_axis`와 `bend_angle`이 나타납니다. | DYNAMIC_COMBO | 예 | `"off"`<br>`"convex"`<br>`"concave"` |
| `bend_axis` | `"xz"`는 좌우 가장자리를 말아 올리고, `"yz"`는 위아래 가장자리를 말아 올립니다. `bend`가 `"convex"` 또는 `"concave"`일 때 사용할 수 있습니다. | COMBO | 예 | `"xz"`<br>`"yz"` |
| `bend_angle` | 굽힘이 차지하는 호의 각도(도)입니다. 360은 부조를 원통으로 닫습니다. `bend`가 `"convex"` 또는 `"concave"`일 때 사용할 수 있습니다(기본값: 60.0). | FLOAT | 예 | 1.0 ~ 360.0 (단계: 1.0) |
| `seed` | 노드의 재실행 여부를 제어하는 시드입니다. 시드와 무관하게 결과는 비결정적입니다. 마지막 실행 이후 연결된 출력을 요청하려면 값을 변경하십시오(기본값: 42). | INT | 예 | 0 ~ 2147483647 |
| `mesh_resolution` | 사진의 긴 변을 따라 배치되는 메시 점의 수입니다. 1024에서는 GLB가 약 50 MB, STL이 약 105 MB이고, 2048에서는 약 200 MB와 420 MB이며, 굽힘을 적용하면 두 배가 됩니다. (기본값: 1024, 고급 옵션) | INT | 예 | 512 ~ 2048 |
| `color_mapping` | GLB, OBJ, FBX, USDZ 파일에 사진의 색상을 입힙니다. STL과 3MF는 흰색으로 유지됩니다. (기본값: False, 고급 옵션) | BOOLEAN | 예 | True / False |

**참고:** 모델 형식은 해당 출력이 연결된 경우에만 생성 및 다운로드됩니다. 모델 출력을 연결하지 않으면 작업은 뎁스 맵만 반환하며, `preview`만 연결한 경우에도 썸네일용으로 모델은 생성되지만 모델 파일은 반환되지 않습니다. `depth_map`은 16비트 전체 범위를 유지하며, Save Image (Advanced)는 이를 16비트 PNG로 저장합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `GLB` | GLB 형식으로 다운로드된 부조 모델입니다. | FILE3DGLB |
| `STL` | STL 형식으로 다운로드된 부조 모델입니다. | FILE3DSTL |
| `OBJ` | OBJ 형식으로 다운로드된 부조 모델입니다. | FILE3DOBJ |
| `FBX` | FBX 형식으로 다운로드된 부조 모델입니다. | FILE3DFBX |
| `USDZ` | USDZ 형식으로 다운로드된 부조 모델입니다. | FILE3DUSDZ |
| `3MF` | 3MF 형식으로 다운로드된 부조 모델입니다. | FILE3D |
| `depth_map` | 16비트 전체 범위를 가진 뎁스 맵입니다. Save Image (Advanced)는 이를 16비트 PNG로 저장합니다. | IMAGE |
| `preview` | 완성된 부조를 위해 Meshy가 렌더링한 썸네일입니다. | IMAGE |
