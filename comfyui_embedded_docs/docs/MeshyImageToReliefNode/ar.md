# Meshy: Image to Relief

هذه العقدة تحوّل صورة إلى نموذج نقش بارز مع خريطة عمق 16 بت للطباعة ثلاثية الأبعاد والنقش بالليزر والحفر باستخدام CNC. تُرفَع الأعمال الفنية الداكنة على خلفية فاتحة، بينما تبقى المناطق الفاتحة منخفضة. لا تُولَّد وتُنزَّل إلا المخرجات التي توصلها، لذا عند عدم توصيل أي مخرج نموذج فإن المهمة تُرجع خريطة العمق فقط.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة لتحويلها إلى نقش بارز. تُرفَع الأعمال الفنية الداكنة على خلفية فاتحة. تُسقَط الشفافية قبل الرفع، لذا اجعل الشعار الشفاف مسطحًا على خلفية بيضاء أولًا. | IMAGE | نعم | صورة واحدة |
| `relief_type` | إعداد مسبق للحفر. `"low"` حفر ضحل للنقش بالليزر وأعمال CNC واللوحات؛ `"high"` أعمق لقطع الطباعة ثلاثية الأبعاد. يختار الإعداد المسبق قيمة `carving_depth_mm`. | DYNAMIC_COMBO | نعم | `"low"`<br>`"high"` |
| `carving_depth_mm` | عمق الحفر بالمليمترات. متاح عند ضبط `relief_type` (افتراضي: 3.0 لـ `"low"`، و6.0 لـ `"high"`). | FLOAT | نعم | 0.1 إلى 60.0 (خطوة 0.1) |
| `size_mm` | طول الضلع الأطول للصورة على النموذج بالمليمترات، مقيسًا مسطحًا قبل أي انحناء (افتراضي: 60.0). | FLOAT | نعم | 20.0 إلى 250.0 (خطوة 1.0) |
| `carving_mode` | `"emboss"` يرفع الأجزاء الأقرب في الصورة، و`"engrave"` يحفرها للداخل. | COMBO | نعم | `"emboss"`<br>`"engrave"` |
| `base` | `"plate"` يبقي لوحة قاعدة أسفل النقش البارز، و`"none"` يقطع الخلفية ولا يبني لوحة. اختيار خيار يكشف معامله. | DYNAMIC_COMBO | نعم | `"plate"`<br>`"none"` |
| `base_thickness_mm` | سُمك لوحة القاعدة بالمليمترات. متاح عندما يكون `base` هو `"plate"` (افتراضي: 1.0). | FLOAT | نعم | 0.1 إلى 10.0 (خطوة 0.1) |
| `removal_threshold` | العمق الذي تُقطع الخلفية دونه، على خريطة العمق من 0 إلى 1. تحافظ 0.3 على تمثال نصفي كاملًا، بينما تقسّمه 0.8 إلى شظايا. متاح عندما يكون `base` هو `"none"` (افتراضي: 0.01). | FLOAT | نعم | 0.01 إلى 1.0 (خطوة 0.01) |
| `bend` | `"convex"` يجعل الواجهة تنتفخ للخارج، و`"concave"` يقوسها للداخل، و`"off"` يبقي النقش البارز مسطحًا. اختيار انحناء يكشف `bend_axis` و`bend_angle`. | DYNAMIC_COMBO | نعم | `"off"`<br>`"convex"`<br>`"concave"` |
| `bend_axis` | `"xz"` يلوي الحافتين اليسرى واليمنى، و`"yz"` الحافتين العلوية والسفلية. متاح عندما يكون `bend` هو `"convex"` أو `"concave"`. | COMBO | نعم | `"xz"`<br>`"yz"` |
| `bend_angle` | قوس الانحناء بالدرجات؛ 360 يغلق النقش البارز على شكل أسطوانة. متاح عندما يكون `bend` هو `"convex"` أو `"concave"` (افتراضي: 60.0). | FLOAT | نعم | 1.0 إلى 360.0 (خطوة 1.0) |
| `seed` | بذرة تتحكم في ما إذا كانت العقدة تعيد التشغيل؛ النتيجة غير حتمية بغض النظر عن البذرة. غيّرها لطلب مخرج تم توصيله بعد آخر تشغيل (افتراضي: 42). | INT | نعم | 0 إلى 2147483647 |
| `mesh_resolution` | نقاط الشبكة على طول الضلع الأطول للصورة. عند 1024 يكون GLB نحو 50 MB وSTL نحو 105 MB، وعند 2048 نحو 200 MB و420 MB؛ ويضاعف الانحناء هذه الأحجام. (افتراضي: 1024؛ خيار متقدم) | INT | نعم | 512 إلى 2048 |
| `color_mapping` | تلوين ملفات GLB وOBJ وFBX وUSDZ بالصورة. تبقى ملفات STL و3MF بيضاء. (افتراضي: False؛ خيار متقدم) | BOOLEAN | نعم | True أو False |

**ملاحظة:** لا تُنشأ صيغة نموذج وتُنزَّل إلا عند توصيل مخرجها. وعند عدم توصيل أي مخرج نموذج، تُرجع المهمة خريطة العمق فقط، كما أن `preview` وحده يظل يولّد النموذج من أجل الصورة المصغرة لكنه لا يُرجع ملف نموذج. يحتفظ `depth_map` بالنطاق الكامل 16 بت؛ ويكتبه Save Image (Advanced) كملف PNG 16 بت.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `GLB` | نموذج النقش البارز الذي يُنزَّل بصيغة GLB. | FILE3DGLB |
| `STL` | نموذج النقش البارز الذي يُنزَّل بصيغة STL. | FILE3DSTL |
| `OBJ` | نموذج النقش البارز الذي يُنزَّل بصيغة OBJ. | FILE3DOBJ |
| `FBX` | نموذج النقش البارز الذي يُنزَّل بصيغة FBX. | FILE3DFBX |
| `USDZ` | نموذج النقش البارز الذي يُنزَّل بصيغة USDZ. | FILE3DUSDZ |
| `3MF` | نموذج النقش البارز الذي يُنزَّل بصيغة 3MF. | FILE3D |
| `depth_map` | خريطة عمق بالنطاق الكامل 16 بت؛ يكتبها Save Image (Advanced) كملف PNG 16 بت. | IMAGE |
| `preview` | صورة مصغرة تُنتجها Meshy للنقش البارز النهائي. | IMAGE |
