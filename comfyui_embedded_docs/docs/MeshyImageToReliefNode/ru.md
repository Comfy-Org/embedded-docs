# Meshy: Image to Relief

Этот узел превращает фотографию в модель барельефа вместе с 16-битной картой глубины для 3D-печати, лазерной гравировки и ЧПУ-фрезеровки. Тёмный рисунок на светлом фоне приподнимается, а светлые участки остаются низкими. Генерируются и скачиваются только те выходы, которые вы подключите, поэтому при отсутствии подключённого выхода модели задача возвращает только карту глубины.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Фотография для преобразования в рельеф. Тёмный рисунок на светлом фоне приподнимается. Прозрачность отбрасывается перед загрузкой, поэтому сначала наложите прозрачный логотип на белый фон. | IMAGE | Да | Одно изображение |
| `relief_type` | Пресет гравировки. `"low"` — неглубокая гравировка для лазерной гравировки, ЧПУ-работ и табличек; `"high"` — более глубокая для 3D-печатных изделий. Пресет выбирает значение `carving_depth_mm`. | DYNAMIC_COMBO | Да | `"low"`<br>`"high"` |
| `carving_depth_mm` | Глубина гравировки в миллиметрах. Доступно, когда задан `relief_type` (по умолчанию: 3.0 для `"low"`, 6.0 для `"high"`). | FLOAT | Да | от 0.1 до 60.0 (шаг 0.1) |
| `size_mm` | Длина большей стороны фотографии на модели в миллиметрах, измеренная в плоском состоянии до любого изгиба (по умолчанию: 60.0). | FLOAT | Да | от 20.0 до 250.0 (шаг 1.0) |
| `carving_mode` | `"emboss"` приподнимает более близкие части фотографии, `"engrave"` врезает их. | COMBO | Да | `"emboss"`<br>`"engrave"` |
| `base` | `"plate"` сохраняет базовую пластину под рельефом, `"none"` вырезает фон и не создаёт пластину. Выбор опции открывает её параметр. | DYNAMIC_COMBO | Да | `"plate"`<br>`"none"` |
| `base_thickness_mm` | Толщина базовой пластины в миллиметрах. Доступно, когда `base` равно `"plate"` (по умолчанию: 1.0). | FLOAT | Да | от 0.1 до 10.0 (шаг 0.1) |
| `removal_threshold` | Глубина, ниже которой фон вырезается, на карте глубины от 0 до 1. 0.3 сохраняет бюст целым, 0.8 разбивает его на фрагменты. Доступно, когда `base` равно `"none"` (по умолчанию: 0.01). | FLOAT | Да | от 0.01 до 1.0 (шаг 0.01) |
| `bend` | `"convex"` выгибает переднюю часть наружу, `"concave"` изгибает её внутрь, `"off"` оставляет рельеф плоским. Выбор изгиба открывает `bend_axis` и `bend_angle`. | DYNAMIC_COMBO | Да | `"off"`<br>`"convex"`<br>`"concave"` |
| `bend_axis` | `"xz"` закручивает левый и правый края, `"yz"` — верхний и нижний края. Доступно, когда `bend` равно `"convex"` или `"concave"`. | COMBO | Да | `"xz"`<br>`"yz"` |
| `bend_angle` | Дуга изгиба в градусах; 360 замыкает рельеф в цилиндр. Доступно, когда `bend` равно `"convex"` или `"concave"` (по умолчанию: 60.0). | FLOAT | Да | от 1.0 до 360.0 (шаг 1.0) |
| `seed` | Сид, управляющий повторным запуском узла; результат недетерминирован независимо от сида. Измените его, чтобы запросить выход, подключённый после последнего запуска (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |
| `mesh_resolution` | Количество точек сетки вдоль большей стороны фотографии. При 1024 GLB весит около 50 МБ, а STL — около 105 МБ; при 2048 — около 200 МБ и 420 МБ; изгиб удваивает их. (по умолчанию: 1024; расширенная опция) | INT | Да | от 512 до 2048 |
| `color_mapping` | Окрашивать файлы GLB, OBJ, FBX и USDZ фотографией. STL и 3MF остаются белыми. (по умолчанию: False; расширенная опция) | BOOLEAN | Да | True / False |

**Примечание:** Формат модели генерируется и скачивается только тогда, когда подключён его выход. При отсутствии подключённого выхода модели задача возвращает только карту глубины, а один только `preview` всё равно генерирует модель для миниатюры, но не возвращает файл модели. `depth_map` сохраняет полный 16-битный диапазон; Save Image (Advanced) записывает его как 16-битный PNG.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `GLB` | Модель рельефа, скачанная в формате GLB. | FILE3DGLB |
| `STL` | Модель рельефа, скачанная в формате STL. | FILE3DSTL |
| `OBJ` | Модель рельефа, скачанная в формате OBJ. | FILE3DOBJ |
| `FBX` | Модель рельефа, скачанная в формате FBX. | FILE3DFBX |
| `USDZ` | Модель рельефа, скачанная в формате USDZ. | FILE3DUSDZ |
| `3MF` | Модель рельефа, скачанная в формате 3MF. | FILE3D |
| `depth_map` | Карта глубины с полным 16-битным диапазоном; Save Image (Advanced) записывает её как 16-битный PNG. | IMAGE |
| `preview` | Миниатюра, отрисованная Meshy для готового рельефа. | IMAGE |
