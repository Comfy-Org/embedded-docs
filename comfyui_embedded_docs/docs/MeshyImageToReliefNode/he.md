# Meshy: Image to Relief

הצומת הופך תמונה למודל תבליט בתוספת מפת עומק 16-ביט להדפסת תלת-ממד, חריטת לייזר וחריטת CNC. איור כהה על רקע בהיר מובלט, ואזורים בהירים נשארים נמוכים. רק הפלטים שאתם מחברים נוצרים ומורדים, לכן כאשר לא מחובר פלט מודל המשימה מחזירה רק את מפת העומק.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונה להמרה לתבליט. איור כהה על רקע בהיר מובלט. שקיפות מוסרת לפני ההעלאה, לכן יש להשטיח לוגו שקוף על רקע לבן תחילה. | IMAGE | כן | תמונה בודדת |
| `relief_type` | הגדרה מוקדמת לחריטה. `"low"` היא חריטה רדודה לחריטת לייזר, עבודות CNC ושלטים; `"high"` עמוקה יותר עבור פריטים מודפסים בתלת-ממד. ההגדרה המוקדמת בוחרת את הערך של `carving_depth_mm`. | DYNAMIC_COMBO | כן | `"low"`<br>`"high"` |
| `carving_depth_mm` | עומק החריטה במילימטרים. זמין כאשר `relief_type` מוגדר (ברירת מחדל: 3.0 עבור `"low"`, 6.0 עבור `"high"`). | FLOAT | כן | 0.1 עד 60.0 (צעד 0.1) |
| `size_mm` | אורך הצלע הארוכה של התמונה על המודל במילימטרים, נמדד שטוח לפני כיפוף כלשהו (ברירת מחדל: 60.0). | FLOAT | כן | 20.0 עד 250.0 (צעד 1.0) |
| `carving_mode` | `"emboss"` מבליט את החלקים הקרובים יותר של התמונה, `"engrave"` חורט אותם פנימה. | COMBO | כן | `"emboss"`<br>`"engrave"` |
| `base` | `"plate"` משאיר לוחית בסיס מתחת לתבליט, `"none"` מסיר את הרקע ואינו בונה לוחית. בחירת אפשרות חושפת את הפרמטר שלה. | DYNAMIC_COMBO | כן | `"plate"`<br>`"none"` |
| `base_thickness_mm` | עובי לוחית הבסיס במילימטרים. זמין כאשר `base` הוא `"plate"` (ברירת מחדל: 1.0). | FLOAT | כן | 0.1 עד 10.0 (צעד 0.1) |
| `removal_threshold` | עומק שמתחתיו הרקע מוסר, במפת עומק בטווח 0 עד 1. 0.3 שומר על פסל חזה שלם, 0.8 מפרק אותו לשברים. זמין כאשר `base` הוא `"none"` (ברירת מחדל: 0.01). | FLOAT | כן | 0.01 עד 1.0 (צעד 0.01) |
| `bend` | `"convex"` מקמר את החזית כלפי חוץ, `"concave"` מעקל אותה פנימה, `"off"` משאיר את התבליט שטוח. בחירת כיפוף חושפת את `bend_axis` ואת `bend_angle`. | DYNAMIC_COMBO | כן | `"off"`<br>`"convex"`<br>`"concave"` |
| `bend_axis` | `"xz"` מעקל את הקצוות השמאליים והימניים, `"yz"` את הקצוות העליונים והתחתונים. זמין כאשר `bend` הוא `"convex"` או `"concave"`. | COMBO | כן | `"xz"`<br>`"yz"` |
| `bend_angle` | הקשת שהכיפוף משתרע עליה במעלות; 360 סוגר את התבליט לגליל. זמין כאשר `bend` הוא `"convex"` או `"concave"` (ברירת מחדל: 60.0). | FLOAT | כן | 1.0 עד 360.0 (צעד 1.0) |
| `seed` | ערך seed ששולט אם הצומת מופעל מחדש; התוצאה אינה דטרמיניסטית ללא קשר ל-seed. יש לשנות אותו כדי לבקש פלט שחובר לאחר ההרצה האחרונה (ברירת מחדל: 42). | INT | כן | 0 עד 2147483647 |
| `mesh_resolution` | נקודות רשת לאורך הצלע הארוכה של התמונה. ב-1024 קובץ GLB הוא כ-50 MB וקובץ STL כ-105 MB; ב-2048 כ-200 MB ו-420 MB; כיפוף מכפיל אותם. (ברירת מחדל: 1024; אפשרות מתקדמת) | INT | כן | 512 עד 2048 |
| `color_mapping` | צובע את קובצי GLB, OBJ, FBX ו-USDZ בתמונה. STL ו-3MF נשארים לבנים. (ברירת מחדל: False; אפשרות מתקדמת) | BOOLEAN | כן | True / False |

**הערה:** פורמט מודל נוצר ומורד רק כאשר הפלט שלו מחובר. כאשר לא מחובר פלט מודל, המשימה מחזירה רק את מפת העומק, ו-`preview` לבדו עדיין גורם למודל להיווצר עבור התמונה הממוזערת אך אינו מחזיר קובץ מודל. `depth_map` שומר על טווח 16-ביט מלא; Save Image (Advanced) כותב אותו כ-PNG 16-ביט.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `GLB` | מודל התבליט מורד בפורמט GLB. | FILE3DGLB |
| `STL` | מודל התבליט מורד בפורמט STL. | FILE3DSTL |
| `OBJ` | מודל התבליט מורד בפורמט OBJ. | FILE3DOBJ |
| `FBX` | מודל התבליט מורד בפורמט FBX. | FILE3DFBX |
| `USDZ` | מודל התבליט מורד בפורמט USDZ. | FILE3DUSDZ |
| `3MF` | מודל התבליט מורד בפורמט 3MF. | FILE3D |
| `depth_map` | מפת עומק עם טווח 16-ביט מלא; Save Image (Advanced) כותב אותה כ-PNG 16-ביט. | IMAGE |
| `preview` | תמונה ממוזערת שמרונדרת על ידי Meshy עבור התבליט המוגמר. | IMAGE |
