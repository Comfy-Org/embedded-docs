# تحميل كامن

عقدة LoadLatent تقوم بتحميل التمثيلات الكامنة (latent) التي تم حفظها مسبقًا كملفات `.latent` في دليل الإدخال. تقرأ بيانات الموتر الكامن من الملف المحدد وتطبّق أي تعديلات قياس ضرورية قبل إرجاع النتائج لاستخدامها في العقد الأخرى.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `latent` | يحدد ملف `.latent` الذي سيتم تحميله من الملفات المتاحة في دليل الإدخال | COMBO | نعم | جميع ملفات `.latent` في دليل الإدخال |

ملاحظة: بالنسبة لملفات `.latent` التي لا تحتوي على علامة `latent_format_version_0`، يتم ضرب الموتر الكامن المحمَّل في 1/0.18215 بحيث يتوافق مقياسه مع التنسيق المتوقع من العقد الأخرى.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `LATENT` | يُرجع بيانات التمثيل الكامن المحمَّلة من الملف المحدد | LATENT |
