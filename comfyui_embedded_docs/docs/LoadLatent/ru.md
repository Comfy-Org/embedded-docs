# Загрузить латент

Узел LoadLatent загружает латентные представления, которые ранее были сохранены в виде файлов .latent в каталоге ввода. Он считывает данные латентного тензора из выбранного файла и применяет необходимые корректировки масштабирования перед возвратом результатов для использования в других узлах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Выбирает, какой файл .latent загрузить из доступных файлов в каталоге ввода | COMBO | Да | Все файлы .latent в каталоге ввода |

Примечание. Для файлов .latent, которые не содержат маркер `latent_format_version_0`, загруженный латентный тензор умножается на 1/0,18215, чтобы его масштабирование соответствовало формату, ожидаемому другими узлами.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Возвращает данные загруженного латентного представления из выбранного файла | LATENT |
