# Загрузить латент

Узел LoadLatent загружает ранее сохранённые скрытые представления из файлов `.latent` во входной директории. Он считывает данные тензора скрытого представления из выбранного файла и применяет необходимые корректировки масштабирования перед возвратом данных скрытого представления для использования в других узлах.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `скрытый` | Выбирает, какой файл `.latent` загрузить из доступных файлов во входной директории | COMBO | Да | Все файлы `.latent` во входной директории (динамический список, отсортирован по алфавиту) |

Примечание: Список доступных файлов формируется динамически и включает только файлы с расширением `.latent`, присутствующие во входной директории. Если выбранный файл больше не существует, узел сообщает о нем как о недопустимом файле скрытого представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Возвращает данные скрытого представления, загруженные из выбранного файла, в виде тензора с плавающей запятой. Если файл не содержит маркера `latent_format_version_0`, тензор масштабируется с коэффициентом 1/0.18215 перед возвратом; файлы, содержащие этот маркер, возвращаются в исходном масштабе. | LATENT |
