# BriaReplaceImageBackground

Этот узел заменяет фон изображения на новый, сгенерированный Bria. Новый фон можно описать текстовым промптом или задать с помощью эталонных изображений. Пиксели объекта сохраняются, а фон генерируется вокруг них.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, фон которого будет заменён. | IMAGE | Да | |
| `фон` | Опишите новый фон с помощью промпта или задайте его с помощью эталонных изображений. | DYNAMIC_COMBO | Да | `"prompt"`<br>`"reference images"` |
| `original_quality` | Возвращать точный размер входного изображения в пикселях вместо масштабирования результата примерно до 1 мегапикселя. Тогда большое входное изображение вернёт большое изображение. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `сид` | Одно и то же значение `seed` обычно возвращает одинаковый фон; автоматическое улучшение промпта всё равно может его изменить. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `модерация` | Настройки модерации. (по умолчанию: "false") | DYNAMIC_COMBO | Нет | `"false"`<br>`"true"` |

### Входы промпта

Отображаются, когда `background` имеет значение `"prompt"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание нового фона. Шестнадцатеричный код цвета, например #FF5733, создаёт однотонный фон. Должен содержать не менее 1 символа. | STRING | Да | |
| `mode` | `high_control` наиболее точно следует промпту, `base` — сбалансированный вариант по умолчанию, а `fast` жертвует детализацией ради скорости. | COMBO | Да | `"high_control"`<br>`"base"`<br>`"fast"` |
| `refine_prompt` | Переписывать промпт для лучших результатов; также переводит промпты на других языках. Отключите, чтобы отправлять промпт точно как написано. (по умолчанию: true) | BOOLEAN | Нет | `true`<br>`false` |

### Входы эталонных изображений

Отображаются, когда `background` имеет значение `"reference images"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `ref_images` | Расширяемый слот: подключите от 1 до 10 изображений, задающих новый фон; они не обязаны иметь одинаковый размер. Каждое эталонное изображение изменяет результат, поэтому несколько согласованных изображений лучше многих противоречивых. При пакетном входе каждое изображение учитывается отдельно. | IMAGE | Да | 1 до 10 images |
| `enhance_ref_images` | Дополнительная обработка эталонных изображений для лучших результатов. (по умолчанию: true) | BOOLEAN | Нет | `true`<br>`false` |

### Входы модерации

Отображаются, когда `moderation` имеет значение `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | Включить модерацию содержимого промпта. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `visual_input_moderation` | Включить модерацию визуального входа. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |
| `visual_output_moderation` | Включить модерацию визуального выхода. (по умолчанию: false) | BOOLEAN | Нет | `true`<br>`false` |

**Примечание.** Вход `ref_images` принимает не более 10 изображений; при передаче более 10 возвращается ошибка. Поле `prompt` должно содержать не менее 1 символа. Если `original_quality` имеет значение false, входное изображение перед обработкой уменьшается примерно до 1 мегапикселя.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Изображение с новым фоном. | IMAGE |
| `refined_prompt` | Промпт, на основе которого сгенерировала Bria; пусто при использовании эталонных изображений. | STRING |
