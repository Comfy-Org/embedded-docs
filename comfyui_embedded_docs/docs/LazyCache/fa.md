# LazyCache

LazyCache نسخه‌ای آزمایشی و غیررسمی از EasyCache است که برای کاهش محاسبات، در حین نمونه‌گیری کش‌گذاری را اضافه می‌کند. این ابزار برای سازگاری همگانی با مدل‌ها در ComfyUI طراحی شده است، هرچند به‌طور کلی عملکرد ضعیف‌تری نسبت به EasyCache دارد و ممکن است فقط در موارد نادر بهتر عمل کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `model` | مدلی که LazyCache به آن اضافه می‌شود. | MODEL | بله | - |
| `reuse_threshold` | آستانه استفاده مجدد از گام‌های کش‌شده. پیش‌فرض: 0.2. | FLOAT | بله | 0.0 - 3.0 (گام 0.01) |
| `start_percent` | گام نسبی نمونه‌گیری برای شروع استفاده از LazyCache. پیش‌فرض: 0.15. | FLOAT | بله | 0.0 - 1.0 (گام 0.01) |
| `end_percent` | گام نسبی نمونه‌گیری برای پایان استفاده از LazyCache. پیش‌فرض: 0.95. | FLOAT | بله | 0.0 - 1.0 (گام 0.01) |
| `verbose` | اینکه اطلاعات مفصل ثبت شود یا نه. پیش‌فرض: False. | BOOLEAN | بله | - |

توجه: `reuse_threshold`، `start_percent`، `end_percent` و `verbose` به‌عنوان ورودی‌های پیشرفته علامت‌گذاری شده‌اند.
