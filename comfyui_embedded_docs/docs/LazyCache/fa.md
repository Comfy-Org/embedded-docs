# LazyCache

LazyCache یک نسخهٔ دست‌ساز از EasyCache است که پیاده‌سازی آسان‌تری ارائه می‌دهد. با هر مدلی در ComfyUI کار می‌کند و قابلیت کش کردن را برای کاهش محاسبات در هنگام نمونه‌برداری اضافه می‌کند. اگرچه عملکرد آن به‌طور کلی بدتر از EasyCache است، در برخی موارد نادر می‌تواند مؤثرتر باشد و سازگاری جهانی ارائه دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که LazyCache به آن اضافه می‌شود. | MODEL | بله | - |
| `آستانه استفاده مجدد` | آستانهٔ استفادهٔ مجدد از مراحل کش‌شده (پیش‌فرض: 0.2). | FLOAT | خیر | 0.0 - 3.0 |
| `درصد شروع` | گام نسبی نمونه‌برداری برای شروع استفاده از LazyCache (پیش‌فرض: 0.15). | FLOAT | خیر | 0.0 - 1.0 |
| `درصد پایان` | گام نسبی نمونه‌برداری برای پایان استفاده از LazyCache (پیش‌فرض: 0.95). | FLOAT | خیر | 0.0 - 1.0 |
| `گزارش‌گیری کامل` | آیا اطلاعات جزئی (verbose) ثبت شود یا خیر (پیش‌فرض: False). | BOOLEAN | خیر | - |

توجه: `reuse_threshold`، `start_percent`، `end_percent` و `verbose` گزینه‌های پیشرفتهٔ اختیاری هستند.
