# Ленивый кэш

LazyCache — экспериментальная, неофициальная версия EasyCache, которая добавляет кэширование во время сэмплирования, чтобы сократить вычисления. Она разработана для универсальной совместимости с моделями в ComfyUI, хотя обычно работает хуже, чем EasyCache, и может работать лучше лишь в редких случаях.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой нужно добавить LazyCache. | MODEL | Да | - |
| `порог повторного использования` | Порог повторного использования кэшированных шагов. По умолчанию: 0.2. | FLOAT | Да | 0.0 - 3.0 (шаг 0.01) |
| `start_percent` | Относительный шаг сэмплирования, с которого начинается использование LazyCache. По умолчанию: 0.15. | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `end_percent` | Относительный шаг сэмплирования, на котором заканчивается использование LazyCache. По умолчанию: 0.95. | FLOAT | Да | 0.0 - 1.0 (шаг 0.01) |
| `verbose` | Выводить ли подробную информацию в журнал. По умолчанию: False. | BOOLEAN | Да | - |

Примечание: `reuse_threshold`, `start_percent`, `end_percent` и `verbose` отмечены как расширенные входы.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модель с добавленной функциональностью LazyCache. | MODEL |
