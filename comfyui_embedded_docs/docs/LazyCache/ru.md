# Ленивый кэш

LazyCache — это самодельная версия EasyCache, которая обеспечивает ещё более простую реализацию. Он работает с любой моделью в ComfyUI и добавляет функцию кэширования для уменьшения вычислений во время сэмплирования. Хотя в целом он работает хуже, чем EasyCache, в некоторых редких случаях он может быть более эффективным и обеспечивает универсальную совместимость.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой добавляется LazyCache. | MODEL | Да | - |
| `reuse_threshold` | Порог повторного использования кэшированных шагов (по умолчанию: 0.2). | FLOAT | Нет | 0.0 - 3.0 |
| `start_percent` | Относительный шаг сэмплирования для начала использования LazyCache (по умолчанию: 0.15). | FLOAT | Нет | 0.0 - 1.0 |
| `end_percent` | Относительный шаг сэмплирования для окончания использования LazyCache (по умолчанию: 0.95). | FLOAT | Нет | 0.0 - 1.0 |
| `verbose` | Нужно ли записывать подробную информацию в журнал (по умолчанию: False). | BOOLEAN | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
