# Загрузчик диффузоров

Узел DiffusersLoader устарел. Он загружает предварительно обученные модели, сохранённые в формате Hugging Face diffusers, и возвращает три стандартных компонента, необходимых для пайплайна: MODEL, CLIP и VAE. Узел автоматически сканирует настроенные папки diffusers на наличие допустимых каталогов моделей (папок, содержащих файл `model_index.json`) и позволяет выбрать, какую из них загрузить.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `model_path` | Путь к каталогу модели diffusers для загрузки. Узел сканирует настроенные папки diffusers и перечисляет все каталоги, содержащие файл `model_index.json`. | COMBO | Да | Автозаполняется из настроенных папок diffusers (каждая подпапка, содержащая файл `model_index.json`) |

Примечание: выбранный путь проверяется по списку обнаруженных моделей. Загрузка завершится ошибкой, если путь больше не находится в списке или если каталог модели не может быть найден.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `MODEL` | Загруженный компонент модели из формата diffusers | MODEL |
| `CLIP` | Загруженный компонент модели CLIP для кодирования текста из формата diffusers | CLIP |
| `VAE` | Загруженный компонент VAE (вариационного автокодировщика) из формата diffusers | VAE |
