# Загрузчик диффузоров

Узел DiffusersLoader загружает предварительно обученные модели, сохранённые в формате diffusers. Он выполняет поиск в настроенных папках `diffusers` на наличие каталогов, содержащих файл `model_index.json`, позволяет выбрать один из них и загружает его как компоненты MODEL, CLIP и VAE, используемые в конвейере. Этот узел устарел, но остаётся доступным для совместимости с моделями diffusers от Hugging Face.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `путь_модели` | Путь к каталогу модели diffusers для загрузки. Узел автоматически сканирует настроенные папки diffusers на наличие допустимых моделей и выводит список доступных вариантов. | COMBO | Да | Доступно несколько вариантов<br>(автоматически заполняется из папок diffusers) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-----------|-------------|-----------|
| MODEL | Загруженный компонент модели из формата diffusers. | MODEL |
| CLIP | Загруженный компонент CLIP-модели из формата diffusers. | CLIP |
| VAE | Загруженный компонент VAE (вариационного автокодировщика) из формата diffusers. | VAE |
