# تحميل Diffusers

عقدة `DiffusersLoader` مهملة. تقوم بتحميل النماذج المدربة مسبقًا والمحفوظة بتنسيق Hugging Face diffusers، وتُرجع المكونات القياسية الثلاثة التي تحتاجها خط المعالجة: `MODEL` و`CLIP` و`VAE`. تقوم العقدة تلقائيًا بفحص مجلدات diffusers المُهيأة بحثًا عن مجلدات النماذج الصالحة (المجلدات التي تحتوي على ملف `model_index.json`) وتتيح لك اختيار أي منها لتحميله.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model_path` | المسار إلى مجلد نموذج diffusers المراد تحميله. تقوم العقدة بفحص مجلدات diffusers المُهيأة وتعرض كل مجلد يحتوي على ملف `model_index.json`. | COMBO | نعم | يتم ملؤها تلقائيًا من مجلدات diffusers المُهيأة (كل مجلد فرعي يحتوي على ملف `model_index.json`) |

ملاحظة: يتم التحقق من المسار المحدد مقابل قائمة النماذج المكتشفة. يفشل التحميل مع ظهور خطأ إذا لم يعد المسار موجودًا في القائمة أو إذا تعذر العثور على مجلد النموذج.

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `MODEL` | مكوّن النموذج المُحمَّل من تنسيق diffusers | MODEL |
| `CLIP` | مكوّن CLIP لتشفير النصوص المُحمَّل من تنسيق diffusers | CLIP |
| `VAE` | مكوّن VAE (التشفير التلقائي التبايني) المُحمَّل من تنسيق diffusers | VAE |
