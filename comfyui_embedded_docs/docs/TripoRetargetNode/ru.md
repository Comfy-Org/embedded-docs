# Tripo: Перепривязка ригнутой модели

TripoRetargetNode применяет предустановленную анимацию к существующей 3D-модели с ригом. Он принимает ID задачи модели, для которой ранее был создан риг, отправляет запрос на ретаргетинг в Tripo API и скачивает полученный анимированный файл. Анимированная модель может быть возвращена в формате GLB или FBX, с необязательной геометрией меша и необязательным воспроизведением на месте.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `идентификатор_задачи_исходной_модели` | ID задачи ранее оснащённой ригом 3D-модели для ретаргетинга. Указанная задача должна быть задачей создания рига. | RIG_TASK_ID | Да | - |
| `анимация` | Предустановленная анимация для применения к модели с ригом. Анимации `preset:*` работают с обеими моделями рига. Анимации `preset:biped:*` созданы для ригов из модели v1.0-20240301; риг v2.5 принимает только chop, climb, dive, fall, hurt, idle, jump, run, shoot, slash, turn и walk. | COMBO | Да | `"preset:idle"`<br>`"preset:walk"`<br>`"preset:run"`<br>`"preset:dive"`<br>`"preset:climb"`<br>`"preset:jump"`<br>`"preset:slash"`<br>`"preset:shoot"`<br>`"preset:hurt"`<br>`"preset:fall"`<br>`"preset:turn"`<br>`"preset:quadruped:walk"`<br>`"preset:hexapod:walk"`<br>`"preset:octopod:walk"`<br>`"preset:serpentine:march"`<br>`"preset:aquatic:march"`<br>плюс дополнительные опции `"preset:biped:*"`, отображаемые в UI |
| `out_format` | Формат выходного файла; результат поступает на соответствующий выход. (по умолчанию: glb) | COMBO | Нет | `"glb"`<br>`"fbx"` |
| `export_with_geometry` | Включать меш в экспорт; при выключении экспортируется только анимированный скелет. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `animate_in_place` | Воспроизводить анимацию на месте, без смещения корня. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `auth_token_comfy_org` | Токен аутентификации для доступа к API Comfy.org (скрытый параметр). | AUTH_TOKEN_COMFY_ORG | Нет | - |
| `api_key_comfy_org` | Ключ API для доступа к сервису Comfy.org (скрытый параметр). | API_KEY_COMFY_ORG | Нет | - |
| `unique_id` | Уникальный идентификатор для отслеживания операции (скрытый параметр). | UNIQUE_ID | Нет | - |

Примечание: Анимации из группы `preset:*` работают с обеими моделями рига. Анимации из группы `preset:biped:*` созданы для ригов из модели v1.0-20240301; риг v2.5 принимает только chop, climb, dive, fall, hurt, idle, jump, run, shoot, slash, turn и walk. Если указанный риг был создан по спецификации Mixamo и версии модели, начинающейся с `v1.0`, вызов ретаргетинга завершается ошибкой. Запрошенный выходной формат должен быть GLB или FBX; если сервис возвращает любой другой тип файла, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Сгенерированный файл анимированной 3D-модели (только для обратной совместимости). | STRING |
| `retarget task_id` | ID задачи для отслеживания операции ретаргетинга. | RETARGET_TASK_ID |
| `GLB` | Анимированная 3D-модель в формате GLB. Заполняется, когда `out_format` имеет значение glb. | FILE3DGLB |
| `FBX` | Анимированная 3D-модель в формате FBX. Заполняется, когда `out_format` имеет значение fbx. | FILE3DFBX |
