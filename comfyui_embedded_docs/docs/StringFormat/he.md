# עיצוב טקסט

## סקירה כללית

צומת זה מעצב טקסט באמצעות מתודת הפורמט של מחרוזות בפייתון. הוא פועל כמו תבנית שבה מגדירים דפוס טקסט עם מצייני מקום, ואז מספקים ערכים למילוי מצייני המקום. הוא תומך בכל אפשרויות הפורמט והתכונות של פייתון.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `f_string` | תבנית מחרוזת הפורמט עם מצייני מקום (ברירת מחדל: `{a}`). תומך בקלט מרובה שורות. | STRING | כן | N/A |
| `values` | קלט דינמי לאספקת ערכים למילוי מצייני מקום במחרוזת הפורמט. ניתן להוסיף מספר קלטי ערכים לפי הצורך. | STRING | כן | N/A |

**הערה על קלט `values`:** קלט זה דינמי וניתן להרחיב אותו כך שיכלול מספר ערכים בעלי שמות. כל קלט ערך מסומן באות (a, b, c וכו') ומתאים למציין מקום במחרוזת הפורמט (למשל `{a}`, `{b}`, `{c}`). ניתן להוסיף או להסיר קלטי ערכים לפי הצורך.
