# VEED Dubbing

VEED Dubbing מתרגם את הדיבור בסרטון לשפה אחרת באמצעות VEED, משכפל את קולו של כל דובר ומסנכרן את תנועות השפתיים שלו עם התרגום. הקליפ מועלה, משימת VEED נבדקת שוב ושוב (polling), והסרטון המדובב חוזר בקצב של 25 פריימים לשנייה, באורך של רצועת השמע החדשה שלו. השתמשו בו כדי להתאים קליפ מוגמר לשוק מקומי בלי לצלם מחדש או להקליט מחדש את הקול.

## קלטים

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל דיבוב. `"standard"` זול יותר ומחזיר שמע מונו, עם ספרדית לטינו-אמריקאית ופורטוגזית ברזילאית; `"pro"` מוסיף מבטאים אזוריים ושמע סטריאו. בחירת מודל חושפת את `video`, `target_language`, `source_language` ו-`seed`. | DYNAMIC_COMBO | כן | `"standard"`<br>`"pro"` |

### קלטים של standard

קלטים אלו מופיעים כאשר `model` מוגדר ל-`"standard"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `video` | סרטון עם פנים נראות ודיבור, באורך של עד 599 שניות. הפלט באורך של רצועת השמע שלו ומוצג בקצב של 25 פריימים לשנייה. | VIDEO | כן | עד 599 שניות |
| `target_language` | השפה שאליה מדבבים, אחת מ-85 שפות. (ברירת מחדל: `"English"`) | COMBO | כן | 85 שפות |
| `source_language` | השפה המדוברת בסרטון, או `"auto"` כדי לזהות אותה אוטומטית. (ברירת מחדל: `"auto"`) | COMBO | כן | `"auto"`<br>85 שפות |
| `seed` | ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 42) | INT | כן | 0 עד 2147483647 |

### קלטים של pro

קלטים אלו מופיעים כאשר `model` מוגדר ל-`"pro"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `video` | סרטון עם פנים נראות ודיבור, באורך של עד 599 שניות. הפלט באורך של רצועת השמע שלו ומוצג בקצב של 25 פריימים לשנייה. | VIDEO | כן | עד 599 שניות |
| `target_language` | השפה או המבטא האזורי שאליהם מדבבים: 87 שפות ועוד 14 מבטאים כגון `"English (UK)"`, `"Spanish (Mexico)"` ו-`"Portuguese (Brazil)"`. (ברירת מחדל: `"English (US)"`) | COMBO | כן | 101 אפשרויות |
| `source_language` | השפה המדוברת בסרטון, או `"auto"` כדי לזהות אותה אוטומטית. (ברירת מחדל: `"auto"`) | COMBO | כן | `"auto"`<br>91 שפות |
| `seed` | ה-seed קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-seed. (ברירת מחדל: 42) | INT | כן | 0 עד 2147483647 |

הצומת נעצר עם שגיאה כאשר לסרטון אין רצועת שמע, כאשר הקליפ ארוך מ-599 שניות, או כאשר משימת VEED נכשלת.
