# HeyGen صورة متحركة ناطقة

قم بتحريك صورة ثابتة لشخص إلى فيديو يتحدث مع مزامنة الشفاه باستخدام تقنية Avatar IV من HeyGen. يمكنك تشغيل الحركة باستخدام نص برمجي يحوّله HeyGen إلى كلام، أو توفير الصوت الخاص بك ليقوم الأفاتار بمزامنة الشفاه معه.

## المدخلات

| Parameter | الوصف | Data Type | الإلزامية | Range |
|-----------|-------------|-----------|----------|-------|
| `صورة` | صورة لشخص لتحريكها. يتم تقليل حجمها تلقائيًا إذا كانت أكبر من 2K. | IMAGE | نعم | - |
| `الصوت` | قم بتشغيل الأفاتار باستخدام نص برمجي (تحويل النص إلى كلام من HeyGen) أو باستخدام الصوت الخاص بك. | COMBO | نعم | `"script"`<br>`"audio"` |
| `text` | النص الذي سيلقيه الأفاتار (حتى 5000 حرف). يجب أن تكون مدة الكلام المُولّد ثانية واحدة على الأقل. (الافتراضي: فارغ) | STRING | نعم (عندما يكون `الصوت` هو `"script"`) | - |
| `voice` | الصوت المستخدم للنص (الأصوات الأكثر شيوعًا في HeyGen). | COMBO | نعم (عندما يكون `الصوت` هو `"script"`) | توجد خيارات متعددة |
| `custom_voice_id` | معرّف صوت HeyGen اختياري. عند تعيينه، يتجاوز الصوت المحدد أعلاه. يمكن استخدام أي صوت من مكتبة HeyGen (أكثر من 2000 صوت). (الافتراضي: فارغ) | STRING | لا | - |
| `voice_speed` | مضاعف سرعة الكلام (الافتراضي: 1.0). | FLOAT | لا | 0.5 إلى 1.5 |
| `audio` | الصوت الذي سيقوم الأفاتار بمزامنة الشفاه معه، حتى 10 دقائق. | AUDIO | نعم (عندما يكون `الصوت` هو `"audio"`) | - |
| `الدقة` | دقة فيديو الإخراج (الافتراضي: `"1080p"`). | COMBO | لا | `"720p"`<br>`"1080p"` |
| `نسبة العرض إلى الارتفاع` | نسبة أبعاد الإخراج. `"auto"` يتبع صورة الإدخال (الافتراضي: `"auto"`). | COMBO | لا | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `التعبيرية` | مقدار تعبيرية الوجه والإيماءات (الافتراضي: `"low"`). | COMBO | لا | `"low"`<br>`"medium"`<br>`"high"` |
| `البذرة` | لا يُرسل إلى HeyGen؛ قم بتغييره لإجبار إعادة التشغيل (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |

ملاحظة: `speech` هو إدخال ديناميكي يحدد مصدر الكلام. عند ضبطه على `"script"`، يكون `text` و `voice` مطلوبين، ويكون `custom_voice_id` و `voice_speed` اختياريين. وعند ضبطه على `"audio"`، يكون `audio` مطلوبًا بدلاً من ذلك.
