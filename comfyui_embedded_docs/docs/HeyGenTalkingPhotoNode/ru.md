# HeyGen Talking Photo

Оживите неподвижное изображение человека и превратите его в говорящее видео с синхронизацией губ с помощью технологии HeyGen Avatar IV. Управляйте анимацией с помощью текстового сценария, который HeyGen преобразует в речь, или загрузите собственный аудиофайл — аватар будет синхронизировать движения губ с речью.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение человека для анимации. Автоматически уменьшается, если его размер превышает 2K. | IMAGE | Да | - |
| `speech` | Управление аватаром с помощью текстового сценария (текстовый синтез речи HeyGen) или собственного аудиофайла. | DYNAMIC_COMBO | Да | `"script"`<br>`"audio"` |
| `resolution` | Разрешение выходного видео (по умолчанию: `"1080p"`). | COMBO | Нет | `"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. `"auto"` соответствует входному изображению (по умолчанию: `"auto"`). | COMBO | Нет | `"auto"`<br>`"16:9"`<br>`"9:16"`<br>`"1:1"`<br>`"4:5"`<br>`"5:4"` |
| `expressiveness` | Уровень выразительности анимации лица и жестов (по умолчанию: `"low"`). | COMBO | Нет | `"low"`<br>`"medium"`<br>`"high"` |
| `seed` | Не отправляется в HeyGen; измените его, чтобы принудительно запустить повторное выполнение (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |

### Входы сценария

Отображается, когда `speech` равно `"script"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text` | Текст, который будет произносить аватар (до 5000 символов). Сгенерированная речь должна быть не короче 1 секунды. (по умолчанию: пусто) | STRING | Да | от 1 до 5000 символов |
| `voice` | Голос для сценария (самые популярные голоса HeyGen). | COMBO | Да | Доступно несколько вариантов |
| `custom_voice_id` | Необязательный идентификатор голоса HeyGen. Если задан, отменяет выбранный выше голос. Можно использовать любой голос из библиотеки HeyGen (2000+). (по умолчанию: пусто) | STRING | Нет | - |
| `voice_speed` | Множитель скорости речи (по умолчанию: 1.0). | FLOAT | Нет | от 0.5 до 1.5 (шаг 0.05) |

### Аудиовходы

Отображается, когда `speech` равно `"audio"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для синхронизации губ аватара, длительностью до 10 минут. | AUDIO | Да | до 10 минут |

Примечание: если `speech` равно `"script"`, необходимо указать `text`, а также выбрать голос через селектор `voice` (любой голос, отличный от голоса аватара по умолчанию) или задать `custom_voice_id`. Если `speech` равно `"audio"`, вместо этого требуется указать `audio`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео с анимированным говорящим фото и речью, синхронизированной с движениями губ. | VIDEO |
