# טעינת 3D ואנימציה

צומת Load3D הוא צומת ליבה לטעינה ולעיבוד של קובצי מודל תלת-ממדיים. בעת טעינת הצומת, הוא שולף אוטומטית משאבי תלת-ממד זמינים מתוך `ComfyUI/input/3d/`. ניתן גם להעלות קובצי תלת-ממד נתמכים לתצוגה מקדימה באמצעות פונקציית ההעלאה.

**פורמטים נתמכים**
נכון לעכשיו, צומת זה תומך במספר פורמטים של קובצי תלת-ממד, כולל `.gltf`, `.glb`, `.obj`, `.fbx` ו-`.stl`.

**העדפות צומת תלת-ממד**
ניתן להגדיר העדפות קשורות מסוימות עבור צומות תלת-ממד בתפריט ההגדרות של ComfyUI. אנא עיין בתיעוד הבא להגדרות המתאימות:

[תפריט הגדרות](https://docs.comfy.org/interface/settings/3d)

מלבד פלטי הצומת הרגילים, ל-Load3D יש הגדרות רבות הקשורות לתצוגת תלת-ממד בתפריט הקנבס.

## קלטים

| שם הפרמטר | תיאור | סוג | ברירת מחדל | טווח |
| --- | --- | --- | --- | --- |
| model_file | נתיב לקובץ מודל תלת-ממד, תומך בהעלאה, כברירת מחדל קורא קובצי מודל מתוך `ComfyUI/input/3d/` | בחירת קובץ | - | פורמטים נתמכים |
| width | רוחב רינדור הקנבס | INT | 1024 | 1-4096 |
| height | גובה רינדור הקנבס | INT | 1024 | 1-4096 |

## פלטים

| שם הפרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| image | תמונת רינדור הקנבס | IMAGE |
| mask | מסיכה המכילה את מיקום המודל הנוכחי | MASK |
| mesh_path | נתיב לקובץ המודל | STRING |
| normal | מפת נורמלים | IMAGE |
| lineart | פלט תמונת קווי מתאר; ניתן להתאים את `edge_threshold` המתאים בתפריט המודל בקנבס | IMAGE |
| camera_info | מידע על המצלמה | LOAD3D_CAMERA |
| recording_video | וידאו מוקלט (רק כאשר קיימת הקלטה) | VIDEO |

## תיאור אזור הקנבס

אזור הקנבס של צומת Load3D מכיל פעולות תצוגה רבות, כולל:

- הגדרות תצוגה מקדימה (רשת, צבע רקע, תצוגה מקדימה)
- שליטת מצלמה: שליטה ב-FOV, סוג מצלמה
- עוצמת תאורה גלובלית: התאמת עוצמת התאורה
- הקלטת וידאו: הקלטה וייצוא וידאו
- ייצוא מודל: תומך בפורמטים `GLB`, `OBJ`, `STL`
- ועוד

![ממשק צומת Load 3D](./asset/load3d_ui.jpg)

1. מכיל מספר תפריטים ותפריטים מוסתרים של צומת Load 3D
2. תפריט עבור `resizing preview window` ו-`canvas video recording`
3. ציר פעולת תצוגת תלת-ממד
4. תמונת ממוזערת של תצוגה מקדימה
5. הגדרות גודל תצוגה מקדימה, שינוי קנה המידה של התצוגה המקדימה על ידי הגדרת מידות ואז שינוי גודל החלון

### 2. פונקציות התפריט השמאלי

![תפריט](./asset/menu.webp)

בקנבס, חלק מההגדרות מוסתרות בתפריט. לחץ על כפתור התפריט כדי לפרוש תפריטים שונים

- 1. סצנה: מכיל רשת חלון תצוגה מקדימה, צבע רקע, הגדרות תצוגה מקדימה
- 2. מודל: מצב רינדור המודל, חומרי טקסטורה, הגדרות כיוון מעלה
- 3. מצלמה: מעבר בין תצוגות אורתוגרפיות לפרספקטיביות, וקביעת גודל זווית הפרספקטיבה
- 4. תאורה: עוצמת תאורה גלובלית של הסצנה
- 5. ייצוא: ייצוא המודל לפורמטים אחרים (GLB, OBJ, STL)

#### סצנה

![תפריט סצנה](./asset/menu_scene.webp)

תפריט הסצנה מספק פונקציות בסיסיות להגדרת הסצנה

1. הצג/הסתר רשת
2. הגדר צבע רקע
3. לחץ כדי להעלות תמונת רקע
4. הסתר את התצוגה המקדימה

#### מודל

![תפריט מודל](./asset/menu_model.webp)

תפריט המודל מספק פונקציות הקשורות למודל

1. **כיוון מעלה**: קבע איזה ציר הוא כיוון המעלה עבור המודל
2. **מצב חומר**: החלף בין מצבי רינדור המודל - מקורי, נורמל, מסגרת תיל, קווי מתאר

#### מצלמה

![תפריט מצלמה](./asset/menu_camera.webp)

תפריט זה מספק מעבר בין תצוגות אורתוגרפיות לפרספקטיביות, והגדרות גודל זווית פרספקטיבה

1. **מצלמה**: מעבר מהיר בין תצוגה אורתוגרפית לתצוגת פרספקטיבה
2. **FOV**: התאם זווית FOV

#### תאורה

![תפריט תאורה](./asset/menu_light.webp)

דרך תפריט זה, ניתן להתאים במהירות את עוצמת התאורה הגלובלית של הסצנה

#### ייצוא

![תפריט ייצוא](./asset/menu_export.webp)

תפריט זה מספק את היכולת להמיר ולייצא פורמטים של מודלים במהירות

לתפריט הימני יש שתי פונקציות עיקריות:

1. **איפוס יחס התצוגה**: לאחר לחיצה על הכפתור, התצוגה תתאים את יחס אזור רינדור הקנבס בהתאם לרוחב ולגובה שהוגדרו
2. **הקלטת וידאו**: מאפשר להקליט פעולות תצוגת תלת-ממד נוכחיות כווידאו, מאפשר ייבוא, ויכול להיות מופק כ-`recording_video` לצמתים עוקבים
