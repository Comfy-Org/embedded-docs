# BasicGuider

گره BasicGuider یک سازوکار هدایت ساده برای فرآیند نمونه‌برداری ایجاد می‌کند. این گره یک مدل و داده‌های شرطی‌سازی را به‌عنوان ورودی دریافت کرده و یک شیء هدایت‌گر تولید می‌کند که می‌تواند برای راهنمایی فرآیند تولید در طول نمونه‌برداری استفاده شود. این گره قابلیت هدایت پایه‌ای موردنیاز برای تولید کنترل‌شده را فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که برای هدایت استفاده می‌شود | MODEL | بله | - |
| `شرط‌گذاری` | داده‌های شرطی‌سازی که فرآیند تولید را هدایت می‌کنند | CONDITIONING | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
