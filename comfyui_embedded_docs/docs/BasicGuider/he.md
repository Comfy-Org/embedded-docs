# מנחה בסיסי

צומת BasicGuider יוצר מנגנון הנחיה פשוט עבור תהליך הדגימה. הוא מקבל מודל ונתוני התניה כקלטים ומפיק אובייקט guider שאפשר להשתמש בו כדי להנחות את תהליך היצירה במהלך הדגימה. צומת זה מספק את פונקציונליות ההנחיה הבסיסית הנדרשת ליצירה מבוקרת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שישמש להנחיה | MODEL | כן | - |
| `conditioning` | נתוני ההתניה שמנחים את תהליך היצירה | CONDITIONING | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `GUIDER` | אובייקט guider שאפשר להשתמש בו במהלך תהליך הדגימה כדי להנחות את היצירה | GUIDER |
