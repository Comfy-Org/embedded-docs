# Основной гид

Узел BasicGuider создаёт простой механизм управления для процесса семплирования. Он принимает модель и данные кондиционирования в качестве входных данных и создаёт объект guider, который можно использовать для управления процессом генерации во время семплирования. Этот узел обеспечивает базовую функциональность управления, необходимую для контролируемой генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для управления | MODEL | Да | - |
| `кондиционирование` | Данные кондиционирования, управляющие процессом генерации | CONDITIONING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Объект guider, который можно использовать во время процесса семплирования для управления генерацией | GUIDER |
