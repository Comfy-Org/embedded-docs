# Основной гид

Узел BasicGuider создает простой механизм управления для процесса сэмплирования. Он принимает модель и данные кондиционирования в качестве входных данных и создает объект guider, который можно использовать для управления процессом генерации во время сэмплирования. Этот узел обеспечивает базовую функциональность управления, необходимую для контролируемой генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, используемая для управления | MODEL | Да | - |
| `conditioning` | Данные кондиционирования, которые управляют процессом генерации | CONDITIONING | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Объект guider, который можно использовать во время процесса сэмплирования для управления генерацией | GUIDER |
