# Recraft Crisp Upscale Image

Amplía la imagen de forma síncrona. Mejora una imagen rasterizada dada utilizando la herramienta 'crisp upscale', aumentando la resolución de la imagen, haciéndola más nítida y limpia.

## Entradas

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
|-----------|-------------|---------------|-----------|-------|
| `image` | La imagen de entrada que se ampliará. Acepta un lote de imágenes. | IMAGE | Sí | - |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `image` | La imagen ampliada con resolución y nitidez mejoradas. Devuelve un lote de imágenes si se proporcionó un lote como entrada. | IMAGE |
