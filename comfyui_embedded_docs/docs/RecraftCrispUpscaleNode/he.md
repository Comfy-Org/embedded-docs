# Recraft הגדלה חדה של תמונה

צומת זה מבצע הגדלת רזולוציה (upscale) של תמונה באופן סינכרוני באמצעות כלי "crisp upscale". הוא משפר תמונת רסטר נתונה על ידי הגדלת הרזולוציה שלה, מה שהופך את התמונה לחדה ונקייה יותר. כאשר מסופקת אצוות תמונות, כל תמונה מעובדת בנפרד והתוצאות המוגדלות מוחזרות כאצווה.
