# Recraft Ampliação Nítida de Imagem

Upscale image synchronously. Amplia uma imagem raster fornecida usando a ferramenta 'crisp upscale', aumentando a resolução da imagem, tornando-a mais nítida e limpa.

## Entradas

| Parâmetro | Descrição | Tipo de Dados | Obrigatório | Intervalo |
|-----------|-------------|-----------|----------|-------|
| `image` | A imagem de entrada a ser ampliada. Aceita um lote de imagens. | IMAGE | Sim | - |

## Saídas

| Nome da Saída | Descrição | Tipo de Dados |
|-------------|-------------|-----------|
| `image` | A imagem ampliada com resolução e nitidez aprimoradas. Retorna um lote de imagens se um lote foi fornecido como entrada. | IMAGE |
