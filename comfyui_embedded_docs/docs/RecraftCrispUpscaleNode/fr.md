# Recraft Crisp Upscale Image

Agrandir l'image de manière synchrone. Améliore une image raster donnée à l'aide de l'outil « crisp upscale », en augmentant la résolution de l'image, la rendant plus nette et plus propre.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
|-----------|-------------|-----------------|--------|-------|
| `image` | L'image d'entrée à agrandir. Accepte un lot d'images. | IMAGE | Oui | - |

## Sorties

| Nom de sortie | Description | Type de données |
|---------------|-------------|-----------------|
| `image` | L'image agrandie avec une résolution et une clarté améliorées. Renvoie un lot d'images si un lot a été fourni en entrée. | IMAGE |
