# Recraft Четкое Увеличение Изображения

Этот узел синхронно увеличивает разрешение изображения с помощью инструмента «crisp upscale». Он улучшает заданное растровое изображение, повышая его разрешение, что делает изображение более чётким и чистым. Если передан пакет изображений, каждое изображение обрабатывается независимо, а результаты с увеличенным разрешением возвращаются в виде пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для увеличения разрешения. Принимает пакет изображений; каждое изображение обрабатывается независимо. | IMAGE | Да | — |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `image` | Изображение с увеличенным разрешением и повышенной чёткостью. Возвращает пакет изображений, если на вход был подан пакет. | IMAGE |
