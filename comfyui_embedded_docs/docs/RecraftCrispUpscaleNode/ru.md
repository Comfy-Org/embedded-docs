# Recraft Четкое Увеличение Изображения

Синхронное увеличение изображения. Повышает качество заданного растрового изображения с помощью инструмента `'crisp upscale'`, увеличивая разрешение и делая изображение более чётким и чистым.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для увеличения. Принимает пакет изображений. | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Увеличенное изображение с улучшенным разрешением и чёткостью. Возвращает пакет изображений, если на вход был подан пакет. | IMAGE |
