# Recraft Четкое Увеличение Изображения

Синхронно увеличивает разрешение входного изображения с помощью инструмента 'crisp upscale', повышая его разрешение и делая его более чётким и чистым. Каждое изображение во входном пакете обрабатывается независимо, и результаты увеличения возвращаются в виде пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `изображение` | Входное изображение для увеличения разрешения. Принимает пакет изображений. | IMAGE | Да | — |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Увеличенное изображение с повышенным разрешением и чёткостью. Возвращает пакет изображений, если на вход был подан пакет. | IMAGE |
