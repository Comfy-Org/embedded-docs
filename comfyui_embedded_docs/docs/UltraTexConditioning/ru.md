# UltraTex Conditioning

Формирует условия для FLUX.2 Klein 9B с LoRA UltraTex, чтобы перенести внешний вид эталонного изображения на меш, по одному изображению на вид. Отрисуйте виды с помощью Render Mesh в режиме `world normal`, используя Create Camera Orbit с 4 видами плюс верхний и нижний, и запеките результат с помощью Bake Texture From Views.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `conditioning` | Текстовое кондиционирование. UltraTex обучалась с пустым запросом. | CONDITIONING | Да | - |
| `vae` | VAE, используемый для кодирования нормалей, видов и эталона. | VAE | Да | - |
| `normals` | Изображения Render Mesh в режиме `world normal`: 6 канонических видов или 4 боковых вида. | IMAGE | Да | - |
| `masks` | Маски Render Mesh для тех же видов, по одной на вид. | MASK | Да | - |
| `reference` | Объект в желаемом виде, каким он виден со стороны фронтальной камеры. | IMAGE | Да | - |
| `reference_mask` | Маска объекта для эталона; белый цвет соответствует объекту. По умолчанию: полностью белая. | MASK | Нет | - |
| `extra_views` | Дополнительные эталоны: объект, видимый с других видов; каждый привязан к своему виду так же, как эталон привязан к фронтальному виду. По умолчанию: `"off"`. | DYNAMIC_COMBO | Да | `"off"`<br>`"on"` |

### Входы Extra Views "on"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `right` | Объект, видимый с правого вида. | IMAGE | Нет | - |
| `back` | Объект, видимый с заднего вида. | IMAGE | Нет | - |
| `left` | Объект, видимый с левого вида. | IMAGE | Нет | - |
| `top` | Объект, видимый с верхнего вида. | IMAGE | Нет | - |
| `bottom` | Объект, видимый с нижнего вида. | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Кондиционирование, содержащее сетку видов, латенты эталона и маски токенов, необходимые UltraTex. | CONDITIONING |

Примечание: `normals` должен содержать либо 6 канонических видов (Create Camera Orbit с `count` 4 и `poles` top и bottom), либо 4 боковых вида, а `masks` должен соответствовать количеству его видов.
