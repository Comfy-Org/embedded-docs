# LoopProgress

LoopProgress — это вспомогательный узел только для разработки, который сообщает о прогрессе цикла интерфейсу сервера ComfyUI. При каждом выполнении он отправляет клиенту текст "Iteration X / Y" и возвращает текущую позицию итерации без изменений, что позволяет размещать его внутри цикла, не изменяя поток данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `start_id` | Идентификатор экземпляра промпта/цикла, к которому относится сообщение о прогрессе. Первый элемент переданного списка используется, чтобы направить текст прогресса в правильное выполняемое исполнение. | STRING | Да | - |
| `position` | Текущая позиция итерации (индекс). Первый элемент переданного списка используется в сообщении о прогрессе и также возвращается как выход. | INT | Да | - |
| `total` | Общее количество итераций. Используется вместе с `position` для формирования сообщения о прогрессе "Iteration X / Y". | INT | Да | - |

Примечание: этот узел объявлен с list-входами (`is_input_list=True`) и принимает все входы, поэтому каждое подключённое значение рассматривается как список, и читается только его первый элемент. Узел выполняется всегда (его входной отпечаток фиксирован), поэтому он перезапускается на каждом проходе цикла.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-----------|-----------|
| `position` | Текущая позиция итерации, передаваемая без изменений из входа `position`. | INT |
