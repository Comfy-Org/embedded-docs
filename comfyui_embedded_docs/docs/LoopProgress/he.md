# LoopProgress

LoopProgress הוא צומת עזר המיועדת לפיתוח בלבד, שמדווחת על התקדמות לולאה לממשק השרת של ComfyUI. בכל הרצה הוא שולח ללקוח את הטקסט "Iteration X / Y" ומחזיר את מיקום האיטרציה הנוכחי ללא שינוי, מה שמאפשר לו לפעול בתוך לולאה מבלי לשנות את זרימת הנתונים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `start_id` | מזהה של מופע prompt/loop שאליו שייכת הודעת ההתקדמות. הפריט הראשון ברשימה שסופקה משמש לניתוב טקסט ההתקדמות להרצה הנכונה שפועלת. | STRING | כן | - |
| `position` | מיקום האיטרציה הנוכחי (אינדקס). הפריט הראשון ברשימה שסופקה משמש בהודעת ההתקדמות וגם מוחזר כפלט. | INT | כן | - |
| `total` | מספר האיטרציות הכולל. משמש יחד עם `position` כדי לבנות את הודעת ההתקדמות "Iteration X / Y". | INT | כן | - |

הערה: צומת זה מוצהר עם קלטי רשימה (`is_input_list=True`) ומקבל את כל הקלטים, כך שכל ערך מחובר מטופל כרשימה ורק האיבר הראשון שלו נקרא. הצומת תמיד פועל (טביעת האצבע של הקלט שלו קבועה), ולכן הוא מתבצע מחדש בכל סבב לולאה.
