# LoopProgress

LoopProgress یک گره کمکی فقط برای توسعه است که پیشرفت یک حلقه را به رابط سرور ComfyUI گزارش می‌دهد. در هر اجرا، متن "Iteration X / Y" را به کلاینت می‌فرستد و موقعیت تکرار فعلی را بدون تغییر بازمی‌گرداند، که به آن اجازه می‌دهد بدون تغییر جریان داده، به‌صورت درون‌خطی درون یک حلقه قرار بگیرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `start_id` | شناسه نمونه prompt/loop که پیام پیشرفت به آن تعلق دارد. اولین آیتم از فهرست ارائه‌شده برای مسیریابی متن پیشرفت به اجرای در حال اجرای صحیح استفاده می‌شود. | STRING | بله | - |
| `position` | موقعیت تکرار فعلی (اندیس). اولین آیتم از فهرست ارائه‌شده در پیام پیشرفت استفاده می‌شود و همچنین به‌عنوان خروجی بازگردانده می‌شود. | INT | بله | - |
| `total` | تعداد کل تکرارها. همراه با `position` برای ساخت پیام پیشرفت "Iteration X / Y" استفاده می‌شود. | INT | بله | - |

توجه: این گره با ورودی‌های فهرستی اعلام شده است (`is_input_list=True`) و همه ورودی‌ها را می‌پذیرد، بنابراین هر مقدار متصل‌شده به‌صورت فهرست در نظر گرفته می‌شود و فقط اولین عنصر آن خوانده می‌شود. این گره همیشه اجرا می‌شود (اثر انگشت ورودی آن ثابت است)، بنابراین در هر گذر حلقه دوباره اجرا می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `position` | موقعیت تکرار فعلی که بدون تغییر از ورودی `position` عبور داده شده است. | INT |
