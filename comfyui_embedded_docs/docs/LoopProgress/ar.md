# LoopProgress

LoopProgress هي عقدة مساعدة خاصة بالتطوير فقط، تُبلّغ عن تقدم حلقة إلى واجهة خادم ComfyUI. عند كل تنفيذ، ترسل النص "Iteration X / Y" إلى العميل وتعيد موضع التكرار الحالي دون تغيير، ما يسمح لها بالبقاء ضمن سياق الحلقة دون تغيير تدفق البيانات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `start_id` | معرّف نسخة المطالبة/الحلقة التي تنتمي إليها رسالة التقدم. يُستخدم العنصر الأول من القائمة المزوَّدة لتوجيه نص التقدم إلى التنفيذ الجاري الصحيح. | STRING | نعم | - |
| `الموضع` | موضع التكرار الحالي (الفهرس). يُستخدم العنصر الأول من القائمة المزوَّدة في رسالة التقدم، ويُعاد أيضًا كمخرج. | INT | نعم | - |
| `الإجمالي` | العدد الإجمالي للتكرارات. يُستخدم مع `position` لبناء رسالة التقدم "Iteration X / Y". | INT | نعم | - |

ملاحظة: تُعرَّف هذه العقدة بمدخلات قائمة (`is_input_list=True`) وتقبل جميع المدخلات، لذا تُعامَل كل قيمة موصولة كقائمة ويُقرأ العنصر الأول منها فقط. تعمل العقدة دائمًا (بصمة مدخلاتها ثابتة)، لذا يُعاد تنفيذها في كل مرور للحلقة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `position` | موضع التكرار الحالي، يُمرَّر دون تغيير من مدخل `position`. | INT |
