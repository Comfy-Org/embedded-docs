# ResizeAndPadImage

הצומת ResizeAndPadImage משנה את גודל התמונה כך שתתאים למידות שצוינו תוך שמירה על יחס הגובה-רוחב המקורי. הוא מקטין את התמונה באופן פרופורציונלי כדי שתתאים לרוחב ולגובה היעד, ולאחר מכן מוסיף ריפוד סביב השוליים כדי למלא את החלל שנותר. ניתן להתאים את צבע הריפוד ואת שיטת האינטרפולציה כדי לשלוט במראה של אזורי הריפוד ובאיכות שינוי הגודל.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט ששינוי הגודל והריפוד יחולו עליה | IMAGE | כן | - |
| `target_width` | הרוחב הרצוי של תמונת הפלט (ברירת מחדל: 512) | INT | כן | 1 עד MAX_RESOLUTION |
| `target_height` | הגובה הרצוי של תמונת הפלט (ברירת מחדל: 512) | INT | כן | 1 עד MAX_RESOLUTION |
| `padding_color` | הצבע שישמש לאזורי הריפוד סביב התמונה ששונתה בגודלה (ברירת מחדל: "white") | COMBO | כן | "white"<br>"black" |
| `interpolation` | שיטת האינטרפולציה שבה משתמשים לשינוי גודל התמונה (ברירת מחדל: "area") | COMBO | כן | "area"<br>"bicubic"<br>"nearest-exact"<br>"bilinear"<br>"lanczos" |
