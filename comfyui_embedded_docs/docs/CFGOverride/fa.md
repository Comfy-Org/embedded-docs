# جایگزینی CFG

گره CFG Override به شما امکان می‌دهد یک مقدار مقیاس CFG (Classifier-Free Guidance) ثابت را برای محدوده‌ی مشخصی از فرآیند نمونه‌برداری تنظیم کنید که به‌صورت درصدی از کل مراحل تعریف می‌شود. وقتی چند گره CFG Override متصل باشند، گره‌ای که در زنجیره به نمونه‌بردار نزدیک‌تر است، برای محدوده‌های همپوشان اولویت دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که باید CFG override روی آن اعمال شود | MODEL | بله | |
| `cfg` | مقدار ثابت مقیاس CFG که در طول محدوده override استفاده می‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 100.0 |
| `درصد شروع` | نقطه شروع محدوده override به‌عنوان درصدی از فرآیند نمونه‌برداری (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 |
| `درصد پایان` | نقطه پایان محدوده override به‌عنوان درصدی از فرآیند نمونه‌برداری (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 1.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | مدل با اعمال wrapper CFG override | MODEL |
