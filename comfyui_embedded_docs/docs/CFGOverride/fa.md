# جایگزینی CFG

گره CFG Override مقیاس CFG (راهنمایی بدون طبقه‌بند) را در محدوده‌ای درصدی (سیگما) از فرایند نمونه‌برداری به مقدار ثابتی بازنویسی می‌کند. وقتی چند گره CFG Override استفاده می‌شود، در محدوده‌های هم‌پوشان، بازنویسی‌ای که به سمپلر نزدیک‌تر است اولویت دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که بازنویسی CFG باید روی آن اعمال شود. | MODEL | بله | |
| `cfg` | مقدار ثابت مقیاس CFG که در محدوده بازنویسی استفاده می‌شود. پیش‌فرض: 1.0. | FLOAT | بله | 0.0 تا 100.0 (گام: 0.1) |
| `start_percent` | نقطه شروع محدوده بازنویسی به‌صورت درصدی از فرایند نمونه‌برداری. پیش‌فرض: 0.0. | FLOAT | بله | 0.0 تا 1.0 (گام: 0.001) |
| `end_percent` | نقطه پایان محدوده بازنویسی به‌صورت درصدی از فرایند نمونه‌برداری. پیش‌فرض: 1.0. | FLOAT | بله | 0.0 تا 1.0 (گام: 0.001) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `MODEL` | مدل با پوشش بازنویسی CFG اعمال‌شده. | MODEL |
