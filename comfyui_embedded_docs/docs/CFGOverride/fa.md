# جایگزینی CFG

گره CFG Override به شما امکان می‌دهد مقدار ثابتی از مقیاس CFG (راهنمایی بدون طبقه‌بندی) را برای محدوده‌ای مشخص از فرآیند نمونه‌برداری، که به صورت درصدی از کل گام‌ها تعریف می‌شود، تنظیم کنید. وقتی چند گره CFG Override به یکدیگر متصل می‌شوند، برای بازه‌های همپوشان، گره‌ای که در زنجیره به نمونه‌بردار نزدیک‌تر است اولویت دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `model` | مدلی که باید عمل override روی آن اعمال شود | MODEL | بله | |
| `cfg` | مقدار ثابت مقیاس CFG که در طول بازه override استفاده می‌شود (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 to 100.0 |
| `start_percent` | نقطه شروع بازه override به عنوان درصدی از فرآیند نمونه‌برداری (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 to 1.0 |
| `end_percent` | نقطه پایان بازه override به عنوان درصدی از فرآیند نمونه‌برداری (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 to 1.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `MODEL` | مدلی که پوشش (Wrapper) مربوط به CFG override به آن اعمال شده است | MODEL |
