# Переопределение CFG

Узел CFG Override переопределяет масштаб CFG (Classifier-Free Guidance) на фиксированное значение в процентном (sigma) диапазоне процесса сэмплирования. Если используется несколько узлов CFG Override, на пересекающихся диапазонах приоритет имеет переопределение, ближайшее к сэмплеру.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, к которой применяется переопределение CFG. | MODEL | Да | |
| `cfg` | Фиксированное значение масштаба CFG, используемое в течение диапазона переопределения. По умолчанию: 1.0. | FLOAT | Да | 0.0 до 100.0 (шаг: 0.1) |
| `начальный_процент` | Начальная точка диапазона переопределения в процентах от процесса сэмплирования. По умолчанию: 0.0. | FLOAT | Да | 0.0 до 1.0 (шаг: 0.001) |
| `конечный_процент` | Конечная точка диапазона переопределения в процентах от процесса сэмплирования. По умолчанию: 1.0. | FLOAT | Да | 0.0 до 1.0 (шаг: 0.001) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Модель с применённой обёрткой переопределения CFG. | MODEL |
