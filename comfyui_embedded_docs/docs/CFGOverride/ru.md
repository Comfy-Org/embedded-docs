# Переопределение CFG

Узел CFG Override позволяет задать фиксированное значение масштаба CFG (Classifier-Free Guidance) для определённого диапазона процесса сэмплирования, выраженного в процентах от общего числа шагов. Когда подключено несколько узлов CFG Override, приоритет для перекрывающихся диапазонов получает узел, расположенный ближе всего к сэмплеру в цепочке.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель, к которой применяется переопределение CFG | MODEL | Yes | |
| `cfg` | Фиксированное значение масштаба CFG, используемое в диапазоне переопределения (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 100.0 |
| `start_percent` | Начальная точка диапазона переопределения в процентах от процесса сэмплирования (по умолчанию: 0.0) | FLOAT | Yes | 0.0 to 1.0 |
| `end_percent` | Конечная точка диапазона переопределения в процентах от процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Yes | 0.0 to 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `MODEL` | Модель с применённой обёрткой переопределения CFG | MODEL |
