# Переопределение CFG

Узел CFG Override позволяет задать фиксированное значение масштаба CFG (Classifier-Free Guidance) для определённого диапазона процесса сэмплирования, выраженного в процентах от общего числа шагов. Если подключено несколько узлов CFG Override, приоритет для перекрывающихся диапазонов имеет узел, расположенный ближе всего к сэмплеру в цепочке.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `модель` | Модель, к которой применяется переопределение CFG | MODEL | Да | |
| `cfg` | Фиксированное значение масштаба CFG, используемое в диапазоне переопределения (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 100.0 |
| `начальный_процент` | Начальная точка диапазона переопределения в процентах от процесса сэмплирования (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 |
| `конечный_процент` | Конечная точка диапазона переопределения в процентах от процесса сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-----------|----------|------------|
| `MODEL` | Модель с применённой обёрткой переопределения CFG | MODEL |
