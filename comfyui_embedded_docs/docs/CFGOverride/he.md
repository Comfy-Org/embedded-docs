# CFGOverride

הצומת CFG Override עוקף את סולם CFG (הנחיה ללא מסווג) לערך קבוע על פני טווח אחוזים (sigma) של תהליך הדגימה. כאשר משתמשים במספר צמתי CFG Override, העקיפה הקרובה ביותר לסמפלר גוברת בטווחים חופפים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל שעליו להחיל את עקיפת ה-CFG. | MODEL | כן | |
| `cfg` | ערך סולם ה-CFG הקבוע שיש להשתמש בו במהלך טווח העקיפה. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 100.0 (צעד: 0.1) |
| `start_percent` | נקודת ההתחלה של טווח העקיפה כאחוז מתהליך הדגימה. ברירת מחדל: 0.0. | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.001) |
| `end_percent` | נקודת הסיום של טווח העקיפה כאחוז מתהליך הדגימה. ברירת מחדל: 1.0. | FLOAT | כן | 0.0 עד 1.0 (צעד: 0.001) |
