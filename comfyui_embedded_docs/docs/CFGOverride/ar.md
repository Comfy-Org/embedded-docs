# تجاوز cfg

تعمل عقدة CFG Override على تجاوز مقياس CFG (Classifier-Free Guidance — التوجيه بدون مصنّف) إلى قيمة ثابتة خلال نطاق نسبي (sigma) من عملية أخذ العينات. عند استخدام عدة عُقد CFG Override، تفوز العقدة الأقرب إلى الـ sampler في النطاقات المتداخلة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المراد تطبيق تجاوز CFG عليه. | MODEL | نعم | |
| `cfg` | قيمة مقياس CFG الثابتة المستخدمة خلال نطاق التجاوز. القيمة الافتراضية: 1.0. | FLOAT | نعم | 0.0 إلى 100.0 (step: 0.1) |
| `start_percent` | نقطة البداية لنطاق التجاوز كنسبة مئوية من عملية أخذ العينات. القيمة الافتراضية: 0.0. | FLOAT | نعم | 0.0 إلى 1.0 (step: 0.001) |
| `end_percent` | نقطة النهاية لنطاق التجاوز كنسبة مئوية من عملية أخذ العينات. القيمة الافتراضية: 1.0. | FLOAT | نعم | 0.0 إلى 1.0 (step: 0.001) |

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `MODEL` | النموذج مع تطبيق غلاف تجاوز CFG عليه. | MODEL |
