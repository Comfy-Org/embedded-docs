# モデルサンプリングLTXV

ModelSamplingLTXV ノードは、トークン数に基づいてモデルに高度なサンプリングパラメータを適用します。このノードは、基本シフト値と最大シフト値の間の線形補間を使用してシフト値を計算します。計算は入力された潜在変数のトークン数に依存します。その後、ノードは特殊なモデルサンプリング設定を作成し、それを入力モデルに適用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | サンプリングパラメータを適用する入力モデル | MODEL | はい | - |
| `max_shift` | 線形補間計算で使用される最大シフト値。4096 トークン時にシフト値はこの最大値と等しくなります（デフォルト: 2.05） | FLOAT | はい | 0.0 to 100.0 |
| `base_shift` | 線形補間計算で使用される基本シフト値。1024 トークン時にシフト値はこの基本値と等しくなります（デフォルト: 0.95） | FLOAT | はい | 0.0 to 100.0 |
| `latent` | シフト計算のトークン数を決定するために使用されるオプションの潜在変数。トークン数は潜在サンプルの空間次元の積です。提供されていない場合は、デフォルトのトークン数 4096 が使用されます | LATENT | いいえ | - |

注: シフト値は、1024 トークン時の `base_shift` と 4096 トークン時の `max_shift` の間の線形補間によって計算されます。`latent` が提供されていない場合、デフォルトのトークン数 4096 により、シフトは `max_shift` と等しくなります。
