# Выборка модели LTXV

Узел ModelSamplingLTXV применяет расширенные параметры сэмплирования к модели на основе количества токенов. Он вычисляет значение сдвига с помощью линейной интерполяции между базовым и максимальным значениями сдвига, причём расчёт зависит от количества токенов во входном латентном представлении. Затем узел создаёт специализированную конфигурацию сэмплирования модели и применяет её к входной модели.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Входная модель, к которой применяются параметры сэмплирования | MODEL | Да | - |
| `max_shift` | Максимальное значение сдвига, используемое в расчёте линейной интерполяции. Значение сдвига равно этому максимуму при 4096 токенах (по умолчанию: 2.05) | FLOAT | Да | 0.0 to 100.0 |
| `base_shift` | Базовое значение сдвига, используемое в расчёте линейной интерполяции. Значение сдвига равно этому базовому значению при 1024 токенах (по умолчанию: 0.95) | FLOAT | Да | 0.0 to 100.0 |
| `latent` | Необязательное латентное представление, используемое для определения количества токенов для расчёта сдвига. Количество токенов равно произведению пространственных размерностей латентных сэмплов. Если не указано, используется количество токенов по умолчанию, равное 4096 | LATENT | Нет | - |

Примечание: значение сдвига вычисляется линейной интерполяцией между `base_shift` при 1024 токенах и `max_shift` при 4096 токенах. Когда `latent` не предоставлен, количество токенов по умолчанию (4096) делает сдвиг равным `max_shift`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применёнными параметрами сэмплирования | MODEL |
