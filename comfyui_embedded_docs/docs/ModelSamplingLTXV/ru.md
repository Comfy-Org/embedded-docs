# Выборка модели LTXV

Узел ModelSamplingLTXV применяет расширенные параметры сэмплирования к модели на основе количества токенов. Он вычисляет значение сдвига путём линейной интерполяции между `base_shift` и `max_shift` по диапазону токенов, затем модифицирует входную модель с помощью специализированной конфигурации сэмплирования. Если передан `latent`, его размерности определяют количество токенов; в противном случае используется 4096 токенов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Входная модель, к которой применяются параметры сэмплирования. | MODEL | Да | - |
| `макс_сдвиг` | Максимальное значение сдвига, используемое в расчёте линейной интерполяции (по умолчанию: 2.05). | FLOAT | Да | от 0.0 до 100.0 (шаг: 0.01) |
| `базовый_сдвиг` | Базовое значение сдвига, используемое в расчёте линейной интерполяции (по умолчанию: 0.95). | FLOAT | Да | от 0.0 до 100.0 (шаг: 0.01) |
| `скрытый` | Необязательный вход `latent`, используемый для определения количества токенов для расчёта сдвига. Если он не указан, используется количество токенов по умолчанию — 4096. | LATENT | Нет | - |

Значение сдвига вычисляется путём интерполяции между `base_shift` при 1024 токенах и `max_shift` при 4096 токенах. Если `latent` передан, количество токенов равно произведению всех размерностей после первых двух в сэмплах `latent` (пространственных/временных размерностей). Если `latent` не предоставлен, количество токенов по умолчанию равно 4096.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с применёнными параметрами сэмплирования. | MODEL |
