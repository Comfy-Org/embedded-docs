# Выборка модели LTXV

Узел ModelSamplingLTXV применяет расширенные параметры сэмплирования к модели на основе количества токенов. Он вычисляет значение сдвига с помощью линейной интерполяции между базовым и максимальным значениями сдвига, причем расчет зависит от количества токенов во входном латентном представлении. Затем узел создает специализированную конфигурацию сэмплирования модели и применяет ее к входной модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Входная модель, к которой применяются параметры сэмплирования | MODEL | Да | - |
| `макс_сдвиг` | Максимальное значение сдвига, используемое в расчете линейной интерполяции (по умолчанию: 2.05) | FLOAT | Да | 0.0 до 100.0 (step: 0.01) |
| `базовый_сдвиг` | Базовое значение сдвига, используемое в расчете линейной интерполяции (по умолчанию: 0.95) | FLOAT | Да | 0.0 до 100.0 (step: 0.01) |
| `скрытый` | Необязательный латентный вход, используемый для определения количества токенов для расчета сдвига. Если не указан, используется количество токенов по умолчанию — 4096 | LATENT | Нет | - |

Значение сдвига вычисляется интерполяцией между `base_shift` и `max_shift` в диапазоне количества токенов от 1024 до 4096. Когда передан `latent`, количество токенов вычисляется как произведение его пространственных размеров (например, высоты и ширины). Если `latent` не передан, количество токенов по умолчанию равно 4096.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененными параметрами сэмплирования | MODEL |
