# 모델 샘플링 (LTXV)

ModelSamplingLTXV 노드는 토큰 수를 기반으로 모델에 고급 샘플링 매개변수를 적용합니다. 이 노드는 기본 시프트 값과 최대 시프트 값 사이의 선형 보간을 사용하여 시프트 값을 계산하며, 이 계산은 입력 latent의 토큰 수에 따라 달라집니다. 그런 다음 노드는 전문화된 모델 샘플링 구성을 생성하고 이를 입력 모델에 적용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 샘플링 매개변수를 적용할 입력 모델입니다 | MODEL | 예 | - |
| `max_shift` | 선형 보간 계산에 사용되는 최대 시프트 값입니다. 시프트 값은 4096개 토큰에서 이 최대값과 같아집니다 (기본값: 2.05) | FLOAT | 예 | 0.0 to 100.0 |
| `base_shift` | 선형 보간 계산에 사용되는 기본 시프트 값입니다. 시프트 값은 1024개 토큰에서 이 기본값과 같아집니다 (기본값: 0.95) | FLOAT | 예 | 0.0 to 100.0 |
| `latent` | 시프트 계산을 위한 토큰 수를 결정하는 데 사용되는 선택적 latent 입력입니다. 토큰 수는 latent 샘플의 공간 차원을 곱한 값입니다. 제공되지 않으면 기본 토큰 수인 4096이 사용됩니다 | LATENT | 아니오 | - |

참고: 시프트 값은 1024개 토큰에서의 `base_shift`와 4096개 토큰에서의 `max_shift` 사이의 선형 보간으로 계산됩니다. `latent`가 제공되지 않으면 기본 토큰 수인 4096으로 인해 시프트가 `max_shift`와 같아집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 샘플링 매개변수가 적용된 수정된 모델입니다 | MODEL |
