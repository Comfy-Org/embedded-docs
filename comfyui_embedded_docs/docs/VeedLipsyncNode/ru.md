# VEED Lipsync 2.0

Повторно синхронизируйте губы говорящего на видео с новой речевой дорожкой с помощью VEED Lipsync. Используйте это для дублирования клипа или замены его диалога, сохраняя исходный видеоматериал. Выходные данные сохраняют разрешение видео при 25 кадрах в секунду и имеют длительность, равную длительности аудио; на каждом видео должен быть один говорящий.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель. При выборе модели отображаются параметры, специфичные для неё: `video`, `audio` и `seed`. | DYNAMIC_COMBO | Да | `"lipsync-2.0"` |
| `video` | Видеоматериал с одним говорящим, обращённым лицом к камере. Если он короче аудио, воспроизведение идёт вперёд и назад, пока не закончится аудио. | VIDEO | Да | - |
| `audio` | Новая речь длительностью до 600 секунд. Определяет длительность видео. | AUDIO | Да | До 600 секунд |
| `seed` | Параметр `seed` управляет тем, следует ли повторно запускать узел; результаты недетерминированы независимо от `seed`. (по умолчанию: 42) | INT | Да | 0–2147483647 |

Узел завершается с ошибкой, если речевая дорожка длиннее 600 секунд или если задание VEED завершается неудачно.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `VIDEO` | Видео с повторно синхронизированной речью: исходный видеоматериал, в котором движения губ согласованы с новой речью. | VIDEO |
