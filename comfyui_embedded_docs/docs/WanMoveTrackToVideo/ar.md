# WanMoveTrackToVideo

عقدة `WanMoveTrackToVideo` تُحضّر بيانات التكييف والفضاء الكامن لتوليد الفيديو، مع دمج معلومات تتبع الحركة الاختيارية. تقوم بترميز تسلسل الصور الابتدائي إلى تمثيل كامن، ويمكنها دمج البيانات الموضعية من مسارات الكائنات لتوجيه الحركة في الفيديو المُولّد. تُخرج العقدة تكييفًا موجبًا وسالبًا معدَّلًا، بالإضافة إلى موتر كامن فارغ جاهز لنموذج الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخلات التكييف الموجب المراد تعديلها. | CONDITIONING | نعم | - |
| `سلبي` | مدخلات التكييف السالب المراد تعديلها. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصورة الابتدائية في الفضاء الكامن. | VAE | نعم | - |
| `المسارات` | بيانات تتبع الحركة الاختيارية التي تحتوي على مسارات الكائنات. | TRACKS | لا | - |
| `القوة` | قوة تكييف المسارات. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 - 100.0 |
| `العرض` | عرض الفيديو الناتج. يجب أن يكون قابلاً للقسمة على 16. (الافتراضي: 832) | INT | نعم | 16 - MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج. يجب أن يكون قابلاً للقسمة على 16. (الافتراضي: 480) | INT | نعم | 16 - MAX_RESOLUTION |
| `الطول` | عدد الإطارات في تسلسل الفيديو، بزيادات مقدارها 4. (الافتراضي: 81) | INT | نعم | 1 - MAX_RESOLUTION |
| `حجم الدفعة` | حجم الدفعة للمخرجات الكامنة. (الافتراضي: 1) | INT | نعم | 1 - 4096 |
| `صورة البداية` | الصورة الابتدائية أو تسلسل الصور المراد ترميزها. | IMAGE | نعم | - |
| `clip_vision_output` | مخرجات نموذج CLIP البصري الاختيارية لإضافتها إلى التكييف. | CLIP_VISION_OUTPUT | لا | - |

**ملاحظة:** لا يكون للمعامل `strength` أي تأثير إلا عند توفير `tracks` وكانت قيمة `strength` أكبر من 0.0؛ ولا يتم تطبيق تكييف المسارات إلا عند توفير `start_image` أيضًا. إذا لم يتم توفير `tracks` أو كانت `strength` تساوي 0.0، يتم تخطي دمج المسارات. وعندما يكون دمج المسارات نشطًا، يستقبل التكييف الموجب الصورة الكامنة المدمجة مع المسارات، بينما يستقبل التكييف السالب الصورة الكامنة غير المعدّلة. إذا لم يتم توفير `start_image`، فلن يتم إنشاء أي صورة كامنة أو تكييف قناع؛ ويمر كل من التكييف الموجب والسالب دون تغيير (باستثناء أنه لا يزال يتم إضافة `clip_vision_output` إذا تم توفيره)، وتُخرج العقدة كامنًا فارغًا.

**ملاحظة:** عند توفير `start_image`، يتم تغيير حجم تسلسل الصور إلى `width` و `height` المطلوبين واقتطاعه إلى أول `length` إطار. إذا كان التسلسل أقصر من `length`، يتم ملء الإطارات المتبقية بإطارات رمادية محايدة (قيمة 0.5) قبل ترميز VAE. يتضمن التكييف الناتج `concat_mask` بقيمة 0 في المواضع الزمنية المقابلة لإطارات الصورة الابتدائية وبقيمة 1 في其余 المواضع.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | التكييف الموجب المعدَّل، والذي قد يحتوي على `concat_latent_image` و `concat_mask` و `clip_vision_output`. | CONDITIONING |
| `سلبي` | التكييف السالب المعدَّل، والذي قد يحتوي على `concat_latent_image` و `concat_mask` و `clip_vision_output`. | CONDITIONING |
| `كامنة` | موتر كامن فارغ بأبعاد `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`، حسب مدخلات `batch_size` و `length` و `height` و `width`. | LATENT |
