# WanMoveTrackToVideo

عقدة **WanMoveTrackToVideo** تُعدّ بيانات التكييف (conditioning) والبيانات الكامنة (latent) لتوليد الفيديو. وهي ترمّز تسلسل الصورة الابتدائية إلى الفضاء الكامن باستخدام VAE، ويمكنها اختياريًا دمج معلومات تتبع الحركة لتوجيه حركة الكائنات في الفيديو المُولَّد. تُخرج العقدة تكييفًا إيجابيًا وسلبيًا معدَّلًا بالإضافة إلى موتر كامن فارغ جاهز لنموذج توليد الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مدخل التكييف الإيجابي الذي سيتم تعديله. | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي الذي سيتم تعديله. | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصورة الابتدائية إلى الفضاء الكامن. | VAE | نعم | - |
| `tracks` | بيانات تتبع الحركة الاختيارية التي تحتوي على مسارات الكائنات. | TRACKS | لا | - |
| `strength` | قوة تكييف التتبع. لها تأثير فقط عند توفير `tracks` وكانت القيمة أكبر من 0.0. (الافتراضي: 1.0) | FLOAT | نعم | 0.0 - 100.0 |
| `width` | عرض الفيديو الناتج. يُضبط بمضاعفات 16. (الافتراضي: 832) | INT | نعم | 16 - MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج. يُضبط بمضاعفات 16. (الافتراضي: 480) | INT | نعم | 16 - MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو. يُضبط بمضاعفات 4. (الافتراضي: 81) | INT | نعم | 1 - MAX_RESOLUTION |
| `batch_size` | حجم الدفعة لمخرجات الموتر الكامن. (الافتراضي: 1) | INT | نعم | 1 - 4096 |
| `start_image` | الصورة الابتدائية أو تسلسل الصور المراد ترميزها بواسطة VAE. | IMAGE | نعم | - |
| `clip_vision_output` | مخرجات نموذج CLIP vision الاختيارية لإضافتها إلى التكييف. | CLIP_VISION_OUTPUT | لا | - |

ملاحظة: يتم تطبيق الحركة المستندة إلى التتبع فقط عند توفير `tracks` وكانت قيمة `strength` أكبر من 0.0. وإلا، يستقبل التكييف الصورة الابتدائية المشفَّرة دون تعديل. تُستخدم `start_image` لإنشاء صورة كامنة وقناع (mask) للتكييف؛ إذا لم تكن متوفرة، تقوم العقدة فقط بتمرير التكييف وإخراج كامن فارغ.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الإيجابي المعدَّل، والذي قد يحتوي على `concat_latent_image` و`concat_mask` و`clip_vision_output`. | CONDITIONING |
| `negative` | التكييف السلبي المعدَّل، والذي قد يحتوي على `concat_latent_image` و`concat_mask` و`clip_vision_output`. | CONDITIONING |
| `latent` | موتر كامن فارغ بأبعاد مُشكَّلة بواسطة مدخلات `batch_size` و`length` و`height` و`width`. | LATENT |
