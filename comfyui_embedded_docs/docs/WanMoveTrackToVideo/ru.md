# WanMoveTrackToVideo

Узел WanMoveTrackToVideo подготавливает данные кондиционирования и латентного пространства для генерации видео, включая необязательную информацию отслеживания движения. Он кодирует начальную последовательность изображений в латентное представление и может смешивать позиционные данные из треков объектов для управления движением в генерируемом видео. Узел выводит модифицированные положительный и отрицательный conditioning, а также пустой латентный тензор, готовый для видеомодели.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное кондиционирование, которое будет изменено. | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование, которое будет изменено. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования начального изображения в латентное пространство. | VAE | Да | - |
| `треки` | Необязательные данные отслеживания движения, содержащие пути объектов. | TRACKS | Нет | - |
| `интенсивность` | Сила кондиционирования треками. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `ширина` | Ширина выходного видео. Должна быть кратна 16. (по умолчанию: 832) | INT | Да | 16 - MAX_RESOLUTION |
| `высота` | Высота выходного видео. Должна быть кратна 16. (по умолчанию: 480) | INT | Да | 16 - MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности, с шагом 4. (по умолчанию: 81) | INT | Да | 1 - MAX_RESOLUTION |
| `размер_пакета` | Размер пакета для скрытого вывода. (по умолчанию: 1) | INT | Да | 1 - 4096 |
| `стартовое_изображение` | Начальное изображение или последовательность изображений для кодирования. | IMAGE | Да | - |
| `clip_vision_output` | Необязательный выход модели CLIP vision, добавляемый к conditioning. | CLIP_VISION_OUTPUT | Нет | - |

**Примечание:** Параметр `strength` действует только при наличии `tracks` и если `strength` больше 0.0; кондиционирование треками применяется только при наличии `start_image`. Если `tracks` не предоставлены или `strength` равен 0.0, смешивание треков пропускается. Когда смешивание треков активно, положительное кондиционирование получает скрытое изображение, смешанное с треками, а отрицательное кондиционирование получает неизменённое скрытое изображение. Если `start_image` не предоставлено, скрытое изображение и маска conditioning не создаются; положительное и отрицательное conditioning передаются без изменений (за исключением того, что `clip_vision_output` всё равно добавляется, если он предоставлен), и узел выводит пустой латент.

**Примечание:** Если `start_image` предоставлено, последовательность изображений изменяется до целевых `width` и `height` и обрезается до первых `length` кадров. Если последовательность короче `length`, оставшиеся кадры заполняются нейтральными серыми кадрами (значение 0.5) перед кодированием VAE. Результирующее кондиционирование включает `concat_mask` со значением 0 во временных позициях, соответствующих кадрам начального изображения, и 1 в остальных позициях.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование, возможно содержащее `concat_latent_image`, `concat_mask` и `clip_vision_output`. | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование, возможно содержащее `concat_latent_image`, `concat_mask` и `clip_vision_output`. | CONDITIONING |
| `latent` | Пустой латентный тензор формы `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`, определяемой входами `batch_size`, `length`, `height` и `width`. | LATENT |
