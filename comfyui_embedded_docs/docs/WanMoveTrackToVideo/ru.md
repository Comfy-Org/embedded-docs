# WanMoveTrackToVideo

Узел WanMoveTrackToVideo подготавливает данные conditioning и latent для генерации видео. Он кодирует начальную последовательность изображений в скрытое пространство с помощью VAE и при необходимости может включать информацию отслеживания движения для управления движением объектов в генерируемом видео. Узел выводит модифицированные положительные и отрицательные conditioning, а также пустой latent-тензор, готовый для модели генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Входное положительное conditioning, которое будет изменено. | CONDITIONING | Да | - |
| `negative` | Входное отрицательное conditioning, которое будет изменено. | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования начального изображения в скрытое пространство. | VAE | Да | - |
| `tracks` | Необязательные данные отслеживания движения, содержащие пути объектов. | TRACKS | Нет | - |
| `strength` | Сила кондиционирования треков. Действует только при наличии `tracks` и значении больше 0.0. (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `width` | Ширина выходного видео. Задаётся с шагом 16. (по умолчанию: 832) | INT | Да | 16 - MAX_RESOLUTION |
| `height` | Высота выходного видео. Задаётся с шагом 16. (по умолчанию: 480) | INT | Да | 16 - MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности. Задаётся с шагом 4. (по умолчанию: 81) | INT | Да | 1 - MAX_RESOLUTION |
| `batch_size` | Размер пакета (batch size) для выходного латентного представления. (по умолчанию: 1) | INT | Да | 1 - 4096 |
| `start_image` | Начальное изображение или последовательность изображений для кодирования с помощью VAE. | IMAGE | Да | - |
| `clip_vision_output` | Необязательный выход модели CLIP vision, добавляемый к conditioning. | CLIP_VISION_OUTPUT | Нет | - |

Примечание: движение на основе треков применяется только при наличии `tracks` и значении `strength` больше 0.0. В противном случае conditioning получает немодифицированное закодированное начальное изображение. `start_image` используется для создания латентного изображения и маски для conditioning; если оно недоступно, узел только пропускает conditioning и выводит пустой латентный тензор.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное conditioning, потенциально содержащее `concat_latent_image`, `concat_mask` и `clip_vision_output`. | CONDITIONING |
| `negative` | Модифицированное отрицательное conditioning, потенциально содержащее `concat_latent_image`, `concat_mask` и `clip_vision_output`. | CONDITIONING |
| `latent` | Пустой латентный тензор с размерами, определяемыми входными параметрами `batch_size`, `length`, `height` и `width`. | LATENT |
