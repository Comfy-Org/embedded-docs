# WanMoveTrackToVideo

گره WanMoveTrackToVideo داده‌های شرطی‌سازی و فضای نهان را برای تولید ویدیو آماده می‌کند و اطلاعات اختیاری ردیابی حرکت را نیز در بر می‌گیرد. این گره یک دنباله تصویر شروع را به نمایش نهان رمزگذاری می‌کند و می‌تواند داده‌های موقعیتی حاصل از ردیابی اشیاء را برای هدایت حرکت در ویدیوی تولیدشده ترکیب کند. خروجی این گره شامل شرطی‌سازی مثبت و منفی اصلاح‌شده و همچنین یک تانسور نهان خالی آماده برای مدل ویدیو است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `مثبت` | ورودی شرطی‌سازی مثبت که باید اصلاح شود. | CONDITIONING | بله | - |
| `منفی` | ورودی شرطی‌سازی منفی که باید اصلاح شود. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر شروع به فضای نهان. | VAE | بله | - |
| `ترک‌ها` | داده‌های اختیاری ردیابی حرکت شامل مسیرهای اشیاء. | TRACKS | خیر | - |
| `شدت` | قدرت شرطی‌سازی ردیابی. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 100.0 |
| `عرض` | عرض ویدیوی خروجی. باید بر ۱۶ بخش‌پذیر باشد. (پیش‌فرض: 832) | INT | بله | 16 - MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی. باید بر ۱۶ بخش‌پذیر باشد. (پیش‌فرض: 480) | INT | بله | 16 - MAX_RESOLUTION |
| `طول` | تعداد فریم‌های دنباله ویدیو، در گام‌های ۴. (پیش‌فرض: 81) | INT | بله | 1 - MAX_RESOLUTION |
| `اندازه بچ` | اندازه دسته برای خروجی نهان. (پیش‌فرض: 1) | INT | بله | 1 - 4096 |
| `تصویر شروع` | تصویر شروع یا دنباله تصویری که باید رمزگذاری شود. | IMAGE | بله | - |
| `خروجی clip vision` | خروجی اختیاری مدل بینایی CLIP که به شرطی‌سازی اضافه می‌شود. | CLIP_VISION_OUTPUT | خیر | - |

**نکته:** پارامتر `strength` تنها زمانی اثر دارد که `tracks` ارائه شده باشد و `strength` بزرگ‌تر از 0.0 باشد؛ شرطی‌سازی ردیابی فقط زمانی اعمال می‌شود که `start_image` نیز ارائه شده باشد. اگر `tracks` ارائه نشود یا `strength` برابر 0.0 باشد، ترکیب ردیابی نادیده گرفته می‌شود. وقتی ترکیب ردیابی فعال است، شرطی‌سازی مثبت تصویر نهان ترکیب‌شده با ردیابی را دریافت می‌کند، در حالی که شرطی‌سازی منفی تصویر نهان تغییرنیافته را دریافت می‌کند. اگر `start_image` ارائه نشود، هیچ تصویر نهان و شرطی‌سازی ماسکی ایجاد نمی‌شود؛ شرطی‌سازی مثبت و منفی بدون تغییر عبور می‌کنند (به‌جز اینکه `clip_vision_output` در صورت ارائه همچنان اضافه می‌شود) و گره یک فضای نهان خالی خروجی می‌دهد.

**نکته:** وقتی `start_image` ارائه می‌شود، دنباله تصویر به `width` و `height` هدف تغییر اندازه می‌یابد و به `length` فریم اول بریده می‌شود. اگر دنباله کوتاه‌تر از `length` باشد، فریم‌های باقی‌مانده قبل از رمزگذاری VAE با فریم‌های خاکستری خنثی (مقدار 0.5) پر می‌شوند. شرطی‌سازی حاصل شامل یک `concat_mask` با مقدار 0 در موقعیت‌های زمانی مربوط به فریم‌های تصویر شروع و 1 در سایر موقعیت‌ها است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده، که احتمالاً شامل `concat_latent_image`، `concat_mask` و `clip_vision_output` است. | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده، که احتمالاً شامل `concat_latent_image`، `concat_mask` و `clip_vision_output` است. | CONDITIONING |
| `latent` | یک تانسور نهان خالی با شکل `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]` که توسط ورودی‌های `batch_size`، `length`، `height` و `width` تعیین می‌شود. | LATENT |
