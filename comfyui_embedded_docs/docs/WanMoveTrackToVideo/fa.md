# WanMoveTrackToVideo

گره WanMoveTrackToVideo داده‌های شرطی‌سازی و نهان را برای تولید ویدیو آماده می‌کند. این گره با استفاده از یک VAE، دنباله تصویر شروع را به فضای نهان رمزگذاری می‌کند و به‌صورت اختیاری می‌تواند اطلاعات ردیابی حرکت را برای هدایت حرکت اشیاء در ویدیوی تولیدشده در نظر بگیرد. خروجی این گره، شرطی‌سازی مثبت و منفی اصلاح‌شده به همراه یک تنسور نهان خالی است که برای مدل تولید ویدیو آماده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت که باید اصلاح شود. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی که باید اصلاح شود. | CONDITIONING | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگذاری تصویر شروع در فضای نهان. | VAE | بله | - |
| `tracks` | داده‌های اختیاری ردیابی حرکت شامل مسیرهای اشیاء. | TRACKS | خیر | - |
| `strength` | قدرت شرطی‌سازی مسیر. تنها زمانی تأثیر دارد که `tracks` ارائه شده باشد و مقدار آن بزرگ‌تر از 0.0 باشد. (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 - 100.0 |
| `width` | عرض ویدیوی خروجی. در مضارب 16 تنظیم می‌شود. (پیش‌فرض: 832) | INT | بله | 16 - MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی. در مضارب 16 تنظیم می‌شود. (پیش‌فرض: 480) | INT | بله | 16 - MAX_RESOLUTION |
| `length` | تعداد فریم‌ها در دنباله ویدیو. در مضارب 4 تنظیم می‌شود. (پیش‌فرض: 81) | INT | بله | 1 - MAX_RESOLUTION |
| `batch_size` | اندازه دسته برای خروجی نهان. (پیش‌فرض: 1) | INT | بله | 1 - 4096 |
| `start_image` | تصویر شروع یا دنباله تصاویر برای رمزگذاری با VAE. | IMAGE | بله | - |
| `clip_vision_output` | خروجی اختیاری مدل بینایی CLIP برای افزودن به شرطی‌سازی. | CLIP_VISION_OUTPUT | خیر | - |

توجه: حرکت مبتنی بر مسیر تنها زمانی اعمال می‌شود که `tracks` ارائه شده باشد و `strength` بزرگ‌تر از 0.0 باشد. در غیر این صورت، شرطی‌سازی تصویر شروع رمزگذاری‌شده بدون تغییر را دریافت می‌کند. `start_image` برای ایجاد یک تصویر نهان و یک ماسک برای شرطی‌سازی استفاده می‌شود؛ اگر در دسترس نباشد، گره فقط شرطی‌سازی را عبور می‌دهد و یک نهان خالی خروجی می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت اصلاح‌شده، که احتمالاً شامل `concat_latent_image`، `concat_mask` و `clip_vision_output` است. | CONDITIONING |
| `negative` | شرطی‌سازی منفی اصلاح‌شده، که احتمالاً شامل `concat_latent_image`، `concat_mask` و `clip_vision_output` است. | CONDITIONING |
| `latent` | یک تنسور نهان خالی با ابعادی که توسط ورودی‌های `batch_size`، `length`، `height` و `width` شکل گرفته است. | LATENT |
