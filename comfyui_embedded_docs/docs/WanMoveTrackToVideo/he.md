# WanMoveTrackToVideo

צומת WanMoveTrackToVideo מכינה נתוני התניה ומרחב לטנט ליצירת וידאו, תוך שילוב מידע אופציונלי של מעקב תנועה. היא מקודדת רצף תמונות התחלתי לייצוג לטנט, ויכולה למזג לתוכו נתוני מיקום ממסלולי אובייקטים כדי להנחות את התנועה בווידאו הנוצר. הצומת מוציאה התניות חיוביות ושליליות ששונו יחד עם טנזור לטנט ריק המוכן למודל וידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט ההתניה החיובית שיש לשנות. | CONDITIONING | כן | - |
| `negative` | קלט ההתניה השלילית שיש לשנות. | CONDITIONING | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד תמונת ההתחלה למרחב הלטנט. | VAE | כן | - |
| `tracks` | נתוני מעקב תנועה אופציונליים המכילים מסלולי אובייקטים. משתמש ב-`track_path` ובאופן אופציונלי ב-`track_visibility`; אם `track_visibility` חסר, כל המסלולים מטופלים כגלויים. | TRACKS | לא | - |
| `strength` | עוצמת התניית המסלולים. (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 - 100.0 |
| `width` | רוחב הווידאו בפלט. חייב להיות מתחלק ב-16. (ברירת מחדל: 832) | INT | כן | 16 - MAX_RESOLUTION |
| `height` | גובה הווידאו בפלט. חייב להיות מתחלק ב-16. (ברירת מחדל: 480) | INT | כן | 16 - MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו, בכפולות של 4. (ברירת מחדל: 81) | INT | כן | 1 - MAX_RESOLUTION |
| `batch_size` | גודל האצווה עבור פלט הלטנט. (ברירת מחדל: 1) | INT | כן | 1 - 4096 |
| `start_image` | תמונת ההתחלה או רצף התמונות לקידוד. | IMAGE | כן | - |
| `clip_vision_output` | פלט אופציונלי של מודל ראייה CLIP להוספה להתניה. | CLIP_VISION_OUTPUT | לא | - |

**הערה:** לפרמטר `strength` יש השפעה רק כאשר מסופקים `tracks` ו-`strength` גדול מ-0.0; התניית מסלולים מיושמת רק כאשר גם `start_image` מסופק. אם `tracks` לא מסופקים או `strength` הוא 0.0, מיזוג המסלולים מדולג. כאשר מיזוג המסלולים פעיל, ההתניה החיובית מקבלת את תמונת הלטנט הממוזגת עם המסלולים, ואילו ההתניה השלילית מקבלת את תמונת הלטנט ללא שינוי. אם `start_image` לא מסופק, לא נוצרת התניית תמונת לטנט ומסכה; ההתניות החיובית והשלילית עוברות ללא שינוי (למעט ש-`clip_vision_output` עדיין מתווסף אם סופק), והצומת מוציא לטנט ריק.

**הערה:** כאשר `start_image` מסופק, רצף התמונות משתנה לגודל היעד `width` ו-`height` ומקוצר ל-`length` הפריימים הראשונים. אם הרצף קצר מ-`length`, הפריימים הנותרים ממולאים בפריימים אפורים ניטרליים (ערך 0.5) לפני קידוד VAE. ההתניה המתקבלת כוללת `concat_mask` עם ערך 0 במיקומים הזמניים המתאימים לפריימי תמונת ההתחלה וערך 1 במקומות אחרים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | ההתניה החיובית ששונתה, שעשויה להכיל `concat_latent_image`, `concat_mask` ו-`clip_vision_output`. | CONDITIONING |
| `negative` | ההתניה השלילית ששונתה, שעשויה להכיל `concat_latent_image`, `concat_mask` ו-`clip_vision_output`. | CONDITIONING |
| `latent` | טנזור לטנט ריק בצורה `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`, שנקבע על ידי הקלטים `batch_size`, `length`, `height` ו-`width`. | LATENT |
