# LTXV Dual CFG Guider

Этот узел создает объект направленного сэмплирования (CFG guider) для моделей LTXV-AV. Он применяет отдельный коэффициент CFG к видео- и аудио-частям упакованного латентного представления, позволяя независимо контролировать влияние кондиционирования на каждую модальность. Если два коэффициента равны или если латентное представление не содержит отдельных видео- и аудио-компонентов, используется единый общий масштаб.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая при сэмплировании. | MODEL | Да | - |
| `positive` | Позитивное кондиционирование, направляющее генерацию к желаемому результату. | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование, отводящее генерацию от нежелательного. | CONDITIONING | Да | - |
| `video_cfg` | Коэффициент CFG, применяемый к видео-части латентного представления (по умолчанию: 3.0). | FLOAT | Да | 0.0 до 100.0 |
| `audio_cfg` | Коэффициент CFG, применяемый к аудио-части латентного представления (по умолчанию: 7.0). | FLOAT | Да | 0.0 до 100.0 |

Примечание: когда `video_cfg` и `audio_cfg` равны или очень близки по значению, направитель использует это значение как единый коэффициент CFG для всего латентного представления. Если латентное представление не является упакованным латентным представлением LTXV-AV, используется только значение `video_cfg`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `guider` | Настроенный CFG-направитель для передачи в узел сэмплирования. | GUIDER |
