# LTXV Dual CFG Guider

Этот узел создаёт объект направляемого сэмплирования (CFG guider) для моделей LTXV-AV. Он применяет отдельный масштаб управления к видеочасти и аудиочасти упакованного латента LTXV-AV, позволяя независимо управлять влиянием кондиционирования на каждую модальность. Если оба масштаба равны или латент не содержит отдельных видео- и аудиокомпонентов, вместо этого используется единый общий масштаб.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая при сэмплировании. | MODEL | Да | - |
| `positive` | Положительное кондиционирование, к которому нужно направлять генерацию. | CONDITIONING | Да | - |
| `negative` | Отрицательное кондиционирование, от которого нужно отводить генерацию. | CONDITIONING | Да | - |
| `video_cfg` | Сила управления, применяемая к видеомодальности латента (по умолчанию: 3.0). | FLOAT | Да | 0.0–100.0 |
| `audio_cfg` | Сила управления, применяемая к аудиомодальности латента (по умолчанию: 7.0). | FLOAT | Да | 0.0–100.0 |

Примечание. Когда `video_cfg` и `audio_cfg` равны (или очень близки по значению), CFG guider использует это значение как единый масштаб CFG для всего латента. Если латент не является упакованным латентом LTXV-AV, используется только значение `video_cfg`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `guider` | Настроенный CFG guider, который следует передать в узел сэмплера. | GUIDER |
