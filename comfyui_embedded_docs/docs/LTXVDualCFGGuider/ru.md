# LTXVDualCFGGuider

Этот узел создаёт объект управляемой выборки (CFG guider) для моделей LTXV-AV. Он применяет отдельный масштаб управления к видео- и аудиочастям упакованного латента, позволяя независимо контролировать влияние кондиционирования на каждую модальность. Если два масштаба равны или латент не содержит отдельных видео- и аудиокомпонентов, используется единый общий масштаб.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель для использования при сэмплировании. | MODEL | Да | - |
| `positive` | Позитивное кондиционирование, направляющее генерацию к заданному результату. | CONDITIONING | Да | - |
| `negative` | Негативное кондиционирование, уводящее генерацию от нежелательных результатов. | CONDITIONING | Да | - |
| `video_cfg` | Сила управления, применяемая к видеомодальности латента (по умолчанию: 3.0). | FLOAT | Да | 0.0 до 100.0 |
| `audio_cfg` | Сила управления, применяемая к аудиомодальности латента (по умолчанию: 7.0). | FLOAT | Да | 0.0 до 100.0 |

Примечание: когда значения `video_cfg` и `audio_cfg` совпадают, guider использует это значение как единый масштаб CFG для всего латента. Если латент не является упакованным латентом LTXV-AV, используется только значение `video_cfg`.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `guider` | Настроенный объект CFG guider, который нужно передать узлу сэмплера. | GUIDER |
