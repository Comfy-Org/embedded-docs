# LTXVDualCFGGuider

این گره یک شیء نمونه‌گیری هدایت‌شده (راهنمای CFG) برای مدل‌های LTXV-AV ایجاد می‌کند. این گره مقیاس راهنمایی جداگانه‌ای را برای بخش ویدیو و بخش صوتی latent بسته‌بندی‌شده اعمال می‌کند و به شما امکان می‌دهد تأثیر شرطی‌سازی را بر هر مدالیته به‌طور مستقل کنترل کنید. اگر این دو مقیاس برابر باشند، یا اگر latent حاوی اجزای ویدیو و صوتی جداگانه نباشد، از یک مقیاس کلی واحد استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|-----------|-----------|----------|-------|
| `model` | مدلی که هنگام نمونه‌گیری استفاده می‌شود. | MODEL | بله | - |
| `positive` | شرطی‌سازی مثبت برای هدایت تولید به سمت آن. | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی برای دور کردن تولید از آن. | CONDITIONING | بله | - |
| `video_cfg` | شدت راهنمایی اعمال‌شده به مدالیته ویدیویی latent (پیش‌فرض: 3.0). | FLOAT | بله | 0.0 تا 100.0 |
| `audio_cfg` | شدت راهنمایی اعمال‌شده به مدالیته صوتی latent (پیش‌فرض: 7.0). | FLOAT | بله | 0.0 تا 100.0 |

نکته: وقتی `video_cfg` و `audio_cfg` مقدار یکسانی داشته باشند، راهنما از آن مقدار به‌عنوان یک مقیاس CFG واحد برای کل latent استفاده می‌کند. اگر latent یک latent بسته‌بندی‌شدهٔ LTXV-AV نباشد، فقط مقدار `video_cfg` استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `guider` | راهنمای CFG پیکربندی‌شده که باید به یک گره نمونه‌گیر (sampler) ارسال شود. | GUIDER |
