# راهنمای دوگانه CFG LTXV

این گره یک شیء نمونه‌برداری هدایت‌شده (راهنمای CFG) برای مدل‌های LTXV-AV ایجاد می‌کند. این گره یک مقیاس راهنمایی جداگانه به بخش ویدئو و بخش صوتی لاتنت فشرده اعمال می‌کند و به شما امکان می‌دهد تأثیر شرط‌گذاری را بر هر یک از این دو مدالیته به‌طور مستقل کنترل کنید. اگر دو مقیاس برابر باشند، یا اگر لاتنت شامل مؤلفه‌های ویدئو و صوتی جداگانه نباشد، از یک مقیاس کلی واحد استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که هنگام نمونه‌برداری استفاده می‌شود. | MODEL | بله | - |
| `مثبت` | شرط‌گذاری مثبت برای هدایت تولید به سمت خواسته. | CONDITIONING | بله | - |
| `منفی` | شرط‌گذاری منفی برای دور کردن تولید از حالت ناخواسته. | CONDITIONING | بله | - |
| `ویدیو CFG` | قدرت راهنمایی اعمال‌شده به مدالیته ویدئویی لاتنت (پیش‌فرض: 3.0). | FLOAT | بله | 0.0 تا 100.0 |
| `صوت CFG` | قدرت راهنمایی اعمال‌شده به مدالیته صوتی لاتنت (پیش‌فرض: 7.0). | FLOAT | بله | 0.0 تا 100.0 |

نکته: وقتی `video_cfg` و `audio_cfg` برابر یا بسیار نزدیک به هم باشند، راهنما از آن مقدار به‌عنوان یک مقیاس CFG واحد برای کل لاتنت استفاده می‌کند. اگر لاتنت، یک لاتنت فشرده LTXV-AV نباشد، فقط مقدار `video_cfg` استفاده می‌شود.
