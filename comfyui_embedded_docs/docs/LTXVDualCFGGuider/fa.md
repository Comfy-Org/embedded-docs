# راهنمای دوگانه CFG LTXV

این گره برای مدل‌های LTXV-AV یک شیء نمونه‌گیری هدایت‌شده (CFG guider) می‌سازد. یک مقیاس راهنمایی جداگانه برای بخش ویدئو و بخش صدا از یک latent بسته‌بندی‌شده LTXV-AV اعمال می‌کند و به شما امکان می‌دهد تأثیر شرطی‌سازی را روی هر مودالیتی به‌صورت مستقل کنترل کنید. اگر دو مقیاس برابر باشند، یا اگر latent دارای اجزای جداگانه ویدئو و صدا نباشد، در عوض یک مقیاس کلی واحد استفاده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که هنگام نمونه‌گیری استفاده می‌شود. | MODEL | بله | - |
| `positive` | شرطی‌سازی مثبت برای هدایت تولید به سمت آن. | CONDITIONING | بله | - |
| `negative` | شرطی‌سازی منفی برای هدایت تولید به دور از آن. | CONDITIONING | بله | - |
| `video_cfg` | قدرت راهنمایی اعمال‌شده به مودالیتی ویدئو در latent (پیش‌فرض: 3.0). | FLOAT | بله | 0.0 تا 100.0 |
| `audio_cfg` | قدرت راهنمایی اعمال‌شده به مودالیتی صدا در latent (پیش‌فرض: 7.0). | FLOAT | بله | 0.0 تا 100.0 |

توجه: زمانی که `video_cfg` و `audio_cfg` برابر باشند (یا مقادیرشان بسیار نزدیک باشد)، راهنمای CFG از آن مقدار به‌عنوان یک مقیاس CFG واحد برای کل latent استفاده می‌کند. اگر latent یک latent بسته‌بندی‌شده LTXV-AV نباشد، فقط مقدار `video_cfg` استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `guider` | راهنمای CFG پیکربندی‌شده که باید به یک گره نمونه‌گیر داده شود. | GUIDER |
