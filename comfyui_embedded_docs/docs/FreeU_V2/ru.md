# FreeU_V2

Узел FreeU_V2 улучшает качество генерации изображений, применяя частотные модификации к U-Net архитектуре диффузионной модели. Он использует настраиваемые коэффициенты масштабирования для регулировки каналов признаков в разных блоках, улучшая результат без необходимости дополнительного обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется улучшение FreeU | MODEL | Да | - |
| `b1` | Коэффициент масштабирования признаков backbone для первого блока (по умолчанию: 1.3) | FLOAT | Да | 0.0 - 10.0 |
| `b2` | Коэффициент масштабирования признаков backbone для второго блока (по умолчанию: 1.4) | FLOAT | Да | 0.0 - 10.0 |
| `s1` | Коэффициент масштабирования skip-признаков для первого блока (по умолчанию: 0.9) | FLOAT | Да | 0.0 - 10.0 |
| `s2` | Коэффициент масштабирования skip-признаков для второго блока (по умолчанию: 0.2) | FLOAT | Да | 0.0 - 10.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Улучшенная диффузионная модель с применёнными модификациями FreeU | MODEL |
