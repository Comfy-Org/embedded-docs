# FreeU_V2

FreeU_V2 улучшает качество генерации изображений, применяя частотные модификации к архитектуре U-Net диффузионной модели. Он использует настраиваемые коэффициенты масштабирования для регулировки каналов признаков в различных блоках, улучшая результат без необходимости дополнительного обучения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Диффузионная модель, к которой применяется улучшение FreeU | MODEL | Да | - |
| `b1` | Коэффициент масштабирования признаков магистрали для первого блока (по умолчанию: 1.3) | FLOAT | Да | 0.0 - 10.0 |
| `b2` | Коэффициент масштабирования признаков магистрали для второго блока (по умолчанию: 1.4) | FLOAT | Да | 0.0 - 10.0 |
| `s1` | Коэффициент масштабирования признаков пропуска (skip) для первого блока (по умолчанию: 0.9) | FLOAT | Да | 0.0 - 10.0 |
| `s2` | Коэффициент масштабирования признаков пропуска (skip) для второго блока (по умолчанию: 0.2) | FLOAT | Да | 0.0 - 10.0 |

Примечание: `b1`, `b2`, `s1` и `s2` — это дополнительные параметры, скрытые по умолчанию в интерфейсе узла. Их можно задавать с шагом 0.01 в диапазоне 0.0 - 10.0. `b1` и `s1` управляют блоком U-Net с наибольшим числом каналов, а `b2` и `s2` — блоком с вдвое меньшим числом каналов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Улучшенная диффузионная модель с применёнными модификациями FreeU | MODEL |
