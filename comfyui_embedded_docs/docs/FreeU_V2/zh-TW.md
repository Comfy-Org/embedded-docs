# FreeU_V2

FreeU_V2 透過對擴散模型的 U-Net 架構套用基於頻率的修改，來提升影像生成品質。它使用可設定的縮放因子來調整不同區塊中的特徵通道，無需額外訓練即可改善輸出。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要套用 FreeU 增強功能的擴散模型 | MODEL | 是 | - |
| `b1` | 第一個區塊的主幹特徵縮放因子（預設值：1.3） | FLOAT | 是 | 0.0 - 10.0 |
| `b2` | 第二個區塊的主幹特徵縮放因子（預設值：1.4） | FLOAT | 是 | 0.0 - 10.0 |
| `s1` | 第一個區塊的跳躍特徵縮放因子（預設值：0.9） | FLOAT | 是 | 0.0 - 10.0 |
| `s2` | 第二個區塊的跳躍特徵縮放因子（預設值：0.2） | FLOAT | 是 | 0.0 - 10.0 |

注意：`b1`、`b2`、`s1` 和 `s2` 是進階參數，在節點的使用者介面中預設為隱藏。它們可在 0.0 - 10.0 範圍內以 0.01 為步進值進行設定。`b1` 和 `s1` 控制通道數最多的 U-Net 區塊，而 `b2` 和 `s2` 控制通道數為其一半的區塊。
