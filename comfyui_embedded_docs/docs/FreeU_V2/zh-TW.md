# FreeU_V2

FreeU_V2 透過對擴散模型的 U-Net 架構套用以頻率為基礎的修改，來提升影像生成品質。它使用可設定的縮放因子調整不同區塊中的特徵通道，無需額外訓練即可改善輸出。此節點透過修補模型的輸出區塊，並過濾隱藏狀態的高頻成分來運作。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要套用 FreeU 增強效果的擴散模型 | MODEL | 是 | - |
| `b1` | 第一個區塊的主幹特徵縮放因子（預設值：1.3） | FLOAT | 是 | 0.0 - 10.0 |
| `b2` | 第二個區塊的主幹特徵縮放因子（預設值：1.4） | FLOAT | 是 | 0.0 - 10.0 |
| `s1` | 第一個區塊的跳躍特徵縮放因子（預設值：0.9） | FLOAT | 是 | 0.0 - 10.0 |
| `s2` | 第二個區塊的跳躍特徵縮放因子（預設值：0.2） | FLOAT | 是 | 0.0 - 10.0 |

注意：`b1`、`b2`、`s1` 和 `s2` 是節點 UI 中預設隱藏的高階參數。它們可在 0.0 - 10.0 範圍內以 0.01 為增量設定。`b1` 和 `s1` 控制通道數最多的 U-Net 區塊（模型基礎通道數的四倍），而 `b2` 和 `s2` 控制通道數為前者一半的區塊（基礎通道數的兩倍）。
