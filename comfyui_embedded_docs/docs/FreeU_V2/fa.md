# FreeU_V2

گره FreeU_V2 کیفیت تولید تصویر را با اعمال تغییرات مبتنی بر فرکانس بر معماری U-Net مدل انتشار بهبود می‌بخشد. این گره از ضرایب مقیاس قابل تنظیم برای تنظیم کانال‌های ویژگی در بلوک‌های مختلف استفاده می‌کند و خروجی را بدون نیاز به آموزش اضافی بهبود می‌دهد.

| `b2` | ضریب مقیاس ویژگی‌های Backbone برای بلوک دوم (پیش‌فرض: 1.4) | FLOAT | بله | 0.0 - 10.0 |
| `s1` | ضریب مقیاس ویژگی‌های Skip برای بلوک اول (پیش‌فرض: 0.9) | FLOAT | بله | 0.0 - 10.0 |
| `s2` | ضریب مقیاس ویژگی‌های Skip برای بلوک دوم (پیش‌فرض: 0.2) | FLOAT | بله | 0.0 - 10.0 |
