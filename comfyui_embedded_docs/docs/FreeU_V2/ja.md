# FreeU_V2

FreeU_V2 ノードは、拡散モデルの U-Net アーキテクチャに周波数ベースの変更を適用することで、画像生成品質を向上させます。設定可能なスケーリング係数を使用してさまざまなブロックの特徴チャンネルを調整し、追加のトレーニングを必要とせずに出力を改善します。

| `b2` | 2 番目のブロックのバックボーン特徴スケーリング係数（デフォルト: 1.4） | FLOAT | はい | 0.0 - 10.0 |
| `s1` | 最初のブロックのスキップ特徴スケーリング係数（デフォルト: 0.9） | FLOAT | はい | 0.0 - 10.0 |
| `s2` | 2 番目のブロックのスキップ特徴スケーリング係数（デフォルト: 0.2） | FLOAT | はい | 0.0 - 10.0 |
