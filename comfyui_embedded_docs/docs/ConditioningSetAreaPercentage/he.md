# התניה (הגדרת אזור באחוזים)

צומת ConditioningSetAreaPercentage מתמחה בהתאמת אזור ההשפעה של רכיבי התניה בהתבסס על ערכי אחוזים. היא מאפשרת לציין את מידות האזור ומיקומו כאחוזים מגודל התמונה הכולל, יחד עם פרמטר עוצמה לכוונון עוצמת אפקט ההתניה.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `CONDITIONING` | מייצג את רכיבי ההתניה שיש לשנות, ומשמש כבסיס להחלת התאמות אזור ועוצמה. | CONDITIONING |
| `width` | מציין את רוחב האזור כאחוז מרוחב התמונה הכולל, ומשפיע על המידה שבה ההתניה משפיעה אופקית על התמונה. | `FLOAT` |
| `height` | קובע את גובה האזור כאחוז מגובה התמונה הכולל, ומשפיע על ההיקף האנכי של השפעת ההתניה. | `FLOAT` |
| `x` | מציין את נקודת ההתחלה האופקית של האזור כאחוז מרוחב התמונה הכולל, וממקם את אפקט ההתניה. | `FLOAT` |
| `y` | מציין את נקודת ההתחלה האנכית של האזור כאחוז מגובה התמונה הכולל, וממקם את אפקט ההתניה. | `FLOAT` |
| `strength` | שולט בעוצמת אפקט ההתניה בתוך האזור שצוין, ומאפשר כוונון עדין של השפעתו. | `FLOAT` |
