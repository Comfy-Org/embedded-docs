# ARVideoI2V

## 개요

이 노드는 AR(자동 회귀) 비디오 모델을 위한 이미지-투-비디오 생성 설정을 준비합니다. 시작 이미지를 가져와 VAE를 사용하여 잠재 공간으로 인코딩하고, 인코딩된 이미지를 모델의 구성에 저장합니다. 이를 통해 비디오 샘플링 프로세스가 이미지를 첫 번째 프레임으로 사용할 수 있으므로, 별도의 이미지-투-비디오 모델 아키텍처 없이 생성을 시드할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 생성에 사용할 AR 비디오 모델입니다. | MODEL | 예 | - |
| `vae` | 시작 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `start_image` | 생성된 비디오의 첫 번째 프레임으로 사용될 초기 이미지입니다. | IMAGE | 예 | - |
| `width` | 생성된 비디오 프레임의 너비입니다 (기본값: 832). | INT | 예 | 16 to 8192 (step: 16) |
| `height` | 생성된 비디오 프레임의 높이입니다 (기본값: 480). | INT | 예 | 16 to 8192 (step: 16) |
| `length` | 생성된 비디오의 총 프레임 수입니다 (기본값: 81). | INT | 예 | 1 to 1024 (step: 4) |
| `batch_size` | 단일 배치에서 생성할 비디오 시퀀스 수입니다 (기본값: 1). | INT | 예 | 1 to 64 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 비디오 생성을 위해 인코딩된 시작 이미지가 구성에 저장된 복제 모델입니다. | MODEL |
| `LATENT` | 형상이 [batch_size, 16, lat_t, height/8, width/8]인 빈 잠재 텐서입니다. 여기서 lat_t = ((length - 1) // 4) + 1은 요청된 비디오 길이에서 파생된 잠재 프레임 수입니다. | LATENT |
