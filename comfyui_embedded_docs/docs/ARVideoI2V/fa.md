# ARVideoI2V

این گره یک چیدمان تولید ویدئو از تصویر را برای مدل‌های ویدئویی AR (خودرگرسیو) که از Causal Forcing یا Self-Forcing استفاده می‌کنند آماده می‌کند. تصویر آغازین را با یک VAE به فضای نهفته کدگذاری می‌کند و آن را در گزینه‌های ترنسفورمر مدل ذخیره می‌کند، تا فرایند نمونه‌گیری ویدئو بتواند پیش از نویززدایی، حافظه نهان KV را مقداردهی اولیه کند. از همان چک‌پوینت مدل متن‌به‌ویدئو استفاده می‌کند، بنابراین به معماری جداگانهٔ تصویر‌به‌ویدئو نیازی نیست.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل ویدئویی AR که برای تولید استفاده می‌شود. | MODEL | بله | - |
| `vae` | مدل VAE که برای کدگذاری تصویر آغازین به فضای نهفته استفاده می‌شود. | VAE | بله | - |
| `start_image` | تصویر اولیه‌ای که به‌عنوان نخستین فریم ویدئوی تولیدشده عمل می‌کند. فقط نخستین تصویر در دسته ورودی استفاده می‌شود و تنها کانال‌های RGB آن کدگذاری می‌شوند. | IMAGE | بله | - |
| `width` | عرض فریم‌های ویدئوی تولیدشده (پیش‌فرض: 832). | INT | بله | 16 تا 8192 (گام: 16) |
| `height` | ارتفاع فریم‌های ویدئوی تولیدشده (پیش‌فرض: 480). | INT | بله | 16 تا 8192 (گام: 16) |
| `length` | تعداد کل فریم‌های ویدئوی تولیدشده (پیش‌فرض: 81). | INT | بله | 1 تا 1024 (گام: 4) |
| `batch_size` | تعداد دنباله‌های ویدئویی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 64 |

توجه: تصویر آغازین پیش از کدگذاری به `width` و `height` مشخص‌شده تغییر اندازه داده می‌شود. بُعد زمانی نهفته به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود، و ابعاد مکانی نهفته برابر `height / 8` و `width / 8` هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدل کلون‌شده که تصویر آغازین کدگذاری‌شده در گزینه‌های ترنسفورمر آن ذخیره شده است (`ar_config.initial_latent`)، که نمونه‌گیر از آن برای مقداردهی اولیه حافظه نهان KV پیش از نویززدایی استفاده می‌کند. | MODEL |
| `LATENT` | یک تنسور نهفتهٔ پر‌شده از صفر با شکل `[batch_size, 16, lat_t, height // 8, width // 8]`، که در آن `lat_t = ((length - 1) // 4) + 1`. | LATENT |
