# ARVideoI2V

## مرور کلی

این گره یک تنظیمات تولید ویدئو از تصویر را برای مدل‌های ویدئویی AR (خودرگرسیون) آماده می‌کند. یک تصویر شروع دریافت کرده، آن را با استفاده از VAE به فضای نهان رمزگذاری می‌کند و تصویر رمزگذاری‌شده را در پیکربندی مدل ذخیره می‌کند. این کار امکان می‌دهد فرآیند نمونه‌برداری ویدئو از تصویر به‌عنوان فریم اول استفاده کند و عملاً تولید را بدون نیاز به معماری جداگانه مدل ویدئویی تصویر‌به‌ویدئو آغاز نماید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل ویدئویی AR که برای تولید استفاده می‌شود. | MODEL | بله | - |
| `vae` | مدل VAE که برای رمزگذاری تصویر شروع به فضای نهان استفاده می‌شود. | VAE | بله | - |
| `start_image` | تصویر اولیه‌ای که به‌عنوان فریم اول ویدئوی تولیدشده عمل خواهد کرد. | IMAGE | بله | - |
| `width` | عرض فریم‌های ویدئوی تولیدشده (پیش‌فرض: 832). | INT | بله | 16 تا 8192 (گام: 16) |
| `height` | ارتفاع فریم‌های ویدئوی تولیدشده (پیش‌فرض: 480). | INT | بله | 16 تا 8192 (گام: 16) |
| `length` | تعداد کل فریم‌های ویدئوی تولیدشده (پیش‌فرض: 81). | INT | بله | 1 تا 1024 (گام: 4) |
| `batch_size` | تعداد توالی‌های ویدئویی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 64 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدل شبیه‌سازی‌شده (clone) با تصویر شروع رمزگذاری‌شده که در پیکربندی آن برای تولید ویدئو ذخیره شده است. | MODEL |
| `LATENT` | یک تانسور نهان خالی با شکل [batch_size, 16, lat_t, height/8, width/8] که در آن lat_t = ((length - 1) // 4) + 1 تعداد فریم‌های نهان استخراج‌شده از طول ویدئوی درخواستی است. | LATENT |
