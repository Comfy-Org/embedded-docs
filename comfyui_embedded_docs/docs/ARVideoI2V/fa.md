# ARVideoI2V

## نمای کلی

این گره یک راه‌اندازی تولید ویدیو از تصویر را برای مدل‌های ویدیویی AR (خودرگرسیون) که از Causal Forcing یا Self-Forcing استفاده می‌کنند، آماده می‌کند. تصویر شروع را با یک VAE به فضای نهان رمزگذاری کرده و آن را در گزینه‌های ترنسفورمر مدل ذخیره می‌کند، به‌طوری که فرآیند نمونه‌برداری ویدیو بتواند قبل از نویززدایی، کش KV را مقداردهی اولیه کند. این کار از همان checkpoint مدل متن‌به‌ویدیو استفاده می‌کند، بنابراین نیازی به معماری جداگانه ویدیو از تصویر نیست.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | بازه |
| --- | --- | --- | --- | --- |
| `مدل` | مدل ویدیویی AR که برای تولید استفاده می‌شود. | MODEL | بله | - |
| `vae` | مدل VAE که برای رمزگذاری تصویر شروع به فضای نهان استفاده می‌شود. | VAE | بله | - |
| `تصویر اولیه` | تصویر اولیه که به عنوان اولین فریم ویدیوی تولیدشده عمل می‌کند. تنها اولین تصویر در دسته ورودی استفاده می‌شود و فقط کانال‌های RGB آن رمزگذاری می‌شوند. | IMAGE | بله | - |
| `عرض` | عرض فریم‌های ویدیوی تولیدشده (پیش‌فرض: 832). | INT | بله | 16 تا 8192 (گام: 16) |
| `ارتفاع` | ارتفاع فریم‌های ویدیوی تولیدشده (پیش‌فرض: 480). | INT | بله | 16 تا 8192 (گام: 16) |
| `طول` | تعداد کل فریم‌های ویدیوی تولیدشده (پیش‌فرض: 81). | INT | بله | 1 تا 1024 (گام: 4) |
| `اندازه بچ` | تعداد توالی‌های ویدیویی که در یک دسته تولید می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 64 |

نکته: تصویر شروع قبل از رمزگذاری به ابعاد `width` و `height` مشخص‌شده تغییر اندازه می‌دهد. بعد زمانی نهان به‌صورت `((length - 1) // 4) + 1` محاسبه می‌شود و ابعاد فضایی نهان نیز `height / 8` و `width / 8` هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدل کلون‌شده با تصویر شروع رمزگذاری‌شده که در گزینه‌های ترنسفورمر آن (`ar_config.initial_latent`) ذخیره شده است؛ نمونه‌بردار از آن برای مقداردهی اولیه کش KV قبل از نویززدایی استفاده می‌کند. | MODEL |
| `LATENT` | یک تنسور نهان پر از صفر با شکل `[batch_size, 16, lat_t, height // 8, width // 8]`، که در آن `lat_t = ((length - 1) // 4) + 1` است. | LATENT |
