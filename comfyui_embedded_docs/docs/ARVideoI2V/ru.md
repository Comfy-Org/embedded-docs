# ARVideoI2V

## Обзор

Этот узел подготавливает конфигурацию для генерации видео из изображения с использованием AR (авторегрессионных) видеомоделей. Он принимает начальное изображение, кодирует его в скрытое пространство с помощью VAE и сохраняет закодированное изображение в конфигурации модели. Это позволяет процессу сэмплирования видео использовать изображение в качестве первого кадра, фактически задавая начальные условия генерации без необходимости отдельной архитектуры «изображение-в-видео».

## Входные данные

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | AR-видеомодель, используемая для генерации. | MODEL | Да | - |
| `vae` | Модель VAE, используемая для кодирования начального изображения в скрытое пространство. | VAE | Да | - |
| `start_image` | Начальное изображение, которое будет служить первым кадром генерируемого видео. | IMAGE | Да | - |
| `width` | Ширина кадров генерируемого видео (по умолчанию: 832). | INT | Да | 16 to 8192 (step: 16) |
| `height` | Высота кадров генерируемого видео (по умолчанию: 480). | INT | Да | 16 to 8192 (step: 16) |
| `length` | Общее количество кадров в генерируемом видео (по умолчанию: 81). | INT | Да | 1 to 1024 (step: 4) |
| `batch_size` | Количество видеопоследовательностей для генерации в одном пакете (по умолчанию: 1). | INT | Да | 1 to 64 |

## Выходные данные

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Клонированная модель с сохраненным в ее конфигурации закодированным начальным изображением для генерации видео. | MODEL |
| `LATENT` | Пустой латентный тензор формы [batch_size, 16, lat_t, height/8, width/8], где lat_t = ((length - 1) // 4) + 1 — это количество латентных кадров, полученное из запрошенной длины видео. | LATENT |
