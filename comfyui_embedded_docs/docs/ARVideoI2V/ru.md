# ARVideoI2V

Этот узел подготавливает настройку генерации видео из изображения для AR (авторегрессивных) видеомоделей, использующих Causal Forcing или Self-Forcing. Он кодирует стартовое изображение в латентное пространство с помощью VAE и сохраняет его в опциях трансформера модели, чтобы процесс сэмплирования видео мог инициализировать KV-кэш перед денойзингом. Используется тот же чекпойнт модели текст-в-видео, поэтому отдельная архитектура для генерации видео из изображения не требуется.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | AR-видеомодель, используемая для генерации. | MODEL | Да | - |
| `vae` | VAE-модель, используемая для кодирования стартового изображения в латентное пространство. | VAE | Да | - |
| `start_image` | Исходное изображение, которое будет служить первым кадром сгенерированного видео. Используется только первое изображение во входном батче, и кодируются только его RGB-каналы. | IMAGE | Да | - |
| `ширина` | Ширина кадров генерируемого видео (по умолчанию: 832). | INT | Да | от 16 до 8192 (шаг: 16) |
| `высота` | Высота кадров генерируемого видео (по умолчанию: 480). | INT | Да | от 16 до 8192 (шаг: 16) |
| `длина` | Общее количество кадров генерируемого видео (по умолчанию: 81). | INT | Да | от 1 до 1024 (шаг: 4) |
| `размер_пакета` | Количество видеопоследовательностей для генерации в одном батче (по умолчанию: 1). | INT | Да | от 1 до 64 |

Примечание: перед кодированием стартовое изображение масштабируется до указанных `width` и `height`. Временная размерность латентного представления вычисляется как `((length - 1) // 4) + 1`, а пространственные размерности латентного представления — `height / 8` и `width / 8`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Клонированная модель с закодированным стартовым изображением, сохранённым в опциях трансформера (`ar_config.initial_latent`); сэмплер использует его для инициализации KV-кэша перед денойзингом. | MODEL |
| `LATENT` | Латентный тензор, заполненный нулями, с формой `[batch_size, 16, lat_t, height // 8, width // 8]`, где `lat_t = ((length - 1) // 4) + 1`. | LATENT |
