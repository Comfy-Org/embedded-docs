# ARVideoI2V

## Обзор

Этот узел подготавливает конфигурацию генерации изображения в видео для AR (авторегрессионных) видеомоделей, использующих Causal Forcing или Self-Forcing. Он кодирует начальное изображение в латентное пространство с помощью VAE и сохраняет его в параметрах трансформера модели, чтобы процесс сэмплирования видео мог инициализировать KV-кэш перед шумоподавлением. Используется та же контрольная точка модели «текст-в-видео», поэтому отдельная архитектура «изображение-в-видео» не требуется.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | AR-видеомодель, используемая для генерации. | MODEL | Да | - |
| `vae` | Модель VAE, используемая для кодирования начального изображения в латентное пространство. | VAE | Да | - |
| `start_image` | Начальное изображение, которое будет служить первым кадром генерируемого видео. Используется только первое изображение во входном пакете, и кодируются только его RGB-каналы. | IMAGE | Да | - |
| `ширина` | Ширина кадров генерируемого видео (по умолчанию: 832). | INT | Да | 16 до 8192 (step: 16) |
| `высота` | Высота кадров генерируемого видео (по умолчанию: 480). | INT | Да | 16 до 8192 (step: 16) |
| `длина` | Общее количество кадров в генерируемом видео (по умолчанию: 81). | INT | Да | 1 до 1024 (step: 4) |
| `размер_пакета` | Количество видеопоследовательностей для генерации в одном пакете (по умолчанию: 1). | INT | Да | 1 до 64 |

Примечание: начальное изображение масштабируется до указанных значений `width` и `height` перед кодированием. Временное измерение латентного пространства вычисляется как `((length - 1) // 4) + 1`, а пространственные измерения латентного пространства равны `height / 8` и `width / 8`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Клонированная модель с сохранённым в её параметрах трансформера закодированным начальным изображением (`ar_config.initial_latent`), которое сэмплер использует для инициализации KV-кэша перед шумоподавлением. | MODEL |
| `LATENT` | Латентный тензор, заполненный нулями, с формой `[batch_size, 16, lat_t, height // 8, width // 8]`, где `lat_t = ((length - 1) // 4) + 1`. | LATENT |
