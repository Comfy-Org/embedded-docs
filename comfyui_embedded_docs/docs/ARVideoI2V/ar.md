# ARVideoI2V

تُهيّئ هذه العقدة إعداد توليد من الصورة إلى الفيديو لنماذج الفيديو AR (Auto-Regressive) التي تستخدم Causal Forcing أو Self-Forcing. تقوم بتشفير صورة البداية إلى الفضاء الكامن باستخدام VAE وتخزينها في خيارات المحوّل الخاصة بالنموذج، بحيث يمكن لعملية أخذ عينات الفيديو تهيئة ذاكرة KV المؤقتة قبل إزالة الضوضاء. وتستخدم نفس نقطة تحقق نموذج النص-إلى-فيديو، لذا لا حاجة إلى معمارية منفصلة للصورة-إلى-فيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج الفيديو AR المراد استخدامه للتوليد. | MODEL | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير صورة البداية إلى الفضاء الكامن. | VAE | نعم | - |
| `start_image` | الصورة الأولية التي ستكون الإطار الأول من الفيديو المولّد. تُستخدم فقط أول صورة في دفعة الإدخال، ويُشفَّر فقط قنوات RGB فيها. | IMAGE | نعم | - |
| `width` | عرض إطارات الفيديو المولّد (الافتراضي: 832). | INT | نعم | 16 إلى 8192 (الخطوة: 16) |
| `height` | ارتفاع إطارات الفيديو المولّد (الافتراضي: 480). | INT | نعم | 16 إلى 8192 (الخطوة: 16) |
| `length` | العدد الإجمالي لإطارات الفيديو المولّد (الافتراضي: 81). | INT | نعم | 1 إلى 1024 (الخطوة: 4) |
| `batch_size` | عدد تسلسلات الفيديو المراد توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 64 |

ملاحظة: يتم تغيير حجم صورة البداية إلى `width` و`height` المحددين قبل تشفيرها. يُحسب البعد الزمني الكامن كـ `((length - 1) // 4) + 1`، والأبعاد المكانية الكامنة هي `height / 8` و`width / 8`.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `MODEL` | النموذج المستنسخ مع تخزين صورة البداية المشفرة في خيارات المحوّل الخاصة به (`ar_config.initial_latent`)، والذي تستخدمه أداة أخذ العينات لتهيئة ذاكرة KV المؤقتة قبل إزالة الضوضاء. | MODEL |
| `LATENT` | موتر كامن مملوء بالأصفار بالشكل `[batch_size, 16, lat_t, height // 8, width // 8]`، حيث `lat_t = ((length - 1) // 4) + 1`. | LATENT |
