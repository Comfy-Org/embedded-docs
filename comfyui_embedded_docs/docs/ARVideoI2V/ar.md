# ARVideoI2V

## نظرة عامة

يعمل هذا العقد على تجهيز إعداد إنشاء فيديو من صورة لنماذج الفيديو ذات الانحدار الذاتي (AR) التي تستخدم أسلوب الفرض السببي (Causal Forcing) أو الفرض الذاتي (Self-Forcing). يقوم بتشفير الصورة الأولية إلى الفضاء الكامن باستخدام VAE ويخزنها في خيارات المحول الخاصة بالنموذج، بحيث يمكن لعملية أخذ العينات للفيديو أن تهيئ ذاكرة التخزين المؤقت KV قبل إزالة التشويش. يستخدم نفس نقطة تفتيش نموذج النص-إلى-فيديو، لذلك لا حاجة إلى بنية منفصلة لتحويل الصورة إلى فيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | نموذج الفيديو AR الذي سيُستخدم في التوليد. | MODEL | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير الصورة الأولية إلى الفضاء الكامن. | VAE | نعم | - |
| `الصورة_البدء` | الصورة الأولية التي ستكون بمثابة الإطار الأول للفيديو المُولَّد. يتم استخدام الصورة الأولى فقط من دفعة الإدخال، ويتم تشفير قنوات RGB الخاصة بها فقط. | IMAGE | نعم | - |
| `العرض` | عرض إطارات الفيديو المُولَّد (الافتراضي: 832). | INT | نعم | 16 إلى 8192 (step: 16) |
| `الارتفاع` | ارتفاع إطارات الفيديو المُولَّد (الافتراضي: 480). | INT | نعم | 16 إلى 8192 (step: 16) |
| `الطول` | إجمالي عدد الإطارات في الفيديو المُولَّد (الافتراضي: 81). | INT | نعم | 1 إلى 1024 (step: 4) |
| `حجم الدفعة` | عدد تسلسلات الفيديو المطلوب توليدها في دفعة واحدة (الافتراضي: 1). | INT | نعم | 1 إلى 64 |

ملاحظة: يتم تغيير حجم الصورة الأولية إلى `width` و `height` المحددين قبل التشفير. يُحسب البعد الزمني الكامن كالتالي `((length - 1) // 4) + 1`، والأبعاد المكانية الكامنة هي `height / 8` و `width / 8`.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
| MODEL | النموذج المُستنسَخ الذي يحتوي على الصورة الأولية المشفرة المخزنة في خيارات المحول الخاصة به (`ar_config.initial_latent`)، ويستخدمه أداة أخذ العينات لتهيئة ذاكرة التخزين المؤقت KV قبل إزالة التشويش. | MODEL |
| LATENT | موتر كامن مملوء بالأصفار بُعده `[batch_size, 16, lat_t, height // 8, width // 8]`، حيث `lat_t = ((length - 1) // 4) + 1`. | LATENT |
