# ARVideoI2V

צומת זה מכין הגדרת יצירת תמונה לווידאו עבור מודלים של וידאו AR (אוטו-רגרסיבי) המשתמשים ב-Causal Forcing או Self-Forcing. הוא מקודד תמונת התחלה למרחב לטנטי באמצעות VAE ושומר אותה באפשרויות ה-Transformer של המודל, כך שתהליך הדגימה של הווידאו יכול לזרוע את מטמון ה-KV לפני הסרת הרעש. הוא משתמש באותו צ'ק פוינט של מודל טקסט לווידאו, כך שאין צורך בארכיטקטורה נפרדת של תמונה לווידאו.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הווידאו AR שישמש ליצירה. | MODEL | כן | - |
| `vae` | מודל ה-VAE המשמש לקידוד תמונת ההתחלה למרחב לטנטי. | VAE | כן | - |
| `start_image` | התמונה ההתחלתית שתשמש כפריים הראשון של הווידאו שנוצר. רק התמונה הראשונה באצוות הקלט משמשת, ורק ערוצי ה-RGB שלה מקודדים. | IMAGE | כן | - |
| `width` | רוחב פריימי הווידאו שנוצרים (ברירת מחדל: 832). | INT | כן | 16 עד 8192 (צעד: 16) |
| `height` | גובה פריימי הווידאו שנוצרים (ברירת מחדל: 480). | INT | כן | 16 עד 8192 (צעד: 16) |
| `length` | המספר הכולל של פריימים בווידאו שנוצר (ברירת מחדל: 81). | INT | כן | 1 עד 1024 (צעד: 4) |
| `batch_size` | מספר רצפי הווידאו ליצירה באצווה אחת (ברירת מחדל: 1). | INT | כן | 1 עד 64 |

הערה: תמונת ההתחלה משתנה לגודל שצוין ב-`width` וב-`height` לפני קידודה. הממד הזמני הלטנטי מחושב כ-`((length - 1) // 4) + 1`, והממדים המרחביים הלטנטיים הם `height / 8` ו-`width / 8`.

## פלטים

| שם פלט | תיאור | סוג נתון |
| --- | --- | --- |
| `MODEL` | המודל המשוכפל עם תמונת ההתחלה המקודדת המאוחסנת באפשרויות ה-Transformer שלו (`ar_config.initial_latent`), שבה הדוגם משתמש כדי לזרוע את מטמון ה-KV לפני הסרת הרעש. | MODEL |
| `LATENT` | טנזור לטנטי מלא באפסים עם צורה `[batch_size, 16, lat_t, height // 8, width // 8]`, כאשר `lat_t = ((length - 1) // 4) + 1`. | LATENT |
