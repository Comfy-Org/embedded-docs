# ARVideoI2V

## 概要

このノードは、AR（自己回帰）ビデオモデル向けの画像からビデオへの生成設定を準備します。開始画像を受け取り、VAEを使用して潜在空間にエンコードし、エンコードされた画像をモデルの構成に保存します。これにより、ビデオサンプリングプロセスがその画像を最初のフレームとして使用できるようになり、別の画像からビデオへのモデルアーキテクチャを必要とせずに生成を効果的にシードします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 生成に使用するARビデオモデルです。 | MODEL | はい | - |
| `vae` | 開始画像を潜在空間にエンコードするために使用されるVAEモデルです。 | VAE | はい | - |
| `start_image` | 生成されたビデオの最初のフレームとして機能する初期画像です。 | IMAGE | はい | - |
| `width` | 生成されるビデオフレームの幅です（デフォルト: 832）。 | INT | はい | 16 to 8192 (step: 16) |
| `height` | 生成されるビデオフレームの高さです（デフォルト: 480）。 | INT | はい | 16 to 8192 (step: 16) |
| `length` | 生成されるビデオの総フレーム数です（デフォルト: 81）。 | INT | はい | 1 to 1024 (step: 4) |
| `batch_size` | 単一バッチで生成するビデオシーケンスの数です（デフォルト: 1）。 | INT | はい | 1 to 64 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| MODEL | ビデオ生成用に、エンコードされた開始画像がその構成に保存されたクローンモデルです。 | MODEL |
| LATENT | 形状 [batch_size, 16, lat_t, height/8, width/8] の空の潜在テンソルです。ここで lat_t = ((length - 1) // 4) + 1 は、要求されたビデオ長から導出される潜在フレーム数です。 | LATENT |
