# TextEncodeAceStepAudio

تعالج عقدة `TextEncodeAceStepAudio` المدخلات النصية لتكييف الصوت من خلال دمج الوسوم وكلمات الأغاني في رموز، ثم ترميزها مع إمكانية ضبط قوة تأثير كلمات الأغاني. تأخذ العقدة نموذج CLIP إلى جانب الأوصاف النصية وكلمات الأغاني، وتُرمّزها معًا، وتولّد بيانات تكييف مناسبة لمهام توليد الصوت. تتيح العقدة ضبط تأثير كلمات الأغاني بدقة عبر معامل قوة يتحكم في مدى تأثيرها على المخرجات النهائية.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لتحويل النص إلى رموز وتشفيرها | CLIP | نعم | - |
| `tags` | وسوم نصية أو أوصاف لتكييف الصوت (تدعم الإدخال متعدد الأسطر والموجهات الديناميكية) | STRING | نعم | - |
| `lyrics` | نص كلمات الأغاني لتكييف الصوت (تدعم الإدخال متعدد الأسطر والموجهات الديناميكية) | STRING | نعم | - |
| `lyrics_strength` | يتحكم في قوة تأثير كلمات الأغاني على مخرجات التكييف (الافتراضي: 1.0، الخطوة: 0.01) | FLOAT | لا | 0.0 - 10.0 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `conditioning` | بيانات التكييف المرمزة التي تحتوي على الرموز النصية المعالجة مع تطبيق قوة كلمات الأغاني | CONDITIONING |
