# TextEncodeAceStepAudio

عقدة TextEncodeAceStepAudio تعالج مدخلات النص لتكييف الصوت من خلال دمج الوسوم وكلمات الأغاني في رموز، ثم ترميزها مع قوة قابلة للتعديل لكلمات الأغاني. تأخذ العقدة نموذج CLIP إلى جانب الأوصاف النصية وكلمات الأغاني، وتحولها إلى رموز معًا، وتُنشئ بيانات تكييف مناسبة لمهام توليد الصوت. تتيح العقدة ضبط تأثير كلمات الأغاني بدقة عبر معلمة قوة تتحكم في تأثيرها على المخرجات النهائية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم للترميز والتحويل إلى رموز | CLIP | نعم | - |
| `علامات` | وسوم نصية أو أوصاف لتكييف الصوت (يدعم الإدخال متعدد الأسطر والموجهات الديناميكية) | STRING | نعم | - |
| `كلمات الأغاني` | نص كلمات الأغاني لتكييف الصوت (يدعم الإدخال متعدد الأسطر والموجهات الديناميكية) | STRING | نعم | - |
| `قوة الكلمات` | يتحكم في قوة تأثير كلمات الأغاني على مخرجات التكييف (الافتراضي: 1.0، الخطوة: 0.01) | FLOAT | نعم | 0.0 - 10.0 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `conditioning` | بيانات التكييف المشفرة التي تحتوي على الرموز النصية المعالجة مع قوة كلمات الأغاني المطبقة | CONDITIONING |
