# TextEncodeAceStepAudio

Узел TextEncodeAceStepAudio обрабатывает текстовые входные данные для звукового кондиционирования, объединяя теги и текст песни в токены, а затем кодируя их с регулируемой силой влияния текста песни. Он принимает модель CLIP вместе с текстовыми описаниями и текстом песни, токенизирует их вместе и генерирует данные conditioning, подходящие для задач генерации звука. Узел позволяет точно настраивать влияние текста песни с помощью параметра силы, который управляет его воздействием на итоговый результат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Да | - |
| `теги` | Текстовые теги или описания для звукового кондиционирования (поддерживается многострочный ввод и динамические промпты) | STRING | Да | - |
| `текст_песни` | Текст песни для звукового кондиционирования (поддерживается многострочный ввод и динамические промпты) | STRING | Да | - |
| `сила_текста_песни` | Управляет силой влияния текста песни на выходные данные conditioning (по умолчанию: 1.0, шаг: 0.01) | FLOAT | Да | 0.0 - 10.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Закодированные данные conditioning, содержащие обработанные текстовые токены с применённой силой влияния текста песни | CONDITIONING |
