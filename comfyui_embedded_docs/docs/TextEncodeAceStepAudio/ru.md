# TextEncodeAceStepAudio

Узел TextEncodeAceStepAudio обрабатывает текстовые входы для аудио-кондиционирования, объединяя теги и текст песни в токены, а затем кодируя их с регулируемой силой влияния текста песни. Он принимает модель CLIP вместе с текстовыми описаниями и текстом песни, токенизирует их вместе и генерирует данные кондиционирования, подходящие для задач аудиогенерации. Узел позволяет точно настраивать влияние текста песни с помощью параметра силы, который контролирует его воздействие на конечный результат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации и кодирования | CLIP | Да | - |
| `tags` | Текстовые теги или описания для аудио-кондиционирования (поддерживает многострочный ввод и динамические промпты) | STRING | Да | - |
| `lyrics` | Текст песни для аудио-кондиционирования (поддерживает многострочный ввод и динамические промпты) | STRING | Да | - |
| `lyrics_strength` | Управляет силой влияния текста песни на выходное кондиционирование (по умолчанию: 1.0, шаг: 0.01) | FLOAT | Нет | 0.0 - 10.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `conditioning` | Закодированные данные кондиционирования, содержащие обработанные текстовые токены с применённой силой влияния текста песни | CONDITIONING |
