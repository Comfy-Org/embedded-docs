# TextEncodeAceStepAudio

הצומת TextEncodeAceStepAudio מעבד קלטי טקסט עבור התניית אודיו על ידי שילוב תגים ומילות שיר לאסימונים, ואז מקודד אותם עם עוצמת מילות שיר ניתנת להתאמה. הוא מקבל מודל CLIP יחד עם תיאורי טקסט ומילות שיר, מבצע עליהם טוקניזציה יחד, ומייצר נתוני התניה המתאימים למשימות יצירת אודיו. הצומת מאפשר כוונון עדין של ההשפעה של מילות השיר באמצעות פרמטר עוצמה ששולט בהשפעתן על הפלט הסופי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל CLIP המשמש לטוקניזציה ולקידוד | CLIP | כן | - |
| `tags` | תגי טקסט או תיאורים עבור התניית אודיו (תומך בקלט מרובה שורות ובפרומפטים דינמיים) | STRING | כן | - |
| `lyrics` | טקסט מילות שיר עבור התניית אודיו (תומך בקלט מרובה שורות ובפרומפטים דינמיים) | STRING | כן | - |
| `lyrics_strength` | שולט בעוצמת ההשפעה של מילות השיר על פלט ההתניה (ברירת מחדל: 1.0, צעד: 0.01) | FLOAT | כן | 0.0 - 10.0 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
