# TextEncodeAceStepAudio

گره TextEncodeAceStepAudio ورودی‌های متنی را برای شرطی‌سازی صوتی پردازش می‌کند؛ به این صورت که تگ‌ها و متن ترانه را به توکن تبدیل کرده، سپس آن‌ها را با قدرت قابل تنظیم متن ترانه رمزگذاری می‌کند. این گره یک مدل CLIP را همراه با توضیحات متنی و متن ترانه دریافت می‌کند، آن‌ها را با هم توکن‌سازی می‌کند و داده‌های شرطی‌سازی مناسبی برای کارهای تولید صدا تولید می‌کند. همچنین امکان تنظیم دقیق تأثیر متن ترانه را از طریق پارامتر قدرت فراهم می‌کند که میزان تأثیر آن را بر خروجی نهایی کنترل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی و رمزگذاری | CLIP | بله | - |
| `برچسب‌ها` | تگ‌ها یا توضیحات متنی برای شرطی‌سازی صوتی (پشتیبانی از ورودی چندخطی و پرامپت‌های پویا) | STRING | بله | - |
| `متن ترانه` | متن ترانه برای شرطی‌سازی صوتی (پشتیبانی از ورودی چندخطی و پرامپت‌های پویا) | STRING | بله | - |
| `قدرت متن ترانه` | قدرت تأثیر متن ترانه بر خروجی شرطی‌سازی را کنترل می‌کند (پیش‌فرض: 1.0، گام: 0.01) | FLOAT | بله | 0.0 - 10.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `conditioning` | داده‌های شرطی‌سازی رمزگذاری‌شده شامل توکن‌های متنی پردازش‌شده به همراه قدرت اعمال‌شدهٔ متن ترانه | CONDITIONING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TextEncodeAceStepAudio/fa.md)
