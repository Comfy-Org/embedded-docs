# TextEncodeAceStepAudio

گره TextEncodeAceStepAudio ورودی‌های متنی را برای شرطی‌سازی صوتی با ترکیب برچسب‌ها و متن آهنگ به توکن پردازش می‌کند و سپس آن‌ها را با قدرت قابل تنظیم متن آهنگ کدگذاری می‌کند. این گره یک مدل CLIP را به همراه توضیحات متنی و متن آهنگ دریافت می‌کند، آن‌ها را با هم توکن‌ایز می‌کند و داده‌های شرطی‌سازی مناسب برای وظایف تولید صدا تولید می‌کند. این گره امکان تنظیم دقیق تأثیر متن آهنگ را از طریق یک پارامتر قدرت فراهم می‌کند که تأثیر آن را بر خروجی نهایی کنترل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP که برای توکن‌ایز کردن و کدگذاری استفاده می‌شود | CLIP | بله | - |
| `tags` | برچسب‌ها یا توضیحات متنی برای شرطی‌سازی صوتی (پشتیبانی از ورودی چندخطی و پرامپت‌های پویا) | STRING | بله | - |
| `lyrics` | متن آهنگ برای شرطی‌سازی صوتی (پشتیبانی از ورودی چندخطی و پرامپت‌های پویا) | STRING | بله | - |
| `lyrics_strength` | قدرت تأثیر متن آهنگ بر خروجی شرطی‌سازی را کنترل می‌کند (پیش‌فرض: 1.0، گام: 0.01) | FLOAT | خیر | 0.0 - 10.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `conditioning` | داده‌های شرطی‌سازی کدگذاری‌شده حاوی توکن‌های متنی پردازش‌شده با قدرت اعمال‌شده متن آهنگ | CONDITIONING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TextEncodeAceStepAudio/fa.md)
