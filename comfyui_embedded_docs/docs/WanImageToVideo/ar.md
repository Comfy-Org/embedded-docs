# وان صورة إلى فيديو

تقوم عقدة WanImageToVideo بتهيئة تمثيلات التهيئة (conditioning) والكامن (latent) لمهام توليد الفيديو. تنشئ مساحة كامنة فارغة لتوليد الفيديو، ويمكنها اختياريًا دمج الصور الأولية ومخرجات CLIP vision لتوجيه عملية توليد الفيديو. تعدّل العقدة كلًا من مدخلات التهيئة الإيجابية والسلبية بناءً على بيانات الصورة والرؤية المقدمة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل التهيئة الإيجابي لتوجيه عملية التوليد | CONDITIONING | نعم | - |
| `سلبي` | مدخل التهيئة السلبي لتوجيه عملية التوليد | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لتشفير الصور إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | عدد الإطارات في الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم الدفعة` | عدد مقاطع الفيديو المراد توليدها في الدفعة الواحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `ناتج رؤية الكليب` | مخرج CLIP vision اختياري لتهيئة إضافية | CLIP_VISION_OUTPUT | لا | - |
| `صورة البداية` | صورة بداية اختيارية لتهيئة توليد الفيديو. عند توفيرها، يتم تغيير حجم الصورة ليطابق العرض والارتفاع المحددين، وتُهيَّأ الإطارات الأولى للفيديو من هذه الصورة. تُملأ الإطارات المتبقية باللون الرمادي المحايد (0.5). يتم تجاهل أي إطارات تتجاوز `length`. | IMAGE | لا | - |

**ملاحظة:** عند توفير `start_image`، تقوم العقدة بتشفير تسلسل الصور باستخدام VAE وتطبيق قناع على مدخلات التهيئة. يغطي القناع جميع الإطارات باستثناء تلك التي تمت تهيئتها بواسطة الصورة الأولية، مما يسمح للتوليد بالبناء على الصورة المقدمة. يتم استخدام القنوات الثلاث الأولى فقط (RGB) من الصورة عند التشفير. معامل `clip_vision_output`، عند توفيره، يضيف تهيئة قائمة على الرؤية إلى كل من المدخلات الإيجابية والسلبية.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | تهيئة إيجابية معدّلة تتضمن بيانات الصورة والرؤية | CONDITIONING |
| `سلبي` | تهيئة سلبية معدّلة تتضمن بيانات الصورة والرؤية | CONDITIONING |
| `مضمر` | موتر فضاء كامن فارغ جاهز لتوليد الفيديو، بشكله [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
