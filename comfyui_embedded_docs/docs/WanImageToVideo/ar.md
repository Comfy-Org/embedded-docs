# وان صورة إلى فيديو

تُهيّئ عقدة WanImageToVideo تمثيلات التهيئة والتمثيلات الكامنة لتوليد الفيديو. وهي تُنشئ فضاءً كامنًا فارغًا للفيديو، ويمكنها اختياريًا دمج صورة بداية ومخرجات رؤية CLIP لتوجيه التوليد. يتم تحديث كل من مدخلي التهيئة الإيجابي والسلبي بالصورة وبيانات الرؤية الموفرة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مدخل التهيئة الإيجابي المستخدم لتوجيه التوليد | CONDITIONING | نعم | - |
| `سلبي` | مدخل التهيئة السلبي المستخدم لتوجيه التوليد | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز الصور إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الفيديو المولَّد (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو المولَّد (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `الطول` | عدد الإطارات في الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `حجم الدفعة` | عدد الفيديوهات المراد توليدها في دفعة واحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `ناتج رؤية الكليب` | مخرجات رؤية CLIP الاختيارية التي تُضاف كتهيئة إضافية إلى كل من المدخلين الإيجابي والسلبي | CLIP_VISION_OUTPUT | لا | - |
| `صورة البداية` | صورة البداية الاختيارية المستخدمة لتهيئة الفيديو. عند توفيرها، يُعاد تحجيمها إلى `width` و`height` المحددين وتُوضع في بداية تسلسل الإطارات؛ يتم تجاهل أي إطارات تتجاوز `length`. وتُملأ الإطارات المتبقية بقيم رمادية محايدة (0.5)، ما لم يتم توفير `ref_pad_image`. | IMAGE | لا | - |
| `ref_pad_image` | صورة مرجعية اختيارية يحل إطارها الأول محل التعبئة الرمادية المحايدة لتسلسل الإطارات. يُعاد تحجيمها إلى `width` و`height` المحددين، ويُستخدم فقط أول صورة في الدفعة. لا يكون لها تأثير إلا عند توفير `start_image` أيضاً. | IMAGE | لا | - |

**ملاحظة:** عند توفير `start_image`، يتم ترميز تسلسل الإطارات باستخدام VAE ويُطبَّق قناع على التهيئة. يُضبط القناع على 0 للإطارات التي تغطيها صورة البداية و1 للإطارات المتبقية، بحيث يستمر التوليد من الصورة الموفرة. يُستخدم فقط أول ثلاث قنوات لونية (RGB) من الصورة أثناء الترميز. يتلقى كل من التهيئة الإيجابية والسلبية نفس الصورة الكامنة المدمجة، والقناع، ومخرجات رؤية CLIP (إن وُفّرت). عند توفير `ref_pad_image` مع `start_image`، يُعاد تحجيم إطارها الأول إلى `width` و`height` ويُكتب في قنوات RGB لإطارات التعبئة قبل وضع صورة البداية فوقها، بحيث تحمل التعبئة الصورة المرجعية بدلاً من الرمادي المسطح. هذه تعبئة مضادة للانحراف بنمط SVI، تُستخدم في نماذج مثل ID-V2V.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تهيئة إيجابية، مُحدَّثة ببيانات الصورة والرؤية | CONDITIONING |
| `negative` | تهيئة سلبية، مُحدَّثة ببيانات الصورة والرؤية | CONDITIONING |
| `latent` | موتر كامن فارغ جاهز لتوليد الفيديو، بالشكل [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
