# Wan画像からビデオへ

WanImageToVideo ノードは、動画生成タスク用のコンディショニングと潜在表現を準備します。動画生成用の空の潜在空間を作成し、オプションで開始画像とCLIPビジョン出力を組み込んで、動画生成プロセスを導くことができます。このノードは、指定された画像とビジョンデータに基づいて、ポジティブおよびネガティブの両方のコンディショニング入力を変更します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 生成を導くためのポジティブコンディショニング入力 | CONDITIONING | はい | - |
| `negative` | 生成を導くためのネガティブコンディショニング入力 | CONDITIONING | はい | - |
| `vae` | 画像を潜在空間にエンコードするためのVAEモデル | VAE | はい | - |
| `width` | 出力動画の幅（デフォルト: 832、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `height` | 出力動画の高さ（デフォルト: 480、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `length` | 動画のフレーム数（デフォルト: 81、ステップ: 4） | INT | はい | 1 to MAX_RESOLUTION |
| `batch_size` | 1回のバッチで生成する動画の数（デフォルト: 1） | INT | はい | 1 to 4096 |
| `clip_vision_output` | 追加のコンディショニング用のオプションのCLIPビジョン出力 | CLIP_VISION_OUTPUT | いいえ | - |
| `start_image` | 動画生成を初期化するためのオプションの開始画像。指定すると、画像は指定された幅と高さにリサイズされ、動画の最初のフレームがこの画像から初期化されます。残りのフレームはニュートラルグレー（0.5）の値で埋められます。画像の最初の`length`フレームのみが使用されます。 | IMAGE | いいえ | - |

**注記:** `start_image` が指定された場合、ノードはVAEを使用して画像シーケンスをエンコードし、コンディショニング入力にマスクを適用します。マスクは、開始画像によって初期化されたフレーム以外のすべてのフレームを覆うため、指定された画像に基づいて生成を構築できます。`clip_vision_output` パラメータは、指定された場合、ポジティブ入力とネガティブ入力の両方にビジョンベースのコンディショニングを追加します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 画像データとビジョンデータが組み込まれた変更済みポジティブコンディショニング | CONDITIONING |
| `negative` | 画像データとビジョンデータが組み込まれた変更済みネガティブコンディショニング | CONDITIONING |
| `latent` | 動画生成用の空の潜在空間テンソル。形状は [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
