# WanImageToVideo

הצומת WanImageToVideo מכין ייצוגי קונדישנינג ו-latent ליצירת וידאו. הוא יוצר חלל latent ריק עבור הווידאו ויכול לשלב באופן אופציונלי תמונת התחלה ופלט CLIP vision כדי להנחות את היצירה. הן קלט הקונדישנינג החיובי והן השלילי מתעדכנים עם התמונה והנתונים החזותיים שסופקו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט קונדישנינג חיובי המשמש להנחות את היצירה | CONDITIONING | כן | - |
| `negative` | קלט קונדישנינג שלילי המשמש להנחות את היצירה | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד תמונות למרחב latent | VAE | כן | - |
| `width` | רוחב הווידאו הנוצר (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה הווידאו הנוצר (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים בווידאו (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הווידאו שייווצרו באצווה אחת (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `clip_vision_output` | פלט CLIP vision אופציונלי שנוסף כקונדישנינג נוסף הן לקלט החיובי והן לקלט השלילי | CLIP_VISION_OUTPUT | לא | - |
| `start_image` | תמונת התחלה אופציונלית המשמשת לאתחול הווידאו. כאשר מסופקת, היא משתנה לגודל `width` ו-`height` שצוינו ומוצבת בתחילת רצף הפריימים; פריימים מעבר ל-`length` אינם נלקחים בחשבון. שאר הפריימים ממולאים בערכי אפור ניטרלי (0.5) אלא אם כן מסופק `ref_pad_image`. | IMAGE | לא | - |
| `ref_pad_image` | תמונת עזר אופציונלית שהפריים הראשון שלה מחליף את ריפוד האפור הניטרלי של רצף הפריימים. היא משתנה לגודל `width` ו-`height` שצוינו, ורק התמונה הראשונה באצווה משמשת. יש לכך השפעה רק כאשר מסופק גם `start_image`. | IMAGE | לא | - |

**הערה:** כאשר מסופק `start_image`, רצף הפריימים מקודד עם ה-VAE ומוחלת מסכה על הקונדישנינג. המסכה מוגדרת ל-0 עבור הפריימים המכוסים על ידי תמונת ההתחלה ול-1 עבור שאר הפריימים, כך שהיצירה ממשיכה מהתמונה שסופקה. רק שלושת ערוצי הצבע הראשונים (RGB) של התמונה משמשים בזמן הקידוד. גם הקונדישנינג החיובי וגם השלילי מקבלים את אותו latent תמונה משורשר, את המסכה, ואת פלט CLIP vision (אם סופק). כאשר `ref_pad_image` מסופק יחד עם `start_image`, הפריים הראשון שלו משתנה לגודל `width` ו-`height` ונכתב לערוצי ה-RGB של פריימי הריפוד לפני שתמונת ההתחלה מונחת מעל, כך שהריפוד נושא את תמונת העזר במקום אפור שטוח. זהו ריפוד אנטי-סחיפה בסגנון SVI, המשמש במודלים כגון ID-V2V.

| שם פלט | תיאור | סוג נתונים |
