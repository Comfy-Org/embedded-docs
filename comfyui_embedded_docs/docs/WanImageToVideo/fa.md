# وان تصویر به ویدیو

گره WanImageToVideo شرطی‌سازی و نمایش‌های نهفته را برای تولید ویدیو آماده می‌کند. یک فضای نهفته خالی برای ویدیو ایجاد می‌کند و می‌تواند به‌صورت اختیاری یک تصویر شروع و خروجی CLIP vision را برای هدایت تولید بگنجاند. هر دو ورودی شرطی‌سازی مثبت و منفی با تصویر و داده‌های vision ارائه‌شده به‌روزرسانی می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی شرطی‌سازی مثبت که برای هدایت تولید استفاده می‌شود | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی که برای هدایت تولید استفاده می‌شود | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر به فضای نهفته | VAE | بله | - |
| `width` | عرض ویدیوی تولیدشده (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی تولیدشده (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `clip_vision_output` | خروجی اختیاری CLIP vision که به‌عنوان شرطی‌سازی اضافی به هر دو ورودی مثبت و منفی افزوده می‌شود | CLIP_VISION_OUTPUT | خیر | - |
| `start_image` | تصویر شروع اختیاری که برای مقداردهی اولیه ویدیو استفاده می‌شود. وقتی ارائه شود، به `width` و `height` مشخص‌شده تغییر اندازه می‌یابد و در ابتدای دنباله فریم‌ها قرار می‌گیرد؛ هر فریمی فراتر از `length` نادیده گرفته می‌شود. فریم‌های باقی‌مانده با مقادیر خاکستری خنثی (0.5) پر می‌شوند. | IMAGE | خیر | - |

**توجه:** وقتی `start_image` ارائه می‌شود، دنباله فریم‌ها با VAE رمزگذاری می‌شود و یک ماسک روی شرطی‌سازی اعمال می‌گردد. ماسک برای فریم‌های پوشش‌داده‌شده توسط تصویر شروع روی 0 و برای فریم‌های باقی‌مانده روی 1 تنظیم می‌شود، بنابراین تولید از تصویر ارائه‌شده ادامه می‌یابد. در هنگام رمزگذاری فقط سه کانال رنگی اول (RGB) تصویر استفاده می‌شوند. هر دو شرطی‌سازی مثبت و منفی، تصویر latent الحاق‌شده، ماسک و (در صورت ارائه) خروجی CLIP vision یکسان را دریافت می‌کنند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی مثبت، به‌روزرسانی‌شده با تصویر و داده‌های vision | CONDITIONING |
| `negative` | شرطی‌سازی منفی، به‌روزرسانی‌شده با تصویر و داده‌های vision | CONDITIONING |
| `latent` | تنسور latent خالی آماده برای تولید ویدیو، با شکل [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
