# وان تصویر به ویدیو

گره WanImageToVideo نماینده‌های شرطی‌سازی و نهان را برای وظایف تولید ویدیو آماده می‌کند. این گره یک فضای نهان خالی برای تولید ویدیو ایجاد می‌کند و می‌تواند به‌صورت اختیاری تصاویر شروع و خروجی‌های CLIP vision را برای هدایت فرآیند تولید ویدیو ترکیب کند. این گره هر دو ورودی شرطی‌سازی مثبت و منفی را بر اساس تصویر و داده‌های بینایی ارائه‌شده اصلاح می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | ورودی شرطی‌سازی مثبت برای هدایت تولید | CONDITIONING | بله | - |
| `منفی` | ورودی شرطی‌سازی منفی برای هدایت تولید | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر به فضای نهان | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `طول` | تعداد فریم‌های ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `اندازه بچ` | تعداد ویدیوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی clip vision` | خروجی CLIP vision اختیاری برای شرطی‌سازی اضافی | CLIP_VISION_OUTPUT | خیر | - |
| `تصویر شروع` | تصویر شروع اختیاری برای مقداردهی اولیه تولید ویدیو. هنگامی که ارائه شود، تصویر برای مطابقت با عرض و ارتفاع مشخص‌شده تغییر اندازه می‌دهد و فریم‌های اول ویدیو از این تصویر مقداردهی می‌شوند. فریم‌های باقی‌مانده با مقادیر خاکستری خنثی (0.5) پر می‌شوند. هر فریم فراتر از `length` نادیده گرفته می‌شود. | IMAGE | خیر | - |

**نکته:** هنگامی که `start_image` ارائه می‌شود، گره دنباله تصویر را با استفاده از VAE رمزگذاری می‌کند و یک ماسک روی ورودی‌های شرطی‌سازی اعمال می‌کند. ماسک همه فریم‌ها به‌جز آن‌هایی که توسط تصویر شروع مقداردهی شده‌اند را پوشش می‌دهد و به تولید اجازه می‌دهد بر اساس تصویر ارائه‌شده بنا شود. هنگام رمزگذاری، فقط سه کانال رنگی اول (RGB) تصویر استفاده می‌شود. پارامتر `clip_vision_output`، در صورت ارائه، شرطی‌سازی مبتنی بر بینایی را به هر دو ورودی مثبت و منفی اضافه می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | شرطی‌سازی مثبت اصلاح‌شده با داده‌های تصویر و بینایی ترکیب‌شده | CONDITIONING |
| `منفی` | شرطی‌سازی منفی اصلاح‌شده با داده‌های تصویر و بینایی ترکیب‌شده | CONDITIONING |
| `latent` | تانسور فضای نهان خالی آماده برای تولید ویدیو، با شکل [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
