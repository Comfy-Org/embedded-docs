# وان تصویر به ویدیو

گره WanImageToVideo، بازنمایی‌های conditioning و latent را برای وظایف تولید ویدئو آماده می‌کند. این گره یک فضای latent خالی برای تولید ویدئو ایجاد می‌کند و به‌صورت اختیاری می‌تواند تصاویر شروع و خروجی‌های CLIP vision را برای هدایت فرآیند تولید ویدئو وارد کند. این گره، هر دو ورودی conditioning مثبت و منفی را بر اساس تصویر و داده vision ارائه‌شده اصلاح می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | ورودی conditioning مثبت برای هدایت تولید | CONDITIONING | بله | - |
| `negative` | ورودی conditioning منفی برای هدایت تولید | CONDITIONING | بله | - |
| `vae` | مدل VAE برای رمزگذاری تصاویر به فضای latent | VAE | بله | - |
| `width` | عرض ویدئوی خروجی (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدئوی خروجی (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های ویدئو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدئوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `clip_vision_output` | خروجی اختیاری CLIP vision برای conditioning اضافی | CLIP_VISION_OUTPUT | خیر | - |
| `start_image` | تصویر شروع اختیاری برای مقداردهی اولیه تولید ویدئو. در صورت ارائه، تصویر تغییر اندازه می‌یابد تا با عرض و ارتفاع مشخص‌شده مطابقت داشته باشد و فریم‌های اول ویدئو از این تصویر مقداردهی می‌شوند. فریم‌های باقی‌مانده با مقادیر خاکستری خنثی (0.5) پر می‌شوند. تنها `length` فریم اول تصویر استفاده می‌شود. | IMAGE | خیر | - |

**توجه:** وقتی `start_image` ارائه شود، گره توالی تصویر را با استفاده از VAE رمزگذاری می‌کند و یک ماسک روی ورودی‌های conditioning اعمال می‌کند. ماسک همه فریم‌ها به جز فریم‌هایی که توسط تصویر شروع مقداردهی شده‌اند را پوشش می‌دهد و به تولید اجازه می‌دهد بر اساس تصویر ارائه‌شده بنا شود. پارامتر `clip_vision_output` در صورت ارائه، conditioning مبتنی بر vision را به هر دو ورودی مثبت و منفی اضافه می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | conditioning مثبت اصلاح‌شده با گنجاندن داده‌های تصویر و vision | CONDITIONING |
| `negative` | conditioning منفی اصلاح‌شده با گنجاندن داده‌های تصویر و vision | CONDITIONING |
| `latent` | تانسور فضای latent خالی آماده برای تولید ویدئو، با شکل [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
