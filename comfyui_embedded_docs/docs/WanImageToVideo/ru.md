# WanИзображениеВВидео

Узел WanImageToVideo подготавливает кондиционирование и латентные представления для генерации видео. Он создаёт пустое латентное пространство для видео и может дополнительно включать начальное изображение и выход CLIP vision для направления генерации. Оба входа кондиционирования — positive и negative — обновляются с использованием предоставленных данных изображения и CLIP vision.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Вход положительного кондиционирования, используемый для направления генерации | CONDITIONING | Да | - |
| `отрицательный` | Вход отрицательного кондиционирования, используемый для направления генерации | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования изображений в латентное пространство | VAE | Да | - |
| `ширина` | Ширина генерируемого видео (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота генерируемого видео (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео, генерируемых в одном пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `clip_vision_output` | Необязательный выход CLIP vision, добавляемый как дополнительное кондиционирование к обоим входам — positive и negative | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное начальное изображение, используемое для инициализации видео. Если оно предоставлено, его размер изменяется до указанных `width` и `height`, и оно помещается в начало последовательности кадров; любые кадры сверх `length` игнорируются. Остальные кадры заполняются нейтральным серым (0.5). | IMAGE | Нет | - |

**Примечание:** Если указан `start_image`, последовательность кадров кодируется с помощью VAE, и к кондиционированию применяется маска. Для кадров, покрытых начальным изображением, маска устанавливается в 0, а для остальных кадров — в 1, поэтому генерация продолжается с предоставленного изображения. При кодировании используются только первые три цветовых канала изображения (RGB). Как positive, так и negative кондиционирование получают одно и то же объединённое латентное изображение, маску и (если он предоставлен) выход CLIP vision.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительное кондиционирование, обновлённое с учётом данных изображения и CLIP vision | CONDITIONING |
| `negative` | Отрицательное кондиционирование, обновлённое с учётом данных изображения и CLIP vision | CONDITIONING |
| `latent` | Пустой латентный тензор, готовый для генерации видео, с формой [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
