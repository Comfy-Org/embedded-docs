# WanИзображениеВВидео

Узел `WanImageToVideo` подготавливает представления кондиционирования и латентного пространства для задач генерации видео. Он создаёт пустое латентное пространство для генерации видео и при необходимости может включать стартовые изображения и выходы `CLIP Vision` для управления процессом генерации видео. Узел изменяет как положительные, так и отрицательные входы кондиционирования на основе предоставленных изображений и визуальных данных.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительный вход кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `negative` | Отрицательный вход кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `vae` | Модель VAE для кодирования изображений в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного видео (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `clip_vision_output` | Необязательный выход CLIP Vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `start_image` | Необязательное стартовое изображение для инициализации генерации видео. При наличии изображение масштабируется до указанных ширины и высоты, а первые кадры видео инициализируются из этого изображения. Остальные кадры заполняются нейтральными серыми значениями (0.5). Используются только первые `length` кадров изображения. | IMAGE | Нет | - |

**Примечание:** Когда указан `start_image`, узел кодирует последовательность изображений с помощью VAE и применяет маску к входам кондиционирования. Маска покрывает все кадры, кроме тех, что инициализированы стартовым изображением, что позволяет генерации опираться на предоставленное изображение. Параметр `clip_vision_output`, если он задан, добавляет кондиционирование на основе визуальных данных к положительным и отрицательным входам.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Модифицированное положительное кондиционирование с включёнными данными изображения и визуальными данными | CONDITIONING |
| `negative` | Модифицированное отрицательное кондиционирование с включёнными данными изображения и визуальными данными | CONDITIONING |
| `latent` | Пустой тензор латентного пространства, готовый к генерации видео, с формой `[batch_size, 16, ((length-1)//4)+1, height//8, width//8]` | LATENT |
