# WanИзображениеВВидео

Узел WanImageToVideo подготавливает представления кондиционирования и скрытые представления для задач генерации видео. Он создает пустое скрытое пространство для генерации видео и может дополнительно включать начальные изображения и выходы CLIP vision для управления процессом генерации. Узел изменяет как положительные, так и отрицательные входы кондиционирования на основе предоставленного изображения и визуальных данных.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Вход положительного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `отрицательный` | Вход отрицательного кондиционирования для управления генерацией | CONDITIONING | Да | - |
| `vae` | Модель VAE для кодирования изображений в скрытое пространство | VAE | Да | - |
| `ширина` | Ширина выходного видео (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в видео (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `clip_vision_output` | Необязательный выход CLIP vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное начальное изображение для инициализации генерации видео. При его наличии изображение масштабируется до указанных ширины и высоты, а первые кадры видео инициализируются этим изображением. Остальные кадры заполняются нейтральными серыми значениями (0.5). Кадры за пределами `length` игнорируются. | IMAGE | Нет | - |

**Примечание:** Когда указан `start_image`, узел кодирует последовательность изображений с помощью VAE и применяет маску к входам кондиционирования. Маска покрывает все кадры, кроме инициализированных начальным изображением, что позволяет генерации опираться на предоставленное изображение. При кодировании используются только первые три цветовых канала (RGB) изображения. Параметр `clip_vision_output` при его наличии добавляет кондиционирование на основе визуальных данных к положительным и отрицательным входам.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Модифицированное положительное кондиционирование с включенными данными изображения и визуальными данными | CONDITIONING |
| `отрицательный` | Модифицированное отрицательное кондиционирование с включенными данными изображения и визуальными данными | CONDITIONING |
| `latent` | Тензор пустого скрытого пространства, готовый для генерации видео, с формой [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
