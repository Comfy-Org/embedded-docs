# Luma UNI-1 圖像編輯

此節點由 Luma UNI-1 模型驅動，可透過文字提示編輯現有影像。它接受一張來源影像以及所需變更的描述，然後產生一張新的編輯後影像版本。您可以在 `uni-1` 與 `uni-1-max` 模型之間選擇、調整風格、啟用網路搜尋，並可選擇性地提供最多 8 張參考影像。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要用於編輯的模型。選取模型後，下方會顯示模型專屬選項。 | DYNAMIC_COMBO | 是 | `"uni-1"`<br>`"uni-1-max"` |
| `source` | 要編輯的來源影像。 | IMAGE | 是 | - |
| `prompt` | 描述所需的編輯內容。1–6000 字元。預設值：""（空字串；在輸入至少一個字元前，請求無效）。 | STRING | 是 | 1 至 6000 字元 |
| `seed` | 種子控制節點是否應重新執行；無論種子為何，結果皆非確定性。預設值：0。 | INT | 是 | 0 至 2147483647 |

### uni-1 與 uni-1-max 輸入

以下選項由 `uni-1` 與 `uni-1-max` 模型共用。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `style` | 風格預設。`"auto"` 會依提示自動挑選；`"manga"` 則套用漫畫／動畫美學，且需要直向長寬比（2:3、9:16、1:2、1:3）。預設值：`"auto"`。 | COMBO | 是 | `"auto"`<br>`"manga"` |
| `web_search` | 在生成前搜尋網路上的視覺參考。預設值：false。 | BOOLEAN | 是 | `true`<br>`false` |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `image_ref` | 可擴充插槽：可連接最多 8 張參考影像（`image_1` 至 `image_8`），作為風格／內容引導。選填。 | IMAGE | 否 | 0 至 8 張影像 |

**注意事項：**
- `prompt` 必須介於 1 至 6000 字元之間。
- `style`、`web_search` 與 `image_ref` 輸入會在 `model` 設為 `"uni-1"` 或 `"uni-1-max"` 時出現。
- 兩個模型都支援相同的模型專屬選項，包括最多 8 張參考影像。
- `"manga"` 風格需要直向長寬比（2:3、9:16、1:2 或 1:3）。
- 連接超過 8 張參考影像會引發錯誤。
