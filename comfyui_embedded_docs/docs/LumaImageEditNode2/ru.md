# Luma UNI-1 Image Edit

Этот узел редактирует существующее изображение по текстовому запросу, используя модель Luma UNI-1. Он принимает исходное изображение и описание желаемого изменения, а затем генерирует новую отредактированную версию изображения. Вы можете выбрать одну из моделей `uni-1` и `uni-1-max`, настроить стиль, включить веб-поиск и дополнительно указать до 8 референсных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для редактирования. Выбор модели отображает параметры, специфичные для выбранной модели, ниже. | MODEL | Да | `"uni-1"`<br>`"uni-1-max"` |
| `source` | Исходное изображение для редактирования. | IMAGE | Да | - |
| `prompt` | Описание желаемого изменения. От 1 до 6000 символов. По умолчанию: "" (пустая строка; запрос недействителен, пока не введён хотя бы один символ). | STRING | Да | от 1 до 6000 символов |
| `seed` | Seed управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Да | 0 до 2147483647 |

### Входы uni-1 и uni-1-max

Эти параметры общие для обеих моделей `uni-1` и `uni-1-max`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `style` | Пресет стиля. `"auto"` выбирает стиль на основе промпта; `"manga"` применяет эстетику манги/аниме и требует портретное соотношение сторон (2:3, 9:16, 1:2, 1:3). По умолчанию: `"auto"`. | STRING | Да | `"auto"`<br>`"manga"` |
| `web_search` | Выполнять поиск в интернете визуальных референсов перед генерацией. По умолчанию: false. | BOOLEAN | Да | `true`<br>`false` |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_ref` | Расширяемый слот: подключите до 8 референсных изображений (`image_1` – `image_8`) для управления стилем/содержимым. Необязательный. | IMAGE | Нет | от 0 до 8 изображений |

**Примечания:**
- Параметр `prompt` должен содержать от 1 до 6000 символов.
- Параметры `style`, `web_search` и `image_ref` появляются, когда для `model` задано значение `"uni-1"` или `"uni-1-max"`.
- Обе модели поддерживают одинаковые специфичные для модели параметры, включая до 8 референсных изображений.
- Стиль `"manga"` требует портретного соотношения сторон (2:3, 9:16, 1:2 или 1:3).
- Подключение более 8 референсных изображений вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение, сгенерированное моделью Luma UNI-1. | IMAGE |
