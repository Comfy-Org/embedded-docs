# Luma UNI-1 Image Edit

Этот узел редактирует существующее изображение по текстовому запросу, используя модель Luma UNI-1. Он принимает исходное изображение и описание желаемого изменения, а затем генерирует новую отредактированную версию изображения. Вы можете выбрать одну из моделей `uni-1` и `uni-1-max`, настроить стиль, включить веб-поиск и дополнительно указать до 8 референсных изображений.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель для редактирования. Выбор модели отображает параметры, специфичные для выбранной модели, ниже. | DYNAMIC_COMBO | Да | `"uni-1"`<br>`"uni-1-max"` |
| `source` | Исходное изображение для редактирования. | IMAGE | Да | - |
| `prompt` | Описание желаемого изменения. От 1 до 6000 символов. По умолчанию: "" (пустая строка; запрос недействителен, пока не введён хотя бы один символ). | STRING | Да | 1 to 6000 characters |
| `seed` | Seed управляет тем, должен ли узел запускаться повторно; результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Да | 0 to 2147483647 |

### Входы uni-1 и uni-1-max

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `style` | Пресет стиля. `"auto"` выбирает стиль на основе промпта; `"manga"` применяет эстетику манги/аниме и требует портретное соотношение сторон (2:3, 9:16, 1:2, 1:3). По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"manga"` |
| `web_search` | Выполнять поиск в интернете визуальных референсов перед генерацией. По умолчанию: false. | BOOLEAN | Да | `true`<br>`false` |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `image_ref` | Расширяемый слот: подключите до 8 референсных изображений (`image_1` – `image_8`) для управления стилем/содержимым. Необязательный. | IMAGE | Нет | 0 to 8 images |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `image` | The edited image generated by the Luma UNI-1 model, returned in PNG format. | IMAGE |
