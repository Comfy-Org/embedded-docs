# Luma UNI-1 图像编辑

此节点由 Luma UNI-1 模型驱动，使用文本提示编辑现有图像。它接收源图像和所需更改的描述，然后生成新的编辑版本图像。您可以在 `uni-1` 和 `uni-1-max` 模型之间进行选择，调整样式，启用网络搜索，并可选择提供最多 8 张参考图像。

## 输入

### 通用输入

| 参数 | 说明 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于编辑的模型。选择模型会显示下方模型专属选项。 | MODEL | 是 | `"uni-1"`<br>`"uni-1-max"` |
| `source` | 要编辑的源图像。 | IMAGE | 是 | - |
| `prompt` | 所需编辑的描述。1–6000 个字符。默认值：""（空字符串）。 | STRING | 是 | 1 到 6000 个字符 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。默认值：0。 | INT | 是 | 0 到 2147483647 |

### uni-1 和 uni-1-max 输入

这些选项由 `uni-1` 和 `uni-1-max` 两个模型共用。

| 参数 | 说明 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `style` | 样式预设。`"auto"` 根据提示自动选择；`"manga"` 应用漫画/动漫美学，需要竖屏宽高比（2:3、9:16、1:2、1:3）。默认值：`"auto"`。 | STRING | 是 | `"auto"`<br>`"manga"` |
| `web_search` | 生成前在网络上搜索视觉参考。默认值：false。 | BOOLEAN | 是 | `true`<br>`false` |

### 参考输入

| 参数 | 说明 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_ref` | 可增长插槽：连接最多 8 张参考图像（`image_1` 到 `image_8`）以提供风格/内容指导。可选。 | IMAGE | 否 | 1 到 8 张图像 |

**注意：**

- `prompt` 必须包含 1 到 6000 个字符。
- 当 `model` 设置为 `"uni-1"` 或 `"uni-1-max"` 时，会出现 `style`、`web_search` 和 `image_ref` 输入。
- 两个模型支持相同的模型专属选项，包括最多 8 张参考图像。
- `"manga"` 样式需要竖屏宽高比（2:3、9:16、1:2 或 1:3）。
- 连接超过 8 张参考图像将引发错误。

## 输出

| 输出名 | 说明 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 由 Luma UNI-1 模型生成的编辑后图像。 | IMAGE |
