# Luma UNI-1 이미지 편집

이 노드는 Luma UNI-1 모델을 기반으로 텍스트 프롬프트를 사용하여 기존 이미지를 편집합니다. 소스 이미지와 원하는 변경 사항에 대한 설명을 입력받아 새롭게 편집된 버전의 이미지를 생성합니다. `uni-1`과 `uni-1-max` 모델 중에서 선택하고, 스타일을 조정하고, 웹 검색을 활성화하고, 선택적으로 최대 8개의 참조 이미지를 제공할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 편집에 사용할 모델입니다. 모델을 선택하면 아래에 해당 모델별 옵션이 표시됩니다. | MODEL | 예 | `"uni-1"`<br>`"uni-1-max"` |
| `source` | 편집할 소스 이미지입니다. | IMAGE | 예 | - |
| `prompt` | 원하는 편집 내용에 대한 설명입니다. 1~6000자. 기본값: ""(빈 문자열. 최소 1자를 입력할 때까지 요청이 유효하지 않습니다). | STRING | 예 | 1~6000자 |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 0. | INT | 예 | 0~2147483647 |

### uni-1 및 uni-1-max 입력

이 옵션은 `uni-1` 및 `uni-1-max` 모델에서 공통으로 사용됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `style` | 스타일 프리셋입니다. `"auto"`는 프롬프트를 기반으로 선택하며, `"manga"`는 만화/애니메이션 미학을 적용하고 세로 비율(2:3, 9:16, 1:2, 1:3)이 필요합니다. 기본값: `"auto"`. | STRING | 예 | `"auto"`<br>`"manga"` |
| `web_search` | 생성 전에 웹에서 시각적 참조 자료를 검색합니다. 기본값: false. | BOOLEAN | 예 | `true`<br>`false` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_ref` | 확장 가능한 슬롯: 스타일/콘텐츠 안내를 위해 최대 8개의 참조 이미지(`image_1`~`image_8`)를 연결할 수 있습니다. 선택 사항입니다. | IMAGE | 아니요 | 0~8개 이미지 |

**참고 사항:**
- `prompt`는 1~6000자 사이여야 합니다.
- `style`, `web_search`, `image_ref` 입력은 `model`이 `"uni-1"` 또는 `"uni-1-max"`로 설정된 경우에 나타납니다.
- 두 모델 모두 최대 8개의 참조 이미지를 포함하여 동일한 모델별 옵션을 지원합니다.
- `"manga"` 스타일에는 세로 비율(2:3, 9:16, 1:2 또는 1:3)이 필요합니다.
- 8개를 초과하는 참조 이미지를 연결하면 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Luma UNI-1 모델이 생성한 편집된 이미지입니다. | IMAGE |
