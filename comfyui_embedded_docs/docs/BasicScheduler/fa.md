# BasicScheduler

گره `BasicScheduler` برای محاسبه دنباله‌ای از مقادیر sigma برای مدل‌های انتشار بر اساس زمان‌بند، مدل و پارامترهای نویززدایی ارائه‌شده طراحی شده است. این گره تعداد کل مراحل را به‌صورت پویا بر اساس عامل `denoise` تنظیم می‌کند تا فرایند انتشار را دقیق‌تر تنظیم کند و «دستورالعمل‌های» دقیقی برای مراحل مختلف در فرایندهای نمونه‌گیری پیشرفته که نیاز به کنترل دقیق دارند (مانند نمونه‌گیری چندمرحله‌ای) فراهم آورد.

## ورودی‌ها

| پارامتر | توضیح استعاری | نوع داده | نوع ورودی | پیش‌فرض | محدوده | هدف فنی |
| --- | --- | --- | --- | --- | --- | --- |
| `مدل` | **نوع بوم**: مواد بوم مختلف به فرمول‌های رنگ متفاوتی نیاز دارند | MODEL | ورودی | - | - | شیء مدل انتشار، مبنای محاسبه sigma را تعیین می‌کند |
| `زمان‌بندی` | **تکنیک ترکیب**: انتخاب کنید که غلظت رنگ چگونه تغییر کند | COMBO[STRING] | ویجت | - | 9 گزینه | الگوریتم زمان‌بندی، نحوه کاهش نویز را کنترل می‌کند |
| `گام‌ها` | **تعداد ترکیب**: تفاوت دقت بین ۲۰ ترکیب و ۵۰ ترکیب | INT | ویجت | 20 | 1-10000 | مراحل نمونه‌گیری، بر کیفیت و سرعت تولید تأثیر می‌گذارد |
| `کاهش نویز` | **شدت خلق**: سطح کنترل از تنظیم دقیق تا رنگ‌آمیزی مجدد | FLOAT | ویجت | 1.0 | 0.0-1.0 | قدرت نویززدایی، از سناریوهای رنگ‌آمیزی جزئی پشتیبانی می‌کند |

### انواع زمان‌بند

بر اساس کد منبع `comfy.samplers.SCHEDULER_NAMES`، از ۹ زمان‌بند زیر پشتیبانی می‌کند:

| نام زمان‌بند | ویژگی‌ها | موارد استفاده | الگوی کاهش نویز |
| --- | --- | --- | --- |
| **normal** | خطی استاندارد | سناریوهای عمومی، متعادل | کاهش یکنواخت |
| **karras** | انتقال نرم | کیفیت بالا، پرجزئیات | کاهش نرم و غیرخطی |
| **exponential** | کاهش نمایی | تولید سریع، کارایی | کاهش سریع نمایی |
| **sgm_uniform** | یکنواخت SGM | بهینه‌سازی مدل خاص | کاهش بهینه‌شده SGM |
| **simple** | زمان‌بندی ساده | تست سریع، استفاده پایه | کاهش ساده‌شده |
| **ddim_uniform** | یکنواخت DDIM | بهینه‌سازی نمونه‌گیری DDIM | کاهش مخصوص DDIM |
| **beta** | توزیع بتا | نیازهای توزیع ویژه | کاهش تابع بتا |
| **linear_quadratic** | خطی درجه دوم | بهینه‌سازی سناریوی پیچیده | کاهش تابع درجه دوم |
| **kl_optimal** | بهینه KL | بهینه‌سازی نظری | کاهش بهینه‌شده واگرایی KL |

## نقش گره: دستیار ترکیب رنگ هنرمند

تصور کنید هنرمندی هستید که می‌خواهید از یک ترکیب آشفته رنگ (نویز) تصویری واضح بسازید. `BasicScheduler` مانند **دستیار حرفه‌ای ترکیب رنگ** شما عمل می‌کند که وظیفه‌اش آماده‌سازی مجموعه‌ای از دستورالعمل‌های دقیق غلظت رنگ است:

### گردش کار

- **مرحله ۱**: استفاده از رنگ با غلظت ۹۰٪ (سطح نویز بالا)
- **مرحله ۲**: استفاده از رنگ با غلظت ۸۰٪
- **مرحله ۳**: استفاده از رنگ با غلظت ۷۰٪
- **...**
- **مرحله نهایی**: استفاده از غلظت ۰٪ (بوم تمیز، بدون نویز)

### مهارت‌های ویژه دستیار رنگ

**روش‌های مختلف ترکیب (`scheduler`)**:

- **روش ترکیب "karras"**: غلظت رنگ بسیار نرم تغییر می‌کند، مانند تکنیک گرادیان یک هنرمند حرفه‌ای
- **روش ترکیب "exponential"**: غلظت رنگ به‌سرعت کاهش می‌یابد، مناسب برای خلق سریع
- **روش ترکیب "linear"**: غلظت رنگ به‌صورت یکنواخت کاهش می‌یابد، پایدار و قابل‌کنترل

**کنترل دقیق (`steps`)**:

- **۲۰ ترکیب**: نقاشی سریع، اولویت با کارایی
- **۵۰ ترکیب**: نقاشی دقیق، اولویت با کیفیت

**شدت خلق (`denoise`)**:

- **1.0 = خلق کاملاً جدید**: شروع کاملاً از بوم سفید
- **0.5 = دگرگونی نیمی**: نگه‌داشتن نیمی از نقاشی اصلی، تغییر نیم دیگر
- **0.2 = تنظیم دقیق**: فقط تغییرات ظریف در نقاشی اصلی اعمال شود

### همکاری با سایر گره‌ها

`BasicScheduler` (دستیار رنگ) → آماده‌سازی دستور → `SamplerCustom` (هنرمند) → نقاشی واقعی → اثر تکمیل‌شده
