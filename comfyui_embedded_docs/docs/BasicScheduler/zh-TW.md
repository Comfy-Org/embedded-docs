# BasicScheduler

`BasicScheduler` 節點旨在根據提供的排程器、模型與去噪參數，為擴散模型計算一系列 sigma 值。它會根據 `denoise` 因子動態調整總步數，以微調擴散過程，為需要精細控制的高級取樣流程（例如多階段取樣）中的不同階段提供精確的「配方」。

## 節點角色：藝術家的調色助手

想像你是一位藝術家，正從混亂的顏料混合物（雜訊）中創作出清晰的圖像。`BasicScheduler` 就像你的**專業調色助手**，其工作是準備一系列精確的顏料濃度配方：

### 工作流程

- **步驟 1**：使用 90% 濃度的顏料（高雜訊程度）
- **步驟 2**：使用 80% 濃度的顏料  
- **步驟 3**：使用 70% 濃度的顏料
- **...**
- **最後步驟**：使用 0% 濃度（乾淨畫布，無雜訊）

### 調色助手的特殊技能

**不同的混合方法（`scheduler`）**：

- **「karras」混合法**：顏料濃度變化非常平滑，就像專業藝術家的漸層技法
- **「exponential」混合法**：顏料濃度快速下降，適合快速創作
- **「linear」混合法**：顏料濃度均勻下降，穩定且可控

**精細控制（`steps`）**：

- **20 次混合**：快速繪製，效率優先
- **50 次混合**：精細繪製，品質優先

**創作強度（`denoise`）**：

- **1.0 = 完全重新創作**：完全從空白畫布開始
- **0.5 = 一半轉換**：保留一半原畫，轉換一半
- **0.2 = 微調**：僅對原畫進行細微調整
