# Основной scheduler

Узел `BasicScheduler` предназначен для вычисления последовательности значений sigma для диффузионных моделей на основе заданных планировщика, модели и параметров удаления шума. Он динамически корректирует общее количество шагов в зависимости от коэффициента denoise для точной настройки процесса диффузии, предоставляя точные «рецепты» для разных этапов в продвинутых процессах сэмплирования, требующих тонкого контроля (например, многоэтапного сэмплирования).

## Входы

| Параметр | Метафорическое описание | Тип данных | Тип входа | По умолчанию | Диапазон | Техническое назначение |
| --- | --- | --- | --- | --- | --- | --- |
| `модель` | **Тип холста**: разным материалам холста нужны разные рецепты краски | MODEL | Вход | - | - | Объект диффузионной модели, определяет основу расчёта sigma |
| `scheduler` | **Техника смешивания**: выберите, как меняется концентрация краски | COMBO[STRING] | Виджет | - | 9 вариантов | Алгоритм планирования, управляет режимом затухания шума |
| `шаги` | **Количество смешиваний**: разница в точности между 20 и 50 смешиваниями | INT | Виджет | 20 | 1-10000 | Шаги сэмплирования, влияют на качество и скорость генерации |
| `шумоподавление` | **Интенсивность создания**: уровень управления от тонкой настройки до полной перерисовки | FLOAT | Виджет | 1.0 | 0.0-1.0 | Сила удаления шума, поддерживает сценарии частичной перерисовки |

### Типы планировщиков

На основе исходного кода `comfy.samplers.SCHEDULER_NAMES` поддерживаются следующие 9 планировщиков:

| Имя планировщика     | Характеристики       | Сценарии использования          | Характер затухания шума          |
| -------------------- | -------------------- | ------------------------------- | -------------------------------- |
| **normal**           | Стандартный линейный | Общие сценарии, сбалансированный | Равномерное затухание            |
| **karras**           | Плавный переход      | Высокое качество, насыщенность деталями | Плавное нелинейное затухание     |
| **exponential**      | Экспоненциальное затухание | Быстрая генерация, эффективность | Экспоненциально быстрое затухание |
| **sgm_uniform**      | Равномерный SGM      | Оптимизация под конкретную модель | Оптимизированное для SGM затухание |
| **simple**           | Простое планирование | Быстрое тестирование, базовое использование | Упрощённое затухание             |
| **ddim_uniform**     | Равномерный DDIM     | Оптимизация сэмплирования DDIM  | Специфичное для DDIM затухание   |
| **beta**             | Бета-распределение   | Особые потребности в распределении | Затухание по бета-функции        |
| **linear_quadratic** | Линейно-квадратичный | Оптимизация сложных сценариев   | Затухание по квадратичной функции |
| **kl_optimal**       | Оптимальный KL       | Теоретическая оптимизация       | Затухание, оптимизированное по дивергенции KL |

## Выходы

| Параметр | Метафорическое описание | Тип данных | Тип выхода | Техническое значение |
| --- | --- | --- | --- | --- |
| `sigmas` | **Схема рецепта краски**: подробный список концентраций краски для пошагового использования | SIGMAS | Выход | Последовательность уровней шума, направляет процесс удаления шума диффузионной модели |

## Роль узла: помощник художника по смешиванию красок

Представьте, что вы художник, создающий чёткое изображение из хаотичной смеси краски (шума). `BasicScheduler` действует как ваш **профессиональный помощник по смешиванию красок**, чья задача — подготовить серию точных рецептов концентрации краски:

### Рабочий процесс

- **Шаг 1**: Использовать краску концентрации 90% (высокий уровень шума)
- **Шаг 2**: Использовать краску концентрации 80%  
- **Шаг 3**: Использовать краску концентрации 70%
- **...**
- **Последний шаг**: Использовать 0% концентрации (чистый холст, без шума)

### Особые навыки помощника по смешиванию красок

**Разные методы смешивания (scheduler)**:

- **Метод смешивания "karras"**: Концентрация краски меняется очень плавно, как градиентная техника профессионального художника
- **Метод смешивания "exponential"**: Концентрация краски быстро снижается, подходит для быстрого создания
- **Метод смешивания "linear"**: Концентрация краски снижается равномерно, стабильно и контролируемо

**Точный контроль (steps)**:

- **20 смешиваний**: Быстрое рисование, приоритет эффективности
- **50 смешиваний**: Тонкое рисование, приоритет качества

**Интенсивность создания (denoise)**:

- **1.0 = Полное новое создание**: Начать полностью с чистого холста
- **0.5 = Половинное преобразование**: Сохранить половину исходной картины, преобразовать половину
- **0.2 = Тонкая настройка**: Внести лишь незначительные корректировки в исходную картину

### Взаимодействие с другими узлами

`BasicScheduler` (Помощник по смешиванию красок) → Подготовка рецепта → `SamplerCustom` (Художник) → Фактическое рисование → Завершённая работа
