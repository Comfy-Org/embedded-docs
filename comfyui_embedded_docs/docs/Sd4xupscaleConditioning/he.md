# Sd4xupscaleConditioning

צומת זה מתמחה בשיפור הרזולוציה של תמונות באמצעות תהליך הגדלה פי 4 (4x upscale), תוך שילוב רכיבי התניה (conditioning) כדי לחדד את הפלט. הוא משתמש בטכניקות דיפוזיה כדי להגדיל תמונות, תוך מתן אפשרות לכוונן את יחס ההגדלה ואת הגברת הרעש כדי לדייק את תהליך השיפור.

## קלטים

| פרמטר | תיאור | סוג נתונים ב-Comfy |
| --- | --- | --- |
| `images` | תמונות הקלט שיש להגדיל. פרמטר זה קריטי מכיוון שהוא משפיע ישירות על האיכות והרזולוציה של תמונות הפלט. | `IMAGE` |
| `positive` | רכיבי התניה חיוביים שמכוונים את תהליך ההגדלה نحو מאפיינים או תכונות רצויים בתמונות הפלט. | `CONDITIONING` |
| `negative` | רכיבי התניה שליליים שתהליך ההגדלה צריך להימנע מהם, ובכך לעזור להסיט את הפלט ממאפיינים או תכונות לא רצויים. | `CONDITIONING` |
| `scale_ratio` | קובע את הגורם שבו רזולוציית התמונה מוגדלת. יחס הגדלה גבוה יותר מפיק תמונת פלט גדולה יותר, ומאפשר יותר פרטים וחדות. | `FLOAT` |
| `noise_augmentation` | שולט ברמת הגברת הרעש המיושמת במהלך תהליך ההגדלה. ניתן להשתמש בכך כדי להכניס שונות ולשפר את העמידות של תמונות הפלט. | `FLOAT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | רכיבי ההתניה החיוביים המעודנים שנוצרו כתוצאה מתהליך ההגדלה. | `CONDITIONING` |
| `negative` | רכיבי ההתניה השליליים המעודנים שנוצרו כתוצאה מתהליך ההגדלה. | `CONDITIONING` |
| `latent` | ייצוג לטנטי שנוצר במהלך תהליך ההגדלה, אשר יכול לשמש לעיבוד נוסף או לאימון מודל. | `LATENT` |
