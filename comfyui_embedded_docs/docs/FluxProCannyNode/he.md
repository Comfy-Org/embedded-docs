# FluxProCannyNode

צור תמונה באמצעות תמונת בקרה (canny). צומת זה מקבל תמונת בקרה ומייצר תמונה חדשה בהתבסס על ההנחיה שסופקה, תוך עמידה במבנה הקצוות שזוהה בתמונת הבקרה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `control_image` | תמונת הקלט המשמשת לשליטה בזיהוי קצוות canny | IMAGE | כן | - |
| `prompt` | הנחיה ליצירת התמונה (ברירת מחדל: מחרוזת ריקה) | STRING | לא | - |
| `prompt_upsampling` | האם לבצע upsampling להנחיה. אם פעיל, משנה אוטומטית את ההנחיה ליצירה יצירתית יותר, אך התוצאות אינן דטרמיניסטיות (אותו seed לא יפיק בדיוק את אותה התוצאה). (ברירת מחדל: False) | BOOLEAN | לא | - |
| `canny_low_threshold` | סף נמוך לזיהוי קצוות Canny; מתעלמים ממנו אם `skip_preprocessing` הוא True (ברירת מחדל: 0.1) | FLOAT | לא | 0.01 - 0.99 |
| `canny_high_threshold` | סף גבוה לזיהוי קצוות Canny; מתעלמים ממנו אם `skip_preprocessing` הוא True (ברירת מחדל: 0.4) | FLOAT | לא | 0.01 - 0.99 |
| `skip_preprocessing` | האם לדלג על עיבוד מקדים; יש להגדיר ל-True אם `control_image` כבר עברה המרה ל-canny, או False אם מדובר בתמונה גולמית. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `guidance` | עוצמת הנחיה לתהליך יצירת התמונה (ברירת מחדל: 30) | FLOAT | לא | 1 - 100 |
| `steps` | מספר הצעדים בתהליך יצירת התמונה (ברירת מחדל: 50) | INT | לא | 15 - 50 |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש. (ברירת מחדל: 0) | INT | לא | 0 - 18446744073709551615 |

**הערה:** כאשר `skip_preprocessing` מוגדר ל-True, הפרמטרים `canny_low_threshold` ו-`canny_high_threshold` מתעלמים מהם, מכיוון שההנחה היא שתמונת הבקרה כבר עובדה כתמונת קצוות canny. לאחר מכן משתמשים ב-`control_image` ישירות כתמונה המעובדת מראש.
