# MeshToFile3D

此節點會將網格序列化為 GLB 檔案物件，可傳遞給「儲存 3D」或「預覽 3D」節點。它會攜帶所有網格資料，包括 UV、顏色、法線、紋理、法線貼圖／遮蔽貼圖／自發光貼圖，以及材質設定。若批次中包含多個項目，僅會使用第一個項目。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要轉換為 GLB 檔案的網格，包括 UV、顏色、法線、紋理、法線貼圖／遮蔽貼圖／自發光貼圖，以及材質。每個批次僅支援一個項目；若批次包含多個項目，則使用第一個項目。 | MESH | 是 | 單一網格 |

注意：此節點每個批次僅支援一個項目。若輸入網格的批次包含多個項目，系統會記錄警告，並使用第一個項目。網格必須至少包含一個頂點和一個面；空的網格會引發錯誤。
