# 建立 3D 檔案（從網格）

此節點會將網格序列化為 GLB 檔案物件，該物件可傳遞至 Save 3D 或 Preview 3D 節點。它會攜帶所有網格資料，包括 UV、顏色、法線、紋理、法線/環境遮蔽/自發光貼圖，以及材質設定。對於包含多個項目的批次，只會使用第一個項目。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要轉換為 GLB 檔案的網格，包括 UV、顏色、法線、紋理、法線/環境遮蔽/自發光貼圖，以及材質。每個批次僅支援一個項目；如果批次包含多個項目，則使用第一個項目。 | MESH | 是 | Single mesh |

注意：此節點每個批次僅支援一個項目。如果輸入網格在其批次中包含多個項目，系統會記錄警告並使用第一個項目。網格必須至少包含一個頂點和一個面；空網格會引發錯誤。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `model_3d` | 一個 GLB（glTF Binary）檔案物件，包含序列化後的網格，可供其他 3D 節點儲存或預覽。 | FILE3D |
