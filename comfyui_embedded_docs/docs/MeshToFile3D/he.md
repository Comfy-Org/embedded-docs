# MeshToFile3D

צומת זה מבצע סריאליזציה של mesh לאובייקט קובץ GLB שניתן להעביר לצמתי Save 3D או Preview 3D. הוא נושא עמו את כל נתוני ה-mesh, כולל UVs, צבעים, נורמלים, טקסטורה, מפות normal/occlusion/emissive, והגדרות חומר. רק הפריט הראשון מתוך batch מרובה-פריטים משמש.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `mesh` | ה-mesh להמרה לקובץ GLB, כולל UVs, צבעים, נורמלים, טקסטורה, מפות normal/occlusion/emissive, וחומר. נתמך רק פריט אחד לכל batch; אם batch מכיל מספר פריטים, הפריט הראשון משמש. | MESH | כן | mesh בודד |

הערה: הצומת תומך בפריט אחד לכל batch בלבד. אם mesh הקלט מכיל יותר מפריט אחד ב-batch שלו, נרשמת אזהרה והפריט הראשון משמש. ה-mesh חייב להכיל לפחות קודקוד אחד ופאה אחת; mesh ריק יגרום לשגיאה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_3d` | אובייקט קובץ GLB (glTF בינארי) המכיל את ה-mesh המסריאלי, מוכן לשמירה או לתצוגה מקדימה על ידי צמתי 3D אחרים. | FILE3D |
