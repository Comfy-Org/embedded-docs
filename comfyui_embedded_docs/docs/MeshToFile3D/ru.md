# Создать 3D-файл (из сетки)

Этот узел сериализует сетку в объект файла GLB, который можно передать узлам Save 3D или Preview 3D. Он переносит все данные сетки, включая UV-развертки, цвета, нормали, текстуру, карты нормалей/окклюзии/эмиссии и настройки материала. Используется только первый элемент пакета, содержащего несколько элементов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Сетка для преобразования в файл GLB, включая UV-развертки, цвета, нормали, текстуру, карты нормалей/окклюзии/эмиссии и материал. Поддерживается только один элемент на пакет; если пакет содержит несколько элементов, используется первый. | MESH | Да | Одна сетка |

Примечание: Узел поддерживает только один элемент на пакет. Если входная сетка содержит более одного элемента в пакете, записывается предупреждение и используется первый элемент. Сетка должна содержать как минимум одну вершину и одну грань; пустая сетка вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Объект файла GLB (glTF Binary), содержащий сериализованную сетку, готовый для сохранения или предварительного просмотра другими 3D-узлами. | FILE3D |
