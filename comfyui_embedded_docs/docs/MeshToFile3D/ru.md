# MeshToFile3D

Этот узел сериализует сетку в файловый объект GLB, который можно передать в узлы Save 3D или Preview 3D. Он переносит все данные сетки, включая UV-карты, цвета, нормали, текстуры, карты нормалей/окклюзии/эмиссии и настройки материалов. Используется только первый элемент мультиэлементного пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `сетка` | Сетка для преобразования в файл GLB, включая UV-карты, цвета, нормали, текстуры, карты нормалей/окклюзии/эмиссии и материалы. Поддерживается только один элемент на пакет; если пакет содержит несколько элементов, используется первый. | MESH | Да | Одиночная сетка |

Примечание: Узел поддерживает только один элемент на пакет. Если входная сетка содержит более одного элемента в своем пакете, регистрируется предупреждение и используется первый элемент. Сетка должна содержать как минимум одну вершину и одну грань; пустая сетка вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `3D-модель` | Объект файла GLB (glTF Binary), содержащий сериализованную сетку, готовый к сохранению или предпросмотру другими 3D-узлами. | FILE3D |
