# Flux 3 Image

Flux 3 Image генерирует изображение с помощью FLUX 3 по промпту либо редактирует и объединяет эталонные изображения. Напишите желаемое в виде инструкции, затем подключите до 10 эталонных изображений и ссылайтесь на них в промпте как image 1, image 2 и так далее. Промпт интерпретируется и расширяется перед генерацией, а результат рендерится в выбранных вами соотношении сторон и разрешении.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Что сгенерировать или какое редактирование выполнить. Промпт интерпретируется и расширяется перед генерацией. Ссылайтесь на подключённые эталонные изображения как image 1, image 2 и так далее. (по умолчанию: "") | STRING | Да | от 1 до 15000 символов |
| `изображения` | Расширяемый слот для эталонных изображений; всего можно подключить до 10. Каждое изображение должно быть не меньше 256x256 пикселей, а его соотношение сторон не может быть более экстремальным, чем 64:1. | IMAGE | Нет | от 0 до 10 изображений |
| `bounding_boxes` | Необязательные ограничивающие рамки из узла Create Bounding Boxes, которые размещают объекты или текст в выходных данных. Позиции задаются относительно холста, поэтому передайте узлу соотношение сторон выходного изображения. | ARRAY | Нет | - |
| `aspect_ratio` | Соотношение сторон генерируемого изображения. "auto" использует первое эталонное изображение или выбирает соотношение из промпта. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"21:9"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"7:5"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"5:7"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"9:21"` |
| `разрешение` | Размер выходного изображения при выбранном соотношении сторон: 0.75K — около 0,6 мегапикселя, 1K — 1 МП, 1.5K — 2,4 МП, 2K — 4,2 МП, 4K — 16,8 МП. (по умолчанию: "2K") | COMBO | Да | `"0.75K"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"`<br>`"4K"` |
| `привязка` | Позволяет модели исследовать промпт с помощью веб-поиска и поиска изображений перед генерацией. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `safety_tolerance` | Допуск модерации; 0 — самый строгий. (по умолчанию: 4) | INT | Да | от 0 до 4 |
| `сид` | Сид для определения, должен ли узел перезапуститься; FLUX 3 выбирает собственный сид, поэтому фактические результаты недетерминированы независимо от этого значения. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |

`safety_tolerance` — это расширенный вход, а `seed` включает элементы управления Control After Generate в интерфейсе.

Эталонные изображения загружаются до отправки запроса. Один слот может содержать пакет, и каждый кадр каждого пакета учитывается в лимите 10 изображений.

Строки `bounding_boxes` добавляются к промпту, поэтому промпт и описания рамок вместе должны содержать не более 15000 символов.

Отображаемая цена зависит от `resolution`: $0.05863 при 0.75K, $0.06864 при 1K, $0.1001 при 1.5K, $0.143 при 2K и $0.86801 при 4K.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение, загруженное из результата FLUX 3. | IMAGE |
