# Flux 3 Image

Flux 3 Image 會根據提示詞使用 FLUX 3 生成影像，或編輯並組合參考影像。將您想要的內容寫成指示，然後連接最多 10 張參考影像，並在提示詞中以 image 1、image 2 等方式指稱它們。提示詞會在生成前被解讀與擴充，結果會以您選擇的長寬比與解析度渲染。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成什麼，或要進行的編輯。提示詞會在生成前被解讀與擴充。將已連接的參考影像稱為 image 1、image 2，依此類推。（預設：""） | STRING | 是 | 1 到 15000 個字元 |
| `images` | 參考影像的可擴充插槽；總共最多可連接 10 張。每張影像至少須為 256x256 像素，且其長寬比不得比 64:1 更極端。 | IMAGE | 否 | 0 到 10 張影像 |
| `bounding_boxes` | 來自 Create Bounding Boxes 節點的可選邊界框，用於在輸出中放置物件或文字。位置相對於畫布，因此請為此節點提供輸出的長寬比。 | ARRAY | 否 | - |
| `aspect_ratio` | 生成影像的長寬比。"auto" 會沿用第一張參考影像，或從提示詞中選擇一個比例。（預設："auto"） | COMBO | 是 | `"auto"`<br>`"21:9"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"7:5"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"5:7"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"9:21"` |
| `resolution` | 所選長寬比下的輸出尺寸：0.75K 約為 0.6 百萬像素，1K 為 1 MP，1.5K 為 2.4 MP，2K 為 4.2 MP，4K 為 16.8 MP。（預設："2K"） | COMBO | 是 | `"0.75K"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"`<br>`"4K"` |
| `grounding` | 讓模型在生成前使用網頁與影像搜尋來研究提示詞。（預設：True） | BOOLEAN | 是 | True<br>False |
| `safety_tolerance` | 內容審核容忍度，0 最嚴格。（預設：4） | INT | 是 | 0 到 4 |
| `seed` | 用來決定節點是否應重新執行的種子；FLUX 3 會自行選擇種子，因此無論此值為何，實際結果都是不確定的。（預設：42） | INT | 是 | 0 到 4294967295 |

`safety_tolerance` 是進階輸入，且 `seed` 在 UI 中包含 Control After Generate 控制項。

參考影像會在請求送出前上傳。單一插槽可承載一個批次，而每個批次的每個影格都會計入 10 張影像的上限。

`bounding_boxes` 的資料列會附加到提示詞，因此提示詞與邊界框描述合計必須為 15000 個字元或更少。

顯示的價格取決於 `resolution`：0.75K 為 $0.05863，1K 為 $0.06864，1.5K 為 $0.1001，2K 為 $0.143，4K 為 $0.86801。
