# Flux3ImageNode

Flux 3 Image יוצר תמונה עם FLUX 3 מתוך פרומפט, או עורך ומשלב תמונות עזר. כתבו את מה שאתם רוצים כהוראה, ואז חברו עד 10 תמונות עזר והתייחסו אליהן בפרומפט בתור image 1, image 2 וכן הלאה. הפרומפט מפוענח ומורחב לפני היצירה, והתוצאה מרונדרת ביחס הרוחב-גובה וברזולוציה שבחרתם.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | מה ליצור, או העריכה שיש לבצע. הפרומפט מפוענח ומורחב לפני היצירה. התייחסו לתמונות העזר המחוברות בתור image 1, image 2 וכן הלאה. (ברירת מחדל: "") | STRING | כן | 1 עד 15000 תווים |
| `images` | משבצת ניתנת להרחבה עבור תמונות עזר; חברו עד 10 בסך הכול. כל תמונה חייבת להיות בגודל של לפחות 256x256 פיקסלים, ויחס הרוחב-גובה שלה לא יכול להיות קיצוני מ-64:1. | IMAGE | לא | 0 עד 10 תמונות |
| `bounding_boxes` | תיבות אופציונליות מצומת Create Bounding Boxes שממקמות אובייקטים או טקסט בפלט. המיקומים יחסיים לקנבס, לכן יש לתת לצומת את יחס הרוחב-גובה של הפלט. | ARRAY | לא | - |
| `aspect_ratio` | יחס הרוחב-גובה של התמונה הנוצרת. "auto" עוקב אחרי תמונת העזר הראשונה, או בוחר יחס מתוך הפרומפט. (ברירת מחדל: "auto") | COMBO | כן | `"auto"`<br>`"21:9"`<br>`"2:1"`<br>`"16:9"`<br>`"3:2"`<br>`"7:5"`<br>`"4:3"`<br>`"5:4"`<br>`"1:1"`<br>`"4:5"`<br>`"3:4"`<br>`"5:7"`<br>`"2:3"`<br>`"9:16"`<br>`"1:2"`<br>`"9:21"` |
| `resolution` | גודל הפלט ביחס הרוחב-גובה שנבחר: 0.75K הוא בערך 0.6 מגה-פיקסל, 1K ‏1 MP, 1.5K ‏2.4 MP, 2K ‏4.2 MP, 4K ‏16.8 MP. (ברירת מחדל: "2K") | COMBO | כן | `"0.75K"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"`<br>`"4K"` |
| `grounding` | לאפשר למודל לחקור את הפרומפט באמצעות חיפוש באינטרנט ובתמונות לפני היצירה. (ברירת מחדל: True) | BOOLEAN | כן | True<br>False |
| `safety_tolerance` | סבילות למודרציה, 0 הוא המחמיר ביותר. (ברירת מחדל: 4) | INT | כן | 0 עד 4 |
| `seed` | Seed לקביעה אם הצומת צריך לרוץ מחדש; FLUX 3 בוחר seed משלו, כך שהתוצאות בפועל אינן דטרמיניסטיות ללא תלות בערך הזה. (ברירת מחדל: 42) | INT | כן | 0 עד 4294967295 |

`safety_tolerance` הוא קלט מתקדם, ו-`seed` כולל בקרות Control After Generate בממשק המשתמש.

תמונות עזר מועלות לפני שהבקשה נשלחת. משבצת בודדת יכולה לשאת אצווה, וכל פריים בכל אצווה נספר במסגרת המגבלה של 10 תמונות.

שורות `bounding_boxes` מתווספות לפרומפט, לכן הפרומפט ותיאורי התיבות יחד חייבים להיות 15000 תווים או פחות.

המחיר המוצג תלוי ב-`resolution`: ‏$0.05863 ב-0.75K, ‏$0.06864 ב-1K, ‏$0.1001 ב-1.5K, ‏$0.143 ב-2K ו-$0.86801 ב-4K.
