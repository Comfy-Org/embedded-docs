# MoGe инференс панорамы

Этот узел выполняет оценку глубины для панорамных изображений в равнопромежуточной проекции. Он разделяет панораму на 12 перспективных видов, запускает модель оценки глубины MoGe для каждого вида и объединяет результаты по отдельным видам обратно в единую карту глубины, покрывающую всю панораму. Предсказанные нормали и метрический масштаб для каждого вида игнорируются, поскольку масштабы отдельных видов не согласовывались бы на швах перекрытия.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | Модель MoGe, используемая для инференса. | MOGE_MODEL | Да |  |
| `image` | Панорама в равнопромежуточной проекции (любое соотношение сторон). Узел принимает только одно изображение; передача пакета изображений вызывает ошибку. Используются только первые 3 цветовых канала (RGB). | IMAGE | Да |  |
| `resolution_level` | Детализация для каждого вида (0 = самый быстрый, 9 = наиболее детальный) (по умолчанию: 9). | INT | Да | 0–9 |
| `split_resolution` | Разрешение каждого перспективного разбиения (по умолчанию: 512). | INT | Да | 256–1024 |
| `merge_resolution` | Разрешение по длинной стороне объединённой карты расстояний в равнопромежуточной проекции (по умолчанию: 1920). | INT | Да | 256–8192 |
| `batch_size` | Количество видов на один батч инференса (всего 12 разбиений) (по умолчанию: 4). | INT | Да | 1–12 |
| `refine_steps` | Только для MoGe-3: разреженные объёмные проходы уточнения по предсказанной глубине. Большее число проходов повышает резкость мелких деталей и границ при примерно линейном росте затрат. 0 отключает уточнение. Игнорируется в MoGe-1 / MoGe-2 (по умолчанию: 3). | INT | Да | 0–8 |

**Примечания:**

- Входные данные должны быть одним изображением. Если `image` содержит более одного изображения в пакете, узел вызывает ошибку.
- `merge_resolution` рассматривается как максимальный размер длинной стороны. Если панорама меньше этого значения, объединённая карта создаётся в исходном размере панорамы, а не увеличивается. Перед возвратом объединённый результат изменяется обратно до исходного разрешения панорамы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `moge_geometry` | Словарь, содержащий оценённую геометрию: `points` (3D-облако точек), `depth` (карта глубины), `mask` (маска допустимой области) и `image` (входное изображение). | MOGE_GEOMETRY |
