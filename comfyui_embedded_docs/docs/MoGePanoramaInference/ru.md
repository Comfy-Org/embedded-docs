# MoGe инференс панорамы

Этот узел выполняет оценку глубины на изображениях эквиректангулярной панорамы. Он разделяет панораму на 12 перспективных видов, запускает модель оценки глубины MoGe для каждого вида и объединяет результаты по каждому виду обратно в единую карту глубины, покрывающую всю панораму. Предсказанные для каждого вида нормали и метрический масштаб игнорируются, поскольку масштабы отдельных видов не согласовывались бы на перекрывающихся швах.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | Модель MoGe, используемая для инференса. | MOGE_MODEL | Да |  |
| `image` | Эквиректангулярная панорама (любое соотношение сторон). Узел принимает только одно изображение; передача пакета изображений вызывает ошибку. Используются только первые 3 цветовых канала (RGB). | IMAGE | Да |  |
| `resolution_level` | Детализация для каждого вида (0 = самый быстрый, 9 = максимально детализированный) (по умолчанию: 9). | INT | Да | от 0 до 9 |
| `split_resolution` | Разрешение каждого перспективного разбиения (по умолчанию: 512). | INT | Да | от 256 до 1024 |
| `merge_resolution` | Разрешение по длинной стороне объединённой эквиректангулярной карты расстояний (по умолчанию: 1920). | INT | Да | от 256 до 8192 |
| `batch_size` | Видов на один пакет инференса (всего 12 разбиений) (по умолчанию: 4). | INT | Да | от 1 до 12 |

**Примечания:**

- Входные данные должны быть одним изображением. Если `image` содержит более одного изображения в пакете, узел вызывает ошибку.
- `merge_resolution` рассматривается как максимальный размер длинной стороны. Если панорама меньше этого значения, объединённая карта создаётся в исходном размере панорамы, а не масштабируется вверх. Перед возвратом объединённый результат масштабируется обратно до исходного разрешения панорамы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `moge_geometry` | Словарь, содержащий оценённую геометрию: `points` (трёхмерное облако точек), `depth` (карта глубины), `mask` (маска допустимой области) и `image` (входное изображение). | MOGE_GEOMETRY |
