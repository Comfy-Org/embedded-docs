# MoGe инференс панорамы

## Обзор

Этот узел выполняет оценку глубины на эквидистантных панорамных изображениях. Он разбивает панораму на 12 перспективных видов, запускает модель оценки глубины MoGe на каждом виде и объединяет результаты обратно в единую карту глубины, покрывающую всю панораму.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | Модель MoGe для инференса. | MOGE_MODEL | Да |  |
| `image` | Эквидистантная панорама (с любым соотношением сторон). Узел принимает только одно изображение; передача пакета изображений вызывает ошибку. Используются только первые 3 цветовых канала (RGB). | IMAGE | Да |  |
| `resolution_level` | Детализация для каждого вида (0 = быстрее, 9 = максимальная детализация) (по умолчанию: 9). | INT | Да | 0 до 9 |
| `split_resolution` | Разрешение каждого перспективного разбиения (по умолчанию: 512). | INT | Да | 256 до 1024 |
| `merge_resolution` | Разрешение по длинной стороне объединённой эквидистантной карты расстояний (по умолчанию: 1920). | INT | Да | 256 до 8192 |
| `batch_size` | Количество видов на инференсный батч (всего 12 разбиений) (по умолчанию: 4). | INT | Да | 1 до 12 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `moge_geometry` | Словарь, содержащий оценённую геометрию: `points` (трёхмерное облако точек), `depth` (карта глубины), `mask` (маска допустимой области) и `image` (входное изображение). | MOGE_GEOMETRY |
