# MoGe инференс панорамы

Этот узел выполняет оценку глубины для панорамных изображений в равнопромежуточной проекции. Он разбивает панораму на 12 перспективных видов, запускает модель оценки глубины MoGe на каждом виде, а затем объединяет результаты в единую полную карту глубины исходной панорамы.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_model` | Модель MoGe, используемая для инференса. | MOGE_MODEL | Да |  |
| `image` | Панорама в равнопромежуточной проекции (с любым соотношением сторон). Принимает только одно изображение. | IMAGE | Да |  |
| `resolution_level` | Детализация для каждого вида (0 — максимальная скорость, 9 — максимальная детализация). По умолчанию: 9. | INT | Да | 0 to 9 |
| `split_resolution` | Разрешение каждого перспективного сегмента. По умолчанию: 512. | INT | Да | 256 to 1024 |
| `merge_resolution` | Разрешение по длинной стороне объединённой карты глубины в равнопромежуточной проекции. По умолчанию: 1920. | INT | Да | 256 to 8192 |
| `batch_size` | Количество видов на один пакет инференса (всего 12 сегментов). По умолчанию: 4. | INT | Да | 1 to 12 |

Примечание: этот узел принимает только одно изображение. Передача пакета изображений вызывает ошибку. Панорама всегда разбивается на 12 перспективных видов; `batch_size` управляет только количеством этих видов, обрабатываемых за один пакет инференса.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `moge_geometry` | Словарь, содержащий оценённую геометрию: `points` (трёхмерное облако точек), `depth` (карта глубины), `mask` (маска достоверной области) и `image` (входное изображение). | MOGE_GEOMETRY |
