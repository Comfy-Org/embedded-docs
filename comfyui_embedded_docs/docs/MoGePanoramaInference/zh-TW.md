# MoGe 全景推論

此節點會對等距長方投影全景影像執行深度估計。它會將全景圖分割成 12 個透視視圖，在每個視圖上執行 MoGe 深度估計模型，並將各視圖的結果合併回單一深度圖，涵蓋完整全景。每個視圖預測的法線與公制尺度會被忽略，因為各視圖的尺度無法在重疊接縫處對齊。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | 用於推論的 MoGe 模型。 | MOGE_MODEL | 是 |  |
| `image` | 等距長方投影全景圖（任何長寬比）。此節點僅接受單一影像；傳入一批影像會引發錯誤。僅使用前 3 個顏色通道（RGB）。 | IMAGE | 是 |  |
| `resolution_level` | 每個視圖的細節程度（0 = 最快，9 = 最精細）（預設：9）。 | INT | 是 | 0 至 9 |
| `split_resolution` | 每個透視分割的解析度（預設：512）。 | INT | 是 | 256 至 1024 |
| `merge_resolution` | 合併後等距長方投影距離圖的長邊解析度（預設：1920）。 | INT | 是 | 256 至 8192 |
| `batch_size` | 每個推論批次的視圖數量（總共 12 個分割）（預設：4）。 | INT | 是 | 1 至 12 |
| `refine_steps` | 僅限 MoGe-3：對預測深度執行稀疏體積細化遍數。更多遍數會銳化精細細節與邊緣，成本大致呈線性增加。0 會停用細化。MoGe-1 / MoGe-2 會忽略此參數（預設：3）。 | INT | 是 | 0 至 8 |

**注意：**

- 輸入必須是單一影像。如果 `image` 的批次中包含多張影像，此節點會引發錯誤。
- `merge_resolution` 會被視為最大長邊尺寸。如果全景圖小於此值，合併後的圖會以原始全景尺寸產生，而不會進行放大。合併結果在回傳前會調整回原始全景解析度。
