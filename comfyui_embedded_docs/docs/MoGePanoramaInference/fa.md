# استنتاج پانورامای MoGe

این گره تخمین عمق را روی تصاویر پانورامای استوانه‌ای (equirectangular) انجام می‌دهد. عملکرد آن به این صورت است که پانوراما را به ۱۲ نمای پرسپکتیو تقسیم می‌کند، مدل تخمین عمق MoGe را روی هر نما اجرا می‌کند و سپس نتایج را در یک نقشه عمق کامل و یکپارچه برای پانورامای اصلی ادغام می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `moge_model` | مدل MoGe مورد استفاده برای استنتاج. | MOGE_MODEL | بله |  |
| `image` | پانورامای استوانه‌ای (با هر نسبت ابعادی). فقط یک تصویر را می‌پذیرد. | IMAGE | بله |  |
| `resolution_level` | جزئیات به‌ازای هر نما (0 = سریع‌ترین، 9 = بیشترین جزئیات). پیش‌فرض: 9. | INT | بله | 0 to 9 |
| `split_resolution` | رزولوشن هر بخش پرسپکتیو. پیش‌فرض: 512. | INT | بله | 256 to 1024 |
| `merge_resolution` | رزولوشن ضلع بلند نقشه عمق استوانه‌ای ادغام‌شده. پیش‌فرض: 1920. | INT | بله | 256 to 8192 |
| `batch_size` | تعداد نما در هر دسته استنتاج (در مجموع ۱۲ بخش). پیش‌فرض: 4. | INT | بله | 1 to 12 |

نکته: این گره فقط یک تصویر را می‌پذیرد. ارسال یک دسته تصویر باعث بروز خطا می‌شود. پانوراما همیشه به ۱۲ نمای پرسپکتیو تقسیم می‌شود؛ `batch_size` فقط کنترل می‌کند که چه تعداد از این نماها در هر دسته استنتاج پردازش شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `moge_geometry` | یک دیکشنری شامل هندسه تخمین‌زده‌شده: `points` (ابر نقطه سه‌بعدی)، `depth` (نقشه عمق)، `mask` (ماسک ناحیه معتبر) و `image` (تصویر ورودی). | MOGE_GEOMETRY |
