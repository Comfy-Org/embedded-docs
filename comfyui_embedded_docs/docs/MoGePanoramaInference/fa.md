# استنتاج پانورامای MoGe

این گره تخمین عمق را روی تصاویر پانوراما استوانه‌ای هم‌فاصله (equirectangular) انجام می‌دهد. پانوراما را به ۱۲ نمای پرسپکتیو تقسیم می‌کند، مدل تخمین عمق MoGe را روی هر نما اجرا می‌کند و نتایج هر نما را دوباره در یک نقشه عمق واحد که کل پانوراما را پوشش می‌دهد ادغام می‌کند. نرمال‌های پیش‌بینی‌شده و مقیاس متریک هر نما نادیده گرفته می‌شوند، زیرا مقیاس‌های هر نما در امتداد درزهای هم‌پوشانی با یکدیگر هم‌تراز نمی‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | مدل MoGe برای استنتاج. | MOGE_MODEL | بله |  |
| `image` | پانوراما equirectangular (هر نسبت تصویری). گره تنها یک تصویر را می‌پذیرد؛ ارسال یک دسته از تصاویر خطا ایجاد می‌کند. فقط ۳ کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله |  |
| `resolution_level` | میزان جزئیات هر نما (0 = سریع‌ترین، 9 = با بیشترین جزئیات) (پیش‌فرض: 9). | INT | بله | 0 تا 9 |
| `split_resolution` | رزولوشن هر تقسیم پرسپکتیو (پیش‌فرض: 512). | INT | بله | 256 تا 1024 |
| `merge_resolution` | رزولوشن ضلع بلند نقشه فاصله equirectangular ادغام‌شده (پیش‌فرض: 1920). | INT | بله | 256 تا 8192 |
| `batch_size` | تعداد نماها در هر دسته استنتاج (در مجموع ۱۲ تقسیم) (پیش‌فرض: 4). | INT | بله | 1 تا 12 |
| `refine_steps` | فقط MoGe-3: پاس‌های پالایش حجمی تنک روی عمق پیش‌بینی‌شده. پاس‌های بیشتر جزئیات ریز و لبه‌ها را با هزینه‌ای تقریباً خطی تیزتر می‌کنند. مقدار 0 پالایش را غیرفعال می‌کند. توسط MoGe-1 / MoGe-2 نادیده گرفته می‌شود (پیش‌فرض: 3). | INT | بله | 0 تا 8 |

**نکات:**

- ورودی باید یک تصویر باشد. اگر `image` بیش از یک تصویر در دسته داشته باشد، گره خطا می‌دهد.
- `merge_resolution` به‌عنوان حداکثر اندازه ضلع بلند در نظر گرفته می‌شود. اگر پانوراما کوچک‌تر از این مقدار باشد، نقشه ادغام‌شده با اندازه اصلی پانوراما تولید می‌شود و بزرگ‌نمایی نمی‌شود. نتیجه ادغام‌شده پیش از بازگرداندن، به رزولوشن اصلی پانوراما تغییر اندازه داده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `moge_geometry` | یک دیکشنری شامل هندسه تخمین‌زده: `points` (ابر نقطه‌ای سه‌بعدی)، `depth` (نقشه عمق)، `mask` (ماسک ناحیه معتبر)، و `image` (تصویر ورودی). | MOGE_GEOMETRY |
