# استنتاج پانورامای MoGe

## بررسی اجمالی

این گره تخمین عمق را بر روی تصاویر پانورامای استوانه‌ای (equirectangular) انجام می‌دهد. پانوراما را به ۱۲ نمای پرسپکتیو تقسیم می‌کند، مدل تخمین عمق MoGe را بر روی هر نما اجرا می‌کند و نتایج هر نما را دوباره به یک نقشه عمق واحد که کل پانوراما را پوشش می‌دهد، ادغام می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | مدل MoGe برای استنتاج. | MOGE_MODEL | بله |  |
| `image` | پانورامای استوانه‌ای (هر نسبتی). گره فقط یک تصویر واحد را می‌پذیرد؛ ارسال دسته‌ای از تصاویر باعث بروز خطا می‌شود. فقط ۳ کانال رنگی اول (RGB) استفاده می‌شود. | IMAGE | بله |  |
| `resolution_level` | جزئیات هر نما (۰ = سریع‌ترین، ۹ = دقیق‌ترین) (پیش‌فرض: ۹). | INT | بله | 0 تا 9 |
| `split_resolution` | رزولوشن هر بخش پرسپکتیو (پیش‌فرض: ۵۱۲). | INT | بله | 256 تا 1024 |
| `merge_resolution` | رزولوشن ضلع بلند نقشه فاصله استوانه‌ای ادغام‌شده (پیش‌فرض: ۱۹۲۰). | INT | بله | 256 تا 8192 |
| `batch_size` | تعداد نماها در هر دسته استنتاج (مجموعاً ۱۲ بخش) (پیش‌فرض: ۴). | INT | بله | 1 تا 12 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `moge_geometry` | یک دیکشنری شامل هندسه تخمین‌زده‌شده: `points` (ابر نقطه سه‌بعدی)، `depth` (نقشه عمق)، `mask` (ماسک ناحیه معتبر)، و `image` (تصویر ورودی). | MOGE_GEOMETRY |
