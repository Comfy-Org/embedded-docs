# استنتاج پانورامای MoGe

این گره تخمین عمق را روی تصاویر پانورامای هم‌سطح (equirectangular) انجام می‌دهد. پانوراما را به ۱۲ نمای پرسپکتیو تقسیم می‌کند، مدل تخمین عمق MoGe را روی هر نما اجرا می‌کند و نتایج هر نما را دوباره در یک نقشه عمق واحد که کل پانوراما را پوشش می‌دهد ادغام می‌کند. نرمال‌های پیش‌بینی‌شده هر نما و مقیاس متریک نادیده گرفته می‌شوند، زیرا مقیاس‌های هر نما در درزهای هم‌پوشانی با یکدیگر هم‌راستا نمی‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | مدل MoGe برای استنتاج. | MOGE_MODEL | بله |  |
| `image` | پانورامای هم‌سطح (هر نسبت ابعادی). گره فقط یک تصویر را می‌پذیرد؛ ارسال یک دسته تصویر خطا ایجاد می‌کند. فقط ۳ کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله |  |
| `resolution_level` | میزان جزئیات هر نما (0 = سریع‌ترین، 9 = پرجزئیات‌ترین) (پیش‌فرض: 9). | INT | بله | 0 تا 9 |
| `split_resolution` | رزولوشن هر تقسیم پرسپکتیو (پیش‌فرض: 512). | INT | بله | 256 تا 1024 |
| `merge_resolution` | رزولوشن ضلع بلند نقشه فاصله هم‌سطح ادغام‌شده (پیش‌فرض: 1920). | INT | بله | 256 تا 8192 |
| `batch_size` | تعداد نماها در هر دسته استنتاج (در مجموع ۱۲ تقسیم) (پیش‌فرض: 4). | INT | بله | 1 تا 12 |

**یادداشت‌ها:**

- ورودی باید یک تصویر باشد. اگر `image` بیش از یک تصویر در دسته داشته باشد، گره خطا ایجاد می‌کند.
- `merge_resolution` به عنوان حداکثر اندازه ضلع بلند در نظر گرفته می‌شود. اگر پانوراما کوچک‌تر از این مقدار باشد، نقشه ادغام‌شده به‌جای بزرگ‌نمایی، در اندازه اصلی پانوراما تولید می‌شود. نتیجه ادغام‌شده پیش از بازگرداندن، دوباره به رزولوشن اصلی پانوراما تغییر اندازه داده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `moge_geometry` | یک دیکشنری شامل هندسه تخمین‌زده: `points` (ابر نقاط سه‌بعدی)، `depth` (نقشه عمق)، `mask` (ماسک ناحیه معتبر)، و `image` (تصویر ورودی). | MOGE_GEOMETRY |
