# استدلال MoGe بانوراما

تنفذ هذه العقدة تقدير العمق على الصور البانورامية متساوية المستطيلات. وهي تقسّم البانوراما إلى 12 مشهدًا منظوريًا، وتشغّل نموذج MoGe لتقدير العمق على كل مشهد، ثم تدمج نتائج كل مشهد مرة أخرى في خريطة عمق واحدة تغطي البانوراما الكاملة. يتم تجاهل المتجهات العمودية (normals) المتوقعة لكل مشهد والمقياس المتري، لأن المقاييس لكل مشهد لن تتحاذى عبر درزات التداخل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | نموذج MoGe المستخدم للاستدلال. | MOGE_MODEL | نعم |  |
| `image` | بانوراما متساوية المستطيلات (أي نسبة أبعاد). تقبل العقدة صورة واحدة فقط؛ تمرير دفعة من الصور يرفع خطأ. تُستخدم أول 3 قنوات لونية فقط (RGB). | IMAGE | نعم |  |
| `resolution_level` | مستوى التفاصيل لكل مشهد (0 = الأسرع، 9 = الأكثر تفصيلاً) (الافتراضي: 9). | INT | نعم | 0 إلى 9 |
| `split_resolution` | دقة كل تقسيم منظوري (الافتراضي: 512). | INT | نعم | 256 إلى 1024 |
| `merge_resolution` | دقة الضلع الطويل لخريطة مسافات الإسقاط المتساوي المستطيلات المدمجة (الافتراضي: 1920). | INT | نعم | 256 إلى 8192 |
| `batch_size` | عدد المشاهد لكل دفعة استدلال (إجمالاً 12 تقسيمًا) (الافتراضي: 4). | INT | نعم | 1 إلى 12 |
| `refine_steps` | خاص بـ MoGe-3 فقط: تمريرات تحسين حجمية متفرقة على العمق المتوقع. المزيد من التمريرات يشحذ التفاصيل الدقيقة والحواف بتكلفة خطية تقريبًا. القيمة 0 تعطّل التحسين. يتم تجاهله بواسطة MoGe-1 / MoGe-2 (الافتراضي: 3). | INT | نعم | 0 إلى 8 |

**ملاحظات:**

- يجب أن يكون الإدخال صورة واحدة. إذا احتوى `image` على أكثر من صورة في الدفعة، ترفع العقدة خطأ.
- تُعامل `merge_resolution` كحد أقصى لحجم الضلع الطويل. إذا كانت البانوراما أصغر من هذه القيمة، تُنتج الخريطة المدمجة بالحجم الأصلي للبانوراما بدلاً من تكبيرها. يُعاد تحجيم النتيجة المدمجة إلى دقة البانوراما الأصلية قبل إرجاعها.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `moge_geometry` | قاموس يحتوي على الهندسة المقدّرة: `points` (سحابة نقاط ثلاثية الأبعاد)، `depth` (خريطة عمق)، `mask` (قناع المنطقة الصالحة)، و`image` (الصورة المدخلة). | MOGE_GEOMETRY |
