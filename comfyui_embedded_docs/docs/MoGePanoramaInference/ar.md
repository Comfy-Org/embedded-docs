# استدلال MoGe بانوراما

تقوم هذه العقدة بتقدير العمق على صور البانوراما متساوية الإسقاط. تقسم البانوراما إلى 12 مشهدًا منظوريًا، وتشغّل نموذج MoGe لتقدير العمق على كل مشهد، ثم تدمج نتائج كل مشهد مرة أخرى في خريطة عمق واحدة تغطي البانوراما كاملة. يتم تجاهل المتجهات الطبيعية والمقياس المتري المتوقعين لكل مشهد، لأن مقاييس كل مشهد لن تتحاذى عبر وصلات التداخل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | نموذج MoGe المستخدم للاستدلال. | MOGE_MODEL | نعم |  |
| `image` | بانوراما متساوية الإسقاط (أي نسبة أبعاد). تقبل العقدة صورة واحدة فقط؛ تمرير دفعة من الصور يؤدي إلى خطأ. يتم استخدام أول 3 قنوات ألوان (RGB) فقط. | IMAGE | نعم |  |
| `resolution_level` | مستوى تفاصيل كل مشهد (0 = الأسرع، 9 = الأكثر تفصيلًا) (الافتراضي: 9). | INT | نعم | 0 إلى 9 |
| `split_resolution` | دقة كل تقسيم منظوري (الافتراضي: 512). | INT | نعم | 256 إلى 1024 |
| `merge_resolution` | دقة الضلع الأطول لخريطة المسافة متساوية الإسقاط المدموجة (الافتراضي: 1920). | INT | نعم | 256 إلى 8192 |
| `batch_size` | عدد المشاهد لكل دفعة استدلال (12 تقسيمًا إجمالًا) (الافتراضي: 4). | INT | نعم | 1 إلى 12 |

**ملاحظات:**

- يجب أن يكون الإدخال صورة واحدة. إذا احتوى `image` على أكثر من صورة في الدفعة، تُطلق العقدة خطأ.
- يتم التعامل مع `merge_resolution` كحد أقصى لحجم الضلع الأطول. إذا كانت البانوراما أصغر من هذه القيمة، فسيتم إنتاج الخريطة المدموجة بحجم البانوراما الأصلي بدلًا من تكبيرها. يتم تغيير حجم النتيجة المدموجة مرة أخرى إلى دقة البانوراما الأصلية قبل إرجاعها.
