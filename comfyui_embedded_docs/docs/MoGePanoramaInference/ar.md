# استدلال MoGe بانوراما

## نظرة عامة

تقوم هذه العقدة بإجراء تقدير للعمق على صور البانوراما متساوية المستطيلات. تقوم بتقسيم البانوراما إلى 12 عرضًا منظوريًا، وتشغيل نموذج تقدير العمق MoGe على كل عرض، ثم دمج النتائج لكل عرض في خريطة عمق واحدة تغطي كامل البانوراما.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | نموذج MoGe المستخدم في الاستدلال. | MOGE_MODEL | نعم |  |
| `image` | صورة بانوراما متساوية المستطيلات (بأي نسبة أبعاد). تقبل العقدة صورة واحدة فقط؛ تمرير مجموعة من الصور يسبب خطأ. يتم استخدام أول 3 قنوات لونية (RGB) فقط. | IMAGE | نعم |  |
| `resolution_level` | درجة تفاصيل كل عرض (0 = الأسرع، 9 = الأكثر تفصيلًا) (الافتراضي: 9). | INT | نعم | 0 إلى 9 |
| `split_resolution` | دقة كل تقسيم منظوري (الافتراضي: 512). | INT | نعم | 256 إلى 1024 |
| `merge_resolution` | دقة الجانب الطويل لخريطة العمق متساوية المستطيلات المدمجة (الافتراضي: 1920). | INT | نعم | 256 إلى 8192 |
| `batch_size` | عدد المشاهدات في كل دفعة استدلال (إجمالي التقسيمات 12) (الافتراضي: 4). | INT | نعم | 1 إلى 12 |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `moge_geometry` | قاموس يحتوي على الهندسة المُقدَّرة: `points` (سحابة نقاط ثلاثية الأبعاد)، `depth` (خريطة العمق)، `mask` (قناع المنطقة الصالحة)، و`image` (صورة الإدخال). | MOGE_GEOMETRY |
