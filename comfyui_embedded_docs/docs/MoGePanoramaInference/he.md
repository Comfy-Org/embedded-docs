# MoGePanoramaInference

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | מודל MoGe שיש להשתמש בו להסקה. | MOGE_MODEL | כן |  |
| `image` | פנורמה אקווירקטולרית (בכל יחס ממדים). הצומת מקבל תמונה בודדת בלבד; העברת אצוות תמונות מעוררת שגיאה. רק 3 ערוצי הצבע הראשונים (RGB) משמשים. | IMAGE | כן |  |
| `resolution_level` | רמת פירוט לפי מבט (0 = המהיר ביותר, 9 = המפורט ביותר) (ברירת מחדל: 9). | INT | כן | 0 to 9 |
| `split_resolution` | רזולוציה של כל פיצול פרספקטיבי (ברירת מחדל: 512). | INT | כן | 256 to 1024 |
| `merge_resolution` | רזולוציית הצלע הארוכה של מפת המרחק האקווירקטולרית הממוזגת (ברירת מחדל: 1920). | INT | כן | 256 to 8192 |
| `batch_size` | מבטים לכל אצוות הסקה (12 פיצולים בסך הכול) (ברירת מחדל: 4). | INT | כן | 1 to 12 |
| `refine_steps` | רק MoGe-3: מעברי עידון נפחיים דלילים על העומק החזוי. מעברים נוספים מחדדים פרטים עדינים וקצוות בעלות ליניארית בקירוב. 0 משבית את העידון. מתעלמים ממנו ב-MoGe-1 / MoGe-2 (ברירת מחדל: 3). | INT | כן | 0 to 8 |

**הערות:**

- הקלט חייב להיות תמונה בודדת. אם `image` מכיל יותר מתמונה אחת באצווה, הצומת מעורר שגיאה.
- `merge_resolution` מטופל כגודל מקסימלי של הצלע הארוכה. אם הפנורמה קטנה מערך זה, המפה הממוזגת מופקת בגודל הפנורמה המקורי במקום להיות מוגדלת. התוצאה הממוזגת מותאמת מחדש לרזולוציית הפנורמה המקורית לפני החזרתה.
