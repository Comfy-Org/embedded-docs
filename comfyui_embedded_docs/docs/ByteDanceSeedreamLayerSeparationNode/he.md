# ByteDance Seedream 5.0 Pro הפרדת שכבות (מדור קודם)

ByteDance Seedream 5.0 Pro Layer Separation מפרק תמונה ללוחית רקע בתוספת עד 16 שכבות שקופות הניתנות למיקום מחדש, כאשר לכל אחת סדר ערימה, תיבה תוחמת, שם ותיאור. הוא מחזיר את הרקע, תמונות לכל שכבה עם מסכות, תיבות מיקום ומחסנית שכבות מוכנה לעריכה.

**הערה:** צומת זה מסומן כמיושן בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה שיש להפריד. תמונה אחת בדיוק, בגודל של לפחות 512x512 פיקסלים, עם יחס גובה-רוחב בין 1:16 ל-16:1. קלטים גדולים מכ-4MP מוקטנים לפני ההעלאה. | IMAGE | כן | Single image |
| `prompt` | כיצד להפריד את התמונה. השאר ריק כדי לזהות אוטומטית ולהפריד את כל האלמנטים העיקריים. תאר אלמנטים בשפה טבעית כדי לשלוט בהפרדה, או כוון לאזורים מדויקים באמצעות תגי `<bbox>left top right bottom</bbox>` (קואורדינטות של 0-1000 באלפיות). ברירת מחדל: מחרוזת ריקה. | STRING | כן | Multiline text |
| `size` | רמת רזולוציית הפלט. "auto" עוקב אחר גודל תמונת הקלט (מוגבל לטווח 1K-2K). ברירת מחדל: "auto". | COMBO | כן | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | Seed לשימוש ביצירה. ברירת מחדל: 0. | INT | כן | 0 to 2147483647 |
| `prompt_optimization` | מצב אופטימיזציה של פרומפט: "standard" נותן איכות גבוהה יותר, "fast" זמן יצירה קצר יותר. ברירת מחדל: "standard". | COMBO | לא | "standard"<br>"fast" |
| `watermark` | האם להוסיף סימן מים "AI generated" לתמונות. ברירת מחדל: false. | BOOLEAN | לא | false<br>true |
| `crop_layers` | גאומטריית פלטי האצווה של השכבות/מסכות (layer_stack אינו מושפע ותמיד צמוד). קנבס מלא: כל שכבה על קנבס בגודל הבסיס במיקום תיבת התוחמת שלה - חבר מחדש ישירות עם ImageCompositeMasked. גודל מינימלי: כל שכבה נחתכת לתיבה התוחמת שלה (עם ריפוד לשכבה הגדולה ביותר לצורך אצווה) - טנסורים קטנים בהרבה; בנה מחדש את המיקום עם Layers From Bounding Boxes באמצעות פלט ה-bboxes. ברירת מחדל: false (קנבס מלא). | BOOLEAN | לא | false (full canvas)<br>true (minimal size) |

הערה: הקלט `image` חייב להיות תמונה בודדת; אצוות אינן נתמכות. התמונה חייבת להיות בגודל של לפחות 512x512 פיקסלים עם יחס גובה-רוחב בין 1:16 ל-16:1.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `base_image` | תמונת הבסיס (לוחית הרקע) שעליה נערמות השכבות. | IMAGE |
| `base_mask` | השקיפות של תמונת הבסיס (1 = שקוף, לפי המוסכמה של LoadImage); נכון לעכשיו תמיד אטום לחלוטין. | MASK |
| `layers` | שכבות שקופות מסודרות מלמטה למעלה. מצב קנבס מלא: ממוקמות על קנבס שחור בגודל הבסיס במיקום תיבת התוחמת שלהן. מצב גודל מינימלי: נחתכות לתיבה התוחמת שלהן, מעוגנות בפינה השמאלית העליונה, ומרופדות לשכבה הגדולה ביותר. | IMAGE |
| `masks` | שקיפות לכל שכבה, מיושרת לפי אינדקס עם אצוות השכבות (1 = שקוף, לפי המוסכמה של LoadImage). לקומפוזיציה בסגנון ImageCompositeMasked, הוסף תחילה InvertMask. | MASK |
| `bboxes` | תיבת מיקום אחת לכל שכבה, מיושרת לפי אינדקס עם אצוות השכבות (הזן את שתיהן, יחד עם masks, אל Layers From Bounding Boxes כדי לבנות מחדש את המיקום לכל שכבה): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` הוא אזור התוכן של השכבה בתוך המסגרת של עצמה; הוא ממוקם על הקנבס במיקום התיבה בתוספת ההיסט הזה. | BOUNDING_BOX |
| `layer_stack` | מסמך שכבות מוכן לעריכה עבור Create Layered Image: לוחית הבסיס בתוספת כל אלמנט כשכבה משלו בעלת שם, חתוכה באופן הדוק, במיקומה האמיתי ובסדר הערימה שלה. חבר ישירות, או הרחב עם Add Layer. | LAYERS |
