# ByteDanceSeedreamLayerSeparationNode

ByteDance Seedream 5.0 Pro Layer Separation

تقوم أداة فصل الطبقات ByteDance Seedream 5.0 Pro بتحليل الصورة إلى لوحة خلفية بالإضافة إلى ما يصل إلى 16 طبقة شفافة، لكل منها ترتيب تراص خاص بها، وإطار محيط، واسم، ووصف. تُرجع الأداة الخلفية، وصور كل طبقة مع الأقنعة، ومربعات التنسيب، ومكدس طبقات جاهز للتحرير.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المراد فصلها. صورة واحدة بالضبط، بحجم لا يقل عن 512×512 بكسل، ونسبة أبعاد بين 1:16 و16:1. يتم تصغير المدخلات الأكبر من حوالي 4 ميجابكسل قبل الرفع. | IMAGE | نعم | Single image |
| `prompt` | كيفية فصل الصورة. اتركه فارغًا للاكتشاف التلقائي وفصل جميع العناصر الرئيسية. صف العناصر باللغة الطبيعية للتحكم في الفصل، أو استهدف مناطق محددة باستخدام وسوم `<bbox>left top right bottom</bbox>` (إحداثيات بالأجزاء من الألف من 0 إلى 1000). الافتراضي: سلسلة فارغة. | STRING | نعم | Multiline text |
| `size` | مستوى دقة المخرجات. "auto" يتبع حجم صورة الإدخال (مقيدًا بالنطاق من 1K إلى 2K). الافتراضي: "auto". | STRING | نعم | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | البذرة المستخدمة للتوليد. الافتراضي: 0. | INT | نعم | 0 إلى 2147483647 |
| `prompt_optimization` | وضع تحسين المطالبة: "standard" يعطي جودة أعلى، و"fast" زمن توليد أقصر. الافتراضي: "standard". | STRING | لا | "standard"<br>"fast" |
| `watermark` | ما إذا كان سيتم إضافة علامة مائية "منشأة بواسطة الذكاء الاصطناعي" إلى الصور. الافتراضي: false. | BOOLEAN | لا | false<br>true |
| `crop_layers` | هندسة مخرجات دُفعات الطبقات والأقنعة (لا يتأثر layer_stack ويظل دائمًا مضبوطًا). لوحة كاملة: كل طبقة على لوحة بحجم الأساس في موضع إطارها المحدد - أعد التركيب مباشرة باستخدام ImageCompositeMasked. حجم أدنى: كل طبقة مقصوصة إلى إطارها المحدد (مبطنة إلى أكبر طبقة للتجميع في دفعة) - موترات أصغر بكثير؛ أعد بناء التنسيب باستخدام Layers From Bounding Boxes مع مخرجات bboxes. الافتراضي: false (full canvas). | BOOLEAN | لا | false (full canvas)<br>true (minimal size) |

ملاحظة: يجب أن تكون صورة الإدخال صورة واحدة؛ لا تُدعم الدُفعات. يجب أن يكون حجم الصورة 512×512 بكسل على الأقل مع نسبة أبعاد بين 1:16 و16:1.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `base_image` | الصورة الأساسية (لوحة الخلفية) التي تُكدَّس عليها الطبقات. | IMAGE |
| `base_mask` | شفافية الصورة الأساسية (1 = شفاف، اصطلاح LoadImage)؛ حاليًا معتمة تمامًا دائمًا. | MASK |
| `layers` | طبقات شفافة مرتّبة من الأسفل إلى الأعلى. وضع اللوحة الكاملة: موضوعة على لوحة سوداء بحجم الأساس في موضع إطارها المحدد. وضع الحجم الأدنى: مقصوصة إلى إطارها المحدد، مثبتة أعلى اليسار، ومبطنة إلى أكبر طبقة. | IMAGE |
| `masks` | شفافية كل طبقة، متوافقة في الفهرس مع دفعة الطبقات (1 = شفاف، اصطلاح LoadImage). لتركيب بأسلوب ImageCompositeMasked، أضف InvertMask أولاً. | MASK |
| `bboxes` | صندوق تنسيب واحد لكل طبقة، متوافق في الفهرس مع دفعة الطبقات (غذِّ كليهما مع الأقنعة إلى Layers From Bounding Boxes لإعادة بناء تنسيب كل طبقة): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` هو منطقة محتوى الطبقة داخل إطارها الخاص؛ يقع على اللوحة عند موضع الصندوق بالإضافة إلى ذلك الإزاحة. | BOUNDING_BOX |
| `layer_stack` | مستند طبقات جاهز للتحرير لـ Create Layered Image: اللوحة الأساسية مع كل عنصر كطبقة خاصة به مسمّاة ومقصوصة بإحكام في موضعها الحقيقي وترتيب تراصها. وصّله مباشرة، أو وسّعه باستخدام Add Layer. | LAYERS |
