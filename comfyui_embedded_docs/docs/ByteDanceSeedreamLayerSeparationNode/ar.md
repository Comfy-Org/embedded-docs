# ByteDance Seedream 5.0 Pro فصل الطبقات

تقوم أداة ByteDance Seedream 5.0 Pro Layer Separation بتحليل الصورة إلى لوحة خلفية بالإضافة إلى ما يصل إلى 16 طبقة شفافة، لكل منها ترتيب تكديس خاص بها، ومربع إحاطة، واسم، ووصف. وتُعيد الخلفية، وصور كل طبقة مع أقنعة، ومربعات موضع، ومكدس طبقات جاهز للتعديل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المطلوب تحليلها. صورة واحدة بالضبط، بحجم لا يقل عن 512×512 بكسل، ونسبة أبعاد بين 1:16 و16:1. يتم تقليل حجم المدخلات الأكبر من حوالي 4 ميجابكسل قبل الرفع. | IMAGE | نعم | صورة واحدة |
| `prompt` | كيفية تحليل الصورة. اتركه فارغًا للاكتشاف التلقائي وفصل جميع العناصر الرئيسية. صف العناصر باللغة الطبيعية للتحكم في الفصل، أو استهدف مناطق محددة باستخدام وسوم `<bbox>left top right bottom</bbox>` (إحداثيات بالأجزاء من الألف 0-1000). الافتراضي: سلسلة فارغة. | STRING | نعم | نص متعدد الأسطر |
| `size` | مستوى دقة المخرجات. يتبع الخيار `"auto"` حجم الصورة المدخلة (مقيدًا بالنطاق 1K-2K). الافتراضي: `"auto"`. | COMBO | نعم | `"auto"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"` |
| `seed` | البذرة (Seed) المستخدمة في التوليد. الافتراضي: 0. | INT | نعم | من 0 إلى 2147483647 |
| `prompt_optimization` | وضع تحسين الوصف: يمنح الخيار `"standard"` جودة أعلى، بينما يمنح الخيار `"fast"` وقت توليد أقصر. الافتراضي: `"standard"`. | COMBO | لا | `"standard"`<br>`"fast"` |
| `watermark` | ما إذا كان سيتم إضافة علامة مائية `"AI generated"` إلى الصور. الافتراضي: false. | BOOLEAN | لا | false<br>true |
| `crop_layers` | هندسة مخرجات الدفعة للطبقات/الأقنعة (لا يتأثر layer_stack ويظل دائمًا محكمًا). لوحة كاملة: كل طبقة على لوحة بحجم القاعدة في موضع مربع الإحاطة الخاص بها - يمكن إعادة التركيب مباشرة باستخدام ImageCompositeMasked. حجم أدنى: كل طبقة مقصوصة إلى مربع الإحاطة الخاص بها (مبطّنة إلى أكبر طبقة للدفعة) - موترات أصغر بكثير؛ أعد بناء الموضع باستخدام Layers From Bounding Boxes مع مخرج bboxes. الافتراضي: false (لوحة كاملة). | BOOLEAN | لا | false (لوحة كاملة)<br>true (حجم أدنى) |

ملاحظة: يجب أن تكون الصورة المدخلة صورة واحدة؛ لا تُدعم الدفعات. يجب أن يكون حجم الصورة 512×512 بكسل على الأقل مع نسبة أبعاد بين 1:16 و16:1.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `base_image` | الصورة الأساسية (لوحة الخلفية) التي تُكدّس عليها الطبقات. | IMAGE |
| `base_mask` | شفافية الصورة الأساسية (1 = شفاف، اصطلاح LoadImage)؛ حاليًا دائمًا معتمة بالكامل. | MASK |
| `layers` | طبقات شفافة مرتبة من الأسفل إلى الأعلى. وضع اللوحة الكاملة: توضع على لوحة سوداء بحجم القاعدة في موضع مربع الإحاطة الخاص بها. وضع الحجم الأدنى: تُقصّ إلى مربع الإحاطة الخاص بها، مثبتة في الزاوية العلوية اليسرى، ومبطّنة إلى أكبر طبقة. | IMAGE |
| `masks` | شفافية كل طبقة، بمحاذاة الفهرس مع دفعة الطبقات (1 = شفاف، اصطلاح LoadImage). لدمج بنمط ImageCompositeMasked، أضف InvertMask أولاً. | MASK |
| `bboxes` | مربع موضع واحد لكل طبقة، بمحاذاة الفهرس مع دفعة الطبقات (مرّر الاثنين معًا، بالإضافة إلى الأقنعة، إلى Layers From Bounding Boxes لإعادة بناء موضع كل طبقة): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` هو منطقة محتوى الطبقة داخل إطارها الخاص؛ وتقع على اللوحة عند موضع المربع مضافًا إليه ذلك الإزاحة. | BOUNDING_BOX |
| `layer_stack` | مستند طبقات جاهز للتعديل لأداة Create Layered Image: لوحة القاعدة مع كل عنصر كطبقة خاصة به مسمّاة ومقصوصة بإحكام في موضعها الحقيقي وترتيب تكديسها. يمكنك توصيله مباشرة، أو توسيعه باستخدام Add Layer. | LAYERS |
