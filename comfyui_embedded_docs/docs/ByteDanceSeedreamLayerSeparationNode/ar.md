# ByteDance Seedream 5.0 Pro فصل الطبقات

يقوم ByteDance Seedream 5.0 Pro Layer Separation بتفكيك صورة إلى لوحة خلفية بالإضافة إلى ما يصل إلى 16 طبقة شفافة قابلة لإعادة التموضع، لكل منها ترتيب تكديس ومربع محيط واسم ووصف. يُرجع الخلفية، وصورًا لكل طبقة مع أقنعة، ومربعات تموضع، ومكدس طبقات جاهزًا للتحرير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المراد فصلها. صورة واحدة بالضبط، بحد أدنى 512×512 بكسل، ونسبة أبعاد بين 1:16 و16:1. يتم تصغير المدخلات الأكبر من نحو 4MP قبل الرفع. | IMAGE | نعم | صورة واحدة |
| `prompt` | كيفية فصل الصورة. اتركه فارغًا للاكتشاف التلقائي وفصل جميع العناصر الرئيسية. صف العناصر باللغة الطبيعية للتحكم في الفصل، أو استهدف مناطق محددة بوسوم `<bbox>left top right bottom</bbox>` (إحداثيات من 0 إلى 1000 أجزاء من الألف). القيمة الافتراضية: سلسلة فارغة. | STRING | نعم | نص متعدد الأسطر |
| `size` | مستوى دقة المخرجات. "auto" يتبع حجم الصورة المدخلة (مقيّد بنطاق 1K-2K). القيمة الافتراضية: "auto". | COMBO | نعم | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | البذرة المستخدمة للتوليد. القيمة الافتراضية: 0. | INT | نعم | 0 إلى 2147483647 |
| `prompt_optimization` | وضع تحسين الوصف النصي: "standard" يمنح جودة أعلى، و"fast" وقت توليد أقصر. القيمة الافتراضية: "standard". | COMBO | لا | "standard"<br>"fast" |
| `watermark` | هل تُضاف علامة مائية "AI generated" إلى الصور. القيمة الافتراضية: false. | BOOLEAN | لا | false<br>true |
| `crop_layers` | هندسة مخرجات دفعة الطبقات/الأقنعة (layer_stack غير متأثر ودائمًا محكم الاقتصاص). اللوحة الكاملة: كل طبقة على لوحة بحجم الأساس عند موضع مربعها المحيط - أعد التجميع مباشرة باستخدام ImageCompositeMasked. الحجم الأدنى: تُقص كل طبقة إلى مربعها المحيط (مع الحشو إلى أكبر طبقة لأجل الدفعات) - موترات أصغر بكثير؛ أعد بناء التموضع باستخدام Layers From Bounding Boxes عبر مخرج bboxes. القيمة الافتراضية: false (اللوحة الكاملة). | BOOLEAN | لا | false (اللوحة الكاملة)<br>true (حجم أدنى) |

ملاحظة: يجب أن يكون المدخل `image` صورة واحدة؛ لا تُدعم الدفعات. يجب أن تكون الصورة بحد أدنى 512×512 بكسل ونسبة أبعاد بين 1:16 و16:1.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `base_image` | الصورة الأساسية (لوحة الخلفية) التي تتكدس عليها الطبقات. | IMAGE |
| `base_mask` | شفافية الصورة الأساسية (1 = شفاف، وفق اصطلاح LoadImage)؛ وهي حاليًا معتمة بالكامل دائمًا. | MASK |
| `layers` | طبقات شفافة مرتبة من الأسفل إلى الأعلى. وضع اللوحة الكاملة: توضع على لوحة سوداء بحجم الأساس عند موضع مربعها المحيط. وضع الحجم الأدنى: تُقص إلى مربعها المحيط، وتُثبّت من الأعلى-اليسار، وتُحشى إلى أكبر طبقة. | IMAGE |
| `masks` | شفافية لكل طبقة، متوافقة بالترتيب مع دفعة layers (1 = شفاف، وفق اصطلاح LoadImage). للتجميع بأسلوب ImageCompositeMasked، أضف InvertMask أولًا. | MASK |
| `bboxes` | مربع تموضع واحد لكل طبقة، متوافق بالترتيب مع دفعة layers (مرّر كليهما، مع masks، إلى Layers From Bounding Boxes لإعادة بناء تموضع كل طبقة): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` هو منطقة محتوى الطبقة داخل إطارها الخاص؛ ويستقر على اللوحة عند موضع المربع زائد ذلك الإزاحة. | BOUNDING_BOX |
| `layer_stack` | مستند طبقات جاهز للتحرير من أجل Create Layered Image: اللوحة الأساسية بالإضافة إلى كل عنصر كطبقة خاصة به، مسماة ومقصوصة بإحكام، عند موضعه الحقيقي وترتيب تكديسه. وصّله مباشرة، أو وسّعه باستخدام Add Layer. | LAYERS |
