# ByteDance Seedream 5.0 Pro Разделение Слоёв

ByteDance Seedream 5.0 Pro Layer Separation разделяет изображение на фоновый слой и до 16 прозрачных слоёв, каждый со своим порядком наложения, ограничивающей рамкой, именем и описанием. Возвращает фон, изображения слоёв с масками, блоки размещения и готовый к редактированию документ слоёв.

## Входные данные

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для разделения. Ровно одно изображение, не менее 512×512 пикселей, соотношение сторон от 1:16 до 16:1. Изображения крупнее примерно 4 МП уменьшаются перед загрузкой. | IMAGE | Да | Single image |
| `prompt` | Как разделять изображение. Оставьте пустым для автоматического обнаружения и разделения всех основных элементов. Опишите элементы на естественном языке, чтобы управлять разделением, или укажите точные области с помощью тегов `<bbox>left top right bottom</bbox>` (координаты в промилле от 0 до 1000). По умолчанию: пустая строка. | STRING | Да | Multiline text |
| `size` | Уровень разрешения на выходе. «auto» соответствует размеру входного изображения (ограничен диапазоном 1K–2K). По умолчанию: «auto». | COMBO | Да | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | Сид для генерации. По умолчанию: 0. | INT | Да | 0 to 2147483647 |
| `prompt_optimization` | Режим оптимизации промпта: «standard» даёт более высокое качество, «fast» — более короткое время генерации. По умолчанию: «standard». | COMBO | Нет | "standard"<br>"fast" |
| `watermark` | Добавлять ли водяной знак «AI generated» к изображениям. По умолчанию: false. | BOOLEAN | Нет | false<br>true |
| `crop_layers` | Геометрия пакетных выходов слоёв/масок (layer_stack не затрагивается и всегда плотно обрезан). Full canvas (полный холст): каждый слой на холсте базового размера в позиции его ограничивающей рамки — можно сразу собирать обратно с помощью ImageCompositeMasked. Minimal size (минимальный размер): каждый слой обрезается до ограничивающей рамки (дополняется до наибольшего слоя для пакетной обработки) — тензоры значительно меньше; восстановите размещение с помощью Layers From Bounding Boxes, используя выход bboxes. По умолчанию: false (полный холст). | BOOLEAN | Нет | false (full canvas)<br>true (minimal size) |

Примечание: входное изображение должно быть одним изображением; пакеты не поддерживаются. Изображение должно быть не менее 512×512 пикселей с соотношением сторон от 1:16 до 16:1.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_image` | Базовое изображение (фоновый слой), на которое накладываются слои. | IMAGE |
| `base_mask` | Прозрачность базового изображения (1 = прозрачный, по соглашению LoadImage); в настоящее время всегда полностью непрозрачный. | MASK |
| `layers` | Прозрачные слои, упорядоченные снизу вверх. Режим полного холста: размещаются на чёрном холсте базового размера в позиции ограничивающей рамки. Режим минимального размера: обрезаются по ограничивающей рамке, выравниваются по верхнему левому углу, дополняются до наибольшего слоя. | IMAGE |
| `masks` | Прозрачность каждого слоя, согласованная по индексу с пакетом слоёв (1 = прозрачный, по соглашению LoadImage). Для композитинга в стиле ImageCompositeMasked сначала добавьте InvertMask. | MASK |
| `bboxes` | Один блок размещения на каждый слой, согласованный по индексу с пакетом слоёв (подайте их вместе с масками в Layers From Bounding Boxes, чтобы восстановить размещение по слоям): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` — это область содержимого слоя в его собственном кадре; она попадает на холст в позиции блока плюс указанное смещение. | BOUNDING_BOX |
| `layer_stack` | Готовый к редактированию документ слоёв для Create Layered Image: базовый слой плюс каждый элемент как отдельный именованный плотно обрезанный слой в его истинной позиции и порядке наложения. Подключайтесь напрямую или расширяйте с помощью Add Layer. | LAYERS |
