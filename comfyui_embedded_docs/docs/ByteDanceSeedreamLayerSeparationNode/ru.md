# ByteDance Seedream 5.0 Pro Разделение Слоёв

ByteDance Seedream 5.0 Pro Layer Separation разлагает изображение на фоновую подложку и до 16 прозрачных слоёв, каждый со своим порядком наложения, ограничивающей рамкой, именем и описанием. На выходе возвращаются фон, изображения слоёв с масками, блоки размещения и готовый к редактированию стек слоёв.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для разделения. Ровно одно изображение, не менее 512x512 пикселей, соотношение сторон от 1:16 до 16:1. Входные изображения размером более примерно 4 Мп уменьшаются перед отправкой. | IMAGE | Да | Одно изображение |
| `prompt` | Как разделять изображение. Оставьте пустым для автоматического обнаружения и разделения всех основных элементов. Описывайте элементы на естественном языке для управления разделением или указывайте точные области с помощью тегов `<bbox>left top right bottom</bbox>` (координаты в промилле от 0 до 1000). По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `size` | Уровень выходного разрешения. Значение `"auto"` соответствует размеру входного изображения (ограничено диапазоном 1K–2K). По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"` |
| `seed` | Сид для генерации. По умолчанию: 0. | INT | Да | от 0 до 2147483647 |
| `prompt_optimization` | Режим оптимизации промпта: `"standard"` даёт более высокое качество, `"fast"` — меньшее время генерации. По умолчанию: `"standard"`. | COMBO | Нет | `"standard"`<br>`"fast"` |
| `watermark` | Добавлять ли к изображениям водяной знак «AI generated». По умолчанию: false. | BOOLEAN | Нет | false<br>true |
| `crop_layers` | Геометрия выходных пакетов слоёв/масок (`layer_stack` не затрагивается и всегда плотно обрезан). Full canvas: каждый слой размещается на холсте базового размера в позиции своей ограничивающей рамки — можно сразу компоновать обратно через ImageCompositeMasked. Minimal size: каждый слой обрезается по своей ограничивающей рамке (дополняется до самого большого слоя для формирования пакета) — тензоры значительно меньше; восстановите размещение с помощью Layers From Bounding Boxes, используя выходные данные `bboxes`. По умолчанию: false (full canvas). | BOOLEAN | Нет | false (full canvas)<br>true (minimal size) |

Примечание: входное изображение `image` должно быть одиночным; пакеты не поддерживаются. Изображение должно быть не менее 512x512 пикселей с соотношением сторон от 1:16 до 16:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_image` | Базовое изображение (фоновая подложка), на которую собираются слои. | IMAGE |
| `base_mask` | Прозрачность базового изображения (1 = прозрачный, по соглашению LoadImage); в настоящее время всегда полностью непрозрачный. | MASK |
| `layers` | Прозрачные слои в порядке снизу вверх. Режим full canvas: размещаются на чёрном холсте базового размера в позиции своей ограничивающей рамки. Режим minimal size: обрезаются по своей ограничивающей рамке, выравниваются по верхнему левому углу и дополняются до самого большого слоя. | IMAGE |
| `masks` | Прозрачность каждого слоя, согласованная по индексу с пакетом слоёв (1 = прозрачный, по соглашению LoadImage). Для композитинга в стиле ImageCompositeMasked сначала добавьте InvertMask. | MASK |
| `bboxes` | Один блок размещения на слой, согласованный по индексу с пакетом слоёв (передайте их вместе с масками в Layers From Bounding Boxes, чтобы восстановить размещение каждого слоя): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` — это область содержимого слоя внутри его собственного кадра; на холсте она располагается в позиции блока с учётом этого смещения. | BOUNDING_BOX |
| `layer_stack` | Готовый к редактированию документ слоёв для Create Layered Image: базовая подложка и каждый элемент в виде отдельного именованного слоя с плотной обрезкой, в его истинной позиции и порядке наложения. Подключайте напрямую или расширяйте с помощью Add Layer. | LAYERS |
