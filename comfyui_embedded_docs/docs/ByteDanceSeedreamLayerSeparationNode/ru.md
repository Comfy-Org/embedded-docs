# ByteDance Seedream 5.0 Pro Разделение Слоёв (устаревшая версия)

ByteDance Seedream 5.0 Pro Layer Separation разлагает изображение на фоновую подложку и до 16 перемещаемых прозрачных слоёв, каждый с порядком наложения, ограничивающей рамкой, именем и описанием. Узел возвращает фон, изображения отдельных слоёв с масками, рамки размещения и готовый к редактированию стек слоёв.

**Примечание:** В исходном коде этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для разделения. Ровно одно изображение, не менее 512x512 пикселей, соотношение сторон от 1:16 до 16:1. Входные изображения размером более примерно 4 МП уменьшаются перед загрузкой. | IMAGE | Да | Одно изображение |
| `prompt` | Как разделить изображение. Оставьте пустым, чтобы автоматически определить и разделить все основные элементы. Описывайте элементы на естественном языке для управления разделением или нацеливайтесь на точные области с помощью тегов `<bbox>left top right bottom</bbox>` (координаты в промилле, 0–1000). По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `size` | Уровень разрешения выходного изображения. `"auto"` соответствует размеру входного изображения (ограничивается диапазоном 1K–2K). По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"1K"`<br>`"1.5K"`<br>`"2K"` |
| `seed` | Зерно (seed) для генерации. По умолчанию: 0. | INT | Да | 0 до 2147483647 |
| `prompt_optimization` | Режим оптимизации промпта: `"standard"` обеспечивает более высокое качество, `"fast"` — более короткое время генерации. По умолчанию: `"standard"`. | COMBO | Нет | `"standard"`<br>`"fast"` |
| `watermark` | Добавлять ли водяной знак `"AI generated"` на изображения. По умолчанию: false. | BOOLEAN | Нет | false<br>true |
| `crop_layers` | Геометрия пакетных выходов слоёв/масок (`layer_stack` не затрагивается и всегда плотно обрезан). Полный холст: каждый слой размещается на холсте размером с базовое изображение в позиции своей ограничивающей рамки — можно напрямую пересобрать с помощью ImageCompositeMasked. Минимальный размер: каждый слой обрезается по своей ограничивающей рамке (дополняется до самого большого слоя для пакетной обработки) — тензоры значительно меньше; восстановите размещение с помощью Layers From Bounding Boxes, используя выход `bboxes`. По умолчанию: false (полный холст). | BOOLEAN | Нет | false (полный холст)<br>true (минимальный размер) |

Примечание. Вход `image` должен быть одним изображением; пакеты (batches) не поддерживаются. Изображение должно быть не менее 512x512 пикселей с соотношением сторон от 1:16 до 16:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_image` | Базовое изображение (фоновая подложка), на которое накладываются слои. | IMAGE |
| `base_mask` | Прозрачность базового изображения (1 = прозрачный, соглашение LoadImage); в настоящее время всегда полностью непрозрачно. | MASK |
| `layers` | Прозрачные слои, упорядоченные снизу вверх. Режим полного холста: размещаются на чёрном холсте размером с базовое изображение в позиции своей ограничивающей рамки. Режим минимального размера: обрезаются по своей ограничивающей рамке, привязываются к верхнему левому углу, дополняются до самого большого слоя. | IMAGE |
| `masks` | Прозрачность для каждого слоя, согласованная по индексу с пакетом `layers` (1 = прозрачный, соглашение LoadImage). Для композитинга в стиле ImageCompositeMasked сначала добавьте InvertMask. | MASK |
| `bboxes` | Одна рамка размещения на слой, согласованная по индексу с пакетом `layers` (подайте оба выхода, а также `masks`, в Layers From Bounding Boxes, чтобы восстановить размещение каждого слоя): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` — это область содержимого слоя внутри его собственного кадра; она размещается на холсте в позиции рамки плюс это смещение. | BOUNDING_BOX |
| `layer_stack` | Готовый к редактированию документ слоёв для Create Layered Image: базовая подложка плюс каждый элемент как отдельный именованный слой, плотно обрезанный, на своей истинной позиции и в порядке наложения. Подключите напрямую или расширьте с помощью Add Layer. | LAYERS |
