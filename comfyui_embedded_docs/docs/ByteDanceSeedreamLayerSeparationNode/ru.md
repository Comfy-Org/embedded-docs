# ByteDanceSeedreamLayerSeparationNode

ByteDance Seedream 5.0 Pro Layer Separation разделяет изображение на фоновую подложку и до 16 прозрачных слоёв, каждый со своим порядком наложения, ограничивающей рамкой, именем и описанием. Он возвращает фон, изображения слоёв с масками, рамки размещения и готовый к редактированию стек слоёв.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение для разделения. Ровно одно изображение, не менее 512x512 пикселей, соотношение сторон от 1:16 до 16:1. Входные изображения размером более примерно 4 МП перед загрузкой уменьшаются. | IMAGE | Да | Одиночное изображение |
| `prompt` | Как разделить изображение. Оставьте пустым, чтобы автоматически обнаруживать и разделять все основные элементы. Опишите элементы на естественном языке, чтобы управлять разделением, или укажите точные области с помощью тегов `<bbox>left top right bottom</bbox>` (координаты в тысячных долях, 0–1000). По умолчанию: пустая строка. | STRING | Да | Многострочный текст |
| `size` | Уровень разрешения выходного изображения. Значение «auto» следует размеру входного изображения (ограничено диапазоном 1K–2K). По умолчанию: «auto». | STRING | Да | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | Сид (seed) для генерации. По умолчанию: 0. | INT | Да | от 0 до 2147483647 |
| `prompt_optimization` | Режим оптимизации промпта: «standard» даёт более высокое качество, «fast» — сокращённое время генерации. По умолчанию: «standard». | STRING | Нет | "standard"<br>"fast" |
| `watermark` | Добавлять ли на изображения водяной знак «AI generated». По умолчанию: false. | BOOLEAN | Нет | false<br>true |
| `crop_layers` | Геометрия пакетных выходов слоёв/масок (layer_stack не затрагивается и всегда плотно обрезан). Режим полного холста: каждый слой размещается на холсте размером с базовый в позиции своей ограничивающей рамки — можно сразу собрать с помощью ImageCompositeMasked. Режим минимального размера: каждый слой обрезается до своей ограничивающей рамки (дополняется до самого большого слоя для пакетной обработки) — тензоры значительно меньше; восстановите размещение с помощью Layers From Bounding Boxes, используя выход bboxes. По умолчанию: false (полный холст). | BOOLEAN | Нет | false (full canvas)<br>true (minimal size) |

Примечание: входное изображение должно быть одиночным; пакеты не поддерживаются. Изображение должно быть не менее 512x512 пикселей с соотношением сторон от 1:16 до 16:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `base_image` | Базовое изображение (фоновая подложка), на которое накладываются слои. | IMAGE |
| `base_mask` | Прозрачность базового изображения (1 = прозрачный, по соглашению LoadImage); в настоящее время изображение всегда полностью непрозрачно. | MASK |
| `layers` | Прозрачные слои, упорядоченные снизу вверх. Режим полного холста: размещены на чёрном холсте размером с базовый в позиции своей ограничивающей рамки. Режим минимального размера: обрезаны по своей ограничивающей рамке, привязаны к верхнему левому углу, дополнены до самого большого слоя. | IMAGE |
| `masks` | Прозрачность для каждого слоя, совпадающая по индексу с пакетом слоёв (1 = прозрачный, по соглашению LoadImage). Для композитинга в стиле ImageCompositeMasked сначала добавьте InvertMask. | MASK |
| `bboxes` | Одна рамка размещения для каждого слоя, совпадающая по индексу с пакетом слоёв (передайте пакет слоёв, маски и рамки размещения в Layers From Bounding Boxes, чтобы восстановить размещение каждого слоя): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` — это область содержимого слоя в его собственном кадре; на холсте она попадает в позицию рамки плюс это смещение. | BOUNDING_BOX |
| `layer_stack` | Готовый к редактированию документ слоёв для Create Layered Image: базовая подложка плюс каждый элемент в виде отдельного именованного слоя с плотной обрезкой, в его истинном положении и порядке наложения. Подключайте напрямую или расширяйте с помощью Add Layer. | LAYERS |
