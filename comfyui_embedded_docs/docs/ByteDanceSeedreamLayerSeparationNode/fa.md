# ByteDanceSeedreamLayerSeparationNode

ByteDance Seedream 5.0 Pro Layer Separation تصویری را به یک صفحه‌ی پس‌زمینه و حداکثر ۱۶ لایه‌ی شفاف تجزیه می‌کند؛ هر لایه دارای ترتیب چیدمان، کادر محدودکننده، نام و توضیحات مخصوص به خود است. این گره تصویر پس‌زمینه، تصاویر مربوط به هر لایه همراه با ماسک‌ها، کادرهای جای‌گذاری و یک پشته‌ی لایه‌ی آماده‌ی ویرایش را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که باید جداسازی شود. دقیقاً یک تصویر، حداقل ۵۱۲×۵۱۲ پیکسل، با نسبت ابعاد بین ۱:۱۶ و ۱۶:۱. ورودی‌های بزرگ‌تر از حدود ۴ مگاپیکسل قبل از آپلود کوچک‌سازی می‌شوند. | IMAGE | بله | Single image |
| `prompt` | نحوه جداسازی تصویر. برای تشخیص خودکار و جداسازی همه‌ی عناصر اصلی، آن را خالی بگذارید. برای کنترل جداسازی، عناصر را به زبان طبیعی توصیف کنید، یا با تگ‌های `<bbox>left top right bottom</bbox>` مناطق دقیق را هدف بگیرید (مختصات ۰ تا ۱۰۰۰ در هزار). پیش‌فرض: رشته‌ی خالی. | STRING | بله | Multiline text |
| `size` | سطح وضوح خروجی. «auto» از اندازه‌ی تصویر ورودی پیروی می‌کند (به بازه‌ی ۱K تا ۲K محدود می‌شود). پیش‌فرض: «auto». | STRING | بله | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | seed مورد استفاده برای تولید. پیش‌فرض: 0. | INT | بله | 0 تا 2147483647 |
| `prompt_optimization` | حالت بهینه‌سازی prompt: «standard» کیفیت بالاتری می‌دهد و «fast» زمان تولید کوتاه‌تری. پیش‌فرض: «standard». | STRING | خیر | "standard"<br>"fast" |
| `watermark` | آیا واترمارک «AI generated» به تصاویر اضافه شود. پیش‌فرض: false. | BOOLEAN | خیر | false<br>true |
| `crop_layers` | هندسه‌ی خروجی‌های دسته‌ای layers/masks (خروجی layer_stack تحت تأثیر قرار نمی‌گیرد و همیشه دقیق/بدون حاشیه‌ی اضافه است). حالت تمام‌بوم (full canvas): هر لایه روی بومی به اندازه‌ی بوم پایه، در موقعیت کادر محدودکننده‌ی خودش قرار می‌گیرد؛ می‌توانید مستقیماً با ImageCompositeMasked دوباره ترکیب کنید. حالت اندازه‌ی حداقل (minimal size): هر لایه به کادر محدودکننده‌ی خودش برش می‌خورد (برای دسته‌بندی تا بزرگ‌ترین لایه padding می‌شود)؛ تنسورها بسیار کوچک‌ترند؛ با استفاده از خروجی `bboxes` و گره Layers From Bounding Boxes جای‌گذاری را بازسازی کنید. پیش‌فرض: false (full canvas). | BOOLEAN | خیر | false (full canvas)<br>true (minimal size) |

توجه: تصویر ورودی باید یک تصویر واحد باشد؛ حالت دسته‌ای (batch) پشتیبانی نمی‌شود. تصویر باید حداقل ۵۱۲×۵۱۲ پیکسل باشد و نسبت ابعاد آن بین ۱:۱۶ و ۱۶:۱ قرار داشته باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `base_image` | تصویر پایه (صفحه‌ی پس‌زمینه) که لایه‌ها روی آن قرار می‌گیرند. | IMAGE |
| `base_mask` | شفافیت تصویر پایه (۱ = شفاف، طبق قرارداد LoadImage)؛ در حال حاضر همیشه کاملاً مات است. | MASK |
| `layers` | لایه‌های شفاف به ترتیب از پایین به بالا. حالت تمام‌بوم: روی یک بوم سیاه به اندازه‌ی بوم پایه، در موقعیت کادر محدودکننده‌ی خودشان قرار می‌گیرند. حالت اندازه‌ی حداقل: به کادر محدودکننده‌ی خودشان برش می‌خورند، با مبدأ در گوشه‌ی بالا-چپ، و تا اندازه‌ی بزرگ‌ترین لایه padding می‌شوند. | IMAGE |
| `masks` | شفافیت هر لایه، هم‌اندیس با دسته‌ی لایه‌ها (۱ = شفاف، طبق قرارداد LoadImage). برای ترکیب به سبک ImageCompositeMasked، ابتدا InvertMask را اضافه کنید. | MASK |
| `bboxes` | برای هر لایه یک کادر جای‌گذاری، هم‌اندیس با دسته‌ی لایه‌ها (هر دو را به همراه ماسک‌ها به Layers From Bounding Boxes بدهید تا جای‌گذاری هر لایه بازسازی شود): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` ناحیه‌ی محتوایی لایه درون قاب خودش است؛ این ناحیه روی بوم در موقعیت کادر به‌علاوه‌ی آن offset قرار می‌گیرد. | BOUNDING_BOX |
| `layer_stack` | سند لایه‌ی آماده‌ی ویرایش برای Create Layered Image: صفحه‌ی پایه به‌همراه هر عنصر به‌عنوان یک لایه‌ی مستقل، نام‌دار و دقیقاً برش‌خورده، در موقعیت واقعی و ترتیب چیدمان خود. مستقیماً متصل کنید یا با Add Layer گسترش دهید. | LAYERS |
