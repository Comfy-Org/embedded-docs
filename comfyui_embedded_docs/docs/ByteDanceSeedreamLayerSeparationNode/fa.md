# ByteDance Seedream ۵.۰ Pro جداسازی لایه

ByteDance Seedream 5.0 Pro Layer Separation یک تصویر را به یک پلیت پس‌زمینه به‌همراه حداکثر ۱۶ لایهٔ شفاف قابل جابه‌جایی تجزیه می‌کند؛ هر لایه دارای ترتیب چیدمان، کادر محدودکننده، نام و توضیحات است. خروجی آن شامل پس‌زمینه، تصاویر هر لایه همراه با ماسک‌ها، کادرهای جای‌گذاری و یک پشتهٔ لایهٔ آمادهٔ ویرایش است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که باید تفکیک شود. دقیقاً یک تصویر، حداقل ۵۱۲×۵۱۲ پیکسل، نسبت ابعاد بین ۱:۱۶ و ۱۶:۱. ورودی‌های بزرگ‌تر از حدود ۴ مگاپیکسل پیش از بارگذاری مقیاس‌کوچک می‌شوند. | IMAGE | بله | یک تصویر |
| `prompt` | نحوهٔ تفکیک تصویر. برای تشخیص و تفکیک خودکار همهٔ عناصر اصلی، خالی بگذارید. برای کنترل تفکیک، عناصر را با زبان طبیعی توصیف کنید، یا با تگ‌های `<bbox>left top right bottom</bbox>` (مختصات هزارم ۰ تا ۱۰۰۰) نواحی دقیق را هدف بگیرید. پیش‌فرض: رشتهٔ خالی. | STRING | بله | متن چندخطی |
| `size` | سطح وضوح خروجی. مقدار "auto" از اندازهٔ تصویر ورودی تبعیت می‌کند (محدود به بازهٔ 1K-2K). پیش‌فرض: "auto". | COMBO | بله | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `seed` | بذری که برای تولید استفاده می‌شود. پیش‌فرض: 0. | INT | بله | 0 تا 2147483647 |
| `prompt_optimization` | حالت بهینه‌سازی پرامپت: "standard" کیفیت بالاتر و "fast" زمان تولید کوتاه‌تر می‌دهد. پیش‌فرض: "standard". | COMBO | خیر | "standard"<br>"fast" |
| `watermark` | اینکه واترمارک «تولیدشده با هوش مصنوعی» به تصاویر افزوده شود یا نه. پیش‌فرض: false. | BOOLEAN | خیر | false<br>true |
| `crop_layers` | هندسهٔ خروجی‌های دسته‌ای لایه‌ها/ماسک‌ها (`layer_stack` تحت تأثیر قرار نمی‌گیرد و همیشه دقیقاً برش‌خورده است). بوم کامل: هر لایه روی یک بوم هم‌اندازهٔ پایه در موقعیت کادر محدودکننده‌اش قرار می‌گیرد — مستقیماً با ImageCompositeMasked بازترکیب کنید. اندازهٔ کمینه: هر لایه تا کادر محدودکننده‌اش برش می‌خورد (برای دسته‌بندی تا بزرگ‌ترین لایه پُر می‌شود) — تنسورها بسیار کوچک‌تر؛ جای‌گذاری را با Layers From Bounding Boxes و با استفاده از خروجی `bboxes` بازسازی کنید. پیش‌فرض: false (بوم کامل). | BOOLEAN | خیر | false (بوم کامل)<br>true (اندازهٔ کمینه) |

توجه: ورودی `image` باید یک تصویر واحد باشد؛ دسته‌ها پشتیبانی نمی‌شوند. تصویر باید حداقل ۵۱۲×۵۱۲ پیکسل و نسبت ابعاد آن بین ۱:۱۶ و ۱۶:۱ باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `base_image` | تصویر پایه (پلیت پس‌زمینه) که لایه‌ها روی آن چیده می‌شوند. | IMAGE |
| `base_mask` | شفافیت تصویر پایه (۱ = شفاف، قرارداد LoadImage)؛ در حال حاضر همیشه کاملاً مات است. | MASK |
| `layers` | لایه‌های شفاف مرتب‌شده از پایین به بالا. حالت بوم کامل: روی یک بوم مشکی هم‌اندازهٔ پایه در موقعیت کادر محدودکننده‌شان قرار می‌گیرند. حالت اندازهٔ کمینه: تا کادر محدودکننده‌شان برش می‌خورند، به بالا-چپ لنگر می‌شوند و تا بزرگ‌ترین لایه پُر می‌شوند. | IMAGE |
| `masks` | شفافیت هر لایه، هم‌ایه با اندیس دستهٔ `layers` (۱ = شفاف، قرارداد LoadImage). برای ترکیب به سبک ImageCompositeMasked، ابتدا InvertMask را اضافه کنید. | MASK |
| `bboxes` | یک کادر جای‌گذاری برای هر لایه، هم‌ایه با اندیس دستهٔ `layers` (هر دو خروجی `layers` و `bboxes` را به‌همراه `masks` به Layers From Bounding Boxes بدهید تا جای‌گذاری هر لایه بازسازی شود): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. مقدار `content_rect = [left, top, width, height]` ناحیهٔ محتوای لایه در چارچوب خودش است؛ روی بوم در موقعیت کادر به‌علاوهٔ آن افست قرار می‌گیرد. | BOUNDING_BOX |
| `layer_stack` | سند لایهٔ آمادهٔ ویرایش برای Create Layered Image: پلیت پایه به‌همراه هر عنصر به‌عنوان لایه‌ای نام‌دار و دقیقاً برش‌خورده در موقعیت واقعی و ترتیب چیدمان خودش. مستقیماً متصل کنید، یا با Add Layer گسترش دهید. | LAYERS |
