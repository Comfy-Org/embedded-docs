# ByteDance Seedream ۵.۰ Pro جداسازی لایه

ByteDance Seedream 5.0 Pro Layer Separation یک تصویر را به یک صفحه پس‌زمینه به‌همراه حداکثر ۱۶ لایه شفاف تجزیه می‌کند؛ هر لایه دارای ترتیب چیدمان، جعبه مرزبندی، نام و توضیحات مخصوص به خود است. این گره پس‌زمینه، تصاویر هر لایه به‌همراه ماسک‌ها، جعبه‌های جایگذاری و یک پشته لایه آماده ویرایش را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویری که باید جدا شود. دقیقاً یک تصویر، حداقل ۵۱۲×۵۱۲ پیکسل، با نسبت ابعاد بین ۱:۱۶ و ۱۶:۱. ورودی‌های بزرگ‌تر از حدود ۴ مگاپیکسل پیش از بارگذاری کوچک‌سازی می‌شوند. | IMAGE | بله | تک‌تصویر |
| `پرامپت` | نحوه جداسازی تصویر. برای تشخیص خودکار و جداسازی همه عناصر اصلی، خالی بگذارید. برای کنترل جداسازی، عناصر را به زبان طبیعی توصیف کنید، یا با برچسب‌های `<bbox>left top right bottom</bbox>` (مختصات در هزار با بازه ۰ تا ۱۰۰۰) مناطق دقیق را هدف بگیرید. پیش‌فرض: رشته خالی. | STRING | بله | متن چندخطی |
| `اندازه` | سطح وضوح خروجی. «auto» اندازه تصویر ورودی را دنبال می‌کند (در بازه ۱K تا ۲K محدود می‌شود). پیش‌فرض: «auto». | COMBO | بله | "auto"<br>"1K"<br>"1.5K"<br>"2K" |
| `بذر` | مقدار seed برای تولید. پیش‌فرض: ۰. | INT | بله | 0 تا 2147483647 |
| `بهینه‌سازی پرامپت` | حالت بهینه‌سازی پرامپت: «standard» کیفیت بالاتری می‌دهد، «fast» زمان تولید کوتاه‌تری. پیش‌فرض: «standard». | COMBO | خیر | "standard"<br>"fast" |
| `واترمارک` | مشخص می‌کند که آیا به تصاویر واترمارک «AI generated» اضافه شود یا خیر. پیش‌فرض: false. | BOOLEAN | خیر | false<br>true |
| `برش لایه‌ها` | هندسه خروجی‌های دسته‌ای لایه‌ها/ماسک‌ها (layer_stack تحت تأثیر قرار نمی‌گیرد و همیشه دقیقاً منطبق بر محتوا است). تمام بوم: هر لایه روی یک بوم با اندازه پایه در موقعیت جعبه مرزبندی خود قرار می‌گیرد - می‌توانید مستقیماً با ImageCompositeMasked دوباره ترکیب کنید. اندازه حداقل: هر لایه تا جعبه مرزبندی خود برش می‌خورد (برای دسته‌کردن تا بزرگ‌ترین لایه padding می‌شود) - تنسورهای بسیار کوچک‌تر؛ جایگذاری را با استفاده از Layers From Bounding Boxes و خروجی bboxes بازسازی کنید. پیش‌فرض: false (تمام بوم). | BOOLEAN | خیر | false (تمام بوم)<br>true (اندازه حداقل) |

توجه: ورودی `image` باید یک تصویر واحد باشد؛ دسته‌ها (batches) پشتیبانی نمی‌شوند. تصویر باید حداقل ۵۱۲×۵۱۲ پیکسل با نسبت ابعاد بین ۱:۱۶ و ۱۶:۱ باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصویر پایه` | تصویر پایه (صفحه پس‌زمینه) که لایه‌ها روی آن سوار می‌شوند. | IMAGE |
| `ماسک پایه` | شفافیت تصویر پایه (۱ = شفاف، طبق قرارداد LoadImage)؛ در حال حاضر همیشه کاملاً مات است. | MASK |
| `لایه‌ها` | لایه‌های شفاف به‌ترتیب از پایین به بالا. حالت تمام بوم: روی یک بوم سیاه با اندازه پایه در موقعیت جعبه مرزبندی خود قرار می‌گیرند. حالت اندازه حداقل: تا جعبه مرزبندی خود برش می‌خورند، گوشه بالا-چپ لنگر انداخته و تا بزرگ‌ترین لایه padding می‌شوند. | IMAGE |
| `ماسک‌ها` | شفافیت هر لایه، هم‌شاخص با دسته لایه‌ها (۱ = شفاف، طبق قرارداد LoadImage). برای ترکیب به سبک ImageCompositeMasked، ابتدا InvertMask را اضافه کنید. | MASK |
| `جعبه‌های مرزی` | به‌ازای هر لایه یک جعبه جایگذاری، هم‌شاخص با دسته لایه‌ها (هر دو را به‌همراه ماسک‌ها به Layers From Bounding Boxes بدهید تا جایگذاری هر لایه بازسازی شود): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]` ناحیه محتوای لایه درون قاب خودش است؛ این ناحیه روی بوم در موقعیت جعبه به‌علاوه آن آفست قرار می‌گیرد. | BOUNDING_BOX |
| `پشته لایه` | سند لایه‌ای آماده ویرایش برای Create Layered Image: صفحه پایه به‌همراه هر عنصر به‌عنوان یک لایه نام‌گذاری‌شده و دقیقاً برش‌خورده، در موقعیت واقعی و ترتیب چیدمان خود. مستقیماً متصل کنید، یا با Add Layer گسترش دهید. | LAYERS |
