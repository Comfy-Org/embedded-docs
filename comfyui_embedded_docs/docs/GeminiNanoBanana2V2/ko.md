# Nano Banana 2

이 노드는 Gemini 3.1 Flash Image 모델을 통해 Google의 Vertex AI API에 텍스트 프롬프트를 전송하여 이미지를 생성하거나 편집합니다. 설명을 기반으로 새 이미지를 생성하거나 선택적 참조 이미지를 사용하여 기존 이미지를 수정합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 생성할 이미지 또는 적용할 편집 내용을 설명하는 텍스트 프롬프트입니다. 모델이 따라야 하는 제약 조건, 스타일 또는 세부 사항을 포함해야 합니다. 비어 있으면 안 됩니다. | STRING | 예 | N/A |
| `모델` | 이미지 생성에 사용할 Gemini 모델을 선택합니다. 이 매개변수에는 해상도, 화면 비율, 추론 수준 및 참조 입력에 대한 추가 하위 매개변수가 포함됩니다. | COMBO | 예 | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `시드` | 시드가 특정 값으로 고정되면 모델은 반복 요청에 동일한 응답을 제공하기 위해 최선을 다합니다. 결정적 출력은 보장되지 않습니다. 또한 모델 또는 온도와 같은 매개변수 설정을 변경하면 동일한 시드 값을 사용하더라도 응답에 변형이 발생할 수 있습니다. 기본적으로 임의의 시드 값이 사용됩니다. (기본값: 42) | INT | 예 | 0 ~ 18446744073709551615 |
| `응답 모달리티` | 응답 형식을 결정합니다. IMAGE는 이미지만 반환하고, IMAGE+TEXT는 이미지와 텍스트 응답을 반환합니다. (기본값: IMAGE) 고급 매개변수입니다. | COMBO | 예 | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `시스템 프롬프트` | AI의 동작을 규정하는 기본 지침입니다. 기본값은 모델이 항상 이미지를 생성하도록 지시하는 내장 프롬프트입니다. 고급 매개변수입니다. | STRING | 아니요 | N/A |
| `temperature` | 생성 시 무작위성을 제어합니다. 값이 낮을수록 더 집중적이고 결정적입니다. (기본값: 1.0) 고급 매개변수입니다. | FLOAT | 아니요 | 0.0 ~ 2.0 (단계 0.01) |
| `top_p` | 핵 샘플링 임계값입니다. 값이 낮을수록 더 집중적이고, 높을수록 더 다양합니다. (기본값: 0.95) 고급 매개변수입니다. | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.01) |

### Nano Banana 2 (Gemini 3.1 Flash Image) 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 'auto'로 설정하면 입력 이미지의 화면 비율과 일치하며, 이미지가 제공되지 않으면 일반적으로 16:9 비율의 이미지가 생성됩니다. (기본값: auto) | COMBO | 예 | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"`<br>`"1:4"`<br>`"4:1"`<br>`"8:1"`<br>`"1:8"` |
| `resolution` | 대상 출력 해상도입니다. | COMBO | 예 | `"1K"`<br>`"2K"`<br>`"4K"` |
| `thinking_level` | 모델이 사용할 추론 수준을 선택합니다. | COMBO | 예 | `"MINIMAL"`<br>`"HIGH"` |

### Nano Banana 2 Lite 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 'auto'로 설정하면 입력 이미지의 화면 비율과 일치하며, 이미지가 제공되지 않으면 일반적으로 16:9 비율의 이미지가 생성됩니다. (기본값: auto) | COMBO | 예 | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"`<br>`"1:4"`<br>`"4:1"`<br>`"8:1"`<br>`"1:8"` |
| `resolution` | 대상 출력 해상도입니다. | COMBO | 예 | `"1K"` |
| `thinking_level` | 모델이 사용할 추론 수준을 선택합니다. | COMBO | 예 | `"MINIMAL"`<br>`"HIGH"` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 선택적 참조 이미지입니다. 총 최대 14개까지 사용할 수 있습니다. 확장 가능한 슬롯: `image_1`부터 `image_14`까지 연결할 수 있습니다. | IMAGE | 아니요 | 0 ~ 14 개 이미지 |
| `files` | 모델에 컨텍스트로 제공할 선택적 파일입니다. Gemini Generate Content Input Files 노드의 입력을 받습니다. | GEMINI_INPUT_FILES | 아니요 | N/A |

**참고:** `images` 입력에는 최대 14개의 참조 이미지를 연결할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성되거나 편집된 이미지입니다. | IMAGE |
| `STRING` | 모델이 생성한 텍스트 설명 또는 캡션입니다. | STRING |
| `사고 이미지` | 모델의 추론 과정에서 생성된 첫 번째 이미지입니다. `thinking_level`이 HIGH이고 IMAGE+TEXT 방식인 경우에만 사용할 수 있습니다. | IMAGE |

**참고:** `response_modalities`가 `IMAGE`로 설정된 경우 `STRING` 출력은 비어 있습니다.
