# نانا موز 2

تقوم هذه العقدة بتوليد الصور أو تعديلها عن طريق إرسال موجه نصي إلى واجهة برمجة تطبيقات Google Vertex AI عبر نماذج Gemini 3.1 Flash Image. وهي تنشئ صورًا جديدة من وصف نصي أو تعدّل صورًا موجودة باستخدام صور مرجعية اختيارية.
