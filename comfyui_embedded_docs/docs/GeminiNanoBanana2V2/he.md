# Nano Banana 2

צומת זה יוצר או עורך תמונות על ידי שליחת הנחיית טקסט אל ה-API של Vertex AI של Google דרך מודלי התמונות של Gemini. הוא יוצר תמונות חדשות מתיאור או משנה תמונות קיימות באמצעות תמונות עזר אופציונליות.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | בוחר את מודל התמונות של Gemini שיש להשתמש בו. המודל הנבחר קובע את אפשרויות הרזולוציה הזמינות ואת הקלטים הספציפיים למודל. | DYNAMIC_COMBO | כן | `"Gemini Nano Banana 2.1"`<br>`"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `prompt` | הנחיית טקסט המתארת את התמונה שיש ליצור או את העריכות שיש להחיל. יש לכלול כל אילוץ, סגנון או פרט שעל המודל לפעול לפיהם. אסור שיהיה ריק. (ברירת מחדל: ריק) | STRING | כן | N/A |
| `seed` | כאשר ה-seed מקובע לערך מסוים, המודל עושה מאמץ מיטבי לספק את אותה תגובה לבקשות חוזרות. פלט דטרמיניסטי אינו מובטח. כמו כן, שינוי המודל או הגדרות פרמטרים, כגון temperature, יכול לגרום לשינויים בתגובה גם כאשר משתמשים באותו ערך seed. כברירת מחדל, משתמשים בערך seed אקראי. (ברירת מחדל: 42) | INT | כן | 0 to 18446744073709551615 |
| `response_modalities` | קובע את פורמט התגובה. IMAGE מחזיר תמונה בלבד; IMAGE+TEXT מחזיר תמונה ותגובת טקסט. (ברירת מחדל: IMAGE) פרמטר מתקדם. | COMBO | כן | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `system_prompt` | הוראות בסיס שקובעות את התנהגות ה-AI. ברירת המחדל היא הנחיה מובנית שמורה למודל תמיד להפיק תמונה. פרמטר מתקדם. | STRING | לא | N/A |
| `temperature` | שולט ברמת האקראיות ביצירה. ערך נמוך יותר ממוקד/דטרמיניסטי יותר. (ברירת מחדל: 1.0) פרמטר מתקדם. | FLOAT | לא | 0.0 to 2.0 (step 0.01) |
| `top_p` | סף דגימת גרעין (Nucleus sampling). ערך נמוך יותר ממוקד יותר, גבוה יותר מגוון יותר. (ברירת מחדל: 0.95) פרמטר מתקדם. | FLOAT | לא | 0.0 to 1.0 (step 0.01) |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `IMAGE` | התמונה שנוצרה או נערכה. | IMAGE |
| `STRING` | תיאור טקסטואלי או כיתוב שנוצר על ידי המודל. ריק כאשר לא מוחזר טקסט, למשל כאשר `response_modalities` מוגדר ל-`IMAGE`. | STRING |
| `thought_image` | התמונה הראשונה מתהליך החשיבה של המודל. זמין רק עם מודאליות IMAGE+TEXT. | IMAGE |

**הערה:** הפלט `STRING` ריק כאשר `response_modalities` מוגדר ל-`IMAGE`. אם המודל אינו יוצר תמונה במצב זה, הצומת מעלה שגיאה שמציעה לעבור ל-IMAGE+TEXT כדי לראות את תהליך החשיבה של המודל.
