# Nano Banana 2

Этот узел генерирует или редактирует изображения, отправляя текстовый запрос в API Google Vertex AI через модели генерации изображений Gemini. Он создаёт новые изображения по описанию или изменяет существующие изображения с использованием необязательных эталонных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Выбирает модель генерации изображений Gemini. Выбранная модель определяет доступные параметры разрешения и входные параметры, специфичные для модели. | DYNAMIC_COMBO | Да | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `prompt` | Текстовый запрос, описывающий изображение для генерации или правки, которые нужно применить. Укажите все ограничения, стили или детали, которым должна следовать модель. Не должен быть пустым. (по умолчанию: пусто) | STRING | Да | N/A |
| `seed` | Когда seed зафиксирован на определённом значении, модель прилагает все усилия, чтобы дать одинаковый ответ на повторные запросы. Детерминированный результат не гарантируется. Кроме того, изменение модели или параметров, например температуры, может вызвать различия в ответе даже при одинаковом seed. По умолчанию используется случайное значение seed. (по умолчанию: 42) | INT | Да | 0 до 18446744073709551615 |
| `response_modalities` | Определяет формат ответа. IMAGE возвращает только изображение; IMAGE+TEXT возвращает изображение и текстовый ответ. (по умолчанию: IMAGE) Расширенный параметр. | COMBO | Да | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию используется встроенный запрос, который предписывает модели всегда создавать изображение. Расширенный параметр. | STRING | Нет | N/A |
| `temperature` | Управляет случайностью генерации. Чем ниже значение, тем более сфокусированным и детерминированным будет результат. (по умолчанию: 1.0) Расширенный параметр. | FLOAT | Нет | 0.0 до 2.0 (step 0.01) |
| `top_p` | Порог семплирования по ядру (nucleus sampling). Чем ниже значение, тем более сфокусирован результат, чем выше — тем более разнообразный. (по умолчанию: 0.95) Расширенный параметр. | FLOAT | Нет | 0.0 до 1.0 (step 0.01) |

### Входы Nano Banana 2 (Gemini 3.1 Flash Image)

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Если задано значение 'auto', соотношение сторон соответствует входному изображению; если изображение не предоставлено, обычно генерируется изображение с соотношением сторон 16:9. (по умолчанию: auto) | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"`<br>`"1:4"`<br>`"4:1"`<br>`"8:1"`<br>`"1:8"` |
| `resolution` | Целевое разрешение выходного изображения. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"` |
| `thinking_level` | Выбирает уровень рассуждений, используемый моделью. | COMBO | Да | `"MINIMAL"`<br>`"HIGH"` |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные эталонные изображения. Всего до 14 изображений. Расширяемый слот: подключайте `image_1` через `image_14`. | IMAGE | Нет | 0 до 14 images |
| `files` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | Нет | N/A |

**Примечание:** К входу `images` можно подключить не более 14 эталонных изображений; превышение этого лимита вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение. | IMAGE |
| `STRING` | Текстовое описание или подпись, сгенерированные моделью. Пусто, если текст не возвращается, например когда `response_modalities` установлено в `IMAGE`. | STRING |
| `thought_image` | Первое изображение из процесса рассуждений модели. Доступно только при `thinking_level` HIGH и модальности IMAGE+TEXT. | IMAGE |

**Примечание:** Выход `STRING` пуст, когда `response_modalities` установлено в `IMAGE`. Если модель не генерирует изображение в этом режиме, узел выдаёт ошибку с предложением переключиться на IMAGE+TEXT, чтобы просмотреть ход рассуждений модели.
