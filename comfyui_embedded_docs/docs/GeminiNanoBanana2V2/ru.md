# Nano Banana 2

Этот узел генерирует или редактирует изображения, отправляя текстовый запрос в Google Vertex AI API через модели Gemini 3.1 Flash Image. Он создает новые изображения по описанию или изменяет существующие изображения с использованием необязательных референсных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Выбирает модель Gemini для генерации изображений. Этот параметр включает дополнительные подпараметры для разрешения, соотношения сторон, уровня мышления и референсных входов. | DYNAMIC_COMBO | Да | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `prompt` | Текстовый запрос, описывающий изображение для генерации или изменения, которые нужно применить. Включите любые ограничения, стили или детали, которым должна следовать модель. Не должен быть пустым. | STRING | Да | N/A |
| `seed` | Когда сид зафиксирован на определенном значении, модель прилагает все усилия, чтобы обеспечить одинаковый ответ на повторные запросы. Детерминированный вывод не гарантируется. Кроме того, изменение модели или параметров, таких как температура, может вызывать различия в ответе, даже если вы используете одно и то же значение сида. По умолчанию используется случайное значение сида. (по умолчанию: 42) | INT | Да | 0–18446744073709551615 |
| `response_modalities` | Определяет формат ответа. IMAGE возвращает только изображение; IMAGE+TEXT возвращает изображение и текстовый ответ. (по умолчанию: IMAGE) Расширенный параметр. | COMBO | Да | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `system_prompt` | Базовые инструкции, определяющие поведение ИИ. По умолчанию используется встроенный промпт, предписывающий модели всегда создавать изображение. Расширенный параметр. | STRING | Нет | N/A |
| `temperature` | Управляет случайностью генерации. Более низкое значение — более сфокусированный/детерминированный результат. (по умолчанию: 1.0) Расширенный параметр. | FLOAT | Нет | 0.0–2.0 (шаг 0.01) |
| `top_p` | Порог семплирования по ядру (nucleus sampling). Более низкое значение — более сфокусированный результат, более высокое — более разнообразный. (по умолчанию: 0.95) Расширенный параметр. | FLOAT | Нет | 0.0–1.0 (шаг 0.01) |

### Nano Banana 2 (Gemini 3.1 Flash Image) Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Если установлено значение 'auto', соответствует соотношению сторон вашего входного изображения; если изображение не предоставлено, обычно генерируется изображение с соотношением сторон 16:9. (по умолчанию: auto) | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"`<br>`"21:9"`<br>`"1:4"`<br>`"4:1"`<br>`"8:1"`<br>`"1:8"` |
| `resolution` | Целевое разрешение выходного изображения. | COMBO | Да | `"1K"`<br>`"2K"`<br>`"4K"` |
| `thinking_level` | Выбирает уровень мышления, используемый моделью. | COMBO | Да | `"MINIMAL"`<br>`"HIGH"` |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные референсные изображения. Всего до 14 изображений. Расширяемый слот: подключайте `image_1` через `image_14`. | IMAGE | Нет | от 0 до 14 изображений |
| `files` | Необязательные файлы для использования в качестве контекста для модели. Принимает входные данные от узла Gemini Generate Content Input Files. | GEMINI_INPUT_FILES | Нет | N/A |

**Примечание:** К входу `images` можно подключить максимум 14 референсных изображений.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение. | IMAGE |
| `STRING` | Текстовое описание или подпись, сгенерированная моделью. | STRING |
| `thought_image` | Первое изображение из процесса мышления модели. Доступно только при уровне мышления HIGH и модальности IMAGE+TEXT. | IMAGE |

**Примечание:** Выход `STRING` пуст, когда для `response_modalities` установлено значение `IMAGE`.
