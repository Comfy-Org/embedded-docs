# Nano Banana 2

このノードは、テキストプロンプトを Google の Vertex AI API に送信し、Gemini 3.1 Flash Image モデルを通じて画像を生成または編集します。説明文から新しい画像を作成したり、オプションの参照画像を使って既存の画像を修正したりできます。
