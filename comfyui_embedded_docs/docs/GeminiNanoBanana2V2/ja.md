# Nano Banana 2

このノードは、Gemini 画像モデルを介してテキストプロンプトを Google Vertex AI API に送信し、画像を生成または編集します。説明文から新しい画像を作成したり、オプションの参照画像を使用して既存の画像を変更したりします。
