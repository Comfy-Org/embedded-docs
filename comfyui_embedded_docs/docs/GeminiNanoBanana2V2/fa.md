# نانو بنانا ۲

این گره با ارسال یک پرامپت متنی به Vertex AI API گوگل از طریق مدل‌های تصویری Gemini، تصاویر را تولید یا ویرایش می‌کند. این گره از روی یک توصیف، تصاویر جدید می‌سازد یا با استفاده از تصاویر مرجع اختیاری، تصاویر موجود را اصلاح می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل تصویری Gemini مورد استفاده را انتخاب می‌کند. مدل انتخابی تعیین‌کننده گزینه‌های وضوح موجود و ورودی‌های مختص آن مدل است. | DYNAMIC_COMBO | بله | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `پرامپت` | پرامپت متنی که تصویر موردنظر برای تولید یا ویرایش‌های موردنظر را توصیف می‌کند. هرگونه محدودیت، سبک یا جزئیاتی که مدل باید دنبال کند را شامل شود. نباید خالی باشد. (پیش‌فرض: خالی) | STRING | بله | N/A |
| `بذر` | هنگامی که seed به یک مقدار مشخص ثابت شود، مدل برای ارائه پاسخ یکسان در درخواست‌های تکراری نهایت تلاش خود را می‌کند. خروجی قطعی تضمین نمی‌شود. همچنین تغییر مدل یا تنظیمات پارامترهایی مانند temperature می‌تواند حتی با استفاده از همان مقدار seed باعث تغییر در پاسخ شود. به‌طور پیش‌فرض، از یک مقدار seed تصادفی استفاده می‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 18446744073709551615 |
| `حالت‌های پاسخ` | قالب پاسخ را تعیین می‌کند. IMAGE فقط یک تصویر برمی‌گرداند؛ IMAGE+TEXT یک تصویر و یک پاسخ متنی برمی‌گرداند. (پیش‌فرض: IMAGE) پارامتر پیشرفته. | COMBO | بله | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `پرامپت سیستمی` | دستورالعمل‌های بنیادینی که رفتار هوش مصنوعی را تعیین می‌کنند. به‌طور پیش‌فرض شامل یک دستور داخلی است که به مدل می‌گوید همیشه تصویر تولید کند. پارامتر پیشرفته. | STRING | خیر | N/A |
| `temperature` | تصادفی بودن در تولید را کنترل می‌کند. مقادیر پایین‌تر باعث تمرکز/قطعی بودن بیشتر می‌شود. (پیش‌فرض: 1.0) پارامتر پیشرفته. | FLOAT | خیر | 0.0 تا 2.0 (step 0.01) |
| `top_p` | آستانه نمونه‌برداری هسته‌ای (Nucleus sampling). مقادیر پایین‌تر متمرکزتر و مقادیر بالاتر متنوع‌تر هستند. (پیش‌فرض: 0.95) پارامتر پیشرفته. | FLOAT | خیر | 0.0 تا 1.0 (step 0.01) |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | تصویر(های) مرجع اختیاری. حداکثر 14 تصویر در مجموع. اسلات قابل افزایش: `image_1` تا `image_14` را متصل کنید. | IMAGE | خیر | 0 تا 14 تصویر |
| `files` | فایل(های) اختیاری برای استفاده به عنوان زمینه (context) مدل. ورودی‌ها را از گره Gemini Generate Content Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر | N/A |

**نکته:** حداکثر 14 تصویر مرجع می‌توانند به ورودی `images` متصل شوند؛ عبور از این محدودیت خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر تولیدشده یا ویرایش‌شده. | IMAGE |
| `STRING` | توضیح متنی یا عنوانی که توسط مدل تولید شده است. زمانی که هیچ متنی بازگردانده نشود، مانند وقتی که `response_modalities` روی `IMAGE` تنظیم شده باشد، خالی است. | STRING |
| `تصویر تفکر` | اولین تصویر از فرآیند تفکر مدل. فقط با `thinking_level` برابر HIGH و حالت IMAGE+TEXT در دسترس است. | IMAGE |

**نکته:** خروجی `STRING` زمانی که `response_modalities` روی `IMAGE` تنظیم شود خالی است. اگر مدل در این حالت تصویری تولید نکند، گره خطایی صادر می‌کند که پیشنهاد می‌دهد برای مشاهده استدلال مدل به حالت IMAGE+TEXT تغییر دهید.
