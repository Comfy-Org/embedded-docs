# نانو بنانا ۲

این گره با ارسال یک پرامپت متنی به API Vertex AI گوگل از طریق مدل‌های Gemini 3.1 Flash Image، تصاویر را تولید یا ویرایش می‌کند. این گره از روی یک توضیح، تصاویر جدید می‌سازد یا با استفاده از تصاویر مرجع اختیاری، تصاویر موجود را ویرایش می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | متن پرامپتی که تصویر موردنظر برای تولید یا تغییرات موردنظر برای اعمال را توصیف می‌کند. هرگونه محدودیت، سبک یا جزئیاتی که مدل باید دنبال کند را شامل شود. نباید خالی باشد. | STRING | بله | N/A |
| `مدل` | مدل Gemini مورد استفاده برای تولید تصویر را انتخاب می‌کند. این پارامتر شامل زیرپارامترهای اضافی برای رزولوشن، نسبت ابعاد، سطح تفکر و ورودی‌های مرجع است. | COMBO | بله | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br>`"Nano Banana 2 Lite"` |
| `بذر` | وقتی `seed` روی مقدار مشخصی ثابت شود، مدل بهترین تلاش خود را می‌کند تا برای درخواست‌های تکراری پاسخ یکسانی ارائه دهد؛ با این حال خروجی قطعی تضمین نمی‌شود. همچنین تغییر مدل یا تنظیمات پارامترهایی مانند `temperature` می‌تواند حتی با استفاده از مقدار seed یکسان، تغییراتی در پاسخ ایجاد کند. به‌طور پیش‌فرض از یک مقدار seed تصادفی استفاده می‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 18446744073709551615 |
| `حالت‌های پاسخ` | قالب پاسخ را تعیین می‌کند. IMAGE فقط یک تصویر برمی‌گرداند؛ IMAGE+TEXT یک تصویر و یک پاسخ متنی برمی‌گرداند. (پیش‌فرض: IMAGE) پارامتر پیشرفته. | COMBO | بله | `"IMAGE"`<br>`"IMAGE+TEXT"` |
| `پرامپت سیستمی` | دستورالعمل‌های بنیادینی که رفتار هوش مصنوعی را تعیین می‌کنند. به‌طور پیش‌فرض شامل یک پرامپت داخلی است که به مدل دستور می‌دهد همیشه تصویر تولید کند. پارامتر پیشرفته. | STRING | خیر | N/A |
| `temperature` | میزان تصادفی‌بودن در تولید را کنترل می‌کند. مقدار کمتر متمرکزتر/قطعی‌تر است. (پیش‌فرض: 1.0) پارامتر پیشرفته. | FLOAT | خیر | 0.0 تا 2.0 (گام 0.01) |
| `top_p` | آستانه نمونه‌برداری هسته‌ای. مقدار کمتر متمرکزتر و مقدار بیشتر متنوع‌تر است. (پیش‌فرض: 0.95) پارامتر پیشرفته. | FLOAT | خیر | 0.0 تا 1.0 (گام 0.01) |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | تصویر(های) مرجع اختیاری. در مجموع حداکثر ۱۴ تصویر. اسلات قابل افزایش: `image_1` تا `image_14` را وصل کنید. | IMAGE | خیر | 0 تا 14 تصویر |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌های گره Gemini Generate Content Input Files را می‌پذیرد. | GEMINI_INPUT_FILES | خیر | N/A |

**نکته:** حداکثر ۱۴ تصویر مرجع می‌توانند به ورودی `images` متصل شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر تولیدشده یا ویرایش‌شده. | IMAGE |
| `STRING` | توضیح یا کپشن متنی تولیدشده توسط مدل. | STRING |
| `thought_image` | اولین تصویر از فرایند تفکر مدل. فقط با thinking_level برابر HIGH و حالت IMAGE+TEXT در دسترس است. | IMAGE |

**نکته:** خروجی `STRING` زمانی که `response_modalities` روی `IMAGE` تنظیم شده باشد خالی است.
