# CLIPマージシンプル

`CLIPMergeSimple` は、2つのCLIPテキストエンコーダーモデルを1つにマージします。最初のCLIPモデルをベースとしてクローンし、2番目のCLIPモデルから取得した加重パラメータパッチを適用するため、結果は両方のモデルの特徴を組み合わせたものになります。`ratio` 設定は各モデルの寄与度を制御し、デフォルトの1.0では最初のモデルがそのまま使用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip1` | 最初のCLIPモデル。クローンされ、マージのベースモデルとして使用されます。 | CLIP | はい | — |
| `clip2` | 2番目のCLIPモデル。キーが `.position_ids` または `.logit_scale` で終わるパッチを除き、そのキーパッチがベースモデルに適用されます。 | CLIP | はい | — |
| `ratio` | 2つのモデルの相対的な強さを制御します。ベースモデル（`clip1`）は `ratio` に等しい強さを維持し、`clip2` のパッチは `1.0 - ratio` の強さで適用されます。デフォルトの1.0では出力は `clip1` と等しくなります。値を下げると `clip2` がより多くブレンドされ、0.0では `clip2` のパッチが完全な強さで適用されます。 | FLOAT | はい | 0.0 to 1.0 (default: 1.0, step: 0.01) |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `clip` | マージされたCLIPモデル。`clip1` のクローンに、`ratio` に従って `clip2` のパッチが適用されたものです。 | CLIP |

## マージの仕組みの説明

### マージアルゴリズム

このノードは、加重パッチ適用を使用して2つのモデルを結合します。

1. **ベースモデルのクローン**: `clip1` をクローンしてベースモデルにします。
2. **パッチの取得**: `clip2` からすべてのキーパッチ（パラメータ値）を収集します。
3. **特別なキーの除外**: `.position_ids` と `.logit_scale` で終わるキーをスキップし、それらのパラメータを変更しないままにします。
4. **加重マージの適用**: クローンされたベースモデルに `clip2` のパッチをパッチ強度 `1.0 - ratio` で適用し、ベースモデルは `ratio` の強さを維持します。

### ratioパラメータの説明

- **ratio = 1.0**: ベースの強さは1.0、パッチの強さは0.0なので、出力は `clip1` と同一になります（デフォルト）。
- **ratio = 0.5**: ベースの強さとパッチの強さがともに0.5なので、両方のモデルが同じ強さで寄与します。
- **ratio = 0.0**: ベースの強さは0.0、パッチの強さは1.0なので、`clip2` のパッチが完全な強さで適用されます。
