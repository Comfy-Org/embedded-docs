# CLIP融合简易

`CLIPMergeSimple` 将两个 CLIP 文本编码器模型合并为一个模型。它先克隆第一个 CLIP 模型作为基础，再应用从第二个 CLIP 模型获取的带权重参数补丁，因此结果会融合两个模型的特征。`ratio` 设置控制每个模型的贡献强度；在默认值 1.0 下，第一个模型保持原样使用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip1` | 第一个 CLIP 模型。它会被克隆并用作合并的基础模型。 | CLIP | 是 | — |
| `clip2` | 第二个 CLIP 模型。其键补丁会应用到基础模型上，但以 `.position_ids` 或 `.logit_scale` 结尾的键对应的补丁除外。 | CLIP | 是 | — |
| `ratio` | 控制两个模型的相对强度。基础模型（`clip1`）保持的强度等于 `ratio`，而 `clip2` 的补丁以 `1.0 - ratio` 的强度应用。默认值为 1.0 时输出等于 `clip1`；值越低，`clip2` 的混合程度越高；为 0.0 时，`clip2` 的补丁以完整强度应用。 | FLOAT | 是 | 0.0 to 1.0 (default: 1.0, step: 0.01) |

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `clip` | 合并后的 CLIP 模型：`clip1` 的克隆，并根据 `ratio` 应用了来自 `clip2` 的补丁。 | CLIP |

## 合并机制说明

### 合并算法

该节点使用加权补丁应用来合并两个模型：

1. **克隆基础模型**：克隆 `clip1` 作为基础模型。
2. **获取补丁**：收集 `clip2` 中的所有键补丁（参数值）。
3. **过滤特殊键**：跳过以 `.position_ids` 和 `.logit_scale` 结尾的键，使这些参数保持不变。
4. **应用加权合并**：以 `1.0 - ratio` 的补丁强度将 `clip2` 的补丁应用到克隆的基础模型上，同时基础模型保持 `ratio` 的强度。

### Ratio 参数说明

- **ratio = 1.0**：基础强度为 1.0，补丁强度为 0.0，因此输出与 `clip1` 完全相同（默认值）。
- **ratio = 0.5**：基础强度和补丁强度均为 0.5，因此两个模型以相同强度贡献。
- **ratio = 0.0**：基础强度为 0.0，补丁强度为 1.0，因此 `clip2` 的补丁以完整强度应用。
