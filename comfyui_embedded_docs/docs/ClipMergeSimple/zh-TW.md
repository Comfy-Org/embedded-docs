# CLIPMergeSimple

`CLIPMergeSimple` 將兩個 CLIP 文字編碼器模型合併為單一模型。它會複製第一個 CLIP 模型作為基礎，並套用取自第二個 CLIP 模型的加權參數修補，因此結果會結合兩者的特徵。`ratio` 設定控制每個模型的貢獻強度；在預設值 1.0 時，第一個模型保持不變。

## 合併機制說明

### 合併演算法

此節點使用加權修補應用來組合兩個模型：

1. **複製基礎模型**：複製 `clip1` 作為基礎模型。
2. **取得修補**：收集 `clip2` 中的所有關鍵修補（參數值）。
3. **過濾特殊鍵**：跳過結尾為 `.position_ids` 與 `.logit_scale` 的鍵，使這些參數保持不變。
4. **套用加權合併**：以 `1.0 - ratio` 的修補強度將 `clip2` 的修補套用至複製的基礎模型，而基礎模型保持 `ratio` 的強度。

### Ratio 參數說明

- **ratio = 1.0**：基礎強度為 1.0，修補強度為 0.0，因此輸出與 `clip1` 完全相同（預設值）。
- **ratio = 0.5**：基礎強度與修補強度皆為 0.5，因此兩個模型以相同強度貢獻。
- **ratio = 0.0**：基礎強度為 0.0，修補強度為 1.0，因此 `clip2` 的修補會以完整強度套用。
