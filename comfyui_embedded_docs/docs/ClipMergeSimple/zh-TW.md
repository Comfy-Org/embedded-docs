# ClipMergeSimple

`CLIPMergeSimple` 是一個模型合併節點，可根據指定比例合併兩個 CLIP 文字編碼器模型。它會先複製第一個 CLIP 模型，然後套用來自第二個 CLIP 模型的加權修補，並略過位置 ID 與 logit scale 元件，以產生融合兩者特徵的混合模型。

## 合併機制說明

### 合併演算法

此節點使用加權平均來合併兩個模型：

1. **複製基礎模型**：先複製 `clip1` 作為基礎模型
2. **取得修補**：從 `clip2` 取得所有關鍵修補
3. **篩選特殊鍵**：略過以 `.position_ids` 與 `.logit_scale` 結尾的鍵
4. **套用加權合併**：使用公式 `(1.0 - ratio) * clip1 + ratio * clip2`

### 比例參數說明

- **ratio = 0.0**：完全使用 clip1，忽略 clip2
- **ratio = 0.5**：每個模型各貢獻 50%
- **ratio = 1.0**：完全使用 clip2，忽略 clip1
