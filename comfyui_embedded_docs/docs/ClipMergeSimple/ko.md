# CLIP 병합 (단순)

`CLIPMergeSimple`는 두 개의 CLIP 텍스트 인코더 모델을 하나로 병합합니다. 첫 번째 CLIP 모델을 복제하여 기본 모델로 사용하고, 두 번째 CLIP 모델에서 가져온 가중치가 적용된 매개변수 패치를 적용하므로 결과물에는 두 모델의 특징이 결합됩니다. `ratio` 설정은 각 모델이 기여하는 강도를 제어합니다. 기본값 1.0에서는 첫 번째 모델이 변경 없이 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip1` | 첫 번째 CLIP 모델입니다. 병합의 기본 모델로 복제되어 사용됩니다. | CLIP | 예 | — |
| `clip2` | 두 번째 CLIP 모델입니다. 키가 `.position_ids` 또는 `.logit_scale`로 끝나는 패치를 제외한 해당 키 패치가 기본 모델에 적용됩니다. | CLIP | 예 | — |
| `ratio` | 두 모델의 상대적 강도를 제어합니다. 기본 모델(`clip1`)은 `ratio`에 해당하는 강도를 유지하고, `clip2`의 패치는 `1.0 - ratio`의 강도로 적용됩니다. 기본값 1.0에서는 출력이 `clip1`과 동일하며, 값이 낮을수록 `clip2`가 더 많이 혼합되고, 0.0에서는 `clip2`의 패치가 전체 강도로 적용됩니다. | FLOAT | 예 | 0.0 to 1.0 (default: 1.0, step: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `clip` | 병합된 CLIP 모델: `clip2`의 패치가 `ratio`에 따라 적용된 `clip1`의 복제본입니다. | CLIP |

## 병합 메커니즘 설명

### 병합 알고리즘

이 노드는 두 모델을 결합하기 위해 가중치가 적용된 패치 방식을 사용합니다:

1. **기본 모델 복제**: `clip1`을 복제하여 기본 모델로 사용합니다.
2. **패치 가져오기**: `clip2`에서 모든 키 패치(매개변수 값)를 수집합니다.
3. **특수 키 필터링**: `.position_ids` 및 `.logit_scale`로 끝나는 키를 건너뛰어 해당 매개변수가 변경되지 않도록 유지합니다.
4. **가중치 병합 적용**: 복제된 기본 모델에 `1.0 - ratio`의 패치 강도로 `clip2`의 패치를 적용하고, 기본 모델은 `ratio`의 강도를 유지합니다.

### 비율 매개변수 설명

- **ratio = 1.0**: 기본 강도는 1.0이고 패치 강도는 0.0이므로 출력은 `clip1`과 동일합니다(기본값).
- **ratio = 0.5**: 기본 강도와 패치 강도가 모두 0.5이므로 두 모델이 동일한 강도로 기여합니다.
- **ratio = 0.0**: 기본 강도는 0.0이고 패치 강도는 1.0이므로 `clip2`의 패치가 전체 강도로 적용됩니다.

## 사용 사례

1. **모델 스타일 융합**: 서로 다른 데이터로 학습된 CLIP 모델의 특징을 결합합니다.
2. **성능 최적화**: 서로 다른 모델의 장단점을 균형 있게 조정합니다.
3. **실험 연구**: 다양한 CLIP 인코더의 조합을 탐구합니다.
