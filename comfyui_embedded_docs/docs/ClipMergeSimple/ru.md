# ClipMergeSimple

`CLIPMergeSimple` — это узел слияния моделей, который объединяет две модели текстового энкодера CLIP на основе заданного соотношения. Он клонирует первую модель CLIP и применяет взвешенные патчи из второй модели CLIP, пропуская компоненты позиционных идентификаторов и логит-шкалы, чтобы получить гибридную модель, сочетающую признаки из обоих источников.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip1` | Первая модель CLIP для слияния. Она служит базовой моделью для процесса слияния. | CLIP | Да | - |
| `clip2` | Вторая модель CLIP для слияния. Ее ключевые патчи, за исключением позиционных идентификаторов и логит-шкалы, применяются к первой модели в соответствии с заданным соотношением. | CLIP | Да | - |
| `соотношение` | Определяет долю признаков второй модели, которые будут смешаны с первой моделью. Соотношение 1.0 означает полное использование признаков второй модели, а 0.0 сохраняет только признаки первой модели. По умолчанию: 1.0. | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `clip` | Результирующая объединенная модель CLIP, сочетающая признаки обеих входных моделей в соответствии с заданным соотношением. | CLIP |

## Объяснение механизма слияния

### Алгоритм слияния

Узел использует взвешенное усреднение для слияния двух моделей:

1. **Клонирование базовой модели**: Сначала клонируется `clip1` как базовая модель.
2. **Получение патчей**: Извлекаются все ключевые патчи из `clip2`.
3. **Фильтрация специальных ключей**: Пропускаются ключи, оканчивающиеся на `.position_ids` и `.logit_scale`.
4. **Применение взвешенного слияния**: Используется формула `(1.0 - ratio) * clip1 + ratio * clip2`.

### Объяснение параметра ratio

- **ratio = 0.0**: Полностью используется clip1, clip2 игнорируется.
- **ratio = 0.5**: Каждая модель вносит 50% вклада.
- **ratio = 1.0**: Полностью используется clip2, clip1 игнорируется.

## Варианты использования

1. **Слияние стилей моделей**: Объединение характеристик моделей CLIP, обученных на различных данных.
2. **Оптимизация производительности**: Балансировка сильных и слабых сторон различных моделей.
3. **Экспериментальные исследования**: Исследование комбинаций различных энкодеров CLIP.
