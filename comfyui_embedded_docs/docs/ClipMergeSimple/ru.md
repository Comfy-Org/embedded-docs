# Простое слияние CLIP

`CLIPMergeSimple` объединяет две CLIP-модели текстового энкодера в одну. Он клонирует первую модель CLIP как базовую и применяет взвешенные патчи параметров, взятые из второй модели CLIP, поэтому результат объединяет признаки обеих. Параметр `ratio` управляет силой вклада каждой модели; при значении по умолчанию 1.0 первая модель используется без изменений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip1` | Первая модель CLIP. Она клонируется и используется в качестве базовой модели для слияния. | CLIP | Да | — |
| `clip2` | Вторая модель CLIP. Её патчи по ключам применяются к базовой модели, за исключением патчей, чьи ключи заканчиваются на `.position_ids` или `.logit_scale`. | CLIP | Да | — |
| `ratio` | Управляет относительной силой двух моделей. Базовая модель (`clip1`) сохраняет силу, равную `ratio`, а патчи `clip2` применяются с силой `1.0 - ratio`. При значении по умолчанию 1.0 выход равен `clip1`; более низкие значения добавляют больше признаков из `clip2`; при 0.0 патчи `clip2` применяются на полную силу. | FLOAT | Да | от 0.0 до 1.0 (по умолчанию: 1.0, шаг: 0.01) |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `clip` | Объединённая модель CLIP: клон `clip1` с патчами из `clip2`, применёнными в соответствии с `ratio`. | CLIP |

## Объяснение механизма слияния

### Алгоритм слияния

Узел использует взвешенное применение патчей для объединения двух моделей:

1. **Клонирование базовой модели**: Клонирует `clip1` для получения базовой модели.
2. **Получение патчей**: Собирает все патчи по ключам (значения параметров) из `clip2`.
3. **Фильтрация специальных ключей**: Пропускает ключи, заканчивающиеся на `.position_ids` и `.logit_scale`, чтобы эти параметры оставались без изменений.
4. **Взвешенное слияние**: Применяет патчи `clip2` к клонированной базовой модели с силой патча `1.0 - ratio`, а базовая модель сохраняет силу `ratio`.

### Пояснение параметра ratio

- **ratio = 1.0**: Сила базовой модели равна 1.0, сила патча — 0.0, поэтому выход идентичен `clip1` (по умолчанию).
- **ratio = 0.5**: Силы базовой модели и патча равны 0.5, поэтому обе модели вносят вклад с одинаковой силой.
- **ratio = 0.0**: Сила базовой модели равна 0.0, сила патча — 1.0, поэтому патчи `clip2` применяются на полную силу.

## Варианты использования

1. **Слияние стилей моделей**: Объединение характеристик моделей CLIP, обученных на разных данных.
2. **Оптимизация производительности**: Балансировка сильных и слабых сторон различных моделей.
3. **Экспериментальные исследования**: Изучение комбинаций различных энкодеров CLIP.
