# מיזוג רשימת אריחים לתמונה

צומת זה מקבל רשימה של אריחי תמונה וממזג אותם בחזרה לתמונה אחת גדולה יותר. הוא מיועד לשחזר תמונה שפוצלה קודם לכן לרשת של אריחים חופפים, תוך שימוש בטכניקת מיזוג משוקלל כדי ליצור תוצאה סופית חלקה ללא תפרים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image_list` | רשימה של אריחי תמונה למיזוג. האריח הראשון ברשימה משמש לקביעת מידות האריח וסוג הנתונים עבור כל התהליך. | IMAGE | כן | N/A |
| `final_width` | הרוחב של התמונה הממוזגת הסופית בפיקסלים (ברירת מחדל: 1024). | INT | כן | 64 - 32768 |
| `final_height` | הגובה של התמונה הממוזגת הסופית בפיקסלים (ברירת מחדל: 1024). | INT | כן | 64 - 32768 |
| `overlap` | כמות החפיפה בין אריחים סמוכים בפיקסלים. ערך גדול מ-0 מפעיל אפקט מיזוג חלק בתפרי האריחים (ברירת מחדל: 128). | INT | כן | 0 - 4096 |

**הערה:** `image_list` היא רשימת קלט דינמית. הצומת יעבד את האריחים לפי הסדר שבו סופקו, עד למספר הנדרש למילוי הרשת המוגדרת על ידי `final_width`, `final_height` והמידות של האריח הראשון. אם הרשימה מכילה יותר אריחים מהנדרש, האריחים הנוספים יוזנחו.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | התמונה הממוזגת הסופית, המשוחזרת מאריחי הקלט. | IMAGE |
