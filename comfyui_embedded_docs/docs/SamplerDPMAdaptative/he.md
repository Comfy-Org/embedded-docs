# SamplerDPMAdaptative

הצומת SamplerDPMAdaptative מיישם דוגם DPM (מודל הסתברותי דיפוזי) אדפטיבי שמכוונן אוטומטית גדלי צעד במהלך תהליך הדגימה. הוא משתמש בבקרת שגיאה מבוססת סובלנות כדי לקבוע גדלי צעד אופטימליים, תוך איזון בין יעילות חישובית לדיוק הדגימה. גישה אדפטיבית זו עוזרת לשמור על איכות תוך צמצום פוטנציאלי של מספר הצעדים הנדרשים.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `order` | סדר שיטת הדגימה (ברירת מחדל: 3) | INT | כן | 2-3 |
| `rtol` | סובלנות יחסית לבקרת שגיאה (ברירת מחדל: 0.05) | FLOAT | כן | 0.0-100.0 |
| `atol` | סובלנות מוחלטת לבקרת שגיאה (ברירת מחדל: 0.0078) | FLOAT | כן | 0.0-100.0 |
| `h_init` | גודל צעד התחלתי (ברירת מחדל: 0.05) | FLOAT | כן | 0.0-100.0 |
| `pcoeff` | מקדם פרופורציונלי לבקרת גודל צעד (ברירת מחדל: 0.0) | FLOAT | כן | 0.0-100.0 |
| `icoeff` | מקדם אינטגרלי לבקרת גודל צעד (ברירת מחדל: 1.0) | FLOAT | כן | 0.0-100.0 |
| `dcoeff` | מקדם נגזרת לבקרת גודל צעד (ברירת מחדל: 0.0) | FLOAT | כן | 0.0-100.0 |
| `accept_safety` | מקדם בטיחות לקבלת צעד (ברירת מחדל: 0.81) | FLOAT | כן | 0.0-100.0 |
| `eta` | פרמטר סטוכסטיות (ברירת מחדל: 0.0) | FLOAT | כן | 0.0-100.0 |
| `s_noise` | מקדם קנה מידה לרעש (ברירת מחדל: 1.0) | FLOAT | כן | 0.0-100.0 |

כל הקלטים הם פרמטרים מתקדמים המשמשים לכוונון עדין של התנהגות הדגימה האדפטיבית. כל הקלטים המספריים מאפשרים ערכים עשרוניים ומקבלים מינימום של 0.0 ומקסימום של 100.0, למעט `order`, שמוגבל לערכים השלמים 2 או 3.
