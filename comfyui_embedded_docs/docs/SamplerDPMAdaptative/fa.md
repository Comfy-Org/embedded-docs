# SamplerDPMAdaptative

گره SamplerDPMAdaptative یک نمونه‌گیر DPM (مدل احتمالی انتشار) تطبیقی را پیاده‌سازی می‌کند که اندازه گام‌ها را در طول فرایند نمونه‌گیری به‌طور خودکار تنظیم می‌کند. این گره از کنترل خطای مبتنی بر تلورانس برای تعیین اندازه گام‌های بهینه استفاده می‌کند و میان کارایی محاسباتی و دقت نمونه‌گیری توازن برقرار می‌سازد. این رویکرد تطبیقی به حفظ کیفیت کمک می‌کند و در عین حال ممکن است تعداد گام‌های موردنیاز را کاهش دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `order` | مرتبه روش نمونه‌گیر (پیش‌فرض: 3) | INT | بله | 2-3 |
| `rtol` | تلورانس نسبی برای کنترل خطا (پیش‌فرض: 0.05) | FLOAT | بله | 0.0-100.0 |
| `atol` | تلورانس مطلق برای کنترل خطا (پیش‌فرض: 0.0078) | FLOAT | بله | 0.0-100.0 |
| `h_init` | اندازه گام اولیه (پیش‌فرض: 0.05) | FLOAT | بله | 0.0-100.0 |
| `pcoeff` | ضریب تناسبی برای کنترل اندازه گام (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `icoeff` | ضریب انتگرالی برای کنترل اندازه گام (پیش‌فرض: 1.0) | FLOAT | بله | 0.0-100.0 |
| `dcoeff` | ضریب مشتق برای کنترل اندازه گام (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `accept_safety` | ضریب ایمنی برای پذیرش گام (پیش‌فرض: 0.81) | FLOAT | بله | 0.0-100.0 |
| `eta` | پارامتر تصادفی‌بودن (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `s_noise` | ضریب مقیاس‌دهی نویز (پیش‌فرض: 1.0) | FLOAT | بله | 0.0-100.0 |

همه ورودی‌ها پارامترهای پیشرفته‌ای هستند که برای تنظیم دقیق رفتار نمونه‌گیری تطبیقی به کار می‌روند. همه ورودی‌های عددی مقادیر اعشاری را می‌پذیرند و حداقل 0.0 و حداکثر 100.0 را قبول می‌کنند، به‌جز `order` که به مقادیر صحیح 2 یا 3 محدود است.
