# SamplerDPMAdaptative

گره SamplerDPMAdaptative یک نمونه‌گیر تطبیقی DPM (مدل احتمالی انتشار) را پیاده‌سازی می‌کند که در طول فرآیند نمونه‌گیری اندازه گام‌ها را به‌طور خودکار تنظیم می‌کند. این گره از کنترل خطای مبتنی بر تلورانس برای تعیین اندازه‌های گام بهینه استفاده می‌کند و کارایی محاسباتی را با دقت نمونه‌گیری متوازن می‌سازد. این رویکرد تطبیقی به حفظ کیفیت کمک می‌کند و در عین حال ممکن است تعداد گام‌های لازم را کاهش دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `ترتیب` | مرتبه روش نمونه‌گیری (پیش‌فرض: 3) | INT | بله | 2-3 |
| `rtol` | تلورانس نسبی برای کنترل خطا (پیش‌فرض: 0.05) | FLOAT | بله | 0.0-100.0 |
| `atol` | تلورانس مطلق برای کنترل خطا (پیش‌فرض: 0.0078) | FLOAT | بله | 0.0-100.0 |
| `h_init` | اندازه گام اولیه (پیش‌فرض: 0.05) | FLOAT | بله | 0.0-100.0 |
| `pcoeff` | ضریب تناسبی برای کنترل اندازه گام (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `icoeff` | ضریب انتگرالی برای کنترل اندازه گام (پیش‌فرض: 1.0) | FLOAT | بله | 0.0-100.0 |
| `dcoeff` | ضریب مشتقی برای کنترل اندازه گام (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `تأیید ایمنی` | ضریب ایمنی برای پذیرش گام (پیش‌فرض: 0.81) | FLOAT | بله | 0.0-100.0 |
| `eta` | پارامتر تصادفی بودن (پیش‌فرض: 0.0) | FLOAT | بله | 0.0-100.0 |
| `s_noise` | ضریب مقیاس نویز (پیش‌فرض: 1.0) | FLOAT | بله | 0.0-100.0 |

همه ورودی‌ها پارامترهای پیش‌رفته‌ای هستند که برای تنظیم دقیق رفتار نمونه‌گیری تطبیقی استفاده می‌شوند.
