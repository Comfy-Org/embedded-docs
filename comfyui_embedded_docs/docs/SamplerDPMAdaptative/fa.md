# SamplerDPMAdaptative

گره SamplerDPMAdaptative یک نمونه‌بردار DPM تطبیقی (Diffusion Probabilistic Model) پیاده‌سازی می‌کند که به‌طور خودکار اندازه گام‌ها را در طول فرآیند نمونه‌برداری تنظیم می‌کند. این گره از کنترل خطای مبتنی بر تلورانس برای تعیین اندازه گام‌های بهینه استفاده می‌کند و کارایی محاسباتی را با دقت نمونه‌برداری متعادل می‌سازد. این رویکرد تطبیقی به حفظ کیفیت کمک می‌کند و در عین حال به‌طور بالقوه تعداد گام‌های موردنیاز را کاهش می‌دهد.
