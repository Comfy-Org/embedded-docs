# Topaz Video Enhance

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `فيديو` | ملف الفيديو المُدخل المراد تحسينه. | VIDEO | نعم | - |
| `تمكين التكبير` | تفعيل أو تعطيل ميزة رفع دقة الفيديو (الافتراضي: True). | BOOLEAN | نعم | - |
| `نموذج التكبير` | نموذج الذكاء الاصطناعي المستخدم لرفع دقة الفيديو. | COMBO | نعم | `"Starlight (Astra) Fast"`<br>`"Starlight (Astra) Creative"`<br>`"Starlight Precise 2.5"` |
| `دقة التكبير` | الدقة المستهدفة للفيديو بعد رفع الدقة. | COMBO | نعم | `"FullHD (1080p)"`<br>`"4K (2160p)"` |
| `مستوى الإبداع` | مستوى الإبداع (يُطبَّق فقط على Starlight (Astra) Creative). (الافتراضي: "low") | COMBO | لا | `"low"`<br>`"middle"`<br>`"high"` |
| `تمكين التداخل` | تفعيل أو تعطيل ميزة استيفاء الإطارات (الافتراضي: False). | BOOLEAN | لا | - |
| `نموذج التداخل` | النموذج المستخدم لاستيفاء الإطارات (الافتراضي: "apo-8"). | COMBO | لا | `"apo-8"` |
| `عامل الحركة البطيئة` | معامل الحركة البطيئة المُطبَّق على الفيديو المُدخل. على سبيل المثال، القيمة 2 تجعل المخرجات أبطأ بمرتين وتضاعف المدة. (الافتراضي: 1) | INT | لا | 1 إلى 16 |
| `معدل الإطارات` | معدل إطارات المخرجات. (الافتراضي: 60) | INT | لا | 15 إلى 240 |
| `إزالة الإطارات المكررة` | تحليل الفيديو المُدخل بحثًا عن الإطارات المكررة وإزالتها. (الافتراضي: False) | BOOLEAN | لا | - |
| `حساسية اكتشاف التكرار` | حساسية اكتشاف الإطارات المكررة. (الافتراضي: 0.01) | FLOAT | لا | 0.001 إلى 0.1 |
| `مستوى الضغط الديناميكي` | مستوى CQP. (الافتراضي: "Low") | COMBO | لا | `"Low"`<br>`"Mid"`<br>`"High"` |

**ملاحظة:** يجب تفعيل ميزة تحسين واحدة على الأقل. ستُظهر العقدة خطأً إذا تم ضبط كل من `upscaler_enabled` و `interpolation_enabled` على False. يجب أن يكون الفيديو المُدخل بصيغة MP4. يُطبَّق إعداد `upscaler_creativity` فقط عندما يكون `upscaler_model` مضبوطًا على "Starlight (Astra) Creative". لا يتم دعم ملفات الفيديو الكبيرة جدًا التي تتطلب رفعًا متعدد الأجزاء.
