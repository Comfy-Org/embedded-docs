# Topaz Video Enhance

گره Topaz Video Enhance با فناوری قدرتمند افزایش مقیاس و بازیابی، جان تازه‌ای به ویدیو می‌بخشد و با استفاده از یک API خارجی کیفیت ویدیو را بهبود می‌دهد. این گره می‌تواند رزولوشن ویدیو را افزایش دهد، نرخ فریم را از طریق درون‌یابی افزایش دهد و فشرده‌سازی اعمال کند. گره یک ویدیوی ورودی MP4 را پردازش کرده و بر اساس تنظیمات انتخابی، نسخه‌ای بهبودیافته بازمی‌گرداند. این گره به عنوان منسوخ (legacy) علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `ویدیو` | فایل ویدیوی ورودی که باید بهبود یابد. | VIDEO | بله | - |
| `فعال‌سازی بزرگ‌نمایی` | ویژگی افزایش مقیاس ویدیو را فعال یا غیرفعال می‌کند (پیش‌فرض: True). | BOOLEAN | بله | - |
| `مدل بزرگ‌نمایی` | مدل هوش مصنوعی مورد استفاده برای افزایش مقیاس ویدیو. | COMBO | بله | `"Starlight (Astra) Fast"`<br>`"Starlight (Astra) Creative"`<br>`"Starlight Precise 2.5"` |
| `وضوح بزرگ‌نمایی` | رزولوشن هدف برای ویدیوی افزایش‌یافته. | COMBO | بله | `"FullHD (1080p)"`<br>`"4K (2160p)"` |
| `سطح خلاقیت` | سطح خلاقیت (فقط برای Starlight (Astra) Creative اعمال می‌شود). (پیش‌فرض: "low") | COMBO | خیر | `"low"`<br>`"middle"`<br>`"high"` |
| `فعال‌سازی درون‌یابی` | ویژگی درون‌یابی فریم را فعال یا غیرفعال می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | - |
| `مدل درون‌یابی` | مدل مورد استفاده برای درون‌یابی فریم (پیش‌فرض: "apo-8"). | COMBO | خیر | `"apo-8"` |
| `ضریب حرکت آهسته` | ضریب حرکت آهسته اعمال‌شده بر ویدیوی ورودی. به عنوان مثال، 2 خروجی را دو برابر کندتر می‌کند و مدت‌زمان را دو برابر می‌کند. (پیش‌فرض: 1) | INT | خیر | 1 تا 16 |
| `نرخ فریم خروجی` | نرخ فریم خروجی. (پیش‌فرض: 60) | INT | خیر | 15 تا 240 |
| `حذف فریم‌های تکراری` | ورودی را برای فریم‌های تکراری تحلیل کرده و آن‌ها را حذف می‌کند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `حساسیت تشخیص فریم تکراری` | حساسیت تشخیص فریم‌های تکراری. (پیش‌فرض: 0.01) | FLOAT | خیر | 0.001 تا 0.1 |
| `سطح فشرده‌سازی پویا` | سطح CQP. (پیش‌فرض: "Low") | COMBO | خیر | `"Low"`<br>`"Mid"`<br>`"High"` |

**نکته:** حداقل یک ویژگی بهبود باید فعال باشد. اگر هر دو `upscaler_enabled` و `interpolation_enabled` روی False تنظیم شوند، گره خطا ایجاد می‌کند. ویدیوی ورودی باید با فرمت MP4 باشد. تنظیم `upscaler_creativity` فقط زمانی اعمال می‌شود که `upscaler_model` روی "Starlight (Astra) Creative" تنظیم شده باشد. فایل‌های ویدیویی بسیار بزرگ که نیاز به آپلود چندبخشی دارند، پشتیبانی نمی‌شوند.
