# Topaz Video Enhance

Узел Topaz Video Enhance вдыхает новую жизнь в видео с помощью мощной технологии масштабирования и восстановления, используя внешний API для улучшения качества видео. Он может повышать разрешение видео, увеличивать частоту кадров с помощью интерполяции и применять сжатие. Узел обрабатывает входное видео в формате MP4 и возвращает улучшенную версию на основе выбранных настроек. Этот узел помечен как устаревший (legacy).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Входной видеофайл для улучшения. | VIDEO | Да | - |
| `включить увеличитель` | Включает или отключает функцию масштабирования видео (по умолчанию: True). | BOOLEAN | Да | - |
| `модель увеличителя` | Модель ИИ, используемая для масштабирования видео. | COMBO | Да | `"Starlight (Astra) Fast"`<br>`"Starlight (Astra) Creative"`<br>`"Starlight Precise 2.5"` |
| `разрешение увеличителя` | Целевое разрешение для масштабированного видео. | COMBO | Да | `"FullHD (1080p)"`<br>`"4K (2160p)"` |
| `креативность увеличителя` | Уровень креативности (применяется только к Starlight (Astra) Creative). (по умолчанию: "low") | COMBO | Нет | `"low"`<br>`"middle"`<br>`"high"` |
| `включить интерполяцию` | Включает или отключает функцию интерполяции кадров (по умолчанию: False). | BOOLEAN | Нет | - |
| `модель интерполяции` | Модель, используемая для интерполяции кадров (по умолчанию: "apo-8"). | COMBO | Нет | `"apo-8"` |
| `замедление интерполяции` | Коэффициент замедления, применяемый к входному видео. Например, 2 делает выходное видео вдвое медленнее и удваивает продолжительность. (по умолчанию: 1) | INT | Нет | 1 до 16 |
| `частота кадров интерполяции` | Выходная частота кадров. (по умолчанию: 60) | INT | Нет | 15 до 240 |
| `удаление дубликатов кадров` | Анализировать входное видео на наличие дублирующихся кадров и удалять их. (по умолчанию: False) | BOOLEAN | Нет | - |
| `порог дубликатов кадров` | Чувствительность обнаружения дублирующихся кадров. (по умолчанию: 0.01) | FLOAT | Нет | 0.001 до 0.1 |
| `уровень динамического сжатия` | Уровень CQP. (по умолчанию: "Low") | COMBO | Нет | `"Low"`<br>`"Mid"`<br>`"High"` |

**Примечание:** Необходимо включить хотя бы одну функцию улучшения. Узел выдаст ошибку, если и `upscaler_enabled`, и `interpolation_enabled` имеют значение False. Входное видео должно быть в формате MP4. Настройка `upscaler_creativity` применяется только когда для `upscaler_model` установлено значение "Starlight (Astra) Creative". Очень большие видеофайлы, требующие многокомпонентной загрузки, не поддерживаются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Улучшенный выходной видеофайл. | VIDEO |
