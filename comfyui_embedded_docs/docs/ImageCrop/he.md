# ImageCrop

הצומת `ImageCrop` מיועד לחיתוך תמונות לרוחב וגובה מוגדרים, החל מקואורדינטות x ו-y נתונות. פונקציונליות זו חיונית להתמקדות באזורים מסוימים בתמונה או להתאמת גודל התמונה כדי לעמוד בדרישות מסוימות.

## קלטים

| שדה | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | תמונת הקלט שיש לחתוך. פרמטר זה קריטי מכיוון שהוא מגדיר את תמונת המקור שממנה ייחלץ אזור בהתאם למידות ולקואורדינטות שצוינו. | `IMAGE` |
| `width` | מגדיר את רוחב התמונה החתוכה. פרמטר זה קובע עד כמה רחבה תהיה התמונה החתוכה המתקבלת. | `INT` |
| `height` | מגדיר את גובה התמונה החתוכה. פרמטר זה קובע את גובה התמונה החתוכה המתקבלת. | `INT` |
| `x` | קואורדינטת ה-x של הפינה השמאלית העליונה של אזור החיתוך. פרמטר זה קובע את נקודת ההתחלה עבור ממד הרוחב של החיתוך. | `INT` |
| `y` | קואורדינטת ה-y של הפינה השמאלית העליונה של אזור החיתוך. פרמטר זה קובע את נקודת ההתחלה עבור ממד הגובה של החיתוך. | `INT` |

## פלטים
