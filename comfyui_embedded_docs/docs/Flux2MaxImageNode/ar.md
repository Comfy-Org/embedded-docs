# Flux.2 [max] صورة

يولّد صورة باستخدام Flux.2 [max] عبر واجهة BFL API انطلاقًا من موجّه نصي وأبعاد إخراج محددة صراحةً، مع إمكانية الاستعانة بصور مرجعية اختيارية. ويكشف عن المدخلات نفسها التي توفرها عقدة Flux.2 [pro] Image.

**ملاحظة:** هذه العقدة موسومة بأنها مهملة (deprecated) في الشيفرة المصدرية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النص` | الموجّه النصي لتوليد الصورة أو تعديلها. | STRING | نعم | - |
| `العرض` | عرض الصورة المولّدة بالبكسل (الافتراضي: 1024). | INT | نعم | 256 إلى 2048 (خطوة: 32) |
| `الارتفاع` | ارتفاع الصورة المولّدة بالبكسل (الافتراضي: 768). | INT | نعم | 256 إلى 2048 (خطوة: 32) |
| `البذرة` | البذرة العشوائية المستخدمة في إنشاء التشويش (الافتراضي: 0). | INT | نعم | 0 إلى 18446744073709551615 |
| `رفع دقة النص` | ما إذا كان سيتم رفع دقة الموجّه النصي (upsampling). عند التفعيل، يُعدَّل الموجّه تلقائيًا للحصول على توليد أكثر إبداعًا (الافتراضي: `True`). هذا إعداد متقدم. | BOOLEAN | نعم | True / False |
| `الصور` | صور مرجعية اختيارية للتوليد من صورة إلى صورة. تُصغَّر كل صورة إلى 2048x2048 بكسل كحد أقصى قبل الرفع. | IMAGE | لا | 0 إلى 9 صور |

**القيود:**

* توصيل أكثر من 9 صور مرجعية يؤدي إلى خطأ.
* تُحتسب تكلفة حجم الإخراج لكل ميغابكسل، لذا فإن قيم `width` و`height` الأكبر تكلّف أكثر.
