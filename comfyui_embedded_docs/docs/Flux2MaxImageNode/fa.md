# Flux.2 [max] Image

با استفاده از API ‏BFL و بر اساس یک پرامپت و ابعاد خروجی صریح، تصویری با Flux.2 [max] تولید می‌کند و به‌صورت اختیاری از تصاویر مرجع راهنمایی می‌گیرد. ورودی‌های آن همان ورودی‌های Flux.2 [pro] Image است.

**توجه:** این گره در کد منبع به‌عنوان منسوخ علامت‌گذاری شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | پرامپت برای تولید یا ویرایش تصویر. | STRING | بله | - |
| `عرض` | عرض تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 256 تا 2048 (گام 32) |
| `ارتفاع` | ارتفاع تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 256 تا 2048 (گام 32) |
| `بذر` | دانه تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |
| `افزایش وضوح پرامپت` | آیا روی پرامپت نمونه‌برداری افزایشی انجام شود یا خیر. اگر فعال باشد، پرامپت به‌طور خودکار برای تولید خلاقانه‌تر تغییر می‌کند (پیش‌فرض: `True`). این یک تنظیم پیشرفته است. | BOOLEAN | بله | True / False |
| `تصاویر` | تصاویر مرجع اختیاری برای تولید تصویر به تصویر. هر تصویر پیش از بارگذاری حداکثر تا 2048x2048 پیکسل کوچک‌سازی می‌شود. | IMAGE | خیر | 0 تا 9 تصویر |

**محدودیت‌ها:**

* اتصال بیش از 9 تصویر مرجع خطا ایجاد می‌کند.
* هزینه اندازه خروجی به ازای هر مگاپیکسل محاسبه می‌شود؛ بنابراین مقادیر بزرگ‌تر `width` و `height` هزینه بیشتری دارند.
