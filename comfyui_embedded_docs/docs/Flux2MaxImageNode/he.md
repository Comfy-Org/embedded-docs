# Flux.2 [max] תמונה

יוצר תמונה עם Flux.2 [max] דרך ה-API של BFL מתוך הנחיה וממדי פלט מפורשים, כאשר ניתן להנחות אותו באמצעות תמונות עזר. הוא חושף את אותם קלטים כמו Flux.2 [pro] Image.

**הערה:** צומת זה מסומן כדפרקטי (deprecated) בקוד המקור.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיה ליצירת התמונה או לעריכתה. | STRING | כן | - |
| `width` | רוחב התמונה הנוצרת בפיקסלים (ברירת מחדל: 1024). | INT | כן | 256 עד 2048 (בצעדים של 32) |
| `height` | גובה התמונה הנוצרת בפיקסלים (ברירת מחדל: 768). | INT | כן | 256 עד 2048 (בצעדים של 32) |
| `seed` | הזרע האקראי המשמש ליצירת הרעש (ברירת מחדל: 0). | INT | כן | 0 עד 18446744073709551615 |
| `prompt_upsampling` | האם לבצע upsampling (דגימה מחדש) על ההנחיה. אם פעיל, ההנחיה משתנה אוטומטית ליצירה יצירתית יותר (ברירת מחדל: `True`). זוהי הגדרה מתקדמת. | BOOLEAN | כן | True / False |
| `images` | תמונות עזר אופציונליות ליצירת תמונה-לתמונה. כל תמונה מוקטנת ל-2048x2048 פיקסלים לכל היותר לפני ההעלאה. | IMAGE | לא | 0 עד 9 תמונות |

**אילוצים:**

* חיבור של יותר מ-9 תמונות עזר יגרום לשגיאה.
* גודל הפלט מחויב לפי מגה-פיקסל, כך שערכים גדולים יותר של `width` ו-`height` עולים יותר.
