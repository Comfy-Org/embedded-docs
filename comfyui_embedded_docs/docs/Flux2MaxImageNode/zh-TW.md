# Flux.2 [max] 圖像

使用 Flux.2 [max] 透過 BFL API，根據提示詞與明確的輸出尺寸生成影像，並可選擇以參考影像作為引導。它公開的輸入與 Flux.2 [pro] Image 相同。

**注意：** 此節點在原始碼中標記為已棄用。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `提示詞` | 用於影像生成或編輯的提示詞。 | STRING | 是 | - |
| `寬度` | 生成影像的寬度，單位為像素（預設值：1024）。 | INT | 是 | 256 至 2048 （步進值：32） |
| `高度` | 生成影像的高度，單位為像素（預設值：768）。 | INT | 是 | 256 至 2048 （步進值：32） |
| `隨機種子` | 用於建立雜訊的隨機種子（預設值：0）。 | INT | 是 | 0 至 18446744073709551615 |
| `提示詞升頻` | 是否對提示詞執行上採樣。若啟用，提示詞會自動修改以獲得更具創意的生成結果（預設值：`True`）。此為進階設定。 | BOOLEAN | 是 | True / False |
| `參考圖像` | 可選的參考影像，用於影像到影像生成。每張影像在上傳前會縮小至最多 2048x2048 像素。 | IMAGE | 否 | 0 至 9 張圖像 |

**限制：**

* 連接超過 9 張參考影像會引發錯誤。
* 輸出尺寸按每百萬像素計費，因此 `width` 和 `height` 值越大，費用越高。

|-------------|-------------|-----------|
