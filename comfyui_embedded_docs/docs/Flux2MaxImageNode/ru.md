# Flux.2 [max] Image

Создаёт изображение с помощью Flux.2 [max] через BFL API по промпту и явно заданным выходным размерам, опционально с использованием эталонных изображений в качестве направляющих. Он предоставляет те же входы, что и Flux.2 [pro] Image.

**Примечание:** В исходном коде этот узел помечен как устаревший.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт для генерации или редактирования изображения. | STRING | Да | - |
| `width` | Ширина генерируемого изображения в пикселях (по умолчанию: 1024). | INT | Да | 256–2048 (шаг 32) |
| `height` | Высота генерируемого изображения в пикселях (по умолчанию: 768). | INT | Да | 256–2048 (шаг 32) |
| `seed` | Случайное зерно, используемое для создания шума (по умолчанию: 0). | INT | Да | 0–18446744073709551615 |
| `prompt_upsampling` | Выполнять ли апсемплинг промпта. Если активно, промпт автоматически изменяется для более креативной генерации (по умолчанию: `True`). Это дополнительная настройка. | BOOLEAN | Да | True / False |
| `images` | Необязательные эталонные изображения для генерации по схеме «изображение в изображение». Каждое изображение перед загрузкой уменьшается до максимум 2048x2048 пикселей. | IMAGE | Нет | 0–9 изображений |

**Ограничения:**

* Подключение более 9 эталонных изображений вызывает ошибку.
* Размер выходного изображения оплачивается за мегапиксель, поэтому большие значения `width` и `height` стоят дороже.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение. | IMAGE |
