# StableZero123_Conditioning

צומת StableZero123_Conditioning מעבד תמונת קלט וזוויות מצלמה כדי לייצר נתוני התניה וייצוגי latent ליצירת מודלים תלת-ממדיים. הוא משתמש במודל CLIP vision כדי לקודד מאפייני תמונה, משלב אותם עם מידע הטמעת מצלמה המבוסס על זוויות הגבהה ואזימוט, ומייצר התניה חיובית ושלילית יחד עם ייצוג latent עבור משימות יצירת תלת-ממד בהמשך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip_vision` | מודל CLIP vision המשמש לקידוד מאפייני תמונה | CLIP_VISION | כן | - |
| `init_image` | תמונת הקלט לעיבוד ולקידוד | IMAGE | כן | - |
| `vae` | מודל VAE המשמש לקידוד פיקסלים למרחב latent | VAE | כן | - |
| `width` | רוחב הפלט עבור ייצוג latent (ברירת מחדל: 256, צעד: 8) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה הפלט עבור ייצוג latent (ברירת מחדל: 256, צעד: 8) | INT | כן | 16 עד MAX_RESOLUTION |
| `batch_size` | מספר הדגימות ליצירה באצווה (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `elevation` | זווית הגבהה של המצלמה במעלות (ברירת מחדל: 0.0, צעד: 0.1) | FLOAT | כן | -180.0 עד 180.0 |
| `azimuth` | זווית אזימוט של המצלמה במעלות (ברירת מחדל: 0.0, צעד: 0.1) | FLOAT | כן | -180.0 עד 180.0 |

**הערה:** הפרמטרים `width` ו-`height` משתמשים בצעד של 8, כך שהערכים מוגדרים במרווחים של 8. הצומת מחלק אותם ב-8 כדי לקבוע את ממדי ייצוג ה-latent. התמונה מותאמת מחדש ל-`width` ול-`height` הנתונים באמצעות הגדלה בילינארית עם חיתוך מרכזי לפני קידוד VAE.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | נתוני התניה חיוביים המשלבים מאפייני תמונה והטמעות מצלמה, כולל תמונת הקלט המקודדת ב-VAE כ-latent לשרשור | CONDITIONING |
| `negative` | נתוני התניה שליליים עם מאפיינים מאותחלים לאפס ו-latent מאותחל לאפס | CONDITIONING |
| `latent` | ייצוג latent מאותחל לאפס עם ממדים [batch_size, 4, height//8, width//8] | LATENT |
