# StableZero123_Conditioning

گره StableZero123_Conditioning یک تصویر ورودی و زوایای دوربین را پردازش می‌کند تا داده‌های شرطی (conditioning) و نمایش‌های نهفته (latent) برای تولید مدل سه‌بعدی ایجاد کند. این گره از مدل بینایی CLIP برای رمزگذاری ویژگی‌های تصویر استفاده می‌کند، آن‌ها را با اطلاعات جاسازی دوربین بر اساس زوایای ارتفاع (elevation) و آزیموت (azimuth) ترکیب می‌کند، و شرطی مثبت و منفی به همراه یک نمایش نهفته برای وظایف تولید سه‌بعدی پایین‌دستی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip_vision` | مدل بینایی CLIP که برای رمزگذاری ویژگی‌های تصویر استفاده می‌شود | CLIP_VISION | بله | - |
| `تصویر اولیه` | تصویر ورودی که پردازش و رمزگذاری می‌شود | IMAGE | بله | - |
| `vae` | مدل VAE که برای رمزگذاری پیکسل‌ها به فضای نهفته استفاده می‌شود | VAE | بله | - |
| `عرض` | عرض خروجی برای نمایش نهفته (پیش‌فرض: 256، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی برای نمایش نهفته (پیش‌فرض: 256، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 to MAX_RESOLUTION |
| `اندازه دسته` | تعداد نمونه‌هایی که در هر دسته تولید می‌شود (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `زاویه ارتفاع` | زاویه ارتفاع دوربین بر حسب درجه (پیش‌فرض: 0.0) | FLOAT | بله | -180.0 تا 180.0 |
| `زاویه سمت` | زاویه آزیموت دوربین بر حسب درجه (پیش‌فرض: 0.0) | FLOAT | بله | -180.0 تا 180.0 |

**توجه:** پارامترهای `width` و `height` باید بر 8 بخش‌پذیر باشند، زیرا گره به‌طور خودکار آن‌ها را بر 8 تقسیم می‌کند تا ابعاد نمایش نهفته را ایجاد کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `مثبت` | داده‌های شرطی مثبت که ویژگی‌های تصویر و جاسازی‌های دوربین را ترکیب می‌کند، و شامل تصویر ورودی رمزگذاری‌شده با VAE به‌صورت یک نمایش نهفته برای الحاق (concat) است | CONDITIONING |
| `منفی` | داده‌های شرطی منفی با ویژگی‌های مقداردهی‌شده با صفر و یک نمایش نهفته صفر | CONDITIONING |
| `latent` | نمایش نهفته صفر با ابعاد [batch_size, 4, height//8, width//8] | LATENT |
