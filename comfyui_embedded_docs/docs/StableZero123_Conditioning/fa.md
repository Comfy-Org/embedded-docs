# StableZero123_Conditioning

گره `StableZero123_Conditioning` یک تصویر ورودی و زوایای دوربین را پردازش می‌کند تا داده‌های شرطی‌سازی و نمایش‌های نهان برای تولید مدل سه‌بعدی ایجاد کند. این گره از یک مدل بینایی CLIP برای رمزگذاری ویژگی‌های تصویر استفاده می‌کند، آن‌ها را با اطلاعات جاسازی دوربین بر اساس زوایای ارتفاع و آزیموت ترکیب می‌کند و شرطی‌سازی مثبت و منفی را همراه با نمایش نهان برای وظایف پایین‌دستی تولید سه‌بعدی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip_vision` | مدل بینایی CLIP که برای رمزگذاری ویژگی‌های تصویر استفاده می‌شود | CLIP_VISION | بله | - |
| `init_image` | تصویر ورودی که پردازش و رمزگذاری می‌شود | IMAGE | بله | - |
| `vae` | مدل VAE که برای رمزگذاری پیکسل‌ها به فضای نهان استفاده می‌شود | VAE | بله | - |
| `width` | عرض خروجی برای نمایش نهان (پیش‌فرض: 256، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `height` | ارتفاع خروجی برای نمایش نهان (پیش‌فرض: 256، باید بر 8 بخش‌پذیر باشد) | INT | بله | 16 تا MAX_RESOLUTION |
| `batch_size` | تعداد نمونه‌هایی که در دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `elevation` | زاویه ارتفاع دوربین بر حسب درجه (پیش‌فرض: 0.0) | FLOAT | بله | -180.0 تا 180.0 |
| `azimuth` | زاویه آزیموت دوربین بر حسب درجه (پیش‌فرض: 0.0) | FLOAT | بله | -180.0 تا 180.0 |

**نکته:** پارامترهای `width` و `height` باید بر 8 بخش‌پذیر باشند، زیرا گره به‌طور خودکار آن‌ها را بر 8 تقسیم می‌کند تا ابعاد نمایش نهان ایجاد شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | داده‌های شرطی‌سازی مثبت که ویژگی‌های تصویر و جاسازی‌های دوربین را ترکیب می‌کند | CONDITIONING |
| `negative` | داده‌های شرطی‌سازی منفی با ویژگی‌های مقداردهی‌شده با صفر | CONDITIONING |
| `latent` | نمایش نهان با ابعاد [batch_size, 4, height//8, width//8] | LATENT |
