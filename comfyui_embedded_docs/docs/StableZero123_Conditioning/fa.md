# StableZero123_Conditioning

گره StableZero123_Conditioning یک تصویر ورودی و زوایای دوربین را پردازش می‌کند تا داده‌های شرطی‌سازی و نمایش‌های نهفته برای تولید مدل سه‌بعدی ایجاد کند. این گره از یک مدل بینایی CLIP برای رمزگذاری ویژگی‌های تصویر استفاده می‌کند، آن‌ها را با اطلاعات جاسازی دوربین بر اساس زوایای ارتفاع و آزیموت ترکیب می‌کند، و شرطی‌سازی مثبت و منفی را همراه با یک نمایش نهفته برای وظایف پایین‌دستی تولید سه‌بعدی تولید می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip_vision` | مدل بینایی CLIP که برای رمزگذاری ویژگی‌های تصویر استفاده می‌شود | CLIP_VISION | بله | - |
| `تصویر اولیه` | تصویر ورودی که باید پردازش و رمزگذاری شود | IMAGE | بله | - |
| `vae` | مدل VAE که برای رمزگذاری پیکسل‌ها به فضای نهفته استفاده می‌شود | VAE | بله | - |
| `عرض` | عرض خروجی برای نمایش نهفته (پیش‌فرض: 256، گام: 8) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع خروجی برای نمایش نهفته (پیش‌فرض: 256، گام: 8) | INT | بله | 16 تا MAX_RESOLUTION |
| `اندازه دسته` | تعداد نمونه‌هایی که در دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `زاویه ارتفاع` | زاویه ارتفاع دوربین بر حسب درجه (پیش‌فرض: 0.0، گام: 0.1) | FLOAT | بله | -180.0 تا 180.0 |
| `زاویه سمت` | زاویه آزیموت دوربین بر حسب درجه (پیش‌فرض: 0.0، گام: 0.1) | FLOAT | بله | -180.0 تا 180.0 |

**توجه:** پارامترهای `width` و `height` از گام 8 استفاده می‌کنند، بنابراین مقادیر با افزایش‌های 8 تنظیم می‌شوند. گره آن‌ها را بر 8 تقسیم می‌کند تا ابعاد نمایش نهفته را تعیین کند. تصویر پیش از رمزگذاری VAE با استفاده از بزرگ‌نمایی دوخطی همراه با برش مرکزی به `width` و `height` داده‌شده تغییر مقیاس می‌یابد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | داده‌های شرطی‌سازی مثبت که ویژگی‌های تصویر و جاسازی‌های دوربین را ترکیب می‌کند و شامل تصویر ورودی رمزگذاری‌شده با VAE به‌عنوان یک latent برای الحاق است | CONDITIONING |
| `negative` | داده‌های شرطی‌سازی منفی با ویژگی‌های مقدار اولیه صفر و یک latent با مقدار اولیه صفر | CONDITIONING |
| `latent` | نمایش نهفته با مقدار اولیه صفر با ابعاد [batch_size, 4, height//8, width//8] | LATENT |
