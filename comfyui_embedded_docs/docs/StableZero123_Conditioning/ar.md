# تهيئة StableZero123

تعالج عقدة StableZero123_Conditioning صورة إدخال وزوايا كاميرا لإنشاء بيانات تكييف وتمثيلات كامنة لتوليد نماذج ثلاثية الأبعاد. وتستخدم نموذج رؤية CLIP لتشفير سمات الصورة، وتدمجها مع معلومات تضمين الكاميرا بناءً على زاويتي الارتفاع والسمت، وتنتج تكييفًا موجبًا وسالبًا إلى جانب تمثيل كامن لمهام التوليد ثلاثي الأبعاد اللاحقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip_vision` | نموذج رؤية CLIP المستخدم لتشفير سمات الصورة | CLIP_VISION | نعم | - |
| `init_image` | صورة الإدخال المراد معالجتها وتشفيرها | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير البكسلات إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض الإخراج للتمثيل الكامن (القيمة الافتراضية: 256، الخطوة: 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع الإخراج للتمثيل الكامن (القيمة الافتراضية: 256، الخطوة: 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `batch_size` | عدد العينات المراد توليدها في الدفعة (القيمة الافتراضية: 1) | INT | نعم | 1 إلى 4096 |
| `elevation` | زاوية ارتفاع الكاميرا بالدرجات (القيمة الافتراضية: 0.0، الخطوة: 0.1) | FLOAT | نعم | -180.0 إلى 180.0 |
| `azimuth` | زاوية سمت الكاميرا بالدرجات (القيمة الافتراضية: 0.0، الخطوة: 0.1) | FLOAT | نعم | -180.0 إلى 180.0 |

**ملاحظة:** تستخدم المعلمتان `width` و `height` خطوة مقدارها 8، لذا تُضبط القيم بزيادات قدرها 8. وتقسمهما العقدة على 8 لتحديد أبعاد التمثيل الكامن. وتُعاد تحجيم الصورة إلى قيمتي `width` و `height` المعطاتين باستخدام تحجيم ثنائي الخطي مع اقتصاص من المركز قبل تشفير VAE.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | بيانات تكييف موجبة تجمع بين سمات الصورة وتضمينات الكاميرا، بما في ذلك صورة الإدخال المشفرة بواسطة VAE كتمثيل كامن ليتم دمجها | CONDITIONING |
| `negative` | بيانات تكييف سالبة بسمات مهيأة إلى الصفر وتمثيل كامن مهيأ إلى الصفر | CONDITIONING |
| `latent` | تمثيل كامن مهيأ إلى الصفر بأبعاد [batch_size, 4, height//8, width//8] | LATENT |
