# تهيئة StableZero123

```markdown
تقوم عقدة `StableZero123_Conditioning` بمعالجة صورة إدخال وزوايا الكاميرا لتوليد بيانات التكييف والتمثيلات الكامنة لتوليد النماذج ثلاثية الأبعاد. تستخدم نموذج رؤية CLIP لتشفير ميزات الصورة، وتدمجها مع معلومات تضمين الكاميرا استنادًا إلى زوايا الارتفاع والسمت، وتنتج تكييفًا موجبًا وسالبًا إلى جانب تمثيل كامن لمهام توليد النماذج ثلاثية الأبعاد اللاحقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip_vision` | نموذج رؤية CLIP المستخدم لتشفير ميزات الصورة | CLIP_VISION | نعم | - |
| `init_image` | صورة الإدخال التي سيتم معالجتها وتشفيرها | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير البكسلات إلى الفضاء الكامن | VAE | نعم | - |
| `width` | عرض الإخراج للتمثيل الكامن (الافتراضي: 256، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `height` | ارتفاع الإخراج للتمثيل الكامن (الافتراضي: 256، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `batch_size` | عدد العينات المولدة في الدفعة الواحدة (الافتراضي: 1) | INT | نعم | 1 to 4096 |
| `elevation` | زاوية ارتفاع الكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 to 180.0 |
| `azimuth` | زاوية سمت الكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 to 180.0 |

**ملاحظة:** يجب أن يكون المعاملان `width` و `height` قابلين للقسمة على 8، حيث تقوم العقدة تلقائيًا بقسمتهما على 8 لإنشاء أبعاد التمثيل الكامن.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | بيانات تكييف موجبة تجمع بين ميزات الصورة وتضمينات الكاميرا | CONDITIONING |
| `negative` | بيانات تكييف سالبة بميزات مهيأة بأصفار | CONDITIONING |
| `latent` | تمثيل كامن بأبعاد [batch_size, 4, height//8, width//8] | LATENT |
```
