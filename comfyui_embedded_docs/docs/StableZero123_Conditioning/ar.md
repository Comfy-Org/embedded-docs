# تهيئة StableZero123

عقدة StableZero123_Conditioning تعالج صورة إدخال وزوايا الكاميرا لتوليد بيانات التوجيه (conditioning) وتمثيلات كامنة (latent) لتوليد نماذج ثلاثية الأبعاد. تستخدم نموذج رؤية CLIP لتشفير ميزات الصورة، وتدمجها مع معلومات تضمين الكاميرا بناءً على زاويتي الارتفاع والسمت، وتنتج توجيهًا إيجابيًا وسلبيًا بالإضافة إلى تمثيل كامن لمهام توليد ثلاثية الأبعاد اللاحقة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `رؤية المقطع` | نموذج رؤية CLIP المستخدم لتشفير ميزات الصورة | CLIP_VISION | نعم | - |
| `الصورة الأصلية` | صورة الإدخال التي ستتم معالجتها وتشفيرها | IMAGE | نعم | - |
| `vae` | نموذج VAE المستخدم لتشفير وحدات البكسل إلى الفضاء الكامن | VAE | نعم | - |
| `العرض` | عرض الإخراج للتمثيل الكامن (الافتراضي: 256، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الإخراج للتمثيل الكامن (الافتراضي: 256، يجب أن يكون قابلاً للقسمة على 8) | INT | نعم | 16 to MAX_RESOLUTION |
| `حجم الدفعة` | عدد العينات المراد توليدها في الدفعة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `الارتفاع الزاوي` | زاوية ارتفاع الكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |
| `السمت` | زاوية سمت الكاميرا بالدرجات (الافتراضي: 0.0) | FLOAT | نعم | -180.0 إلى 180.0 |

**ملاحظة:** يجب أن تكون معاملتا `width` و`height` قابلتين للقسمة على 8، حيث تقوم العقدة تلقائيًا بقسمتهما على 8 لإنشاء أبعاد التمثيل الكامن.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `إيجابي` | بيانات توجيه إيجابية تجمع بين ميزات الصورة وتضمينات الكاميرا، وتتضمن صورة الإدخال المشفرة بواسطة VAE كتمثيل كامن لتسلسله | CONDITIONING |
| `سلبي` | بيانات توجيه سالبة بميزات مُهيأة إلى صفر وتمثيل كامن مُهيأ إلى صفر | CONDITIONING |
| `كامِن` | تمثيل كامن مُهيأ إلى صفر بأبعاد [batch_size, 4, height//8, width//8] | LATENT |
