# StableZero123_Кондиционирование

Узел StableZero123_Conditioning обрабатывает входное изображение и углы камеры для генерации данных кондиционирования и латентных представлений для создания 3D-моделей. Он использует модель CLIP vision для кодирования признаков изображения, объединяет их с информацией эмбеддинга камеры на основе углов возвышения и азимута, а также создаёт положительное и отрицательное кондиционирование вместе с латентным представлением для последующих задач 3D-генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования признаков изображения | CLIP_VISION | Да | - |
| `начальное_изображение` | Входное изображение для обработки и кодирования | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования пикселей в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного латентного представления (по умолчанию: 256, шаг: 8) | INT | Да | 16 до MAX_RESOLUTION |
| `высота` | Высота выходного латентного представления (по умолчанию: 256, шаг: 8) | INT | Да | 16 до MAX_RESOLUTION |
| `размер_пакета` | Количество образцов для генерации в пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `высота` | Угол возвышения камеры в градусах (по умолчанию: 0.0, шаг: 0.1) | FLOAT | Да | -180.0 до 180.0 |
| `азимут` | Азимутальный угол камеры в градусах (по умолчанию: 0.0, шаг: 0.1) | FLOAT | Да | -180.0 до 180.0 |

**Примечание:** Параметры `width` и `height` используют шаг 8, поэтому значения задаются с шагом 8. Узел делит их на 8, чтобы определить размеры латентного представления. Перед кодированием VAE изображение масштабируется до заданных `width` и `height` с помощью билинейного увеличения с центральным кадрированием.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Положительные данные кондиционирования, объединяющие признаки изображения и эмбеддинги камеры, включая VAE-кодированное входное изображение в виде латента для конкатенации | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования с инициализированными нулями признаками и инициализированным нулями латентом | CONDITIONING |
| `latent` | Латентное представление, инициализированное нулями, с размерностями [batch_size, 4, height//8, width//8] | LATENT |
