# StableZero123_Кондиционирование

Узел StableZero123_Conditioning обрабатывает входное изображение и углы камеры, формируя данные кондиционирования и латентные представления для генерации 3D-моделей. Он использует модель CLIP vision для кодирования признаков изображения, объединяет их с эмбеддингом камеры, рассчитанным на основе углов elevation и azimuth, и создает позитивное и негативное кондиционирование, а также латентное представление для последующих задач 3D-генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования признаков изображения | CLIP_VISION | Да | - |
| `начальное_изображение` | Входное изображение, которое нужно обработать и закодировать | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования пикселей в латентное пространство | VAE | Да | - |
| `ширина` | Ширина выходного латентного представления (по умолчанию: 256, должно быть кратно 8) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного латентного представления (по умолчанию: 256, должно быть кратно 8) | INT | Да | 16 to MAX_RESOLUTION |
| `размер_пакета` | Количество образцов для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `высота` | Угол возвышения камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |
| `азимут` | Азимутальный угол камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 до 180.0 |

**Примечание:** Параметры `width` и `height` должны быть кратны 8, так как узел автоматически делит их на 8 для создания размеров латентного представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `положительный` | Позитивные данные кондиционирования, объединяющие признаки изображения и эмбеддинги камеры, включая закодированное VAE входное изображение в качестве латентного представления для конкатенации | CONDITIONING |
| `отрицательный` | Негативные данные кондиционирования с признаками, инициализированными нулями, и нулевым латентным представлением | CONDITIONING |
| `латентный` | Латентное представление, инициализированное нулями, с размерами [batch_size, 4, height//8, width//8] | LATENT |
