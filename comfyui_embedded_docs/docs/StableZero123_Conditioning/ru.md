# StableZero123_Кондиционирование

Узел `StableZero123_Conditioning` обрабатывает входное изображение и углы камеры для генерации данных кондиционирования и латентного представления, используемых при создании 3D-моделей. Он применяет модель CLIP vision для кодирования признаков изображения, объединяет их с эмбеддингами камеры на основе углов места и азимута, а также формирует позитивное и негативное кондиционирование вместе с латентным представлением для последующих этапов 3D-генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip_vision` | Модель CLIP vision, используемая для кодирования признаков изображения | CLIP_VISION | Да | - |
| `init_image` | Входное изображение для обработки и кодирования | IMAGE | Да | - |
| `vae` | Модель VAE, используемая для кодирования пикселей в латентное пространство | VAE | Да | - |
| `width` | Ширина выходного латентного представления (по умолчанию: 256, должно делиться на 8) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного латентного представления (по умолчанию: 256, должно делиться на 8) | INT | Да | 16 to MAX_RESOLUTION |
| `batch_size` | Количество образцов для генерации в батче (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `elevation` | Угол места камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 to 180.0 |
| `azimuth` | Азимутальный угол камеры в градусах (по умолчанию: 0.0) | FLOAT | Да | -180.0 to 180.0 |

**Примечание:** Параметры `width` и `height` должны делиться на 8, так как узел автоматически делит их на 8 для создания размеров латентного представления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Данные позитивного кондиционирования, объединяющие признаки изображения и эмбеддинги камеры | CONDITIONING |
| `negative` | Данные негативного кондиционирования с признаками, инициализированными нулями | CONDITIONING |
| `latent` | Латентное представление размерностью [batch_size, 4, height//8, width//8] | LATENT |
