# WanMoveConcatTrack

Узел WanMoveConcatTrack объединяет два набора данных отслеживания движения в одну более длинную последовательность. Он работает путём объединения путей треков и масок видимости из входных треков по соответствующим размерностям. Если передан только один входной трек, он просто передаёт эти данные без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `tracks_1` | Первый набор данных отслеживания движения для конкатенации. | TRACKS | Да |  |
| `tracks_2` | Необязательный второй набор данных отслеживания движения. Если не задан, `tracks_1` передаётся напрямую на выход. | TRACKS | Нет |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `tracks` | Конкатенированные данные отслеживания движения, содержащие объединённые `track_path` и `track_visibility` из входных данных. | TRACKS |
