# WanMoveConcatTrack

Узел WanMoveConcatTrack объединяет два набора данных отслеживания движения в одну более длинную последовательность. Он работает путём соединения траекторий треков и масок видимости из входных треков по соответствующим измерениям. Если предоставлен только один вход треков, он просто передаёт эти данные без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `tracks_1` | Первый набор данных отслеживания движения для объединения. | TRACKS | Да |  |
| `tracks_2` | Необязательный второй набор данных отслеживания движения. Если не предоставлен, `tracks_1` передаётся напрямую на выход. | TRACKS | Нет |  |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `tracks` | Объединённые данные отслеживания движения, содержащие комбинированные `track_path` и `track_visibility` из входов. Возвращает `tracks_1` без изменений, когда `tracks_2` не подключён. | TRACKS |
