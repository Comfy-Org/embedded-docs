# 自适应投影引导

APG（自适应投影引导）节点通过调整扩散过程中引导的应用方式来修改采样过程。它将引导向量相对于条件输出分解为平行分量和正交分量，从而实现对图像生成更精确的控制。该节点提供了用于缩放引导、归一化其幅度以及应用动量以实现扩散步骤间更平滑过渡的参数。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要应用自适应投影引导的扩散模型 | MODEL | 是 | - |
| `eta` | 控制平行引导向量的缩放比例。设置为 1 时表现为默认 CFG 行为（默认值：1.0）。 | FLOAT | 是 | -10.0 到 10.0 |
| `norm_threshold` | 将引导向量归一化到此值，设置为 0 时禁用归一化（默认值：5.0）。 | FLOAT | 是 | 0.0 到 50.0 |
| `momentum` | 控制扩散过程中引导的运行平均值，设置为 0 时禁用（默认值：0.0）。 | FLOAT | 是 | -5.0 到 1.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 返回经过修改的模型，其采样过程已应用自适应投影引导 | MODEL |
