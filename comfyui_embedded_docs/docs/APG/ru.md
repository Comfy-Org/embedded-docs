# Адаптивное проекционное управление

Узел APG (Adaptive Projected Guidance) изменяет процесс семплирования, регулируя способ применения управления (guidance) во время диффузии. Он разделяет вектор управления на параллельную и ортогональную составляющие относительно условного выхода, что обеспечивает более контролируемую генерацию изображений. Узел предоставляет параметры для масштабирования управления, нормализации его величины и применения моментума для более плавных переходов между шагами диффузии.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой применяется адаптивное проекционное управление | MODEL | Да | - |
| `eta` | Управляет масштабом параллельного вектора управления. При значении 1 поведение соответствует стандартному CFG (по умолчанию: 1.0). | FLOAT | Да | -10.0 to 10.0 |
| `norm_threshold` | Нормализует вектор управления до этого значения; при значении 0 нормализация отключена (по умолчанию: 5.0). | FLOAT | Да | 0.0 to 50.0 |
| `momentum` | Управляет скользящим средним управления во время диффузии; при значении 0 отключено (по умолчанию: 0.0). | FLOAT | Да | -5.0 to 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Возвращает изменённую модель, к процессу семплирования которой применено адаптивное проекционное управление | MODEL |
