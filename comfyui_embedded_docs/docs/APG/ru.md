# Адаптивное проекционное управление

Узел APG (Adaptive Projected Guidance) изменяет процесс сэмплирования, регулируя способ применения направляющего воздействия (guidance) во время диффузии. Он разделяет вектор направляющего воздействия на параллельную и ортогональную компоненты относительно условного выхода, что обеспечивает более контролируемую генерацию изображений. Узел предоставляет параметры для масштабирования направляющего воздействия, нормализации его величины и применения импульса (momentum) для более плавных переходов между шагами диффузии.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель диффузии, к которой применяется адаптивная проекционная направляющая | MODEL | Да | - |
| `эта` | Управляет масштабом параллельного вектора направляющей. Поведение стандартного CFG при значении 1 (по умолчанию: 1.0). | FLOAT | Да | -10.0 до 10.0 |
| `порог_нормализации` | Нормализует вектор направляющей до этого значения; нормализация отключена при значении 0 (по умолчанию: 5.0). | FLOAT | Да | 0.0 до 50.0 |
| `импульс` | Управляет скользящим средним направляющей во время диффузии; отключено при значении 0 (по умолчанию: 0.0). | FLOAT | Да | -5.0 до 1.0 |

Примечание: Когда уровень шума (`sigma`) увеличивается во время сэмплирования, скользящее среднее импульса сбрасывается до нуля. Если модель предоставляет только один выход conditioning (без отдельного безусловного conditioning), корректировка направляющей пропускается, и conditioning остается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Возвращает измененную модель, к процессу сэмплирования которой применена адаптивная проекционная направляющая | MODEL |
