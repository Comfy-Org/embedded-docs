# 自適應投影引導

APG（Adaptive Projected Guidance）節點透過調整擴散期間的引導應用方式來修改採樣過程。它將引導向量相對於條件輸出拆分為平行分量與正交分量，從而實現更可控的圖像生成。此節點提供參數來縮放引導、正規化其幅度，並應用動量以實現擴散步驟之間更平滑的過渡。

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `model` | 要應用自適應投影引導的擴散模型 | MODEL | 是 | - |
| `eta` | 控制平行引導向量的縮放。設定為 1 時為預設 CFG 行為（預設值：1.0）。 | FLOAT | 是 | -10.0 至 10.0 |
| `norm_threshold` | 將引導向量正規化為此值，設定為 0 時停用正規化（預設值：5.0）。 | FLOAT | 是 | 0.0 至 50.0 |
| `momentum` | 控制擴散期間引導的運行平均值，設定為 0 時停用（預設值：0.0）。 | FLOAT | 是 | -5.0 至 1.0 |
