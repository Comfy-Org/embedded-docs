# 自適應投影引導

APG（自適應投影引導）節點透過調整擴散過程中引導的應用方式來修改取樣過程。它將引導向量相對於條件輸出分離為平行與正交分量，從而實現更可控的影像生成。此節點提供參數來縮放引導、正規化其大小，並應用動量以在擴散步驟之間實現更平滑的轉換。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `模型` | 要應用自適應投影引導的擴散模型 | MODEL | 是 | - |
| `eta` | 控制平行引導向量的縮放。設定為 1 時為預設 CFG 行為（預設值：1.0）。 | FLOAT | 是 | -10.0 至 10.0 |
| `norm_threshold` | 將引導向量正規化為此值，設定為 0 時停用正規化（預設值：5.0）。 | FLOAT | 是 | 0.0 至 50.0 |
| `momentum` | 控制擴散期間引導的移動平均，設定為 0 時停用（預設值：0.0）。 | FLOAT | 是 | -5.0 至 1.0 |

注意：當取樣過程中雜訊等級（`sigma`）增加時，動量移動平均會重設為零。如果模型僅提供單一條件輸出（沒有單獨的無條件條件），則跳過引導調整，並保持條件不變。

## 輸出

| --- | --- | --- |
