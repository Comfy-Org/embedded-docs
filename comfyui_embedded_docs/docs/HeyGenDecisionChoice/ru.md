# HeyGen Decision (Choice)

Выберите один из собственных вариантов для текста, изображений, аудио или видео, которые вы подключаете, и получите обратно выбранный вариант, его позицию и значение уверенности. Подключите `choice` к узлу Branch, входы которого имеют те же имена вариантов, или выполняйте маршрутизацию по `option_index`. Узел Branch принимает не более 32 входов, поэтому для наборов с большим числом вариантов используйте маршрутизацию по `option_index`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. `heygen-decision-1-turbo` быстрее и дешевле, чем `heygen-decision-1` (по умолчанию: `"heygen-decision-1"`). | COMBO | Да | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | Вопрос, на который отвечают варианты, до 5000 символов (по умолчанию: "What style is the image?"). | STRING | Да | от 1 до 5000 символов |
| `options` | Один вариант на строку, используется точно так, как введён, до 128 символов каждый. Добавьте вариант, например `other`, для входов, которые не подходят ни под один из них (по умолчанию: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | Да | от 2 до 255 вариантов |
| `images` | Изображения для классификации, всего до 4, с учётом каждого кадра пакета. Они нумеруются `image_1`–`image_4` по порядку по всем слотам. | IMAGE | Нет | До 4 изображений |
| `audio_1` | Аудио для классификации, до 30 минут. | AUDIO | Нет | До 30 минут |
| `video_1` | Видео для классификации, до 60 секунд. | VIDEO | Нет | До 60 секунд |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Укажите от 2 до 255 вариантов, ни один из них не должен повторяться, и никакие два не должны отличаться только регистром букв, иначе узел выдаст ошибку. Подключите хотя бы один вход для классификации и указывайте их по имени слота в вопросе, например: «Какое время года показано в image_1?».

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `choice` | Выбранный вариант, точно как он был записан в `options`. | STRING |
| `option_index` | Позиция выбранного варианта в `options`, начиная с 0. | INT |
| `confidence` | Уверенность в выборе, от 0 до 1. | FLOAT |
