# HeyGen Decision (Choice)

Выберите один из собственных вариантов для подключаемых текста, изображений, аудио или видео и получите выбранный вариант, его позицию и степень уверенности. Подключите `choice` к узлу Branch, входы которого имеют те же имена вариантов, или выполняйте маршрутизацию по `option_index`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. `heygen-decision-1-turbo` работает быстрее и стоит меньше, чем `heygen-decision-1` (по умолчанию: `"heygen-decision-1"`). | COMBO | Да | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | Вопрос, на который отвечают варианты, до 5000 символов (по умолчанию: "What style is the image?"). | STRING | Да | от 1 до 5000 символов |
| `options` | Один вариант на строку, используется ровно так, как введено, до 128 символов каждый. Добавьте вариант, например `other`, для входов, которые не подходят ни под один из них (по умолчанию: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | Да | от 2 до 255 вариантов |
| `images` | Изображения для классификации, всего до 4, с учётом каждого кадра пакета. Они нумеруются от `image_1` до `image_4` по порядку по всем сокетам. | IMAGE | Нет | До 4 изображений |
| `audio_1` | Аудио для классификации, до 30 минут. | AUDIO | Нет | До 30 минут |
| `video_1` | Видео для классификации, до 60 секунд. | VIDEO | Нет | До 60 секунд |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Укажите от 2 до 255 вариантов; ни один не должен повторяться, и никакие два не должны различаться только регистром букв, иначе узел выдаст ошибку. Подключите хотя бы один вход для классификации и назовите их по имени сокета в вопросе, например «Какой сезон показан на image_1?».

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `choice` | Выбранный вариант, ровно в том виде, в каком он был записан в `options`. | STRING |
| `option_index` | Позиция выбранного варианта в `options`, начиная с 0. | INT |
| `confidence` | Степень уверенности в выборе, от 0 до 1. | FLOAT |
