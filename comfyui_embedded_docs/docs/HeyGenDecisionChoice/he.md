# HeyGen Decision (Choice)

בחר אחת מהאפשרויות שלך עבור הטקסט, התמונות, האודיו או הווידאו שאתה מחבר, וקבל בחזרה את האפשרות שנבחרה, את מיקומה ואת רמת הביטחון. חבר את `choice` לצומת Branch שקליטיה נושאים את אותם שמות אפשרויות, או נתב לפי `option_index`. צומת Branch מקבל לכל היותר 32 קלטים, לכן נתב קבוצות אפשרויות גדולות יותר באמצעות `option_index`.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש. `heygen-decision-1-turbo` מהיר יותר וזול יותר מ-`heygen-decision-1` (ברירת מחדל: `"heygen-decision-1"`). | COMBO | כן | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | השאלה שהאפשרויות עונות עליה, עד 5000 תווים (ברירת מחדל: "What style is the image?"). | STRING | כן | 1 עד 5000 תווים |
| `options` | אפשרות אחת בכל שורה, בשימוש בדיוק כפי שהוקלדה, עד 128 תווים כל אחת. הוסף אפשרות כגון `other` עבור קלטים שאינם מתאימים לאף אחת מהן (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | כן | 2 עד 255 אפשרויות |
| `images` | תמונות לסיווג, עד 4 בסך הכול, כאשר נספר כל פריים באצווה. הן ממוספרות `image_1` עד `image_4` לפי הסדר על פני השקעים. | IMAGE | לא | עד 4 תמונות |
| `audio_1` | אודיו לסיווג, עד 30 דקות. | AUDIO | לא | עד 30 דקות |
| `video_1` | וידאו לסיווג, עד 60 שניות. | VIDEO | לא | עד 60 שניות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

ספק 2 עד 255 אפשרויות, כאשר אף אחת מהן אינה מופיעה פעמיים ואין אפשרויות שנבדלות רק באותיות רישיות/קטנות, אחרת הצומת תעלה שגיאה. חבר לפחות קלט אחד לסיווג, וציין את שמות השקעים בתוך השאלה, לדוגמה "איזו עונה מוצגת ב-image_1?".

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `choice` | האפשרות שנבחרה, בדיוק כפי שנכתבה ב-`options`. | STRING |
| `option_index` | מיקום האפשרות שנבחרה ב-`options`, החל מ-0. | INT |
| `confidence` | רמת הביטחון בבחירה, בין 0 ל-1. | FLOAT |
