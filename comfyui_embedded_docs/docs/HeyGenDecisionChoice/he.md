# HeyGen Decision (Choice)

בחרו אחת מהאפשרויות שאתם עצמכם מגדירים עבור הטקסט, התמונות, האודיו או הווידאו שאתם מחברים, וקבלו בחזרה את האפשרות שנבחרה, את מיקומה ואת רמת הביטחון. חברו את `choice` לצומת Branch שדרכי הקלט שלה נושאות את שמות האפשרויות הזהים, או נתבו לפי `option_index`.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל לשימוש. `heygen-decision-1-turbo` מהיר יותר וזול יותר מ-`heygen-decision-1` (ברירת מחדל: `"heygen-decision-1"`). | COMBO | כן | `"heygen-decision-1"`<br>`"heygen-decision-1-turbo"` |
| `question` | השאלה שעליה עונות האפשרויות, עד 5000 תווים (ברירת מחדל: "What style is the image?"). | STRING | כן | 1 עד 5000 תווים |
| `options` | אפשרות אחת בכל שורה, בשימוש בדיוק כפי שהוקלדה, עד 128 תווים כל אחת. הוסיפו אפשרות כגון `other` עבור קלטים שאינם מתאימים לאף אחת מהאפשרויות (ברירת מחדל: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | כן | 2 עד 255 אפשרויות |
| `images` | תמונות לסיווג, עד 4 בסך הכול, בספירת כל פריים באצווה. הן ממוספרות `image_1` עד `image_4` לפי הסדר לאורך השקעים. | IMAGE | לא | עד 4 תמונות |
| `audio_1` | אודיו לסיווג, עד 30 דקות. | AUDIO | לא | עד 30 דקות |
| `video_1` | וידאו לסיווג, עד 60 שניות. | VIDEO | לא | עד 60 שניות |
| `text` | הטקסט שהשאלה עוסקת בו, כגון פרומפט או תגובת LLM, עד 20000 תווים. | STRING | לא | עד 20000 תווים |

יש לספק בין 2 ל-255 אפשרויות, ללא כפילות וללא אפשרויות הנבדלות זו מזו רק ברישיות האותיות, אחרת הצומת תעלה שגיאה. חברו לפחות קלט אחד לסיווג ותנו להם שמות לפי השקע בתוך השאלה, למשל "Which season is shown in image_1?".

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `choice` | האפשרות שנבחרה, בדיוק כפי שנכתבה ב-`options`. | STRING |
| `option_index` | המיקום של האפשרות שנבחרה ב-`options`, החל מ-0. | INT |
| `confidence` | רמת הביטחון בבחירה, בין 0 ל-1. | FLOAT |
