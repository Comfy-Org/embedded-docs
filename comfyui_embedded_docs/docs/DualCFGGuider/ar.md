# موجّه CFG مزدوج

عقدة Dual CFG Guider تنشئ نظام توجيه لأخذ العينات يستخدم مدخلَي تكييف مع مدخل تكييف سلبي واحد. وتطبّق مقياسَي توجيه منفصلين للتحكم في مدى تأثير كل تكييف على النتيجة الناتجة، وتدعم طريقتين لدمج هذين المقياسين: "regular" و"nested".

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `model` | النموذج المستخدم للتوجيه | MODEL | نعم | - |
| `cond1` | مدخل التكييف الإيجابي الأول | CONDITIONING | نعم | - |
| `cond2` | مدخل التكييف الثاني، ويُستخدم كمرجع بين التكييف الإيجابي الأول والتكييف السلبي | CONDITIONING | نعم | - |
| `negative` | مدخل التكييف السلبي | CONDITIONING | نعم | - |
| `cfg_conds` | مقياس التوجيه المطبَّق على مدخل التكييف الإيجابي الأول (الافتراضي: 8.0) | FLOAT | نعم | 0.0 - 100.0 |
| `cfg_cond2_negative` | مقياس التوجيه المطبَّق بين التكييف الثاني والتكييف السلبي (الافتراضي: 8.0) | FLOAT | نعم | 0.0 - 100.0 |
| `style` | نمط التوجيه المطبَّق (الافتراضي: "regular"). عند ضبطه على "nested"، يتم تطبيق التوجيه بطريقة متداخلة | COMBO | نعم | "regular"<br>"nested" |

ملاحظة: في النمط `regular`، يتم تطبيق `cfg_cond2_negative` بين `cond2` و`negative`، ويتم تطبيق `cfg_conds` بين `cond1` و`cond2`. وفي النمط `nested`، يتم تطبيق `cfg_conds` أولًا بين `cond1` و`cond2`، ثم يتم توجيه التنبؤ الناتج بعيدًا عن `negative` باستخدام `cfg_cond2_negative`.

ملاحظة: في النمط `regular`، عندما تكون قيمة `cfg_cond2_negative` مساوية لـ 1.0 يتم تخطي التكييف السلبي، وعندما تكون قيمة `cfg_conds` مساوية لـ 1.0 أيضًا يتم تخطي التكييف الثاني كذلك. يؤدي هذا إلى تقليل عدد عمليات تقييم النموذج التي يتم تنفيذها.
