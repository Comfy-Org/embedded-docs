# موجّه CFG مزدوج

تُنشئ العقدة `DualCFGGuider` نظام إرشاد لأخذ العينات بتوجيه خالٍ من المصنف المزدوج. وهي تجمع بين مدخلَي توجيه إيجابيين ومدخل توجيه سلبي واحد، وتطبّق مقياسَي إرشاد منفصلين للتحكم في مدى تأثير كل توجيه على المخرجات المُولَّدة. وهي تدعم نمطين للجمع بين مقياسَي الإرشاد هذين: `"regular"` و`"nested"`.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المستخدم للإرشاد | MODEL | نعم | - |
| `الشرط 1` | المدخل التوجيهي الإيجابي الأول | CONDITIONING | نعم | - |
| `الشرط 2` | المدخل التوجيهي الثاني، يُستخدم كمرجع بين المدخل التوجيهي الإيجابي الأول والمدخل التوجيهي السلبي | CONDITIONING | نعم | - |
| `سلبي` | المدخل التوجيهي السلبي | CONDITIONING | نعم | - |
| `شروط CFG` | مقياس الإرشاد المطبَّق على المدخل التوجيهي الإيجابي الأول (الافتراضي: 8.0) | FLOAT | نعم | 0.0 - 100.0 |
| `شرط CFG 2 سلبي` | مقياس الإرشاد المطبَّق بين المدخل التوجيهي الثاني والمدخل التوجيهي السلبي (الافتراضي: 8.0) | FLOAT | نعم | 0.0 - 100.0 |
| `النمط` | نمط الإرشاد المطلوب تطبيقه (الافتراضي: `"regular"`). عند ضبطه على `"nested"`، يُطبَّق الإرشاد بطريقة متداخلة | COMBO | نعم | `"regular"`<br>`"nested"` |

ملاحظة: في النمط `regular`، يُطبَّق `cfg_cond2_negative` بين `cond2` و`negative`، ويُطبَّق `cfg_conds` بين `cond1` و`cond2`. وفي النمط `nested`، يُطبَّق `cfg_conds` أولاً بين `cond1` و`cond2`، ثم يُوجَّه التنبؤ الناتج بعيدًا عن `negative` باستخدام `cfg_cond2_negative`.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `GUIDER` | نظام إرشاد مُهيَّأ وجاهز للاستخدام مع أخذ العينات | GUIDER |
