# Dual CFG Guider

צומת Dual CFG Guider יוצר מערכת הנחיה לדגימה שמשתמשת בשני קלטי התניה יחד עם קלט התניה שלילי אחד. הוא מחיל שני מקדמי הנחיה נפרדים כדי לשלוט בעוצמת ההשפעה של כל התניה על התוצאה הנוצרת, ותומך בשתי דרכים לשילוב המקדמים הללו: "regular" ו-"nested".

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שבו יש להשתמש להנחיה | MODEL | כן | - |
| `cond1` | קלט ההתניה החיובי הראשון | CONDITIONING | כן | - |
| `cond2` | קלט ההתניה השני, המשמש כנקודת ייחוס בין ההתניה החיובית הראשונה להתניה השלילית | CONDITIONING | כן | - |
| `negative` | קלט ההתניה השלילי | CONDITIONING | כן | - |
| `cfg_conds` | מקדם ההנחיה המוחל על ההתניה החיובית הראשונה (ברירת מחדל: 8.0) | FLOAT | כן | 0.0 - 100.0 |
| `cfg_cond2_negative` | מקדם ההנחיה המוחל בין ההתניה השנייה להתניה השלילית (ברירת מחדל: 8.0) | FLOAT | כן | 0.0 - 100.0 |
| `style` | סגנון ההנחיה להחלה (ברירת מחדל: "regular"). כאשר הוא מוגדר ל-"nested", ההנחיה מוחלת באופן מקונן | COMBO | כן | "regular"<br>"nested" |

הערה: בסגנון `regular`, ‏`cfg_cond2_negative` מוחל בין `cond2` ל-`negative`, ו-`cfg_conds` מוחל בין `cond1` ל-`cond2`. בסגנון `nested`, ‏`cfg_conds` מוחל תחילה בין `cond1` ל-`cond2`, ולאחר מכן התחזית המתקבלת מונחית הרחק מ-`negative` באמצעות `cfg_cond2_negative`.

הערה: בסגנון `regular`, כאשר `cfg_cond2_negative` שווה ל-1.0, ההתניה השלילית מדולגת, וכאשר גם `cfg_conds` שווה ל-1.0, גם ההתניה השנייה מדולגת. הדבר מפחית את מספר הערכות המודל שמבוצעות.
