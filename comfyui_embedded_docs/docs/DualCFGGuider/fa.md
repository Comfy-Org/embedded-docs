# راهنمای DualCFG

گره DualCFGGuider یک سیستم هدایت برای نمونه‌برداری با هدایت بدون طبقه‌بندی دوگانه ایجاد می‌کند. این گره دو ورودی شرطی‌سازی را با یک ورودی شرطی‌سازی منفی ترکیب می‌کند و دو مقیاس هدایت جداگانه اعمال می‌کند تا نحوه تأثیر هر شرطی‌سازی بر خروجی تولیدشده را کنترل کند. این گره از دو سبک ترکیب این مقیاس‌های هدایت، «regular» و «nested» پشتیبانی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که برای هدایت استفاده می‌شود | MODEL | بله | - |
| `شرط ۱` | اولین ورودی شرطی‌سازی مثبت | CONDITIONING | بله | - |
| `شرط ۲` | دومین ورودی شرطی‌سازی که به عنوان مرجع بین اولین شرطی‌سازی مثبت و شرطی‌سازی منفی استفاده می‌شود | CONDITIONING | بله | - |
| `منفی` | ورودی شرطی‌سازی منفی | CONDITIONING | بله | - |
| `شرایط cfg` | مقیاس هدایت اعمال‌شده بر اولین شرطی‌سازی مثبت (پیش‌فرض: 8.0) | FLOAT | بله | 0.0 - 100.0 |
| `cfg_cond2 منفی` | مقیاس هدایت اعمال‌شده بین دومین شرطی‌سازی و شرطی‌سازی منفی (پیش‌فرض: 8.0) | FLOAT | بله | 0.0 - 100.0 |
| `استایل` | سبک هدایت برای اعمال (پیش‌فرض: "regular"). وقتی روی "nested" تنظیم شود، هدایت به صورت تودرتو اعمال می‌شود | COMBO | بله | "regular"<br>"nested" |

نکته: در سبک `regular`، `cfg_cond2_negative` بین `cond2` و `negative` اعمال می‌شود و `cfg_conds` بین `cond1` و `cond2` اعمال می‌شود. در سبک `nested`، ابتدا `cfg_conds` بین `cond1` و `cond2` اعمال می‌شود و سپس پیش‌بینی حاصل با استفاده از `cfg_cond2_negative` از `negative` دور می‌شود.
