# راهنمای DualCFG

گره Dual CFG Guider یک سیستم راهنمایی (guidance) برای نمونه‌گیری ایجاد می‌کند که از دو ورودی شرطی‌سازی (conditioning) به همراه یک ورودی شرطی‌سازی منفی استفاده می‌کند. این گره دو مقیاس راهنمایی مجزا را اعمال می‌کند تا میزان تأثیر هر یک از شرطی‌سازی‌ها بر نتیجه تولیدشده را کنترل کند و از دو روش برای ترکیب این مقیاس‌ها پشتیبانی می‌کند: "regular" و "nested".

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدلی که برای راهنمایی استفاده می‌شود | MODEL | بله | - |
| `cond1` | نخستین ورودی شرطی‌سازی مثبت | CONDITIONING | بله | - |
| `cond2` | دومین ورودی شرطی‌سازی که به‌عنوان مرجع میان نخستین شرطی‌سازی مثبت و شرطی‌سازی منفی به کار می‌رود | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی | CONDITIONING | بله | - |
| `cfg_conds` | مقیاس راهنمایی اعمال‌شده بر نخستین شرطی‌سازی مثبت (پیش‌فرض: 8.0) | FLOAT | بله | 0.0 - 100.0 |
| `cfg_cond2_negative` | مقیاس راهنمایی اعمال‌شده میان دومین شرطی‌سازی و شرطی‌سازی منفی (پیش‌فرض: 8.0) | FLOAT | بله | 0.0 - 100.0 |
| `style` | سبک راهنمایی که اعمال می‌شود (پیش‌فرض: "regular"). هنگامی که روی "nested" تنظیم شود، راهنمایی به‌صورت تودرتو اعمال می‌گردد | COMBO | بله | "regular"<br>"nested" |

توجه: در سبک `regular`، مقدار `cfg_cond2_negative` میان `cond2` و `negative` اعمال می‌شود و مقدار `cfg_conds` میان `cond1` و `cond2` اعمال می‌گردد. در سبک `nested`، ابتدا `cfg_conds` میان `cond1` و `cond2` اعمال می‌شود و سپس پیش‌بینی حاصل با استفاده از `cfg_cond2_negative` از `negative` دور می‌شود.

توجه: در سبک `regular`، هنگامی که `cfg_cond2_negative` برابر با 1.0 باشد، شرطی‌سازی منفی نادیده گرفته می‌شود و اگر `cfg_conds` نیز برابر با 1.0 باشد، دومین شرطی‌سازی هم نادیده گرفته می‌شود. این امر شمار ارزیابی‌های مدل را کاهش می‌دهد.
