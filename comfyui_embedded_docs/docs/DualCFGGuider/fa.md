# راهنمای DualCFG

گره DualCFGGuider یک سیستم راهنمایی برای نمونه‌برداری با راهنمایی دوگانه بدون طبقه‌بند ایجاد می‌کند. این گره دو ورودی شرطی‌سازی مثبت را با یک ورودی شرطی‌سازی منفی ترکیب می‌کند و مقیاس‌های راهنمایی متفاوتی را برای هر جفت شرطی‌سازی اعمال می‌کند تا میزان تأثیر هر پرامپت بر خروجی تولیدشده را کنترل کند.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `model` | مدل مورد استفاده برای راهنمایی. | MODEL | بله | - |
| `cond1` | اولین ورودی شرطی‌سازی مثبت. | CONDITIONING | بله | - |
| `cond2` | دومین ورودی شرطی‌سازی مثبت، که به‌عنوان شرطی‌سازی میانی در نظر گرفته می‌شود. | CONDITIONING | بله | - |
| `negative` | ورودی شرطی‌سازی منفی. | CONDITIONING | بله | - |
| `cfg_conds` | مقیاس راهنمایی اعمال‌شده بین `cond1` و `cond2` (پیش‌فرض: 8.0). | FLOAT | بله | 0.0 - 100.0 |
| `cfg_cond2_negative` | مقیاس راهنمایی اعمال‌شده بین `cond2` و شرطی‌سازی منفی (پیش‌فرض: 8.0). | FLOAT | بله | 0.0 - 100.0 |
| `style` | سبک راهنمایی مورد اعمال (پیش‌فرض: "regular"). حالت "regular" هر دو مقیاس راهنمایی را در یک مرحله ترکیب می‌کند؛ حالت "nested" ابتدا `cfg_conds` را اعمال کرده و سپس نتیجه را با `cfg_cond2_negative` نسبت به شرطی‌سازی منفی مقیاس‌بندی می‌کند. | COMBO | بله | "regular"<br>"nested" |

## خروجی‌ها

| Output Name | Description | Data Type |
| --- | --- | --- |
| `GUIDER` | یک سیستم راهنمایی پیکربندی‌شده که برای استفاده در نمونه‌برداری آماده است. | GUIDER |
