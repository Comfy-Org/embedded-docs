# Двойной CFG Гид

Узел DualCFGGuider создает систему управления для двойного бесклассового направляющего сэмплирования (dual classifier-free guidance). Он объединяет два положительных входа conditioning с одним отрицательным входом conditioning, применяя различные масштабы управления к каждой паре conditioning, чтобы контролировать, насколько сильно каждый промпт влияет на генерируемый результат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель для использования в управлении. | MODEL | Да | - |
| `cond1` | Первый положительный вход conditioning. | CONDITIONING | Да | - |
| `cond2` | Второй положительный вход conditioning, рассматриваемый как промежуточный conditioning. | CONDITIONING | Да | - |
| `negative` | Отрицательный вход conditioning. | CONDITIONING | Да | - |
| `cfg_conds` | Масштаб управления, применяемый между `cond1` и `cond2` (по умолчанию: 8.0). | FLOAT | Да | 0.0 - 100.0 |
| `cfg_cond2_negative` | Масштаб управления, применяемый между `cond2` и отрицательным conditioning (по умолчанию: 8.0). | FLOAT | Да | 0.0 - 100.0 |
| `style` | Применяемый стиль управления (по умолчанию: "regular"). "regular" объединяет оба масштаба управления за один шаг; "nested" сначала применяет `cfg_conds`, а затем масштабирует результат с помощью `cfg_cond2_negative` относительно отрицательного conditioning. | COMBO | Да | "regular"<br>"nested" |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Настроенная система управления, готовая к использованию с сэмплированием. | GUIDER |
