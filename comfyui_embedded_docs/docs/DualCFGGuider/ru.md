# Двойной CFG Гид

### DualCFGGuider

Узел DualCFGGuider создает направляющую систему для двойного семплинга с бесклассификаторным направлением. Он объединяет два входных conditioning-сигнала с одним негативным conditioning-сигналом и применяет две отдельные шкалы направления, чтобы контролировать, насколько сильно каждый conditioning влияет на генерируемый результат. Поддерживаются два стиля комбинирования этих шкал направления: «regular» и «nested».

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для направления | MODEL | Да | - |
| `cond1` | Первый положительный conditioning-вход | CONDITIONING | Да | - |
| `cond2` | Второй conditioning-вход, используемый как эталон между первым положительным conditioning и негативным conditioning | CONDITIONING | Да | - |
| `отрицательный` | Негативный conditioning-вход | CONDITIONING | Да | - |
| `cfg_conds` | Масштаб направления, применяемый к первому положительному conditioning (по умолчанию: 8.0) | FLOAT | Да | 0.0 - 100.0 |
| `cfg_cond2_negative` | Масштаб направления, применяемый между вторым conditioning и негативным conditioning (по умолчанию: 8.0) | FLOAT | Да | 0.0 - 100.0 |
| `стиль` | Стиль направления (по умолчанию: "regular"). При значении "nested" направление применяется вложенным образом | COMBO | Да | "regular"<br>"nested" |

Примечание: В стиле `regular` `cfg_cond2_negative` применяется между `cond2` и `negative`, а `cfg_conds` — между `cond1` и `cond2`. В стиле `nested` `cfg_conds` применяется сначала между `cond1` и `cond2`, а затем полученный прогноз направляется от `negative` с помощью `cfg_cond2_negative`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `GUIDER` | Настроенная направляющая система, готовая к использованию для сэмплинга | GUIDER |
