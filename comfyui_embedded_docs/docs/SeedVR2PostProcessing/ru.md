# Постобработка вывода SeedVR2

Этот узел выравнивает сгенерированное изображение с исходным масштабированным изображением и применяет опциональную коррекцию цвета. Он принимает выходные данные процесса увеличения масштаба SeedVR2 и корректирует их, чтобы они соответствовали цветам и размерам исходного эталонного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Сгенерированное изображение для обработки. | IMAGE | Да | - |
| `original_resized_images` | Исходное масштабированное изображение до предварительной обработки, используется как эталон. | IMAGE | Да | - |
| `color_correction_method` | Метод согласования цветов сгенерированного изображения с исходным. lab: перенос цвета в пространстве CIELAB с сохранением деталей (наиболее точный). wavelet: перенос низкочастотного цвета с сохранением увеличенных высокочастотных деталей. adain: согласование среднего/стандартного отклонения по каждому каналу (самый быстрый, общий оттенок). none: пропустить перенос цвета (только выравнивание геометрии). (по умолчанию: "lab") | COMBO | Да | `"lab"`<br>`"wavelet"`<br>`"adain"`<br>`"none"` |

**Примечание:** Выходное изображение обрезается до меньшей высоты и ширины из сгенерированного и эталонного изображений, а итоговые размеры округляются вниз до четных чисел. Если эталонное изображение имеет альфа-канал (4 канала), он сохраняется и применяется к выходному изображению. Оба входных данных могут быть 4D или 5D тензорами изображений, и выходные данные используют ту же размерность, что и входное сгенерированное изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Выровненное изображение с цветовой коррекцией. | IMAGE |
