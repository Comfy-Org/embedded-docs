# Постобработка вывода SeedVR2

Этот узел выравнивает сгенерированное изображение относительно исходного изображения с изменённым размером и применяет опциональную цветокоррекцию. Он принимает результат процесса апскейлинга SeedVR2 и подстраивает его под цвета и размеры исходного эталонного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Сгенерированное изображение для обработки. | IMAGE | Да | - |
| `original_resized_images` | Исходное изображение с изменённым размером до предварительной обработки, используемое в качестве эталона. | IMAGE | Да | - |
| `color_correction_method` | Метод сопоставления цветов сгенерированного изображения с исходным изображением. lab: перенос цвета в пространстве CIELAB с сохранением деталей (наиболее точный). wavelet: перенос низкочастотного цвета с сохранением высокочастотных деталей после апскейлинга. adain: сопоставление среднего/стандартного отклонения по каждому каналу (самый быстрый, глобальный оттенок). none: пропустить перенос цвета (только геометрическое выравнивание). (по умолчанию: "lab") | COMBO | Да | `"lab"`<br>`"wavelet"`<br>`"adain"`<br>`"none"` |

**Примечание:** Оба входа могут быть 4-мерными (батч, высота, ширина, каналы) или 5-мерными (батч, кадры, высота, ширина, каналы) тензорами. Узел обрезает оба тензора до наименьшего батча, количества кадров, высоты и ширины, поэтому они не обязаны точно совпадать. Когда используется метод цветокоррекции, отличный от `none`, эталонное изображение сначала изменяется до размера выхода. Цветокоррекция обрабатывается чанками с учётом памяти, переключаясь на меньший размер чанка при нехватке памяти. Высота и ширина выхода округляются вниз до чётных чисел. Если эталонное изображение имеет альфа-канал (4 канала), этот альфа-канал сохраняется и применяется к выходу.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Выровненное изображение с цветокоррекцией. | IMAGE |
