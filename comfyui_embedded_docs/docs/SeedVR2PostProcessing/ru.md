# Постобработка вывода SeedVR2

Данный узел выравнивает сгенерированное изображение по исходному изображению с изменённым размером и применяет дополнительную коррекцию цвета. Он принимает результат процесса увеличения масштаба SeedVR2 и приводит его в соответствие с цветами и размерами исходного эталонного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `images` | Сгенерированное изображение для обработки. | IMAGE | Да | - |
| `original_resized_images` | Исходное изображение с изменённым размером до предварительной обработки, используется как эталон. | IMAGE | Да | - |
| `color_correction_method` | Метод согласования цветов сгенерированного изображения с исходным. lab: перенос цвета в цветовом пространстве CIELAB с сохранением деталей (наиболее точен). wavelet: перенос низкочастотного цвета с сохранением высокочастотных деталей после увеличения масштаба. adain: сопоставление среднего/стандартного отклонения по каналам (самый быстрый, глобальная тонировка). none: пропустить перенос цвета (только выравнивание геометрии). (по умолчанию: `"lab"`) | COMBO | Да | `"lab"`<br>`"wavelet"`<br>`"adain"`<br>`"none"` |

**Примечание:** Оба входных тензора могут быть 4-D (пакет, высота, ширина, каналы) или 5-D (пакет, кадры, высота, ширина, каналы). Узел обрезает оба тензора до наименьших значений размера пакета, количества кадров, высоты и ширины, поэтому они не обязаны точно совпадать. Выходная высота и ширина округляются вниз до чётных чисел. Если эталонное изображение имеет альфа-канал (4 канала), этот альфа-канал сохраняется и применяется к выходному изображению.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `images` | Выровненное изображение с коррекцией цвета. | IMAGE |
