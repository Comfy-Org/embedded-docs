# 後處理 SeedVR2 輸出

此節點會將生成的影像與原始調整尺寸後的影像對齊，並套用可選的色彩校正。它接收 SeedVR2 放大處理的輸出，並調整該輸出以符合原始參考影像的色彩與尺寸。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `images` | 要處理的生成影像。 | IMAGE | 是 | - |
| `original_resized_images` | 預處理前的原始調整尺寸影像，用作參考。 | IMAGE | 是 | - |
| `color_correction_method` | 將生成影像色彩匹配至原始影像的方法。lab：在 CIELAB 空間中轉移色彩，保留細節（最忠實）。wavelet：轉移低頻色彩，保留放大後的高頻細節。adain：匹配每通道平均值/標準差（最快，全域色調）。none：跳過色彩轉移（僅幾何對齊）。（預設值："lab"） | COMBO | 是 | `"lab"`<br>`"wavelet"`<br>`"adain"`<br>`"none"` |

**注意：** 這兩個輸入可以是 4-D（批次、高度、寬度、通道）或 5-D（批次、影格、高度、寬度、通道）張量。此節點會將兩者裁剪至最小的批次、影格數、高度與寬度，因此它們不需要完全相符。當使用 `none` 以外的色彩校正方法時，參考影像會先調整尺寸至輸出尺寸。色彩校正會以記憶體感知分塊方式處理，若記憶體不足則退回較小的分塊大小。輸出高度與寬度會向下取整為偶數。若參考影像具有 Alpha 通道（4 個通道），該 Alpha 通道會被保留並套用至輸出。
