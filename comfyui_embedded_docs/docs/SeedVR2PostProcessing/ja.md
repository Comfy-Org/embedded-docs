# SeedVR2出力の後処理

このノードは、生成された画像を元のリサイズ画像に位置合わせし、必要に応じて色補正を適用します。SeedVR2 アップスケーリング処理の出力を受け取り、元の参照画像の色と寸法に合うように調整します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 処理する生成画像。 | IMAGE | はい | - |
| `original_resized_images` | 前処理前の元のリサイズ画像。参照として使用します。 | IMAGE | はい | - |
| `color_correction_method` | 生成画像の色を元の画像に合わせる方法。lab: CIELAB色空間で色を転送し、ディテールを保持（最も忠実）。wavelet: 低周波の色を転送し、アップスケールされた高周波のディテールを維持。adain: チャンネルごとの平均と標準偏差を一致させます（最速、全体的な色かぶり）。none: 色転送をスキップ（幾何学的な位置合わせのみ）。(デフォルト: `"lab"`) | COMBO | はい | `"lab"`<br>`"wavelet"`<br>`"adain"`<br>`"none"` |

**注記:** 出力は、生成画像と参照画像の高さと幅のうち小さい方にクロップされ、最終的な寸法は偶数に切り捨てられます。参照画像にアルファチャンネル（4チャンネル）がある場合は、それが保持され出力に適用されます。両方の入力は4次元または5次元の画像テンソルに対応しており、出力は生成画像の入力と同じ次元数になります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | 位置合わせおよび色補正後の画像。 | IMAGE |
