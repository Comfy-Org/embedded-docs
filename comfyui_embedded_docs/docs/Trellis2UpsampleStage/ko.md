# Trellis2UpsampleStage

이 노드는 첫 번째 형상 단계 샘플링 패스에서 생성된 512 해상도 형상 잠재를 가져와 더 높은 목표 해상도로 업스케일링하고, 두 번째 형상 단계 샘플링 패스에 필요한 컨디셔닝과 잠재를 준비합니다. 또한 단계별 메타데이터를 컨디셔닝에 첨부하여 모델이 생성 중에 이를 사용할 수 있게 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 업스케일링 단계 형상 메타데이터가 첨부되는 긍정 컨디셔닝입니다. | CONDITIONING | 예 | |
| `negative` | 업스케일링 단계 형상 메타데이터가 첨부되는 부정 컨디셔닝입니다. | CONDITIONING | 예 | |
| `shape_latent` | 첫 번째 형상 단계 KSampler에서 출력된 512 해상도 형상 잠재입니다. | LATENT | 예 | |
| `vae` | 형상 잠재를 고해상도 희소 좌표로 디코딩하는 데 사용되는 Trellis2 VAE입니다. | VAE | 예 | |
| `target_resolution` | 업스케일링된 형상의 복셀 해상도입니다. 값이 높을수록 더 세밀해지고 VRAM을 더 많이 사용합니다. 기본값: 1024. | INT | 예 | 1024 - 2048 (step 128) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 업스케일링 단계 형상 메타데이터가 첨부된 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 업스케일링 단계 형상 메타데이터가 첨부된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 목표 해상도에서 두 번째 형상 단계 샘플링 패스를 위해 준비된 0으로 채워진 잠재입니다. 업스케일링된 좌표와 해상도 메타데이터를 포함합니다. | LATENT |
