# مرحلهٔ Upsample ‏Trellis2

این گره یک لاتنت شکل با وضوح ۵۱۲ را به مختصات پراکنده با وضوح بالا ارتقا می‌دهد و پاس نمونه‌گیری دوم مرحله شکل را در وضوح هدف آماده می‌کند. این گره فراداده هر مرحله را به شرطی‌سازی متصل می‌کند تا مدل بتواند در طول تولید از آن استفاده کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مثبت` | شرطی‌سازی مثبتی که فراداده شکل مرحله ارتقای مقیاس به آن متصل می‌شود. | CONDITIONING | بله | |
| `منفی` | شرطی‌سازی منفی‌ای که فراداده شکل مرحله ارتقای مقیاس به آن متصل می‌شود. | CONDITIONING | بله | |
| `shape_latent` | لاتنت شکل با وضوح ۵۱۲ که خروجی اولین KSampler مرحله شکل است. | LATENT | بله | |
| `vae` | VAE مدل Trellis2 که برای رمزگشایی لاتنت شکل به مختصات پراکنده با وضوح بالا استفاده می‌شود. | VAE | بله | |
| `target_resolution` | وضوح وکسل شکل ارتقایافته. مقدار بیشتر = جزئیات بیشتر، VRAM بیشتر. پیش‌فرض: 1024. | INT | بله | 1024 - 2048 (گام: 128) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت با فراداده شکل مرحله ارتقای مقیاس متصل‌شده. | CONDITIONING |
| `negative` | شرطی‌سازی منفی با فراداده شکل مرحله ارتقای مقیاس متصل‌شده. | CONDITIONING |
| `latent` | لاتنت پرشده با صفر که برای پاس نمونه‌گیری دوم مرحله شکل در وضوح هدف آماده شده است و مختصات ارتقایافته، تعداد مختصات هر نمونه و فراداده وضوح مختصات را حمل می‌کند. | LATENT |
