# Trellis2UpsampleStage

این گره، لاتنت شکل با وضوح 512 را که توسط اولین پاس نمونه‌برداری مرحله شکل تولید شده است دریافت کرده، آن را به وضوح هدف بالاتری بزرگ‌نمایی می‌کند و کاندیشنینگ و لاتنت مورد نیاز برای دومین پاس نمونه‌برداری مرحله شکل را آماده می‌سازد. این گره، فراداده‌های مربوط به هر مرحله را به کاندیشنینگ متصل می‌کند تا مدل بتواند در طول تولید از آن استفاده کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|----------|-----------|---------|--------|
| `positive` | کاندیشنینگ مثبتی که فراداده‌های شکل مرحله بزرگ‌نمایی به آن متصل می‌شود. | CONDITIONING | بله | |
| `negative` | کاندیشنینگ منفی که فراداده‌های شکل مرحله بزرگ‌نمایی به آن متصل می‌شود. | CONDITIONING | بله | |
| `shape_latent` | لاتنت شکل با وضوح 512 خروجی از اولین KSampler مرحله شکل. | LATENT | بله | |
| `vae` | VAE مدل Trellis2 که برای رمزگشایی لاتنت شکل به مختصات پراکنده با وضوح بالا استفاده می‌شود. | VAE | بله | |
| `target_resolution` | وضوح وکسل شکل بزرگ‌نمایی شده. مقدار بالاتر = جزئیات بیشتر، حافظه گرافیکی بیشتر. پیش‌فرض: 1024. | INT | بله | 1024 - 2048 (step 128) |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|------------|-------------|-----------|
| `positive` | کاندیشنینگ مثبت با فراداده‌های شکل مرحله بزرگ‌نمایی متصل شده. | CONDITIONING |
| `negative` | کاندیشنینگ منفی با فراداده‌های شکل مرحله بزرگ‌نمایی متصل شده. | CONDITIONING |
| `latent` | لاتنت پر از صفر که برای دومین پاس نمونه‌برداری مرحله شکل در وضوح هدف آماده شده و مختصات بزرگ‌نمایی شده و فراداده وضوح را حمل می‌کند. | LATENT |
