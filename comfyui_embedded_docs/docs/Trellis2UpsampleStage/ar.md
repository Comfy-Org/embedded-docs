# Trellis2UpsampleStage

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `positive` | التكييف الإيجابي الذي تُرفق به البيانات الوصفية للشكل الخاصة بمرحلة رفع الدقة. | CONDITIONING | نعم | |
| `negative` | التكييف السلبي الذي تُرفق به البيانات الوصفية للشكل الخاصة بمرحلة رفع الدقة. | CONDITIONING | نعم | |
| `shape_latent` | الكامن (latent) للشكل بدقة 512 الناتج من أول KSampler في مرحلة الشكل. | LATENT | نعم | |
| `vae` | VAE من نوع Trellis2 المستخدم لفك تشفير كامن الشكل إلى إحداثيات متفرقة عالية الدقة. | VAE | نعم | |
| `target_resolution` | دقة فوكسل (Voxel) للشكل بعد رفع الدقة. القيم الأعلى تعني تفاصيل أكثر واستهلاكًا أكبر للذاكرة (VRAM). الافتراضي: 1024. | INT | نعم | 1024 - 2048 (step 128) |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | التكييف الإيجابي مع البيانات الوصفية للشكل الخاصة بمرحلة رفع الدقة المرفقة به. | CONDITIONING |
| `negative` | التكييف السلبي مع البيانات الوصفية للشكل الخاصة بمرحلة رفع الدقة المرفقة به. | CONDITIONING |
| `latent` | كامن (latent) مملوء بأصفار مُجهز لتمرير أخذ العينات الثاني لمرحلة الشكل عند الدقة المستهدفة، ويحمل الإحداثيات المرفوعة الدقة والبيانات الوصفية للدقة. | LATENT |

تستقبل هذه العقدة الكامن (latent) للشكل بدقة 512 الذي ينتجه تمرير أخذ العينات الأول لمرحلة الشكل، وترفعه إلى دقة مستهدفة أعلى، وتُحضّر التكييف (conditioning) والكامن (latent) اللازمين لتمرير أخذ العينات الثاني لمرحلة الشكل. وتُرفق بيانات وصفية خاصة بكل مرحلة إلى التكييف ليتمكن النموذج من استخدامها أثناء التوليد.
