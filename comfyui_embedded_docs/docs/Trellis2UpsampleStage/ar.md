# Trellis2UpsampleStage

تقوم هذه العقدة بأخذ الكمون الشكلي بدقة 512 الناتج عن تمريرة المعاينة الأولى لمرحلة الشكل، وترفع دقته إلى دقة مستهدفة أعلى، ثم تُهيئ التهيئة (conditioning) والكمون اللازمين لتمريرة المعاينة الثانية لمرحلة الشكل. كما تُرفق بيانات وصفية خاصة بكل مرحلة بالتهيئة ليتمكن النموذج من استخدامها أثناء التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `إيجابي` | التهيئة الإيجابية التي تُرفق بها البيانات الوصفية لمرحلة رفع دقة الشكل. | CONDITIONING | نعم | |
| `سلبي` | التهيئة السلبية التي تُرفق بها البيانات الوصفية لمرحلة رفع دقة الشكل. | CONDITIONING | نعم | |
| `shape_latent` | الكمون الشكلي بدقة 512 الناتج من أول عقدة KSampler في مرحلة الشكل. | LATENT | نعم | |
| `vae` | VAE الخاص بـ Trellis2 المستخدم لفك ترميز الكمون الشكلي إلى إحداثيات متفرقة عالية الدقة. | VAE | نعم | |
| `target_resolution` | دقة الفوكسل للشكل المرفوع الدقة. القيم الأعلى تعني تفاصيل أكثر واستهلاكًا أعلى لذاكرة الفيديو. الافتراضي: 1024. | INT | نعم | 1024 - 2048 (step 128) |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `إيجابي` | التهيئة الإيجابية مع إرفاق البيانات الوصفية لمرحلة رفع دقة الشكل بها. | CONDITIONING |
| `سلبي` | التهيئة السلبية مع إرفاق البيانات الوصفية لمرحلة رفع دقة الشكل بها. | CONDITIONING |
| `latent` | كمون معبأ بالأصفار مُهيأ لتمريرة المعاينة الثانية لمرحلة الشكل بالدقة المستهدفة، ويحمل الإحداثيات المرفوعة والبيانات الوصفية للدقة. | LATENT |
