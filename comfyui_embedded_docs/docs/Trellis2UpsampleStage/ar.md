# Trellis2 Upsample Stage

تقوم هذه العقدة برفع دقة شكل كامن بدقة 512 إلى إحداثيات متفرقة عالية الدقة، وتُهيّئ تمريرة أخذ العينات الثانية لمرحلة الشكل عند الدقة الهدف. وتُرفق بيانات وصفية خاصة بكل مرحلة بالتكييف كي يتمكن النموذج من استخدامها أثناء التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `إيجابي` | التكييف الإيجابي الذي تُرفق به البيانات الوصفية لشكل مرحلة الرفع. | CONDITIONING | نعم | |
| `سلبي` | التكييف السلبي الذي تُرفق به البيانات الوصفية لشكل مرحلة الرفع. | CONDITIONING | نعم | |
| `shape_latent` | الشكل الكامن بدقة 512 الناتج من KSampler لمرحلة الشكل الأولى. | LATENT | نعم | |
| `vae` | VAE من Trellis2 المستخدم لفك ترميز الشكل الكامن إلى إحداثيات متفرقة عالية الدقة. | VAE | نعم | |
| `target_resolution` | دقة الفوكسل للشكل المرفوع. كلما زادت القيمة، زادت التفاصيل وزاد استهلاك VRAM. القيمة الافتراضية: 1024. | INT | نعم | 1024 - 2048 (خطوة: 128) |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | التكييف الإيجابي مع البيانات الوصفية لشكل مرحلة الرفع المرفقة. | CONDITIONING |
| `negative` | التكييف السلبي مع البيانات الوصفية لشكل مرحلة الرفع المرفقة. | CONDITIONING |
| `latent` | كامن مملوء بالأصفار مُهيأ لتمريرة أخذ العينات الثانية لمرحلة الشكل عند الدقة الهدف، ويحمل الإحداثيات المرفوعة، وعدد الإحداثيات لكل عينة، وبيانات وصفية لدقة الإحداثيات. | LATENT |
