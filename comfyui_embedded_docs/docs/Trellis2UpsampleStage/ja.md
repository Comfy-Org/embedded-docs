# Trellis2UpsampleStage

このノードは、最初のシェイプステージのサンプリングパスで生成された512解像度のシェイプ潜在変数を受け取り、それをより高い目標解像度にアップスケールし、2回目のシェイプステージのサンプリングパスに必要な条件付けと潜在変数を準備します。ステージごとのメタデータを条件付けに付加し、モデルが生成時にそれを利用できるようにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | アップスケール段階のシェイプメタデータが付加されたポジティブ条件付け。 | CONDITIONING | はい | |
| `negative` | アップスケール段階のシェイプメタデータが付加されたネガティブ条件付け。 | CONDITIONING | はい | |
| `shape_latent` | 最初のシェイプステージのKSamplerから出力された512解像度のシェイプ潜在変数。 | LATENT | はい | |
| `vae` | シェイプ潜在変数を高解像度のスパース座標にデコードするために使用されるTrellis2 VAE。 | VAE | はい | |
| `target_resolution` | アップスケールされたシェイプのボクセル解像度。値が大きいほど詳細になりますが、VRAM消費も増加します。デフォルト: 1024。 | INT | はい | 1024 - 2048 (step 128) |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | アップスケール段階のシェイプメタデータが付加されたポジティブ条件付け。 | CONDITIONING |
| `negative` | アップスケール段階のシェイプメタデータが付加されたネガティブ条件付け。 | CONDITIONING |
| `latent` | 目標解像度での2回目のシェイプステージのサンプリングパス用に準備されたゼロ埋め潜在変数。アップスケールされた座標と解像度メタデータを保持します。 | LATENT |
