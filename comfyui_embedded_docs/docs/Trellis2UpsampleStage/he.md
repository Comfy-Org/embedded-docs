# שלב הגדלת דגימה של Trellis2

צומת זה מבצע העלאה ברזולוציה של latent צורה ברזולוציית 512 לקואורדינטות דלילות ברזולוציה גבוהה, ומכין את מעבר הדגימה השני של שלב הצורה ברזולוציית היעד. הוא מצרף מטא-נתונים לכל שלב אל ה-conditioning כך שהמודל יוכל להשתמש בהם במהלך היצירה.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `positive` | ה-conditioning החיובי שאליו מצורפים מטא-נתוני הצורה של שלב העלאה ברזולוציה. | CONDITIONING | כן | |
| `negative` | ה-conditioning השלילי שאליו מצורפים מטא-נתוני הצורה של שלב העלאה ברזולוציה. | CONDITIONING | כן | |
| `shape_latent` | latent הצורה ברזולוציית 512 שמופק מה-KSampler של שלב הצורה הראשון. | LATENT | כן | |
| `vae` | ה-VAE של Trellis2 המשמש לפענוח latent הצורה לקואורדינטות דלילות ברזולוציה גבוהה. | VAE | כן | |
| `target_resolution` | רזולוציית הווקסל של הצורה המועלית ברזולוציה. גבוה יותר = יותר פירוט, יותר VRAM. ברירת מחדל: 1024. | INT | כן | 1024 - 2048 (step 128) |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `positive` | conditioning חיובי עם מטא-נתוני הצורה של שלב העלאה ברזולוציה מצורפים. | CONDITIONING |
| `negative` | conditioning שלילי עם מטא-נתוני הצורה של שלב העלאה ברזולוציה מצורפים. | CONDITIONING |
| `latent` | latent מלא באפסים המוכן למעבר הדגימה השני של שלב הצורה ברזולוציית היעד, הנושא את הקואורדינטות המועלות ברזולוציה, ספירות קואורדינטות לכל דגימה, ומטא-נתוני רזולוציית קואורדינטות. | LATENT |
