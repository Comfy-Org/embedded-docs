# Trellis2UpsampleStage

Этот узел принимает latent формы с разрешением 512, полученный на первом проходе семплирования этапа формы, увеличивает его до более высокого целевого разрешения и подготавливает conditioning и latent, необходимые для второго прохода семплирования этапа формы. Он добавляет метаданные этапа к conditioning, чтобы модель могла использовать их во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительный conditioning, к которому добавляются метаданные формы этапа апскейла. | CONDITIONING | Да | |
| `negative` | Отрицательный conditioning, к которому добавляются метаданные формы этапа апскейла. | CONDITIONING | Да | |
| `shape_latent` | Latent формы с разрешением 512, полученный от первого KSampler этапа формы. | LATENT | Да | |
| `vae` | VAE Trellis2, используемый для декодирования latent формы в высокоразрешающие разреженные координаты. | VAE | Да | |
| `target_resolution` | Воксельное разрешение увеличенной формы. Больше — больше деталей и VRAM. По умолчанию: 1024. | INT | Да | 1024 - 2048 (шаг 128) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительный conditioning с добавленными метаданными формы этапа апскейла. | CONDITIONING |
| `negative` | Отрицательный conditioning с добавленными метаданными формы этапа апскейла. | CONDITIONING |
| `latent` | Заполненный нулями latent, подготовленный для второго прохода семплирования этапа формы на целевом разрешении, содержащий увеличенные координаты и метаданные разрешения. | LATENT |
