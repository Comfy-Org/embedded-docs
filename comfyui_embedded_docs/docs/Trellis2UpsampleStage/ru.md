# Этап апсемплинга Trellis2

Этот узел выполняет апскейл латента формы с разрешением 512 в высокоразрешённые разреженные координаты и подготавливает второй проход сэмплирования этапа формы при целевом разрешении. Он прикрепляет поэтапные метаданные к conditioning, чтобы модель могла использовать их во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительный conditioning, к которому прикрепляются метаданные формы этапа апскейла. | CONDITIONING | Да | |
| `negative` | Отрицательный conditioning, к которому прикрепляются метаданные формы этапа апскейла. | CONDITIONING | Да | |
| `shape_latent` | Латент формы с разрешением 512, выходящий с первого KSampler этапа формы. | LATENT | Да | |
| `vae` | VAE Trellis2, используемый для декодирования латента формы в высокоразрешённые разреженные координаты. | VAE | Да | |
| `target_resolution` | Воксельное разрешение апскейленной формы. Выше = больше деталей, больше VRAM. По умолчанию: 1024. | INT | Да | 1024 - 2048 (шаг: 128) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительный conditioning с прикреплёнными метаданными формы этапа апскейла. | CONDITIONING |
| `negative` | Отрицательный conditioning с прикреплёнными метаданными формы этапа апскейла. | CONDITIONING |
| `latent` | Латент, заполненный нулями, подготовленный для второго прохода сэмплирования этапа формы при целевом разрешении; содержит апскейленные координаты, количество координат для каждого образца и метаданные разрешения координат. | LATENT |
