# Trellis2UpsampleStage

Этот узел принимает латент формы с разрешением 512, полученный на первом проходе этапа сэмплирования формы, увеличивает его до более высокого целевого разрешения и подготавливает кондиционирование и латент, необходимые для второго прохода этапа сэмплирования формы. Он прикрепляет к кондиционированию метаданные для каждого этапа, чтобы модель могла использовать их во время генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное кондиционирование, к которому прикрепляются метаданные этапа апсемплинга. | CONDITIONING | Да | |
| `negative` | Отрицательное кондиционирование, к которому прикрепляются метаданные этапа апсемплинга. | CONDITIONING | Да | |
| `shape_latent` | Латент формы с разрешением 512, полученный от первого KSampler этапа формы. | LATENT | Да | |
| `vae` | VAE Trellis2, используемый для декодирования латента формы в разреженные координаты высокого разрешения. | VAE | Да | |
| `target_resolution` | Разрешение вокселей увеличенной формы. Больше = больше деталей, больше VRAM. По умолчанию: 1024. | INT | Да | 1024 - 2048 (шаг 128) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с прикрепленными метаданными этапа апсемплинга. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с прикрепленными метаданными этапа апсемплинга. | CONDITIONING |
| `latent` | Заполненный нулями латент, подготовленный для второго прохода этапа сэмплирования формы на целевом разрешении и содержащий увеличенные координаты и метаданные разрешения. | LATENT |
