# LoraLoader

צומת זה מזהה אוטומטית מודלים הממוקמים בתיקיית LoRA (כולל תיקיות משנה), כאשר נתיב המודל המתאים הוא `ComfyUI\models\loras`. למידע נוסף, עיין במדריך התקנת מודלי LoRA.

צומת LoRA Loader משמש בעיקר לטעינת מודלי LoRA. אפשר לחשוב על מודלי LoRA כמסננים שיכולים להעניק לתמונות שלך סגנונות, תוכן ופרטים מסוימים:

- החלת סגנונות אמנותיים מסוימים (כגון ציור בדיו)
- הוספת מאפיינים של דמויות מסוימות (כגון דמויות ממשחקים)
- הוספת פרטים מסוימים לתמונה
את כל אלה ניתן להשיג באמצעות LoRA.

אם ברצונך לטעון מספר מודלי LoRA, ניתן לשרשר ישירות מספר צמתים זה לזה, כפי שמוצג להלן:

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `model` | משמש בדרך כלל לחיבור למודל הבסיס | MODEL |
| `clip` | משמש בדרך כלל לחיבור למודל CLIP | CLIP |
| `lora_name` | בחר את שם מודל ה-LoRA לשימוש | COMBO[STRING] |
| `strength_model` | טווח ערכים מ-100.0- עד 100.0, בדרך כלל משמש בין 0~1 ליצירת תמונות יומיומית. ערכים גבוהים יותר מביאים לאפקטים בולטים יותר של התאמת המודל | FLOAT |
| `strength_clip` | טווח ערכים מ-100.0- עד 100.0, בדרך כלל משמש בין 0~1 ליצירת תמונות יומיומית. ערכים גבוהים יותר מביאים לאפקטים בולטים יותר של התאמת המודל | FLOAT |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `model` | המודל עם התאמות LoRA שהוחלו | MODEL |
| `clip` | מופע ה-CLIP עם התאמות LoRA שהוחלו | CLIP |
