# تولید ویدیو از متن Vidu2

گره Vidu2 Text-to-Video Generation یک ویدیو را از یک توصیف متنی ایجاد می‌کند. این گره برای تولید محتوای ویدیویی بر اساس پرامپت شما به یک API خارجی متصل می‌شود و به شما امکان می‌دهد طول، سبک بصری و قالب ویدیو را کنترل کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل هوش مصنوعی مورد استفاده برای تولید ویدیو. در حال حاضر، فقط یک مدل در دسترس است. | COMBO | بله | `"viduq2"` |
| `prompt` | توصیف متنی برای تولید ویدیو، با حداکثر طول 2000 کاراکتر. | STRING | بله | - |
| `duration` | طول ویدیوی تولیدشده بر حسب ثانیه. مقدار آن را می‌توان با یک اسلایدر تنظیم کرد (پیش‌فرض: 5). | INT | خیر | 1 تا 10 |
| `seed` | عددی که برای کنترل تصادفی‌بودن تولید استفاده می‌شود و امکان نتایج قابل بازتولید را فراهم می‌کند. این مقدار پس از تولید قابل کنترل است (پیش‌فرض: 1). | INT | خیر | 0 تا 2147483647 |
| `aspect_ratio` | رابطه تناسبی بین عرض و ارتفاع ویدیو. | COMBO | خیر | `"16:9"`<br>`"9:16"`<br>`"3:4"`<br>`"4:3"`<br>`"1:1"` |
| `resolution` | ابعاد پیکسلی ویدیوی تولیدشده. این یک پارامتر پیشرفته است. | COMBO | خیر | `"720p"`<br>`"1080p"` |
| `background_music` | اینکه موسیقی پس‌زمینه به ویدیوی تولیدشده اضافه شود یا نه (پیش‌فرض: False). این یک پارامتر پیشرفته است. | BOOLEAN | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | فایل ویدیوی تولیدشده. | VIDEO |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Vidu2TextToVideoNode/fa.md)
