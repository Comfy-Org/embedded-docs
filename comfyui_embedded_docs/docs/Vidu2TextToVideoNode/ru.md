# Vidu2 Генерация видео по тексту

Узел Vidu2 Text-to-Video Generation создаёт видео из текстового описания. Он подключается к внешнему API для генерации видеоконтента на основе вашего промпта, позволяя управлять длительностью видео, визуальным стилем и форматом.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | ИИ-модель, используемая для генерации видео. В настоящее время доступна только одна модель. | COMBO | Да | `"viduq2"` |
| `prompt` | Текстовое описание для генерации видео, максимальная длина — 2000 символов. | STRING | Да | - |
| `duration` | Длительность создаваемого видео в секундах. Значение можно регулировать с помощью ползунка (по умолчанию: 5). | INT | Нет | 1–10 |
| `seed` | Число, используемое для управления случайностью генерации и обеспечивающее воспроизводимость результатов. Его можно контролировать после генерации (по умолчанию: 1). | INT | Нет | 0–2147483647 |
| `aspect_ratio` | Пропорциональное соотношение между шириной и высотой видео. | COMBO | Нет | `"16:9"`<br>`"9:16"`<br>`"3:4"`<br>`"4:3"`<br>`"1:1"` |
| `resolution` | Пиксельные размеры создаваемого видео. Это расширенный параметр. | COMBO | Нет | `"720p"`<br>`"1080p"` |
| `background_music` | Добавлять ли фоновую музыку к создаваемому видео (по умолчанию: False). Это расширенный параметр. | BOOLEAN | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
