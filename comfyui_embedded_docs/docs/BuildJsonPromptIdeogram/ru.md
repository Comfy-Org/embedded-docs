# Создать JSON-промпт (Ideogram)

Этот узел формирует структурированный JSON-промпт, специально предназначенный для модели генерации изображений Ideogram 4. Он организует ваши текстовые инструкции, предпочтения по стилю, детали камеры или художественного исполнения, освещение, носитель и необязательную цветовую палитру в требуемую JSON-структуру, которую ожидает модель.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `элемент` | Элементы промпта из узла Create Bounding Boxes. | ARRAY | Да | - |
| `высокоуровневое_описание` | Необязательное описание изображения в одном-двух предложениях. Настоятельно рекомендуется. (по умолчанию: пусто) | STRING | Нет | - |
| `фон` | Обязательное описание фона или окружения изображения. Настоятельно рекомендуется указать значение — узел будет работать и с пустой строкой, но результат может быть непредсказуемым. (по умолчанию: пусто) | STRING | Нет | - |
| `стиль` | Категория визуального стиля для сгенерированного изображения. Выберите один из вариантов. (по умолчанию: "none") | COMBO | Да | `"none"`<br>`"photo"`<br>`"art_style"` |
| `photo` | Детали камеры или объектива для фотографических результатов (например, 35mm, f/1.4, bokeh). Доступно только когда `стиль` установлен в "photo". (по умолчанию: пусто) | STRING | Нет | - |
| `art_style` | Описание художественного стиля (например, плоская векторная иллюстрация, жирные контуры). Доступно только когда `стиль` установлен в "art_style". (по умолчанию: пусто) | STRING | Нет | - |
| `эстетика` | Обязательные эстетические ключевые слова (например, moody, cinematic, desaturated). Настоятельно рекомендуется указать значение. (по умолчанию: пусто) | STRING | Нет | - |
| `освещение` | Обязательное описание освещения (например, золотой час, контровой свет, драматичные тени). Настоятельно рекомендуется указать значение. (по умолчанию: пусто) | STRING | Нет | - |
| `носитель` | Обязательный тип носителя (например, photograph, illustration, 3d_render, painting, graphic_design). Когда style = photo, установите photograph. Настоятельно рекомендуется указать значение. (по умолчанию: пусто) | STRING | Нет | - |
| `цветовая_палитра` | Шестнадцатеричные коды цветов, определяющие доминирующие цвета изображения. До 16 записей. | COLORS | Нет | - |

**Примечание:** Когда `style` установлен в "photo", вход `photo` становится доступным, и обычно следует устанавливать `medium` в "photograph". Когда `style` установлен в "art_style", вход `art_style` становится доступным. Параметры `background`, `aesthetics`, `lighting` и `medium` имеют пустые строки по умолчанию, но считаются обязательными для надежной генерации изображений; настоятельно рекомендуется указывать значения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `промпт` | Структурированный JSON-словарь, содержащий высокоуровневое описание, описание стиля (если выбран стиль, отличный от "none"), и композиционную декомпозицию с фоном и элементами. | DICT |
