# בניית פרומפט JSON (Ideogram)

צומת זה בונה פרומפט JSON מובנה בפורמט המיועד במיוחד למודל יצירת התמונות Ideogram 4. הוא מארגן את הוראות הטקסט שלך, העדפות סגנון, פרטי מצלמה או אמנות, תאורה, מדיום ופלטת צבעים אופציונלית במבנה ה-JSON הנדרש שהמודל מצפה לו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `element` | אלמנטים של פרומפט מהצומת Create Bounding Boxes. | ARRAY | כן | - |
| `high_level_description` | תיאור אופציונלי של התמונה במשפט אחד או שניים. מומלץ מאוד. (ברירת מחדל: ריק) | STRING | לא | - |
| `background` | תיאור חובה של רקע התמונה או הסביבה. מומלץ מאוד לספק ערך – הצומת יפעל עם מחרוזת ריקה, אך התוצאות עלולות להיות לא צפויות. (ברירת מחדל: ריק) | STRING | לא | - |
| `style` | קטגוריית הסגנון החזותי של התמונה שתיווצר. בחר אחת מהאפשרויות. (ברירת מחדל: "none") | COMBO | כן | `"none"`<br>`"photo"`<br>`"art_style"` |
| `photo` | פרטי מצלמה או עדשה עבור פלטים צילומיים (למשל 35mm, f/1.4, bokeh). זמין רק כאשר `style` מוגדר ל-"photo". (ברירת מחדל: ריק) | STRING | לא | - |
| `art_style` | תיאור סגנון אמנותי (למשל flat vector illustration, bold outlines). זמין רק כאשר `style` מוגדר ל-"art_style". (ברירת מחדל: ריק) | STRING | לא | - |
| `aesthetics` | מילות מפתח אסתטיות חובה (למשל moody, cinematic, desaturated). מומלץ מאוד לספק ערך. (ברירת מחדל: ריק) | STRING | לא | - |
| `lighting` | תיאור תאורה חובה (למשל golden hour, rim light, dramatic shadows). מומלץ מאוד לספק ערך. (ברירת מחדל: ריק) | STRING | לא | - |
| `medium` | סוג מדיום חובה (למשל photograph, illustration, 3d_render, painting, graphic_design). כאשר style = photo, יש להגדיר ל-photograph. מומלץ מאוד לספק ערך. (ברירת מחדל: ריק) | STRING | לא | - |
| `color_palette` | קודי צבע Hex שמכוונים את הצבעים הדומיננטיים של התמונה. עד 16 ערכים. | COLORS | לא | - |

**הערה:** כאשר `style` מוגדר ל-"photo", הקלט `photo` הופך לזמין ובדרך כלל יש להגדיר את `medium` ל-"photograph". כאשר `style` מוגדר ל-"art_style", הקלט `art_style` הופך לזמין. לפרמטרים `background`, `aesthetics`, `lighting` ו-`medium` יש מחרוזות ריקות כברירת מחדל, אך הם נחשבים להכרחיים ליצירת תמונה אמינה; מומלץ מאוד לספק ערכים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `prompt` | מילון JSON מובנה המכיל את התיאור ברמה גבוהה, תיאור סגנון (אם נבחר סגנון שאינו "none"), ופירוק קומפוזיציוני עם רקע ואלמנטים. | DICT |
