# Wan Image to Video

צומת Wan Image to Video יוצר וידאו מתמונת קלט יחידה ומפרומפט טקסטואלי. הוא משתמש בתמונה שסופקה בתור הפריים הראשון ויוצר רצף וידאו על בסיס התיאור, עם אפשרויות לרזולוציה, משך, שמע והגדרות מתקדמות נוספות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל לשימוש (ברירת מחדל: "wan2.6-i2v") | COMBO | כן | "wan2.5-i2v-preview"<br>"wan2.6-i2v" |
| `image` | תמונת קלט שמשמשת בתור הפריים הראשון ליצירת הווידאו. נדרשת תמונה אחת בדיוק. | IMAGE | כן | - |
| `prompt` | פרומפט המתאר את האלמנטים והמאפיינים החזותיים. תומך באנגלית ובסינית (ברירת מחדל: ריק). | STRING | כן | - |
| `negative_prompt` | פרומפט שלילי המתאר ממה להימנע (ברירת מחדל: ריק). | STRING | לא | - |
| `resolution` | איכות רזולוציית הווידאו (ברירת מחדל: "720P"). מודל Wan 2.6 אינו תומך ב-480P. | COMBO | לא | "480P"<br>"720P"<br>"1080P" |
| `duration` | משך הווידאו שנוצר בשניות. משך של 15 שניות נתמך רק במודל Wan 2.6 (ברירת מחדל: 5). | INT | לא | 5-15 (step: 5) |
| `audio` | השמע חייב להכיל קול ברור וחזק, ללא רעש מיותר או מוזיקת רקע. כאשר מסופק, משך השמע חייב להיות בין 3.0 ל-29.0 שניות. | AUDIO | לא | - |
| `seed` | Seed לשימוש ביצירה (ברירת מחדל: 0). | INT | לא | 0-2147483647 |
| `generate_audio` | אם לא מסופק קלט שמע, צור שמע באופן אוטומטי (ברירת מחדל: False). | BOOLEAN | לא | - |
| `prompt_extend` | האם לשפר את הפרומפט בעזרת AI (ברירת מחדל: True). | BOOLEAN | לא | - |
| `watermark` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה (ברירת מחדל: False). | BOOLEAN | לא | - |
| `shot_type` | מציין את סוג הצילום עבור הווידאו שנוצר, כלומר, האם הווידאו הוא צילום רציף יחיד או מספר צילומים עם חיתוכים. פרמטר זה נכנס לתוקף רק כאשר `prompt_extend` הוא True (ברירת מחדל: "single"). | COMBO | לא | "single"<br>"multi" |

**אילוצים:**

- נדרשת תמונת קלט אחת בדיוק ליצירת וידאו.
- מודל Wan 2.6 (`wan2.6-i2v`) אינו תומך ברזולוציית 480P.
- משך של 15 שניות נתמך רק במודל Wan 2.6 (`wan2.6-i2v`).
- כאשר מסופק שמע, משכו חייב להיות בין 3.0 ל-29.0 שניות.
