# Wan Image to Video

צומת Wan Image to Video יוצר וידאו מתמונת קלט יחידה ומפרומפט טקסטואלי. הוא משתמש בתמונה שסופקה בתור הפריים הראשון ויוצר רצף וידאו על בסיס התיאור, עם אפשרויות לרזולוציה, משך, שמע והגדרות מתקדמות נוספות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `מודל` | מודל לשימוש (ברירת מחדל: "wan2.6-i2v") | COMBO | כן | "wan2.5-i2v-preview"<br>"wan2.6-i2v" |
| `תמונה` | תמונת קלט שמשמשת בתור הפריים הראשון ליצירת הווידאו. נדרשת תמונה אחת בדיוק. | IMAGE | כן | - |
| `פרומפט` | פרומפט המתאר את האלמנטים והמאפיינים החזותיים. תומך באנגלית ובסינית (ברירת מחדל: ריק). | STRING | כן | - |
| `פרומפט שלילי` | פרומפט שלילי המתאר ממה להימנע (ברירת מחדל: ריק). | STRING | לא | - |
| `רזולוציה` | איכות רזולוציית הווידאו (ברירת מחדל: "720P"). מודל Wan 2.6 אינו תומך ב-480P. | COMBO | לא | "480P"<br>"720P"<br>"1080P" |
| `משך` | משך הווידאו שנוצר בשניות. משך של 15 שניות נתמך רק במודל Wan 2.6 (ברירת מחדל: 5). | INT | לא | 5-15 (צעד: 5) |
| `אודיו` | השמע חייב להכיל קול ברור וחזק, ללא רעש מיותר או מוזיקת רקע. כאשר מסופק, משך השמע חייב להיות בין 3.0 ל-29.0 שניות. | AUDIO | לא | - |
| `seed` | Seed לשימוש ביצירה (ברירת מחדל: 0). | INT | לא | 0-2147483647 |
| `יצירת אודיו` | אם לא מסופק קלט שמע, צור שמע באופן אוטומטי (ברירת מחדל: False). | BOOLEAN | לא | - |
| `הרחבת פרומפט` | האם לשפר את הפרומפט בעזרת AI (ברירת מחדל: True). | BOOLEAN | לא | - |
| `סימן מים` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה (ברירת מחדל: False). | BOOLEAN | לא | - |
| `סוג שוט` | מציין את סוג הצילום עבור הווידאו שנוצר, כלומר, האם הווידאו הוא צילום רציף יחיד או מספר צילומים עם חיתוכים. פרמטר זה נכנס לתוקף רק כאשר `prompt_extend` הוא True (ברירת מחדל: "single"). | COMBO | לא | "single"<br>"multi" |

**אילוצים:**

- נדרשת תמונת קלט אחת בדיוק ליצירת וידאו.
- מודל Wan 2.6 (`wan2.6-i2v`) אינו תומך ברזולוציית 480P.
- משך של 15 שניות נתמך רק במודל Wan 2.6 (`wan2.6-i2v`).
- כאשר מסופק שמע, משכו חייב להיות בין 3.0 ל-29.0 שניות.
