# ריקרפט תמונה לתמונה

צומת זה משנה תמונה קיימת בהתבסס על הנחיית טקסט והגדרת עוצמה. הוא שולח את התמונה ל-API של Recraft V3 ומחזיר תמונה חדשה שממלאת אחר ההנחיה תוך שמירה על דמיון פחות או יותר לתמונה המקורית, בהתאם לערך העוצמה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת הקלט שיש לשנות. כאשר מסופק מקבץ תמונות, כל תמונה מעובדת בנפרד. | IMAGE | כן | - |
| `prompt` | הנחיה ליצירת התמונה. ברירת מחדל: מחרוזת ריקה. אורך מקסימלי: 1000 תווים. | STRING | כן | - |
| `n` | מספר התמונות ליצירה. ברירת מחדל: 1. | INT | כן | 1-6 |
| `strength` | מגדיר את ההבדל מהתמונה המקורית; צריך להיות בטווח [0, 1], כאשר 0 פירושו כמעט זהה, ו-1 פירושו דמיון מועט. ברירת מחדל: 0.5. | FLOAT | כן | 0.0-1.0 (step 0.01) |
| `seed` | ערך seed לקביעה אם הצומת צריך לרוץ מחדש; התוצאות בפועל אינן דטרמיניסטיות ללא תלות ב-seed. ברירת מחדל: 0. | INT | כן | 0-18446744073709551615 |
| `recraft_style` | בחירת סגנון אופציונלית ליצירת התמונה. אם לא מסופק, ברירת המחדל היא `realistic_image`. | STYLEV3 | לא | - |
| `negative_prompt` | תיאור טקסט אופציונלי של רכיבים לא רצויים בתמונה. ברירת מחדל: מחרוזת ריקה. מסופק כשקע קלט. | STRING | לא | - |
| `recraft_controls` | בקרות נוספות אופציונליות על היצירה באמצעות הצומת Recraft Controls. | CONTROLS | לא | - |

**הערה:** הפרמטר `seed` רק מפעיל הרצה מחדש של הצומת אך אינו מבטיח תוצאות דטרמיניסטיות. הפרמטר `strength` מעוגל באופן פנימי ל-2 ספרות עשרוניות. הפרמטר `prompt` עובר ולידציה ואסור שיעלה על 1000 תווים. `negative_prompt` ריק מטופל כאילו אין הנחיה שלילית. אם `recraft_style` לא מסופק, ברירת המחדל של הצומת היא הסגנון `realistic_image`. אם אתה משתמש ב-`style_id` מספריית Infinite Style Library, ודא שהוא אינו סגנון אמנות וקטורית (Vector art), מכיוון שהדבר עלול לגרום לצומת לקבל נתוני SVG במקום תמונה, וכתוצאה מכך לשגיאה. כאשר הקלט `image` הוא מקבץ, כל תמונה במקבץ מעובדת בנפרד וכל התוצאות מוחזרות יחד.
