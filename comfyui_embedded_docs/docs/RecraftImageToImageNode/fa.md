# تبدیل تصویر به تصویر Recraft

این گره بر اساس یک پرامپت متنی و پارامتر strength، تصویر موجود را تغییر می‌دهد. این گره از API مربوط به Recraft برای تبدیل تصویر ورودی طبق توضیحات ارائه‌شده استفاده می‌کند، در حالی‌که بر اساس تنظیم strength، شباهتی نسبی با تصویر اصلی حفظ می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که قرار است تغییر کند | IMAGE | بله | - |
| `prompt` | پرامپت برای تولید تصویر (پیش‌فرض: «»، حداکثر طول: ۱۰۰۰ کاراکتر) | STRING | بله | - |
| `n` | تعداد تصاویری که باید تولید شود (پیش‌فرض: ۱) | INT | بله | 1-6 |
| `strength` | میزان تفاوت با تصویر اصلی را تعیین می‌کند؛ باید در بازه [0,1] باشد، جایی که ۰ به معنای تقریباً یکسان و ۱ به معنای شباهت بسیار اندک است (پیش‌فرض: ۰٫۵) | FLOAT | بله | 0.0-1.0 |
| `seed` | Seed برای تعیین این‌که آیا گره دوباره اجرا شود؛ نتایج واقعی بدون توجه به seed غیرقطعی هستند (پیش‌فرض: ۰) | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب سبک اختیاری برای تولید تصویر. اگر ارائه نشود، به طور پیش‌فرض روی `realistic_image` تنظیم می‌شود | STYLEV3 | خیر | - |
| `negative_prompt` | توضیح متنی اختیاری درباره عناصر نامطلوب در تصویر (پیش‌فرض: «») | STRING | خیر | - |
| `recraft_controls` | کنترل‌های اضافی اختیاری بر فرآیند تولید از طریق گره Recraft Controls | CONTROLS | خیر | - |

**نکته:** پارامتر `seed` تنها اجرای مجدد گره را فعال می‌کند اما نتایج قطعی را تضمین نمی‌کند. پارامتر `strength` به صورت داخلی به ۲ رقم اعشار گرد می‌شود. پرامپت اعتبارسنجی می‌شود و نباید از ۱۰۰۰ کاراکتر بیشتر باشد. اگر `recraft_style` ارائه نشود، گره به طور پیش‌فرض از سبک `realistic_image` استفاده می‌کند. اگر از `style_id` از کتابخانه سبک بی‌نهایت (Infinite Style Library) استفاده می‌کنید، مطمئن شوید که سبک وکتور (Vector art) نباشد؛ زیرا ممکن است باعث شود گره داده SVG به جای تصویر دریافت کند و خطا رخ دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) تولیدشده بر اساس تصویر ورودی و پرامپت. برای هر تصویر ورودی، تعداد `n` تصویر تولید می‌شود، بنابراین تعداد کل خروجی‌ها برابر با تعداد ورودی‌ها ضرب‌در `n` است. | IMAGE |
