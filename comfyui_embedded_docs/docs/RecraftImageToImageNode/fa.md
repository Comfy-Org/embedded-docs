# تبدیل تصویر به تصویر Recraft

این گره یک تصویر موجود را بر اساس یک پرامپت متنی و تنظیم `strength` تغییر می‌دهد. تصویر را به API مربوط به Recraft V3 می‌فرستد و تصویر جدیدی برمی‌گرداند که از پرامپت پیروی می‌کند و بسته به مقدار `strength` کمابیش شبیه تصویر اصلی باقی می‌ماند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که باید تغییر کند. وقتی دسته‌ای از تصاویر ارائه شود، هر تصویر به‌صورت جداگانه پردازش می‌شود. | IMAGE | بله | - |
| `prompt` | پرامپت برای تولید تصویر. پیش‌فرض: رشته خالی. حداکثر طول: 1000 کاراکتر. | STRING | بله | - |
| `n` | تعداد تصاویری که باید تولید شود. پیش‌فرض: 1. | INT | بله | 1-6 |
| `strength` | تفاوت با تصویر اصلی را تعیین می‌کند؛ باید در بازهٔ [0, 1] باشد، که 0 به معنای تقریباً یکسان و 1 به معنای شباهت بسیار ضعیف است. پیش‌فرض: 0.5. | FLOAT | بله | 0.0-1.0 (گام: 0.01) |
| `seed` | `seed` تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج واقعی بدون توجه به `seed` غیرقطعی هستند. پیش‌فرض: 0. | INT | بله | 0-18446744073709551615 |
| `recraft_style` | انتخاب سبک اختیاری برای تولید تصویر. اگر ارائه نشود، به‌طور پیش‌فرض `realistic_image` است. | STYLEV3 | خیر | - |
| `negative_prompt` | توضیح متنی اختیاری از عناصر ناخواسته در تصویر. پیش‌فرض: رشته خالی. به‌صورت سوکت ورودی ارائه می‌شود. | STRING | خیر | - |
| `recraft_controls` | کنترل‌های اضافی اختیاری بر فرایند تولید از طریق گره Recraft Controls. | CONTROLS | خیر | - |

**توجه:** پارامتر `seed` فقط باعث اجرای دوبارهٔ گره می‌شود، اما نتایج قطعی را تضمین نمی‌کند. پارامتر `strength` به‌صورت داخلی تا 2 رقم اعشار گرد می‌شود. `prompt` اعتبارسنجی می‌شود و نباید از 1000 کاراکتر بیشتر باشد. `negative_prompt` خالی به‌عنوان نبود پرامپت منفی در نظر گرفته می‌شود. اگر `recraft_style` ارائه نشود، گره به‌طور پیش‌فرض از سبک `realistic_image` استفاده می‌کند. اگر از یک `style_id` از Infinite Style Library استفاده می‌کنید، مطمئن شوید که سبک هنری برداری نیست، چون ممکن است باعث شود گره به‌جای تصویر داده‌های SVG دریافت کند و در نتیجه خطا رخ دهد. وقتی ورودی `image` یک دسته باشد، هر تصویر در دسته به‌صورت جداگانه پردازش می‌شود و همهٔ نتایج با هم بازگردانده می‌شوند.
