# تبدیل تصویر به تصویر Recraft

این گره یک تصویر موجود را بر اساس یک متن راهنما (prompt) و پارامتر strength تغییر می‌دهد. این گره از API نسخه ۳ Recraft برای تبدیل تصویر ورودی مطابق با توضیحات ارائه‌شده استفاده می‌کند و در عین حال شباهت‌هایی به تصویر اصلی را با تنظیم strength حفظ می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که قرار است تغییر یابد | IMAGE | بله | - |
| `پرامپت` | راهنمای متن (prompt) برای تولید تصویر (پیش‌فرض: رشته خالی، حداکثر طول: ۱۰۰۰ کاراکتر) | STRING | بله | - |
| `تعداد` | تعداد تصاویری که باید تولید شود (پیش‌فرض: 1) | INT | بله | 1-6 |
| `قدرت` | میزان تفاوت با تصویر اصلی را تعیین می‌کند؛ باید در بازه [0, 1] باشد، که 0 به معنای تقریباً یکسان و 1 به معنای شباهت بسیار ناچیز است (پیش‌فرض: 0.5) | FLOAT | بله | 0.0-1.0 |
| `seed` | دانه (seed) برای تعیین اینکه گره دوباره اجرا شود؛ نتایج واقعی صرف‌نظر از seed قطعی نیستند (پیش‌فرض: 0) | INT | بله | 0-18446744073709551615 |
| `سبک Recraft` | انتخاب سبک اختیاری برای تولید تصویر. اگر ارائه نشود، به‌صورت پیش‌فرض روی `realistic_image` تنظیم می‌شود | STYLEV3 | خیر | - |
| `پرامپت منفی` | توضیح متنی اختیاری از عناصر نامطلوب در تصویر (پیش‌فرض: رشته خالی) | STRING | خیر | - |
| `کنترل‌های Recraft` | کنترل‌های اضافی اختیاری بر روی تولید از طریق گره Recraft Controls | CONTROLS | خیر | - |

**نکته:** پارامتر `seed` فقط اجرای مجدد گره را فعال می‌کند اما نتایج قطعی را تضمین نمی‌کند. پارامتر `strength` در داخل به ۲ رقم اعشار گرد می‌شود. `prompt` اعتبارسنجی می‌شود و نباید از ۱۰۰۰ کاراکتر بیشتر باشد. `negative_prompt` خالی به‌عنوان عدم وجود negative prompt در نظر گرفته می‌شود. اگر `recraft_style` ارائه نشود، گره به‌صورت پیش‌فرض از سبک `realistic_image` استفاده می‌کند. اگر از `style_id` از کتابخانه سبک بی‌نهایت (Infinite Style Library) استفاده می‌کنید، مطمئن شوید که سبک وکتور (Vector art) نباشد، زیرا ممکن است باعث شود گره به‌جای تصویر، داده SVG دریافت کند و خطا رخ دهد. وقتی ورودی `image` یک دسته (batch) باشد، هر تصویر در دسته به‌طور جداگانه پردازش می‌شود و همه نتایج با هم بازگردانده می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصویر(های) تولیدشده بر اساس تصویر ورودی و راهنما (prompt) | IMAGE |
