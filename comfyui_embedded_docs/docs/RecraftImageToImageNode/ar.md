# إعادة صياغة صورة إلى صورة

```markdown
تعدّل هذه العقدة صورة موجودة استنادًا إلى موجه نصي ومعامل قوة. تستخدم واجهة برمجة تطبيقات Recraft لتحويل الصورة المدخلة وفقًا للوصف المقدم مع الحفاظ على بعض التشابه مع الصورة الأصلية بناءً على إعداد القوة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المدخلة المراد تعديلها | IMAGE | نعم | - |
| `prompt` | موجه لتوليد الصورة (الافتراضي: ""، الحد الأقصى للطول: 1000 حرف) | STRING | نعم | - |
| `n` | عدد الصور المراد توليدها (الافتراضي: 1) | INT | نعم | 1-6 |
| `strength` | يحدد درجة الاختلاف عن الصورة الأصلية، ويجب أن يكون في النطاق [0, 1]، حيث يعني 0 تطابقًا شبه تام، ويعني 1 تشابهًا ضئيلًا للغاية (الافتراضي: 0.5) | FLOAT | نعم | 0.0-1.0 |
| `seed` | بذرة لتحديد ما إذا كانت العقدة ستعيد التشغيل؛ النتائج الفعلية غير حتمية بغض النظر عن البذرة (الافتراضي: 0) | INT | نعم | 0-18446744073709551615 |
| `recraft_style` | اختيار نمط اختياري لتوليد الصورة. إذا لم يتم توفيره، يكون الافتراضي هو `realistic_image` | STYLEV3 | لا | - |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة (الافتراضي: "") | STRING | لا | - |
| `recraft_controls` | تحكمات إضافية اختيارية في عملية التوليد عبر عقدة Recraft Controls | CONTROLS | لا | - |

**ملاحظة:** يعمل معامل `seed` فقط على إعادة تنفيذ العقدة ولكنه لا يضمن نتائج حتمية. يتم تقريب معامل القوة إلى منزلتين عشريتين داخليًا. يتم التحقق من الموجه ويجب ألا يتجاوز 1000 حرف. إذا لم يتم توفير `recraft_style`، فستستخدم العقدة نمط `realistic_image` افتراضيًا. إذا كنت تستخدم `style_id` من مكتبة الأنماط اللانهائية، فتأكد من أنه ليس نمط فن متجهي، لأن ذلك قد يؤدي إلى استلام العقدة لبيانات SVG بدلاً من صورة، مما يسبب خطأ.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصور المولّدة استنادًا إلى الصورة المدخلة والموجه. لكل صورة مدخلة، يتم توليد `n` صورة، لذا يكون إجمالي عدد المخرجات مساويًا لعدد المدخلات مضروبًا في `n`. | IMAGE |
```
