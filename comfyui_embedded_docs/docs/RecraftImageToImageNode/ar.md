# إعادة صياغة صورة إلى صورة

تقوم هذه العقدة بتعديل صورة موجودة بناءً على موجِّه نصي وإعداد قوة. وهي ترسل الصورة إلى Recraft V3 API وتُرجع صورة جديدة تتبع الموجِّه مع بقائها مشابهة إلى حد ما للصورة الأصلية، وذلك اعتمادًا على قيمة `strength`.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المُدخَلة المراد تعديلها. عند توفير دفعة من الصور، تتم معالجة كل صورة على حدة. | IMAGE | نعم | - |
| `prompt` | الموجِّه الخاص بتوليد الصورة. الافتراضي: سلسلة نصية فارغة. الحد الأقصى للطول: 1000 حرف. | STRING | نعم | - |
| `n` | عدد الصور المراد توليدها. الافتراضي: 1. | INT | نعم | 1-6 |
| `strength` | يحدد مقدار الاختلاف عن الصورة الأصلية، ويجب أن يقع ضمن [0, 1]، حيث تعني 0 تطابقًا شبه تام، وتعني 1 تشابهًا ضعيفًا جدًا. الافتراضي: 0.5. | FLOAT | نعم | 0.0-1.0 (خطوة: 0.01) |
| `seed` | بذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ النتائج الفعلية غير حتمية بصرف النظر عن البذرة. الافتراضي: 0. | INT | نعم | 0-18446744073709551615 |
| `recraft_style` | اختيار نمط اختياري لتوليد الصورة. إذا لم يتم توفيره، فسيكون الافتراضي `realistic_image`. | STYLEV3 | لا | - |
| `negative_prompt` | وصف نصي اختياري للعناصر غير المرغوب فيها في الصورة. الافتراضي: سلسلة نصية فارغة. يتم توفيره كمنفذ إدخال. | STRING | لا | - |
| `recraft_controls` | عناصر تحكم إضافية اختيارية على التوليد عبر عقدة Recraft Controls. | CONTROLS | لا | - |

**ملاحظة:** المعامل `seed` يؤدي فقط إلى إعادة تنفيذ العقدة لكنه لا يضمن نتائج حتمية. يتم تقريب المعامل `strength` داخليًا إلى منزلتين عشريتين. يتم التحقق من `prompt` ويجب ألا يتجاوز 1000 حرف. تُعامَل قيمة `negative_prompt` الفارغة كما لو لم يكن هناك موجِّه سلبي. إذا لم يتم توفير `recraft_style`، فستكون القيمة الافتراضية للعقدة هي النمط `realistic_image`. إذا استخدمت `style_id` من Infinite Style Library، فتأكد من أنه ليس نمط Vector art، لأن ذلك قد يجعل العقدة تستقبل بيانات SVG بدلًا من صورة، مما يؤدي إلى حدوث خطأ. عندما يكون الإدخال `image` دفعة، تتم معالجة كل صورة في الدفعة على حدة وتُعاد جميع النتائج معًا.
