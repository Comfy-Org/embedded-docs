# Recraft 影像轉影像

此節點會根據文字提示詞與強度設定修改既有影像。它會將影像傳送至 Recraft V3 API，並回傳一張遵循提示詞的新影像，同時依強度值不同，或多或少與原始影像保持相似。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要修改的輸入影像。當提供一批影像時，每張影像會個別處理。 | IMAGE | 是 | - |
| `提示詞` | 用於影像生成的提示詞。預設：空字串。最大長度：1000 個字元。 | STRING | 是 | - |
| `數量` | 要生成的影像數量。預設：1。 | INT | 是 | 1-6 |
| `強度` | 定義與原始影像的差異程度，應介於 [0, 1]，其中 0 表示幾乎完全相同，1 表示相似度極低。預設：0.5。 | FLOAT | 是 | 0.0-1.0 （步進值：0.01） |
| `種子值` | 用來決定節點是否應重新執行的種子；無論種子為何，實際結果皆不具確定性。預設：0。 | INT | 是 | 0-18446744073709551615 |
| `recraft 風格` | 可選的影像生成風格選擇。若未提供，預設為 `realistic_image`。 | STYLEV3 | 否 | - |
| `負向提示詞` | 影像上不希望出現元素的選用文字描述。預設：空字串。作為輸入插槽提供。 | STRING | 否 | - |
| `recraft 控制` | 可透過 Recraft Controls 節點對生成過程進行選用的額外控制。 | CONTROLS | 否 | - |

**注意：** `seed` 參數只會觸發節點重新執行，但不保證結果具確定性。`strength` 參數在內部會四捨五入至小數點後兩位。`prompt` 會經過驗證，且不得超過 1000 個字元。空的 `negative_prompt` 會被視為沒有負面提示詞。若未提供 `recraft_style`，節點會預設為 `realistic_image` 風格。若你使用來自 Infinite Style Library 的 `style_id`，請確保它不是 Vector art 風格，因為這可能導致節點收到 SVG 資料而非影像，進而產生錯誤。當輸入 `image` 為批次時，批次中的每張影像會個別處理，且所有結果會一併回傳。
