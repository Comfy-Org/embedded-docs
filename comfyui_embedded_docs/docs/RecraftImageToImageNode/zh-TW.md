# Recraft 影像轉影像

此節點根據文字提示和強度參數修改現有影像。它使用 Recraft V3 API 根據提供的描述轉換輸入影像，同時透過強度設定保持與原始影像的某些相似性。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 要修改的輸入影像 | IMAGE | 是 | - |
| `提示詞` | 影像生成的提示詞（預設：空字串，最大長度：1000 個字元） | STRING | 是 | - |
| `數量` | 要生成的影像數量（預設：1） | INT | 是 | 1-6 |
| `強度` | 定義與原始影像的差異程度，應介於 [0, 1] 之間，其中 0 表示幾乎相同，1 表示相似性極低（預設：0.5） | FLOAT | 是 | 0.0-1.0 |
| `種子值` | 用於決定節點是否重新執行的種子；無論種子為何，實際結果都是非確定性的（預設：0） | INT | 是 | 0-18446744073709551615 |
| `recraft 風格` | 影像生成的可選樣式選擇。若未提供，預設為 `realistic_image` | STYLEV3 | 否 | - |
| `負向提示詞` | 影像中不希望出現的元素的可選文字描述（預設：空字串） | STRING | 否 | - |
| `recraft 控制` | 透過 Recraft Controls 節點對生成過程進行的可選附加控制 | CONTROLS | 否 | - |

**注意：** `seed` 參數僅會觸發節點重新執行，但無法保證結果具有確定性。`strength` 參數在內部會四捨五入到小數點後兩位。`prompt` 會經過驗證，且不得超過 1000 個字元。空的 `negative_prompt` 會被視為沒有負面提示詞。若未提供 `recraft_style`，節點預設使用 `realistic_image` 樣式。如果您使用 Infinite Style Library 中的 `style_id`，請確保它不是向量藝術（Vector art）樣式，因為這可能導致節點收到 SVG 資料而非影像，從而產生錯誤。當輸入 `image` 是批次時，批次中的每張影像都會被單獨處理，並一起回傳所有結果。
