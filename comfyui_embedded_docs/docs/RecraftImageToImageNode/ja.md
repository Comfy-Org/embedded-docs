# Recraft 画像から画像へ

このノードは、テキストプロンプトと強度パラメータに基づいて既存の画像を変更します。Recraft API を使用して、指定された説明に従って入力画像を変換し、強度設定に基づいて元の画像との類似性を維持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 変更される入力画像 | IMAGE | はい | - |
| `prompt` | 画像生成のプロンプト（デフォルト: "", 最大長: 1000文字） | STRING | はい | - |
| `n` | 生成する画像の数（デフォルト: 1） | INT | はい | 1-6 |
| `strength` | 元画像との差を定義します。[0, 1] の範囲で、0 はほぼ同一、1 は類似性がほとんどないことを意味します（デフォルト: 0.5） | FLOAT | はい | 0.0-1.0 |
| `seed` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0） | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 画像生成のオプションのスタイル選択。指定しない場合、デフォルトは `realistic_image` です | STYLEV3 | いいえ | - |
| `negative_prompt` | 画像に含まれたくない要素のオプションのテキスト記述（デフォルト: ""） | STRING | いいえ | - |
| `recraft_controls` | Recraft Controls ノードによる生成のオプションの追加コントロール | CONTROLS | いいえ | - |

**注記:** `seed` パラメータはノードの再実行をトリガーするだけであり、決定的な結果を保証するものではありません。`strength` パラメータは内部で小数点以下2桁に丸められます。プロンプトは検証され、1000文字を超えてはなりません。`recraft_style` が指定されない場合、ノードは `realistic_image` スタイルをデフォルトとして使用します。Infinite Style Library の `style_id` を使用する場合、Vector アートスタイルではないことを確認してください。Vector アートスタイルの場合、ノードが画像の代わりに SVG データを受け取り、エラーが発生する可能性があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 入力画像とプロンプトに基づいて生成された画像。入力画像ごとに `n` 枚の画像が生成されるため、出力の総数は入力数に `n` を掛けた数になります。 | IMAGE |
