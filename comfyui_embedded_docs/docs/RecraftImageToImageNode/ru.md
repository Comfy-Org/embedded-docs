# Recraft: Изображение в изображение

Этот узел изменяет существующее изображение на основе текстового промпта и настройки `strength`. Он отправляет изображение в API Recraft V3 и возвращает новое изображение, которое соответствует промпту, оставаясь более или менее похожим на оригинал в зависимости от значения `strength`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение для изменения. Если передан пакет изображений, каждое изображение обрабатывается отдельно. | IMAGE | Да | - |
| `запрос` | Промпт для генерации изображения. По умолчанию: пустая строка. Максимальная длина: 1000 символов. | STRING | Да | - |
| `n` | Количество генерируемых изображений. По умолчанию: 1. | INT | Да | 1-6 |
| `степень изменения` | Определяет степень отличия от исходного изображения, должен находиться в диапазоне [0, 1], где 0 означает почти идентичное изображение, а 1 — минимальное сходство. По умолчанию: 0.5. | FLOAT | Да | 0.0-1.0 (шаг: 0.01) |
| `seed` | Сид для определения необходимости повторного выполнения узла; фактические результаты недетерминированы независимо от seed. По умолчанию: 0. | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерации изображения. Если не указан, по умолчанию используется `realistic_image`. | STYLEV3 | Нет | - |
| `негативный запрос` | Необязательное текстовое описание нежелательных элементов на изображении. По умолчанию: пустая строка. Предоставляется как входной сокет. | STRING | Нет | - |
| `recraft_controls` | Необязательные дополнительные средства управления генерацией через узел Recraft Controls. | CONTROLS | Нет | - |

**Примечание:** Параметр `seed` только инициирует повторное выполнение узла, но не гарантирует детерминированные результаты. Параметр `strength` внутри округляется до 2 знаков после запятой. Параметр `prompt` проверяется и не должен превышать 1000 символов. Пустой `negative_prompt` рассматривается как отсутствие негативного промпта. Если `recraft_style` не указан, узел по умолчанию использует стиль `realistic_image`. Если вы используете `style_id` из Infinite Style Library, убедитесь, что это не стиль Vector art, так как это может привести к тому, что узел получит данные SVG вместо изображения, что вызовет ошибку. Когда входной `image` является пакетом, каждое изображение в пакете обрабатывается отдельно, и все результаты возвращаются вместе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (или изображения) на основе входного изображения, промпта и параметра `strength`. | IMAGE |
