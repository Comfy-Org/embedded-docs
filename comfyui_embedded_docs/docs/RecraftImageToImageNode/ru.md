# Recraft: Изображение в изображение

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для изменения | IMAGE | Да | - |
| `prompt` | Подсказка для генерации изображения (по умолчанию: "", максимум 1000 символов) | STRING | Да | - |
| `n` | Количество генерируемых изображений (по умолчанию: 1) | INT | Да | 1-6 |
| `strength` | Определяет отличие от исходного изображения; должно лежать в диапазоне [0, 1], где 0 означает почти полное сходство, а 1 — минимальное сходство (по умолчанию: 0.5) | FLOAT | Да | 0.0-1.0 |
| `seed` | Зерно для определения необходимости повторного запуска узла; фактические результаты недетерминированы независимо от зерна (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерации изображения. Если не указано, по умолчанию используется `realistic_image` | STYLEV3 | Нет | - |
| `negative_prompt` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: "") | STRING | Нет | - |
| `recraft_controls` | Необязательное дополнительное управление генерацией через узел Recraft Controls | CONTROLS | Нет | - |

**Примечание:** Параметр `seed` только запускает повторное выполнение узла, но не гарантирует детерминированный результат. Параметр `strength` округляется до двух десятичных знаков. Подсказка проверяется и не должна превышать 1000 символов. Если `recraft_style` не указан, узел по умолчанию использует стиль `realistic_image`. Если вы используете `style_id` из Infinite Style Library, убедитесь, что это не векторный стиль, так как это может привести к получению SVG-данных вместо изображения, что вызовет ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (изображения) на основе входного изображения и подсказки. Для каждого входного изображения создается `n` изображений, поэтому общее количество выходных изображений равно количеству входных изображений, умноженному на `n`. | IMAGE |
