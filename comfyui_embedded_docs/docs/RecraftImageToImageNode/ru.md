# Recraft: Изображение в изображение

Этот узел изменяет существующее изображение на основе текстового запроса и параметра силы (`strength`). Он использует API Recraft V3 для преобразования входного изображения в соответствии с заданным описанием, сохраняя при этом некоторое сходство с исходным изображением, которое контролируется параметром `strength`.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение, которое нужно изменить | IMAGE | Да | - |
| `запрос` | Текстовый запрос для генерации изображения (по умолчанию: пустая строка, максимальная длина: 1000 символов) | STRING | Да | - |
| `n` | Количество изображений для генерации (по умолчанию: 1) | INT | Да | 1-6 |
| `степень изменения` | Определяет отличие от исходного изображения; должно находиться в диапазоне [0, 1], где 0 означает почти полную идентичность, а 1 — очень слабое сходство (по умолчанию: 0.5) | FLOAT | Да | 0.0-1.0 |
| `seed` | Сид, определяющий, должен ли узел выполняться заново; фактические результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | 0-18446744073709551615 |
| `recraft_style` | Необязательный выбор стиля для генерации изображения. Если не указан, по умолчанию используется `realistic_image` | STYLEV3 | Нет | - |
| `негативный запрос` | Необязательное текстовое описание нежелательных элементов на изображении (по умолчанию: пустая строка) | STRING | Нет | - |
| `recraft_controls` | Необязательные дополнительные параметры управления генерацией через узел Recraft Controls | CONTROLS | Нет | - |

**Примечание:** Параметр `seed` только запускает повторное выполнение узла, но не гарантирует детерминированных результатов. Параметр `strength` внутренне округляется до 2 знаков после запятой. `prompt` проходит проверку и не должен превышать 1000 символов. Пустой `negative_prompt` рассматривается как отсутствие негативного промпта. Если `recraft_style` не указан, узел по умолчанию использует стиль `realistic_image`. Если вы используете `style_id` из библиотеки Infinite Style, убедитесь, что это не стиль Vector art, поскольку в этом случае узел может получить SVG-данные вместо изображения, что приведёт к ошибке. Когда входное изображение `image` является пакетом, каждое изображение в пакете обрабатывается отдельно, и все результаты возвращаются вместе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение (изображения) на основе входного изображения и запроса | IMAGE |
