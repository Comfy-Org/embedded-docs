# Загрузить модель увеличения latent

Узел `LatentUpscaleModelLoader` загружает специализированную модель, предназначенную для масштабирования латентных представлений. Он считывает файл модели из назначенной папки системы и автоматически определяет его тип (720p, 1080p или другой), чтобы создать и настроить правильную внутреннюю архитектуру модели. Загруженная модель затем готова к использованию другими узлами для задач сверхразрешения в латентном пространстве.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `model_name` | Имя файла модели латентного масштабирования для загрузки. Доступные параметры динамически заполняются из файлов, находящихся в каталоге `latent_upscale_models` вашего ComfyUI. | COMBO | Да | Все файлы в папке `latent_upscale_models` |

Примечание: узел автоматически определяет архитектуру модели по содержимому файла. Модели, содержащие слои суперразрешения 720p HunyuanVideo, загружаются как модели 720p, модели со слоями повышения разрешения в стиле 1080p загружаются как модели 1080p, а модели с другими структурами слоев загружаются как модели LatentUpsampler.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Загруженная модель латентного масштабирования, настроенная и готовая к использованию. | LATENT_UPSCALE_MODEL |
