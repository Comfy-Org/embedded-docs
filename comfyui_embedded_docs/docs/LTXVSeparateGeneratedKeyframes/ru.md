# LTXV Отделить сгенерированные ключевые кадры

## Обзор

Узел LTXV Separate Generated Keyframes выделяет обратно сгенерированные ключевые кадры, добавленные узлом LTXV Add Generated Keyframes, из сэмплированного латента и удаляет их из кондиционирования. Используйте его перед пространственным апскейлом видеолатента. Не запускайте сначала LTXV Crop Guides — он рассматривает сгенерированные ключевые кадры как одноразовые направляющие и отбрасывает их.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное кондиционирование, которое содержит метаданные сгенерированных ключевых кадров. При выводе эти метаданные удаляются из него. | CONDITIONING | Да | N/A |
| `negative` | Отрицательное кондиционирование, которое содержит метаданные сгенерированных ключевых кадров. При выводе эти метаданные удаляются из него. | CONDITIONING | Да | N/A |
| `latent` | Видеолатент, содержащий сгенерированные ключевые кадры. При выводе ключевые кадры удаляются из него. | LATENT | Да | N/A |
| `keyframes_to_batch` | Возвращать ключевые кадры в виде батча однокадровых латентов. Оставьте выключенным, чтобы получить их как один многокадровый латент — именно это ожидают апсемплер латента и последующий Add Generated Keyframes. | BOOLEAN | Нет | default: False |

### Примечания по входам

- `positive` должен содержать метаданные сгенерированных ключевых кадров, иначе узел выдаёт ошибку с указанием сначала добавить их с помощью LTXV Add Generated Keyframes.
- `latent` должен быть обычным видеолатентом (5D-тензор). Если видеолатент и аудиолатент всё ещё объединены, сначала разделите их с помощью Separate AV Latent.
- Количество токенов на кадр латента, записанное при добавлении ключевых кадров, должно совпадать с количеством токенов на кадр у переданного `latent`. Если латент был масштабирован после добавления ключевых кадров, они больше не совпадают, и узел выдаёт ошибку — отделите их перед апскейлом латента.
- Записанный диапазон кадров ключевых кадров должен помещаться в переданный `latent`, иначе узел выдаёт ошибку о том, что ключевые кадры были записаны относительно другого латента.
- Записанный индекс элемента guide attention должен всё ещё существовать в кондиционировании. Если кондиционирование было пересобрано после добавления ключевых кадров, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с удалёнными метаданными сгенерированных ключевых кадров. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с удалёнными метаданными сгенерированных ключевых кадров. | CONDITIONING |
| `latent` | Видеолатент с удалёнными сгенерированными ключевыми кадрами. | LATENT |
| `keyframes` | Отделённые ключевые кадры с метками generated_keyframe_indices и generated_keyframe_num_frames. Передайте их в последующий Add Generated Keyframes для инициализации новых слотов или в Generated Keyframes To Guides, чтобы закрепить их как замороженные направляющие-изображения (индексы переназначаются, если длина холста изменилась). | LATENT |

## Примечания

- Параметр `keyframes_to_batch` определяет, возвращаются ли ключевые кадры как батч однокадровых латентов или как один многокадровый латент.
- Узел гарантирует, что сгенерированные ключевые кадры удаляются из кондиционирования и латента перед любой дальнейшей обработкой.
- Выход `keyframes` можно использовать для инициализации новых слотов для сгенерированных ключевых кадров или для их закрепления в качестве замороженных направляющих-изображений.
- Узел вызывает `ValueError`, если латент не содержит сгенерированных ключевых кадров или если ключевые кадры не соответствуют ожидаемому формату.
- Узел предполагает, что сгенерированные ключевые кадры были добавлены с помощью узла LTXV Add Generated Keyframes и совместимы с текущим латентом.
