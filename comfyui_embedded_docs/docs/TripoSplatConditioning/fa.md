# شرط‌گذاری TripoSplat

این گره تصویر ورودی را با استفاده از رمزگذار تصویر DINOv3 و VAE فلوکس 2 رمزگذاری می‌کند تا داده‌های شرطی‌سازی مثبت و منفی برای مدل TripoSplat ایجاد کند. همچنین یک هدف نویز با اندازه ثابت (لاتنت به‌علاوه داده‌های دوربین) تولید می‌کند که به‌عنوان نقطه شروع برای KSampler عمل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | رمزگذار تصویر DINOv3 ViT-H/16+ | CLIP_VISION | بله | - |
| `vae` | Flux2 VAE | VAE | بله | - |
| `تصویر` | تصویر ورودی برای رمزگذاری | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مثبت` | داده‌های شرطی‌سازی مثبت شامل ویژگی‌های DINOv3 و لاتنت Flux2 VAE | CONDITIONING |
| `منفی` | داده‌های شرطی‌سازی منفی شامل ویژگی‌های DINOv3 با مقادیر صفر و لاتنت Flux2 VAE با مقادیر صفر | CONDITIONING |
| `latent` | هدف نویز با اندازه ثابت (لاتنت + دوربین) برای KSampler | LATENT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TripoSplatConditioning/fa.md)
