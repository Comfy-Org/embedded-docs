# شرط‌گذاری TripoSplat

این گره با استفاده از رمزگذار تصویر DINOv3 و Flux2 VAE، تصویر ورودی را کدگذاری می‌کند تا داده‌های شرطی‌سازی مثبت و منفی برای مدل TripoSplat ایجاد کند. همچنین یک هدف نویز با اندازه ثابت (یک توالی نهفته به همراه توکن دوربین) تولید می‌کند که به عنوان نقطه شروع برای KSampler عمل می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | رمزگذار تصویر DINOv3 ViT-H/16+ | CLIP_VISION | بله | - |
| `vae` | Flux2 VAE | VAE | بله | - |
| `image` | تصویر ورودی برای کدگذاری | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | داده‌های شرطی‌سازی مثبت حاوی ویژگی‌های تصویر DINOv3 و Latent حاصل از Flux2 VAE تصویر ورودی | CONDITIONING |
| `negative` | داده‌های شرطی‌سازی منفی حاوی ویژگی‌های DINOv3 صفرپرشده و Latent صفرپرشده Flux2 VAE | CONDITIONING |
| `latent` | هدف نویز با اندازه ثابت (latent + توکن دوربین) برای KSampler | LATENT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TripoSplatConditioning/fa.md)
