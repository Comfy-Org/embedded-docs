# TripoSplat кондиционирование

Данный узел кодирует входное изображение с помощью кодировщика изображений DINOv3 и VAE Flux2 для создания положительных и отрицательных данных кондиционирования для модели TripoSplat. Он также генерирует целевой шум фиксированного размера (латентное представление и данные камеры), который служит отправной точкой для KSampler.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | Кодировщик изображений DINOv3 ViT-H/16+ | CLIP_VISION | Да | - |
| `vae` | VAE Flux2 | VAE | Да | - |
| `изображение` | Входное изображение для кодирования | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `положительный` | Положительные данные кондиционирования, содержащие признаки DINOv3 и латентное представление VAE Flux2 | CONDITIONING |
| `отрицательный` | Отрицательные данные кондиционирования, содержащие нулевые признаки DINOv3 и нулевое латентное представление VAE Flux2 | CONDITIONING |
| `latent` | Целевой шум фиксированного размера (латентное представление + данные камеры) для KSampler | LATENT |
