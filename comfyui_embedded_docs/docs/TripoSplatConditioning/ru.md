# TripoSplat кондиционирование

Этот узел кодирует входное изображение с помощью кодировщика изображений DINOv3 и Flux2 VAE, чтобы создать положительные и отрицательные данные кондиционирования для модели TripoSplat. Он также создаёт шумовую цель фиксированного размера (латент + данные камеры), которая служит начальной точкой для KSampler.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | Кодировщик изображений DINOv3 ViT-H/16+ | CLIP_VISION | Да | - |
| `vae` | Flux2 VAE | VAE | Да | - |
| `изображение` | Входное изображение для кодирования | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительные данные кондиционирования, содержащие последовательность признаков DINOv3 и латент Flux2 VAE, передаваемый как эталонный латент | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования, содержащие заполненные нулями признаки DINOv3 и заполненный нулями эталонный латент Flux2 VAE | CONDITIONING |
| `latent` | Шумовая цель фиксированного размера (латент + камера) для KSampler. Латент представляет собой последовательность shape-code постоянной формы (8192 x 16) в паре с одним токеном камеры (1 x 5) | LATENT |
