# TripoSplat кондиционирование

Этот узел кодирует входное изображение с помощью энкодера зрения DINOv3 и VAE Flux2 для создания положительных и отрицательных данных кондиционирования для модели TripoSplat. Он также генерирует цель шума фиксированного размера (последовательность скрытого представления плюс токен камеры), которая служит отправной точкой для KSampler.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `clip_vision` | Энкодер изображений DINOv3 ViT-H/16+ | CLIP_VISION | Да | - |
| `vae` | VAE Flux2 | VAE | Да | - |
| `image` | Входное изображение для кодирования | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `positive` | Положительные данные кондиционирования, содержащие признаки изображения DINOv3 и скрытое представление VAE Flux2 входного изображения | CONDITIONING |
| `negative` | Отрицательные данные кондиционирования, содержащие заполненные нулями признаки DINOv3 и заполненное нулями скрытое представление VAE Flux2 | CONDITIONING |
| `latent` | Цель шума фиксированного размера (скрытое представление + камера) для KSampler | LATENT |
