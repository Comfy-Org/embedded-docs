# تهيئة TripoSplat

تقوم هذه العقدة بترميز صورة الإدخال باستخدام مشفّر الرؤية DINOv3 و Flux2 VAE لإنشاء بيانات توجيه إيجابية وسلبية لنموذج TripoSplat. كما تُنشئ هدف ضوضاء ثابت الحجم (تسلسل كمون بالإضافة إلى رمز الكاميرا) ليكون نقطة البداية لـ KSampler.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | مشفّر الصور DINOv3 ViT-H/16+ | CLIP_VISION | نعم | - |
| `vae` | Flux2 VAE | VAE | نعم | - |
| `image` | صورة الإدخال المراد ترميزها | IMAGE | نعم | - |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | بيانات توجيه إيجابية تحتوي على ميزات صورة DINOv3 وكمون Flux2 VAE للصورة المدخلة | CONDITIONING |
| `negative` | بيانات توجيه سلبية تحتوي على ميزات DINOv3 معبأة بالأصفار وكمون Flux2 VAE معبأ بالأصفار | CONDITIONING |
| `latent` | هدف الضوضاء ثابت الحجم (الكمون + رمز الكاميرا) لـ KSampler | LATENT |
