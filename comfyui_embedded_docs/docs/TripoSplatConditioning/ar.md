# تهيئة TripoSplat

تقوم هذه العقدة بترميز صورة إدخال باستخدام مُرمّز صور DINOv3 و Flux2 VAE لإنتاج بيانات تكييف موجبة وسالبة لنموذج TripoSplat. كما تُنشئ هدف ضوضاء ثابت الحجم (latent بالإضافة إلى بيانات الكاميرا) يخدم كنقطة بداية لـ KSampler.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | مُرمّز صور DINOv3 ViT-H/16+ | CLIP_VISION | نعم | - |
| `vae` | Flux2 VAE | VAE | نعم | - |
| `image` | صورة الإدخال المراد ترميزها | IMAGE | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `positive` | بيانات تكييف موجبة تحتوي على تسلسل ميزات DINOv3 و latent الخاص بـ Flux2 VAE محمولًا كـ latent مرجعي | CONDITIONING |
| `negative` | بيانات تكييف سالبة تحتوي على ميزات DINOv3 مملوءة بالأصفار و latent مرجعي لـ Flux2 VAE مملوء بالأصفار | CONDITIONING |
| `latent` | هدف الضوضاء ثابت الحجم (latent + الكاميرا) الخاص بـ KSampler. يكون latent عبارة عن تسلسل شيفرة شكل ثابت (8192 x 16) مقترنًا برمز كاميرا واحد (1 x 5) | LATENT |
