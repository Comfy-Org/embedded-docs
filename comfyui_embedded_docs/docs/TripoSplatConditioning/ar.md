# تهيئة TripoSplat

هذه العقدة ترمّز صورة مدخلة باستخدام مشفر الصور DINOv3 وVAE الخاص بـ Flux2 لإنشاء بيانات توجيه (conditioning) موجبة وسالبة لنموذج TripoSplat. كما تولّد هدف ضوضاء ثابت الحجم (الكمون + بيانات الكاميرا) ليكون نقطة البداية لعنصر KSampler.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | مشفر الصور DINOv3 ViT-H/16+ | CLIP_VISION | نعم | - |
| `vae` | VAE الخاص بـ Flux2 | VAE | نعم | - |
| `صورة` | الصورة المدخلة المطلوب ترميزها | IMAGE | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `إيجابي` | بيانات توجيه موجبة تحتوي على خصائص DINOv3 وكمون VAE الخاص بـ Flux2 | CONDITIONING |
| `سلبي` | بيانات توجيه سالبة تحتوي على خصائص DINOv3 المعبأة بالأصفار وكمون VAE الخاص بـ Flux2 المعبأ بالأصفار | CONDITIONING |
| `latent` | هدف الضوضاء ثابت الحجم (الكمون + الكاميرا) لعنصر KSampler | LATENT |
