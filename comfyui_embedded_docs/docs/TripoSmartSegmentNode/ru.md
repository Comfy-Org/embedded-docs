# TripoSmartSegmentNode

Разделяет 3D-модель на семантически значимые части и присваивает каждой части имя. Он может либо сегментировать существующую модель (переданную через ID задачи), либо сначала сгенерировать модель из изображения, а затем сегментировать её. Полученный `segment task_id` можно использовать в других узлах Tripo, таких как Complete Mesh Parts, Retopology, Texture model и Convert model, так же, как результат Tripo: Segment Model.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `source` | Сегментировать существующую модель или сгенерировать модель из изображения и сегментировать её. Выбранный вариант определяет, какие дополнительные входы появятся. | DYNAMIC_COMBO | Да | `"model"`<br>`"image"` |

### Входы модели

Отображается, когда `source` имеет значение `"model"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Результат GLB. Quad (FBX) меши должны сначала пройти через Tripo: Convert model (GLTF). | MODEL_TASK_ID | Да | - |
| `granularity` | Насколько мелко модель разбивается на части (по умолчанию: "medium"). | COMBO | Нет | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | Необязательный текст с названиями частей, которые нужно найти, например 'игровой персонаж с мечом и доспехами' (по умолчанию: пусто). | STRING | Нет | - |

### Входы изображения

Отображается, когда `source` имеет значение `"image"`. Tripo сначала генерирует модель из изображения, затем сегментирует её.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение, используемое для генерации модели, которая будет сегментирована. | IMAGE | Да | - |
| `granularity` | Насколько мелко модель разбивается на части (по умолчанию: "medium"). | COMBO | Нет | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | Необязательный текст с названиями частей, которые нужно найти, например 'игровой персонаж с мечом и доспехами' (по умолчанию: пусто). | STRING | Нет | - |

**Примечания:**

- `granularity` и `hint` общие для обоих вариантов `source` и являются необязательными. Если `hint` оставить пустым, подсказка не отправляется в сервис.
- Когда `source` имеет значение `"model"`, принимаются только модели GLB. Другие форматы, например quad (FBX) меши, должны быть сначала преобразованы с помощью Tripo: Convert model (GLTF).
- Задача опрашивается до достижения конечного состояния; примерная длительность — около 180 секунд. Если Tripo возвращает неполный результат сегментации, узел сообщает об ошибке.
- Значок цены: примерно 0,85 USD, когда `source` имеет значение `"image"`, и примерно 0,55 USD, когда `source` имеет значение `"model"` (значения указаны приблизительно).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `segment task_id` | ID задачи сегментации, который можно использовать как вход для других узлов Tripo. | SEGMENT_TASK_ID |
| `model task_id` | Модель, которая была сегментирована (сгенерирована из изображения или импортирована). | MODEL_TASK_ID |
| `GLB` | Файл сегментированной 3D-модели. | FILE3DGLB |
| `part_names` | Имена частей, разделённые запятыми. | STRING |
| `части` | Описание частей, найденных Tripo. | STRING |
| `маска` | Изображение-маска, созданное в результате сегментации. | IMAGE |
