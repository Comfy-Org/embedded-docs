# TripoSmartSegmentNode

يقسّم نموذجًا ثلاثي الأبعاد إلى أجزاء ذات معنى دلالي ويمنح كل جزء اسمًا. يمكنه إما تقسيم نموذج موجود (يُقدَّم عبر معرّف مهمة) أو أولًا توليد نموذج من صورة ثم تقسيمه. يمكن استخدام `segment task_id` الناتج بواسطة عُقد Tripo أخرى، مثل Complete Mesh Parts وRetopology وTexture model وConvert model، بالطريقة نفسها التي تُستخدم بها نتيجة Tripo: Segment Model.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `المصدر` | تقسيم نموذج موجود، أو توليد نموذج من صورة ثم تقسيمه. يحدد الخيار المُحدد المدخلات الإضافية التي تظهر. | DYNAMIC_COMBO | نعم | `"model"`<br>`"image"` |

### مدخلات النموذج

تظهر عندما تكون قيمة `source` مضبوطة على `"model"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | نتيجة GLB. يجب أن تمرّ الشبكات من نوع Quad (FBX) أولًا عبر Tripo: Convert model (GLTF). | MODEL_TASK_ID | نعم | - |
| `granularity` | مدى دقة تقسيم النموذج إلى أجزاء (الافتراضي: "medium"). | COMBO | لا | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | نص اختياري يسمّي الأجزاء المطلوب البحث عنها، مثل 'شخصية لعبة بسيف ودرع' (الافتراضي: فارغ). | STRING | لا | - |

### مدخلات الصورة

تظهر عندما تكون قيمة `source` مضبوطة على `"image"`. تولّد Tripo أولًا نموذجًا من الصورة، ثم تقسّمه.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | الصورة المستخدمة لتوليد النموذج الذي سيتم تقسيمه. | IMAGE | نعم | - |
| `granularity` | مدى دقة تقسيم النموذج إلى أجزاء (الافتراضي: "medium"). | COMBO | لا | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | نص اختياري يسمّي الأجزاء المطلوب البحث عنها، مثل 'شخصية لعبة بسيف ودرع' (الافتراضي: فارغ). | STRING | لا | - |

**ملاحظات:**

- `granularity` و`hint` مشتركان بين كلا خيارَي `source` وهما اختياريان. عندما يُترك `hint` فارغًا، لا تُرسل أي تلميحات إلى الخدمة.
- عندما تكون `source` هي `"model"`، تُقبل نماذج GLB فقط. يجب تحويل التنسيقات الأخرى، مثل الشبكات من نوع Quad (FBX)، أولًا باستخدام Tripo: Convert model (GLTF).
- يتم الاستعلام عن المهمة دوريًا حتى تصل إلى حالة نهائية، وتقدّر مدتها بنحو 180 ثانية. إذا أعادت Tripo نتيجة تقسيم غير مكتملة، تُبلّغ العقدة عن خطأ.
- شارة السعر: نحو 0.85 دولار أمريكي عندما تكون `source` هي `"image"`، ونحو 0.55 دولار أمريكي عندما تكون `source` هي `"model"` (القيم معروضة على سبيل التقريب).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `segment task_id` | معرّف مهمة التقسيم، ويمكن استخدامه كمدخل لعُقد Tripo أخرى. | SEGMENT_TASK_ID |
| `task_id النموذج` | النموذج الذي جرى تقسيمه (المولَّد من الصورة، أو المستورد). | MODEL_TASK_ID |
| `GLB` | ملف النموذج ثلاثي الأبعاد المقسّم. | FILE3DGLB |
| `part_names` | أسماء الأجزاء مفصولة بفواصل. | STRING |
| `الأجزاء` | وصف Tripo للأجزاء التي عثرت عليها. | STRING |
| `قناع` | صورة القناع الناتجة عن التقسيم. | IMAGE |
