# TripoSmartSegmentNode

یک مدل سه‌بعدی را به بخش‌های معنادار تقسیم می‌کند و به هر بخش نامی می‌دهد. می‌تواند یک مدل موجود (که از طریق شناسه تسک ارائه می‌شود) را تقسیم‌بندی کند، یا ابتدا یک مدل را از تصویر تولید کند و سپس آن را تقسیم‌بندی کند. خروجی `segment task_id` می‌تواند توسط سایر گره‌های Tripo، مانند Complete Mesh Parts، Retopology، Texture model و Convert model، به همان روش نتیجه Tripo: Segment Model استفاده شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `source` | یک مدل موجود را تقسیم‌بندی کنید، یا یک مدل را از تصویر تولید کنید و سپس آن را تقسیم‌بندی کنید. گزینه انتخاب‌شده تعیین می‌کند کدام ورودی‌های اضافی نمایش داده شوند. | DYNAMIC_COMBO | بله | `"model"`<br>`"image"` |

### ورودی‌های مدل

وقتی `source` روی `"model"` تنظیم شده باشد نمایش داده می‌شود.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | یک نتیجه GLB. مش‌های Quad (FBX) ابتدا باید با Tripo: Convert model (GLTF) تبدیل شوند. | MODEL_TASK_ID | بله | - |
| `granularity` | میزان ریزدانه بودن تقسیم مدل به بخش‌ها (پیش‌فرض: "medium"). | COMBO | خیر | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | متن اختیاری برای نام‌گذاری بخش‌هایی که باید جست‌وجو شوند، مثلاً 'شخصیت بازی با شمشیر و زره' (پیش‌فرض: خالی). | STRING | خیر | - |

### ورودی‌های تصویر

وقتی `source` روی `"image"` تنظیم شده باشد نمایش داده می‌شود. Tripo ابتدا یک مدل را از تصویر تولید می‌کند و سپس آن را تقسیم‌بندی می‌کند.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویری که برای تولید مدلی که تقسیم‌بندی خواهد شد استفاده می‌شود. | IMAGE | بله | - |
| `granularity` | میزان ریزدانه بودن تقسیم مدل به بخش‌ها (پیش‌فرض: "medium"). | COMBO | خیر | `"coarse"`<br>`"medium"`<br>`"fine"` |
| `hint` | متن اختیاری برای نام‌گذاری بخش‌هایی که باید جست‌وجو شوند، مثلاً 'شخصیت بازی با شمشیر و زره' (پیش‌فرض: خالی). | STRING | خیر | - |

**نکات:**

- `granularity` و `hint` بین هر دو گزینه `source` مشترک و اختیاری هستند. وقتی `hint` خالی بماند، هیچ راهنمایی به سرویس ارسال نمی‌شود.
- وقتی `source` روی `"model"` باشد، فقط مدل‌های GLB پذیرفته می‌شوند. سایر قالب‌ها، مانند مش‌های Quad (FBX)، ابتدا باید با Tripo: Convert model (GLTF) تبدیل شوند.
- وضعیت تسک به‌صورت دوره‌ای بررسی می‌شود تا به حالت نهایی برسد؛ مدت‌زمان تخمینی حدود 180 ثانیه است. اگر Tripo نتیجه تقسیم‌بندی ناقصی برگرداند، گره خطا گزارش می‌کند.
- نشان هزینه: تقریباً 0.85 دلار وقتی `source` روی `"image"` است و تقریباً 0.55 دلار وقتی `source` روی `"model"` است (مقادیر به‌صورت تقریبی نمایش داده می‌شوند).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `segment task_id` | شناسه تسک تقسیم‌بندی، قابل استفاده به‌عنوان ورودی برای سایر گره‌های Tripo. | SEGMENT_TASK_ID |
| `model task_id` | مدلی که تقسیم‌بندی شد (تولیدشده از تصویر یا واردشده). | MODEL_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تقسیم‌بندی‌شده. | FILE3DGLB |
| `part_names` | نام بخش‌ها، جداشده با کاما. | STRING |
| `parts` | توصیف Tripo از بخش‌هایی که پیدا کرده است. | STRING |
| `mask` | تصویر ماسک تولیدشده توسط تقسیم‌بندی. | IMAGE |
