# تبدیل ویدئو به SFX با Mirelo

با Mirelo SFX جلوه‌های صوتی‌ای تولید کنید که ویدئو را دنبال کنند. کلیپ بارگذاری می‌شود، مدل کنش روی صفحه را دنبال می‌کند و یک میکس جلوه‌های صوتی، به‌همراه یک ترک گفتار جداگانه با گفت‌وگوی استخراج‌شده از صدای همراه، برمی‌گرداند. از آن برای افزودن فولی، فضای صوتی و ضربه‌ها به کلیپ‌های بی‌صدا یا نیمه‌بی‌صدا استفاده کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل مورد استفاده. انتخاب یک مدل پارامترهای مخصوص آن را نمایش می‌دهد: `video`، `audio`، `prompt`، `negative_prompt`، `preserve_speech`، `seed` و `auto_downscale`. | DYNAMIC_COMBO | بله | `"sfx-2.0"` |
| `video` | ویدئویی که برای آن صدا تولید می‌شود. صدا برای کل کلیپ، از 1 تا 600 ثانیه، تولید می‌شود. | VIDEO | بله | 1 تا 600 ثانیه |
| `audio` | ترک گفت‌وگو که به‌جای صدای همراه خود ویدئو برای `preserve_speech` و برای خروجی `speech` استفاده می‌شود. برای استفاده از صدای جاسازی‌شده در ویدئو، آن را متصل نکنید. | AUDIO | خیر | - |
| `prompt` | صدای تولیدی چه ویژگی‌ای داشته باشد. می‌تواند خالی بماند (پیش‌فرض: خالی) چون مدل خود ویدئو را توصیف می‌کند و همیشه از `prompt` پیروی نمی‌کند. حداکثر 2000 کاراکتر. | STRING | بله | حداکثر 2000 کاراکتر |
| `negative_prompt` | صداهایی که باید از آن‌ها اجتناب شود، به‌صورت فهرستی کوتاه جدا‌شده با کاما. می‌تواند خالی بماند (پیش‌فرض: خالی). حداکثر 1000 کاراکتر. | STRING | بله | حداکثر 1000 کاراکتر |
| `preserve_speech` | گفت‌وگو زیر صدای تولیدشده میکس بماند. حالت خاموش فقط جلوه‌های صوتی برمی‌گرداند. (پیش‌فرض: True) | BOOLEAN | بله | false<br>true |
| `seed` | مقدار seed برای درخواست. نتایج قطعی نیستند، بنابراین یک seed یکسان یک کلیپ را تکرار نمی‌کند. (پیش‌فرض: 42) | INT | بله | 0 تا 4294967295 |
| `auto_downscale` | اگر ضلع کوتاه‌تر کلیپ بالای 2160 پیکسل باشد، پیش از بارگذاری آن را با حفظ نسبت تصویر کوچک‌مقیاس می‌کند؛ کلیپ‌های کوچک‌تر دست‌نخورده می‌مانند (پیش‌فرض: True). | BOOLEAN | خیر | `True`<br>`False` |

گره وقتی کلیپ کوتاه‌تر از 1 ثانیه یا بلندتر از 600 ثانیه باشد، با خطا متوقف می‌شود. یک ترک `audio` متصل‌شده همان گفت‌وگویی را تعیین می‌کند که `preserve_speech` نگه می‌دارد و خروجی `speech` آن را جدا می‌کند؛ بدون آن، گفت‌وگو از صدای همراه خود ویدئو می‌آید.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `audio` | میکس جلوه‌های صوتی برای کلیپ، به‌طوری‌که وقتی `preserve_speech` روشن است گفت‌وگو زیر آن میکس شده باشد. | AUDIO |
| `speech` | گفت‌وگوی جداشده از صدای همراه. زمانی که گفتاری یافت نشود یا جداسازی گفتار چیزی برنگرداند، بی‌صدا و با همان نرخ نمونه‌برداری `audio` است. | AUDIO |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MireloVideoToSFX/fa.md)
