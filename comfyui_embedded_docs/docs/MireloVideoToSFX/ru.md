# Mirelo: видео в SFX

Генерируйте звуковые эффекты, синхронизированные с видео, с помощью Mirelo SFX. Клип загружается, модель отслеживает действие на экране и возвращает микс звуковых эффектов, а также отдельную речевую дорожку с диалогом, извлечённым из звуковой дорожки. Используйте это для добавления фоли, атмосферных звуков и ударных акцентов к беззвучным или частично беззвучным клипам.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель для использования. При выборе модели отображаются параметры, специфичные для неё: `video`, `audio`, `prompt`, `negative_prompt`, `preserve_speech`, `seed` и `auto_downscale`. | DYNAMIC_COMBO | Да | `"sfx-2.0"` |
| `video` | Видео, для которого нужно сгенерировать звук. Звук генерируется для всего клипа, от 1 до 600 секунд. | VIDEO | Да | от 1 до 600 секунд |
| `audio` | Дорожка диалога, используемая вместо собственной звуковой дорожки видео для `preserve_speech` и для выхода `speech`. Оставьте её неподключённой, чтобы использовать звук, встроенный в видео. | AUDIO | Нет | - |
| `prompt` | Каким должен быть звук. Можно оставить пустым (по умолчанию: пусто), поскольку модель сама описывает видео, и она не всегда следует промпту. Максимум 2000 символов. | STRING | Да | До 2000 символов |
| `negative_prompt` | Звуки, которых следует избегать, в виде короткого списка через запятую. Можно оставить пустым (по умолчанию: пусто). Максимум 1000 символов. | STRING | Да | До 1000 символов |
| `preserve_speech` | Сохранять диалог в общем миксе под сгенерированным звуком. При выключении возвращаются только звуковые эффекты. (по умолчанию: True) | BOOLEAN | Да | false<br>true |
| `seed` | Сид для запроса. Результаты недетерминированы, поэтому один и тот же сид не повторяет клип. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |
| `auto_downscale` | Уменьшать масштаб клипа, у которого меньшая сторона превышает 2160 пикселей, перед загрузкой, сохраняя его соотношение сторон; клипы меньшего размера не затрагиваются (по умолчанию: True). | BOOLEAN | Нет | `True`<br>`False` |

Узел завершается с ошибкой, если клип короче 1 секунды или длиннее 600 секунд. Подключённая дорожка `audio` задаёт диалог, который сохраняет `preserve_speech` и который выделяет выход `speech`; без неё диалог берётся из собственной звуковой дорожки видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Микс звуковых эффектов для клипа; диалог смешан под ним, когда `preserve_speech` включён. | AUDIO |
| `speech` | Диалог, отделённый от звуковой дорожки. Беззвучный, с той же частотой дискретизации, что и `audio`, если речь не найдена или разделение речи не дало результата. | AUDIO |
