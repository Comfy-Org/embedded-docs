# Mirelo Video to SFX

Генерируйте звуковые эффекты, синхронизированные с видео, с помощью Mirelo SFX. Клип загружается, модель отслеживает действие на экране и возвращает микс звуковых эффектов, а также отдельную дорожку речи с диалогом, извлечённым из звуковой дорожки. Используйте узел, чтобы добавлять фоли, атмосферные шумы и звуки ударов к немым или частично немым клипам.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель для использования. Выбор модели открывает специфичные для неё параметры: `video`, `audio`, `prompt`, `negative_prompt`, `preserve_speech` и `seed`. | DYNAMIC_COMBO | Да | `"sfx-2.0"` |
| `video` | Видео, для которого нужно сгенерировать звук. Звук генерируется для всего клипа, от 1 до 600 секунд. | VIDEO | Да | от 1 до 600 секунд |
| `audio` | Дорожка диалога, которую нужно использовать вместо собственной звуковой дорожки видео для `preserve_speech` и для выхода `speech`. Оставьте её неподключённой, чтобы использовать звук, встроенный в видео. | AUDIO | Нет | - |
| `prompt` | Каким должен быть звук. Можно оставить пустым (по умолчанию: пусто), поскольку модель сама описывает видео, и она не всегда следует промпту. Максимум 2000 символов. | STRING | Да | До 2000 символов |
| `negative_prompt` | Звуки, которых нужно избегать, в виде короткого списка через запятую. Можно оставить пустым (по умолчанию: пусто). Максимум 1000 символов. | STRING | Да | До 1000 символов |
| `preserve_speech` | Сохранять диалог смешанным под сгенерированным звуком. При выключении возвращаются только звуковые эффекты. (по умолчанию: True) | BOOLEAN | Да | false<br>true |
| `seed` | Начальное значение для запроса. Результаты недетерминированы, поэтому одно и то же значение seed не повторяет клип. (по умолчанию: 42) | INT | Да | от 0 до 4294967295 |

Узел завершается с ошибкой, если клип короче 1 секунды или длиннее 600 секунд. Подключённая дорожка `audio` задаёт диалог, который сохраняет `preserve_speech` и который выделяет выход `speech`; без неё диалог берётся из собственной звуковой дорожки видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Микс звуковых эффектов для клипа; диалог смикширован под него, когда `preserve_speech` включён. | AUDIO |
| `speech` | Диалог, выделенный из звуковой дорожки. Беззвучный, с той же частотой дискретизации, что и `audio`, если речь не обнаружена или разделение речи ничего не вернуло. | AUDIO |
