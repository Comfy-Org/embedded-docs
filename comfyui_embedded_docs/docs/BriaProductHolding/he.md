# Bria Product Holding

צומת זה מניח מוצר בידיו של אדם באמצעות Bria. זהותו, התנוחה והרקע של האדם נשמרים, בעוד שהסצנה מרונדרת מחדש בכ-1 מגה-פיקסל, ולכן התוצאה אינה מיושרת ברמת הפיקסל לתמונת הקלט. כל תמונות המוצר מתארות מוצר אחד מזוויות או משלבים שונים.

## קלטים

בורר `moderation` חושף אפשרות מודרציה נוספת כאשר הוא מוגדר ל-`"true"`.

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `person_image` | התמונה של האדם המחזיק במוצר. ערוץ האלפא מוסר לפני העלאת התמונה. | IMAGE | כן | - |
| `product_images` | 1 עד 3 תמונות של מוצר אחד: המוצר עצמו, האריזה שלו, זווית נוספת או פריט נלווה. קלט באצווה נספר פעם אחת לכל תמונה, ואזורים שקופים מטופלים כלבנים. | AUTOGROW | כן | 1 עד 3 תמונות |
| `instruction` | הנחיה נוספת אופציונלית שמתווספת להנחיה המובנית של Bria, כגון באיזו יד להשתמש או לאיזה כיוון פונה התווית. ברירת מחדל: `""` (מחרוזת ריקה). | STRING | כן | - |
| `aspect_ratio` | `"auto"` שומר על מסגור תמונת האדם בכ-1 מגה-פיקסל. יחס קבוע מחזיר 0.6 עד 1 מגה-פיקסל, לדוגמה 768x1024 עבור `"3:4"`. ברירת מחדל: `"auto"`. | COMBO | כן | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"` |
| `seed` | Seed שנשלח ל-Bria עם הבקשה. ברירת מחדל: 42. | INT | כן | 1 עד 2147483647 |
| `moderation` | הגדרות מודרציה. כאשר מוגדר ל-`"true"`, דגל המודרציה שלהלן הופך לזמין. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |

### קלטים של מודרציה "true"

פרמטר זה מופיע רק כאשר `moderation` מוגדר ל-`"true"`.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | מפעיל מודרציה על תוכן התמונה שנוצרה. ברירת מחדל: `False`. | BOOLEAN | לא | True / False |

**מגבלות:**

* `product_images` מקבל לכל היותר 3 תמונות, כאשר כל תמונה נספרת בנפרד אם הקלט הוא באצווה.
* פיקסלים שקופים בתמונות המוצר מוטמעים על רקע לבן לפני ההעלאה.
* ערוץ האלפא של `person_image` מוסר לפני ההעלאה.
