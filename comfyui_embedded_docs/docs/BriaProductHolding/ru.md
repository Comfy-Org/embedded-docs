# Bria Product Holding

Этот узел помещает продукт в руки человека с помощью Bria. Личность человека, поза и фон сохраняются, при этом сцена перерисовывается с разрешением около 1 мегапикселя, поэтому результат не совпадает с входной фотографией попиксельно. Все изображения продукта описывают один продукт с разных ракурсов или стадий.

## Входы

Селектор `moderation` открывает дополнительную опцию модерации, если установлен в `"true"`.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `person_image` | Фотография человека, который держит продукт. Альфа-канал удаляется перед загрузкой изображения. | IMAGE | Да | - |
| `product_images` | От 1 до 3 изображений одного продукта: сам продукт, его упаковка, другой ракурс или сопутствующий товар. При пакетном вводе каждое изображение учитывается отдельно, а прозрачные области обрабатываются как белые. | AUTOGROW | Да | 1 до 3 изображений |
| `instruction` | Необязательное дополнительное указание, добавляемое к встроенной инструкции Bria, например, какую руку использовать или в какую сторону направлена этикетка. По умолчанию: `""` (пустая строка). | STRING | Да | - |
| `aspect_ratio` | `"auto"` сохраняет кадрирование фотографии человека на уровне около 1 мегапикселя. Фиксированное соотношение возвращает изображение размером от 0.6 до 1 мегапикселя, например 768x1024 для `"3:4"`. По умолчанию: `"auto"`. | COMBO | Да | `"auto"`<br>`"1:1"`<br>`"2:3"`<br>`"3:2"`<br>`"3:4"`<br>`"4:3"`<br>`"4:5"`<br>`"5:4"`<br>`"9:16"`<br>`"16:9"` |
| `seed` | Сид, отправляемый в Bria вместе с запросом. По умолчанию: 42. | INT | Да | 1 до 2147483647 |
| `moderation` | Настройки модерации. Если установлено `"true"`, становится доступен флаг модерации, указанный ниже. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |

### Входы при moderation "true"

Этот параметр появляется только когда `moderation` установлен в `"true"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | Включает модерацию содержимого для сгенерированного изображения. По умолчанию: `False`. | BOOLEAN | Нет | True / False |

**Ограничения:**

* `product_images` принимает не более 3 изображений; при пакетном вводе они считаются по одному изображению.
* Прозрачные пиксели на изображениях продукта перед загрузкой совмещаются с белым фоном.
* Альфа-канал `person_image` удаляется перед загрузкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированная фотография с продуктом, помещённым в руки человека. | IMAGE |
