# Kling Omni تبدیل متن به ویدیو (Pro)

این گره با استفاده از جدیدترین مدل Kling AI از یک توضیح متنی ویدئو تولید می‌کند. پرامپت شما را به یک API راه دور می‌فرستد و ویدئوی تولیدشده را برمی‌گرداند. می‌توانید طول، شکل و کیفیت ویدئو را کنترل کنید و به‌صورت اختیاری استوری‌بوردهای چندصحنه‌ای بسازید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل خاص Kling برای تولید ویدئو (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک پرامپت متنی که محتوای ویدئو را توصیف می‌کند. این می‌تواند شامل توصیف‌های مثبت و منفی باشد. وقتی استوری‌بوردها فعال باشند، نادیده گرفته می‌شود. | STRING | بله | 0 تا 2500 نویسه |
| `aspect_ratio` | شکل یا ابعاد ویدئوی تولیدشده. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | طول ویدئو بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 ثانیه |
| `resolution` | کیفیت یا وضوح پیکسلی ویدئو (پیش‌فرض: `"1080p"`). در داخل به کیفیت استاندارد، pro یا 4k نگاشت می‌شود. | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید مجموعه‌ای از بخش‌های ویدئویی با پرامپت‌ها و مدت‌های مجزا. برای مدل o1 نادیده گرفته می‌شود. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | آیا برای ویدئو صدا تولید شود (پیش‌فرض: False). | BOOLEAN | خیر | True / False |
| `seed` | مقدار seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های فرعی استوری‌بورد

وقتی `storyboards` روی مقداری غیر از `"disabled"` تنظیم شود، ورودی‌های زیر برای هر بخش استوری‌بورد نمایش داده می‌شوند. در نام پارامترهای زیر، `{i}` شماره بخش است، از 1 تا تعداد استوری‌بورد انتخاب‌شده.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | پرامپت برای بخش {i} استوری‌بورد. حداکثر 512 نویسه. | STRING | بله | 1 تا 512 نویسه |
| `storyboard_{i}_duration` | مدت بخش {i} استوری‌بورد بر حسب ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 ثانیه |

### محدودیت‌ها و قیود پارامترها

- **محدودیت‌های مخصوص مدل:**
  - مدل `kling-video-o1` فقط از مدت‌های **5 یا 10 ثانیه** پشتیبانی می‌کند.
  - مدل `kling-video-o1` از تولید صدا **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` از وضوح 4k **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` از استوری‌بوردها **پشتیبانی نمی‌کند**.
- **محدودیت‌های استوری‌بورد:**
  - وقتی استوری‌بوردها فعال هستند، فیلد `prompt` نادیده گرفته می‌شود.
  - هر استوری‌بورد به پرامپت (1 تا 512 نویسه) و مدت اختصاصی خود نیاز دارد.
  - مجموع مدت همه استوری‌بوردها باید دقیقاً برابر پارامتر سراسری `duration` باشد.
- **الزامات پرامپت:**
  - وقتی استوری‌بوردها **غیرفعال** هستند، فیلد `prompt` الزامی است (حداقل 1 نویسه).
  - وقتی استوری‌بوردها **فعال** هستند، فیلد `prompt` می‌تواند خالی باشد (0 نویسه).
