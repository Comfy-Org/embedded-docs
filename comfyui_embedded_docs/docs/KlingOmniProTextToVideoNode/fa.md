# Kling Omni تبدیل متن به ویدیو (Pro)

این گره از جدیدترین مدل Kling AI برای تولید ویدیو از توضیحات متنی استفاده می‌کند. این گره، prompt شما را به یک API راه دور ارسال کرده و ویدیوی تولیدشده را بازمی‌گرداند. این گره به شما امکان می‌دهد طول، شکل، کیفیت ویدیو را کنترل کرده و حتی استوری‌بوردهای چندصحنه‌ای ایجاد کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل Kling خاص برای تولید ویدیو (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک متن prompt که محتوای ویدیو را توصیف می‌کند. این متن می‌تواند شامل توضیحات مثبت و منفی باشد. زمانی که استوری‌بورد فعال باشد نادیده گرفته می‌شود. | STRING | بله | 0 تا 2500 کاراکتر |
| `aspect_ratio` | شکل یا ابعاد ویدیوی مورد نظر برای تولید. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | طول ویدیو بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 ثانیه |
| `resolution` | کیفیت یا وضوح پیکسلی ویدیو (پیش‌فرض: `"1080p"`). در داخل به کیفیت استاندارد، حرفه‌ای یا 4k نگاشت می‌شود. | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید یک سری بخش‌های ویدیویی با promptها و مدت‌زمان‌های مستقل. برای مدل o1 نادیده گرفته می‌شود. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | آیا برای ویدیو صدا تولید شود یا نه (پیش‌فرض: False). | BOOLEAN | خیر | True / False |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed قطعی نیستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### زیرورودی‌های استوری‌بورد

هنگامی که `storyboards` روی مقداری غیر از `"disabled"` تنظیم شود، ورودی‌های زیر برای هر بخش استوری‌بورد ظاهر می‌شوند. در نام پارامترهای زیر، `{i}` شماره بخش است، از 1 تا تعداد استوری‌بورد انتخاب‌شده.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | prompt برای بخش {i} استوری‌بورد. حداکثر 512 کاراکتر. | STRING | بله | 1 تا 512 کاراکتر |
| `storyboard_{i}_duration` | مدت‌زمان برای بخش {i} استوری‌بورد بر حسب ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 ثانیه |

### محدودیت‌ها و الزامات پارامترها

- **محدودیت‌های خاص مدل:**
  - مدل `kling-video-o1` فقط مدت‌زمان‌های **5 یا 10 ثانیه** را پشتیبانی می‌کند.
  - مدل `kling-video-o1` از تولید صدا **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` وضوح 4k را **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` استوری‌بورد را **پشتیبانی نمی‌کند**.
- **محدودیت‌های استوری‌بورد:**
  - هنگامی که استوری‌بورد فعال باشد، فیلد `prompt` نادیده گرفته می‌شود.
  - هر استوری‌بورد به prompt و مدت‌زمان مخصوص به خود نیاز دارد (1 تا 512 کاراکتر).
  - مجموع مدت‌زمان همه استوری‌بوردها باید دقیقاً برابر با پارامتر سراسری `duration` باشد.
- **الزامات prompt:**
  - هنگامی که استوری‌بورد **غیرفعال** باشد، فیلد `prompt` الزامی است (حداقل 1 کاراکتر).
  - هنگامی که استوری‌بورد **فعال** باشد، فیلد `prompt` می‌تواند خالی باشد (0 کاراکتر).
