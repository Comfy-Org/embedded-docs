# Kling Omni تبدیل متن به ویدیو (Pro)

این گره از جدیدترین مدل Kling AI برای تولید ویدیو از روی توضیح متنی استفاده می‌کند. درخواست شما را به یک API راه‌دور ارسال کرده و ویدیوی تولیدشده را بازمی‌گرداند. این گره به شما امکان می‌دهد طول، شکل، کیفیت ویدیو را کنترل کرده و حتی استوری‌بوردهای چندصحنه‌ای ایجاد کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_name` | مدل مشخص Kling برای استفاده در تولید ویدیو (پیش‌فرض: `"kling-v3-omni"`). | COMBO | بله | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | یک درخواست متنی که محتوای ویدیو را توصیف می‌کند. این می‌تواند شامل توضیحات مثبت و منفی باشد. هنگامی که استوری‌بورد فعال باشد نادیده گرفته می‌شود. | STRING | بله | 0 تا 2500 characters |
| `aspect_ratio` | شکل یا ابعاد ویدیوی موردنظر برای تولید. | COMBO | بله | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | مدت‌زمان ویدیو به ثانیه (پیش‌فرض: 5). | INT | بله | 3 تا 15 seconds |
| `resolution` | کیفیت یا وضوح پیکسلی ویدیو (پیش‌فرض: `"1080p"`). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `استوری‌بوردها` | تولید مجموعه‌ای از بخش‌های ویدیویی با درخواست‌ها و مدت‌زمان‌های جداگانه. برای مدل o1 نادیده گرفته می‌شود. | DYNAMIC_COMBO | خیر | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `تولید صدا` | مشخص می‌کند که آیا برای ویدیو صدا تولید شود یا نه (پیش‌فرض: False). | BOOLEAN | خیر | True / False |
| `seed` | سید کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید قطعی نیستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### زیرورودی‌های استوری‌بورد

هنگامی که `storyboards` به مقداری غیر از `"disabled"` تنظیم شود، ورودی‌های زیر برای هر بخش استوری‌بورد ظاهر می‌شوند. در نام پارامترهای زیر، `{i}` شماره بخش است، از 1 تا تعداد استوری‌بورد انتخاب‌شده.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | درخواست برای بخش استوری‌بورد {i}. حداکثر ۵۱۲ کاراکتر. | STRING | بله | 1 تا 512 characters |
| `storyboard_{i}_duration` | مدت‌زمان برای بخش استوری‌بورد {i} به ثانیه (پیش‌فرض: 4). | INT | بله | 1 تا 15 seconds |

### محدودیت‌ها و الزامات پارامترها

- **محدودیت‌های مخصوص مدل:**
  - مدل `kling-video-o1` فقط مدت‌زمان‌های **5 یا 10 ثانیه** را پشتیبانی می‌کند.
  - مدل `kling-video-o1` تولید صدا را **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` وضوح 4k را **پشتیبانی نمی‌کند**.
  - مدل `kling-video-o1` استوری‌بورد را **پشتیبانی نمی‌کند**.
- **محدودیت‌های استوری‌بورد:**
  - هنگامی که استوری‌بورد فعال باشد، فیلد `prompt` نادیده گرفته می‌شود.
  - هر استوری‌بورد به درخواست (1 تا 512 کاراکتر) و مدت‌زمان مخصوص به خود نیاز دارد.
  - مجموع مدت‌زمان همه استوری‌بوردها باید دقیقاً برابر با پارامتر `duration` سراسری باشد.
- **الزامات درخواست:**
  - هنگامی که استوری‌بورد **غیرفعال** باشد، فیلد `prompt` الزامی است (حداقل 1 کاراکتر).
  - هنگامی که استوری‌بورد **فعال** باشد، فیلد `prompt` می‌تواند خالی باشد (0 کاراکتر).
