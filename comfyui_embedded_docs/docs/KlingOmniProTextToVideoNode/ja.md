# Kling Omni テキストからビデオへ (Pro)

このノードは、最新のKling AIモデルを使用して、テキスト記述から動画を生成します。プロンプトをリモートAPIに送信し、生成された動画を返します。このノードでは、動画の長さ、縦横比、品質を制御でき、マルチショットのストーリーボードを作成することもできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 動画生成に使用するKlingモデルを指定します（デフォルト: `"kling-v3-omni"`）。 | COMBO | 必須 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `プロンプト` | 動画の内容を説明するテキストプロンプトです。肯定的な記述と否定的な記述の両方を含めることができます。ストーリーボードが有効な場合は無視されます。 | STRING | 必須 | 0 〜 2500 characters |
| `アスペクト比` | 生成する動画の縦横比です。 | COMBO | 必須 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `継続時間` | 動画の長さ（秒単位）です（デフォルト: 5）。 | INT | 必須 | 3 〜 15 seconds |
| `解像度` | 動画の品質またはピクセル解像度です（デフォルト: `"1080p"`）。 | COMBO | 任意 | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `ストーリーボード` | 個別のプロンプトと長さを持つ一連の動画セグメントを生成します。o1モデルでは無視されます。 | DYNAMIC_COMBO | 任意 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `音声を生成` | 動画のオーディオを生成するかどうか（デフォルト: False）。 | BOOLEAN | 任意 | True / False |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 0）。 | INT | 任意 | 0 〜 2147483647 |

### ストーリーボードのサブ入力

`storyboards` が `"disabled"` 以外の値に設定されている場合、各ストーリーボードセグメントに対して以下の入力が表示されます。以下のパラメータ名では、`{i}` はセグメント番号で、1から選択したストーリーボード数までの値を取ります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | ストーリーボードセグメント {i} のプロンプトです。最大512文字です。 | STRING | 必須 | 1 〜 512 characters |
| `storyboard_{i}_duration` | ストーリーボードセグメント {i} の長さ（秒単位）です（デフォルト: 4）。 | INT | 必須 | 1 〜 15 seconds |

### パラメータの制約と制限

- **モデル固有の制限:**
  - `kling-video-o1` モデルは、**5秒または10秒**の長さのみサポートします。
  - `kling-video-o1` モデルはオーディオ生成をサポート**しません**。
  - `kling-video-o1` モデルは4k解像度をサポート**しません**。
  - `kling-video-o1` モデルはストーリーボードをサポート**しません**。
- **ストーリーボードの制約:**
  - ストーリーボードが有効な場合、`prompt` フィールドは無視されます。
  - 各ストーリーボードには、独自のプロンプト（1〜512文字）と長さが必要です。
  - すべてのストーリーボードの合計時間は、全体の `duration` パラメータと正確に一致する必要があります。
- **プロンプトの要件:**
  - ストーリーボードが**無効**の場合、`prompt` フィールドは必須です（最小1文字）。
  - ストーリーボードが**有効**の場合、`prompt` フィールドは空にできます（0文字）。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 指定されたテキストプロンプトと設定に基づいて生成された動画です。 | VIDEO |
