# Kling Omni Текст в Видео (Pro)

Этот узел использует новейшую модель Kling AI для генерации видео по текстовому описанию. Он отправляет ваш промпт на удалённый API и возвращает сгенерированное видео. Узел позволяет управлять длительностью, формой, качеством видео и даже создавать многосегментные раскадровки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_name` | Конкретная модель Kling для генерации видео (по умолчанию: `"kling-v3-omni"`). | COMBO | Да | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | Текстовый промпт, описывающий содержимое видео. Может включать как положительные, так и отрицательные описания. Игнорируется, когда раскадровки включены. | STRING | Да | от 0 до 2500 символов |
| `aspect_ratio` | Форма или размеры генерируемого видео. | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | Длительность видео в секундах (по умолчанию: 5). | INT | Да | от 3 до 15 секунд |
| `resolution` | Качество или разрешение видео в пикселях (по умолчанию: `"1080p"`). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `storyboards` | Создаёт последовательность видеосегментов с отдельными промптами и длительностями. Игнорируется для модели o1. | DYNAMIC_COMBO | Нет | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `generate_audio` | Определяет, следует ли генерировать аудио для видео (по умолчанию: False). | BOOLEAN | Нет | True / False |
| `seed` | Сид управляет необходимостью повторного запуска узла; результаты недетерминированы независимо от сида (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |

### Под-входы раскадровки

Когда параметр `storyboards` установлен в значение, отличное от `"disabled"`, для каждого сегмента раскадровки появляются следующие входы. В приведённых ниже именах параметров `{i}` — это номер сегмента, от 1 до выбранного количества раскадровок.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | Промпт для сегмента раскадровки {i}. Максимум 512 символов. | STRING | Да | от 1 до 512 символов |
| `storyboard_{i}_duration` | Длительность сегмента раскадровки {i} в секундах (по умолчанию: 4). | INT | Да | от 1 до 15 секунд |

### Ограничения параметров

- **Ограничения, связанные с моделью:**
  - Модель `kling-video-o1` поддерживает только длительность **5 или 10 секунд**.
  - Модель `kling-video-o1` **не** поддерживает генерацию аудио.
  - Модель `kling-video-o1` **не** поддерживает разрешение 4k.
  - Модель `kling-video-o1` **не** поддерживает раскадровки.
- **Ограничения раскадровки:**
  - Когда раскадровки включены, поле `prompt` игнорируется.
  - Каждая раскадровка требует собственный промпт (от 1 до 512 символов) и длительность.
  - Суммарная длительность всех раскадровок должна точно равняться глобальному параметру `duration`.
- **Требования к промпту:**
  - Когда раскадровки **отключены**, поле `prompt` обязательно (минимум 1 символ).
  - Когда раскадровки **включены**, поле `prompt` может быть пустым (0 символов).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Видео, сгенерированное на основе предоставленного текстового промпта и настроек. | VIDEO |
