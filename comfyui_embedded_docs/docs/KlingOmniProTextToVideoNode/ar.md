# Kling Omni من نص إلى فيديو (احترافي)

تُنشئ هذه العقدة مقطع فيديو من وصف نصي باستخدام أحدث نموذج Kling AI. ترسل طلبك إلى واجهة برمجة تطبيقات بعيدة وتعيد الفيديو المُنشأ. يمكنك التحكم في طول الفيديو وشكله وجودته، واختيارياً بناء لوحات قصصية متعددة اللقطات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_name` | نموذج Kling المحدد المستخدم لإنشاء الفيديو (الافتراضي: `"kling-v3-omni"`). | COMBO | نعم | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `prompt` | موجه نصي يصف محتوى الفيديو. يمكن أن يتضمن أوصافاً إيجابية وسلبية. يتم تجاهله عند تمكين اللوحات القصصية. | STRING | نعم | 0 إلى 2500 حرف |
| `aspect_ratio` | شكل أو أبعاد الفيديو المراد إنشاؤه. | COMBO | نعم | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `duration` | طول الفيديو بالثواني (الافتراضي: 5). | INT | نعم | 3 إلى 15 ثانية |
| `resolution` | جودة أو دقة بكسل الفيديو (الافتراضي: `"1080p"`). يُعيَّن داخلياً إلى جودة standard أو pro أو 4k. | COMBO | لا | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `لوحات القصة` | إنشاء سلسلة من مقاطع الفيديو بموجهات ومدد فردية. يتم تجاهله لنموذج o1. | DYNAMIC_COMBO | لا | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `توليد الصوت` | ما إذا كان سيتم إنشاء صوت للفيديو (الافتراضي: False). | BOOLEAN | لا | True / False |
| `البذرة` | تتحكم البذرة في ما إذا كان يجب إعادة تشغيل العقدة؛ النتائج غير حتمية بغض النظر عن البذرة (الافتراضي: 0). | INT | لا | 0 إلى 2147483647 |

### مدخلات القصة المصورة الفرعية

عندما يتم ضبط `storyboards` على قيمة غير `"disabled"`، تظهر المدخلات التالية لكل مقطع قصة مصورة. في أسماء المعاملات أدناه، `{i}` هو رقم المقطع، من 1 حتى عدد القصص المصورة المحدد.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | موجه لمقطع القصة المصورة {i}. الحد الأقصى 512 حرف. | STRING | نعم | 1 إلى 512 حرف |
| `storyboard_{i}_duration` | مدة مقطع القصة المصورة {i} بالثواني (الافتراضي: 4). | INT | نعم | 1 إلى 15 ثانية |

### قيود المعاملات والحدود

- **قيود خاصة بالنموذج:**
  - نموذج `kling-video-o1` يدعم فقط مدد **5 أو 10 ثوانٍ**.
  - نموذج `kling-video-o1` **لا** يدعم إنشاء الصوت.
  - نموذج `kling-video-o1` **لا** يدعم دقة 4k.
  - نموذج `kling-video-o1` **لا** يدعم اللوحات القصصية.
- **قيود اللوحات القصصية:**
  - عند تمكين اللوحات القصصية، يتم تجاهل حقل `prompt`.
  - تتطلب كل لوحة قصصية موجهها الخاص (1 إلى 512 حرفاً) ومدتها.
  - يجب أن تساوي المدة الإجمالية لجميع اللوحات القصصية بالضبط المعامل العام `duration`.
- **متطلبات الموجه:**
  - عند **تعطيل** اللوحات القصصية، يكون حقل `prompt` مطلوباً (1 حرف كحد أدنى).
  - عند **تمكين** اللوحات القصصية، يمكن أن يكون حقل `prompt` فارغاً (0 حرف).
