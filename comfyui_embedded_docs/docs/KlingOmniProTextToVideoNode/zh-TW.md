# Kling Omni 文字轉影片 (Pro)

此節點使用最新的 Kling AI 模型，根據文字描述生成影片。它會將您的提示詞傳送至遠端 API，並回傳生成的影片。此節點可讓您控制影片的長度、形狀、品質，甚至建立多鏡頭故事板。

## 輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 用於影片生成的特定 Kling 模型（預設：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `提示詞` | 描述影片內容的文字提示詞。可包含正向與負向描述。啟用故事板時會被忽略。 | STRING | 是 | 0 至 2500 個字元 |
| `長寬比` | 生成影片的形狀或尺寸。 | COMBO | 是 | `"16:9"`<br>`"9:16"<br>`"1:1"` |
| `時長` | 影片長度（秒）（預設：5）。 | INT | 是 | 3 至 15 秒 |
| `解析度` | 影片的品質或像素解析度（預設：`"1080p"`）。內部會對應至標準、專業或 4k 品質。 | COMBO | 否 | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `分鏡腳本` | 以個別提示詞與長度生成一系列影片片段。`o1` 模型不支援此功能。 | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `產生音訊` | 是否為影片生成音訊（預設：False）。 | BOOLEAN | 否 | True / False |
| `種子` | 種子用於控制節點是否重新執行；無論種子為何，結果皆為非確定性（預設：0）。 | INT | 否 | 0 至 2147483647 |

### 故事板子輸入

當 `storyboards` 設定為 `"disabled"` 以外的值時，每個故事板片段會顯示以下輸入。在下列參數名稱中，`{i}` 代表片段編號，從 1 到所選的故事板數量。

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | 故事板片段 {i} 的提示詞。最多 512 個字元。 | STRING | 是 | 1 至 512 個字元 |
| `storyboard_{i}_duration` | 故事板片段 {i} 的長度（秒）（預設：4）。 | INT | 是 | 1 至 15 秒 |

### 參數限制與約束

- **模型特定限制：**
  - `kling-video-o1` 模型僅支援 **5 秒或 10 秒** 的長度。
  - `kling-video-o1` 模型 **不** 支援音訊生成。
  - `kling-video-o1` 模型 **不** 支援 4k 解析度。
  - `kling-video-o1` 模型 **不** 支援故事板。
- **故事板限制：**
  - 啟用故事板時，`prompt` 欄位會被忽略。
  - 每個故事板都需要自己的提示詞（1 至 512 個字元）與長度。
  - 所有故事板的總長度必須與整體 `duration` 參數完全相等。
- **提示詞要求：**
  - 當故事板 **停用** 時，`prompt` 欄位為必填（至少 1 個字元）。
  - 當故事板 **啟用** 時，`prompt` 欄位可為空白（0 個字元）。
