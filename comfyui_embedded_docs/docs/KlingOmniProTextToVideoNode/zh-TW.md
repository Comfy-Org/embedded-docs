# Kling Omni 文字轉影片 (Pro)

此節點使用最新的 Kling AI 模型，根據文字描述生成影片。它會將您的提示詞傳送至遠端 API，並傳回生成的影片。此節點可讓您控制影片的長度、形狀、品質，甚至可以建立多鏡頭故事板。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 指定用於影片生成的 Kling 模型（預設：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br>`"kling-video-o1"` |
| `提示詞` | 描述影片內容的文字提示詞。可包含正面與負面描述。啟用故事板時會忽略此欄位。 | STRING | 是 | 0 到 2500 個字元 |
| `長寬比` | 要生成之影片的形狀或尺寸比例。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"1:1"` |
| `時長` | 影片的長度（秒）（預設：5）。 | INT | 是 | 3 到 15 秒 |
| `解析度` | 影片的品質或像素解析度（預設：`"1080p"`）。 | COMBO | 否 | `"4k"`<br>`"1080p"`<br>`"720p"` |
| `分鏡腳本` | 生成一系列帶有個別提示詞與長度的影片片段。`o1` 模型會忽略此參數。 | DYNAMIC_COMBO | 否 | `"disabled"`<br>`"1 storyboard"`<br>`"2 storyboards"`<br>`"3 storyboards"`<br>`"4 storyboards"`<br>`"5 storyboards"`<br>`"6 storyboards"` |
| `產生音訊` | 是否要為影片生成音訊（預設：False）。 | BOOLEAN | 否 | True / False |
| `種子` | Seed 控制節點是否應重新執行；無論 seed 為何，結果皆為非確定性（預設：0）。 | INT | 否 | 0 到 2147483647 |

### 故事板子輸入

當 `storyboards` 設定為 `"disabled"` 以外的值時，每個故事板片段會出現下列輸入。在下列參數名稱中，`{i}` 是片段編號，範圍從 1 到所選的故事板數量。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | 故事板片段 {i} 的提示詞。最多 512 個字元。 | STRING | 是 | 1 到 512 個字元 |
| `storyboard_{i}_duration` | 故事板片段 {i} 的長度（秒）（預設：4）。 | INT | 是 | 1 到 15 秒 |

### 參數約束與限制

- **模型特定限制：**
  - `kling-video-o1` 模型僅支援 **5 或 10 秒**的影片長度。
  - `kling-video-o1` 模型**不**支援音訊生成。
  - `kling-video-o1` 模型**不**支援 4k 解析度。
  - `kling-video-o1` 模型**不**支援故事板。
- **故事板限制：**
  - 啟用故事板時，`prompt` 欄位會被忽略。
  - 每個故事板都需要各自的提示詞（1 到 512 個字元）與長度。
  - 所有故事板的總長度必須完全等於全域 `duration` 參數。
- **提示詞需求：**
  - 當故事板**停用**時，`prompt` 欄位為必填（至少 1 個字元）。
  - 當故事板**啟用**時，`prompt` 欄位可以為空（0 個字元）。
