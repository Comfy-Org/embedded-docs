# Wan 3.0 מתמונה לווידאו

הצומת הזה יוצר וידאו מתמונת פריים ראשון באמצעות מודל Wan 3.0. ניתן באופציונליות לספק תמונת פריים אחרון כדי לשלוט באופן שבו הווידאו מסתיים; המודל יוצר אז וידאו שעובר מהפריים הראשון לפריים האחרון.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | בוחר את גרסת מודל Wan 3.0 לשימוש, וקובע אילו הגדרות ספציפיות למודל יוצגו להלן. | DYNAMIC_COMBO | כן | "wan3.0-video"<br>"wan3.0-video-prime" |
| `first_frame` | תמונת הפריים הראשון. נדרשת תמונה אחת בדיוק. | IMAGE | כן | תמונה בודדת |
| `last_frame` | תמונת הפריים האחרון. המודל יוצר וידאו שעובר מהפריים הראשון לפריים האחרון. אופציונלי; אם מסופק, נדרשת תמונה אחת בדיוק. | IMAGE | לא | תמונה בודדת |
| `seed` | ערך seed לשימוש ביצירה (ברירת מחדל: 42). | INT | כן | 0 - 2147483647 |
| `watermark` | האם להוסיף סימן מים שנוצר בבינה מלאכותית לתוצאה (ברירת מחדל: false). | BOOLEAN | כן | true<br>false |

### קלטים של wan3.0-video ו-wan3.0-video-prime

הגדרות אלה, הספציפיות למודל, משותפות לשתי אפשרויות המודל ומופיעות כאשר נבחר מודל.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט המתאר את האלמנטים והמאפיינים החזותיים. תומך באנגלית ובסינית. ניתן להשאיר ריק (ברירת מחדל: ריק). | STRING | כן | עד 20,000 תווים |
| `resolution` | רזולוציית וידאו הפלט. | COMBO | כן | "1080P"<br>"720P"<br>"480P" |
| `ratio` | יחס הממדים של וידאו הפלט. עם "adaptive", ממדי הפלט נגזרים מהפריים הראשון. | COMBO | כן | "adaptive"<br>"16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | משך וידאו הפלט בשניות. עם "auto", המודל בוחר משך שמתאים לפרומפט. | COMBO | כן | "auto"<br>"2" - "30" |
| `audio` | האם וידאו הפלט מכיל רצועת אודיו (ברירת מחדל: true). | BOOLEAN | כן | true<br>false |
| `prompt_extend` | האם לשפר את הפרומפט בעזרת AI (ברירת מחדל: true). | BOOLEAN | כן | true<br>false |

הערה: הצומת מקבל תמונת `first_frame` אחת בדיוק, ובאופן אופציונלי תמונת `last_frame` אחת. אם מחוברת יותר מתמונה אחת לאחד הקלטים, תיווצר שגיאה. כאשר מסופק `last_frame`, הווידאו שנוצר עובר מהפריים הראשון לפריים האחרון. ה-`prompt` מוגבל ל-20,000 תווים. מחיר הרצה תלוי ב-`model`, `resolution` ו-`duration` הנבחרים.
