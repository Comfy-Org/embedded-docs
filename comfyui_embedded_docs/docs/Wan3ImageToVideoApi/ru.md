# Wan 3.0: из изображения в видео

Этот узел создает видео из изображения первого кадра с использованием модели Wan 3.0. Вы можете дополнительно указать изображение последнего кадра, чтобы управлять окончанием видео; модель создаст видео, которое переходит от первого кадра к последнему.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Выбирает вариант модели Wan 3.0 для использования и определяет, какие настройки, специфичные для модели, отображаются ниже. | DYNAMIC_COMBO | Да | "wan3.0-video"<br>"wan3.0-video-prime" |
| `first_frame` | Изображение первого кадра. Требуется ровно одно изображение. | IMAGE | Да | Одно изображение |
| `last_frame` | Изображение последнего кадра. Модель генерирует видео с переходом от первого кадра к последнему. Необязательно; если указано, требуется ровно одно изображение. | IMAGE | Нет | Одно изображение |
| `seed` | Сид для генерации (по умолчанию: 42). | INT | Да | 0 - 2147483647 |
| `watermark` | Добавлять ли AI-сгенерированный водяной знак к результату (по умолчанию: false). | BOOLEAN | Да | true<br>false |

### Входы wan3.0-video и wan3.0-video-prime

Эти настройки, специфичные для модели, являются общими для обоих вариантов модели и появляются при выборе модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. Может быть пустым (по умолчанию: пусто). | STRING | Да | До 20000 символов |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "1080P"<br>"720P"<br>"480P" |
| `ratio` | Соотношение сторон выходного видео. При значении "adaptive" размеры выходного видео определяются по первому кадру. | COMBO | Да | "adaptive"<br>"16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | Продолжительность выходного видео в секундах. При значении "auto" модель выбирает продолжительность, соответствующую промпту. | COMBO | Да | "auto"<br>"2" - "30" |
| `audio` | Содержит ли выходное видео аудиодорожку (по умолчанию: true). | BOOLEAN | Да | true<br>false |
| `prompt_extend` | Улучшать ли промпт с помощью ИИ (по умолчанию: true). | BOOLEAN | Да | true<br>false |

Примечание: Узел принимает ровно одно изображение `first_frame` и, опционально, одно изображение `last_frame`. Если к любому из входов подключено более одного изображения, возникает ошибка. При наличии `last_frame` сгенерированное видео переходит от первого кадра к последнему. `prompt` ограничен 20 000 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео. Содержит аудиодорожку при включенной опции `audio`. | VIDEO |
