# Wan 3.0: из изображения в видео

Этот узел генерирует видео из изображения первого кадра с помощью модели Wan 3.0. При необходимости можно указать изображение последнего кадра, чтобы контролировать, как видео закончится; тогда модель создаст видео с переходом от первого кадра к последнему.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Выбирает вариант модели Wan 3.0 для использования и определяет, какие настройки, специфичные для модели, будут показаны ниже. | DYNAMIC_COMBO | Да | "wan3.0-video"<br>"wan3.0-video-prime" |
| `first_frame` | Изображение первого кадра. Требуется ровно одно изображение. | IMAGE | Да | Одно изображение |
| `last_frame` | Изображение последнего кадра. Модель генерирует видео с переходом от первого кадра к последнему. Необязательный параметр; если указан, требуется ровно одно изображение. | IMAGE | Нет | Одно изображение |
| `seed` | Сид, используемый для генерации (по умолчанию: 42). | INT | Да | 0 - 2147483647 |
| `watermark` | Добавлять ли к результату водяной знак, сгенерированный ИИ (по умолчанию: false). | BOOLEAN | Да | true<br>false |

### Входы wan3.0-video и wan3.0-video-prime

Эти настройки, специфичные для модели, являются общими для обоих вариантов модели и появляются при выборе модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий элементы и визуальные характеристики. Поддерживает английский и китайский языки. Можно оставить пустым (по умолчанию: пусто). | STRING | Да | До 20 000 символов |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "1080P"<br>"720P"<br>"480P" |
| `ratio` | Соотношение сторон выходного видео. При значении "adaptive" размеры вывода определяются по первому кадру. | COMBO | Да | "adaptive"<br>"16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | Длительность выходного видео в секундах. При значении "auto" модель выбирает длительность, соответствующую промпту. | COMBO | Да | "auto"<br>"2" - "30" |
| `audio` | Содержит ли выходное видео звуковую дорожку (по умолчанию: true). | BOOLEAN | Да | true<br>false |
| `prompt_extend` | Улучшать ли промпт с помощью ИИ (по умолчанию: true). | BOOLEAN | Да | true<br>false |

Примечание: Узел принимает ровно одно изображение `first_frame` и, необязательно, одно изображение `last_frame`. Если к любому из этих входов подключено более одного изображения, возникает ошибка. Если указан `last_frame`, сгенерированное видео выполняет переход от первого кадра к последнему. `prompt` ограничен 20 000 символов. Стоимость запуска зависит от выбранных `model`, `resolution` и `duration`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео. Содержит звуковую дорожку, когда включена опция `audio`. | VIDEO |
