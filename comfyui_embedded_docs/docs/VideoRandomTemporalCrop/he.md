# VideoRandomTemporalCrop

חיתוך אקראי של טווח רציף של פריימים מווידאו קלט. מספר הפריימים שיישמרו נקבע על ידי הפרמטר `length`, ומיקום ההתחלה נבחר באקראי באמצעות הפרמטר `seed`. הצומת פועל באופן עצל, כלומר הוא אינו מעבד את כל הווידאו עד שהפלט משמש בצמתים בהמשך.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `video` | וידאו קלט. | VIDEO | כן | – |
| `length` | מספר הפריימים שיישמרו. אם `length` גדול ממספר הפריימים הכולל בווידאו, כל הווידאו יישמר. (ברירת מחדל: 16) | INT | כן | min: 1, max: 99999 |
| `seed` | זרע אקראי. (ברירת מחדל: 0) | INT | כן | min: 0, max: 0xFFFFFFFFFFFFFFFF |
