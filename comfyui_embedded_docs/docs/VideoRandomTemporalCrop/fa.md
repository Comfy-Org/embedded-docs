# برش تصادفی زمانی ویدیو

یک بازه پیوسته از فریم‌ها را به‌طور تصادفی از ویدیوی ورودی برش می‌دهد. تعداد فریم‌هایی که باید نگه داشته شوند توسط پارامتر `length` تنظیم می‌شود و موقعیت شروع با استفاده از پارامتر `seed` به‌طور تصادفی انتخاب می‌شود. این گره به‌صورت تنبل کار می‌کند، به این معنی که تا زمانی که خروجی در پایین‌دست استفاده نشود، کل ویدیو را پردازش نمی‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `ویدیو` | ویدیوی ورودی. | VIDEO | بله | – |
| `طول` | تعداد فریم‌هایی که باید نگه داشته شوند. اگر `تعداد فریم‌ها` بزرگ‌تر از تعداد کل فریم‌های ویدیو باشد، کل ویدیو نگه داشته می‌شود. (پیش‌فرض: ۱۶) | INT | بله | حداقل: ۱، حداکثر: ۹۹۹۹۹ |
| `seed` | seed تصادفی. (پیش‌فرض: 0) | INT | بله | min: 0, max: 0xFFFFFFFFFFFFFFFF |
