# Обрезка видео (случайная по времени)

---

Случайное обрезание непрерывного диапазона кадров из входного видео. Длина обрезки управляется параметром `length`, а начальная позиция выбирается с помощью случайного зерна. Узел работает лениво, то есть не обрабатывает всё видео до тех пор, пока выходные данные не будут использованы далее по цепочке.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Входное видео. | VIDEO | Да | – |
| `длина` | Количество кадров для сохранения. (по умолчанию: 16) | INT | Да | min: 1, max: 99999 |
| `seed` | Случайное зерно. (по умолчанию: 0) | INT | Да | min: 0, max: 0xFFFFFFFFFFFFFFFF |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `видео` | Обрезанное видео (ленивое). | VIDEO |
