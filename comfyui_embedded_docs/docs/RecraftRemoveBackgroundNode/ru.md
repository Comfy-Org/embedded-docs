# Recraft Remove Background

Этот узел удаляет фон с изображений с помощью сервиса Recraft API. Он обрабатывает каждое изображение из входного пакета и возвращает как обработанные изображения с прозрачным фоном, так и соответствующие альфа-маски, указывающие на удалённые области фона.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение(я) для удаления фона | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Обработанные изображения с прозрачным фоном | IMAGE |
| `mask` | Альфа-маски, указывающие на удалённые области фона | MASK |
