# Recraft Remove Background

Этот узел удаляет фон с изображений с помощью сервиса Recraft API. Он обрабатывает каждое изображение во входном пакете и возвращает как обработанные изображения с прозрачным фоном, так и соответствующие альфа-маски, которые указывают на удаленные области фона.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|----------|----------|------------|----------------|----------|
| `изображение` | Входное изображение(я) для удаления фона. Каждое изображение в пакете обрабатывается индивидуально. | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Обработанные изображения с прозрачным фоном (формат RGBA) | IMAGE |
| `mask` | Альфа-маски, указывающие на удаленные области фона, в формате B,H,W | MASK |
