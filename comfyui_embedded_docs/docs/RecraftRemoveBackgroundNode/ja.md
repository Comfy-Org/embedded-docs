# Recraft 背景除去

このノードは、Recraft API サービスを使用して画像から背景を削除します。入力バッチ内の各画像を処理し、透明な背景を持つ処理済みの画像と、削除された背景領域を示す対応するアルファマスクの両方を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 背景除去の対象となる入力画像 | IMAGE | Yes | - |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 透明な背景を持つ処理済み画像 | IMAGE |
| `mask` | 削除された背景領域を示すアルファチャンネルマスク | MASK |
