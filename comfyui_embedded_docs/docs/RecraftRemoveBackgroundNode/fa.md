# حذف پس‌زمینه Recraft

این گره پس‌زمینه تصاویر را با استفاده از سرویس API «Recraft» حذف می‌کند. هر تصویر در دسته ورودی را به‌صورت جداگانه پردازش کرده و هم تصاویر پردازش‌شده با پس‌زمینه شفاف و هم ماسک‌های آلفای متناظر را که نواحی حذف‌شده پس‌زمینه را نشان می‌دهند، بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر(های) ورودی برای پردازش حذف پس‌زمینه. هر تصویر در دسته به‌صورت جداگانه پردازش می‌شود. | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصاویر پردازش‌شده با پس‌زمینه شفاف (فرمت RGBA) | IMAGE |
| `mask` | ماسک‌های کانال آلفا که نواحی حذف‌شده پس‌زمینه را نشان می‌دهند، در قالب B,H,W | MASK |
