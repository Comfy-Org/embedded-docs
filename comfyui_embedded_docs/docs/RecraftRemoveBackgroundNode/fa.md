# حذف پس‌زمینه Recraft

این گره با استفاده از سرویس API رِکرفت، پس‌زمینه تصاویر را حذف می‌کند. هر تصویر را در دسته ورودی پردازش کرده و هم تصاویر پردازش‌شده با پس‌زمینه شفاف و هم ماسک‌های آلفای متناظر را که نواحی حذف‌شده پس‌زمینه را نشان می‌دهند، برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر(های) ورودی برای حذف پس‌زمینه | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `image` | تصاویر پردازش‌شده با پس‌زمینه شفاف | IMAGE |
| `mask` | ماسک‌های کانال آلفا که نواحی حذف‌شده پس‌زمینه را نشان می‌دهند | MASK |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/RecraftRemoveBackgroundNode/fa.md)
