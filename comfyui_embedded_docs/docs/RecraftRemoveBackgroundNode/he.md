# RecraftRemoveBackgroundNode

צומת זה מסיר את הרקע מתמונות באמצעות שירות Recraft API. הוא מעבד כל תמונה באצוות הקלט בנפרד ומחזיר גם את התמונות המעובדות עם רקע שקוף וגם מסכות אלפא מתאימות שמציינות את אזורי הרקע שהוסרו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת/תמונות הקלט שיש לעבד להסרת רקע. כל תמונה באצווה מעובדת בנפרד. | IMAGE | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `image` | תמונות מעובדות עם רקע שקוף (פורמט RGBA) | IMAGE |
| `mask` | מסכות ערוץ אלפא שמציינות את אזורי הרקע שהוסרו, בפורמט B,H,W | MASK |
