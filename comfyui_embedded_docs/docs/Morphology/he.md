# החלת מורפולוגיה

צומת Morphology מחיל פעולות מורפולוגיות שונות על תמונות, שהן פעולות מתמטיות המשמשות לעיבוד וניתוח צורות בתמונות. הוא יכול לבצע פעולות כמו שחיקה, הרחבה, פתיחה, סגירה ועוד, תוך שימוש בגודל קרנל הניתן להתאמה לשליטה בעוצמת ההשפעה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `image` | תמונת הקלט לעיבוד | IMAGE | כן | - |
| `operation` | הפעולה המורפולוגית להחלה (ברירת מחדל: "erode") | STRING | כן | `"erode"`<br>`"dilate"`<br>`"open"`<br>`"close"`<br>`"gradient"`<br>`"bottom_hat"`<br>`"top_hat"` |
| `kernel_size` | גודל הקרנל של רכיב המבנה (ברירת מחדל: 3). חייב להיות מספר אי-זוגי. | INT | כן | 3-999 |
