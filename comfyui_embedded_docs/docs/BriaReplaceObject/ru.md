# BriaReplaceObject

Заменяет объект на изображении на другой, описанный обычным текстом, используя управляемое текстом редактирование изображений от Bria. Bria полностью перерисовывает кадр примерно на 1 мегапикселе, поэтому результат не совпадает попиксельно с входным изображением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Изображение, содержащее объект для замены. Альфа-канал отбрасывается перед загрузкой изображения. | IMAGE | Да | - |
| `инструкция` | Что на что заменить, например: «Замените красное яблоко на зелёную грушу». Длина должна быть не менее 1 символа. | STRING | Да | Многострочный текст; по умолчанию: "" (пусто) |
| `сид` | Bria не принимает seed здесь и заново придумывает редактирование при каждом вызове, поэтому повторные запуски могут отличаться. Значение никогда не отправляется: оно только изменяет ключ кэша этого узла, чтобы в остальном идентичный граф выполнил редактирование снова вместо возврата кэшированного результата. | INT | Да | от 0 до 2147483647, шаг 1; по умолчанию: 42; управление после генерации включено |

### Входы модерации

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модерация` | Настройки модерации. Выбор "true" показывает подпараметры модерации ниже, которые в противном случае не отображаются. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |
| `visual_input_moderation` | Включает модерацию входного изображения. Доступно только когда `moderation` установлен в "true". | BOOLEAN | Нет | `true` / `false`; по умолчанию: false |
| `visual_output_moderation` | Включает модерацию сгенерированного выходного изображения. Доступно только когда `moderation` установлен в "true". | BOOLEAN | Нет | `true` / `false`; по умолчанию: false |

Примечание: `instruction` проверяется перед отправкой запроса и должен содержать не менее 1 символа. Значение `seed` не передаётся в Bria; оно влияет только на то, повторно ли узел выполняет редактирование или возвращает кэшированный результат.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отредактированное изображение с применённой описанной заменой объекта. | IMAGE |
| `structured_prompt` | Структурированное описание отредактированного изображения для последующего редактирования с помощью Bria FIBO Image Edit. | STRING |
