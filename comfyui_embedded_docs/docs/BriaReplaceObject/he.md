# BriaReplaceObject

מחליף אובייקט בתמונה באובייקט אחר המתואר בטקסט חופשי, באמצעות עריכת תמונה מונחית טקסט של Bria. Bria מרנדרת מחדש את כל הפריים ברזולוציה של כמיגה-פיקסל אחד, כך שהתוצאה אינה מיושרת פיקסל-אל-פיקסל עם הקלט.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | התמונה המכילה את האובייקט שיש להחליף. ערוץ האלפא מושמט לפני העלאת התמונה. | IMAGE | כן | - |
| `instruction` | מה להחליף ובמה, כגון "החלף את התפוח האדום באגס ירוק". חייב להיות באורך של תו אחד לפחות. | STRING | כן | טקסט רב-שורתי; ברירת מחדל: "" (ריק) |
| `seed` | Bria אינה מקבלת seed כאן ומדמיינת מחדש את העריכה בכל קריאה, כך שהרצות חוזרות עשויות להיות שונות. הערך לעולם אינו נשלח: הוא רק משנה את מפתח המטמון של הצומת, כך שגרף זהה אחרת מריץ את העריכה שוב במקום להחזיר את התוצאה השמורה במטמון. | INT | כן | 0 עד 2147483647, צעד 1; ברירת מחדל: 42; שליטה לאחר יצירה מופעלת |

### קלטי מודרציה

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `moderation` | הגדרות מודרציה. בחירת "true" חושפת את תת-האפשרויות של מודרציה שלהלן, שאחרת אינן מוצגות. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |
| `visual_input_moderation` | מפעיל מודרציה של תמונת הקלט. זמין רק כאשר `moderation` מוגדר ל-"true". | BOOLEAN | לא | `true` / `false`; ברירת מחדל: false |
| `visual_output_moderation` | מפעיל מודרציה של תמונת הפלט שנוצרה. זמין רק כאשר `moderation` מוגדר ל-"true". | BOOLEAN | לא | `true` / `false`; ברירת מחדל: false |

הערה: `instruction` נבדק לפני שליחת הבקשה וחייב להכיל לפחות תו אחד. ערך `seed` אינו נשלח אל Bria; הוא משפיע רק על האם הצומת מריץ מחדש את העריכה או מחזיר תוצאה שמורה במטמון.

## פלטים

| שם פלט | תיאור | סוג נתונים |
