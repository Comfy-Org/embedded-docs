# Создать файл 3D-анимации

Этот узел создает готовый к сохранению файл 3D-анимации из данных позы. Вы можете экспортировать анимированный GLB в нескольких визуальных стилях — полная сетка тела, предпросмотр только суставов, скелет OpenPose или капсульный риг SCAIL, — или вместо этого сохранить клип захвата движения BVH. Выходной результат подключается к узлу сохранения файла, например Save 3D Model, для записи файла на диск.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pose_data` | Данные 3D-позы. Принимает данные позы MHR (параметры модели/формы/выражения, ключевые точки MHR70, канонические цвета, маска вершин кистей) или данные позы Kimodo (внешний риг с осью Y вверх, с попреждественно предсказанными вершинами и камерой). | MHR_POSE_DATA / KIMODO_POSE_DATA | Да | — |
| `format` | Выходной формат, который также передается в Save 3D Model для записи на диск. 'glb' = анимированный GLB (mesh / bones / openpose / scail). 'bvh' = клип захвата движения BVH (один скелет; требуется модель). (по умолчанию: glb) | DYNAMIC_COMBO | Да | "glb"<br>"bvh" |
| `sam3d_body_model` | Необязательная модель тела SAM3D. Требуется для форматов 'bvh', 'body_mesh' и 'bones_only', если только данные позы не содержат переопределение скелета. | SAM3D_BODY_MODEL | Нет | — |
| `fps` | Частота кадров анимации. (по умолчанию: 24.0) | FLOAT | Да | 1.0-240.0 |
| `camera_translation` | Встраивать pred_cam_t в трансляцию корня: 'off' = базовая позиция; 'centered' = дельта от кадра 0; 'absolute' = сырое значение (Z — глубина камеры, обычно расстояние в метрах). (по умолчанию: off) | COMBO | Да | "off"<br>"centered"<br>"absolute" |
| `track_index` | Выбор дорожки: -1 = все дорожки; ≥0 = одна дорожка. (по умолчанию: -1) | INT | Да | -от 1 до 15 |

### Входы GLB

Эти входы появляются, когда `format` установлен в "glb".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh_style` | Визуальный стиль GLB: 'body_mesh' = настоящая арматура (127 костей, скиннинг, TRS-ключевые кадры, 72 лицевых морфа; требуется модель). 'bones_only' = примитивы формы костей в каждом суставе (предпросмотр арматуры). 'openpose' = 3D-скелет OpenPose-18 из ключевых точек. 'scail' = капсульный риг SCAIL (открытые цилиндры, закрытые заподлицо сферическими суставами). (по умолчанию: body_mesh) | DYNAMIC_COMBO | Да | "body_mesh"<br>"bones_only"<br>"openpose"<br>"scail" |
| `bone_smooth_window` | Окно гауссова сглаживания для ключевых кадров вращения каждой кости / дорожек ключевых точек. 0 = выкл. 7-15 успокаивает вращения/дрожание, когда вышестоящий Smooth пропускает пики. (по умолчанию: 0) | INT | Да | 0-51, step 2 |

#### Входы Body Mesh

Появляются, когда `mesh_style` установлен в "body_mesh".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `bone_vis` | Форма визуализации костей, жестко привязанная к каждому суставу. 'off' = без визуализации костей; 'octahedrons' = направленные кости в стиле Blender. (по умолчанию: off) | DYNAMIC_COMBO | Да | "off"<br>"octahedrons" |
| `bone_vis_radius_m` | Появляется, когда `bone_vis` = "octahedrons". Радиус в метрах (радиус сферы / полуширина октаэдра). (по умолчанию: 0.02) | FLOAT | Да | 0.005-0.5 |
| `bone_vis_color` | Появляется, когда `bone_vis` = "octahedrons". Цвета вершин для каждой кости (материал без освещения). 'white' = нет, 'rainbow_y' = градиент от головы до ног. (по умолчанию: rainbow_y) | COMBO | Да | "white"<br>"rainbow_y" |
| `shader` | Запекать цвета вершин, соответствующие шейдерам узла Render (COLOR_0 + KHR_materials_unlit). 'default' = без цветов. (по умолчанию: default) | DYNAMIC_COMBO | Да | "default"<br>"rainbow"<br>"rainbow_face_normal"<br>"rainbow_face_semantic" |
| `rainbow_tilt_z` | Появляется, когда `shader` является вариантом rainbow. Поворачивает ось градиента вокруг Z (вперед). Различает лево/право. (по умолчанию: -35.0) | FLOAT | Да | -от 90.0 до 90.0 |
| `rainbow_tilt_x` | Появляется, когда `shader` является вариантом rainbow. Поворачивает ось градиента вокруг X (вправо). Различает перед/зад. (по умолчанию: 0.0) | FLOAT | Да | -от 90.0 до 90.0 |
| `person_palette_falloff` | Появляется, когда `shader` является вариантом rainbow. Десатурация на человека: каждая дорожка получает пастельную смесь (1 - falloff^k). (по умолчанию: 0.6) | FLOAT | Да | 0.1-1.0 |

| Параметр | Описание | Тип данных | Обязательный | Диапазон |

| `bone_vis_radius_m` | Радиус в метрах (радиус сферы / полуширина октаэдра). (по умолчанию: 0.02) | FLOAT | Да | 0.005-0.5 |

|-----------|-------------|-----------|----------|-------|
| `marker_radius_m` | Радиус сферы в метрах. (по умолчанию: 0.010) | FLOAT | Да | 0.005-0.1 |

#### Входы SCAIL

Появляются, когда `mesh_style` установлен в "scail".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `stick_radius_m` | Радиус цилиндра в метрах. Кости представляют собой открытые цилиндры постоянного радиуса; сферические суставы (автоматически подогнанные по размеру) закрывают открытые концы. Эталон SCAIL = 0.0215 м. (по умолчанию: 0.022) | FLOAT | Да | 0.002-0.1 |
| `marker_radius_m` | Радиус сферы сустава. 0 = авто = stick_radius_m (закрытие заподлицо). (по умолчанию: 0.0) | FLOAT | Да | 0.0-0.1 |
| `material_roughness` | Шероховатость PBR. Эталон SCAIL = 0.3. 1 = матовая; 0 = хром. (по умолчанию: 0.3) | FLOAT | Да | 0.0-1.0 |
| `include_hands` | Добавить 21+21 ключевую точку кистей + капсульные палочки для каждой дорожки. (по умолчанию: False) | BOOLEAN | Да | True / False |
| `hand_marker_radius_m` | Радиус сферы кисти в метрах. (по умолчанию: 0.005) | FLOAT | Да | 0.001-0.05 |
| `hand_stick_radius_m` | Радиус цилиндра кисти в метрах. (по умолчанию: 0.003) | FLOAT | Да | 0.001-0.05 |
| `face_style` | Ориентиры контура лица, сэмплированные из pred_vertices (требует canonical_colors в pose_data). 'full' = все ~30 точек; 'eyes_mouth' = только глаза и внешние губы. (по умолчанию: disabled) | COMBO | Да | "disabled"<br>"full"<br>"eyes_mouth" |

### Входы BVH

Появляются, когда `format` установлен в "bvh".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `units` | Единицы измерения OFFSET/позиции BVH. 'cm' — стандарт захвата движения. (по умолчанию: cm) | COMBO | Да | "cm"<br>"m" |

**Примечания:**

- Формат `bvh` и стили mesh `body_mesh` и `bones_only` требуют входного параметра `sam3d_body_model`, если только сами данные `pose_data` не содержат переопределение скелета (словарь `_skeleton_override`, например из узла KimodoSample). Узел вызывает ошибку, если ни того, ни другого нет. Стили `openpose` и `scail` не зависят от рига и работают напрямую с ключевыми точками без модели тела.
- В формате `bvh` выходные данные содержат один скелет. Когда `track_index` равен -1 (все дорожки), используется первая дорожка.
- Опции `full` и `eyes_mouth` в параметре `face_style` требуют наличия `canonical_colors` в данных позы; они присутствуют, когда данные позы получены из конвейера MHR вместе с моделью тела.
- `bone_smooth_window` изменяется с шагом 2 в диапазоне от 0 до 51.
