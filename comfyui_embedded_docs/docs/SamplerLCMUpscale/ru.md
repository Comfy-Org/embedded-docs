# Сэмплер LCM Upscale

Узел SamplerLCMUpscale предоставляет специализированный метод сэмплирования, который сочетает сэмплирование Latent Consistency Model (LCM) с возможностями масштабирования изображения. Он позволяет масштабировать изображения в процессе сэмплирования с использованием различных методов интерполяции, что делает его полезным для создания результатов с более высоким разрешением при сохранении качества изображения. Масштабирование применяется постепенно на протяжении шагов сэмплирования до достижения целевого значения `scale_ratio`.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `scale_ratio` | Коэффициент масштабирования, применяемый при увеличении разрешения (по умолчанию: 1.0) | FLOAT | Нет | 0.1 - 20.0 |
| `scale_steps` | Количество шагов для процесса масштабирования. Используйте -1 для автоматического расчета (по умолчанию: -1) | INT | Нет | -1 - 1000 |
| `upscale_method` | Метод интерполяции, используемый для масштабирования изображения (по умолчанию: bislerp) | COMBO | Да | "bislerp"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bicubic" |

Примечание: Когда для `scale_steps` задано положительное значение, фактическое количество шагов масштабирования ограничено общим количеством шагов сэмплирования сэмплера.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера, который можно использовать в конвейере сэмплирования | SAMPLER |
