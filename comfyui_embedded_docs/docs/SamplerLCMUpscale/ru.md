# Сэмплер LCM Upscale

Этот узел предоставляет специализированный метод сэмплирования, который сочетает сэмплирование Latent Consistency Model (LCM) с прогрессивным увеличением изображения. Во время сэмплирования изображение шаг за шагом увеличивается к целевому коэффициенту масштабирования с использованием выбранного метода интерполяции, что позволяет получать результаты более высокого разрешения за один проход сэмплирования. Узел выводит настроенный объект сэмплера, который можно подключить к узлу сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `коэффициент_масштабирования` | Общий коэффициент масштабирования, применяемый при апскейлинге. Значение 1.0 сохраняет исходное разрешение (по умолчанию: 1.0) | FLOAT | Да | 0.1 - 20.0 |
| `шаги_масштабирования` | Количество шагов, используемых для процесса апскейлинга. Используйте -1 для автоматического расчёта на основе расписания сэмплирования (по умолчанию: -1) | INT | Да | -1 - 1000 |
| `метод_масштабирования` | Метод интерполяции, используемый для увеличения изображения на каждом шаге апскейлинга (по умолчанию: "bislerp") | COMBO | Да | "bislerp"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bicubic" |

`scale_ratio` и `scale_steps` — это расширенные параметры. Изображение постепенно увеличивается от исходного размера до целевого `scale_ratio` в течение шагов апскейлинга. Когда `scale_steps` равно -1, количество шагов апскейлинга рассчитывается автоматически как примерно половина количества шагов сэмплирования, но не менее 2; если указано положительное значение, узел корректирует его внутренне и ограничивает на основе общего количества шагов сэмплирования.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, выполняющий сэмплирование LCM с прогрессивным апскейлингом, готовый к использованию в конвейере сэмплирования | SAMPLER |
