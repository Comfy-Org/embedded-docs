# Сэмплер LCM Upscale

Узел SamplerLCMUpscale предоставляет специализированный метод сэмплирования, который сочетает сэмплирование Latent Consistency Model (LCM) с возможностями масштабирования изображения. В процессе сэмплирования изображение постепенно увеличивается с использованием различных методов интерполяции, что позволяет получать выходные данные более высокого разрешения за один проход сэмплирования. Результатом работы узла является настроенный объект сэмплера, который можно подключить к узлу сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `коэффициент_масштабирования` | Общий коэффициент масштабирования, применяемый при увеличении. Значение 1.0 сохраняет исходное разрешение (по умолчанию: 1.0) | FLOAT | Да | 0.1 - 20.0 |
| `шаги_масштабирования` | Количество шагов, используемых в процессе масштабирования. Используйте -1 для автоматического расчета на основе расписания сэмплирования (по умолчанию: -1) | INT | Да | -1 - 1000 |
| `метод_масштабирования` | Метод интерполяции, используемый для масштабирования изображения на каждом шаге масштабирования (по умолчанию: "bislerp") | COMBO | Да | "bislerp"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bicubic" |

`scale_ratio` и `scale_steps` являются расширенными параметрами. Изображение постепенно масштабируется от исходного размера до целевого значения `scale_ratio` в течение шагов масштабирования. Когда `scale_steps` равно -1, количество шагов масштабирования вычисляется автоматически как примерно половина количества шагов сэмплирования, с минимумом 2; если задано положительное значение, узел корректирует его внутренне и ограничивает на основе общего количества шагов сэмплирования.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера, который выполняет сэмплирование LCM с прогрессивным масштабированием и готов к использованию в конвейере сэмплирования | SAMPLER |
