# サンプラーLCM拡大

SamplerLCMUpscale ノードは、潜在整合性モデル（LCM）サンプリングと画像アップスケーリング機能を組み合わせた特殊なサンプリング手法を提供します。このノードを使用すると、サンプリングプロセス中にさまざまな補間メソッドを使用して画像をアップスケールでき、画質を維持しながら高解像度の出力を生成するのに役立ちます。アップスケーリングは、ターゲットの `scale_ratio` に到達するまでサンプリングステップ全体にわたって段階的に適用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `scale_ratio` | アップスケーリング中に適用するスケーリング係数（デフォルト: 1.0） | FLOAT | いいえ | 0.1 - 20.0 |
| `scale_steps` | アップスケーリングプロセスに使用するステップ数。自動計算の場合は -1 を使用します（デフォルト: -1） | INT | いいえ | -1 - 1000 |
| `upscale_method` | 画像のアップスケーリングに使用する補間メソッド（デフォルト: bislerp） | COMBO | はい | "bislerp"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bicubic" |

注: `scale_steps` に正の値を設定した場合、実際のアップスケーリングステップ数はサンプラーの総サンプリングステップ数によって制限されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `sampler` | サンプリングパイプラインで使用できる設定済みのサンプラーオブジェクトを返します | SAMPLER |
