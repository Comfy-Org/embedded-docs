# SamplerLCMUpscale

گره `SamplerLCMUpscale` یک روش نمونه‌برداری تخصصی ارائه می‌دهد که نمونه‌برداری مدل سازگاری نهفته (LCM) را با قابلیت‌های بزرگ‌نمایی تصویر ترکیب می‌کند. این گره به شما امکان می‌دهد در طول فرآیند نمونه‌برداری با استفاده از روش‌های مختلف درون‌یابی، تصاویر را بزرگ‌نمایی کنید و برای تولید خروجی‌هایی با وضوح بالاتر در عین حفظ کیفیت تصویر مفید است. بزرگ‌نمایی به‌تدریج در طول مراحل نمونه‌برداری اعمال می‌شود تا به `scale_ratio` هدف برسد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `scale_ratio` | ضریب مقیاسی که در طول بزرگ‌نمایی اعمال می‌شود (پیش‌فرض: 1.0) | FLOAT | خیر | 0.1 - 20.0 |
| `scale_steps` | تعداد مراحل مورد استفاده برای فرآیند بزرگ‌نمایی. برای محاسبه خودکار از -1 استفاده کنید (پیش‌فرض: -1) | INT | خیر | -1 - 1000 |
| `upscale_method` | روش درون‌یابی مورد استفاده برای بزرگ‌نمایی تصویر (پیش‌فرض: bislerp) | COMBO | بله | "bislerp"<br>"nearest-exact"<br>"bilinear"<br>"area"<br>"bicubic" |

توجه: هنگامی که `scale_steps` روی یک مقدار مثبت تنظیم شود، تعداد مؤثر مراحل بزرگ‌نمایی به تعداد کل مراحل نمونه‌برداری محدود می‌شود.
