# MoGe Point Map to Mesh

Этот узел преобразует карту точек MoGe в трёхмерную сетку. Он берёт данные геометрии, созданные узлом оценки глубины MoGe, и выполняет триангуляцию в сетку с UV-координатами и необязательной текстурой.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_geometry` | Данные геометрии MoGe, содержащие карты точек, глубину и, опционально, исходное изображение. | MOGE_GEOMETRY | Да | N/A |
| `batch_index` | Какое изображение из пакетной геометрии MoGe преобразовывать в сетку. Количество вершин для каждого изображения различается, поэтому пакеты нельзя объединить в одну сетку MESH (по умолчанию: 0). | INT | Да | 0 до 4096 |
| `decimation` | Шаг вершин; 1 = полное разрешение (по умолчанию: 1). | INT | Да | 1 до 8 |
| `discontinuity_threshold` | Отбрасывать пиксели, чей разброс глубины в окрестности 3x3 превышает эту долю. 0 = выключено (по умолчанию: 0.04). | FLOAT | Да | 0.0 до 1.0 |
| `texture` | Переносить исходное изображение как текстуру baseColor (по умолчанию: True). | BOOLEAN | Да | True/False |

Примечание: `batch_index` должен быть меньше размера пакета входного `moge_geometry`; выбор индекса вне допустимого диапазона приводит к ошибке. Если в результате триангуляции получается пустая сетка, узел вызывает ошибку — установка `discontinuity_threshold` в 0 отключает фильтр разрывов глубины. Выходная сетка преобразуется в координаты glTF: данные перспективного MoGe (X вправо, Y вниз, Z вперёд) отражаются для соответствия glTF (Y вверх, Z назад), а панорамные данные поворачиваются соответствующим образом. Когда `texture` включён, исходное изображение из `moge_geometry` используется в качестве текстуры baseColor.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MESH` | Трёхмерная сетка с вершинами, гранями, UV-координатами и необязательной текстурой baseColor из исходного изображения. | MESH |
