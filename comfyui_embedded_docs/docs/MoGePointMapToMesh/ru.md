# MoGe Point Map to Mesh

Этот узел преобразует карту точек MoGe в 3D-меш. Он принимает геометрические данные, созданные узлом оценки глубины MoGe, и триангулирует их в меш с UV-координатами и необязательной текстурой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_geometry` | Геометрические данные MoGe, содержащие карты точек, глубину и, при наличии, исходное изображение. | MOGE_GEOMETRY | Да | N/A |
| `batch_index` | Какое изображение из пакетированной геометрии MoGe преобразовать в меш. Количество вершин для каждого изображения различается, поэтому пакеты нельзя объединить в один MESH (по умолчанию: 0). | INT | Да | 0–4096 |
| `decimation` | Шаг вершин; 1 = полное разрешение (по умолчанию: 1). | INT | Да | 1–8 |
| `discontinuity_threshold` | Отбрасывать пиксели, у которых разброс глубины в окне 3x3 превышает эту долю. 0 = выключено (по умолчанию: 0.04). | FLOAT | Да | 0.0–1.0 |
| `texture` | Передавать исходное изображение как текстуру baseColor (по умолчанию: True). | BOOLEAN | Да | True/False |

Примечание: `batch_index` должен быть меньше размера пакета входных данных `moge_geometry`; выбор индекса вне диапазона вызывает ошибку. Входные данные должны содержать выход points, иначе узел вызывает ошибку. Если в результате триангуляции получается пустой меш, узел вызывает ошибку — установка `discontinuity_threshold` в 0 отключает фильтр разрывов глубины. Выходной меш преобразуется в координаты glTF: перспективные данные MoGe (X вправо, Y вниз, Z вперёд) переворачиваются для соответствия glTF (Y вверх, Z назад), а панорамные данные (геометрия без внутренних параметров) соответствующим образом поворачиваются с исправленным порядком обхода. Когда `texture` включён, исходное изображение из `moge_geometry` используется как текстура baseColor.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MESH` | 3D-меш с вершинами, гранями, UV-координатами и необязательной текстурой baseColor из исходного изображения. | MESH |
