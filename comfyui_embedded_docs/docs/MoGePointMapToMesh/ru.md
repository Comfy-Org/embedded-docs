# MoGe Point Map to Mesh

Этот узел преобразует карту точек MoGe в 3D-сетку. Он принимает данные геометрии, созданные узлом оценки глубины MoGe, и триангулирует из них одно изображение в сетку с UV-координатами и необязательной текстурой.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_geometry` | Данные геометрии MoGe, содержащие карты точек, глубину и, опционально, исходное изображение. | MOGE_GEOMETRY | Да | N/A |
| `batch_index` | Какое изображение из пакетной геометрии MoGe преобразовать в сетку. Количество вершин для каждого изображения различается, поэтому пакеты нельзя объединить в один MESH (по умолчанию: 0). | INT | Да | 0 to 4096 |
| `decimation` | Шаг по вершинам; 1 = полное разрешение (по умолчанию: 1). | INT | Да | 1 to 8 |
| `discontinuity_threshold` | Отбрасывать пиксели, у которых перепад глубины в окрестности 3x3 превышает эту долю. 0 = выключено (по умолчанию: 0.04). | FLOAT | Да | 0.0 to 1.0 |
| `texture` | Передавать исходное изображение как базовую цветную текстуру (по умолчанию: True). | BOOLEAN | Да | True/False |

Примечание: `batch_index` должен быть меньше размера пакета предоставленной `moge_geometry`. Входная геометрия должна содержать данные точек, и если сгенерированная сетка пуста, узел возвращает ошибку с предложением установить `discontinuity_threshold = 0`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MESH` | Трехмерная сетка с вершинами, гранями, UV-координатами и необязательной текстурой из исходного изображения. | MESH |
