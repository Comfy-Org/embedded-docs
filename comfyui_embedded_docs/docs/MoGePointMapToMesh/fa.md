# MoGe Point Map to Mesh

این گره یک نقشه نقطه‌ای MoGe را به یک مش سه‌بعدی تبدیل می‌کند. داده هندسی تولیدشده توسط یک گره تخمین عمق MoGe را دریافت کرده و آن را به مشی با مختصات UV و بافت اختیاری مثلث‌بندی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `moge_geometry` | داده هندسه MoGe شامل نقشه‌های نقطه‌ای، عمق و به‌صورت اختیاری تصویر منبع. | MOGE_GEOMETRY | بله | N/A |
| `batch_index` | کدام تصویر از هندسه MoGe دسته‌ای به مش تبدیل شود. تعداد رأس‌های هر تصویر متفاوت است، بنابراین دسته‌ها را نمی‌توان در یک MESH واحد ادغام کرد (پیش‌فرض: 0). | INT | بله | 0 تا 4096 |
| `decimation` | گام رأس؛ 1 = وضوح کامل (پیش‌فرض: 1). | INT | بله | 1 تا 8 |
| `discontinuity_threshold` | پیکسل‌هایی را که گستره عمق 3x3 آن‌ها از این کسر فراتر می‌رود حذف می‌کند. 0 = خاموش (پیش‌فرض: 0.04). | FLOAT | بله | 0.0 تا 1.0 |
| `texture` | تصویر منبع را به‌عنوان بافت baseColor منتقل می‌کند (پیش‌فرض: True). | BOOLEAN | بله | True/False |

توجه: `batch_index` باید کوچک‌تر از اندازه دسته ورودی `moge_geometry` باشد؛ انتخاب یک اندیس خارج از محدوده خطا ایجاد می‌کند. ورودی باید شامل خروجی points باشد، در غیر این صورت گره خطا ایجاد می‌کند. اگر مثلث‌بندی مش خالی تولید کند، گره خطا ایجاد می‌کند — تنظیم `discontinuity_threshold` روی 0 فیلتر ناپیوستگی عمق را غیرفعال می‌کند. مش خروجی به مختصات glTF تبدیل می‌شود: داده‌های MoGe پرسپکتیو (X راست، Y پایین، Z جلو) برای مطابقت با glTF (Y بالا، Z عقب) وارونه می‌شود، و داده‌های پانوراما (هندسه بدون پارامترهای ذاتی) متناسباً با پیچش تصحیح‌شده چرخانده می‌شوند. وقتی `texture` فعال باشد، تصویر منبع از `moge_geometry` به‌عنوان بافت baseColor استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MESH` | یک مش سه‌بعدی با رأس‌ها، وجه‌ها، مختصات UV و یک بافت baseColor اختیاری از تصویر منبع. | MESH |
