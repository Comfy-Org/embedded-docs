# MoGe Point Map to Mesh

این گره، نقشهٔ نقطه‌ای MoGe را به یک مش سه‌بعدی تبدیل می‌کند. داده‌های هندسی تولیدشده توسط گره تخمین عمق MoGe را دریافت کرده و آن را به مشی با مختصات UV و بافت اختیاری مثلث‌بندی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `moge_geometry` | دادهٔ هندسی MoGe شامل نقشه‌های نقطه‌ای، عمق و به‌صورت اختیاری تصویر منبع. | MOGE_GEOMETRY | بله | N/A |
| `batch_index` | مشخص می‌کند کدام تصویر از هندسهٔ MoGe دسته‌ای به مش تبدیل شود. تعداد رئوس هر تصویر متفاوت است، بنابراین دسته‌ها نمی‌توانند در یک MESH تکی انباشته شوند (پیش‌فرض: 0). | INT | بله | 0 تا 4096 |
| `decimation` | گام رأس؛ 1 = وضوح کامل (پیش‌فرض: 1). | INT | بله | 1 تا 8 |
| `discontinuity_threshold` | پیکسل‌هایی که گسترهٔ عمق 3×3 آن‌ها از این کسر بیشتر باشد حذف می‌شوند. 0 = غیرفعال (پیش‌فرض: 0.04). | FLOAT | بله | 0.0 تا 1.0 |
| `texture` | تصویر منبع را به‌عنوان بافت baseColor منتقل می‌کند (پیش‌فرض: True). | BOOLEAN | بله | True/False |

توجه: `batch_index` باید کوچک‌تر از اندازهٔ دستهٔ ورودی `moge_geometry` باشد؛ انتخاب شاخص خارج از محدوده باعث بروز خطا می‌شود. اگر مثلث‌بندی مشی خالی تولید کند، گره خطا می‌دهد — تنظیم `discontinuity_threshold` روی 0 فیلتر ناپیوستگی عمق را غیرفعال می‌کند. مش خروجی به مختصات glTF تبدیل می‌شود: داده‌های MoGe پرسپکتیو (X به راست، Y به پایین، Z به جلو) برای مطابقت با glTF (Y به بالا، Z به عقب) وارونه می‌شوند و داده‌های پانوراما به‌طور متناظر چرخانده می‌شوند. هنگامی که `texture` فعال باشد، تصویر منبع از `moge_geometry` به‌عنوان بافت baseColor استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MESH` | یک مش سه‌بعدی با رئوس، وجه‌ها، مختصات UV و بافت baseColor اختیاری از تصویر منبع. | MESH |
