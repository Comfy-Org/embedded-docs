# MoGe Point Map to Mesh

این گره، نقشه نقطهٔ MoGe را به یک مش سه‌بعدی تبدیل می‌کند. دادهٔ هندسی تولیدشده توسط گرهٔ تخمین عمق MoGe را دریافت کرده و یک تصویر از آن را به مشی با مختصات UV و بافت اختیاری مثلث‌بندی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `moge_geometry` | داده‌های هندسهٔ MoGe شامل نقشه‌های نقطه، عمق و به‌صورت اختیاری تصویر منبع. | MOGE_GEOMETRY | بله | نامشخص |
| `batch_index` | کدام تصویر از هندسهٔ MoGe دسته‌ای به مش تبدیل شود. تعداد رئوس هر تصویر متفاوت است، بنابراین دسته‌ها را نمی‌توان در یک MESH واحد توده کرد (پیش‌فرض: 0). | INT | بله | 0 تا 4096 |
| `decimation` | گام رئوس؛ 1 = وضوح کامل (پیش‌فرض: 1). | INT | بله | 1 تا 8 |
| `discontinuity_threshold` | پیکسل‌هایی که گسترهٔ عمق 3×3 آن‌ها بیش از این کسر باشد حذف می‌کند. 0 = غیرفعال (پیش‌فرض: 0.04). | FLOAT | بله | 0.0 تا 1.0 |
| `texture` | تصویر منبع را به‌عنوان بافت baseColor منتقل می‌کند (پیش‌فرض: True). | BOOLEAN | بله | True/False |

نکته: `batch_index` باید از اندازهٔ دستهٔ `moge_geometry` ارائه‌شده کوچک‌تر باشد. هندسهٔ ورودی باید شامل دادهٔ نقطه باشد و اگر مش تولیدشده خالی باشد، گره خطایی برمی‌گرداند که `discontinuity_threshold = 0` را پیشنهاد می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MESH` | یک مش سه‌بعدی شامل رئوس، وجوه، مختصات UV و بافت اختیاری از تصویر منبع. | MESH |
