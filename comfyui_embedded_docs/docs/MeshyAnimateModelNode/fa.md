# Meshy: متحرک‌سازی مدل

این گره یک اکشن انیمیشن مشخص را روی کاراکتر سه‌بعدی که قبلاً ریگ شده است با استفاده از سرویس Meshy اعمال می‌کند. این گره یک شناسه وظیفه (Task ID) از عملیات ریگینگ قبلی و یک شناسه اکشن (Action ID) برای انتخاب انیمیشن موردنظر از کتابخانه دریافت می‌کند و سپس مدل انیمیت‌شده را در هر دو قالب فایل GLB و FBX برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | شناسه وظیفه یکتا از یک عملیات ریگینگ کاراکتر Meshy که قبلاً تکمیل شده است. | STRING | بله | N/A |
| `action_id` | شماره شناسه اکشن انیمیشنی که باید اعمال شود. برای فهرست مقادیر موجود، به https://docs.meshy.ai/en/api/animation-library مراجعه کنید. (پیش‌فرض: 0) | INT | بله | 0 تا 696 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | یک شناسه رشته‌ای برای مدل انیمیت‌شده. این خروجی فقط برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `GLB` | فایل مدل سه‌بعدی انیمیت‌شده در قالب GLB. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی انیمیت‌شده در قالب FBX. | FILE3DFBX |
