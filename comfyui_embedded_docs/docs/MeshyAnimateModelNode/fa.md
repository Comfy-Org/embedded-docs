# Meshy: متحرک‌سازی مدل

این گره یک اکشن انیمیشن مشخص را با استفاده از سرویس Meshy روی یک کاراکتر سه‌بعدی که قبلاً ریگ شده است اعمال می‌کند. این گره یک شناسه وظیفه از عملیات ریگینگ قبلی و یک شناسه اکشن برای انتخاب انیمیشن دلخواه از کتابخانه دریافت می‌کند، سپس مدل انیمیشن‌شده را در هر دو قالب فایل GLB و FBX برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | شناسه وظیفه یکتای حاصل از یک عملیات ریگینگ کاراکتر Meshy که قبلاً تکمیل شده است. | MESHY_RIGGED_TASK_ID | بله | N/A |
| `action_id` | شناسه عددی اکشن انیمیشنی که باید اعمال شود. برای مشاهده فهرست مقادیر موجود به https://docs.meshy.ai/en/api/animation-library مراجعه کنید. (پیش‌فرض: 0) | INT | بله | 0 تا 696 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | یک شناسه رشته‌ای برای مدل انیمیشن‌شده. این خروجی فقط برای سازگاری با نسخه‌های قبلی ارائه شده است. | STRING |
| `GLB` | فایل مدل سه‌بعدی انیمیشن‌شده در قالب GLB. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی انیمیشن‌شده در قالب FBX. | FILE3DFBX |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyAnimateModelNode/fa.md)
