# MeshyAnimateModelNode

הצומת הזה מחיל פעולת אנימציה ספציפית על דמות תלת-ממדית שעברה ריגינג קודם לכן, באמצעות שירות Meshy. הוא מקבל מזהה משימה מפעולת ריגינג קודמת ומזהה פעולה כדי לבחור את האנימציה הרצויה מהספרייה, ואז מחזיר את המודל המונפש בפורמטים GLB ו-FBX.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | מזהה המשימה הייחודי מפעולת ריגינג קודמת של דמות Meshy שהושלמה. | MESHY_RIGGED_TASK_ID | כן | N/A |
| `action_id` | מספר המזהה של פעולת האנימציה להחלה. בקרו ב-https://docs.meshy.ai/en/api/animation-library לקבלת רשימה של ערכים זמינים. (ברירת מחדל: 0) | INT | כן | 0 עד 696 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | מזהה מחרוזתי עבור המודל המונפש. פלט זה מסופק לצורך תאימות לאחור בלבד. | STRING |
| `GLB` | קובץ מודל תלת-ממדי מונפש בפורמט GLB. | FILE3DGLB |
| `FBX` | קובץ מודל תלת-ממדי מונפש בפורמט FBX. | FILE3DFBX |
