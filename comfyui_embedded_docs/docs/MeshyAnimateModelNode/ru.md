# Meshy: Анимировать модель

Этот узел применяет конкретное анимационное действие к ранее риггированному 3D-персонажу с помощью сервиса Meshy. Он принимает идентификатор задачи из предыдущей операции риггинга и идентификатор действия для выбора нужной анимации из библиотеки, затем возвращает анимированную модель в форматах GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | Уникальный идентификатор задачи из ранее завершенной операции риггинга персонажа Meshy. | STRING | Да | N/A |
| `action_id` | Идентификатор анимационного действия для применения. Посетите https://docs.meshy.ai/en/api/animation-library для получения списка доступных значений. (по умолчанию: 0) | INT | Да | от 0 до 696 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Строковый идентификатор анимированной модели. Этот выход предоставлен только для обратной совместимости. | STRING |
| `GLB` | Файл анимированной 3D-модели в формате GLB. | FILE3DGLB |
| `FBX` | Файл анимированной 3D-модели в формате FBX. | FILE3DFBX |
