# Meshy: Анимировать модель

Этот узел применяет определённое анимационное действие к ранее подготовленному с помощью риггинга 3D-персонажу через сервис Meshy. Он принимает ID задачи из предыдущей операции риггинга и ID действия для выбора нужной анимации из библиотеки, после чего возвращает анимированную модель в форматах GLB и FBX.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | Уникальный ID задачи из ранее завершённой операции риггинга персонажа Meshy. | MESHY_RIGGED_TASK_ID | Да | N/A |
| `action_id` | ID номер анимационного действия для применения. Список доступных значений см. на https://docs.meshy.ai/en/api/animation-library. (по умолчанию: 0) | INT | Да | 0–696 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Строковый идентификатор анимированной модели. Этот выход предусмотрен только для обратной совместимости. | STRING |
| `GLB` | Файл анимированной 3D-модели в формате GLB. | FILE3DGLB |
| `FBX` | Файл анимированной 3D-модели в формате FBX. | FILE3DFBX |
