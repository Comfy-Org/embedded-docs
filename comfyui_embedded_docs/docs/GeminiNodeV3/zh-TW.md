# GeminiNodeV3

使用 Google 的 Gemini 模型生成文字回應。提供文字提示，並可選擇性地提供一個或多個圖片、音訊剪輯、影片或檔案作為多模態上下文。所選模型決定了會顯示哪些額外設定。
