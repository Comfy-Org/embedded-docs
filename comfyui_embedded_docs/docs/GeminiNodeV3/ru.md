# GeminiNodeV3

Генерируйте текстовые ответы с помощью моделей Gemini от Google. Укажите текстовый запрос и, при необходимости, одно или несколько изображений, аудиоклипов, видео или файлов в качестве мультимодального контекста. Выбранная модель определяет, какие дополнительные настройки отображаются.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель Gemini, используемая для генерации ответа. Выбранная модель определяет, какие дополнительные входы отображаются. | DYNAMIC_COMBO | Да | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |

### Медиа-входы

Эти расширяемые медиа-входы доступны для каждого варианта модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Необязательные изображения для использования в качестве контекста модели. До 16 изображений. Расширяемый слот: подключите изображения к `image_1`–`image_16`. | IMAGE | Нет | До 16 изображений |
| `audio` | Необязательный аудиоклип для использования в качестве контекста модели. Расширяемый слот: `audio_1`. | AUDIO | Нет | 1 аудиоклип |
| `video` | Необязательный видеоклип для использования в качестве контекста модели. Расширяемый слот: `video_1`. | VIDEO | Нет | 1 видеоклип |

### Входы Gemini 3.8 Flash

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый ввод для модели. Включите подробные инструкции, вопросы или контекст. Не должен быть пустым. | STRING | Да | Многострочный текст (должен содержать хотя бы один непробельный символ) |
| `video_processing` | Как модель читает прикреплённое видео. `static` выбирает кадры с фиксированной частотой и отправляет все их как контекст; `agentic` позволяет модели самостоятельно перемещаться по временной шкале и загружать только нужные ей кадры, аудио или транскрипцию, что расходует гораздо меньше входных токенов на длинных видео. | COMBO | Да | `"static"`<br>`"agentic"` (по умолчанию: `"static"`) |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входы от узла Gemini Input Files. | GEMINI_INPUT_FILES | Нет | Н/Д |
| `thinking_level` | Насколько интенсивно модель рассуждает внутренне перед ответом. HIGH повышает качество на сложных задачах, но расходует больше токенов на размышления и работает медленнее. | COMBO | Да | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` (по умолчанию: `"MEDIUM"`) |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая внутренние рассуждения модели. При thinking_level HIGH низкое значение может не оставить места для ответа; увеличьте его, если ответы возвращаются пустыми или обрезанными. Модель останавливается раньше, когда завершает работу, поэтому более высокий лимит не требует дополнительных затрат для коротких ответов. | INT | Да | 16-65536 (по умолчанию: 32768) |
| `seed` | Сид для сэмплирования. Установите 0 для случайного сида. Детерминированный вывод не гарантируется. | INT | Да | 0-2147483647 (по умолчанию: 42) |
| `system_prompt` | Основополагающие инструкции, определяющие поведение модели. | STRING | Да | Многострочный текст (по умолчанию: пусто) |

Примечание: Для Gemini 3.8 Flash параметры `temperature` и `top_p` недоступны, а `video_processing` доступен только для этого варианта модели. Параметры `thinking_level` и значение по умолчанию различаются в зависимости от модели, как указано выше.

Примечание: Вход `prompt` не должен быть пустым. Узел проверяет, что он содержит хотя бы один непробельный символ.

Примечание: Узел загружает до первых 10 медиаэлементов как URL, отдавая приоритет видео, затем аудио, затем изображениям. Все оставшиеся медиа отправляются встроенно в формате base64. Общий объём встроенных медиа ограничен 18 МБ; при превышении узел выдаёт ошибку с просьбой уменьшить количество или размер прикреплённых медиа.
