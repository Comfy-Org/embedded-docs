# ModelMergeFlux1

הצומת ModelMergeFlux1 ממזגת שני מודלי דיפוזיה על ידי ערבוב הרכיבים שלהם באמצעות אינטרפולציה משוקללת. היא מאפשרת שליטה עדינה באופן שבו חלקים שונים של המודלים משולבים, כולל בלוקים לעיבוד תמונה, שכבות הטמעת זמן, מנגנוני הנחיה, קלטי וקטור, מקודדי טקסט ובלוקי טרנספורמר שונים. הדבר מאפשר יצירת מודלים היברידיים עם מאפיינים מותאמים אישית משני מודלי מקור.
