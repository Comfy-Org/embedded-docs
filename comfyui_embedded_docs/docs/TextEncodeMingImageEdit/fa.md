# Text Encode Ming Image Edit

گره Text Encode Ming Image Edit یک پرامپت متنی را برای ویرایش تصویر Ming به conditioning کدگذاری می‌کند و به‌صورت اختیاری تصاویر مرجع را نیز با آن ترکیب می‌کند. پرامپت و تصاویر مرجع توسط یک مدل CLIP توکن‌سازی می‌شوند و وقتی VAE متصل باشد، تصاویر مرجع همچنین به فریم‌های لاتنت کدگذاری می‌شوند که به conditioning افزوده می‌گردند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP که برای توکن‌سازی پرامپت و تصاویر مرجع استفاده می‌شود. | CLIP | بله | - |
| `vae` | VAE اختیاری که تصاویر مرجع را به فریم‌های لاتنت کدگذاری می‌کند و این فریم‌ها به conditioning افزوده می‌شوند. بدون VAE، تصاویر فقط از طریق برج بینایی (vision tower) بر رمزگذار متن اثر می‌گذارند. | VAE | خیر | - |
| `prompt` | پرامپت متنی برای کدگذاری. از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | متن چندخطی |
| `images` | جای‌گاه قابل گسترش: تصاویر مرجع اختیاری که توسط رمزگذار متن دیده می‌شوند و به‌عنوان فریم‌های تمیز به دنباله لاتنت افزوده می‌شوند. از 1 تا 8 تصویر را وصل کنید (`image_1`, `image_2`, ...)؛ تصاویر بعدی به اندازه تصویر اول تغییر اندازه می‌یابند و لاتنت نمونه‌گیری‌شده باید با اندازه آن مطابقت داشته باشد. فقط کانال‌های RGB استفاده می‌شوند. | IMAGE | خیر | 0 تا 8 |

**نکته:** تصاویر مرجع به ترتیب عددی نام جای‌گاه‌هایشان خوانده می‌شوند و جای‌گاه‌های خالی نادیده گرفته می‌شوند. لاتنت‌های مرجع فقط زمانی تولید می‌شوند که هم `vae` و هم حداقل یک تصویر ارائه شده باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `CONDITIONING` | conditioning شامل پرامپت کدگذاری‌شده، به‌همراه لاتنت‌های مرجع در صورت ارائه VAE و تصاویر مرجع. | CONDITIONING |
