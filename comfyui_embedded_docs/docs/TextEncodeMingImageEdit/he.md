# קידוד טקסט לעריכת תמונה Ming

Text Encode Ming Image Edit מקודד פרומפט טקסטואלי לקונדישנינג עבור עריכת תמונות Ming, ובאופן אופציונלי משלב תמונות עזר. הפרומפט ותמונות העזר עוברים טוקניזציה באמצעות מודל CLIP, וכאשר מחובר VAE, תמונות העזר מקודדות גם לפריימים לטנטיים שמצורפים לקונדישנינג.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `clip` | מודל ה-CLIP המשמש לטוקניזציה של הפרומפט ושל תמונות העזר. | CLIP | כן | - |
| `vae` | VAE אופציונלי שמקודד את תמונות העזר לפריימים לטנטיים המצורפים לקונדישנינג. ללא VAE, התמונות משפיעות על מקודד הטקסט רק דרך מגדל הראייה. | VAE | לא | - |
| `prompt` | פרומפט טקסטואלי לקידוד. תומך בקלט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | טקסט מרובה שורות |
| `images` | חריץ מתרחב: תמונות עזר אופציונליות הנראות על ידי מקודד הטקסט ומצורפות לרצף הלטנטי כפריימים נקיים. חבר 1..8 תמונות (`image_1`, `image_2`, ...); תמונות מאוחרות יותר מותאמות בגודלן לראשונה, והלטנט הנדגם צריך להתאים לגודלה. נעשה שימוש רק בערוצי RGB. | IMAGE | לא | 0 עד 8 |

**הערה:** תמונות עזר נקראות לפי סדר מספרי של שמות החריצים שלהן, וחריצים ריקים אינם נלקחים בחשבון. לטנטים של תמונות עזר נוצרים רק כאשר מסופקים גם `vae` וגם לפחות תמונה אחת.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `CONDITIONING` | קונדישנינג המכיל את הפרומפט המקודד, בתוספת הלטנטים של תמונות העזר כאשר מסופקים VAE ותמונות עזר. | CONDITIONING |
