# Text Encode Ming Image Edit

Text Encode Ming Image Edit кодирует текстовый промпт в conditioning для редактирования изображений Ming, при необходимости подмешивая референсные изображения. Промпт и референсные изображения токенизируются моделью CLIP, а при подключении VAE референсные изображения также кодируются в латентные кадры, которые добавляются к conditioning.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации промпта и референсных изображений. | CLIP | Да | - |
| `vae` | Необязательный VAE, который кодирует референсные изображения в латентные кадры, добавляемые к conditioning. Без VAE изображения влияют на текстовый энкодер только через визуальный кодировщик (vision tower). | VAE | Нет | - |
| `prompt` | Текстовый промпт для кодирования. Поддерживает многострочный ввод и динамические промпты. | STRING | Да | Многострочный текст |
| `images` | Расширяемый слот: необязательные референсные изображения, которые видит текстовый энкодер и которые добавляются в латентную последовательность как чистые кадры. Подключите от 1 до 8 изображений (`image_1`, `image_2`, ...); последующие изображения масштабируются под первое, и сэмплированный латент должен соответствовать его размеру. Используются только каналы RGB. | IMAGE | Нет | 0 до 8 |

**Примечание:** Референсные изображения считываются в числовом порядке их имён слотов, пустые слоты игнорируются. Референсные латенты создаются только когда заданы и `vae`, и хотя бы одно изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `CONDITIONING` | Conditioning, содержащий закодированный промпт, а также референсные латенты, если предоставлены VAE и референсные изображения. | CONDITIONING |
