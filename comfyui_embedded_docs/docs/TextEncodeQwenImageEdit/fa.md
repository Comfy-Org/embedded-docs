# TextEncodeQwenImageEdit

گره TextEncodeQwenImageEdit متن‌های ورودی (prompt) و تصاویر اختیاری را به داده‌های شرطی‌سازی (conditioning) برای تولید یا ویرایش تصویر تبدیل می‌کند. این گره از مدل CLIP برای توکنایز کردن ورودی استفاده می‌کند و به‌صورت اختیاری می‌تواند تصاویر مرجع را با VAE کدگذاری کند تا latentهای مرجع ایجاد شود. هنگامی که یک تصویر ارائه می‌شود، به‌طور خودکار تغییر اندازه می‌دهد تا مقیاس پردازشی یکنواختی حفظ شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنایز کردن متن و تصویر | CLIP | بله | - |
| `پرامپت` | پرامپت متنی برای تولید شرطی‌سازی، پشتیبانی از ورودی چندخطی و پرامپت‌های پویا | STRING | بله | - |
| `vae` | مدل VAE اختیاری برای کدگذاری تصاویر مرجع به latent | VAE | خیر | - |
| `تصویر` | تصویر ورودی اختیاری برای مرجع یا اهداف ویرایش | IMAGE | خیر | - |

**توجه:** هنگامی که یک تصویر ارائه می‌شود، اندازه آن تغییر می‌کند تا تعداد کل پیکسل‌ها نزدیک به ۱٬۰۴۸٬۵۷۶ (۱۰۲۴ × ۱۰۲۴) باقی بماند و فقط از کانال‌های RGB آن استفاده می‌شود. تصویر تغییر اندازه‌یافته به همراه پرامپت به توکنایزر CLIP ارسال می‌شود. وقتی هر دو `image` و `vae` ارائه شوند، گره تصویر را به latentهای مرجع کدگذاری کرده و آن‌ها را به خروجی شرطی‌سازی پیوست می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده شرطی‌سازی حاوی توکن‌های متنی و latentهای مرجع اختیاری برای تولید تصویر | CONDITIONING |
