# TextEncodeQwenImageEdit

گره `TextEncodeQwenImageEdit` پردازش متن و تصاویر اختیاری را برای تولید داده‌های شرطی‌سازی جهت تولید یا ویرایش تصویر انجام می‌دهد. این گره از مدل CLIP برای توکنایز کردن ورودی استفاده می‌کند و به‌طور اختیاری می‌تواند تصاویر مرجع را با استفاده از VAE برای ایجاد لاتنت‌های مرجع کدگذاری کند. وقتی تصویری ارائه شود، به‌طور خودکار اندازه تصویر را برای حفظ ابعاد پردازش سازگار تغییر می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای توکنایز کردن متن و تصویر | CLIP | بله | - |
| `prompt` | پرامپت متنی برای تولید شرطی‌سازی، از ورودی چندخطی و پرامپت‌های پویا پشتیبانی می‌کند | STRING | بله | - |
| `vae` | مدل VAE اختیاری برای کدگذاری تصاویر مرجع به لاتنت | VAE | خیر | - |
| `image` | تصویر ورودی اختیاری برای اهداف مرجع یا ویرایش | IMAGE | خیر | - |

**توجه:** هنگامی که هر دو `image` و `vae` ارائه شوند، گره تصویر را به لاتنت‌های مرجع کدگذاری کرده و آن‌ها را به خروجی شرطی‌سازی متصل می‌کند. تصویر به‌طور خودکار برای حفظ مقیاس پردازش سازگار تقریباً 1024×1024 پیکسل تغییر اندازه می‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `CONDITIONING` | داده‌های شرطی‌سازی حاوی توکن‌های متنی و لاتنت‌های مرجع اختیاری برای تولید تصویر | CONDITIONING |
