# TextEncodeQwenImageEdit

הצומת TextEncodeQwenImageEdit ממיר פרומפטים טקסטואליים ותמונות אופציונליות לנתוני התניה עבור יצירת תמונות או עריכה. הוא משתמש במודל CLIP כדי לבצע טוקניזציה של הקלט, ויכול באופן אופציונלי לקודד תמונות עזר עם VAE כדי ליצור לטנטים של עזר. כאשר מסופקת תמונה, היא עוברת שינוי גודל אוטומטי כדי לשמור על קנה מידה עיבודי אחיד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לטוקניזציה של טקסט ותמונה | CLIP | כן | - |
| `prompt` | פרומפט טקסט ליצירת התניה, תומך בקלט רב-שורתי ובפרומפטים דינמיים | STRING | כן | - |
| `vae` | מודל VAE אופציונלי לקידוד תמונות עזר ללטנטים | VAE | לא | - |
| `image` | תמונת קלט אופציונלית למטרות עזר או עריכה | IMAGE | לא | - |

**הערה:** כאשר מסופקת תמונה, היא עוברת שינוי גודל כך שסך הפיקסלים שלה נשאר קרוב ל-1,048,576 (1024 × 1024), ורק ערוצי ה-RGB שלה משמשים. התמונה לאחר שינוי הגודל מועברת ל-CLIP tokenizer יחד עם הפרומפט. כאשר גם `image` וגם `vae` מסופקים, הצומת גם מקודד את התמונה ללטנטים של עזר ומצרף אותם לפלט ההתניה.
