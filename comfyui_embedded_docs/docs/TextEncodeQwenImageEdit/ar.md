# TextEncodeQwenImageEdit

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP المستخدم لترميز النصوص والصور | CLIP | نعم | - |
| `مُوجِّه` | نص التوجيه لتوليد الإشراط، يدعم الإدخال متعدد الأسطر والتوجيهات الديناميكية | STRING | نعم | - |
| `vae` | نموذج VAE اختياري لترميز الصور المرجعية إلى كمونات | VAE | لا | - |
| `صورة` | صورة إدخال اختيارية لأغراض المرجعية أو التحرير | IMAGE | لا | - |

**ملاحظة:** عند توفير صورة، يتم تغيير حجمها بحيث يظل إجمالي عدد البكسلات قريبًا من 1,048,576 (1024 × 1024)، ويتم استخدام قنوات RGB فقط. تُمرَّر الصورة المعاد تغيير حجمها إلى مُرمِّز CLIP مع نص التوجيه. عند توفير كل من `image` و`vae`، تقوم العقدة أيضًا بترميز الصورة إلى كمونات مرجعية وتُرفقها بمخرج الإشراط.
