# TextEncodeQwenImageEdit

Узел TextEncodeQwenImageEdit обрабатывает текстовые промпты и необязательные изображения для генерации данных conditioning для создания или редактирования изображений. Он использует модель CLIP для токенизации входных данных и может опционально кодировать эталонные изображения с помощью VAE для создания эталонных латентных представлений. Когда изображение предоставлено, узел автоматически изменяет его размер для поддержания согласованных размеров обработки.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации текста и изображений | CLIP | Да | - |
| `prompt` | Текстовый промпт для генерации conditioning, поддерживает многострочный ввод и динамические промпты | STRING | Да | - |
| `vae` | Необязательная модель VAE для кодирования эталонных изображений в латентные представления | VAE | Нет | - |
| `image` | Необязательное входное изображение для использования в качестве референса или редактирования | IMAGE | Нет | - |

**Примечание:** Когда одновременно предоставлены `image` и `vae`, узел кодирует изображение в эталонные латентные представления и добавляет их к выходным данным conditioning. Изображение автоматически масштабируется для поддержания единого масштаба обработки примерно 1024x1024 пикселей.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные conditioning, содержащие текстовые токены и необязательные эталонные латентные представления для генерации изображений | CONDITIONING |
