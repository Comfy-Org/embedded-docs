# TextEncodeQwenImageEdit

Узел TextEncodeQwenImageEdit преобразует текстовые промпты и опциональные изображения в данные conditioning для генерации или редактирования изображений. Он использует модель CLIP для токенизации входа и может опционально кодировать эталонные изображения с помощью VAE для создания эталонных латентных представлений. Если изображение предоставлено, оно автоматически масштабируется для сохранения согласованного масштаба обработки.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для токенизации текста и изображений | CLIP | Да | - |
| `промпт` | Текстовый промпт для генерации данных conditioning, поддерживает многострочный ввод и динамические промпты | STRING | Да | - |
| `vae` | Необязательная модель VAE для кодирования эталонных изображений в латентные представления | VAE | Нет | - |
| `изображение` | Необязательное входное изображение для эталонного использования или редактирования | IMAGE | Нет | - |

**Примечание:** Если изображение предоставлено, оно масштабируется так, чтобы общее количество пикселей оставалось близким к 1 048 576 (1024 × 1024), и используются только его RGB-каналы. Масштабированное изображение передаётся токенизатору CLIP вместе с промптом. Если указаны и `image`, и `vae`, узел также кодирует изображение в эталонные латентные представления и присоединяет их к выходу conditioning.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Данные conditioning, содержащие текстовые токены и опциональные эталонные латентные представления для генерации изображений | CONDITIONING |
