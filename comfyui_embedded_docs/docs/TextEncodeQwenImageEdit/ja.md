# TextEncodeQwenImageEdit

TextEncodeQwenImageEdit ノードは、テキストプロンプトとオプションの画像を処理して、画像生成または編集用のコンディショニングデータを生成します。CLIP モデルを使用して入力をトークン化し、オプションで VAE を使用して参照画像をエンコードし、参照用ラテントを作成できます。画像が提供されると、処理ディメンションを一定に保つため、自動的にリサイズされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | テキストおよび画像のトークン化に使用される CLIP モデル | CLIP | はい | - |
| `prompt` | コンディショニング生成用のテキストプロンプト。複数行入力と動的プロンプトに対応 | STRING | はい | - |
| `vae` | 参照画像をラテントにエンコードするためのオプションの VAE モデル | VAE | いいえ | - |
| `image` | 参照または編集目的で使用するオプションの入力画像 | IMAGE | いいえ | - |

**注意：** `image` と `vae` の両方が指定された場合、ノードは画像を参照用ラテントにエンコードし、コンディショニング出力に添付します。画像は約 1024x1024 ピクセルの一貫した処理スケールを維持するよう自動的にリサイズされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `CONDITIONING` | 画像生成のためのテキストトークンとオプションの参照用ラテントを含むコンディショニングデータ | CONDITIONING |
