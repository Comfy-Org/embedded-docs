# HappyHorse تبدیل تصویر به ویدیو

این گره با استفاده از مدل HappyHorse، یک ویدیوی کوتاه از یک تصویر شروع تولید می‌کند. شما یک تصویر فریم اول و یک پیام متنی (prompt) که حرکت و صحنهٔ مورد نظر را توصیف می‌کند، ارائه می‌دهید و گره ویدیویی می‌سازد که از آن تصویر ادامه می‌یابد.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل HappyHorse که برای تولید ویدیو استفاده می‌شود. | DYNAMIC_COMBO | بله | `"happyhorse-1.1-i2v"`<br>`"happyhorse-1.0-i2v"` |
| `فریم اول` | تصویر فریم اول. نسبت ابعاد خروجی از این تصویر گرفته می‌شود. | IMAGE | بله | حداقل 300×300 پیکسل؛ نسبت 1:2.5 تا 2.5:1 |
| `seed` | مقدار Seed برای تولید. (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |
| `واترمارک` | آیا یک واترمارک تولیدشده با هوش مصنوعی به نتیجه اضافه شود. (گزینه پیشرفته؛ پیش‌فرض: False) | BOOLEAN | خیر | True / False |

### ورودی‌های happyhorse-1.1-i2v و happyhorse-1.0-i2v

هر دو نسخه مدل، مجموعه‌ای یکسان از پارامترها را دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | متن راهنما (Prompt) که عناصر و ویژگی‌های بصری را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. (پیش‌فرض: "") | STRING | خیر | N/A |
| `رزولوشن` | دقت ویدیوی خروجی. (پیش‌فرض: "720P") | COMBO | بله | `"720P"`<br>`"1080P"` |
| `مدت زمان` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه. (پیش‌فرض: 5) | INT | بله | 3 تا 15 |

توجه: تصویر `first_frame` باید حداقل 300×300 پیکسل باشد و نسبت ابعاد آن باید بین 1:2.5 و 2.5:1 باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | فایل ویدیویی تولیدشده. | VIDEO |
