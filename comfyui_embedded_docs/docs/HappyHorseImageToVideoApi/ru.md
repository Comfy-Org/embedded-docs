# HappyHorse: изображение в видео

Этот узел генерирует короткое видео из одного стартового изображения с помощью модели HappyHorse. Вы предоставляете изображение первого кадра и текстовый запрос, описывающий желаемое движение и сцену, а узел создает видео, которое продолжается с этого изображения.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель HappyHorse для генерации видео. | DYNAMIC_COMBO | Да | `"happyhorse-1.1-i2v"`<br>`"happyhorse-1.0-i2v"` |
| `first_frame` | Изображение первого кадра. Соотношение сторон выходного видео определяется этим изображением. | IMAGE | Да | мин. 300×300 px; соотношение 1:2.5–2.5:1 |
| `seed` | Сид для генерации. (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |
| `watermark` | Добавлять ли AI-сгенерированный водяной знак к результату. (дополнительная опция; по умолчанию: False) | BOOLEAN | Да | True / False |

### Входы happyhorse-1.1-i2v и happyhorse-1.0-i2v

Обе версии модели используют одинаковый набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Запрос, описывающий элементы и визуальные особенности. Поддерживает английский и китайский языки. (по умолчанию: "") | STRING | Нет | N/A |
| `разрешение` | Разрешение выходного видео. (по умолчанию: "720P") | COMBO | Да | `"720P"`<br>`"1080P"` |
| `длительность` | Длительность генерируемого видео в секундах. (по умолчанию: 5) | INT | Да | от 3 до 15 |

Примечание: изображение `first_frame` должно быть не менее 300x300 пикселей, а его соотношение сторон должно быть от 1:2.5 до 2.5:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
