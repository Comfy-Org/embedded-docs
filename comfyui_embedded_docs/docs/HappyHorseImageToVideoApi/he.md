# HappyHorseImageToVideoApi

צומת זה יוצר סרטון קצר מתמונת התחלה בודדת באמצעות מודל HappyHorse. אתם מספקים תמונת פריים ראשון ופרומפט טקסט המתאר את התנועה והסצנה הרצויות, והצומת יוצר סרטון שממשיך מאותה תמונה.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | מודל HappyHorse שבו יש להשתמש ליצירת וידאו. | DYNAMIC_COMBO | כן | `"happyhorse-1.1-i2v"`<br>`"happyhorse-1.0-i2v"` |
| `first_frame` | תמונת פריים ראשון. יחס הגובה-רוחב של הפלט נגזר מתמונה זו. | IMAGE | כן | 300×300 px מינימום; 1:2.5 עד 2.5:1 |
| `seed` | ה-seed שבו יש להשתמש ליצירה. (ברירת מחדל: 0) | INT | כן | 0 עד 2147483647 |
| `watermark` | האם להוסיף סימן מים שנוצר ב-AI לתוצאה. (אפשרות מתקדמת; ברירת מחדל: False) | BOOLEAN | כן | True / False |

### קלטים של happyhorse-1.1-i2v ו-happyhorse-1.0-i2v

שתי גרסאות המודל חולקות את אותה קבוצת פרמטרים.

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | פרומפט המתאר את המרכיבים והמאפיינים החזותיים. תומך באנגלית ובסינית. (ברירת מחדל: "") | STRING | לא | N/A |
| `resolution` | רזולוציית הווידאו של הפלט. (ברירת מחדל: `"720P"`) | COMBO | כן | `"720P"`<br>`"1080P"` |
| `duration` | משך הסרטון שנוצר בשניות. (ברירת מחדל: 5) | INT | כן | 3 עד 15 |

הערה: תמונת `first_frame` חייבת להיות בגודל של לפחות 300x300 פיקסלים, ויחס הגובה-רוחב שלה חייב להיות בין 1:2.5 ל-2.5:1.
