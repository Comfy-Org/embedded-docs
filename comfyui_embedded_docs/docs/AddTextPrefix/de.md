# AddTextPrefix

Der Node „Add Text Prefix“ ändert Text, indem er jedem Eingabetext eine angegebene Zeichenkette am Anfang hinzufügt. Er nimmt den Text und ein Präfix als Eingabe entgegen und gibt dann das kombinierte Ergebnis zurück.

**Hinweis:** Dieser Node ist veraltet und wird durch den Node „Concatenate Text“ ersetzt.

## Eingaben

| Parameter | Beschreibung | Datentyp | Erforderlich | Bereich |
| --- | --- | --- | --- | --- |
| `text` | Der Text, dem das Präfix hinzugefügt wird. | STRING | Ja |  |
| `prefix` | Die Zeichenkette, die am Anfang des Textes hinzugefügt wird (Standard: ""). | STRING | Nein |  |

## Ausgaben

| Ausgabename | Beschreibung | Datentyp |
| --- | --- | --- |
| `text` | Der resultierende Text mit dem vorangestellten Präfix. | STRING |
