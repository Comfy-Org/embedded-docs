# Aggiungi Prefisso Testo (DEPRECATO)

Il nodo Add Text Prefix modifica il testo aggiungendo una stringa specificata all'inizio di ogni testo di input. Riceve in input il testo e un prefisso, quindi restituisce il risultato combinato.

**Nota:** Questo nodo è deprecato e sostituito dal nodo Concatenate Text.

## Input

| Parametro | Descrizione | Tipo di dato | Obbligatorio | Intervallo |
| --- | --- | --- | --- | --- |
| `text` | Il testo a cui verrà aggiunto il prefisso. | STRING | Sì |  |
| `prefix` | La stringa da aggiungere all'inizio del testo (predefinito: ""). | STRING | No |  |

## Output

| Nome output | Descrizione | Tipo di dato |
| --- | --- | --- |
| `text` | Il testo risultante con il prefisso aggiunto all'inizio. | STRING |
