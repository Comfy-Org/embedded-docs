# AddTextPrefix

צומת Add Text Prefix משנה טקסט על ידי הוספת מחרוזת שצוינה לתחילתו של כל טקסט קלט. הוא מקבל `text` ו-`prefix` כקלט, ואז מחזיר את התוצאה המשולבת.

**הערה:** צומת זה הוצא משימוש (deprecated) והוחלף על ידי הצומת Concatenate Text.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `text` | הטקסט שאליו תתווסף הקידומת. | STRING | כן |  |
| `prefix` | המחרוזת להוספה לתחילת הטקסט (ברירת מחדל: ""). | STRING | לא |  |
