# Empty MiniMax H3 AV 潛空間

此節點建立一個結合 MiniMax H3 模型視訊與音訊資訊的空白潛在空間（latent）。您可以定義內容的寬度、高度與長度，節點會產生一個空白潛在空間，供模型作為生成的起點。持續時間（長度）會自動調整，以符合模型在 24 fps 下所需的 17k+5 幀網格。

## 輸入

| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `寬度` | 潛在空間的寬度（像素）。數值必須是 32 的倍數。預設值：1344。 | INT | 是 | 32 - MAX_RESOLUTION (步長 32) |
| `高度` | 潛在空間的高度（像素）。數值必須是 32 的倍數。預設值：768。 | INT | 是 | 32 - MAX_RESOLUTION (步長 32) |
| `長度` | 以 24 fps 計算的幀數，向上調整至模型的 17k+5 網格（124 = 約 5 秒；訓練範圍約 124-362，更長未經測試）。預設值：124。 | INT | 是 | 5 - 3600 (步長 17) |

注意：`length` 值會向上調整至符合模型 17k+5 網格的下一個幀數（17 x k + 5 幀，例如 5、22、39、56、73、90、107、124 等）。`width` 與 `height` 值必須是 32 的倍數。最大解析度為 ComfyUI 中的系統定義值。

## 輸出

|-------------|-------------|-----------|
| `latent` | 為 MiniMax H3 生成的空白聯合視訊+音訊潛在空間，尺寸依據輸入的寬度、高度與長度而定。 | LATENT |
