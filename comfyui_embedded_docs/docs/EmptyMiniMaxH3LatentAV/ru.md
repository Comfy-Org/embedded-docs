# Пустой MiniMax H3 AV латент

Этот узел создает пустой latent, объединяющий как видео, так и аудио информацию для модели MiniMax H3. Вы определяете ширину, высоту и длину контента, а узел создает пустой latent, который модель может использовать в качестве отправной точки для генерации. Длительность (length) автоматически корректируется, чтобы соответствовать требуемой сетке кадров модели 17k+5 кадров при 24 fps.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|------------|--------------|----------|
| `ширина` | Ширина latent в пикселях. Значения должны быть кратны 32. По умолчанию: 1344. | INT | Да | 32 - MAX_RESOLUTION (шаг 32) |
| `высота` | Высота latent в пикселях. Значения должны быть кратны 32. По умолчанию: 768. | INT | Да | 32 - MAX_RESOLUTION (шаг 32) |
| `длина` | Количество кадров при 24 fps, округляется вверх до сетки 17k+5 модели (124 = ~5 секунд; обученный диапазон составляет ~124-362, большая длительность не тестировалась). По умолчанию: 124. | INT | Да | 5 - 3600 (шаг 17) |

Примечание: Значение `length` округляется вверх до ближайшего количества кадров, соответствующего сетке 17k+5 модели (17 x k + 5 кадров, например, 5, 22, 39, 56, 73, 90, 107, 124 и так далее). Значения `width` и `height` должны быть кратны 32. Максимальное разрешение — это значение, заданное системой в ComfyUI.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-------------|
| `latent` | Сгенерированный пустой совмещенный видео+аудио latent для MiniMax H3, размер которого определяется входными значениями width, height и length. | LATENT |
