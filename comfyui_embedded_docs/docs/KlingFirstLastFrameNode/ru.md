# Kling 3.0: Видео по первому и последнему кадру

Этот узел использует модель Kling 3.0 для генерации видео. Он создает видео на основе текстового промпта, заданной длительности и двух предоставленных изображений: начального кадра и конечного кадра. Узел также может генерировать сопутствующее аудио для видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель и настройки генерации. Выбор этой опции открывает вложенный параметр `resolution`. | COMBO | Нет | `"kling-v3"` |
| `prompt` | Текстовое описание, которое управляет генерацией видео. Должно содержать от 1 до 2500 символов. | STRING | Да | N/A |
| `длительность` | Длительность видео в секундах (по умолчанию: 5). | INT | Нет | 3 до 15 |
| `первый кадр` | Начальное изображение для видео. Должно быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. | IMAGE | Да | N/A |
| `последний кадр` | Конечное изображение для видео. Должно быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1. | IMAGE | Да | N/A |
| `создать аудио` | Управляет генерацией аудио для видео (по умолчанию: True). | BOOLEAN | Нет | N/A |
| `seed` | Seed управляет тем, должен ли узел запускаться заново; результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Нет | 0 до 2147483647 |

### Входы Kling V3

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `resolution` | Разрешение для сгенерированного видео (по умолчанию: `"1080p"`). | COMBO | Нет | `"4k"`<br>`"1080p"`<br>`"720p"` |

**Примечание:** Изображения `first_frame` и `end_frame` должны быть не менее 300x300 пикселей и иметь соотношение сторон от 1:2.5 до 2.5:1 для корректной работы узла. `prompt` должен содержать от 1 до 2500 символов. Опция `resolution` соответствует режиму генерации Kling: `"4k"`, `"1080p"` (pro) и `"720p"` (standard).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл. | VIDEO |
