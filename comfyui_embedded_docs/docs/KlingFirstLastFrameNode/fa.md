# Kling 3.0 تبدیل اولین و آخرین فریم به ویدیو

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل و تنظیمات تولید. انتخاب این گزینه، پارامتر تو در توی `resolution` را نمایان می‌کند. | DYNAMIC_COMBO | خیر | `"kling-v3"` |
| `پرامپت` | توصیف متنی که تولید ویدیو را هدایت می‌کند. طول آن باید بین ۱ تا ۲۵۰۰ کاراکتر باشد. | STRING | بله | N/A |
| `مدت زمان` | طول ویدیو به ثانیه (پیش‌فرض: 5). | INT | خیر | 3 تا 15 |
| `اولین فریم` | تصویر شروع برای ویدیو. باید حداقل 300x300 پیکسل باشد و نسبت تصویر آن بین 1:2.5 و 2.5:1 باشد. | IMAGE | بله | N/A |
| `آخرین فریم` | تصویر پایان برای ویدیو. باید حداقل 300x300 پیکسل باشد و نسبت تصویر آن بین 1:2.5 و 2.5:1 باشد. | IMAGE | بله | N/A |
| `تولید صدا` | کنترل می‌کند که آیا برای ویدیو صدا تولید شود یا نه (پیش‌فرض: True). | BOOLEAN | خیر | N/A |
| `seed` | seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed نامعین هستند (پیش‌فرض: 0). | INT | خیر | 0 تا 2147483647 |

### ورودی‌های Kling V3

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `resolution` | رزولوشن ویدیوی تولیدشده (پیش‌فرض: `"1080p"`). | COMBO | خیر | `"4k"`<br>`"1080p"`<br>`"720p"` |

**نکته:** برای عملکرد صحیح گره، تصاویر `first_frame` و `end_frame` باید حداقل 300x300 پیکسل باشند و نسبت تصویر آن‌ها بین 1:2.5 و 2.5:1 باشد. `prompt` باید بین ۱ تا ۲۵۰۰ کاراکتر باشد. گزینه `resolution` به یک حالت تولید Kling نگاشت می‌شود: `"4k"`، `"1080p"` (حرفه‌ای) و `"720p"` (استاندارد).
