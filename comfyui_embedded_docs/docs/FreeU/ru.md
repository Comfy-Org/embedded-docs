# FreeU

Узел FreeU применяет модификации в частотной области к выходным блокам модели для повышения качества генерации изображений. Он работает путём масштабирования различных групп каналов и применения фильтрации Фурье к определённым картам признаков, что позволяет точнее управлять поведением модели в процессе генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяются модификации FreeU | MODEL | Да | - |
| `b1` | Коэффициент масштабирования backbone, применяемый к картам признаков с model_channels × 4 каналами (по умолчанию: 1.1). Отмечен как расширенная настройка. | FLOAT | Да | 0.0 - 10.0 |
| `b2` | Коэффициент масштабирования backbone, применяемый к картам признаков с model_channels × 2 каналами (по умолчанию: 1.2). Отмечен как расширенная настройка. | FLOAT | Да | 0.0 - 10.0 |
| `s1` | Коэффициент масштабирования skip-соединения, применяемый к картам признаков с model_channels × 4 каналами (по умолчанию: 0.9). Отмечен как расширенная настройка. | FLOAT | Да | 0.0 - 10.0 |
| `s2` | Коэффициент масштабирования skip-соединения, применяемый к картам признаков с model_channels × 2 каналами (по умолчанию: 0.2). Отмечен как расширенная настройка. | FLOAT | Да | 0.0 - 10.0 |

Примечание: Настройки FreeU применяются только к картам признаков, количество каналов которых равно model_channels × 4 (с использованием `b1` и `s1`) или model_channels × 2 (с использованием `b2` и `s2`). Фильтр Фурье масштабирует только центральную низкочастотную область (порог 1) карт признаков skip-соединения; все остальные частотные компоненты остаются без изменений. Все четыре параметра масштабирования принимают значения от 0.0 до 10.0 с шагом 0.01.
