# FreeU

Узел FreeU применяет модификации в частотной области к выходным блокам модели для улучшения качества генерации изображений. Он работает путем масштабирования различных групп каналов и применения фильтрации Фурье к определенным картам признаков, что позволяет точно контролировать поведение модели в процессе генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель, к которой применяются модификации FreeU | MODEL | Да | - |
| `b1` | Масштабный коэффициент основной ветви для карт признаков model_channels × 4 (по умолчанию: 1.1) | FLOAT | Да | 0.0 - 10.0 |
| `b2` | Масштабный коэффициент основной ветви для карт признаков model_channels × 2 (по умолчанию: 1.2) | FLOAT | Да | 0.0 - 10.0 |
| `s1` | Масштабный коэффициент пропускающего соединения для карт признаков model_channels × 4 (по умолчанию: 0.9) | FLOAT | Да | 0.0 - 10.0 |
| `s2` | Масштабный коэффициент пропускающего соединения для карт признаков model_channels × 2 (по умолчанию: 0.2) | FLOAT | Да | 0.0 - 10.0 |

Примечание: Модификации применяются только к картам признаков с каналами model_channels × 4 и model_channels × 2; параметры `b1`/`s1` влияют на первые, а `b2`/`s2` — на вторые. Остальные карты признаков остаются без изменений.

| Имя выхода | Описание | Тип данных |
