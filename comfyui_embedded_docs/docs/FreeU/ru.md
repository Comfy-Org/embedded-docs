# FreeU

Узел FreeU применяет частотные модификации к выходным блокам модели для улучшения качества генерации изображений. Он работает путем масштабирования различных групп каналов и применения фильтрации Фурье к определенным картам признаков, что обеспечивает точный контроль над поведением модели в процессе генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, к которой применяются модификации FreeU | MODEL | Да | - |
| `b1` | Коэффициент масштабирования основной сети для признаков model_channels × 4 (по умолчанию: 1.1) | FLOAT | Да | 0.0 - 10.0 |
| `b2` | Коэффициент масштабирования основной сети для признаков model_channels × 2 (по умолчанию: 1.2) | FLOAT | Да | 0.0 - 10.0 |
| `s1` | Коэффициент масштабирования пропускных соединений для признаков model_channels × 4 (по умолчанию: 0.9) | FLOAT | Да | 0.0 - 10.0 |
| `s2` | Коэффициент масштабирования пропускных соединений для признаков model_channels × 2 (по умолчанию: 0.2) | FLOAT | Да | 0.0 - 10.0 |

Примечание: Корректировки FreeU применяются только к картам признаков, количество каналов которых равно model_channels × 4 (с использованием `b1` и `s1`) или model_channels × 2 (с использованием `b2` и `s2`). Фильтр Фурье масштабирует только центральную низкочастотную область карт признаков пропускных соединений; все остальные частотные компоненты остаются неизменными.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model` | Модифицированная модель с примененными патчами FreeU | MODEL |
