# ImageYUVToRGB

Узел ImageYUVToRGB преобразует изображения из цветового пространства YUV в цветовое пространство RGB. Он принимает три отдельных входных изображения, представляющих компоненты Y (яркость), U (синяя проекция) и V (красная проекция), и объединяет их в одно RGB-изображение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `Y` | Входное изображение компонента Y (яркость). Если изображение имеет более трёх каналов, используются только первые три, которые усредняются в один канал. | IMAGE | Да | - |
| `U` | Входное изображение компонента U (синяя проекция). Если изображение имеет более трёх каналов, используются только первые три, которые усредняются в один канал. | IMAGE | Да | - |
| `V` | Входное изображение компонента V (красная проекция). Если изображение имеет более трёх каналов, используются только первые три, которые усредняются в один канал. | IMAGE | Да | - |

**Примечание:** Все три входных изображения (Y, U и V) должны быть предоставлены вместе и иметь совместимые размеры (совпадающие высота, ширина и размер пакета), чтобы преобразование успешно выполнилось.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Преобразованное RGB-изображение | IMAGE |
