# זיהוי נקודות פנים (MediaPipe)

## סקירה כללית

מזהה פנים בתמונה ומזהה 468 נקודות ציון (נקודות מפתח) על כל פנים באמצעות המודלים BlazeFace ו-FaceMesh של MediaPipe. כמו כן מחשב מקדמי בלנדשייפ ARKit-52 לניתוח הבעות פנים. הצומת יכול לעבד מספר תמונות באצווה ולפלוט גם את נתוני נקודות הציון וגם תיבות תוחמות עבור כל פנים שזוהו.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `face_detection_model` | מודל זיהוי הפנים של MediaPipe שיש להשתמש בו לזיהוי נקודות ציון. | FACE_DETECTION_MODEL | כן |  |
| `image` | תמונת הקלט או אצוות תמונות שבהן יש לזהות פנים. | IMAGE | כן |  |
| `detector_variant` | טווח גלאי הפנים. `"short"` מכוון לפנים בקרבה (עד ~2 מטר מהמצלמה); `"full"` מכסה פנים רחוקות/קטנות יותר (עד ~5 מטר) אך איטי יותר. `"both"` מריץ את שני הגלאים ושומר את זה שמצא יותר פנים בכל פריים (עלות זיהוי ~כפולה). ברירת מחדל: `"short"`. | COMBO | כן | `"short"`<br>`"full"`<br>`"both"` |
| `num_faces` | מספר הפנים המקסימלי להחזרה בכל פריים. 0 פירושו ללא הגבלה (החזר את כל הפנים שזוהו). ברירת מחדל: 1. | INT | כן | 0 to 16 |
| `min_confidence` | סף ניקוד BlazeFace. ערכים נמוכים יותר עוזרים לזהות פנים קטנות או מוסתרות. ברירת מחדל: 0.5. | FLOAT | לא | 0.00 to 1.00 |
| `missing_frame_fallback` | התנהגות לכל פריים כאשר הזיהוי נכשל באצווה. `"empty"` משאיר את הפריים ללא פנים. `"previous"` מעתיק את הזיהוי המוצלח האחרון. `"interpolate"` מבצע אינטרפולציה לינארית של נקודות ציון/תיבות תוחמות/בלנדשייפ בין פריימים מוצלחים תוחמים. ריבוי פנים: מתאים פנים בין פריימים באמצעות NN חמדני של מרכז תיבה תוחמת. ברירת מחדל: `"empty"`. | COMBO | לא | `"empty"`<br>`"previous"`<br>`"interpolate"` |

## פלטים

| שם פלט | תיאור | סוג נתונים |
