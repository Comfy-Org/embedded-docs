# Разделить сигмы для удаления шума

Узел SplitSigmasDenoise разделяет последовательность значений сигмы на две части на основе параметра силы шумоподавления. Он разбивает входные сигмы на последовательности с высокой и низкой сигмой, где точка разделения определяется умножением общего количества шагов на коэффициент шумоподавления. Это позволяет разделить график шума на различные диапазоны интенсивности для специализированной обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `сигмы` | Входная последовательность значений сигмы, представляющая график шума | SIGMAS | Да | - |
| `шумоподавление` | Коэффициент силы шумоподавления, определяющий точку разделения последовательности сигмы (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (step: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `высокие сигмы` | Первая часть последовательности сигмы, содержащая более высокие значения сигмы | SIGMAS |
| `низкие сигмы` | Вторая часть последовательности сигмы, содержащая более низкие значения сигмы | SIGMAS |
