# Разделить сигмы для удаления шума

Узел SplitSigmasDenoise делит последовательность значений сигм на две части на основе параметра силы шумоподавления. Он разделяет входные сигмы на последовательности высоких и низких сигм, где точка разделения определяется умножением общего количества шагов (на единицу меньше числа значений сигм) на коэффициент `denoise`. Это позволяет разделить расписание шума на различные диапазоны интенсивности для специализированной обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `сигмы` | Входная последовательность значений сигм, представляющая расписание шума | SIGMAS | Да | - |
| `шумоподавление` | Коэффициент силы шумоподавления, определяющий, где разделить последовательность сигм (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 (шаг: 0.01) |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `high_sigmas` | Первая часть последовательности сигм, содержащая более высокие значения сигм до точки разделения | SIGMAS |
| `low_sigmas` | Вторая часть последовательности сигм, содержащая более низкие значения сигм начиная с точки разделения | SIGMAS |
