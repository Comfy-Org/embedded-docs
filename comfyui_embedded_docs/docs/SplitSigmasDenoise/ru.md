# Разделить сигмы для удаления шума

Узел `SplitSigmasDenoise` разделяет последовательность значений сигмы на две части на основе параметра силы шумоподавления. Он разделяет входные сигмы на последовательности с высокой и низкой сигмой, при этом точка разделения определяется умножением общего количества шагов на коэффициент denoise. Это позволяет разделить график шума на диапазоны различной интенсивности для специализированной обработки.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
| --- | --- | --- | --- | --- |
| `sigmas` | Входная последовательность значений сигмы, представляющая график шума | SIGMAS | Да | - |
| `denoise` | Коэффициент силы шумоподавления, определяющий точку разделения последовательности сигм (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 1.0 |

Примечание: общее количество шагов равно количеству значений сигмы минус 1. Две выходные последовательности имеют одно общее значение сигмы в точке разделения. При `denoise` = 0.0, `high_sigmas` пуста; при `denoise` = 1.0, `high_sigmas` содержит только первое значение сигмы, а `low_sigmas` содержит полную последовательность.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `high_sigmas` | Первая часть последовательности сигм, содержащая более высокие значения сигмы | SIGMAS |
| `low_sigmas` | Вторая часть последовательности сигм, содержащая более низкие значения сигмы | SIGMAS |
