# シグマを分割してノイズ除去

SplitSigmasDenoise ノードは、ノイズ除去強度パラメータに基づいて、シグマ値のシーケンスを2つの部分に分割します。入力されたシグマを高いシグマ値のシーケンスと低いシグマ値のシーケンスに分割し、分割点は総ステップ数にノイズ除去係数を掛けて決定されます。これにより、ノイズスケジュールを異なる強度範囲に分離し、特殊な処理を行うことができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `sigmas` | ノイズスケジュールを表すシグマ値の入力シーケンス | SIGMAS | はい | - |
| `denoise` | シグマシーケンスを分割する位置を決定するノイズ除去強度係数（デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 |

注記: 総ステップ数は、シグマ値の数から1を引いた値です。2つの出力シーケンスは、分割点において1つのシグマ値を共有します。`denoise` が 0.0 の場合、`high_sigmas` は空になり、`denoise` が 1.0 の場合、`high_sigmas` は最初のシグマ値のみを含み、`low_sigmas` は完全なシーケンスを含みます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `high_sigmas` | 高いシグマ値を含むシグマシーケンスの最初の部分 | SIGMAS |
| `low_sigmas` | 低いシグマ値を含むシグマシーケンスの2番目の部分 | SIGMAS |
