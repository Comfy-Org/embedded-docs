# Google Gemini Decision (Score)

Оценивайте текст, изображения, аудио или видео, которые вы подключаете, по шкале от 1 до 10 и получайте оценку плюс логическое значение, которое переключается на заданном вами пороге. Используйте это для фильтрации или сортировки выходных данных, например чтобы оставлять только изображения с оценкой не ниже 7, и подключайте `result` к узлу If/Else Switch, чтобы выполнять по нему действия.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `question` | Что оценивать, с указанием того, что означают 1 и 10 (по умолчанию: "Rate the technical quality of the image from 1 (worst) to 10 (best)."). | STRING | Да | от 1 до 5000 символов |
| `threshold` | `result` равно True, когда оценка не меньше этого значения. Чистые резкие изображения получают оценку примерно 7–8, сильно повреждённые — примерно 3–5 (по умолчанию: 6.0). | FLOAT | Да | от 1.0 до 10.0 (шаг 0.1) |
| `images` | Изображения для оценки, до 16 в расширяемых слотах (`image_1` ... `image_16`). Пакет изображений учитывается по каждому изображению отдельно. | IMAGE | Нет | До 16 изображений |
| `audio` | Аудиоклип для оценки. | AUDIO | Нет | - |
| `video` | Видеоклип для оценки. | VIDEO | Нет | - |
| `text` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Подключите хотя бы один из параметров `text`, `images`, `audio` или `video`; узел вызывает ошибку, если оценивать нечего. При наличии нескольких изображений называйте их `image_1`, `image_2` и так далее в вопросе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `result` | True, когда оценка не меньше `threshold`, иначе False. | BOOLEAN |
| `score` | Оценка от 1 до 10. | FLOAT |
