# Google Gemini Decision (Score)

Оценивайте текст, изображения, аудио или видео, которые вы подключаете, по шкале от 1 до 10 и получайте оценку плюс логическое значение, которое переключается при заданном вами пороге. Используйте это для фильтрации или сортировки выходов, например чтобы оставлять только изображения с оценкой не ниже 7, и подключайте `result` к узлу If/Else Switch, чтобы действовать по результату. За один запуск оценивается всё, что вы подключили, как единое целое, поэтому для фильтрации отдельных изображений их нужно оценивать по одному.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель для использования (по умолчанию: `"gemini-decision-1"`). | COMBO | Да | `"gemini-decision-1"` |
| `вопрос` | Что оценивать, с пояснением, что означают 1 и 10 (по умолчанию: "Rate the technical quality of the image from 1 (worst) to 10 (best)."). | STRING | Да | от 1 до 5000 символов |
| `порог` | `result` имеет значение true, когда оценка не меньше этого значения. Чистые, резкие изображения получают оценку примерно от 7 до 8, сильно повреждённые — примерно от 3 до 5 (по умолчанию: 6.0). | FLOAT | Да | от 1.0 до 10.0 (шаг 0.1) |
| `изображения` | Изображения для оценки, до 16 в расширяемых слотах (`image_1` ... `image_16`). Изображение в пакете учитывается отдельно для каждого изображения. | IMAGE | Нет | До 16 изображений |
| `аудио` | Аудиоклип для оценки. | AUDIO | Нет | - |
| `видео` | Видеоклип для оценки. | VIDEO | Нет | - |
| `текст` | Текст, к которому относится вопрос, например промпт или ответ LLM, до 20000 символов. | STRING | Нет | До 20000 символов |

Подключите хотя бы один из параметров `text`, `images`, `audio` или `video`; узел выдаёт ошибку, если нечего оценивать. При использовании нескольких изображений называйте их `image_1`, `image_2` и так далее внутри вопроса.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `result` | True, когда оценка не меньше `threshold`, иначе false. | BOOLEAN |
| `score` | Оценка от 1 до 10. | FLOAT |
