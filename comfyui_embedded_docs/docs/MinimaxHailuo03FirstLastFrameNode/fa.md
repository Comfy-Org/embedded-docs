# MinimaxHailuo03FirstLastFrameNode

این گره با استفاده از مدل MiniMax H3، ویدیویی را از تصویر فریم اول و به‌صورت اختیاری تصویر فریم آخر تولید می‌کند. ویدیو از نسبت ابعاد تصاویر ارائه‌شده پیروی می‌کند و در صورت وجود فریم آخر، از فریم اول به سمت فریم آخر متحرک‌سازی می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید ویدیو. این ترکیب شامل انتخاب مدل («MiniMax H3»)، یک متن پرامپت توصیف‌کننده ویدیوی موردنظر، وضوح خروجی و مدت‌زمان ویدیو است. پرامپت باید حداقل یک نویسه غیرفاصله داشته باشد. | COMBO | بله | "MiniMax H3" |
| `first_frame` | تصویر فریم اول برای ویدیو. نسبت ابعاد ویدیوی تولیدشده از این تصویر پیروی می‌کند. باید حداقل ۲۵۶×۲۵۶ پیکسل با نسبت عرض به ارتفاع بین 0.4 و 2.5 باشد. | IMAGE | بله | - |
| `last_frame` | تصویر فریم آخر اختیاری برای ویدیو. در صورت ارائه، ویدیو از فریم اول شروع شده و به این تصویر ختم می‌شود. باید همان الزامات اندازه و نسبت ابعاد `first_frame` را برآورده کند. | IMAGE | خیر | - |
| `seed` | دانه تصادفی (seed). درخواست یکسان با همان seed نتایج مشابه اما نه لزوماً یکسان می‌دهد. شامل گزینه «کنترل پس از تولید» برای تصادفی‌سازی پس از هر تولید است. پیش‌فرض: 42. | INT | بله | 0 تا 4294967295 |
| `watermark` | آیا واترمارک AIGC به ویدیو اضافه شود. این یک پارامتر پیشرفته است. پیش‌فرض: False. | BOOLEAN | بله | True<br>False |

**نکته درباره محدودیت‌ها:**
- متن پرامپت داخل ترکیب `model` نمی‌تواند خالی باشد؛ پرامپت‌های فقط‌فاصله رد می‌شوند.
- هر تصویر فریم ارائه‌شده (`first_frame` و در صورت استفاده `last_frame`) باید حداقل ۲۵۶ پیکسل عرض و ۲۵۶ پیکسل ارتفاع داشته باشد، با نسبت عرض به ارتفاع بین 0.4 و 2.5 (تقریباً 2:5 تا 5:2).
- `last_frame` اختیاری است. در صورت حذف، ویدیو فقط از فریم اول تولید می‌شود.
- نسبت ابعاد ویدیوی خروجی توسط تصاویر ارائه‌شده تعیین می‌شود، نه توسط یک تنظیم نسبت جداگانه.
