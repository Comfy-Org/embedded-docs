# تبدیل اولین و آخرین فریم MiniMax H3 به ویدیو

این گره با استفاده از مدل MiniMax H3، ویدیویی از یک تصویر فریم اول و به‌صورت اختیاری یک تصویر فریم آخر تولید می‌کند. ویدیو از نسبت ابعاد تصاویر ارائه‌شده پیروی می‌کند و زمانی که فریم آخر ارائه شود، از فریم اول به سمت فریم آخر متحرک می‌شود.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید ویدیو. انتخاب یک مدل، تنظیمات خاص آن (پرامپت، رزولوشن، مدت‌زمان) را نمایش می‌دهد. | COMBO | بله | "MiniMax H3" |
| `first_frame` | تصویر فریم اول برای ویدیو. نسبت ابعاد ویدیوی تولیدشده از این تصویر پیروی می‌کند. باید حداقل 256×256 پیکسل با نسبت ابعاد عرض به ارتفاع بین 0.4 و 2.5 باشد. | IMAGE | بله | - |
| `last_frame` | تصویر فریم آخر اختیاری برای ویدیو. وقتی ارائه شود، ویدیو از فریم اول شروع شده و به این تصویر ختم می‌شود. باید همان الزامات اندازه و نسبت ابعاد `first_frame` را داشته باشد. | IMAGE | خیر | - |
| `seed` | seed تصادفی. درخواست یکسان با seed یکسان نتایج مشابهی می‌دهد، اما نتایج یکسان تضمین نمی‌شود. شامل گزینه «control after generate» برای تصادفی‌سازی پس از هر تولید است. پیش‌فرض: 42. | INT | بله | 0 تا 4294967295 |
| `watermark` | آیا به ویدیو واترمارک AIGC اضافه شود. این یک پارامتر پیشرفته است. پیش‌فرض: False. | BOOLEAN | بله | True<br>False |

### ورودی‌های MiniMax H3

این ورودی‌ها زمانی ظاهر می‌شوند که «MiniMax H3» در انتخابگر `model` انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن پرامپت برای تولید ویدیو. باید حداقل یک کاراکتر غیر از فضای خالی داشته باشد. | STRING | بله | - |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | "768P"<br>"2K" |
| `duration` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه (4 تا 15). پیش‌فرض: 5. | INT | بله | 4 تا 15 |

**نکته درباره محدودیت‌ها:**
- متن پرامپت داخل کومبوی `model` نمی‌تواند خالی باشد؛ پرامپت‌های فقط-فضای خالی رد می‌شوند.
- هر تصویر فریم ارائه‌شده (`first_frame` و در صورت استفاده، `last_frame`) باید حداقل 256 پیکسل عرض و 256 پیکسل ارتفاع داشته باشد، با نسبت ابعاد عرض به ارتفاع بین 0.4 تا 2.5 (تقریباً 2:5 تا 5:2).
- `last_frame` اختیاری است. وقتی حذف شود، ویدیو فقط از فریم اول تولید می‌شود.
- نسبت ابعاد ویدیوی خروجی توسط تصاویر ارائه‌شده تعیین می‌شود، نه توسط یک تنظیم نسبت جداگانه.
