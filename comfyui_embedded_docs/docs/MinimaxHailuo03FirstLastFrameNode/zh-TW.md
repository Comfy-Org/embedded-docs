# MiniMax H3 首末幀生成影片

此節點使用 MiniMax H3 模型，從第一幀影像和可選的最後一幀影像生成影片。影片遵循所提供影像的長寬比，當提供最後一幀時，會從第一幀動畫過渡到最後一幀。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片生成的模型。選擇模型會顯示其特定設定（提示詞、解析度、時長）。 | COMBO | 是 | "MiniMax H3" |
| `first_frame` | 影片的第一幀影像。生成影片的長寬比遵循此影像。必須至少為 256x256 像素，且寬高比介於 0.4 至 2.5 之間。 | IMAGE | 是 | - |
| `last_frame` | 可選的影片最後一幀影像。提供後，影片從第一幀開始，並以此影像結束。必須滿足與 `first_frame` 相同的尺寸和長寬比要求。 | IMAGE | 否 | - |
| `seed` | 隨機種子。相同種子的相同請求會產生相似但不保證完全相同的結果。包含「生成後控制」選項，可在每次生成後隨機化。預設值：42。 | INT | 是 | 0 至 4294967295 |
| `watermark` | 是否在影片中加入 AIGC 浮水印。這是一個進階參數。預設值：False。 | BOOLEAN | 是 | True<br>False |

### MiniMax H3 輸入

當在 `model` 選擇器中選取「MiniMax H3」時，會顯示這些輸入。

| 參數 | 說明 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 影片生成的文字提示詞。必須包含至少一個非空白字元。 | STRING | 是 | - |
| `resolution` | 輸出影片的解析度。 | COMBO | 是 | "768P"<br>"2K" |
| `duration` | 輸出影片的時長（秒），範圍為 4 至 15。預設值：5。 | INT | 是 | 4 至 15 |

**關於限制的注意事項：**
- `model` 下拉式選單中的文字提示詞不能為空；僅含空白的提示詞會被拒絕。
- 任何提供的幀影像（`first_frame` 以及使用的 `last_frame`）必須至少為 256 像素寬和 256 像素高，寬高比介於 0.4 至 2.5 之間（約 2:5 至 5:2）。
- `last_frame` 為可選。省略時，影片僅從第一幀生成。
- 輸出影片的長寬比由提供的影像決定，而非由單獨的長寬比設定決定。
