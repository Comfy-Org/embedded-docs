# MinimaxHailuo03FirstLastFrameNode

此節點使用 MiniMax H3 模型，從第一幀影像與可選的最後一幀影像生成影片。影片遵循所提供影像的長寬比；當提供最後一幀時，會從第一幀向最後一幀動畫過渡。

## 輸入

| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用於影片生成的模型。此下拉組合包含模型選擇（"MiniMax H3"）、描述要生成影片的文字提示、輸出解析度以及影片時長。提示必須至少包含一個非空白字元。 | COMBO | 是 | "MiniMax H3" |
| `first_frame` | 影片的第一幀影像。生成影片的長寬比遵循此影像。必須至少為 256x256 像素，寬高比介於 0.4 至 2.5 之間。 | IMAGE | 是 | - |
| `last_frame` | 可選的影片最後一幀影像。若提供，影片從第一幀開始，以該影像結束。必須符合與 `first_frame` 相同的大小和長寬比要求。 | IMAGE | 否 | - |
| `seed` | 隨機種子。相同請求與相同種子會給出相似但不保證完全相同的結果。包含「生成後控制」選項，可在每次生成後隨機化。預設值：42。 | INT | 是 | 0 至 4294967295 |
| `watermark` | 是否在影片中加入 AIGC 浮水印。此為進階參數。預設值：False。 | BOOLEAN | 是 | True<br>False |

**關於限制的說明：**

- `model` 下拉組合中的文字提示不能為空；僅含空白字元的提示會被拒絕。
- 任何提供的幀影像（`first_frame` 以及（若使用）`last_frame`）必須至少為 256 像素寬、256 像素高，寬高比介於 0.4 至 2.5（約 2:5 至 5:2）之間。
- `last_frame` 為可選。若省略，影片僅從第一幀生成。
- 輸出影片的長寬比由所提供影像決定，而非由單獨的比率設定決定。
