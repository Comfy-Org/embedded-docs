# MiniMax H3: видео по первому и последнему кадру

Этот узел генерирует видео на основе изображения первого кадра и, при необходимости, изображения последнего кадра с помощью модели MiniMax H3. Видео сохраняет соотношение сторон предоставленных изображений, а при наличии последнего кадра анимирует переход от первого кадра к последнему.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации видео. Выбор модели открывает её специфические настройки (запрос, разрешение, длительность). | DYNAMIC_COMBO | Да | "MiniMax H3" |
| `first_frame` | Изображение первого кадра видео. Соотношение сторон генерируемого видео соответствует этому изображению. Должно быть не менее 256x256 пикселей с соотношением ширины к высоте от 0.4 до 2.5. | IMAGE | Да | - |
| `last_frame` | Необязательное изображение последнего кадра видео. При его наличии видео начинается с первого кадра и заканчивается этим изображением. Должно соответствовать тем же требованиям к размеру и соотношению сторон, что и `first_frame`. | IMAGE | Нет | - |
| `seed` | Случайное зерно (seed). При одинаковом запросе и одинаковом seed результаты будут похожими, но не гарантированно идентичными. Включает опцию «control after generate» для рандомизации после каждой генерации. По умолчанию: 42. | INT | Да | 0 до 4294967295 |
| `watermark` | Определяет, добавлять ли AIGC-водяной знак к видео. Это расширенный параметр. По умолчанию: False. | BOOLEAN | Да | True<br>False |

### Входы MiniMax H3

Эти входы появляются, когда в селекторе `model` выбрано значение «MiniMax H3».

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `duration` | Длительность выходного видео в секундах (4-15). По умолчанию: 5. | INT | Да | 4 до 15 |

**Примечание об ограничениях:**
- Текстовый запрос внутри комбинированного списка `model` не может быть пустым; запросы, состоящие только из пробелов, отклоняются.
- Любое предоставленное изображение кадра (`first_frame` и, если используется, `last_frame`) должно быть не менее 256 пикселей в ширину и 256 пикселей в высоту, с соотношением ширины к высоте от 0.4 до 2.5 (приблизительно от 2:5 до 5:2).
- `last_frame` необязателен. При его отсутствии видео генерируется только из первого кадра.
- Соотношение сторон выходного видео определяется предоставленными изображениями, а не отдельной настройкой соотношения сторон.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, созданное из первого кадра и, при необходимости, последнего кадра с использованием модели MiniMax H3. | VIDEO |
