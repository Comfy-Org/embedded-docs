# MiniMax H3: видео по первому и последнему кадру

Этот узел генерирует видео из изображения первого кадра и, опционально, изображения последнего кадра с использованием моделей MiniMax H3. Селектор `model` изменяет, какие настройки генерации и ограничения применяются, а соотношение сторон сгенерированного видео соответствует соотношению сторон переданных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации видео. Выбор модели открывает её специфические настройки ниже. | DYNAMIC_COMBO | Да | "MiniMax H3"<br>"MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |
| `first_frame` | Изображение первого кадра для видео. Сгенерированное видео соответствует соотношению сторон этого изображения. | IMAGE | Да | - |
| `last_frame` | Необязательное изображение последнего кадра для видео. Если оно указано, видео генерируется от первого кадра к этому последнему кадру. | IMAGE | Нет | - |
| `seed` | Случайное зерно. Один и тот же запрос с одинаковым зерном даёт похожие, но не гарантированно идентичные результаты. Включает опцию «control after generate». По умолчанию: 42. | INT | Да | 0–4294967295 |
| `watermark` | Добавлять ли AIGC-водяной знак к видео. Это расширенный параметр. Поддерживается только моделью `MiniMax H3`. По умолчанию: False. | BOOLEAN | Да | True<br>False |

### Входы MiniMax H3

Эти настройки отображаются, когда в селекторе `model` выбрана `MiniMax H3`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `duration` | Длительность выходного видео в секундах. По умолчанию: 5. | INT | Да | 4–15 |

### Входы MiniMax H3 Max и MiniMax H3 Max Turbo

Эти настройки являются общими для `MiniMax H3 Max` и `MiniMax H3 Max Turbo`. Выбор любой из этих моделей открывает одни и те же настройки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый промпт для генерации видео. Не должен быть пустым или состоять только из пробельных символов; ограничен 50 000 символов. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: 768P. | COMBO | Да | "480P"<br>"768P" |
| `duration` | Длительность выходного видео в секундах. По умолчанию: 5. | INT | Да | 5–15 |
| `prompt_expansion_mode` | Насколько интенсивно переписывается промпт перед генерацией. По умолчанию: balanced. | COMBO | Да | "balanced"<br>"quality" |

**Примечания по ограничениям:**

- Промпт должен содержать текст: пустые промпты или промпты, состоящие только из пробельных символов, отклоняются.
- Любое переданное изображение кадра должно быть не менее 256 пикселей в ширину и 256 пикселей в высоту, а соотношение сторон ширина/высота должно быть от 0.4 до 2.5 (приблизительно от 2:5 до 5:2). Это требование применяется к `first_frame` и, если оно указано, к `last_frame`.
- Если `last_frame` не указан, видео генерируется только из первого кадра.
- Выходное видео соответствует соотношению сторон переданных изображений.
- `watermark` поддерживается только в `MiniMax H3`. Включение его с `MiniMax H3 Max` или `MiniMax H3 Max Turbo` вызывает ошибку.
- Диапазон длительности: от 4 до 15 секунд для `MiniMax H3` и от 5 до 15 секунд для `MiniMax H3 Max` и `MiniMax H3 Max Turbo`.

## Выходы
