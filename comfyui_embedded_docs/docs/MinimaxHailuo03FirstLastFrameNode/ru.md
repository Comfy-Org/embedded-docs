# MinimaxHailuo03FirstLastFrameNode

Этот узел генерирует видео из изображения первого кадра и, опционально, изображения последнего кадра с использованием модели MiniMax H3. Видео сохраняет соотношение сторон переданных изображений; если задан последний кадр, анимация происходит от первого кадра к последнему.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации видео. Этот комбинированный параметр включает выбор модели («MiniMax H3»), текстовый запрос (промпт), описывающий видео для генерации, разрешение вывода и длительность видео. Промпт должен содержать хотя бы один непробельный символ. | COMBO | Да | "MiniMax H3" |
| `first_frame` | Изображение первого кадра для видео. Соотношение сторон генерируемого видео соответствует этому изображению. Изображение должно быть не менее 256x256 пикселей, а соотношение ширины к высоте — от 0,4 до 2,5. | IMAGE | Да | - |
| `last_frame` | Необязательное изображение последнего кадра для видео. При его указании видео начинается с первого кадра и заканчивается этим изображением. Должно соответствовать тем же требованиям по размеру и соотношению сторон, что и `first_frame`. | IMAGE | Нет | - |
| `seed` | Случайное зерно (seed). Одинаковые запросы с одинаковым зерном дают похожие, но не гарантированно идентичные результаты. Включает опцию «control after generate» для рандомизации после каждой генерации. По умолчанию: 42. | INT | Да | от 0 до 4294967295 |
| `watermark` | Добавлять ли AIGC-водяной знак на видео. Это расширенный параметр. По умолчанию: False. | BOOLEAN | Да | True<br>False |

**Примечание об ограничениях:**
- Текстовый промпт внутри комбинированного параметра `model` не может быть пустым; промпты, состоящие только из пробелов, отклоняются.
- Любое переданное изображение кадра (`first_frame` и, если используется, `last_frame`) должно быть не менее 256 пикселей в ширину и 256 пикселей в высоту, с соотношением ширины к высоте от 0,4 до 2,5 (примерно от 2:5 до 5:2).
- Параметр `last_frame` необязателен. Если он не указан, видео генерируется только из первого кадра.
- Соотношение сторон выходного видео определяется переданными изображениями, а не отдельной настройкой соотношения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео, созданное из первого кадра и, опционально, последнего кадра с использованием модели MiniMax H3. | VIDEO |
