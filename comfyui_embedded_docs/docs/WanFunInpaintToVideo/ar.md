# وان تلوين ممتع إلى فيديو

تُهيّئ عقدة WanFunInpaintToVideo بيانات التكييف والكامن (latent) لتوليد فيديو بأسلوب الترميم الداخلي، باستخدام صورة بداية وصورة نهاية اختياريتين لتوجيه النتيجة. وتعمل عبر تمرير التكييف وVAE وإطارات الصور المزوّدة عبر المنطق نفسه المستخدم لتوليد الفيديو بإطار أول وآخر، ثم تُعيد التكييف المحدّث بالإضافة إلى كامن فارغ لأخذ العينات.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مطالبات التكييف الإيجابية لتوليد الفيديو | CONDITIONING | نعم | - |
| `negative` | مطالبات التكييف السلبية لتجنّبها في توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE المستخدم لترميز وفك ترميز إطارات الفيديو | VAE | نعم | - |
| `width` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو المراد توليدها في دفعة واحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `clip_vision_output` | مخرج رؤية CLIP الاختياري المستخدم كتكييف لصورة البداية | CLIP_VISION_OUTPUT | لا | - |
| `start_image` | صورة الإطار الابتدائي الاختيارية لتوليد الفيديو | IMAGE | لا | - |
| `end_image` | صورة الإطار النهائي الاختيارية لتوليد الفيديو | IMAGE | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | مخرج التكييف الإيجابي المعالج | CONDITIONING |
| `negative` | مخرج التكييف السلبي المعالج | CONDITIONING |
| `latent` | تمثيل الكامن للفيديو المولّد | LATENT |
