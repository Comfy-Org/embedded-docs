# وان تلوين ممتع إلى فيديو

تنشئ عقدة WanFunInpaintToVideo تسلسلات فيديو عن طريق استكمال الصور بين صورتي البداية والنهاية. تأخذ العقدة شروطًا إيجابية وسلبية إلى جانب صور إطارات اختيارية لتوليد التمثيلات الكامنة للفيديو. تتعامل العقدة مع توليد الفيديو مع معاملات أبعاد وطول قابلة للتكوين.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `positive` | مطالبات التهيئة الإيجابية لتوليد الفيديو | CONDITIONING | نعم | - |
| `negative` | مطالبات التهيئة السلبية لتجنبها أثناء توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لعمليات التشفير وفك التشفير | VAE | نعم | - |
| `width` | عرض فيديو الإخراج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `height` | ارتفاع فيديو الإخراج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 إلى MAX_RESOLUTION |
| `length` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 إلى MAX_RESOLUTION |
| `batch_size` | عدد مقاطع الفيديو المراد توليدها في دفعة واحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `clip_vision_output` | مخرج رؤية CLIP اختياري لتهيئة إضافية | CLIP_VISION_OUTPUT | لا | - |
| `start_image` | صورة إطار بداية اختيارية لتوليد الفيديو | IMAGE | لا | - |
| `end_image` | صورة إطار نهاية اختيارية لتوليد الفيديو | IMAGE | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | مخرج التهيئة الإيجابية المُعالَج | CONDITIONING |
| `negative` | مخرج التهيئة السلبية المُعالَج | CONDITIONING |
| `latent` | تمثيل الفيديو الكامن المُولَّد | LATENT |
