# وان تلوين ممتع إلى فيديو

تنشئ عقدة WanFunInpaintToVideo تسلسلات فيديو عبر تقنية inpainting بين صورتي البداية والنهاية. تأخذ العقدة تكييفًا موجبًا وسالبًا (positive and negative conditioning) بالإضافة إلى صور إطارات اختيارية لتوليد تمثيلات الفيديو الكامنة (video latents). تدير العقدة توليد الفيديو مع أبعاد ومعاملات طول قابلة للتكوين.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `إيجابي` | مطالبات الشرط الموجب لتوليد الفيديو | CONDITIONING | نعم | - |
| `سلبي` | مطالبات الشرط السالب لتجنبها في توليد الفيديو | CONDITIONING | نعم | - |
| `vae` | نموذج VAE لعمليات الترميز وفك الترميز | VAE | نعم | - |
| `العرض` | عرض الفيديو الناتج بالبكسل (الافتراضي: 832، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الفيديو الناتج بالبكسل (الافتراضي: 480، الخطوة: 16) | INT | نعم | 16 to MAX_RESOLUTION |
| `الطول` | عدد الإطارات في تسلسل الفيديو (الافتراضي: 81، الخطوة: 4) | INT | نعم | 1 to MAX_RESOLUTION |
| `حجم الدفعة` | عدد الفيديوهات المولدة في الدفعة الواحدة (الافتراضي: 1) | INT | نعم | 1 إلى 4096 |
| `ناتج رؤية الكليب` | مخرج رؤية CLIP اختياري يُستخدم كشرط لصورة البداية | CLIP_VISION_OUTPUT | لا | - |
| `صورة البداية` | صورة إطار البداية الاختيارية لتوليد الفيديو | IMAGE | لا | - |
| `صورة النهاية` | صورة إطار النهاية الاختيارية لتوليد الفيديو | IMAGE | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `إيجابي` | مخرج التكييف الإيجابي المعالج | CONDITIONING |
| `سلبي` | مخرج التكييف السلبي المعالج | CONDITIONING |
| `مضمر` | التمثيل الكامن للفيديو المُولَّد | LATENT |
