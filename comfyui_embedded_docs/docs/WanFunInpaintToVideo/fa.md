# WanFunInpaintToVideo

گره WanFunInpaintToVideo با درون‌پرکنی (inpainting) بین تصاویر شروع و پایان، توالی‌های ویدیویی ایجاد می‌کند. این گره شرطی‌سازی مثبت و منفی را به همراه تصاویر فریم اختیاری دریافت کرده و لاتنت‌های ویدیویی تولید می‌کند. این گره تولید ویدیو را با ابعاد و طول قابل تنظیم مدیریت می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `positive` | پرامپت‌های شرطی‌سازی مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی‌سازی منفی برای اجتناب در تولید ویدیو | CONDITIONING | بله | - |
| `vae` | مدل VAE برای عملیات رمزگذاری/رمزگشایی | VAE | بله | - |
| `width` | عرض ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `height` | ارتفاع ویدیوی خروجی بر حسب پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 to MAX_RESOLUTION |
| `length` | تعداد فریم‌های توالی ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `batch_size` | تعداد ویدیوهای تولید شده در یک دسته (پیش‌فرض: 1) | INT | بله | 1 to 4096 |
| `clip_vision_output` | خروجی اختیاری CLIP vision برای شرطی‌سازی اضافی | CLIP_VISION_OUTPUT | خیر | - |
| `start_image` | تصویر فریم شروع اختیاری برای تولید ویدیو | IMAGE | خیر | - |
| `end_image` | تصویر فریم پایان اختیاری برای تولید ویدیو | IMAGE | خیر | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | خروجی شرطی‌سازی مثبت پردازش‌شده | CONDITIONING |
| `negative` | خروجی شرطی‌سازی منفی پردازش‌شده | CONDITIONING |
| `latent` | نمایش لاتنت ویدیوی تولیدشده | LATENT |
