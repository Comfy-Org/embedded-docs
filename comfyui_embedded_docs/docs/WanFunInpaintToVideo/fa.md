# WanFunInpaintToVideo

گره WanFunInpaintToVideo با ترمیم (inpainting) میان تصاویر شروع و پایان، توالی‌های ویدیویی ایجاد می‌کند. این گره، شرط‌گذاری مثبت و منفی (positive و negative conditioning) را همراه با فریم‌های تصویری اختیاری دریافت کرده و latentهای ویدیویی تولید می‌کند. این گره تولید ویدیو را با ابعاد و طول قابل‌تنظیم انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مثبت` | پرامپت‌های شرط‌گذاری مثبت برای تولید ویدیو | CONDITIONING | بله | - |
| `منفی` | پرامپت‌های شرط‌گذاری منفی که در تولید ویدیو باید از آن‌ها اجتناب شود | CONDITIONING | بله | - |
| `vae` | مدل VAE برای عملیات کدگذاری/کدگشایی | VAE | بله | - |
| `عرض` | عرض ویدیوی خروجی به پیکسل (پیش‌فرض: 832، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `ارتفاع` | ارتفاع ویدیوی خروجی به پیکسل (پیش‌فرض: 480، گام: 16) | INT | بله | 16 تا MAX_RESOLUTION |
| `طول` | تعداد فریم‌های توالی ویدیو (پیش‌فرض: 81، گام: 4) | INT | بله | 1 تا MAX_RESOLUTION |
| `اندازه دسته` | تعداد ویدیوهایی که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | بله | 1 تا 4096 |
| `خروجی clip vision` | خروجی اختیاری CLIP vision که به‌عنوان شرط‌گذاری برای تصویر شروع استفاده می‌شود | CLIP_VISION_OUTPUT | خیر | - |
| `تصویر شروع` | تصویر فریم شروع اختیاری برای تولید ویدیو | IMAGE | خیر | - |
| `تصویر پایان` | تصویر فریم پایان اختیاری برای تولید ویدیو | IMAGE | خیر | - |
