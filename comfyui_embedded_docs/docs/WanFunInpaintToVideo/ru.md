# WanFunInpaintToVideo

Узел WanFunInpaintToVideo создает видеопоследовательности путем инпейнтинга между начальным и конечным изображениями. Он принимает положительный и отрицательный кондишининг, а также необязательные кадры изображений для генерации латентных представлений видео. Узел выполняет генерацию видео с настраиваемыми параметрами размеров и длины.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительные промпты кондишининга для генерации видео | CONDITIONING | Да | - |
| `негативный` | Отрицательные промпты кондишининга, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `vae` | Модель VAE для операций кодирования/декодирования | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `размер_пакета` | Количество видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 до 4096 |
| `clip_vision_output` | Необязательный выход CLIP vision, используемый как кондишининг для начального изображения | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное начальное изображение кадра для генерации видео | IMAGE | Нет | - |
| `конечное_изображение` | Необязательное конечное изображение кадра для генерации видео | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитивный` | Обработанный положительный выход кондишининга | CONDITIONING |
| `негативный` | Обработанный отрицательный выход кондишининга | CONDITIONING |
| `latent` | Сгенерированное латентное представление видео | LATENT |
