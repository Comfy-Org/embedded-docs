# WanFunInpaintToVideo

Узел WanFunInpaintToVideo создает видеопоследовательности путем инпейнтинга между начальным и конечным изображениями. Он принимает положительные и отрицательные кондиционирования вместе с дополнительными кадрами для генерации видео-латентов. Узел выполняет генерацию видео с настраиваемыми параметрами размеров и длины.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные промпты кондиционирования для генерации видео | CONDITIONING | Да | - |
| `negative` | Отрицательные промпты кондиционирования, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `vae` | Модель VAE для операций кодирования/декодирования | VAE | Да | - |
| `width` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `height` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | 16 to MAX_RESOLUTION |
| `length` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `batch_size` | Количество видео для генерации в одном пакете (по умолчанию: 1) | INT | Да | 1 to 4096 |
| `clip_vision_output` | Необязательный вывод CLIP vision для дополнительного кондиционирования | CLIP_VISION_OUTPUT | Нет | - |
| `start_image` | Необязательное начальное изображение кадра для генерации видео | IMAGE | Нет | - |
| `end_image` | Необязательное конечное изображение кадра для генерации видео | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанный выход положительного кондиционирования | CONDITIONING |
| `negative` | Обработанный выход отрицательного кондиционирования | CONDITIONING |
| `latent` | Сгенерированное латентное представление видео | LATENT |
