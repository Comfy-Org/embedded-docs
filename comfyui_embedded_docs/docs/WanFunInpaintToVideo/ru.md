# WanFunInpaintToVideo

Узел WanFunInpaintToVideo подготавливает кондиционирование и латентные данные для генерации видео в стиле inpainting, используя необязательные начальное и конечное изображения для управления результатом. Он работает путём передачи предоставленного кондиционирования, VAE и кадров изображений через ту же логику, которая используется при генерации видео по первому и последнему кадру, и возвращает обновлённое кондиционирование, а также пустой латент для сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `позитивный` | Положительные кондиционирующие промпты для генерации видео | CONDITIONING | Да | - |
| `негативный` | Негативные кондиционирующие промпты, которых следует избегать при генерации видео | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования и декодирования кадров видео | VAE | Да | - |
| `ширина` | Ширина выходного видео в пикселях (по умолчанию: 832, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `высота` | Высота выходного видео в пикселях (по умолчанию: 480, шаг: 16) | INT | Да | от 16 до MAX_RESOLUTION |
| `длина` | Количество кадров в видеопоследовательности (по умолчанию: 81, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `размер_пакета` | Количество видео для генерации в пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |
| `clip_vision_output` | Необязательный вывод CLIP vision, используемый как кондиционирование для начального изображения | CLIP_VISION_OUTPUT | Нет | - |
| `начальное_изображение` | Необязательное изображение начального кадра для генерации видео | IMAGE | Нет | - |
| `конечное_изображение` | Необязательное изображение конечного кадра для генерации видео | IMAGE | Нет | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанный выход положительного кондиционирования | CONDITIONING |
| `negative` | Обработанный выход отрицательного кондиционирования | CONDITIONING |
| `latent` | Латентное представление сгенерированного видео | LATENT |
