# WanFunInpaintToVideo

הצומת WanFunInpaintToVideo מכין קונדישנינג ונתוני latent ליצירת וידאו בסגנון inpainting, תוך שימוש בתמונת התחלה ובתמונת סיום אופציונליות כדי להנחות את התוצאה. הוא פועל על ידי העברת הקונדישנינג, ה-VAE ופריימי התמונה שסופקו דרך אותה לוגיקה המשמשת ליצירת וידאו עם פריים ראשון ואחרון, ומחזיר קונדישנינג מעודכן בתוספת latent ריק לדגימה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `positive` | פרומפטים של קונדישנינג חיובי ליצירת וידאו | CONDITIONING | כן | - |
| `negative` | פרומפטים של קונדישנינג שלילי שיש להימנע מהם ביצירת וידאו | CONDITIONING | כן | - |
| `vae` | מודל VAE המשמש לקידוד ופענוח של פריימי הווידאו | VAE | כן | - |
| `width` | רוחב וידאו הפלט בפיקסלים (ברירת מחדל: 832, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `height` | גובה וידאו הפלט בפיקסלים (ברירת מחדל: 480, צעד: 16) | INT | כן | 16 עד MAX_RESOLUTION |
| `length` | מספר הפריימים ברצף הווידאו (ברירת מחדל: 81, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `batch_size` | מספר הווידאו שיש ליצור באצווה (ברירת מחדל: 1) | INT | כן | 1 עד 4096 |
| `clip_vision_output` | פלט CLIP vision אופציונלי המשמש כקונדישנינג לתמונת ההתחלה | CLIP_VISION_OUTPUT | לא | - |
| `start_image` | תמונת פריים התחלה אופציונלית ליצירת וידאו | IMAGE | לא | - |
| `end_image` | תמונת פריים סיום אופציונלית ליצירת וידאו | IMAGE | לא | - |
