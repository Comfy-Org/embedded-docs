# CombineHooksFour

הצומת Combine Hooks [4] ממזג עד ארבע קבוצות hook נפרדות לקבוצת hook משולבת אחת. הוא מקבל כל שילוב של ארבעת קלטי ה-hook הזמינים ומשלב אותם באמצעות מערכת שילוב ה-hooks של ComfyUI. הדבר מאפשר לאחד מספר תצורות hook לעיבוד יעיל בתהליכי עבודה מתקדמים.

## קלטים

| פרמטר | תיאור | סוג נתונים | סוג קלט | ברירת מחדל | טווח |
| --- | --- | --- | --- | --- | --- |
| `hooks_A` | קבוצת ה-hook הראשונה לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_B` | קבוצת ה-hook השנייה לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_C` | קבוצת ה-hook השלישית לשילוב | HOOKS | אופציונלי | None | - |
| `hooks_D` | קבוצת ה-hook הרביעית לשילוב | HOOKS | אופציונלי | None | - |

**הערה:** כל ארבעת קלטי ה-hook אופציונליים. הצומת ישלב רק את קבוצות ה-hook שסופקו, ויחזיר קבוצת hook ריקה אם לא מחוברים קלטים.
