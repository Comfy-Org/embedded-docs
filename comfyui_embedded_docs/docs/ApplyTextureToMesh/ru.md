# Применить текстуру к mesh

Этот узел прикрепляет изображения запечённых текстур к UV-разметке меша, чтобы их можно было экспортировать вместе с мешем с помощью узла SaveGLB. Подайте на него тот же UV-развёрнутый меш, с которого вы запекали текстуры, вместе с запечёнными картами изображений. Необязательные карты metallic, roughness и occlusion упаковываются в единую текстуру ORM, а при подаче карты нормалей также сохраняются сглаженные нормали вершин и касательный базис, необходимые для корректного затенения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | UV-развёрнутый меш, к которому будут прикреплены запечённые текстуры. Должен быть тем же мешем, который использовался при запекании; если у меша нет UV, возникает ошибка. | MESH | Да | — |
| `base_color` | Запечённое изображение базового цвета. Сохраняется как текстура меша и ограничивается диапазоном 0–1. | IMAGE | Да | — |
| `metallic` | Запечённая карта metallic. Используется как синий канал объединённой текстуры ORM; по умолчанию равна 0, если не указана. | IMAGE | Нет | — |
| `roughness` | Запечённая карта roughness. Используется как зелёный канал объединённой текстуры ORM; по умолчанию равна 1, если не указана. | IMAGE | Нет | — |
| `occlusion` | Запечённая карта occlusion. Используется как красный канал объединённой текстуры ORM; по умолчанию равна 1, если не указана. Когда она предоставлена, текстура ORM также помечается как текстура occlusion для SaveGLB. | IMAGE | Нет | — |
| `normal_map` | Запечённая карта нормалей в касательном пространстве. Если она предоставлена, узел пересчитывает касательные для каждой вершины и экспортирует сглаженные нормали вершин, чтобы карта нормалей корректно затенялась. | IMAGE | Нет | — |

Примечание: Вход `mesh` должен иметь UV-координаты; если их нет, узел выдаёт ошибку с просьбой подключить тот же UV-развёрнутый меш, который использовался для запекания.

Примечание: Когда подключён любой из входов `metallic`, `roughness` или `occlusion`, все три упаковываются в единую текстуру glTF ORM с каналами R = occlusion, G = roughness, B = metallic. Отсутствующие карты заполняются значениями по умолчанию (occlusion 1, roughness 1, metallic 0), а карты с разными разрешениями масштабируются до наибольшей ширины и высоты среди предоставленных карт.

Примечание: Когда подключён `normal_map`, сохранённые нормали меша заменяются вычисленными сглаженными нормалями вершин и добавляется касательный базис для каждой вершины. UV-координаты, выходящие за пределы диапазона [0,1], равномерно масштабируются в [0,1] с сохранением соотношения сторон; если UV-разброс выглядит как тайловый/UDIM-макет, записывается предупреждение. Для пакетных мешей нормализация UV применяется отдельно к каждому элементу пакета по той же логике, что и на этапе запекания, поэтому оба остаются согласованными.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входной меш с прикреплёнными к его UV-разметке изображениями текстур, готовый к сохранению узлом SaveGLB. | MESH |
