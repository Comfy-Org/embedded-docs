# ApplyTextureToMesh

Этот узел прикрепляет запечённые изображения текстур к UV-развёртке меша, чтобы их можно было экспортировать вместе с мешем с помощью узла SaveGLB. Подключите ту же UV-развёртку меша, которую вы использовали для запекания, вместе с запечёнными картами изображений. Дополнительные карты металличности, шероховатости и окклюзии упаковываются в единую текстуру ORM, а при подаче карты нормалей также сохраняются сглаженные нормали и касательные, необходимые для корректного затенения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Меш с UV-развёрткой, к которому будут прикреплены запечённые текстуры. Должен быть тем же мешем, который использовался при запекании; если у меша нет UV-координат, будет вызвана ошибка. | MESH | Да | — |
| `base_color` | Запечённое изображение базового цвета. Сохраняется как текстура меша и ограничивается диапазоном 0–1. | IMAGE | Да | — |
| `metallic` | Запечённая карта металличности. Используется как синий канал объединённой текстуры ORM; по умолчанию равна 0, если не задана. | IMAGE | Нет | — |
| `roughness` | Запечённая карта шероховатости. Используется как зелёный канал объединённой текстуры ORM; по умолчанию равна 1, если не задана. | IMAGE | Нет | — |
| `occlusion` | Запечённая карта окклюзии окружающего света. Используется как красный канал объединённой текстуры ORM; по умолчанию равна 1, если не задана. При наличии карты текстура ORM также помечается как текстура окклюзии для SaveGLB. | IMAGE | Нет | — |
| `normal_map` | Запечённая карта нормалей в касательном пространстве. Если она задана, узел пересчитывает касательный базис для каждой вершины и экспортирует сглаженные вершинные нормали, чтобы карта нормалей затенялась корректно. | IMAGE | Нет | — |

Примечание: Если подключена любая из карт `metallic`, `roughness` или `occlusion`, все три упаковываются в единую glTF-текстуру ORM с каналами R = окклюзия, G = шероховатость, B = металличность. Отсутствующие карты заполняются значениями по умолчанию (окклюзия 1, шероховатость 1, металличность 0), а карты с разным разрешением масштабируются до наибольшей ширины и высоты. Если подключена карта `normal_map`, нормали меша заменяются вычисленными сглаженными вершинными нормалями и добавляется касательный базис. UV-координаты, выходящие за пределы диапазона [0,1], равномерно масштабируются в [0,1] с сохранением пропорций.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входной меш с прикреплёнными к его UV-развёртке изображениями текстур, готовый к сохранению с помощью SaveGLB. | MESH |
