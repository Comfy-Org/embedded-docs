# 將紋理套用至網格

此節點會將烘焙後的紋理影像附加到網格的 UV 佈局，以便能與網格一起由 SaveGLB 節點匯出。請將您烘焙紋理時所用的同一個已展開 UV 的網格，連同烘焙後的影像貼圖一併輸入。選用的金屬度、粗糙度與環境光遮蔽貼圖會被打包成單一 ORM 紋理；若提供法線貼圖，也會儲存正確著色所需的平滑頂點法線與切線基底。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 將附加烘焙紋理的已展開 UV 網格。必須與烘焙期間使用的網格相同；若網格沒有 UV，會引發錯誤。 | MESH | 是 | — |
| `base_color` | 烘焙後的基礎顏色影像。會儲存為網格的紋理，並限制在 0-1 範圍內。 | IMAGE | 是 | — |
| `metallic` | 烘焙後的金屬度貼圖。用作合併 ORM 紋理的藍色通道；未提供時預設為 0。 | IMAGE | 否 | — |
| `roughness` | 烘焙後的粗糙度貼圖。用作合併 ORM 紋理的綠色通道；未提供時預設為 1。 | IMAGE | 否 | — |
| `occlusion` | 烘焙後的環境光遮蔽貼圖。用作合併 ORM 紋理的紅色通道；未提供時預設為 1。提供時，ORM 紋理也會被標記為 SaveGLB 的環境光遮蔽紋理。 | IMAGE | 否 | — |
| `normal_map` | 烘焙後的切線空間法線貼圖。提供時，此節點會重新計算每個頂點的切線，並匯出平滑頂點法線，使法線貼圖能正確著色。 | IMAGE | 否 | — |

注意：`mesh` 輸入必須具有 UV 座標；若沒有，節點會引發錯誤，要求您連接烘焙時所用的同一個已展開 UV 網格。

注意：當 `metallic`、`roughness` 或 `occlusion` 任一項連接時，三者會被打包成單一 glTF ORM 紋理，通道為 R = `occlusion`、G = `roughness`、B = `metallic`。缺少的貼圖會以預設值填入（`occlusion` 為 1、`roughness` 為 1、`metallic` 為 0），而解析度不同的貼圖會調整大小為所提供貼圖中最大的寬度與高度。

注意：當連接 `normal_map` 時，網格儲存的法線會替換為計算出的平滑頂點法線，並新增每個頂點的切線基底。落在 [0,1] 範圍外的 UV 座標會以等比例均勻縮放到 [0,1] 內；若 UV 跨度看起來像平鋪/UDIM 佈局，會記錄一則警告。對於批次網格，UV 正規化會使用與烘焙步驟相同的邏輯分別套用到批次中的每個項目，因此兩者會保持一致。
