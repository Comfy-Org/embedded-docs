# LTXV Загрузчик аудио-текстового энкодера

---

Этот узел загружает специализированный текстовый энкодер для аудиомодели LTXV. Он объединяет файл текстового энкодера с файлом контрольной точки (checkpoint) для создания модели CLIP, которую можно использовать для задач кондиционирования текста, связанных с аудио. Согласно описанию рецепта узла, текстовый энкодер LTXV audio должен быть моделью Gemma 3 12B или совместимой моделью Gemma 4.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `text_encoder` | Имя файла текстового энкодера LTXV для загрузки. Доступные варианты загружаются из папки `text_encoders`. | COMBO | Да | Доступно несколько вариантов |
| `ckpt_name` | Имя файла контрольной точки для загрузки. Доступные варианты загружаются из папки `checkpoints`. | COMBO | Да | Доступно несколько вариантов |
| `device` | Указывает устройство, на которое будет загружена модель. Используйте `"cpu"`, чтобы принудительно загрузить модель на ЦП. Поведение по умолчанию (`"default"`) использует автоматическое размещение устройства в системе (по умолчанию: `"default"`). | COMBO | Нет | `"default"`<br>`"cpu"` |

**Примечание:** Параметры `text_encoder` и `ckpt_name` работают вместе. Узел загружает оба указанных файла для создания единой функциональной модели CLIP. Файлы должны быть совместимы с архитектурой LTXV.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `clip` | Загруженная модель CLIP LTXV, готовая к использованию для кодирования текстовых подсказок для генерации аудио. | CLIP |
