# LTXV Загрузчик аудио-текстового энкодера

Этот узел загружает специализированный текстовый энкодер для аудиомодели LTXV. Он объединяет файл текстового энкодера с файлом чекпоинта для создания модели CLIP, используемой для текстового кондиционирования при генерации аудио. Согласно описанию узла, текстовый энкодер должен быть моделью Gemma 3 12B или совместимой моделью Gemma 4.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `text_encoder` | Имя файла модели текстового энкодера LTXV для загрузки. Доступные варианты загружаются из папки `text_encoders`. | COMBO | Да | Доступно несколько вариантов |
| `ckpt_name` | Имя файла чекпоинта для загрузки. Доступные варианты загружаются из папки `checkpoints`. | COMBO | Да | Доступно несколько вариантов |
| `device` | Указывает устройство, на которое загружается модель. Используйте `"cpu"`, чтобы принудительно загрузить модель на ЦП. Поведение по умолчанию (`"default"`) использует автоматическое размещение на устройстве, выбранное системой (по умолчанию: `"default"`). Это дополнительный параметр. | COMBO | No | `"default"`<br>`"cpu"` |

**Примечание:** Параметры `text_encoder` и `ckpt_name` работают вместе. Узел загружает оба указанных файла для создания единой рабочей модели CLIP. Файлы должны быть совместимы с архитектурой LTXV, а текстовый энкодер должен быть моделью Gemma 3 12B или совместимой моделью Gemma 4.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `clip` | Загруженная модель CLIP LTXV, готовая к использованию для кодирования текстовых промптов при генерации аудио. | CLIP |
