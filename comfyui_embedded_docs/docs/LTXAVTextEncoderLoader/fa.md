# بارگذاری رمزگذار متنی LTXV Audio

این گره یک رمزگذار متن تخصصی برای مدل صوتی LTXV بارگذاری می‌کند. این گره یک فایل رمزگذار متن را با یک فایل checkpoint ترکیب می‌کند تا یک مدل CLIP ایجاد کند که می‌تواند برای وظایف شرطی‌سازی متن مرتبط با صدا استفاده شود. طبق توضیحات دستور پخت گره، رمزگذار متن صوتی LTXV باید یک مدل Gemma 3 12B یا یک مدل Gemma 4 سازگار باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `text_encoder` | نام فایل مدل رمزگذار متن LTXV که باید بارگذاری شود. گزینه‌های موجود از پوشه `text_encoders` بارگذاری می‌شوند. | COMBO | بله | چند گزینه موجود است |
| `ckpt_name` | نام فایل checkpoint که باید بارگذاری شود. گزینه‌های موجود از پوشه `checkpoints` بارگذاری می‌شوند. | COMBO | بله | چند گزینه موجود است |
| `device` | دستگاهی را که مدل روی آن بارگذاری می‌شود مشخص می‌کند. برای اجبار به بارگذاری روی CPU از `"cpu"` استفاده کنید. رفتار پیش‌فرض (`"default"`) از مکان‌دهی خودکار دستگاه توسط سیستم استفاده می‌کند (پیش‌فرض: `"default"`). | COMBO | خیر | `"default"`<br>`"cpu"` |

**نکته:** پارامترهای `text_encoder` و `ckpt_name` با هم کار می‌کنند. این گره هر دو فایل مشخص‌شده را بارگذاری می‌کند تا یک مدل CLIP واحد و کاربردی ایجاد کند. فایل‌ها باید با معماری LTXV سازگار باشند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `clip` | مدل CLIP بارگذاری‌شده LTXV، آماده برای استفاده در رمزگذاری پرامپت‌های متنی برای تولید صدا. | CLIP |
