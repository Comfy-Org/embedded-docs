# بارگذاری رمزگذار متنی LTXV Audio

این گره یک رمزگذار متنی تخصصی برای مدل صوتی LTXV بارگذاری می‌کند. این گره یک فایل رمزگذار متنی را با یک فایل checkpoint ترکیب می‌کند تا یک مدل CLIP برای شرطی‌سازی متن در تولید صدا ایجاد کند. بنا بر توضیحات گره، رمزگذار متنی باید Gemma 3 12B یا مدل سازگار Gemma 4 باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `رمزگذار متنی` | نام فایل مدل رمزگذار متنی LTXV برای بارگذاری. گزینه‌های موجود از پوشه `text_encoders` بارگذاری می‌شوند. | COMBO | بله | گزینه‌های متعدد موجود است |
| `نام checkpoint` | نام فایل checkpoint برای بارگذاری. گزینه‌های موجود از پوشه `checkpoints` بارگذاری می‌شوند. | COMBO | بله | گزینه‌های متعدد موجود است |
| `دستگاه` | دستگاه مورد نظر برای بارگذاری مدل را مشخص می‌کند. برای اجبار بارگذاری روی CPU از `"cpu"` استفاده کنید. رفتار پیش‌فرض (`"default"`) از جای‌گذاری خودکار دستگاه توسط سیستم استفاده می‌کند (پیش‌فرض: `"default"`). این یک پارامتر پیشرفته است. | COMBO | خیر | `"default"`<br>`"cpu"` |

**توجه:** پارامترهای `text_encoder` و `ckpt_name` با هم کار می‌کنند. گره هر دو فایل مشخص‌شده را بارگذاری می‌کند تا یک مدل CLIP واحد و کاربردی ایجاد کند. فایل‌ها باید با معماری LTXV سازگار باشند و رمزگذار متنی باید Gemma 3 12B یا مدل سازگار Gemma 4 باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `clip` | مدل CLIP بارگذاری‌شده LTXV، آماده برای استفاده در رمزگذاری پرامپت‌های متنی برای تولید صدا. | CLIP |
