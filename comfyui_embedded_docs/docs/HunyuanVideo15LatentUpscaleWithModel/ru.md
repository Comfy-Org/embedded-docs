# Hunyuan Video 15 Latent Upscale With Model

Узел **Hunyuan Video 15 Latent Upscale With Model** увеличивает разрешение скрытого представления изображения (latent image). Сначала он повышает разрешение скрытых семплов (latent samples) до указанного размера с помощью выбранного метода интерполяции, а затем уточняет полученный результат с помощью специализированной модели увеличения Hunyuan Video 1.5 для повышения качества.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель увеличения Hunyuan Video 1.5, используемая для уточнения увеличенных семплов. | LATENT_UPSCALE_MODEL | Да | N/A |
| `samples` | Скрытое представление изображения, которое необходимо увеличить. | LATENT | Да | N/A |
| `upscale_method` | Алгоритм интерполяции, используемый для начального этапа увеличения (по умолчанию: `"bilinear"`). | COMBO | Нет | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `width` | Целевая ширина увеличенного скрытого представления в пикселях. Значение 0 позволяет вычислить ширину автоматически на основе целевой высоты и исходного соотношения сторон. Итоговая ширина будет кратна 16 (по умолчанию: 1280). | INT | Нет | от 0 до 16384 (шаг 8) |
| `height` | Целевая высота увеличенного скрытого представления в пикселях. Значение 0 позволяет вычислить высоту автоматически на основе целевой ширины и исходного соотношения сторон. Итоговая высота будет кратна 16 (по умолчанию: 720). | INT | Нет | от 0 до 16384 (шаг 8) |
| `crop` | Определяет, как увеличенное скрытое представление обрезается для соответствия целевым размерам. | COMBO | Нет | `"disabled"`<br>`"center"` |

**Примечание о размерах:** Если и `width`, и `height` установлены в 0, узел возвращает входные `samples` без изменений. Если только одно измерение установлено в 0, другое вычисляется для сохранения исходного соотношения сторон. Итоговые размеры всегда корректируются так, чтобы быть не менее 64 пикселей и кратными 16.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
