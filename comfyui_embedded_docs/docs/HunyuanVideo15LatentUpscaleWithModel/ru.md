# Hunyuan Video 15 Latent Upscale With Model

Узел Hunyuan Video 15 Latent Upscale With Model увеличивает разрешение латентного представления изображения. Сначала он увеличивает латентные сэмплы до заданного размера с помощью выбранного метода интерполяции, затем уточняет полученный результат с использованием специализированной модели увеличения разрешения Hunyuan Video 1.5 для повышения качества.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель увеличения разрешения латентного пространства Hunyuan Video 1.5, используемая для уточнения увеличенных сэмплов. | LATENT_UPSCALE_MODEL | Да | N/A |
| `samples` | Латентное представление изображения, которое необходимо увеличить. | LATENT | Да | N/A |
| `upscale_method` | Алгоритм интерполяции, используемый на начальном этапе увеличения разрешения (по умолчанию: `"bilinear"`). | COMBO | Нет | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `width` | Целевая ширина увеличенного латента в пикселях. Значение 0 автоматически вычисляет ширину на основе целевой высоты и исходного соотношения сторон. Итоговая ширина выходного изображения будет кратна 16 (по умолчанию: 1280). | INT | Нет | 0 до 16384 (step: 8) |
| `height` | Целевая высота увеличенного латента в пикселях. Значение 0 автоматически вычисляет высоту на основе целевой ширины и исходного соотношения сторон. Итоговая высота выходного изображения будет кратна 16 (по умолчанию: 720). | INT | Нет | 0 до 16384 (step: 8) |
| `crop` | Определяет, как увеличенный латент обрезается для соответствия целевым размерам. | COMBO | Нет | `"disabled"`<br>`"center"` |

**Примечание о размерах:** Если и `width`, и `height` равны 0, узел возвращает входные `samples` без изменений. Если только один из размеров равен 0, другой вычисляется так, чтобы сохранить исходное соотношение сторон. Итоговые размеры всегда корректируются так, чтобы быть не менее 64 пикселей и кратными 16.
