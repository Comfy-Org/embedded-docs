# Hunyuan Video 15 Latent Upscale With Model

Узел Hunyuan Video 15 Latent Upscale With Model повышает разрешение латентного представления изображения. Сначала он увеличивает латентные образцы до заданного размера с помощью выбранного метода интерполяции, а затем улучшает результат апскейла с использованием специализированной модели апскейла Hunyuan Video 1.5 для повышения качества.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель латентного апскейла Hunyuan Video 1.5, используемая для улучшения увеличенных образцов. | LATENT_UPSCALE_MODEL | Да | N/A |
| `samples` | Латентное представление изображения, которое нужно увеличить. | LATENT | Да | N/A |
| `upscale_method` | Алгоритм интерполяции, используемый на начальном этапе увеличения (по умолчанию: `"bilinear"`). | COMBO | Да | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `width` | Целевая ширина увеличенного латента в пикселях. Значение 0 означает, что ширина будет рассчитана автоматически на основе целевой высоты и исходного соотношения сторон. Итоговая ширина выхода будет кратна 16 (по умолчанию: 1280). | INT | Да | от 0 до 16384 (шаг: 8) |
| `height` | Целевая высота увеличенного латента в пикселях. Значение 0 означает, что высота будет рассчитана автоматически на основе целевой ширины и исходного соотношения сторон. Итоговая высота выхода будет кратна 16 (по умолчанию: 720). | INT | Да | от 0 до 16384 (шаг: 8) |
| `crop` | Определяет, как увеличенный латент обрезается, чтобы соответствовать целевым размерам. | COMBO | Да | `"disabled"`<br>`"center"` |

**Примечание о размерах:** Если и `width`, и `height` равны 0, узел возвращает входной `samples` без изменений. Если только один размер равен 0, другой рассчитывается с сохранением исходного соотношения сторон. Оба значения ограничиваются снизу значением 64, а целевой размер для апскейла, передаваемый на этап интерполяции, равен `width // 16` на `height // 16`, поэтому запрошенные размеры фактически округляются вниз до кратных 16.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `LATENT` | Увеличенное и улучшенное моделью латентное представление изображения, возвращаемое как тензор типа float на CPU. | LATENT |
