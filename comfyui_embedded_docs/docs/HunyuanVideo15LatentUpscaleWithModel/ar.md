# Hunyuan Video 15 تكبير latent بالنموذج

عقدة Hunyuan Video 15 Latent Upscale With Model تزيد دقة تمثيل الصورة الكامن. تقوم أولاً بتكبير العينات الكامنة إلى حجم محدد باستخدام طريقة استيفاء مختارة، ثم تحسّن النتيجة المكبّرة باستخدام نموذج تكبير Hunyuan Video 1.5 المتخصص لتحسين الجودة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `النموذج` | نموذج التكبير الكامن Hunyuan Video 1.5 المستخدم لتحسين العينات المكبّرة. | LATENT_UPSCALE_MODEL | نعم | N/A |
| `العينات` | تمثيل الصورة الكامن المراد تكبيره. | LATENT | نعم | N/A |
| `طريقة التكبير` | خوارزمية الاستيفاء المستخدمة في خطوة التكبير الأولية (الافتراضي: `"bilinear"`). | COMBO | نعم | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `العرض` | العرض الهدف للعنصر الكامن المكبّر، بالبكسل. القيمة 0 ستحسب العرض تلقائيًا استنادًا إلى الارتفاع الهدف ونسبة الأبعاد الأصلية. سيكون عرض المخرجات النهائي من مضاعفات 16 (الافتراضي: 1280). | INT | نعم | 0 إلى 16384 (الخطوة: 8) |
| `الارتفاع` | الارتفاع الهدف للعنصر الكامن المكبّر، بالبكسل. القيمة 0 ستحسب الارتفاع تلقائيًا استنادًا إلى العرض الهدف ونسبة الأبعاد الأصلية. سيكون ارتفاع المخرجات النهائي من مضاعفات 16 (الافتراضي: 720). | INT | نعم | 0 إلى 16384 (الخطوة: 8) |
| `اقتصاص` | يحدد كيفية اقتصاص العنصر الكامن المكبّر ليلائم الأبعاد الهدف. | COMBO | نعم | `"disabled"`<br>`"center"` |

**ملاحظة حول الأبعاد:** إذا كانت كل من `width` و`height` مضبوطتين على 0، فستعيد العقدة `samples` المدخلة دون تغيير. إذا تم ضبط بُعد واحد فقط على 0، فسيُحسب البُعد الآخر للحفاظ على نسبة الأبعاد الأصلية. يتم تثبيت كلتا القيمتين بحد أدنى 64، ويكون هدف التكبير الذي يُمرر إلى خطوة الاستيفاء هو `width // 16` × `height // 16`، لذا يتم تقريب الأبعاد المطلوبة فعليًا للأسفل إلى مضاعفات 16.
