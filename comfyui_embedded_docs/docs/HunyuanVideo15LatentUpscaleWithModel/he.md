# הגדלת latent של Hunyuan Video 1.5 באמצעות מודל

הצומת Hunyuan Video 15 Latent Upscale With Model מגדיל את הרזולוציה של ייצוג תמונה לטנטי. תחילה הוא מגדיל את דגימות ה-latent לגודל מוגדר באמצעות שיטת אינטרפולציה נבחרת, ולאחר מכן מעדן את התוצאה המוגדלת באמצעות מודל הגדלה ייעודי של Hunyuan Video 1.5 לשיפור האיכות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הגדלת ה-latent של Hunyuan Video 1.5 המשמש לעידון הדגימות המוגדלות. | LATENT_UPSCALE_MODEL | כן | N/A |
| `samples` | ייצוג התמונה הלטנטי שיש להגדיל. | LATENT | כן | N/A |
| `upscale_method` | אלגוריתם האינטרפולציה המשמש בשלב ההגדלה הראשוני (ברירת מחדל: `"bilinear"`). | COMBO | כן | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `width` | רוחב היעד של ה-latent המוגדל, בפיקסלים. ערך 0 יחשב את הרוחב אוטומטית בהתאם לגובה היעד וליחס הגובה-רוחב המקורי. רוחב הפלט הסופי יהיה כפולה של 16 (ברירת מחדל: 1280). | INT | כן | 0 עד 16384 (צעד: 8) |
| `height` | גובה היעד של ה-latent המוגדל, בפיקסלים. ערך 0 יחשב את הגובה אוטומטית בהתאם לרוחב היעד וליחס הגובה-רוחב המקורי. גובה הפלט הסופי יהיה כפולה של 16 (ברירת מחדל: 720). | INT | כן | 0 עד 16384 (צעד: 8) |
| `crop` | קובע כיצד ה-latent המוגדל נחתך כדי להתאים למידות היעד. | COMBO | כן | `"disabled"`<br>`"center"` |

**הערה לגבי מידות:** אם גם `width` וגם `height` מוגדרים ל-0, הצומת מחזיר את הקלט `samples` ללא שינוי. אם רק מימד אחד מוגדר ל-0, המימד האחר מחושב כדי לשמור על יחס הגובה-רוחב המקורי. שני הערכים מוגבלים למינימום של 64, ויעד ההגדלה המועבר לשלב האינטרפולציה הוא `width // 16` על `height // 16`, כך שהמידות המבוקשות למעשה מעוגלות כלפי מטה לכפולות של 16.
