# بزرگ‌نمایی Latent ویدیو ۱۵ با مدل

گره Hunyuan Video 15 Latent Upscale With Model وضوح یک نمایش تصویر نهفته (latent) را افزایش می‌دهد. ابتدا نمونه‌های نهفته را با استفاده از روش درون‌یابی انتخاب‌شده به اندازه‌ای مشخص بزرگ‌نمایی می‌کند، سپس نتیجه بزرگ‌نمایی‌شده را با یک مدل تخصصی بزرگ‌نمایی Hunyuan Video 1.5 برای بهبود کیفیت پالایش می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل بزرگ‌نمایی نهفته Hunyuan Video 1.5 که برای پالایش نمونه‌های بزرگ‌نمایی‌شده استفاده می‌شود. | LATENT_UPSCALE_MODEL | بله | N/A |
| `نمونه‌ها` | نمایش تصویر نهفته‌ای که باید بزرگ‌نمایی شود. | LATENT | بله | N/A |
| `روش بزرگ‌نمایی` | الگوریتم درون‌یابی استفاده‌شده برای مرحله بزرگ‌نمایی اولیه (پیش‌فرض: `"bilinear"`). | COMBO | بله | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `عرض` | عرض هدف برای latent بزرگ‌نمایی‌شده، بر حسب پیکسل. مقدار 0 عرض را به‌صورت خودکار بر اساس ارتفاع هدف و نسبت ابعاد اصلی محاسبه می‌کند. عرض خروجی نهایی مضربی از 16 خواهد بود (پیش‌فرض: 1280). | INT | بله | 0 تا 16384 (گام: 8) |
| `ارتفاع` | ارتفاع هدف برای latent بزرگ‌نمایی‌شده، بر حسب پیکسل. مقدار 0 ارتفاع را به‌صورت خودکار بر اساس عرض هدف و نسبت ابعاد اصلی محاسبه می‌کند. ارتفاع خروجی نهایی مضربی از 16 خواهد بود (پیش‌فرض: 720). | INT | بله | 0 تا 16384 (گام: 8) |
| `برش` | تعیین می‌کند که latent بزرگ‌نمایی‌شده چگونه برای تطابق با ابعاد هدف برش داده شود. | COMBO | بله | `"disabled"`<br>`"center"` |

**نکته درباره ابعاد:** اگر هر دو `width` و `height` روی 0 تنظیم شوند، گره ورودی `samples` را بدون تغییر برمی‌گرداند. اگر فقط یک بُعد روی 0 تنظیم شود، بُعد دیگر برای حفظ نسبت ابعاد اصلی محاسبه می‌شود. هر دو مقدار حداقل به 64 محدود می‌شوند، و هدف بزرگ‌نمایی که به مرحله درون‌یابی داده می‌شود `width // 16` در `height // 16` است، بنابراین ابعاد درخواستی به‌طور مؤثر به مضرب‌های 16 به پایین گرد می‌شوند.
