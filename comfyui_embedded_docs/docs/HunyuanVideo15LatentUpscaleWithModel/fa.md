# بزرگ‌نمایی Latent ویدیو ۱۵ با مدل

گره «Hunyuan Video 15 Latent Upscale With Model» وضوح نمایش تصویر نهفته (latent) را افزایش می‌دهد. این گره ابتدا نمونه‌های نهفته را با استفاده از یک روش درون‌یابی انتخابی به اندازه مشخصی بزرگ‌نمایی می‌کند، سپس نتیجه بزرگ‌شده را با استفاده از یک مدل بزرگ‌نمایی تخصصی Hunyuan Video 1.5 برای بهبود کیفیت، پردازش می‌کند.
