# بزرگ‌نمایی Latent ویدیو ۱۵ با مدل

گره «Hunyuan Video 1.5 Latent Upscale With Model» وضوح بازنمایی لاتنت تصویر را افزایش می‌دهد. ابتدا نمونه‌های لاتنت را با استفاده از یک روش درون‌یابی انتخاب‌شده به اندازه مشخص‌شده بزرگ‌نمایی می‌کند، سپس نتیجه بزرگ‌شده را با استفاده از یک مدل تخصصی بزرگ‌نمایی Hunyuan Video 1.5 برای بهبود کیفیت، پالایش می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل بزرگ‌نمایی لاتنت Hunyuan Video 1.5 که برای پالایش نمونه‌های بزرگ‌شده استفاده می‌شود. | LATENT_UPSCALE_MODEL | بله | N/A |
| `samples` | بازنمایی لاتنت تصویری که قرار است بزرگ‌نمایی شود. | LATENT | بله | N/A |
| `upscale_method` | الگوریتم درون‌یابی مورد استفاده برای مرحله بزرگ‌نمایی اولیه (پیش‌فرض: `"bilinear"`). | COMBO | خیر | `"nearest-exact"`<br>`"bilinear"`<br>`"area"`<br>`"bicubic"`<br>`"bislerp"` |
| `width` | عرض هدف برای لاتنت بزرگ‌شده، بر حسب پیکسل. مقدار ۰ باعث می‌شود عرض به‌صورت خودکار بر اساس ارتفاع هدف و نسبت ابعاد اصلی محاسبه شود. عرض نهایی خروجی مضربی از ۱۶ خواهد بود (پیش‌فرض: ۱۲۸۰). | INT | خیر | 0 تا 16384 (گام 8) |
| `height` | ارتفاع هدف برای لاتنت بزرگ‌شده، بر حسب پیکسل. مقدار ۰ باعث می‌شود ارتفاع به‌صورت خودکار بر اساس عرض هدف و نسبت ابعاد اصلی محاسبه شود. ارتفاع نهایی خروجی مضربی از ۱۶ خواهد بود (پیش‌فرض: ۷۲۰). | INT | خیر | 0 تا 16384 (گام 8) |
| `crop` | تعیین می‌کند لاتنت بزرگ‌شده چگونه برای تطبیق با ابعاد هدف برش بخورد. | COMBO | خیر | `"disabled"`<br>`"center"` |

**نکته درباره ابعاد:** اگر هر دو `width` و `height` برابر ۰ باشند، گره همان `samples` ورودی را بدون تغییر برمی‌گرداند. اگر فقط یکی از ابعاد برابر ۰ باشد، بُعد دیگر برای حفظ نسبت ابعاد اصلی محاسبه می‌شود. ابعاد نهایی همیشه حداقل ۶۴ پیکسل تنظیم می‌شوند و بر ۱۶ بخش‌پذیر هستند.
