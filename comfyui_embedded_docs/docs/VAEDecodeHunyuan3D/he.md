# פענוח VAE של Hunyuan 3D

הצומת VAEDecodeHunyuan3D ממיר ייצוגים חבויים לנתוני ווקסל תלת-ממדיים באמצעות מפענח VAE. הוא מעביר את דגימות ה-latent דרך מודל ה-VAE עם הגדרות פיצול ורזולוציה הניתנות להגדרה, כדי ליצור נתונים נפחיים המתאימים ליישומי תלת-ממד.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `samples` | הייצוג החבוי שיש לפענח לנתוני ווקסל תלת-ממדיים | LATENT | כן | - |
| `vae` | מודל ה-VAE המשמש לפענוח דגימות ה-latent | VAE | כן | - |
| `num_chunks` | מספר המקטעים שאליהם מפצלים את העיבוד לצורך ניהול זיכרון. פרמטר מתקדם (ברירת מחדל: 8000) | INT | כן | 1000-500000 |
| `octree_resolution` | הרזולוציה של מבנה ה-octree המשמשת ליצירת ווקסלים תלת-ממדיים. פרמטר מתקדם (ברירת מחדל: 256) | INT | כן | 16-512 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `voxels` | נתוני הווקסל התלת-ממדיים שנוצרו מהייצוג החבוי המפוענח | VOXEL |
