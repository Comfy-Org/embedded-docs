# فك ترميز VAE Hunyuan3D

تقوم عقدة `VAEDecodeHunyuan3D` بتحويل التمثيلات الكامنة إلى بيانات فوكسل ثلاثية الأبعاد باستخدام مفكك ترميز VAE. تعالج العينات الكامنة عبر نموذج VAE مع إعدادات قابلة للتهيئة للتقسيم والدقة لتوليد بيانات حجمية مناسبة للتطبيقات ثلاثية الأبعاد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `samples` | التمثيل الكامن الذي سيتم فك ترميزه إلى بيانات فوكسل ثلاثية الأبعاد | LATENT | نعم | - |
| `vae` | نموذج VAE المستخدم لفك ترميز العينات الكامنة | VAE | نعم | - |
| `num_chunks` | عدد الأجزاء المستخدمة لتقسيم المعالجة لأغراض إدارة الذاكرة (الافتراضي: 8000) | INT | نعم | 1000-500000 |
| `octree_resolution` | دقة بنية الشجرة الثمانية المستخدمة لتوليد الفوكسل ثلاثي الأبعاد (الافتراضي: 256) | INT | نعم | 16-512 |

ملاحظة: `num_chunks` و `octree_resolution` معاملات متقدمة.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `voxels` | بيانات الفوكسل ثلاثية الأبعاد المولدة من التمثيل الكامن المفكك | VOXEL |
