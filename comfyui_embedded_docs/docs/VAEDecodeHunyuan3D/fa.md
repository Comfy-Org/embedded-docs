# VAEDecodeHunyuan3D

گره VAEDecodeHunyuan3D با استفاده از یک رمزگشای VAE، نمایش‌های نهفته (latent) را به داده‌های وکسل سه‌بعدی تبدیل می‌کند. این گره نمونه‌های نهفته را با تنظیمات قابل‌پیکربندی تکه‌بندی و وضوح، از طریق مدل VAE پردازش می‌کند تا داده‌های حجمی مناسب برای کاربردهای سه‌بعدی تولید کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `نمونه‌ها` | نمایش نهفته‌ای که باید به داده‌های وکسل سه‌بعدی رمزگشایی شود | LATENT | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگشایی نمونه‌های نهفته | VAE | بله | - |
| `تعداد بخش‌ها` | تعداد تکه‌هایی که پردازش برای مدیریت حافظه به آن‌ها تقسیم می‌شود. پارامتر پیشرفته (پیش‌فرض: 8000) | INT | بله | 1000-500000 |
| `وضوح octree` | وضوح ساختار هشت‌درختی (Octree) مورد استفاده برای تولید وکسل سه‌بعدی. پارامتر پیشرفته (پیش‌فرض: 256) | INT | بله | 16-512 |
