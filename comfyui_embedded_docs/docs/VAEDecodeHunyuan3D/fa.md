# VAEDecodeHunyuan3D

گره VAEDecodeHunyuan3D با استفاده از یک رمزگشای VAE، بازنمایی‌های نهان را به داده‌های وکسل سه‌بعدی تبدیل می‌کند. این گره نمونه‌های نهان را با تنظیمات قابل‌پیکربندی تکه‌بندی و وضوح، از طریق مدل VAE پردازش می‌کند تا داده‌های حجمی مناسب برای برنامه‌های سه‌بعدی تولید کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `samples` | بازنمایی نهانی که باید به داده وکسل سه‌بعدی رمزگشایی شود | LATENT | بله | - |
| `vae` | مدل VAE مورد استفاده برای رمزگشایی نمونه‌های نهان | VAE | بله | - |
| `num_chunks` | تعداد تکه‌هایی که پردازش برای مدیریت حافظه به آن‌ها تقسیم می‌شود (پیش‌فرض: 8000) | INT | بله | 1000-500000 |
| `octree_resolution` | وضوح ساختار هشت‌درختی مورد استفاده برای تولید وکسل سه‌بعدی (پیش‌فرض: 256) | INT | بله | 16-512 |

نکته: `num_chunks` و `octree_resolution` پارامترهای پیشرفته هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `voxels` | داده وکسل سه‌بعدی تولیدشده از بازنمایی نهان رمزگشایی‌شده | VOXEL |
