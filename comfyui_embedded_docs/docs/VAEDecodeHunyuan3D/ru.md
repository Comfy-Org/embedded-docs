# VAEDecodeHunyuan3D

Узел VAEDecodeHunyuan3D преобразует скрытые представления в 3D-данные вокселей с помощью декодера VAE. Он обрабатывает скрытые образцы через модель VAE с настраиваемыми параметрами разбиения на чанки и разрешения для генерации объемных данных, подходящих для 3D-приложений.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `samples` | Скрытое представление, которое должно быть декодировано в 3D-данные вокселей | LATENT | Да | - |
| `vae` | Модель VAE, используемая для декодирования скрытых представлений | VAE | Да | - |
| `num_chunks` | Количество чанков, на которые разбивается обработка для управления памятью (по умолчанию: 8000) | INT | Да | 1000-500000 |
| `octree_resolution` | Разрешение октодерева, используемого для генерации 3D-вокселей (по умолчанию: 256) | INT | Да | 16-512 |

Примечание: `num_chunks` и `octree_resolution` являются дополнительными (продвинутыми) параметрами.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voxels` | Сгенерированные 3D-данные вокселей из декодированного скрытого представления | VOXEL |
