# تنظیم نوع Union ControlNet

گره SetUnionControlNetType به شما امکان می‌دهد نوع کنترل یک شبکه کنترلی مورد استفاده برای شرطی‌سازی را تنظیم کنید. این گره یک شبکه کنترلی موجود را دریافت می‌کند، یک نسخه تغییر یافته از آن ایجاد می‌کند و نوع کنترل انتخابی را در آن نسخه ذخیره می‌کند تا نسخه اصلی بدون تغییر باقی بماند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `control_net` | شبکه کنترلی که باید با نوع کنترل انتخابی کپی و تغییر یابد | CONTROL_NET | بله | - |
| `type` | نوع کنترلی که باید روی شبکه کنترلی کپی‌شده اعمال شود. برای بدون تنظیم ماندن نوع کنترل، «auto» را انتخاب کنید، یا یک نوع خاص از انواع شبکه کنترل اتحاد موجود را انتخاب کنید (پیش‌فرض: «auto») | COMBO | بله | `"auto"`<br>`"openpose"`<br>`"depth"`<br>`"hed/pidi/scribble/ted"`<br>`"canny/softedge"`<br>`"normal/bms"`<br>`"seg"`<br>`"inpaint"`<br>`"lineart"`<br>`"s4"`<br>`"tile/color"`<br>`"blur"`<br>`"identity"` |

توجه: وقتی `type` برابر با «auto» باشد، فهرست نوع کنترل روی شبکه کنترلی کپی‌شده پاک می‌شود. وقتی یک نوع خاص انتخاب شود، شبکه کنترلی کپی‌شده شماره نوع متناظر را ذخیره می‌کند.
