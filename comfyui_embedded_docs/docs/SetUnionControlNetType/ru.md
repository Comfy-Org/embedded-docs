# Установить тип объединенного ControlNet

Узел SetUnionControlNetType позволяет выбрать, какой тип управления использует ControlNet. Он принимает существующий ControlNet и создаёт изменённую копию с выбранным типом управления, оставляя исходный ControlNet без изменений. Когда выбрано "auto", сохранённый тип управления очищается, чтобы тип можно было определить автоматически.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `control_net` | ControlNet для изменения с новой настройкой типа | CONTROL_NET | Да | - |
| `тип` | Тип ControlNet для применения. Используйте "auto" для автоматического определения типа или выберите конкретный тип ControlNet из доступных вариантов (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"openpose"`<br>`"depth"`<br>`"hed/pidi/softedge"`<br>`"canny"`<br>`"scribble"`<br>`"seg"`<br>`"tile"`<br>`"inpaint"`<br>`"lineart"`<br>`"blur"`<br>`"mlsd"`<br>`"normalbae"`<br>`"mask"` |

Когда для `type` установлено `"auto"`, узел очищает сохранённый тип управления, чтобы тип можно было определить автоматически. Когда выбран конкретный тип, узел сохраняет соответствующий тип управления в скопированном ControlNet. Входной ControlNet никогда не изменяется на месте; вместо этого возвращается изменённая копия.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `control_net` | Изменённый ControlNet с применённой указанной настройкой типа | CONTROL_NET |
