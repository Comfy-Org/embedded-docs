# Установить тип объединенного ControlNet

Узел SetUnionControlNetType позволяет выбрать, какой тип управления использует сеть управления. Он принимает существующую сеть управления и создает измененную копию с выбранным типом управления, оставляя исходную сеть управления без изменений. Когда выбрано значение «auto», сохраненный тип управления очищается, чтобы тип мог определяться автоматически.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `control_net` | Сеть управления для изменения с новой настройкой типа | CONTROL_NET | Да | - |
| `тип` | Применяемый тип сети управления. Используйте «auto» для автоматического определения типа или выберите конкретный тип сети управления из доступных опций (по умолчанию: «auto») | COMBO | Да | `"auto"`<br>`"openpose"`<br>`"depth"`<br>`"hed/pidi/softedge"`<br>`"canny"`<br>`"scribble"`<br>`"seg"`<br>`"tile"`<br>`"inpaint"`<br>`"lineart"`<br>`"blur"`<br>`"mlsd"`<br>`"normalbae"`<br>`"mask"` |

Когда для параметра `type` установлено значение `"auto"`, узел очищает сохраненный тип управления, чтобы тип мог определяться автоматически. Когда выбран конкретный тип, узел сохраняет соответствующий тип управления в скопированной сети управления.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `control_net` | Измененная сеть управления с примененной указанной настройкой типа | CONTROL_NET |
