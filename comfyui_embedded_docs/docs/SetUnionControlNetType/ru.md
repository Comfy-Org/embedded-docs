# Установить тип объединенного ControlNet

Узел SetUnionControlNetType позволяет задать тип управления для управляющей сети, используемой для кондиционирования. Он принимает существующую управляющую сеть, создаёт её модифицированную копию и сохраняет выбранный тип управления в этой копии, чтобы оригинал остался без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `control_net` | Управляющая сеть, которую нужно скопировать и изменить с помощью выбранного типа управления | CONTROL_NET | Да | - |
| `type` | Тип управления, применяемый к скопированной управляющей сети. Выберите `"auto"`, чтобы оставить тип управления не заданным, или выберите конкретный тип из доступных типов объединённой управляющей сети (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"openpose"`<br>`"depth"`<br>`"hed/pidi/scribble/ted"`<br>`"canny/softedge"`<br>`"normal/bms"`<br>`"seg"`<br>`"inpaint"`<br>`"lineart"`<br>`"s4"`<br>`"tile/color"`<br>`"blur"`<br>`"identity"` |

Примечание: когда `type` имеет значение "auto", список типов управления в скопированной управляющей сети очищается. Когда выбран конкретный тип, скопированная управляющая сеть сохраняет соответствующий номер типа.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `control_net` | Модифицированная копия управляющей сети с применённым выбранным типом управления | CONTROL_NET |
