# Tripo: רב-תצוגה למודל

צומת זה יוצר מודלים תלת-ממדיים באופן סינכרוני באמצעות ה-API של Tripo, על ידי עיבוד של עד ארבע תמונות המציגות זוויות שונות של אובייקט (חזית, שמאל, אחור, ימין). הוא דורש תמונת חזית ולפחות זווית נוספת אחת (שמאל, אחור או ימין) כדי לבנות את המודל התלת-ממדי. ניתן לשלוט בצומת על טקסטורה, חומר PBR, איכות גאומטריה ופורמט פלט.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | תמונת חזית של האובייקט. | IMAGE | כן | - |
| `image_left` | תמונת צד שמאל של האובייקט. | IMAGE | לא | - |
| `image_back` | תמונת צד אחורי של האובייקט. | IMAGE | לא | - |
| `image_right` | תמונת צד ימין של האובייקט. | IMAGE | לא | - |
| `model_version` | גרסת המודל שיש להשתמש בה ליצירה. | COMBO | לא | אפשרויות מרובות זמינות |
| `orientation` | הגדרת אוריינטציה עבור המודל התלת-ממדי (ברירת מחדל: `"default"`). | COMBO | לא | אפשרויות מרובות זמינות |
| `texture` | יצירת מפות טקסטורה. כיבוי מחזיר גאומטריה בלבד ומתעלם מ-pbr. (ברירת מחדל: True) | BOOLEAN | לא | - |
| `pbr` | מפות חומר PBR (צבע בסיס, מטאלי, חספוס, נורמל). דורש טקסטורה. (ברירת מחדל: True) | BOOLEAN | לא | - |
| `model_seed` | זרע אקראי ליצירת המודל (ברירת מחדל: 42). | INT | לא | 0 עד 2,147,483,647 |
| `texture_seed` | זרע אקראי ליצירת טקסטורה (ברירת מחדל: 42). | INT | לא | 0 עד 2,147,483,647 |
| `texture_quality` | רמת איכות ליצירת טקסטורה (ברירת מחדל: `"standard"`). `"detailed"` = טקסטורות HD, `"extreme"` = טקסטורות 8K Ultra. | COMBO | לא | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | השיטה המשמשת ליישור טקסטורות למודל (ברירת מחדל: `"original_image"`). | COMBO | לא | `"original_image"`<br>`"geometry"` |
| `face_limit` | מספר הפאות המקסימלי. -1 מאפשר ל-Tripo לבחור באופן אדפטיבי (כ-1.4M פאות ב-v3.x standard, 2M ב-detailed). Tripo מגביל בשקט: v2.5 ב-500,000, משטחי quad ב-150,000. (ברירת מחדל: -1) | INT | לא | -1 עד 2,000,000 |
| `quad` | פלט משטח quad. Tripo מספק משטחי quad כ-FBX, כך שהתוצאה מגיעה בפלט FBX ופלט GLB נשאר ריק. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `geometry_quality` | רמת איכות ליצירת גאומטריה (ברירת מחדל: `"standard"`). | COMBO | לא | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | משטח low-poly עם טופולוגיה נקייה בסגנון עבודת יד (500-20,000 פאות, quad 500-10,000). מתאים ביותר לאובייקטים פשוטים; מורכבים עשויים להיכשל. (ברירת מחדל: False) | BOOLEAN | לא | - |
| `auto_size` | מבצע קנה מידה למודלים עם טקסטורה לגודל המציאותי שלהם במטרים. Tripo שומר את הגודל כטרנספורמציית סצנה של המודל ומטביע אותו כאשר המודל מומר, עובר ריגינג או רטרגוט; מתעלם ממנו ללא טקסטורה. (ברירת מחדל: False) | BOOLEAN | לא | - |

**הערה:** תמונת החזית (`image`) נדרשת תמיד, ולפחות אחת מבין `image_left`, `image_back` או `image_right` חייבת גם היא להיות מסופקת. כיבוי `texture` מכבה אוטומטית גם את `pbr`, מכיוון ש-`pbr` דורש טקסטורה. כאשר `smart_low_poly` מופעל ו-`face_limit` אינו נשאר -1, `face_limit` חייב להיות בין 500 ל-20,000 עבור משטחי משולשים או בין 500 ל-10,000 עבור משטחי quad.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `model_file` | נתיב קובץ או מזהה עבור המודל התלת-ממדי שנוצר (לצורכי תאימות לאחור בלבד). | STRING |
| `model task_id` | מזהה משימה למעקב אחר תהליך יצירת המודל. | MODEL_TASK_ID |
| `GLB` | קובץ המודל התלת-ממדי שנוצר בפורמט GLB. ריק כאשר `quad` מופעל. | FILE3DGLB |
| `FBX` | קובץ המודל התלת-ממדי שנוצר בפורמט FBX. מאוכלס רק כאשר `quad` מופעל. | FILE3DFBX |
