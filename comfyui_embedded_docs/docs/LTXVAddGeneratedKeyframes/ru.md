# LTXV Добавить сгенерированные ключевые кадры

Узел LTXV Add Generated Keyframes добавляет детализирующие ключевые кадры к видео-латенту. Каждый ключевой кадр — это один латентный кадр токенов, размещённый поверх одного пиксельного кадра; он проходит денойзинг вместе с видео и не является частью декодированного вывода. Размещение — один слот каждые `interval_frames` пикселей, с пропуском I2V-кадров, существующих направляющих и сгенерированных ключевых кадров, уже присутствующих в кондиционировании; извлечь их обратно можно с помощью LTXV Separate Generated Keyframes. Требуется чекпойнт, обученный для сгенерированных ключевых кадров (содержащий `keyframes_abs_pos_embedding`).

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Позитивное кондиционирование, к которому прикрепляются ключевые кадры. | CONDITIONING | Да | N/A |
| `negative` | Негативное кондиционирование, к которому прикрепляются ключевые кадры. | CONDITIONING | Да | N/A |
| `vae` | Используется только для чтения коэффициентов масштаба латента. | VAE | Да | N/A |
| `latent` | Обычный 5D видео-латент, вместе с которым нужно сгенерировать ключевые кадры. Добавьте их перед Concat AV Latent. | LATENT | Да | N/A |
| `interval_frames` | Шаг в пиксельных кадрах для автоматического размещения. Значение по умолчанию 24 — это примерно один ключевой кадр в секунду при 24 fps. Занятые пиксели пропускаются. Игнорируется, если задан `frame_indices`. (по умолчанию: 24) | INT | Нет | 1-1024 |
| `keyframes` | Необязательное содержимое для инициализации новых ключевых кадров. Подключите ключевые кадры из более раннего Separate (того же пространственного размера) или обычный видео-латент, чтобы скопировать ближайший кадр в каждый новый слот (например, после временного апскейла). Они всё ещё проходят денойзинг, а не закрепляются как направляющие. Записанные индексы в латенте ключевых кадров игнорируются, если не задан `frame_indices`. Действует только если сэмплирование начинается ниже sigma 1. | LATENT | Нет | N/A |
| `frame_indices` | Необязательные индексы пиксельных кадров. Оставьте пустым, чтобы размещать по `interval_frames` на текущем холсте. Если задано, этот список определяет размещение (подключённые ключевые кадры сопоставляются по порядку). Последний кадр допускается; кадр 0 — нет (он уже является отдельным токеном). (по умолчанию: пустая строка) | STRING | Нет | Целые числа через запятую; от 1 до последнего пиксельного кадра (кадр 0 исключён) |

**Примечание:** `latent` должен быть обычным 5D видео-латентом со сгенерированными ключевыми кадрами, добавленными до Concat AV Latent. Если задан `frame_indices`, каждый указанный пиксельный кадр должен быть уникальным и не может уже содержать ключевой кадр изображения, направляющую или сгенерированный ключевой кадр. Если `frame_indices` пуст, занятые пиксели пропускаются автоматически; если свободного слота для детализации нет, узел выдаёт ошибку. При добавлении к существующим сгенерированным ключевым кадрам латент всё ещё должен иметь то же количество токенов на кадр, а существующий блок должен заканчиваться на последнем латентном кадре.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Позитивное кондиционирование с подключённым вниманием к сгенерированным ключевым кадрам. | CONDITIONING |
| `negative` | Негативное кондиционирование с подключённым вниманием к сгенерированным ключевым кадрам. | CONDITIONING |
| `latent` | Видео-латент со сгенерированными ключевыми кадрами, добавленными по оси T. | LATENT |

## Примечания

- Параметр `interval_frames` задаёт интервал автоматически размещаемых ключевых кадров. Более высокое значение приводит к меньшему числу ключевых кадров и более широкому интервалу; более низкое значение создаёт больше ключевых кадров.
- Вход `keyframes` позволяет инициализировать новые ключевые кадры существующими ключевыми кадрами или видео-латентом. Если передан более длинный обычный видео-латент, в каждый новый слот копируется ближайший видеокадр. Эти ключевые кадры всё ещё проходят денойзинг и не закрепляются в качестве направляющих.
- Параметр `frame_indices` позволяет указать точные индексы пиксельных кадров, куда следует размещать ключевые кадры. Если он задан, `interval_frames` игнорируется. Список должен содержать уникальные целые числа в допустимом диапазоне пиксельных кадров, а кадр 0 не допускается.
- Выходы `positive` и `negative` содержат кондиционирование с подключённым вниманием к сгенерированным ключевым кадрам.
- Выход `latent` содержит видео-латент со сгенерированными ключевыми кадрами, добавленными по оси T.
- Требуется чекпойнт, обученный для сгенерированных ключевых кадров (содержащий `keyframes_abs_pos_embedding`).
- Извлекайте сгенерированные ключевые кадры обратно с помощью LTXV Separate Generated Keyframes.
