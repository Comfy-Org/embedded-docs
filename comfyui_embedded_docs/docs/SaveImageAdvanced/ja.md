# 画像を保存（詳細）

**SaveImageAdvanced** ノードは、ファイル形式、ビット深度、カラースペースを高度に制御しながら、画像を ComfyUI の出力ディレクトリに保存します。PNG または EXR ファイルとしての保存に対応しており、ワークフローメタデータを保存ファイルに埋め込むこともできます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 保存する画像。 | IMAGE | はい | - |
| `filename_prefix` | 保存するファイルのプレフィックス。`%date:yyyy-MM-dd%` や `%Empty Latent Image.width%` などのフォーマットトークンを含めることができます。（デフォルト："ComfyUI"） | STRING | はい | - |
| `format` | 画像を保存するファイル形式。形式を選択すると、その形式に固有の追加オプションが表示されます。 | DYNAMIC_COMBO | はい | `"png"`<br>`"exr"` |

### PNG 入力

これらの入力は、`format` が `"png"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | 画像保存時に使用するビット深度。（デフォルト："8-bit"） | COMBO | はい（条件付き） | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | 入力テンソルのカラースペース。（デフォルト："sRGB"） | COMBO | はい（条件付き） | `"sRGB"` |

### EXR 入力

これらの入力は、`format` が `"exr"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | 画像保存時に使用するビット深度。（デフォルト："32-bit float"） | COMBO | はい（条件付き） | `"32-bit float"` |
| `input_color_space` | 入力テンソルのカラースペース。EXR は常に、対応するガマット内のシーンリニアとして書き込まれます。（デフォルト："sRGB"） | COMBO | はい（条件付き） | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

**パラメータの依存関係とファイル動作に関する注意：**

- `bit_depth` と `input_color_space` は、親である `format` が選択された場合にのみ表示されます。
- PNG 形式では、ビット深度は `"8-bit"` と `"16-bit"` のみ、カラースペースは `"sRGB"` のみが使用できます。カラースペースの選択は PNG ピクセルを変更しません。PNG ファイルは常に sRGB エンコードされた画像として保存されます。
- EXR 形式では、ビット深度は `"32-bit float"` のみで、カラースペースは `"sRGB"`、`"HDR"`、`"linear"` のいずれかを使用できます。
- EXR の `input_color_space` パラメータは、保存前に入力テンソルがどのように解釈されるかを決定します：
  - `"sRGB"` — 入力は sRGB エンコードされた Rec.709 です。逆 sRGB EOTF が適用されます。
  - `"HDR"` — 入力は HLG エンコードされた Rec.2020（BT.2100）です。シーンリニア光を得るために逆 HLG OETF が適用されます。
  - `"linear"` — 入力はすでにシーンリニア（Rec.709 原色）であり、そのまま書き込まれます。レンダラーやコンポジターの出力にはこれを使用してください。
- ワークフローメタデータ（プロンプトと追加 PNG 情報）は、`--disable-metadata` コマンドライン引数でメタデータ書き込みが無効にされていない限り、保存された PNG および EXR ファイルに埋め込まれます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | 保存された画像（`images` 入力に渡されたものと同じ画像）。ノードの UI 結果には、保存されたファイルのリストが含まれ、各ファイルはそのファイル名、サブフォルダー、タイプ（"output"）とともに報告されます。 | IMAGE |
