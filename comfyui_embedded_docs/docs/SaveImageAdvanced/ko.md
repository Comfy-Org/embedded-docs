# 이미지 저장 (고급)

**SaveImageAdvanced** 노드는 파일 형식, 비트 심도 및 색상 공간을 고급으로 제어하여 이미지를 ComfyUI 출력 디렉터리에 저장합니다. PNG 또는 EXR 파일로 저장할 수 있으며 작업 흐름 메타데이터를 저장된 파일에 포함할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 저장할 이미지입니다. | IMAGE | 예 | - |
| `filename_prefix` | 저장할 파일의 접두사입니다. `%date:yyyy-MM-dd%` 또는 `%Empty Latent Image.width%` 같은 형식 토큰을 포함할 수 있습니다. (기본값: "ComfyUI") | STRING | 예 | - |
| `format` | 이미지를 저장할 파일 형식입니다. 형식을 선택하면 해당 형식에 대한 추가 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `"png"`<br>`"exr"` |

### PNG 입력

이 입력은 `format`이 `"png"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | 이미지를 저장할 때 사용되는 비트 심도입니다. (기본값: "8-bit") | COMBO | 예 (조건부) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | 입력 텐서의 색상 공간입니다. (기본값: "sRGB") | COMBO | 예 (조건부) | `"sRGB"` |

### EXR 입력

이 입력은 `format`이 `"exr"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | 이미지를 저장할 때 사용되는 비트 심도입니다. (기본값: "32-bit float") | COMBO | 예 (조건부) | `"32-bit float"` |
| `input_color_space` | 입력 텐서의 색상 공간입니다. EXR은 항상 일치하는 색역의 장면 선형(scene-linear)으로 기록됩니다. (기본값: "sRGB") | COMBO | 예 (조건부) | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

**매개변수 종속성 및 파일 동작에 대한 참고 사항:**

- `bit_depth`와 `input_color_space`는 상위 항목인 `format`이 선택된 경우에만 표시됩니다.
- PNG 형식의 경우 `"8-bit"` 및 `"16-bit"` 비트 심도만 사용할 수 있으며, 색상 공간은 `"sRGB"`만 사용할 수 있습니다. 색상 공간 선택은 PNG 픽셀을 수정하지 않습니다. PNG 파일은 항상 sRGB 인코딩 이미지로 저장됩니다.
- EXR 형식의 경우 `"32-bit float"` 비트 심도만 사용할 수 있으며, 색상 공간은 `"sRGB"`, `"HDR"` 또는 `"linear"`입니다.
- EXR의 `input_color_space` 매개변수는 저장 전에 입력 텐서가 해석되는 방식을 결정합니다.
  - `"sRGB"` — 입력이 sRGB 인코딩된 Rec.709입니다. 역 sRGB EOTF가 적용됩니다.
  - `"HDR"` — 입력이 HLG 인코딩된 Rec.2020(BT.2100)입니다. 장면 선형 광원을 얻기 위해 역 HLG OETF가 적용됩니다.
  - `"linear"` — 입력이 이미 장면 선형(Rec.709 원색)입니다. 변경 없이 그대로 기록됩니다. 렌더러/합성기 출력에 사용하십시오.
- 작업 흐름 메타데이터(프롬프트 및 추가 PNG 정보)는 `--disable-metadata` 명령줄 인수로 메타데이터 기록을 비활성화하지 않는 한 저장된 PNG 및 EXR 파일에 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 저장된 이미지입니다(`images` 입력으로 전달된 동일한 이미지). 노드의 UI 결과에는 저장된 파일 목록이 포함되며, 각 파일의 이름, 하위 폴더 및 유형("output")이 보고됩니다. | IMAGE |
