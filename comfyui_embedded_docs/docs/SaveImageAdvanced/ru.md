# Сохранить изображение (расширенно)

Узел **Save Image (Advanced)** сохраняет входные изображения в ваш выходной каталог ComfyUI с расширенным контролем над форматом файла, битовой глубиной и цветовым пространством. Он поддерживает сохранение в файлы PNG, EXR или AVIF (включая анимированный AVIF) и может встраивать метаданные рабочего процесса в сохраняемые файлы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Изображения для сохранения. | IMAGE | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может включать токены форматирования, такие как `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`. (по умолчанию: "ComfyUI") | STRING | Да | - |
| `формат` | Формат файла, в котором нужно сохранить изображение. Выбор формата открывает дополнительные параметры для этого формата. | DYNAMIC_COMBO | Да | `"png"`<br>`"exr"`<br>`"avif"` |

### Входы PNG

Эти параметры появляются, когда `format` установлен в `"png"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого файла PNG. (по умолчанию: "8-bit") | COMBO | Да (условно) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | Цветовое пространство входного тензора. Для формата PNG доступно только sRGB. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"` |

### Входы EXR

Эти параметры появляются, когда `format` установлен в `"exr"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого файла EXR. (по умолчанию: "32-bit float") | COMBO | Да (условно) | `"32-bit float"` |
| `input_color_space` | Цветовое пространство входного тензора. EXR всегда записывается как линейное относительно сцены (scene-linear) изображение в соответствующем цветовом охвате.<br>`"sRGB"` — входные данные закодированы в sRGB Rec.709; применяется обратная функция EOTF sRGB.<br>`"HDR"` — входные данные закодированы в HLG Rec.2020 (BT.2100); применяется обратная функция OETF HLG для получения линейного относительно сцены света.<br>`"linear"` — входные данные уже линейны относительно сцены (первичные цвета Rec.709); записываются без изменений. Используйте это для вывода рендерера/компоновщика. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

### Входы AVIF

Эти параметры появляются, когда `format` установлен в `"avif"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого файла AVIF. Автоматический режим (`auto`) использует 8-битный YUV420 для sRGB и 10-битный YUV420 для HDR. (по умолчанию: "auto") | COMBO | Да (условно) | `"auto"`<br>`"8-bit YUV420"`<br>`"10-bit YUV420"` |
| `input_color_space` | Цветовое пространство входных изображений. HDR выбирает BT.2020/HLG, а HDR PQ выбирает BT.2020/PQ. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |
| `crf` | Более низкие значения обеспечивают более высокое качество и больший размер файлов. (по умолчанию: 18) | INT | Да (условно) | 1 до 63 |
| `save_mode` | Режим сохранения файла AVIF. `"still images"` сохраняет каждое изображение в пакете как отдельный статичный файл; `"animated"` сохраняет весь пакет как один анимированный файл AVIF и открывает параметры `fps` и `loop_count`. (по умолчанию: "still images") | DYNAMIC_COMBO | Да (условно) | `"still images"`<br>`"animated"` |

### Параметры анимации AVIF

Эти параметры появляются, когда `save_mode` установлен в `"animated"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `fps` | Частота кадров анимации. (по умолчанию: 6.0) | FLOAT | Да (условно) | 0.01 до 1000.0 |
| `loop_count` | Количество повторений анимации. 0 означает бесконечный цикл. (по умолчанию: 0) | INT | Да (условно) | 0 до 1000 |

**Примечания о зависимостях параметров:**
- Параметры, специфичные для формата (`bit_depth`, `input_color_space`, а для AVIF также `crf` и `save_mode`), доступны только при выборе конкретного `format`.
- Для формата PNG доступны только битовые глубины "8-bit" и "16-bit", и только цветовое пространство "sRGB".
- Для формата EXR доступна только битовая глубина "32-bit float", с цветовыми пространствами "sRGB", "HDR" или "linear".
- Для формата AVIF `fps` и `loop_count` доступны только когда `save_mode` установлен в `"animated"`.
- Изображения PNG и EXR должны иметь 1 (оттенки серого), 3 (RGB) или 4 (RGBA) канала; другие количества каналов не поддерживаются и вызывают ошибку.
- AVIF поддерживает только 1-канальные изображения в оттенках серого и 3-канальные изображения RGB; изображения RGBA (с альфа-каналом) не поддерживаются и вызывают ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Входные изображения, передаваемые без изменений. UI-выход узла предоставляет список результатов сохранённых изображений, каждый из которых содержит имя файла, подпапку и тип ("output"). Для анимированного AVIF с более чем одним изображением UI-выход также включает флаг `animated`. | IMAGE |
