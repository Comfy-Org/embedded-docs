# Сохранить изображение (расширенно)

**Узел SaveImageAdvanced** сохраняет изображения в каталог вывода ComfyUI с расширенными возможностями управления форматом файла, глубиной цвета и цветовым пространством. Он поддерживает сохранение в форматах PNG и EXR, а также может встраивать метаданные рабочего процесса в сохраняемые файлы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Изображения для сохранения. | IMAGE | Да | - |
| `filename_prefix` | Префикс имени сохраняемого файла. Может содержать токены форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`. (по умолчанию: "ComfyUI") | STRING | Да | - |
| `format` | Формат файла для сохранения изображения. Выбор формата отображает дополнительные параметры для этого формата. | DYNAMIC_COMBO | Да | `"png"`<br>`"exr"` |

### Входы PNG

Эти входы отображаются, когда `format` установлен в `"png"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | Глубина цвета, используемая при сохранении изображения. (по умолчанию: "8-bit") | COMBO | Да (условно) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | Цветовое пространство входного тензора. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"` |

### Входы EXR

Эти входы отображаются, когда `format` установлен в `"exr"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `bit_depth` | Глубина цвета, используемая при сохранении изображения. (по умолчанию: "32-bit float") | COMBO | Да (условно) | `"32-bit float"` |
| `input_color_space` | Цветовое пространство входного тензора. EXR всегда записывается как линейное по сцене (scene-linear) в соответствующем цветовом охвате. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

**Примечания о зависимостях параметров и поведении файлов:**

- Параметры `bit_depth` и `input_color_space` появляются только при выбранном родительском параметре `format`.
- Для формата PNG доступны только глубина цвета `"8-bit"` и `"16-bit"` и только цветовое пространство `"sRGB"`. Выбор цветового пространства не изменяет пиксели PNG — файлы PNG всегда сохраняются как изображения в кодировке sRGB.
- Для формата EXR доступна только глубина цвета `"32-bit float"` с цветовыми пространствами `"sRGB"`, `"HDR"` или `"linear"`.
- Параметр `input_color_space` для EXR определяет, как интерпретируется входной тензор перед сохранением:
  - `"sRGB"` — входные данные закодированы в sRGB (Rec.709); применяется обратная EOTF sRGB.
  - `"HDR"` — входные данные закодированы в HLG (Rec.2020, BT.2100); применяется обратная OETF HLG для получения линейного освещения сцены.
  - `"linear"` — входные данные уже линейны относительно сцены (основные цвета Rec.709); записываются без изменений. Используйте этот вариант для вывода рендерера или композитора.
- Метаданные рабочего процесса (prompt и дополнительная информация PNG) встраиваются в сохраняемые файлы PNG и EXR, если запись метаданных не отключена аргументом командной строки `--disable-metadata`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `images` | Сохраненные изображения (те же изображения, что были переданы во вход `images`). Результат в интерфейсе узла включает список сохраненных файлов с указанием имени файла, подпапки и типа ("output"). | IMAGE |
