# Сохранить изображение (расширенно)

Узел **Save Image (Advanced)** сохраняет входные изображения в выходной каталог ComfyUI с расширенным управлением форматом файла, битовой глубиной и цветовым пространством. Он поддерживает сохранение в форматах PNG или EXR и может встраивать метаданные рабочего процесса в сохраняемые файлы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Изображения для сохранения. | IMAGE | Да | - |
| `префикс_имени_файла` | Префикс для имени сохраняемого файла. Может включать токены форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`. (по умолчанию: "ComfyUI") | STRING | Да | - |
| `формат` | Формат файла, в котором сохраняется изображение. Выбор формата отображает дополнительные параметры для этого формата. | DYNAMIC_COMBO | Да | `"png"`<br>`"exr"` |

### Входы PNG

Эти параметры появляются, когда для `format` установлено значение `"png"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина для сохраняемого файла PNG. (по умолчанию: "8-bit") | COMBO | Да (условно) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | Цветовое пространство входного тензора. Для формата PNG доступен только sRGB. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"` |

### Входы EXR

Эти параметры появляются, когда для `format` установлено значение `"exr"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина для сохраняемого файла EXR. (по умолчанию: "32-bit float") | COMBO | Да (условно) | `"32-bit float"` |
| `input_color_space` | Цветовое пространство входного тензора. EXR всегда записывается как сцена-линейное изображение в соответствующем цветовом охвате.<br>`"sRGB"` — входные данные закодированы в sRGB (Rec.709); применяется обратная EOTF sRGB.<br>`"HDR"` — входные данные закодированы в HLG (Rec.2020, BT.2100); применяется обратная OETF HLG для получения сцена-линейного света.<br>`"linear"` — входные данные уже являются сцена-линейными (основные цвета Rec.709); записываются без изменений. Используйте это для вывода рендерера/композитора. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

**Примечания о зависимостях параметров:**
- Параметры `bit_depth` и `input_color_space` доступны только при выборе определённого `format`.
- Для формата PNG доступны только битовые глубины "8-bit" и "16-bit", а также только цветовое пространство "sRGB".
- Для формата EXR доступна только битовая глубина "32-bit float" с цветовыми пространствами "sRGB", "HDR" или "linear".
- Изображения должны иметь 1 (градации серого), 3 (RGB) или 4 (RGBA) канала; другие количества каналов не поддерживаются и вызывают ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Входные изображения, передаваемые без изменений. Выход узла в интерфейсе предоставляет список результатов сохранённых изображений, каждый из которых содержит имя файла, вложенную папку и тип ("output"). | IMAGE |
