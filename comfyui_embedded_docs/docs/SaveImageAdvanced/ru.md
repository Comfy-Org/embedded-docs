# Сохранить изображение (расширенно)

Узел **Save Image (Advanced)** сохраняет входные изображения в каталог вывода ComfyUI с расширенным контролем формата файла, битовой глубины и цветового пространства. Он поддерживает сохранение в файлы PNG, EXR или AVIF (включая анимированный AVIF) и может встраивать метаданные рабочего процесса в сохраняемые файлы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `images` | Изображения для сохранения. | IMAGE | Да | - |
| `filename_prefix` | Префикс для сохраняемого файла. Может включать токены форматирования, такие как `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`. (по умолчанию: "ComfyUI") | STRING | Да | - |
| `format` | Формат файла, в котором нужно сохранить изображение. При выборе формата отображаются дополнительные параметры для этого формата. | DYNAMIC_COMBO | Да | `"png"`<br>`"exr"`<br>`"avif"` |

### Входы PNG

Эти параметры появляются, когда для `format` выбрано значение `"png"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина для сохраняемого файла PNG. (по умолчанию: "8-bit") | COMBO | Да (условно) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | Цветовое пространство входного тензора. Для формата PNG доступен только sRGB. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"` |
| `channels` | Какие каналы записывать в PNG. `"auto"` сохраняет входные каналы, режим оттенков серого преобразует RGB в яркость и отбрасывает альфа-канал, RGB сохраняет цвет без альфа-канала, а RGBA сохраняет альфа-канал или добавляет полностью непрозрачный. (по умолчанию: `"auto"`) | COMBO | Нет | `"auto"`<br>`"grayscale (1 channel)"`<br>`"RGB (3 channels)"`<br>`"RGBA (4 channels)"` |

### Входы EXR

Эти параметры появляются, когда для `format` выбрано значение `"exr"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина для сохраняемого файла EXR. (по умолчанию: "16-bit float") | COMBO | Да (условно) | `"16-bit float"`<br>`"32-bit float"` |
| `input_color_space` | Цветовое пространство входного тензора. EXR всегда записывается как scene-linear в соответствующем цветовом охвате.<br>`"sRGB"` — входные данные закодированы в sRGB Rec.709; применяется обратная EOTF sRGB.<br>`"HDR"` — входные данные закодированы в HLG Rec.2020 (BT.2100); применяется обратная OETF HLG для получения света в scene-linear.<br>`"linear"` — входные данные уже scene-linear (основные цвета Rec.709); записываются без изменений. Используйте этот вариант для вывода рендерера/композитора.<br>`"linear ACEScg"` — входные данные уже scene-linear ACEScg (AP1 / D60); записываются без изменений с координатами цветности ACEScg. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"linear"`<br>`"linear ACEScg"` |

### Входы AVIF

Эти параметры появляются, когда для `format` выбрано значение `"avif"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина для сохраняемого файла AVIF. Режим auto использует 8-bit YUV420 для sRGB и 10-bit YUV420 для HDR. (по умолчанию: "auto") | COMBO | Да (условно) | `"auto"`<br>`"8-bit YUV420"`<br>`"10-bit YUV420"` |
| `input_color_space` | Цветовое пространство входных изображений. HDR выбирает BT.2020/HLG, а HDR PQ выбирает BT.2020/PQ. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. (по умолчанию: 18) | INT | Да (условно) | от 1 до 63 |
| `save_mode` | Режим сохранения для файла AVIF. `"still images"` сохраняет каждое изображение в пакете как отдельный статичный файл; `"animated"` сохраняет весь пакет как один анимированный файл AVIF и показывает параметры `fps` и `loop_count`. (по умолчанию: "still images") | DYNAMIC_COMBO | Да (условно) | `"still images"`<br>`"animated"` |

### Параметры анимации AVIF

Эти параметры появляются, когда для `save_mode` выбрано значение `"animated"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `fps` | Частота кадров анимации. (по умолчанию: 6.0) | FLOAT | Да (условно) | от 0.01 до 1000.0 |
| `loop_count` | Количество повторений анимации. 0 означает бесконечное повторение. (по умолчанию: 0) | INT | Да (условно) | от 0 до 1000 |

**Примечания о зависимостях параметров:**
- Параметры, зависящие от формата (`bit_depth`, `input_color_space`, а для AVIF также `crf` и `save_mode`), доступны только при выборе конкретного `format`.
- Для формата PNG доступны только битовые глубины "8-bit" и "16-bit" и только цветовое пространство "sRGB".
- Для формата EXR доступны битовые глубины "16-bit float" и "32-bit float" с цветовыми пространствами "sRGB", "HDR", "linear" или "linear ACEScg". "16-bit float" используется по умолчанию и создаёт файлы меньшего размера.
- Для формата AVIF параметры `fps` и `loop_count` доступны только когда для `save_mode` выбрано значение `"animated"`.
- Изображения PNG и EXR должны иметь 1 (оттенки серого), 3 (RGB) или 4 (RGBA) канала; другое количество каналов не поддерживается и вызывает ошибку.
- AVIF поддерживает только одноканальные изображения в оттенках серого и трёхканальные изображения RGB; изображения RGBA (с альфа-каналом) не поддерживаются и вызывают ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `images` | Входные изображения, передаваемые без изменений. Выход узла в пользовательском интерфейсе предоставляет список результатов сохранённых изображений, каждый из которых содержит имя файла, подпапку и тип ("output"). Для анимированного AVIF с более чем одним изображением выход в пользовательском интерфейсе также включает флаг `animated`. | IMAGE |
