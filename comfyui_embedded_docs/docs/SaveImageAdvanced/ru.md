# Сохранить изображение (расширенно)

Узел **Save Image (Advanced)** сохраняет входные изображения в выходной каталог ComfyUI с расширенными возможностями управления форматом файла, битовой глубиной и цветовым пространством. Он поддерживает сохранение в форматах PNG, EXR или AVIF (включая анимированный AVIF) и может встраивать метаданные рабочего процесса в сохраняемые файлы.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `изображения` | Изображения для сохранения. | IMAGE | Да | - |
| `префикс_имени_файла` | Префикс для сохраняемого файла. Может содержать токены форматирования, например `%date:yyyy-MM-dd%` или `%Empty Latent Image.width%`. (по умолчанию: "ComfyUI") | STRING | Да | - |
| `формат` | Формат файла, в котором будет сохранено изображение. Выбор формата открывает дополнительные параметры для этого формата. | DYNAMIC_COMBO | Да | `"png"`<br>`"exr"`<br>`"avif"` |

### Входы PNG

Эти параметры появляются, когда для `format` задано значение `"png"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого PNG-файла. (по умолчанию: "8-bit") | COMBO | Да (условно) | `"8-bit"`<br>`"16-bit"` |
| `input_color_space` | Цветовое пространство входного тензора. Для формата PNG доступно только sRGB. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"` |

### Входы EXR

Эти параметры появляются, когда для `format` задано значение `"exr"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого EXR-файла. (по умолчанию: "32-bit float") | COMBO | Да (условно) | `"32-bit float"` |
| `input_color_space` | Цветовое пространство входного тензора. EXR всегда записывается как сцена-линейное изображение в соответствующем цветовом охвате.<br>`"sRGB"` — входные данные закодированы в sRGB (Rec.709); применяется обратная EOTF sRGB.<br>`"HDR"` — входные данные закодированы в HLG (Rec.2020, BT.2100); применяется обратная OETF HLG для получения сцена-линейного света.<br>`"linear"` — входные данные уже являются сцена-линейными (основные цвета Rec.709); записываются без изменений. Используйте этот режим для вывода рендереров и композиторов. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"linear"` |

### Входы AVIF

Эти параметры появляются, когда для `format` задано значение `"avif"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `bit_depth` | Битовая глубина сохраняемого AVIF-файла. Режим "auto" использует 8-бит YUV420 для sRGB и 10-бит YUV420 для HDR. (по умолчанию: "auto") | COMBO | Да (условно) | `"auto"`<br>`"8-bit YUV420"`<br>`"10-bit YUV420"` |
| `input_color_space` | Цветовое пространство входных изображений. HDR выбирает BT.2020/HLG, а HDR PQ выбирает BT.2020/PQ. (по умолчанию: "sRGB") | COMBO | Да (условно) | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |
| `crf` | Меньшие значения обеспечивают более высокое качество и больший размер файлов. (по умолчанию: 18) | INT | Да (условно) | от 1 до 63 |
| `save_mode` | Режим сохранения для AVIF-файла. `"still images"` сохраняет каждое изображение из пакета как отдельный файл; `"animated"` сохраняет весь пакет как один анимированный AVIF-файл и открывает параметры `fps` и `loop_count`. (по умолчанию: "still images") | DYNAMIC_COMBO | Да (условно) | `"still images"`<br>`"animated"` |

### Параметры анимации AVIF

Эти параметры появляются, когда для `save_mode` задано значение `"animated"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `fps` | Частота кадров анимации. (по умолчанию: 6.0) | FLOAT | Да (условно) | от 0.01 до 1000.0 |
| `loop_count` | Количество повторений анимации. Значение 0 означает бесконечный цикл. (по умолчанию: 0) | INT | Да (условно) | от 0 до 1000 |

**Примечания о зависимостях параметров:**
- Параметры, зависящие от формата (`bit_depth`, `input_color_space`, а для AVIF также `crf` и `save_mode`), доступны только при выборе конкретного `format`.
- Для формата PNG доступны только битовые глубины "8-bit" и "16-bit" и только цветовое пространство "sRGB".
- Для формата EXR доступна только битовая глубина "32-bit float" с цветовыми пространствами "sRGB", "HDR" или "linear".
- Для формата AVIF параметры `fps` и `loop_count` доступны только когда для `save_mode` задано значение `"animated"`.
- Изображения PNG и EXR должны иметь 1 (градации серого), 3 (RGB) или 4 (RGBA) канала; другие количества каналов не поддерживаются и вызывают ошибку.
- AVIF поддерживает только одноканальные изображения в градациях серого и трехканальные RGB; изображения RGBA (с альфа-каналом) не поддерживаются и вызывают ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Входные изображения, передаваемые без изменений. Выход узла в пользовательском интерфейсе предоставляет список сохранённых изображений, каждый элемент которого содержит имя файла, подпапку и тип ("output"). | IMAGE |
