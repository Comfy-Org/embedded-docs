# Flux.2 圖像

使用 Flux.2 [pro] 或 Flux.2 [max] 模型，從文字提示詞及選用參考圖像生成圖像。此節點會將請求傳送至 BFL API，輪詢直到結果就緒，並回傳生成的圖像。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Flux.2 模型版本。選擇模型會解鎖寬度、高度及選用參考圖像的額外參數。 | DYNAMIC_COMBO | 是 | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `提示詞` | 用於圖像生成或編輯的提示詞（預設：空字串）。 | STRING | 是 | N/A |
| `種子` | 用於建立雜訊的隨機種子（預設：0）。支援 control-after-generate 選項，在每次執行後將數值隨機化。 | INT | 是 | 0 至 18446744073709551615 |

### Flux.2 [pro] and Flux.2 [max] 輸入

兩個模型共用——參數集完全相同。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `寬度` | 生成圖像的寬度，單位為像素（預設：1024）。 | INT | 是 | 256 至 2048 （步進值：32） |
| `高度` | 生成圖像的高度，單位為像素（預設：768）。 | INT | 是 | 256 至 2048 （步進值：32） |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 用於圖像到圖像生成的選用參考圖像。最多 8 張圖像。可增長插槽：連接 1..8 個項目 (`image_1`...`image_8`)。 | IMAGE | 否 | 0 至 8 images |

**注意：**
- 參考圖像的最大數量為 8。若提供的圖像超過 8 張，會引發錯誤。批次圖像會計入此上限，因為批次中的每張圖像都會個別計數。
- 參考圖像在傳送至 API 前會調整大小，使總像素數不超過 2048 x 2048。
- `model.width` 和 `model.height` 的值會影響生成成本。成本也取決於所選模型，以及是否提供參考圖像。
