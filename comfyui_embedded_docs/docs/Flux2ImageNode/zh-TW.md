# Flux.2 圖像

Flux.2 圖像

使用 Flux.2 [pro] 或 Flux.2 [max] 模型，根據文字提示詞和可選的參考圖像生成圖像。此節點會將您的請求傳送至 BFL API，輪詢結果，然後將生成的圖像以張量形式返回。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Flux.2 模型版本。選擇模型後，會解鎖額外的寬度、高度及可選參考圖像參數。 | DYNAMIC_COMBO | 是 | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `提示詞` | 用於圖像生成或編輯的提示詞（預設：空字串）。 | STRING | 是 | N/A |
| `種子` | 用於建立雜訊的隨機種子。可設為在每次生成後隨機化（預設：0）。 | INT | 是 | 0 至 18446744073709551615 |

### Flux.2 [pro] 與 Flux.2 [max] 輸入

兩個模型共用 — 參數集完全相同。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `寬度` | 生成圖像的寬度（像素）（預設：1024）。 | INT | 是 | 256 至 2048 (step 32) |
| `高度` | 生成圖像的高度（像素）（預設：768）。 | INT | 是 | 256 至 2048 (step 32) |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 可選的參考圖像，用於圖生圖生成。最多 8 張圖像。可擴充插槽：可連接 1..8 個項目（`image_1`...`image_8`）。 | IMAGE | 否 | 0 至 8 images |

**注意：**
- 參考圖像的最大數量為 8 張。如果提供超過 8 張圖像，將引發錯誤。
- `model.width` 與 `model.height` 的值會影響生成成本。成本也取決於所選模型以及是否提供參考圖像。
