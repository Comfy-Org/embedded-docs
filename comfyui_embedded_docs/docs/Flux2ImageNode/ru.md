# Flux.2 Image

Flux.2 Image

Генерирует изображения с помощью модели Flux.2 [pro] или Flux.2 [max] на основе текстового запроса и необязательных эталонных изображений. Этот узел отправляет запрос к BFL API, ожидает результат и возвращает сгенерированное изображение в виде тензора.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели Flux.2 для использования. Выбор модели открывает дополнительные параметры ширины, высоты и необязательных эталонных изображений. | DYNAMIC_COMBO | Да | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `prompt` | Текстовый запрос для генерации или редактирования изображения (по умолчанию: пустая строка). | STRING | Да | N/A |
| `seed` | Случайное зерно (seed), используемое для создания шума. Можно настроить на рандомизацию после каждой генерации (по умолчанию: 0). | INT | Да | 0 до 18446744073709551615 |

### Входы Flux.2 [pro] и Flux.2 [max]

Общие для обеих моделей — наборы параметров идентичны.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина сгенерированного изображения в пикселях (по умолчанию: 1024). | INT | Да | 256 до 2048 (step 32) |
| `height` | Высота сгенерированного изображения в пикселях (по умолчанию: 768). | INT | Да | 256 до 2048 (step 32) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model.images` | Необязательные эталонные изображения для генерации «изображение-в-изображение». До 8 изображений. Расширяемый слот: подключайте от 1 до 8 элементов (`image_1`...`image_8`). | IMAGE | Нет | 0 до 8 images |

**Примечание:**
- Максимальное количество эталонных изображений — 8. Если передано более 8 изображений, возникает ошибка.
- Значения `model.width` и `model.height` влияют на стоимость генерации. Стоимость также зависит от выбранной модели и от того, переданы ли эталонные изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение в виде тензора, загруженное из результата BFL API. | IMAGE |
