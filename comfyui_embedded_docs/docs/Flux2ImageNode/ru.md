# Flux.2 Image

Генерация изображений с помощью модели Flux.2 [pro] или Flux.2 [max] по текстовому запросу и необязательным эталонным изображениям. Узел отправляет запрос в BFL API, опрашивает состояние до готовности результата и возвращает сгенерированное изображение.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая версия модели Flux.2. Выбор модели открывает дополнительные параметры для ширины, высоты и необязательных эталонных изображений. | DYNAMIC_COMBO | Да | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `prompt` | Текстовый запрос для генерации или редактирования изображения (по умолчанию: пустая строка). | STRING | Да | N/A |
| `seed` | Случайное начальное число, используемое для создания шума (по умолчанию: 0). Поддерживает опцию control-after-generate для рандомизации значения после каждого запуска. | INT | Да | от 0 до 18446744073709551615 |

### Входы Flux.2 [pro] и Flux.2 [max]

Общие для обеих моделей — наборы параметров идентичны.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина сгенерированного изображения в пикселях (по умолчанию: 1024). | INT | Да | от 256 до 2048 (шаг 32) |
| `height` | Высота сгенерированного изображения в пикселях (по умолчанию: 768). | INT | Да | от 256 до 2048 (шаг 32) |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model.images` | Необязательное(ые) эталонное(ые) изображение(я) для генерации изображения по изображению. До 8 изображений. Расширяемый слот: подключите от 1 до 8 элементов (`image_1`...`image_8`). | IMAGE | Нет | от 0 до 8 изображений |

**Примечание:**
- Максимальное количество эталонных изображений — 8. Если предоставлено более 8 изображений, возникает ошибка. Пакетные изображения учитываются в этом лимите, так как каждое изображение в пакете считается отдельно.
- Перед отправкой в API эталонные изображения масштабируются так, чтобы общее количество пикселей не превышало 2048 x 2048.
- Значения `model.width` и `model.height` влияют на стоимость генерации. Стоимость также зависит от выбранной модели и от того, предоставлены ли эталонные изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение в виде тензора, загруженное из результата BFL API. | IMAGE |
