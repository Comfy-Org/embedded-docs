# Flux.2 Image

با استفاده از مدل Flux.2 [pro] یا Flux.2 [max] از روی یک متن پرامپت و تصاویر مرجع اختیاری، تصویر تولید کنید. این گره درخواست شما را به BFL API ارسال می‌کند، نتیجه را پیگیری می‌کند و تصویر تولیدشده را به صورت یک تنسور برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|-----------|--------|--------|
| `model` | نسخه مدل Flux.2 که استفاده می‌شود. انتخاب یک مدل، پارامترهای اضافی برای عرض، ارتفاع و تصاویر مرجع اختیاری را فعال می‌کند. | DYNAMIC_COMBO | بله | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `prompt` | پرامپت برای تولید یا ویرایش تصویر (پیش‌فرض: رشته خالی). | STRING | بله | N/A |
| `seed` | دانه تصادفی (seed) که برای ایجاد نویز استفاده می‌شود. می‌توان آن را طوری تنظیم کرد که پس از هر تولید تصادفی شود (پیش‌فرض: 0). | INT | بله | 0 تا 18446744073709551615 |

### ورودی‌های Flux.2 [pro] و Flux.2 [max]

مشترک بین هر دو مدل — مجموعه پارامترها یکسان است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `width` | عرض تصویر تولیدشده به پیکسل (پیش‌فرض: 1024). | INT | بله | 256 تا 2048 (گام 32) |
| `height` | ارتفاع تصویر تولیدشده به پیکسل (پیش‌فرض: 768). | INT | بله | 256 تا 2048 (گام 32) |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.images` | تصویر(های) مرجع اختیاری برای تولید تصویر به تصویر. حداکثر 8 تصویر. اسلات رشدپذیر: 1..8 مورد را متصل کنید (`image_1`...`image_8`). | IMAGE | خیر | 0 تا 8 تصویر |

**توجه:**
- حداکثر تعداد تصاویر مرجع ۸ است. اگر بیش از ۸ تصویر ارائه شود، خطا رخ می‌دهد.
- مقادیر `model.width` و `model.height` بر هزینه تولید تأثیر می‌گذارند. هزینه همچنین به مدل انتخابی و به ارائه تصاویر مرجع بستگی دارد.
