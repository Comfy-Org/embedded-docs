# Flux.2 Image

با استفاده از مدل Flux.2 [pro] یا Flux.2 [max] و بر اساس یک پرامپت متنی و تصاویر مرجع اختیاری، تصویر تولید کنید. این گره درخواست را به BFL API ارسال می‌کند، تا آماده‌شدن نتیجه به‌طور مکرر بررسی می‌کند و تصویر تولیدشده را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | نسخه مدل Flux.2 که باید استفاده شود. با انتخاب یک مدل، پارامترهای بیشتری برای عرض، ارتفاع و تصاویر مرجع اختیاری در دسترس قرار می‌گیرد. | DYNAMIC_COMBO | بله | "Flux.2 [pro]"<br>"Flux.2 [max]" |
| `prompt` | پرامپت برای تولید یا ویرایش تصویر (پیش‌فرض: رشته خالی). | STRING | بله | N/A |
| `seed` | بذر تصادفی مورد استفاده برای ایجاد نویز (پیش‌فرض: 0). از گزینه کنترل پس از تولید برای تصادفی‌سازی مقدار پس از هر اجرا پشتیبانی می‌کند. | INT | بله | 0 تا 18446744073709551615 |

### ورودی‌های Flux.2 [pro] و Flux.2 [max]

مشترک بین هر دو مدل — مجموعه پارامترها یکسان است.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.width` | عرض تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 256 تا 2048 (گام 32) |
| `model.height` | ارتفاع تصویر تولیدشده بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 256 تا 2048 (گام 32) |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model.images` | تصویر(های) مرجع اختیاری برای تولید تصویر به تصویر. حداکثر 8 تصویر. اسلات قابل‌گسترش: اتصال 1..8 مورد (`image_1`...`image_8`). | IMAGE | خیر | 0 تا 8 تصویر |

**نکته:**
- حداکثر تعداد تصاویر مرجع 8 است. اگر بیش از 8 تصویر ارائه شود، خطایی ایجاد می‌شود. تصاویر دسته‌ای نیز در این محدودیت به حساب می‌آیند، زیرا هر تصویر در یک دسته به‌صورت جداگانه شمرده می‌شود.
- تصاویر مرجع پیش از ارسال به API تغییر اندازه داده می‌شوند تا تعداد کل پیکسل‌ها از 2048 x 2048 فراتر نرود.
- مقادیر `model.width` و `model.height` بر هزینه تولید تأثیر می‌گذارند. هزینه همچنین به مدل انتخاب‌شده و به اینکه تصاویر مرجع ارائه شده باشند یا نه بستگی دارد.
