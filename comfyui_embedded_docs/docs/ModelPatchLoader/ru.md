# ModelPatchLoader

Узел ModelPatchLoader загружает файл патча модели из папки `model_patches` и подготавливает его для использования в рабочем процессе. Он автоматически определяет тип патча, содержащегося в файле, строит соответствующую архитектуру, загружает сохранённые веса и оборачивает всё в патчер модели, чтобы его можно было применить к другим моделям. Он поддерживает множество специализированных форматов патчей, включая дополнительные ветви ControlNet, модели встраивания признаков, адаптеры, модули управления анимацией/LLLite и подобные модули.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название` | Имя файла патча модели для загрузки из папки `model_patches`. Выберите один из доступных файлов патчей из списка. | COMBO | Да | Динамически создаваемый список всех файлов патчей моделей, найденных в папке `model_patches` |

Примечание: Этот узел помечен как экспериментальный. Тип патча определяется автоматически по содержимому файла, поэтому выбор типа вручную не требуется. Узел читает метаданные контрольной точки и проверяет ключи весов, чтобы определить, какую архитектуру построить (например, Qwen Image block-wise ControlNet, Qwen Image 2.1 Fun ControlNet, Z-Image ControlNet, Wan Uni3C ControlNet, MiniMax H3 Fun ControlNet, SigLIP feature projection, Lightricks duration head, Anima LLLite, MultiTalk или SUPIR). Веса загружаются с включённой безопасной загрузкой, а модель размещается на устройстве выгрузки внутри `CoreModelPatcher`, чтобы позже её можно было применить к другой модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL_PATCH` | Загруженный патч модели, обёрнутый в патчер модели, готовый к применению к модели в рабочем процессе | MODEL_PATCH |
