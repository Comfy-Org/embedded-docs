# ModelPatchLoader

Узел ModelPatchLoader загружает файл патча модели из папки `model_patches` и подготавливает его к использованию в рабочем процессе. Он автоматически определяет тип патча, содержащегося в файле, строит соответствующую архитектуру, загружает сохранённые веса и оборачивает всё в патчер модели, чтобы его можно было применить к другим моделям. Он поддерживает множество специализированных форматов патчей, включая дополнительные ветви ControlNet, модели эмбеддинга признаков, адаптеры, модули управления анимацией/LLLite и аналогичные модули.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название` | Имя файла патча модели для загрузки из папки `model_patches`. Выберите один из доступных файлов патчей из списка. | COMBO | Да | Динамически формируемый список всех файлов патчей модели, найденных в папке `model_patches` |

Примечание: Этот узел помечен как экспериментальный. Тип патча определяется автоматически по содержимому файла, поэтому ручной выбор типа не требуется. Узел считывает метаданные чекпоинта и проверяет ключи весов, чтобы определить, какую архитектуру строить (например, поблочный ControlNet Qwen Image, ControlNet Z-Image, ControlNet Wan Uni3C, ControlNet MiniMax H3 Fun, проекция признаков SigLIP, duration head от Lightricks, LLLite Anima, MultiTalk или SUPIR). Веса загружаются с включённым безопасным режимом загрузки, а модель размещается на устройстве выгрузки внутри `CoreModelPatcher`, чтобы позже её можно было применить к другой модели.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL_PATCH` | Загруженный патч модели, обёрнутый в патчер модели, готовый к применению к модели в рабочем процессе | MODEL_PATCH |
