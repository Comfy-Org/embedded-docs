# ModelPatchLoader

Узел ModelPatchLoader загружает специализированные файлы патчей модели из папки model_patches. Он автоматически определяет тип патча по содержимому файла и загружает соответствующую архитектуру модели, после чего оборачивает её в ModelPatcher для использования в рабочем процессе. Этот узел поддерживает различные типы патчей, включая блоки controlnet, модели эмбеддеров признаков и другие специализированные архитектуры.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название` | Имя файла патча модели для загрузки из каталога model_patches | STRING | Да | Все доступные файлы патчей модели из папки model_patches |

Примечание: Этот узел помечен как экспериментальный. Тип патча определяется автоматически по содержимому файла, поэтому ручной выбор типа не требуется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL_PATCH` | Загруженный патч модели, обёрнутый в ModelPatcher для использования в рабочем процессе | MODEL_PATCH |
