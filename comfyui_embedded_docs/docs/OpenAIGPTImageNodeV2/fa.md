# OpenAI GPT Image ۲

این گره با استفاده از OpenAI GPT Image API تصاویر تولید می‌کند. از چندین مدل (`gpt-image-2`، `gpt-image-1.5` و `gpt-image-1`) پشتیبانی می‌کند، امکان ارائه تصاویر مرجع برای ویرایش را فراهم می‌کند و می‌تواند از ماسک برای مشخص کردن بخش‌هایی از تصویر که باید تغییر کنند استفاده کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل OpenAI GPT Image مورد استفاده. انتخاب یک مدل پارامترهای اضافی مخصوص همان مدل را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | متن راهنما (prompt) برای GPT Image (پیش‌فرض: `""`). | STRING | بله | N/A |
| `n` | تعداد تصاویر برای تولید (پیش‌فرض: `1`). | INT | بله | 1 تا 8 |
| `seed` | Seed برای تکرارپذیری (پیش‌فرض: `0`). هنوز در بک‌اند پیاده‌سازی نشده است. | INT | بله | 0 تا 2147483647 |

### ورودی‌های gpt-image-2

این ورودی‌ها زمانی ظاهر می‌شوند که `model` روی `gpt-image-2` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `size` | اندازه تصویر. برای استفاده از عرض و ارتفاع سفارشی، «Custom» را انتخاب کنید (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `custom_width` | فقط زمانی استفاده می‌شود که `model.size` برابر «Custom» باشد. باید مضربی از 16 باشد (پیش‌فرض: `1024`). | INT | خیر | 1024 تا 3840 |
| `custom_height` | فقط زمانی استفاده می‌شود که `model.size` برابر «Custom» باشد. باید مضربی از 16 باشد (پیش‌فرض: `1024`). | INT | خیر | 1024 تا 3840 |
| `background` | بازگرداندن تصویر با یا بدون پس‌زمینه (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"opaque"` |
| `quality` | کیفیت تصویر؛ بر هزینه و زمان تولید تأثیر می‌گذارد (پیش‌فرض: `"low"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | تصویر(های) مرجع اختیاری برای ویرایش تصویر. حداکثر 16 تصویر. برای جزئیات به ورودی‌های مرجع مراجعه کنید. | IMAGE | خیر | 0 تا 16 |
| `model.mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین خواهند شد). دقیقاً به یک تصویر مرجع نیاز دارد. | MASK | خیر | N/A |

### ورودی‌های gpt-image-1.5 و gpt-image-1

این ورودی‌ها زمانی ظاهر می‌شوند که `model` روی `gpt-image-1.5` یا `gpt-image-1` تنظیم شده باشد. هر دو مدل مجموعه پارامترهای یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `size` | اندازه تصویر (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `background` | بازگرداندن تصویر با یا بدون پس‌زمینه (پیش‌فرض: `"auto"`). | COMBO | بله | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `quality` | کیفیت تصویر؛ بر هزینه و زمان تولید تأثیر می‌گذارد (پیش‌فرض: `"low"`). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | تصویر(های) مرجع اختیاری برای ویرایش تصویر. حداکثر 16 تصویر. برای جزئیات به ورودی‌های مرجع مراجعه کنید. | IMAGE | خیر | 0 تا 16 |
| `model.mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین خواهند شد). دقیقاً به یک تصویر مرجع نیاز دارد. | MASK | خیر | N/A |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model.images` | اسلات قابل توسعه (Growable slot): اتصال 1..N آیتم (مثلاً `image_1`...`image_16`)؛ حداکثر 16 تصویر مرجع برای همه مدل‌ها. | IMAGE | خیر | 1 تا 16 |
| `model.mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین خواهند شد). دقیقاً به یک تصویر مرجع نیاز دارد. | MASK | خیر | N/A |

**محدودیت‌ها و الزامات پارامترها:**

- هنگامی که `model.size` برابر «Custom» است (فقط gpt-image-2)، `model.custom_width` و `model.custom_height` هر دو باید مضربی از 16 باشند، طولانی‌ترین ضلع نباید از 3840 تجاوز کند، نسبت ابعاد نباید از 3:1 بیشتر شود، و تعداد کل پیکسل‌ها باید بین 655,360 و 8,294,400 باشد.
- `model.mask` دقیقاً به یک تصویر مرجع در `model.images` نیاز دارد: بدون تصویر قابل استفاده نیست و با بیش از یک تصویر نیز قابل استفاده نیست.
- هنگامی که `model.mask` استفاده می‌شود، ابعاد آن باید با ابعاد تصویر مرجع مطابقت داشته باشد.
- هنگامی که `model.images` ارائه شود، گره در حالت ویرایش تصویر عمل می‌کند؛ بدون `model.images`، تصاویر را تنها از روی prompt تولید می‌کند.
- تصاویر مرجع قبل از ارسال به API کوچک‌سازی (downscale) می‌شوند.
- `seed` در حال حاضر در بک‌اند پیاده‌سازی نشده است.
