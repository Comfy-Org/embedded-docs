# OpenAI GPT Image ۲

این گره با استفاده از API تصویر GPT از OpenAI تصویر تولید می‌کند. این گره از چند مدل GPT Image، تصاویر مرجع اختیاری برای ویرایش، و یک ماسک اختیاری برای ترمیم تصویر (inpainting) پشتیبانی می‌کند. وقتی تصاویر مرجع ارائه شوند، گره یک درخواست ویرایش به API ارسال می‌کند؛ در غیر این صورت یک درخواست تولید ساده ارسال می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل GPT Image متعلق به OpenAI که باید استفاده شود. انتخاب یک مدل، پارامترهای اضافی مخصوص آن مدل را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | متن راهنما (prompt) برای GPT Image (پیش‌فرض: ""). | STRING | بله | N/A |
| `n` | تعداد تصاویری که تولید می‌شوند (پیش‌فرض: ۱). | INT | بله | ۱ تا ۸ |
| `seed` | دانه (seed) برای تکرارپذیری (پیش‌فرض: ۰). هنوز در بک‌اند پیاده‌سازی نشده است. | INT | بله | ۰ تا ۲۱۴۷۴۸۳۶۴۷ |

### ورودی‌های gpt-image-2

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |

| `model.size` | اندازه تصویر. برای استفاده از عرض و ارتفاع سفارشی، گزینه «Custom» را انتخاب کنید (پیش‌فرض: «auto»). | COMBO | بله | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |

| `model.custom_height` | فقط زمانی استفاده می‌شود که `size` برابر «Custom» باشد. باید مضربی از ۱۶ باشد (پیش‌فرض: ۱۰۲۴). | INT | خیر | ۱۰۲۴ تا ۳۸۴۰ |

### ورودی‌های gpt-image-1.5 و gpt-image-1

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model.size` | اندازه تصویر (پیش‌فرض: «auto»). | COMBO | بله | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `model.background` | بازگرداندن تصویر با یا بدون پس‌زمینه (پیش‌فرض: «auto»). | COMBO | بله | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | کیفیت تصویر؛ بر هزینه و زمان تولید تأثیر می‌گذارد (پیش‌فرض: «low»). | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |

### ورودی‌های مرجع

این ورودی‌ها برای همه مدل‌ها در دسترس هستند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model.images` | تصویر(های) مرجع اختیاری برای ویرایش تصویر. اسلات قابل افزایش: تا ۱۶ تصویر (`image_1` تا `image_16`) را متصل کنید. | IMAGE | خیر | ۰ تا ۱۶ تصویر |
| `model.mask` | ماسک اختیاری برای ترمیم تصویر (ناحیه‌های سفید جایگزین می‌شوند). دقیقاً به یک تصویر مرجع نیاز دارد. | MASK | خیر | N/A |

**محدودیت‌ها و قیود پارامترها:**

- وقتی `model.size` برابر «Custom» است (فقط در gpt-image-2)، `model.custom_width` و `model.custom_height` باید مضربی از ۱۶ باشند، طولانی‌ترین ضلع نباید از ۳۸۴۰ پیکسل بیشتر شود، نسبت تصویر نباید از ۳:۱ تجاوز کند و تعداد کل پیکسل‌ها باید بین ۶۵۵٬۳۶۰ و ۸٬۲۹۴٬۴۰۰ باشد.
- ماسک دقیقاً به یک تصویر مرجع نیاز دارد. ماسک بدون تصویر ورودی قابل استفاده نیست و با چند تصویر ورودی نیز نمی‌توان از آن استفاده کرد.
- وقتی ماسک ارائه می‌شود، ارتفاع و عرض ماسک باید با ارتفاع و عرض تصویر ورودی یکسان باشد.
- تصاویر مرجع قبل از ارسال به API حداکثر به ۲۰۴۸×۲۰۴۸ پیکسل کاهش مقیاس می‌یابند.
- پارامتر `seed` هنوز در بک‌اند پیاده‌سازی نشده است.
- اگر API در یک پاسخ واحد تصاویری با ابعاد متفاوت بازگرداند، همه تصاویر به‌گونه‌ای تغییر اندازه می‌یابند که با ابعاد اولین تصویر مطابقت داشته باشند.
