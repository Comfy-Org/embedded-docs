# OpenAI GPT Image 2

このノードは、OpenAI の GPT Image API を使用して画像を生成します。複数の GPT Image モデル、編集用のオプションの参照画像、およびインペインティング用のオプションのマスクをサポートしています。参照画像が指定された場合、ノードは API に編集リクエストを送信し、それ以外の場合は通常の生成リクエストを送信します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 使用する OpenAI GPT Image モデル。モデルを選択すると、そのモデル固有の追加パラメータが表示されます。 | DYNAMIC_COMBO | はい | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | GPT Image 用のテキストプロンプト（デフォルト: ""）。 | STRING | はい | N/A |
| `n` | 生成する画像の枚数（デフォルト: 1）。 | INT | はい | 1〜8 |
| `seed` | 再現性のためのシード（デフォルト: 0）。バックエンドではまだ実装されていません。 | INT | はい | 0〜2147483647 |

### 参照入力

これらの入力は、すべてのモデルで使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model.images` | 画像編集用のオプションの参照画像（複数可）。追加可能スロット: 最大 16 枚の画像（`image_1` から `image_16`）を接続できます。 | IMAGE | いいえ | 0〜16 枚 |
| `model.mask` | インペインティング用のオプションのマスク（白い領域が置き換えられます）。参照画像が正確に 1 枚必要です。 | MASK | いいえ | N/A |

**パラメータの制約と制限:**

- `model.size` が "Custom"（gpt-image-2 のみ）の場合、`model.custom_width` と `model.custom_height` は 16 の倍数である必要があり、最長辺は 3840 ピクセル以下、アスペクト比は 3:1 以下、総ピクセル数は 655,360 から 8,294,400 の間である必要があります。
- マスクには参照画像が正確に 1 枚必要です。マスクは入力画像なしでは使用できず、複数の入力画像と一緒に使用することもできません。
- マスクを指定する場合、マスクの高さと幅は入力画像の高さと幅と一致している必要があります。
- 参照画像は、API に送信される前に、最大 2048 x 2048 ピクセルに縮小されます。
- `seed` パラメータはバックエンドではまだ実装されていません。
- API が 1 つのレスポンスで異なる寸法の画像を返した場合、すべての画像が最初の画像の寸法に合わせてリサイズされます。
