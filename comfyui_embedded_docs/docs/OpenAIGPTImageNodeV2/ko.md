# OpenAI GPT 이미지 2

이 노드는 OpenAI의 GPT Image API를 사용하여 이미지를 생성합니다. 여러 GPT Image 모델, 편집용 선택적 참조 이미지, 인페인팅용 선택적 마스크를 지원합니다. 참조 이미지가 제공되면 노드는 API에 편집 요청을 보내고, 그렇지 않으면 일반 생성 요청을 보냅니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 OpenAI GPT Image 모델입니다. 모델을 선택하면 해당 모델에 특화된 추가 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | GPT Image용 텍스트 프롬프트입니다(기본값: ""). | STRING | 예 | N/A |
| `n` | 생성할 이미지 수입니다(기본값: 1). | INT | 예 | 1 to 8 |
| `seed` | 재현을 위한 시드입니다(기본값: 0). 아직 백엔드에서 구현되지 않았습니다. | INT | 예 | 0 to 2147483647 |

### gpt-image-2 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model.size` | 이미지 크기입니다. 사용자 지정 너비와 높이를 사용하려면 "Custom"을 선택하세요(기본값: "auto"). | COMBO | 예 | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `model.custom_width` | `size`가 "Custom"일 때만 사용됩니다. 16의 배수여야 합니다(기본값: 1024). | INT | 아니오 | 1024 to 3840 |
| `model.custom_height` | `size`가 "Custom"일 때만 사용됩니다. 16의 배수여야 합니다(기본값: 1024). | INT | 아니오 | 1024 to 3840 |
| `model.background` | 배경이 있거나 없는 이미지를 반환합니다(기본값: "auto"). | COMBO | 예 | `"auto"`<br>`"opaque"` |
| `model.quality` | 이미지 품질로, 비용과 생성 시간에 영향을 줍니다(기본값: "low"). | COMBO | 예 | `"low"`<br>`"medium"`<br>`"high"` |

### gpt-image-1.5 및 gpt-image-1 입력

이 두 모델은 동일한 모델별 매개변수 세트를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model.size` | 이미지 크기입니다(기본값: "auto"). | COMBO | 예 | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `model.background` | 배경이 있거나 없는 이미지를 반환합니다(기본값: "auto"). | COMBO | 예 | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | 이미지 품질로, 비용과 생성 시간에 영향을 줍니다(기본값: "low"). | COMBO | 예 | `"low"`<br>`"medium"`<br>`"high"` |

### 참조 입력

이 입력은 모든 모델에 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model.images` | 이미지 편집용 선택적 참조 이미지입니다. 확장 가능한 슬롯: 최대 16개 이미지(`image_1`~`image_16`)를 연결할 수 있습니다. | IMAGE | 아니오 | 0 to 16 images |
| `model.mask` | 인페인팅용 선택적 마스크입니다(흰색 영역이 교체됩니다). 정확히 하나의 참조 이미지가 필요합니다. | MASK | 아니오 | N/A |

**매개변수 제약 조건 및 제한 사항:**

- `model.size`가 "Custom"인 경우(gpt-image-2 전용), `model.custom_width` 및 `model.custom_height`는 16의 배수여야 하며, 가장 긴 변은 3840픽셀을 초과할 수 없고, 종횡비는 3:1을 초과할 수 없으며, 총 픽셀 수는 655,360에서 8,294,400 사이여야 합니다.
- 마스크는 정확히 하나의 참조 이미지가 필요합니다. 마스크는 입력 이미지 없이는 사용할 수 없으며, 여러 입력 이미지와 함께 사용할 수도 없습니다.
- 마스크가 제공되면 마스크의 높이와 너비는 입력 이미지의 높이와 너비와 일치해야 합니다.
- 참조 이미지는 API로 전송되기 전에 최대 2048 x 2048 총 픽셀로 축소됩니다.
- `seed` 매개변수는 아직 백엔드에서 구현되지 않았습니다.
- API가 단일 응답에서 서로 다른 크기의 이미지를 반환하면 모든 이미지가 첫 번째 이미지의 크기에 맞게 조정됩니다.

| 출력 이름 | 설명 | 데이터 타입 |
