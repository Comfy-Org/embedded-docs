# OpenAI GPT Image 2.5

Этот узел генерирует изображения с помощью OpenAI GPT Image API. Он поддерживает пять моделей — `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst`, `gpt-image-2`, `gpt-image-1.5` и `gpt-image-1` — позволяет прикреплять эталонные изображения для редактирования изображений и может использовать маску, чтобы указать, какие части изображения нужно заменить.

## Входы

### Общие входы

Эти входы отображаются всегда.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI GPT Image для использования. Выбор модели открывает дополнительные параметры, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2.5-flare"`<br>`"gpt-image-2.5-sunburst"`<br>`"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | Текстовый промпт для GPT Image (по умолчанию: `""`). | STRING | Да | N/A |
| `n` | Сколько изображений сгенерировать (по умолчанию: `1`). | INT | Да | от 1 до 8 |
| `seed` | Seed для воспроизводимости (по умолчанию: `0`). Пока не реализовано в бэкенде. | INT | Да | от 0 до 2147483647 |

### Входы gpt-image-2.5-flare и gpt-image-2.5-sunburst

Эти входы появляются, когда `model` имеет значение `gpt-image-2.5-flare` или `gpt-image-2.5-sunburst`. Обе модели используют один и тот же набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `size` | Размер изображения. Выберите "Custom", чтобы использовать пользовательские ширину и высоту (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `custom_width` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | от 480 до 3840 (шаг 16) |
| `custom_height` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | от 480 до 3840 (шаг 16) |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `quality` | Качество изображения; влияет на стоимость и время генерации (по умолчанию: `"low"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.images` | Необязательное эталонное изображение(я) для редактирования изображений. До 16 изображений. Подробнее см. в разделе «Эталонные входы». | IMAGE | Нет | от 0 до 16 |
| `model.mask` | Необязательная маска для inpainting (белые области будут заменены). Требует ровно одно эталонное изображение. | MASK | Нет | N/A |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.images` | Расширяемый слот: подключите от 1 до N элементов (например, `image_1`...`image_16`); до 16 эталонных изображений для всех моделей. | IMAGE | Нет | от 0 до 16 |
| `model.mask` | Необязательная маска для inpainting (белые области будут заменены). Требует ровно одно эталонное изображение. | MASK | Нет | N/A |

**Ограничения параметров:**

- Когда `model.size` имеет значение "Custom" (только для `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2`), `model.custom_width` и `model.custom_height` должны оба быть кратны 16, самая длинная сторона не должна превышать 3840, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно быть от 655 360 до 8 294 400.
- `model.mask` требует ровно одно эталонное изображение в `model.images`: маску нельзя использовать без изображения, и её нельзя использовать с более чем одним изображением.
- Когда используется `model.mask`, её высота и ширина должны совпадать с высотой и шириной эталонного изображения.
- Когда указан `model.images`, узел работает в режиме редактирования изображений; без `model.images` он генерирует изображения только по промпту.
- Эталонные изображения и маска уменьшаются в масштабе перед отправкой в API.
- Уровни качества `"xhigh"` и `"max"` доступны только для `gpt-image-2.5-flare` и `gpt-image-2.5-sunburst`.
- `seed` в настоящее время не реализован в бэкенде.
