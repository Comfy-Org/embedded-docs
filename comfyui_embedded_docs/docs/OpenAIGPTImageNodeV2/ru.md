# OpenAI GPT Image 2

Этот узел генерирует изображения с помощью OpenAI GPT Image API. Он поддерживает несколько моделей (`gpt-image-2`, `gpt-image-1.5` и `gpt-image-1`), позволяет предоставлять эталонные изображения для редактирования и использовать маску для указания частей изображения, которые нужно изменить.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI GPT Image для использования. Выбор модели открывает дополнительные параметры, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | Текстовый промпт для GPT Image (по умолчанию: `""`). | STRING | Да | N/A |
| `n` | Сколько изображений сгенерировать (по умолчанию: `1`). | INT | Да | 1 до 8 |
| `seed` | Сид для воспроизводимости результатов (по умолчанию: `0`). В бэкенде пока не реализовано. | INT | Да | 0 до 2147483647 |

### Входы gpt-image-2

Эти входы появляются, когда для `model` задано значение `gpt-image-2`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `size` | Размер изображения. Выберите «Custom», чтобы использовать собственные ширину и высоту (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `custom_width` | Используется только когда `model.size` имеет значение «Custom». Значение должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | 1024 до 3840 |
| `custom_height` | Используется только когда `model.size` имеет значение «Custom». Значение должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | 1024 до 3840 |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"opaque"` |
| `quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: `"low"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | Необязательное эталонное изображение (изображения) для редактирования. До 16 изображений. Подробнее см. «Эталонные входы». | IMAGE | Нет | 0 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | N/A |

### Входы gpt-image-1.5 и gpt-image-1

Эти входы появляются, когда для `model` задано значение `gpt-image-1.5` или `gpt-image-1`. Обе модели используют одинаковый набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `size` | Размер изображения (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: `"low"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | Необязательное эталонное изображение (изображения) для редактирования. До 16 изображений. Подробнее см. «Эталонные входы». | IMAGE | Нет | 0 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | N/A |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.images` | Расширяемый слот: можно подключить от 1 до N элементов (например, `image_1`...`image_16`); до 16 эталонных изображений для всех моделей. | IMAGE | Нет | 1 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | N/A |

**Ограничения параметров:**

- Когда `model.size` имеет значение «Custom» (только для gpt-image-2), `model.custom_width` и `model.custom_height` должны быть кратны 16, самая длинная сторона не должна превышать 3840, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно составлять от 655 360 до 8 294 400.
- `model.mask` требует ровно одного эталонного изображения в `model.images`: его нельзя использовать без изображения или с более чем одним изображением.
- При использовании `model.mask` её размеры должны совпадать с размерами эталонного изображения.
- Если указано `model.images`, узел работает в режиме редактирования изображения; без `model.images` он генерирует изображения только на основе промпта.
- Эталонные изображения уменьшаются перед отправкой в API.
- `seed` в настоящее время не реализован в бэкенде.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `image` | Сгенерированное изображение или изображения. Все возвращённые изображения объединяются в один пакет; если их размеры различаются, они масштабируются до размеров первого изображения. | IMAGE |
