# OpenAI GPT Image 2

Этот узел генерирует изображения с помощью OpenAI GPT Image API. Он поддерживает несколько моделей GPT Image, необязательные референсные изображения для редактирования и необязательную маску для инпейнтинга. Если предоставлены референсные изображения, узел отправляет запрос на редактирование в API; в противном случае он отправляет обычный запрос на генерацию.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI GPT Image для использования. Выбор модели открывает дополнительные параметры, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | Текстовый запрос для GPT Image (по умолчанию: ""). | STRING | Да | N/A |
| `n` | Сколько изображений генерировать (по умолчанию: 1). | INT | Да | 1 to 8 |
| `seed` | Сид для воспроизводимости (по умолчанию: 0). Пока не реализовано в бэкенде. | INT | Да | 0 to 2147483647 |

### Входы gpt-image-2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.size` | Размер изображения. Выберите "Custom", чтобы использовать собственную ширину и высоту (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `model.custom_width` | Используется только когда `size` равно "Custom". Должно быть кратно 16 (по умолчанию: 1024). | INT | Нет | 1024 to 3840 |
| `model.custom_height` | Используется только когда `size` равно "Custom". Должно быть кратно 16 (по умолчанию: 1024). | INT | Нет | 1024 to 3840 |
| `model.background` | Возвращает изображение с фоном или без фона (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>`"opaque"` |
| `model.quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: "low"). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |

### Входы gpt-image-1.5 и gpt-image-1

Эти две модели используют одинаковый набор специфических для модели параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.size` | Размер изображения (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"` |
| `model.background` | Возвращает изображение с фоном или без фона (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: "low"). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |

### Референсные входы

Эти входы доступны для всех моделей.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.images` | Необязательное референсное изображение(я) для редактирования изображений. Расширяемый слот: подключайте до 16 изображений (`image_1` to `image_16`). | IMAGE | Нет | 0 to 16 images |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно референсное изображение. | MASK | Нет | N/A |

**Ограничения и лимиты параметров:**

- Когда `model.size` равно "Custom" (только для gpt-image-2), `model.custom_width` и `model.custom_height` должны быть кратны 16, самая длинная сторона не должна превышать 3840 пикселей, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно быть от 655,360 до 8,294,400.
- Маска требует ровно одного референсного изображения. Маску нельзя использовать без входного изображения и нельзя использовать с несколькими входными изображениями.
- Если маска предоставлена, высота и ширина маски должны совпадать с высотой и шириной входного изображения.
- Референсные изображения уменьшаются до максимум 2048 x 2048 общих пикселей перед отправкой в API.
- Параметр `seed` пока не реализован в бэкенде.
- Если API возвращает изображения с разными размерами в одном ответе, все изображения масштабируются до размеров первого изображения.
