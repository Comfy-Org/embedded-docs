# OpenAI GPT Image 2.6

Этот узел генерирует изображения с помощью API GPT Image от OpenAI. Он поддерживает шесть моделей — `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst`, `gpt-image-2` и `gpt-image-1.5` — позволяет прикреплять эталонные изображения для редактирования изображений и может использовать маску, чтобы указать, какие части изображения заменить.

## Входы

### Общие входы

Эти входы всегда видны.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI GPT Image для использования. Выбор модели открывает дополнительные параметры, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2.6-flare"`<br>`"gpt-image-2.6-sunburst"`<br>`"gpt-image-2.5-flare"`<br>`"gpt-image-2.5-sunburst"`<br>`"gpt-image-2"`<br>`"gpt-image-1.5"` |
| `prompt` | Текстовый промпт для GPT Image (по умолчанию: `""`). | STRING | Да | Н/Д |
| `n` | Сколько изображений сгенерировать (по умолчанию: `1`). | INT | Да | от 1 до 8 |
| `seed` | Сид для воспроизводимости (по умолчанию: `0`). Пока не реализовано в бэкенде. | INT | Да | от 0 до 2147483647 |

### Входы gpt-image-2.6-flare и gpt-image-2.6-sunburst

Эти входы появляются, когда `model` имеет значение `gpt-image-2.6-flare` или `gpt-image-2.6-sunburst`. Обе модели используют один и тот же набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `size` | Размер изображения. Выберите "Custom", чтобы использовать пользовательские ширину и высоту (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `custom_width` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | от 480 до 3840 (шаг 16) |
| `custom_height` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | от 480 до 3840 (шаг 16) |
| `background` | Возвращать изображение с фоном или без фона (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `quality` | Качество изображения; влияет на стоимость и время генерации (по умолчанию: `"low"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.images` | Необязательные эталонные изображения для редактирования изображений. До 16 изображений. Подробности см. в разделе «Эталонные входы». | IMAGE | Нет | от 0 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | Н/Д |
| `model.complexity` | Насколько модель планирует изображение перед рендерингом. Меньшие значения быстрее возвращают результат, большие — обеспечивают большее планирование. По умолчанию: `"high"`. | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.images` | Расширяемый слот: подключите 1..N элементов (например, `image_1`...`image_16`); до 16 эталонных изображений для всех моделей. | IMAGE | Нет | от 0 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | Н/Д |

**Ограничения параметров:**

- Когда `model.size` имеет значение "Custom" (только для `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2`), `model.custom_width` и `model.custom_height` должны оба быть кратны 16, длина самой длинной стороны не должна превышать 3840, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно быть от 655,360 до 8,294,400.
- `model.mask` требует ровно одного эталонного изображения в `model.images`: его нельзя использовать без изображения и нельзя использовать с более чем одним изображением.
- При использовании `model.mask` его высота и ширина должны совпадать с высотой и шириной эталонного изображения.
- Если `model.images` указан, узел работает в режиме редактирования изображений; без `model.images` он генерирует изображения только по промпту.
- Эталонные изображения и маска уменьшаются перед отправкой в API.
- Уровни качества `"xhigh"` и `"max"` доступны только для `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-image-2.5-flare` и `gpt-image-2.5-sunburst`.
- `model.complexity` доступен только для `gpt-image-2.6-flare` и `gpt-image-2.6-sunburst`; остальные модели используют фиксированную глубину планирования.
- `seed` в настоящее время не реализован в бэкенде.
