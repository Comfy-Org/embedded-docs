# FLUX 3 Image Layout Prompt

يبني جدول التخطيط الذي يقرأه FLUX 3 Image من الموجّه. يأخذ العناصر المرسومة في عقدة Create Bounding Boxes ويضيفها إلى الموجّه الخاص بك كقائمة من الصناديق، لكل منها معرّف وإحداثياته ووصفه. أشِر إلى صندوق في الموجّه بالصيغة `<obj_N>` لربط الكلمات بتلك المنطقة، ثم صِل المخرج بمدخل الموجّه في عقدة FLUX 3 Image. إذا لم تكن هناك عناصر متصلة، يُعاد الموجّه دون تغيير.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `prompt` | نص الموجّه. أشِر إلى الصندوق N بالصيغة `<obj_N>` لربط الكلمات به. | STRING | نعم | - |
| `element` | العناصر المراد وضعها في التخطيط، مأخوذة من عقدة Create Bounding Boxes. لا تُستخدم لوحات الألوان، لذا صِف الألوان في الوصف بدلاً من ذلك. | ARRAY | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `prompt` | الموجّه مع إلحاق جدول تخطيط الصناديق به، وجاهز للتغذية إلى عقدة FLUX 3 Image. | STRING |
