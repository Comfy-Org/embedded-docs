# FLUX 3 Image Layout Prompt

جدول چیدمانی را می‌سازد که FLUX 3 Image از یک پرامپت می‌خواند. عناصر رسم‌شده در گره Create Bounding Boxes را می‌گیرد و آن‌ها را به‌صورت فهرستی از جعبه‌ها به پرامپت شما می‌افزاید؛ هر جعبه دارای یک id، مختصات آن و توضیحش است. برای گره‌زدن کلمات به آن ناحیه، در پرامپت به یک جعبه با `<obj_N>` ارجاع دهید، سپس خروجی را به ورودی `prompt` گره FLUX 3 Image متصل کنید. اگر هیچ عنصری متصل نباشد، پرامپت بدون تغییر بازگردانده می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `prompt` | متن پرامپت. برای گره‌زدن کلمات به جعبه N، آن را با `<obj_N>` ارجاع دهید. | STRING | بله | - |
| `element` | عناصری که باید در چیدمان قرار گیرند و از گره Create Bounding Boxes گرفته می‌شوند. از پالت‌های رنگ استفاده نمی‌شود، بنابراین رنگ‌ها را به‌جای آن در توضیح توصیف کنید. | ARRAY | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `prompt` | پرامپت به‌همراه جدول چیدمان افزوده‌شده، آماده برای تغذیه به گره FLUX 3 Image. | STRING |
