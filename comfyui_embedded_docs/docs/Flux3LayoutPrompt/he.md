# FLUX 3 Image Layout Prompt

בונה את טבלת הפריסה ש-FLUX 3 Image קורא מתוך פרומפט. הוא לוקח את האלמנטים שצוירו בצומת Create Bounding Boxes ומצרף אותם לפרומפט שלך כרשימת תיבות, שלכל אחת מהן יש מזהה, הקואורדינטות שלה והתיאור שלה. אזכר תיבה בפרומפט כ-`<obj_N>` כדי לקשור מילים לאזור הזה, ואז חבר את הפלט לקלט ה-`prompt` של הצומת FLUX 3 Image. כאשר לא מחוברים אלמנטים, הפרומפט מוחזר ללא שינוי.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `prompt` | טקסט הפרומפט. אזכר תיבה N כ-`<obj_N>` כדי לקשור אליה מילים. | STRING | כן | - |
| `element` | האלמנטים שיש למקם בפריסה, שנלקחים מהצומת Create Bounding Boxes. אין שימוש בפלטות צבע, ולכן יש לתאר צבעים בתיאור במקום זאת. | ARRAY | כן | - |
