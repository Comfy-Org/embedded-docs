# FLUX 3 Image Layout Prompt

Создаёт таблицу компоновки, которую FLUX 3 Image считывает из промпта. Он берёт элементы, нарисованные в узле Create Bounding Boxes, и добавляет их к вашему промпту в виде списка боксов, каждый из которых имеет id, координаты и описание. Ссылайтесь на бокс в промпте как `<obj_N>`, чтобы привязать слова к этой области, затем подключите выход к входу `prompt` узла FLUX 3 Image. Если элементы не подключены, промпт возвращается без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текст промпта. Ссылайтесь на бокс N как `<obj_N>`, чтобы привязать к нему слова. | STRING | Да | - |
| `element` | Элементы для размещения в компоновке, взятые из узла Create Bounding Boxes. Цветовые палитры не используются, поэтому указывайте цвета в описании. | ARRAY | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `prompt` | Промпт с добавленной таблицей компоновки боксов, готовый для подачи в узел FLUX 3 Image. | STRING |
