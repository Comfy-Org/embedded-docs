# Mahiro

צומת Mahiro משנה את פונקציית ההנחיה כך שתתמקד יותר בכיוון של הפרומפט החיובי, ולא בהבדל בין הפרומפט החיובי לפרומפט השלילי. הוא יוצר מודל מתוקן (patched) שמיישם גישת סקיילינג הנחיה מותאמת אישית באמצעות דמיון קוסינוס בין פלטי denoising מותנים ולא-מותנים שעברו נרמול. צומת ניסיוני זה עוזר לכוון את היצירה בעוצמה רבה יותר לעבר הכיוון המיועד של הפרומפט החיובי.
