# استنتاج MoGe

MoGe را روی تصاویر اجرا کنید تا عمق و هندسه را تخمین بزنید. این گره یک تصویر ورودی را از طریق مدل MoGe پردازش می‌کند تا یک ابر نقطه‌ای سه‌بعدی، نقشه عمق، پارامترهای درونی دوربین، یک ماسک و نرمال‌های سطح تولید کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `moge_model` | مدل MoGe برای استفاده در استنتاج. | MOGE_MODEL | بله | N/A |
| `image` | تصویر ورودی برای تخمین عمق و هندسه. فقط سه کانال رنگی اول (RGB) استفاده می‌شوند. | IMAGE | بله | N/A |
| `resolution_level` | وضوح پردازش را کنترل می‌کند. 0 = سریع‌ترین، 9 = بیشترین جزئیات. (پیش‌فرض: 9) | INT | بله | 0 تا 9 |
| `fov_x_degrees` | (پیشرفته) میدان دید افقی دوربین مبدأ. فاصله کانونی‌ای را تنظیم می‌کند که برای بازتصویر نقشه عمق به فضای سه‌بعدی استفاده می‌شود. 0 = بازیابی خودکار از نقاط پیش‌بینی‌شده. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 170.0 (گام 0.1) |
| `batch_size` | تعداد تصاویر در هر فراخوانی استنتاج. اگر روی یک ویدیو / مجموعه تصویر طولانی با کمبود حافظه (OOM) مواجه شدید، این مقدار را کمتر کنید. (پیش‌فرض: 4) | INT | بله | 1 تا 64 |
| `force_projection` | (پیشرفته) تصویربرداری/تصویر معکوس نقاط پیش‌بینی‌شده را اجباری می‌کند. (پیش‌فرض: True) | BOOLEAN | بله | True/False |
| `apply_mask` | (پیشرفته) پیکسل‌های ماسک‌شده (آسمان / نامعتبر) را در نقاط و عمق برابر inf قرار می‌دهد تا مرحله مش‌سازی آن‌ها را حذف کند. غیرفعال کنید تا هندسه خام پیش‌بینی‌شده در همه‌جا حفظ شود؛ ماسک همچنان به‌صورت جداگانه بازگردانده می‌شود. (پیش‌فرض: True) | BOOLEAN | بله | True/False |
| `refine_steps` | (پیشرفته) فقط MoGe-3: پاس‌های پالایش حجمی تُنُک روی عمق پیش‌بینی‌شده. پاس‌های بیشتر جزئیات ریز و لبه‌ها را با هزینه تقریباً خطی تیزتر می‌کنند. مقدار 0 پالایش را غیرفعال می‌کند. در MoGe-1 / MoGe-2 نادیده گرفته می‌شود. (پیش‌فرض: 3) | INT | بله | 0 تا 8 |

توجه: وقتی `image` ورودی فریم‌های بیشتری از `batch_size` داشته باشد، گره آن‌ها را در چند فراخوانی استنتاج پردازش می‌کند و نتایج را در یک هندسه خروجی واحد ترکیب می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `moge_geometry` | یک دیکشنری شامل هندسه تخمین‌زده‌شده. شامل `image` اصلی است و ممکن است شامل `points` (ابر نقطه‌ای سه‌بعدی)، `depth` (نقشه عمق)، `intrinsics` (ماتریس پارامترهای درونی دوربین)، `mask` (ماسکی که پیکسل‌های معتبر را مشخص می‌کند)، و `normal` (نرمال‌های سطح) باشد. | MOGE_GEOMETRY |
