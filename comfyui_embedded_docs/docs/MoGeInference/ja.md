# MoGe推論

Run MoGe を単一の画像に実行して、深度とジオメトリを推定します。このノードは、入力画像を MoGe モデルで処理して、3D ポイントクラウド、深度マップ、カメラ内部パラメータ、マスク、サーフェス法線を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `moge_model` | 推論に使用する MoGe モデル。 | MOGE_MODEL | はい | N/A |
| `image` | 深度とジオメトリの推定に使用する入力画像。RGB チャンネルのみが使用され、アルファチャンネルは無視されます。 | IMAGE | はい | N/A |
| `resolution_level` | 処理解像度を制御します。0 が最も速く、9 が最も詳細です。(デフォルト: 9) | INT | はい | 0 to 9 |
| `fov_x_degrees` | (上級) ソースカメラの水平視野角（度単位）。深度マップを 3D に逆投影する際に使用する焦点距離を設定します。0.0 に設定すると、予測されたポイントから視野角を自動的に復元します。(デフォルト: 0.0) | FLOAT | はい | 0.0 to 170.0 |
| `batch_size` | 1 回の推論呼び出しで処理する画像の数。長い動画や大きな画像セットを処理する際にメモリが不足する場合は、この値を下げてください。(デフォルト: 4) | INT | はい | 1 to 64 |
| `force_projection` | (上級) 予測されたポイントの投影を強制します。(デフォルト: True) | BOOLEAN | はい | True/False |
| `apply_mask` | (上級) 有効にすると、ポイント出力と深度出力において、マスクで除外された（空または無効な）ピクセルが無限大に設定されます。これにより、メッシュ生成ツールがこれらの領域を無視するのに役立ちます。無効にすると、すべての場所で生の予測ジオメトリが保持されます。マスクは引き続き個別に返されます。(デフォルト: True) | BOOLEAN | はい | True/False |

注: `image` 入力には複数の画像を含めることができます。ノードはそれらを `batch_size` のグループで処理し、結果を単一の出力に結合します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `moge_geometry` | 推定されたジオメトリを含む辞書。常に入力 `image` (RGB チャンネルのみ) を含み、`points` (3D ポイントクラウド)、`depth` (深度マップ)、`intrinsics` (カメラ内部パラメータ行列)、`mask` (有効なピクセルを識別するマスク)、`normal` (サーフェス法線) が含まれる場合があります。 | MOGE_GEOMETRY |
