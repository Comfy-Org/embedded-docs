# MoGe 추론

단일 이미지에 MoGe를 실행하여 깊이와 지오메트리를 추정합니다. 이 노드는 입력 이미지를 MoGe 모델을 통해 처리하여 3D 포인트 클라우드, 깊이 맵, 카메라 내부 파라미터, 마스크 및 표면 법선을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `moge_model` | 추론에 사용할 MoGe 모델입니다. | MOGE_MODEL | 예 | N/A |
| `image` | 깊이 및 지오메트리 추정을 위한 입력 이미지입니다. RGB 채널만 사용되며 알파 채널은 무시됩니다. | IMAGE | 예 | N/A |
| `resolution_level` | 처리 해상도를 제어합니다. 0이 가장 빠르고 9가 가장 상세합니다. (기본값: 9) | INT | 예 | 0 to 9 |
| `fov_x_degrees` | (고급) 소스 카메라의 수평 화각(도)입니다. 깊이 맵을 3D로 역투영하는 데 사용되는 초점 거리를 설정합니다. 0.0으로 설정하면 예측된 포인트에서 화각을 자동으로 복원합니다. (기본값: 0.0) | FLOAT | 예 | 0.0 to 170.0 |
| `batch_size` | 추론 호출당 처리되는 이미지 수입니다. 긴 비디오나 대규모 이미지 세트를 처리할 때 메모리가 부족하면 이 값을 낮추십시오. (기본값: 4) | INT | 예 | 1 to 64 |
| `force_projection` | (고급) 예측된 포인트의 투영을 강제합니다. (기본값: True) | BOOLEAN | 예 | True/False |
| `apply_mask` | (고급) 활성화하면 마스크 처리된(하늘 또는 무효) 픽셀을 포인트 및 깊이 출력에서 무한대로 설정합니다. 이는 메시 생성 도구가 이러한 영역을 무시하는 데 도움이 됩니다. 비활성화하면 모든 위치에서 원시 예측 지오메트리를 유지하며, 마스크는 여전히 별도로 반환됩니다. (기본값: True) | BOOLEAN | 예 | True/False |

참고: `image` 입력에는 여러 이미지가 포함될 수 있습니다. 노드는 이미지를 `batch_size` 그룹으로 처리하고 결과를 단일 출력으로 결합합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `moge_geometry` | 추정된 지오메트리를 포함하는 딕셔너리입니다. 항상 입력 `image`(RGB 채널만)를 포함하며 `points`(3D 포인트 클라우드), `depth`(깊이 맵), `intrinsics`(카메라 내부 파라미터 행렬), `mask`(유효 픽셀을 식별하는 마스크), `normal`(표면 법선)을 포함할 수 있습니다. | MOGE_GEOMETRY |
