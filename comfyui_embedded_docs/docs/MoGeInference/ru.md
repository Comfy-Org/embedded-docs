# MoGe инференс

Запустите MoGe на одном изображении для оценки глубины и геометрии. Этот узел обрабатывает входное изображение через модель MoGe, формируя 3D-облако точек, карту глубины, внутренние параметры камеры, маску и нормали поверхности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_model` | Модель MoGe для выполнения инференса. | MOGE_MODEL | Да | N/A |
| `image` | Входное изображение для оценки глубины и геометрии. Используются только каналы RGB; альфа-канал игнорируется. | IMAGE | Да | N/A |
| `resolution_level` | Управляет разрешением обработки. 0 — максимальная скорость, 9 — максимальная детализация. (по умолчанию: 9) | INT | Да | от 0 до 9 |
| `fov_x_degrees` | (Дополнительно) Горизонтальное поле зрения исходной камеры в градусах. Задает фокусное расстояние, используемое для обратного проецирования карты глубины в 3D. Установите 0.0, чтобы автоматически восстановить поле зрения из предсказанных точек. (по умолчанию: 0.0) | FLOAT | Да | от 0.0 до 170.0 |
| `batch_size` | Количество изображений, обрабатываемых за один вызов инференса. Уменьшите это значение, если у вас заканчивается память при обработке длинных видео или больших наборов изображений. (по умолчанию: 4) | INT | Да | от 1 до 64 |
| `force_projection` | (Дополнительно) Принудительно выполняет проецирование предсказанных точек. (по умолчанию: True) | BOOLEAN | Да | True/False |
| `apply_mask` | (Дополнительно) При включении устанавливает для замаскированных (небо или недопустимые) пикселей значение бесконечности в выходах точек и глубины. Это помогает инструментам построения сетки игнорировать эти области. Отключите, чтобы сохранить необработанную предсказанную геометрию везде; маска по-прежнему возвращается отдельно. (по умолчанию: True) | BOOLEAN | Да | True/False |

Примечание: вход `image` может содержать несколько изображений. Узел обрабатывает их группами по `batch_size` и объединяет результаты в один выход.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `moge_geometry` | Словарь, содержащий оцененную геометрию. Он всегда включает входное `image` (только каналы RGB) и может содержать `points` (3D-облако точек), `depth` (карта глубины), `intrinsics` (матрица внутренних параметров камеры), `mask` (маска, определяющая допустимые пиксели) и `normal` (нормали поверхности). | MOGE_GEOMETRY |
