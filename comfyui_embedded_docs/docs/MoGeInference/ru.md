# MoGe инференс

Запустите MoGe на изображениях для оценки глубины и геометрии. Этот узел обрабатывает входное изображение через модель MoGe, чтобы сгенерировать 3D-облако точек, карту глубины, внутренние параметры камеры, маску и нормали к поверхности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_model` | Модель MoGe для использования при инференсе. | MOGE_MODEL | Да | N/A |
| `image` | Входное изображение для оценки глубины и геометрии. Используются только первые три цветовых канала (RGB). | IMAGE | Да | N/A |
| `resolution_level` | Управляет разрешением обработки. 0 = самый быстрый, 9 = максимальная детализация. (по умолчанию: 9) | INT | Да | 0 до 9 |
| `fov_x_degrees` | (Дополнительно) Горизонтальный угол обзора исходной камеры. Устанавливает фокусное расстояние, используемое для обратного проецирования карты глубины в 3D. 0 = автоматическое восстановление из предсказанных точек. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 170.0 (шаг 0.1) |
| `batch_size` | Количество изображений на один вызов инференса. Уменьшите, если возникает ошибка нехватки памяти на длинном видео / наборе изображений. (по умолчанию: 4) | INT | Да | 1 до 64 |
| `force_projection` | (Дополнительно) Принудительно проецирует предсказанные точки. (по умолчанию: True) | BOOLEAN | Да | True/False |
| `apply_mask` | (Дополнительно) Устанавливает замаскированные (небо / недействительные) пиксели в inf в точках и глубине, чтобы при построении сетки они отбрасывались. Отключите, чтобы сохранить исходную предсказанную геометрию везде; маска всё равно возвращается отдельно. (по умолчанию: True) | BOOLEAN | Да | True/False |
| `refine_steps` | (Дополнительно) Только для MoGe-3: проходы разреженного объемного уточнения по предсказанной глубине. Больше проходов обостряет мелкие детали и края при примерно линейных затратах. 0 отключает уточнение. Игнорируется MoGe-1 / MoGe-2. (по умолчанию: 3) | INT | Да | 0 до 8 |

Примечание: Когда входное `image` содержит больше кадров, чем `batch_size`, узел обрабатывает их за несколько вызовов инференса и объединяет результаты в единую выходную геометрию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `moge_geometry` | Словарь, содержащий оцененную геометрию. Он включает исходное `image` и может содержать `points` (3D-облако точек), `depth` (карту глубины), `intrinsics` (матрицу внутренних параметров камеры), `mask` (маску, определяющую действительные пиксели) и `normal` (нормали к поверхности). | MOGE_GEOMETRY |
