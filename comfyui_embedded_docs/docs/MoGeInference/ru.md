# MoGe инференс

Запуск MoGe на одном изображении для оценки глубины и геометрии. Этот узел обрабатывает входное изображение через модель MoGe, чтобы сгенерировать 3D-облако точек, карту глубины, внутренние параметры камеры, маску и нормали поверхности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `moge_model` | Модель MoGe для выполнения инференса. | MOGE_MODEL | Да | N/A |
| `image` | Входное изображение для оценки глубины и геометрии. Используются только первые три цветовых канала (RGB). | IMAGE | Да | N/A |
| `resolution_level` | Управляет разрешением обработки. 0 — самое быстрое, 9 обеспечивает наибольшую детализацию. (по умолчанию: 9) | INT | Да | 0 до 9 |
| `fov_x_degrees` | (Дополнительно) Горизонтальное поле зрения исходной камеры в градусах. Задаёт фокусное расстояние, используемое для развертывания карты глубины в 3D. Установите 0.0 для автоматического восстановления поля зрения из предсказанных точек. (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 170.0 |
| `batch_size` | Изображений на один вызов инференса. Уменьшите это значение, если память заканчивается при обработке длинного видео или набора изображений. (по умолчанию: 4) | INT | Да | 1 до 64 |
| `force_projection` | (Дополнительно) Принудительно выполняет проекцию предсказанных точек. (по умолчанию: True) | BOOLEAN | Да | True/False |
| `apply_mask` | (Дополнительно) Задаёт замаскированным (небо или недопустимые) пикселям значение бесконечности в выходах точек и глубины, чтобы инструменты мешинга могли их игнорировать. Отключите, чтобы сохранить сырую предсказанную геометрию везде; маска по-прежнему возвращается отдельно. (по умолчанию: True) | BOOLEAN | Да | True/False |

Примечание: Если входное `image` содержит больше кадров, чем `batch_size`, узел обрабатывает их за несколько вызовов инференса и объединяет результаты в одну выходную геометрию.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `moge_geometry` | Словарь, содержащий оценённую геометрию. Он включает исходное `image` и может содержать `points` (3D-облако точек), `depth` (карта глубины), `intrinsics` (матрица внутренних параметров камеры), `mask` (маска, определяющая допустимые пиксели) и `normal` (нормали поверхности). | MOGE_GEOMETRY |
