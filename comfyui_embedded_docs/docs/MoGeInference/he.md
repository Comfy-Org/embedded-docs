# הרץ MoGe Inference

הפעל את MoGe על תמונות כדי לאמוד עומק וגאומטריה. צומת זה מעבד תמונת קלט באמצעות מודל MoGe כדי ליצור ענן נקודות תלת-ממדי, מפת עומק, פרמטרים פנימיים של המצלמה, מסכה ונורמלים למשטח.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `moge_model` | מודל MoGe שישמש להסקה. | MOGE_MODEL | כן | N/A |
| `image` | תמונת הקלט לאמידת עומק וגאומטריה. נעשה שימוש רק בשלושת ערוצי הצבע הראשונים (RGB). | IMAGE | כן | N/A |
| `resolution_level` | שולט ברזולוציית העיבוד. 0 = המהיר ביותר, 9 = המפורט ביותר. (ברירת מחדל: 9) | INT | כן | 0 עד 9 |
| `fov_x_degrees` | (מתקדם) שדה ראייה אופקי של מצלמת המקור. קובע את אורך המוקד המשמש לביצוע היטל הפוך של מפת העומק לתלת-ממד. 0 = שחזור אוטומטי מהנקודות החזויות. (ברירת מחדל: 0.0) | FLOAT | כן | 0.0 עד 170.0 (צעד 0.1) |
| `batch_size` | תמונות לכל קריאת הסקה. יש להקטין אם מתרחש OOM בסרטון ארוך / ערכת תמונות. (ברירת מחדל: 4) | INT | כן | 1 עד 64 |
| `force_projection` | (מתקדם) כופה היטל של הנקודות החזויות. (ברירת מחדל: True) | BOOLEAN | כן | True/False |
| `apply_mask` | (מתקדם) מגדיר פיקסלים מוסתרים (שמיים / לא חוקיים) כ-inf בנקודות ובעומק, כך שתהליך יצירת הרשת (meshing) מסלק אותם. יש להשבית כדי לשמור על הגאומטריה החזויה הגולמית בכל מקום; המסכה עדיין מוחזרת בנפרד. (ברירת מחדל: True) | BOOLEAN | כן | True/False |
| `refine_steps` | (מתקדם) MoGe-3 בלבד: מעברי עידון נפחיים דלילים על העומק החזוי. מעברים נוספים מחדדים פרטים עדינים וקצוות בעלות בקירוב לינארית. 0 משבית את העידון. מתעלמים מכך ב-MoGe-1 / MoGe-2. (ברירת מחדל: 3) | INT | כן | 0 עד 8 |

הערה: כאשר הקלט `image` מכיל יותר פריימים מ-`batch_size`, הצומת מעבד אותם במספר קריאות הסקה ומאחד את התוצאות לגאומטריית פלט יחידה.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `moge_geometry` | מילון המכיל את הגאומטריה המוערכת. הוא כולל את `image` המקורי, ועשוי להכיל את `points` (ענן נקודות תלת-ממדי), `depth` (מפת עומק), `intrinsics` (מטריצת פרמטרים פנימיים של המצלמה), `mask` (מסכה המזהה פיקסלים חוקיים), ו-`normal` (נורמלים למשטח). | MOGE_GEOMETRY |
