# HeyGen 创建虚拟人

根据人物照片或描述角色的文本提示创建可复用的 HeyGen 虚拟形象。生成的 `avatar_id` 可配合 HeyGen 虚拟形象视频节点使用，建议保存该 ID 以便在后续工作流中复用此虚拟形象。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `来源` | 通过文本提示生成新角色，或根据所连接的人物照片创建虚拟形象。 | DYNAMIC_COMBO | 是 | `"prompt"`<br>`"photo"` |

### 提示输入

当 `source` 设置为 `"prompt"` 时可用。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的虚拟形象的描述（最多 1000 个字符）。必须包含至少 1 个非空白字符。默认值：空字符串。 | STRING | 是 | 1 至 1000 个字符 |

### 照片输入

当 `source` 设置为 `"photo"` 时可用。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `identity_photo` | 要制作成虚拟形象的人物照片。若大于 2K，将自动缩小。 | IMAGE | 是 | 单张图片 |

### 参考输入

当 `source` 设置为 `"prompt"` 时可用。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接最多 3 张图片（`ref_image_1`...`ref_image_3`）以引导生成的外观。若图片大于 2K，将自动缩小。 | IMAGE | 否 | 0 至 3 张图片 |

**注意：** `source` 参数可在两种互斥模式之间切换。在 `"prompt"` 模式下，`prompt` 为必填项，并且可选择性连接最多 3 张参考图片。在 `"photo"` 模式下，`identity_photo` 为必填项。照片和参考图片大于 2K 时会自动缩小；不接受超过 3 张参考图片。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `avatar_id` | 虚拟形象外观 ID。将其传递给 HeyGen 虚拟形象视频的 `custom_avatar_id`；保存该 ID 以便日后复用此虚拟形象。 | STRING |
| `预览` | 所生成虚拟形象的预览图片。 | IMAGE |
