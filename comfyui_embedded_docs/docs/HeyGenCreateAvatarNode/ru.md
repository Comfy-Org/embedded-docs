# HeyGen Создать Аватар

Создайте многоразовый аватар HeyGen из фотографии человека или текстового запроса, описывающего персонажа для генерации. Полученный `avatar_id` можно использовать с узлом HeyGen Avatar Video, и его следует сохранить, чтобы использовать аватар в будущих рабочих процессах.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `источник` | Сгенерировать нового персонажа из текстового запроса или создать аватар из подключенной фотографии человека. | DYNAMIC_COMBO | Да | `"prompt"`<br>`"photo"` |

### Входы Prompt

Доступны, когда `source` имеет значение `"prompt"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание аватара для генерации (до 1000 символов). Должно содержать как минимум 1 непробельный символ. По умолчанию: пустая строка. | STRING | Да | от 1 до 1000 символов |

### Входы Photo

Доступны, когда `source` имеет значение `"photo"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `identity_photo` | Фотография человека, которого нужно превратить в аватар. Автоматически уменьшается, если больше 2K. | IMAGE | Да | Одно изображение |

### Эталонные входы

Доступны, когда `source` имеет значение `"prompt"`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите до 3 изображений (`ref_image_1`...`ref_image_3`), направляющих сгенерированный внешний вид. Изображения автоматически уменьшаются, если больше 2K. | IMAGE | Нет | от 0 до 3 изображений |

**Примечание:** Параметр `source` переключается между двумя взаимоисключающими режимами. В режиме `"prompt"` обязателен параметр `prompt`, и опционально можно подключить до 3 эталонных изображений. В режиме `"photo"` обязателен `identity_photo`. Фотографии и эталонные изображения автоматически уменьшаются, если их размер больше 2K; более 3 эталонных изображений не принимаются.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `avatar_id` | Идентификатор внешнего вида аватара. Передайте его в `custom_avatar_id` узла HeyGen Avatar Video; сохраните его, чтобы использовать аватар позже. | STRING |
| `превью` | Предварительное изображение сгенерированного аватара. | IMAGE |
