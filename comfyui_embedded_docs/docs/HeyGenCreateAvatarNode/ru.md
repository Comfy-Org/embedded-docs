# HeyGen Создать Аватар

Создайте многоразового аватара HeyGen по фотографии человека или по текстовому запросу с описанием персонажа для генерации. Полученный `avatar_id` можно использовать с узлом HeyGen Avatar Video, а также сохранить, чтобы повторно использовать аватар в будущих рабочих процессах.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `источник` | Создать нового персонажа по текстовому запросу или создать аватара из подключённой фотографии человека. | DYNAMIC_COMBO | Да | `"prompt"`<br>`"photo"` |

### Входы для prompt

Доступно, когда `source` имеет значение `"prompt"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описание аватара для генерации (до 1000 символов). Должен содержать как минимум 1 непробельный символ. По умолчанию: пустая строка. | STRING | Да | от 1 до 1000 символов |

### Входы для photo

Доступно, когда `source` имеет значение `"photo"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `identity_photo` | Фотография человека, которого нужно превратить в аватара. Автоматически уменьшается, если размер превышает 2K. | IMAGE | Да | Одно изображение |

### Эталонные входы

Доступно, когда `source` имеет значение `"prompt"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Расширяемый слот: подключите до 3 изображений (`ref_image_1`...`ref_image_3`), определяющих генерируемый внешний вид. Изображения автоматически уменьшаются, если их размер превышает 2K. | IMAGE | Нет | от 0 до 3 изображений |

**Примечание:** Параметр `source` переключает между двумя взаимоисключающими режимами. В режиме `"prompt"` обязателен параметр `prompt`, и дополнительно можно подключить до 3 эталонных изображений. В режиме `"photo"` обязателен параметр `identity_photo`. Фотографии и эталонные изображения автоматически уменьшаются при размере более 2K; более 3 эталонных изображений не принимается.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `avatar_id` | Идентификатор образа аватара. Передайте его в параметр `custom_avatar_id` узла HeyGen Avatar Video; сохраните его, чтобы повторно использовать аватара позже. | STRING |
| `превью` | Предварительное изображение созданного аватара. | IMAGE |
