# HeyGen 建立分身

從人物照片或描述要生成角色的文字提示詞，建立可重複使用的 HeyGen 虛擬化身。產生的 `avatar_id` 可與 HeyGen Avatar Video 節點搭配使用，建議將其儲存起來，以便在未來的工作流程中重複使用該虛擬化身。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `來源` | 從文字提示詞生成新角色，或從連接的人物照片建立虛擬化身。 | DYNAMIC_COMBO | 是 | `"prompt"`<br>`"photo"` |

### Prompt 輸入

當 `source` 設為 `"prompt"` 時可用。

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的虛擬化身描述（最多 1000 個字元）。必須包含至少 1 個非空白字元。預設值：空字串。 | STRING | 是 | 1 到 1000 個字元 |

### Photo 輸入

當 `source` 設為 `"photo"` 時可用。

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `identity_photo` | 要轉換為虛擬化身的人物照片。如果大於 2K，會自動縮小。 | IMAGE | 是 | 單張圖片 |

### 參考輸入

當 `source` 設為 `"prompt"` 時可用。

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可擴充插槽：連接最多 3 張圖片（`ref_image_1`...`ref_image_3`）以引導生成的外觀。如果圖片大於 2K，會自動縮小。 | IMAGE | No | 0 到 3 張圖片 |

**注意：** `source` 參數會在兩個互斥模式之間切換。在 `"prompt"` 模式中，`prompt` 為必填，且可選擇連接最多 3 張參考圖片。在 `"photo"` 模式中，`identity_photo` 為必填。當照片和參考圖片大於 2K 時會自動縮小；不接受超過 3 張參考圖片。
