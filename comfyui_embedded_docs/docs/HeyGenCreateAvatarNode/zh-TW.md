# HeyGen 建立分身

建立一個可重複使用的 HeyGen 虛擬化身，可從人物照片或描述要生成角色的文字提示詞來建立。產生的 `avatar_id` 可與 HeyGen Avatar Video 節點搭配使用，並應儲存起來以便在未來的工作流程中重複使用該虛擬化身。

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|------|------|----------|------|------|
| `來源` | 從文字提示詞生成新角色，或從已連接的人物照片建立虛擬化身。 | DYNAMIC_COMBO | 是 | `"prompt"`<br>`"photo"` |

### 提示詞輸入

當 `source` 設定為 `"prompt"` 時可用。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|------|------|----------|------|------|
| `prompt` | 要生成的虛擬化身的描述（最多 1000 個字元）。必須包含至少 1 個非空白字元。預設值：空字串。 | STRING | 是 | 1 至 1000 個字元 |

### 照片輸入

當 `source` 設定為 `"photo"` 時可用。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|------|------|----------|------|------|
| `identity_photo` | 要轉換為虛擬化身的人物照片。若大於 2K 會自動縮小。 | IMAGE | 是 | 單張圖片 |

### 參考輸入

當 `source` 設定為 `"prompt"` 時可用。

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|------|------|----------|------|------|
| `reference_images` | 可擴充插槽：連接最多 3 張參考圖片（`ref_image_1`...`ref_image_3`）來引導生成的外觀。若圖片大於 2K 會自動縮小。 | IMAGE | 否 | 0 至 3 張圖片 |

**注意：** `source` 參數在兩種互斥模式之間切換。在 `"prompt"` 模式下，`prompt` 為必填，且可選擇連接最多 3 張參考圖片。在 `"photo"` 模式下，`identity_photo` 為必填。照片和參考圖片若大於 2K 會自動縮小；不接受超過 3 張參考圖片。
