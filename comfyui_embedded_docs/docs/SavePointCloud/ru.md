# Сохранить облако точек

Узел Save Point Cloud сохраняет файл трехмерного облака точек в выходной каталог и при необходимости предоставляет данные предварительного просмотра для 3D-просмотрщика. Он управляет именованием и сохранением файла, а также передает информацию о камере и модели для отображения.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл облака точек (.ply) | FILE3D_POINT_CLOUD_ANY или FILE3D_PLY | Да | - |
| `filename_prefix` | Префикс для имени сохраняемого файла (по умолчанию: "3d/ComfyUI") | STRING | Да | - |
| `viewport_state` | Текущее состояние области просмотра, содержащее информацию о камере и модели | LOAD3D | Да | - |
| `model_3d_info` | Дополнительная информация о модели для 3D-просмотрщика | LOAD3D_MODEL_INFO | Нет | - |
| `camera_info` | Информация о камере для 3D-просмотрщика | LOAD3D_CAMERA | Нет | - |
| `width` | Ширина области предварительного просмотра в пикселях (по умолчанию: 1024) | INT | Да | 1 to 4096 |
| `height` | Высота области предварительного просмотра в пикселях (по умолчанию: 1024) | INT | Да | 1 to 4096 |

Сохраненный файл записывается в выходной каталог с использованием `filename_prefix` и добавляемым пятизначным счетчиком (например, `3d/ComfyUI_00001.ply`). Если необязательный вход `camera_info` не подключен, информация о камере берется из `viewport_state`; аналогично, если `model_3d_info` не подключен, информация о модели берется из `viewport_state` (или пустого списка, если она недоступна).

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Сохраненный файл облака точек | FILE3D_POINT_CLOUD_ANY |
| `model_3d_info` | Информация о модели для 3D-просмотрщика | LOAD3D_MODEL_INFO |
| `camera_info` | Информация о камере для 3D-просмотрщика | LOAD3D_CAMERA |
| `width` | Ширина области предварительного просмотра | INT |
| `height` | Высота области предварительного просмотра | INT |
