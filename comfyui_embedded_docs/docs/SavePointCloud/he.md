# SavePointCloud

הצומת Save Point Cloud שומר קובץ ענן נקודות תלת-ממדי בספריית הפלט, ובאופן אופציונלי מספק נתוני תצוגה מקדימה עבור מציג התלת-ממד. הוא מטפל בשמות קבצים ובשמירה, ובמקביל מעביר הלאה מידע על מצלמה ומודל לצורכי תצוגה.

## קלטים

| פרמטר | תיאור | סוג נתון | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | קובץ ענן נקודות (.ply) | FILE3D_POINT_CLOUD_ANY או FILE3D_PLY | כן | - |
| `filename_prefix` | קידומת לשם הקובץ הנשמר (ברירת מחדל: "3d/ComfyUI") | STRING | כן | - |
| `viewport_state` | מצב אזור התצוגה הנוכחי המכיל מידע על מצלמה ומודל | LOAD3D | כן | - |
| `model_3d_info` | מידע נוסף על המודל עבור מציג התלת-ממד | LOAD3D_MODEL_INFO | לא | - |
| `camera_info` | מידע על מצלמה עבור מציג התלת-ממד | LOAD3D_CAMERA | לא | - |
| `width` | רוחב התצוגה המקדימה בפיקסלים (ברירת מחדל: 1024) | INT | כן | 1 עד 4096 |
| `height` | גובה התצוגה המקדימה בפיקסלים (ברירת מחדל: 1024) | INT | כן | 1 עד 4096 |

הקובץ הנשמר נכתב לספריית הפלט תוך שימוש ב-`filename_prefix` עם מונה בן 5 ספרות שמצורף לו (לדוגמה, `3d/ComfyUI_00001.ply`). כאשר הקלט האופציונלי `camera_info` אינו מחובר, מידע המצלמה נלקח מ-`viewport_state`; באופן דומה, כאשר `model_3d_info` אינו מחובר, מידע המודל נלקח מ-`viewport_state` (או רשימה ריקה אם אין מידע זמין).
