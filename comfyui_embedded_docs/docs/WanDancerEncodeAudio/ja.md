# WanDancerEncodeAudio

このノードは、オーディオ入力を処理して、ビデオ生成モデルをガイドするために使用できる特徴を抽出します。オーディオを分析してテンポ、ビート、その他の音楽的特性を検出し、この情報をビデオモデルのコンディショニングに適した形式にパッケージ化します。これにより、生成されたビデオをオーディオと同期させることができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `audio` | 分析およびエンコードされるオーディオ入力です。 | AUDIO | はい | - |
| `video_frames` | ターゲットビデオのフレーム数です。同期用のフレームレートを計算するために使用されます（デフォルト：149）。 | INT | はい | Min: 1, Max: 268435456 (MAX_RESOLUTION), Step: 4 |
| `audio_inject_scale` | ビデオモデルに注入される際のオーディオ特徴のスケールです（デフォルト：1.0）。 | FLOAT | はい | Min: 0.0, Max: 10.0, Step: 0.01 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `audio_encoder_output` | 処理されたオーディオ特徴、計算されたフレームレート（fps）、およびオーディオ注入スケールを含む辞書です。この出力は、ビデオ生成モデルをコンディショニングするために使用されます。 | AUDIO_ENCODER_OUTPUT |
| `fps_string` | オーディオの長さとビデオのフレーム数に基づいて計算されたフレームレート（fps）を説明するテキスト文字列です。この文字列は、ビデオモデルのプロンプトで使用されることを意図しています。 | STRING |
