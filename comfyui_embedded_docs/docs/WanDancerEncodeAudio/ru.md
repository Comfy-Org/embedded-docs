# WanDancerEncodeAudio

Этот узел обрабатывает аудиовход для извлечения признаков, которые можно использовать для управления моделью генерации видео. Он анализирует аудио для обнаружения темпа, битов и других музыкальных характеристик, затем упаковывает эту информацию в формат, подходящий для обусловливания видеомодели, что позволяет синхронизировать генерируемое видео с аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Аудиовход для анализа и кодирования. Если аудио имеет несколько каналов, каналы усредняются до моно перед извлечением признаков. | AUDIO | Да | - |
| `video_frames` | Количество кадров в целевом видео. Используется для расчета частоты кадров для синхронизации (по умолчанию: 149). | INT | Да | Min: 1, Max: 268435456 (MAX_RESOLUTION), Step: 4 |
| `audio_inject_scale` | Масштаб аудио-признаков при их внедрении в видеомодель (по умолчанию: 1.0). | FLOAT | Да | Min: 0.0, Max: 10.0, Step: 0.01 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder_output` | Словарь, содержащий обработанные аудио-признаки, рассчитанную частоту кадров (fps) и масштаб внедрения аудио. Этот выход используется для обусловливания модели генерации видео. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | Текстовая строка, описывающая рассчитанную частоту кадров (fps) на основе длины аудио и количества видеокадров. Эта строка предназначена для использования в промпте видеомодели. Она отформатирована на китайском языке для соответствия эталонному конвейеру. | STRING |
