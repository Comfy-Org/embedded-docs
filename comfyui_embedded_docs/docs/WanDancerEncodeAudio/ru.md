# WanDancerEncodeAudio

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Входной аудиофайл для анализа и кодирования. | AUDIO | Да | - |
| `video_frames` | Количество кадров в целевом видео. Используется для расчёта частоты кадров для синхронизации (по умолчанию: 149). | INT | Да | Мин: 1, Макс: 268435456 (MAX_RESOLUTION), Шаг: 4 |
| `audio_inject_scale` | Масштаб аудио-признаков при внедрении в видеомодель (по умолчанию: 1.0). | FLOAT | Да | Мин: 0.0, Макс: 10.0, Шаг: 0.01 |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder_output` | Словарь, содержащий обработанные аудио-признаки, рассчитанную частоту кадров (fps) и масштаб внедрения аудио. Этот выход используется для управления моделью генерации видео. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | Текстовая строка, описывающая рассчитанную частоту кадров (fps) на основе длины аудио и количества кадров видео. Эта строка предназначена для использования в промпте для видеомодели. | STRING |
