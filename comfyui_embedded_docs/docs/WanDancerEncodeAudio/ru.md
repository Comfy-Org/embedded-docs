# WanDancerEncodeAudio

Этот узел анализирует аудиоклип и преобразует его в набор признаков, которые могут управлять моделью генерации видео. Он оценивает темп и биты, извлекает мел-спектрограмму, MFCC, хроматические и onset-признаки, затем объединяет их вместе с рассчитанной частотой кадров для синхронизации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Входной аудиофайл для анализа и кодирования. Если аудио многоканальное, каналы усредняются до моно перед извлечением признаков. | AUDIO | Да | - |
| `video_frames` | Количество кадров в целевом видео. Используется для расчёта частоты кадров для синхронизации (по умолчанию: 149). | INT | Да | Мин.: 1, Макс.: 16384 (MAX_RESOLUTION), Шаг: 4 |
| `audio_inject_scale` | Масштаб для аудиопризнаков при их внедрении в видеомодель (по умолчанию: 1.0). | FLOAT | Да | Мин.: 0.0, Макс.: 10.0, Шаг: 0.01 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio_encoder_output` | Словарь, содержащий обработанные аудиопризнаки, рассчитанную частоту кадров (fps) и масштаб внедрения аудио. Этот выход используется для обусловливания модели генерации видео. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | Текстовая строка, описывающая рассчитанную частоту кадров (fps) на основе длины аудио и количества кадров видео. Эта строка предназначена для использования в промпте для видеомодели. Она отформатирована на китайском языке в соответствии с эталонным пайплайном. | STRING |
