# WanDancerEncodeAudio

צומת זה מנתח קטע אודיו והופך אותו לקבוצת מאפיינים שיכולים להנחות מודל ליצירת וידאו. הוא מעריך טמפו ופעימות, מחלץ מאפייני mel-spectrogram, MFCC, chroma ו-onset, ואז אורז אותם יחד עם קצב פריימים מחושב לסנכרון.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `audio` | קלט האודיו שיש לנתח ולקודד. אם לאודיו יש מספר ערוצים, הערוצים ממוצעים למונו לפני חילוץ המאפיינים. | AUDIO | כן | - |
| `video_frames` | מספר הפריימים בסרטון היעד. משמש לחישוב קצב הפריימים לסנכרון (ברירת מחדל: 149). | INT | כן | מינימום: 1, מקסימום: 16384 (MAX_RESOLUTION), צעד: 4 |
| `audio_inject_scale` | קנה המידה של מאפייני האודיו בעת הזרקתם למודל הווידאו (ברירת מחדל: 1.0). | FLOAT | כן | מינימום: 0.0, מקסימום: 10.0, צעד: 0.01 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `audio_encoder_output` | מילון המכיל את מאפייני האודיו המעובדים, קצב הפריימים המחושב (fps), וקנה המידה להזרקת האודיו. פלט זה משמש להתניה של מודל יצירת הווידאו. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | מחרוזת טקסט המתארת את קצב הפריימים המחושב (fps) בהתאם לאורך האודיו ולמספר פריימי הווידאו. מחרוזת זו מיועדת לשימוש בפרומפט עבור מודל הווידאו. היא מעוצבת בסינית כדי להתאים ל-pipeline הייחוס. | STRING |
