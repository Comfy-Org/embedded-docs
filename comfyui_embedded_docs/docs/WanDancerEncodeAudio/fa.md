# WanDancerEncodeAudio

این گره ورودی صدا را پردازش می‌کند تا ویژگی‌هایی استخراج کند که می‌توانند برای هدایت یک مدل تولید ویدیو استفاده شوند. صدا را برای تشخیص تمپو، ضرب‌ها و سایر ویژگی‌های موسیقیایی تحلیل می‌کند و سپس این اطلاعات را در قالبی مناسب برای شرطی‌سازی مدل ویدیویی بسته‌بندی می‌کند و امکان همگام‌سازی ویدیوی تولیدشده با صدا را فراهم می‌آورد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `audio` | ورودی صوتی که باید تحلیل و کدگذاری شود. اگر صدا چند کاناله باشد، کانال‌ها قبل از استخراج ویژگی به مونو میانگین‌گیری می‌شوند. | AUDIO | بله | - |
| `video_frames` | تعداد فریم‌های ویدیوی هدف. برای محاسبه نرخ فریم جهت همگام‌سازی استفاده می‌شود (پیش‌فرض: 149). | INT | بله | Min: 1, Max: 268435456 (MAX_RESOLUTION), Step: 4 |
| `audio_inject_scale` | مقیاس ویژگی‌های صوتی هنگام تزریق به مدل ویدیویی (پیش‌فرض: 1.0). | FLOAT | بله | Min: 0.0, Max: 10.0, Step: 0.01 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `audio_encoder_output` | یک دیکشنری شامل ویژگی‌های صوتی پردازش‌شده، نرخ فریم محاسبه‌شده (fps) و مقیاس تزریق صدا. این خروجی برای شرطی‌سازی مدل تولید ویدیو استفاده می‌شود. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | یک رشته متنی که نرخ فریم محاسبه‌شده (fps) را بر اساس طول صدا و تعداد فریم‌های ویدیو توصیف می‌کند. این رشته برای استفاده در پرامپت مدل ویدیویی در نظر گرفته شده است. برای مطابقت با خط لوله مرجع، به زبان چینی قالب‌بندی شده است. | STRING |
