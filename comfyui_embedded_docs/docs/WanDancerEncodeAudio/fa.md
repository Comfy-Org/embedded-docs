# WanDancerEncodeAudio

این گره یک ورودی صوتی را پردازش می‌کند تا ویژگی‌هایی استخراج کند که می‌توان از آن‌ها برای هدایت یک مدل تولید ویدیو استفاده کرد. این گره صدا را تحلیل می‌کند تا تمپو، ضرب‌ها و سایر ویژگی‌های موسیقایی را تشخیص دهد و سپس این اطلاعات را در قالبی مناسب برای شرطی‌سازی مدل ویدیو بسته‌بندی می‌کند و به ویدیوی تولیدشده امکان می‌دهد با صدا همگام‌سازی شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `audio` | ورودی صوتی که باید تحلیل و کدگذاری شود. | AUDIO | بله | - |
| `video_frames` | تعداد فریم‌های ویدیوی هدف. برای محاسبه نرخ فریم جهت همگام‌سازی استفاده می‌شود (پیش‌فرض: 149). | INT | بله | Min: 1, Max: 268435456 (MAX_RESOLUTION), Step: 4 |
| `audio_inject_scale` | مقیاس ویژگی‌های صوتی هنگام تزریق به مدل ویدیو (پیش‌فرض: 1.0). | FLOAT | بله | Min: 0.0, Max: 10.0, Step: 0.01 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `audio_encoder_output` | یک دیکشنری شامل ویژگی‌های صوتی پردازش‌شده، نرخ فریم محاسبه‌شده (fps) و مقیاس تزریق صدا. این خروجی برای شرطی‌سازی مدل تولید ویدیو استفاده می‌شود. | AUDIO_ENCODER_OUTPUT |
| `fps_string` | یک رشته متنی که نرخ فریم محاسبه‌شده (fps) را بر اساس طول صدا و تعداد فریم‌های ویدیو توصیف می‌کند. این رشته برای استفاده در پرامپت مدل ویدیو در نظر گرفته شده است. | STRING |
