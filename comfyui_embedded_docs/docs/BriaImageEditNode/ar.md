# تحرير صورة Bria

تُعدِّل عقدة Bria FIBO Image Edit صورةً موجودة باستخدام تعليمات نصية. فهي ترسل الصورة والنص الموجّه إلى Bria API، حيث يُنشئ نموذج FIBO نسخة معدّلة. ويمكن لقناع اختياري أن يحدّد التغييرات في منطقة معيّنة.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | إصدار النموذج المستخدم لتحرير الصورة. | COMBO | نعم | `"FIBO"` |
| `الصورة` | الصورة المدخلة التي تريد تحريرها. | IMAGE | نعم | - |
| `التوجيه` | تعليمات لتحرير الصورة (الافتراضي: فارغ). | STRING | نعم | - |
| `توجيه سلبي` | نص يصف ما لا تريد أن يظهر في الصورة المحرّرة (الافتراضي: فارغ). | STRING | نعم | - |
| `توجيه منظم` | سلسلة نصية تحتوي على موجه التحرير المنظم بصيغة JSON. استخدمها بدلاً من الموجّه المعتاد للتحكم الدقيق والبرمجي (الافتراضي: فارغ). | STRING | نعم | - |
| `البذرة` | رقم يُستخدم لتهيئة التوليد العشوائي، لضمان نتائج قابلة لإعادة الإنتاج (الافتراضي: 1). | INT | نعم | 1 إلى 2147483647 |
| `مقياس التوجيه` | القيمة الأعلى تجعل الصورة تتبع الموجّه بشكل أدق (الافتراضي: 3). | FLOAT | نعم | 3.0 إلى 5.0 |
| `الخطوات` | عدد خطوات إزالة الضوضاء التي ينفذها النموذج (الافتراضي: 50). | INT | نعم | 20 إلى 50 |
| `الإشراف` | إعدادات الإشراف. اختيار `"true"` يكشف عن خيارات إشراف إضافية. | DYNAMIC_COMBO | نعم | `"false"`<br>`"true"` |
| `القناع` | إذا تم حذفه، يُطبَّق التحرير على الصورة بأكملها. | MASK | لا | - |

### مدخلات الإشراف

عندما تكون قيمة `moderation` هي `"true"`، تصبح هذه المدخلات الإضافية متاحة:

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | ما إذا كان سيتم الإشراف على نص الموجّه بحثًا عن محتوى غير مناسب (الافتراضي: false). | BOOLEAN | لا | `true`<br>`false` |
| `visual_input_moderation` | ما إذا كان سيتم الإشراف على الصورة المدخلة بحثًا عن محتوى غير مناسب (الافتراضي: false). | BOOLEAN | لا | `true`<br>`false` |
| `visual_output_moderation` | ما إذا كان سيتم الإشراف على صورة الإخراج المحرّرة بحثًا عن محتوى غير مناسب (الافتراضي: true). | BOOLEAN | لا | `true`<br>`false` |

**قيود مهمة:**

- يجب أن يكون أحد المعاملين على الأقل غير فارغ: `prompt` أو `structured_prompt`. إذا كان كلاهما فارغًا، تُصدر العقدة خطأً.
- عندما تكون قيمة `moderation` هي `"true"`، تظهر المدخلات الإشرافية الثلاثة المذكورة أعلاه.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `IMAGE` | الصورة المحرّرة التي تُرجعها Bria API. | IMAGE |
| `توجيه منظم` | الموجّه المنظم المستخدم أو المولّد أثناء عملية التحرير. | STRING |
