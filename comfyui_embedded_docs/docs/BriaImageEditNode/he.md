# Bria FIBO עריכת תמונה

צומת Bria FIBO Image Edit עורך תמונה קיימת באמצעות הוראת טקסט. הוא שולח את התמונה ואת ההנחיה שלך אל Bria API, שם מודל FIBO יוצר גרסה ערוכה. מסכה אופציונלית יכולה להגביל את השינויים לאזור מסוים.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | גרסת המודל לשימוש בעריכת התמונה. | COMBO | כן | `"FIBO"` |
| `תמונה` | תמונת הקלט שברצונך לערוך. | IMAGE | כן | - |
| `הנחיה` | הוראה לעריכת התמונה (ברירת מחדל: ריק). | STRING | כן | - |
| `הנחיה שלילית` | טקסט המתאר מה אינך רוצה שיופיע בתמונה הערוכה (ברירת מחדל: ריק). | STRING | כן | - |
| `הנחיה מובנית` | מחרוזת המכילה הנחיית עריכה מובנית בפורמט JSON. השתמש בזה במקום בהנחיה הרגילה לשליטה מדויקת ותכנותית (ברירת מחדל: ריק). | STRING | כן | - |
| `seed` | מספר המשמש לאתחול היצירה האקראית, להבטחת תוצאות ניתנות לשחזור (ברירת מחדל: 1). | INT | כן | 1 to 2147483647 |
| `guidance_scale` | ערך גבוה יותר גורם לתמונה לפעול לפי ההנחיה בצורה צמודה יותר (ברירת מחדל: 3). | FLOAT | כן | 3.0 to 5.0 |
| `שלבים` | מספר שלבי הפחתת הרעש שמבצע המודל (ברירת מחדל: 50). | INT | כן | 20 to 50 |
| `הגדרות בקרה` | הגדרות מודרציה. בחירה ב-`"true"` חושפת אפשרויות מודרציה נוספות. | DYNAMIC_COMBO | כן | `"false"`<br>`"true"` |
| `mask` | אם הוא מושמט, העריכה תחול על התמונה כולה. | MASK | לא | - |

### קלטי מודרציה

כאשר `moderation` מוגדר ל-`"true"`, קלטים נוספים אלה הופכים לזמינים:

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | האם להפעיל מודרציה על טקסט ההנחיה לתוכן לא הולם (ברירת מחדל: false). | BOOLEAN | לא | `true`<br>`false` |
| `visual_input_moderation` | האם להפעיל מודרציה על תמונת הקלט לתוכן לא הולם (ברירת מחדל: false). | BOOLEAN | לא | `true`<br>`false` |
| `visual_output_moderation` | האם להפעיל מודרציה על תמונת הפלט הערוכה לתוכן לא הולם (ברירת מחדל: true). | BOOLEAN | לא | `true`<br>`false` |

**אילוצים חשובים:**

- בדיוק אחד מהפרמטרים `prompt` או `structured_prompt` חייב להיות לא ריק. אם שניהם ריקים או ששניהם מלאים, הצומת יעלה שגיאה.
- אם `mask` מחובר, עליו להיות באותו רוחב וגובה כמו `image`; אחרת הצומת יעלה שגיאה.
- כאשר `moderation` מוגדר ל-`"true"`, שלושת קלטי המודרציה שלמעלה מוצגים.
