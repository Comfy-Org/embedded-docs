# Bria Image Edit

Узел Bria FIBO Image Edit редактирует существующее изображение с помощью текстовой инструкции. Он отправляет изображение и ваш запрос в API Bria, где модель FIBO создает отредактированную версию. Дополнительная маска может ограничить изменения определенной областью.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Версия модели, используемая для редактирования изображения. | COMBO | Да | `"FIBO"` |
| `изображение` | Входное изображение, которое вы хотите отредактировать. | IMAGE | Да | - |
| `промпт` | Инструкция по редактированию изображения (по умолчанию: пусто). | STRING | Да | - |
| `негативный_промпт` | Текст, описывающий то, что вы не хотите видеть в отредактированном изображении (по умолчанию: пусто). | STRING | Да | - |
| `структурированный_промпт` | Строка, содержащая структурированный запрос на редактирование в формате JSON. Используйте ее вместо обычного запроса для точного программного управления (по умолчанию: пусто). | STRING | Да | - |
| `seed` | Число, используемое для инициализации случайной генерации, обеспечивающее воспроизводимые результаты (по умолчанию: 1). | INT | Да | 1 до 2147483647 |
| `guidance_scale` | Более высокое значение заставляет изображение точнее следовать запросу (по умолчанию: 3). | FLOAT | Да | 3.0 до 5.0 |
| `шаги` | Количество шагов шумоподавления, выполняемых моделью (по умолчанию: 50). | INT | Да | 20 до 50 |
| `модерация` | Настройки модерации. Выбор `"true"` открывает дополнительные параметры модерации. | DYNAMIC_COMBO | Да | `"false"`<br>`"true"` |
| `маска` | Если не указано, редактирование применяется ко всему изображению. | MASK | Нет | - |

### Входы модерации

Когда для `moderation` установлено значение `"true"`, становятся доступны следующие дополнительные входы:

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | Определяет, следует ли проверять текст запроса на недопустимое содержимое (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `visual_input_moderation` | Определяет, следует ли проверять входное изображение на недопустимое содержимое (по умолчанию: false). | BOOLEAN | Нет | `true`<br>`false` |
| `visual_output_moderation` | Определяет, следует ли проверять отредактированное выходное изображение на недопустимое содержимое (по умолчанию: true). | BOOLEAN | Нет | `true`<br>`false` |

**Важные ограничения:**

- По крайней мере одно из полей `prompt` или `structured_prompt` должно быть непустым. Если оба пусты, узел вызывает ошибку.
- Когда для `moderation` установлено значение `"true"`, отображаются три указанных выше параметра модерации.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Отредактированное изображение, возвращенное API Bria. | IMAGE |
| `структурированный_промпт` | Структурированный запрос, использованный или сгенерированный в процессе редактирования. | STRING |
