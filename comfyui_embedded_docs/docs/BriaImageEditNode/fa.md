# ویرایش تصویر Bria

گره Bria FIBO Image Edit یک تصویر موجود را با استفاده از یک دستور متنی ویرایش می‌کند. این گره تصویر و دستور شما را به API شرکت Bria ارسال می‌کند، جایی که مدل FIBO نسخه ویرایش‌شده را ایجاد می‌کند. یک mask اختیاری می‌تواند تغییرات را به ناحیه خاصی محدود کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مدل` | نسخه مدل مورد استفاده برای ویرایش تصویر. | COMBO | بله | `"FIBO"` |
| `تصویر` | تصویر ورودی که می‌خواهید ویرایش کنید. | IMAGE | بله | - |
| `پرامپت` | دستور ویرایش تصویر (پیش‌فرض: خالی). | STRING | بله | - |
| `پرامپت منفی` | متنی که توصیف می‌کند چه چیزهایی را نمی‌خواهید در تصویر ویرایش‌شده ظاهر شوند (پیش‌فرض: خالی). | STRING | بله | - |
| `پرامپت ساختاریافته` | رشته‌ای شامل دستور ویرایش ساختارمند در قالب JSON. برای کنترل دقیق و برنامه‌ای به‌جای دستور معمولی از این استفاده کنید (پیش‌فرض: خالی). | STRING | بله | - |
| `بذر` | عددی که برای مقداردهی اولیه تولید تصادفی استفاده می‌شود و نتایج قابل تکرار را تضمین می‌کند (پیش‌فرض: ۱). | INT | بله | ۱ تا ۲۱۴۷۴۸۳۶۴۷ |
| `مقیاس راهنما` | مقدار بالاتر باعث می‌شود تصویر با دقت بیشتری از دستور پیروی کند (پیش‌فرض: ۳). | FLOAT | بله | ۳.۰ تا ۵.۰ |
| `گام‌ها` | تعداد گام‌های حذف نویز (denoising) که توسط مدل اجرا می‌شود (پیش‌فرض: ۵۰). | INT | بله | ۲۰ تا ۵۰ |
| `تنظیمات نظارت` | تنظیمات پالایش. انتخاب `"true"` گزینه‌های پالایش بیشتری را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"false"`<br>`"true"` |
| `ماسک` | در صورت حذف، ویرایش بر روی کل تصویر اعمال می‌شود. | MASK | خیر | - |

### ورودی‌های پالایش

هنگامی که `moderation` روی `"true"` تنظیم شود، این ورودی‌های اضافی در دسترس قرار می‌گیرند:

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | آیا متن دستور برای محتوای نامناسب پالایش شود (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `visual_input_moderation` | آیا تصویر ورودی برای محتوای نامناسب پالایش شود (پیش‌فرض: false). | BOOLEAN | خیر | `true`<br>`false` |
| `visual_output_moderation` | آیا تصویر خروجی ویرایش‌شده برای محتوای نامناسب پالایش شود (پیش‌فرض: true). | BOOLEAN | خیر | `true`<br>`false` |

**محدودیت‌های مهم:**

- حداقل یکی از `prompt` یا `structured_prompt` باید غیرخالی باشد. اگر هر دو خالی باشند، گره خطا صادر می‌کند.
- هنگامی که `moderation` روی `"true"` تنظیم شود، سه ورودی پالایش فوق نمایش داده می‌شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `IMAGE` | تصویر ویرایش‌شده که توسط API شرکت Bria بازگردانده شده است. | IMAGE |
| `پرامپت ساختاریافته` | دستور ساختارمندی که در طول فرآیند ویرایش استفاده یا تولید شده است. | STRING |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/BriaImageEditNode/fa.md)
