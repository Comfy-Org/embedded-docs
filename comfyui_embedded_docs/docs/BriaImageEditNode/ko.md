# Bria 이미지 편집

Bria FIBO Image Edit 노드는 텍스트 지시를 사용하여 기존 이미지를 수정할 수 있게 해 줍니다. 이미지와 프롬프트를 Bria API에 전송하면, API가 FIBO 모델을 사용하여 요청에 따라 새롭게 편집된 이미지 버전을 생성합니다. 또한 마스크를 제공하여 편집 범위를 특정 영역으로 제한할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 이미지 편집에 사용할 모델 버전입니다. | COMBO | 예 | `"FIBO"` |
| `image` | 편집하려는 입력 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 이미지를 편집하기 위한 지시문입니다 (기본값: 비어 있음). | STRING | 예 | - |
| `네거티브 프롬프트` | 편집된 이미지에 나타나지 않기를 원하는 내용을 설명하는 텍스트입니다 (기본값: 비어 있음). | STRING | 예 | - |
| `구조화된 프롬프트` | JSON 형식의 구조화된 편집 프롬프트를 포함하는 문자열입니다. 정밀하고 프로그래밍 방식으로 제어하려면 일반 프롬프트 대신 이 값을 사용하세요 (기본값: 비어 있음). | STRING | 예 | - |
| `시드` | 무작위 생성을 초기화하는 데 사용되는 숫자로, 결과를 재현할 수 있게 보장합니다 (기본값: 1). | INT | 예 | 1 ~ 2147483647 |
| `가이던스 스케일` | 값이 높을수록 이미지가 프롬프트를 더 밀접하게 따르게 됩니다 (기본값: 3.0). | FLOAT | 예 | 3.0 ~ 5.0 |
| `스텝` | 모델이 수행할 노이즈 제거 단계 수입니다 (기본값: 50). | INT | 예 | 20 ~ 50 |
| `모더레이션` | 모더레이션 설정입니다. `"true"`를 선택하면 프롬프트 내용, 시각적 입력, 시각적 출력에 대한 추가 모더레이션 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `"false"`<br>`"true"` |
| `마스크` | 이 값을 생략하면 편집이 전체 이미지에 적용됩니다. | MASK | 아니오 | - |

**중요 제약 사항:**

- `prompt` 또는 `structured_prompt` 입력 중 하나 이상을 제공해야 합니다. 둘 다 비어 있을 수 없습니다.
- `moderation` 매개변수가 `"true"`로 설정되면 세 가지 추가 부울 입력인 `prompt_content_moderation` (기본값: false), `visual_input_moderation` (기본값: false), `visual_output_moderation` (기본값: true)을 사용할 수 있게 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API가 반환한 편집된 이미지입니다. | IMAGE |
| `구조화된 프롬프트` | 편집 과정에서 사용되거나 생성된 구조화된 프롬프트입니다. | STRING |
