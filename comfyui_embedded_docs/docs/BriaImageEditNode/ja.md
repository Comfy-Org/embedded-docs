# Bria画像編集

Bria FIBO Image Edit ノードは、テキストによる指示で既存の画像を編集できます。画像とプロンプトを Bria API に送信し、FIBO モデルを使用して編集版の画像を生成します。また、マスクを指定して、変更を特定の領域に限定することもできます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像編集に使用するモデルバージョン。 | COMBO | 必須 | `"FIBO"` |
| `image` | 編集する入力画像。 | IMAGE | 必須 | - |
| `prompt` | 画像を編集するための指示（デフォルト：空）。 | STRING | 必須 | - |
| `negative_prompt` | 編集後の画像に表示させたくない内容を説明するテキスト（デフォルト：空）。 | STRING | 必須 | - |
| `structured_prompt` | JSON 形式の構造化編集プロンプトを含む文字列。通常のプロンプトの代わりにこれを使用すると、正確でプログラム的な制御が可能です（デフォルト：空）。 | STRING | 必須 | - |
| `seed` | ランダム生成を初期化するために使用する数値。再現可能な結果を保証します（デフォルト：1）。 | INT | 必須 | 1 から 2147483647 |
| `guidance_scale` | 値を大きくすると、画像がプロンプトにより忠実に従うようになります（デフォルト：3）。 | FLOAT | 必須 | 3.0 から 5.0 |
| `steps` | モデルが実行するノイズ除去ステップ数（デフォルト：50）。 | INT | 必須 | 20 から 50 |
| `moderation` | モデレーション設定。`"true"` を選択すると、追加のモデレーションオプションが表示されます。 | DYNAMIC_COMBO | 必須 | `"false"`<br>`"true"` |
| `mask` | 省略した場合、編集は画像全体に適用されます。 | MASK | 任意 | - |

### モデレーション入力

`moderation` を `"true"` に設定すると、以下の追加入力が使用可能になります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | プロンプトテキストに不適切なコンテンツが含まれていないかモデレーションするかどうか（デフォルト：false）。 | BOOLEAN | 任意 | `true`<br>`false` |
| `visual_input_moderation` | 入力画像に不適切なコンテンツが含まれていないかモデレーションするかどうか（デフォルト：false）。 | BOOLEAN | 任意 | `true`<br>`false` |
| `visual_output_moderation` | 編集後の出力画像に不適切なコンテンツが含まれていないかモデレーションするかどうか（デフォルト：true）。 | BOOLEAN | 任意 | `true`<br>`false` |

**重要な制約事項：**

- `prompt` または `structured_prompt` の少なくとも一方は空以外である必要があります。両方が空の場合、ノードはエラーを発生させます。
- `moderation` が `"true"` に設定されている場合、上記の3つのモデレーション入力が表示されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API によって返された編集後の画像。 | IMAGE |
| `structured_prompt` | 編集処理中に使用または生成された構造化プロンプト。 | STRING |
