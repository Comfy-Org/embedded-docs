# Pruna P-Video-2: текст в видео

Генерирует видео из текстового промпта с помощью модели P-Video-2 от Pruna. Промпт описывает сцену, её движение и её звук, а узел либо создаёт собственную звуковую дорожку, либо принимает аудиоклип, который управляет движением и становится звуковой дорожкой.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Видеомодель Pruna для использования. При выборе модели ниже отображаются её собственные входы. | DYNAMIC_COMBO | Да | `"p-video-2"` |

### Входы P-Video-2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `промпт` | Описывает видео, его движение и его звук. Должен содержать хотя бы один непробельный символ, до 5000 символов (по умолчанию: пусто). | STRING | Да | До 5000 символов |
| `соотношение сторон` | Соотношение сторон выходного видео (по умолчанию: `"16:9"`). | COMBO | Да | `"16:9"`<br>`"9:16"`<br>`"4:3"`<br>`"3:4"`<br>`"3:2"`<br>`"2:3"`<br>`"1:1"` |
| `длительность` | Длительность видео в секундах. `"auto"` позволяет модели выбрать длительность на основе промпта. Игнорируется, если подключён `model.audio`: тогда видео следует длительности аудио, округлённой вверх до целой секунды, но не более 20 секунд (по умолчанию: `"5"`). | COMBO | Да | `"auto"`<br>`"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"`<br>`"11"`<br>`"12"`<br>`"13"`<br>`"14"`<br>`"15"`<br>`"16"`<br>`"17"`<br>`"18"`<br>`"19"`<br>`"20"` |
| `разрешение` | Разрешение выходного видео. 720p рендерит около 0,9 мегапикселя (1280x704 при 16:9), 1080p — около 2 мегапикселей (1920x1088 при 16:9) (по умолчанию: `"720p"`). | COMBO | Да | `"720p"`<br>`"1080p"` |
| `fps` | Кадров в секунду. 48 fps недоступно в черновом режиме при 1080p (по умолчанию: `"24"`). | COMBO | Да | `"24"`<br>`"48"` |
| `черновик` | Более быстрый, менее детализированный рендеринг, тарифицируется по более низкому тарифу, чем стандартный рендеринг (по умолчанию: False). | BOOLEAN | Да | True/False |
| `генерировать аудио` | Создавать звуковую дорожку для видео. Игнорируется, если подключён `model.audio`, который вместо этого становится звуковой дорожкой (по умолчанию: True). | BOOLEAN | Да | True/False |
| `улучшить промпт` | Переписывать промпт с большей детализацией перед генерацией; коротким промптам это необходимо. Отключите, чтобы точно воспроизвести результат с тем же seed (по умолчанию: True). Дополнительная настройка. | BOOLEAN | Да | True/False |
| `model.audio` | Аудио, которое управляет движением и становится звуковой дорожкой. Длительностью не менее 1 секунды; аудио длиннее 20 секунд обрезается. Задаёт длительность видео вместо `model.duration`. | AUDIO | Нет | - |
| `сид` | Seed для генерации. Одинаковый seed точно воспроизводит результат только если `model.enhance_prompt` отключён (по умолчанию: 42). | INT | Да | 0–2147483647 |

**Примечания:**

- `model.prompt` обязателен и ограничен 5000 символами.
- Черновой режим при 1080p нельзя сочетать с 48 fps: узел выдаёт ошибку, поэтому либо отключите черновой режим, либо используйте 24 fps.
- Подключённое аудио должно быть длительностью не менее 1 секунды; всё, что превышает 20 секунд, игнорируется.
- Если подключён `model.audio`, длительность видео задаёт аудио, поэтому `model.duration` и `model.generate_audio` не влияют на результат.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сгенерированное видео с его звуковой дорожкой. | VIDEO |
