# Pruna P-Video-2 文字轉影片

使用 Pruna 的 P-Video-2 模型，從文字提示生成影片。提示會描述場景、其動作與聲音，而此節點會自行生成配樂，或接收一段音訊片段來驅動動作並成為配樂。

## 輸入

### 通用輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `模型` | 要使用的 Pruna 影片模型。選取模型後，下方會顯示其專屬輸入。 | DYNAMIC_COMBO | 是 | `"p-video-2"` |

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |

| `提示詞` | 描述影片、其動作與其聲音。必須包含至少一個非空白字元，最多 5000 個字元（預設：空）。 | STRING | 是 | 最多 5000 個字元 |
| `aspect_ratio` | 輸出影片的長寬比（預設：`"16:9"`）。 | COMBO | 是 | `"16:9"`<br>`"9:16"`<br>`"4:3"`<br>`"3:4"`<br>`"3:2"`<br>`"2:3"`<br>`"1:1"` |

| `解析度` | 輸出解析度。720p 渲染約 0.9 百萬像素（16:9 時為 1280x704），1080p 約 2 百萬像素（16:9 時為 1920x1088）（預設：`"720p"`）。 | COMBO | 是 | `"720p"`<br>`"1080p"` |

| `草稿` | 更快、細節較少的渲染，計費低於標準渲染（預設：False）。 | BOOLEAN | 是 | True/False |
| `generate_audio` | 為影片生成配樂。當連接 `model.audio` 時會忽略此參數，改由該音訊作為配樂（預設：True）。 | BOOLEAN | 是 | True/False |

**注意事項：**

- `model.prompt` 為必填，且限制為 5000 個字元。
- 1080p 的草稿模式無法與 48 fps 搭配使用：節點會引發錯誤，因此請關閉草稿模式或改用 24 fps。
- 連接的音訊長度必須至少 1 秒；超過 20 秒的部分會被忽略。
- 連接 `model.audio` 時，音訊會設定影片長度，因此 `model.duration` 與 `model.generate_audio` 不會產生作用。
