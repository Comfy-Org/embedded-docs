# VaeDecodeStructureTrellis2

این گره نمونه‌های نهان ساختار Trellis را با استفاده از رمزگشای ساختار یک VAE به یک گرید وکسل سه‌بعدی تبدیل می‌کند. تنها ۸ کانال اول نمونه نهان را می‌خواند، اشغال وکسل را بازسازی می‌کند و وضوح خروجی را به ۳۲ یا ۶۴ بنا به درخواست تنظیم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `نمونه‌ها` | نمایش نهان ساختار برای رمزگشایی. تنها ۸ کانال اول نمونه نهان برای رمزگشایی استفاده می‌شود. | LATENT | بله | - |
| `vae` | VAE که رمزگشای ساختار آن نمونه نهان را به گرید وکسل تبدیل می‌کند. رمزگشایی به صورت دسته‌ای انجام می‌شود. | VAE | بله | - |
| `وضوح` | وضوح فضایی هدف گرید وکسل خروجی (پیش‌فرض: "32"). اگر گرید رمزگشایی‌شده وضوح متفاوتی داشته باشد، برای مطابقت با آن کوچک‌مقیاس می‌شود. | COMBO | بله | "32"<br>"64" |

نکته: وقتی وضوح گرید وکسل رمزگشایی‌شده با `resolution` انتخاب‌شده تفاوت دارد، گرید با استفاده از max pooling سه‌بعدی به اندازه مورد نظر کوچک‌مقیاس می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `وکسل` | یک گرید اشغال وکسل دودویی به صورت تنسور اعشاری با شکل [دسته، عمق، ارتفاع، عرض]. مقادیر برای وکسل‌های اشغال‌شده 1.0 و برای وکسل‌های خالی 0.0 است. | VOXEL |
