# VaeDecodeStructureTrellis2

此節點使用 VAE 的結構解碼器，將 Trellis 結構潛在樣本轉換為 3D 體素網格。它僅讀取潛在變數的前 8 個通道，重建體素佔用情況，並將輸出解析度調整為要求的 32 或 64。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `樣本` | 待解碼的結構潛在表示。僅使用潛在變數的前 8 個通道進行解碼。 | LATENT | 是 | - |
| `vae` | 其結構解碼器將潛在變數轉換為體素網格的 VAE。解碼以批次方式執行。 | VAE | 是 | - |
| `解析度` | 輸出體素網格的目標空間解析度（預設值："32"）。若解碼後的網格解析度不同，則會降採樣以符合此設定。 | COMBO | 是 | "32"<br>"64" |

注意：當解碼後的體素網格解析度與所選 `resolution` 不同時，會使用 3D 最大池化將網格降採樣至要求的大小。
