# VaeDecodeStructureTrellis2

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Латентное представление структуры для декодирования. Для декодирования используются только первые 8 каналов латентного представления. | LATENT | Да | - |
| `vae` | VAE, структурный декодер которого преобразует латентное представление в воксельную сетку. Декодирование выполняется батчами. | VAE | Да | - |
| `resolution` | Целевое пространственное разрешение выходной воксельной сетки (по умолчанию: "32"). Если декодированная сетка имеет другое разрешение, она уменьшается до требуемого. | COMBO | Да | "32"<br>"64" |

Примечание: Если разрешение декодированной воксельной сетки отличается от выбранного `resolution`, сетка уменьшается до требуемого размера с помощью 3D max pooling.

## Выходные данные

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `voxel` | Бинарная воксельная сетка занятости в виде тензора с плавающей запятой формы [batch, depth, height, width]. Значения: 1.0 — для занятых вокселей, 0.0 — для пустых. | VOXEL |
