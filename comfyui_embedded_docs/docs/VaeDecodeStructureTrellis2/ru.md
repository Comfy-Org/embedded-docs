# VaeDecodeStructureTrellis2

Этот узел преобразует скрытые представления структуры Trellis в трехмерную воксельную сетку с помощью декодера структуры VAE. Он использует только первые 8 каналов скрытого представления, восстанавливает заполнение вокселей и изменяет разрешение результата на 32 или 64 по запросу.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Скрытое представление структуры для декодирования. Для декодирования используются только первые 8 каналов скрытого представления. | LATENT | Да | - |
| `vae` | VAE, декодер структуры которого преобразует скрытое представление в воксельную сетку. Декодирование выполняется пакетами. | VAE | Да | - |
| `resolution` | Целевое пространственное разрешение выходной воксельной сетки (по умолчанию: "32"). Если декодированная сетка имеет другое разрешение, она уменьшается до требуемого. | COMBO | Да | "32"<br>"64" |

Примечание. Если разрешение декодированной воксельной сетки отличается от выбранного `resolution`, сетка уменьшается с помощью 3D-максимального пулинга до требуемого размера.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `voxel` | Бинарная воксельная сетка заполнения в виде тензора с плавающей точкой формы [batch, depth, height, width]. Значения равны 1.0 для занятых вокселей и 0.0 для пустых вокселей. | VOXEL |
