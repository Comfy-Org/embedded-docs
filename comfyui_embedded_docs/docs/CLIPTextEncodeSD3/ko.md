# CLIP 텍스트 인코딩 (SD3)

CLIPTextEncodeSD3 노드는 여러 CLIP 모델을 사용하여 여러 텍스트 프롬프트를 인코딩함으로써 Stable Diffusion 3 모델용 텍스트 입력을 처리합니다. 이 노드는 세 개의 개별 텍스트 입력(`clip_g`, `clip_l`, `t5xxl`)을 처리하며 빈 텍스트 패딩을 관리하는 옵션을 제공합니다. 또한 서로 다른 텍스트 입력 간 토큰 정렬을 보장하고 SD3 생성 파이프라인에 적합한 컨디셔닝 데이터를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 텍스트 인코딩에 사용되는 CLIP 모델입니다. | CLIP | 예 | - |
| `clip_l` | 로컬 CLIP 모델용 텍스트 입력입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `clip_g` | 글로벌 CLIP 모델용 텍스트 입력입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `t5xxl` | T5-XXL 모델용 텍스트 입력입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `empty_padding` | 빈 텍스트 입력이 처리되는 방식을 제어합니다. "none"으로 설정하면 `clip_g`, `clip_l` 또는 `t5xxl`에 대한 빈 텍스트 입력이 패딩 대신 빈 토큰 목록으로 처리됩니다. 이는 고급 매개변수입니다(기본값: "none"). | COMBO | 예 | `"none"`<br>`"empty_prompt"` |

**매개변수 제약 사항:**

- `empty_padding`이(가) "none"으로 설정된 경우 `clip_g`, `clip_l` 또는 `t5xxl`에 대한 빈 텍스트 입력은 패딩 대신 빈 토큰 목록으로 처리됩니다.
- 이 노드는 길이가 다를 때 더 짧은 입력을 빈 토큰으로 패딩하여 `clip_l` 및 `clip_g` 입력 간의 토큰 길이를 자동으로 균형 있게 맞춥니다.
- 모든 텍스트 입력은 동적 프롬프트와 여러 줄 텍스트 입력을 지원합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `CONDITIONING` | SD3 생성 파이프라인에서 사용할 준비가 된 인코딩된 텍스트 컨디셔닝 데이터입니다. | CONDITIONING |
