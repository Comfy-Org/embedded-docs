# CLIPTextEncodeSD3

CLIPTextEncodeSD3 با رمزگذاری چندین ورودی متنی با استفاده از مدل‌های مختلف CLIP، ورودی‌های متنی را برای مدل‌های Stable Diffusion 3 پردازش می‌کند. این گره سه ورودی متنی جداگانه (`clip_g`، `clip_l` و `t5xxl`) را مدیریت می‌کند و گزینه‌هایی برای مدیریت padding متن خالی فراهم می‌کند. این گره ترازبندی صحیح توکن‌ها را بین ورودی‌های متنی مختلف تضمین می‌کند و داده‌های conditioning مناسب برای خطوط تولید SD3 بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن | CLIP | بله | - |
| `clip_l` | ورودی متنی برای مدل CLIP محلی. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `clip_g` | ورودی متنی برای مدل CLIP سراسری. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `t5xxl` | ورودی متنی برای مدل T5-XXL. از متن چندخطی و پرامپت‌های پویا پشتیبانی می‌کند. | STRING | بله | - |
| `فاصله خالی` | نحوه مدیریت ورودی‌های متنی خالی را کنترل می‌کند. وقتی روی "none" تنظیم شود، ورودی‌های متنی خالی برای `clip_g`، `clip_l` یا `t5xxl` به‌جای padding به لیست‌های توکن خالی منجر می‌شوند. وقتی روی "empty_prompt" تنظیم شود، ورودی‌های خالی به‌عنوان پرامپت‌های خالی توکنایز می‌شوند (رفتار استاندارد padding). این یک پارامتر پیشرفته است (پیش‌فرض: "none"). | COMBO | بله | `"none"`<br>`"empty_prompt"` |

**محدودیت‌های پارامتر:**

- وقتی `empty_padding` روی "none" تنظیم شود، ورودی‌های متنی خالی برای `clip_g`، `clip_l` یا `t5xxl` به‌جای padding به لیست‌های توکن خالی منجر می‌شوند
- این گره به‌طور خودکار طول توکن‌ها را بین ورودی‌های `clip_l` و `clip_g` با padding کردن ورودی کوتاه‌تر با توکن‌های خالی در صورت اختلاف طول، متوازن می‌کند
- همه ورودی‌های متنی از پرامپت‌های پویا و ورودی متن چندخطی پشتیبانی می‌کنند
