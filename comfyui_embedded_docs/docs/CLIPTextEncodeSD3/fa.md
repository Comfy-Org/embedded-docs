# CLIPTextEncodeSD3

گره `CLIPTextEncodeSD3` ورودی‌های متنی را برای مدل‌های Stable Diffusion 3 با رمزگذاری چندین prompt متنی با استفاده از مدل‌های مختلف CLIP پردازش می‌کند. این گره سه ورودی متنی جداگانه (`clip_g`، `clip_l` و `t5xxl`) را مدیریت کرده و گزینه‌هایی برای مدیریت padding متن خالی فراهم می‌آورد. گره ترازبندی صحیح توکن‌ها را بین ورودی‌های متنی مختلف تضمین کرده و داده‌های conditioning مناسب برای خط لوله تولید SD3 برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `clip` | مدل CLIP مورد استفاده برای رمزگذاری متن | CLIP | Yes | - |
| `clip_l` | ورودی متنی برای مدل CLIP محلی. از متن چندخطی و promptهای پویا پشتیبانی می‌کند. | STRING | Yes | - |
| `clip_g` | ورودی متنی برای مدل CLIP سراسری. از متن چندخطی و promptهای پویا پشتیبانی می‌کند. | STRING | Yes | - |
| `t5xxl` | ورودی متنی برای مدل T5-XXL. از متن چندخطی و promptهای پویا پشتیبانی می‌کند. | STRING | Yes | - |
| `empty_padding` | کنترل می‌کند که ورودی‌های متنی خالی چگونه مدیریت شوند. هنگامی که روی «"none"» تنظیم شود، ورودی‌های متنی خالی برای `clip_g`، `clip_l` یا `t5xxl` به جای padding، لیست توکن‌های خالی تولید می‌کنند. این یک پارامتر پیشرفته است (پیش‌فرض: «"none"»). | COMBO | Yes | `"none"`<br>`"empty_prompt"` |

**محدودیت‌های پارامتر:**

- هنگامی که `empty_padding` روی «"none"» تنظیم شده باشد، ورودی‌های متنی خالی برای `clip_g`، `clip_l` یا `t5xxl` به جای padding، لیست توکن‌های خالی تولید می‌کنند.
- گره به‌طور خودکار طول توکن‌ها را بین ورودی‌های `clip_l` و `clip_g` متعادل می‌کند؛ در صورت تفاوت طول، ورودی کوتاه‌تر با توکن‌های خالی padding می‌شود.
- همه ورودی‌های متنی از promptهای پویا و ورود متن چندخطی پشتیبانی می‌کنند.
