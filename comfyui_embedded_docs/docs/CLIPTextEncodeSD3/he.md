# קידוד טקסט CLIP (SD3)

CLIPTextEncodeSD3 מעבד קלטי טקסט עבור מודלים של Stable Diffusion 3 על ידי קידוד מספר פרומפטים של טקסט באמצעות מודלי CLIP שונים. הוא מטפל בשלושה קלטי טקסט נפרדים (`clip_g`, `clip_l`, ו-`t5xxl`) ומספק אפשרויות לניהול ריפוד טקסט ריק. הצומת מבטיח יישור טוקנים תקין בין קלטי טקסט שונים ומחזיר נתוני התניה המתאימים לצינורות יצירה של SD3.

## קלטים

| פרמטר | תיאור | סוג נתון | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP המשמש לקידוד טקסט | CLIP | כן | - |
| `clip_l` | קלט טקסט עבור מודל ה-CLIP המקומי. תומך בטקסט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `clip_g` | קלט טקסט עבור מודל ה-CLIP הגלובלי. תומך בטקסט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `t5xxl` | קלט טקסט עבור מודל T5-XXL. תומך בטקסט מרובה שורות ובפרומפטים דינמיים. | STRING | כן | - |
| `empty_padding` | שולט באופן שבו מטופלים קלטי טקסט ריקים. כאשר מוגדר ל-"none", קלטי טקסט ריקים עבור `clip_g`, `clip_l`, או `t5xxl` מפיקים רשימות טוקנים ריקות במקום ריפוד. כאשר מוגדר ל-"empty_prompt", קלטים ריקים עוברים טוקניזציה כפרומפטים ריקים (התנהגות ריפוד סטנדרטית). זהו פרמטר מתקדם (ברירת מחדל: "none"). | COMBO | כן | `"none"`<br>`"empty_prompt"` |

**אילוצי פרמטרים:**

- כאשר `empty_padding` מוגדר ל-"none", קלטי טקסט ריקים עבור `clip_g`, `clip_l`, או `t5xxl` מפיקים רשימות טוקנים ריקות במקום ריפוד
- הצומת מאזן אוטומטית אורכי טוקנים בין הקלטים `clip_l` ו-`clip_g` על ידי ריפוד הקצר מביניהם בטוקנים ריקים כאשר האורכים שונים
- כל קלטי הטקסט תומכים בפרומפטים דינמיים ובהזנת טקסט מרובת שורות
