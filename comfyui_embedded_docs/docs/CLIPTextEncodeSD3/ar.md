# ترميز نص CLIP لـ SD3

تعالج عقدة `CLIPTextEncodeSD3` الإدخالات النصية لنماذج Stable Diffusion 3 من خلال تشفير موجهات نصية متعددة باستخدام نماذج CLIP مختلفة. وتتعامل مع ثلاثة إدخالات نصية منفصلة (`clip_g` و`clip_l` و`t5xxl`)، وتوفر خيارات لإدارة حشو النص الفارغ. وتضمن العقدة المحاذاة الصحيحة للرموز المميزة بين الإدخالات النصية المختلفة، وتُرجع بيانات تكييف مناسبة لخطوط توليد SD3.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `clip` | نموذج CLIP المستخدم لتشفير النص | CLIP | نعم | - |
| `clip_l` | إدخال نصي لنموذج CLIP المحلي. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `clip_g` | إدخال نصي لنموذج CLIP العالمي. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `t5xxl` | إدخال نصي لنموذج T5-XXL. يدعم النص متعدد الأسطر والموجهات الديناميكية. | STRING | نعم | - |
| `empty_padding` | يتحكم في كيفية التعامل مع الإدخالات النصية الفارغة. عند الضبط على "none"، ستؤدي الإدخالات النصية الفارغة لـ `clip_g` أو `clip_l` أو `t5xxl` إلى قوائم رموز مميزة فارغة بدلاً من الحشو. هذا معامل متقدم (الافتراضي: "none"). | COMBO | نعم | `"none"`<br>`"empty_prompt"` |

**قيود المعاملات:**

- عند ضبط `empty_padding` على "none"، ستؤدي الإدخالات النصية الفارغة لـ `clip_g` أو `clip_l` أو `t5xxl` إلى قوائم رموز مميزة فارغة بدلاً من الحشو.
- تقوم العقدة تلقائيًا بموازنة أطوال الرموز المميزة بين مدخلي `clip_l` و`clip_g` عن طريق حشو الأقصر برموز مميزة فارغة عندما تختلف الأطوال.
- تدعم جميع الإدخالات النصية الموجهات الديناميكية وإدخال النص متعدد الأسطر.
