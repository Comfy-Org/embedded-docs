# Кодирование текста CLIP SD3

CLIPTextEncodeSD3 обрабатывает текстовые входы для моделей Stable Diffusion 3, кодируя несколько текстовых подсказок с помощью различных моделей CLIP. Он работает с тремя отдельными текстовыми входами (`clip_g`, `clip_l` и `t5xxl`) и предоставляет опции для управления заполнением пустого текста. Узел обеспечивает правильное выравнивание токенов между различными текстовыми входами и возвращает данные conditioning, подходящие для конвейеров генерации SD3.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Модель CLIP, используемая для кодирования текста | CLIP | Да | - |
| `clip_l` | Текстовый вход для локальной модели CLIP. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `clip_g` | Текстовый вход для глобальной модели CLIP. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `t5xxl` | Текстовый вход для модели T5-XXL. Поддерживает многострочный текст и динамические подсказки. | STRING | Да | - |
| `пустое_заполнение` | Управляет обработкой пустых текстовых входов. Если задано значение "none", пустые текстовые входы для `clip_g`, `clip_l` или `t5xxl` приводят к пустым спискам токенов вместо заполнения. Если задано значение "empty_prompt", пустые входы токенизируются как пустые подсказки (стандартное поведение заполнения). Это расширенный параметр (по умолчанию: "none"). | COMBO | Да | `"none"`<br>`"empty_prompt"` |

**Ограничения параметров:**

- Когда параметр `empty_padding` имеет значение "none", пустые текстовые входы для `clip_g`, `clip_l` или `t5xxl` приводят к пустым спискам токенов вместо заполнения
- Узел автоматически выравнивает длины токенов между входами `clip_l` и `clip_g`, дополняя более короткий пустыми токенами при различии длин
- Все текстовые входы поддерживают динамические подсказки и многострочный ввод текста

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CONDITIONING` | Закодированные данные conditioning, готовые к использованию в конвейерах генерации SD3 | CONDITIONING |
