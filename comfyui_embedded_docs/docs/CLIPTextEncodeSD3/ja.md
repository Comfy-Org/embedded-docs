# CLIPテキストエンコードSD3

CLIPTextEncodeSD3 ノードは、異なる CLIP モデルを使用して複数のテキストプロンプトをエンコードすることで、Stable Diffusion 3 モデル用のテキスト入力を処理します。このノードは 3 つの個別のテキスト入力（`clip_g`、`clip_l`、`t5xxl`）を処理し、空のテキストパディングを管理するオプションを提供します。ノードは、異なるテキスト入力間でトークンの整合性を確保し、SD3 生成パイプラインに適した conditioning データを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | テキストエンコーディングに使用される CLIP モデル | CLIP | はい | - |
| `clip_l` | ローカル CLIP モデル用のテキスト入力。複数行テキストと動的プロンプトをサポートします。 | STRING | はい | - |
| `clip_g` | グローバル CLIP モデル用のテキスト入力。複数行テキストと動的プロンプトをサポートします。 | STRING | はい | - |
| `t5xxl` | T5-XXL モデル用のテキスト入力。複数行テキストと動的プロンプトをサポートします。 | STRING | はい | - |
| `empty_padding` | 空のテキスト入力の処理方法を制御します。"none" に設定すると、`clip_g`、`clip_l`、または `t5xxl` の空のテキスト入力はパディングではなく空のトークンリストになります。これは上級者向けパラメータです（デフォルト: "none"）。 | COMBO | はい | `"none"`<br>`"empty_prompt"` |

**パラメータ制約：**

- `empty_padding` が "none" に設定されている場合、`clip_g`、`clip_l`、または `t5xxl` の空のテキスト入力は、パディングではなく空のトークンリストになります。
- このノードは、`clip_l` と `clip_g` の入力間でトークン長が異なる場合、短い方に空トークンをパディングすることで自動的にバランスを取ります。
- すべてのテキスト入力は動的プロンプトと複数行テキスト入力をサポートしています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `CONDITIONING` | SD3 生成パイプラインで使用できるエンコードされたテキスト conditioning データ | CONDITIONING |
