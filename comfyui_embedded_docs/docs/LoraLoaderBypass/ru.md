# Загрузка LoRA (Обход) (для отладки)

Узел LoraLoaderBypass применяет LoRA (Low-Rank Adaptation) к диффузионной модели и CLIP-модели в специальном режиме «bypass». В отличие от стандартного загрузчика LoRA, этот метод не изменяет постоянно веса базовой модели. Вместо этого он вычисляет результат, добавляя вклад LoRA к обычному прямому проходу модели, что полезно для обучения или при работе с моделями, веса которых выгружены.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будет применена LoRA. | MODEL | Да | - |
| `clip` | CLIP-модель, к которой будет применена LoRA. | CLIP | Да | - |
| `lora_name` | Имя LoRA. Доступные файлы LoRA загружаются из папки `loras`. | COMBO | Да | Список доступных файлов LoRA |
| `strength_model` | Насколько сильно изменить диффузионную модель. Значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | от -100.0 до 100.0 (шаг: 0.01) |
| `strength_clip` | Насколько сильно изменить CLIP-модель. Значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | от -100.0 до 100.0 (шаг: 0.01) |

**Примечание:** Если для `strength_model` и `strength_clip` установлено значение 0, узел возвращает исходные, неизменённые входы `model` и `clip` без обработки.

**Примечание:** Выбранный файл LoRA кэшируется после первой загрузки. Он повторно считывается с диска только при выборе другого `lora_name`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Изменённая диффузионная модель. | MODEL |
| `CLIP` | Изменённая CLIP-модель. | CLIP |

**Примечание:** Этот узел помечен как экспериментальный.
