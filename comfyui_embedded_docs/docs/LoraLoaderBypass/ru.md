# Загрузка LoRA (Обход) (для отладки)

Узел `LoraLoaderBypass` применяет LoRA (низкоранговую адаптацию) к диффузионной модели и модели CLIP в специальном режиме обхода (bypass). В отличие от стандартного загрузчика LoRA, он не изменяет постоянно веса базовой модели. Вместо этого он добавляет эффект LoRA к нормальному прямому проходу модели, что полезно для обучения или при работе с моделями, веса которых выгружены.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будет применена LoRA. | MODEL | Да | N/A |
| `clip` | Модель CLIP, к которой будет применена LoRA. | CLIP | Да | N/A |
| `lora_name` | Имя файла LoRA для применения. Варианты загружаются из папки `loras`. | COMBO | Да | Список доступных LoRA-файлов |
| `strength_model` | Насколько сильно изменять диффузионную модель. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 to 100.0 |
| `strength_clip` | Насколько сильно изменять модель CLIP. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 to 100.0 |

**Примечание:** Если оба значения `strength_model` и `strength_clip` установлены в 0, узел возвращает исходные неизменённые входы `model` и `clip` без обработки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Диффузионная модель с применённой LoRA в режиме обхода. | MODEL |
| `CLIP` | Модель CLIP с применённой LoRA в режиме обхода. | CLIP |
