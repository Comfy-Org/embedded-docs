# Загрузка LoRA (Обход) (для отладки)

Узел LoraLoaderBypass применяет LoRA (низкоранговую адаптацию) к диффузионной модели и модели CLIP в особом режиме обхода (bypass). В отличие от стандартного загрузчика LoRA, этот метод не изменяет постоянно веса базовой модели. Вместо этого он вычисляет результат, добавляя эффект LoRA к обычному прямому проходу модели, что полезно для обучения или при работе с моделями, веса которых выгружены.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Диффузионная модель, к которой будет применена LoRA. | MODEL | Да | - |
| `clip` | Модель CLIP, к которой будет применена LoRA. | CLIP | Да | - |
| `lora_name` | Название LoRA. Доступные файлы LoRA загружаются из папки `loras`. | COMBO | Да | Список доступных LoRA-файлов |
| `strength_model` | Насколько сильно изменить диффузионную модель. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 до 100.0 (шаг: 0.01) |
| `strength_clip` | Насколько сильно изменить модель CLIP. Это значение может быть отрицательным (по умолчанию: 1.0). | FLOAT | Да | -100.0 до 100.0 (шаг: 0.01) |

**Примечание:** Если оба значения `strength_model` и `strength_clip` установлены в 0, узел возвращает исходные неизменённые входы `model` и `clip` без обработки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Модифицированная диффузионная модель. | MODEL |
| `CLIP` | Модифицированная модель CLIP. | CLIP |

**Примечание:** Этот узел помечен как экспериментальный.
