# LoraLoaderBypass

הצומת LoraLoaderBypass מחיל LoRA (Low-Rank Adaptation) על מודל דיפוזיה ועל מודל CLIP במצב "bypass" מיוחד. בניגוד לטוען LoRA רגיל, שיטה זו אינה משנה באופן קבוע את המשקולות של מודל הבסיס. במקום זאת, היא מחשבת את התוצאה על ידי הוספת התרומה של ה-LoRA למעבר הקדימה הרגיל של המודל, דבר שמועיל לאימון או בעבודה עם מודלים שהמשקולות שלהם מפונות (offloaded).

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `model` | מודל הדיפוזיה שה-LoRA יוחל עליו. | MODEL | כן | - |
| `clip` | מודל ה-CLIP שה-LoRA יוחל עליו. | CLIP | כן | - |
| `lora_name` | שם ה-LoRA. קבצי LoRA זמינים נטענים מתיקיית `loras`. | COMBO | כן | רשימת קבצי LoRA זמינים |
| `strength_model` | עוצמת השינוי של מודל הדיפוזיה. ערך זה יכול להיות שלילי (ברירת מחדל: 1.0). | FLOAT | כן | -100.0 עד 100.0 (צעד: 0.01) |
| `strength_clip` | עוצמת השינוי של מודל ה-CLIP. ערך זה יכול להיות שלילי (ברירת מחדל: 1.0). | FLOAT | כן | -100.0 עד 100.0 (צעד: 0.01) |

**הערה:** אם גם `strength_model` וגם `strength_clip` מוגדרים ל-0, הצומת מחזיר את קלטי ה-`model` וה-`clip` המקוריים, ללא שינוי, ללא עיבוד.

**הערה:** קובץ ה-LoRA הנבחר נשמר במטמון לאחר טעינתו הראשונה. הוא נקרא מחדש מהדיסק רק כאשר נבחר `lora_name` אחר.
