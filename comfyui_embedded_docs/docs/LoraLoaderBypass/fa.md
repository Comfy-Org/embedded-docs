# بارگذاری LoRA (حالت Bypass) (برای اشکال‌زدایی)

گره LoraLoaderBypass یک LoRA (انطباق رتبه‌پایین) را در حالت ویژه «بایپس» به یک مدل دیفیوژن و یک مدل CLIP اعمال می‌کند. برخلاف بارگذار استاندارد LoRA، این روش به‌طور دائمی وزن‌های مدل پایه را تغییر نمی‌دهد. در عوض، خروجی را با افزودن اثر LoRA به گذر پیشروی عادی مدل محاسبه می‌کند؛ این قابلیت برای آموزش یا کار با مدل‌هایی که وزن‌هایشان تخلیه (offload) شده است مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل دیفیوژنی که LoRA روی آن اعمال می‌شود. | MODEL | بله | - |
| `clip` | مدل CLIP که LoRA روی آن اعمال می‌شود. | CLIP | بله | - |
| `lora_name` | نام LoRA. فایل‌های LoRA موجود از پوشه `loras` بارگذاری می‌شوند. | COMBO | بله | فهرست فایل‌های LoRA موجود |
| `قدرت_مدل` | میزان تغییر مدل دیفیوژن. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | 100.0- تا 100.0 (گام: 0.01) |
| `قدرت_clip` | میزان تغییر مدل CLIP. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | 100.0- تا 100.0 (گام: 0.01) |

**نکته:** اگر هر دو `strength_model` و `strength_clip` روی 0 تنظیم شوند، گره ورودی‌های `model` و `clip` اصلی و تغییرنیافته را بدون پردازش برمی‌گرداند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدل دیفیوژن اصلاح‌شده. | MODEL |
| `CLIP` | مدل CLIP اصلاح‌شده. | CLIP |

**نکته:** این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
