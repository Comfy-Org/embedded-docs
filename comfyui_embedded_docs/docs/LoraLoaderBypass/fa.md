# بارگذاری LoRA (حالت Bypass) (برای اشکال‌زدایی)

گره LoraLoaderBypass یک LoRA (تطبیق کم‌رتبه) را در حالت ویژه «بای‌پس» روی یک مدل دیفیوژن و یک مدل CLIP اعمال می‌کند. برخلاف بارگذار استاندارد LoRA، این روش وزن‌های مدل پایه را به‌طور دائمی تغییر نمی‌دهد. در عوض، نتیجه را با افزودن سهم LoRA به پاس پیش‌رو عادی مدل محاسبه می‌کند؛ این ویژگی برای آموزش یا کار با مدل‌هایی که وزن‌هایشان آفلود شده‌اند مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل دیفیوژنی که LoRA روی آن اعمال می‌شود. | MODEL | بله | - |
| `clip` | مدل CLIP که LoRA روی آن اعمال می‌شود. | CLIP | بله | - |
| `lora_name` | نام LoRA. فایل‌های LoRA موجود از پوشه `loras` بارگذاری می‌شوند. | COMBO | بله | فهرست فایل‌های LoRA موجود |
| `strength_model` | میزان شدت تغییر مدل دیفیوژن. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | -100.0 تا 100.0 (گام: 0.01) |
| `strength_clip` | میزان شدت تغییر مدل CLIP. این مقدار می‌تواند منفی باشد (پیش‌فرض: 1.0). | FLOAT | بله | -100.0 تا 100.0 (گام: 0.01) |

**توجه:** اگر هر دو `strength_model` و `strength_clip` روی 0 تنظیم شوند، گره ورودی‌های اصلی و تغییرنیافتهٔ `model` و `clip` را بدون پردازش بازمی‌گرداند.

**توجه:** فایل LoRA انتخاب‌شده پس از نخستین بارگذاری در کش ذخیره می‌شود. تنها زمانی دوباره از دیسک خوانده می‌شود که `lora_name` متفاوتی انتخاب شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدل دیفیوژن تغییر یافته. | MODEL |
| `CLIP` | مدل CLIP تغییر یافته. | CLIP |

**توجه:** این گره به‌عنوان آزمایشی علامت‌گذاری شده است.
