# Сэмплер DPMPP_2S_Ancestral

Узел SamplerDPMPP_2S_Ancestral создаёт сэмплер, использующий метод сэмплирования DPM++ 2S Ancestral для генерации изображений. Этот сэмплер сочетает детерминированные и стохастические элементы, чтобы получать разнообразные результаты при сохранении некоторой согласованности. Он позволяет управлять случайностью и уровнем шума в процессе сэмплирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет количеством стохастического шума, добавляемого во время сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |
| `s_noise` | Управляет масштабом шума, применяемого в процессе сэмплирования (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера, который можно использовать в конвейере сэмплирования | SAMPLER |
