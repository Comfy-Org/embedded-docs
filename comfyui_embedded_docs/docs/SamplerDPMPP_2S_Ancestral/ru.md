# Сэмплер DPMPP_2S_Ancestral

Узел SamplerDPMPP_2S_Ancestral создаёт сэмплер, использующий метод выборки DPM++ 2S Ancestral для генерации изображений. Этот сэмплер сочетает детерминированные и стохастические элементы, что позволяет получать разнообразные результаты при сохранении некоторой согласованности. Он даёт возможность управлять случайностью и уровнем шума в процессе выборки.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `eta` | Управляет количеством стохастического шума, добавляемого во время выборки (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 (step 0.01) |
| `s_noise` | Управляет масштабом шума, применяемого в процессе выборки (по умолчанию: 1.0) | FLOAT | Да | 0.0 - 100.0 (step 0.01) |

## Выходные параметры

| Выходное имя | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Возвращает настроенный объект сэмплера, который можно использовать в конвейере выборки | SAMPLER |
