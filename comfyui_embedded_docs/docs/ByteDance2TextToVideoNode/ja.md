# ByteDance Seedance 2.0 テキストから動画生成

このノードは、ByteDance の Seedance 2.5 または 2.0 モデルを使用して、テキスト記述からビデオを生成します。プロンプトを選択したモデルに送信し、ビデオが処理されるのを待って、最終結果を返します。

## 入力

`model` パラメータは動的コンボです。モデルを選択すると、テキストプロンプト、解像度、アスペクト比、長さ、音声生成設定など、必ず入力しなければならないモデル固有の入力がいくつか表示されます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画生成に使用するモデル。Seedance 2.5 は最新モデルで、mp4/mov 出力で最大30秒の動画を生成できます。Seedance 2.0 は最高品質を提供し、1080p/4k に対応しています。Fast は速度最適化用、Mini は最速・低コストの生成用です。 | DYNAMIC_COMBO | はい | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | いいえ | 0 ～ 2147483647 |
| `watermark` | ビデオに透かしを追加するかどうか（デフォルト: False）。これは高度な設定です。 | BOOLEAN | いいえ | True / False |

### Seedance 2.0 Fast および Seedance 2.0 Mini 入力

これらの入力は、`model` が `Seedance 2.0 Fast` または `Seedance 2.0 Mini` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
