# ByteDance Seedance 2.0 텍스트에서 비디오 생성

이 노드는 ByteDance의 Seedance 2.5 또는 2.0 모델을 사용하여 텍스트 설명에서 비디오를 생성합니다. 프롬프트를 선택한 모델로 전송하고, 비디오가 처리될 때까지 대기한 후 최종 결과를 반환합니다.

## 입력

`model` 매개변수는 동적 콤보입니다. 모델을 선택하면 텍스트 프롬프트, 해상도, 화면 비율, 지속 시간 및 오디오 생성 설정을 포함한 여러 모델별 입력이 표시됩니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다. Seedance 2.5는 최신 모델로, 최대 30초 비디오를 mp4/mov 출력으로 생성합니다. Seedance 2.0은 최대 품질로 1080p/4k를 제공합니다. Fast는 속도 최적화용이며, Mini는 가장 빠르고 저렴한 생성 방식입니다. | DYNAMIC_COMBO | 예 | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다(기본값: False). 고급 설정입니다. | BOOLEAN | 아니요 | True / False |

### Seedance 2.5 입력

이 입력은 `model`이 `Seedance 2.5`로 설정된 경우에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 생성되는 대화를 조정하려면 대사(구어체)를 큰따옴표로 묶습니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "720p"). | COMBO | 예 | `"480p"`<br>`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다(기본값: 5). | INT | 예 | 4 ~ 30 |
| `generate_audio` | 출력 비디오에 오디오 생성 활성화 여부입니다(기본값: True). | BOOLEAN | 아니요 | True / False |
| `output_format` | 출력 비디오의 컨테이너 형식입니다(기본값: "mp4"). | COMBO | 예 | `"mp4"` |

### Seedance 2.0 입력

이 입력은 `model`이 `Seedance 2.0`으로 설정된 경우에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"4k"` |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다(기본값: 7). | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성 활성화 여부입니다(기본값: True). | BOOLEAN | 아니요 | True / False |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

이 입력은 `model`이 `Seedance 2.0 Fast` 또는 `Seedance 2.0 Mini`로 설정된 경우에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br>`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다(기본값: 7). | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성 활성화 여부입니다(기본값: True). | BOOLEAN | 아니요 | True / False |

**참고:** `prompt`는 공백을 제거한 후 최소 1자 이상이어야 하며, 그렇지 않으면 작업이 검증에 실패합니다. 지속 시간 제한은 모델에 따라 다릅니다. Seedance 2.5는 4~30초를 지원하며, Seedance 2.0, Seedance 2.0 Fast 및 Seedance 2.0 Mini는 4~15초를 지원합니다. 해상도 옵션도 모델별로 다릅니다. Seedance 2.5는 480p와 720p를 지원하고, Seedance 2.0은 480p, 720p, 1080p 및 4k를 지원하며, Seedance 2.0 Fast 및 Seedance 2.0 Mini는 480p와 720p만 지원합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. | VIDEO |
