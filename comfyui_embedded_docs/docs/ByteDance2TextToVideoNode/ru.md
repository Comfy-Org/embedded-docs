# ByteDance Seedance 2.0: текст в видео

Этот узел генерирует видео по текстовому запросу с помощью моделей ByteDance Seedance 2.5 или 2.0. Он отправляет запрос выбранной модели, ожидает завершения обработки видео и возвращает полученный видеофайл.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель Seedance для генерации видео. Seedance 2.5 — новейшая модель, поддерживающая видео до 30 секунд и выход в форматах mp4/mov; Seedance 2.0 — для максимального качества и 4k; Seedance 2.0 Fast — для оптимизации скорости; Seedance 2.0 Mini — для самой быстрой и недорогой генерации. Выбор модели открывает дополнительные входы для запроса, разрешения, соотношения сторон, длительности и генерации аудио. | DYNAMIC_COMBO | Да | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | Управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от seed. (по умолчанию: 0) | INT | Нет | 0 до 2147483647 |
| `водяной знак` | Следует ли добавлять водяной знак к видео. (по умолчанию: False) Это дополнительная настройка. | BOOLEAN | Нет | True / False |

### Входы Seedance 2.5

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. Заключайте произносимые реплики в двойные кавычки, чтобы управлять сгенерированным диалогом. | STRING | Да | — |
| `resolution` | Разрешение выходного видео. (по умолчанию: `"720p"`) | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `ratio` | Соотношение сторон выходного видео. (по умолчанию: `"16:9"`) | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах. (по умолчанию: 5) | INT | Да | 4 до 30 |
| `generate_audio` | Включить генерацию аудио для выходного видео. (по умолчанию: True) | BOOLEAN | Да | True / False |
| `output_format` | Контейнерный формат выходного видео. (по умолчанию: `"mp4"`) | COMBO | Да | `"mp4"` |

### Входы Seedance 2.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. | STRING | Да | — |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"4k"` |
| `ratio` | Соотношение сторон выходного видео. (по умолчанию: `"16:9"`) | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах. (по умолчанию: 7) | INT | Да | 4 до 15 |
| `generate_audio` | Включить генерацию аудио для выходного видео. (по умолчанию: True) | BOOLEAN | Да | True / False |

### Входы Seedance 2.0 Fast и Seedance 2.0 Mini

Общие для Seedance 2.0 Fast и Seedance 2.0 Mini; обе модели предоставляют одинаковые параметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. | STRING | Да | — |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `ratio` | Соотношение сторон выходного видео. (по умолчанию: `"16:9"`) | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах. (по умолчанию: 7) | INT | Да | 4 до 15 |
| `generate_audio` | Включить генерацию аудио для выходного видео. (по умолчанию: True) | BOOLEAN | Да | True / False |

**Примечание:** Селектор `model` является динамическим; входы, показанные в разделе каждой модели, появляются при выборе этой модели. Запрос должен содержать не менее 1 символа после удаления пробелов. Ограничения по разрешению и длительности зависят от выбранной модели: Seedance 2.5 поддерживает 480p/720p/1080p и от 4 до 30 секунд; Seedance 2.0 поддерживает 480p/720p/1080p/4k и от 4 до 15 секунд; Seedance 2.0 Fast и Seedance 2.0 Mini поддерживают только 480p/720p и от 4 до 15 секунд. Значение `seed` управляет только тем, перезапускается ли узел; оно не делает результаты детерминированными.
