# ByteDance Seedance 2.0: текст в видео

Этот узел генерирует видео по текстовому описанию с использованием моделей ByteDance Seedance 2.5 или 2.0. Он отправляет ваш запрос выбранной модели, ожидает обработки видео и возвращает конечный результат.

## Входы

Параметр `model` — это динамическое комбинированное поле. При выборе модели отображаются несколько специфических для модели входных параметров, которые необходимо заполнить, включая текстовый запрос, разрешение, соотношение сторон, длительность и настройку генерации звука.

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для генерации видео. Seedance 2.5 — новейшая модель, создающая видео длительностью до 30 секунд с выводом в формате mp4/mov; Seedance 2.0 обеспечивает максимальное качество с разрешением 1080p/4k; Fast предназначена для оптимизации скорости; Mini — самая быстрая и недорогая генерация. | DYNAMIC_COMBO | Да | `"Seedance 2.5"`<br>`"Seedance 2.0"`<br>`"Seedance 2.0 Fast"`<br>`"Seedance 2.0 Mini"` |
| `seed` | Управляет необходимостью повторного запуска узла; результаты недетерминированы независимо от seed (по умолчанию: 0). | INT | Нет | 0 to 2147483647 |
| `watermark` | Добавлять ли водяной знак к видео (по умолчанию: False). Это расширенная настройка. | BOOLEAN | Нет | True / False |

### Входы Seedance 2.5

Эти входные параметры появляются, когда для `model` установлено значение `Seedance 2.5`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео. Заключайте реплики в двойные кавычки, чтобы управлять генерируемым диалогом (по умолчанию: пусто). | STRING | Да | Any text |
| `resolution` | Разрешение выходного видео (по умолчанию: "720p"). | COMBO | Да | `"480p"`<br>`"720p"` |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9"). | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | 4 to 30 |
| `generate_audio` | Включить генерацию звука для выходного видео (по умолчанию: True). | BOOLEAN | Нет | True / False |
| `output_format` | Формат контейнера выходного видео (по умолчанию: "mp4"). | COMBO | Да | `"mp4"` |

### Входы Seedance 2.0

Эти входные параметры появляются, когда для `model` установлено значение `Seedance 2.0`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео (по умолчанию: пусто). | STRING | Да | Any text |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"`<br>`"4k"` |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9"). | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 7). | INT | Да | 4 to 15 |
| `generate_audio` | Включить генерацию звука для выходного видео (по умолчанию: True). | BOOLEAN | Нет | True / False |

### Входы Seedance 2.0 Fast и Seedance 2.0 Mini

Эти входные параметры появляются, когда для `model` установлено значение `Seedance 2.0 Fast` или `Seedance 2.0 Mini`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос для генерации видео (по умолчанию: пусто). | STRING | Да | Any text |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"` |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: "16:9"). | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"`<br>`"adaptive"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 7). | INT | Да | 4 to 15 |
| `generate_audio` | Включить генерацию звука для выходного видео (по умолчанию: True). | BOOLEAN | Нет | True / False |

**Примечание:** `prompt` должен содержать не менее 1 символа после удаления пробелов, в противном случае задача не пройдет проверку. Лимиты длительности зависят от модели: Seedance 2.5 поддерживает от 4 до 30 секунд, а Seedance 2.0, Seedance 2.0 Fast и Seedance 2.0 Mini — от 4 до 15 секунд. Варианты разрешения также различаются в зависимости от модели: Seedance 2.5 поддерживает 480p и 720p; Seedance 2.0 поддерживает 480p, 720p, 1080p и 4k; Seedance 2.0 Fast и Seedance 2.0 Mini поддерживают только 480p и 720p.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированный видеофайл. | VIDEO |
