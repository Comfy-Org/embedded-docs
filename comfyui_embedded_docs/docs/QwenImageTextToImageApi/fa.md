# QwenImageTextToImageApi

Qwen Image 3 Text to Image با استفاده از مدل‌های Qwen-Image 3.0 یک یا چند تصویر را از روی یک متن ورودی (prompt) تولید می‌کند. شما یک مدل انتخاب کرده و یک prompt ارائه می‌دهید و گره تصاویر تولیدشده را به صورت یک دسته (batch) برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که استفاده می‌شود (پیش‌فرض: "qwen-image-3.0-pro"). این انتخابگر ترکیبی همچنین prompt، عرض و ارتفاع تصویر، و prompt منفی اختیاری را فراهم می‌کند. | MODEL | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | تعداد تصاویری که تولید می‌شود و به صورت یک دسته بازگردانده می‌شود (پیش‌فرض: 1). | INT | خیر | 1 تا 6 |
| `seed` | دانه (Seed) مورد استفاده برای تولید (پیش‌فرض: 42). می‌توان آن را طوری تنظیم کرد که پس از هر تولید به‌صورت خودکار به‌روزرسانی شود. | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | آیا prompt با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: true). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |
| `watermark` | آیا واترمارک تولیدشده با هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: false). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

مشترک بین qwen-image-3.0-pro و qwen-image-3.0.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Prompt توصیف‌کننده تصویر. از انگلیسی و چینی پشتیبانی می‌کند. باید حداقل ۱ کاراکتر داشته باشد. | STRING | بله | متن آزاد |
| `negative_prompt` | Prompt منفی توصیف‌کننده آنچه باید اجتناب شود (پیش‌فرض: ""). | STRING | خیر | متن آزاد |
| `width` | مساحت کل پیکسل باید بین 512×512 و 2560×2560 باشد؛ هر نسبت ابعادی در آن مساحت کار می‌کند. (پیش‌فرض: 1024) | INT | خیر | 256 تا 2560 (گام 16) |
| `height` | مساحت کل پیکسل باید بین 512×512 و 2560×2560 باشد؛ هر نسبت ابعادی در آن مساحت کار می‌کند. (پیش‌فرض: 1024) | INT | خیر | 256 تا 2560 (گام 16) |

توجه: ورودی `model` یک انتخابگر ترکیبی است با زیرفیلدهای `model` (شناسه مدل)، `prompt` (الزامی، باید حداقل ۱ کاراکتر داشته باشد)، `width` و `height` (ابعاد تصویر)، و `negative_prompt` (اختیاری). مساحت پیکسلی ترکیبی `width` و `height` باید بین ۲۶۲٬۱۴۴ پیکسل (512×512) و ۶٬۵۵۳٬۶۰۰ پیکسل (2560×2560) باشد و نسبت ابعاد باید بین 1:8 و 8:1 حفظ شود.
