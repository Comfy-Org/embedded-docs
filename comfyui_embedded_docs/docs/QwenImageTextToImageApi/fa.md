# تبدیل متن به تصویر Qwen ۳

Qwen Image 3 Text to Image با استفاده از مدل‌های Qwen-Image 3.0 یک یا چند تصویر را از یک پرامپت متنی تولید می‌کند. شما یک مدل انتخاب می‌کنید و یک پرامپت ارائه می‌دهید، و گره تصاویر تولیدشده را به‌صورت یک batch بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده (پیش‌فرض: "qwen-image-3.0-pro"). این انتخابگر ترکیبی همچنین پرامپت، پرامپت منفی، عرض تصویر و ارتفاع تصویر را فراهم می‌کند. | DYNAMIC_COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `تعداد` | تعداد تصاویر برای تولید، که به‌صورت یک batch بازگردانده می‌شوند (پیش‌فرض: 1). | INT | خیر | 1 تا 6 |
| `seed` | مقدار seed مورد استفاده برای تولید (پیش‌فرض: 42). می‌توان آن را طوری تنظیم کرد که پس از هر تولید به‌صورت خودکار به‌روزرسانی شود. | INT | خیر | 0 تا 2147483647 |
| `افزایش پرامپت` | این‌که پرامپت با کمک هوش مصنوعی تقویت شود یا نه (پیش‌فرض: true). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |
| `واترمارک` | این‌که یک واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود یا نه (پیش‌فرض: false). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

مشترک بین qwen-image-3.0-pro و qwen-image-3.0.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپتی که تصویر را توصیف می‌کند. از انگلیسی و چینی پشتیبانی می‌کند. باید حداقل 1 کاراکتر داشته باشد. | STRING | بله | متن آزاد |
| `negative_prompt` | پرامپت منفی که مواردی را توصیف می‌کند که باید از آن‌ها اجتناب شود (پیش‌فرض: ""). | STRING | خیر | متن آزاد |
| `width` | مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ هر نسبت ابعادی در این محدوده قابل‌قبول است. (پیش‌فرض: 1024) | INT | خیر | 256 تا 2560 (گام 16) |
| `height` | مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ هر نسبت ابعادی در این محدوده قابل‌قبول است. (پیش‌فرض: 1024) | INT | خیر | 256 تا 2560 (گام 16) |

نکته: ورودی `model` یک انتخابگر ترکیبی با زیرفیلدهای `model` (شناسه مدل)، `prompt` (الزامی، باید حداقل 1 کاراکتر داشته باشد)، `negative_prompt` (اختیاری)، `width` و `height` است. مساحت پیکسلی ترکیبی `width` و `height` باید بین 262,144 پیکسل (512x512) و 6,553,600 پیکسل (2560x2560) باشد، و نسبت ابعاد باید بین 1:8 و 8:1 باقی بماند.
