# QwenImageTextToImageApi

Qwen Image 3 Text to Image با استفاده از مدل‌های Qwen-Image 3.0، یک یا چند تصویر از یک فرمان متنی تولید می‌کند. شما یک مدل انتخاب کرده و یک فرمان ارائه می‌دهید؛ گره تصاویر تولیدشده را به‌صورت یک دسته (batch) برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `model` | مدل مورد استفاده (پیش‌فرض: "qwen-image-3.0-pro"). این انتخابگر ترکیبی همچنین فرمان، عرض تصویر، ارتفاع تصویر و فرمان منفی اختیاری را فراهم می‌کند. | MODEL | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | تعداد تصاویر برای تولید که به‌صورت یک دسته بازگردانده می‌شوند (پیش‌فرض: 1). | INT | خیر | 1 تا 6 |
| `seed` | دانه (seed) مورد استفاده برای تولید (پیش‌فرض: 42). می‌توان آن را طوری تنظیم کرد که پس از هر تولید به‌صورت خودکار به‌روزرسانی شود. | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | آیا فرمان با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: true). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |
| `watermark` | آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: false). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |

توجه: ورودی `model` یک انتخابگر ترکیبی با زیرفیلدهای زیر است: `model` (شناسه مدل)، `prompt` (فرمان متنی که باید حداقل ۱ نویسه داشته باشد)، `width` و `height` (ابعاد تصویر که توسط گره اعتبارسنجی می‌شوند)، و `negative_prompt` (فرمان منفی اختیاری).

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `image` | تصویر یا تصاویر تولیدشده که به‌صورت یک دسته بازگردانده می‌شوند. | IMAGE |
