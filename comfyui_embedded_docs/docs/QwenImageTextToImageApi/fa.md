# QwenImageTextToImageApi

Qwen Image 3 Text to Image با استفاده از مدل‌های Qwen-Image 3.0 یک یا چند تصویر را از روی یک متن ورودی (prompt) تولید می‌کند. شما یک مدل انتخاب کرده و یک prompt ارائه می‌دهید و گره تصاویر تولیدشده را به صورت یک دسته (batch) برمی‌گرداند.
## ورودیها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `model` | مدلی که استفاده می‌شود (پیش‌فرض: "qwen-image-3.0-pro"). این انتخابگر ترکیبی همچنین prompt، عرض و ارتفاع تصویر، و prompt منفی اختیاری را فراهم می‌کند. | DYNAMIC_COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | تعداد تصاویری که تولید می‌شود و به صورت یک دسته بازگردانده می‌شود (پیش‌فرض: 1). | INT | خیر | 1 to 6 |
| `seed` | دانه (Seed) مورد استفاده برای تولید (پیش‌فرض: 42). می‌توان آن را طوری تنظیم کرد که پس از هر تولید به‌صورت خودکار به‌روزرسانی شود. | INT | خیر | 0 to 2147483647 |
| `prompt_extend` | آیا prompt با کمک هوش مصنوعی بهبود یابد (پیش‌فرض: true). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |
| `watermark` | آیا واترمارک تولیدشده با هوش مصنوعی به نتیجه اضافه شود (پیش‌فرض: false). گزینه پیشرفته. | BOOLEAN | خیر | true<br>false |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `prompt` | Prompt توصیف‌کننده تصویر. از انگلیسی و چینی پشتیبانی می‌کند. باید حداقل ۱ کاراکتر داشته باشد. | STRING | بله | Free text |
| `negative_prompt` | Prompt منفی توصیف‌کننده آنچه باید اجتناب شود (پیش‌فرض: ""). | STRING | خیر | Free text |
| `width` | مساحت کل پیکسل باید بین 512×512 و 2560×2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | خیر | 256 to 2560 (step 16) |
| `height` | مساحت کل پیکسل باید بین 512×512 و 2560×2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | خیر | 256 to 2560 (step 16) |

## خروجیها

| نام خروجی | توضیحات | نوع داده |
|---|---|---|
| `image` | The generated image or images, returned as a batch. | IMAGE |
