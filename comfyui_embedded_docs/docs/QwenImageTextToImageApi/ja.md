# QwenImageTextToImageApi

Qwen Image 3 Text to Image は、Qwen-Image 3.0 モデルを使用して、テキストプロンプトから1つ以上の画像を生成します。モデルを選択してプロンプトを入力すると、ノードは生成された画像をバッチとして返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル（デフォルト: "qwen-image-3.0-pro"）。この複合セレクターは、プロンプト、画像の幅、画像の高さ、およびオプションのネガティブプロンプトも提供します。 | MODEL | はい | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | 生成する画像の数。バッチとして返されます（デフォルト: 1）。 | INT | いいえ | 1 〜 6 |
| `seed` | 生成に使用するシード（デフォルト: 42）。各生成後に自動更新するよう設定できます。 | INT | いいえ | 0 〜 2147483647 |
| `prompt_extend` | AI支援でプロンプトを拡張するかどうか（デフォルト: true）。詳細オプションです。 | BOOLEAN | いいえ | true<br>false |
| `watermark` | 結果にAI生成透かしを追加するかどうか（デフォルト: false）。詳細オプションです。 | BOOLEAN | いいえ | true<br>false |

### qwen-image-3.0-pro および qwen-image-3.0 入力

qwen-image-3.0-pro と qwen-image-3.0 で共通です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 画像を説明するプロンプト。英語と中国語に対応しています。1文字以上である必要があります。 | STRING | はい | 自由テキスト |
| `negative_prompt` | 避けたい内容を説明するネガティブプロンプト（デフォルト: ""）。 | STRING | いいえ | 自由テキスト |
| `width` | 総ピクセル面積は512x512から2560x2560の間でなければなりません。アスペクト比は 1:8 から 8:1 の間である必要があります。（デフォルト: 1024） | INT | いいえ | 256 〜 2560 (ステップ 16) |
| `height` | 総ピクセル面積は512x512から2560x2560の間でなければなりません。アスペクト比は 1:8 から 8:1 の間である必要があります。（デフォルト: 1024） | INT | いいえ | 256 〜 2560 (ステップ 16) |

注: `model` 入力は複合セレクターであり、サブフィールドとして `model`（モデルID）、`prompt`（必須、1文字以上）、`width` と `height`（画像寸法）、および `negative_prompt`（オプション）を持ちます。`width` と `height` を掛け合わせた総ピクセル数は、262,144ピクセル（512x512）から6,553,600ピクセル（2560x2560）の間でなければならず、アスペクト比は1:8から8:1の範囲に収まる必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-----------|-------------|-----------|
| `image` | 生成された画像（複数可）。バッチとして返されます。 | IMAGE |
