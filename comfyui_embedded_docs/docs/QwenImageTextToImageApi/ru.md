# Qwen Image 3 Text to Image

Qwen Image 3 Text to Image генерирует одно или несколько изображений из текстового промпта с использованием моделей Qwen-Image 3.0. Вы выбираете модель и задаёте промпт, а узел возвращает сгенерированные изображения в виде пакета.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования (по умолчанию: "qwen-image-3.0-pro"). Этот составной селектор также предоставляет промпт, негативный промпт, ширину и высоту изображения. | DYNAMIC_COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | Количество изображений для генерации, возвращаемых в виде пакета (по умолчанию: 1). | INT | Нет | от 1 до 6 |
| `seed` | Начальное значение (seed) для генерации (по умолчанию: 42). Может быть настроено на автоматическое обновление после каждой генерации. | INT | Нет | от 0 до 2147483647 |
| `prompt_extend` | Улучшать ли промпт с помощью ИИ (по умолчанию: true). Дополнительная опция. | BOOLEAN | Нет | true<br>false |
| `watermark` | Добавлять ли водяной знак, сгенерированный ИИ, к результату (по умолчанию: false). Дополнительная опция. | BOOLEAN | Нет | true<br>false |

### Входы qwen-image-3.0-pro и qwen-image-3.0

Общие для qwen-image-3.0-pro и qwen-image-3.0.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Промпт, описывающий изображение. Поддерживает английский и китайский языки. Должен содержать не менее 1 символа. | STRING | Да | Свободный текст |
| `negative_prompt` | Негативный промпт, описывающий, чего следует избегать (по умолчанию: ""). | STRING | Нет | Свободный текст |
| `width` | Общая площадь в пикселях должна быть от 512x512 до 2560x2560; подходит любое соотношение сторон в пределах этой площади. (по умолчанию: 1024) | INT | Нет | от 256 до 2560 (шаг 16) |
| `height` | Общая площадь в пикселях должна быть от 512x512 до 2560x2560; подходит любое соотношение сторон в пределах этой площади. (по умолчанию: 1024) | INT | Нет | от 256 до 2560 (шаг 16) |

Примечание: вход `model` — составной селектор с подполями `model` (ID модели), `prompt` (обязательный, должен содержать не менее 1 символа), `negative_prompt` (необязательный), `width` и `height`. Общая площадь в пикселях для `width` и `height` должна быть от 262 144 пикселей (512x512) до 6 553 600 пикселей (2560x2560), а соотношение сторон должно оставаться в диапазоне от 1:8 до 8:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение или изображения, возвращаемые в виде пакета. | IMAGE |
