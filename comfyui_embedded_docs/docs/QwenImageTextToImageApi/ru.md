# QwenImageTextToImageApi

Qwen Image 3 Text to Image создаёт одно или несколько изображений по текстовому запросу с использованием моделей Qwen-Image 3.0. Вы выбираете модель и вводите запрос, а узел возвращает сгенерированные изображения в виде батча.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель для использования (по умолчанию: "qwen-image-3.0-pro"). Этот составной селектор также задаёт текстовый запрос, ширину и высоту изображения, а также необязательный негативный запрос. | DYNAMIC_COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | Количество изображений для генерации, возвращаемых в виде батча (по умолчанию: 1). | INT | Нет | 1 to 6 |
| `seed` | Сид для генерации (по умолчанию: 42). Может быть настроен на автоматическое обновление после каждой генерации. | INT | Нет | 0 to 2147483647 |
| `prompt_extend` | Нужно ли улучшать запрос с помощью ИИ (по умолчанию: true). Дополнительная опция. | BOOLEAN | Нет | true<br>false |
| `watermark` | Добавлять ли к результату водяной знак, созданный ИИ (по умолчанию: false). Дополнительная опция. | BOOLEAN | Нет | true<br>false |

### qwen-image-3.0-pro и qwen-image-3.0 Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Текстовый запрос, описывающий изображение. Поддерживает английский и китайский языки. Должен содержать как минимум 1 символ. | STRING | Да | Free text |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать (по умолчанию: ""). | STRING | Нет | Free text |
| `width` | Общая площадь изображения в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Нет | 256 to 2560 (step 16) |
| `height` | Общая площадь изображения в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Нет | 256 to 2560 (step 16) |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `image` | The generated image or images, returned as a batch. | IMAGE |
