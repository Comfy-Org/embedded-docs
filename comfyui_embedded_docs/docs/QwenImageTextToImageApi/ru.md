# QwenImageTextToImageApi

Qwen Image 3 Text to Image создаёт одно или несколько изображений по текстовому запросу с использованием моделей Qwen-Image 3.0. Вы выбираете модель и вводите запрос, а узел возвращает сгенерированные изображения в виде батча.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования (по умолчанию: "qwen-image-3.0-pro"). Этот составной селектор также задаёт текстовый запрос, ширину и высоту изображения, а также необязательный негативный запрос. | MODEL | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | Количество изображений для генерации, возвращаемых в виде батча (по умолчанию: 1). | INT | Нет | от 1 до 6 |
| `seed` | Сид для генерации (по умолчанию: 42). Может быть настроен на автоматическое обновление после каждой генерации. | INT | Нет | от 0 до 2147483647 |
| `prompt_extend` | Нужно ли улучшать запрос с помощью ИИ (по умолчанию: true). Дополнительная опция. | BOOLEAN | Нет | true<br>false |
| `watermark` | Добавлять ли к результату водяной знак, созданный ИИ (по умолчанию: false). Дополнительная опция. | BOOLEAN | Нет | true<br>false |

### qwen-image-3.0-pro и qwen-image-3.0 Входы

Общие для qwen-image-3.0-pro и qwen-image-3.0.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение. Поддерживает английский и китайский языки. Должен содержать как минимум 1 символ. | STRING | Да | Произвольный текст |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать (по умолчанию: ""). | STRING | Нет | Произвольный текст |
| `width` | Общая площадь изображения в пикселях должна быть от 512×512 до 2560×2560; в этих пределах подходит любое соотношение сторон. (по умолчанию: 1024) | INT | Нет | от 256 до 2560 (шаг 16) |
| `height` | Общая площадь изображения в пикселях должна быть от 512×512 до 2560×2560; в этих пределах подходит любое соотношение сторон. (по умолчанию: 1024) | INT | Нет | от 256 до 2560 (шаг 16) |

Примечание: входной параметр `model` — это составной селектор со следующими подполями: `model` (идентификатор модели), `prompt` (обязательное, должно содержать как минимум 1 символ), `width` и `height` (размеры изображения), и `negative_prompt` (необязательное). Общая площадь в пикселях для `width` и `height` должна быть от 262 144 пикселей (512×512) до 6 553 600 пикселей (2560×2560), а соотношение сторон должно оставаться в пределах от 1:8 до 8:1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Сгенерированное изображение или изображения, возвращаемые в виде батча. | IMAGE |
