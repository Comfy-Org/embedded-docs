# QwenImageTextToImageApi

Qwen Image 3 Text to Image генерирует одно или несколько изображений по текстовому запросу с использованием моделей Qwen-Image 3.0. Вы выбираете модель и вводите запрос, а узел возвращает сгенерированные изображения в виде пакета.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Используемая модель (по умолчанию: "qwen-image-3.0-pro"). Этот составной селектор также содержит запрос, ширину и высоту изображения и необязательный негативный запрос. | MODEL | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | Количество изображений для генерации, возвращаемых в виде пакета (по умолчанию: 1). | INT | Нет | 1 до 6 |
| `seed` | Зерно (seed) для генерации (по умолчанию: 42). Может быть настроено на автоматическое обновление после каждой генерации. | INT | Нет | 0 до 2147483647 |
| `prompt_extend` | Следует ли улучшать запрос с помощью ИИ-ассистента (по умолчанию: true). Расширенная опция. | BOOLEAN | Нет | true<br>false |
| `watermark` | Следует ли добавлять водяной знак, созданный ИИ, к результату (по умолчанию: false). Расширенная опция. | BOOLEAN | Нет | true<br>false |

Примечание: входной параметр `model` является составным селектором со следующими подполями: `model` (идентификатор модели), `prompt` (текстовый запрос, который должен содержать как минимум 1 символ), `width` и `height` (размеры изображения, проверяемые узлом) и `negative_prompt` (необязательный негативный запрос).

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `image` | Сгенерированное изображение или изображения, возвращаемые в виде пакета. | IMAGE |
