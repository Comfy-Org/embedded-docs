# QwenImageTextToImageApi

```markdown
Qwen Image 3 Text to Image

يقوم هذا العقدة بتوليد صورة أو أكثر من موجه نصي باستخدام نماذج Qwen-Image 3.0. يمكنك تحديد نموذج وتقديم موجه، وتقوم العقدة بإرجاع الصور المولّدة كدفعة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج المستخدم (الافتراضي: "qwen-image-3.0-pro"). يوفر هذا المحدد المركب أيضًا الموجه النصي وعرض الصورة وارتفاعها والموجه السلبي الاختياري. | MODEL | نعم | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `n` | عدد الصور المراد توليدها، ويتم إرجاعها كدفعة (الافتراضي: 1). | INT | لا | 1 إلى 6 |
| `seed` | البذرة المستخدمة في التوليد (الافتراضي: 42). يمكن ضبطها للتحديث تلقائيًا بعد كل عملية توليد. | INT | لا | 0 إلى 2147483647 |
| `prompt_extend` | ما إذا كان سيتم تحسين الموجه بمساعدة الذكاء الاصطناعي (الافتراضي: true). خيار متقدم. | BOOLEAN | لا | true<br>false |
| `watermark` | ما إذا كان سيتم إضافة علامة مائية بتقنية الذكاء الاصطناعي إلى النتيجة (الافتراضي: false). خيار متقدم. | BOOLEAN | لا | true<br>false |

ملاحظة: يُعد معامل `model` محددًا مركبًا يحتوي على الحقول الفرعية التالية: `model` (معرّف النموذج)، و`prompt` (الموجه النصي، ويجب أن يحتوي على حرف واحد على الأقل)، و`width` و`height` (أبعاد الصورة، ويتم التحقق منها بواسطة العقدة)، و`negative_prompt` (الموجه السلبي الاختياري).

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `image` | الصورة أو الصور المولّدة، ويتم إرجاعها كدفعة. | IMAGE |
```
