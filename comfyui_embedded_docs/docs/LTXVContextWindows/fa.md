# پنجره‌های زمینه LTXV

این گره پنجره‌های زمینه (context windows) را برای مدل‌های مشابه LTXV در حین نمونه‌برداری تنظیم می‌کند. این گره فرآیند تولید ویدیو را به پنجره‌های همپوشانی‌دار تقسیم می‌کند تا استفاده از حافظه مدیریت شده و هماهنگی زمانی بهبود یابد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که پنجره‌های زمینه در حین نمونه‌برداری روی آن اعمال می‌شود. | MODEL | بله | - |
| `طول زمینه` | طول پنجره زمینه بر حسب فریم‌های واقعی. باید برابر 8*n + 1 باشد. (پیش‌فرض: 145) | INT | بله | حداقل: 1<br>حداکثر: nodes.MAX_RESOLUTION<br>گام: 8 |
| `همپوشانی زمینه` | همپوشانی پنجره زمینه بر حسب فریم‌های واقعی. (پیش‌فرض: 40) | INT | بله | حداقل: 0<br>گام: 8 |
| `زمان‌بندی زمینه` | الگوریتم زمان‌بندی وابسته به مرحله برای پنجره‌های زمینه. (پیش‌فرض: UNIFORM_STANDARD) | COMBO | بله | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `گام زمینه` | گام پنجره زمینه؛ فقط برای زمان‌بندی‌های یکنواخت کاربرد دارد. (پیش‌فرض: 1) | INT | بله | حداقل: 1 |
| `حلقه بسته` | اینکه آیا حلقه پنجره زمینه بسته شود؛ فقط برای زمان‌بندی‌های حلقوی کاربرد دارد. (پیش‌فرض: False) | BOOLEAN | بله | True<br>False |
| `روش ادغام` | روش مورد استفاده برای ادغام پنجره‌های زمینه. (پیش‌فرض: PYRAMID) | COMBO | بله | گزینه‌ها از comfy.context_windows.ContextFuseMethods.LIST_STATIC |
| `FreeNoise` | اینکه آیا آشفتگی نویز FreeNoise اعمال شود، ترکیب پنجره را بهبود می‌بخشد. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `حفظ اولین فریم` | حفظ اولین فریم نهفته (latent) در هر پنجره زمینه (ممکن است به حفظ مرجع اولیه کمک کند). (پیش‌فرض: False) | BOOLEAN | بله | True<br>False |
| `تقسیم شرط‌ها به پنجره‌ها` | اینکه آیا چندین conditioning (ایجاد شده توسط ConditionCombine) بر اساس شاخص منطقه به هر پنجره تقسیم شوند. (پیش‌فرض: False) | BOOLEAN | بله | True<br>False |

**توجه:** پارامتر `context_length` باید از فرمول 8*n + 1 پیروی کند، که در آن n یک عدد صحیح مثبت است. گره به‌طور خودکار مقدار را برای برآورده کردن این نیاز با تبدیل فریم‌های واقعی به فریم‌های نهفته تنظیم می‌کند. `context_overlap` نیز از فریم‌های واقعی به فریم‌های نهفته تبدیل می‌شود (تقسیم بر 8).
