# Окна контекста LTXV

Этот узел задаёт контекстные окна для LTXV-подобных моделей во время сэмплирования. Он разделяет генерацию на перекрывающиеся окна, чтобы помочь управлять использованием памяти и улучшить временную согласованность.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, к которой нужно применить контекстные окна во время сэмплирования. | MODEL | Да | - |
| `context_length` | Длина контекстного окна в реальных кадрах. Должна быть 8*n + 1. (по умолчанию: 145) | INT | Да | Минимум: 1<br>Максимум: nodes.MAX_RESOLUTION<br>Шаг: 8 |
| `context_overlap` | Перекрытие контекстного окна в реальных кадрах. (по умолчанию: 40) | INT | Да | Минимум: 0<br>Шаг: 8 |
| `context_schedule` | Алгоритм планирования контекстных окон, зависящий от шага. (по умолчанию: "UNIFORM_STANDARD") | COMBO | Да | `"STATIC_STANDARD"`<br>`"UNIFORM_STANDARD"`<br>`"UNIFORM_LOOPED"`<br>`"BATCHED"` |
| `context_stride` | Шаг контекстного окна; применимо только к равномерным расписаниям. (по умолчанию: 1) | INT | Да | Минимум: 1 |
| `closed_loop` | Замыкать ли цикл контекстного окна; применимо только к зацикленным расписаниям. (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `fuse_method` | Метод, используемый для объединения контекстных окон. Доступные варианты определяются `ContextFuseMethods.LIST_STATIC`. (по умолчанию: "PYRAMID") | COMBO | Да | Определяется `ContextFuseMethods.LIST_STATIC` |
| `freenoise` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `retain_first_frame` | Сохранять первый латентный кадр в каждом контекстном окне (может помочь сохранить исходный референс). (по умолчанию: False) | BOOLEAN | Да | True<br>False |
| `split_conds_to_windows` | Разделять ли несколько кондиционирований (созданных ConditionCombine) по каждому окну на основе индекса региона. (по умолчанию: False) | BOOLEAN | Да | True<br>False |

**Примечание:** Значение `context_length` указывается в реальных кадрах и внутренне преобразуется в латентные кадры по формуле `((context_length - 1) // 8) + 1` с минимумом 1. Значение `context_overlap` также указывается в реальных кадрах и преобразуется в латентные кадры с помощью целочисленного деления на 8 с минимумом 0. Всплывающая подсказка для `context_length` указывает, что оно должно соответствовать шаблону 8*n + 1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Модель с применёнными контекстными окнами для сэмплирования. | MODEL |
