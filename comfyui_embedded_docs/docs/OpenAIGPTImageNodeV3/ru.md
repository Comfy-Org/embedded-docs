# OpenAI GPT Image 2.6

## Обзор

OpenAI GPT Image 2.6 генерирует изображения по промпту и редактирует их, когда вы подключаете эталонные изображения, используя модели OpenAI GPT Image. Узел предлагает четыре модели: `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-image-2.5-flare` и `gpt-image-2.5-sunburst`. Нанесите аннотации на первое эталонное изображение и подключите их как пару разметки, чтобы показать модели, где именно нужно редактировать.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Используемая модель GPT Image. При выборе модели отображаются параметры для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2.6-flare"`<br>`"gpt-image-2.6-sunburst"`<br>`"gpt-image-2.5-flare"`<br>`"gpt-image-2.5-sunburst"` |

### Входы gpt-image-2.6-flare и gpt-image-2.6-sunburst

Эти входы появляются, когда для `model` задано значение `gpt-image-2.6-flare` или `gpt-image-2.6-sunburst`. Обе модели используют одни и те же параметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Что сгенерировать или какое изменение внести. (по умолчанию: `""`) | STRING | Да | N/A |
| `model.size` | Размер изображения. Выберите "Custom", чтобы использовать пользовательские ширину и высоту. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `model.custom_width` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16. (по умолчанию: `1024`) | INT | Нет | от 480 до 3840 (шаг 16) |
| `model.custom_height` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16. (по умолчанию: `1024`) | INT | Нет | от 480 до 3840 (шаг 16) |
| `model.background` | Возвращать изображение с фоном или без него. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | Качество изображения. Более высокие уровни стоят дороже и занимают больше времени. (по умолчанию: `"low"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.complexity` | Насколько тщательно модель планирует изображение перед рендерингом. (по умолчанию: `"high"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | Необязательные эталонные изображения для редактирования. До 16. | AUTOGROW | Нет | от 0 до 16 |
| `model.markup` | Аннотации, нанесённые поверх первого эталонного изображения и показывающие, где нужно редактировать. Должны совпадать по размеру с этим изображением и подключаться вместе с `model.markup_alpha`. | IMAGE | Нет | N/A |
| `model.markup_alpha` | Белый цвет обозначает аннотации в `model.markup`. Выход MASK узла Painter подходит напрямую; для маски из Load Image сначала требуется Invert Mask. | MASK | Нет | N/A |
| `model.seed` | Управляет тем, будет ли узел повторно выполняться; результаты недетерминированы независимо от seed. (по умолчанию: `42`) | INT | Да | от 0 до 2147483647 |

### Входы gpt-image-2.5-flare и gpt-image-2.5-sunburst

Эти входы появляются, когда для `model` задано значение `gpt-image-2.5-flare` или `gpt-image-2.5-sunburst`. Они совпадают с моделями 2.6, за исключением того, что `model.complexity` не предлагается.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Что сгенерировать или какое изменение внести. (по умолчанию: `""`) | STRING | Да | N/A |
| `model.size` | Размер изображения. Выберите "Custom", чтобы использовать пользовательские ширину и высоту. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `model.custom_width` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16. (по умолчанию: `1024`) | INT | Нет | от 480 до 3840 (шаг 16) |
| `model.custom_height` | Используется только когда `model.size` имеет значение "Custom". Должно быть кратно 16. (по умолчанию: `1024`) | INT | Нет | от 480 до 3840 (шаг 16) |
| `model.background` | Возвращать изображение с фоном или без него. (по умолчанию: `"auto"`) | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `model.quality` | Качество изображения. Более высокие уровни стоят дороже и занимают больше времени. (по умолчанию: `"low"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.images` | Необязательные эталонные изображения для редактирования. До 16. | AUTOGROW | Нет | от 0 до 16 |
| `model.markup` | Аннотации, нанесённые поверх первого эталонного изображения и показывающие, где нужно редактировать. Должны совпадать по размеру с этим изображением и подключаться вместе с `model.markup_alpha`. | IMAGE | Нет | N/A |

| `model.seed` | Управляет тем, будет ли узел повторно выполняться; результаты недетерминированы независимо от seed. (по умолчанию: `42`) | INT | Да | от 0 до 2147483647 |

**Ограничения и условия для параметров:**

- Если для `model.size` задано значение "Custom", `model.custom_width` и `model.custom_height` должны быть кратны 16, самая длинная сторона не должна превышать 3840, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно быть в диапазоне от 655 360 до 8 294 400.
- `model.markup` и `model.markup_alpha` должны быть подключены вместе. Для разметки требуется как минимум одно эталонное изображение, а её ширина и высота должны совпадать с первым эталонным изображением.
- Без `model.images` узел генерирует изображения только по промпту; при наличии эталонных изображений он редактирует и объединяет их.
- Эталонные изображения уменьшаются перед отправкой в API.
- `model.complexity` доступен только в `gpt-image-2.6-flare` и `gpt-image-2.6-sunburst`; модели 2.5 используют фиксированную глубину планирования.
