# OpenAI GPT Image 2.6

## مرور کلی

OpenAI GPT Image 2.6 تصاویر را از روی یک پرامپت تولید می‌کند و وقتی تصاویر مرجع را متصل می‌کنید، با استفاده از مدل‌های GPT Image شرکت OpenAI آن‌ها را ویرایش می‌کند. این گره چهار مدل ارائه می‌دهد: `gpt-image-2.6-flare`، `gpt-image-2.6-sunburst`، `gpt-image-2.5-flare` و `gpt-image-2.5-sunburst`. روی اولین تصویر مرجع حاشیه‌نویسی بکشید و آن‌ها را به‌صورت یک جفت نشانه‌گذاری متصل کنید تا به مدل دقیقاً نشان دهید کجا باید ویرایش شود.

### ورودی‌های gpt-image-2.6-flare و gpt-image-2.6-sunburst

این ورودی‌ها زمانی ظاهر می‌شوند که `model` روی `gpt-image-2.6-flare` یا `gpt-image-2.6-sunburst` تنظیم شود. هر دو مدل پارامترهای یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |

| `model.size` | اندازه تصویر. برای استفاده از عرض و ارتفاع سفارشی، "Custom" را انتخاب کنید. (پیش‌فرض: `"auto"`) | COMBO | بله | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `model.custom_width` | فقط زمانی استفاده می‌شود که `model.size` روی "Custom" باشد. باید مضربی از 16 باشد. (پیش‌فرض: `1024`) | INT | خیر | 480 تا 3840 (گام: 16) |

| `model.quality` | کیفیت تصویر. سطوح بالاتر هزینه و زمان بیشتری می‌برند. (پیش‌فرض: `"low"`) | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.complexity` | میزان برنامه‌ریزی مدل برای تصویر پیش از رندر. (پیش‌فرض: `"high"`) | COMBO | بله | `"low"`<br>`"medium"`<br>`"high"` |
| `model.images` | تصاویر مرجع اختیاری برای ویرایش. حداکثر 16. | AUTOGROW | خیر | 0 تا 16 |

| `model.markup_alpha` | رنگ سفید، حاشیه‌نویسی‌ها را در `model.markup` مشخص می‌کند. خروجی MASK گره Painter مستقیماً مناسب است؛ ماسک Load Image ابتدا به Invert Mask نیاز دارد. | MASK | خیر | نامشخص |

**محدودیت‌ها و قیود پارامترها:**

- وقتی `model.size` روی "Custom" تنظیم شود، `model.custom_width` و `model.custom_height` هر دو باید مضربی از 16 باشند، طولانی‌ترین ضلع نباید از 3840 بیشتر شود، نسبت ابعاد نباید از 3:1 بیشتر شود و تعداد کل پیکسل‌ها باید بین 655,360 و 8,294,400 باشد.
- `model.markup` و `model.markup_alpha` باید به‌صورت همراه متصل شوند. نشانه‌گذاری به حداقل یک تصویر مرجع نیاز دارد و عرض و ارتفاع آن باید با اولین تصویر مرجع مطابقت داشته باشد.
- بدون `model.images`، گره تصاویر را تنها بر اساس پرامپت تولید می‌کند؛ با تصاویر مرجع، آن‌ها را ویرایش و ترکیب می‌کند.
- تصاویر مرجع پیش از ارسال به API کوچک‌سازی می‌شوند.
- `model.complexity` فقط در `gpt-image-2.6-flare` و `gpt-image-2.6-sunburst` وجود دارد؛ مدل‌های 2.5 از عمق برنامه‌ریزی ثابت استفاده می‌کنند.
