# WeVisOne-VL Detect

WeVisOne-VL Detect اشیا را در یک تصویر بر اساس یک پرامپت متنی پیدا می‌کند و بسته به وظیفه‌ای که انتخاب می‌کنید، جعبه‌ها، ماسک‌های آلفا، نقاط یا پاسخ خود مدل را برمی‌گرداند. این گره تشخیص و قطعه‌بندی با واژگان باز، عبارات ارجاعی، اشاره‌کردن، شمارش و مکانیابی OCR را پوشش می‌دهد و برای هر تصویر در دسته یک پرامپت اجرا می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | رمزگذار متنی WeVisOne-VL که چک‌پوینت را بارگذاری می‌کند. | CLIP | بله | - |
| `image` | تصویر یا دسته‌ای از تصاویر که باید جست‌وجو شوند. | IMAGE | بله | - |
| `task` | آنچه گره باید برگرداند. `segmentation` جعبه‌ها به‌همراه ماسک‌های آلفا برمی‌گرداند؛ `detection`، `referring`، `ocr` و `ocr_grounding` جعبه‌ها را برمی‌گردانند؛ `point` و `count_point` نقاط را برمی‌گردانند؛ `count_box` با جعبه‌ها می‌شمارد؛ `visual_prompt` اشیای مشابه جعبه‌های مرجع در `bboxes` را پیدا می‌کند؛ `freeform` پرس‌وجو را بدون تغییر می‌فرستد و فقط متن برمی‌گرداند (پیش‌فرض: "segmentation"). | COMBO | بله | `"segmentation"`<br>`"detection"`<br>`"referring"`<br>`"point"`<br>`"count_box"`<br>`"count_point"`<br>`"ocr"`<br>`"ocr_grounding"`<br>`"visual_prompt"`<br>`"freeform"` |
| `query` | آنچه باید پیدا شود، به زبان ساده (مثلاً «لیوان قرمز»). `detection` و `point` در هر خط یک برچسب می‌خوانند، `count_box` و `count_point` موضوعی را که نام می‌برید می‌شمارند، `ocr_grounding` همین متن دقیق را جست‌وجو می‌کند، `visual_prompt` در عوض از `bboxes` استفاده می‌کند، و `freeform` آن را به‌عنوان کل پرامپت می‌فرستد. `ocr` آن را نادیده می‌گیرد. | STRING | بله | - |
| `bboxes` | جعبه‌های مرجع که `visual_prompt` از آن‌ها به‌عنوان نمونه‌هایی از شیء مورد جست‌وجو استفاده می‌کند. | BOUNDING_BOX | خیر | - |
| `individual_masks` | به‌جای یک ماسک آلفای ترکیبی برای هر فریم، برای هر جعبهٔ شناسایی‌شده در خروجی `bboxes` یک ماسک آلفا فریم‌به‌فریم برگردان (پیش‌فرض: false). | BOOLEAN | خیر | true<br>false |
| `max_length` | حداکثر تعداد توکن‌هایی که مدل می‌تواند برای پاسخ خود تولید کند (پیش‌فرض: 4096). | INT | بله | 1 تا 32768 |

**توجه:** ماسک‌های آلفا فقط زمانی پر می‌شوند که مدل با ارجاع‌های شیء پاسخ دهد؛ همان چیزی که وظیفه segmentation می‌خواهد. سایر وظایف جعبه‌ها، نقاط یا متن را با یک ماسک آلفای خالی برمی‌گردانند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `masks` | ماسک‌های آلفای اشیای مطابقت‌یافته، به‌طور پیش‌فرض یکی برای هر فریم یا با `individual_masks` یکی برای هر جعبه. | MASK |
| `bboxes` | جعبه‌های یافته‌شده در هر تصویر، ذخیره‌شده به‌صورت `x`، `y`، `width`، `height` و `label`. | BOUNDING_BOX |
| `points` | نقاط به‌صورت JSON در پیکسل؛ برای هر نقطه یک شیء با `x`، `y`، `label` و `frame`، مثلاً `[{"x": 128, "y": 96, "label": "cup", "frame": 0}]`. توسط وظایف `point` و `count_point` پر می‌شود. | STRING |
| `text` | پاسخ‌های خام مدل که با خط جدید به هم چسبانده شده‌اند؛ خودِ یک پاسخ هم می‌تواند چندخطی باشد. | STRING |
