# WeVisOne-VL Detect

WeVisOne-VL Detect находит объекты на изображении по текстовому запросу и возвращает рамки, альфа-маски, точки или собственный ответ модели в зависимости от выбранной задачи. Он поддерживает обнаружение и сегментацию по открытому словарю, референтные выражения, указание, подсчёт и OCR-локализацию, а также выполняет один запрос на каждое изображение в пакете.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Текстовый кодировщик WeVisOne-VL, который загружает чекпоинт. | CLIP | Да | - |
| `image` | Изображение или пакет изображений для поиска. | IMAGE | Да | - |
| `task` | Что должен вернуть узел. Режим segmentation возвращает рамки и альфа-маски; режимы detection, referring, ocr и ocr_grounding возвращают рамки; режимы point и count_point возвращают точки; режим count_box считает с рамками; режим visual_prompt находит объекты, похожие на эталонные рамки в `bboxes`; режим freeform отправляет запрос без изменений и возвращает только текст (по умолчанию: "segmentation"). | COMBO | Да | `"segmentation"`<br>`"detection"`<br>`"referring"`<br>`"point"`<br>`"count_box"`<br>`"count_point"`<br>`"ocr"`<br>`"ocr_grounding"`<br>`"visual_prompt"`<br>`"freeform"` |
| `query` | Что искать, простыми словами (например, "красная кружка"). `detection` и `point` читают одну метку на строку, `count_box` и `count_point` считают названный вами субъект, `ocr_grounding` ищет именно этот текст, `visual_prompt` вместо этого использует `bboxes`, а `freeform` отправляет его как весь запрос. `ocr` игнорирует его. | STRING | Да | - |
| `bboxes` | Эталонные рамки, которые `visual_prompt` использует как примеры искомого объекта. | BOUNDING_BOX | Нет | - |
| `individual_masks` | Возвращать одну альфа-маску на каждую обнаруженную рамку из выхода `bboxes`, покадрово, вместо одной объединённой маски на кадр (по умолчанию: false). | BOOLEAN | Нет | true<br>false |
| `max_length` | Максимальное количество токенов, которое модель может сгенерировать для своего ответа (по умолчанию: 4096). | INT | Да | от 1 до 32768 |

**Примечание:** Альфа-маски заполняются только когда модель отвечает ссылками на объекты, что и требуется для задачи segmentation. Другие задачи возвращают рамки, точки или текст с пустой альфа-маской.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `masks` | Альфа-маски найденных объектов, по одной на кадр по умолчанию или по одной на рамку при `individual_masks`. | MASK |
| `bboxes` | Рамки, найденные на каждом изображении, сохраняются как `x`, `y`, `width`, `height` и `label`. | BOUNDING_BOX |
| `points` | Точки в формате JSON в пикселях, в виде `[{"x", "y", "label", "frame"}]`, заполняются задачами `point` и `count_point`. | STRING |
| `text` | Необработанный ответ модели, по одной строке на изображение. | STRING |
