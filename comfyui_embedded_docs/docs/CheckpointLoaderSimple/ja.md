# チェックポイントを読み込む

拡散モデルのチェックポイントファイルを読み込み、それを3つの主要コンポーネントに分解します。潜在表現のノイズ除去に使用されるメインモデル、CLIPテキストエンコーダー、そしてVAE画像エンコーダー/デコーダーです。このノードは、`ComfyUI/models/checkpoints` フォルダ内のすべてのモデルファイルと、`extra_model_paths.yaml` ファイルで設定された追加パスを自動的に検出します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ckpt_name` | 読み込むチェックポイント（モデル）の名前です。チェックポイントのモデルファイル名を選択します。これにより、その後の画像生成に使用されるAIモデルが決まります。 | STRING | 必須 | チェックポイントフォルダ内のすべてのモデルファイル |

**注：** ComfyUIの実行中に新しいモデルファイルが追加された場合は、ブラウザを更新（Ctrl+R）すると、ドロップダウンリストに新しいファイルが表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 潜在表現のノイズ除去に使用されるモデルです。画像生成のためのコアとなる拡散モデルです。 | MODEL |
| `CLIP` | テキストプロンプトをエンコードするためのCLIPモデルで、テキスト記述をAIが理解できる情報に変換します。 | CLIP |
| `VAE` | 画像を潜在空間との間でエンコードおよびデコードするためのVAEモデルです。 | VAE |
