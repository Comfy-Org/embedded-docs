# Загрузить сheckpoint

Загружает файл контрольной точки диффузионной модели и разбивает его на три основных компонента: основную модель, используемую для шумоподавления латентных представлений, текстовый энкодер CLIP и энкодер/декодер изображений VAE. Этот узел автоматически обнаруживает все файлы моделей в папке `ComfyUI/models/checkpoints` и любых дополнительных путей, настроенных в вашем файле `extra_model_paths.yaml`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название_точки_проверки` | Имя контрольной точки (модели) для загрузки. Выберите имя файла контрольной точки модели, которое определяет модель ИИ, используемую для последующей генерации изображений. | COMBO | Да | Все файлы моделей в папке checkpoints |

**Примечание:** Если новые файлы моделей добавлены во время работы ComfyUI, необходимо обновить браузер (Ctrl+R), чтобы увидеть новые файлы в раскрывающемся списке.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Модель, используемая для шумоподавления латентных представлений. Это основная диффузионная модель, используемая для генерации изображений. | MODEL |
| `CLIP` | Модель CLIP, используемая для кодирования текстовых запросов, преобразует текстовые описания в информацию, понятную ИИ. | CLIP |
| `VAE` | Модель VAE, используемая для кодирования и декодирования изображений в латентное пространство и обратно. | VAE |
