# Загрузить сheckpoint

Загружает файл чекпоинта диффузионной модели и разделяет его на три основных компонента: основную модель, используемую для шумоподавления латентов, текстовый энкодер CLIP и кодировщик/декодировщик изображений VAE. Узел автоматически обнаруживает все файлы моделей в папке `ComfyUI/models/checkpoints` и любые дополнительные пути, настроенные в вашем файле `extra_model_paths.yaml`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название_точки_проверки` | Имя загружаемого чекпоинта (модели). Выберите имя файла модели чекпоинта, которое определяет ИИ-модель, используемую для последующей генерации изображений. | COMBO | Да | Все файлы моделей, найденные в папке checkpoints |

**Примечание:** Если новые файлы моделей добавляются во время работы ComfyUI, необходимо обновить браузер (Ctrl+R), чтобы увидеть новые файлы в раскрывающемся списке.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Модель, используемая для шумоподавления латентов. Это основная диффузионная модель, используемая для генерации изображений. | MODEL |
| `CLIP` | Модель CLIP, используемая для кодирования текстовых промптов и преобразования текстовых описаний в информацию, понятную ИИ. | CLIP |
| `VAE` | Модель VAE, используемая для кодирования и декодирования изображений в латентное пространство и обратно. | VAE |
