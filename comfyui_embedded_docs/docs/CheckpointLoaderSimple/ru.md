# Загрузить сheckpoint

Загружает файл контрольной точки диффузионной модели и разделяет его на три основных компонента: основную модель, используемую для денойзинга латентных представлений, текстовый энкодер CLIP и VAE-энкодер/декодер изображений. Этот узел автоматически обнаруживает все файлы моделей в папке `ComfyUI/models/checkpoints`, а также любые дополнительные пути, указанные в вашем файле `extra_model_paths.yaml`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ckpt_name` | Имя загружаемой контрольной точки (модели). Выберите имя файла модели, которое определяет ИИ-модель, используемую для последующей генерации изображений. | STRING | Да | Все файлы моделей в папке checkpoints |

**Примечание:** Если новые файлы моделей добавляются во время работы ComfyUI, необходимо обновить страницу браузера (Ctrl+R), чтобы увидеть новые файлы в выпадающем списке.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL` | Модель, используемая для денойзинга латентных представлений. Это основная диффузионная модель для генерации изображений. | MODEL |
| `CLIP` | Модель CLIP, используемая для кодирования текстовых запросов, преобразования текстовых описаний в информацию, понятную ИИ. | CLIP |
| `VAE` | Модель VAE, используемая для кодирования и декодирования изображений в латентное пространство и обратно. | VAE |
