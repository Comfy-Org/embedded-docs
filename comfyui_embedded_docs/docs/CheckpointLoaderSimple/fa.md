# بارگذاری چک‌پوینت

یک فایل checkpoint مدل دیفیوژن را بارگذاری میکند و آن را به سه مؤلفهٔ اصلی تجزیه میکند: مدل اصلی برای نویززدایی لاتنت‌ها، رمزگذار متن CLIP، و رمزگذار/رمزگشای تصویر VAE. این گره به‌طور خودکار همهٔ فایل‌های مدل را در پوشهٔ `ComfyUI/models/checkpoints` و هر مسیر اضافی که در فایل `extra_model_paths.yaml` شما پیکربندی شده است، شناسایی می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `ckpt_name` | نام checkpoint (مدل) که باید بارگذاری شود. نام فایل مدل checkpoint را انتخاب کنید، که تعیین می‌کند از کدام مدل هوش مصنوعی برای تولید تصویر بعدی استفاده شود. | STRING | بله | همه فایل‌های مدل در پوشه checkpoints |

**نکته:** اگر در حین اجرای ComfyUI فایل‌های مدل جدیدی اضافه شوند، باید مرورگر را تازه‌سازی کنید (Ctrl+R) تا فایل‌های جدید در فهرست کشویی دیده شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `MODEL` | مدلی که برای نویززدایی لاتنت‌ها استفاده می‌شود. این مدل دیفیوژن اصلی برای تولید تصویر است. | MODEL |
| `CLIP` | مدل CLIP که برای رمزگذاری متن پرامپت‌ها استفاده می‌شود و توصیف‌های متنی را به اطلاعات قابل‌درک برای هوش مصنوعی تبدیل می‌کند. | CLIP |
| `VAE` | مدل VAE که برای رمزگذاری و رمزگشایی تصاویر به/از فضای لاتنت استفاده می‌شود. | VAE |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/CheckpointLoaderSimple/fa.md)
