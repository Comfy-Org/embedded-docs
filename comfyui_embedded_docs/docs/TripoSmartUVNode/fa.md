# Tripo: Smart UV

Tripo: Smart UV UVهای یک مدل را دوباره باز می‌کند و بافت‌ها، ریگ و انیمیشن آن را روی چیدمان جدید بازنقشه‌گذاری می‌کند. از آن زمانی استفاده کنید که چیدمان UV اصلی مدل غیرقابل استفاده است؛ مثلاً پس از بازتوپولوژی یا زمانی که درزهای بافت باید دوباره انجام شوند. مدل ورودی نباید از 80,000 مثلث بیشتر باشد (هر چهارضلعی دو مثلث حساب می‌شود)، بنابراین مدل‌های بزرگ‌تر را ابتدا با Tripo: Retopology یا یک `face_limit` کاهش دهید.

> **توجه:** Tripo سوابق وظیفه را به مدت ۷ روز روی سرورهای خود نگه می‌دارد (مؤثر از ۱ دسامبر ۲۰۲۶). شناسه وظیفه‌ای که قدیمی‌تر از این مدت باشد دیگر قابل بازیابی نیست؛ بنابراین اجرای مجدد یک گردش‌کار ذخیره‌شده پس از پایان این بازه در این گره شکست می‌خورد. گره Tripo قبلی را دوباره اجرا کنید تا شناسه وظیفه تازه‌ای ایجاد شود، یا مدل دانلودشده را با **Tripo: Import Model** دوباره وارد کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدلی که باید دوباره باز شود. یک شناسه وظیفه مدل از یک گره تولید Tripo، یا یک شناسه وظیفه ریگ، بازهدف‌گذاری (retarget) یا قطعه‌بندی (segment) را می‌پذیرد. | MODEL_TASK_ID | بله | شناسه وظیفه Tripo |
| `bake` | بافت‌های موجود را روی چیدمان UV جدید بیک کنید. حالت خاموش، بیک را نادیده می‌گیرد و مدل را بدون بافت‌های رنگی آن برمی‌گرداند (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model task_id` | شناسه وظیفه مربوط به وظیفه UV تکمیل‌شده. می‌توان آن را به سایر گره‌های Tripo، برای مثال Tripo: Texture، ارسال کرد. | MODEL_TASK_ID |
| `GLB` | مدل با UV بازشده مجدد در قالب GLB. زمانی که مدل مبدأ FBX باشد خالی است. | FILE_3D_GLB |
| `FBX` | مدل با UV بازشده مجدد در قالب FBX. فقط زمانی پر می‌شود که مدل مبدأ FBX باشد، برای مثال یک مش چهارضلعی. | FILE_3D_FBX |
| `UV atlas` | چیدمان UV رندرشده مدل به‌صورت یک تصویر. | IMAGE |
