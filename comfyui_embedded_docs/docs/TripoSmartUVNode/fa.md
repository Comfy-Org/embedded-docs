# Tripo: Smart UV

Tripo: Smart UV چیدمان UVهای یک مدل را دوباره بازمی‌کند و بافت‌ها، ریگ و انیمیشن آن را روی چیدمان جدید بازنقشه‌گذاری می‌کند. از آن زمانی استفاده کنید که چیدمان UV اصلی مدل قابل استفاده نباشد، مثلاً پس از بازتوپولوژی یا زمانی که لازم است درزهای بافت دوباره انجام شوند. مدل ورودی نباید بیش از 80,000 مثلث باشد (هر چهارضلعی به‌عنوان دو مثلث حساب می‌شود)، بنابراین مدل‌های بزرگ‌تر را ابتدا با Tripo: Retopology یا یک `face_limit` کاهش دهید.

> **توجه:** Tripo سوابق تسک را روی سرورهای خود به مدت 7 روز نگه می‌دارد (از 1 دسامبر 2026 لازم‌الاجرا). شناسه تسکی که قدیمی‌تر از این مدت باشد دیگر قابل بازیابی نیست، بنابراین اجرای مجدد یک گردش‌کار ذخیره‌شده پس از این بازه در این گره شکست می‌خورد. گره Tripo قبلی را دوباره اجرا کنید تا شناسه تسک تازه‌ای ایجاد شود، یا مدل دانلودشده را با **Tripo: Import Model** دوباره وارد کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه تسک مدلی که باید UV آن دوباره باز شود. شناسه تسک مدل از یک گره تولید Tripo، یا شناسه تسک ریگ، retarget یا segment را می‌پذیرد. | MODEL_TASK_ID | بله | شناسه تسک Tripo |
| `bake` | بافت‌های موجود را روی چیدمان UV جدید بیک کند. حالت خاموش بیک را رد می‌کند و مدل را بدون بافت‌های رنگی آن برمی‌گرداند (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model task_id` | شناسه تسک مربوط به تسک UV تکمیل‌شده. می‌توان آن را به سایر گره‌های Tripo، برای مثال Tripo: Texture، داد. | MODEL_TASK_ID |
| `GLB` | مدل دوباره UV‌بازشده در قالب GLB. وقتی مدل منبع FBX باشد، خالی است. | GLB FILE |
| `FBX` | مدل دوباره UV‌بازشده در قالب FBX. فقط زمانی پر می‌شود که مدل منبع FBX باشد، برای مثال یک مش چهارضلعی. | FBX FILE |
| `UV atlas` | چیدمان UV رندرشده مدل به‌صورت یک تصویر. | IMAGE |
