# Tripo: Smart UV

Tripo: Smart UV يعيد فك التفاف UV للنموذج ويعيد تعيين قوامه وتسليحه ورسومه المتحركة على التخطيط الجديد. استخدمه عندما يكون تخطيط UV الأصلي للنموذج غير قابل للاستخدام، على سبيل المثال بعد إعادة الطوبولوجيا أو عندما يلزم إعادة إنشاء حدود القوام. يجب ألا يتجاوز النموذج المدخل 80,000 مثلث (يُحسب الشكل الرباعي كمثلثين)، لذا قلّل النماذج الأكبر باستخدام Tripo: Retopology أو `face_limit` أولًا.

> **ملاحظة:** يحتفظ Tripo بسجلات المهام على خوادمه لمدة 7 أيام (اعتبارًا من 1 ديسمبر 2026). لا يمكن حل معرّف مهمة أقدم من ذلك، لذا فإن إعادة تشغيل سير عمل محفوظ بعد هذه المدة تفشل عند هذه العقدة. شغّل عقدة Tripo السابقة مرة أخرى لإنشاء معرّف مهمة جديد، أو أعد استيراد النموذج الذي تم تنزيله باستخدام **Tripo: Import Model**.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة النموذج المراد إعادة فك التفاف UV الخاص به. يقبل معرّف مهمة نموذج من عقدة توليد Tripo، أو معرّف مهمة تسليح أو إعادة استهداف أو تقسيم. | MODEL_TASK_ID | نعم | معرّف مهمة Tripo |
| `bake` | اخبز القوام الموجود على تخطيط UV الجديد. عند الإيقاف، يتم تخطي الخبز وإرجاع النموذج دون قوام الألوان (الافتراضي: True). | BOOLEAN | نعم | `True`<br>`False` |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model task_id` | معرّف مهمة UV المكتملة. يمكن تمريره إلى عقد Tripo أخرى، مثل Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | النموذج بعد إعادة فك التفاف UV بصيغة GLB. فارغ عندما يكون النموذج المصدر من نوع FBX. | FILE_3D_GLB |
| `FBX` | النموذج بعد إعادة فك التفاف UV بصيغة FBX. يُملأ فقط عندما يكون النموذج المصدر من نوع FBX، مثل شبكة رباعية. | FILE_3D_FBX |
| `UV atlas` | تخطيط UV المُصيَّر للنموذج على شكل صورة. | IMAGE |
