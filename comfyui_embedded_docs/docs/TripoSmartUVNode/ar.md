# Tripo: Smart UV

تقوم عقدة Tripo: Smart UV بإعادة فك UVs النموذج وإعادة تعيين خرائطه النسيجية وهيكله العظمي ورسومه المتحركة على التخطيط الجديد. استخدمها عندما يكون تخطيط UV الأصلي للنموذج غير قابل للاستخدام، مثلًا بعد إعادة التوبولوجيا أو عندما يلزم إعادة إنشاء فواصل النسيج. يجب ألا يتجاوز النموذج المُدخل 80,000 مثلث (تُحتسب الوجهة الرباعية مثلثين)، لذلك قلّل النماذج الأكبر باستخدام Tripo: Retopology أو `face_limit` أولًا.

> **ملاحظة:** يحتفظ Tripo بسجلات المهام على خوادمه لمدة 7 أيام (اعتبارًا من 1 ديسمبر 2026). لا يمكن استرجاع معرّف مهمة أقدم من ذلك، لذا فإن إعادة تشغيل سير عمل محفوظ بعد انتهاء تلك المدة تفشل عند هذه العقدة. شغّل عقدة Tripo السابقة مرة أخرى لإنشاء معرّف مهمة جديد، أو أعد استيراد النموذج الذي تم تنزيله باستخدام **Tripo: Import Model**.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف المهمة الخاص بالنموذج المراد إعادة فك UVs له. يقبل معرّف مهمة نموذج من عقدة توليد Tripo، أو معرّف مهمة هيكل عظمي أو إعادة استهداف أو تقسيم. | MODEL_TASK_ID | نعم | معرّف مهمة Tripo |
| `bake` | إجراء خَبز للخرائط النسيجية الموجودة على تخطيط UV الجديد. عند الإيقاف يتم تخطي الخَبز وإرجاع النموذج دون خرائطه النسيجية الملوّنة (افتراضي: True). | BOOLEAN | نعم | `True`<br>`False` |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model task_id` | معرّف المهمة لمهمة UV المكتملة. يمكن تمريره إلى عقد Tripo أخرى، مثل Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | النموذج بعد إعادة فك UVs بصيغة GLB. يكون فارغًا عندما يكون النموذج المصدر بصيغة FBX. | GLB FILE |
| `FBX` | النموذج بعد إعادة فك UVs بصيغة FBX. يُملأ فقط عندما يكون النموذج المصدر بصيغة FBX، مثل شبكة رباعية. | FBX FILE |
| `UV atlas` | تخطيط UV المُصيّر للنموذج كصورة. | IMAGE |
