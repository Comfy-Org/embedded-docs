# Tripo: Smart UV

تقوم عقدة Tripo: Smart UV بإعادة فك UVs لطراز ما وإعادة تعيين خرائطه النسيجية وهيكله ورسومه المتحركة على التخطيط الجديد. استخدمها عندما يكون تخطيط UV الأصلي للطراز غير قابل للاستخدام، على سبيل المثال بعد إعادة الطوبولوجيا أو عندما يلزم إعادة إنشاء حواف النسيج. يجب ألا يتجاوز الطراز المدخل 80,000 مثلث (تُحتسب الرباعية كمثلثين)، لذا قلّل الطرازات الأكبر أولًا باستخدام Tripo: Retopology أو `face_limit`.

> **ملاحظة:** يحتفظ Tripo بسجلات المهام على خوادمه لمدة 7 أيام (يسري اعتبارًا من 1 ديسمبر 2026). لم يعد من الممكن حل معرّف مهمة أقدم من ذلك، لذا فإن إعادة تشغيل سير عمل محفوظ بعد انتهاء هذه المدة تفشل عند هذه العقدة. أعد تشغيل عُقد Tripo الأولية التي أنتجت المهمة، أو أعد استيراد طراز تم تنزيله باستخدام **Tripo: Import Model**. نزّل الطراز قبل إغلاق النافذة: لا يمكن استرداد أصل منتهي الصلاحية من سجل المهمة.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة الطراز المراد إعادة فك UVs له. يقبل معرّف مهمة طراز من عقدة توليد Tripo، أو معرّف مهمة ريغ أو إعادة استهداف أو تقسيم. | MODEL_TASK_ID | نعم | معرّف مهمة Tripo |
| `bake` | خبز الخرائط النسيجية الموجودة على تخطيط UV الجديد. عند الإيقاف، يتم تخطي الخبز وإرجاع الطراز دون خرائطه النسيجية الملونة (افتراضي: True). | BOOLEAN | نعم | `True`<br>`False` |

## المخرجات

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model task_id` | معرّف مهمة UV المكتملة. يمكن تمريره إلى عُقد Tripo الأخرى، على سبيل المثال Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | الطراز بعد إعادة فك UVs بصيغة GLB. فارغ عندما يكون الطراز المصدر FBX. | FILE_3D_GLB |
| `FBX` | الطراز بعد إعادة فك UVs بصيغة FBX. يُملأ فقط عندما يكون الطراز المصدر FBX، على سبيل المثال شبكة رباعية. | FILE_3D_FBX |
| `UV atlas` | تخطيط UV المعروض للطراز كصورة. | IMAGE |
