# Tripo: Smart UV

Tripo: Smart UV заново разворачивает UV-развёртку модели и переназначает её текстуры, риг и анимацию на новую раскладку. Используйте его, когда исходная UV-развёртка модели непригодна, например после ретопологии или когда швы текстуры нужно переделать. Входная модель не должна превышать 80 000 треугольников (квад считается за два), поэтому сначала уменьшите большие модели с помощью Tripo: Retopology или `face_limit`.

> **Примечание.** Tripo хранит записи задач на своих серверах в течение 7 дней (действует с 1 декабря 2026 года). ID задачи старше этого срока больше не может быть обработан, поэтому повторный запуск сохранённого workflow после этого окна завершится ошибкой на этом узле. Снова запустите предыдущий узел Tripo, чтобы создать новый ID задачи, или повторно импортируйте скачанную модель с помощью **Tripo: Import Model**.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи модели для повторной развёртки. Принимает ID задачи модели из узла генерации Tripo, а также ID задачи рига, ретаргета или сегментации. | MODEL_TASK_ID | Да | ID задачи Tripo |
| `bake` | Запекать существующие текстуры на новую UV-развёртку. Если выключено, запекание пропускается и возвращается модель без цветовых текстур (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи завершённой UV-задачи. Может передаваться в другие узлы Tripo, например Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | Модель с повторно выполненной развёрткой в формате GLB. Пусто, когда исходная модель имеет формат FBX. | GLB FILE |
| `FBX` | Модель с повторно выполненной развёрткой в формате FBX. Заполняется только когда исходная модель имеет формат FBX, например четырёхугольная сетка. | FBX FILE |
| `UV atlas` | Отрисованная UV-развёртка модели в виде изображения. | IMAGE |
