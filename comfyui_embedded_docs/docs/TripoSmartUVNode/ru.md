# Tripo: Smart UV

Tripo: Smart UV заново разворачивает UV-развёртку модели и переназначает её текстуры, риг и анимацию на новую развёртку. Используйте этот узел, когда исходная UV-развёртка модели непригодна, например после ретопологии или когда требуется переделать швы текстуры. Входная модель не должна превышать 80 000 треугольников (квад считается за два), поэтому сначала уменьшите более крупные модели с помощью Tripo: Retopology или параметра `face_limit`.

> **Примечание:** Tripo хранит записи о задачах на своих серверах в течение 7 дней (действует с 1 декабря 2026 г.). ID задачи, созданный раньше этого срока, больше не может быть обработан, поэтому повторный запуск сохранённого workflow после истечения этого окна завершится ошибкой на этом узле. Повторно запустите вышестоящие узлы Tripo, создавшие задачу, или повторно импортируйте загруженную модель с помощью **Tripo: Import Model**. Скачайте модель до истечения этого срока: просроченный ресурс невозможно восстановить из записи задачи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи модели для повторной развёртки. Принимает ID задачи модели из узла генерации Tripo, а также ID задачи рига, ретаргетинга или сегментации. | MODEL_TASK_ID | Да | ID задачи Tripo |
| `bake` | Запечь существующие текстуры на новую UV-развёртку. Если выключено, запекание пропускается и возвращается модель без цветовых текстур (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи завершённой UV-задачи. Может передаваться другим узлам Tripo, например Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | Модель с повторной развёрткой в формате GLB. Пусто, если исходная модель в формате FBX. | FILE_3D_GLB |
| `FBX` | Модель с повторной развёрткой в формате FBX. Заполняется только когда исходная модель в формате FBX, например сетка из квадов. | FILE_3D_FBX |
| `UV atlas` | Отрисованная UV-развёртка модели в виде изображения. | IMAGE |
