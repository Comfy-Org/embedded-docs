# Tripo: Smart UV

Tripo: Smart UV повторно разворачивает UV-развёртку модели и переносит её текстуры, риг и анимацию на новую раскладку. Используйте этот узел, когда исходная UV-развёртка модели непригодна, например после ретопологии или когда швы текстуры нужно переделать. Входная модель не должна превышать 80 000 треугольников (квад считается за два), поэтому сначала уменьшите крупные модели с помощью Tripo: Retopology или `face_limit`.

> **Примечание:** Tripo хранит записи задач на своих серверах в течение 7 дней (с 1 декабря 2026 года). ID задачи старше этого срока больше не может быть обработан, поэтому повторный запуск сохранённого рабочего процесса после этого окна завершится ошибкой на этом узле. Запустите предыдущий узел Tripo снова, чтобы создать новый ID задачи, или повторно импортируйте скачанную модель с помощью **Tripo: Import Model**.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи модели для повторного разворачивания UV. Принимает ID задачи модели из узла генерации Tripo, а также ID задачи рига, ретаргета или сегментации. | MODEL_TASK_ID | Да | ID задачи Tripo |
| `bake` | Запекает существующие текстуры на новую UV-развёртку. Если выключено, запекание пропускается и возвращается модель без цветовых текстур (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи готовой UV-задачи. Можно передать другим узлам Tripo, например Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | Модель после повторного разворачивания UV в формате GLB. Пусто, если исходная модель в формате FBX. | FILE_3D_GLB |
| `FBX` | Модель после повторного разворачивания UV в формате FBX. Заполняется только если исходная модель в формате FBX, например квад-сетка. | FILE_3D_FBX |
| `UV atlas` | Отрисованная UV-развёртка модели в виде изображения. | IMAGE |
