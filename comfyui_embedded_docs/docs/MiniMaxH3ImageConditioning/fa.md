# MiniMax H3 Image Conditioning

تبدیل پرامپت به شرطی‌سازی و یک latent خالی برای تصویر ثابت با MiniMax H3 Image. بدون تصاویر، متن‌به‌تصویر است؛ با اتصال تصاویر، آن‌ها را ویرایش می‌کند و پرامپت با `<Picture 1>`، `<Picture 2>` و به همین ترتیب به آن‌ها اشاره می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `clip` | مدل CLIP مربوط به MiniMax H3 Image که پرامپت را همراه با هر تصویر مرجع توکن‌بندی می‌کند و شرطی‌سازی را کدگذاری می‌کند. | CLIP | بله | - |
| `vae` | VAE مربوط به MiniMax H3 Image. با آن، تصاویر به‌عنوان latentهای مرجع نیز تثبیت می‌شوند؛ بدون آن، فقط رمزگذار متن را شرطی می‌کنند. | VAE | خیر | - |
| `prompt` | آنچه باید تولید شود، یا نحوه ویرایش تصاویر مرجع. | STRING | بله | متن چندخطی |
| `width` | عرض خروجی بر حسب پیکسل. مقدار 0 از عرض `image_1` پس از مقیاس‌بندی مرجع آن استفاده می‌کند، یا در صورت نبود تصاویر از 2048. پیش‌فرض: 0. | INT | بله | 0 تا MAX_RESOLUTION (گام: 32) |
| `height` | ارتفاع خروجی بر حسب پیکسل. مقدار 0 از ارتفاع `image_1` پس از مقیاس‌بندی مرجع آن استفاده می‌کند، یا در صورت نبود تصاویر از 2048. پیش‌فرض: 0. | INT | بله | 0 تا MAX_RESOLUTION (گام: 32) |
| `images` | گروه قابل‌افزایش از تصاویر مرجع، از `image_1` به بالا؛ `image_1` تصویری است که باید ویرایش شود. پرامپت با `<Picture n>` به آن‌ها اشاره می‌کند. | AUTOGROW | خیر | 0 تا 100 تصویر |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | شرطی‌سازی برای نمونه‌بردار MiniMax H3 Image، با latentهای مرجع پیوست‌شده در صورت اتصال تصاویر. | CONDITIONING |
| `latent` | latent خالی برای یک تصویر، 24 کانال با یک‌شانزدهم اندازه خروجی. | LATENT |

توجه: مدل برای مساحت 2048×2048 پیکسل تنظیم شده است، بنابراین `width` و `height` را روی 0 بگذارید مگر اینکه بوم متفاوتی لازم باشد.
