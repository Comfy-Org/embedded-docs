# MiniMax H3 Image Conditioning

يحوّل التوجيه النصي إلى تكييف (conditioning) وكامن فارغ (empty latent) لصورة ثابتة باستخدام MiniMax H3 Image. من دون صور يكون النمط نصًا إلى صورة؛ ومع توصيل الصور يقوم بتحريرها، ويشير التوجيه النصي إليها بصيغة `<Picture 1>` و`<Picture 2>` وهكذا.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | نموذج CLIP الخاص بـ MiniMax H3 Image، الذي يجزّئ التوجيه النصي مع أي صور مرجعية ويشفّر التكييف. | CLIP | نعم | - |
| `vae` | نموذج VAE الخاص بـ MiniMax H3 Image. عند استخدامه، تُثبّت الصور أيضًا ككامنات مرجعية؛ وبدونه فإنها تؤثر فقط في مشفّر النصوص. | VAE | لا | - |
| `prompt` | ما الذي تريد توليده، أو كيفية تحرير الصور المرجعية. | STRING | نعم | نص متعدد الأسطر |
| `width` | عرض المخرجات بالبكسل. تعني القيمة 0 استخدام عرض `image_1` بعد تحجيمه المرجعي، أو 2048 عند عدم وجود صور. الافتراضي: 0. | INT | نعم | 0 إلى MAX_RESOLUTION (خطوة: 32) |
| `height` | ارتفاع المخرجات بالبكسل. تعني القيمة 0 استخدام ارتفاع `image_1` بعد تحجيمه المرجعي، أو 2048 عند عدم وجود صور. الافتراضي: 0. | INT | نعم | 0 إلى MAX_RESOLUTION (خطوة: 32) |
| `images` | مجموعة قابلة للتوسيع من الصور المرجعية، بدءًا من `image_1` فما فوق؛ و`image_1` هي الصورة المطلوب تحريرها. يشير التوجيه النصي إليها بصيغة `<Picture n>`. | AUTOGROW | لا | 0 إلى 100 صور |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | التكييف الخاص بمنقّح MiniMax H3 Image، مع إرفاق الكامنات المرجعية عند توصيل الصور. | CONDITIONING |
| `latent` | كامن فارغ لصورة واحدة، بـ 24 قناة وبمقاس يساوي 1/16 من أبعاد المخرجات. | LATENT |

ملاحظة: النموذج مضبوط لمساحة مقدارها 2048x2048 بكسل، لذا اترك `width` و`height` عند القيمة 0 ما لم تكن هناك حاجة إلى لوحة رسم مختلفة.
