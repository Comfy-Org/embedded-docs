# MiniMax H3 Image Conditioning

Преобразует промпт в кондиционирование и пустой латент для статического изображения с помощью MiniMax H3 Image. Без изображений выполняется преобразование текста в изображение; при подключённых изображениях узел редактирует их, а промпт ссылается на них как на `<Picture 1>`, `<Picture 2>` и т. д.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | CLIP-модель MiniMax H3 Image, которая токенизирует промпт вместе с любыми эталонными изображениями и кодирует кондиционирование. | CLIP | Да | - |
| `vae` | VAE для MiniMax H3 Image. При наличии VAE изображения также закрепляются как эталонные латенты; без VAE они только влияют на текстовый энкодер. | VAE | Нет | - |
| `prompt` | Что сгенерировать или как редактировать эталонные изображения. | STRING | Да | Многострочный текст |
| `width` | Ширина выходного изображения в пикселях. Значение 0 использует ширину `image_1` после её масштабирования как эталона или 2048 при отсутствии изображений. По умолчанию: 0. | INT | Да | от 0 до MAX_RESOLUTION (шаг: 32) |
| `height` | Высота выходного изображения в пикселях. Значение 0 использует высоту `image_1` после её масштабирования как эталона или 2048 при отсутствии изображений. По умолчанию: 0. | INT | Да | от 0 до MAX_RESOLUTION (шаг: 32) |
| `images` | Расширяемая группа эталонных изображений, начиная с `image_1`; `image_1` — изображение для редактирования. В промпте к ним обращаются как к `<Picture n>`. | AUTOGROW | Нет | от 0 до 100 изображений |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Кондиционирование для сэмплера MiniMax H3 Image, с прикреплёнными эталонными латентами, когда изображения подключены. | CONDITIONING |
| `latent` | Пустой латент для одного изображения: 24 канала при размере в одну шестнадцатую от выходного. | LATENT |

Примечание: модель настроена на площадь 2048x2048 пикселей, поэтому оставляйте `width` и `height` равными 0, если не требуется другой холст.
