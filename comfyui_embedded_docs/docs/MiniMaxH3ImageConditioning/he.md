# MiniMax H3 Image Conditioning

הופך פרומפט ל-conditioning ול-latent ריק עבור תמונה נייחת עם MiniMax H3 Image. ללא תמונות זה טקסט לתמונה; כאשר תמונות מחוברות זה עורך אותן, והפרומפט מתייחס אליהן כ-`<Picture 1>`, `<Picture 2>` וכן הלאה.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מודל ה-CLIP של MiniMax H3 Image, אשר מבצע טוקניזציה לפרומפט יחד עם תמונות עזר ומקודד את הקונדישינינג. | CLIP | כן | - |
| `vae` | ה-VAE של MiniMax H3 Image. איתו התמונות גם מעוגנות כ-latents עזר; בלעדיו הן רק משמשות כקונדישינינג למקודד הטקסט. | VAE | לא | - |
| `prompt` | מה לייצר, או כיצד לערוך את תמונות העזר. | STRING | כן | טקסט רב-שורתי |
| `width` | רוחב הפלט בפיקסלים. 0 משתמש ברוחב של `image_1` לאחר התאמת הגודל היחסית שלו, או 2048 ללא תמונות. ברירת מחדל: 0. | INT | כן | 0 עד MAX_RESOLUTION (צעד 32) |
| `height` | גובה הפלט בפיקסלים. 0 משתמש בגובה של `image_1` לאחר התאמת הגודל היחסית שלו, או 2048 ללא תמונות. ברירת מחדל: 0. | INT | כן | 0 עד MAX_RESOLUTION (צעד 32) |
| `images` | קבוצה ניתנת להרחבה של תמונות עזר, מ-`image_1` ומעלה; `image_1` היא התמונה לעריכה. הפרומפט מתייחס אליהן כ-`<Picture n>`. | AUTOGROW | לא | 0 עד 100 תמונות |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | קונדישינינג עבור הסמפלר של MiniMax H3 Image, עם latents העזר שמצורפים כאשר תמונות מחוברות. | CONDITIONING |
| `latent` | latent ריק עבור תמונה אחת, 24 ערוצים בגודל של 1/16 מגודל הפלט. | LATENT |

הערה: המודל מכוונן לשטח של 2048x2048 פיקסלים, לכן השאר את `width` ואת `height` כ-0 אלא אם כן נדרש קנבס אחר.
