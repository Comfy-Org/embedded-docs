# ConditioningSetDefaultAndCombine

צומת זה משלב קלט קונדישנינג ראשי עם קלט קונדישנינג ברירת מחדל באמצעות מערכת מבוססת hooks. הוא ממזג את שני מקורות הקונדישנינג לפלט יחיד, ומאפשר לקונדישנינג ברירת המחדל לשמש כגיבוי או כבסיס כאשר הקונדישנינג הראשי אינו שלם.

## קלטים

| פרמטר | תיאור | סוג נתונים | סוג קלט | ברירת מחדל | טווח |
| --- | --- | --- | --- | --- | --- |
| `cond` | קלט הקונדישנינג הראשי שיש לעבד ולשלב | CONDITIONING | חובה | - | - |
| `cond_DEFAULT` | נתוני קונדישנינג ברירת המחדל שיש לשלב עם הקונדישנינג הראשי | CONDITIONING | חובה | - | - |
| `hooks` | תצורת hooks אופציונלית שקובעת כיצד נתוני הקונדישנינג מעובדים ומשולבים | HOOKS | אופציונלי | - | - |
