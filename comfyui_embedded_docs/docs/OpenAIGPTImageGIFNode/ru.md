# OpenAI GPT Image 2.6 GIF

## Обзор

OpenAI GPT Image 2.6 GIF создаёт анимированный GIF по промпту с помощью моделей GPT Image от OpenAI и возвращает его в виде пакета кадров вместе с частотой кадров, поэтому результат можно сразу передать в узел сохранения видео или анимированных изображений. Доступны две модели: `gpt-image-2.6-flare` и `gpt-image-2.6-sunburst`.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель GPT Image, используемая для анимации. | DYNAMIC_COMBO | Да | `"gpt-image-2.6-flare"`<br>`"gpt-image-2.6-sunburst"` |

### Входы gpt-image-2.6-flare и gpt-image-2.6-sunburst

Обе модели используют одинаковые параметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Что анимировать. (по умолчанию: `""`) | STRING | Да | N/A |
| `model.size` | Размер каждого кадра. Большие размеры подходят только для меньшего количества кадров. (по умолчанию: `"512x512"`) | COMBO | Да | `"384x384"`<br>`"512x512"`<br>`"640x640"`<br>`"720x720"`<br>`"768x768"`<br>`"960x960"`<br>`"512x288"`<br>`"288x512"`<br>`"1024x576"`<br>`"576x1024"`<br>`"1280x720"`<br>`"720x1280"` |
| `model.frame_count` | Количество кадров. Кадры тарифицируются по диапазонам: от 2 до 8, 9, от 10 до 12, от 13 до 16. (по умолчанию: `9`) | INT | Да | от 2 до 16 |
| `model.frame_duration_ms` | Как долго отображается каждый кадр, в миллисекундах. (по умолчанию: `200`) | INT | Да | от 20 до 2000 (шаг 10) |
| `model.background` | Фон кадра. Прозрачность сохраняется узлами Save WEBM with vp9, Save Animated WEBP и Save Animated PNG. (по умолчанию: `"opaque"`) | COMBO | Да | `"opaque"`<br>`"transparent"` |
| `model.quality` | Качество изображения. Более высокие уровни стоят дороже и требуют больше времени. (по умолчанию: `"low"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.complexity` | Насколько детально модель планирует анимацию перед рендерингом. (по умолчанию: `"high"`) | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"` |
| `model.seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от seed. (по умолчанию: `42`) | INT | Да | от 0 до 2147483647 |

**Ограничения параметров:**

- Частота кадров рассчитывается на основе `model.frame_duration_ms`: 200 мс соответствуют 5 fps.
- Большой `model.size` в сочетании с большим `model.frame_count` недоступен; на ценовом бейдже отображается сообщение «Размер слишком велик для этого количества кадров».

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `frames` | Анимация в виде пакета кадров, готовая для узла сохранения видео или анимированных изображений. | IMAGE |
| `fps` | Кадров в секунду; считывается из длительности кадра возвращённого GIF. | FLOAT |
