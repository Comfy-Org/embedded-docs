# שילוב מסכות

צומת זה מתמחה בשילוב של שני קלטי מסכות באמצעות מגוון פעולות כגון חיבור, חיסור ופעולות לוגיות, כדי ליצור מסכה חדשה שעברה שינוי. הוא מטפל באופן מופשט במניפולציה של נתוני מסכות כדי להשיג אפקטי מיסוך מורכבים, ומשמש כרכיב חיוני בתהליכי עריכת תמונות ועיבוד מבוססי מסכות.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `destination` | המסכה הראשית שתעודכן בהתבסס על הפעולה עם מסכת המקור. היא ממלאת תפקיד מרכזי בפעולת המיזוג, ומשמשת כבסיס לשינויים. | MASK |
| `source` | המסכה המשנית שתשמש יחד עם מסכת היעד לביצוע הפעולה שצוינה, ומשפיעה על מסכת הפלט הסופית. | MASK |
| `x` | ההיסט האופקי שבו מסכת המקור תוחל על מסכת היעד, ומשפיע על מיקום תוצאת המיזוג. | INT |
| `y` | ההיסט האנכי שבו מסכת המקור תוחל על מסכת היעד, ומשפיע על מיקום תוצאת המיזוג. | INT |
| `operation` | מציין את סוג הפעולה שיש להחיל בין מסכת היעד למסכת המקור, כגון 'add', 'subtract' או פעולות לוגיות, וקובע את אופי אפקט המיזוג. | COMBO[STRING] |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `mask` | המסכה המתקבלת לאחר החלת הפעולה שצוינה בין מסכת היעד למסכת המקור, ומייצגת את תוצאת המיזוג. | MASK |
