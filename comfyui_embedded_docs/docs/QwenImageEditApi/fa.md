# ویرایش تصویر Qwen ۳

این گره از مدل‌های Qwen-Image 3.0 برای ویرایش یا ترکیب حداکثر ۳ تصویر مرجع با هدایت یک پرامپت متنی استفاده می‌کند. شما یک مدل را انتخاب می‌کنید، پرامپت و تصاویر مرجع را ارائه می‌دهید و گره یک یا چند تصویر تولیدشده را برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. این انتخاب همچنین شامل پرامپت متنی، حداکثر ۳ ورودی تصویر مرجع و یک پرامپت منفی اختیاری است. | DYNAMIC_COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | رزولوشن خروجی. "match input" اندازهٔ نخستین تصویر مرجع را دوباره استفاده می‌کند، "auto" به مدل اجازه می‌دهد اندازه‌ای با همان نسبت تصویر انتخاب کند، و "custom" عرض و ارتفاع صریح را تنظیم می‌کند. | DYNAMIC_COMBO | بله | "match input"<br>"auto"<br>"custom" |
| `n` | تعداد تصاویر برای تولید که به‌صورت یک دسته (batch) برگردانده می‌شوند. (پیش‌فرض: 1) | INT | خیر | 1 تا 6 |
| `seed` | seed مورد استفاده برای تولید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | این‌که پرامپت با کمک هوش مصنوعی بهبود یابد یا نه. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `watermark` | این‌که یک واترمارک تولیدشده توسط هوش مصنوعی به نتیجه افزوده شود یا نه. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

هر دو مدل زیرپارامترهای یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | دستورالعمل‌های ویرایش. از زبان‌های انگلیسی و چینی و ارجاع‌های به‌سبک @Image1 به تصاویر ورودی پشتیبانی می‌کند. (پیش‌فرض: "") | STRING | بله | - |
| `negative_prompt` | پرامپت منفی که چیزهایی را که باید از آن‌ها اجتناب شود توصیف می‌کند. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | اسلات قابل‌افزایش: ۱ تا ۳ تصویر مرجع را متصل کنید (`image_1`، `image_2`، `image_3`). در پرامپت با @Image1، @Image2، @Image3 به آن‌ها ارجاع دهید که به ترتیب ورودی شماره‌گذاری شده‌اند؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود. | IMAGE | بله | 1 تا 3 |

### ورودی‌های اندازه سفارشی

زمانی نمایش داده می‌شود که `size` روی "custom" تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `width` | عرض خروجی. مساحت کل پیکسل‌ها باید بین 512x512 و 2560x2560 باشد؛ هر نسبت تصویری در آن محدوده کار می‌کند. (پیش‌فرض: 1024) | INT | بله (وقتی `size` روی "custom" تنظیم شده است) | 256 تا 2560، گام 16 |
| `height` | ارتفاع خروجی. مساحت کل پیکسل‌ها باید بین 512x512 و 2560x2560 باشد؛ هر نسبت تصویری در آن محدوده کار می‌کند. (پیش‌فرض: 1024) | INT | بله (وقتی `size` روی "custom" تنظیم شده است) | 256 تا 2560، گام 16 |

### محدودیت‌ها

- پرامپت متنی الزامی است و باید حداقل یک نویسه داشته باشد.
- حداکثر ۳ تصویر مرجع پشتیبانی می‌شود؛ اگر بیشتر ارائه شود خطا رخ می‌دهد (یک ورودی دسته‌ای برای هر تصویر یک بار شمرده می‌شود).
- وقتی `size` روی "custom" تنظیم شده است، باید مقادیر صریح عرض و ارتفاع ارائه شوند و اعتبارسنجی می‌شوند: مساحت کل پیکسل‌ها باید بین 262,144 (512x512) و 6,553,600 (2560x2560) پیکسل باشد، و نسبت تصویر باید بین 1:8 و 8:1 باشد.
- وقتی `size` روی "match input" تنظیم شده است، حداقل یک تصویر مرجع لازم است زیرا از ابعاد نخستین تصویر مرجع استفاده می‌شود؛ ابعاد برای جا شدن در مساحت و محدودهٔ نسبت تصویر پشتیبانی‌شده مقیاس‌بندی می‌شوند.
- وقتی `size` روی "auto" تنظیم شده است، مدل اندازهٔ خروجی (1.9-4.2 مگاپیکسل) را با حفظ نسبت تصویر ورودی انتخاب می‌کند.
- ارجاع‌های پرامپت از @Image1، @Image2، @Image3 استفاده می‌کنند که به ترتیب ورودی شماره‌گذاری شده‌اند؛ ارجاع به نمایه‌ای بالاتر از تعداد تصاویر متصل خطا ایجاد می‌کند. برچسب‌ها فقط در مرزهای واژه شناسایی می‌شوند، بنابراین نشانی‌هایی مانند user@image1.com بدون تغییر می‌مانند.
- تصاویر مرجع ورودی پیش از ارسال به API حداکثر به 2048x2048 پیکسل کوچک‌سازی می‌شوند. اگر رمزگذاری PNG از حد اندازهٔ API فراتر رود، به‌جای آن از رمزگذاری JPEG استفاده می‌شود.
