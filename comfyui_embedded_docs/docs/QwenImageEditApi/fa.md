# QwenImageEditApi

این گره از مدل‌های Qwen-Image 3.0 برای ویرایش یا ترکیب حداکثر ۳ تصویر مرجع با هدایت یک پرامپت متنی استفاده می‌کند. شما پرامپت متنی و تصاویر مرجع را ارائه می‌دهید و گره نتیجه تولیدشده را به‌صورت یک یا چند تصویر بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. این انتخاب شامل متن پرامپت، حداکثر ۳ ورودی تصویر مرجع، و یک پرامپت منفی اختیاری نیز می‌شود. | COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | رزولوشن خروجی. «match input» اندازه اولین تصویر مرجع را استفاده می‌کند، «auto» به مدل اجازه می‌دهد اندازه‌ای با همان نسبت ابعاد انتخاب کند، و «custom» عرض و ارتفاع صریح تعیین می‌کند. | COMBO | بله | "match input"<br>"auto"<br>"custom" |
| `n` | تعداد تصاویر تولیدی، که به‌صورت یک دسته بازگردانده می‌شوند. (پیش‌فرض: ۱) | INT | خیر | 1 تا 6 |
| `seed` | دانه (Seed) مورد استفاده برای تولید. (پیش‌فرض: ۴۲) | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | آیا پرامپت با کمک هوش مصنوعی بهبود یابد یا خیر. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `watermark` | آیا یک واترمارک تولیدشده با هوش مصنوعی به نتیجه اضافه شود یا خیر. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### محدودیت‌ها

- متن پرامپت الزامی است و باید حداقل یک نویسه داشته باشد.
- حداکثر ۳ تصویر مرجع پشتیبانی می‌شود؛ اگر بیش از این تعداد ارائه شود، خطا رخ می‌دهد (یک ورودی دسته‌ای به‌ازای هر تصویر یک بار شمارش می‌شود).
- وقتی `size` روی «custom» تنظیم شود، باید مقادیر صریح عرض و ارتفاع ارائه شوند و اعتبارسنجی می‌شوند.
- وقتی `size` روی «match input» تنظیم شود، حداقل یک تصویر مرجع الزامی است، زیرا ابعاد اولین تصویر مرجع استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| IMAGE | تصویر یا تصاویر تولیدشده که به‌صورت یک دسته بازگردانده می‌شوند. حداکثر `n` تصویر بازگردانده می‌شود. | IMAGE |
