# ویرایش تصویر Qwen ۳

این گره از مدل‌های Qwen-Image 3.0 برای ویرایش یا ترکیب حداکثر ۳ تصویر مرجع با هدایت یک متن راهنما استفاده می‌کند. شما یک مدل انتخاب می‌کنید، متن راهنما و تصاویر مرجع را ارائه می‌دهید و گره یک یا چند تصویر تولیدشده را بازمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده. این انتخاب همچنین شامل متن راهنما، حداکثر ۳ ورودی تصویر مرجع و یک راهنمای منفی اختیاری است. | DYNAMIC_COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `اندازه` | رزولوشن خروجی. «match input» اندازه اولین تصویر مرجع را دوباره استفاده می‌کند، «auto» به مدل اجازه می‌دهد اندازه‌ای با همان نسبت ابعاد انتخاب کند، و «custom» عرض و ارتفاع صریح تنظیم می‌کند. | DYNAMIC_COMBO | بله | "match input"<br>"auto"<br>"custom" |
| `تعداد` | تعداد تصاویر برای تولید که به صورت یک دسته بازگردانده می‌شوند. (پیش‌فرض: ۱) | INT | خیر | ۱ تا ۶ |
| `seed` | دانه (seed) مورد استفاده برای تولید. (پیش‌فرض: ۴۲) | INT | خیر | ۰ تا ۲۱۴۷۴۸۳۶۴۷ |
| `افزایش پرامپت` | آیا متن راهنما با کمک هوش مصنوعی بهبود یابد؟ (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `واترمارک` | آیا یک واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود؟ (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

هر دو مدل زیرپارامترهای یکسانی دارند.

|-----------|-------------|-----------|----------|-------|

| `negative_prompt` | متن راهنمای منفی که موارد اجتناب‌ناپذیر را توصیف می‌کند. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | اسلات قابل‌گسترش: ۱ تا ۳ تصویر مرجع را متصل کنید (`image_1`, `image_2`, `image_3`). در متن راهنما به آن‌ها به صورت @Image1، @Image2، @Image3 ارجاع دهید که به ترتیب ورودی شماره‌گذاری شده‌اند؛ یک ورودی دسته‌ای برای هر تصویر یک بار شمارش می‌شود. | IMAGE | بله | ۱ تا ۳ |

### ورودی‌های اندازه سفارشی

زمانی نمایش داده می‌شود که `size` روی «custom» تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `width` | عرض خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | بله (زمانی که `size` روی «custom» است) | ۲۵۶ تا ۲۵۶۰، گام ۱۶ |
| `height` | ارتفاع خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | بله (زمانی که `size` روی «custom» است) | ۲۵۶ تا ۲۵۶۰، گام ۱۶ |

### محدودیت‌ها

- متن راهنما الزامی است و باید حداقل یک نویسه داشته باشد.
- حداکثر ۳ تصویر مرجع پشتیبانی می‌شود؛ اگر تعداد بیشتری ارائه شود خطا برمی‌خیزد (یک ورودی دسته‌ای برای هر تصویر یک بار شمارش می‌شود).
- وقتی `size` روی «custom» تنظیم شده است، مقادیر صریح عرض و ارتفاع باید ارائه شوند و اعتبارسنجی می‌شوند: مساحت کل پیکسل باید بین 262,144 (512x512) و 6,553,600 (2560x2560) پیکسل باشد و نسبت ابعاد باید بین 1:8 و 8:1 باشد.
- وقتی `size` روی «match input» تنظیم شده است، حداقل یک تصویر مرجع الزامی است زیرا ابعاد اولین تصویر مرجع استفاده می‌شود؛ ابعاد برای قرار گرفتن در محدوده مساحت و نسبت ابعاد پشتیبانی‌شده مقیاس‌دهی می‌شوند.
- وقتی `size` روی «auto» تنظیم شده است، مدل اندازه خروجی (۱.۹ تا ۴.۲ مگاپیکسل) را انتخاب می‌کند و نسبت ابعاد ورودی را حفظ می‌کند.
- ارجاع‌های متن راهنما از @Image1، @Image2، @Image3 استفاده می‌کنند که به ترتیب ورودی شماره‌گذاری شده‌اند؛ ارجاع به اندیسی بالاتر از تعداد تصاویر متصل‌شده خطا ایجاد می‌کند. برچسب‌ها فقط در مرز کلمات شناسایی می‌شوند، بنابراین آدرس‌هایی مانند user@image1.com بدون تغییر می‌مانند.
- تصاویر مرجع ورودی قبل از ارسال به API حداکثر به 2048x2048 پیکسل کاهش می‌یابند. اگر رمزگذاری PNG از محدودیت اندازه API فراتر رود، به جای آن از رمزگذاری JPEG استفاده می‌شود.
