# QwenImageEditApi

این گره از مدل‌های Qwen-Image 3.0 برای ویرایش یا ترکیب حداکثر ۳ تصویر مرجع با هدایت یک متن راهنما (prompt) استفاده می‌کند. شما متن راهنما و تصاویر مرجع را ارائه می‌دهید و گره نتیجه تولیدشده را به‌صورت یک یا چند تصویر برمی‌گرداند.

## ورودی‌ها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده. این انتخاب شامل متن راهنما، حداکثر ۳ ورودی تصویر مرجع و یک negative prompt اختیاری نیز می‌شود. | MODEL | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | رزولوشن خروجی. «match input» اندازه اولین تصویر مرجع را دوباره استفاده می‌کند، «auto» به مدل اجازه می‌دهد اندازه‌ای با همان نسبت ابعاد انتخاب کند و «custom» عرض و ارتفاع صریح تنظیم می‌کند. | COMBO | بله | "match input"<br>"auto"<br>"custom" |
| `n` | تعداد تصاویر تولیدشده که به‌صورت یک دسته (batch) بازگردانده می‌شوند. (پیش‌فرض: 1) | INT | خیر | 1 تا 6 |
| `seed` | دانه (seed) مورد استفاده برای تولید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `prompt_extend` | آیا متن راهنما با کمک هوش مصنوعی بهبود یابد؟ (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `watermark` | آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود؟ (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

هر دو مدل زیرپارامترهای مشترکی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | دستورالعمل‌های ویرایش. از زبان انگلیسی و چینی و ارجاع‌های سبک @Image1 به تصاویر ورودی پشتیبانی می‌کند. (پیش‌فرض: "") | STRING | بله | - |
| `negative_prompt` | Negative prompt که توصیف می‌کند از چه چیزهایی باید اجتناب شود. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | جاگاه قابل رشد: ۱ تا ۳ تصویر مرجع را متصل کنید (`image_1`، `image_2`، `image_3`). در prompt با @Image1، @Image2 و @Image3 به آن‌ها ارجاع دهید؛ شماره‌گذاری به ترتیب ورودی است. یک ورودی دسته‌ای برای هر تصویر یک بار شمارش می‌شود. | IMAGE | بله | 1 تا 3 |

### ورودی‌های اندازه سفارشی

زمانی نمایش داده می‌شود که `size` روی «custom» تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `width` | عرض خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | بله (زمانی که `size` برابر «custom» باشد) | 256 تا 2560، گام 16 |
| `height` | ارتفاع خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | بله (زمانی که `size` برابر «custom» باشد) | 256 تا 2560، گام 16 |

### محدودیت‌ها

- متن راهنما (prompt) الزامی است و باید حداقل یک نویسه داشته باشد.
- حداکثر ۳ تصویر مرجع پشتیبانی می‌شود؛ اگر بیشتر ارائه شود خطا رخ می‌دهد (یک ورودی دسته‌ای برای هر تصویر یک بار شمارش می‌شود).
- وقتی `size` روی «custom» تنظیم شده است، باید مقادیر صریح عرض و ارتفاع ارائه شود و اعتبارسنجی می‌شوند: مساحت کل پیکسل باید بین 262,144 (512x512) و 6,553,600 (2560x2560) پیکسل باشد و نسبت ابعاد باید بین 1:8 و 8:1 باشد.
- وقتی `size` روی «match input» تنظیم شده است، حداقل یک تصویر مرجع لازم است؛ زیرا از ابعاد اولین تصویر مرجع استفاده می‌شود. ابعاد برای قرار گرفتن در محدوده مساحت و نسبت ابعاد پشتیبانی‌شده مقیاس می‌شوند.
- وقتی `size` روی «auto» تنظیم شده است، مدل اندازه خروجی را با حفظ نسبت ابعاد ورودی انتخاب می‌کند.
- ارجاع‌های prompt از @Image1، @Image2 و @Image3 با شماره‌گذاری به ترتیب ورودی استفاده می‌کنند؛ ارجاع به اندیسی بالاتر از تعداد تصاویر متصل‌شده باعث خطا می‌شود. برچسب‌ها فقط در مرز کلمات شناسایی می‌شوند، بنابراین آدرس‌هایی مانند user@image1.com بدون تغییر می‌مانند.
- تصاویر مرجع ورودی قبل از ارسال به API حداکثر به 2048x2048 پیکسل مقیاس کاهشی می‌شوند.
