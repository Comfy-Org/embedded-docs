# QwenImageEditApi

این گره از مدل‌های Qwen-Image 3.0 برای ویرایش یا ترکیب حداکثر ۳ تصویر مرجع با هدایت یک متن راهنما (prompt) استفاده می‌کند. شما متن راهنما و تصاویر مرجع را ارائه می‌دهید و گره نتیجه تولیدشده را به‌صورت یک یا چند تصویر برمی‌گرداند.
## ورودیها

### ورودی‌های عمومی

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `model` | مدل مورد استفاده. این انتخاب شامل متن راهنما، حداکثر ۳ ورودی تصویر مرجع و یک negative prompt اختیاری نیز می‌شود. | DYNAMIC_COMBO | بله | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | رزولوشن خروجی. «match input» اندازه اولین تصویر مرجع را دوباره استفاده می‌کند، «auto» به مدل اجازه می‌دهد اندازه‌ای با همان نسبت ابعاد انتخاب کند و «custom» عرض و ارتفاع صریح تنظیم می‌کند. | DYNAMIC_COMBO | بله | "match input"<br>"auto"<br>"custom" |
| `n` | تعداد تصاویر تولیدشده که به‌صورت یک دسته (batch) بازگردانده می‌شوند. (پیش‌فرض: 1) | INT | خیر | 1 to 6 |
| `seed` | دانه (seed) مورد استفاده برای تولید. (پیش‌فرض: 42) | INT | خیر | 0 to 2147483647 |
| `prompt_extend` | آیا متن راهنما با کمک هوش مصنوعی بهبود یابد؟ (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `watermark` | آیا واترمارک تولیدشده توسط هوش مصنوعی به نتیجه اضافه شود؟ (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های qwen-image-3.0-pro و qwen-image-3.0

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `prompt` | دستورالعمل‌های ویرایش. از زبان انگلیسی و چینی و ارجاع‌های سبک @Image1 به تصاویر ورودی پشتیبانی می‌کند. (پیش‌فرض: "") | STRING | بله | - |
| `negative_prompt` | Negative prompt که توصیف می‌کند از چه چیزهایی باید اجتناب شود. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `images` | جاگاه قابل رشد: ۱ تا ۳ تصویر مرجع را متصل کنید (`image_1`، `image_2`، `image_3`). در prompt با @Image1، @Image2 و @Image3 به آن‌ها ارجاع دهید؛ شماره‌گذاری به ترتیب ورودی است. یک ورودی دسته‌ای برای هر تصویر یک بار شمارش می‌شود. | IMAGE | بله | 1 to 3 |

### ورودی‌های اندازه سفارشی

| پارامتر | توضیحات | نوع داده | اجباری | محدوده |
|---|---|---|---|---|
| `width` | عرض خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | خیر | 256 to 2560, step 16 |
| `height` | ارتفاع خروجی. مساحت کل پیکسل باید بین 512x512 و 2560x2560 باشد؛ نسبت ابعاد باید بین 1:8 و 8:1 باشد. (پیش‌فرض: 1024) | INT | خیر | 256 to 2560, step 16 |

## خروجیها

| نام خروجی | توضیحات | نوع داده |
|---|---|---|
| `IMAGE` | The generated image or images returned as a batch. Up to `n` images are returned. | IMAGE |
