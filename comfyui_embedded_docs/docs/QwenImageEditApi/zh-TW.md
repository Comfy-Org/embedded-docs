# Qwen Image 3 編輯

此節點使用 Qwen-Image 3.0 模型，在文字提示詞的引導下編輯或組合最多 3 張參考圖像。您選擇模型、提供提示詞與參考圖像，節點會回傳一張或多張生成的圖像。

### 限制條件

- 文字提示詞為必填，且必須至少包含一個字元。
- 最多支援 3 張參考圖像；若提供更多則會引發錯誤（批次輸入會以每張圖像各計一次）。
- 當 `size` 設為 "custom" 時，必須提供明確的 `width` 與 `height` 值，且會進行驗證：總像素面積必須介於 262,144（512x512）與 6,553,600（2560x2560）像素之間，且長寬比必須介於 1:8 與 8:1 之間。
- 當 `size` 設為 "match input" 時，至少需要一張參考圖像，因為會使用第一張參考圖像的尺寸；該尺寸會縮放以符合支援的面積與長寬比範圍。
- 當 `size` 設為 "auto" 時，模型會挑選輸出尺寸（1.9-4.2 百萬像素），同時保留輸入的長寬比。
- 提示詞引用使用 @Image1、@Image2、@Image3，並依輸入順序編號；若引用的索引高於已連接的圖像數量，則會引發錯誤。標籤僅在詞邊界辨識，因此像 user@image1.com 這樣的地址會保持不變。
- 輸入參考圖像在傳送到 API 前會縮小至最多 2048x2048 像素。若 PNG 編碼超過 API 大小限制，則改用 JPEG 編碼。
