# QwenImageEditApi

此節點使用 Qwen-Image 3.0 模型，在文字提示的引導下編輯或組合最多 3 張參考圖片。您提供文字提示和參考圖片，節點會將生成的結果以一或多張圖片的形式返回。

## 輸入

|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。此選擇還包含文字提示、最多 3 個參考圖片輸入，以及可選的負面提示。 | COMBO | 是 | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |

### 限制條件

- 文字提示為必填項，且必須至少包含一個字元。
- 最多支援 3 張參考圖片；如果提供更多圖片則會引發錯誤（批次輸入每張圖片計數一次）。
- 當 `size` 設定為「custom」時，必須提供明確的寬度和高度值並進行驗證：總像素面積必須介於 262,144（512x512）和 6,553,600（2560x2560）像素之間，且長寬比必須介於 1:8 和 8:1 之間。
- 當 `size` 設定為「match input」時，至少需要一張參考圖片，因為會使用第一張參考圖片的尺寸；尺寸會縮放以符合支援的面積和長寬比範圍。
- 當 `size` 設定為「auto」時，模型在保留輸入長寬比的同時選擇輸出大小。
- 提示引用使用 @Image1、@Image2、@Image3，按輸入順序編號；引用高於所連接圖片數量的索引會引發錯誤。標籤僅在單詞邊界處識別，因此像 user@image1.com 這樣的地址會保持不變。
- 輸入參考圖片在傳送到 API 之前會縮小至最多 2048x2048 像素。
