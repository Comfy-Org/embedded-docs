# Qwen Image 3 編輯

此節點使用 Qwen-Image 3.0 模型，根據文字提示編輯或組合最多 3 張參考圖片。您選擇模型、提供提示與參考圖片，節點將回傳一或多張生成的圖片。

### 限制條件

- 文字提示為必填，且必須至少包含一個字元。
- 最多支援 3 張參考圖片；若提供超過數量將產生錯誤（批次輸入中的每張圖片各計為一次）。
- 當 `size` 設定為「custom」時，必須提供明確的寬度與高度值並進行驗證：總像素面積必須介於 262,144（512x512）與 6,553,600（2560x2560）像素之間，且寬高比必須介於 1:8 與 8:1 之間。
- 當 `size` 設定為「match input」時，需要至少一張參考圖片，因為會使用第一張參考圖片的尺寸；系統會縮放尺寸以符合支援的面積與寬高比範圍。
- 當 `size` 設定為「auto」時，模型會選擇輸出尺寸，同時保留輸入的寬高比。
- 提示參照使用 @Image1、@Image2、@Image3，依輸入順序編號；參照的索引高於已連接圖片數量時會產生錯誤。標籤僅在詞邊界被辨識，因此 user@image1.com 這類地址不會被變更。
- 輸入的參考圖片在傳送至 API 前會縮小至最多 2048x2048 像素。如果 PNG 編碼超過 API 大小限制，則改用 JPEG 編碼。
