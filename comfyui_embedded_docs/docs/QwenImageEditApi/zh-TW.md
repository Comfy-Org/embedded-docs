# Qwen Image 3 編輯

此節點使用 Qwen-Image 3.0 模型，根據文字提示詞編輯或組合最多 3 張參考圖片。您可選擇模型、提供提示詞與參考圖片，節點將傳回一張或多張產生的圖片。

### 約束條件

- 文字提示詞為必填，且必須包含至少一個字元。
- 最多支援 3 張參考圖片；若提供超過 3 張則會產生錯誤（批次輸入的每張圖片各計一次）。
- 當 `size` 設為「custom」時，必須提供明確的寬度與高度值，並會進行驗證：總像素面積必須介於 262,144（512x512）與 6,553,600（2560x2560）像素之間，且長寬比必須介於 1:8 與 8:1 之間。
- 當 `size` 設為「match input」時，至少需要一張參考圖片，因為會使用第一張參考圖片的尺寸；系統會縮放尺寸以符合支援的面積與長寬比範圍。
- 當 `size` 設為「auto」時，模型會選擇輸出尺寸（1.9 至 4.2 百萬像素），同時保留輸入的長寬比。
- 提示詞引用使用 @Image1、@Image2、@Image3，依輸入順序編號；若引用的索引高於已連接圖片的數量，則會產生錯誤。標記僅在字詞邊界處辨識，因此 user@image1.com 這類位址不會被變更。
- 輸入參考圖片在傳送至 API 前會縮小至最多 2048x2048 像素。若 PNG 編碼超過 API 大小限制，則改用 JPEG 編碼。
