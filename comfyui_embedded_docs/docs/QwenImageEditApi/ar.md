# تحرير Qwen Image 3

تستخدم هذه العقدة نماذج Qwen-Image 3.0 لتحرير أو دمج ما يصل إلى 3 صور مرجعية وفقًا لموجه نصي. يمكنك تحديد نموذج وتقديم الموجه والصور المرجعية، وتقوم العقدة بإرجاع صورة واحدة أو أكثر من الصور المُولَّدة.

## المدخلات

### المدخلات العامة

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المطلوب استخدامه. يتضمن هذا التحديد أيضًا موجه النص، وما يصل إلى 3 مدخلات صور مرجعية، وموجهًا سلبيًا اختياريًا. | DYNAMIC_COMBO | نعم | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `الحجم` | دقة الإخراج. الخيار "match input" يعيد استخدام حجم الصورة المرجعية الأولى، و"auto" يسمح للنموذج باختيار حجم بنفس نسبة العرض إلى الارتفاع، و"custom" يحدد عرضًا وارتفاعًا صريحين. | DYNAMIC_COMBO | نعم | "match input"<br>"auto"<br>"custom" |
| `عدد الصور` | عدد الصور المراد توليدها، ويتم إرجاعها كدفعة واحدة. (الافتراضي: 1) | INT | لا | من 1 إلى 6 |
| `البذرة` | البذرة المستخدمة في التوليد. (الافتراضي: 42) | INT | لا | من 0 إلى 2147483647 |
| `تعزيز التوجيه` | ما إذا كان سيتم تحسين الموجه بمساعدة الذكاء الاصطناعي. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `علامة مائية` | ما إذا كان سيتم إضافة علامة مائية مُولَّدة بالذكاء الاصطناعي إلى النتيجة. (الافتراضي: False) | BOOLEAN | لا | True<br>False |

### مدخلات qwen-image-3.0-pro و qwen-image-3.0

يشترك النموذجان في نفس المعاملات الفرعية.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | تعليمات التحرير. يدعم اللغة الإنجليزية والصينية، والإشارات على غرار @Image1 إلى الصور المدخلة. (الافتراضي: "") | STRING | نعم | - |
| `negative_prompt` | الموجه السلبي الذي يصف ما يجب تجنبه. (الافتراضي: "") | STRING | لا | - |

### المدخلات المرجعية

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `images` | فتحة قابلة للتوسيع: قم بتوصيل من 1 إلى 3 صور مرجعية (`image_1`، `image_2`، `image_3`). قم بالإشارة إليها في الموجه بصيغة @Image1 و@Image2 و@Image3، مرقمة حسب ترتيب الإدخال؛ المدخلات المجمعة تُحتسب كل صورة منها كصورة مرجعية واحدة. | IMAGE | نعم | من 1 إلى 3 |

### مدخلات الحجم المخصص

تظهر عندما يتم تعيين `size` إلى "custom".

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `width` | عرض الإخراج. يجب أن تكون المساحة البكسلية الإجمالية بين 512×512 و2560×2560؛ كما يجب أن تكون نسبة العرض إلى الارتفاع بين 1:8 و8:1. (الافتراضي: 1024) | INT | نعم (عندما يكون `size` هو "custom") | من 256 إلى 2560، بخطوة 16 |
| `height` | ارتفاع الإخراج. يجب أن تكون المساحة البكسلية الإجمالية بين 512×512 و2560×2560؛ كما يجب أن تكون نسبة العرض إلى الارتفاع بين 1:8 و8:1. (الافتراضي: 1024) | INT | نعم (عندما يكون `size` هو "custom") | من 256 إلى 2560، بخطوة 16 |

### القيود

- موجه النص مطلوب ويجب أن يحتوي على حرف واحد على الأقل.
- يُدعم حد أقصى قدره 3 صور مرجعية؛ يتم إصدار خطأ إذا تم توفير أكثر من ذلك (يُحتسب كل صورة في الدفعة كصورة مرجعية واحدة).
- عندما يتم تعيين `size` إلى "custom"، يجب توفير قيمتي العرض والارتفاع بشكل صريح، ويتم التحقق منهما: يجب أن تكون المساحة البكسلية الإجمالية بين 262,144 (512×512) و6,553,600 (2560×2560) بكسل، ويجب أن تكون نسبة العرض إلى الارتفاع بين 1:8 و8:1.
- عندما يتم تعيين `size` إلى "match input"، يلزم وجود صورة مرجعية واحدة على الأقل لأن أبعاد الصورة المرجعية الأولى تُستخدم؛ يتم قياس الأبعاد لتناسب نطاق المساحة ونسبة العرض إلى الارتفاع المدعومة.
- عندما يتم تعيين `size` إلى "auto"، يختار النموذج حجم الإخراج (1.9-4.2 ميغابكسل) مع الحفاظ على نسبة العرض إلى الارتفاع المدخلة.
- إشارات الموجه تستخدم @Image1 و@Image2 و@Image3، مرقمة حسب ترتيب الإدخال؛ الإشارة إلى فهرس أعلى من عدد الصور المتصلة تؤدي إلى خطأ. يتم التعرف على العلامات فقط عند حدود الكلمات، لذا تظل العناوين مثل user@image1.com دون تغيير.
- يتم تصغير الصور المرجعية المدخلة إلى 2048×2048 بكسل كحد أقصى قبل إرسالها إلى API. إذا تجاوز ترميز PNG حد حجم API، يتم استخدام ترميز JPEG بدلاً من ذلك.
