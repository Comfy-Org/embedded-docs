# QwenImageEditApi

此节点使用 Qwen-Image 3.0 模型，在文本提示的引导下编辑或组合最多 3 张参考图像。您提供文本提示和参考图像，节点将生成结果作为一张或多张图像返回。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。此选择还包括文本提示、最多 3 个参考图像输入以及可选的负向提示词。 | MODEL | 是 | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | 输出分辨率。“match input”复用第一张参考图像的尺寸，“auto”让模型选择与输入具有相同宽高比的尺寸，“custom”设置明确的宽度和高度。 | COMBO | 是 | "match input"<br>"auto"<br>"custom" |
| `n` | 要生成的图像数量，作为批次返回。（默认：1） | INT | 否 | 1 到 6 |
| `seed` | 用于生成的随机种子。（默认：42） | INT | 否 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词。（默认：True） | BOOLEAN | 否 | True<br>False |
| `watermark` | 是否在结果中添加 AI 生成的水印。（默认：False） | BOOLEAN | 否 | True<br>False |

| `height` | 输出高度。总像素面积必须介于 512x512 到 2560x2560 之间；宽高比必须介于 1:8 和 8:1 之间。（默认：1024） | INT | 是（当 `size` 为“custom”时） | 256 到 2560，步长 16 |

### 约束

- 文本提示为必填项，且必须至少包含一个字符。
- 最多支持 3 张参考图像；如果提供更多，则会引发错误（批量输入按每张图像计数一次）。
- 当 `size` 设置为“custom”时，必须提供显式的宽度和高度值，并会进行验证：总像素面积必须介于 262,144（512x512）和 6,553,600（2560x2560）像素之间，宽高比必须介于 1:8 和 8:1 之间。
- 当 `size` 设置为“match input”时，至少需要一张参考图像，因为会使用第一张参考图像的尺寸；尺寸会被缩放以适配支持的面积和宽高比范围。
- 当 `size` 设置为“auto”时，模型会在保留输入宽高比的同时选择输出尺寸。
- 提示词引用使用 @Image1、@Image2、@Image3，按输入顺序编号；引用大于已连接图像数量的索引会引发错误。标签仅在单词边界处识别，因此类似 user@image1.com 的地址会保持不变。
- 输入参考图像在发送到 API 之前会缩小到最大 2048x2048 像素。
