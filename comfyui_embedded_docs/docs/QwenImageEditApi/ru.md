# QwenImageEditApi

Этот узел использует модели Qwen-Image 3.0 для редактирования или объединения до 3 референсных изображений на основе текстового запроса. Вы предоставляете текстовый запрос и референсные изображения, а узел возвращает сгенерированный результат в виде одного или нескольких изображений.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. Этот выбор также включает текстовый запрос, до 3 входов для референсных изображений и опциональный негативный запрос. | COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | Разрешение вывода. "match input" использует размер первого референсного изображения, "auto" позволяет модели выбрать размер с тем же соотношением сторон, "custom" задает явные значения ширины и высоты. | COMBO | Да | "match input"<br>"auto"<br>"custom" |
| `n` | Количество изображений для генерации, возвращаемых в виде пакета. (по умолчанию: 1) | INT | Нет | 1 до 6 |
| `seed` | Сид для генерации. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `prompt_extend` | Нужно ли улучшать запрос с помощью ИИ. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `watermark` | Нужно ли добавлять к результату водяной знак, созданный ИИ. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Ограничения

- Текстовый запрос обязателен и должен содержать хотя бы один символ.
- Поддерживается максимум 3 референсных изображения; при передаче большего количества возникает ошибка (пакетный вход учитывается по количеству изображений).
- Когда для `size` задано значение "custom", необходимо указать явные значения ширины и высоты, которые проходят проверку.
- Когда для `size` задано значение "match input", требуется хотя бы одно референсное изображение, поскольку используются размеры первого референсного изображения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| IMAGE | Сгенерированное изображение или изображения, возвращаемые в виде пакета. Возвращается до `n` изображений. | IMAGE |
