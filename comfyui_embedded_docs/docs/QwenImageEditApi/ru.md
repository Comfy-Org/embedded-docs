# QwenImageEditApi

Этот узел использует модели Qwen-Image 3.0 для редактирования или объединения до 3 референсных изображений на основе текстового запроса. Вы предоставляете текстовый запрос и референсные изображения, а узел возвращает сгенерированный результат в виде одного или нескольких изображений.
## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Используемая модель. Этот выбор также включает текстовый запрос, до 3 входов референсных изображений и необязательный негативный запрос. | DYNAMIC_COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | Разрешение вывода. «match input» использует размер первого референсного изображения, «auto» позволяет модели выбрать размер с тем же соотношением сторон, «custom» задает явные ширину и высоту. | DYNAMIC_COMBO | Да | "match input"<br>"auto"<br>"custom" |
| `n` | Количество изображений для генерации, возвращаемых пакетом. (по умолчанию: 1) | INT | Нет | 1 to 6 |
| `seed` | Сид, используемый для генерации. (по умолчанию: 42) | INT | Нет | 0 to 2147483647 |
| `prompt_extend` | Следует ли улучшать запрос с помощью ИИ. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `watermark` | Следует ли добавлять водяной знак, созданный ИИ, к результату. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы qwen-image-3.0-pro и qwen-image-3.0

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Инструкции по редактированию. Поддерживает английский и китайский языки, а также ссылки в стиле @Image1 на входные изображения. (по умолчанию: "") | STRING | Да | - |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать. (по умолчанию: "") | STRING | Нет | - |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `images` | Расширяемый слот: подключите от 1 до 3 референсных изображений (`image_1`, `image_2`, `image_3`). Ссылайтесь на них в запросе как @Image1, @Image2, @Image3, нумерованных в порядке ввода; пакетный вход учитывается как одно изображение. | IMAGE | Да | 1 to 3 |

### Входы пользовательского размера

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `width` | Ширина вывода. Общая площадь в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Нет | 256 to 2560, step 16 |
| `height` | Высота вывода. Общая площадь в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Нет | 256 to 2560, step 16 |

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `IMAGE` | The generated image or images returned as a batch. Up to `n` images are returned. | IMAGE |
