# QwenImageEditApi

Этот узел использует модели Qwen-Image 3.0 для редактирования или объединения до 3 референсных изображений на основе текстового запроса. Вы предоставляете текстовый запрос и референсные изображения, а узел возвращает сгенерированный результат в виде одного или нескольких изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. Этот выбор также включает текстовый запрос, до 3 входов референсных изображений и необязательный негативный запрос. | MODEL | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | Разрешение вывода. «match input» использует размер первого референсного изображения, «auto» позволяет модели выбрать размер с тем же соотношением сторон, «custom» задает явные ширину и высоту. | COMBO | Да | "match input"<br>"auto"<br>"custom" |
| `n` | Количество изображений для генерации, возвращаемых пакетом. (по умолчанию: 1) | INT | Нет | от 1 до 6 |
| `seed` | Сид, используемый для генерации. (по умолчанию: 42) | INT | Нет | от 0 до 2147483647 |
| `prompt_extend` | Следует ли улучшать запрос с помощью ИИ. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `watermark` | Следует ли добавлять водяной знак, созданный ИИ, к результату. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы qwen-image-3.0-pro и qwen-image-3.0

Обе модели используют одни и те же подпараметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает английский и китайский языки, а также ссылки в стиле @Image1 на входные изображения. (по умолчанию: "") | STRING | Да | - |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать. (по умолчанию: "") | STRING | Нет | - |

### Референсные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 3 референсных изображений (`image_1`, `image_2`, `image_3`). Ссылайтесь на них в запросе как @Image1, @Image2, @Image3, нумерованных в порядке ввода; пакетный вход учитывается как одно изображение. | IMAGE | Да | от 1 до 3 |

### Входы пользовательского размера

Отображается, когда для `size` установлено значение "custom".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина вывода. Общая площадь в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Да (когда для `size` установлено "custom") | от 256 до 2560, шаг 16 |
| `height` | Высота вывода. Общая площадь в пикселях должна быть от 512×512 до 2560×2560; соотношение сторон должно быть от 1:8 до 8:1. (по умолчанию: 1024) | INT | Да (когда для `size` установлено "custom") | от 256 до 2560, шаг 16 |

### Ограничения

- Текстовый запрос обязателен и должен содержать хотя бы один символ.
- Поддерживается не более 3 референсных изображений; при передаче большего количества возникает ошибка (пакетный вход учитывается как одно изображение).
- Когда для `size` установлено значение "custom", необходимо указать явные значения ширины и высоты, которые проверяются: общая площадь в пикселях должна быть от 262 144 (512×512) до 6 553 600 (2560×2560) пикселей, а соотношение сторон — от 1:8 до 8:1.
- Когда для `size` установлено значение "match input", требуется хотя бы одно референсное изображение, поскольку используются размеры первого референсного изображения; размеры масштабируются, чтобы соответствовать поддерживаемой площади и диапазону соотношения сторон.
- Когда для `size` установлено значение "auto", модель выбирает размер вывода, сохраняя соотношение сторон входного изображения.
- Ссылки в запросе используют @Image1, @Image2, @Image3, которые нумеруются в порядке ввода; ссылка на индекс, превышающий количество подключенных изображений, вызывает ошибку. Теги распознаются только на границах слов, поэтому адреса вида user@image1.com остаются без изменений.
- Входные референсные изображения уменьшаются до размера не более 2048×2048 пикселей перед отправкой в API.

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение или изображения, возвращаемые пакетом. Возвращается до `n` изображений. | IMAGE |
