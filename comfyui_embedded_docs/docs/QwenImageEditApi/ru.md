# Qwen Image 3 Edit

Этот узел использует модели Qwen-Image 3.0 для редактирования или объединения до 3 эталонных изображений под управлением текстового промпта. Вы выбираете модель, задаёте промпт и эталонные изображения, а узел возвращает одно или несколько сгенерированных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Используемая модель. Этот выбор также включает текстовый промпт, до 3 входов эталонных изображений и необязательный негативный промпт. | DYNAMIC_COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | Разрешение выходного изображения. "match input" повторно использует размер первого эталонного изображения, "auto" позволяет модели выбрать размер с тем же соотношением сторон, "custom" задаёт явные ширину и высоту. | DYNAMIC_COMBO | Да | "match input"<br>"auto"<br>"custom" |
| `n` | Количество генерируемых изображений, возвращаемых в виде пакета. (по умолчанию: 1) | INT | Нет | 1 до 6 |
| `seed` | Seed, используемый для генерации. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `prompt_extend` | Улучшать ли промпт с помощью ИИ. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `watermark` | Добавлять ли сгенерированный ИИ водяной знак к результату. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы qwen-image-3.0-pro и qwen-image-3.0

Обе модели используют одни и те же подпараметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает английский и китайский языки, а также ссылки на входные изображения в стиле @Image1. (по умолчанию: "") | STRING | Да | - |
| `negative_prompt` | Негативный промпт, описывающий, чего следует избегать. (по умолчанию: "") | STRING | Нет | - |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 3 эталонных изображений (`image_1`, `image_2`, `image_3`). Ссылайтесь на них в промпте как @Image1, @Image2, @Image3, пронумерованные в порядке входов; при пакетном входе каждое изображение учитывается отдельно. | IMAGE | Да | 1 до 3 |

### Входы пользовательского размера

Отображается, когда для `size` установлено значение "custom".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина выходного изображения. Общая площадь пикселей должна быть в диапазоне от 512x512 до 2560x2560; подходит любое соотношение сторон в пределах этой площади. (по умолчанию: 1024) | INT | Да (когда `size` имеет значение "custom") | 256 до 2560, step 16 |
| `height` | Высота выходного изображения. Общая площадь пикселей должна быть в диапазоне от 512x512 до 2560x2560; подходит любое соотношение сторон в пределах этой площади. (по умолчанию: 1024) | INT | Да (когда `size` имеет значение "custom") | 256 до 2560, step 16 |

### Ограничения

- Текстовый промпт обязателен и должен содержать хотя бы один символ.
- Поддерживается максимум 3 эталонных изображения; если передано больше, возникает ошибка (при пакетном входе каждое изображение учитывается отдельно).
- Когда для `size` установлено значение "custom", необходимо указать явные значения ширины и высоты, которые проверяются: общая площадь пикселей должна быть в диапазоне от 262 144 (512x512) до 6 553 600 (2560x2560) пикселей, а соотношение сторон — от 1:8 до 8:1.
- Когда для `size` установлено значение "match input", требуется хотя бы одно эталонное изображение, поскольку используются размеры первого эталонного изображения; размеры масштабируются, чтобы соответствовать поддерживаемой площади и диапазону соотношения сторон.
- Когда для `size` установлено значение "auto", модель выбирает размер выходного изображения (1.9–4.2 мегапикселя), сохраняя соотношение сторон входного изображения.
- Ссылки в промпте используют @Image1, @Image2, @Image3, пронумерованные в порядке входов; ссылка на индекс, превышающий количество подключённых изображений, вызывает ошибку. Теги распознаются только на границах слов, поэтому адреса вида user@image1.com остаются без изменений.
- Входные эталонные изображения уменьшаются максимум до 2048x2048 пикселей перед отправкой в API. Если кодирование PNG превышает ограничение размера API, вместо него используется кодирование JPEG.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение или изображения, возвращаемые в виде пакета. Возвращается до `n` изображений. | IMAGE |
