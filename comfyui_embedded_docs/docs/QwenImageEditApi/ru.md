# Qwen Image 3 Edit

Этот узел использует модели Qwen-Image 3.0 для редактирования или объединения до 3 эталонных изображений на основе текстового запроса. Вы выбираете модель, указываете запрос и эталонные изображения, а узел возвращает одно или несколько сгенерированных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для использования. Этот выбор также включает текстовый запрос, до 3 входов эталонных изображений и опциональный негативный запрос. | DYNAMIC_COMBO | Да | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | Разрешение на выходе. «match input» использует размер первого эталонного изображения, «auto» позволяет модели выбрать размер с тем же соотношением сторон, «custom» задает явные ширину и высоту. | DYNAMIC_COMBO | Да | "match input"<br>"auto"<br>"custom" |
| `n` | Количество изображений для генерации, возвращаемых пакетом. (по умолчанию: 1) | INT | Нет | 1 до 6 |
| `seed` | Сид для генерации. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `prompt_extend` | Следует ли улучшать запрос с помощью ИИ. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `watermark` | Следует ли добавлять водяной знак, созданный ИИ, к результату. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы qwen-image-3.0-pro и qwen-image-3.0

Обе модели используют одни и те же подпараметры.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Инструкции по редактированию. Поддерживает английский и китайский языки, а также ссылки в стиле @Image1 на входные изображения. (по умолчанию: "") | STRING | Да | - |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать. (по умолчанию: "") | STRING | Нет | - |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 3 эталонных изображений (`image_1`, `image_2`, `image_3`). Ссылайтесь на них в запросе как @Image1, @Image2, @Image3, нумерованных в порядке ввода; пакетный вход считается один раз на каждое изображение. | IMAGE | Да | 1 до 3 |

### Входы пользовательского размера

Отображается, когда `size` имеет значение «custom».

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `width` | Ширина вывода. Общая площадь пикселей должна быть между 512x512 и 2560x2560; соотношение сторон должно быть между 1:8 и 8:1. (по умолчанию: 1024) | INT | Да (когда `size` равен «custom») | 256 до 2560, step 16 |
| `height` | Высота вывода. Общая площадь пикселей должна быть между 512x512 и 2560x2560; соотношение сторон должно быть между 1:8 и 8:1. (по умолчанию: 1024) | INT | Да (когда `size` равен «custom») | 256 до 2560, step 16 |

### Ограничения

- Текстовый запрос обязателен и должен содержать хотя бы один символ.
- Поддерживается не более 3 эталонных изображений; при передаче большего количества возникает ошибка (пакетный вход считается один раз на каждое изображение).
- Когда `size` имеет значение «custom», необходимо указать явные значения ширины и высоты, которые проверяются: общая площадь пикселей должна быть между 262 144 (512x512) и 6 553 600 (2560x2560) пикселей, а соотношение сторон — между 1:8 и 8:1.
- Когда `size` имеет значение «match input», требуется хотя бы одно эталонное изображение, поскольку используются размеры первого эталонного изображения; размеры масштабируются, чтобы соответствовать поддерживаемой площади и диапазону соотношения сторон.
- Когда `size` имеет значение «auto», модель выбирает размер вывода (1,9–4,2 мегапикселя) с сохранением соотношения сторон входного изображения.
- Ссылки в запросе используют @Image1, @Image2, @Image3, нумерованных в порядке ввода; ссылка на индекс, превышающий количество подключенных изображений, вызывает ошибку. Теги распознаются только на границах слов, поэтому адреса вида user@image1.com остаются без изменений.
- Входные эталонные изображения уменьшаются до не более 2048x2048 пикселей перед отправкой в API. Если кодирование PNG превышает ограничение размера API, вместо него используется кодирование JPEG.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение или изображения, возвращаемые пакетом. Возвращается до `n` изображений. | IMAGE |
