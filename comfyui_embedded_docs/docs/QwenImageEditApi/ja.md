# QwenImageEditApi

このノードは、Qwen-Image 3.0 モデルを使用して、テキストプロンプトに基づき最大3枚の参照画像を編集または合成します。テキストプロンプトと参照画像を指定すると、ノードは生成結果を1枚以上の画像として返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル。この選択には、テキストプロンプト、最大3枚の参照画像入力、およびオプションのネガティブプロンプトも含まれます。 | MODEL | はい | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | 出力解像度。"match input" は最初の参照画像のサイズを再利用し、"auto" はモデルが同じアスペクト比のサイズを選択し、"custom" は明示的な幅と高さを設定します。 | COMBO | はい | "match input"<br>"auto"<br>"custom" |
| `n` | 生成する画像の数。バッチとして返されます。（デフォルト: 1） | INT | いいえ | 1 〜 6 |
| `seed` | 生成に使用するシード値。（デフォルト: 42） | INT | いいえ | 0 〜 2147483647 |
| `prompt_extend` | AI支援によるプロンプト拡張を行うかどうか。（デフォルト: True） | BOOLEAN | いいえ | True<br>False |
| `watermark` | 結果にAI生成ウォーターマークを追加するかどうか。（デフォルト: False） | BOOLEAN | いいえ | True<br>False |

| `negative_prompt` | 避けたい内容を説明するネガティブプロンプト。（デフォルト: ""） | STRING | いいえ | - |

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|

### カスタムサイズ入力

`size` が "custom" に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |

| `width` | 出力幅。総ピクセル面積は 512x512 から 2560x2560 の間である必要があります。アスペクト比は 1:8 から 8:1 の間である必要があります。（デフォルト: 1024） | INT | はい（`size` が "custom" の場合） | 256 〜 2560, ステップ 16 |
| `height` | 出力高さ。総ピクセル面積は 512x512 から 2560x2560 の間である必要があります。アスペクト比は 1:8 から 8:1 の間である必要があります。（デフォルト: 1024） | INT | はい（`size` が "custom" の場合） | 256 〜 2560, ステップ 16 |

### 制約事項

- テキストプロンプトは必須であり、少なくとも1文字以上含む必要があります。
- 最大3枚の参照画像がサポートされています。それ以上提供された場合はエラーが発生します（バッチ入力は画像ごとに1回としてカウントされます）。
- `size` が "custom" に設定されている場合、明示的な幅と高さの値を指定する必要があり、検証されます。総ピクセル面積は 262,144（512x512）から 6,553,600（2560x2560）ピクセルの間で、アスペクト比は 1:8 から 8:1 の間である必要があります。
- `size` が "match input" に設定されている場合、最初の参照画像の寸法が使用されるため、少なくとも1枚の参照画像が必要です。寸法は、サポートされている面積とアスペクト比の範囲に収まるようにスケーリングされます。
- `size` が "auto" に設定されている場合、モデルは入力のアスペクト比を維持しながら出力サイズを選択します。
- プロンプト内の参照は、入力順に番号が付けられた @Image1、@Image2、@Image3 を使用します。接続された画像の数を超えるインデックスへの参照はエラーになります。タグは単語境界でのみ認識されるため、user@image1.com のようなアドレスは変更されません。
- 入力参照画像は、API に送信される前に最大 2048x2048 ピクセルに縮小されます。
