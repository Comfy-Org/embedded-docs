# Qwen Image 3 編集

このノードは、Qwen-Image 3.0 モデルを使用して、テキストプロンプトに従って最大3枚の参照画像を編集または合成します。モデルを選択し、プロンプトと参照画像を指定すると、1枚以上の生成画像が返されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル。この選択には、テキストプロンプト、最大3枚の参照画像入力、およびオプションのネガティブプロンプトも含まれます。 | DYNAMIC_COMBO | 必須 | "qwen-image-3.0-pro"<br>"qwen-image-3.0" |
| `size` | 出力解像度。"match input" は最初の参照画像のサイズを再利用し、"auto" は同じアスペクト比でモデルがサイズを選択し、"custom" は明示的な幅と高さを設定します。 | DYNAMIC_COMBO | 必須 | "match input"<br>"auto"<br>"custom" |
| `n` | 生成する画像の数。バッチとして返されます。（デフォルト: 1） | INT | 任意 | 1 〜 6 |
| `seed` | 生成に使用するシード。（デフォルト: 42） | INT | 任意 | 0 〜 2147483647 |
| `prompt_extend` | AI支援によるプロンプト拡張を行うかどうか。（デフォルト: True） | BOOLEAN | 任意 | True<br>False |
| `watermark` | 結果にAI生成透かしを追加するかどうか。（デフォルト: False） | BOOLEAN | 任意 | True<br>False |

| `height` | 出力高さ。総ピクセル面積は 512x512 から 2560x2560 の間、アスペクト比は 1:8 から 8:1 の間である必要があります。（デフォルト: 1024） | INT | 必須（`size` が "custom" の場合） | 256 〜 2560, step 16 |

### 制約事項

- テキストプロンプトは必須で、少なくとも1文字以上含む必要があります。
- 参照画像は最大3枚までサポートされます。それ以上指定するとエラーが発生します（バッチ入力は画像1枚ごとに1回としてカウントされます）。
- `size` が "custom" の場合、明示的な幅と高さの指定が必須となり、検証されます。総ピクセル面積は 262,144（512x512）から 6,553,600（2560x2560）ピクセルの間、アスペクト比は 1:8 から 8:1 の間である必要があります。
- `size` が "match input" の場合、最初の参照画像の寸法が使用されるため、参照画像が少なくとも1枚必要です。寸法は、対応可能な面積とアスペクト比の範囲に合わせてスケーリングされます。
- `size` が "auto" の場合、モデルは入力のアスペクト比を維持しながら出力サイズを選択します。
- プロンプト内の参照は @Image1、@Image2、@Image3 を使用し、入力順に番号付けされます。接続されている画像数を超えるインデックスを参照するとエラーが発生します。タグは単語境界でのみ認識されるため、user@image1.com のようなアドレスは変更されません。
- 入力参照画像は、API に送信される前に最大 2048x2048 ピクセルに縮小されます。PNG エンコードが API のサイズ上限を超える場合は、代わりに JPEG エンコードが使用されます。
