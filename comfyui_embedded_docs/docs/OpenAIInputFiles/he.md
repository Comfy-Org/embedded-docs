# OpenAI ChatGPT קבצי קלט

טוען ומפרמט קובצי קלט עבור OpenAI API. צומת זה מכין קובצי טקסט (.txt) וקובצי PDF (.pdf) לשילוב כקלטי הקשר עבור צומת OpenAI Chat. המודל של OpenAI יקרא את הקבצים בעת יצירת תגובה. ניתן לשרשר יחד מספר צמתי OpenAI Input Files כדי לכלול מספר קבצים בהודעה אחת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `file` | קובצי קלט שיש לכלול כהקשר עבור המודל. לעת עתה מקבל רק קובצי טקסט (.txt) וקובצי PDF (.pdf). הקבצים חייבים להיות קטנים מ-32MB. | COMBO | כן | אפשרויות מרובות זמינות (כל קובצי ה-.txt וה-.pdf בספריית הקלט שגודלם קטן מ-32MB) |
| `OPENAI_INPUT_FILES` | קובץ/קבצים נוספים אופציונליים לצירוף באצווה יחד עם הקובץ הנטען מצומת זה. מאפשר שרשרור של קובצי קלט כך שהודעה אחת יכולה לכלול מספר קובצי קלט. | OPENAI_INPUT_FILES | לא | N/A |

**מגבלות קבצים:**

- נתמכים רק קובצי .txt ו-.pdf
- גודל קובץ מקסימלי: 32MB
- הקבצים נטענים מספריית הקלט של ComfyUI
