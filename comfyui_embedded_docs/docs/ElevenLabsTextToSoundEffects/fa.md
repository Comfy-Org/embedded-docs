# تبدیل متن به افکت صوتی ElevenLabs

گره **ElevenLabs Text to Sound Effects** افکت‌های صوتی را از روی یک توصیف متنی تولید می‌کند. این گره از API سرویس ElevenLabs برای ساخت افکت‌های صوتی بر اساس پرامپت شما استفاده می‌کند و به شما امکان می‌دهد مدت‌زمان، رفتار حلقه‌زنی، و میزان نزدیکی صدا به متن را کنترل کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید افکت صوتی. در حال حاضر فقط یک مدل موجود است: `eleven_sfx_v2`. | DYNAMIC_COMBO | بله | `"eleven_sfx_v2"` |
| `text` | توصیف متنی افکت صوتی که باید تولید شود. (پیش‌فرض: خالی) | STRING | بله | N/A |
| `output_format` | قالب خروجی صوتی. | COMBO | بله | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### ورودی‌های eleven_sfx_v2

این پارامترها وقتی نمایش داده می‌شوند که مدل `eleven_sfx_v2` انتخاب شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `duration` | مدت‌زمان صدای تولیدشده بر حسب ثانیه. (پیش‌فرض: 5.0) | FLOAT | بله | 0.5 تا 30.0 |
| `loop` | ایجاد یک افکت صوتی با حلقه‌زنی نرم. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `prompt_influence` | میزان نزدیکی تولید به پرامپت. مقادیر بالاتر باعث می‌شوند صدا متن را دقیق‌تر دنبال کند. (پیش‌فرض: 0.3) | FLOAT | بله | 0.0 تا 1.0 |

**نکته:** پارامتر `text` نباید خالی باشد؛ این پارامتر پیش از ارسال درخواست تولید صدا اعتبارسنجی می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | فایل صوتی افکت تولیدشده. | AUDIO |
