# تبدیل متن به افکت صوتی ElevenLabs

گره **ElevenLabs Text to Sound Effects** افکت‌های صوتی را از روی یک توصیف متنی تولید می‌کند. این گره از API سرویس ElevenLabs برای ساخت افکت‌های صوتی بر اساس پرامپت شما استفاده می‌کند و به شما امکان می‌دهد مدت‌زمان، رفتار حلقه‌زنی، و میزان نزدیکی صدا به متن را کنترل کنید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل مورد استفاده برای تولید افکت صوتی. دو مدل موجود است: `eleven_sfx_v3` (پیش‌فرض) و `eleven_sfx_v2`. | DYNAMIC_COMBO | بله | `"eleven_sfx_v3"`<br>`"eleven_sfx_v2"` |
| `text` | توصیف متنی افکت صوتی که باید تولید شود. آن را به انگلیسی و حداکثر 450 کاراکتر بنویسید؛ پرامپت‌های زبان‌های دیگر اغلب به‌جای تبدیل شدن به صدا، بلند خوانده می‌شوند. (پیش‌فرض: خالی) | STRING | بله | 1 تا 450 کاراکتر |
| `output_format` | قالب خروجی صوتی. | COMBO | بله | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### ورودی‌های eleven_sfx_v3 و eleven_sfx_v2

این پارامترها وقتی نمایش داده می‌شوند که یکی از دو مدل انتخاب شده باشد؛ هر دو مدل تنظیمات یکسانی دارند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `duration` | مدت‌زمان صدای تولیدشده بر حسب ثانیه. (پیش‌فرض: 5.0) | FLOAT | بله | 0.5 تا 30.0 |
| `loop` | ایجاد یک افکت صوتی با حلقه‌زنی نرم. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `prompt_influence` | میزان نزدیکی تولید به پرامپت. مقادیر بالاتر باعث می‌شوند صدا متن را دقیق‌تر دنبال کند. (پیش‌فرض: 0.3) | FLOAT | بله | 0.0 تا 1.0 |

**نکته:** پارامتر `text` باید بین 1 تا 450 کاراکتر باشد؛ این پارامتر پیش از ارسال درخواست تولید صدا اعتبارسنجی می‌شود.
