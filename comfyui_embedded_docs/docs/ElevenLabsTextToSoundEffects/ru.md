# ElevenLabs Текст в звуковые эффекты

Узел ElevenLabs Text to Sound Effects генерирует звуковые эффекты на основе текстового описания. Он использует API ElevenLabs для создания звуковых эффектов по вашему запросу, позволяя контролировать длительность, зацикливание и степень соответствия звука тексту.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель для генерации звуковых эффектов. В настоящее время доступна только одна модель: `eleven_sfx_v2`. | DYNAMIC_COMBO | Да | `"eleven_sfx_v2"` |
| `text` | Текстовое описание звукового эффекта для генерации. (по умолчанию: пусто) | STRING | Да | N/A |
| `output_format` | Формат аудиовыхода. | COMBO | Да | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### Входы eleven_sfx_v2

Эти параметры отображаются при выборе модели `eleven_sfx_v2`.

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `duration` | Длительность генерируемого звука в секундах. (по умолчанию: 5.0) | FLOAT | Да | 0.5–30.0 |
| `loop` | Создать плавно зацикленный звуковой эффект. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `prompt_influence` | Насколько точно генерация следует подсказке. Более высокие значения делают звук более соответствующим тексту. (по умолчанию: 0.3) | FLOAT | Да | 0.0–1.0 |

**Примечание:** Параметр `text` не должен быть пустым; он проверяется перед отправкой запроса на генерацию звука.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированный аудиофайл звукового эффекта. | AUDIO |
