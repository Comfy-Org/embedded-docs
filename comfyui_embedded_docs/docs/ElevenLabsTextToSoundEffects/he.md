# ElevenLabsTextToSoundEffects

הצומת ElevenLabs Text to Sound Effects מייצר אפקטי קול אודיו מתוך תיאור טקסטואלי. הוא משתמש ב־ElevenLabs API כדי ליצור אפקטי קול על בסיס ההנחיה שלך, ומאפשר לשלוט במשך, בהתנהגות הלופ ובמידת ההתאמה של הצליל לטקסט.

## קלטים

### קלטים משותפים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל שישמש ליצירת אפקט קול. נכון לעכשיו זמין מודל אחד בלבד: `eleven_sfx_v2`. | DYNAMIC_COMBO | כן | `"eleven_sfx_v2"` |
| `text` | תיאור טקסטואלי של אפקט הקול שיש ליצור. (ברירת מחדל: ריק) | STRING | כן | N/A |
| `output_format` | פורמט פלט אודיו. | COMBO | כן | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### קלטים של eleven_sfx_v2

פרמטרים אלה מוצגים כאשר המודל `eleven_sfx_v2` נבחר.

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `duration` | משך הצליל שנוצר בשניות. (ברירת מחדל: 5.0) | FLOAT | כן | 0.5 עד 30.0 |
| `loop` | יצירת אפקט קול עם לופ חלק. (ברירת מחדל: False) | BOOLEAN | לא | True<br>False |
| `prompt_influence` | עד כמה היצירה עוקבת אחרי ההנחיה. ערכים גבוהים יותר גורמים לצליל לעקוב אחרי הטקסט בצורה צמודה יותר. (ברירת מחדל: 0.3) | FLOAT | כן | 0.0 עד 1.0 |

**הערה:** הפרמטר `text` לא יכול להיות ריק; הוא נבדק לפני שליחת בקשת יצירת הצליל.
