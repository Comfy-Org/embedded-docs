# Get Audio Latent Size

يقرأ كامنًا صوتيًا ويعيد طوله وعدد قنوات الصوت وحجم الدفعة، بحيث يمكن إعادة استخدام هذه القيم دون فك ترميز الصوت. استخدمه لتحديد حجم أقنعة الضوضاء أو لمطابقة أطوال الصوت والفيديو قبل أخذ العينات. تُطبع القيم المقيسة أيضًا على العقدة نفسها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `latent` | الكامن الصوتي أو الكامن الصوتي/المرئي المراد فحصه. عندما يحتوي الكامن على عدة تدفقات، يتم قياس التدفق الصوتي. | LATENT | نعم | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `length` | طول الكامن الصوتي، بوحدات خلايا الكامن وليس بعينات الصوت. | INT |
| `audio_channels` | عدد قنوات الصوت. الكوامن التي لا تحتوي على بعد قنوات الصوت تُبلغ عن قناة واحدة. | INT |
| `batch_size` | عدد الكوامن في الدفعة. | INT |
