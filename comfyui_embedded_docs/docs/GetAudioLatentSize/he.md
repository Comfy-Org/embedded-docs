# Get Audio Latent Size

קורא לטנט אודיו ומחזיר את אורכו, מספר ערוצי האודיו וגודל האצווה, כך שניתן לעשות שימוש חוזר בערכים אלה בלי לפענח את האודיו. השתמשו בו כדי לקבוע את גודל מסכות הרעש או להתאים אורכים של אודיו ווידאו לפני הדגימה. הערכים הנמדדים מודפסים גם על הצומת עצמו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `latent` | הלטנט של אודיו או אודיו/וידאו שיש לבדוק. כאשר הלטנט מכיל כמה זרמים, נמדד זרם האודיו. | LATENT | כן | - |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `length` | אורכו של לטנט האודיו, ביחידות של תאי לטנט ולא בדגימות אודיו. | INT |
| `audio_channels` | מספר ערוצי האודיו. לטנטים ללא ממד ערוצי אודיו מדווחים על ערוץ אחד. | INT |
| `batch_size` | מספר הלטנטים באצווה. | INT |
