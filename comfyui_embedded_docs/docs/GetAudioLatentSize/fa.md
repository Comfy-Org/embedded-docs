# Get Audio Latent Size

یک latent صوتی را می‌خواند و طول، تعداد کانال‌های صوتی و اندازه دسته (batch size) آن را برمی‌گرداند تا بتوان این مقادیر را بدون رمزگشایی صدا دوباره استفاده کرد. از آن برای تعیین اندازه ماسک‌های نویز یا تطبیق طول صدا و تصویر پیش از نمونه‌گیری استفاده کنید. مقادیر اندازه‌گیری‌شده همچنین روی خود گره چاپ می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `latent` | latent صوتی یا صوتی/تصویری که باید بررسی شود. وقتی latent شامل چندین جریان باشد، جریان صوتی اندازه‌گیری می‌شود. | LATENT | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `length` | طول latent صوتی، بر حسب سلول‌های latent و نه نمونه‌های صوتی. | INT |
| `audio_channels` | تعداد کانال‌های صوتی. latentهای بدون بُعد کانال صوتی، یک کانال گزارش می‌کنند. | INT |
| `batch_size` | تعداد latentها در دسته. | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetAudioLatentSize/fa.md)
