# Get Audio Latent Size

Считывает аудиолатент и возвращает его длину, количество аудиоканалов и размер пакета, чтобы эти значения можно было повторно использовать без декодирования аудио. Используйте его, чтобы задать размер шумовых масок или согласовать длину аудио и видео перед сэмплированием. Измеренные значения также отображаются на самом узле.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `latent` | Аудио- или аудио/видеолатент для проверки. Если латент содержит несколько потоков, измеряется аудиопоток. | LATENT | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `length` | Длина аудиолатента, в латентных ячейках, а не в аудиосэмплах. | INT |
| `audio_channels` | Количество аудиоканалов. Латенты без размерности аудиоканалов сообщают об одном канале. | INT |
| `batch_size` | Количество латентов в пакете. | INT |
