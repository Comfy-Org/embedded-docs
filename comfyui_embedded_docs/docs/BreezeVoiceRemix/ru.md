# Breeze Voice Remix

Создаёт изменённую копию голоса на том же языке — либо по текстовому описанию изменения, либо по именованному пресету. Копия сохраняется в вашей учётной записи и возвращается вместе с аудиопредпросмотром.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `voice` | Голос Breeze, который нужно изменить. | BREEZE_VOICE | Да | - |
| `change` | `custom` описывает изменение текстом, `preset` выбирает именованное изменение. По умолчанию: `"custom"`. | DYNAMIC_COMBO | Да | `"custom"`<br>`"preset"` |
| `strength` | Более высокие значения сильнее изменяют голос. По умолчанию: 4.0. | FLOAT | Нет | от 1.0 до 10.0 (шаг: 0.1) |
| `seed` | Управляет тем, будет ли узел запускаться повторно; результаты недетерминированы независимо от значения seed. По умолчанию: 42. | INT | Нет | от 0 до 2147483647 |

### Входы изменения "custom"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Как должен измениться голос, например сделать его более старым и хриплым. По умолчанию: пусто. | STRING | Да | Многострочный текст |

### Входы изменения "preset"

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `preset` | Именованное изменение, сгруппированное по возрасту, полу, высоте тона, темпу, энергии и эмоции. | COMBO | Да | Доступно несколько вариантов |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `voice` | Изменённая копия голоса. | BREEZE_VOICE |
| `preview` | Аудиопредпросмотр ремикшированного голоса. | AUDIO |
