# WanMoveTracksFromCoords

WanMoveTracksFromCoords ノードは、座標の JSON 形式の文字列からモーショントラックを生成します。座標データを他の動画処理ノードで使用できるテンソル形式に変換し、オプションでマスクを適用して時間経過に伴うトラックの可視性を制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `track_coords` | トラックの座標データを含む JSON 形式の文字列です。デフォルト値は空のリスト（`"[]"`）です。 | STRING | いいえ | N/A |
| `track_mask` | オプションのマスクです。指定すると、ノードはこれを使用して各フレームの各トラックの可視性を判定します。指定しない場合、すべてのトラックがすべてのフレームで可視と見なされます。 | MASK | いいえ | N/A |

**メモ：** `track_coords` 入力は特定の JSON 構造を期待します。トラックのリストであり、各トラックはフレームのリストで、各フレームは `x` と `y` 座標を持つオブジェクトです。フレーム数はすべてのトラックで一貫している必要があります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `tracks` | 生成されたトラックデータ。各トラックのパス座標と可視性情報を含みます。 | TRACKS |
| `track_length` | 生成されたトラックの総フレーム数。 | INT |
