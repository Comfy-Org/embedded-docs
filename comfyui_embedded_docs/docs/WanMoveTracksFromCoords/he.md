# WanMoveTracksFromCoords

הצומת WanMoveTracksFromCoords יוצר מסלולי תנועה ממחרוזת קואורדינטות בפורמט JSON. הוא ממיר את נתוני הקואורדינטות לפורמט מסלולים שניתן להשתמש בו בצומתי עיבוד וידאו אחרים, ויכול באופן אופציונלי להחיל מסכה כדי לשלוט בנראות המסלולים לאורך הזמן.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `track_coords` | מחרוזת בפורמט JSON המכילה את נתוני הקואורדינטות עבור המסלולים. ערך ברירת המחדל הוא רשימה ריקה (`"[]"`). זהו קלט כפוי, ולכן יש לחבר אותו בממשק המשתמש. | STRING | לא | N/A |
| `track_mask` | מסכה אופציונלית. כאשר היא מסופקת, הצומת משתמש בה כדי לקבוע את נראות המסלולים בכל פריים: המסלולים נראים בפריימים שבהם המסכה מכילה פיקסל שאינו אפס. כאשר היא לא מסופקת, כל המסלולים נראים בכל הפריימים. | MASK | לא | N/A |

**הערה:** הקלט `track_coords` מצפה למבנה JSON מסוים. עליו להיות רשימה של מסלולים, כאשר כל מסלול הוא רשימה של פריימים, וכל פריים הוא אובייקט עם קואורדינטות `x` ו-`y`. מספר הפריימים חייב להיות עקבי בכל המסלולים, ולפחות מסלול אחד חייב להיות מסופק.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `tracks` | נתוני המסלולים שנוצרו, הכוללים את קואורדינטות הנתיב ומידע הנראות עבור כל מסלול. | TRACKS |
| `track_length` | המספר הכולל של הפריימים במסלולים שנוצרו. | INT |
