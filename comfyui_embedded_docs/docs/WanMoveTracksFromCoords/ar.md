# WanMoveTracksFromCoords

```markdown
تنشئ عقدة WanMoveTracksFromCoords مسارات حركة من سلسلة JSON منسقة للإحداثيات. تحوّل بيانات الإحداثيات إلى تنسيق موتر يمكن استخدامه بواسطة عُقد معالجة الفيديو الأخرى، ويمكنها اختياريًا تطبيق قناع للتحكم في رؤية المسارات بمرور الوقت.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `track_coords` | سلسلة نصية منسقة بصيغة JSON تحتوي على بيانات إحداثيات المسارات. القيمة الافتراضية هي قائمة فارغة (`"[]"`). | STRING | لا | N/A |
| `track_mask` | قناع اختياري. عند توفيره، تستخدمه العقدة لتحديد رؤية كل مسار لكل إطار. عندما لا يتم توفيره، تُعتبر جميع المسارات مرئية في كل إطار. | MASK | لا | N/A |

**ملاحظة:** يتوقع مُدخل `track_coords` بنية JSON محددة. يجب أن يكون قائمة من المسارات، حيث يكون كل مسار قائمة من الإطارات، وكل إطار عبارة عن كائن بإحداثيات `x` و `y`. يجب أن يكون عدد الإطارات متسقًا عبر جميع المسارات.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `tracks` | بيانات المسارات المُولّدة، وتحتوي على إحداثيات المسار ومعلومات الرؤية لكل مسار. | TRACKS |
| `track_length` | إجمالي عدد الإطارات في المسارات المُولّدة. | INT |
```
