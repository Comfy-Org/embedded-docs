# WanMoveTracksFromCoords

گره WanMoveTracksFromCoords مسیرهای حرکتی را از یک رشته مختصات با قالب JSON ایجاد می‌کند. این گره داده‌های مختصات را به قالب مسیری تبدیل می‌کند که می‌تواند توسط سایر گره‌های پردازش ویدئو استفاده شود، و به‌صورت اختیاری می‌تواند ماسکی را برای کنترل قابلیت مشاهده مسیرها در طول زمان اعمال کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `track_coords` | یک رشته با قالب JSON که داده‌های مختصات مسیرها را در خود دارد. مقدار پیش‌فرض یک فهرست خالی (`"[]"`) است. این ورودی اجباری است، بنابراین باید در رابط کاربری متصل شود. | STRING | خیر | N/A |
| `track_mask` | یک ماسک اختیاری. وقتی ارائه شود، گره از آن برای تعیین قابلیت مشاهده مسیرها در هر فریم استفاده می‌کند: مسیرها در فریم‌هایی قابل مشاهده هستند که ماسک هر پیکسل غیرصفر داشته باشد. وقتی ارائه نشود، همه مسیرها در همه فریم‌ها قابل مشاهده هستند. | MASK | خیر | N/A |

**توجه:** ورودی `track_coords` انتظار یک ساختار JSON مشخص را دارد. باید فهرستی از مسیرها باشد، که هر مسیر فهرستی از فریم‌ها است و هر فریم شیئی با مختصات `x` و `y` است. تعداد فریم‌ها باید در همه مسیرها یکسان باشد و حداقل یک مسیر باید ارائه شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `tracks` | داده‌های مسیر تولیدشده، شامل مختصات مسیر و اطلاعات قابلیت مشاهده برای هر مسیر. | TRACKS |
| `track_length` | تعداد کل فریم‌ها در مسیرهای تولیدشده. | INT |
