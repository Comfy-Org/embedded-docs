# WanMoveTracksFromCoords

گره WanMoveTracksFromCoords مسیرهای حرکتی را از یک رشته‌ی JSON حاوی مختصات ایجاد می‌کند. این گره داده‌های مختصات را به قالب تنسور تبدیل می‌کند که می‌تواند توسط سایر گره‌های پردازش ویدیو استفاده شود، و به‌صورت اختیاری می‌تواند ماسکی برای کنترل قابلیت مشاهده‌ی مسیرها در طول زمان اعمال کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `track_coords` | یک رشته با فرمت JSON حاوی داده‌های مختصات برای مسیرها. مقدار پیش‌فرض یک لیست خالی (`"[]"`) است. | STRING | خیر | N/A |
| `track_mask` | یک ماسک اختیاری. وقتی ارائه شود، گره از آن برای تعیین قابلیت مشاهده‌ی هر مسیر در هر فریم استفاده می‌کند. وقتی ارائه نشود، همه‌ی مسیرها برای همه‌ی فریم‌ها قابل مشاهده در نظر گرفته می‌شوند. | MASK | خیر | N/A |

**نکته:** ورودی `track_coords` انتظار ساختار JSON خاصی دارد. باید لیستی از مسیرها باشد، که هر مسیر شامل لیستی از فریم‌هاست، و هر فریم یک شیء با مختصات `x` و `y` است. تعداد فریم‌ها باید در همه‌ی مسیرها یکسان باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `tracks` | داده‌های مسیر تولیدشده، شامل مختصات مسیر و اطلاعات قابلیت مشاهده برای هر مسیر. | TRACKS |
| `track_length` | تعداد کل فریم‌ها در مسیرهای تولیدشده. | INT |
