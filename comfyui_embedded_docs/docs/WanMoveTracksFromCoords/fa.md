# WanMoveTracksFromCoords

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `track_coords` | رشته‌ای با فرمت JSON شامل داده‌های مختصات مسیرها. مقدار پیش‌فرض یک لیست خالی (`"[]"`) است. این ورودی اجباری است و باید در رابط کاربری متصل شود. | STRING | خیر | N/A |
| `track_mask` | یک ماسک اختیاری. در صورت ارائه، گره از آن برای تعیین دید مسیرها در هر فریم استفاده می‌کند: مسیرها در فریم‌هایی قابل مشاهده هستند که ماسک شامل هر پیکسل غیرصفر باشد. در صورت عدم ارائه، همه مسیرها در همه فریم‌ها قابل مشاهده هستند. | MASK | خیر | N/A |

**توجه:** ورودی `track_coords` ساختار JSON خاصی را انتظار دارد. این ورودی باید لیستی از مسیرها باشد که هر مسیر شامل لیستی از فریم‌ها است و هر فریم یک شیء با مختصات `x` و `y` می‌باشد. تعداد فریم‌ها باید در همه مسیرها یکسان باشد و حداقل یک مسیر باید ارائه شود.
