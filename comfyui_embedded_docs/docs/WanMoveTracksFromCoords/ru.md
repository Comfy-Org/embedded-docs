# WanMoveTracksFromCoords

Узел WanMoveTracksFromCoords создаёт треки движения из строки координат в формате JSON. Он преобразует данные координат в тензорный формат, который может использоваться другими узлами обработки видео, и может дополнительно применять маску для управления видимостью треков с течением времени.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `track_coords` | Строка в формате JSON, содержащая данные координат для треков. Значение по умолчанию — пустой список (`"[]"`). Этот вход является принудительным, поэтому он должен быть подключён в интерфейсе. | STRING | Нет | N/A |
| `track_mask` | Необязательная маска. Если она задана, узел использует её для определения видимости треков по кадрам: треки видны в кадрах, где маска содержит любой ненулевой пиксель. Если маска не задана, все треки видны во всех кадрах. | MASK | Нет | N/A |

**Примечание:** Вход `track_coords` ожидает определённую структуру JSON. Это должен быть список треков, где каждый трек — список кадров, а каждый кадр — объект с координатами `x` и `y`. Количество кадров должно быть одинаковым для всех треков, и должен быть предоставлен как минимум один трек.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `tracks` | Сгенерированные данные треков, содержащие координаты пути и информацию о видимости для каждого трека. | TRACKS |
| `track_length` | Общее количество кадров в сгенерированных треках. | INT |
