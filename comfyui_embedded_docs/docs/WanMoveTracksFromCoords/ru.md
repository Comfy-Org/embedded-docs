# WanMoveTracksFromCoords

Узел WanMoveTracksFromCoords создает треки движения из строки координат в формате JSON. Он преобразует данные координат в тензорный формат, который может использоваться другими узлами обработки видео, и при необходимости может применять маску для управления видимостью треков во времени.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `track_coords` | Строка в формате JSON, содержащая координатные данные для треков. Значение по умолчанию — пустой список (`"[]"`). | STRING | Нет | N/A |
| `track_mask` | Необязательная маска. Если она задана, узел использует её для определения видимости каждого трека в каждом кадре. Если маска не задана, все треки считаются видимыми в каждом кадре. | MASK | Нет | N/A |

**Примечание:** Вход `track_coords` ожидает определенную JSON-структуру. Это должен быть список треков, где каждый трек — список кадров, а каждый кадр — объект с координатами `x` и `y`. Количество кадров должно быть одинаковым для всех треков.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `tracks` | Сгенерированные данные треков, содержащие координаты пути и информацию о видимости для каждого трека. | TRACKS |
| `track_length` | Общее количество кадров в сгенерированных треках. | INT |
