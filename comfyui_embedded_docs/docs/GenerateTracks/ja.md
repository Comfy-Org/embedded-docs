# GenerateTracks

`GenerateTracks` ノードは、動画生成用の複数の平行なモーション軌跡を作成します。始点から終点までの主経路を定義し、その経路に平行で等間隔に配置された一連のトラックを生成します。経路の形状（直線またはベジェ曲線）、移動速度、トラックを表示するフレームを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `width` | 動画フレームの幅（ピクセル単位）。デフォルト値は 832 です。 | INT | はい | 16 - 4096 |
| `height` | 動画フレームの高さ（ピクセル単位）。デフォルト値は 480 です。 | INT | はい | 16 - 4096 |
| `start_x` | 開始位置の正規化された X 座標（0-1）。デフォルト値は 0.0 です。 | FLOAT | はい | 0.0 - 1.0 |
| `start_y` | 開始位置の正規化された Y 座標（0-1）。デフォルト値は 0.0 です。 | FLOAT | はい | 0.0 - 1.0 |
| `end_x` | 終了位置の正規化された X 座標（0-1）。デフォルト値は 1.0 です。 | FLOAT | はい | 0.0 - 1.0 |
| `end_y` | 終了位置の正規化された Y 座標（0-1）。デフォルト値は 1.0 です。 | FLOAT | はい | 0.0 - 1.0 |
| `num_frames` | トラック位置を生成するフレームの総数。デフォルト値は 81 です。 | INT | はい | 1 - 1024 |
| `num_tracks` | 生成する平行トラックの数。デフォルト値は 5 です。 | INT | はい | 1 - 100 |
| `track_spread` | トラック間の正規化された距離。トラックは移動方向に対して垂直に配置されます。デフォルト値は 0.025 です。 | FLOAT | はい | 0.0 - 1.0 |
| `bezier` | 中間点を制御点として使用するベジェ曲線経路を有効にします。デフォルト値は False です。 | BOOLEAN | はい | True / False |
| `mid_x` | ベジェ曲線の正規化された X 制御点。`bezier` が有効な場合にのみ使用されます。デフォルト値は 0.5 です。 | FLOAT | はい | 0.0 - 1.0 |
| `mid_y` | ベジェ曲線の正規化された Y 制御点。`bezier` が有効な場合にのみ使用されます。デフォルト値は 0.5 です。 | FLOAT | はい | 0.0 - 1.0 |
| `interpolation` | 経路に沿った移動のタイミング／速度を制御します。デフォルト値は `"linear"` です。`"constant"` の場合、すべてのポイントは開始位置に留まります。 | COMBO | はい | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | 表示フレームを示すオプションのマスク。 | MASK | いいえ | - |

**注：** `mid_x` と `mid_y` パラメータは、`bezier` パラメータが `True` に設定されている場合にのみ使用されます。`bezier` が `False` の場合、経路は始点から終点までの直線になります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `TRACKS` | 生成された経路座標と、全フレームにわたる全トラックの可視情報を含むトラックオブジェクト。 | TRACKS |
| `track_length` | トラックが生成されたフレーム数。入力の `num_frames` と一致します。 | INT |
