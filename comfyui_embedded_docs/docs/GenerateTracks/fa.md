# تولید مسیرها

گره `GenerateTracks` چند مسیر حرکتی موازی (track) برای تولید ویدیو ایجاد می‌کند. این گره یک مسیر اصلی از موقعیت شروع تا موقعیت پایان تعریف می‌کند و سپس مجموعه‌ای از مسیرهای موازی با این مسیر را با فاصله‌های مساوی تولید می‌کند. می‌توانید شکل مسیر (خط مستقیم یا منحنی Bezier)، سرعت حرکت در طول آن و فریم‌هایی را که مسیرها در آن‌ها قابل مشاهده هستند کنترل کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `عرض` | عرض فریم ویدیو بر حسب پیکسل. مقدار پیش‌فرض 832 است. | INT | بله | 16 - 4096 |
| `ارتفاع` | ارتفاع فریم ویدیو بر حسب پیکسل. مقدار پیش‌فرض 480 است. | INT | بله | 16 - 4096 |
| `مختصات X شروع` | مختصات X نرمال‌شده (0-1) برای موقعیت شروع. مقدار پیش‌فرض 0.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `مختصات Y شروع` | مختصات Y نرمال‌شده (0-1) برای موقعیت شروع. مقدار پیش‌فرض 0.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `مختصات X پایان` | مختصات X نرمال‌شده (0-1) برای موقعیت پایان. مقدار پیش‌فرض 1.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `مختصات Y پایان` | مختصات Y نرمال‌شده (0-1) برای موقعیت پایان. مقدار پیش‌فرض 1.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `تعداد فریم‌ها` | تعداد کل فریم‌هایی که برای آن‌ها موقعیت مسیرها تولید می‌شود. مقدار پیش‌فرض 81 است. | INT | بله | 1 - 1024 |
| `تعداد مسیرها` | تعداد مسیرهای موازی که تولید می‌شوند. مقدار پیش‌فرض 5 است. | INT | بله | 1 - 100 |
| `فاصله مسیرها` | فاصله نرمال‌شده بین مسیرها. مسیرها عمود بر جهت حرکت پخش می‌شوند. مقدار پیش‌فرض 0.025 است. | FLOAT | بله | 0.0 - 1.0 |
| `Bezier` | فعال‌سازی مسیر منحنی Bezier با استفاده از نقطه میانی به عنوان نقطه کنترل. مقدار پیش‌فرض False است. | BOOLEAN | بله | True / False |
| `کنترل X میانی` | مختصات X نرمال‌شده نقطه کنترل برای منحنی Bezier. فقط زمانی استفاده می‌شود که «bezier» فعال باشد. مقدار پیش‌فرض 0.5 است. | FLOAT | بله | 0.0 - 1.0 |
| `کنترل Y میانی` | مختصات Y نرمال‌شده نقطه کنترل برای منحنی Bezier. فقط زمانی استفاده می‌شود که «bezier» فعال باشد. مقدار پیش‌فرض 0.5 است. | FLOAT | بله | 0.0 - 1.0 |
| `درون‌یابی` | کنترل زمان‌بندی/سرعت حرکت در طول مسیر (پیش‌فرض: "linear"):<br>"linear" - سرعت ثابت<br>"ease_in" - آهسته شروع می‌شود و سرعت می‌گیرد<br>"ease_out" - سریع شروع می‌شود و کند می‌شود<br>"ease_in_out" - شتاب و کاهش سرعت نرم<br>"constant" - همه موقعیت‌ها را در نقطه شروع نگه می‌دارد | COMBO | بله | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `ماسک مسیر` | ماسک اختیاری برای نشان دادن فریم‌های قابل مشاهده. اگر ارائه شود، فریم‌هایی که ماسک در آن‌ها حداقل یک پیکسل غیر صفر دارد، برای همه مسیرها به عنوان قابل مشاهده علامت‌گذاری می‌شوند. | MASK | خیر | - |

**توجه:** پارامترهای `mid_x` و `mid_y` فقط زمانی استفاده می‌شوند که پارامتر `bezier` روی `True` تنظیم شده باشد. وقتی `bezier` برابر `False` باشد، مسیر یک خط مستقیم از نقطه شروع تا نقطه پایان است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
