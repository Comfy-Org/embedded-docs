# تولید مسیرها

گره `GenerateTracks` چند مسیر حرکتی موازی برای تولید ویدئو ایجاد می‌کند. این گره یک مسیر اصلی از نقطه شروع تا نقطه پایان تعریف می‌کند و سپس مجموعه‌ای از مسیرها را تولید می‌کند که به‌صورت موازی و با فاصله‌ای یکنواخت از این مسیر عبور می‌کنند. می‌توانید شکل مسیر (خط مستقیم یا منحنی بزیه)، سرعت حرکت در طول آن و فریم‌هایی را که مسیرها در آن‌ها قابل مشاهده هستند کنترل کنید.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `width` | عرض فریم ویدئو بر حسب پیکسل. مقدار پیش‌فرض 832 است. | INT | بله | 16 - 4096 |
| `height` | ارتفاع فریم ویدئو بر حسب پیکسل. مقدار پیش‌فرض 480 است. | INT | بله | 16 - 4096 |
| `start_x` | مختصات X نرمال‌شده (0-1) برای موقعیت شروع. مقدار پیش‌فرض 0.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `start_y` | مختصات Y نرمال‌شده (0-1) برای موقعیت شروع. مقدار پیش‌فرض 0.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `end_x` | مختصات X نرمال‌شده (0-1) برای موقعیت پایان. مقدار پیش‌فرض 1.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `end_y` | مختصات Y نرمال‌شده (0-1) برای موقعیت پایان. مقدار پیش‌فرض 1.0 است. | FLOAT | بله | 0.0 - 1.0 |
| `num_frames` | تعداد کل فریم‌هایی که موقعیت مسیرها برای آن‌ها تولید می‌شود. مقدار پیش‌فرض 81 است. | INT | بله | 1 - 1024 |
| `num_tracks` | تعداد مسیرهای موازی که تولید می‌شوند. مقدار پیش‌فرض 5 است. | INT | بله | 1 - 100 |
| `track_spread` | فاصله نرمال‌شده بین مسیرها. مسیرها به‌صورت عمود بر جهت حرکت پخش می‌شوند. مقدار پیش‌فرض 0.025 است. | FLOAT | بله | 0.0 - 1.0 |
| `bezier` | فعال‌سازی مسیر منحنی بزیه با استفاده از نقطه میانی به‌عنوان نقطه کنترل. مقدار پیش‌فرض False است. | BOOLEAN | بله | True / False |
| `mid_x` | نقطه کنترل X نرمال‌شده برای منحنی بزیه. فقط زمانی استفاده می‌شود که `bezier` فعال باشد. مقدار پیش‌فرض 0.5 است. | FLOAT | بله | 0.0 - 1.0 |
| `mid_y` | نقطه کنترل Y نرمال‌شده برای منحنی بزیه. فقط زمانی استفاده می‌شود که `bezier` فعال باشد. مقدار پیش‌فرض 0.5 است. | FLOAT | بله | 0.0 - 1.0 |
| `interpolation` | زمان‌بندی/سرعت حرکت در طول مسیر را کنترل می‌کند. مقدار پیش‌فرض "linear" است. با "constant"، همه نقاط در موقعیت شروع می‌مانند. | COMBO | بله | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | ماسک اختیاری برای نشان دادن فریم‌های قابل مشاهده. | MASK | خیر | - |

**توجه:** پارامترهای `mid_x` و `mid_y` فقط زمانی استفاده می‌شوند که پارامتر `bezier` روی `True` تنظیم شده باشد. وقتی `bezier` روی `False` باشد، مسیر یک خط مستقیم از نقطه شروع تا نقطه پایان است.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `TRACKS` | یک شیء tracks شامل مختصات مسیر تولیدشده و اطلاعات قابلیت مشاهده برای همه مسیرها در همه فریم‌ها. | TRACKS |
| `track_length` | تعداد فریم‌هایی که مسیرها برای آن‌ها تولید شده‌اند که با `num_frames` ورودی مطابقت دارد. | INT |
