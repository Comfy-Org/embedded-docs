# توليد المسارات

```markdown
تقوم عقدة `GenerateTracks` بإنشاء مسارات حركة متوازية متعددة لتوليد الفيديو. وهي تحدد مسارًا رئيسيًا من نقطة البداية إلى نقطة النهاية، ثم تولّد مجموعة من المسارات التي تعمل بالتوازي مع هذا المسار، متباعدة بشكل متساوٍ. يمكنك التحكم في شكل المسار (خط مستقيم أو منحنى بيزير)، وسرعة الحركة على طوله، والإطارات التي تكون فيها المسارات مرئية.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `width` | عرض إطار الفيديو بالبكسل. القيمة الافتراضية هي 832. | INT | نعم | 16 - 4096 |
| `height` | ارتفاع إطار الفيديو بالبكسل. القيمة الافتراضية هي 480. | INT | نعم | 16 - 4096 |
| `start_x` | الإحداثي السيني المعياري (0-1) لموضع البداية. القيمة الافتراضية هي 0.0. | FLOAT | نعم | 0.0 - 1.0 |
| `start_y` | الإحداثي الصادي المعياري (0-1) لموضع البداية. القيمة الافتراضية هي 0.0. | FLOAT | نعم | 0.0 - 1.0 |
| `end_x` | الإحداثي السيني المعياري (0-1) لموضع النهاية. القيمة الافتراضية هي 1.0. | FLOAT | نعم | 0.0 - 1.0 |
| `end_y` | الإحداثي الصادي المعياري (0-1) لموضع النهاية. القيمة الافتراضية هي 1.0. | FLOAT | نعم | 0.0 - 1.0 |
| `num_frames` | العدد الإجمالي للإطارات التي سيتم توليد مواقع المسارات لها. القيمة الافتراضية هي 81. | INT | نعم | 1 - 1024 |
| `num_tracks` | عدد المسارات المتوازية المراد توليدها. القيمة الافتراضية هي 5. | INT | نعم | 1 - 100 |
| `track_spread` | المسافة المعيارية بين المسارات. تتباعد المسارات بشكل عمودي على اتجاه الحركة. القيمة الافتراضية هي 0.025. | FLOAT | نعم | 0.0 - 1.0 |
| `bezier` | تفعيل مسار منحنى بيزير باستخدام نقطة المنتصف كنقطة تحكم. القيمة الافتراضية هي False. | BOOLEAN | نعم | True / False |
| `mid_x` | نقطة التحكم المعيارية على المحور السيني لمنحنى بيزير. تُستخدم فقط عند تفعيل `bezier`. القيمة الافتراضية هي 0.5. | FLOAT | نعم | 0.0 - 1.0 |
| `mid_y` | نقطة التحكم المعيارية على المحور الصادي لمنحنى بيزير. تُستخدم فقط عند تفعيل `bezier`. القيمة الافتراضية هي 0.5. | FLOAT | نعم | 0.0 - 1.0 |
| `interpolation` | يتحكم في توقيت/سرعة الحركة على طول المسار. القيمة الافتراضية هي "linear". مع القيمة "constant"، تبقى جميع النقاط عند موضع البداية. | COMBO | نعم | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | قناع اختياري لتحديد الإطارات المرئية. | MASK | لا | - |

**ملاحظة:** يُستخدم المعاملان `mid_x` و `mid_y` فقط عند ضبط المعامل `bezier` على `True`. وعندما يكون `bezier` هو `False`، يكون المسار خطًا مستقيمًا من نقطة البداية إلى نقطة النهاية.

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `TRACKS` | كائن مسارات يحتوي على إحداثيات المسار المُولَّدة ومعلومات الرؤية لجميع المسارات عبر جميع الإطارات. | TRACKS |
| `track_length` | عدد الإطارات التي تم توليد المسارات لها، وهو مطابق لمدخل `num_frames`. | INT |
```
