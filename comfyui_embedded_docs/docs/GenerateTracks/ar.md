# توليد المسارات

The `GenerateTracks` node creates multiple parallel motion paths (tracks) for video generation. It defines a main path from a start position to an end position, then generates a set of tracks that run parallel to this path, spaced evenly apart. You can control the shape of the path (straight line or Bezier curve), the speed of movement along it, and which frames the tracks are visible in.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `العرض` | عرض إطار الفيديو بالبكسل. القيمة الافتراضية هي 832. | INT | نعم | 16 - 4096 |
| `الارتفاع` | ارتفاع إطار الفيديو بالبكسل. القيمة الافتراضية هي 480. | INT | نعم | 16 - 4096 |
| `إحداثي X للبداية` | إحداثي X المُطبَّع (0-1) لموضع البداية. القيمة الافتراضية هي 0.0. | FLOAT | نعم | 0.0 - 1.0 |
| `إحداثي Y للبداية` | إحداثي Y المُطبَّع (0-1) لموضع البداية. القيمة الافتراضية هي 0.0. | FLOAT | نعم | 0.0 - 1.0 |
| `إحداثي X للنهاية` | إحداثي X المُطبَّع (0-1) لموضع النهاية. القيمة الافتراضية هي 1.0. | FLOAT | نعم | 0.0 - 1.0 |
| `إحداثي Y للنهاية` | إحداثي Y المُطبَّع (0-1) لموضع النهاية. القيمة الافتراضية هي 1.0. | FLOAT | نعم | 0.0 - 1.0 |
| `عدد الإطارات` | إجمالي عدد الإطارات التي سيتم توليد مواضع المسارات لها. القيمة الافتراضية هي 81. | INT | نعم | 1 - 1024 |
| `عدد المسارات` | عدد المسارات المتوازية المراد توليدها. القيمة الافتراضية هي 5. | INT | نعم | 1 - 100 |
| `توزيع المسارات` | المسافة المُطبَّعة بين المسارات. تنتشر المسارات بشكل عمودي على اتجاه الحركة. القيمة الافتراضية هي 0.025. | FLOAT | نعم | 0.0 - 1.0 |
| `منحنى بيزيه` | تفعيل مسار منحنى بيزيه باستخدام نقطة المنتصف كنقطة تحكم. القيمة الافتراضية هي False. | BOOLEAN | نعم | True / False |
| `إحداثي X للمنتصف` | إحداثي X المُطبَّع لنقطة التحكم في منحنى بيزيه. يُستخدم فقط عند تفعيل 'bezier'. القيمة الافتراضية هي 0.5. | FLOAT | نعم | 0.0 - 1.0 |
| `إحداثي Y للمنتصف` | إحداثي Y المُطبَّع لنقطة التحكم في منحنى بيزيه. يُستخدم فقط عند تفعيل 'bezier'. القيمة الافتراضية هي 0.5. | FLOAT | نعم | 0.0 - 1.0 |
| `الاستيفاء` | التحكم في توقيت/سرعة الحركة على طول المسار (الافتراضي: "linear"):<br>"linear" - سرعة ثابتة<br>"ease_in" - يبدأ ببطء ثم يتسارع<br>"ease_out" - يبدأ بسرعة ثم يتباطأ<br>"ease_in_out" - تسارع وتباطؤ سلس<br>"constant" - يُبقي جميع المواضع عند نقطة البداية | COMBO | نعم | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `قناع المسار` | قناع اختياري لتحديد الإطارات المرئية. إذا تم توفيره، يتم تمييز الإطارات التي يحتوي القناع فيها على أي بكسل غير صفري كمرئية لجميع المسارات. | MASK | لا | - |

**ملاحظة:** يتم استخدام المعاملين `mid_x` و`mid_y` فقط عندما يتم تعيين المعامل `bezier` إلى `True`. عندما يكون `bezier` هو `False`، يكون المسار خطًا مستقيمًا من نقطة البداية إلى نقطة النهاية.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
| --- | --- | --- |
