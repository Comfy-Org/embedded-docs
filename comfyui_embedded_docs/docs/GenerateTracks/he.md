# יצירת מסלולי וידאו

הצומת `GenerateTracks` יוצר מספר נתיבי תנועה מקבילים (מסלולים) להפקת וידאו. הוא מגדיר נתיב ראשי מנקודת התחלה לנקודת סיום, ולאחר מכן יוצר קבוצת מסלולים העוברים במקביל לנתיב זה, במרווחים אחידים. ניתן לשלוט בצורת הנתיב (קו ישר או עקומת בזייה), במהירות התנועה לאורכו, ובאילו פריימים המסלולים גלויים.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `width` | הרוחב של פריים הווידאו בפיקסלים. ערך ברירת המחדל הוא 832. | INT | כן | 16 - 4096 |
| `height` | הגובה של פריים הווידאו בפיקסלים. ערך ברירת המחדל הוא 480. | INT | כן | 16 - 4096 |
| `start_x` | קואורדינטת X מנורמלת (0-1) עבור נקודת ההתחלה. ערך ברירת המחדל הוא 0.0. | FLOAT | כן | 0.0 - 1.0 |
| `start_y` | קואורדינטת Y מנורמלת (0-1) עבור נקודת ההתחלה. ערך ברירת המחדל הוא 0.0. | FLOAT | כן | 0.0 - 1.0 |
| `end_x` | קואורדינטת X מנורמלת (0-1) עבור נקודת הסיום. ערך ברירת המחדל הוא 1.0. | FLOAT | כן | 0.0 - 1.0 |
| `end_y` | קואורדינטת Y מנורמלת (0-1) עבור נקודת הסיום. ערך ברירת המחדל הוא 1.0. | FLOAT | כן | 0.0 - 1.0 |
| `num_frames` | המספר הכולל של פריימים עבורם ייווצרו מיקומי מסלולים. ערך ברירת המחדל הוא 81. | INT | כן | 1 - 1024 |
| `num_tracks` | מספר המסלולים המקבילים ליצירה. ערך ברירת המחדל הוא 5. | INT | כן | 1 - 100 |
| `track_spread` | מרחק מנורמל בין מסלולים. המסלולים נפרסים בניצב לכיוון התנועה. ערך ברירת המחדל הוא 0.025. | FLOAT | כן | 0.0 - 1.0 |
| `bezier` | הפעל נתיב עקומת בזייה תוך שימוש בנקודת האמצע כנקודת בקרה. ערך ברירת המחדל הוא False. | BOOLEAN | כן | True / False |
| `mid_x` | נקודת בקרה X מנורמלת עבור עקומת בזייה. בשימוש רק כאשר `bezier` מופעל. ערך ברירת המחדל הוא 0.5. | FLOAT | כן | 0.0 - 1.0 |
| `mid_y` | נקודת בקרה Y מנורמלת עבור עקומת בזייה. בשימוש רק כאשר `bezier` מופעל. ערך ברירת המחדל הוא 0.5. | FLOAT | כן | 0.0 - 1.0 |
| `interpolation` | שולט בתזמון/מהירות התנועה לאורך הנתיב (ברירת מחדל: "linear"):<br>"linear" - מהירות קבועה<br>"ease_in" - מתחיל לאט ומאיץ<br>"ease_out" - מתחיל מהר ומאט<br>"ease_in_out" - האצה והאטה חלקות<br>"constant" - שומר את כל המיקומים בנקודת ההתחלה | COMBO | כן | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | מסכה אופציונלית לציון פריימים גלויים. אם מסופקת, פריימים שבהם למסכה יש פיקסל שאינו אפס מסומנים כגלויים עבור כל המסלולים. | MASK | לא | - |

**הערה:** הפרמטרים `mid_x` ו-`mid_y` משמשים רק כאשר הפרמטר `bezier` מוגדר ל-`True`. כאשר `bezier` הוא `False`, הנתיב הוא קו ישר מנקודת ההתחלה לנקודת הסיום.

## פלטים

| שם פלט | תיאור | סוג נתונים |

| `track_length` | מספר הפריימים עבורם נוצרו מסלולים, בהתאמה לקלט `num_frames`. | INT |
