# GenerateTracks

Узел `GenerateTracks` создаёт несколько параллельных траекторий движения (треков) для генерации видео. Он задаёт основной путь от начальной точки до конечной, а затем создаёт набор треков, идущих параллельно этому пути с равномерным интервалом. Можно управлять формой пути (прямая линия или кривая Безье), скоростью движения вдоль него, а также кадрами, в которых треки видны.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина видеокадра в пикселях. Значение по умолчанию: 832. | INT | Да | 16 - 4096 |
| `height` | Высота видеокадра в пикселях. Значение по умолчанию: 480. | INT | Да | 16 - 4096 |
| `start_x` | Нормализованная координата X (0–1) начальной позиции. Значение по умолчанию: 0.0. | FLOAT | Да | 0.0 - 1.0 |
| `start_y` | Нормализованная координата Y (0–1) начальной позиции. Значение по умолчанию: 0.0. | FLOAT | Да | 0.0 - 1.0 |
| `end_x` | Нормализованная координата X (0–1) конечной позиции. Значение по умолчанию: 1.0. | FLOAT | Да | 0.0 - 1.0 |
| `end_y` | Нормализованная координата Y (0–1) конечной позиции. Значение по умолчанию: 1.0. | FLOAT | Да | 0.0 - 1.0 |
| `num_frames` | Общее количество кадров, для которых необходимо сгенерировать позиции треков. Значение по умолчанию: 81. | INT | Да | 1 - 1024 |
| `num_tracks` | Количество параллельных треков для генерации. Значение по умолчанию: 5. | INT | Да | 1 - 100 |
| `track_spread` | Нормализованное расстояние между треками. Треки распределяются перпендикулярно направлению движения. Значение по умолчанию: 0.025. | FLOAT | Да | 0.0 - 1.0 |
| `bezier` | Включить путь по кривой Безье, используя среднюю точку в качестве контрольной. Значение по умолчанию: False. | BOOLEAN | Да | True / False |
| `mid_x` | Нормализованная координата X контрольной точки кривой Безье. Используется только при включённом `bezier`. Значение по умолчанию: 0.5. | FLOAT | Да | 0.0 - 1.0 |
| `mid_y` | Нормализованная координата Y контрольной точки кривой Безье. Используется только при включённом `bezier`. Значение по умолчанию: 0.5. | FLOAT | Да | 0.0 - 1.0 |
| `interpolation` | Управляет временем/скоростью движения вдоль пути (по умолчанию: "linear"):<br>"linear" — постоянная скорость<br>"ease_in" — начинается медленно и ускоряется<br>"ease_out" — начинается быстро и замедляется<br>"ease_in_out" — плавное ускорение и замедление<br>"constant" — все позиции остаются в начальной точке | COMBO | Да | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | Необязательная маска для указания видимых кадров. Если задана, кадры, в которых маска имеет хотя бы один ненулевой пиксель, помечаются как видимые для всех треков. | MASK | Нет | - |

**Примечание:** параметры `mid_x` и `mid_y` используются только тогда, когда параметр `bezier` имеет значение `True`. Когда `bezier` имеет значение `False`, путь представляет собой прямую линию от начальной до конечной точки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `TRACKS` | Объект треков, содержащий сгенерированные координаты пути и информацию о видимости для всех треков во всех кадрах. | TRACKS |
| `track_length` | Количество кадров, для которых были сгенерированы треки, соответствующее входному параметру `num_frames`. | INT |
