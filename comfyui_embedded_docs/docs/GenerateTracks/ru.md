# GenerateTracks

Узел `GenerateTracks` создает несколько параллельных траекторий движения для генерации видео. Он определяет основной путь от начальной точки до конечной, затем генерирует набор треков, идущих параллельно этому пути и расположенных на равном расстоянии друг от друга. Вы можете управлять формой пути (прямая линия или кривая Безье), скоростью движения по нему, а также тем, в каких кадрах отображаются треки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина видеокадра в пикселях. Значение по умолчанию: 832. | INT | Yes | 16 - 4096 |
| `height` | Высота видеокадра в пикселях. Значение по умолчанию: 480. | INT | Yes | 16 - 4096 |
| `start_x` | Нормализованная координата X (0-1) начальной позиции. Значение по умолчанию: 0.0. | FLOAT | Yes | 0.0 - 1.0 |
| `start_y` | Нормализованная координата Y (0-1) начальной позиции. Значение по умолчанию: 0.0. | FLOAT | Yes | 0.0 - 1.0 |
| `end_x` | Нормализованная координата X (0-1) конечной позиции. Значение по умолчанию: 1.0. | FLOAT | Yes | 0.0 - 1.0 |
| `end_y` | Нормализованная координата Y (0-1) конечной позиции. Значение по умолчанию: 1.0. | FLOAT | Yes | 0.0 - 1.0 |
| `num_frames` | Общее количество кадров, для которых генерируются позиции треков. Значение по умолчанию: 81. | INT | Yes | 1 - 1024 |
| `num_tracks` | Количество генерируемых параллельных треков. Значение по умолчанию: 5. | INT | Yes | 1 - 100 |
| `track_spread` | Нормализованное расстояние между треками. Треки располагаются перпендикулярно направлению движения. Значение по умолчанию: 0.025. | FLOAT | Yes | 0.0 - 1.0 |
| `bezier` | Включить путь по кривой Безье с использованием средней точки в качестве контрольной точки. Значение по умолчанию: False. | BOOLEAN | Yes | True / False |
| `mid_x` | Нормализованная координата X контрольной точки для кривой Безье. Используется только когда `bezier` включен. Значение по умолчанию: 0.5. | FLOAT | Yes | 0.0 - 1.0 |
| `mid_y` | Нормализованная координата Y контрольной точки для кривой Безье. Используется только когда `bezier` включен. Значение по умолчанию: 0.5. | FLOAT | Yes | 0.0 - 1.0 |
| `interpolation` | Управляет временем/скоростью движения вдоль пути. Значение по умолчанию: "linear". При выборе "constant" все точки остаются в начальной позиции. | COMBO | Yes | `"linear"`<br>`"ease_in"`<br>`"ease_out"`<br>`"ease_in_out"`<br>`"constant"` |
| `track_mask` | Необязательная маска, указывающая видимые кадры. | MASK | No | - |

**Примечание:** Параметры `mid_x` и `mid_y` используются только когда параметр `bezier` установлен в `True`. Когда `bezier` равен `False`, путь представляет собой прямую линию от начальной до конечной точки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `TRACKS` | Объект tracks, содержащий сгенерированные координаты пути и информацию о видимости для всех треков во всех кадрах. | TRACKS |
| `track_length` | Количество кадров, для которых были сгенерированы треки, соответствующее входному параметру `num_frames`. | INT |
