# Сэмплер LMS

Узел SamplerLMS создает сэмплер на основе метода наименьших средних квадратов (LMS) для использования в диффузионных моделях. Он генерирует объект сэмплера, который можно использовать в процессе сэмплирования, позволяя управлять порядком алгоритма LMS для обеспечения численной устойчивости и точности.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `порядок` | Порядок алгоритма сэмплера LMS, который управляет точностью и устойчивостью численного метода (по умолчанию: 4). Этот параметр отображается в дополнительном разделе интерфейса узла. | INT | Да | 1 до 100 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `sampler` | Настроенный объект сэмплера LMS, который можно использовать в конвейере сэмплирования | SAMPLER |
