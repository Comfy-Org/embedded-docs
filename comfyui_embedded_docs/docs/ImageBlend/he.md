# ImageBlend

הצומת `ImageBlend` נועד למזג שתי תמונות יחד בהתבסס על מצב מיזוג ומקדם מיזוג מוגדרים. הוא תומך במצבי מיזוג שונים כגון normal, multiply, screen, overlay, soft light ו-difference, מה שמאפשר טכניקות מגוונות לעיבוד ולקומפוזיציה של תמונות. צומת זה חיוני ליצירת תמונות מורכבות על ידי כוונון האינטראקציה החזותית בין שתי שכבות תמונה.

## קלטים

| שדה | תיאור | סוג נתונים |
| --- | --- | --- |
| `image1` | התמונה הראשונה שיש למזג. היא משמשת כשכבת הבסיס עבור פעולת המיזוג. | `IMAGE` |
| `image2` | התמונה השנייה שיש למזג. בהתאם למצב המיזוג, היא משנה את המראה של התמונה הראשונה. | `IMAGE` |
| `blend_factor` | קובע את המשקל של התמונה השנייה במיזוג. מקדם מיזוג גבוה יותר מעניק בולטות רבה יותר לתמונה השנייה בתוצאה. | `FLOAT` |
| `blend_mode` | מגדיר את שיטת מיזוג שתי התמונות. תומך במצבים כגון normal, multiply, screen, overlay, soft light ו-difference, שכל אחד מהם יוצר אפקט חזותי ייחודי. | COMBO[STRING] |

## פלטים

| שדה | תיאור | סוג נתונים |
| --- | --- | --- |
| `image` | התמונה המתקבלת לאחר מיזוג שתי תמונות הקלט בהתאם למצב המיזוג ולמקדם שצוינו. | `IMAGE` |
