# RenderMesh

このノードは、単一ビューをレイキャスティングすることで3Dメッシュを2D画像にレンダリングします。出力は、テクスチャ付きメッシュ、頂点カラー、ソリッドシェーディングされたサーフェス、サーフェス法線、深度のいずれかです。カメラとオプションのモデル変換は、Load3D / Preview3Dビューアから取得できます。カメラが接続されていない場合は、デフォルトの正面ビューが自動フレーミングされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | レンダリングする3Dメッシュ。 | MESH | はい | — |
| `mode` | レンダリングする内容。auto: テクスチャがあればテクスチャ、なければ頂点カラー、それもなければシェーデッドクレイをレンダリングします。（デフォルト："auto"） | COMBO | はい | `"auto"`<br>`"texture"`<br>`"vertex colors"`<br>`"solid"`<br>`"normal"`<br>`"depth"` |
| `width` | レンダリング画像の幅（ピクセル単位）。（デフォルト：1024） | INT | はい | 64 to 4096 (step 8) |
| `height` | レンダリング画像の高さ（ピクセル単位）。（デフォルト：1024） | INT | はい | 64 to 4096 (step 8) |
| `background` | メッシュが覆っていないピクセルに使用する背景色。（デフォルト："#000000"） | COLOR | はい | — |
| `model_3d_info` | 同じLoad3D / Preview3Dビューアから取得したモデル変換。camera_infoと一緒に接続すると、ビューアのフレーミングに合わせてレンダリングされます。 | LOAD3D_MODEL_INFO | いいえ | — |
| `camera_info` | Load3D / Preview3DビューアまたはCreate Camera Infoノードからのカメラ。何も接続されていない場合は、デフォルトの正面ビューが自動フレーミングされます。 | LOAD3D_CAMERA | いいえ | — |

注意： バッチ処理されたメッシュの最初の項目のみがレンダリングされます。メッシュバッチに複数の項目が含まれている場合、ノードは警告をログに記録し、最初の項目を使用します。`texture`モードでは、メッシュにテクスチャとUVの両方が必要です。`vertex colors`モードでは頂点カラーが必要です。選択したモードに必要なデータがない場合、ノードはソリッドシェーディングのレンダリングにフォールバックします。`model_3d_info`と`camera_info`は、同じLoad3D / Preview3Dビューアから一緒に接続して、レンダリングがビューアのフレーミングと一致するようにすることを想定しています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | メッシュのレンダリング画像。 | IMAGE |
| `mask` | メッシュがレンダリングされた場所が1.0、それ以外が0.0のマスク。 | MASK |
