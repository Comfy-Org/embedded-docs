# Рендер меша

Этот узел рендерит 3D-меш в 2D-изображение путём рейкастинга одного вида. Он может выводить текстурированный меш, цвета вершин, сплошную затенённую поверхность, нормали поверхности или глубину. Камера и необязательное преобразование модели могут поступать из вьюера Load3D / Preview3D; если камера не подключена, автоматически кадрируется вид спереди по умолчанию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-меш для рендеринга. | MESH | Да | — |
| `mode` | Что рендерить. auto: текстура, если присутствует, иначе цвета вершин, иначе затенённая глина. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"texture"`<br>`"vertex colors"`<br>`"solid"`<br>`"normal"`<br>`"depth"` |
| `width` | Ширина рендерируемого изображения в пикселях. (по умолчанию: 1024) | INT | Да | от 64 до 4096 (шаг 8) |
| `height` | Высота рендерируемого изображения в пикселях. (по умолчанию: 1024) | INT | Да | от 64 до 4096 (шаг 8) |
| `background` | Цвет фона, используемый для пикселей, не покрытых мешем. (по умолчанию: "#000000") | COLOR | Да | — |
| `model_3d_info` | Преобразование модели из того же вьюера Load3D / Preview3D. Подключите его вместе с `camera_info`, чтобы совпадало кадрирование вьюера. | LOAD3D_MODEL_INFO | Нет | — |
| `camera_info` | Камера из вьюера Load3D / Preview3D или узла Create Camera Info. Если ничего не подключено, автоматически кадрируется вид спереди по умолчанию. | LOAD3D_CAMERA | Нет | — |

Примечание: Рендерится только первый элемент пакетного меша — если пакет мешей содержит более одного элемента, узел выводит предупреждение в журнал и использует первый. Режим `texture` требует, чтобы у меша были и текстура, и UV-координаты, а режим `vertex colors` требует наличия цветов вершин; если данные для выбранного режима недоступны, узел переключается на рендер сплошной затенённой поверхности. Режим `normal` использует сглаженные нормали вершин меша, если они присутствуют, иначе нормаль каждой грани. В режиме `depth` более близкие поверхности выглядят ярче (ближняя = белая), а пиксели, не покрытые мешем, остаются чёрными. `model_3d_info` и `camera_info` предназначены для совместного подключения из одного и того же вьюера Load3D / Preview3D, чтобы рендер совпадал с кадрированием вьюера.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отрендеренное изображение меша. | IMAGE |
| `mask` | Маска, равная 1.0 там, где меш был отрендерен, и 0.0 в остальных местах. | MASK |
