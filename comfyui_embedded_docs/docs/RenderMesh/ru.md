# RenderMesh

Этот узел выполняет рендеринг 3D-сетки в 2D-изображение с помощью трассировки лучей для одного вида. Он может выводить текстурированную сетку, цвета вершин, однотонную затенённую поверхность, нормали поверхности или глубину. Камера и опциональная трансформация модели могут поступать из вьювера Load3D / Preview3D; если камера не подключена, автоматически выбирается вид спереди по умолчанию.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 3D-сетка для рендеринга. | MESH | Да | — |
| `mode` | Что рендерить. auto: текстура, если она есть, иначе цвета вершин, иначе затенённая глина. (по умолчанию: "auto") | COMBO | Да | `"auto"`<br>`"texture"`<br>`"vertex colors"`<br>`"solid"`<br>`"normal"`<br>`"depth"` |
| `width` | Ширина рендеренного изображения в пикселях. (по умолчанию: 1024) | INT | Да | 64 to 4096 (step 8) |
| `height` | Высота рендеренного изображения в пикселях. (по умолчанию: 1024) | INT | Да | 64 to 4096 (step 8) |
| `background` | Цвет фона для пикселей, не покрытых сеткой. (по умолчанию: "#000000") | COLOR | Да | — |
| `model_3d_info` | Трансформация модели из того же вьювера Load3D / Preview3D. Подключите её вместе с camera_info, чтобы соответствовать кадрированию вьювера. | LOAD3D_MODEL_INFO | Нет | — |
| `camera_info` | Камера из вьювера Load3D / Preview3D или узла Create Camera Info. Если ничего не подключено, автоматически выбирается вид спереди по умолчанию. | LOAD3D_CAMERA | Нет | — |

Примечание: рендерится только первый элемент пакетной сетки — если пакет сетки содержит более одного элемента, узел выводит предупреждение и использует первый. Режим `texture` требует, чтобы у сетки были и текстура, и UV-координаты, а режим `vertex colors` требует цвета вершин; если данные для выбранного режима недоступны, узел возвращается к рендерингу с однотонной заливкой. `model_3d_info` и `camera_info` предназначены для совместного подключения из одного вьювера Load3D / Preview3D, чтобы рендер соответствовал кадрированию вьювера.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Рендеренное изображение сетки. | IMAGE |
| `mask` | Маска, равная 1.0 там, где была отрендерена сетка, и 0.0 в остальных местах. | MASK |
