# Wan 2.7 リファレンスから動画へ

このノードは、提供された参照素材に基づいて、人物や物体が登場する動画を生成します。Wan 2.7 モデルを使用してテキストプロンプトから動画を作成し、単一キャラクターの演技や複数キャラクターのインタラクションに対応しています。生成を機能させるには、少なくとも1つの参照ビデオまたは参照画像を指定する必要があります。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 動画生成に使用する特定のモデルです。 | COMBO | はい | "wan2.7-r2v" |
| `seed` | 生成に使用するシード値です。出力のランダム性を制御するのに役立ちます（デフォルト：0）。 | INT | いいえ | 0〜2147483647 |
| `watermark` | 結果にAI生成の透かしを追加するかどうかです（デフォルト：False）。これは詳細設定です。 | BOOLEAN | いいえ | True<br>False |

### wan2.7-r2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | 動画を説明するプロンプトです。参照キャラクターを参照するには、`character1` や `character2` などの識別子を使用します。少なくとも1つのキャラクターを含める必要があります。 | STRING | はい | - |
| `negative_prompt` | 避けたい内容を説明するネガティブプロンプトです（デフォルト：空）。 | STRING | いいえ | - |
| `resolution` | 出力動画の解像度です。 | COMBO | はい | "720P"<br>"1080P" |
| `ratio` | 出力動画のアスペクト比です。 | COMBO | はい | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | 生成される動画の長さ（秒）です（デフォルト：5）。 | INT | はい | 2〜10 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model.reference_videos` | 拡張可能なスロットです。最大3つの参照ビデオを接続できます（スロット `video1` ～ `video3`）。全体として、少なくとも1つの参照ビデオまたは参照画像が必要です。 | VIDEO | いいえ | 0〜3 個 |
| `model.reference_images` | 拡張可能なスロットです。最大5つの参照画像を接続できます（スロット `image1` ～ `image5`）。全体として、少なくとも1つの参照ビデオまたは参照画像が必要です。 | IMAGE | いいえ | 0〜5 個 |

**重要な制約：**

* `model.reference_videos` または `model.reference_images` 入力に、少なくとも1つの参照ビデオまたは参照画像を指定する必要があります。
* 参照ビデオと参照画像を合わせた総数は5を超えることはできません。
* `model.prompt` 入力には少なくとも1つのキャラクターを含める必要があります。
