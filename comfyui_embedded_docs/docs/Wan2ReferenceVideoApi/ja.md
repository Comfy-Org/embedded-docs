# Wan 2.7 リファレンスから動画へ

このノードは、提供された参照資料に基づいて、人物またはオブジェクトを特徴とする動画を生成します。Wan 2.7 モデルを使用してテキストプロンプトから動画を作成し、単一キャラクターの演技と複数キャラクターのインタラクションをサポートします。生成を機能させるには、少なくとも1つの参照ビデオまたは参照画像を提供する必要があります。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 動画生成に使用する特定のモデル。 | DYNAMIC_COMBO | 必須 | "wan2.7-r2v" |
| `seed` | 生成に使用するシード。出力のランダム性を制御するのに役立ちます（デフォルト: 0）。 | INT | 必須 | 0～2147483647 |
| `watermark` | 結果にAI生成の透かしを追加するかどうか（デフォルト: False）。これは高度な設定です。 | BOOLEAN | 必須 | True<br>False |

### wan2.7-r2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | 動画を説明するプロンプト。参照キャラクターを指すには、'character1' や 'character2' などの識別子を使用します。少なくとも1人のキャラクターを含める必要があります。 | STRING | 必須 | - |
| `negative_prompt` | 避けたい内容を説明するネガティブプロンプト（デフォルト: 空）。 | STRING | 任意 | - |
| `resolution` | 出力動画の解像度。 | COMBO | 必須 | "720P"<br>"1080P" |
| `ratio` | 出力動画のアスペクト比。 | COMBO | 必須 | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | 生成される動画の長さ（秒単位）（デフォルト: 5）。 | INT | 必須 | 2～10 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `reference_videos` | 拡張可能スロット: 最大3本の参照ビデオを接続できます（スロット `video1` から `video3`）。全体として少なくとも1つの参照ビデオまたは参照画像が必要です。 | VIDEO | 任意 | 0～3項目 |
| `reference_images` | 拡張可能スロット: 最大5枚の参照画像を接続できます（スロット `image1` から `image5`）。全体として少なくとも1つの参照ビデオまたは参照画像が必要です。 | IMAGE | 任意 | 0～5項目 |

**重要な制約事項:**

* `model.reference_videos` または `model.reference_images` 入力に、少なくとも1つの参照ビデオまたは参照画像を提供する必要があります。
* 参照ビデオと参照画像の合計数は5つを超えることはできません。
* `model.prompt` 入力には少なくとも1人のキャラクターを含める必要があります。
