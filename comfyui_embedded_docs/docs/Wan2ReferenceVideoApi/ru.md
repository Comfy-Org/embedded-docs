# Wan 2.7 Референс в Видео

Этот узел генерирует видео с человеком или объектом на основе предоставленных референсных материалов. Он использует модель Wan 2.7 для создания видео по текстовому промпту и поддерживает выступления одного персонажа и взаимодействие нескольких персонажей. Для работы генерации необходимо предоставить как минимум одно референсное видео или референсное изображение.

## Входные параметры

### Общие входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Конкретная модель для генерации видео. | COMBO | Да | "wan2.7-r2v" |
| `seed` | Сид (seed) для генерации, который помогает контролировать случайность выходного результата (по умолчанию: 0). | INT | Нет | от 0 до 2147483647 |
| `watermark` | Нужно ли добавлять водяной знак, созданный ИИ, к результату (по умолчанию: False). Это расширенная настройка. | BOOLEAN | Нет | True<br>False |

### Входные параметры wan2.7-r2v

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.prompt` | Промпт, описывающий видео. Используйте идентификаторы, такие как 'character1' и 'character2', для ссылки на референсных персонажей. Должен содержать как минимум одного персонажа. | STRING | Да | - |
| `model.negative_prompt` | Негативный промпт, описывающий, чего следует избегать (по умолчанию: пусто). | STRING | Нет | - |
| `model.resolution` | Разрешение выходного видео. | COMBO | Да | "720P"<br>"1080P" |
| `model.ratio` | Соотношение сторон выходного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `model.duration` | Длительность генерируемого видео в секундах (по умолчанию: 5). | INT | Да | от 2 до 10 |

### Референсные входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.reference_videos` | Расширяемый слот: подключите до 3 референсных видео (слоты `video1`–`video3`). Требуется как минимум одно референсное видео или изображение в целом. | VIDEO | Нет | от 0 до 3 элементов |
| `model.reference_images` | Расширяемый слот: подключите до 5 референсных изображений (слоты `image1`–`image5`). Требуется как минимум одно референсное видео или изображение в целом. | IMAGE | Нет | от 0 до 5 элементов |

**Важные ограничения:**

* Вы должны указать как минимум одно референсное видео или референсное изображение во входных параметрах `model.reference_videos` или `model.reference_images`.
* Общее суммарное количество референсных видео и референсных изображений не может превышать 5.
* Входной параметр `model.prompt` должен содержать как минимум одного персонажа.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
