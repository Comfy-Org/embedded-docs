# Wan 2.7 Референс в Видео

Этот узел генерирует видео с человеком или объектом на основе предоставленных эталонных материалов. Он использует модель Wan 2.7 для создания видео по текстовому запросу, поддерживая выступления с одним персонажем и взаимодействия нескольких персонажей. Для работы генерации необходимо предоставить по крайней мере одно эталонное видео или эталонное изображение.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Конкретная модель, используемая для генерации видео. | DYNAMIC_COMBO | Да | "wan2.7-r2v" |
| `seed` | Сид для генерации, который помогает контролировать случайность выходного результата (по умолчанию: 0). | INT | Да | от 0 до 2147483647 |
| `watermark` | Добавлять ли ИИ-водяной знак к результату (по умолчанию: False). Это расширенная настройка. | BOOLEAN | Да | True<br>False |

### Входы wan2.7-r2v

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `prompt` | Текстовый запрос, описывающий видео. Используйте идентификаторы, такие как 'character1' и 'character2', для ссылки на эталонных персонажей. Должен содержать хотя бы одного персонажа. | STRING | Да | - |
| `negative_prompt` | Негативный запрос, описывающий, чего следует избегать (по умолчанию: пусто). | STRING | Нет | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "720P"<br>"1080P" |
| `ratio` | Соотношение сторон выходного видео. | COMBO | Да | "16:9"<br>"9:16"<br>"1:1"<br>"4:3"<br>"3:4" |
| `duration` | Длительность генерируемого видео в секундах (по умолчанию: 5). | INT | Да | от 2 до 10 |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `reference_videos` | Расширяемый слот: подключите до 3 эталонных видео (слоты `video1`–`video3`). В целом требуется хотя бы одно эталонное видео или изображение. | VIDEO | Нет | от 0 до 3 элементов |
| `reference_images` | Расширяемый слот: подключите до 5 эталонных изображений (слоты `image1`–`image5`). В целом требуется хотя бы одно эталонное видео или изображение. | IMAGE | Нет | от 0 до 5 элементов |

**Важные ограничения:**

* Необходимо предоставить хотя бы одно эталонное видео или эталонное изображение во входах `reference_videos` или `reference_images`.
* Общее суммарное количество эталонных видео и эталонных изображений не может превышать 5.
* Вход `prompt` должен содержать хотя бы одного персонажа.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
