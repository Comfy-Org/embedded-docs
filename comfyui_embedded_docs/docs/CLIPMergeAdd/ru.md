# Сложение CLIP

Узел CLIPMergeAdd объединяет две модели CLIP, добавляя патчи из второй модели в первую. Он создает копию первой модели CLIP и выборочно включает ключевые патчи из второй модели, исключая идентификаторы позиций и параметры масштаба логитов. Это позволяет объединять компоненты модели CLIP, сохраняя структуру базовой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip1` | Базовая модель CLIP, которая будет клонирована и использована в качестве основы для объединения | CLIP | Да | - |
| `clip2` | Вторичная модель CLIP, которая предоставляет ключевые патчи для добавления в базовую модель | CLIP | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CLIP` | Объединенная модель CLIP, содержащая структуру базовой модели с добавленными патчами из вторичной модели | CLIP |
