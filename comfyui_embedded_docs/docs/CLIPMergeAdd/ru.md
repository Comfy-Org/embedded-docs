# Сложение CLIP

Узел CLIPMergeAdd объединяет две модели CLIP, добавляя патчи из второй модели в первую. Он создает копию первой модели CLIP и выборочно включает ключевые патчи из второй модели, исключая параметры position IDs и logit scale. Это позволяет объединять компоненты моделей CLIP, сохраняя структуру базовой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip1` | Базовая модель CLIP, которая будет клонирована и использована в качестве основы для объединения. | CLIP | Да | - |
| `clip2` | Вторичная модель CLIP, которая предоставляет ключевые патчи для добавления к базовой модели. | CLIP | Да | - |

Примечание: ключевые патчи из `clip2` добавляются с силой 1.0. Ключи, оканчивающиеся на `.position_ids` или `.logit_scale`, исключаются из объединения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CLIP` | Объединенная модель CLIP, содержащая структуру базовой модели с добавленными патчами из вторичной модели. | CLIP |
