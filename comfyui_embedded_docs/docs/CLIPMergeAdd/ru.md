# Сложение CLIP

Узел CLIPMergeAdd объединяет две CLIP-модели, добавляя патчи из второй модели в первую. Он создаёт копию первой CLIP-модели и выборочно включает ключевые патчи из второй модели, исключая идентификаторы позиций и параметры logit scale. Это позволяет объединять компоненты CLIP-модели, сохраняя структуру базовой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip1` | Базовая CLIP-модель, которая будет клонирована и использована как основа для объединения | CLIP | Да | - |
| `clip2` | Дополнительная CLIP-модель, предоставляющая ключевые патчи, которые будут добавлены в базовую модель | CLIP | Да | - |

Ключи, оканчивающиеся на `.position_ids` или `.logit_scale`, из `clip2` пропускаются, поэтому эти параметры сохраняют значения из `clip1`.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `CLIP` | Объединённая CLIP-модель, содержащая структуру базовой модели с добавленными патчами из дополнительной модели | CLIP |
