# Stablezero123ConditioningBatched

צומת זה מיועד לעבד מידע התניה באופן אצוותי, המותאם במיוחד למודל StableZero123. הוא מתמקד בטיפול יעיל בקבוצות מרובות של נתוני התניה בו-זמנית, תוך אופטימיזציה של זרימת העבודה בתרחישים שבהם עיבוד אצוות הוא קריטי.

## קלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `clip_vision` | הטמעות הראייה של CLIP המספקות הקשר חזותי לתהליך ההתניה. | `CLIP_VISION` |
| `init_image` | התמונה הראשונית שעליה מתבצעת ההתניה, ומשמשת כנקודת התחלה לתהליך היצירה. | `IMAGE` |
| `vae` | האוטואנקודר הווריאציוני המשמש לקידוד ופענוח תמונות בתהליך ההתניה. | `VAE` |
| `width` | רוחב תמונת הפלט. | `INT` |
| `height` | גובה תמונת הפלט. | `INT` |
| `batch_size` | מספר קבוצות ההתניה שיעובדו באצווה אחת. | `INT` |
| `elevation` | זווית הגובה להתנית מודל תלת-ממדי, המשפיעה על נקודת המבט של התמונה הנוצרת. | `FLOAT` |
| `azimuth` | זווית האזימוט להתנית מודל תלת-ממדי, המשפיעה על כיוון התמונה הנוצרת. | `FLOAT` |
| `elevation_batch_increment` | התוספת ההדרגתית לזווית הגובה לאורך האצווה, ומאפשרת נקודות מבט מגוונות. | `FLOAT` |
| `azimuth_batch_increment` | התוספת ההדרגתית לזווית האזימוט לאורך האצווה, ומאפשרת כיוונים מגוונים. | `FLOAT` |

## פלטים

| פרמטר | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | פלט ההתניה החיובית, המותאם לקידום תכונות או היבטים מסוימים בתוכן הנוצר. | `CONDITIONING` |
| `negative` | פלט ההתניה השלילית, המותאם להחליש תכונות או היבטים מסוימים בתוכן הנוצר. | `CONDITIONING` |
| `latent` | הייצוג הלטנטי הנגזר מתהליך ההתניה, המוכן לעיבוד נוסף או לשלבי יצירה. | `LATENT` |
