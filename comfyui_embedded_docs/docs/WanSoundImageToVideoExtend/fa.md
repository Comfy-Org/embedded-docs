# وان‌ساند ایمیج تو ویدیو اکستند

```markdown
گره WanSoundImageToVideoExtend با تولید فریم‌های اضافی، یک latent ویدیوی موجود را گسترش می‌دهد و به‌صورت اختیاری توسط صدا، یک تصویر مرجع و یک ویدیوی کنترل هدایت می‌شود. این گره یک latent ویدیوی آغازین می‌گیرد و با استفاده از نشانه‌های شرطی‌سازی (conditioning) و صوتی ارائه‌شده، دنباله ویدیویی طولانی‌تری تولید می‌کند که بر محتوای جدید تأثیر می‌گذارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|---------|
| `positive` | پرامپت‌های شرطی مثبت که مشخص می‌کنند ویدیو چه چیزهایی را شامل شود | CONDITIONING | بله | - |
| `negative` | پرامپت‌های شرطی منفی که مشخص می‌کنند ویدیو از چه چیزهایی اجتناب کند | CONDITIONING | بله | - |
| `vae` | خودرمزنگار متغیر (Variational Autoencoder) که برای رمزگذاری و رمزگشایی فریم‌های ویدیو استفاده می‌شود | VAE | بله | - |
| `length` | تعداد کل فریم‌هایی که برای دنباله ویدیو تولید می‌شود (پیش‌فرض: 77، گام: 4) | INT | بله | 1 to MAX_RESOLUTION |
| `video_latent` | نمایش latent اولیه ویدیو که به‌عنوان نقطه شروع برای گسترش استفاده می‌شود. عرض، ارتفاع، اندازه دسته (batch size) و افست فریم از این latent مشتق می‌شوند. همچنین ۱۹ فریم آخر این latent به‌عنوان حرکت مرجع برای دنباله جدید استفاده می‌شوند. | LATENT | بله | - |
| `audio_encoder_output` | خروجی اختیاری رمزگذار صدا که می‌تواند بر اساس ویژگی‌های صدا، تولید ویدیو را تحت تأثیر قرار دهد. در صورت ارائه، صدا درون‌یابی شده و برای ایجاد یک bucket جاسازی صوتی استفاده می‌شود که به شرطی‌سازی اضافه می‌شود. | AUDIO_ENCODER_OUTPUT | خیر | - |
| `ref_image` | تصویر مرجع اختیاری که راهنمای بصری برای تولید ویدیو فراهم می‌کند. تصویر برای مطابقت با ابعاد هدف بزرگ‌نمایی (upscale) شده و به یک latent رمزگذاری می‌شود که سپس به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود. تنها اولین تصویر از دسته استفاده می‌شود. | IMAGE | خیر | - |
| `control_video` | ویدیوی کنترلی اختیاری که می‌تواند حرکت و سبک ویدیوی تولیدشده را هدایت کند. ویدیو بزرگ‌نمایی، رمزگذاری و به هر دو شرطی‌سازی مثبت و منفی اضافه می‌شود. ویدیوی کنترل به طول مشخص‌شده `length` محدود می‌شود. | IMAGE | خیر | - |

توجه: هنگامی که `audio_encoder_output` ارائه می‌شود، جاسازی‌های صوتی به شرطی‌سازی مثبت اضافه می‌شوند، در حالی که شرطی‌سازی منفی همان جاسازی‌ها را با مقدار صفر دریافت می‌کند. افست فریم مشتق‌شده از `video_latent` تعیین می‌کند که فریم‌های جدید در کجای دنباله صوتی شروع شوند. اگر دنباله صوتی فریم‌های کافی برای پوشش دادن گسترش درخواستی نداشته باشد، هیچ شرطی‌سازی صوتی اعمال نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `positive` | شرطی‌سازی مثبت پردازش‌شده با زمینه ویدیویی اعمال‌شده، شامل جاسازی‌های صوتی، latent مرجع، حرکت مرجع و ویدیوی کنترل در صورت وجود | CONDITIONING |
| `negative` | شرطی‌سازی منفی پردازش‌شده با زمینه ویدیویی اعمال‌شده، شامل جاسازی‌های صوتی (صفرشده)، latent مرجع، حرکت مرجع و ویدیوی کنترل در صورت وجود | CONDITIONING |
| `latent` | نمایش latent ویدیوی تولیدشده شامل دنباله ویدیویی گسترش‌یافته، که به‌صورت صفر مقداردهی اولیه شده و ابعاد آن از `video_latent` ورودی و `length` هدف مشتق شده است | LATENT |
```
