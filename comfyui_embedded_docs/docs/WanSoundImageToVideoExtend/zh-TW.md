# 萬聲圖像轉影片擴展

WanSoundImageToVideoExtend 節點透過生成額外幀來擴展現有的影片潛在表示，並可選擇性地由音訊、參考影像和控制影片引導。它接受一個起始影片潛在表示，並產生更長的影片序列，使用提供的條件提示和音訊線索來影響新內容。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 正向條件提示，用於引導影片應包含的內容 | CONDITIONING | 是 | - |
| `negative` | 負向條件提示，用於指定影片應避免的內容 | CONDITIONING | 是 | - |
| `vae` | 用於編碼和解碼影片幀的變分自編碼器 | VAE | 是 | - |
| `length` | 影片序列要生成的總幀數（預設：77，步進：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `video_latent` | 初始影片潛在表示，作為擴展的起點。寬度、高度、批次大小和幀偏移均由此潛在表示推導而來。此潛在表示的最後 19 幀也會用作新序列的參考運動。 | LATENT | 是 | - |
| `audio_encoder_output` | 可選的音訊嵌入，可根據聲音特徵影響影片生成。提供時，音訊會被插值並用於建立音訊嵌入桶，並添加到條件中。 | AUDIO_ENCODER_OUTPUT | 否 | - |
| `ref_image` | 可選的參考影像，為影片生成提供視覺引導。影像會放大以符合目標尺寸，並編碼成潛在表示，然後添加到正向與負向條件中。僅使用批次中的第一張影像。 | IMAGE | 否 | - |
| `control_video` | 可選的控制影片，可引導生成影片的動作和風格。影片會放大、編碼，並添加到正向與負向條件中。控制影片會被截斷至指定的 `length`。 | IMAGE | 否 | - |

注意：當提供 `audio_encoder_output` 時，音訊嵌入會添加到正向條件中，而負向條件則接收相同的嵌入但設為零。從 `video_latent` 推導出的幀偏移決定了新幀在音訊序列中的起始位置。如果音訊序列沒有足夠的幀來涵蓋要求的擴展長度，則不會應用音訊條件。
