# 萬聲圖像轉影片擴展

WanSoundImageToVideoExtend 節點透過生成額外影格來擴展現有的影片潛在表示，並可選擇性地以音訊、參考影像和控制影片作為引導。此節點以起始的影片潛在表示作為輸入，並產生較長的影片序列，使用所提供的條件設定及音訊線索來影響新內容。
