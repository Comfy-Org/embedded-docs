# WanSoundImageToVideoExtend

The WanSoundImageToVideoExtend 노드는 기존 비디오 잠재 표현을 확장하여 추가 프레임을 생성하며, 선택적으로 오디오, 참조 이미지 및 제어 비디오의 안내를 받습니다. 시작 비디오 잠재 표현을 가져와 더 긴 비디오 시퀀스를 생성하며, 제공된 컨디셔닝과 오디오 큐를 사용하여 새 콘텐츠에 영향을 줍니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 비디오에 포함되어야 하는 내용을 안내하는 긍정 컨디셔닝 프롬프트 | CONDITIONING | 예 | - |
| `negative` | 비디오가 피해야 하는 내용을 지정하는 부정 컨디셔닝 프롬프트 | CONDITIONING | 예 | - |
| `vae` | 비디오 프레임을 인코딩하고 디코딩하는 데 사용되는 변분 오토인코더 | VAE | 예 | - |
| `length` | 비디오 시퀀스에 생성할 총 프레임 수 (기본값: 77, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `video_latent` | 확장의 시작점 역할을 하는 초기 비디오 잠재 표현입니다. 너비, 높이, 배치 크기 및 프레임 오프셋은 이 잠재 표현에서 파생됩니다. 이 잠재 표현의 마지막 19개 프레임은 새 시퀀스의 참조 모션으로도 사용됩니다. | LATENT | 예 | - |
| `audio_encoder_output` | 사운드 특성에 따라 비디오 생성에 영향을 줄 수 있는 선택적 오디오 임베딩입니다. 제공되면 오디오가 보간되고 컨디셔닝에 추가되는 오디오 임베딩 버킷을 만드는 데 사용됩니다. | AUDIO_ENCODER_OUTPUT | 아니오 | - |
| `ref_image` | 비디오 생성에 시각적 안내를 제공하는 선택적 참조 이미지입니다. 이미지는 대상 크기에 맞게 업스케일되고 잠재 표현으로 인코딩된 다음 긍정 및 부정 컨디셔닝 모두에 추가됩니다. 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니오 | - |
| `control_video` | 생성된 비디오의 모션과 스타일을 안내할 수 있는 선택적 제어 비디오입니다. 비디오는 업스케일, 인코딩되어 긍정 및 부정 컨디셔닝에 모두 추가됩니다. 제어 비디오는 지정된 `length`로 잘립니다. | IMAGE | 아니오 | - |

참고: `audio_encoder_output`이 제공되면 오디오 임베딩이 긍정 컨디셔닝에 추가되고, 부정 컨디셔닝은 동일한 임베딩을 0으로 설정하여 받습니다. `video_latent`에서 파생된 프레임 오프셋은 새 프레임이 오디오 시퀀스에서 시작되는 위치를 결정합니다. 오디오 시퀀스에 요청된 확장을 충당할 만큼 충분한 프레임이 없으면 오디오 컨디셔닝이 적용되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 오디오 임베딩, 참조 잠재 표현, 참조 모션 및 제공된 경우 제어 비디오를 포함하여 비디오 컨텍스트가 적용된 처리된 긍정 컨디셔닝 | CONDITIONING |
| `negative` | 오디오 임베딩(0으로 설정), 참조 잠재 표현, 참조 모션 및 제공된 경우 제어 비디오를 포함하여 비디오 컨텍스트가 적용된 처리된 부정 컨디셔닝 | CONDITIONING |
| `latent` | 입력 `video_latent` 및 대상 `length`에서 파생된 차원으로 0으로 초기화된, 확장된 비디오 시퀀스를 포함하는 생성된 비디오 잠재 표현 | LATENT |
