# WanSoundImageToVideoExtend

Узел `WanSoundImageToVideoExtend` расширяет существующий видеолатент, генерируя дополнительные кадры, при необходимости направляемый аудио, эталонным изображением и управляющим видео. Он принимает начальный видеолатент и создает более длинную видеопоследовательность, используя предоставленные условия кондиционирования и аудиосигналы для влияния на новое содержимое.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительные промпты кондиционирования, которые задают, что должно быть включено в видео | CONDITIONING | Да | - |
| `negative` | Отрицательные промпты кондиционирования, которые указывают, чего следует избегать в видео | CONDITIONING | Да | - |
| `vae` | Вариационный автокодировщик (VAE), используемый для кодирования и декодирования видеокадров | VAE | Да | - |
| `length` | Общее количество кадров для генерации видеопоследовательности (по умолчанию: 77, шаг: 4) | INT | Да | от 1 до MAX_RESOLUTION |
| `video_latent` | Начальный видеолатент, служащий отправной точкой для расширения. Ширина, высота, размер пакета и смещение кадров наследуются из этого латента. Последние 19 кадров этого латента также используются как эталонное движение для новой последовательности. | LATENT | Да | - |
| `audio_encoder_output` | Необязательные аудиоэмбеддинги, которые могут влиять на генерацию видео на основе характеристик звука. При их наличии аудио интерполируется и используется для создания набора аудиоэмбеддингов, который добавляется к кондиционированию. | AUDIO_ENCODER_OUTPUT | Нет | - |
| `ref_image` | Необязательное эталонное изображение, обеспечивающее визуальное направление для генерации видео. Изображение масштабируется до целевых размеров и кодируется в латент, который затем добавляется и к положительному, и к отрицательному кондиционированию. Используется только первое изображение из пакета. | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое может направлять движение и стиль генерируемого видео. Видео масштабируется, кодируется и добавляется и к положительному, и к отрицательному кондиционированию. Управляющее видео обрезается до указанного `length`. | IMAGE | Нет | - |

Примечание. Когда указан `audio_encoder_output`, аудиоэмбеддинги добавляются к положительному кондиционированию, а отрицательное кондиционирование получает те же эмбеддинги, установленные в ноль. Смещение кадров, полученное из `video_latent`, определяет место в аудиопоследовательности, где начинаются новые кадры. Если аудиопоследовательность не содержит достаточного количества кадров для требуемого расширения, аудиокондиционирование не применяется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Обработанное положительное кондиционирование с применённым видеоконтекстом, включая аудиоэмбеддинги, эталонные латенты, эталонное движение и управляющее видео (если предоставлено) | CONDITIONING |
| `negative` | Обработанное отрицательное кондиционирование с применённым видеоконтекстом, включая аудиоэмбеддинги (обнулённые), эталонные латенты, эталонное движение и управляющее видео (если предоставлено) | CONDITIONING |
| `latent` | Сгенерированное латентное представление видео, содержащее расширенную видеопоследовательность, инициализированную нулями с размерами, выведенными из входного `video_latent` и целевого `length` | LATENT |
