# WanSoundImageToVideoExtend

Узел WanSoundImageToVideoExtend расширяет существующий видео-латент, генерируя дополнительные кадры, опционально направляемые аудио, эталонным изображением и управляющим видео. Он принимает начальный видео-латент и создает более длинную видео-последовательность, используя предоставленное кондиционирование и аудио-сигналы для влияния на новый контент.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительные подсказки кондиционирования, которые направляют, что должно быть включено в видео | CONDITIONING | Да | - |
| `negative` | Отрицательные подсказки кондиционирования, которые указывают, чего видео должно избегать | CONDITIONING | Да | - |
| `vae` | Вариационный автоэнкодер, используемый для кодирования эталонного изображения и управляющего видео в латентное пространство | VAE | Да | - |
| `length` | Общее количество кадров для генерации видео-последовательности (по умолчанию: 77, шаг: 4) | INT | Да | 1 to MAX_RESOLUTION |
| `video_latent` | Исходный видео-латент, служащий отправной точкой для расширения. Выходные ширина, высота, размер пакета и смещение кадров определяются из этого латента. Его последние 19 кадров используются как эталонное движение для кондиционирования. | LATENT | Да | - |
| `audio_encoder_output` | Необязательные аудио-встраивания, которые могут влиять на генерацию видео на основе характеристик звука. При их наличии аудио интерполируется и преобразуется в блок аудио-встраиваний, который добавляется к кондиционированию. | AUDIOENCODEROUTPUT | Нет | - |
| `ref_image` | Необязательное эталонное изображение, обеспечивающее визуальное руководство для генерации видео. Изображение увеличивается до целевых размеров и кодируется в латент, который затем добавляется и к положительному, и к отрицательному кондиционированию. Используется только первое изображение в пакете. | IMAGE | Нет | - |
| `control_video` | Необязательное управляющее видео, которое направляет движение и структуру генерируемого видео. Видео увеличивается, кодируется и добавляется и к положительному, и к отрицательному кондиционированию. Управляющее видео обрезается до указанной `length`. | IMAGE | Нет | - |

Примечание: Выходной латент инициализируется нулями с целевыми размерами. Входной `video_latent` не копируется в этот выход; его последние 19 кадров используются как эталонное движение вместо этого.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанное положительное кондиционирование с примененным видеоконтекстом, включая аудио-встраивания, эталонные латенты, эталонное движение и управляющее видео при его наличии | CONDITIONING |
| `negative` | Обработанное отрицательное кондиционирование с примененным видеоконтекстом, включая аудио-встраивания (обнуленные), эталонные латенты, эталонное движение и управляющее видео при его наличии | CONDITIONING |
| `latent` | Латентное представление видео расширенной последовательности, инициализированное нулями с размерами, определенными из входного `video_latent` и целевой `length` | LATENT |
