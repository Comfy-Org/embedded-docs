# WanSoundImageToVideoExtend

צומת WanSoundImageToVideoExtend מרחיב latent וידאו קיים על ידי יצירת פריימים נוספים, באופן אופציונלי בהנחיית אודיו, תמונת עזר ווידאו בקרה. הוא מקבל latent וידאו התחלתי ומפיק רצף וידאו ארוך יותר, תוך שימוש בהתניה וברמזי אודיו שסופקו כדי להשפיע על התוכן החדש.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | פרומפטים של התניה חיובית המנחים מה הווידאו אמור לכלול | CONDITIONING | כן | - |
| `negative` | פרומפטים של התניה שלילית המציינים ממה הווידאו צריך להימנע | CONDITIONING | כן | - |
| `vae` | מקודד אוטומטי וריאציוני (Variational Autoencoder) המשמש לקידוד תמונת העזר ווידאו הבקרה למרחב latent | VAE | כן | - |
| `length` | מספר הפריימים הכולל ליצירה עבור רצף הווידאו (ברירת מחדל: 77, צעד: 4) | INT | כן | 1 עד MAX_RESOLUTION |
| `video_latent` | latent וידאו התחלתי המשמש כנקודת התחלה להרחבה. רוחב הפלט, הגובה, גודל האצווה והיסט הפריימים נגזרים מה-latent הזה. 19 הפריימים האחרונים שלו משמשים כהתניית תנועת עזר. | LATENT | כן | - |
| `audio_encoder_output` | הטמעות אודיו אופציונליות שיכולות להשפיע על יצירת הווידאו בהתבסס על מאפייני הצליל. כאשר מסופקות, האודיו עובר אינטרפולציה ומומר למקבץ הטמעות אודיו שמתווסף להתניה. | AUDIOENCODEROUTPUT | לא | - |
| `ref_image` | תמונת עזר אופציונלית המספקת הנחיה חזותית ליצירת הווידאו. התמונה מוגדלת כדי להתאים למידות היעד ומקודדת ל-latent, אשר לאחר מכן מתווסף גם להתניה החיובית וגם לשלילית. רק התמונה הראשונה באצווה משמשת. | IMAGE | לא | - |
| `control_video` | וידאו בקרה אופציונלי המנחה את התנועה והמבנה של הווידאו הנוצר. הווידאו מוגדל, מקודד ומתווסף גם להתניה החיובית וגם לשלילית. וידאו הבקרה נחתך בהתאם ל-`length` שצוין. | IMAGE | לא | - |

הערה: ה-latent של הפלט מאותחל כאפסים עם מידות היעד. הקלט `video_latent` אינו מועתק אל הפלט הזה; במקום זאת, 19 הפריימים האחרונים שלו משמשים כתנועת העזר.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | התניה חיובית מעובדת עם הקשר וידאו מיושם, כולל הטמעות אודיו, latent-ים של עזר, תנועת עזר ווידאו בקרה אם סופק | CONDITIONING |
| `negative` | התניה שלילית מעובדת עם הקשר וידאו מיושם, כולל הטמעות אודיו (מאופסות), latent-ים של עזר, תנועת עזר ווידאו בקרה אם סופק | CONDITIONING |
| `latent` | ייצוג latent וידאו של הרצף המורחב, מאותחל כאפסים עם מידות הנגזרות מהקלט `video_latent` ומה-`length` המיועד | LATENT |
