# WanSoundImageToVideoExtend

```
WanSoundImageToVideoExtend ノードは、追加のフレームを生成することで既存のビデオ潜在表現を拡張します。オプションで、オーディオ、参照画像、およびコントロールビデオによってガイドされます。開始ビデオの潜在表現を受け取り、指定された条件付けとオーディオの手がかりを使用して新しいコンテンツに影響を与えながら、より長いビデオシーケンスを生成します。

| `negative` | ビデオが避けるべき内容を指定するネガティブ条件付けプロンプトです。 | CONDITIONING | はい | - |
| `vae` | ビデオフレームのエンコードとデコードに使用される変分オートエンコーダーです。 | VAE | はい | - |
| `length` | ビデオシーケンス用に生成する総フレーム数です（デフォルト: 77、ステップ: 4）。 | INT | はい | 1 to MAX_RESOLUTION |
```
