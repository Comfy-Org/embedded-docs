# LTX 2.5 圖像轉影片

此節點使用 LTX 2.5 模型，從起始圖片生成專業品質的影片。您可以使用文字提示描述影片內容、選擇模型變體，並調整時長、解析度、影格率與音訊生成。也可以提供選用的最後一個影格來定義影片的結尾。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影像` | 用於影片的第一個影格。 | IMAGE | 是 | 正好一張圖片 |
| `模型` | 模型設定群組。選擇要使用的 LTX 2.5 模型變體。 | COMBO | 是 | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `時長` | 生成影片的長度，以秒為單位。 | INT | 是 | 整數 |
| `解析度` | 生成影片的解析度。可用選項可能取決於所選的模型。 | COMBO | 是 | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `幀率` | 生成影片的影格率。 | INT | 是 | 整數（預設值：25） |
| `生成音訊` | 是否為影片生成音訊。 | BOOLEAN | 是 | True<br>False（預設值：True） |
| `提示詞` | 要生成之影片內容的文字描述。長度必須介於 1 到 10000 個字元之間。 | STRING | 是 | 1 到 10000 個字元 |
| `種子` | 用於可重現生成的種子值。使用相同的 `seed` 搭配相同設定會產生相同的結果。 | INT | 是 | 整數（預設值：42） |
| `最後幀` | 用於影片的最後一個影格。 | IMAGE | 否 | 正好一張圖片 |

**注意：** `image` 僅支援一張圖片。如果提供 `last_frame`，它也必須正好包含一張圖片。可用的 `model.resolution` 選項可能會因所選的 `model` 變體而異。單次執行的價格取決於所選的 `model`、`model.duration` 和 `model.resolution`。

|-------------|-------------|-----------|
