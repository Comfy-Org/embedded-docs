# LTX ۲.۵ تبدیل تصویر به ویدیو

این گره با استفاده از مدل LTX 2.5، ویدیویی با کیفیت حرفه‌ای از روی یک تصویر شروع تولید می‌کند. شما محتوای ویدیو را با یک توضیح متنی توصیف می‌کنید، نوع مدل را انتخاب کرده و مدت، وضوح، نرخ فریم و تولید صدا را تنظیم می‌کنید. یک فریم پایانی اختیاری نیز می‌تواند برای تعریف پایان ویدیو ارائه شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | اولین فریمی که برای ویدیو استفاده می‌شود. | IMAGE | بله | دقیقاً یک تصویر |
| `مدل` | گروه تنظیمات مدل. نوع مدل LTX 2.5 مورد استفاده را انتخاب می‌کند. | COMBO | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `مدت زمان` | مدت زمان ویدیوی تولید شده بر حسب ثانیه. | INT | بله | عدد صحیح |
| `رزولوشن` | وضوح ویدیوی تولید شده. گزینه‌های موجود ممکن است به مدل انتخابی بستگی داشته باشد. | COMBO | بله | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `فریم بر ثانیه` | نرخ فریم ویدیوی تولید شده. | INT | بله | عدد صحیح (پیش‌فرض: 25) |
| `تولید صوت` | آیا صدا برای ویدیو تولید شود. | BOOLEAN | بله | True<br>False (پیش‌فرض: True) |
| `پرامپت` | توضیح متنی محتوای ویدیویی که باید تولید شود. باید بین 1 تا 10000 نویسه باشد. | STRING | بله | 1 تا 10000 نویسه |
| `بذر` | مقدار Seed برای تولید قابل تکرار. استفاده از همان seed با همان تنظیمات نتیجه یکسانی تولید می‌کند. | INT | بله | عدد صحیح (پیش‌فرض: 42) |
| `فریم آخر` | آخرین فریمی که برای ویدیو استفاده می‌شود. | IMAGE | خیر | دقیقاً یک تصویر |

**توجه:** فقط یک تصویر برای `image` پشتیبانی می‌شود. اگر `last_frame` ارائه شود، باید دقیقاً یک تصویر داشته باشد. گزینه‌های `model.resolution` موجود ممکن است بسته به نوع `model` انتخابی متفاوت باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدیوی تولید شده بر اساس تصویر شروع ارائه‌شده و تنظیمات تولید. | VIDEO |
