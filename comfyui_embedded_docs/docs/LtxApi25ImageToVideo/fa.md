# LtxApi25ImageToVideo

این گره بر اساس یک تصویر آغازین، ویدئویی با کیفیت حرفه‌ای تولید می‌کند. می‌توانید نوع مدل LTX 2.5 را انتخاب کنید، ویدئو را با یک متن توصیفی شرح دهید، مدت‌زمان، وضوح، نرخ فریم و تولید صدا را تنظیم کنید و به‌صورت اختیاری یک فریم پایانی تعیین کنید. خروجی، ویدئویی است که از تصویر ارائه‌شده شروع می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | فریم اول برای استفاده در ویدئو. | IMAGE | بله | دقیقاً یک تصویر |
| `model` | گروه تنظیمات مدل. نوع مدل LTX 2.5 را انتخاب می‌کند. | COMBO | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `model.duration` | طول ویدئوی تولیدشده بر حسب ثانیه. | INT | بله | عدد صحیح |
| `model.resolution` | وضوح ویدئوی تولیدشده. گزینه‌های موجود ممکن است به مدل انتخابی بستگی داشته باشند. | COMBO | بله | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `model.fps` | نرخ فریم ویدئوی تولیدشده. | INT | بله | عدد صحیح (پیش‌فرض: 25) |
| `model.generate_audio` | آیا برای ویدئو صدا تولید شود؟ | BOOLEAN | بله | True<br>False |
| `prompt` | توصیف متنی محتوای ویدئو برای تولید. باید بین ۱ تا ۱۰۰۰۰ کاراکتر باشد. | STRING | بله | ۱ تا ۱۰۰۰۰ کاراکتر |
| `seed` | مقدار seed برای تولید قابل تکرار. استفاده از seed یکسان با تنظیمات یکسان، نتیجه یکسان تولید می‌کند. | INT | بله | عدد صحیح (پیش‌فرض: 42) |
| `last_frame` | آخرین فریم برای استفاده در ویدئو. | IMAGE | خیر | دقیقاً یک تصویر |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `video` | ویدئوی تولیدشده بر اساس تصویر شروع ارائه‌شده و تنظیمات تولید. | VIDEO |
