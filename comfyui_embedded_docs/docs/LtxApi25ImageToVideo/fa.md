# LTX ۲.۵ تبدیل تصویر به ویدیو

این گره با استفاده از مدل LTX 2.5 از یک تصویر آغازین، ویدئویی با کیفیت حرفه‌ای تولید می‌کند. شما محتوای ویدئو را با یک پرامپت متنی توصیف می‌کنید، یک گونه از مدل را انتخاب می‌کنید و مدت‌زمان، وضوح، نرخ فریم و تولید صدا را تنظیم می‌کنید. می‌توان یک فریم پایانی اختیاری نیز ارائه کرد تا پایان ویدئو مشخص شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | اولین فریمی که برای ویدئو استفاده می‌شود. | IMAGE | بله | دقیقاً یک تصویر |
| `model` | گروه تنظیمات مدل. گونه مدل LTX 2.5 را برای استفاده انتخاب می‌کند. | COMBO | بله | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `model.duration` | طول ویدئوی تولیدشده بر حسب ثانیه. | INT | بله | عدد صحیح |
| `model.resolution` | وضوح ویدئوی تولیدشده. گزینه‌های موجود ممکن است به مدل انتخاب‌شده بستگی داشته باشد. | COMBO | بله | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `model.fps` | نرخ فریم ویدئوی تولیدشده. | INT | بله | عدد صحیح (پیش‌فرض: 25) |
| `model.generate_audio` | اینکه برای ویدئو صدا تولید شود یا نه. | BOOLEAN | بله | True<br>False (پیش‌فرض: True) |
| `prompt` | توصیف متنی محتوای ویدئویی که باید تولید شود. باید بین ۱ و ۱۰۰۰۰ کاراکتر باشد. | STRING | بله | ۱ تا ۱۰۰۰۰ کاراکتر |
| `seed` | مقدار seed برای تولید قابل بازتولید. استفاده از همان seed با همان تنظیمات، نتیجه یکسانی تولید می‌کند. | INT | بله | عدد صحیح (پیش‌فرض: 42) |
| `last_frame` | آخرین فریمی که برای ویدئو استفاده می‌شود. | IMAGE | خیر | دقیقاً یک تصویر |

**توجه:** برای `image` تنها یک تصویر پشتیبانی می‌شود. اگر `last_frame` ارائه شود، آن نیز باید دقیقاً شامل یک تصویر باشد. گزینه‌های موجود `model.resolution` ممکن است بسته به گونه `model` انتخاب‌شده متفاوت باشد. قیمت هر اجرا به `model`، `model.duration` و `model.resolution` انتخاب‌شده بستگی دارد.
