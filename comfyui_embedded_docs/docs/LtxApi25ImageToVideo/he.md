# LtxApi25ImageToVideo

הצומת הזה יוצר וידאו באיכות מקצועית מתמונת התחלה באמצעות מודל LTX 2.5. אתה מתאר את תוכן הווידאו עם פרומפט טקסטואלי, בוחר גרסת מודל, ומכוונן משך, רזולוציה, קצב פריימים ויצירת אודיו. ניתן לספק פריים סופי אופציונלי כדי להגדיר את סוף הווידאו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `image` | הפריים הראשון שישמש עבור הווידאו. | IMAGE | כן | בדיוק תמונה אחת |
| `model` | קבוצת הגדרות מודל. בוחר את גרסת מודל LTX 2.5 לשימוש. | COMBO | כן | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `model.duration` | אורך הווידאו הנוצר בשניות. | INT | כן | מספר שלם |
| `model.resolution` | רזולוציה של הווידאו הנוצר. האפשרויות הזמינות עשויות להיות תלויות במודל הנבחר. | COMBO | כן | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `model.fps` | קצב הפריימים של הווידאו הנוצר. | INT | כן | מספר שלם (ברירת מחדל: 25) |
| `model.generate_audio` | האם ליצור אודיו עבור הווידאו. | BOOLEAN | כן | True<br>False (ברירת מחדל: True) |
| `prompt` | תיאור טקסטואלי של תוכן הווידאו שיש ליצור. חייב להיות בין 1 ל-10000 תווים. | STRING | כן | 1 עד 10000 תווים |
| `seed` | ערך seed ליצירה ניתנת לשחזור. שימוש באותו seed עם אותן הגדרות מפיק את אותה תוצאה. | INT | כן | מספר שלם (ברירת מחדל: 42) |
| `last_frame` | הפריים האחרון שישמש עבור הווידאו. | IMAGE | לא | בדיוק תמונה אחת |

**הערה:** רק תמונה אחת נתמכת עבור `image`. אם `last_frame` מסופק, עליו להכיל גם תמונה אחת בדיוק. אפשרויות `model.resolution` הזמינות עשויות להשתנות בהתאם לגרסת ה-`model` הנבחרת. המחיר של הרצה תלוי ב-`model`, `model.duration`, ו-`model.resolution` הנבחרים.

## פלטים
