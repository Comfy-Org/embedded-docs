# LTX 2.5 Изображение в Видео

Этот узел создаёт профессиональное видео из начального изображения с использованием модели LTX 2.5. Вы описываете содержимое видео текстовым запросом, выбираете вариант модели, настраиваете длительность, разрешение, частоту кадров и генерацию аудио. Можно указать необязательный последний кадр, чтобы задать концовку видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Первый кадр, используемый для видео. | IMAGE | Да | Ровно одно изображение |
| `модель` | Группа настроек модели. Выбирает вариант модели LTX 2.5 для использования. | COMBO | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `длительность` | Длительность генерируемого видео в секундах. | INT | Да | Целое число |
| `разрешение` | Разрешение генерируемого видео. Доступные опции могут зависеть от выбранной модели. | COMBO | Да | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `fps` | Частота кадров генерируемого видео. | INT | Да | Целое число (по умолчанию: 25) |
| `генерировать аудио` | Нужно ли генерировать аудио для видео. | BOOLEAN | Да | True<br>False (по умолчанию: True) |
| `промпт` | Текстовое описание содержимого видео для генерации. Должно содержать от 1 до 10000 символов. | STRING | Да | от 1 до 10000 символов |
| `seed` | Значение seed для воспроизводимой генерации. Использование того же seed с теми же настройками даёт тот же результат. | INT | Да | Целое число (по умолчанию: 42) |
| `последний кадр` | Последний кадр, используемый для видео. | IMAGE | Нет | Ровно одно изображение |

**Примечание:** Для `image` поддерживается только одно изображение. Если указан `last_frame`, он также должен содержать ровно одно изображение. Доступные опции `model.resolution` могут различаться в зависимости от выбранного варианта `model`.

## Выходы

| Выход | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео на основе предоставленного начального изображения и настроек генерации. | VIDEO |
