# LtxApi25ImageToVideo

Этот узел генерирует видео профессионального качества на основе исходного изображения. Вы можете выбрать вариант модели LTX 2.5, описать видео с помощью текстового промпта, настроить длительность, разрешение, частоту кадров и генерацию аудио, а также при желании указать конечный кадр. Результатом является видео, которое начинается с предоставленного изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Первый кадр для видео. | IMAGE | Да | Ровно одно изображение |
| `модель` | Группа настроек модели. Выбирает вариант модели LTX 2.5 для использования. | COMBO | Да | "LTX-2.5 (Fast)"<br>"LTX-2.5 (Pro)" |
| `длительность` | Длительность сгенерированного видео в секундах. | INT | Да | Целое число |
| `разрешение` | Разрешение сгенерированного видео. Доступные варианты могут зависеть от выбранной модели. | COMBO | Да | "1280x720"<br>"720x1280"<br>"1920x1080"<br>"1080x1920"<br>"2560x1440"<br>"1440x2560"<br>"3840x2160"<br>"2160x3840" |
| `fps` | Частота кадров сгенерированного видео. | INT | Да | Целое число (по умолчанию: 25) |
| `генерировать аудио` | Нужно ли генерировать аудио для видео. | BOOLEAN | Да | True<br>False |
| `промпт` | Текстовое описание содержимого видео для генерации. Должно содержать от 1 до 10000 символов. | STRING | Да | от 1 до 10000 символов |
| `seed` | Значение сида для воспроизводимой генерации. Использование одного и того же сида с одинаковыми настройками даёт один и тот же результат. | INT | Да | Целое число (по умолчанию: 42) |
| `последний кадр` | Последний кадр для видео. | IMAGE | Нет | Ровно одно изображение |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Сгенерированное видео на основе предоставленного начального изображения и настроек генерации. | VIDEO |
