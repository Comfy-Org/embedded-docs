# Преобразовать цветовое пространство изображения

Узел ImageColorSpace преобразует изображения между цветовыми пространствами sRGB (Rec.709), линейным Rec.709, HDR (Rec.2020 HLG) и HDR PQ (Rec.2020 PQ). При преобразовании в вывод SDR или из HDR PQ в HDR он выполняет тональную компрессию избыточной яркости по всему батчу и сжимает цвета, выходящие за пределы цветового охвата; линейный вывод и преобразования из линейного пространства в HDR сохраняют расширенные значения без тональной компрессии. Преобразования вычисляются в float32, а любой альфа-канал передаётся без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для преобразования. | IMAGE | Да | Любое допустимое изображение. |
| `source` | Цветовое пространство входных пикселей. По умолчанию: "sRGB". | COMBO | Да | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |
| `destination` | Цветовое пространство выходных пикселей. Установите узел сохранения в такое же цветовое пространство. По умолчанию: "sRGB". | COMBO | Да | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Преобразованное изображение в указанном целевом цветовом пространстве. | IMAGE |

## Примечания

- Linear 1.0 использует тот же опорный белый 203 нит, что и sRGB; HLG использует опорный дисплей 1000 нит.
- Линейный вывод и преобразования из линейного пространства в HDR сохраняют расширенные значения без тональной компрессии.
- Вывод SDR и преобразование PQ→HLG выполняют тональную компрессию избыточной яркости по всему батчу (используя одну общую белую точку, чтобы экспозиция не менялась от кадра к кадру) и сжимают цвета, выходящие за пределы цветового охвата.
- Преобразования вычисляются в float32 и возвращают результат на промежуточном устройстве с промежуточным dtype.
- Прямая альфа (straight alpha) не подвергается цветовому преобразованию; преобразуются только каналы RGB.
- Если `source` и `destination` совпадают, цветовое преобразование не применяется — изображение только перемещается на промежуточное устройство с промежуточным dtype.
