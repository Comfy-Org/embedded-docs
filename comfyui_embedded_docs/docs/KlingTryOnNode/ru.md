# Kling Virtual Try-On

Оденьте человека в предмет одежды с помощью виртуальной примерки Kling. Подключите фотографию человека и фотографию одежды, и узел вернёт новое изображение этого человека в этой вещи.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `person_image` | Фотография одного человека, желательно анфас или в три четверти. Изображения со стороной более 2048 пикселей сначала уменьшаются. | IMAGE | Да | N/A |
| `garment_image` | Одежда, которую нужно надеть: фотография товара, раскладка (flat lay), манекен или фото на модели. Фото на модели может перенести остальную часть этого комплекта. Только одежда; обувь, сумки и аксессуары не поддерживаются. | IMAGE | Да | N/A |
| `keep_pose` | Отключите, чтобы позволить позе измениться для лучшей презентации образа. Расширенный параметр (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `seed` | `seed` управляет тем, должен ли узел перезапуститься; результаты недетерминированы независимо от `seed`. Этот параметр имеет функциональность «control after generate» (по умолчанию: 42). | INT | Да | 0–2147483647 |

**Примечание:** Результат имеет тот же размер, что и `person_image`, с ограничением в 2048 пикселей по самой длинной стороне. Оба входных изображения загружаются в API Kling, что может занять некоторое время.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Человек в этом предмете одежды. | IMAGE |
