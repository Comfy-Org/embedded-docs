# Kling Virtual Try-On

Оденьте человека в предмет одежды с помощью виртуальной примерки Kling. Подключите фотографию человека и фотографию одежды, и узел вернёт новое изображение этого человека в этом предмете одежды.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `person_image` | Фотография одного человека, желательно в анфас или в три четверти. Должна быть не менее 300x300 пикселей; изображения со стороной более 2048 пикселей сначала уменьшаются. | IMAGE | Да | N/A |
| `garment_image` | Одежда, которую нужно надеть: фотография товара, раскладка (flat lay), манекен или фото на модели. Фото на модели может перенести остальную часть этого наряда. Должна быть не менее 300x300 пикселей. Только одежда; обувь, сумки и аксессуары не поддерживаются. | IMAGE | Да | N/A |
| `keep_pose` | Отключите, чтобы разрешить изменение позы для лучшей демонстрации наряда. Расширенный параметр (по умолчанию: True). | BOOLEAN | Да | `True`<br>`False` |
| `seed` | `seed` управляет тем, должен ли узел повторно запускаться; результаты недетерминированы независимо от значения seed. У этого параметра есть функциональность «управление после генерации» (по умолчанию: 42). | INT | Да | 0 до 2147483647 |

**Примечание:** Результат имеет тот же размер, что и `person_image`, с ограничением 2048 пикселей по самой длинной стороне. Оба входных изображения загружаются в API Kling, что может занять некоторое время.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Человек, на котором надет предмет одежды. | IMAGE |
