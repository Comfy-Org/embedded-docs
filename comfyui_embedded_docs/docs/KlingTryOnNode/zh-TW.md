# Kling Virtual Try-On

使用 Kling 的虛擬試穿功能為人物換上服裝單品。連接一張人物照片和一張服裝照片，節點會回傳該人物穿著該單品的新圖像。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 單一人物的照片，最好為正面或四分之三視角。必須至少 300x300 像素；任一側超過 2048 像素的圖像會先被縮小。 | IMAGE | 是 | N/A |
| `garment_image` | 要穿上的服裝：商品照、平鋪照、人台照或模特兒實穿照。模特兒實穿照可能會沿用該套穿搭的其他部分。必須至少 300x300 像素。僅限服裝；不支援鞋子、包包和配件。 | IMAGE | 是 | N/A |
| `keep_pose` | 關閉後可讓姿勢改變，以獲得更佳的服裝呈現。進階參數（預設：True）。 | BOOLEAN | 是 | `True`<br>`False` |
| `seed` | Seed 控制節點是否應重新執行；無論 seed 為何，結果都是非確定性的。此參數具有「生成後控制」功能（預設：42）。 | INT | 是 | 0 至 2147483647 |

**注意：** 結果大小與 `person_image` 相同，最長邊上限為 2048 像素。兩個輸入都會上傳至 Kling 的 API，因此可能需要一些時間。

| 輸出名稱 | 描述 | 資料類型 |
|-------------|-------------|-----------|
