# Kling Virtual Try-On

Kling のバーチャル試着を使用して、人物に衣類アイテムを着せます。人物の写真と衣類の写真を接続すると、ノードはその人物がアイテムを着用した新しい画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 人物1人の写真。正面またはスリークォータービューが理想的です。一辺が2048ピクセルを超える画像は、最初にダウンスケールされます。 | IMAGE | はい | N/A |
| `garment_image` | 着用させる衣類：商品写真、フラットレイ、マネキン、またはモデル着用写真。モデル着用写真の場合、そのコーディネートの他の部分も引き継がれることがあります。衣類のみです。靴、バッグ、アクセサリーには対応していません。 | IMAGE | はい | N/A |
| `keep_pose` | オフにすると、衣装をより良く見せるためにポーズの変更を許可します。詳細パラメータ（デフォルト: True）。 | BOOLEAN | はい | `True`<br>`False` |
| `seed` | `seed` はノードを再実行すべきかどうかを制御します。結果は `seed` に関係なく非決定的です。このパラメータには「生成後の制御」機能があります（デフォルト: 42）。 | INT | はい | 0 〜 2147483647 |

**注記:** 結果は `person_image` と同じサイズで、長辺が2048ピクセルに制限されます。両方の入力は Kling の API にアップロードされるため、少し時間がかかる場合があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 衣類アイテムを着用した人物。 | IMAGE |
