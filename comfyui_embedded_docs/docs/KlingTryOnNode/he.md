# KlingTryOnNode

הלבישו אדם בפריט לבוש עם ההלבשה הווירטואלית של Kling. חברו תמונה של אדם ותמונה של הבגד, והצומת מחזיר תמונה חדשה של אותו אדם כשהוא לובש את הפריט.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `person_image` | תמונה של אדם אחד, עדיף חזיתית או בזווית שלושת-הרבעים. חייבת להיות לפחות 300x300 פיקסלים; תמונות שצד כלשהו בהן גדול מ-2048 פיקסלים מוקטנות תחילה. | IMAGE | כן | N/A |
| `garment_image` | הבגד להלבשה: תמונת מוצר, פריסה שטוחה, בובת ראווה, או תמונה על דוגמן. תמונה על דוגמן יכולה להעביר גם את שאר התלבושת. חייבת להיות לפחות 300x300 פיקסלים. בגדים בלבד; נעליים, תיקים ואביזרים אינם נתמכים. | IMAGE | כן | N/A |
| `keep_pose` | השביתו כדי לאפשר לתנוחה להשתנות ולהציג את התלבושת בצורה טובה יותר. פרמטר מתקדם (ברירת מחדל: True). | BOOLEAN | כן | `True`<br>`False` |
| `seed` | הפרמטר `seed` קובע אם הצומת אמור לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. לפרמטר זה יש פונקציונליות של "שליטה לאחר יצירה" (ברירת מחדל: 42). | INT | כן | 0 to 2147483647 |

**הערה:** התוצאה היא באותו גודל כמו `person_image`, כאשר הצד הארוך ביותר מוגבל ל-2048 פיקסלים. שני הקלטים מועלים ל-API של Kling, מה שעשוי לקחת רגע.
