# Kling Virtual Try-On

فردی را با یک تکه لباس، با استفاده از پرو مجازی Kling بپوشانید. عکس یک فرد و عکس یک لباس را متصل کنید؛ گره تصویر جدیدی از همان فرد بازمی‌گرداند که آن لباس را پوشیده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `person_image` | عکس یک فرد، ترجیحاً از روبه‌رو یا نمای سه‌چهارم. تصاویری که یک ضلع آن‌ها بیش از 2048 پیکسل باشد، ابتدا کوچک‌سازی می‌شوند. | IMAGE | بله | N/A |
| `garment_image` | لباسی که باید پوشانده شود: عکس محصول، چیدمان تخت، مانکن، یا عکس روی مدل. عکس روی مدل می‌تواند بقیهٔ آن ست لباس را نیز منتقل کند. فقط پوشاک؛ کفش، کیف و اکسسوری پشتیبانی نمی‌شوند. | IMAGE | بله | N/A |
| `keep_pose` | برای اینکه ژست برای نمایش بهتر لباس تغییر کند، آن را خاموش کنید. پارامتر پیشرفته (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |
| `seed` | `seed` تعیین می‌کند که گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

**توجه:** اندازهٔ نتیجه با `person_image` یکسان است و در بلندترین ضلع به 2048 پیکسل محدود می‌شود. هر دو ورودی به API سرویس Kling بارگذاری می‌شوند که ممکن است کمی زمان ببرد.
