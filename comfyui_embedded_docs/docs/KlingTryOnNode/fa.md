# Kling Virtual Try-On

یک فرد را با قابلیت پرو مجازی Kling به پوشیدن یک قطعه لباس درآورید. عکسی از فرد و عکسی از لباس را متصل کنید؛ گره تصویری جدید از همان فرد در حال پوشیدن آن لباس برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `person_image` | عکس یک نفر، ترجیحاً از روبه‌رو یا نمای سه‌چهارم. باید حداقل 300×300 پیکسل باشد؛ تصاویری که یک ضلع آن‌ها بیش از 2048 پیکسل است، ابتدا کوچک‌سازی می‌شوند. | IMAGE | بله | N/A |
| `garment_image` | لباسی که باید پوشانده شود: عکس محصول، چیدمان تخت، مانکن، یا عکس روی مدل. عکس روی مدل می‌تواند بقیه آن ست لباس را نیز منتقل کند. باید حداقل 300×300 پیکسل باشد. فقط لباس؛ کفش، کیف و لوازم جانبی پشتیبانی نمی‌شوند. | IMAGE | بله | N/A |
| `keep_pose` | غیرفعال کنید تا اجازه دهید حالت بدن برای نمایش بهتر لباس تغییر کند. پارامتر پیشرفته (پیش‌فرض: True). | BOOLEAN | بله | `True`<br>`False` |
| `seed` | `seed` تعیین می‌کند که آیا گره باید دوباره اجرا شود یا نه؛ نتایج بدون توجه به مقدار seed غیرقطعی هستند. این پارامتر قابلیت «کنترل پس از تولید» را دارد (پیش‌فرض: 42). | INT | بله | 0 تا 2147483647 |

**توجه:** نتیجه همان اندازه `person_image` را دارد و حداکثر در بلندترین ضلع به 2048 پیکسل محدود می‌شود. هر دو ورودی به API شرکت Kling آپلود می‌شوند، که ممکن است کمی زمان ببرد.
