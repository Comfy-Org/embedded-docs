# تصيير وضعية الجسم ثلاثية الأبعاد

يعرض بيانات وضعية الجسم ثلاثية الأبعاد في صورة باستخدام نمط قابل للتحديد. تقبل العقدة بيانات الوضعية من متتبع الجسم SAM3D (MHR) أو من هيكل خارجي بمحور Y للأعلى مثل Kimodo، ويمكنها تركيب النتيجة فوق صورة خلفية اختيارية (أو لوحة سوداء عند عدم توفيرها). تتضمن أنماط العرض المتاحة شبكة ثلاثية الأبعاد مظللة، وصورة ظلية ثنائية، وهياكل عظمية بنمط OpenPose ثنائية وثلاثية الأبعاد، وكبسولات الجسم بنمط SCAIL.

## المدخلات

### المدخلات العامة

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `render_style` | وضع العرض. 'mesh' = شبكة MHR ثلاثية الأبعاد مُعرضة عبر الكاميرا. 'silhouette' = قناع ثنائي للشبكة. 'openpose_2d' = هيكل عظمي ثنائي الأبعاد مسطح. 'openpose_3d' = هيكل عظمي OpenPose كنموذج ثلاثي الأبعاد بتظليل مسطح. 'scail' = كبسولات SCAIL ثلاثية الأبعاد. (الافتراضي: "mesh") | DYNAMIC_COMBO | نعم | "mesh"<br>"silhouette"<br>"openpose_2d"<br>"openpose_3d"<br>"scail" |
| `pose_data` | بيانات وضعية MHR، أو بيانات وضعية من هيكل خارجي بمحور Y (KimodoSample). تعمل جميع أنماط العرض مع الهياكل الخارجية التي تحمل خرائط مفاصل OpenPose في `_skeleton_override` الخاصة بها (كما تفعل KimodoSample). | MHR_POSE_DATA or KIMODO_POSE_DATA | نعم | — |
| `background` | خلفية لكل إطار. عند حذفها = لوحة سوداء. | IMAGE | لا | — |
| `width` | عرض الإخراج بالبكسل. 0 = استخدام image_size الأصلي لبيانات الوضعية. إذا تم تعيين أحدهما فقط من العرض/الارتفاع، يتم اشتقاق الآخر مع الحفاظ على نسبة الأبعاد الأصلية. (الافتراضي: 0) | INT | لا | 0 إلى 16384, step 8 |
| `height` | ارتفاع الإخراج بالبكسل. 0 = استخدام image_size الأصلي لبيانات الوضعية. إذا تم تعيين أحدهما فقط من العرض/الارتفاع، يتم اشتقاق الآخر مع الحفاظ على نسبة الأبعاد الأصلية. (الافتراضي: 0) | INT | لا | 0 إلى 16384, step 8 |
| `camera_info` | تجاوز حر للكاميرا بست درجات حرية. عند التوصيل، تُعاد إسقاط الوضعية عبر هذه الكاميرا (الموضع/الهدف/التكبير/الاستدارة/مجال الرؤية) بدلاً من الكاميرا المتوقعة. | LOAD_3D_CAMERA | لا | — |

### مدخلات الشبكة

تظهر هذه المعاملات عندما يكون `render_style` هو "mesh".

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `shader` | تظليل مسبق الإعداد. 'normals' = العمود السطحي الحالي في فضاء الكاميرا (اصطلاح خريطة العمود OpenGL Y+: +X→R، +Y→G، +Z→B). 'rainbow' = تدرج ألوان الجسم- Y بنمط RealisDance؛ تنويعات 'rainbow_face_*' تستبدل رؤوس الوجه بألوان العمود/المنطقة؛ 'depth' = رمادي خطي. (الافتراضي: "default") | DYNAMIC_COMBO | لا | "default"<br>"normals"<br>"rainbow"<br>"rainbow_face_normal"<br>"rainbow_face_semantic"<br>"depth" |
| `rainbow_tilt_z` | يدور محور تدرج الألوان حول Z (للأمام). يميّز بين اليسار/اليمين. متاح فقط عندما يكون `shader` هو "rainbow" أو "rainbow_face_normal" أو "rainbow_face_semantic". (الافتراضي: -35.0) | FLOAT | لا | -90.0 إلى 90.0, step 0.5 |
| `rainbow_tilt_x` | يدور محور تدرج الألوان حول X (لليمين). يميّز بين الأمام/الخلف. متاح فقط عندما يكون `shader` هو "rainbow" أو "rainbow_face_normal" أو "rainbow_face_semantic". (الافتراضي: 0.0) | FLOAT | لا | -90.0 إلى 90.0, step 0.5 |
| `opacity` | شفافية الشبكة فوق صورة الخلفية، أو فوق الأسود عند عدم توصيل أي خلفية. (الافتراضي: 1.0) | FLOAT | لا | 0.0 إلى 1.0, step 0.01 |
| `person_palette_falloff` | إزالة تشبع لكل شخص نحو الأبيض: المسار k يحصل على مزيج باستيل (1 - falloff^k) (SCAIL 'الشخص الثاني الأكثر نعومة'). 1.0 = معطّل. (الافتراضي: 0.6) | FLOAT | لا | 0.1 إلى 1.0, step 0.05 |
| `region` | 'hands_only' يفلتر الوجوه عبر `hand_vert_mask` المحسوب مسبقًا (أوزان LBS مقابل نقاط مرجعية لليد) — يعزل شبكة اليد لتصحيح الأخطاء. يتراجع إلى الشبكة الكاملة إذا كانت القناع مفقودًا. (الافتراضي: "full_body") | COMBO | لا | "full_body"<br>"hands_only" |

### مدخلات الصورة الظلية

عندما يكون `render_style` هو "silhouette"، تعرض العقدة قناعًا ثنائيًا للشبكة ثلاثية الأبعاد. لا يحتوي هذا الوضع على معاملات إضافية.

### مدخلات OpenPose ثنائية الأبعاد

تظهر هذه المعاملات عندما يكون `render_style` هو "openpose_2d".

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `marker_radius_px` | نصف قطر نقطة النقطة الرئيسية للجسم (بكسل). (الافتراضي: 4) | INT | لا | 1 إلى 32, step 1 |
| `stick_width_px` | نصف عرض قطع ناقص لطرف الجسم (بكسل). القيمة الافتراضية DWPose = 4. (الافتراضي: 4) | INT | لا | 1 إلى 32, step 1 |
| `limb_alpha` | الشفافية لكل طرف. القيمة الافتراضية DWPose = 0.6. (الافتراضي: 0.6) | FLOAT | لا | 0.0 إلى 1.0, step 0.05 |
| `face_style` | 'full' = جميع معالم الوجه (sapiens-238 إذا كانت موجودة، وإلا تراجع الهيكل ~30). 'eyes_mouth' = مجموعة فرعية من تراجع الهيكل (~12 نقطة: العينان والشفتان الخارجيتان فقط). 'disabled' = لا نقاط وجه. (الافتراضي: "disabled") | COMBO | لا | "disabled"<br>"full"<br>"eyes_mouth" |
| `hand_style` | رسم 21+21 نقطة رئيسية لليد + خطوط الربط. 'disabled' = بدون يدين. 'dwpose' = نقاط زرقاء مصمتة؛ 'openpose' = نقاط ملونة بطيف الألوان. (الافتراضي: "disabled") | COMBO | لا | "disabled"<br>"dwpose"<br>"openpose" |
| `person_palette_falloff` | إزالة تشبع لكل شخص: المسار k يمتزج نحو الأبيض بمقدار 1 - falloff^k. يبقى المسار 0 نابضًا بالحياة؛ 1.0 يعطل التلاشي. (الافتراضي: 0.6) | FLOAT | لا | 0.1 إلى 1.0, step 0.05 |

### مدخلات OpenPose ثلاثية الأبعاد

تظهر هذه المعاملات عندما يكون `render_style` هو "openpose_3d".

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `radius_m` | نصف قطر كبسولة الطرف بالأمتار (رفيع = شبيه بالعصا). (الافتراضي: 0.015) | FLOAT | لا | 0.004 إلى 0.1, step 0.001 |
| `include_hands` | رسم 21+21 نقطة رئيسية لليد ككبسولات ثلاثية الأبعاد. (الافتراضي: True) | BOOLEAN | لا | True or False |
| `person_palette_falloff` | إزالة تشبع لكل شخص: المسار k يمتزج نحو الأبيض بمقدار 1 - falloff^k. يبقى المسار 0 نابضًا بالحياة؛ 1.0 يعطل التلاشي. (الافتراضي: 0.6) | FLOAT | لا | 0.1 إلى 1.0, step 0.05 |

### مدخلات SCAIL

تظهر هذه المعاملات عندما يكون `render_style` هو "scail".

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `radius_m` | نصف قطر الكبسولة بالأمتار (مرجع SCAIL: ~0.022 م). (الافتراضي: 0.022) | FLOAT | لا | 0.005 إلى 0.2, step 0.001 |
| `hand_style` | تركيب يدين OpenPose ثنائيتي الأبعاد فوق جسم الكبسولة ثلاثي الأبعاد (يطابق SCAIL — لا توجد كبسولات يد ثلاثية الأبعاد). 'disabled' = بدون يدين. 'dwpose' = نقاط يد زرقاء مصمتة؛ 'openpose' = نقاط ملونة بطيف الألوان. تظل خطوط الربط ملونة بطيف الألوان لكل إصبع في كلتا الحالتين. (الافتراضي: "dwpose") | COMBO | لا | "disabled"<br>"dwpose"<br>"openpose" |
| `face_style` | 'full' = جميع معالم الوجه (sapiens-238 إذا كانت موجودة، وإلا تراجع الهيكل ~30). 'eyes_mouth' = مجموعة فرعية من تراجع الهيكل (~12 نقطة: العينان والشفتان الخارجيتان فقط). 'disabled' = لا نقاط وجه. (الافتراضي: "disabled") | COMBO | لا | "disabled"<br>"full"<br>"eyes_mouth" |
| `person_palette_falloff` | إزالة تشبع لكل شخص: المسار k يمتزج نحو الأبيض بمقدار 1 - falloff^k. يبقى المسار 0 نابضًا بالحياة؛ 1.0 يعطل التلاشي. (الافتراضي: 0.6) | FLOAT | لا | 0.1 إلى 1.0, step 0.05 |

### ملاحظات

- إذا كان كل من `width` و `height` يساويان 0، يستخدم الإخراج حجم الصورة الأصلي لبيانات الوضعية. إذا تم تعيين أحدهما فقط، يتم اشتقاق الآخر مع الحفاظ على نسبة الأبعاد الأصلية. يتم تغيير حجم `background` المتصل ليطابق دقة العرض.
- عند توصيل `camera_info`، تُعاد إسقاط الوضعية عبر تلك الكاميرا بدلاً من الكاميرا المتوقعة.
- في وضع الشبكة، يتوفر `rainbow_tilt_z` و `rainbow_tilt_x` فقط عندما يكون `shader` مضبوطًا على "rainbow" أو "rainbow_face_normal" أو "rainbow_face_semantic".
- في وضع الشبكة، عندما يكون `region` هو "hands_only"، يتطلب فلتر منطقة اليد أن تحتوي بيانات الوضعية على قناع رؤوس اليد؛ إذا كان القناع مفقودًا، يتم عرض الشبكة الكاملة بدلاً من ذلك.
- في وضع scail، تُرسم اليدان دائمًا كطبقات متراكبة ثنائية الأبعاد؛ لا توجد كبسولات يد ثلاثية الأبعاد.
- عندما تختلف دقة الإخراج عن الدقة الأصلية لبيانات الوضعية، يتم قياس أحجام علامات وخطوط openpose_2d بشكل تناسبي.
- إذا كانت الخلفية تحتوي على إطارات أقل من بيانات الوضعية، يُعاد استخدام آخر إطار خلفية للإطارات المتبقية.
- يحتوي الإخراج على إطار واحد لكل إطار وضعية مدخل. إذا كانت بيانات الوضعية لا تحتوي على إطارات، يتم إرجاع صورة سوداء واحدة.
