# Визуализировать 3D-позу тела

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `render_style` | Режим рендеринга. 'mesh' — 3D-сетка MHR, растеризованная через камеру. 'silhouette' — бинарная маска сетки. 'openpose_2d' — плоский 2D-скелет. 'openpose_3d' — скелет OpenPose в виде 3D-модели с плоской заливкой. 'scail' — 3D-капсулы SCAIL. (по умолчанию: "mesh") | DYNAMIC_COMBO | Да | "mesh"<br>"silhouette"<br>"openpose_2d"<br>"openpose_3d"<br>"scail" |
| `pose_data` | Данные позы MHR или данные позы внешнего Y-up рига (KimodoSample). Все стили рендеринга работают для внешних ригов, которые содержат карты суставов OpenPose в своём `_skeleton_override` (KimodoSample содержит). | MHR_POSE_DATA или KIMODO_POSE_DATA | Да | — |
| `фон` | Покадровый фон. Если не задан — чёрный холст. | IMAGE | Нет | — |
| `ширина` | Ширина выходного изображения в пикселях. 0 = использовать собственный image_size данных позы. Если задан только один из параметров width/height, второй вычисляется с сохранением исходного соотношения сторон. (по умолчанию: 0) | INT | Нет | от 0 до 16384, step 8 |
| `высота` | Высота выходного изображения в пикселях. 0 = использовать собственный image_size данных позы. Если задан только один из параметров width/height, второй вычисляется с сохранением исходного соотношения сторон. (по умолчанию: 0) | INT | Нет | от 0 до 16384, step 8 |
| `camera_info` | Переопределение свободной камеры 6DOF. При подключении поза проецируется через эту камеру (позиция/цель/зум/поворот/FoV) вместо предсказанной. | LOAD_3D_CAMERA | Нет | — |

### Входы Mesh

Эти параметры появляются, когда `render_style` установлен в "mesh".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `shader` | Предустановленный шейдер. 'normals' — текущая нормаль поверхности в пространстве камеры (соглашение карт нормалей OpenGL Y+: +X→R, +Y→G, +Z→B). 'rainbow' — радужная градация jet по оси Y тела в стиле RealisDance; варианты 'rainbow_face_*' переопределяют вершины лица цветами нормалей/регионов; 'depth' — линейный серый. (по умолчанию: "default") | DYNAMIC_COMBO | Нет | "default"<br>"normals"<br>"rainbow"<br>"rainbow_face_normal"<br>"rainbow_face_semantic"<br>"depth" |
| `rainbow_tilt_z` | Поворот оси радужной градации вокруг Z (вперёд). Различает лево/право. Доступен только когда `shader` равен "rainbow", "rainbow_face_normal" или "rainbow_face_semantic". (по умолчанию: -35.0) | FLOAT | Нет | -от 90.0 до 90.0, step 0.5 |
| `rainbow_tilt_x` | Поворот оси радужной градации вокруг X (вправо). Различает перед/зад. Доступен только когда `shader` равен "rainbow", "rainbow_face_normal" или "rainbow_face_semantic". (по умолчанию: 0.0) | FLOAT | Нет | -от 90.0 до 90.0, step 0.5 |
| `opacity` | Альфа сетки поверх фонового изображения или поверх чёрного, если фон не подключён. (по умолчанию: 1.0) | FLOAT | Нет | от 0.0 до 1.0, step 0.01 |
| `person_palette_falloff` | Обесцвечивание для каждого человека в сторону белого: трек k получает пастельную смесь (1 - falloff^k) (SCAIL «более мягкий второй человек»). 1.0 — выключено. (по умолчанию: 0.6) | FLOAT | Нет | от 0.1 до 1.0, step 0.05 |
| `region` | 'hands_only' фильтрует грани через предварительно вычисленную `hand_vert_mask` (веса LBS относительно канонических ключевых точек кисти) — изолирует сетку кисти для отладки. Если маска отсутствует, используется полная сетка. (по умолчанию: "full_body") | COMBO | Нет | "full_body"<br>"hands_only" |

### Входы Silhouette

Когда `render_style` установлен в "silhouette", узел рендерит бинарную маску 3D-сетки. В этом режиме нет дополнительных параметров.

### Входы OpenPose 2D

Эти параметры появляются, когда `render_style` установлен в "openpose_2d".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `marker_radius_px` | Радиус точки ключевой точки тела (px). (по умолчанию: 4) | INT | Нет | от 1 до 32, step 1 |
| `stick_width_px` | Полуширина эллипса конечности тела (px). По умолчанию DWPose = 4. (по умолчанию: 4) | INT | Нет | от 1 до 32, step 1 |
| `limb_alpha` | Альфа каждой конечности. По умолчанию DWPose = 0.6. (по умолчанию: 0.6) | FLOAT | Нет | от 0.0 до 1.0, step 0.05 |
| `face_style` | 'full' — все лицевые ключевые точки (sapiens-238, если доступны, иначе запасной вариант рига ~30). 'eyes_mouth' — подмножество запасного варианта рига (~12 точек: только глаза и внешний контур губ). 'disabled' — без лицевых точек. (по умолчанию: "disabled") | COMBO | Нет | "disabled"<br>"full"<br>"eyes_mouth" |
| `hand_style` | Рисовать 21+21 ключевых точек кистей и линии. 'disabled' — без кистей. 'dwpose' — синие точки; 'openpose' — радужные точки. (по умолчанию: "disabled") | COMBO | Нет | "disabled"<br>"dwpose"<br>"openpose" |
| `person_palette_falloff` | Обесцвечивание для каждого человека: трек k смешивается к белому на 1 - falloff^k. Трек 0 остаётся ярким; 1.0 отключает обесцвечивание. (по умолчанию: 0.6) | FLOAT | Нет | от 0.1 до 1.0, step 0.05 |

### Примечания

- Если `width` и `height` равны 0, выходное изображение использует собственный размер изображения данных позы. Если задан только один из них, второй вычисляется с сохранением исходного соотношения сторон. Подключённый `background` масштабируется под разрешение рендеринга.
- Когда `camera_info` подключена, поза проецируется через эту камеру вместо предсказанной.
- В режиме mesh параметры `rainbow_tilt_z` и `rainbow_tilt_x` доступны только когда `shader` установлен в "rainbow", "rainbow_face_normal" или "rainbow_face_semantic".
- В режиме mesh, когда `region` равен "hands_only", фильтр области кистей требует, чтобы данные позы содержали маску вершин кистей; если маска отсутствует, вместо неё рендерится полная сетка.
- В режиме scail кисти всегда рисуются как 2D-оверлеи; 3D-капсул для кистей нет.
- Когда разрешение вывода отличается от собственного разрешения данных позы, размеры маркеров и линий openpose_2d масштабируются пропорционально.
- Если в фоне меньше кадров, чем в данных позы, последний кадр фона используется для остальных кадров.
- Выходные данные содержат один кадр на каждый входной кадр позы. Если данные позы не содержат кадров, возвращается одно чёрное изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `изображение` | Отрендеренные кадры: данные позы, отрисованные в выбранном стиле рендеринга, скомпонованные поверх фона, если он подключён, или поверх чёрного в противном случае. Один кадр на каждый входной кадр позы, возвращается в виде одного пакетного изображения. | IMAGE |
