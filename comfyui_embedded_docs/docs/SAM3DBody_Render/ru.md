# Визуализировать 3D-позу тела

Отрисовывает данные 3D-позы тела в изображение с использованием выбираемого стиля. Узел принимает данные позы от трекера тела SAM3D (MHR) или от внешнего Y-up-рига, такого как Kimodo, и может накладывать результат на необязательное фоновое изображение (или на чёрное полотно, если оно не задано). Доступные стили отрисовки включают затенённую 3D-сетку, бинарный силуэт, скелеты в стиле OpenPose 2D и 3D, а также капсулы тела в стиле SCAIL.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `render_style` | Режим отрисовки. 'mesh' = 3D MHR-сетка, растеризованная через камеру. 'silhouette' = бинарная маска сетки. 'openpose_2d' = плоский 2D-скелет. 'openpose_3d' = скелет OpenPose в виде 3D-модели с плоским затенением. 'scail' = 3D-капсулы SCAIL. (по умолчанию: "mesh") | DYNAMIC_COMBO | Да | "mesh"<br>"silhouette"<br>"openpose_2d"<br>"openpose_3d"<br>"scail" |
| `pose_data` | Данные позы MHR или данные позы внешнего Y-up-рига (KimodoSample). Все стили отрисовки работают для внешних ригов, которые содержат карты суставов OpenPose в своём `_skeleton_override` (KimodoSample содержит). | MHR_POSE_DATA or KIMODO_POSE_DATA | Да | — |
| `фон` | Покадровый фон. Если не задан = чёрное полотно. | IMAGE | Нет | — |
| `ширина` | Ширина вывода в пикселях. 0 = использовать собственный размер изображения из данных позы. Если задан только один из параметров width/height, другой вычисляется с сохранением исходного соотношения сторон. (по умолчанию: 0) | INT | Нет | 0 до 16384, step 8 |
| `высота` | Высота вывода в пикселях. 0 = использовать собственный размер изображения из данных позы. Если задан только один из параметров width/height, другой вычисляется с сохранением исходного соотношения сторон. (по умолчанию: 0) | INT | Нет | 0 до 16384, step 8 |
| `camera_info` | Свободное переопределение 6DOF-камеры. Когда подключено, поза повторно проецируется через эту камеру (положение/цель/зум/поворот/FoV) вместо предсказанной. | LOAD_3D_CAMERA | Нет | — |

### Входы Mesh

Эти параметры появляются, когда `render_style` имеет значение "mesh".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `shader` | Предустановленный шейдер. 'normals' = текущая нормаль поверхности в пространстве камеры (соглашение карты нормалей OpenGL Y+: +X→R, +Y→G, +Z→B). 'rainbow' = градиент body-Y в стиле RealisDance; варианты 'rainbow_face_*' переопределяют вершины лица цветами нормалей/по регионам; 'depth' = линейный серый. (по умолчанию: "default") | DYNAMIC_COMBO | Нет | "default"<br>"normals"<br>"rainbow"<br>"rainbow_face_normal"<br>"rainbow_face_semantic"<br>"depth" |
| `rainbow_tilt_z` | Поворот оси градиента rainbow вокруг Z (вперёд). Различает лево/право. Доступно только когда `shader` равен "rainbow", "rainbow_face_normal" или "rainbow_face_semantic". (по умолчанию: -35.0) | FLOAT | Нет | -90.0 до 90.0, step 0.5 |
| `rainbow_tilt_x` | Поворот оси градиента rainbow вокруг X (вправо). Различает перед/зад. Доступно только когда `shader` равен "rainbow", "rainbow_face_normal" или "rainbow_face_semantic". (по умолчанию: 0.0) | FLOAT | Нет | -90.0 до 90.0, step 0.5 |
| `opacity` | Альфа-канал сетки поверх фонового изображения или поверх чёрного, если фон не подключён. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 до 1.0, step 0.01 |
| `person_palette_falloff` | Обесцвечивание в сторону белого для каждого человека: трек k получает пастельную смесь (1 - falloff^k) (SCAIL 'softer second person'). 1.0 = выключено. (по умолчанию: 0.6) | FLOAT | Нет | 0.1 до 1.0, step 0.05 |
| `region` | 'hands_only' фильтрует грани через предвычисленную `hand_vert_mask` (LBS-веса относительно канонических ключевых точек (KP) руки) — изолирует сетку руки для отладки. При отсутствии маски возвращается к полной сетке. (по умолчанию: "full_body") | COMBO | Нет | "full_body"<br>"hands_only" |

### Входы Silhouette

Когда `render_style` имеет значение "silhouette", узел отрисовывает бинарную маску 3D-сетки. У этого режима нет дополнительных параметров.

### Входы OpenPose 2D

Эти параметры появляются, когда `render_style` имеет значение "openpose_2d".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `marker_radius_px` | Радиус маркера ключевой точки тела (px). (по умолчанию: 4) | INT | Нет | 1 до 32, step 1 |
| `stick_width_px` | Полуширина эллипса конечности тела (px). Значение по умолчанию DWPose = 4. (по умолчанию: 4) | INT | Нет | 1 до 32, step 1 |
| `limb_alpha` | Альфа для каждой конечности. Значение по умолчанию DWPose = 0.6. (по умолчанию: 0.6) | FLOAT | Нет | 0.0 до 1.0, step 0.05 |
| `face_style` | Стиль лица. 'full' = все ключевые точки лица (sapiens-238, если присутствует, иначе rig-fallback ~30). 'eyes_mouth' = подмножество rig-fallback (~12 точек: только глаза + внешние губы). 'disabled' = без точек лица. (по умолчанию: "disabled") | COMBO | Нет | "disabled"<br>"full"<br>"eyes_mouth" |
| `hand_style` | Рисовать 21+21 ключевых точек рук + линии. 'disabled' = без рук. 'dwpose' = сплошные синие точки; 'openpose' = радужные точки. (по умолчанию: "disabled") | COMBO | Нет | "disabled"<br>"dwpose"<br>"openpose" |
| `person_palette_falloff` | Обесцвечивание для каждого человека: трек k смешивается с белым на 1 - falloff^k. Трек 0 остаётся ярким; 1.0 отключает falloff. (по умолчанию: 0.6) | FLOAT | Нет | 0.1 до 1.0, step 0.05 |

### Входы OpenPose 3D

Эти параметры появляются, когда `render_style` имеет значение "openpose_3d".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `radius_m` | Радиус капсулы конечности в метрах (тонкий = похожий на палочку). (по умолчанию: 0.015) | FLOAT | Нет | 0.004 до 0.1, step 0.001 |
| `include_hands` | Рисовать 21+21 ключевых точек рук в виде 3D-капсул. (по умолчанию: True) | BOOLEAN | Нет | True or False |
| `person_palette_falloff` | Обесцвечивание для каждого человека: трек k смешивается с белым на 1 - falloff^k. Трек 0 остаётся ярким; 1.0 отключает falloff. (по умолчанию: 0.6) | FLOAT | Нет | 0.1 до 1.0, step 0.05 |

### Входы SCAIL

Эти параметры появляются, когда `render_style` имеет значение "scail".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `radius_m` | Радиус капсулы в метрах (эталон SCAIL: ~0.022 м). (по умолчанию: 0.022) | FLOAT | Нет | 0.005 до 0.2, step 0.001 |
| `hand_style` | Накладывать 2D-руки OpenPose поверх 3D-капсульного тела (соответствует SCAIL — без 3D-капсул рук). 'disabled' = без рук. 'dwpose' = сплошные синие точки рук; 'openpose' = радужные точки. Линии в любом случае остаются радужными для каждого пальца. (по умолчанию: "dwpose") | COMBO | Нет | "disabled"<br>"dwpose"<br>"openpose" |
| `face_style` | Стиль лица. 'full' = все ключевые точки лица (sapiens-238, если присутствует, иначе rig-fallback ~30). 'eyes_mouth' = подмножество rig-fallback (~12 точек: только глаза + внешние губы). 'disabled' = без точек лица. (по умолчанию: "disabled") | COMBO | Нет | "disabled"<br>"full"<br>"eyes_mouth" |
| `person_palette_falloff` | Обесцвечивание для каждого человека: трек k смешивается с белым на 1 - falloff^k. Трек 0 остаётся ярким; 1.0 отключает falloff. (по умолчанию: 0.6) | FLOAT | Нет | 0.1 до 1.0, step 0.05 |

### Примечания

- Если и `width`, и `height` равны 0, вывод использует собственный размер изображения из данных позы. Если задан только один из них, другой вычисляется с сохранением исходного соотношения сторон. Подключённый `background` масштабируется до разрешения рендера.
- Когда `camera_info` подключён, поза повторно проецируется через эту камеру вместо предсказанной.
- В режиме mesh параметры `rainbow_tilt_z` и `rainbow_tilt_x` доступны только когда `shader` установлен в "rainbow", "rainbow_face_normal" или "rainbow_face_semantic".
- В режиме mesh, когда `region` имеет значение "hands_only", фильтр области рук требует, чтобы данные позы содержали маску вершин руки; если маска отсутствует, вместо этого отрисовывается полная сетка.
- В режиме scail руки отрисовываются как 2D-наложения OpenPose поверх 3D-капсульного тела, а не как 3D-капсулы; установка `hand_style` в "disabled" полностью убирает их.
- Когда разрешение вывода отличается от собственного разрешения данных позы, размеры маркеров и линий openpose_2d масштабируются пропорционально.
- Если фон содержит меньше кадров, чем данные позы, последний кадр фона повторно используется для оставшихся кадров.
- Вывод содержит один кадр на каждый входной кадр позы. Если данные позы не содержат кадров, возвращается одно чёрное изображение.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Отрисованные кадры: данные позы, отрисованные в выбранном стиле отрисовки, наложенные на фон, если он подключён, или иначе на чёрный фон. Один кадр на каждый входной кадр позы, возвращается как одно батчевое изображение. | IMAGE |
