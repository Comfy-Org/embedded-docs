# ElevenLabsVoiceSelector

צומת ElevenLabs Voice Selector מאפשר לבחור קול ספציפי מתוך רשימה מוגדרת מראש של קולות ElevenLabs להמרת טקסט לדיבור. הוא מקבל שם קול כקלט ומוציא את מזהה הקול המתאים הדרוש ליצירת אודיו. צומת זה מפשט את תהליך בחירת קול תואם לשימוש עם צמתי אודיו אחרים של ElevenLabs.
