# صورة كامنة فارغة من StableCascade

تنشئ عقدة `StableCascade_EmptyLatentImage` موترات كامنة فارغة لنماذج Stable Cascade. تُولّد تمثيلين كامنين منفصلين - أحدهما للمرحلة C والآخر للمرحلة B - بأبعاد مناسبة بناءً على دقة الإدخال وإعدادات الضغط. توفر هذه العقدة نقطة البداية لخط أنابيب توليد Stable Cascade.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `العرض` | عرض الصورة الناتجة بالبكسل (الافتراضي: 1024، الخطوة: 8) | INT | نعم | 256 إلى MAX_RESOLUTION |
| `الارتفاع` | ارتفاع الصورة الناتجة بالبكسل (الافتراضي: 1024، الخطوة: 8) | INT | نعم | 256 إلى MAX_RESOLUTION |
| `ضغط` | عامل الضغط الذي يحدد الأبعاد الكامنة للمرحلة C (الافتراضي: 42، الخطوة: 1). هذه معلمة متقدمة. | INT | نعم | 4 إلى 128 |
| `حجم الدفعة` | عدد العينات الكامنة التي سيتم توليدها في دفعة واحدة (الافتراضي: 1) | INT | لا | 1 إلى 4096 |

ملاحظة: تتحكم قيمة `compression` في الحجم الكامن للمرحلة C: حيث يتم قسمة كل من `height` و`width` المدخلين على `compression`. بينما يستخدم كمون المرحلة B دائمًا ضغطًا ثابتًا قيمته 4.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `المرحلة_ج` | الموتر الكامن للمرحلة C بأبعاد [batch_size, 16, height//compression, width//compression] | LATENT |
| `المرحلة_ب` | الموتر الكامن للمرحلة B بأبعاد [batch_size, 4, height//4, width//4] | LATENT |
