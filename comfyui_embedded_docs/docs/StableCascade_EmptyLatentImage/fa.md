# StableCascade_EmptyLatentImage

گره StableCascade_EmptyLatentImage تنسورهای خالی لاتنت را برای مدل‌های Stable Cascade ایجاد می‌کند. این گره دو نمایش لاتنت جداگانه تولید می‌کند - یکی برای مرحله C و دیگری برای مرحله B - با ابعاد مناسب بر اساس رزولوشن ورودی و تنظیمات فشرده‌سازی. این گره نقطه شروع خط تولید Stable Cascade را فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `عرض` | عرض تصویر خروجی بر حسب پیکسل (پیش‌فرض: 1024، گام: 8) | INT | بله | 256 to MAX_RESOLUTION |
| `ارتفاع` | ارتفاع تصویر خروجی بر حسب پیکسل (پیش‌فرض: 1024، گام: 8) | INT | بله | 256 to MAX_RESOLUTION |
| `فشرده‌سازی` | ضریب فشرده‌سازی که ابعاد لاتنت را برای مرحله C تعیین می‌کند (پیش‌فرض: 42، گام: 1). این یک پارامتر پیشرفته است. | INT | بله | 4 تا 128 |
| `اندازه بچ` | تعداد نمونه‌های لاتنت که در یک دسته تولید می‌شوند (پیش‌فرض: 1) | INT | خیر | 1 تا 4096 |

نکته: مقدار `compression` اندازه لاتنت مرحله C را کنترل می‌کند: ارتفاع و عرض آن برابر با `height` و `width` ورودی تقسیم بر `compression` است. لاتنت مرحله B همیشه از فشرده‌سازی ثابت 4 استفاده می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `stage_c` | تنسور لاتنت مرحله C با ابعاد [batch_size, 16, height//compression, width//compression] | LATENT |
| `stage_b` | تنسور لاتنت مرحله B با ابعاد [batch_size, 4, height//4, width//4] | LATENT |
