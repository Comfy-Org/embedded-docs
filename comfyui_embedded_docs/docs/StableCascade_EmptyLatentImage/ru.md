# StableCascade_Пустое латентное изображение

Узел StableCascade_EmptyLatentImage создаёт пустые латентные тензоры для моделей Stable Cascade. Он генерирует два отдельных латентных представления — одно для стадии C, другое для стадии B — с размерами, вычисляемыми на основе входного разрешения и настроек сжатия. Этот узел служит отправной точкой для пайплайна генерации Stable Cascade.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | от 256 до MAX_RESOLUTION |
| `высота` | Высота выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | от 256 до MAX_RESOLUTION |
| `сжатие` | Коэффициент сжатия, определяющий размеры латентного представления для стадии C (по умолчанию: 42, шаг: 1). Это расширенный параметр. | INT | Да | от 4 до 128 |
| `размер_пакета` | Количество латентных образцов, генерируемых в пакете (по умолчанию: 1) | INT | Да | от 1 до 4096 |

Примечание. Значение `compression` управляет размером латентного представления стадии C: его высота и ширина равны входным `height` и `width`, разделённым на `compression`. Латентное представление стадии B всегда использует фиксированное сжатие 4.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `stage_c` | Латентный тензор стадии C с размерами [batch_size, 16, height//compression, width//compression] | LATENT |
| `stage_b` | Латентный тензор стадии B с размерами [batch_size, 4, height//4, width//4] | LATENT |
