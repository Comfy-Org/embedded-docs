# StableCascade_Пустое латентное изображение

Узел `StableCascade_EmptyLatentImage` создаёт пустые латентные тензоры для моделей Stable Cascade. Он генерирует два отдельных латентных представления — одно для этапа C и другое для этапа B — с соответствующими размерами на основе входного разрешения и настроек сжатия. Этот узел является отправной точкой для конвейера генерации Stable Cascade.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `width` | Ширина выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | 256 to MAX_RESOLUTION |
| `height` | Высота выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | 256 to MAX_RESOLUTION |
| `compression` | Коэффициент сжатия, определяющий размеры латентного пространства для этапа C (по умолчанию: 42, шаг: 1). Это дополнительный (продвинутый) параметр. | INT | Да | 4 to 128 |
| `batch_size` | Количество латентных сэмплов для генерации в одном пакете (по умолчанию: 1) | INT | Нет | 1 to 4096 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `stage_c` | Латентный тензор этапа C с размерами [batch_size, 16, height//compression, width//compression] | LATENT |
| `stage_b` | Латентный тензор этапа B с размерами [batch_size, 4, height//4, width//4] | LATENT |
