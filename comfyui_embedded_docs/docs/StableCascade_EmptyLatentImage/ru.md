# StableCascade_Пустое латентное изображение

Узел StableCascade_EmptyLatentImage создает пустые латентные тензоры для моделей Stable Cascade. Он генерирует два отдельных латентных представления — одно для стадии C и другое для стадии B — с соответствующими размерами, основанными на входном разрешении и настройках сжатия. Этот узел обеспечивает отправную точку для конвейера генерации Stable Cascade.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `ширина` | Ширина выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | от 256 до MAX_RESOLUTION |
| `высота` | Высота выходного изображения в пикселях (по умолчанию: 1024, шаг: 8) | INT | Да | от 256 до MAX_RESOLUTION |
| `сжатие` | Коэффициент сжатия, определяющий размеры латентного пространства для стадии C (по умолчанию: 42, шаг: 1). Это расширенный параметр. | INT | Да | от 4 до 128 |
| `размер_пакета` | Количество латентных образцов для генерации в одном пакете (по умолчанию: 1) | INT | Нет | от 1 до 4096 |

Примечание: значение `compression` управляет размером латентного пространства стадии C: его высота и ширина равны входным значениям `height` и `width`, разделенным на `compression`. Латентное пространство стадии B всегда использует фиксированное сжатие 4.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `этап_c` | Латентный тензор стадии C с размерами [batch_size, 16, height//compression, width//compression] | LATENT |
| `этап_b` | Латентный тензор стадии B с размерами [batch_size, 4, height//4, width//4] | LATENT |
