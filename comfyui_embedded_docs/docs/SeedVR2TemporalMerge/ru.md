# Объединить SeedVR2 latents

Этот узел объединяет семплированные временные чанки скрытого представления SeedVR2 в одно полное скрытое представление полной длины. Когда указано временное перекрытие, он применяет кроссфейд с окном Ханна к каждой перекрывающейся области для создания плавных переходов между чанками; когда перекрытие равно 0, выполняется простое объединение.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `latents` | Семплированные временные чанки в порядке следования. | LATENT | Да | Список скрытых представлений |
| `temporal_overlap` | Значение temporal_overlap из выхода узла Split SeedVR2 Latent. 0 = простое объединение. (по умолчанию: 0) | INT | Да | от 0 до 16384 |

**Примечание:** Значение `temporal_overlap` должно быть больше или равно 0. Все чанки должны быть 5-мерными видеолатентами (B, C, T, H, W) и совпадать по всем размерностям, кроме временной оси (T); только последний чанк может быть короче остальных. Если передан только один чанк, он возвращается без изменений.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `latent` | Объединенное скрытое представление полной длины. | LATENT |
