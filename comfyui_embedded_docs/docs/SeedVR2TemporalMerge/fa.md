# ادغام نهفته‌های SeedVR2

این گره، تکه‌های زمانی نهان (latent temporal chunks) نمونه‌برداری‌شده از SeedVR2 را دوباره به یک نهان تمام‌طول واحد ترکیب می‌کند. وقتی هم‌پوشانی زمانی مشخص شود، برای ایجاد انتقال‌های نرم بین تکه‌ها، روی هر ناحیه هم‌پوشانی کراس‌فید با پنجره هان اعمال می‌کند؛ و وقتی هم‌پوشانی ۰ باشد، اتصال ساده انجام می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `latents` | تکه‌های زمانی نهان نمونه‌برداری‌شده به ترتیب توالی. | LATENT | بله | فهرستی از latents |
| `temporal_overlap` | خروجی temporal_overlap گره Split SeedVR2 Latent. مقدار 0 به معنای الحاق ساده است. (پیش‌فرض: 0) | INT | بله | 0 تا 16384 |

**نکته:** مقدار `temporal_overlap` باید بزرگ‌تر یا مساوی ۰ باشد. همه تکه‌ها باید نهان‌های ویدیویی ۵ بعدی (B, C, T, H, W) باشند و در همه ابعاد به‌جز محور زمانی (T) منطبق باشند؛ فقط تکه پایانی می‌تواند از بقیه کوتاه‌تر باشد. اگر فقط یک تکه ارائه شود، بدون تغییر بازگردانده می‌شود.
