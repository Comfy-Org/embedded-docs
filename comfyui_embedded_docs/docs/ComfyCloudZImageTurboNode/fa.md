# ComfyCloudZImageTurboNode

این گره با استفاده از مدل Z-Image Turbo، تصویری از یک متن ورودی (prompt) تولید می‌کند که تنها در ۸ مرحله تکمیل می‌شود. تولید به‌صورت از راه دور بر روی GPUهای Comfy Cloud اجرا و بر اساس مدت زمان استفاده از GPU محاسبه می‌شود؛ به همین دلیل این گره یکی از سریع‌ترین و کم‌هزینه‌ترین گزینه‌ها برای تکرار روی ایده‌های تصویری است. پس از پایان تولید، گره تصویر نهایی را برای استفاده در گردش کار شما دانلود می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن ورودی توصیف‌کننده تصویر موردنظر برای تولید. ورودی چندخطی را می‌پذیرد و قبل از ارسال، فضای خالی ابتدا و انتهای آن حذف می‌شود. پس از حذف فاصله‌ها نباید خالی باشد. | STRING | بله | 1 - 4096 کاراکتر |
| `seed` | دانه تصادفی (seed) برای کنترل تکرارپذیری تولید. تغییر آن، حالت متفاوتی ایجاد می‌کند. شامل گزینه کنترل پس از تولید (control-after-generate) است. پیش‌فرض: 42. | INT | خیر | 0 - 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد تصویر تولیدشده. پیش‌فرض: «1:1». | COMBO | خیر | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | بودجه کل پیکسل‌ها. مقدار 1.0 تقریباً معادل 1024×1024 در نسبت مربع است. پیش‌فرض: 1.0. | FLOAT | خیر | 0.1 - 16.0<br>(گام 0.1) |

توجه: مقادیر ورودی قبل از ارسال تولید اعتبارسنجی می‌شوند. `prompt` باید بین 1 تا 4,096 کاراکتر پس از حذف فاصله‌های ابتدا و انتها داشته باشد، `aspect_ratio` باید یکی از گزینه‌های لیست‌شده باشد، و `megapixels` باید با افزایش‌های 0.1 وارد شود.
