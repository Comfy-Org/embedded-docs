# Comfy Cloud Z-Image Turbo متن به تصویر [BETA]

این گره با استفاده از مدل Z-Image Turbo و تنها در ۸ مرحله، تصویری را از یک پرامپت متنی تولید می‌کند. فرآیند تولید به‌صورت راه‌دور روی GPUهای Comfy Cloud اجرا می‌شود و هزینه بر اساس مدت اجرا محاسبه می‌گردد؛ همین موضوع آن را به یکی از سریع‌ترین و کم‌هزینه‌ترین گزینه‌های موجود در اینجا برای تکرار و آزمایش ایده‌های تصویری تبدیل می‌کند. پس از پایان تولید، گره تصویر نهایی را دانلود می‌کند تا در گردش‌کار شما استفاده شود. این گره بخشی از مجموعه گره‌های Comfy Cloud است که با برچسب BETA مشخص شده است: ممکن است گزینه‌هایی اضافه یا حذف شوند و ممکن است یک گردش‌کار بازنشسته شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی که تصویر مورد نظر برای تولید را توصیف می‌کند. ورودی چندخطی را می‌پذیرد و پیش از ارسال، فاصله‌های ابتدا و انتهای آن حذف می‌شود. پس از حذف فاصله‌ها نباید خالی باشد. پیش‌فرض: "" (خالی). | STRING | بله | 1 - 4096 characters |
| `seed` | بذر تصادفی برای کنترل بازتولیدپذیری تولید. تغییر آن، واریانت متفاوتی ایجاد می‌کند. شامل گزینه کنترل پس از تولید است. پیش‌فرض: 42. | INT | خیر | 0 - 18446744073709551615 |
| `aspect_ratio` | نسبت ابعاد تصویر تولیدشده. پیش‌فرض: "1:1". | COMBO | خیر | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | بودجه کل پیکسل‌ها. مقدار 1.0 در نسبت مربعی حدوداً معادل 1024x1024 است. پیش‌فرض: 1.0. | FLOAT | خیر | 0.1 - 16.0<br>(گام 0.1) |

توجه: مقادیر ورودی پیش از ارسال تولید اعتبارسنجی می‌شوند. `prompt` پس از حذف فاصله‌های سفید باید بین 1 و 4,096 نویسه باشد، `aspect_ratio` باید یکی از گزینه‌های فهرست‌شده باشد و `megapixels` باید با گام‌های 0.1 وارد شود.
