# ComfyCloudZImageTurboNode

Этот узел генерирует изображение по текстовому запросу с помощью модели Z-Image Turbo, которая выполняет генерацию всего за 8 шагов. Генерация выполняется удаленно на GPU в Comfy Cloud и тарифицируется по времени использования GPU, что делает этот узел одним из самых быстрых и дешевых вариантов для проработки идей изображений. После завершения генерации узел загружает готовое изображение для использования в вашем рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Текстовый запрос, описывающий изображение для генерации. Поддерживает многострочный ввод; перед отправкой пробелы по краям удаляются. После удаления пробелов запрос не должен быть пустым. | STRING | Да | 1 - 4096 символов |
| `seed` | Случайный сид, используемый для управления воспроизводимостью генерации. Его изменение дает другой вариант. Включает опцию управления после генерации. По умолчанию: 42. | INT | Нет | 0 - 18446744073709551615 |
| `aspect_ratio` | Соотношение сторон генерируемого изображения. По умолчанию: "1:1". | COMBO | Нет | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `megapixels` | Общий бюджет пикселей. 1.0 приблизительно соответствует 1024x1024 при квадратном соотношении. По умолчанию: 1.0. | FLOAT | Нет | 0.1 - 16.0<br>(шаг 0.1) |

Примечание: Значения входных параметров проверяются перед отправкой генерации. `prompt` должен содержать от 1 до 4096 символов после удаления пробелов по краям, `aspect_ratio` должен быть одним из перечисленных вариантов, а `megapixels` должен вводиться с шагом 0.1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение, возвращаемое в виде тензора изображения, готового для дальнейшей обработки или сохранения узлами. | IMAGE |
