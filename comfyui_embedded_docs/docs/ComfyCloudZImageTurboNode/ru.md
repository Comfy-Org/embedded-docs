# Comfy Cloud Z-Image Turbo: текст в изображение [БЕТА]

Этот узел генерирует изображение по текстовому промпту с помощью модели Z-Image Turbo, которая выполняет генерацию всего за 8 шагов. Генерация запускается удалённо на GPU Comfy Cloud и оплачивается по времени выполнения, что делает её одним из самых быстрых и дешёвых вариантов для перебора идей изображений. После завершения генерации узел загружает готовое изображение для использования в вашем рабочем процессе. Этот узел входит в набор узлов Comfy Cloud, который помечен как BETA: параметры могут добавляться или удаляться, а рабочий процесс может быть снят с поддержки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовый промпт, описывающий изображение для генерации. Принимает многострочный ввод; перед отправкой пробельные символы по краям обрезаются. После обрезки не должен быть пустым. По умолчанию: "" (пустая строка). | STRING | Да | 1 - 4096 символов |
| `сид` | Случайное зерно, используемое для управления воспроизводимостью генерации. Изменение значения даёт другую вариацию. Включает опцию управления после генерации. По умолчанию: 42. | INT | Нет | 0 - 18446744073709551615 |
| `соотношение сторон` | Соотношение сторон генерируемого изображения. По умолчанию: "1:1". | COMBO | Нет | "1:1"<br>"3:4"<br>"2:3"<br>"3:2"<br>"4:3"<br>"16:9"<br>"9:16"<br>"21:9" |
| `мегапиксели` | Общий бюджет пикселей. Значение 1.0 соответствует примерно 1024x1024 при квадратном соотношении сторон. По умолчанию: 1.0. | FLOAT | Нет | 0.1 - 16.0<br>(шаг 0.1) |

Примечание: Значения входов проверяются перед отправкой генерации. `prompt` должен содержать от 1 до 4 096 символов после удаления пробельных символов по краям, `aspect_ratio` должен быть одним из перечисленных вариантов, а `megapixels` должен быть указан с шагом 0.1.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное изображение, возвращаемое в виде тензора изображения, готовое для дальнейшей обработки изображения или узлов сохранения. | IMAGE |
