# Transform Splat

הצומת Transform Splat מחיל טרנספורמציות של הזזה, סיבוב וקנה מידה על splat גאוסי. הוא מזיז, מסובב ומשנה את הגודל של כל ה-splat כאובייקט יחיד, וכאשר מוחל קנה מידה לא-אחיד, הוא גם משנה את הצורה של כל splat גאוסי בודד כדי לקבל תוצאות מדויקות.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
|-----------|-------------|-----------|----------|-------|
| `splat` | ה-splat הגאוסי עליו לבצע טרנספורמציה | SPLAT | כן | - |
| `translate_x` | הזזה לאורך ציר X (ברירת מחדל: 0.0) | FLOAT | כן | -100.0 to 100.0 |
| `translate_y` | הזזה לאורך ציר Y (ברירת מחדל: 0.0) | FLOAT | כן | -100.0 to 100.0 |
| `translate_z` | הזזה לאורך ציר Z (ברירת מחדל: 0.0) | FLOAT | כן | -100.0 to 100.0 |
| `rotate_x` | סיבוב סביב ציר X במעלות (ברירת מחדל: 0.0) | FLOAT | כן | -360.0 to 360.0 |
| `rotate_y` | סיבוב סביב ציר Y במעלות (ברירת מחדל: 0.0) | FLOAT | כן | -360.0 to 360.0 |
| `rotate_z` | סיבוב סביב ציר Z במעלות (ברירת מחדל: 0.0) | FLOAT | כן | -360.0 to 360.0 |
| `scale_x` | מקדם קנה מידה לאורך ציר X (ברירת מחדל: 1.0) | FLOAT | כן | 0.01 to 100.0 |
| `scale_y` | מקדם קנה מידה לאורך ציר Y (ברירת מחדל: 1.0) | FLOAT | כן | 0.01 to 100.0 |
| `scale_z` | מקדם קנה מידה לאורך ציר Z (ברירת מחדל: 1.0) | FLOAT | כן | 0.01 to 100.0 |
