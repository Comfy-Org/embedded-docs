# LTXV Кодирование аудио VAE

Узел LTXV Audio VAE Encode принимает аудиовход и сжимает его в более компактное скрытое представление с помощью указанной модели Audio VAE. Этот процесс необходим для генерации или манипуляции аудио в рамках рабочего процесса со скрытым пространством, поскольку он преобразует исходные аудиоданные в формат, который другие узлы конвейера могут понимать и обрабатывать.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Аудио для кодирования. | AUDIO | Да | - |
| `audio_vae` | Модель Audio VAE, используемая для кодирования. | VAE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `Audio Latent` | Сжатое скрытое представление входного аудио. Выход включает скрытые сэмплы, частоту дискретизации модели VAE и идентификатор типа. | LATENT |
