# Meshy: تصویر به مدل

گره «Meshy: Image to Model» از Meshy API برای تولید یک مدل سه‌بعدی از یک تصویر ورودی استفاده می‌کند. تصویر شما را بارگذاری می‌کند، یک وظیفه پردازش ارسال می‌کند و فایل‌های مدل سه‌بعدی تولیدشده (GLB و FBX) را به همراه شناسه وظیفه برای مرجع بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | نسخه مدل هوش مصنوعی مورد استفاده برای تولید را مشخص می‌کند. | COMBO | بله | `"meshy-7.1"`<br>`"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `image` | تصویر ورودی برای تبدیل به مدل سه‌بعدی. | IMAGE | بله | - |
| `should_remesh` | وقتی روی `"false"` تنظیم شود، یک مش مثلثی پردازش‌نشده بازگردانده می‌شود. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `topology` | توپولوژی چندضلعی هدف برای مدل بازمش‌بندی‌شده. این ورودی فقط زمانی در دسترس است که `should_remesh` روی `"true"` تنظیم شده باشد. | COMBO | خیر* | `"triangle"`<br>`"quad"` |
| `target_polycount` | تعداد چندضلعی‌های هدف برای مدل بازمش‌بندی‌شده. این ورودی فقط زمانی در دسترس است که `should_remesh` روی `"true"` تنظیم شده باشد. پیش‌فرض: 300000. | INT | خیر* | 100 - 300000 |
| `symmetry_mode` | تقارن اعمال‌شده بر مدل سه‌بعدی تولیدشده را کنترل می‌کند. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | تعیین می‌کند که آیا بافت‌ها تولید شوند یا نه. تنظیم آن روی `"false"` مرحله بافت‌دهی را رد می‌کند و مشی بدون بافت بازمی‌گرداند. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `enable_pbr` | نقشه‌های PBR (فلزینگی، زبری، نرمال) را علاوه بر رنگ پایه تولید می‌کند. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: `False`. | BOOLEAN | خیر* | - |
| `texture_prompt` | یک پرامپت متنی برای هدایت فرآیند بافت‌دهی ارائه می‌دهد. حداکثر ۶۰۰ کاراکتر. نمی‌توان همزمان با `texture_image` استفاده شود. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: رشته خالی. | STRING | خیر* | - |
| `texture_image` | فقط یکی از `texture_image` یا `texture_prompt` می‌تواند همزمان استفاده شود. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. | IMAGE | خیر* | - |
| `texture_resolution` | رزولوشن بافت رنگ پایه. رزولوشن‌های بالاتر جزئیات بیشتری از سطح را ثبت می‌کنند. این ورودی فقط زمانی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. | COMBO | خیر* | `"2k"`<br>`"4k"`<br>`"8k"` |
| `pose_mode` | حالت ژست برای مدل تولیدشده را مشخص می‌کند. این یک پارامتر پیشرفته است. | COMBO | بله | `""` (خالی)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | سید کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به سید، غیرقطعی هستند. پیش‌فرض: 0. | INT | بله | 0 - 2147483647 |
| `ultra_mode` | یک مرحله بازپردازش اضافی برای هندسه با وفاداری بالاتر و جزئیات سطح دقیق‌تر اجرا می‌کند. پیش‌فرض: `False`. | BOOLEAN | بله | - |
| `ultra_resolution` | رزولوشن پاس ultra: `"2k"` آن را در 2048³ و `"4k"` در 4096³ برای ریزترین جزئیات سطح اجرا می‌کند. `"4k"` به مدل `"meshy-7.1"` یا `"latest"` نیاز دارد. فقط زمانی استفاده می‌شود که `ultra_mode` فعال باشد (پیش‌فرض: `"2k"`). | COMBO | خیر | `"2k"`<br>`"4k"` |

**نکته درباره محدودیت‌های پارامتر:**

* ورودی‌های `topology` و `target_polycount` فقط زمانی در دسترس هستند که `should_remesh` روی `"true"` تنظیم شده باشد.
* ورودی‌های `enable_pbr`، `texture_prompt`، `texture_image` و `texture_resolution` فقط زمانی در دسترس هستند که `should_texture` روی `"true"` تنظیم شده باشد.
* وقتی `should_texture` روی `"true"` تنظیم شده باشد، `texture_prompt` و `texture_image` نمی‌توانند همزمان استفاده شوند. اگر هر دو ارائه شوند، گره خطا صادر می‌کند.
* `texture_prompt` حداکثر ۶۰۰ کاراکتر طول دارد.
* هنگامی که `ultra_mode` فعال باشد، پارامتر `model` باید روی `"meshy-7.1"`، `"meshy-7"` یا `"latest"` تنظیم شود؛ انتخاب هر مدل دیگری خطا ایجاد می‌کند. با `"meshy-7"` پاس ultra همیشه در 2048³ اجرا می‌شود و رزولوشن `"4k"` به `"meshy-7.1"` یا `"latest"` نیاز دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `فایل مدل` | نام فایل مدل GLB تولیدشده. فقط برای سازگاری با نسخه‌های قبلی نگهداری می‌شود. | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای وظیفه Meshy API که می‌تواند برای مرجع یا عیب‌یابی استفاده شود. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب فایل GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدشده در قالب فایل FBX. | FILE3DFBX |
