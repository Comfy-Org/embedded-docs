# Meshy: تصویر به مدل

گره Meshy: Image to Model از API سرویس Meshy برای تولید مدل سه‌بعدی از یک تصویر ورودی استفاده می‌کند. این گره تصویر شما را بارگذاری می‌کند، یک وظیفه پردازشی ارسال می‌کند و فایل‌های مدل سه‌بعدی تولیدشده (GLB و FBX) را به‌همراه شناسه وظیفه برای مرجع بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | نسخه مدل هوش مصنوعی مورد استفاده برای تولید را مشخص می‌کند. | COMBO | بله | `"latest"` |
| `image` | تصویر ورودی که باید به مدل سه‌بعدی تبدیل شود. | IMAGE | بله | - |
| `should_remesh` | وقتی روی `"false"` تنظیم شود، مش مثلثی پردازش‌نشده را برمی‌گرداند. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `topology` | توپولوژی چندضلعی هدف برای مدل بازمشی‌شده. این ورودی فقط وقتی در دسترس است که `should_remesh` روی `"true"` تنظیم شده باشد. | COMBO | خیر* | `"triangle"`<br>`"quad"` |
| `target_polycount` | تعداد چندضلعی‌های هدف برای مدل بازمشی‌شده. این ورودی فقط وقتی در دسترس است که `should_remesh` روی `"true"` تنظیم شده باشد. پیش‌فرض: 300000. | INT | خیر* | 100 - 300000 |
| `symmetry_mode` | تقارن اعمال‌شده بر مدل سه‌بعدی تولیدشده را کنترل می‌کند. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | مشخص می‌کند که آیا بافت تولید شود. تنظیم آن روی `"false"` فاز بافت را رد می‌کند و مش را بدون بافت برمی‌گرداند. | DYNAMIC_COMBO | بله | `"true"`<br>`"false"` |
| `enable_pbr` | نقشه‌های PBR (فلزینگی، زبری، نرمال) را علاوه بر رنگ پایه تولید می‌کند. این ورودی فقط وقتی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: `False`. | BOOLEAN | خیر* | - |
| `texture_prompt` | یک متن راهنما برای هدایت فرآیند بافت‌دهی ارائه دهید. حداکثر ۶۰۰ کاراکتر. نمی‌توان همزمان با `texture_image` استفاده کرد. این ورودی فقط وقتی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. پیش‌فرض: رشته خالی. | STRING | خیر* | - |
| `texture_image` | در هر زمان فقط یکی از `texture_image` یا `texture_prompt` می‌تواند استفاده شود. این ورودی فقط وقتی در دسترس است که `should_texture` روی `"true"` تنظیم شده باشد. | IMAGE | خیر* | - |
| `pose_mode` | حالت ژست (pose) را برای مدل تولیدشده مشخص می‌کند. این یک پارامتر پیشرفته است. | COMBO | بله | `""` (خالی)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | seed تعیین می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed غیرقطعی هستند. پیش‌فرض: 0. | INT | بله | 0 - 2147483647 |

**یادداشت درباره محدودیت‌های پارامتر:**

* ورودی‌های `topology` و `target_polycount` فقط وقتی در دسترس هستند که `should_remesh` روی `"true"` تنظیم شده باشد.
* ورودی‌های `enable_pbr`، `texture_prompt` و `texture_image` فقط وقتی در دسترس هستند که `should_texture` روی `"true"` تنظیم شده باشد.
* وقتی `should_texture` روی `"true"` تنظیم شده باشد، `texture_prompt` و `texture_image` نمی‌توانند همزمان استفاده شوند. اگر هر دو ارائه شوند، گره خطا ایجاد می‌کند.
* `texture_prompt` حداکثر ۶۰۰ کاراکتر طول دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `فایل مدل` | نام فایل مدل GLB تولیدشده. فقط برای سازگاری با نسخه‌های قبلی نگهداری می‌شود. | STRING |
| `شناسه وظیفه meshy` | شناسه یکتای وظیفه API سرویس Meshy که می‌تواند برای مرجع یا عیب‌یابی استفاده شود. | MESHY_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب فایل GLB. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدشده در قالب فایل FBX. | FILE3DFBX |
