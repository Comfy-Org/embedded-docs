# Meshy: Изображение в модель

Узел Meshy: Image to Model использует API Meshy для создания 3D-модели из одного входного изображения. Он загружает ваше изображение, отправляет задачу на обработку и возвращает созданные файлы 3D-модели (GLB и FBX) вместе с идентификатором задачи для справки.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Указывает версию модели ИИ, используемую для генерации. | COMBO | Да | `"meshy-7"`<br>`"meshy-6"`<br>`"latest"` |
| `image` | Входное изображение для преобразования в 3D-модель. | IMAGE | Да | - |
| `should_remesh` | Если установлено значение `"false"`, возвращается необработанная треугольная сетка. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `topology` | Целевая полигональная топология для переработанной модели. Этот вход доступен только когда `should_remesh` установлен в `"true"`. | COMBO | Нет* | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для переработанной модели. Этот вход доступен только когда `should_remesh` установлен в `"true"`. По умолчанию: 300000. | INT | Нет* | 100 - 300000 |
| `symmetry_mode` | Управляет симметрией, применяемой к созданной 3D-модели. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | Определяет, создаются ли текстуры. Установка значения `"false"` пропускает этап текстурирования и возвращает сетку без текстур. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `enable_pbr` | Создавать PBR-карты (metallic, roughness, normal) в дополнение к базовому цвету. Этот вход доступен только когда `should_texture` установлен в `"true"`. По умолчанию: `False`. | BOOLEAN | Нет* | - |
| `texture_prompt` | Текстовый промпт для управления процессом текстурирования. Максимум 600 символов. Не может использоваться одновременно с `texture_image`. Этот вход доступен только когда `should_texture` установлен в `"true"`. По умолчанию: пустая строка. | STRING | Нет* | - |
| `texture_image` | Одновременно можно использовать только одно из значений `texture_image` или `texture_prompt`. Этот вход доступен только когда `should_texture` установлен в `"true"`. | IMAGE | Нет* | - |
| `texture_resolution` | Разрешение текстуры базового цвета. Более высокое разрешение позволяет передать больше деталей поверхности. Этот вход доступен только когда `should_texture` установлен в `"true"`. | COMBO | Нет* | `"2k"`<br>`"4k"`<br>`"8k"` |
| `pose_mode` | Задаёт режим позы для создаваемой модели. Это расширенный параметр. | COMBO | Да | `""` (пусто)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Сид управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от сида. По умолчанию: 0. | INT | Да | 0 - 2147483647 |
| `ультра-режим` | Выполняет дополнительный проход уточнения для геометрии более высокой точности с более тонкой детализацией поверхности. По умолчанию: `False`. | BOOLEAN | Да | - |

**Примечание об ограничениях параметров:**

* Входы `topology` и `target_polycount` доступны только когда `should_remesh` установлен в `"true"`.
* Входы `enable_pbr`, `texture_prompt`, `texture_image` и `texture_resolution` доступны только когда `should_texture` установлен в `"true"`.
* Когда `should_texture` установлен в `"true"`, `texture_prompt` и `texture_image` не могут использоваться одновременно. Если указаны оба, узел вызывает ошибку.
* `texture_prompt` имеет максимальную длину 600 символов.
* `ultra_mode` требует модель `"meshy-7"` или `"latest"`. Если `ultra_mode` включен с моделью `"meshy-6"`, узел вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model_file` | Имя файла созданной GLB-модели. Сохраняется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи API Meshy, который можно использовать для справки или устранения неполадок. | MESHY_TASK_ID |
| `GLB` | Созданная 3D-модель в формате файла GLB. | FILE3DGLB |
| `FBX` | Созданная 3D-модель в формате файла FBX. | FILE3DFBX |
