# Meshy: Изображение в модель

Узел Meshy: Image to Model использует API Meshy для создания 3D-модели из одного входного изображения. Он загружает ваше изображение, отправляет задачу на обработку и возвращает сгенерированные файлы 3D-модели (GLB и FBX) вместе с идентификатором задачи для справки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Указывает версию модели ИИ для генерации. | COMBO | Да | `"latest"` |
| `image` | Входное изображение для преобразования в 3D-модель. | IMAGE | Да | - |
| `should_remesh` | Если установлено значение `"false"`, возвращается необработанная треугольная сетка. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `topology` | Целевая полигональная топология для перестроенной модели. Этот вход доступен только когда `should_remesh` установлен в `"true"`. | COMBO | Нет* | `"triangle"`<br>`"quad"` |
| `target_polycount` | Целевое количество полигонов для перестроенной модели. Этот вход доступен только когда `should_remesh` установлен в `"true"`. По умолчанию: 300000. | INT | Нет* | 100 - 300000 |
| `symmetry_mode` | Управляет симметрией, применяемой к сгенерированной 3D-модели. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `should_texture` | Определяет, генерируются ли текстуры. Установка значения `"false"` пропускает этап текстурирования и возвращает сетку без текстур. | DYNAMIC_COMBO | Да | `"true"`<br>`"false"` |
| `enable_pbr` | Генерирует PBR-карты (metallic, roughness, normal) в дополнение к базовому цвету. Этот вход доступен только когда `should_texture` установлен в `"true"`. По умолчанию: `False`. | BOOLEAN | Нет* | - |
| `texture_prompt` | Предоставьте текстовый промпт для управления процессом текстурирования. Максимум 600 символов. Не может использоваться одновременно с `texture_image`. Этот вход доступен только когда `should_texture` установлен в `"true"`. По умолчанию: пустая строка. | STRING | Нет* | - |
| `texture_image` | Только один из `texture_image` или `texture_prompt` может использоваться одновременно. Этот вход доступен только когда `should_texture` установлен в `"true"`. | IMAGE | Нет* | - |
| `pose_mode` | Укажите режим позы для сгенерированной модели. Это дополнительный параметр. | COMBO | Да | `""` (пусто)<br>`"A-pose"`<br>`"T-pose"` |
| `seed` | Сид управляет тем, должен ли узел перезапускаться; результаты недетерминированы независимо от сида. По умолчанию: 0. | INT | Да | 0 - 2147483647 |

**Примечание об ограничениях параметров:**

* Входы `topology` и `target_polycount` доступны только когда `should_remesh` установлен в `"true"`.
* Входы `enable_pbr`, `texture_prompt` и `texture_image` доступны только когда `should_texture` установлен в `"true"`.
* Когда `should_texture` установлен в `"true"`, `texture_prompt` и `texture_image` не могут использоваться одновременно. Если оба предоставлены, узел вызывает ошибку.
* `texture_prompt` имеет максимальную длину 600 символов.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model_file` | Имя файла сгенерированной GLB-модели. Сохраняется только для обратной совместимости. | STRING |
| `meshy_task_id` | Уникальный идентификатор задачи Meshy API, который можно использовать для справки или устранения неполадок. | MESHY_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате файла GLB. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате файла FBX. | FILE3DFBX |
