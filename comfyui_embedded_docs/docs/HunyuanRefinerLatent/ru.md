# HunyuanRefinerLatent

Узел `HunyuanRefinerLatent` обрабатывает conditioning и latent входные данные для операций уточнения. Он применяет шумовую аугментацию как к положительному, так и к отрицательному conditioning, одновременно включая данные латентного изображения, и генерирует новый latent выход с определенными размерами для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `positive` | Положительное conditioning-входные данные для обработки | CONDITIONING | Да | - |
| `negative` | Отрицательное conditioning-входные данные для обработки | CONDITIONING | Да | - |
| `latent` | Входное латентное представление | LATENT | Да | - |
| `noise_augmentation` | Величина шумовой аугментации для применения (по умолчанию: 0.10, шаг: 0.01, расширенный параметр) | FLOAT | Да | 0.0 - 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Обработанный положительный conditioning с применённой шумовой аугментацией и конкатенацией латентного изображения | CONDITIONING |
| `negative` | Обработанный отрицательный conditioning с применённой шумовой аугментацией и конкатенацией латентного изображения | CONDITIONING |
| `latent` | Новый латентный вектор, заполненный нулями, с тем же размером пакета и теми же размерами последних трёх измерений, что и входной `latent`, но с 32 каналами | LATENT |
