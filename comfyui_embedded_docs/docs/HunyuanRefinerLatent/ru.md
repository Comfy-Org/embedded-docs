# HunyuanRefinerLatent

Узел HunyuanRefinerLatent подготавливает данные conditioning и латента для процесса уточнения видео Hunyuan. Он присоединяет входные данные латентного изображения к положительному и отрицательному conditioning, применяет к ним значение шумовой аугментации и создает новый латент, заполненный нулями, с 32 каналами для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `позитив` | Входное положительное кондиционирование для обработки | CONDITIONING | Да | - |
| `негатив` | Входное отрицательное кондиционирование для обработки | CONDITIONING | Да | - |
| `латент` | Входное латентное представление, используемое в качестве данных латентного изображения для conditioning и для определения размеров выходного латента | LATENT | Да | - |
| `шумовое_усиление` | Величина шумовой аугментации, которую нужно применить (по умолчанию: 0.10). Этот параметр отображается в расширенном разделе узла. | FLOAT | Да | 0.0 - 1.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `позитив` | Обработанное положительное кондиционирование с присоединенными данными латентного изображения и примененной шумовой аугментацией | CONDITIONING |
| `негатив` | Обработанное отрицательное кондиционирование с присоединенными данными латентного изображения и примененной шумовой аугментацией | CONDITIONING |
| `латент` | Новый латент, заполненный нулями, с тем же размером пакета (batch size) и теми же последними тремя размерностями, что и входной латент, и 32 каналами | LATENT |
