# Hunyuan Latent Refiner

הצומת HunyuanRefinerLatent מכין נתוני התניה ולטנטיים עבור תהליך העידון של Hunyuan video. הוא מצרף את נתוני התמונה הלטנטית לקלטי ההתניה החיובית והשלילית, מחיל עליהם ערך הגברת רעש, ויוצר לטנטי חדש מלא באפסים עם 32 ערוצים להמשך עיבוד.

## קלטים

| פרמטר | תיאור | סוג נתונים | נדרש | טווח |
| --- | --- | --- | --- | --- |
| `positive` | קלט ההתניה החיובית שיש לעבד | CONDITIONING | כן | - |
| `negative` | קלט ההתניה השלילית שיש לעבד | CONDITIONING | כן | - |
| `latent` | קלט הייצוג הלטנטי, המשמש כנתוני התמונה הלטנטית עבור ההתניה וכדי להגדיר את ממדי הפלט הלטנטי | LATENT | כן | - |
| `noise_augmentation` | כמות הגברת הרעש להחלה (ברירת מחדל: 0.10). פרמטר זה מוצג בחלק המתקדם של הצומת. | FLOAT | כן | 0.0 - 1.0 |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | ההתניה החיובית המעובדת, עם נתוני התמונה הלטנטית מצורפים ועם הגברת הרעש מיושמת | CONDITIONING |
| `negative` | ההתניה השלילית המעובדת, עם נתוני התמונה הלטנטית מצורפים ועם הגברת הרעש מיושמת | CONDITIONING |
| `latent` | לטנטי חדש מלא באפסים, עם אותו גודל אצווה ואותם שלושת הממדים האחרונים כמו קלט ה-latent, ועם 32 ערוצים | LATENT |
