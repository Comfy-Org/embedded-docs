# Cadena

El nodo String proporciona una forma sencilla de ingresar y transferir datos de texto en su flujo de trabajo. Toma una cadena de texto como entrada y produce la misma cadena sin cambios, lo que resulta útil para proporcionar entradas de texto a otros nodos que requieran parámetros de cadena.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `valor` | La cadena de texto que se pasará a través del nodo. | STRING | Sí | Cualquier texto |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `output` | La misma cadena de texto que se proporcionó como entrada. | STRING |
