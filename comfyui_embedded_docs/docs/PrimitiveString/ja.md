# 文字列

Stringノードは、ワークフロー内でテキストデータを入力し、そのまま通過させるためのシンプルな方法を提供します。テキスト文字列を入力として受け取り、同じ文字列を変更せずに出力するため、文字列パラメータを必要とする他のノードにテキスト入力を提供するのに役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `value` | ノードを通過させるテキスト文字列 | STRING | はい | 任意のテキスト |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 入力として提供された同じテキスト文字列 | STRING |
