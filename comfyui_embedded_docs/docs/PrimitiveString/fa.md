# رشته

گره String روشی ساده برای وارد کردن و عبور دادن داده‌های متنی در گردش کار شما فراهم می‌کند. این گره یک رشته متنی را به عنوان ورودی می‌گیرد و همان رشته را بدون تغییر خروجی می‌دهد و آن را برای فراهم کردن ورودی‌های متنی به سایر گره‌هایی که به پارامترهای رشته‌ای نیاز دارند، مفید می‌سازد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مقدار` | رشته متنی که باید از گره عبور داده شود | STRING | بله | هر متنی |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | همان رشته متنی که به عنوان ورودی ارائه شده است | STRING |
