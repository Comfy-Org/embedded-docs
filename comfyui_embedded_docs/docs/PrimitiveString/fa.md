# رشته

گره Text یک روش ساده برای وارد کردن و عبور دادن داده متنی در گردش‌کار شما فراهم می‌کند. این گره یک رشته متنی را به‌عنوان ورودی دریافت می‌کند و همان رشته را بدون تغییر خروجی می‌دهد؛ بنابراین برای تأمین ورودی‌های متنی برای سایر گره‌هایی که به پارامترهای رشته‌ای نیاز دارند مفید است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
| --- | --- | --- | --- | --- |
| `مقدار` | رشته متنی که باید از گره عبور داده شود | STRING | بله | هر متنی |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | همان رشته متنی که به‌عنوان ورودی ارائه شده بود | STRING |
