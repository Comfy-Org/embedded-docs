# PrimitiveString

צומת Text מספק דרך פשוטה להזין ולהעביר נתוני טקסט בזרימת העבודה שלך. הוא מקבל מחרוזת טקסט כקלט ומוציא את אותה מחרוזת ללא שינוי, ולכן הוא שימושי לאספקת קלטי טקסט לצמתים אחרים שדורשים פרמטרים מסוג מחרוזת.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `value` | מחרוזת הטקסט שתועבר דרך הצומת | STRING | כן | Any text |

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `output` | אותה מחרוזת טקסט שסופקה כקלט | STRING |
