# Chaîne

Le nœud String offre un moyen simple de saisir et de transmettre des données texte dans votre flux de travail. Il prend une chaîne de caractères en entrée et renvoie la même chaîne inchangée, ce qui est utile pour fournir des entrées texte à d'autres nœuds nécessitant des paramètres de type chaîne.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `value` | La chaîne de texte à transmettre via le nœud | STRING | Oui | Any text |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La même chaîne de texte fournie en entrée | STRING |
