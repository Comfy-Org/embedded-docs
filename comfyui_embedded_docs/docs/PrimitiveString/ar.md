# نص

توفّر عقدة Text طريقة بسيطة لإدخال البيانات النصية وتمريرها عبر سير العمل الخاص بك. تأخذ سلسلة نصية كمدخل وتُخرِج السلسلة نفسها دون تغيير، مما يجعلها مفيدة لتوفير مدخلات نصية لعُقد أخرى تتطلب معاملات نصية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `القيمة` | سلسلة النص التي سيتم تمريرها عبر العقدة | STRING | نعم | أي نص |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | سلسلة النص نفسها التي تم توفيرها كمدخل | STRING |
