# نص

يوفّر عقدة String طريقة بسيطة لإدخال البيانات النصية وتمريرها عبر سير العمل الخاص بك. تأخذ هذه العقدة سلسلة نصية كمدخل وتُخرج نفس السلسلة دون أي تغيير، مما يجعلها مفيدة لتوفير مدخلات نصية للعقد الأخرى التي تتطلب معاملات نصية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `value` | السلسلة النصية التي سيتم تمريرها عبر العقدة | STRING | نعم | أي نص |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `output` | نفس السلسلة النصية التي تم توفيرها كمدخل | STRING |
