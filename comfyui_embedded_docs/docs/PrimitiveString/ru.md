# Строка

Узел **String** предоставляет простой способ ввода и передачи текстовых данных в вашем рабочем процессе. Он принимает текстовую строку на вход и возвращает ту же строку без изменений, что удобно для подачи текстовых значений в другие узлы, требующие строковые параметры.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `value` | Текстовая строка для передачи через узел | STRING | Да | Любой текст |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Та же текстовая строка, которая была подана на вход | STRING |
