# Hunyuan3D: טופולוגיה חכמה

הצומת מבצע רטופולוגיה חכמה על מודל תלת-ממדי, ויוצר אוטומטית מש חדש ונקי יותר עם מספר מצולעים מיטבי. הוא מתחבר ל-API של Tencent Hunyuan 3D כדי לעבד את המודל, ותומך בפורמטים GLB ו-OBJ עד 200MB. הצומת מחזיר את המודל המעובד כקובץ OBJ.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | מודל תלת-ממדי קלט (GLB או OBJ). הקובץ חייב להיות בפורמט GLB או OBJ ולא יכול לעלות על 200MB. | FILE3D | כן | - |
| `polygon_type` | סוג הרכב המשטח. | STRING | כן | `"triangle"`<br>`"quadrilateral"` |
| `face_level` | רמת הפחתת המצולעים. | STRING | כן | `"medium"`<br>`"high"`<br>`"low"` |
| `seed` | `seed` קובע אם הצומת צריך לרוץ מחדש; התוצאות אינן דטרמיניסטיות ללא תלות ב-`seed`. (ברירת מחדל: 0) | INT | לא | 0 עד 2147483647 |

**הערה:** פרמטר ה-`seed` משמש להפעלת הרצה מחדש של הצומת, אך הפלט הסופי אינו מובטח להיות זהה עבור אותו ערך seed.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `OBJ` | המודל התלת-ממדי המעובד עם טופולוגיה מיטבית, מוחזר בפורמט OBJ. | FILE3D |
