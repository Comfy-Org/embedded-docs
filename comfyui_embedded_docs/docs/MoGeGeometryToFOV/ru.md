# Получить FoV из геометрии MoGe

Этот узел вычисляет угол обзора и фокусное расстояние на основе внутренних параметров камеры, хранящихся в объекте геометрии MoGe. Он может возвращать вертикальный, горизонтальный или диагональный FOV в градусах или радианах. Выход вертикального FOV можно использовать, например, для подачи на вход узла SAM3DBody_Predict.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `moge_geometry` | Объект геометрии MoGe. Он должен содержать матрицу внутренних параметров и хотя бы один из типов данных `image`, `points` или `depth`, которые используются для чтения высоты в пикселях при преобразовании фокусного расстояния. | MOGE_GEOMETRY | Да | — |
| `ось` | Ось, вдоль которой вычисляется FOV: "vertical" (fov_y), "horizontal" (fov_x) или "diagonal" (по умолчанию: "vertical"). | COMBO | Да | "vertical"<br>"horizontal"<br>"diagonal" |
| `единица измерения` | Единица вывода для FOV (по умолчанию: "degrees"). | COMBO | Да | "degrees"<br>"radians" |

Примечание: Узел выдаёт ошибку, если `moge_geometry` не содержит внутренних параметров (у панорамной геометрии их нет) или если он не содержит ни данных `image`, ни `points`, ни `depth`.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `fov` | Угол обзора вдоль выбранной оси в выбранных единицах измерения (градусах или радианах). | FLOAT |
| `focal_pixels` | Фокусное расстояние объектива в пикселях, вычисленное на основе вертикального внутреннего параметра и высоты в пикселях. | FLOAT |
