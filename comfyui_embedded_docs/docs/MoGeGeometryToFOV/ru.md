# MoGeGeometryToFOV

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|----------|----------|------------|-------------|----------|
| `moge_geometry` | Объект геометрии MoGe. Он должен содержать матрицу внутренних параметров и хотя бы один из следующих элементов: изображение, точки или данные глубины, которые используются для чтения высоты пикселя при преобразовании фокусного расстояния. | MOGE_GEOMETRY | Да | — |
| `axis` | Ось, вдоль которой вычисляется FOV: "vertical" (fov_y), "horizontal" (fov_x) или "diagonal" (по умолчанию: "vertical"). | COMBO | Да | "vertical"<br>"horizontal"<br>"diagonal" |
| `unit` | Единица измерения выходного значения FOV (по умолчанию: "degrees"). | COMBO | Да | "degrees"<br>"radians" |

Примечание: Узел вызывает ошибку, если `moge_geometry` не содержит внутренних параметров (панорамная геометрия их не имеет) или если он не содержит ни изображения, ни точек, ни данных глубины.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `fov` | Поле зрения вдоль выбранной оси в выбранной единице измерения (градусы или радианы). | FLOAT |
| `focal_pixels` | Фокусное расстояние объектива в пикселях, вычисленное на основе вертикального внутреннего параметра и высоты пикселя. | FLOAT |
