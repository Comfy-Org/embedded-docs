# MoGeGeometryToFOV

Этот узел вычисляет поле обзора и фокусное расстояние из внутренних параметров камеры, хранящихся в объекте геометрии MoGe. Он может возвращать вертикальное, горизонтальное или диагональное поле обзора (FOV) в градусах или радианах. Выходное вертикальное поле обзора можно использовать, например, для подачи в узел `SAM3DBody_Predict`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `moge_geometry` | Объект геометрии MoGe. Он должен содержать матрицу внутренних параметров камеры и по крайней мере один из следующих элементов: изображение, точки или данные глубины. Эти данные используются для чтения высоты пикселя при преобразовании фокусного расстояния. | MOGE_GEOMETRY | Да | — |
| `ось` | Ось, вдоль которой вычисляется поле обзора: `"vertical"` (fov_y), `"horizontal"` (fov_x) или `"diagonal"` (по умолчанию: `"vertical"`). | COMBO | Да | `"vertical"`<br>`"horizontal"`<br>`"diagonal"` |
| `единица измерения` | Единица измерения выходного значения FOV (по умолчанию: `"degrees"`). | COMBO | Да | `"degrees"`<br>`"radians"` |

Примечание: узел вызывает ошибку, если `moge_geometry` не содержит внутренних параметров камеры (панорамная геометрия их не имеет) или если он не содержит ни изображения, ни точек, ни данных глубины.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `fov` | Поле обзора вдоль выбранной оси в выбранной единице измерения (градусы или радианы). | FLOAT |
| `focal_pixels` | Фокусное расстояние объектива в пикселях, полученное из вертикальной внутренней характеристики камеры и высоты пикселя. | FLOAT |
