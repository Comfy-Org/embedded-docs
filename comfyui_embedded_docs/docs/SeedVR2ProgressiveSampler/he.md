# SeedVR2ProgressiveSampler

סמפלר לחלוקה זמנית סדרתית למקטעים עבור זרימות עבודה מקוריות של SeedVR2. צומת זה מעבד לטנטים של וידאו ארוך על ידי פיצולם למקטעים זמניים קטנים יותר, דוגם כל מקטע ברצף וממזג את התוצאות יחד. הוא משמש כתחליף ישיר ל-KSampler הסטנדרטי כאשר עובדים עם מודלים של SeedVR2 על רצפים שאחרת יגרמו לשגיאות חוסר בזיכרון.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `model` | המודל המשמש להסרת רעש מלטנט הקלט | MODEL | כן | |
| `seed` | ה-seed האקראי המשמש ליצירת הרעש (ברירת מחדל: 0) | INT | כן | 0 to 0xffffffffffffffff |
| `steps` | מספר הצעדים המשמשים בתהליך הסרת הרעש (ברירת מחדל: 20) | INT | כן | 1 to 10000 |
| `cfg` | סקאלת Classifier-Free Guidance מאזנת בין יצירתיות לדבקות בפרומפט. ערכים גבוהים יותר מפיקים תמונות המתאימות מקרוב יותר לפרומפט, אך ערכים גבוהים מדי יפגעו באיכות (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 100.0 |
| `sampler_name` | האלגוריתם המשמש בדגימה; זה יכול להשפיע על האיכות, המהירות והסגנון של הפלט הנוצר | COMBO | כן | אפשרויות מרובות זמינות |
| `scheduler` | המתזמן שולט באופן שבו הרעש מוסר בהדרגה ליצירת התמונה | COMBO | כן | אפשרויות מרובות זמינות |
| `positive` | הקונדישנינג המתאר את התכונות שברצונך לכלול בתמונה | CONDITIONING | כן | |
| `negative` | הקונדישנינג המתאר את התכונות שברצונך להוציא מהתמונה | CONDITIONING | כן | |
| `latent` | תמונת הלטנט להסרת רעש | LATENT | כן | |
| `denoise` | כמות הסרת הרעש המופעלת; ערכים נמוכים יותר ישמרו על המבנה של התמונה ההתחלתית ויאפשרו דגימת image-to-image (ברירת מחדל: 1.0) | FLOAT | כן | 0.0 to 1.0 |
| `frames_per_chunk` | פריימים בפיקסלים לכל מקטע זמני. חייב להיות ערך 4n+1 (1, 5, 9, 13, 17, 21, ...) כדי להתאים למגבלות SeedVR2 (ברירת מחדל: 21) | INT | כן | 1 to 16384 (step of 4) |
| `temporal_overlap` | פריימי לטנט הממוזגים בין מקטעים סמוכים כדי להסתיר את התפר; 0 פירושו ללא מיזוג (ברירת מחדל: 0) | INT | כן | 0 to 16384 |
| `chunking_mode` | manual = השתמש בדיוק ב-frames_per_chunk; auto = כווץ את המקטע עד שהוא נכנס ב-VRAM (ברירת מחדל: "manual") | COMBO | כן | "manual"<br>"auto" |

**הערה על `frames_per_chunk`:** פרמטר זה חייב להיות מספר פריימים בפיקסלים בצורת 4n+1 (1, 5, 9, 13, 17, 21, ...). הצומת יעלה שגיאה אם יסופק ערך לא חוקי.

**הערה על `temporal_overlap`:** ערך החפיפה מוגבל אוטומטית להיות לכל היותר אחד פחות מגודל מקטע הלטנט כדי להבטיח עיבוד מקטעים תקין.

**הערה על `chunking_mode`:** כאשר הוא מוגדר ל-"auto", הצומת ינסה אוטומטית גדלים קטנים יותר של מקטעים אם המקטע הנוכחי גורם לשגיאת חוסר בזיכרון. אם כל הניסיונות נכשלים, הצומת יעלה שגיאה.
