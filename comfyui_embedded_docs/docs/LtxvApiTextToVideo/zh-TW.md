# LTXV 文字轉影片

LTXV Text To Video 節點可從文字描述生成高品質影片。它連接到外部 API，以建立具有可自訂時長、解析度和幀率的影片。您也可以選擇讓 AI 生成的音訊加入影片中。

## 輸入

| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `模型` | 用於影片生成的 AI 模型。「LTX-2 (Pro)」提供較高品質，而「LTX-2 (Fast)」則針對速度最佳化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `提示詞` | AI 用來生成影片的文字描述。此欄位支援多行文字，且必須包含 1 到 10,000 個字元。 | STRING | 是 | - |
| `持續時間` | 生成影片的長度（秒）（預設值：8）。 | COMBO | 是 | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `解析度` | 輸出影片的像素尺寸（寬 x 高）。 | COMBO | 是 | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `幀率` | 影片的幀率（每秒幀數）（預設值：25）。 | COMBO | 是 | `25`<br>`50` |
| `生成音訊` | 啟用時，生成的影片將包含符合場景的 AI 生成音訊（預設值：False）。這是進階選用設定。 | BOOLEAN | 否 | - |

**重要限制：**

* `prompt` 的長度必須介於 1 到 10,000 個字元之間。
* 如果您選擇的 `duration` 大於 10 秒，則必須使用 `"LTX-2 (Fast)"` 模型、`"1920x1080"` 解析度以及 `25` 的 `fps`。此組合為較長影片所必需。

**注意：** 此節點已棄用。
