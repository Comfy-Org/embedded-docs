# LtxvApiTextToVideo

Узел LTXV Text To Video создает видеоролики профессионального качества из текстового описания. Он подключается к внешнему API для создания видео с настраиваемой длительностью, разрешением и частотой кадров. Вы также можете включить добавление аудио, сгенерированного ИИ, к видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель ИИ, используемая для генерации видео. `"LTX-2 (Pro)"` обеспечивает более высокое качество, а `"LTX-2 (Fast)"` оптимизирована для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | Текстовое описание, которое ИИ будет использовать для генерации видео. Это поле поддерживает многострочный текст и должно содержать от 1 до 10 000 символов. По умолчанию: `""` (пусто). | STRING | Да | - |
| `duration` | Длительность сгенерированного видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | Размеры выходного видео в пикселях (ширина x высота). | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | Частота кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `generate_audio` | Если true, сгенерированное видео будет включать аудио, сгенерированное ИИ и соответствующее сцене (по умолчанию: False). Это расширенная необязательная настройка. | BOOLEAN | Нет | - |

**Важные ограничения:**

* `prompt` должен содержать от 1 до 10 000 символов.
* Если вы выбираете `duration` больше 10 секунд, необходимо также использовать модель `"LTX-2 (Fast)"`, разрешение `"1920x1080"` и `fps` равный `25`. Такая комбинация требуется для более длинных видео.
* Стоимость зависит от выбранных `model`, `duration` и `resolution`.

**Примечание:** Этот узел устарел.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
