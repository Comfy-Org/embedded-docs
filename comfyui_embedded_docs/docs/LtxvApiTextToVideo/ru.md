# LTXV Текст в Видео

Узел LTXV Text To Video создает видео профессионального качества на основе текстового описания. Он подключается к внешнему API для создания видео с настраиваемой длительностью, разрешением и частотой кадров. Вы также можете добавить в видео аудио, сгенерированное ИИ.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель ИИ для генерации видео. "LTX-2 (Pro)" обеспечивает более высокое качество, а "LTX-2 (Fast)" оптимизирована для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `промпт` | Текстовое описание, которое ИИ использует для генерации видео. Это поле поддерживает многострочный текст и должно содержать от 1 до 10 000 символов. | STRING | Да | - |
| `длительность` | Длительность генерируемого видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `разрешение` | Размер в пикселях (ширина x высота) выходного видео. | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `кадров_в_секунду` | Количество кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `генерировать_аудио` | Если значение равно true, сгенерированное видео будет содержать созданное ИИ аудио, соответствующее сцене (по умолчанию: False). Это расширенная необязательная настройка. | BOOLEAN | Нет | - |

**Важные ограничения:**

* `prompt` должен содержать от 1 до 10 000 символов.
* Если вы выберете `duration` больше 10 секунд, необходимо также использовать модель `"LTX-2 (Fast)"`, разрешение `"1920x1080"` и `fps`, равный 25. Эта комбинация обязательна для более длинных видео.

**Примечание:** Этот узел устарел.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
