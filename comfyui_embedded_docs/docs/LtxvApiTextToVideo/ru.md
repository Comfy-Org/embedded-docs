# LTXV Текст в Видео

Узел LTXV Text To Video создает профессиональные видео по текстовому описанию. Он подключается к внешнему API для создания видео с настраиваемыми продолжительностью, разрешением и частотой кадров. Вы также можете выбрать добавление к видео сгенерированного искусственным интеллектом аудио.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель ИИ для генерации видео. «LTX-2 (Pro)» обеспечивает более высокое качество, а «LTX-2 (Fast)» оптимизирована для скорости. | COMBO | Да | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | Текстовое описание, которое ИИ использует для генерации видео. Это поле поддерживает многострочный текст. | STRING | Да | - |
| `duration` | Длительность создаваемого видео в секундах (по умолчанию: 8). | COMBO | Да | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | Размеры в пикселях (ширина x высота) выходного видео. | COMBO | Да | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | Частота кадров в секунду для видео (по умолчанию: 25). | COMBO | Да | `25`<br>`50` |
| `generate_audio` | Если значение true, созданное видео будет включать сгенерированное ИИ аудио, соответствующее сцене (по умолчанию: False). | BOOLEAN | Нет | `True`<br>`False` |

**Важные ограничения:**

* Параметр `prompt` должен содержать от 1 до 10 000 символов.
* Если вы выбираете `duration` более 10 секунд, вы также должны использовать модель `"LTX-2 (Fast)"`, разрешение `"1920x1080"` и `fps` равный `25`. Эта комбинация обязательна для более длинных видео.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
