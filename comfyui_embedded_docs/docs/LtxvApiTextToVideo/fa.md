# LtxvApiTextToVideo

گره LTXV Text To Video ویدئوهایی با کیفیت حرفه‌ای را از یک توضیح متنی تولید می‌کند. این گره به یک API خارجی متصل می‌شود تا ویدئوهایی با مدت‌زمان، رزولوشن و نرخ فریم قابل‌تنظیم بسازد. همچنین می‌توانید انتخاب کنید که صدای تولیدشده توسط هوش مصنوعی به ویدئو اضافه شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل هوش مصنوعی برای تولید ویدئو. «LTX-2 (Pro)» کیفیت بالاتری ارائه می‌دهد، در حالی که «LTX-2 (Fast)» برای سرعت بهینه شده است. | COMBO | بله | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | توضیح متنی که هوش مصنوعی برای تولید ویدئو از آن استفاده می‌کند. این فیلد از چند خط متن پشتیبانی می‌کند و باید بین ۱ تا ۱۰٬۰۰۰ نویسه باشد. پیش‌فرض: "" (خالی). | STRING | بله | - |
| `duration` | طول ویدئوی تولیدشده بر حسب ثانیه (پیش‌فرض: ۸). | COMBO | بله | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | ابعاد پیکسلی (عرض × ارتفاع) ویدئوی خروجی. | COMBO | بله | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | تعداد فریم در ثانیه برای ویدئو (پیش‌فرض: ۲۵). | COMBO | بله | `25`<br>`50` |
| `generate_audio` | وقتی true باشد، ویدئوی تولیدشده شامل صدای تولیدشده توسط هوش مصنوعی متناسب با صحنه خواهد بود (پیش‌فرض: False). این یک تنظیم پیشرفته و اختیاری است. | BOOLEAN | خیر | - |

**محدودیت‌های مهم:**

* طول `prompt` باید بین ۱ و ۱۰٬۰۰۰ نویسه باشد.
* اگر `duration` بزرگ‌تر از ۱۰ ثانیه را انتخاب کنید، باید از مدل `"LTX-2 (Fast)"`، رزولوشن `"1920x1080"` و `fps` برابر `25` نیز استفاده کنید. این ترکیب برای ویدئوهای طولانی‌تر الزامی است.
* قیمت‌گذاری به `model`، `duration` و `resolution` انتخاب‌شده بستگی دارد.

**توجه:** این گره منسوخ شده است.
