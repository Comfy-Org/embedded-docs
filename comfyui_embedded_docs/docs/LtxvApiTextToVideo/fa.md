# LTXV تبدیل متن به ویدیو

گره LTXV Text To Video ویدیویی با کیفیت حرفه‌ای از روی توضیح متنی تولید می‌کند. این گره به یک API خارجی متصل می‌شود و ویدیوهایی با مدت‌زمان، وضوح و نرخ فریم قابل تنظیم می‌سازد. همچنین می‌توانید انتخاب کنید که صدای تولیدشده توسط هوش مصنوعی نیز به ویدیو اضافه شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدل هوش مصنوعی مورد استفاده برای تولید ویدیو. «LTX-2 (Pro)» کیفیت بالاتری ارائه می‌دهد، در حالی که «LTX-2 (Fast)» برای سرعت بهینه شده است. | COMBO | بله | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `پرامپت` | توضیح متنی که هوش مصنوعی برای تولید ویدیو از آن استفاده می‌کند. این فیلد از چند خط متن پشتیبانی می‌کند و باید بین ۱ تا ۱۰,۰۰۰ نویسه باشد. | STRING | بله | - |
| `مدت زمان` | مدت‌زمان ویدیوی تولیدشده بر حسب ثانیه (پیش‌فرض: ۸). | COMBO | بله | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `وضوح` | ابعاد پیکسلی (عرض × ارتفاع) ویدیوی خروجی. | COMBO | بله | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `فریم بر ثانیه` | نرخ فریم ویدیو بر حسب فریم بر ثانیه (پیش‌فرض: ۲۵). | COMBO | بله | `25`<br>`50` |
| `تولید صدا` | وقتی مقدار true باشد، ویدیوی تولیدشده شامل صدای تولیدشده توسط هوش مصنوعی متناسب با صحنه خواهد بود (پیش‌فرض: False). این یک تنظیم اختیاری پیشرفته است. | BOOLEAN | خیر | - |

**محدودیت‌های مهم:**

* متن `prompt` باید بین ۱ تا ۱۰,۰۰۰ نویسه باشد.
* اگر `duration` بزرگ‌تر از ۱۰ ثانیه انتخاب کنید، باید از مدل `"LTX-2 (Fast)"`، وضوح `"1920x1080"` و `fps` برابر با `25` استفاده کنید. این ترکیب برای ویدیوهای طولانی‌تر الزامی است.

**توجه:** این گره منسوخ شده است.
