# LTXV テキストから動画へ

LTXV Text To Video ノードは、テキスト記述からプロフェッショナル品質の動画を生成します。外部APIに接続して、期間、解像度、フレームレートをカスタマイズした動画を作成します。AIが生成したオーディオを動画に追加するオプションも選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 動画生成に使用するAIモデルです。"LTX-2 (Pro)" は高品質を提供し、"LTX-2 (Fast)" は速度に最適化されています。 | COMBO | はい | `"LTX-2 (Pro)"`<br>`"LTX-2 (Fast)"` |
| `prompt` | AIが動画の生成に使用するテキスト記述です。このフィールドは複数行のテキストに対応しています。 | STRING | はい | - |
| `duration` | 生成される動画の長さ（秒単位）です（デフォルト: 8）。 | COMBO | はい | `6`<br>`8`<br>`10`<br>`12`<br>`14`<br>`16`<br>`18`<br>`20` |
| `resolution` | 出力動画のピクセル寸法（幅×高さ）です。 | COMBO | はい | `"1920x1080"`<br>`"2560x1440"`<br>`"3840x2160"` |
| `fps` | 動画のフレームレート（1秒あたりのフレーム数）です（デフォルト: 25）。 | COMBO | はい | `25`<br>`50` |
| `generate_audio` | trueの場合、生成された動画にはシーンに合ったAI生成オーディオが含まれます（デフォルト: False）。 | BOOLEAN | いいえ | `True`<br>`False` |

**重要な制約事項:**

* `prompt` は1文字以上10,000文字以下である必要があります。
* `duration` に10秒より大きい値を選択した場合は、`"LTX-2 (Fast)"` モデル、`"1920x1080"` の解像度、および `25` の `fps` も使用する必要があります。この組み合わせは、より長い動画に必要です。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成された動画ファイルです。 | VIDEO |
