# HeyGen Voice 1.0 Instant Clone

Клонируйте голос по записи одного диктора с помощью движка Voice 1.0 от HeyGen. Узел загружает запись, создаёт мгновенный клон голоса, ждёт, пока HeyGen завершит обработку, и возвращает `voice_id`. Подключите полученный `voice_id` к узлу HeyGen Voice 1.0 Text to Speech или передайте как `custom_voice_id` в HeyGen Avatar Video и HeyGen Talking Photo. Создание клона бесплатно; оплата взимается за речь, которую вы генерируете с помощью этого голоса.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `audio` | Запись одного диктора. Используйте не менее 10 секунд чёткой речи; используются только первые 3 минуты. | AUDIO | Да | N/A |
| `language` | Язык, на котором говорят в записи (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>Несколько языковых пресетов |
| `similarity` | Насколько точно голос повторяет запись (по умолчанию: "max"). | COMBO | Да | `"medium"`<br>`"high"`<br>`"extra_high"`<br>`"max"` |
| `remove_background_noise` | Очищать фоновый шум в записи перед клонированием (по умолчанию: True). | BOOLEAN | Да | True<br>False |
| `seed` | Измените `seed`, чтобы повторно клонировать запись; каждый клон — немного другой голос (по умолчанию: 42). | INT | Да | 0 до 2147483647 |

**Примечание:** Голос создаётся с именем "ComfyUI Voice" в вашей учётной записи HeyGen, а узел выводит `voice_id` в интерфейсе, чтобы вы могли скопировать его для повторного использования. Оставляйте `language` в значении "auto", кроме случаев, когда диктор говорит на языке, который легко спутать с близкородственным. Вход `seed` включает фиксированный элемент управления Control After Generate в интерфейсе, поэтому изменяйте его вручную, когда захотите создать ещё один клон.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `voice_id` | Идентификатор клонированного голоса для повторного использования в узле HeyGen Voice 1.0 Text to Speech или в качестве `custom_voice_id`. | STRING |
