# Tripo P2: چندنما به مدل

با استفاده از مدل P2 شرکت Tripo، یک مدل سه‌بعدی کم‌پالیگان با توپولوژی تمیز از چند نمای سوژه یکسان تولید می‌کند. نمای روبه‌رو الزامی است و می‌توان یک تا سه نما از نماهای چپ، پشت و راست را برای بهبود نتیجه افزود. مدل به‌صورت یک مش مثلثی (GLB) بازگردانده می‌شود یا، زمانی که `model.quad` فعال باشد، به‌صورت یک مش غالباً چهارضلعی (FBX).

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model` | مدل سری P شرکت Tripo برای استفاده. با انتخاب یک مدل، ورودی‌های مخصوص خود آن در پایین نمایش داده می‌شود. | DYNAMIC_COMBO | بله | `"P2"` |

| `model.image_left` | نمای چپ (90°)، سمت چپ خودِ سوژه. | IMAGE | خیر | - |
| `model.image_back` | نمای پشت (180°). | IMAGE | خیر | - |
| `model.image_right` | نمای راست (270°)، سمت راست خودِ سوژه. | IMAGE | خیر | - |
| `quad` | بازگرداندن یک مش غالباً چهارضلعی در خروجی FBX به‌جای مش مثلثی در خروجی GLB (پیش‌فرض: False). | BOOLEAN | بله | True/False |

**یادداشت‌ها:**

- `model.image` الزامی است و حداقل یکی از `model.image_left`، `model.image_back` یا `model.image_right` نیز باید متصل شود؛ اگر نمای روبه‌رو تنها تصویر باشد، گره خطا می‌دهد.
- فقط اولین تصویر از هر batch استفاده می‌شود.
- `model.face_limit` یک هدف است نه یک سقف سخت؛ بنابراین نتیجه می‌تواند وجه‌های بیشتری از مقدار درخواستی داشته باشد. `-1` انتخاب را به Tripo واگذار می‌کند.
- `model.quad` تعیین می‌کند کدام خروجی مش را حمل کند. با فعال بودن آن، مدل روی خروجی FBX می‌آید و خروجی GLB خالی می‌ماند؛ با غیرفعال بودن آن، مدل روی GLB می‌آید و FBX خالی می‌ماند. اگر خروجی خالی همان خروجی‌ای باشد که متصل کرده‌اید، گره خطا می‌دهد.
- `model.texture`، `model.pbr`، `model.texture_seed`، `model.auto_size`، `model.texture_alignment` و `model.orientation` فقط برای مدل‌های بافت‌دار اعمال می‌شوند: با `"none"` گره هیچ تنظیم بافتی ارسال نمی‌کند و هندسه بدون بافت بازمی‌گرداند.
- `model.compress_geometry` روی مش‌های چهارضلعی اثری ندارد.
