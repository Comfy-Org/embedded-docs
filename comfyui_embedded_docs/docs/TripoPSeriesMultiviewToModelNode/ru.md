# Tripo P2: Из нескольких ракурсов в модель

Создаёт низкополигональную 3D-модель с чистой топологией по нескольким видам одного и того же объекта с использованием модели P2 от Tripo. Вид спереди обязателен, а для улучшения результата можно добавить от одного до трёх видов: слева, сзади и справа. Модель возвращается в виде треугольной сетки (GLB) или, если включён `model.quad`, в виде сетки с преобладанием четырёхугольников (FBX).

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель Tripo серии P для использования. При выборе модели ниже появляются её собственные входы. | DYNAMIC_COMBO | Да | `"P2"` |

### Входы P2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.image` | Вид спереди (0°) объекта. | IMAGE | Да | - |
| `model.image_left` | Вид слева (90°), собственная левая сторона объекта. | IMAGE | Нет | - |
| `model.image_back` | Вид сзади (180°). | IMAGE | Нет | - |
| `model.image_right` | Вид справа (270°), собственная правая сторона объекта. | IMAGE | Нет | - |
| `quad` | Возвращать сетку с преобладанием четырёхугольников на выходе FBX вместо треугольной сетки на выходе GLB (по умолчанию: False). | BOOLEAN | Да | True/False |
| `face_limit` | Целевое количество граней. `-1` позволяет Tripo выбрать самостоятельно. При включённом `model.quad` ограничение составляет от 48 до 25 000, иначе от 48 до 50 000 (по умолчанию: -1). | INT | Да | -1 или от 48 до 50000 |
| `текстура` | Разрешение текстуры базового цвета: standard — 2K, detailed — 4K, extreme — 8K. `"none"` возвращает сетку без текстуры (по умолчанию: `"standard"`). | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"`<br>`"none"` |
| `pbr` | Добавлять карты металличности, шероховатости и нормалей к базовому цвету. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: True). | BOOLEAN | Да | True/False |
| `model_seed` | Начальное значение (seed) для геометрии (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |
| `texture_alignment` | Сопоставлять цвета входных изображений или подгонять текстуры под сгенерированную геометрию. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: `"original_image"`). Расширенная настройка. | COMBO | Да | `"original_image"`<br>`"geometry"` |
| `orientation` | `"align_image"` поворачивает модель к точке обзора входных изображений. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: `"default"`). Расширенная настройка. | COMBO | Да | `"default"`<br>`"align_image"` |
| `texture_seed` | Начальное значение (seed) для текстур (по умолчанию: 42). Расширенная настройка. | INT | Да | от 0 до 2147483647 |
| `auto_size` | Масштабировать модель до её реального размера в метрах через преобразование сцены. Игнорируется, когда `model.texture` имеет значение `"none"` (по умолчанию: False). Расширенная настройка. | BOOLEAN | Да | True/False |
| `export_uv` | Выполнять UV-развёртку сетки, если она без текстуры. Сетки с текстурами всегда разворачиваются (по умолчанию: True). Расширенная настройка. | BOOLEAN | Да | True/False |
| `compress_geometry` | Применять сжатие геометрии meshopt: файлы намного меньше, но 3D-предпросмотр ComfyUI не может их отображать. Игнорируется для четырёхугольных сеток (по умолчанию: False). Расширенная настройка. | BOOLEAN | Да | True/False |

**Примечания:**

- `model.image` обязателен, и как минимум один из параметров `model.image_left`, `model.image_back` или `model.image_right` также должен быть подключён; узел выдаёт ошибку, если вид спереди является единственным изображением.
- Используется только первое изображение из каждого пакета.
- `model.face_limit` — это целевое значение, а не жёсткое ограничение, поэтому в результате может оказаться больше граней, чем запрошено. `-1` оставляет выбор Tripo.
- `model.quad` определяет, на какой выход подаётся сетка. Если он включён, модель появляется на выходе FBX, а выход GLB остаётся пустым; если он отключён, модель появляется на выходе GLB, а FBX остаётся пустым. Узел выдаёт ошибку, если пустым оказывается тот выход, который вы подключили.
- `model.texture`, `model.pbr`, `model.texture_seed`, `model.auto_size`, `model.texture_alignment` и `model.orientation` применяются только к текстурированным моделям: при `"none"` узел не отправляет настройки текстуры и возвращает «голую» геометрию.
- `model.compress_geometry` не оказывает влияния на четырёхугольные сетки.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `model task_id` | Уникальный ID задачи для запроса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пустой, когда включён `model.quad`. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только когда включён `model.quad`. | FILE3DFBX |
