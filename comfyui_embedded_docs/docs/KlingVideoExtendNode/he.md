# KlingVideoExtendNode

צומת Kling Video Extend מאפשר לך להאריך סרטונים שנוצרו על ידי צמתי Kling אחרים. הוא מקבל סרטון קיים המזוהה לפי מזהה הסרטון שלו ומייצר תוכן נוסף בהתבסס על הנחיות הטקסט שלך. הצומת פועל על ידי שליחת בקשת ההארכה שלך אל Kling API ומחזיר את הסרטון המוארך יחד עם המזהה החדש והמשך שלו.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
|-----------|-------------|-----------|----------|-------|
| `prompt` | הנחיית טקסט חיובית להכוונת הארכת הסרטון | STRING | לא | - |
| `negative_prompt` | הנחיית טקסט שלילית עבור אלמנטים שיש להימנע מהם בסרטון המוארך | STRING | לא | - |
| `cfg_scale` | שולט בעוצמת הכוונת ההנחיה (ברירת מחדל: 0.5) | FLOAT | לא | 0.0 - 1.0 |
| `video_id` | המזהה של הסרטון שיש להאריך. תומך בסרטונים שנוצרו באמצעות טקסט לווידאו, תמונה לווידאו ופעולות הארכת סרטון קודמות. אינו יכול לחרוג ממשך כולל של 3 דקות לאחר ההארכה. | STRING | כן | - |

**הערה:** ה-`video_id` חייב להפנות לסרטון שנוצר על ידי צמתי Kling אחרים, והמשך הכולל לאחר ההארכה אינו יכול לעלות על 3 דקות. ההנחיה החיובית לא יכולה להיות ריקה ושתי ההנחיות חייבות להיות באורך של פחות מ-2500 תווים.

## פלטים

| שם פלט | תיאור | סוג נתונים |
|-------------|-------------|-----------|
| `output` | הסרטון המוארך שנוצר על ידי Kling API | VIDEO |
| `video_id` | המזהה הייחודי של הסרטון המוארך | STRING |
| `duration` | משך הסרטון המוארך | STRING |
