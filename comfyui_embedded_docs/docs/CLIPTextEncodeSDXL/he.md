# ClipTextEncodeSdxl

צומת זה מיועד לקודד קלט טקסט באמצעות מודל CLIP המותאם במיוחד לארכיטקטורת SDXL. הוא משתמש במערכת מקודדים כפולה (CLIP-L ו-CLIP-G) לעיבוד תיאורי טקסט, וכתוצאה מכך ליצירת תמונות מדויקת יותר.

## קלטים

| פרמטר | תיאור | סוג נתון |
| --- | --- | --- |
| `clip` | מופע מודל CLIP המשמש לקידוד טקסט. | CLIP |
| `width` | מציין את רוחב התמונה בפיקסלים, ברירת מחדל 1024. | INT |
| `height` | מציין את גובה התמונה בפיקסלים, ברירת מחדל 1024. | INT |
| `crop_w` | רוחב אזור החיתוך בפיקסלים, ברירת מחדל 0. | INT |
| `crop_h` | גובה אזור החיתוך בפיקסלים, ברירת מחדל 0. | INT |
| `target_width` | רוחב היעד של תמונת הפלט, ברירת מחדל 1024. | INT |
| `target_height` | גובה היעד של תמונת הפלט, ברירת מחדל 1024. | INT |
| `text_g` | תיאור טקסט גלובלי לתיאור הסצנה הכולל. | STRING |
| `text_l` | תיאור טקסט מקומי לתיאור פרטים. | STRING |

## פלטים

| פרמטר | תיאור | סוג נתון |
| --- | --- | --- |
| `CONDITIONING` | מכיל טקסט מקודד ומידע מותנה הדרוש ליצירת תמונה. | CONDITIONING |
