# Bria Video Green Screen

این گره با استفاده از API بریا، پس‌زمینه ویدیو را با یک صفحهٔ کروماکی ساده جایگزین می‌کند. ویدیوی ورودی را پردازش کرده و ویدیوی جدیدی برمی‌گرداند که در آن پس‌زمینهٔ اصلی حذف و با یک رنگ یکنواخت سبز یا آبی جایگزین شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|---------|---------|----------|--------|--------|
| `video` | ویدیوی ورودی برای پردازش | VIDEO | بله | فایل ویدیو |
| `green_shade` | سایهٔ کروماکی یکنواخت که پشت پیش‌زمینه قرار می‌گیرد: broadcast_green (#00B140)، chroma_green (#00FF00) یا blue_screen (#0000FF) | COMBO | بله | `"broadcast_green"`<br>`"chroma_green"`<br>`"blue_screen"` |
| `seed` | Seed کنترل می‌کند که آیا گره باید دوباره اجرا شود؛ نتایج بدون توجه به seed قطعی نیستند (پیش‌فرض: 0) | INT | بله | 0 تا 2147483647 |

**توجه:** ویدیوی ورودی نباید بیشتر از ۶۰ ثانیه باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-----------|---------|----------|
| `video` | ویدیوی پردازش‌شده با پس‌زمینهٔ اصلی که با سایهٔ کروماکی انتخابی جایگزین شده، به‌صورت MP4 (H.264) برگردانده می‌شود | VIDEO |
