# Bria Video Green Screen

Этот узел заменяет фон видео на сплошной хромакей-экран с помощью API Bria. Он обрабатывает входное видео и возвращает новое видео, в котором исходный фон удалён и заменён равномерным зелёным или синим цветом экрана.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `видео` | Входное видео для обработки | VIDEO | Да | Видеофайл |
| `оттенок зелёного` | Сплошной оттенок хромакея, применяемый за объектом переднего плана: broadcast_green (#00B140), chroma_green (#00FF00) или blue_screen (#0000FF). | COMBO | Да | `"broadcast_green"`<br>`"chroma_green"`<br>`"blue_screen"` |
| `seed` | Сид управляет тем, должен ли узел выполняться заново; результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Да | от 0 до 2147483647 |

**Примечание:** Входное видео не должно превышать 60 секунд по длительности.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `video` | Обработанное видео (MP4, H.264) с заменой исходного фона на выбранный оттенок хромакея | VIDEO |
