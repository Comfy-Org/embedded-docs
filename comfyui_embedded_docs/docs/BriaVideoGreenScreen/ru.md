# Bria Video Green Screen

Этот узел заменяет фон видео на однотонный хромакейный экран с помощью Bria API. Он обрабатывает входное видео и возвращает новое видео, в котором исходный фон удалён и заменён равномерным зелёным или синим цветом экрана.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `video` | Входное видео для обработки | VIDEO | Да | Video file |
| `green_shade` | Однотонный хромакейный оттенок, накладываемый за передним планом: broadcast_green (#00B140), chroma_green (#00FF00) или blue_screen (#0000FF) | COMBO | Да | `"broadcast_green"`<br>`"chroma_green"`<br>`"blue_screen"` |
| `seed` | `seed` управляет тем, должен ли узел выполняться повторно; результаты недетерминированы независимо от seed (по умолчанию: 0) | INT | Да | 0 to 2147483647 |

**Примечание:** Длительность входного видео не должна превышать 60 секунд.

## Выходные параметры

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `video` | Обработанное видео, в котором исходный фон заменён выбранным хромакейным оттенком; возвращается в формате MP4 (H.264) | VIDEO |
