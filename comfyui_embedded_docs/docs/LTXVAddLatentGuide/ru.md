# LTXV Добавить латентную направляющую

Узел LTXV Add Latent Guide закрепляет уже закодированный latent в качестве направляющего, для случаев, когда направляющий поступает с более раннего этапа, а не из изображения. Он даёт тот же эффект, что и LTXV Add Guide, но без цикла декодирования/кодирования через VAE. Направляющий, который пространственно меньше целевого (референс IC-LoRA или детализации), дилатируется на разреженную сетку, а его конечные позиции RoPE расширяются на тот же коэффициент, чтобы он покрывал целевой холст, а не только его верхний левый угол.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Вход положительного кондиционирования. | CONDITIONING | Да | N/A |
| `negative` | Вход отрицательного кондиционирования. | CONDITIONING | Да | N/A |
| `vae` | Модель VAE, используемая для считывания формулы индекса уменьшения масштаба для размещения кадров. | VAE | Да | N/A |
| `latent` | Целевой latent видео, на который закрепляется направляющий. | LATENT | Да | N/A |
| `guiding_latent` | Latent направляющего. Его пространственный размер должен делить размер целевого на одно и то же целое число по обеим осям; при одинаковом размере он закрепляется как есть, размер в половину обрабатывается как референс IC-LoRA с коэффициентом x2. | LATENT | Да | N/A |
| `latent_idx` | Индекс latent-кадра, с которого начинается направляющий, отсчитывается в latent-кадрах, а не в пиксельных кадрах. Отрицательные значения размещают направляющий на кадрах до начала latent, а не отсчитываются назад от его конца. По умолчанию: 0. | INT | Да | -9999 до 9999 |
| `strength` | Ограничено значением 1.0. Дилатированный направляющий помечает свои позиции заполнения (padding) отрицательной маской шумоподавления, чтобы модель их отбросила; при значении выше 1.0 сохранённые позиции тоже стали бы отрицательными, и весь направляющий был бы отброшен. Для усиления свыше 1.0 используйте вместо этого attention_mask. По умолчанию: 1.0. | FLOAT | Да | 0.0 до 1.0, step 0.01 |
| `attention_mask` | Необязательная пространственная маска в пиксельном пространстве. Управляет влиянием кондиционирования по регионам через self-attention, умножается на strength. | MASK | Нет | N/A |

### Примечания

- И `latent`, и `guiding_latent` должны быть 5D видео-latent-тензорами формы (batch, channels, frames, height, width).
- Направляющий должен помещаться внутри целевого latent: количество кадров направляющего, сложенное с `latent_idx`, не должно выходить за конец целевого latent. Отрицательные значения `latent_idx` допустимы и размещают направляющий перед началом latent.
- Пространственный размер направляющего должен делить пространственный размер целевого на целое число как по оси высоты, так и по оси ширины.
- Коэффициент по высоте и коэффициент по ширине должны быть одинаковыми (квадратное соотношение). Неквадратное соотношение вызывает ошибку, поскольку дилатация и размещение RoPE используют единый коэффициент уменьшения масштаба для обеих осей.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное кондиционирование с прикреплённым направляющим. | CONDITIONING |
| `negative` | Отрицательное кондиционирование с прикреплённым направляющим. | CONDITIONING |
| `latent` | Выходной latent с применённым направляющим, включая обновлённую `noise_mask`. | LATENT |
