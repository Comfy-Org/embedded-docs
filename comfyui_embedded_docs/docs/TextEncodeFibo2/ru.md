# TextEncodeFibo2

Кодирует промпт Fibo 2.0 в кондиционирование и соответствующий пустой латент. Промпт может быть обычным текстом или структурированным JSON-описанием; при подключённых изображениях он становится инструкцией по редактированию либо JSON-описанием результата с ключом `edit_instruction`, а изображения при подключённом VAE выступают в роли эталонных латентов для обоих выходов. Сэмплируйте выход `latent`, размер которого совпадает с размером, до которого обрезаются изображения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `clip` | Текстовый энкодер Fibo 2.0, используемый для токенизации и кодирования промпта. | CLIP | Да | - |
| `prompt` | Описание, из которого нужно сгенерировать, или инструкция по редактированию, когда подключены изображения. Ссылайтесь на изображения как `<image_1>`, `<image_2>` и т. д. Также подойдёт JSON-описание ожидаемого результата, где изменение описано в ключе `edit_instruction`. | STRING | Да | - |
| `negative_prompt` | Описание, от которого нужно отходить; кодируется как негативное кондиционирование. Пустое значение — это нулевое описание (null caption), с которым обучалась Fibo 2.0 для classifier-free guidance (по умолчанию: пусто). | STRING | Да | - |
| `vae` | VAE, используемый для кодирования изображений в эталонные латенты. Без него изображения влияют только на текстовое кодирование. | VAE | Нет | - |
| `images` | Изображения для редактирования, до 16. Одно изображение масштабируется и обрезается по центру до размера результата, поскольку редактирование совпадает с ним пиксель в пиксель; несколько изображений каждое масштабируется до собственного обученного размера. | IMAGE | Нет | от 0 до 16 изображений |
| `width` | Ширина результата, округлённая вниз до кратной 16. Значение 0 использует размер, на котором обучалась Fibo 2.0 для соотношения сторон первого изображения, около 1 мегапикселя, или 1024 без изображений (по умолчанию: 0). | INT | Да | от 0 до 16384 (шаг 16) |
| `height` | Высота результата, округлённая вниз до кратной 16. Значение 0 использует размер, на котором обучалась Fibo 2.0 для соотношения сторон первого изображения, около 1 мегапикселя, или 1024 без изображений (по умолчанию: 0). | INT | Да | от 0 до 16384 (шаг 16) |
| `batch_size` | Количество латентов для создания в пакете (по умолчанию: 1). | INT | Да | от 1 до 4096 |

Эталонные латенты прикрепляются к обоим выходам, поэтому изображения передаются вместе с кондиционированием, а не только с положительной ветвью. Если VAE не подключён, изображения видит только текстовый энкодер, и эталонные латенты не добавляются.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `positive` | Кондиционирование промпта, с эталонными латентами, когда подключены VAE и изображения. | CONDITIONING |
| `negative` | Кондиционирование для `negative_prompt`, только текст, с теми же эталонными латентами. | CONDITIONING |
| `latent` | Пустой латент запрошенного размера, готовый к сэмплированию. | LATENT |
