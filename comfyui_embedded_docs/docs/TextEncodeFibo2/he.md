# TextEncodeFibo2

קידוד פרומפט של Fibo 2.0 לקונדישנינג ול-latent ריק תואם. הפרומפט הוא טקסט רגיל או כיתוב JSON מובנה; כאשר מחוברות תמונות הוא הופך להוראת העריכה, או לכיתוב JSON של התוצאה עם מפתח `edit_instruction`, והתמונות משמשות כ-latents עזר לשני הפלטים כאשר VAE מחובר. בצעו דגימה של פלט `latent`, שגודלו הוא הגודל שאליו התמונות נחתכות.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `clip` | מקודד הטקסט של Fibo 2.0 המשמש לטוקניזציה ולקידוד הפרומפט. | CLIP | כן | - |
| `prompt` | הכיתוב שממנו ליצור, או הוראת העריכה כאשר תמונות מחוברות. יש להתייחס לתמונות בתור `<image_1>`, `<image_2>` וכן הלאה. כיתוב JSON של התוצאה הצפויה גם עובד, כאשר השינוי מתואר במפתח `edit_instruction` שלו. | STRING | כן | - |
| `negative_prompt` | כיתוב שממנו יש להתרחק, המקודד כקונדישנינג שלילי. ריק הוא כיתוב ה-null שבו Fibo 2.0 אומן עבור classifier-free guidance (ברירת מחדל: ריק). | STRING | כן | - |
| `vae` | VAE המשמש לקידוד התמונות ל-latents עזר. בלעדיו התמונות משמשות רק כדי להתנות את קידוד הטקסט. | VAE | לא | - |
| `images` | תמונות לעריכה, עד 16. תמונה בודדת משונה בגודל ונחתכת מהמרכז לגודל התוצאה, מפני שהעריכה מתיישרת איתה פיקסל אחר פיקסל; כאשר יש כמה תמונות, כל אחת מוגדלת לגודל שעבורו היא אומנה. | IMAGE | לא | 0 עד 16 תמונות |
| `width` | רוחב התוצאה, מעוגל כלפי מטה לכפולה של 16. ערך 0 משתמש בגודל שבו Fibo 2.0 אומן עבור יחס הגובה-רוחב של התמונה הראשונה, כ-1 מגה-פיקסל, או 1024 ללא תמונות (ברירת מחדל: 0). | INT | כן | 0 עד 16384 (צעד 16) |
| `height` | גובה התוצאה, מעוגל כלפי מטה לכפולה של 16. ערך 0 משתמש בגודל שבו Fibo 2.0 אומן עבור יחס הגובה-רוחב של התמונה הראשונה, כ-1 מגה-פיקסל, או 1024 ללא תמונות (ברירת מחדל: 0). | INT | כן | 0 עד 16384 (צעד 16) |
| `batch_size` | מספר ה-latents ליצירה באצווה (ברירת מחדל: 1). | INT | כן | 1 עד 4096 |

latents העזר מצורפים לשני הפלטים, כך שהתמונות עוברות יחד עם הקונדישנינג ולא רק עם הענף החיובי. כאשר ה-VAE אינו מחובר, התמונות נראות רק על ידי מקודד הטקסט ולא מתווספים latents עזר.

## פלטים

| שם פלט | תיאור | סוג נתונים |
| --- | --- | --- |
| `positive` | קונדישנינג של הפרומפט, יחד עם latents העזר כאשר VAE ותמונות מחוברים. | CONDITIONING |
| `negative` | קונדישנינג של `negative_prompt`, טקסט בלבד, עם אותם latents עזר. | CONDITIONING |
| `latent` | latent ריק בגודל המבוקש, מוכן לדגימה. | LATENT |
