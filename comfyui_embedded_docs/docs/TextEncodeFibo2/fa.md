# TextEncodeFibo2

یک پرامپت Fibo 2.0 را به conditioning و یک latent خالی متناظر کدگذاری می‌کند. پرامپت یا متن ساده است یا یک کپشن JSON ساختاریافته؛ وقتی تصاویر متصل باشند، به دستور ویرایش تبدیل می‌شود، یا به یک کپشن JSON از نتیجه با کلید `edit_instruction`، و تصاویر زمانی که VAE متصل است به‌عنوان latentهای مرجع برای هر دو خروجی عمل می‌کنند. از خروجی `latent` نمونه‌گیری کنید که اندازه‌اش همان اندازه‌ای است که تصاویر به آن برش داده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `clip` | رمزگذار متنی Fibo 2.0 که برای توکن‌بندی و کدگذاری پرامپت استفاده می‌شود. | CLIP | بله | - |
| `prompt` | کپشنی که تولید بر اساس آن انجام می‌شود، یا وقتی تصاویر متصل هستند، دستور ویرایش. به تصاویر با `<image_1>`، `<image_2>` و به همین ترتیب ارجاع دهید. یک کپشن JSON از نتیجهٔ مورد انتظار نیز کار می‌کند، با تغییری که در کلید `edit_instruction` آن توصیف شده است. | STRING | بله | - |
| `negative_prompt` | کپشنی که باید از آن دوری کرد و به‌عنوان conditioning منفی کدگذاری می‌شود. مقدار غیرخالی همان‌طور که هست و بدون پاکسازی مانند کپشن، داخل قالب چت Fibo 2.0 قرار می‌گیرد. مقدار خالی همان کپشن تهی است که Fibo 2.0 برای classifier-free guidance در جریان‌های کاری ویرایش با آن آموزش دیده است (پیش‌فرض: خالی). | STRING | بله | - |
| `vae` | VAEای که برای کدگذاری تصاویر به latentهای مرجع استفاده می‌شود. بدون آن، تصاویر فقط کدگذاری متنی را شرطی می‌کنند. | VAE | خیر | - |
| `images` | تصاویری برای ویرایش، حداکثر ۱۶ تصویر. یک تصویر منفرد به اندازهٔ نتیجه مقیاس و از مرکز برش داده می‌شود، زیرا ویرایش پیکسل‌به‌پیکسل با آن هم‌تراز می‌شود؛ چند تصویر هرکدام به اندازهٔ آموزش‌دیدهٔ خودشان مقیاس می‌شوند. | IMAGE | خیر | 0 تا 16 تصویر |
| `width` | عرض نتیجه، که به‌سمت پایین به مضربی از ۱۶ گرد می‌شود. مقدار 0 از اندازه‌ای استفاده می‌کند که Fibo 2.0 برای نسبت ابعاد تصویر اول با آن آموزش دیده است، حدود ۱ مگاپیکسل، یا 1024 بدون تصاویر (پیش‌فرض: 0). | INT | بله | 0 تا 16384 (گام 16) |
| `height` | ارتفاع نتیجه، که به‌سمت پایین به مضربی از ۱۶ گرد می‌شود. مقدار 0 از اندازه‌ای استفاده می‌کند که Fibo 2.0 برای نسبت ابعاد تصویر اول با آن آموزش دیده است، حدود ۱ مگاپیکسل، یا 1024 بدون تصاویر (پیش‌فرض: 0). | INT | بله | 0 تا 16384 (گام 16) |
| `batch_size` | تعداد latentهایی که در batch ایجاد می‌شوند (پیش‌فرض: 1). | INT | بله | 1 تا 4096 |

latentهای مرجع به هر دو خروجی متصل می‌شوند، بنابراین تصاویر همراه conditioning منتقل می‌شوند نه فقط همراه شاخهٔ مثبت. وقتی VAE متصل نیست، تصاویر فقط توسط رمزگذار متنی دیده می‌شوند و هیچ latent مرجعی اضافه نمی‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `positive` | conditioning پرامپت، همراه با latentهای مرجع زمانی که VAE و تصاویر متصل باشند. | CONDITIONING |
| `negative` | conditioning مربوط به `negative_prompt`، فقط متنی، همراه با همان latentهای مرجع. | CONDITIONING |
| `latent` | latent خالی با اندازهٔ درخواستی، آماده برای نمونه‌گیری. | LATENT |
