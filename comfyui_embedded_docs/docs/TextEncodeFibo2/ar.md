# TextEncodeFibo2

يرمّز موجه Fibo 2.0 إلى تكييف (conditioning) وإلى latent فارغ مطابق. يكون الموجه إما نصًا عاديًا أو وصفًا JSON منظمًا؛ وعند توصيل الصور يصبح تعليمة التحرير، أو وصفًا JSON للنتيجة يتضمن مفتاح `edit_instruction`، وتعمل الصور كـ latents مرجعية لكلا المخرجين عند توصيل VAE. خُذ عينات من مخرج `latent`، الذي يكون حجمه هو الحجم الذي تُقصّ إليه الصور.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
| --- | --- | --- | --- | --- |
| `clip` | مشفّر النص Fibo 2.0 المستخدم لتقسيم الموجه إلى رموز وترميزه. | CLIP | نعم | - |
| `prompt` | الوصف الذي تُولّد منه، أو تعليمة التحرير عند توصيل الصور. أشر إلى الصور بالصيغة `<image_1>` و`<image_2>` وهكذا. يمكن أيضًا استخدام وصف JSON للنتيجة المتوقعة، مع وصف التغيير في مفتاح `edit_instruction` الخاص به. | STRING | نعم | - |
| `negative_prompt` | وصف موجّه للابتعاد عنه، ويُرمّز كتكييف سلبي. تعني القيمة الفارغة الوصف الفارغ (null caption) الذي دُرّب عليه Fibo 2.0 من أجل التوجيه بدون مصنف (classifier-free guidance) (الافتراضي: فارغ). | STRING | نعم | - |
| `vae` | VAE المستخدم لترميز الصور إلى latents مرجعية. من دونه، تؤثر الصور في ترميز النص فقط. | VAE | لا | - |
| `images` | الصور المراد تحريرها، حتى 16 صورة. تُحجّم الصورة الواحدة وتُقص من المركز إلى حجم النتيجة، لأن التحرير يحاذيها بكسلًا بكسل؛ وتُحجّم كل صورة من الصور المتعددة إلى الحجم المدرّب الخاص بها. | IMAGE | لا | 0 إلى 16 صورة |
| `width` | عرض النتيجة، مقرّبًا للأسفل إلى مضاعف للعدد 16. تعني القيمة 0 استخدام الحجم الذي دُرّب عليه Fibo 2.0 لنسبة أبعاد الصورة الأولى، نحو 1 ميغابكسل، أو 1024 عند عدم وجود صور (الافتراضي: 0). | INT | نعم | 0 إلى 16384 (بخطوة 16) |
| `height` | ارتفاع النتيجة، مقرّبًا للأسفل إلى مضاعف للعدد 16. تعني القيمة 0 استخدام الحجم الذي دُرّب عليه Fibo 2.0 لنسبة أبعاد الصورة الأولى، نحو 1 ميغابكسل، أو 1024 عند عدم وجود صور (الافتراضي: 0). | INT | نعم | 0 إلى 16384 (بخطوة 16) |
| `batch_size` | عدد الـ latents المراد إنشاؤها في الدفعة (الافتراضي: 1). | INT | نعم | 1 إلى 4096 |

تُرفق الـ latents المرجعية بكلا المخرجين، لذا تنتقل الصور مع الـ conditioning بدلًا من أن ترتبط بالفرع الموجب فقط. وعندما لا يكون VAE موصولًا، لا يرى الصورَ سوى مشفّر النص ولا تُضاف أي latents مرجعية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
| --- | --- | --- |
| `positive` | تكييف الموجه، مع الـ latents المرجعية عند توصيل VAE والصور. | CONDITIONING |
| `negative` | تكييف `negative_prompt`، نص فقط، مع الـ latents المرجعية نفسها. | CONDITIONING |
| `latent` | latent فارغ بالحجم المطلوب، جاهز لأخذ العينات منه. | LATENT |
