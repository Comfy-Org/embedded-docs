# HeyGen Voice 1.0 Text to Speech

Озвучивает текст голосом HeyGen. Узел отправляет текст и идентификатор голоса в HeyGen и возвращает сгенерированную речь в виде аудио. Доступны две модели: `heygen-voice-1` и более быстрая и дешёвая `heygen-voice-1-turbo`. Чтобы озвучить текст голосом, клонированным по записи, используйте HeyGen Voice 1.0 Instant Clone Text to Speech.

При выборе `model` отображаются параметры, специфичные для этой модели.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Используемая модель. `heygen-voice-1-turbo` работает быстрее и стоит дешевле. При выборе модели отображаются специфичные для неё параметры: `voice_id`, `text`, `language` и `expressiveness_boost`. | DYNAMIC_COMBO | Да | `"heygen-voice-1"`<br>`"heygen-voice-1-turbo"` |
| `voice_id` | Идентификатор голоса HeyGen, например из библиотеки голосов HeyGen (по умолчанию: пусто). | STRING | Да | N/A |
| `text` | Текст для озвучивания. До 5000 символов; речь длительностью более примерно 12 минут завершается ошибкой, поэтому очень длинный китайский или японский текст следует разбивать на части (по умолчанию: пусто). | STRING | Да | от 1 до 5000 символов |
| `language` | Язык текста. Указывайте его для близкородственных языков, таких как сербский или малайский, которые может перепутать автоопределение (по умолчанию: "auto"). | COMBO | Да | `"auto"`<br>Несколько языковых предустановок |
| `expressiveness_boost` | Чем выше значение, тем выразительнее речь; чем ниже значение, тем ближе она к исходному голосу (по умолчанию: 0.5). | FLOAT | Да | от 0.0 до 1.0 (шаг 0.05) |

**Примечание:** `voice_id` не должен быть пустым; если он отсутствует, узел останавливается с ошибкой. `text` должен содержать хотя бы один символ.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `AUDIO` | Речь, сгенерированная из текста и произнесённая выбранным голосом. | AUDIO |
