# SkipLayerGuidanceSD3

הצומת SkipLayerGuidanceSD3 משפר את ההכוונה לעבר מבנה מפורט על ידי הפעלת סט נוסף של הנחיה ללא מסווג (classifier-free guidance) עם שכבות מדולגות. מימוש ניסיוני זה נוצר בהשראת Perturbed Attention Guidance ופועל באמצעות עקיפה סלקטיבית של שכבות מסוימות במהלך תהליך ההתניה השלילית כדי לשפר פרטים מבניים בפלט שנוצר.

## קלטים

| פרמטר | תיאור | סוג נתונים | חובה | טווח |
| --- | --- | --- | --- | --- |
| `model` | המודל שעליו להחיל את הנחיית דילוג השכבות | MODEL | כן | - |
| `layers` | רשימת אינדקסים של שכבות לדילוג, מופרדת בפסיקים (ברירת מחדל: "7, 8, 9") | STRING | כן | - |
| `scale` | עוצמת אפקט הנחיית דילוג השכבות (ברירת מחדל: 3.0) | FLOAT | כן | 0.0 - 10.0 |
| `start_percent` | נקודת ההתחלה של החלת ההנחיה כאחוז מסך הצעדים (ברירת מחדל: 0.01) | FLOAT | כן | 0.0 - 1.0 |
| `end_percent` | נקודת הסיום של החלת ההנחיה כאחוז מסך הצעדים (ברירת מחדל: 0.15) | FLOAT | כן | 0.0 - 1.0 |
