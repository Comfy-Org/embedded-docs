# ElevenLabs تحويل النص إلى حوار

تولّد عقدة ElevenLabs Text to Dialogue حوارًا صوتيًا متعدد المتحدثين من النص. تتيح لك إنشاء محادثة من خلال تحديد أسطر نصية مختلفة وأصوات مميزة لكل مشارك. ترسل العقدة طلب الحوار إلى واجهة برمجة تطبيقات ElevenLabs وتُرجع الصوت المُولَّد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الثبات` | ثبات الصوت. القيم الأقل تعطي نطاقًا عاطفيًا أوسع، بينما تنتج القيم الأعلى كلامًا أكثر اتساقًا لكنه قد يكون رتيبًا. (الافتراضي: 0.5) | FLOAT | لا | 0.0 - 1.0 |
| `تطبيق تنسيق النص` | وضع تطبيع النص. يسمح الخيار 'auto' للنظام باتخاذ القرار، بينما يطبق الخيار 'on' التطبيع دائمًا، ويتخطاه الخيار 'off'. | COMBO | لا | `"auto"`<br>`"on"`<br>`"off"` |
| `النموذج` | النموذج المستخدم لتوليد الحوار. | COMBO | لا | `"eleven_v3"` |
| `عدد الحوارات` | عدد إدخالات الحوار. سيؤدي اختيار رقم إلى توليد عدد مماثل من حقول إدخال النص والصوت. | DYNAMIC_COMBO | نعم | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `رمز اللغة` | رمز اللغة وفق معيار ISO-639-1 أو ISO-639-3 (مثل 'en' أو 'es' أو 'fra'). اتركه فارغًا للكشف التلقائي. (الافتراضي: فارغ) | STRING | لا | - |
| `البذرة` | البذرة (Seed) لإمكانية إعادة الإنتاج. (الافتراضي: 1) | INT | لا | 0 - 4294967295 |
| `صيغة الإخراج` | صيغة إخراج الصوت. | COMBO | لا | `"mp3_44100_192"`<br>`"opus_48000_192"` |

**ملاحظة:** معامل `inputs` ديناميكي. عند تحديد رقم (مثل "3")، ستعرض العقدة ثلاثة حقول إدخال مقابلة من نص وصوت (مثل `text1`، `voice1`، `text2`، `voice2`، `text3`، `voice3`). يجب أن يحتوي كل حقل `text` على حرف واحد على الأقل. ويتوقع كل حقل `voice` صوتًا موصولًا من عقدة Voice Selector أو Instant Voice Clone.
