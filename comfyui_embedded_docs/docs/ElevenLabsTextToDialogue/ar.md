# ElevenLabs تحويل النص إلى حوار

تُنشئ عقدة ElevenLabs Text to Dialogue حوارًا صوتيًا متعدد المتحدثين من النص. تتيح لك إنشاء محادثة عبر تحديد أسطر نصية مختلفة وأصوات مميزة لكل مشارك. ترسل العقدة طلب الحوار إلى ElevenLabs API وتُرجع الصوت المُنشأ.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الثبات` | استقرار الصوت. القيم الأقل تمنح نطاقًا عاطفيًا أوسع، بينما تنتج القيم الأعلى كلامًا أكثر اتساقًا لكنه قد يكون رتيبًا. (الافتراضي: 0.5) | FLOAT | نعم | 0.0 - 1.0 |
| `تطبيق تنسيق النص` | وضع تسوية النص. 'auto' يدع النظام يقرر، 'on' يطبّق التسوية دائمًا، 'off' يتخطاها. | COMBO | نعم | `"auto"`<br>`"on"`<br>`"off"` |
| `النموذج` | النموذج المستخدم لإنشاء الحوار. | COMBO | نعم | `"eleven_v3"` |
| `عدد الحوارات` | عدد عناصر الحوار. اختيار رقم يُنشئ هذا العدد من أزواج مدخلات النص والصوت. | DYNAMIC_COMBO | نعم | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `رمز اللغة` | رمز اللغة ISO-639-1 أو ISO-639-3 (مثل 'en'، 'es'، 'fra'). اتركه فارغًا للكشف التلقائي. (الافتراضي: فارغ) | STRING | نعم | - |
| `البذرة` | البذرة لإمكانية إعادة الإنتاج. (الافتراضي: 1) | INT | نعم | 0 - 4294967295 |
| `صيغة الإخراج` | تنسيق إخراج الصوت. | COMBO | نعم | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### مدخلات عناصر الحوار

مشتركة بين جميع خيارات `inputs`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | محتوى النص لعنصر الحوار المقابل. تُنشئ العقدة حقل `text` واحدًا لكل عنصر حوار محدد. يجب أن تحتوي كل قيمة نصية على حرف واحد على الأقل. | STRING | نعم | - |
| `voice1` ... `voice10` | الصوت لعنصر الحوار المقابل. وصّله من عقدة Voice Selector أو Instant Voice Clone. تُنشئ العقدة حقل `voice` واحدًا لكل عنصر حوار محدد. | ELEVENLABS_VOICE | نعم | - |

**ملاحظة:** يمكن لمحدد `inputs` إنشاء ما يصل إلى 10 عناصر حوار. يتطلب كل عنصر حقل `text` وحقل `voice` معًا. لا يمكن أن تكون قيمة `text` فارغة. يتوقع مدخل `voice` معرّف الصوت الذي توفره عقدة صوت ElevenLabs متوافقة.
