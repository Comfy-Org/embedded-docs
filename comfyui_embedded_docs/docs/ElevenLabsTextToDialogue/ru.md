# ElevenLabs Текст в диалог

Узел ElevenLabs Text to Dialogue генерирует многоголосый аудиодиалог из текста. Он позволяет создавать разговор, указывая разные текстовые реплики и отдельные голоса для каждого участника. Узел отправляет запрос диалога в API ElevenLabs и возвращает сгенерированное аудио.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `stability` | Стабильность голоса. Меньшие значения дают более широкий эмоциональный диапазон, более высокие значения создают более согласованную, но потенциально монотонную речь. (по умолчанию: 0.5) | FLOAT | Да | 0.0 - 1.0 |
| `apply_text_normalization` | Режим нормализации текста. 'auto' позволяет системе решить, 'on' всегда применяет нормализацию, 'off' пропускает её. | COMBO | Да | `"auto"`<br>`"on"`<br>`"off"` |
| `model` | Модель для генерации диалога. | COMBO | Да | `"eleven_v3"` |
| `inputs` | Количество реплик диалога. Выбор числа создаёт соответствующее количество пар входов текста и голоса. | DYNAMIC_COMBO | Да | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `language_code` | Код языка ISO-639-1 или ISO-639-3 (например, 'en', 'es', 'fra'). Оставьте пустым для автоматического определения. (по умолчанию: пусто) | STRING | Да | - |
| `seed` | Seed для воспроизводимости. (по умолчанию: 1) | INT | Да | 0 - 4294967295 |
| `output_format` | Формат выходного аудио. | COMBO | Да | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### Входы реплик диалога

Общие для всех вариантов `inputs`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | Текстовое содержимое для соответствующей реплики диалога. Узел создаёт одно поле `text` для каждой выбранной реплики диалога. Каждое значение текста должно содержать как минимум один символ. | STRING | Да | - |
| `voice1` ... `voice10` | Голос для соответствующей реплики диалога. Подключите от узла Voice Selector или Instant Voice Clone. Узел создаёт одно поле `voice` для каждой выбранной реплики диалога. | ELEVENLABS_VOICE | Да | - |

**Примечание:** Селектор `inputs` может создать до 10 реплик диалога. Каждая реплика требует как поле `text`, так и поле `voice`. Значение `text` не может быть пустым. Вход `voice` ожидает ID голоса, предоставленный совместимым узлом голоса ElevenLabs.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `audio` | Сгенерированное многоголосое аудио диалога в выбранном формате вывода. | AUDIO |
