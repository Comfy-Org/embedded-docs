# ElevenLabs 文字轉對話

ElevenLabs Text to Dialogue 節點會從文字生成多說話者音訊對話。它可讓您透過指定不同的文字行與每位參與者不同的語音來建立對話。此節點會將對話請求傳送至 ElevenLabs API，並回傳生成的音訊。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `穩定性` | 語音穩定性。較低的值會帶來更廣泛的情緒範圍，較高的值會產生更一致但可能較單調的語音。（預設：0.5） | FLOAT | 是 | 0.0 - 1.0 |
| `套用文字正規化` | 文字正規化模式。'auto' 讓系統自行決定，'on' 一律套用正規化，'off' 則略過。 | COMBO | 是 | `"auto"`<br>`"on"`<br>`"off"` |
| `模型` | 用於對話生成的模型。 | COMBO | 是 | `"eleven_v3"` |
| `對話項目數` | 對話條目數量。選取數字會建立對應數量的 `text` 與 `voice` 輸入配對。 | DYNAMIC_COMBO | 是 | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `語言代碼` | ISO-639-1 或 ISO-639-3 語言代碼（例如 'en'、'es'、'fra'）。留空以自動偵測。（預設：空） | STRING | 是 | - |
| `隨機種子` | 用於重現結果的種子。（預設：1） | INT | 是 | 0 - 4294967295 |
| `輸出格式` | 音訊輸出格式。 | COMBO | 是 | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### 對話條目輸入

所有 `inputs` 選項共用。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | 對應對話條目的文字內容。節點會為每個選取的對話條目建立一個 `text` 欄位。每個文字值必須至少包含一個字元。 | STRING | 是 | - |
| `voice1` ... `voice10` | 對應對話條目的語音。可從 Voice Selector 或 Instant Voice Clone 節點連接。節點會為每個選取的對話條目建立一個 `voice` 欄位。 | ELEVENLABS_VOICE | 是 | - |

**注意：** `inputs` 選擇器最多可建立 10 個對話條目。每個條目都需要一個 `text` 欄位和一個 `voice` 欄位。`text` 值不能為空。`voice` 輸入需要由相容的 ElevenLabs 語音節點提供的語音 ID。
