# تبدیل متن به دیالوگ ElevenLabs

گره ElevenLabs Text to Dialogue یک دیالوگ صوتی چندگوینده از متن تولید می‌کند. این گره به شما امکان می‌دهد با مشخص کردن خطوط متنی مختلف و صداهای متمایز برای هر شرکت‌کننده، یک مکالمه ایجاد کنید. گره درخواست دیالوگ را به API سرویس ElevenLabs ارسال کرده و صوتی تولیدشده را بازمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `stability` | پایداری صدا. مقادیر پایین‌تر محدودهٔ احساسی گسترده‌تری می‌دهند؛ مقادیر بالاتر گفتاری سازگارتر ولی احتمالاً یکنواخت تولید می‌کنند. (پیش‌فرض: 0.5) | FLOAT | خیر | 0.0 - 1.0 |
| `apply_text_normalization` | حالت عادی‌سازی متن. «auto» به سیستم اجازه می‌دهد تصمیم بگیرد، «on» همیشه عادی‌سازی را اعمال می‌کند، «off» آن را نادیده می‌گیرد. | COMBO | خیر | `"auto"`<br>`"on"`<br>`"off"` |
| `model` | مدل مورد استفاده برای تولید دیالوگ. | COMBO | خیر | `"eleven_v3"` |
| `inputs` | تعداد ورودی‌های دیالوگ. انتخاب یک عدد، به همان تعداد فیلد ورودی متن و صدا ایجاد می‌کند. | DYNAMIC_COMBO | بله | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `language_code` | کد زبان ISO-639-1 یا ISO-639-3 (مثلاً «en»، «es»، «fra»). برای تشخیص خودکار خالی بگذارید. (پیش‌فرض: خالی) | STRING | خیر | - |
| `seed` | مقدار seed برای بازتولیدپذیری. (پیش‌فرض: 1) | INT | خیر | 0 - 4294967295 |
| `output_format` | قالب خروجی صدا. | COMBO | خیر | `"mp3_44100_192"`<br>`"opus_48000_192"` |

**توجه:** پارامتر `inputs` پویا است. وقتی عددی را انتخاب می‌کنید (مثلاً «3»)، گره سه فیلد ورودی متن و صدا متناظر را نمایش می‌دهد (مثلاً `text1`، `voice1`، `text2`، `voice2`، `text3`، `voice3`). هر فیلد `text` باید حداقل یک نویسه داشته باشد. هر فیلد `voice` انتظار صدایی متصل از گره Voice Selector یا Instant Voice Clone را دارد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `audio` | صوتی دیالوگ چندگویندهٔ تولیدشده در قالب خروجی انتخاب‌شده. | AUDIO |
