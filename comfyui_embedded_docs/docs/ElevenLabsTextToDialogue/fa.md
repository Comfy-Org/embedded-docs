# تبدیل متن به دیالوگ ElevenLabs

گره ElevenLabs Text to Dialogue یک دیالوگ صوتی چندگوینده از متن تولید می‌کند. این گره به شما امکان می‌دهد با تعیین خطوط متنی متفاوت و صداهای متمایز برای هر شرکت‌کننده، یک گفتگو ایجاد کنید. گره درخواست دیالوگ را به ElevenLabs API می‌فرستد و صدای تولیدشده را برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `stability` | پایداری صدا. مقادیر کمتر گستره احساسی بازتری می‌دهند؛ مقادیر بالاتر گفتاری باثبات‌تر اما بالقوه یکنواخت تولید می‌کنند. (پیش‌فرض: 0.5) | FLOAT | بله | 0.0 - 1.0 |
| `apply_text_normalization` | حالت نرمال‌سازی متن. 'auto' اجازه می‌دهد سیستم تصمیم بگیرد، 'on' همیشه نرمال‌سازی را اعمال می‌کند، 'off' آن را نادیده می‌گیرد. | COMBO | بله | `"auto"`<br>`"on"`<br>`"off"` |
| `model` | مدل مورد استفاده برای تولید دیالوگ. | COMBO | بله | `"eleven_v3"` |
| `inputs` | تعداد مدخل‌های دیالوگ. انتخاب یک عدد، همان تعداد جفت ورودی متن و صدا ایجاد می‌کند. | DYNAMIC_COMBO | بله | `"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"` |
| `language_code` | کد زبان ISO-639-1 یا ISO-639-3 (مثلاً 'en'، 'es'، 'fra'). برای تشخیص خودکار خالی بگذارید. (پیش‌فرض: خالی) | STRING | بله | - |
| `seed` | Seed برای تکرارپذیری. (پیش‌فرض: 1) | INT | بله | 0 - 4294967295 |
| `output_format` | قالب خروجی صدا. | COMBO | بله | `"mp3_44100_192"`<br>`"opus_48000_192"` |

### ورودی‌های مدخل دیالوگ

مشترک میان همه گزینه‌های `inputs`.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | محتوای متنی برای مدخل دیالوگ مربوطه. گره برای هر مدخل دیالوگ انتخاب‌شده یک فیلد `text` ایجاد می‌کند. هر مقدار متنی باید حداقل یک نویسه داشته باشد. | STRING | بله | - |
| `voice1` ... `voice10` | صدا برای مدخل دیالوگ مربوطه. از یک گره Voice Selector یا Instant Voice Clone متصل کنید. گره برای هر مدخل دیالوگ انتخاب‌شده یک فیلد `voice` ایجاد می‌کند. | ELEVENLABS_VOICE | بله | - |

**توجه:** انتخاب‌گر `inputs` می‌تواند تا ۱۰ مدخل دیالوگ ایجاد کند. هر مدخل هم به یک فیلد `text` و هم به یک فیلد `voice` نیاز دارد. مقدار `text` نمی‌تواند خالی باشد. ورودی `voice` انتظار یک شناسه صدا را دارد که توسط یک گره سازگار صدای ElevenLabs ارائه می‌شود.

|-------------|-------------|-----------|
