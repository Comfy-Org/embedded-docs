# Pruna P-Video-2: изображение в видео

Анимирует изображение, превращая его в видео, с помощью модели P-Video-2 от Pruna. Первый кадр обязателен и фиксирует соотношение сторон выходного видео; необязательный последний кадр задаёт конечную точку, к которой нужно интерполировать. Промпт описывает, как движется сцена, а узел либо генерирует собственную звуковую дорожку, либо принимает аудиоклип, который управляет движением.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Видеомодель Pruna для использования. При выборе модели ниже отображаются её собственные входы. | DYNAMIC_COMBO | Да | `"p-video-2"` |

### Входы P-Video-2

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.first_frame` | Изображение, с которого начинается видео. Выходное видео сохраняет соотношение сторон этого изображения. | IMAGE | Да | - |
| `model.last_frame` | Изображение, которым заканчивается видео. Его соотношение сторон должно быть близко к соотношению сторон первого кадра. | IMAGE | Нет | - |
| `промпт` | Описывает, как движется и звучит сцена. Должен содержать хотя бы один непробельный символ, максимум 5000 символов (по умолчанию: пусто). | STRING | Да | До 5000 символов |
| `длительность` | Длительность видео в секундах. `"auto"` позволяет модели выбрать длительность на основе промпта. Игнорируется, когда подключён `model.audio`: тогда длительность видео определяется длительностью аудио, округлённой вверх до целой секунды, максимум до 20 секунд (по умолчанию: `"5"`). | COMBO | Да | `"auto"`<br>`"1"`<br>`"2"`<br>`"3"`<br>`"4"`<br>`"5"`<br>`"6"`<br>`"7"`<br>`"8"`<br>`"9"`<br>`"10"`<br>`"11"`<br>`"12"`<br>`"13"`<br>`"14"`<br>`"15"`<br>`"16"`<br>`"17"`<br>`"18"`<br>`"19"`<br>`"20"` |
| `разрешение` | Разрешение выходного видео. 720p даёт около 0,9 мегапикселя (1280x704 при 16:9), 1080p — около 2 мегапикселей (1920x1088 при 16:9) (по умолчанию: `"720p"`). | COMBO | Да | `"720p"`<br>`"1080p"` |
| `fps` | Кадров в секунду. 48 fps недоступно при включённом черновом режиме и разрешении 1080p (по умолчанию: `"24"`). | COMBO | Да | `"24"`<br>`"48"` |
| `черновик` | Более быстрый рендер с меньшей детализацией, тарифицируется по более низкой ставке, чем стандартный рендер (по умолчанию: False). | BOOLEAN | Да | True/False |
| `генерировать аудио` | Генерировать звуковую дорожку для видео. Игнорируется, когда подключён `model.audio`, который вместо этого становится звуковой дорожкой (по умолчанию: True). | BOOLEAN | Да | True/False |
| `улучшить промпт` | Переписывать промпт с большей детализацией перед генерацией; коротким промптам это необходимо. Отключите, чтобы точно воспроизвести результат с тем же seed (по умолчанию: True). Дополнительная настройка. | BOOLEAN | Да | True/False |
| `model.audio` | Аудио, которое управляет движением и становится звуковой дорожкой. Длительностью не менее 1 секунды; аудио длиннее 20 секунд обрезается. Задаёт длительность видео вместо `model.duration`. | AUDIO | Нет | - |
| `сид` | Seed для генерации. Один и тот же seed точно воспроизводит результат только когда `model.enhance_prompt` отключён (по умолчанию: 42). | INT | Да | от 0 до 2147483647 |

**Примечания:**

- `model.first_frame` обязателен и фиксирует соотношение сторон выходного видео, поэтому у этого узла нет входного параметра соотношения сторон.
- `model.last_frame` необязателен, но его соотношение сторон должно быть близко к соотношению сторон первого кадра, иначе узел выдаёт ошибку.
- `model.prompt` обязателен и ограничен 5000 символами.
- Черновой режим при 1080p нельзя сочетать с 48 fps: узел выдаёт ошибку, поэтому либо отключите черновой режим, либо используйте 24 fps.
- Подключённое аудио должно быть длительностью не менее 1 секунды; всё, что длиннее 20 секунд, игнорируется.
- Когда подключён `model.audio`, длительность видео задаёт аудио, поэтому `model.duration` и `model.generate_audio` не оказывают эффекта.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Сгенерированное видео со звуковой дорожкой. | VIDEO |
