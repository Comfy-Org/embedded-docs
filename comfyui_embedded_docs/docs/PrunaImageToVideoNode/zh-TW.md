# Pruna P-Video-2 圖片轉影片

使用 Pruna 的 P-Video-2 模型將圖片製作成動畫影片。第一幀為必填，並會固定輸出的長寬比；選填的最後一幀可為影片提供一個可插值趨近的結束點。提示詞描述場景如何移動，而此節點會自行生成配樂，或接收一段驅動動作的音訊片段。

| `模型` | 要使用的 Pruna 影片模型。選取模型後，下方會顯示其專屬輸入。 | DYNAMIC_COMBO | 是 | `"p-video-2"` |

**備註：**

- `model.first_frame` 為必填，且會固定輸出長寬比，因此此節點沒有長寬比輸入。
- `model.last_frame` 為選填，但其長寬比必須接近第一幀，否則節點會引發錯誤。
- `model.prompt` 為必填，且限制為 5000 個字元。
- 1080p 的草稿模式無法與 48 fps 搭配使用：節點會引發錯誤，因此請關閉草稿模式或改用 24 fps。
- 已連接的音訊長度必須至少 1 秒；超過 20 秒的部分會被忽略。
- 當 `model.audio` 已連接時，音訊會設定影片長度，因此 `model.duration` 和 `model.generate_audio` 不會生效。
